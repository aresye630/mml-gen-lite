# 修改本地用户属性（MOD OP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改网元侧已配置的本地用户的属性信息，包括密码、用户组、接入方式、用户状态、接入限制数、老化周期、密码有效期和允许登录时间段。具体有哪些本地用户，可以通过**LST OP**命令查出。

#### 注意事项

- 该命令执行后立即生效。
- 本地用户的属性（密码、状态、接入类型）变更时，会强制下线在线用户。
- 本地用户的其他属性变更不会对当前在线用户产生影响，已在线用户重新登录之后此配置变更生效。
- 当本地用户属性变更时，为降低安全风险，建议该用户重新登录。
- 修改网元侧已配置的用户的属性信息后，MANO侧该用户的属性信息要修改保持一致。
- 使用该命令配置用户允许二次授权后，用户状态正常时才能进行二次授权。状态不正常包括：用户未执行过首次登录修改初始密码、用户密码过期、用户被锁定等。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识                 | 参数名称            | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                          |
|:---------------------|:----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USERNAME             | 用户名             | 可选必选说明：必选参数 参数含义：本地用户的用户名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。不区分大小写。 默认值：无                                                                                                                                                                                                                                                                                                                                                     |
| PASSWORD             | 密码              | 可选必选说明：可选参数 参数含义：本地用户的密码。 数据来源：本端规划 取值范围：密码类型，密码长度范围为8～64，区分大小写。 默认值：无 配置原则： 密码必须包含数字、大写字母、小写字母、特殊字符，不包括逗号、分号、等号、双引号、单引号、问号和空格。密码不能包含账号或账号的反向字符串。密码不能与之前N次历史密码相同（与当前密码相同也视为与历史密码相同，即当前密码包含在N次历史密码之内），N为密码策略配置的历史密码保留个数。                                                                                                                                                                                                       |
| CFMPASSWORD          | 确认密码            | 可选必选说明：可选参数 参数含义：本地用户的确认密码。 数据来源：本端规划 取值范围：密码类型，密码长度范围为8～64。 默认值：无 配置原则：必须与第一次输入的密码一致。                                                                                                                                                                                                                                                                                                                                        |
| USERGROUPNAME        | 用户组             | 可选必选说明：可选参数 参数含义：本地用户的用户组。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。系统缺省定义了十个用户组： “manage-ug”：管理用户组“system-ug”：系统用户组“monitor-ug”：监视用户组“visit-ug”：参观用户组“ems-ug”：网管用户组“oper-manage-ug”：管理操作组“oper-system-ug”：系统操作组“time-client-ug”：time-client用户组“mano-ug”：mano用户组“internal-ug”：内联用户组其中“oper-manage-ug”、“oper-system-ug”、“time-client-ug”和“internal-ug”为内部使用用户组，不支持本地用户加入。  说明： 仅“emscomm”用户可添加进“ems-ug”组。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。 |
| SERVICESSH           | SSH服务           | 可选必选说明：可选参数 参数含义：用户能否采用SSH方式登录。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。SSH服务与HTTP服务不能同时使能。 默认值：无                                                                                                                                                                                                                                                                                                                            |
| SERVICEHTTP          | HTTP服务          | 可选必选说明：可选参数 参数含义：用户能否采用HTTP方式登录，mml业务中使用的登录方式实际是HTTPS非HTTP方式。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。SSH服务与HTTP服务不能同时使能。 默认值：无                                                                                                                                                                                                                                                                                              |
| USERSTATE            | 用户状态            | 可选必选说明：可选参数 参数含义：用户的状态。 数据来源：本端规划 取值范围：枚举类型。 block：用户状态为阻塞。active：用户状态为激活。 默认值：无                                                                                                                                                                                                                                                                                                                                              |
| MAXACCESSNUM         | 接入限制数目          | 可选必选说明：可选参数 参数含义：接入限制数目。 数据来源：本端规划 取值范围：整数类型，取值范围为1～10，2147483647。 默认值：无 配置原则：当不配置的情况下，缺省值为2147483647，此时不检查用户接入限制个数。可以通过将参数设置为缺省值，取消该配置。使用当前账号登录系统时需确保该参数值不小于2。                                                                                                                                                                                                                                                               |
| USERAGINGPERIOD      | 用户老化周期（天）       | 可选必选说明：可选参数 参数含义：用户老化周期。 数据来源：本端规划 取值范围：整数类型，取值范围为0～365，65535，单位是天。0表示永不老化。 默认值：无 配置原则：当不配置的情况下，缺省值为65535。                                                                                                                                                                                                                                                                                                                    |
| PASSWORDEXPIREINDAYS | 密码有效期（天）        | 可选必选说明：可选参数 参数含义：密码有效期。 数据来源：本端规划 取值范围：整数类型，取值范围为0～999，65535，单位是天。0表示永不过期。65535表示密码有效期取默认值，默认值是18250天。 默认值：无 配置原则：机机账户emscomm和internaluser永不过期，密码有效期默认是“0”，不建议修改。当密码过期天数小于等于30天时，提醒用户修改密码。当不配置的情况下，缺省值为“65535”，表示密码有效期取默认值18250天。                                                                                                                                                                                             |
| ENDDATE              | 用户有效结束时间        | 可选必选说明：可选参数 参数含义：用户有效的截止日期，超出该日期后，用户无效。 数据来源：本端规划 取值范围：日期类型，输入格式是YYYY&MM&DD。 默认值：无                                                                                                                                                                                                                                                                                                                                            |
| LOGINLIMIT           | 是否限制登录时间        | 可选必选说明：可选参数 参数含义：是否限制用户只能在配置的允许登录时间范围内登录。 数据来源：本端规划 取值范围：枚举类型。 NO：没有登录时间段限制。YES：有登录时间段限制。 默认值：无                                                                                                                                                                                                                                                                                                                               |
| STARTWEEK            | 允许登录起始星期        | 可选必选说明：条件可选参数，该参数在“LOGINLIMIT”配置为“YES”时为可选参数。 参数含义：允许该本地用户登录的起始星期。 数据来源：本端规划 取值范围：枚举类型。 Sun：星期天。Mon：星期一。Tue：星期二。Wed：星期三。Thu：星期四。Fri：星期五。Sat：星期六。 默认值：无                                                                                                                                                                                                                                                                        |
| ENDWEEK              | 允许登录结束星期        | 可选必选说明：条件可选参数，该参数在“LOGINLIMIT”配置为“YES”时为可选参数。 参数含义：允许该本地用户登录的结束星期。 数据来源：本端规划 取值范围：枚举类型。 Sun：星期天。Mon：星期一。Tue：星期二。Wed：星期三。Thu：星期四。Fri：星期五。Sat：星期六。 默认值：无                                                                                                                                                                                                                                                                        |
| STARTTIME            | 允许登录开始时间        | 可选必选说明：条件可选参数，该参数在“LOGINLIMIT”配置为“YES”时为可选参数。 参数含义：允许该本地用户登录的起始时间。 数据来源：本端规划 取值范围：时间类型，输入格式是HH&MM&SS。 默认值：无                                                                                                                                                                                                                                                                                                                   |
| ENDTIME              | 允许登录结束时间        | 可选必选说明：条件可选参数，该参数在“LOGINLIMIT”配置为“YES”时为可选参数。 参数含义：允许该本地用户登录的结束时间。 数据来源：本端规划 取值范围：时间类型，输入格式是HH&MM&SS。 默认值：无                                                                                                                                                                                                                                                                                                                   |
| CONFIRMAUTH          | 二次授权            | 可选必选说明：可选参数 参数含义：是否允许二次授权。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无                                                                                                                                                                                                                                                                                                                                                    |
| FIRSTLGISWITCH       | 重置后首次登录是否强制修改密码 | 可选必选说明：可选参数 参数含义：重置后首次登录是否强制修改密码。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 TRUE：重置后首次登录需要强制修改密码。 FALSE：重置后首次登录不需要强制修改密码，用户在日常运维中仅需要修改密码时使用。 默认值：无 配置说明： “FIRSTLGISWITCH”参数不选等效于选择“FALSE”。emscomm用户在“FIRSTLGISWITCH”参数选择“TRUE”时，重置密码后首次登录需要修改密码，可能导致网元与网管断链。需要在OM Portal上，选择“安全>用户管理>用户”界面，重置emscomm用户密码，重新对接网管。                                                                                                              |

#### 使用实例

修改用户，用户名为“omuser”，密码为“\*\*\*\*\*”，确认密码为“\*\*\*\*\*”，SSH服务为使能，HTTP服务为去使能，用户组为“manage-ug”，用户状态为激活，最大连接数为10，用户老化天数为300天，密码过期天数为500天，用户过期时间为2015-10-10，是否限制登录时间为YES，允许登录起始星期为星期一，允许登录结束星期为星期五，允许登录开始时间为01:00:00，允许登录结束时间为23:59:00，不允许二次授权，重置后首次登录不强制修改密码：

```
MOD OP: USERNAME="omuser", PASSWORD="*****", CFMPASSWORD="*****", SERVICESSH=TRUE, SERVICEHTTP=FALSE,USERGROUPNAME="manage-ug", USERSTATE=active,MAXACCESSNUM=10,USERAGINGPERIOD=300,PASSWORDEXPIREINDAYS=500,ENDDATE=2015&10&10,LOGINLIMIT=YES,STARTWEEK=Mon,ENDWEEK=Fri,STARTTIME=01&00&00,ENDTIME=23&59&00,CONFIRMAUTH=FALSE,FIRSTLGISWITCH=FALSE;
```
