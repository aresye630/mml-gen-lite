# 配置ARP静态黑名单（ADD ARPSTATICBLACKLIST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于配置ARP静态黑名单。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1000。
- 执行该命令前，需要先执行SET ARPANTISPOOFING命令使能ARP防欺骗功能。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                              |
|:--------|:-------|:--------------------------------------------------------------------------------------------------|
| IPADDR  | IP地址   | 可选必选说明：必选参数 参数含义：该参数用于指定ARP静态黑名单的IP地址。 数据来源：本端规划 取值范围：IPv4地址类型。IP地址0.0.0.0～255.255.255.255。 默认值：无 |
| MACADDR | MAC地址  | 可选必选说明：必选参数 参数含义：该参数用于指定ARP静态黑名单的MAC地址。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～48。 默认值：无                   |

#### 使用实例

配置IP地址为10.1.1.2，MAC地址为00E0-FC12-3456的ARP静态黑名单：

```
ADD ARPSTATICBLACKLIST: IPADDR="10.1.1.2", MACADDR="00E0-FC12-3456";
```
