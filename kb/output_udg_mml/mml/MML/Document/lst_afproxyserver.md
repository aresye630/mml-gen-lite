# 查询防欺诈可信代理服务器（LST AFPROXYSERVER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明

- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询当前防欺诈功能配置的可信代理服务器信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询所有可信代理服务器IP地址：

```
LST AFPROXYSERVER:;
```

```
RETCODE = 0  操作成功。

防欺诈代理服务器信息
--------------------
  IP地址版本类型  =  IPV4
代理服务器IP地址  =  192.168.0.2
(结果个数 = 1)
---    END
```
