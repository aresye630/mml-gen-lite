# 删除内容过滤模板（RMV CFTEMPLATE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于删除一个内容过滤模板的配置。

#### 注意事项

- 该命令执行后立即生效。
- 如果内容过滤模板绑定了内容过滤策略，则不允许删除，需要执行命令RMV CFPROFBINDCFT接触绑定关系后再删除。
- 如果内容过滤模板绑定了APN，则不允许删除，需要执行命令RMV APNCFTEMPLATE接触绑定关系后再删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                          |
|:---------------|:---------|:----------------------------------------------------------------------------------------------|
| CFTEMPLATENAME | 内容过滤模板名称 | 可选必选说明：必选参数 参数含义：该参数用于设置内容过滤模板名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

删除一个内容过滤模板的配置：

```
RMV CFTEMPLATE: CFTEMPLATENAME="test";
```
