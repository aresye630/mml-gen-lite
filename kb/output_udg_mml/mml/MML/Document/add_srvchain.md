# 添加业务链（ADD SRVCHAIN）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于新增业务链配置，配置上下行业务链ID，为Rule提供业务链转发策略。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为500。
- 修改被Rule关联的SrvChain配置的UPSRVCHAINID或DNSRVCHAINID参数数值时，请确保SFIP上已关联相应的Uplink ID或Downlink ID，保证分流业务不受影响。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                       |
|:-------------|:--------|:-------------------------------------------------------------------------------------------|
| SRVCHAINNAME | 业务链名称   | 可选必选说明：必选参数 参数含义：该参数用于设置业务链名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |
| UPSRVCHAINID | 上行业务链ID | 可选必选说明：可选参数 参数含义：该参数用于设置上行业务链ID。 数据来源：全网规划 取值范围：0~16777215。 默认值：无 配置原则：无                   |
| DNSRVCHAINID | 下行业务链ID | 可选必选说明：可选参数 参数含义：该参数用于设置下行业务链ID。 数据来源：全网规划 取值范围：0~16777215。 默认值：无 配置原则：无                   |

#### 使用实例

如果运营商想要配置业务链名称为TestSrvChain，上行业务链ID为101，下行业务链ID为201的流量分类策略。命令如下：

```
ADD SRVCHAIN:SRVCHAINNAME="TestSrvChain",UPSRVCHAINID=101,DNSRVCHAINID=201;
```
