# 添加SFIP业务IP（ADD SFIPSRVIP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于添加SFIP业务IP地址。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为128。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称    | 参数说明                                                                                                                                                                       |
|:----------------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPENAME | 业务类型名称  | 可选必选说明：必选参数 参数含义：该参数用于指定SFIP业务类型名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无                                                                                         |
| IPVERSION       | IP版本    | 可选必选说明：必选参数 参数含义：该参数用于指定SFIP业务IP的版本信息。 数据来源：本端规划 取值范围： IPV4：表示地址类型为IPv4。IPV6：表示地址类型为IPv6。IPV4_IPV6：同时支持IPv4和IPv6地址。 默认值：无 配置原则：无                                           |
| IPV4ADDR        | IPv4 地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV4” 或 “IPV4_IPV6”时为必选参数。 参数含义：该参数用于指定SFIP业务的IPv4地址。当SFIP用于DNS业务场景时，该IP为提供DNS查询业务的服务器IPv4地址。 数据来源：全网规划 取值范围：有效的IPv4地址。 默认值：无 配置原则：无 |
| IPV6ADDR        | IPv6 地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV6” 或 “IPV4_IPV6”时为必选参数。 参数含义：该参数用于指定SFIP业务的IPv6地址。当SFIP用于DNS业务场景时，该IP为提供DNS查询业务的服务器IPv6地址。 数据来源：全网规划 取值范围：有效的IPv6地址。 默认值：无 配置原则：无 |

#### 使用实例

添加SFIP业务IP地址，业务类型名称为dns，IP地址类型为IPv4，IPv4地址为192.168.1.1：

```
ADD SFIPSRVIP: SERVICETYPENAME="dns", IPVERSION=IPV4, IPV4ADDR="192.168.1.1";
```
