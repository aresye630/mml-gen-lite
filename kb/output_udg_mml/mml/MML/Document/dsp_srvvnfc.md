# 查询服务VNFC（DSP SRVVNFC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询消费者信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询服务VNFC。

`DSP SRVVNFC:;`

```
%%DSP SRVVNFC:;%%
RETCODE = 0  操作成功。

操作结果如下：
--------------
   服务VNFC ID  =  5
  服务VNFC类型  =  CSLB
  申请服务类型  =  LB服务 & TN服务
服务IP地址规格  =  小规格
    IP业务模式  =  业务模式1
IP接入网络个数  =  1
    TS业务模式  =  NULL
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称     | 输出项解释                                                                     |
|:----------|:--------------------------------------------------------------------------|
| 服务VNFC ID | 参数含义：该参数用于表示消费者的唯一标识。                                                     |
| 服务VNFC类型  | 参数含义：该参数用于表示消费者类型。                                                        |
| 申请服务类型    | 参数含义：该参数用于表示申请的CSLB服务类型。 取值范围：“LB服务”“LB服务 & TN服务”                         |
| 服务IP地址规格  | 参数含义：该参数用于表示申请的服务地址规模，按照范围分为不同规格。 取值范围：“大规格”“中规格”“小规格”                    |
| IP业务模式    | 参数含义：该参数用于表示IP业务模式。 取值范围：“NULL”“业务模式1”“业务模式2”“业务模式3”“业务模式4”“业务模式5”“业务模式6” |
| IP接入网络个数  | 参数含义：该参数用于表示IP接入网络个数。                                                     |
| TS业务模式    | 参数含义：该参数用于表示TS业务模式。 取值范围：“NULL”“业务模式1”“业务模式2”“业务模式3”“业务模式4”“业务模式5”“业务模式6” |
