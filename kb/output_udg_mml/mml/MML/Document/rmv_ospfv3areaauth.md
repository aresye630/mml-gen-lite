# 删除OSPFv3区域认证配置（RMV OSPFV3AREAAUTH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除OSPFv3区域所使用的认证模式及验证口令。

**须知** 

本命令属于高危命令，如果OSPFv3区域认证与邻居配置不同，可能会使此进程的OSPFv3邻接关系中断，造成业务影响。

#### 注意事项

- 该命令执行后立即生效。
- 删除OSPFv3区域认证，请确保和邻居认证配置相同，否则会导致邻接关系中断，影响业务。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                             |
|:-----------|:----------|:---------------------------------------------------------------------------------|
| PROCID     | OSPFv3进程号 | 可选必选说明：必选参数 参数含义：OSPFv3进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无         |
| AREAID     | OSPFv3区域号 | 可选必选说明：必选参数 参数含义：OSPFv3区域号。 数据来源：本端规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无               |
| AUTHENMODE | 认证模式      | 可选必选说明：必选参数 参数含义：认证模式。 数据来源：本端规划 取值范围：枚举类型。 hmac-sha256：HMAC-SHA256密文验证模式。 默认值：无 |
| KEYID      | 密文验证字标识符  | 可选必选说明：必选参数 参数含义：密文验证字标识符。 数据来源：本端规划 取值范围：整数类型，取值范围为1～65535。 默认值：无               |

#### 使用实例

删除OSPFv3区域0.0.0.0使用HMAC-SHA256认证：

```
RMV OSPFV3AREAAUTH:PROCID=1,AREAID="0.0.0.0",AUTHENMODE=hmac-sha256,KEYID=10;
```
