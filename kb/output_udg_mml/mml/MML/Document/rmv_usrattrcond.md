# 删除用户属性过滤条件（RMV USRATTRCOND）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于删除用户属性过滤条件。当运营商希望删除用户属性过滤条件时，则配置该命令。

#### 注意事项

- 该命令执行后只对新激活用户生效。
- 如果不输入过滤条件名称，表示删除系统中所有过滤条件。
- 如果过滤条件被用户属性引用，则不允许删除用户属性过滤条件。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                     |
|:------------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------|
| CONDNAME    | 过滤条件名称   | 可选必选说明：可选参数 参数含义：该参数用于设置过滤条件名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无                                              |
| ITEMID      | 过滤条件项目索引 | 可选必选说明：可选参数 参数含义：该参数用于设置用户过滤条件项目索引。 数据来源：本端规划 取值范围：整数类型 ，取值范围是1~4294967295。 默认值：无 配置原则：如需使用该参数，请先输入CONDNAME。                             |
| CONTENTTYPE | 内容类型     | 可选必选说明：可选参数 参数含义：该参数用于设置过滤条件内容类型。 数据来源：本端规划 取值范围：枚举类型。 USER_PROFILE：用户模板。APN：APN。RAT：RAT类型。MSISDN：MSISDN。 默认值：无 配置原则：如需使用该参数，请先输入ITEMID。 |

#### 使用实例

运营商需要删除名称为user\_cond1的过滤器：

```
RMV USRATTRCOND: CONDNAME="user_cond1";
```
