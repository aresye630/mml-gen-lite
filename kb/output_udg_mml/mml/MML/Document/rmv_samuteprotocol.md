# 删除SA EGN规则不启用协议（RMV SAMUTEPROTOCOL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF、GGSN**

该命令用于恢复指定SA EGN协议规则。

#### 注意事项

该命令执行后60s生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                              |
|:-------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
| PROTOCOLNAME | 协议名称   | 可选必选说明：必选参数 参数含义：SA EGN规则不启用的协议。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：数据源为系统支持识别的所有类型的子协议，可以通过工程命令smctrldsp protocol-list查询。 |

#### 使用实例

恢复socks5协议规则：

```
RMV SAMUTEPROTOCOL:PROTOCOLNAME="socks5";
```
