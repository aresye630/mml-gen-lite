# 设置用户IP分片统计参数（SET USRFRAGSTAT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于设置用户面IP分片报文的统计参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | SRVIPSTATSW   | STATCONDTYPE       |   USRFRAGTHD |   USRFRAGPKTTHD |   SRVIPSTATPRD |
|:-------|:--------------|:-------------------|-------------:|----------------:|---------------:|
| 初始值    | ENABLE        | FRAGPKTS_THRESHOLD |          200 |            1000 |             60 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称           | 参数说明                                                                                                                                                                                                                                             |
|:--------------|:---------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SRVIPSTATSW   | 基于服务器IP地址统计的开关 | 可选必选说明：可选参数 参数含义：该参数用于指定基于服务器IP地址统计分片报文的功能开关。使能该功能后，系统周期性统计用户使用的IP分片资源数，当超过阈值后记录该用户访问的服务器IP地址，并统计该服务器IP地址的分片报文包数。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无                                                                       |
| STATCONDTYPE  | 触发统计的条件类型      | 可选必选说明：条件可选参数 前提条件：该参数在“SRVIPSTATSW”配置为“ENABLE”时为可选参数。 参数含义：该参数用于指定触发统计的条件类型。 数据来源：本端规划 取值范围：枚举类型。 FRAGPKTS_THRESHOLD：用户IP分片报文数超阈值。RESOURCE_THRESHOLD：用户IP分片资源数超阈值。 默认值：无 配置原则：无                                                                 |
| USRFRAGTHD    | 用户IP分片资源数阈值    | 可选必选说明：条件可选参数 前提条件：该参数在“SRVIPSTATSW”配置为“ENABLE”时为可选参数。 参数含义：该参数用于指定用户的IP分片报文占用资源数阈值。当用户当前占用的分片资源数达到该配置值后，记录该用户访问的服务器IP地址，并统计该服务器IP地址的分片报文数量。 数据来源：本端规划 取值范围：整数类型，取值范围为10～2000，单位是个。 默认值：无 配置原则：该参数仅在参数“STATCONDTYPE”配置为“RESOURCE_THRESHOLD”时才生效。 |
| USRFRAGPKTTHD | 用户IP分片报文数阈值    | 可选必选说明：条件可选参数 前提条件：该参数在“SRVIPSTATSW”配置为“ENABLE”时为可选参数。 参数含义：该参数用于指定用户的IP分片报文数阈值，当用户分片数在30s周期内达到该配置值后，记录该用户访问的服务器IP地址，并统计该服务器IP地址的分片报文数量。 数据来源：本端规划 取值范围：整数类型，取值范围为100～20000，单位是个。 默认值：无 配置原则：该参数仅在参数“STATCONDTYPE”配置为“FRAGPKTS_THRESHOLD”时才生效。   |
| SRVIPSTATPRD  | 统计周期时长（分钟）     | 可选必选说明：条件可选参数 前提条件：该参数在“SRVIPSTATSW”配置为“ENABLE”时为可选参数。 参数含义：该参数用于指定基于服务器IP地址统计的周期时长。每个周期开始时，会重新统计用户的IP分片报文及服务器IP地址的分片报文数量，并将上一个周期内记录的服务器IP地址统计数据进行排序，记录前50个服务器IP地址统计数据。 数据来源：本端规划 取值范围：整数类型，取值范围为10～120，单位是分钟。 默认值：无 配置原则：无                      |

#### 使用实例

开启基于Server IP统计用户面IP分片报文数开关：

```
SET USRFRAGSTAT: SRVIPSTATSW=ENABLE;
```
