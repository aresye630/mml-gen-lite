# 查询RD路由过滤节点（LST RDFILTERNODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询一个RD属性过滤器。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称      | 参数说明                                                                            |
|:-------------|:----------|:--------------------------------------------------------------------------------|
| INDEX        | RD过滤器索引   | 可选必选说明：可选参数 参数含义：该参数用于指定RD过滤器索引。 数据来源：本端规划 取值范围：整数类型，取值范围为1～1024。 默认值：无         |
| NODESEQUENCE | RD过滤索引节点号 | 可选必选说明：可选参数 参数含义：该参数用于指定RD过滤索引节点号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 |

#### 使用实例

查询RD属性过滤器：

```
LST RDFILTERNODE:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
    RD过滤器索引   =  1
RD过滤索引节点号   =  10
        匹配模式   =  拒绝
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释        |
|:--------|:-------------|
| RD过滤器索引 | 用于指定RD过滤器索引。 |

其余输出项请参见ADD RDFILTERNODE的参数说明。
