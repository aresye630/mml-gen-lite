# 修改TWAMP响应端（MOD TWAMPRESPONDER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于修改TWAMP响应端。

## 注意事项

- 该命令执行后在会话重新建立时生效。

- 本端IPv4地址不允许修改。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                   |
|:------------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RESPONDERID | 响应端索引    | 可选必选说明：必选参数  参数含义：该参数用于配置响应端索引。  数据来源：全网规划  取值范围：整数类型，取值范围是1~32。  默认值：无  配置原则：无                                                                                                                                                                                                                                                        |
| AFTYPE      | 地址族类型    | 可选必选说明：可选参数  参数含义：该参数用于用户指定地址族类型。  数据来源：全网规划 取值范围： IPV4（IPV4）  默认值：无  配置原则：无                                                                                                                                                                                                                                                           |
| TWAMPARCH   | TWAMP架构  | 可选必选说明：可选参数  参数含义：该参数用于指定TWAMP架构。  数据来源：全网规划 取值范围： FULL（FULL）  默认值：无  配置原则：无                                                                                                                                                                                                                                                           |
| LOCALIPV4   | 本端IPV4地址 | 可选必选说明：该参数在"AFTYPE"配置为"IPV4"时为条件必选参数。  参数含义：该参数用于指示本端IPV4地址。  数据来源：全网规划  取值范围：IPv4地址类型。0.0.0.0～255.255.255.255。  默认值：无  配置原则：  采用点分十进制"X.X.X.X"格式。  IP地址必须是A、B或者C类地址，不能为环回地址（127.x.y.z）、组播地址（240.x.y.z）或（255.0.0.0）。  LOCALIPV4必须在ADD TWAMPLOGICINF已经配置，可以用LST TWAMPLOGICINF查询。  LOCALIPV4不能已在ADD TWAMPCLIENT中配置，可以用LST TWAMPCLIENT查询。 |
| SERVWAIT    | 协商等待时间   | 可选必选说明：可选参数  参数含义：该参数用于指定协商等待时间。  数据来源：全网规划  取值范围：整数类型，取值范围是10~1800，单位是秒。  默认值：无  配置原则：无                                                                                                                                                                                                                                               |
| REFWAIT     | 测试等待时间   | 可选必选说明：可选参数  参数含义：该参数用于指定测试等待时间。  数据来源：全网规划  取值范围：整数类型，取值范围是10~1800，单位是秒。  默认值：无  配置原则：无                                                                                                                                                                                                                                               |

## 使用实例

修改响应端索引为1的实例：

```
MOD TWAMPRESPONDER: RESPONDERID=1, SERVWAIT=1000, REFWAIT=1000;
```
