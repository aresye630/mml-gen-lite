# 查询恢复进度（DSP RESTSKPROG）

## 命令功能

查询恢复任务的进度。

**须知** 

本命令只能查询到**CRT RESTSK**命令创建的恢复任务的进度，在OM Portal界面本地接管后无法再查到任务的进度。

## 注意事项

无。

## 参数说明

无。

## 使用实例

1. 查询恢复任务进度：

```
%%DSP RESTSKPROG:;%% 
RETCODE = 0  操作成功  
任务信息如下 
------------   
任务进度  =  12% 
(结果个数 = 1)  
---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息，输出结果说明如表1所示。

命令执行异常，请联系华为技术支持处理。输出结果说明如表2所示。

| 输出项名称   | 输出项解释      |
|:--------|:-----------|
| 任务进度    | 恢复任务当前的进度。 |

|    错误码 | 错误码解释              | 原因分析               | 处理建议             |
|-------:|:-------------------|:-------------------|:-----------------|
| 111503 | 内部错误。              | 未预期的内部处理错误。        | 请联系华为技术支持。       |
| 111512 | 其他未知错误。            | 其他未知错误。            | 请联系华为技术支持。       |
| 111518 | 存在弹窗或恢复流程执行失败。     | 恢复任务执行到弹窗处或者有失败项。  | 请参考参考信息处理。       |
| 111519 | 当前不存在MML命令创建的恢复任务。 | 当前不存在MML命令创建的恢复任务。 | 请先通过MML命令创建恢复任务。 |

## 参考信息

当**DSP RESTSKPROG**命令返回错误码“111518”时，参照如下方式进行处理：

- 登录OM Portal页面。
- 在主菜单选择“应用管理 > 备份恢复”，并在左侧导航树单击“恢复”，然后等待10s，自动进入“任务详情”页面。
- 单击提示弹窗的“确认”，然后点击页面左上角的“本地接管”，在弹出的弹窗中勾选“我已知晓”然后点击“接管”。

  **图1** 提示弹窗

  **图2** 接管按钮

  **图3** 接管弹窗
- 等待10s，查看是存在弹窗还是存在报错。
  - 存在弹窗 => 根据弹窗内容点击相应按钮处理弹窗。
  - 存在报错 => 联系华为技术支持处理。
