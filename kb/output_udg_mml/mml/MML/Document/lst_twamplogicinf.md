# 查询本地逻辑接口（LST TWAMPLOGICINF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询本地逻辑接口。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                |
|:-------|:-------|:------------------------------------------------------------------------------------|
| NAME   | 逻辑接口名称 | 可选必选说明：可选参数  参数含义：该参数用于配置逻辑接口名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。  默认值：无  配置原则：无 |

## 使用实例

查询逻辑接口名称为：n3if1/1/0的实例：

```
%%LST TWAMPLOGICINF: NAME="n3if1/1/0";%%
RETCODE = 0  操作成功

结果如下
--------
    逻辑接口名称  =  n3if1/1/0
      地址族类型  =  IPV4
逻辑接口IPv4地址  =  10.0.0.0
    逻辑接口掩码  =  255.255.255.255
     VPN实例名称  =  ck
      SHAREDTYPE  =  TRUE
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释              |
|:--------|:-------------------|
| 逻辑接口名称  | 该参数用于配置逻辑接口名称。     |
| 地址族类型   | 该参数用于配置地址族类型。      |
| 逻辑接口地址  | 该参数用于配置逻辑接口IPv4地址。 |
| 逻辑接口掩码  | 该参数用于配置逻辑接口掩码。     |
| VPN实例名称 | 该参数用于配置VPN实例名称。    |
| 共享IP地址  | 该参数用于是否共地址。        |
