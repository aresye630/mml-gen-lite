# 设置TCP流老化功能配置（SET TOFLOWAGINGCFG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于设置TCP流老化功能配置。

#### 注意事项

- 该命令执行后对新数据流生效。
- 该命令最大记录数为1。
- 此配置时间应该大于保活时间，执行LST TORELIABLECFG命令确认KEEPALIVE配置时间。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | FLOWAGINGSWITCH   |   FLOWAGINGTIME |
|:-------|:------------------|----------------:|
| 初始值    | ENABLE            |             600 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称        | 参数说明                                                                                                                         |
|:----------------|:------------|:-----------------------------------------------------------------------------------------------------------------------------|
| FLOWAGINGSWITCH | TCP流老化功能开关  | 可选必选说明：必选参数 参数含义：设置TCP流的老化功能开关。 数据来源：本端规划 取值范围： DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无                                          |
| FLOWAGINGTIME   | TCP流老化时间（秒） | 可选必选说明：条件可选参数 前提条件：该参数在“FLOWAGINGSWITCH”配置为“ENABLE”时为可选参数。 参数含义：TCP流老化时间。 数据来源：本端规划 取值范围：整数类型，取值范围30～7200，单位是秒。 默认值：无 配置原则：无 |

#### 使用实例

开启TCP流老化功能开关，设置TCP流老化时间为500秒：

```
SET TOFLOWAGINGCFG: FLOWAGINGSWITCH=ENABLE, FLOWAGINGTIME=500;
```
