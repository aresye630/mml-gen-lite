# 修改TLS参数（MOD TLSPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于修改一组TLS参数。

## 注意事项

- 该命令执行后立即生效。

- 如果修改TLSPARA中除“描述”外的参数，需要先执行**ADD TLSPARA**命令增加一条记录，然后执行**MOD HTTPLE**MOD HTTPLE命令，将“TLS索引”参数修改为**ADD TLSPARA**命令新增加的索引值。操作后对新建立的HTTPS链路生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                           |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------|
| INDEX  | 索引     | 可选必选说明：必选参数  参数含义：该参数用于指定TLS参数索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~128。  默认值：无  配置原则：  与ADD HTTPLE中配置的TLS参数索引保持一致。 |
| DESC   | 描述     | 可选必选说明：可选参数  参数含义：该参数用于指定TLS上下文描述。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无                         |

## 使用实例

若运营商想修改索引为1的TLS配置的描述，可以用如下命令：

```
MOD TLSPARA:  INDEX=1, DESC= "mod tlspara";
```
