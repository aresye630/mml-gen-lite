# 查询告警开关配置数据（LST MSFAULTALARM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询告警抑制的配置。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

无

## 使用实例

查询告警抑制使能开关的配置：

```
%%LST MSFAULTALARM:;%%
RETCODE = 0  操作成功

结果如下
------------------------
告警抑制使能开关  =  开启
告警抑制时间(秒)  =  300
(结果个数 = 1)
```

## 输出结果说明

| 输出项名称     | 输出项解释            |
|:----------|:-----------------|
| 告警抑制使能开关  | 该参数用于表示告警抑制使能开关。 |
| 告警抑制时间(秒) | 该参数用于表示告警抑制时间。   |
