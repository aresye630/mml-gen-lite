# 修改VXLAN隧道组绑定APN（MOD VXLANBINDAPN）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于修改VXLAN隧道组与apn的绑定关系。

#### 注意事项

- 该命令执行后立即生效。
- 执行该命令时，会修改Vxlan组绑定APN的关系，将改变数据转发流程，会将数据报文转发至新的MEP。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                            |
|:-------------|:---------|:------------------------------------------------------------------------------------------------|
| APN          | APN      | 可选必选说明：必选参数 参数含义：该参数用于指定APN实例名。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无     |
| VXLANGRPNAME | VXLAN组名称 | 可选必选说明：必选参数 参数含义：该参数用于指定VXLAN隧道组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

修改与apn1绑定的VXLAN隧道组为vxlangrp2：

```
MOD VXLANBINDAPN: APN="apn1", VXLANGRPNAME="vxlangrp2";
```
