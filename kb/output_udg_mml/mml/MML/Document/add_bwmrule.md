# 增加带宽管理规则（ADD BWMRULE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于增加一条用户组或用户的业务带宽管理规则。规则包括用户组级默认、特定规则和用户级默认、特定规则。当运营商希望基于用户组或用户级进行精细化带宽控制时，则使用该命令配置用户组和用户级的规则，并配置业务类型、用户属性和时间段及相应的带宽控制器。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为5000。当配置记录数大于规格的90%时，会上报“ALM-135602215 配置数量超阈值”告警。当配置记录数小于等于配置规格90%时，恢复“ALM-135602215 配置数量超阈值”告警。阈值可以通过MOD CFGTHRESHOLD命令修改。
- ADD BWMRULE命令与ADD BWMRULEGLOBAL命令同属于BwmRule对象，共享配置记录空间，即两个命令的总记录数最大为5000。
- 如果用户激活或者更新时，所属的用户组配置下没有用户级或用户组级的带宽管理规则，则该用户后续业务不进行带宽管理规则的匹配，后续再增加带宽管理规则的配置，也不生效。
- 如果TOS类型的组级BWMRULE已经生效，修改该BWMRULE下的BWMCONTROLLER，只对新用户或重新激活用户生效，所有组级用户生效前可能会导致带宽控制不准。
- 配置用户级或用户组级默认带宽管理规则时，必须指定上行、下行或双向的带宽控制器，不需要指定带宽管理业务，优先级，用户属性（接入类型、漫游类型）以及业务规则的时段。当报文匹配其它规则失败就会使用默认的规则，由于默认规则下不能设置带宽管理业务，所以这时不会再对报文类型进行限制了，即所有报文都会使用该默认规则做带宽控制。
- 配置非默认的业务带宽管理规则，必须指定一个带宽管理业务和优先级，必须指定上行、下行或双向的带宽管理控制器，可以选择指定用户属性以及业务规则的生效时段。
- 配置规则的带宽管理业务时，同一个用户组级下的TOS业务类型不能相同。
- 配置规则的生效时段时，该规则下的时间段不能重叠或者覆盖，否则时间段切换时可能无法正确使用带宽控制规则。
- 配置规则的生效时段不能小于30分钟。
- 带宽控制器是基于时间段生效的，当配置两组及两组以上的上下行带宽控制器时，必须指定规则生效时段。
- 同等情况下，配置用户组级带宽管理会比用户级带宽管理消耗更多性能，使用前请联系华为技术支持评估。
- 当带宽管理控制器按照上行、下行分别配置时，如果其中配置了业务最大可以使用的五元组个数不同，则取二者中较小的。
- 需要为每一个规则指定优先级，每个用户级、或用户组级下的规则优先级不能相同。进行规则匹配时，优先匹配优先级高的规则，优先级的值越小，优先级越高。
- 每个用户组下可以配置一个默认的用户级规则和一个默认的用户组级规则。
- 组级带宽管理规则最大记录数为100。
- 每个用户组支持最多配置300条BWMRULE。
- 该命令误配后会影响系统性能。执行命令前请评估对性能的影响，如果无法评估请联系华为技术支持。
- 如果添加的BwmService下的业务类型和BwmUsergroup下的业务类型不一致时，则不允许配置。
- 用户级带宽规则不支持进行SHAPING分级管控控制。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

| CFGDOMAINNAME  | 配置域名称        | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
