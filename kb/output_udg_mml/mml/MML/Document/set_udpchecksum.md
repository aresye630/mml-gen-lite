# 配置UDP报文中是否携带checksum（SET UDPCHECKSUM）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

**须知** 

本命令属于高危命令，执行该命令时，开启UDP checksum功能前，需要确认对端支持程度，否则影响整机信令转发

该命令用来配置系统发送的UDP报文是否携带checksum。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为4。
- 在现网中与对端网元对接时，由于对端网元的处理方式不同，对接可能会失败。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | UDPTYPE   | SWITCH   |
|:-------|:----------|:---------|
| 初始值    | L2TP_CTRL | DISABLE  |
| 初始值    | L2TP_DATA | DISABLE  |
| 初始值    | PFCP      | DISABLE  |
| 初始值    | SIP       | DISABLE  |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称        | 参数说明                                                                                                                                                     |
|:--------|:------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------|
| UDPTYPE | UDP Type    | 可选必选说明：可选参数 参数含义：指定是何种类型的报文。 数据来源：本端规划 取值范围：枚举类型。 L2TP_CTRL：表示L2TP控制报文。L2TP_DATA：表示L2TP数据报文。PFCP：表示PFCP报文。SIP：表示SIP报文。 默认值：无 配置原则：无                      |
| SWITCH  | Checksum 开关 | 可选必选说明：可选参数 参数含义：指定系统发送的系统报文中是否携带checksum。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则： IPv6报文始终开启checksum，不受配置控制。IPv4报文可以配置为ENABLE或者DISABLE。 |

#### 使用实例

配置L2TP信令报文携带checksum：

```
SET UDPCHECKSUM:UDPTYPE=L2TP_CTRL,SWITCH=ENABLE;
```
