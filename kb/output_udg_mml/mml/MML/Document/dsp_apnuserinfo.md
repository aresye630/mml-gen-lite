# 显示APN用户信息（DSP APNUSERINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

**须知** 

本命令属于高危命令，查询前先确认是否接受回显存在个人数据。

用于查询指定APN下用户的上下文信息。显示内容包括IMSI、IMEI、MSISDN、User Role Type、IPv4 Address、IPv6 Address、PodName。

#### 注意事项

整机最多能查到5000个会话，每个isu pod能查询到的最大会话数为(5000/isu pod数量)个。如果isu pod间会话数分布不均，在整机会话数大于等于5000的情况下也可能会导致查询数小于5000。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                         |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN     | APN    | 可选必选说明：必选参数 参数含义：该参数用于指定APN实例名。表示查询该APN下用户上下文信息，该APN必须在系统上已经配置。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格及部分特殊字符。可以支持的特殊字符有“.”和“-”，“.”不可以是第一个字符且不可以连续出现。 默认值：无 配置原则：无                                                           |
| RATTYPE | 无线接入类型 | 可选必选说明：可选参数 参数含义：该参数用于指定RAT类型。 数据来源：本端规划 取值范围：位域类型。 UTRAN：通用陆地无线接入网。GERAN：GSM/EDGE无线接入网。WLAN：无线局域网。GAN：通用访问网络。HSPA：高速分组接入。EUTRAN：演进型通用陆地无线接入网。EUTRAN_NB_IOT：窄带物联网。LTE_M：低功耗窄带物联网。NR：5G用户。REDCAP：RedCap NR的5G用户。 默认值：无 配置原则：无 |
| ROAMING | 用户漫游类型 | 可选必选说明：可选参数 参数含义：该参数用于指定用户漫游状态。 数据来源：本端规划 取值范围：位域类型。 home：表示本地用户。roaming：表示漫游用户。visiting：表示拜访用户。 默认值：无 配置原则：无                                                                                                                |

#### 使用实例

查询APN为apn01.com下用户的用户上下文信息：

```
DSP APNUSERINFO: APN="apn01.com";
```
