# 查询IPv6路由表（DSP ROUTE6）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示IPv6路由表，默认显示公网路由和所有VPN路由。

路由表是路由器转发数据包的关键。

路由表中保存了各种路由协议发现的路由，根据来源不同，路由表中的路由通常可以分为链路层协议发现的路由即直连路由、由网络管理员手工配置的静态路由，以及动态路由协议发现的路由。

在路由数目较多时，该命令执行时间较长，且最多查询20万条路由。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                                                     |
|:--------------|:---------|:-------------------------------------------------------------------------------------------------------------------------|
| VRFNAME       | VPN实例名称  | 可选必选说明：可选参数 参数含义：该参数用于表示路由所属VPN的名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：公网需要输入_public_，默认显示公网和所有VPN下的路由。        |
| PREFIX        | 路由前缀     | 可选必选说明：可选参数 参数含义：该参数用于表示路由前缀。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无                                                             |
| ADDRESSFAMILY | 地址族      | 可选必选说明：可选参数 参数含义：该参数用于表示路由所属VPN的地址族。 数据来源：本端规划 取值范围：枚举类型。 ipv6unicast：IPv6单播。 默认值：ipv6unicast                            |
| MASKLENGTH    | 路由前缀长度   | 可选必选说明：可选参数 参数含义：该参数用于表示IPv6路由的前缀长度。 数据来源：本端规划 取值范围：整数类型，取值范围为0～128。 默认值：无                                               |
| PROTOCOLID    | 路由协议名字   | 可选必选说明：可选参数 参数含义：该参数用于表示路由协议的名字。 数据来源：本端规划 取值范围：枚举类型。 Direct：直连路由。OSPFv3：OSPFv3路由。Static：静态路由。BGP：BGP路由。wlr：无线路由。 默认值：无  |
| ISACTIVE      | 路由是否活跃   | 可选必选说明：可选参数 参数含义：该参数用于表示路由是否活跃。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无                                          |
| ISLONGERMATCH | 是否应用最长匹配 | 可选必选说明：可选参数 参数含义：该参数用于表示是否查询最长匹配能匹配到的所有路由。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无 配置原则：该参数需和前缀一起使用，不能和前缀长度一起使用。 |

```
DSP ROUTE6:;
```
