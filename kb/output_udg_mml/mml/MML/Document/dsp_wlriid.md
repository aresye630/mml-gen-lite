# 显示无线路由IID信息（DSP WLRIID）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示无线路由IID信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                           |
|:-------|:-------|:-----------------------------------------------------------------------------------------------|
| AFTYPE | 地址族    | 可选必选说明：必选参数 参数含义：该参数用于表示地址族。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。ipv6unicast：IPv6单播。 默认值：无 |

#### 使用实例

显示无线路由IID信息：

```
DSP WLRIID:AFTYPE=ipv4unicast;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
      路由IID  =  0xa000023
    原始下一跳 =  10.0.0.1
         标识  =  D

           TP  =  1
      TB high  =  1
       TB low  =  1
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称    | 输出项解释           |
|:---------|:----------------|
| 路由IID    | 用于表示路由的IID。     |
| 原始下一跳    | 用于表示原始下一跳。      |
| 标识       | 用于表示无线路由标识。     |
| 组ID      | 用于表示组ID。        |
| 下一跳VPN名字 | 用于表示下一跳所属VPN名字。 |
| TP       | 用于表示TP。         |
| TB high  | 用于表示TB high。    |
| TB low   | 用于表示TB low。     |
