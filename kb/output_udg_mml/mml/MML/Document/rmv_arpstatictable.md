# 删除静态ARP表项（RMV ARPSTATICTABLE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除ARP静态表项。当网络重新规划，之前创建的ARP静态表项失效。此时可执行该命令删除已创建的ARP静态表项。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                   |
|:--------|:--------|:-------------------------------------------------------------------------------------------------------|
| IPADDR  | IP地址    | 可选必选说明：可选参数 参数含义：该参数用于显示指定（目的）IPv4地址的ARP表项。 数据来源：本端规划 取值范围：IPv4地址类型。IP地址0.0.0.0～255.255.255.255。 默认值：无 |
| VRFNAME | VPN实例名称 | 可选必选说明：必选参数 参数含义：该参数用于指定ARP表项的VPN名称。 数据来源：本端规划 取值范围：字符串类型，取值范围是1～31。 默认值：无                             |

#### 使用实例

针对已经配置的VPN实例名称为\_public\_的静态ARP表项，现需要删除该表项：

```
RMV ARPSTATICTABLE:VRFNAME="_public_";
```
