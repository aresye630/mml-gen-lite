# 查询内部资源QOS映射关系。（LST RESCTRLQOSMAP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于查询内部资源QOS映射关系。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                            |
|:-----------|:--------|:--------------------------------------------------------------------------------|
| QOSMAPTYPE | QoS映射类型 | 可选必选说明：可选参数 参数含义：该参数用于指定QOS映射类型。 数据来源：本端规划 取值范围： DSCP_VALUE：DSCP值。 默认值：无 配置原则：无 |
| DSCPVALUE  | DSCP值   | 可选必选说明：可选参数 参数含义：该参数用于指定DSCP值。 数据来源：全网规划 取值范围：0-63。 默认值：无 配置原则：无                |

#### 使用实例

查询当前映射关系：

```
LST RESCTRLQOSMAP:;
```
