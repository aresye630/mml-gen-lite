# 查询组播组成员配置（LST MCASTGRPMEM）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询静态组播组IMSI成员记录。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                |
|:-------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| MCASTGRPNAME | 组播组名称  | 可选必选说明：可选参数 参数含义：该参数用于配置组播组的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63，区分大小写。 默认值：无 配置原则：该参数使用ADD MULTICASTGRP命令配置生成。并且要先在ADD NGBINDMCASTGRP中和5G LAN实例绑定。 |

#### 使用实例

查询静态组播组成员配置：

```
LST MCASTGRPMEM:;
```
