# 查询OS补丁版本号（DSP OSPATCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明
- 参考信息

## 命令功能

该命令用于查询节点的OS补丁版本号。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                     |
|:-------|:-------|:-----------------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：用于指示系统需要查询指定网元ID下的节点数据。 取值范围：0～65535。 默认值：无。 配置原则： 网元ID可以通过执行LST ME查询。 |
| NODEIP | 节点IP   | 可选必选说明：可选参数。 参数含义：用于指示系统需要查询哪个节点的数据。 取值范围：不超过128位字符串。 默认值：无。 配置原则： 若不输入，则表示查询所有节点的OS信息。  |

## 使用实例

1. 查询“网元ID”为“0”的所有节点配置信息：

   ```
   #65 %%DSP OSPATCH: MEID=0;%% 
   RETCODE = 0  操作成功  
   操作结果如下 
   ------------ 
   网元ID  节点IP           内核版本号                        补丁列表       是否生效     
   0       10.0.0.0         xxxx-xxxx.x.x.xxxx.xxxxxx.xxxxx   xxx.xxx.xxx    yes
   0       10.0.0.0         xxxx-xxxx.x.x.xxxx.xxxxxx.xxxxx   xxx.xxx.xxx    yes
   0       10.0.0.0         xxxx-xxxx.x.x.xxxx.xxxxxx.xxxxx   xxx.xxx.xxx    yes
   (结果个数 = 3)  
   ---    END
   ```
2. 查询“网元ID”为“0”，“节点IP”为“10.0.0.0”的节点配置信息：

   ```
   #66 %%DSP OSPATCH: MEID=0, NODEIP="10.0.0.0";%% 
   RETCODE = 0  操作成功  
   操作结果如下 
   ------------     
       网元ID  =  0     
       节点IP  =  10.0.0.0 
   内核版本号  =  xxxx-xxxx.x.x.xxxx.xxxxxx.xxxxx 
     补丁列表  =  xxx.xxx.xxx
     是否生效  =  yes
   (结果个数 = 1)  
   ---    END
   ```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。输出结果说明如表1所示。

命令执行异常，请联系华为技术支持处理。输出结果说明如表2所示。

| 输出项名称   | 输出项解释                                                           |
|:--------|:----------------------------------------------------------------|
| 网元ID    | 节点所属的网元ID。                                                      |
| 节点IP    | 节点网络地址。                                                         |
| 内核版本号   | 节点OS的内核版本号。                                                     |
| 补丁列表    | 节点OS的补丁版本号。                                                     |
| 是否生效    | 节点OS的补丁是否生效。  说明： 补丁安装、重建系统盘、强制重建虚拟机及扩容场景，“是否生效”为“no”，需要重启节点生效。 |

|    错误码 | 错误码解释     | 原因分析                     | 处理建议                            |
|-------:|:----------|:-------------------------|:--------------------------------|
| 130013 | 操作失败      | 查询对象不在线、查询对象状态异常或内部执行报错。 | 检查是否存在节点被下电、节点状态异常等情况或联系华为技术支持。 |
| 130014 | 未知操作      | 不识别对应MML命令。              | 检查MML名称是否正确。                    |
| 130015 | 没有符合条件的节点 | 没有网元ID对应的节点。             | 请检查网元ID是否正确。                    |
| 130016 | 参数不合法     | 参数校验失败。                  | 请检查参数是否填写正确。                    |
