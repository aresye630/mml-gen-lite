# 查询HTTP染色配置（LST HTTPLINKDSCP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询HTTP TCP头中的DSCP字段的染色配置。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

若需要查询一条HTTP染色配置，可以用如下命令：

```
%%LST HTTPLINKDSCP:;%%
RETCODE = 0  操作成功

结果如下
------------------------
HTTPLINKDSCP索引  =  1
         IP类型  =  IPv4 Address
     源IPV4地址  =  255.255.255.255
     源IPV6地址  =  ::
	目的IPV4地址  =  192.168.0.0
	目的IPV6地址  =  ::
       目的端口  =  0
         源端口  =  0
        DSCP值  =  1
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称          | 输出项解释                     |
|:---------------|:--------------------------|
| HTTPLINKDSCP索引 | 该参数用于指定HTTPLINKDSCP的索引信息。 |
| IP类型           | 该参数用于指定配置的地址的IP类型。        |
| 源IPV4地址        | 源IPv4地址。                  |
| 源IPV6地址        | 源IPv6地址。                  |
| 目的IPV4地址       | 目的IPv4地址。                 |
| 目的IPV6地址       | 目的IPv6地址。                 |
| 目的端口           | 目的端口。                     |
| 源端口            | 源端口。                      |
| DSCP值          | DSCP值，在染色过程中用来标记指定的报文。    |
