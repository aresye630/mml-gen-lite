# 查询容灾倒换记录（LST DRSWAPREC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询容灾倒换记录。

在主容灾实例上执行，查询的结果是主容灾实例发起倒换复位的记录，包含手工命令倒换。

在备容灾实例上执行，查询的结果是备容灾实例升主倒换的记录，包含手工命令倒换。

主备容灾实例记录配合查看，可以观测容灾实例倒换的完整过程。

## 注意事项

该命令适用于支持热备或冷备容灾的网元执行。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                             |
|:----------|:-------|:-----------------------------------------------------------------------------------------------------------------|
| DRGROUPID | 容灾组标识  | 可选必选说明：必选参数  参数含义：该参数用于指定容灾组标识。  数据来源：全网规划  取值范围：整数类型，取值范围是1~8。  默认值：无  配置原则：  可使用LST DRGROUPINFO返回的容灾组标识作为参数输入。 |

## 使用实例

查询容灾倒换记录：

```
%%LST DRSWAPREC: DRGROUPID=1;%%
RETCODE = 0  操作成功

结果如下
--------
容灾组标识      容灾倒换事件时间              容灾倒换事件类型              容灾倒换事件产生原因

1               2022-05-17 13:31:521          主容灾实例复位                关键服务异常                                                                 
2               2022-05-17 13:31:23           手动主备倒换                  手动主备倒换                                                                                                                         
(结果个数 = 2)

---    END
```
