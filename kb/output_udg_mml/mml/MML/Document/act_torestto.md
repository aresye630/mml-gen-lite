# TCP重启TO（ACT TORESTTO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

**须知** 

本命令属于高危命令，此命令执行后，会复位TO进程，导致业务中断，请确保在无业务时执行此命令。

该命令用于重启TO。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                            |
|:-------|:-------|:--------------------------------------------------------------------------------|
| SWITCH | 重启TO   | 可选必选说明：必选参数 参数含义：设置重启TO的开关。 数据来源：本端规划 取值范围： DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无 |

#### 使用实例

重启TO：

```
ACT TORESTTO: SWITCH=ENABLE;
RETCODE = 0  操作成功
```
