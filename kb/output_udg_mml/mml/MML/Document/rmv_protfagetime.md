# 删除协议五元组老化时间（RMV PROTFAGETIME）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令,执行本命令后将删除指定或所有协议或协议组的五元组老化时间，影响资源利用或影响业务识别解析成功率，请谨慎使用。

该命令用于删除配置的协议组、协议相关的五元组老化时间。

#### 注意事项

- 该命令执行后立即生效。
- 如果执行批量删除操作，需要开启软参BYTE692。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                                                  |
|:--------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROTOCOLLEVEL | 协议等级   | 可选必选说明：可选参数 参数含义：该参数用于显示配置的协议组、协议级别。 数据来源：本端规划 取值范围：枚举类型。 PROTOCOLGROUP：协议组级别。PROTOCOL：协议级别。 默认值：无 配置原则：无                                                                                                             |
| PROTGROUPNAME | 协议组名称  | 可选必选说明：条件必选参数 前提条件：该参数在“PROTOCOLLEVEL”配置为“PROTOCOLGROUP”时为必选参数。 参数含义：该参数用于设置协议组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：数据源为系统支持识别的默认协议组，可以通过工程命令smctrldsp protocol-list查询。                      |
| PROTOCOLNAME  | 协议名称   | 可选必选说明：条件必选参数 前提条件：该参数在“PROTOCOLLEVEL”配置为“PROTOCOL”时为必选参数。 参数含义：该参数用于设置协议名称。数据源为系统支持识别的所有类型的协议、子协议。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：数据源为系统支持识别的所有类型的协议、子协议，可以通过工程命令display protocol-list查询。 |

#### 使用实例

假如运营商需要删除配置的p2p协议组的五元组老化时间，则执行如下命令：

```
RMV PROTFAGETIME:PROTOCOLLEVEL=PROTOCOLGROUP,PROTGROUPNAME="p2p";
```
