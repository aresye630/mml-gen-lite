# 查询GRE隧道KeepAlive报文计数（DSP GREKPLVSTAT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示GRE隧道的Keepalive报文计数。

使用GRE隧道的Keepalive功能，在业务模块选择承载隧道时，可防止选择对端不可达的GRE隧道，避免造成数据丢失。为了获取隧道Keepalive的状态，可使用该命令显示Keepalive报文计数。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                     |
|:--------|:-------|:-------------------------------------------------------------------------------------------------------------------------|
| TNLNAME | 隧道名称   | 可选必选说明：必选参数 参数含义：该参数用于指定GRE隧道接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：字符串形式为Tunnel+接口编号。 接口编号为一维或三维（格式为X/Y/Z）。 |

#### 使用实例

显示设备上的Tunnel1的Keepalive报文计数：

```
DSP GREKPLVSTAT:TNLNAME="Tunnel1";
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
                 隧道名称  =  Tunnel1
    发送Keepalive报文个数  =  0
接收Keepalive报文应答个数  =  0
    接收Keepalive报文个数  =  0
发送Keepalive报文应答个数  =  0
(结果个数 = 1)
---    END
```
