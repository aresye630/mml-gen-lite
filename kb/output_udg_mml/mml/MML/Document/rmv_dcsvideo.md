# 删除DCS点播视频资源（RMV DCSVIDEO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令用于删除DCS视频资源，资源删除后需要重新拉取，会对业务造成较大影响。

该命令用于删除DCS点播视频资源，作应急逃生手段。执行命令后，可通过DSP DCSVODVIDEO命令来校验删除操作的结果。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                        |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------|
| OTTNAME | OTT名称  | 可选必选说明：必选参数  参数含义：该参数用于表示OTT名称，OTT名称由OTT厂商提供，可通过执行LST RELAYDOMAIN命令，获取查询结果中的“媒体中继模板名称”。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~256。  默认值：无  配置原则：无 |
| URL     | URL名称  | 可选必选说明：必选参数  参数含义：该参数用于表示视频文件的URL名称。URL名称由OTT厂商提供。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~1024。  默认值：无  配置原则：无                                     |

## 使用实例

删除OTT名称为“douyin”，URL为“aaa.douyincdn.com/fantasy/stream-404357031821050550.mp4”的点播视频资源。

```
RMV DCSVIDEO: OTTNAME="douyin", URL="aaa.douyincdn.com/fantasy/stream-404357031821050550.mp4";
```
