# 显示IPsec安全联盟（DSP IPSECSA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示IPsec安全联盟。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                    |
|:-------|:-------|:------------------------------------------------------------------------|
| SANAME | 安全联盟名称 | 可选必选说明：可选参数 参数含义：安全联盟名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～15。不区分大小写。 默认值：无 |

#### 使用实例

显示IPsec安全联盟：

```
DSP IPSECSA: SANAME="1";
```

```
RETCODE = 0  操作成功。

结果如下
--------
  安全联盟名称  =  1
SA配置是否完整  =  TRUE
      引用次数  =  0
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称    | 输出项解释     |
|:---------|:----------|
| 安全联盟名称   | 安全联盟名称。   |
| SA配置是否完整 | SA配置是否完整。 |
| 引用次数     | 引用次数。     |
