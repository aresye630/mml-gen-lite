# 设置APN Tethering终端数量检测开关（SET APNTETHERDETSW）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用来设置APN下Tethering终端数量检测开关。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为10000。
- 此命令的生效范围限于APN。
- 如果开关设置为继承，则继承SET TetherDetGlbSw命令的Switch参数配置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                        |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN    | APN    | 可选必选说明：必选参数 参数含义：该参数用于指定APN名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                  |
| SWITCH | 开关标识   | 可选必选说明：必选参数 参数含义：该参数用来配置Tethering用户终端数量检测功能开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：Tethering终端数量检测功能关闭。ENABLE：Tethering终端数量检测功能打开。INHERIT：继承全局缺省的Tethering终端数量检测开关状态。 默认值：无 配置原则：无 |

#### 使用实例

假如运营商需使能名称为“huawei.com”的APN的Tethering终端数量检测功能：

```
SET APNTETHERDETSW: APN="huawei.com", SWITCH=ENABLE;
```
