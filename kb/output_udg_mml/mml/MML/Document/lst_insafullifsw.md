# 查询全量智能SA识别开关（LST INSAFULLIFSW）

- 命令功能
- 注意事项
- 操作用户权限

#### 命令功能

**适用NF：PGW-U、UPF**

查询全量智能SA识别开关。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询当前全量智能SA识别开关状态：

```
LST INSAFULLIFSW:;
```

```
RETCODE = 0 操作成功。

全量智能SA识别开关信息
------
 
        全量推理开关 = Enable

(结果个数 = 1)
--- END
```
