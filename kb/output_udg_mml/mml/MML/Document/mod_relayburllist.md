# 修改媒体中继黑名单URL列表（MOD RELAYBURLLIST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、PGW-U**

该命令用于修改媒体中继URL黑名单列表。

#### 注意事项

- 该命令执行后60s生效。
- 对于URL，特殊字符的输入要求：

  - 对于空格必须使用%20代替；例如：www.hua wei.com 输入应该是：www.hua%20wei.com。
  - 对于逗号,，可以使用,本身，也可以使用％2c代替；例如：www.hua,wei.com 输入应该是：www.hua,wei.com 或者是 www.hua%2cwei.com。
  - 对于普通字符?，可以使用?本身，也可以使用%3f代替；例如：www.huawei.com.a?c 输入应该是：www.huawei.com.a?c 或者是 www.huawei.com.a%3fc。
  - 对于加号+，可以使用+本身，也可以使用％2b代替；例如：www.hua+++wei.com 输入应该是：www.hua+++wei.com 或者是 www.hua%2b%2b%2bwei.com。
  - 当字符串中出现%3f、%2c、%20、%2b或者%25本身时，对于%必须使用%25代替；例如：www.hua%3fwei.com 输入应该是：www.hua%253fwei.com。
  - 其他情况下，%就认为是%本身，可以保持原有实现即可，也可以使用%25替代%；例如：www.hua%wei.com 输入应该是：www.hua%wei.com或者是www.hua%25wei.com。
  - 对于分号使用\;代替；例如：www.hua;wei.com 输入应该是：www.hua\;wei.com。
  - 对于双引号使用\"代替；例如：www.hua"wei.com 输入应该是：www.hua\"wei.com。
  - 对于反斜杠使用\\代替；例如：www.hua\wei.com 输入应该是：www.hua\\wei.com。
  - 输入“\”只支持上述三种转义字符，不支持其他情况下输入“\”，如果要使用“\”本身，请输入“\\”代替。
  - 在CSP MML执行界面手动输入参数时，不需在';'、'"'、'\' 前手动加转义字符'\'，在MML编辑框能够看到已经自动为该特殊字符进行了转义。
  - 对于'<'、'>'、'"'、'#'、'`'、'{'、'}'、'|'、'\\'、'^'、'~'、'['、']'等特殊字符可以正常输入和显示，但在业务处理时会被转义成3个字符，所以计算长度时会按照转义后长度进行计算，即比原始长度多两个字符长度，例如：www.hua>wei.com的长度为17个字符而不是15个。
  - 不能包含ASCII码值为0x00~0x1F和0x7F的非法字符。
  - URL支持配置带通配符?和\*的参数值，通配符\*可以出现多次，通配符?最多出现5次。
  - 通配符?可以匹配除'/'，':'之外的任何单字符，不可以匹配空。
    输入通配符?时使用&#3f代替，长度按4个字符计算；例如：www.hua?ei.com输入应该是：www.hua&#3fei.com，长度为17个字符。
    由于' '、'<'、'>'、'"'、'#'、'`'、'{'、'}'、'|'、'\\'、'^'、'~'、'['、']'等特殊字符在报文传输中被转义为三个字符，而通配符?只能匹配单字符，故这些特殊字符和通配符?匹配时会匹配失败。
  - 通配符\*可以匹配多个字符，为了减少对性能的影响，建议如下：
    相似度要配置的尽可能低。尽可能保证host或者path中“\*”字母（非首字母是“\*”的情况）之前内容不相同。避免出现类似www.huawei.\*.cn www.huawei.\*.hk的配置。避免出现类似www.huawei.com\stuff\*indexa.html www.huawei.com\stuff\*indexb.html的配置。
    尽可能少使用通配符“\*”，尽可能穷举。如\*.huawei.com可以修改为www.huawei.com, www2.huawei.com, www3.huawei.com.。
- 对于报文携带Referer头域值为相对路径的场景，需要配置黑名单URL格式为\*/Path，其中Path部分可匹配报文携带的Referer头域值。
- 媒体中继URL列表配置包含端口时，对请求的Referer端口做强校验，不配置端口时，忽略端口检查。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称        | 参数说明                                                                                                |
|:---------------|:------------|:----------------------------------------------------------------------------------------------------|
| RELAYURLLISTNM | 媒体中继URL列表名称 | 可选必选说明：必选参数 参数含义：该参数用于指定媒体中继URL列表名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不区分大小写。 默认值：无 配置原则：无          |
| RELAYURLNAME   | 媒体中继URL名称   | 可选必选说明：必选参数 参数含义：该参数用于指定媒体中继URL名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围是1~31。不区分大小写。 默认值：无 配置原则：无            |
| URL            | URL         | 可选必选说明：可选参数 参数含义：该参数用于设定黑名单URL。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～119。转义后的长度不超过127。 默认值：无 配置原则：无        |
| PRIORITY       | 优先级         | 可选必选说明：可选参数 参数含义：该参数用于设置优先级。 数据来源：本端规划 取值范围：整数类型。取值范围为1～65535。值越小优先级越高。 默认值：无 配置原则：不允许重复，以免同时匹配中多个。 |
| CFGDOMAINNAME  | 配置域名称       | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。  |

#### 使用实例

修改媒体中继URL黑名单列表：

```
MOD RELAYBURLLIST: RELAYURLLISTNM="list01", RELAYURLNAME="url01",URL="www.huawei.com",PRIORITY=1;
```
