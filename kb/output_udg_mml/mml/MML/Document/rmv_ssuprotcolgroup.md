# 删除基于协议的质差检测策略（RMV SSUPROTCOLGROUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于删除基于七层协议的质差判断策略。

#### 注意事项

- 该命令执行后立即生效。
- DEFPRTGRPNAME如果在APPPOLICYCTRL中被绑定，需先解除绑定再删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                    |
|:--------------|:---------|:----------------------------------------------------------------------------------------|
| DEFPRTGRPNAME | 自定义协议组名称 | 可选必选说明：必选参数 参数含义：该参数用于指定自定义的三级协议组名称。 数据来源：本端规划 取值范围：字符串类型，不区分大小写，长度为1-63位。 默认值：无 配置原则：无 |
| PROTOCOLNAME  | 协议名称     | 可选必选说明：必选参数 参数含义：该参数用于指定三级协议名称。 数据来源：本端规划 取值范围：参数来源于知识库中支持的三级协议名称。 默认值：无 配置原则：无         |

#### 使用实例

删除自定义协议组为testadc下协议为adc的基于协议的质差策略：

```
RMV SSUPROTCOLGROUP: DEFPRTGRPNAME="testadc", PROTOCOLNAME="adc";
```
