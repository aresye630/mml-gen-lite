# 显示NETCONF代理操作失败信息（DSP NCSPROXYFAILOPER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示NETCONF代理操作失败信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

无。

#### 使用实例

NETCONF代理操作失败信息：

```
DSP NCSPROXYFAILOPER:;
```

```
RETCODE = 0  操作成功

结果如下:
------------------------
NETCONF会话ID  =  316
       时间戳  =  2017-10-11, 00:31:09:737
    NLS通道ID  =  5
      NLS名称  =  kk
     错误信息  =  系统正忙，请稍后重试。
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称       | 输出项解释        |
|:------------|:-------------|
| NETCONF会话ID | NETCONF会话ID。 |
| 时间戳         | 时间戳。         |
| NLS通道ID     | NLS通道ID。     |
| NLS名称       | NLS名称。       |
| 错误信息        | 错误信息。        |
