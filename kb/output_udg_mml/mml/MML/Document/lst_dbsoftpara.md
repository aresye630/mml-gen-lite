# 查询CSDB软件调试参数表(LST DBSOFTPARA)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询软件调试参数表。

#### 注意事项

该命令参数的具体说明请参见产品文档中“CSDB软件参数”。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                        |
|:-------|:-------|:--------------------------------------------------------------------------------------------|
| PARAID | 参数标识   | 可选必选说明：可选参数。 参数含义：该参数用于指定唯一一个参数标识号。 数据来源：本端规划 取值范围：0～1023。 默认值：无。 配置原则：如果不指定参数标识，则显示所有参数信息。 |

#### 使用实例

查询“参数标识”为“1012”的软调参数：

```
LST DBSOFTPARA: PARAID=1012;
```

#### 输出结果说明

参见**SET DBSOFTPARA**命令的参数说明。
