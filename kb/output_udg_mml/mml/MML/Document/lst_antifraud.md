#### 命令功能

**适用NF：PGW-U、UPF**

此命令用于查询当前系统的防欺诈相关参数的配置信息。包括DNS防欺诈开关、FUI防欺诈开关、HTTP防欺诈开关的开启状态。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

假如运营商需要查看防欺诈功能的配置，则命令如下：

```
LST ANTIFRAUD:;
```

```

----------

  启发式DNS防欺诈开关  =  不使能
```
