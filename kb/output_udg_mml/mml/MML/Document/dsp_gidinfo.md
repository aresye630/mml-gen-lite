# 显示POD的GID信息（DSP GIDINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询POD的GID、TB、NPTB信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                            |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------|
| SCENE   | 查询场景   | 可选必选说明：必选参数  参数含义：该参数用于表示查询场景。  数据来源：本端规划 取值范围： “PODNAME（POD名称）”：基于POD名称查询“GID（GID）”：基于GID查询“TB（TB）”：基于TB查询“NPTB（NPTB）”：基于NPTB查询  默认值：无  配置原则：无 |
| PODNAME | POD名称  | 可选必选说明：该参数在"SCENE"配置为"PODNAME"时为条件必选参数。  参数含义：该参数用于表示POD名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~1024。  默认值：无  配置原则：无                                |
| GID     | GID    | 可选必选说明：该参数在"SCENE"配置为"GID"时为条件必选参数。  参数含义：该参数用于表示GID。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无                                   |
| TB      | TB     | 可选必选说明：该参数在"SCENE"配置为"TB"时为条件必选参数。  参数含义：该参数用于表示TB。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无                                     |
| NPTB    | NPTB   | 可选必选说明：该参数在"SCENE"配置为"NPTB"时为条件必选参数。  参数含义：该参数用于表示NPTB。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无                                 |

## 使用实例

假如操作员想查询POD的GID信息，可以调用以下命令：

```
%%DSP GIDINFO: SCENE=PODNAME, PODNAME="a-pod-0";%%
RETCODE = 0  操作成功

结果如下
--------
 POD名称  =  a-pod-0
     GID  =  6000
      TB  =  2049
NPTB列表  =  1/2/3
(结果个数 = 1)

---    END
```
