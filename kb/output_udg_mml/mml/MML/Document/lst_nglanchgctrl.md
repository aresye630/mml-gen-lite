# 查询5G LAN计费控制相关参数（LST NGLANCHGCTRL）

- 命令功能

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询5G LAN计费控制相关参数。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询5G LAN计费控制相关参数：

```
LST NGLANCHGCTRL:;
```

```
RETCODE = 0  操作成功

5GLAN计费控制相关参数信息
----------------------
                    5GLAN 本地离线计费策略开关  =  是
(结果数 = 1)
```

#### 输出结果说明

参见SET NGLANCHGCTRL的参数说明。
