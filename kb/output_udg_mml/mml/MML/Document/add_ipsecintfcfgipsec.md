# 增加IPsec隧道接口（ADD IPSECINTFCFGIPSEC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于增加IPsec隧道。

## 注意事项

- 该命令执行后立即生效。

- 此配置会将安全策略与接口进行绑定，若配置了空的安全策略，则不会进行记录，只有配置真实有效的安全策略才会生成IPsec隧道接口。

- 最多可输入512条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称        | 参数说明                                                                                                                                   |
|:--------------|:------------|:---------------------------------------------------------------------------------------------------------------------------------------|
| INTERFACENAME | 接口名称        | 可选必选说明：必选参数  参数含义：配置接口名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。  默认值：无  配置原则：无                                                            |
| TNLTYPE       | Tunnel口协议类型 | 可选必选说明：必选参数  参数含义：Tunnel口协议类型。  数据来源：本端规划 取值范围： “IPSEC（IPv4IP安全）”：IPv4IP安全“IPSEC6（IPv6IP安全）”：IPv6IP安全  默认值：无  配置原则：无                   |
| POLICYNAME    | 策略名称        | 可选必选说明：可选参数  参数含义：配置策略名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~15。不区分大小写。  默认值：无  配置原则：  策略名称与ADD IPSECPOLICY/ADD IPSECPOLICY6命令配置的策略名称保持一致。 |
| SRCIFNAME     | 源接口名称       | 可选必选说明：可选参数  参数含义：地址借用接口名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。  默认值：无  配置原则：  只支持配置环回口。被借用的接口不可用于其他协议，否则有可能影响已有业务。                    |

## 使用实例

增加接口名为“Tunnel1”的安全隧道：

```
ADD IPSECINTFCFGIPSEC:INTERFACENAME="Tunnel1",TNLTYPE=IPSEC,POLICYNAME="policy1";
```
