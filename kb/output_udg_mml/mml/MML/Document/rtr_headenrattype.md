# 恢复头增强RAT类型定义（RTR HEADENRATTYPE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于恢复头增强全局参数默认值，初始化RAT类型设置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                        |
|:-------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RATTYPEVALUE | RAT类型  | 可选必选说明：可选参数 参数含义：该参数用于指定一个RAT类型，查询其相应字符串的值。 数据来源：全网规划 取值范围：枚举类型。 RESERVED：预留RAT类型。UTRAN：无线接入类型为UMTS陆地无线接入网。GERAN：无线接入类型为GSM/EDGE无线接入网。WLAN：无线接入类型为无线局域网。GAN：无线接入类型为通用接入网络。HSPAE：无线接入类型为增强型高速分组接入。EUTRAN：无线接入类型为演进UMTS陆地无线接入网。VIRTUAL：无线接入类型为Virtual。EUTRANNBIOT：无线接入类型为EUTRAN-NB-IoT。LTEM：无线接入类型为LTE-M。NR：无线接入类型为NR。REDCAPNR：无线接入类型为RedCap-NR。 默认值：无 配置原则：无 |

#### 使用实例

假如运营商希望恢复无线接入类型为WLAN的头增强参数默认值WLANSTR，可以通过该命令恢复该无线接入类型的头增强参数默认值：

```
RTR HEADENRATTYPE:RATTYPEVALUE=WLAN;
```
