# 查询TOP丢包统计参数（LST TOPDROPPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用户查询TOP丢包统计参数。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询TOP丢包统计参数：

```
LST TOPDROPPARA:;
```

```
RETCODE = 0  操作成功

结果如下
--------
    TOP丢包统计开关  =  使能（开启）
     TOP丢包统计APN  =  NULL
    TOP丢包统计场景  =  0
TOP丢包统计用户周期  =  10
    TOP丢包统计周期  =  500
TOP丢包统计丢包阈值  =  20
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见SET TOPDROPPARA的参数说明。
