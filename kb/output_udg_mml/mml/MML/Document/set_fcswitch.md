# 设置流控开关（SET FCSWITCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，关闭流控功能后在接入业务量大的情况下可能导致系统过载和复位，请谨慎使用。如需使用本命令请联系华为技术支持协助操作。

该命令用于设置整系统的流控功能禁用/启用状态。在通过**ADD FCPARAM**命令完成流控参数配置后，可以通过本命令来开启流控功能。

## 注意事项

- 该命令执行后立即生效。

- 此命令需要华为技术支持人员指导下才能执行，请慎重使用。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| SWITCH   |
|:---------|
| ENABLE   |

#### 操作用户权限

G\_1，管理员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                              |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------|
| SWITCH | 开关     | 可选必选说明：必选参数  参数含义：该参数用于配置流控功能的禁用/启用状态。  数据来源：本端规划 取值范围： DISABLE（禁用）ENABLE（启用）  默认值：无。  配置原则：  系统初始值为“ENABLE(启用)”。 |

## 使用实例

启用流控功能。

```
SET FCSWITCH: SWITCH=ENABLE;
```
