# 查询媒体中继功能配置（LST RELAYFUNC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF、PGW-U**

该命令用于查询媒体中继功能配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询媒体中继功能配置：

```
LST RELAYFUNC:;
```

```
RETCODE = 0  操作成功

媒体中继功能配置
-----------------------------
媒体中继功能开关  =  禁用
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见SET RELAYFUNC的参数说明。
