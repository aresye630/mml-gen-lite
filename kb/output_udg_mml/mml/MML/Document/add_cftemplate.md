# 增加内容过滤模板（ADD CFTEMPLATE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于增加一个内容过滤模板的配置。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为100。
- 整机最多可以配置100个内容过滤模板实例。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

增加一个内容过滤模板的配置：

```
ADD CFTEMPLATE: CFTEMPLATENAME="test", ICAPSRVGMNAME="srg", ACTION=BLOCK;
```
