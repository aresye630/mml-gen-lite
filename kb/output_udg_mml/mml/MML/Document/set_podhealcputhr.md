# 设置POD的CPU使用率的过载阈值和空载阈值（SET PODHEALCPUTHR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，如果阈值设置不合理可能导致网元倒换或者主机隔离异常，请参考网元流控阈值进行合理设置。

该命令用于设置POD的CPU使用率的过载阈值和空载阈值。

## 注意事项

- 该命令执行后立即生效。

- 系统初始记录来源于适配包。
- 该命令只在裸机场景下生效。
- POD类型可通过LST PODHEALCPUTHR查询。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                       |
|:------------|:--------|:---------------------------------------------------------------------------------------------------------------------------|
| PODTYPE     | POD类型   | 可选必选说明：必选参数  参数含义：用于设置POD类型。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无。  配置原则：无                                          |
| NOLOADTHR   | 空载阈值（%） | 可选必选说明：必选参数  参数含义：用于配置某种类型的POD实例的CPU使用率在空载时的阈值。  数据来源：本端规划  取值范围：整数类型，取值范围是1~100。  默认值：无。  配置原则：  POD实例CPU使用率的空载阈值需小于过载阈值。 |
| OVERLOADTHR | 过载阈值（%） | 可选必选说明：必选参数  参数含义：用于配置某种类型的POD实例的CPU使用率过载的阈值。  数据来源：本端规划  取值范围：整数类型，取值范围是1~100。  默认值：无。  配置原则：  POD实例CPU使用率的过载阈值需大于空载阈值。   |

## 使用实例

设置POD类型为“vup-pod”的CPU使用率空载阈值为20%，过载阈值为90%。

```
%%SET PODHEALCPUTHR: PODTYPE="vup-pod", NOLOADTHR=20, OVERLOADTHR=90;%%
RETCODE = 0  操作成功

---    END
```
