# 增加本地逻辑接口（ADD TWAMPLOGICINF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于增加本地逻辑接口。

## 注意事项

- 该命令执行后立即生效。

- 如果IPAPM与UDG共用业务侧配置的逻辑接口IP，**ADD TWAMPLOGICINF**命令中“SHAREDTYPE”需设置为“TRUE”。
- 如果IPAPM与UDG不共用业务侧配置的逻辑接口IP，**ADD TWAMPLOGICINF**命令中“SHAREDTYPE”需设置为“FALSE”。
- 必须先在业务侧配置逻辑接口IP，然后再配置本命令。

- 最多可输入32条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                                                                       |
|:------------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NAME        | 逻辑接口名称  | 可选必选说明：必选参数  参数含义：该参数用于配置逻辑接口名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。  默认值：无  配置原则：无                                                                                                                                                        |
| AFTYPE      | 地址族类型   | 可选必选说明：必选参数  参数含义：该参数用于配置地址族类型。  数据来源：全网规划 取值范围： IPV4（IPV4）  默认值：无  配置原则：无                                                                                                                                                                 |
| IPV4ADDRESS | 逻辑接口地址  | 可选必选说明：该参数在"AFTYPE"配置为"IPV4"时为条件必选参数。  参数含义：该参数用于配置逻辑接口IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。0.0.0.0～255.255.255.255。  默认值：无  配置原则：  采用点分十进制"X.X.X.X"格式。  IP地址必须是A、B或者C类地址，不能为环回地址（127.x.y.z）、组播地址（240.x.y.z）或（255.0.0.0）。  不支持不同VPN下配置相同IP地址。 |
| IPV4MASK    | 逻辑接口掩码  | 可选必选说明：该参数在"AFTYPE"配置为"IPV4"时为条件必选参数。  参数含义：该参数用于配置逻辑接口掩码。  数据来源：全网规划  取值范围：IPv4地址类型。0.0.0.0～255.255.255.255。  默认值：无  配置原则：  采用点分十进制"X.X.X.X"格式。  逻辑接口IP地址的掩码为32位。                                                                         |
| VRFNAME     | VPN实例名称 | 可选必选说明：可选参数  参数含义：该参数用于配置VPN实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~31。  默认值：无  配置原则：  VRFNAME必须在ADD TWAMPVPNINST已经配置，可以用LST TWAMPVPNINST查询。                                                                                                 |
| SHAREDTYPE  | 共享IP地址  | 可选必选说明：必选参数  参数含义：该参数用于是否共地址。  数据来源：全网规划  取值范围： TRUE(TRUE)FALSE(FALSE)  默认值：无  配置原则：  如果本命令配置的逻辑接口IP和业务侧配置的逻辑接口IP相同，则必须将本字段设置为TRUE。  如果本命令配置的逻辑接口IP和业务侧配置的逻辑接口IP不同，则必须将本字段设置为FALSE。                                                        |

## 使用实例

增加逻辑接口名称为：n3if1/1/0的实例：

```
ADD TWAMPLOGICINF: NAME="n3if1/1/0", AFTYPE=IPV4, IPV4ADDRESS="10.0.0.0", IPV4MASK="255.255.255.255", VRFNAME="ck", SHAREDTYPE=FALSE;
```
