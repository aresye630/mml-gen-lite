# 查询RSA2048公钥配置（LST RSA2048）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询所有的RSA2048配置，支持指定查询某个记录。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称        | 参数说明                                                                                               |
|:------------|:------------|:---------------------------------------------------------------------------------------------------|
| RSA2048NAME | RSA2048公钥名称 | 可选必选说明：可选参数 参数含义：该参数用于指定RSA2048公钥配置名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

假如运营商想查看名称为“test”的RSA2048记录：

```
LST RSA2048: RSA2048NAME="test";
```
