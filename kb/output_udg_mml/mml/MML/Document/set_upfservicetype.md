# 设置UPF可选服务类型（SET UPFSERVICETYPE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于设置UPF可选服务类型。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 可选服务类型1~可选服务类型3不能全部为空。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | SERVICETYPE1   |
|:-------|:---------------|
| 初始值    | Common         |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                                               |
|:-------------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE1 | 可选服务类型1 | 可选必选说明：可选参数 参数含义：该参数用于指定UPF可选服务类型。 数据来源：本端规划 取值范围：字符串类型，支持范围："Common"，"Relay"，"IISA"和"MobileVPN"，区分大小写。 默认值：无 配置原则： "Common"与其余配置不兼容。输入为空将删除已有配置项。 |
| SERVICETYPE2 | 可选服务类型2 | 可选必选说明：可选参数 参数含义：该参数用于指定UPF可选服务类型。 数据来源：本端规划 取值范围：字符串类型，支持范围："Common"，"Relay"，"IISA"和"MobileVPN"，区分大小写。 默认值：无 配置原则： "Common"与其余配置不兼容。输入为空将删除已有配置项。 |
| SERVICETYPE3 | 可选服务类型3 | 可选必选说明：可选参数 参数含义：该参数用于指定UPF可选服务类型。 数据来源：本端规划 取值范围：字符串类型，支持范围："Common"，"Relay"，"IISA"和"MobileVPN"，区分大小写。 默认值：无 配置原则： "Common"与其余配置不兼容。输入为空将删除已有配置项。 |

#### 使用实例

假如需要设置UPF可选服务类型，则命令如下：

```
SET UPFSERVICETYPE:SERVICETYPE1="Relay", SERVICETYPE2="IISA", SERVICETYPE3="MobileVPN";
```
