# 修改容灾组信息（MOD DRGROUPINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令为高危命令，修改容灾控制通道信息，可能导致主备网元协商中断，请谨慎使用并联系华为技术支持协助操作。

该命令用于修改容灾组信息中的对端容灾控制通道IPv4地址或IPv6地址。

## 注意事项

- 该命令执行后立即生效。

- 该命令适用于支持热备或冷备容灾的网元执行。
- “容灾组标识”，“容灾组名称”，“本端容灾实例标识”，“对端容灾实例标识”，“对端容灾控制通道IP地址版本号”可执行**LST DRGROUPINFO**查询获得。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称            | 参数说明                                                                                                             |
|:------------|:----------------|:-----------------------------------------------------------------------------------------------------------------|
| DRGROUPID   | 容灾组标识           | 可选必选说明：必选参数  参数含义：该参数用于标识一条容灾组信息，不同容灾组信息的该标识不能相同。  数据来源：全网规划  取值范围：整数类型，取值范围是1~8。  默认值：无  配置原则：无                 |
| DRGROUPNAME | 容灾组名称           | 可选必选说明：必选参数  参数含义：该参数用于表示容灾组的名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~32。只支持字母和数字，字母区分大小写，不能包含空格和特殊字符。  默认值：无  配置原则：无 |
| LDRINSTID   | 本端容灾实例标识        | 可选必选说明：必选参数  参数含义：该参数用于表示容灾组中本端的网元标识。  数据来源：全网规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无                           |
| PDRINSTID   | 对端容灾实例标识        | 可选必选说明：必选参数  参数含义：该参数用于表示容灾组中对端的网元标识。  数据来源：全网规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无                           |
| IPVERSION   | 对端容灾控制通道IP地址版本号 | 可选必选说明：必选参数  参数含义：该参数用于用户指定对端容灾控制通道IP地址类型。  数据来源：全网规划 取值范围： IPV4（IPv4类型地址）IPV6（IPv6类型地址）  默认值：无  配置原则：无          |
| PGRCIP      | 对端容灾控制通道IPv4地址  | 可选必选说明：该参数在"IPVERSION"配置为"IPV4"时为条件必选参数。  参数含义：该参数用于配置对端容灾控制通道的IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无 |
| PGRCIPV6    | 对端容灾控制通道IPv6地址  | 可选必选说明：该参数在"IPVERSION"配置为"IPV6"时为条件必选参数。  参数含义：该参数用于配置对端容灾控制通道的IPv6地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无 |

## 使用实例

修改一条指定的容灾组信息中的对端容灾控制通道IPv4地址：

```
%%MOD DRGROUPINFO: DRGROUPID=1, DRGROUPNAME="UEG88A91", LDRINSTID=1, PDRINSTID=2, IPVERSION=IPV4, PGRCIP="192.168.0.1";%%
RETCODE = 0  操作成功

---    END
```
