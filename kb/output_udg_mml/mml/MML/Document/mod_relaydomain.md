# 修改媒体中继域名配置（MOD RELAYDOMAIN）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，修改该配置后，会导致媒体中继业务受影响。

该命令用于修改媒体中继域名配置。

#### 注意事项

该命令执行后60s生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

如果需要修改一组媒体中继域名配置，则配置命令如下：

```
MOD RELAYDOMAIN: RELAYDOMAINNAME="test001", DOMAINVALUE="modDomain";
```
