# 查询流特征节点超时时间（LST INSAFEATTMOUT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：CloudEPSN**

查询流特征节点超时时间。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询当前流特征节点超时时间：

```
LST INSAFEATTMOUT:;
```

```
INSAFEATTMOUT信息
------
      超时时间(秒) = 30
 
(结果个数 = 1)
--- END
```

#### 输出结果说明

参见SET INSAFEATTMOUT的参数说明。
