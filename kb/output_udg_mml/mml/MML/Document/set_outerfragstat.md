# 设置外层IP分片统计相关参数。（SET OUTERFRAGSTAT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF、SGW-U**

该命令用于设置外层IP分片统计相关参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | PEERIPSTATSW   |   FRAGSTATTHD |   FRAGSTATPRD |
|:-------|:---------------|--------------:|--------------:|
| 初始值    | ENABLE         |           200 |            60 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称         | 参数说明                                                                                                                                                                                                                         |
|:-------------|:-------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PEERIPSTATSW | 基于对端IP地址统计开关 | 可选必选说明：可选参数 参数含义：该参数用于指定基于对端IP地址统计分片报文的功能开关。使能该功能后，系统基于DSCP值周期性统计IP分片资源数，当超过阈值后记录服务器IP地址，并统计该服务器IP地址的分片报文包数。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无                                                        |
| FRAGSTATTHD  | IP分片资源阈值     | 可选必选说明：条件可选参数 前提条件：该参数在“PEERIPSTATSW”配置为“ENABLE”时为可选参数。 参数含义：该参数用于指定IP分片报文占用资源数阈值，当某个DSCP值对应的分片资源数达到该配置值后，记录该DSCP值的对端IP地址，并统计该IP地址的分片报文数量。 数据来源：本端规划 取值范围：整数类型，取值范围为10～2000，单位是个。 默认值：无 配置原则：无                               |
| FRAGSTATPRD  | 统计周期时长（分钟）   | 可选必选说明：条件可选参数 前提条件：该参数在“PEERIPSTATSW”配置为“ENABLE”时为可选参数。 参数含义：该参数用于指定基于服务器IP地址统计的周期时长。每个周期开始时，会重新统计用户的IP分片报文及服务器IP地址的分片报文数量，并将上一个周期内记录的服务器IP地址统计数据进行排序，记录前50个服务器IP地址统计数据。 数据来源：本端规划 取值范围：整数类型，取值范围为10～120，单位是分钟。 默认值：无 配置原则：无 |

#### 使用实例

开启基于对端IP地址统计外层IP分片的开关及阈值：

```
SET OUTERFRAGSTAT: PEERIPSTATSW=ENABLE, FRAGSTATTHD=200;
```
