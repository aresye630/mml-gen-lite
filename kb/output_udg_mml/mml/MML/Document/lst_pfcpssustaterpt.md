# 查询智能单元状态上报相关属性（LST PFCPSSUSTATERPT）

#### 命令功能

**适用NF：UPF、PGW-U、SGW-U**

该命令用来查询智能单元状态上报相关属性。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询查询智能单元状态上报相关属性：

```
LST PFCPSSUSTATERPT:;
```

#### 输出结果说明

参见SET PFCPSSUSTATERPT的参数说明。
