# 查询喂狗功能相关配置（LST NPWATCHDOG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询喂狗功能相关配置：喂狗检测周期，喂狗超时时长。

## 注意事项

该命令仅适用于NP卡加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询喂狗功能相关配置：

```
LST NPWATCHDOG:;
RETCODE = 0  操作成功

结果如下
--------
喂狗检测周期  =  500
喂狗超时时长  =  24
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                           |
|:--------|:------------------------------------------------|
| 喂狗检测周期  | 该参数用于表示喂狗检测周期。                                  |
| 喂狗超时时长  | 该参数用于表示喂狗检测周期的倍数，当检测时间超过喂狗检测周期乘以喂狗超时时长时即认为喂狗超时。 |
