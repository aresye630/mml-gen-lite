# 恢复APN软参记录（RTR APNSOFTPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于恢复APN下软件参数信息。

#### 注意事项

- 该命令执行后立即生效。
- BIT与BYTE类型软参执行该命令后将恢复成零，STRING类型软参执行该命令后将恢复成NULL。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                                                                               |
|:----------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN       | APN      | 可选必选说明：必选参数 参数含义：该参数用于指定APN实例名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”特殊字符，不区分大小写。 默认值：无 配置原则：无 |
| DT        | 软参记录数据类型 | 可选必选说明：必选参数 参数含义：该参数用于指定APN下软件参数的数据类型。 数据来源：本端规划 取值范围：枚举类型。 BIT：比特。BYTE：字节。STRING：字符串。 默认值：无 配置原则： 配置BIT表示需要设置比特类型软件参数。配置BYTE表示需要设置字节类型软件参数。配置STRING表示需要设置字符串类型软件参数。                               |
| BITNUM    | Bit索引    | 可选必选说明：条件必选参数 前提条件：该参数在“DT”配置为“BIT”时为必选参数。 参数含义：该参数用于指定比特类型软件参数的索引。 数据来源：本端规划 取值范围：整数类型，取值范围为1～64。 默认值：无 配置原则：无                                                                                    |
| BYTENUM   | Byte索引   | 可选必选说明：条件必选参数 前提条件：该参数在“DT”配置为“BYTE”时为必选参数。 参数含义：该参数用于指定字节类型软件参数的索引。 数据来源：本端规划 取值范围：整数类型，取值范围为1～16。 默认值：无 配置原则：无                                                                                   |
| STRINGNUM | String索引 | 可选必选说明：条件必选参数 前提条件：该参数在“DT”配置为“STRING”时为必选参数。 参数含义：该参数用于指定字符串类型软件参数的索引。 数据来源：本端规划 取值范围：整数类型，取值范围为1～5。 默认值：无 配置原则：无                                                                                 |

#### 使用实例

- 当需要恢复当前索引为8的APN BYTE类软参值为0时：

  ```
  RTR APNSOFTPARA: APN="f1", DT=BYTE, BYTENUM=8;
  ```
- 当需要恢复当前索引为8的APN BIT类软参值为0时：

  ```
  RTR APNSOFTPARA: APN="f1", DT=BIT, BITNUM=8;
  ```
- 当需要恢复当前索引为5的APN STRING类软参值为NULL时：

  ```
  RTR APNSOFTPARA: APN="f1", DT=STRING, STRINGNUM=5;
  ```
