# 删除媒体中继HTTP消息头（RMV RELAYHTTPMHD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、PGW-U**

该命令用于删除媒体中继HTTP消息头。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称       | 参数说明                                                                                                                                                                                       |
|:----------------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HTTPMSGCTRLNAME | HTTP消息控制名称 | 可选必选说明：必选参数 参数含义：该参数用于指定HTTP消息控制名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围是1~31。不区分大小写。 默认值：无 配置原则： 该参数使用ADD RELAYHTTPMCTL命令配置生成。该取值必须和ADD RELAYHTTPMCTL中配置的"HTTPMAGCTRLNAME"参数取值相同。                  |
| MSGTYPE         | 消息类型       | 可选必选说明：可选参数 参数含义：该参数用于指定消息类型。 数据来源：本端规划 取值范围：枚举类型。 UEHTTPRSP：UE HTTP响应。CDNHTTPREQ：CDN HTTP请求。 默认值：无 配置原则：无                                                                                 |
| HEADERNAME      | 头域名称       | 可选必选说明：可选参数 参数含义：该参数用于指定头域名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围是1~63。区分大小写，不允许仅大小写不同的重复记录。 默认值：无 配置原则：以下字段为通用必选或条件必选字段，不允许配置 Connection、Content-Length、Content-Range、Content-Type、Date、Location。 |

#### 使用实例

删除媒体中继HTTP消息头：

```
RMV RELAYHTTPMHD: HTTPMSGCTRLNAME="http01";
```
