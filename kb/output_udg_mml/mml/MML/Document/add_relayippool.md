# 增加媒体中继IP池（ADD RELAYIPPOOL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于增加媒体中继IP池。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为6。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                 |
|:---------|:-------|:---------------------------------------------------------------------------------------------------------------------|
| POOLNAME | IP池名   | 可选必选说明：必选参数 参数含义：该参数用于配媒体中继IP池名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无                         |
| VPNNAME  | VPN名称  | 可选必选说明：可选参数 参数含义：该参数用于设置VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。区分大小写。 默认值：无 配置原则：绑定VPN时需要确保该VPN已经配置（ADD VPNINST）。 |

#### 使用实例

假设需要增媒体中继IP池，则命令如下：

```
ADD RELAYIPPOOL: POOLNAME="pool_relay";
```
