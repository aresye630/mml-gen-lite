# 清除ACL规则匹配计数（RTR ACLGROUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于清除ACL规则组下规则的匹配计数，也可以清除当前所有ACL的匹配计数。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                                                                   |
|:--------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------|
| ACLNAME | ACL规则组标识 | 可选必选说明：可选参数 参数含义：该参数用于指定规则属于哪个规则组。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。不支持空格，区分大小写。以英文字母a～z或A～Z开始，可以是英文字母、数字、连字符“-”、下划线“_”或中文字符的组合。 默认值：无 |

#### 使用实例

- 用户需要清除当前所有ACL规则的匹配计数：

  ```
  RTR ACLGROUP:;
  ```
- 用户需要清除当前ACL规则组2000的匹配计数：

  ```
  RTR ACLGROUP:ACLNAME="2000";
  ```
