# 修改探测路径配置（MOD DETECTPATH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于修改探测路径配置。

#### 注意事项

- 该命令执行后立即生效。
- 探测路径绑定APN后，路径信息不允许修改。
- 探测路径名称不允许修改。
- 探测路径不能更新为已经存在的路径配置。本端逻辑接口名、对端IP地址类型、对端IP均相同，则认为是同一路径配置。
- 当 IPVERSION 配置为 "IPV4" 且 REDUNDRDTSW 配置为 "ENABLE" 时，REDUNDRDTIPV4 为必填参数。
- 当 IPVERSION 配置为 "IPV6" 且 REDUNDRDTSW 配置为 "ENABLE" 时，REDUNDRDTIPV6 为必填参数。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称           | 参数说明                                                                                                                                 |
|:---------------|:---------------|:-------------------------------------------------------------------------------------------------------------------------------------|
| PATHNAME       | 路径名称           | 可选必选说明：必选参数 参数含义：该参数用于指定用于连通性探测的路径名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无                                     |
| LOCALINF       | 本端逻辑接口名称       | 可选必选说明：必选参数 参数含义：该参数用于指定逻辑接口名称，此处只能为Phif接口。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD LOGICINF命令配置生成。       |
| IPVERSION      | IP地址版本类型       | 可选必选说明：必选参数 参数含义：该参数用于指定路径IP地址类型。 数据来源：本端规划 取值范围：枚举类型。 IPV4：表示地址类型为IPv4。IPV6：表示地址类型为IPv6。 默认值：无 配置原则：无                               |
| PEERIPV4       | 对端IPV4地址       | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV4”时为必选参数。 参数含义：该参数用于指定路径的对端ipv4地址。 数据来源：全网规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无 配置原则：无            |
| PEERIPV6       | 对端IPV6地址       | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV6”时为必选参数。 参数含义：该参数用于指定对端ipv6地址。 数据来源：全网规划 取值范围：IPv6地址类型。采用冒号分十六进制格式。 默认值：无 配置原则：无           |
| ECHOINTERVAL   | 发送探测报文的间隔时间    | 可选必选说明：可选参数 参数含义：该参数用于指定发送探测报文的间隔时间。 数据来源：全网规划 取值范围：整数类型，取值范围为1～60，单位是秒。 默认值：无 配置原则：无                                                |
| TIMEOUT        | 等待探测报文响应超时时间   | 可选必选说明：可选参数 参数含义：该参数用于指定发送完探测报文后，等待探测报文的超时时间。 数据来源：全网规划 取值范围：整数类型，取值范围为1～60。 默认值：无 配置原则：无                                            |
| RECVTHRESHOLD  | 故障恢复阈值         | 可选必选说明：可选参数 参数含义：当连续收到探测报文的数量到达该阈值时，认为链路状态恢复。 数据来源：全网规划 取值范围：整数类型，取值范围为1～65535。 默认值：无 配置原则：无                                         |
| FAULTTHRESHOLD | 故障阈值           | 可选必选说明：可选参数 参数含义：当连续未收到探测报文的数量到达该阈值时，认为链路状态故障。 数据来源：全网规划 取值范围：整数类型，取值范围为1～65535。 默认值：无 配置原则：无                                        |
| REDUNDRDTSW    | 探测路径的重定向开关     | 可选必选说明：可选参数 参数含义：该参数用于指定探测路径的重定向开关。 数据来源：全网规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无                                         |
| REDUNDRDTIPV4  | 探测路径的重定向IPV4地址 | 可选必选说明：条件可选参数 前提条件：该参数在“REDUNDRDTSW”配置为“ENABLE”时为可选参数。 参数含义：该参数用于指定探测路径的重定向IPV4地址。 数据来源：全网规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无 配置原则：无     |
| REDUNDRDTIPV6  | 探测路径的重定向IPV6地址 | 可选必选说明：条件可选参数 前提条件：该参数在“REDUNDRDTSW”配置为“ENABLE”时为可选参数。 参数含义：该参数用于指定探测路径的重定向IPV6地址。 数据来源：全网规划 取值范围：IPv6地址类型。采用冒号分十六进制格式。 默认值：无 配置原则：无 |

#### 使用实例

- 修改名为“testpath3”的探测路径，Echo探测间隔为5秒， Echo探测超时时间为5秒， 故障恢复阈值为8次， 故障阈值为16次：

  ```
  MOD DETECTPATH: PATHNAME="testpath3", LOCALINF="phif1/0/1", IPVERSION=IPV6, PEERIPV6="FC00:0000:0000:0000:0000:0000:0000:0000", ECHOINTERVAL=5, TIMEOUT=5, RECVTHRESHOLD=8, FAULTTHRESHOLD=16;
  ```
- 修改名为“testpath4”的探测路径，Echo探测间隔为5秒， Echo探测超时时间为5秒， 故障恢复阈值为8次， 故障阈值为16次，探测路径的重定向开关为关闭：

  ```
  MOD DETECTPATH: PATHNAME="testpath4", LOCALINF="phif1/0/2", IPVERSION=IPV6, PEERIPV6="FC00:0000:0000:0000:0000:0000:0000:0000", ECHOINTERVAL=5, TIMEOUT=5, RECVTHRESHOLD=8, FAULTTHRESHOLD=16,REDUNDRDTSW = DISABLE;
  ```
