# 删除TCP旁路配置（RMV TOBYPASSCFG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于删除旁路Pod配置。

#### 注意事项

该命令执行后对新数据流生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                               |
|:--------|:-------|:-----------------------------------------------------------------------------------|
| PODNAME | Pod名称  | 可选必选说明：必选参数 参数含义：Pod名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

删除名称为“to-pod-0”的pod旁路：

```
RMV TOBYPASSCFG: PODNAME="to-pod-0";
```
