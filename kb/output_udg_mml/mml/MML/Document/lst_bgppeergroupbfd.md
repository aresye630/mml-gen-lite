# 查询BGP对等体组BFD检测（LST BGPPEERGROUPBFD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查看对等体组的BFD参数。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                         |
|:----------|:--------|:-----------------------------------------------------------------------------------------------------------------------------|
| VRFNAME   | VPN实例名称 | 可选必选说明：可选参数 参数含义：该参数用于指定用户的BGP VPN实例。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                                                |
| GROUPNAME | 组名      | 可选必选说明：可选参数 参数含义：该参数用于指定用户所配置的对等体组。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～47。 默认值：无 配置原则：使用LST BGPPEERGROUP命令查看可用对等体组名。              |
| AFTYPE    | 组地址族类型  | 可选必选说明：可选参数 参数含义：该参数用于指定BGP VPN实例下的地址族。 数据来源：本端规划 取值范围：枚举类型。 public：公网地址族。ipv4uni：IPv4地址族。ipv6uni：IPv6地址族。noaf：不指定地址族。 默认值：无 |

#### 使用实例

查看对等体组的BFD参数：

```
LST BGPPEERGROUPBFD:;
```

