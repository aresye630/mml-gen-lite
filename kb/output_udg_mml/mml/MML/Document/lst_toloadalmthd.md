# 查询告警阈值（LST TOLOADALMTHD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询告警阈值。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询告警阈值：

```
LST TOLOADALMTHD:;
```

```
RETCODE = 0  操作成功

TCP负载告警阈值控制
------------------
告警产生阈值（%）  =  80
告警恢复阈值（%）  =  60
(结果个数 = 1)

--- END
```

#### 输出结果说明

参见SET TOLOADALMTHD的参数说明。
