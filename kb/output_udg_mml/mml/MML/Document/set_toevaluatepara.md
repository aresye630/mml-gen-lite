# 设置TCP优化评估配置信息（SET TOEVALUATEPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于设置TCP优化评估配置信息。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | TOEVASWITCH   |   TOEVASAMPRATIO |
|:-------|:--------------|-----------------:|
| 初始值    | DISABLE       |              100 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称        | 参数说明                                                                                                                         |
|:---------------|:------------|:-----------------------------------------------------------------------------------------------------------------------------|
| TOEVASWITCH    | TCP优化评估开关   | 可选必选说明：可选参数 参数含义：该参数用于设置TCP优化评估开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无                                  |
| TOEVASAMPRATIO | TCP优化评估抽样比率 | 可选必选说明：条件可选参数 前提条件：该参数在“TOEVASWITCH”配置为“ENABLE”时为可选参数。 参数含义：该参数用于设置TCP优化评估抽样比率。 数据来源：本端规划 取值范围：整数类型，取值范围为0～100。 默认值：无 配置原则：无 |

#### 使用实例

开启TCP优化评估开关，设置TCP优化评估抽样比率为50%：

```
SET TOEVALUATEPARA:TOEVASWITCH=ENABLE,TOEVASAMPRATIO=50;
```
