# 查询测量结果文件(LST MEASRST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询网元上的测量结果文件状态。

## 注意事项

执行该MML前，UDG需要完成MAE对接。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                     |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------|
| NEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：标识网元ID，可以通过LST ME命令查询获取。 取值范围：0~65535。 默认值：无。 配置原则：无。                                                                  |
| SDT    | 开始时间   | 可选必选说明：可选参数。 参数含义：查询起始时间。 取值范围：年月日时分秒，规则为YYYY/MM/DD HH:MM:SS。 默认值：无。 配置原则：若不输入，则表示该参数不作为查询的限制条件。                                         |
| EDT    | 结束时间   | 可选必选说明：可选参数。 参数含义：查询结束时间。 取值范围：年月日时分秒，规则为YYYY/MM/DD HH:MM:SS。 默认值：无。 配置原则：若不输入，则表示该参数不作为查询的限制条件。                                         |
| PRD    | 周期     | 可选必选说明：可选参数。 参数含义：标识查询的周期。 取值范围： ALL(全部)FIVE(5分钟)FIFTEEN(15分钟)THIRTY(30分钟)SIXTY(1小时)ONE_DAY(一天) 默认值：ALL(全部)。 配置原则：若不输入，则表示查询所有周期的测量结果文件。 |
| ISULD  | 是否已上报  | 可选必选说明：可选参数。 参数含义：测量结果文件是否已上报网管。 取值范围： NO_UPLOAD(未上报)UPLOADED(已上报)ALL(全部) 默认值：NO_UPLOAD(未上报)。 配置原则：若不输入，则表示查询未上报网管的测量结果文件。               |
| EMS    | 网管类型   | 可选必选说明：必选参数。 参数含义：网管类型。 取值范围：1~65535。 默认值：无。 配置原则：联系相应的网管运维人员获取网管类型。                                                                     |
