# 恢复全部IKE统计信息（RTR IKEALLSTATISTIC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于清除所有的IKE统计数据，包括错误计数统计。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                             |
|:--------|:-------|:---------------------------------------------------------------------------------|
| PODNAME | Pod名称  | 可选必选说明：可选参数  参数含义：该参数表示Pod名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~63。  默认值：无  配置原则：无 |

## 使用实例

清除所有的IKE统计数据，包括错误计数统计：

```
RTR IKEALLSTATISTIC:;
```
