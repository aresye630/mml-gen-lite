# 增加媒体中继URL检查规则（ADD RELAYURLCHK）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于增加媒体中继URL检查规则。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为100。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称       | 参数说明                                                                                                                                                                                                                    |
|:---------------|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RELAYTPLNAME   | 媒体中继模板名称   | 可选必选说明：必选参数 参数含义：该参数用来指定媒体中继模板名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数使用ADD RELAYTEMPLATE命令配置生成。配置时需要确保RELAYTPLNAME已经配置（ADD RELAYTEMPLATE）。                                                   |
| BLKURLLISTNAME | 黑名单URL列表名称 | 可选必选说明：必选参数 参数含义：该参数用来指定黑名单URL列表名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数使用ADD RELAYBURLLIST命令配置生成。配置时需要确保RelayURLListNM已经配置（ADD RELAYBURLLIST）。                                               |
| DFTBLKURLACT   | 缺省的黑名单动作   | 可选必选说明：可选参数 参数含义：该参数用于指定缺省黑名单动作。 数据来源：本端规划 取值范围：枚举类型。 FORBIDDEN：拒绝。REDIRECT：重定向。 默认值：FORBIDDEN 配置原则：无                                                                                                                   |
| IGNORESCHEME   | 忽略Scheme   | 可选必选说明：可选参数 参数含义：该参数用于控制开启或关闭忽略Scheme开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：ENABLE 配置原则：当绑定的黑名单URL列表中配置的URL包含Scheme时，根据本参数的配置控制是否忽略Scheme进行URL匹配；当绑定的黑名单URL列表中配置的URL未包含Scheme时，此参数配置不生效，按照忽略Scheme进行URL匹配。 |
| CFGDOMAINNAME  | 配置域名称      | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1~31。 默认值：无 配置原则：1.输入单空格将删除该参数已有配置项。                                                                                                                    |

#### 使用实例

假如需要创建一组媒体中继URL检查规则，则命令如下：

```
ADD RELAYURLCHK: RELAYTPLNAME="test", BLKURLLISTNAME="test";
```
