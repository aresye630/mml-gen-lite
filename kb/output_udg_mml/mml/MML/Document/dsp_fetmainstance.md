# 显示FETMA实例信息（DSP FETMAINSTANCE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来显示单板上的FETM进程中注册的所有FETMA实例信息。

#### 注意事项

该命令仅适用于NP卡加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                               |
|:-------|:-------|:---------------------------------------------------------------------------------------------------|
| RUID   | RU编号   | 可选必选说明：必选参数。 参数含义：该参数用于指定RU编号。 数据来源：本端规划。 取值范围：整数类型，输入长度范围为0～4294967294。 默认值：无。 配置原则：通过DSP RU命令查询。 |

#### 使用实例

显示69号单板中注册的FETMA实例信息：

```
%%DSP FETMAINSTANCE: RUID=69;%%
RETCODE = 0  操作成功
```

#### 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                                                           |
|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 实例ID    | 该参数表示实例ID，注册时由FETM分配，单板范围内唯一。                                                                                                                                   |
| 实例状态    | 该参数表示实例的状态，枚举类型，取值范围： INIT（注册态）：表示实例正在进行申请资源、清理数据和解析表信息等操作。SEQNEG（协商态）：表示实例注册成功，正在协商数据通信的序列号。RUNNING（运行态）：表示实例正常运行，可以进行数据通信。LINKFAULT（链路故障态）：表示实例链路中断，无法进行数据通信。 |
| 实例TB    | 该参数表示实例在数据通信时使用的TB值。                                                                                                                                            |
| 实例TP    | 该参数表示实例在数据通信时使用的TP值。                                                                                                                                            |
| 服务实例类型  | 该参数表示实例所在服务的类型。                                                                                                                                                 |
| 服务实例名称  | 该参数表示实例所在服务的名称。                                                                                                                                                 |
| 服务实例ID  | 该参数表示实例所在服务的实例ID，由CSR分配，整系统唯一。                                                                                                                                  |
| 注册时间    | 该参数表示实例的注册时间。                                                                                                                                                   |
| 注册次数    | 该参数表示实例的注册次数。                                                                                                                                                   |
| 清表标识    | 该参数表示实例注册时是否清理表项数据，枚举类型，取值范围： CLEAR（清表）：表示注册时需要清理表项数据，在清理结束前，实例处于注册态。UNCLEAR（不清表）：表示注册时不清理表项数据。                                                                 |
| 清表状态    | 该参数表示注册时的清表状态，“清表标识”为“清表”时有效，枚举类型，取值范围： UNCLEARED（未清表）：表示存在未清理的表项数据。CLEARING（清表中）：表示正在清理表项数据。CLEARED（清表成功）：表示清表已完成。                                             |
| 主机ID    | 该参数表示实例所在主机的ID。NULL表示实例注册时无需携带主机信息。                                                                                                                             |
