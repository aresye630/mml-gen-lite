# 增加TCP优化策略配置（ADD TOPOLICYCFG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于增加TCP优化策略配置,实现基于小区/IMSI/RAT类型的TCP优化参数定制化功能。

#### 注意事项

- 该命令执行后只对之后发生承载更新的用户或者新激活用户生效。
- 该命令最大记录数为7。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称      | 参数说明                                                                                                                           |
|:---------|:----------|:-------------------------------------------------------------------------------------------------------------------------------|
| POLICYID | 策略ID      | 可选必选说明：必选参数 参数含义：策略ID。 数据来源：本端规划 取值范围：整数类型,取值范围为1~7。 默认值：无 配置原则：无                                                              |
| CCALG    | TCP拥塑控制算法 | 可选必选说明：必选参数 参数含义：设置TCP拥塑控制算法。 数据来源：本端规划 取值范围：枚举类型。 CUBIC：CCALG_CUBIC。BIC：CCALG_BIC。BBR：CCALG_BBR。EBBR：CCALG_EBBR。 默认值：无 配置原则：无 |
| RCVBUF   | 接收缓存区大小   | 可选必选说明：可选参数 参数含义：用于设置为TCP Socket预留的接收缓存大小。 数据来源：本端规划 取值范围：整数类型,取值范围4096~31457280。 默认值：无 配置原则：无                                 |
| SNDBUF   | 发送缓存区大小   | 可选必选说明：可选参数 参数含义：用于设置为TCP Socket预留的发送缓存大小。 数据来源：本端规划 取值范围：整数类刑,取值范围为4096~31457280。 默认值：无 配置原则：无                                |

#### 使用实例

运营商需要增加一个策略ID为1,拥塞控制算法为EBBR的TCP优化策略配置：

```
ADD TOPOLICYCFG: POLICYID=1,CCALG=EBBR;
```
