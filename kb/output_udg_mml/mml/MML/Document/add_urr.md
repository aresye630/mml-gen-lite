# 增加URR（ADD URR）

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于增加使用量上报规则信息，通过该命令可以针对不同应用类型的数据采取不同的上报规则。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为65000。当配置记录数大于规格的90%时，会上报“ALM-135602215 配置数量超阈值”告警。当配置记录数小于等于配置规格90%时，恢复“ALM-135602215 配置数量超阈值”告警。阈值可以通过MOD CFGTHRESHOLD命令修改。
- 该命令支持配置在线计费URR、离线计费URR以及监控属性的URR。
- 该命令中的URRID字段要求在所有URR内唯一，建议从1000开始分配。
- 开启事件计费时, 对性能会产生一定影响。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                                    |
|:----------------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| URRNAME         | 使用量上报规则名称 | 可选必选说明：必选参数 参数含义：该参数用于设置URR名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                              |
| URRID           | URR标识     | 可选必选说明：必选参数 参数含义：该参数用于设置URR标识。 数据来源：本端规划 取值范围：整数类型，取值范围为0～2147483646。 默认值：2147483647                                                                                                                                                                                                                                                                                                    |
| USAGERPTMODE    | 使用量上报模式   | 可选必选说明：必选参数 参数含义：该参数用于设置使用量上报模式。 数据来源：本端规划 取值范围：枚举类型。 OFFLINE：离线计费，表示该URR为离线计费应用的URR。ONLINE：在线计费，表示该URR为在线计费应用的URR。MONITORINGKEY：监控属性值，表示该URR为流量累计应用的Monitoring-Key。QOS：QoS，表示该URR为QoS保证。 默认值：无 配置原则：无                                                                                                                                                                                  |

| DFTQUOTATIME    | 默认时长配额（秒） | 可选必选说明：条件可选参数 前提条件：该参数在“USAGERPTMODE”配置为“ONLINE”时为可选参数。 参数含义：该参数用于设置默认时长配额。 数据来源：本端规划 取值范围：整数类型，取值范围为0～3600、4294967295。配置为0时，表示该URR不使能默认配额时长功能，配置为4294967295时，表示默认时长配额继承全局配置。 默认值：无 配置原则：如果运营商希望设定用户使用的默认配额时长，则配置该参数。该参数无默认值，如果不配置，表示默认时长配额继承全局配置。                                                                                                                                      |
| ONLMETERINGTYPE | 在线计费统计类型  | 可选必选说明：条件可选参数 前提条件：该参数在“USAGERPTMODE”配置为“ONLINE”时为可选参数。 参数含义：该参数用于设置在线计费统计类型。 数据来源：本端规划 取值范围：枚举类型。 VOLUME：按流量计费。TIME：按时长计费。EVENT：按事件计费。FREE：免费。表示该URR有计费欺诈风险，需要做计费防欺诈判断。VOLUME_TIME：按流量和时长计费。EVENT_VOLUME：按事件和流量计费。EVENT_TIME：按事件和时长计费。EVENT_VOLUME_TIME：按事件、流量和时长计费。 默认值：VOLUME 配置原则： 如果运营商希望采取计费方式为在线计费，可以配置该参数。要实现流量免费，需要在UNC上一起配合做配置。开启事件计费时, 对性能会产生一定影响，误配后影响系统性能，执行命令前请评估对性能的影响。  |

| DFTQUOTAPARA    | 默认流量配额的单位 | 可选必选说明：条件可选参数 前提条件：该参数在“USAGERPTMODE”配置为“ONLINE”时为可选参数。 参数含义：默认流量配额的单位。 数据来源：本端规划 取值范围：枚举类型。 Byte：默认配额单位是字节。KByte：默认配额单位是千字节。 默认值：Byte 配置原则：一般可以不配置或者配置Byte，如果需要的配额超过4G则需要配置Kbyte。                                                                                                                                                                                                      |

| RG              | 计费组       | 可选必选说明：条件可选参数 前提条件：该参数在“USAGERPTMODE”配置为“OFFLINE” 或 “ONLINE”时为可选参数。 参数含义：该参数用于设置计费组。 数据来源：本端规划 取值范围：整数类型，取值范围为0~4294967294。 默认值：无 配置原则：报表功能开启，软参bit1557开启，则需要配置此参数，同时参数值需要与SMF保持一致，否则报表上报的RG与实际计费的RG不一致。                                                                                                                                                                                |

#### 使用实例

假如运营商需要增加一个使用量上报规则信息用于在线计费，设置在线计费方式为免费：

```
ADD URR: URRNAME="onlineURR", URRID=1000, USAGERPTMODE=ONLINE, ONLMETERINGTYPE=FREE;
```
