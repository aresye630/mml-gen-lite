# 节点设置自动修复开关（SET NODEREPSWITCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**须知** 

I层虚拟机HA开关打开场景下，执行该命令打开Error节点故障自愈或Unknown节点故障自愈开关，可能会导致I层与网元故障自愈冲突，请谨慎使用。

本命令用于设置节点故障自愈开关状态。

**说明** 

该命令仅在Full-stack虚机场景下支持。

#### 注意事项

- 开启Error节点故障自愈或Unknown节点故障自愈开关，需要关闭I层虚拟机HA开关，否则可能会导致I层与网元的故障自愈冲突。

该命令存在系统初始记录，参数的初始设置值如下：

| 故障自愈开关   | Error节点自愈开关   | Unknown节点自愈开关   |
|:---------|:--------------|:----------------|
| 开启       | 关闭            | 关闭              |

#### 参数说明

| 参数标识                 | 参数名称          | 参数说明                                                                                                                                                |
|:---------------------|:--------------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| REPAIRSWITCH         | 故障自愈开关        | 可选必选说明：必选参数 参数含义：用于指示要设置的节点故障自愈开关状态。 取值范围：“ON(开启节点故障自愈)”“OFF(关闭节点故障自愈)” 默认值：“ON(开启节点故障自愈)”。 配置原则：关闭故障自愈开关会联动关闭Error节点自愈开关和Unknown节点自愈开关。            |
| REPERRORNODESWITCH   | Error节点自愈开关   | 可选必选说明：该参数在“REPAIRSWITCH”配置为“ON(开启节点故障自愈)”时为条件可选参数。 参数含义：用于指示要设置的Error节点故障自愈开关状态。 取值范围：“ON(开启Error节点故障自愈)”“OFF(关闭Error节点故障自愈)” 默认值：无。 配置原则：无。       |
| REPUNKNOWNNODESWITCH | Unknown节点自愈开关 | 可选必选说明：该参数在“REPAIRSWITCH”配置为“ON(开启节点故障自愈)”时为条件可选参数。 参数含义：用于指示要设置的Unknown节点故障自愈开关状态。 取值范围：“ON(开启Unknown节点故障自愈)”“OFF(关闭Unknown节点故障自愈)” 默认值：无。 配置原则：无。 |

#### 使用实例

1. 关闭节点故障自愈开关。

   ```
   %%SET NODEREPSWITCH: REPAIRSWITCH=OFF;%% 
   RETCODE = 0  操作成功  

   ---    END
   ```
2. 打开节点故障自愈开关，打开Error节点自愈开关，打开Unknown节点自愈开关。

   ```
   %%SET NODEREPSWITCH: REPAIRSWITCH=ON, REPERRORNODESWITCH=ON, REPUNKNOWNNODESWITCH=ON;%% 
   RETCODE = 0  操作成功  

   ---    END
   ```

#### 输出结果说明

命令执行正常，会返回命令执行成功的提示信息，表示成功修改故障自愈开关。

命令执行异常，会返回提示设置故障自愈开关状态失败。错误码列表如表1所示。

|    错误码 | 错误码解释     | 原因分析                      | 处理建议        |
|-------:|:----------|:--------------------------|:------------|
| 130001 | 没有符合条件的节点 | 所要查询的节点或者网元ID不存在，无相应配置信息。 | 请检查输入参数并重试。 |
| 130002 | 操作失败      | MML命令参数解析、校验失败。           | 请联系华为技术支持。  |
