# 创建OSPF协议路由的优先级配置（ADD OSPFPREFERENCE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于设置OSPF协议路由的优先级。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为32064。
- 只有在执行ADD OSPF配置了OSPF进程后才能使用此命令。
- 当前OSPF路由优先级的两种路由类型ASE和default不支持创建操作。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                                                    |
|:----------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROCID          | 进程号    | 可选必选说明：必选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 配置原则：OSPF进程必须已经存在。请使用LST OSPF命令查看可用的OSPF进程。                                                                      |
| TOPOID          | 拓扑标识   | 可选必选说明：可选参数 参数含义：拓扑标识。 数据来源：全网规划 取值范围：整数类型，取值范围为0。 默认值：0 配置原则：目前只支持默认拓扑0。                                                                                                               |
| ROUTETYPE       | 路由类型   | 可选必选说明：必选参数 参数含义：路由类型。 数据来源：本端规划 取值范围：枚举类型。 default：区域内和区域间路由。ase：AS-External路由。intra：区域内路由。inter：区域间路由。 默认值：无                                                                          |
| PREFERENCE      | 路由优先级  | 可选必选说明：可选参数 参数含义：路由优先级。 数据来源：本端规划 取值范围：整数类型，取值范围为1～255。 默认值：无 配置原则： 优先级的值越小，其实际的优先程度越高。PREFERENCE和ROUTEPOLICYNAME参数如果都不配置，则实际没有调整路由优先级。如果不输入该参数，则AS-External路由的优先级为150，其他OSPF路由的优先级为10。 |
| ROUTEPOLICYNAME | 路由策略名称 | 可选必选说明：可选参数 参数含义：路由策略名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无 配置原则： 不支持空格，区分大小写。PREFERENCE和ROUTEPOLICYNAME参数如果都不配置，则实际没有调整路由优先级。                                                    |

#### 使用实例

配置OSPF进程1的区域内路由的优先级为100：

```
ADD OSPFPREFERENCE:PROCID=1,TOPOID=0,ROUTETYPE=intra,PREFERENCE=100;
```
