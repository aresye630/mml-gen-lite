# 查询系统HA状态（DSP HASTAT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询系统RU的HA状态，HA（High Availability）是为对象存储服务提供高可靠性的模块。当系统进行灰度升级时，可以使用该命令确定RU的组件状态是否正常。灰度升级，需要确保所有组件状态正常。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                        |
|:----------------|:-------|:----------------------------------------------------------------------------------------------------------------------------|
| RUNAME          | RU名称   | 可选必选说明：可选参数 参数含义：该参数表示RU名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63，区分大小写。 默认值：无                                                   |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识，但不能填写0，0表示VNFP。 |

#### 使用实例

查询系统HA状态：

```
DSP HASTAT:SERVICEINSTANCE="vnfc";
```

```
RETCODE = 0  操作成功
 
结果如下:
 -------------------------
 RU ID = 1
RU名称 = VNODE_CSLB_VNFC_OMU_0001
HA状态 = 正常    
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                                      |
|:--------|:-------------------------------------------|
| RU ID   | 表示RU ID。                                   |
| RU名称    | 表示RU名称。                                    |
| HA状态    | 表示HA状态。 正常：RU状态正常； 异常：RU状态异常； 暂停：RU处于暂停状态。 |
