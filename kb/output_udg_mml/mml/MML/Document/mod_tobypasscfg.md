# 设置TCP旁路配置修改（MOD TOBYPASSCFG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于修改旁路Pod配置。

#### 注意事项

该命令执行后对新数据流生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                 |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------|
| PODNAME | Pod名称  | 可选必选说明：必选参数 参数含义：Pod名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：无                                   |
| MODE    | 旁路模式   | 可选必选说明：必选参数 参数含义：设置该Pod的Bypass模式。 数据来源：本端规划 取值范围：无。 mode1：所有的流量都不上送to pod。mode2：所有的流量都上送to pod，但是不上送内核。 默认值：无 配置原则：无 |

#### 使用实例

修改名称为“to-pod-0”的pod旁路模式为mode2模式：

```
MOD TOBYPASSCFG: PODNAME="to-pod-0", MODE=mode2;
```
