# 删除业务报表映射承载协议分类配置（RMV RPTPROTMPCLASS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于删除业务报表映射承载协议分类配置。当运营商希望删除业务报表映射承载协议分类配置，则配置该命令。

#### 注意事项

- 该命令执行后立即生效。
- 如果引用了该映射承载协议分类的映射记录存在，则不允许删除映射承载协议分类。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称       | 参数说明                                                                                            |
|:--------------|:-----------|:------------------------------------------------------------------------------------------------|
| MPPROTCLASSNM | 映射承载协议分类名称 | 可选必选说明：必选参数 参数含义：该参数用于设置映射承载协议分类名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

假如运营商需要删除名称为p2p的业务报表映射承载协议分类配置：

```
RMV RPTPROTMPCLASS: MPPROTCLASSNM="p2p";
```
