# 查询QoS重定向下一跳信息（LST QOSACTRDRNHP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询流行为重定向动作的相关配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称      | 参数说明                                                                                                                                                                                            |
|:-------------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| BEHAVIORNAME | 流行为名称     | 可选必选说明：可选参数 参数含义：该参数用于指定流行为名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：区分大小写，不支持空格。                                                                                                        |
| IFNAME       | 接口名称      | 可选必选说明：可选参数 参数含义：该参数用于指定出接口，指定了出接口，表示强策略路由。处理流程为不查FIB表，直接通过指定的下一跳与出接口进行转发。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：使用LST INTERFACE命令查看可用接口。                                                |
| VRFNAME      | VPN名称     | 可选必选说明：可选参数 参数含义：该参数用于指定出接口，如果配置下一跳IP+VPN，不指定出接口，表示弱策略路由，表示重定向到私网IP，处理流程为使用指定的下一跳和VPN去查私网FIB表，查找成功则根据查到的表项转发；否则再使用报文中的目的IP地址去查FIB表，查找成功则根据查到的表项转发；否则丢弃。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 |
| IPVERSION    | IP协议版本    | 可选必选说明：可选参数 参数含义：该参数用于指定下一跳为IPv4类型还是IPv6类型。 数据来源：本端规划 取值范围：枚举类型。 IPv4：IPv4类型。IPv6：IPv6类型。 默认值：无                                                                                                 |
| NEXTHOP      | 下一跳地址     | 可选必选说明：可选参数 参数含义：该参数用于指定下一跳IP，如果只配置下一跳IP，表示重定向到公网IP，处理流程为使用指定的下一跳去查公网FIB表，查找成功则根据查到的表项转发；否则再使用报文中的目的IP地址去查FIB表，查找成功则根据查到的表项转发；否则丢弃。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无                              |
| NEXTHOP6     | IPv6下一跳地址 | 可选必选说明：可选参数 参数含义：该参数用于指定下一跳IPv6，如果只配置下一跳IPv6，表示重定向到公网IPv6，处理流程为使用指定的下一跳去查公网FIB表，查找成功则根据查到的表项转发；否则再使用报文中的目的IPv6地址去查FIB表，查找成功则根据查到的表项转发；否则丢弃。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无                      |

#### 使用实例

查询所有流行为重定向动作：

```
LST QOSACTRDRNHP:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------

b6            NULL        NULL       IPv6         0.0.0.0          2001:db8::3
(结果个数 = 2)
---    END
```
