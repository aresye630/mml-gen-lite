# 清除IPv6 Path MTU配置（RTR IPV6PATHMTU）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于清除IPv6路径MTU。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                   |
|:--------|:-------|:-----------------------------------------------------------------------|
| VRFNAME | VPN名称  | 可选必选说明：可选参数 参数含义：该参数用于表示VPN名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 |

#### 使用实例

清除IPv6 Path MTU：

```
RTR IPV6PATHMTU:VRFNAME="vpn1";
```
