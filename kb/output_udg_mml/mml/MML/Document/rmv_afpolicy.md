# 删除防欺诈策略配置（RMV AFPOLICY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于删除判断出欺诈行为后的处理策略。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                             |
|:-------------|:--------|:-----------------------------------------------------------------------------------------------------------------|
| AFPOLICYTYPE | 防欺诈策略类型 | 可选必选说明：必选参数 参数含义：该参数用于指定防欺诈策略类型。 数据来源：本端规划 取值范围：枚举类型。 DNS：指定DNS防欺诈。HTTP：指定HTTP防欺诈。HTTPS：指定HTTPS防欺诈。 默认值：无 配置原则：无 |

#### 使用实例

如果运营商要删除在判断出DNS欺诈行为后处理策略，则配置命令如下：

```
RMV AFPOLICY:AFPOLICYTYPE=DNS;
```
