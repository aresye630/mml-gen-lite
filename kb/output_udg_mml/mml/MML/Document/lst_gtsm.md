# 查询GTSM全局配置属性（LST GTSM）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询GTSM全局属性。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询GTSM全局属性：

```
LST GTSM:;
```

```
        RETCODE = 0  操作成功

        结果如下
        -------------------------
        动作行为  =  通过
        (结果个数 = 1)
        ---    END
```
