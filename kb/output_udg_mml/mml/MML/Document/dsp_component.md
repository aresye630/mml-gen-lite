# 显示组件信息（DSP COMPONENT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示组件信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                                                                |
|:----------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| QUERYTYPE       | 查询类型   | 可选必选说明：必选参数。 参数含义：该参数用于指定查询类型。 数据来源：本端规划。 取值范围：枚举类型。 QUERYBYPROCID：根据进程ID查询组件信息。QUERYBYCOMPCID：根据组件ID查询组件信息。 默认值：QUERYBYPROCID                                                                      |
| PROCID          | 进程ID   | 可选必选说明：条件必选参数，该参数在“QUERYTYPE”配置为“QUERYBYPROCID”时为必选参数。 参数含义：该参数用于指定要查询组件所属进程的ID。 数据来源：本端规划。 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                                                      |
| COMPNAME        | 组件名    | 可选必选说明：条件可选参数，该参数在“QUERYTYPE”配置为“QUERYBYPROCID”时为可选参数。 参数含义：该参数用于指定要查询的组件名。 数据来源：本端规划。 取值范围：字符串类型，输入长度范围为1～31。不支持空格，区分大小写。 默认值：无                                                                    |
| COMPSTATE       | 状态     | 可选必选说明：条件可选参数，该参数在“QUERYTYPE”配置为“QUERYBYPROCID”时为可选参数。 参数含义：组件的主备状态。 数据来源：本端规划。 取值范围：枚举类型。 PRIMARY：主用组件。BACKUP：备用组件。FAILURE：组件运行失败。NOTBACKUP：批备未完成状态。NULL：组件不存在。INVALID：角色未定。COLDBACKUP：冷备组件。 默认值：无 |
| COMPCID         | 组件ID   | 可选必选说明：条件必选参数，该参数在“QUERYTYPE”配置为“QUERYBYCOMPCID”时为必选参数。 参数含义：该参数用于指定要查询的组件ID。 数据来源：本端规划。 取值范围：十六进制整数类型，取值范围为0x0～0xFFFFFFFF。 默认值：无                                                                   |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数。 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划。 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识，但不能填写0，0表示VNFP。                                                                       |

#### 输出结果说明

| 输出项名称      | 输出项解释                                                                           |
|:-----------|:--------------------------------------------------------------------------------|
| 组件名        | 用于说明组件的名称。                                                                      |
| 组件ID       | 用于说明组件的编号。                                                                      |
| 逻辑ID       | 用于说明组件的逻辑编号。                                                                    |
| RU名称       | 表示资源单元的名称。                                                                      |
| 进程ID       | 用于说明组件所在进程的进程ID。                                                                |
| 组件类型       | 用于说明组件的类型。                                                                      |
| 版本号        | 用于说明组件的版本号。                                                                     |
| 状态         | 用于说明组件的主备状态。 主：主用组件；备：备用组件；未定：角色未定；运行失败：组件运行失败；不存在：组件不存在；批备未完成：批备未完成状态；冷备：冷备组件。 |
| CPU使用率（%）  | 用于说明组件当前的CPU占用率，单位是%。                                                           |
| 内存使用大小（KB） | 用于说明组件当前的内存占用量，单位是KB。                                                           |
