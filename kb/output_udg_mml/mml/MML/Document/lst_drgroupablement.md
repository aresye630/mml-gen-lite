# 查询是否使能热备容灾组（LST DRGROUPABLEMENT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询是否使能热备容灾组。

## 注意事项

该命令适用于支持热备容灾的网元执行。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询是否使能热备容灾组:

```
%%LST DRGROUPABLEMENT:;%%
RETCODE = 0  操作成功

结果如下
--------
                    是否使能热备容灾组  =  去使能热备容灾功能
                          是否自动升主  =  是
运行备升为运行主所需的持续时间（分钟）  =  15
        配置不自动升主容忍时间（分钟）  =  60
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称               | 输出项解释                                                                 |
|:--------------------|:----------------------------------------------------------------------|
| 是否使能热备容灾组           | 该参数用于是否使能热备容灾组。                                                       |
| 是否自动升主              | 该参数用于配置在热备容灾模式首次协商持续失败场景下是否自动升为运行主状态。                                 |
| 运行备升为运行主所需的持续时间（分钟） | 该参数用于配置当参数“ISAUTOACTIVE”设置为“TRUE”后，持续多长时间可升为运行主状态。                    |
| 配置不自动升主容忍时间（分钟）     | 该参数用于配置当参数“ISAUTOACTIVE”设置为“FALSE”后，持续多长时间后上报“ALM-100686 自动升主配置错误”告警。 |
