# 设置是否使能热备容灾组（SET DRGROUPABLEMENT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置是否使能热备容灾组。

## 注意事项

- 该命令执行后立即生效。

- 该命令适用于支持热备容灾的网元执行。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| DRGROUPABLEMENT   | ISAUTOACTIVE   |   STBYTOACTTIME |   NOAUTOTIME |
|:------------------|:---------------|----------------:|-------------:|
| DISABLE           | True           |              15 |           60 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称                | 参数说明                                                                                                                                                                                                           |
|:----------------|:--------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DRGROUPABLEMENT | 是否使能热备容灾组           | 可选必选说明：必选参数  参数含义：该参数用于是否使能热备容灾组。  数据来源：全网规划 取值范围： ENABLE（使能热备容灾功能）DISABLE（去使能热备容灾功能）  默认值：无。  配置原则：无                                                                                                          |
| ISAUTOACTIVE    | 是否自动升主              | 可选必选说明：可选参数  参数含义：该参数用于配置在热备容灾模式首次协商持续失败场景下是否自动升为运行主状态。  数据来源：全网规划 取值范围： TRUE（是）FALSE（否）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST DRGROUPABLEMENT查询当前参数配置值。  配置原则：  热备容灾使能若配置为不自动升主，容灾控制通道异常时，通过SWAP DR命令强制升主。 |
| STBYTOACTTIME   | 运行备升为运行主所需的持续时间（分钟） | 可选必选说明：可选参数  参数含义：该参数用于配置当参数“ISAUTOACTIVE”设置为“TRUE”后，持续多长时间可升为运行主状态。  数据来源：本端规划  取值范围：整数类型，取值范围是1~120。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST DRGROUPABLEMENT查询当前参数配置值。  配置原则：无                              |
| NOAUTOTIME      | 配置不自动升主容忍时间（分钟）     | 可选必选说明：可选参数  参数含义：该参数用于配置当参数“ISAUTOACTIVE”设置为“FALSE”后，持续多长时间后上报“ALM-100686 自动升主配置错误”告警。  数据来源：本端规划  取值范围：整数类型，取值范围是0~65535。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST DRGROUPABLEMENT查询当前参数配置值。  配置原则：无         |

## 使用实例

使能热备容灾组:

```
%%SET DRGROUPABLEMENT: DRGROUPABLEMENT=ENABLE;%%
RETCODE = 0  操作成功

---    END
```
