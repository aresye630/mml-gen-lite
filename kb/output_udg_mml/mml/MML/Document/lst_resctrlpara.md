# 查询内部资源使用控制的参数。（LST RESCTRLPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF、SGW-U、PGW-U**

该命令用于查询内部资源使用控制的参数。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                        |
|:--------|:-------|:--------------------------------------------------------------------------------------------|
| RESTYPE | 资源类型   | 可选必选说明：可选参数 参数含义：该参数用于指定内部资源类型。 数据来源：本端规划 取值范围： OUTER_IPFRAG_REASS：该参数仅用于NP场景。 默认值：无 配置原则：无 |

#### 使用实例

查询当前内部资源使用控制的参数：

```
LST RESCTRLPARA:;
```

#### 输出结果说明

参见SET RESCTRLPARA的参数说明。
