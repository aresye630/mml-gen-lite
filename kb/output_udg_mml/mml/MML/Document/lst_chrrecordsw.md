#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

用来查询当前的CHR本地存盘开关。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询CHRRECORDSW内容：

```
LST CHRRECORDSW:;
```
