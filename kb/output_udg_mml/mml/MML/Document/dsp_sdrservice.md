# 显示SDRC中的Service信息（DSP SDRSERVICE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询SDRC中指定APP的Service信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                 |
|:--------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------|
| APPTYPE | App类型  | 可选必选说明：必选参数  参数含义：该参数用于表示业务类型，可通过DSP SDRPOLICYKEYS: POLICYTYPE=Service;命令获取。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无 |

## 使用实例

使用如下命令查询SDRC中缓存的服务实例信息：

```
%%DSP SDRSERVICE: APPTYPE=2001;%%
RETCODE = 0  操作成功

结果如下
--------
实例 ID                POD ID                  容器 ID                       进程号  进程 ID                          

13358201890078505928  vup-pod-010-107-0-165  vup-pod-010-107-0-165__121  0       vup-pod-010-107-0-165__121__0
13358201890079338002  vup-pod-110-107-1-11   vup-pod-110-107-1-11__121   0       vup-pod-110-107-1-11__121__0
```

## 输出结果说明

| 输出项名称   | 输出项解释               |
|:--------|:--------------------|
| 实例ID    | 该参数用于标识该实例的ID，全局唯一。 |
| POD ID  | 该参数用于标识该实例所在POD的ID。 |
| 容器ID    | 该参数用于标识实例所在容器的ID。   |
| 进程号     | 该参数用于标识实例对应的进程号。    |
| 进程ID    | 该参数用于标识实例对应的进程ID。   |
