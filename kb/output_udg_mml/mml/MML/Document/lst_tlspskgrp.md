# 查询预共享密钥组（LST TLSPSKGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询预共享密钥组信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                    |
|:----------|:---------|:----------------------------------------------------------------------------------------|
| PSKGRPIDX | 预共享密钥组索引 | 可选必选说明：可选参数  参数含义：该参数用于指定TLS预共享密钥组的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~128。  默认值：无  配置原则：无 |

## 使用实例

- 需要查询组索引为1的TLS预共享密钥组信息，可执行如下命令：

  ```
  %%LST TLSPSKGRP: PSKGRPIDX=1;%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
            预共享密钥组索引  =  1
                        描述  =  NULL
  (结果个数 = 1)

  ---    END
  ```
- 需要查询所有的TLS预共享密钥组信息，可执行如下命令：

  ```
  %%LST TLSPSKGRP:;%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
            预共享密钥组索引  =  1
                        描述  =  NULL
  (结果个数 = 1)

  ---    END
  ```

## 输出结果说明

| 输出项名称    | 输出项解释                |
|:---------|:---------------------|
| 预共享密钥组索引 | 该参数用于指定TLS预共享密钥组的索引。 |
| 描述       | 该参数用于指定TLS预共享密钥组的描述。 |
