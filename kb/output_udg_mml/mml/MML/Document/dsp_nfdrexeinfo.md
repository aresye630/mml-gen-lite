# 显示网元级KPI异常检测与容灾功能的容灾失败原因（DSP NFDREXEINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示网元级KPI异常检测与容灾功能的容灾失败原因。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询网元级KPI异常检测与容灾功能的容灾失败原因。

```
%%DSP NFDREXEINFO:;%%
RETCODE = 0  操作成功

结果如下
--------
容灾失败原因  =  容灾执行失败
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                                                                                                                                                              |
|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 容灾失败原因  | 该参数用于表示网元级KPI异常检测与容灾功能容灾失败原因。 取值说明： NULL（无）REFNOTALLOW（周边网元状态正常的数目不满足正常比例）REMAINCAPNOTREPORT（周边网元数目与上报剩余容量的网元数目不一致）CPUINSUFFICIENT（周边网元CPU剩余容量不足）LICENSEINSUFFICIENT（周边网元license剩余容量不足）REMAINCAPINSUFFICIENT（周边网元CPU和license剩余容量均不足）MANUAL（配置为人工倒换）EXEFAIL（容灾执行失败） |
