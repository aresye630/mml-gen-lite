# 删除DCS批量视频资源（RMV DCSBATCHVIDEO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令用于删除DCS批量视频资源，资源删除后需要重新缓存，会对业务造成较大影响，请谨慎使用该命令。

该命令用于删除DCS批量视频资源。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                    |
|:----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------|
| OTTNAME   | OTT名称  | 可选必选说明：必选参数  参数含义：该参数用于表示OTT名称，OTT名称由OTT厂商提供，可通过执行LST RELAYDOMAIN命令，获取查询结果中的“媒体中继模板名称”。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~256。  默认值：无  配置原则：无             |
| VIDEOTYPE | 视频类型   | 可选必选说明：可选参数  参数含义：该参数用于表示视频的类型。  数据来源：本端规划 取值范围： VIDEO_TYPE_LIVE（直播视频）VIDEO_TYPE_VOD（点播视频）VIDEO_TYPE_ALL（所有视频）  默认值：VIDEO_TYPE_VOD  配置原则：  当前只支持配置点播视频。 |
| RMVTYPE   | 删除类型   | 可选必选说明：可选参数  参数含义：该参数用于表示批量删除的视频类型。  数据来源：本端规划 取值范围： VIDEODIR（视频目录）  默认值：VIDEODIR  配置原则：无                                                               |
| RMVPARAM  | 删除参数   | 可选必选说明：必选参数  参数含义：该参数用于表示批量删除的视频参数。例如：当删除类型为视频目录时，该参数可以从视频文件的URL名称中获取。URL名称由OTT厂商提供。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~1024。  默认值：无  配置原则：无               |

## 使用实例

删除OTT名称为“douyin”，视频类型为“点播视频”，删除类型为“视频目录”，删除参数为“aaa.douyincdn.com/fantasy/”的批量视频资源。

```
%%RMV DCSBATCHVIDEO: OTTNAME="douyin",VIDEOTYPE="VIDEO_TYPE_VOD",RMVTYPE:="VIDEODIR",RMVPARAM="aaa.douyincdn.com/fantasy/";%%
RETCODE = 0  操作成功

结果如下
------------------------
Task No.  =  2
(结果个数 = 1)

---    END
```
