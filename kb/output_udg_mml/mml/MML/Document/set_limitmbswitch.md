# 设置有界邮箱开关（SET LIMITMBSWITCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置SDRC有界邮箱开关，默认开启，表示SDRC将使用有界邮箱功能。

## 注意事项

- 该命令执行后需要重新启动系统才能生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| SWITCH   |
|:---------|
| ON       |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                       |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------|
| SWITCH | 有界邮箱开关 | 可选必选说明：必选参数  参数含义：有界邮箱开关，ON表示sdrc将使用有界邮箱功能，OFF表示sdrc使用无界邮箱。  数据来源：本端规划 取值范围： ON（开启）OFF（关闭）  默认值：无。  配置原则：无 |

## 使用实例

开启有界邮箱功能

```
*MEID:0 MENAME:*/        2021-01-19 09:56:57+8:00
O&M    #55
%%SET LIMITMBSWITCH: SWITCH=ON;%%
RETCODE = 0  操作成功

---    结束
```
