# 设置正常状态网元的占比阈值（SET MONNFTHR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于配置与当前网元具有容灾关系的其他网元中，状态正常的网元数目在所有网元数目的占比阈值。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| REFNBRVNF   |   NFNORMALTHR |
|:------------|--------------:|
| True        |           100 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称          | 参数说明                                                                                                                                                                    |
|:------------|:--------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| REFNBRVNF   | 是否参考周边网元状态    | 可选必选说明：可选参数  参数含义：该参数用于指定容灾决策是否参考周边网元状态。  数据来源：本端规划 取值范围： “TRUE（是）”：参考周边网元状态“FALSE（否）”：不参考周边网元状态  默认值：TRUE。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST MONNFTHR查询当前参数配置值。  配置原则：无 |
| NFNORMALTHR | 正常状态网元占比阈值（%） | 可选必选说明：可选参数  参数含义：当前网元具有容灾关系的其他网元中，状态正常的网元数目在所有网元数目的占比阈值。  数据来源：全网规划  取值范围：整数类型，取值范围是1~100，单位是百分比。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST MONNFTHR查询当前参数配置值。  配置原则：无  |

## 使用实例

设置容灾决策参考周边网元状态，正常状态网元的占比阈值为100%。

```
%%SET MONNFTHR: REFNBRVNF=TRUE, NFNORMALTHR=100;%%
RETCODE = 0  操作成功

---    END
```
