# 设置HTTP染色配置（SET HTTPLINKDSCP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置HTTP TCP头中的DSCP字段的染色配置。

## 注意事项

- 该命令执行后立即生效。

- 该命令只支持设置已存在的INDEX染色配置，可通过LST HTTPLINKDSCP查询 。若需要设置一条源端口号和目的端口号为空的HTTP染色配置，源端口号和目的端口号必须同时配置，或同时为空。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

若需要设置索引为1的HTTP染色配置，修改为IP类型为IPv4，源地址为255.255.255.255，目的地址为192.168.0.0，标记指定报文的DSCP值为1，可以用如下命令：

```
SET HTTPLINKDSCP: INDEX=1, IPVERSION=IPv4, SIPV4="255.255.255.255", DIPV4="192.168.0.0", DSCPVALUE=1;
```
