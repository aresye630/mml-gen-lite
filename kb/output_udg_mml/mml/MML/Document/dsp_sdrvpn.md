# 查询SDRC中的VPN信息（DSP SDRVPN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询SDRC中的VPN信息，若命令不接任何参数，则该命令列出SDRC中所有VPN的信息，否则显示特定的VPN信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                 |
|:--------|:-------|:-------------------------------------------------------------------------------------|
| VPNNAME | VPN名称  | 可选必选说明：可选参数  参数含义：该参数用于表示vpn的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无 |

## 使用实例

显示SDRC中VPNNAME等于\_public\_的VPN信息

```
%%DSP SDRVPN:;%%
RETCODE = 0  操作成功

结果如下
--------
VPN 名称  =  _public_
 SDR ID  =  1
 下行经过LB  =  是
VPN拓扑  =  instance_id:281492156580961 low_tb:1121 tp:2416123937  instance_id:281492156580949 low_tb:1109 tp:2416123937
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                             |
|:--------|:--------------------------------------------------|
| VPN名称   | 该参数用于表示vpn的名称。                                    |
| SDR ID  | 该参数用于表示SDRC给该VPN分配的ID。                            |
| 下行经过LB  | 该参数用于表示该VPN是否关联CSLB。 取值说明： TRUE(TRUE)FALSE(FALSE) |
| VPN拓扑   | 该参数用于表示该VPN的TOPO信息。                               |
