# 配置超时时间（SET SCFMVNFMLNK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置VNFM-VNF之间同步消息超时时间。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

|   LNKTIME |
|----------:|
|       180 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                                                           |
|:--------|:---------|:-------------------------------------------------------------------------------------------------------------------------------|
| LNKTIME | 同步消息超时时间 | 可选必选说明：必选参数  参数含义：该参数用于表示VNFM-VNF之间同步消息的最大等候时间。  数据来源：本端规划  取值范围：整数类型，取值范围是180~600，单位是秒。180 <= LNKTIME <= 600。  默认值：无。  配置原则：无 |

## 使用实例

设置最大等候时间为180秒。

```
%%SET SCFMVNFMLNK: LNKTIME=180;%%
```
