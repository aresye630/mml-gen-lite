# 修改ACL（MOD ACL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

**须知** 

本命令属于高危命令，操作不当会导致性能下降明显，请谨慎使用并联系华为技术支持协助操作。

该命令用于修改ACL节点的匹配方式，当需要改变ACL下ACL节点的匹配方式时，可以使用此命令。

#### 注意事项

- 修改的ACL必须是已配置的。
- ACL没有绑定ACL节点时，可以修改ACL的匹配方式，绑定了ACL节点后，则不允许修改。
- Acl配置修改后，在执行SET REFRESHSRV命令30s后生效。建议该操作在对所有ACL的配置修改完成后执行。
- 操作不当会导致性能下降明显，请谨慎使用并联系华为技术支持协助操作。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                     |
|:--------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ACLNAME       | ACL名称  | 可选必选说明：必选参数 参数含义：该参数用于指定ACL名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                               |
| MATCHORDER    | 匹配方式   | 可选必选说明：必选参数 参数含义：该参数用于设置ACL节点的匹配方式。 数据来源：本端规划 取值范围：枚举类型。 AUTO：自动排序，即按照filter深度优先。CONFIG：按照ACL节点的优先级排序。 默认值：无 配置原则： 该参数配置为AUTO时，不能指定ACL下绑定的ACL节点的优先级。该参数配置为CONFIG时，必须指定改ACL下绑定的ACL节点的优先级。 |
| CFGDOMAINNAME | 配置域名称  | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。                                                                                       |

#### 使用实例

假如运营商需要将ACL下ACL节点的匹配方式由原来的AUTO改为CONFIG时，需要使用此命令，且该ACL下未绑定ACL节点：

```
MOD ACL: ACLNAME="testacl1",MATCHORDER=CONFIG;
```
