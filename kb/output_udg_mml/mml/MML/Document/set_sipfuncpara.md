# 设置SIP信令代理功能参数（SET SIPFUNCPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于设置SIP信令代理功能参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | SWITCH   |   EXPIRES | ISIPCODE   | MSIPCODE   |
|:-------|:---------|----------:|:-----------|:-----------|
| 初始值    | DISABLE  |         0 | SIP486     | SIP486     |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称       | 参数说明                                                                                                                                                                              |
|:---------|:-----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SWITCH   | 功能开关       | 可选必选说明：必选参数 参数含义：该参数用于开启SIP信令代理功能。 数据来源：本端规划 取值范围： DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无                                                                                            |
| EXPIRES  | 注册时长       | 可选必选说明：条件可选参数 前提条件：该参数在“SWITCH”配置为“ENABLE”时为可选参数。 参数含义：该参数用于指定注册时长值。 数据来源：本端规划 取值范围：设置为0时表示注册时长为3600秒。 默认值：无 配置原则：无                                                               |
| ISIPCODE | 呼叫SIP状态码   | 可选必选说明：条件可选参数 前提条件：该参数在“SWITCH”配置为“ENABLE”时为可选参数。 参数含义：该参数用于指定呼叫失败的SIP状态码。 数据来源：本端规划 取值范围： SIP486：SIP状态码486(被叫忙)。SIP603：SIP状态码603(请求拒绝)。SIP503：SIP状态码503(服务不可用)。 默认值：无 配置原则：无     |
| MSIPCODE | 短消息SIP状态码  | 可选必选说明：条件可选参数 前提条件：该参数在“SWITCH”配置为“ENABLE”时为可选参数。 参数含义：该参数用于指定短消息失败的SIP状态码。 数据来源：本端规划 取值范围： SIP486：SIP状态码486(被叫忙)。SIP603：SIP状态码603(请求拒绝)。SIP503：SIP状态码503(服务不可用)。 默认值：无 配置原则：无    |
| IMPUSIP  | IMPU SIP格式 | 可选必选说明：条件必选参数 前提条件：该参数在“SWITCH”配置为“ENABLE”时为必选参数。 参数含义：该参数用于指定要添加的IMPU的值，SIP URI格式。 数据来源：本端规划 取值范围：以“sip:”开头，格式：sip:+<MSISDN>@ims.mnc<mnc>.mcc<mcc>.3gppnetwork.org。 默认值：无 配置原则：无 |
| IMPUTEL  | IMPU TEL格式 | 可选必选说明：条件必选参数 前提条件：该参数在“SWITCH”配置为“ENABLE”时为必选参数。 参数含义：该参数用于指定要添加的IMPU的值，TEL URI格式。 数据来源：本端规划 取值范围：以“tel:”开头，格式：tel:+<MSISDN>。 默认值：无 配置原则：无                                       |

#### 使用实例

开启SIP信令代理功能，设置“注册时长”为“3600”，“呼叫SIP状态码”为“SIP状态码486”，“短消息SIP状态码”为“SIP状态码603”，“IMPU SIP格式”为“sip:+8612341234567@ims.mnc000.mcc460.3gppnetwork.org”，“IMPU TEL格式”为“tel:+8612341234567”：

```
SET SIPFUNCPARA: SWITCH=ENABLE, EXPIRES=3600, ISIPCODE=SIP486, MSIPCODE=SIP603, IMPUSIP="sip:+8612341234567@ims.mnc000.mcc460.3gppnetwork.org", IMPUTEL="tel:+8612341234567";
```
