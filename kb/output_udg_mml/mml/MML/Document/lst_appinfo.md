# 查询应用信息(LST APPINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询网元的实例信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询UDG网元的应用实例信息：

```
%%LST APPINFO:;%%
RETCODE = 0  操作成功

操作结果如下：
--------------
      网元ID  =  0
    网元类型  =  UDG
    应用名称  =  UDG
    应用版本  =  22.1.0.B220
应用补丁版本  =  NULL
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回操作成功的提示信息和相关参数，各参数含义请参见表1所示。

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

| 输出项名称   | 输出项解释                                    |
|:--------|:-----------------------------------------|
| 网元ID    | 网元的ID信息。                                 |
| 网元类型    | 网元类型。                                    |
| 应用名称    | 应用名称。                                    |
| 应用版本    | 应用版本号。                                   |
| 应用补丁版本  | 应用补丁版本号，用于表示应用的补丁版本。如果该应用没有安装补丁，则显示NULL。 |

|    错误码 | 错误码解释   | 原因分析           | 处理建议         |
|-------:|:--------|:---------------|:-------------|
| 112004 | 内部错误    | 升级工具处理MML命令异常。 | 请联系华为技术支持处理。 |
