# 删除媒体中继模板（RMV RELAYTEMPLATE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，删除该配置后，会导致媒体中继业务中断

该命令用于删除一组媒体中继模板。

#### 注意事项

- 该命令执行后立即生效。
- 如果基于模板绑定了媒体中继URL检查规则（RELAYURLCHK），删除模板会自动删除与此模板关联的媒体中继URL检查规则。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                          |
|:-------------|:---------|:----------------------------------------------------------------------------------------------|
| RELAYTPLNAME | 媒体中继模板名称 | 可选必选说明：必选参数 参数含义：该参数用来指定媒体中继模板名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

如果要删除一组媒体中继模板，则配置命令如下：

```
RMV RELAYTEMPLATE:RELAYTPLNAME="test";
```
