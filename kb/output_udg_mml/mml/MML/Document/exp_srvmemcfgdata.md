# 导出微服务内存配置数据(EXP SRVMEMCFGDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

通过本命令可以导出微服务内存配置数据。

## 注意事项

- 本命令执行过程中，若存在配置变更，则导出的数据仅以导出时获取数据为准。
- ACS侧存在导出时间限制，超出10min还未导出完毕，则报超时错误。
- 本命令导出的文件存放位置：“系统 > 文件传输 > ACS文件”。导出文件名称由网元ID、服务名称、实例ID组成。举例：网元ID\_服务名称\_实例ID\_export.zip。
- 本命令导出的单个数据文件不可大于4G。
- 本命令导出数据文件最多只能同时存在10个，累计大小不可超过20G。若超过该限制命令会报48036错误，需要清除现有数据文件后再重试。
- 本命令执行过程中不可重复执行，需等待进度响应结束后再次执行。

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                            |
|:------------|:---------|:------------------------------------------------------------------------------------------------|
| SERVICENAME | 服务名称     | 可选必选说明：必选参数。 参数含义：用于指定需要导出配置数据的微服务的服务名称。 取值范围：长度1~255的字符串。 默认值：无。 配置原则：可以使用DSP ACSSYNCINFO命令查询。 |
| INSTANCEID  | 实例ID     | 可选必选说明：必选参数。 参数含义：用于指定需要导出配置数据的微服务实例ID。 取值范围：长度1~255的字符。 默认值：无。 配置原则：可以使用DSP ACSSYNCINFO命令查询。   |
| OBJECTNAME  | 对象名称     | 可选必选说明：可选参数。 参数含义：配置对象名称。 取值范围：长度范围1~16的字符串。 默认值：无。 配置原则：若不输入，则表示导出服务实例所有支持导出的对象的数据。            |
| FILESIZE    | 文件大小（MB） | 可选必选说明：可选参数。 参数含义：导出的单表文件最大限制，单位为MB。 取值范围：1~500。 默认值：300。 配置原则：无。                               |

## 使用实例

导出“服务名称”为“TestCForCM”，“实例ID”为“cmimage2-500-pod-79d9db695c-b6zgh172-16-1-1086\_\_cType”，“对象名称”为“TsdkTypeInner”的内存配置数据。

```
EXP SRVMEMCFGDATA: SERVICENAME="TestCForCM", INSTANCEID="cmimage2-500-pod-79d9db695c-b6zgh172-16-1-1086__cType", OBJECTNAME="TsdkTypeInner";
```
