# 增加组播组成员配置（ADD MCASTGRPMEM）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于增加静态组播组内成员。

#### 注意事项

- 该命令执行后立即生效。
- 该静态组播组必须在MulticastGrp记录里存在。
- 单个静态组播组最多添加64个IMSI、32个双发选收结对、8个VTEP或者1个以太PDN。
- IMSI绑定到静态组播组时，如果该IMSI和静态组播组绑定的双发选收结对中的IMSI重复，则绑定失败。
- 双发选收结对绑定到静态组播组时，如果双发选收结对中的IMSI和静态组播组中绑定的IMSI重复，绑定失败。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称        | 参数说明                                                                                                                                                                                                              |
|:-------------|:------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MCASTGRPNAME | 组播组名称       | 可选必选说明：必选参数 参数含义：该参数用于配置组播组的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63，区分大小写。 默认值：无 配置原则：该参数使用ADD MULTICASTGRP命令配置生成。并且要先在ADD NGBINDMCASTGRP中和5G LAN实例绑定。                                                               |
| MEMTYPE      | 成员类型        | 可选必选说明：可选参数 参数含义：该参数用于配置成员类型。 数据来源：本端规划 取值范围：枚举类型。 IMSI：IMSI。VTEP：VTEP。DFSRPAIR：双发选收结对。ETHERNETPDN：以太PDN。 默认值：IMSI 配置原则：增加静态组播组成员时，成员类型参数不可为空；当VN组为层二直出场景，且需要添加N6侧成员时，将此参数配置为ETHERNETPDN。                         |
| IMSI         | IMSI        | 可选必选说明：条件必选参数 前提条件：该参数在“MEMTYPE”配置为“IMSI”时为必选参数。 参数含义：组播组成员IMSI。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～15，每个字符必须为0~9的数字。 默认值：无 配置原则：无                                                                                     |
| VTEPNAME     | VXLAN隧道端点名称 | 可选必选说明：条件必选参数 前提条件：该参数在“MEMTYPE”配置为“VTEP”时为必选参数。 参数含义：该参数用于配置VXLAN隧道端点名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不区分大小写，不支持空格。 默认值：无 配置原则：该参数使用ADD VTEP命令配置生成。并且要先在ADD NGVNBINDVXLAN中将组播组所关联的5G LAN实例和本VTEP所属的VXLAN组绑定。 |
| DFSRPAIRID   | 双发选收结对ID    | 可选必选说明：条件必选参数 前提条件：该参数在“MEMTYPE”配置为“DFSRPAIR”时为必选参数。 参数含义：该参数用于配置双发选收结对ID。 数据来源：本端规划 取值范围：整数类型，取值范围为1～2048。 默认值：无 配置原则：该参数使用ADD DFSRPAIR命令配置生成。                                                                   |

#### 使用实例

增加静态组播组成员配置：

```
ADD MCASTGRPMEM: MCASTGRPNAME="group1", MEMTYPE=IMSI, IMSI="217456789012353";
```
