# 查询负荷分担容灾功能开启信息（LST DRCOUPLINGRESET）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询负荷分担容灾功能开启信息。

## 注意事项

该命令适用于支持负荷分担容灾的网元执行。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询负荷分担容灾功能开启信息：

```
%%LST DRCOUPLINGRESET:;%%
RETCODE = 0  操作成功

结果如下
--------
是否使能负荷分担容灾功能 =  否
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称        | 输出项解释              |
|:-------------|:-------------------|
| 是否使能负荷分担容灾功能 | 该参数用于是否使能负荷分担容灾功能。 |
