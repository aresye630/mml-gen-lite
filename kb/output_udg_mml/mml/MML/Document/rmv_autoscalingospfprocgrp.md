# 删除OSPF进程组自动化配置模板（RMV AUTOSCALINGOSPFPROCGRP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除OSPF进程组自动化配置模板。

#### 注意事项

- 该命令执行后立即生效。
- 删除该模板时，要保证该模板添加过，且没有被引用。
- 该命令在自动化配置开关为关闭的状态下才能执行，请先使用SET AUTOCONFIG命令关闭自动配置开关。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                             |
|:--------|:----------|:-------------------------------------------------------------------------------------------------|
| GROUPID | OSPF进程组ID | 可选必选说明：必选参数 参数含义：该参数用于指定OSPF进程组ID。 数据来源：本端规划 取值范围：整数类型，取值范围为1～16。 默认值：无                          |
| VERSION | OSPF版本号   | 可选必选说明：必选参数 参数含义：该参数用来表示自动化配置模板中OSPF版本号。 数据来源：本端规划 取值范围：枚举类型。 OSPFv2：OSPFv2。OSPFv3：OSPFv3。 默认值：无 |

#### 使用实例

删除一个OSPF进程组ID为1的自动化配置模板：

```
RMV AUTOSCALINGOSPFPROCGRP:GROUPID=1,VERSION=OSPFv2;
```
