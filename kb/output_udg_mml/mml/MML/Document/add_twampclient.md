# 增加TWAMP客户端（ADD TWAMPCLIENT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于增加TWAMP客户端。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入12000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                         |
|:--------------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CLIENTID      | 客户端ID    | 可选必选说明：必选参数  参数含义：该参数用于配置客户端ID。  数据来源：全网规划  取值范围：整数类型，取值范围是1~12000。  默认值：无  配置原则：无                                                                                                                                                                                                                                                           |
| TWAMPARCH     | TWAMP架构  | 可选必选说明：必选参数  参数含义：该参数用于指定TWAMP架构。  数据来源：全网规划 取值范围： LIGHT（LIGHT）  默认值：无  配置原则：无                                                                                                                                                                                                                                                               |
| AFTYPE        | 地址族类型    | 可选必选说明：必选参数  参数含义：该参数用于用户指定地址族类型。  数据来源：全网规划 取值范围： IPV4（IPV4）  默认值：无  配置原则：无                                                                                                                                                                                                                                                                 |
| LOCALIPV4     | 本端IPV4地址 | 可选必选说明：该参数在"AFTYPE"配置为"IPV4"时为条件必选参数。  参数含义：该参数用于指示本端IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。0.0.0.0～255.255.255.255。  默认值：无  配置原则：  采用点分十进制"X.X.X.X"格式。  IP地址必须是A、B或者C类地址，不能为环回地址（127.x.y.z）、组播地址（240.x.y.z）或（255.0.0.0）。  LOCALIPV4必须在ADD TWAMPLOGICINF已经配置，可以用LST TWAMPLOGICINF查询。  LOCALIPV4不能已在ADD TWAMPRESPONDER中配置，可以用LST TWAMPRESPONDER查询。 |
| PEERIPV4      | 对端IPV4地址 | 可选必选说明：该参数在"AFTYPE"配置为"IPV4"时为条件必选参数。  参数含义：该参数用于指示对端IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。0.0.0.0～255.255.255.255。  默认值：无  配置原则：  采用点分十进制"X.X.X.X"格式。  IP地址必须是A、B或者C类地址，不能为环回地址（127.x.y.z）、组播地址（240.x.y.z）或（255.0.0.0）。                                                                                                                         |
| LLOCALUDPPORT | 本端UDP端口  | 可选必选说明：该参数在"TWAMPARCH"配置为"LIGHT"时为条件必选参数。  参数含义：该参数用于配置本端UDP端口。  数据来源：全网规划  取值范围：整数类型，取值范围是65450~65530。  默认值：无  配置原则：无                                                                                                                                                                                                                       |
| LPEERUDPPORT  | 对端UDP端口  | 可选必选说明：该参数在"TWAMPARCH"配置为"LIGHT"时为条件必选参数。  参数含义：该参数用于配置对端UDP端口。  数据来源：全网规划  取值范围：整数类型，取值范围是1~65535。  默认值：无  配置原则：无                                                                                                                                                                                                                           |
| DSCP          | 差分服务码    | 可选必选说明：可选参数  参数含义：该参数用于配置差分服务码。  数据来源：全网规划  取值范围：整数类型，取值范围是0~63。  默认值：0  配置原则：无                                                                                                                                                                                                                                                              |
| VRFNAME       | VPN实例名称  | 可选必选说明：可选参数  参数含义：该参数用于配置VPN实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~31。  默认值：无  配置原则：  VRFNAME必须和关联的本地逻辑接口配置中的VRFNAME相同，本地逻辑接口配置中的VRFNAME可使用。                                                                                                                                                                                                  |
| DESCRIPTION   | 描述       | 可选必选说明：可选参数  参数含义：该参数用于配置描述。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~31。  默认值：无  配置原则：无                                                                                                                                                                                                                                                              |

## 使用实例

增加客户端ID为1的实例：

```
ADD TWAMPCLIENT: CLIENTID=1, TWAMPARCH=LIGHT, AFTYPE=IPV4, LOCALIPV4="10.0.0.0", PEERIPV4="192.168.0.0", LLOCALUDPPORT=65450, LPEERUDPPORT=1, VRFNAME="ck", DESCRIPTION="1";
```
