# 设置冗余策略老化开关（SET PLCYCLSWITCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置冗余策略老化开关。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| SWITCH   |   AGINGTIMES |
|:---------|-------------:|
| ON       |           60 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                                   |
|:-----------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SWITCH     | 冗余策略老化开关 | 可选必选说明：必选参数  参数含义：该参数用于指示是否开启冗余策略老化。  数据来源：本端规划 取值范围： OFF（关闭）ON（打开）  默认值：无。  配置原则：无                                                                                                    |
| AGINGTIMES | 老化阈值     | 可选必选说明：该参数在"SWITCH"配置为"ON"时为条件必选参数。  参数含义：该参数用于设置老化阈值，单位：次数。  数据来源：本端规划  取值范围：整数类型，取值范围是3~9223372036854775807。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST PLCYCLSWITCH查询当前参数配置值。  配置原则：无 |

## 使用实例

设置冗余策略老化开关，ON表示开启，OFF表示关闭。

```
%%SET PLCYCLSWITCH: SWITCH=OFF;%%
RETCODE = 0  操作成功

---    结束
```
