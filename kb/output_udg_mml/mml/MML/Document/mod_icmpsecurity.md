# 修改ICMP安全配置（MOD ICMPSECURITY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改ICMP安全配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|:-----------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ACTION     | 报文方向     | 可选必选说明：必选参数 参数含义：该参数表示ICMP安全配置生效的方向。 数据来源：本端规划 取值范围：枚举类型。 rcvPkt：接收报文。sndPkt：发送报文。 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| SWITCHOP   | ICMP配置开关 | 可选必选说明：必选参数 参数含义：该参数表示使能或去使能对应ICMP报文的处理能力。 数据来源：本端规划 取值范围：枚举类型。 disable：去使能。enable：使能。 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| CONFIGTYPE | ICMP配置类型 | 可选必选说明：必选参数 参数含义：该参数表示对ICMP安全配置的配置方式。 数据来源：本端规划 取值范围：枚举类型。 USER：用户自定义。PKTTYPE：报文类型。 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| PKTTYPE    | ICMP报文类型 | 可选必选说明：条件必选参数 前提条件：该参数在“CONFIGTYPE”配置为“PKTTYPE”时为必选参数。 参数含义：该参数表示创建ICMP安全配置的名称。 数据来源：本端规划 取值范围：枚举类型。 echo：回显请求（Type=8, Code=0）。echo_reply：ICMP回显应答报文的设置（Type=0, Code=0）。fragmentneed_dfset：需要分片但设置了不分片标志（Type=3, Code=4）。host_redirect：主机重定向（Type=5, Code=1）。host_tos_redirect：主机TOS重定向（Type=5, Code=3）。host_unreachable：主机不可达（Type=3, Code=1）。information_reply：信息应答（Type=16, Code=0）。information_request：信息请求（Type=15, Code=0）。net_redirect：对网络重定向（Type=5, Code=0）。net_tos_redirect：网络TOS重定向（Type=5, Code=2）。net_unreachable：网络不可达（Type=3, Code=0）。parameter_problem：参数问题（Type=12, Code=0）。port_unreachable：端口不可达（Type=3, Code=3）。protocol_unreachable：协议不可达（Type=3, Code=2）。reassembly_timeout：分片重组超时（Type=11, Code=1）。source_quench：源抑制报文（Type=4, Code=0）。source_route_failed：源路由失败（Type=3, Code=5）。timestamp_reply：时间戳应答（Type=14, Code=0）。timestamp_request：时间戳请求（Type=13, Code=0）。ttl_exceeded：TTL超时（Type=11, Code=0）。 默认值：无 |
| ICMPTYPE   | 类型       | 可选必选说明：条件必选参数 前提条件：该参数在“CONFIGTYPE”配置为“USER”时为必选参数。 参数含义：该参数表示ICMP安全配置的类型值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～255。 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ICMPCODE   | 编码       | 可选必选说明：条件必选参数 前提条件：该参数在“CONFIGTYPE”配置为“USER”时为必选参数。 参数含义：该参数表示ICMP安全配置的消息码值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～255。 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |

#### 使用实例

修改系统发送ICMP Echo报文功能的ICMP安全配置实例：

```
MOD ICMPSECURITY: ACTION=sndPkt, CONFIGTYPE=PKTTYPE, PKTTYPE=echo, SWITCHOP=enable;
```
