# 查询特性开关（LST FEATURESWITCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询网元的特性开关。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                   |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------|
| NAME   | 名称     | 可选必选说明：可选参数  参数含义：该参数表示特性功能的名称。  数据来源：本端规划 取值范围： VMPODINCONSISTENCYALARM（VM POD关系不一致告警）  默认值：无  配置原则：无 |

## 使用实例

当运营商需要查询特性开关的状态，可使用该命令进行查询。

```
%%LST FEATURESWITCH:;%%
RETCODE = 0  操作成功

结果如下
--------
名称  =  VM POD关系不一致告警
状态  =  开启
备注  =  NULL
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释             |
|:--------|:------------------|
| 名称      | 该参数表示特性功能的名称。     |
| 状态      | 该参数表示特性功能的状态。     |
| 备注      | 该参数表示特性功能状态的附加说明。 |
