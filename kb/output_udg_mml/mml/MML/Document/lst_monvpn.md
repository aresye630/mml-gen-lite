# 查询监控VPN实例（LST MONVPN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询监控VPN实例。

## 注意事项

该命令适用于支持热备容灾的网元执行。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                             |
|:----------|:-------|:---------------------------------------------------------------------------------|
| DRGROUPID | 容灾组标识  | 可选必选说明：必选参数  参数含义：该参数用于配置容灾组标识。  数据来源：全网规划  取值范围：整数类型，取值范围是1~8。  默认值：无  配置原则：无   |
| VPNGRPID  | VPN组标识 | 可选必选说明：必选参数  参数含义：该参数用于配置VPN组标识。  数据来源：全网规划  取值范围：整数类型，取值范围是1~10。  默认值：无  配置原则：无 |

## 使用实例

查询监控VPN实例:

```
%%LST MONVPN:DRGROUPID=1,VPNGRPID=1;%%
RETCODE = 0  操作成功

结果如下
--------
 容灾组标识 = 1
  VPN组标识 = 1
VPN实例名称 = 1
是否联动快速隔离 = 否
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释               |
|:--------|:--------------------|
| 容灾组标识   | 该参数用于配置容灾组标识。       |
| VPN组标识  | 该参数用于配置VPN组标识。      |
| VPN实例名称 | 该参数用于配置VPN实例名称。     |
| 是否联动隔离  | 该参数用于配置VPN实例是否联动隔离。 |
