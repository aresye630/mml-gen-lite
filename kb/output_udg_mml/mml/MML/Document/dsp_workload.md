# 查询系统负载(DSP WORKLOAD)

- 命令功能

- 操作用户权限

- 输出结果说明

#### 命令功能

该命令用来查看VNFC下所有ScaleGroup的负载。当前VNFC的负载是由多项指标（内存指标、CPU指标）中取最高值得到的。其中内存指标是业务上报的多个内存相关的百分比中的最高值；CPU指标为对应ScaleGroup下所有RU的CPU占用率的平均值。

该命令在合一KPI模式下使用，在多KPI模式下不使用。查询KPI模式，请通过命令查看。

#### 注意事项

- 无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                             |
|:----------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识，不支持对"VNFC类型名称"为VNFP、VNRS_VNFC、ACS、IPSEC_VNFC的RU状态查询。 |

#### 使用实例

查看VNFC负载。

```
DSP WORKLOAD:SERVICEINSTANCE="CSLB_VNFC_999";
```

```
RETCODE = 0  操作成功。

结果如下
--------
ScaleGroup的名字  =  SG0_CSLB_IPFWD
        VNFC的ID  =  2
        VNFC负载  =  12%
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称         | 输出项解释                                                                       |
|:--------------|:----------------------------------------------------------------------------|
| ScaleGroup的名字 | VNFC下的物理资源组名字。 字符串类型，长度为：1～63。                                              |
| VNFC的ID       | 虚拟化网络功能模块ID，一个完整的网元由多个VNFC组成，每个VNFC有自己独有的一个ID。 取值范围：整数类型，取值范围为1～4294967294。 |
| VNFC负载        | VNFC监控的各个指标的最高值。 取值范围：整数类型，取值范围为0～100，单位：%。                                 |
