# 查询阻塞IMSI在特定的Worker Pod上激活信息（DSP IMSIBLOCKWKPOD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用来查询当前设置为阻塞的IMSI和Work pod。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                     |
|:-----------|:---------|:-----------------------------------------------------------------------------------------|
| IMSI       | IMSI     | 可选必选说明：可选参数 参数含义：用户的IMSI信息。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～15。每个字符必须为0~9的数字。 默认值：无 配置原则：无 |
| WORKERTYPE | Worker类型 | 可选必选说明：可选参数 参数含义：该参数用于指定Worker类型。 数据来源：本端规划 取值范围：枚举类型。 to：TCP优化。 默认值：无 配置原则：无            |

#### 使用实例

当需要查询IMSI 1234567890的阻塞在哪些Worker Pod上激活配置时，进行如下设置：

```
DSP IMSIBLOCKWKPOD: IMSI="1234567890";
```


#### 输出结果说明

| 输出项名称    | 输出项解释         |
|:---------|:--------------|
| IMSI     | 用户的IMSI信息。    |
| Pod 名称   | 用于指定Pod名称。    |
| 超时时长     | 用于指定配置生效时长。   |
| Worker类型 | 用于指定Worker类型。 |
