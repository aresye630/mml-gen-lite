# 显示CFG诊断日志（DSP CFGDEBUG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示CFG诊断日志。

#### 注意事项

该命令仅用于研发问题定位。

#### 操作用户权限

G\_1，管理员级别命令组

#### 使用实例

显示CFG诊断日志：

```
DSP CFGDEBUG:DEBUGTYPE=4,LOCINDEX1=3,SERVICEINSTANCE="vnfc";
```
