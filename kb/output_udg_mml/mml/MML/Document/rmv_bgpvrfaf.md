# 删除BGP VPN地址族（RMV BGPVRFAF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除BGP VPN地址族。

**须知** 

本命令属于高危命令，该操作会删除BGP所有该VPN实例地址族下的关联配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                                  |
|:--------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------|
| VRFNAME | VPN实例名称 | 可选必选说明：可选参数 参数含义：该参数用于指定VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：_public_ 配置原则：使用LST BGPVRFAF命令查看可用VPN。                         |
| AFTYPE  | 地址族类型   | 可选必选说明：必选参数 参数含义：该参数用于指定BGP VPN实例下的地址族。 数据来源：本端规划 取值范围：枚举类型。 ipv4uni：IPv4地址族。ipv4vpn：VPNv4地址族。ipv6uni：IPv6地址族。ipv6vpn：VPNv6地址族。 默认值：无 |

#### 使用实例

删除BGP VPN中IPv4单播地址族：

```
RMV BGPVRFAF:VRFNAME="vrf1",AFTYPE=ipv4uni;
```
