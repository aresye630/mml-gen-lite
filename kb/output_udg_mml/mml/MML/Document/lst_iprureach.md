# 查询RU到网关的可达性检测配置（LST IPRUREACH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询RU到网关可达性的检测配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                 |
|:----------|:--------|:-----------------------------------------------------------------------------------------------------|
| VPNNAME   | VPN实例名称 | 可选必选说明：可选参数 参数含义：该参数用于表示VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                             |
| IPVERSION | IP版本    | 可选必选说明：可选参数 参数含义：该参数用来表示网关地址的IP版本。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。ipv6unicast：IPv6单播。 默认值：无 |
| SOURCERU  | RU名称    | 可选必选说明：可选参数 参数含义：该参数用来表示资源单元名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～49。 默认值：无                              |

#### 使用实例

查询RU到网关可达性检测的配置：

```
LST IPRUREACH:VPNNAME="vrf";
```

