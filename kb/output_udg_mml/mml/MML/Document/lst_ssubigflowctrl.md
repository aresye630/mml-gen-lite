# 查询智能板的大流判断速率阈值（LST SSUBIGFLOWCTRL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询智能板的大流判断速率阈值。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询智能板的大流判断速率阈值：

```
%%LST SSUBIGFLOWCTRL:;
```

```
%%
RETCODE = 0  操作成功

查询智能板的大流判断速率阈值
----------------------------
VVIP业务大流速率（千比特/秒）  =  800
 CCO业务大流速率（千比特/秒）  =  800
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见SET SSUBIGFLOWCTRL的参数说明。
