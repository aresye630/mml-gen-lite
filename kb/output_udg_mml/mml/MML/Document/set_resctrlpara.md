# 设置内部资源使用控制的全局参数。（SET RESCTRLPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、SGW-U、PGW-U**

该命令用于配置内部资源使用控制的全局参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为128。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | RESTYPE            | RESISOBYDSCP   |   HRSVRATIO |
|:-------|:-------------------|:---------------|------------:|
| 初始值    | OUTER_IPFRAG_REASS | DISABLE        |          10 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称       | 参数说明                                                                                                                                                                                                                                           |
|:-------------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RESTYPE      | 资源类型       | 可选必选说明：必选参数 参数含义：该参数用于指定内部资源类型。 数据来源：本端规划 取值范围： OUTER_IPFRAG_REASS：该参数仅用于NP场景。 默认值：无 配置原则：无                                                                                                                                                    |
| RESISOBYDSCP | 基于DSCP隔离资源 | 可选必选说明：条件可选参数 前提条件：该参数在“RESTYPE”配置为“OUTER_IPFRAG_REASS”时为可选参数。 参数含义：该参数用于设置基于DSCP值隔离资源的功能是否使能。使能该功能后，系统从资源池中预留一部分资源。当资源不足时，DSCP优先级高的IP报文使用预留的资源。 数据来源：本端规划 取值范围： DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：该参数需使用SET RESCTRLQOSMAP命令设置DSCP映射的优先级后才会生效。 |
| HRSVRATIO    | 高优先级预留比例   | 可选必选说明：条件可选参数 前提条件：该参数在“RESISOBYDSCP”配置为“ENABLE”时为可选参数。 参数含义：该参数用于设置为高优先级IP报文预留的资源百分比。 数据来源：本端规划 取值范围：3-20。 默认值：无 配置原则：无                                                                                                                       |

#### 使用实例

当前网络上大量异常IP分片报文，导致系统进行重组时资源过载，为了优先保障高优先级业务（比如语音、信令等），开启资源隔离功能，预留部分资源，当资源过载时，DSCP优先级高的IP分片报文使用预留资源，低优先级的IP分片报文被丢弃：

```
SET RESCTRLQOSMAP: QOSMAPTYPE=DSCP_VALUE, DSCPVALUE=46, PRIORITY=HIGH;
SET RESCTRLPARA: RESTYPE=OUTER_IPFRAG_REASS, RESISOBYDSCP=ENABLE, HRSVRATIO=10;
```
