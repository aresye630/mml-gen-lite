# 删除用户关联识别（RMV USRRELATEIDEN）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，删除UsrRelateIden可能改变协议识别结果，影响策略获取。

当运营商业务变更，为了提高系统性能，删除用户关联识别功能时配置，该命令用于删除指定的用户关联识别配置，该命令支持批量删除。

#### 注意事项

该命令执行后60s生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                 |
|:-------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
| PROTOCOLNAME | 协议名称   | 可选必选说明：必选参数 参数含义：该参数用于设置对应的协议名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：数据源为系统支持识别的所有类型的协议、子协议，可以通过工程命令smctrldsp protocol-list查询。 |

#### 使用实例

假设运营商不需要对https协议提高识别率，删除指定的协议的用户关联识别功能配置：

```
RMV USRRELATEIDEN:  PROTOCOLNAME="https";
```
