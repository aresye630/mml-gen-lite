# 删除VPN实例名称（RMV TWAMPVPNINST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除VPN实例名称。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                               |
|:--------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------|
| VRFNAME | VPN实例名称 | 可选必选说明：必选参数  参数含义：该参数用于配置VPN实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~31。  默认值：无  配置原则：  区分大小写，不支持空格。  “_public_”是公网缺省VPN的实例名，不允许用户配置。 |

## 使用实例

删除VPN实例名称为ck的实例：

```
RMV TWAMPVPNINST: VRFNAME="ck";
```
