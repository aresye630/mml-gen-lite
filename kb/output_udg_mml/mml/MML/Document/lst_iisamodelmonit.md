# 查询模型监控功能（LST IISAMODELMONIT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF、PGW-U**

此命令用于查询模型监控功能相关参数。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询模型监控功能：

```
%%LST IISAMODELMONIT:;
```

```
%%
RETCODE = 0  操作成功

结果如下
------------------------
            模型能力异常告警开关  =  不使能
                       监控阈值  =  80
                       有效次数  =  10000
               协议推理监控开关  =  不使能
           应用大类推理监控开关  =  不使能
                QoE推理监控开关  =  不使能
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见LST IISAMODELMONIT的参数说明。
