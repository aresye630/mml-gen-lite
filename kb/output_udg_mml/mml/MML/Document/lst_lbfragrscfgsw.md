# 查询CSLB分片重组配置开关（LST LBFRAGRSCFGSW）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询CSLB分片重组独占资源池开关和资源比例。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询分片重组独占资源池开关和资源比例，命令如下：

```
LST LBFRAGRSCFGSW:;
```

```
%%LST LBFRAGRSCFGSW:;%%
RETCODE = 0  操作成功

操作结果如下：
--------------
独占资源池配置开关  =  独占资源池配置开关开启
独占资源池独占比例  =  10
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见SET LBFRAGRSCFGSW的参数说明。
