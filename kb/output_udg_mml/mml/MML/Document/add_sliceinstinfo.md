# 添加切片实例信息（ADD SLICEINSTINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

此命令用于添加切片实例信息。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为128。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                               |
|:--------------|:--------|:-----------------------------------------------------------------------------------|
| NSIINFO       | NsiInfo | 可选必选说明：必选参数 参数含义：NSIINFO。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～40。 默认值：无 配置原则：无           |
| NSSIID        | NSSI ID | 可选必选说明：必选参数 参数含义：NSSI ID。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～40。 默认值：无 配置原则：无           |
| CFGDOMAINNAME | 配置域名称   | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无 |

#### 使用实例

添加切片实例信息：

```
ADD SLICEINSTINFO: NSSIID="1", NsiInfo="test";RETCODE = 0  操作成功
```
