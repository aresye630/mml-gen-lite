# 增加TCP优化策略匹配规则（ADD TOPOLICYMATCH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于增加TCP优化策略匹配规则，实现基于小区/IMSI/RAT类型的TCP优化参数定制化功能。

#### 注意事项

- 该命令执行后只对之后发生承载更新的用户或者新激活用户生效。
- 该命令最大记录数为100。
- 在同一条TCP优化策略匹配命令中，CellGroupName/IMSIGroupName/RATtype之间为与关系，即配置的所有条件均匹配中，才认为匹配中TCP优化策略。
- CellGroupName/IMSIGroupName/RATtype三个可选参数中至少有一个有值。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                                              |
|:--------------|:---------|:------------------------------------------------------------------------------------------------------------------|
| CELLGROUPNAME | 小区组名称    | 可选必选说明：可选参数 参数含义：指定小区组名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD CELLBINDGRP命令配置生成。   |
| IMSIGROUPNAME | IMSI 组名称 | 可选必选说明：可选参数 参数含义：指定IMSI组名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD IMSIBINDGRP命令配置生成。 |
| RATTYPE       | RAT类型    | 可选必选说明：可选参数 参数含义：无线接入技术类型。 数据来源：全网规划 取值范围：枚举类型。 UTRAN：3G用户。EUTRAN：4G用户。NR：5G用户。 默认值：无 配置原则：无                      |
| POLICYID      | 策略ID     | 可选必选说明：必选参数 参数含义：策略ID。 数据来源：全网规划 取值范围：整数类型，取值范围为1～7。 默认值：无 配置原则：该参数使用ADD TOPOLICYCFG命令配置生成。                       |

#### 使用实例

运营商需要增加一个小区组名称为TestCellGroupName，策略ID为1的策略匹配规则：

```
ADD TOPOLICYMATCH: CELLGROUPNAME="TestCellGroupName",POLICYID=1;
```
