# 查询ARP快回（LST SECARP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询ARP快回使能配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                     |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------|
| RUNAME | RU名称   | 可选必选说明：可选参数 参数含义：资源单元名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。区分大小写。 默认值：无 配置原则： 区分大小写，不支持空格。使用DSP RU查看RU名称。 |

#### 使用实例

- 查询ARP快回使能配置：

  ```
  LST SECARP:;
  ```

  ```
  RETCODE = 0  操作成功

  结果如下
  -------------------------
  RU名称                      使能标记

  VNODE_VNRS_VNFC_IPU_0066    是
  VNODE_VNRS_VNFC_IPU_0067    是
  (结果个数 = 2)
  ---    END
  ```
- 查询指定条件的ARP快回使能配置：

  ```
  LST SECARP:RUNAME="VNODE_VNRS_VNFC_IPU_0066";
  ```

  ```
  RETCODE = 0  操作成功

  结果如下
  -------------------------
    RU名称  =  VNODE_VNRS_VNFC_IPU_0066
  使能标记  =  是
  (结果个数 = 1)
  ---    END
  ```

#### 输出结果说明

| 输出项名称   | 输出项解释         |
|:--------|:--------------|
| RU名称    | 该参数表示资源单元的名称。 |
| 使能标记    | 该参数表示使能标记。    |
