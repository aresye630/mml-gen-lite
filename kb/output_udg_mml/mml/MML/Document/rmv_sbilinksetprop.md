# 删除SBI链路集策略（RMV SBILINKSETPROP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令用于删除SBI链路集策略，该策略删除以后，使用该策略的链路集的LINKNUMPERPROC会变化为默认值1，可能导致单链路上负载过大，一旦网络传输质量变化，容易出现该链路上的传输拥塞导致丢包，可能影响业务。

该命令用于删除SBI链路集策略。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                   |
|:-------|:-------|:---------------------------------------------------------------------------------------|
| INDEX  | 索引     | 可选必选说明：必选参数  参数含义：该参数用于指定SBI链路集策略的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~255。  默认值：无  配置原则：无 |

## 使用实例

若运营商想删除索引为1的SBI链路集策略，可以执行如下命令：

```
RMV SBILINKSETPROP: INDEX=1;
```
