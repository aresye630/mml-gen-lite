# 显示PAE多队列信息（DSP PAEPORTQUEUE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示PAE多队列信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                    |
|:-------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CELLTYPE     | 微服务类型  | 可选必选说明：必选参数 参数含义：该参数用于指定微服务类型。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～63。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符。 默认值：无 配置原则：使用DSP PAENODE查看微服务类型。    |
| CELLINSTANCE | 微服务实例号 | 可选必选说明：必选参数 参数含义：该参数用于指定微服务实例号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～127。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符。 默认值：无 配置原则：使用DSP PAENODE查看微服务实例号。 |
| PORTTYPE     | 端口类型   | 可选必选说明：可选参数 参数含义：该参数用于指定PAE端口类型。 数据来源：本端规划 取值范围：枚举类型。 extern：外联口。fabric：内联口。loop：Loop口。base：base口。acc：加速端口。control：控制端口。 默认值：无 配置原则：使用DSP PAEPORT查看端口类型。                |

#### 使用实例

显示类型为104的微服务csdb-pod-0172-16-2-45\_\_103\_\_0的PAE队列统计信息：

```
%%DSP PAEPORTQUEUE: CELLTYPE="104", CELLINSTANCE="csdb-pod-0172-16-2-45__103__0";%%
RETCODE = 0  操作成功

结果如下:
```
