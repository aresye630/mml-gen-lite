# 查询容灾信息(DSP DRINFO)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明

- 输出结果说明

#### 命令功能

该命令用于查询容灾信息。

#### 注意事项

容灾部署模式为主备容灾时，仅适用于支持热备的网元查询。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                                                                                                                                        |
|:-------------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PEERDRINSTID | 对端容灾实例ID | 可选必选说明：可选参数。 参数含义：对端容灾实例标识。 如果部署模式为双活容灾，可以通过LST DRINST命令查询本端容灾实例ID，再通过LST DRCOMM命令查询到本端和对端容灾实例ID，从而得知对端容灾实例ID。如果部署模式为主备容灾，可以通过LST DRGROUPINFO命令查询到本端和对端容灾实例ID，从而得知对端容灾实例ID。 数据来源：全网规划。 取值范围：整型，0~63。 默认值：无。 |

#### 使用实例

查询“对端容灾实例ID”为“1”的容灾信息：

```
%%DSP DRINFO: PEERDRINSTID=1;%%
RETCODE = 0  操作成功
操作结果如下：
--------------
  本端容灾实例ID  =  0
  对端容灾实例ID  =  1
    数据备份状态  =  数据实时备份状态
对端数据备份状态  =  数据实时备份状态
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称    | 输出项解释                                                                                                                                                                                                                                                                                                                                |
|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 本端容灾实例ID | 本端容灾实例标识。                                                                                                                                                                                                                                                                                                                            |
| 对端容灾实例ID | 对端容灾实例标识。                                                                                                                                                                                                                                                                                                                            |
| 数据备份状态   | 用于返回当前的数据备份状态。 取值范围： 容灾准备状态：容灾配置已下发，但尚未激活，激活可以通过MML命令、软参、License项等。数据批量备份状态：初次完成容灾激活后或容灾故障恢复后，系统将自动进行容灾数据同步（即批量备份），同步完成后即进入数据实时备份状态。数据实时备份状态：批量备份完成，进入实时备份状态，此时处于稳态。容灾通道故障状态：容灾通道故障，备份失效。数据备份中断状态：备份停止，可能原因为内存过载，或软参介入中断等原因。容灾配置表仍然存在：下发删除容灾实例命令后，容灾配置删除中或删除失败。容灾配置表已删除：未下发容灾配置，或下发删除容灾实例命令后容灾配置信息已同步删除完毕。对端版本不支持：获取对端集群的容灾配置失败。     |
