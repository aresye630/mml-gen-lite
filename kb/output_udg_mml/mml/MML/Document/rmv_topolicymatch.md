# 删除TCP优化策略匹配规则（RMV TOPOLICYMATCH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令,执行本命令后将删除指定或所有TCP优化策略匹配规则，可能影响TCP优化效果，请谨慎使用。

该命令用于删除TCP优化策略匹配规则。当运营商希望删除TCP优化策略匹配规则时，则配置该命令。

#### 注意事项

- 该命令执行后只对之后发生承载更新的用户或者新激活用户生效。
- 如果CellGroupName/IMSIGroupName/RATtype都不输入，表示删除系统中所有TCP优化策略匹配规则。
- 如果执行批量删除操作，需要开启软参BYTE692。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                                              |
|:--------------|:---------|:------------------------------------------------------------------------------------------------------------------|
| CELLGROUPNAME | 小区组名称    | 可选必选说明：可选参数 参数含义：指定小区组名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD CELLBINDGRP命令配置生成。   |
| IMSIGROUPNAME | IMSI 组名称 | 可选必选说明：可选参数 参数含义：指定IMSI组名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD IMSIBINDGRP命令配置生成。 |
| RATTYPE       | RAT类型    | 可选必选说明：可选参数 参数含义：无线接入技术类型。 数据来源：全网规划 取值范围：枚举类型。 UTRAN：3G用户。EUTRAN：4G用户。NR：5G用户。 默认值：无 配置原则：无                      |

#### 使用实例

运营商需要删除匹配条件为小区组名称是TestCellGroupName，IMSI组名称是TestImsiGroupName，RAT类型是EUTRAN的小区：

```
RMV TOPOLICYMATCH: CELLGROUPNAME="TestCellGroupName", IMSIGROUPNAME="TestImsiGroupName", RATTYPE=EUTRAN;
```
