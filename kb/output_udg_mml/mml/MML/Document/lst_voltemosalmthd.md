# 查询异常MOS告警阈值（LST VOLTEMOSALMTHD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明

- 输出结果说明

#### 命令功能

**适用NF：PGW-U**

该命令用于查询异常MOS告警阈值和恢复告警阈值。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询异常MOS告警阈值和恢复告警阈值：

```
LST VOLTEMOSALMTHD:;
```

```
RETCODE = 0  操作成功。

异常MOS告警阈值配置
-------------------
    告警阈值  =  10
恢复告警阈值  =  8
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见SET VOLTEMOSALMTHD的参数说明。
