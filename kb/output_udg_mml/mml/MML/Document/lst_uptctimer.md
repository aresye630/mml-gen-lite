# 查询TC定时器（LST UPTCTIMER）

- 命令功能
- 注意事项
- 操作用户权限

#### 命令功能

**适用NF：UPF**

该命令用于查询Diameter TC定时器。

#### 注意事项

该命令相关的功能当前版本暂不支持。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询Diameter TC定时器，则可以按如下配置：

```
LST UPTCTIMER:;
```

```
RETCODE = 0  操作成功。
TC定时器配置
------------
TC定时器时长（单位500ms）  =  3
               定时器模式  =  固定方式
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见SET UPTCTIMER的参数说明。
