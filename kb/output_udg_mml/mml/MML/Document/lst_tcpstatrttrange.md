# 查询TCP统计功能的RTT区间（LST TCPSTATRTTRANGE）

- 命令功能
- 注意事项
- 操作用户权限

- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询TCP统计功能中的UE侧、SP侧RTT区间。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

如果运营商需要查询TCP统计功能中的UE侧、SP侧RTT区间：

```
LST TCPSTATRTTRANGE:;
```
