# 查询组播引流表项叶子信息（DSP MCASTPAEELB）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示组播引流表项叶子信息。

#### 注意事项

该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                               |
|:--------------|:--------|:-------------------------------------------------------------------------------------------------------------------|
| ADDRESSFAMILY | 地址族     | 可选必选说明：必选参数 参数含义：该参数用于表示地址族类型。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。 默认值：无                                      |
| VRFNAME       | VPN实例名称 | 可选必选说明：可选参数 参数含义：该参数用于表示VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：_public_ 配置原则：通过LST L3VPNINST查看当前已存在的VPN实例。 |
| SRCADDR       | 源地址     | 可选必选说明：条件必选参数 前提条件：该参数在“ADDRESSFAMILY”配置为“ipv4unicast”时为必选参数。 参数含义：该参数用于表示组播源地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无    |
| GRPADDR       | 组地址     | 可选必选说明：条件必选参数 前提条件：该参数在“ADDRESSFAMILY”配置为“ipv4unicast”时为必选参数。 参数含义：该参数用于表示组播组地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无    |

#### 使用实例

显示组播引流表项叶子信息：

```
DSP MCASTPAEELB:VRFNAME="_public_",ADDRESSFAMILY=ipv4unicast,SRCADDR="0.0.0.0",GRPADDR="239.2.2.2";
```

```
RETCODE = 0 操作成功。

结果如下
------------------------
  VPN实例名称  =  _public_
       地址族  =  IPv4单播
       源地址  =  0.0.0.0
       组地址  =  239.2.2.2
PAE Group索引  =  2
     过滤模式  =  Include模式
 表项建立时间  =  00:00:01
     表项标记  =  PAE
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称       | 输出项解释                                            |
|:------------|:-------------------------------------------------|
| VPN实例名称     | 用于表示VPN实例名称。                                     |
| 地址族         | 用于表示地址族类型。                                       |
| 源地址         | 用于表示组播源地址。                                       |
| 组地址         | 用于表示组播组地址。                                       |
| PAE Group索引 | 用于表示组播引流路由表项叶子的PAE Group索引。                      |
| 过滤模式        | 用于表示组播引流路由表项叶子的过滤模式，包括： Include模式。Exclude模式。     |
| 表项建立时间      | 用于表示组播引流路由表项叶子的建立时间。                             |
| 表项标记        | 用于表示组播引流路由表项叶子的标记，包括： PAE表示引流消息创建的表项。INH表示出接口标记。 |
