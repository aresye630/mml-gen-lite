# 修改重定向（MOD REDIRECT）

#### 命令功能

**适用NF：PGW-U、UPF**

此命令用于运营商修改已经配置的URL重定向策略，可以修改重定向携带信息的名称。

#### 注意事项

- 该命令执行后立即生效。
- 对于URL，特殊字符的输入要求：

  - 对于普通字符?必须使用%3f代替；例如：www.huawei.com/a?c 输入应该是：www.huawei.com/a%3fc。
  - 对于空格必须使用%20代替；例如：www.hua wei.com 输入应该是：www.hua%20wei.com。
  - 对于逗号必须使用％2c代替；例如：www.hua,wei.com 输入应该是：www.hua%2cwei.com。
  - 对于加号尽量使用％2b代替，可以直接输入连续一到两个的加号，但在查询时都会以%2b显示，在业务处理时会转义成加号，例如：www.hua+++wei.com 输入应该是：www.hua%2b%2b%2bwei.com。
  - 当字符串中出现%3f、%2c、%20、%2b或者%25本身时，对于%必须使用%25代替；例如：www.hua%3fwei.com 输入应该是：www.hua%253fwei.com。
  - 其他情况下，%就认为是%本身，可以保持原有实现即可，也可以使用%25替代%；例如：www.hua%wei.com 输入应该是：www.hua%wei.com或者是www.hua%25wei.com。
  - 对于分号使用\;代替；例如：www.hua;wei.com 输入应该是：www.hua\;wei.com。
  - 对于双引号使用\"代替；例如：www.hua"wei.com 输入应该是：www.hua\"wei.com。
  - 对于反斜杠使用\\代替；例如：www.hua\wei.com 输入应该是：www.hua\\wei.com。
  - 输入“\”只支持上述三种转义字符，不支持其他情况下输入“\”，如果要使用“\”本身，请输入“\\”代替。
  - 不能包含ASCII码值为0x00~0x1F和0x7F的非法字符。
  - URL不允许以“/”开头，可以支持配置“http://”或者“https://”scheme信息，如果没有配置scheme信息，重定向url的scheme默认为“http://”。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称      | 参数说明                                                                                                                                                                 |
|:---------------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| REDIRECTNAME   | 重定向名称     | 可选必选说明：必选参数 参数含义：该参数用于设置重定向配置名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～31。不区分大小写，不支持空格。 默认值：无 配置原则：无                                                                         |
| URL            | URL       | 可选必选说明：可选参数 参数含义：该参数用于设定重定向URL。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～119。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。                                                                      |
| FLOWCONTROL    | 流控标识      | 可选必选说明：可选参数 参数含义：该参数用于设置重定向的流控开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能（关闭）。ENABLE：使能（开启）。 默认值：无 配置原则： 如果重定向不开启流控功能，则设置该参数为DISABLE。如果重定向要开启流控功能，则设置该参数为ENABLE。            |
| ACTIONINTERVAL | 流控时间间隔（秒） | 可选必选说明：条件可选参数 前提条件：该参数在“FLOWCONTROL”配置为“ENABLE”时为可选参数。 参数含义：该参数用于设置重定向流控处理的时间间隔。 数据来源：本端规划 取值范围：整数类型，取值范围为0～3600，单位是秒。 默认值：无 配置原则：由于重定向成功率会下降，请现网根据重定向频次配置此参数。       |
| DEFAULTACT     | 重定向缺省动作   | 可选必选说明：可选参数 参数含义：该参数用于设置不满足重定向条件时报文的缺省动作。 数据来源：本端规划 取值范围：枚举类型。 BLOCK：阻塞。PASS：通过。 默认值：无 配置原则： 当运营商在做重定向业务时，对于不满足条件的业务需要放通，配置PASS。当运营商在做重定向业务时，对于不满足条件的业务需要阻塞，配置BLOCK。 |
| APPENDINFONAME | 重定向携带信息名称 | 可选必选说明：可选参数 参数含义：该参数用于指定重定向携带信息名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～31。不区分大小写，不支持空格。 默认值：无 配置原则： 该参数使用ADD REDIRAPPENDINFO命令配置生成。输入单空格将删除该参数已有配置项。                       |
| CFGDOMAINNAME  | 配置域名称     | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。                                                                   |

#### 使用实例

运营商希望将一个名为testredirect的URL重定向策略中配置的重定向URL修改为“www.huawei.com”：

```
MOD REDIRECT:REDIRECTNAME="testredirect",URL="www.huawei.com";
```
