# 查询QoS属性（LST QOSPROP）

- 命令功能
- 注意事项
- 操作用户权限

- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令是用来查询QoS属性的，其中包括QoS属性名称，保证的上下行比特率，最大上下行比特率。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                         |
|:------------|:--------|:---------------------------------------------------------------------------------------------|
| QOSPROPNAME | Qos属性名称 | 可选必选说明：可选参数 参数含义：该参数用于指定QoS属性名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

查询名称为“test”的QoS属性的信息，命令为：

```
LST QOSPROP: QOSPROPNAME="test";
```
