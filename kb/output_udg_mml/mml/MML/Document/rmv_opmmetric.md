# 删除话统指标优化公式(RMV OPMMETRIC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

执行该命令会删除话统指标的优化公式，影响该话统指标的测量结果值，请慎重执行。

该命令用于删除网元的话统指标的优化公式。

## 注意事项

该命令有高危提示，请谨慎执行。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                         |
|:---------|:-------|:---------------------------------------------------------------------------------------------|
| MEID     | 网元ID   | 可选必选说明：必选参数。 参数含义：标识网元ID，可以通过LST ME命令查询获取。 取值范围：0~65535。 默认值：无。 配置原则：无。                      |
| METRICID | 测量指标ID | 可选必选说明：必选参数。 参数含义：测量指标ID，可以通过LST MEASUNIT命令查询获取。 取值范围：整数类型，取值范围为0~4294967294。 默认值：无。 配置原则：无。 |

## 使用实例

删除话统指标优化公式：

```
%%RMV OPMMETRIC: MEID=10, METRICID=24100151;%%
RETCODE = 0  操作成功

---    END
```
