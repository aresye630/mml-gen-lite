# 删除APNBindPath配置（RMV APNBINDPATH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

使用该命令删除APN/DNN与探测路径的关联关系。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                                                  |
|:-----------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN        | APN名称  | 可选必选说明：必选参数 参数含义：该参数用于指定APN实例名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。 默认值：无 配置原则：该参数使用ADD APN命令配置生成。 |
| DETECTPATH | 路径名称   | 可选必选说明：必选参数 参数含义：该参数用于指定绑定APN的探测路径名。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD DETECTPATH命令配置生成。                                                                                             |

#### 使用实例

删除名为“testapn”的apn与名为“testpath3”的探测路径之间的绑定关系：

```
RMV APNBINDPATH: APN="testapn", DETECTPATH="testpath3";
```
