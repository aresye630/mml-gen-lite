# 删除带宽管理控制器（RMV BWMCONTROLLER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于删除指定的bwm控制器。

#### 注意事项

- 该命令执行后立即生效。
- 如果某个BwmController已经被引用，则它不能被删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称      | 参数说明                                                                                            |
|:---------|:----------|:------------------------------------------------------------------------------------------------|
| BWMCNAME | 带宽管理控制器名称 | 可选必选说明：可选参数 参数含义：该参数用于表示带宽管理控制器的名字。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

如果要删除名为“bc1”的BwmController，则使用如下命令：

```
RMV BWMCONTROLLER:BWMCNAME="bc1";
```
