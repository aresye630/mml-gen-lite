# 查询RawIP状态（DSP RAWIPSTATUS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查看RawIP连接状态信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称       | 参数说明                                                                                 |
|:--------------|:-----------|:-------------------------------------------------------------------------------------|
| SOCKETFD      | Socket实例ID | 可选必选说明：可选参数 参数含义：该参数用于指定Socket实例ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～2147418111。 默认值：无     |
| APPCID        | APP组件CID   | 可选必选说明：可选参数 参数含义：该参数用于指定APP组件CID。 数据来源：本端规划 取值范围：十六进制整数类型，取值范围为0x0～0xFFFFFFFF。 默认值：无 |
| LOCALADDRESS  | 本端地址       | 可选必选说明：可选参数 参数含义：该参数用于指定本端地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无                         |
| REMOTEADDRESS | 远端地址       | 可选必选说明：可选参数 参数含义：该参数用于指定远端地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无                         |

#### 使用实例

显示当前系统的RawIP状态：

```
DSP RAWIPSTATUS:;
```

```
        RETCODE = 0  操作成功

        结果如下
        ------------------------
        Socket实例ID  =  8
          APP组件CID  =  0x8069042E
            本端地址  =  0.0.0.0
            远端地址  =  0.0.0.0
        (结果个数 = 1)
        ---    END
```

#### 输出结果说明

| 输出项名称      | 输出项解释           |
|:-----------|:----------------|
| Socket实例ID | 用于指定Socket实例ID。 |
| APP组件CID   | 用于指定APP组件CID。   |
| 本端地址       | 用于指定本端地址。       |
| 远端地址       | 用于指定远端地址。       |
