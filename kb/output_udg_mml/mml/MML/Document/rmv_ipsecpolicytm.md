# 删除IPsec策略模板（RMV IPSECPOLICYTM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

删除IPsec策略模板，影响业务流量使用IPSEC进行加解密功能，有业务影响。

该命令用于删除IPsec策略模板。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称    | 参数说明                                                                               |
|:---------------|:--------|:-----------------------------------------------------------------------------------|
| POLICYNAME     | 策略模板名称  | 可选必选说明：必选参数  参数含义：策略模板名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~15。不区分大小写。  默认值：无  配置原则：无 |
| SEQUENCENUMBER | 策略模板序列号 | 可选必选说明：必选参数  参数含义：策略模板序列号。  数据来源：对端协商  取值范围：整数类型，取值范围是1~10000。  默认值：无  配置原则：无      |

## 使用实例

删除策略模板名为“temp3”，序列号为1的IPsec策略模板：

```
RMV IPSECPOLICYTM:POLICYNAME="temp3",SEQUENCENUMBER=1;
```
