# 查询地址池统计配置（LST ADDRPOOLSTAT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询已经配置的地址池性能统计对象。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                                   |
|:-------------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------|
| POOLSTATNAME | 地址池统计名称 | 可选必选说明：可选参数 参数含义：该参数用于指定地址池统计配置的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～79。由“_”、“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

查询已经配置的地址池性能统计对象：

```
LST ADDRPOOLSTAT:;
```

```

    切片区分码  =  123456
 切片/服务类型  =  1
(结果个数 = 1)

---    END
```
