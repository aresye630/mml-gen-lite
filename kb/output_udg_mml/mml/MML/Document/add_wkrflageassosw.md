# 增加Worker流表老化关联开关（ADD WKRFLAGEASSOSW）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于配置是否使能特定类型Worker的流表老化关联功能。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为32。
- 当没有配置对应Worker的流表老化关联开关时，缺省为关闭流表老化关联功能。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                     |
|:-----------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------|
| WORKERNAME | Worker名称 | 可选必选说明：必选参数 参数含义：该参数用于设置需要控制流表关联老化功能的Worker名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：根据部署的业务策略选择相应的子策略名称。选择范围和ADD RULE的WORKERNAME一致。 |
| SWITCH     | 开关       | 可选必选说明：必选参数 参数含义：该参数用于设置是否开启流表关联老化功能。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能（关闭）。ENABLE：使能（开启）。 默认值：0 配置原则：无                                                   |

#### 使用实例

当需要开启to的流表老化关联功能时，进行如下设置：

```
ADD WKRFLAGEASSOSW: WORKERNAME="to", SWITCH=ENABLE;
```
