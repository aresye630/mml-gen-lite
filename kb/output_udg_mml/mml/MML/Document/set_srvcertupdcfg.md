# 设置证书更新拆链配置（SET SRVCERTUPDCFG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、PGW-U**

该命令用于设置证书更新拆链配置参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | RBDLINKSW   |   RBDINTERVAL |   RBDLINKNUM |   RBDLINKDELAY |
|:-------|:------------|--------------:|-------------:|---------------:|
| 初始值    | ON          |             4 |           10 |              5 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称          | 参数说明                                                                                                       |
|:-------------|:--------------|:-----------------------------------------------------------------------------------------------------------|
| RBDLINKSW    | 证书更新时拆链开关     | 可选必选说明：可选参数 参数含义：该参数用于控制证书开关打开的场景下更新证书，是否拆链。 数据来源：本端规划 取值范围：枚举类型。 OFF：关闭。ON：打开。 默认值：无 配置原则：无               |
| RBDINTERVAL  | 单进程每批次拆链间隔（秒） | 可选必选说明：可选参数 参数含义：该参数用于控制证书开关打开的场景下更新证书，每个进程每批次拆链的时间间隔。 数据来源：本端规划 取值范围：整数类型，取值范围是4~500，单位是秒。 默认值：无 配置原则：无   |
| RBDLINKNUM   | 单进程每批次拆链数（条）  | 可选必选说明：可选参数 参数含义：该参数用于控制证书开关打开的场景下更新证书，每个进程每批次拆链数量。 数据来源：本端规划 取值范围：整数类型，取值范围是5~500，单位是条。 默认值：无 配置原则：无      |
| RBDLINKDELAY | 证书延迟拆链的时间(分钟) | 可选必选说明：可选参数 参数含义：该参数用于控制证书开关打开的场景下更新证书，每个进程每批次证书延迟拆链的时间。 数据来源：本端规划 取值范围：整数类型，取值范围为0~10，单位为分钟。 默认值：无 配置原则：无 |

#### 使用实例

假如需要设置证书更新拆链配置参数，则命令如下：

```
SET SRVCERTUPDCFG: RBDLINKSW=ON, RBDINTERVAL=4, RBDLINKNUM=10, RBDLINKDELAY=5;
```
