# 查询媒体中继绑定回源IP地址池（LST RELAYIPPOOLBD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询媒体中继绑定回源IP地址池。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                                                                                                  |
|:-------------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RELAYTPLNAME | 媒体中继模板名称 | 可选必选说明：可选参数 参数含义：该参数用来指定媒体中继模板名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数使用ADD RELAYTEMPLATE命令配置生成。配置时需要确保RELAYTPLNAME已经配置（ADD RELAYTEMPLATE）。 |

#### 使用实例

假设需要查询媒体中继绑定回源IP地址池，则命令如下：

```
LST RELAYIPPOOLBD: RELAYTPLNAME="template_relay";
```

```

结果如下
------------------------

    ip地址池名称  =  pool_relay1
(结果个数 = 1)

---    END
```
