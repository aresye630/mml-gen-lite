# 显示设备EOS时间（DSP UPVERLC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

显示设备EOS时间。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

当需要查询生命周期EOSTIME时，进行如下设置：

```
DSP UPVERLC:;
```

```
RETCODE = 0操作成功
 
结果如下
------------------------
设备EOS时间= 2028-12-31
（结果个数=1）
 
---结束
```

#### 输出结果说明

| 输出项名称   | 输出项解释    |
|:--------|:---------|
| 设备EOS时间 | 是生命周期时间。 |
