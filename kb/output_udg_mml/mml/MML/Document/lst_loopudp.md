# 查询UDP环回配置（LST LOOPUDP）

- 命令功能
- 注意事项

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于查询UDP环回功能的配置情况。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询UDP环回配置：

```
LST LOOPUDP:;
```
