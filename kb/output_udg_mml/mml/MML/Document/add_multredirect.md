# 增加多级重定向密码（ADD MULTREDIRECT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于配置多级重定向字段加密的密码。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令与软参BIT\_1704配合使用。
- 该命令仅能配置加密算法AES256的CBC模式，存在安全风险，建议使用ADD MULTREDIRECTEX并配置安全的加密模式。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识             | 参数名称           | 参数说明                                                                                             |
|:-----------------|:---------------|:-------------------------------------------------------------------------------------------------|
| MULTREDIRECTNAME | 多级重定向名称        | 可选必选说明：必选参数 参数含义：该参数用于设置多级重定向密码配置名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31，不区分大小写，不支持空格。 默认值：无 配置原则：无 |
| AES256CBCKEY     | AES256 CBC密码   | 可选必选说明：必选参数 参数含义：该参数用于指定对多级重定向字段加密的密码。 数据来源：本端规划 取值范围：密码类型，输入长度范围为1～32的字符串，不支持空格。 默认值：无 配置原则：无   |
| AES256CBCKEYCONF | AES256 CBC密码确认 | 可选必选说明：必选参数 参数含义：该参数用于确认对多级重定向字段加密的密码。 数据来源：本端规划 取值范围：密码类型，输入长度为1~32位的字符串，不支持空格。 默认值：无 配置原则：无    |

#### 使用实例

假如运营商想要设置加密密码为1234567890123456，配置如下：

```
ADD MULTREDIRECT:MULTREDIRECTNAME="test",AES256CBCKEY="1234567890123456",AES256CBCKEYCONF="1234567890123456";
```
