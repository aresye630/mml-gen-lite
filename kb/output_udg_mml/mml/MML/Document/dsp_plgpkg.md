# 显示扩展包版本信息（DSP PLGPKG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示扩展包版本信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| PLGTYPE         | 扩展包类型  | 可选必选说明：可选参数 参数含义：该参数用于指定扩展包类型。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无                                       |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

显示扩展包版本信息：

```
DSP PLGPKG:SERVICEINSTANCE="vnfc";
```

```
RETCODE = 0  操作成功
 
结果如下:
 -------------------------
 扩展包类型 = Listening
     版本号 = V100R005C00MOD    
 (结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释      |
|:--------|:-----------|
| 扩展包类型   | 表示扩展包的类型。  |
| 版本号     | 表示扩展包的版本号。 |
