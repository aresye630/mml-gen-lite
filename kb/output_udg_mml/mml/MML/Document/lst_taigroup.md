# 查看指定TAI组或者已配置所有TAI组的配置信息（LST TAIGROUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用来查看指定TAI组或者所有TAI组的配置信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                       |
|:-------------|:--------|:-------------------------------------------------------------------------------------------|
| TAIGROUPNAME | 指定TAI组名 | 可选必选说明：可选参数 参数含义：该参数用于指定TAI组名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

假设运营商需要去查询指定TAI组beijing：

```
LST TAIGROUP: TAIGROUPNAME="beijing";
```
