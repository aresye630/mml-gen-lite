# 查询系统HA状态（DSP RESHASTAT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询系统资源的HA状态，HA（High Availability）是为系统存储服务提供高可靠性的模块。当系统进行升级时，需要确保所有组件状态正常，可以使用该命令确定资源的进程、组件状态是否正常。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                         |
|:--------|:-------|:-------------------------------------------------------------------------------------------------------------|
| RESNAME | 资源名称   | 可选必选说明：可选参数 参数含义：该参数表示节点或容器资源的名称。 配置原则：当不输入时显示所有资源的HA状态。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 |

#### 使用实例

查询“OMU1”的HA状态：

```
DSP RESHASTAT:RESNAME="OMU1";
```

```
RETCODE = 0  操作成功
 
结果如下:
 -------------------------
 逻辑资源编号 = 1
     资源名称 = OMU1
       HA状态 = 正常    
 (结果个数 = 1)
  ---   END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                      |
|:--------|:---------------------------|
| 逻辑资源编号  | 表示逻辑资源编号，该编号在网元进行分配。       |
| 资源名称    | 表示节点或容器的资源名称。              |
| HA状态    | 表示HA状态。 包括“正常”、 “异常”及“暂停”。 |
