# 修改媒体中继引用检查规则（MOD RELAYRFCHKRULE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于修改媒体中继引用检查规则。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称            | 参数说明                                                                                                                                                                                                                   |
|:---------------|:----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RELAYRFCHKNAME | 媒体中继引用检查名称      | 可选必选说明：必选参数 参数含义：该参数用来指定媒体中继引用检查名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                                                        |
| CHECKMODE      | 检测模式            | 可选必选说明：可选参数 参数含义：该参数用于指定检测模式。 数据来源：本端规划 取值范围：枚举类型。 BLACKLIST：黑名单模式。WHITELIST：白名单模式。 默认值：无 配置原则：无                                                                                                                       |
| BLKURLLISTNAME | 黑名单URL列表名称      | 可选必选说明：条件必选参数 前提条件：该参数在“CHECKMODE”配置为“BLACKLIST”时为必选参数。 参数含义：该参数用来指定黑名单URL列表名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                            |
| WHTURLLISTNAME | 白名单URL列表名称      | 可选必选说明：条件必选参数 前提条件：该参数在“CHECKMODE”配置为“WHITELIST”时为必选参数。 参数含义：该参数用来指定白名单URL列表名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                            |
| NOREFERACT     | 未携带Referer字段的动作 | 可选必选说明：可选参数 参数含义：该参数用于指定未携带Referer字段的动作。 数据来源：本端规划 取值范围：枚举类型。 DEFAULT：缺省处理动作，白名单场景按检查失败处理，执行失败动作，黑名单场景按检查通过处理，允许业务访问。SUCCESS：检查通过，允许业务访问。FAILURE：检查失败，执行失败动作。 默认值：无 配置原则：无                                             |
| CHECKFAILACT   | 检查失败动作          | 可选必选说明：可选参数 参数含义：该参数用于指定检查失败动作。 数据来源：本端规划 取值范围：枚举类型。 FORBIDDEN：拒绝。REDIRECT：重定向。 默认值：无 配置原则：无                                                                                                                           |
| IGNORESCHEME   | 忽略Scheme        | 可选必选说明：可选参数 参数含义：该参数用于控制开启或关闭忽略Scheme开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：当绑定的黑/白名单URL列表中配置的URL包含Scheme时，根据本参数的配置控制是否忽略Scheme进行URL匹配；当绑定的黑/白名单URL列表中配置的URL未包含Scheme时，此参数配置不生效，按照忽略Scheme进行URL匹配。 |
| CFGDOMAINNAME  | 配置域名称           | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。                                                                                                                     |

#### 使用实例

假如需要修改一组媒体中继引用检查规则，则命令如下：

```
MOD RELAYRFCHKRULE: RELAYRFCHKNAME="test", CHECKMODE=WHITELIST, WHTURLLISTNAME="test_mod";
```
