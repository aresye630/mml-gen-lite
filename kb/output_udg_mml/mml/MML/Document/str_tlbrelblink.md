# 启动触发HTTP服务端TCP链路重均衡检测及调整（STR TLBRELBLINK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

执行重均衡命令可能会拆链导致消息呼损。

该命令用于触发HTTP服务端TCP链路重均衡检测及调整。

## 注意事项

- 该命令执行后立即生效。

- 若期望执行此命令触发重均衡检测及调整，则必须先执行**LST TLBGLBCONF**命令确认TLBGLBSW开关打开，否则执行此命令将没有任何效果。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

无

## 使用实例

如果服务端链路分布不均衡，希望调整链路分布，可以执行如下命令：

```
STR TLBRELBLINK:;
```
