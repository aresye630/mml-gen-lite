# 加载Lua脚本（LOD LUASCRIPT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于加载Lua脚本。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| SCRIPTNAME      | 脚本名称   | 可选必选说明：必选参数 参数含义：需要加载的Lua脚本文件名称。 数据来源：本端规划 取值范围：0~256。 默认值：无 配置原则：无                                          |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

```
加载Lua脚本：
LOD LUASCRIPT: SCRIPTNAME="TcmcTypeInner.lua", SERVICEINSTANCE="vnfc";
```
