# 查询Worker流表老化关联开关（LST WKRFLAGEASSOSW）

- 命令功能
- 注意事项

#### 命令功能

**适用NF：UPF**

该命令用于查询Worker的流表老化关联功能是否开启。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

当需要查询所有worker的流表老化关联功能开关时，执行一下命令：

```
LST WKRFLAGEASSOSW:;
```
