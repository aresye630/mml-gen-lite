# 增加用户模板（ADD USERPROFILE）

- 命令功能

- 操作用户权限

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于增加用户模板。用户模板可用于设置Alias Marking功能是否开启，防范攻击功能是否开启，免费业务是否进行在线、离线计费，用户实时位置信息是否上报到报表服务器，UserProfile级别的监控属性，预留配置属性等功能。

#### 注意事项

- 该命令执行后立即生效。
- 当UPSPECTYPE参数不指定或者指定为DEFAULT时，该命令最大记录数为5000；当UPSPECTYPE参数指定为SPECIFICATION\_LIMITED时，该命令最大记录数为100000。
- 当两种配置的记录总数大于规格（105000）的90%时，会上报“ALM-135602215 配置数量超阈值”告警。当两种配置的记录总数小于等于配置规格（105000）的90%时，恢复“ALM-135602215 配置数量超阈值”告警。阈值可以通过MOD CFGTHRESHOLD命令修改。
- 当DEFAULT类型配置的记录总数大于规格（5000）的90%时，会上报“ALM-81254 业务配置数量超阈值”告警。当DEFAULT类型配置的记录总数小于等于配置规格（5000）的90%时，恢复“ALM-81254 业务配置数量超阈值”告警。
- 当SPECIFICATION\_LIMITED类型配置的记录总数大于规格（100000）的90%时，会上报“ALM-81254 业务配置数量超阈值”告警。当SPECIFICATION\_LIMITED类型配置的记录总数小于等于配置规格（100000）的90%时，恢复“ALM-81254 业务配置数量超阈值”告警。
- DEFAULT类型的UserProfile只能绑定DEFAULT类型的Rule。SPECIFICATION\_LIMITED类型的UserProfile只能绑定SPECIFICATION\_LIMITED类型的Rule。
- 单个用户模板可以配置绑定1个扩展属性名称。
- 当前版本不支持此命令的“实时位置上报开关”参数。
- Rule、filter、flowfilter和缺省URR相关配置在特定组合下需要兜底配置，当前没有检查手段，影响计费准确性，建议配置兜底配置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| USERPROFILENAME | 用户模板名称                   | 可选必选说明：必选参数 参数含义：该参数用于指定用户模板名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格及“,”、“;”、“"”等特殊字符，不区分大小写。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                     |
| UPSPECTYPE      | 用户模板规格类型                 | 可选必选说明：可选参数 参数含义：该参数用于指定用户模板类型，当取值为SPECIFICATION_LIMITED时，表示规格受限用户模板，表示会话安装的该类型的USERPROFILE数和该类型的USERPROFILE绑定的规则数量均存在一定限制。 数据来源：本端规划 取值范围： DEFAULT：默认配置。SPECIFICATION_LIMITED：规格受限配置。 默认值：无 配置原则： 不配置此参数时值默认为Default。该参数配置后不允许修改。                                                                                                                                                                               |
| ALIASMARKFLAG   | Alias Marking使能标记        | 可选必选说明：可选参数 参数含义：指定Alias Marking使能标记。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能（关闭）。ENABLE：使能（开启）。 默认值：DISABLE 配置原则： 如果运营商希望不使能Alias Marking，则配置该参数为DISABLE。Alias Marking不使能，在上/下行数据转发时，系统在修改报文头的DSCP或ToS值的基础上，根据指定的DSCP或ToS值转发报文。如果运营商希望使能Alias Marking，则配置该参数为ENABLE。Alias Marking使能，在上/下行数据转发时，系统在不修改报文头的DSCP或ToS值的基础上，根据指定的DSCP或ToS值转发报文。                                                                             |
| DDOSCHECK       | 防DDOS攻击标记                | 可选必选说明：可选参数 参数含义：指定防DDOS攻击标记。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能（关闭）。ENABLE：使能（开启）。 默认值：DISABLE 配置原则： 如果运营商希望不使能防DDOS攻击功能，则配置该参数为DISABLE。如果运营商希望使能防DDOS攻击功能，则配置该参数为ENABLE。                                                                                                                                                                                                                                         |
| CAPMODETHRES    | Captive模式时间阈值（分）         | 可选必选说明：可选参数 参数含义：指定Captive模式时间阈值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～60，单位是分钟。 默认值：0 配置原则：如果运营商希望通过设定一个时间阈值用于定期向终端用户推送广告，则配置该参数。从用户接收推送的广告时开始计时，在时间阈值内不推送广告，超过设定阈值则重新推送广告。如果输入为0，则只对用户做一次重定向，用户被重定向一次后进入non captive模式，此后不再进入captive模式。CAPMODETHRES生效的必要条件是UserProfile作为Common Policy下发，否则不生效。                                                                                                                            |
| LOCRPTSWITCH    | 实时位置上报开关                 | 可选必选说明：可选参数 参数含义：指定实时位置上报开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能，用户位置信息不实时上报到报表服务器。ENABLE：使能，用户位置信息实时上报到报表服务器。INHERIT：继承，用户位置信息是否实时上报到报表服务器继承全局配置。 默认值：INHERIT 配置原则： 如果运营商希望用户位置信息不实时上报，则配置该参数为DISABLE。如果运营商希望用户位置信息实时上报，则配置该参数为ENABLE。如果运营商希望用户位置信息是否实时上报继承全局配置。                                                                                                                                                   |
| EXTENDPROPNAME  | 扩展属性名称                   | 可选必选说明：可选参数 参数含义：指定扩展属性名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数使用ADD EXTENDPROP命令配置生成。如果运营商希望配置一些定制的业务需求，但是现网的系统受限于业务配置，不能快速配置出业务需求的业务配置信息，可以通过配置扩展属性快速满足定制的业务需求。                                                                                                                                                                                                                      |
| USERPROFALIAS   | 用户模板别名                   | 可选必选说明：可选参数 参数含义：该参数用于指定用户模板的别名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：如果需要执行用户模板的别名，可以配置该参数。                                                                                                                                                                                                                                                                                                             |
| TETHERINGMAXNUM | Tethering用户下最多可接入后台终端的数量 | 可选必选说明：可选参数 参数含义：该参数用于指定Tethering用户下最多可接入后台终端的数量。 数据来源：本端规划 取值范围：整数类型，取值范围为0～20，255。其中255为无效值，表示不开启Tethering功能。 默认值：255 配置原则：如果运营商希望限制某个Tethering用户下最多可接入后台终端的数量，则需要用该参数进行配置。                                                                                                                                                                                                                                    |

| V6TCPMSSVALUE   | IPv6 TCP报文长度（字节）         | 可选必选说明：可选参数 参数含义：该参数用于表示对端能接收的最大报文段长度， 用于IPv6用户。MSS值一般设置为外出接口上MTU的长度减去固定的IP首部和TCP首部的长度。User-profile下优先级高于APN下配置的TCP MSS值。 数据来源：全网规划 取值范围：整数类型，取值范围为0，496～1500，单位是字节。0是无效值，设置为0时表示该参数不生效。 默认值：无 配置原则： 头增强开启后，建议修改UserProfile配置的TCPMSS参数，修改为外出接口上MTU的长度减去固定IP和TCP首部长度，再减去头增强插入的报文的最大长度。配置过小，会导致tcp分段增多；配置的值加上IP和TCP首部长度超过MTU值，会导致ip分片增多。现网部署头增强等改变报文长度的特性，参考相关命令的配置建议设置参数。其他情况建议设置为外出接口上MTU的长度减去固定的IP首部和TCP首部的长度。  |

#### 使用实例

假如运营商需要增加用户模板，用户模板名称为“testuserprofilename”：

```
ADD USERPROFILE:USERPROFILENAME="testuserprofilename";
```
