# 增加BGP路由信息的路由源设置（ADD APPLYORIGIN）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于增加BGP路由信息的路由源设置。Origin是BGP协议的私有属性，该属性定义路径信息的来源，标记一条路由是怎么成为BGP路由的。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 配置该命令前，必须首先配置ADD ROUTEPOLICYNODE命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                                                                                       |
|:-------------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| POLICYNAME   | 路由策略名字  | 可选必选说明：必选参数 参数含义：该参数用来表示路由策略名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无                                                                                                                   |
| NODESEQUENCE | 路由策略节点号 | 可选必选说明：必选参数 参数含义：该参数用来表示路由策略节点号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无                                                                                                                   |
| ORIGINTYPE   | 路由源类型   | 可选必选说明：必选参数 参数含义：该参数用来表示路由源类型。 数据来源：本端规划 取值范围：枚举类型。 EGP：外部路由。IGP：内部路由。INCOMPLETE：未知源。 默认值：无                                                                                                |
| ASSTRORNUM   | AS号     | 可选必选说明：条件必选参数 前提条件：该参数在“ORIGINTYPE”配置为“EGP”时为必选参数。 参数含义：该参数用来表示AS号。支持两种格式的AS值： 1、整数形式，取值范围是1～4294967295。 2、点分式，形式为number<1～65535>.number<0～65535>。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～11。 默认值：无 |

#### 使用实例

配置policy路由策略10节点下，路由源类型设置为IGP：

```
ADD APPLYORIGIN:POLICYNAME="policy",NODESEQUENCE=10,ORIGINTYPE=IGP;
```
