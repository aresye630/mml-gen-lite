# 显示直播视频信息（DSP DCSLIVEINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于显示直播视频信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

显示所有实例的直播视频信息。

```
%%DSP DCSLIVEINFO:;%%
RETCODE = 0  操作成功

结果如下
------------------------
                实例ID  =  1837857504428137284
内存空间最大大小（MB）  =  5160
内存空间申请大小（MB）  =  10
            直播用户数  =  63
          直播视频个数  =  2
               POD名称  =  relay-pod-0
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称        | 输出项解释                 |
|:-------------|:----------------------|
| 实例ID         | 该参数用于表示SERVER分配的实例ID。 |
| 内存空间最大大小（MB） | 该参数用于表示内存空间最大大小。      |
| 内存空间申请大小（MB） | 该参数用于表示内存空间申请大小。      |
| 直播用户数        | 该参数用于表示直播用户数。         |
| 直播视频个数       | 该参数用于表示直播视频个数。        |
| POD名称        | 该参数用于表示POD名称。         |
