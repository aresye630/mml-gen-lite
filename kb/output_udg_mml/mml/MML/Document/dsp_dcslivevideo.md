# 显示指定直播视频信息（DSP DCSLIVEVIDEO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示指定直播视频信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                        |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------|
| OTTNAME | OTT名称  | 可选必选说明：必选参数  参数含义：该参数用于表示OTT名称，OTT名称由OTT厂商提供，可通过执行LST RELAYDOMAIN命令，获取查询结果中的“媒体中继模板名称”。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~256。  默认值：无  配置原则：无 |
| URL     | URL名称  | 可选必选说明：必选参数  参数含义：该参数用于表示视频文件的URL名称，URL名称由OTT厂商提供。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~1024。  默认值：无  配置原则：无                                     |

## 使用实例

显示OTT名称为“douyin”，URL为“aaa.douyincdn.com/fantasy/stream-404357031821050550.flv”的直播视频信息。

```
%%DSP DCSLIVEVIDEO: OTTNAME="douyin", URL="aaa.douyincdn.com/fantasy/stream-404357031821050550.flv";%%
RETCODE = 0  操作成功

结果如下
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                 |
|:--------|:------------------------------------------------------------------------------------------------------|
| 实例ID    | 该参数用于表示SERVER分配的实例ID。                                                                                 |
| 文件状态    | 该参数用于表示视频文件状态。 取值说明： FILE_STATUS_EXIST（文件存在）FILE_STATUS_NOT_EXIST（文件不存在）FILE_STATUS_NOT_RETURN（文件未返回） |
| 视频创建时间  | 该参数用于表示视频创建时间。                                                                                        |
| 热度      | 该参数用于表示热度。                                                                                            |
| POD名称   | 该参数用于表示POD名称。                                                                                         |
