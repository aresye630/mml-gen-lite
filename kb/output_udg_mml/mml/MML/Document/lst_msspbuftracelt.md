# 查询PBUF轨迹开关状态和持续时间（LST MSSPBUFTRACELT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询PBUF轨迹开关状态和持续时间。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询当前PBUF轨迹开关状态和持续时间:

```
%%LST MSSPBUFTRACELT:;%%
RETCODE = 0  操作成功

结果如下
--------
            PBUF轨迹开关  =  开
轨迹开关持续时间（分钟）  =  1440
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称        | 输出项解释                     |
|:-------------|:--------------------------|
| PBUF轨迹开关     | 该参数用于表示轨迹开关标记。            |
| 轨迹开关持续时间（分钟） | 该参数用于表示本次规则设置的持续时间，单位:分钟。 |
