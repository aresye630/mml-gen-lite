#### 命令功能

PING命令用于排查网元之间接口IP（VNRS外联口上配置的IP）是否可以PING通。PING是最常见的用于检测网络设备可访问性的调试工具，它使用ICMP报文来检测远程设备是否可用、远程主机通信的来回旅程的延迟以及包的丢失情况。

#### 注意事项

- 该命令执行后立即生效。

- 无线路由Ping场景必须指定源地址。

- 无线路由Ping场景和指定出接口冲突。

- 本端同网段外联口间Ping场景必须指定出接口。

当前存在三类PING调测命令：PING、INNERPING、NGPING，差异如下。

- **PING**：该命令用于排查本网元**外联口IP**与对端设备之间是否可以PING通。

**INNERPING、NGPING**

：该命令用于排查本网元

**业务IP**

与对端设备之间是否可以PING通。INNERPING适用场景如下表所示，其他场景均使用NGPING。

| NF形态     | 接口           | 业务IP配置方式       |
|:---------|:-------------|:---------------|
| SGSN/MME | ALL          | ADD SERVICEIP  |
| AMF      | N2           | ADD SERVICEIP  |
| AMF      | DNS接口        | ADD SERVICEIP  |
| SMSF     | MAP接口        | ADD SERVICEIP  |
| CHF      | Ga（内部）Server | ADD IPRESOURCE |
| CHF      | Bi           | ADD IPRESOURCE |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识              | 参数名称        | 参数说明                                                                                                                                                                         |
|:------------------|:------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPVERSION         | IP协议版本号     | 可选必选说明：必选参数 参数含义：该参数用于指定发送ECHO-REQUEST报文的IP协议版本。 数据来源：本端规划 取值范围：枚举类型。 IPv4：IPv4协议族。IPv6：IPv6协议族。 默认值：无                                                                       |
| VPNNAME           | VPN实例名称     | 可选必选说明：可选参数 参数含义：该参数用于指定VPN实例名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                                                                                                      |
| SOURCEIPV4ADDRESS | 源IPv4地址     | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPv4”时为可选参数。 参数含义：该参数用于指定发送ECHO-REQUEST报文的源IPv4地址。可使用LST INTERFACE和LST IFIPV4ADDRESS获取接口地址信息。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无           |
| SOURCEIPV6ADDRESS | 源IPv6地址     | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPv6”时为可选参数。 参数含义：该参数用于指定发送ECHO-REQUEST报文的源IPv6地址。可使用LST INTERFACE和LST IFIPV6ADDRESS获取接口地址信息。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无           |
| DESTIPV4ADDRESS   | 目的IPv4地址    | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPv4”时为必选参数。 参数含义：该参数用于指定目的主机IPv4地址。可使用LST INTERFACE和LST IFIPV4ADDRESS获取接口地址信息。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无                         |
| DESTIPV6ADDRESS   | 目的IPv6地址    | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPv6”时为必选参数。 参数含义：该参数用于指定目的主机IPv6地址。可使用LST INTERFACE和LST IFIPV6ADDRESS获取接口地址信息。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无                         |
| PACKETCOUNT       | 发包数         | 可选必选说明：可选参数 参数含义：该参数用于指定发送ECHO-REQUEST报文次数。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295，单位是包数。 默认值：5                                                                               |
| PACKETSIZE        | 报文字节数       | 可选必选说明：可选参数 参数含义：该参数用于指定ECHO-REQUEST报文的有效载荷长度。 数据来源：本端规划 取值范围：整数类型，取值范围为20～9600，单位是字节。 默认值：56                                                                                |
| INTERVAL          | 报文间隔（ms）    | 可选必选说明：可选参数 参数含义：该参数用于指定发送下一个ECHO-REQUEST报文的等待时间。 数据来源：本端规划 取值范围：整数类型，取值范围为100～10000，单位是毫秒。 默认值：500                                                                          |
| TIMEOUT           | 超时时间（ms）    | 可选必选说明：可选参数 参数含义：该参数用于指定发送完ECHO-REQUEST报文后，等待ECHO-REPLY报文的超时时间。 数据来源：本端规划 取值范围：整数类型，取值范围为1～20000，单位是毫秒。 默认值：2000                                                             |
| TTL               | TTL值        | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPv4”时为可选参数。 参数含义：该参数用于指定TTL的值。 数据来源：本端规划 取值范围：整数类型，取值范围为1～255。 默认值：255                                                                |
| TOSORDSCP         | 基于TOS或者DSCP | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPv4”时为可选参数。 参数含义：该参数用于指定发送ECHO-REQUEST报文是基于TOS还是DSCP。 数据来源：本端规划 取值范围：枚举类型。 TOS：TOS服务类型。DSCP：DSCP服务类型。 默认值：无 配置原则：如果不输入该参数，则实际生效值为TOS。 |
| DSCP              | DSCP值       | 可选必选说明：条件可选参数 前提条件：该参数在“TOSORDSCP”配置为“DSCP”时为可选参数。 参数含义：该参数用于指定发送ECHO-REQUEST报文的DSCP值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～63。 默认值：0                                                  |
| TOS               | TOS值        | 可选必选说明：条件可选参数 前提条件：该参数在“TOSORDSCP”配置为“TOS”时为可选参数。 参数含义：该参数用于指定发送ECHO-REQUEST报文的TOS值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～255。 默认值：0                                                   |
| OBIFNAME          | 出接口名称       | 可选必选说明：可选参数 参数含义：该参数用于指定发送ECHO-REQUEST报文的接口。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。                                                          |
| VERBOSE           | 详细回显        | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPv4”时为可选参数。 参数含义：该参数用于显示PING详细回显信息。 数据来源：本端规划 取值范围：枚举类型。 ENABLE：使能。DISABLE：去使能。 默认值：无 配置原则：如果不输入该参数，则表示不显示详细信息。                       |
