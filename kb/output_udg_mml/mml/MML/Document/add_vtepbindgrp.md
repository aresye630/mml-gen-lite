# 增加VXLAN隧道端点绑定隧道组（ADD VTEPBINDGRP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于添加VXLAN隧道端点与VXLAN隧道组的绑定关系。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为512。
- 每个VXLAN组最多可以配置8个主隧道端点和8个备隧道端点。
- VXLAN隧道组和IPFARM开启心跳检测的链路，共可以配置512个，超出规格的链路，心跳检测失效，并且不会自动开启，链路为断开状态。
- 如果VXLAN隧道组已经被5G LAN会话实例绑定，要确保不同5G LAN会话实例不能使用相同的VNI和VTEP，否则会配置失败。
- 绑定到同一个VXLAN组的隧道端点要确保业务处理能力一致，如果隧道端点的业务处理能力不一致，则应新增VXLAN组绑定该隧道端点承载业务。
- 配置该命令时，若新加的VTEP和本组内的已有VTEP业务处理能力相同，则增加到本VxLAN组；若不一样，需要绑定到新的VxLAN组。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                                                    |
|:-------------|:---------|:------------------------------------------------------------------------------------------------------------------------|
| VXLANGRPNAME | VXLAN组名称 | 可选必选说明：必选参数 参数含义：该参数用于指定VXLAN隧道组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用 ADD VXLANGRP命令配置生成。 |
| VTEPNAME     | VTEP名称   | 可选必选说明：必选参数 参数含义：该参数用于指定VXLAN隧道端点名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用 ADD VTEP命令配置生成。    |
| PRIFLAG      | 主备用类型    | 可选必选说明：可选参数 参数含义：指定VXLAN隧道端点主备用类型。 数据来源：本端规划 取值范围：枚举类型。 PRIMARY：主用。SECONDARY：备用。 默认值：PRIMARY 配置原则：无                     |

#### 使用实例

配置隧道端点vtep1绑定在VXLAN隧道组vxlangrp上，且设置为主用类型：

```
ADD VTEPBINDGRP: VXLANGRPNAME="vxlangrp", VTEPNAME="vtep1", PRIFLAG=PRIMARY;
```
