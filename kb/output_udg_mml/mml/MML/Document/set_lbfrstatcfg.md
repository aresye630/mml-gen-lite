# 设置CSLB分片重组统计配置（SET LBFRSTATCFG）

- 命令功能
- 注意事项。
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

本命令属于高危命令，操作不当会导致业务受损，请谨慎使用并联系华为技术支持协助操作。

该命令用于设置DSP LBFRAGRSSTAT统计分片资源topN高的对端IP地址的参数。

#### 注意事项。

该命令存在系统初始记录，参数的初始设置值如下表：

| PEERIPSTATSW   |   FRAGSTATTHD |
|:---------------|--------------:|
| SW_DISABLE     |           200 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称          | 参数说明                                                                                                                                                                              |
|:-------------|:--------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PEERIPSTATSW | 基于对端IP的统计开关   | 可选必选说明：可选参数 参数含义：该参数用于指定是否统计分片资源topN高的对端IP地址。 数据来源：本端规划 取值范围：枚举类型 SW_ENABLE(基于对端IP的统计开关开启)：CSLB统计分片资源topN高的对端IP地址。SW_DISABLE(基于对端IP的统计开关关闭)：CSLB不统计分片资源topN高的对端IP地址。 默认值：无 配置原则：无 |
| FRAGSTATTHD  | 基于对端IP的统计开关阈值 | 可选必选说明：可选参数 参数含义：该参数用于配置IP分片报文占用资源数阈值。当某个DSCP值对应的分片资源数达到该配置值后，记录该DSCP值的对端IP地址，并统计该IP地址的分片报文数量。 数据来源：本端规划 取值范围：整数类型，取值范围为50～5000。 默认值：无 配置原则：无                                     |

#### 使用实例

设置基于对端IP的统计开关为开启，基于对端IP的统计开关阈值为200，命令如下：

```
SET LBFRSTATCFG: PEERIPSTATSW=SW_ENABLE, FRAGSTATTHD=200;
```
