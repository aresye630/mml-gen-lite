# 修改IPv6 Path MTU配置（MOD IPV6PATHMTU）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改IPv6路径MTU配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称         | 参数说明                                                                            |
|:------------|:-------------|:--------------------------------------------------------------------------------|
| IPV6ADDRESS | IPv6地址       | 可选必选说明：必选参数 参数含义：该参数用于表示IPv6地址。 数据来源：全网规划 取值范围：IPv6地址类型。 默认值：无                  |
| VRFNAME     | VPN名称        | 可选必选说明：必选参数 参数含义：该参数用于表示VPN名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无          |
| PATHMTU     | 路径MTU值（byte） | 可选必选说明：必选参数 参数含义：该参数用于表示路径MTU。 数据来源：全网规划 取值范围：整数类型，取值范围为1280～10000，单位是字节。 默认值：无 |

#### 使用实例

修改IPv6 Path MTU配置：

```
MOD IPV6PATHMTU:VRFNAME="vpn1",IPV6ADDRESS="2001:db8::11",PATHMTU=1500;
```
