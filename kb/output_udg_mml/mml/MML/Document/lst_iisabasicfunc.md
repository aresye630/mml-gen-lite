# 查询SA基本功能（LST IISABASICFUNC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明

#### 命令功能

**适用NF：PGW-U、UPF**

此命令用于查询SA基本功能相关参数。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询SA基本功能：

```
%%LST IISABASICFUNC:;
```

```
%%
RETCODE = 0  操作成功

结果如下
--------
          分析开关  =  不使能
(结果个数 = 1)

---    END
```
