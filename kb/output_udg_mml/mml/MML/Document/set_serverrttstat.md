# 设置服务器时延统计功能（SET SERVERRTTSTAT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、PGW-U、SGW-U、GGSN**

**须知** 

本命令属于高危命令，此命令开启后可能导致性能下降明显。执行命令前请评估对性能的影响，如果无法评估请联系华为技术支持。

该命令用于设置统计服务器时延统计功能。如果现网需要基于特定协议类型的CDN或DNS服务器进行进延统计，则开启开关并选择需要统计的应用类型。

#### 注意事项

- 该命令执行后仅对新流生效，老流不生效。
- 该命令最大记录数为1。
- 针对开启时延统计的协议，网元自动学习并保存使用该协议的前1000个IP地址，对访问该服务器的业务流进行流量统计，并按10%的抽样率进行时延统计。
- 如果同一个服务器IP同时部署了多种协议的服务，按首次统计到的协议类型统计流量和时延，不统计到其他类型的协议流量和时延中。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | RTTSTATSW   |   PROTOCOLLIST |   STATDURATION |
|:-------|:------------|---------------:|---------------:|
| 初始值    | DISABLE     |            nan |              1 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称        | 参数说明                                                                                                                                                                                                                                                            |
|:-------------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RTTSTATSW    | 服务器时延统计开关   | 可选必选说明：必选参数 参数含义：该参数用于设置服务器时延统计开关。 数据来源：本端规划 取值范围： DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无                                                                                                                                                                          |
| PROTOCOLLIST | 服务器时延统计协议列表 | 可选必选说明：条件必选参数 前提条件：该参数在“RTTSTATSW”配置为“ENABLE”时为必选参数。 参数含义：该参数用于设置开启时延统计的服务器协议类型。开启时延统计开关时，至少需要选择一种协议。 数据来源：本端规划 取值范围：时延统计开关至少选择一个协议。 FACEBOOK：Facebook协议CDN服务器。TIKTOK：Tiktok协议CDN服务器。YOUTUBE：Youtube协议CDN服务器。NETFLIX：Netflix协议CDN服务器。DNS：DNS协议服务器。 默认值：无 配置原则：无 |
| STATDURATION | 时延统计时长      | 可选必选说明：条件可选参数 前提条件：该参数在“RTTSTATSW”配置为“ENABLE”时为可选参数。 参数含义：该参数用于设置时延统计的统计时长。 数据来源：本端规划 取值范围：整数类型，取值范围为1～7，单位是天。 默认值：无 配置原则：无                                                                                                                                     |

#### 使用实例

对协议类型是Facebook的服务器 开启时延统计功能，统计周期为2天：

```
SET SERVERRTTSTAT: RTTSTATSW=ENABLE, PROTOCOLLIST=FACEBOOK-1&TIKTOK-0&YOUTUBE-0&NETFLIX-0&DNS-0, STATDURATION=2;
```
