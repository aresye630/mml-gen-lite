# 新增高带宽用户属性（ADD HBUSRATTRCONF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于新增高带宽用户属性。

#### 注意事项

- 该命令执行后只对新激活用户生效。
- 该命令最大记录数为8。
- 在同一条高带宽用户属性命令中，不同的过滤条件为与关系，即所有过滤条件均匹配中，才认为匹配中高带宽用户。
- 用户的高带宽用户属性变化后，对新流生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

新增指定UsrAttrCondNm1为高带宽用户的高带宽用户属性：

```
ADD HBUSRATTRCONF: CONFNAME="conf1", USRATTRCONDNM1="UsrAttrCondNm1";
```
