# 查询COS TOS映射策略（LST COSTOS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于查询是否使能Cos Tos映射策略。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询是否使能Cos Tos映射策略：

```
LST COSTOS:;
```

```
RETCODE = 0  操作成功。

结果如下
--------
TOS策略  =  不使能
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见SET COSTOS的参数说明。
