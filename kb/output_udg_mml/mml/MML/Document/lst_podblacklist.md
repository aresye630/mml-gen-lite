# 查询Pod自愈黑名单（LST PODBLACKLIST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询Pod自愈黑名单。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询Pod自愈黑名单。

```
%%LST PODBLACKLIST:;%%
RETCODE = 0  操作成功

结果如下
--------
Pod类型     

ipctrl-pod  
sbim-pod    
(结果个数 = 2)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                   |
|:--------|:----------------------------------------|
| Pod类型   | 该参数用于指示Pod自愈黑名单的Pod类型。可通过DSP PODINFO查询。 |
