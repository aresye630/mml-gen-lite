# 增加ACL规则组（ADD ACLGROUPIPSEC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于增加ACL规则组。

## 注意事项

- 该命令执行后立即生效。

- 当参数ACLNAME为非数字时，ACLTYPE参数默认为高级ACL。

- 最多可输入65535条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                                                                                                |
|:---------------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ACLNAME        | ACL规则组标识 | 可选必选说明：必选参数  参数含义：该参数用于指定规则组名称或是编号。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。不支持空格，区分大小写。以英文字母a～z或A～Z开始，可以是英文字母、数字、连字符“-”、下划线“_”或中文字符的组合。整数形式，取值范围是3000～3999（高级ACL），但兼容CE版本，允许配置其他数值但不会生效。  默认值：无  配置原则：无 |
| ACLSTEP        | 规则组步长    | 可选必选说明：可选参数  参数含义：该参数用于指定规则组规则步长，仅当不指定规则ID时生效。  数据来源：本端规划  取值范围：整数类型，取值范围是1~20。  默认值：5  配置原则：无                                                                                                      |
| ACLTYPE        | 规则组类型    | 可选必选说明：可选参数  参数含义：该参数用于指定规则组类型。如果不输入该参数，当参数ACLNAME为非数字时，该参数默认为高级ACL。  数据来源：本端规划 取值范围： “Basic（基本ACL）”：基本ACL规则。“Advance（高级ACL）”：高级ACL规则。  默认值：无  配置原则：无                                               |
| ACLMATCHORDER  | 规则的匹配顺序  | 可选必选说明：可选参数  参数含义：该参数用于指定规则的匹配顺序是深度优先还是配置优先。  数据来源：本端规划 取值范围： “Config（规则组下的规则按照配置优先排序）”：配置优先。“Auto（规则组下的规则按照深度优先自动排序）”：深度优先。  默认值：Config  配置原则：无                                                    |
| ACLDESCRIPTION | 规则组描述    | 可选必选说明：可选参数  参数含义：该参数用于指定ACL规则组描述信息。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~127。支持空格，区分大小写。  默认值：无  配置原则：  建议取有实际意义的名称，以方便识别。                                                                              |

## 使用实例

用户想通过流分类进行报文过滤或重定向，需要绑定ACL规则组，可以创建编号为3005的ACL规则组：

```
ADD ACLGROUPIPSEC: ACLNAME="3005";
```
