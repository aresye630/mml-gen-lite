# 删除HTTP流控组（RMV HTTPFCIPGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除HTTP固定速率流控的IP地址组信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                        |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------|
| RMVTYPE | 删除类型   | 可选必选说明：必选参数  参数含义：该参数用于指定待删除的HTTP固定速率流控组类型。  数据来源：本端规划 取值范围： “INDEX（索引）”：HTTP固定速率流控IP地址组索引“GROUP（流控组）”：HTTP固定速率流控IP地址组唯一标识  默认值：无  配置原则：无   |
| INDEX   | 索引     | 可选必选说明：该参数在"RMVTYPE"配置为"INDEX"时为条件必选参数。  参数含义：该参数用于标识具有相同前缀的一组IP地址。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4095。  默认值：无  配置原则：无                       |
| GROUP   | 流控组    | 可选必选说明：该参数在"RMVTYPE"配置为"GROUP"时为条件必选参数。  参数含义：该参数用于指定HTTP固定速率流控组的唯一标识。一个流控组中可以包括多个IP地址索引。  数据来源：全网规划  取值范围：整数类型，取值范围是0~4095。  默认值：无  配置原则：无 |

## 使用实例

删除索引为1的HTTP固定速率流控地址组信息：

```
RMV HTTPFCIPGRP:RMVTYPE=INDEX, INDEX=1;
```
