# 修改NSH头增强（MOD NSHHEADEN）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用来修改一个NSH头增强的相关配置。

#### 注意事项

- 该命令执行后立即生效。
- 不同datatype对应的TAGVALUE不能重复。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称      | 参数说明                                                                                                                                                                                                                                                           |
|:---------------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NSHNAME        | NSH头增强名称  | 可选必选说明：必选参数 参数含义：该参数用于设置NSH头增强名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                                                                                                  |
| DATATYPE       | 数据类型      | 可选必选说明：必选参数 参数含义：该参数用于设置NSH头增强的数据类型。 数据来源：本端规划 取值范围：枚举类型。 MSISDN1：指定插入项的类型为MSISDN。IMSI1：指定插入项的类型为IMSI。IMEI1：指定插入项的类型为IMEI。RAT1：指定插入项的类型为RAT。ULI1：指定插入项的类型为ULI。MCC_MNC1：指定插入项的类型为MCC_MNC1。 默认值：无 配置原则：无                                                         |
| TAGVALUE       | TAG编码     | 可选必选说明：条件可选参数 前提条件：该参数在“DATATYPE”配置为“MSISDN1”、“IMSI1”、“IMEI1”、“RAT1”、“ULI1” 或 “MCC_MNC1”时为可选参数。 参数含义：该参数用于设置NSH头增强数据类型对应的TAG编码。 数据来源：本端规划 取值范围：整数类型，取值范围为0～255。 默认值：无 配置原则：无                                                                                   |
| REMOVEDMCC     | 需去除的移动国家码 | 可选必选说明：条件可选参数 前提条件：该参数在“DATATYPE”配置为“MSISDN1”时为可选参数。 参数含义：该参数用于指定头增强动作插入MSISDN字段需要去除的国家码信息。 数据来源：本端规划 取值范围：字符串类型，0~4位数字。 默认值：无 配置原则： 输入单空格将删除该参数已有配置项。该字符串为空时，代表无需去除用户的MSISDN信息中国家码。                                                                           |
| ENCRYALGORI    | 加密算法标识    | 可选必选说明：条件可选参数 前提条件：该参数在“DATATYPE”配置为“IMEI1”、“IMSI1”、“MCC_MNC1”、“MSISDN1”、“RAT1” 或 “ULI1”时为可选参数。 参数含义：该参数用于指定对携带的参数的加密方式。 数据来源：本端规划 取值范围：枚举类型。 NONE：表示不进行加密，有安全风险，不建议使用。SHA256：表示加密类型为SHA256。 默认值：SHA256 配置原则：请根据需求选择相应加密算法，建议使用SHA256加密算法，当配置NONE时有安全风险，不建议使用。 |
| PSWDKEY        | 密钥        | 可选必选说明：条件必选参数 前提条件：该参数在“ENCRYALGORI”配置为“SHA256”时为必选参数。 参数含义：该参数用于设置用于参数加密算法的密钥。 数据来源：本端规划 取值范围：密钥类型，输入长度范围为1～256。不支持空格。 默认值：无 配置原则：无                                                                                                                           |
| PSWDKEYCONFIRM | 确认密钥      | 可选必选说明：条件必选参数 前提条件：该参数在“ENCRYALGORI”配置为“SHA256”时为必选参数。 参数含义：该参数用于确认加密算法的密钥。 数据来源：本端规划 取值范围：密钥类型，输入长度范围为1～256。不支持空格。 默认值：无 配置原则：无                                                                                                                               |
| CFGDOMAINNAME  | 配置域名称     | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。                                                                                                                                                             |

#### 使用实例

假如运营商希望把名称为“nsh”的NSH头增强修改为支持插入MSISDN，TAG编码值为1，选择SHA256加密方式，密钥为XXXXXX：

```
MOD NSHHEADEN: NSHNAME="nsh", DATATYPE=MSISDN1, TAGVALUE=1, ENCRYALGORI=SHA256, PSWDKEY="*****", PSWDKEYCONFIRM="*****";
```
