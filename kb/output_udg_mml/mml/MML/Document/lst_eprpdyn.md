# 查询EPRPDYN对象（LST EPRPDYN）

- 命令功能
- 注意事项
- 操作用户权限

- 输出结果说明

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于查询EPRPDYN对象。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                                                          |
|:--------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INTERFACETYPE | 接口类型   | 可选必选说明：必选参数 参数含义：接口类型。 数据来源：本端规划 取值范围：枚举类型。 S5S8PGW：接口类型为S5S8PGW，最大配置规格为12。S5S8SGW：接口类型为S5S8SGW，最大配置规格为12。N3UPF：接口类型为N3，最大配置规格为12。N9UPF：接口类型为N9，最大配置规格为12。S1USGW：接口类型为S1U，最大配置规格为12。S11USGW：接口类型为S11U，最大配置规格为12。 默认值：无 配置原则：无 |

#### 使用实例

查询接口类型为S5S8PGW的EPRPDYN对象：

```
LST EPRPDYN: INTERFACETYPE=S5S8PGW;
```

```
RETCODE = 0  操作成功。

结果如下
--------
接口类型  =  S5S8PGW
对象名称  =  pgw1
(结果个数 = 1)
---    END
```
