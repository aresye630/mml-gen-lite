# 清除组播组引流信息表项（RTR MCASTPAEGROUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来清除组播组引流信息表项。

#### 注意事项

- 该命令执行后立即生效。
- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称        | 参数说明                                                                                                           |
|:--------------|:------------|:---------------------------------------------------------------------------------------------------------------|
| ADDRESSFAMILY | 地址族         | 可选必选说明：必选参数 参数含义：该参数用于表示地址族类型。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。 默认值：无                                  |
| VRFNAME       | VPN实例名称     | 可选必选说明：必选参数 参数含义：该参数用来表示VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：通过LST L3VPNINST查看当前已存在的VPN实例。    |
| PAEGROUPID    | PAE Group索引 | 可选必选说明：可选参数 参数含义：该参数用来表示PAE Group索引。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无 配置原则：如果不输入该参数，则表示清除所有的PAE表项。 |
| GRPADDR       | 组地址         | 可选必选说明：条件可选参数 前提条件：该参数在“ADDRESSFAMILY”配置为“ipv4unicast”时为可选参数。 参数含义：该参数用来表示组地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无  |
| PAEJOINTYPE   | 引流类型        | 可选必选说明：必选参数 参数含义：该参数用来表示引流类型。 数据来源：本端规划 取值范围：枚举类型。 IPTV：IPTV模式。BIDIR-CPE：BIDIR-CPE模式。 默认值：无                    |

#### 使用实例

清除组播引流信息：

```
RTR MCASTPAEGROUP:VRFNAME="_public_",ADDRESSFAMILY=ipv4unicast,PAEJOINTYPE=IPTV;
```
