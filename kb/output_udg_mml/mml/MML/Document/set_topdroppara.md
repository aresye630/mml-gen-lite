# 设置TOP丢包统计参数（SET TOPDROPPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用户设置TOP丢包统计功能参数。用于设置系统TOP丢包统计功能开关、丢包场景、统计周期等参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | SWITCH   |   USERPERIOD |   TOPPERIOD |   DROPTHD |
|:-------|:---------|-------------:|------------:|----------:|
| 初始值    | ENABLE   |           10 |         300 |        20 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称        | 参数说明                                                                                                                                       |
|:-----------|:------------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| SWITCH     | TOP丢包统计开关   | 可选必选说明：可选参数 参数含义：该参数用于配置TOP丢包统计功能开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能（关闭）。ENABLE：使能（开启）。 默认值：ENABLE 配置原则：无                                 |
| APN        | TOP丢包统计APN  | 可选必选说明：条件可选参数 前提条件：该参数在“SWITCH”配置为“ENABLE”时为可选参数。 参数含义：该参数用于指定APN名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不区分大小写。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。 |
| SCENARIO   | TOP丢包统计场景   | 可选必选说明：条件可选参数 前提条件：该参数在“SWITCH”配置为“ENABLE”时为可选参数。 参数含义：该参数用于设置TOP丢包统计场景。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无 配置原则：输入0表示统计所有丢包场景。       |
| USERPERIOD | TOP丢包统计用户周期 | 可选必选说明：条件可选参数 前提条件：该参数在“SWITCH”配置为“ENABLE”时为可选参数。 参数含义：该参数用于设置TOP丢包统计用户周期。 数据来源：本端规划 取值范围：整数类型，取值范围为1～60，单位是秒。 默认值：无 配置原则：无                |
| TOPPERIOD  | TOP丢包统计周期   | 可选必选说明：条件可选参数 前提条件：该参数在“SWITCH”配置为“ENABLE”时为可选参数。 参数含义：该参数用于设置TOP丢包统计周期。 数据来源：本端规划 取值范围：整数类型，取值范围为120～600，单位是秒。 默认值：无 配置原则：无               |
| DROPTHD    | TOP丢包统计丢包阈值 | 可选必选说明：条件可选参数 前提条件：该参数在“SWITCH”配置为“ENABLE”时为可选参数。 参数含义：该参数用于设置TOP丢包统计丢包阈值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～10000。 默认值：无 配置原则：无                  |

#### 使用实例

设置TOP丢包统计周期为500秒：

```
SET TOPDROPPARA: SWITCH=ENABLE, TOPPERIOD=500;
```
