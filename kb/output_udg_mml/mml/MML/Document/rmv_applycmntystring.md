# 删除团体属性值设置（RMV APPLYCMNTYSTRING）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除应用团体属性值。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                      |
|:-------------|:---------|:--------------------------------------------------------------------------|
| POLICYNAME   | 路由策略名字   | 可选必选说明：必选参数 参数含义：该参数用于指定路由策略名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无  |
| NODESEQUENCE | 路由策略节点ID | 可选必选说明：必选参数 参数含义：该参数用于指定路由策略节点ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无 |
| STRINGVALUE  | 团体属性字符串  | 可选必选说明：必选参数 参数含义：该参数用于指定团体属性值。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～51。 默认值：无    |

#### 使用实例

删除设置团体属性的操作值：

```
RMV APPLYCMNTYSTRING:NODESEQUENCE=10,POLICYNAME="a",STRINGVALUE="1"
```
