# 查询地址池信息（LST POOLINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF、PGW-U**

该命令用于查询地址池相关的信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                              |
|:----------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| QUERYTYPE | 查询方式   | 可选必选说明：必选参数 参数含义：该参数用于指定查询方式。 数据来源：本端规划 取值范围：枚举类型。 POOL：通过POOL查询地址池信息。APN：通过APN查询地址池信息。 默认值：POOL 配置原则：无                                                                                                                           |
| POOLNAME  | 地址池名称  | 可选必选说明：条件必选参数 前提条件：该参数在“QUERYTYPE”配置为“POOL”时为必选参数。 参数含义：地址池的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～79，单位是字节。由“_”、“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”，不区分大小写。 默认值：无 配置原则：无                                                          |
| APN       | APN名称  | 可选必选说明：条件必选参数 前提条件：该参数在“QUERYTYPE”配置为“APN”时为必选参数。 参数含义：APN实例名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”特殊字符，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

- 基于POOL查询“pool1”下的地址池信息：

  ```
  LST POOLINFO: QUERYTYPE=POOL, POOLNAME="pool1";
  ```

  ```
  RETCODE = 0 操作成功。

  结果如下
  ----------
  地址池名称  地址池组名称  APN名称  SMF名称  映射规则名称  位置区组类型  位置区组名称  移动国家码   移动网络号   IP地址类型

  pool1       group1        apn1     smf01    map1          NONE          NULL          NULL         NULL         IPv4
  pool1       group1        apn10    smf01    map10         NONE          NULL          NULL         NULL         IPv4
  (结果个数 = 2)

  --- END
  ```
- 基于APN查询“apn1”下的地址池信息：

  ```
  LST POOLINFO: QUERYTYPE=APN, APN="apn1";
  ```

  ```
  RETCODE = 0 操作成功。

  结果如下
  ----------
  地址池名称  地址池组名称  APN名称  SMF名称  映射规则名称  位置区组类型  位置区组名称  移动国家码   移动网络号   IP地址类型

  pool1       group1        apn1     smf01    map1          NONE          NULL          NULL         NULL         IPv4
  pool2       group2        apn1     smf01    map10         NONE          NULL          NULL         NULL         IPv4
  (结果个数 = 2)

  --- END
  ```

| 位置区组名称  | 位置组名称。       |
| 移动国家码   | 移动国家码。       |
| 移动网络号   | 移动网络号。       |
| IP地址类型  | IP地址类型。      |
