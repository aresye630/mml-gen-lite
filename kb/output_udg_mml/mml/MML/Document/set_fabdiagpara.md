# 设置Pod Fabric平面亚健康诊断参数（SET FABDIAGPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用来设置Pod Fabric平面亚健康诊断参数。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

|   PODSUBHEALTHD |
|----------------:|
|              50 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称        | 参数说明                                                                                                 |
|:--------------|:------------|:-----------------------------------------------------------------------------------------------------|
| PODSUBHEALTHD | POD亚健康阈值(%) | 可选必选说明：必选参数  参数含义：该参数用于指定Pod级fabric平面亚健康诊断阈值，单位：%。  数据来源：本端规划  取值范围：整数类型，取值范围是1~100。  默认值：无。  配置原则：无 |

## 使用实例

设置Pod Fabric平面亚健康诊断参数为50%。

```
SET FABDIAGPARA: PODSUBHEALTHD=50;
```
