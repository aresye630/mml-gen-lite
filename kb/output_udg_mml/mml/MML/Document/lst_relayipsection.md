# 查询媒体中继IP段（LST RELAYIPSECTION）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询媒体中继IP段。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                        |
|:----------|:-------|:----------------------------------------------------------------------------------------------------------------------------|
| POOLNAME  | IP池名   | 可选必选说明：可选参数 参数含义：该参数用于指定媒体中继IP段对应的IP池名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：IP池名与IP段ID不能与已有媒体中继IP段冲突。 |
| SECTIONID | IP段ID  | 可选必选说明：可选参数 参数含义：该参数用于指定媒体中继IP段ID。 数据来源：本端规划 取值范围：整数类型，取值范围0~4294967295。 默认值：无 配置原则：IP池名与IP段ID不能与已有媒体中继IP段冲突。               |

#### 使用实例

假设需要查询媒体中继IP段，则命令如下：

```
LST RELAYIPSECTION:;
```
