# 查询接口IPv6使能（LST IFIPV6ENABLE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询使能了IPv6的接口的IPv6接口最大传输单元和自动生成链路层地址标志。

#### 注意事项

- 该命令执行后立即生效。
- 该命令在VNRS\_VNFC上的Ethernet接口，Ethernet子接口以及Loopback口，Tunnel口上配置执行。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                        |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------|
| IFNAME | 接口名    | 可选必选说明：可选参数 参数含义：该参数用于配置IPv6使能的接口名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。接口名称由接口类型+接口编号组成。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。 |

#### 使用实例

查询接口的IPv6使能信息：

```
LST IFIPV6ENABLE:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
接口名                  IPv6使能标志    IPv6接口最大传输单元（byte）    自动生成链路层地址标志
Ethernet64/0/3          使能            1500                            FALSE
Ethernet64/0/4          使能            1500                            FALSE
(结果个数 = 2)
---     END
```
