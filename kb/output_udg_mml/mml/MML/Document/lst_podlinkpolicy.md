# 查询Pod级链路策略（LST PODLINKPOLICY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此命令用于查看Pod级链路策略。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                           |
|:-----------|:-------|:---------------------------------------------------------------------------------------------------------------|
| PEERNFTYPE | 对端网元类型 | 可选必选说明：可选参数  参数含义：该参数用于指定使用Pod级链路策略的NF类型。  数据来源：本端规划 取值范围： “SEPP（SEPP）”：该参数用于指定使用Pod级链路策略的NF类型。  默认值：无  配置原则：无 |

## 使用实例

查询对端网元为SEPP的Pod级链路策略。

```
%%LST PODLINKPOLICY: PEERNFTYPE=SEPP;%%
RETCODE = 0  操作成功

结果如下
--------
 对端网元类型  =  SEPP
Pod级链路控制  =  开启
Pod级链路数量  =  1
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称    | 输出项解释                   |
|:---------|:------------------------|
| 对端网元类型   | 该参数用于指定使用Pod级链路策略的NF类型。 |
| Pod级链路控制 | 该参数用于指定是否开启Pod级链路控制。    |
| Pod级链路数量 | 该参数用于指定Pod级链路的数量。       |
