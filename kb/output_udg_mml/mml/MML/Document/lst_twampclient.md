# 查询TWAMP客户端（LST TWAMPCLIENT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询TWAMP客户端。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                               |
|:---------|:-------|:-----------------------------------------------------------------------------------|
| CLIENTID | 客户端ID  | 可选必选说明：可选参数  参数含义：该参数用于配置客户端ID。  数据来源：全网规划  取值范围：整数类型，取值范围是1~12000。  默认值：无  配置原则：无 |

## 使用实例

查询客户端ID为1的实例：

```
%%LST TWAMPCLIENT: CLIENTID=1;%%
RETCODE = 0  操作成功

结果如下
--------
       客户端ID  =  1
      TWAMP架构  =  LIGHT
      地址族类型  =  IPV4
    本端IPV4地址  =  10.0.0.0
    对端IPV4地址  =  192.168.0.0
     本端UDP端口  =  65450
     对端UDP端口  =  1
      差分服务码  =  0
     VPN实例名称  =  ck
            描述  =  1
(结果个数 = 1)

---    END
```

| 本端IPV4地址 | 该参数用于指示本端IPv4地址。 |
| 对端IPV4地址 | 该参数用于指示对端IPv4地址。 |
| 本端UDP端口  | 该参数用于配置本端UDP端口。  |
| 对端UDP端口  | 该参数用于配置对端UDP端口。  |
| 差分服务码    | 该参数用于配置差分服务码。    |
| VPN实例名称  | 该参数用于配置VPN实例名称。  |
