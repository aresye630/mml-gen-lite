# 删除指定的LAC组（RMV LACGROUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用来删除指定的LAC组。

#### 注意事项

- 该命令执行后只对新激活用户生效。
- 当LAC组下绑定LAC号段时，同时可以删除该LAC组下的所有绑定的LAC号段。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                       |
|:-------------|:--------|:-------------------------------------------------------------------------------------------|
| LACGROUPNAME | 指定LAC组名 | 可选必选说明：必选参数 参数含义：该参数用于指定LAC组名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

假设运营商需要去删除一个本地已经配置的LAC组beijing：

```
RMV LACGROUP:LACGROUPNAME="beijing";
```
