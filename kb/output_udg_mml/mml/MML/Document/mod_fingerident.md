# 修改SA指纹识别配置（MOD FINGERIDENT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用来修改SA指纹识别功能配置。

#### 注意事项

- 该命令执行后立即生效。
- 该命令仅用于修改参数FingerIdentCtrl或CfgDomainName。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称       | 参数说明                                                                                                                              |
|:----------------|:-----------|:----------------------------------------------------------------------------------------------------------------------------------|
| CFGPROTMODE     | 协议配置方式     | 可选必选说明：必选参数 参数含义：该参数用于设置SA指纹识别功能协议的配置方式。 数据来源：本端规划 取值范围： ALL：所有协议。SPECIFIC：指定协议。 默认值：无 配置原则：无                                     |
| PROTOCOLNAME    | 协议名称       | 可选必选说明：条件必选参数 前提条件：该参数在“CFGPROTMODE”配置为“SPECIFIC”时为必选参数。 参数含义：该参数用于设置协议名称。 数据来源：本端规划 取值范围：不支持空格，不区分大小写。 默认值：无 配置原则：无              |
| FINGERIDENTCTRL | 指纹识别结果控制开关 | 可选必选说明：可选参数 参数含义：该参数用于设置指纹识别结果控制开关。 数据来源：本端规划 取值范围： DISABLE：SA指纹识别结果既用于统计，又参与业务控制。STATIC_ONLY：SA指纹识别结果只用于统计，不参与业务控制。 默认值：无 配置原则：无 |
| CFGDOMAINNAME   | 配置域名称      | 可选必选说明：条件可选参数 前提条件：该参数在“CFGPROTMODE”配置为“SPECIFIC”时为可选参数。 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无   |

#### 使用实例

修改Facebook协议SA指纹识别结果只用于统计不用于业务控制，配置如下：

```
MOD FINGERIDENT: CFGPROTMODE=SPECIFIC, PROTOCOLNAME="facebook", FINGERIDENTCTRL=STATIC_ONLY;
```
