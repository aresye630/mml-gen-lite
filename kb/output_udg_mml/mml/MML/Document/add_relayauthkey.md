# 增加媒体中继鉴权密钥（ADD RELAYAUTHKEY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、PGW-U**

**须知** 

本命令属于高危命令，执行该命令后，会影响媒体中继防盗链校验功能。

该命令用于增加媒体中继鉴权密钥。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为100。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

增加媒体中继鉴权密钥：

```
ADD RELAYAUTHKEY: RELAYAUTHKEYNAME="auth1", MASTERAUTHKEY="*****", MASTERKEYCONFIRM="*****";
```
