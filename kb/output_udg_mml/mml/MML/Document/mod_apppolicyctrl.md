# 修改基于应用的质差上报策略（MOD APPPOLICYCTRL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于修改基于应用的质差上报策略。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称         | 参数说明                                                                                                                                                                                                                                               |
|:---------------|:-------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APPIDNAME      | 应用ID         | 可选必选说明：必选参数 参数含义：该参数用于指定重点业务保障的应用组名称。 数据来源：全网规划 取值范围：字符串类型，区分大小写，长度为1-63位。 默认值：无 配置原则：无                                                                                                                                                            |
| SUBAPPIDNAME   | 子应用ID        | 可选必选说明：必选参数 参数含义：该参数用于指定重点业务保障的应用名称。 数据来源：全网规划 取值范围：字符串类型，区分大小写，长度为1-63位。 默认值：无 配置原则：无                                                                                                                                                             |
| DEFPRTGRPNAME  | 自定义协议组名称     | 可选必选说明：可选参数 参数含义：该参数用于指定自定义的三级协议组名称。 数据来源：本端规划 取值范围：参数来源于ADD SSUPROTCOLGROUP中的DEFPRTGRPNAME。 默认值：无 配置原则：同一个应用ID下不同的子应用ID，不能配置相同的自定义协议组名称。                                                                                                          |
| QOEDETPRD      | 基于应用的质差上报周期  | 可选必选说明：可选参数 参数含义：该参数指定该应用下UPF检测用户业务发生质差时向NWDAF上报单据的时间间隔。 数据来源：本端规划 取值范围：整数类型，取值范围为1~300，单位为秒，必须大于等于SET VVIPBASICFUNC中配置的SAMPLEPERIOD。建议按5秒、10秒和15秒的粒度配置。 默认值：无 配置原则：无                                                                              |
| NONQOEDETPRD   | 基于应用的非质差上报周期 | 可选必选说明：可选参数 参数含义：该参数指定该应用下UPF检测用户业务未发生质差时向NWDAF上报单据的时间间隔。 数据来源：本端规划 取值范围：整数类型，取值范围为1~300，单位为秒。1. 必须大于等于SET VVIPBASICFUNC中配置的SAMPLEPERIOD。2. 建议按60秒粒度配置。3. 体验单据配置周期应当大于BYTE1115中配置的应用结束时延时间，如果BYTE1115未配置，体验单据配置周期应当大于BYTE1115默认值（2秒）。 默认值：无 配置原则：无 |
| MOS            | 平均意见分        | 可选必选说明：可选参数 参数含义：该参数用于配置平均意见分，UPF检测到应用实际的平均意见分不大于该值时，认为该应用质差。 数据来源：本端规划 取值范围：整数类型，取值范围0到100。 默认值：无 配置原则：请填写整数，取值范围为0～100。                                                                                                                          |
| QOERPTPOLICY   | 应用质差上报策略     | 可选必选说明：可选参数 参数含义：该参数用于设置应用质差时的单据上报策略。 数据来源：本端规划 取值范围：枚举类型。 QOE_REPORT_ONCE：检测到质差时新流触发上报。QOE_REPORT_PERIOD：检测到质差时周期触发上报。 默认值：无 配置原则：无                                                                                                               |
| ENDDELAY       | 应用结束延时时间     | 可选必选说明：可选参数 参数含义：应用所有流老化后判断应用结束的等待时间。 数据来源：本端规划 取值范围：整数类型，取值范围0到300，单位为秒。 默认值：无 配置原则：体验单据配置周期应当大于应用结束延时时间。                                                                                                                                         |
| BYPASS         | 业务bypass开关   | 可选必选说明：可选参数 参数含义：业务bypass开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能业务bypass。INSA：使能SA模型业务BYPASS。INQOE：使能QOE模型业务BYPASS。ALL：使能所有模型业务BYPASS。 默认值：无 配置原则：无                                                                                                   |
| ASSURANCELEVEL | 质差保障级别       | 可选必选说明：可选参数 参数含义：该参数用于设置质差保障级别。 数据来源：本端规划 取值范围：枚举类型。 FLOW：流级质差保障SUB_APP：子应用级质差保障 默认值：无 配置原则：无                                                                                                                                                      |
| ULICHANGERPT   | 位置变更上报       | 可选必选说明：条件可选参数 前提条件：该参数在“QOERPTPOLICY”配置为“QOE_REPORT_ONCE”时为可选参数。 参数含义：设置位置变更后发生过质差上报的老流能再触发上报一次质差上报。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：设置位置变更后发生过质差上报的老流不能再触发上报一次质差上报。ENABLE：设置位置变更后发生过质差上报的老流能再触发上报一次质差上报。 默认值：无 配置原则：无                                |
| EXPCTRLFACTOR  | 体验大流阈值系数     | 可选必选说明：可选参数 参数含义：该参数用于设置体验单据的大流阈值系数。 数据来源：本端规划 取值范围：浮点数，精确到十分位，取值范围为0.1～9.9。 默认值：无 配置原则：无                                                                                                                                                          |

#### 使用实例

- 修改应用ID为zhibo，子应用ID为huya的自定义协议组名称为testadc，执行如下命令：

  ```
  MOD APPPOLICYCTRL: APPIDNAME="zhibo", SUBAPPIDNAME="huya", DEFPRTGRPNAME="testadc";
  ```
- 删除应用ID为zhibo，子应用ID为huya配置的MOS值，可以通过MOD APPPOLICYCTRL命令在MOS参数字段中输入一个空格实现，执行命令如下：

  ```
  MOD APPPOLICYCTRL: APPIDNAME="zhibo", SUBAPPIDNAME="huya", MOS=" ";
  ```
