# 设置IP报文ECN功能参数（SET IPECNCTRL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于设置IP报文ECN相关功能参数。

#### 注意事项

- 开启后在收到基站侧发出携带拥塞比例的报文后生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | L4SECNDLSW   |
|:-------|:-------------|
| 初始值    | DISABLE      |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称       | 参数说明                                                                                             |
|:-----------|:-----------|:-------------------------------------------------------------------------------------------------|
| L4SECNDLSW | L4S下行ECN开关 | 可选必选说明：可选参数 参数含义：该参数用于设置下行报文是否使能L4S ECN标记功能。 数据来源：本端规划 取值范围： DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无 |

#### 使用实例

设置下行报文使能L4S ECN标记功能：

```
SET IPECNCTRL: L4SECNDLSW=ENABLE;
```
