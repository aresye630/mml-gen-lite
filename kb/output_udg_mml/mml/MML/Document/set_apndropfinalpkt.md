# 配置指定APN配额耗尽末包动作（SET APNDROPFINALPKT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

本命令用于基于指定APN配置，当配额耗尽时，UPF是否阻塞最后一个超出配额范围的数据报文。

#### 注意事项

- 该命令执行后立即生效。
- 系统最多支持配置10000条APNDROPFINALPKT。
- 该配置初始记录为INHERIT。
- 当UPF上获取不到基于APN的配置时，使用全局配置SET DROPFINALPKT。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN    | APN    | 可选必选说明：必选参数 参数含义：该参数用于指定APN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”特殊字符，不区分大小写。 默认值：无 配置原则：无 |
| SWITCH | SWITCH | 可选必选说明：必选参数 参数含义：该参数用来配置配额耗尽时，是否阻塞最后一个报文。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：最后一个报文不阻塞。ENABLE：最后一个报文阻塞。INHERIT：继承全局配置。 默认值：无 配置原则：无                                                                       |

#### 使用实例

若要配置指定APN，UPF不阻塞最后一个超出配额范围的数据报文：

```
SET APNDROPFINALPKT: APN="net", SWITCH=DISABLE;
```
