# 删除对端公钥（RMV PEERPUBLICKEY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除对端公钥。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                             |
|:-----------|:-------|:---------------------------------------------------------------------------------|
| KEYNAME    | 密钥名称   | 可选必选说明：必选参数 参数含义：密钥名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无                   |
| PUBKEYTYPE | 密钥类型   | 可选必选说明：必选参数 参数含义：密钥类型。 数据来源：本端规划 取值范围：枚举类型。 RSA：RSA公钥。DSA：DSA公钥。ECC：ECC公钥。 默认值：无 |

#### 使用实例

删除类型为RSA、名称为rsa1的对端公钥：

```
RMV PEERPUBLICKEY:KEYNAME="rsa1",PUBKEYTYPE=RSA;
```
