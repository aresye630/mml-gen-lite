# 设置NP安全防攻击CAR规则(SET NPSECPOLICYCAR)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**须知** 

修改CAR参数，影响系统功能和可靠性。参数配置不合理，会导致路由协议等相关报文丢弃，或导致控制面过载。

该命令用来设置IP的安全防攻击CAR规则。

#### 注意事项

- 该命令执行后立即生效。
- 该命令仅适用于NP卡加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称          | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
|:--------|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CARTYPE | 安全协议类型        | 可选必选说明：必选参数 参数含义：该参数用于指定安全协议类型。 数据来源：本端规划 取值范围：枚举类型 OSPF：OSPF协议。 LDP：LDP协议。IPV6_OSPF：IPV6_OSPF协议。IPV6_BGP：IPV6_BGP协议。IPV6_RA：IPV6_RA协议。IPV6_NS：IPV6_NS协议。GRE：GRE协议。IPV6_NA：IPV6_NA协议。BGP：BGP协议。IPV6_TOO_BIG：IPV6_TOO_BIG协议。Trace：IP Trace协议。UNKNOWN：未知协议。IPV6_RS：IPV6_RS协议。ARP_MISS：ARP_MISS协议。IPV4_MFIB_MISS：IPV4_MFIB_MISS协议。IPV6_ICMP：IPV6_ICMP协议。IGMP：IGMP协议。BFD_Trace：BFD_Trace协议。ARP：ARP协议。IPV6_DHCP：IPV6_DHCP协议。PIM：PIM协议。BFD：BFD协议。ICMP：ICMP协议。DHCP：DHCP协议。TOTAL_CAR：TOTAL_CAR。 默认值：无 配置原则：无 |
| CIR     | 承诺信息速率（kbps）  | 可选必选说明：必选参数 参数含义：该参数用于指定安全策略承诺信息速率。 该参数表示正常情况下允许发送的信息速率。即向漏桶发送令牌的速率，单位为kbps。 数据来源：本端规划 取值范围：整数类型，取值范围为1～1000000。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                                        |
| CBS     | 承诺突发尺寸（bytes） | 可选必选说明：可选参数 参数含义：该参数用于指定安全策略承诺突发尺寸。 此参数用于描述令牌桶C的容量，即在按CIR转发数据时允许转发的最大突发IP包尺寸。 数据来源：本端规划 取值范围：整数类型，取值范围为0～9000000。 默认值：无 配置原则：该参数建议大于或等于可能转发的最大IP包长度。如果不设置该参数，CBS的取值通过CIR*187计算得出。                                                                                                                                                                                                                                                                                                                    |
| PIR     | 峰值信息速率（kbps）  | 可选必选说明：可选参数 参数含义：该参数用于指定安全策略峰值信息速率。该参数表示峰值流量速率，单位为kbps。 数据来源：本端规划 取值范围：整数类型，取值范围为0～1000000。 默认值：无 配置原则：该参数值应大于或等于CIR。不设置该参数时，PIR默认为0。不配置时为单桶模式。                                                                                                                                                                                                                                                                                                                                                      |
| PBS     | 峰值突发尺寸（bytes） | 可选必选说明：可选参数 参数含义：该参数用于指定安全策略峰值突发尺寸。 此参数用于描述令牌桶P的容量，即在按PIR转发数据时允许转发的最大突发IP包尺寸。 数据来源：本端规划 取值范围：整数类型，取值范围为0～9000000。 默认值：无 配置原则：该参数建议大于或等于可能转发的最大IP包长度。不设置该参数时，PBS的取值通过PIR*187计算得出。                                                                                                                                                                                                                                                                                                                     |

#### 使用实例

- 设置ARP协议的安全防攻击CAR规则：

  ```
  SET NPSECPOLICYCAR: CARTYPE=ARP, CIR=100, CBS=200, PIR=300, PBS=400;
  ```

  ```
  RETCODE = 0  操作成功。

  ---    END
  ```

#### 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                     | 原因分析                                     | 处理建议                                                        |
|------:|:--------------------------|:-----------------------------------------|:------------------------------------------------------------|
|    14 | 输入参数值不在有效范围内              | CBS或PBS参数缺省情况下，使用默认规则计算出的参数值可能不在参数有效范围内。 | 两种处理方式： 明确输入CBS或PBS参数值；输入合理的CIR和PIR参数值，确保CBS和PBS的缺省值在有限范围内。 |
| 47612 | 当PIR不为0时，不符合PIR大于等于CIR的约束 | 当PIR不为0时，参数约束要求PIR大于等于CIR。               | 设置PIR大于等于CIR。                                               |
