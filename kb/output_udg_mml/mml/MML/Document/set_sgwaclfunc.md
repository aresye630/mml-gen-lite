# 设置SGW ACL功能（SET SGWACLFUNC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于控制SGW\I-UPF\ULCL\BP上ACL功能是否使能。当SGW\I-UPF\ULCL\BP不作为透传设备需要开启其ACL功能，使用该命令配置。

当ULCL UPF和锚点UPF共部署时，不受该命令控制。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | SGWACL   |
|:-------|:---------|
| 初始值    | ENABLE   |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                                              |
|:-------|:-----------|:------------------------------------------------------------------------------------------------------------------|
| SGWACL | S-GW ACL功能 | 可选必选说明：必选参数 参数含义：该参数用于控制SGW上ACL功能是否使能。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能SGW ACL功能。ENABLE：使能SGW ACL功能。 默认值：无 配置原则：无 |

#### 使用实例

- 当SGW\I-UPF\ULCL\BP不作为透传设备时，使能其ACL功能：

  ```
  SET SGWACLFUNC:SGWACL=ENABLE;
  ```
- 当SGW\I-UPF\ULCL\BP作为透传设备时，不使能其ACL功能：

  ```
  SET SGWACLFUNC:SGWACL=DISABLE;
  ```
