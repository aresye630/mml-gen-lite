# 增加ACL节点（ADD ACLNODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

**须知** 

本命令属于高危命令，操作不当会导致性能下降明显，请谨慎使用并联系华为技术支持协助操作。

该命令用于增加ACL节点，即配置filter过滤条件及对应的动作。配置完的ACL节点将作为ACL的一个配置项。

#### 注意事项

- 该命令最大记录数为5000。
- 系统最大支持同时配置IPv4和IPv6的ACL节点共5000条。
- SET REFRESHSRV命令必须在对所有ACL节点的配置完成后执行。ACL节点配置增加后，在执行SET REFRESHSRV命令30s后生效。
- 不允许增加ACL节点名称不同、其他参数都相同的配置。
- 系统最大支持配置的ACL节点数为10000，当要添加的ACL节点所绑定的过滤器指定了手机IP列表或服务器IP列表时，会自动生成多个ACL节点，这些自动生成的ACL节点会占用ACL节点总规格。生成ACL节点数目的计算公式为：生成ACL节点数目 = 手机IP列表名称的IP数目 \* 服务器IP列表名称的IP数目。
- 操作不当会导致性能下降明显，请谨慎使用并联系华为技术支持协助操作。
- 执行该命令配置REDIRECTIPV4/REDIRECTIPV6参数时，需要确保对应路由存在，否则业务无法重定向到指定ip地址对应的设备，ACL重定向功能不生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

- 假如运营商需要增加一个ACL节点，其过滤器FilterName为“testfilter1”，对应的动作类型为“GATE”，门控制器动作为PASS：

  ```
  ADD ACLNODE: ACLNODENAME="testaclnode1",FILTERNAME="testfilter1",ACTIONTYPE=GATE,GATEACTION=PASS;
  ```
- 假如运营商需要增加一条ACL节点，其过滤器FilterName为“testfilter2”，对应的动作类型为“GATE”，门控制器动作为DISCARD：

  ```
  ADD ACLNODE: ACLNODENAME="testaclnode2",FILTERNAME="testfilter2",ACTIONTYPE=GATE,GATEACTION=DISCARD;
  ```
