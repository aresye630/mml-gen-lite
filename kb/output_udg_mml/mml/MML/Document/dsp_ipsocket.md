# 查询IP Socket状态（DSP IPSOCKET）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查看已创建的IP Socket信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称       | 参数说明                                                                                                               |
|:-----------|:-----------|:-------------------------------------------------------------------------------------------------------------------|
| IPVERSION  | IP版本       | 可选必选说明：可选参数 参数含义：该参数用于指定IP版本。 数据来源：本端规划 取值范围：枚举类型。 IPv4：IPv4协议族。IPv6：IPv6协议族。 默认值：IPv4                             |
| SOCKETTYPE | Socket类型   | 可选必选说明：可选参数 参数含义：该参数用于指定Socket类型。 数据来源：本端规划 取值范围：枚举类型。 TCP：TCP报文。UDP：UDP报文。RAWIP：RawIP报文。RAWLINK：Raw-link报文。 默认值：无 |
| APPCID     | APP组件CID   | 可选必选说明：可选参数 参数含义：该参数用于指定APP组件CID。 数据来源：本端规划 取值范围：十六进制整数类型，取值范围为0x0～0xFFFFFFFF。 默认值：无                               |
| SOCKETFD   | Socket实例ID | 可选必选说明：可选参数 参数含义：该参数用于指定Socket实例ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～2147418111。 默认值：无                                   |

#### 使用实例

- 显示当前系统的IPv4 Socket状态：

  ```
  DSP IPSOCKET: APPCID="0x8093042C", SOCKETFD=10;
  ```

  ```
                        远端地址  =  0.0.0.0
                      本端端口号  =  22
                      远端端口号  =  0
                    发送窗口大小  =  0

          ---    END
  ```
