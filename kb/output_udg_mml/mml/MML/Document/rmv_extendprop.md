# 删除扩展属性配置（RMV EXTENDPROP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用来删除所有扩展属性配置信息，或者指定名称的配置信息。

#### 注意事项

- 该命令执行后立即生效。
- 如果扩展属性配置被绑定到其他配置中，如绑定到某个分类组中，则不允许删除，需要先解除绑定关系。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                        |
|:---------------|:-------|:--------------------------------------------------------------------------------------------|
| EXTENDPROPNAME | 扩展属性名称 | 可选必选说明：可选参数 参数含义：该参数用于设置扩展属性名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

删除配置扩展属性：EXTENDPROPNAME为textcategoryprop：

```
RMV EXTENDPROP:EXTENDPROPNAME="textcategoryprop";
```
