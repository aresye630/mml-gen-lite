# 设置模型监控功能（SET IISAMODELMONIT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、PGW-U**

此命令用于设置模型监控功能相关参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | ALARMSWITCH   |   MONITORTHRES |   VALIDTIME | SAMONITOR   | CATEMONITOR   | QOEMONITOR   |
|:-------|:--------------|---------------:|------------:|:------------|:--------------|:-------------|
| 初始值    | DISABLE       |            200 |       10000 | DISABLE     | DISABLE       | DISABLE      |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称       | 参数说明                                                                                                                                           |
|:-------------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| ALARMSWITCH  | 模型能力异常告警开关 | 可选必选说明：可选参数 参数含义：控制模型异常时是否上报模型能力异常告警开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能告警上报。ENABLE：使能告警上报。 默认值：无 配置原则：无                                       |
| MONITORTHRES | 监控阈值       | 可选必选说明：可选参数 参数含义：该参数用于设置模型监控阈值。 数据来源：本端规划 取值范围：整数类型，取值范围1到10000，单位是万分比。 默认值：无 配置原则：通过检测模型监控置信度与模型文件中的置信度基线的差值是否大于监控阈值判断模型是否异常，差值大于监控阈值时表示模型异常。 |
| VALIDTIME    | 有效次数       | 可选必选说明：可选参数 参数含义：该参数用于设置模型监控有效次数。 数据来源：本端规划 取值范围：整数类型，取值范围1到4294967295。 默认值：无 配置原则：无                                                           |
| SAMONITOR    | 协议推理监控开关   | 可选必选说明：可选参数 参数含义：该参数用于设置协议模型监控开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能SA分析。ENABLE：使能SA分析。 默认值：无 配置原则：无                                             |
| CATEMONITOR  | 应用大类推理监控开关 | 可选必选说明：可选参数 参数含义：该参数用于设置应用大类模型监控开关。 数据来源：全网规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无                                                   |
| QOEMONITOR   | QoE推理监控开关  | 可选必选说明：可选参数 参数含义：该参数用于设置QoE模型监控开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能QoE分析。ENABLE：使能QoE分析。 默认值：无 配置原则：无                                          |

#### 使用实例

设置模型监控功能：

```
SET IISAMODELMONIT: ALARMSWITCH=ENABLE, MONITORTHRES=1, VALIDTIME=1, SAMONITOR=ENABLE, CATEMONITOR=ENABLE, QOEMONITOR=ENABLE;
```
