# 查询黑白名单协议配置（LST INSAPROTOCOL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

查询黑白名单协议配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                    |
|:---------|:-------|:----------------------------------------------------------------------------------------|
| PROTTYPE | 协议类型   | 可选必选说明：必选参数 参数含义：该参数用来表示配置协议类型。 数据来源：本端规划 取值范围： BLACK：黑名单协议。ENHANCE：待增强协议。 默认值：无 配置原则：无 |

#### 使用实例

查询所有黑名单协议配置：

```
LST INSAPROTOCOL:PROTTYPE=BLACK;
```

```
RETCODE = 0  操作成功。
 
黑白名单协议配置信息
------

        Black Protocol                   http 
        Black Protocol                   https

```
