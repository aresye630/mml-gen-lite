# 增加IGMP Snooping组播源配置（ADD MULTICASTSOURCE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于增加IGMP Snooping组播源配置。

#### 注意事项

- 该命令执行后立即生效。
- 如果此IMSI配置成了结对成员，那么此IMSI就只能以结对方式配置为组播源。
- 该命令最大记录数为128个IMSI和128个DFSRPAIRID。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                          |
|:-------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VNINSTANCE   | 5G LAN组名称 | 可选必选说明：必选参数 参数含义：该参数用于指定5G LAN会话实例名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为18～37。VNINSTANCE以连字号分为4段，形式为GroupServiceID-MCC-MNC-LocalGroupID。其中，GroupServiceID长度为8，只能输入数字或者范围为A到F或a-f的字母；MCC长度为3，只能输入数字；MNC长度为2~3，只能输入数字；LocalGroupID长度为2~20的偶数，只能输入数字或者范围为A到F或a-f的字母。例如，A0000001-460-003-01，A0000001-460-003-A000000001。不区分大小写。 默认值：无 配置原则：该参数使用ADD NGVNINSTANCE命令配置生成。 |
| MCSOURCETYPE | 组播源类型     | 可选必选说明：必选参数 参数含义：该参数用于配置组播源类型。 数据来源：全网规划 取值范围： IMSI：IMSI。DFSRPAIR：双发选收结对。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                        |
| IMSI         | IMSI      | 可选必选说明：条件必选参数 前提条件：该参数在“MCSOURCETYPE”配置为“IMSI”时为必选参数。 参数含义：组播源IMSI。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～15，每个字符必须为0~9的数字。 默认值：无 配置原则：无                                                                                                                                                                                                                              |
| DFSRPAIRID   | 双发选收结对ID  | 可选必选说明：条件必选参数 前提条件：该参数在“MCSOURCETYPE”配置为“DFSRPAIR”时为必选参数。 参数含义：该参数用于配置双发选收结对ID。 数据来源：本端规划 取值范围：整数类型，取值范围1-2048。 默认值：无 配置原则：无                                                                                                                                                                                                                                  |

#### 使用实例

设置配置5G LAN组的N3侧的组播源：

```
ADD MULTICASTSOURCE: VNINSTANCE="a0000001-460-003-01", MCSOURCETYPE=IMSI, IMSI="217456789012353";

%%ADD MULTICASTSOURCE: VNINSTANCE="a0000001-460-003-01", MCSOURCETYPE=IMSI, IMSI="217456789012353";%%

---    END
```
