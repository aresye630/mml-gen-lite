# 查询IPSQM整形配置（LST IPSQMSHAPING）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-U、UPF**

该命令用于查询基于基站的下行流量整形带宽。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                            |
|:------------|:---------|:----------------------------------------------------------------------------------------------------------------|
| IPTYPE      | IP地址类型   | 可选必选说明：可选参数 参数含义：指定对端地址类型。 数据来源：本端规划 取值范围：枚举类型。 IPv4：表示地址类型为IPv4。IPv6：表示地址类型为IPv6。 默认值：无 配置原则：无                 |
| PEERIPV4    | 对端IPv4地址 | 可选必选说明：条件可选参数 前提条件：该参数在“IPTYPE”配置为“IPv4”时为可选参数。 参数含义：指定基站的IPv4地址。 数据来源：全网规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无 配置原则：无 |
| PEERIPV6    | 对端IPv6地址 | 可选必选说明：条件可选参数 前提条件：该参数在“IPTYPE”配置为“IPv6”时为可选参数。 参数含义：指定基站的IPv6地址。 数据来源：全网规划 取值范围：IPv6地址类型。 默认值：无 配置原则：无         |
| VPNINSTANCE | VPN实例    | 可选必选说明：可选参数 参数含义：指定基站所在VPN，如果整形配置的VPN与实际的VPN不一致，则整形失败。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无           |

#### 使用实例

查询基于基站的下行流量整形带宽：

```
LST IPSQMSHAPING:;
```
