# 激活模块级KPI异常检测与恢复功能（ACT SGLISOLATION）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令属于高危命令，隔离Pod可能会导致业务受损，请谨慎使用该命令。

该命令用于激活模块级KPI异常检测与恢复功能。

## 注意事项

- 该命令执行后立即生效。

- 该命令涉及模块级KPI异常检测与恢复特性，执行命令前请使用LST CFSHEALCTRL命令确认模块级KPI异常检测与恢复功能开关状态为“ENABLE(打开)”且SGLISOMODE设置为“MANUAL(手动)”。
- 执行该命令下发Pod隔离操作后，请使用**DSP POD**命令查询Pod的状态是否为"Pending"，是则表示隔离成功，否则表示隔离失败，需进行重试。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                            |
|:--------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PODNAME | Pod名称  | 可选必选说明：可选参数  参数含义：该参数用于指定Pod名称。可通过DSP SGLDETECTION命令查询。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~1024。  默认值：无  配置原则：  未输入Pod名称表示处理DSP SGLDETECTION命令中所有隔离结果为"未隔离，需人工隔离"的Pod。  输入的Pod名称在DSP SGLDETECTION命令显示的Pod中，则处理该Pod。  输入的Pod名称不在DSP SGLDETECTION命令显示的Pod中，则返回失败错误码。 |

## 使用实例

激活Pod名称为“vup-pod-0”的模块级KPI异常检测与恢复功能。

```
%%ACT SGLISOLATION: PODNAME="vup-pod-0";%%
RETCODE = 0  操作成功

---    END
```
