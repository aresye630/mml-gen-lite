# 触发FES对账（OPR FESVERIFICATION）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于手工触发FES对账。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                                                                                                                                                                         |
|:---------------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UCORMC         | 对账模式     | 可选必选说明：必选参数 参数含义：该参数用于表示对账模式。 数据来源：本端规划 取值范围：枚举类型。 SLOW：慢对账。FAST_UC：单播快对账。FAST_MC：多播快对账。 默认值：无                                                                                                                                                                               |
| SLOWVRFCTYPE   | 慢对账类型    | 可选必选说明：条件可选参数 前提条件：该参数在“UCORMC”配置为“SLOW”时为可选参数。 参数含义：该参数用于慢对账类型。 数据来源：本端规划 取值范围：枚举类型。 ALL：全对账。IP：IP信息对账。MPLS：MPLS信息对账。MC：组播信息对账。 默认值：ALL                                                                                                                                     |
| FASTVRFCUCTYPE | 单播快对账类型  | 可选必选说明：条件必选参数 前提条件：该参数在“UCORMC”配置为“FAST_UC”时为必选参数。 参数含义：该参数用于表示单播快对账类型。 数据来源：本端规划 取值范围：枚举类型。 IP：IP信息对账。MPLS：MPLS信息对账。MC：组播信息对账。 默认值：无                                                                                                                                        |
| FASTVRFCMCTYPE | 多播快对账类型  | 可选必选说明：条件必选参数 前提条件：该参数在“UCORMC”配置为“FAST_MC”时为必选参数。 参数含义：该参数用于表示多播快对账类型。 数据来源：本端规划 取值范围：枚举类型。 RM：路由管理信息对账。MBFES：资源单元FES对账。 默认值：无                                                                                                                                              |
| IDENTITYFLAGUC | 单播快对账标志位 | 可选必选说明：条件可选参数 前提条件：该参数在“FASTVRFCUCTYPE”配置为“IP”、“MPLS” 或 “MC”时为可选参数。 参数含义：该参数用于表示单播快对账标志位。 数据来源：本端规划 取值范围：枚举类型。 COMPONENTID：组件ID。RUNAME：资源单元名称。 默认值：无 配置原则：如果不输入该参数，则表示触发与指定单播快对账类型相关的所有组件的对账。                                                                                |
| IDENTITYFLAGMC | 多播快对账标志位 | 可选必选说明：条件必选参数 前提条件：该参数在“FASTVRFCMCTYPE”配置为“RM” 或 “MBFES”时为必选参数。 参数含义：该参数用于表示多播快对账标志位。 数据来源：本端规划 取值范围：枚举类型。 ALLSLOT：所有资源单元。RUNAME：资源单元名称。 默认值：无                                                                                                                               |
| COMPONENTID    | 组件ID     | 可选必选说明：条件必选参数 前提条件：该参数在“IDENTITYFLAGUC”配置为“COMPONENTID”时为必选参数。 参数含义：该参数用于表示组件ID。 数据来源：本端规划 取值范围：十六进制整数类型，取值范围为0x0～0xFFFFFFFF。 默认值：无                                                                                                                                          |
| RUNAME         | 资源单元名称   | 可选必选说明：条件必选参数 前提条件：该参数在“IDENTITYFLAGUC”配置为“RUNAME”时为必选参数。 可选必选说明：条件必选参数 前提条件：该参数在“IDENTITYFLAGMC”配置为“RUNAME”时为必选参数。 可选必选说明：条件可选参数 前提条件：该参数在“UCORMC”配置为“SLOW”时为可选参数。 参数含义：该参数用于表示资源单元名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：区分大小写，不支持空格，下发本MML命令前可使用DSP RU查看资源单元信息。 |

#### 使用实例

手工触发单播快对账：

```
OPR FESVERIFICATION: UCORMC=FAST_UC, FASTVRFCUCTYPE=MC;
```
