# 显示PAE批量接收报文数（DSP PAEBATCHRECVNUM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示PAE批量接收报文数。

## 注意事项

该命令查询到的为实际生效的批收数，若环境变量SVC\_VFABRIC\_FWD\_BATCH\_RECV\_NUM与SET PAEBATCHRECVNUM配置同时存在时，MML配置优先生效；若无MML配置，查询结果为环境变量配置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                               |
|:-------|:--------|:-------------------------------------------------------------------------------------------------------------------|
| CELLID | Cell ID | 可选必选说明：可选参数  参数含义：该参数表示PAE调试消息发送的CELLID，可以通过使用DSP PAENODE命令获取。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~127。  默认值：无  配置原则：无 |

## 使用实例

动态查询PAE批量收包数量：

```
%%DSP PAEBATCHRECVNUM:;%%
RETCODE = 0  操作成功

结果如下
--------
Cell ID  					PAE批收数量  

esa-pod-0__103__0				224          
csdb-pod-0__103__0				224          
ipapmexec-pod-b6988575-kmvm7__103__0		224   
isu-pod-1__103__0				224          
gcp-pod-1__103__0				224                                  
(结果个数 = 5)

---    END
```
