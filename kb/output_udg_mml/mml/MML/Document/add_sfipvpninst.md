# 添加SFIP VPN实例（ADD SFIPVPNINST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：EPSN**

该命令用于创建指定的VPN实例。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为4096。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                            |
|:------------|:-------|:--------------------------------------------------------------------------------|
| VPNINSTANCE | VPN实例名 | 可选必选说明：必选参数 参数含义：该参数用于设置VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无 |
| DESC        | 描述信息   | 可选必选说明：可选参数 参数含义：描述信息。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～255。 默认值：无 配置原则：无          |

#### 使用实例

增加SFIP VPNInst业务配置，VPN实例名称为vpn1，描述信息为vpn：

```
ADD SFIPVPNINST: VPNINSTANCE="vpn1", DESC="vpn";
```
