# 修改L2TP组的LNS信息（MOD L2TPLNSINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

修改L2TP组的LNS信息。

#### 注意事项

- 该命令执行后只对新激活用户生效。
- 只能通过MOD L2TPLNSINFO修改已有的LNS配置。
- 同一个组内的IP地址不能重复。
- 如果要修改L2TP组的IP类型，需要删除对应的L2TP组下所有L2TPLNSINFO配置。
- 当L2TP组存在用户时，不允许通过MOD L2TPLNSINFO命令修改LNSIP或密码信息。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称        | 参数说明                                                                                                                                   |
|:------------|:------------|:---------------------------------------------------------------------------------------------------------------------------------------|
| GROUPID     | L2TP组号      | 可选必选说明：必选参数 参数含义：指定L2TP组号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～1500。 默认值：无 配置原则：该参数使用ADD L2TPGROUP命令配置生成。                                       |
| LNSNO       | LNS序号       | 可选必选说明：必选参数 参数含义：该参数用于指定添加LNS的序号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～30。 默认值：无 配置原则：无                                                          |
| LNSIPVER    | LNS IP类型    | 可选必选说明：可选参数 参数含义：该参数用于指定LNS IP类型。 数据来源：本端规划 取值范围：枚举类型。 IPV4：LNS的IP版本号为IPv4。IPV6：LNS的IP版本号为IPV6。 默认值：无 配置原则：无                           |
| IPV4ADDRESS | LNS IPv4地址  | 可选必选说明：条件必选参数 前提条件：该参数在“LNSIPVER”配置为“IPV4”时为必选参数。 参数含义：指定LNS的IPv4地址。 数据来源：全网规划 取值范围：IPv4地址类型。采用点分十进制"X.X.X.X"格式。 默认值：无 配置原则：无          |
| IPV6ADDRESS | LNS IPv6地址  | 可选必选说明：条件必选参数 前提条件：该参数在“LNSIPVER”配置为“IPV6”时为必选参数。 参数含义：指定该LNS的IPv6地址。 数据来源：全网规划 取值范围：IPv6地址类型。采用冒号分十六进制X:X:X:X:X:X:X:X格式。 默认值：无 配置原则：无 |
| PWD         | LNS隧道认证密码   | 可选必选说明：可选参数 参数含义：指定该LNS的密码。 数据来源：对端协商 取值范围：密码类型，不加密输入时，取值范围1～432个字符。不支持空格，区分大小写。输入PWD时，必须同时输入确认密码CFMPWD，且密码相同。 默认值：无 配置原则：无            |
| CFMPWD      | 确认LNS隧道认证密码 | 可选必选说明：可选参数 参数含义：该参数用于确认LNS隧道认证密码。 数据来源：对端协商 取值范围：密码类型，输入长度范围为1～432。不支持空格，区分大小写。CFMPWD需要和PWD密码相同。 默认值：无 配置原则：无                         |

#### 使用实例

假设用户需要修改隧道的IP地址：

```
MOD L2TPLNSINFO: GROUPID=1, LNSNO=1, LNSIPVER=IPV4, IPV4ADDRESS="10.1.1.1";
```
