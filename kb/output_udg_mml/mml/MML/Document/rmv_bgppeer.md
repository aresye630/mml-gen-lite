# 删除BGP对等体（RMV BGPPEER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除IPv4或IPv6地址类型的对等体及其相关参数。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                     |
|:------------|:----------|:-------------------------------------------------------------------------------------------------------------------------|
| VRFNAME     | VPN实例名称   | 可选必选说明：可选参数 参数含义：该参数用于指定用户所配置的VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：_public_ 配置原则：使用LST L3VPNINST命令查看可用VPN。     |
| ADDRESSTYPE | 地址类型      | 可选必选说明：必选参数 参数含义：该参数用于指定对等体的地址类型。 数据来源：本端规划 取值范围：枚举类型。 noaf：不指定地址族。ipv4：IPv4。ipv6：IPv6。 默认值：无                            |
| PEERADDR    | IPv4对等体地址 | 可选必选说明：条件必选参数 前提条件：该参数在“ADDRESSTYPE”配置为“noaf” 或 “ipv4”时为必选参数。 参数含义：该参数用于指定连接对等体的IPv4接口地址。 数据来源：对端协商 取值范围：IPv4地址类型。 默认值：无 |
| PEERADDRV6  | IPv6对等体地址 | 可选必选说明：条件必选参数 前提条件：该参数在“ADDRESSTYPE”配置为“ipv6”时为必选参数。 参数含义：该参数用于指定连接对等体的IPv6接口地址。 数据来源：对端协商 取值范围：IPv6地址类型。 默认值：无          |

#### 使用实例

- 在名称为“vrf1”的BGP VPN实例下删除指定对等体10.2.2.2：

  ```
  RMV BGPPEER:VRFNAME="vrf1",ADDRESSTYPE=ipv4,PEERADDR="10.2.2.2";
  ```
- 在名称为“vrf1”的BGP VPN实例下删除指定对等体2001:db8:1:1:1:1:1:1：

  ```
  RMV BGPPEER:VRFNAME="vrf1",ADDRESSTYPE=ipv6,PEERADDRV6="2001:db8:1:1:1:1:1:1";
  ```
