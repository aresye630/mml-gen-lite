# 设置日志导出参数（EXP LOG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于设置日志导出参数。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                                                                                            |
|:-----------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SWITCH     | 导出开关      | 可选必选说明：必选参数 参数含义：该参数用于指定日志导出开关。 数据来源：本端规划 取值范围： DISABLE：关闭。ENABLE：打开。 默认值：无 配置原则：无                                                                              |
| IPVERSION  | IP版本信息    | 可选必选说明：条件必选参数 前提条件：该参数在“SWITCH”配置为“ENABLE”时为必选参数。 参数含义：该参数用于指定IP版本信息。 数据来源：本端规划 取值范围： IPV4：表示地址类型为IPv4。IPV6：表示地址类型为IPv6。IPV4_IPV6：同时支持IPv4和IPv6地址。 默认值：无 配置原则：无 |
| IPV4       | 服务器IPv4地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV4”时为必选参数。 可选必选说明：条件可选参数 前提条件：该参数在“SWITCH”配置为“ENABLE”时为可选参数。 参数含义：该参数用于指定服务器IPV4地址。 数据来源：本端规划 取值范围：NA。 默认值：无 配置原则：无     |
| IPV6       | 服务器IPv6地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV6”时为必选参数。 可选必选说明：条件可选参数 前提条件：该参数在“SWITCH”配置为“ENABLE”时为可选参数。 参数含义：该参数用于指定服务器IPV6地址。 数据来源：本端规划 取值范围：NA。 默认值：无 配置原则：无     |
| PORT       | 服务器端口     | 可选必选说明：条件必选参数 前提条件：该参数在“SWITCH”配置为“ENABLE”时为必选参数。 参数含义：该参数用于指定服务器端口。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无 配置原则：无                                             |
| USER       | 用户名       | 可选必选说明：条件必选参数 前提条件：该参数在“SWITCH”配置为“ENABLE”时为必选参数。 参数含义：该参数用于指定服务器用户名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～255。 默认值：无 配置原则：无                                           |
| PASSWORD   | 密码        | 可选必选说明：条件必选参数 前提条件：该参数在“SWITCH”配置为“ENABLE”时为必选参数。 参数含义：该参数用于指定服务器密码。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：无                                             |
| REMOTEPATH | 远端路径      | 可选必选说明：条件必选参数 前提条件：该参数在“SWITCH”配置为“ENABLE”时为必选参数。 参数含义：该参数用于指定服务器日志导出路径。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～1023。 默认值：无 配置原则：无                                       |

#### 使用实例

设置日志导出参数：

```
EXP LOG: SWITCH=ENABLE, IPVERSION=IPV4, IPV4="10.104.64.129", PORT=22, USER="user", PASSWORD="password", REMOTEPATH="./logpath";
```
