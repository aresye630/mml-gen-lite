# 显示基于协议的质差检测策略（LST SSUPROTCOLGROUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

此命令用于查询SSUPROTCOLGROUP，支持批量查询。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                    |
|:--------------|:---------|:----------------------------------------------------------------------------------------|
| DEFPRTGRPNAME | 自定义协议组名称 | 可选必选说明：可选参数 参数含义：该参数用于指定自定义的三级协议组名称。 数据来源：本端规划 取值范围：字符串类型，不区分大小写，长度为1-63位。 默认值：无 配置原则：无 |

#### 使用实例

- 假如运营商需要查询一条自定义协议组名称为testadc下基于协议的质差策略：

  ```
  %%LST SSUPROTCOLGROUP: DEFPRTGRPNAME="testadc";
  ```

  ```
  %%
  RETCODE = 0  操作成功

  基于协议的质差检测策略
  ------------------
  自定义协议组名称  =  testadc
          协议名称  =  adc
        策略参数名  =  policyname
      业务流量特征  =  上下行均判断
        业务流分类  =  主业务流
  (结果个数 = 1)

  ---    END
  ```
- 假如运营商需要查询所有已配置的基于协议的质差策略：

  ```
  %%LST SSUPROTCOLGROUP:;
  ```

  ```
  %%
  RETCODE = 0  操作成功

  基于协议的质差检测策略
  ------------------
  自定义协议组名称     协议名称  策略参数名   业务流量特征  业务流分类  

  testadc              adc       policyname   上下行均判断  主业务流    
  ssuprotclogroupname  http      policyname2  上下行均判断  主业务流    
  (结果个数 = 2)

  ---    END
  ```
