#### 命令功能

**适用NF：UPF**

该命令用于设置MOS计算值的补偿因子。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为10。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 初始值    | MOS_CODEC_AMR_NB  |            0 |            0 |            0 |            0 |            0 |
| 初始值    | MOS_CODEC_AMR_WB  |            0 |            0 |            0 |            0 |            0 |

#### 使用实例

- 设置AMR WB编解码语音的MOS计算值的补偿因子：

  ```
  SET VONRMOSFACTOR: MOSCODEC=MOS_CODEC_AMR_WB, FACTOR1TO2="1", FACTOR2TO3="-1";
  ```
- 设置所有编解码语音的MOS计算值的补偿因子：

  ```
  SET VONRMOSFACTOR: MOSCODEC=MOS_CODEC_ALL, FACTOR1TO2="1", FACTOR2TO3="-1";
  ```

#### 参考信息

针对不同编解码类型在不同丢包率下对语音质量检测的MOS计算值进行补偿。
