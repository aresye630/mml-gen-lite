# 显示地址分配规则（LST IPALLOCRULE）

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于显示全局地址分配规则。

#### 注意事项

该命令执行后只对新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询全局地址分配规则：

```
LST IPALLOCRULE:;
```

```
RETCODE = 0 操作成功。

地址分配规则
---------------------
IPv4第一级规则开关 = 使能
IPv4第一级规则 = APN & SMF
IPv4第二级规则开关 = 使能
IPv4第二级规则 = SMF
IPv4第三级规则开关 = 不使能
IPv4第三级规则 = NULL
IPv6第一级规则开关 = 使能
IPv6第一级规则 = APN & SMF
IPv6第二级规则开关 = 使能
IPv6第二级规则 = SMF
IPv6第三级规则开关 = 不使能
IPv6第三级规则 = NULL
(结果个数 = 1)
--- END
```
