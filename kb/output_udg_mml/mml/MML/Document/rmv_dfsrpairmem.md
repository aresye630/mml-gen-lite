# 删除双发选收结对成员配置（RMV DFSRPAIRMEM）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于删除双发选收结对内IMSI成员。

#### 注意事项

- 该命令执行后立即生效。
- 记录存在。
- 如果执行批量删除操作，需要开启软参BYTE692。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                        |
|:-----------|:---------|:--------------------------------------------------------------------------------------------|
| DFSRPAIRID | 双发选收结对ID | 可选必选说明：必选参数 参数含义：该参数用于配置双发选收结对ID。 数据来源：本端规划 取值范围：整数类型，取值范围1-2048。 默认值：无 配置原则：无              |
| IMSI       | IMSI     | 可选必选说明：可选参数 参数含义：双发选收结对成员IMSI。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～15，每个字符必须为0~9的数字。 默认值：无 配置原则：无 |

#### 使用实例

删除双发选收中imsi为460111111111111的结对成员：

```
RMV DFSRPAIRMEM: DFSRPAIRID=1, IMSI="460111111111111";
```
