# 增加IPv6前缀过滤器节点（ADD IPV6PREFIXFILTERNODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于添加基于IPv6信息的前缀过滤器。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为100000。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称         | 参数说明                                                                                                                                                                                                                                                            |
|:-------------|:-------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NAME         | IPv6前缀列表名字   | 可选必选说明：必选参数 参数含义：IP前缀列表名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～169。 默认值：无 配置原则：不支持输入空格。                                                                                                                                                                               |
| NODESEQUENCE | IPv6前缀列表节点号  | 可选必选说明：必选参数 参数含义：IP前缀列表节点号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 配置原则：缺省情况下，该序号值按照配置先后顺序依次递增。                                                                                                                                                           |
| MATCHMODE    | IPv6前缀列表匹配模式 | 可选必选说明：必选参数 参数含义：IP前缀列表匹配模式。 数据来源：本端规划 取值范围：枚举类型。 permit：允许。deny：拒绝。 默认值：无 配置原则：要求输入完全一致，如果为permit则通过前缀过滤器为允许，否则为不允许。                                                                                                                                           |
| ADDRESS      | IPv6地址       | 可选必选说明：必选参数 参数含义：IPv6地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无 配置原则：IPv6地址。                                                                                                                                                                                            |
| MASKLENGTH   | 掩码长度         | 可选必选说明：必选参数 参数含义：该参数用于表示IPv6路由的前缀长度。 数据来源：本端规划 取值范围：整数类型，取值范围为0～128。 默认值：无                                                                                                                                                                                      |
| MATCHNETWORK | 是否匹配网络地址     | 可选必选说明：可选参数 参数含义：是否匹配网络。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：FALSE                                                                                                                                                                                    |
| GREATEREQUAL | 掩码长度匹配范围下限   | 可选必选说明：可选参数 参数含义：大于或等于。 数据来源：本端规划 取值范围：整数类型，取值范围为0～128。 默认值：无 配置原则： GREATEREQUAL的意思是“大于等于”； LESSEQUAL的意思是“小于等于”。长度范围可以表达为MASKLENGTH <= GREATEREQUAL <= LESSEQUAL <= 128。如果只指定了GREATEREQUAL，前缀范围为[GREATEREQUAL，128]。当只指定LESSEQUAL时，前缀范围为[MASKLENGTH，LESSEQUAL]。  |
| LESSEQUAL    | 掩码长度匹配范围上限   | 可选必选说明：可选参数 参数含义：小于或等于。 数据来源：本端规划 取值范围：整数类型，取值范围为0～128。 默认值：无 配置原则： GREATEREQUAL的意思是“大于等于”； LESSEQUAL的意思是“小于等于”。长度范围是可以表达为MASKLENGTH <= GREATEREQUAL <= LESSEQUAL <= 128。如果只指定了LESSEQUAL，前缀范围为[MASKLENGTH，LESSEQUAL]。当只指定GREATEREQUAL时，前缀范围为[GREATEREQUAL，128]。 |

#### 使用实例

增加IPv6前缀过滤器：

```
ADD IPV6PREFIXFILTERNODE:NAME="c",NODESEQUENCE=25,MATCHMODE=permit,ADDRESS="2001:DB8::",MASKLENGTH=128;
```
