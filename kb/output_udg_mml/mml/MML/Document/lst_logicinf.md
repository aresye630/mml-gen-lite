# 查询逻辑接口（LST LOGICINF）

- 命令功能

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于显示逻辑接口的相关信息。

#### 注意事项

默认为输出所有逻辑接口配置信息；若想查看指定逻辑接口配置信息，可指定逻辑接口名称，如果输入的逻辑接口名称在系统中不存在，则查询失败。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|:------------|:------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NAME        | 逻辑接口名称      | 可选必选说明：可选参数 参数含义：该参数用于配置逻辑接口名称，确保逻辑接口的唯一性。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则： 字符串形式，用户输入形式例如：n4if1/0/0。其中n4if为逻辑接口类型；1/0/0中第一个数字为ISU组号，第二个数字为实例类型；第三个数字为逻辑接口号，各逻辑接口类型有各自的配置范围。逻辑接口类型：giif，s5-sif，s1-uif，saif，paif，grpif，phif，s11-uif，nxccif，nxucif，n4if，n3if，n9cif，scif，vxlanif，n19if，tm3if，tx-uif，n6mbif，n3mbif，gcfif，swuif，swmif，gmif。（其中nxccif为预置接口，配置后只允许执行ping操作。）。ISU组号：1。ISU实例类型：0~64。0表示组级类型，1~64表示Instance级类型。ISU实例类型为0时，逻辑接口号：giif：0~1023，grpif：0，phif：0~2047，nxccif：0，n4if：0，tm3if：0，gcfif：0，swuif：0，swmif：0~15，gmif: 0~7。ISU实例类型为1时，逻辑接口号：s5-sif：0~31，s1-uif：0~31，saif：0~31，paif：0~31，s11-uif：0~31，nxucif：0~31，n3if：0~31，n9cif：0~31，scif：0~31，vxlanif：0~31，n19if：0~31，tx-uif：0，n6mbif：0，n3mbif：0~31。ISU实例类型为2~64时，逻辑接口号: s5-sif：0，s1-uif：0，saif：0，paif：0，n3if：0，n9cif：0，scif：0。 |
| IPVERSION   | 逻辑接口的IP版本   | 可选必选说明：可选参数 参数含义：该参数用于用户指定IP类型。 数据来源：全网规划 取值范围：枚举类型。 IPV4：逻辑接口IP的版本为IPv4。IPV6：逻辑接口IP的版本为IPv6。IPVER_ALL：逻辑接口IP的版本为IPv4和IPv6。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| IPV4ADDRESS | 逻辑接口的IPv4地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV4” 或 “IPVER_ALL”时为必选参数。 参数含义：该参数用于指示逻辑接口配置IP。 数据来源：全网规划 取值范围：IPv4地址类型。采用点分十进制"X.X.X.X"格式。 默认值：无 配置原则：根据环境的网络规划进行配置，点分十进制格式。除A、B、C类地址合法外，其余都为非法地址。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| IPV6ADDRESS | 逻辑接口的IPv6地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV6” 或 “IPVER_ALL”时为必选参数。 参数含义：该参数用于指示逻辑接口配置IPV6地址。 数据来源：全网规划 取值范围：IPv6地址类型。采用冒号分十六进制X:X:X:X:X:X:X:X格式。 默认值：无 配置原则：根据环境的网络规划进行配置，冒号分十六进制格式。不能是全0全1，不能是环回IP。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| VPNINSTANCE | VPN实例名称     | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPV4”、“IPV6” 或 “IPVER_ALL”时为可选参数。 参数含义：该参数用于将逻辑接口与VPN绑定。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～31。区分大小写。 默认值：无 配置原则：绑定VPN时需要确保该VPN已经配置（ADD VPNINST）。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

#### 输出结果说明

| 输出项名称           | 输出项解释                  |
|:----------------|:-----------------------|
| 逻辑接口名称          | 用于配置逻辑接口名称，确保逻辑接口的唯一性。 |
| 逻辑接口的IPv4地址1    | 用于指示逻辑接口配置主IP。         |
| 逻辑接口的IPv4掩码1    | 用于指示逻辑接口配置主IP掩码。       |
| 逻辑接口的IPv4地址2    | 用于指示逻辑接口配置子IP。         |
| 逻辑接口的IPv4掩码2    | 用于指示逻辑接口配置子IP掩码。       |
| IPv4逻辑接口MTU（字节） | 用于指定逻辑接口IPv4报文的最大传输单元。 |
| VPN实例名称         | 用于将逻辑接口与VPN绑定。         |
| 逻辑接口的IP版本       | 用于用户指定IP类型。            |
| 逻辑接口的IPv6地址1    | 用于指示逻辑接口配置主IPV6地址。     |
| IPv6前缀长度1       | 用于指示逻辑接口配置的主IPv6前缀长度。  |
| 逻辑接口的IPv6地址2    | 用于指示逻辑接口配置子IPV6地址。     |
| IPv6前缀长度2       | 用于指示逻辑接口配置的子IPv6前缀长度。  |
| IPv6逻辑接口MTU（字节） | 用于指定逻辑接口IPv6报文的最大传输单元。 |
| 接口切片属性          | 用于指示该逻辑接口的切片属性。        |
