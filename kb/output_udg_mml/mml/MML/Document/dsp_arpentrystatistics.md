# 显示ARP统计计数（DSP ARPENTRYSTATISTICS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示ARP表项的统计信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                            |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------|
| IFNAME | 接口名称   | 可选必选说明：可选参数 参数含义：该参数指定需要统计表项信息的接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。以太网接口名称由接口类型和接口编号组成。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。 |

#### 使用实例

统计接口Ethernet64/0/5下表项信息：

```
DSP ARPENTRYSTATISTICS:IFNAME="Ethernet64/0/5";
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
   接口名称  =  Ethernet64/0/5
动态ARP数量  =  8
静态ARP数量  =  0
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释           |
|:--------|:----------------|
| 接口名称    | 该参数表示接口名称。      |
| 动态ARP数量 | 该参数表示动态ARP表项数量。 |
| 静态ARP数量 | 该参数表示静态ARP表项数量。 |
