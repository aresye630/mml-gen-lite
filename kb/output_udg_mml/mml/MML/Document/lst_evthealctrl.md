# 查询事件全局开关（LST EVTHEALCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示事件全局开关。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询事件全局开关状态

```
%%LST EVTHEALCTRL:;%% 
RETCODE = 0  操作成功 

结果如下 
----------- 
事件全局开关 = 打开
(结果个数 = 1) 

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释          |
|:--------|:---------------|
| 事件全局开关  | 该参数用于表示事件全局开关。 |
