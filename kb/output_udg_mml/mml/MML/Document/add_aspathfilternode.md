# 增加AS路径过滤节点（ADD ASPATHFILTERNODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来增加一个AS路径过滤器表项。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为65535。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称        | 参数说明                                                                                                            |
|:-------------|:------------|:----------------------------------------------------------------------------------------------------------------|
| NAME         | AS路径过滤器名字或号 | 可选必选说明：必选参数 参数含义：该参数用于指定AS路径过滤器名字或号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～51。 默认值：无 配置原则：区分大小写，不支持空格。如果是数字则取值范围为1-256。 |
| NODESEQUENCE | AS路径过滤器节点号  | 可选必选说明：必选参数 参数含义：该参数用于指定AS路径过滤器节点号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无                                |
| MATCHMODE    | 匹配模式        | 可选必选说明：必选参数 参数含义：该参数用于指定匹配模式。 数据来源：本端规划 取值范围：枚举类型。 permit：允许。deny：拒绝。 默认值：无                                     |
| REGULAR      | 正则表达式       | 可选必选说明：必选参数 参数含义：该参数用于指定正则表达式。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～255。 默认值：无 配置原则：支持空格，不支持单空格。                       |

#### 使用实例

增加AS路径过滤器：

```
ADD ASPATHFILTERNODE: NAME ="a",NODESEQUENCE=1, MATCHMODE=permit, REGULAR="[1-9]";
```
