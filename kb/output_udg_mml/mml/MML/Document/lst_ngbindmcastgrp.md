# 查询5G LAN实例绑定组播组配置（LST NGBINDMCASTGRP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询静态组播组与5G LAN会话实例绑定记录。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称       | 参数说明                                                                                                             |
|:-----------|:-----------|:-----------------------------------------------------------------------------------------------------------------|
| VNINSTANCE | 5G LAN实例名称 | 可选必选说明：可选参数 参数含义：该参数用于指定5G LAN会话实例名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为18～37。 默认值：无 配置原则：该参数使用ADD NGVNINSTANCE命令配置生成。 |

#### 使用实例

查询静态组播组和5G LAN会话实例绑定关系：

```
%%LST NGBINDMCASTGRP:;
```

```
%%
```
