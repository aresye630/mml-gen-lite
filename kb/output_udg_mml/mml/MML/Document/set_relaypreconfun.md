# 设置媒体中继预建链功能（SET RELAYPRECONFUN）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于设置媒体中继预建链功能以减少回源过程中的链路创建时延，提升端到端的时延体验。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | PRECONSW   |   LIVEMINCONNUM |   VODMINCONNUM |   MAXUSEDTIME |   VODMAXRUDTIMES |
|:-------|:-----------|----------------:|---------------:|--------------:|-----------------:|
| 初始值    | DISABLE    |               2 |              2 |             5 |               20 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称           | 参数说明                                                                                                                                                                         |
|:---------------|:---------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PRECONSW       | 预建链功能开关        | 可选必选说明：可选参数 参数含义：该参数用于指定预建链功能开关。 数据来源：本端规划 取值范围：枚举类型，取值范围为ENABLE或DISABLE。 DISABLE：不使能预建链。ENABLE：使能预建链。 默认值：无 配置原则：无                                                          |
| LIVEMINCONNUM  | 直播最小预建链个数      | 可选必选说明：条件可选参数 前提条件：该参数在“PRECONSW”配置为“ENABLE”时为可选参数。 参数含义：该参数用于指定直播最小预建链个数。 数据来源：本端规划 取值范围：整数类型，取值范围是1~10。 默认值：无 配置原则：若配置直播最小预建链个数为2，则表示单域名至少有两个可用预建链资源，允许创建的直播预建链个数最大是10。    |
| VODMINCONNUM   | 点播最小预建链个数      | 可选必选说明：条件可选参数 前提条件：该参数在“PRECONSW”配置为“ENABLE”时为可选参数。 参数含义：该参数用于指定点播最小预建链个数。 数据来源：本端规划 取值范围：整数类型，取值范围是1~10。 默认值：无 配置原则：若配置点播最小预建链个数为2，则表示单域名至少有两个可用预建链资源，允许创建的点播预建链个数最大是10。    |
| MAXUSEDTIME    | 点播链路最长复用时间（分钟） | 可选必选说明：条件可选参数 前提条件：该参数在“PRECONSW”配置为“ENABLE”时为可选参数。 参数含义：该参数用于指定链路最大使用时长（分钟）。 数据来源：本端规划 取值范围：整数类型，取值范围是1~120。 默认值：无 配置原则：若超过链路最长复用时间，则老化点播预建链。                               |
| VODMAXRUDTIMES | 点播链路最大复用次数（次）  | 可选必选说明：条件可选参数 前提条件：该参数在“PRECONSW”配置为“ENABLE”时为可选参数。 参数含义：该参数用于指定点播链路最大复用次数（次）。 数据来源：本端规划 取值范围：整数类型，取值范围是0~1000。 默认值：无 配置原则： 当点播链路最大复用次数为0时，点播链路无限次复用。当点播链路超过最大复用次数时，则老化点播链路。 |

#### 使用实例

假如需要设置媒体中继预建链功能，则命令如下：

```
SET RELAYPRECONFUN: PreConSw=ENABLE, LiveMinConNum=5, VodMinConNum=5, MaxUsedTime=60, VodMaxRUDTimes=500;
```
