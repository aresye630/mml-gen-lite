# 显示FES表项统计信息（DSP FESTABLESTATICS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示FES表项统计信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称           | 参数说明                                                                                                          |
|:------------|:---------------|:--------------------------------------------------------------------------------------------------------------|
| TABLENAME   | 转发数据表名称        | 可选必选说明：可选参数 参数含义：转发数据表名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～15。 默认值：无 配置原则：转发数据表名称和转发数据表ID必须配置其中一项。               |
| TABLEID     | 转发数据表ID        | 可选必选说明：可选参数 参数含义：转发数据表ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无 配置原则：转发数据表名称和转发数据表ID必须配置其中一项。          |
| FIRSTRECNUM | 获取前几条记录        | 可选必选说明：可选参数 参数含义：获取前几条记录。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                        |
| FIELD       | 字段名称           | 可选必选说明：可选参数 参数含义：字段名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～15。 默认值：无                                                |
| OPERFLAG    | 命令操作标记         | 可选必选说明：可选参数 参数含义：命令操作标记。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无 配置原则：值为3表示显示的所有表项统计信息命令。                |
| MBORLC      | 操作维护单元还是接口处理单元 | 可选必选说明：可选参数 参数含义：操作维护单元还是接口处理单元。 数据来源：本端规划 取值范围：枚举类型。 mbfes：操作维护单元。lcfes：接口处理单元。 默认值：无                        |
| RUNAME      | 资源单元名称         | 可选必选说明：可选参数 参数含义：资源单元名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：区分大小写，不支持空格，下发本MML命令前可使用DSP RU查看资源单元信息。 |
