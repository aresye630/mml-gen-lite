# 查询路由管理消息明细（DSP RMMSGDETAIL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询路由管理消息明细。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                           |
|:--------------|:-------|:-----------------------------------------------------------------------------------------------|
| ADDRESSFAMILY | 地址族    | 可选必选说明：必选参数 参数含义：该参数用于表示地址族。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。ipv6unicast：IPv6单播。 默认值：无 |
| MSGTRACETYPE  | 消息类型   | 可选必选说明：必选参数 参数含义：该参数用于表示消息类型。 数据来源：本端规划 取值范围：枚举类型。 send：发送。receive：接收。 默认值：无                   |

#### 使用实例

查询路由管理消息明细：

```
DSP RMMSGDETAIL:ADDRESSFAMILY=ipv4unicast,MSGTRACETYPE=send;
```
