# 删除VXLAN隧道端点（RMV VTEP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于删除VXLAN隧道端点。

#### 注意事项

- 该命令执行后立即生效。
- 当VTEP绑定到VXLAN Group上时需要先解除绑定关系才可以删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称        | 参数说明                                                                                             |
|:---------|:------------|:-------------------------------------------------------------------------------------------------|
| VTEPNAME | VXLAN隧道端点名称 | 可选必选说明：可选参数 参数含义：该参数用于配置VXLAN隧道端点名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不区分大小写，不支持空格。 默认值：无 配置原则：无 |

#### 使用实例

删除VTEP Name为vtep1的隧道端点：

```
RMV VTEP: VTEPNAME="vtep1";
```
