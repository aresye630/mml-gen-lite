# 设置媒体中继回源带宽控制（SET RELAYORIGINBWM）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于配置媒体中继回源带宽控制以防止回源带宽过高，影响其他业务。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | BWMSW   |   PERIOD | ORIGINCTRLSW   | OVERLOADALMSW   |   PODPIR |
|:-------|:--------|---------:|:---------------|:----------------|---------:|
| 初始值    | DISABLE |        5 | DISABLE        | ENABLE          |    18000 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称           | 参数说明                                                                                                                                                                         |
|:--------------|:---------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| BWMSW         | 带宽控制开关         | 可选必选说明：可选参数 参数含义：该参数用于配置带宽控制开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能带宽控制开关。ENABLE：使能带宽控制开关。 默认值：无 配置原则：若带宽控制开关开启，则统计回源侧带宽。                                                       |
| PERIOD        | 带宽统计周期（秒）      | 可选必选说明：可选参数 参数含义：该参数用于设置带宽统计周期。 数据来源：本端规划 取值范围：整数类型，取值范围是1~60，单位是秒。 默认值：无 配置原则：无                                                                                             |
| ORIGINCTRLSW  | 回源失败控制开关       | 可选必选说明：可选参数 参数含义：该参数用于配置回源失败控制开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能回源失败控制开关。ENABLE：使能回源失败控制开关。 默认值：无 配置原则：若取值为Enable，当回源侧带宽超过配置的PODPIR值的80%时，则动态控制部分业务流重定向到普通域名继续访问业务。        |
| OVERLOADALMSW | 过载告警开关         | 可选必选说明：可选参数 参数含义：该参数用于配置过载告警开关以控制是否在媒体中继资源不足时上报81200告警。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能过载告警开关。ENABLE：使能过载告警开关。 默认值：无 配置原则：带宽控制开关和过载告警开关开启时，若带宽使用率超过配置的PODPIR的80%时上报81200告警。 |
| PODPIR        | POD峰值带宽（兆比特每秒） | 可选必选说明：可选参数 参数含义：该参数用于设置POD峰值带宽。 数据来源：本端规划 取值范围：整数类型，取值范围是100~50000，单位是兆比特每秒。 默认值：无 配置原则：无                                                                                   |

#### 使用实例

假如需要创建配置媒体中继回源带宽控制，则命令如下：

```
SET RELAYORIGINBWM:BWMSW=ENABLE, PERIOD=5, ORIGINCTRLSW=ENABLE, OVERLOADALMSW=ENABLE, PODPIR=18000;
```
