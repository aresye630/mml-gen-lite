# 查询APN绑定PA口UE互访白名单（LST UEMUTWLISTBIND）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF、PGW-U**

该命令用于查询APN下绑定的PA口UE互访白名单。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                               |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APNNAME | APN名称  | 可选必选说明：可选参数 参数含义：该参数用于指定APN实例名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”特殊字符，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

查询APN名称为testapn的APN下绑定的PA口UE互访白名单：

```
LST UEMUTWLISTBIND:APNNAME="testapn";
```
