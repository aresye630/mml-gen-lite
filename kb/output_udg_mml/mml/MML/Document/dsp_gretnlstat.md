# 查询GRE隧道数目（DSP GRETNLSTAT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询GRE隧道数目。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询GRE隧道数目：

```
DSP GRETNLSTAT:;
```

```
        RETCODE = 0  操作成功。

        结果如下
        --------
        IPv4 GRE隧道个数 = 1
        IPv6 GRE隧道个数 = 1

        (结果个数 = 1)
        ---    END
```

#### 输出结果说明

| 输出项名称        | 输出项解释             |
|:-------------|:------------------|
| IPv4 GRE隧道个数 | 用来显示IPv4 GRE隧道个数。 |
| IPv6 GRE隧道个数 | 用来显示IPv6 GRE隧道个数。 |
