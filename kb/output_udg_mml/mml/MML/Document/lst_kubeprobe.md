# 查询是否放通就绪状态检测（LST KUBEPROBE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询是否放通就绪状态检测。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询是否放通就绪状态检测。

```
%%LST KUBEPROBE:;%%
RETCODE = 0  操作成功

结果如下
--------
                  是否检测就绪状态 = 开启
        特定网元下是否检测就绪状态 = 开启
 PSP平台大颗粒服务是否检测就绪状态 = 开启
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称              | 输出项解释                        |
|:-------------------|:-----------------------------|
| 是否检测就绪状态           | 该参数用于表示是否放通就绪状态检测。           |
| 特定网元下是否检测就绪状态      | 该参数用于表示特定网元下是否放通就绪状态检测。      |
| PSP平台大颗粒服务是否检测就绪状态 | 该参数用于表示PSP平台大颗粒服务是否放通就绪状态检测。 |
