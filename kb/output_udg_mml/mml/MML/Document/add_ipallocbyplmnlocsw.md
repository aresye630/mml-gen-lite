# 添加基于位置区+PLMN分配地址的开关（ADD IPALLOCBYPLMNLOCSW）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于配置基于位置区+PLMN分配地址开关。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为30000。
- 在位置区组+PLMN映射地址池存在的情况下，若对应 ‘基于位置区组+PLMN分配地址开关-ADD IPALLOCBYPLMNLOCSW’ 配置为使能：
  漫游用户需严格基于位置区组+PLMN匹配地址池组，即仅能匹配中位置区组+PLMN映射地址池。
  本地用户优先匹配位置区组+PLMN映射址池组；若匹配不中，二次匹配单独基于位置区组映射地址池。
- 在位置区组+PLMN映射地址池存在的情况下，若对应 ‘基于位置区组+PLMN分配地址开关-ADD IPALLOCBYPLMNLOCSW’ 不存在或者配置为INHERIT状态时，地址分配流程受 ‘基于位置区组分配地址的开关-SET IPALLOCBYLOCSW’ 的控制。
- 在位置区组+PLMN映射地址池不存在的情况下，地址分配流程受 ‘基于位置区组分配地址的开关-SET IPALLOCBYLOCSW’ 的控制，不受 ‘基于位置区组+PLMN分配地址开关-ADD IPALLOCBYPLMNLOCSW’ 的控制。
- ‘基于位置区组+PLMN分配地址开关-ADD IPALLOCBYPLMNLOCSW’ 的配置生效条件：
  当SET APNIPALLOCRULE中参数ALLOCATTR配置了使用本APN配置，并且基于APN的地址分配规则SET APNIPALLOCRULE配置了按照位置区映射的地址范围分配地址的规则时，‘基于位置区组+PLMN分配地址开关-ADD IPALLOCBYPLMNLOCSW’ 的配置生效。
  当SET APNIPALLOCRULE中参数ALLOCATTR配置了使用继承全局配置，并且全局地址分配规则SET IPALLOCRULE配置了按照位置区映射的地址范围分配地址的规则时，‘基于位置区组+PLMN分配地址开关-ADD IPALLOCBYPLMNLOCSW’ 的配置生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称    | 参数说明                                                                                                                                                                                                         |
|:----------------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LOCATIONGRPTYPE | 位置区组类型  | 可选必选说明：必选参数 参数含义：该参数用于指定位置区组类型。 数据来源：本端规划 取值范围：枚举类型。只能选取一个选项。 LAC：LAC。TAC：TAC。 默认值：无 配置原则：无                                                                                                                  |
| LOCATIONGRPNAME | 位置区组名称  | 可选必选说明：必选参数 参数含义：该参数用于指定位置区组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：该位置区组名称必须通过ADD LACGROUP或ADD TACGROUP命令配置过。                                                                                      |
| MCC             | 移动国家码   | 可选必选说明：必选参数 参数含义：该参数用于指定移动国家码。 数据来源：全网规划 取值范围：字符串类型，为3位数字，000～999。 默认值：无 配置原则：无                                                                                                                              |
| MNC             | 移动网络号   | 可选必选说明：必选参数 参数含义：该参数用于指定移动网络号。 数据来源：全网规划 取值范围：字符串类型，可为2或3位数字，00~99或000~999。 默认值：无 配置原则：MNC有效配置长度为两位或三位。配置长度取决于PFCP Session Establishment Request消息ULI信元中携带的MNC有效值的长度，两位有效数字即配置两位，三位有效数字需配置三位。不受ADD MNCLEN影响。 |
| SWITCH          | IPv4 开关 | 可选必选说明：可选参数 参数含义：该参数用于指定基于位置区分配地址的IPv4开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。INHERIT：继承。 默认值：无 配置原则：无                                                                                                |
| IPV6SWITCH      | IPv6 开关 | 可选必选说明：可选参数 参数含义：该参数用于指定基于位置区分配地址的IPv6开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。INHERIT：继承。 默认值：无 配置原则：无                                                                                                |

#### 使用实例

在位置区组tacgrp1+PLMN 460011映射地址池存在的情况下，允许激活携带信源tac属于tacgrp1，且PLMN为460011的用户基于位置区分配IPV4地址；不允许该用户基于位置区分配IPV6地址：

```
ADD IPALLOCBYPLMNLOCSW: LOCATIONGRPTYPE=TAC, LOCATIONGRPNAME="tacgrp1", MCC="460", MNC="011", SWITCH=ENABLE, IPV6SWITCH=DISABLE;
```
