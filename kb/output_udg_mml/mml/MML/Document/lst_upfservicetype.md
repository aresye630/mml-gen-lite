# 查询UPF可选服务类型（LST UPFSERVICETYPE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于显示查询UPF可选服务类型。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询UPF可选服务类型：

```
LST UPFSERVICETYPE:;
```

```
RETCODE = 0 操作成功

结果如下
------------------
可选服务类型1  =  IISA
可选服务类型2  =  Relay
可选服务类型3  =  MobileVPN
(结果个数 = 1)
--- END
```

#### 输出结果说明

参见SET UPFSERVICETYPE的参数说明。
