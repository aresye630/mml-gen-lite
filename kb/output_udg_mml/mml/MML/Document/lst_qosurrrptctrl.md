# 查询QoS URR上报的相关参数（LST QOSURRRPTCTRL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询QoS URR上报的相关参数。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询QoS URR上报的相关参数：

```
LST QOSURRRPTCTRL:;
```

```
RETCODE = 0 操作成功。

设置QoS URR上报的的相关参数。
------------------------
   QoS类型URR Stop上报迟滞时间（秒）  =  20
Rule删除时触发QoS URR Stop上报的开关  =  使能
                 QoS质差分析上报开关  =  不使能
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见SET QOSURRRPTCTRL的参数说明。
