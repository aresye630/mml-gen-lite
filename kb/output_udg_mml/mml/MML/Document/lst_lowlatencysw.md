# 查询低时延业务开关（LST LOWLATENCYSW）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明

- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询低时延业务开关。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询低时延业务开关：

```
%%LST LOWLATENCYSW:;
```

```
%%
RETCODE = 0 操作成功

低时延业务开关
--------------
低时延业务开关 = 不使能
(结果个数 = 1)

--- END
```

#### 输出结果说明

参见SET LOWLATENCYSW的参数说明。
