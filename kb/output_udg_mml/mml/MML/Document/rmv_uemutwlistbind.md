# 删除APN绑定PA口UE互访白名单（RMV UEMUTWLISTBIND）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、PGW-U**

该命令用于删除APN与PA口UE互访白名单的绑定关系。

#### 注意事项

- 该命令执行后，对新激活的用户生效；对于已在线的用户，需要N9承载的对端IP地址发生变更时才会生效，该修改通过承载更新消息下发。
- 该命令执行后，发生ssg进程复位后对所有用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                   |
|:----------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APNNAME   | APN名称  | 可选必选说明：必选参数 参数含义：该参数用于指定APN实例名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”特殊字符，不区分大小写。 默认值：无 配置原则：无     |
| WLISTTYPE | 白名单类型  | 可选必选说明：必选参数 参数含义：该参数用于指定白名单类型。 数据来源：本端规划 取值范围：枚举类型。 SGWUUPF 默认值：无 配置原则：无                                                                                                                               |
| WLISTNAME | 白名单名称  | 可选必选说明：必选参数 参数含义：该参数用于指定UE互访白名单名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

删除 APN名称为testapn下绑定的类型为UPF的白名单名称为testwlist的白名单：

```
RMV UEMUTWLISTBIND:APNNAME="testapn",WLISTTYPE=UPF,WLISTNAME="testwlist";
```
