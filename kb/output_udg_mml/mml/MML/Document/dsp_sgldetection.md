# 显示模块级KPI异常检测隔离结果（DSP SGLDETECTION）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示模块级KPI异常检测隔离结果。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                   |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------|
| HOSTNAME | 主机名称   | 可选必选说明：可选参数  参数含义：该参数用于指定主机的名称，可通过DSP POD获取“主机名称”。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~127。  默认值：无  配置原则：无 |

## 使用实例

显示模块级KPI异常检测隔离结果。

```
%%DSP SGLDETECTION:;%%
RETCODE = 0  操作成功

结果如下
--------
主机名称  =  vlab10-dc12-sr5-slot23
 Pod名称  =  vusn-pod-0
隔离策略  =  Pod隔离
隔离结果  =  隔离成功
隔离时间  =  2025-04-09 12:10:28+00:00    
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                                                                                                                                                                                                                                                                                                          |
|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 主机名称    | 该参数用于指定主机的名称，可通过DSP POD获取“主机名称”。                                                                                                                                                                                                                                                                                                                                                                               |
| Pod名称   | 该参数表示主机上的隔离Pod名称。                                                                                                                                                                                                                                                                                                                                                                                              |
| 隔离策略    | 该参数表示业务隔离策略。 取值说明： “PODISOLATION（Pod隔离）”：Pod隔离“SERVICEMIGRATION（业务迁移）”：业务迁移“MODULEISOLATION（模块隔离）”：模块隔离                                                                                                                                                                                                                                                                                                        |
| 隔离结果    | 该参数表示隔离操作结果。 取值说明： “ISOLATIONSUCCEEDED（隔离成功）”：隔离成功“ISOLATIONFAILED（隔离失败）”：隔离失败“MANUALISOLATIONREQUIRED（未隔离；需人工隔离）”：未隔离；需人工隔离“INSUFFICIENTCAPACITY（未隔离；剩余容量不足）”：未隔离；剩余容量不足“SAMETYPEFAULT（未隔离；其余Host上无同类型实例或同类型实例故障）”：未隔离；其余Host上无同类型实例或同类型实例故障“ISOLATIONOPERATED（未隔离；其余Host上存在隔离操作）”：未隔离；其余Host上存在隔离操作“UNKNOWNREASON（未隔离；未知原因）”：未隔离；未知原因“UNDERISOLATION（隔离中）”：隔离中“NOTNOTIFIED（未隔离；网元未通知可隔离Pod）”：未隔离；网元未通知可隔离Pod |
| 隔离时间    | 该参数表示隔离成功时间。                                                                                                                                                                                                                                                                                                                                                                                                   |
