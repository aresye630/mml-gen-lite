# 设置Work过滤规则信息（SET MSSWORKFILTER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

本命令属于高危命令，操作不当会导致性能下降，请谨慎使用并联系华为技术支持协助操作。

该命令用于设置Work的过滤规则信息。

Work是转发调度的基本单元，可以通过设置特定的规则，将符合规则的Work运行信息记录下来并可以查询，进行故障诊断。

设置Work过滤规则之后，系统性能会下降0.2%左右。

#### 注意事项

- 该命令执行后立即生效。
- 本命令用于使能work过滤规则开关，使能后会降低性能且在用户指定的时间之后会自动去使能，关闭后会恢复性能。默认时间是60秒。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                                                |
|:-------------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------|

| RULEFLAG     | 规则标志位   | 可选必选说明：必选参数 参数含义：该参数用于标识规则打开还是关闭。 数据来源：本端规划 取值范围：枚举类型。 FALSE：关闭。TRUE：打开。 默认值：无                                                                      |
| WORKTYPE     | Work类型  | 可选必选说明：条件可选参数 前提条件：该参数在“RULEFLAG”配置为“TRUE”时为可选参数。 参数含义：该参数用于表示Work类型。如果不输入该参数，则表示匹配所有Work类型。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无           |

| QOS          | 权重      | 可选必选说明：条件可选参数 前提条件：该参数在“RULEFLAG”配置为“TRUE”时为可选参数。 参数含义：该参数用于表示Work的QoS权重。如果不输入该参数，则表示匹配所有QoS权重。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无        |
| SCHEDULETYPE | 调度类型    | 可选必选说明：条件可选参数 前提条件：该参数在“RULEFLAG”配置为“TRUE”时为可选参数。 参数含义：该参数用于表示Work的调度类型。 数据来源：本端规划 取值范围：枚举类型。 fixed：静态调度类型。dynamic：动态调度类型。all：全部调度类型。 默认值：all       |

| USERDATA1    | 第二个参数   | 可选必选说明：条件可选参数 前提条件：该参数在“RULEFLAG”配置为“TRUE”时为可选参数。 参数含义：该参数用于表示Work的第二个自定义参数。如果不输入该参数，则表示匹配第二个自定义参数所有值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无 |
| RECORDNUM    | 记录条目数   | 可选必选说明：条件可选参数 前提条件：该参数在“RULEFLAG”配置为“TRUE”时为可选参数。 参数含义：该参数用于表示本次规则设置的记录条目数。 数据来源：本端规划 取值范围：整数类型，取值范围为1～1000。 默认值：100                                |

#### 使用实例

设置任务过滤规则：

```
SET MSSWORKFILTER:RULEFLAG = TRUE, RUNAME = "VNODE_VNRS_VNFC_IPU_0064";
```
