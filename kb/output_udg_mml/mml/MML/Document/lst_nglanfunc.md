# 查询5G LAN功能配置（LST NGLANFUNC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询5G LAN功能开关状态。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询5G LAN功能开关：

```
LST NGLANFUNC:;
```

```
返回值 = 0  操作成功

5G LAN 功能配置
-----------------------------
5G LAN 功能开关  =  开启
N19数据转发开关  =  开启
(结果数= 1)

---    结束
```

#### 输出结果说明

参见SET NGLANFUNC的参数说明。
