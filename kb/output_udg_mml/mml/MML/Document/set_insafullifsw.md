# 设置全量智能SA识别开关（SET INSAFULLIFSW）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，当开启开关后，此命令会对ISU资源和性能影响产生极大挑战，开启后可能会发生CPU过载。

设置全量非可信流量上送TPU推理。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | INFERSWITCH   |
|:-------|:--------------|
| 初始值    | DISABLE       |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                   |
|:--------------|:-------|:-----------------------------------------------------------------------------------------------------------------------|
| INFERSWITCH   | 全量推理开关 | 可选必选说明：必选参数 参数含义：该参数用于设置是否全量非可信流量使用智能识别。 数据来源：本端规划 取值范围： DISABLE：全量非可信流量使用智能识别不使能。ENABLE：全量非可信流量使用智能识别使能。 默认值：无 配置原则：无 |
| CFGDOMAINNAME | 配置域名称  | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无                                     |

#### 使用实例

设置全量智能SA识别开关为开：

```
SET INSAFULLIFSW:INFERSWITCH=ENABLE;
```
