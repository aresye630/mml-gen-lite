# 查询告警配置信息（LST ALMINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询系统内告警配置信息。

## 注意事项

默认查询64条，最大支持1000条告警。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                              |
|:----------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID      | 网元ID   | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个网元来查询告警配置信息。 取值范围：0~65535 默认值：无。 配置原则：若不输入，则表示查询所有网元的告警配置信息，网元ID可以通过LST ME命令查询。                                                     |
| SAID      | 起始告警ID | 可选必选说明：可选参数。 参数含义：用于指示系统查询时，告警ID的取值下限。 取值范围：0~999999999 默认值：无。 配置原则：若不输入，则表示取值下限大于等于0且小于等于结束告警ID。                                                                 |
| MASKED    | 是否屏蔽   | 可选必选说明：必选参数。 参数含义：用于指示告警是否屏蔽的标识。 取值范围： “ALL(全部)”：表示查询屏蔽和未屏蔽告警。“UNMASKED(未屏蔽)”：表示只查询未屏蔽告警。 “MASKED(已屏蔽)”：标识只查询屏蔽告警。 默认值：“ALL(全部)”。 配置原则：无。                         |
| EAID      | 结束告警ID | 可选必选说明：可选参数。 参数含义：用于指示系统查询时，告警ID的取值上限。 取值范围：0~999999999 默认值：无。 配置原则：若不输入，则表示取值上限小于等于999999999且大于等于起始告警ID。                                                         |
| MASK_TYPE | 屏蔽类型   | 可选必选说明：可选参数。 参数含义：用于指示系统需要以哪种屏蔽类型来查询告警配置信息。 取值范围： “BYID(按告警ID)”：表示按告警ID查询告警配置信息。“BYPARAMS(按告警参数)”：表示按告警参数查询告警配置信息。 默认值：“BYID(按告警ID)”。 配置原则：若不输入，则表示按告警ID查询告警配置信息。 |
| CNT       | 返回记录数  | 可选必选说明：可选参数。 参数含义：用于指示系统返回记录条数的最大值。 取值范围：1~1000 默认值：无。 配置原则：若不输入，则表示返回记录的最大数目是64。                                                                                 |

## 使用实例

1. 按告警ID查询告警配置信息：

   ```
   %%LST ALMINFO: MEID=0, SAID=5521, EAID=5521, MASKED=ALL, CNT=1;%%
   RETCODE = 0  操作成功

   告警配置信息
   ------------
     网元ID  =  0
   网元名称  =  omteam15-v6-2
     告警ID  =  5521
   告警名称  =  服务中心和服务通信故障
   是否屏蔽  =  已屏蔽
   (结果个数 = 1)

   统计信息
   --------
   符合查询条件的总记录数  =  1
           实际返回记录数  =  1
   (结果个数 = 1)

   ---    END
   ```
2. 按告警参数查询已屏蔽的告警配置信息：

   ```
   %%LST ALMINFO: MASKED=MASKED, MASK_TYPE=BYPARAMS;%% 
   RETCODE = 0  操作成功  

   告警配置信息 
   ------------   
   网元ID    =  12 
   网元名称  =  superom07-v4   
   告警ID    =  36161 
   告警名称  =  GO服务进程故障告警 
   屏蔽规则  =  进程号=0,进程名=Test 
   (结果个数 = 1)  

   统计信息 
   -------- 
   符合查询条件的总记录数  =  1         
           实际返回记录数  =  1 
   (结果个数 = 1)  

   ---    END
   ```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息，输出结果说明如表1所示。

命令执行异常，会返回提示对应的失败信息。错误码列表如表2所示。

| 输出项名称       | 输出项解释             |
|:------------|:------------------|
| 网元ID        | 用于表示产生告警的网元对应的ID。 |
| 网元名称        | 用于表示产生告警的网元名称。    |
| 告警ID        | 用于表示产生告警的ID。      |
| 告警名称        | 用于表示产生告警的名称。      |
| 是否屏蔽        | 用于表示告警是否被屏蔽。      |
| 屏蔽规则        | 用于表示告警按参数屏蔽的屏蔽规则。 |
| 符合查询条件的总记录数 | 用于表示符合查询条件的总记录数。  |
| 实际返回记录数     | 用于表示实际返回记录数。      |

|    错误码 | 错误码解释   | 原因分析    | 处理建议        |
|-------:|:--------|:--------|:------------|
| 113001 | 参数不合法   | 输入参数错误。 | 参考参数说明输入参数。 |
| 113002 | 数据库执行失败 | 数据库异常。  | 请联系华为技术支持。  |
