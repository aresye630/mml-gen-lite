# 设置欠费用户下行RST报文处理动作（SET TCPRST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用来配置欠费用户下行TCP RST报文的处理动作。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | ACTION   | SIGONLYRSTACT   |
|:-------|:---------|:----------------|
| 初始值    | PASS     | PASS            |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称             | 参数说明                                                                                                                            |
|:--------------|:-----------------|:--------------------------------------------------------------------------------------------------------------------------------|
| ACTION        | 欠费用户下行RST报文处理动作  | 可选必选说明：必选参数 参数含义：欠费用户下行RST报文处理动作。 数据来源：本端规划 取值范围：枚举类型。 PASS：允许报文通过。DROP：报文丢弃。 默认值：无 配置原则：无                                      |
| SIGONLYRSTACT | 欠费用户纯RST信令报文处理动作 | 可选必选说明：条件可选参数 前提条件：该参数在“ACTION”配置为“PASS”时为可选参数。 参数含义：欠费用户纯RST信令报文处理动作。 数据来源：本端规划 取值范围：枚举类型。 PASS：允许报文通过。DROP：报文丢弃。 默认值：无 配置原则：无 |

#### 使用实例

配置允许欠费用户下行RST报文通过，但是丢弃欠费用户下行纯RST信令报文：

```
SET TCPRST: ACTION=PASS, SIGONLYRSTACT=DROP;
```
