# 设置双发选收配置（SET NGDFSRFUNC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于设置指定5G LAN组的双发选收功能开关。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为3000。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                  |
|:-----------|:----------|:--------------------------------------------------------------------------------------|
| VNINSTANCE | 5G LAN组名称 | 可选必选说明：必选参数 参数含义：该参数用于指定5G LAN会话实例名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为18～37。 默认值：无 配置原则：无 |
| DFSRSWITCH | 双发选收功能开关  | 可选必选说明：必选参数 参数含义：双发选收功能开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无   |

#### 使用实例

开启双发选收开关：

```
SET NGDFSRFUNC: VNINSTANCE="a0000001-460-003-01", DFSRSWITCH=ENABLE;
```
