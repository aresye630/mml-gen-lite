# 查询全局Gi重定向信息（LST GIREDIRECTFUNC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用来查询全局IPv4和IPv6 Gi重定向开关。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询IPv4和IPv6 Gi重定向全局开关：

```
LST GIREDIRECTFUNC:;
```

```
RETCODE = 0  操作成功。

结果如下
--------
IPV4全局Gi重定向开关  =  使能
IPV6全局Gi重定向开关  =  使能
(结果个数 = 1)
---    END
```
