# 设置媒体中继全局业务参数控制（SET GLBRLYSPARACTL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于配置媒体中继全局业务参数控制。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   |   UESRVWAITTIME |   CDNSRVWAITTM |   VODMAXDATASIZE |   CDNIPWAITTIME |   ORIGINRETRYTMS |   MAXORIGINRDTMS |   DNSFTTRYTM |   DNSRSPETRYTM |   MAXDNSIDLETM |   DBGSAMPLERATE | LOGMSGSW                                | TCPCHKSW   | HTTPCHKSW   |   VODFSTPUSHLEN |   VODPUSHACKNUM |   VODPRELOADLEN |   LIVEFSTPUSHLEN |   LIVEPUSHACKNUM |
|:-------|----------------:|---------------:|-----------------:|----------------:|-----------------:|-----------------:|-------------:|---------------:|---------------:|----------------:|:----------------------------------------|:-----------|:------------|----------------:|----------------:|----------------:|-----------------:|-----------------:|
| 初始值    |              15 |              5 |               50 |               5 |                2 |                3 |            5 |             30 |             30 |               1 | UEVODREQ、UELIVEREQ、CDNVODREQ、CDNLIVEREQ | ENABLE     | ENABLE      |             512 |               0 |            1024 |             1024 |                0 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称               | 参数说明                                                                                                                                                                                                               |
|:---------------|:-------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UESRVWAITTIME  | 用户业务等待时间（秒）        | 可选必选说明：可选参数 参数含义：该参数用来指定UE业务等待时间。 数据来源：本端规划 取值范围：整数类型，取值范围为1~30，单位为秒。 默认值：无 配置原则：无                                                                                                                                 |
| CDNSRVWAITTM   | 回源业务数据等待时间（秒）      | 可选必选说明：可选参数 参数含义：该参数用来指定回源业务数据等待时间。 数据来源：本端规划 取值范围：整数类型，取值范围为1~30，单位为秒。 默认值：无 配置原则：无                                                                                                                               |
| VODMAXDATASIZE | 点播推流最大数据块（千字节）     | 可选必选说明：可选参数 参数含义：该参数用来指定每次点播业务推送的最大数据块。每5ms推送一次点播业务数据，实际推送的数据块大小受限于TCP发送窗口状态。 数据来源：本端规划 取值范围：整数类型，取值范围为1~1024，单位为千字节。 默认值：无 配置原则：无                                                                                 |
| CDNIPWAITTIME  | 获取CDNIP的最大等待时长（秒）  | 可选必选说明：可选参数 参数含义：该参数用来指定获取CDNIP最大等待时长。 数据来源：本端规划 取值范围：整数类型，取值范围为2~30，单位为秒。 默认值：无 配置原则：无                                                                                                                            |
| ORIGINRETRYTMS | 回源重试次数（次数）         | 可选必选说明：可选参数 参数含义：该参数用来指定回源重试次数。实际回源重试次数受获取到的CDN IP个数影响，当只有一个IP地址时，只重试一次；当配置的重试次数大于等于IP个数时，实际重试次数为（IP个数-1）次，即每个IP都访问一次；当配置的重试次数小于IP个数时，实际重试次数为配置的重试次数，即只向部分IP发送请求。 数据来源：本端规划 取值范围：整数类型，取值范围为0~5，单位为次数。 默认值：无 配置原则：无 |
| MAXORIGINRDTMS | 回源重定向最大次数（次数）      | 可选必选说明：可选参数 参数含义：该参数用来指定回源重定向最大次数。 数据来源：本端规划 取值范围：整数类型，取值范围为1~5，单位为次数。 默认值：无 配置原则：无                                                                                                                                |
| DNSFTTRYTM     | 回源DNS服务器故障重试间隔（秒）  | 可选必选说明：可选参数 参数含义：该参数用来指定回源DNS服务器故障重试间隔。 数据来源：本端规划 取值范围：整数类型，取值范围为1~600，单位为秒。 默认值：无 配置原则：无                                                                                                                          |
| DNSRSPETRYTM   | 回源DNS响应异常最小重试间隔（秒） | 可选必选说明：可选参数 参数含义：该参数用来指定回源DNS响应异常最小重试间隔。 数据来源：本端规划 取值范围：整数类型，取值范围为5~600，单位为秒。 默认值：无 配置原则：无                                                                                                                         |
| MAXDNSIDLETM   | 回源DNS记录最大空闲时长（分钟）  | 可选必选说明：可选参数 参数含义：该参数用来指定回源DNS记录最大空闲时长。 数据来源：本端规划 取值范围：整数类型，取值范围为5~1440，单位为分钟。 默认值：无 配置原则：无                                                                                                                         |
| DBGSAMPLERATE  | 业务流抽样率（万分比）        | 可选必选说明：可选参数 参数含义：该参数用来指定记录关键流程日志的业务流抽样率。 数据来源：本端规划 取值范围：整数类型，取值范围为0~10000，单位为万分比。 默认值：无 配置原则：无                                                                                                                     |
| LOGMSGSW       | 抽样日志类型开关           | 可选必选说明：可选参数 参数含义：该参数用来指定抽样日志记录类型。 数据来源：本端规划 取值范围：枚举类型。 UEVODREQ：推流点播请求。UELIVEREQ：推流直播请求。CDNVODREQ：回源点播请求。CDNLIVEREQ：回源直播请求。 默认值：无 配置原则：无                                                                           |
| TCPCHKSW       | TCP资源核查开关          | 可选必选说明：可选参数 参数含义：该参数用于控制开启或关闭TCP资源核查开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能TCP资源核查开关。ENABLE：使能TCP资源核查开关。 默认值：无 配置原则：无                                                                                                 |
| HTTPCHKSW      | HTTP资源核查开关         | 可选必选说明：可选参数 参数含义：该参数用于控制开启或关闭HTTP资源核查开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能HTTP资源核查开关。ENABLE：使能HTTP资源核查开关。 默认值：无 配置原则：无                                                                                              |
| VODFSTPUSHLEN  | 点播业务首次推送数据大小（千字节）  | 可选必选说明：可选参数 参数含义：该参数用于指定点播业务首次推送数据大小。 数据来源：本端规划 取值范围：整数类型，取值范围为100~4096，单位为千字节。 默认值：无 配置原则：无                                                                                                                       |
| VODPUSHACKNUM  | 点播推流ACK间隔（次数）      | 可选必选说明：可选参数 参数含义：该参数用来指定点播推流ACK间隔（次数）。 数据来源：本端规划 取值范围：整数类型，取值范围为0~50，单位为次数。 默认值：无 配置原则：无                                                                                                                           |
| VODPRELOADLEN  | 点播回源预加载数据大小（千字节）   | 可选必选说明：可选参数 参数含义：该参数用来指定点播回源预加载数据大小。 数据来源：本端规划 取值范围：整数类型，取值范围为100~10240或0,，单位为千字节。 默认值：无 配置原则：无                                                                                                                    |
| LIVEFSTPUSHLEN | 直播业务首次推送数据大小（千字节）  | 可选必选说明：可选参数 参数含义：该参数用于指定直播业务首次推送数据大小。 数据来源：本端规划 取值范围：整数类型，取值范围为100~10240，单位为千字节。 默认值：无 配置原则：无                                                                                                                      |
| LIVEPUSHACKNUM | 直播推流ACK间隔（次数）      | 可选必选说明：可选参数 参数含义：该参数用来指定直播推流ACK间隔（次数）。 数据来源：本端规划 取值范围：整数类型，取值范围为0~50，单位为次数。 默认值：无 配置原则：无                                                                                                                           |

#### 使用实例

假如需要创建配置媒体中继全局业务参数控制，则命令如下：

```
SET GLBRLYSPARACTL: UESRVWAITTIME=10, VODMAXDATASIZE=20, CDNIPWAITTIME=10, ORIGINRETRYTMS=2, MAXORIGINRDTMS=2, VODFSTPUSHLEN=1000, VODPUSHACKNUM=10, VODPRELOADLEN=10000, LIVEFSTPUSHLEN=1000, LIVEPUSHACKNUM=10;
```
