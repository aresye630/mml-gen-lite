# 删除组播组配置（RMV MULTICASTGRP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于删除静态组播组配置。

#### 注意事项

- 该组播组记录必须已经存在。
- 该组播组内如果有IMSI或与5G LAN会话实例绑定，则不能删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                 |
|:-------------|:-------|:-------------------------------------------------------------------------------------|
| MCASTGRPNAME | 组播组名称  | 可选必选说明：必选参数 参数含义：该参数用于配置组播组的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63，区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

删除一个静态组播组配置：

```
RMV MULTICASTGRP: MCASTGRPNAME="group";
```
