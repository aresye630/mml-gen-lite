# 设置APN主备状态动态管理开关（SET APNDYNSTATESW）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，设置APN主备状态动态管理功能后，系统内部的主备状态会影响IKE会话接入。

该命令用于配置是否开启指定APN主备状态动态管理功能。

#### 注意事项

- 该命令执行后立即生效。
- 系统最多支持配置32个APN开启此功能。
- 该功能用于智家随行业务特性部署时，主备UPF容灾场景下，备UPF上基于N4信令完成专用DNN的本地主备状态动态管理。
- 该功能的配置仅限于备UPF，并要求备UPF处于未承载业务状态。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | SWITCH   |
|:-------|:---------|
| 初始值    | DISABLE  |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                   |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN    | APN名称  | 可选必选说明：必选参数 参数含义：该参数用于指定APN实例名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“ ” ”、“ ` ”特殊字符，不区分大小写。 默认值：无 配置原则：无 |
| SWITCH | 开关标识   | 可选必选说明：必选参数 参数含义：主备状态动态管理功能开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：关闭主备状态动态管理功能。ENABLE：开启主备状态动态管理功能。 默认值：无 配置原则：无                                                                                             |

#### 使用实例

使能apn apn1.com的主备状态动态管理：

```
SET APNDYNSTATESW: APN="apn1.com", SWITCH=ENABLE;
```
