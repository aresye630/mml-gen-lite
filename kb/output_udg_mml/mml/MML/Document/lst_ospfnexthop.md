# 查询OSPF等价路由优先级配置（LST OSPFNEXTHOP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询OSPF等价路由优先级配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                   |
|:-------------|:--------|:-----------------------------------------------------------------------|
| PROCID       | 进程号     | 可选必选说明：可选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 |
| NBRIPADDRESS | 下一跳IP地址 | 可选必选说明：可选参数 参数含义：下一跳IP地址。 数据来源：本端规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无       |

#### 使用实例

查询OSPF等价路由优先级配置：

```
LST OSPFNEXTHOP:;
```

```
RETCODE = 0  操作成功。

结果如下
-----------
      进程号  =  1
    拓扑标识  =  0
下一跳IP地址  =  10.4.4.4
  下一跳权重  =  10
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                         |
|:--------|:------------------------------|
| 进程号     | 该参数指定用户创建的OSPF进程号。            |
| 拓扑标识    | 该参数指定用户创建的OSPF拓扑标识。           |
| 下一跳IP地址 | 该参数指定等价路由的下一跳IP地址。            |
| 下一跳权重   | 该参数指定等价路由的下一跳权重。该值越小，路由优先级越高。 |
