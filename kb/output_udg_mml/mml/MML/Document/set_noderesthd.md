## 命令功能

**须知** 

该命令为高危命令，执行将修改节点资源告警阈值，影响资源告警的上报，请慎重执行。

该命令用于设置节点资源告警阈值。

## 注意事项

- 该命令不支持在BYPASS期间执行。

- 该配置区分版本，版本升级或补丁安装场景会继承低版本配置，版本回退或补丁回退场景会退回低版本配置。

- 配置在本分钟的前九秒内设置，则在本分钟的第十秒生效，否则在下一分钟的第十秒生效。

节点资源告警默认阈值配置如下表1。

| 资源类型   | 开关   | 触发阈值   |   触发连续次数 | 恢复阈值   |   恢复连续次数 |
|:-------|:-----|:-------|---------:|:-------|---------:|
| CPU共享核 | 开启   | 90%    |        3 | 80%    |        3 |
| CPU隔离核 | 开启   | 95%    |        3 | 85%    |        3 |

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                         |
|:-----------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RES_TYPE   | 资源类型   | 可选必选说明：必选参数。 参数含义：标识可配置的资源类型。 取值范围： “S_CORE(CPU共享核)”“I_CORE(CPU隔离核)”“CLEAR(清除配置)” 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                             |
| ENABLE     | 开关     | 可选必选说明：在“资源类型”配置为“S_CORE(CPU共享核)”或“I_CORE(CPU隔离核)”时为条件必选参数。 参数含义：对应资源类型的告警检测开关。 取值范围： “ON(开启)”：在“资源类型”配置为“S_CORE(CPU共享核)”或“I_CORE(CPU隔离核)”时，当节点的CPU核使用率超阈值会上报ALM-135556 CPU核过载告警。“OFF(关闭)”：关闭检测开关。 默认值：ON。 配置原则： 当取值为“OFF(关闭)”，且未更改“触发阈值”、“触发连续次数”、“恢复阈值”和“恢复连续次数”参数的配置时，已上报的ALM-135556 CPU核过载告警在满足恢复阈值时才会被清除。当取值为“OFF(关闭)”，且更改了“触发阈值”、“触发连续次数”、“恢复阈值”和“恢复连续次数”任一参数的配置后，已上报的ALM-135556 CPU核过载告警会在下一个检测周期被清除。 |
| T_VALUE    | 触发阈值   | 可选必选说明：在“资源类型”配置为“S_CORE(CPU共享核)”或“I_CORE(CPU隔离核)”时为条件可选参数。 参数含义：标识触发告警的阈值。 取值范围：1~100 默认值：无。 配置原则：在“资源类型”配置为“S_CORE(CPU共享核)”或“I_CORE(CPU隔离核)”时，该值的单位为%。                                                                                                                                                                                                                                                     |
| T_COUNT    | 触发连续次数 | 可选必选说明：在“资源类型”配置为“S_CORE(CPU共享核)”或“I_CORE(CPU隔离核)”时为条件可选参数。 参数含义：标识触发告警的连续检测次数。 取值范围：1~30 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                     |
| R_VALUE    | 恢复阈值   | 可选必选说明：在“资源类型”配置为“S_CORE(CPU共享核)”或“I_CORE(CPU隔离核)”时为条件可选参数。 参数含义：标识恢复告警的阈值。 取值范围：0~100 默认值：无。 配置原则： 需小于配置的触发阈值。在“资源类型”配置为“S_CORE(CPU共享核)”或“I_CORE(CPU隔离核)”时，该值的单位为%。                                                                                                                                                                                                                                         |
| R_COUNT    | 恢复连续次数 | 可选必选说明：在“资源类型”配置为“S_CORE(CPU共享核)”或“I_CORE(CPU隔离核)”时为条件可选参数。 参数含义：标识恢复告警的连续检测次数。 取值范围：1~30 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                     |
| CLEAR_TYPE | 清除项    | 可选必选说明：在“资源类型”配置为“CLEAR(清除配置)”时为条件必选参数。 参数含义：标识要清除的资源类型，执行后对应资源类型的配置更改为默认值，参见表1。 取值范围： “ALL(全部配置)”“S_CORE(CPU共享核)”“I_CORE(CPU隔离核)” 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                            |

## 使用实例

设置节点资源告警阈值：

```
%%SET NODERESTHD: RES_TYPE=S_CORE, ENABLE=ON, T_VALUE=95, T_COUNT=2;%%
RETCODE = 0  操作成功

---    END
```
