# 添加PIM静态RP配置（ADD PIMSTATICRP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于添加静态RP配置。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为65535。
- 通过重复执行该命令可以最多配置50个静态RP，但同一个ACL不能对应到多个静态RP，如果不引用ACL，则只能配置一个静态RP。
- 需要首先在公网或VPN实例下配置ADD MCASTENABLE命令。
- 需要首先通过命令ADD PIMSITE使能PIM。
- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称        | 参数说明                                                                                                               |
|:----------------|:------------|:-------------------------------------------------------------------------------------------------------------------|
| ADDRESSFAMILY   | 地址族         | 可选必选说明：必选参数 参数含义：该参数用于表示地址族类型。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。 默认值：无                                      |
| VRFNAME         | VPN实例名称     | 可选必选说明：可选参数 参数含义：该参数用于表示VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：_public_ 配置原则：通过LST L3VPNINST查看当前已存在的VPN实例。 |
| STATICRPADDR    | 静态RP的地址     | 可选必选说明：条件必选参数 前提条件：该参数在“ADDRESSFAMILY”配置为“ipv4unicast”时为必选参数。 参数含义：该参数用于表示静态RP地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无   |
| STATICRPPLYIPV4 | 静态RP策略      | 可选必选说明：可选参数 参数含义：该参数用于表示静态RP名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无                                            |
| PREFERENCE      | 静态RP的优先级    | 可选必选说明：可选参数 参数含义：该参数用于表示静态RP优先。 数据来源：本端规划 取值范围：整数类型，取值范围为0～1。 默认值：0                                                |
| BIDIRENABLE     | 静态RP使能双向PIM | 可选必选说明：可选参数 参数含义：该参数用于表示静态RP使能双向PIM。 数据来源：本端规划 取值范围：枚举类型。 FALSE：不使能。TRUE：使能。 默认值：FALSE                             |

#### 使用实例

添加PIM静态RP配置(192.168.0.1)：

```
ADD PIMSTATICRP:VRFNAME="_public_",ADDRESSFAMILY=ipv4unicast,STATICRPADDR="192.168.0.1";
```
