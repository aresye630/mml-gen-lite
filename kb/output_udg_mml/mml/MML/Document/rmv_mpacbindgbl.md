# 删除MPAC全局策略（RMV MPACBINDGBL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除全局MPAC策略。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                |
|:----------|:-------|:------------------------------------------------------------------------------------|
| IPVERSION | IP版本   | 可选必选说明：必选参数 参数含义：该参数用于指定IP版本。 数据来源：本端规划 取值范围：枚举类型。 IPv4：IPv4协议族。IPv6：IPv6协议族。 默认值：无 |

#### 使用实例

删除MPAC全局策略：

```
RMV MPACBINDGBL:IPVERSION=IPv4;
```
