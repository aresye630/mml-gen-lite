# 查询CSLB分片重组统计配置（LST LBFRSTATCFG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询SET LBFRSTATCFG设置分片资源topN高的对端ip地址的参数。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询分片资源topN高的对端ip地址的参数，命令如下：

```
LST LBFRSTATCFG:;
```

```
%%LST LBFRSTATCFG:;%%
RETCODE = 0  操作成功

操作结果如下：
--------------
    基于对端IP的统计开关  =  基于对端IP的统计开关开启
基于对端IP的统计开关阈值  =  200
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见SET LBFRSTATCFG的参数说明。
