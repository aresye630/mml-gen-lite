# 修改防火墙策略（MOD FWPOLICY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于修改防火墙策略。通过该命令可以修改防火墙策略对上下行发起业务流的上下行报文控制策略。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称          | 参数说明                                                                                                         |
|:---------------|:--------------|:-------------------------------------------------------------------------------------------------------------|
| FWPOLICYNAME   | 防火墙策略名称       | 可选必选说明：必选参数 参数含义：该参数用于指定防火墙策略的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无                |
| UPINITUPACTION | 上行发起业务流上行门控动作 | 可选必选说明：可选参数 参数含义：该参数用于指定上行发起业务流上行门控动作。 数据来源：本端规划 取值范围：枚举类型。 PASS：表示业务报文直接通过。DISCARD：表示业务报文直接丢弃。 默认值：无 配置原则：无 |
| UPINITDNACTION | 上行发起业务流下行门控动作 | 可选必选说明：可选参数 参数含义：该参数用户指定上行发起业务流下行门控动作。 数据来源：本端规划 取值范围：枚举类型。 PASS：表示业务报文直接通过。DISCARD：表示业务报文直接丢弃。 默认值：无 配置原则：无 |
| DNINITUPACTION | 下行发起业务流上行门控动作 | 可选必选说明：可选参数 参数含义：该参数用于指定下行发起业务流上行门控动作。 数据来源：本端规划 取值范围：枚举类型。 PASS：表示业务报文直接通过。DISCARD：表示业务报文直接丢弃。 默认值：无 配置原则：无 |
| DNINITDNACTION | 下行发起业务流下行门控动作 | 可选必选说明：可选参数 参数含义：该参数用于指定下行发起业务流下行门控动作。 数据来源：本端规划 取值范围：枚举类型。 PASS：表示业务报文直接通过。DISCARD：表示业务报文直接丢弃。 默认值：无 配置原则：无 |
| CFGDOMAINNAME  | 配置域名称         | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。           |

#### 使用实例

当运行商需要修改已有的防火墙策略，策略要求是：上行发起业务流的上行报文丢弃，上行发起业务流的下行报文丢弃，下行发起业务流的上行报文通过，下行发起业务流的下行报文通过：

```
MOD FWPOLICY: FWPOLICYNAME="testfwpolicy", UPINITUPACTION=DISCARD, UPINITDNACTION=DISCARD, DNINITUPACTION=PASS, DNINITDNACTION=PASS;
```
