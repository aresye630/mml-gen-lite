# 删除RSA3072公钥配置（RMV RSA3072）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于删除RSA3072的相关配置。

#### 注意事项

- 该命令执行后立即生效。
- 已经被绑定到HeadEn命令中的RSA3072配置不能删除，若需要删除该RSA3072信息，需要先执行MOD HEADEN或RMV HEADEN命令解除绑定关系。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称        | 参数说明                                                                                               |
|:------------|:------------|:---------------------------------------------------------------------------------------------------|
| RSA3072NAME | RSA3072公钥名称 | 可选必选说明：必选参数 参数含义：该参数用于指定RSA3072公钥配置名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

假如运营商想删除名称为“test”的RSA3072配置：

```
RMV RSA3072: RSA3072NAME="test";
```
