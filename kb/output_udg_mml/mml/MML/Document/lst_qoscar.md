# 查询QosCar配置（LST QOSCAR）

- 命令功能
- 注意事项

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于查询用户上下行QosCar功能的全局开关。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询全局的QosCar功能开关：

```
LST QOSCAR:;
```

```
RETCODE = 0  操作成功。

结果如下
--------
用户漫游类型    上行RAT类型    下行RAT类型

本地            NULL           NULL       
漫游            NULL           NULL       
拜访            NULL           NULL       
(结果个数 = 3)
---    END
```
