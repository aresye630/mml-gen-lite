# 查询扩展包详细信息（DSP PLGPKGDETAILINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示扩展包详细信息，包括扩展包单元文件名、类型及生效时间等。

扩展包的激活、删除会触发扩展包单元状态的变化，使用该命令显示系统当前的扩展包单元状态信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                  |
|:----------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------|
| PLGTYPE         | 扩展包类型  | 可选必选说明：可选参数 参数含义：该参数用于指定要查询扩展包单元所属的扩展包的类型。可通过DSP PLGPKG查询获取。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无                                  |
| RUNAME          | RU名称   | 可选必选说明：可选参数 参数含义：该参数用于指定要查询扩展包单元所属的RU名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：使用DSP RU查看RU名称。                                 |
| PROCID          | 进程号    | 可选必选说明：可选参数 参数含义：该参数用于指定要查询扩展包单元所属进程的ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                                 |
| TYPE            | 类型     | 可选必选说明：可选参数 参数含义：该参数用于指定要查询扩展包单元的类型。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无                                                          |
| EFFECTIVETIME   | 生效时间   | 可选必选说明：可选参数 参数含义：该参数用于指定要查询扩展包单元的生效时间。 数据来源：本端规划 取值范围：日期时间类型，输入格式是YYYY&MM&DD&HH&NN&SS。2000/01/01 00:00:00～ 2037/12/31 23:59:59。 默认值：无 |
| FILENAME        | 文件名    | 可选必选说明：可选参数 参数含义：该参数用于指定要查询扩展包单元文件名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无                                                          |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识，但不能填写0，0表示VNFP。           |

#### 使用实例

显示扩展包详细信息：

```
DSP PLGPKGDETAILINFO:SERVICEINSTANCE="vnfc";
```
