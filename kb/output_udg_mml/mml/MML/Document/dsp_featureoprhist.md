# 查询特性上下线历史（DSP FEATUREOPRHIST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

查询特性上下线历史。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

无

## 使用实例

DSP FEATUREOPRHIST:;

```
%%DSP FEATUREOPRHIST:;%%
RETCODE = 0  操作成功

结果如下
------------------------
                          操作类型  =  特性上线
记录操作对象信息(Feature和Pod信息)  =  usnom-pod:1,usn-pod:1
                      处理开始时间  =  20191216-14:17:35
                      处理结束时间  =  20191216-14:17:35
                          结果说明  =  NULL
                          处理结果  =  处理成功
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称    | 输出项解释                                                        |
|:---------|:-------------------------------------------------------------|
| 操作类型     | 操作类型。 取值说明： Enable（特性上线）Disable（特性下线）                        |
| 记录操作对象信息 | 记录操作对象信息。                                                    |
| 处理开始时间   | 处理开始时间。                                                      |
| 处理结束时间   | 处理结束时间。                                                      |
| 结果说明     | 结果说明。                                                        |
| 处理结果     | 处理结果。 取值说明： OK（处理成功）Nok（处理失败）PartlyOK（部分处理成功）Processing（处理中） |
