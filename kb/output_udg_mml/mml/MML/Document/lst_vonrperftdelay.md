# 查询理想报文的最小时延偏差、固定传输时延（LST VONRPERFTDELAY）

#### 命令功能

**适用NF：UPF**

该命令用于查询理想报文的最小时延偏差、固定传输时延。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询理想报文的最小时延偏差、固定传输：

```
LST VONRPERFTDELAY:;
```

```
RETCODE = 0  操作成功

理想报文的最小时延偏差、固定传输时延
------------------------------------
理想到达报文的最小时延偏差  =  10
理想时延报文的固定传输时延  =  180
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见SET VONRPERFTDELAY的参数说明。
