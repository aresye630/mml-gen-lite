# 查询CSDB容灾主备本记录数(DSP DBDRTBLNUM)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询CSDB容灾主备本记录数。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                        |
|:-----------|:-------|:----------------------------------------------------------------------------------------------------------------------------|
| INSTANCEID | 子实例ID  | 可选必选说明：必选参数。 参数含义：该参数用于指定唯一一个子实例，可以通过DSP DBINSTANCE命令查询获取。 数据来源：全网规划 取值范围：1~100。 默认值：无。                                     |
| TABLEID    | 表ID    | 可选必选说明：可选参数。 参数含义：该参数用于指定唯一一张数据表。 数据来源：全网规划 取值范围：0~4294967295。 默认值：无。                                                       |
| DRNODETYPE | 数据主备类型 | 可选必选说明：可选参数。 参数含义：该参数用于指定查询数据主备类型。 数据来源：全网规划 取值范围： “DR_MASTER_NODE”：容灾主本数据“DR_SLAVE_NODE”容灾备本数据。 默认值：容灾主本数据。                |
| DRINSTID   | 容灾实例ID | 可选必选说明：条件可选参数。 参数含义：表示备份了哪个容灾实例的容灾表数据。可以通过LST DRCOMM命令查询获取。该参数在“DRNODETYPE”是“DR_SLAVE_NODE”时生效。 数据来源：全网规划 取值范围：0～63。 默认值：无。 |

#### 使用实例

查询CSDB**“子实例ID”**为“7”的容灾主备本记录数：

```
%%DSP DBDRTBLNUM: INSTANCEID=7;%%
RETCODE = 0  操作成功

操作结果如下：
--------------
子实例ID  表ID  表名称                  容灾记录数

7         201   GeoTable_dr_test            2
7         202   GeoTableCopy_dr_test        1
7         0     ALL                         3
(结果个数 = 3)

---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                                                                                                     |
|:--------|:----------------------------------------------------------------------------------------------------------|
| 子实例ID   | 指定唯一一个子实例。 取值范围：1 ~ 100。                                                                                  |
| 表ID     | 唯一标识一张数据表。 取值范围：0～4294967295。                                                                             |
| 表名称     | 数据表名称。 取值范围：不超过63个英文字符。                                                                                   |
| 容灾记录数   | 容灾表记录数 取值范围：0～4294967295。  说明： 数据主备类型是“容灾主本数据”时，显示容灾主本记录数。数据主备类型是“容灾备本数据”时，和“容灾实例ID”配合，显示对应容灾实例ID的容灾备本记录数 |
| 容灾实例ID  | 容灾实例ID。 取值范围：0～63。  说明： “数据主备类型”是“容灾备本数据”时显示。当查询所有备本容灾数据，不输入“容灾实例ID”时，输出结果“容灾实例ID”显示0。                    |
