# 显示LDP的邻居地址信息（DSP LDPLSPMGPEERADDR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示LDP的邻居地址信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称       | 参数说明                                                                                                     |
|:--------|:-----------|:---------------------------------------------------------------------------------------------------------|
| VRFNAME | VPN实例名称    | 可选必选说明：可选参数 参数含义：该参数用于表示VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：_public_                          |
| FECFLAG | 本地地址标志位    | 可选必选说明：可选参数 参数含义：该参数用于表示LSP的本地地址标志位。 数据来源：本端规划 取值范围：枚举类型。 PEER：指定对等体ID。ADDRESS：指定地址。 默认值：无               |
| ADDRESS | 本地地址       | 可选必选说明：条件必选参数 前提条件：该参数在“FECFLAG”配置为“ADDRESS”时为必选参数。 参数含义：该参数用于表示LSP的本地地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无 |
| PEERID  | 对等体的LSR ID | 可选必选说明：条件必选参数 前提条件：该参数在“FECFLAG”配置为“PEER”时为必选参数。 参数含义：该参数用于表示对等体的LSR ID。 数据来源：对端协商 取值范围：IPv4地址类型。 默认值：无  |

#### 使用实例

显示LDP的邻居地址信息：

```
DSP LDPLSPMGPEERADDR:FECFLAG=ADDRESS,ADDRESS="10.1.1.2";
```

```
RETCODE = 0  操作成功。

结果如下
--------
   VPN实例名称  =  _public_
对等体的LSR ID  =  10.10.10.10
      本地地址  =  10.1.1.2
   通告FSM状态  =  已完成通告
 LDP备份版本号  =  0
 LDP平滑版本号  =  1
        组件ID  =  0x1c0037
(结果个数 = 1)
---    END
```

|:-----------|:------------------------------|

| LDP备份版本号   | 用于表示LDP备份版本号。                 |
| LDP平滑版本号   | 用于表示LDP平滑版本号。                 |
| 组件ID       | 用于表示组件ID。                     |
