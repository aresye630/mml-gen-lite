# 创建备份任务（CRT BKMTSK）

- 注意事项

- 参考信息

## 命令功能

通过本命令可创建手动备份任务。

## 注意事项

通过本命令创建的备份任务，不能用于OM Portal界面创建恢复任务。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                           |
|:------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------|
| BACKUP_TYPE | 备份方式   | 可选必选说明：必选参数。 参数含义：备份方式。 取值范围： LOGICAL_BACKUP(逻辑备份)：实例化备份，适用于重装场景下的恢复。PHYSICAL_BACKUP(物理备份)：非实例化备份，适用于不重装场景下的恢复。 默认值：无。 配置原则：无。 |

## 使用实例

1. 创建备份任务：

```
%%CRT BKMTSK: BACKUP_TYPE=PHYSICAL_BACKUP;%% 
RETCODE = 0  操作成功  
任务信息如下 
------------ 
任务名称  =  physicalmanual20250414014224 
备份状态  =  进行中 
(结果个数 = 1)  
---    END

%%CRT BKMTSK: BACKUP_TYPE=PHYSICAL_BACKUP;%% 
RETCODE = 0  操作成功

------------

备份状态  =  进行中 
(结果个数 = 1)  
---    END

---    END
```
