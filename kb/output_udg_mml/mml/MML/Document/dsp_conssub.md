# 显示消费者订阅信息（DSP CONSSUB）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示Diameter消费者订阅状态信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

显示Diameter消费者订阅状态信息：

```
DSP CONSSUB:;
```

```
RETCODE = 0 操作成功

结果如下
------------------------
用户PID        用户订阅类型     对端地址     服务ID

0x2DF0056      服务ID           0.0.0.0      2
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释             |
|:--------|:------------------|
| 用户PID   | 该参数用于表示消费者PID。    |
| 用户订阅类型  | 该参数用于表示订阅类型。      |
| 对端地址    | 该参数用于表示Peer IP地址。 |
| 服务ID    | 该参数用于表示服务ID。      |
