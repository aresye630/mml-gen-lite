# 显示端口队列统计信息（DSP MSSPORTQUEUESTC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示指定端口的MSS端口多队列统计信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组。

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                  |
|:-------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CELLTYPE     | 微服务类型  | 可选必选说明：必选参数 参数含义：该参数用于指定微服务类型。 数据来源：本端规划。 取值范围：字符串类型，输入长度范围为0～63。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符。 默认值：无。 配置原则：使用DSP PAENODE查看工作角色为数据转发对应的微服务类型。    |
| CELLINSTANCE | 微服务实例号 | 可选必选说明：必选参数 参数含义：该参数用于指定微服务实例号。 数据来源：本端规划。 取值范围：字符串类型，输入长度范围为0～127。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符。 默认值：无。 配置原则：使用DSP PAENODE查看工作角色为数据转发对应的微服务实例号。 |
| PORTID       | 端口号    | 可选必选说明：必选参数。 参数含义：该参数用于表示端口号。 数据来源：本端规划。 取值范围：整数类型，取值范围为0～255。 默认值：无。 配置原则：使用DSP MSSPORTINFO命令获取端口号。                                                                                  |

#### 使用实例

显示类型为104的微服务csdb-pod-0172-16-2-45\_\_103\_\_0端口2的队列统计信息：

```
%%DSP MSSPORTQUEUESTC: CELLTYPE="104", CELLINSTANCE="csdb-pod-0172-16-2-45__103__0", PORTID=2;%%
RETCODE = 0  操作成功

结果如下:
---------
                  端口号  =  2
                  端口名  =  uio0
                  队列ID  =  0
      队列发送的报文个数  =  880333
        队列发送的字节数  =  932486814
      队列接收的报文个数  =  975093
        队列接收的字节数  =  961601058
队列接收中丢弃的报文个数  =  0
            发送队列深度  =  4294967295
(结果个数 = 1)

---    END
```

#### 输出结果说明

| 输出项名称        | 输出项解释                                                                                        |
|:-------------|:---------------------------------------------------------------------------------------------|
| 端口号          | 用于表示端口号。                                                                                     |
| 端口名          | 用于表示端口名。                                                                                     |
| 队列ID         | 用于表示队列ID。                                                                                    |
| 队列发送的报文个数    | 用于表示队列发送的报文个数。                                                                               |
| 队列发送的字节数     | 用于表示队列发送的字节数。                                                                                |
| 队列接收的报文个数    | 用于表示队列接收的报文个数。                                                                               |
| 队列接收的字节数     | 用于表示队列接收的字节数。                                                                                |
| 队列接收中丢弃的报文个数 | 用于表示队列接收中丢弃的报文个数。                                                                            |
| 发送队列深度       | 用于表示当前网卡支持的发送队列深度。 说明： 当发送队列深度返回数据结果为4294967295时，表明当前设备使用的网卡不支持该属性获取。即该数据不能作为依据，进行配置队列反压的阈值。 |
