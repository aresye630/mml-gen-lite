# 修改隧道策略（MOD TUNNELPOLICY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改隧道策略。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                                           |
|:---------------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| TNLPOLICYNAME  | 隧道策略名字   | 可选必选说明：必选参数 参数含义：该参数用于表示隧道策略名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～39。 默认值：无                                                                        |
| DESCRIPTION    | 隧道策略描述   | 可选必选说明：可选参数 参数含义：该参数用于表示隧道策略描述。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～80。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。                                                 |
| TNLPOLICYTYPE  | 隧道策略类型   | 可选必选说明：必选参数 参数含义：该参数用于表示隧道策略类型。 数据来源：本端规划 取值范围：枚举类型。 invalid：无效类型的隧道策略。tnlSelectSeq：隧道选择序列。 默认值：无                                              |
| LOADBALANCENUM | 负载均衡数    | 可选必选说明：条件必选参数 前提条件：该参数在“TNLPOLICYTYPE”配置为“tnlSelectSeq”时为必选参数。 参数含义：该参数用于表示负载均衡数。 数据来源：本端规划 取值范围：整数类型，取值范围为1～64。 默认值：无                         |
| SELTNLTYPE1    | 第一优选隧道类型 | 可选必选说明：条件必选参数 前提条件：该参数在“TNLPOLICYTYPE”配置为“tnlSelectSeq”时为必选参数。 参数含义：该参数用于表示选择隧道类型。 数据来源：本端规划 取值范围：枚举类型。 lsp：LSP。gre：GRE。 默认值：无                 |
| SELTNLTYPE2    | 第二优选隧道类型 | 可选必选说明：条件可选参数 前提条件：该参数在“TNLPOLICYTYPE”配置为“tnlSelectSeq”时为可选参数。 参数含义：该参数用于表示选择隧道类型。 数据来源：本端规划 取值范围：枚举类型。 invalid：INVALID。lsp：LSP。gre：GRE。 默认值：无 |

#### 使用实例

修改隧道策略：

```
MOD TUNNELPOLICY:TNLPOLICYNAME="tp",TNLPOLICYTYPE=tnlSelectSeq,DESCRIPTION="The first policy",LOADBALANCENUM=20,SELTNLTYPE1=gre,SELTNLTYPE2=lsp;
```
