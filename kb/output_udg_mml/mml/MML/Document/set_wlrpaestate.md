# 设置无线路由PAE使能状态（SET WLRPAESTATE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

本命令属于高危命令，操作不当会导致转发中断，请谨慎使用并联系华为技术支持协助操作。

该命令用于设置PAE使能状态。

#### 注意事项

- 该命令执行后立即生效。
- 执行该命令可能会导致转发中断。
- 该命令仅供灰度升级使用。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                               |
|:------------|:----------|:-----------------------------------------------------------------------------------|
| ISENABLENTF | 是否使能PAE通告 | 可选必选说明：必选参数 参数含义：该参数用于指定是否使能PAE通告。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无 |

#### 使用实例

设置PAE使能状态：

```
SET WLRPAESTATE:ISENABLENTF = TRUE;
```
