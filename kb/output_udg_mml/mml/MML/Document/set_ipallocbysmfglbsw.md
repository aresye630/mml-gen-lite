# 设置基于SMF分配地址全局开关（SET IPALLOCBYSMFGLBSW）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于配置基于SMF分配地址全局开关。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | SWITCH   | IPV6SWITCH   |
|:-------|:---------|:-------------|
| 初始值    | DISABLE  | DISABLE      |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                               |
|:-----------|:--------|:---------------------------------------------------------------------------------------------------|
| SWITCH     | IPv4 开关 | 可选必选说明：可选参数 参数含义：该参数用于指定基于SMF分配地址的IPv4开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无 |
| IPV6SWITCH | IPv6 开关 | 可选必选说明：可选参数 参数含义：该参数用于指定基于SMF分配地址的IPv6开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无 |

#### 使用实例

将基于SMF分配地址全局开关设置为允许基于SMF分配：

```
SET IPALLOCBYSMFGLBSW: SWITCH=ENABLE, IPV6SWITCH=ENABLE;
```
