# 查询CP配置（LST CPASSOCIATION）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用来查询CP配置信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称           | 参数说明                                                                                                                                                                                       |
|:--------------|:---------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CPTYPE        | CP类型           | 可选必选说明：可选参数 参数含义：该参数用于根据HostName或者IP地址进行删除或查询SMF操作。 数据来源：本端规划 取值范围：枚举类型。 HOSTNAME：表示类型是SMF主机名。IPVERSION：表示为N4 IP地址版本。 默认值：无 配置原则：无                                                         |
| CPDESCRIPTION | CP标识信息         | 可选必选说明：条件必选参数 前提条件：该参数在“CPTYPE”配置为“HOSTNAME”时为必选参数。 可选必选说明：条件可选参数 前提条件：该参数在“CPTYPE”配置为“IPVERSION”时为可选参数。 参数含义：该参数用于指定CP的标识信息。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～255。不支持空格，不区分大小写。 默认值：无 配置原则：无 |
| IPVERSION     | IP地址版本类型       | 可选必选说明：条件必选参数 前提条件：该参数在“CPTYPE”配置为“IPVERSION”时为必选参数。 参数含义：该参数用于设置CP N4 接口的IP地址版本类型。 数据来源：本端规划 取值范围：枚举类型。 IPV4：表示地址类型为IPv4。IPV6：表示地址类型为IPv6。 默认值：无 配置原则：无                                   |
| N4IPADDRESS   | CP N4 接口IPv4地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV4”时为必选参数。 参数含义：该参数用于设定CP的N4接口的IPv4地址。 数据来源：全网规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无 配置原则：无                                                               |
| N4IPV6ADDRESS | CP N4 接口IPv6地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV6”时为必选参数。 参数含义：该参数用于设定CP的N4接口的IPv6地址。 数据来源：全网规划 取值范围：IPv6地址类型。采用冒号分十六进制X:X:X:X:X:X:X:X格式。 默认值：无 配置原则：无                                            |

#### 使用实例

查询CP配置信息：

```
LST CPASSOCIATION:;
```

```
RETCODE = 0 Operation Success.

---------------

CP N4 接口IPv6地址 = ::
CP 标识信息 = cp1
(Number of results = 1)
--- END
```
