# 查询IPv6阈值（LST IPV6THRESHOLD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询IPv6整机路由前缀阈值告警的阈值。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询IPv6整机路由前缀阈值告警的阈值：

```
LST IPV6THRESHOLD:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
最大百分比（%） =  80
最小百分比（%） =  70
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见SET IPV6THRESHOLD的参数说明。
