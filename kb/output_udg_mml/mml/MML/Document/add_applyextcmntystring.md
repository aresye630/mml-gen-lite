# 增加扩展团体属性值设置（ADD APPLYEXTCMNTYSTRING）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于添加应用扩展团体属性值。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为65535。
- 配置该命令前，需要通过ADD APPLYEXTENDCOMMUNITY配置了应用扩展团体属性值。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称      | 参数说明                                                                                 |
|:-------------|:----------|:-------------------------------------------------------------------------------------|
| POLICYNAME   | 路由策略名字    | 可选必选说明：必选参数 参数含义：该参数用于指定路由策略名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无 配置原则：区分大小写。 |
| NODESEQUENCE | 路由策略节点ID  | 可选必选说明：必选参数 参数含义：该参数用于指定路由策略节点ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无            |
| STRINGVALUE  | 扩展团体属性字符串 | 可选必选说明：必选参数 参数含义：该参数用于指定扩展团体属性值。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～21。 默认值：无 配置原则：区分大小写。 |

#### 使用实例

增加设置扩展团体属性的操作值：

```
ADD APPLYEXTCMNTYSTRING:NODESEQUENCE=10,POLICYNAME="a",STRINGVALUE="1:1";
```
