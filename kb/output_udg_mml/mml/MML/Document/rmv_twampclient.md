# 删除TWAMP客户端（RMV TWAMPCLIENT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除TWAMP客户端。

## 注意事项

- 该命令执行后立即生效。

- 如果要删除的CLIENTID已经被ADD TWAMPSENDER引用，需要先删除TWAMPSENDER后再执行此命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                               |
|:---------|:-------|:-----------------------------------------------------------------------------------|
| CLIENTID | 客户端ID  | 可选必选说明：必选参数  参数含义：该参数用于配置客户端ID。  数据来源：全网规划  取值范围：整数类型，取值范围是1~12000。  默认值：无  配置原则：无 |

## 使用实例

删除客户端ID为1的实例：

```
RMV TWAMPCLIENT: CLIENTID=1;
```
