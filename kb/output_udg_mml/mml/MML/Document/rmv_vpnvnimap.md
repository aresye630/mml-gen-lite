# 删除VPN VNI映射（RMV VPNVNIMAP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，删除配置会导致匹配到对应规则的数据报文无法转发给MEP。

该命令用于删除VNI与VPN的映射关系。

#### 注意事项

- 该命令执行后立即生效。
- 执行该命令删除VPN与VNI映射关系时，会改变对应业务数据转发流程，数据报文由转发给MEP修改为直接路由转发。
- 如果执行批量删除操作，需要开启软参BYTE692。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                             |
|:------------|:-------|:-----------------------------------------------------------------------------------------------------------------|
| VPNINSTANCE | VPN实例名 | 可选必选说明：可选参数 参数含义：该参数用于配置VPN实例。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，区分大小写。 默认值：无 配置原则：该参数使用 ADD VPNINST命令配置生成。 |
| RULENAME    | 规则名称   | 可选必选说明：可选参数 参数含义：该参数用于设置规则名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无                        |

#### 使用实例

删除VNI与VPN为vpn1的映射关系：

```
RMV VPNVNIMAP: VPNINSTANCE="vpn1";
```
