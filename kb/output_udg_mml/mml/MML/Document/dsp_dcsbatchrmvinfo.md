# 显示批量删除视频的任务信息（DSP DCSBATCHRMVINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示批量删除视频的任务信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                               |
|:----------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
| MAXTASKID | 最大任务序号 | 可选必选说明：可选参数  参数含义：该参数用于表示查询批量删除视频的任务信息时，能够查询的最大任务序号。  数据来源：本端规划  取值范围：整数类型，取值范围是1~9223372036854775807。  默认值：无  配置原则：  没有配置该参数的情况下，显示最近批量删除视频的任务信息。 |
| QUERYNUM  | 查询任务数量 | 可选必选说明：可选参数  参数含义：该参数用于表示查询批量删除视频的任务数量。  数据来源：本端规划  取值范围：整数类型，取值范围是1~300。  默认值：无  配置原则：  没有配置该参数的情况下，默认查询20条。                                      |

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                                                                           |
|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 任务序号    | 该参数用于表示批量删除视频的任务序号。                                                                                                                                                             |
| OTT名称   | 该参数用于表示OTT名称，OTT名称由OTT厂商提供，可通过执行LST RELAYDOMAIN命令，获取查询结果中的“媒体中继模板名称”。                                                                                                           |
| 视频类型    | 该参数用于表示视频的类型。 取值说明： VIDEO_TYPE_LIVE（直播视频）VIDEO_TYPE_VOD（点播视频）VIDEO_TYPE_ALL（所有视频）                                                                                               |
| 删除类型    | 该参数用于表示批量删除的视频类型。 取值说明： VIDEODIR（视频目录）                                                                                                                                          |
| 删除参数    | 该参数用于表示批量删除的视频参数。例如：当删除类型为视频目录时，该参数可以从视频文件的URL名称中获取。URL名称由OTT厂商提供。                                                                                                              |
| 任务状态    | 该参数用于表示批量删除视频的任务状态信息。 取值说明： TASK_STATUS_STARTING（启动中）TASK_STATUS_DISTRIBUTED（已分发）TASK_STATUS_RUNNING（运行中）TASK_STATUS_COMPLETED（完成）TASK_STATUS_TIMEOUT（超时）TASK_STATUS_FAILED（失败） |
| 开始时间    | 该参数用于表示批量删除视频的任务开始时间。                                                                                                                                                           |
| 结束时间    | 该参数用于表示批量删除视频的任务结束时间。                                                                                                                                                           |
| 需要扫描文件数 | 该参数用于表示批量删除视频的任务需扫描文件数。                                                                                                                                                         |
| 已扫描文件数  | 该参数用于表示批量删除视频的任务已扫描文件数。                                                                                                                                                         |
| 已删除文件数  | 该参数用于表示批量删除视频的任务已删除文件数。                                                                                                                                                         |
