# 删除补丁（RMV ACSPATCH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

本命令属于高危命令，会删除系统补丁，涉及冷补丁时，会重启系统，请谨慎使用并联系华为技术支持协助操作。

该命令用于当系统中补丁存在问题时，删除系统补丁。

本命令只适用于ACS服务，其他微服务请使用RMV PATCH命令。

#### 注意事项

- 该命令执行后立即生效。
- 该命令会删除系统补丁，无补丁、已加载补丁，已激活补丁，执行该操作的结果都是成功。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

无。

#### 使用实例

删除系统补丁：

```
RMV ACSPATCH:;
```
