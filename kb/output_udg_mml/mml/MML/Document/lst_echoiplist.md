#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用来查询GTP路径管理的黑白名单控制的IP地址段。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询GTP路径管理的黑白名单控制的IP地址段信息：

```
LST ECHOIPLIST:;
```

```
RETCODE = 0  操作成功。

Echo List
---------
IP地址版本类型  =  IPV4
IP地址段的地址  =  10.36.0.2
      掩码长度  =  27
(结果个数 = 1)
---    END
```
