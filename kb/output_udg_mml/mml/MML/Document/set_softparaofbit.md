# 设置软件参数表比特位的值（SET SOFTPARAOFBIT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于设置软件参数表比特位。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称          | 参数说明                                                                                                                          |
|:--------------|:--------------|:------------------------------------------------------------------------------------------------------------------------------|
| DT2           | 软参记录数据类型      | 可选必选说明：必选参数 参数含义：软件参数的数据类型。 数据来源：本端规划 取值范围：枚举类型。 默认值：无 配置原则： 配置BYTE表示需要设置字节类型软件参数。配置DWORD表示需要设置双字类型软件参数。                      |
| BYTENUM       | Byte索引        | 可选必选说明：条件必选参数 前提条件：该参数在“DT2”配置为“BYTE”时为必选参数。 参数含义：字节类型软件参数的索引。 数据来源：本端规划 取值范围：整数类型，取值范围为1～1200。取值范围在1到1200之间的整数。 默认值：无 配置原则：无 |
| DWORDNUM      | DWord索引       | 可选必选说明：条件必选参数 前提条件：该参数在“DT2”配置为“DWORD”时为必选参数。 参数含义：双字类型软件参数的索引。 数据来源：本端规划 取值范围：整数类型，取值范围为1～180。取值范围在1到180之前的整数。 默认值：无 配置原则：无  |
| BYTEPOSITION  | Byte软参BIT位位置  | 可选必选说明：条件必选参数 前提条件：该参数在“DT2”配置为“BYTE”时为必选参数。 参数含义：Byte软参指定的BIT位位置。 数据来源：本端规划 取值范围：整数类型，取值范围为1～8。 默认值：无 配置原则：无                 |
| DWORDPOSITION | Dword软参BIT位位置 | 可选必选说明：条件必选参数 前提条件：该参数在“DT2”配置为“DWORD”时为必选参数。 参数含义：Dword软参指定的BIT位位置。 数据来源：本端规划 取值范围：整数类型，取值范围为1～32。 默认值：无 配置原则：无              |
| BYTEVALUE     | Byte值         | 可选必选说明：条件必选参数 前提条件：该参数在“DT2”配置为“BYTE”时为必选参数。 参数含义：字节类型参数的值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～1。取值范围在0到1之间的整数。 默认值：无 配置原则：无          |
| DWORDVALUE    | Dword值        | 可选必选说明：条件必选参数 前提条件：该参数在“DT2”配置为“DWORD”时为必选参数。 参数含义：双字类型参数的值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～1。取值范围在0到1之间的整数。 默认值：无 配置原则：无         |

#### 使用实例

设置单字节类型1号软参Bit1位的值为1：

```
SET SOFTPARAOFBIT: DT2=BYTE, BYTENUM=1, BYTEPOSITION=1, BYTEVALUE=1;
```
