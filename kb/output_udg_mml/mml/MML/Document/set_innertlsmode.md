# 设置TLS模式（SET INNERTLSMODE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

SERVICETYPE选择HAFETCD后，执行该命令会导致整系统复位。

该命令用于根据服务类型设置TLS模式。

## 注意事项

- 该命令执行后立即生效。

- FusionStage裸机场景，本命令配置不生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| SERVICETYPE   | TLSMODE   |
|:--------------|:----------|
| HAFETCD       | DEFAULT   |
| CMF           | DEFAULT   |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                |
|:------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 服务类型   | 可选必选说明：必选参数  参数含义：该参数用于表示服务类型。  数据来源：本端规划 取值范围： HAFETCD（HAFETCD）CMF（CMF）  默认值：无。  配置原则：无                                                                                            |
| TLSMODE     | TLS模式  | 可选必选说明：必选参数  参数含义：该参数用于表示TLS模式。  数据来源：本端规划 取值范围： HTTP（HTTP协议）HTTPS（HTTPS协议）DEFAULT（默认值）  默认值：无。  配置原则： DEFAULT代表TLSMODE以TOSCA模板中的VNF_TLS_MODE为准。对安全要求较高的场景，可以设置为HTTPS，但会影响性能，需谨慎使用。 |

## 使用实例

设置hafetcd的TLS模式为http

```
SET INNERTLSMODE: SERVICETYPE=HAFETCD, TLSMODE=HTTP;
```
