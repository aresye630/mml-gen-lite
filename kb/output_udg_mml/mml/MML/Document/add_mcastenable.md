# 添加组播使能（ADD MCASTENABLE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于添加组播使能配置。

只有在公网实例或VPN实例下使能组播功能，才能配置该实例下的其它所有组播命令。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1024。
- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                               |
|:--------------|:--------|:-------------------------------------------------------------------------------------------------------------------|
| ADDRESSFAMILY | 地址族     | 可选必选说明：必选参数 参数含义：该参数用于指定地址族类型。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。 默认值：无                                      |
| VRFNAME       | VPN实例名称 | 可选必选说明：可选参数 参数含义：该参数用来指定VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：_public_ 配置原则：通过LST L3VPNINST查看当前已存在的VPN实例。 |

#### 使用实例

添加组播使能配置：

```
ADD MCASTENABLE:VRFNAME="_public_",ADDRESSFAMILY=ipv4unicast;
```
