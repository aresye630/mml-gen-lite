# 显示端口信息（DSP MSSPORTINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示端口信息。

#### 注意事项

- 该命令执行后立即生效。
- 该命令不支持单条件查询。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                |
|:-------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CELLTYPE     | 微服务类型  | 可选必选说明：可选参数 参数含义：该参数用于指定微服务类型。 数据来源：本端规划 取值范围：字符串类型，输入长度范围0～63。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符。 默认值：无 配置原则：使用DSP PAENODE查看工作角色为数据转发对应的微服务类型。     |
| CELLINSTANCE | 微服务实例号 | 可选必选说明：可选参数 参数含义：该参数用于指定微服务实例号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～127。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符。 默认值：无 配置原则：使用DSP PAENODE查看工作角色为数据转发对应的微服务实例号。 |

#### 使用实例

显示端口信息：

```
DSP MSSPORTINFO:CELLTYPE="aa", CELLINSTANCE="bb";
```

```
RETCODE = 0  操作成功。

结果如下
--------------------------------- 
微服务类型   微服务实例号   端口号   端口名     PCI地址       驱动类型     设备类型    逻辑进程号  

aa           bb             2        uio1       0000:00:07.0  pmd          virtio       0                 
aa           bb             3        uio7       0000:00:08.0  pmd          virtio       0     
(结果个数 = 2)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                                                     |
|:--------|:----------------------------------------------------------|
| 微服务类型   | 用于指定微服务类型。                                                |
| 微服务实例号  | 用于指定微服务实例号。                                               |
| 端口号     | 用于表示以太网口端口号。                                              |
| 端口名     | 用于表示以太网口端口名。                                              |
| PCI地址   | 用于表示以太网口的PCI地址。                                           |
| 驱动类型    | 用于表示驱动类型，主要有pmd、pcap和netmap类型。                            |
| 设备类型    | 用于表示设备类型，主要有ixgbe vf、virtio、vmxnet3、mlx4 vf、mlx4 pf、gpub。 |
| 逻辑进程号   | 用于表示端口的逻辑进程号。                                             |
