# 显示应用联动默认动作（DSP SECPOLICYAPPLNK）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示应用联动的缺省动作。

#### 注意事项

- 该命令执行后立即生效。
- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                        |
|:------------|:-------|:------------------------------------------------------------|
| SECPOLICYID | 策略编号   | 可选必选说明：必选参数 参数含义：策略编号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～30。 默认值：无 |

#### 使用实例

显示应用联动的缺省动作：

```
DSP SECPOLICYAPPLNK: SECPOLICYID=1;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
    策略编号  =  1
默认处理方式  =  传给CPU
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释              |
|:--------|:-------------------|
| 策略编号    | 该参数用于表示防攻击策略。      |
| 默认处理方式  | 该参数用于表示应用层联动的默认动作。 |
