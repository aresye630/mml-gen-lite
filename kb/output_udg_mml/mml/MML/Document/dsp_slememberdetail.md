# 显示仲裁成员详细信息（DSP SLEMEMBERDETAIL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示仲裁成员详细信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                                                                                                            |
|:----------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RUNAME          | RU名称   | 可选必选说明：必选参数 参数含义：该参数用于显示RU名称。通过DSP SLEMEMBER命令可以查询所有仲裁成员对应的资源单元信息。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则： 只能填写实际存在的资源单元或资源名称。当本命令在VNFP上使用时，需要先使用DSP RES查到“资源名称”，然后将“资源名称”的取值配置到本参数。当本命令在VNFC上使用时，需要先使用DSP RU查到“RU名称”，然后将“RU名称”的取值配置到本参数。 |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。                                                                                                                                    |

#### 使用实例

显示仲裁成员详细信息：

```
DSP SLEMEMBERDETAIL:RUNAME="VNODE_VNRS_VNFC_OMU_0001",SERVICEINSTANCE="vnfc";
```

#### 输出结果说明

| 输出项名称         | 输出项解释                                                                                                                |
|:--------------|:---------------------------------------------------------------------------------------------------------------------|
| RU名称          | 用于显示RU名称。通过DSP SLEMEMBER命令可以查询所有仲裁成员对应的资源单元信息。                                                                       |
| 是否候选者         | 该参数表示是否资源单元主节点候选者。 TRUE：是资源单元主节点候选者。FALSE：不是资源单元主节点候选者。                                                              |
| 角色            | 该参数表示主从角色。 未知：表示当前节点尚未决策出主从角色。主节点：表示当前节点角色为主。从节点：表示当前节点角色为备。                                                         |
| 工作模式          | 该参数表示工作模式。 非防脑裂：表示当前节点工作在非防脑裂模式，即OMU节点自己决策主备角色的模式。防脑裂：表示当前节点工作在防脑裂模式，即由若干成员节点（通常5个节点）投票决策主备节点的模式。未知：表示当前节点尚未参与仲裁的模式。 |
