# 查询NF支持的网络切片选择标识（LST SNSSAI）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明

#### 命令功能

**适用NF：UPF**

该命令用于显示UPF上配置的所有网络切片选择标识。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

获取当前UPF配置的所有网络切片选择标识：

```
LST SNSSAI:;
```

```

   配置域名称  =  NULL
```
