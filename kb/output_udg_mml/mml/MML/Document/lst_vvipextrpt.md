# 查询重点业务保障增强上报功能（LST VVIPEXTRPT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询重点业务保障增强上报功能的开关。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询重点业务保障增强上报功能：

```
%%LST VVIPEXTRPT:;
```

```
%%
RETCODE = 0  操作成功

结果如下
--------
         QOE参数上报  =  使能
        模型参数上报  =  使能
媒体中继用户标识开关  =  使能
          可视化开关  =  使能
     5QI参数增强上报  =  不使能
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见SET VVIPEXTRPT的参数说明。
