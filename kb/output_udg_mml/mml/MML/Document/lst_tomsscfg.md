# 查询Tcp Mss配置（LST TOMSSCFG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询TCP MSS值。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询TCP MSS值：

```
LST TOMSSCFG:;
```

```
RETCODE = 0 操作成功。

TCP MSS配置
-----------
IPv4 TCP报文长度（字节） = 496
IPv6 TCP报文长度（字节） = 1500
(结果个数 = 1)

--- END
```

#### 输出结果说明

参见SET TOMSSCFG的参数说明。
