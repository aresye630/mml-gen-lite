# 添加消息跟踪限制（ADD MTSPOLICY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

执行该命令后，可能会影响到跟踪任务的创建以及消息上报，请谨慎使用该命令。

本命令用于添加对消息跟踪能力的限制，例如限制消息跟踪任务的创建。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                             |
|:------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID        | 网元ID   | 可选必选说明：必选参数。 参数含义：标识网元ID，可以通过LST ME命令查询获取。 取值范围：0~65535 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                           |
| POLICYTYPE  | 规则类型   | 可选必选说明：必选参数。 参数含义：限制消息跟踪的规则类型。 取值范围： DISABLE_BY_TYPE(限制跟踪类型)DISABLE_BY_SERVICE(限制服务名称) 默认值：无。 配置原则： 当配置“DISABLE_BY_TYPE(限制跟踪类型)”，此跟踪类型对应的拓展跟踪类型任务会同步限制，已经创建的任务不受影响。当配置“DISABLE_BY_SERVICE(限制服务名称)”后，如果系统已存在该服务的消息跟踪任务， 处理建议如下：用户自行决定是否需要提前删除，如果不删除对应任务，跟踪任务校验将会在配置限制后最长6分钟内通知对应服务自动删除任务；并在解除限制后最长6分钟内通知对应服务创建任务。                                                                 |
| TRACETYPE   | 跟踪类型   | 可选必选说明： 该参数在“规则类型”配置为“DISABLE_BY_TYPE(限制跟踪类型)”时为必选参数。该参数在“规则类型”配置为“DISABLE_BY_SERVICE(限制服务名称)”时为可选参数。 参数含义：跟踪类型，可以通过DSP MTSMODEL命令查询获取。 取值范围：整数类型，取值范围0~2147483647 默认值：无。 配置原则： 当“规则类型”配置为“DISABLE_BY_TYPE(限制跟踪类型)”时，本参数需要与DSP MTSMODEL命令的“跟踪类型”输出项保持一致。当“规则类型”配置为“DISABLE_BY_SERVICE(限制服务名称)”时，本参数需要与DSP MTSMODEL命令的“拓展跟踪类型”输出项保持一致。如果不填写本参数，当前“服务名称”订阅的所有跟踪类型的任务，都将被禁止下发给对应服务。 |
| SERVICENAME | 服务名称   | 可选必选说明：该参数在“规则类型”配置为“DISABLE_BY_SERVICE(限制服务名称)”时为条件必选参数。 参数含义：跟踪类型订阅的服务名称，可以通过DSP MTSMODEL命令查询获取。 取值范围：字符串类型，长度为0~512。 默认值：无。 配置原则：一次配置仅支持单个服务。                                                                                                                                                                                                                                 |

## 使用实例

1. 添加指定跟踪类型的跟踪消息限制：

   ```
   %%ADD MTSPOLICY: MEID=10, POLICYTYPE=DISABLE_BY_TYPE, TRACETYPE=1005;%%
   RETCODE = 0  操作成功
   ---    END
   ```
2. 添加指定跟踪类型下某个订阅服务的跟踪消息限制：

   ```
   %%ADD MTSPOLICY: MEID=12, POLICYTYPE=DISABLE_BY_SERVICE, SERVICENAME="A", TRACETYPE=1;%%
   RETCODE = 0  操作成功
   ---    END
   ```
3. 添加指定某个订阅服务的跟踪消息限制：

   ```
   %%ADD MTSPOLICY: MEID=12, POLICYTYPE=DISABLE_BY_SERVICE, SERVICENAME="A";%%
   RETCODE = 0  操作成功
   ---    END
   ```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息，无输出项。

命令执行异常，会返回提示对应的失败信息。错误码列表如表1所示。

|    错误码 | 消息解释          | 原因分析                                                                       | 处理建议         |
|-------:|:--------------|:---------------------------------------------------------------------------|:-------------|
| 101601 | 系统异常          | 服务离线、数据库异常、操作冲突等。                                                          | 请等待几分钟后重试。   |
| 101602 | 网元不存在         | “网元ID”输入非法，与实际环境不一致。                                                       | 修改网元ID后重试。   |
| 101603 | 请求消息错误        | 请求消息错误。                                                                    | 请联系华为技术支持处理。 |
| 101604 | 跟踪类型不存在       | 跟踪类型输入非法，与当前模型不一致。                                                         | 更正跟踪类型后重试。   |
| 101605 | 该跟踪类型已被限制     | 当前跟踪类型已被限制。                                                                | 无需处理。        |
| 101607 | 服务名称不存在       | 如果配置了“跟踪类型”，则表示当前选择的跟踪类型的订阅列表不包含此服务。如果没有配置“跟踪类型”，则表示当前网元所有跟踪类型的订阅列表不包含此服务。 | 更正服务名称后重试。   |
| 101608 | 该服务已被限制       | 当前服务已经被限制。                                                                 | 无需处理。        |
| 101609 | 该跟踪类型下该服务已被限制 | 对应的跟踪类型下该服务已被限制。                                                           | 无需处理。        |
