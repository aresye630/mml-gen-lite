# 查询IPv4静态路由全局属性（LST SRIPV4STATICSITE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询IPv4静态路由全局属性。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询IPv4静态路由全局属性：

```
LST SRIPV4STATICSITE:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
      全局默认优先级  =  60
BFD最小接收间隔（ms） =  200
BFD最小传输间隔（ms） =  200
        本地检测倍数  =  3
        迭代深度开关  =  FALSE
      最大IPv4路由数  =  200000
      当前IPv4路由数  =  2
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称     | 输出项解释                |
|:----------|:---------------------|
| 最大IPv4路由数 | 用于指定可配置的最大IPv4静态路由数。 |
| 当前IPv4路由数 | 用于表示已配置的IPv4静态路由数。   |

其余输出项请参见SET SRIPV4STATICSITE的参数说明。
