# 设置进程故障告警上报模式（SET PROCFAULTALM）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

设置进程故障告警上报模式。

进程故障“告警快速上报使能位”开启时：

- 出现一次进程异常就立刻上报告警。
- 故障恢复后立刻上报告警恢复。

进程故障“告警快速上报使能位”关闭时：

- 进程初次启动，90秒内未运行正常，或连续启动失败三次上报告警。
- 进程运行异常，60秒内未恢复正常，或连续恢复失败三次上报告警。

- 默认进程故障告警恢复的限制时长是90s，故障后重新注册，超过该限定时间没有故障则上报告警恢复。

#### 注意事项

- 该命令执行后立即生效。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| ISTRGALMIMMDTLY   |
|:------------------|
| Disable           |

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称      | 参数说明                                                                                                         |
|:----------------|:----------|:-------------------------------------------------------------------------------------------------------------|
| ISTRGALMIMMDTLY | 告警快速上报使能位 | 可选必选说明：必选参数 参数含义：告警快速上报使能位。 数据来源：本端规划 取值范围：枚举类型。 Disable：去使能。Enable：使能。 默认值：无                                |
| SERVICEINSTANCE | 服务实例      | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

设置进程故障告警上报模式：

```
SET PROCFAULTALM:ISTRGALMIMMDTLY=Enable,SERVICEINSTANCE="vnfc";
```
