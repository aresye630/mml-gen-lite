# 删除业务报表承载协议映射配置（RMV RPTPROTOCOLMAP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于删除业务报表承载协议映射配置。当运营商希望删除业务报表承载协议映射配置，则配置该命令。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                               |
|:--------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROTOCOLLEVEL | 协议等级   | 可选必选说明：必选参数 参数含义：该参数用于指示配置的协议组、协议级别。 数据来源：本端规划 取值范围：枚举类型。 PROTOCOLGROUP：协议组级别。PROTOCOL：协议级别。 默认值：无 配置原则：无                                                          |
| PROTOCOLNAME  | 协议名称   | 可选必选说明：条件必选参数 前提条件：该参数在“PROTOCOLLEVEL”配置为“PROTOCOL”时为必选参数。 参数含义：该参数用于设置协议名称。数据源为UPF支持识别的所有类型的协议、子协议。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无   |
| PROTGROUPNAME | 协议组名称  | 可选必选说明：条件必选参数 前提条件：该参数在“PROTOCOLLEVEL”配置为“PROTOCOLGROUP”时为必选参数。 参数含义：该参数用于设置协议组名称。数据源为UPF支持识别的所有默认协议组。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

假如运营商需要删除p2p协议组业务报表承载协议映射配置：

```
RMV RPTPROTOCOLMAP: PROTOCOLLEVEL=PROTOCOLGROUP, PROTGROUPNAME="p2p";
```
