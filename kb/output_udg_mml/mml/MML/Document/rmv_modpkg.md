# 删除模型包（RMV MODPKG）

## 命令功能

该命令用于删除已经成功上传至在DFS的模型包。与OM Portal界面中“应用管理 > 智能应用管理 > 模型存储 > 模型包”界面中“删除”模型包作用相同。

**须知** 

此命令为高危命令，模型包删除后将无法使用。若模型为预置模型，其在服务重启时才会上传，删除后可能无法恢复，请谨慎操作。

## 注意事项

无。

## 参数说明

| 参数标识             | 参数名称   | 参数说明                                                                                                                    |
|:-----------------|:-------|:------------------------------------------------------------------------------------------------------------------------|
| MEID             | 网元ID   | 可选必选说明：必选参数。 参数含义：需要删除模型包的网元ID。 取值范围：整数类型，取值范围为0~65535。 默认值：无。 配置原则：网元ID可通过LST ME命令查询获得。                                |
| MODELPACKAGENAME | 模型包名称  | 可选必选说明：必选参数。 参数含义：需要删除的模型包名称。 取值范围：字符串类型，长度1~128。 默认值：无。 配置原则：只能包括大小写字母、数字、中划线-、下划线_、英文句号.，必须包含下划线_，以.zip后缀结尾。长度最大为128。 |
| PKGSOURCE        | 模型包来源  | 可选必选说明：必选参数。 参数含义：需要删除的模型包来源。 取值范围： “MANUAL（手动）”：模型包来源为手工上传。“PRESET（预置）”：模型包来源为预置上传。 默认值：无。 配置原则：无。                     |

## 使用实例

为网元ID=0的网元删除手动来源的“MODEL-AUTO\_2025313204538.zip”模型包。

```
%%RMV MODPKG: MEID=0, MODELPACKAGENAME="MODEL-AUTO_2025313204538.zip", PKGSOURCE=MANUAL;%%
RETCODE = 0  操作成功

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见的错误码如表1所示。

|    错误码 | 错误码解释          | 原因分析                             | 处理建议                                          |
|-------:|:---------------|:---------------------------------|:----------------------------------------------|
| 181001 | 下发的MML参数不正确。   | 非法的命令参数。                         | 请检查输入的命令参数或联系华为技术支持。                          |
| 181002 | 系统内部错误，请联系管理员。 | 执行过程中可能存在网络故障或者服务不可用等异常因素。       | 等待几分钟后重试。                                     |
| 181030 | 模型包不存在。        | DFS存储服务中不存在该模型包。                 | 请执行DSP MODPKG命令，若查询不到该模型包，则表明该模型包不存在，无需删除。    |
| 181031 | 模型包来源输入有误。     | DFS存储服务中存在模型包名称一致、来源不一致的情况，删除失败。 | 请执行DSP MODPKG命令查询该模型包来源，输入正确的来源进行删除。          |
| 181032 | 模型包不支持删除。      | 模型包里面的模型文件可能正在使用中或锁定中，不支持删除。     | 请执行DSP MODPKG命令查询该模型包状态，若处于使用中或锁定中，该模型包不支持删除。 |
