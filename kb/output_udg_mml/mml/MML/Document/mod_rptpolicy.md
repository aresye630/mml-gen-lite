# 修改基于策略的报表开关（MOD RPTPOLICY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

此命令用于修改指定策略的业务报表功能开关。

#### 注意事项

- 该命令执行后只对之后发生承载更新的用户或者新激活用户生效。
- 所有用户缺省业务报表开关为DISABLE。只有通过设置SET RPTGLBCFG命令GLOBALSWITCH参数为ENABLE，或者使用MOD RPTPOLICY命令设置SWITCH参数为ENALBE，才能开启业务报表上报功能。
- 该命令执行60s后对承载更新的用户或者新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                                                                                                                                   |
|:---------------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| POLICYNAME     | 策略名称     | 可选必选说明：必选参数 参数含义：该参数用于指定报表功能使用的策略名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                                                                       |
| SWITCH         | 业务报表开关   | 可选必选说明：必选参数 参数含义：该参数用于配置指定策略的业务报表上报开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：上报功能关闭，不管全局业务报表上报开关是否是上报的状态，该用户策略都不会上报业务报表。ENABLE：上报功能打开，不管全局业务报表上报开关是否是上报的状态，该用户策略都会上报业务报表。GLOBAL：继承全局开关，当业务报表开关是该选项时，则用户策略是否上报业务报表取决于全局业务报表上报开关的状态。 默认值：无 配置原则：无 |
| USERSELPLYTYPE | 用户选择策略类型 | 可选必选说明：必选参数 参数含义：该参数指定用户选择策略类型。 数据来源：本端规划 取值范围：枚举类型。 ANY：选择所有用户。SPECIFIC：指定用户选择策略名称。 默认值：无 配置原则：无                                                                                                                                      |
| USERSELPLYNAME | 用户选择策略名称 | 可选必选说明：条件必选参数 前提条件：该参数在“USERSELPLYTYPE”配置为“SPECIFIC”时为必选参数。 参数含义：该参数指定用户选择策略名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                            |
| PRIORITY       | 全局优先级    | 可选必选说明：可选参数 参数含义：该参数用于配置报表策略的优先级。 数据来源：本端规划 取值范围：整数类型，取值范围为1～65535。 默认值：无 配置原则：无                                                                                                                                                       |
| SAMPLERANGE    | 报表抽样范围   | 可选必选说明：可选参数 参数含义：该参数用于设置指定策略的抽样范围。 数据来源：本端规划 取值范围：枚举类型。 INHERIT：继承SET RPTGLBPARA的FLOWSAMPLERATE参数配置的全局抽样能力，不做单独控制。ALL：全量抽样。 默认值：无 配置原则：无                                                                                               |

#### 使用实例

运营商需要改基于策略的业务报表开关：

```
MOD RPTPOLICY:POLICYNAME="policy01",USERSELPLYTYPE=SPECIFIC,USERSELPLYNAME="userpolicy1",SWITCH=ENABLE,PRIORITY=100;
```
