# 修改APN的IMS分类器（MOD APNIMSSIGFLTR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，请确认修改规则后合法的IMS信令报文都能命中其中一条规则。

该命令用于修改APN下的IMS信令专用上下文的Filter。使用VoLTE语音业务时，需要使用该命令修改IMS信令专用上下文的Filter来设置报文的过滤规则。

#### 注意事项

- 该命令执行后只对新激活用户生效。
- 执行该命令时，如果需要修改APN参数，只能修改为做IMS业务的APN，且规则修改后要保证所有合法IMS业务能够命中。如果配置不当，将会影响IMS语音信令的转发，造成语音不通。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

根据网络规划，需要在APN下修改一个Filter：

```
MOD APNIMSSIGFLTR:APN="huawei.com",PRIORITY=8,IPVERSION=IPV4,SRCIPV4SPECTYPE=SPECIFY,SRCIPV4ADDR="10.23.23.23",SRCIPV4MASKLEN=32,SRCPORTSPECTYPE=SPECIFY,SRCPORTSTART=1,SRCPORTEND=65535,DSTIPV4SPECTYPE=SPECIFY,DSTIPV4ADDR="10.5.5.5",DSTIPV4MASKLEN=1,DSTPORTSPECTYPE=SPECIFY,DSTPORTSTART=50,DSTPORTEND=80,PROSPECTYPE=SPECIFY,PROTOCOL=6;
```
