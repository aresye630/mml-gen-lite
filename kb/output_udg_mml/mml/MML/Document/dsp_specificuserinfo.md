# 显示特定类型用户信息（DSP SPECIFICUSERINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

用来查看特定类型用户信息。

#### 注意事项

下发命令不会全量显示用户信息，每次查询单进程显示100条记录，再次执行命令顺序向后查询用户信息。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                   |
|:----------|:-------|:---------------------------------------------------------------------------------------|
| QUERYTYPE | 查询方式   | 可选必选说明：必选参数 参数含义：查询方式。 数据来源：本端规划 取值范围：枚举类型。 IMSBYPASS：查询当前ims-bypass用户信息。 默认值：无 配置原则：无 |

#### 使用实例

查询特定类型用户信息，QRYTYPE为IMSBYPASS：

```
DSP SPECIFICUSERINFO: QUERYTYPE=IMSBYPASS;
```

```
RETCODE = 0  操作成功

特定类型用户信息
------------
                             IMSI  =  176456789012342
                           MSISDN  =  12341234
(结果个数 = 1)

---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                                 |
|:--------|:--------------------------------------|
| IMSI    | 国际移动用户标识，当用户接入不携带IMSI时，显示为“NULL”。     |
| MSISDN  | 用户的MSISDN号，当用户接入不携带MSISDN时，显示为“NULL”。 |
