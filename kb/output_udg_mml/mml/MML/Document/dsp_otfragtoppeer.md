# 显示外层IP分片异常的对端信息（DSP OTFRAGTOPPEER）

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于显示存在异常IP分片的对端信息。当某个DSCP的IP分片资源数超阈值后，则认为存在异常IP分片情况，开始记录后续IP分片报文中对端IP地址，并基于该IP统计分片包数、资源申请失败次数等相关信息，使用该命令可显示记录的对端IP地址及相关统计信息。

#### 注意事项

- 该命令保存的内容不支持备份恢复，进程复位后会清空。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                   |
|:----------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------|
| PODNAME   | POD名称    | 可选必选说明：必选参数 参数含义：该参数用于指定POD名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～127。不支持空格，区分大小写。 默认值：无 配置原则：无                                             |
| PERIODSEQ | 统计周期相对序号 | 可选必选说明：必选参数 参数含义：该参数用于指定统计周期的相对序号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～24。 默认值：无 配置原则：数值越小，相对当前周期时间间隔越小。0表示查询当前周期的统计。                           |
| ORDERITEM | 用于排序的统计项 | 可选必选说明：可选参数 参数含义：该参数指定用于排序的统计项。指定该参数后，显示的结果将从大到小排序。 数据来源：本端规划 取值范围：枚举类型。 FRAG_PKT_NUM：分片报文数。AGED_FRAG_MNODE_NUM：被老化的分片流数。 默认值：无 配置原则：无 |

#### 使用实例

显示存在异常IP分片的对端信息：

```
DSP OTFRAGTOPPEER: PODNAME="isu-pod-0", PERIODSEQ=1, ORDERITEM=AGED_FRAG_MNODE_NUM;
```
