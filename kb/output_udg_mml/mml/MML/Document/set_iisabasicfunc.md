# 设置智能SA推理基本功能（SET IISABASICFUNC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

此命令用于设置智能SA推理模型基本功能相关参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | SWITCH   |
|:-------|:---------|
| 初始值    | DISABLE  |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                       |
|:-------|:-------|:-------------------------------------------------------------------------------------------|
| SWITCH | 分析开关   | 可选必选说明：必选参数 参数含义：该参数用于设置智能SA推理开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无 |

#### 使用实例

设置使能SA基本功能：

```
SET IISABASICFUNC: SWITCH=DISABLE;
```
