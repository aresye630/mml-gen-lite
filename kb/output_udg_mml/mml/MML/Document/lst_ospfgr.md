# 查询OSPF的平滑重启配置（LST OSPFGR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询OSPF的平滑重启配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识           | 参数名称       | 参数说明                                                                       |
|:---------------|:-----------|:---------------------------------------------------------------------------|
| PROCID         | 进程号        | 可选必选说明：可选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无     |
| HELPERROLEFLAG | 使能Helper模式 | 可选必选说明：可选参数 参数含义：使能Helper模式。 数据来源：本端规划 取值范围：枚举类型。 FALSE：不使能。TRUE：使能。 默认值：无 |
| HELPERFLAG     | 使能GR       | 可选必选说明：可选参数 参数含义：使能GR。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无     |

#### 使用实例

查询OSPF的平滑重启配置：

```
LST OSPFGR:;
```

```
RETCODE = 0  操作成功。

结果如下
------------------------

               只支持计划GR  =  FALSE

             Helper过滤类型  =  空

```

#### 输出结果说明

| 输出项名称                 | 输出项解释                                                       |
|:----------------------|:------------------------------------------------------------|
| 进程号                   | 该参数指定用户创建的OSPF进程号。                                          |
| 只支持计划GR               | 该参数指定在路由器上是否支持计划内的平滑重启。默认支持计划内和计划外的。                        |
| 使能Helper模式            | 该参数指定是否使能Helper模式。                                          |
| 不检查Type-5和Type-7类的LSA | 该参数指定是否不检查Type-5和Type-7类的LSA。                               |
| 不支持Helper模式           | 该参数指定是否不支持Helper模式。                                         |
| 使能GR                  | 该参数指定是否使能平滑重启。                                              |
| Helper过滤值             | 该参数指定Helper过滤值，当Helper过滤类型配置为acl_name，ip_prefix或acl_num时生效。 |
| Helper过滤类型            | 该参数指定Helper过滤类型，当使能Helper模式为true时生效。                        |
