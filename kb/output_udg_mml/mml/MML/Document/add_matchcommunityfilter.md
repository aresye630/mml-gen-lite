# 增加匹配团体属性过滤器（ADD MATCHCOMMUNITYFILTER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于添加匹配团体属性过滤器。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为65535。
- 配置该命令前，必须已经通过ADD ROUTEPOLICY配置了指定路由策略的名字以及通过ADD ROUTEPOLICYNODE配置了该策略下的节点。
- 配置该命令前，必须已经通过ADD COMMUNITYFILTER配置了团体属性过滤器。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称        | 参数说明                                                                                                                                                                                                         |
|:---------------|:------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| POLICYNAME     | 路由策略名字      | 可选必选说明：必选参数 参数含义：该参数用于指定路由策略名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无 配置原则：区分大小写。                                                                                                                         |
| NODESEQUENCE   | 路由策略节点ID    | 可选必选说明：必选参数 参数含义：该参数用于指定路由策略节点ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无                                                                                                                                    |
| CMNTYNAMEORNUM | 团体属性过滤器名字或号 | 可选必选说明：必选参数 参数含义：该参数用于指定团体属性过滤器名字或团体属性过滤器号。 数据来源：本端规划 取值范围：字符串类型，团体属性过滤器名称其长度范围是1～51。 默认值：无 配置原则：团体属性过滤器号为整数形式，其中基本团体属性过滤器号的取值范围为1～99，高级团体属性过滤器号的取值范围为100～199。团体属性过滤器名称为字符串形式，区分大小写，不支持空格，长度范围是1～51，且不能都是数字。 |
| WHOLEMATCH     | 完全匹配        | 可选必选说明：可选参数 参数含义：该参数用于指定是否需要完全匹配。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：FALSE                                                                                                                        |

#### 使用实例

增加基于团体属性过滤器的匹配规则：

```
ADD MATCHCOMMUNITYFILTER:NODESEQUENCE=10,CMNTYNAMEORNUM="aaa",POLICYNAME="a";
```
