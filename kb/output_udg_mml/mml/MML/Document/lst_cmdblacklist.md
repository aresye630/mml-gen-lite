# 查询黑名单命令（LST CMDBLACKLIST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

本命令用于查询所有在命令黑名单中的MML命令。

#### 注意事项

无。

#### 参数说明

无。

#### 使用实例

查看黑名单命令：

```
LST CMDBLACKLIST:;
```

```
%%LST CMDBLACKLIST:;%%
RETCODE = 0  操作成功

操作结果如下
------------
网元ID  命令名称  预警号  预期解决版本号

0       MOD USER  12      34
0       LST ME    1       1
(结果个数 = 2)

---    END
```

#### 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。输出结果说明如表1所示。

命令执行异常，请联系华为技术支持处理。常见异常场景如表2所示。

| 输出项名称   | 输出项解释         |
|:--------|:--------------|
| 网元ID    | 黑名单命令对应的网元ID。 |
| 命令名称    | 黑名单命令的名称。     |
| 预警号     | 预警号。          |
| 预期解决版本号 | 预期解决版本号。      |

|    错误码 | 错误码解释    | 原因分析       | 处理建议       |
|-------:|:---------|:-----------|:-----------|
| 101099 | 数据库执行失败。 | 执行数据库操作失败。 | 请联系华为技术支持。 |
