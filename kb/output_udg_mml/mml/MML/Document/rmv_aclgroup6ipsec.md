# 删除IPv6 ACL规则组（RMV ACLGROUP6IPSEC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

删除IPv6 ACL规则组，影响业务流量使用IPSEC进行加解密功能，有业务影响。

该命令用于删除ACL规则组。

## 注意事项

- 该命令执行后立即生效。

- 如果规则组下配置了规则，则所有规则会一并删除。
- 如果有业务已经在IPSEC策略中配置了该规则组，不可以删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                |
|:--------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ACLNAME | 规则组标识  | 可选必选说明：必选参数  参数含义：该参数用于指定规则组名称或是编号。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。不支持空格，区分大小写。以英文字母a～z或A～Z开始，可以是英文字母、数字、连字符“-”、下划线“_”或中文字符的组合。整数形式，取值范围是3000～3999（高级ACL），但兼容CE版本，允许配置其他数值但不会生效。  默认值：无  配置原则：无 |

## 使用实例

用户不再使用ACL进行报文过滤，可以将规则组3005删除：

```
RMV ACLGROUP6IPSEC: ACLNAME="3005";
```
