# 查询网元场景和模型（DSP MESCNMOD）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询指定网元下的推理场景和部署模型信息。

#### 注意事项

无。

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                              |
|:-------|:-------|:--------------------------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：需要查询推理场景和部署的模型信息的网元ID。 取值范围：整数类型，取值范围为0~65535。 默认值：无。 配置原则：网元ID可通过LST ME命令查询获得。 |

#### 使用实例

查询网元ID=0的推理场景信息和部署的模型信息。

```
%%DSP MESCNMOD: MEID=0;%%
RETCODE = 0  操作成功

网元推理场景信息和部署的模型信息
--------------------------------
网元ID  服务名称               场景类型           模型包名称                    模型文件名称                    来源  

0       CSPCCommonServiceDemo  FACE_RECOGNITION   MODEL-AUTO_20241204144727.zip FACE_RECOGNITION_1.0.0.tar.gz   手动  
0       CSPCCommonServiceDemo  PROTOCOL_CLASSIFY  MODEL-AUTO_202412041447.zip   PROTOCOL_CLASSIFY_1.0.1.tar.gz  预置  
(结果个数 = 2) 

---    END
```

#### 输出结果说明

命令执行正常，会返回给定的网元ID下注册的服务和推理场景信息，如果该服务在该场景下有部署过模型，也会一同展示最近一次部署的模型信息。输出结果项信息项目如表1。

命令执行异常，会返回对应的错误码。常见错误码如表2所示。

| 输出项名称   | 输出项解释                  |
|:--------|:-----------------------|
| 网元ID    | 用于返回当前网元ID。            |
| 服务名称    | 用于返回该网元ID下注册推理场景的服务名称。 |
| 场景类型    | 用于返回该网元ID下服务注册的推理场景。   |
| 模型包名称   | 用于返回服务在对应场景下部署的模型包名称。  |
| 模型文件名称  | 用于返回服务在对应场景下部署的模型文件名称。 |
| 来源      | 用于返回服务在对应场景下部署的模型来源。   |

|    错误码 | 错误码解释          | 原因分析                       | 处理建议                 |
|-------:|:---------------|:---------------------------|:---------------------|
| 181001 | 下发的MML参数不正确。   | 非法的命令参数。                   | 请检查输入的命令参数或联系华为技术支持。 |
| 181002 | 系统内部错误，请联系管理员。 | 执行过程中可能存在网络故障或者服务不可用等异常因素。 | 等待几分钟后重试。            |
