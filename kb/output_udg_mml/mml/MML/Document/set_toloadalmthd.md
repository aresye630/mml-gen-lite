# 设置告警阈值（SET TOLOADALMTHD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于设置告警阈值。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   |   WARNTHRESH |   RECVTHRESH |
|:-------|-------------:|-------------:|
| 初始值    |           90 |           70 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                  |
|:-----------|:----------|:--------------------------------------------------------------------------------------|
| WARNTHRESH | 告警产生阈值（%） | 可选必选说明：可选参数 参数含义：告警的阈值。 数据来源：本端规划 取值范围：整数类型，取值范围0～100。 默认值：无 配置原则：告警产生阈值必须大于恢复告警阈值。   |
| RECVTHRESH | 告警恢复阈值（%） | 可选必选说明：可选参数 参数含义：告警的恢复阈值。 数据来源：本端规划 取值范围：整数类型，取值范围0～100。 默认值：无 配置原则：恢复告警阈值必须小于告警产生阈值。 |

#### 使用实例

设置告警产生阈值为80%、告警恢复阈值为60%：

```
SET TOLOADALMTHD: WARNTHRESH=80, RECVTHRESH=60;
```
