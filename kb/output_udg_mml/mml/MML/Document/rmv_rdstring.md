# 删除RD字符（RMV RDSTRING）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来删除RD属性。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                                                                                                                                               |
|:-------------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INDEX        | RD过滤器索引  | 可选必选说明：必选参数 参数含义：该参数用于指定RD过滤器索引。 数据来源：本端规划 取值范围：整数类型，取值范围为1～1024。 默认值：无                                                                                                                                            |
| NODESEQUENCE | RD过滤器节点号 | 可选必选说明：必选参数 参数含义：该参数用于指定RD过滤器节点号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无                                                                                                                                     |
| STRINGVALUE  | 字符值      | 可选必选说明：必选参数 参数含义：该参数用于指定RD属性值，支持如下4种格式： 1. IPv4地址:nn，如10.1.1.1:200。 2. aa:nn，如100:1。 3. IPv4地址:*，通配格式。如10.1.1.1:*表示匹配所有以10.1.1.1开头的RD。 4. aa:*，通配格式。如100:*表示匹配所有以100开头的RD。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～21。 默认值：无 |

#### 使用实例

删除RD属性：

```
RMV RDSTRING:INDEX=55,NODESEQUENCE=10,STRINGVALUE="1:1";
```
