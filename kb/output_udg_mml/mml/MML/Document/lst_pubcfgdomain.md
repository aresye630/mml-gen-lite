#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

本命令用于查询网元已加入的配置域的名称。配置域也称之为集中配置管理组。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

显示网元已加入的所有域的域信息：

```
LST PUBCFGDOMAIN:;
```

```
RETCODE = 0  操作成功。

公共配置域信息
-------------------------
域名称  

aaa            
bbb            
ccc            
ddd            
sss            
(Number of results = 5)

---    END
```
