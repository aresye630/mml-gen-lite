# 修改区域（MOD ZONE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：CloudEPSN**

本命令实现修改区域的功能。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                           |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VIEWNAME | 视图名称   | 可选必选说明：可选参数 参数含义：资源所属的域名解析视图名称。 数据来源：本端规划 取值范围：1、名称如果分段，每段不超过63个字符，并且视图名称（填入的视图名称）总长度不超过253个字符；如果不分段，填入的视图名称最长不超过63个字符。该字符数转化为符合DNS标准ASCII格式（Punycode编码）后的要求。 2、不支持连续的点、下划线、中横线（如“..”、“__”、“--”）。 3、视图名称的每段的内容支持以字母、数字、下划线、中横线的任意组合，但是不支持以中横线开头和不支持下划线结尾。 4、不允许输入仅一个“.”。 5、不支持以“.”开头和结尾。 默认值：default 配置原则： 输入单空格将删除该参数已有配置项。视图名称需要在CMS WEB端配置。CloudDNS中视图默认值为"default"。大小写不敏感。 |
| ZONE     | 区域名称   | 可选必选说明：必选参数 参数含义：资源记录的区域名。 数据来源：全网规划 取值范围：1、区名称的输入格式要正确（例：xxx.com），同视图内区名称唯一（同一视图下的权威区的区名称均唯一），“@”表示根区。如果分段，每段不超过63个字符，并且整个区名称（填入的权威区名称）总长度不超过189个字符；如果不分段，最长不超过63个字符。该字符数是转化为符合DNS标准ASCII格式（Punycode编码）后的要求。 2、不支持连续的点、下划线（如".."、"__"）。 3、不支持“*”。 4、不支持以“.”开头和结尾。 5、区名中每段的内容支持以字母、数字、下划线、中横线的任意组合，但是不支持以中横线开头。 默认值：无 配置原则：大小写不敏感。                                             |
| TTL      | TTL    | 可选必选说明：必选参数 参数含义：NA。 数据来源：本端规划 取值范围：NA。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                           |

#### 使用实例

修改区域，“视图名称”填写为“default”，“区域名称”填写为“test.cmnet.mnc000.mcc460.gprs”，“TTL”填写为600：

```
MOD ZONE: VIEWNAME="default", ZONE="test.cmnet.mnc000.mcc460.gprs", TTL=600;
```
