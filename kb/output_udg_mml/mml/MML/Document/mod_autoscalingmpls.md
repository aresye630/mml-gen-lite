# 修改MPLS自动化配置模板（MOD AUTOSCALINGMPLS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改MPLS自动化配置模板。

#### 注意事项

- 该命令执行后立即生效。
- 修改该模板时，要保证该模板添加过。
- 该命令在自动化配置开关为关闭的状态下才能执行，请先使用SET AUTOCONFIG命令关闭自动配置开关；若要使配置生效，需要再次使用SET AUTOCONFIG命令开启自动配置开关。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                         |
|:------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICENAME | 服务名称   | 可选必选说明：必选参数 参数含义：该参数用来表示接口自动化配置服务模板名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格和中文。 默认值：无                                                                                                      |
| MTU         | 最大传输单元 | 可选必选说明：必选参数 参数含义：该参数用于指定MPLS接口最大传输单元。 数据来源：本端规划 取值范围：整数类型，取值范围为46～9600。 默认值：无 配置原则：该命令不支持删除此参数已有配置，若需删除，须先使用RMV AUTOSCALINGMPLS命令删除MPLS自动化配置模板，再使用ADD AUTOSCALINGMPLS命令配置MPLS自动化配置模板且不配置该参数。 |

#### 使用实例

修改一个MPLS自动化配置模板：

```
MOD AUTOSCALINGMPLS:SERVICENAME="s1", MTU=1500;
```
