# 增加用户模板和规则的绑定关系（ADD RULEBINDING）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于增加用户模板与规则绑定关系，当用户数据报文可以匹配到多个规则时，需要将多个规则绑定到用户模板下。

#### 注意事项

- 该命令执行后只对新激活用户生效。
- 该命令最大记录数为200000。当配置记录数大于规格的90%时，会上报“ALM-135602215 配置数量超阈值”告警。当配置记录数小于等于配置规格90%时，恢复“ALM-135602215 配置数量超阈值”告警。阈值可以通过MOD CFGTHRESHOLD命令修改。
- 单个默认规则用户模板最多可以绑定8000个规则。
- 单个规格受限规则用户模板最多可以绑定100个规则。
- 对已经在线的用户，依次扫描生效，生效时间最长为1小时。
- DEFAULT类型的UserProfile只能绑定DEFAULT类型的Rule。SPECIFICATION\_LIMITED类型的UserProfile只能绑定SPECIFICATION\_LIMITED类型的Rule。
- 按需开启软参BIT2553以开启支持不同类型的规则和用户模板之间交叉绑定的功能。
- 该命令会导致用户匹配范围发生变化，可能导致性能下降。执行命令前请评估对性能的影响，如果无法评估请联系华为技术支持。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

如果PGW-C/SMF下发用户模板名称给系统，则在系统上需要将配置的规则绑定到对应的用户模板上：

```
ADD RULEBINDING: USERPROFILENAME="userprofile",RULENAME="rule";
```
