# 查询IGMP加入组信息（DSP MGMDGROUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示IGMP加入组信息。

#### 注意事项

该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称    | 参数说明                                                                                                               |
|:----------------|:--------|:-------------------------------------------------------------------------------------------------------------------|
| ADDRESSFAMILY   | 地址族     | 可选必选说明：必选参数 参数含义：该参数用于指定地址族类型。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。 默认值：无                                      |
| VRFNAME         | VPN实例名称 | 可选必选说明：可选参数 参数含义：该参数用来表示VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：_public_ 配置原则：通过LST L3VPNINST查看当前已存在的VPN实例。 |
| MASTERSLAVETYPE | OMU类型   | 可选必选说明：可选参数 参数含义：该参数表示OMU类型。 数据来源：本端规划 取值范围：枚举类型。 MASTER：主。SLAVE：备。 默认值：MASTER                                     |
| IFNAME          | 接口名称    | 可选必选说明：可选参数 参数含义：该参数用于指定接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。               |

#### 使用实例

显示IGMP加入组信息：

```
DSP MGMDGROUP:ADDRESSFAMILY=ipv4unicast,VRFNAME="_public_";
```

#### 输出结果说明

| 输出项名称                | 输出项解释                                                 |
|:---------------------|:------------------------------------------------------|
| VPN实例名称              | 用来表示VPN实例名称。                                          |
| 接口名称                 | 用于指定接口名称。                                             |
| 组地址                  | 用于指定组地址。                                              |
| 上一次发送report报文的主机IP地址 | 用于指定上一次发送report报文的主机IP地址。                             |
| 表项建立时间               | 用于指定表项建立时间。                                           |
| 表项超时时间               | 用于指定表项超时时间。                                           |
| 最后一个成员查询次数           | 用于指定最后一个成员查询次数。                                       |
| 最后一个成员查询定时器          | 用于指定最后一个成员查询定时器。                                      |
| 源过滤模式                | 用于指定源过滤模式，包括： Include表示Include模式。Exclude表示Exclude模式。  |
| V1主机存在定时器            | 用于指定IGMPv1主机的超时时间，包括两种取值： 时间：时间格式为时:分:秒。off：表示定时器未启动。 |
| V2主机存在定时器            | 用于指定IGMPv2主机的超时时间，包括两种取值： 时间：时间格式为时:分:秒。off：表示定时器未启动。 |
| 组标记                  | 用于指定组标记，区分是Report建立的组还是SSM映射建立的组。                     |
