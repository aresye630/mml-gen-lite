# 查询在复杂故障场景下自愈功能控制参数（LST CFSHEALCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询在复杂故障场景下自愈功能控制参数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

显示在复杂故障场景下自愈功能控制参数。

```
%%LST CFSHEALCTRL:;%%
RETCODE = 0  操作成功

结果如下
--------
             通信亚健康隔离功能开关  =  关闭
           亚健康诊断等待时间(分钟)  =  10
             Q922连续诊断周期（次）  =  3
    网元级KPI异常检测与容灾功能开关  =  关闭
             容灾决策等待时间（秒）  =  300
                       容灾执行策略  =  手动
    模块级KPI异常检测与恢复功能开关  =  开启
         诊断隔离处理等待时间（秒）  =  120
                      异常阈值（%）  =  90
                          差值（%）  =  20
模块级KPI异常检测与恢复功能隔离策略  =  自动
                       连续检测周期  =  3
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称               | 输出项解释                                                                                                                                                          |
|:--------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 通信亚健康隔离功能开关         | 该参数用于控制在出现通信亚健康故障后是否诊断隔离。                                                                                                                                      |
| 亚健康诊断等待时间(分钟)       | 该参数用于配置通信亚健康延迟诊断时间。                                                                                                                                            |
| Q922连续诊断周期（次）       | 该参数用于指定Q922诊断周期N，目的是防止网络丢包震荡。如果连续N次查询都有“ALM-1011 控制平面丢包错包”告警，每次查询告警的定位信息中有相同的目的Pod，则以第N次查询结果作为诊断输入。                                                            |
| 网元级KPI异常检测与容灾功能开关   | 在网元出现亚健康（如多个主机出现fabric平面亚健康/cpu过载/pod持续故障等）故障而导致业务KPI下降达到阈值时，该参数用于控制网元级KPI异常检测与容灾功能开关。                                                                         |
| 容灾决策等待时间（秒）         | 该参数用于配置容灾决策的等待时间。                                                                                                                                              |
| 容灾执行策略              | 该参数用于配置容灾执行处理的策略。                                                                                                                                              |
| 模块级KPI异常检测与恢复功能开关   | 用于控制由于网元内单主机出现Fabric平面丢包/CPU过载/流控故障而导致KPI下降满足阈值时做对应自愈隔离处理的功能开关。                                                                                                |
| 诊断隔离处理等待时间（秒）       | 用于配置延后诊断隔离处理的等待时间。该参数已废弃。                                                                                                                                      |
| 异常阈值（%）             | 该参数在虚机形态下用于配置Node的CPU使用率异常阈值，在裸机形态下用于配置Pod的CPU使用率异常阈值，大于等于此值初步判断为异常。                                                                                           |
| 差值（%）               | 该参数在虚机形态下用于配置与同类型Node的CPU使用率平均值的差值，在裸机形态下用于配置与同类型Pod的CPU使用率平均值的差值，若某个Node/Pod的CPU使用率大于等于同类型Node/Pod的CPU使用率平均值与差值之和（由于CPU使用率上限是100%，当该和超过100%时视为100%），则初步判断为异常。 |
| 模块级KPI异常检测与恢复功能隔离策略 | 该参数用于配置模块级KPI异常检测与恢复功能的隔离策略。                                                                                                                                   |
| 连续检测周期              | 该参数用于设置连续检测周期。                                                                                                                                                 |
