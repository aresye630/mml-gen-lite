# 显示进程消息队列信息（DSP PROCMSGQUEUE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示进程内的消息队列使用信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| PROCID          | 进程ID   | 可选必选说明：必选参数 参数含义：网元内一个进程的进程ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                  |
| COMPNAME        | 组件名    | 可选必选说明：可选参数 参数含义：进程内一个组件的名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，区分大小写。 默认值：无                             |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

查询进程内消息队列的使用情况：

```
DSP PROCMSGQUEUE:PROCID=1001,COMPNAME="SEM_Agent",SERVICEINSTANCE="vnfc";
```

#### 输出结果说明

| 输出项名称     | 输出项解释            |
|:----------|:-----------------|
| 进程ID      | 网元内一个进程的进程ID。    |
| 组件名       | 进程内一个组件的名字。      |
| 组件ID      | 进程内一个组件的ID。      |
| 队列名称      | 进程内一个消息队列的名字。    |
| 消息数目      | 进程内消息队列的数目。      |
| 消息最大数目    | 进程内消息队列的最大数目。    |
| 消息最大数目的时间 | 进程内消息队列的最大数目的时间。 |
