# 删除报表服务器（RMV RPTSVR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于删除报表服务器。当希望删除报表服务器，则配置该命令。

#### 注意事项

- 该命令执行后立即生效。
- 如果RptSvr被RptSvrAddr绑定，删除时，需要将绑定关系解除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                    |
|:-----------|:--------|:----------------------------------------------------------------------------------------|
| RPTSVRNAME | 报表服务器名称 | 可选必选说明：必选参数 参数含义：设置报表服务器名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

删除报表服务器report01：

```
RMV RPTSVR: RPTSVRNAME="report01";
```
