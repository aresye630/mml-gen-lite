# 显示外置DB过滤器信息（DSP EXTERDBFILTER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询外置DataBase过滤器。当运营商希望查询外置DataBase过滤器时，则执行该命令。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                                                                                                                                   |
|:---------------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OTTFILTERNAME  | 外部过滤器名称  | 可选必选说明：条件必选参数 前提条件：该参数在“OTTDBQRYTYPE”配置为“OTT_FILTER_INFO”时为必选参数。 参数含义：该参数用于设置过滤器名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：需配置为当前加载的规则库内FILTER的名字。                                                                  |
| FLOWFILTERNAME | 外部流过滤器名称 | 可选必选说明：条件必选参数 前提条件：该参数在“OTTDBQRYTYPE”配置为“OTT_FLOWFILTER_INFO”时为必选参数。 可选必选说明：条件可选参数 前提条件：该参数在“OTTDBQRYTYPE”配置为“NUMBER”时为可选参数。 参数含义：该参数用于设置流过滤器名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：需配置为当前加载的规则库内FLOWFILTER的名字。 |
| OTTDBQRYTYPE   | OTT库查询类型 | 可选必选说明：必选参数 参数含义：该参数用于指定OTT库查询类型。 数据来源：本端规划 取值范围：枚举类型。 NUMBER：对外部流过滤器数量查询。OTT_FILTER_INFO：外部过滤器信息查询。OTT_FLOWFILTER_INFO：外部流过滤器信息查询。 默认值：无 配置原则：无                                                                                       |

#### 使用实例

运营商需要查询名称为ff1的流过滤器：

```
DSP EXTERDBFILTER: OTTDBQRYTYPE=OTT_FLOWFILTER_INFO,FLOWFILTERNAME="ff1";
```

```
RETCODE = 0  Operation Success.

-------------------------

```
