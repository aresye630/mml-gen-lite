# 设置头增强全局参数（SET HEADENGLBPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于设置头增强全局参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | RC4KEYMD5EN   |   MSISDNMINLEN |   RSANODEAGETIME | RSAEXPIREDALM   |   RSACERTEXPALMDAYS | HEADENSALTTYPE   |
|:-------|:--------------|---------------:|-----------------:|:----------------|--------------------:|:-----------------|
| 初始值    | DISABLE       |              0 |               10 | ENABLE          |                  30 | RANDNUM          |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识              | 参数名称               | 参数说明                                                                                                                                    |
|:------------------|:-------------------|:----------------------------------------------------------------------------------------------------------------------------------------|
| RC4KEYMD5EN       | RC4的密钥MD5 Hash使能标识 | 可选必选说明：可选参数 参数含义：该参数用于设置RC4的密钥MD5 Hash使能标识。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能，RC4加密前不需要做一次MD5加密。ENABLE：使能，RC4加密前需要做一次MD5加密。 默认值：无 配置原则：无 |
| MSISDNMINLEN      | MSISDN字段最小长度       | 可选必选说明：可选参数 参数含义：该参数用于设置头增强功能去除国家码之后MSISDN字段最小长度。 数据来源：本端规划 取值范围：整数类型，取值范围为0～17。 默认值：无 配置原则：无                                           |
| RSANODEAGETIME    | RSA加密节点老化时间（分）     | 可选必选说明：可选参数 参数含义：该参数用于设置RSA加密节点的老化时间。 数据来源：本端规划 取值范围：整数类型，取值范围为1～1440，单位是分钟。 默认值：无 配置原则：无                                               |
| RSAEXPIREDALM     | RSA证书过期告警          | 可选必选说明：可选参数 参数含义：该参数用于配置RSA证书文件过期告警开关。 数据来源：本端规划 取值范围：枚举类型。 ENABLE：使能。DISABLE：不使能。 默认值：无 配置原则：无                                         |
| RSACERTEXPALMDAYS | RSA证书过期告警提前天数      | 可选必选说明：可选参数 参数含义：该参数用于设置RSA证书过期告警提前天数。 数据来源：本端规划 取值范围：整数类型，取值范围为0～365，单位是天。 默认值：无 配置原则：无                                                |
| HEADENSALTTYPE    | 头增强插入盐值生成方法类型      | 可选必选说明：可选参数 参数含义：头增强盐值。 数据来源：本端规划 取值范围：枚举类型。 RANDNUM：使用随机数生成盐值。TIMESTAMP：使用时间戳生成盐值，有安全风险，不建议使用。 默认值：无 配置原则：无                            |

#### 使用实例

假如运营商需要设置MSISDN字段最小长度为1：

```
SET HEADENGLBPARA: MSISDNMINLEN=1;
```
