# 显示计费URR上报失败动作参数（LST URRFAILACTION）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

本条命令用于查询计费URR上报失败的动作。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询URR上报失败动作：

```
LST URRFAILACTION:;
```

```
RETCODE = 0  操作成功

配额申请失败动作信息
--------------------
        重发间隔  =  60
        重发次数  =  2
重发失败后的动作  =  阻塞
        保持时长  =  30
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见SET URRFAILACTION的参数说明。
