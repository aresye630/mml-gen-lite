# 增加L3VPN实例地址族（ADD VPNINSTAF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于设置指定VPN实例下的地址族。

使能VPN实例下的地址族后，才可以进行VPN该地址族下的相关配置。一些路由协议在对VPN路由进行操作时，也要求VPN使能相应的地址族。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为16378。
- 需要确保指定的VPN实例在设备上已经通过ADD L3VPNINST创建。
- 不能给VPN实例\_\_mpp\_vpn\_inner\_\_、\_\_mpp\_vpn\_inner\_server\_\_添加地址族。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识             | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                                                                                            |
|:-----------------|:-------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VRFNAME          | VPN实例名称      | 可选必选说明：必选参数 参数含义：该参数用于指定L3VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：使用LST L3VPNINST命令查看可用VPN。                                                                                                                                                                                                                                                       |
| AFTYPE           | 地址族类型        | 可选必选说明：必选参数 参数含义：该参数用于指定VPN实例下的地址族。 数据来源：本端规划 取值范围：枚举类型。 ipv4uni：IPv4地址族。ipv6uni：IPv6地址族。 默认值：无                                                                                                                                                                                                                                                                 |
| VRFRD            | 路由标识         | 可选必选说明：可选参数 参数含义：该参数用于指定用户需要修改的路由标识符。在不同VPN使用相同网段的场景下，BGP服务可以根据VRFRD区分使用相同网段的不同VPN的路由。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为3～21。 默认值：无 配置原则：该参数配置后不支持直接修改，但是可以下发单空格，执行清空操作，再进行配置。VRFRD值唯一，取值范围是X.X.X.X:number<0-65535>、number<0-65535>:number<0-4294967295>、number<0-65535>.number<0-65535>:number<0-65535>或者number<65536-4294967295>:number<0-65535>，但不支持配置为0:0和0.0:0。 |
| IMPOLICYNAME     | 引入路由策略名称     | 可选必选说明：可选参数 参数含义：该参数用于指定路由交叉入该VPN时的入口策略名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无 配置原则：在此之前应使用ADD ROUTEPOLICY命令配置对应策略。使用LST ROUTEPOLICY命令查看可用路由策略。                                                                                                                                                                                                            |
| LOCALCROSSNHPMOD | 可更改本地交叉下一跳   | 可选必选说明：可选参数 参数含义：该参数用于指定是否使能本地交叉修改下一跳功能。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：FALSE 配置原则： 该参数配置时，需要同时配置IMPOLICYNAME参数。该参数配置时，需要同时配置VRFRD参数。                                                                                                                                                                                                            |
| EXPOLICYNAME     | 发布路由策略名称     | 可选必选说明：可选参数 参数含义：该参数用于指定路由发布时的出口策略名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无 配置原则：在此之前应使用ADD ROUTEPOLICY命令配置对应策略。使用LST ROUTEPOLICY命令查看可用路由策略。                                                                                                                                                                                                                 |
| EXPLYADDERTFIRST | 路由上送时首先添加ERT | 可选必选说明：可选参数 参数含义：该参数用于指定路由上送时是否在过策略前添加ERT。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：FALSE 配置原则： 该参数配置时，需要配置EXPOLICYNAME参数。当指定的路由策略中有对RT值进行匹配的条件时，需要配置此参数。该参数配置时，需要配置VRFRD参数。                                                                                                                                                                               |
| VRFLABELMODE     | 实例的标签分配模式    | 可选必选说明：可选参数 参数含义：该参数用于指定VPN实例的标签分配模式。 数据来源：本端规划 取值范围：枚举类型。 perRoute：每路由每标签。perInstance：每实例每标签。perInstanceStatic：每实例每静态标签。 默认值：perRoute                                                                                                                                                                                                                          |
| VRFLABEL         | 实例的标签值       | 可选必选说明：该参数在“VRFLABELMODE”配置为“perInstanceStatic”时为条件可选参数。 参数含义：该参数用于指定VPN实例的静态标签值。 数据来源：本端规划 取值范围：整数类型，取值范围为16～32767。 默认值：无 配置原则：无                                                                                                                                                                                                                               |
| TNLPOLICYNAME    | 隧道策略名称       | 可选必选说明：可选参数 参数含义：该参数用于指定隧道策略名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～39。 默认值：无 配置原则：在此之前应使用ADD TUNNELPOLICY命令配置对应策略。使用LST TUNNELPOLICY命令查看可用隧道策略。                                                                                                                                                                                                                      |
| FRRENABLE        | FRR使能        | 可选必选说明：可选参数 参数含义：该参数用于指定是否允许FRR使能。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：FALSE 配置原则： 只有配置了VRFRD才可配置FRRENABLE为TRUE。配置FRR可以形成主备路由，提升路由收敛性能。                                                                                                                                                                                                               |

#### 使用实例

增加名称为“vrf1”的VPN实例下的IPv4单播地址族：

```
ADD L3VPNINST: VRFNAME="vrf1";
ADD VPNINSTAF:VRFNAME="vrf1", AFTYPE=ipv4uni;
```
