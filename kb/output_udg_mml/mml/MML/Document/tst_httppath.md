# 测试HTTP链路（TST HTTPPATH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在完成系统配置后，接入业务前，探测本端与对端能否成功建立HTTP/HTTPS连接。

## 注意事项

- 该命令最长耗时15s，只支持逐个探测对端，不支持同时探测多个对端，即只能串行执行探测命令。
- 该命令在SBILINK微服务扩缩容或故障等情况下，存在实际正常的链路探测不通，建议在探测失败时，多次尝试。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称     | 参数说明                                                                                                                                                                                       |
|:----------------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SCHEMA          | 模式       | 可选必选说明：必选参数  参数含义：该参数用于指定探测链路的模式。  数据来源：全网规划 取值范围： “HTTP（HTTP）”：明文传输HTTP协议传输的数据“HTTPS（HTTPS）”：密文传输HTTP协议传输的数据  默认值：无  配置原则：  可根据网络规划选择HTTP或者HTTPS模式进行探测，如果对端同时支持HTTP和HTTPS，则可以对两种模式分别进行探测。 |
| IPTYPE          | IP类型     | 可选必选说明：必选参数  参数含义：该参数用于指定IP类型。  数据来源：全网规划 取值范围： “IPv4（IPv4地址）”：IPv4地址“IPv6（IPv6地址）”：IPv6地址  默认值：无  配置原则：无                                                                                  |
| PEERPORT        | 对端端口     | 可选必选说明：必选参数  参数含义：该参数用于指定对端端口。  数据来源：全网规划  取值范围：整数类型，取值范围是1~65535。  默认值：无  配置原则：无                                                                                                          |
| LOCALIPADDRIPV4 | 本端IPv4地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPv4"时为条件必选参数。  参数含义：该参数用于指定本端IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：  必须与ADD HTTPLE命令中客户端的IPv4地址一致。                                                       |
| LOCALIPADDRIPV6 | 本端IPv6地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPv6"时为条件必选参数。  参数含义：该参数用于指定本端IPv6地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：  必须与ADD HTTPLE命令中客户端的IPv6地址一致。                                                       |
| PEERIPADDRIPV4  | 对端IPv4地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPv4"时为条件必选参数。  参数含义：该参数用于指定对端IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无                                                                                     |
| PEERIPADDRIPV6  | 对端IPv6地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPv6"时为条件必选参数。  参数含义：该参数用于指定对端IPv6地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无                                                                                     |

## 使用实例

若一线人员想测试本端到对端是否能够成功建立链路，模式为HTTP、IP类型为IPv4、本端IP为10.15.186.9、对端IP为10.168.36.39、对端端口为10，可以执行如下命令：

```
%%TST HTTPPATH: SCHEMA=HTTP, IPTYPE=IPv4, PEERPORT=10, LOCALIPADDRIPV4="10.15.186.9", PEERIPADDRIPV4="10.168.36.39";%%
RETCODE = 0 操作成功

输出结果如下
------------------------
结果  =  测试成功
原因  =  连接成功
（结果个数 = 1）

---    END
```
