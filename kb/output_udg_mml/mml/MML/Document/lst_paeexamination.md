# 查询PAE故障检测使能配置（LST PAEEXAMINATION）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询PAE故障检测功能使能状态。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无

#### 使用实例

查询所有微服务的PAE故障检测功能使能状态：

```
LST PAEEXAMINATION:;
```

```
RETCODE = 0  操作成功。

结果如下
---------
使能标志  =  是      
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见**SET PAEEXAMINATION**的参数说明。
