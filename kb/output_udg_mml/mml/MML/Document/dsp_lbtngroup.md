# 查询隧道组信息（DSP LBTNGROUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询隧道组信息，辅助定位隧道转发失败的问题。

#### 注意事项

该命令批量下发可能导致执行超时。

manage-ug；system-ug；monitor-ug

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                      |
|:----------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------|
| SRVVNFCID | 业务VNFCID | 可选必选说明：可选参数 参数含义：该参数用于指定业务VNFC的唯一标识，通过在业务VNFC下执行LST NODE获得，所得NODE ID（节点ID）即为业务VNFCID。 数据来源：本端规划 取值范围：整数类型，取值范围为0~4294967295。 默认值：无 配置原则：无 |
| TNGRPID   | 隧道组ID    | 可选必选说明：可选参数 参数含义：该参数用于表示业务VNFC定义的隧道组的标识。 数据来源：本端规划 取值范围：整数类型，取值范围为0~4294967295。 默认值：无 配置原则：无                                              |
| TNGRPNAME | 隧道组名称    | 可选必选说明：可选参数 参数含义：该参数用于表示业务VNFC定义的隧道组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围0~15。 默认值：无 配置原则：使用DSP LBTN命令查看可用的隧道组名称                                |

#### 使用实例

查询隧道组。

`DSP LBTNGROUP:;`

```
%%DSP LBTNGROUP:;%%
RETCODE = 0  操作成功。

操作结果如下：
--------------
  隧道组名称    =  tnc_grp1
  隧道组ID      =  1
  业务VNFCID    =  5
  是否共享隧道  =  共享
  隧道传输QOS   =  1
  探测开关状态  =  打开
  上报状态开关  =  打开
  心跳间隔时长  =  1
  心跳重传次数  =  3
  隧道组状态    =  正常
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称    | 输出项解释                                                                                                                               |
|:---------|:------------------------------------------------------------------------------------------------------------------------------------|
| 隧道组名称    | 参数含义：该参数用于表示业务VNFC定义的隧道组名称。 取值范围：字符串类型，输入长度范围为0~15。                                                                                 |
| 隧道组ID    | 参数含义：该参数用于表示业务VNFC定义的隧道组的标识。 取值范围：整数类型，取值范围为0~4294967295。                                                                           |
| 业务VNFCID | 参数含义：该参数用于指定业务VNFC的唯一标识。 取值范围：整数类型，取值范围为0~4294967295。                                                                               |
| 是否共享隧道   | 参数含义：该参数用于表示是否共享隧道。 取值范围：“共享”“非共享”                                                                                                  |
| 隧道传输QoS  | 参数含义：该参数用于表示隧道传输QoS。 取值范围：整数类型，取值范围为0~63。                                                                                           |
| 探测开关状态   | 参数含义：该参数用于表示业务VNFC是否要求CSLB发起隧道探测。 取值范围：“打开”“关闭”                                                                                     |
| 上报状态开关   | 参数含义：该参数用于表示业务VNFC是否要求CSLB上报隧道组状态。 取值范围：“打开”“关闭”                                                                                    |
| 心跳间隔时长   | 参数含义：该参数用于表示业务VNFC下发隧道组信息时配置的隧道组下所有隧道探测的心跳间隔时长。 取值范围：整数类型，取值范围为5~100，单位100毫秒。                                                       |
| 心跳重传次数   | 参数含义：该参数用于表示业务VNFC下发隧道组信息时配置的隧道组下所有隧道探测的心跳重传次数。 取值范围：整数类型，取值范围为1~60。                                                                |
| 隧道组状态    | 参数含义：该参数用于表示隧道组状态。 取值范围：“初始态”：隧道组下没有正常状态的隧道且有初始态的隧道，则该隧道组状态为初始态。“正常”：隧道组下只要有一条隧道状态为正常，则该隧道组的状态为正常。“故障”：隧道组下所有隧道的状态均为故障，则该隧道组的状态为故障。 |
