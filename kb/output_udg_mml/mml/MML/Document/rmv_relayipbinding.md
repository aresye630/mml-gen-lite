# 删除媒体中继服务IP绑定配置（RMV RELAYIPBINDING）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、PGW-U**

**须知** 

本命令属于高危命令，删除该配置后，会导致媒体中继业务中断。

该命令用于删除媒体中继服务IP配置和媒体中继模板名称的绑定关系。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称       | 参数说明                                                                                                                                                                  |
|:-------------|:-----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RELAYTPLNAME | 媒体中继模板名称   | 可选必选说明：必选参数 参数含义：该参数用于表示媒体中继模板名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数使用ADD RELAYTEMPLATE命令配置生成。配置时需要确保RELAYTPLNAME已经配置（ADD RELAYTEMPLATE）。 |
| RELAYIPNAME  | 媒体中继IP地址名称 | 可选必选说明：可选参数 参数含义：该参数用于表示媒体中继服务IP配置。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数使用ADD RELAYIPINFO命令配置生成。配置时需要确保RELAYIPNAME已经配置（ADD RELAYIPINFO）。    |

#### 使用实例

删除服务IP配置为testIP，模板名为test的绑定关系：

```
RMV RELAYIPBINDING: RELAYIPNAME="testIP", RELAYTPLNAME="test";
```
