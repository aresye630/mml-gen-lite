# 恢复五元组老化时间（RTR FLOWAGETIME）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用来恢复头增强五元组、三四层五元组、TCP信令五元组和任意协议五元组的老化时间初始设置值。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                               |
|:--------|:------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RMVTYPE | 五元组老化时间删除类型 | 可选必选说明：可选参数 参数含义：该参数用于指定五元组老化时间删除类型。 数据来源：本端规划 取值范围：枚举类型。 ANY_PROTOCOL：恢复任意协议五元组老化时间的初始设置值。L34_PROTOCOL：恢复三四层五元组老化时间的初始设置值。TCP_SIGNALING：恢复TCP信令五元组老化时间的初始设置值。HEAD_ENRICH：恢复头增强五元组老化时间的初始设置值。TRAFF_CLASS：恢复流量分类五元组老化时间的初始设置值。LBO：恢复LBO业务五元组老化时间的初始设置值，此参数当前不支持。 默认值：无 配置原则：如果不设置五元组老化时间删除类型，则恢复所有类型的五元组老化时间的初始设置值。 |

#### 使用实例

- 假如运营商需要恢复五元组老化时间的初始设置值：

  ```
  RTR FLOWAGETIME:;
  ```
- 假如运营商需要恢复三四层五元组老化时间的初始设置值：

  ```
  RTR FLOWAGETIME: RMVTYPE=L34_PROTOCOL;
  ```
