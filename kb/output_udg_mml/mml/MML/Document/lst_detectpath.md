# 查询探测路径配置（LST DETECTPATH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询指定探测路径或者已配置的所有探测路径的配置信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                             |
|:---------|:-------|:-------------------------------------------------------------------------------------------------|
| PATHNAME | 路径名称   | 可选必选说明：可选参数 参数含义：该参数用于指定用于连通性探测的路径名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

查询当前已经配置的所有探测路径配置：

```
LST DETECTPATH:;
```

#### 输出结果说明

| 输出项名称          | 输出项解释                         |
|:---------------|:------------------------------|
| 路径名称           | 用于指定用于连通性探测的路径名。              |
| 本端逻辑接口名称       | 用于指定逻辑接口名称，此处只能为Phif接口。       |
| 对端IPV4地址       | 用于指定路径的对端ipv4地址。              |
| 对端IPV6地址       | 用于指定对端ipv6地址。                 |
| 发送探测报文的间隔时间    | 用于指定发送探测报文的间隔时间。              |
| 等待探测报文响应超时时间   | 用于指定发送完探测报文后，等待探测报文的超时时间。     |
| 故障恢复阈值         | 当连续收到探测报文的数量到达该阈值时，认为链路状态恢复。  |
| 故障阈值           | 当连续未收到探测报文的数量到达该阈值时，认为链路状态故障。 |
| 探测路径状态         | 用于表示路径的状态。                    |
| 是否绑定APN        | 用于表示探测路径是否绑定APN。              |
| 注册异步Ping任务     | 用于表示探测路径是否注册了异步PING任务。        |
| 上次更新时间         | 用于表示探测路径上次状态更新时间。             |
| 探测路径的重定向开关     | 用于表示指定探测路径的重定向开关              |
| 探测路径的重定向IPV4地址 | 用于表示指定探测路径的重定向IPV4地址。         |
| 探测路径的重定向IPV6地址 | 用于表示指定探测路径的重定向IPV6地址。         |

其余输出项请参见ADD DETECTPATH的参数说明。
