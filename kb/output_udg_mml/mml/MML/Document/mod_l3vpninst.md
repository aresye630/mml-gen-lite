# 修改L3VPN实例（MOD L3VPNINST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改L3VPN实例参数。

#### 注意事项

- 该命令执行后立即生效。
- 需要修改参数的L3VPN实例必须已配置。
- 不能修改VPN实例\_\_mpp\_vpn\_inner\_\_、\_\_mpp\_vpn\_inner\_server\_\_的配置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称    | 参数说明                                                                                                                                                      |
|:---------------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
| VRFNAME        | VPN实例名称 | 可选必选说明：必选参数 参数含义：该参数用于指定L3VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                                                                                |
| VRFDESCRIPTION | VPN实例描述 | 可选必选说明：可选参数 参数含义：该参数用于描述L3VPN实例。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～242。 默认值：无 配置原则： 输入单空格将删除该参数已有配置项。可以带空格的描述性语句。VRFDESCRIPTION不能在公网下配置。                      |
| ROUTERID       | 路由器ID   | 可选必选说明：可选参数 参数含义：该参数用于指定Router ID。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～15。取值为一个IPv4地址。 默认值：无 配置原则： 输入单空格将删除该参数已有配置项。ROUTERID只能在公网下配置。修改该参数后请重置相关协议以更新Router ID。 |

#### 使用实例

修改名称为“vrf1”的VPN实例描述：

```
MOD L3VPNINST: VRFNAME="vrf1", VRFDESCRIPTION="description change";
```
