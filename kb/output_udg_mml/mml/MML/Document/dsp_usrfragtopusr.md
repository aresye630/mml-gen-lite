# 显示占用用户面IP分片资源数最多的用户信息（DSP USRFRAGTOPUSR）

- 命令功能
- 注意事项
- 操作用户权限

- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于显示占用用户层IP分片资源数最多的用户信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                           |
|:----------|:---------|:-------------------------------------------------------------------------------------------------------------------------------|
| PODNAME   | POD名称    | 可选必选说明：必选参数 参数含义：该参数用于指定POD名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～127。不支持空格，区分大小写。 默认值：无 配置原则：无                                     |
| PERIODSEQ | 周期相对序号   | 可选必选说明：可选参数 参数含义：该参数用于指定统计周期的相对序号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～24。 默认值：无 配置原则： 数值越小，相对当前周期时间间隔越小。该参数不配置时显示所有周期的统计结果。            |
| ORDERITEM | 用于排序的统计项 | 可选必选说明：可选参数 参数含义：该参数指定用于排序的统计项。指定该参数后，显示的结果将从大到小排序。 数据来源：本端规划 取值范围：枚举类型。 MNODE_NUM：母节点数量。CNODE_NUM：子节点数量。 默认值：MNODE_NUM 配置原则：无 |

#### 使用实例

显示分片报文数TOP的用户信息：

```
DSP USRFRAGTOPUSR: PODNAME="isu-pod-0", PERIODSEQ=1, ORDERITEM=MNODE_NUM;
```
