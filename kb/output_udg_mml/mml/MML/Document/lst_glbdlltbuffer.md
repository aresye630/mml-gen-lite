# 查询全局下行数据长时间缓存配置（LST GLBDLLTBUFFER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

此命令用来查询全局的用户下行数据长时间缓存配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询全局下行报文长时间缓存的配置：

```
LST GLBDLLTBUFFER:;
```

```
RETCODE = 0  操作成功

下行数据长时间缓存全局配置
--------------------------
最大缓存个数  =  1
    存储方式  =  环形存储
(结果个数 = 1)

---    END
```

参见SET GLBDLLTBUFFER的参数说明。
