# 设置IP防护开关（SET IPSPOOFFUNC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

设置IP防护开关。

#### 注意事项

- 该命令执行后只对新激活用户生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | ANTISPOOFINGUL   | ANTISPOOFINGDL   |
|:-------|:-----------------|:-----------------|
| 初始值    | ENABLE           | ENABLE           |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称      | 参数说明                                                                                 |
|:---------------|:----------|:-------------------------------------------------------------------------------------|
| ANTISPOOFINGUL | 上行IP防攻击开关 | 可选必选说明：可选参数 参数含义：上行IP防攻击开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无 |
| ANTISPOOFINGDL | 下行IP防攻击开关 | 可选必选说明：可选参数 参数含义：下行IP防攻击开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无 |

#### 使用实例

假如运营商需要关闭IP防攻击检查，可以通过此命令配置：

```
SET IPSPOOFFUNC: ANTISPOOFINGUL=DISABLE, ANTISPOOFINGDL=DISABLE;
```
