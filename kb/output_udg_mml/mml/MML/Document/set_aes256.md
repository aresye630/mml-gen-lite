# 设置aes256加密算法的IV值（SET AES256）

- 命令功能
- 注意事项
- 操作用户权限

- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用来设置aes256加密算法的IV值。当重定向或者头增强配置需要进行aes256加密处理时，使用该数值作为加密算法的IV值。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 当需要配置IV值时，需要同时输入IV值确认，两次输入一致才能配置成功。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | RDRCTRANDOMIV   | HEADENRANDOMIV   |
|:-------|:----------------|:-----------------|
| 初始值    | ENABLE          | ENABLE           |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

假如运营商想要设置aes256加密算法的IV值为1234567890123456，配置如下：

```
SET AES256: RDRCTRANDOMIV=DISABLE, REDIRECTIV="1234567890123456", REDIRECTIVCONFIRM="1234567890123456", HEADENRANDOMIV=DISABLE, HEADENIV="1234567890123456", HEADENIVCONFIRM="1234567890123456";
```
