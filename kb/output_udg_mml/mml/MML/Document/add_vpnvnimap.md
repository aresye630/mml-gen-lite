# 增加VPN VNI映射（ADD VPNVNIMAP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于添加VNI与VPN的映射关系。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为4097。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                          |
|:------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VPNINSTANCE | VPN实例名 | 可选必选说明：必选参数 参数含义：该参数用于配置VPN实例。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，区分大小写。 默认值：无 配置原则：该参数使用 ADD VPNINST命令配置生成。                                                                              |
| RULESWITCH  | Rule开关 | 可选必选说明：必选参数 参数含义：该参数用于控制是否支持配置Rule。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：DISABLE 配置原则：1. 如果运营商希望仅基于用户VPN映射到VNI，设置该参数为DISABLE。 2. 如果运营商希望在同一个用户VPN中，基于不同业务规则映射到不同的VNI，设置该参数为ENABLE。 |
| RULENAME    | 规则名称   | 可选必选说明：条件必选参数 前提条件：该参数在“RULESWITCH”配置为“ENABLE”时为必选参数。 参数含义：该参数用于设置规则名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数通过ADD RULE命令配置生成，RULENAME绑定的RULE中POLICYTYPE必须为WORKER。    |
| VNI         | VNI    | 可选必选说明：必选参数 参数含义：配置VXLAN隧道头中的VNI标识的值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～16777215。 默认值：无 配置原则：无                                                                                                       |

#### 使用实例

配置VNI为4096与VPN为vpn1的映射关系：

```
ADD VPNVNIMAP: VPNINSTANCE="vpn1", RULESWITCH=DISABLE, VNI=4096;
```
