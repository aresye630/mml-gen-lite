# 增加二次授权用户（ADD USRSECAUTH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

用于给用户添加二次授权功能。

#### 注意事项

- 用户名称必须已存在。
- 该命令仅限具有Administrators角色的用户可以执行。在扩展域，仅限系统管理员可以执行。

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                           |
|:--------|:-------|:-----------------------------------------------------------------------------------------------|
| USRNAME | 用户名称   | 可选必选说明：必选参数 参数含义：用户名称，该用户在OM Portal的“安全 > 用户管理”或MML命令页面创建时的名称。 取值范围：长度不超过32个字符。 默认值：无。 配置原则：无。 |

#### 使用实例

增加二次授权用户：

```
%%ADD USRSECAUTH: USRNAME="test01";%%
RETCODE = 0  操作成功

---    END
```

#### 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，请联系华为技术支持处理。输出结果说明如表1所示。

| 101014 | 缺少必选参数用户名称 | 缺少必选参数用户名称。     | 请输入正确的用户名称。                            |
