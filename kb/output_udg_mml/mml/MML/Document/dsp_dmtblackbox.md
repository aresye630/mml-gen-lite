# 显示Diameter黑匣子信息（DSP DMTBLACKBOX）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示Diameter黑匣子信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                       |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| BOXID   | 黑匣子ID  | 可选必选说明：必选参数 参数含义：该参数用于指定黑匣子ID。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 当前黑匣子ID：链路创建和删除黑匣子，黑匣子ID：1SOCKET信息，黑匣子ID：2服务信息，黑匣子ID：3网络消息跟踪信息，黑匣子ID：4接口错误信息，黑匣子ID：5消息错误信息，黑匣子ID：6恢复信息，黑匣子ID：7邻居信息，黑匣子ID：8IPv6信息，黑匣子ID：9NETCONF信息，黑匣子ID：10流控信息，黑匣子ID：11 配置原则：无 |
| COMTYPE | 组件类型   | 可选必选说明：可选参数 参数含义：该参数用于表示组件类型。 数据来源：本端规划 取值范围：枚举类型。 RM：路由管理。CM：连接管理。 默认值：无 配置原则：无                                                                                                                                                                           |
| RUNAME  | 资源单元名称 | 可选必选说明：条件必选参数 前提条件：该参数在“COMTYPE”配置为“CM”时为必选参数。 参数含义：该参数用于表示资源单元名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～64。 默认值：无 配置原则：使用DSP RU查看RU名称。                                                                                                                            |

#### 使用实例

显示ID为1的Diameter黑匣子信息：

```
DSP DMTBLACKBOX:BOXID=1;
```

```
RETCODE = 0  操作成功。

结果如下
-------------------------
  黑匣子ID  =  1
黑匣子信息  = <0000>0828-223625 NotifyNewIncoming:LsConnId[1231] RetCode[6]
<0001>0828-223625 DeleteRMPeerTree:PeerIndex[0x127], PeerAddress[0x245]
(结果个数 = 1)
---    END
```

| 输出项名称   | 输出项解释      |
|:--------|:-----------|
| 黑匣子ID   | 用于指定黑匣子ID。 |
| 黑匣子信息   | 用于表示黑匣子信息。 |
