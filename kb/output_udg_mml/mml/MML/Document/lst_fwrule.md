# 查询转发规则（LST FWRULE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明
- 参考信息

## 命令功能

此命令用于查询已配置的转发规则。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询转发规则：

```
%%LST FWRULE:;%%
RETCODE = 0  操作成功

操作结果如下
------------
目的IP         端口   目的端口

192.168.1.1    22       2222
192.168.1.2    22       2222
(结果个数 = 2)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。输出结果说明如表1所示。

该命令执行异常，请联系华为技术支持处理。错误码说明如表2所示。

| 输出项名称   | 输出项解释        |
|:--------|:-------------|
| 目的IP    | 目的IP地址。      |
| 端口      | 目的IP地址的原端口。  |
| 目的端口    | 目的IP地址的目的端口。 |

|    错误码 | 错误码解释      | 原因分析   | 处理建议       |
|-------:|:-----------|:-------|:-----------|
| 100799 | 执行数据库命令错误。 | 数据库异常。 | 请联系华为技术支持。 |
