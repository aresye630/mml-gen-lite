# 修改RSA3072公钥参数（MOD RSA3072）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于修改一个RSA3072的相关配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                |
|:--------------|:------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RSA3072NAME   | RSA3072公钥名称 | 可选必选说明：必选参数 参数含义：该参数用于指定RSA3072公钥配置名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                                                                                                                  |
| RSAPSWDKEYN   | 公钥的N值       | 可选必选说明：条件必选参数 前提条件：该参数在“RSAPSWDTYPE”配置为“PUBLIC_KEY”时为必选参数。 参数含义：该参数用于直接配置公钥中的N值，与RSAPSWDKEYE共同组成公钥内容。配置了该参数，则不需要对公钥名称 RSA3072NAME进行文件查找、校验和解析，直接使用配置值进行加密。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～768。由字符0~9和字母A~F、a~f组成，不区分大小写，长度为偶数。 默认值：无 配置原则：配置字符长度不应少于384字节，并且配置值字符按照十六进制转换成数字后必须大于E值。 |
| RSAPSWDKEYE   | 公钥的E值       | 可选必选说明：条件必选参数 前提条件：该参数在“RSAPSWDTYPE”配置为“PUBLIC_KEY”时为必选参数。 参数含义：该参数用于直接配置公钥中的E值，与RSAPSWDKEYN共同组成公钥内容。配置了该参数，则不需要对公钥名称 RSA3072NAME进行文件查找、校验和解析，直接使用配置值进行加密。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～768。由字符0~9和字母A~F、a~f组成，不区分大小写，长度为偶数。 默认值：无 配置原则：配置值字符按照十六进制转换成数字后，不应小于2^16 + 1。            |
| HEADPREFIXSW  | 头增强前缀开关     | 可选必选说明：可选参数 参数含义：该参数用于设置头增强RSA3072加密时是否携带前缀。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能（关闭）。ENABLE：使能（开启）。 默认值：无 配置原则：无                                                                                                                                                                       |
| COUNTRYCODE   | 国家码         | 可选必选说明：条件必选参数 前提条件：该参数在“HEADPREFIXSW”配置为“ENABLE”时为必选参数。 参数含义：该参数用于设置头增强RSA3072加密携带前缀时，前缀中的国家码。 数据来源：本端规划 取值范围：字符串类型，输入必须为3位数字，000~999。 默认值：无 配置原则：输入单空格时将删除该参数已有配置。                                                                                                                 |
| NETWORKCODE   | 网络码         | 可选必选说明：条件必选参数 前提条件：该参数在“HEADPREFIXSW”配置为“ENABLE”时为必选参数。 参数含义：该参数用于设置头增强RSA3072加密携带前缀时，前缀中的网络码。 数据来源：本端规划 取值范围：字符串类型，输入长度必须为3位数字，000~999。 默认值：无 配置原则：输入单空格时将删除该参数已有配置。                                                                                                               |
| RSAPSWDTYPE   | 公钥配置方式      | 可选必选说明：必选参数 参数含义：该参数用于指定RSA公钥的配置方式。 数据来源：本端规划 取值范围：枚举类型。 PUBLIC_KEY：配置公钥。 默认值：无 配置原则：无                                                                                                                                                                                              |
| CFGDOMAINNAME | 配置域名称       | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。                                                                                                                                                                                  |

#### 使用实例

假如运营商希望把名称为“test”的RSA3072配置修改为公钥N值BCDE，E值101010，关闭头增强前缀：

```
MOD RSA3072: RSA3072NAME="test", HEADPREFIXSW=DISABLE, RSAPSWDTYPE=PUBLIC_KEY, RSAPSWDKEYN="BCDE", RSAPSWDKEYE="101010";
```
