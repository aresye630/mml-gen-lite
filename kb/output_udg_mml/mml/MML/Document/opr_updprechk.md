# 升级前检查（OPR UPDPRECHK）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于基础版本、补丁或者基础版本和补丁升级前执行风险检查。

#### 注意事项

- 该命令执行后立即生效。
- 执行该命令时，请不要执行主备倒换、复位RU和其他消耗系统资源操作，否则会影响检查结果。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                                                                                                          |
|:----------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VERSIONID       | 包版本号   | 可选必选说明：必选参数 参数含义：包版本号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                                                                                                                                                                                |
| UPDMODE         | 升级模式   | 可选必选说明：必选参数 参数含义：升级模式。 数据来源：本端规划 取值范围：枚举类型。 SU：普通升级。ISSU：无损升级。 默认值：无                                                                                                                                                                          |
| RESULTFILE      | 报告名称   | 可选必选说明：必选参数 参数含义：报告名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无                                                                                                                                                                                |
| VERSIONTYPE     | 版本类型   | 可选必选说明：条件可选参数，该参数在“UPDMODE”配置为“SU”时为可选参数。 参数含义：该参数用于指定版本类型。 数据来源：本端规划 取值范围：枚举类型。 BaseSoftware：包含网元或APP运行所需所有软件的全版本。ColdPatch：为网元或APP运行所需的部分软件，为对基础版本的补充，冷补丁不能独立运行，冷补丁升级往往会中断业务。HotPatch：为对基础版本或冷补丁的热补充，热补丁不能独立运行，热补丁升级不中断业务。 默认值：BaseSoftware |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。                                                                                                                                  |

#### 使用实例

执行升级前检查：

```
OPR UPDPRECHK:VERSIONID="V100R005C10CHK",UPDMODE=SU,RESULTFILE="UPD_PRE_REPORT",SERVICEINSTANCE="vnfc";
```
