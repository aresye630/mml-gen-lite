# 设置节点CPU使用率的过载阈值和空载阈值（SET NODEHEALCPUTHR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，如果阈值设置不合理可能导致网元倒换或者主机隔离异常，请参考网元流控阈值进行合理设置。

该命令用于设置节点CPU使用率的过载阈值和空载阈值。

## 注意事项

- 该命令执行后立即生效。

- 系统初始记录来源于适配包。
- 该命令只在虚机场景下生效。
- Node类型可通过LST NODEHEALCPUTHR查询。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                     |
|:------------|:--------|:-------------------------------------------------------------------------------------------------------------------------|
| NODETYPE    | Node类型  | 可选必选说明：必选参数  参数含义：该参数表示节点类型。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无。  配置原则：无                                        |
| NOLOADTHR   | 空载阈值（%） | 可选必选说明：必选参数  参数含义：该参数表示节点实例CPU使用率在空载时的阈值。  数据来源：本端规划  取值范围：整数类型，取值范围是0~99，单位是百分比。  默认值：无。  配置原则：  节点CPU使用率的空载阈值需小于过载阈值。  |
| OVERLOADTHR | 过载阈值（%） | 可选必选说明：必选参数  参数含义：该参数表示节点实例CPU使用率在过载时的阈值。  数据来源：本端规划  取值范围：整数类型，取值范围是1~100，单位是百分比。  默认值：无。  配置原则：  节点CPU使用率的过载阈值需大于空载阈值。 |

## 使用实例

设置Node类型为SDU的CPU使用率空载阈值为20%，过载阈值为90%。

```
%%SET NODEHEALCPUTHR: NODETYPE="SDU", NOLOADTHR=20, OVERLOADTHR=90;%%
RETCODE = 0  操作成功

---    END
```
