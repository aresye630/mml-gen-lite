# 设置TCP优化软参（SET TOSOFTPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于设置TCP优化软参。

#### 注意事项

- 该命令执行后对新数据流生效。
- 该命令最大记录数为1。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                            |
|:----------|:---------|:--------------------------------------------------------------------------------|
| SOFTPARA1 | TCP优化软参1 | 可选必选说明：可选参数 参数含义：设置TCP优化软参1。 数据来源：本端规划 取值范围：整数类型，取值范围0~4294967295。 默认值：无 配置原则：无 |
| SOFTPARA2 | TCP优化软参2 | 可选必选说明：可选参数 参数含义：设置TCP优化软参2。 数据来源：本端规划 取值范围：整数类型，取值范围0~4294967295。 默认值：无 配置原则：无 |
| SOFTPARA3 | TCP优化软参3 | 可选必选说明：可选参数 参数含义：设置TCP优化软参3。 数据来源：本端规划 取值范围：整数类型，取值范围0~4294967295。 默认值：无 配置原则：无 |

#### 使用实例

设置TCP优化软参：

```
SET TOSOFTPARA: SOFTPARA1=0, SOFTPARA2=0, SOFTPARA3=0;
```
