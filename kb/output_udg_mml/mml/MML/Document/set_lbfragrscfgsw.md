# 设置CSLB分片重组配置开关（SET LBFRAGRSCFGSW）

- 命令功能
- 注意事项
- 操作用户权限

- 使用实例

#### 命令功能

**须知** 

本命令属于高危命令，操作不当会导致业务受损，请谨慎使用并联系华为技术支持协助操作。

该命令用于设置CSLB分片重组独占资源池开关和资源比例。

#### 注意事项

- 该命令仅在分片重组优先级配置命令（SET LBFRAGRSCFG）至少配置一个DSCP值为高优先级才生效，可通过LST LBFRAGRSCFG查询是否存在高优先级报文配置。

该命令存在系统初始记录，参数的初始设置值如下表：

| EXRESSW    |   EXRESRATIO |
|:-----------|-------------:|
| SW_DISABLE |           10 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                                                                                      |
|:-----------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
| EXRESSW    | 独占资源池配置开关 | 可选必选说明：必选参数 参数含义：该参数用于指定开启或关闭CSLB分片重组独占资源池配置的开关。 数据来源：本端规划 取值范围：枚举类型 SW_ENABLE(独占资源池配置开关开启)：CSLB开启独占资源池。SW_DISABLE(独占资源池配置开关关闭)：CSLB关闭独占资源池。 默认值：无 配置原则：无 |
| EXRESRATIO | 独占资源池独占比例 | 可选必选说明：可选参数 参数含义：该参数用于配置CSLB分片重组独占资源池相对总资源池的比例占比。 数据来源：本端规划 取值范围：整数类型，取值范围为3~20，单位是百分比(%)。 默认值：无 配置原则：无                                                   |

#### 使用实例

设置独占资源池配置开关为开启，独占资源池独占比例为5，命令如下：

```
SET LBFRAGRSCFGSW: EXRESSW=SW_ENABLE, EXRESRATIO=5;
```
