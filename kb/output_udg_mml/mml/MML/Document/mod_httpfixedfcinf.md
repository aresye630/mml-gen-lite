# 修改HTTP接口类型固定速率流控信息（MOD HTTPFIXEDFCINF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于修改HTTP接口类型固定速率流控门限值信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称               | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                      |
|:---------------|:-------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OFCIDX         | 局向索引               | 可选必选说明：必选参数  参数含义：该参数用于指定局向索引。该参数来源于ADD HTTPOFC命令的“局向索引”参数，可通过LST HTTPOFC命令查询获取。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4095。  默认值：无  配置原则：  此处只能绑定"NFITEM"包含"FIXSPDFCINTF（基于接口类型固定速率流控）"的局向。                                                                                                                                                                                                                       |
| LETYPE         | 本端实体类型             | 可选必选说明：必选参数  参数含义：该参数用于指定HTTP本端实体的类型。  数据来源：全网规划 取值范围： “SERVER（服务端）”：服务端“CLIENT（客户端）”：客户端  默认值：无  配置原则：  HTTP本端实体可以作为服务端也可以作为客户端，两者需要分别配置。                                                                                                                                                                                                                                                                |
| SENDTHD        | 发送消息流控门限(条/秒)      | 可选必选说明：该参数在"LETYPE"配置为"CLIENT"时为条件必选参数。  参数含义：该参数用于指定发送消息流控门限。该门限按整机粒度设置。  数据来源：全网规划  取值范围：整数类型，取值范围是1~4294967295。  默认值：无  配置原则：  门限值由对端网元的消息处理能力决定。设置过低会导致消息被丢弃，设置过高起不到保护对端网元不过载的作用。                                                                                                                                                                                                                     |
| RECVTHD        | 接收消息流控门限(条/秒)      | 可选必选说明：该参数在"LETYPE"配置为"SERVER"时为条件必选参数。  参数含义：该参数用于指定接收消息流控门限。该门限按整机粒度设置。  数据来源：全网规划  取值范围：整数类型，取值范围是1~4294967295。  默认值：无  配置原则：  门限值由本端网元的消息处理能力决定。设置过低会导致消息被丢弃，设置过高起不到保护本端网元不过载的作用。                                                                                                                                                                                                                     |
| STATUSCODE     | 状态码                | 可选必选说明：该参数在"LETYPE"配置为"SERVER"时为条件可选参数。  参数含义：该参数用于指定接收消息速率超过流控门限时，给对端网元响应的HTTP消息中的Status Code。该参数可以和“是否携带Retry-After消息头”参数配合使用，告知对端本端的过载情况的同时携带Retry-After来指示对端多久后再发送请求。  数据来源：全网规划 取值范围： “TooManyRequests（Too Many Requests）”：当NF服务生产者检测到给定NF服务消费者发送过多的流量时，可以发送该状态代码告知NF服务消费者生产者端即将过载。“ServiceUnavailable（Service Unavailable）”：当NF服务生产者检测到给定NF服务消费者发送过多的流量时，可以发送该状态代码告知NF服务消费者生产者端已经过载。  默认值：无  配置原则：无 |
| RETRYAFTERFLAG | 是否携带Retry-After消息头 | 可选必选说明：该参数在"LETYPE"配置为"SERVER"时为条件可选参数。  参数含义：该参数用于指定接收消息速率超过流控门限时，给对端网元响应的HTTP消息中是否携带Retry-After消息头。该参数可以和“状态码”参数配合使用，告知对端本端的过载情况的同时携带Retry-After来指示对端多久后再发送请求。  数据来源：全网规划 取值范围： “YES（YES）”：携带Retry-After消息头“NO（NO）”：不携带Retry-After消息头  默认值：无  配置原则：  携带Retry-After消息头可能会使对端网元不发请求消息给本端网元，导致业务受损。需谨慎使用该参数。如需设置Retry-After消息头，请联系华为技术支持。                                                                  |
| TIMER          | Retry-After时长(秒)   | 可选必选说明：该参数在"RETRYAFTERFLAG"配置为"YES"时为条件可选参数。  参数含义：该参数用于指定Retry-After的时长。  数据来源：全网规划  取值范围：整数类型，取值范围是0~3600。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                               |

## 使用实例

- 修改局向索引为1，本端实体类型为客户端的HTTP接口类型固定速率流控门限值，将发送消息流控门限从1000改为100：

  ```
  MOD HTTPFIXEDFCINF: OFCIDX=1, LETYPE=CLIENT, SENDTHD=100;
  ```
- 修改局向索引为2，本端实体类型为服务端的HTTP接口类型固定速率流控门限值，将接收消息流控门限从1000改为100，状态码修改为ServiceUnavailable，是否携带Retry-After消息头修改为YES，Retry-After时长修改为100：

  ```
  MOD HTTPFIXEDFCINF: OFCIDX=2, LETYPE=SERVER, RECVTHD=100, STATUSCODE=ServiceUnavailable, RETRYAFTERFLAG=YES, TIMER=100;
  ```
