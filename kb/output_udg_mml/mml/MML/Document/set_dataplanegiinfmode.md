# 设置用户面下行模式（SET DATAPLANEGIINFMODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，配置此命令时需要检查当前的POD Type是否是ISU/APU POD， 如果不是，不能开启入不转板功能。

设置数据面接口模式，包含Gi、N6、SGi等接口的模式。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 修改此命令前需要删除所有用户。
- 外部地址分配的后路由用户不支持入不转板。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | MODE   | ROUTEENHANCEDSW   |
|:-------|:-------|:------------------|
| 初始值    | Group  | DISABLE           |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称     | 参数说明                                                                                                                                                                                                |
|:----------------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MODE            | 模式       | 可选必选说明：必选参数 参数含义：该参数用于指定用户面下行模式。 数据来源：全网规划 取值范围：枚举类型。 Group：组级用户面IP模式。RU：RU级用户面IP模式。 默认值：无 配置原则：无                                                                                                   |
| ROUTEENHANCEDSW | 路由增强功能开关 | 可选必选说明：条件可选参数 前提条件：该参数在“MODE”配置为“RU”时为可选参数。 参数含义：该参数用于指定用户面IP下行路由发布时是否开启增强功能。 数据来源：全网规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：参数取值ENABLE：开启用户面IP下行路由发布的增强功能。参数取值DISABLE：不开启用户面IP下行路由发布的增强功能。 |

#### 使用实例

设置数据面接口模式为RU级别，可以使用该命令设置：

```
SET DATAPLANEGIINFMODE: MODE=RU;
```
