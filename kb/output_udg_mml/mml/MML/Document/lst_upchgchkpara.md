# 显示计费检查参数（LST UPCHGCHKPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

用于查询用户面计费检查相关参数。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

使用LST UPCHGCHKPARA命令查询用户面计费检查相关参数：

```
LST UPCHGCHKPARA:;
```

```
RETCODE = 0 操作成功

计费检查参数
----------------------
用户资源告警开关 = 否
计费配置核查告警开关 = 否
计费配置核查告警上报阈值 = 500
计费配置核查告警恢复阈值 = 300
(结果数 = 1)
```

#### 输出结果说明

参见SET UPCHGCHKPARA的参数说明。
