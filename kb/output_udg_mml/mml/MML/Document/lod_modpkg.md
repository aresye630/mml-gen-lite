# 加载模型包（LOD MODPKG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

对于注册了推理场景的网元服务，执行此命令完成对应场景的模型包、模型文件的加载和更新。

**须知** 

此命令为高危命令，加载模型包期间对应的业务服务推理能力不可用，请谨慎操作。

#### 注意事项

- 如果需要加载手动、预置来源的模型文件，必须输入所属的模型包名称；如果需要加载自动来源下的模型文件，模型包名称为空，来源为空或者选择“自动”。
- 如果服务名为空，则默认对该网元下所有注册该场景的服务下发加载模型包的任务。
- 同一网元下同一个服务不支持并发执行加载模型包的操作。

#### 参数说明

| 参数标识             | 参数名称   | 参数说明                                                                                                                                                            |
|:-----------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID             | 网元ID   | 可选必选说明：必选参数。 参数含义：需要加载模型包的网元ID。 取值范围：整数类型，取值范围为0~65535。 默认值：无。 配置原则：网元ID可通过LST ME命令查询获得。                                                                        |
| MODELPACKAGENAME | 模型包名称  | 可选必选说明：可选参数。 参数含义：需要加载的模型包名称。 取值范围：字符串类型，长度1~128。 默认值：无。 配置原则：当选择加载自动来源下的模型文件时，该项为空；当选择加载其他来源下的模型文件，该项只能包括大小写字母、数字、中划线-、下划线_、英文句号.，必须包含下划线_，以.zip后缀结尾。长度最大为128。 |
| MODELFILENAME    | 模型文件名称 | 可选必选说明：必选参数。 参数含义：需要加载的模型文件名称。 取值范围：字符串类型，长度1~128。 默认值：无。 配置原则：只能包括大小写字母、数字、中划线-、下划线_、英文句号.。长度最大为128。                                                           |
| SOURCE           | 来源     | 可选必选说明：可选参数。 参数含义：需要加载的模型来源。 取值范围： “MANUAL（手动）”：模型包来源为手工上传。“PRESET（预置）”：模型包来源为预置上传。“AUTO（自动）”：模型包来源为模型训练生成。 默认值：无。 配置原则：无。                                      |
| SERVICENAME      | 服务名    | 可选必选说明：可选参数。 参数含义：需要加载模型的服务列表。 取值范围：字符串类型，长度1~128。 默认值：默认为空。 配置原则：多个服务名以管道符|分割。                                                                                 |

#### 使用实例

#### 输出结果说明

该命令执行异常，会返回对应的错误码。常见错误码如表3所示。

| 网元ID    | 用于返回网元ID。         |
| 场景类型    | 用于返回加载的模型文件归属的场景。 |
| 模型包名称   | 用于返回加载的模型包名称。     |
