# 设置CSLB隧道探测参数（SET LBTNTSTPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于设置CSLB隧道探测参数。

#### 注意事项

- 系统初次上电运行时，会执行系统初始设置值。
- 该命令执行后立即生效。
- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称         | 参数说明                                                                                                    |
|:---------------|:-------------|:--------------------------------------------------------------------------------------------------------|
| DELAYDETPERIOD | 隧道时延探测周期（秒）  | 可选必选说明：可选参数 参数含义：该参数表示隧道时延探测周期，即隧道时延探测报文的发送时间间隔。 数据来源：本端规划 取值范围：1~100 默认值：无 系统初始设置值：10 配置原则：无特殊情况不需要修改。 |
| DROPSTATPERIOD | 隧道丢包率统计周期（秒） | 可选必选说明：可选参数 参数含义：该参数表示隧道丢包率统计周期。 数据来源：本端规划 取值范围：1~60 默认值：无 系统初始设置值：5 配置原则：无特殊情况不需要修改。                   |

#### 使用实例

设置隧道时延探测周期为20秒，隧道丢包率统计周期为10秒:

`SET LBTNTSTPARA: DELAYDETPERIOD=20, DROPSTATPERIOD=10;`
