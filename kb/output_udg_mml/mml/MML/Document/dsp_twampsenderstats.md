# 显示TWAMP发送端详细信息（DSP TWAMPSENDERSTATS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示TWAMP发送端详细信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                               |
|:---------|:-------|:-----------------------------------------------------------------------------------|
| CLIENTID | 客户端ID  | 可选必选说明：可选参数  参数含义：该参数用于配置客户端ID。  数据来源：全网规划  取值范围：整数类型，取值范围是1~12000。  默认值：无  配置原则：无 |

## 使用实例

查询客户端ID为1的发送端实例：

```
%%DSP TWAMPSENDERSTATS: CLIENTID=1;%%
RETCODE = 0  操作成功
 
结果如下
--------
    客户端ID  =  1
      源地址  =  10.0.0.0
    目的地址  =  192.168.0.0
      丢包率  =  0
    双向时延  =  1
发送方向抖动  =  0
接收方向抖动  =  0
(结果个数 = 1)

---    END
```

| 目的地址    | 该参数用于指定目的地址。   |
| 丢包率     | 该参数用于指定丢包率。    |
| 双向时延    | 该参数用于指定双向时延。   |
| 发送方向抖动  | 该参数用于指定发送方向抖动。 |
| 接收方向抖动  | 该参数用于指定接收方向抖动。 |
