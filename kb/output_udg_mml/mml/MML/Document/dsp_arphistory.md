# 查询ARP表项变更历史（DSP ARPHISTORY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查看ARP表项变更历史。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查看ARP表项变更历史：

```
DSP ARPHISTORY:;
```

```
        RETCODE = 0  操作成功

        结果如下
        -------------------------
        操作类型    变更类型    IPv4地址    接口名称        MAC地址         VLAN ID值    内层VLAN ID值    变更时间

        增加        报文        10.10.7.14  Ethernet64/0/5  00E0-FC12-3456  0            0                2017-06-06 11:01:56
        修改        报文        10.10.7.1   Ethernet64/0/5  00E0-FC12-3457  0            0                2017-06-06 11:03:05
        删除        报文        10.10.7.1   Ethernet64/0/5  00E0-FC12-3458  0            0                2017-06-06 11:03:50
        (结果个数 = 3)
        ---    END
```

|:-----------|:-------------------|
| 操作类型       | 该参数用于显示操作类型。       |
| 变更类型       | 该参数用于显示变更类型。       |
| IPv4地址     | 该参数用于显示IPv4地址。     |
| 接口名称       | 该参数用于显示接口名称。       |
| MAC地址      | 该参数用于显示MAC地址。      |
| VLAN ID值   | 该参数用于显示VLAN ID值。   |
| 内层VLAN ID值 | 该参数用于显示内层VLAN ID值。 |
| 变更时间       | 该参数用于显示变更时间。       |
