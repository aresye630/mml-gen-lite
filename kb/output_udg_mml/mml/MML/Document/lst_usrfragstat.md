# 查询用户面IP分片统计参数（LST USRFRAGSTAT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于查询用户面IP分片统计参数。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询当前用户面IP分片统计参数：

```
LST USRFRAGSTAT:;
```

```
RETCODE = 0  操作成功

结果如下
--------
基于服务器IP地址统计的开关  =  使能
        触发统计的条件类型  =  用户IP分片报文数超阈值
      用户IP分片资源数阈值  =  200
	  用户IP分片报文数阈值  =  1000
      统计周期时长（分钟）  =  60
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见SET USRFRAGSTAT的参数说明。
