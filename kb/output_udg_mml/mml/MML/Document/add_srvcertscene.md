# 增加配置证书场景（ADD SRVCERTSCENE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、PGW-U**

该命令用于增加配置证书场景。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为512。
- 当用户不输入CNDESC、 ENDESC时，会将SCENE的值赋给未输入的CNDESC、ENDESC。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称       | 参数说明                                                                                                                              |
|:--------------|:-----------|:----------------------------------------------------------------------------------------------------------------------------------|
| SCENE         | 证书使用场景名称   | 可选必选说明：必选参数 参数含义：该参数用于指定证书使用场景的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围是1~127。区分大小写，不允许仅大小写不同的重复记录。不支持中文字符，只能由“_”、数字和大小写字母组成。 默认值：无 配置原则：无 |
| TYPE          | 场景类型       | 可选必选说明：必选参数 参数含义：该参数用于指示证书使用场景类型。 数据来源：本端规划 取值范围：枚举类型。 SCENE_CA：CA证书场景类型。SCENE_NE：设备证书场景类型。 默认值：无 配置原则：无                          |
| CNDESC        | 证书使用场景中文描述 | 可选必选说明：可选参数 参数含义：证书使用场景中文描述。 数据来源：本端规划 取值范围：字符串类型，输入长度范围是1~255。不区分大小写。 默认值：无 配置原则：无                                               |
| ENDESC        | 证书使用场景英文描述 | 可选必选说明：可选参数 参数含义：证书使用场景英文描述。 数据来源：本端规划 取值范围：字符串类型，输入长度范围是1~255。不区分大小写。 默认值：无 配置原则：无                                               |
| CFGDOMAINNAME | 配置域名称      | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。                                |

#### 使用实例

新增配置证书场景：

```
ADD SRVCERTSCENE: SCENE="test01", TYPE=SCENE_CA;
```
