# 显示进程内存分区信息（DSP PROCMEMPT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示进程内的分区内存使用信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                        |
|:----------------|:-------|:----------------------------------------------------------------------------------------------------------------------------|
| RUNAME          | RU名称   | 可选必选说明：可选参数 参数含义：该参数用于指定RU名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：当不输入时显示所有资源单元信息。                     |
| PROCID          | 进程ID   | 可选必选说明：可选参数 参数含义：网元内一个进程的进程ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                                 |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识，但不能填写0，0表示VNFP。 |

#### 使用实例

查询进程内分区内存的使用情况：

```
DSP PROCMEMPT:RUNAME="VNODE_CSLB_VNFC_OMU_0001",PROCID=1001,SERVICEINSTANCE="vnfc";
```

#### 输出结果说明

| 输出项名称             | 输出项解释                            |
|:------------------|:---------------------------------|
| 进程ID              | 用于说明进程的编号。                       |
| RU名称              | 表示资源单元的名称。                       |
| 内存分区名             | 用于说明进程中内存分区的名称。                  |
| 分区内存总大小（Kbytes）   | 用于说明进程内分区内存总大小（单位：Kbytes）。       |
| 分区内存使用大小（Kbytes）  | 用于说明此进程内已经使用了的内存分区大小（单位：Kbytes）。 |
| 分区内存使用最大值（Kbytes） | 用于说明此进程内分区内存使用的最大峰值（单位：Kbytes）。  |
| 分区内存使用率（%）        | 用于说明此进程内分区内存使用的百分比（单位：%）。        |
