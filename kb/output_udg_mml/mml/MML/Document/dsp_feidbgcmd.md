# FEI调试查询命令（DSP FEIDBGCMD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于在VNRS\_VNFC上查询FEI调试信息。

#### 注意事项

- 该命令用于收集定位信息，需要谨慎执行，请在华为工程师指导下执行。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                    |
|:-------|:--------|:----------------------------------------------------------------------------------------|
| RUNAME | RU名称    | 可选必选说明：必选参数。 参数含义：指定RU的名称。 数据来源：本端规划 取值范围：字符串类型，长度范围1～63。 默认值：无。 配置原则：参考DSP RU命令查询RU编号。 |
| CMDMSG | 调试命令字符串 | 可选必选说明：必选参数。 参数含义：调试命令字符串。 数据来源：本端规划 取值范围：字符串类型，长度范围1～255。 默认值：无。 配置原则：参考使用指南。          |

#### 使用实例

查询“VNRS\_IP\_RU\_C24\_0064”的不同部署模式下的启动状态信息：

```
%%DSP FEIDBGCMD: RUNAME="VNRS_IP_RU_C24_0064", CMDMSG="fei init";%%
RETCODE = 0  操作成功

结果如下:
---------
调试命令执行结果返回信息  =  
 DeployMode=0
 [FEI]    
 cpStateMachine=0
 pipeState=0 
 dpReadyFlag=0
 faultSmoothStartFlag=0
 faultSmoothEndFlag=1

 [SFE]
 dpStateMachine=0
 pipeState=0
 cpReadyFlag=0
 cpInitCfgFlag=0
 fwdAllowedFlag=0
 bfdSendAllowedFlag=0
 fwdResInitFlag=0

(结果个数 = 1)
```
