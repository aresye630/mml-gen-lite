# 查询PFCP上报业务运行信息功能的管理参数（LST PFCPSRVRPT）

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用来查询PFCP上报业务运行信息功能的管理参数。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询PFCP上报业务运行信息功能的管理参数：

```
LST PFCPSRVRPT:;
```

