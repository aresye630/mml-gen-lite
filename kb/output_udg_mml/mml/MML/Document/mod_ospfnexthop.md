# 修改OSPF等价路由优先级配置（MOD OSPFNEXTHOP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改等价路由的优先级。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                               |
|:-------------|:--------|:-------------------------------------------------------------------------------------------------------------------|
| PROCID       | 进程号     | 可选必选说明：必选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 配置原则：OSPF进程必须已经存在。请使用LST OSPF命令查看可用的OSPF进程。 |
| TOPOID       | 拓扑标识    | 可选必选说明：必选参数 参数含义：拓扑标识。 数据来源：全网规划 取值范围：整数类型，取值范围为0。 默认值：无 配置原则：目前只支持默认拓扑0。                                          |
| NBRIPADDRESS | 下一跳IP地址 | 可选必选说明：必选参数 参数含义：下一跳IP地址。 数据来源：本端规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无                                                   |
| WEIGHT       | 下一跳权重   | 可选必选说明：必选参数 参数含义：下一跳权重。 数据来源：本端规划 取值范围：整数类型，取值范围为1～254。 默认值：无 配置原则：该值越小，路由优先级越高。                                   |

#### 使用实例

修改OSPF进程1中等价路由的权重值为100：

```
MOD OSPFNEXTHOP:PROCID=1,TOPOID=0,NBRIPADDRESS="10.1.1.1",WEIGHT=100;
```
