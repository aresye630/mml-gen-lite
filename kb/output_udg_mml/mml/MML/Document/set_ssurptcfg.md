# 设置SSU基础报表功能开关（SET SSURPTCFG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、PGW-U**

此命令用于设置SSU基础报表功能开关。

#### 注意事项

- 该命令配置后对新业务数据流和已经建立的业务数据流均生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | BASICRPTSW   |
|:-------|:-------------|
| 初始值    | DISABLE      |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                            |
|:-----------|:-------|:----------------------------------------------------------------------------------------------------------------|
| BASICRPTSW | 基础报表开关 | 可选必选说明：可选参数 参数含义：该参数用于配置SSU基础报表功能开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：SSU不使能基础报表功能。ENABLE：SSU使能基础报表功能。 默认值：无 配置原则：无 |

#### 使用实例

使能SSU基础报表功能开关：

```
SET SSURPTCFG:BASICRPTSW=ENABLE;
```
