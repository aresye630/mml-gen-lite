# 查询SDRC中的TOPIC信息（DSP SDRTOPIC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询SDRC中指定topicId的TOPIC策略信息。若命令不接任何参数，则该命令列出SDRC中所有TOPIC的信息，否则显示特定的TOPIC信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                         |
|:--------|:---------|:---------------------------------------------------------------------------------------------|
| TOPICID | TOPIC ID | 可选必选说明：可选参数  参数含义：该参数用于表示topic策略的id。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无 |

## 使用实例

使用如下命令查询SDRC中缓存的topic策略信息：

```
%%DSP SDRTOPIC: TOPICID=4128;%%
RETCODE = 0  操作成功

结果如下
--------
    TOPIC ID  =  4128
    驱动类型  =  0
使用外部通信  =  否
      优先级  =  0
安全开关  =  false
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称    | 输出项解释                                               |
|:---------|:----------------------------------------------------|
| TOPIC ID | 该参数用于表示topic策略的id。                                  |
| 驱动类型     | 该参数用于标识当前策略通信时使用的驱动类型。                              |
| 使用外部通信   | 该参数用于标识此topic是否用于外部通信。 取值说明： TRUE(TRUE)FALSE(FALSE) |
| 优先级      | 该参数用于标识消息优先级。范围:[0,3]，0表示最高优先级，优先级递减。               |
| 安全开关     | 该参数用于标识该策略是否具有安全能力，加密开关是否打开。                        |
