# 显示NP Fabric统计数据（DSP NPFABRICOAMSTAT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示NP Fabric统计数据。

#### 注意事项

- 该命令仅适用于NP卡加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                  |
|:--------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RESNAME | 源资源名称  | 可选必选说明：必选参数。 参数含义：该参数用于指定源资源名称。 数据来源：本端规划。 取值范围：字符串类型，输入长度范围为1～128。不支持空格，区分大小写。 配置原则：FRAME-x-SLOT-y，区分大小写。其中x为框号，y为槽位号，可通过DSP NPNODE查询。例：FRAME-0-SLOT-8表示0框8板。 默认值：无。 |

#### 使用实例

显示资源名称为FRAME-0-SLOT-8到所有远端资源的NP Fabric统计数据：

```
DSP NPFABRICOAMSTAT:RESNAME="FRAME-0-SLOT-8";
```

