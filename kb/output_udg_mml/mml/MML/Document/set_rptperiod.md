# 设置APN N6故障状态上报周期（SET RPTPERIOD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于设置APN N6故障状态上报周期。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 周期上报时间参数配置需要小于SMF故障apn的老化时长（通过LST PFCPPARA命令查询）。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   |   RPTPERIOD |
|:-------|------------:|
| 初始值    |           4 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称             | 参数说明                                                                                                             |
|:----------|:-----------------|:-----------------------------------------------------------------------------------------------------------------|
| RPTPERIOD | APN N6故障状态周期上报时长 | 可选必选说明：必选参数 参数含义：设置APN状态周期上报时长。 数据来源：本端规划 取值范围：整数类型，取值范围0~72，单位是小时。需要关闭周期上报功能时，设置为0。 默认值：无 配置原则：必须小于SMF上配置的老化时间。 |

#### 使用实例

设置APN N6故障状态上报周期为4小时,做如下配置：

```
SET RPTPERIOD: RPTPERIOD=4;
```
