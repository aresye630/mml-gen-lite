# 设置全局协议报文统计配置（SET HOSTSTCGLB）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于设置全局协议报文统计配置。

该命令的优先级低于ADD HOSTSTCIF命令，如果接口上配置了接口协议报文统计配置，则对应接口的协议报文统计功能不受该命令的影响。

#### 注意事项

- 该命令执行后立即生效。
- 该配置会影响设备性能。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| STCENABLE   |
|:------------|
| DISABLE     |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称       | 参数说明                                                                                                  |
|:----------|:-----------|:------------------------------------------------------------------------------------------------------|
| STCENABLE | 协议报文统计功能状态 | 可选必选说明：必选参数 参数含义：该参数用于表示协议报文统计功能状态。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：去使能协议报文统计功能。ENABLE：使能协议报文统计功能。 默认值：无 |

#### 使用实例

- 使能全局协议报文统计：

  ```
  SET HOSTSTCGLB: STCENABLE=ENABLE;
  ```
- 去使能全局协议报文统计：

  ```
  SET HOSTSTCGLB: STCENABLE=DISABLE;
  ```
