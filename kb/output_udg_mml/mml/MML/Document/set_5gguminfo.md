# 设置灰度升级所处于的阶段（SET 5GGUMINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

灰度升级流程中，执行此命令，用于设置灰度升级所处的阶段。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| STAGE      |
|:-----------|
| PreUpgrade |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                     |
|:-------|:-------|:-----------------------------------------------------------------------------------------|
| STAGE  | 阶段     | 可选必选说明：必选参数  参数含义：该参数用于标识灰度升级所处的阶段。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无。  配置原则：无 |

## 使用实例

设置灰度升级阶段为InUpgrade：

```
%%SET 5GGUMINFO: STAGE="InUpgrade";%%
RETCODE = 0  操作成功

---    END
```
