# 显示NETCONFC与其他组件的消息交互信息（DSP NCCDIAGLOG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示NETCONFC与其他组件的消息交互信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                                                                                     |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DATATYPE        | 诊断数据类型 | 可选必选说明：必选参数。 参数含义：该参数用于表示诊断信息数据的类型。 数据来源：本端规划。 取值范围：枚举类型。 FSM：状态机信息。NCCOPERATION：NETCONFC操作信息。MESSAGE：消息交互信息。FAILOPERATION：操作失败信息。CONNECT：建连信息。RPC：报文信息。DATA：静态数据信息。MODELRSHHIS：模型刷新历史。 默认值：无                            |
| PEERID          | 远端ID   | 可选必选说明：条件必选参数或条件可选参数，该参数在“DATATYPE”配置为“MODELRSHHIS”时为必选参数。该参数在“DATATYPE”配置为“MESSAGE”、“FAILOPERATION”、“CONNECT”、“RPC”、“FSM” 或“ DATA”时为可选参数。 参数含义：该参数用于表示远端设备ID。 数据来源：本端规划。 取值范围：整数类型，取值范围为0～4294967295。 默认值：无             |
| PID             | 组件PID  | 可选必选说明：条件可选参数，该参数在“DATATYPE”配置为“MESSAGE”、“FAILOPERATION”、“CONNECT”、“RPC”、“FSM ”或“DATA”时为可选参数。 参数含义：该参数用于表示NETCONFC的组件PID。 数据来源：本端规划。 取值范围：十六进制整数类型，取值范围为0～0xFFFFFFFF。 默认值：无                                              |
| RPCTYPE         | 报文类型   | 可选必选说明：条件必选参数，该参数在“DATATYPE”配置为“RPC”时为必选参数。 参数含义：该参数用于表示报文信息类型。 数据来源：本端规划。 取值范围：枚举类型。 HISTORY：报文历史信息。ERROR：报文错误信息。 默认值：无                                                                                                 |
| STATCDATATYPE   | 静态数据类型 | 可选必选说明：条件必选参数，该参数在“DATATYPE”配置为“DATA”时为必选参数。 参数含义：该参数用于表示静态数据类型。 数据来源：本端规划。 取值范围：枚举类型。 LOCAL：本地数据。DRVLOAD：驱动加载记录。 默认值：无                                                                                                  |
| FAILTYPE        | 失败信息类型 | 可选必选说明：条件可选参数，该参数在“DATATYPE”配置为“FAILOPERATION”时为可选参数。 参数含义：该参数用于表示失败信息类型。 数据来源：本端规划。 取值范围：枚举类型。XSS：Xss Lib失败信息。 默认值：无                                                                                                    |
| FSMTYPE         | 状态机类型  | 可选必选说明：条件必选参数，该参数在“DATATYPE”配置为“FSM”时为必选参数。 参数含义：该参数用于表示状态机信息类型。 数据来源：本端规划。 取值范围：枚举类型。 SESSION：会话状态机信息。CHANNEL：通道状态机信息。SYNCGETPEER：对账获取远端状态机。SYNCGETLOCAL：对账获取本地状态机。SYNCEDIT：对账编辑远端状态机。SYNCCONFIG：对账状态机。RPC：报文状态机。 默认值：无 |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数。 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划。 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。                                                                                                           |

显示NETCONFC与其他组件的消息交互信息：

```
DSP NCCDIAGLOG:DATATYPE=NCCOPERATION,SERVICEINSTANCE="vnfc";
```

#### 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                                                                                                                                                                                                                                                                     |
|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 输出字符串   | 该参数用于表示诊断信息数据输出字符串。 Time：操作的时间点。Event：建连的事件。FromAppName：Schema操作的业务名称。ChannelID：NETCONFC分配的通道ID。OriChannelID：业务携带的通道ID。SvrSessionID：NETCONF会话ID。Terminal：目的地址。MsgID：RPC报文的message id。Dir：报文的传送方向。取值范围：枚举类型。NCC->NCS：从NETCONFC发送至NETCONFS。NCS->NCC：从NETCONFS发送至NETCONFC。 Method：操作类型。取值范围：枚举类型。POST：创建。DELETE：删除。PUT：修改。GET：查询。ACTION：维护。 Operation：Schema操作的URI和BODY简要信息。 |
