# 查询HAF服务内部功能的参数（LST HAFFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

当前版本配置此命令不生效。

该命令用于查询HAF服务内部功能的参数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询域故障功能和多连接增强功能开关。

```
LST HAFFUNC:;
```

## 输出结果说明

| 输出项名称   | 输出项解释               |
|:--------|:--------------------|
| 域故障开关   | 该参数用于指定域故障功能的开关。    |
| 多连接增强开关 | 该参数用于指定是否开启多连接增强功能。 |
