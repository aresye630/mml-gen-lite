# 启动事务模式（STR MMLTRAN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

执行该命令后，会启动事务模式，在该模式下，下发给管道OS的配置类命令只有在执行提交配置命令**CMT MMLTRAN**后才会真正生效。

## 注意事项

- 如果已经开始事务模式，再次下发该命令**STR MMLTRAN**，按照操作成功处理。
- 如果在事务模式下，已经下发过配置命令，再次下发该命令**STR MMLTRAN**对已经下发的配置命令无影响。
- 如果通过“应用管理 > MML”下发该命令**STR MMLTRAN**，后续执行事务管理模块的其他命令时，只有通过“应用管理 > MML”下发时才生效；如果通过“应用管理 > MML批处理”下发该命令**STR MMLTRAN**，后续执行事务管理模块的其他命令时，只有通过“应用管理 > MML批处理”下发时才生效。

## 参数说明

无。

## 使用实例

```
%%STR MMLTRAN:;%% 
RETCODE = 0  操作成功  

---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，请联系华为技术支持处理。
