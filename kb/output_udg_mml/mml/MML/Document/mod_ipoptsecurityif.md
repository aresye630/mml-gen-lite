# 修改接口IP选项安全配置（MOD IPOPTSECURITYIF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改接口IP选项安全配置。接口名称可以通过LST IPOPTSECURITYIF命令获取。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                                                                 |
|:-----------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OPTIONTYPE | IP选项类型   | 可选必选说明：必选参数 参数含义：该参数表示IP选项的类型。 数据来源：本端规划 取值范围：枚举类型。 routeAlert：系统处理带路由告警选项IP报文的功能。routeRecord：系统处理带记录路由选项IP报文的功能。sourceRoute：系统处理带源路由选项IP报文的功能。该选项控制报文传输路径。timeStamp：系统处理带记录时间戳选项IP报文的功能。该选项用于计算报文传输/处理时消耗的时间。 默认值：无 |
| SWITCHOP   | IP选项配置开关 | 可选必选说明：必选参数 参数含义：该参数表示使能或去使能对应选项报文的处理能力。 数据来源：本端规划 取值范围：枚举类型。 disable：去使能。enable：使能。 默认值：无                                                                                                                           |
| IFNAME     | 接口名称     | 可选必选说明：必选参数 参数含义：该参数用于表示接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。接口名称由接口类型+接口编号组成。 默认值：无                                                                                                                               |

#### 使用实例

修改记录路由选项routeRecord的配置实例：

```
MOD IPOPTSECURITYIF: OPTIONTYPE=routeRecord, SWITCHOP=enable, IFNAME="Ethernet66/0/4";
```
