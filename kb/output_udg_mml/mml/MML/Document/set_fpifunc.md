# 设置FPI差异化控制功能（SET FPIFUNC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、PGW-U**

该命令用于设置FPI差异化控制功能。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | FPISWITCH   | FPITRANSMETHOD   |   FPIPOLICYORIGIN |
|:-------|:------------|:-----------------|------------------:|
| 初始值    | ENABLE      | DSCP             |               nan |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称    | 参数说明                                                                                                                                                                             |
|:----------------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FPISWITCH       | FPI使能开关 | 可选必选说明：必选参数 参数含义：该参数用于设置FPI差异化控制功能开关。 数据来源：本端规划 取值范围： DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无                                                                                        |
| FPITRANSMETHOD  | FPI传递类型 | 可选必选说明：条件必选参数 前提条件：该参数在“FPISWITCH”配置为“ENABLE”时为必选参数。 参数含义：该参数用于设置FPI传递类型。 数据来源：本端规划 取值范围： GTPU：配置FPI信息以GTP-U方式向RAN侧传递。DSCP：配置FPI信息以DSCP方式向RAN侧传递。 默认值：无 配置原则：无                   |
| FPIPOLICYORIGIN | 策略来源    | 可选必选说明：条件必选参数 前提条件：该参数在“FPITRANSMETHOD”配置为“GTPU”时为必选参数。 参数含义：该参数用于设置FPI策略来源。 数据来源：本端规划 取值范围： INTERNAL：表示FPI值来源于网关内部策略。EXTERNAL：表示FPI值来源于下行用户报文的IP DSCP值，是由外部策略网元设置。 默认值：无 配置原则：无 |

#### 使用实例

设置FPI差异化控制功能为使能，FPI传递方式为DSCP方式：

```
SET FPIFUNC: FPISWITCH=ENABLE, FPITRANSMETHOD=DSCP;
```
