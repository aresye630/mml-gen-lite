# 查询BGP建立的BFD会话信息（DSP BGPBFDSESSION）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询BGP建立的BFD会话信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                                  |
|:--------------|:---------|:------------------------------------------------------------------------------------------------------|
| VRFNAME       | VPN实例名称  | 可选必选说明：可选参数 参数含义：VPN名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：_public_ 配置原则：使用LST L3VPNINST命令查看可用VPN。 |
| AFTYPE        | BGP地址族类型 | 可选必选说明：可选参数 参数含义：BGP地址族类型。 数据来源：本端规划 取值范围：枚举类型。 ipv4uni：IPv4地址族。ipv6uni：IPv6地址族。 默认值：ipv4uni          |
| REMOTEADDRESS | 对端地址     | 可选必选说明：可选参数 参数含义：对端地址。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～39。取值为一个IP地址。 默认值：无                              |
| SOURCEIFNAME  | 多源接口名称   | 可选必选说明：可选参数 参数含义：多源对等体的接口名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：不区分大小写。                      |

#### 使用实例

查询BGP建立的BFD会话信息：

```
DSP BGPBFDSESSION:;
```

```
RETCODE = 0  操作成功。

结果如下
------------------------
BFD会话信息  =
----------------------------------------
Local_Address    :  10.1.1.1
Peer_Address     :  10.1.1.2
Interface        :  unknown
Tx-interval(ms)  :  0
Rx-interval(ms)  :  0
Multiplier       :  0
Session-State    :  BFD global disable
----------------------------------------

(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释              |
|:--------|:-------------------|
| BFD会话信息 | 用于指定BGP建立的BFD会话信息。 |
