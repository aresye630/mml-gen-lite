# 查询TCP流老化功能配置（LST TOFLOWAGINGCFG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询TCP流老化功能配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询TCP流老化功能配置：

```
LST TOFLOWAGINGCFG:;
```

```
RETCODE = 0  操作成功

TCP流老化配置
-------------
TCP流老化功能开关  =  ENABLE
TCP流老化时间（秒）  =  500
(结果个数 = 1)

--- END
```

#### 输出结果说明

参见SET TOFLOWAGINGCFG的参数说明。
