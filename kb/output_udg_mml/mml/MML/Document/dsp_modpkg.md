# 查询模型包信息（DSP MODPKG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询指定网元下的模型信息，包括模型包名称、模型文件名称、模型版本等。

#### 注意事项

- 查询结果只包含已在DFS存储服务上传成功的模型信息，不包含在OM Portal或通过**ULD MODPKG**命令上传失败、正在上传的模型信息。
- 该命令支持通过模型包名称和模型文件名称匹配具体的模型信息，区分大小写。

#### 参数说明

| 参数标识             | 参数名称   | 参数说明                                                                                                                       |
|:-----------------|:-------|:---------------------------------------------------------------------------------------------------------------------------|
| MEID             | 网元ID   | 可选必选说明：必选参数。 参数含义：需要查询模型信息的网元ID。 取值范围：整数类型，取值范围为0~65535。 默认值：无。 配置原则：网元ID可通过LST ME命令查询获得。                                  |
| MODELPACKAGENAME | 模型包名称  | 可选必选说明：可选参数。 参数含义：模型包名称。 取值范围：字符串类型，长度1~128。 默认值：无。 配置原则：只能包括大小写字母、数字、中划线-、下划线_、英文句号.。长度最大为128。                            |
| MODELFILENAME    | 模型文件名称 | 可选必选说明：可选参数。 参数含义：模型文件名称。 取值范围：字符串类型，长度1~128。 默认值：无。 配置原则：只能包括大小写字母、数字、中划线-、下划线_、英文句号.。长度最大为128。                           |
| SOURCE           | 来源     | 可选必选说明：可选参数。 参数含义：需要查询的模型来源。 取值范围： “MANUAL（手动）”：模型包来源为手工上传。“PRESET（预置）”：模型包来源为预置上传。“AUTO（自动）”：模型包来源为模型训练生成。 默认值：无。 配置原则：无。 |
