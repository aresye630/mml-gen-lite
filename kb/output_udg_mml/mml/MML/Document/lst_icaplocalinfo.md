# 查询ICAP本端信息（LST ICAPLOCALINFO）

- 命令功能
- 注意事项
- 操作用户权限

- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于显示ICAP本端信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识           | 参数名称      | 参数说明                                                                                           |
|:---------------|:----------|:-----------------------------------------------------------------------------------------------|
| ICAPSERVERTYPE | ICAP服务器类型 | 可选必选说明：可选参数 参数含义：该参数用于指定ICAP服务器类型。 数据来源：本端规划 取值范围： URL_FILTERING：支持URL过滤的ICAP服务器。 默认值：无 配置原则：无 |

#### 使用实例

显示ICAP本端信息：

```
LST ICAPLOCALINFO:;
```

```
RETCODE = 0  操作成功

ICAP本端信息
------------
ICAP服务器类型  =  URL过滤
    User Agent  =  first
    配置域名称  =  NULL
(结果个数 = 1)

---    END
```
