# 查询TWAMP发送端（LST TWAMPSENDER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询TWAMP发送端。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                    |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------|
| CLIENTID | 客户端ID  | 可选必选说明：可选参数  参数含义：该参数用于配置客户端ID。  数据来源：全网规划  取值范围：整数类型，取值范围是1~12000。  默认值：无  配置原则：  CLIENTID必须在ADD TWAMPCLIENT已经配置，可以用LST TWAMPCLIENT查询。 |

## 使用实例

查询客户端ID为1的发送端实例：

```
%%LST TWAMPSENDER: CLIENTID=1;%%
RETCODE = 0  操作成功

结果如下
--------
    客户端ID  =  1
会话发送类型  =  连续统计
  差分服务码  =  0
    报文类型  =  固定报文长度
    报文长度  =  128
报文填充类型  =  报文随机填充
报文发送周期  =  100
    超时时间  =  5
(结果个数 = 1)

---    END
```
