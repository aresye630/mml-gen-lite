# 增加媒体中继Http消息控制（ADD RELAYHTTPMCTL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于添加媒体中继Http消息控制。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为20。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称           | 参数说明                                                                                                |
|:----------------|:---------------|:----------------------------------------------------------------------------------------------------|
| HTTPMSGCTRLNAME | 媒体中继Http消息控制名称 | 可选必选说明：必选参数 参数含义：该参数用来指定媒体中继Http消息控制名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |
| CFGDOMAINNAME   | 配置域名称          | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。  |

#### 使用实例

假如需要创建一组媒体中继Http消息控制，则命令如下：

```
ADD RELAYHTTPMCTL:HTTPMSGCTRLNAME="test";
```
