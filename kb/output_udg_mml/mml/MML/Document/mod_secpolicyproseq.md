# 修改安全策略匹配顺序（MOD SECPOLICYPROSEQ）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来修改安全策略匹配顺序。

#### 注意事项

- 该命令执行后立即生效。
- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                               |
|:------------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
| SECPOLICYID | 安全策略编号    | 可选必选说明：必选参数 参数含义：安全策略号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～30。 默认值：无                                                                                       |
| SECPROSEQWL | 安全白名单匹配顺序 | 可选必选说明：必选参数 参数含义：安全白名单匹配顺序。 数据来源：本端规划 取值范围：枚举类型。 First：匹配优先级高。Second：匹配优先级中。Third：匹配优先级低。 默认值：无 配置原则：SECPROSEQWL/SECPROSEQBL/SECPROSEQUF三个参数值不能相同。 |
| SECPROSEQBL | 安全黑名单匹配顺序 | 可选必选说明：必选参数 参数含义：安全黑名单匹配顺序。 数据来源：本端规划 取值范围：枚举类型。 First：匹配优先级高。Second：匹配优先级中。Third：匹配优先级低。 默认值：无 配置原则：SECPROSEQWL/SECPROSEQBL/SECPROSEQUF三个参数值不能相同。 |
| SECPROSEQUF | 安全用户流匹配顺序 | 可选必选说明：必选参数 参数含义：安全用户自定义流。 数据来源：本端规划 取值范围：枚举类型。 First：匹配优先级高。Second：匹配优先级中。Third：匹配优先级低。 默认值：无 配置原则：SECPROSEQWL/SECPROSEQBL/SECPROSEQUF三个参数值不能相同。  |

#### 使用实例

修改安全策略匹配顺序：

```
MOD SECPOLICYPROSEQ:SECPOLICYID=1,SECPROSEQWL=Third,SECPROSEQBL=Second,SECPROSEQUF=First;
```
