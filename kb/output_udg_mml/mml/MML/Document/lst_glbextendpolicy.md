# 查询全局扩展策略（LST GLBEXTENDPOLICY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于显示对应扩展策略类型的全局扩展策略。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                     |
|:--------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| EXTENDPLYTYPE | 扩展策略类型 | 可选必选说明：可选参数 参数含义：该参数用于设置扩展策略类型。 数据来源：本端规划 取值范围：枚举类型。 TETHERING：表示在没有超规格的情况下对Tethering前后台进行控制。EXCEED_TETHERING：表示在超规格情况下对Tethering前后台进行控制。 默认值：无 配置原则：根据部署的业务策略选择相应的策略类型。 |

#### 使用实例

假如运营商希望查看扩展策略类型为TETHERING的全局扩展策略：

```
LST GLBEXTENDPOLICY:;
```

```

```
