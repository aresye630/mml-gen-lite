# 修改扩展的多级重定向密码（MOD MULTREDIRECTEX）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于修改多级重定向字段加密的密码。

#### 注意事项

- 该命令执行后立即生效。
- 该命令与软参BIT\_1704配合使用。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识             | 参数名称       | 参数说明                                                                                                   |
|:-----------------|:-----------|:-------------------------------------------------------------------------------------------------------|
| MULTREDIRECTNAME | 多级重定向名称    | 可选必选说明：必选参数 参数含义：该参数用于设置多级重定向密码配置名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31，不区分大小写，不支持空格。 默认值：无 配置原则：无       |
| AESMODE          | AES加密模式    | 可选必选说明：必选参数 参数含义：AES加密模式。 数据来源：本端规划 取值范围：枚举类型。 CBC：CBC模式，有安全风险，不建议使用。GCM：GCM模式。CTR：CTR模式。 默认值：无 配置原则：无 |
| AES256KEY        | AES256 密码  | 可选必选说明：必选参数 参数含义：该参数用于指定对多级重定向字段加密的密码。 数据来源：本端规划 取值范围：密码类型，输入长度为1~32位的字符串，不支持空格。 默认值：无 配置原则：无          |
| AES256KEYCONF    | AES256密码确认 | 可选必选说明：必选参数 参数含义：该参数用于确认对多级重定向字段加密的密码。 数据来源：本端规划 取值范围：密码类型，输入长度为1~32位的字符串，不支持空格。 默认值：无 配置原则：无          |

#### 使用实例

假如运营商想要修改加密密码为1234567890123456，配置如下：

```
MOD MULTREDIRECTEX:MULTREDIRECTNAME="test", AESMODE=GCM,AES256KEY="1234567890123456",AES256KEYCONF="1234567890123456";
```
