# 查询TCP优化软参（LST TOSOFTPARA）

- 命令功能
- 注意事项
- 操作用户权限

#### 命令功能

**适用NF：UPF**

该命令用于查询TCP优化软参。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询TCP优化软参：

```
LST TOSOFTPARA:;
```

```
RETCODE = 0  操作成功
 
TCP优化软参
-------------
TCP优化软参1  =  0
TCP优化软参2  =  0
TCP优化软参3  =  0
(结果个数 = 1)
 
--- END
```
