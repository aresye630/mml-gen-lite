# 修改转发过载告警参数（MOD SFELOADALARM）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改转发过载告警参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                       |
|:---------------|:---------|:-------------------------------------------------------------------------------------------|
| OVERLOADTYPE   | 过载类型     | 可选必选说明：必选参数 参数含义：该参数用于表示转发过载告警的类型。 数据来源：本端规划 取值范围：枚举类型。 queue：队列告警。 默认值：无                  |
| TRIGTHRESHOLD  | 触发阈值（%）  | 可选必选说明：必选参数 参数含义：该参数用于表示触发转发过载告警的阈值。 数据来源：本端规划 取值范围：整数类型，取值范围为2～99。 默认值：无                  |
| RESUMTHRESHOLD | 恢复阈值（%）  | 可选必选说明：必选参数 参数含义：该参数用于表示转发过载告警的恢复阈值。 数据来源：本端规划 取值范围：整数类型，取值范围为1～98。 默认值：无                  |
| CHECKINTERVAL  | 检测间隔（ms） | 可选必选说明：必选参数 参数含义：该参数用于表示转发过载告警的检测间隔，单位为ms。 数据来源：本端规划 取值范围：整数类型，取值范围为1000～4294967295。 默认值：无 |
| CHECKTIMES     | 检测次数     | 可选必选说明：必选参数 参数含义：该参数用于表示转发过载告警的检测次数。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无          |

#### 使用实例

修改转发过载告警参数：

```
MOD SFELOADALARM:OVERLOADTYPE=queue,TRIGTHRESHOLD=92,RESUMTHRESHOLD=60,CHECKINTERVAL=2000,CHECKTIMES=10;
```
