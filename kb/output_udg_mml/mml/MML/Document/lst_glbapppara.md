#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于显示全局app参数配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

显示全局app参数配置参数：

```
LST GLBAPPPARA:;
```

```
RETCODE = 0  操作成功。

全局app参数
--------------------------
  App规则生效条件  =  N4_INDICATION
     通用应用标识  =  NULL
(结果个数 = 1)

---    END
```
