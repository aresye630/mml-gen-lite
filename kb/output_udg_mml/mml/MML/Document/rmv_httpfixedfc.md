# 删除HTTP流控组固定速率流控信息（RMV HTTPFIXEDFC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除HTTP固定速率流控门限值信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                  |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------|
| GROUP  | 流控组    | 可选必选说明：必选参数  参数含义：该参数用于指定HTTP固定速率流控组的唯一标识。该参数来源于ADD HTTPFCIPGRP命令的“流控组”参数，可通过LST HTTPFCIPGRP命令查询获取。  数据来源：全网规划  取值范围：整数类型，取值范围是0~4095。  默认值：无  配置原则：无 |

## 使用实例

删除HTTP固定速率流控门限值信息

```
RMV HTTPFIXEDFC: GROUP=1;
```
