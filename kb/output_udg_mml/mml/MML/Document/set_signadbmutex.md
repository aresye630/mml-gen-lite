# 配置特征库规则的加载条件（SET SIGNADBMUTEX）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，影响SA业务识别结果。

配置特征库规则的加载条件。

#### 注意事项

- 该命令执行后60秒生效。
- 该命令最大记录数为1。
- 启用之前需要先和华为工程师联系，确认当前特征库，以及需要配置的area-id和mutex-id是否支持。
- 避免LOD SIGNATUREDB、ADD SIGNADBRULE、SET SIGNADBMUTEX在5分钟内连续配置操作。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   |   MUTEXID |   AREAID |
|:-------|----------:|---------:|
| 初始值    |         1 |        0 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称        | 参数说明                                                                                                                                                                                        |
|:--------|:------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MUTEXID | 特征库规则加载分类ID | 可选必选说明：必选参数 参数含义：当需要设置特征库的加载规则分类ID时，使用该字段。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 配置原则：该功能属于定制需求，启用之前需要先和华为工程师联系，确认当前特征库是否支持，以及需要配置的area-id和mutex-id。如果需要配置多个mutex-id，需要确保多个id间无冲突关系。 |
| AREAID  | 特征库加载规则区域ID | 可选必选说明：必选参数 参数含义：当需要设置特征库的加载规则区域ID时，使用该字段。 数据来源：本端规划 取值范围：整数类型，取值范围为0～32。 默认值：无 配置原则：该功能属于定制需求，启用之前需要先和华为工程师联系，确认当前特征库是否支持，以及需要配置的area-id和mutex-id。                                         |

#### 使用实例

配置特征库规则的加载规则分类ID为2，规则区域ID为0如下：

```
SET SIGNADBMUTEX: MUTEXID=2, AREAID=0;
```
