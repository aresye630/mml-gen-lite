# 在S1TAC组内添加一个S1TAC（ADD S1TACID）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U**

该命令用来在S1TAC组内绑定S1TAC号段。当需要在指定S1TAC组内绑定某个S1TAC号段时，使用该命令。

#### 注意事项

- 该命令执行后只对新激活用户生效。
- 该命令最大记录数为16000。
- 当一个S1TAC号段被绑定到某个S1TAC组内后，就不允许再绑定到其他的S1TAC组。S1TAC号段之间的S1TAC值不允许重叠。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称       | 参数说明                                                                                                                                                                                                          |
|:-------------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TACGROUPNAME | 指定S1TAC组名  | 可选必选说明：必选参数 参数含义：该参数用于指定S1TAC组名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。不支持空格，不区分大小写。 默认值：无 配置原则：该TACGROUPNAME必须已经配置过。                                                                                              |
| TACSECNUM    | S1Tac 段编号  | 可选必选说明：必选参数 参数含义：该参数用于指定S1TAC段编号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～15999。 默认值：无 配置原则：无                                                                                                                              |
| TACSTARTID   | S1Tac 起始ID | 可选必选说明：必选参数 参数含义：该参数用于指定S1TAC起始ID。 数据来源：本端规划 取值范围：字符串类型，长度为4位或者6位表示十六进制的字符串。仅支持输入0x/X、a-f/A-F 、0-9。字母不区分大小写，如果输入6位字符串则取值范围0x0000~0xFFFF，允许不输入0x前缀，4位字符串取值范围0000~FFFF。 默认值：无 配置原则：TACSTARTID的取值应小于或等于TACENDID。 |
| TACENDID     | S1TAC截止ID  | 可选必选说明：必选参数 参数含义：该参数用于指定S1TAC截止ID。 数据来源：本端规划 取值范围：字符串类型，长度为4位或者6位表示十六进制的字符串。仅支持输入0x/X、a-f/A-F 、0-9。字母不区分大小写，如果输入6位字符串则取值范围0x0000~0xFFFF，允许不输入0x前缀，4位字符串取值范围0000~FFFF。 默认值：无 配置原则：TACENDID的取值应大于或等于TACSTARTID。 |

#### 使用实例

假设运营商需要在一个本地已经配置的S1TAC组绑定一个S1TAC号段：

```
ADD S1TACID:TACGROUPNAME="beijing",TACSECNUM=2,TACSTARTID="0x0001",TACENDID="0x0010";
```
