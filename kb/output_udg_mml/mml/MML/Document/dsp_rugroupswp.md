# 显示资源单元组主备倒换状态信息（DSP RUGROUPSWP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示资源单元组的主备倒换状态信息，包括资源单元组的主用RU、备用RU及倒换状态。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                          |
|:----------------|:-------|:------------------------------------------------------------------------------------------------------------------------------|
| GROUPNAME       | RU组名称  | 可选必选说明：可选参数 参数含义：该参数用于表示资源单元组名称。可使用DSP RUGROUP命令查询对应的资源单元组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无 |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识，但不能填写0，0表示VNFP。   |

#### 使用实例

- 显示所有资源单元组的主备倒换状态信息：

  ```
  DSP RUGROUPSWP:SERVICEINSTANCE="vnfc";
  ```

  ```
  RETCODE = 0  操作成功

  结果如下:
  -----------------------------------
  RU组名称        主用RU                       备用RU                       倒换状态
  MMB-BG1         VNODE_VNRS_VNFC_OMU_0001     VNODE_VNRS_VNFC_OMU_0002     就绪 
  BG_IPCTRL       VNODE_VNRS_VNFC_IPCTR_0071   VNODE_VNRS_VNFC_IPCTR_0072   未就绪         
  (结果个数 = 2)
  ---    END
  ```
- 显示指定资源单元组的主备倒换状态信息，资源单元组的名称为MMB-BG1：

  ```
  DSP RUGROUPSWP:GROUPNAME="MMB-BG1",SERVICEINSTANCE="vnfc";
  ```

  ```
  RETCODE = 0  操作成功

  结果如下:
  -----------------------------------
  资源单元组名称 = MMB-BG1
          主用RU = VNODE_VNRS_VNFC_OMU_0001
          备用RU = VNODE_VNRS_VNFC_OMU_0002
        倒换状态 = 批备中
  (结果个数 = 1)
  ---    END
  ```

#### 输出结果说明

| 输出项名称   | 输出项解释                                                                                               |
|:--------|:----------------------------------------------------------------------------------------------------|
| RU组名称   | 用于表示资源单元组名称。可使用DSP RUGROUP命令查询对应的资源单元组名称。                                                           |
| 主用RU    | 用于表示主用资源单元。                                                                                         |
| 备用RU    | 用于表示备用资源单元。                                                                                         |
| 倒换状态    | 该参数用于表示资源单元组倒换状态。 就绪：资源单元组倒换状态为就绪；。未就绪：资源单元组倒换状态为未就绪；。无备用资源单元：资源单元组倒换状态为无备用资源单元；。批备中：资源单元组倒换状态为批备中。 |
