# 设置策略流控开关（SET POLICYFCSWITCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置策略流控开关。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| FCSWITCH   |
|:-----------|
| ON         |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                          |
|:---------|:-------|:----------------------------------------------------------------------------------------------|
| FCSWITCH | 策略流控开关 | 可选必选说明：必选参数  参数含义：该参数用于显示策略流控开关状态。  数据来源：本端规划 取值范围： ON（策略流控开关打开）OFF（策略流控开关关闭）  默认值：无。  配置原则：无 |

## 使用实例

设置策略流控开关为开。

```
%%SET POLICYFCSWITCH: FCSWITCH=ON;%%
RETCODE = 0  操作成功

---    结束
```
