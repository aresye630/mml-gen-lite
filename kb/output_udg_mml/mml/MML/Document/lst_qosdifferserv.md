# 查询DS域（LST QOSDIFFERSERV）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询系统上所有的DS域。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                    |
|:-------|:-------|:------------------------------------------------------------------------|
| DSNAME | DS域名   | 可选必选说明：可选参数 参数含义：该参数用于指定DS域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 |

#### 使用实例

查询当前系统存在的所有DS域：

```
LST QOSDIFFERSERV:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
DS域名
default
5p3d
(结果个数 = 2)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释       |
|:--------|:------------|
| DS域名    | 该参数表示DS域名称。 |
