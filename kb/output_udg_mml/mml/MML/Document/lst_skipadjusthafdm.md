# 查询跳过调整HAF域开关状态（LST SKIPADJUSTHAFDM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询跳过调整HAF域开关状态。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询跳过调整HAF域开关状态。

```
%%LST SKIPADJUSTHAFDM:;%%
RETCODE = 0  操作成功

结果如下
------------------------
开关状态      = 关闭
(结果个数 = 1)
```

## 输出结果说明

| 输出项名称      | 输出项解释                                                        |
|:-----------|:-------------------------------------------------------------|
| 跳过HAF调整域开关 | 该参数用于表示跳过HAF域调整的触发方式，值为ON表示跳过HAF调整域开关打开，值为OFF表示跳过HAF调整域开关关闭。 |
