# 查询HTTP CCA属性（LST HTTPCCACONF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询HTTP CCA属性。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

如果想查询HTTP CCA属性，可以用如下命令：

```
%%LST HTTPCCACONF:;%%
RETCODE = 0  操作成功

结果如下
--------
     CCA校验开关  =  打开
CCA的有效时长(s)  =  86400
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称       | 输出项解释                      |
|:------------|:---------------------------|
| CCA校验开关     | 该参数用于控制HTTP服务端CCA校验功能是否开启。 |
| CCA的有效时长(s) | 该参数用于配置HTTP客户端生成的CCA的有效时长。 |
