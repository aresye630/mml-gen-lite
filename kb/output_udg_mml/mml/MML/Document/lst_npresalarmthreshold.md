# 查询NP资源占用告警阈值（LST NPRESALARMTHRESHOLD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询NP资源占用告警阈值。

#### 注意事项

- 该命令执行后立即生效。
- 该命令仅适用于NP卡加速模式场景。
- 该命令当前只支持NP121/NP120，NP类型可通过DSP NPNODE命令查询。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                              |
|:--------|:-------|:--------------------------------------------------------------------------------------------------|
| RUID    | RU编号   | 可选必选说明：可选参数。 参数含义：该参数用于指定RU编号。 数据来源：本端规划。 取值范围：整数类型，输入长度范围为64～9999。 默认值：无。 配置原则：通过DSP RU命令查询。     |
| RESTYPE | 资源类型   | 可选必选说明：可选参数。 参数含义：该参数用于指定资源类型。 数据来源：本端规划。 取值范围：枚举类型 “NP_RESTYPE_ACL（ACL）”：ACL表项资源。 默认值：无。 配置原则：无。 |

#### 使用实例

查询NP资源占用告警阈值：

```
LST NPRESALARMTHRESHOLD:;
```

```
%%LST NPRESALARMTHRESHOLD:;%%
RETCODE = 0  操作成功

结果如下
--------
RU编号  资源类型  告警上报阈值  告警恢复阈值  

70      ACL       80            75                 
71      ACL       80            75                 
(结果个数 = 2)

---    END
```
