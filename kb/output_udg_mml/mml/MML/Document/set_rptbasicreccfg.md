# 设置基础单据上报配置开关（SET RPTBASICRECCFG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，该命令会导致用户匹配数发生变化，可能导致性能下降。执行命令前请评估对性能的影响，如果无法评估请联系华为技术支持。

该命令用于配置基础单据上报功能开关，包括用户信息开关、用户统计开关、APP统计开关和资源开关。当运营商部署业务报表业务时使用该命令。

#### 注意事项

- 该命令执行后60s生效。
- 该命令最大记录数为1。
- 该命令会导致用户匹配数发生变化，可能导致性能下降。执行命令前请评估对性能的影响，如果无法评估请联系华为技术支持。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | USERINFOSW   | USERSTATSSW   | APPSTATSSW   | RESOUCESW   |
|:-------|:-------------|:--------------|:-------------|:------------|
| 初始值    | DISABLE      | DISABLE       | DISABLE      | DISABLE     |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                       |
|:------------|:--------|:-------------------------------------------------------------------------------------------|
| USERINFOSW  | 用户信息开关  | 可选必选说明：可选参数 参数含义：用户信息开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能（关闭）。ENABLE：使能（开启）。 默认值：无 配置原则：无  |
| USERSTATSSW | 用户统计开关  | 可选必选说明：可选参数 参数含义：用户统计开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能（关闭）。ENABLE：使能（开启）。 默认值：无 配置原则：无  |
| APPSTATSSW  | APP统计开关 | 可选必选说明：可选参数 参数含义：APP统计开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能（关闭）。ENABLE：使能（开启）。 默认值：无 配置原则：无 |
| RESOUCESW   | 资源开关    | 可选必选说明：可选参数 参数含义：资源开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能（关闭）。ENABLE：使能（开启）。 默认值：无 配置原则：无    |

#### 使用实例

使能用户信息开关：

```
SET RPTBASICRECCFG:USERINFOSW = ENABLE;
```
