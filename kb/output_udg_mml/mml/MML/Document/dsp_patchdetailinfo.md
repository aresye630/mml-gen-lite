# 显示补丁信息（DSP PATCHDETAILINFO）

#### 命令功能

该命令用于显示补丁详细信息，包括补丁单元文件名、运行状态、补丁类型、是否生效及生效时间等。

补丁的加载、激活，删除会触发补丁状态的变化，使用该命令显示系统当前的补丁单元状态信息。

#### 注意事项

不指定查询条件时，该命令只支持返回最多30000个补丁记录；超过30000个补丁记录查询时该命令会报错，此时请指定RU名称或进程ID进行查询操作。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RUNAME          | RU名称   | 可选必选说明：可选参数 参数含义：该参数用于指定要查询补丁单元的RU的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：只能填写实际存在的资源单元，使用DSP RU查看RU名称。                                            |
| PROCID          | 进程ID   | 可选必选说明：可选参数 参数含义：该参数用于指定要查询补丁单元所属进程的ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                                                         |
| STATE           | 状态     | 可选必选说明：可选参数 参数含义：该参数用于指定要查询补丁单元的状态。 数据来源：本端规划 取值范围：枚举类型。 Idle：补丁状态为空闲。Deactive：补丁状态为去激活。Active：补丁状态为激活。Running：补丁状态为运行。 默认值：无                                |
| PATCHTYPE       | 类型     | 可选必选说明：可选参数 参数含义：该参数用于指定要查询补丁单元的类型。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无                                                                                  |
| VALID           | 是否生效   | 可选必选说明：可选参数 参数含义：该参数用于指定查询是否生效的补丁单元。 数据来源：本端规划 取值范围：枚举类型。 No：补丁单元不生效。Yes：补丁单元生效。 默认值：无                                                                       |
| EFFECTIVETIME   | 生效时间   | 可选必选说明：可选参数 参数含义：该参数用于指定要查询补丁单元的生效时间，补丁未生效时显示为NULL，NULL不能作为入参。 数据来源：本端规划 取值范围：日期时间类型，输入格式是YYYY&MM&DD&HH&NN&SS。01/01/2000 00:00:00～31/12/2037 23:59:59。 默认值：无 |
| PATCHFILENAME   | 文件名    | 可选必选说明：可选参数 参数含义：该参数用于指定要查询补丁单元文件名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无                                                                                  |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。                                                 |

#### 使用实例

显示补丁详细信息：

```
DSP PATCHDETAILINFO:SERVICEINSTANCE="vnfc";
```


#### 输出结果说明

| 输出项名称   | 输出项解释                        |
|:--------|:-----------------------------|
| RU名称    | 表示补丁单元所属的RU名称。               |
| 进程ID    | 表示补丁单元所属进程ID。                |
| 状态      | 表示补丁单元状态，包括空闲、去激活、激活和运行四种状态。 |
| 类型      | 表示补丁单元类型。                    |
| 是否生效    | 表示补丁单元是否生效。                  |
| 生效时间    | 表示补丁单元生效时间。                  |
| 文件名     | 表示补丁单元文件名。                   |
