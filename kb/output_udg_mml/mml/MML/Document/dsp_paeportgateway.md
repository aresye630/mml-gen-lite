# 显示PAE端口网关信息（DSP PAEPORTGATEWAY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示指定资源上PAE端口对应的网关信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                   |
|:-------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CELLTYPE     | 微服务类型  | 可选必选说明：可选参数  参数含义：该参数用于标识微服务类型。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~63。仅支持数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符。  默认值：无  配置原则：  使用DSP PAENODE查看“工作角色”为“数据转发”的微服务类型。    |
| CELLINSTANCE | 微服务实例号 | 可选必选说明：可选参数  参数含义：该参数用于标识微服务实例号。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~127。仅支持数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符。  默认值：无  配置原则：  使用DSP PAENODE查看“工作角色”为“数据转发”的微服务实例号。 |

## 输出结果说明

| 输出项名称   | 输出项解释                                                      |
|:--------|:-----------------------------------------------------------|
| 微服务类型   | 该参数用于标识微服务类型。                                              |
| 微服务实例号  | 该参数用于标识微服务实例号。                                             |
| 网段索引    | 该参数用于标识PAE端口网关地址的网段索引。                                     |
| 平面ID    | 该参数用于标识平面ID。                                               |
| 端口名称    | 该参数用于标识PAE端口名称。                                            |
| 端口类型    | 该参数用于标识PAE端口类型。 取值说明： PAE_PORT_EXT（外联口）PAE_PORT_INNER（内联口） |
| 网关IP地址  | 该参数用于标识PAE端口网关IP地址。                                        |
| 网关MAC地址 | 该参数用于标识PAE端口的网关MAC地址。                                      |
| 端口状态    | 该参数用于标识PAE端口状态。 取值说明： DOWN（down）UP（up）INVALID（invalid）     |
