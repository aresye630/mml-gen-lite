# 查询PAE告警配置（LST FABRICINALARMCFG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询多框级联的情况下PAE的Fabric平面不可达告警的屏蔽配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询PAE的Fabric平面不可达告警配置：

```
%%LST FABRICINALARMCFG:;%%
RETCODE = 0  操作成功

结果如下:
---------
屏蔽告警标记  =  否
(结果个数 = 1)

---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释           |
|:--------|:----------------|
| 屏蔽告警标记  | 用于表示是否开启告警屏蔽功能。 |
