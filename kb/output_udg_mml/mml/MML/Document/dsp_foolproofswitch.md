# 显示防呆开关状态（DSP FOOLPROOFSWITCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示防呆开关状态。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

假如操作员想了解防呆开关的当前状态，可以调用以下命令显示所有防呆开关的状态。

```
%%DSP FOOLPROOFSWITCH:;%%
RETCODE = 0  操作成功

结果如下
--------
名称  =  ONECLICKDEPLOY
状态  =  打开
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                |
|:--------|:-----------------------------------------------------|
| 名称      | 该参数用于表示防呆开关名称。                                       |
| 状态      | 该参数用于表示防呆开关状态。 取值说明： “ON（打开）”：防呆开关打开“OFF（关闭）”：防呆开关关闭 |
