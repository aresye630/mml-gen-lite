# 显示NP资源实时占用信息（DSP NPRESOURCE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示指定RU的NP资源实时占用信息。

#### 注意事项

- 该命令执行后立即生效。
- 该命令仅适用于NP卡加速模式场景。
- 该命令当前只支持NP121/NP120，NP类型可通过DSP NPNODE命令查询。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                     |
|:-------|:-------|:-----------------------------------------------------------------------------------------|
| RUID   | RU编号   | 可选必选说明：必选参数。 参数含义：RU编号。 数据来源：本端规划。 取值范围：整数类型，取值范围为64～9999。 默认值：无。 配置原则：使用DSP RU命令查询RU编号。 |

#### 使用实例

显示RU编号为70的NP资源实时占用情况：

```
DSP NPRESOURCE: RUID=70;
```

```
%%DSP NPRESOURCE: RUID=70;%%
RETCODE = 0  操作成功

结果如下
--------
NP编号  资源类型  告警上报阈值  告警恢复阈值  实时占用率  

0       ACL       80            75            0           
1       ACL       80            75            0           
(结果个数 = 2)

---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                                            |
|:--------|:-------------------------------------------------|
| NP编号    | 该参数用于表示NP编号。                                     |
| 资源类型    | 该参数用于表示对应的资源类型，如当前暂时只支持ACL表项资源占用实时查询。            |
| 告警上报阈值  | 该参数用于表示该类表项资源占用的告警上报阈值，单位为百分比。                   |
| 告警恢复阈值  | 该参数用于表示该类表项资源占用的告警恢复阈值，单位为百分比。                   |
| 实时占用率   | 该参数用于表示该类资源的实时占用率，单位为百分比。非NP121/NP120场景查询结果为无效值。 |
