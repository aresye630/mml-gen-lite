# 实例化完成结果查询（DSP VNFINSTANTIATIONRESULT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询实例化结果。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                              |
|:-------|:-------|:----------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：可选参数  参数含义：该参数用于标识网元ID。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~40。  默认值：无  配置原则：无 |

## 使用实例

查询实例化结果:

```
DSP VNFINSTANTIATIONRESULT:;
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                            |
|:--------|:-----------------------------------------------------------------|
| 实例化处理进度 | 该参数用于表示实例化进度。                                                    |
| 实例化处理结果 | 该参数用于表示实例化处理结果。 取值说明： Processing（处理中）OK（成功）Nok（失败）PartlyOK（部分成功） |
| 实例化结果说明 | 该参数用于说明实例化结果，仅在InstResult为Nok或者PartlyOK时有效。                      |
