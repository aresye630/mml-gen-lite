# 解闭CSDB RU（UBLK RU）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于解闭已闭塞的CSDB RU，使其他RU上的数据迁回到RU上。在分批升级之后，执行本命令，将数据迁移回RU上。

#### 注意事项

- 该命令执行后，需要通过**LST BLKHISTORY**命令查询解闭结果。
- 同一子集群中，待解闭RU的状态为闭塞状态时，才可以执行**UBLK RU**操作。
- 在执行**UBLK RU**后，RU处于**处理中**和**处理失败**状态时，禁止进行扩缩容和动态上下线操作。
- 该命令在容器场景下不支持。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                                                      |
|:-----------|:--------|:--------------------------------------------------------------------------------------------------------------------------|
| SCALEGROUP | 物理资源组名称 | 可选必选说明：必选参数。 参数含义：该参数用于指定唯一一个物理资源组。 数据来源：该物理资源组名称可以通过LST SERVICERUSTATE命令查询获取，对应ScaleGroup的名字。 取值范围：字符串类型，长度为1～63。 默认值：无。 |

#### 使用实例

解闭“物理资源组名称”为“SG1\_CSDB\_ForCommon”中已经闭塞的RU:

```
UBLK RU: SCALEGROUP="SG1_CSDB_ForCommon";
```
