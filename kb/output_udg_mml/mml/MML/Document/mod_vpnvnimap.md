# 修改VPN VNI映射（MOD VPNVNIMAP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，修改VPN与VNI映射关系时，需要同步修改对应MEP上VNI与VPN的映射关系。

该命令用于修改VNI与VPN映射关系对应的规则配置。

#### 注意事项

- 该命令执行后立即生效。
- 执行该命令修改VPN与VNI映射关系时，需要同步修改对应MEP上VNI与VPN的映射关系。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                             |
|:------------|:-------|:-----------------------------------------------------------------------------------------------------------------|
| VPNINSTANCE | VPN实例名 | 可选必选说明：必选参数 参数含义：该参数用于配置VPN实例。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，区分大小写。 默认值：无 配置原则：该参数使用 ADD VPNINST命令配置生成。 |
| RULENAME    | 规则名称   | 可选必选说明：可选参数 参数含义：该参数用于设置规则名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无                        |
| VNI         | VNI    | 可选必选说明：必选参数 参数含义：配置VXLAN隧道头中的VNI标识的值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～16777215。 默认值：无 配置原则：无                          |

#### 使用实例

修改VNI为4096与VPN为vpn1映射的规则配置为rule1：

```
MOD VPNVNIMAP: VPNINSTANCE="vpn1", RULENAME="rule1", VNI=4096;
```
