# 添加会话均衡基线能力值（ADD SESSLBCAPABILITY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

**须知** 

本命令属于高危命令，如果参数设置不合理，会导致业务板负荷不均、转发不通、用户激活失败等。

在异构硬件场景下，使用该命令用于配置CPU的基线能力。

#### 注意事项

- 该命令执行后立即生效。
- 系统最多支持配置3000条。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                  |
|:-----------|:-------|:------------------------------------------------------------------------------------------------------|
| TYPE       | Cpu类型  | 可选必选说明：必选参数 参数含义：该参数用于指定CPU类型。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～15。当前只支持x86_64和aarch64两种类型。 默认值：无 配置原则：无 |
| VERSION    | Cpu代数  | 可选必选说明：必选参数 参数含义：该参数用于指定Cpu代数。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无                         |
| FREQUENCY  | Cpu主频  | 可选必选说明：必选参数 参数含义：该参数用于指定Cpu主频。 数据来源：本端规划 取值范围：整数类型，取值范围为1～65535。 默认值：无 配置原则：无                         |
| CAPABILITY | 能力     | 可选必选说明：必选参数 参数含义：该参数用来配置Cpu基线能力。 数据来源：本端规划 取值范围：整数类型，取值范围为100～3000。 默认值：无 配置原则：无                      |

#### 使用实例

在异构硬件场景下，配置此命令，让用户会话根据CPU的能力进行负载均衡：

```
ADD SESSLBCAPABILITY: TYPE="x86_64", VERSION="Intel(R) Xeon(R) CPU E5-2658 v4 @ 2.30GHz", FREQUENCY=2500, CAPABILITY=900;
```
