# 设置FE自愈功能配置（SET FEHEALCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用来设置FE自愈功能开关：包括Mesh网口故障自愈功能开关和FE服务丢失心跳自愈开关。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| MESHFAULTSW   | FEFAULTSW   |
|:--------------|:------------|
| Enable        | Enable      |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称           | 参数说明                                                                                                                                            |
|:------------|:---------------|:------------------------------------------------------------------------------------------------------------------------------------------------|
| MESHFAULTSW | Mesh网口故障自愈功能开关 | 可选必选说明：可选参数  参数含义：Mesh网口故障自愈功能开关。  数据来源：本端规划 取值范围： Disable（去使能）Enable（使能）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST FEHEALCTRL查询当前参数配置值。  配置原则：无 |
| FEFAULTSW   | FE服务丢失心跳自愈开关   | 可选必选说明：可选参数  参数含义：FE服务丢失心跳自愈开关。  数据来源：本端规划 取值范围： Disable（去使能）Enable（使能）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST FEHEALCTRL查询当前参数配置值。  配置原则：无   |

## 使用实例

设置Mesh网口故障自愈使能，FE服务丢失心跳自愈使能：

```
SET FEHEALCTRL: MESHFAULTSW=Enable, FEFAULTSW=Enable;
```
