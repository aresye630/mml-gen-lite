# 添加用户选择范围列表（ADD USERSELRANGE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用来添加用户选择范围的属性配置，应用于该策略选定用户的性能统计。

#### 注意事项

- 该命令执行后只对新激活用户生效。
- 该命令最大记录数为20000。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                     |
|:----------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NAME      | 用户选择范围名称 | 可选必选说明：必选参数 参数含义：用户选择范围集合配置名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63，单位是字节。只能由“_”、“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。 默认值：无 配置原则：最大规格为1-63。                                                                        |
| RANGETYPE | 用户标识类型   | 可选必选说明：必选参数 参数含义：该参数用于设置策略类型。 数据来源：本端规划 取值范围：枚举类型。 APN：范围类型为APN。 默认值：无 配置原则：无                                                                                                                                                                                                            |
| APN       | APN名称    | 可选必选说明：条件必选参数 前提条件：该参数在“RANGETYPE”配置为“APN”时为必选参数。 参数含义：APN名称信息。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63，单位是字节。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。 默认值：无 配置原则： 该参数使用ADD APN命令配置生成。对于同一用户选择列表名称，最大可配置10000个APN。 |

#### 使用实例

当运营商需要配置一个apn策略：

```
ADD USERSELRANGE: NAME="test", RANGETYPE=APN, APN="test.apn";
```
