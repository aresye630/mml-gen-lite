# 删除HTTP统计参数（RMV HTTPSTATPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除一个HTTP对端地址。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                       |
|:-----------|:---------|:-----------------------------------------------------------------------------------------------------------|
| PEERIPTYPE | 对端IP地址类型 | 可选必选说明：必选参数  参数含义：该参数用于指定对端IP地址类型。  数据来源：全网规划 取值范围： “IPv4（IPv4）”：IPv4地址“IPv6（IPv6）”：IPv6地址  默认值：无  配置原则：无  |
| PEERIPV4   | 对端IPv4地址 | 可选必选说明：该参数在"PEERIPTYPE"配置为"IPv4"时为条件必选参数。  参数含义：该参数用于指定对端IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无 |
| PEERIPV6   | 对端IPv6地址 | 可选必选说明：该参数在"PEERIPTYPE"配置为"IPv6"时为条件必选参数。  参数含义：该参数用于指定对端IPv6地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无 |

## 使用实例

删除一条对端IP地址，执行命令如下：

```
RMV HTTPSTATPARA: PEERIPTYPE=IPv4, PEERIPV4="10.2.3.4";
```
