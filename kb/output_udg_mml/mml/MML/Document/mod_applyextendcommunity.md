# 修改扩展团体属性设置（MOD APPLYEXTENDCOMMUNITY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改应用扩展团体属性。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称       | 参数说明                                                                                                                                       |
|:-------------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| POLICYNAME   | 路由策略名字     | 可选必选说明：必选参数 参数含义：该参数用于指定路由策略名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无 配置原则：区分大小写。                                                       |
| NODESEQUENCE | 路由策略节点ID   | 可选必选说明：必选参数 参数含义：该参数用于指定路由策略节点ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无                                                                  |
| ADDITIVEFLAG | 增加已有团体属性标记 | 可选必选说明：可选参数 参数含义：该参数用于表示追加标记： true：配置的扩展团体属性将追加到路由原有扩展团体属性上。 false：配置的扩展团体属性将替换路由原有扩展团体属性。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无 |

#### 使用实例

修改设置扩展团体属性的操作：

```
MOD APPLYEXTENDCOMMUNITY:NODESEQUENCE=10,POLICYNAME="a",ADDITIVEFLAG=TRUE;
```
