# 删除FUI扩展过滤器绑定配置（RMV FUIEXTFILTER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，删除FuiExtFilter会修改欠费重定向动作，引起欠费用户业务行为发生变化，请谨慎使用并联系华为支持协助操作。

该命令用于删除FUI扩展过滤器绑定关系，删除后将会直接执行。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                                                                   |
|:-----------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------|
| EXTFLTNAME | 扩展过滤器名字 | 可选必选说明：可选参数 参数含义：该参数用于指定扩展过滤器名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则： 如果输入过滤器名称，表示删除指定的过滤器条件。如果不输入任何名称，表示删除全部条件。 |

#### 使用实例

运营商想要删除扩展过滤名称为ExtFilter1的FUI扩展过滤器绑定关系，使用此命令：

```
RMV FUIEXTFILTER:EXTFLTNAME="ExtFilter1";
```
