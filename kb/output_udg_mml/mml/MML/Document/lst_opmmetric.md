# 查询话统指标优化公式(LST OPMMETRIC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询网元的话统指标的优化公式。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                         |
|:---------|:-------|:---------------------------------------------------------------------------------------------|
| MEID     | 网元ID   | 可选必选说明：可选参数。 参数含义：标识网元ID，可以通过LST ME命令查询获取。 取值范围：0~65535。 默认值：无。 配置原则：无。                      |
| METRICID | 测量指标ID | 可选必选说明：可选参数。 参数含义：测量指标ID，可以通过LST MEASUNIT命令查询获取。 取值范围：整数类型，取值范围为0~4294967294。 默认值：无。 配置原则：无。 |

## 使用实例

查询话统指标优化公式：

```
%%LST OPMMETRIC:;%%
RETCODE = 0  操作成功

测量指标优化公式
----------------
网元ID  测量指标ID  测量指标名称  测量指标优化公式         公式指标说明                       

100     141100092   指标92        [141100092]*{2}          141100092:指标92                   
100     141100093   指标93        [141100091]+[141100092]  141100091:指标93;141100092:指标93  
100     141100094   指标94        {123}                    NULL                               
(结果个数 = 3)

---    END
```
