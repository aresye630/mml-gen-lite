# 设置裸机节点自动进入BYPASS开关（SET BMBYPASSSWITCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

在存储故障场景，节点可能无法自动进入BYPASS状态，请慎重使用该命令。

本命令用于设置存储故障时，裸机节点是否自动进入BYPASS状态。

**说明** 

该命令仅在Full-stack裸机场景下支持。

## 注意事项

- 如果关闭此开关，存储故障修复后，存储故障告警无法自动恢复，需要通过手工进入、退出BYPASS触发恢复流程或重启节点修复存储故障告警。
- 该命令存在系统初始记录，参数的初始设置值如下：

| 参数名称         | 初始设置值   |
|:-------------|:--------|
| 自动进入BYPASS开关 | 开启      |

## 参数说明

| 参数标识              | 参数名称         | 参数说明                                                                                                   |
|:------------------|:-------------|:-------------------------------------------------------------------------------------------------------|
| SSW_BYPASS_SWITCH | 自动进入BYPASS开关 | 可选必选说明：必选参数 参数含义：用于设置节点自动进入BYPASS开关的状态。 取值范围： “ON(开启自动进入BYPASS功能)”“OFF(关闭自动进入BYPASS功能)” 默认值：无。 配置原则：无。 |

## 使用实例

1. 设置自动进入BYPASS开关。

   ```
   %%SET BMBYPASSSWITCH: SSW_BYPASS_SWITCH=ON;%% 
   RETCODE = 0  操作成功  
   操作结果如下 
   ------------ 
   节点名称                           节点IP      详细信息

   e23d6419-cie-qb8it-dbf4467df-6vpwh XX.XX.XX.XX Success             
   (结果个数 = 3) 
   ---    END
   ```
