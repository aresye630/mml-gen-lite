# 修改Acl节点绑定关系（MOD ACLNODEBINDACL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于修改ACL节点绑定关系。当需要改变ACL节点在该ACL下的优先级时，可以使用此命令。

#### 注意事项

- 该命令执行后立即生效。
- 对于ACL为自动排序方式的，在绑定ACL节点时不需要指定优先级，如果指定了优先级，优先级也是无效的。
- ACL正在被使用时，可以修改ACL节点的优先级。
- ACL节点的动作需要与ACL下其他ACL节点的动作一致。
- 修改或删除ACL后需要执行SET REFRESHSRV使当前配置生效，建议该操作在对所有ACL的配置修改完成后执行。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                               |
|:------------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------|
| ACLNAME     | ACL名称   | 可选必选说明：必选参数 参数含义：该参数用于配置ACL名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无                                         |
| ACLNODENAME | ACL节点名称 | 可选必选说明：必选参数 参数含义：该参数用于配置ACL节点名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无                                       |
| PRIORITY    | 优先级     | 可选必选说明：可选参数 参数含义：该参数用于配置ACL节点的优先级。 数据来源：本端规划 取值范围：整数类型，取值范围为1～65535。 默认值：无 配置原则： 该参数的值越小优先级越高。当ACL的MatchOrder配置方式为CONFIG时必须要配置优先级。 |

#### 使用实例

假如运营商需要提高ACL节点“testaclnode2”在ACL“testacl2”下的优先级：

```
MOD ACLNODEBINDACL: ACLNAME="testacl2",ACLNODENAME="testaclnode2",PRIORITY=10;
```
