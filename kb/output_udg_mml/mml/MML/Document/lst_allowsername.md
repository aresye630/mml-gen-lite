# 查询基于地址的白名单（LST ALLOWSERNAME）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询基于服务地址的NF实例的服务白名单信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                              |
|:-------|:-------|:----------------------------------------------------------------------------------|
| INDEX  | 索引     | 可选必选说明：可选参数  参数含义：该参数用于指定白名单索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~2047。  默认值：无  配置原则：无 |

## 使用实例

查询所有配置的基于服务地址的服务白名单信息。

```
%%LST ALLOWSERNAME:;%%
RETCODE = 0  操作成功

结果如下
--------
      索引  =  0
NF实例标识  =  SMF_Instance_0
  服务名称  =  nsmfP dusess
  本端地址  =  192.168.0.1
  对端地址  =  192.168.0.2
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                      |
|:--------|:-------------------------------------------|
| 索引      | 该参数用于指定白名单索引。                              |
| NF实例标识  | 该参数用于指定添加到白名单的服务的NF实例标识。目前本参数不生效。          |
| 服务名称    | 该参数用于指定添加到白名单中的服务的服务名称，取自URI中的servicename。 |
| 本端地址    | 该参数用于指定添加到白名单的服务的服务地址。                     |
| 对端地址    | 该参数用于指定允许访问白名单中的服务的对端地址。                   |
| NFAFID  | 该参数用于指定添加到白名单的服务的NFAFID。                   |
