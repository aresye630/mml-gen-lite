# 增加流行为下级联流策略（ADD QOSACTRDRPOLICY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于在流行为视图下级联一个流策略，前提是流策略已经配置。

#### 注意事项

- 该命令最大记录数为1。

- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                         |
|:-------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------|
| BEHAVIORNAME | 行为名称   | 可选必选说明：必选参数 参数含义：该参数用于指定流行为的名称，不允许为系统预定义策略default。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：需要先使用ADD MQCBEHAVIOR命令添加流行为。 |
| POLICYNAME   | 策略名称   | 可选必选说明：必选参数 参数含义：该参数用于指定流策略的名称，不允许为系统预定义策略default。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：需要先使用ADD MQCPOLICY命令增加流策略。   |

#### 使用实例

流行为下配置级联流策略：

```
ADD QOSACTRDRPOLICY:BEHAVIORNAME="2",POLICYNAME="1";
```
