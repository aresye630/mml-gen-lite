# 查询全局内容过滤模板（LST GLBCFTEMPLATE）

- 命令功能
- 注意事项

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于显示配置的全局的内容过滤模板。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

显示配置的全局的内容过滤模板：

```
LST GLBCFTEMPLATE:;
```

```
RETCODE = 0  操作成功
 
全局内容过滤模板信息
--------------------
内容过滤模板名称  =  test
(结果个数 = 1)
 
---    END
```
