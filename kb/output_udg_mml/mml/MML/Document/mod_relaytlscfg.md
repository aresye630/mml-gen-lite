# 修改媒体中继业务TLS认证配置（MOD RELAYTLSCFG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于修改Relay域名业务分别作为客户端或服务端认证属性。

#### 注意事项

该命令执行后对新数据流生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称      | 参数说明                                                                                                                                                                                                                                  |
|:--------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TLSCONFIGNAME | TLS配置名称   | 可选必选说明：必选参数 参数含义：该参数用于设置该Relay业务TLS配置描述。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                                                                  |
| UETLSPLYNAME  | UE认证策略名称  | 可选必选说明：可选参数 参数含义：该参数用于指定Relay作为服务端与UE客户端使用HTTPS方式连接时使用的TLS认证策略名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～31。不支持空格，不区分大小写。 默认值：无 配置原则： Relay与UE之间使用HTTPS时必须配置否则TLS协商失败。该参数来源于ADD SRVTLSPLY命令的“PLYNM”参数，可通过LST SRVTLSPLY命令查询获取。输入单空格将删除该参数已有配置项。 |
| CDNTLSPLYNAME | CDN认证策略名称 | 可选必选说明：可选参数 参数含义：该参数用于指定Relay作为客户端与CDN服务端使用HTTPS方式连接时使用的TLS认证策略名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～31。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数来源于ADD SRVTLSPLY命令的“PLYNM”参数，可通过LST SRVTLSPLY命令查询获取。输入单空格将删除该参数已有配置项。                                |
| CFGDOMAINNAME | 配置域名称     | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无                                                                                                                                                    |

#### 使用实例

假如需要修改一组媒体中继业务TLS认证配置，则命令如下：

```
MOD RELAYTLSCFG: TLSCONFIGNAME="douyintlscfg", UETLSPLYNAME="ue_douyinply";
```
