# 查询ICMP安全配置（LST ICMPSECURITY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询ICMP安全配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询系统ICMP安全配置实例：

```
LST ICMPSECURITY:;
```

```
        RETCODE = 0  操作成功。

        结果如下
        --------
            报文方向  =  接收报文
        ICMP配置类型  =  报文类型
        ICMP报文类型  =  回显请求：Type=8, Code=0
                类型  =  8
                编码  =  0
        ICMP配置开关  =  使能
        (结果个数 = 1)
        ---    END
```
