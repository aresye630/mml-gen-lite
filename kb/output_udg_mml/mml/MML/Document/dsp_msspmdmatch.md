# 显示端口报文匹配统计信息（DSP MSSPMDMATCH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

显示端口报文匹配统计信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                |
|:-------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CELLTYPE     | 微服务类型  | 可选必选说明：必选参数 参数含义：该参数用于指定微服务类型。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～63。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符。 默认值：无 配置原则：使用DSP PAENODE查看工作角色为数据转发对应的微服务类型。    |
| CELLINSTANCE | 微服务实例号 | 可选必选说明：必选参数 参数含义：该参数用于指定微服务实例号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～127。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符。 默认值：无 配置原则：使用DSP PAENODE查看工作角色为数据转发对应的微服务实例号。 |
| PORTID       | 端口号    | 可选必选说明：必选参数 参数含义：该参数用于表示端口ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无 配置原则：使用DSP MSSPORTINFO命令获取端口号。                                                                           |
| RXTXTYPE     | 收发包类型  | 可选必选说明：必选参数 参数含义：该参数用于表示收包或发包。 数据来源：本端规划 取值范围：枚举类型。 rx：接收报文统计。tx：发送报文统计。 默认值：无                                                                                                      |

#### 使用实例

显示微服务类型为104的微服务实例csdb-pod-0172-16-0-247\_\_103\_\_0的发送报文统计信息：

```
%%DSP MSSPMDMATCH: CELLTYPE="104", CELLINSTANCE="csdb-pod-0172-16-0-247__103__0", PORTID=2, RXTXTYPE=rx;%%
RETCODE = 0  操作成功

结果如下:
---------
      匹配规则ID  =  --
        开关状态  =  enable
 记录时间（min）  =  30
        匹配计数  =  607
记录报文功能使能  =  False
(结果个数 = 1)

---    END
```

#### 输出结果说明

| 输出项名称     | 输出项解释                                         |
|:----------|:----------------------------------------------|
| 匹配规则ID    | 用于表示匹配规则。 当SET MSSPMDMATCH输入参数RULELIST不为空时有值。 |
| 开关状态      | 用于表示统计开关的状态。                                  |
| 记录时间（min） | 用于表示统计的时长。                                    |
| 匹配计数      | 用于表示匹配包数。                                     |
| 记录报文功能使能  | 用于表示记录报文功能状态。                                 |
