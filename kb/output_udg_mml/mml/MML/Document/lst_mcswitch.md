# 查询多连接开关配置数据（LST MCSWITCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询多连接开关的配置。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

无

## 使用实例

查询多连接开关的配置：

```
%%LST MCSWITCH:;%%
RETCODE = 0  操作成功

结果如下
--------
多连接开关  =  开启
```

## 输出结果说明

| 输出项名称   | 输出项解释         |
|:--------|:--------------|
| 多连接开关   | 该参数用于表示多连接开关。 |
