# 设置策略类型和核查间隔（SET PLCYCKTIMERINR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置策略类型和核查间隔。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| POLICYTYPE   |   INTERVAL |
|:-------------|-----------:|
| Inner        |          1 |
| Outer        |         10 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称          | 参数说明                                                                                                             |
|:-----------|:--------------|:-----------------------------------------------------------------------------------------------------------------|
| POLICYTYPE | 策略类型          | 可选必选说明：必选参数  参数含义：该参数用于设置策略类型，Inner表示内部策略，Outer表示外部策略。  数据来源：本端规划 取值范围： Inner（内部策略）Outer（外部通信策略）  默认值：无。  配置原则：无 |
| INTERVAL   | 策略核查时间间隔 (分钟) | 可选必选说明：必选参数  参数含义：该参数用于设置策略核查时间间隔，单位分钟。  数据来源：本端规划  取值范围：整数类型，取值范围是1~4294967295，单位是分钟。  默认值：无。  配置原则：无           |

## 使用实例

设置策略类型和核查间隔，内部策略用Inner，外部策略用Outer，核查间隔单位为分钟。

```
%%SET PLCYCKTIMERINR: POLICYTYPE=Inner, INTERVAL=1;%%
RETCODE = 0  操作成功

---    结束
```
