# 设置流量转发APN开关（SET APNTRAFDFUNC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

设置流量转发APN开关，当TRAFFICFDSW配置为ENABLE时，UPF支持通过VXLAN隧道转发数据流到MPF，否则不支持。

#### 注意事项

- 该命令执行后立即生效。
- 系统最多支持配置10000条。
- 初始值均为DISABLE。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                |
|:------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------|
| APN         | APN    | 可选必选说明：必选参数 参数含义：该参数用于指定APN实例名。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数使用ADD APN命令配置生成。该参数必须已经通过ADD APN命令配置。 |
| TRAFFICFDSW | 流量转发开关 | 可选必选说明：必选参数 参数含义：该参数用于配置是否开启流量转发功能。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无                                        |

#### 使用实例

设置APN apn1的流量转发开关为ENABLE：

```
SET APNTRAFDFUNC: APN="apn1", TRAFFICFDSW=ENABLE;
```
