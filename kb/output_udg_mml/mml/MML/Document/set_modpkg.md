# 设置模型老化配置（SET MODPKG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于设置指定网元下的模型老化配置信息，包括老化空间和老化模型个数。

#### 注意事项

设置的模型老化配置场景，必须在对应的业务类型中存在。

#### 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                                    |
|:-------------|:---------|:--------------------------------------------------------------------------------------------------------|
| MEID         | 网元ID     | 可选必选说明：必选参数。 参数含义：设置模型老化配置信息的网元ID。 取值范围：整数类型，取值范围为0~65535。 默认值：无。 配置原则：网元ID可通过LST ME命令查询获得。             |
| BUSINESSTYPE | 业务类型     | 可选必选说明：必选参数。 参数含义：设置模型老化配置信息的业务类型。 取值范围： “TRAIN（训练）”：业务类型为训练。“INFER（推理）”：业务类型为推理。 默认值：无。 配置原则：无。        |
| SCENETYPE    | 场景       | 可选必选说明：必选参数。 参数含义：设置模型老化配置信息的场景。 取值范围：字符串类型，长度1~128。 默认值：无。 配置原则：只能包括大小写字母、数字、中划线-、下划线_、英文句号.。长度最大为128。 |
| TOTALSIZE    | 老化空间（MB） | 可选必选说明：必选参数。 参数含义：设置模型老化配置信息的老化空间大小。 取值范围：整数类型，取值范围为1~10240。 默认值：无。 配置原则：无。                             |
| FILENUM      | 老化模型个数   | 可选必选说明：必选参数。 参数含义：设置模型老化配置信息的老化模型个数。 取值范围：整数类型，取值范围为2~50。 默认值：无。 配置原则：无。                                |

#### 使用实例

1、设置网元ID=0，业务类型为“TRAIN”，场景为“PROTOCOL\_CLASSIFY”，老化空间为60（MB）和老化模型个数为44的模型老化配置信息。

```
%%SET MODPKG: MEID=0, BUSINESSTYPE=TRAIN, SCENETYPE="PROTOCOL_CLASSIFY", TOTALSIZE=60, FILENUM=44;%%
RETCODE = 0  操作成功
---    END
```

2、设置网元ID=0，业务类型为“INFER”，场景为“FACE\_RECOGNITION”，老化空间为62（MB）和老化模型个数为46的模型老化配置信息。

```
%%SET MODPKG: MEID=0, BUSINESSTYPE=INFER, SCENETYPE="FACE_RECOGNITION", TOTALSIZE=62, FILENUM=46;%%
RETCODE = 0  操作成功
---    END
```

#### 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 181001 | 下发的MML参数不正确。   | 非法的命令参数。                   | 请检查输入的命令参数或联系华为技术支持。 |
| 181002 | 系统内部错误，请联系管理员。 | 执行过程中可能存在网络故障或者服务不可用等异常因素。 | 等待几分钟后重试。            |
| 181040 | 输入的场景不存在。      | 该场景在对应的业务类型下不存在。           | 请检查输入的场景在对应业务类型是否注册。 |
