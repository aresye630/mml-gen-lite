# 查询证书（DSP CERTFILE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询OM Portal内在“安全 > 证书管理 > 证书与证书集管理”页面内显示的所有证书。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                     |
|:---------|:-------|:-------------------------------------------------------------------------|
| CERTNAME | 证书名称   | 可选必选说明：可选参数。 参数含义：证书文件名称，支持模糊查询。 取值范围：字符串类型，输入长度范围为0~192。 默认值：无。 配置原则：无。 |

## 使用实例

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息，输出结果说明如表1所示。

命令执行异常，请联系华为技术支持处理。输出结果说明如表2所示。

| 输出项名称     | 输出项解释                                                                                   |
|:----------|:----------------------------------------------------------------------------------------|
| 证书名称      | 用于标识一个数字证书，在同一个作用域内证书名称必须唯一。                                                            |
| 证书类型      | 证书类型。 取值范围包括： CA证书设备证书证书集                                                               |
| 创建时间      | 证书创建时间。                                                                                 |
| 证书CN Name | 证书CN Name。                                                                              |
| 序列号       | 证书序列号。  说明： 证书序列号为整型。由于各系统解析规则可能存在差异，前缀可能存在一到两位0，CertMgr服务存储的十六进制证书序列号会省略前缀0，实际取值含义无差异。 |
| 颁发者       | 证书颁发者。                                                                                  |
| 持有者       | 证书持有者。                                                                                  |
| 生效时间      | 证书生效时间。                                                                                 |
| 失效时间      | 证书失效时间。                                                                                 |
| 到期天数      | 距离证书失效的天数。                                                                              |
| 吊销列表分发点   | 证书对应吊销列表的分发点。                                                                           |
| 状态        | 证书当前状态。 取值范围包括： 正常即将过期已过期                                                               |
| 关联状态      | 证书的关联状态。 取值范围包括： 已关联未关联                                                                 |
| 所属应用      | 证书所属的网元。                                                                                |
| 场景名称      | 证书使用场景。                                                                                 |

|    错误码 | 错误码解释   | 原因分析    | 处理建议       |
