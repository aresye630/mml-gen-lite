#### 命令功能

**适用NF：PGW-U、UPF**

该命令用来查询AES256加密算法的IV值。当重定向或者头增强配置需要对imsi、msisdn、imei、msip进行AES256加密处理时，使用该数值作为加密算法的IV值。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询AES256加密算法的IV值，查询命令如下：

```
LST AES256:;
```

```
RETCODE = 0  操作成功。

AES256加密算法的IV值信息
---------------------------------
    重定向随机IV值开关 = 不使能
重定向动作AES256的IV值 = *****
    头增强随机IV值开关 = 不使能
头增强动作AES256的IV值 = *****

---    END
```
