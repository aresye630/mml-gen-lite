# 显示PAE网络配置信息（DSP PAENETWORKCFG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示PAE网络配置信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                    |
|:-------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CELLTYPE     | 微服务类型  | 可选必选说明：可选参数 参数含义：该参数用于指定微服务类型。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～63。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符。 默认值：无 配置原则：使用DSP PAENODE查看微服务类型。    |
| CELLINSTANCE | 微服务实例号 | 可选必选说明：可选参数 参数含义：该参数用于指定微服务实例号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～127。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符。 默认值：无 配置原则：使用DSP PAENODE查看微服务实例号。 |

#### 使用实例

查询微服务类型“aa”微服务实例“bb”的网络配置信息：

```
%%DSP PAENETWORKCFG: CELLTYPE="aa", CELLINSTANCE="bb";%%
RETCODE = 0  操作成功

结果如下:
-------------------------
微服务类型   微服务实例号 平面类型  组网类型  IP版本号  IP模式     报文是否转发到网关  封装类型
aa           bb           数据平面  L2        IPv4      SYSASSIGN  否                  UDP_LITE  
aa           bb           控制平面  L2        IPv4      SYSASSIGN  否                  UDP 
(结果个数 = 2)

---    END
```

#### 输出结果说明

| 输出项名称     | 输出项解释                                                     |
|:----------|:----------------------------------------------------------|
| 微服务类型     | 用于指定微服务类型。                                                |
| 微服务实例号    | 用于指定微服务实例号。                                               |
| 平面类型      | 显示PAE平面类型： 数据平面：PAE数据平面 控制平面：PAE控制平面                      |
| 组网类型      | PAE的组网类型： L2：二层组网L3：三层组网                                  |
| IP版本号     | 显示IP版本号。                                                  |
| IP模式      | 获取IP的模式： DHCP：动态分配IP模式SYSASSIGN：系统分配IP模式INJECT：外部注入分配IP模式 |
| 报文是否转发到网关 | 报文是否转发到网关。                                                |
| 封装类型      | 报文封装类型： UDP：UDP协议封装UDP_LITE：UDP_LITE协议封装                  |
