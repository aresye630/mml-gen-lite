# 查询NF的锁定信息（LST NF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于查询NF的状态。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询当前所有的NF的信息：

```
LST NF:;
```

```
RETCODE = 0  操作成功

NF信息
--------------
NF锁定状态开关  =  使能
(结果个数 = 1)

---    结束
```

#### 输出结果说明

| 输出项名称    | 输出项解释                         |
|:---------|:------------------------------|
| NF锁定状态开关 | 使能时，NF为锁定状态，该参数为不使能时，NF为解锁状态。 |
