# 查询服务实例地址数（DSP SRVADDRNUM）

- 命令功能

- 操作用户权限

- 使用实例

#### 命令功能

查询业务VNFC服务实例地址数量。用于核对业务VNFC的服务实例地址数量、CSLB的服务实例地址数量以及VNRS的路由数量是否一致。 CSLB查询到的一条服务实例地址对应VNRS上查询到的一条路由。

#### 注意事项

- 如果业务VNFC和CSLB的服务实例地址数量不一致，需要业务VNFC确认是否存在服务实例地址丢失。如果存在丢失，执行如下命令，触发服务实例地址的重配置，恢复业务。

  **ACT SRVRECFG**: SRVTYPE=SRVADDR;
- 如果CSLB和VNRS的服务实例地址数量不一致，需要业务VNFC确认是否存在服务实例地址丢失。如果存在丢失，执行命令**SYN LBSRVADDR**，触发服务实例地址的批量同步，恢复业务。
- 该命令批量下发可能导致执行超时。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                                                      |
|:-------------|:---------|:--------------------------------------------------------------------------------------------------------------------------|
| SRVVNFCID    | 业务VNFCID | 可选必选说明：可选参数 参数含义：该参数用于指定业务VNFC的唯一标识，通过在窗口下执行LST NODE获得，所得NODE ID即为服务VNFC ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0~4294967295。 默认值：无 |
| SERVICEINDEX | 服务实例ID   | 可选必选说明：可选参数 参数含义：业务VNFC定义的服务实例ID，通过DSP LBSRVINST查询获取。 数据来源：本端规划 取值范围：整数类型，取值范围为0~4294967295。 默认值：无                        |

#### 使用实例

- 查询所有业务VNFC的服务实例地址数。

  `DSP SRVADDRNUM: ;`

  ```
  %%DSP SRVADDRNUM: ;%%
  RETCODE = 0  操作成功。

  操作结果如下：
  -------------------------
  服务VNFC ID = 4
  服务实例ID = 0
  服务实例地址数 = 9
  (结果个数 = 1)
  --- END
  ```
- 查询指定业务VNFC的服务实例地址数。

  `DSP SRVADDRNUM: SRVVNFCID=4;`

  ```
  %%DSP SRVADDRNUM: SRVVNFCID=4;%%
  RETCODE = 0  操作成功。

  操作结果如下：
  -------------------------
  服务VNFC ID = 4
  服务实例ID = 0
  服务实例地址数 = 9
  (Number of results = 1)
  --- END
  ```

#### 输出结果说明

| 输出项名称     | 输出项解释                                                |
|:----------|:-----------------------------------------------------|
| 服务VNFC ID | 参数含义：业务VNFC的唯一标识。 取值范围：整数类型，取值范围为0~4294967295。       |
| 服务实例ID    | 参数含义：业务VNFC定义的服务实例ID。 取值范围：整数类型，取值范围为0~4294967295。   |
| 服务实例地址数   | 参数含义：指定业务VNFC的服务实例地址数量。 取值范围：整数类型，取值范围为0~4294967295。 |
