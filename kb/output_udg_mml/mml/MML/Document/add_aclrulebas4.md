# 增加基本ACL规则（ADD ACLRULEBAS4）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于增加基本ACL规则。访问控制列表ACL(Access Control List)是应用到设备接口的指令列表。ACL规则规定了符合某种特征的IP报文处理策略。基本ACL规则支持按照源IP进行报文匹配。主要应用场景为路由策略，端口流量策略以及路由过滤策略等。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为65535。
- 增加ACL规则前必须先执行ADD ACLGROUP指定所在规则组，单个ACL规则组下最多支持16384条ACL规则。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识               | 参数名称     | 参数说明                                                                                                                                                                                                                                                                   |
|:-------------------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ACLNAME            | ACL规则组标识 | 可选必选说明：必选参数 参数含义：该参数用于指定规则属于哪个规则组。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。不支持空格，区分大小写。以英文字母a～z或A～Z开始，可以是英文字母、数字、连字符“-”、下划线“_”或中文字符的组合。整数形式，取值范围是2000～2999。 默认值：无                                                                                                             |
| ACLRULENAME        | 规则名称     | 可选必选说明：必选参数 参数含义：该参数用于指定规则名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。不支持空格，区分大小写。 默认值：无                                                                                                                                                                                      |
| ACLRULEID          | 规则ID     | 可选必选说明：可选参数 参数含义：该参数用于指定规则的ID。如果不输入该参数，则规则ID按照规则组步长增长。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967294。 默认值：无 配置原则：当某类数据流能与指定规则组中的多条规则匹配时，实际生效的是规则号最低的规则。                                                                                                                        |
| ACLACTION          | 规则行为     | 可选必选说明：必选参数 参数含义：该参数用于指定对符合本规则的报文采取的动作。 数据来源：本端规划 取值范围：枚举类型。 Permit：允许符合该规则的访问。Deny：拒绝符合该规则的访问。 默认值：无                                                                                                                                                                  |
| ACLFRAGTYPE        | 报文分片类型   | 可选必选说明：可选参数 参数含义：该参数用于指定规则所的报文分片类型，共有分片报文中的首片、分片报文中的非首片、非分片报文三种报文类型。如果不输入该参数，则表示不校验报文的分片信息。 数据来源：本端规划 取值范围：枚举类型。 FragmentSubseq：检查分片报文中的非首片。Fragment：检查报文是否为分片报文。NonFragment：检查非分片报文。NonSubseq：检查分片报文中的首分片，或非分片报文。FragmentSpeFirst：检查分片报文中的首片。Unconfiged：清除分片配置。 默认值：无 |
| ACLSOURCEIP        | 源IP地址    | 可选必选说明：可选参数 参数含义：该参数用于指定规则要匹配的源IPv4地址。 数据来源：全网规划 取值范围：IPv4地址类型。0.0.0.0～255.255.255.255。 默认值：0.0.0.0 配置原则：根据需要匹配的IP报文的源地址范围来设置该参数。                                                                                                                                      |
| ACLSRCWILD         | 源IP地址反掩码 | 可选必选说明：可选参数 参数含义：该参数用于指定规则要匹配的源IPv4地址反掩码。 数据来源：全网规划 取值范围：IPv4地址类型。0.0.0.0～255.255.255.255。 默认值：255.255.255.255 配置原则：根据需要匹配的IP报文的源地址范围来设置该参数。                                                                                                                           |
| VRFNAME            | VPN实例名称  | 可选必选说明：可选参数 参数含义：该参数用于指定规则匹配要生效的VPN实例。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。字符之间不支持空格，区分大小写。 默认值：_public_ 配置原则： 使用LST L3VPNINST命令查看可用VPN。当前添加ACL规则时不支持配置VPN。                                                                                                               |
| ACLRULEDESCRIPTION | 规则描述     | 可选必选说明：可选参数 参数含义：该参数用于指定规则描述。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～127。支持空格，区分大小写。 默认值：无 配置原则：建议取有实际意义的名称，以方便识别。                                                                                                                                                              |

#### 使用实例

用户使用流分类，需要过滤源IP地址为10.1.1.1的报文，可以配置基本ACL规则：

```
ADD ACLRULEBAS4: ACLNAME="2000",ACLRULENAME="rule_5",ACLACTION=Deny,ACLSOURCEIP="10.1.1.1",ACLSRCWILD="0.0.0.0";
```
