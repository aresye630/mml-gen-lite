# 设置媒体中继全局回源TCP控制（SET GLBRLYOTCPCTRL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、PGW-U**

该命令用于设置媒体中继全局回源TCP控制。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   |   IPV4MSS |   SENDBUFSIZE |   REVBUFSIZE |   IPV6MSS |
|:-------|----------:|--------------:|-------------:|----------:|
| 初始值    |      1460 |            20 |          512 |      1440 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称         | 参数说明                                                                                    |
|:------------|:-------------|:----------------------------------------------------------------------------------------|
| IPV4MSS     | IPv4最大报文段长度  | 可选必选说明：可选参数 参数含义：该参数用于指定IPv4最大报文段长度。 数据来源：本端规划 取值范围：整数类型，取值范围是为536～1460。 默认值：无 配置原则：无   |
| SENDBUFSIZE | 发送缓冲区大小（千字节） | 可选必选说明：可选参数 参数含义：该参数用于指定发送缓冲区大小。 数据来源：本端规划 取值范围：整数类型，取值范围是为10～100，单位是千字节。 默认值：无 配置原则：无  |
| REVBUFSIZE  | 接收缓冲区大小（千字节） | 可选必选说明：可选参数 参数含义：该参数用于指定接收缓冲区大小。 数据来源：本端规划 取值范围：整数类型，取值范围是为10～4096，单位是千字节。 默认值：无 配置原则：无 |
| IPV6MSS     | IPv6最大报文段长度  | 可选必选说明：可选参数 参数含义：该参数用于指定IPv6最大报文段长度。 数据来源：本端规划 取值范围：整数类型，取值范围是为536～1440。 默认值：无 配置原则：无   |

#### 使用实例

设置媒体中继全局回源TCP控制：

```
SET GLBRLYOTCPCTRL: IPV4MSS=1460, IPV6MSS=1000;
```
