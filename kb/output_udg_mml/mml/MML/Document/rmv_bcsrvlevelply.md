# 删除带宽管理控策略制器业务级别（RMV BCSRVLEVELPLY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于删除指定BWM控制器下，特定ServiceLevel的业务流量保证带宽比例和峰值带宽比例。

#### 注意事项

- 该命令执行后立即生效。
- 如果执行批量删除操作，需要开启软参BYTE692。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称      | 参数说明                                                                                                                                                                   |
|:-------------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| BWMCNAME     | 带宽管理控制器名称 | 可选必选说明：可选参数 参数含义：该参数用于表示带宽管理控制器的名字。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：不输入此参数表示删除所有“BCSrvLevelPly”配置。输入“ServiceLevel”参数时必须输入“BwmcName”参数。       |
| SERVICELEVEL | 业务级别      | 可选必选说明：可选参数 参数含义：该参数用于指定使用同一控制器的不同业务流间的优先级，值越小优先级越高。如果配置优先级，优先保证高优先级的带宽。 数据来源：本端规划 取值范围：整数类型，取值范围为1～30。 默认值：无 配置原则：不输入此参数表示删除指定BwmController下所有业务级别的“BCSrvLevelPly”配置。 |

#### 使用实例

删除带宽管理控制器“bc1”下业务级别为1的控制策略：

```
RMV BCSRVLEVELPLY: BWMCNAME="bc1", SERVICELEVEL=1;
```
