# 删除对应PODTYPE的配置记录（RMV PODHEALCPUTHR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除对应PODTYPE的CPU使用率阈值配置。

## 注意事项

- 该命令执行后立即生效。

- 该命令已废弃。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                             |
|:--------|:-------|:---------------------------------------------------------------------------------|
| PODTYPE | POD类型  | 可选必选说明：必选参数  参数含义：用于设置POD类型。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无 |

## 使用实例

删除对应PODTYPE的CPU使用率阈值配置。

```
%%RMV PODHEALCPUTHR: PODTYPE="vha-pod";%%
RETCODE = 0  操作成功

---    END
```
