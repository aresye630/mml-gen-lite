# 查询VXLAN隧道端点绑定隧道组（LST VTEPBINDGRP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询VXLAN隧道端点与隧道组的绑定关系。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                            |
|:-------------|:---------|:------------------------------------------------------------------------------------------------|
| VXLANGRPNAME | VXLAN组名称 | 可选必选说明：可选参数 参数含义：该参数用于指定VXLAN隧道组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

查询VXLAN隧道组为vxlangrp的绑定关系的相关信息：

```
LST VTEPBINDGRP: VXLANGRPNAME="vxlangrp";
```
