# 删除媒体中继IP信息（RMV RELAYIPINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，删除该配置后，会导致媒体中继业务中断。

该命令用于删除媒体中继IP信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称       | 参数说明                                                                                                                           |
|:--------------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------|
| RELAYIPNAME   | 媒体中继IP地址名称 | 可选必选说明：必选参数 参数含义：该参数用于表示媒体中继服务IP配置。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无                                |
| IPSERVICETYPE | IP业务类型     | 可选必选说明：可选参数 参数含义：该参数用于表示IP业务类型。 数据来源：本端规划 取值范围：枚举类型。 GROUPIP：表示填写的IP地址是组级IP。REDIRECTIP：表示填写的IP地址是重定向IP。 默认值：无 配置原则：无           |
| INSTID        | 实例ID       | 可选必选说明：条件可选参数 前提条件：该参数在“IPSERVICETYPE”配置为“REDIRECTIP”时为可选参数。 参数含义：该参数用于表示实例ID。 数据来源：本端规划 取值范围：对应RelayPodID(0~15)。 默认值：无 配置原则：无 |

#### 使用实例

删除服务IP配置为test的IP信息：

```
RMV RELAYIPINFO:  RELAYIPNAME="test";
```
