# 修改TWAMP发送端（MOD TWAMPSENDER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于修改TWAMP发送端。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                            |
|:------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------|
| CLIENTID    | 客户端ID  | 可选必选说明：必选参数  参数含义：该参数用于配置客户端ID。  数据来源：全网规划  取值范围：整数类型，取值范围是1~12000。  默认值：无  配置原则：  CLIENTID必须在ADD TWAMPCLIENT已经配置，可以用LST TWAMPCLIENT查询。         |
| MODE        | 会话发送类型 | 可选必选说明：可选参数  参数含义：该参数用于会话发送类型。  数据来源：全网规划 取值范围： CONTINUAL（连续统计）  默认值：无  配置原则：无                                                                  |
| DSCP        | 差分服务码  | 可选必选说明：可选参数  参数含义：该参数用于配置差分服务码。  数据来源：全网规划  取值范围：整数类型，取值范围是0~63。  默认值：无  配置原则：无                                                                 |
| PKTSIZETYPE | 报文类型   | 可选必选说明：可选参数  参数含义：该参数用于配置报文类型。  数据来源：全网规划 取值范围： FIXED（固定报文长度）RANDOM（报文随机填充）  默认值：无  配置原则：无                                                      |
| PKTSIZE     | 报文长度   | 可选必选说明：该参数在"PKTSIZETYPE"配置为"FIXED"时为条件可选参数。  参数含义：该参数用于配置报文长度。  数据来源：全网规划  取值范围：整数类型，取值范围是69~1500，单位是字节。该参数取值范围上限不能超过外联口配置的MTU值。  默认值：无  配置原则：无 |
| PADDINGTYPE | 报文填充类型 | 可选必选说明：可选参数  参数含义：该参数用于配置报文填充类型。  数据来源：全网规划 取值范围： PADDING_ZERO（报文全零填充）PADDING_RANDOM（报文随机填充）  默认值：无  配置原则：无                                     |
| PERIOD      | 报文发送周期 | 可选必选说明：可选参数  参数含义：该参数用于配置报文发送周期。  数据来源：全网规划  取值范围：整数类型，取值范围是10~100。单位：10毫秒。  默认值：无  配置原则：无                                                      |
| TIMEOUT     | 超时时间   | 可选必选说明：可选参数  参数含义：该参数用于配置超时时间。  数据来源：全网规划  取值范围：整数类型，取值范围是1~10，单位是秒。  默认值：无  配置原则：无                                                             |

## 使用实例

修改客户端ID为1的发送端实例：

```
MOD TWAMPSENDER: CLIENTID=1, MODE=CONTINUAL, DSCP=0, PKTSIZETYPE=FIXED, PKTSIZE=128, PADDINGTYPE=PADDING_RANDOM, PERIOD=100, TIMEOUT=5;
```
