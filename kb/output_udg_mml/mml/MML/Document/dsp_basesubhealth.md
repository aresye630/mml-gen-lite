# 显示base链路亚健康信息（DSP BASESUBHEALTH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示base链路亚健康信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                               |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------------|
| SRCRUNAME       | 本端RU名  | 可选必选说明：必选参数 参数含义：本端RU名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63，不支持空格。 默认值：无                                              |
| DSTRUNAME       | 对端RU名  | 可选必选说明：可选参数 参数含义：对端RU名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63，不支持空格。 默认值：无                                              |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取，不支持空格。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

显示base链路亚健康信息：

```
DSP BASESUBHEALTH:SRCRUNAME="VNODE_CSLB_VNFC_OMU_0001",SERVICEINSTANCE="vnfc";
```
