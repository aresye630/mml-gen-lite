# 查询CSDB数据表信息（DSP DBTBL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询CSDB指定实例的数据表的信息，包括数据表名称、数据表记录个数、数据表的节点分布信息。

#### 注意事项

针对参数"CSTYPE" （客户端服务端类型）取值为“CLIENT”的查询，存在如下约束：

- 通过命令**DSP DBINSTANCE**查询CSDB子实例信息时， 返回信息中初始容量和总容量为0的不支持查询。
- 通过命令**DSP DBINSTANCE**查询CSDB子实例信息时， 返回信息中初始容量和总容量不为0，但是通过命令**DSP DBPLUGIN**查询CSDB插件信息时，返回信息为“NLS或插件不存在”的不支持查询。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称        | 参数说明                                                                                                                                         |
|:-----------|:------------|:---------------------------------------------------------------------------------------------------------------------------------------------|
| INSTANCEID | 子实例标识       | 可选必选说明：必选参数。 参数含义：该参数用于指定唯一一个子实例，可以通过DSP DBINSTANCE命令查询获取。 数据来源：本端规划 取值范围：1～100。 默认值：无。                                                      |
| TBLID      | 数据表标识       | 可选必选说明：可选参数。 参数含义：该参数用于指定唯一一张数据表。 数据来源：本端规划 取值范围：0～4095。 默认值：无。 配置原则：如果不指定数据表标识，则显示所有数据表的信息。                                                 |
| CSTYPE     | 客户端服务端类型    | 可选必选说明：必选参数。 参数含义：该参数用于指定是客户端还是服务端。 数据来源：本端规划 取值范围：“CLIENT”：显示客户端的数据表信息。“SERVER”：显示服务端的数据表信息。 默认值：无。                                         |
| VNFCID     | 虚拟化网络功能组件标识 | 可选必选说明：条件可选参数。 参数含义：该参数用于指定客户端进程所在的VNFC标识，可以通过DSP DBINSTANCE命令查询获取。 前提条件：该参数在“CSTYPE”参数设置为“CLIENT”后生效。 数据来源：本端规划 取值范围：0～4294967295。 默认值：无。   |
| RUNAME     | 资源单元名称      | 可选必选说明：条件可选参数。 参数含义：该参数用于指定服务端进程所在的资源单元名称，可以通过LST SERVICERUSTATE命令查询获取。 前提条件：该参数在“CSTYPE”参数设置为“SERVER”后生效。 数据来源：本端规划 取值范围：不超过63个英文字符。 默认值：无。 |

#### 输出结果说明

| 输出项名称       | 输出项解释                                                                                                                                  |
|:------------|:---------------------------------------------------------------------------------------------------------------------------------------|
| 数据表标识       | 唯一标识一张数据表。 取值范围：0～4095。                                                                                                                |
| 数据表名称       | 数据表名称。 取值范围：不超过63个英文字符。                                                                                                                |
| 虚拟化网络功能组件标识 | 客户端进程所在的VNFC标识。 取值范围：0～4294967295。  说明： 信息统计行中，该参数无输入值时，输出项取无效值：NULL，有输入值时，输出项显示输入值。                                                   |
| 插件标识        | 客户端进程指定的插件标识。 取值范围：0～4294967295。  说明： 信息统计行中，插件标识取无效值：NULL。                                                                            |
| 资源单元名称      | 描述服务端进程所在的资源单元名称。  说明： 信息统计行中，该参数无输入值时，输出项取无效值：NULL，有输入值时，输出项显示输入值。                                                                    |
| 节点类型        | 节点类型。 取值范围： 控制节点（PRP进程）。存储节点（DNP进程）。                                                                                                   |
| 同类进程实例号     | 同类型进程在资源单元内的排序序号，从0开始排序。 取值范围：0～63。  说明： 信息统计行中，节点序号取无效值：NULL。                                                                         |
| 数据表的实际记录个数  | 数据表实际存储的记录个数。 取值范围：0～4294967295。                                                                                                       |
