# 添加LDP认证组（ADD LDPAUTHGROUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于添加LDP认证组。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识              | 参数名称          | 参数说明                                                                                                                                                                                                                                                                                                   |
|:------------------|:--------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VRFNAME           | VPN实例名称       | 可选必选说明：可选参数 参数含义：该参数用于指定VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：_public_                                                                                                                                                                                                                        |
| AUTHPEERGROUPNAME | 认证组名称         | 可选必选说明：必选参数 参数含义：该参数用于指定认证组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～169。 默认值：无 配置原则： 所用的IP前缀名需提前配好。只能配置一个LDP认证组。                                                                                                                                                                                              |
| AUTHENTYPE        | LDP认证类型       | 可选必选说明：必选参数 参数含义：该参数用于指定LDP认证类型。 数据来源：本端规划 取值范围：枚举类型。 MD5：MD5认证类型。MD5验证是在TCP发出去之前进行的：LDP消息在经TCP发出前，会在TCP头后面填充一个唯一的信息摘要再发出。KEYCHAIN：Keychain认证类型。Keychain类似于MD5，针对同一段信息计算出对应的信息摘要，实现LDP报文防篡改校验。Keychain允许用户定义一组密码，形成一个密码串，并且分别为每个密码指定加解密算法及密码使用的有效时间。 默认值：无 配置原则：在使用中需要注意，MD5属于不安全的加密算法，建议使用Keychain认证。 |
| MD5PASSWORD       | 认证组MD5密码      | 可选必选说明：条件必选参数 前提条件：该参数在“AUTHENTYPE”配置为“MD5”时为必选参数。 参数含义：该参数用于指定认证组MD5密码。 数据来源：本端规划 取值范围：密码类型，输入长度范围为1～255。 默认值：无 配置原则：配置的密码建议至少包含大写、小写、数字、特殊字符中的2种，并且长度不能小于6。                                                                                                                                          |
| KEYCHAINNAME      | 认证组KeyChain名字 | 可选必选说明：条件必选参数 前提条件：该参数在“AUTHENTYPE”配置为“KEYCHAIN”时为必选参数。 参数含义：该参数用于指定认证组KeyChain名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～47。 默认值：无 配置原则：所用的KeyChain名字需提前配好。                                                                                                                                                    |

#### 使用实例

添加LDP认证组：

```
ADD LDPAUTHGROUP:VRFNAME="_public_",AUTHPEERGROUPNAME="bb",AUTHENTYPE=KEYCHAIN,KEYCHAINNAME="key1";
```
