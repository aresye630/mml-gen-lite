# 导出测量结果文件(EXP MEASRST)

- 命令功能
- 注意事项

- 输出结果说明

## 命令功能

该命令用于导出网元的测量结果文件。

## 注意事项

该命令最多支持同时下发4个并发导出任务，建议不同的任务导出到不同的目标目录下。

如果下发的并发任务存在导出相同名称的话统结果文件，且目标目录相同，会出现并发任务之间上传文件冲突，只有最后一个任务可全部导出成功，其他任务可能呈现部分文件导出失败。

在升级场景下，为兼容低版本需要，系统会在对接SFTP时针对安全算法使用兼容方式处理。

## 参数说明

| 参数标识         | 参数名称          | 参数说明                                                                                                           |
|:-------------|:--------------|:---------------------------------------------------------------------------------------------------------------|
| MEID         | 网元ID          | 可选必选说明：必选参数。 参数含义：标识网元ID，可以通过LST ME命令查询获取。 取值范围：0~65535。 默认值：无。 配置原则：无。                                        |
| SERVERIPTYPE | SFTP服务器IP地址类型 | 可选必选说明：必选参数 参数含义：用于标识SFTP服务器的IP地址类型。 取值范围： IPV4(IPV4) IPV6(IPV6) 默认值：无。 配置原则：无。                                |
| IPV4         | SFTP服务器IP地址   | 可选必选说明：该参数在“SFTP服务器IP地址类型”配置为“IPV4(IPV4)”时为条件必选参数。 参数含义：标识SFTP服务器的IP地址。 取值范围：合法的IPv4地址。 默认值：无。 配置原则：无。         |
| IPV6         | SFTP服务器IP地址   | 可选必选说明：该参数在“SFTP服务器IP地址类型”配置为“IPV6(IPV6)”时为条件必选参数。 参数含义：标识SFTP服务器的IP地址。 取值范围：合法的IPv6地址。 默认值：无。 配置原则：无。         |
| FTPUSER      | SFTP用户名       | 可选必选说明：必选参数 参数含义：用于标识登录SFTP服务器的用户名。 取值范围：字符串类型，长度不超过128个字符。 默认值：无。 配置原则：无。                                     |
| FTPPSSWD     | SFTP密码        | 可选必选说明：必选参数 参数含义：用于标识登录SFTP服务器的密码。 取值范围：字符串类型，长度不超过128个字符。 默认值：无。 配置原则：无。                                      |
| DSTF         | 目标目录          | 可选必选说明：必选参数 参数含义：用于标识SFTP传输的目标路径。 取值范围：字符串类型，长度不超过256个字符。 默认值：无。 配置原则：无。                                       |
| FTPPORT      | SFTP端口号       | 可选必选说明：可选参数 参数含义：用于标识SFTP服务器的端口号。 取值范围：1～65535。 默认值：22。 配置原则：需要和真实的SFTP服务器端口一致，不填写则使用默认端口22。                   |
| PRD          | 测量周期          | 可选必选说明：必选参数。 参数含义：标识导出的周期。 取值范围： ALL(全部)FIVE(5分钟)FIFTEEN(15分钟)THIRTY(30分钟)SIXTY(1小时)ONE_DAY(一天) 默认值：无。 配置原则：无。 |
| SDT          | 导出起始时间        | 可选必选说明：必选参数。 参数含义：导出起始时间。 取值范围：年月日时分秒，规则为YYYY/MM/DD HH:MM:SS。 默认值：客户端当前时间。 配置原则：无。                             |
| EDT          | 导出结束时间        | 可选必选说明：必选参数。 参数含义：导出结束时间。 取值范围：年月日时分秒，规则为YYYY/MM/DD HH:MM:SS。 默认值：客户端当前时间。 配置原则：无。                             |

导出网元测量结果文件：

