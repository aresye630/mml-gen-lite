# 设置PFCP上报业务运行信息功能的管理参数（SET PFCPSRVRPT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用来设置PFCP上报业务运行信息功能的管理参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令执行后对后续流程生效。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | SWITCH   |   INTERVAL | BASICCAPSW   |   BASICCAP | QANACAPSW   |   QANACAP | QEXPCAPSW   |   QEXPCAP | MEDIARELAYCAPSW   |   MEDIARELAYCAP |
|:-------|:---------|-----------:|:-------------|-----------:|:------------|----------:|:------------|----------:|:------------------|----------------:|
| 初始值    | DISABLE  |         20 | DISABLE      |          0 | DISABLE     |         0 | DISABLE     |         0 | DISABLE           |               0 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

#### 使用实例

设置PFCP上报业务运行信息功能的业务信息上报开关为开：

```
SET PFCPSRVRPT: SWITCH=ENABLE;
```
