# 增加流行为（ADD MQCBEHAVIOR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于创建流行为；在复杂流分类的QoS策略中，如果需要对某类流执行相同的流行为，则需要用该命令创建流行为并在流行为中配置流动作。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为8192。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                      |
|:-------------|:-------|:----------------------------------------------------------------------------------------------------------|
| BEHAVIORNAME | 行为名称   | 可选必选说明：必选参数 参数含义：指定流行为名称。定义的行为名不允许为系统预定义的流行为be。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：区分大小写，不支持空格。 |

#### 使用实例

创建流行为b1：

```
ADD MQCBEHAVIOR:BEHAVIORNAME="b1";
```
