# 增加监控VPN实例（ADD MONVPN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于增加监控VPN实例。

## 注意事项

- 该命令执行后立即生效。

- 该命令适用于支持热备容灾的网元执行。
- 添加监控VPN实例后，如果监控中的单个VPN实例的邻居全部异常则上报告警“ALM-100545 容灾组中监控VPN邻居状态异常”。
- 在运行状态为主的容灾实例中，如果任意一个VPN组内所有监控的VPN实例内邻居全部异常，则自动发起容灾实例的主备倒换。
- 在运行状态为备的容灾实例中，如果任意一个VPN组内所有监控的VPN实例内邻居全部异常，则收到运行主容灾实例的倒换请求后将回应不允许倒换。
- 该命令执行前，请确保ISLINKED设置正确，否则可能造成误隔离。

- 最多可输入160条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                                       |
|:------------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DRGROUPID   | 容灾组标识   | 可选必选说明：必选参数  参数含义：该参数用于配置容灾组标识。  数据来源：全网规划  取值范围：整数类型，取值范围是1~8。  默认值：无  配置原则：无                                                                                                                             |
| VPNGRPID    | VPN组标识  | 可选必选说明：必选参数  参数含义：该参数用于配置VPN组标识。  数据来源：全网规划  取值范围：整数类型，取值范围是1~10。  默认值：无  配置原则：无                                                                                                                           |
| VPNINSTANCE | VPN实例名称 | 可选必选说明：必选参数  参数含义：该参数用于配置VPN实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~31。VPN实例名称禁止相同。  默认值：无  配置原则：无                                                                                                           |
| ISLINKED    | 是否联动隔离  | 可选必选说明：可选参数  参数含义：该参数用于配置VPN实例是否联动隔离。  数据来源：本端规划 取值范围： “YES（是）”：此VPN故障会联动隔离ADD DRSEPINTERFACE命令添加的接口。“NO（否）”：此VPN故障不会联动隔离ADD DRSEPINTERFACE命令添加的接口。  默认值：无  配置原则：  在免交换组网下组成热备容灾关系的网元间DCI通道相关的VPN实例需要设置为是。 |

## 使用实例

增加监控VPN实例:

```
%%ADD MONVPN:DRGROUPID=1,VPNGRPID=1,VPNINSTANCE="1";%%
```
