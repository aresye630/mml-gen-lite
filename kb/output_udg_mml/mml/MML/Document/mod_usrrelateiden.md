# 修改用户关联识别（MOD USRRELATEIDEN）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于修改指定的protocol的用户关联配置，对某些配置过用户关联功能的protocol，运营商的需求发生变化，不需要提升识别准确率时配置该命令。

#### 注意事项

该命令执行后60s生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                                                                                        |
|:--------------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROTOCOLNAME  | 协议名称     | 可选必选说明：必选参数 参数含义：该参数用于设置对应的协议名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：当需要修改用户关联识别配置时配置该参数，该参数用于输入指定修改的协议名称。                            |
| USRRLTIDENSW  | 用户关联识别开关 | 可选必选说明：必选参数 参数含义：该参数用于设置是否开启用户关联识别功能。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：关闭用户关联识别功能。ENABLE：开启用户关联识别功能。 默认值：无 配置原则： DISABLE：关闭对应协议的用户关联识别功能。ENABLE：开启对应协议用户关联识别功能。 |
| CFGDOMAINNAME | 配置域名称    | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。                                                          |

#### 使用实例

假设运营商的某个应用有变更，不需要对https协议提升识别准确率时，需要修改指定protocol的用户关联识别功能：

```
MOD USRRELATEIDEN: PROTOCOLNAME="https",USRRLTIDENSW=DISABLE;
```
