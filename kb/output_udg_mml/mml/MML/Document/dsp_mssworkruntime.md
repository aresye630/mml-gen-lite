# 查询Work运行时间信息（DSP MSSWORKRUNTIME）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询Work的运行时间信息。

通过统计特定规则的Work的运行信息，进行故障诊断。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                   |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------|
| RUNAME   | RU名称   | 可选必选说明：必选参数 参数含义：该参数用于指定RU名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：使用DSP RU查看RU名称。 |
| THREADID | 线程ID   | 可选必选说明：可选参数 参数含义：该参数用于表示线程的ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～255。 默认值：无                                   |

#### 使用实例

查询目前为止统计的Work运行时间信息：

```
DSP MSSWORKRUNTIME:RUNAME = "VNODE_VNRS_VNFC_IPU_0064";
```

```
RETCODE = 0  操作成功。

结果如下
------------------------

---    END
```

#### 输出结果说明

| 输出项名称    | 输出项解释                    |
|:---------|:-------------------------|
| Work序列号  | 用于表示Work序列号。             |
| Work类型   | 用于表示Work类型。              |
| 组ID      | 用于表示Work所在的组。            |
| 权重       | 用于表示Work的QoS权重。          |
| 调度类型     | 用于表示Work的调度类型。           |
| 第一个参数    | 用于表示Work的第一个自定义参数。       |
| 第二个参数    | 用于表示Work的第二个自定义参数。       |
| 线程ID     | 用于表示线程的ID。               |
| 起始时间（ms） | 用于表示该Work被调度的起始时间，单位为毫秒。 |
| 完成时间（ms） | 用于表示该Work被调度完成的时间，单位为毫秒。 |
