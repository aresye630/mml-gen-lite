# 清除ARP动态黑名单（RTR ARPDYNBLACKLIST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于清除ARP动态黑名单。

当ARP动态黑名单已经不需要且未到老化时间，可使用该命令清除。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                           |
|:--------|:-------|:-------------------------------------------------------------------------------------------------------------------------------|
| IPADDR  | IP地址   | 可选必选说明：可选参数 参数含义：该参数用于指定ARP动态黑名单的IP地址。 数据来源：本端规划 取值范围：IPv4地址类型。IP地址0.0.0.0～255.255.255.255。 默认值：无                              |
| MACADDR | MAC地址  | 可选必选说明：可选参数 参数含义：该参数用于指定ARP动态黑名单的MAC地址。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～48。 默认值：无                                                |
| IFNAME  | 接口名称   | 可选必选说明：可选参数 参数含义：该参数用于指定ARP动态黑名单的接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。接口名称由接口类型+接口编号组成。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。 |

#### 使用实例

不指定参数时，清除VNFC上所有ARP动态黑名单：

```
RTR ARPDYNBLACKLIST:;
```
