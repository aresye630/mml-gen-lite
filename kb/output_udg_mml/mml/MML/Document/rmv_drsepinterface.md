# 删除故障隔离接口（RMV DRSEPINTERFACE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在免交换组网下组成热备容灾关系的网元间DCI通道变化时，删除需要关闭/开启的逻辑接口。

## 注意事项

- 该命令执行后立即生效。

- 该命令适用于支持热备容灾的网元执行。
- 参数“接口名”可通过**LST DRSEPINTERFACE**命令查询获取。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                              |
|:----------|:-------|:----------------------------------------------------------------------------------|
| DRGROUPID | 容灾组标识  | 可选必选说明：必选参数  参数含义：该参数用于配置容灾组标识。  数据来源：本端规划  取值范围：整数类型，取值范围是1~8。  默认值：无  配置原则：无    |
| IFNAME    | 接口名    | 可选必选说明：必选参数  参数含义：该参数用于配置接口名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。  默认值：无  配置原则：无 |

## 使用实例

删除故障隔离接口。

```
RMV DRSEPINTERFACE: DRGROUPID=1, IFNAME="itf1";
```
