# 删除RSA密钥对标签（RMV RSAKEYPAIRLABEL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除RSA密钥对标签。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识         | 参数名称      | 参数说明                                                                                         |
|:-------------|:----------|:---------------------------------------------------------------------------------------------|
| KEYPAIRLABEL | RSA密钥对标签名 | 可选必选说明：必选参数 参数含义：RSA密钥对标签名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～35。名称只能使用数字、字母和下划线，不区分字母大小写。 默认值：无 |

#### 使用实例

删除名称为hw\_key的RSA密钥对标签：

```
RMV RSAKEYPAIRLABEL:KEYPAIRLABEL="hw_key";
```
