# 修改匹配IPv6地址前缀列表（MOD MATCHDESTPREFIX6FILTER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 参考信息

#### 命令功能

该命令用于修改基于IPv6信息的前缀过滤器匹配目的地址。

#### 注意事项

- 该命令执行后立即生效。
- 配置该命令前，必须已经配置了指定路由策略的名字以及该策略下的节点。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称       | 参数说明                                                                                                              |
|:---------------|:-----------|:------------------------------------------------------------------------------------------------------------------|
| POLICYNAME     | 路由策略名字     | 可选必选说明：必选参数 参数含义：配置操作的路由策略名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无 配置原则：不支持输入空格。                              |
| NODESEQUENCE   | 路由策略节点号    | 可选必选说明：必选参数 参数含义：该参数用于配置操作的路由策略节点号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无                                       |
| IPV6PREFIXNAME | IPv6前缀列表名字 | 可选必选说明：可选参数 参数含义：该参数用于配置匹配的IP前缀列表名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～169。 默认值：无 配置原则： 输入单空格将删除该参数已有配置项。区分大小写，不支持空格。 |

#### 使用实例

修改路由策略a节点10的匹配条件，前缀过滤器a匹配目的地址：

```
MOD MATCHDESTPREFIX6FILTER: NODESEQUENCE=10,IPV6PREFIXNAME="a",POLICYNAME="a";
```

#### 参考信息

为实现路由策略，首先定义将要实施路由策略的路由特征，即定义一组匹配规则和设置规则，然后将它们应用于路由的发布、接收和引入等过程的路由策略中。
