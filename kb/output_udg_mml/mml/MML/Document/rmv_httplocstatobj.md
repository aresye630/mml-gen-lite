# 删除基于本端和对端结点的性能统计测量对象信息（RMV HTTPLOCSTATOBJ）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

删除基于本端和对端结点的性能统计测量对象信息。当测量对象无法正常老化时，可通过该命令删除。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                         |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------|
| PTYPE  | 对端网元类型 | 可选必选说明：必选参数  参数含义：用于标识通信对端结点的类型，对于服务化接口的消息统计，标识对端NFTYPE。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~128。  默认值：无  配置原则：无 |
| PADDR  | 对端IP地址 | 可选必选说明：必选参数  参数含义：用于标识通信对端结点的IP，对于服务化接口的消息统计，标识对端IP。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~128。  默认值：无  配置原则：无     |
| LTYPE  | 本端类型   | 可选必选说明：必选参数  参数含义：用于标识通信本端结点的类型，对于服务化接口的消息统计，标识本端NFTYPE。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~128。  默认值：无  配置原则：无 |
| LADDR  | 本端IP地址 | 可选必选说明：必选参数  参数含义：用于标识通信本端结点的IP，对于服务化接口的消息统计，标识本端IP。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~128。  默认值：无  配置原则：无     |

## 使用实例

如果想删除基于本端和对端结点的性能统计测量对象信息，可以用如下命令：

```
RMV HTTPLOCSTATOBJ: PTYPE="AMF", PADDR="192.168.111.222", LTYPE="SMF", LADDR="192.168.111.333";
```
