# 设置IPv6参数(SET IPV6PARA)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于设置IPv6功能参数。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                          |
|:----------------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PMTUAGINGTIMER  | PMTU老化时长 | 可选必选说明：必选参数。 参数含义：设置PMTU（Path Maximum Transmission Unit）缓存数据老化时长，单位为天。 数据来源：本端规划 取值范围：整数类型，取值范围为0～365。 系统设置初始值：1 默认值：无 配置原则：0：关闭PMTU缓存数据老化功能。如果IP或端口经常变化，会导致PMTU缓存数据持续增长，存在PMTU缓存数据过载的风险。1～365：PMTU缓存数据老化时长。PMTU缓存记录老化超时，会清除PMTU缓存数据，对应的IPv6网络路径使用系统默认PMTU发送消息。如果网络路径上的路由器不支持此默认PMTU，会导致短暂丢包。 |
| SERVICEINSTANCE | 服务实例     | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。不支持对"VNFC类型名称"为VNFP、VNRS_VNFC、ACS、IPSEC_VNFC的VNFC进行配置。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。                                                                                                                             |

#### 使用实例

设置IPv6功能参数，“PMTU老化时长”为3天：

`SET IPV6PARA: PMTUAGINGTIMER=3,SERVICEINSTANCE="CSLB_VNFC_999";`
