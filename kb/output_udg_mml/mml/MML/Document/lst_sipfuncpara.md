# 查询SIP信令代理功能参数（LST SIPFUNCPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于查询SIP信令代理功能参数。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询SIP信令代理功能参数：

```
LST SIPFUNCPARA:;
```

```
RETCODE = 0  操作成功。

结果如下
--------
          功能开关  =  不使能
          注册时长  =  0
     呼叫SIP状态码  =  SIP486
   短消息SIP状态码  =  SIP486
     IMPU SIP格式  =  NULL
     IMPU TEL格式  =  NULL
(结果个数 = 1)
---    END
```
