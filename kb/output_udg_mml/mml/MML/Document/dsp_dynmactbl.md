# 显示动态MAC表项信息（DSP DYNMACTBL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示MAC地址表记录数量或指定MAC地址的表项信息。

#### 注意事项

该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                               |
|:-----------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RUNAME     | RU名称   | 可选必选说明：可选参数。 参数含义：指定RU的名称。 数据来源：本端规划。 取值范围：字符串类型，长度范围1～63。 默认值：无。 配置原则：参考DSP RU命令查询RU编号。                                                                           |
| SHOWTYPE   | 查询展示类型 | 可选必选说明：必选参数。 参数含义：指定查询MAC表项信息的方式。 数据来源：本端规划。 取值范围：枚举类型。 CERTAINMAC：指定MAC地址的信息。SUMMARY：MAC地址表记录数量。 默认值：无。 配置原则：在取值范围内进行选择。                                          |
| MACADDRESS | MAC地址  | 可选必选说明：条件必选参数。 前提条件：该参数在“SHOWTYPE”配置为“CERTAINMAC”时为必选参数。 参数含义：该参数用于指定查询表项信息的MAC地址。 数据来源：本端规划。 取值范围：MAC地址类型。 默认值：无。 配置原则：格式为H-H-H。其中H为4位的十六进制数，可以输入1～4位，如00e0、fc01。 |

#### 使用实例

显示MAC地址表记录数量：

```
DSP DYNMACTBL: SHOWTYPE=SUMMARY;
```

```
RETCODE = 0  操作成功。

结果如下
-------------------------
RU名称           MAC地址数量  
VNRS_IP_RU_0064  256   
VNRS_IP_RU_0065  123   
(结果个数 = 2)
---    END
```

显示指定MAC地址的信息：

```
DSP DYNMACTBL: SHOWTYPE=CERTAINMAC, MACADDRESS="5566-1122-3344";
```

```
RETCODE = 0  操作成功。

结果如下
-------------------------
  RU名称 = VNRS_IP_RU_0064
 MAC地址 = 5566-1122-3344
  端口号 = 8
老化时间 = 4
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                     |
|:--------|:--------------------------|
| RU名称    | 用于指定资源单元名称。               |
| MAC地址   | 用于表示MAC地址。                |
| 端口号     | 用于表示MAC地址对应的端口号。          |
| 老化时间    | 用于表示MAC地址对应的剩余老化时间，单位：分钟。 |
| MAC地址数量 | 用于表示指定资源单元的MAC地址数量。       |
