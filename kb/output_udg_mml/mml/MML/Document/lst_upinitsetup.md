# 显示主被动切换（LST UPINITSETUP）

- 注意事项

- 输出结果说明

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于查询是否主动发起建立偶联的配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询是否主动发起建立偶联的配置：

```
LST UPINITSETUP:;
```

```
RETCODE = 0  操作成功

主被动切换。
-----------------------------
UP 切换  =  ENABLE
(结果个数 = 1)
---    END
```

#### 输出结果说明
