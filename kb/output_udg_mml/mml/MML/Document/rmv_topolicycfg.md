# 删除TCP优化策略配置（RMV TOPOLICYCFG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于删除TCP优化策略配置。

#### 注意事项

该命令执行后只对之后发生承载更新的用户或者新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                              |
|:---------|:-------|:------------------------------------------------------------------|
| POLICYID | 策略ID   | 可选必选说明：必选参数 参数含义：策略ID。 数据来源：本端规划 取值范围：整数类型,取值范围为1~7。 默认值：无 配置原则：无 |

#### 使用实例

运营商需要删除策略ID为1的TCP优化策略：

```
RMV TOPOLICYCFG: POLICYID=1;
```
