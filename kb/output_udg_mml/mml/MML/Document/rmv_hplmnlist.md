# 删除UPF设备的归属PLMN（RMV HPLMNLIST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于删除UPF设备的一个归属PLMN。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                     |
|:-------|:-------|:-----------------------------------------------------------------------------------------|
| MCC    | 移动国家码  | 可选必选说明：必选参数 参数含义：该参数用于指定移动国家码。 数据来源：全网规划 取值范围：字符串类型，为3位数字，000～999。 默认值：无 配置原则：无          |
| MNC    | 移动网络号  | 可选必选说明：必选参数 参数含义：该参数用于指定移动网络号。 数据来源：全网规划 取值范围：字符串类型，可为2或3位数字，00~99或000~999。 默认值：无 配置原则：无 |

#### 使用实例

删除一个移动国家码为460、移动网络号为02的归属PLMN：

```
RMV HPLMNLIST:MCC="460",MNC="02";
```
