# 增加NP升级平面（ADD NPUPGPLANE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

该命令是高危命令，操作不当可能会影响灰度升级。

该命令用来增加NP升级平面。

如果灰度升级前平面不是按照奇数和偶数槽位进行划分，则需要执行此命令，划分原则请从网设文档中获取。

#### 注意事项

- 该命令执行后立即生效。
- 该命令仅适用于NP卡省交换组网模式。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                  |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------|
| RUID    | RU编号   | 可选必选说明：必选参数。 参数含义：该参数用于指定RU编号。 数据来源：本端规划。 取值范围：整数类型，取值范围为0～4294967294。 默认值：无。 配置原则：使用DSP RU命令查询RU类型不是VNRS_OM_RU以及VNRS_IPCTRL_RU的RU编号。 |
| PLANEID | 平面编号   | 可选必选说明：必选参数。 参数含义：该参数用于设置升级平面。 数据来源：本端规划。 取值范围： “plane_1”：升级平面一。“plane_2”：升级平面二。 默认值：无。 配置原则：无。                                       |

#### 使用实例

增加RUID为66到升级平面plane\_1：

```
ADD NPUPGPLANE: RUID=66, PLANEID=plane_1;
```
