# 删除黑名单命令（RMV CMDBLACKLIST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

本命令用于删除命令黑名单中的MML命令。

#### 注意事项

- 网元ID必须在系统中存在。
- 被删除的黑名单命令必须是已在命令黑名单中的MML命令。
- 该命令仅限具有Administrators角色的用户可以执行。在扩展域，仅限系统管理员可以执行。

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                          |
|:--------|:-------|:--------------------------------------------------------------|
| MEID    | 网元ID   | 可选必选说明：必选参数 参数含义：网元ID。 取值范围：0～65535。 默认值：无。 配置原则：无。           |
| COMMAND | 命令名称   | 可选必选说明：必选参数 参数含义：MML命令名称。 取值范围：长度不超过100的英文字符串。 默认值：无。 配置原则：无。 |

#### 使用实例

从命令黑名单中删除**LST ME**命令：

```
RMV CMDBLACKLIST: MEID=0, COMMAND="LST ME";
```

```
%%RMV CMDBLACKLIST: MEID=0, COMMAND="LST ME";%%
RETCODE = 0  操作成功

---    END
```
