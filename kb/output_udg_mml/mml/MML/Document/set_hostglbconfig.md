# 设置主机收发全局属性（SET HOSTGLBCONFIG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于设置主机收发忽略管理平面接口上送的TCP或UDP协议报文的校验和。

如果网卡开启了GRO功能，分片的TCP或UDP报文被网卡聚合上送，聚合时校验和未刷新，在这种场景下使用该命令通知主机收发忽略校验和检查。

#### 注意事项

- 当前版本不支持此命令。
- 该命令存在系统初始记录，参数的初始设置值如下表：

|   ISIGNORECHKSUM |
|-----------------:|
|                0 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                             |
|:---------------|:-------|:---------------------------------------------------------------------------------|
| ISIGNORECHKSUM | 忽略校验和  | 可选必选说明：必选参数 参数含义：该参数用于表示过滤校验和标记。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无 |

#### 使用实例

配置主机收发忽略校验和：

```
SET HOSTGLBCONFIG:ISIGNORECHKSUM=TRUE;
```
