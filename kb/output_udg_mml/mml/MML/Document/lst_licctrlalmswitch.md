# 查询LicenseCtrl告警控制开关（LST LICCTRLALMSWITCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

查询LicenseCtrl告警控制开关。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                 |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------|
| ALMID  | 告警ID   | 可选必选说明：可选参数  参数含义：该参数用于表示LicenseCtrl中的告警ID。  数据来源：本端规划 取值范围： ALM-100775（100775 - 系统存在未生效关键License控制项）  默认值：无  配置原则：无 |

## 使用实例

查询当前已配置所有的Licensectrl告警开关状态。

```
%%LST LICCTRLALMSWITCH:;%%
RETCODE = 0  操作成功

结果如下
------------------------
  告警ID  =  100775 - 系统存在未生效关键License控制项
告警开关  =  开启
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                     |
|:--------|:--------------------------|
| 告警ID    | 该参数用于表示LicenseCtrl中的告警ID。 |
| 告警开关    | 该参数用于表示告警能力开启或关闭。         |
