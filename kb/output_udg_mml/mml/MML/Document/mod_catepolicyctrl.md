# 修改基于应用大类的质差上报策略（MOD CATEPOLICYCTRL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于修改基于应用大类的质差策略。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称         | 参数说明                                                                                                                                                                                                                                               |
|:--------------|:-------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APPIDNAME     | 应用ID         | 可选必选说明：必选参数 参数含义：该参数用于指定重点业务保障的应用组名称。 数据来源：全网规划 取值范围：字符串类型，区分大小写，长度为1-63位。 默认值：无 配置原则：无                                                                                                                                                            |
| CATEGORYID    | 应用大类ID       | 可选必选说明：可选参数 参数含义：应用大类ID。 数据来源：本端规划 取值范围：101-200。 默认值：无 配置原则：无                                                                                                                                                                                      |
| QOEDETPRD     | 基于应用的质差上报周期  | 可选必选说明：可选参数 参数含义：该参数指定该应用下UPF检测用户业务发生质差时向NWDAF上报单据的时间间隔。 数据来源：本端规划 取值范围：整数类型，取值范围为1~300，单位为秒，必须大于等于SET VVIPBASICFUNC中配置的SAMPLEPERIOD。建议按5秒、10秒和15秒的粒度配置。 默认值：无 配置原则：无                                                                              |
| NONQOEDETPRD  | 基于应用的非质差上报周期 | 可选必选说明：可选参数 参数含义：该参数指定该应用下UPF检测用户业务未发生质差时向NWDAF上报单据的时间间隔。 数据来源：本端规划 取值范围：整数类型，取值范围为1~300，单位为秒。1. 必须大于等于SET VVIPBASICFUNC中配置的SAMPLEPERIOD。2. 建议按60秒粒度配置。3. 体验单据配置周期应当大于BYTE1115中配置的应用结束时延时间，如果BYTE1115未配置，体验单据配置周期应当大于BYTE1115默认值（2秒）。 默认值：无 配置原则：无 |
| MOS           | 平均意见分        | 可选必选说明：可选参数 参数含义：该参数用于配置平均意见分，UPF检测到应用实际的平均意见分不大于该值时，认为该应用质差。 数据来源：本端规划 取值范围：整数类型，取值范围0到100。 默认值：无 配置原则：无                                                                                                                                          |
| QOERPTPOLICY  | 应用质差上报策略     | 可选必选说明：可选参数 参数含义：该参数用于设置应用质差时的单据上报策略。 数据来源：本端规划 取值范围：枚举类型。 QOE_REPORT_ONCE：检测到质差时新流触发上报。QOE_REPORT_PERIOD：检测到质差时周期触发上报。 默认值：无 配置原则：无                                                                                                               |
| ENDDELAY      | 应用结束延时时间     | 可选必选说明：可选参数 参数含义：应用所有流老化后判断应用结束的等待时间。 数据来源：本端规划 取值范围：整数类型，取值范围1到300，单位为秒。 默认值：无 配置原则：体验单据配置周期应当大于应用结束延时时间。                                                                                                                                         |
| BYPASS        | 业务bypass开关   | 可选必选说明：可选参数 参数含义：业务bypass开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无                                                                                                                                                              |
| POLICYCNDNAME | 策略参数名        | 可选必选说明：可选参数 参数含义：该参数用于指定需要绑定的策略参数名。 数据来源：本端规划 取值范围：参数来源于ADD POLICYCONDITION中的POLICYCNDNAME。 默认值：无 配置原则：无                                                                                                                                           |
| ULICHANGERPT  | 位置变更上报       | 可选必选说明：条件可选参数 前提条件：该参数在“QOERPTPOLICY”配置为“QOE_REPORT_ONCE”时为可选参数。 参数含义：设置位置变更后发生过质差上报的老流能再触发上报一次质差上报。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：设置位置变更后发生过质差上报的老流不能再触发上报一次质差上报。ENABLE：设置位置变更后发生过质差上报的老流能再触发上报一次质差上报。 默认值：无 配置原则：无                                |
| EXPCTRLFACTOR | 体验大流阈值系数     | 可选必选说明：可选参数 参数含义：该参数用于设置体验单据的大流阈值系数。 数据来源：本端规划 取值范围：浮点数，精确到十分位，取值范围为0.1～9.9。 默认值：无 配置原则：无                                                                                                                                                          |

#### 使用实例

修改应用ID为OpenLive，应用大类ID为102的平均意见分为40，执行如下命令：

```
MOD CATEPOLICYCTRL: APPIDNAME="OpenLive", CATEGORYID=102, MOS=40;
```
