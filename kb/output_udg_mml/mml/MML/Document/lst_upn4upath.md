#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用来查看N4U路径相关属性。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询N4 GTP-U路径相关属性：

```
LST UPN4UPATH:;
```

```
RETCODE = 0  操作成功

N4 GTP路径配置
--------------

               是否去活路径上已激活的上下文  =  使能
          N4接口的GTP请求消息的重发时间间隔  =  3
      N4接口的GTP请求消息的最大尝试发送次数  =  5
                                   Echo开关  =  使能
```
