# 查询FE自愈功能配置（LST FEHEALCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询FE自愈功能配置：包括Mesh网口故障自愈功能开关和FE服务丢失心跳自愈开关。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询FE自愈功能配置

```
LST FEHEALCTRL:;
RETCODE = 0  操作成功

结果如下
--------
Mesh网口故障自愈功能开关  =  使能
  FE服务丢失心跳自愈开关  =  使能
(结果个数 = 1)
```

## 输出结果说明

| 输出项名称          | 输出项解释           |
|:---------------|:----------------|
| Mesh网口故障自愈功能开关 | Mesh网口故障自愈功能开关。 |
| FE服务丢失心跳自愈开关   | FE服务丢失心跳自愈开关。   |
