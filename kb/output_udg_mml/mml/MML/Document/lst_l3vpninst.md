# 查询L3VPN实例（LST L3VPNINST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询已配置的L3VPN实例信息。

#### 注意事项

- 该命令执行后立即生效。
- 不指定参数，则显示设备上所有已配置的VPN实例名称。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                       |
|:--------|:--------|:---------------------------------------------------------------------------|
| VRFNAME | VPN实例名称 | 可选必选说明：可选参数 参数含义：该参数用于指定L3VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 |

#### 使用实例

查询所有VPN实例，其中VPN实例\_public\_为公网实例：

```
LST L3VPNINST:;
```

```
RETCODE = 0  操作成功。

结果如下
-------------------------
VPN实例名称          VPN实例描述     路由器ID
_public_             NULL            NULL
__mpp_vpn_inner__    NULL            NULL
(结果个数 = 2)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释          |
|:--------|:---------------|
| 路由器ID   | 用于指定Router ID。 |

其余输出项请参见ADD L3VPNINST的参数说明。
