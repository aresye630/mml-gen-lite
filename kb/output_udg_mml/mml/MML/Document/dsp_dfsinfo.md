# 查询DFS集群信息（DSP DFSINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明
- 参考信息

## 命令功能

该命令用于查询分布式文件系统集群信息。

## 注意事项

无

## 参数说明

无。

## 使用实例

查询hofs集群的基本信息。

```
%%DSP DFSINFO:;%% 
RETCODE = 0  操作成功
  
分布式文件系统信息 
------------------        
            应用ID  =  0       
           OSD数量  =  2      
          对象数量  =  10855
        读成功次数  =  0    
        写成功次数  =  0      
          失败次数  =  0    
        对象总大小  =  112400
      PV总大小(MB)  =  160685.0625 
PV剩余可用大小(MB)  =  14247.4551 
  PV已使用大小(MB)  =  138640.1309 
       PV使用率(%)  =  90.6811 
      Inode总数(B)  =  10485760
  Inode使用数量(B)  =  147975
    Inode使用率(%)  =  1.4112 
(结果个数 = 1) 
 
---    END
```

## 输出结果说明

命令执行正常，会返回分布式文件系统的基本信息，输出结果项信息项目如表1。

命令执行异常，会返回对应的错误码。常见错误码如表2所示。

| 输出项名称        | 输出项解释                   |
|:-------------|:------------------------|
| 应用ID         | 用于返回当前应用ID。             |
| OSD数量        | 用于返回OSD数量。              |
| 对象数量         | 用于返回存储的文件个数。            |
| 读成功次数        | 用于返回操作数据桶读成功次数。         |
| 写成功次数        | 用于返回操作数据桶写成功次数。         |
| 失败次数         | 用于返回操作数据桶失败次数。          |
| 对象总大小        | 用于返回存储的文件总大小。           |
| PV总大小(MB)    | 用于返回实际存储空间大小，单位MB。      |
| PV剩余可用大小(MB) | 用于返回实际存储空间剩余可使用大小，单位MB。 |
| PV已使用大小(MB)  | 用于返回实际存储空间已使用大小，单位MB。   |
| PV使用率(%)     | 用于返回实际存储空间使用率，单位%。      |
| Inode总数(B)   | 用于返回文件系统对象总大小，单位B。      |
| Inode使用数量(B) | 用于返回文件系统对象使用数量，单位B。     |
| Inode使用率(%)  | 用于返回文件系统对象使用率，单位%。      |

|    错误码 | 错误码解释         | 原因分析                             | 处理建议               |
|-------:|:--------------|:---------------------------------|:-------------------|
| 181001 | 下发的MML命令不正确   | 非法的命令                            | 请联系华为技术支持。         |
| 181002 | 系统内部错误，请联系管理员 | 执行过程中可能存在网络故障或者服务不可用等异常因素，出现此种情况 | 等待几分钟后重试或联系华为技术支持。 |
| 180002 | MML处理失败       | 内部错误                             | 请联系华为技术支持。         |
