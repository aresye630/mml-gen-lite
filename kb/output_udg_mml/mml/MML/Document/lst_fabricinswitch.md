# 查询Fabric-In功能开关（LST FABRICINSWITCH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询Fabric-In功能开关。Fabric-In对应是内置FullMesh卡，内置FullMesh卡负责框内流量交换。

#### 注意事项

该命令本版本不再支持生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

- 查询Fabric-In功能开关：

  ```
  %%LST FABRICINSWITCH:;%%
  RETCODE = 0  操作成功

  结果如下:
  ---------
  功能是否开启  =  是
  (结果个数 = 1)

  ---    END
  ```

#### 输出结果说明

| 输出项名称   | 输出项解释                |
|:--------|:---------------------|
| 功能是否开启  | 用于表示Fabric-In功能是否开启。 |
