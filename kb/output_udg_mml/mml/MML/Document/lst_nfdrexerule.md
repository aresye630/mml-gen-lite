# 查询容灾执行规则（LST NFDREXERULE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询容灾执行规则。

## 注意事项

该命令用于AMF网元查询容灾执行规则。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询容灾执行规则。

```
%%LST NFDREXERULE:;%%
RETCODE = 0  操作成功

结果如下
--------
              容灾执行规则  =  优雅迁移
容灾执行规则等待时间(分钟)  =  30
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称          | 输出项解释               |
|:---------------|:--------------------|
| 容灾执行规则         | 该参数用于表示容灾执行规则。      |
| 容灾执行规则等待时间(分钟) | 该参数用于设置容灾执行规则的等待时间。 |
