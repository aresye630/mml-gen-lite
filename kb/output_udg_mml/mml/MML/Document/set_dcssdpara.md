# 设置DCS直通存储慢盘检测参数（SET DCSSDPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置DCS直通存储慢盘检测参数。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| SWITCH   |   SAMPLE |   PERIOD |   SVCTMTHD |   UTILTHD |   SDALMTHD |   SDRCVTHD |
|:---------|---------:|---------:|-----------:|----------:|-----------:|-----------:|
| ON       |       30 |        1 |         30 |        98 |         70 |         50 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称       | 参数说明                                                                                                                                                                                                        |
|:---------|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SWITCH   | 慢盘检测开关     | 可选必选说明：可选参数  参数含义：该参数用于开启或关闭DCS直通存储慢盘检测功能。  数据来源：本端规划 取值范围： ON（开启）OFF（关闭）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST DCSSDPARA查询当前参数配置值。  配置原则：无                                                              |
| SAMPLE   | 检测次数       | 可选必选说明：可选参数  参数含义：该参数表示一轮直通慢盘检测的总次数。  数据来源：本端规划  取值范围：整数类型，取值范围是1~300，单位是次。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST DCSSDPARA查询当前参数配置值。  配置原则：无                                                            |
| PERIOD   | 检测周期(s)    | 可选必选说明：可选参数  参数含义：该参数用于设置直通存储慢盘检测周期，表示连续两次检测间的时间间隔。  数据来源：本端规划  取值范围：整数类型，取值范围是1~300，单位是秒。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST DCSSDPARA查询当前参数配置值。  配置原则：无                                             |
| SVCTMTHD | IO服务时间(ms) | 可选必选说明：可选参数  参数含义：该参数表示系统进行IO操作的响应时间，IO操作表示在磁盘上进行读写操作。该参数已废弃。  数据来源：本端规划  取值范围：整数类型，取值范围是1~5000，单位是毫秒。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST DCSSDPARA查询当前参数配置值。  配置原则：  该参数配置不生效。                       |
| UTILTHD  | IO使用率(%)   | 可选必选说明：可选参数  参数含义：该参数表示系统IO操作所占用的CPU负载。  数据来源：本端规划  取值范围：整数类型，取值范围是1~100，单位是百分比。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST DCSSDPARA查询当前参数配置值。  配置原则：无                                                       |
| SDALMTHD | 慢盘故障阈值(%)  | 可选必选说明：可选参数  参数含义：该参数表示一轮慢盘检测中，慢盘状态次数在总检测次数中占比的故障阈值，大于等于该阈值判定为直通存储慢盘。  数据来源：本端规划  取值范围：整数类型，取值范围是1~100，单位是百分比。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST DCSSDPARA查询当前参数配置值。  配置原则：  “慢盘故障阈值”要求大于“慢盘恢复阈值”。   |
| SDRCVTHD | 慢盘恢复阈值(%)  | 可选必选说明：可选参数  参数含义：该参数表示一轮慢盘检测中，慢盘状态次数在总检测次数中占比的恢复阈值，小于等于该阈值则表示直通存储慢盘恢复。  数据来源：本端规划  取值范围：整数类型，取值范围是1~100，单位是百分比。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST DCSSDPARA查询当前参数配置值。  配置原则：  “慢盘故障阈值”要求大于“慢盘恢复阈值”。 |

## 使用实例

设置慢盘检测开关为ON，检测周期为1s，IO服务时间为30ms, IO使用率为98，检测次数为30次，慢盘故障阈值为70，慢盘恢复阈值为50的实例：

```
SET DCSSDPARA: SWITCH=ON, PERIOD=1, SVCTMTHD=30, UTILTHD=98, SAMPLE=30, SDALMTHD=70, SDRCVTHD=50;
```
