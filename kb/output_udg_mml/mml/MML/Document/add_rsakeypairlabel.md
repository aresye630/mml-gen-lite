# 创建RSA密钥对标签（ADD RSAKEYPAIRLABEL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于创建RSA密钥对标签。为SSH服务器分配RSA服务器密钥，使用该命令生成密钥对标签。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为20。
- 密钥需定期修改否则会有安全风险。
- RSA算法如果密钥长度小于等于2048位将存在安全风险，建议使用3072位的密钥。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识         | 参数名称      | 参数说明                                                                                         |
|:-------------|:----------|:---------------------------------------------------------------------------------------------|
| KEYPAIRLABEL | RSA密钥对标签名 | 可选必选说明：必选参数 参数含义：RSA密钥对标签名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～35。名称只能使用数字、字母和下划线，不区分字母大小写。 默认值：无 |
| KEYSIZE      | 公钥长度      | 可选必选说明：可选参数 参数含义：公钥的长度。 数据来源：本端规划 取值范围：整数类型，取值范围为2048，3072。 默认值：3072                         |

#### 使用实例

创建名称为hw\_key的RSA密钥对标签：

```
ADD RSAKEYPAIRLABEL:KEYPAIRLABEL="hw_key";
```
