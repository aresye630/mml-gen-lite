# 查询系统是否开启专网UPF动态分流功能（LST DEDICATEDLBO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用来查看专网UPF动态分流功能开关状态。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查看专网UPF动态分流功能开关状态，可以使用该命令：

```
LST DEDICATEDLBO:;
```

```
RETCODE = 0  操作成功。

开关状态
------------------
专网UPF动态分流功能开关  =  使能
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见SET DEDICATEDLBO的参数说明。
