# 删除APN的IMS分类器（RMV APNIMSSIGFLTR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，请确认删除规则后合法的IMS信令报文都能命中其中一条规则。

该命令用于删除指定优先级的APN下的IMS信令专用上下文的Filter。当运营商不需要某个信令分类器的规则过滤包时，使用该命令删除该filter。

#### 注意事项

- 该命令执行后只对新激活用户生效。
- 执行该命令时，请确认是否会对该APN下的业务造成影响，操作不当，可能会造成语音业务不通。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                        |
|:---------|:-------|:------------------------------------------------------------------------------------------------------------|
| APN      | APN名称  | 可选必选说明：必选参数 参数含义：该参数用于指定APN实例名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格以及特殊字符：“_”、“#”、“$”、“&”等。 默认值：无 配置原则：无 |
| PRIORITY | 优先级    | 可选必选说明：必选参数 参数含义：该参数用于指定静态分组过滤优先级。值越小优先级越高。 数据来源：本端规划 取值范围：整数类型，取值范围为1～64。同一个APN内唯一。 默认值：无 配置原则：无           |

#### 使用实例

当运营商不需要APN huawei.com的信令分类器的规则过滤包时，使用该命令删除这个filter。配置APN为huawei.com，PRIORITY为3：

```
RMV APNIMSSIGFLTR:APN="huawei.com",PRIORITY=3;
```
