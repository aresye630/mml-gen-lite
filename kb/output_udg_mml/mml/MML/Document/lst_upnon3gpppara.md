# 查询非3GPP业务配置参数（LST UPNON3GPPPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用来查询非3GPP业务配置参数。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询非3GPP业务配置参数：

```
LST UPNON3GPPPARA:;
```

```
RETCODE = 0  操作成功。

结果如下:
---------
      SWU接口UE接入速率  =  1000
ToH SESSION的老化时长  =  1440
(结果个数 = 1)

---    END
```
