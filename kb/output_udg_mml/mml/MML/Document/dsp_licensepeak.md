# 显示话务高峰信息（DSP LICENSEPEAK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此命令用于查看话务高峰的相关信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询当年发生的话务峰值事件信息：

```
%%DSP LICENSEPEAK:;%%
RETCODE = 0  操作成功

已使用的峰值License记录
-----------------------
     使用日期  =  2025-07-09 至 2025-07-11
过载License项  =  CU FullMesh组网
(结果个数 = 1)

剩余次数
--------
 剩余使用次数  =  9
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称      | 输出项解释                      |
|:-----------|:---------------------------|
| 使用日期       | 该参数用于指定本次话务高峰的峰值日时间段。      |
| 过载License项 | 该参数用于指定本次话务高峰内的过载License项。 |
| 剩余使用次数     | 该参数用于指定本年度剩余可用的高峰次数。       |
