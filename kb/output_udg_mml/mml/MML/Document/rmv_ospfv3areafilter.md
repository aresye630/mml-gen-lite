# 删除OSPFv3区域过滤LSA配置（RMV OSPFV3AREAFILTER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除对区域内Type 3 LSA进行过滤配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称       | 参数说明                                                                                                                                                    |
|:-------------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROCID       | OSPFv3进程号  | 可选必选说明：必选参数 参数含义：OSPFv3进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无                                                                                |
| AREAID       | OSPFv3区域号  | 可选必选说明：必选参数 参数含义：OSPFv3区域号。 数据来源：本端规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无                                                                                      |
| TOPOID       | 拓扑标识       | 可选必选说明：可选参数 参数含义：拓扑标识。 数据来源：本端规划 取值范围：整数类型，取值范围为0。 默认值：无 配置原则：目前只支持默认拓扑0。                                                                               |
| FILTERTYPE   | 过滤方向       | 可选必选说明：必选参数 参数含义：过滤方向。 数据来源：本端规划 取值范围：枚举类型。 import：引入方向的过滤。export：发布方向的过滤。 默认值：无                                                                        |
| TYPE         | 过滤类型       | 可选必选说明：可选参数 参数含义：过滤规则类型(ACL名称或ACL号/IP前缀过滤策略名称)。 数据来源：本端规划 取值范围：枚举类型。 acl_name：ACL6名称。ip_prefix：IPv6前缀池列表。route_policy：路由策略。acl_num：ACL号。 默认值：无          |
| ACLNAMEORNUM | ACL名称或ACL号 | 可选必选说明：条件必选参数 前提条件：该参数在“TYPE”配置为“acl_name” 或 “acl_num”时为必选参数。 参数含义：该参数用于指定ACL规则组名称或是编号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32；字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无 |
| IPPREFIX     | IP前缀       | 可选必选说明：条件必选参数 前提条件：该参数在“TYPE”配置为“ip_prefix”时为必选参数。 参数含义：IP前缀。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～169。 默认值：无                                                  |
| ROUTEPLYNAME | 路由策略名称     | 可选必选说明：条件必选参数 前提条件：该参数在“TYPE”配置为“route_policy”时为必选参数。 参数含义：路由策略名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无                                             |

#### 使用实例

删除OSPFv3对出方向的Type 3 LSA的过滤配置：

```
RMV OSPFV3AREAFILTER:PROCID=1,AREAID="0.0.0.1",FILTERTYPE=export,TYPE=acl_num,ACLNAMEORNUM="2500";
```
