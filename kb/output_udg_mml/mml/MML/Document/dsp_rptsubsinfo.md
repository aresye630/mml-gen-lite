# 显示报表订阅信息（DSP RPTSUBSINFO）

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于显示报表订阅信息。

#### 注意事项

- 该命令执行后立即生效。
- 该命令每次查询结果可能显示不全，多次查询显示结果从上一次查询到的最后一条记录的下一条记录开始。查询不同类型、或者5分钟不执行该命令，再次查询从第一条记录开始。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
|:---------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TYPE           | 类型     | 可选必选说明：必选参数 参数含义：查询类型。 数据来源：本端规划 取值范围：枚举类型。 SUBS_POLICY：查询规则类型的订阅信息。SUBS_CONFIG：查询配置类型的订阅信息。LOCAL_RPT_EVT：查询本地可以支持订阅的RPT event信息。LOCAL_FLT_EVT：查询本地可以支持订阅的过滤Event信息。LOCAL_AGGR_EVT：查询本地可以支持订阅的汇聚Event信息。LOCAL_TOPN_EVT：查询本地可以支持订阅的Topn Event信息。 默认值：无 配置原则：无                                                                                                                                                                                                                                      |
| SUBSPOLICYID   | 订阅规则ID | 可选必选说明：条件可选参数 前提条件：该参数在“TYPE”配置为“SUBS_POLICY”时为可选参数。 参数含义：条件可选，type参数是SubsPolicy时可选，用于输入要查询的订阅规则ID，如果没有输入，会显示所有Policy类型的订阅规则信息。 数据来源：本端规划 取值范围：{{0~4294967295}}。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                     |
| SUBSCONFIGTYPE | 配置信息类型 | 可选必选说明：条件必选参数 前提条件：该参数在“TYPE”配置为“SUBS_CONFIG”时为必选参数。 参数含义：条件可选，type参数是SubsConfig时可选，用于输入要查询的配置信息类型。 数据来源：本端规划 取值范围：枚举类型。 CONFIG_TYPE_REALRPT：实时报表。CONFIG_TYPE_FILTERGROUP：配置过滤器组。CONFIG_TYPE_QOSMONITOR：Qos Monitor规则。CONFIG_TYPE_HIGHBAND：高带宽用户规则。CONFIG_TYPE_VVIP：VVIP用户GRB保障策略。CONFIG_TYPE_USRTATS：直播业务的用户统计信息。CONFIG_TYPE_CCO_CELLSPEC：CCO小区及web应用规则。CONFIG_TYPE_CCO_ABRVIDEO：CCO视频应用规则。CONFIG_TYPE_CCO_CELLLEVEL：CCO小区分级规则。CONFIG_TYPE_CCO_CTRL：CCO控制规则。CONFIG_TYPE_QOE：客户感知体验。 默认值：无 配置原则：无 |

#### 使用实例

显示运营商查阅报表订阅信息：

```
DSP RPTSUBSINFO: TYPE=LOCAL_FLT_EVT;
```
