# 修改知名端口（MOD WELLKNOWNPORT）

#### 命令功能

**适用NF：PGW-U、UPF**

MOD WELLKNOWNPORT此命令用来修改知名端口。

#### 注意事项

- 该命令执行后立即生效。
- 修改知名端口，支持端口段、支持多个端口一种协议，如果配置的端口有重叠，则根据优先级匹配。 如果通过匹配端口号仍无法识别协议类型，则使用特征字识别。
- 对于协议类型，如FTP，HTTP等类型，可以配置协议类型的知名端口。
- 配置同名WellKnownPort相当于对其进行修改。修改一原来存在的配置，对已经识别的业务不受影响，新访问的业务将按照修改后知名端口进行匹配。
- 配置ProtocolName时，SubProtocol表记录必须存在。
- 需要添加协议识别特征库。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                                                                                                                                                                      |
|:--------------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IDENPROTNAME  | 知名端口名称  | 可选必选说明：必选参数 参数含义：该参数用于指定指知名端口名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                                                                                              |
| PROTOCOLNAME  | 协议名称    | 可选必选说明：必选参数 参数含义：该参数用于指定协议名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：数据源为系统支持识别的所有类型的子协议，可以通过工程命令smctrldsp protocol-list查询。                                                                                                            |
| PORTOP        | 端口范围操作码 | 可选必选说明：必选参数 参数含义：该参数用于指定端口范围操作码。 数据来源：本端规划 取值范围：枚举类型。 EQUAL：等于指定值。LT：小于等于指定值。GT：大于等于指定值。RANGE：在指定范围内，包括边界值。 默认值：无 配置原则： 当运营商需要配置端口号等于指定值时，该参数需配置为EQUAL。当运营商需要配置端口号小于等于指定值时，该参数需配置为LT。当运营商需要配置端口号大于等于指定值时，该参数需配置为GT。当运营商需要配置端口号在指定范围（包括边界值）时，该参数需配置为RANGE。 |
| STARTPORT     | 起始端口号   | 可选必选说明：条件必选参数 前提条件：该参数在“PORTOP”配置为“EQUAL”、“GT” 或 “RANGE”时为必选参数。 参数含义：该参数用于指定起始端口号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无 配置原则：当PORTOP配置为EQUAL、GT或RANGE时，该参数为必选参数。                                                                                       |
| ENDPORT       | 结束端口号   | 可选必选说明：条件必选参数 前提条件：该参数在“PORTOP”配置为“LT” 或 “RANGE”时为必选参数。 参数含义：该参数用于指定结束端口号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无 配置原则：当PORTOP配置为LT或RANGE时,该参数为必选参数。                                                                                                     |
| PRIORITY      | 优先级     | 可选必选说明：必选参数 参数含义：该参数用于指定优先级。 数据来源：本端规划 取值范围：整数类型，取值范围为1～65535。建议配置时按照5、10、15等配置，便于以后再插入新的优先级。 默认值：无 配置原则：无                                                                                                                                                |
| CFGDOMAINNAME | 配置域名称   | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。                                                                                                                                                        |

#### 使用实例

修改WellKnownPort知名端口，“IDENPROTNAME”为“10086”，“PROTOCOLNAME”为“ftp”，“PORTOP”为“RANGE”,“PRIORITY”为“100”，“STARTPORT”为“1000”，“ENDPORT”为“3000”：

```
MOD WELLKNOWNPORT:IDENPROTNAME="10086",PROTOCOLNAME="ftp",PORTOP=RANGE,STARTPORT=1000,ENDPORT=3000,PRIORITY=100;
```
