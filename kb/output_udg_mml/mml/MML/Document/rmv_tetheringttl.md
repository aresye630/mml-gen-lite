# 删除tethering的TTL值（RMV TETHERINGTTL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于删除判断tethering的TTL值。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称           | 参数说明                                                                                   |
|:---------|:---------------|:---------------------------------------------------------------------------------------|
| TTLVALUE | Tethering TTL值 | 可选必选说明：必选参数 参数含义：该参数用于设置判断tethering的TTL值。 数据来源：本端规划 取值范围：整数类型，取值范围为1～255。 默认值：无 配置原则：无 |

#### 使用实例

删除判断tethering的TTL值：

```
RMV TETHERINGTTL: TTLVALUE=56;
```
