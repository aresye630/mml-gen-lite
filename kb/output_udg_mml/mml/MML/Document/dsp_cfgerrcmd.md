# 显示CFG方式配置恢复的失败信息（DSP CFGERRCMD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示CFG方式配置恢复的失败信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

显示CFG方式配置恢复的失败信息：

```
DSP CFGERRCMD:SERVICEINSTANCE="vnfc";
```

```

```

#### 输出结果说明

| 输出项名称   | 输出项解释            |
|:--------|:-----------------|
| 时间      | 用于指定配置恢复失败的时间。   |
| 原因      | 用于指定配置恢复失败的原因。   |
| 行号      | 用于指定命令在配置中所在的行号。 |
| 视图      | 用于指定配置恢复失败的视图。   |
| 命令      | 用于指定命令内容。        |
