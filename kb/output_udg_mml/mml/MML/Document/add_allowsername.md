# 增加基于地址的白名单（ADD ALLOWSERNAME）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于增加基于IP地址过滤的允许访问的服务白名单，当系统作为服务端时，添加到白名单中的指定IP地址的服务，只允许白名单中指定的对端地址的服务访问。未添加到白名单的服务则允许所有对端访问。

## 注意事项

- 该命令执行后立即生效。

- 如果配置了该白名单，白名单中的服务不允许白名单以外的NF的业务访问。

- 最多可输入2048条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                      |
|:-------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INDEX        | 索引     | 可选必选说明：必选参数  参数含义：该参数用于指定白名单索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~2047。  默认值：无  配置原则：无                                                                                                         |
| NFINSTANCEID | NF实例标识 | 可选必选说明：必选参数  参数含义：该参数用于指定添加到白名单的服务的NF实例标识。目前本参数不生效。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~60。  默认值：无  配置原则：无                                                                                    |
| SERVICENAME  | 服务名称   | 可选必选说明：必选参数  参数含义：该参数用于指定添加到白名单中的服务的服务名称，取自URI中的servicename。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无                                                                          |
| LOCALADDR    | 本端地址   | 可选必选说明：必选参数  参数含义：该参数用于指定添加到白名单的服务的服务地址。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无                                                                                              |
| PEERADDR     | 对端地址   | 可选必选说明：必选参数  参数含义：该参数用于指定允许访问白名单中的服务的对端地址。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无                                                                                            |
| NFAFID       | NFAFID | 可选必选说明：可选参数  参数含义：该参数用于指定添加到白名单的服务的NFAFID。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~60。  默认值：无  配置原则：  当参数“服务名称”为"nsg-senseservice"，"nsg-sensetask"，"nscf-senseservice"，"nscf-sensetask"时，必须配置该参数。 |

## 使用实例

添加标识为SMF\_Instance\_0的NF实例的服务类型为nsmf-event-exposure且本端地址为192.168.0.1的服务，仅允许对端地址为192.168.0.2的服务访问，则执行如下命令：

```
ADD ALLOWSERNAME: INDEX=0, NFINSTANCEID="SMF_Instance_0", SERVICENAME="nsmf-event-exposure", LOCALADDR="192.168.0.1", PEERADDR="192.168.0.2";
```
