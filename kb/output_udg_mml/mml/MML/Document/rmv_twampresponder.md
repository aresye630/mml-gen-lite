# 删除TWAMP响应端（RMV TWAMPRESPONDER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除TWAMP响应端。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                            |
|:------------|:-------|:--------------------------------------------------------------------------------|
| RESPONDERID | 响应端索引  | 可选必选说明：必选参数  参数含义：该参数用于配置响应端索引。  数据来源：全网规划  取值范围：整数类型，取值范围是1~32。  默认值：无  配置原则：无 |

## 使用实例

删除响应端索引为1的实例：

```
RMV TWAMPRESPONDER: RESPONDERID=1;
```
