# 查询单通检测周期（LST SGLPASSPERIOD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

查询单通故障检测时间周期。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询单通故障检测时间周期：

```
LST SGLPASSPERIOD:;
```

```
RETCODE = 0  操作成功。

单通检测周期
------------
周期  =  20
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见SET SGLPASSPERIOD的参数说明。
