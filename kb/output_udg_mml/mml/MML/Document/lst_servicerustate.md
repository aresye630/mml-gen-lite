# 查询RU的信息(LST SERVICERUSTATE)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询当前配置表中存储的所有RU的状态信息。

#### 注意事项

- 该命令如果输入RUID，则查询指定RUID的RU信息。
- 如果命令输入的RUID在记录中不存在，则返回无记录。
- 该命令不输入RUID，则查询所有RU的信息。
- 存储故障场景下，以DSP SERVICERUSTATE返回结果为准。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                            |
|:----------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RUID            | RU的ID  | 可选必选说明：可选参数。 参数含义：RU的ID。 数据来源：本端规划 取值范围：整数类型，取值范围为64～4294967294 默认值：无。                                                                                          |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识，不支持对"VNFC类型名称"为VNFP、VNRS_VNFC、ACS、IPSEC_VNFC的RU状态查询。 |

#### 使用实例

显示当前所有RU的状态。

```
LST SERVICERUSTATE:SERVICEINSTANCE="CSLB_VNFC_999";
```

```
RETCODE = 0  操作成功。

结果如下
--------
RU的ID  RU的名字         ScaleGroup的名字   RU的状态 
64      CSLB_IP_RU_0064   SG0_CSLB_IPFWD      RU正常   
65      CSLB_IP_RU_0065   SG0_CSLB_IPFWD      RU正常 
(结果个数 = 2)
---    END
```

#### 输出结果说明

| 输出项名称         | 输出项解释                                                             |
|:--------------|:------------------------------------------------------------------|
| RU的ID         | RU的ID。 取值范围：整数类型，取值范围为64～4294967294                               |
| RU的名字         | RU的名字。 字符串类型，长度为：1～63                                             |
| ScaleGroup的名字 | RU所在ScaleGroup的名字。 字符串类型，长度为：1～63                                 |
| RU的状态         | RU的状态。 取值范围：“RU等待VM（裸机）创建完成”“RU插入”“RU注册”“RU等待软件初始化完成”“RU正常”“RU故障” |
