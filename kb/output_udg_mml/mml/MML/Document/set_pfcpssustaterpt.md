# 设置智能单元状态上报开关相关属性（SET PFCPSSUSTATERPT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、PGW-U、SGW-U**

该命令用于设置智能单元状态上报开关相关属性。包括过载上报阈值，过载停止上报阈值和定时器值。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称          | 参数说明                                                                                                                                                                        |
|:----------------|:--------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SWITCH          | 配置智能单元状态上报的开关 | 可选必选说明：必选参数 参数含义：该参数是配置智能单元状态上报的开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则： ENABLE：使能智能单元状态上报功能。DISABLE：不使能智能单元状态上报功能。                                      |
| OVERLOADRPTTHD  | 过载上报阈值        | 可选必选说明：条件可选参数 前提条件：该参数在“SWITCH”配置为“ENABLE”时为可选参数。 参数含义：过载上报阈值，过载达到阈值后，通知SMF过载状态。 数据来源：本端规划 取值范围：整数类型，取值范围为1～100。 默认值：无 配置原则：无                                               |
| OVERLOADSTOPTHD | 过载停止上报阈值      | 可选必选说明：条件可选参数 前提条件：该参数在“SWITCH”配置为“ENABLE”时为可选参数。 参数含义：过载停止上报阈值，过载上报后，低于过载停止上报阈值时，通知SMF正常状态；负载低于停止上报阈值后，后续若负载未达到上报阈值，则不再通知SMF。 数据来源：本端规划 取值范围：整数类型，取值范围为1～100。 默认值：无 配置原则：无 |
| TIMERVALUE      | 指定定时器值        | 可选必选说明：条件可选参数 前提条件：该参数在“SWITCH”配置为“ENABLE”时为可选参数。 参数含义：指定定时器值，定期通知SMF智能单元状态，取值为0时表示关闭定期通知。 数据来源：本端规划 取值范围：整数类型，取值范围为0～60，单位为分钟。 默认值：无 配置原则：无                                |

#### 使用实例

设置智能单元状态上报开关为ENABLE时，设置过载上报阈值为90：

```
SET PFCPSSUSTATERPT:SWITCH=ENABLE,OVERLOADRPTTHD=90;
```
