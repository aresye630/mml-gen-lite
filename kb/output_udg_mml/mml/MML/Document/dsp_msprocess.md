# 显示微服务进程信息（DSP MSPROCESS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此命令用于显示微服务进程信息，如进程运行状态。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                                                        |
|:-----------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROCOBJECT | 操作类型   | 可选必选说明：必选参数  参数含义：该参数用于表示查询进程的关键字：进程类型名或进程ID。  数据来源：本端规划 取值范围： “PROCNAME（进程类型名）”：进程类型“PROCID（进程ID）”：进程ID  默认值：无  配置原则：无                                                                                                     |
| PROCNAME   | 进程类型名称 | 可选必选说明：该参数在"PROCOBJECT"配置为"PROCNAME"时为条件必选参数。  参数含义：该参数用于表示微服务进程所属的进程类型名称。进程类型名可以通过DSP MSPROCTYPE命令查询。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。  默认值：无  配置原则：无                                                                   |
| PROCID     | 进程ID   | 可选必选说明：该参数在"PROCOBJECT"配置为"PROCID"时为条件必选参数。  参数含义：该参数用于表示微服务进程ID，查询进程ID为PROCID的进程信息。DSP MSPROCESS命令按进程类型名查询会返回该类型的所有进程ID。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~100。  默认值：无  配置原则：无                                               |
| PROCSTAT   | 进程状态   | 可选必选说明：该参数在"PROCOBJECT"配置为"PROCNAME"、"PROCID"时为条件可选参数。  参数含义：该参数用于表示微服务进程状态，根据进程状态筛选查询结果。  数据来源：本端规划 取值范围： “Unknown（未知状态）”：进程是未知状态“Normal（正常状态）”：进程启动正常“Fault（异常状态）”：进程是故障状态“Ready（就绪状态）”：进程启动正常，并且进程内业务状态就绪  默认值：无  配置原则：无 |
| MEID       | 网元ID   | 可选必选说明：该参数在"PROCOBJECT"配置为"PROCNAME"、"PROCID"时为条件可选参数。  参数含义：该参数用于指定网元来查询进程信息；网元ID可以通过LST ME命令查询出来。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~40。  默认值：无  配置原则：  该参数若不输入，则表示查询所有网元下的进程。                                               |

## 使用实例

- 按进程类型查询微服务进程

  ```
  %%DSP MSPROCESS: PROCOBJECT=PROCNAME, PROCNAME="CELL_SBIM", MEID="0";%%
  RETCODE = 0  操作成功

  结果如下
  --------
  进程类型名         进程ID                                           进程状态       节点ID       故障类型   故障原因     进程类型      网元ID

  CELL_SBIM          sbim-pod-6649765996-2mjhb192-168-0-1__1001__0    就绪状态       192.168.1.1  0          0            1001          0
  CELL_SBIM          sbim-pod-6649765996-dsn56192-168-0-2__1001__0    就绪状态       192.168.1.2  0          0            1001          0
  (结果个数 = 2)

  ---    END
  ```
- 按进程ID查询微服务进程

  ```
  %%DSP MSPROCESS: PROCOBJECT=PROCID, PROCID="sbim-pod-6649765996-2mjhb192-168-0-1__1001__0", MEID="0";%%
  RETCODE = 0  操作成功

  结果如下
  --------
  进程类型名称  =  CELL_SBIM
        进程ID  =  sbim-pod-6649765996-2mjhb192-168-0-1__1001__0
      进程状态  =  就绪状态
        节点ID  =  192.168.1.1
      故障类型  =  0
      故障原因  =  0
      进程类型  =  1001
        网元ID  =  0
  (结果个数 = 1)

  ---    END
  ```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                                |
|:--------|:-------------------------------------------------------------------------------------------------------------------------------------|
| 进程类型名称  | 该参数用于表示微服务进程所属的进程类型名称。进程类型名可以通过DSP MSPROCTYPE命令查询。                                                                                   |
| 进程ID    | 该参数用于表示微服务进程ID，查询进程ID为PROCID的进程信息。DSP MSPROCESS命令按进程类型名查询会返回该类型的所有进程ID。                                                              |
| 进程状态    | 该参数用于表示微服务进程状态，根据进程状态筛选查询结果。 取值说明： “Unknown（未知状态）”：进程是未知状态“Normal（正常状态）”：进程启动正常“Fault（异常状态）”：进程是故障状态“Ready（就绪状态）”：进程启动正常，并且进程内业务状态就绪 |
| 节点ID    | 该参数用于表示微服务进程所在节点的编号。                                                                                                                 |
| 故障类型    | 该参数用于表示进程故障类型。                                                                                                                       |
| 故障原因    | 该参数用于表示进程故障原因。                                                                                                                       |
| 进程类型    | 该参数用于表示微服务进程所属的进程类型。                                                                                                                 |
| 网元ID    | 该参数用于指定网元来查询进程信息；网元ID可以通过LST ME命令查询出来。                                                                                               |
