# 查询ApnReportAttr配置（LST APNREPORTATTR）

- 命令功能
- 注意事项
- 操作用户权限

- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于查询性能统计，头增强，给CloudUDN上报记录时，与其他网元交互和支持拥塞控制使用的APN类型。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                   |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN    | APN名称  | 可选必选说明：可选参数 参数含义：该参数用于指定配置上报属性的APN。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”特殊字符，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

查询APN apn1.com下性能统计，头增强，给CloudUDN上报记录时，与其他网元交互时和支持拥塞控制使用的APN类型：

```
LST APNREPORTATTR:APN="apn1.com";
```

```

-----------------

            上报给话统的APN名  =  请求的

                     拥塞控制  =  使能

```
