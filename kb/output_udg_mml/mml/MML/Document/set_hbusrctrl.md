# 设置高带宽用户功能控制参数（SET HBUSRCTRL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于设置高带宽用户功能相关控制参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | FASTFWDSW   | LOADBALANCESW   |   LOCALCFGAGETM |   SUBSCFGAGETM |   AUTOLEARNAGETM |
|:-------|:------------|:----------------|----------------:|---------------:|-----------------:|
| 初始值    | DISABLE     | DISABLE         |              60 |            300 |             7200 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称               | 参数说明                                                                                                                                                                              |
|:---------------|:-------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FASTFWDSW      | 高带宽用户快转加速开关        | 可选必选说明：可选参数 参数含义：该参数用于设置高带宽用户快转加速功能是否使能。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能高带宽用户加速功能。ENABLE：使能高带宽用户快转加速功能。 默认值：无 配置原则：无                                                             |
| LOADBALANCESW  | 高带宽用户资源均衡开关        | 可选必选说明：可选参数 参数含义：该参数用于设置高带宽用户资源均衡加速功能是否使能。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能高带宽用户资源均衡功能。ENABLE：使能高带宽用户资源均衡加速功能。 默认值：无 配置原则：该参数仅在FASTFWDSW参数配置为ENABLE时生效。                           |
| GLBPROTGROUP   | 全局协议组名称            | 可选必选说明：可选参数 参数含义：该参数用于设置高带宽用户支持的协议组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则： 该参数使用ADD PROTOCOLGROUP命令配置生成。该命令配置为NULL时表示所有协议均不支持高带宽用户快转加速功能。该参数只能配置仅包含Speedtest业务相关协议的协议组。 |
| LOCALCFGAGETM  | 本地配置高带宽用户老化时间（秒）   | 可选必选说明：可选参数 参数含义：该参数用于设置本地配置的高带宽用户记录老化时间。 数据来源：本端规划 取值范围：整数类型 ，取值范围是0~3600，单位是秒。 默认值：无 配置原则：该参数配置为0时代表不老化。                                                                        |
| SUBSCFGAGETM   | 订阅接口下发高带宽用户老化时间（秒） | 可选必选说明：可选参数 参数含义：该参数用于设置订阅接口下发高带宽用户老化时间。 数据来源：本端规划 取值范围：整数类型 ，取值范围是0~3600，单位是秒。 默认值：无 配置原则：该参数配置为0时代表不老化。                                                                         |
| AUTOLEARNAGETM | 自学习高带宽用户老化时间（秒）    | 可选必选说明：可选参数 参数含义：该参数用于设置自学习高带宽用户老化时间。 数据来源：本端规划 取值范围：整数类型 ，取值范围是0~999999999，单位是秒。 默认值：无 配置原则：该参数配置为0时代表不老化。                                                                       |

#### 使用实例

设置高带宽用户快转加速功能使能：

```
SET HBUSRCTRL: FASTFWDSW=ENABLE;
```
