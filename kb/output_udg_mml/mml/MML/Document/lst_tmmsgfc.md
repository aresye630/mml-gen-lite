# 查询跟踪消息流控状态（LST TMMSGFC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询跟踪消息流控状态。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询跟踪消息流控状态：

```
%%LST TMMSGFC:;%%
RETCODE = 0  操作成功

跟踪消息流控状态
----------------
客户端启用流控  =  是
(结果个数 = 1)

---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息，输出结果说明如表1所示。

命令执行异常，会返回提示对应的失败信息。错误码列表如表2所示。

| 输出项名称   | 输出项解释                                                  |
|:--------|:-------------------------------------------------------|
| 客户端启用流控 | 用于表示从跟踪服务到客户端的消息流控是否开启。 取值范围： “是”：表示开启流控。 “否”：表示未开启流控。 |

|    错误码 | 消息解释   | 原因分析         | 处理建议        |
|-------:|:-------|:-------------|:------------|
| 101601 | 系统异常   | 服务离线、数据库异常等。 | 等待几分钟后，请重试。 |
