# 修改基于协议的质差检测策略（MOD SSUPROTCOLGROUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于修改基于七层协议的质差判断策略。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                                                                                                        |
|:--------------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DEFPRTGRPNAME | 自定义协议组名称 | 可选必选说明：必选参数 参数含义：该参数用于指定自定义的三级协议组名称。 数据来源：本端规划 取值范围：字符串类型，不区分大小写，长度为1-63位。 默认值：无 配置原则：无                                                                                     |
| PROTOCOLNAME  | 协议名称     | 可选必选说明：必选参数 参数含义：该参数用于指定三级协议名称。 数据来源：本端规划 取值范围：参数来源于知识库中支持的三级协议名称。 默认值：无 配置原则：无                                                                                             |
| POLICYCNDNAME | 策略参数名    | 可选必选说明：可选参数 参数含义：该参数用于指定需要绑定的策略参数名。 数据来源：本端规划 取值范围：参数来源于ADD POLICYCONDITION中的POLICYCNDNAME。 默认值：无 配置原则：无                                                                    |
| QOEDETECTCOND | 业务流量特征   | 可选必选说明：可选参数 参数含义：该参数用于指定进行质差判断的业务流量特征。 数据来源：本端规划 取值范围：枚举类型。 ALL_CHECK：均进行质差判断。UP_BIGFLOW_CHECK：只对上行速率大于下行速率的业务进行质差判断。DOWN_BIGFLOW_CHECK：只对下行速率大于上行速率的业务进行质差判断。 默认值：无 配置原则：无 |
| CATEGORYID    | 应用大类ID   | 可选必选说明：可选参数 参数含义：应用大类ID。 数据来源：本端规划 取值范围：0-200。 默认值：无 配置原则：无                                                                                                                 |

#### 使用实例

修改自定义协议组名称为ssuprotcolgroupname下协议名称为http的质差检测策略为policyname2：

```
MOD SSUPROTCOLGROUP: DEFPRTGRPNAME="ssuprotclogroupname", PROTOCOLNAME="http", POLICYCNDNAME="policyname2";
```
