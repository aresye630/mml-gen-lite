# 显示APN N6故障状态上报周期（LST RPTPERIOD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询APN N6故障状态上报周期。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询APN N6故障状态上报周期,使用一下命令：

```
LST RPTPERIOD:;
```

```
RETCODE = 0  操作成功

APN N6故障状态上报周期
------------------------------------------
APN N6故障状态上报周期  =  4
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见SET RPTPERIOD的参数说明。
