# 设置跳过调整HAF域开关（SET SKIPADJUSTHAFDM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置跳过调整HAF域开关。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| SWITCH   |
|:---------|
| OFF      |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                                                                              |
|:-------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
| SWITCH | 跳过HAF调整域开关 | 可选必选说明：必选参数  参数含义：该参数用于表示跳过HAF域调整的触发方式，值为ON表示跳过HAF调整域开关打开，值为OFF表示跳过HAF调整域开关关闭。  数据来源：本端规划 取值范围： OFF（关闭跳过HAF调整域开关）ON（打开跳过调整HAF域开关）  默认值：无。  配置原则：无 |

## 使用实例

设置跳过调整HAF域开关为关闭。

```
SET SKIPADJUSTHAFDM:SWITCH=OFF;
```
