# 增加密码禁用词（ADD PWDBLACKLIST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于增加密码禁用词。配置密码禁用词后，所有包含密码禁用词的字符串（不区分大小写）都不能被配置成本地用户的密码。可以通过执行查询本地用户（**LST OP**）命令查看本地用户的信息。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为32。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                   |
|:--------------|:-------|:-----------------------------------------------------------------------|
| FORBIDDENWORD | 密码禁用词  | 可选必选说明：必选参数 参数含义：密码禁用词。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～64。不区分大小写。 默认值：无 |

#### 使用实例

设置字符a为密码禁用词：

```
ADD PWDBLACKLIST:FORBIDDENWORD="a";
```
