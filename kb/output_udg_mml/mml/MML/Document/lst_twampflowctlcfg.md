# 查询跟踪流控配置（LST TWAMPFLOWCTLCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

用于查询TWAMP功能的跟踪流控配置。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询TWAMP功能的跟踪流控配置参数。

```
%%LST TWAMPFLOWCTLCFG:;%%
RETCODE = 0  操作成功

结果如下
--------
    跟踪流控开关  =  打开
    流控恢复阈值  =  60
    流控触发阈值  =  70
允许跟踪创建阈值  =  60
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称    | 输出项解释            |
|:---------|:-----------------|
| 跟踪流控开关   | 该参数用于控制流控功能开关。   |
| 流控恢复阈值   | 该参数用于设置流控恢复阈值。   |
| 流控触发阈值   | 该参数用于设置流控触发阈值。   |
| 允许跟踪创建阈值 | 该参数用于设置允许跟踪创建阈值。 |
