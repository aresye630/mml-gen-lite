# IP Tracert（TRACERT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

TRACERT命令用来测试数据包从发送主机到目的地所经过的路径节点。对于网络中出现的故障，可以执行PING命令，根据回应的报文查看网络连通的情况，然后进一步使用该命令查看网络中出现故障的位置，为故障诊断提供依据。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

| VPNNAME           | VPN实例名称    | 可选必选说明：可选参数 参数含义：该参数用于指定VPN实例名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                                                    |
| SOURCEIPV4ADDRESS | 源IPv4地址    | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPv4”时为可选参数。 参数含义：该参数用于指定源IPv4地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无                     |
| SOURCEIPV6ADDRESS | 源IPv6地址    | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPv6”时为可选参数。 参数含义：该参数用于指定源IPv6地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无                     |
| DESTIPV4ADDRESS   | 目的IPv4地址   | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPv4”时为必选参数。 参数含义：该参数用于指定目的主机IPv4地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无                  |
| DESTIPV6ADDRESS   | 目的IPv6地址   | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPv6”时为必选参数。 参数含义：该参数用于指定目的主机IPv6地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无                  |

| TIMEOUT           | 超时时间（ms）   | 可选必选说明：可选参数 参数含义：该参数用于指定等待响应报文的超时时间。 数据来源：本端规划 取值范围：整数类型，取值范围为1～20000，单位是毫秒。 默认值：5000                                      |
| FIRSTTTL          | 初始TTL      | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPv4”时为可选参数。 参数含义：该参数用于指定初始TTL。 数据来源：本端规划 取值范围：整数类型，取值范围为1～255。 默认值：1                |
| MAXTTL            | 最大TTL      | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPv4”时为可选参数。 参数含义：该参数用于指定最大TTL。 数据来源：本端规划 取值范围：整数类型，取值范围为1～255。 默认值：30               |
| FIRSTHOPLIMIT     | 初始跳限制      | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPv6”时为可选参数。 参数含义：该参数用于指定初始跳限制。 数据来源：本端规划 取值范围：整数类型，取值范围为1～255。 默认值：1                |
| MAXHOPLIMIT       | 最大跳限制      | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPv6”时为可选参数。 参数含义：该参数用于指定最大跳限制。 数据来源：本端规划 取值范围：整数类型，取值范围为1～255。 默认值：30               |
| IPV4PACKETSIZE    | IPv4报文字节数  | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPv4”时为可选参数。 参数含义：该参数用于指定IPv4报文大小。 数据来源：本端规划 取值范围：整数类型，取值范围为12～9600，单位是字节。 默认值：12    |

| PACKETCOUNT       | 发包数        | 可选必选说明：可选参数 参数含义：该参数用于指定每次发送的探测数据包个数。 数据来源：本端规划 取值范围：整数类型，取值范围为1～65535，单位是包数。 默认值：3                                        |

#### 使用实例

- 检查从发送主机到IP地址为10.137.144.1的主机所经过的路径节点：

  ```
  TRACERT: IPVERSION=IPv4, DESTIPV4ADDRESS="10.137.144.1";
  ```

  ```
   traceroute to 10.137.144.1(10.137.144.1), max hops: 30, packet length: 40

   1 10.137.144.1 2 ms

   1 10.137.144.1 1 ms

   1 10.137.144.1 1 ms

  共有7个报告
  ---    END
  ```
- 检查从发送主机到IPv6地址为2001:db8::1的主机所经过的路径节点：

  ```
  TRACERT: IPVERSION=IPv6, DESTIPV6ADDRESS="2001:db8::1";
  ```

  ```
    traceroute to 2001:db8::1  30 hops max, 60 bytes packet

   1 2001:db8::1 107 ms

   1 2001:db8::1 1 ms

   1 2001:db8::1 1 ms

  共有7个报告
  ---    END
  ```
- 检查从发送主机到IP地址为10.137.144.1的主机所经过的路径节点，同时显示经过节点的标签信息：

  ```
  TRACERT: IPVERSION=IPv4, DESTIPV4ADDRESS="10.137.144.1", MPLSLABEL=ENABLE;
  ```

  ```
   traceroute to 10.137.144.1(10.137.144.1), max hops: 30, packet length: 40

   1 10.137.144.1[MPLS Label=32894 Exp=0 S=1 TTL=1] 2 ms

   1 10.137.144.1[MPLS Label=32894 Exp=0 S=1 TTL=1] 1 ms

   1 10.137.144.1[MPLS Label=32894 Exp=0 S=1 TTL=1] 1 ms

  共有7个报告
  ---    END
  ```
