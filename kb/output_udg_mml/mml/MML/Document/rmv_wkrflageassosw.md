# 删除Worker流表老化关联开关（RMV WKRFLAGEASSOSW）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于删除特定类型Worker的流表老化关联功能开关。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                     |
|:-----------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------|
| WORKERNAME | Worker名称 | 可选必选说明：必选参数 参数含义：该参数用于设置需要控制流表关联老化功能的Worker名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：根据部署的业务策略选择相应的子策略名称。选择范围和ADD RULE的WORKERNAME一致。 |

#### 使用实例

当需要删除to的流表老化关联功能开关时，进行如下设置：

```
RMV WKRFLAGEASSOSW: WORKERNAME="to";
```
