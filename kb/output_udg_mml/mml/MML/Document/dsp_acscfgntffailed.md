# 查询ACS配置推送失败信息(DSP ACSCFGNTFFAILED)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

通过本命令可以查看当前存在的业务侧推送及校验失败的对象信息。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                        |
|:------------|:-------|:--------------------------------------------------------------------------------------------|
| SERVICENAME | 服务名称   | 可选必选说明：可选参数。 参数含义：用于指定需要查询的微服务的服务名称。 取值范围：长度1~255的字符串。 默认值：无。 配置原则：可以使用DSP ACSSYNCINFO命令查询。 |
| INSTANCEID  | 实例ID   | 可选必选说明：可选参数。 参数含义：用于指定需要查询的微服务实例ID。 取值范围：长度1~255的字符串。 默认值：无。 配置原则：可以使用DSP ACSSYNCINFO命令查询。  |

## 使用实例

查看当前存在失败的对象信息时，执行以下命令：

```
DSP ACSCFGNTFFAILED:;
```

```
%%DSP ACSCFGNTFFAILED:;%%
RETCODE = 0  操作成功

操作结果如下
------------
    服务名称  =  ccell4-app237-pod-6cc9df6ccc-hlmgm
      实例ID  =  ccell4-app237-pod-6cc9df6ccc-hlmgm172-16-1-108_cCell
  服务IP地址  =  172.16.1.108
  服务端口号  =  830
    对象名称  =  testsdk
(结果个数 = 1)

---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。输出结果说明如下表所示。

| 输出项名称   | 输出项解释         |
|:--------|:--------------|
| 服务名称    | 微服务名称。        |
| 实例ID    | 微服务实例ID。      |
| 服务IP地址  | 微服务使用的IP地址。   |
| 服务端口号   | 微服务使用的端口号。    |
| 对象名称    | 推送或校验失败的对象名称。 |
