# 查询Domain Bypass配置（LST DOMAINBYPASS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询已配置的不需要进行domain学习的IP地址信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                             |
|:----------|:---------|:-------------------------------------------------------------------------------------------------|
| IPVERSION | IP地址版本类型 | 可选必选说明：可选参数 参数含义：该参数用于指定IP地址版本类型。 数据来源：本端规划 取值范围：枚举类型。 IPV4：IPv4地址类型。IPV6：IPv6地址类型。 默认值：无 配置原则：无 |

#### 使用实例

查询Domain Bypass配置：

```
LST DOMAINBYPASS:;
```

```
RETCODE = 0  操作成功

结果如下
------------------------
IP地址版本类型 	IPv4地址 	  IPv6地址  		配置域名称

IPV4         	192.168.0.1       ::              NULL
IPV6         	0.0.0.0       2001:db8::01        NULL
(结果个数 = 2)

---    END
```
