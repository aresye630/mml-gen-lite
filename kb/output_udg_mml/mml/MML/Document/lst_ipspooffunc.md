# 展示IP防攻击功能状态（LST IPSPOOFFUNC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该参数用于查询当前配置的IP防欺诈功能开关状态。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

使用LST ANTISPOOFINGTHD命令查询当前配置的IP防欺诈功能开关状态：

```
LST IPSPOOFFUNC:;
```

```
RETCODE = 0 操作成功

IPSpoof攻击防护
-------------
上行IP防攻击开关 = 已使能
下行IP防攻击开关 = 已使能
(结果个数 = 1)

--- 结束
```

#### 输出结果说明

参见SET IPSPOOFFUNC的参数说明。
