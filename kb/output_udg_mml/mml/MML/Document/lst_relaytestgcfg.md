# 查询媒体中继测试分组配置（LST RELAYTESTGCFG）

- 命令功能

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询媒体中继测试分组配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识           | 参数名称       | 参数说明                                                                               |
|:---------------|:-----------|:-----------------------------------------------------------------------------------|
| RELAYTESTGNAME | 媒体中继测试分组名称 | 可选必选说明：可选参数 参数含义：该参数用于设置媒体中继测试分组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无 |

#### 使用实例

假如需要查询媒体中继测试分组配置，则命令如下：

```
LST RELAYTESTGCFG:;
```
