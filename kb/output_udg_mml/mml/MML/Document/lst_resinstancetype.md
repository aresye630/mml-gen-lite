# 查询资源实例类型（LST RESINSTANCETYPE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询资源实例类型。当用户需要知道本网元VNFC下支持哪些资源实例类型时，可以使用此命令查询。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

查询资源实例类型：

```
LST RESINSTANCETYPE:SERVICEINSTANCE="vnfc";
```

```
RETCODE = 0  操作成功。

结果如下
------------------------
资源实例类型 

CSDB_SD_RU
CSDB_OM_RU
(结果个数 = 2)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释          |
|:--------|:---------------|
| 资源实例类型  | 用于表示资源实例类型的名称。 |
