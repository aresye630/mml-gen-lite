# 查询以太网隧道自动化多虚拟网卡配置模板（LST AUTOSCALINGETHTRUNK）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询以太网隧道多虚拟网卡自动化配置模板信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称        | 参数说明                                                                      |
|:--------------|:------------|:--------------------------------------------------------------------------|
| ETHTRUNKTMPID | 以太Trunk模板ID | 可选必选说明：可选参数 参数含义：该参数用来指定以太Trunk模板ID。 数据来源：本端规划 取值范围：整数类型，取值范围为1～99。 默认值：无 |

#### 使用实例

查询以太网隧道多虚拟网卡自动化配置模板信息：

```
LST AUTOSCALINGETHTRUNK: ETHTRUNKTMPID=1;
```

