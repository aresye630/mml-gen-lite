# 恢复MOS补偿因子（RTR VONRMOSFACTOR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于恢复MOS补偿因子为系统初始设置值。

#### 注意事项

- 该命令执行后立即生效。
- 如果MOSCODEC设置为SM\_MOS\_CODEC\_ALL，则表示对所有MOSCODEC进行设置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                       |
|:---------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MOSCODEC | 语音编解码类型 | 可选必选说明：必选参数 参数含义：该参数用于指语音编解码类型。 数据来源：本端规划 取值范围：枚举类型。 MOS_CODEC_AMR_NB：编解码类型为AMR NB。MOS_CODEC_AMR_WB：编解码类型为AMR WB。MOS_CODEC_G711：编解码类型为G.711。MOS_CODEC_G722：编解码类型为G.722。MOS_CODEC_G729：编解码类型为G.729。MOS_CODEC_EVS_NB：编解码类型为EVS NB。MOS_CODEC_EVS_WB：编解码类型为EVS WB。MOS_CODEC_EVS_SWB：编解码类型为EVS SWB。MOS_CODEC_EVS_FB：编解码类型为EVS FB。MOS_CODEC_EVS_AMR：编解码类型为EVS AMR-WB IO。MOS_CODEC_ALL：支持的全部语音编解码类型。 默认值：无 配置原则：无 |

#### 使用实例

- 恢复AMR WB编解码语音的MOS计算值的补偿因子为系统初始设置值：

  ```
  RTR VONRMOSFACTOR: MOSCODEC=MOS_CODEC_AMR_WB;
  ```
- 恢复所有编解码语音的MOS补偿因子为系统初始设置值，初始值见SET VONRMOSFACTOR：

  ```
  RTR VONRMOSFACTOR: MOSCODEC=MOS_CODEC_ALL;
  ```
