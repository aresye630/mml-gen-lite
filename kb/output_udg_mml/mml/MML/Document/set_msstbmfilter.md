# 设置MSS表项开关过滤规则（SET MSSTBMFILTER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

本命令属于高危命令，操作不当会导致性能下降，请谨慎使用并联系华为技术支持协助操作。

该命令用于设置过滤规则，是诊断开关命令；通过开关设置过滤规则，记录指定表项的刷表轨迹，协助问题定位；用户打开开关后对下表性能有影响，2小时后会自动关闭。

#### 注意事项

- 该命令执行后立即生效。
- 本命令用于开启TBM过滤规则开关，开启后会降低性能。开关将在2小时后自动关闭。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| ENABLE      | 开关使能     | 可选必选说明：必选参数 参数含义：该参数用于表示开关使能。 数据来源：本端规划 取值范围：枚举类型。 FALSE：关闭。TRUE：打开。 默认值：无                                                                                                |
| TABLEID     | 表ID      | 可选必选说明：条件可选参数 前提条件：该参数在“ENABLE”配置为“TRUE”时为可选参数。 参数含义：该参数用于表示表ID。如果不设置该参数，则表示匹配所有的表ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                        |

| LINEARINDEX | 线性索引值    | 可选必选说明：条件必选参数 前提条件：该参数在“TABLETYPE”配置为“linear”时为必选参数。 参数含义：该参数用于表示线性索引值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                                      |

| VPNID       | 虚拟专用网号   | 可选必选说明：条件必选参数 前提条件：该参数在“TABLETYPE”配置为“fib4” 或 “fib6”时为必选参数。 参数含义：该参数用于表示虚拟专用网号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                              |

#### 使用实例

设置表过滤规则：

```
SET MSSTBMFILTER:RUNAME="VNODE_VNRS_VNFC_IPU_0064",ENABLE=TRUE,TABLETYPE=linear, LINEARINDEX=1;
```
