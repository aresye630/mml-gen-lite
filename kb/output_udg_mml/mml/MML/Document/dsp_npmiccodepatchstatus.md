# 显示NP微码补丁加载状态（DSP NPMICCODEPATCHSTATUS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示NP微码补丁加载状态信息。

#### 注意事项

- 该命令仅适用于NP卡加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                          |
|:-------|:-------|:----------------------------------------------------------------------------------------------|
| RUID   | RU编号   | 可选必选说明：必选参数。 参数含义：RU编号。 数据来源：本端规划。 取值范围：整数类型，取值范围为0～4294967294。 配置原则：使用DSP RU命令查询RU编号。 默认值：无。 |

#### 使用实例

显示RUID为66的NP卡微码补丁加载状态信息：

```
DSP NPMICCODEPATCHSTATUS:RUID=66;
```

```
RETCODE = 0  操作成功

结果如下
--------
补丁状态  =  未加载        
(结果个数 = 1)

---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                                                                                              |
|:--------|:---------------------------------------------------------------------------------------------------|
| 补丁状态    | NP微码补丁加载状态。 补丁状态枚举类型： 未加载：未加载NP微码补丁。加载中：正在加载NP微码补丁。加载成功：加载NP微码补丁成功。回退中：正在回退NP微码补丁。回退成功：回退NP微码补丁成功。 |
