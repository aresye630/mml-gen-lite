# 创建OSPFv3域标识符配置（ADD OSPFV3DOMAINID）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于配置OSPFv3域标识符。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为8000。
- 只有执行ADD OSPFV3配置了OSPFV3进程后才能使用此命令。
- 该命令只能在私网OSPFv3进程下运行。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称      | 参数说明                                                                                                                                         |
|:----------------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------|
| PROCID          | OSPFv3进程号 | 可选必选说明：必选参数 参数含义：OSPFv3进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 配置原则：OSPFv3进程必须已经存在。请使用LST OSPFV3命令查看可用的OSPFv3进程。                   |
| DOMAINID        | 域标识符      | 可选必选说明：必选参数 参数含义：OSPFv3域标识符。 数据来源：本端规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无                                                                          |
| DOMAINIDTYPE    | 域标识符的类型   | 可选必选说明：可选参数 参数含义：指定OSPFv3域标识符的类型。 数据来源：本端规划 取值范围：枚举类型。 Type0005：Type0005。Type0105：Type0105。Type0205：Type0205。Type8005：Type8005。 默认值：Type0005 |
| DOMAINTYPEVALUE | 域标识符类型的值  | 可选必选说明：可选参数 参数含义：指定OSPFv3域标识符类型的值。 数据来源：本端规划 取值范围：十六进制整数类型，取值范围为0x0～0xFFFF。 默认值：0                                                            |
| DOMAINIDSECFLG  | 次级域标识符    | 可选必选说明：可选参数 参数含义：指定次级域标识符。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：FALSE                                                               |

#### 使用实例

配置OSPFv3进程的域标识符：

```
ADD OSPFV3DOMAINID:PROCID=1,DOMAINID="10.1.1.0",DOMAINTYPEVALUE="234";
```
