# 修改NP升级平面（MOD NPUPGPLANE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来修改NP升级平面。

#### 注意事项

- 该命令执行后立即生效。
- 该命令仅适用于NP卡省交换组网模式。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                  |
|:--------|:-------|:------------------------------------------------------------------------------------------------------|
| RUID    | RU编号   | 可选必选说明：必选参数。 参数含义：RU编号。 数据来源：本端规划。 取值范围：整数类型，取值范围为0～4294967294。 默认值：无。 配置原则：使用LST NPUPGPLANE命令查询RU编号。 |
| PLANEID | 平面编号   | 可选必选说明：必选参数。 参数含义：该参数用于设置升级平面。 数据来源：本端规划。 取值范围： “plane_1”：升级平面一。“plane_2”：升级平面二。 默认值：无。 配置原则：无。       |

#### 使用实例

修改RUID为66的升级平面为plane\_2：

```
MOD NPUPGPLANE: RUID=66, PLANEID=plane_2;
```
