# 设置NP资源占用告警阈值（SET NPRESALARMTHRESHOLD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来设置NP资源占用告警阈值。

#### 注意事项

- 该命令执行后立即生效。
- 该命令仅适用于NP卡加速模式场景。
- 该命令当前只支持NP121/NP120，NP类型可通过DSP NPNODE命令查询。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                         |
|:------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RUID        | RU编号   | 可选必选说明：必选参数。 参数含义：该参数用于指定RU编号。 数据来源：本端规划。 取值范围：整数类型，输入长度范围为64～9999。 默认值：无。 配置原则：通过DSP RU命令查询。                                                                |
| RESTYPE     | 资源类型   | 可选必选说明：必选参数。 参数含义：该参数用于指定资源类型。 数据来源：本端规划。 取值范围：枚举类型 “NP_RESTYPE_ACL（ACL）”：ACL表项资源。 默认值：无。 配置原则：无。                                                            |
| REPORTTHLD  | 告警上报阈值 | 可选必选说明：可选参数。 参数含义：该参数用于指定对应资源占用告警上报阈值，当NP资源占用率大于等于该阈值时上报告警“ALM-89004 NP资源使用率异常告警”。 数据来源：本端规划。 取值范围：整数类型，输入长度范围为0～100，单位为百分比。 默认值：无。 配置原则：必须大于“告警清除阈值”参数的配置值。 |
| RECOVERTHLD | 告警清除阈值 | 可选必选说明：可选参数。 参数含义：该参数用于指定对应资源占用告警清除阈值。当NP资源占用率小于等于该阈值时清除告警“ALM-89004 NP资源使用率异常告警”。 数据来源：本端规划。 取值范围：整数类型，输入长度范围为0～100，单位为百分比。 默认值：无。 配置原则：必须小于“告警上报阈值”参数的配置值。 |

#### 使用实例

设置RU编号为70、资源类型为NP\_RESTYPE\_ACL（ACL）、告警上报阈值为80、告警清除阈值为70：

```
SET NPRESALARMTHRESHOLD: RUID=70, RESTYPE=NP_RESTYPE_ACL, REPORTTHLD=80, RECOVERTHLD=70;
```
