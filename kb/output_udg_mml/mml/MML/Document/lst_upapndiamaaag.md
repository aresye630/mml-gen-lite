# 查询APN的Diameter AAA服务器组（LST UPAPNDIAMAAAG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

此命令用于查询指定APN下的Diameter AAA组绑定关系或者所有APN下的Diameter AAA组绑定关系。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                   |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN    | APN名称  | 可选必选说明：可选参数 参数含义：该参数用于指定APN实例名。 数据来源：本端规划 取值范围：只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“ ” ”、“ ' ”特殊字符，不区分大小写。 默认值：无 配置原则：该参数使用ADD APN命令配置生成。 |

#### 使用实例

- 查询名称为“apn”的APN下的Diameter AAA组绑定关系：

  ```
  %%LST UPAPNDIAMAAAG: APN="apn";
  ```

  ```
  %%
  RETCODE = 0  操作成功
  APN的Diameter AAA服务器组
  -------------------------
           APN名称  =  apn
  Diameter AAA组名  =  diametergroup
  (结果个数 = 1)
  ---    END
  ```
- 查询所有APN下的Diameter AAA组绑定关系：

  ```
  %%LST UPAPNDIAMAAAG:;
  ```

  ```
  %%
  RETCODE = 0  操作成功
  APN的Diameter AAA服务器组
  -------------------------
  APN名称  Diameter AAA组名  
  apn      diametergroup     
  apn2     diametergroup1    
  (结果个数 = 2)
  ---    END
  ```
