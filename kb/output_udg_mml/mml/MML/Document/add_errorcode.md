# 增加错误码（ADD ERRORCODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

此命令用于配置错误码信息。运营商可以根据报文中错误码进行不同的重定向动作处理。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为100。
- 单个ErrorCodeName下最多配置500组错误码范围。
- 整机最多可以配置2000组错误码范围。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                                                                                                                                                       |
|:---------------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERRORCODENAME  | 错误码名称    | 可选必选说明：必选参数 参数含义：该参数用于设置错误码配置名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～31。不区分大小写，不支持空格。 默认值：无 配置原则：无                                                                                                                                                               |
| ERRORCODEOP    | 错误码范围操作码 | 可选必选说明：必选参数 参数含义：该参数用于配置错误码范围操作码。 数据来源：本端规划 取值范围：枚举类型。 EQUAL：等于指定值。LT：小于等于指定值。GT：大于等于指定值。RANGE：在指定范围内，包括边界值。 默认值：无 配置原则： 当运营商需要配置错误码等于指定值时，该参数需配置为EQUAL。当运营商需要配置错误码小于等于指定值时，该参数需配置为LT。当运营商需要配置错误码大于等于指定值时，该参数需配置为GT。当运营商需要配置错误码在指定范围（包括边界值）时，该参数需配置为RANGE。 |
| ERRORCODESTART | 错误码范围起始值 | 可选必选说明：条件必选参数 前提条件：该参数在“ERRORCODEOP”配置为“EQUAL”、“GT” 或 “RANGE”时为必选参数。 参数含义：该参数用于配置错误码范围起始值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～1000。 默认值：无 配置原则：无                                                                                                                   |
| ERRORCODEEND   | 错误码范围终止值 | 可选必选说明：条件必选参数 前提条件：该参数在“ERRORCODEOP”配置为“LT” 或 “RANGE”时为必选参数。 参数含义：该参数用于配置错误码范围终止值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～1000。 默认值：无 配置原则：无                                                                                                                           |

#### 使用实例

运营商规划定义一个名为“testerrorcode”的错误码：

```
ADD ERRORCODE: ERRORCODENAME="testerrorcode", ERRORCODEOP=LT, ERRORCODEEND=10;
```
