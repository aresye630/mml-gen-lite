# 删除OSPF过滤策略配置（RMV OSPFFILTERPOLICY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除OSPF过滤策略。

#### 注意事项

- 该命令执行后立即生效。
- 要删除的FilterPolicy必须存在。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识              | 参数名称   | 参数说明                                                                                                                                                                           |
|:------------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROCID            | 进程号    | 可选必选说明：必选参数 参数含义：OSPF进程号。 数据来源：全网规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无                                                                                                         |
| TOPOID            | 拓扑标识   | 可选必选说明：可选参数 参数含义：拓扑标识。 数据来源：全网规划 取值范围：整数类型，取值范围为0。 默认值：无 配置原则：目前只支持默认拓扑0。                                                                                                      |
| FILTERTYPE        | 过滤方向   | 可选必选说明：必选参数 参数含义：该参数用于指定过滤方向是import还是export。 数据来源：本端规划 取值范围：枚举类型。 import：引入方向的过滤。export：发布方向的过滤。 默认值：无                                                                         |
| PROTOCOL          | 协议分类   | 可选必选说明：条件可选参数 前提条件：该参数在“FILTERTYPE”配置为“export”时为可选参数。 参数含义：该参数用于指定对某一种协议的路由进行过滤。 数据来源：本端规划 取值范围：枚举类型。 Direct：直连路由。OSPF：OSPF路由。Static：静态路由。BGP：BGP路由。wlr：无线路由。Total：全部匹配。 默认值：无 |
| PROTOCOLPROCESSID | 协议进程号  | 可选必选说明：条件可选参数 前提条件：该参数在“PROTOCOL”配置为“OSPF”时为可选参数。 参数含义：该参数用于指定对某一进程的路由进行过滤。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：1                                                       |

#### 使用实例

删除设备上OSPF进程1下的import类型过滤策略：

```
RMV OSPFFILTERPOLICY: PROCID=1, FILTERTYPE=import;
```
