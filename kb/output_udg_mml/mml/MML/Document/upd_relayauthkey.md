# 更新媒体中继鉴权密钥（UPD RELAYAUTHKEY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、PGW-U**

**须知** 

本命令属于高危命令，执行该命令后，会影响媒体中继防盗链校验功能。

该命令用于更新主鉴权密钥，原主鉴权密钥置为备鉴权密钥。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识             | 参数名称       | 参数说明                                                                                               |
|:-----------------|:-----------|:---------------------------------------------------------------------------------------------------|
| RELAYAUTHKEYNAME | 媒体中继鉴权密钥名称 | 可选必选说明：必选参数 参数含义：该参数用于指定媒体中继认证密钥名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无    |
| NEWAUTHKEY       | 新增鉴权密钥     | 可选必选说明：必选参数 参数含义：该参数用于指定新增认证密钥。 数据来源：本端规划 取值范围：密码类型，输入长度范围为6～64。不支持空格。 默认值：无 配置原则：无                |
| NEWKEYCONFIRM    | 确认新增鉴权密钥   | 可选必选说明：必选参数 参数含义：该参数用于指定确认新增认证密钥。 数据来源：本端规划 取值范围：密码类型，输入长度范围为6～64。不支持空格。 默认值：无 配置原则：无              |
| DESC             | 媒体中继鉴权密钥描述 | 可选必选说明：可选参数 参数含义：该参数用于指定媒体中继鉴权密钥描述。 数据来源：本端规划 取值范围：字符串类型，输入长度范围是1~255。不区分大小写。 默认值：无 配置原则：无         |
| CFGDOMAINNAME    | 配置域名称      | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。 |

#### 使用实例

更新媒体中继鉴权密钥：

```
UPD RELAYAUTHKEY: RELAYAUTHKEYNAME="auth1", NEWAUTHKEY="*****", NEWKEYCONFIRM="*****";
```
