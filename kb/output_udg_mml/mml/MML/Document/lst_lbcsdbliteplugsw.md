# 查询CSLB使用轻量化CSDB插件的开关（LST LBCSDBLITEPLUGSW）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询CSLB是否使用轻量化CSDB插件。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询CSLB使用轻量化CSDB插件的开关状态，命令如下：

```
%%LST LBCSDBLITEPLUGSW:;%%
RETCODE = 0  操作成功

操作结果如下：
--------------
CSLB使用轻量化CSDB插件的开关  =  CSLB使用轻量化CSDB插件开启
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见**SET LBCSDBLITEPLUGSW**的参数说明。
