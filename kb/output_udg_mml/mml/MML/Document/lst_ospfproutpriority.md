# 查询OSPF路由的收敛优先级配置（LST OSPFPROUTPRIORITY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询OSPF路由的收敛优先级配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                         |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------------|
| PROCID   | 进程号    | 可选必选说明：可选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无                                                       |
| PRIORITY | 收敛优先级  | 可选必选说明：可选参数 参数含义：收敛优先级。 数据来源：本端规划 取值范围：枚举类型。 critical：配置OSPF路由的收敛优先级为关键。high：配置OSPF路由的收敛优先级为高。medium：配置OSPF路由的收敛优先级为中。 默认值：无 |

#### 使用实例

查询OSPF路由的收敛优先级配置：

```
LST OSPFPROUTPRIORITY:;
```

```
RETCODE = 0  操作成功。

结果如下
------------
    进程号  =  1
  拓扑标识  =  0
收敛优先级  =  Critical
    前缀名  =  IpPrefix
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                           |
|:--------|:--------------------------------|
| 进程号     | 该参数指定用户创建的OSPF进程号。              |
| 拓扑标识    | 该参数指定用户创建的OSPF拓扑标识。             |
| 收敛优先级   | 该参数指定匹配前缀列表的OSPF路由收敛优先级。        |
| 前缀名     | 该参数指定IP前缀列表名称，IP前缀列表用于匹配OSPF路由。 |
