# 查询OSPF错误报文的信息（DSP OSPFERRORPACKET）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询OSPF错误报文的信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称         | 参数说明                                                                         |
|:-------|:-------------|:-----------------------------------------------------------------------------|
| PKTNUM | 指定查询的错误报文的数量 | 可选必选说明：可选参数 参数含义：该参数用于指定查询最近接收的错误报文的数目。 数据来源：本端规划 取值范围：整数类型，取值范围为1～10。 默认值：1 |

#### 使用实例

查询OSPF错误报文的信息：

```
DSP OSPFERRORPACKET:PKTNUM=1;
```
