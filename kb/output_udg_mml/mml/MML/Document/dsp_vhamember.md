# 查询vHA ETCD集群节点详细信息（DSP VHAMEMBER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询vHA ETCD集群节点的详细信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

无

## 使用实例

查询集群节点相关信息：

```
%%DSP VHAMEMBER:;%%
RETCODE = 0  操作成功
```

## 输出结果说明

| 输出项名称       | 输出项解释                                                          |
|:------------|:---------------------------------------------------------------|
| 节点名称        | 该参数用于表示集群节点的名称。                                                |
| 与Client通讯地址 | 该参数用于表示集群节点告知给客户端的通讯地址。                                        |
| 与Peer通讯地址   | 该参数用于表示集群节点告知给对端的通讯地址。                                         |
| 节点成员标识      | 该参数用于表示集群节点的唯一标识。                                              |
| 角色          | 该参数用于表示集群节点的角色。 取值说明： Leader（主节点）Follower（从节点）Unknown（无效）      |
| 运行状态        | 该参数用于表示集群节点当前的运行状态。 取值说明： Healthy（健康）UnHealthy（非健康）Suspend（挂起） |
| Pod名称       | 该参数用于表示本节点所在的pod名称信息。                                          |
| Node名称      | 该参数用于表示本节点所在的node信息。                                           |
| 版本号         | 该参数用于表示本节点的ETCD版本信息。                                           |
| 存储数据大小      | 该参数用于表示本节点的db数据大小。                                             |
| 集群节点个数      | 该参数用于表示集群节点个数。                                                 |
