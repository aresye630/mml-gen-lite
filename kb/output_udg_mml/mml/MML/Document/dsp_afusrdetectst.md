# 显示欺诈用户检测结果（DSP AFUSRDETECTST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用来显示可疑欺诈用户信息，历史记录，防欺诈库匹配次数等。

#### 注意事项

使用该命令查询前，需要通过SET AFUSRDETECT命令配置计费欺诈用户检测功能开关。使用命令DSP AFUSRDETECT查看开关状态为DISABLE，不显示统计信息。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                 |
|:-------------|:-------|:-------------------------------------------------------------------------------------|
| RESOURCEUNIT | Pod名称  | 可选必选说明：可选参数 参数含义：该参数用于设置资源单元名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格。 默认值：无 配置原则：无 |

#### 使用实例

查询用户防欺诈流量检测统计信息：

```
DSP AFUSRDETECTST:;
```

#### 输出结果说明

| 输出项名称         | 输出项解释           |
|:--------------|:----------------|
| Pod名称         | 资源单元名称。         |
| 查询结果          | 用于存放查询结果。       |
| MSISDN        | 移动用户号码，如果没有则为空。 |
| SpecialRG(KB) | 免费流量。           |
| Total(KB)     | 总流量。            |
| Ratio(%)      | 免费流量占总流量百分比。    |
| Af-DB-Stats   | 命中欺诈库次数。        |
| DetectTime    | 记录欺诈流量的时间戳。     |
