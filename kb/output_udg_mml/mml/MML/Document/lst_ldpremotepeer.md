# 查询LDP远端邻居配置（LST LDPREMOTEPEER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询LDP远端邻居。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识           | 参数名称    | 参数说明                                                                                            |
|:---------------|:--------|:------------------------------------------------------------------------------------------------|
| VRFNAME        | VPN实例名称 | 可选必选说明：可选参数 参数含义：该参数用于表示VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                        |
| REMOTEPEERNAME | 远端邻居名   | 可选必选说明：可选参数 参数含义：该参数用于指定远端邻居名。配置LDP远端会话，需要指定远端邻居名和IP地址。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 |

#### 使用实例

查询LDP远端邻居：

```
LST LDPREMOTEPEER:;
```
