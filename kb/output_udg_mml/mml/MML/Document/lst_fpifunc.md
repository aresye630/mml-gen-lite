# 查询FPI差异化控制功能（LST FPIFUNC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF、PGW-U**

该命令用于查询FPI差异化控制功能状态。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询FPI差异化控制功能状态：

```
LST FPIFUNC:;
```

```
RETCODE = 0  操作成功

结果如下
--------
FPI使能开关  =  使能
FPI传递类型  =  DSCP
   策略来源  =  NULL
(结果个数 = 1)

---    END
```
