# 加载扩展包（LOD PLGPKG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

当系统需要添加侦听、跟踪等功能时，使用该命令用于加载该功能的扩展包，将扩展包下载到本地，并加载到系统中。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称      | 参数说明                                                                                                                                      |
|:----------------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------|
| PKGSOURCE       | 包来源       | 可选必选说明：可选参数 参数含义：该参数用于指定包来源。 数据来源：本端规划 取值范围：枚举类型。 REMOTE：文件来自远端。LOCAL：文件来自本地。 默认值：REMOTE                                                  |
| IPVERSION       | 服务器IP版本   | 可选必选说明：条件可选参数，该参数在“PKGSOURCE”配置为“REMOTE”时为可选参数。 参数含义：该参数用于指定服务器地址族。 数据来源：对端协商 取值范围：枚举类型。 IPv4：IPv4地址。IPv6：IPv6地址。 默认值：IPv4                |
| SERVERIP        | 服务器IPv4地址 | 可选必选说明：条件必选参数，该参数在“IPVERSION”配置为“IPv4”时为必选参数。 参数含义：该参数用于指定服务器IP地址。 数据来源：对端协商 取值范围：IPv4地址类型。 默认值：无                                         |
| SERVERPORT      | 服务器端口号    | 可选必选说明：条件必选参数，该参数在“PKGSOURCE”配置为“REMOTE”时为必选参数。 参数含义：该参数用于指定服务器端口号。 数据来源：对端协商 取值范围：整数类型，取值范围为0～65535。 默认值：无                               |
| USERNAME        | 用户名       | 可选必选说明：条件必选参数，该参数在“PKGSOURCE”配置为“REMOTE”时为必选参数。 参数含义：该参数用于指定服务器的用户名。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～63。 默认值：无                              |
| PASSWORD        | 密码        | 可选必选说明：条件必选参数，该参数在“PKGSOURCE”配置为“REMOTE”时为必选参数。 参数含义：该参数用于指定服务器的密码。 数据来源：对端协商 取值范围：密码类型，输入长度范围为1～127。 默认值：无                               |
| FILENAMEDIR     | 软件路径      | 可选必选说明：条件必选参数，该参数在“PKGSOURCE”配置为“REMOTE”时为必选参数。 参数含义：该参数用于指定软件路径。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～127。 默认值：无                                |
| FN              | 文件名       | 可选必选说明：条件必选参数，该参数在“PKGSOURCE”配置为“REMOTE”时为必选参数。 参数含义：该参数用于指定软件包的文件名。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～63。 默认值：无                              |
| TRANSFERPRTL    | 传输协议      | 可选必选说明：可选参数 参数含义：该参数用于指定下载扩展包使用的传输协议。 数据来源：对端协商 取值范围：枚举类型。 SFTP：使用SFTP协议下载文件。 默认值：SFTP                                                    |
| SERVERIPV6      | 服务器IPv6地址 | 可选必选说明：条件必选参数，该参数在“IPVERSION”配置为“IPv6”时为必选参数。 参数含义：该参数用于指定服务器IPv6地址，服务器需要提前放置新的软件包。 数据来源：对端协商 取值范围：IPv6地址类型。 默认值：无                        |
| PLGTYPE         | 扩展包类型     | 可选必选说明：条件必选参数，该参数在“PKGSOURCE”配置为“LOCAL”时为必选参数。 参数含义：该参数用于指定扩展包的类型。可通过LST PLGPKG或DSP SOFTWARE查询获取。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 |
| VERSIONID       | 版本号       | 可选必选说明：条件必选参数，该参数在“PKGSOURCE”配置为“LOCAL”时为必选参数。 参数含义：该参数用于指定扩展包的版本号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                               |
| SERVICEINSTANCE | 服务实例      | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。                              |

#### 使用实例

加载侦听扩展包：

```
LOD PLGPKG:PKGSOURCE=REMOTE,SERVERIP="192.168.0.15",SERVERPORT=22,USERNAME="HUAWEI-123",PASSWORD="*****",FILENAMEDIR="/home/plgpkg",FN="vVNFPV100R005C00MODPlug_1.8.zip",SERVICEINSTANCE="vnfc";
```
