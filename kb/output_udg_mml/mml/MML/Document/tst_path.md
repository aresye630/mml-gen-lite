#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于手动控制系统向对端网元（eNodeB、gNodeB、UPF、SGSN、SGW-U、PGW-U、SMF、SGW-C、PGW-C或可信非3GPP接入网关）发送心跳检测消息。

#### 注意事项

- 该命令执行后立即生效。
- 未开启大包探测开关，如果路径正常，则探测信号发送一次就停止发送。如果路径异常，发送探测信号后没有收到回应，则会根据设置的默认次数发送。
- 开启大包探测开关，发送echo消息若未收到回响则超时后立刻重发echo消息；若收到回响则在收到回响后按照设置的重发时间间隔启动定时器，待时间到后发送下一条echo消息。
- 开启大包探测开关，系统单条命令接收回响最大超时时间为110s，重发时间间隔及超时时间建议使用默认值，如果需要修改，保证：包数\*(重发时间间隔+超时时间)<110s。
- 开启大包探测开关，系统最短重发间隔为200ms，当重发时间间隔与超时时间设置为小于200ms时，消息跟踪结果中两条消息的时间间隔将仍为200ms。
- 开启大包探测开关，对端UPF需要支持大包能力的最新版本。
- PAYLOAD长度当前仅限于N9接口超大包探测功能使用，探测其他接口时使用此功能可能存在风险，请现网操作人员慎重使用。
- N9接口超大包探测时如果对端网元不是同厂商设备，可能对端网元不识别或对超大包无法处理等出现业务故障，存在引发事故风险，请现网操作人员慎重使用。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称            | 参数说明                                                                                                                                                                                  |
|:-------------|:----------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPVERSION    | IP地址版本类型        | 可选必选说明：必选参数 参数含义：该参数用于指定路径IP地址类型。 数据来源：本端规划 取值范围：枚举类型。 IPV4：表示地址类型为IPv4。IPV6：表示地址类型为IPv6。 默认值：无 配置原则：无                                                                                |
| LOCALIPV4    | 本端IPv4地址        | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV4”时为必选参数。 参数含义：该参数用于指定路径的本端IPV4地址。 数据来源：本端规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无 配置原则：无                                                             |
| PEERIPV4     | 对端IPv4地址        | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV4”时为必选参数。 参数含义：该参数用于指定路径的对端ipv4地址。 数据来源：本端规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无 配置原则：无                                                             |
| LOCALIPV6    | 本端IPv6地址        | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV6”时为必选参数。 参数含义：该参数用于指定路径的本端ipv6地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无 配置原则：无                                                                     |
| PEERIPV6     | 对端IPv6地址        | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV6”时为必选参数。 参数含义：该参数用于指定对端ipv6地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无 配置原则：无                                                                        |
| VPNNAME      | VPN名字           | 可选必选说明：可选参数 参数含义：该参数用于指定VPN。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：当下发探测命令时本端IP地址对应的逻辑接口未绑定VPN时，本次探测命令中不需要填写VPN参数。当下发探测命令时本端IP地址对应的逻辑接口绑定了VPN时，本次探测命令的VPN参数需要和此逻辑接口绑定的VPN保持一致。 |
| PROTOCOLTYPE | 协议版本            | 可选必选说明：必选参数 参数含义：该参数用于指定路径的协议版本信息。 数据来源：本端规划 取值范围：枚举类型。 GTPV1：指定GTP协议版本为V1版本。PFCP：指定PFCP协议版本。TM：指定TM协议版本。 默认值：无 配置原则：无                                                                |
| LARGEDETSW   | 大包探测功能开关        | 可选必选说明：可选参数 参数含义：该参数用于指定是否使用大包探测功能。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：DISABLE 配置原则：当本端IPv4地址或本端IPv6地址是本设备的scif或paif或n9cif或s5-sif逻辑接口的IP地址时才允许使能此开关。                     |
| PACKETNUM    | 发包数             | 可选必选说明：条件可选参数 前提条件：该参数在“LARGEDETSW”配置为“ENABLE”时为可选参数。 参数含义：该参数用于指定心跳检测消息的报文次数。 数据来源：本端规划 取值范围：整数类型，取值范围为1～200，单位是次数。 默认值：5 配置原则：一次报文发送的重发报文不算在此发包数范围。                                 |
| PAYLOADLEN   | PAYLOAD长度       | 可选必选说明：条件必选参数 前提条件：该参数在“LARGEDETSW”配置为“ENABLE”时为必选参数。 参数含义：该参数用于指定心跳检测消息构造的私有信元长度。 数据来源：本端规划 取值范围：整数类型，取值范围为6~4000。 默认值：无 配置原则：无                                                      |
| INTERVAL     | 探测消息的重发时间间隔（ms） | 可选必选说明：条件可选参数 前提条件：该参数在“LARGEDETSW”配置为“ENABLE”时为可选参数。 参数含义：超大包探测消息的重发时间间隔。 数据来源：本端规划 取值范围：整数类型，取值范围为1~10000，单位是毫秒。 默认值：500 配置原则：无                                                     |
| TIMEOUT      | 超时时间（ms）        | 可选必选说明：条件可选参数 前提条件：该参数在“LARGEDETSW”配置为“ENABLE”时为可选参数。 参数含义：该参数用于指定发送完心跳探测报文后，等待心跳响应报文的超时时间。 数据来源：本端规划 取值范围：整数类型，取值范围为1~20000，单位是毫秒。 默认值：2000 配置原则：无                                   |

#### 使用实例

探测系统地址为10.6.6.1到MME10.6.6.2的GTPv1数据路径通信是否正常：

```
TST PATH: IPVERSION=IPV4, LOCALIPV4="10.6.6.1", PEERIPV4="10.6.6.2", PROTOCOLTYPE=GTPV1, LARGEDETSW=DISABLE;
```
