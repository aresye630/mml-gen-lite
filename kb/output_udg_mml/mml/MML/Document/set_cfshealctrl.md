# 设置在复杂故障场景下自愈功能控制参数（SET CFSHEALCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，操作不当可能会加剧业务负载，请谨慎使用并联系华为技术支持协助操作。

该命令用于在复杂故障场景下，设置自愈功能控制参数。

## 注意事项

- 该命令执行后立即生效。

- 为避免频繁执行对系统性能产生冲击，该命令在三分钟之内只能执行一次。
- 如果系统时间发生跳变，跳变到上一次执行本命令的前N（N<=3）分钟，下一次可执行本命令最少需等待N+3分钟。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| SUBHEALTHSW   |   SUBHWAITTIME |   Q922PERIOD | NFSUBHEALTHSW   |   NFSUBWAITTIME | NFSUBEXEPLY   | SGLSUBHEALTHSW   |   SGLSUBWAITTIME |   FAULTTHR |   DIFFTHR | SGLISOMODE   |   DETNUM |
|:--------------|---------------:|-------------:|:----------------|----------------:|:--------------|:-----------------|-----------------:|-----------:|----------:|:-------------|---------:|
| DISABLE       |             10 |            3 | DISABLE         |             300 | MANUAL        | DISABLE          |              120 |         90 |        20 | AUTOMATIC    |        3 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称                | 参数说明                                                                                                                                                                                                                                                                                                                                |
|:---------------|:--------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBHEALTHSW    | 通信亚健康隔离功能开关         | 可选必选说明：可选参数  参数含义：该参数用于控制在出现通信亚健康故障后是否诊断隔离。  数据来源：本端规划 取值范围： “ENABLE（开启）”：开启通信亚健康隔离功能。“DISABLE（关闭）”：关闭通信亚健康隔离功能。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CFSHEALCTRL查询当前参数配置值。  配置原则：无                                                                                                                                             |
| SUBHWAITTIME   | 亚健康诊断等待时间(分钟)       | 可选必选说明：该参数在"SUBHEALTHSW"配置为"ENABLE"时为条件可选参数。  参数含义：该参数用于配置通信亚健康延迟诊断时间。  数据来源：本端规划  取值范围：整数类型，取值范围是1~1800。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CFSHEALCTRL查询当前参数配置值。  配置原则：  开启亚健康诊断时建议配置为10。若Fabric平面丢包情况在反复震荡时，当震荡过程中短暂稳定时间小于“亚健康诊断等待时间”取值时，参数“亚健康诊断等待时间”无法生效；只有当Fabric平面丢包情况处于稳定状态，且稳定时间大于等于“亚健康诊断等待时间”取值时，参数“亚健康诊断等待时间”才生效。 |
| Q922PERIOD     | Q922连续诊断周期（次）       | 可选必选说明：该参数在"SUBHEALTHSW"配置为"ENABLE"时为条件可选参数。  参数含义：该参数用于指定Q922诊断周期N，目的是防止网络丢包震荡。如果连续N次查询都有“ALM-1011 控制平面丢包错包”告警，每次查询告警的定位信息中有相同的目的Pod，则以第N次查询结果作为诊断输入。  数据来源：本端规划  取值范围：整数类型，取值范围是1~255。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CFSHEALCTRL查询当前参数配置值。  配置原则：无                                                                     |
| NFSUBHEALTHSW  | 网元级KPI异常检测与容灾功能开关   | 可选必选说明：可选参数  参数含义：在网元出现亚健康（如多个主机出现fabric平面亚健康/cpu过载/pod持续故障等）故障而导致业务KPI下降达到阈值时，该参数用于控制网元级KPI异常检测与容灾功能开关。  数据来源：本端规划 取值范围： “ENABLE（开启）”：开启网元级KPI异常检测与容灾功能“DISABLE（关闭）”：关闭网元级KPI异常检测与容灾功能  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CFSHEALCTRL查询当前参数配置值。  配置原则：无                                                                      |
| NFSUBWAITTIME  | 容灾决策等待时间（秒）         | 可选必选说明：该参数在"NFSUBHEALTHSW"配置为"ENABLE"时为条件可选参数。  参数含义：该参数用于配置容灾决策的等待时间。  数据来源：本端规划  取值范围：整数类型，取值范围是1~1800。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CFSHEALCTRL查询当前参数配置值。  配置原则：无                                                                                                                                                    |
| NFSUBEXEPLY    | 容灾执行策略              | 可选必选说明：该参数在"NFSUBHEALTHSW"配置为"ENABLE"时为条件可选参数。  参数含义：该参数用于配置容灾执行处理的策略。  数据来源：本端规划 取值范围： “MANUAL（手动）”：人工执行STR NFDREXE命令完成容灾倒换“AUTOMATIC（自动）”：自动执行容灾倒换  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CFSHEALCTRL查询当前参数配置值。  配置原则：无                                                                                                         |
| SGLSUBHEALTHSW | 模块级KPI异常检测与恢复功能开关   | 可选必选说明：可选参数  参数含义：用于控制由于网元内单主机出现Fabric平面丢包/CPU过载/流控故障而导致KPI下降满足阈值时做对应自愈隔离处理的功能开关。  数据来源：本端规划 取值范围： “ENABLE（开启）”：开启模块级KPI异常检测与恢复功能“DISABLE（关闭）”：关闭模块级KPI异常检测与恢复功能  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CFSHEALCTRL查询当前参数配置值。  配置原则：无                                                                                             |
| SGLSUBWAITTIME | 诊断隔离处理等待时间（秒）       | 可选必选说明：该参数在"SGLSUBHEALTHSW"配置为"ENABLE"时为条件可选参数。  参数含义：用于配置延后诊断隔离处理的等待时间。该参数已废弃。  数据来源：本端规划  取值范围：整数类型，取值范围是1~1800。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CFSHEALCTRL查询当前参数配置值。  配置原则：  该参数配置不生效。                                                                                                                                 |
| FAULTTHR       | 异常阈值（%）             | 可选必选说明：该参数在"SGLSUBHEALTHSW"配置为"ENABLE"时为条件可选参数。  参数含义：该参数在虚机形态下用于配置Node的CPU使用率异常阈值，在裸机形态下用于配置Pod的CPU使用率异常阈值，大于等于此值初步判断为异常。  数据来源：本端规划  取值范围：整数类型，取值范围是50~100。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CFSHEALCTRL查询当前参数配置值。  配置原则：无                                                                                                |
| DIFFTHR        | 差值（%）               | 可选必选说明：该参数在"SGLSUBHEALTHSW"配置为"ENABLE"时为条件可选参数。  参数含义：该参数在虚机形态下用于配置与同类型Node的CPU使用率平均值的差值，在裸机形态下用于配置与同类型Pod的CPU使用率平均值的差值，若某个Node/Pod的CPU使用率大于等于同类型Node/Pod的CPU使用率平均值与差值之和（由于CPU使用率上限是100%，当该和超过100%时视为100%），则初步判断为异常。  数据来源：本端规划  取值范围：整数类型，取值范围是0~100。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CFSHEALCTRL查询当前参数配置值。  配置原则：无       |
| SGLISOMODE     | 模块级KPI异常检测与恢复功能隔离策略 | 可选必选说明：该参数在"SGLSUBHEALTHSW"配置为"ENABLE"时为条件可选参数。  参数含义：该参数用于配置模块级KPI异常检测与恢复功能的隔离策略。  数据来源：本端规划 取值范围： “MANUAL（手动）”：人工执行ACT SGLISOLATION命令完成模块级KPI异常检测与恢复。“AUTOMATIC（自动）”：自动完成模块级KPI异常检测与恢复。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CFSHEALCTRL查询当前参数配置值。  配置原则：无                                                                    |
| DETNUM         | 连续检测周期              | 可选必选说明：该参数在"SGLSUBHEALTHSW"配置为"ENABLE"时为条件可选参数。  参数含义：该参数用于设置连续检测周期。  数据来源：本端规划  取值范围：整数类型，取值范围是1~100。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CFSHEALCTRL查询当前参数配置值。  配置原则：无                                                                                                                                                       |

## 使用实例

开启通信亚健康隔离功能。

```
SET CFSHEALCTRL: SUBHEALTHSW=ENABLE;
```
