# 查询无线路由全局属性配置（LST WLRSITE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询无线路由全局属性配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询无线路由全局属性配置：

```
LST WLRSITE:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
     GR定时器（s）  =  1
PAE延时定时器（s）  =  30
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见SET WLRSITE的参数说明。
