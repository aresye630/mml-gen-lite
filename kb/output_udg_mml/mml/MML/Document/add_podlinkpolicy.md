# 增加Pod级链路策略（ADD PODLINKPOLICY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此命令用于增加Pod级链路策略。当本网元与对端的SEPP之间的SBI链路数达到SEPP支持的SBI链路数规格上限时，需要对本网元与SEPP之间的SBI链路数进行控制。

## 注意事项

- 该命令执行后立即生效。

- 当"LST SBILINKSETPROP"查询到“系统控制标识”为“是”时，开启Pod级链路控制之前，需要联系华为技术工程师。
- 当“DWORD1604 控制HTTP链路自动扩缩容门限”不为0时，开启Pod级链路控制之前，需要联系华为技术工程师。

- 最多可输入10条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                            |
|:---------------|:---------|:----------------------------------------------------------------------------------------------------------------|
| PEERNFTYPE     | 对端网元类型   | 可选必选说明：必选参数  参数含义：该参数用于指定使用Pod级链路策略的NF类型。  数据来源：本端规划 取值范围： “SEPP（SEPP）”：该参数用于指定使用Pod级链路策略的NF类型。  默认值：无  配置原则：无  |
| PODCTRLFLAG    | Pod级链路控制 | 可选必选说明：必选参数  参数含义：该参数用于指定是否开启Pod级链路控制。  数据来源：本端规划 取值范围： “OFF（关闭）”：关闭Pod级链路控制“ON（开启）”：开启Pod级链路控制  默认值：无  配置原则：无  |
| LINKNUMPERPPOD | Pod级链路数量 | 可选必选说明：该参数在"PODCTRLFLAG"配置为"ON"时为条件可选参数。  参数含义：该参数用于指定Pod级链路的数量。  数据来源：本端规划  取值范围：整数类型，取值范围是1~2。  默认值：1  配置原则：无 |

## 使用实例

增加对端网元类型为SEPP的Pod级链路策略，开启Pod级链路控制，Pod级链路数量设置为1。

```
ADD PODLINKPOLICY:PEERNFTYPE=SEPP,PODCTRLFLAG=ON,LINKNUMPERPPOD=1;
```
