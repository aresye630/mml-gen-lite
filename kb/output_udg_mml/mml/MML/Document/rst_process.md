# 复位进程(RST PROCESS)

#### 命令功能

**须知** 

本命令属于高危命令，复位进程可能会导致RU复位引起业务中断，请确认是否继续执行。

该命令用于按照进程ID来复位系统中的进程。

#### 注意事项

- 复位UNIPLT\_MPU\_SMU、UNIPLT\_LPU\_SMU会导致RU复位，请谨慎使用。
- 复位有主备模式的主进程，会导致备升主。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                                    |
|:----------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROCID          | 进程ID   | 可选必选说明：必选参数 参数含义：该参数表示指定复位进程的ID。通过DSP PROCESSXXX （XXX表示CSLB等服务，例如CSLB的命令为DSP PROCESSCSLB，CSDB的命令为DSP PROCESSCSDB）命令可以查询进程ID。 数据来源：本端规划 取值范围：整数类型，取值范围为1000～65535。 默认值：无 |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。该参数不能取值为VNFP、ACS、VNRS_VNFC的服务实例名称。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。                          |

#### 使用实例

复位进程ID号为1002的进程：

```
RST PROCESS:PROCID=1002,SERVICEINSTANCE="vnfc";
```
