# 设置双发选收属性配置（SET DFSRATTR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于设置双发选收相关属性信息。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | NEPRIFLAG   |   PAIRUEACTTIME |
|:-------|:------------|----------------:|
| 初始值    | PRIMARY     |               0 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称          | 参数说明                                                                                                                                                        |
|:--------------|:--------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NEPRIFLAG     | 网元主备用标识       | 可选必选说明：可选参数 参数含义：当网元主备部署时，该参数用于指定网元是主用网元还是备用网元。 数据来源：本端规划 取值范围：枚举类型。 PRIMARY：主用。SECONDARY：备用。 默认值：无 配置原则：无                                                  |
| PAIRUEACTTIME | 双发选收结对内用户激活时长 | 可选必选说明：条件必选参数 前提条件：该参数在“NEPRIFLAG”配置为“SECONDARY”时为必选参数。 参数含义：该参数用于配置双发选收结对内两个UE激活的最大时间间隔，超过配置的间隔则已激活的用户会被去激活。 数据来源：本端规划 取值范围：整数类型，取值范围为3-300秒。 默认值：无 配置原则：无 |

#### 使用实例

设置网元主备类型为备用，设置双发选收结对中ue会话老化时间为20秒：

```
SET DFSRATTR: NEPRIFLAG=SECONDARY, PAIRUEACTTIME=20;
```
