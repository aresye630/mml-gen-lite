# 设置告警阈值（SET SFIPCPUALMTHD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：CloudEPSN**

该命令用于设置第三方app的CPU过载告警阈值。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   |   WARNTHRESH |   RECVTHRESH |
|:-------|-------------:|-------------:|
| 初始值    |           80 |           60 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                 |
|:-----------|:----------|:-------------------------------------------------------------------------------------|
| WARNTHRESH | 告警产生阈值(%) | 可选必选说明：必选参数 参数含义：该参数用于指定CPU过载告警触发阈值(%)。 数据来源：本端规划 取值范围：整数类型，取值范围为0～100。 默认值：无 配置原则：无 |
| RECVTHRESH | 告警恢复阈值(%) | 可选必选说明：必选参数 参数含义：该参数用于指定CPU过载告警恢复阈值(%)。 数据来源：本端规划 取值范围：整数类型，取值范围为0～100。 默认值：无 配置原则：无 |

#### 使用实例

设置第三方app的过载告警阈值：告警阈值默认值为80%，恢复阈值默认值为60%：

```
SET SFIPCPUALMTHD: WARNTHRESH=80, RECVTHRESH=60;
```
