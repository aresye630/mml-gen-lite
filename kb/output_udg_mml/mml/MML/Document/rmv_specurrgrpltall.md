# 删除所有特殊URR组列表（RMV SPECURRGRPLTALL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，删除所有特殊URR组列表可能会影响业务匹配结果，导致用户业务受损，请谨慎使用并联系华为技术支持协助操作。

该命令用于删除所有特殊URR组列表配置。

#### 注意事项

- 该命令执行后立即生效。
- 当配置量较大时单次执行可能无法删除全部记录，需要执行多次。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

无。

#### 使用实例

删除所有配置的特殊URR组列表：

```
RMV SPECURRGRPLTALL:;
```
