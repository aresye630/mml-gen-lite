# 查询OSPF引入路由配置（LST OSPFIMPORTROUTE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询OSPF引入路由配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                     |
|:---------|:--------|:-------------------------------------------------------------------------------------------------------------------------|
| PROCID   | OSPF进程号 | 可选必选说明：可选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无                                                   |
| PROTOCOL | 协议分类    | 可选必选说明：可选参数 参数含义：用于指定OSPF引入外部路由的路由类型。 数据来源：本端规划 取值范围：枚举类型。 Direct：直连路由。OSPF：OSPF路由。Static：静态路由。BGP：BGP路由。wlr：无线路由。 默认值：无 |

#### 使用实例

查询OSPF引入路由配置：

```
LST OSPFIMPORTROUTE:;
```

#### 输出结果说明

| 输出项名称     | 输出项解释                                    |
|:----------|:-----------------------------------------|
| OSPF进程号   | 该参数指定用户创建的OSPF进程号。                       |
| 拓扑标识      | 该参数指定拓扑标识。                               |
| 协议分类      | 该参数指定OSPF引入外部路由的协议类型。                    |
| 协议进程号     | 该参数指定引入路由协议的进程号，当协议分类配置为OSPF时生效。         |
| 引入路由开销值配置 | 该参数指定允许配置引入的外部路由的开销值。                    |
| 引入路由标签配置  | 该参数指定允许配置引入的外部路由的标签。                     |
| 引入路由类型配置  | 该参数指定允许配置引入的外部路由的类型。                     |
| 路径Cost值   | 该参数指定自治系统外部路径的开销，当引入路由开销值配置为true时生效。     |
| 标签        | 该参数指定外部LSA中的标记，当引入路由标签配置为true时生效。        |
| 引入路由类型    | 该参数指定外部LSA的度量类型，当引入路由Type使能标志配置为true时生效。 |
| 路由策略名称    | 该参数指定引入时依据的路由策略名称。                       |
| 允许BGP配置   | 该参数指定允许使能引入IBGP路由，当协议分类配置为BGP时生效。        |
