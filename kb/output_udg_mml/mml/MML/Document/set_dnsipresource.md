# 设置DNS IP地址资源列表（SET DNSIPRESOURCE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：CloudEPSN**

该命令用于设置DNS的管理接口和业务接口IP地址资源列表。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为2。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | INTERFACETYPE   | IPVERSION   | IPV4ADDRS   |
|:-------|:----------------|:------------|:------------|
| 初始值    | Mgt             | IPV4_IPV6   | nan         |
| 初始值    | Dns             | IPV4        | 192.168.0.1 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                                                                                   |
|:--------------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
| INTERFACETYPE | 接口类型     | 可选必选说明：必选参数 参数含义：接口类型。 数据来源：全网规划 取值范围：仅支持输入“Mgt”、“Dns”。Mgt：管理接口；Dns：业务接口。 默认值：无 配置原则：无                                                                 |
| IPVERSION     | IP地址类型   | 可选必选说明：可选参数 参数含义：IP地址版本。 数据来源：本端规划 取值范围： IPV4：IPv4。IPV6：IPv6。IPV4_IPV6：同时支持IPv4和IPv6。 默认值：无 配置原则：当接口类型输入“Mgt”时，该字段不支持配置。                               |
| IPV4ADDRS     | IPv4地址列表 | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV4” 或 “IPV4_IPV6”时为必选参数。 参数含义：IPv4地址资源列表。 数据来源：全网规划 取值范围：不支持输入0开头的IP地址。 默认值：无 配置原则：输入合法的IP地址列表，多个IP地址之间使用空格分隔。 |
| IPV6ADDRS     | IPv6地址列表 | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV6” 或 “IPV4_IPV6”时为必选参数。 参数含义：IPv6地址资源列表。 数据来源：全网规划 取值范围：NA。 默认值：无 配置原则：输入合法的IP地址列表，多个IP地址之间使用空格分隔。            |

#### 使用实例

设置Dns接口类型，IPV4地址列表为192.168.0.1、192.168.0.2，运行如下命令：

```
+++    CloudEPSN/*MEID:0 MENAME:APP-VNF-CloudEPSN-X86-B003_IP60*/        2024-02-20 13:05:28
O&M    #3700
%%SET DNSIPRESOURCE: INTERFACETYPE="Dns", IPVERSION=IPV4, IPV4ADDRS="192.168.0.1 192.168.0.2";%%
RETCODE = 0  操作成功
```
