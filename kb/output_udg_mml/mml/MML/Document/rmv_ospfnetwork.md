# 删除OSPF运行的接口及所属区域（RMV OSPFNETWORK）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 参考信息

#### 命令功能

该命令用于在OSPF进程下的区域删除网段的配置。

#### 注意事项

- 该命令执行后立即生效。
- 只有配置了OSPF进程、OSPF区域和区域下的网段后才能使用该命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                   |
|:-------------|:-------|:-----------------------------------------------------------------------|
| PROCID       | 进程号    | 可选必选说明：必选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 |
| AREAID       | 区域号    | 可选必选说明：必选参数 参数含义：OSPF区域号。 数据来源：对端协商 取值范围：IPv4地址类型。点分十进制格式。 默认值：无       |
| IPADDRESS    | IP地址   | 可选必选说明：必选参数 参数含义：接口所在的网段地址。 数据来源：全网规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无     |
| WILDCARDMASK | 反掩码    | 可选必选说明：必选参数 参数含义：IP地址的反掩码。 数据来源：全网规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无      |

#### 使用实例

删除在OSPF进程下1区域0.0.0.0下网段192.168.0.0/24：

```
RMV OSPFNETWORK: PROCID=1, AREAID="0.0.0.0", IPADDRESS="192.168.0.0", WILDCARDMASK="0.0.0.255";
```

#### 参考信息

该命令用于删除运行OSPF协议的接口所在的网段及所属的区域。删除OSPF协议接口，则接口不再运行OSPF协议。
