# 设置体验分析增强上报功能（SET EXPEXTRPT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

此命令用于设置体验分析增强上报功能的开关。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- QOE参数上报只对IISA模式生效。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | QOEPARAMRPT   | MEDIARELAYSW   | VISUALSWITCH   |
|:-------|:--------------|:---------------|:---------------|
| 初始值    | DISABLE       | DISABLE        | DISABLE        |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称       | 参数说明                                                                                              |
|:-------------|:-----------|:--------------------------------------------------------------------------------------------------|
| QOEPARAMRPT  | QOE参数上报    | 可选必选说明：可选参数 参数含义：QOE参数上报。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无                |
| MEDIARELAYSW | 媒体中继用户标识开关 | 可选必选说明：可选参数 参数含义：媒体中继用户标识开关。 数据来源：本端规划 取值范围： DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无                  |
| VISUALSWITCH | 可视化开关      | 可选必选说明：可选参数 参数含义：用于设置体验分析增强单据中可视化字段是否开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无 |

#### 使用实例

设置体验分析增强上报功能：

```
SET EXPEXTRPT: QOEPARAMRPT=ENABLE, MEDIARELAYSW=DISABLE, VISUALSWITCH=DISABLE;
```
