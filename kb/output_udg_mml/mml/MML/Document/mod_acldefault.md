# 修改缺省Acl绑定（MOD ACLDEFAULT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于修改默认的ACL。当APN下没有配置任何ACL时，APN会使用默认ACL，而该命令用于修改APN使用的默认ACL。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                    |
|:----------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DIRECTION | 方向     | 可选必选说明：必选参数 参数含义：该参数用于指定默认ACL的方向。 数据来源：本端规划 取值范围：枚举类型。 UPIN：APN绑定ACL的方向为上行进系统。UPOUT：APN绑定ACL的方向为上行出系统。DOWNIN：APN绑定ACL的方向为下行进系统。DOWNOUT：APN绑定ACL的方向为下行出系统。 默认值：无 配置原则：按实际需要控制的方向来置值。                                     |
| ACLNAME   | ACL名称  | 可选必选说明：必选参数 参数含义：该参数用于配置默认ACL名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则： 当参数Direction配置为UPIN、DOWNIN时，该参数只能配置ACL节点的动作为gate、remark的ACL名称。当参数Direction配置为UPOUT、DOWNOUT时，该参数只能配置ACL节点的动作为redirect的ACL名称。 |

#### 使用实例

假如运营商需要将上行、进系统方向的默认ACL修改为“testacl1”：

```
MOD ACLDEFAULT:DIRECTION=UPIN,ACLNAME="testacl1";
```
