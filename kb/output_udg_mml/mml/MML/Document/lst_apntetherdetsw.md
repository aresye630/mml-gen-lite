# 查询APN Tethering终端数量检测开关（LST APNTETHERDETSW）

- 命令功能
- 注意事项
- 操作用户权限

- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用来显示APN下Tethering终端数量检测开关信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                       |
|:-------|:-------|:-------------------------------------------------------------------------------------------|
| APN    | APN    | 可选必选说明：可选参数 参数含义：该参数用于指定APN名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

假如运营商查询名称为“huawei.com”的APN的Tethering的终端数量检测开关信息：

```
%%LST APNTETHERDETSW: APN="huawei.com";
```

```
%%
RETCODE = 0 操作成功。

APN Tethering终端数量检测开关
----------------------------------------------------------
     APN = huawei.com
开关标识 = 开启
(结果个数 = 1)
--- END
```
