# 查询基于应用大类的质差上报策略（LST CATEPOLICYCTRL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询CATEPOLICYCTRL，支持批量查询。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                    |
|:----------|:-------|:----------------------------------------------------------------------------------------|
| APPIDNAME | 应用ID   | 可选必选说明：可选参数 参数含义：该参数用于指定重点业务保障的应用组名称。 数据来源：全网规划 取值范围：字符串类型，区分大小写，长度为1-63位。 默认值：无 配置原则：无 |

#### 使用实例

- 假如运营商需要查询应用ID为OpenLive的基于应用大类的质差检测：

  ```
  %%LST CATEPOLICYCTRL: APPIDNAME="OpenLive";
  ```

  ```
  %%
  RETCODE = 0  操作成功

  结果如下
  --------
                    应用ID  =  OpenLive
                应用大类ID  =  102
    基于应用的质差上报周期  =  5
  基于应用的非质差上报周期  =  60
                平均意见分  =  40
          应用质差上报策略  =  检测到质差时新流触发上报
          应用结束延时时间  =  0
            业务bypass开关  =  不使能
                 策略参数名 =  NULL
  	     位置变更上报 =  使能
  	 体验大流阈值系数 =  NULL
  (结果个数 = 1)

  ---    END
  ```
- 假如运营商需要查询所有已配置的基于应用大类的质差检测：

  ```
  %%LST CATEPOLICYCTRL:;
  ```

  ```
  %%
  RETCODE = 0  操作成功

  结果如下
  --------
                    应用ID  =  OpenLive
                应用大类ID  =  102
    基于应用的质差上报周期  =  5
  基于应用的非质差上报周期  =  60
                平均意见分  =  40
          应用质差上报策略  =  检测到质差时新流触发上报
          应用结束延时时间  =  0
            业务bypass开关  =  不使能
                 策略参数名 =  NULL
  	     位置变更上报 =  使能
  	 体验大流阈值系数 =  NULL
  (结果个数 = 1)

  ---    END
  ```
