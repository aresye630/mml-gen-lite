# 删除DNS规则（RMV DNSRULE）

- 命令功能

- 操作用户权限

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，该命令会删除满足条件的DNS规则，并且会导致正在使用这些规则的用户出现规则匹配错误、计费错误等现象。

该命令用于删除DNS规则，可以根据不同的参数组合删除一条或者多条DNS规则，当没有输入参数时，删除所有DNS规则。

#### 注意事项

- 该命令执行后立即生效。
- 如果执行批量删除操作，需要开启软参BYTE692。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                                             |
|:--------------|:--------|:---------------------------------------------------------------------------------------------------------------------------------|
| APPLICATIONID | 应用标识    | 可选必选说明：可选参数 参数含义：该参数用于配置DNS列表所属的应用标识。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不区分大小写。 默认值：无 配置原则：该参数用于和SMF下发的PDR中携带的Application ID进行匹配。 |
| DNSRULENAME   | DNS规则名称 | 可选必选说明：可选参数 参数含义：该参数用于配置DNS规则名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不区分大小写。 默认值：无 配置原则：无                                           |
| DOMAIN        | 域名      | 可选必选说明：可选参数 参数含义：该参数用于设置DNS规则的服务器域名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不区分大小写。 默认值：无 配置原则：无                                       |

#### 使用实例

删除一条DNS规则，其中APPLICATIONID是‘app1’，DNSRULENAME是'rule1'：

```
RMV DNSRULE: APPLICATIONID="app1", DNSRULENAME="rule1";
```
