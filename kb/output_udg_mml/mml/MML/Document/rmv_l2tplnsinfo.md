# 删除L2TP组中的LNS信息（RMV L2TPLNSINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于删除L2TP组中的LNS信息。

#### 注意事项

- 该命令执行后立即生效。
- 当L2TP组存在用户时，不允许通过RMV L2TPLNSINFO命令删除LNS配置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                             |
|:--------|:-------|:-------------------------------------------------------------------------------------------------|
| GROUPID | L2TP组号 | 可选必选说明：必选参数 参数含义：指定L2TP组号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～1500。 默认值：无 配置原则：该参数使用ADD L2TPGROUP命令配置生成。 |
| LNSNO   | LNS序号  | 可选必选说明：必选参数 参数含义：该参数用于指定添加LNS的序号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～30。 默认值：无 配置原则：无                    |

#### 使用实例

假设用户不需要使用l2TP组1中的LNS NUMBER为1的LNS：

```
RMV L2TPLNSINFO: GROUPID=1, LNSNO=1;
```
