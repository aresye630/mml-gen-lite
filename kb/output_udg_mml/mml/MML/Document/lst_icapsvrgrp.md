# 查询ICAP服务器组（LST ICAPSVRGRP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询ICAP Server Group的相关信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识           | 参数名称       | 参数说明                                                                                                      |
|:---------------|:-----------|:----------------------------------------------------------------------------------------------------------|
| ICAPSVRGRPNAME | ICAP服务器组名称 | 可选必选说明：可选参数 参数含义：该参数用于指定ICAP Server Group的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格。不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

查询ICAP Server Group的相关信息：

```
LST ICAPSVRGRP: ICAPSVRGRPNAME="isg2";
```

```
RETCODE = 0  操作成功

ICAP服务器组信息
----------------
ICAP服务器组名称  =  isg2
  ICAP服务器类型  =  URL过滤
      配置域名称  =  NULL
(结果个数 = 1)

---    END
```
