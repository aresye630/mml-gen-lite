# 修改5G LAN虚拟接口配置（MOD NGVNVIF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于修改5G LAN虚拟接口配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                               |
|:------------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VNINSTANCE  | 5G LAN组名称  | 可选必选说明：必选参数 参数含义：该参数用于指定5G LAN会话实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为18～37。VNINSTANCE以连字号分为4段，形式为GroupServiceID-MCC-MNC-LocalGroupID。其中，GroupServiceID长度为8，只能输入数字或者范围为A到F或a-f的字母；MCC长度为3，只能输入数字；MNC长度为2~3，只能输入数字；LocalGroupID长度为2~20的偶数，只能输入数字或者范围为A到F或a-f的字母。例如，A0000001-460-003-01，A0000001-460-003-A000000001。不区分大小写。 默认值：无 配置原则：无 |
| VIFIPTYPE   | 虚拟接口IP地址类型 | 可选必选说明：必选参数 参数含义：该参数用于指定虚拟接口IP地址类型。 数据来源：本端规划 取值范围： IPV4：表示地址类型为IPv4。 默认值：无 配置原则：无                                                                                                                                                                                                                                                 |
| VIFIPV4ADDR | 虚拟接口IPv4地址 | 可选必选说明：条件必选参数 前提条件：该参数在“VIFIPTYPE”配置为“IPV4”时为必选参数。 参数含义：该参数用于指定虚拟接口IPv4地址。 数据来源：全网规划 取值范围：IPv4地址类型。采用点分十进制"X.X.X.X"格式。 默认值：无 配置原则：根据局点的网络规划进行配置，点分十进制格式。除A、B、C类地址合法外，其余都为非法地址。                                                                                                                                                     |

#### 使用实例

修改5G LAN虚拟接口配置：

```
MOD NGVNVIF: VNINSTANCE="a0000001-460-01-01", VIFIPTYPE=IPV4, VIFIPV4ADDR="192.168.0.1";
```
