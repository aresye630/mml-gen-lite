# 查询接口IP选项安全配置（LST IPOPTSECURITYIF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询接口IP选项安全配置。不指定IFNAME参数时，查询所有接口的配置信息；当指定IFNAME参数时，可以查询指定接口的配置信息。接口名称可以通过LST INTERFACE命令获取。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                                                 |
|:-----------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OPTIONTYPE | IP选项类型 | 可选必选说明：可选参数 参数含义：该参数表示IP选项的类型。 数据来源：本端规划 取值范围：枚举类型。 routeAlert：系统处理带路由告警选项IP报文的功能。routeRecord：系统处理带记录路由选项IP报文的功能。sourceRoute：系统处理带源路由选项IP报文的功能。该选项控制报文传输路径。timeStamp：系统处理带记录时间戳选项IP报文的功能。该选项用于计算报文传输/处理时消耗的时间。 默认值：无 |
| IFNAME     | 接口名称   | 可选必选说明：可选参数 参数含义：该参数用于表示接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。接口名称由接口类型+接口编号组成。 默认值：无                                                                                                                               |

#### 使用实例

查询记录路由选项routeRecord的配置实例：

```
LST IPOPTSECURITYIF: OPTIONTYPE=routeRecord, IFNAME="Ethernet66/0/4";
```

```
        RETCODE = 0  操作成功

        IP选项配置开关  =  使能

        (结果个数 = 1)
        ---   END
```
