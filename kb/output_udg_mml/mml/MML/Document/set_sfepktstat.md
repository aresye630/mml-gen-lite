# 设置报文统计记录开关（SET SFEPKTSTAT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

设置报文统计记录开关。

#### 注意事项

该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称       | 参数说明                                                                         |
|:---------|:-----------|:-----------------------------------------------------------------------------|
| ISENABLE | 报文统计记录开关使能 | 可选必选说明：必选参数 参数含义：报文统计记录开关使能。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无 |

#### 使用实例

软转发报文统计记录使能：

```
SET SFEPKTSTAT: ISENABLE = TRUE;
```
