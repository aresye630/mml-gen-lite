# 查询IP报文ECN功能参数（LST IPECNCTRL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询IP报文ECN相关功能参数。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询下行报文使能L4S ECN标记功能：

```
LST IPECNCTRL:;
```

```
RETCODE = 0  操作成功

结果如下
--------
L4S下行ECN开关 = 使能
(结果个数 = 1)

---    END
```
