# 修改证书场景描述（MOD CERTSCENE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于修改证书场景描述。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                |
|:--------------|:-------|:----------------------------------------------------------------------------------------------------|
| SCENENAME     | 场景名称   | 可选必选说明：必选参数  参数含义：场景名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~192。不区分大小写，最多允许一个空格，不支持中文字符。  默认值：无  配置原则：无 |
| ENDESCRIPTION | 场景英文描述 | 可选必选说明：可选参数  参数含义：场景英文描述。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~192。不区分大小写。  默认值：无  配置原则：无                |
| CNDESCRIPTION | 场景中文描述 | 可选必选说明：可选参数  参数含义：场景中文描述。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~192。不区分大小写。  默认值：无  配置原则：无                |

## 使用实例

修改场景名为“DeviceA”的证书场景：

```
MOD CERTSCENE: SCENENAME="DeviceA", ENDESCRIPTION="DeviceA", CNDESCRIPTION="DeviceA";
```
