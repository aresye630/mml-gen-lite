# 显示网络功能集状态（DSP FUNCTIONSETSTAT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示网络功能集。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

无

## 使用实例

显示当前网络功能集:
DSP FUNCTIONSETSTAT :;

```
%%DSP FUNCTIONSETSTAT :;%%
RETCODE = 0  操作成功 
结果如下 
--------
网络功能集名称       状态信息
Plat_Base            online
```

## 输出结果说明

| 输出项名称   | 输出项解释    |
|:--------|:---------|
| 网络功能集名称 | 网络功能集名称。 |
| 状态信息    | 状态信息。    |
