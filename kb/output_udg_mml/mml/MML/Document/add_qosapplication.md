# 增加流策略（ADD QOSAPPLICATION）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来在接口应用流量策略；需要对接口进行QoS策略时，可以使用该命令在配置指定的QoS流策略。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为131072。
- 本命令参数参与自动化配置，请在下发本MML命令前使用DSP OPSASSISTSTATE命令查询自动化配置维护助手autoscaling\_autoconfig.py，确保当前设备不在自动化配置过程中。如果当前正在自动化配置过程中，不要做本业务的增删改操作，否则最终生效的配置将不可预期。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                        |
|:-----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IFNAME     | 接口名称   | 可选必选说明：必选参数 参数含义：该参数用于指定应用流量策略的接口，以太主接口/子接口。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：与设备接口名称保持一致，下发本MML命令前可使用LST INTERFACE查看设备接口。                                                      |
| DIRECTION  | 报文方向   | 可选必选说明：必选参数 参数含义：该参数用于指定在接口入方向还是出方向应用流量策略。 数据来源：本端规划 取值范围：枚举类型。 inbound：入方向报文。outbound：出方向报文。 默认值：无 配置原则：inbound入方向流量策略不支持对非单播协议报文过滤。 outbound出方向流量策略不支持对IPv6报文过滤，对于IPv4报文只支持Permit/Deny动作。 |
| POLICYNAME | 策略名称   | 可选必选说明：必选参数 参数含义：该参数用于指定应用的流量策略。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：需要先使用ADD MQCPOLICY命令增加流策略。                                                                                    |
| LAYER      | 层信息    | 可选必选说明：可选参数 参数含义：该参数用于指定应用的流量策略。 数据来源：本端规划 取值范围：枚举类型。 default：此策略应用在IP层。link_layer：此策略应用在链路层。 默认值：default                                                                                   |

#### 使用实例

在以太网接口Ethernet66/0/3入方向应用流量策略p1：

```
ADD QOSAPPLICATION:IFNAME="Ethernet66/0/3", DIRECTION=inbound, POLICYNAME="p1",LAYER=link_layer;
```
