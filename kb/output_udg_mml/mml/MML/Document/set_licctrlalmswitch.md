# 设置LicenseCtrl告警控制开关（SET LICCTRLALMSWITCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

设置Licctrl告警控制开关。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| ALMID      | ALMSWITCH   |
|:-----------|:------------|
| ALM-100775 | OFF         |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                  |
|:----------|:-------|:----------------------------------------------------------------------------------------------------------------------|
| ALMID     | 告警ID   | 可选必选说明：必选参数  参数含义：该参数用于表示LicenseCtrl中的告警ID。  数据来源：本端规划 取值范围： ALM-100775（100775 - 系统存在未生效关键License控制项）  默认值：无。  配置原则：无 |
| ALMSWITCH | 告警开关   | 可选必选说明：必选参数  参数含义：该参数用于表示告警能力开启或关闭。  数据来源：本端规划 取值范围： OFF（关闭）ON（开启）  默认值：无。  配置原则：无                                    |

## 使用实例

关闭100775告警的开关。

```
%%SET LICCTRLALMSWITCH: ALMID=ALM-100775, ALMSWITCH=OFF;%%
RETCODE = 0  操作成功

---    END
```
