# 查看S1TAC与S1TAC组的绑定关系（LST S1TACID）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用来查看指定S1TAC号段与S1TAC组的绑定关系或者配置的所有S1TAC号段和S1TAC组的绑定关系。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称      | 参数说明                                                                                         |
|:-------------|:----------|:---------------------------------------------------------------------------------------------|
| TACGROUPNAME | 指定S1TAC组名 | 可选必选说明：可选参数 参数含义：该参数用于指定S1TAC组名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。不支持空格，不区分大小写。 默认值：无 配置原则：无 |
| TACSECNUM    | S1Tac 段编号 | 可选必选说明：可选参数 参数含义：该参数用于指定S1TAC段编号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～15999。 默认值：无 配置原则：无             |

#### 使用实例

假设运营商需要查看指定S1TAC号段与S1TAC组的绑定关系：S1TAC组为beijing，S1TAC号段为2：

```
LST S1TACID:TACGROUPNAME="beijing",TACSECNUM=2;
```

```
RETCODE = 0  操作成功。

结果如下
--------
  S1TAC段编号  =  2
指定S1TAC组名  =  beijing
  S1TAC起始ID  =  0x0001
  S1TAC截止ID  =  0x0010
(结果个数 = 1)
---    END
```
