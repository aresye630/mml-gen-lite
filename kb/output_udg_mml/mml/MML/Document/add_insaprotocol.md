# 增加黑白名单协议配置（ADD INSAPROTOCOL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

增加黑白名单协议配置。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为8192。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                        |
|:--------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROTTYPE      | 协议类型   | 可选必选说明：必选参数 参数含义：该参数用来表示配置协议类型。 数据来源：本端规划 取值范围： BLACK：黑名单协议。ENHANCE：待增强协议。 默认值：无 配置原则：无                                                                     |
| PROTOCOLNAME  | 协议名称   | 可选必选说明：必选参数 参数含义：协议组包含的协议的名字。 数据来源：本端规划 取值范围：1、字符串类型，输入长度范围为1～31; 2、不支持空格，不区分大小写。 默认值：无 配置原则：数据源为系统支持识别的子协议，可以通过工程命令smctrldsp protocol-list sub-protocol查询。 |
| CFGDOMAINNAME | 配置域名称  | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无                                                                          |

#### 使用实例

增加一个http待增强协议：

```
ADD INSAPROTOCOL:PROTTYPE=ENHANCE, PROTOCOLNAME="http";
```
