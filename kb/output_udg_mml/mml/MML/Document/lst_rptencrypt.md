# 查询业务报表加密算法配置（LST RPTENCRYPT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

此命令用于查询业务报表加密算法配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

假如运营商需要查询业务报表加密算法配置：

```
LST RPTENCRYPT:;
```

```
RETCODE = 0 操作成功

业务报表加密算法配置信息
---------------------------
加密模式 = DEFAULT
加密算法 = SHA256
     
(结果个数 = 1)
--- END
```

#### 输出结果说明

参见SET RPTENCRYPT的参数说明。
