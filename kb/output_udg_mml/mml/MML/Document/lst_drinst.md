# 查询容灾实例(LST DRINST)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询本端容灾实例信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                             |
|:---------|:-------|:-----------------------------------------------------------------|
| DRINSTID | 容灾实例ID | 可选必选说明：可选参数。 参数含义：该参数用于配置容灾实例标识。 数据来源：全网规划。 取值范围：整型，0~63。 默认值：无。 |

#### 使用实例

查询容灾实例：

```
%%LST DRINST:;%%
RETCODE = 0  操作成功

操作结果如下：
--------------
  容灾实例ID  =  0
容灾实例名称  =  NULL
(结果个数 = 1)

---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释   |
|:--------|:--------|
| 容灾实例ID  | 容灾实例标识。 |
| 容灾实例名称  | 容灾实例名称。 |
