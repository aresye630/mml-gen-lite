# 增加PCC动作属性（ADD PCCACTIONPROP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

此命令用于增加PCC动作属性。可以通过命令，配置PCC策略相关的动作属性，包括Gate、URL Redirect动作。支持配置不同业务发起端定义不同的上下行报文处理动作。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为200。
- 如果上行或下行发起业务的相应策略没有配置，则按照默认Pass处理。
- 报文动作需要上下行都配置且保持一致，配置不一致可能导致业务不通。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

假如运营商需要定义一个PCC动作属性，要求对于上行发起的业务，上下行报文均可以正常通过，下行发起的业务，上下行报文均丢弃。
增加一个PCC动作属性，“PCCACTPROPNAME”为“TestPccActPropName”，“UPINITUPGATE”为“PASS”，“UPINITDNGATE”为“PASS”，“DNINITUPGATE”为“DISCARD”，“DNINITDNGATE”为“DISCARD”：

```
ADD PCCACTIONPROP:PCCACTPROPNAME="TestPccActPropName",UPINITUPGATE=PASS,UPINITDNGATE=PASS,DNINITUPGATE=DISCARD,DNINITDNGATE=DISCARD;
```
