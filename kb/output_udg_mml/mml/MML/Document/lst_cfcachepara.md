# 查询内容过滤缓存参数（LST CFCACHEPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询内容过滤本地缓存参数。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询内容过滤本地缓存参数：

```
LST CFCACHEPARA:;
```

```
RETCODE = 0  操作成功
 
内容过滤本地缓存参数
--------------------
本地缓存过期时间（秒）  =  3600
        缓存开关  =  使能（开启）
(结果个数 = 1)
 
---    END
```

#### 输出结果说明

参见SET CFCACHEPARA的参数说明。
