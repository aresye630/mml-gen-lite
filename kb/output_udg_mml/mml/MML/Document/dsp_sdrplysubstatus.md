# 显示SDRC中保存的策略订阅关系（DSP SDRPLYSUBSTATUS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示SDRC中保存的策略订阅关系。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                    |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------|
| PLYTYPE | 策略类型   | 可选必选说明：必选参数  参数含义：该参数用于指定订阅者订阅的策略类型。  数据来源：本端规划 取值范围： APPROUTE（APPROUTE）TOPIC（TOPIC）VPN（VPN）VPNIP（VPNIP）TOKEN（TOKEN）KEYMATCH（KEYMATCH）  默认值：无  配置原则：无   |
| PLYKEY  | 策略键值   | 可选必选说明：该参数在"PLYTYPE"配置为"TOKEN"、"KEYMATCH"时为条件必选参数。  参数含义：该参数用于指定策略键值，可以通过命令DSP SDRPOLICYKEYS获取。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无 |

## 使用实例

查询SDRC中保存的路由策略的订阅者信息：

```
%%DSP SDRPLYSUBSTATUS: PLYTYPE=TOKEN, PLYKEY=1007;%%
RETCODE = 0  操作成功

结果如下
--------

```

## 输出结果说明

| 输出项名称   | 输出项解释                                               |
|:--------|:----------------------------------------------------|
| 实例ID    | 该参数用于指定订阅者的实例ID。                                    |
| 进程标识    | 该参数用于指定订阅者的进程标识。                                    |
| 订阅时间    | 该参数用于指定订阅者最新一次的订阅时间。                                |
| 推送时间    | 该参数用于指定最新一次发送策略给订阅者的时间。                             |
| 订阅状态    | 该参数用于指定当前是否需要向订阅者发送响应。 取值说明： TRUE(TRUE)FALSE(FALSE) |
