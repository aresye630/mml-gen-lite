# 显示IKE内部负载分担策略信息（DSP IKEINNERPOLICY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示IKE内部负载分担策略信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                       |
|:--------|:-------|:-------------------------------------------------------------------------------------------|
| TULNAME | 隧道名    | 可选必选说明：必选参数  参数含义：该参数用于指定查询内部策略关联的隧道名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。  默认值：无  配置原则：无 |

## 使用实例

显示与隧道名称为“Tunnel27”的隧道接口相关的IKE内部负载分担策略信息

```
DSP IKEINNERPOLICY: TULNAME="Tunnel27";
RETCODE = 0  操作成功

结果如下
------------------------
           隧道名  =  Tunnel27
         隧道标识  =  1
            VPN名  =  NULL
          VPN标识  =  0
         Policy名  =  ipsecply27
     Policy序列号  =  1
       Proposal名  =  ipsecpsl27
     Proposal标识  =  27
           Peer名  =  env27
       Peer优先级  =  1
(结果个数 = 1)
```

## 输出结果说明

| 输出项名称      | 输出项解释                     |
|:-----------|:--------------------------|
| 隧道名        | 该参数用于指定查询内部策略关联的隧道名称。     |
| 隧道标识       | 该参数用于描述内部策略关联的隧道标识。       |
| VPN名       | 该参数用于描述内部策略关联的vpn名。       |
| VPN标识      | 该参数用于描述内部策略关联的vpn标识。      |
| 策略名        | 该参数用于描述内部策略名。             |
| 策略序列号      | 该参数用于描述内部策略序列号。           |
| Proposal名  | 该参数用于描述内部策略关联的proposal名。  |
| Proposal标识 | 该参数用于描述内部策略关联的proposal标识。 |
| Peer名      | 该参数用于描述内部策略关联的peer名。      |
| Peer优先级    | 该参数用于描述内部策略关联的peer优先级。    |
