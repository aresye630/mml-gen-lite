# 设置RU CPU占用率告警上报门限和告警恢复门限(SET RUCPUTHRESH)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于配置“ALM-82802 RU CPU过载”的CPU过载告警上报门限和告警恢复门限。

#### 注意事项

- 该命令执行后，会直接恢复已经上报的告警。
- 该命令执行后立即生效。
- 该命令只对非主控的RU生效。
- 如果命令输入“RU的ID”在记录中不存在，则返回无记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                                                                                              |
|:----------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RUID            | RU的ID  | 可选必选说明：必选参数。 参数含义：表示资源单元的ID。通过LST SERVICERUSTATE命令可以查询RU的ID 数据来源：本端规划 取值范围：整数类型，取值范围为64～4294967294。 系统设置初始值：无 默认值：无                                                                                                               |
| WARNTHRESH      | 告警上报门限 | 可选必选说明：必选参数。 参数含义：CPU过载告警的上报门限，RU的CPU占用率持续超过2分钟高于该数值则上报RU CPU过载告警。 数据来源：本端规划 取值范围：整数类型，取值范围为0～100，单位为%。 系统设置初始值 (CSLB_VNFC)：85 系统设置初始值 (其他VNFC类型)：80 默认值：无 配置原则：“告警上报门限”必须大于“告警恢复门限”。如果CSLB_VNFC设置的告警上报门限低于下限值81，会在RU复位后恢复成初始值85。 |
| RECVTHRESH      | 告警恢复门限 | 可选必选说明：必选参数。 参数含义：CPU过载告警的恢复门限，RU的CPU占用率一旦低于该数值则恢复告警。 数据来源：本端规划 取值范围：整数类型，取值范围为0～100，单位为%。 系统设置初始值：70 默认值：无 配置原则：“告警恢复门限”必须小于“告警上报门限”。                                                                                            |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识，不支持对"VNFC类型名称"为VNFP、VNRS_VNFC、ACS、IPSEC_VNFC的RU状态查询。                                                                  |

#### 使用实例

设置“RU的ID”为64的CPU过载告警上报门限和告警恢复门限：

`SET RUCPUTHRESH: RUID = 64,WARNTHRESH = 90,RECVTHRESH = 60,SERVICEINSTANCE="CSLB_VNFC_999";`
