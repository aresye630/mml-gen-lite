# 查询流过滤器下的所有7层过滤器信息（LST L7FILTERINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询流过滤器下绑定的所有7层过滤器信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                        |
|:---------------|:-------|:--------------------------------------------------------------------------------------------|
| FLOWFILTERNAME | 流过滤器名称 | 可选必选说明：必选参数 参数含义：该参数用于指定流过滤器名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

- 运营商需要查询名称为ff1的流过滤器下的所有7层过滤器信息：

  ```
  LST L7FILTERINFO: FLOWFILTERNAME="ff1";
  ```

  ```
  RETCODE = 0  操作成功

  结果如下
  --------
           流过滤器名称	=   ff1
              协议名称	=   dns
         七层过滤器名称	=   l7_1
       子七层过滤器名称 	=   sl7_1
              URL类型	=   URL
                  URL	=   www.huawei.com
                 HOST	=   NULL
            客户端类型	=   NULL
              方法类型	=   CONNECT
   Referer关联计费开关	=   不使能（关闭）
          彩信模糊匹配	=   不使能（关闭）
          扩展头域名称	=   NULL
            配置域名称	=   NULL
  (结果个数 = 1)
  ```
- 运营商需要查询名称为ff2的流过滤器下的所有7层过滤器信息：

  ```
  LST L7FILTERINFO: FLOWFILTERNAME="ff2";
  ```

  ```
  RETCODE = 0  操作成功

  结果如下
  --------
  流过滤器名称  协议名称  七层过滤器名称  子七层过滤器名称  URL类型  URL             HOST  客户端类型  方法类型  Referer关联计费开关  彩信模糊匹配    扩展头域名称  配置域名称

  ---    END
  ```

#### 输出结果说明

| 输出项名称         | 输出项解释                 |
|:--------------|:----------------------|
| 流过滤器名称        | 表示流过滤器名称。             |
| 协议名称          | 表示协议名称。               |
| 七层过滤器名称       | 表示七层过滤器名称。            |
| 子七层过滤器名称      | 表示该L7Filter的子七层过滤器名称。 |
| URL类型         | 表示七层URL配置类型。          |
| URL           | 表示URL。                |
| HOST          | 表示HOST。               |
| 客户端类型         | 表示客户端类型。              |
| 方法类型          | 表示数据请求的类型。            |
| Referer关联计费开关 | 表示referer关联开关。        |
| 彩信模糊匹配        | 表示彩信模糊匹配功能。           |
| 扩展头域名称        | 表示扩展头域条件名称。           |
| 配置域名称         | 表示命令所属公共配置域的名称。       |
