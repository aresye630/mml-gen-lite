# 增加主接口允许通过的VLAN（ADD IFALLOWEDVLAN）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于增加主接口允许通过的VLAN。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为65536。
- 每个主接口允许通过的VLAN数量上限为1024，允许通过的VLAN范围为2~4094。
- 若接口被配置了子接口，此接口不能再使用该命令配置VLAN，可执行命令LST ETHSUBIF查看子接口的VLAN配置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                      |
|:----------|:--------|:--------------------------------------------------------------------------------------------------------------------------|
| IFNAME    | 接口名1    | 可选必选说明：必选参数。 参数含义：该参数用于指定接口名称。 数据来源：本端规划。 取值范围：字符串类型，输入长度范围为1～63。接口名称由接口类型+接口编号组成。 默认值：无。 配置原则：请使用LST INTERFACE命令查看可用接口。  |
| IFNAME2   | 接口名2    | 可选必选说明：必选参数。 参数含义：该参数用于指定接口2名称。 数据来源：本端规划。 取值范围：字符串类型，输入长度范围为1～63。接口名称由接口类型+接口编号组成。 默认值：无。 配置原则：请使用LST INTERFACE命令查看可用接口。 |
| VLANBEGIN | VLAN最小值 | 可选必选说明：必选参数。 参数含义：该参数用于设置允许通过的VLAN范围最小值。 数据来源：本端规划。 取值范围：2~4094，VLANBEGIN <= VLANEND。 默认值：无。 配置原则：无。                      |
| VLANEND   | VLAN最大值 | 可选必选说明：必选参数。 参数含义：该参数用于设置允许通过的VLAN范围最大值。 数据来源：本端规划。 取值范围：2~4094，VLANEND >= VLANBEGIN。 默认值：无。 配置原则：无。                      |

#### 使用实例

配置主接口Ethernet64/0/4，Ethernet65/0/4允许通过的VLAN范围，VLAN最小值为20，VLAN最大值为25：

```
ADD IFALLOWEDVLAN: IFNAME="Ethernet64/0/4",  IFNAME2="Ethernet65/0/4", VLANBEGIN=20, VLANEND=25;
```
