# 显示当前版本信息（DSP UPDVER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

在日常维护和版本升级时，执行该命令检查当前的基础包和补丁包的版本号信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

显示版本信息：

```
DSP UPDVER:SERVICEINSTANCE="vnfc";
```

```
RETCODE = 0  操作成功 

结果如下:  
-------------------------  
基础软件包版本号 = V100R005C00B021
      补丁版本号 = SPH0020
(结果个数 = 1)  
---    END
```

#### 输出结果说明

| 输出项名称    | 输出项解释       |
|:---------|:------------|
| 基础软件包版本号 | 表示系统基础版本号。  |
| 补丁版本号    | 表示系统的补丁版本号。 |
