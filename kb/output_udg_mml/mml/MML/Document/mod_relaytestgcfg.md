# 修改媒体中继测试分组配置（MOD RELAYTESTGCFG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于修改媒体中继测试分组配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称         | 参数说明                                                                                                                                                                                                                       |
|:----------------|:-------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RELAYTESTGNAME  | 媒体中继测试分组名称   | 可选必选说明：必选参数 参数含义：该参数用于设置媒体中继测试分组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无                                                                                                                                         |
| RELAYUSERDMLIST | 媒体中继用户域名探测列表 | 可选必选说明：必选参数 参数含义：该参数用于指定媒体中继分组用户探测分组使用的域名列表。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～255，前后域名使用空格隔开，最多支持配置5个域名，不区分大小写。 默认值：无 配置原则： 输入参数为空格时清除原有值。DNS代理时根据配置在此字段中的域名对代理的DNS请求进行匹配，若匹配中则进行后续AB分组的记录、话统、日志等功能。                          |
| COMUSERDMLIST   | 普通用户域名探测列表   | 可选必选说明：可选参数 参数含义：该参数用于指定普通分组用户探测分组使用的域名列表。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～255，前后域名使用空格隔开，最多支持配置5个域名，不区分大小写。如果配置为空，媒体中继分组之外的用户均为普通分组用户。 默认值：无 配置原则： 输入参数为空格时清除原有值。DNS代理时根据配置在此字段中的域名对代理的DNS请求进行匹配，若匹配中则进行后续AB分组的记录、话统、日志等功能。 |
| USERLOGSW       | 用户分组日志开关     | 可选必选说明：可选参数 参数含义：该参数用于设置是否开启用户分组日志功能。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：关闭用户分组日志功能。ENABLE：开启用户分组日志功能。 默认值：DISABLE 配置原则：无                                                                                                        |
| LOGMAXKEEPDAYS  | 日志最大保存时间     | 可选必选说明：条件必选参数 前提条件：该参数在“USERLOGSW”配置为“ENABLE”时为必选参数。 参数含义：该参数设置用户分组日志的最大保存时间。 数据来源：本端规划 取值范围：取值范围1~255，默认值为7，单位为天。 默认值：无 配置原则：无                                                                                            |
| PSWDKEY         | 日志加密密钥       | 可选必选说明：条件可选参数 前提条件：该参数在“USERLOGSW”配置为“ENABLE”时为可选参数。 参数含义：该参数用于设置日志加密使用的密钥。 数据来源：本端规划 取值范围：密码类型，输入长度范围为1～32，不支持空格，区分大小写。 默认值：无 配置原则：无                                                                                      |
| PSWDKEYCONFIRM  | 日志加密确认密钥     | 可选必选说明：条件可选参数 前提条件：该参数在“USERLOGSW”配置为“ENABLE”时为可选参数。 参数含义：该参数用于确认日志加密使用的密钥。 数据来源：本端规划 取值范围：密码类型，输入长度范围为1～32，不支持空格，区分大小写。 默认值：无 配置原则：无                                                                                      |
| APPPERFNAME1    | APP业务类型实例1   | 可选必选说明：必选参数 参数含义：该参数用于设置分组统计的业务APP实例1。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则： 该参数使用ADD APPPERFSTAT命令配置生成。输入参数值为空格时清除原有值。                                                                                            |
| APPPERFNAME2    | APP业务类型实例2   | 可选必选说明：可选参数 参数含义：该参数用于设置分组统计的业务APP实例2。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则： 该参数使用ADD APPPERFSTAT命令配置生成。输入参数值为空格时清除原有值。                                                                                            |

#### 使用实例

假如需要修改媒体中继测试分组配置，则命令如下：

```
MOD RELAYTESTGCFG: RELAYTESTGNAME="test", RELAYUSERDMLIST="relaydomain", COMUSERDMLIST="commondomain", USERLOGSW=ENABLE, LOGMAXKEEPDAYS=10, PSWDKEY="pwsdkey", PSWDKEYCONFIRM="confirmkey", APPPERFNAME1="appperfname1";
```
