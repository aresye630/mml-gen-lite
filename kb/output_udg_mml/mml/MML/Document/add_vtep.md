# 增加VXLAN隧道端点配置（ADD VTEP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于增加VXLAN隧道端点。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为512。
- 在5G LAN业务中，地址类型只支持配置为IPv4。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称          | 参数说明                                                                                                                                                                                                                |
|:----------|:--------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VTEPNAME  | VXLAN隧道端点名称   | 可选必选说明：必选参数 参数含义：该参数用于配置VXLAN隧道端点名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不区分大小写，不支持空格。 默认值：无 配置原则：无                                                                                                                    |
| IPVERSION | IP协议版本        | 可选必选说明：必选参数 参数含义：该参数用于设置VTEP IP地址类型。 数据来源：本端规划 取值范围：枚举类型。 IPV4：IPv4地址类型。IPV6：IPv6地址类型。 默认值：无 配置原则：无                                                                                                                 |
| VTEPIPV4  | 隧道对端端点的IPv4地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV4”时为必选参数。 参数含义：该参数用于配置VXLAN隧道端点IPv4地址。 数据来源：对端协商 取值范围：IPv4地址类型。有效的IP地址。采用点分十进制"X.X.X.X"格式，不能是全0全1，不能是组播IP，不能是环回IP。 默认值：无 配置原则：根据环境的网络规划进行配置，点分十进制格式。除A、B、C类地址合法外，其余都为非法地址。 |
| VTEPIPV6  | 隧道对端端点的IPv6地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV6”时为必选参数。 参数含义：该参数用于配置VXLAN隧道端点IPv6地址。 数据来源：对端协商 取值范围：IPv6地址类型。采用冒号分十六进制X:X:X:X:X:X:X:X格式。 默认值：无 配置原则：无                                                                    |
| TYPE      | VXLAN隧道对端的类型  | 可选必选说明：可选参数 参数含义：该参数用于配置VXLAN隧道对端的类型。 数据来源：对端协商 取值范围：枚举类型。 N6：VXLAN隧道对端的类型为N6。N19：VXLAN隧道对端的类型为N19。 默认值：N6 配置原则：当需要组内互访控制时，需要用此参数明确标识对端类型用于报文转发控制。                                                                  |

#### 使用实例

配置VXLAN隧道端点，VTEPNAME为vtep1，IP为192.168.1.1：

```
ADD VTEP: VTEPNAME="vtep1", IPVERSION=IPV4, VTEPIPV4="192.168.1.1";
```
