# 查询HTTPS证书检查功能配置（LST AFHTTPSCTCK）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用来查询配置的HTTPS证书检查功能。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询所有HTTPS证书检查功能配置：

```
LST AFHTTPSCTCK:;
```

```
RETCODE = 0  操作成功

HTTPS证书检查配置信息
---------------------
协议名称      证书检查开关  配置域名称  

facebook      使能（开启）  NULL        
youtube       使能（开启）  NULL        
all-protocol  使能（开启）  NULL        
(结果个数 = 3)

---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                 |
|:--------|:----------------------|
| 证书检查开关  | 用于显示是否开启了HTTPS证书检查功能。 |

其余输出项请参见ADD AFHTTPSCTCK的参数说明。
