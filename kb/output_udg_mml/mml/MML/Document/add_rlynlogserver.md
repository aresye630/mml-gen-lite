# 增加媒体中继回源NAT日志服务器配置（ADD RLYNLOGSERVER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于增加媒体中继回源NAT日志服务器配置。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为4。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                         |
|:------------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------|

| IPV4ADDRESS | 服务器IPv4地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV4”时为必选参数。 参数含义：该参数用于配置服务器IPv4地址。 数据来源：本端规划 取值范围：IPv4地址类型。采用点分十进制格式。不支持255.255.255.255。 默认值：无 配置原则：无 |

| SERVERPORT  | 服务器端口号    | 可选必选说明：可选参数 参数含义：该参数用于指定服务器端口号。 数据来源：本端规划 取值范围：整数类型，取值范围为1~65535。 默认值：514 配置原则：无                                                             |
| VPNINSTANCE | VPN实例名称   | 可选必选说明：可选参数 参数含义：该参数用于指定VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1~31，不支持空格，不区分大小写。 默认值：无 配置原则：无                                                 |
| DETECTSW    | 链路探测开关    | 可选必选说明：可选参数 参数含义：该参数用于指定链路探测开关。 数据来源：本端规划 取值范围：枚举类型。 ENABLE：使能链路探测。DISABLE：不使能链路探测。 默认值：ENABLE 配置原则：无                                        |
| DETECTTIME  | 探测周期（秒）   | 可选必选说明：条件可选参数 前提条件：该参数在“DETECTSW”配置为“ENABLE”时为可选参数。 参数含义：该参数用于指定探测周期（秒）。 数据来源：本端规划 取值范围：整数类型，取值范围为5~3600，单位是秒。 默认值：60 配置原则：无                 |
| SERVERTYPE  | 服务器类型     | 可选必选说明：必选参数 参数含义：该参数用于指定服务器类型。 数据来源：本端规划 取值范围：枚举类型。 MASTER：主服务器。SLAVE：备服务器。 默认值：无 配置原则：无                                                     |

#### 使用实例

假如需要增加媒体中继回源NAT日志服务器配置，则命令如下：

```
ADD RLYNLOGSERVER: ServerName="test01", Ipversion =IPv4, IPv4Address="192.168.255.254", ServerPort =25535, VPNInstance="INS1", ServerType=Master, DetectSw=ENABLE, DetectTime=1800;
```
