# 查询SDRC中缓存的进程信息（DSP SDRPROCESS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询SDRC中缓存的进程信息，若指定进程号则显示特定的进程信息，否则列出所有的进程信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                     |
|:----------|:-------|:-----------------------------------------------------------------------------------------|
| PROCESSID | 进程ID   | 可选必选说明：可选参数  参数含义：该参数用于标识实例对应的进程ID。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~1024。  默认值：无  配置原则：无 |

## 使用实例

使用如下命令查询SDRC中缓存的进程信息：

```
%%DSP SDRPROCESS: PROCESSID="vup-pod-010-107-0-165__121__0";%%
RETCODE = 0  操作成功

结果如下
--------
   进程ID  =  vup-pod-010-107-0-165__121__0
 FABRIC TB  =  low:1124
FABRIC TPS  =  sdr:2210930432 external:2210995968
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称      | 输出项解释                   |
|:-----------|:------------------------|
| 进程ID       | 该参数用于标识实例对应的进程ID。       |
| FABRIC TB  | 该参数用于标识进程所在虚拟机（裸机）的ID。  |
| FABRIC TPS | 该参数用于标识虚拟机（裸机）中的虚拟端口ID。 |
