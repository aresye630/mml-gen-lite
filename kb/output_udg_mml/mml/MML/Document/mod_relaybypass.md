# 修改媒体中继Bypass机制（MOD RELAYBYPASS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，执行该命令后，会影响媒体中继功能。

该命令用于修改媒体中继Bypass机制。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                                                                                                                                                     |
|:-------------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RELAYTPLNAME | 媒体中继模板名称 | 可选必选说明：必选参数 参数含义：该参数用来指定媒体中继模板名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数使用ADD RELAYTEMPLATE命令配置生成。配置时需要确保RELAYTPLNAME已经配置（ADD RELAYTEMPLATE）。                                                    |
| BYPASSACT    | Bypass动作 | 可选必选说明：必选参数 参数含义：该参数用来指定媒体中继Bypass动作。 数据来源：本端规划 取值范围：枚举。 NewSrvBypass：DNS Proxy关闭，新业务重定向到CDN，老业务继续。DNSProxyByPass：DNS Proxy关闭，新业务继续，老业务继续。AllSrvByPass：DNS Proxy关闭，新业务重定向到CDN，老业务拆链，新业务再做Bypass。 默认值：NewSrvBypass 配置原则：无 |

#### 使用实例

假如需要修改一组媒体中继Bypass机制，则命令如下：

```
MOD RELAYBYPASS: RELAYTPLNAME="test", BYPASSACT=NewSrvBypass;
```
