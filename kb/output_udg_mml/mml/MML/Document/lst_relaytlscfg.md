# 查询媒体中继业务TLS认证配置（LST RELAYTLSCFG）

- 命令功能
- 注意事项

- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询Relay域名业务分别作为客户端或服务端认证属性。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                 |
|:--------------|:--------|:-----------------------------------------------------------------------------------------------------|
| TLSCONFIGNAME | TLS配置名称 | 可选必选说明：可选参数 参数含义：该参数用于设置该Relay业务TLS配置描述。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

假如需要查询媒体中继业务TLS认证配置，则命令如下：

```
LST RELAYTLSCFG:;
```
