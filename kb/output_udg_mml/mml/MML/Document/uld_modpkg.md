## 命令功能

该命令用于将存储在FileServer服务上的模型包上传到DFS存储服务中。

## 注意事项

- 上传的模型包不可和预置的模型包同名，已有的预置模型包可通过**DSP MODPKG**命令查询。
- 单次上传的模型包大小不超过500MB。
- 模型包在FileServer服务存放最大空间不超过2048MB，FileServer服务临时存储模型包时间为7天。
- 成功上传到DFS的模型包会在FileServer删除。
- 上传失败的系统会自动清理模型包残留文件，上传记录不会在OM Portal展示。
- 该命令每次仅支持上传一个模型包，不支持同时上传多个模型包。

## 参数说明

| 参数标识             | 参数名称   | 参数说明                                                                                                                                 |
|:-----------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------|
| MEID             | 网元ID   | 可选必选说明：必选参数。 参数含义：需要上传模型包的网元ID。 取值范围：整数类型，取值范围为0~65535。 默认值：无。 配置原则：网元ID可通过LST ME命令查询获得。                                             |
| MODELPACKAGENAME | 模型包名称  | 可选必选说明：必选参数。 参数含义：已存储在FileServer服务上的模型包名称。 取值范围：字符串类型，长度1~128。 默认值：无。 配置原则：只能包括大小写字母、数字、中划线-、下划线_、英文句号.，必须包含下划线_，以.zip后缀结尾。长度最大为128。 |

## 使用实例

为网元ID=0的网元上传名称为“MODEL-AUTO\_202542204327.zip”的模型包。

```
%%ULD MODPKG: MEID=0, MODELPACKAGENAME="MODEL-AUTO_202542204327.zip";%%
RETCODE = 0  上传中

进度报告
--------
已完成 = 10%
(结果个数 = 1)

---    END

%%ULD MODPKG: MEID=0, MODELPACKAGENAME="MODEL-AUTO_202542204327.zip";%%
RETCODE = 0  操作成功

模型包信息
----------
模型包名称  =  MODEL-AUTO_202542204327.zip
      大小  =  0.05 MB
(结果个数 = 1)

模型文件信息
------------
  模型包名称  =  MODEL-AUTO_202542204327.zip
模型文件名称  =  PROTOCOL_CLASSIFY_1.0.13.tar.gz
        版本  =  1.0.13
    场景类型  =  PROTOCOL_CLASSIFY
        大小  =  0.05 MB
(结果个数 = 1)

共有2个报告
---    END
```
