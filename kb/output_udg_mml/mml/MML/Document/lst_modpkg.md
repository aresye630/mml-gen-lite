# 查询模型老化配置（LST MODPKG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询指定网元下的模型老化配置信息，包括场景、老化空间、老化模型个数、模型类型等。

#### 注意事项

无。

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                       |
|:-------------|:-------|:-------------------------------------------------------------------------------------------|
| MEID         | 网元ID   | 可选必选说明：必选参数。 参数含义：需要查询模型信息的网元ID。 取值范围：整数类型，取值范围为0~65535。 默认值：无。 配置原则：网元ID可通过LST ME命令查询获得。  |
| BUSINESSTYPE | 业务类型   | 可选必选说明：可选参数。 参数含义：需要查询的业务类型。 取值范围： “TRAIN（训练）”：业务类型为训练。“INFER（推理）”：业务类型为推理。 默认值：无。 配置原则：无。 |

#### 使用实例

1、查询网元ID=0的网元下所有模型老化配置信息。

```
%%LST MODPKG: MEID=0;%%
RETCODE = 0  操作成功
模型老化配置信息
----------------
网元ID  场景                    老化空间（MB）  老化模型个数  模型类型   
0       PROTOCOL_CLASSIFY       50              11            自动       
0       PROTOCOL_CLASSIFY_STOP  5               2             自动       
0       PROTOCOL_CLASSIFY1      40              5             自动       
0       FACE_RECOGNITION        48              22            手动|预置  
0       PROTOCOL_CLASSIFY       5               55            手动|预置  
(结果个数 = 5)
---    END
```

2、查询网元ID=0，业务类型为“TRAIN”的模型老化配置信息。

```
%%LST MODPKG: MEID=0, BUSINESSTYPE=TRAIN;%%
RETCODE = 0  操作成功
模型老化配置信息
----------------
网元ID  场景                    老化空间（MB）  老化模型个数  模型类型  
0       PROTOCOL_CLASSIFY       50              11            自动      
0       PROTOCOL_CLASSIFY_STOP  5               2             自动      
0       PROTOCOL_CLASSIFY1      40              5             自动      
(结果个数 = 3)
---    END
```

3、查询网元ID=0，业务类型为“INFER”的模型老化配置信息。

```
%%LST MODPKG: MEID=0, BUSINESSTYPE=INFER;%%
RETCODE = 0  操作成功
模型老化配置信息
----------------
网元ID  场景               老化空间（MB）  老化模型个数  模型类型   
0       FACE_RECOGNITION   48              22            手动|预置  
0       PROTOCOL_CLASSIFY  5               55            手动|预置  
(结果个数 = 2)
---    END
```

#### 输出结果说明

命令执行正常，会返回模型老化配置信息，输出结果项信息项目如表1。

命令执行异常，会返回对应的错误码。常见错误码如表2所示。

| 输出项名称    | 输出项解释            |
|:---------|:-----------------|
| 网元ID     | 用于返回网元ID。        |
| 场景       | 用于返回不同业务注册的场景。   |
| 老化空间（MB） | 用于返回不同场景的老化空间大小。 |
| 老化模型个数   | 用于返回不同场景的老化模型个数。 |
| 模型类型     | 用于返回模型包的来源。      |

|    错误码 | 错误码解释          | 原因分析                       | 处理建议                 |
|-------:|:---------------|:---------------------------|:---------------------|
| 181001 | 下发的MML参数不正确。   | 非法的命令参数。                   | 请检查输入的命令参数或联系华为技术支持。 |
| 181002 | 系统内部错误，请联系管理员。 | 执行过程中可能存在网络故障或者服务不可用等异常因素。 | 等待几分钟后重试。            |
