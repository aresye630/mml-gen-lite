# 删除带宽管理业务（RMV BWMSERVICE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于删除带宽管理业务。当运营商希望删除已配置的带宽管理业务时，则执行该命令。

#### 注意事项

- 该命令执行后立即生效。
- 如果带宽管理业务正在被引用，则不允许删除。
- 如果不指定带宽管理业务名称，则删除所有的带宽管理业务。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                           |
|:---------------|:---------|:-----------------------------------------------------------------------------------------------|
| BWMSERVICENAME | 带宽控制业务名称 | 可选必选说明：可选参数 参数含义：该参数用于配置带宽管理业务的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

- 假如运营商需要删除名为“testbwmservice1”的带宽管理业务：

  ```
  RMV BWMSERVICE:BWMSERVICENAME="testbwmservice1";
  ```
- 假如运营商需要删除所有已配置的带宽管理业务：

  ```
  RMV BWMSERVICE:;
  ```
