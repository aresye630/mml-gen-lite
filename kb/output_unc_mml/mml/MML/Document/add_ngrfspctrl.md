# 增加指定RFSP的传递策略（ADD NGRFSPCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于对指定的用户（群）增加指定RFSP的传递策略。通过本配置，AMF可以对不同用户（群）使用差异化的RFSP传递策略。

## 注意事项

- 下一次移动性流程生效。

- 最多可输入128条记录。
- 对于指定的用户（群），匹配优先级从高到低依次为：“SPECIFIC\_IMSI(指定IMSI)”，“IMSI\_PREFIX(指定IMSI前缀)”，“FOREIGN\_USER(外网用户)”或“HOME\_USER(本网用户)”，“ALL\_USER(所有用户)”。
- 当SUBRANGE取值为“SPECIFIC\_IMSI(指定IMSI)”时，匹配用户的方式为全匹配。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称        | 参数说明                                                                                                                                                                                                          |
|:---------|:------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围        | 可选必选说明：必选参数  参数含义：该参数用于指定控制RFSP传递策略的用户范围。  数据来源：全网规划 取值范围： “ALL_USER（所有用户）”：所有用户。“HOME_USER（本网用户）”：本网用户。“FOREIGN_USER（外网用户）”：外网用户。“IMSI_PREFIX（IMSI前缀）”：IMSI前缀。“SPECIFIC_IMSI（指定IMSI）”：指定IMSI。  默认值：无  配置原则：无 |
| IMSIPRE  | IMSI前缀      | 可选必选说明：该参数在"SUBRANGE"配置为"IMSI_PREFIX"时为条件必选参数。  参数含义：该参数用于指定控制RFSP传递策略的用户的IMSI前缀。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是5~14。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                                          |
| IMSI     | IMSI        | 可选必选说明：该参数在"SUBRANGE"配置为"SPECIFIC_IMSI"时为条件必选参数。  参数含义：该参数用于指定控制RFSP传递策略的用户的IMSI。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是14~15。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                                         |
| RFSP     | RFSP        | 可选必选说明：必选参数  参数含义：该参数用于指定RFSP ID。  数据来源：全网规划  取值范围：整数类型，取值范围是1~256。  默认值：无  配置原则：无                                                                                                                            |
| NGSW     | 5GS之间是否传递   | 可选必选说明：可选参数  参数含义：该参数用于控制指定的RFSP ID是否在5GS之间传递。  数据来源：全网规划 取值范围： “YES（是）”：是“NO（否）”：否  默认值：无  配置原则：  如果需要在5GS之间传递指定的RFSP，需要将此参数设置为“YES”。                                                                        |
| IWKSW    | 5GS到EPS是否传递 | 可选必选说明：可选参数  参数含义：该参数用于控制指定的RFSP ID是否在5GS到EPS的流程中传递。  数据来源：全网规划 取值范围： “YES（是）”：是“NO（否）”：否  默认值：无  配置原则：  如果需要在5GS到EPS流程中传递指定的RFSP，需要将此参数设置为“YES”。                                                             |

## 使用实例

为IMSI前缀为12345的用户指定RFSP ID为3的传递策略，执行如下命令：

```
ADD NGRFSPCTRL: SUBRANGE=IMSI_PREFIX, IMSIPRE="12345", RFSP=3, NGSW=NO, IWKSW=YES;
```
