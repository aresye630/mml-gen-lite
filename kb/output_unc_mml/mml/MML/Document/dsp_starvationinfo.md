# 显示长时间未被调度的组件消息（DSP STARVATIONINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于在系统繁忙时，显示当前系统中10秒内未被调度的组件消息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称       | 参数说明                                                                                                                                                                                          |
|:----------------|:-----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RUNAME          | RU名称       | 可选必选说明：可选参数 参数含义：该参数用于表示RU名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：当不输入时显示所有的资源单元的信息。使用DSP RU查看RU名称。                                                                      |
| SHOWNUM         | 要查询的数据最大个数 | 可选必选说明：可选参数 参数含义：该参数用于表示每个资源能够显示的最大记录量。 数据来源：本端规划 取值范围：整数类型，取值范围为1～100。 默认值：20 配置原则：当不输入时，若是某个资源的实际数据量达到此参数的默认值，则显示的数据量为此参数默认值，否则按实际数据量显示。当输入某个值时，若是某个资源的实际数据量达到此参数值，则显示的数据量为此参数值，否则按实际数据量显示。 |
| BEGININDEX      | 记录起始位置     | 可选必选说明：可选参数 参数含义：该参数用于表示每个资源从第几条记录开始显示。 数据来源：本端规划 取值范围：整数类型，取值范围为0～99。 默认值：无 配置原则：当不输入时，从最新的数据开始显示，否则从指定的起始数据索引开始显示。                                                                          |
| SERVICEINSTANCE | 服务实例       | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。                                                                                  |

#### 使用实例

显示所有10秒内未被调度的组件消息：

```
DSP STARVATIONINFO:SERVICEINSTANCE="vnfc";
```
