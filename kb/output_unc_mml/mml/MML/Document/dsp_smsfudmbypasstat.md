# 显示SMSF用户UDM Bypass状态信息（DSP SMSFUDMBYPASSTAT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMSF**

该命令用于显示SMSF用户UDM Bypass状态信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                               |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------|
| QUERYOPT | 查询方式   | 可选必选说明：必选参数  参数含义：该参数用于表示查询SMSF用户UDM Bypass状态信息的方式。  数据来源：本端规划 取值范围： “SUPI（SUPI）”：用户的SUPI信息“GPSI（GPSI）”：用户的GPSI信息  默认值：无  配置原则：无   |
| SUPI     | SUPI   | 可选必选说明：该参数在"QUERYOPT"配置为"SUPI"时为条件可选参数。  参数含义：该参数用于指定用户的SUPI信息。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是5~15。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无 |
| GPSI     | GPSI   | 可选必选说明：该参数在"QUERYOPT"配置为"GPSI"时为条件可选参数。  参数含义：该参数用于指定用户的GPSI信息。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~15。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无 |

## 使用实例

当运营商希望查询SMSF用户UDM Bypass状态信息，执行如下命令：

```
DSP SMSFUDMBYPASSTAT: QUERYOPT=SUPI, SUPI="460023500100001";
```
