# 删除话单备份（RMV CDRBACKUP）

- 网管用户权限

- 使用实例

#### 命令功能

**须知** 

删除话单备份会导致话单不能传送到第三方服务器。

**适用NF：NCG**

该命令用于删除已添加的话单备份任务。

执行任务之前，可执行**LST CDRBACKUP**查询当前系统中需要删除的话单备份任务情况，找到对应的备份任务标识。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                         |
|:---------|:-------|:-----------------------------------------------------------------------------|
| BACKUPID | 备份任务标识 | 可选必选说明：必选参数 参数含义：备份任务标识，全局唯一。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：无 |

#### 使用实例

删除话单标识为“1st\_cdr\_backup”的话单备份任务，示例如下：

```
RMV CDRBACKUP: BACKUPID="1st_cdr_backup";
```
