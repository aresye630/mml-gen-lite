# 修改VSMF的Default QoS Flow配置（MOD VSMFDFTQOSCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用来修改V-SMF的Default QoS Flow配置。

## 注意事项

命令执行后只对新接入用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

将“移动国家码”为“460”，“移动网号”为“00”，控制类型为GLOBAL\_LEVEL的QoS配置修改为“ARP的优先级别”为“1”，“ARP的抢占能力”为NOT\_PREEMPT，“ARP的被抢占能力”为PREEMPTABLE。

```
MOD VSMFDFTQOSCTRL: MCC="460", MNC="00", CTRLTYPE=GLOBAL_LEVEL, ARPPL=1, ARPPCI=NOT_PREEMPT, ARPPVI=PREEMPTABLE;
```
