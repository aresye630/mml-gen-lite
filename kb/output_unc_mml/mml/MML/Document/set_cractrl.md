# 设置CRA控制参数（SET CRACTRL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于配置实时位置上报的开关及本地实时位置上报的Trigger。

#### 注意事项

- 该命令执行后只对新激活用户生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | CRARULE   | TAI     | ECGI    |
|:-------|:----------|:--------|:--------|
| 初始值    | PCRF      | DISABLE | DISABLE |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                     |
|:--------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CRARULE | CRA控制  | 可选必选说明：可选参数 参数含义：该参数用于配置Gx接口实时位置上报指示的来源。 数据来源：对端协商 取值范围：枚举类型。 PCRF：PCRF。LOCAL：LOCAL。COMBINE：COMBINE。 默认值：无 配置原则：无                                                        |
| TAI     | TAI    | 可选必选说明：条件可选参数 前提条件：该参数在“CRARULE”配置为“LOCAL” 或 “COMBINE”时为可选参数。 参数含义：该参数用于配置Change Reporting Action信元中是否开启TAI指示。 数据来源：全网规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无  |
| ECGI    | ECGI   | 可选必选说明：条件可选参数 前提条件：该参数在“CRARULE”配置为“LOCAL” 或 “COMBINE”时为可选参数。 参数含义：该参数用于配置Change Reporting Action信元中是否开启ECGI指示。 数据来源：全网规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无 |

#### 使用实例

如果希望Gx接口实时位置上报功能以本地配置为准，且本地配置TAI和ECGI都使能，则可以进行如下设置：

```
SET CRACtrl: CRARULE=LOCAL,TAI=ENABLE,ECGI=ENABLE;
```
