# 修改指定实例名称的UPF节点特征（MOD NGLANUPNODE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于5G LAN场景中修改指定UPF实例对应的UPF节点特征参数。

## 注意事项

该命令执行后只对新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                        |
|:---------------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCENAME | UPF实例名称   | 可选必选说明：必选参数  参数含义：该参数用于指定UPF实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~255。字符串类型，输入长度范围是0~255。不区分大小写。  默认值：无  配置原则：  本参数取值与ADD PNFPROFILE命令中的“NF实例标识”参数取值保持一致时，关联关系生效。                                                                                                                                                           |
| GROUPID        | 5G LAN组ID | 可选必选说明：必选参数  参数含义：该参数用于指定5G LAN组的ID。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是18~37。GROUPID以连字号分为4段，形式为GroupServiceID-MCC-MNC-LocalGroupID。其中，GroupServiceID长度为8，只能输入数字或者范围为A-F或a-f的字母；MCC长度为3，只能输入数字；MNC长度为2~3，只能输入数字；LocalGroupID长度为2~20的偶数，只能输入数字或者范围为A-F或a-f的字母。例如，A0000001-460-003-01，A0000001-460-003-A000000001。  默认值：无  配置原则：无 |
| N6SUPPORT      | 是否支持N6通信  | 可选必选说明：必选参数  参数含义：该参数用于标识UPF是否支持通过N6通信。  数据来源：本端规划 取值范围： “ENABLE（使能）”：UPF支持通过N6通信。“DISABLE（不使能）”：UPF不支持通过N6通信。  默认值：无  配置原则：  5G LAN特性支持N19通信时，一个层二的5G LAN组内最多只有一个UPF支持N6通信，需要将开关置为ENABLE。                                                                                                                                  |

## 使用实例

在指定组ID为“A0000001-460-003-A000000001”的5G LAN组内，为实例名称为“upf1”的UPF修改节点特征：

```
MOD NGLANUPNODE:NFINSTANCENAME="upf1",GROUPID="A0000001-460-003-A000000001", N6SUPPORT=ENABLE;
```
