# 显示网元故障重选信息（DSP AMFNFFAULTINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于显示AMF上保存的对端故障网元信息。在网络故障的场景下，通过本命令可以查询对端故障网元的实例ID信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识      | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                    |
|:----------|:-----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TASKTYPE  | 故障网元扫描任务类型 | 可选必选说明：必选参数  参数含义：该参数用于指定故障网元扫描任务类型。  数据来源：本端规划 取值范围： “AUSF（AUSF故障重选任务）”：AUSF故障重选任务“UDMIMME（UDM立即故障重选任务）”：UDM立即故障重选任务，AMF扫描到用户后立即为用户重选UDM“UDM（UDM故障重选任务）”：UDM故障重选任务，AMF随下一次注册流程为用户重选UDM“SMF（SMF故障重选任务）”：SMF故障重选任务“SMSF（SMSF故障重选任务）”：SMSF故障重选任务“PCF（PCF故障重选任务）”：PCF故障重选任务  默认值：无  配置原则：无 |
| QUERYTYPE | 查询类型       | 可选必选说明：可选参数  参数含义：该参数用于指定故障网元信息的查询类型。  数据来源：本端规划 取值范围： “SINGLEDS（指定编号为0的DS）”：默认返回编号为0的DS的故障网元实例ID。“ALLDS（全量DS）”：返回全量DS的故障网元实例ID。  默认值：无  配置原则：无                                                                                                                                         |
| POD       | POD ID     | 可选必选说明：该参数在"QUERYTYPE"配置为"ALLDS"时为条件可选参数。  参数含义：该参数用于指定AMF业务服务的POD ID。POD ID可以通过执行DSP MSPROCESS命令，将PROCNAME参数置为"CELL_AM"，从结果报文的Process ID字段中查询获取。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~255。  默认值：无  配置原则：无                                                                                   |

## 使用实例

- 查询AMF业务编号0上保存的对端故障UDM信息。执行如下命令：

  ```
  %%DSP AMFNFFAULTINFO: TASKTYPE=UDM, QUERYTYPE=SINGLEDS;%%
  RETCODE = 0  操作成功

  结果如下
  --------
             POD ID  =  usnpod-0
  AMF业务服务的编号  =  0
       故障网元信息  =  |00000000-0000-0000-0000-000000000002+1970-01-01T08:00:00+08:00|
  (结果个数 = 1) 

  ---    END
  ```
- 查询USN-POD 0上保存的对端故障UDM信息。执行如下命令：

  ```
  %%DSP AMFNFFAULTINFO: TASKTYPE=UDM, QUERYTYPE=ALLDS, POD="usnpod-0";%%
  RETCODE = 0  操作成功

  结果如下
  --------
  POD ID    AMF业务服务的编号  故障网元信息

  usnpod-0  0                  |00000000-0000-0000-0000-000000000002+1970-01-01T08:00:00+08:00|
  usnpod-0  1                  |00000000-0000-0000-0000-000000000002+1970-01-01T08:00:00+08:00|
  (结果个数 = 2)

  ---    END
  ```

## 输出结果说明

| 输出项名称      | 输出项解释                                                                                                                                                                                       |
|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| POD ID     | 该参数用于指定AMF业务服务的POD ID。POD ID可以通过执行DSP MSPROCESS命令，将PROCNAME参数置为"CELL_AM"，从结果报文的Process ID字段中查询获取。                                                                                           |
| AMF业务服务的编号 | 该参数用户标识AMF业务服务的编号。                                                                                                                                                                          |
| 故障网元信息     | 该参数用于显示故障网元信息。故障信息由实例ID和故障时间组成，使用“+”号连接，不同网元信息之间使用“|”号分隔，如：|00000000-0000-0000-0000-000000000001+1970-01-01T08:00:00+08:00|00000000-0000-0000-0000-000000000002+1970-01-01T08:00:00+08:00|。 |
