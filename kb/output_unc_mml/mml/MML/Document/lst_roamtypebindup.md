# 查询UPF与用户漫游类型的绑定关系（LST ROAMTYPEBINDUP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：GGSN、SGW-C、PGW-C、SMF**

该命令用于查询UPF与用户漫游类型的绑定关系，对非ULCL场景生效。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识           | 参数名称    | 参数说明                                                                                                                                            |
|:---------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------|
| ROAMINGTYPE    | 用户漫游类型  | 可选必选说明：可选参数  参数含义：该参数用于指定用户漫游类型。  数据来源：全网规划 取值范围： “INBOUND（漫入）”：对于漫入用户，使用绑定UPF过滤接入UPF列表。“OUTBOUND（漫出）”：对于漫出用户，使用绑定UPF过滤主锚点UPF列表。  默认值：无  配置原则：无 |
| NFINSTANCENAME | UPF实例名称 | 可选必选说明：可选参数  参数含义：该参数用于指定UPF实例名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。不区分大小写。  默认值：无  配置原则：无                                                    |

## 使用实例

显示UPF与用户漫游类型的绑定关系：
LST ROAMTYPEBINDUP:;

```
%%LST ROAMTYPEBINDUP:;%%
RETCODE = 0  操作成功。

结果如下
------------------------
用户漫游类型         UPF实例名称     

漫入                 UPF1
漫出                 UPF2
(结果个数 = 2)
```

## 输出结果说明

| 输出项名称   | 输出项解释           |
|:--------|:----------------|
| 用户漫游类型  | 该参数用于指定用户漫游类型。  |
| UPF实例名称 | 该参数用于指定UPF实例名称。 |
