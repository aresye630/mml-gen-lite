# 设置网关Proxy功能（SET GWPROXYFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、GGSN**

该命令用于设置网关Proxy功能配置。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| PROXYSW   |   RECOVERY |
|:----------|-----------:|
| DISABLE   |          0 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称      | 参数说明                                                                                                                                                                                                 |
|:---------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROXYSW  | Proxy功能开关 | 可选必选说明：可选参数  参数含义：该参数用于控制是否打开网关Proxy功能。  数据来源：本端规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST GWPROXYFUNC查询当前参数配置值。  配置原则：无                                               |
| RECOVERY | 重启计数器     | 可选必选说明：可选参数  参数含义：该参数用于控制Proxy GGSN/PGW在转发用户激活请求消息时将消息中的Recovery信元替换成本参数设置的值。该参数也适用于Echo消息。  数据来源：全网规划  取值范围：整数类型，取值范围是0~255。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST GWPROXYFUNC查询当前参数配置值。  配置原则：无 |

## 使用实例

打开网关proxy功能，并且设置重启计数器值为1：

```
SET GWPROXYFUNC:PROXYSW=ENABLE,RECOVERY=1;
```
