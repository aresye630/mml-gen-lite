# 删除费率组信息（RMV RGINFO）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：NCG**

该命令用于删除已添加的话单费率组。

执行任务之前，可执行**LST RGINFO**命令查询当前系统中的费率组信息，找到对应的费率组ID。

#### 注意事项

删除费率组信息，可能会导致以费率组ID为对象的流量统计信息不全。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                    |
|:-------|:-------|:----------------------------------------------------------------------------------------|
| RGID   | 费率组ID  | 可选必选说明：必选参数 参数含义：该参数用于表示用户话单所属的费率组。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无 配置原则：无 |

#### 使用实例

删除ID为“33”的费率组：

```
RMV RGINFO: RGID=33;
```
