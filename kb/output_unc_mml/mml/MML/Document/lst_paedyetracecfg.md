# 查询PAE染色流控开关及阈值参数（LST PAEDYETRACECFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询PAE染色跟踪流控开关及阈值参数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询PAE染色跟踪流控开关及阈值参数：

```
%%LST PAEDYETRACECFG:;%%
RETCODE = 0  操作成功

结果如下
------------------------
                  全流控开关  =  开
        起控阈值X86 (千分比)  =  880
        停控阈值X86 (千分比)  =  800
        起控阈值ARM (千分比)  =  1000
        停控阈值ARM (千分比)  =  900
染色消耗CPU比例阈值 (千分比)  =  40
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称             | 输出项解释                   |
|:------------------|:------------------------|
| 全流控开关             | 染色跟踪全流控开关。              |
| 起控阈值X86 (千分比)     | X86染色跟踪开启流控的阈值，千分比形式。   |
| 停控阈值X86 (千分比)     | X86染色跟踪停止流控的阈值，千分比形式。   |
| 起控阈值ARM (千分比)     | ARM染色跟踪开启流控的阈值，千分比形式。   |
| 停控阈值ARM (千分比)     | ARM染色跟踪停止流控的阈值，千分比形式。   |
| 染色消耗CPU比例阈值 (千分比) | 染色跟踪部分流控中染色模块消耗CPU比例阈值。 |
