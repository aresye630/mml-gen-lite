# 增加IPv6下一跳设置（ADD APPLYIPV6NEXTHOP）

- 操作用户权限

#### 命令功能

该命令用于设置基于IPv6信息的路由下一跳。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为65535。
- 配置该命令前，必须已经通过ADD ROUTEPOLICY配置了指定路由策略的名字以及通过ADD ROUTEPOLICYNODE配置了该策略下的节点。
- 当参数ISPEERADDRESS配置为TRUE时，不能配置参数IPV6NEXTHOP、NEXTHOPTYPE和IFNAME。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称       | 参数说明                                                                                                                                                     |
|:--------------|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------|
| POLICYNAME    | 路由策略名字     | 可选必选说明：必选参数 参数含义：该参数用于指定路由策略名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无 配置原则：不支持输入空格。                                                                   |
| NODESEQUENCE  | 路由策略节点号    | 可选必选说明：必选参数 参数含义：该参数用于指定路由策略节点号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无 配置原则：无                                                                          |
| ISPEERADDRESS | 是否是对等体IP地址 | 可选必选说明：必选参数 参数含义：该参数用于指定是否是对等体IP地址。 数据来源：本端规划 取值范围：枚举类型。 FALSE：否。TRUE：是。 默认值：无 配置原则：无                                                                    |
| NEXTHOPTYPE   | 下一跳类型      | 可选必选说明：可选参数 前提条件：该参数在“ISPEERADDRESS”配置为“FALSE”时为可选参数。 参数含义：该参数用于指定应用下一跳的类型。 数据来源：本端规划 取值范围：枚举类型。 ipaddress：下一跳类型为IP地址。interface：下一跳类型为接口名称。 默认值：无 配置原则：无 |
| IPV6NEXTHOP   | 下一跳地址      | 可选必选说明：条件必选参数 前提条件： 该参数在“ISPEERADDRESS”配置为“FALSE”且“NEXTHOPTYPE”不为“interface”时为必选参数。 参数含义：该参数用于指定下一跳IPv6地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无 配置原则：无         |
| IFNAME        | 接口名称       | 可选必选说明：条件必选参数 前提条件：该参数在“NEXTHOPTYPE”配置为“interface”时为必选参数。 参数含义：该参数用于指定接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无                               |

#### 使用实例

路由策略a节点10，添加设置下一跳为2001:DB8::：

```
ADD APPLYIPV6NEXTHOP:POLICYNAME="a",NODESEQUENCE=10,ISPEERADDRESS=FALSE,IPV6NEXTHOP="2001:DB8::";
```

#### 参考信息

为实现路由策略，首先定义将要实施路由策略的路由特征，即定义一组匹配规则和设置规则，然后将它们应用于路由的发布、接收和引入等过程的路由策略中。
