# 查询禁止访问NCG的CTF实例（LST INHCTF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NCG**

该命令用于查询禁止访问NCG的CTF实例。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                                                                                             |
|:--------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCEID  | NF实例标识 | 可选必选说明：可选参数  参数含义：该参数表示指定禁止访问NCG的CTF实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~40。该参数只能由字母（A-Z或者a-z）、数字（0-9）、中划线（-）组成。  默认值：无  配置原则：无                                                                                                                                 |
| IPADDRESSTYPE | IP地址类型 | 可选必选说明：可选参数  参数含义：该参数用于指定CTF的IP地址类型。  数据来源：本端规划 取值范围： IPV4（IPv4地址）IPV6（IPv6地址）  默认值：无  配置原则：无                                                                                                                                                                    |
| IPV4ADDRESS   | IPv4地址 | 可选必选说明：该参数在"IPADDRESSTYPE"配置为"IPV4"时为条件必选参数。  参数含义：该参数用于指定IPv4类型地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：  IPv4地址和IPv6地址至少配置一个。                                                                                                                               |
| IPV6ADDRESS   | IPv6地址 | 可选必选说明：该参数在"IPADDRESSTYPE"配置为"IPV6"时为条件必选参数。  参数含义：该参数用于指定IPv6类型地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：  IPv4地址和IPv6地址至少配置一个。                                                                                                                               |
| CHRSP         | 计费响应   | 可选必选说明：可选参数  参数含义：该参数用于指定接收被禁止CTF的计费请求消息时，NCG如何响应。  数据来源：全网规划 取值范围： “TooManyRequest_429（请求过多）”：NCG收到被禁止的CTF的计费请求后直接回复响应消息，错误码为429。“ServiceUnavailable_503（服务不可用）”：NCG收到被禁止的CTF的计费请求后直接回复响应消息，错误码为503。“NoResponse（无响应）”：NCG收到被禁止的CTF的计费请求后直接将消息丢弃。  默认值：无  配置原则：无 |

## 使用实例

查询所有禁止访问NCG的CTF实例。

```
LST INHCTF:;
%%LST INHCTF:;%%
RETCODE = 0  操作成功

结果如下
------------------------
   NF实例标识  =  nfinstanceid001
   IP地址类型  =  IPv4地址
     IPv4地址  =  192.168.100.1
     IPv6地址  =  ::
     计费响应  =  请求过多
(结果个数 = 1)

---    END
```
