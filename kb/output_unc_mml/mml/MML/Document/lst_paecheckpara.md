# 查询PAE寻呼反压流控检测参数(LST PAECHECKPARA)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：MME、AMF**

该命令用于查询LINK节点相关资源过载检测参数，包括link-pod内pBuf资源和PAE与虚拟交换机间消息发送队列所使用的检测周期、检测次数等信息。

#### 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无

#### 使用实例

查询PAE寻呼反压流控检测参数：

```
%%LST PAECHECKPARA:;%%
RETCODE = 0  操作成功

操作结果如下
------------------------ 
检测间隔（s）  =  1
检测次数       =  5
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见SET PAECHECKPARA的参数说明。
