# 修改过滤组（MOD FILTERGP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

此命令用于修改由过滤组ID指定的过滤组的过滤组名称。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                       |
|:-------------|:-------|:-------------------------------------------------------------------------------------------|
| FILTERGPID   | 过滤组ID  | 可选必选说明：必选参数  参数含义：该参数用于指定过滤组唯一标识。  数据来源：本端规划  取值范围：整数类型，取值范围是0~1023。  默认值：无  配置原则：无        |
| FILTERGPNAME | 过滤组名   | 可选必选说明：可选参数  参数含义：该参数用于指定过滤组的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~100。区分大小写。  默认值：无  配置原则：无 |

## 使用实例

修改由过滤组ID为1的过滤组的名称：

```
MOD FILTERGP:FILTERGPID=1,FILTERGPNAME="UPFILTERNAME";
```
