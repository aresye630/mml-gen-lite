# 查询关口局NF信息（LST NRFPLMNNF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NRF**

该命令用于查询本NRF管理的关口局NF。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                            |
|:-------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFTYPE       | NF类型   | 可选必选说明：可选参数  参数含义：该参数用于表示目的NF类型。  数据来源：全网规划 取值范围： NRF（NRF）UDM（UDM）AMF（AMF）SMF（SMF）AUSF（AUSF）NEF（NEF）PCF（PCF）SMSF（SMSF）NSSF（NSSF）UDR（UDR）LMF（LMF）GMLC（GMLC）EIR_5G（EIR_5G）SEPP（SEPP）UPF（UPF）N3IWF（N3IWF）AF（AF）UDSF（UDSF）BSF（BSF）CHF（CHF）NWDAF（NWDAF）CUSTOM_OCS（CUSTOM_OCS）SCP（SCP）  默认值：无  配置原则：无 |
| NFINSTANCEID | NF实例标识 | 可选必选说明：可选参数  参数含义：该参数用于表示本NRF管理的关口局NF实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~36。该参数只能由字母（A-Z或者a-z）、数字（0-9）、中划线（-）、星号（*）组成，不区分大小写。  默认值：无  配置原则：  支持统配ID，通配ID为“*”，表示该NRF下所有的NF均为关口局NF。                                                                                                             |
| NFNAME       | NF名称   | 可选必选说明：可选参数  参数含义：该参数用于表示本NRF管理的关口局NF名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~64。  默认值：无  配置原则：无                                                                                                                                                                                                     |

## 使用实例

使用以下命令查询关口局NF信息：

```
%%LST NRFPLMNNF:;%%
RETCODE = 0  操作成功

结果如下
--------
    NF类型  =  SMF
NF实例标识  =  123e4567-e89b-12d3-a456-426655440000
    NF名称  =  superom11-v6
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                    |
|:--------|:-------------------------|
| NF类型    | 该参数用于表示目的NF类型。           |
| NF实例标识  | 该参数用于表示本NRF管理的关口局NF实例标识。 |
| NF名称    | 该参数用于表示本NRF管理的关口局NF名称。   |
