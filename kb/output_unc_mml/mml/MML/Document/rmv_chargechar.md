# 删除对本地用户、漫游用户、拜访用户所采用的计费属性（RMV CHARGECHAR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

该命令用来删除计费属性。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                    |
|:-------|:-------|:------------------------------------------------------------------------|
| CCNAME | 计费属性名称 | 可选必选说明：必选参数 参数含义：计费属性名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无 |

#### 使用实例

删除计费属性名称为“cc”的所有配置信息：

```
RMV CHARGECHAR:CCNAME="cc";
```
