# 修改NSE和属性模板的关联(MOD GBNSEGRP)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

此命令用于修改NSE和属性模板的关联，通过属性模板制定NSE的属性。

#### 注意事项

此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称         | 参数说明                                                                                                 |
|:----------|:-------------|:-----------------------------------------------------------------------------------------------------|
| GRPINDEX  | 关联索引         | 可选必选说明：必选参数 参数含义：该参数用于指定待修改的关联索引 。 数据来源：整网规划 取值范围：0～65535 默认值：无                                      |
| NSEIBGN   | 起始NSEI       | 可选必选说明：可选参数 参数含义：该参数用于指定修改后关联的起始NSEI。 数据来源：整网规划 取值范围：0～65535 默认值：无                                   |
| NSEIEND   | 结束NSEI       | 可选必选说明：可选参数 参数含义：该参数用于指定修改后关联的结束NSEI。 数据来源：整网规划 取值范围：0～65535 默认值：无                                   |
| PARAINDEX | 关联的NSE属性模板索引 | 可选必选说明：可选参数 参数含义：该参数用于指定修改后关联的NSE属性模板索引。 前提条件：该参数已在ADD GBNSECFGPARA中添加。 数据来源：整网规划 取值范围：0～65535 默认值：无 |
| DESC      | 描述信息         | 可选必选说明：可选参数 参数含义：该参数用于指定修改后关联的描述信息。 数据来源：整网规划 取值范围：1～33位字符串 默认值：无                                    |

#### 使用实例

修改一组“关联索引”为“0”的NSE到属性模板的关联，且“起始NSEI ”改为“2”，“结束NSEI ”改为“5”：

MOD GBNSEGRP: GRPINDEX=0, NSEIBGN=2, NSEIEND=5;
