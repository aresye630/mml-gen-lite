# 设置系统定时器（SET SYSTIMER）

#### 命令功能

**适用NF：NCG**

该命令用于设置NCG的系统定时器时长。其中系统定时器包括统计2G/3G的PDP信息老化定时器、统计4G的Bearer信息老化定时器。对超过定时器时长的信息执行老化操作，防止无用数据对统计准确性的干扰。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为2。
- 定时器时长的单位为分钟。
- 该命令存在系统初始设置记录，参数的初始设置值如下表：

| TIMERNAME           |   OUTTIME |
|:--------------------|----------:|
| PDPs_Aging_Timer    |        30 |
| Bearers_Aging_Timer |        75 |

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称      | 参数说明                                                                                                                                                                                                                                                                         |
|:----------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TIMERNAME | 定时器名称     | 可选必选说明：必选参数 参数含义：选择设置时长的定时器标识。 数据来源：本端规划 取值范围：枚举类型。 PDPs_Aging_Timer：统计2G/3G的PDP信息老化定时器。Bearers_Aging_Timer：统计4G的Bearer信息老化定时器。5G_Bearers_Aging_Timer：统计5G的Bearer信息老化定时器。 默认值：无 配置原则：无                                                                                       |
| OUTTIME   | 定时器时长(分钟) | 可选必选说明：条件可选参数 前提条件：该参数在“TIMERNAME”配置为“PDPs_Aging_Timer” 或 “Bearers_Aging_Timer”时为条件可选参数。 参数含义：系统定时器时长，单位为分钟。 数据来源：本端规划 取值范围：整数类型，取值范围为1～35790。 默认值：无 配置原则： 对于“PDPs_Aging_Timer(统计2G/3G的PDP信息老化定时器)”，默认的定时器时长为30分钟。对于“Bearers_Aging_Timer(统计4G的Bearer信息老化定时器)”，默认的定时器时长为75分钟。 |

#### 使用实例

设置NCG的“定时器名称”为“PDPs\_Aging\_Timer(统计2G/3G的PDP信息老化定时器)”，“定时器时长(分钟)”为“8888”：

```
SET SYSTIMER: TIMERNAME=PDPs_Aging_Timer, OUTTIME=8888;
```
