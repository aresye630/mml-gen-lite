# 增加TAI组性能统计对象（ADD PERFTAIGROUP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C、SMF**

该命令用于增加TAI组性能统计对象的配置。

## 注意事项

- 该命令执行后立即生效。

- 本命令实际允许配置的记录数同时受网管能力约束。如果有疑问，请联系华为技术支持。

- 最多可输入3000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                            |
|:-------------|:-------|:----------------------------------------------------------------------------------------------------------------|
| TAIGROUPNAME | TAI组名  | 可选必选说明：必选参数  参数含义：该参数用于指定TAI组的性能统计名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~255。不区分大小写，不支持空格及“\”且全局唯一。  默认值：无  配置原则：无 |

## 使用实例

当需要添加一个组名为"huawei"的TAI组对象，执行如下命令：

```
ADD PERFTAIGROUP: TAIGROUPNAME="huawei";
```
