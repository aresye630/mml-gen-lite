# 删除SMSF本局信令点(RMV SMSFOPC)

- 命令功能
- 注意事项
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SMSF**

该命令用于删除SMSFOPC本局信令点指定配置。

#### 注意事项

- 该命令执行后立即生效。
- 删除该记录会导致SMSF业务失败。

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                  |
|:-------|:----------|:----------------------------------------------------------------------|
| OPX    | SMSF信令点索引 | 可选必选说明：必选参数 参数含义：该参数用于指定SMSF本局信令点索引。 数据来源：本端规划 取值范围：1～10 默认值：无 配置原则：无 |

#### 使用实例

删除SMSF信令点索引为1的SMSFOPC信令点。

```
RMV SMSFOPC: OPX=1;
```
