#### 命令功能

**适用网元：SGSN、MME、SMSF**

该命令用于查询M3UA信令路由状态，M3UA信令路由信息描述了从本地实体出发去往其它目的实体的信令路由。

#### 注意事项

系统会自行选取可用的信令进程（SPP/SGP），因此，执行该操作的时候要确保系统中有可用的信令进程。否则，操作将不能正常执行。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                     |
|:-------|:-------|:-------------------------------------------------------------------------|
| RUNAME | RU名称   | 可选必选说明：可选参数 参数含义：该参数用于指定SPU资源单元名称。该参数可以通过DSP RU命令查询。 取值范围：1~63位字符串 默认值：无 |
| PT     | 进程类型   | 可选必选说明：可选参数 参数含义：该参数用于指定进程的进程类型。 取值范围： “SPP(SPP)”“SGP(SGP)” 默认值：无        |
| PN     | 进程号    | 可选必选说明：可选参数 参数含义：该参数用于指定进程号。 取值范围：0~11 默认值：无                             |
| RTX    | 路由索引   | 可选必选说明：可选参数 参数含义：该参数用于指定准备查询的路由的索引。 取值范围：0~1279 默认值：无                    |
| DEX    | 目的实体索引 | 可选必选说明：可选参数 参数含义：该参数用于指定该M3UA路由的目的实体。 取值范围：0~1279 默认值：无                  |
| LSX    | 链路集索引  | 可选必选说明：可选参数 参数含义：该参数用于指定到达该的目的实体的M3UA链路集。 取值范围：0~1279 默认值：无              |
| RTN    | 信令路由名  | 可选必选说明：可选参数 参数含义：该参数用于指定M3UA路由名称，标识M3UA路由。 取值范围：长度不超过32的字符串 默认值：无        |

#### 使用实例

查询路由索引为0的M3UA信令路由状态：

DSP M3RT: RTX=0;

```
%%DSP M3RT: RTX=0;%%
RETCODE = 0  操作成功。

查询M3UA路由状态
----------------
         路由索引  =  0
     目的实体索引  =  0
       链路集索引  =  0
         路由状态  =  不可用
SG和SEP间路由禁止  =  否
SG和SEP间路由受限  =  否
     链路集不可用  =  是
              SLS  =  NULL
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称       | 输出项解释                                                                                     |
|:------------|:------------------------------------------------------------------------------------------|
| 路由索引        | 准备查询的路由的索引。                                                                               |
| 目的实体索引      | 该M3UA路由的目的实体。                                                                             |
| 链路集索引       | 到达该的目的实体的M3UA链路集。                                                                         |
| 路由状态        | 指定M3UA路由的当前状态，有可用、不可用两种状态。正常情况下为可用。 取值说明：“可用”“不可用”  说明： 路由不可用时，参考ALM-10336 M3UA路由不可用进行处理。 |
| SG和SEP间路由禁止 | SG和SEP间路由是否禁止，有是、否两种状态。正常情况下应该为否。 取值说明：“否”“是”                                             |
| SG和SEP间路由受限 | SG和SEP间路由是否受限，有是、否两种状态。正常情况下应该为否。 取值说明：“否”“是”                                             |
| 链路集不可用      | 指定M3UA路由对应的链路集是否可用，有是、否两种状态。正常情况下应该为否。取值说明：“否”“是”                                         |
| SLS         | 信令链路选择码，有数值、NULL两种状态。正常情况下应该为有效数值，该数值与链路的负荷分担情况相关。路由不可用时为NULL。                            |
