# 修改MAP协议接口兼容性IMSI号段配置(MOD MAPCMPTBYIMSI)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用于修改MAP协议接口兼容性IMSI号段配置。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称             | 参数说明                                                                                                                                                                                                 |
|:---------|:-----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围             | 可选必选说明：必选参数 参数含义：该参数用于指定MAP兼容性参数策略的用户范围。 数据来源：全网规划 取值范围：“ALL_USER(所有用户)”“FOREIGN_USER(外网用户)”“HOME_USER(本网用户)”“IMSI_PREFIX(指定IMSI前缀)” 默认值：无                                                           |
| NOID     | 运营商标识            | 可选必选说明：条件必选参数 参数含义：该参数用于指定运营商标识。 前提条件：该参数在“用户范围”参数配置为“FOREIGN_USER(外网用户)”或“HOME_USER(本网用户)”后生效。 数据来源：全网规划 取值范围：0～64，128～254 默认值：无                                                                    |
| IMSIPRE  | IMSI前缀           | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI前缀。 前提条件：该参数在“用户范围”参数配置为“IMSI_PREFIX(指定IMSI前缀)”后生效。 数据来源：全网规划 取值范围：1～15位十进制数字字符串。 默认值：无                                                                                |
| SF       | 特性列表             | 可选必选说明：可选参数 参数含义：该参数表示SGSN给HLR发送的Update Location Request消息中的Supported-Features信元中设置的比特位，每个比特位表示SGSN支持的一种功能（目前仅支持第39比特“支持DCNR”），详细说明请参照3GPP 29.002。 数据来源：全网规划 取值范围：“NR_AS_SECONDARY_RAT(支持双连接)” 默认值：无 |
| NODCNR   | 未签约DCNR是否支持高速用户面 | 可选必选说明：可选参数 参数含义：该参数用于控制是否支持选择高速用户面。 数据来源：全网规划 取值范围：“NO（否）”“YES（是）” 默认值：无                                                                                                                            |

#### 使用实例

配置方式：修改一条“用户范围”为“ALL\_USER(所有用户)”“未签约DCNR是否支持高速用户面”为“NO（否）”的记录。

MOD MAPCMPTBYIMSI: SUBRANGE=ALL\_USER, NODCNR=NO;
