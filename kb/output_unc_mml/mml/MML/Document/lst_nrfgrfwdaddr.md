# 查询备份NRF地址（LST NRFGRFWDADDR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NRF**

查询备份NRF地址。

## 注意事项

仅供调测使用。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识          | 参数名称      | 参数说明                                                                                                     |
|:--------------|:----------|:---------------------------------------------------------------------------------------------------------|
| PEERNRFNAME   | 备份NRF名称   | 可选必选说明：可选参数  参数含义：该参数表示对端NRF名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~64。  默认值：无  配置原则：无                       |
| IPTYPE        | IP类型      | 可选必选说明：可选参数  参数含义：该参数表示对端NRF地址的IP类型。  数据来源：本端规划 取值范围： IPV4（IPv4地址）IPV6（IPv6地址）  默认值：无  配置原则：无            |
| IPV4          | IPV4地址    | 可选必选说明：该参数在"IPTYPE"配置为"IPV4"时为条件必选参数。  参数含义：该参数表示对端NRF的IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无 |
| IPV6          | IPV6地址    | 可选必选说明：该参数在"IPTYPE"配置为"IPV6"时为条件必选参数。  参数含义：该参数表示对端NRF的IPv6地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无 |
| PORT          | 端口        | 可选必选说明：可选参数  参数含义：该参数表示对端NRF地址所对应的端口号。  数据来源：本端规划  取值范围：整数类型，取值范围是0~65535。  默认值：无  配置原则：无                |
| PEERNRFINSTID | 备份NRF实例标识 | 可选必选说明：可选参数  参数含义：该参数表示备份NRF实例标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~40。  默认值：无  配置原则：无                     |
| TLS           | 是否支持TLS   | 可选必选说明：可选参数  参数含义：该参数用于指定NRF是否支持TLS。  数据来源：本端规划  取值范围： TRUE(TRUE)FALSE(FALSE)  默认值：无  配置原则：无             |

## 使用实例

- 查询备份NRF名称peernrfname01，IPTYPE为IPV4的NRF备份地址信息。

  ```
  LST NRFGRFWDADDR:PEERNRFNAME="peernrfname01", IPTYPE=IPV4;
  %%LST NRFGRFWDADDR:PEERNRFNAME="peernrfname01", IPTYPE=IPV4;%%
  RETCODE = 0  执行成功

  结果如下
  ------------------------
      对端NRF名称  =  peernrfname01
           IP类型  =  IPv4地址
         IPV4地址  =  192.168.16.2
         IPV6地址  =  ::
  对端NRF实例标识  =  123e4567-e89b-12d3-a456-426655440000
             端口  =  12345
      是否支持TLS  =  TRUE
  (结果个数 = 1)
  ```
- 查询所有的NRF备份地址信息。

  ```
  LST NRFGRFWDADDR:;
  %%LST NRFGRFWDADDR:;%%
  RETCODE = 0  执行成功

  结果如下
  ------------------------ 
  对端NRF名称    IP类型        IPV4地址       IPV6地址      端口         对端NRF实例标识                       是否支持TLS
  peernrfname01  IPv4地址      192.168.16.2   ::            12345        123e4567-e89b-12d3-a456-426655440000  FALSE
  peernrfname02  IPv4地址      192.168.16.11  ::            23456        123e4567-e89b-12d3-a456-426655440011  TRUE
  peernrfname02  IPv6地址      0.0.0.0        fc00::0001    12345        123e4567-e89b-12d3-a456-426655660000  TRUE
  (结果个数 = 3)
  ```

| IP类型      | 该参数表示对端NRF地址的IP类型。   |
| IPV4地址    | 该参数表示对端NRF的IPv4地址。   |
| IPV6地址    | 该参数表示对端NRF的IPv6地址。   |
| 端口        | 该参数表示对端NRF地址所对应的端口号。 |
| 备份NRF实例标识 | 该参数表示备份NRF实例标识。      |
| 是否支持TLS   | 该参数用于指定NRF是否支持TLS。   |
