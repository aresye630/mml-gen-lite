#### 命令功能

**须知** 

功能开启后，如果已接入基站的TAC不在规划范围内，基站断链后将无法再次接入，导致业务受损。

**适用网元：MME**

此命令用于配置4G基站接入控制参数，根据基站所在的TAC区域，控制是否允许基站接入。

该命令的使用场景：当运营商希望只允许在白名单TAC区的基站接入时，可使用该命令开启对应功能。

#### 注意事项

- 该命令执行后立即生效。

- 功能开启前，需要提前规划好允许基站接入的TAC全集，并通过**ADD S1RANTAGP**、**ADD S1RANTAGPMEM**进行配置。
- 功能开启前，需要对已接入基站的TAC进行检查，确认是否在规划范围内，避免功能开启后，已接入的基站断链后无法再次接入，导致业务受损。
- 功能开启后，MME对于不满足TAC区域规划且已接入的基站不主动断链，在基站下次建链时进行限制。
- 基站建链消息中携带的任意一个TAC只要在配置范围内则允许建链。

#### 本地用户权限

manage-ug；system-ug；

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；

#### 参数说明

| 参数标识        | 参数名称          | 参数说明                                                                                                                                                                                |
|:------------|:--------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| S1RANACCSW  | 基于位置区基站接入限制开关 | 可选必选说明：可选参数 参数含义：是否开启基于位置区基站接入限制功能。 数据来源：本端规划 取值范围：“ON（开启）”“OFF（关闭）” 默认值：无 系统初始设置值：“OFF（关闭）” 配置原则： 当运营商希望只允许指定TAC区（通过ADD S1RANTAGP、ADD S1RANTAGPMEM进行配置）的基站与MME建链时，将本参数设置为“ON（开启）”。 |
| S1RANTAGPID | 跟踪区群组标识       | 可选必选说明：条件必选参数 参数含义：该参数用于指定跟踪区群组标识，该参数需在ADD S1RANTAGP中配置。 前提条件：该参数在“基于位置区基站接入限制开关”参数设置为“ON（开启）”时生效。 数据来源：本端规划 取值范围：整数类型，取值范围是1~256。 默认值：无 系统初始设置值：0 配置原则： 该参数需在ADD S1RANTAGP中配置。     |

#### 使用实例

运营商希望只允许TAC组ID为1的基站接入MME，可执行如下命令。

```
SET S1RANACCCTRL: S1RANACCSW=ON, S1RANTAGPID=1;
```
