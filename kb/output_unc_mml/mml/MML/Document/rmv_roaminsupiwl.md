# 删除漫入场景SUPI白名单（RMV ROAMINSUPIWL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于删除漫入场景SUPI白名单。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                             |
|:---------|:--------|:---------------------------------------------------------------------------------|
| SEGSTART | 号段起始字符串 | 可选必选说明：必选参数  参数含义：该参数用于表示号段的起始号码。  数据来源：本端规划  取值范围：字符串类型，输入长度是15。  默认值：无  配置原则：无 |
| SEGEND   | 号段结束字符串 | 可选必选说明：必选参数  参数含义：该参数用于表示号段的结束号码。  数据来源：本端规划  取值范围：字符串类型，输入长度是15。  默认值：无  配置原则：无 |

## 使用实例

删除漫入场景SUPI白名单，号段起始字符串123456789876501，号段结束字符串123456789876505：

```
RMV ROAMINSUPIWL: SEGSTART="123456789876501", SEGEND="123456789876505";
```
