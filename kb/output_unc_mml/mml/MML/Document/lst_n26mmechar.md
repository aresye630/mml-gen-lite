# 查询N26接口MME属性（LST N26MMECHAR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询N26接口对端MME的属性信息。

## 注意事项

网段完全重叠的记录不能重复下发，网段有包含关系的记录可以同时下发。如果对端MME的IP与多个记录的网段都匹配，产品选择掩码最长的记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称          | 参数说明                                                                                                                                                                                                                    |
|:-------|:--------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RANGE  | 对端设备范围        | 可选必选说明：可选参数  参数含义：该参数用于指示对端MME设备范围。  数据来源：全网规划 取值范围： “ALL_MME（所有MME）”：所有MME“SPECIAL_MME（指定MME）”：指定MME“COMB_MME（UAMF融合MME）”：UAMF融合MME  默认值：无  配置原则：  系统开工时缺省增加了“所有MME”的记录，ADD命令中就不需要增加“所有MME”的记录。                        |
| IPTYPE | IP地址类型        | 可选必选说明：该参数在"RANGE"配置为"SPECIAL_MME"时为条件可选参数。  参数含义：该参数用于指定对端MME的信令面IP地址类型。  数据来源：全网规划 取值范围： “IPV4（IPv4）”：IPv4“IPV6（IPv6）”：IPv6  默认值：无  配置原则：无                                                                            |
| IPV4   | MME IPv4信令面地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPV4"时为条件可选参数。  参数含义：该参数用于指定对端MME的信令面IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：  有效的IPv4地址必须是A、B或者C类地址，且不能为环回地址（127.x.y.z）。                                                                |
| MASKV4 | IPv4掩码        | 可选必选说明：该参数在"IPTYPE"配置为"IPV4"时为条件可选参数。  参数含义：该参数用于指定对端MME的信令面IPv4地址的掩码。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：  输入的掩码要求对应的二进制值1和1之间不允许存在0。例如：“255.255.0.0”是有效掩码；“123.123.123.123”是无效掩码。因为123对应的二进制为“1111011”，1之间存在0。   |
| IPV6   | MME IPv6信令面地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPV6"时为条件可选参数。  参数含义：该参数用于指定对端MME的信令面IPv6地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：  IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址（::1）、链路本地地址（FE80::/10）和组播地址（FF00::/8）。 |
| MASKV6 | IPv6子网前缀长度    | 可选必选说明：该参数在"IPTYPE"配置为"IPV6"时为条件可选参数。  参数含义：该参数用于指定子网前缀的长度。  数据来源：本端规划  取值范围：整数类型，取值范围是0~128。  默认值：无  配置原则：无                                                                                                            |

## 使用实例

- 查询IP地址为2001:db8:0:0:0:0:0:0的MME的属性信息，执行如下命令：

  ```
  %%LST N26MMECHAR: RANGE=SPECIAL_MME, IPTYPE=IPV6, IPV6="2001:db8:0:0:0:0:0:0", MASKV6=126;%%
  RETCODE = 0  操作成功

  结果如下

                     MME IPv6信令面地址  =  2001:db8::
                       IPv6子网前缀长度  =  126
                                MME能力  =  NULL
                 是否传递AM-PCF签约RFSP  =  否
  ```

## 输出结果说明

| 输出项名称                          | 输出项解释                                                                                                                                                                                                                                                                            |
|:-------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 对端设备范围                         | 该参数用于指示对端MME设备范围。                                                                                                                                                                                                                                                                |
| IP地址类型                         | 该参数用于指定对端MME的信令面IP地址类型。                                                                                                                                                                                                                                                          |
| MME IPv4信令面地址                  | 该参数用于指定对端MME的信令面IPv4地址。                                                                                                                                                                                                                                                          |
| IPv4掩码                         | 该参数用于指定对端MME的信令面IPv4地址的掩码。                                                                                                                                                                                                                                                       |
| MME IPv6信令面地址                  | 该参数用于指定对端MME的信令面IPv6地址。                                                                                                                                                                                                                                                          |
| IPv6子网前缀长度                     | 该参数用于指定子网前缀的长度。                                                                                                                                                                                                                                                                  |
| MME能力                          | 该参数用于指定MME支持的能力。                                                                                                                                                                                                                                                                 |
| 是否传递AM-PCF签约RFSP               | 该参数用于设置是否支持N26接口传递AM-PCF签约RFSP的功能。                                                                                                                                                                                                                                               |
| 是否传递AM-PCF签约NI                 | 该参数用于设置是否支持N26接口传递AM-PCF签约NI的功能。                                                                                                                                                                                                                                                 |
| 接口类型                           | 该参数用于设置AMF在发送N26接口消息时，控制面F-TEID中携带的接口类型。 接口消息为Forward Relocation Request/Forward Relocation Response信元名称为Sender's F-TEID for Control Plane、接口消息为Context Request信元名称为S3/S16/S10/N26 Address and TEID for Control Plane、接口消息为Context Response信元名称为Sender F-TEID for Control Plane。 |
| 互操作数据持续性信元传递开关                 | 该参数用于指示当UAM开启基于位置的地址分配功能且4/5G归属同一IP区域群时，用户在4/5G互操作流程中是否传递数据业务不断流信元。                                                                                                                                                                                                              |
| 是否传递MSISDN                     | 该参数用于控制AMF在发送Context Response和Forward Relocation Request消息时，是否支持携带MSISDN信元。                                                                                                                                                                                                      |
| 是否在Private Extension信元传递MSISDN | 该参数用于设置AMF在发送Identification Response消息时，是否支持通过私有信元传递MSISDN。                                                                                                                                                                                                                      |
