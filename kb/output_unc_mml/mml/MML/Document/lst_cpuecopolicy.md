# 查询全局的CPU调频和休眠策略（LST CPUECOPOLICY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

使用CPU节能功能时，通过此命令可以查询全局的调频和休眠策略。

**说明** 

该命令仅在Full-stack虚机场景下支持。

#### 注意事项

- 网元ID必须在系统中存在。

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                             |
|:-------|:-------|:-----------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：网元ID，可以通过LST ME获取。 取值范围：0～65535 默认值：无。 配置原则：无。 |

#### 使用实例

查询“网元ID”为“222”的网元的CPU节能策略。

```
%%LST CPUECOPOLICY: MEID=222;%%
RETCODE = 0  操作成功

操作结果如下
------------
CPU休眠策略  =  浅休眠
CPU调频策略  =  开启
(结果个数 = 1)

---    END
```

#### 输出结果说明

命令执行正常，会返回命令执行成功的提示信息及当前网元的CPU节能策略，输出结果项信息项目如表1。

命令执行失败则返回相应的错误，参见表2；命令执行异常，请联系华为技术支持处理。

| 输出项名称   | 输出项解释                                                                                 |
|:--------|:--------------------------------------------------------------------------------------|
| CPU休眠策略 | 用于返回查询的全局CPU休眠策略。 取值说明： 关闭：CPU休眠策略为关闭。浅休眠：CPU休眠策略为浅休眠。深休眠：CPU休眠策略为深休眠。未配置：未配置CPU休眠策略。 |
| CPU调频策略 | 用于返回查询的全局CPU调频策略。 取值说明： 关闭：CPU调频策略为关闭。开启：CPU调频策略为开启。未配置：未配置CPU调频策略。                   |

|    错误码 | 错误码解释                                       | 原因分析                                                             | 处理建议                   |
|-------:|:--------------------------------------------|:-----------------------------------------------------------------|:-----------------------|
| 150001 | 查询网元信息失败                                    | 输入的网元ID在系统中不存在。                                                  | 检查并修改为正确的网元ID。         |
| 150021 | 当前模式不支持此命令                                  | 该命令仅在Full-Stack虚机场景下支持，若在Full-Stack裸机及三方CaaS场景执行该命令，会返回此错误码作为提示。 | 无需处理。                  |
| 150035 | 查询全局的CPU节能策略失败                              | 查询全局的CPU节能策略失败。                                                  | 请联系华为技术支持。             |
| 150040 | 系统中存在LST ECOPOLICY命令，请使用LST ECOPOLICY命令进行查询 | 系统中存在LST ECOPOLICY命令，请使用LST ECOPOLICY命令进行查询。                     | 使用LST ECOPOLICY命令进行查询。 |
