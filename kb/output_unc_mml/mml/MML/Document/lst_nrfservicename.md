# 查看NRF功能实体服务列表（LST NRFSERVICENAME）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NRF**

该命令用于查看NRF功能实体服务列表。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询NRF功能实体服务列表：

```
LST NRFSERVICENAME:;
%%LST NRFSERVICENAME:;%%
RETCODE = 0  执行成功

操作结果如下:
-------------------------
NRF服务名称      

nrf-servcename001  
nrf-servcename002
nrf-servcename003
(结果个数 = 3)
```

## 输出结果说明

| 输出项名称   | 输出项解释                  |
|:--------|:-----------------------|
| NRF服务名称 | 该参数用于表示特定NRF功能实例的服务名称。 |
