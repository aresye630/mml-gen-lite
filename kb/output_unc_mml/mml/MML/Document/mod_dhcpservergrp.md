# 修改DHCP服务器组（MOD DHCPSERVERGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于修改DHCP服务器组。

## 注意事项

- 该命令执行后立即生效。

- 如果DHCP服务器组下配置有DHCP服务器，则不允许修改IP类型（IPVERSION）；
- 执行该命令修改租约时间（REQLEASETIME）前，需要先去激活绑定的地址池组（通过LST DHCPBINDPOOLGRP查询）下的用户。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称            | 参数说明                                                                                                                                                |
|:-------------|:----------------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| GROUPNAME    | DHCP服务器组名称      | 可选必选说明：必选参数  参数含义：该参数用于指定DHCP服务器组的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。不支持空格，不区分大小写。  默认值：无  配置原则：无                                               |
| IPVERSION    | IP类型            | 可选必选说明：可选参数  参数含义：该参数用于指定IP地址类型。  数据来源：本端规划 取值范围： IPV4（IPv4地址类型）IPV6（IPv6地址类型）  默认值：无  配置原则：无                                                       |
| REQLEASETIME | 租约时间(小时)        | 可选必选说明：可选参数  参数含义：该参数用于指定DHCP服务器组的地址租期。  数据来源：本端规划  取值范围：整数类型，取值范围是0，16~192，单位是小时。  默认值：无  配置原则：无                                                   |
| RETRYINTVAL  | DHCP消息超时重发时间(秒) | 可选必选说明：可选参数  参数含义：该参数用于指定向DHCP服务器发送消息的超时时间。  数据来源：本端规划  取值范围：整数类型，取值范围是1~10，单位是秒。  默认值：无  配置原则：无                                                    |
| RETRYTIMES   | DHCP重发次数        | 可选必选说明：可选参数  参数含义：该参数用于指定向DHCP服务器发送消息的重发次数。  数据来源：本端规划  取值范围：整数类型，取值范围是0~5。  默认值：无  配置原则：无                                                          |
| HASVPN       | 绑定VPN           | 可选必选说明：可选参数  参数含义：该参数用于指定是否绑定VPN实例。  数据来源：本端规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无  配置原则：无                                                          |
| VPNINSTANCE  | VPN实例名          | 可选必选说明：该参数在"HASVPN"配置为"ENABLE"时为条件必选参数。  参数含义：该参数用于指定VPN实例名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。不支持空格，区分大小写。  默认值：无  配置原则：  该参数使用ADD VPNINST命令配置生成。 |

## 使用实例

当需要对一个DHCP服务器组的地址租期和VPN进行修改时，使用该命令：

```
MOD DHCPSERVERGRP:GROUPNAME="testgrp",IPVERSION=IPV4,REQLEASETIME=25,HASVPN=ENABLE,VPNINSTANCE="testvpn";
```
