# 查询相同APN建立多个PDP/PDN连接的网关选择策略(LST SCNDGWSELPLCY)

- 命令功能
- 注意事项
- 本地用户权限

#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询用户使用相同APN建立多个PDP/PDN连接场景下，系统选择GGSN/P-GW的策略。

#### 注意事项

- 无。

#### 本地用户权限

manage-ug; system-ug; monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组；G\_4，来宾级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                        |
|:---------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RATTYPE  | 接入类型   | 可选必选说明：可选参数 参数含义：该参数用以指定网关地址选择策略的适用用户的接入方式。 数据来源：整网规划 取值范围：“LTE(LTE)”：指定的接入类型是LTE。“GPRS_UMTS(GPRS&UMTS)”：指定的接入类型是GPRS或者UMTS。 默认值：无                                                                          |
| SUBRANGE | 用户范围   | 可选必选说明：可选参数 参数含义：该参数用以指定网关地址选择策略的适用用户范围。 数据来源：整网规划 取值范围：“ALL_USER（所有用户）”：所有指定接入类型的用户。“HOME_USER（本网用户）”：所有指定接入类型的本网用户。“FOREIGN_USER（外网用户）”：所有指定接入类型的外网用户。“IMSI_PREFIX（指定IMSI前缀）”：所有指定接入类型且指定IMSI前缀的用户。 默认值：无 |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件可选参数 参数含义：该参数用以指定网关地址选择策略的适用用户IMSI前缀。 前提条件：该参数在“用户范围”参数配置为“指定IMSI前缀”后生效。 数据来源：整网规划 取值范围：5~15位数字。 默认值：无                                                                                             |

#### 使用实例

不输入“接入类型”和“用户范围”，查询所有相同APN建立多个PDP/PDN连接的网关选择策略。

LST SCNDGWSELPLCY:;

```
%%LST SCNDGWSELPLCY:;%%
RETCODE = 0  操作成功。

操作结果如下
------------
接入类型      用户范围        IMSI前缀     LTE模式相同APN网关选择策略     GU模式相同APN网关选择策略    描述信息

LTE           外网用户        NULL         使用接口IP                     NULL                         for 4g roaming user
LTE           指定IMSI前缀    123035       使用接口IP                     NULL                         for 4g imsipre 123035 user
GPRS&UMTS     指定IMSI前缀    123038       NULL                           使用接口IP                   for 23g imsipre 123038 user
(结果个数 = 3)
```
