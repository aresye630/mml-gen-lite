# 查询服务化接口本端实体（LST SBIAPLE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询服务化接口本端实体信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                    |
|:-------|:-------|:----------------------------------------------------------------------------------------|
| INDEX  | 索引     | 可选必选说明：可选参数  参数含义：该参数用于指定服务化接口本端实体的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~128。  默认值：无  配置原则：无 |

## 使用实例

若运营商想查询所有配置的服务化接口本端实体信息，可以执行如下命令：

```
LST SBIAPLE:;

%%LST SBIAPLE:;%%
RETCODE = 0  操作成功

结果如下
------------------------
                        索引  =  1
          HTTP本端实体组标识  =  1
                  本端NF类型  =  NFTypeAMF
                  目的NF类型  =  INVALID
                  CHF的目的NF类型  =  INVALID
                  目的NF服务  =  INVALID
                  描述  =  NULL
                  CHF的目的NF实例ID = NULL
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称        | 输出项解释                                                                        |
|:-------------|:-----------------------------------------------------------------------------|
| 索引           | 该参数用于指定服务化接口本端实体的索引。                                                         |
| HTTP本端实体组标识  | 该参数用于指定服务化接口引用的HTTP本端实体组的索引。依赖于ADD HTTPLEGRP的“INDEX”参数。                      |
| 本端NF类型       | 该参数用于指定本端服务化接口服务的NF类型。如果配置NF类型为AMF，则该服务化接口服务于AMF；如果配置NF类型为SMF，则该服务化接口服务于SMF。 |
| 目的NF类型       | 该参数用于指定本端在客户端模式下，需要访问的目的NF的类型。                                               |
| CHF的目的NF类型   | 该参数用于指定本端CHF在客户端模式下，需要访问的目的NF的类型。                                            |
| 目的NF服务       | 该参数用于指定当本端为客户端模式时，需要访问的NF的具体服务。                                              |
| 描述           | 该参数用于配置服务化接口本端实体的描述信息。                                                       |
| CHF的目的NF实例ID | 该参数用于当本端CHF在客户端模式下，指定目的NF的实例ID。                                              |
