# 设置基于位置区地址分配的开关（SET IPALLOCBYLOCSW）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、GGSN、SMF**

该命令用于设置基于位置区地址分配开关。

## 注意事项

- 该命令执行后立即生效。

- “开关”为“INHERIT”时，按照基于位置区组地址分配的全局开关的配置进行地址分配，不为“INHERIT”时，按照基于位置区组地址分配的开关配置进行地址分配。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                                                                                                                                             |
|:----------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LOCATIONGRPTYPE | 位置区组类型 | 可选必选说明：必选参数  参数含义：该参数用于指定位置区组类型。  数据来源：本端规划 取值范围： LAC（LAC）TAC（TAC）  默认值：无。  配置原则： 配置类型为TAC，LOCATIONGRPNAME必须由ADD ADDRTACGROUP新增。配置类型为LAC，LOCATIONGRPNAME必须由ADD ADDRLACGROUP新增。                                                                                                   |
| LOCATIONGRPNAME | 位置区组名称 | 可选必选说明：必选参数  参数含义：该参数用于标识位置区组名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。  默认值：无。  配置原则：  该参数使用ADD ADDRTACGROUP或ADD ADDRLACGROUP命令配置生成。                                                                                                                                               |
| SWITCH          | IPv4开关 | 可选必选说明：必选参数  参数含义：该参数用于指定基于位置区分配IPv4地址的开关。  数据来源：本端规划 取值范围： “DISABLE（去使能）”：不使用UPF所在的群组标识作为地址分配规则的匹配条件。“INHERIT（继承）”：继承SET IPALLOCBYUPFGLBSW命令的“基于UPF地址分配的全局开关”。“ENABLE（使能）”：使用UPF所在的群组标识作为地址分配规则的匹配条件。  默认值：无。  配置原则：无                                                           |
| IPV6SWITCH      | IPv6开关 | 可选必选说明：可选参数  参数含义：该参数用于指定基于位置区分配IPv6地址的开关。  数据来源：本端规划 取值范围： “DISABLE（去使能）”：不使用UPF所在的群组标识作为地址分配规则的匹配条件。“INHERIT（继承）”：继承SET IPALLOCBYUPFGLBSW命令的“基于UPF地址分配的全局开关”。“ENABLE（使能）”：使用UPF所在的群组标识作为地址分配规则的匹配条件。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST IPALLOCBYLOCSW查询当前参数配置值。  配置原则：无 |

## 使用实例

禁止名为tac1的TAC-Group基于位置区地址分配：

```
SET IPALLOCBYLOCSW: LOCATIONGRPTYPE=TAC, LOCATIONGRPNAME="tac1", SWITCH=DISABLE, IPV6SWITCH=DISABLE;
```
