# 删除PGW重定向配置(RMV PGWRNSI)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于删除PGW重定向配置记录。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                   |
|:---------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：必选参数 参数含义：该参数用于指定支持PGW重定向的用户范围。 数据来源：整网规划 取值范围： “IMSI_PREFIX(指定IMSI前缀)”:指网络中与指定的IMSI前缀匹配的用户。“HOME_USER(本网用户)”:指网络中的本网签约用户。“FOREIGN_USER(外网用户)”:指网络中的漫游用户。“ALL_USER(所有用户)”：指网络中的所有用户。默认值：无                                                                                                                                       |
| NOID     | 运营商标识  | 可选必选说明：条件必选参数 参数含义：该参数用于指定运营商标识。 前提条件：该参数在"用户范围"参数配置为"本网用户"或"外网用户"后生效。 数据来源：整网规划 取值范围：整数类型，取值范围为0~64,128~254。 默认值：无 配置原则： 当用户为MNO用户时，该参数需要配置为0或128～254之间的值，该取值必须和ADD MNO中配置的“MNOID”参数取值相同。当用户为MVNO用户时，该参数需要配置为1～64之间的值，该取值必须和ADD MVNO中配置的“MVNOID”参数取值相同。对于外网用户，该参数是与其归属运营商签订可漫游协议，为其提供服务的MNO/MVNO运营商标识。对于本网用户，该参数是该用户归属的MNO/MVNO运营商标识。 |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI前缀以区分不同的用户群。 前提条件：该参数在“用户范围”参数配置为“IMSI_PREFIX(指定IMSI前缀)”后生效。 数据来源：整网规划 取值范围：1～15位十进制数字字符串 默认值：无  说明： 当该参数配置生效时，按照IMSI最长匹配进行查询，如果匹配到记录，使用该记录的配置；如果没有匹配的记录，则查找IMSI次长匹配的记录。                                                                                                                                 |
| APNNI    | APNNI  | 可选必选说明：必选参数 参数含义：该参数用于指定APNNI。 数据来源：整网规划 取值范围：1～62位字符串 默认值：无 配置原则：该APNNI需要与打开PGW重定向功能的用户携带的APNNI一致。 说明： 紧急呼叫的APN不建议配置PGWRNSI功能，如果端到端规划不合理，可能导致紧急呼叫失败。                                                                                                                                                                                  |

#### 使用实例

删除SUBRANGE为ALL\_USER，APNNI为HUAWEI.COM的PGW重定向配置记录：

```
RMV PGWRNSI: SUBRANGE=ALL_USER, APNNI="HUAWEI.COM";
```
