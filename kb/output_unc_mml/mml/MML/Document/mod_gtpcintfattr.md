# 修改GTP-C IP地址接口属性(MOD GTPCINTFATTR)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME、AMF**

该命令用于修改已存在记录的名称等维护信息。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                          |
|:---------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MODTYPE  | 修改条件   | 可选必选说明：必选参数 参数含义：该参数用于指定修改操作的类型。 数据来源：本端规划 取值范围：“BYINDEX(根据记录索引)”“BYINTFSUB(根据接口类型和用户范围)”                                                                                                                                     |
| INDEX    | 记录索引   | 可选必选说明：条件必选参数 参数含义：该参数用于指定已存在记录的名称。 前提条件：该参数在"操作条件"参数配置为"BYINDEX(根据记录索引)"后生效。 数据来源：本端规划 取值范围：0~4294967295 默认值：无  说明： 使用LST GTPCINTFATTR查询记录的名称。                                                                               |
| SUBRANGE | 用户范围   | 可选必选说明：条件必选参数 参数含义：该参数用于指定GTPC IP地址适用的用户范围。 前提条件：该参数在"修改条件"参数配置为"BYINTFSUB(根据接口类型和用户范围)"后生效。 数据来源：全网规划 取值范围：“ALL_USER(所有用户)”“SPECIAL_IMSIPRE(指定IMSI前缀)”“SPECIAL_NOID(指定运营商)” 默认值：无                                            |
| NOID     | 运营商标识  | 可选必选说明：条件必选参数。 参数含义：该参数用于指定运营商ID。 前提条件：该参数在“用户范围”设置为“指定运营商”后生效。 数据来源：全网规划。 取值范围： 0~64,128~254 默认值：无 配置原则：若该参数需要配置为0或128～254之间的值时，请先在ADD MNO中配置取值相同的“MNOID”参数。若该参数需要配置为1～64之间的值时，须先在ADD MVNO中配置取值相同的“MVNOID”参数。                |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件必选参数。 参数含义：这个参数指明IMSI前缀。在查询过程中采用最长匹配原则。 前提条件：该参数在“用户范围”设置为“指定IMSI前缀”后生效。 数据来源：全网规划。 取值范围：1至15位的十进制数字 默认值：无                                                                                                           |
| INTFTP   | 接口类型   | 可选必选说明：条件必选参数 参数含义：该参数用于指定GTPC IP地址适用的接口类型。 前提条件：该参数在"用户范围"参数配置为"ALL_USER(所有用户)"后生效。 数据来源：全网规划 取值范围：“ALL_INTERFACE(所有接口)”“GN-GGSN/GP(Gn-GGSN/Gp)”“GN-SGSN/S16(Gn-SGSN/S16)”“S10(S10)”“S11(S11)”“S3(S3)”“S4(S4)”“SV(Sv)” 默认值：无 |
| INTFTP2  | 接口类型2  | 可选必选说明：条件必选参数 参数含义：该参数用于指定GTPC IP地址适用的接口类型。 前提条件： 该参数在"用户范围"参数配置为"SPECIAL_NOID(指定运营商)"后生效。该参数在"用户范围"参数配置为"SPECIAL_IMSIPRE(指定IMSI前缀)"后生效。 数据来源：全网规划 取值范围：“ALL_INTERFACE(所有接口)”“GN-GGSN/GP(Gn-GGSN/Gp)”“S11(S11)”“S4(S4)” 默认值：无 |
| DESC     | 描述信息   | 可选必选说明：可选参数 参数含义：该参数用于指定描述信息。 数据来源：本端规划 取值范围：0~31位字符串 默认值：无                                                                                                                                                                   |

#### 使用实例

将修改类型为BYINDEX、INDEX为1的记录的DESC修改为"huawei01"

MOD GTPCINTFATTR: MODTYPE=BYINDEX,INDEX=1,DESC="huawei01";
