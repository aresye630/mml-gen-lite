# 删除扩展QCI转换关系(RMV QCICONV)

- 本地用户权限

#### 命令功能

**适用网元：MME**

该命令用于删除系统中扩展QCI(QoS Class Identifier)向标准QCI的转换关系配置表。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                                                                                                                                |
|:--------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| QCIEXT  | 扩展QCI基准值 | 可选必选说明：必选参数 参数含义：待删除的扩展QCI基准值。 取值范围：10～254 默认值：无                                                                                                                                                    |
| QCISTEP | 扩展QCI范围  | 可选必选说明：可选参数 参数含义：待删除的扩展QCI取值范围值。扩展QCI范围是指“扩展QCI基准值”加上“扩展QCI范围”，在这一范围内的扩展QCI向标准QCI的转换关系配置表将统一被删除。 取值范围：0～244 默认值：无  说明： “扩展QCI范围”与“扩展QCI基准值”之和必须大于9并小于255。如果不输入，则表示删除系统内扩展QCI值为扩展QCI基准值向QCI标准值的转换关系。 |

#### 使用实例

删除扩展QCI值从10到30内向标准QCI的转换关系配置表：

RMV QCICONV: QCIEXT=10, QCISTEP=20;
