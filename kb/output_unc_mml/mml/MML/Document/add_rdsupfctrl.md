# 增加RADIUS服务器的UP列表中指定UP的功能属性（ADD RDSUPFCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、PGW-C、GGSN**

该命令用来增加RADIUS服务器使用的UP列表中指定UPF的功能属性。

## 注意事项

- 该命令执行后立即生效。

- 执行该命令时需保证UPLIST4RDS配置中已添加相同UPLISTNAME和UPINSTANCEID的配置。
- 如果新增记录优先级字段非0值时，则会在下一次二次鉴权RADIUS中转UPF会话创建时生效。

- 最多可输入512条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                            |
|:-------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UPLISTNAME   | UP列表名称 | 可选必选说明：必选参数  参数含义：该参数用于指定UP列表名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。该参数需要是UPLIST4RDS配置中已添加的UPLISTNAME的值。不区分大小写。  默认值：无  配置原则：  该参数使用ADD UPLIST4RDS命令配置生成。                       |
| UPINSTANCEID | UP实例标识 | 可选必选说明：必选参数  参数含义：该参数用于指定UP实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~36。该参数取值需要是UPLIST4RDS配置中已添加的UPINSTANCEID的值。不区分大小写。  默认值：无  配置原则：  该参数使用ADD UPLIST4RDS命令配置生成。                   |
| PREFERENCE   | 优先级    | 可选必选说明：必选参数  参数含义：该参数用于指定UP的优先级。  数据来源：本端规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：  优先级值越大优先级越高，优先级值越小优先级越低。                                                                      |
| LOCKED       | 锁定     | 可选必选说明：必选参数  参数含义：该参数用于对该UPF进行锁定操作，当取值为ENABLE时，SMF无法选择该UPF创建UPF中转RADIUS会话。  数据来源：本端规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无  配置原则：  该参数为ENABLE时，指定为锁定该UPF。该参数为DISABLE时，指定为解锁该UPF。 |

## 使用实例

增加UP列表名为“uplist1”，UP名为“up1”的主机，优先级的值为1，锁定为ENABLE：

```
ADD RDSUPFCTRL: UPLISTNAME="uplist1", UPINSTANCEID="up1",PREFERENCE=1,LOCKED=ENABLE;
```
