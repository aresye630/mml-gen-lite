#### 命令功能

**适用网元：SGSN、MME、SMSF**

该命令用于查询M3UA目的实体状态，目的实体是从本地实体的角度出发，在本地实体所在的所有信令网络中可见的实体。

#### 注意事项

- 系统会自行选取正常可用的信令进程（SPP/SGP），因此，执行该操作的时候要确保系统中有可用的信令进程，否则，操作将不能正常执行。
- 支持目的实体索引、目的实体状态、目的实体名称的单独查询方式和任意组合查询方式。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                          |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------|
| RUNAME | RU名称   | 可选必选说明：可选参数 参数含义：该参数用于指定SPU资源单元名称。该参数可以通过DSP RU命令查询。 取值范围：0~63位字符串 默认值：无 配置原则：无                                               |
| PT     | 进程类型   | 可选必选说明：可选参数 参数含义：该参数用于指定进程的进程类型。 取值范围： “SGP（SGP）” 默认值：无 配置原则：无                                                                |
| PN     | 进程号    | 可选必选说明：可选参数 参数含义：该参数用于指定进程号。 取值范围：0~11 默认值：无 配置原则：无                                                                           |
| DEX    | 目的实体索引 | 可选必选说明：可选参数 参数含义：该参数用于指定查询的目的实体的索引。 取值范围：0~1279 默认值：无 配置原则：无                                                                  |
| DES    | 目的实体状态 | 可选必选说明：可选参数 参数含义：该参数用于指定查询目的实体时需要匹配的状态，即只有符合该状态的目的实体才显示。 取值范围：“INACCESS（不可达）”“ACCESS（可达）”“NOCONG（未拥塞）”“CONG（拥塞）” 默认值：无 配置原则：无 |
| DEN    | 目的实体名  | 可选必选说明：可选参数 参数含义：该参数用于指定目的实体名称，标识目的实体。 取值范围：长度不超过32的字符串 默认值：无 配置原则：无                                                          |

#### 使用实例

查询实体索引为1的M3UA目的实体状态：

```
DSP M3DE: DEX=1;
```

```
%%DSP M3DE: DEX=1;%%
RETCODE = 0  操作成功。

查询M3UA目的实体状态
--------------------
 目的实体索引  =  1
   网络指示语  =  国内备用网
 目的实体编码  =  0x491
 本地实体编码  =  0x1449
     是否可达  =  是
     是否拥塞  =  否
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                                                                                                             |
|:--------|:------------------------------------------------------------------------------------------------------------------|
| 目的实体索引  | 待查询的目的实体的索引。                                                                                                      |
| 目的实体编码  | 用于指定该目的实体在No.7信令网中的信令点编码。  说明： 信令点编码结构与对应的本地实体的信令点编码结构一致； 目的实体编码为16进制数，可以输入0x为前缀。即输入“0xB23”和“B23”均表示实体编码为“0xB23”。 |
| 网络指示语   | M3UA目的实体的“网络指示语”取值，与该目的实体所对应的M3UA本地实体的“网络指示语”一致。 取值说明： “国际网”“国际备用网”“国内网”“国内备用网”                                   |
| 本地实体编码  | 本地实体编码。                                                                                                           |
| 是否可达    | 目的实体是否可达，有是、否两种状态。正常情况下应该为是。 取值说明： “否”“是”  说明： 不可达时，参考ALM-10337 M3UA目的实体不可达帮助进行处理。                                |
| 是否拥塞    | 目的实体是否拥塞，有是、否两种状态。正常情况下应该为否。 取值说明： “否”“是”  说明： 拥塞时，参考ALM-80634 M3UA链路拥塞帮助进行处理。                                    |
