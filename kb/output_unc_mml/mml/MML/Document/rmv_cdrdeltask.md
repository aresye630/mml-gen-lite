# 删除话单删除任务（RMV CDRDELTASK）

- 命令功能

- 本地用户权限

#### 命令功能

**须知** 

话单删除任务删除后，其配置的目录下如果还有话单文件，将不会再被过期删除。

**适用NF：NCG**

该命令用于删除已添加的话单删除任务。

执行任务之前，可执行**LST CDRDELTASK**命令查询当前系统中需要删除的话单删除任务情况，找到对应的删除任务标识。

#### 注意事项

- 话单删除任务删除后，NCG不再自动删除其配置的目录下的过期话单文件。
- 此命令可以动态生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                           |
|:-------------|:-------|:-------------------------------------------------------------------------------|
| CDRDELTASKID | 删除任务标识 | 可选必选说明：必选参数 参数含义：话单删除任务标识，全局唯一。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：无 |

#### 使用实例

删除任务标识为“cdr\_deltask1”的话单删除任务：

```
RMV CDRDELTASK: CDRDELTASKID="cdr_deltask1";
```
