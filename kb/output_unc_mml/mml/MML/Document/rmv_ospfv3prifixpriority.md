# 删除OSPFv3路由收敛优先级配置（RMV OSPFV3PRIFIXPRIORITY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于恢复OSPFv3路由的默认收敛优先级。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称      | 参数说明                                                                                                                               |
|:---------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------|
| PROCID   | OSPFv3进程号 | 可选必选说明：必选参数 参数含义：OSPFv3进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无                                                           |
| TOPOID   | 拓扑标识      | 可选必选说明：可选参数 参数含义：拓扑标识。 数据来源：全网规划 取值范围：整数类型，取值范围为0。 默认值：无 配置原则：目前只支持默认拓扑0。                                                          |
| PRIORITY | 路由优先级     | 可选必选说明：必选参数 参数含义：路由优先级。 数据来源：本端规划 取值范围：枚举类型。 critical：配置OSPFv3路由的收敛优先级为关键。high：配置OSPFv3路由的收敛优先级为高。medium：配置OSPFv3路由的收敛优先级为中。 默认值：无 |

#### 使用实例

删除OSPFv3进程1下critical路由收敛优先级配置：

```
RMV OSPFV3PRIFIXPRIORITY:PROCID=1,PRIORITY=critical;
```
