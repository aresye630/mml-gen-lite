# 设置SDR参数（SET SDRPARAMS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令是高危命令，操作不当可能会导致业务受损，请谨慎使用并联系华为技术支持协助操作。

该命令用于设置SDR服务的相关参数。SDR主要功能是为微服务间提供分布式透明通信。

## 注意事项

- 该命令执行后立即生效。

- SDR参数ID为0和6的功能该版本不支持。
- SDR参数ID为4的功能，其对应的PARAVALUE1表示Fabric平面可靠传输的校验和开关。修改PARAVALUE1的值后，请全量复位POD，否则会上报系统命令配置修改未生效告警。
- 默认使用系统初始值，如需修改，请联系华为技术支持协助操作。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

|   PARAID |   PARAVALUE1 |   PARAVALUE2 |
|---------:|-------------:|-------------:|
|        0 |            0 |            0 |
|        1 |            1 |            0 |
|        2 |            0 |            0 |
|        3 |            1 |            0 |
|        4 |            0 |            0 |
|        5 |            1 |            0 |
|        6 |            1 |           10 |
|        7 |            1 |            0 |
|        8 |            0 |            0 |
|        9 |            1 |            0 |
|       10 |            1 |            5 |
|       11 |            0 |            0 |

#### 操作用户权限

G\_1，管理员级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|:-----------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PARAID     | 参数ID   | 可选必选说明：必选参数  参数含义：该参数用于指定SDR命令标识。  数据来源：本端规划  取值范围：整数类型，取值范围是0~11。  默认值：无。  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| PARAVALUE1 | 第一个参数值 | 可选必选说明：必选参数  参数含义：该参数用于SDR命令。 当PARAID为0时，该参数值用于SDR可靠传输开关控制，0表示关闭base和fabric可靠传输开关，1表示只开启可靠base传输开关，2表示只开启可靠fabric传输开关，3表示开启base和fabric可靠传输开关。 当PARAID为1时，该参数值用于Token通信场景Fabric链路的故障检测和业务隔离能力功能开关，0表示关闭，1表示开启。 当PARAID为2时，该参数值用于DTP功能开关，0表示关闭，1表示开启。 当PARAID为3时，该参数值用于SDRS内多线程消息处理转组件线程消息处理功能开关，0表示关闭，1表示开启。 当PARAID为4时，该参数值用于Fabric可靠传输校验和开关，0表示关闭，1表示开启。 当PARAID为5时，该参数值用于SDR话统数据上报开关，0表示关闭，1表示开启。 当PARAID为6时，该参数值用于SDRS与SDRC之间的策略核查开关，0表示关闭，1表示开启。 当PARAID为7时，该参数值用于SDR pbuf流控功能开关，0表示关闭，1表示开启。 当PARAID为8时，该参数值用于无状态通信场景Fabric链路的故障检测和业务隔离能力功能开关，0表示关闭，1表示开启。 当PARAID为9时，该参数值用于SDR内统日志打印功能开关，0表示关闭，1表示开启。 当PARAID为10时，该参数值用于SDR系统命令配置修改未生效告警功能开关，0表示关闭，1表示开启。 当PARAID为11时，该参数值用于SDR配置PAEChannel下发加权轮询算法开关，0表示关闭，1表示开启。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无。  配置原则：  当PARAID为11时，当前版本默认关闭，若需修改“第一个参数值”为1，请及时联系华为技术支持。 |
| PARAVALUE2 | 第二个参数值 | 可选必选说明：可选参数  参数含义：该参数用于SDR命令值扩展，类型是字符串。当SDR参数ID为6时，该参数值用于表示SDRS与SDRC之间的策略核查周期，单位为分钟。 当PARAID为7时，该参数值用于表示pbuf流控功能起控阈值和pbuf使用率刷新周期，刷新周期单位为毫秒。 当PARAID为10时，该参数值用于表示系统命令配置修改未生效告警检测周期，单位为分钟。 当PARAID为11时，该参数值用于表示配置PAEChannel各队列的权重。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~256。当PARAID的取值为6且PARAVALUE1取值为1时，请按照无符号整数类型的数值进行输入，有效数值范围1~4294967295，输入其他内容则该命令不生效。当PARAID的取值为10时，请按照无符号整数类型的数值进行输入，有效数值范围1~15，输入其他内容则该阈值的配置不生效。当PARAID的取值为11且PARAVALUE1取值为1时，请按照无符号整数类型的数值进行输入，有效数值范围为1~100，输入4个数值以空格隔开，4个数值用于配置4个队列的权重，当前调度队列权重耗尽才会调度下一调度队列，每调度一次调度队列权重减1。若输入其他内容，则该命令不生效。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST SDRPARAMS查询当前参数配置值。  配置原则：  当PARAID的取值为6且PARAVALUE1取值为1时，该参数为必选，若不输入，则该命令不生效。  当PARAID的取值为11且PARAVALUE1取值为1时，该参数为必选，若不输入，则该命令不生效。                                                                                          |

## 使用实例

通过如下命令开启SDRS与SDRC之间的策略核查功能：

```
SET SDRPARAMS: PARAID=6, PARAVALUE1=1, PARAVALUE2="10";
```
