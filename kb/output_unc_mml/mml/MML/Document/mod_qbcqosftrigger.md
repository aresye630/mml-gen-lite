# 修改QBC计费QoS Flow级的trigger参数（MOD QBCQOSFTRIGGER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于修改QBC计费QoS Flow级的trigger参数。

## 注意事项

该命令执行后只对新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                         |
|:---------------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CCTMPLTNAME    | 融合计费模板名称 | 可选必选说明：必选参数  参数含义：该参数用于指定融合计费模板名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。不区分大小写。  默认值：无  配置原则：  该参数使用ADD CCT命令配置生成。                                                                                                                                                                                                                             |
| QOSCHG         | QoS更新    | 可选必选说明：可选参数  参数含义：该参数用于设置QoS更新的trigger上报方式。  数据来源：本端规划 取值范围： “NONREPORT（不上报）”：事件发生，不生成容器，不上报CHF。“IMMEDIATE（立即上报）”：事件发生，按Immediate上报，对已经产生的用量生成用量容器，向CHF发送Charging Data Request Update消息携带所有生成的用量容器，并开始新的用量计量。“DEFERRED（延迟上报）”：事件发生，按Deferred上报，对已经产生的用量生成用量容器，并开始新的用量计量。  默认值：无  配置原则：无                                                      |
| QFLOWTIMELIMIT | QoS流时间阈值 | 可选必选说明：可选参数  参数含义：该参数用于设置QoS流时间阈值的trigger上报方式。  数据来源：本端规划 取值范围： “NONREPORT（不上报）”：事件发生，不生成容器，不上报CHF。“IMMEDIATE（立即上报）”：事件发生，按Immediate上报，对已经产生的用量生成用量容器，向CHF发送Charging Data Request Update消息携带所有生成的用量容器，并开始新的用量计量。“DEFERRED（延迟上报）”：事件发生，按Deferred上报，对已经产生的用量生成用量容器，并开始新的用量计量。  默认值：无  配置原则：无                                                   |
| QFLOWVOLLIMIT  | QoS流流量阈值 | 可选必选说明：可选参数  参数含义：该参数用于设置QoS流流量阈值的trigger上报方式。  数据来源：本端规划 取值范围： “NONREPORT（不上报）”：事件发生，不生成容器，不上报CHF。“IMMEDIATE（立即上报）”：事件发生，按Immediate上报，对已经产生的用量生成用量容器，向CHF发送Charging Data Request Update消息携带所有生成的用量容器，并开始新的用量计量。“DEFERRED（延迟上报）”：事件发生，按Deferred上报，对已经产生的用量生成用量容器，并开始新的用量计量。  默认值：无  配置原则：无                                                   |
| QFLOWEND       | QoS流结束   | 可选必选说明：可选参数  参数含义：该参数用于设置QoS流结束的trigger上报方式。  数据来源：本端规划 取值范围： “NONREPORT（不上报）”：事件发生，不生成容器，不上报CHF。“IMMEDIATE（立即上报）”：事件发生，按Immediate上报，对已经产生的用量生成用量容器，向CHF发送Charging Data Request Update消息携带所有生成的用量容器，并开始新的用量计量。“DEFERRED（延迟上报）”：事件发生，按Deferred上报，对已经产生的用量生成用量容器，并开始新的用量计量。  默认值：无  配置原则：  当前版本不支持配置为NONREPORT。当该参数配置为NONREPORT时，按照DEFERRED处理。 |

## 使用实例

修改绑定名称为“test”的CCT融合计费模板的QBC计费QoS Flow级的trigger参数，QOS更新trigger上报方式为延迟上报：

```
MOD QBCQOSFTRIGGER: CCTMPLTNAME="test", QOSCHG=DEFERRED;
```
