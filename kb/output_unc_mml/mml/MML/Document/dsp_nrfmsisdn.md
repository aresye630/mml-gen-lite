# 显示MSISDN号段匹配信息（DSP NRFMSISDN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NRF**

该命令用于查询与输入MSISDN号段存在交集的配置号段及所属NF组标识。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识          | 参数名称        | 参数说明                                                                                                                                                          |
|:--------------|:------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFTYPE        | NF类型        | 可选必选说明：必选参数  参数含义：该参数用于表示待查询的NF类型。  数据来源：本端规划 取值范围： PCF（PCF）UDM（UDM）UDR（UDR）CHF（CHF）CUSTOM_OCS（CUSTOM_OCS）  默认值：无  配置原则：无                                     |
| SEGQUERYSTART | 号段查询条件起始字符串 | 可选必选说明：必选参数  参数含义：该参数用于表示查询NRF上MSISDN号段配置的起始字符串。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是5~15。号段的起始号码必须与结束号码长度保持一致，数值必须小于或等于结束号码的数值，且号段的起始号码不能以0开始，全0除外。  默认值：无  配置原则：无 |
| SEGQUERYEND   | 号段查询条件结束字符串 | 可选必选说明：必选参数  参数含义：该参数用于表示查询NRF上MSISDN号段配置的结束字符串。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是5~15。号段的结束号码必须与起始号码长度保持一致，数值大于或等于起始号码的数值，且号段的结束号码不能以0开始。  默认值：无  配置原则：无        |

## 使用实例

查询起始字符串为"11111"，结束字符串为"44444"的MSISDN号段匹配信息。

```
DSP NRFMSISDN: NFTYPE=CHF, SEGQUERYSTART="11111", SEGQUERYEND="44444";
%%DSP NRFMSISDN: NFTYPE=CHF, SEGQUERYSTART="11111", SEGQUERYEND="44444";%%
RETCODE = 0  执行成功

结果如下
------------------------
NF组标识            号段查询结果起始字符串  号段查询结果结束字符串    NF类型

chfpool-guangf-001  000000000000000    111111111111111      CHF
chfpool-guangf-001  111111111111111    222222222222222      CHF
(结果个数 = 2)
```

## 输出结果说明

| 输出项名称       | 输出项解释                                                                         |
|:------------|:------------------------------------------------------------------------------|
| NF组标识       | 该参数用于表示支持MSISDN号段范围的NF组标识。                                                    |
| 号段查询结果起始字符串 | 该参数用于表示与输入MSISDN号段存在交集的配置号段的实际起始字符串。                                          |
| 号段查询结果结束字符串 | 该参数用于表示与输入MSISDN号段存在交集的配置号段的实际结束字符串。                                          |
| NF类型        | 该参数用于表示待查询的NF类型。 取值说明： PCF（PCF）UDM（UDM）UDR（UDR）CHF（CHF）CUSTOM_OCS（CUSTOM_OCS） |
