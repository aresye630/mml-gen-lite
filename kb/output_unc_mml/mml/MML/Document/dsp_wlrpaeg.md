# 显示PAEG信息（DSP WLRPAEG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示PAEG信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                           |
|:--------------|:-------|:-----------------------------------------------------------------------------------------------|
| ADDRESSFAMILY | 地址族    | 可选必选说明：必选参数 参数含义：该参数用于表示地址族。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。ipv6unicast：IPv6单播。 默认值：无 |

#### 使用实例

显示PAEG信息：

```
DSP WLRPAEG:ADDRESSFAMILY=ipv4unicast;
```

