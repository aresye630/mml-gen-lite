# 增加CG配置参数（ADD CHGCG）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用于配置与本端SGSN对接的CG需满足的相关参数。

SGSN与CG对接时，需要配置该命令。

#### 注意事项

- 该命令执行后立即生效。
- 此表最大记录数为16。
- “GTP承载协议（PRO）”、“CG的IP地址（IP）”和“CG接收端口号（SPN）”唯一确定一条记录。
- 只有在本命令中配置的CG，才能在**SET CHGCHAR**、**ADD CHGBEHA**和**ADD CHGPLMNCG**中生效。
- 不同命令配置的CG优先级从高到低的次序是：**ADD CHGPLMNCG**，**ADD CHGBEHA**，**SET CHGCHAR**，**ADD CHGCG**。
- 当**SET CHGCDR**中配置“PLMNCG范围扩展（EXTRANGE）”为“NO”时，**ADD CHGPLMNCG**中配置的CGIP，其在本命令中的“缺省CG（DEFAULTCG）”必须为“NO”。
- CG上支持接入的GA链路条数有规格限制，不能超过“CG上2G类型的AP数量 \* 300”，配置GA链路前，需要联系华为工程师提前规划GA链路总数。CG上2G类型的AP数量可以通过****LST MODULE****命令查询。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                   |
|:----------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPT       | IP地址类型    | 可选必选说明：可选参数 参数含义：该参数用于标识与本端SGSN连接的CG的IP地址类型。 数据来源：全网规划 取值范围：“IPV4(IPV4地址)”“IPV6(IPV6地址)” 默认值：“IPV4(IPV4地址)”                                                                                                                                                                                                                                                            |
| IP        | CG的IPV4地址 | 可选必选说明：条件必选参数 参数含义：该参数用于标识与本端SGSN连接的CG的IPV4地址。 前提条件：该参数在“IPT(IP地址类型)”配置为“IPV4(IPV4地址)”后生效。 数据来源：整网规划 取值范围：0.0.0.0~255.255.255.255 默认值：无 配置原则： 有效的IPV4地址不能为环回地址（127.x.y.z）。有效的IPV4地址必须是A、B或者C类地址。                                                                                                                                                                       |
| IPV6      | CG的IPV6地址 | 可选必选说明：条件必选参数 参数含义：该参数用于标识与本端SGSN连接的CG的IPV6地址。 前提条件：该参数在“IPT(IP地址类型)”配置为“IPV6(IPV6地址)”后生效。 数据来源：全网规划 取值范围：::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 配置原则：IPV6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址(::1)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。                                                                                              |
| GRD       | 优先级       | 可选必选说明：条件可选参数 参数含义：该参数用于标识CG的优先级。SGSN首先向高优先级的CG发送话单，高优先级的CG不可达后，选择次高优先级的CG发送。对于优先级别相同的CG，同一个用户的话单每次都发往相同的CG，不同用户的话单发送时则会轮选CG。 前提条件：该参数在“DEFAULTCG”设置为“YES（是）”时生效。 数据来源：整网规划 取值范围：0~11 默认值：0 配置原则：0为最高等级，11为最低等级。                                                                                                                                                       |
| PRO       | GTP承载协议   | 可选必选说明：必选参数 参数含义：该参数用于标识CG支持的GTP'承载协议。 数据来源：整网规划 取值范围： “UDP(UDP)”：表示SGSN和CG之间通过UDP/IP进行通讯。“TCP(TCP)”：表示SGSN和CG之间通过TCP/IP进行通讯。 默认值：无  说明： 本版本暂不支持将“GTP承载协议（PRO）”设置为“TCP(TCP)”。                                                                                                                                                                                          |
| CGR       | CG协议版本    | 可选必选说明：必选参数 参数含义：该参数用于标识CG支持的协议版本。 数据来源：整网规划 取值范围： “R98(R98)”：表示CG支持的协议版本为R98。“R99(R99)”：表示CG支持的协议版本为R99。“R4(R4)”：表示CG支持的协议版本为R4。“R5(R5)”：表示CG支持的协议版本为R5。“R6(R6)”：表示CG支持的协议版本为R6。“R7(R7)”：表示CG支持的协议版本为R7。“R9(R9)”：表示CG支持的协议版本为R9。 默认值：无 配置原则：对于GPRS，可以使用R98、R99、R4、R5、R6、R7和R9协议版本的CG。对于WCDMA，可以使用R99、R4、R5、R6、R7和R9协议版本的CG。                                           |
| SPN       | CG接收端口号   | 可选必选说明：可选参数 参数含义：该参数用于标识UDP类型CG的SGSN消息所要发往的端口号（亦即UDP类型CG的接收端口号）或TCP类型CG的侦听端口号。 数据来源：整网规划 取值范围：1024~65535 默认值：3386 配置原则：与对端CG网元的设置保持一致。具有相同IP地址的UDP CG之间的“CG接收端口号”不能相同。具有相同IP地址的TCP CG之间的“CG接收端口号”不能相同。具有相同IP地址的UDP CG和TCP CG之间的“CG接收端口号”不能相同。                                                                                                                          |
| DEFAULTCG | 缺省CG      | 可选必选说明：可选参数 参数含义：该参数用于控制当PLMN CG（ADD CHGPLMNCG），计费行为CG（ADD CHGBEHA），计费属性CG（SET CHGCHAR）推荐CG都不可用的情况下，是否选择缺省CG。 数据来源：整网规划 取值范围： “NO（否）”“YES（是）” 默认值：“YES（是）” 配置原则：当SET CHGCDR中配置“PLMNCG范围扩展（EXTRANGE）”为“NO”时，ADD CHGPLMNCG中配置的CGIP，其在本命令中的“缺省CG（DEFAULTCG）”必须为“NO”。当PLMN CG（ADD CHGPLMNCG），计费行为CG（ADD CHGBEHA），计费属性CG（SET CHGCHAR）和推荐CG都不可用的情况下，该参数需配置为“YES”，否则话单将存储在硬盘。 |
| CGN       | CG名       | 可选必选说明：可选参数 参数含义：该参数用于标识CG的名称。 数据来源：整网规划 取值范围：1~32位字符串 默认值：noname                                                                                                                                                                                                                                                                                                      |

#### 使用实例

1. 增加一个CG的配置，IP地址类型为IPV4，CG的IPV4地址为172.22.5.50，优先级为0，GTP承载协议为UDP，CG协议版本为R98，CG接收端口号为3386，CG名为“xx”：

   ADD CHGCG: IPT=IPV4, IP="172.22.5.50", PRO=UDP, CGR=R98, SPN=3386, DEFAULTCG=YES, GRD=0, CGN="xx";
2. 增加一个CG的配置，IP地址类型为IPV4，CG的IPV4地址为172.22.5.42，优先级为1，GTP承载协议为UDP，CG协议版本为R4，CG接收端口号为3386，CG名为“yy”：

   ADD CHGCG: IPT=IPV4, IP="172.22.5.42", PRO=UDP, CGR=R4, SPN=3386, DEFAULTCG=YES, GRD=1, CGN="yy";
