# 删除性能对象信息(RMV PERFOBJ)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

本命令用于删除指定的性能统计对象。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称      | 参数说明                                                                                                                                                                         |
|:-------------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MOC          | 测量对象类型    | 可选必选说明：必选参数 参数含义：待删除的测量对象类型。 取值范围：“APN(APN)”“TAIGP(TAI组)” “HSSHOSTNAME(HSS主机名)” 默认值：无                                                                                        |
| NAME         | 对象名称      | 可选必选说明：条件可选参数 参数含义：待删除APN测量对象名称。 前提条件：该参数在“MOC(测量对象类型)”参数设置为“APN(APN)”时，才需要配置。 取值范围：0~63位字符串 默认值：无  说明： 只有先确定在网管上删除了此APN对象，方可成功删除对象索引。只能输入大小写字母、“.”、“-”、0~9的整数。              |
| INDEX        | 索引        | 可选必选说明：条件可选参数 参数含义：待删除APN测量对象对应的索引。 前提条件：该参数在“MOC(测量对象类型)”参数设置为“APN(APN)”时，才需要配置。 取值范围：1~1000 默认值：无  说明： 至少指定参数“对象名称”或者参数“索引”。可通过命令LST PERFOBJ获取相应的参数值。                      |
| TAIGPN       | TAI组名     | 可选必选说明：条件必选参数 参数含义：待删除TAI组测量对象的名称。 前提条件：该参数在“MOC(测量对象类型)”参数设置为“TAIGP(TAI组)”时，才需要配置。 删除TAI组前，需要先通过命令RMV PERFOBJRULE删除对应该TAI组的规则。删除TAI组后，此TAI组对象将无法进行性能统计。 取值范围：1~32位字符串 默认值：无 |
| HSSNAMEINDEX | HSS对象名称索引 | 可选必选说明：条件必选参数 参数含义：该参数用于指定待删除的HSS对象名称索引。 前提条件：该参数在“MOC(测量对象类型)”参数设置为“HSSHOSTNAME(HSS主机名)”时，才需要配置。 取值范围：1~64 默认值：无  说明： 可通过命令LST PERFOBJ获取相应的参数值。 删除HSS对象后，此对象对应的性能指标将无法进行统计。 |

#### 使用实例

1. 以下两种方式都可以删除APN对象“huawei.com”对应的索引:
   - RMV PERFOBJ: MOC=APN, NAME="huawei.com";
   - RMV PERFOBJ: MOC=APN, INDEX=1;
2. 以下可以删除TAI组名为“huawei”的TAI组对象：
   - RMV PERFOBJ: MOC=TAIGP, TAIGPN="huawei";
3. 以下可以删除HSS对象名称索引为“1”的HSS对象记录：
   - RMV PERFOBJ: MOC=HSSHOSTNAME, HSSNAMEINDEX=1;
