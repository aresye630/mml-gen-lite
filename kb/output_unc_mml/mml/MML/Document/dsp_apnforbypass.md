# 显示APN锁定状态（DSP APNFORBYPASS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C、SMF、GGSN**

该命令用来查看存储Bypass场景下所有被锁定的APN实例名。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                          |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN    | APN    | 可选必选说明：可选参数  参数含义：该参数用于指定APN实例名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无  配置原则：  输入的APN名称需要符合APN命名规则。 |
| POD_ID | POD名称  | 可选必选说明：可选参数  参数含义：该参数用于指定POD名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~255。  默认值：无  配置原则：无                                                                                                                                           |

## 使用实例

- 显示整机APN实例信息

  ```
  %%DSP APNFORBYPASS:;%%
  RETCODE = 0  操作成功。

  结果如下
  ------------------------
  APN          Pod Name  APN Lock Status  

  huawei.com   uncpod-1  locked           
  huawei2.com  uncpod-1  locked       
  huawei2.com  uncpod-0  locked
  huawei.com   uncpod-0  locked    
  (结果个数 = 4)

  ---    END
  ```
- 显示指定APN实例信息

  ```
  %%DSP APNFORBYPASS: APN="huawei.com";%%
  RETCODE = 0  操作成功。

  结果如下
  ------------------------
  APN          Pod Name  APN Lock Status  

  huawei.com  uncpod-0  locked           
  huawei.com  uncpod-1  locked           
  (结果个数 = 2)

  ---    END
  ```
- 显示指定POD中的APN实例信息

  ```
  %%DSP APNFORBYPASS: POD_ID="uncpod-0";%%
  RETCODE = 0  操作成功。

  结果如下
  ------------------------
  APN          Pod Name  APN Lock Status  

  huawei2.com  uncpod-0  locked           
  huawei.com   uncpod-0  locked           
  (结果个数 = 2)

  ---    END
  ```

## 输出结果说明

| 输出项名称    | 输出项解释                                                 |
|:---------|:------------------------------------------------------|
| APN      | 该参数用于指定APN实例名。                                        |
| POD名称    | 该参数用于指定POD名称。                                         |
| APN的锁定状态 | 此参数描述存储Bypass状态下APN的锁定状态。 取值说明： INVALID（无效）LOCKED（锁定） |
