# 设置P-CSCF控制配置（SET PCSCFCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于配置P-CSCF控制属性。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| FAILRST   | PCSCFBYPASS   | BYPASSAUTOEXIT   |
|:----------|:--------------|:-----------------|
| ENABLE    | DISABLE       | DISABLE          |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称           | 参数说明                                                                                                                                                                                                          |
|:---------------|:---------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FAILRST        | 故障恢复           | 可选必选说明：可选参数  参数含义：该参数用于设置检测到P-CSCF故障时，是否主动向用户侧发起UpdateBearerRequest消息更新P-CSCF地址。  数据来源：本端规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST PCSCFCTRL查询当前参数配置值。  配置原则：无                 |
| PCSCFBYPASS    | P-CSCF故障逃生     | 可选必选说明：可选参数  参数含义：该参数用于控制SMF未查询到可用的P-CSCF IP时，是否将代理地址返回终端用于IMS注册。  数据来源：本端规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST PCSCFCTRL查询当前参数配置值。  配置原则：无                                |
| BYPASSAUTOEXIT | 自动退出P-CSCF故障逃生 | 可选必选说明：可选参数  参数含义：该参数用于控制P-CSCF全故障恢复时，SMF是否支持自动退出P-CSCF故障逃生。  数据来源：本端规划 取值范围： “DISABLE（不使能）”：根据终端能力更新可用的P-CSCF地址或去活会话。“ENABLE（使能）”：去活会话。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST PCSCFCTRL查询当前参数配置值。  配置原则：无 |

## 使用实例

关闭P-CSCF故障后主动发送UpdateBearerRequest消息：

```
SET PCSCFCTRL: FAILRST=DISABLE;
```
