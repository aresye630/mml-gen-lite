# 删除CG（RMV CG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

**须知** 

本命令属于高危命令，删除对端信息可能导致无可用CG，话单无法被正常处理，进而影响计费。

RMV CG命令用来在CG配置表中删除一个CG信息。

#### 注意事项

- 该命令执行后立即生效。
- CG服务器的配置是支持用户进行离线计费必不可少的一部分，删除CG服务器配置时需要谨慎操作。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称      | 参数说明                                                                                                                          |
|:----------|:----------|:------------------------------------------------------------------------------------------------------------------------------|
| IPVERSION | CG IP版本   | 可选必选说明：必选参数 参数含义：该参数用于指定CG IP类型。 数据来源：全网规划 取值范围：枚举类型。 IPV4：IPv4。IPV6：IPv6。 默认值：IPV4 配置原则：无                                    |
| IPV4ADDR  | CG IPv4地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV4”时为必选参数。 参数含义：CG服务器的IPv4地址。 数据来源：全网规划 取值范围：IPv4地址类型。 默认值：无 配置原则：无                   |
| IPV6ADDR  | CG IPv6地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV6”时为必选参数。 参数含义：CG服务器的IPv6地址。 数据来源：全网规划 取值范围：IPv6地址类型。 默认值：无 配置原则：无                   |
| PORT      | CG端口号     | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPV4” 或 “IPV6”时为可选参数。 参数含义：CG服务器的端口号。 数据来源：全网规划 取值范围：整数类型，取值范围为1024～65535。 默认值：无 配置原则：无 |

#### 使用实例

将IP地址为192.168.0.2，端口号为25009的CG服务器删除：

```
RMV CG:IPVERSION=IPV4, IPV4ADDR="192.168.0.2",PORT=25009;
```
