# 更新CG FTP密码（UPL CGFTPPWD）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：NCG**

该命令用于更新FTP PULL分发任务的密码为不可逆加密方式存储。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                        |
|:-------|:-------|:----------------------------------------------------------------------------|
| INPUT  | 输入     | 可选必选说明：必选参数 参数含义：该参数用于指定输入参数 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～128 默认值：无 配置原则：无 |

#### 使用实例

执行UPL CGFTPPWD更新FTP PULL分发任务的密码为不可逆加密方式存储：

```
UPL CGFTPPWD: INPUT="ncg";
```
