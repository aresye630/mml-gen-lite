# 查询基于ARP的Paging消息在流控期间放通的优先级（LST NGPAGINGARPPRI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询基于ARP的Paging消息在流控期间放通的优先级。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                          |
|:-------|:-------|:------------------------------------------------------------------------------|
| ARP    | ARP数值  | 可选必选说明：可选参数  参数含义：该参数用于指定ARP。  数据来源：本端规划  取值范围：整数类型，取值范围是1~15。  默认值：无  配置原则：无 |

## 使用实例

查询基于ARP的Paging消息在流控期间放通的优先级，执行如下命令：

```
%%LST NGPAGINGARPPRI:;%%
RETCODE = 0  操作成功

结果如下
--------
ARP数值  优先级                 

1        高  
2        高  
(结果个数 = 2)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                       |
|:--------|:----------------------------|
| ARP数值   | 该参数用于指定ARP。                 |
| 优先级     | 该参数用于指定Paging消息在流控期间放通的优先级。 |
