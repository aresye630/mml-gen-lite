# 查询节点资源告警阈值(LST NODERESTHD)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明
- 参考信息

## 命令功能

该命令用于查询节点资源告警阈值。

## 注意事项

无。

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                |
|:-------------|:-------|:------------------------------------------------------------------------------------|
| LST_RES_TYPE | 资源类型   | 可选必选说明：可选参数。 参数含义：标识要查询的资源类型。 取值范围： “S_CORE(CPU共享核)”“I_CORE(CPU隔离核)” 默认值：无。 配置原则：无。 |

## 使用实例

查询节点资源告警阈值信息：

```
%%LST NODERESTHD:;%%
RETCODE = 0  操作成功

CPU核告警阈值信息
-----------------
资源类型   开关  触发阈值  触发连续次数  恢复阈值  恢复连续次数  

CPU共享核  关闭  85%       3             80%       3            
CPU隔离核  开启  95%       3             85%       3             
(结果个数 = 2)

---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息，输出项如表1 输出项说明所示。

命令执行异常，请联系华为技术支持处理。输出错误码说明如表2 错误码列表所示。

| 输出项名称   | 输出型解释                                                                                                  |
|:--------|:-------------------------------------------------------------------------------------------------------|
| 资源类型    | 资源类型。 取值范围： “CPU共享核”“CPU隔离核”                                                                           |
| 开关      | 对应资源类型的告警检测开关。 取值范围： “开启”：在“资源类型”为“CPU共享核”或“CPU隔离核”时，当节点的CPU核使用率超阈值会上报ALM-135556 CPU核过载告警。“关闭”：关闭检测开关。 |
| 触发阈值    | 触发告警的阈值。                                                                                               |
| 触发连续次数  | 触发告警的连续检测次数。                                                                                           |
| 恢复阈值    | 恢复告警的阈值。                                                                                               |
| 恢复连续次数  | 恢复告警的连续检测次数。                                                                                           |

|   错误码 | 错误码解释        | 原因分析   | 处理建议       |
|------:|:-------------|:-------|:-----------|
| 20002 | 查询mk失败       | 内部错误。  | 请联系华为技术支持。 |
| 20010 | gauss服务状态不正确 | 内部错误。  | 请联系华为技术支持。 |
