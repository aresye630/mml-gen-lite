# 查询S1-U黑名单参数(LST S1UBLACKLSTPARA)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

此命令用于查询S1-U IP地址黑名单参数。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询S1-U黑名单参数：

LST S1UBLACKLSTPARA:;

```
%%LST S1UBLACKLSTPARA:;%% 
RETCODE = 0  操作成功  

输出结果如下： 
-------------- 
  发送黑名单策略  =  发送 
异常日志打印开关  =  打印
(结果个数 = 1)

---    END
```

**输出结果说明**

参见**SET S1UBLACKLSTPARA**的参数说明。
