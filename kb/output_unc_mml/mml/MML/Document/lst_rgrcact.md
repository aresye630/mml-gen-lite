# 查询RG级异常返回码处理动作（LST RGRCACT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于查询RG级异常返回码的处理动作配置。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                         |
|:------------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CCTMPLTNAME | 融合计费模板名称 | 可选必选说明：可选参数  参数含义：该参数用于指定融合计费模板名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。不区分大小写。  默认值：无  配置原则：  该参数使用ADD CCT命令配置生成。                                                                                                                                                                                             |
| RCCODE      | RG级异常返回码 | 可选必选说明：可选参数  参数含义：该参数用于指定RG级异常返回码。  数据来源：全网规划 取值范围： “DEFAULT（缺省值）”：当收到配置指定之外的结果码时需要执行的动作。“SERVICEDENIED（因终端用户限制拒绝服务）”：因为终端用户业务限制而拒绝服务。“QUOTAMNOTAPPL（转离线计费）”：业务不再做配额管理。“QUOTALIMITRCH（配额不足）”：配额不足。“SERVICEREJECT（拒绝服务）”：拒绝服务请求，以终止请求信用的服务。“USERUNKNOWN（未知用户）”：未知用户。“RATINGFAILED（计费失败）”：计费失败。  默认值：无  配置原则：无 |

## 使用实例

查询全局融合计费模板的所有RG级异常返回码处理动作：

```
%%LST RGRCACT: CCTMPLTNAME="global";%%
RETCODE = 0  操作成功

结果如下
--------
            融合计费模板名称  =  global
              RG级异常返回码  =  缺省值
          RG级异常返回码动作  =  阻塞业务，后续有Trigger触发时，上报Charging Data Request Update消息
  RG级阻塞处理时间间隔(分钟)  =  0
            RG级重新激活请求  =  不使能
RG级重定向处理重定向IPv4地址  =  0.0.0.0
RG级重定向处理重定向IPv6地址  =  ::
          用户保持时长(分钟)  =  0
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称             | 输出项解释                                                              |
|:------------------|:-------------------------------------------------------------------|
| 融合计费模板名称          | 该参数用于指定融合计费模板名称。                                                   |
| RG级异常返回码          | 该参数用于指定RG级异常返回码。                                                   |
| RG级异常返回码动作        | 该参数用于指定RG级异常返回码的处理动作。                                              |
| RG级阻塞处理时间间隔(分钟)   | 该参数用于指定RG级异常返回码阻塞动作的业务阻塞时间。从阻塞开始经过配置时长以后，业务再来时可以重新触发配额申请。          |
| RG级重新激活请求         | 该参数用于指示当用户因RG级异常结果码激活失败或更新失败时，SMF是否通知用户重新激活。                       |
| RG级重定向处理重定向IPv4地址 | 该参数用于指定RG级异常返回码重定向动作的IPv4地址。                                       |
| RG级重定向处理重定向IPv6地址 | 该参数用于指定RG级异常返回码重定向动作的IPv6地址。                                       |
| 用户保持时长(分钟)        | 该参数用于指定RG级异常返回码动作是CONTINUE时，允许用户保持业务的时长。超出该时长则去活用户。当取值为0时，不主动去活用户。 |
