# 查询TAI组性能统计对象成员（LST PERFTAIGROUPMEM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C、SMF**

该命令用于查询指定TAI组性能统计对象内的TAI成员。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                     |
|:-------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TAIGROUPNAME | TAI组名  | 可选必选说明：可选参数  参数含义：该参数用于标识基于TAI组的性能统计对象名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~255。不区分大小写，不支持空格及“\”。 TAI组性能统计对象名称通过ADD PERFTAIGROUP命令创建。  默认值：无  配置原则：无                                                       |
| BEGINTAI     | 起始TAI  | 可选必选说明：可选参数  参数含义：该参数用于表示TAI组所包含的TAI起始值。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是9~12。TAI由MCC、MNC和TAC组成。其中MCC为3位数字，MNC为2个或者3位数字，填写时请遵循实际长度；TAC编码为16进制数，S1类型TAC固定为4位，若不足则左起补0；N2类型TAC固定为6位，若不足则左起补0。  默认值：无  配置原则：无 |
| ENDTAI       | 终止TAI  | 可选必选说明：可选参数  参数含义：该参数用于表示TAI组所包含的TAI结束值。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是9~12。TAI由MCC、MNC和TAC组成。其中MCC为3位数字，MNC为2个或者3位数字，填写时请遵循实际长度；TAC编码为16进制数，S1类型TAC固定为4位，若不足则左起补0；N2类型TAC固定为6位，若不足则左起补0。  默认值：无  配置原则：无 |

## 使用实例

当需要查询所有TAI组性能统计对象成员，执行如下命令：

```
LST PERFTAIGROUPMEM:;
RETCODE = 0  操作成功。

结果如下
------------------------
  TAI组名  =  huawei
TAI组类型  =  S1TAC
  起始TAI  =  100000000
  终止TAI  =  10000FFFF
(结果个数 = 1)
```

| 输出项名称   | 输出项解释                   |
|:--------|:------------------------|
| TAI组名   | 该参数用于标识基于TAI组的性能统计对象名称。 |
| TAI组类型  | 该参数用于指定TAI组类型。          |
| 起始TAI   | 该参数用于表示TAI组所包含的TAI起始值。  |
| 终止TAI   | 该参数用于表示TAI组所包含的TAI结束值。  |
