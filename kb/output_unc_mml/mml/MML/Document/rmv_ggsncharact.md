# 删除GGSN属性配置信息(RMV GGSNCHARACT)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用于删除GGSN属性配置信息表中GGSN属性的记录。

#### 注意事项

- 该命令执行后立即生效。
- 删除记录后，系统会继续查找最匹配的记录，采用最匹配的记录的配置值。
- 删除记录前需要确认指定GGSN网元的功能，以免因与实际设备不兼容而导致流程失败。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称         | 参数说明                                                                                                                                                                                                                                                 |
|:---------|:-------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RANGE    | 对端设备范围       | 可选必选说明：必选参数 参数含义：该参数用于指定需要设置属性信息的对端GGSN范围。 取值范围：“Gn_GGSN（Gn接口GGSN）”“Gp_GGSN（Gp接口GGSN）”、“SPECIAL_GGSN（指定GGSN）” 默认值： 无                                                                                                                                 |
| IPT      | IP地址类型       | 可选必选说明：条件必选参数 参数含义：该参数用于指定GGSN信令面IP地址类型。 前提条件：只有在“RANGE”配置为“SPECIAL_GGSN（指定GGSN）”时，该参数生效。 取值范围：“IPV4(IPV4)”“IPV6(IPV6)” 默认值：无                                                                                                                        |
| GGSNIPV4 | GGSN的信令面IP地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定GGSN信令面IPv4地址。 前提条件：只有在“IPT”配置为“IPV4”时，才需要配置该类型的IP地址。 取值范围：0.0.0.1～255.255.255.254 默认值：无 配置原则：有效的IPv4地址不能为环回地址（127.x.y.z）。有效的IPv4地址必须是A、B或者C类地址。                                                                           |
| MASKV4   | 掩码           | 可选必选说明：条件必选参数 参数含义：该参数用于指定对端GGSN的信令面IPv4地址的掩码。 前提条件：只有在“IPT”配置为“IPV4”时，才需要配置该参数。 取值范围：0.0.0.1～255.255.255.255 默认值： 无  说明： 输入的掩码要求对应的二进制值1和1之间不允许存在0。例如：“255.255.0.0”是有效掩码；“123.123.123.123”是无效掩码。因为123对应的二进制为“1111011”，1之间存在0。                       |
| GGSNIPV6 | GGSN的信令面IP地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定GGSN信令面IPv6地址。 前提条件：只有在“IPT”配置为“IPV6”时，才需要配置该类型的IP地址。 取值范围：::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 配置原则：IPV6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址（::1）、链路本地地址（FE80::/10）和组播地址（FF00::/8）。 |
| MASKV6   | 子网前缀长度       | 可选必选说明：条件必选参数 参数含义：该参数用于指定子网前缀的长度。 前提条件：只有在“IPT”配置为“IPV6”时，才需要配置该参数。 取值范围：1～128（数值型） 默认值： 无                                                                                                                                                          |

#### 使用实例

数据配置错误或者指定的GGSN已经不存在，需要删除IP地址类型为“IPv4”，IP地址为"192.168.168.12"，掩码为"255.255.255.255"的GGSN的数据：

RMV GGSNCHARACT: RANGE=SPECIAL\_GGSN, IPT=IPV4, GGSNIPV4="192.168.168.12", MASKV4="255.255.255.255";
