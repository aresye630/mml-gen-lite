# 查询CP GTP-U地址（LST CPGTPUADDR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C、SMF、GGSN**

该命令用于查询与UPF对接的用户面本端地址。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                 |
|:----------|:-------|:-----------------------------------------------------------------------------------------------------|
| IPVERSION | IP地址类型 | 可选必选说明：可选参数  参数含义：该参数用于指定与UPF对接的本端GTP-U IP地址类型。  数据来源：全网规划 取值范围： IPV4（IPv4）IPV6（IPv6）  默认值：无  配置原则：无 |

## 使用实例

查询所有与UPF对接的本端GTP-U地址：

```
%%LST CPGTPUADDR:;%%
RETCODE = 0  操作成功

结果如下
------------------------
IP地址类型  =  IPv4
  IPv4地址  =  192.168.0.20
  IPv6地址  =  ::
   VPN名称  =  _public_
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                          |
|:--------|:-------------------------------|
| IP地址类型  | 该参数用于指定与UPF对接的本端GTP-U IP地址类型。  |
| IPv4地址  | 该参数用于指定与UPF对接的本端GTP-U IPv4地址。  |
| IPv6地址  | 该参数用于指定与UPF对接的本端GTP-U IPv6地址。  |
| VPN名称   | 该参数用于指定与UPF对接的本端GTP-U使用的VPN名称。 |
