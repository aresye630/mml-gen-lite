#### 命令功能

**适用网元：SGSN、MME**

该命令用于遇到系统内部通信消息处理有问题时，查询通信统计。

#### 注意事项

当只输入必选参数时，由于输出结果内容过多，会导致在结果输出区域的“通用维护”页签中无法显示全部内容，建议在结果输出区单击右键选用“重定向”输出。该命令为调测命令，用于华为技术支持定位问题，如需使用，请联系华为技术支持。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

| SOCKIDX     | Socket索引 | 可选必选说明：条件必选参数 参数含义：该参数用于指定查询通信统计的Socket索引。 前提条件：该参数在“统计类型”配置为“SOCK_IDX（SOCK索引）”时生效。 数据来源：无。 取值范围：0~300 默认值： 无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| MSGID       | 兼容消息ID   | 可选必选说明：条件必选参数 参数含义：该参数用于指定查询通信统计的兼容消息ID。 前提条件：该参数在“统计类型”配置为“COMPAT_MSG_ID（兼容消息ID）”时生效。 数据来源：无。 取值范围：0~65535 默认值： 无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |

#### 使用实例

查询USN\_SP\_RU\_0065下UPP进程CDR消息流的通信统计：

DSP COMMSTAT: RUNAME="USN\_SP\_RU\_0065", PROCTYPE=UPP, PROCNO=0, MSGSTATTYPE=MSG\_FLOW, MSGFLOW=CDR, SERVICETYPE="USN\_VNFC";

```
%%DSP COMMSTAT: RUNAME="USN_SP_RU_0065", PROCTYPE=UPP, PROCNO=0, MSGSTATTYPE=MSG_FLOW, MSGFLOW=CDR, SERVICETYPE="USN_VNFC";%%
RETCODE = 0  操作成功。
操作结果如下
--------------
  RU名称    =  USN_SP_RU_0065
  进程类型  =  UPP
进程序列号  =  0
  统计类型  =  Msg flow type
  统计信息  =  NULL
(结果个数 = 1)
---    END
```
