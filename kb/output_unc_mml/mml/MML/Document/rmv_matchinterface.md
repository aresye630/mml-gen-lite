# 删除出接口匹配路由策略（RMV MATCHINTERFACE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除出接口匹配路由策略。

#### 注意事项

- 该命令执行后立即生效。
- 配置该命令前，必须已经配置了指定路由策略的名字以及该策略下的节点。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                      |
|:-------------|:--------|:--------------------------------------------------------------------------------------------------------------------------|
| POLICYNAME   | 路由策略名字  | 可选必选说明：必选参数 参数含义：该参数用于指定路由策略名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无                                                  |
| NODESEQUENCE | 路由策略节点号 | 可选必选说明：必选参数 参数含义：该参数用于指定路由策略节点号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无                                                  |
| IFNAME       | 接口名字    | 可选必选说明：必选参数 参数含义：该参数用于指定接口名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则： 设备必须存在该接口，不区分大小写。通过LST INTERFACE命令查看当前已存在的接口。 |

#### 使用实例

取消路由策略a，节点10的匹配条件，匹配路由出接口NULL0：

```
RMV MATCHINTERFACE:POLICYNAME="a",NODESEQUENCE=10,IFNAME="NULL0";
```
