# 增加漫游切片默认映射配置（ADD AMFDFTNSMAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于增加漫游切片默认映射配置。在漫游场景下，不同运营商对切片的定义可能不同，在处理漫游切片业务时，需要把归属地切片映射为拜访地切片，以便完成漫游业务。

## 注意事项

- 该命令执行后只对新激活用户生效。

- 最多可输入1024条记录。
- ADD AMFROAMNSMAP配置的切片映射规则优先级高于本命令配置的缺省映射规则。
- 基于HMCC和HMNC配置的漫游切片默认映射规则优先级高于基于VMCC和VMNC配置的漫游切片默认映射规则。
- 增加漫游切片映射配置时，对已注册用户不会立即生效。如果需要立即生效，请先执行STR NGUSRBATCHDEREG命令对漫游用户启动批量去注册任务，并指定去注册类型为需要重新注册，触发用户重新注册，获取最新切片映射关系。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称        | 参数说明                                                                                                                                                |
|:---------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| CTRLMODE | 控制模式        | 可选必选说明：可选参数  参数含义：该参数用于指定基于用户归属PLMN还是拜访地PLMN进行切片映射。  数据来源：全网规划 取值范围： VPLMN（拜访地PLMN）HPLMN（归属地PLMN）  默认值：VPLMN  配置原则：无                                |
| VMCC     | 拜访地移动国家码    | 可选必选说明：该参数在"CTRLMODE"配置为"VPLMN"时为条件必选参数。  参数含义：该参数用于指定拜访地移动国家码。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。  默认值：无  配置原则：无                                       |
| VMNC     | 拜访地移动网号     | 可选必选说明：该参数在"CTRLMODE"配置为"VPLMN"时为条件必选参数。  参数含义：该参数用于指定拜访地移动网号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。  默认值：无  配置原则：无                                    |
| HMCC     | 归属地移动国家码    | 可选必选说明：该参数在"CTRLMODE"配置为"HPLMN"时为条件必选参数。  参数含义：该参数用于指定归属地移动国家码。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。  默认值：无  配置原则：无                                       |
| HMNC     | 归属地移动网号     | 可选必选说明：该参数在"CTRLMODE"配置为"HPLMN"时为条件必选参数。  参数含义：该参数用于指定归属地移动网号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。  默认值：无  配置原则：无                                    |
| VSST     | 拜访地默认切片服务类型 | 可选必选说明：必选参数  参数含义：该参数用于指定拜访地默认切片服务类型。  数据来源：全网规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无                                                              |
| VSD      | 拜访地默认切片细分标识 | 可选必选说明：可选参数  参数含义：该参数用于指定拜访地默认切片细分标识。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。该参数只能由字母（A-F或者a-f）、数字（0-9）组成，且大小写不敏感，转大写处理。  默认值：无  配置原则：  当不配置此参数值时，默认为FFFFFF。 |

## 使用实例

如果需要增加“控制模式”为“拜访地PLMN”、“拜访地移动国家码”为“123”、“拜访地移动网号”为“45”、“拜访地默认切片服务类型”为“8”、“拜访地默认切片细分标识”为“ABC123”的漫游切片默认映射配置，执行如下命令：

```
ADD AMFDFTNSMAP: CTRLMODE=VPLMN, VMCC="123", VMNC="45", VSST=8, VSD="ABC123";
```
