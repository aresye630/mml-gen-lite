# 删除流控参数（RMV FCPARAM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除指定微服务实例的流控参数。

## 注意事项

该命令执行后下次流控时生效。

#### 操作用户权限

G\_1，管理员级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                    |
|:------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 服务类型   | 可选必选说明：必选参数  参数含义：该参数用于指定微服务实例的服务类型。 可以使用DSP DBGDATAEX命令查询到各个服务对应的SERVICETYPE参数。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无                                                                                                                                                                                                                                                    |
| SERVICEID   | 实例组ID  | 可选必选说明：必选参数  参数含义：该参数用于指定微服务实例的实例ID。可以使用DSP DBGDATAEX命令查询到各个服务对应的SERVICEID的值。注意这里serviceid已经废弃改为groupid，因为原有serviceid为主键禁止更新。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无                                                                                                                                                                                                   |
| CASEID      | 流控套餐ID | 可选必选说明：必选参数  参数含义：该参数用于指定微服务实例内的流控套餐ID。每个微服务实例可以配置多个流控套餐，每个流控套餐对应唯一的一个ID。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无                                                                                                                                                                                                                                                       |
| PARAMCAT    | 参数类别   | 可选必选说明：必选参数  参数含义：该参数用于指定本次配置的参数类别。  数据来源：本端规划 取值范围： GENERAL（常用参数）WEIGHTS（权重）THRESHOLD（阈值）TARGETCPU（目标cpu）OVERLOADLEVEL（过载级别）STOPALGO（停控算法）BPBACKEND（后端反压）BPFRONTEND（前端反压）WALPARAMETER（WAL算法参数）GCCPUCONFIG（GC时的CPU平滑策略配置）  默认值：无  配置原则：  当取值为“GERNERAL(常用参数)”时，可以配置最小令牌数和最大令牌数，通过修改令牌数来控制业务消息的数量，从而达到流控的目的；当取值为“WEIGHTS(权重)”时，可以配置业务权重获取方式、优先级权重0~15、预期系数0~15。修改权重和预期系数，可以控制被流控的消息的优先级。 |

## 使用实例

删除微服务类型为UesmCtrlSvc、微服务实例ID为999、流控套餐ID为0的常用参数。

```
RMV FCPARAM: SERVICETYPE="UesmCtrlSvc", SERVICEID=999, CASEID=0, PARAMCAT=GENERAL;
```
