# 增加漫游跨PLMN场景间接路由配置（ADD ROAMSCPFUNCSW）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、CBC、CBCF**

该命令用于增加漫游跨PLMN场景间接路由配置。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入10条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                         |
|:-----------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LNFTYPE    | 本端NF类型   | 可选必选说明：必选参数  参数含义：该参数用于指定本端NF的类型。  数据来源：全网规划 取值范围： “AMF（AMF）”：NF类型为AMF“SMF（SMF）”：NF类型是SMF  默认值：无  配置原则：无                                                                                                                                                                                                                                     |
| PNFTYPE    | 对端NF类型   | 可选必选说明：必选参数  参数含义：该参数用于指定对端NF的类型。  数据来源：全网规划 取值范围： “UDM（UDM）”：NF类型是UDM“AUSF（AUSF）”：NF类型为AUSF“AMF（AMF）”：NF类型为AMF“SMF（SMF）”：NF类型为SMF“EIR（5G-EIR）”：NF类型为5G-EIR  默认值：无  配置原则：无                                                                                                                                                                   |
| SCPDISCSW  | 服务发现代理开关 | 可选必选说明：必选参数  参数含义：该参数用于设置漫游跨PLMN场景下是否使用SCP代理NF的服务发现功能，如果设置为ON，则漫游跨PLMN场景下指定的本端和对端类型之间的NF服务发现功能通过SCP间接实现。注意，不是通过直接和SCP进行服务发现交互，而是在业务消息交互的过程中，SCP解码业务消息获得用户号码等信息进行消息路由或抽取业务消息里携带的服务发现头到NRF进行服务发现。  数据来源：全网规划 取值范围： OFF（OFF）ON（ON）  默认值：无  配置原则：无                                                                                               |
| DIALTESTSW | 拨测开关     | 可选必选说明：可选参数  参数含义：该参数用于指定是否开启Model-D或Model-C模式的业务拨测阶段。 拨测只支持基于SUPI号段、GPSI号段、ROUTINGIND及PLMN控制。 Model-D拨测支持的对端NF类型只包括：UDM、AUSF。 Model-C拨测目前支持的本端NF类型只包括：AMF、SMF。 当该参数取值为ON时，只针对通过ADD PNFSUPI、ADD PNFGPSI、ADD PNFROUTEIND及ADD PNFPLMN命令配置的用户生效Model-D或Model-C模式，并且NFINSTANCEID配置为"sbidialtest"。  数据来源：本端规划 取值范围： OFF（OFF）ON（ON）  默认值：无  配置原则：无 |

## 使用实例

运营商需要增加漫游跨PLMN场景下本端AMF与对端UDM的间接路由功能配置，允许本端AMF与对端UDM通过SCP ModeC的方式通信。

```
ADD ROAMSCPFUNCSW: LNFTYPE=AMF, PNFTYPE=UDM, SCPDISCSW=OFF;
```
