# 查询字符串Monitoring-Key（LST STRINGMK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、GGSN**

该命令用于查询字符串类型的Monitoring-Key。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询当前配置的stringmk：

```
LST STRINGMK:;
RETCODE = 0  操作成功。

结果如下
--------
字符串Monitoring-Key    监控属性值

test                     100       
test1                    200       
(结果个数 = 2)
---    END
```

## 输出结果说明

| 输出项名称             | 输出项解释                        |
|:------------------|:-----------------------------|
| 字符串Monitoring-Key | 该参数用于配置字符串类型的Monitoring-Key。 |
| 监控属性值             | 设置监控属性的ID。                   |
