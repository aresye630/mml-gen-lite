# 删除5G TA群组成员（RMV NGTAGPMEM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除跟踪区群组成员记录。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                              |
|:---------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
| NGTAGPID | 跟踪区群组标识  | 可选必选说明：必选参数  参数含义：该参数用于指定跟踪区群组标识。该参数已经通过ADD NGTAGP命令中的NGTAGPID参数配置。  数据来源：本端规划  取值范围：整数类型，取值范围是1~256。“跟踪区群组标识”已经通过ADD NGTAGP配置。  默认值：无  配置原则：无    |
| BGNTAC   | 跟踪区编码起始值 | 可选必选说明：必选参数  参数含义：该参数用于表示跟踪区编码的起始值。  数据来源：本端规划  取值范围：字符串类型，输入长度是6。TAC编码为16进制数，按照字符串格式输入，字符串长度为6，只能由数字（0-9），字母（A-F、a-f）组成。字母大小写不敏感。  默认值：无  配置原则：无 |

## 使用实例

删除一个TA群组成员，TA群组标识为1，群组成员的跟踪区域码为123456。

```
RMV NGTAGPMEM: NGTAGPID=1, BGNTAC="123456";
```
