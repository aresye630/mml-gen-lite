# 增加NRF协议参数（ADD NRFPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

OAUTH2SWITCH配置为ON时，如果端到端不支持OAUTHTOKEN功能，可能会导致业务呼损，建议配置为OFF。

**适用NF：AMF、SMF、NRF、NSSF、SMSF、NCG、CBCF**

该命令用于增加NRF协议相关的配置信息。与NRF对接的时候使用，可用于设置等待时长和最大重传次数等参数。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入2048条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称         | 参数说明                                                                                                                                                                    |
|:----------------|:-------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NRFINSTANCENAME | NRF实例名称      | 可选必选说明：必选参数  参数含义：该参数用于指定NRF实例名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~38。  默认值：无  配置原则：  本参数取值与ADD NRF命令中的“NRF实例名称”参数取值保持一致时，关联关系生效。                                        |
| WAITINTERVAL    | 等待时长         | 可选必选说明：可选参数  参数含义：该参数用于指定NF向NRF发起请求消息后，等待响应的最大时长。  数据来源：全网规划  取值范围：整数类型，取值范围是0~60，单位是秒。  默认值：5  配置原则：无                                                                  |
| MAXRETRYTIMES   | 最大重传次数       | 可选必选说明：可选参数  参数含义：该参数用于指定NF等待NRF响应超时后，重新发起请求消息的最大次数。  数据来源：全网规划  取值范围：整数类型，取值范围是0~65535。  默认值：3  配置原则：无                                                                 |
| HEARTBEATTIMER  | 心跳时长         | 可选必选说明：可选参数  参数含义：向NRF建议的心跳时长，实际心跳以NRF决策为准。  数据来源：全网规划  取值范围：整数类型，取值范围是0~65535，单位是秒。  默认值：60  配置原则：  如果NRF的response中携带心跳时长，以NRF返回的心跳间隔为准。心跳断开后的快速心跳探测周期以WAITINTERVAL为准。 |
| LOADCARRYINHB   | 心跳是否携带Load信息 | 可选必选说明：可选参数  参数含义：该参数用于指定是否在心跳消息中携带NF的Load信息。  数据来源：对端协商  取值范围： TRUE(TRUE)FALSE(FALSE)  默认值：FALSE  配置原则：无                                                               |
| SUBSCRISWITCH   | 订阅流程开关       | 可选必选说明：可选参数  参数含义：该参数用于指定NF是否能发起订阅流程。  数据来源：全网规划 取值范围： OFF（OFF）ON（ON）  默认值：OFF  配置原则：无                                                                                  |
| OAUTH2SWITCH    | OAUTH2鉴权开关   | 可选必选说明：可选参数  参数含义：该参数用于指定NF是否开启Oauth2鉴权。  数据来源：全网规划 取值范围： OFF（OFF）ON（ON）  默认值：ON  配置原则：无                                                                                |

## 使用实例

设置实例名称为NRF\_Instance\_0的NRF的等待时长为5秒，最大重传次数为3次，打开订阅开关，打开OAUTH2开关：

```
ADD NRFPARA: NRFINSTANCENAME="NRF_Instance_0", WAITINTERVAL=5, MAXRETRYTIMES=3, SUBSCRISWITCH=ON, OAUTH2SWITCH=ON;
```
