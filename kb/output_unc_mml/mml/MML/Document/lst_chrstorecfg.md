#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询系统上配置的ucf是否进行CHR单据本地存储的策略。

#### 注意事项

只有在“CHR存储开关”参数配置为“ON(开)”时，“存储类型”才会被输出。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询CHR存盘配置：

`LST CHRSTORECFG:;`

```
%%LST CHRSTORECFG:;%%
RETCODE = 0  操作成功。

输出结果如下
--------------
    CHR存储开关  =  开
       存储类型  =  仅存储
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见**SET CHRSTORECFG**的参数说明。
