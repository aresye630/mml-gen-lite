# 查询内部升级配置表（LST UPDATECTRLCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询内部升级配置表。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询内部升级配置表，执行如下命令：

```
%%LST UPDATECTRLCFG:;%%
RETCODE = 0  操作成功

结果如下
------------------------
升级状态 = 0
低版本号 = 0
高版本号 = 100
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释   |
|:--------|:--------|
| 升级状态    | 升级状态。   |
| 低版本号    | 低版本号。   |
| 高版本号    | 高版本号。   |
