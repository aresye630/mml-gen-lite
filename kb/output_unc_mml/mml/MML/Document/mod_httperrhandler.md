# 修改间接路由代理故障重选配置（MOD HTTPERRHANDLER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于修改间接路由代理故障重选配置。

## 注意事项

- 该命令执行后立即生效。

- 当对端网元是UDM时，状态码为429/500/501/502/503时，默认支持间接路由代理故障重选。
- 当对端网元是SMF或AMF时，状态码为429/500/501/502/503/504时，默认支持间接路由代理故障重选。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称         | 参数说明                                                                                                                                                                                                                       |
|:-------------|:-------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFTYPE       | 对端网络功能类型     | 可选必选说明：必选参数  参数含义：该参数用于指定对端网元类型。  数据来源：本端规划 取值范围： “SMF（SMF）”：表示对端网元为SMF。“UDM（UDM）”：表示对端网元是UDM。“AMF（AMF）”：表示对端网元是AMF。  默认值：无  配置原则：无                                                                                        |
| STATUSCODE   | 状态码          | 可选必选说明：必选参数  参数含义：该参数用于指定状态码。  数据来源：本端规划  取值范围：整数类型，取值范围是0~1000。  默认值：无  配置原则：  当配置为0，且“间接路由代理故障处理开关（RESENDSWITCH）”参数为WILDCARDMODELD时，表示在Model D模式下，任意状态码满足重选条件（近端SCP产生错误码）后可以支持故障重选。                                      |
| RESENDSWITCH | 间接路由代理故障处理开关 | 可选必选说明：必选参数  参数含义：该参数用于控制开启和关闭间接路由代理故障处理功能。  数据来源：本端规划 取值范围： DISABLE（不使能）ENABLE（使能）WILDCARDMODELD（Model D模式下通配使能）  默认值：无  配置原则：  当配置为WILDCARDMODELD，且“状态码（STATUSCODE）”参数为0时，表示在Model D模式下，任意状态码满足重选条件（近端SCP产生错误码）可以支持故障重选。 |

## 使用实例

修改对端为UDM网络功能，状态码504的间接路由代理故障重选配置为开启。

```
MOD HTTPERRHANDLER:NFTYPE=UDM,STATUSCODE=504,RESENDSWITCH=ENABLE;
```
