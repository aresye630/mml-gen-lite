# 查询智能分流DNN（LST SUBSMARTDNN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询智能分流DNN。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询智能分流DNN，执行如下命令：

```
%%LST SUBSMARTDNN:;%%
RETCODE = 0  操作成功

结果如下
------------------------
智能分流DNN  =  huawei.com
(Number of results = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释            |
|:--------|:-----------------|
| 智能分流DNN | 该参数用于指定智能分流的DNN。 |
