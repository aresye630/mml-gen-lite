# 增加N4接口地址映射关系（ADD CPPFCPNATIP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、SGW-C、PGW-C**

该命令用于配置N4接口本端CP端点的IP地址和经过信令安全网关映射后的IP地址映射关系，用于替换CP F-SEID中的IP地址。当需要保证SMF和UPF上报的CP F-SEID中的IP地址保持一致用于标识是同一个用户时，需要使用该配置。

## 注意事项

- 该命令执行后立即生效。

- 该功能仅限于测试。
- 仅支持4/5G，不支持2/3G和WLAN。

- 最多可输入2048条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

新增本端CP端点IP地址为10.1.1.1，代理UP路径的IP地址为10.2.2.2的N4接口地址映射关系，经过信令安全网关映射后的CP端点IP地址为10.1.2.1：

```
ADD CPPFCPNATIP: CPIPTYPE=IPv4, CPADDRIPV4="10.1.1.1", UPIPTYPE=IPv4, UPADDRIPV4="10.2.2.2", CPPROXYIPTYPE=IPv4, CPPROXYADDRIPV4="10.1.2.1";
```
