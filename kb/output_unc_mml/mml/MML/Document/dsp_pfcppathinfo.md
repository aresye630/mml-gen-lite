# 显示PFCP链路相关数据（DSP PFCPPATHINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF、SGW-C、PGW-C、GGSN**

该命令用于查询PFCP链路相关数据，包括链路状态，进入迁移、去活的开始时间，以及本端对端地址等信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                                                                                |
|:--------------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| QUERYTYPE     | 查询类型     | 可选必选说明：可选参数  参数含义：该参数用于指定查询类型。  数据来源：本端规划 取值范围： ALL（所有）UPINSTANCEID（UP实例标识）PATHIP（链路IP地址）  默认值：ALL  配置原则：无                                          |
| UPINSTANCEID  | UP实例标识   | 可选必选说明：该参数在"QUERYTYPE"配置为"UPINSTANCEID"时为条件必选参数。  参数含义：该参数用于指定UPF的实例标识。当需要查询指定UPF的路径信息时，可以指定该参数。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~50。  默认值：无  配置原则：无 |
| IPTYPE        | IP类型     | 可选必选说明：该参数在"QUERYTYPE"配置为"PATHIP"时为条件必选参数。  参数含义：该参数用于指示链路IP地址类型。  数据来源：本端规划 取值范围： IPV4（IPv4）IPV6（IPv6）  默认值：无  配置原则：无                              |
| LOCALIPV4ADDR | 本端IPv4地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPV4"时为条件必选参数。  参数含义：该参数用于指示本端IPv4地址（即CPPOINT命令中配置的IPv4地址）。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无                        |
| LOCALIPV6ADDR | 本端IPv6地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPV6"时为条件必选参数。  参数含义：该参数用于指示本端IPv6地址（即CPPOINT命令中配置的IPv6地址）。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无                        |
| PEERIPV4ADDR  | 对端IPv4地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPV4"时为条件必选参数。  参数含义：该参数用于指示对端IPv4地址（即PNFPROFILE命令中配置的IPv4地址）。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无                     |
| PEERIPV6ADDR  | 对端IPv6地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPV6"时为条件必选参数。  参数含义：该参数用于指示对端IPv6地址（即PNFPROFILE命令中配置的IPv6地址）。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无                     |
| PODNAME       | POD名称    | 可选必选说明：可选参数  参数含义：该参数用于指定需要查询的POD名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无                                                            |

## 输出结果说明

| 输出项名称    | 输出项解释                                                                            |
|:---------|:---------------------------------------------------------------------------------|
| UP实例标识   | 该参数用于指定UPF的实例标识。当需要查询指定UPF的路径信息时，可以指定该参数。                                        |
| 本端IPv4地址 | 该参数用于指示本端IPv4地址（即CPPOINT命令中配置的IPv4地址）。                                           |
| 本端IPv6地址 | 该参数用于指示本端IPv6地址（即CPPOINT命令中配置的IPv6地址）。                                           |
| 本端端口号    | 该参数用于指示本端端口号。                                                                    |
| 对端IPv4地址 | 该参数用于指示对端IPv4地址（即PNFPROFILE命令中配置的IPv4地址）。                                        |
| 对端IPv6地址 | 该参数用于指示对端IPv6地址（即PNFPROFILE命令中配置的IPv6地址）。                                        |
| 对端端口号    | 该参数用于指示对端端口号。                                                                    |
| VPN名称    | 该参数用于指示VPN实例名称。                                                                  |
| 链路状态     | 该参数用于指示链路状态。 取值说明： Unknown（未知）Normal（正常）Abnormal（故障）Silent（静默）SilentNormal（静默正常） |
| 去活开始时间   | 该参数用于指示该链路下会话去活开始时间。                                                             |
| 迁移开始时间   | 该参数用于指示该链路下会话迁移开始时间。                                                             |
| 惯性运行开始时间 | 该参数用于指示该链路下会话进入惯性运行状态开始时间。                                                       |
| 惯性运行状态   | 该参数用于指示该链路下会话是否进入惯性运行状态。 取值说明： TRUE(TRUE)FALSE(FALSE)                            |
| UPF支持的特性 | 该参数用于指示通过该链路连接的UPF支持的功能特性。取值来源于UP Function Features信元，具体参见3GPP TS 29.244。        |
