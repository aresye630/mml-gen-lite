# 删除BGP对等体分组（RMV UPDBGPPEERGROUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除IPv4或IPv6对等体分组。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                                   |
|:----------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------|
| VRFNAME   | VPN实例名称 | 可选必选说明：必选参数 参数含义：该参数用于指定用户所配置的BGP VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：使用LST BGPVRFAF命令查看可用BGP VPN。                   |
| AFTYPE    | 地址类型    | 可选必选说明：必选参数 参数含义：该参数用于指定对等体的地址类型。 数据来源：本端规划 取值范围：枚举类型。 ipv4uni：IPv4地址族。ipv4vpn：VPNv4地址族。ipv6uni：IPv6地址族。ipv6vpn：VPNv6地址族。 默认值：无 配置原则：无 |
| PEERADDR1 | 对等体1地址  | 可选必选说明：必选参数 参数含义：该参数用于指定分组的第一个对等体地址。 数据来源：对端协商 取值范围：IPv4或IPv6地址类型。 默认值：无 配置原则：无                                                        |
| PEERADDR2 | 对等体2地址  | 可选必选说明：必选参数 参数含义：该参数用于指定分组的第二个对等体地址。 数据来源：对端协商 取值范围：IPv4或IPv6地址类型。 默认值：无 配置原则：无                                                        |

#### 使用实例

删除名称为“vrf1”的BGP IPv4 VPN实例下对等体10.1.1.1和10.2.2.2分组：

```
RMV UPDBGPPEERGROUP:VRFNAME="vrf1",AFTYPE=ipv4uni,PEERADDR1="10.1.1.1",PEERADDR2="10.2.2.2";
```
