# 查询融合计费Proxy结果码处理动作（LST CCPRCACT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NCG**

该命令用于查询融合计费Proxy结果码处理动作。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称      | 参数说明                                                                                                                                            |
|:---------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------|
| RCTYPE   | RC类型      | 可选必选说明：可选参数  参数含义：该参数用于指定RC的类型。  数据来源：本端规划 取值范围： DEFAULT（针对未指定的异常返回码设置处理动作）VALUE（针对指定异常返回码设置处理动作）TIMEOUT（等待响应超时）LINKFAULT（链路不可达）  默认值：无  配置原则：无 |
| CODETYPE | 指定异常返回码类型 | 可选必选说明：该参数在"RCTYPE"配置为"VALUE"时为条件可选参数。  参数含义：该参数用于指定异常返回码的类型。  数据来源：本端规划  取值范围：整数类型，取值范围是300~999，65535，0。  默认值：无  配置原则：无                        |

## 使用实例

查询融合计费Proxy结果码处理动作：

```
LST CCPRCACT:;
RETCODE = 0  操作成功

结果如下
--------
            RC类型  =  针对指定的异常返回码设置处理动作
指定异常返回码类型  =  900
  Failover模板标识  =  ccpfot1
    代表对端不可用  =  FALSE
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称        | 输出项解释                           |
|:-------------|:--------------------------------|
| RC类型         | 该参数用于指定RC的类型。                   |
| 指定异常返回码类型    | 该参数用于指定异常返回码的类型。                |
| Failover模板标识 | 该参数用于指定融合计费Proxy Failover模板的名称。 |
| 代表对端不可用      | 该参数用于标识该指定异常返回码是否代表对端不可用。       |
