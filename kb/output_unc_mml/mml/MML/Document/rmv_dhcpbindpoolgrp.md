# 删除DHCP服务器组与地址池组绑定关系（RMV DHCPBINDPOOLGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于解除DHCP服务器组与地址池组的关联。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                       |
|:------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| POOLGRPNAME | 地址池组名称 | 可选必选说明：必选参数  参数含义：该参数用于指定地址池组名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~79。不支持空格及特殊字符“_”、“#”、“$”和“&”等，由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”，不区分大小写。  默认值：无  配置原则：  该参数使用ADD ADDRPOOLGRP命令配置生成。 |

## 使用实例

当需要解除DHCP服务器组与地址池组的关联时，需要使用该命令：

```
RMV DHCPBINDPOOLGRP:POOLGRPNAME="poolgrp1";
```
