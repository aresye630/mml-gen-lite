#### 命令功能

**适用NF：NCG**

该命令用于对CG的多对RU上的业务模块进行配置和维护管理。它包含添加、删除和查询业务模块命令，配置实现话单接收，分拣，转换，存储功能的模块，是CG核心业务处理部分。

#### 注意事项

- 该命令执行后，需在“MML命令行 - UNC”窗口执行“**RST VNFC**”命令重新启动系统才能生效。
- 该命令最大记录数为256。
- 每个RU上最多配置4个业务模块，否则有资源不足的风险。
- 每个AP最多可以接入300条链路，AP的链路接入数量可以通过执行CHK ACTRL命令获取。
- 当通过“**MOD SRVPARA**”配置业务RU约束为ON，本命令将无法在业务RU上添加配有234G格式引擎包的接入网元分组。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                                                                                                                |
|:-------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MNAME  | 模块名      | 可选必选说明：必选参数 参数含义：用于表示一个业务模块对象，全局唯一。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～15。 默认值：无 配置原则： 首先执行LST SERVICERUSTATE命令，查询出当前的RUID。该参数输入格式固定为'AP'接RUID_APID，APID值为1~4。例如：RUID为66时，该参数可以是“AP66_1”、“AP66_2”、“AP66_3”、“AP66_4”。不能输入的特殊字符请参考“特殊字符表”。 |
| AGID   | 接入网元分组标识 | 可选必选说明：必选参数 参数含义：用于区分不同域的接入网元。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则： 该值需要执行LST CDRPROC命令查询“接入网元分组标识”。如果没有符合要求的“接入网元分组标识”，还需执行ADD CDRPROC命令增加。不能输入的特殊字符请参考“特殊字符表”。                                                           |
| RUROLE | RU角色     | 可选必选说明：可选参数 参数含义：用于指定当前RU角色。 数据来源：本端规划 取值范围：枚举类型。 CONVERGE：汇聚RU。SERVICE：业务RU。 默认值：无。  说明： 如果BI收敛开关未开启，该参数默认值为空；如果BI收敛开关开启，该参数默认值动态判断：如果该MODULE所在RU配置了BI口IP或者RESERVEDIP，则默认值为汇聚RU，如果没有配置BI口IP或者RESERVEDIP，则默认值为业务RU。 配置原则：无。         |

#### 使用实例

增加一个“接入网元分组标识”为“PS\_GROUP\_1”的业务模块，示例如下：

```
ADD MODULE: MNAME="AP66_1", AGID="PS_GROUP_1";
```
