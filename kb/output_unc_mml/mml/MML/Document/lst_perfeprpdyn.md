# 查询EpRpDyn性能统计对象（LST PERFEPRPDYN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C、GGSN**

该命令用于查询EpRpDyn性能统计对象。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                                |
|:--------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INTERFACETYPE | 接口类型   | 可选必选说明：可选参数  参数含义：该参数用于指定EpRpDyn性能统计的接口类型。  数据来源：本端规划 取值范围： S5S8PGW（PGW-C S5/S8接口）S11SGW（SGW-C S11接口）S5S8SGW（SGW-C S5/S8接口）SXASGW（SGW-C Sxa接口）SXBPGW（PGW-C Sxb接口）SXGGSN（GGSN-C Sx接口）  默认值：无  配置原则：无 |

## 使用实例

查询接口类型为S5S8PGW的EpRpDyn对象，执行如下命令：

```
%%LST PERFEPRPDYN: INTERFACETYPE=S5S8PGW;%%
RETCODE = 0  操作成功

结果如下
--------
接口类型  =  PGW-C S5/S8接口
对象名称  =  pgw1
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                    |
|:--------|:-------------------------|
| 接口类型    | 该参数用于指定EpRpDyn性能统计的接口类型。 |
| 对象名称    | 该参数用于指定EpRpDyn性能统计对象名称。  |
