#### 命令功能

**适用网元：SGSN、MME、SMSF**

此命令用来查询信令网属性配置数据。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询已经设置的信令网属性：

```
LST SIGATTR:;
```

```
%%LST SIGATTR:;%%
RETCODE = 0  操作成功。
```
