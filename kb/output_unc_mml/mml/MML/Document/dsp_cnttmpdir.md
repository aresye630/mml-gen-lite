# 查询容器引擎临时目录（DSP CNTTMPDIR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询节点的容器引擎临时目录。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

若执行 **DSP CNTTMPDIR** 返回结果中某节点“详细信息”为“容器引擎未启动”，请联系华为技术支持。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                          |
|:-------|:-------|:----------------------------------------------------------------------------------------------|
| NODEIP | 节点IP   | 可选必选说明：可选参数。 参数含义：用于指示系统需要查询哪个节点的数据。 取值范围：不超过128位字符串。 默认值：无。 配置原则： 若不输入，则表示查询所有节点的容器引擎临时目录信息。 |

## 使用实例

1、查询所有节点配置信息：

```
%%DSP CNTTMPDIR:;%% 
RETCODE = 0  操作成功  
操作结果如下 
------------ 
节点IP           容器临时路径类型  详细信息    
10.0.0.0         DISK              成功       
10.0.0.1         DISK              成功       
10.0.0.2         DISK              成功      
(结果个数 = 3)  
---    END
```

2、查询“节点IP”为“10.0.0.0”的节点配置信息：

```
%%DSP CNTTMPDIR: NODEIP="10.0.0.0";%% 
RETCODE = 0  操作成功  
操作结果如下 
------------           
节点IP  =  10.0.0.0 
容器临时路径类型  =  DISK         
详细信息  =  成功 
(结果个数 = 1)  
---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。输出结果说明如表1所示。

命令执行异常，请联系华为技术支持处理。输出结果说明如表2所示。

| 输出项名称    | 输出项解释                                                                              |
|:---------|:-----------------------------------------------------------------------------------|
| 节点IP     | 节点网络地址。                                                                            |
| 容器临时路径类型 | 容器引擎临时路径类型。 取值范围： “DISK”：容器临时路径类型为硬盘类型。“TMPFS”：容器临时路径类型为内存类型。“UNKNOWN”：容器临时路径类型未知。 |
| 详细信息     | 用于返回本次查询的具体执行结果。 取值范围： “成功”“失败”“容器引擎未启动”                                           |

|    错误码 | 错误码解释     | 原因分析        | 处理建议         |
|-------:|:----------|:------------|:-------------|
| 130004 | 部分成功      | 部分节点查询失败。   | 请联系华为技术支持。   |
| 130013 | 操作失败      | 内部执行报错。     | 请联系华为技术支持。   |
| 130014 | 未知操作      | 不识别对应MML命令。 | 检查MML名称是否正确。 |
| 130015 | 没有符合条件的节点 | 没有找到对应的节点。  | 请检查节点IP是否正确。 |
| 130016 | 参数不合法     | 参数校验失败。     | 请检查参数是否填写正确。 |
