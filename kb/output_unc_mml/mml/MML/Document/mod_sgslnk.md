# 修改SGs链路(MOD SGSLNK)

- 命令功能

- 本地用户权限

#### 命令功能

**适用网元：MME**

此命令用于修改SGs链路配置对应的相关参数。

当需要修改SGs链路的“SGs链路名称”、“SCTP协议参数索引”和“交叉路径是否可用”的全部或者部分信息时，用此命令进行修改。

#### 注意事项

此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|:------------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LNK         | 链路索引       | 可选必选说明：必选参数 参数含义：待修改链路的索引。 数据来源：整网规划 取值范围：0~511 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| SGSLNKNM    | SGs链路名称    | 可选必选说明：可选参数 参数含义：待修改的SGs链路的名称。 数据来源：本端规划 取值范围：0~32位字符串 默认值：无 配置原则：建议取有实际意义的名称，以方便识别。例如“VLRconf”。                                                                                                                                                                                                                                                                                                                                                                                                              |
| SCTPINDX    | SCTP协议参数索引 | 可选必选说明：可选参数 参数含义：待修改所引用的SCTP协议参数索引。 前提条件：该参数已经增加，参见ADD SCTPPARA。 数据来源：整网规划 取值范围：0~65534 默认值：无  说明： 修改“SCTP协议参数索引”影响请参见ADD SCTPPARA。                                                                                                                                                                                                                                                                                                                                                                           |
| CROSSIPFLAG | 交叉路径是否可用   | 可选必选说明：可选参数 参数含义：待修改SCTP双归属的交叉路径是否可用。 数据来源：整网规划 取值范围：“NO(否)”“YES(是)” 默认值：无 配置原则：交叉路径会增加组网的复杂度，建议配置为交叉路径不可用。SCTP双归属下配置交叉路径不可用时，“本地IPv4地址1”与“VLRIPv4地址1”，“本地IPv4地址2”与“VLRIPv4地址2”两条路径可用，“本地IPv4地址1”与“VLRIPv4地址2”，“本地IPv4地址2”与“VLRIPv4地址1”两条路径不可用。SCTP双归属下配置交叉路径可用时，“本地IPv4地址1”与“VLRIPv4地址1”，“本地IPv4地址1”与“VLRIPv4地址2”，“本地IPv4地址2”与“VLRIPv4地址1”，“本地IPv4地址2”与“VLRIPv4地址2”四条路径均可用。  说明： 修改交叉路径是否可用将使链路的可靠性受到影响。若之前交叉路径可用，且“本地IPv4地址1”与“VLRIPv4地址1”，“本地IPv4地址2”与“VLRIPv4地址2”两条路径故障，正在使用交叉路径进行通信，修改为交叉路径不可用时，将导致链路中断。 |

#### 使用实例

将链路索引为1的SGs链路名修改为test，交叉路径是否可用改为是：

MOD SGSLNK: LNK=1, SGSLNKNM="test", CROSSIPFLAG=YES;
