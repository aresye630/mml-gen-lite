# 设置融合计费全局参数（SET CNVRGDCHGPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于配置融合计费全局参数。

## 注意事项

- 该命令执行后立即生效。

- 参数OFLRGTIMECALC和CHGDATAREFFMT功能仅针对新用户生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

#### 操作用户权限
