# 设置AMF的PCF故障处理策略（SET AMFPCFRESET）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于设置AMF的PCF故障处理策略。

## 注意事项

- 该命令执行后在下次PCF故障时生效。

- 扫描速率、单位扫描时间和单位扫描个数设置过大可能会对周边PCF产生冲击。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| PCFRESEL   | SCANMODE   |   RATE |   INTERVAL |   SCANNUM |
|:-----------|:-----------|-------:|-----------:|----------:|
| OFF        | DEFAULT    |      1 |          1 |         5 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                                 |
|:---------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PCFRESEL | PCF故障重选开关 | 可选必选说明：必选参数  参数含义：该参数用于指定AMF和PCF的接口故障或者PCF的状态更新为去注册时，AMF是否重选PCF。  数据来源：全网规划 取值范围： “OFF（关闭）”：关闭“ON（打开）”：打开  默认值：无。  配置原则：无                                                                                                                                                                                                                                                            |
| SCANMODE | 扫描模式      | 可选必选说明：该参数在"PCFRESEL"配置为"ON"时为条件可选参数。  参数含义：该参数表示AMF对于用户的扫描模式。  数据来源：全网规划 取值范围： “DEFAULT（默认扫描模式）”：使用RATE设置的扫描速率。“CUSTOM（自定义扫描模式）”：使用通过SCANNUM除以INTERVAL得到的自定义扫描速率。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST AMFPCFRESET查询当前参数配置值。  配置原则：无                                                                                                                                            |
| RATE     | 扫描速率(个/秒) | 可选必选说明：该参数在"SCANMODE"配置为"DEFAULT"时为条件可选参数。  参数含义：该参数用于指定每个DS每秒扫描多少个用户，扫描到后为符合重选PCF条件的用户重新选择正常的PCF进行注册。  数据来源：全网规划  取值范围：整数类型，取值范围是1~20，单位是个每秒。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST AMFPCFRESET查询当前参数配置值。  配置原则：  DS个数 × 扫描速率 = 整系统扫描速率。  DS个数来源于如下命令输出结果中记录个数：  DSP FRAMEDBG: DBGSTR="UeamCtrlSvc coordinator all";  如果结果没有分批显示，则记录个数为回显中“结果个数”字段的值减1；如果结果分批显示，则记录个数为最终的结果个数减1。 |
| INTERVAL | 单位扫描时间(秒) | 可选必选说明：该参数在"SCANMODE"配置为"CUSTOM"时为条件可选参数。  参数含义：该参数用于表示PCF故障后DS对用户扫描的时间间隔。  数据来源：本端规划  取值范围：整数类型，取值范围是1~600，单位是秒。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST AMFPCFRESET查询当前参数配置值。  配置原则：无                                                                                                                                                                                             |
| SCANNUM  | 单位扫描个数    | 可选必选说明：该参数在"SCANMODE"配置为"CUSTOM"时为条件可选参数。  参数含义：该参数用于表示每个DS每隔INTERVAL设置的时间扫描多少个用户，扫描到后为符合重选PCF条件的用户重新选择正常的PCF进行注册。  数据来源：本端规划  取值范围：整数类型，取值范围是1~20，单位是个。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST AMFPCFRESET查询当前参数配置值。  配置原则：无                                                                                                                                                      |

## 使用实例

AMF在PCF故障时重选PCF，使用默认扫描模式，重选速率为5个/秒，执行如下命令：

```
SET AMFPCFRESET:PCFRESEL=ON,SCANMODE=DEFAULT,RATE=5;
```
