# 查询业务属性（LST SERVICEPROP）

- 注意事项
- 操作用户权限

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于查询业务属性。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                                 |
|:------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OPTYPE      | 操作类型   | 可选必选说明：可选参数 参数含义：该参数用于指定业务属性的操作类型。 数据来源：全网规划 取值范围：枚举类型。 SRV_PROP_NAME：删除SRVPROPNAME。SERVICE_ID：删除SERVICEID。 默认值：无 配置原则： SRV_PROP_NAME：当OPTYPE值为SRV_PROP_NAME时，表示基于SRVPROPNAME查询记录。SERVICE_ID：当OPTYPE值为SERVICE_ID时，表示基于SERVICEID查询记录。 |
| SRVPROPNAME | 业务属性名称 | 可选必选说明：条件可选参数 前提条件：该参数在“OPTYPE”配置为“SRV_PROP_NAME”时为可选参数。 参数含义：该参数用于指定业务属性名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                             |
| SERVICEID   | 业务标识   | 可选必选说明：条件可选参数 前提条件：该参数在“OPTYPE”配置为“SERVICE_ID”时为可选参数。 参数含义：该参数用于指定业务标识。全局唯一。 数据来源：全网规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 配置原则：无                                                                                                     |

#### 使用实例

查询业务属性配置：OPTYPE为SRV\_PROP\_NAME，SRVPROPNAME为test：

```
LST SERVICEPROP:OPTYPE=SRV_PROP_NAME,SRVPROPNAME="test";
```

```
RETCODE = 0  操作成功。

业务属性信息
------------
业务属性名称  =  test
    业务标识  =  1
      优先级  =  10
(结果个数 = 1)

```
