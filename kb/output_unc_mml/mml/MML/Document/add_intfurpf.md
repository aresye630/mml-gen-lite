# 增加安全接口URPF（ADD INTFURPF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来增加接口的URPF配置。

URPF通过获取报文的源地址和入接口，以源地址为目的地址，在转发表中查找源地址对应的接口是否与入接口匹配，如果不匹配，则认为源地址是伪装的，并丢弃该报文（松散模式URPF不会匹配入接口）。通过这种方式，URPF就能有效地防范网络中通过修改源地址而进行的恶意攻击行为的发生。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为65536。
- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称       | 参数说明                                                                                                             |
|:---------------|:-----------|:-----------------------------------------------------------------------------------------------------------------|
| IFNAME         | 接口名称       | 可选必选说明：必选参数 参数含义：接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～47。 默认值：无 配置原则：与设备接口名称保持一致，下发本MML命令前可使用LST INTERFACE查看设备接口。 |
| SECURPFLOOSE   | 安全URPF检查类型 | 可选必选说明：必选参数 参数含义：安全URPF增强型检查。 数据来源：本端规划 取值范围：枚举类型。 strict：严格检查。loose：松散检查。 默认值：无                                 |
| SECURFPDEFAULT | 安全匹配默认路由   | 可选必选说明：必选参数 参数含义：默认安全URPF。 数据来源：本端规划 取值范围：枚举类型。 disallow：不接受。allow：接受。 默认值：无                                     |
| SECPROTOFAMILY | 安全协议族      | 可选必选说明：必选参数 参数含义：安全协议族。 数据来源：本端规划 取值范围：枚举类型。 ipv4：IPv4类型。ipv6：IPv6类型。 默认值：无 配置原则：IPv4类型或IPv6类型。                  |

#### 使用实例

增加接口的URPF配置：

```
ADD INTFURPF: IFNAME="Ethernet66/0/2", SECURPFLOOSE=loose, SECURFPDEFAULT=allow, SECPROTOFAMILY=ipv4;
```
