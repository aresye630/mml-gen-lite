# 删除AMF容灾网元状态信息（RMV FTTNFSTATUS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除AMF容灾网元状态信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                                                        |
|:-------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCEID | AMF实例标识 | 可选必选说明：必选参数  参数含义：该参数用于在UNC系统中唯一指定某个AMF实例。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~36。可输入的字符有字母A～Z或a～z、数字0～9、中划线"-"和下划线"_"，例如，AMF_Instance_0，不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

删除NF Instance ID为AMF\_INSTANCE\_0的网元状态信息，执行如下命令：

```
RMV FTTNFSTATUS: NFINSTANCEID="AMF_INSTANCE_0";
```
