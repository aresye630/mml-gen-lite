# 设置流控系统参数(SET FLOWCTRLPARA)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

此命令需要华为技术支持人员指导下才能执行，请慎重使用。

**适用网元：SGSN、MME**

该命令用于设置某个进程上每秒数据流量的接入限制数。

#### 注意事项

- 系统初次上电运行时，会执行系统初始设置值。
- 此命令执行后立即生效。
- 此命令需要华为技术支持人员指导下才能执行，请慎重使用。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称       | 参数说明                                                                                                                                                                                                |
|:----------------|:-----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| WEIGHTMODE      | 业务权重获取方式   | 可选必选说明：可选参数 参数含义：该参数用于设置流控消息业务权重的获取方式。 数据来源：整网规划 取值范围：“CFG(静态配置)”“LEARN(统计学习)” 系统初始设置值：“LEARN(统计学习)” 配置原则：系统默认按照基于统计学习的方式获取流控消息业务权重。  说明： 当业务权重获取方式配置为“LEARN(统计学习)”时，流控消息业务权重为各业务消息的历史统计学习信息计算得到的值。 |
| PROCTYPE        | 进程类型       | 可选必选说明：可选参数 参数含义：该参数用于指定进程的类型。 数据来源：整网规划 取值范围：“SPP(SPP)”“SGP(SGP)”“GBP(GBP)”“UPP(UPP)” 系统初始设置值：“SPP(SPP)”“SGP(SGP)”“GBP(GBP)”“UPP(UPP)”                                                             |
| MINWAL          | 窗口最小值      | 可选必选说明：条件必选参数 参数含义：该参数用于指定窗口的最小值，即进程上每秒允许通过信令消息量的最小值限制。 前提条件：该参数在"进程类型"参数配置为"SPP"、"SGP"、"GBP"或"UPP"后生效。 数据来源：整网规划 取值范围：0~20000 系统初始设置值：30                                                           |
| MAXWAL          | 窗口最大值      | 可选必选说明：条件必选参数 参数含义：该参数用于指定窗口的最大值，即进程上每秒允许通过信令消息量的最大值限制。该参数取值必须大于等于“MINWAL”的取值。 前提条件：该参数在"进程类型"参数配置为"SPP"、"SGP"、"GBP"或"UPP"后生效。 数据来源：整网规划 取值范围：0~20000 系统初始设置值：5000                                  |
| MINWAL_GBDATA   | 2G用户面窗口最小值 | 可选必选说明：条件可选参数 参数含义：该参数用于指定用户面窗口的最小值，即进程上每秒钟允许通过2G数传业务消息量的最小值限制。前提条件：该参数在"进程类型"参数配置为"GBP"后生效。 数据来源：整网规划 取值范围：0~20000 系统初始设置值：2500                                                                    |
| MAXWAL_GBDATA   | 2G用户面窗口最大值 | 可选必选说明：条件可选参数 参数含义：该参数用于指定用户面窗口的最大值，即进程上每秒钟允许通过2G数传业务消息量的最大值限制。该参数取值必须大于等于参数“MINWAL_GBDATA”的取值。 前提条件：该参数在"进程类型"参数配置为"GBP"后生效。 数据来源：整网规划 取值范围：0~20000 系统初始设置值：16000                                  |
| MAXWAL_GBPAGING | 2G寻呼窗口最大值  | 可选必选说明：条件可选参数 参数含义：该参数用于指定2G寻呼窗口的最大值，即进程上每秒钟允许通过的最大寻呼消息量。 前提条件：该参数在"进程类型"参数配置为"GBP"后生效。 数据来源：整网规划 取值范围：0~20000 系统初始设置值：900                                                                          |
| MINWAL_S1PAGING | S1寻呼窗口最小值  | 可选必选说明：条件可选参数 参数含义：该参数用于指定S1寻呼窗口的最小值，即进程上每秒钟允许通过S1寻呼消息量的最小值限制。 前提条件：该参数在"进程类型"参数配置为"SGP"后生效。 数据来源：整网规划 取值范围：0~20000 系统初始设置值：500                                                                     |
| MAXWAL_S1PAGING | S1寻呼窗口最大值  | 可选必选说明：条件可选参数 参数含义：该参数用于指定S1寻呼窗口的最大值，即进程上每秒钟允许通过S1寻呼消息量的最大值限制。该参数取值必须大于等于参数“MINWAL_S1PAGING”的取值。 前提条件：该参数在"进程类型"参数配置为"SGP"后生效。 数据来源：整网规划 取值范围：0~20000 系统初始设置值：10000                                 |
| DROPRATETHD     | 丢包率告警阈值    | 可选必选说明：可选参数 参数含义：该参数用于指定系统流控丢包率告警阈值。当系统流控丢包率超过告警阈值时，上报“ALM-80667 系统流控启动”告警。 前提条件：该参数在"进程类型"参数配置为"SPP"、"SGP"、"GBP"或"UPP"后生效。 数据来源：整网规划 取值范围：0~100 系统初始设置值：5                                          |

#### 使用实例

设置流控系统参数：进程类型为GBP，窗口最小值为30，窗口最大值为5000，用户面窗口最小值为100，用户面窗口最大值为16000，寻呼窗口最大值为800：

SET FLOWCTRLPARA: PROCTYPE=GBP, MINWAL=30, MAXWAL=5000, MINWAL\_GBDATA=100, MAXWAL\_GBDATA=16000, MAXWAL\_GBPAGING=800;
