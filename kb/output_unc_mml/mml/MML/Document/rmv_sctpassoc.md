# 删除SCTP耦联测量对象（RMV SCTPASSOC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

此命令用于删除SCTP耦联测量对象。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称           | 参数说明                                                                                 |
|:---------|:---------------|:-------------------------------------------------------------------------------------|
| OBJECTID | SCTP偶联测量对象实例标识 | 可选必选说明：必选参数 参数含义：该参数用于指定SCTP耦联测量对象实例标识。 数据来源：本端规划 取值范围：整数类型，取值范围为1～200。 默认值：无 配置原则：无 |

#### 使用实例

根据网络规划，需要删除一个SCTP耦联测量对象，则可以按如下配置：

```
RMV SCTPASSOC: OBJECTID=1;
```
