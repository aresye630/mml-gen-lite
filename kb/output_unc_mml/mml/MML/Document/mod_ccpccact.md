# 修改融合计费Proxy基于CC处理动作（MOD CCPCCACT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NCG**

该命令用于修改融合计费Proxy基于CC处理动作。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称         | 参数说明                                                                                                                                                                                |
|:--------------|:-------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CCTYPE        | CC类型         | 可选必选说明：必选参数  参数含义：该参数用于指定CC的类型。  数据来源：本端规划 取值范围： DEFAULT（针对未指定的CC设置处理动作）VALUE（针对CC设置处理动作）  默认值：无  配置原则：无                                                                            |
| CHGCHAR       | 指定计费属性值      | 可选必选说明：该参数在"CCTYPE"配置为"VALUE"时为条件必选参数。  参数含义：该参数用于指定计费属性的值。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~6。十六进制数据类型，仅支持输入0x/X、a-f/A-F 、0-9，允许不输入0x前缀，字母不区分大小写，取值范围0x0000~0xFFFF。  默认值：无  配置原则：无  |
| CHGCHARMASK   | 指定计费属性掩码     | 可选必选说明：该参数在"CCTYPE"配置为"VALUE"时为条件可选参数。  参数含义：该参数用于指定计费属性的掩码。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~6。十六进制数据类型，仅支持输入0x/X、a-f/A-F 、0-9，允许不输入0x前缀，字母不区分大小写，取值范围0x0000~0xFFFF。  默认值：无  配置原则：无 |
| FWDOCSENABLE  | 是否转发OCS      | 可选必选说明：可选参数  参数含义：该参数用于设置是否转发OCS。  数据来源：本端规划  取值范围： TRUE(TRUE)FALSE(FALSE)  默认值：无  配置原则：无                                                                                           |
| FOTNM         | Failover模板标识 | 可选必选说明：可选参数  参数含义：该参数用于指定融合计费Proxy Failover模板的名称，FOTNM参数来源是ADD CCPFOT:FOTNM。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。  默认值：无  配置原则：无                                                     |
| GENCHGDATAREF | 是否生成计费数据标识   | 可选必选说明：可选参数  参数含义：该参数用于设置是否生成数据计费标识(ChargingDataRef)。  数据来源：本端规划  取值范围： TRUE(TRUE)FALSE(FALSE)  默认值：无  配置原则：无                                                                       |

## 使用实例

修改指定计费属性值为“0x1234”的融合计费Proxy基于CC处理动作，设置计费属性掩码为“0x4567”：

```
MOD CCPCCACT: CCTYPE=VALUE, CHGCHAR="0x1234", CHGCHARMASK="0x4567";
```
