# 查询SGSN DNS域名策略(LST SGSNDNS)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限

#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询SGSN DNS域名策略配置。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                          |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DNTYPE | 域名类型   | 可选必选说明：可选参数 参数含义：该参数用于指定DNS域名类型。 数据来源：整网规划 取值范围：“ALL（ALL）”“RAI（RAI）”“NRI（NRI）”“RNC_ID（RNC ID）”“LAI（LAI）” 默认值：无                                                |
| LAC    | 位置区域码  | 可选必选说明：可选参数 参数含义：该参数用于指定位置区域码 前提条件：该参数在“DNTYPE”参数配置为“RAI（RAI）”或“LAI（LAI）”后生效。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值 ：无                                             |
| RAC    | 路由区域码  | 可选必选说明：可选参数 参数含义：该参数用来指定路由区域码 前提条件：该参数在“DNTYPE”参数配置为“RAI（RAI）”后生效。 数据来源：整网规划 取值范围：0x00～0xFF 默认值：无                                                             |
| NRI    | NRI    | 可选必选说明：可选参数 参数含义：该参数用来指定NRI（Net Resource Identify）。NRI用于标识一个CN节点。RAN根据NRI将MS的消息路由到对应的SGSN。 前提条件：该参数在“DNTYPE”参数配置为“NRI（NRI）”后生效。 数据来源：整网规划 取值范围： 0～1023 默认值： 无 |
| RNCID  | RNC ID | 可选必选说明：可选参数 参数含义：该参数用来指定RNC标识。RNC标识用于在一个PLMN中唯一标识一个RNC。 前提条件：该参数在“DNTYPE”参数配置为“RNC_ID（RNC ID）”后生效。 数据来源：整网规划 取值范围： 0～4096 默认值： 无                              |
