#### 命令功能

**适用网元：MME**

该命令用于查询DCN下的MME组成员信息。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                               |
|:-------|:--------|:-----------------------------------------------------------------------------------|
| DCNID  | DCN ID  | 可选必选说明：可选参数 参数含义：该参数用来指定DCN标识。 数据来源：全网规划 取值范围：0~255 默认值：无                          |
| MMEGI  | MME组识别码 | 可选必选说明：可选参数 参数含义：该参数用于配置指定DCN的MME群组标识。 数据来源：全网规划 取值范围：4位16进制编码，范围为0000~FFFF。 默认值：无 |

#### 使用实例

查询“DCN ID”为“0”的DCN下的MME成员：

LST DCNMEMBER: DCNID=0;

```
%%LST DCNMEMBER: DCNID=0;%%
RETCODE = 0  操作成功

操作结果如下：
--------------
     DCN ID  =  0
MME组识别码  =  A1B3
(结果个数 = 1)

---    END
```
