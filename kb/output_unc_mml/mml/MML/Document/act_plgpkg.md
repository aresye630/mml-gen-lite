# 激活扩展包（ACT PLGPKG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

该命令属于高危命令，若激活的是冷扩展包（即激活该扩展包时需要重启系统使其生效），则该操作会重启系统，请谨慎使用。

该命令用于将LOD PLGPKG加载的扩展包激活。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| PLGTYPE         | 扩展包类型  | 可选必选说明：必选参数 参数含义：该参数用于指定扩展包类型。可通过LST PLGPKG查询获取。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无                     |
| VERSIONID       | 版本号    | 可选必选说明：必选参数 参数含义：该参数用于指定版本号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                                         |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

激活扩展包：

```
ACT PLGPKG:PLGTYPE="Listening", VERSIONID="V100R005C00MOD",SERVICEINSTANCE="vnfc";
```
