# 查询对本地用户、漫游用户、拜访用户所采用的计费属性（LST GLBCHARGECHAR）

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用来查询配置对本地用户、漫游用户、拜访用户所采用的计费属性。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询配置对本地用户、漫游用户、拜访用户所采用的计费属性：

```
LST GLBCHARGECHAR:;
```
