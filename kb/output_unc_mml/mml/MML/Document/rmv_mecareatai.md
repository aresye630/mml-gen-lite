# 删除5G MEC TAI信息（RMV MECAREATAI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除5G MEC跟踪区成员。

## 注意事项

下一次移动性流程生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                       |
|:---------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MCC      | MCC     | 可选必选说明：必选参数  参数含义：该参数用于表示移动国家码，与无线接入网的MCC一致。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                                                 |
| MNC      | MNC     | 可选必选说明：必选参数  参数含义：该参数用于表示移动网号，与无线接入网的MNC一致。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                                              |
| TACBEGIN | 跟踪区起始编码 | 可选必选说明：必选参数  参数含义：该参数用于表示跟踪区编码起始值。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。TAC编码为16进制数，按照字符串格式输入，字符串长度为6，只能由数字（0-9），字母（A-F、a-f）组成，且字母大小写不敏感。  默认值：无  配置原则：无                          |
| TACEND   | 跟踪区结束编码 | 可选必选说明：必选参数  参数含义：该参数用于表示跟踪区编码结束值。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。TAC编码为16进制数，按照字符串格式输入，字符串长度为6，只能由数字（0-9），字母（A-F、a-f）组成，且字母大小写不敏感。本参数表示的跟踪区编码不能小于“跟踪区起始编码”。  默认值：无  配置原则：无 |
| AREAID   | 区域标识    | 可选必选说明：可选参数  参数含义：该参数用于表示区域（例如：商场或景区）的标识。  数据来源：全网规划  取值范围：整数类型，取值范围是1~1024。  默认值：无  配置原则：  AREAID需要通过ADD MECAREA命令配置添加。                                                   |

## 使用实例

删除标识为“1”的区域的一个跟踪区成员（MCC="123", MNC="45", TACBEGIN="123456", TACEND="123456"），执行如下命令：

```
RMV MECAREATAI:AREAID=1,MCC="123",MNC="45",TACBEGIN="123456",TACEND="123456";
```
