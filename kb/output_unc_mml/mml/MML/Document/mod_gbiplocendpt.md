# 修改本地端点配置(MOD GBIPLOCENDPT)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用于在Gb OVER IP时修改一个NSE下的一条本端端点配置。

#### 注意事项

- 该命令执行后立即生效。
- 该命令只能修改本端端点权重记录和“描述”。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                             |
|:-------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------|
| NSEI   | NSE标识    | 可选必选说明：必选参数 参数含义：该参数用于设置端点所在的网络服务实体标识。 数据来源：整网规划 取值范围：0～65535 默认值：无  说明： 必须已经配置成IP承载类型的NSE。                                                      |
| IPT    | IP地址类型   | 可选必选说明：必选参数 参数含义：该参数用于设置IP地址类型。 数据来源：整网规划 取值范围：“IPV4(IPv4)”“IPV6(IPv6)” 默认值：无                                                                    |
| LIPV4  | 本端IPv4地址 | 可选必选说明：条件必选参数 参数含义：该参数用于设置本端使用的IPv4地址。 前提条件：该参数在“IP地址类型”设置为“IPV4(IPv4)”时才生效。 数据来源：整网规划 取值范围：0.0.0.0～255.255.255.255 默认值：无                        |
| LIPV6  | 本端IPv6地址 | 可选必选说明：条件必选参数 参数含义：该参数用于设置本端PCU使用的IPv6地址。 前提条件：该参数在“IP地址类型”设置为“IPV6(IPv6)”时才生效。 数据来源：整网规划 取值范围： ::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 |
| LUP    | 本端UDP端口号 | 可选必选说明：必选参数 参数含义：该参数用于设置本端使用的UDP端口号。 数据来源：整网规划 取值范围：1024～65535 默认值：无                                                                             |
| SW     | 信令权重     | 可选必选说明：可选参数 参数含义：该参数为保留参数，暂未实现。 取值范围：0～255 默认值：无  说明： 在NSE为IP动态配置类型时，信令权重可以通过相关流程下发PCU。                                                          |
| DW     | 数据权重     | 可选必选说明：可选参数 参数含义：该参数为保留参数，暂未实现。 数据来源：整网规划 取值范围：0～255 默认值：无  说明： 在NSE为IP动态配置类型时，数据权重可以通过相关流程下发PCU。当取值为0时，表示权重因子是0，不被选择。                           |
| DESC   | 描述       | 可选必选说明：可选参数 参数含义：该参数用于指定本端端点名称，标识本端端点。 数据来源：整网规划 取值范围：1～32位字符串 默认值：无                                                                             |

#### 使用实例

1. 修改IPv4地址为192.168.2.1、UDP端口为2001的本端端点的信令权重为12，数据权重为12，对应BSC1：

   MOD GBIPLOCENDPT: NSEI=600, IPT=IPV4, LIPV4="192.168.2.1", LUP=2001, SW=12, DW=12, DESC="FOR BSC1";
