# 删除CHR本地存盘用户（RMV CHRRPTSUBID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C、SMF、GGSN**

该命令用于删除用户本地存储CHR表单。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                              |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------|
| RANGE  | 范围     | 可选必选说明：可选参数  参数含义：该参数用于指示删除记录时的范围。  数据来源：本端规划 取值范围： “SPECIFIC_IMSI（指定IMSI）”：删除指定IMSI记录“ALL（所有）”：删除所有记录  默认值：SPECIFIC_IMSI  配置原则：无 |
| IMSI   | IMSI   | 可选必选说明：该参数在"RANGE"配置为"SPECIFIC_IMSI"时为条件必选参数。  参数含义：该参数用于指示用户的IMSI。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~15。  默认值：无  配置原则：无            |

## 使用实例

删除指定用户本地存储CHR表单的配置，用户的IMSI为460030123456789：
删除所有指定用户本地存储CHR表单配置：

```
RMV CHRRPTSUBID: RANGE=SPECIFIC_IMSI, IMSI="460030123456789";
RMV CHRRPTSUBID,RANGE=ALL:;
```
