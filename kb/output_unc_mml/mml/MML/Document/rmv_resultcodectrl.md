# 删除返回码控制（RMV RESULTCODECTRL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

此命令用来删除指定返回码的控制信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                           |
|:----------------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PCCTEMPLATE     | PCC模板名称 | 可选必选说明：必选参数 参数含义：该参数用于设置该返回码所绑定的PCC模板。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无                                                                                                                                                                                                                                          |
| INTFTYPE        | 接口类型    | 可选必选说明：可选参数 参数含义：接口类型。 数据来源：对端协商 取值范围：枚举类型。 INTFTYPE_N7：N7接口类型。INTFTYPE_GX：Gx接口类型。 默认值：无 配置原则：无                                                                                                                                                                                                                                |
| N7RESULTCODEVAL | N7返回码   | 可选必选说明：条件可选参数 前提条件：该参数在“INTFTYPE”配置为“INTFTYPE_N7”时为可选参数。 参数含义：N7返回码。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～3。300-599或者3xx-5xx，不区分大小写。其中xx代表一个范围，例如3xx代表300~399。 默认值：无 配置原则： 超时返回码504不受该配置控制，而是执行一次failover操作，若failover失败则根据APN/DNN绑定的PCCTEMPLATE或全局用户PCCFAILACTION相关配置获取失败动作。其中，APN/DNN绑定的PCCTEMPLATE配置优先级高。配置的单个的返回码落在一个范围内时，单个的优先级高。 |
| VENDORID        | 设备提供商标识 | 可选必选说明：条件可选参数 前提条件：该参数在“INTFTYPE”配置为“INTFTYPE_GX”时为可选参数。 参数含义：设备提供商标识。 数据来源：全网规划 取值范围：整数类型，取值范围为0～65535。 默认值：无 配置原则：无                                                                                                                                                                                                          |
| GXRESULTCODEVAL | Gx返回码   | 可选必选说明：条件可选参数 前提条件：该参数在“INTFTYPE”配置为“INTFTYPE_GX”时为可选参数。 参数含义：返回码。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～4。1000-9999，1xxx-9xxx，不区分大小写。其中xxxx代表一个范围，例如1xxx代表1000~1999。配置的单个的返回码落在一个范围内时，单个的优先级高。 默认值：无 配置原则：无                                                                                                                           |

#### 使用实例

删除所有全局RESULTCODECTRL返回码的控制信息：

```
RMV RESULTCODECTRL:PCCTEMPLATE="global";
```
