# 清除BFD会话统计信息（RTR BFDSESSSTAS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于清除BFD会话相关的统计计数信息。可以基于会话清除统计计数信息。

#### 注意事项

- 该命令执行后立即生效。
- 清除后不可恢复计数。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                  |
|:-----------|:-------|:----------------------------------------------------------------------------------------------------------------------|
| RESETTYPE  | 复位类型   | 可选必选说明：必选参数 参数含义：清除统计信息的类型。 数据来源：本端规划 取值范围：枚举类型。 ALL：所有BFD会话。DISCRIMINATOR：指定本地标识符的BFD会话。 默认值：无                       |
| LOCALDISCR | 本地标识符  | 可选必选说明：条件必选参数 前提条件：该参数在“RESETTYPE”配置为“DISCRIMINATOR”时为必选参数。 参数含义：清除单个会话的统计信息。 数据来源：本端规划 取值范围：整数类型，取值范围为1～49152。 默认值：无 |

#### 使用实例

- 清空BFD所有会话的统计信息：

  ```
  RTR BFDSESSSTAS:RESETTYPE=ALL;
  ```
- 清空本地标识符为1222的会话统计信息：

  ```
  RTR BFDSESSSTAS:RESETTYPE=DISCRIMINATOR,LOCALDISCR=1222;
  ```
