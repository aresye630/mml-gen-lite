# 增加Pre-R8签约QoS配置（ADD PRER8SUBQOS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：GGSN**

该命令用于配置用户的签约QoS属性。当APN下使能COA功能时，RADIUS鉴权服务器会下发用户QoS索引，UNC根据索引匹配到subscriber-qos配置，用来进行用户QoS的协商控制，主动调整带宽等。如果RADIUS鉴权服务器没有下发用户QoS索引，则根据APN下绑定的qos-profile下的用户QoS索引进行用户QoS的协商控制、调整带宽等。

## 注意事项

- 命令执行后只对新接入用户生效。

- 确保同类型同方向上的最大带宽值不小于保证带宽值。

- 最多可输入100条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

添加一个SUBQOSINDEX为1，最高业务级别为CONVERSATIONAL，超过最高业务级别时的处理为DEGRADE的QoS签约信息：

```
ADD PRER8SUBQOS: SUBQOSINDEX=1, HIGHESTTC=CONVERSATIONAL, ACTION=DEGRADE;
```
