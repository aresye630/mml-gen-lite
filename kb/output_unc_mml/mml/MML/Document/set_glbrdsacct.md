# 设置全局RADIUS Accounting配置（SET GLBRDSACCT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用来设置全局RADIUS计费配置的信息。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令必须配置其中一个参数。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   |   ONOFFADDITTIMES |   TRANSTHRESHOLD |
|:-------|------------------:|-----------------:|
| 初始值    |                 0 |                0 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称                             | 参数说明                                                                                                  |
|:----------------|:---------------------------------|:------------------------------------------------------------------------------------------------------|
| ONOFFADDITTIMES | 发送RADIUS Accounting On/Off消息附加次数 | 可选必选说明：可选参数 参数含义：该参数用于指定发送RADIUS Accounting On/Off消息附加次数。 数据来源：本端规划 取值范围：整数类型，取值范围为0～63。 默认值：无 配置原则：无 |
| TRANSTHRESHOLD  | 每秒钟尝试发送Accounting Start消息的用户数    | 可选必选说明：可选参数 参数含义：该参数用于指定每秒钟尝试发送Accounting Start消息的用户数。 数据来源：本端规划 取值范围：整数类型，取值范围为0～100。 默认值：无 配置原则：无   |

#### 使用实例

修改PGW APN计费方式：ONOFFADDITTIMES为1，TRANSTHRESHOLD为10：

```
SET GLBRDSACCT: ONOFFADDITTIMES=1,TRANSTHRESHOLD=10;
```
