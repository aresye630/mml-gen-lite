# 删除4G TA群组成员（RMV S1RANTAGPMEM）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于删除跟踪区群组成员记录。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；

#### 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                   |
|:------------|:--------|:-----------------------------------------------------------------------|
| S1RANTAGPID | 跟踪区群组标识 | 可选必选说明：必选参数 参数含义：该参数用于指定跟踪区群组标识。 数据来源：本端规划 取值范围：整数类型，取值范围是1~256。 默认值：无 |
| TAC         | 跟踪区域码   | 可选必选说明：必选参数 参数含义：该参数用于指定跟踪区域码。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无      |

#### 使用实例

删除一个TA群组成员，TA群组标识为1，群组成员的跟踪区域码为0x1234。

```
RMV S1RANTAGPMEM: S1RANTAGPID=1, TAC="0x1234";
```
