# 删除N4接口地址映射关系（RMV CPPFCPNATIP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、SGW-C、PGW-C**

该命令用于删除N4接口本端CP端点的IP地址和经过信令安全网关映射后的IP地址映射关系。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

删除本端CP端点IP地址为10.1.1.1，代理UP路径的IP地址为10.2.2.2的N4接口地址映射关系：

```
RMV CPPFCPNATIP: CPIPTYPE=IPv4, CPADDRIPV4="10.1.1.1", UPIPTYPE=IPv4, UPADDRIPV4="10.2.2.2";
```
