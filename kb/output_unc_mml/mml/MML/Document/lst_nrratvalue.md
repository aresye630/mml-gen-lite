# 查询5G接入用户的RAT填写值（LST NRRATVALUE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF、PGW-C**

查询5G接入用户的RAT填写值。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

无

## 使用实例

查询5G接入用户的RAT填写值。

```
LST NRRATVALUE:;
RETCODE = 0  操作成功

结果如下
------------------------
                  和OCS交互使用的RAT值  =  RAT取值为51
                   和CG交互使用的RAT值  =  RAT取值为51
        和AAA计费服务器交互使用的RAT值  =  RAT取值为51
(结果个数 = 1)
```

## 输出结果说明

| 输出项名称              | 输出项解释                      |
|:-------------------|:---------------------------|
| 和OCS交互使用的RAT值      | 该参数用于设置和OCS交互使用的RAT值。      |
| 和CG交互使用的RAT值       | 该参数用于设置和CG交互使用的RAT值。       |
| 和AAA计费服务器交互使用的RAT值 | 该参数用于设置和AAA计费服务器交互使用的RAT值。 |
