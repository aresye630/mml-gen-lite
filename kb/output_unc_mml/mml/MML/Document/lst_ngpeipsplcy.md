# 查询基于分组的智能寻呼策略（LST NGPEIPSPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询基于分组的智能寻呼策略。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|:------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE    | 用户范围   | 可选必选说明：可选参数  参数含义：该参数用于指定寻呼分组标识下发的用户范围。  数据来源：全网规划 取值范围： “ALL_USER（所有用户）”：所有用户。“HOME_USER（本网用户）”：本网用户。“FOREIGN_USER（外网用户）”：外网用户。“IMSI_PREFIX（IMSI前缀）”：IMSI前缀。“SPECIFIC_IMSI（指定IMSI）”：指定IMSI。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| IMSIPRE     | IMSI前缀 | 可选必选说明：该参数在"SUBRANGE"配置为"IMSI_PREFIX"时为条件可选参数。  参数含义：该参数用于指定应用基于分组的智能寻呼策略的用户IMSI前缀。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是5~14。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| IMSI        | IMSI   | 可选必选说明：该参数在"SUBRANGE"配置为"SPECIFIC_IMSI"时为条件可选参数。  参数含义：该参数用于指定应用基于分组的智能寻呼策略的用户IMSI（完整IMSI）。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是14~15。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| FEATURECOND | 特征条件组合 | 可选必选说明：可选参数  参数含义：该参数用于指示特征条件的组合。  数据来源：全网规划 取值范围： “NONE（不指定特征条件）”：不指定特征条件。“DNN（仅指定DNN条件）”：仅指定DNN条件。“NSSAI（仅指定切片条件）”：仅指定切片条件。“DNN_NSSAI（仅指定DNN和切片条件）”：仅指定DNN和切片条件。“PAGINGPRO（仅指定寻呼概率条件）”：仅指定寻呼概率条件。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| DNN         | DNN    | 可选必选说明：该参数在"FEATURECOND"配置为"DNN"、"DNN_NSSAI"时为条件可选参数。  参数含义：该参数用于指定需要进行智能寻呼用户的DNN。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无  配置原则：  该参数来源于SMF上已通过ADD APN配置的DNN。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| SST         | 切片业务类型 | 可选必选说明：该参数在"FEATURECOND"配置为"DNN_NSSAI"、"NSSAI"时为条件可选参数。  参数含义：该参数用于指定需要进行智能寻呼用户的签约切片业务类型特征。如eMBB（1）、URLLC（2）、MIoT（3）等协议定义的标准SST，或者运营商自定义的SST。  数据来源：全网规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：  该参数来源于AMF上已通过ADD PLMNNS配置的切片。  该值若不设置，默认值为65535。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| SD          | 切片细分标识 | 可选必选说明：该参数在"FEATURECOND"配置为"DNN_NSSAI"、"NSSAI"时为条件可选参数。  参数含义：该参数用于指定需要进行智能寻呼用户的签约切片细分标识特征。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。采用十六进制表示（无须输入“0x”前缀），只能由数字（0-9），字母（A-F、a-f）组成。字母大小写不敏感。  默认值：无  配置原则：  该参数来源于AMF上已通过ADD PLMNNS配置的切片。  该参数在"FEATURECOND"配置为"NONE"、"DNN"时，值为"FFFFFF"。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| PAGINGPRO   | 寻呼概率   | 可选必选说明：该参数在"FEATURECOND"配置为"PAGINGPRO"时为条件可选参数。  参数含义：该参数用于指定需要进行智能寻呼终端的寻呼概率。  数据来源：全网规划 取值范围： “P00（等于0%）”：用户计算的寻呼概率为0%。“P05（小于等于5%）”：用户计算的寻呼概率大于0%，小于等于5%。“P10（小于等于10%）”：用户计算的寻呼概率大于5%，小于等于10%。“P15（小于等于15%）”：用户计算的寻呼概率大于10%，小于等于15%。“P20（小于等于20%）”：用户计算的寻呼概率大于15%，小于等于20%。“P25（小于等于25%）”：用户计算的寻呼概率大于20%，小于等于25%。“P30（小于等于30%）”：用户计算的寻呼概率大于25%，小于等于30%。“P35（小于等于35%）”：用户计算的寻呼概率大于30%，小于等于35%。“P40（小于等于40%）”：用户计算的寻呼概率大于35%，小于等于40%。“P45（小于等于45%）”：用户计算的寻呼概率大于40%，小于等于45%。“P50（小于等于50%）”：用户计算的寻呼概率大于45%，小于等于50%。“P55（小于等于55%）”：用户计算的寻呼概率大于50%，小于等于55%。“P60（小于等于60%）”：用户计算的寻呼概率大于55%，小于等于60%。“P65（小于等于65%）”：用户计算的寻呼概率大于60%，小于等于65%。“P70（小于等于70%）”：用户计算的寻呼概率大于65%，小于等于70%。“P75（小于等于75%）”：用户计算的寻呼概率大于70%，小于等于75%。“P80（小于等于80%）”：用户计算的寻呼概率大于75%，小于等于80%。“P85（小于等于85%）”：用户计算的寻呼概率大于80%，小于等于85%。“P90（小于等于90%）”：用户计算的寻呼概率大于85%，小于等于90%。“P95（小于等于95%）”：用户计算的寻呼概率大于90%，小于等于95%。“P100（小于等于100%）”：用户计算的寻呼概率大于95%，小于等于100%。  默认值：无  配置原则：  该参数在"FEATURECOND"配置为"NONE"、"DNN"、"NSSAI"、"DNN_NSSAI"时，值为“小于等于100%”。 |

## 使用实例

查询用户IMSI为“123450001234567”的智能寻呼策略，执行如下命令：

```
%%LST NGPEIPSPLCY: SUBRANGE=SPECIFIC_IMSI, IMSI="123450001234567";%%
RETCODE = 0  操作成功

结果如下
--------
                     用户范围  =  指定IMSI
                    IMSI 前缀  =  NULL
                         IMSI  =  123450001234567
                 特征条件组合  =  仅指定DNN条件
                          DNN  =  HUAWEI.COM
                 切片业务类型  =  65535
                 切片细分标识  =  FFFFFF
                     寻呼概率  =  小于等于100%
                 寻呼分组来源  =  使用配置
                 寻呼分组标识  =  0
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                           |
|:--------|:--------------------------------------------------------------------------------|
| 用户范围    | 该参数用于指定寻呼分组标识下发的用户范围。                                                           |
| IMSI前缀  | 该参数用于指定应用基于分组的智能寻呼策略的用户IMSI前缀。                                                  |
| IMSI    | 该参数用于指定应用基于分组的智能寻呼策略的用户IMSI（完整IMSI）。                                            |
| 特征条件组合  | 该参数用于指示特征条件的组合。                                                                 |
| DNN     | 该参数用于指定需要进行智能寻呼用户的DNN。                                                          |
| 切片业务类型  | 该参数用于指定需要进行智能寻呼用户的签约切片业务类型特征。如eMBB（1）、URLLC（2）、MIoT（3）等协议定义的标准SST，或者运营商自定义的SST。 |
| 切片细分标识  | 该参数用于指定需要进行智能寻呼用户的签约切片细分标识特征。                                                   |
| 寻呼概率    | 该参数用于指定需要进行智能寻呼终端的寻呼概率。                                                         |
| 寻呼分组来源  | 该参数用于指定下发给UE和NG-RAN使用的寻呼分组取值来源。                                                 |
| 寻呼分组标识  | 该参数用于指定下发给UE和NG-RAN的寻呼分组标识。 该参数需要与无线配合使用。                                       |
