# 查询PAE内联口MTU值（LST FABRICMTU）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询PAE内联口MTU。

通过查询PAE内联口MTU值，方便故障诊断。

#### 注意事项

- 该命令仅适用于非NP卡场景、NP卡非加速模式场景，以及NP卡ECMP组网模式下的fabric平面。
- 该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询PAE内联口MTU值：

```
%%LST FABRICMTU:;%%
RETCODE = 0  操作成功

结果如下:
---------
MTU值（byte）  =  1800
(结果个数 = 1)

---    END
```

#### 输出结果说明

| 输出项名称      | 输出项解释           |
|:-----------|:----------------|
| MTU值（byte） | 用于表示PAE内联口MTU值。 |
