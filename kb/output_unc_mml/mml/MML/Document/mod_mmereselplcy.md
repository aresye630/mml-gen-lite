# 修改MME重选策略(MOD MMERESELPLCY)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于修改不同用户范围内MME重选策略参数。

#### 注意事项

- 无。

#### 本地用户权限

manage-ug；system-ug；

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称              | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
|:--------------|:------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE      | 用户范围              | 可选必选说明：必选参数 参数含义：该参数用于指定待进行网元重选的用户范围。 数据来源：整网规划 取值范围： ALL_USER（所有用户）：表示用户范围为系统内所有用户。HOME_USER（本网用户）：表示用户范围为本网用户。FOREIGN_USER（外网用户）：表示用户范围为外网用户。IMSI_PREFIX（指定IMSI前缀）：表示用户范围通过IMSI前缀指定。 默认值：无                                                                                                                                                                                                                                                                                      |
| NOID          | 运营商标识             | 可选必选说明：条件必选参数 参数含义：该参数用于指定运营商标识。 前提条件：该参数在“用户范围”参数配置为“HOME_USER(本网用户)”或“FOREIGN_USER(外网用户)”后生效。 数据来源：整网规划 取值范围：0～64，128～254 默认值：无 配置原则：若该参数需要配置为0或128～254之间的值时，须先在ADD MNO中配置取值相同的“MNOID”参数。若该参数需要配置为1～64之间的值时，须先在ADD MVNO中配置取值相同的“MVNOID”参数。                                                                                                                                                                                                                                      |
| IMSIPRE       | IMSI前缀            | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI前缀以区分不同的用户群。 前提条件：该参数在"用户范围"参数配置为"指定IMSI前缀"后生效。 数据来源：整网规划 取值范围：5~15十进制数字字符串 默认值：无                                                                                                                                                                                                                                                                                                                                                                   |
| RESELSW       | 重选开关              | 可选必选说明：可选参数 参数含义：该参数用于指定是否开启选择功能。 数据来源：整网规划 取值范围： OFF：关闭ON：开启 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                               |
| RESELPLCY     | 重选策略              | 可选必选说明：条件可选参数 参数含义：该参数用于指定进行MME网元重选的方式。 前提条件：该参数在“重选开关”参数配置为“ON(开启)”后生效。 数据来源：整网规划 取值范围： REROUTE_NAS：使用“REROUTE_NAS”Request方式。 配置原则：当需要通过Reroute NAS Request消息将用户新接入的Attach Request或TAU Request消息重选到目标MME时，将此参数设置为“REROUTE_NAS”。 默认值：无                                                                                                                                                                                                                                            |
| RESELCOND     | 重选条件              | 可选必选说明：条件可选参数 参数含义：该参数用于指定进行MME网元重选时需要满足的条件。 前提条件：该参数在“重选策略”参数配置为“使用Reroute NAS Request方式”后生效。 数据来源：整网规划 取值范围： DCNR：根据UE网络能力中的DCNR字段制定匹配条件。如果用户的UE网络能力中支持DCNR，则用户符合重选条件。DCNR_UUT_INCLUDE：根据UE网络能力中的DCNR字段和UE USAGE TYPE属于UE USAGE TYPE群组制定匹配条件。如果用户的UE网络能力中支持DCNR，并且用户的UE USAGE TYPE在所配置的UE USAGE TYPE群组范围内，则用户符合重选条件。DCNR_UUT_NOT_INCLUDE：根据UE网络能力中的DCNR字段和UE USAGE TYPE不属于UE USAGE TYPE群组制定匹配条件。如果用户的UE网络能力中不支持DCNR，或者用户的UE USAGE TYPE不在所配置的UE USAGE TYPE群组范围内，则用户符合重选条件。 默认值：无 |
| UEUSGTYPEGPID | UE USAGE TYPE群组标识 | 可选必选说明：条件可选参数 参数含义：该参数用于指定UE USAGE TYPE群组标识。 前提条件：该参数在“重选条件”参数配置为“DCNR_UUT_INCLUDE”后生效。该参数在“重选条件”参数配置为“DCNR_UUT_NOT_INCLUDE”后生效。 数据来源：整网规划 取值范围：0~1023的整数类型。 默认值：无 配置原则：此参数已通过ADD UEUSGTYPEGP配置。                                                                                                                                                                                                                                                                                  |
| TMMEGPIDX     | 目标MME组索引          | 可选必选说明：条件可选参数 参数含义：该参数用于指定进行MME网元选择时的目标MME群组的标识。 前提条件：该参数在“重选策略”参数配置为“使用Reroute NAS Request方式”后生效。 数据来源：整网规划 取值范围：0~63的整数类型。 默认值：无 配置原则：该参数必须已经在ADD MMEGP配置。                                                                                                                                                                                                                                                                                                                      |

#### 使用实例

1. 修改用户范围为“所有用户”，重选开关为“ON（开启）”，重选策略为“REROUTE\_NAS(使用Reroute NAS Request方式)”，重选条件为“DCNR(根据网络能力重选NSA用户)”，目标MME组索引为“0”的记录

   MOD MMERESELPLCY: SUBRANGE=ALL\_USER, RESELSW=ON, RESELPLCY=REROUTE\_NAS, RESELCOND=DCNR, TMMEGPIDX=0;
