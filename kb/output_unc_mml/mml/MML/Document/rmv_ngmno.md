# 删除5G模式移动网络运营商信息（RMV NGMNO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C、AMF、SMF、NRF、NSSF、CBC、CBCF**

该命令用于删除移动网络运营商基本信息。

“NOID”为0的默认记录不允许被删除。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                 |
|:-------|:-------|:-------------------------------------------------------------------------------------|
| NOID   | 运营商标识  | 可选必选说明：必选参数  参数含义：该参数用于在系统内唯一标识移动网络运营商。  数据来源：本端规划  取值范围：整数类型，取值范围为0。  默认值：无  配置原则：无 |

## 使用实例

删除退网运营商的信息，执行如下命令：

```
RMV NGMNO: NOID=0;
```
