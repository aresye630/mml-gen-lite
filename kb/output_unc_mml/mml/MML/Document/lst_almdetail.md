# 查询告警详细信息（LST ALMDETAIL）

#### 命令功能

**适用网元：SGSN、MME、AMF**

该命令用于查询批量告警的详细故障信息。

#### 注意事项

- 当“详细信息”选择为“YES(是)”时，系统内可能存在许多原始告警，导致该命令返回时间过长。可通过在命令中限定“起始时间”和“结束时间”来减少查询记录数。
- 由于批量告警是在原始告警产生后按照一定周期合并的结果，所以原始告警的实际故障时间早于批量告警的产生时间。
- 如果批量告警进行了刷新，原始告警和批量告警的时间可能相差很多，因此当根据某条批量告警产生时间作为查询条件时，只能作为命令的“结束时间”。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                            |
|:----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ALMTYPE   | 告警类型   | 可选必选说明：可选参数 参数含义：该参数用于指定告警类型。 数据来源：本端规划 取值范围：“S1apLinkDown(S1ap链路故障)”“SCTPPacketErrorRateTooHigh(SCTP链路错包率过高)”“SCTPFlowControl(S1接口SCTP层流控)”“FrequentIntermittenceofLinks(批量链路频繁闪断)”“RanSctpFlowControl(RAN侧SCTP层链路拥塞流控)” 默认值：无 |
| DETAIL    | 详细信息   | 可选必选说明：分支可选参数 参数含义：该参数用于指定是否输出“告警类型”对应的详细信息。 前提条件：该参数在“告警类型”参数配置后生效。 数据来源:本段规划 取值范围：“NO(否)”“YES(是)” 默认值：“NO(否)”                                                                                                                 |
| SGT       | 起始时间   | 可选必选说明：分支可选参数 参数含义：该参数用于指定系统查询告警产生时间的起始时间。 前提条件：该参数在“详细信息”参数配置为“YES(是)”后生效。 数据来源：本端规划 取值范围：1970-01-01～2099-12-31 默认值：无                                                                                                          |
| EGT       | 结束时间   | 可选必选说明：分支可选参数 参数含义：该参数用于指定系统查询告警产生时间的结束时间。 前提条件：该参数在“详细信息”参数配置为“YES(是)”后生效。 数据来源：本端规划 取值范围：1970-01-01～2099-12-31 默认值：无                                                                                                          |
| MAXRECORD | 最大记录数  | 可选必选说明：分支可选参数 参数含义：该参数用于指定系统查询告警的最大记录数。 前提条件：该参数在“详细信息”参数配置为“YES(是)”后生效。 数据来源：本端规划 取值范围：1～1000 默认值：1000                                                                                                                         |

#### 输出结果说明

| 输出项名称        | 输出项解释                                   |
|:-------------|:----------------------------------------|
| 告警名称         | 告警的名称。                                  |
| 告警ID         | 告警的ID。                                  |
| 故障时间         | 产生告警的时间。                                |
| RU名称         | 产生告警模块所在的RU。                            |
| 进程类型         | 产生告警模块所在的进程类型。                          |
| 进程号          | 产生告警模块所在的进程号。                           |
| PLMN         | 产生告警的eNodeB的所属PLMN。                     |
| EnodeB类型     | 产生告警的eNodeB的类型，取值如下：HOMEMACRO           |
| EnodeB编码     | 产生告警的eNodeB的ID。                         |
| EnodeB名称     | 产生告警的eNodeB的名称。                         |
| EnodeBIP地址1  | 产生告警的eNodeB的第一个IP地址。                    |
| EnodeBIP地址2  | 产生告警的eNodeB的第二个IP地址。                    |
| MME IP地址1    | 产生告警的MME的第一个IP地址。                       |
| MME IP地址2    | 产生告警的MME的第二个IP地址。                       |
| 故障原因         | 链路故障的原因。具体原因是：对端主动断链（0）本端主动断链（1）其他（255） |
| 故障链路个数       | S1AP链路故障的个数。                            |
| 检测错包率（%）     | 每分钟统计该SCTP偶联的错包数/该分钟内SCTP偶联的收包数。        |
| 错误消息包个数      | 每分钟统计该SCTP偶联的错包数。                       |
| 门限（%）        | 该SCTP偶联的错包率大于此门限时，系统判断该SCTP偶联业务受损，需要告警。 |
| 接口类型         | 链路接口类型：S1接口N2接口                         |
| 链路个数         | SCTP偶联故障的个数。                            |
| 当前门限（%）      | 告警产生时的告警门限。                             |
| 平均错包率（%）     | 所有SCTP故障偶联的错误率的平均值。                     |
| EnodeB端口号    | 产生告警的eNodeB端口号。                         |
| MME端口号       | 产生告警的MME端口号。                            |
| 流控链路个数       | S1接口SCTP层流控链路个数。                        |
| 闪断次数         | 某条链路发生瞬间闪断的次数。                          |
| 闪断时间1        | 链路第一次发生瞬间闪断的时间。                         |
| 闪断时间2        | 链路第二次发生瞬间闪断的时间。                         |
| 闪断时间3        | 链路第三次发生瞬间闪断的时间。                         |
| 链路类型         | 产生告警的链路类型。目前仅支持S1AP链路。                  |
| 链路条数         | 发生频繁闪断的链路条数。                            |
| 对端IP地址1      | 产生告警的eNodeB/gNodeB的第一个IP地址。             |
| 对端IP地址2      | 产生告警的eNodeB/gNodeB的第二个IP地址。             |
| 对端端口号        | 产生告警的eNodeB/gNodeB端口号。                  |
| 本端IP地址1      | 产生告警的MME/AMF的第一个IP地址。                   |
| 本端IP地址2      | 产生告警的MME/AMF的第二个IP地址。                   |
| 本端端口号        | 产生告警的MME/AMF端口号。                        |
| 偶联ID         | 产生告警的链路偶联ID。                            |
| 最大带宽         | 产生告警时，链路100ms发送成功的字节数。                  |
| 最小RTT        | 产生告警时的最小RTT，单位：ms。                      |
| TX消息占用率（%）   | 产生告警时，消息发送缓冲区的占用率。                      |
| TX消息缓存时长（ms） | 产生告警时，消息发送缓冲区基于当前最大带宽发送完成所需时间。          |
