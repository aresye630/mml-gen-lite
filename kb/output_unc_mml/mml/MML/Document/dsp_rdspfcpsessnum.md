# 显示RADIUS中转UPF的PFCP会话数目（DSP RDSPFCPSESSNUM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于显示RADIUS中转UPF，UPC创建的会话数目。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                                      |
|:--------------|:--------|:--------------------------------------------------------------------------------------------------------------------------|
| QUERYTYPE     | 查询类型    | 可选必选说明：必选参数  参数含义：该参数用于指定查询类型。  数据来源：本端规划 取值范围： ALL（全部）UPFID（UP实例标识）  默认值：无  配置原则：无                                       |
| UPFINSTANCEID | UPF实例标识 | 可选必选说明：该参数在"QUERYTYPE"配置为"UPFID"时为条件必选参数。  参数含义：该参数用于指示UPF实例ID。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~36。不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

查询所有RADIUS中转UPF的会话数量。 DSP RDSPFCPSESSNUM: QUERYTYPE=ALL;

```
%%DSP RDSPFCPSESSNUM: QUERYTYPE=ALL;%%
RETCODE = 0  操作成功。

结果如下
------------------------
RADIUS中转UPF的PFCP会话数目  =  4
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称                | 输出项解释               |
|:---------------------|:--------------------|
| RADIUS中转UPF的PFCP会话数目 | 表示Radius中转UPF会话的数量。 |
