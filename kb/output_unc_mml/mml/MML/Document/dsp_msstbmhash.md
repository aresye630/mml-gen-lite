# 通过关键字查询哈希表的结果（DSP MSSTBMHASH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于关键字查询哈希表的结果。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                   |
|:----------|:-------|:-------------------------------------------------------------------------------------------------------|
| RUNAME    | RU名称   | 可选必选说明：必选参数 参数含义：该参数用于指定RU名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：使用DSP RU查看RU名称。 |
| TABLEID   | 表号     | 可选必选说明：必选参数 参数含义：该参数用于表示表号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                               |
| HASHKEY   | 哈希关键字  | 可选必选说明：必选参数 参数含义：该参数用于表示哈希关键字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～127。 默认值：无                                |
| MATCHTYPE | 匹配类型   | 可选必选说明：必选参数 参数含义：该参数用于表示匹配类型。 数据来源：本端规划 取值范围：枚举类型。 exact：精确匹配。noexact：模糊匹配。 默认值：无                      |

#### 使用实例

查询关键字查询哈希表的结果：

```
DSP MSSTBMHASH:TABLEID = 1,HASHKEY = "1",MATCHTYPE = exact,RUNAME  = "VNODE_VNRS_VNFC_IPU_0064";
```

#### 输出结果说明

| 输出项名称   | 输出项解释                    |
|:--------|:-------------------------|
| 初始化标识   | 用于表示初始化标识。               |
| 表项存在标识  | 用于表示表项存在标识。              |
| 哈希桶表项数量 | 用于表示哈希桶表项数量，适用于所有哈希表。    |
| 表类型     | 用于表示算法表类型。               |
| 转发表前缀长度 | 用于表示转发表前缀长度，适用于FIB4表。    |
| 表项索引    | 用于表示表项索引，适用于FIB4表和FIB6表。 |
| 错误码     | 用于表示表操作错误码。              |
