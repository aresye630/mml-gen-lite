# 查询N14N26接口跨运营商交互策略（LST N14N26INTOPPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询本AMF和其它运营商的AMF/MME之间的N14/N26接口跨运营商交互策略。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称       | 参数说明                                                                                                                                        |
|:--------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------|
| PEERMCC | 对端运营商移动国家码 | 可选必选说明：可选参数  参数含义：该参数用于指定需要控制交互策略的对端运营商的Serving PLMN中的移动国家码。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~3。  默认值：无  配置原则：  只允许输入3位十进制数字（0-9）或1位通配符（*）。  |
| PEERMNC | 对端运营商移动网号  | 可选必选说明：可选参数  参数含义：该参数用于指定需要控制交互策略的对端运营商的Serving PLMN中的移动网号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~3。  默认值：无  配置原则：  只允许输入2~3位十进制数字（0-9）或1位通配符（*）。 |

## 使用实例

- 查询本AMF和其它运营商的AMF/MME之间的跨运营商交互策略，执行如下命令：

  ```
  %%LST N14N26INTOPPLCY:;%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
     对端运营商移动国家码  =  123
       对端运营商移动网号  =  45
  N14接口跨运营商交互策略  =  是
  N26接口跨运营商交互策略  =  否
  (结果个数 = 1)

  ---    END
  ```
- 查询本AMF和运营商A的AMF/MME之间的跨运营商交互策略，执行如下命令：

  ```
  %%LST N14N26INTOPPLCY:PEERMCC="123",PEERMNC="45";%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
     对端运营商移动国家码  =  123
       对端运营商移动网号  =  45
  N14接口跨运营商交互策略  =  是
  N26接口跨运营商交互策略  =  否
  (结果个数 = 1)

  ---    END
  ```

## 输出结果说明

| 输出项名称         | 输出项解释                                                     |
|:--------------|:----------------------------------------------------------|
| 对端运营商移动国家码    | 该参数用于指定需要控制交互策略的对端运营商的Serving PLMN中的移动国家码。                |
| 对端运营商移动网号     | 该参数用于指定需要控制交互策略的对端运营商的Serving PLMN中的移动网号。                 |
| N14接口跨运营商交互策略 | 该参数用于指定在5G内移动性流程中，是否允许本AMF和指定运营商的AMF之间通过N14接口跨运营商传递用户上下文。 |
| N26接口跨运营商交互策略 | 该参数用于指定在45G互操作流程中，是否允许本AMF和指定运营商的MME之间通过N26接口跨运营商传递用户上下文。 |
