# 查询IPv6指定的VPN路由表项统计（DSP SFEFIB6STC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询IPv6指定的VPN路由表项统计。FIB6用于保存报文转发信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                               |
|:--------|:-------|:-------------------------------------------------------------------------------------------------------------------|
| RUNAME  | RU名称   | 可选必选说明：必选参数 参数含义：该参数用于指定资源单元名称，可使用命令DSP RU查询得到。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。区分大小写。 默认值：无 配置原则：使用DSP RU查看RU名称。 |
| VPNNAME | VPN名称  | 可选必选说明：可选参数 参数含义：该参数用于指定VPN名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                                             |

#### 使用实例

查询IPv6指定的VPN路由表项统计：

```
DSP SFEFIB6STC : RUNAME="VNODE_VNRS_VNFC_IPU_0066", VPNNAME="_public_";
```

```
RETCODE = 0  操作成功。

结果如下
-------------------------
             VPN名称  =  _public_
全部使用FIB6表项总数  =  4
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称        | 输出项解释         |
|:-------------|:--------------|
| VPN名称        | 用于指定VPN名称。    |
| 全部使用FIB6表项总数 | 用于表示VPN的路由总数。 |
