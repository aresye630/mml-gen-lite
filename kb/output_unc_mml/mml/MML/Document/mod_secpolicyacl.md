# 修改安全策略ACL规则（MOD SECPOLICYACL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来修改一个安全策略规则。

#### 注意事项

- 该命令执行后立即生效。
- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称      | 参数说明                                                                                                                                                                                                      |
|:----------------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SECPOLICYID     | 安全策略编号    | 可选必选说明：必选参数 参数含义：安全策略号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～30。 默认值：无                                                                                                                                              |
| SECPOLICYTYPE   | 安全策略类型    | 可选必选说明：必选参数 参数含义：安全策略类型。 数据来源：本端规划 取值范围：枚举类型。 WhiteList：白名单。BlackList：黑名单。UserFlow：用户自定义流。IPV6WhiteList：IPv6白名单。IPV6BlackList：IPv6黑名单。IPV6UserFlow：IPv6用户自定义流。 默认值：无                                      |
| SECPOLICYTYPEID | 安全策略类型编号  | 可选必选说明：条件必选参数 前提条件：该参数在“SECPOLICYTYPE”配置为“UserFlow” 或 “IPV6UserFlow”时为必选参数。 参数含义：安全策略类型编号，对应不同策略类型其含义不同，如SECPOLICYTYPE为User Flow，则此值为1－32的数值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                |
| SECACLNUM       | 安全ACL规则编号 | 可选必选说明：条件必选参数 前提条件：该参数在“SECPOLICYTYPE”配置为“WhiteList”、“BlackList”、“IPV6BlackList”、“IPV6WhiteList”、“UserFlow” 或 “IPV6UserFlow”时为必选参数。 参数含义：安全规则号。 数据来源：本端规划 取值范围：整数类型，取值范围为2000～3999。 默认值：无 配置原则：2000-3999。 |

#### 使用实例

修改安全策略规则：

```
MOD SECPOLICYACL:SECPOLICYID=1,SECPOLICYTYPE=WhiteList,SECACLNUM=2001;
```
