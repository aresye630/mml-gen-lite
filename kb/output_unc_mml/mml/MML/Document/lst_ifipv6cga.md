# 查询IPv6 CGA地址信息（LST IFIPV6CGA）

#### 命令功能

该命令用于查询IPv6 CGA地址配置信息。

#### 注意事项

- 该命令执行后立即生效。
- 该命令可以在VNRS\_VNFC的Ethernet接口，Ethernet子接口上配置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                             |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------------|
| IFNAME | 接口名    | 可选必选说明：可选参数 参数含义：该参数用于指定IPv6地址CGA信息的接口名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。接口名称由接口类型+接口编号组成。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。 |

#### 使用实例

查询接口IPv6 CGA信息：

```
LST IFIPV6CGA:IFNAME="ethernet64/0/3";
```

```
RETCODE = 0  操作成功

结果如下
-------------------------

密钥名称  =  aa

(结果个数 = 1)
---   END
```
