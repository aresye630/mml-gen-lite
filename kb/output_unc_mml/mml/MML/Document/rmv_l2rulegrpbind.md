# 删除层二规则组与用户的绑定关系（RMV L2RULEGRPBIND）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于删除层二规则组与用户的绑定关系。

## 注意事项

该命令执行后只对新接入的会话生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                |
|:------------|:----------|:----------------------------------------------------------------------------------------------------|
| GRPBINDNAME | 层二规则组绑定名称 | 可选必选说明：必选参数  参数含义：该参数用于指定层二规则组绑定名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。不支持空格，不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

删除层二规则组绑定名称为“bind1”的层二规则组与用户的绑定关系：

```
RMV L2RULEGRPBIND: GRPBINDNAME="bind1";
```
