# 增加融合计费Proxy基于DNN处理动作（ADD CCPDNNACT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NCG**

该命令用于增加融合计费Proxy基于DNN的处理动作。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入1010条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                                                                                                                                 |
|:-------------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DNNTYPE      | DNN类型   | 可选必选说明：必选参数  参数含义：该参数用于指定DNN的类型。  数据来源：本端规划 取值范围： DEFAULT（针对未指定的DNN设置处理动作）VALUE（针对DNN设置处理动作）  默认值：无  配置原则：无                                                                                                                          |
| DNNID        | 数据网络名称  | 可选必选说明：该参数在"DNNTYPE"配置为"VALUE"时为条件必选参数。  参数含义：该参数用于指定数据网络名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无  配置原则：无 |
| FWDOCSENABLE | 是否转发OCS | 可选必选说明：必选参数  参数含义：该参数用于设置是否转发OCS。  数据来源：本端规划  取值范围： TRUE(TRUE)FALSE(FALSE)  默认值：无  配置原则：无                                                                                                                                            |

## 使用实例

增加数据网络名称为“IMS”的融合计费Proxy基于DNN处理动作，设置是否转发OCS为FALSE：

```
ADD CCPDNNACT: DNNTYPE=VALUE, DNNID="IMS", FWDOCSENABLE=FALSE;
```
