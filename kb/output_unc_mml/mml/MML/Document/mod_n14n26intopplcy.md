# 修改N14N26接口跨运营商交互策略（MOD N14N26INTOPPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于修改本AMF和指定运营商的AMF/MME之间的跨运营商交互策略。

## 注意事项

下一次移动性流程生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称          | 参数说明                                                                                                                                        |
|:---------------|:--------------|:--------------------------------------------------------------------------------------------------------------------------------------------|
| PEERMCC        | 对端运营商移动国家码    | 可选必选说明：必选参数  参数含义：该参数用于指定需要控制交互策略的对端运营商的Serving PLMN中的移动国家码。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~3。  默认值：无  配置原则：  只允许输入3位十进制数字（0-9）或1位通配符（*）。  |
| PEERMNC        | 对端运营商移动网号     | 可选必选说明：必选参数  参数含义：该参数用于指定需要控制交互策略的对端运营商的Serving PLMN中的移动网号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~3。  默认值：无  配置原则：  只允许输入2~3位十进制数字（0-9）或1位通配符（*）。 |
| N14INTEROPPLCY | N14接口跨运营商交互策略 | 可选必选说明：可选参数  参数含义：该参数用于指定在5G内移动性流程中，是否允许本AMF和指定运营商的AMF之间通过N14接口跨运营商传递用户上下文。  数据来源：全网规划 取值范围： “YES（是）”：是“NO（否）”：否  默认值：无  配置原则：无             |
| N26INTEROPPLCY | N26接口跨运营商交互策略 | 可选必选说明：可选参数  参数含义：该参数用于指定在45G互操作流程中，是否允许本AMF和指定运营商的MME之间通过N26接口跨运营商传递用户上下文。  数据来源：全网规划 取值范围： “YES（是）”：是“NO（否）”：否  默认值：无  配置原则：无             |

## 使用实例

修改本AMF和运营商A之间的运营商交互策略，允许通过N14接口交互，执行如下命令：

```
MOD N14N26INTOPPLCY:PEERMCC="123",PEERMNC="45",N14INTEROPPLCY=YES;
```
