# 修改5G LAN群组（MOD NGLANGROUP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于修改5G LAN群组。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                        |
|:---------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DNN            | DNN       | 可选必选说明：必选参数  参数含义：该参数用于指定5G LAN群组支持的DNN，即用户请求的DNN。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无  配置原则：无                                                                                                                  |
| SST            | 切片业务类型    | 可选必选说明：必选参数  参数含义：该参数用于指定5G LAN群组支持的网络切片业务类型。网络切片标识（S-NSSAI）由切片业务类型（SST）和切片细分标识（SD）两部分组成。  数据来源：全网规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无                                                                                                                                                                                                  |
| SD             | 切片细分标识    | 可选必选说明：必选参数  参数含义：该参数用于指定5G LAN群组支持的网络切片细分标识。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。只能由数字（0-9），字母（A-F、a-f）组成。字母大小写不敏感。  默认值：无  配置原则：无                                                                                                                                                                                                               |
| PDUSESSIONTYPE | PDU会话类型   | 可选必选说明：必选参数  参数含义：该参数用于指定5G LAN群组支持的PDU会话类型。  数据来源：全网规划 取值范围： Ethernet（以太类型会话）IPv4（IPv4类型会话）IPv6（IPv6类型会话）IPv4v6（IPv4v6类型会话）  默认值：无  配置原则：无                                                                                                                                                                                                 |
| GROUPID        | 5G LAN组ID | 可选必选说明：可选参数  参数含义：该参数用于指定5G LAN群组的ID。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是18~37。字母大小写不敏感且全局唯一。  默认值：无  配置原则：  GROUPID以连字号分为4段，形式为GroupServiceID-MCC-MNC-LocalGroupID。其中，GroupServiceID长度为8，只能输入数字或者范围为A-F或a-f的字母；MCC长度为3，只能输入数字；MNC长度为2~3，只能输入数字；LocalGroupID长度为2~20的偶数，只能输入数字或者范围为A-F或a-f的字母。例如，A0000001-460-003-01，A0000001-460-003-A000000001。 |

## 使用实例

将DNN为“huawei.com”，SST为1，SD为“010101”，PDU会话类型为Ethernet的5G LAN群组的GROUPID修改为“A0000001-460-003-02”，执行如下命令：

```
MOD NGLANGROUP: DNN="huawei.com", SST=1,SD="010101", PDUSESSIONTYPE=Ethernet,GROUPID="A0000001-460-003-02";
```
