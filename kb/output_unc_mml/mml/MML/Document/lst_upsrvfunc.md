# 查询UP服务管理功能（LST UPSRVFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C、SMF**

该命令用于查询UP服务管理功能。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询UNC的UP服务管理功能。

```
%%LST UPSRVFUNC:;%%
RETCODE = 0  操作成功

结果如下
----------------
           权重调整策略  =  不调整
   增值业务预留权重比例  =  10
增值UPF预估增值业务占比  =  20
UPF上报动态负载的有效期  =  60
           增值业务功能  =  重点业务保障&用户体验
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称         | 输出项解释                                     |
|:--------------|:------------------------------------------|
| 权重调整策略        | 该参数用于控制UPF选择过程中，UPF权重调整策略。                |
| 增值业务预留权重比例    | 该参数用于控制普通业务UPF选择时，增值UPF为增值业务预留的权重比例。      |
| 增值UPF预估增值业务占比 | 该参数用于控制普通业务UPF选择时，增值UPF未上报有效信息时预估的增值业务占比。 |
| UPF上报动态负载的有效期 | 该参数用于控制UPF上报动态负载的有效期。                     |
| 增值业务功能        | 该参数用于指定UPF统计为增值业务的功能类型。                   |
