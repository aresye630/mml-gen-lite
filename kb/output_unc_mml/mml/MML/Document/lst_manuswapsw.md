# 查询手工倒换开关（LST MANUSWAPSW）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NRF**

该命令用于查询手工倒换开关。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询手工倒换开关，执行如下命令：

```
LST MANUSWAPSW:;
%%LST MANUSWAPSW:;%%
RETCODE = 0  执行成功

结果如下
--------
NRF服务化接口阻断控制开关  =  关闭
(结果个数 = 1) 

---    END
```

## 输出结果说明

| 输出项名称          | 输出项解释                                                                |
|:---------------|:---------------------------------------------------------------------|
| NRF服务化接口阻断控制开关 | 该参数用于表示是否阻断NRF服务化接口。开关打开后，将导致现有的NRF服务化接口链路断连，并且阻止新的接口链路建立，NRF整体业务中断。 |
