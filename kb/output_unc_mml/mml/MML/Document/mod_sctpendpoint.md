# 修改SCTP端点（MOD SCTPENDPOINT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

**须知** 

本命令属于高危命令，修改SCTP端点可能导致Diameter链路重建或中断，进而影响用户使用业务，比如用户被去活等。

此命令用于修改SCTP端点信息。

#### 注意事项

- 该命令执行后立即生效。
- 同一个Port下不能配置相同IP。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                                                                                   |
|:--------------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
| ENDPOINTNAME  | 端点名称     | 可选必选说明：必选参数 参数含义：该参数用于指定SCTP端点名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                          |
| IPVERSION     | IP版本     | 可选必选说明：可选参数 参数含义：该参数用于指定SCTP端点的IP地址类型。 数据来源：对端协商 取值范围：枚举类型。 IPV4：IPv4地址类型。IPV6：IPv6地址类型。 默认值：无 配置原则：无                                                  |
| IPV4ADDRESS1  | IPv4地址1  | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV4”时为必选参数。 参数含义：该参数用于指定SCTP端点的IPv4地址1。 数据来源：对端协商 取值范围：IPv4地址类型。 默认值：无 配置原则：此参数无法被重置为0.0.0.0。                   |
| IPV4ADDRESS2  | IPv4地址2  | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPV4”时为可选参数。 参数含义：该参数用于指定SCTP端点的IPv4地址2。 数据来源：对端协商 取值范围：IPv4地址类型。 默认值：无 配置原则：将此参数重置为0.0.0.0，需要将该参数配置为0.0.0.0。    |
| PORT          | 端口号      | 可选必选说明：可选参数 参数含义：该参数用于指定SCTP端点端口号。 数据来源：对端协商 取值范围：整数类型，取值范围为1～65534。 默认值：无 配置原则：无                                                                      |
| SCTPTEMPLNAME | SCTP模板名称 | 可选必选说明：可选参数 参数含义：该参数用于指定SCTP模板名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则： 该参数使用ADD SCTPTEMPLATE命令配置生成。输入单空格将删除该参数已有配置项。                          |
| IPV6ADDRESS1  | IPv6地址1  | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPV6”时为可选参数。 参数含义：该参数用于指定SCTP端点的IPv6地址1。 数据来源：对端协商 取值范围：IPv6地址类型。 默认值：无 配置原则：此参数无法被重置为::。                        |
| IPV6ADDRESS2  | IPv6地址2  | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPV6”时为可选参数。 参数含义：该参数用于指定SCTP端点的IPv6地址2。 数据来源：对端协商 取值范围：IPv6地址类型。 默认值：无 配置原则：将此参数重置为::，需要将该参数配置为0:0:0:0:0:0:0:0。 |

#### 使用实例

根据网络规划，需要修改一个SCTP端点，则可以按如下配置：

```
MOD SCTPENDPOINT: ENDPOINTNAME="sctp_ep1",IPVERSION=IPV4,IPV4ADDRESS1="10.1.1.1",IPV4ADDRESS2="10.1.1.3",SCTPTEMPLNAME="sctp_tp1";
```
