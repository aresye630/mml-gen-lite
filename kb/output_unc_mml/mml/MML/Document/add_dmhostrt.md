# 增加Diameter主机路由(ADD DMHOSTRT)

#### 命令功能

**适用网元：SGSN、MME**

该命令用于新增一条Diameter主机路由。主机路由是指通过请求消息中的destination-host信元来选择对端。

#### 注意事项

- 该命令执行后立即生效。
- 本表最大记录数1024。
- 当本配置应用于S6a/S6d或者S13接口时，如果BYTE\_EX17 BIT1置为1，本配置不生效。
- 在UNC和HSS或者GMLC直连时使用此命令。相同选路模式的主机路由可以通过命令**ADD DMRTGRP**配到同一个Diameter路由组中，业务通过引用路由组配置进行选路。
- 若Diameter路由组中存在属于该Diameter主机路由的“路由索引”，则配置才能生效。Diameter路由组信息请参考**LST DMRTGRP**命令。
- 该命令部分参数与相关特性license共同完成该特性的开启，请在设置参数前使用**DSP LICENSE**命令确认对应特性license是否得到授权，执行**LST LICENSESWITCH**命令确认特性开关状态为“ENABLE(打开)”，具体相关特性请参考参数的说明。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
|:----------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ROUTEIDX  | 路由索引     | 可选必选说明：必选参数 参数含义：该参数用于在系统范围内标识一条Diameter主机路由。 数据来源：本端规划 取值范围：0~1023 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| APPNAM    | 应用名称     | 可选必选说明：可选参数 参数含义：该参数用于指定该条主机路由对应的应用接口类型。 数据来源：整网规划 取值范围：“S6A/S6D(S6a/S6d)”：表示该主机路由用于S6a/S6d接口，在对端网元为HSS时，选择该应用。“S13(S13)”：表示该主机路由用于S13接口，在对端网元为EIR时，选择该应用。“SLG(SLg)”：表示该主机路由用于SLg接口，在对端网元为GMLC时，选择该应用。“T6A/T6AI/T6B/T6BI(T6a/T6ai/T6b/T6bi)”：表示该主机路由用于T6a/T6ai/T6b/T6bi接口。其中T6a为MME到SCEF的接口；T6ai为MME到IWK-SCEF的接口；T6b为SGSN到SCEF的接口；T6bi为SGSN到IWK-SCEF的接口。 默认值：S6A/S6D(S6a/S6d) 配置原则：目前不支持S13(S13)                                                                                                                                                                                                                                                                                                                                                                                                  |
| RSELMODE  | 选路模式     | 可选必选说明：可选参数 参数含义：该参数用于指定主机路由选择对端的模式。 数据来源：整网规划 取值范围：“SELMODE_ROUND_ROBIN(轮选)”：当同一Diameter路由组存在多条Diameter主机路由时，采用顺序选择的方式选择主机路由。这种选路模式在负荷分担场景时使用。“SELMODE_MASTER_SLAVE(主从)”：当同一Diameter路由组存在多条Diameter主机路由时，采用主从选择的方式选择主机路由。主从关系根据配置的优先级来确定，参见PRIORITY参数。这种选路模式在主备场景时使用。“SELMODE_PRIORITY_WEIGHT(优先级权重)”：表示同一Diameter路由组存在多条Diameter主机路由时，先根据优先级选择主机路由，优先级相同时，再根据权重选择主机路由。 这种选路模式用于对端设备支持不同的接入能力时，通过指定不同的权重来使得能力较强的设备可以处理更多的消息。通过指定优先级可将设备根据优先级分组，支持复杂的负载分担方式。 默认值：SELMODE_MASTER_SLAVE(主从)  说明： 如果此主机路由配到Diameter路由组中，同一Diameter路由组下主机路由的选路模式必须相同。在“MML命令行-UNC”窗口上执行命令LST DMRTGRP查询路由组配置。“目的实体选择方式”为“PEER_HOST_NAME(对端主机名)”的主机路由不能配置成“SELMODE_MASTER_SLAVE(主从)”模式当参数设置为“SELMODE_PRIORITY_WEIGHT(优先级权重)”时，“基于权重/优先级的Diameter负荷分担”特性的相关license授权并开启后，此参数配置才生效（特性编号：WSFD-104404，License项：LKV2DMLS01）。 |
| PEERSEL   | 目的实体选择方式 | 可选必选说明：可选参数 参数含义：该参数用于指定对端选择方式。为了保持兼容性，可以选择对端索引或者对端主机名两种方式标识对端。 数据来源：对端协商 取值范围：“PEER_INDEX(对端索引)”“PEER_HOST_NAME(对端主机名)” 默认值：PEER_INDEX(对端索引)  说明： 只有要添加的对端主机名在DMPE中未配置，才允许将“目的实体选择方式”配置为“PEER_HOST_NAME(对端主机名)”。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| PEERIDX   | 对端实体索引   | 可选必选说明：条件必选参数 参数含义：该参数用于标识目的对端。 数据来源：本端规划 取值范围：0~639 默认值：无  说明： 该参数在“目的实体选择方式”设置为“PEER_INDEX(对端索引)”有效。该对端需支持该条主机路由的“应用名称”。建议网元类型为HSS的对端索引被主机路由引用。在“MML命令行-UNC”窗口上执行命令ADD DMPE设置此参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| PEERHTNAM | 对端主机名    | 可选必选说明：条件必选参数 参数含义：该参数用于标识目的对端的主机名。 数据来源：全网规划 取值范围：1~127位字符串。数字“0~9”，大写字母“A~Z”，小写字母“a~z”，特殊字符“-”，“.”，其他均为非法字符 默认值：无  说明： 该参数在“目的实体选择方式”设置为“PEER_HOST_NAME(对端主机名)”有效。如果该参数在DMPE中已配置，请将“目的实体选择方式”选择为“PEER_INDEX(对端索引)”，在“对端实体索引”中引用该DMPE的“对端实体索引”。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ROUTENAM  | 路由名称     | 可选必选说明：可选参数 参数含义：该参数用于指定添加主机路由的名称。 数据来源：本端规划 取值范围：0~32位字符串 默认值：无 配置原则：建议取有实际意义的名称，以方便识别。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| PRIORITY  | 优先级      | 可选必选说明：条件可选参数 参数含义：该参数用于指定主机路由中对端的优先级。 数据来源：整网规划 取值范围：0～255 默认值：无  说明： 该参数在“选路模式”设置为“SELMODE_MASTER_SLAVE(主从)”时和“SELMODE_PRIORITY_WEIGHT(优先级权重)”有效，如果该参数未配置，则系统默认优先级为0。当“选路模式”设置为“SELMODE_MASTER_SLAVE(主从)”时，同一路由组索引中主机路由的优先级不能相同。在“MML命令行-UNC”窗口上执行命令LST DMRTGRP查询路由组配置。数值越小，优先级越高。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| WEIGHT    | 权重       | 可选必选说明：可选参数 参数含义：该参数用于指定主机路由中对端的权重。 数据来源：整网规划 取值范围：1～255 默认值：1  说明： 该参数只在“选路模式”设置为“SELMODE_PRIORITY_WEIGHT(优先级权重)”有效。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |

#### 使用实例

增加一个选路模式为优先级权重，对端实体选择方式为对端索引的主机路由:

ADD DMHOSTRT: ROUTEIDX=1, RSELMODE=SELMODE\_PRIORITY\_WEIGHT, PEERSEL=PEER\_INDEX, PEERIDX=1, ROUTENAM="DRA", PRIORITY=1;
