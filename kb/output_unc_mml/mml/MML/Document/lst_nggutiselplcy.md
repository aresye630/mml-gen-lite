# 查询AMF区域GUTI选网控制策略（LST NGGUTISELPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询AMF区域GUTI选网功能控制策略。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识            | 参数名称          | 参数说明                                                                                                                                                                                                                                                                                                     |
|:----------------|:--------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AREARANGE       | 区域范围          | 可选必选说明：可选参数  参数含义：该参数用于设置GUTI选网功能的区域范围。  数据来源：全网规划 取值范围： “ALL_AREA（所有区域）”：所有区域“AREA_CODE（指定区域编码）”：指定区域编码  默认值：无  配置原则：无                                                                                                                                                                                  |
| GUTISELAREACODE | GUTI选网功能区域编码  | 可选必选说明：该参数在"AREARANGE"配置为"AREA_CODE"时为条件可选参数。  参数含义：该参数用于指定应用GUTI选网功能的某个区域。该参数已经通过ADD GUTISELAREACODE命令中的GUTISELAREACODE参数配置。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~128。该区域编码必须先通过ADD GUTISELAREACODE进行添加；而区域内的跟踪区列表则通过ADD GUTISELAREAMEM进行添加。  默认值：无  配置原则：无                                                  |
| CTRLOBJECT      | 控制对象          | 可选必选说明：可选参数  参数含义：该参数用于指定应用指定区域GUTI选网功能的用户的识别对象。  数据来源：全网规划 取值范围： “USER_GROUP（用户群）”：用户群“SUB_NS（签约切片）”：签约切片“SUB_UUT（签约UE USAGE TYPE）”：签约UE USAGE TYPE  默认值：无  配置原则：无                                                                                                                                      |
| SUBGRPID        | 用户群组标识        | 可选必选说明：该参数在"CTRLOBJECT"配置为"USER_GROUP"时为条件可选参数。  参数含义：该参数用于指定应用GUTI选网功能的用户群组。该参数已经通过ADD NGUSRGRP命令中的USRGRPID参数配置。  数据来源：全网规划  取值范围：整数类型，取值范围是0~4294967294。该用户群组标识通过ADD NGUSRGRP进行添加；群组内的用户标识列表通过ADD NGUSRGRPMEM进行添加。  默认值：无  配置原则：  当针对指定的区域，有多个用户（号段）需要进行GUTI选网时，建议通过本参数指定用户范围。  该值若不设置，默认值为4294967295。 |
| SST             | 切片业务类型        | 可选必选说明：该参数在"CTRLOBJECT"配置为"SUB_NS"时为条件可选参数。  参数含义：该参数表示切片的业务类型，如eMBB（1）、URLLC（2）、MIoT（3）等协议定义的标准SST，或者运营商自定义的SST。  数据来源：全网规划  取值范围：整数类型，取值范围是0~65534。  默认值：无  配置原则：  该值若不设置，默认值为65535。                                                                                                                   |
| SD              | 切片细分标识        | 可选必选说明：该参数在"CTRLOBJECT"配置为"SUB_NS"时为条件可选参数。  参数含义：该参数表示根据网络切片所提供的服务特点、所服务的对象差异，对某种网络切片的进一步细分。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。采用十六进制表示（无须输入“0x”前缀），只能由数字（0-9），字母（A-F、a-f）组成。字母大小写不敏感。  默认值：无  配置原则：  该值若不设置，默认值为FFFFFF。                                                                                    |
| UUT             | UE USAGE TYPE | 可选必选说明：该参数在"CTRLOBJECT"配置为"SUB_UUT"时为条件可选参数。  参数含义：该参数用于指定应用GUTI选网功能的UE Usage Type。  数据来源：全网规划  取值范围：整数类型，取值范围是0~255。该值若不设置，默认值为65535。  默认值：无  配置原则：无                                                                                                                                                    |

## 使用实例

- 查询区域编码为“GUTISelZone”，用户群组标识“1”的AMF区域重选控制策略，执行如下命令：

  ```
  %%LST NGGUTISELPLCY: AREARANGE=AREA_CODE, GUTISELAREACODE="GUTISelZone",  CTRLOBJECT=USER_GROUP, SUBGRPID=1;%%
  RETCODE = 0  操作成功

  结果如下:
  ------------------------
              区域范围  =  指定区域编码
  GUTI选网功能区域编码  =  GUTISelZone
              控制对象  =  用户群
          用户群组标识  =  1
          切片业务类型  =  65535
          切片细分标识  =  FFFFFF
         UE USAGE TYPE  =  65535
       目标AMF集合标识  =  111
         目标AMF指示符  =  11
  (结果个数 = 1)

  ---    END
  ```
- 查询当前系统的所有AMF区域GUTI选网控制策略，执行如下命令：

  ```
  %%LST NGGUTISELPLCY:;%%
  RETCODE = 0  操作成功

  结果如下:
  ------------------------
  区域范围      GUTI选网功能区域编码  控制对象    用户群组标识  切片业务类型  切片细分标识  UE USAGE TYPE  目标AMF集合标识 目标AMF指示符  

  所有区域      NULL                  签约切片    4294967295    1             AAAAAA        65535           111             11         
  指定区域编码  GUTISelZone           用户群      1             65535         FFFFFF        65535           111             11      
  (结果个数 = 2)

  ---    END
  ```
