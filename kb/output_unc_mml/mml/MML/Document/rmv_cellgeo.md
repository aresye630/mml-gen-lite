# 删除CELLID与地理坐标对应关系(RMV CELLGEO)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

此命令用于删除小区标识CID与地理位置经纬度坐标的对应关系。

#### 注意事项

- 此命令执行后立即生效。
- 小区标识CID必须在CID与地理坐标对照表中存在。
- 删除小区标识CID与地理位置经纬度坐标的对应关系后，在对该小区下2G附着的用户的定位流程中，定位流程会失败。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                   |
|:-------|:-------|:---------------------------------------------------------------------------------------|
| CID    | 小区标识   | 可选必选说明：必选参数 参数含义：该参数用于指定小区的标识，CID = MCC + MNC + LAC + RAC + CI。 取值范围：15~16位十六进制数 默认值：无 |

#### 使用实例

将CID为0123456789012345与地理位置经纬度坐标的对应关系删除：

RMV CELLGEO: CID="0123456789012345";
