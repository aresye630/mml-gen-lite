# 增加支持的S-NSSAI（ADD CFGSNSSAI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NSSF**

该命令用于增加NSSF支持的S-NSSAI列表。

## 注意事项

- 该命令执行后立即生效。

- 主备或双活组网的场景下，如果需要配置此命令，则两个NSSF上均需执行此命令，且配置参数一致。
- 该命令中相同MCC、MNC、SST下SDSTART与SDEND范围不能存在交集，该规则在配置SD时不生效。
- 最多可输入65535条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

主备或双活组网的场景下，如果需要配置此命令，则两个NSSF上均需执行此命令，且配置参数一致。
该命令中相同MCC、MNC、SST下SDSTART与SDEND范围不能存在交集，该规则在配置SD时不生效。

```
ADD CFGSNSSAI: INDEX=1, MCC="460", MNC="03", SST=1, SD="010101", PRIORITY=1025, ISACTIVE=TRUE;
2.ADD CFGSNSSAI: INDEX=1, MCC="460", MNC="03", SST=1, PRIORITY=1025, ISACTIVE=TRUE, SDSTART="000000", SDEND="FFFFFF";
```
