#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询Diameter流控节点信息。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                              |
|:----------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INDEX     | 索引     | 可选必选说明：可选参数 参数含义：该参数用于指定Diameter流控节点的索引。 数据来源：本端规划 取值范围：整数范围1~1000 默认值： 无 配置原则：无                                                                                                                                  |
| TYPE      | 类型     | 可选必选说明：可选参数 参数含义：该参数用于指定Diameter流控节点的类型。 数据来源：整网规划 取值范围：枚举值。 “BYHOSTNAME(基于主机名)”“BYREALMNAME(基于域名)” 默认值：无 配置原则：“BYHOSTNAME(基于主机名)”：配置主机名，表示基于对端实体主机名进行Diameter流控。“BYREALMNAME(基于域名)”：配置域名，表示基于对端实体域名进行Diameter流控。 |
| HOSTNAME  | 主机名    | 可选必选说明：条件可选参数 参数含义：该参数用于指定Diameter流控节点的主机名。 前提条件：该参数在“TYPE”设置为“BYHOSTNAME(基于主机名)”后生效。 数据来源：整网规划 取值范围：长度为1~127位的字符串 默认值：无 配置原则： 该参数只能由字母（A-Z或者a-z）、数字（0-9）、连字符（-）和点（.）组成。例如：epc.mnc015.mcc234.3gppnetwork.org。     |
| REALMNAME | 域名     | 可选必选说明：条件可选参数 参数含义：该参数用于指定Diameter流控节点的域名。 前提条件：该参数在“TYPE”设置为“BYREALMNAME(基于域名)”后生效。 数据来源：整网规划 取值范围：长度为1~127位的字符串 默认值：无 配置原则： 该参数只能由字母（A-Z或者a-z）、数字（0-9）、连字符（-）和点（.）组成。例如：epc.mnc015.mcc234.3gppnetwork.org。      |

#### 使用实例

1. 查询所有Diameter流控节点记录：

   LST DMOC:;
2. 查询索引为1的Diameter流控节点记录：

   LST DMOC: INDEX=1;
3. 查询主机名类型的Diameter流控节点记录（域名同理）：

   LST DMOC: TYPE=BYHOSTNAME;
4. 查询类型为BYHOSTNAME主机名为ewre的Diameter流控节点记录（域名同理）：

   LST DMOC: TYPE=BYHOSTNAME, HOSTNAME="epc.mnc015.mcc234.3gppnetwork.org";
