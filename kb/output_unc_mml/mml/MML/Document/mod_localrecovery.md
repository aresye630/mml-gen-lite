# 修改本端Recovery值及系统重启时间（MOD LOCALRECOVERY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令执行后会修改本端设备重启次数以及重启时间，可能导致周边网元认为本端网元重启引发业务呼损。

**适用NF：SGW-C、PGW-C、AMF、SMF、NRF、NSSF、GGSN、SMSF、NCG、CBC、CBCF**

该命令用于修改本端Recovery值及系统重启时间，本端Recovery值表示本端系统重启的次数。

## 注意事项

- 该命令执行后立即生效。

- 如果通过本命令修改Recovery值后，只影响当前Recovery值，后续当本端设备重启后，Recovery值会在本次修改值基础上继续增加。
- 命令执行后，系统重启时间会被设置为当前时间。
- 当SET AMFN26PLCY命令中N26ITFMODE取值为“COMBINE”时，当前命令无效，请使用命令DSP RECOVERY / MOD RECOVERY配置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称        | 参数说明                                                                                   |
|:--------------|:------------|:---------------------------------------------------------------------------------------|
| LOCALRECOVERY | 本端Recovery值 | 可选必选说明：必选参数  参数含义：该参数用于表示本端Recovery值。  数据来源：本端规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无 |

## 使用实例

如需修改本端系统重启次数为6，系统重启时间为当前时间时。

```
MOD LOCALRECOVERY:LOCALRECOVERY=6;
```
