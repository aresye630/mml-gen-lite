# 查询对鉴权信元用户名和密码的控制（LST AUTHNAMEPWDCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于查询对鉴权信元用户名和密码的控制。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                                                                                                                                                                                                 |
|:---------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| EFFECTIVESCOPE | 生效范围   | 可选必选说明：可选参数  参数含义：该参数用于指定单APN生效或全局生效。  数据来源：本端规划 取值范围： “GLOBAL（全局生效）”：全局生效“SINGLE_APN（单个APN生效）”：单个APN生效  默认值：无  配置原则：无                                                                                                                                               |
| APN            | APN名称  | 可选必选说明：该参数在"EFFECTIVESCOPE"配置为"SINGLE_APN"时为条件必选参数。  参数含义：该参数用于指定APN实例名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无  配置原则：  该参数使用ADD APN命令配置生成。 |

## 使用实例

如果需要读取所有鉴权信元内用户名和密码的填写方式，可以使用该实例：

```
LST AUTHNAMEPWDCTRL:
RETCODE = 0  操作成功

结果如下
------------------------
         生效范围  =  全局生效
          APN名称  =  NULL
PCO是否携带用户名  =  PCO未携带用户名
  PCO是否携带密码  =  PCO未携带密码
         接入模式  =  透明鉴权
         鉴权模式  =  使用PCO
        PCO优先级  =  不使能
  使用PCO中的密码  =  不使能
       用户名来源  =  取自配置
         密码来源  =  取自配置Password值
(结果个数 = 1);
```

## 输出结果说明

| 输出项名称      | 输出项解释                                                             |
|:-----------|:------------------------------------------------------------------|
| 生效范围       | 该参数用于指定单APN生效或全局生效。                                               |
| APN名称      | 该参数用于指定APN实例名。                                                    |
| PCO是否携带用户名 | 该参数表示PCO是否携带用户名。                                                  |
| PCO是否携带密码  | 该参数表示PCO是否携带密码。                                                   |
| 接入模式       | 该参数表示接入模式。                                                        |
| 鉴权模式       | 该参数表示鉴权模式。                                                        |
| PCO优先级     | 该参数用于指定当鉴权方式选择为APN或者MSISDN的时候，如果PCO携带了用户名、密码，是否优先采用PCO中的携带的用户名密码。 |
| 使用PCO中的密码  | 该参数用于指定当鉴权方式选择为APN或者MSISDN的时候，密码是否优先采用PCO中携带的密码。                  |
| 用户名来源      | 该参数用于指定用户名来源。                                                     |
| 密码来源       | 该参数用于指定密码来源。                                                      |
