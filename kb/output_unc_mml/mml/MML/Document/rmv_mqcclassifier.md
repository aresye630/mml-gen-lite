# 删除流分类（RMV MQCCLASSIFIER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除一个已经定义的流分类。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                                              |
|:---------------|:-------|:------------------------------------------------------------------------------------------------------------------|
| CLASSIFIERNAME | 分类名称   | 可选必选说明：必选参数 参数含义：指定流分类的名称。类名不允许为系统预定义类的名称default-class。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：区分大小写，不支持空格。 |

#### 使用实例

删除流分类c1：

```
RMV MQCCLASSIFIER:CLASSIFIERNAME="c1";
```
