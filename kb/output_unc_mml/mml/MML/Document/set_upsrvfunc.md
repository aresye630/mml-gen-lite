# 设置UP服务管理功能（SET UPSRVFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C、SMF**

该命令用于配置UP服务管理功能。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| CAPADJUSTPLCY   |   VALSRVRESRPROP |   VALSRVPROP |   UPFRPTVALIDTIME | VALSRVFUNC                |
|:----------------|-----------------:|-------------:|------------------:|:--------------------------|
| NOADJUST        |               10 |           10 |                60 | QOSANA-1&QOSEXP-1&RELAY-1 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称          | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                               |
|:----------------|:--------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CAPADJUSTPLCY   | 权重调整策略        | 可选必选说明：可选参数  参数含义：该参数用于控制UPF选择过程中，UPF权重调整策略。  数据来源：本端规划 取值范围： “NOADJUST（不调整）”：不调整UPF的权重。“BYSTATIC（静态调整）”：根据ADD PNFPROFILE、ADD PNFTAI、ADD PNFTAIRANGE、ADD PNFDNN命令中的“容量”，本命令中的“增值业务预留权重比例”、“增值UPF预估增值业务占比”调整UPF的权重。“BYUPFRPTUSAGE（动态调整）”：对于为普通业务用户选择普通UPF不调整UPF的权重；对于为增值业务用户选择增值UPF不调整UPF的权重；对于为普通业务用户选择增值UPF，根据UPF上报的普通会话量、增值会话量动态调整增值UPF的权重。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST UPSRVFUNC查询当前参数配置值。  配置原则：无 |
| VALSRVRESRPROP  | 增值业务预留权重比例    | 可选必选说明：可选参数  参数含义：该参数用于控制普通业务UPF选择时，增值UPF为增值业务预留的权重比例。  数据来源：本端规划  取值范围：整数类型，取值范围是0~100，单位是百分比。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST UPSRVFUNC查询当前参数配置值。  配置原则：无                                                                                                                                                                                                                                               |
| VALSRVPROP      | 增值UPF预估增值业务占比 | 可选必选说明：可选参数  参数含义：该参数用于控制普通业务UPF选择时，增值UPF未上报有效信息时预估的增值业务占比。  数据来源：本端规划  取值范围：整数类型，取值范围是0~100，单位是百分比。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST UPSRVFUNC查询当前参数配置值。  配置原则：无                                                                                                                                                                                                                                          |
| UPFRPTVALIDTIME | UPF上报动态负载的有效期 | 可选必选说明：可选参数  参数含义：该参数用于控制UPF上报动态负载的有效期。  数据来源：本端规划  取值范围：整数类型，取值范围是20~900，单位是秒。有效期要大于UPF上通过SET PFCPSRVRPT配置的“业务信息定时上报周期”。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST UPSRVFUNC查询当前参数配置值。  配置原则：无                                                                                                                                                                                                                     |
| VALSRVFUNC      | 增值业务功能        | 可选必选说明：可选参数  参数含义：该参数用于指定UPF统计为增值业务的功能类型。  数据来源：本端规划 取值范围： QOSANA（重点业务保障）QOSEXP（用户体验）RELAY（媒体中继业务）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST UPSRVFUNC查询当前参数配置值。  配置原则：无                                                                                                                                                                                                                                            |

## 使用实例

- 设置UPF权重调整策略为根据配置调整：

  ```
  SET UPSRVFUNC:CAPADJUSTPLCY=BYSTATIC;
  ```
- 设置增值UPF预估增值业务占比为20%：

  ```
  SET UPSRVFUNC:VALSRVPROP=20;
  ```
