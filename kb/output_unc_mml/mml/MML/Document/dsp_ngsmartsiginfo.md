# 显示5G用户信令抑制信息（DSP NGSMARTSIGINFO）

- 输出结果说明

## 命令功能

**须知** 

如果选择“报告输出”，且当前接入到AMF的信令抑制用户数量较多时，执行该命令会占用维护终端较长时间，进而导致用户无法继续使用该维护终端，若连续多次执行该命令可能导致OMU虚机CPU使用率突增。

**适用NF：AMF**

该命令用于查询5G用户信令抑制信息。

## 注意事项

- 如果选择“报告输出”，且当前接入到AMF的信令抑制用户数量较多时，无法保证能查出所有被抑制的用户信息。
- 此功能用于快速定位问题和解决故障，在使用过程中不可避免的使用到用户的某些个人数据，如IMSI。建议您遵从国家的相关法律执行该任务，并采取足够的措施以确保用户的个人数据受到充分的保护。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                     |
|:-----------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------|
| OUTPUTTYPE | 输出类型   | 可选必选说明：必选参数  参数含义：该参数用于指定输出类型。当输出类型为Screen且IMSI为空时，不显示未被抑制用户的信息。  数据来源：本端规划 取值范围： “Summary（统计信息）”：统计信息“Screen（报告输出）”：报告输出  默认值：无  配置原则：无 |
| IMSI       | IMSI   | 可选必选说明：该参数在"OUTPUTTYPE"配置为"Screen"时为条件可选参数。  参数含义：该参数用于指定移动用户标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是14~15。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无     |

## 使用实例

查询5G用户信令抑制信息，输出类型为报告输出，执行如下命令：

```
%%DSP NGSMARTSIGINFO:OUTPUTTYPE=Summary;%%
RETCODE = 0  操作成功

结果如下
------------------------
  系统中总的5G信令异常用户数  =  1
      初始注册信令异常用户数  =  0
      服务请求信令异常用户数  =  0
   PDU会话建立信令异常用户数  =  1 
4G到5G初始注册信令异常用户数  =  0
    4G到5G重选信令异常用户数  =  0
    4G到5G切换信令异常用户数  =  0
(结果个数 = 1)

---    END
```
