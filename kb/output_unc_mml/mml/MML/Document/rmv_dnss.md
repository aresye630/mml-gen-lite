# 删除DNS服务器(RMV DNSS)

- 命令功能

- 本地用户权限

- 使用实例

#### 命令功能

**适用网元：SGSN、MME****、AMF**

该命令用于删除一个DNS服务器。

网元通过向DNS服务器发送域名解析请求，获得域名所对应IP地址。

#### 注意事项

- 该命令执行后立即生效。
- 删除命令执行以后，网元将不会再向此DNS服务器发送域名解析请求，可能造成某些域名无法解析，请慎用此命令。
- 当该IP为其所属服务器组的唯一IP时，删除该IP会导致其所属的服务器组的删除。如果该服务器组的ID被DNSQ表引用（使用**LST DNSQ**查看），则需要首先使用**RMV DNSQ**删除引用该ID的DNSQ记录。但是当该服务器组ID为0时，即使不删除DNSQ记录，也可以删除该服务器组，删除该服务器组后，将导致发向该组的DNS查询失败。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                              |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------|
| GRPID  | 服务器组ID | 可选必选说明：必选参数 参数含义：该参数用来指定DNS服务器所属的服务器组。 数据来源：整网规划 取值范围：0~37 默认值：无                                                                  |
| IPT    | IP地址类型 | 可选必选说明：可选参数 参数含义：IP地址类型。 数据来源：整网规划 取值范围：IPV4(IPV4)IPV6(IPV6) 默认值：无                                                                |
| IP     | IP地址   | 可选必选说明：条件必选参数 参数含义：该参数用来指定DNS服务器IP地址。 该参数在"IP地址类型"参数配置为"IPV4(IPV4)"后生效。 数据来源：整网规划 取值范围：0.0.0.0~255.255.255.255 默认值：无              |
| IPV6   | IPv6地址 | 可选必选说明：条件必选参数 参数含义：DNS服务器IPv6地址 该参数在"IP地址类型"参数配置为"IPV6(IPV6)"后生效。 数据来源：整网规划 取值范围：::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 |

#### 使用实例

删除第一组一个IP地址为192.168.100.101的DNS服务器：

RMV DNSS: GRPID=1, IPT=IPV4, IP="192.168.100.101";
