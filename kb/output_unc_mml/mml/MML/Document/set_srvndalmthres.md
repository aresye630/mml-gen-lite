# 设置业务节点资源不足告警阈值（SET SRVNDALMTHRES）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：GGSN、SGW-C、PGW-C、SMF**

该命令用于配置业务节点告警阈值和恢复告警阈值。当业务节点资源使用率超过配置的告警门限时产生告警。当使用率低于配置的恢复门限时恢复告警。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   |   ALARMTHRES |   RESALARMTHRES |
|:-------|-------------:|----------------:|
| 初始值    |           95 |              90 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称          | 参数说明                                                                                                  |
|:--------------|:--------------|:------------------------------------------------------------------------------------------------------|
| ALARMTHRES    | 业务节点告警阈值（%）   | 可选必选说明：可选参数 参数含义：该参数用于设置业务节点告警阈值。 数据来源：本端规划 取值范围：整数类型，取值范围为1～100，单位是百分比。 默认值：无 配置原则：告警阈值必须大于恢复告警阈值。   |
| RESALARMTHRES | 业务节点恢复告警阈值（%） | 可选必选说明：可选参数 参数含义：该参数用于设置业务节点恢复告警阈值。 数据来源：本端规划 取值范围：整数类型，取值范围为1～100，单位是百分比。 默认值：无 配置原则：恢复告警阈值必须小于告警阈值。 |

#### 使用实例

假如运营商想在业务节点资源使用率超过85%时产生告警，当使用率低于75%时恢复告警，命令如下：

```
SET SRVNDALMTHRES: ALARMTHRES=85,RESALARMTHRES=75;
```
