# 发送模拟S1AP错误消息(SND S1MESSAGE)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于向MME或eNodeB发送一条错误消息。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                     |
|:------------|:---------|:-------------------------------------------------------------------------------------------------------------------------|
| RUNAME      | RU名称     | 可选必选说明：必选参数 参数含义：该参数用于指定SPU资源单元名。该参数可以通过DSP RU命令查询。 取值范围：0~63 位字符串 默认值：无                                                 |
| PROCESSNO   | 进程号      | 可选必选说明：必选参数 参数含义：该参数用于指定SGP进程所在的进程号。通过DSP PROCESSLINK获取。 取值范围：0～20 默认值：无                                                 |
| MESSAGETYPE | 消息类型     | 可选必选说明：必选参数 参数含义：该参数用于指定所模拟消息的类型。 取值范围：“MME(模拟MME消息)”“ENODEB(模拟eNodeB消息)” 默认值：无                                          |
| MCC         | 移动国家码    | 可选必选说明：必选参数 该参数用于指定S1AP链路的eNodeB的移动国家码。 取值范围：3位十进制数 默认值：无                                                                |
| MNC         | 移动网号     | 可选必选说明：必选参数 参数含义：该参数用于指定S1AP链路的eNodeB的移动网号。 取值范围：2～3位的十进制数 默认值：无  说明： 如果MCC相同，有效长度为2和3的MNC的前两位不允许相同。                     |
| ENODEBTYPE  | eNodeB类型 | 可选必选说明：必选参数 参数含义：该参数用于指定S1AP链路的eNodeB的类型。 取值范围：“HOME_ENB(HOME_ENB)”“MACRO_ENB(MACRO_ENB)” 默认值：无                          |
| ENODEBID    | eNodeB标识 | 可选必选说明：必选参数 参数含义：该参数用于指定S1AP链路的eNodeB的标识。 取值范围：0～268435455 默认值：无                                                         |
| MESSAGELEN  | 消息长度     | 可选必选说明：可选参数 参数含义：该参数用于指定S1AP的消息长度。 长度范围：0～4294967294 默认值：100  说明： 当“消息类型”配置为“ENODEB(模拟eNodeB消息)”时，该参数不能为0，且支持的最大值为20480。 |

#### 使用实例

向编号为12的NODEB，发送消息长度为200的错误消息：

SND S1MESSAGE: RUNAME="LINK\_SP\_RU\_0064", PROCESSNO=0, MESSAGETYPE=ENODEB, MCC="123", MNC="230", ENODEBTYPE=HOME\_ENB, ENODEBID=12, MESSAGELEN=200;
