# 修改GUL互操作本地策略 (MOD GULIWKPLCY)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

此命令用于修改GUL互操作本地策略。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                                                                 |
|:-------------|:-------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE     | 用户范围         | 可选必选说明：必选参数 参数含义：该参数用于指定需要限制Non-GBR承载的QoS的用户范围。 数据来源：整网规划 取值范围： “IMSI_PREFIX(指定IMSI前缀)”：指网络中与指定的IMSI前缀匹配的用户。“HOME_USER(本网用户)”：指网络中的本网签约用户。“FOREIGN_USER(外网用户)” ：指网络中的漫游用户。“ALL_USER(所有用户)”：指网络中的所有用户。 默认值：无 配置原则： “SUBRANGE（用户范围）”的优先级从高到低为：“IMSI_PREFIX”，“FOREIGN_USER”或“HOME_USER”，“ALL_USER”。系统优先查找高优先级的配置记录，如果查找不到，再查找低优先级的配置记录。 |
| NOID         | 运营商标识        | 可选必选说明：条件必选参数 参数含义：该参数用于指定运营商标识。 数据来源：整网规划 前提条件：该参数在“SUBRANGE”配置为“FOREIGN_USER”或“HOME_USER”后生效。 取值范围：整数类型，取值范围为0~64，128~254。 默认值：无 配置原则： 若该参数需要配置为0或128～254之间的值时，须先在ADD MNO中配置取值相同的“MNOID”参数。若该参数需要配置为1～64之间的值时，须先在ADD MVNO中配置取值相同的“MVNOID”参数。                                                                                       |
| IMSIPRE      | IMSI前缀       | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI前缀以区分不同的用户群。 数据来源：整网规划 前提条件：该参数在“用户范围”参数配置为“IMSI_PREFIX”后生效。 取值范围：5～15位十进制数字字符串。 默认值：无 配置原则： 当该参数配置生效时，按照IMSI最长匹配进行查询，如果有匹配的记录，使用该记录的配置；如果没有匹配的记录，则查找IMSI次长匹配的记录。                                                                                                                                      |
| GULCTRLCOND  | GUL互操作定制处理条件 | 可选必选说明：可选参数 参数含义：该参数用于指定GU到LTE互操作定制策略生效时，用户需要满足的条件。 数据来源：整网规划 取值范围： 位域类型，取值范围如下： N1CAP（N1能力）CNR（签约CNR）ARD（签约ARD） 默认值：“N1CAP-1&CNR-1&ARD-1” 配置原则：本参数至少要选择一个选项，否则配置将失效。                                                                                                                                                                |
| GULTAUPLCY   | GUL TAU处理策略  | 可选必选说明：可选参数 参数含义：该参数用于指定GU到LTE TAU流程中，MME是否拒绝用户。 数据来源：整网规划 取值范围： YES（是）：指定GU到LTE的TAU流程中，MME拒绝用户。NO（否）：指定GU到LTE的TAU流程中，MME不拒绝用户。 默认值：NO 配置原则： 在GU到LTE的TAU流程中，如果用户满足“GULCTRLCOND（GUL互操作定制处理条件）”时，希望给用户下发TAU Reject（TAU拒绝流程），触发用户在4G重新上线则配置为YES，否则配置为NO。                                                                                |
| GULHOPLCY    | GUL HO处理策略   | 可选必选说明：可选参数 参数含义：该参数用于指定GU到LTE HO流程中，MME是否拒绝用户。 数据来源：整网规划 取值范围： YES（是）：指定GU到LTE的HO流程中，MME拒绝用户。NO（否）：指定GU到LTE的HO流程中，MME不拒绝用户。 默认值：NO 配置原则： 在GU到LTE的HO流程中，如果用户满足“GULCTRLCOND”时，希望按“GULHOREJPLCY（GUL HO拒绝策略）”处理的话，配置为YES，否则配置为NO。                                                                                                       |
| GULHOREJPLCY | GUL HO拒绝策略   | 可选必选说明：条件必选参数 参数含义：该参数用于指定GU到LTE HO流程中，MME拒绝用户的策略。 前提条件：该参数在“GULHOPLCY（GUL HO处理策略）”参数配置为“YES”后生效。 数据来源：整网规划 取值范围： HO_TAU（HO伴随TAU拒绝） 默认值：“HO_TAU-1” 配置原则说明： 如果希望在HO后伴随的TAU流程中拒绝，然后通过TAU Reject触发用户在4G重新上线，则配置“HO_TAU”（HO伴随TAU拒绝）。                                                                                                     |
| TAUREJCAUSE  | TAU拒绝原因值     | 可选必选说明：条件必选参数 参数含义：该参数用于指定GU到LTE HO后的伴随TAU和GU到LTE的TAU，MME拒绝用户的原因值。 前提条件：该参数在“GULHOPLCY（GUL HO处理策略）”或“GULTAUPLCY（GUL TAU处理策略）”参数配置为“YES”后生效。 数据来源：整网规划 取值范围：0~111 默认值：“10”（此值表示隐式分离） 配置原则：无                                                                                                                                           |

#### 使用实例

修改GUL互操作本地策略的用户范围为所有用户，GUL TAU处理策略为是，可以用如下命令：

```
MOD GULIWKPLCY: SUBRANGE=ALL_USER, GULTAUPLCY=YES, TAUREJCAUSE=10;
```
