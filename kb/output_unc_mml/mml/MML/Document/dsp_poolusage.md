# 显示地址池使用信息（DSP POOLUSAGE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于显示本地地址池使用信息。

## 注意事项

当前版本暂时不支持基于APN名称、UPF实例标识查询本地地址池使用信息。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                                           |
|:----------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| QUERYTYPE | 查询类型    | 可选必选说明：可选参数  参数含义：该参数用于指定查询类型。  数据来源：本端规划 取值范围： POOL（地址池）APN（APN名称）UPFID（UPF实例名称）  默认值：POOL  配置原则：无                                            |
| POOLNAME  | 地址池名称   | 可选必选说明：该参数在"QUERYTYPE"配置为"POOL"时为条件必选参数。  参数含义：该参数用于指定已配的本地地址池的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~79。  默认值：无  配置原则：  该参数使用ADD ADDRPOOL命令配置生成。 |
| APN       | APN名称   | 可选必选说明：该参数在"QUERYTYPE"配置为"APN"时为条件必选参数。  参数含义：该参数用于指定APN/DNN名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。  默认值：无  配置原则：  该参数使用ADD APN命令配置生成。         |
| UPFID     | UPF实例标识 | 可选必选说明：该参数在"QUERYTYPE"配置为"UPFID"时为条件必选参数。  参数含义：该参数用于指定UPF实例名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：  该参数使用ADD UPNODE命令配置生成。     |

## 使用实例

显示地址池名称为testpool的地址池使用率信息：
DSP POOLUSAGE:POOLNAME="testpool";

```
%%DSP POOLUSAGE:POOLNAME="testpool";%%
RETCODE = 0  操作成功

结果如下
-------------------------
    地址池名称  =  testpool
  等待释放IP数  =  0
      地址段数  =  1
      地址总数  =  31
    地址使用数  =  0
    无效地址数  =  0
    锁定地址数  =  0
地址使用率 (%)  =  0
(结果个数 = 1)
---    END
```

## 输出结果说明

| 输出项名称    | 输出项解释                                                              |
|:---------|:-------------------------------------------------------------------|
| 地址池名称    | 该参数用于指定已配的本地地址池的名称。                                                |
| 等待释放IP数  | 该参数用于指定本地地址池等待释放IPv4地址/IPv6前缀个数，如果IP地址租约功能使能，则也是租约IPv4地址/IPv6前缀个数。 |
| 地址段数     | 该参数用于指定本地地址池中地址段数。                                                 |
| 地址总数     | 该参数用于指定本地地址池中IPv4地址/IPv6前缀的总数。                                     |
| 地址使用数    | 该参数用于指定本地地址池中IPv4地址/IPv6前缀的使用数。                                    |
| 无效地址数    | 该参数用于指定本地地址池中无效的IPv4地址/IPv6前缀数。                                    |
| 锁定地址数    | 该参数用于指定本地地址池中锁定的IP地址数量。                                            |
| 地址使用率(%) | 该参数用于指定本地地址池的IPv4地址/IPv6前缀的占用率。                                    |
