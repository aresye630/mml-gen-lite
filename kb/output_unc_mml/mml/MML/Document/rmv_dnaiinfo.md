# 删除DNAI信息（RMV DNAIINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、PGW-C**

该命令用于删除DNAI信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                               |
|:-------|:---------|:---------------------------------------------------------------------------------------------------|
| DNAI   | 数据网络访问标识 | 可选必选说明：必选参数  参数含义：该参数用于指定数据网络访问标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。不支持空格，不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

删除cmnet\_dnai的DNAI信息

```
RMV DNAIINFO: DNAI="cmnet_dnai";
```
