# 删除5G小区广播预警信息（DEL NGCBSWARN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

删除预警可能导致CBCF下发的预警无法送达用户。

**适用NF：AMF**

该命令用于删除CBCF发起的预警信息。小区广播场景下使用本命令达到删除预警的效果。

若需要删除的记录不存在，仍会显示删除成功，可通过DSP NGCBSWARN查询是否删除成功。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                          |
|:----------|:---------|:------------------------------------------------------------------------------------------------------------------------------|
| CBCID     | CBCF实例标识 | 可选必选说明：可选参数  参数含义：该参数用于指定发起预警的CBCF实例标识。不填写该参数，则默认为删除不携带CBCF实例标识的预警。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~40。不区分大小写。  默认值：无  配置原则：无 |
| WARNTYPE  | 预警类型     | 可选必选说明：必选参数  参数含义：该参数用于指定预警类型。  数据来源：对端协商 取值范围： Write-ReplaceWarning（下发预警）PWSCancel（取消预警）  默认值：无  配置原则：无                      |
| MSGID     | 预警消息标识   | 可选必选说明：必选参数  参数含义：该参数用于指定预警消息标识。  数据来源：对端协商  取值范围：整数类型，取值范围是0~65535。  默认值：无  配置原则：无                                           |
| SERIALNUM | 预警序列号    | 可选必选说明：必选参数  参数含义：该参数用于指定预警序列号。  数据来源：对端协商  取值范围：整数类型，取值范围是0~65535。  默认值：无  配置原则：无                                            |

## 使用实例

删除实例标识为“CBCF\_Instance\_0”的CBCF发起的预警信息，执行如下命令：

```
DEL NGCBSWARN: CBCID="CBCF_Instance_0", WARNTYPE=Write-ReplaceWarning, MSGID=1, SERIALNUM=0;
```
