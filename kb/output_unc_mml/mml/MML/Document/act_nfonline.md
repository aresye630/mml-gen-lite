# 激活NF上线（ACT NFONLINE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、NRF、NSSF、NCG、SMSF、CBC、CBCF**

该命令用来激活NF向NRF注册。在完成NF相关基础数据配置后，可以通过本命令手动触发NF到NRF的注册。也可以在NF注册、或者配置数据更新异常的情况下，通过本命令重新手动触发NF到NRF的重新上线注册。

## 注意事项

- 该命令执行后立即生效。

- 执行该命令无法切换注册的NRF，请使用DWORD2 BIT8切换到主用NRF注册。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称         | 参数说明                                                                                                                                                              |
|:---------------|:-------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCENAME | NF实例名称       | 可选必选说明：必选参数  参数含义：该参数用于指定NF实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~50。  默认值：无  配置原则：  本参数需要与ADD NFPROFILE命令中的NFINSTANCENAME值保持一致。NFINSTANCENAME值可通过LST NFPROFILE获得。 |
| REGHIGHPRINRF  | 是否注册到高优先级NRF | 可选必选说明：可选参数  参数含义：该参数用于控制是否向高优先级的NRF注册。NRF的优先级可以通过LST NRF中的PRIORITY参数查看。  数据来源：本端规划  取值范围： TRUE(TRUE)FALSE(FALSE)  默认值：无  配置原则：无                                  |

## 使用实例

激活AMF\_Instance\_0向NRF的注册。

```
ACT NFONLINE: NFINSTANCENAME="AMF_Instance_0";
```
