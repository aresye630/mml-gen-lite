#### 命令功能

**适用网元：MME**

此命令用于查询SGs链路集。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                            |
|:-------|:-------|:------------------------------------------------|
| LSX    | 链路集索引  | 可选必选说明：可选参数 参数含义：待查询链路集的索引。 取值范围：0~255 默认值：无    |
| LSN    | 链路集名   | 可选必选说明：可选参数 参数含义：待查询链路集的名称。 取值范围：1~50位字符串 默认值：无 |

#### 使用实例

查询所有链路集：

LST SGSLKS:;

```
%%LST SGSLKS:;%%
RETCODE = 0  操作成功。

操作结果如下
--------------
 链路集索引  VLR号   链路集名

 0           11808   VLR8    
 1           11809   VLR9    
(结果个数 = 2)

---    END
```
