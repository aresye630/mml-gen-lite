# 删除HTTP接口类型固定速率流控信息（RMV HTTPFIXEDFCINF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除HTTP接口类型固定速率流控门限值信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OFCIDX | 局向索引   | 可选必选说明：可选参数  参数含义：该参数用于指定局向索引。该参数来源于ADD HTTPOFC命令的“局向索引”参数，可通过LST HTTPOFC命令查询获取。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4095。  默认值：无  配置原则：  此处只能绑定"NFITEM"包含"FIXSPDFCINTF（基于接口类型固定速率流控）"的局向。 |
| LETYPE | 本端实体类型 | 可选必选说明：可选参数  参数含义：该参数用于指定HTTP本端实体的类型。  数据来源：全网规划 取值范围： “SERVER（服务端）”：服务端“CLIENT（客户端）”：客户端  默认值：无  配置原则：  HTTP本端实体可以作为服务端也可以作为客户端，两者需要分别配置。                                          |

## 使用实例

删除局向索引为1，本端实体类型为客户端的HTTP接口类型固定速率流控门限值信息：

```
RMV HTTPFIXEDFCINF: OFCIDX=1, LETYPE=CLIENT;
```
