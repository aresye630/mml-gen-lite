## 命令功能

**须知** 

如果选择“报告输出”，且当前接入到MME的信令抑制用户数量较多时，执行该命令会占用维护终端较长时间，进而导致用户无法继续使用该维护终端，若连续多次执行该命令可能导致OMU虚机CPU使用率突增。

**适用网元：MME**

该命令用于查询S1模式下的用户信令抑制信息。

## 注意事项

- 该命令执行后立即生效。
- 该命令查询的请求次数显示为历史周期的最大请求次数。
- 指定查询方式为“SCREEN”且不填写“IMSI”时，可能导致SPP进程CPU短暂上升。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| QUERYOPT | 查询方式   | 可选必选说明：必选参数 参数含义：该参数用于指定输出类型。 数据来源：本端规划 取值范围： “SUMMARY（统计信息）”“SCREEN（报告输出）” 默认值：SUMMARY（统计信息） 配置原则：无                                                                |
| IMSI     | IMSI   | 可选必选说明：该参数在"QUERYOPT"配置为"SCREEN"时为条件可选参数。 参数含义：该参数用于指定国际移动用户标识。 数据来源：全网规划 取值范围：字符串类型，输入长度范围是14~15。只允许输入十进制数字（0-9）。 默认值：无 配置原则：如果不配置则显示系统中全量的被抑制用户信息，最多显示15000个用户信息。 |

## 使用实例

1. 显示S1模式用户信令抑制信息，输出统计信息。

   DSP S1SMARTSIGINFO: QUERYOPT=SUMMARY;

   ```
   %%DSP S1SMARTSIGINFO: QUERYOPT=SUMMARY;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------------------
             附着异常用户数  =  0
         服务请求异常用户数  =  0
   控制面服务请求异常用户数  =  0
      PDN连接建立异常用户数  =  1
   (结果个数 = 1)

   ---    END
   ```
2. 显示S1模式用户信令抑制信息，按照报告输出。

   DSP S1SMARTSIGINFO: QUERYOPT=SCREEN;

   ```
   %%DSP S1SMARTSIGINFO: QUERYOPT=SCREEN;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------------------
                     IMSI  =  123456789012345
             附着抑制状态  =  未被抑制
             附着消息计数  =  1
         服务请求抑制状态  =  未被抑制
           服务请求消息数  =  0
   控制面服务请求抑制状态  =  未被抑制
     控制面服务请求消息数  =  0
      PDN连接建立抑制信息  =  [EXAMPLE1.COM:0:1][EXAMPLE2.COM:1:4]
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

| 输出项名称       | 输出项解释                                                                                                                                                |
|:------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | 该参数标识被信令抑制的用户IMSI。                                                                                                                                   |
| 附着抑制状态      | 该参数表示该用户是否存在初始注册信令异常。                                                                                                                                |
| 附着消息计数      | 该参数表示在历史检测周期内，该用户发送的最大附着消息数。                                                                                                                         |
| 服务请求抑制状态    | 该参数表示是否存在服务请求信令异常。                                                                                                                                   |
| 服务请求消息数     | 该参数表示在历史检测周期内，该用户发送的最大服务请求消息数。                                                                                                                       |
| 控制面服务请求抑制状态 | 该参数表示是否存在控制面服务请求信令异常。                                                                                                                                |
| 控制面服务请求消息数  | 该参数表示在历史检测周期内，该用户发送的最大控制面服务请求消息数。                                                                                                                    |
| PDN连接建立抑制信息 | 该参数表示在历史检测周期内基于APN粒度PDN连接建立抑制信息[APN名称：PDN会话被抑制状态：历史周期该APN对应的最大PDN会话建立请求消息数]。如[APN1:1:20]，表示被抑制的APN为APN1，当前的抑制状态为1表示被抑制，该APN粒度历史周期触发的PDN会话建立请求消息数为20。 |
