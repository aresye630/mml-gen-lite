# 删除Gb模式IMEI配置（RMV GBIMEICFG）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用于删除GERAN指定号段用户的获取和检查IMEI的策略。

#### 注意事项

- 该命令执行后立即生效。
- 只能删除指定号段用户的IMEI配置，而不能删除默认的IMEI配置。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                               |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：必选参数 参数含义：该参数用于指定签约用户的范围。 取值范围：“ALL_USER（所有用户）”“IMSI_PREFIX（指定IMSI前缀）”“IMSI_RANGE（指定IMSI范围）” 默认值：无          |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI前缀。 前提条件：只有“用户范围”为“IMSI_PREFIX（指定IMSI前缀）”时，该参数才有效。 取值范围：1～15位十进制数字 默认值：无             |
| IMSI     | IMSI   | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI，对该IMSI所在号段进行删除。 前提条件：只有“用户范围”为“IMSI_RANGE（指定IMSI范围）”时，该参数才有效。 取值范围：1～15位十进制数字 默认值：无 |

#### 使用实例

删除IMSI前缀为“123456”的GERAN用户的IMEI配置：

RMV GBIMEICFG:SUBRANGE=IMSI\_PREFIX, IMSIPRE="123456";
