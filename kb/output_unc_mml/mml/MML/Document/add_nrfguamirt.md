# 增加GUAMI路由（ADD NRFGUAMIRT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

跨NRF的NF查询，当基于不同属性选择NF时，需要在NRF（多层NRF组网中的H-NRF或PLMN-NRF，单层NRF组网中存在东西向NRF的NRF）上配置下一跳路由，以便NRF能够寻址到其下一级NRF上所管理的NF。

该命令用于新增基于GUAMI的路由信息。当跨NRF对某个NF进行寻址时，通过本命令配置的信息可以找到当前NRF的下一级NRF路由，即目标NF所归属的NRF。

## 注意事项

- 该命令执行后立即生效。

- 主备或双活组网的场景下，如果需要配置此命令，则两个NRF上均需执行此命令，且配置参数一致。
- 当发现参数中AMFREGIONID和AMFSETID满足条件时，NRF不再查询Guami路由进行转发。

- 最多可输入4096条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                                                                      |
|:---------------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MCC            | 移动国家码    | 可选必选说明：必选参数  参数含义：该参数用于表示组成GUAMI的PLMN中移动国家码信息。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。3位十进制数。  默认值：无  配置原则：无                                                                       |
| MNC            | 移动网号     | 可选必选说明：必选参数  参数含义：该参数用于表示组成GUAMI的PLMN中移动网号信息。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。2位或者3位十进制数。  默认值：无  配置原则：无                                                                |
| AMFREGIONID    | AMF区域标识  | 可选必选说明：必选参数  参数含义：该参数用于表示组成GUAMI的AMF所在区域标识信息。  数据来源：全网规划  取值范围：字符串类型，输入长度是2。按照十六进制输入，输入时不带0x，不足两位时从左边补0，取值范围0~ff。  默认值：无  配置原则：无                                          |
| AMFSETID       | AMF集合标识  | 可选必选说明：必选参数  参数含义：该参数用于表示组成GUAMI的AMF所在集合（即Pool）标识信息。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。按照十六进制输入，输入时不带0x，不足三位时从左边补0，取值范围0~3ff。  默认值：无  配置原则：无                                  |
| AMFPOINTER     | AMF指示符   | 可选必选说明：必选参数  参数含义：该参数用于表示组成GUAMI的AMF Pionter信息。  数据来源：全网规划  取值范围：字符串类型，输入长度是2。按照十六进制输入，输入时不带0x。不足两位时从左边补0。  默认值：无  配置原则：无                                                 |
| NEXTNRFGRPNAME | 归属NRF组名称 | 可选必选说明：必选参数  参数含义：该参数用于表示当前NRF基于GUAMI寻址AMF时的下一条NRF实例组名称，被寻址的AMF归属于该NRF实例组。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~64。  默认值：无  配置原则：  该参数已通过ADD NRFGROUP配置，可通过LST NRFGROUP命令查询获取。 |

## 使用实例

- 运营商网络为三层组网，最高层PLMN-NRF，中间层H-NRF，最底层L-NRF。L-NRF1归属于H-NRF1，H-NRF1归属于PLMN-NRF，当跨NRF进行服务发现时，希望发现的目标AMF移动国家码为123，移动网号为456，区域标识为09，集合标识为102，指示符为12，归属于L-NRF1，则需要在H-NRF1和PLMN-NRF上分别配置如下路由信息。在H-NRF1上执行：

  ```
  ADD NRFGUAMIRT: MCC="123", MNC="456", AMFREGIONID="09", AMFSETID="102", AMFPOINTER="12", NEXTNRFGRPNAME="L-NRF1 ";
  ```
- 在PLMN-NRF上执行：

  ```
  ADD NRFGUAMIRT: MCC="123", MNC="456", AMFREGIONID="09", AMFSETID="102", AMFPOINTER="12", NEXTNRFGRPNAME="H-NRF1 ";
  ```
