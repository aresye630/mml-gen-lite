#### 命令功能

**适用NF：NCG**

该命令用于立即生成话单。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                                                      |
|:-------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AGID   | 接入网元分组标识 | 可选必选说明：可选参数 参数含义：用于区分不同域的接入网元。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则： 该值需要执行LST CDRPROC命令查询“接入网元分组标识”。如果没有符合要求的“接入网元分组标识”，还需执行ADD CDRPROC命令增加。不能输入的特殊字符请参考“特殊字符表”。 |
| RUID   | RU的ID    | 可选必选说明：可选参数 参数含义：RU的ID。 数据来源：本端规划 取值范围：整数类型，取值范围为64～4294967294。 默认值：无 配置原则：该值需要执行LST SERVICERUSTATE命令，查询出存在的RU ID进行填写。                                                    |
| MNAME  | 模块名      | 可选必选说明：可选参数 参数含义：用于表示一个业务模块对象，全局唯一。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～15。 默认值：无 配置原则： 该值需要执行LST MODULE命令，查询出存在的MNAME进行填写。不能输入的特殊字符请参考“特殊字符表”。                                 |

#### 使用实例

- 显示所有话单生成情况，示例如下：

  ```
  SYN GENERATECDR:;
  RETCODE = 0  操作成功。

  结果如下:
  --------
  模块名    任务状态 

  AP66_1    成功     
  AP67_1    成功     
  (结果个数 = 2)
  ---    END
  ```
- 显示同一个接入网元分组标识的话单生成情况，示例如下：

  ```
  SYN GENERATECDR: AGID="PS_GROUP_1";
  RETCODE = 0  操作成功。

  结果如下
  --------
  模块名     =   AP66_1 
  任务状态   =   成功
  (结果个数 = 1)
  ---    END
  ```

#### 输出结果说明

| 输出项名称   | 输出项解释          |
|:--------|:---------------|
| 模块名     | 用于表示一个业务模块对象。  |
| 任务状态    | 表示立即生成话单的操作结果。 |
