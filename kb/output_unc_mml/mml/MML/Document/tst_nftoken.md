# 测试Token分配（TST NFTOKEN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于测试NRF上NF的Token分配流程。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                                                                             |
|:--------------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCEID  | 源NF实例标识  | 可选必选说明：必选参数  参数含义：该参数表示Token请求的源NF实例标识，即NF服务消费者的NF实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~40。该参数只能由字母（A-Z或者a-z）、数字（0-9）、中划线（-）组成。  默认值：无  配置原则：无   |
| TNFINSTANCEID | 目标NF实例标识 | 可选必选说明：必选参数  参数含义：该参数表示Token请求中的目标NF实例标识，即NF服务提供方的NF实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~40。该参数只能由字母（A-Z或者a-z）、数字（0-9）、中划线（-）组成。  默认值：无  配置原则：无 |
| SCOPE         | 目标服务名称列表 | 可选必选说明：必选参数  参数含义：该参数表示Token请求中的目标NF服务实例列表。如果有多个服务名称，用“%20”隔开。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~1024。  默认值：无  配置原则：无                              |
| REQMCC        | 源MCC     | 可选必选说明：可选参数  参数含义：该参数表示Token请求的服务消费者NF所在的MCC。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。  默认值：无  配置原则：无                                                      |
| REQMNC        | 源MNC     | 可选必选说明：可选参数  参数含义：该参数表示Token请求的服务消费者NF所在的MNC。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。  默认值：无  配置原则：无                                                  |
| TMCC          | 目标MCC    | 可选必选说明：可选参数  参数含义：该参数表示Token请求的服务提供方NF的所在MCC。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。  默认值：无  配置原则：无                                                      |
| TMNC          | 目标MNC    | 可选必选说明：可选参数  参数含义：该参数表示Token请求的服务提供方NF的所在MNC。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。  默认值：无  配置原则：无                                                  |

## 使用实例

测试NF Token申请，其源NF实例标识为123e4567-e89b-12d3-a456-426655440000，目标NF实例标识为ac4567-e89b-12d3-a456-42665544，目标服务名称列表nsmf-pdusession：

```
TST NFTOKEN:NFINSTANCEID="123e4567-e89b-12d3-a456-426655440000", TNFINSTANCEID="ac4567-e89b-12d3-a456-42665544", SCOPE="nsmf-pdusession";
%%TST NFTOKEN:NFINSTANCEID="123e4567-e89b-12d3-a456-426655440000", TNFINSTANCEID="ac4567-e89b-12d3-a456-42665544", SCOPE="nsmf-pdusession";%%
RETCODE = 0    操作成功
```
