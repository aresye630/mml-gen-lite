# 显示系统接口信息（DSP AMFSYSITFINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于显示系统接口信息。

当指定系统接口类型为SBI，显示整系统服务化接口状态信息。

当指定系统接口类型为N2，显示多条N2接口状态信息，每条记录表示链路管理业务进程的N2接口状态。

N26系统接口类型为预埋取值，功能暂未实现。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                  |
|:-----------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------|
| SYSITFTYPE | 系统接口类型 | 可选必选说明：必选参数  参数含义：该参数用于指定查询及显示的系统接口类型。  数据来源：本端规划 取值范围： “SBI（服务化接口）”：服务化接口“N2（N2接口）”：NG-RAN与AMF之间的NGAP接口“N26（N26接口）”：AMF与MME之间的GTP-C接口  默认值：无  配置原则：无 |

## 使用实例

查询SBI系统接口信息，执行如下命令：

```
%%DSP AMFSYSITFINFO: SYSITFTYPE=SBI;%%
RETCODE = 0  操作成功

结果如下
------------------------
系统接口类型  =  服务化接口
系统接口状态  =  打开
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                     |
|:--------|:----------------------------------------------------------------------------------------------------------|
| 系统接口类型  | 该参数用于指定查询及显示的系统接口类型。 取值说明： “SBI（服务化接口）”：服务化接口“N2（N2接口）”：NG-RAN与AMF之间的NGAP接口“N26（N26接口）”：AMF与MME之间的GTP-C接口 |
| 系统接口状态  | 该参数用于显示系统接口状态。 取值说明： “OFF（关闭）”：关闭“ON（打开）”：打开                                                              |
| POD ID  | 该参数用于标识系统中的POD ID。                                                                                        |
