# 设置一个微服务迁移过程（SET L3SERVICEDUALUPG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

灰度升级中，执行此命令，设置一个微服务迁移过程。

## 注意事项

- 该命令执行后立即生效。

- 需要先确保数据库中至少存在一个实例，可以用**ADD L3SERVICEDUALUPG**添加。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称       | 参数说明                                                                                        |
|:-----------|:-----------|:--------------------------------------------------------------------------------------------|
| L3SERVICE  | L3Service  | 可选必选说明：必选参数  参数含义：该参数用于标识一个微服务。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无。  配置原则：无        |
| OLDVERSION | OldVersion | 可选必选说明：必选参数  参数含义：该参数用于标识一个老版本。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~1024。  默认值：无。  配置原则：无       |
| NEWVERSION | NewVersion | 可选必选说明：必选参数  参数含义：该参数用于标识新版本。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~1024。  默认值：无。  配置原则：无         |
| OLDPODNUM  | OldPODNum  | 可选必选说明：必选参数  参数含义：该参数用于标识老pod数量。  数据来源：本端规划  取值范围：整数类型，取值范围是0~2147483647。  默认值：无。  配置原则：无   |
| NEWPODNUM  | NewPODNum  | 可选必选说明：必选参数  参数含义：该参数用于标识新版本pod数量。  数据来源：本端规划  取值范围：整数类型，取值范围是0~2147483647。  默认值：无。  配置原则：无 |

## 使用实例

设置已经存在的微服务AM的迁移流程相关参数：

```
%%SET L3SERVICEDUALUPG: L3SERVICE="AM", OLDVERSION="21.1", NEWVERSION="21.5", OLDPODNUM=5, NEWPODNUM=7;%%
RETCODE = 0  操作成功

---    END
```
