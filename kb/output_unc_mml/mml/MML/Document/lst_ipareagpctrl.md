# 查询基于位置分配IP地址策略(LST IPAREAGPCTRL)

- 注意事项
- 本地用户权限

- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询基于用户位置分配动态IP地址的策略。

#### 注意事项

- 此命令执行后立即生效

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

显示基于位置分配的IP地址策略：

LST IPAREAGPCTRL:;

```
%%LST IPAREAGPCTRL:;%%
RETCODE = 0  操作成功。

输出结果如下
--------------
                 用户下线开关  = 关闭
           用户下线速度(个/秒) = 200
是否区分本网本地和本网异地用户 = 不区分
           GU漫游用户限制方式  = 去激活
        GU本网异地用户限制方式 = 去激活
          GU用户接入限制原因值 = 15
         LTE用户接入限制原因值 = 15
(结果个数 = 1)
---    END
```
