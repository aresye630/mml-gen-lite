# 显示手工恢复GGSN地址状态(DSP USRCTLGGSN)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用网元：SGSN**

此命令用于查询需要手工恢复的GGSN地址。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                    |
|:-------|:-------|:------------------------------------------------------------------------|
| RUNAME | RU名称   | 可选必选说明：可选参数 参数含义：该参数用于指定SPU资源单元名。该参数可以通过DSP RU命令查询。 取值范围：1~63位字符串 默认值：无 |

#### 使用实例

1. 查询所有需要手工恢复的GGSN地址：DSP USRCTLGGSN:;

   ```
   %%DSP USRCTLGGSN:;%%
   RETCODE = 0  操作成功。

   操作结果如下
   --------------
    IP地址类型  本端IP地址     对端IP地址 

    IPv4        192.168.14.20  192.168.45.20
    IPv4        192.168.14.20  192.168.45.21
    IPv4        192.168.14.20  192.168.45.23
   (结果个数 = 3)

   ---    END
   ```

#### 输出结果说明

| 输出项名称   | 输出项解释                                     |
|:--------|:------------------------------------------|
| IP地址类型  | 此参数用于指定查询到的GGSN地址的IP类型。 取值说明：“IPv4”“IPv6” |
| 本端IP地址  | 此参数用于指定本端IP地址。                            |
| 对端IP地址  | 此参数用于指定GGSN的IP地址。                         |
