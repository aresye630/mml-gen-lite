# 查询CSDB灰度升级阶段(LST DBUPGSTAGE)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询当前的灰度升级阶段。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询到当前的**“灰度升级阶段”**为**“CSDB灰度升级结束”**：

```
%%LST DBUPGSTAGE:;%%
RETCODE = 0  操作成功

操作结果如下：
--------------
灰度升级阶段  =  CSDB灰度升级结束
(结果个数 = 1)

---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释        |
|:--------|:-------------|
| 灰度升级阶段  | 当前所处的灰度升级阶段。 |
