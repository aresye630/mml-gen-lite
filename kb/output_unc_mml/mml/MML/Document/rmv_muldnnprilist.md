# 删除本地专网DNN就近接入优先级（RMV MULDNNPRILIST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、PGW-C**

该命令用于删除指定智能分流专网DNN接入省/市的优先级。

## 注意事项

该命令执行后只对新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                                                                                                                                                                           |
|:-------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DEDDNN | 智能分流专网DNN | 可选必选说明：必选参数  参数含义：该参数用于指定智能分流专网DNN。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。  默认值：无  配置原则：  字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。 |

## 使用实例

删除本地专网DNN就近接入优先级，智能分流专网DNN为“special.dnn”。

```
RMV MULDNNPRILIST: DEDDNN="special.dnn";
```
