# 设置获取UPF服务区绑定TAI/LAI的方式（SET UPAREABINDFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、GGSN、SGW-C**

该命令用于设置获取UPF服务区绑定TAI/LAI的方式。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| EFFECTIVEMODE   |
|:----------------|
| PREFIX          |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                  |
|:--------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| EFFECTIVEMODE | 生效方式   | 可选必选说明：必选参数  参数含义：该参数用于标识获取UPF服务区绑定TAI/LAI的方式。  数据来源：全网规划 取值范围： “PREFIX（采用前缀的方式）”：如果配置为采用前缀的方式读取，仅会读取UPAREABINDS1TAI/UPAREABINDLAI配置“SUFFIX（采用后缀的方式）”：如果配置为采用后缀的方式读取，仅会读取SUFFIXS1TAIAREA/SUFFIXLAIAREA配置“BOTH（前缀方式和后缀方式同时生效）”：如果配置为采用前缀方式和后缀方式同时生效的方式读取，会读取UPAREABINDS1TAI/UPAREABINDLAI/SUFFIXS1TAIAREA/SUFFIXLAIAREA配置  默认值：无。  配置原则：  默认采用前缀的方式读取。 |

## 使用实例

以下命令用于设置获取UPF服务区绑定TAI/LAI的方式，将生效方式设置为采用前缀的方式：

```
SET UPAREABINDFUNC: EFFECTIVEMODE=PREFIX;
```
