# 查询UE无线能力策略（LST UECAPBYIMSI）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 使用实例
- 输出结果说明

#### 命令功能

**适用网元：MME**

该命令用于查询UE无线能力策略。

#### 注意事项

此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 使用实例

查询UE无线能力策略:

LST UECAPBYIMSI:;

```
%%LST UECAPBYIMSI:;%%
RETCODE = 0  操作成功

查询结果如下
------------------------
IMSI  =  460011418603055
(结果个数 = 1)

---    END
```
