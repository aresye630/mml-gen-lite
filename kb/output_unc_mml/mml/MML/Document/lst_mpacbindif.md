# 查询MPAC接口策略（LST MPACBINDIF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询接口MPAC策略。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                       |
|:----------|:-------|:---------------------------------------------------------------------------------------------------------------------------|
| IFNAME    | 接口名称   | 可选必选说明：必选参数 参数含义：该参数用于指定绑定策略生效的接口。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。接口名称由接口类型+接口编号组成。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。 |
| IPVERSION | IP版本   | 可选必选说明：必选参数 参数含义：该参数用于指定IP版本。 数据来源：本端规划 取值范围：枚举类型。 IPv4：IPv4协议族。IPv6：IPv6协议族。 默认值：无                                        |

#### 使用实例

查询MPAC接口策略：

```
LST MPACBINDIF:IFNAME="Ethernet64/0/3",IPVERSION=IPv4;
```

```
        RETCODE = 0  操作成功

        结果如下
        -------------------------
            接口名称  =  Ethernet64/0/3
              IP版本  =  IPv4
        IPv4策略名称  =  policyV4
        IPv6策略名称  =  NULL
        (结果个数 = 1)
        ---    END
```
