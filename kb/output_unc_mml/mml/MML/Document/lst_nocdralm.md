#### 命令功能

**适用NF：NCG**

该命令用于查询**ALM-82021 NCG长时间未接收到话单**告警的监控参数。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询**ALM-82021 NCG长时间未接收到话单**告警的监控参数：

```
LST NOCDRALM:;
```

```
RETCODE = 0  操作成功。

结果如下:
------------
          告警开关  =  开启
告警检测周期(分钟)  =  5
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见**SET NOCDRALM**的参数说明。
