# 显示微服务进程信息（DSP CELLINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此命令用于显示微服务进程信息，如进程运行状态。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                  |
|:----------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OBJECT    | 对象类型   | 可选必选说明：必选参数  参数含义：该参数用于表示查询可用状态的对象类型：包括进程类型，进程ID，POD名称。  数据来源：本端规划 取值范围： “PROCESSTYPE（进程类型）”：问题定位相同类型异常进程原因“PROCESSID（进程ID）”：问题定位单个进程异常原因“PODNAME（POD名称）”：问题定位未ready的Pod内异常进程原因  默认值：无  配置原则：无        |
| PODNAME   | POD名称  | 可选必选说明：该参数在"OBJECT"配置为"PODNAME"时为条件必选参数。  参数含义：该参数用于表示按Pod名称查询进程可用状态。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~100。  默认值：无  配置原则：  使用DSP CELLSTAT命令获取POD名称作为输入。                                                |
| PROCID    | 进程ID   | 可选必选说明：该参数在"OBJECT"配置为"PROCESSID"时为条件必选参数。  参数含义：参数用于表示微服务进程ID。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~100。  默认值：无  配置原则：  可通过DSP MSPROCESS命令查询进程ID。                                                         |
| PROCTYPE  | 进程类型   | 可选必选说明：该参数在"OBJECT"配置为"PROCESSTYPE"时为条件必选参数。  参数含义：该参数用于表示微服务进程所属的进程类型名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~100。  默认值：无  配置原则：  可通过DSP MSPROCTYPE命令查询进程类型名。                                             |
| PROCSTATE | 进程状态   | 可选必选说明：可选参数  参数含义：该参数用于表示微服务进程状态，根据进程状态筛选查询结果，进程状态有Ready、Not Ready、Fault三种，分别对应就绪状态、未就绪状态、故障状态。  数据来源：本端规划 取值范围： “NotReady（未就绪状态）”：进程是未就绪状态“Fault（故障状态）”：进程是故障状态	“Ready（就绪状态）”：进程是就绪状态  默认值：无  配置原则：无 |

## 使用实例

基于Pod名称查询进程信息

```
%%DSP CELLINFO: OBJECT=PODNAME, PODNAME="cmf-pod-2";%%
RETCODE = 0  操作成功

结果如下
--------
进程类型       进程ID             进程状态  节点名称      故障原因      故障描述

CELL_CMF      cmf-pod-2__167__0  就绪状态  10.0.0.1     0x00000000   
CELL_SCFA     cmf-pod-2__103__1  就绪状态  10.0.0.1     0x00000000   
CELL_SDRE     cmf-pod-2__103__0  就绪状态  10.0.0.1     0x00000000   
(结果个数 = 3)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                                                     |
|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
| 进程类型    | 该参数用于表示微服务进程所属的进程类型名称。                                                                                                                                    |
| 进程ID    | 参数用于表示微服务进程ID。                                                                                                                                            |
| 进程状态    | 该参数用于表示微服务进程状态，根据进程状态筛选查询结果，进程状态有Ready、Not Ready、Fault三种，分别对应就绪状态、未就绪状态、故障状态。 取值说明： “NotReady（未就绪状态）”：进程是未就绪状态“Fault（故障状态）”：进程是故障状态	“Ready（就绪状态）”：进程是就绪状态 |
| 节点名称    | 该参数用于表示微服务进程所在节点的名称。                                                                                                                                      |
| 故障原因    | 该参数用于表示进程故障原因，错误原因请联系华为工程师。                                                                                                                               |
| 故障描述    | 该参数用于描述故障发生的原因。                                                                                                                                           |
