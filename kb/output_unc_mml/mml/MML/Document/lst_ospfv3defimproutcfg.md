# 显示OSPFv3引入路由默认配置（LST OSPFV3DEFIMPROUTCFG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询OSPFv3引入路由默认配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                     |
|:-------|:----------|:-------------------------------------------------------------------------|
| PROCID | OSPFv3进程号 | 可选必选说明：可选参数 参数含义：OSPFv3进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 |

#### 使用实例

显示OSPFv3进程1下引入路由默认配置：

```
LST OSPFV3DEFIMPROUTCFG:;
```

```
RETCODE = 0  操作成功。

结果如下
------------------------
                      OSPFv3进程号  =  1
                          拓扑标识  =  0
                  等价路由最大数量  =  64
                        默认开销值  =  1
引入路由的开销值为路由自带的cost值  =  FALSE
                    外部路由的标记  =  1
                      外部路由类型  =  Type2
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称               | 输出项解释                                            |
|:--------------------|:-------------------------------------------------|
| OSPFv3进程号           | 该参数指定用户创建的OSPFv3进程号。                             |
| 拓扑标识                | 该参数指定用户创建的OSPFv3拓扑标识。                            |
| 等价路由最大数量            | 该参数指定本OSPFv3进程引入的等价路由最大数量。                       |
| 默认开销值               | 该参数指定本OSPFv3进程引入路由的默认开销值。                        |
| 引入路由的开销值为路由自带的cost值 | 如果指定该参数说明引入路由的开销值为路由自带的cost值，如果没有指定开销值，则使用默认开销值。 |
| 外部路由的标记             | 该参数指定本OSPFv3进程引入路由的标记。                           |
| 外部路由类型              | 该参数指定本OSPFv3进程引入路由的类型。                           |
