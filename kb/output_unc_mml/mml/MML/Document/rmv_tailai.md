#### 命令功能

**须知** 

- 删除TAI与LAI对应关系后，MME将无法找到该TAI所对应的LAI，CSFB功能将失效。
- 如果不输入任何参数，执行该命令会删除所有记录。

**适用网元：MME**

该命令用于删除TAI与LAI的对应关系。

#### 注意事项

- 该命令执行后立即生效。
- 删除TAI与LAI对应关系后，MME将无法找到该TAI所对应的LAI，CSFB功能将失效。
- 如果需要删除系统中唯一一条TAI与LAI的对应关系记录时，需要指定“起始TAI”、“用户范围”和“IMSI前缀”或“IMSI”参数。
- 如果仅指定起始TAI或者LAI参数，则系统默认删除选择模式为用户范围(**SUBRANGE**)对应的记录。
- 如果需要删除起始TAI或者LAI参数对应的所有记录，则需要分别执行选择模式为用户范围，主机名以及域名的删除命令。
- 当软参BYTE\_EX\_B149 BIT4设置为“1”时，该命令必须输入全部可选参数才能执行成功。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                           |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| BGNTAI   | 起始TAI  | 可选必选说明：可选参数 参数含义：该参数用于指定待删除的跟踪区标识。 取值范围：9～10位的字符串 默认值：无 配置原则：“起始TAI”和“LAI”至少要输入一个。如果只输入“起始TAI”，该命令会删除所有与此起始TAI对应的记录。                                                                                                           |
| SELMODE  | 选择模式   | 可选必选说明：可选参数 参数含义：该参数用于表示选择LAI的匹配模式。 数据来源：整网规划 取值范围： “SUBRANGE(用户范围)”：匹配IMSI号段的用户。“HOST(主机名)”：匹配HSS主机名的用户。“REALM(域名)”：匹配HSS域名的用户。 默认值：“SUBRANGE(用户范围)”                                                                          |
| HOST     | 主机名    | 可选必选说明：条件可选参数 参数含义：该参数用于指定用户HSS的主机名。 前提条件：该参数在“选择模式”参数设置为“HOST(主机名)”时，才需要配置。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～127。 默认值：无                                                                                                          |
| REALM    | 域名     | 可选必选说明：条件可选参数 参数含义：该参数用于指定用户HSS的域名。 前提条件：该参数在“选择模式”参数设置为“REALM(域名)”时，才需要配置。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～127。 默认值：无                                                                                                           |
| SUBRANGE | 用户范围   | 可选必选说明：可选参数 参数含义：该参数用于指定待删除用户的范围。 前提条件：该参数在“选择模式”参数设置为“SUBRANGE(用户范围)”时，才需要配置。 取值范围：“ALL_USER（所有用户）”：无匹配IMSI前缀的所有用户。“IMSI_PREFIX（指定IMSI前缀）”：IMSI前缀最长长度优先匹配的用户。“IMSI_RANGE（指定IMSI范围）”:IMSI范围匹配用户“USER_GROUP（用户群）”:用户群中的用户 默认值：无 |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件可选参数 参数含义：该参数用于指定待删除用户的IMSI前缀。 前提条件：该参数在“用户范围”参数设置为“IMSI_PREFIX（指定IMSI前缀）”时，才需要配置。 取值范围：1～15位的数字 默认值：无                                                                                                                |
| IMSI     | IMSI   | 可选必选说明：条件可选参数 参数含义：该参数用于指定IMSI，对该IMSI所在号段进行删除。 前提条件：只有“用户范围”为“IMSI_RANGE（指定IMSI范围）”时，该参数才有效。 取值范围：1~15位十进制数字字符串 默认值：无                                                                                                          |
| SUBID    | 用户群标识  | 可选必选说明：条件可选参数 参数含义：该参数用于指定用户群标识。 前提条件：该参数在“用户范围”参数设置为“USER_GROUP（用户群）”时，才需要配置。 数据来源：整网规划 取值范围：1～100 默认值：无                                                                                                                      |
| LAI      | LAI    | 可选必选说明：可选参数 参数含义：该参数用于指定待删除的位置区标识。 取值范围：9～10位的字符串 默认值：无 配置原则： “起始TAI”和“LAI”至少要输入一个。如果只输入“LAI”，该命令会删除所有与此LAI对应的记录。                                                                                                              |

#### 使用实例

删除“起始TAI”为“308014101”的TAI区间与LAI对应关系：

RMV TAILAI: BGNTAI="308014101";
