# 节点查询自动修复开关（LST NODEREPSWITCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

本命令用于查询节点故障自愈开关状态。

**说明** 

该命令仅在Full-stack虚机场景下支持。

#### 注意事项

无。

#### 参数说明

无。

#### 使用实例

查询系统节点故障自愈开关：

```
%%LST NODEREPSWITCH:;%%
RETCODE = 0  操作成功  

       节点故障自愈开关  =  开启
  Error节点故障自愈开关  =  关闭
Unknown节点故障自愈开关  =  关闭
(结果个数 = 1)  
---    END
```

#### 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。输出结果说明如表1所示。

命令执行异常，会返回提示没有对应的查询结果。错误码列表如表2所示。

| 输出项名称           | 输出项解释                                                                     |
|:----------------|:--------------------------------------------------------------------------|
| 节点故障自愈开关        | 用于返回当前系统的节点故障自愈开关状态。 取值范围：“开启”：开启节点故障自愈“关闭”：关闭节点故障自愈                      |
| Error节点故障自愈开关   | 用于返回当前系统的Error节点故障自愈开关状态。 取值范围：“开启”：开启Error节点故障自愈“关闭”：关闭Error节点故障自愈       |
| Unknown节点故障自愈开关 | 用于返回当前系统的Unknown节点故障自愈开关状态。 取值范围：“开启”：开启Unknown节点故障自愈“关闭”：关闭Unknown节点故障自愈 |

|    错误码 | 错误码解释   | 原因分析            | 处理建议       |
|-------:|:--------|:----------------|:-----------|
| 130002 | 操作失败    | MML命令参数解析、校验失败。 | 请联系华为技术支持。 |
