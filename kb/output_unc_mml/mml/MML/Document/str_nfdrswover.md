# 启动人工倒回命令（STR NFDRSWOVER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，操作不当可能会导致用户接入异常网元影响业务，请谨慎使用并联系华为技术支持协助操作。

该命令用于启动基于业务KPI容灾倒换后的人工倒回操作。

## 注意事项

- 该命令执行后立即生效。

- 执行该命令之前请先执行“**DSP DBGHAFG**: QUERYTYPE="APPID|DSP SELFSTATUS";”命令（其中APPID为可变内容，需要执行**LST ME**查询获取执行倒回操作的网元的MEID），关注查询结果中“Status”是否为“normal”，如果是才可以执行本命令。若查询结果中“Status”不是为“normal”，还需通过本命令做强制倒回操作，则需联系华为技术支持。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                        |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数  参数含义：该参数用于设置执行倒回处理的网元ID。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~40。  默认值：无  配置原则：  可以通过MML命令LST ME获取。 |
| FORCE  | 是否强制倒回 | 可选必选说明：可选参数  参数含义：该参数用于设置是否强制执行倒回。  数据来源：本端规划  取值范围： TRUE(TRUE)FALSE(FALSE)  默认值：无  配置原则：无                  |

## 使用实例

启动人工倒回操作。

```
%%STR NFDRSWOVER: MEID="0";%%
RETCODE = 0  操作成功
```
