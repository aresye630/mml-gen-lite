# 查询基于IMSI的5G缺省NI策略（LST NGDFTNIIMSI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询基于用户范围配置AMF的缺省NI策略。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                       |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：可选参数  参数含义：该参数用于指定配置缺省NI（Network Identity）策略生效的用户范围。  数据来源：本端规划 取值范围： “HOME_USER（本网用户）”：本网用户“IMSI_PREFIX（指定IMSI前缀）”：指定IMSI前缀“SPECIFIC_IMSI（指定IMSI）”：指定IMSI  默认值：无  配置原则：无           |
| IMSIPRE  | IMSI前缀 | 可选必选说明：该参数在"SUBRANGE"配置为"IMSI_PREFIX"时为条件可选参数。  参数含义：该参数用于系统根据指定用户的IMSI前缀进行匹配，从而区分不同的用户群。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是5~14。只允许输入十进制数字（0-9）。  默认值：无  配置原则：  不可与“SPECIFIC_IMSI（指定IMSI）”相同。 |
| IMSI     | IMSI   | 可选必选说明：该参数在"SUBRANGE"配置为"SPECIFIC_IMSI"时为条件可选参数。  参数含义：该参数用于指定国际移动用户标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是14~15。只允许输入十进制数字（0-9）。  默认值：无  配置原则：  不可与“IMSIPRE（IMSI前缀）”相同。                        |

## 使用实例

查询指定IMSI前缀的用户配置的缺省NI策略，其中，“用户范围”为：“IMSI\_PREFIX”，“IMSI前缀”为：“12345678910”，执行如下命令：

```
%%LST NGDFTNIIMSI: SUBRANGE=IMSI_PREFIX, IMSIPRE="12345678910";%%
RETCODE = 0  操作成功

结果如下
------------------------
                 用户范围  =  IMSI Prefix
                 IMSI前缀  =  12345678910
                     IMSI  =  NULL
基于DNN下发缺省NI功能开关  =  OFF
           缺省NI取值策略  =  NULL
     是否使用最小签约数据  =  No
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称           | 输出项解释                                                                                                                                                                        |
|:----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 用户范围            | 该参数用于指定配置缺省NI（Network Identity）策略生效的用户范围。                                                                                                                                    |
| IMSI前缀          | 该参数用于系统根据指定用户的IMSI前缀进行匹配，从而区分不同的用户群。                                                                                                                                         |
| IMSI            | 该参数用于指定国际移动用户标识。                                                                                                                                                             |
| 基于DNN下发缺省NI功能开关 | 该参数用于控制AMF是否支持基于特定DNN关键字下发缺省NI功能。当本参数设置为"ON"时，AMF会根据配置的特定DNN关键字（ADD DFTNIDNN配置）匹配用户签约的DNN来判断是否向用户下发缺省NI；如果DNN匹配不成功，AMF不下发缺省NI。                                               |
| 缺省NI取值策略        | 该参数用于控制AMF缺省NI取值策略。对于未勾选的缺省NI下发时，不考虑用户是否签约特定DNN，默认下发缺省NI。                                                                                                                    |
| 是否使用最小签约数据      | 该参数用于控制是否使用最小签约数据（ADD UDMBYPASSSUB中SNSSAIINFOS参数）进行DNN关键字匹配。 当用户进入UDM BYPASS状态后，由于无法获取用户真实的签约数据，在开启“基于DNN下发缺省NI功能开关”时，DNN会匹配失败，用户始终不下发缺省NI，该参数用于控制是否使用最小签约数据替代真实签约数据进行DNN匹配。 |
