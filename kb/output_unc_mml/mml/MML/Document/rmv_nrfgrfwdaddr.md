# 删除备份NRF地址（RMV NRFGRFWDADDR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于删除备份NRF地址。

## 注意事项

- 该命令执行后立即生效。

- 仅供调测使用。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                     |
|:------------|:--------|:---------------------------------------------------------------------------------------------------------|
| PEERNRFNAME | 备份NRF名称 | 可选必选说明：必选参数  参数含义：该参数表示对端NRF名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~64。  默认值：无  配置原则：无                       |
| IPTYPE      | IP类型    | 可选必选说明：必选参数  参数含义：该参数表示对端NRF地址的IP类型。  数据来源：本端规划 取值范围： IPV4（IPv4地址）IPV6（IPv6地址）  默认值：无  配置原则：无            |
| IPV4        | IPV4地址  | 可选必选说明：该参数在"IPTYPE"配置为"IPV4"时为条件必选参数。  参数含义：该参数表示对端NRF的IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无 |
| IPV6        | IPV6地址  | 可选必选说明：该参数在"IPTYPE"配置为"IPV6"时为条件必选参数。  参数含义：该参数表示对端NRF的IPv6地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无 |
| PORT        | 端口      | 可选必选说明：必选参数  参数含义：该参数表示对端NRF地址所对应的端口号。  数据来源：本端规划  取值范围：整数类型，取值范围是0~65535。  默认值：无  配置原则：无                |

## 使用实例

删除备份NRF地址，删除名称为peernrfname01的备份NRF地址：

```
RMV NRFGRFWDADDR: PEERNRFNAME="peernrfname01", IPTYPE=IPV4, IPV4="192.168.16.2", PORT=12345;
```
