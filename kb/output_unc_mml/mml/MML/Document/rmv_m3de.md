# 删除M3UA目的实体(RMV M3DE)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME、SMSF**

该命令用于删除M3UA目的实体。

#### 注意事项

- 该命令执行后立即生效。
- 当M3UA路由表或M3UA链路集表中存在此目的信令点相关的记录时，不允许删除。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                          |
|:-------|:-------|:--------------------------------------------------------------|
| DEX    | 目的实体索引 | 可选必选说明：必选参数 参数含义：该参数用于指定待删除的目的实体的索引。 取值范围：0~1279 默认值：无 配置原则：无 |

#### 使用实例

删除索引为1的M3UA目的实体：

```
RMV M3DE: DEX=1;
```
