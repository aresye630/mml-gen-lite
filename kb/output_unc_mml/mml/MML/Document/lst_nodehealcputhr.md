# 查询节点CPU使用率的过载阈值和空载阈值（LST NODEHEALCPUTHR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询节点CPU使用率的过载阈值和空载阈值。

## 注意事项

该命令只适用于虚机场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                             |
|:---------|:-------|:---------------------------------------------------------------------------------|
| NODETYPE | Node类型 | 可选必选说明：可选参数  参数含义：该参数表示节点类型。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无 |

## 使用实例

查询节点CPU使用率的过载阈值和空载阈值。

```
%%LST NODEHEALCPUTHR:;%%
RETCODE = 0  操作成功

结果如下
--------
Node类型         空载阈值（%）  过载阈值（%）  

PBU_A             10              70                                
SDU               10              66                 
(结果个数 = 2)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                   |
|:--------|:------------------------|
| Node类型  | 该参数表示节点类型。              |
| 空载阈值（%） | 该参数表示节点实例CPU使用率在空载时的阈值。 |
| 过载阈值（%） | 该参数表示节点实例CPU使用率在过载时的阈值。 |
