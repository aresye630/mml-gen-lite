# 查询灰度升级Pod滚动步长（LST UPGSTEP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

灰度升级阶段，执行此命令，用于显示灰度升级Pod滚动步长。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询灰度升级各Pod类型的冗余资源比例：

```
%%LST UPGSTEP:;%%
RETCODE = 0  操作成功

结果如下
--------
升级POD类型  冗余资源比例  

业务服务     50            
链路类服务   25            
cslb+ip      25            
(结果个数 = 3)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释            |
|:--------|:-----------------|
| POD类型   | 该参数用于标识升级时pod类型。 |
| 冗余资源比例  | 该参数用于标识资源冗余百分比。  |
