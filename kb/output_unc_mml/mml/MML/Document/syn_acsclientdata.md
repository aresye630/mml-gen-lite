# 校验ACS客户端数据(SYN ACSCLIENTDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令执行过程中会导致系统CPU和内存升高，如在话务高峰期需谨慎执行。

通过本命令可以校验ACS客户端侧微服务数据。

## 注意事项

该命令执行成功仅表示校验操作下发成功，校验结果需要通过**DSP ACSCFGNTFFAILED**查看。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                              |
|:------------|:-------|:--------------------------------------------------------------------------------------------------|
| SERVICENAME | 服务名称   | 可选必选说明：必选参数。 参数含义：用于指定需要校验数据的微服务名称。 取值范围：长度1~255的字符串。 默认值：无。 配置原则：可以使用DSP ACSSYNCINFO命令查询。        |
| INSTANCEID  | 实例ID   | 可选必选说明：可选参数。 参数含义：用于指定需要校验数据的微服务实例ID。 取值范围：长度1~255的字符串。 默认值：无。 配置原则：可以使用DSP ACSSYNCINFO命令查询。      |
| OBJECTNAME  | 对象名称   | 可选必选说明：可选参数。 参数含义：用于指定需要校验数据的微服务对象名称。 取值范围：长度范围1~16的字符串。 默认值：空。 配置原则：若不输入，则表示校验服务实例所有支持校验出的对象的数据。 |

## 使用实例

校验“服务名称”为“TestCServerNOS”，“实例ID”为“cservernos-149-pod-5df4f67f78-fvgr2172-16-1-1086\_\_cType”，“对象名称”为“TsdkforSPS2”的客户端数据。

```
SYN ACSCLIENTDATA: SERVICENAME="TestCServerNOS", INSTANCEID="cservernos-149-pod-5df4f67f78-fvgr2172-16-1-1086__cType", OBJECTNAME="TsdkforSPS2";
```

```
%%SYN ACSCLIENTDATA: SERVICENAME="TestCServerNOS", INSTANCEID="cservernos-149-pod-5df4f67f78-fvgr2172-16-1-1086__cType", OBJECTNAME="TsdkforSPS2";%%
RETCODE = 0  操作成功

---    END
```
