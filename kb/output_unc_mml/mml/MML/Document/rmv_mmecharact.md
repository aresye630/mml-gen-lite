# 删除MME属性配置信息（RMV MMECHARACT）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于删除对端MME的属性信息。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称          | 参数说明                                                                                                                                                                                                                                                             |
|:---------|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RANGERMV | 对端设备范围        | 可选必选说明：可选参数 参数含义：该参数用于指示对端MME设备范围。 数据来源：全网规划 取值范围： “SPECIAL_MME（指定MME）”：指定MME “COMB_AMF（MME融合AMF）”：MME融合的AMF，包括S10和N26接口地址合一场景。 默认值： SPECIAL_MME（指定MME） 配置原则：无                                                                                                   |
| IPTYPE   | IP地址类型        | 可选必选说明：条件必选参数 参数含义：该参数用于指定对端MME的信令面IP地址类型。 数据来源：全网规划 取值范围：“IPV4（IPv4）”“IPV6（IPv6）” 默认值：无 配置原则：IPv4: 表示对端MME的信令面IP地址为IPv4类型。IPv6：表示对端MME的信令面IP地址为IPv6类型。                                                                                                          |
| IPV4     | MME IPv4信令面地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定对端MME的信令面IPv4地址。 前提条件：该参数在“IP地址类型”参数配置为“IPV4（IPv4）”后生效。 数据来源：全网规划 取值范围：0.0.0.1~255.255.255.254 默认值：无 配置原则：有效的IPv4地址必须是A、B或者C类地址，且不能为环回地址（127.x.y.z）。                                                                                   |
| MASKV4   | IPv4掩码        | 可选必选说明：条件必选参数 参数含义：该参数用于指定对端MME的信令面IPv4地址的掩码。 前提条件：该参数在“IP地址类型”参数配置为“IPV4（IPv4）”后生效。 数据来源：全网规划 取值范围：0.0.0.1~255.255.255.255 默认值：无  说明： 输入的掩码要求对应的二进制值1和1之间不允许存在0。例如：“255.255.0.0”是有效掩码；“123.123.123.123”是无效掩码。因为123对应的二进制为“1111011”，1之间存在0。                      |
| IPV6     | MME IPv6信令面地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定对端MME的信令面IPv6地址。 前提条件：该参数在“IP地址类型”参数配置为“IPV6（IPv6）”后生效。 数据来源：全网规划 取值范围：::~FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 配置原则：IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址（::1）、链路本地地址（FE80::/10）和组播地址（FF00::/8）。 |
| MASKV6   | IPv6子网前缀长度    | 可选必选说明：条件必选参数 参数含义：该参数用于指定子网前缀的长度。 前提条件：该参数在“IP地址类型”参数配置为“IPV6（IPv6）”后生效。 数据来源：全网规划 取值范围：1~128 默认值：无                                                                                                                                                             |

#### 使用实例

删除信令面IP地址为“192.168.168.12”，掩码为“255.255.255.0”的MME的属性信息：

RMV MMECHARACT: IPTYPE=IPV4, IPV4="192.168.168.12", MASKV4="255.255.255.0";
