#### 命令功能

**适用NF：NCG**

该命令用来查看NCG对外网元接口发送IP包时携带的DSCP值。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                               |
|:----------|:-------|:-----------------------------------------------------------------------------------|
| INTERFACE | 接口类型   | 可选必选说明：可选参数 参数含义：该参数用于选择信令报文修改DSCP值的接口类型。 数据来源：全网规划 取值范围：枚举类型。 Ga：Ga。 默认值：无 配置原则：无 |

#### 使用实例

查询NCG对外网元接口发送IP包时携带的DSCP配置：

```
LST DSCP：;
```

```
RETCODE = 0  操作成功。

结果如下:
--------
      接口类型  =  Ga
差分服务代码点  =  56
(结果个数 = 1)
---    END
```
