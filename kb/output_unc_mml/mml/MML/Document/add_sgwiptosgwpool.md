# 增加SGW IP（ADD SGWIPTOSGWPOOL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SGW-C**

该命令用于为SGW POOL下绑定SGW IP。假设运营商需要在SGW故障或者重启场景PGW保留会话，并在有下行数据和信令时触发恢复操作，需要执行该操作。

## 注意事项

- 该命令执行后立即生效。

- 需要注意每个SGW POOL下可绑定255个SGW IP，如果添加的SGW IP虽然还未到255个，但整机已经到达了1024个，配置失败。
- 当一个SGW IP被绑定到某个SGW POOL下时，还可以绑定到其他的SGW POOL，但实际配置中，建议一个SGW IP只绑定到一个SGW POOL中。

- 最多可输入1024条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                                                                                                                                               |
|:------------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SGWPOOLNAME | SGW POOL名称 | 可选必选说明：必选参数  参数含义：该参数用于指定SGW POOL名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。不区分大小写，不支持空格。  默认值：无  配置原则：  该参数使用ADD SGWPOOL命令配置生成。                                                                                                        |
| IPVERSION   | IP版本       | 可选必选说明：必选参数  参数含义：该参数用于指定SGW POOL的地址类型。  数据来源：本端规划 取值范围： IPV4（IPV4）IPV6（IPV6）  默认值：无  配置原则：无                                                                                                                                       |
| IPV4ADDRESS | SGW的IPv4地址 | 可选必选说明：该参数在"IPVERSION"配置为"IPV4"时为条件必选参数。  参数含义：该参数在“IPVERSION”配置为“IPv4”时为必选参数。  数据来源：本端规划  取值范围：IPv4地址类型。  默认值：无  配置原则：  有效的IPv4地址不能为环回地址(127.x.y.z)。  有效的IPv4地址必须是A、B或者C类地址。                                                      |
| IPV6ADDRESS | SGW的IPv6地址 | 可选必选说明：该参数在"IPVERSION"配置为"IPV6"时为条件必选参数。  参数含义：该参数在“IPVERSION”配置为“IPv6”时为必选参数。  数据来源：本端规划  取值范围：IPv6地址类型。  默认值：无  配置原则：  IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址(::1)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。 |

## 使用实例

假设用户需要为已配置的名为“sgwpool1”的SGW POOL绑定一个地址为“10.1.1.1”的IPv4地址：

```
ADD SGWIPTOSGWPOOL:SGWPOOLNAME="sgwpool1",IPVERSION=IPV4,IPV4ADDRESS="10.1.1.1";
```
