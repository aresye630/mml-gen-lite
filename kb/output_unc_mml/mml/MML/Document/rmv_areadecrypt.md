# 删除基于LAC/RAC关闭加密配置(RMV AREADECRYPT)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用于删除一条基于路由区/位置区的关闭加密功能的记录。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------|
| IDTYPE | 标识类型   | 可选必选说明：必选参数 参数含义：该参数用于指定区域的标识类型。 数据来源：整网规划 取值范围：“LA(位置区)”，“RA(路由区)”。 配置原则： LA：表示该区域标识类型为位置区。RA：表示该区域标识类型为路由区。 默认值：无 |
| MCC    | 移动国家代码 | 可选必选说明：必选参数 参数含义：该参数用于指定移动国家代码。 数据来源：整网规划 取值范围：位数为3的十进制数字 默认值： 无                                                    |
| MNC    | 移动网号   | 可选必选说明：必选参数 参数含义：该参数用于指定移动网号。 数据来源：整网规划 取值范围：位数为2或3的十进制数字 默认值： 无                                                    |
| LAC    | 位置区域码  | 可选必选说明：必选参数 参数含义：该参数用于指定位置区域码。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无                                                   |
| RAC    | 路由区域码  | 可选必选说明：条件必选参数 参数含义：该参数用于指定路由区域码。 前提条件：该参数在“标识类型”设置为“RA(路由区)”时生效。 数据来源：整网规划 取值范围：0x00～0xFF 默认值：无                     |

#### 使用实例

删除一条基于路由区的关闭加密功能的记录，标识类型为“RA(路由区)”，移动国家代码为“123”，移动网号为“02”，位置区域码为“0x0628”，路由区域码为“0x52”。

RMV AREADECRYPT: IDTYPE=RA, MCC="123", MNC="02", LAC="0x0628", RAC="0x52";
