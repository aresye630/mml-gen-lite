# 增加预留功能策略(ADD UFCSFB)

#### 命令功能

**适用网元：MME**

该命令用于增加系统的预留功能策略，配置允许哪些用户和终端使用预留功能。

#### 注意事项

- 此命令最大记录数为1024。
- 该命令相关的预留功能系统还未实现，请勿配置，避免系统升级支持预留功能后，造成非预期结果。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                              |
|:---------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围     | 可选必选说明：必选参数 参数含义：该参数用于指定所包含的用户范围。 数据来源：全网规划 取值范围：“ALL_USER(所有用户)”“HOME_USER(本网用户)”“FOREIGN_USER(外网用户)”“IMSI_PREFIX(指定IMSI前缀)” 默认值：无 配置原则：“SUBRANGE（用户范围）”的优先级从高到低为：“IMSI_PREFIX（指定IMSI前缀）”，“FOREIGN_USER（外网用户）”或“HOME_USER（本网用户）”，“ALL_USER（所有用户）”。系统优先查找高优先级的配置记录，如果查找不到，再查找低优先级的配置记录。                                                                           |
| NOID     | 运营商标识    | 可选必选说明：条件必选参数 参数含义：该参数用于指定运营商标识。 前提条件：该参数在“SUBRANGE（用户范围）”配置为“FOREIGN_USER（外网用户）”或“HOME_USER（本网用户）”后生效。 数据来源：全网规划 取值范围：0～64，128～254 默认值：无 配置原则：当用户为MNO用户时，该参数需要配置为0或128～254之间的值，该取值必须和ADD MNO中配置的“MNOID”参数取值相同。当用户为MVNO用户时，该参数需要配置为1～64之间的值，该取值必须和ADD MVNO中配置的“MVNOID”参数取值相同。  说明： 对于外网用户，该参数是与其归属运营商签订可漫游协议，为其提供服务的MNO/MVNO运营商标识。对于本网用户，该参数是该用户归属的MNO/MVNO运营商标识。 |
| IMSIPRE  | IMSI前缀   | 可选必选说明：条件必选参数 参数含义：该参数用于系统对用户的IMSI进行匹配，从而区分不同的用户群。 前提条件：此参数在“SUBRANGE（用户范围）”设置为“IMSI_PREFIX（指定IMSI前缀）”时有效。 数据来源：全网规划 取值范围：1～15位十进制数字字符串 默认值：无  说明： IMSI前缀的匹配方式采取由前向后的最长匹配，即若对于用户可以匹配到多个用户群，则使用IMSI前缀最长的用户群配置。比如：同时存在IMSI前缀为30801和3080101的配置，则优先使用3080101的配置。                                                                                                      |
| UFCSFB   | 预留功能     | 可选必选说明：必选参数 参数含义：该命令用于设置是否允许用户进行预留功能。 数据来源：全网规划 取值范围：“NO(否)”“YES(是)” 默认值：无 配置原则：“NO(否)”：表示系统不允许“SUBRANGE（用户范围）”参数指定的用户进行预留功能。“YES(是)”：表示系统允许“SUBRANGE（用户范围）”参数指定的用户进行预留功能                                                                                                                                                                                         |
| IMEICTRL | 基于IMEI控制 | 可选必选说明：条件可选参数 参数含义：该参数用于配置基于IMEI的预留功能控制方式。 前提条件：此参数在“UFCSFB（预留功能）”设置为“YES”时有效。 数据来源：本端规划 取值范围：“NO(否)”“WHITELIST(白名单)” 配置原则：“NO(否)”：系统不基于终端IMEI控制是否允许用户进行预留功能。“WHITELIST(白名单)”：系统只允许IMEI白名单内的终端进行预留功能，不允许其它终端进行预留功能。需要根据IMEI控制预留功能业务时，例如从终端兼容性考虑需要限定某几款手机才能进行预留功能时，建议将该参数设置为“WHITELIST(白名单)”。 默认值：NO(否)                                                            |
| IMEIGPID | IMEI群组标识 | 可选必选说明：条件必选参数 参数含义：该参数用于配置IMEI群组的标识。 前提条件：该参数在“IMEICTRL(基于IMEI控制)”参数设置为“WHITELIST(白名单)”时，有效。“IMEI群组标识”已经通过ADD IMEIGP配置。 数据来源：本端规划 取值范围：1～50 默认值：无                                                                                                                                                                                                                 |

#### 使用实例

运营商允许本网用户使用预留功能业务，且优先使用基于白名单的控制方式，不允许外网用户使用预留功能业务：

- 配置本网用户的预留功能策略：

  ADD IMEIGP: IMEIGPID=1;

  ADD UFCSFB: SUBRANGE=HOME\_USER, NOID=0, UFCSFB=YES, IMEICTRL=WHITELIST, IMEIGPID=1;
- 配置外网用户的预留功能策略：

  ADD UFCSFB: SUBRANGE=FOREIGN\_USER, NOID=0, UFCSFB=NO;
