# 显示费率组信息（LST RGINFO）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：NCG**

该命令用于查询NCG用户话单所属的费率组信息。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                    |
|:-------|:-------|:----------------------------------------------------------------------------------------|
| RGID   | 费率组ID  | 可选必选说明：可选参数 参数含义：该参数用于表示用户话单所属的费率组。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无 配置原则：无 |

#### 使用实例

查询话单所属费率组信息：

```
LST RGINFO:;
```

```
RETCODE = 0  操作成功

结果如下:
---------
  费率组ID  =  33
费率组名称  =  RG33
(结果个数 = 1)

---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释            |
|:--------|:-----------------|
| 费率组ID   | 表示费率组ID。         |
| 费率组名称   | 表示费率组ID对应的费率组名称。 |
