# 增加UPF逻辑接口（ADD UPLOGICINTF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、PGW-C、SGW-C、GGSN**

该命令用于增加UPF逻辑接口。当UPF不上报U面逻辑接口信息时，SMF可以用配置的逻辑接口信息筛选UPF。

## 注意事项

- 该命令执行后立即生效。

- 同一UPF的同一逻辑接口类型下NETWORKINSTNAME只能配置一个。

- 最多可输入20480条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                     |
|:----------------|:-------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UPFINSTANCEID   | UPF实例标识      | 可选必选说明：必选参数  参数含义：该参数用于指定UPF实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~36。参数必须满足以下约束规则：1.如果输入为uuid格式（格式例如：a6a61c6f-0d3a-4221-b1da-424eda3ccf67）只能为A-F、a-f、0-9的字符。2.如果输入不为uuid格式，长度不能超过18且不允许输入只包含0-9和“.”的字符串，例如：1.2.3.4、不允许输入只包含十六进制数（A-F、a-f、0-9）和“:”的字符串，例如：1::2、FBFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。不区分大小写。  默认值：无  配置原则：  该参数取值应与ADD UPNODE中参数“NFINSTANCENAME”保持一致，使用该前需通过ADD UPNODE添加一组记录。           |
| ITFTYPE         | 逻辑接口类型       | 可选必选说明：必选参数  参数含义：该参数用于指定逻辑接口类型。  数据来源：全网规划 取值范围： S1U（S1-U接口类型）N4U（N4-U接口类型）S11U（S11-U接口类型）GNU（Gn-U接口类型）S2AU（S2a-U接口类型）S2BU（S2b-U接口类型）N3（N3 3GPP Access接口类型）“N9C（N9 Core接口类型）”：5G系统中UPF与右侧UPF间的接口“N9A（N9 Access接口类型）”：5G系统中UPF与左侧UPF间的接口“S5SU（S5-S-U接口类型）”：SGW-U的右侧S5-U接口“S8SU（S8-S-U接口类型）”：SGW-U的右侧S8-U接口“S5PU（S5-P-U接口类型）”：PGW-U的左侧S5-U接口“S8PU（S8-P-U接口类型）”：PGW-U的左侧S8-U接口GPU（Gp-U接口类型）  默认值：无  配置原则：无 |
| NETWORKINSTNAME | 网络实例名称       | 可选必选说明：必选参数  参数含义：该参数用于指定网络实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~128。  默认值：无  配置原则：  只允许输入字母、数字、“.”、“_”、和“-”。字母大小写敏感。                                                                                                                                                                                                                                                                                    |
| IPVERSION       | IP地址类型       | 可选必选说明：必选参数  参数含义：该参数用于标识逻辑接口支持的IP地址类型。  数据来源：全网规划 取值范围： IPV4V6（IPv4v6）IPV4（IPv4）IPV6（IPv6）  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                               |
| CPN4UIPTYPE     | N4U控制面接口IP类型 | 可选必选说明：该参数在"ITFTYPE"配置为"N4U"时为条件可选参数。  参数含义：该参数用于指定N4U控制面接口IP类型。  数据来源：本端规划 取值范围： IPV4_PRIOR（IPv4优先）ACCORDING_PEER（根据对端能力选择IP类型）  默认值：无  配置原则：无                                                                                                                                                                                                                                                          |

## 使用实例

增加UP逻辑接口，UPF实例标识为upf\_instance\_1，逻辑接口类型为N3，网络实例名称为huawei.com，IP地址类型为IPv4。

```
ADD UPLOGICINTF: UPFINSTANCEID="upf_instance_1", ITFTYPE=N3, NETWORKINSTNAME="huawei.com", IPVERSION=IPV4;
```
