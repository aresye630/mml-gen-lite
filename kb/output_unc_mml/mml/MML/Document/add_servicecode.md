# 增加智能业务编码（ADD SERVICECODE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、PGW-C**

该命令用于增加一个智能业务编码，该业务编码用于映射智能业务规则。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入1000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                              |
|:------------|:-------|:--------------------------------------------------------------------------------------------------|
| SERVICECODE | 智能业务编码 | 可选必选说明：必选参数  参数含义：该参数用于指定业务编码的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。不支持空格，不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

增加智能业务编码为“intelligent”的配置：

```
ADD SERVICECODE: SERVICECODE="intelligent";
```
