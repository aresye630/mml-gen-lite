# 删除基于区域的网络名称 (RMV AREAMMINFO)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

此命令用于删除基于区域的网络名称。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                               |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| BGNTAI   | 起始TAI  | 可选必选说明：必选参数 参数含义：该参数用于指定跟踪区标识，标识一个起始跟踪区。 数据来源：整网规划 取值范围：9～10位的字符串 默认值：无 配置原则： 起始TAI由MCC，MNC，TAC组成。MCC为3个BCD码字符，MNC为2个或者3个BCD码字符，填写时请遵循实际长度。TAC编码为16进制数，固定为4位，不足补0。新增的TAI区间不能和同一用户范围内已有的TAI区间存在交集。                                                                                                                  |
| SUBRANGE | 用户范围   | 可选必选说明：必选参数 参数含义：该参数用于指定用户范围。 数据来源：整网规划 取值范围： “IMSI_PREFIX(指定IMSI前缀)”：指网络中与指定的IMSI前缀匹配的用户。“HOME_USER(本网用户)”：指网络中的本网签约用户。“FOREIGN_USER(外网用户)” ：指网络中的漫游用户。“ALL_USER(所有用户)”：指网络中的所有用户。 默认值：无 配置原则： “SUBRANGE（用户范围）”的优先级从高到低为：“IMSI_PREFIX”，“FOREIGN_USER”或“HOME_USER”，“ALL_USER”。系统优先查找高优先级的配置记录，如果查找不到，再查找低优先级的配置记录。 |
| NOID     | 运营商标识  | 可选必选说明：条件必选参数 参数含义：该参数用于指定运营商标识。 数据来源：整网规划 前提条件：该参数在“SUBRANGE”配置为“FOREIGN_USER”或“HOME_USER”后生效。 取值范围：整数类型，取值范围为0~64，128~254。 默认值：无 配置原则： 若该参数需要配置为0或128～254之间的值时，须先在ADD MNO中配置取值相同的“MNOID”参数。若该参数需要配置为1～64之间的值时，须先在ADD MVNO中配置取值相同的“MVNOID”参数。                                                                     |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI前缀以区分不同的用户群。 数据来源：整网规划 前提条件：该参数在“用户范围”参数配置为“IMSI_PREFIX”后生效。 取值范围：5～15位十进制数字字符串。 默认值：无 配置原则： 当该参数配置生效时，按照IMSI最长匹配进行查询，如果有匹配的记录，使用该记录的配置；如果没有匹配的记录，则查找IMSI次长匹配的记录。                                                                                                                    |

#### 使用实例

删除BGNTAI为1111111111，SUBRANGE为HOME\_USER，NOID为1的基于区域的网络名称：

```
RMV AREAMMINFO: BGNTAI="1111111111", SUBRANGE=HOME_USER, NOID=1;
```
