# 删除隧道策略（RMV TUNNELPOLICY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除隧道策略。

#### 注意事项

- 该命令执行后立即生效。
- 若删除隧道策略名，则当前隧道策略下的隧道选择策略将被同时删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                    |
|:--------------|:-------|:------------------------------------------------------------------------|
| TNLPOLICYNAME | 隧道策略名字 | 可选必选说明：必选参数 参数含义：该参数用于表示隧道策略名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～39。 默认值：无 |

#### 使用实例

删除隧道策略：

```
RMV TUNNELPOLICY:TNLPOLICYNAME="tp";
```
