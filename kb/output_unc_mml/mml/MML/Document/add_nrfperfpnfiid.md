# 增加NRF局向性能统计对象识别标识（ADD NRFPERFPNFIID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于增加NRF局向性能统计对象识别标识。若配置了NRFPERFPEERNF对应的性能统计对象，需配合本命令增加对端网元的标识信息，以便能基于标识信息识别业务消息来精确统计。

## 注意事项

- 该命令执行后立即生效。

- 本命令中的PEERNFNAME参数引用自ADD NRFPERFPEERNF，在执行本命令之前，请首先通过ADD NRFPERFPEERNF配置PEERNFNAME。
- IPv4、IPv6、NF实例标识至少填写一个。
- IPv4、IPv6、NF实例标识同时配置，优先级为：IPv4>IPv6>NF实例标识。

- 最多可输入10000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称        | 参数说明                                                                                                                                                |
|:-----------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| INDEX      | 标识索引        | 可选必选说明：必选参数  参数含义：该参数用于表示NRF上局向性能统计对象的标识索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~2147483647。  默认值：无  配置原则：无                                                 |
| PEERNFNAME | 对端NF实例名称    | 可选必选说明：必选参数  参数含义：该参数用于表示对端网元的实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~255。  默认值：无  配置原则：  本参数的构成字符只能是字母A～Z或a～z、数字0～9、中划线"-"和下划线"_"，例如，AMF_Instance_0。 |
| PEERNFIPV4 | 对端NF的IPV4地址 | 可选必选说明：可选参数  参数含义：该参数用于表示对端网元的IPV4地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无                                                                     |
| PEERNFIPV6 | 对端NF的IPV6地址 | 可选必选说明：可选参数  参数含义：该参数用于表示对端网元的IPV6地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无                                                                     |
| PEERNFID   | 对端NF实例标识    | 可选必选说明：可选参数  参数含义：该参数用于表示对端网元的实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：  需与运营商规划的网元的实例标识一致。                                          |

## 使用实例

若运营商需要查看对端网元 AMF\_Instance\_0发起的服务发现请求的性能指标统计，可配置如下来标识对端网元。

- 场景一：增加INDEX为1，IPv4地址为“192.168.52.1”的标识。

  ```
  ADD NRFPERFPNFIID: INDEX=1, PEERNFNAME="AMF_Instance_0", PEERNFIPV4="192.168.52.1";
  ```
- 场景二：增加INDEX为2，NF实例标识为“bdc3f6f6-69ac-4c06-bfe5-000001000001”的性能统计标识。

  ```
  ADD NRFPERFPNFIID: INDEX=2, PEERNFNAME="AMF_Instance_0", PEERNFID="bdc3f6f6-69ac-4c06-bfe5-000001000001";
  ```
- 场景三：增加INDEX为2，IPv4地址为“192.168.52.1”，NF实例标识为“bdc3f6f6-69ac-4c06-bfe5-000001000001”的性能统计标识。

  ```
  ADD NRFPERFPNFIID: INDEX=2, PEERNFNAME="AMF_Instance_0", PEERNFIPV4="192.168.52.1", PEERNFID="bdc3f6f6-69ac-4c06-bfe5-030101000001";
  ```
