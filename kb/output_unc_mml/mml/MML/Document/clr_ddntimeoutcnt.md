# 清除DDN超时延时删除功能运行信息记录（CLR DDNTIMEOUTCNT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C**

该命令用于DDN消息无响应延时删除用户功能开启后，清除相关累计值信息，包括已经处理过的延时删除用户数、从延时删除状态被恢复的用户数、从延时删除状态被删除的用户数，不清除当前处于延时删除状态的用户数信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

无

## 使用实例

清除DDN消息无响应延时删除用户功能生效后的相关维护信息：

```
CLR DDNTIMEOUTCNT:;
```
