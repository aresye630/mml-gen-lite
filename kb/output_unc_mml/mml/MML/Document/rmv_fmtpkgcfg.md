# 删除格式引擎包软参（RMV FMTPKGCFG）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

此命令不能动态生效，需要执行“RST VNFC”重启服务。

**适用NF：NCG**

该命令用于删除格式引擎包配置的软参信息。

#### 注意事项

该命令执行后，需在“MML命令行 - UNC”窗口执行“**RST VNFC**”命令重新启动系统才能生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                |
|:--------|:----------|:------------------------------------------------------------------------------------|
| PRFNAME | 格式引擎包名    | 可选必选说明：必选参数 参数含义：用于返回查询到的格式引擎配置包名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～255。 默认值：无 配置原则：无 |
| CFGNAME | 格式引擎包软参名称 | 可选必选说明：必选参数 参数含义：用于返回格式引擎配置的软参名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～255。 默认值：无 配置原则：无   |

#### 使用实例

用于删除格式引擎包软参：

```
RMV FMTPKGCFG: PRFNAME="PS_R9_V940_M_RT.tar.gz", CFGNAME="MaxDuration";
```
