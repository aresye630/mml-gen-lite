# 显示用户Iu连接负荷状态(DSP IULOAD)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用网元：SGSN**

该命令用于查询用户Iu连接负荷状态。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                     |
|:-------|:-------|:-------------------------------------------------------------------------|
| RUNAME | RU名称   | 可选必选说明：可选参数 参数含义：该参数用于指定SPU资源单元名。该参数可以通过DSP RU命令查询。 取值范围：0~63 位字符串 默认值：无 |

#### 使用实例

查询用户Iu连接负荷状态：

DSP IULOAD: RUNAME="USN\_SP\_RU\_0064";

```
%%DSP IULOAD: RUNAME="USN_SP_RU_0064";%%
RETCODE = 0  操作成功。

查找IU负荷配置表
----------------
RU名称            进程号    负荷状态    连接数

USN_SP_RU_0064    0         正常        0     
USN_SP_RU_0064    1         正常        0     
USN_SP_RU_0064    2         正常        0     
USN_SP_RU_0064    3         正常        0     
USN_SP_RU_0064    4         正常        0     
(结果个数 = 5)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                                                   |
|:--------|:--------------------------------------------------------|
| RU名称    | SGP进程的资源单元名。                                            |
| 进程号     | SGP进程的进程号。                                              |
| 负荷状态    | SGP进程的负荷状态。 取值说明： “正常”“拥塞”“不可用”  说明： 负荷状态为拥塞时，一般需要考虑扩容。 |
| 连接数     | Iu连接数。                                                  |
