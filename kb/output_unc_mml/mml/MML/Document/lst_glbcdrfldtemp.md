#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

该命令用于查询全局话单模板配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询全局话单模板：

```
LST GLBCDRFLDTEMP:;
```

```
RETCODE = 0  操作成功

----------------

PGW-CDR话单字段模板名  =  pgwcdr

(结果个数 = 1)

---    END
```
