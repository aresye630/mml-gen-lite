# 查询RU资源过载和去过载阈值（LST RURESTHRESHOLD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查看不同RU类型的资源过载和去过载阈值。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                        |
|:----------------|:-------|:----------------------------------------------------------------------------------------------------------------------------|
| RUTYPE          | RU类型   | 可选必选说明：可选参数 参数含义：该参数用于指定RU类型。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：请使用LST RESINSTANCETYPE命令查询存在的资源单元类型。 |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。                |

#### 使用实例

查询VNODE\_CSLB\_VNFC\_OMU类型的资源过载和去过载阈值：

```
LST RURESTHRESHOLD:RUTYPE="VNODE_CSLB_VNFC_OMU",SERVICEINSTANCE="vnfc";
```
