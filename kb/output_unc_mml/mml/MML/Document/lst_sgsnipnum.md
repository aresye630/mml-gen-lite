#### 命令功能

**适用网元：SGSN**

该命令用于查询SGSN控制面IP地址与SGSN号码对照表中的SGSN控制面IP地址与SGSN号码的对照关系。

#### 注意事项

- 该命令执行后立即生效。
- 不输入参数时将显示本SGSN下配置的所有SGSN控制面IP地址与SGSN号码的对照关系。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称          | 参数说明                                                                                                                                                                                                                                                                                                     |
|:-------|:--------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPT    | IP地址类型        | 可选必选说明：可选参数 参数含义：该参数用于指定IP地址类型 取值范围：“IPV4(IPV4)”“IPV6(IPV6)” 默认值：无                                                                                                                                                                                                                                       |
| IPV4   | SGSN控制面IP地址   | 可选必选说明：条件必选参数 参数含义：该参数用于指定SGSN的控制面IPv4地址。 前提条件：当“IP地址类型”为“IPV4(IPV4)”时，该参数有效 取值范围：0.0.0.0～255.255.255.255 默认值：无 配置原则：业务地址不能配置为0.0.0.0、255.255.255.255和环回地址(127.x.y.z)。业务地址必须是A、B或者C类地址。该参数的掩码缺省为255.255.255.255，不可更改。                                                                                    |
| IPV6   | SGSN控制面IPv6地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定SGSN的控制面IPv64地址。 前提条件：当“IP地址类型”为“IPV6(IPV6)”时，该参数有效 取值范围：::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 配置原则：IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址(::1)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。该参数的掩码缺省为FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF，不可更改。 |

#### 使用实例

列出SGSN中所有存在的SGSN控制面IP地址与SGSN号码的对照关系：

LST SGSNIPNUM:;

```
%%LST SGSNIPNUM:;%%
RETCODE = 0  操作成功。

操作结果如下
--------------
              IP地址类型  =  IPV4
        SGSN控制面IP地址  =  10.10.10.16
                SGSN号码  =  861390218888
(结果个数 = 1)
---    END
```
