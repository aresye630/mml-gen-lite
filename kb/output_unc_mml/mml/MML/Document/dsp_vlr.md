# 显示VLR迁移进度(DSP VLR)

- 本地用户权限

#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询VLR迁移进度信息。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称       | 参数说明                                                                                                                                                                                                                                 |
|:-----------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VN         | VLR号       | 可选必选说明：可选参数 参数含义：该参数用于指定VLR在移动网络中的设备号。 数据来源：整网规划 取值范围：1～15位十进制数字 默认值： 无。                                                                                                                                                             |
| POOLNM     | MSC POOL名称 | 可选必选说明：可选参数 参数说明：该参数用于指定MSC POOL名称。 数据来源：整网规划 取值范围：最大长度为19的字符串 默认值：无。  说明： POOLNM唯一标识一个MSC POOL。当此参数没有输入任何值的时候表示新增加的VLR不属于任何MSC POOL。此参数大小写敏感，不支持含有中文字符，不支持包含非法字符，如逗号、分号、冒号、等号、加号、减号、单引号、双引号、百分号。POOLNM的值不能设置为NULL（这里字符N，U和L不区分大小写）。 |
| OFFLOADSTA | 迁移状态       | 可选必选说明：可选参数 参数含义：该参数用于指定VLR目前的迁移状态。 数据来源：整网规划 取值范围： “NORMAL（正常）”“OFFLOAD_MANUALLY（手动迁移中）”“OFFLOAD_AUTO（自动迁移中）” 默认值： 无。                                                                                                               |

#### 使用实例

1. 查询VLR迁移进度信息：

   **DSP VLR:;**

   ```
   %%DSP VLR: VN="1230301";%%
   RETCODE = 0  操作成功。

   操作结果如下
   ------------

          VLR号 = 1230301
        VLR名称 = VLR1
   MSC POOL名称 = NULL
        最小V值 = 0
        最大V值 = 999
    附加最小V值 = NULL
    附加最大V值 = NULL
       迁移状态 = 正常
       迁移阶段 = 初始化
         用户数 = 0
   剩余迁移时间 = 0
   （结果个数 = 1）

   ---    END
   ```

#### 输出结果说明

| 输出项名称      | 输出项解释                                                                                                          |
|:-----------|:---------------------------------------------------------------------------------------------------------------|
| VLR号       | VLR在移动网络中的设备号。                                                                                                 |
| VLR名称      | VLR名称。                                                                                                         |
| MSC POOL名称 | MSC POOL的名称。                                                                                                   |
| 最小V值       | 最小的V值，与最大V值组合，形成V值区间。USN系统采用一种算法从IMSI得到一个V值，V值的范围是0－999。UNC系统再根据本表配置的V值区间，查看从IMSI计算出来的V值在本表的哪个V值区间中，从而选择一个VLR。 |
| 最大V值       | 最大的V值，与最小V值组合，形成V值区间。USN系统采用一种算法从IMSI得到一个V值，V值的范围是0－999。UNC系统再根据本表配置的V值区间，查看从IMSI计算出来的V值在本表的哪个V值区间中，从而选择一个VLR。 |
| 附加最小V值     | 附加最小V值。                                                                                                        |
| 附加最大V值     | 附加最大V值。                                                                                                        |
| 迁移状态       | 目前的迁移状态。 取值范围： 正常手动迁移中自动迁移中                                                                                    |
| 迁移阶段       | 目前的迁移阶段。 取值范围： 初始化第一阶段第二阶段迁移结束                                                                                 |
| 用户数        | 剩余迁移的用户数。  说明： 所查询的VLR上当前处于关联状态的用户数。                                                                           |
| 剩余迁移时间     | 剩余迁移时间。  说明： 根据设置的第二阶段迁移速度，计算VLR上当前关联的用户数全部被迁移所需要的时间。单位：分钟。                                                    |
