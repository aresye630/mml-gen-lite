#### 命令功能

**适用NF：NCG**

该命令用于显示所有业务进程状态。

当系统安装后、进行系统维护时或者系统重启后，可以使用**DSP SERVICE**显示业务进程状态。

如果出现业务状态异常，请检查系统的告警、日志，并进行处理。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                   |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------|
| RUID   | RU的ID  | 可选必选说明：可选参数 参数含义：RU的ID。 数据来源：本端规划 取值范围：整数类型，取值范围为64～4294967294。 默认值：无 配置原则：该值需要执行LST SERVICERUSTATE命令，查询出存在的RU ID进行填写。 |

#### 使用实例

显示所有的业务状态：

```
DSP SERVICE:;
```

```

结果如下:
--------

64        cdm_proc    激活     
64        cbk_proc    激活

65        AP65_1      激活     
65        cdm_proc    激活     
65        cbk_proc    激活     
65        cqb_proc    激活     
(结果个数 = 8)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释      |
|:--------|:-----------|
| RU的ID   | RU的ID。     |
| 模块名     | 业务进程的模块名称。 |
| 模块状态    | 业务进程的模块状态。 |
