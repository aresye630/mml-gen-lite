# 删除5G PRA（RMV NGPRA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除5G PRA基本信息。

## 注意事项

- 该命令执行后立即生效。

- 在PRA内的所有位置成员都已经删除的情况下，才允许删除PRA基本信息。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                           |
|:-------|:-------|:-----------------------------------------------------------------------------------------------|
| PRAID  | PRA标识  | 可选必选说明：必选参数  参数含义：该参数用于表示PRA区域的标识。  数据来源：全网规划  取值范围：整数类型，取值范围是8388608~16777215。  默认值：无  配置原则：无 |

## 使用实例

删除系统中当前配置的标识为16777211的PRA，执行如下命令：

```
RMV NGPRA: PRAID=16777211;
```
