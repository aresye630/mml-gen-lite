# 解锁用户（ULK USER）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

该操作执行后，会影响系统的安全保护，可能存在安全风险，请谨慎操作。

**适用NF：NCG**

该命令用于解锁当前已锁定的用户。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug

#### 网管用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                              |
|:---------|:-------|:----------------------------------------------------------------------------------|
| USERNAME | 用户名    | 可选必选说明：必选参数 参数含义：该参数用于指定需要解锁的用户名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：无 |

#### 使用实例

解锁当前已锁定的用户：

```
ULK USER: USERNAME="BS";
```
