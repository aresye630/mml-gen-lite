# 查询规则（LST RULE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于查询规则。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
|:-------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RULENAME     | 规则名称   | 可选必选说明：可选参数 参数含义：该参数用于设置规则名称。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：设置该参数时表示查询指定名称的规则，未设置该参数时表示查询系统中所有的规则。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| POLICYTYPE   | 策略类型   | 可选必选说明：可选参数 参数含义：该参数用于设置策略类型。 数据来源：对端协商 取值范围：枚举类型。 PCC：计费与策略控制，代表该规则可以配置PCC策略，用于实现计费和策略控制功能。BWM：带宽管理，代表该规则可以配置带宽管理分类策略，其分类结果可以用于带宽管理的策略匹配功能。HEADEN：头增强，代表该规则可以配置头增强策略，可以基于配置的头增强策略向HTTP/RTSP请求报文头域中插入字段。WEBPROXY：Web Proxy，代表该规则可以配置WebProxy的IPFarm对象名称，用于设置WebProxy选择的服务器地址池。IPREDIR：IP重定向，代表该规则可以配置IP重定向的目标IP地址，支持IPv4和IPv6两种类型的IP地址。SMARTREDIRECT：Captive Portal智能重定向，代表该规则可以配置Captive Portal的IPFarm对象名称，用于设置Captive Portal选择的服务器地址池。REMARK_FPI：Remark或者FPI，代表该规则可以配置IP报文的DSCP重标记值或FPI策略。SRV_TRIGGER：Service Trigger Radius，代表该规则可以配置业务触发Radius消息交互功能标识，并配置Radius交互过程中报文处理方式。TRAFFICCLASS：Traffic Classifier，代表该规则可以配置Service Chain对象名称，用于实现业务链功能。LBO：Local Break Out，代表该规则可以用于本地业务分流。FIREWALL：防火墙，代表该规则可以配置防火墙策略。ULCL：ULCL，代表该规则可以配置ULCL策略。ADC：代表该规则用于应用检测与控制功能。QOS：代表该规则可以配置QoS策略，可以基于配置的QoS策略进行业务级QoS处理。FUP：公平使用策略，代表该规则可以配置公平使用策略。NON_SPECIFIC_TYPE：不指定具体的类型。 默认值：无 配置原则：根据部署的业务策略选择相应的策略类型。 |
| RULESPECTYPE | 规则规格类型 | 可选必选说明：可选参数 参数含义：该参数用于指定规则规格类型，当取值为SPECIFICATION_LIMITED时，表示规格受限规则，表示被用户安装的规格和被USERPROFILE绑定的规格均比默认规格小，需要配合相应特性使用。 数据来源：全网规划 取值范围：枚举类型。 DEFAULT：默认配置。SPECIFICATION_LIMITED：规格受限配置。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

#### 使用实例

- 查询一条名为testrule的规则：

  ```
  LST RULE: RULENAME="testrule";
  ```

  ```

    全局优先级  =  50
      策略类型  =  PCC

  流过滤器名称  =  NULL
  规则生效范围  =  对中心和边缘UPF均生效
  规则规格类型  =  默认配置
  NWDAF数据分析事件  =  NULL

  ```

  ```
  LST RULE:;
  ```
