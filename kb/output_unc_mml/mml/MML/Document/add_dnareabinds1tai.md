# 增加DNAI服务区名称绑定的4G TAI范围（ADD DNAREABINDS1TAI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C、SMF、GGSN**

该命令用于增加DNAI服务区名称绑定的4G TAI范围。

## 注意事项

- 该命令执行后立即生效。

- 同一个AREANAME下TAI区域不能有交叠，不同AREANAME下TAI区域不做限制。

- 最多可输入32000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称                    | 参数说明                                                                                                                                                                                                                 |
|:-----------|:------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AREANAME   | DNAI服务区域名称              | 可选必选说明：必选参数  参数含义：该参数用于标识DNAI服务区域名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~255。不能为非法字符，只允许输入字母，数字、“_”、“.”，并且开头和结尾只能是数字或者字母，不能出现连续两个“.”，不区分大小写。  默认值：无  配置原则：  该参数取值应与命令LST DNAREA查询结果中的AREANAME保持一致，且对应的AREATYPE取值应为S1TAI。 |
| S1BEGINTAI | DNAI服务区名称支持4G TAI范围的起始值 | 可选必选说明：必选参数  参数含义：该参数用于标识DNAI服务区名称支持4G TAI范围的起始值，TAI = MCC+ MNC + TAC。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是9~10。后4位为16进制数，其余为10进制数。不区分大小写。  默认值：无  配置原则：  TAI范围的结束值需要不小于TAI范围的开始值，且结束值和开始值长度需相等。                           |
| S1ENDTAI   | DNAI服务区名称支持4G TAI范围的结束值 | 可选必选说明：必选参数  参数含义：该参数用于标识DNAI服务区名称支持4G TAI范围的结束值，TAI = MCC+ MNC + TAC。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是9~10。后4位为16进制数，其余为10进制数。不区分大小写。  默认值：无  配置原则：  TAI范围的结束值需要不小于TAI范围的开始值，且结束值和开始值长度需相等。                           |

## 使用实例

增加DNAI服务区名称为“DNAREA1”的TAI绑定范围460010001~460011234。

```
ADD DNAREABINDS1TAI: AREANAME="DNAREA1", S1BEGINTAI="460010001", S1ENDTAI="460011234";
```
