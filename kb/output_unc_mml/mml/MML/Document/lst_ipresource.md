#### 命令功能

**适用NF：NCG**

该命令用于查询IP资源的详细信息：

如果需要查询全部信息，请不要输入任何参数。

如果需要查询某方面的详细信息，请输入具体参数。例如，查询用于话单分发的IP资源的详细信息，请输入“IP资源用途”值为“Bi”。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                              |
|:-----------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPRID      | IP资源标识 | 可选必选说明：可选参数 参数含义：用于表示一个IP资源对象，全局唯一。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：无                                                                                                |
| IPRPURPOSE | IP资源用途 | 可选必选说明：可选参数 参数含义：IP资源用途。 数据来源：本端规划 取值范围：枚举类型。 Bi：Bi。Omi：Omi。OmiAndBi：Omi&Bi。Ga：Ga。 默认值：无 配置原则：无                                                                                   |
| RUID       | RU的ID  | 可选必选说明：条件可选参数 前提条件：该参数在“IPRPURPOSE”配置为“Bi”、“Omi” 或 “OmiAndBi”时为条件可选参数。 参数含义：RU的ID。 数据来源：本端规划 取值范围：整数类型，取值范围为64～4294967294。 默认值：无 配置原则：该值需要执行LST SERVICERUSTATE命令，查询出存在的RU ID进行填写。 |
| IPTYPE     | IP地址类型 | 可选必选说明：可选参数 参数含义：用于表示Ga、Bi、Omi、OmiAndBi口IP地址属于IPv4网络还是IPv6网络，需根据当前局点规划选择其中一种。 数据来源：对端协商 取值范围：枚举类型。 IPV4：IPv4。IPV6：IPv6。 默认值：无 配置原则：无                                              |
| IPV4       | IPv4地址 | 可选必选说明：条件可选参数 前提条件：该参数在“IPTYPE”配置为“IPV4”时为条件可选参数。 参数含义：用于话单接收的IPv4地址。 数据来源：本端规划 取值范围：IPv4地址类型。0.0.0.0-255.255.255.255。 默认值：无 配置原则：无                                               |
| IPV6       | IPv6地址 | 可选必选说明：条件可选参数 前提条件：该参数在“IPTYPE”配置为“IPV6”时为条件可选参数。 参数含义：用于话单接收的IPv6地址。 数据来源：本端规划 取值范围：IPv6地址类型。::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。 默认值：无 配置原则：无                            |
| VPNNAME    | 虚拟网络名称 | 可选必选说明：可选参数 参数含义：该参数为VPN名称，是业务消息转发时的鉴权参数。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无                                                                                          |

#### 使用实例

查询用于话单分发或者备份的IP资源，示例如下：

```
LST IPRESOURCE:;
```

```

    IPv6地址  =  ::
```
