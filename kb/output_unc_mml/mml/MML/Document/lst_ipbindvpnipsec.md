# 查询接口绑定VPN（LST IPBINDVPNIPSEC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询接口绑定VPN。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                 |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------|
| IFNAME | 接口名    | 可选必选说明：可选参数  参数含义：用于设置绑定VPN的接口名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。接口名称由接口类型+接口编号组成。  默认值：无  配置原则：无 |

## 使用实例

查询接口绑定VPN：

```
LST IPBINDVPNIPSEC:IFNAME="Loopback1";

RETCODE = 0  操作成功。
  
结果如下
------------------------
          接口名  =  Loopback1
    IPv4地址  =  192.168.1.1
IPv4地址掩码  =  255.255.0.0
     VPN实例名称  =  vrf1
(结果个数 = 1)
--END
```

## 输出结果说明

| 输出项名称     | 输出项解释                      |
|:----------|:---------------------------|
| 接口名       | 用于设置绑定VPN的接口名。             |
| IPv4地址    | 该参数用于指定需要配置的IPv4地址。        |
| IPv4地址掩码  | 该参数用于指定需要配置的接口IPv4地址的网络掩码。 |
| IPv6地址    | 该参数用于指定需要配置的IPv6地址。        |
| IPv6地址掩码  | 该参数用于指定需要配置的接口IPv6地址的网络掩码。 |
| 校验为V4还是V6 | 校验为IPv4还是IPv6。             |
| VPN实例名称   | 该参数用于指定接口绑定的VPN实例名称。       |
