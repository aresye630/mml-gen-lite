# 查询话统指标测量状态(DSP MEASSTAT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于获得网元上的话统指标的测量状态，包含采集端、汇聚端的测量信息。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                 |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------|
| MEID     | 网元ID   | 可选必选说明：必选参数。 参数含义：标识网元ID。 取值范围：0~65535。 默认值：无。 配置原则：可以通过LST ME命令查询获取。                                                                |
| METRICID | 测量指标ID | 可选必选说明：必选参数。 参数含义：测量指标ID。 取值范围：字符串类型，长度不超过256个字符。 默认值：无。 配置原则：可以通过LST MEASUNIT命令查询获取。支持最多6个测量指标ID，以&字符分割，不能以&结尾，且属于同一个测量单元。例如 1&2&3。 |
| MOIID    | 对象实例ID | 可选必选说明：必选参数。 参数含义：对象实例ID。 取值范围：字符串类型，长度不超过256个字符。 默认值：无。 配置原则：可以通过DSP MEASOBJ命令查询获取。                                                 |
| SOURCE   | 数据源    | 可选必选说明：必选参数。 参数含义：标识查询的话统指标测量状态的数据来源。 取值范围： COLLECTION_END(采集端)CONVERGENCE_END(汇聚端) 默认值：无。 配置原则：无。                                   |
