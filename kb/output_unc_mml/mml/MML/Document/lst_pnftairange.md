# 查询对端NF的TAI范围（LST PNFTAIRANGE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF、SMF、NSSF、SMSF、NCG、PGW-C、SGW-C、CBC、CBCF**

该命令用于查询本地配置的对端NF实例支持的TAI范围信息。

## 注意事项

- 当PRISWITCH为“INHERIT”时，对端UPF实例的优先级以PNFPROFILE中的优先级为准；当PRISWITCH为“SPECIFIC”时，对端UPF实例的优先级以该配置中的优先级为准。
- 当CAPSWITCH为“INHERIT”时，对端UPF实例的容量以PNFPROFILE中的容量为准；当CAPSWITCH为“SPECIFIC”时，对端UPF实例的容量以该配置中的容量为准。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识            | 参数名称            | 参数说明                                                                                                                                                                                                                                                                                                                                                                                   |
|:----------------|:----------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INDEX           | 索引              | 可选必选说明：可选参数  参数含义：该参数用于指定TAI范围对应的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                           |
| NFINSTANCEID    | NF实例标识          | 可选必选说明：可选参数  参数含义：该参数用于指定NF实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~50。NFINSTANCEID参数建议满足以下约束规则：1.如果输入为uuid格式（格式例如：a6a61c6f-0d3a-4221-b1da-424eda3ccf67）只能为A-F、a-f、0-9和“-”的字符。2.如果输入不为uuid格式，长度不能超过18且不允许输入只包含0-9和“.”的字符串，例如：1.2.3.4、不允许输入只包含十六进制数（A-F、a-f、0-9）和“:”的字符串，例如：1::2、FBFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。  默认值：无  配置原则：  本参数取值与ADD PNFPROFILE命令中的“NF实例标识”参数取值保持一致时，关联关系生效。 |
| PNFNSINDEX      | 对端NF的切片索引       | 可选必选说明：可选参数  参数含义：该参数用于指定对端NF实例支持以TAIRANGE为条件配置优先级与权重时所关联的切片索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：  当该值配置为空或0时，代表支持所有切片索引。                                                                                                                                                                                                                                         |
| BINDNWDAFINFOID | 绑定的NWDAFINFO ID | 可选必选说明：可选参数  参数含义：该参数用于指定绑定的PNFNWDAFEVENT记录。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~32。该参数大小写不敏感。  默认值：无  配置原则：  BINDNWDAFINFOID需要与ADD PNFNWDAFEVENT中的NWDAFINFOID一致。                                                                                                                                                                                                                          |

查询对端NF的TAI范围信息。


## 输出结果说明

| 输出项名称           | 输出项解释                                                                            |
|:----------------|:---------------------------------------------------------------------------------|
| 索引              | 该参数用于指定TAI范围对应的索引。                                                               |
| NF实例标识          | 该参数用于指定NF实例标识。                                                                   |
| 移动国家码           | 该参数用于指定对端NF的移动国家码。                                                               |
| 移动网号            | 该参数用于指定对端NF的移动网号。                                                                |
| 查询方式            | 该参数用于指定TAC的配置号段的方式。                                                              |
| 起始号段            | 该参数用于指定TAC的起始号段。当QUERYTYPE参数设置为START_END模式时有效。                                   |
| 终止号段            | 该参数用于指定TAC的终止号段。当QUERYTYPE参数设置为START_END模式时有效。                                   |
| 模式              | 该参数用于指定TAC的具体的号段匹配正则表达式。当QUERYTYPE参数设置为PATTERN模式时有效。                             |
| 对端NF的切片索引       | 该参数用于指定对端NF实例支持以TAIRANGE为条件配置优先级与权重时所关联的切片索引。                                    |
| 优先级功能开关         | 该参数用于指定对端NF实例针对TAIRANGE的优先级设置方式。                                                 |
| 优先级             | 该参数用于指定对端NF所支持的TAIRANGE的优先级。                                                     |
| 容量功能开关          | 该参数用于指定UPF支持TAIRANGE及其关联切片为条件的权重选择功能是否开启。                                        |
| 容量              | 本参数用于指定对端UPF所支持的TAIRANGE及其关联切片为条件的相对权重。特别地，如果权重的绝对值不超过本参数的取值范围，那么本参数可以直接取用权重绝对值。 |
| 绑定的NWDAFINFO ID | 该参数用于指定绑定的PNFNWDAFEVENT记录。                                                       |
