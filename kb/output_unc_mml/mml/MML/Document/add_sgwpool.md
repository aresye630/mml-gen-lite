# 增加SGW POOL（ADD SGWPOOL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C**

该命令用于添加一个新的SGW POOL。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入20条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                |
|:------------|:-----------|:----------------------------------------------------------------------------------------------------|
| SGWPOOLNAME | SGW POOL名称 | 可选必选说明：必选参数  参数含义：该参数用于指定SGW POOL名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。不支持空格，不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

假设用户需要添加一个名为“sgwpool1”的SGW POOL：

```
ADD SGWPOOL:SGWPOOLNAME="sgwpool1";
```
