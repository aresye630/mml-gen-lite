# 修改候选AMF（MOD CANDIDATEAMF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NSSF**

本命令用于修改候选AMF，修改AMF与AMFSET的关联关系。

## 注意事项

- 该命令执行后立即生效。

- 主备或双活组网的场景下，如果需要配置此命令，则两个NSSF上均需执行此命令，且配置参数一致。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                                                |
|:--------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------|
| INDEX         | 索引      | 可选必选说明：必选参数  参数含义：该参数用于描述命令的索引值。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无                                            |
| AMFINSTANCEID | AMF实例标识 | 可选必选说明：可选参数  参数含义：该参数用于描述全局唯一的AMF标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~255。该参数只能由字母（A-Z或者a-z）、数字（0-9）、中划线（-）组成，不区分大小写。  默认值：无  配置原则：无 |
| MCC           | 移动国家码   | 可选必选说明：可选参数  参数含义：该参数用于描述移动国家码。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。3位十进制数。  默认值：无  配置原则：  该参数需要与ADD AMFSETID命令中MCC参数配置保持一致。              |
| MNC           | 移动网号    | 可选必选说明：可选参数  参数含义：该参数用于描述移动网号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。2位或者3位十进制数。  默认值：无  配置原则：  该参数需要与ADD AMFSETID命令中MNC参数配置保持一致。       |
| REGIONID      | 区域ID    | 可选必选说明：可选参数  参数含义：该参数用于描述AMF区域ID。  数据来源：全网规划  取值范围：字符串类型，输入长度是2。按照十六进制输入，输入时不带0x，不足两位时需手动从左边补0，取值范围00~ff。  默认值：无  配置原则：无            |
| AMFSETID      | AMF集合标识 | 可选必选说明：可选参数  参数含义：该参数用于描述AMF集合的标识。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。按照十六进制输入，输入时不带0x，不足三位时需手动从左边补0，取值范围000~3ff。  默认值：无  配置原则：无         |

## 使用实例

假如运营商希望将已有的INDEX为1记录修改为AMFINSTANCEID为"AMF01"、MCC为"460"、MNC为"03"、REGIONID为"01"、AMFSETID为"001"，执行下列命令。

```
MOD CANDIDATEAMF: INDEX=1, AMFINSTANCEID="AMF01", MCC="460", MNC="03", REGIONID="01", AMFSETID="001";
```
