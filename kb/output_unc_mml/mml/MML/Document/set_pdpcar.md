#### 命令功能

**适用网元：SGSN**

该命令用于设置PDP上下文的流控参数。PDP流控包括上行数据流控和下行数据流控。

#### 注意事项

- 系统初次运行时，会执行系统初始设置值。
- 动态修改该命令的“PDP流控倍数”、“PDP突发系数”只对以后创建的PDP上下文有效，对原来已存在的PDP上下文无效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                                                                                                                                                                                    |
|:-----------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PDPSWITCH  | PDP流控开关 | 可选必选说明：可选参数 参数含义：该参数用来表示PDP流控控制开关。 数据来源：本端规划 取值范围：“OFF(关)”“ON(开)” 系统初始设置值：“ON(开)”。 配置原则：如果开关关闭，不进行PDP流控，即单用户不会限制上下行带宽。如果开关打开，单用户会按照协商带宽进行流控。动态修改该命令的“PDP流控开关”参数，对所有PDP上下文立即生效。                                                                          |
| PDPMULTI   | PDP流控倍数 | 可选必选说明：条件可选参数 参数含义：该参数用来表示PDP流控实际使用的带宽相对协商带宽的倍数。将QoS协商后的最大带宽乘以“PDP流控倍数”即可得到PDP流控实际使用的最大带宽。“PDP流控倍数”越大，则PDP流控实际使用的最大带宽越大。 前提条件：该参数在“PDP流控开关”参数设置为“ON(开)”时，需要配置。 数据来源：本端规划 取值范围：1~127 系统初始设置值：“1”。 配置原则：PDP流控一般按照用户QoS协商后的最大带宽来进行，不建议放大其最大带宽，所以系统初始值为“1”。 |
| BURSTTIMES | PDP突发系数 | 可选必选说明：可选参数 参数含义：该参数用来表示PDP流控时对突发速率的容忍度。“PDP突发系数”越大，对于突发速率的容忍度越高。 数据来源：本端规划 取值范围：1~64 系统初始设置值：“9”。 配置原则：该参数为系统参数，如果设置过大，当大量用户同一时间段内均有较大突发流量时，会造成系统带宽拥塞。根据当前系统转发能力，设置初始值为“9”。                                                                            |

#### 使用实例

设置PDP流量控制参数，打开PDP流控控制开关，其他参数选默认值:

SET PDPCAR: PDPSWITCH=ON, PDPMULTI=1, BURSTTIMES=9;
