# 删除N40去活原因的映射关系（RMV N40DIAGTRIGGER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于删除用户去活时内部诊断字段取值到去活原因的映射关系。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                        |
|:------------|:-------|:--------------------------------------------------------------------------------------------|
| DIAGNOSTICS | 诊断原因值  | 可选必选说明：必选参数  参数含义：该参数用于指定SMF内部的去活诊断字段原因值。  数据来源：本端规划  取值范围：整数类型，取值范围是0~1000。  默认值：无  配置原则：无 |

## 使用实例

删除内部诊断字段取值为259时的映射关系

```
RMV N40DIAGTRIGGER: DIAGNOSTICS =259;
```
