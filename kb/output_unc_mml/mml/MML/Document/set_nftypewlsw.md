# 设置NF类型白名单开关（SET NFTYPEWLSW）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令与ADD NFTYPEWHITELIST配合使用，在白名单未设置完成时请勿打开此开关，否则未加入到白名单中的NF类型将无法正常注册、去注册、更新及维持到NRF的心跳功能。

**适用NF：NRF**

该命令用于设置NF类型白名单功能开关，用于避免新升级NRF未经功能验证完善后就接入业务，导致错误业务导流。

该命令与NF白名单命令ADD NFTYPEWHITELIST配合使用，在白名单未设置完成时请勿打开此开关，否则影响未加入到白名单中NF类型的正常注册、去注册、更新及心跳功能。

## 注意事项

- 该命令执行后立即生效。

- 主备或双活组网的场景下，如果需要配置此命令，则两个NRF上均需配置且配置参数一致。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| NFTYPEWLSW   |
|:-------------|
| FUNC_OFF     |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                       |
|:-----------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFTYPEWLSW | NF类型白名单开关 | 可选必选说明：可选参数  参数含义：该参数用于表示NF类型白名单功能是否打开。开关设置为“FUNC_ON”，NRF将对白名单内外的NF类型做区别处理，正常处理配置的白名单内NF类型的注册、去注册、更新及心跳业务；不在白名单内的NF上述业务将不能被处理。开关设置为“FUNC_OFF”，NRF不对白名单内外NF类型区别处理，正常处理所有NF的注册、去注册、更新及心跳业务。  数据来源：本端规划 取值范围： “FUNC_ON（打开）”：功能开关打开“FUNC_OFF（关闭）”：功能开关关闭  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST NFTYPEWLSW查询当前参数配置值。  配置原则：无 |

## 使用实例

运营商希望对NF的注册、去注册、更新及心跳进行有效控制。开关打开，NRF将使用设置的NF类型白名单对NF的注册、去注册、更新及心跳进行控制，未在白名单内的NF将无法正常注册、去注册、更新以及维持到NRF的心跳。

```
SET NFTYPEWLSW: NFTYPEWLSW=FUNC_ON;
```
