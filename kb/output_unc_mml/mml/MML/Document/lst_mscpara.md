#### 命令功能

**适用网元：MME**

此命令用于查询MSC IP地址和MSC-Number之间的映射关系。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                                                                                                                                                                                         |
|:-------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPTYPE | IP地址类型     | 可选必选说明：可选参数 参数含义：该参数用于指定MSC IP地址类型。 数据来源：全网规划 取值范围：IPV4(IPv4)IPV6(IPv6) 默认值：无                                                                                                                                                                                |
| IPV4   | MSC IPv4地址 | 可选必选说明：条件可选参数 前提条件：该参数在“IP地址类型”参数配置为“IPv4”后生效。 参数含义：该参数用于指定MSC的IPv4地址。 数据来源：全网规划 取值范围：0.0.0.1～255.255.255.254。 默认值：无 配置原则：IPv4地址不能为环回地址（127.x.y.z）。IPv4地址必须是A、B或者C类地址。                                                                                       |
| IPV6   | MSC IPv6地址 | 可选必选说明：条件可选参数 前提条件：该参数在“IP地址类型”参数配置为“IPv6”后生效。 参数含义：该参数用于指定MSC的IPv6地址。 数据来源：全网规划 取值范围：::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。 默认值：无 配置原则：IPv6地址必须是全球单播地址，不能为未指定地址（::）、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址（::1）、链路本地地址（FE80::/10）和组播地址（FF00::/8） |

#### 使用实例

查询“MSC IPv4地址”为“10.141.149.100”的MSC的MSC参数：

`LST MSCPARA: IPTYPE=IPV4, IPV4="10.141.149.100";`

```
%%LST MSCPARA: IPTYPE=IPV4, IPV4="10.141.149.100";%%
RETCODE = 0  操作成功

操作结果如下
--------------
MSC IPv4地址  =  10.141.149.100
  MSC-Number  =  123456789
        描述  =  noname
(结果个数 = 1)

---    END
```
