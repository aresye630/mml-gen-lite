# 设置服务化接口热备接管流控参数（SET SBITAKEOVERFC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

存在较大操作风险，执行不当会导致业务受损或中断。

**适用NF：AMF**

该命令用于设置服务化接口热备接管流控参数。在热备特性开启的场景下，使用本命令可以开启热备接管流控功能，防止对周边网元造成冲击。

## 注意事项

- 该命令执行后立即生效。

- 当本命令“服务化接口名称”参数为“N8接口”的记录中“流控功能开关”参数设置为“开启”时，软参DWORD62功能不生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| SBIITF   | FCSWITCH   | FCSCOPE   |   FCTHD |   STARTALMTIMES |
|:---------|:-----------|:----------|--------:|----------------:|
| N8       | OFF        | POD       |     100 |               3 |
| N11      | OFF        | POD       |     300 |               3 |
| N15AM    | OFF        | POD       |     300 |               3 |
| N15UE    | OFF        | POD       |     300 |               3 |
| N20      | OFF        | POD       |     300 |               3 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称          | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
|:--------------|:--------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SBIITF        | 服务化接口名称       | 可选必选说明：必选参数  参数含义：该参数表示热备接管场景进行流控的服务化接口名称。  数据来源：全网规划 取值范围： “N8（N8接口）”：AMF和UDM之间的服务化接口。“N11（N11接口）”：AMF和SMF之间的服务化接口。“N15AM（N15 AM策略接口）”：AMF和AM策略所属PCF之间的服务化接口。“N15UE（N15 UE策略接口）”：AMF和UE策略所属PCF之间的服务化接口。“N20（N20接口）”：AMF和SMSF之间的服务化接口。  默认值：无。  配置原则：  N11、N15AM、N15UE、N20接口为参数预留取值，功能暂未实现。  AMF向UDM热备接管一次会发送四条消息（Nudm_UECM_RegistrationAMF3GppAccess Request、Nudm_SDM_GetMultipleDataSets Request、Nudm_SDM_Unsubscribe Request、Nudm_SDM_SubscribeCreate Request）。  AMF向SMF热备接管，每个会话会发送一条消息（Nsmf_PDUSession_UpdateSmContext）。  AMF向SMSF热备接管一次会发送一条消息（Nsmsf_SMService_Activate）。  AMF向PCF热备接管，AM策略和UE策略各会发送一条消息（Npcf_AMPolicyControl_Create、Npcf_UEPolicyControl_Create）。 |
| FCSWITCH      | 流控功能开关        | 可选必选说明：可选参数  参数含义：该参数用于控制是否开启服务化接口热备接管流控功能。  数据来源：全网规划 取值范围： “OFF（关闭）”：关闭“ON（打开）”：打开  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST SBITAKEOVERFC查询当前参数配置值。  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| FCSCOPE       | 流控阈值作用范围      | 可选必选说明：该参数在"FCSWITCH"配置为"ON"时为条件必选参数。  参数含义：该参数用于设置消息流控阈值的作用范围。  数据来源：全网规划 取值范围： “POD（单POD）”：单POD每秒钟可以通过的指定热备接管次数。“SYSTEM（整系统）”：整系统每秒钟可以通过的指定热备接管次数。每个POD独立进行流控，整系统的流控阈值除以POD个数作为每个POD的流控阈值。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST SBITAKEOVERFC查询当前参数配置值。  配置原则：  建议配置为“SYSTEM（整系统）”，AMF扩缩容场景下可以保持整系统对后端的流控能力保持不变。                                                                                                                                                                                                                                                                                                                                                   |
| FCTHD         | 接管次数速率门限(次/秒) | 可选必选说明：该参数在"FCSWITCH"配置为"ON"时为条件必选参数。  参数含义：该参数用于设置服务化接口接管次数速率门限。  数据来源：全网规划  取值范围：整数类型，取值范围是0~640000。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST SBITAKEOVERFC查询当前参数配置值。  配置原则：  当参数“FCSCOPE”取值为“POD（单POD）”时，本参数的取值范围为0-10000。  当参数“FCSCOPE”取值为“SYSTEM（整系统）”时，本参数的取值范围为0-640000。                                                                                                                                                                                                                                                                                                                                                                                          |
| STARTALMTIMES | 告警上报周期数       | 可选必选说明：可选参数  参数含义：该参数用于设置连续几个5秒周期处于流控态上报“ALM-100793 SBI服务化接口热备接管固定速率流控起控”告警。  数据来源：本端规划  取值范围：整数类型，取值范围是0~255。如果值为0，则因流控而导致丢包后立即上报告警。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST SBITAKEOVERFC查询当前参数配置值。  配置原则：  该参数设置过低，可能由于突发业务导致热备接管而触发“ALM-100793 SBI服务化接口热备接管固定速率流控起控”，设置过高，会导致长时间流控但不上报告警。                                                                                                                                                                                                                                                                                                                                                                           |

## 使用实例

设置AMF N8接口接管速率门限为100个/秒，按单POD粒度进行阈值控制：

```
SET SBITAKEOVERFC:SBIITF=N8,FCSWITCH=ON,FCSCOPE=POD,FCTHD=100;
```
