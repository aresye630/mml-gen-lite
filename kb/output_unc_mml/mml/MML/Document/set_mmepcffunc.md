# 设置PCF策略功能（SET MMEPCFFUNC）

- 命令功能
- 注意事项
- 本地用户权限
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MME**

本命令用于设置PCF策略功能。

#### 注意事项

- 该命令执行后立即生效。
- 当运营商希望配置的缺省NI（Network Identity）不对所有UE下发，而是通过用户特征（如是否签约特定APN）决策是否向UE下发，需要通过SET DFTNIPLCY配置缺省NI策略。

#### 本地用户权限

manage-ug；system-ug

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称            | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                   |

| FULLNAME      | 运营商全称           | 可选必选说明：条件可选参数。 参数含义：该参数用于指定移动网络运营商的全称。 前提条件：该参数在“是否开启动态NI功能”参数配置为“YES”后生效。 数据来源：全网规划 取值范围：0～79位字符串。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、"!"、"&"、空格符以及中文字符，其他均为非法字符。 默认值：无。 说明：  说明： PCF取消动态NI场景下，当配置本参数时，优先使用该参数填充EMM information消息中携带的“Full name for network”信元值；当未配置本参数时，信元取值优先级如下：ADD AREAMMINFO>ADD USRMMINFO>ADD MVNO或ADD MNO。 因终端实现不同，可能部分终端优先使用SIM/USIM卡自带的网络名称，此时网络侧下发的网络名称会不生效。 输入单空格将删除该参数已有配置项。  |
| SHORTNAME     | 运营商简称           | 可选必选说明：条件可选参数。 参数含义：该参数用于指定移动网络运营商的全称。 前提条件：该参数在“是否开启动态NI功能”参数配置为“YES”后生效。 数据来源：全网规划 取值范围：0～79位字符串。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、"!"、"&"、空格符以及中文字符，其他均为非法字符。 默认值：无。 说明：  说明： PCF取消动态NI场景下，当配置本参数时，优先使用该参数填充EMM information消息中携带的“Short name for network”信元值；当未配置本参数时，信元取值优先级如下：ADD AREAMMINFO>ADD USRMMINFO>ADD MVNO或ADD MNO。 因终端实现不同，可能部分终端优先使用SIM/USIM卡自带的网络名称，此时网络侧下发的网络名称会不生效。 输入单空格将删除该参数已有配置项。 |
| DYNRFSPSW     | 灵活选频功能开关        | 可选必选说明：条件可选参数 参数含义：该参数用于设置是否开启灵活选频功能。 前提条件：该参数在“是否开启AM策略功能”参数配置为“YES”后生效。 数据来源：全网规划 取值范围： “NO（否）”：否 “YES（是）”：是 默认值：NO（否） 配置原则：  说明： 该参数为预留参数。                                                                                                                                                                                                                                                                          |
| RFSPCLRMODE   | RFSP清除方式        | 可选必选说明：条件可选参数。 参数含义：该参数用于设置清除PCF签约RFSP方式。 前提条件：该参数在“灵活选频功能开关”参数配置为“YES”后生效。 数据来源：全网规划 取值范围： WITHOUT_RFSP（未携带RFSP） WITH_NULL（携带RFSP为null） 默认值：“WITH_NULL（携带RFSP为null）” 配置原则：无  说明： 该参数为预留参数。                                                                                                                                                                                                                            |
| RFSPPAGINGPLY | RFSP Paging发起策略 | 可选必选说明：条件可选参数。 参数含义：该参数用于控制灵活选频功能功能开启后，特定场景下是否对空闲态用户发起寻呼。 前提条件：该参数在“灵活选频功能开关”参数配置为“YES”后生效。 数据来源：全网规划 取值范围： “HSSAPNCHG（HSSAPNCHG）”：当HSS签约APN变更触发的创建N15策略发生变化时发起寻呼“AMPCFRFSPCHG（AMPCFRFSPCHG）”：当AM-PCF签约RFSP变更时发起寻呼 默认值：全部清空。 配置原则： 全部清空时（全部不勾选），不对空闲态用户发起寻呼  说明： 该参数为预留参数。                                                                                                                                             |
| DFTRFSP       | 默认RFSP          | 可选必选说明：条件可选参数。 参数含义：该参数用于设置PCF签约的RFSP被清除后，MME给基站下发的RFSP。 前提条件：该参数在“灵活选频功能开关”参数配置为“YES”后生效。 数据来源：全网规划 取值范围：整数类型，取值范围是0~256。 默认值：0 配置原则： HSS签约数据或者ADD RFSP配置的RFSP决策结果优先该参数配置。 取0时，该参数是无效值。 1~128为运营商自定义值。 129~256为协议(3GPP TS 36.300)指定值，其中256表示的优先级从高到低为：E-UTRAN，UTRAN，GERAN。255表示的优先级从高到低为：UTRAN，GERAN，E-UTRAN。254表示的优先级从高到低为：GERAN，UTRAN，E-UTRAN。  说明： 该参数为预留参数。                                                       |

#### 使用实例

设置PCF策略功能，开启AM策略功能，开启动态NI功能，NIPAGINGPLY设置为AMPCFNICHG，运营商全称设置为huawei123，运营商简称设置为hw123，灵活选频功能开关设置为YES，RFSP清除方式设置为WITHOUT\_RFSP，RFSPPAGINGPLY设置为AMPCFRFSPCHG，默认RFSP设置为1：

```
SET MMEPCFFUNC: AMSW=YES, DYNNISW=YES, NIPAGINGPLY=AMPCFNICHG-1&HSSAPNCHG-0, FULLNAME="huawei123", SHORTNAME="hw123", DYNRFSPSW=YES, RFSPCLRMODE=WITHOUT_RFSP, RFSPPAGINGPLY=AMPCFRFSPCHG-1&HSSAPNCHG-0, DFTRFSP=1;
```
