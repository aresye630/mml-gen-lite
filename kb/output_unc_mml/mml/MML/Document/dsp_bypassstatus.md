# 查询BYPASS状态（DSP BYPASSSTATUS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**须知** 

该功能仅支持华为虚拟化层软件FusionSphere，不支持第三方虚拟化层软件。

本命令用于查询节点当前的BYPASS状态。

若需要查询指定节点的BYPASS状态，需要输入“网元ID”和“节点名称”参数。

**说明** 

该命令仅在Full-stack虚机场景下支持。

#### 注意事项

无。

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                 |
|:---------|:-------|:---------------------------------------------------------------------------------------------------------------------|
| APPID    | 网元ID   | 可选必选说明：必选参数。 参数含义：用于指示系统需要查询指定网元ID下的节点BYPASS状态。 取值范围：0～65535。 默认值：无。 配置原则：“网元ID”获取方式为：点击“首页”，查看“应用ID”即可。             |
| NODENAME | 节点名称   | 可选必选说明：可选参数 参数含义：用于指示系统需要查询哪个节点的BYPASS状态。 取值范围：不超过128位字符串。 默认值：无。 配置原则：若不输入，则表示查询所有节点的信息。 用户可以通过DSP NODE命令查看相应的节点名称。 |

#### 使用实例

1. 查询“网元ID”为“0”的所有节点BYPASS状态：

   ```
   %%DSP BYPASSSTATUS: APPID=0;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   网元ID  节点IP           节点名称         查询状态      手工进入BYPASS      节点BYPASS状态      详细信息
   0       10.0.0.1         10.0.0.1         Success       No                  Normal              Success             
   0       10.0.0.2         10.0.0.2         Success       No                  Normal              Success  
   0       10.0.0.3         10.0.0.3         Success       No                  Normal              Success             
   (结果个数 = 3)

   ---    END
   ```
2. 查询“网元ID”为“0”，“节点名称”为“10.0.0.1”的节点BYPASS状态：

   ```
   %%DSP BYPASSSTATUS: APPID=0, NODENAME="10.0.0.1";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
               网元ID  =  0
               节点IP  =  10.0.0.1
             节点名称  =  10.0.0.1
             查询状态  =  Success
       手工进入BYPASS  =  Yes
       节点BYPASS状态  =  Bypass
             详细信息  =  Success
   (结果个数 = 1)

   ---    END
   ```

#### 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。输出结果说明如表1所示。

命令执行异常，会返回提示对应的失败信息。错误码列表如表2所示。

| 输出项名称      | 输出项解释                                                                                                                                           |
|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------|
| 网元ID       | 用于返回查询网元的ID。                                                                                                                                    |
| 节点IP       | 用于返回查询节点的IP地址。                                                                                                                                  |
| 节点名称       | 用于返回查询的节点名称。                                                                                                                                    |
| 查询状态       | 用于返回本节点查询是否成功。 取值范围： “Success”：用于返回当前节点查询状态成功。“Failed”：用于返回当前节点查询状态失败。“Bypass mode is not active”：用于返回当前节点查询状态为未激活Bypass模式。                     |
| 手工进入BYPASS | 用于返回查询的节点的手动设置BYPASS的操作状态。 取值范围： “No”：用于表示返回节点未设置手动进入Bypass。“Yes”：用于表示返回节点已设置手动进入Bypass。“Unknown”：用于返回当前节点的Bypass状态为“Unknown”状态。                |
| 节点BYPASS状态 | 用于返回查询的节点当前所处的BYPASS状态。 取值范围： “Normal”：用于返回当前节点的Bypass状态为非Bypass状态。“Bypass”：用于返回当前节点的Bypass状态为Bypass状态。“Unknown”：用于返回当前节点的Bypass状态为“Unknown”状态。 |
| 详细信息       | 用于返回成功和失败的详细信息。 取值范围： “Success”：用于返回当前节点查询详细信息结果成功。“同步到NRSAgent失败”：用于返回当前节点查询详细信息结果失败。“节点BYPASS模式未激活，命令无效”：用于返回当前节点查询详细信息结果为未激活Bypass模式。        |

|    错误码 | 错误码解释     | 原因分析                          | 处理建议                                            |
|-------:|:----------|:------------------------------|:------------------------------------------------|
| 130001 | 没有符合条件的节点 | 所要查询的节点或者网元ID不存在，无相应BYPASS信息。 | 按照DSP NODE命令查询的所有节点信息，选择确实存在的节点，查询其相应的BYPASS状态。 |
| 130002 | 操作失败      | bypass模式未激活。                  | 请联系华为技术支持。                                      |
| 130004 | 部分成功      | 部分节点接口调用异常或者设置处理异常。           | 请联系华为技术支持。                                      |
| 130009 | 输入参数不合法   | 设置的参数值不在规定范围之内。               | 按照规定的范围进行参数值的设置。                                |
