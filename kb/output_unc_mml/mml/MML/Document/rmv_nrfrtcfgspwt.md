# 删除跨NRF路由配置异常告警白名单记录（RMV NRFRTCFGSPWT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除“ALM-100796 跨NRF服务发现路由相关配置异常”告警的白名单记录。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

删除一条白名单记录，目的NF类型为SMF，路由类型为TAI和DNN，执行如下命令：

```
RMV NRFRTCFGSPWT: TARGETNFTYPE=SMF, RTTYPE=Tai-1&Dnn-1;
```
