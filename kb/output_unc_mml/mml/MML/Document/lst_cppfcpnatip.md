# 查询N4接口地址映射关系（LST CPPFCPNATIP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF、SGW-C、PGW-C**

该命令用于查询N4接口本端CP端点的IP地址和经过信令安全网关映射后的IP地址映射关系。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询所有N4接口本端CP端点的IP地址和经过信令安全网关映射后的IP地址映射关系：
LST CPPFCPNATIP:;

```
%%LST CPPFCPNATIP:;%%
RETCODE = 0  操作成功

结果如下
--------
      本端CP端点IP类型  =  IPv4
    本端CP端点IPV4地址  =  10.1.1.1
    本端CP端点IPV6地址  =  ::
         本端CP端点VPN  =  _public_
    代理UP路径的IP类型  =  IPv4
  代理UP路径的IPV4地址  =  10.2.2.2
  代理UP路径的IPV6地址  =  ::
  CP端点映射后的IP类型  =  IPv4
CP端点映射后的IPV4地址  =  10.1.2.1
CP端点映射后的IPV6地址  =  ::
(结果个数 = 1)

---    END
```
