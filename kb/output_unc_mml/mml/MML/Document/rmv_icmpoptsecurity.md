# 删除ICMP选项安全配置（RMV ICMPOPTSECURITY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除ICMP选项安全配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                  |
|:------------|:---------|:------------------------------------------------------------------------------------------------------|
| RUNAME      | RU名称     | 可选必选说明：必选参数 参数含义：该参数用于指定ICMP选项安全配置的RU名称，通过DSP RU命令可以查询资源单元信息。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 |
| ICMPSECTYPE | ICMP安全类型 | 可选必选说明：必选参数 参数含义：该参数用于指定ICMP选项安全配置的ICMP安全类型。 数据来源：本端规划 取值范围：枚举类型。 TTLEXCEEDED：TTL超时报文。 默认值：无          |

#### 使用实例

删除ICMP选项安全配置：

```
RMV ICMPOPTSECURITY:RUNAME="VNODE_VNRS_VNFC_OMU_0001",ICMPSECTYPE=TTLEXCEEDED;
```
