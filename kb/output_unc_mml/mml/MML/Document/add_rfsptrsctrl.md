# 增加RFSP是否传递控制(ADD RFSPTRSCTRL)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于增加一条RFSP是否传递控制策略。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为128。
- 配置控制对象为N26/S10接口“Forward Relocation Request”和“Context Response”消息中的“RFSP Index in Use”信元。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                       |
|:-----------|:------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RFSP       | RFSP ID     | 可选必选说明：必选参数 参数含义：该参数用于指定RFSP ID。 数据来源：全网规划 取值范围：1~256，65535 默认值：无 配置原则： 1~128为运营商自定义值。129~256为协议(3GPP TS 36.300)指定值，其中256表示的优先级从高到低为：E-UTRAN，UTRAN，GERAN。255表示的优先级从高到低为：UTRAN，GERAN，E-UTRAN。254表示的优先级从高到低为：GERAN，UTRAN，E-UTRAN。65535表示默认配置，对于未配置的RFSP ID，使用此配置值。                                                                                                                                                           |
| EPSSW      | EPS内是否传递    | 可选必选说明：可选参数 参数含义：该参数用于设置在EPS内是否传递指定的RFSP ID。 数据来源：全网规划 取值范围：“NO(否)”“YES(是)” 默认值：“NO(否)” 配置原则： 如果需要在EPS内MME之间传递指定的RFSP，需要将此参数设置为“YES(是)”。                                                                                                                                                                                                                                                                                   |
| EPS5GSSW   | EPS到5GS是否传递 | 可选必选说明：可选参数 参数含义：该参数用于设置在EPS到5GS的流程中是否传递指定的RFSP ID。 数据来源：全网规划 取值范围：“NO(否)”“YES(是)” 默认值：“NO(否)” 配置原则： 如果需要在EPS到5GS流程中传递指定的RFSP，需要将此参数设置为“YES(是)”。                                                                                                                                                                                                                                                                           |
| RFSPUSEDSW | RFSP是否使用    | 可选必选说明：可选参数 参数含义：该参数用于设置新侧MME从N26/S10接口收到老侧AMF/MME在PCF上签约的RFSP之后，是否使用该数据。 数据来源：全网规划 取值范围：“NO(否)”“YES(是)” 默认值：“NO(否)” 配置原则： 当5G系统规划的RFSP和4G系统规划的不一致时，不能开启。  说明： 向4G基站侧传递RFSP ID的决策优先级顺序为：ADD RFSPTRSCTRL配置控制使用N26/S10接口收到的“RFSP Index in Use”信元。SET PCRFPLCY配置控制的灵活选频功能，RFSP来自N26/S10/S11接口的“Private Extension”信元。HSS签约数据或者ADD RFSP配置的RFSP决策结果。ADD RFSPTRSCTRL配置控制RFSP老化后，SET N26RFSPPLCY配置设置的默认RFSP。SET PCRFPLCY配置的默认RFSP。 |
| RFSPAGESW  | RFSP是否老化    | 可选必选说明：可选参数 参数含义：该参数用于设置新侧MME从N26/S10接口收到老侧AMF/MME在PCF上签约的RFSP之后，是否进行老化。 数据来源：全网规划 取值范围：“NO(否)”“YES(是)” 默认值：“NO(否)” 配置原则： 老化时长受SET N26RFSPPLCY控制。                                                                                                                                                                                                                                                                          |

#### 使用实例

对于RFSP ID为1的场景设置传递控制为EPS内不传递、EPS到5GS传递、RFSP使用、RFSP不老化：

ADD RFSPTRSCTRL: RFSP=1, EPSSW=NO, EPS5GSSW=YES, RFSPUSEDSW=YES, RFSPAGESW=NO;
