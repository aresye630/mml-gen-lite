# 设置PAE Channel调度模式（SET PAESCHEDMOD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

如果修改该配置可能会造成业务流量损失。

该命令用于设置PAE Channel调度模式。

#### 注意事项

该命令为高危命令，如果修改该配置可能会造成业务流量损失。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组。

#### 参数说明

| 参数标识      | 参数名称            | 参数说明                                                                                                                                                                                                        |
|:----------|:----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SCHEDMODE | PAE Channel调度模式 | 可选必选说明：必选参数。 参数含义：该参数用于指定PAE Channel调度模式。 数据来源：本端规划。 取值范围：枚举类型。 absolute-priority：绝对优先级模式，按优先级顺序从队列收包，高优先级队列收到报文后结束收包。relative-priority：相对优先级模式，按优先级顺序依次从队列收包，直到批收满或队列遍历完为止。 默认值：absolute-priority。 配置原则：无。 |

#### 使用实例

设置PAE Channel调度模式为绝对优先级：

```
%%SET PAESCHEDMOD: SCHEDMODE=absolute-priority;%%
RETCODE = 0  操作成功

---    END
```
