# 该命令仅用于生成ADD PNFNS和ADD PNFDNN实例（INC PNFNSDNN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、AMF、SMF、NSSF、GGSN、SMSF、NCG、SGW-C、CBC、CBCF**

该命令仅用于生成ADD PNFNS和ADD PNFDNN实例。

## 注意事项

- 该命令执行后立即生效。

- 如果ADD PNFNS、ADD PNFDNN任一记录数达到最大规格，则随后执行INC PNFNSDNN命令不会生成ADD PNFNS、ADD PNFDNN实例。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                                                                                                                      |
|:--------------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCEID  | NF实例标识  | 可选必选说明：必选参数  参数含义：该参数用于指定对端NF实例标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~50。  默认值：无  配置原则：  本参数取值与ADD PNFPROFILE命令中的“NF实例标识”参数取值保持一致时，关联关系生效。本参数长度不能超过38。                                                       |
| SST           | 切片/服务类型 | 可选必选说明：必选参数  参数含义：该参数用于指定对端NF的切片/服务类型。  数据来源：本端规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无                                                                                                                   |
| SD            | 切片分类器   | 可选必选说明：可选参数  参数含义：该参数用于指定对端NF的切片区分码。如果切片需要进一步细化子切片可配置该参数。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~8。  默认值：无  配置原则：  该值若不设置，默认值为FFFFFF。                                                                            |
| DNN           | 数据网络名称  | 可选必选说明：可选参数  参数含义：该参数用于指定对端NF实例支持的数据网络名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~66。  默认值：无  配置原则：无                                                                                                               |
| PRISWITCH     | 优先级功能开关 | 可选必选说明：可选参数  参数含义：该参数用于指定对端UPF实例支持的DNN与其归属切片为条件的优先级选择功能是否启用。  数据来源：本端规划 取值范围： INHERIT（继承）SPECIFIC（指定）  默认值：无  配置原则：无                                                                                      |
| PRIORITY      | 优先级     | 可选必选说明：该参数在"PRISWITCH"配置为"SPECIFIC"时为条件必选参数。  参数含义：本参数用于指定对端UPF实例支持的DNN与其归属切片为条件的优先级。在UPF选择过程的优选阶段中，会按照优先级高低排序待选列表，结合其他优选条件做综合选择。  数据来源：本端规划  取值范围：整数类型，取值范围是0~65535。  默认值：无  配置原则：无                      |
| CAPSWITCH     | 容量功能开关  | 可选必选说明：可选参数  参数含义：该参数用于指定对端UPF实例支持的DNN与其归属切片为条件的权重选择功能是否启用。  数据来源：本端规划 取值范围： INHERIT（继承）SPECIFIC（指定）  默认值：无  配置原则：  当配置的对端网元是UPF，且CAPSWITCH为SPECIFIC时，CAPACITY生效的前提条件是配置UPSELECTFLAG的PRIORITYFLAG为ENABLE。 |
| CAPACITY      | 容量      | 可选必选说明：该参数在"CAPSWITCH"配置为"SPECIFIC"时为条件必选参数。  参数含义：本参数用于指定对端UPF实例支持的DNN与其归属切片为条件的相对权重。特别地，如果NF容量的绝对值不超过本参数的取值范围，那么本参数可以直接取用容量绝对值。  数据来源：本端规划  取值范围：整数类型，取值范围是0~65535。  默认值：无  配置原则：无                      |
| NSDESCRIPTION | 切片描述    | 可选必选说明：可选参数  参数含义：该参数用于指定描述信息。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~50。  默认值：无  配置原则：无                                                                                                                         |

## 使用实例

运营商A需要生成ADD PNFNS和ADD PNFDNN实例，NF实例标识为nf1，切片/服务类型为1。

```
INC PNFNSDNN: NFINSTANCEID="nf1", SST=1;
```
