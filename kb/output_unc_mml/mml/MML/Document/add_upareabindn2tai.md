# 增加UPF服务区名称绑定的5G TAI范围（ADD UPAREABINDN2TAI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于增加UP服务区名称绑定的5G TAI范围。

## 注意事项

- 该命令执行后立即生效。

- 各UPF服务区名称绑定的5G TAI范围不允许出现交集。
- UPF服务区名称绑定的5G TAI范围起始值与结束值的PLMN必须一致。

- 最多可输入16384条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称                   | 参数说明                                                                                                                                                                                                                                          |
|:-----------|:-----------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AREANAME   | UPF服务区名称               | 可选必选说明：必选参数  参数含义：该参数用于标识UPF服务区名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~255。不能为非法字符，只允许输入字母，数字、“_”、“.”，并且开头和结尾只能是数字或者字母，不能出现连续两个“.”。不区分大小写。  默认值：无  配置原则：  该参数取值应与命令LST UPAREA查询结果中的AREANAME保持一致；且该AREANAME在命令LST UPAREA查询结果中对应的AREATYPE取值应为N2TAI。 |
| N2BEGINTAI | UPF服务区名称支持的5GTAI范围的起始值 | 可选必选说明：必选参数  参数含义：该参数用于标识UPF服务区名称支持的5G TAI范围的起始值。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是11~12。后6位为16进制数，其余为10进制数。不区分大小写。  默认值：无  配置原则：  TAI范围的结束值需要不小于TAI范围的开始值，且结束值和开始值长度需相等。                                                                        |
| N2ENDTAI   | UPF服务区名称支持的5GTAI范围的结束值 | 可选必选说明：必选参数  参数含义：该参数用于标识UPF服务区名称支持的5G TAI范围的结束值。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是11~12。后6位为16进制数，其余为10进制数。不区分大小写。  默认值：无  配置原则：  TAI范围的结束值需要不小于TAI范围的开始值，且结束值和开始值长度需相等。                                                                        |

## 使用实例

UPF服务区名称为“UPAREA1”的区域新增绑定5G TAI范围46001000001~46001123456：

```
ADD UPAREABINDN2TAI: AREANAME="UPAREA1", N2BEGINTAI="46001000001", N2ENDTAI="46001123456";
```
