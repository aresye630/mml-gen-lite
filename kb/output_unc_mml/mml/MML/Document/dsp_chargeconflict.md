# 查询计费配置冲突（DSP CHARGECONFLICT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-C、SMF**

命令用来查询当前系统中是否存在与业务有冲突的配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询系统中的计费配置冲突：

```
DSP CHARGECONFLICT:;
```

```
结果如下
------------------------
计费属性 = 0x0800
用户模板名称 = up1
APN名称 = apn2
(结果个数 = 1)

--- END
```

#### 输出结果说明

| 输出项名称   | 输出项解释          |
|:--------|:---------------|
| 计费属性    | 计费属性。          |
| 用户模板名称  | UserProfile名称。 |
| APN名称   | APN名称。         |
