# 删除所有MSISDN用户群成员（RMV MSISDNSUBGPMEMALL）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

本命令用于删除所有MSISDN用户群成员。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                     |
|:------------|:-------|:---------------------------------------------------------|
| SUBID       | 用户群标识  | 可选必选说明：必选参数 参数含义：用户群标识 数据来源：整网规划 取值范围：1~100 默认值：1 配置原则：无 |
| OPTION_TYPE | 操作类型   | 可选必选说明：必选参数 参数含义：操作类型 数据来源：整网规划 取值范围：ALL 默认值：ALL 配置原则：无  |

#### 使用实例

删除所有MSISDN用户群成员。

```
%%RMV MSISDNSUBGPMEMALL: OPTION_TYPE=ALL, SUBID=1;%%
```
