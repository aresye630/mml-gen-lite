# 启动人工恢复已隔离的Pod（STR RCISOLATION）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行前请确认故障已排除，否则可能会导致业务呼损。请谨慎使用。

该命令用于启动模块级KPI异常检测与恢复功能隔离的Pod。

## 注意事项

- 该命令执行后立即生效。

- 当恢复粒度为"Pod粒度"时，执行该命令后需通过**DSP POD**命令查询Pod状态是否为"Running"，是则表示Pod启动成功，否则表示Pod启动失败，需进行重试。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                |
|:--------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------|
| MEID          | 网元标识   | 可选必选说明：可选参数  参数含义：用于选择执行恢复的网元标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~40。  默认值：无  配置原则：无                                                 |
| RCGRANULARITY | 恢复粒度   | 可选必选说明：必选参数  参数含义：用于选择执行恢复的粒度。  数据来源：本端规划 取值范围： POD（POD粒度）MODULE（模块粒度）SERVICE（业务粒度）ALL（恢复所有）  默认值：无  配置原则：无                         |
| RCSCOPE       | 恢复范围   | 可选必选说明：该参数在"RCGRANULARITY"配置为"MODULE"、"POD"、"ALL"时为条件必选参数。  参数含义：用于选择执行恢复的范围。  数据来源：本端规划 取值范围： POD（恢复指定POD）ALL（恢复所有）  默认值：无  配置原则：无 |
| PODNAME       | POD名称  | 可选必选说明：该参数在"RCSCOPE"配置为"POD"时为条件必选参数。  参数含义：用于选择执行指定Pod的Pod Name做恢复处理。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~1024。  默认值：无  配置原则：无         |
| PODTYPE       | POD类型  | 可选必选说明：该参数在"RCGRANULARITY"配置为"SERVICE"时为条件可选参数。  参数含义：该参数用于指定POD类型。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无             |

## 使用实例

启动模块级KPI异常检测与恢复功能隔离的Pod。

```
%%STR RCISOLATION: MEID="0", RCGRANULARITY=ALL, RCSCOPE=ALL;%%
RETCODE = 0  操作成功

---    END
```
