# 增加5G用户允许的ARP列表（ADD SMFALLOWEDARPS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于配置5G用户允许接入的ARP列表。当产品作为V-SMF/I-SMF形态时，通过该配置可以实现QoS管控功能。

## 注意事项

- 命令执行后只对新接入用户生效。

- 最多可输入2048条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                |
|:---------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| QOSINDEX | 用户QOS索引   | 可选必选说明：必选参数  参数含义：该参数表示允许用户接入的ARP列表索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~65535。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                           |
| ARPPL    | ARP的优先级别  | 可选必选说明：可选参数  参数含义：该参数用于指定组成QoS控制的ARP优先级。  数据来源：全网规划  取值范围：本配置采用白名单机制，如果不配本参数，则表示不允许接入。 ARPPL1（ARP优先级别1）ARPPL2（ARP优先级别2	）ARPPL3（ARP优先级别3）ARPPL4（ARP优先级别4）ARPPL5（ARP优先级别5）ARPPL6（ARP优先级别6）ARPPL7（ARP优先级别7）ARPPL8（ARP优先级别8）ARPPL9（ARP优先级别9）ARPPL10（ARP优先级别10）ARPPL11（ARP优先级别11）ARPPL12（ARP优先级别12）ARPPL13（ARP优先级别13）ARPPL14（ARP优先级别14）ARPPL15（ARP优先级别15）  默认值：无  配置原则：无 |
| ARPPCI   | ARP的抢占能力  | 可选必选说明：可选参数  参数含义：该参数用于指定组成QoS控制的ARP抢占能力。  数据来源：全网规划  取值范围：本配置采用白名单机制，如果不配本参数，则表示不允许接入。 NOT_PREEMPT（不抢占）MAY_PREEMPT（抢占）  默认值：无  配置原则：无                                                                                                                                                                                                                              |
| ARPPVI   | ARP的被抢占能力 | 可选必选说明：可选参数  参数含义：该参数用于指定组成QoS控制的ARP被抢占能力。  数据来源：全网规划  取值范围：本配置采用白名单机制，如果不配本参数，则表示不允许接入。 NOT_PREEMPTABLE（不可抢占）PREEMPTABLE（可抢占）  默认值：无  配置原则：无                                                                                                                                                                                                                       |

## 使用实例

如果想增加一条"允许用户接入的ARP列表索引"为1，"ARP的优先级别"为ARPPL1的5G用户允许的ARP列表，执行如下命令:

```
ADD SMFALLOWEDARPS:QOSINDEX=1,ARPPL=ARPPL1-1&ARPPL2-0&ARPPL3-0&ARPPL4-0&ARPPL5-0&ARPPL6-0&ARPPL7-0&ARPPL8-0&ARPPL9-0&ARPPL10-0&ARPPL11-0&ARPPL12-0&ARPPL13-0&ARPPL14-0&ARPPL15-0,ARPPCI=MAY_PREEMPT-1,ARPPVI=NOT_PREEMPTABLE-0&PREEMPTABLE-1;
```
