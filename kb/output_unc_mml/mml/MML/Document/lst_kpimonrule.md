# 查询KPI异常检测规则（LST KPIMONRULE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询KPI异常检测规则。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                     |
|:-----------|:-------|:-----------------------------------------------------------------------------------------|
| METRICTYPE | 指标类型   | 可选必选说明：可选参数  参数含义：该参数用于指定指标类型。  数据来源：本端规划 取值范围： KPI（KPI）  默认值：无  配置原则：无                  |
| METRICID   | 测量指标ID | 可选必选说明：可选参数  参数含义：该参数用于指定测量指标ID。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无 |
| MOIID      | 对象实例ID | 可选必选说明：可选参数  参数含义：该参数用于指定对象实例ID。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无     |

## 使用实例

查询当前配置的所有KPI异常检测规则。

```
%%LST KPIMONRULE:;%%
            RETCODE = 0  操作成功

            结果如下
            --------
            指标类型  测量指标ID  对象实例ID   测量周期  检测算法            同比阈值下限  同比阈值上限  环比阈值下限  环比阈值上限  告警开关

            KPI       2000000001  MOIID_1      5分钟     同比或环比检测生效  80            150           80            150            开启
            KPI       2000000002  MOIID_2      5分钟     同上一周期环比      NULL          NULL          80            150            开启
            KPI       2000000003  MOIID_3      5分钟     7天平均值同比       80            150           NULL          NULL           开启
            (结果个数 = 3)

            ---    END
```
