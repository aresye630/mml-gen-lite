# 删除关口局NF信息（RMV NRFPLMNNF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于删除本NRF管理的关口局NF。

## 注意事项

- 该命令执行后立即生效。

- 当删除关口局NF配置时，漫游场景下该NF将不能被发现。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                            |
|:-------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFTYPE       | NF类型   | 可选必选说明：必选参数  参数含义：该参数用于表示目的NF类型。  数据来源：全网规划 取值范围： NRF（NRF）UDM（UDM）AMF（AMF）SMF（SMF）AUSF（AUSF）NEF（NEF）PCF（PCF）SMSF（SMSF）NSSF（NSSF）UDR（UDR）LMF（LMF）GMLC（GMLC）EIR_5G（EIR_5G）SEPP（SEPP）UPF（UPF）N3IWF（N3IWF）AF（AF）UDSF（UDSF）BSF（BSF）CHF（CHF）NWDAF（NWDAF）CUSTOM_OCS（CUSTOM_OCS）SCP（SCP）  默认值：无  配置原则：无 |
| NFINSTANCEID | NF实例标识 | 可选必选说明：必选参数  参数含义：该参数用于表示本NRF管理的关口局NF实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~36。该参数只能由字母（A-Z或者a-z）、数字（0-9）、中划线（-）、星号（*）组成，不区分大小写。  默认值：无  配置原则：  支持统配ID，通配ID为“*”，表示该NRF下所有的NF均为关口局NF。                                                                                                             |
| NFNAME       | NF名称   | 可选必选说明：可选参数  参数含义：该参数用于表示本NRF管理的关口局NF名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~64。  默认值：无  配置原则：无                                                                                                                                                                                                     |

## 使用实例

使用如下命令删除NF类型为NRF，NF实例标识为123e4567-e89b-12d3-a456-426655440000的关口局信息。

```
RMV NRFPLMNNF: NFTYPE=SMF, NFINSTANCEID="123e4567-e89b-12d3-a456-426655440000";
```
