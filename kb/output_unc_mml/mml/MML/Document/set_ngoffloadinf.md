# 设置5G迁移配置表（SET NGOFFLOADINF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置5G迁移参数。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

|   DRRATE |
|---------:|
|       30 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称           | 参数说明                                                                                                                                                                                                                                                                                                                                                                                       |
|:-------|:---------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DRRATE | 容灾场景迁移速率(千/分钟) | 可选必选说明：可选参数  参数含义：参数含义：该参数仅用于指定容灾倒换场景AMF迁移用户的速率。 注意： 迁移速率的设置需要考虑本AMF，目标AMF、NG-RAN、UDM、PCF等周边NF的负载情况，设置过大，可能导致上述NF过载。由于实现原因，AMF在系统内部分发迁移任务时迁移速率按照向下取整，故存在实际迁移速率略微低于本设置值的可能。实际的最大迁移速度会产生100用户/分钟的误差，即可能会略低于该设置值。如果STR OFFLOADAMF命令执行时指定迁移速率，则以指定的迁移速率为准进行用户迁移。配置参数变更后，下次触发容灾迁移时生效。  数据来源：本端规划  取值范围：整数类型，取值范围是0~500。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST NGOFFLOADINF查询当前参数配置值。  配置原则：无 |

## 使用实例

设置容灾倒换场景AMF迁移用户的速率为400(千/分钟)，执行以下命令：

```
SET NGOFFLOADINF: DRRATE=400;
```
