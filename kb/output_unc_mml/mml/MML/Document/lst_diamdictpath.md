# 查询Diameter字典加载路径（LST DIAMDICTPATH）

- 注意事项

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于查询Diameter字典加载路径。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

当需要查询当前配置的Diameter字典加载路径时：

```
LST DIAMDICTPATH:;
```

```
RETCODE = 0  操作成功

Diameter字典加载路径
--------------------
应用  字典序号  字典加载路径     

Gy    1         EPC标准字典路径  
Gy    2         定制字典路径2    
Gx    1         定制字典路径1    
S6b   1         EPC标准字典路径  
(结果个数 = 4)

---    END
```
