# 设置自定义NF的服务发现策略（SET CUSTNFDISCPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、CBC、CBCF**

该命令用于配置自定义服务发现流程的策略。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| PCSCFPOLICY   |
|:--------------|
| PAIR_ID       |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                             |
|:------------|:------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PCSCFPOLICY | 服务发现PCSCF策略 | 可选必选说明：可选参数  参数含义：该参数用于指定服务发现PCSCF策略。  数据来源：本端规划 取值范围： “PAIR_ID（结对ID）”：当存在多个DC时，一个Group内同一个PCSCF IP只能拥有一个结对ID。“ANTI_AFFINITY（反亲和组）”：亲合组基于DC配置，保证主备PCSCF地址分属于不同DC。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CUSTNFDISCPLCY查询当前参数配置值。  配置原则：  配置为“ANTI_AFFINITY”时，所有ADD PCSCFIP均需要配置AFFINITYGRPID。 |

## 使用实例

添加服务发现对端PCSCF策略：PCSCFPOLICY为ANTI\_AFFINITY。

```
SET CUSTNFDISCPLCY: PCSCFPOLICY=ANTI_AFFINITY;
```
