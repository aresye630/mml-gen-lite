# 查询HTTP性能参数（LST HTTPPERFPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询HTTP性能参数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询HTTP性能参数：

```
%%LST HTTPPERFPARA:;%%
RETCODE = 0  操作成功

结果如下
--------
       HTTP自保流控起控阈值  =  85
HTTP收包线程睡眠时间（微秒） =  100
           批量处理包数阈值  =  16
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称            | 输出项解释                    |
|:-----------------|:-------------------------|
| HTTP自保流控起控阈值     | 该参数用于配置HTTP自保流控起控阈值。     |
| HTTP收包线程睡眠时间（微秒） | 该参数用于配置HTTP收包线程睡眠时间。     |
| 批量处理包数阈值         | 该参数用于配置HTTP进程批量包数处理数量阈值。 |
