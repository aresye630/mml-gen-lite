# 增加AMF小范围CHR上报规则配置（ADD NGSRCHRCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于增加AMF小范围CHR上报规则配置。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入16条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                      |
|:---------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围     | 可选必选说明：必选参数  参数含义：该参数用于指定配置小范围CHR的用户范围。  数据来源：本端规划 取值范围： SPECIFIC_IMSI（指定用户IMSI）  默认值：无  配置原则：无                                           |
| IMSIPRE  | IMSI前缀   | 可选必选说明：该参数在"SUBRANGE"配置为"SPECIFIC_IMSI"时为条件必选参数。  参数含义：该参数用于指定IMSI前缀。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是11~15。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无 |
| TMPLIDX  | 流程控制模板索引 | 可选必选说明：必选参数  参数含义：该参数用于指定CHR上报流程控制模板索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~127。  默认值：无  配置原则：  TMPLIDX参数依赖于ADD NGACCCHRPRCTMPL命令的TMPLIDX参数。     |

## 使用实例

增加IMSI前缀为12303000100，流程控制模板索引为0的小范围CHR上报规则配置，执行如下命令：

```
ADD NGSRCHRCFG: SUBRANGE=SPECIFIC_IMSI, IMSIPRE="12303000100", TMPLIDX=0;
```
