# 查询对端NF允许的PLMN信息（LST PNFALLOWEDPLMN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF、SMF、NSSF、SMSF、NCG、CBC、CBCF**

该命令用于查询对端NF服务支持的允许访问的PLMN。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询对端NF支持的PLMN信息。

```
%%LST PNFALLOWEDPLMN:;%%
RETCODE = 0 操作成功

结果如下
------------------------
  NF实例标识 = smf_instance_0
服务实例标识 = service_instance_0
  移动国家码 = 460
    移动网号 = 01
（结果个数 = 1）

----    END
```

## 输出结果说明

| 输出项名称   | 输出项解释            |
|:--------|:-----------------|
| NF实例标识  | 该参数用于指定对端NF实例标识。 |
| 服务实例标识  | 该参数用于指定对端服务实例标识。 |
| 移动国家码   | 该参数用于指定移动国家码。    |
| 移动网号    | 该参数用于指定移动网号。     |
