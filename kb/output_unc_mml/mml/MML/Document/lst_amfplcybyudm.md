# 查询基于UDM标识控制创建AMF策略（LST AMFPLCYBYUDM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询基于UDM标识控制创建AMF策略。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                     |
|:----------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UDMIDTYPE | UDM标识类型 | 可选必选说明：可选参数  参数含义：该参数用于指定UDM标识类型。  数据来源：全网规划 取值范围： UDMINSTANCEID（UDM实例标识）  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                 |
| UDMINSTID | UDM实例标识 | 可选必选说明：该参数在"UDMIDTYPE"配置为"UDMINSTANCEID"时为条件可选参数。  参数含义：该参数用于指定UDM实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~36。  默认值：无  配置原则：  参数必须满足以下约束规则：1.如果输入为uuid格式（格式例如：a6a61c6f-0d3a-4221-b1da-424eda3ccf67）只能为A-F、a-f、0-9的字符。2.如果输入不为uuid格式，长度不能超过18且不允许输入只包含0-9和“.”的字符串，例如：1.2.3.4、不允许输入只包含十六进制数（A-F、a-f、0-9）和“:”的字符串，例如：1::2、FBFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。3.该参数大小写不敏感。 |

## 使用实例

查询基于UDM标识限制策略控制的配置，执行如下命令：

```
%%LST AMFPLCYBYUDM:;%%
RETCODE = 0  操作成功

结果如下
--------
           UDM标识类型  =  UDM实例标识
           UDM实例标识  =  12345678-1234-1234-1234-123456789123
              匹配策略  =  全匹配
      区域标识起始位置  =  0
      区域标识终止位置  =  0		   
限制创建AM策略偶联开关  =  否
限制发送运营商标识开关  =  否
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称        | 输出项解释                                                                                                            |
|:-------------|:-----------------------------------------------------------------------------------------------------------------|
| UDM标识类型      | 该参数用于指定UDM标识类型。                                                                                                  |
| UDM实例标识      | 该参数用于指定UDM实例标识。                                                                                                  |
| 匹配策略         | 该参数用于指定UDM实例标识的匹配策略。 本参数取值MATCH_RANGE匹配策略为预埋取值，功能暂未实现。                                                           |
| 区域标识起始位置     | 该参数用于指定UDM实例标识的起始字符位置。假设其取值为N,N表示NF Instance ID中node标识中的第N个字符。 当“匹配策略”设置为MATCH_RANGE时，该参数配置才生效。 本参数为预留参数，功能暂未实现。 |
| 区域标识终止位置     | 该参数用于指定UDM实例标识的终止字符位置。假设其取值为N，N表示NF Instance ID中node标识中的第N个字符。 当“匹配策略”设置为MATCH_RANGE时，该参数配置才生效。 本参数为预留参数，功能暂未实现。 |
| 限制创建AM策略偶联开关 | 该参数用于设置是否开启基于用户归属UDM标识限制创建AM策略偶联的功能。                                                                             |
| 限制发送运营商标识开关  | 该参数用于设置是否开启基于UDM标识限制发送运营商标识的功能。                                                                                  |
