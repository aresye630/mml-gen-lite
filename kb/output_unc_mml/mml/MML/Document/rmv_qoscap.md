# 删除Non-GBR承载QoS限制配置(RMV QOSCAP)

- 命令功能

- 本地用户权限
- 网管用户权限

#### 命令功能

**适用网元：MME**

该命令用于删除一条或多条QoS限制配置。

#### 注意事项

- 该命令执行后立即生效。
- 同一网络内，所有MME/SGSN中的QoS限制配置数据应保持一致。
- 当UNC作为MME/SGSN网元时，对应用户群的QoS信息将会被配置中的QoS信息限制。
- 配置记录删除时，如果当前用户正在进行业务流程，配置限制不会实时生效，在当前流程结束后才会生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                    |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RATTYPE  | RAT类型  | 可选必选说明：必选参数 参数含义：该参数用于指定用户的接入类型，系统优先匹配与当前用户所处网络类型相同的配置数据，当相同RAT类型配置中不包含该用户时，再进行“ALL”类型的匹配。 数据来源：整网规划 取值范围：“ALL(ALL)”“GERAN(GERAN)”“UTRAN(UTRAN)”“E-UTRAN(E-UTRAN)”“NB-IoT(NB-IoT)” 默认值：无                                                                |
| SUBRANGE | 用户范围   | 可选必选说明：必选参数 参数含义：该参数用于指定待增加Non-GBR承载QoS限制配置的用户范围。 数据来源：整网规划 取值范围：“ALL_USER(所有用户)”“HOME_USER(本网用户)”“FOREIGN_USER(外网用户)”“IMSI_PREFIX(指定IMSI前缀)” 默认值：无                                                                                                     |
| NOID     | 运营商标识  | 可选必选说明：条件必选参数 参数含义：该参数用于指定运营商标识。 前提条件：该参数必须先由ADD QOSCAP命令定义，才能在此处引用。 数据来源：整网规划 取值范围：0～64，128～254 默认值：无 配置原则：若该参数需要配置为0或128～254之间的值时，须先在ADD MNO中配置取值相同的“MNOID”参数。若该参数需要配置为1～64之间的值时，须先在ADD MVNO中配置取值相同的“MVNOID”参数。                                       |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件必选参数 参数含义：该参数用于系统根据对用户的IMSI进行匹配，从而区分不同的用户群。 前提条件：该参数必须先由ADD QOSCAP命令定义，才能在此处引用。 取值范围：5～15位数字 默认值：无  说明： IMSI前缀取决于需要使用本条QoS限制的IMSI范围。确定IMSI前缀时应遵循最大匹配原则。例如，需要限制所有IMSI号在308010700000000~308010700099999范围内用户的QoS信息，则应配置一条IMSI前缀为“3080107000”的记录。 |

#### 使用实例

删除“RAT类型”为“ALL”，“用户范围”类型为“IMSI\_PREFIX”，“IMSI前缀”为“3080107000”的QoS限制配置。

`RMV QOSCAP: RATTYPE=ALL,SUBRANGE=IMSI_PREFIX,IMSIPRE="3080107000";`
