# 查询安全防攻击CAR规则（LST SECPOLICYCAR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询报文CAR动作规则。

#### 注意事项

- 该命令执行后立即生效。
- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|:----------------|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SECPOLICYID     | 安全策略编号     | 可选必选说明：可选参数 参数含义：策略编号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～30。 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| SECPOLICYTYPE   | 安全策略类型     | 可选必选说明：可选参数 参数含义：安全策略类型。 数据来源：本端规划 取值范围：枚举类型。 Tcpip：TCP/IP策略。WhiteList：白名单策略。BlackList：黑名单策略。Index：索引策略。UserFlow：用户自定义流策略。Protocol：协议策略。WhiteListV6：IPv6白名单。 默认值：无                                                                                                                                                                                                                                                                                                                                                            |
| SECPOLICYTYPEID | 安全策略类型编号   | 可选必选说明：可选参数 参数含义：安全策略类型编号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| SUBPROTOTYPE    | 安全协议类型     | 可选必选说明：条件可选参数 前提条件：该参数在“SECPOLICYTYPE”配置为“Protocol”时为可选参数。 参数含义：协议类型。 数据来源：本端规划 取值范围：枚举类型。 bfd：BFD协议。bgp：BGP协议。icmp：ICMP协议。ldp：LDP协议。ospf：OSPF协议。arp：ARP协议。arp-miss：ARP-MISS消息。gre：GRE协议。ssh_server：SSH服务器。ssh_client：SSH客户端。dhcp：DHCP协议。dhcpv6：DHCPv6协议。pim：PIM协议。igmp：IGMP协议。ipv4-reserved-mc：IPv4默认保留组播报文。ipv6-too-big：IPv6超大报文。ipv4-mc-fib-miss：IPv4组播转发表项MISS协议。bgpv6：BGPv6报文。icmpv6：ICMPv6协议。ospfv3：OSPFv3报文。na：NA报文。ns：NS报文。ra：RA报文。rs：RS报文。mld：MLD报文。ipv6-nd-miss：IPv6 ND-MISS消息。ipv6-ndh-miss：IPv6 NDH-MISS消息。 默认值：无 |
| SUBTCPIPTYPE    | 安全TCP/IP类型 | 可选必选说明：条件可选参数 前提条件：该参数在“SECPOLICYTYPE”配置为“Tcpip”时为可选参数。 参数含义：TCP/IP防攻击类型。 数据来源：本端规划 取值范围：枚举类型。 TCPSYN：TCPSYN报文。FRAGMENT：分片报文。 默认值：无                                                                                                                                                                                                                                                                                                                                                                                           |

#### 使用实例

- 查询所有CAR规则：

  ```
  LST SECPOLICYCAR:;
  ```

  ```
  RETCODE = 0  操作成功

  结果如下
  -------------------------
  安全策略编号    安全策略类型      安全策略承诺信息速率      安全策略承诺突发尺寸      安全最小包补偿长度      安全协议类型      安全TCP/IP类型

  1               TCP/IP策略        2333                      9000000                   128                     OSPF协议         分片报文  
  1               黑名单策略        2333                      1000                      128                     OSPF协议           分片报文
  (结果个数 = 2)
  ---    END
  ```
- 查询TCP/IP的CAR规则：

  ```
  LST SECPOLICYCAR:SECPOLICYTYPE=Tcpip,SUBTCPIPTYPE=TCPSYN;
  ```

  ```
  RETCODE = 0  操作成功

  结果如下
  -------------------------
          安全策略编号  =  1
          安全策略类型  =  TCP/IP策略
  安全策略承诺信息速率  =  2333
  安全策略承诺突发尺寸  =  9000000
    安全最小包补偿长度  =  128
          安全协议类型  =  OSPF协议
         安全TCP/IP类型 =  TCPSYN报文
  (结果个数 = 1)
  ---    END
  ```
