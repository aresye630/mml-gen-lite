# 查询用户面PDP规格表(LST USRPDPCAP)

- 命令功能

#### 命令功能

**适用网元：SGSN**

该命令用于查询GTP用户面PDP规格表。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询用户面PDP规格表：

LST USRPDPCAP:;

```
%%LST USRPDPCAP:;%%
RETCODE = 0  执行成功。

输出结果如下
-------------------
      PDP数过载门限(%) = 85             
  PDP数过载恢复门限(%) = 80
      PDP数拥塞门限(%) = 95
  PDP数拥塞恢复门限(%) = 90

---    END
```

#### 输出结果说明

请参考命令**SET USRPDPCAP**的参数标识。
