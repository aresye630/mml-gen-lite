#### 命令功能

**适用网元：MME**

该命令用于基于运营商修改LCS扩展参数。

#### 注意事项

- 该命令执行后立即生效。
- 此配置涉及位置定位服务（LCS）特性（特性编号：WSFD-106401，license部件编码：LKV2LCS02）、VoLTE紧急呼叫特性（特性编号：WSFD-106401，license部件编码：LKV2VLEC01）和VoLTE紧急呼叫的定位（NI-LR）特性（特性编号：WSFD-102102，license部件编码：LKV2NVEC01），请在设置参数前使用**DSP LICENSE**命令确认对应特性license是否得到授权，执行**LST LICENSESWITCH**命令确认特性开关状态为“ENABLE(打开)”。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称                | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
|:----------------|:--------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NOID            | 运营商标识               | 可选必选说明：必选参数 参数含义：该参数用于指定运营商标识。 数据来源：整网规划 取值范围：0~64,128~254 默认值：无                                                                                                                                                                                                                                                                                                                                                                                         |
| NILRSWITCH      | 紧急呼叫NI-LR支持开关       | 可选必选说明：可选参数 参数含义：该参数用于控制紧急呼叫流程是否发起NI-LR流程。 数据来源：整网规划 默认值：无 取值范围： OFF（关）：表示紧急呼叫流程不发起NI-LR流程。ON（开）：表示紧急呼叫流程发起NI-LR流程。  说明： 该参数与VoLTE紧急呼叫特性license和VoLTE紧急呼叫的定位（NI-LR）特性license共同完成紧急呼叫NI-LR功能的开启。                                                                                                                                                                                                                                                          |
| GMLCGRPID       | GMLC选择策略组索引         | 可选必选说明：可选参数 参数含义：该参数用于在系统范围内标识一个GMLC选择策略组。 前提条件：该参数在"紧急呼叫NI-LR支持开关"参数配置为"开"后生效。 数据来源：本端规划 取值范围：0~191 默认值：无 配置原则： 该参数需要在ADD GMLCSELGRP中事先配置，可执行LST GMLCSELGRP进行查看。同一GMLC选择策略组索引只能被ADD LCSPARAEX引用一次。                                                                                                                                                                                                                                                      |
| RPTTYPE         | 上报类型                | 可选必选说明：条件可选参数 参数含义：该参数用于配置紧急呼叫场景触发NI-LR流程的上报方式。 前提条件：该参数在"紧急呼叫NI-LR支持开关"参数配置为"开"后生效。 数据来源：整网规划 取值范围： IMMEDIATELY（立刻上报）：当MME识别出紧急呼叫时，立刻发送Subscriber Location Report消息给GMLC，消息中的定位信息只有ECGI。LOCATE（定位上报）：当MME识别出紧急呼叫时，MME获取E-SMLC的定位信息后再上报给GMLC。 默认值：无 配置原则：无卡用户MT-LR流程中，LRF/GMLC选择MME依赖于NI-LR流程中上报的信息。如果在做MT-LR时，LRF/GMLC还没收到NI-LR流程的上报信息，则会导致MT-LR流程失败。所以当网络中定位时延较大时，建议勾选"立刻上报"。  说明： 当同时勾选“立即上报”和“定位上报”时，NI-LR流程中可能会给GMLC发送两次Subscriber Location Report。 |
| SPTDFTBRCALL    | 是否支持缺省承载呼叫          | 可选必选说明：条件可选参数 参数含义：该参数表示网络中是否支持使用缺省承载进行紧急呼叫。 前提条件：该参数在"紧急呼叫NI-LR支持开关"参数配置为"开"后生效。 数据来源：整网规划 取值范围： NO（不支持）YES（支持） 默认值：无 配置原则：紧急专有承载创建失败时，如果网络侧允许使用紧急缺省承载进行通话，将本参数设置为YES（支持）。                                                                                                                                                                                                                                                                              |
| CRTBRTMINTERVAL | 创建承载时间间隔（秒）         | 可选必选说明：条件可选参数 参数含义：该参数表示紧急缺省承载和紧急专有承载创建的最大时间间隔。如果紧急附着或者PDN连接建立流程创建紧急缺省承载后，网络侧在该时间间隔内没有发起紧急专有承载创建，则认为使用了紧急缺省承载通话。 前提条件：该参数在"是否支持缺省承载呼叫"参数配置为"支持"后生效。 数据来源：整网规划 取值范围：2~15 默认值：无 配置原则：根据系统中紧急呼叫流程，紧急专有承载和紧急缺省承载创建的实测的时间间隔来配置。                                                                                                                                                                                                                               |
| RLSRPT          | 紧急呼叫释放是否触发上报        | 可选必选说明：条件可选参数 参数含义：该参数用于控制紧急呼叫释放场景是否触发NI-LR上报。 前提条件：该参数在"紧急呼叫NI-LR支持开关"参数配置为"开"后生效。 数据来源：整网规划 默认值：无 取值范围： NO（否）：紧急呼叫释放场景不触发NI-LR流程。YES（是）：急呼叫释放场景触发NI-LR流程。  说明： 缺省承载通话场景，呼叫释放MME无法识别，本参数只对专有承载通话释放场景生效。                                                                                                                                                                                                                                                 |
| HORPTTYPE       | HO上报类型              | 可选必选说明：条件可选参数 参数含义：该参数用于控制由Handover/SRVCC/TAU流程触发NI-LR流程时，由源侧MME还是目标侧MME/MSC上报定位信息。 前提条件：该参数在"紧急呼叫NI-LR支持开关"参数配置为"开"后生效。 数据来源：整网规划 取值范围： SOURCE（源侧上报）：由源侧MME上报。TARGET（目标侧上报）：由目标侧MME/MSC上报。 默认值：无 配置原则： 协议规定源侧或者目标侧只能有一侧进行上报，该参数在整网MME/MSC中需要配置一致。若用户Handover/TAU/SRVCC到新侧，目标MME/MSC不能识别并触发紧急呼叫NI-LR，则配置成SOURCE（由源侧上报）。当此参数配置成SOURCE（由源侧上报）时，为了GMLC直接定位到用户所在MME或MSC，需配置MME为携带MME Identifier和MSC-Number信元，相关配置参考ADD MMECHARACT的“MMEIDIE”参数及ADD MSCPARA命令。 |
| LRCBEFOREESMLC  | 和E-SMLC交互前是否启动LRC流程 | 可选必选说明：条件可选参数 参数含义：该参数用于控制MME在发送Location Request给E-SMLC之前，是否通过Location Report Control消息获取最新的ECGI。 前提条件：该参数在"紧急呼叫NI-LR支持开关"参数配置为"开"且"上报类型"参数勾选了"定位上报"后生效。 数据来源：整网规划 取值范围： NO（否）：不触发Location Report Control消息。YES（是）：触发Location Report Control消息。 默认值：无 配置原则：E-SMLC使用ECGI信息做辅助定位。  说明： 当参数设置为“YES（是）”时，“ 小区位置信息上报功能（S11接口）”特性的相关license授权并开启后，此参数配置才生效（特性编号：WSFD-106403，license部件编码：LKV2LCR01）。                                                            |
| LRCAFTERESMLC   | 和E-SMLC交互后是否启动LRC流程 | 可选必选说明：条件可选参数 参数含义：该参数用于控制E-SMLC响应Location Response超时或者失败时，是否通过Location Report Control消息获取最新的ECGI。 前提条件：该参数在"紧急呼叫NI-LR支持开关"参数配置为"开"且"上报类型"参数勾选了"定位上报"后生效。 数据来源：整网规划 取值范围：枚举类型。NO（否）：不触发Location Report Control消息。YES（是）：触发Location Report Control消息。 默认值：无 配置原则：紧急呼叫中心使用ECGI信息做辅助定位。  说明： 当参数设置为“YES（是）”时，“ 小区位置信息上报功能（S11接口）”特性的相关license授权并开启后，此参数配置才生效（特性编号：WSFD-106403，license部件编码：LKV2LCR01）。                                                       |
| HA              | 水平精度                | 可选必选说明：条件可选参数 参数含义：Location Request消息中的LCS QoS信元中的“Horizontal Accuracy”字段。 前提条件：该参数在"紧急呼叫NI-LR支持开关"参数配置为"开"且"上报类型"参数勾选了"定位上报"后生效。 数据来源：整网规划 取值范围：0~127 默认值：无 配置原则：根据协议3GPP TS 23.032 V13.0.0，水平距离r（米）和K（水平精度）之间的关系为r = 10*(1.1K - 1)。例如，当K设置为19时，r的取值为51米。                                                                                                                                                                                               |
| RT              | 响应时间                | 可选必选说明：条件可选参数 参数含义：Location Request消息中的LCS QoS信元中的“Response Time”字段。 前提条件：该参数在"紧急呼叫NI-LR支持开关"参数配置为"开"且"上报类型"参数勾选了"定位上报"后生效。 数据来源：整网规划 取值范围： LOW_DELAY（低时延）DELAY_TOLERANT（时延可接受） 默认值：无                                                                                                                                                                                                                                                                    |
| IV              | 移动速度                | 可选必选说明：条件可选参数 参数含义：Location Request消息中的Include Velocity信元。 前提条件：该参数在"紧急呼叫NI-LR支持开关"参数配置为"开"且"上报类型"参数勾选了"定位上报"后生效。 数据来源：整网规划 取值范围： NOT_REQUESTED（不请求）：不请求移动速度。REQUESTED（请求）：请求移动速度。 默认值：无                                                                                                                                                                                                                                                                 |
| DESC            | 描述                  | 可选必选说明：可选参数 参数含义：该参数用于指定LCS扩展软件参数表的描述信息。 数据来源：本端规划 取值范围：0~32位字符串 默认值：无                                                                                                                                                                                                                                                                                                                                                                                   |

#### 使用实例

关闭NOID为0的运营商的NI-LR功能。

MOD LCSPARAEX: NOID=0, NILRSWITCH=OFF;
