# 设置扩缩容业务控制参数(SET SCALINGCTRL)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

设置产品扩缩容时业务控制参数。

#### 注意事项

系统暂不支持该命令。

#### 本地用户权限

manage-ug；system-ug。

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组。

#### 参数说明

| 参数标识            | 参数名称         | 参数说明                                                                                                                  |
|:----------------|:-------------|:----------------------------------------------------------------------------------------------------------------------|
| SCALEWINDOW     | 暂态业务保护时长（秒）  | 可选必选说明：可选参数 参数含义：该参数用于设定扩缩容时保护用户暂态业务的时长。 数据来源：本端规划 取值范围：整数类型，取值范围为0～10。 系统初始设置值：0  说明： 当此参数设置为“0”时，表示设定扩缩容时不保护用户暂态业务。 |
| SCTPREBALANCESW | SCTP链路自动均衡开关 | 可选必选说明：可选参数 参数含义：该参数用于指定扩容时SCTP链路自动均衡的控制开关。 数据来源：本端规划 取值范围：ON(开启)OFF(关闭) 系统初始设置值：ON(开启)                               |
| GTPREBALANCESW  | GTP路径自动均衡开关  | 可选必选说明：可选参数 参数含义：该参数用于指定扩容时GTP路径自动均衡的控制开关。 数据来源：本端规划 取值范围：ON(开启)OFF(关闭) 系统初始设置值：ON(开启)                                |

#### 使用实例

设置“暂态业务保护时长(秒)”为“5”，“SCTP链路自动均衡开关”和“GTP路径自动均衡开关”“ON(开启)”：

```
SET SCALINGCTRL: SCALEWINDOW = 5,SCTPREBALANCESW = ON,GTPREBALANCESW = ON;
```
