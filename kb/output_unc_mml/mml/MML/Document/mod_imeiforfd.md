# 修改强制分离策略(MOD IMEIFORFD)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用来修改强制分离策略的配置数据。

#### 注意事项

- 该命令执行后立即生效。
- 该命令只能修改“描述”。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                      |
|:-------|:-------|:--------------------------------------------------------------------------|
| IMEISV | IMEISV | 可选必选说明：必选参数 参数含义：该参数用于设置UNC需要保留的IMEISV字段。 数据来源：整网规划 取值范围：16位十进制数字 默认值：无   |
| MASK   | 掩码     | 可选必选说明：必选参数 参数含义：该参数用于表示IMEISV字段相应的掩码。 数据来源：整网规划 取值范围：16位二进制数字 默认值：无      |
| DESC   | 描述     | 可选必选说明：可选参数 参数含义：该参数用于指定IMEISV匹配规则的记录名称。 数据来源：整网规划 取值范围：长度不超过32的字符串 默认值：无 |

#### 使用实例

将强制分离策略的描述修改为“FOR USERGRP2”：

MOD IMEIFORFD: IMEISV="1234567890123456", MASK="1111110000000000", DESC="FOR USERGRP2";
