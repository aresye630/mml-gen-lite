# 增加性能对象规则(ADD PERFOBJRULE)

- 命令功能

- 本地用户权限
- 网管用户权限

#### 命令功能

**适用网元：SGSN、MME**

该命令用于特定性能统计对象规则的配置，当前仅支持TAI组对象规则的配置。

TAI组是将同一区域范围内的TAI组合在一起。当配置了TAI组规则后，属于该规则下的TAI，性能指标均会统计到该TAI组对象下。

#### 注意事项

- 该命令执行后立即生效。
- 最大可配TAI组规则数为1500条。
- 每个TAI组可以有多个规则，但是同一个TAI只能包含在一个TAI组内。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                         |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MOC    | 测量对象类型 | 可选必选说明：必选参数 参数含义：待增加规则的测量统计对象类型。 数据来源：本端规划 取值范围：“TAIGP(TAI组)” 默认值：无                                                                                                                                                                                                                                          |
| TAIGPN | TAI组名  | 可选必选说明：条件必选参数 参数含义：待增加规则的TAI组名称。 前提条件：该参数在“MOC(测量对象类型)”参数设置为“TAIGP(TAI组)”时，才需要配置。 数据来源：本端规划 取值范围：1~32位字符串 默认值：无 配置原则：TAI组名可通过命令LST PERFOBJ查询。                                                                                                                                                                |
| BGNTAI | 起始TAI  | 可选必选说明：条件必选参数 参数含义：待增加TAI组规则所包含的TAI起始值。 前提条件：该参数在“MOC(测量对象类型)”参数设置为“TAIGP(TAI组)”时，才需要配置。 数据来源：本端规划 取值范围：9～10位字符串 默认值：无 配置原则：TAI值首位不允许为‘0’。输入的起始TAI值必须小于或者等于结束TAI值。输入的起始TAI值和终止TAI值定义的TAI号段范围不允许与其它记录定义的TAI号段范围相互交叉、包含或重合。  说明： TAI由MCC、MNC和TAC组成。 MCC为3位数字，MNC为2个或者3位数字，填写时请遵循实际长度。TAC编码为16进制数，固定为4位，不足前面补0。 |
| ENDTAI | 终止TAI  | 可选必选说明：条件必选参数 参数含义：待增加TAI组规则所包含的TAI结束值。 前提条件：该参数在“MOC(测量对象类型)”参数设置为“TAIGP(TAI组)”时，才需要配置。 数据来源：本端规划 取值范围：9～10位字符串 默认值：无 配置原则：TAI值首位不允许为‘0’。输入的终止TAI值必须大于或者等于起始TAI值。输入的起始TAI值和终止TAI值定义的TAI号段范围不允许与其它记录定义的TAI号段范围相互交叉、包含或重合。  说明： TAI由MCC、MNC和TAC组成。 MCC为3位数字，MNC为2个或者3位数字，填写时请遵循实际长度。TAC编码为16进制数，固定为4位，不足前面补0。 |

#### 使用实例

为TAI组名为“huawei”的TAI组对象增加TAI组规则，其TAI范围为308014101~308014103:

ADD PERFOBJRULE: MOC=TAIGP, TAIGPN="huawei", BGNTAI="308014101", ENDTAI="308014103";
