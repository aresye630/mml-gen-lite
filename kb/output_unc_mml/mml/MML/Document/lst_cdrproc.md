#### 命令功能

**适用NF：NCG**

该命令用于查询当前系统的格式引擎包信息。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称           | 参数说明                                                                                                                                                                                                         |
|:-------------|:---------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AGID         | 接入网元分组标识       | 可选必选说明：可选参数 参数含义：用于区分不同域的接入网元。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：无                                                                                                                                |
| PRFNAME      | 格式引擎包名         | 可选必选说明：可选参数 参数含义：格式引擎包定义了CG话单处理的业务规则，主要包括话单字段过滤配置、分拣条件配置、通道配置、话单处理脚本等。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～255。 默认值：无 配置原则：无                                                                                       |
| CDRTIMEOUT   | 话单超时时间（分钟）     | 可选必选说明：可选参数 参数含义：表示话单合并过程中能容许的超时时间。 数据来源：对端协商 取值范围：整数类型，取值范围为0～14400，单位是分钟。 默认值：无 配置原则：无                                                                                                                     |
| SHAREFILECSN | 共享第二份最终话单文件序列号 | 可选必选说明：可选参数 参数含义：用于设置共享第二份最终话单文件序列号功能关闭或开启。 数据来源：本端规划 取值范围：枚举类型。 OFF：关闭。ON：开启。 默认值：无 配置原则：无                                                                                                                  |
| SEQNUMMODE   | 序列号模式          | 可选必选说明：可选参数 参数含义：控制NCG回复的Cancel response和Release response的IE中携带的Sequence number来自GSN发送的Cancel request或Release request的gtp'帧的Head还是IE。 数据来源：本端规划 取值范围：枚举类型。 IE：序列号源自gtp'的IE。HEAD：序列号源自gtp'的Head。 默认值：无 配置原则：无 |

#### 使用实例

查询CG系统当前使用的话单处理配置：

```
LST CDRPROC:;
```

```

                  序列号模式  =  序列号源自gtp'的IE
```
