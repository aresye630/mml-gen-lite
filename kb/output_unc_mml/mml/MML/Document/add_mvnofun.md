# 增加MVNO功能配置信息(ADD MVNOFUN)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

此命令用于配置MVNO的用户可以使用的一些业务和功能。通过配置MVNO功能，可以限制MVNO用户的业务特性。

#### 注意事项

- MVNOID在MVNO标识表中已经配置。
- 此命令执行后立即生效。
- 此命令最大记录数为64个。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称        | 参数说明                                                                                                                                                                                        |
|:-------|:------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MVNOID | MVNO标识      | 可选必选说明：必选参数 参数含义：该参数用于增加此MVNO用户的功能配置。 数据来源：整网规划 取值范围：1～64 默认值：无                                                                                                                             |
| SMS    | 是否支持短消息     | 可选必选说明：可选参数 参数含义：该参数用于设置此MVNO的用户是否支持短消息业务。 数据来源：整网规划 取值范围： “NO(否)”“YES(是)” 默认值：“YES(是)” 配置原则：如果填写“YES(是)”，此MVNO的用户可以使用短消息业务。如果填写“NO(否)”，系统将限制此MVNO的用户不能使用短消息业务。                             |
| LCS    | 是否支持LCS     | 可选必选说明：可选参数 参数含义：该参数用于设置此MVNO的用户是否支持LCS业务。 数据来源：整网规划 取值范围： “NO(否)”“YES(是)” 默认值：“YES(是)” 配置原则：如果填写“YES(是)”，此MVNO的用户可以使用LCS业务。如果填写“NO(否)”，系统将限制此MVNO的用户不能使用LCS业务。                             |
| CMP    | 是否支持SNDCP压缩 | 可选必选说明：可选参数 参数含义：该参数用于设置此MVNO的用户是否支持Gb接口的SNDCP压缩功能。 数据来源：整网规划 取值范围：“ NO(否)”“YES(是)” 默认值：“ NO(否)” 配置原则：如果填写“YES(是)”，此MVNO的用户可以使用Gb接口的SNDCP压缩功能。如果填写“ NO(否)”，系统将限制此MVNO的用户不能使用Gb接口的SNDCP压缩功能。 |

#### 使用实例

配置标识为2的MVNO的功能，不支持LCS功能，支持SNDCP压缩功能：

ADD MVNOFUN: MVNOID=2, LCS=NO, CMP=YES;
