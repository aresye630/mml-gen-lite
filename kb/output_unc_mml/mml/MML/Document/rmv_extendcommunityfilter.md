# 删除扩展团体属性过滤器（RMV EXTENDCOMMUNITYFILTER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除扩展团体属性过滤器。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称          | 参数说明                                                                                              |
|:-------|:--------------|:--------------------------------------------------------------------------------------------------|
| NAME   | 扩展团体属性过滤器名字或号 | 可选必选说明：必选参数 参数含义：该参数用于指定扩展团体属性过滤器名字或扩展团体属性过滤器号。 数据来源：本端规划 取值范围：字符串类型，扩展团体属性过滤器名称其长度范围是1～51。 默认值：无 |

#### 使用实例

删除扩展团体属性过滤器：

```
RMV EXTENDCOMMUNITYFILTER:NAME="a";
```
