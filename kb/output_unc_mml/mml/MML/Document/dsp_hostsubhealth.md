# 显示IFCM诊断的故障主机信息（DSP HOSTSUBHEALTH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示IFCM诊断的故障主机信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                |
|:---------|:-------|:----------------------------------------------------------------------------------------------------|
| HOSTNAME | 主机名称   | 可选必选说明：可选参数  参数含义：该参数用于表示故障主机名称。可通过DSP POD查询获取。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~127。  默认值：无  配置原则：无 |

## 使用实例

显示IFCM诊断的故障主机信息。

```
%%DSP HOSTSUBHEALTH:;%%
RETCODE = 0  操作成功

结果如下
--------
主机名称   Pod名称       损伤类型       损伤程度

E9000V5-5  usn-pod-1     计算类异常     Damage
E9000V5-5  cslbip-pod-1  计算类异常     Damage
E9000V5-5  usn-pod-1     业务KPI类异常  97.56%
(结果个数 = 3)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                                                                                              |
|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 主机名称    | 该参数用于表示故障主机名称。可通过DSP POD查询获取。                                                                                                                                                                      |
| Pod名称   | 该参数用于表示故障Pod名称。                                                                                                                                                                                    |
| 损伤类型    | 该参数用于表示损伤类型。 取值说明： “COMPUTE（计算类异常）”：节点计算维度异常（如：CPU、内存资源异常占用）。“NETWORK（网络类异常）”：节点网络维度异常（如：通信亚健康）。“STORAGE（存储类异常）”：节点存储维度异常（如：存储读写响应时延大）。“KPI（业务KPI类异常）”：Pod粒度业务维度异常。                                |
| 损伤程度    | 该参数用于表示损伤程度。 非KPI类损伤：Normal代表正常，Warning代表预警，Damage代表损伤，Fault代表故障。 KPI类损伤：数值代表业务KPI类异常的损伤程度，范围0~100%，0代表无损伤，100%代表KPI全损伤。 若KPI阈值大于KPI真实值时，损伤程度=(KPI阈值-KPI真实值)/KPI阈值x100%。 若KPI阈值小于等于KPI真实值时，损伤程度为0。 |
