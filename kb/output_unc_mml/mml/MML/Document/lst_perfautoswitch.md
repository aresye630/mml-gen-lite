#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询性能统计对象自动生成开关。

#### 注意事项

无。

#### 本地用户权限

manage-ug;system-ug

#### 网管用户权限

G\_1管理员级别命令组；G\_2操作员级别命令组；G\_3用户级别命令组

#### 参数说明

| 参数标识            | 参数名称          | 参数说明                                                                                                                                                                                                                                      |
|:----------------|:--------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TAIAUTOSWITCH   | TAI组对象自动生成开关  | 可选必选说明：可选参数 参数含义：该参数用于设置TAI组对象自动生成开关。 数据来源：本端规划 取值范围：ON(打开)：TAI组对象自动生成功能打开。OFF(关闭)：TAI组对象自动生成功能关闭。 系统初始设置值：OFF(关闭) 配置原则：如果要支持TAI组对象动态创建，无需人工干预，可以打开此功能配置。如果关闭，TAI组测量对象只能通过ADD PERFOBJ和ADD PERFOBJRULE命令配置；如果打开，可以同时支持自动生成和手工配置两种方式上报话统对象。 |
| GBRAIAUTOSWITCH | GB路由区对象自动生成开关 | 可选必选说明：可选参数 参数含义：该参数用于设置GB模式路由区对象自动生成开关。 数据来源：本端规划 取值范围：ON(打开)：GB路由区对象自动生成功能打开。OFF(关闭)：GB路由区对象自动生成功能关闭。 系统初始设置值：OFF(关闭) 配置原则：如果要支持Gb模式路由区号对象动态创建，无需人工干预，可以打开此功能配置。如果关闭，此测量对象只能通过ADD PERFGBPAGING命令配置；如果打开，可以同时支持自动生成和手工配置两种方式上报话统对象。      |
| APNAUTOSWITCH   | APN对象自动生成开关   | 可选必选说明：可选参数 参数含义：该参数用于设置APN对象自动生成开关。 数据来源：本端规划 取值范围：ON(打开)：APN对象自动生成功能打开。OFF(关闭)：APN对象自动生成功能关闭。 系统初始设置值：OFF(关闭)配置原则：如果要支持APN对象动态创建，无需人工干预，可以打开此功能配置。如果关闭，此测量对象只能通过ADD PERFOBJ命令配置；如果打开，可以同时支持自动生成和手工配置两种方式上报话统对象。                         |

#### 使用实例

查询话统对象自动生成开关:

LST PERFAUTOSWITCH:;

```
%%LST PERFAUTOSWITCH:;%%
RETCODE = 0  操作成功。

操作结果如下：
--------------
    TAI组对象自动生成开关  =  打开
 GB路由区对象自动生成开关  =  打开
      APN对象自动生成开关  =  打开
---  END
```
