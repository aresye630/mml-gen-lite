# 查询UPF服务区名称绑定的LAI范围（LST UPAREABINDLAI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：GGSN**

该命令用于查询UPF服务区名称绑定的LAI范围。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                                                                       |
|:---------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AREANAME | UPF服务区名称 | 可选必选说明：可选参数  参数含义：该参数用于配置UPF服务区的名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~255。不支持空格，不区分大小写。  默认值：无  配置原则：  该参数取值应与命令LST UPAREA查询结果中的AREANAME保持一致；且该AREANAME在命令LST UPAREA查询结果中对应的AREATYPE取值应为LAI。 |

## 使用实例

- 查询UPF服务区名称为"iuarea1"的区域绑定的LAI。
  LST UPAREABINDLAI: AREANAME="iuarea1";

  ```
  %%LST UPAREABINDLAI: AREANAME="iuarea1";%%
  RETCODE = 0  操作成功。

  结果如下
  ------------------------
                       UPF服务区名称  =  iuarea1
  UPF服务区名称绑定的LAI范围的起始值  =  0000000000
  UPF服务区名称绑定的LAI范围的结束值  =  9999999999
  (结果个数 = 1)
  ```
- 查询所有UPF服务区名称绑定的LAI。
  LST UPAREABINDLAI:;

  ```
  %%LST UPAREABINDLAI:;%%
  RETCODE = 0  操作成功。

  结果如下
  ------------------------
  UPF服务区名称  UPF服务区名称绑定的LAI范围的起始值  UPF服务区名称绑定的LAI范围的结束值    

  iuarea1        0000000000                          9999999999  
  uparea3        460010001                           460011111   
  (结果个数 = 2)
  ```

## 输出结果说明

| 输出项名称                | 输出项解释                        |
|:---------------------|:-----------------------------|
| UPF服务区名称             | 该参数用于配置UPF服务区的名称。            |
| UPF服务区名称绑定的LAI范围的起始值 | 该参数用于标识UPF服务区名称绑定的LAI范围的起始值。 |
| UPF服务区名称绑定的LAI范围的结束值 | 该参数用于标识UPF服务区名称绑定的LAI范围的结束值。 |
