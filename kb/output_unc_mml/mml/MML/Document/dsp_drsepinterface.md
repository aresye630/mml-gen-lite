# 显示故障隔离逻辑接口的状态（DSP DRSEPINTERFACE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询添加故障隔离的逻辑接口的管理状态。

## 注意事项

该命令适用于支持热备容灾的网元执行。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询添加故障隔离的逻辑接口的管理状态。

```
%%DSP DRSEPINTERFACE:;%%
RETCODE = 0  操作成功

结果如下
--------
        接口名  =  itf1
      管理状态  =  开启
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                                             |
|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
| 接口名     | 该参数用于表示接口名称。                                                                                                                                      |
| 管理状态    | 该参数用于表示接口管理状态。 取值说明： “UP（开启）”：表示接口状态为开启。“DOWN（关闭）”：表示接口状态为关闭。“UNKNOWN（未知）”：在整系统复位或HAFG重启后的2分钟内，查询结果可能为“未知”。此时，请于2分钟后再次查询。“NOTEXIST（不存在）”：表示接口不存在。 |
