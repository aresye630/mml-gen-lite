# 查询5G迁移配置表（LST NGOFFLOADINF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询5G迁移参数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询5G迁移配置表，执行以下命令：

```
%%LST NGOFFLOADINF:;%%
RETCODE = 0  操作成功

结果如下
--------
容灾场景迁移速率(千/分钟)  =  30
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称          | 输出项解释                                                                                                                                                                                                                                                          |
|:---------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 容灾场景迁移速率(千/分钟) | 参数含义：该参数仅用于指定容灾倒换场景AMF迁移用户的速率。 注意： 迁移速率的设置需要考虑本AMF，目标AMF、NG-RAN、UDM、PCF等周边NF的负载情况，设置过大，可能导致上述NF过载。由于实现原因，AMF在系统内部分发迁移任务时迁移速率按照向下取整，故存在实际迁移速率略微低于本设置值的可能。实际的最大迁移速度会产生100用户/分钟的误差，即可能会略低于该设置值。如果STR OFFLOADAMF命令执行时指定迁移速率，则以指定的迁移速率为准进行用户迁移。配置参数变更后，下次触发容灾迁移时生效。 |
