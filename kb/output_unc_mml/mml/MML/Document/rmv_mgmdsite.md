# 删除IGMP全局配置（RMV MGMDSITE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来删除IGMP全局配置。

#### 注意事项

- 该命令执行后立即生效。
- 执行该命令时，不携带可选参数的作用是删除配置。
- 执行该命令时，携带可选参数的作用是恢复指定参数为默认值。
- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识              | 参数名称           | 参数说明                                                                                                        |
|:------------------|:---------------|:------------------------------------------------------------------------------------------------------------|
| ADDRESSFAMILY     | 地址族            | 可选必选说明：必选参数 参数含义：该参数用于表示地址族类型。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。 默认值：无                               |
| VRFNAME           | VPN实例名称        | 可选必选说明：必选参数 参数含义：该参数用来指定VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：通过LST L3VPNINST查看当前已存在的VPN实例。 |
| QUERYINTERVAL     | 周期性普遍查询时间（s）   | 可选必选说明：可选参数 参数含义：该参数用来指定周期性普遍查询时间。 数据来源：本端规划 取值范围：整数类型，取值范围为1～18000，单位是秒。 默认值：无                             |
| QUERYRSPINTERVAL  | 查询响应时间（s）      | 可选必选说明：可选参数 参数含义：该参数用来指定查询响应时间。 数据来源：本端规划 取值范围：整数类型，取值范围为1～125，单位是秒。 默认值：无                                  |
| ROBUSTNESS        | 鲁棒稳定系数         | 可选必选说明：可选参数 参数含义：该参数用来指定鲁棒稳定系数。 数据来源：本端规划 取值范围：整数类型，取值范围为2～5。 默认值：无                                         |
| LMQT              | 特定组查询的周期性时间（s） | 可选必选说明：可选参数 参数含义：该参数用来指定特定组查询的周期性时间。 数据来源：本端规划 取值范围：整数类型，取值范围为1～25，单位是秒。 默认值：无                              |
| OTHQUERIERPSTTIME | 其他查询器存在的时间（s）  | 可选必选说明：可选参数 参数含义：该参数用来指定其他查询器存在的时间。 数据来源：本端规划 取值范围：整数类型，取值范围为60～300，单位是秒。 默认值：无                             |

#### 使用实例

删除IGMP全局鲁棒系数配置：

```
RMV MGMDSITE:VRFNAME="_public_",ADDRESSFAMILY=ipv4unicast,ROBUSTNESS=3;
```
