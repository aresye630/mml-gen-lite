# 删除漫游切片映射配置（RMV AMFROAMNSMAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除漫游切片映射配置。

## 注意事项

- 该命令执行后立即生效。

- 删除漫游切片映射配置时，对已注册用户不会立即生效。如果需要立即生效，请先执行STR NGUSRBATCHDEREG命令对漫游用户启动批量去注册任务，并指定去注册类型为需要重新注册，触发用户重新注册，获取最新切片映射关系。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                                                                                                                                            |
|:-------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HMCC   | 归属地移动国家码  | 可选必选说明：必选参数  参数含义：该参数用于描述归属地移动国家码。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。3位十进制数。  默认值：无  配置原则：无                                                                                                         |
| HMNC   | 归属地移动网号   | 可选必选说明：必选参数  参数含义：该参数用于描述归属地移动网号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。2位或者3位十进制数。  默认值：无  配置原则：无                                                                                                  |
| HSST   | 归属地切片服务类型 | 可选必选说明：必选参数  参数含义：该参数用于描述归属地切片服务类型。  数据来源：全网规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无                                                                                                            |
| HSD    | 归属地切片细分标识 | 可选必选说明：必选参数  参数含义：该参数用于表示归属地切片细分标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~6。该参数输入长度为6或1。长度为6时，只能由字母（A-F或者a-f）、数字（0-9）组成，且大小写不敏感，转大写处理。长度为1时，只能为“*”，表示通配符，任意SD值都可以匹配。  默认值：无  配置原则：  如果该参数为空请填入FFFFFF。 |
| VMCC   | 拜访地移动国家码  | 可选必选说明：必选参数  参数含义：该参数用于描述拜访地移动国家码。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。3位十进制数。  默认值：无  配置原则：无                                                                                                         |
| VMNC   | 拜访地移动网号   | 可选必选说明：必选参数  参数含义：该参数用于描述拜访地移动网号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。2位或者3位十进制数。  默认值：无  配置原则：无                                                                                                  |

## 使用实例

删除漫游切片映射配置，执行如下命令：

```
RMV AMFROAMNSMAP: HMCC="245", HMNC="38", HSST=1, HSD="123FFF", VMCC="123", VMNC="45";
```
