# 查询自动部署RU黑名单（LST AUTOSCALINGRUBLACKLIST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询自动化配置RU黑名单。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                   |
|:-------|:-------|:-----------------------------------------------------------------------|
| RUID   | RU ID  | 可选必选说明：可选参数 参数含义：该参数用于指定RU ID。 数据来源：本端规划 取值范围：整数类型，取值范围为64～9999。 默认值：无 |

#### 使用实例

查询自动化配置RU黑名单：

```
LST AUTOSCALINGRUBLACKLIST:;
```

```
RETCODE = 0 操作成功

结果如下
-------------------------
RU ID

64
65
(结果个数 = 2)
---    END
```
