# 显示S1模式负载信息(DSP S1LOAD)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限

- 输出结果说明

#### 命令功能

**适用网元：MME**

此命令用于查询S1用户连接信息。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                     |
|:----------|:-------|:-------------------------------------------------------------------------------------------------------------------------|
| QUERYTYPE | 查询类型   | 可选必选说明：必选参数 参数含义：待查询的类型。 取值范围： “BYSGP(基于SGP查询)” 默认值：无  说明： 当前版本只支持基于SGP查询，其他查询类型暂不支持。                                    |
| RUNAME    | RU名称   | 可选必选说明：条件可选参数 参数含义：该参数用于指定SPU资源单元名。该参数可以通过DSP RU命令查询。 前提条件：该参数在“QUERYTYPE”参数配置为“BYSGP(基于SGP查询)”时生效。 取值范围：0~63 位字符串 默认值：无 |

#### 使用实例

查看S1连接信息：

DSP S1LOAD: QUERYTYPE=BYSGP, RUNAME="USN\_VSU1";

```
%%DSP S1LOAD: QUERYTYPE=BYSGP, RUNAME="USN_VSU1";%%
RETCODE = 0  操作成功。

操作结果如下
-------------------------
RU名称      SGP模块号         S1用户连接数                 记录有效标志 
USN_VSU1    1016              0                            1                 
USN_VSU1    1017              0                            1                 
USN_VSU1    1018              0                            1                 
USN_VSU1    1019              0                            1                 
仍有后续报告输出
---    END
```

```
%%DSP S1LOAD: QUERYTYPE=BYSGP, RUNAME="USN_VSU1";%%
RETCODE = 0  操作成功。

操作结果如下
-------------------------
S1用户总连接数 = 0
(结果个数 = 5)
共有2个报告
---    END
```

#### 输出结果说明

| 输出项名称    | 输出项解释                            |
|:---------|:---------------------------------|
| RU名称     | SGP进程所在节点的RU名称。                  |
| SGP模块号   | SGP进程模块号。                        |
| S1用户连接数  | S1用户连接数。                         |
| 记录有效标志   | 记录是否有效的标志。  说明： 标志为1说明有效，为0说明无效。 |
| S1用户总连接数 | 所有SGP进程的总的S1用户连接数。               |
