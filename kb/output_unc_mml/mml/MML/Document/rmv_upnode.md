# 删除UPF节点（RMV UPNODE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、SGW-C、PGW-C、GGSN**

该命令用于删除指定实例名称的UPF节点特征。

## 注意事项

- 该命令执行后立即生效。

- 执行RMV UPNODE时会同步删除的配置：IPALLOCBYUPFSW。
- 如果UPNODE已经绑定在UPFBINDGRP中，则不允许删除，需要执行命令RMV UPFBINDGRP解除绑定关系后再删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称    | 参数说明                                                                                                                                           |
|:---------------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCENAME | UPF实例名称 | 可选必选说明：必选参数  参数含义：该参数用于指定UPF实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~255。不区分大小写。  默认值：无  配置原则：  本参数取值与ADD PNFPROFILE命令中的“NF实例标识”参数取值保持一致时，关联关系生效。 |

## 使用实例

删除实例名称为“upf1”的UPF节点特征：

```
RMV UPNODE:NFINSTANCENAME="upf1";
```
