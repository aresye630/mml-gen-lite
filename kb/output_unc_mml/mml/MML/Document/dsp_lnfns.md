# 查询本端NF支持的网络切片（DSP LNFNS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF、SMF**

该命令用以查询本端NF支持的网络切片。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                  |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SST    | 切片业务类型 | 可选必选说明：必选参数  参数含义：该参数表示切片的业务类型，如eMBB（1）、URLLC（2）、MIoT（3）等协议定义的标准SST，或者运营商自定义的SST。  数据来源：全网规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无                                                    |
| SD     | 切片细分标识 | 可选必选说明：可选参数  参数含义：该参数表示根据网络切片所提供的服务特点、所服务的对象差异，对某种网络切片的进一步细分。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。采用十六进制表示（无须输入“0x”前缀），只能由数字（0-9），字母（A-F、a-f）组成。字母大小写不敏感。  默认值：无  配置原则：  该值若不设置，默认值为FFFFFF。 |

## 使用实例

查询系统中“切片业务类型”为1，“切片细分标识”为“010101”的切片信息，执行如下命令：

```
%%DSP LNFNS: SST=1, SD="010101";%%
RETCODE = 0  操作成功

结果如下
--------
    网络切片索引  =  0
       PLMN 索引  =  0
          NF类型  =  NfAMF
    切片业务类型  =  1
    切片细分标识  =  010101
    数据网络名称  =  NULL
绑定的SMFINFO ID  =  null
        描述信息  =  NULL
(结果个数 = 1)

---    END
```
