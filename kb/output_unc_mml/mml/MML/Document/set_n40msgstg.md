# 设置缓存开关、回放间隔、回放速率（SET N40MSGSTG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

当打开缓存功能后，需要使用命令SET CNVRGDCHGPARA配置参数CHGDATAREFGEN为SMF，即配置生成ChargingDataRef的方法为使用SMF生成，如果使用CHF生成ChargingDataRef时，可能导致放通用户用量丢失。

**适用NF：SMF、PGW-C**

该命令用于设置缓存开关、回放间隔、回放速率。

## 注意事项

- 该命令执行后立即生效。

- 该命令内的参数具体的生效机制，还需要参考对应的参数说明。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| STGSWITCH   |   REPLAYINTERVAL |   REPLAYRATE | ENCRYPT   |   STGTXTIMER |
|:------------|-----------------:|-------------:|:----------|-------------:|
| DISABLE     |               30 |          500 | DISABLE   |           15 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称              | 参数说明                                                                                                                                                                                                                                                         |
|:---------------|:------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| STGSWITCH      | 融合计费消息缓存开关        | 可选必选说明：必选参数  参数含义：融合计费消息缓存开关。  数据来源：全网规划 取值范围： ENABLE（使能）DISABLE（不使能）  默认值：无。  配置原则：  只有在CHF支持处理SMF回放消息时，才可配置该功能使能。  当打开缓存功能后，需要使用命令SET CNVRGDCHGPARA配置参数CHGDATAREFGEN为SMF，即配置生成ChargingDataRef的方法为使用SMF生成。                                                  |
| REPLAYINTERVAL | 融合计费消息回放的最小间隔(分钟) | 可选必选说明：该参数在"STGSWITCH"配置为"ENABLE"时为条件可选参数。  参数含义：融合计费消息回放的最小间隔。  数据来源：本端规划  取值范围：整数类型，取值范围是5~1440，单位是分钟。回放间隔参数修改对应的数值后，需要加锁解锁对应的目录，修改才可生效。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST N40MSGSTG查询当前参数配置值。  配置原则：  可根据现网CHF典型的故障恢复时长进行配置。                       |
| REPLAYRATE     | 融合计费消息回放的速率(个/秒)  | 可选必选说明：该参数在"STGSWITCH"配置为"ENABLE"时为条件可选参数。  参数含义：融合计费消息回放的速率。  数据来源：本端规划  取值范围：整数类型，取值范围是10~10000，单位是个每秒。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST N40MSGSTG查询当前参数配置值。  配置原则：  融合计费缓存消息回放速率 <= CHF的信令处理能力 - 正常情况下SMF发送融合计费消息的峰值速率。                           |
| ENCRYPT        | 加密开关              | 可选必选说明：该参数在"STGSWITCH"配置为"ENABLE"时为条件可选参数。  参数含义：该参数用于指定被缓存的融合计费消息是否被加密。  数据来源：本端规划 取值范围： ENABLE（使能）DISABLE（不使能）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST N40MSGSTG查询当前参数配置值。  配置原则：  计费消息的加密存储会增加额外的性能开销，开启加密功能前请联系华为技术服务评估当前系统是否满足开启条件。                    |
| STGTXTIMER     | 缓存Tx定时器时长(秒)      | 可选必选说明：该参数在"STGSWITCH"配置为"ENABLE"时为条件可选参数。  参数含义：该参数用于设置融合计费缓存服务等待CHF响应消息的时长，当超过该时长，则认为融合计费缓存服务等待CHF消息响应失败。  数据来源：全网规划  取值范围：整数类型，取值范围是0~20，单位是秒。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST N40MSGSTG查询当前参数配置值。  配置原则：  只有在融合计费消息缓存开关（STGSWITCH）打开时，该配置参数才生效。 |

## 使用实例

设置缓存开关打开、回放间隔20分钟、回放速率600个/秒

```
SET N40MSGSTG: STGSWITCH=ENABLE, REPLAYINTERVAL=20, REPLAYRATE=600;
```
