# 显示最后订阅Session信息（DSP TRCLASTSUBSESSION）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示最后订阅session信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

显示最后订阅session信息，可通过如下命令显示：

```
DSP TRCLASTSUBSESSION:SERVICEINSTANCE="vnfc";
```

```
RETCODE = 0  操作成功

结果如下:
------------------------
最近的SESSION  =  1
     订阅时间  =  2016-06-02 15:15:43
   去订阅时间  =  2016-06-02 18:10:10 
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称      | 输出项解释       |
|:-----------|:------------|
| 最近的SESSION | 最近的SESSION。 |
| 订阅时间       | 订阅时间。       |
| 去订阅时间      | 去订阅时间。      |
