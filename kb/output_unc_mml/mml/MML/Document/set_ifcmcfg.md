# 设置IFCM配置信息(SET IFCMCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

**执行该命令会改变IFCM系统配置，对故障诊断恢复结果造成影响，请慎重执行。**

该命令用于设置IDRService配置信息。

该命令中阈值（“下界阈值”，“上界阈值”，“阈值”）的初始值已由网元部署时通过配置文件创建，可以通过**DSP IFCMCFG**命令查看。

## 注意事项

无。

## 参数说明

| 参数标识             | 参数名称    | 参数说明                                                                                                                                                                                                                                                                         |
|:-----------------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID             | 网元ID    | 可选必选说明：必选参数。 参数含义：指定要设置哪个网元的配置信息。 取值范围：0~65535。 默认值：无。 配置原则：无。                                                                                                                                                                                                               |
| CFG_TYPE         | 配置类型    | 可选必选说明：必选参数。 参数含义：指定要配置项。 取值范围： “byME(网元)”：配置网元级阈值。“byPod(Pod)”：配置Pod级阈值。“byPool(网元容灾阈值)”：配置网元容灾阈值。 默认值：无。 配置原则：无。                                                                                                                                                           |
| THRESHOLD_TYPE   | 阈值类型    | 可选必选说明：该参数在“配置类型”取值为“byME(网元)”或“byPod(Pod)”时为必选参数。 参数含义：指定阈值类型。 取值范围： “byDiagnose(诊断阈值)”：配置故障诊断阈值。“byKPI(KPI栅栏)”：配置KPI栅栏上下界阈值。 默认值：无。 配置原则：无。                                                                                                                                |
| POD_SELECT_RANGE | POD选择范围 | 可选必选说明：该参数在“配置类型”取值为“byPod(Pod)”时为必选参数。 参数含义：选择POD的设置范围。 取值范围： “byAllPod(所有POD)”：所有POD。“bySinglePod(单个POD)”：单个POD。 默认值：无。 配置原则：当“阈值类型”为“byDiagnose(诊断阈值)”时，“byAllPod(所有POD)”对设置过的POD的诊断阈值不生效，如需再次修改该POD的诊断阈值，需按POD关键字修改；当“阈值类型”为“byKPI(KPI栅栏)”时，“byAllPod(所有POD)”对所有POD进行修改。 |
| POD_KEYWORD      | POD关键字  | 可选必选说明：该参数在“POD选择范围”为“bySinglePod(单个POD)”时为必选参数。 参数含义：指定要设置哪个POD的阈值信息。 取值范围：无。 默认值：无。 配置原则：使用DSP IFCMCFG命令查询（网元ID输入对应网元，阈值类型选择“byKPI(KPI栅栏)”），查询结果中配置对象列除网元外即为取值范围。                                                                                                          |
| LOWER_THRESHOLD  | 下界阈值(%) | 可选必选说明：该参数在“阈值类型”为“byKPI(KPI栅栏)”时，为必选参数。 参数含义：指定KPI的栅栏下界阈值。 取值范围：0~80。 默认值：无。 配置原则：无。                                                                                                                                                                                        |
| UPPER_THRESHOLD  | 上界阈值(%) | 可选必选说明：该参数在“阈值类型”为“byKPI(KPI栅栏)”时，为必选参数。 参数含义：指定KPI的栅栏上界阈值。 取值范围：1~100。 默认值：无。 配置原则：需严格大于对应KPI的下界阈值。                                                                                                                                                                         |
| THRESHOLD        | 阈值(%)   | 可选必选说明：该参数在“配置类型”为“byPool(网元容灾阈值)”或“阈值类型”为“byDiagnose(诊断阈值)”时，为必选参数。 参数含义：发送给服务的阈值信息。 取值范围：整数类型，当“配置类型”为“byME(网元)”和“byPod(Pod)”时取值范围为1~100，当“配置类型”为“byPool(网元容灾阈值)”时取值范围为5~100。“byME(网元)”必须严格小于“byPool(网元容灾阈值)”。 默认值：无。 配置原则：无。                                              |
| METRIC_ID        | 指标ID    | 可选必选说明：该参数在“阈值类型”为“byKPI(KPI栅栏)”时，为可选参数。 参数含义：指定要设置哪个指标ID的阈值信息。 取值范围：1~4294967295。 默认值：无。 配置原则：使用DSP IFCMCFG命令查询（网元ID输入对应网元，阈值类型选择“byKPI(KPI栅栏)”），查询结果中的指标ID即为取值范围。                                                                                                          |

## 使用实例

1. 设置网元容灾倒换阈值：

   ```
   %%SET IFCMCFG: MEID=0, CFG_TYPE=byPool, THRESHOLD=18;%%
   RETCODE = 0  操作成功
   操作结果如下： 
   -------------- 
   操作结果  =  success 
   (结果个数 = 1)  
   ---    END
   ```
2. 设置网元诊断阈值：

   ```
   %%SET IFCMCFG: MEID=0, CFG_TYPE=byME, THRESHOLD_TYPE=byDiagnose, THRESHOLD=10;%%
   RETCODE = 0  操作成功
   操作结果如下： 
   -------------- 
   操作结果  =  success 
   (结果个数 = 1)  
   ---    END
   ```
3. 设置umf-pod的KPI栅栏阈值：

   ```
   %%SET IFCMCFG: MEID=331, CFG_TYPE=byPod, THRESHOLD_TYPE=byKPI, POD_SELECT_RANGE=bySinglePod, POD_KEYWORD="umf-pod", LOWER_THRESHOLD=78, UPPER_THRESHOLD=99, METRIC_ID=1000010000;%% 
   RETCODE = 0  操作成功  
   操作结果如下： 
   -------------- 
   操作结果  =  success 
   (结果个数 = 1)  
   ---    END
   ```
