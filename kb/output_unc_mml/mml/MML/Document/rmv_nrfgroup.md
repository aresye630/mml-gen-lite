# 删除对端NRF实例组（RMV NRFGROUP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

当运营商不再需要原规划的NRF实例组时，可以使用此命令。该命令用于删除对端NRF实例组。

## 注意事项

- 该命令执行后立即生效。

- 主备或双活组网的场景下，如果需要配置此命令，则两个NRF上均需执行此命令，且配置参数一致。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                 |
|:----------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
| GROUPNAME | 实例组名称  | 可选必选说明：必选参数  参数含义：该参数用于表示对端NRF实例组的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~64。该参数只能由字母（A-Z或者a-z）、数字（0-9）、连字符（-）和点（.）组成，不能以“.”开始，也不能以“.”结束。  默认值：无  配置原则：无 |

## 使用实例

当不再需要实例组名称为nrfgroup001的NRF实例组时，执行此命令。

```
RMV NRFGROUP: GROUPNAME="nrfgroup001";
```
