# 修改基于特性的位置上报配置（MOD FEATLOCREPORT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于修改基于特性的位置上报配置。

## 注意事项

随流程生效

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称             | 参数说明                                                                                                                                                                                               |
|:---------------|:-----------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FEATURE        | 特性名称             | 可选必选说明：必选参数  参数含义：该参数用于指定特性名称。  数据来源：本端规划 取值范围： QOSANA（质差分析）  默认值：无  配置原则：无                                                                                                                        |
| NCGITRIGGERFLG | 配置NR全球小区的trigger | 可选必选说明：该参数在"FEATURE"配置为"QOSANA"时为条件可选参数。  参数含义：该参数用于指定5G NR全球小区的trigger是否使能。  数据来源：本端规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无  配置原则：  FEATURE配置为“QOSANA”时，需配置。配置为“ENABLE”时，会基于FEATURE中配置的特性上报NCGI信息。 |

## 使用实例

修改“FEATURE”为QOSANA的用户，NCGI信息上报为不使能。

```
MOD FEATLOCREPORT:FEATURE=QOSANA,NCGITRIGGERFLG=DISABLE;
```
