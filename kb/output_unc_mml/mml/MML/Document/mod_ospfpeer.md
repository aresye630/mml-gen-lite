# 修改OSPF的NBMA网络邻居路由器配置（MOD OSPFPEER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改NBMA网络上指定相邻路由器的IP地址及DR选举权。

#### 注意事项

- 该命令执行后立即生效。
- 只有配置了OSPF进程后才能使用该命令。
- 通过此命令设置对端设备的DR选举的优先级，必须与本端设备的DR的优先级一致。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                                               |
|:-----------|:----------|:-------------------------------------------------------------------------------------------------------------------|
| PROCID     | 进程号       | 可选必选说明：必选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 配置原则：OSPF进程必须已经存在。请使用LST OSPF命令查看可用的OSPF进程。 |
| IPADDRESS  | 邻居路由器IP地址 | 可选必选说明：必选参数 参数含义：邻居路由器IP地址。 数据来源：对端协商 取值范围：IPv4地址类型。点分十进制格式。 默认值：无                                                 |
| DRPRIORITY | 邻居路由器优先级  | 可选必选说明：可选参数 参数含义：邻居路由器优先级。 数据来源：对端协商 取值范围：整数类型，取值范围为0～255。 默认值：无                                                   |

#### 使用实例

修改NBMA网络中IP地址为10.1.1.1的邻居设备的优先级为100：

```
MOD OSPFPEER:PROCID=1,IPADDRESS="10.1.1.1",DRPRIORITY=100;
```
