# 设置ServingPlmn映射功能（SET SRVPLMNMAPFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、MME**

该命令用于设置Serving PLMN映射功能。

当运营商增加了新的Serving PLMN时，例如漫游场景下，希望后端HSS、SGW、UDM、SMF和PCF等网元不感知新的Serving PLMN，还是按照之前已有Serving Plmn处理用户业务，可以使用此命令配置是否启用Serving PLMN映射功能，映射关系使用ADD SRVPLMNMAP进行配置。

## 注意事项

- 该命令执行后立即生效。

- PRA/MEC相关当前只支持AMF匹配PRA场景，不支持PRA区域下发给基站时进行映射。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| MAPSW   | USRCTRL   | TYPE5G                                                                                | TYPE4G                  | PRAMECSW   |
|:--------|:----------|:--------------------------------------------------------------------------------------|:------------------------|:-----------|
| OFF     | ALL_USER  | UDM-1&SMF-1&PCF-1&EVENT_EXPOSURE-1&NF_DISCOVER_ALL-1&NF_DISCOVER_SPECNF-1&DNS_QUERY-1 | HSS-1&SGW-1&DNS_QUERY-1 | OFF        |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称          | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                       |
|:---------|:--------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MAPSW    | 映射功能开关        | 可选必选说明：必选参数  参数含义：该参数用于配置支持Serving PLMN映射功能控制开关。  数据来源：全网规划 取值范围： “OFF（关闭）”：关闭“ON（打开）”：打开  默认值：无。  配置原则：无                                                                                                                                                                                                                                                                                                                  |
| USRCTRL  | 用户范围控制        | 可选必选说明：该参数在"MAPSW"配置为"ON"时为条件可选参数。  参数含义：该参数用于控制支持Serving PLMN映射功能的用户范围。  数据来源：全网规划 取值范围： “ALL_USER（全部用户）”：全部用户“ROAM_USER（漫游用户）”：漫游用户  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST SRVPLMNMAPFUNC查询当前参数配置值。  配置原则：无                                                                                                                                                                                                            |
| TYPE5G   | 5G消息类型        | 可选必选说明：该参数在"MAPSW"配置为"ON"时为条件可选参数。  参数含义：该参数用于控制5G制式下进行Serving PLMN映射的消息类型。  数据来源：全网规划 取值范围： “UDM（UDM相关消息）”：UDM相关消息“SMF（SMF相关消息）”：SMF相关消息“PCF（PCF相关消息）”：PCF相关消息“EVENT_EXPOSURE（事件订阅消息）”：事件订阅消息“NF_DISCOVER_ALL（所有服务发现消息）”：所有服务发现消息“NF_DISCOVER_SPECNF（指定网元的服务发现消息）”：指定网元（AUSF/UDM/SMF/PCF）的服务发现消息“DNS_QUERY（DNS请求消息）”：使用TAI/MMEID组成FQDN进行DNS记录查询  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST SRVPLMNMAPFUNC查询当前参数配置值。  配置原则：无 |
| TYPE4G   | 4G消息类型        | 可选必选说明：该参数在"MAPSW"配置为"ON"时为条件可选参数。  参数含义：该参数用于控制4G制式下进行Serving PLMN映射的消息类型。  数据来源：全网规划 取值范围： “HSS（HSS相关消息）”：HSS相关消息“SGW（SGW相关消息）”：SGW相关消息“DNS_QUERY（DNS请求消息）”：使用TAI/MMEID/AMFID组成FQDN进行DNS记录查询  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST SRVPLMNMAPFUNC查询当前参数配置值。  配置原则：无                                                                                                                                                   |
| PRAMECSW | PRA和MEC区域映射开关 | 可选必选说明：该参数在"MAPSW"配置为"ON"时为条件可选参数。  参数含义：该参数用于配置对于其他网元下发的PRA区域，以及AMF/MME通过命令配置的MEC/PRA区域，支持AMF/MME本地Serving PLMN映射之后再进行区域匹配。 AMF配置涉及：ADD MECAREATAI、ADD MECAREAGNB和ADD NGPRAMEM； MME配置涉及：ADD PRALSTMEM。  数据来源：全网规划 取值范围： “OFF（关闭）”：关闭“ON（打开）”：打开  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST SRVPLMNMAPFUNC查询当前参数配置值。  配置原则：无                                                                                                 |

## 使用实例

设置映射功能开启，设置用户范围控制为漫游用户：

```
SET SRVPLMNMAPFUNC:MAPSW=ON,USRCTRL=ROAM_USER;
```
