# 查询中转UPF与Radius客户端的绑定关系（LST UPFRDSCLIENTIP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于查询中转UPF与Radius客户端的绑定关系。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                                                                                                    |
|:-----------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CLIENTYPE  | 客户端类型   | 可选必选说明：可选参数  参数含义：该参数用于指定RADIUS客户端类型。  数据来源：本端规划 取值范围： “AUTHENTICATION（鉴权客户端）”：表示鉴权客户端。“ACCOUNTING（计费客户端）”：表示计费客户端。“ACCT_AND_AUTH（计费和鉴权客户端）”：表示计费和鉴权客户端。  默认值：无  配置原则：无 |
| IPVERSION  | 客户端IP版本 | 可选必选说明：可选参数  参数含义：该参数用于指定RADIUS客户端IP地址类型。  数据来源：全网规划 取值范围： “IPV4（IPv4）”：IPv4“IPV6（IPv6）”：IPv6  默认值：无  配置原则：无                                                            |
| CLIENTIPV4 | IPv4地址  | 可选必选说明：该参数在"IPVERSION"配置为"IPV4"时为条件可选参数。  参数含义：该参数用于指定RADIUS客户端IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无                                                        |
| CLIENTIPV6 | IPv6地址  | 可选必选说明：该参数在"IPVERSION"配置为"IPV6"时为条件可选参数。  参数含义：该参数用于指定RADIUS客户端IPv6地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无                                                        |

## 使用实例

如果想要查询UPF中转Radius客户端IP配置信息：

```
LST UPFRDSCLIENTIP:;
RETCODE = 0  操作成功

结果如下
--------
  客户端类型  =  鉴权服务器
客户端IP版本  =  IPv4
  UP实例标识  =  up1
     VPN实例  =  NULL
客户端IP地址  =  192.168.10.1
(结果个数 = 1)

---    END
```
