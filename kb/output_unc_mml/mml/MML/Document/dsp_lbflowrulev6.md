# 查询业务IPv6引流规则（DSP LBFLOWRULEV6）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询业务IPv6引流规则。引流规则由业务VNFC下发，用来指示业务流和业务VNFC服务实例的关联关系。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                            |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RULETYPE | 引流规则类型 | 可选必选说明：必选参数 参数含义：该参数表示引流规则类型。 数据来源：本端规划 默认值：无 取值范围：“TRIPLE(三元组引流规则)”：即使用目的IP，目的端口号和协议类型来确定一个服务VNFC实例。“QUINT(五元组引流规则)”：即使用目的IP，目的端口号，源IP，源端口号和协议类型来确定一个服务VNFC实例。 |
| DSTIPV6  | 目的IPv6 | 可选必选说明：条件必选参数 参数含义：本参数表示目的IPv6地址。 前提条件：该参数在"引流规则类型"参数配置为"三元组引流规则"或"五元组引流规则"后生效。 数据来源：本端规划 默认值：无 取值范围：::~FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF                 |
| SRCIPV6  | 源IPv6  | 可选必选说明：条件必选参数 参数含义：本参数表示源IPv6地址。 前提条件：该参数在"引流规则类型"参数配置为"五元组引流规则"后生效。 数据来源：本端规划 默认值：无 取值范围：::~FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF                            |
| VPNNAME  | VPN名称  | 可选必选说明：必选参数 参数含义：本参数表示引流规则中的VPN名称。 数据来源：本端规划 默认值：无 取值范围：0 ~ 31位字符串  说明： 公网填“_public_”。                                                                          |
| DSTPORT  | 目的端口号  | 可选必选说明：条件必选参数 参数含义：本参数表示引流规则中的目的端口。 前提条件：该参数在"引流规则类型"参数配置为"三元组引流规则"或"五元组引流规则"后生效。 数据来源：本端规划 默认值：无 取值范围：0~65535。                                                 |
| SRCPORT  | 源端口号   | 可选必选说明：条件必选参数 参数含义：本参数表示引流规则中的源端口。 前提条件：该参数在"引流规则类型"参数配置为"五元组引流规则"后生效。 数据来源：本端规划 默认值：无 取值范围：0~65535。                                                            |
| PROTO    | 协议类型   | 可选必选说明：条件必选参数 参数含义：本参数表示引流规则中的协议类型。 前提条件：该参数在"引流规则类型"参数配置为"三元组引流规则"或"五元组引流规则"后生效。 数据来源：本端规划 默认值：无 取值范围：0~255。常用的协议类型有6（TCP）和17（UDP）。                            |

#### 使用实例

查询所有引流规则类型为三元组引流规则，目的IPv6为2001:0db8:ffff:ffff:ffff:ffff:ffff:ffff，VPN名称为VPN1，目的端口为1，协议为17的业务VNFCID与业务VNFC服务实例ID的详细信息：

`DSP LBFLOWRULEV6: RULETYPE=TRIPLE, DSTIPV6="2001:0db8:ffff:``ffff:ffff:ffff:ffff:ffff", VPNNAME="VPN1", DSTPORT=1, PROTO=17;`

```
%%DSP LBFLOWRULEV6: RULETYPE=TRIPLE, DSTIPV6="2001:0db8:ffff:ffff:ffff:ffff:ffff:ffff", VPNNAME="VPN1", DSTPORT=1, PROTO=17;%%
RETCODE = 0  操作成功。

操作结果如下：
--------------
业务VNFCID    业务VNFC服务实例ID

4             0                 
4             1                 
(结果个数 = 2)
---    END
```
