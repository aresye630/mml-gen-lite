# 显示NB流控状态统计(DSP NBFCSTAT)

#### 命令功能

**适用网元：MME**

该命令用于显示NB-IoT流控功能的相关状态和统计信息。

#### 注意事项

无

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                     |
|:----------|:-------|:-------------------------------------------------------------------------------------------------------------------------|
| QUERYTYPE | 查询方式   | 可选必选说明：可选参数 参数含义：该参数用于指定NB-IoT流控状态统计信息的查询方式。 数据来源：本端规划 取值范围：“ALL(整系统查询)”“PROC(按进程查询)” 默认值：“ALL(整系统查询)”                   |
| RUNAME    | RU名称   | 可选必选说明：条件必选参数 参数含义：该参数用于指定SPU资源单元名称。该参数可以通过DSP RU命令查询。 前提条件：该参数在“查询方式”配置为“PROC(按进程查询)”后生效。 数据来源：本端规划 取值范围：1～63位字符串 默认值：无 |
| PROCNO    | 进程号    | 可选必选说明：条件必选参数 参数含义：该参数用于指定需要查看流控状态信息对应SPP进程的进程号。 前提条件：该参数在“查询方式”配置为“PROC(按进程查询)”后生效。 数据来源：本端规划 取值范围：0～20 默认值：无           |

#### 使用实例

按照“查询方式为ALL(整系统查询)”显示NB-IoT流控状态统计：

DSP NBFCSTAT: QUERYTYPE=ALL;

```
%%DSP NBFCSTAT: QUERYTYPE=ALL;%%
RETCODE = 0  操作成功。
```

#### 输出结果说明

| 输出项名称     | 输出项解释                                                                                                                              |
|:----------|:-----------------------------------------------------------------------------------------------------------------------------------|
| RU名称      | 该参数用于显示SPP进程所属的资源单元名称。                                                                                                             |
| 进程号       | 该参数用于显示SPP进程序号。                                                                                                                    |
| 流控告警状态    | 参数含义：该参数用于显示NB-IoT流控告警状态。 取值范围： 功能关闭：表示NB-IoT流控功能未开启。正常状态：表示功能开启，但非ALM-80684 NB-IoT信令拥塞流控告警状态。告警状态：表示处于ALM-80684 NB-IoT信令拥塞流控告警状态。 |
| 流控速率（个/秒） | 参数含义：该参数用于显示系统每个SPP进程允许通过的NB-IoT业务消息的速率。 取值范围：0～2000                                                                               |
| 通过量（个）    | 参数含义：该参数用于显示NB-IoT业务通过的消息包数总量累计值，超出取值范围后会重新计数。 取值范围：0～4294967295                                                                   |
| 拒绝量（个）    | 参数含义：该参数用于显示NB-IoT业务拒绝的消息包数总量累计值，超出取值范围后会重新计数。 取值范围：0～4294967295                                                                   |
