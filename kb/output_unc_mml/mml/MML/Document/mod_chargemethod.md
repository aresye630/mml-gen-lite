# 修改计费方式（MOD CHARGEMETHOD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

MOD CHARGEMETHOD命令用来基于用户计费属性修改在线计费、离线计费和融合计费方式。

#### 注意事项

该命令执行后只对新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                            |
|:--------------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CHARGECHARACT | 计费属性     | 可选必选说明：必选参数 参数含义：该参数用于指定计费属性。 数据来源：全网规划 取值范围：枚举类型。 PREPAID：表示要配置计费属性为预付费，对应的特殊CC值为0x0400。NORMAL：表示要配置计费属性为普通计费，对应的特殊CC值为0x0800。HOT_BILLING：表示要配置计费属性为热计费，对应的特殊CC值为0x0100。FLAT_BILLING：表示要配置计费属性为统一费率，对应的特殊CC值为0x0200。SPECIFIC_VALUE：表示要配置计费属性为特殊CC值。DEFAULT：表示要配置计费属性为缺省，对应的特殊CC值为0x0000。 默认值：无 配置原则：无          |
| CCVALUE       | 计费属性值    | 可选必选说明：条件必选参数 前提条件：该参数在“CHARGECHARACT”配置为“SPECIFIC_VALUE”时为必选参数。 参数含义：该参数用于指定特殊的CC值。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～6。该参数为十六进制数据类型，仅支持输入0x/X、a-f/A-F 、0-9，允许不输入0x前缀，字母不区分大小写，取值范围0x0000~0xFFFF。 默认值：无 配置原则：无                                                                                                     |
| MASK          | 计费属性掩码   | 可选必选说明：条件可选参数 前提条件：该参数在“CHARGECHARACT”配置为“SPECIFIC_VALUE”时为可选参数。 参数含义：该参数用于指定计费属性的掩码。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～6。该参数为十六进制数据类型，仅支持输入0x/X、a-f/A-F 、0-9，允许不输入0x前缀，字母不区分大小写，取值范围0x0001~0xFFFF。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。                                                                                    |
| PRIORITY      | 计费属性优先级  | 可选必选说明：条件可选参数 前提条件：该参数在“CHARGECHARACT”配置为“SPECIFIC_VALUE”时为可选参数。 参数含义：该参数用于设置优先级。在计费属性值相同时，不允许指定相同的优先级。配置mask时必须指定优先级。 数据来源：全网规划 取值范围：整数类型，取值范围为1～65535。 默认值：无 配置原则：优先级的初始值为0。                                                                                                                                  |
| ONLINE        | 在线计费开关   | 可选必选说明：可选参数 参数含义：该参数用于配置用户是否开启在线计费功能。 数据来源：全网规划 取值范围：枚举类型。 DISABLE：否。ENABLE：是。 默认值：无 配置原则：无                                                                                                                                                                                                                     |
| OFFLINE       | 离线计费开关   | 可选必选说明：可选参数 参数含义：该参数用于配置用户是否开启离线计费功能。 数据来源：全网规划 取值范围：枚举类型。 DISABLE：否。ENABLE：是。 默认值：无 配置原则：无                                                                                                                                                                                                                     |
| CONVERGED     | 融合计费开关   | 可选必选说明：可选参数 参数含义：该参数用于配置用户是否开启融合计费功能。 数据来源：全网规划 取值范围：枚举类型。 DISABLE：否。ENABLE：是。 默认值：无 配置原则：无                                                                                                                                                                                                                     |
| RGAPPLIED     | 业务申请上报模式 | 可选必选说明：条件可选参数 前提条件：该参数在“CONVERGED”配置为“ENABLE”时为可选参数。 参数含义：该参数用于指定SMF与CHF交互时的业务申请上报模式。 数据来源：全网规划 取值范围：枚举类型。 DEFAULT：融合业务申请上报模式，表示在线RG与离线RG均可向CHF进行业务申请和上报。ONLINERGONLY：在线业务申请上报模式，表示仅在线RG向CHF进行业务申请和上报，不能使用离线RG。OFFLINERGONLY：离线业务申请上报模式，表示仅离线RG向CHF进行业务申请和上报，不能使用在线RG。NOCHG：配置非QBC计费场景下，不使能融合计费功能。 默认值：无 配置原则：无 |
| QBCSW         | QBC计费开关  | 可选必选说明：条件可选参数 前提条件：该参数在“CONVERGED”配置为“ENABLE”时为可选参数。 参数含义：该参数设置QBC计费场景下，是否使能计费功能。 数据来源：全网规划 取值范围：枚举类型。 ENABLE：使能计费功能。DISABLE：不使能计费功能。 默认值：无 配置原则：无                                                                                                                                                              |

#### 使用实例

修改计费属性为0x0400的离线计费不使能，在线计费使能：

```
MOD CHARGEMETHOD: CHARGECHARACT=SPECIFIC_VALUE, CCVALUE="0x400", MASK="0x400", PRIORITY=2, ONLINE=ENABLE, OFFLINE=DISABLE;
```
