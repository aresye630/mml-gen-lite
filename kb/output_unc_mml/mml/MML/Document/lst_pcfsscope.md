# 查询PCF的业务服务区（LST PCFSSCOPE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF、PGW-C、GGSN**

该命令用于查询PCF的业务服务区。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                             |
|:---------|:-------|:-------------------------------------------------------------------------------------------------|
| SSCOPEID | 服务区标识  | 可选必选说明：可选参数  参数含义：该参数用于指定服务区标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。不区分大小写，转为小写存储。  默认值：无  配置原则：无 |

## 使用实例

- 查询服务区标识为citya的PCF业务服务区。

  ```
  LST PCFSSCOPE:SSCOPEID="citya";
  RETCODE = 0  操作成功

  结果如下
  --------
  服务区标识  =  citya
  服务区名称  =  City_A
  (结果个数 = 1)

  ---    END
  ```
- 查询所有PCF业务服务区。

  ```
  LST PCFSSCOPE:;
  RETCODE = 0  操作成功

  结果如下
  --------
  服务区标识  =  citya
  服务区名称  =  City_A
  (结果个数 = 1)

  ---    END
  ```

## 输出结果说明

| 输出项名称   | 输出项解释         |
|:--------|:--------------|

| 服务区名称   | 该参数用于指定服务区名称。 |
