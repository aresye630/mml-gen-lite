# 修改TAI路由（MOD NRFTAIRT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于在NRF上修改指定NF支持的TAI路由所归属的NRF实例组名称。

## 注意事项

- 该命令执行后立即生效。

- 根据输入参数条件，如果待修改的记录在系统中只存在一条，则直接执行此命令进行修改。
- 根据输入参数条件，如果待修改的记录在系统中可以匹配到多条，则系统无法判断待修改记录具体是哪一条，不能通过此MOD命令进行修改，此时需要执行对应的RMV记录先删除待修改记录，再执行对应ADD命令新增新的记录（修改后的记录）完成修改。
- 主备或双活组网的场景下，如果需要配置此命令，则两个NRF上均需执行此命令，且配置参数一致。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                                                                |
|:---------------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFTYPE         | NF类型     | 可选必选说明：必选参数  参数含义：该参数用于表示NF类型。  数据来源：全网规划 取值范围： SMF（SMF）AMF（AMF）NWDAF（NWDAF）  默认值：无  配置原则：  当前NRF仅支持NFTYPE为SMF、AMF、NWDAF的路由转发功能，其他NF类型为预留功能。                        |
| MCC            | 移动国家码    | 可选必选说明：必选参数  参数含义：该参数用于表示移动国家码。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。3位十进制数。  默认值：无  配置原则：无                                                                                |
| MNC            | 移动网号     | 可选必选说明：必选参数  参数含义：该参数用于表示移动网号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。2位或者3位十进制数。  默认值：无  配置原则：无                                                                         |
| TACSTART       | TAC起始字符  | 可选必选说明：必选参数  参数含义：该参数用于表示TAI路由的TAC起始字符。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~50。该参数只能由字母（A-F或者a-f）、数字（0-9）组成。  默认值：无  配置原则：无                                             |
| TACEND         | TAC结束字符  | 可选必选说明：必选参数  参数含义：该参数用于表示TAI路由的TAC结束字符。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~50。该参数只能由字母（A-F或者a-f）、数字（0-9）组成。  默认值：无  配置原则：无                                             |
| NEXTNRFGRPNAME | 归属NRF组名称 | 可选必选说明：可选参数  参数含义：该参数用于表示当前NRF基于TAI寻址NF时的下一跳NRF实例组名称，被寻址的NF归属于该NRF实例组。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~64。  默认值：无  配置原则：  该参数已通过ADD NRFGROUP配置，可通过LST NRFGROUP命令获取。 |

## 使用实例

运营商网络规划变更，当前NRF上寻址的SMF, 移动国家码为123，移动网号为456，TAC起始字符为000001，TAC结束字符为000100的TAI路由下一跳路由发生变化，SMF所归属的NRF实例组名称由“L-NRF1”变为“L-NRF2”，需要执行：

```
MOD NRFTAIRT: NFTYPE=SMF, MCC="123", MNC="456", TACSTART="000001", TACEND="000100", NEXTNRFGRPNAME="L-NRF2";
```
