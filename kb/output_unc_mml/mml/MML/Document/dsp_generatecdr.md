# 查询强制生成话单结果（DSP GENERATECDR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

该命令用来查询上次强制产生用户话单结果信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询上次强制产生所有用户话单信息：

```
DSP GenerateCDR:;
```

```
RETCODE = 0 操作成功

上次强制话单生成结果
-------------------------
                    POD名称  =  uncpod-012-30-0-243__1020__0
                       时间  =  2015-08-21 14:17:47
                 成功话单数  =  1
                 失败话单数  =  0
                     结果  =  成功
(结果个数 = 1)

---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释        |
|:--------|:-------------|
| POD名称   | 用于指定POD名称。   |
| 时间      | 上次强制产生话单的时间。 |
| 成功话单数   | 成功话单数。       |
| 失败话单数   | 失败话单数。       |
| 结果      | 上次强制生成话单的结果。 |
