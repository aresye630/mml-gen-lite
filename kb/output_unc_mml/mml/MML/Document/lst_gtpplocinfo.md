# 查询GTPP本端信息（LST GTPPLOCINFO）

- 命令功能
- 注意事项
- 操作用户权限

#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

该命令用于查询GTPP本端信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询GTPP本端信息：

```
LST GTPPLOCINFO:;
```

```
RETCODE = 0  操作成功

GTPP本端主机信息
----------------
    本端主机名  =  test
      本端域名  =  test
业务上下文标识  =  abc
    本端接口名  =  gaif1/0/1
(结果个数 = 1)

---    END
```
