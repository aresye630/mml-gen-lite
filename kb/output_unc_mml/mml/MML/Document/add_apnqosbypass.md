# 增加BYPASS场景QoS描述配置（ADD APNQOSBYPASS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于UDM全故障BYPASS场景下设置指定APN的QoS的描述信息。

## 注意事项

- 该命令执行后只对新激活用户生效。

- 当本配置APNQOSBYPASS与SET COMMQOSBYPASS同时配置时，优先生效本配置APNQOSBYPASS。
- 当某APN未配置APNQOSBYPASS时，则会默认生效SET COMMQOSBYPASS功能。

- 最多可输入20000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                         |
|:------------|:----------|:-----------------------------------------------------------------------------------------------------------------------------|
| APN         | APN名称     | 可选必选说明：必选参数  参数含义：该参数用来指定APN名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。  默认值：无  配置原则：  该参数使用ADD APN或者ADD APNALIAS命令配置生成。         |
| SUBQOSINDEX | 5G用户QoS索引 | 可选必选说明：必选参数  参数含义：该参数表示用户QoS索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：  该取值必须和ADD 5GCSUBQOS中配置的“SUBQOSINDEX”参数取值相同。 |

## 使用实例

当UDM全故障进入BYPASS状态时，需要设置用户的QoS信息，此时增加APNQOSBYPASS配置信息：

```
ADD APNQOSBYPASS:APN="huawei.com",SUBQOSINDEX=5;
```
