# 删除过滤组（RMV FILTERGP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于删除过滤组。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                |
|:-----------|:-------|:------------------------------------------------------------------------------------|
| FILTERGPID | 过滤组ID  | 可选必选说明：必选参数  参数含义：该参数用于指定过滤组唯一标识。  数据来源：本端规划  取值范围：整数类型，取值范围是0~1023。  默认值：无  配置原则：无 |

## 使用实例

删除指定过滤组ID是1的过滤组：

```
RMV FILTERGP: FILTERGPID=1;
```
