# 删除手工恢复GGSN地址(RMV USRCTLGGSN)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

此命令用于删除已配置的手工恢复GGSN地址。

#### 注意事项

- 该命令执行后立即生效。
- 该命令执行后，指定的GGSN在故障恢复后无需手动恢复就会重新被启用。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                        |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPT    | IP地址类型 | 可选必选说明：必选参数 参数含义：此参数指定要删除的GGSN地址的IP类型。 取值范围：“IPV4(IPv4)”“IPV6(IPv6)” 默认值：无                                                                                                                                                                                                  |
| IPV4   | IPv4地址 | 可选必选说明：条件必选参数 参数含义：此参数指定待删除的GGSN网元的IPv4地址。 前提条件：该参数在“IP地址类型”设置为“IPV4(IPv4)”时生效。 取值范围：0.0.0.0~255.255.255.255 默认值：无  说明： “0.0.0.0”和“255.255.255.255”是无效的IP地址。 配置原则：IPv4地址不能为0.0.0.0、255.255.255.255和0.x.y.z。IPv4地址不能为组播地址（如：224.x.y.z）和环回地址(如：127.x.y.z)。IPv4地址必须是A、B或者C类地址。 |
| IPV6   | IPv6地址 | 可选必选说明：条件必选参数 参数含义：此参数指定待删除的GGSN网元的IPv6地址。 前提条件：该参数在“IP地址类型”设置为“IPV6(IPv6)”时生效。 取值范围： ::~FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无                                                                                                                                      |

#### 使用实例

删除需手工恢复GGSN地址192.168.66.6：

RMV USRCTLGGSN: IPT=IPV4, IPV4="192.168.66.6";
