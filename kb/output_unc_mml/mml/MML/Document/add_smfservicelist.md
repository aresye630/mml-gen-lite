# 增加特定SMF功能实例服务名（ADD SMFSERVICELIST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

本命令用于添加特定SMF功能实例服务。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入100条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                               |
|:------------|:-------|:-----------------------------------------------------------------------------------|
| SERVICENAME | 服务名称   | 可选必选说明：必选参数  参数含义：特定SMF功能实例服务名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~65。  默认值：无  配置原则：无 |

## 使用实例

添加SMF服务名称：

```
ADD SMFSERVICELIST: SERVICENAME="SMF-SERVICENAME001";
```
