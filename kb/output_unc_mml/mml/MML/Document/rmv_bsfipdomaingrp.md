# 删除IPDOMAIN组（RMV BSFIPDOMAINGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除IPDOMAIN组。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称       | 参数说明                                                                                     |
|:---------|:-----------|:-----------------------------------------------------------------------------------------|
| GRPNAME  | IPDOMAIN组名 | 可选必选说明：必选参数  参数含义：该参数用于指定IPDOMAIN组名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。  默认值：无  配置原则：无  |
| IPDOMAIN | IPDOMAIN名称 | 可选必选说明：必选参数  参数含义：该参数用于指定IPDOMAIN名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~255。  默认值：无  配置原则：无 |

## 使用实例

在IPDOMAIN组"ipdomaingroup1"中删除IPDOMAIN信息"Domain\_0"：

```
RMV BSFIPDOMAINGRP: GRPNAME="ipdomaingroup1", IPDOMAIN="Domain_0";
```
