# 删除自动上报的NSE下的本端端点(RMV AUTOLOCEP)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

- 此命令会导致删除端点的IPNSVC链路无法再承载业务。
- 删除NSE下唯一的本端端点会导致NSE相关业务不可用。

**适用网元：SGSN**

此命令用于删除自动上报的动态Gb over IP的NSE下的本端端点。自动上报的动态Gb over IP的NSE的属性和端点信息请通过**DSP NSE**命令和**DSP IPNSVC**命令查询。

#### 注意事项

- 此命令执行后立即生效。
- 此命令会导致删除端点的IPNSVC链路无法再承载业务。
- 删除NSE下唯一的本端端点会导致NSE相关业务不可用。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                                                                                                 |
|:------------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NSEI        | NSE标识    | 可选必选说明：必选参数 参数含义：该参数用于指定待删除的本端端点的网络服务实体标识。 取值范围：0～65535 默认值：无                                                                                                                                                                                        |
| IPTYPE      | IP类型     | 可选必选说明：必选参数 参数含义：该参数用于指定待删除的本端端点的IP地址类型。 取值范围：“IPV4(IPv4)”“IPV6(IPv6)” 默认值：无 配置原则：系统目前仅支持IPV4地址。                                                                                                                                                     |
| LOCIPV4ADDR | 本端IPv4地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定待删除的本端端点的IPv4地址。 前提条件：该参数在“ IP类型 ”设置为“IPV4(IPv4)”时生效。 取值范围：0.0.0.1～255.255.255.254 默认值：无  说明： 有效的IPv4地址不能为环回地址(127.x.y.z)。有效的IPv4地址必须是A、B或者C类地址。                                                                           |
| LOCIPV6ADDR | 本端IPv6地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定待删除的本端端点的IPv6地址。 前提条件：该参数在“ IP类型 ”设置为“IPV6(IPv6)”时生效。 取值范围：::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无  说明： IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址(::1)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。 |
| LOCPORT     | 本端端口号    | 可选必选说明：必选参数 参数含义：该参数用于指定待删除的本端端点的端口号。 取值范围：1024～65535 默认值：无                                                                                                                                                                                          |

#### 使用实例

删除一个“NSE标识”为“1”“IP类型”为“IPV4(IPv4)”，“本端IPv4地址”为“192.168.4.101”，“本端端口号”为“1024”的自动上报的NSE下的本端端点：

RMV AUTOLOCEP: NSEI=1, IPTYPE=IPV4, LOCIPV4ADDR="192.168.4.101", LOCPORT=1024;
