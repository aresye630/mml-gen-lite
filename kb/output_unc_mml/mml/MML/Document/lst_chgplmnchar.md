# 查询PLMN的计费属性参数(LST CHGPLMNCHAR)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用网元：SGSN**

该命令用于查询PLMN类型的用户计费属性参数的配置。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                    |
|:-------|:--------|:------------------------------------------------------------------------------------------------------------------------|
| PLMN   | PLMN 类型 | 可选必选说明：必选参数 参数含义：该参数用于运营商对不同PLMN用户的话单生成采取不同的策略。 取值范围：“HPLMN（本地 PLMN）”：表示本网用户。“VPLMN（拜访 PLMN）”：表示拜访用户，非本网用户即拜访用户 。 默认值：无 |

#### 使用实例

查询普通计费属性的配置信息：

LST CHGPLMNCHAR: PLMN=HPLMN;

```
%%LST CHGPLMNCHAR: PLMN=HPLMN;%%
RETCODE = 0  操作成功。

输出结果如下
------------
```
