# 删除设置路由开销值（RMV APPLYCOST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除匹配路由开销值。

#### 注意事项

- 该命令执行后立即生效。
- 配置该命令前，必须已经配置了指定路由策略的名字以及该策略下的节点。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                                |
|:-------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------|
| POLICYNAME   | 路由策略名字  | 可选必选说明：必选参数 参数含义：该参数用于指定路由策略名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无                                                            |
| NODESEQUENCE | 路由策略节点号 | 可选必选说明：必选参数 参数含义：该参数用于指定路由策略节点号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无                                                            |
| APPLYCHOICE  | 应用选择    | 可选必选说明：必选参数 参数含义：该参数用于指定设置方式。 数据来源：本端规划 取值范围：枚举类型。 Add：加上路由的原有开销值。Sub：减去路由的原有开销值。Replace：代替路由的原有开销值。Inherit：继承路由的原有开销值。 默认值：无       |
| COSTVALUE    | Cost值   | 可选必选说明：条件必选参数 前提条件：该参数在“APPLYCHOICE”配置为“Replace”、“Add” 或 “Sub”时为必选参数。 参数含义：该参数用于指定开销值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无 |

#### 使用实例

路由策略a节点10，取消设置路由开销：

```
RMV APPLYCOST:NODESEQUENCE=10,COSTVALUE=10,POLICYNAME="a", APPLYCHOICE=Replace;
```
