# 显示GTP-C链路信息（DSP GTPCPATHINFO）

## 命令功能

**适用NF：AMF、PGW-C、SGW-C、GGSN**

该命令用于查询GTP-C路径信息。

## 注意事项

- 当“接口类型”未输入时，默认查询所有接口类型的路径状态信息。
- 当“查询类型”未输入时，默认查询内存(MEMORY)中的路径状态信息。
- 当“查询类型”为“内存(MEMORY)”时，不显示“对端Recovery值”、“路径断去激活会话时间”、“对端Recovery变化去激活会话时间”信息。
- 当“路径状态筛选”未输入时，默认查询路径状态为故障(Error)的路径状态信息。
- 当SET AMFN26PLCY命令中N26ITFMODE取值为“COMBINE”时，当前命令无效，请使用命令DSP GTPCPATH查询。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识            | 参数名称     | 参数说明                                                                                                                                                                                                                         |
|:----------------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GTPVER          | GTP版本    | 可选必选说明：必选参数  参数含义：该参数用于指定GTP-C路径的GTP版本号。  数据来源：全网规划 取值范围： GTPv1（GTPv1）GTPv2（GTPv2）  默认值：无  配置原则：无                                                                                                                            |
| IPTYPE          | IP地址类型   | 可选必选说明：必选参数  参数含义：该参数用于指定GTP-C路径的IP地址类型。  数据来源：全网规划 取值范围： “IPTypeV4（IPv4类型）”：IPTypeV4“IPTypeV6（IPv6类型）”：IPTypeV6  默认值：无  配置原则：无                                                                                              |
| LOCALIPV4       | 本端IPv4地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPTypeV4"时为条件可选参数。  参数含义：该参数用于指定GTP-C路径的本端IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：  业务地址不能配置为0.0.0.0、255.255.255.255和环回地址(127.x.y.z)。  业务地址必须是A、B或者C类地址。                                      |
| LOCALIPV6       | 本端IPv6地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPTypeV6"时为条件可选参数。  参数含义：该参数用于指定GTP-C路径的本端IPv6地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：  IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址(::1)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。 |
| PEERIPV4        | 对端IPv4地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPTypeV4"时为条件可选参数。  参数含义：该参数用于指定GTP-C路径的对端IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：  业务地址不能配置为0.0.0.0、255.255.255.255和环回地址(127.x.y.z)。  业务地址必须是A、B或者C类地址。                                      |
| PEERIPV6        | 对端IPv6地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPTypeV6"时为条件可选参数。  参数含义：该参数用于指定GTP-C路径的对端IPv6地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：  IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址(::1)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。 |
| PATHST          | 路径状态筛选   | 可选必选说明：可选参数  参数含义：该参数用于指定查询GTP-C路径的状态。  数据来源：本端规划 取值范围： ERROR（故障）NORMAL（正常）ALL（所有）  默认值：ERROR  配置原则：无                                                                                                                        |
| QRYTP           | 查询类型     | 可选必选说明：可选参数  参数含义：该参数用于指定查询类型。  数据来源：本端规划 取值范围： MEMORY（内存）DDB（数据库）  默认值：MEMORY  配置原则：无                                                                                                                                       |
| INTERFACETYPEIN | 接口类型     | 可选必选说明：可选参数  参数含义：该参数用于指定GTP-C路径的接口类型。  数据来源：本端规划 取值范围： Unknow（未知接口）Gn（Gn接口）Gp（Gp接口）S5（S5接口）S8（S8接口）S11（S11接口）N26（N26接口）S4（S4接口）All（All）Proxy（Proxy接口）  默认值：All  配置原则：无                                                      |

## 使用实例

查询本端IP地址为10.1.12.3，对端IP地址为10.2.20.1，GTP版本号为GTPv2的GTP-C路径信息：DSP GTPCPATHINFO: GTPVER=GTPv2, IPTYPE=IPTypeV4, LOCALIPV4="10.1.12.3", PEERIPV4="10.2.20.1", PATHST=ALL;

```
%%DSP GTPCPATHINFO: GTPVER=GTPv2, IPTYPE=IPTypeV4, LOCALIPV4="10.1.12.3", PEERIPV4="10.2.20.1", PATHST=ALL;%%
RETCODE = 0  操作成功

结果如下
------------------------
   IP地址类型  =  IPTypeV4
 本端IPv4地址  =  10.1.12.3
 对端IPv4地址  =  10.2.20.1
      GTP版本  =  GTPv2
     路径状态  =  Normal
     接口类型  =  S5接口
      POD名称  =  uncpod-0
(结果个数 = 1)

---    END
```
