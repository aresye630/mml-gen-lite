# 增加TAI与LAI对应关系(ADD TAILAI)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限

- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于增加TAI与LAI的对应关系。在启用CSFB功能时，MME可以根据TAI获得对应的LAI。

#### 注意事项

- 该命令执行后立即生效。

- 该表最大记录数为10000。

- “起始TAI”、“用户范围”和“IMSI前缀”或“起始IMSI”的组合确定唯一一条TAI与LAI的对应关系记录。

- LAI可以重复，一个LAI可对应多个TAI区间。

- 针对用户群的TAI可以重复，同一个TAI或者同一连续TAI区段，“IMSI前缀”或“起始IMSI”不同可以对应不同LAI。

- 同一个TAI或者同一连续TAI区段，只允许配置一条“用户范围”为“ALL\_USER（所有用户）”的记录。

- 该命令部分参数与相关特性license共同完成该特性的开启，请在设置参数前使用**DSP LICENSE**命令确认对应特性license是否得到授权，执行**LST LICENSESWITCH**命令确认特性开关状态为“ENABLE（打开）”，具体相关特性请参考参数的说明。

输入的起始IMSI必须小于或者等于终止IMSI。判断起始IMSI和终止IMSI大小的原则是：对于输入IMSI的长度小于系统规定IMSI长度时， 将该IMSI补足0到规定长度后进行大小比较，且起始IMSI必须小于终止IMSI。只有输入IMSI长度等于系统规定长度时，起始IMSI才能等于终止IMSI。 对于系统规定IMSI长度为15的情况，如表1所示：

|          起始IMSI |          终止IMSI | 实际限定IMSI范围                                                              |
|----------------:|----------------:|:------------------------------------------------------------------------|
|       123002666 |          123002 | 增加记录失败，起始IMSI大于终止IMSI                                                   |
|          123002 |       123002666 | 123002000000000 ~ 123002666000000，即区间[123002000000000， 123002666000000] |
|          123002 |          123002 | 增加记录失败，起始IMSI不能等于终止IMSI                                                 |
| 123002000000000 | 123002000000000 | 仅限定IMSI号码123002000000000                                                |
| 123003000000000 | 123004000000000 | 123003000000000 ~ 123004000000000，即区间[123003000000000， 123004000000000] |

- 输入的起始IMSI和终止IMSI定义的IMSI号段范围不允许与其它记录定义的IMSI号段范围相互交叉、包含或重合。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| BGNTAI   | 起始TAI  | 可选必选说明：必选参数 参数含义：该参数用于指定跟踪区标识，标识一个起始跟踪区。 数据来源：整网规划 取值范围：9～10位的字符串 默认值：无 配置原则：起始TAI由MCC，MNC，TAC组成。MCC为3个BCD码字符，MNC为2个或者3个BCD码字符，填写时请遵循实际长度。TAC编码为16进制数，固定为4位，不足补0。新增的TAI区间不能和TAILAI表中已有的TAI区间存在交集。需要配置系统缺省LAI记录，则输入的TAI为“FFFFFFFFFF”。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ENDTAI   | 终止TAI  | 可选必选说明：可选参数 参数含义：该参数用于指定跟踪区标识，标识一个终止跟踪区。 数据来源：整网规划 取值范围：9～10位的字符串 默认值：无 配置原则：终止TAI由MCC，MNC，TAC组成。MCC为3个BCD码字符，MNC为2个或者3个BCD码字符，填写时请遵循实际长度。TAC编码为16进制数，固定为4位，不足补0。输入参数终止TAI要大于或等于起始TAI。如果未输入终止TAI或输入值等于起始TAI，则表示某个固定的TAI。新增的TAI区间不能和TAILAI表中已有的TAI区间存在交集。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| SELMODE  | 选择模式   | 可选必选说明：可选参数 参数含义：该参数用于表示选择LAI的匹配模式。 数据来源：整网规划 取值范围： “SUBRANGE(用户范围)”：匹配IMSI号段的用户。“HOST(主机名)”：匹配HSS主机名的用户。“REALM(域名)”：匹配HSS域名的用户。 默认值：“SUBRANGE(用户范围)” 配置原则：当用户能够匹配多条选择模式时，优先选择HOST(主机名)，次选REALM(域名)，再次选SUBRANGE(用户范围)对应的配置。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| HOST     | 主机名    | 可选必选说明：条件可选参数 参数含义：该参数用于指定用户HSS的主机名。 前提条件：该参数在“选择模式”参数设置为“HOST(主机名)”时，才需要配置。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～127。 默认值：无 配置原则： 不能为非法字符，只允许输入字母，数字，“.”和“-”。例如:hss.epc.mnc123.mcc123.3gppnetwork.org不允许配置字符串“null”。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| REALM    | 域名     | 可选必选说明：条件可选参数 参数含义：该参数用于指定用户HSS的域名。 前提条件：该参数在“选择模式”参数设置为“REALM(域名)”时，才需要配置。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～127。 默认值：无 配置原则: 不能为非法字符，只允许输入字母，数字，“.”和“-”，不区分大小写。例如：epc.mnc123.mcc123.3gppnetwork.org。不允许配置以“null”开头的字符串。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| SUBRANGE | 用户范围   | 可选必选说明：条件可选参数 参数含义：该参数用于指定用户的范围。 前提条件：该参数在“选择模式”参数设置为“SUBRANGE(用户范围)”时，才需要配置。 数据来源：整网规划 取值范围：“ALL_USER（所有用户）”：无匹配IMSI前缀的所有用户。“IMSI_PREFIX（指定IMSI前缀）”：IMSI前缀最长长度优先匹配的用户。“IMSI_RANGE（指定IMSI范围）”:IMSI范围匹配用户“USER_GROUP（用户群）”:用户群中的用户 默认值：“ALL_USER（所有用户）” 配置原则：当系统内存在多种用户范围的记录时，匹配的优先级由高到低为： “IMSI_PREFIX（指定IMSI前缀）”或“IMSI_RANGE（指定IMSI范围）”，“USER_GROUP（用户群）”，“ALL_USER（所有用户）”。同一个TAI或者同一连续TAI区段，最多只允许配置一条“USER_GROUP（用户群）”的记录。  说明： 当存在“用户范围”为“IMSI_PREFIX（指定IMSI前缀）”的记录时，不允许再添加“用户范围”为“IMSI_RANGE（指定IMSI范围）”的记录。同理，当存在“用户范围”为“IMSI_RANGE（指定IMSI范围）”的记录时，不允许再添加“用户范围”为“IMSI_PREFIX（指定IMSI前缀）”的记录。当开启“WSFD-102505 基于CSFB的Multi PLMN”特性时，系统会按照“IMSI_PREFIX（指定IMSI前缀）”记录或“IMSI_RANGE（指定IMSI范围）”记录，“USER_GROUP（用户群）”记录优先匹配。当关闭“WSFD-102505 基于CSFB的Multi PLMN”特性时，“IMSI_PREFIX（指定IMSI前缀）”记录，“IMSI_RANGE（指定IMSI范围）”记录和“USER_GROUP（用户群）”记录均不会生效。当关闭“WSFD-102505 基于CSFB的Multi PLMN”特性时，并且存在“IMSI_RANGE（指定IMSI范围）”记录和“ALL_USER（所有用户）”记录时，由软参BYTE_EX_B24 BIT6控制配置生效方式。 |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件必选参数 参数含义：该参数用于指定用户的IMSI前缀。系统根据该参数值对用户的IMSI进行匹配，从而区分不同的用户群。 前提条件：该参数在“用户范围”参数设置为“IMSI_PREFIX（指定IMSI前缀）”时，才需要配置。 数据来源：整网规划 取值范围：1～15位的数字 默认值：无  说明： 当“用户范围”设置为“IMSI_PREFIX（指定IMSI前缀）”时，基于CSFB的Multi PLMN特性相关的license授权并开启后，此参数配置才生效（特性编号：WSFD-102505，License部件编码：LKV2CSFB04）。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| BEGIMSI  | 起始IMSI | 可选必选说明：条件必选参数 参数含义：该参数用于指定起始IMSI。 前提条件：该参数在“用户范围”参数配置为“IMSI_RANGE（指定IMSI范围）”后生效。 数据来源：整网规划 取值范围：1~15位十进制数字字符串 默认值：无 配置原则：当起始IMSI与终止IMSI长度全为15位时，起始IMSI要小于等于终止IMSI，否则起始IMSI要小于终止IMSI。  说明： 当“用户范围”设置为“IMSI_RANGE（指定IMSI范围）”时，基于CSFB的Multi PLMN特性相关的license授权并开启后，此参数配置才生效（特性编号：WSFD-102505，License部件编码：LKV2CSFB04）。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ENDIMSI  | 终止IMSI | 可选必选说明：条件必选参数 参数含义：该参数用于指定终止IMSI。 前提条件：该参数在“用户范围”参数配置为“IMSI_RANGE（指定IMSI范围）”后生效。 数据来源：整网规划 取值范围：1~15位十进制数字字符串 默认值：无 配置原则：当终止IMSI与起始IMSI长度全为15位时，终止IMSI要大于等于起始IMSI，否则终止IMSI要大于起始IMSI。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| SUBID    | 用户群标识  | 可选必选说明：条件必选参数 参数含义：该参数用于指定用户群标识。 前提条件：该参数在“用户范围”参数设置为“USER_GROUP（用户群）”时，才需要配置。 数据来源：整网规划 取值范围：1～100 默认值：无 配置原则：该参数必须已经在ADD TAILAISUBGP配置。  说明： 当“用户范围”设置为“USER_GROUP（用户群）”时，基于CSFB的Multi PLMN特性相关的license授权并开启后，此参数配置才生效（特性编号：WSFD-102505，License部件编码：LKV2CSFB04）。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| LAI      | LAI    | 可选必选说明：必选参数 参数含义：该参数用于指定位置区标识，标识一个位置区。 前提条件：在“MML命令行-UNC”窗口上执行命令ADD LAIVLR设置此参数。 数据来源：整网规划 取值范围：9～10位的字符串 默认值：无 配置原则： LAI由MCC，MNC，LAC组成。MCC为3个BCD码字符，MNC为2个或者3个BCD码字符，填写时请遵循实际长度。LAC编码为16进制数，固定为4位，不足补0。LAI可以重复，一个LAI可对应多个TAI区间。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |

#### 使用实例

1. 增加“起始TAI”为“308014101”，“终止TAI”为“308014103”，“用户范围”为“ALL\_USER（所有用户）”，“LAI”为“308010001”的TAI与LAI对应关系：

   ADD TAILAI: BGNTAI="308014101", ENDTAI="308014103", SUBRANGE=ALL\_USER, LAI="308010001";
2. 增加“起始TAI”为“308015101”，“用户范围”为“IMSI\_PREFIX（指定IMSI前缀）”，“IMSI前缀”为“12345”，“LAI”为“308010002”的TAI与LAI对应关系：

   ADD TAILAI: BGNTAI="308015101", SUBRANGE=IMSI\_PREFIX, IMSIPRE="12345", LAI="308010002";
3. 增加“起始TAI”为“308015101”，“用户范围”为“IMSI\_PREFIX（指定IMSI前缀）”，“IMSI前缀”为“67890”，“LAI”为“308020003”的TAI与LAI对应关系：

   ADD TAILAI: BGNTAI="308015101", SUBRANGE=IMSI\_PREFIX, IMSIPRE="67890", LAI="308020003";
4. 增加“起始TAI”为“308015101”，“用户范围”为“IMSI\_RANGE（指定IMSI范围）”，“起始IMSI”为“567890”，“终止IMSI”为“567892”，“LAI”为“308020003”的TAI与LAI对应关系：

   ADD TAILAI: BGNTAI="308015101", SUBRANGE=IMSI\_RANGE, BEGIMSI="567890",ENDIMSI="567892", LAI="308020003";
