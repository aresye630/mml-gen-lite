# 查询IGMP加入源信息（DSP MGMDSOURCE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示IGMP加入源信息。

#### 注意事项

该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称    | 参数说明                                                                                                               |
|:----------------|:--------|:-------------------------------------------------------------------------------------------------------------------|
| IFNAME          | 接口名称    | 可选必选说明：必选参数 参数含义：该参数用于指定接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。               |
| ADDRESSFAMILY   | 地址族     | 可选必选说明：必选参数 参数含义：该参数用于指定地址族类型。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。 默认值：无                                      |
| VRFNAME         | VPN实例名称 | 可选必选说明：可选参数 参数含义：该参数用来表示VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：_public_ 配置原则：通过LST L3VPNINST查看当前已存在的VPN实例。 |
| MASTERSLAVETYPE | OMU类型   | 可选必选说明：可选参数 参数含义：该参数表示OMU类型。 数据来源：本端规划 取值范围：枚举类型。 MASTER：主。SLAVE：备。 默认值：MASTER                                     |
| GRPADDR         | 组地址     | 可选必选说明：条件必选参数 前提条件：该参数在“ADDRESSFAMILY”配置为“ipv4unicast”时为必选参数。 参数含义：该参数用于指定组地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无      |

#### 使用实例

显示IGMP加入源信息：

```
DSP MGMDSOURCE:VRFNAME="_public_",IFNAME="Ethernet64/0/5",GRPADDR="239.0.0.1",ADDRESSFAMILY=ipv4unicast;
```

