# 清除动态PCRF（CLR DYNAMICPCRF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、GGSN**

**须知** 

本命令属于高危命令，删除对端信息可能导致已在线用户发送CCR消息失败。

此命令用于删除动态PCRF主机列表表项。

#### 注意事项

- 该命令执行后立即生效。
- 动态PCRF主机列表最多支持2000个表项。
- 删除动态PCRF会导致已在线用户无法按照之前的Destination-Host和Destination-Realm封装发送CCR消息。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                  |
|:---------|:---------|:--------------------------------------------------------------------------------------|
| HOSTNAME | PCRF主机名称 | 可选必选说明：可选参数 参数含义：该参数用于表示动态PCRF主机的主机名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～127。 默认值：无 配置原则：无 |

#### 使用实例

删除所有动态PCRF主机列表：

```
CLR DYNAMICPCRF:;
```
