# 查询无人机控制管理策略（LST UAVCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF**

该命令用于查询无人机控制管理策略。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DNN    | 数据网络名称 | 可选必选说明：可选参数  参数含义：该参数用于表示指定的网络切片支持的数据网络名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~63。  默认值：无  配置原则：  只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。 |
| NSIDX  | 网络切片索引 | 可选必选说明：可选参数  参数含义：该参数用于指定网络切片，可以使用LST PLMNNS命令查询获取。  数据来源：全网规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：  本参数通过ADD NFNS命令进行配置，且NF类型必须是NfSMF。                                                                      |

## 使用实例

查询指定切片和DNN的无人机控制管理策略列表：

```
%%LST UAVCTRL: DNN="huawei.com", NSIDX=0;%%
RETCODE = 0  操作成功

结果如下
--------
         数据网络名称  =  huawei.com
         网络切片索引  =  0
UAV ID未携带导致流程拒绝的NAS原因值  =  0
UDM签约不允许接入导致流程拒绝的NAS原因值  =  0
NEF拒绝接入导致流程拒绝的NAS原因值  =  0
(结果个数 = 1)

---    END
```

|:------------------------|:-----------------------------------------------|
| 数据网络名称                  | 该参数用于表示指定的网络切片支持的数据网络名称。                       |

| NEF拒绝接入导致流程拒绝的NAS原因值    | 该参数用于设置因NEF拒绝接入而导致流程拒绝时，下发给终端的NAS消息中的拒绝原因值。    |
