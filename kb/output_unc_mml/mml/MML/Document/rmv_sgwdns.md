# 删除S-GW DNS域名策略（RMV SGWDNS）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于删除S-GW的域名中PLMNID的组装策略。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                |
|:-------|:-------|:----------------------------------------------------------------------------------------------------|
| DNTYPE | 域名类型   | 可选必选说明：必选参数 参数含义：该参数用于指定DNS域名类型。 取值范围： “RAI(RAI)”“TAI(TAI)” 默认值：无                                   |
| LAC    | 位置区域码  | 可选必选说明：条件必选参数 参数含义：该参数用于指定位置区域码。 前提条件：该参数在“DNTYPE(域名类型)”设置为“RAI(RAI)”时生效。 取值范围：0x0000～0xFFFF 默认值：无  |
| RAC    | 路由区域码  | 可选必选说明：条件必选参数 参数含义：该参数用于指定路由区域码。 前提条件：该参数在“DNTYPE(域名类型)”设置为“RAI(RAI)”时生效。 取值范围：0x00～0xFF 默认值：无      |
| TAC    | 跟踪区域码  | 可选必选说明：条件必选参数 参数含义：该参数用于指定跟踪区域码。 前提条件：该参数在“DNTYPE(域名类型)”设置为“TAI(TAI)”时生效。 取值范围：0x0000～0xFFFF 默认值 ：无 |

#### 使用实例

删除一条域名类型为“TAI”，跟踪区域码为“1”的DNS域名策略记录：

RMV SGWDNS: DNTYPE=TAI, TAC="1";
