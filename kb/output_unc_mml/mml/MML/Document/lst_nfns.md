# 查询NF支持的网络切片（LST NFNS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF、SMF、NSSF、CBC、CBCF**

该命令用以查询指定的NF所支持的网络切片。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFTYPE | NF类型   | 可选必选说明：可选参数  参数含义：该参数用于表示NF类型。  数据来源：本端规划 取值范围： “NfInvalid（NfInvalid）”：无效的NF“NfNRF（NfNRF）”：NRF“NfUDM（NfUDM）”：UDM“NfAMF（NfAMF）”：AMF“NfSMF（NfSMF）”：SMF“NfAUSF（NfAUSF）”：AUSF“NfNEF（NfNEF）”：NEF“NfPCF（NfPCF）”：PCF“NfSMSF（NfSMSF）”：SMSF“NfNSSF（NfNSSF）”：NSSF“NfUDR（NfUDR）”：UDR“NfLMF（NfLMF）”：LMF“NfGMLC（NfGMLC）”：GMLC“Nf5G_EIR（Nf5G_EIR）”：5G_EIR“NfSEPP（NfSEPP）”：SEPP“NfUPF（NfUPF）”：UPF“NfN3IWF（NfN3IWF）”：N3IWF“NfAF（NfAF）”：AF“NfUDSF（NfUDSF）”：UDSF“NfBSF（NfBSF）”：BSF“NfCHF（NfCHF）”：CHF“NfNWDAF（NfNWDAF）”：NWDAF“NfTypeMAX（NfTypeMAX）”：NfTypeMAX“NfMBSMF（NfMBSMF）”：MBSMF“NfCBCF（NfCBCF）”：NfCBCF“NfSCF（NfSCF）”：NfSCF“NfSPF（NfSPF）”：NfSPF  默认值：无  配置原则：无 |
| NSIDX  | 网络切片索引 | 可选必选说明：可选参数  参数含义：该参数在系统中唯一标识某个网络切片。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。本参数通过ADD PLMNNS命令进行配置。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |

## 使用实例

- 查询AMF支持的网络切片列表，执行如下命令：

  ```
  %%LST NFNS: NFTYPE=NfAMF;%%
  RETCODE = 0  操作成功

  结果如下
  --------
        NF类型  =  NfAMF
  网络切片索引  =  0
      描述信息  =  NULL
  (结果个数 = 1)

  ---    END
  ```
- 查询所有NF支持的网络切片列表，执行如下命令：

  ```
  %%LST NFNS:;%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
  NF类型   网络切片索引         描述信息  

  NfAMF    0                    NULL         
  NfSMF    0                    NULL         
  (结果个数 = 2)

  ---    END
  ```

## 输出结果说明

| 输出项名称   | 输出项解释              |
|:--------|:-------------------|
| NF类型    | 该参数用于表示NF类型。       |
| 网络切片索引  | 该参数在系统中唯一标识某个网络切片。 |
| 描述信息    | 该参数表示对网络切片的描述信息。   |
