# 删除用户位置（RMV USRLOCATION）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于删除用户位置信息。当运营商希望删除用户位置时，则配置该命令。

#### 注意事项

- 该命令执行后立即生效。
- 如果不输入位置名称，表示删除系统中所有用户位置信息。
- 位置信息删除时，该位置信息与所有的位置组的绑定关系同步删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                 |
|:-------------|:-------|:-------------------------------------------------------------------------------------|
| LOCATIONNAME | 位置名称   | 可选必选说明：可选参数 参数含义：指定位置名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

假如运营商需要删除位置名称为TestLocName的位置信息：

```
RMV USRLOCATION: LOCATIONNAME="TestLocName";
```
