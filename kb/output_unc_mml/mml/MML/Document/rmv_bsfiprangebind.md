# 删除BSF实例与IPRANGE之间的绑定关系（RMV BSFIPRANGEBIND）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于删除BSF（Binding Support Function）所管辖的IP地址范围。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称      | 参数说明                                                                                                                           |
|:----------------|:----------|:-------------------------------------------------------------------------------------------------------------------------------|
| BSFINSTANCENAME | BSF实例名称   | 可选必选说明：必选参数  参数含义：该参数用于指定BSF的实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~50。  默认值：无  配置原则：  该参数需要在ADD NFUUID中事先配置，可执行LST NFUUID进行查看。 |
| IPRANGENAME     | IPRANGE名称 | 可选必选说明：必选参数  参数含义：该参数用于指定该BSF实例所管辖的IP地址范围的名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~64。  默认值：无  配置原则：无                               |

## 使用实例

删除NF实例标识为BSF\_Instance\_0的BSF的rang1的IP地址管辖：

```
RMV BSFIPRANGEBIND: BSFINSTANCENAME="BSF_Instance_0", IPRANGENAME="range1";
```
