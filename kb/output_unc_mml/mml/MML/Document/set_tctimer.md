# 设置TC定时器（SET TCTIMER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于配置Diameter TC定时器。设置定时器时长，用来控制当UNC与OCS等Diameter对端断链后，重建链接的间隔时长。当此定时器超时，UNC则会向OCS等Diameter对端重新发起建链请求。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   |   TCTIMERLEN | TCMODE   |
|:-------|-------------:|:---------|
| 初始值    |            1 | MULTIPLY |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称             | 参数说明                                                                                                                                                                       |
|:-----------|:-----------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TCTIMERLEN | TC定时器时长（单位500ms） | 可选必选说明：必选参数 参数含义：该参数用于指定TC定时器时长。 数据来源：本端规划 取值范围：整数类型，取值范围为1～3600，单位是500毫秒。 默认值：无 配置原则：无                                                                                    |
| TCMODE     | 定时器模式            | 可选必选说明：可选参数 参数含义：该参数用于指定选择TC定时器的方式。 数据来源：本端规划 取值范围：枚举类型。 FIXED：表示TC定时器为固定方式，即每次重建链间隔是固定的。MULTIPLY：表示TC定时器为累加方式，即每次重建链间隔是N*TcTimerr时长，N表示重发建链请求消息的次数，N的最大值为20。 默认值：无 配置原则：无 |

#### 使用实例

配置Diameter TC定时器，则可以按如下配置：

```
SET TCTIMER:TCTIMERLEN=3,TCMODE=FIXED;
```
