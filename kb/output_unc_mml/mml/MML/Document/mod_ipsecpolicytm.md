# 修改IPsec策略模板（MOD IPSECPOLICYTM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

修改配置，影响协商及加解密性能。

该命令用于配置IPsec策略模板。

## 注意事项

- 该命令执行后立即生效。

- 当配置“SA按时计长”字段值为0时，该字段会采用**SET IKEGLOBALCONFIG**命令中TIMESADURTN参数的取值。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

修改策略模板名称为“temp3”，序列号为1，IKE对等体名称为“peer1”，Proposal名称为“prop1”，ACL编号为3001：

```
MOD IPSECPOLICYTM:POLICYNAME="temp3",SEQUENCENUMBER=1,PEERNAME="peer1",IPSECPROPNAME="prop1",ACLNUMBER=3001;
```
