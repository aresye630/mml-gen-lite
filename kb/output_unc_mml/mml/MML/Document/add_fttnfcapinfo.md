# 增加AMF容灾网元剩余容量信息（ADD FTTNFCAPINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令仅在调测场景下使用，且调测结束后需要删除相关配置信息，否则网元级KPI异常检测与容灾功能不能正常生效。

**适用NF：AMF**

该命令用于添加AMF POOL内其它AMF网元的剩余容量信息。

仅在调测场景下，通过本命令配置周边网元剩余容量信息，AMF会优先使用本配置的信息判断周边网元剩余容量能否满足容灾要求，从而可以实现网元级KPI异常检测与容灾功能。

## 注意事项

- 该命令执行后立即生效。

- 如果仅通过该配置增加指定某个AMF实例的剩余容量，但未通过ADD FTTNFSTATUS配置网元状态，则该AMF网元状态默认为Normal。
- 若配置本AMF的NF Instance ID，则该配置不生效。

- 最多可输入1024条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                                                                                               |
|:-------------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCEID | AMF实例标识 | 可选必选说明：必选参数  参数含义：该参数用于在UNC系统中唯一指定某个AMF实例。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~36。可输入的字符有字母A～Z或a～z、数字0～9、中划线"-"和下划线"_"，例如，AMF_Instance_0，不区分大小写。  默认值：无  配置原则：无                                        |
| RESTYPE      | 资源类型    | 可选必选说明：必选参数  参数含义：本参数用于指定资源类型。  数据来源：本端规划 取值范围： “CPURES（CPU资源）”：CPU资源  默认值：无  配置原则：无                                                                                                               |
| RESNAME      | 资源名称    | 可选必选说明：必选参数  参数含义：本参数用于指定资源名称，如果资源类型为CPU则对应节点（VM或POD）名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~100。  默认值：无  配置原则：  如果资源类型为CPU则对应的资源名称为：虚机类型，例如PBU_C-A；裸机类型，如usn-pod。可以通过DSP NODE（虚机类型）或者DSP POD（裸机类型）查询。 |
| RESVALUE     | 资源值     | 可选必选说明：可选参数  参数含义：本参数用于指定资源值。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：  如果资源类型为CPU，则配置资源名称对应的总的剩余CPU即系统中该所有资源名称的剩余CPU（过载CPU阈值 - 该资源当前的CPU值）总和。                                       |

## 使用实例

为NF Instance ID为Amf\_Instance\_1的网元增加VM为PBU\_C-A的CPU剩余容量的配置，执行如下命令：

```
ADD FTTNFCAPINFO: NFINSTANCEID="Amf_Instance_1", RESTYPE=CPURES, RESNAME="PBU_C-A";
```
