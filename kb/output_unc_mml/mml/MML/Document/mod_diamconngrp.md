# 修改Diameter链路组（MOD DIAMCONNGRP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于修改Diameter链路组的链路选择模式。当Diameter链路组建立后，需要修改链路选择模式时执行该命令。

#### 注意事项

- 该命令执行后立即生效。
- 配置SELECTMODE为SESSION\_ID时，根据session-id选择Diameter链路状态异常时，会选择其他可用Diameter链路进行消息交互。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称         | 参数说明                                                                                                                                                                      |
|:--------------|:-------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CONNGROUPNAME | Diameter链路组名 | 可选必选说明：必选参数 参数含义：该参数用于指定Diameter链路组名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                         |
| SELECTMODE    | 链路选择模式       | 可选必选说明：可选参数 参数含义：该参数用于指定Diameter链路组的链路选择模式。 数据来源：全网规划 取值范围：枚举类型。 SESSION_ID：基于会话（Session-id）轮询方式进行链路选择。MASTER_SLAVE：基于主备方式进行链路选择。ROUND_ROBIN：基于消息轮询方式进行链路选择。 默认值：无 配置原则：无 |

#### 使用实例

如果希望diameter链路组gxconngrp的链路选择模式修改为session-id轮选方式，可以使用该命令修改链路组：

```
MOD DIAMCONNGRP: CONNGROUPNAME="gxconngrp", SELECTMODE=SESSION_ID;
```
