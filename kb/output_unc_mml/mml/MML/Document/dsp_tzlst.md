# 显示多时区参数(DSP TZLST)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用网元：SGSN**

此命令用于查询某个时区是否进入夏令时。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                |
|:-------|:-------|:----------------------------------------------------|
| TZID   | 时区标识   | 可选必选说明：可选参数 参数含义：该参数用于指定待查询时区信息的索引。 取值范围：1～24 默认值：无 |

#### 使用实例

查询“时区标识”为“1”的时区信息：

DSP TZLST: TZID=1;

```
%%DSP TZLST: TZID=1;%%
RETCODE = 0  操作成功。

输出结果如下
--------------
          时区标识  =  1
              时区  =  GMT+01:00
夏令时偏移量(小时)  =  1
(结果个数 = 1)

---    END
```

查询多条时区信息：

DSP TZLST:;

```
%%DSP TZLST:;%%
RETCODE = 0  操作成功。

输出结果如下
--------------
 时区标识  时区       夏令时偏移量(小时)

 1         GMT+03:30  0                 
 2         GMT+05:45  0                 
(结果个数 = 2)

---    END
```
