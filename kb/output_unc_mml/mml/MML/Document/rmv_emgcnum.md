# 删除紧急号码信息表记录(RMV EMGCNUM)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

此命令用于删除配置的紧急呼叫号码信息。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                         |
|:-------|:-------|:-------------------------------------------------------------|
| MCC    | 移动国家码  | 可选必选说明：可选参数 参数含义：该参数表示所要删除的紧急呼叫号码所属国家码。 取值范围：3位的十进制数字 默认值：无  |
| NUM    | 紧急呼叫号码 | 可选必选说明：可选参数 参数含义：该参数用于表示要删除的紧急呼叫号码。 取值范围：长度不超过80的十进制数字 默认值：无 |

#### 使用实例

删除给MCC为“123”配置的紧急号码“119”：

RMV EMGCNUM: MCC="123", NUM="119";
