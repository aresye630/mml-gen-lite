# 查询PAE参数（LST PAEPARAMS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询PAE服务的相关参数。PAE主要功能是为微服务通信提供报文高速转发及适配。

## 注意事项

参数"PARAVALUE2"仅作为保留域，暂未启用。

#### 操作用户权限

G\_1，管理员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                             |
|:-------|:-------|:---------------------------------------------------------------------------------|
| PARAID | 参数ID   | 可选必选说明：可选参数  参数含义：该参数用于指定PAE参数ID。  数据来源：本端规划  取值范围：整数类型，取值范围是0~2。  默认值：无  配置原则：无 |

## 使用实例

查询PAE参数：

```
%%LST PAEPARAMS:;%%
RETCODE = 0  操作成功

结果如下
--------
参数ID  第一个参数值  第二个参数值  

0       1             NULL          
1       1             NULL          
2       1             NULL          
(结果个数 = 3)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                                                                                                                             |
|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 参数ID    | 该参数用于指定PAE参数ID。                                                                                                                                                                                                                   |
| 第一个参数值  | 该参数用于设置PAE参数的取值。 当PAE参数ID为0时，该参数值用于设置pbuflist分片数大于等于4的情况下发送网卡前是否进行合并处理，0表示不做合并处理，1表示需要做合并处理；当该合并处理开启时，外联口MTU最大支持3*PBUF报文单元有效荷载数据长度。 当PAE参数ID为1时，该参数值用于设置pbuf重用检测开关，0表示关，1表示开。 当PAE参数ID为2时，该参数值用于设置EVS卸载场景支持Packed模式的开关，0表示关，1表示开。 |
| 第二个参数值  | 该参数用于设置PAE参数的扩展取值，类型是字符串。仅作为保留域，暂未启用。                                                                                                                                                                                             |
