# 修改GTP-U本地实体(MOD GTPULE)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

本命令用于修改已存在的GTPU本端实体的描述信息。

#### 注意事项

- 本命令执行后立即生效。
- 同一个IP地址不能配置不同的VPN名称。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                            |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MODTYPE | 修改类型   | 可选必选说明：必选参数 参数含义：本参数用于指定修改GTPU本端实体的操作类型。 数据来源：本端规划 取值范围：“BYINDEX(根据记录索引)”“BYIP(根据IP地址)” 默认值：无                                                                                   |
| INDEX   | 记录索引   | 可选必选说明：条件必选参数 参数含义：本参数用于指定GTPU本端实体的记录索引。 前提条件：该参数在“修改条件”参数配置为“BYINDEX(根据记录索引)”后生效。 数据来源：本端规划 取值范围：0~65535 默认值：无  说明： 使用LST GTPULE查询记录的索引。                                       |
| GROUPID | 组号     | 可选必选说明：条件必选参数 参数含义：本参数用于指定GTPU本端实体对应的组号。组号用于组网规划时不同接口，或者不同用户范围使用独立的GTPU本端实体。 前提条件：该参数在“修改条件”参数配置为“BYIP(根据IP地址)”后生效。 数据来源：本端规划 取值范围：0~32 默认值：无  说明： 组号的应用参考ADD GTPUINTFATTR命令帮助。 |
| IPTYPE  | IP地址类型 | 可选必选说明：条件必选参数 参数含义：本参数用于指定GTPU本端实体的IP地址类型。 前提条件：该参数在“删除条件”参数配置为“BYIP(根据IP地址)”后生效。 数据来源：本端规划 取值范围：“TPTADDR_TYPE_IPV4(IPV4)”“TPTADDR_TYPE_IPV6(IPV6)” 默认值：无                       |
| LEIPV4  | IPv4地址 | 可选必选说明：条件必选参数 参数含义：本参数用于指定GTPU本端实体的IPv4地址。 前提条件：该参数在“IP类型”参数配置为“TPTADDR_TYPE_IPV4(IPV4)”后生效。 数据来源：本端规划 取值范围：0.0.0.0~255.255.255.255 默认值：无                                       |
| LEIPV6  | IPv6地址 | 可选必选说明：条件必选参数 参数含义：本参数用于指定GTPU本端实体的IPv6地址。 前提条件：该参数在“IP类型”参数配置为“TPTADDR_TYPE_IPV6(IPV6)”后生效。 数据来源：本端规划 取值范围：::~FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无                    |
| VPNNAME | VPN名称  | 可选必选说明：可选参数 参数含义：本参数用于指定新的VPN名称。 数据来源：本端规划 取值范围：0~31位字符串 默认值：无                                                                                                                  |
| DESC    | 描述信息   | 可选必选说明：可选参数 参数含义：本参数用于指定新的描述信息。新的描述信息将会覆盖原描述信息。 数据来源：本端规划 取值范围：0~32位字符串 默认值：无                                                                                                   |

#### 使用实例

修改GTPU本地实体，索引为1：

MOD GTPULE: MODTYPE=BYINDEX, INDEX=1, DESC="private";
