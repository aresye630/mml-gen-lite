# 查询5G N2原因值映射配置（LST N2CAUSEMAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询5G N2原因值映射配置。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|:--------------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROT          | 流程类型    | 可选必选说明：可选参数  参数含义：该参数用于指定流程类型，根据场景来确认是否需要配置相应的流程。  数据来源：全网规划 取值范围： INIT_REG（初始注册）MOBL_INTRA_REG（移动性注册）PROD_REG（周期性注册）EPS_TO_5GS_REG（EPS到5GS注册）SERVICE_REQUEST（服务请求）INTRA_N2_HO（INTRA N2接口切换流程）INTER_N2_HO（INTER N2接口切换流程）XN_HO（Xn接口切换）EPS_TO_5GS_HO（EPS到5GS切换）ALL（所有流程）REG_REDIRECT（注册重定向流程）HO_REDIRECT（切换重定向流程）OFFLOAD（迁移流程）RESERV_PROC1（预留字段1）RESERV_PROC2（预留字段2）RESERV_PROC3（预留字段3）RESERV_PROC4（预留字段4）RESERV_PROC5（预留字段5）RESERV_PROC6（预留字段6）  默认值：无  配置原则：  指定流程和“ALL”类型同时配置时，指定流程配置的原因值映射优先级高于“ALL”类型配置的原因值映射。 |
| SCAUSETYPE    | 原始原因值类型 | 可选必选说明：可选参数  参数含义：该参数用于指定需要映射的原始原因值的类型。  数据来源：全网规划 取值范围： “PROTOCOL_CAUSE（协议原因值）”：表示协议定义的原因值。“INNER_CAUSE（内部原因值）”：表示产品内部使用的原因值。  默认值：无  配置原则：  如需使用内部原因值转换功能，请联系华为技术支持处理。  如果同时存在协议原因值和内部原因值的配置记录，内部原因值的配置记录优先级高于协议原因值的配置记录。                                                                                                                                                                                                                                                                                        |
| SCAUSEGRP     | 原始原因值组  | 可选必选说明：该参数在"SCAUSETYPE"配置为"PROTOCOL_CAUSE"时为条件可选参数。  参数含义：该参数用于指定下发到目标网元的原始原因值组。  数据来源：全网规划 取值范围： “RADIO_NETWORK_LAYER（无线网络层）”：无线网络层“TRANSPORT_LAYER（传输层）”：传输层“NAS（非接入层）”：非接入层“PROTOCOL（协议）”：协议“MIS（其他）”：其他  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                         |
| SCAUSE        | 原始原因值   | 可选必选说明：该参数在"SCAUSETYPE"配置为"PROTOCOL_CAUSE"时为条件可选参数。  参数含义：该参数用于指定下发到目标网元的原始原因值。  数据来源：全网规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                   |
| SRCINNERCAUSE | 原始内部原因值 | 可选必选说明：该参数在"SCAUSETYPE"配置为"INNER_CAUSE"时为条件可选参数。  参数含义：该参数用于指定用户流程失败的原始内部原因值。  数据来源：全网规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                              |

## 使用实例

- 不输入查询条件，查询表中全部5G N2原因值映射配置记录，执行如下命令：

  ```
  %%LST N2CAUSEMAP:;%%
  RETCODE = 0  操作成功

  结果如下
  --------
  流程类型  原始原因值类型  原始原因值组   原始原因值   原始内部原因值   目标原因值组   目标原因值   

  初始注册  协议原因值      非接入层       27           NULL             非接入层       50
  初始注册  协议原因值      非接入层       28           NULL             非接入层       50
  (结果个数 = 2)

  ---    END
  ```
- 查询流程类型为初始注册，原始原因值类型为协议原因值，原始原因值组为非接入层，原始原因值为27的5G N2原因值映射配置记录，执行如下命令：

  ```
  %%LST N2CAUSEMAP: PROT=INIT_REG, SCAUSETYPE=PROTOCOL_CAUSE, SCAUSEGRP=NAS, SCAUSE=27;%%
  RETCODE = 0  操作成功

  结果如下
  --------
        流程类型  =  初始注册
  原始原因值类型  =  协议原因值 
    原始原因值组  =  非接入层
      原始原因值  =  27
  原始内部原因值  =  NULL
    目标原因值组  =  非接入层
      目标原因值  =  50
  (结果个数 = 1)

  ---    END
  ```
