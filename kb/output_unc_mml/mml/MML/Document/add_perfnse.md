# 增加NSE标识(ADD PERFNSE)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用于增加一个NSE标识，用于Gb接口NSE话统上报的对象。指定NSE NS和指定NSE BSSGP话统测量单元下的指标上报时必需知道所要上报的NSEI，否则无法上报。因此需要通过该命令手动增加动态上报的NSE ID。

#### 注意事项

- 该命令执行后立即生效。

- 用户在执行ADD PERFNSE时候必需先使用**DSP NSE**查询所有需要处理的NSE标识。
- 本表最大记录数为2048。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                           |
|:-------|:-------|:---------------------------------------------------------------|
| NSEI   | NSE标识  | 可选必选说明：必选参数 参数含义：该参数用于指定网络服务实体标识。 数据来源：整网规划 取值范围：0～65535 默认值：无 |

#### 使用实例

增加一个待处理的NSE标识，NSEI为10：

ADD PERFNSE: NSEI=10;
