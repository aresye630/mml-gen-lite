# 查询目标NF发现和选择的位置匹配信息（LST NFLOC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF、SMF**

该命令用于查询为目标NF的发现和选择配置的位置匹配相关的信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                                                       |
|:----------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFTYPE    | NF类型   | 可选必选说明：可选参数  参数含义：该参数用于表示服务发现的目标NF的请求者的NF类型。  数据来源：全网规划 取值范围： “NfAMF（NfAMF）”：AMF“NfSMF（NfSMF）”：SMF  默认值：无  配置原则：无                                                                                                                                          |
| TGTNFTYPE | 目标NF类型 | 可选必选说明：可选参数  参数含义：该参数用于表示目标NF的类型。  数据来源：全网规划 取值范围： “NF_ALL（所有NF）”：所有NF“UDM（UDM）”：UDM“AMF（AMF）”：AMF“SMF（SMF）”：SMF“AUSF（AUSF）”：AUSF“PCF（PCF）”：PCF“SMSF（SMSF）”：SMSF“NSSF（NSSF）”：NSSF“LMF（LMF）”：LMF“GMLC（GMLC）”：GMLC“FIFTHG_EIR（5G_EIR）”：5G_EIR  默认值：无  配置原则：无 |

## 使用实例

查询AMF在发现SMF时使用的优选区域信息，执行如下命令：

```
%%LST NFLOC: NFTYPE=NfAMF;%%
RETCODE = 0  操作成功

结果如下
--------
    NF类型  =  NfAMF
目标NF类型  =  所有NF
  位置类型  =  优选位置
  优选位置  =  DC2
  描述信息  =  prefer the NFs of DC2
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                 |
|:--------|:--------------------------------------|
| NF类型    | 该参数用于表示服务发现的目标NF的请求者的NF类型。            |
| 目标NF类型  | 该参数用于表示目标NF的类型。                       |
| 位置类型    | 该参数用于表示目标NF发现和选择流程中用作匹配条件的位置类型。       |
| 优选位置    | 该参数用于表示目标NF的优选位置，即在该指定位置中的目标NF将被优先选择。 |
| 描述信息    | 该参数是对本NF配置优选区域的描述信息，在运维中起助记的作用。       |
