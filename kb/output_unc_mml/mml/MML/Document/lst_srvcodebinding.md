# 查询智能业务编码组和智能业务编码的绑定关系（LST SRVCODEBINDING）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF、PGW-C**

该命令用于查询智能业务编码和智能业务编码组的绑定关系。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                   |
|:------------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SRVCODEGRP  | 智能业务编码组 | 可选必选说明：可选参数  参数含义：该参数用于指定智能业务编码组的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。不支持空格，不区分大小写。  默认值：无  配置原则： 该参数使用ADD SRVCODEGRP命令配置生成。配置的SRVCODEGRP必须是系统已经存在的SrvCodeGrp对象名称。   |
| SERVICECODE | 智能业务编码  | 可选必选说明：可选参数  参数含义：该参数用于指定智能业务编码的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。不支持空格，不区分大小写。  默认值：无  配置原则： 该参数使用ADD SERVICECODE命令配置生成。配置的SERVICECODE必须是系统已经存在的ServiceCode对象名称。 |

## 使用实例

查询智能业务编码“intelligent”和智能业务编码组的绑定关系：

```
%%LST SRVCODEBINDING: SERVICECODE="intelligent";%%
RETCODE = 0  操作成功

结果如下
------------------------
智能业务编码组  =  codegrp
  智能业务编码  =  intelligent
(结果个数 = 1)

---    END
```
