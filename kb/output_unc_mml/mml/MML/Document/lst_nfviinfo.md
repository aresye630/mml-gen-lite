# 查询NFVI信息（LST NFVIINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询网元对接的云服务信息。

**说明** 

该命令依赖LCM配套版本，需要强配套VNF LCM：V100R025C10SPC180及以上版本才支持。

#### 注意事项

无。

#### 参数说明

无。

#### 使用实例

裸机场景查询结果示例如下：

```
%%LST NFVIINFO:;%%
RETCODE = 0  操作成功
操作结果如下
------------
  NFVI名称  =  PaasIpv6
  NFVI类型  =  FusionStage
  NFVI URL  =  https://10.10.10.10:30000
  NFVI域名  =  DefaultTenant
NFVI域账号 =  nerestuser
   NFVI IP  =  10.10.10.10
(结果个数 = 1)
---    END
```

虚机场景查询结果示例如下：

```
%%LST NFVIINFO:;%%
RETCODE = 0  操作成功
操作结果如下
------------
NFVI名称       NFVI类型         NFVI URL                                NFVI域名         NFVI域账号    NFVI IP
FS_104         FusionSphere     https://xx.xx.dc1.xx.com/identity       VDC_01           VDC_01_om     10.10.10.10
PaaS_Edge01    FusionStage      https://10.10.10.10:31943               DefaultTenant    nerestuser    10.10.10.10   
(结果个数 = 2)
---    END
```

#### 输出结果说明

命令执行正常，会返回命令执行成功的提示信息以及NFVI信息，输出结果项信息如表1 输出项说明。

命令执行失败则返回相应的错误，参见表2 错误码列表；命令执行异常，请联系华为技术支持处理。

| 输出项名称    | 输出项解释                                      |
|:---------|:-------------------------------------------|
| NFVI名称   | VNFM对接FusionSphere和FusionStage时填写的云服务名称。   |
| NFVI类型   | VNFM对接云服务的类型，目前支持FusionSphere和FusionStage。 |
| NFVI URL | VNFM对接云服务使用的URL。                           |
| NFVI域名   | VNFM对接云服务使用的域名。                            |
| NFVI域账号  | VNFM对接云服务使用的域账号。                           |
| NFVI IP  | VNFM对接云服务使用的IP。                            |
