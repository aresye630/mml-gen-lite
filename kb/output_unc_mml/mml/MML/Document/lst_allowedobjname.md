# 查询授权控制对象（LST ALLOWEDOBJNAME）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NRF**

该命令用于在NRF上查询访问授权控制策略的NF对象信息。

查询所有授权控制对象信息，请不要输入任何参数信息。

查询某个授权控制对象信息，请输入具体的授权对象名称。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                       |
|:--------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| OBJNAME | 授权对象名称 | 可选必选说明：可选参数  参数含义：该参数表示设置访问授权控制策略的NF对象名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。该字段值需要全系统唯一，只能由字母（A-Z或者a-z）、数字（0-9）组成，不能以数字开始。  默认值：无  配置原则：无 |

## 使用实例

查询对象名称为objname001的受控对象的记录：

```
LST ALLOWEDOBJNAME: OBJNAME="objname001";
%%LST ALLOWEDOBJNAME: OBJNAME="objname001";%%
RETCODE = 0  操作成功

结果如下
--------
授权对象名称  =  objname001
(结果个数 = 1)

---    END
```
