# 查询MSC选择策略(LST MSCSELPLCY)

#### 命令功能

**适用网元：MME**

该命令用于查询MSC域名解析策略。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询Sv接口域名解析采用的是RAI还是LAI解析MSC，使用该命令：

`LST MSCSELPLCY:;`

```
%%LST MSCSELPLCY:;%%
RETCODE = 0  操作成功。

输出结果如下
--------------
Sv接口域名解析策略 = LAI
(结果个数 = 1)

---    END
```

#### 输出结果说明

请参见**SET MSCSELPLCY**的参数说明。
