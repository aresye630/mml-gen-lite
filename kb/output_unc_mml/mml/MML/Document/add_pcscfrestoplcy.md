# 增加P-CSCF故障恢复策略(ADD PCSCFRESTOPLCY)

#### 命令功能

**适用网元：MME**

该命令用于增加P-CSCF故障恢复策略配置。该命令对应的业务功能暂未实现。

该命令的使用场景：当P-CSCF故障时，可以设置该命令通过承载更新流程刷新故障的P-CSCF，减少IMS会话重建。

#### 注意事项

- 该命令执行后立即生效。
- 最大配置记录数是1024条。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

| SUBRANGE | 用户范围                           | 可选必选说明：必选参数 参数含义：该参数用于指定配置P-CSCF故障恢复策略的用户范围。 数据来源：整网规划 取值范围： ALL_USER（所有用户）：表示用户范围为系统内所有用户。HOME_USER（本网用户）：表示用户范围为本网用户。FOREIGN_USER（外网用户）：表示用户范围为外网用户。IMSI_PREFIX（指定IMSI前缀）：表示用户范围通过IMSI前缀指定。SPECIFIC_IMSI（特定IMSI）：表示用户范围通过IMSI指定。 默认值：无 配置原则：控制策略优先级高到低为：“SPECIFIC_IMSI（特定IMSI）”，“IMSI_PREFIX（指定IMSI前缀）”，“FOREIGN_USER(外网用户)”或“HOME_USER(本网用户)”， “ALL_USER(所有用户)”。系统优先查找高优先级的配置记录，如果查找不到，再查找低优先级的配置记录。                                                                                       |

#### 使用实例

增加一条“用户范围”为“所有用户”，“PCO-based optional extension功能”为“ON（开启）”的记录；

```
ADD PCSCFRESTOPLCY: SUBRANGE=ALL_USER, PCOOPEX=ON;
```
