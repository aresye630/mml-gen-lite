# 查询MPLS自动化配置模板（LST AUTOSCALINGMPLS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询MPLS自动化配置模板。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                    |
|:------------|:-------|:----------------------------------------------------------------------------------------|
| SERVICENAME | 服务名称   | 可选必选说明：可选参数 参数含义：该参数用来表示接口自动化配置服务模板名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格和中文。 默认值：无 |

#### 使用实例

查询MPLS自动化配置模板：

```
LST AUTOSCALINGMPLS:;
```

```
RETCODE = 0  操作成功。

结果如下
--------
    服务名称  =  service1
最大传输单元  =  1500
(结果个数 = 1)
---    END
```
