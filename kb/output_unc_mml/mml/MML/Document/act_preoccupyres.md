# 预占RU资源（ACT PREOCCUPYRES）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：NCG**

该命令用于触发预占的RU资源。

#### 注意事项

- 该命令执行后立即生效。
- 再次执行该命令需间隔30秒。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                  |
|:--------|:-------|:--------------------------------------------------------------------------------------|
| RUTYPE  | RU类型   | 可选必选说明：必选参数 参数含义：该参数用于指定预占RU的类型。 数据来源：本端规划 取值范围：枚举类型。 CG_SP_RU：CG_SP_RU。 默认值：无 配置原则：无 |
| IDLENUM | 预占数量   | 可选必选说明：必选参数 参数含义：该参数用于指定预占RU的个数。 数据来源：本端规划 取值范围：整数类型，取值范围为1～7。 默认值：无 配置原则：目前只支持1-2。   |

#### 使用实例

预占RU资源：

```
ACT PREOCCUPYRES: RUTYPE=CG_SP_RU, IDLENUM=2;
```
