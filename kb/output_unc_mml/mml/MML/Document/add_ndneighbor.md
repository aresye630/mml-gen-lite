# 增加静态ND邻居表项（ADD NDNEIGHBOR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于IPv6 ND静态表项的新增。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为16384。
- 接口名称可以通过LST INTERFACE命令获取。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                |
|:------------|:-------|:----------------------------------------------------------------------------------------------------|
| IFNAME      | 接口名    | 可选必选说明：必选参数 参数含义：该参数用于指定接口名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。 |
| IPV6ADDRESS | IPv6地址 | 可选必选说明：必选参数 参数含义：该参数用于指定IPv6地址。 数据来源：全网规划 取值范围：IPv6地址类型。 默认值：无                                      |
| MACADDRESS  | MAC地址  | 可选必选说明：必选参数 参数含义：该参数用于指定MAC地址。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～18。 默认值：无                              |

#### 使用实例

新增IPv6 ND静态表项：

```
ADD NDNEIGHBOR:IFNAME="Ethernet65/0/8",IPV6ADDRESS="2001:db8::11",MACADDRESS="00e0-fc01-0001";
```
