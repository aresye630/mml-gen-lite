# 增加对端AMF的GUAMI信息（ADD PNFGUAMI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、NSSF、SMSF、NCG、CBC、CBCF**

该命令用于增加本地配置的对端AMF实例支持的GUAMI信息。该命令用于在网络中没有部署NRF，或对端NF没有注册到NRF，或网络中存在NRF但需基于运营商策略本地配置周边NF的场景下，配置对端NF实例相关的信息。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入512条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                   |
|:-------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCEID | NF实例标识 | 可选必选说明：必选参数  参数含义：该参数用于指定对端AMF的实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~50。NFINSTANCEID参数建议满足以下约束规则：1.如果输入为uuid格式（格式例如：a6a61c6f-0d3a-4221-b1da-424eda3ccf67）只能为A-F、a-f、0-9和“-”的字符。2.如果输入不为uuid格式，长度不能超过18且不允许输入只包含0-9和“.”的字符串，例如：1.2.3.4、不允许输入只包含十六进制数（A-F、a-f、0-9）和“:”的字符串，例如：1::2、FBFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。3.该参数大小写不敏感。  默认值：无  配置原则：  本参数取值与ADD PNFPROFILE命令中的“NF实例标识”参数取值保持一致时，关联关系生效。 |
| MCC          | 移动国家码  | 可选必选说明：必选参数  参数含义：该参数用于指定对端AMF的移动国家码。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。  默认值：无  配置原则：  本参数由3个十进制数字组成。                                                                                                                                                                                                                                                                                                     |
| MNC          | 移动网号   | 可选必选说明：必选参数  参数含义：该参数用于指定对端AMF的移动网号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。  默认值：无  配置原则：  本参数由2~3个十进制数字组成。                                                                                                                                                                                                                                                                                                |
| AMFID        | AMF标识  | 可选必选说明：必选参数  参数含义：该参数用于指定对端AMF的AMF标识。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                    |

## 使用实例

老侧AMF本端需要基于GUAMI选择新侧AMF，增加对端AMF GUAMI信息，NF实例标识为AMF\_Instance\_1，MCC为460，MNC为03，AMFID为00001。

```
ADD PNFGUAMI: NFINSTANCEID="AMF_Instance_1", MCC="460", MNC="03", AMFID="000001";
```
