# 查询IMSI和MSISDN号段（LST IMSIMSISDNSEG）

- 命令功能

- 操作用户权限

- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于查询IMSI/MSISDN号码段。

#### 注意事项

LST IMSIMSISDNSEG时如果显示有%3f表示的是通配符“？”。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称            | 参数说明                                                                                                                           |
|:------------|:----------------|:-------------------------------------------------------------------------------------------------------------------------------|
| SEGMENTNAME | IMSI/MSISDN号段名称 | 可选必选说明：可选参数 参数含义：该参数用于指定IMSI/MSISDN号段名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：如果参数不提供则查询所有IMSI/MSISDN号码段。 |

#### 使用实例

- 查询IMSI和MSISDN号段：

  ```
  LST IMSIMSISDNSEG: SEGMENTNAME="huawei";
  ```

  ```
  RETCODE = 0  操作成功

  IMSI或MSISDN号段信息
  --------------------
  IMSI/MSISDN号段名称  =  huawei
  IMSI/MSISDN号段类型  =  IMSI
       号段起始字符串  =  130
       号段结束字符串  =  139
       通配号段字符串  =  NULL
   锁定IMSIMSISDN号段  =  不使能
  (结果个数 = 1)

  ---    END
  ```
- 查询所有IMSI和MSISDN号段：

  ```
  LST IMSIMSISDNSEG:;
  ```

  ```
  RETCODE = 0  操作成功

  IMSI或MSISDN号段信息
  --------------------
  IMSI/MSISDN号段名称  =  huawei
  IMSI/MSISDN号段类型  =  IMSI
       号段起始字符串  =  130
       号段结束字符串  =  139
       通配号段字符串  =  NULL
   锁定IMSIMSISDN号段  =  不使能
  (结果个数 = 1)

  ---    END
  ```

#### 输出结果说明

| 输出项名称          | 输出项解释                                                                                     |
|:---------------|:------------------------------------------------------------------------------------------|
| 锁定IMSIMSISDN号段 | 用于锁定或解锁标识。当IMSI/MSISDN号码段锁定后，后续该IMSI/MSISDN号码段内的用户会激活失败，已经在线的用户无影响。通过LCK IMSIMSISDNSEG配置。 |

其余输出项请参见ADD IMSIMSISDNSEG的参数说明。
