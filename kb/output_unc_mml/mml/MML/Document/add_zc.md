#### 命令功能

**适用网元：SGSN、MME**

此命令用于增加区域码记录。区域码用于定义允许或者禁止用户漫游的区域，借助一个完全的区域码列表，运营商可以确定用户是否能在此区域漫游。用户不允许在此区域漫游的情况下，UNC回复给用户的拒绝消息中携带的原因值可通过软参配置，2G/3G用户可使用软参BYTE\_EX64配置，4G用户可使用软参BYTE\_EX209配置。

#### 注意事项

- 此命令最大记录数为20000。
- 此命令配置后，需要把移动性扩展功能(**SET MMFUNC**)中的“区域码”设置为“YES”，配置才能生效。
- 可以为一个ZC配置多个LAI或RAI等位置区域，一个ZC代表一组位置区域。
- 此命令配置后，如果用户签约了ZC（区域码），则只能从签约ZC对应的本命令的位置接入系统，若签约ZC没有在本命令配置也不允许接入。
- 配置此命令时，需要同时考虑2G/3G/4G情况，对允许用户接入的TAI和LAI（或者TAI和RAI）需同时进行配置，避免用户在未配置的制式接入时受限。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                                            |
|:---------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ZC       | 区域码     | 可选必选说明：必选参数 参数含义：该参数用于指定区域码。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无 配置原则：输入16进制数时，可以直接输入，也可以在数字前加0X或0x。                                                                                             |
| IDTYPE   | 标识类型    | 可选必选说明：必选参数 参数含义：该参数用于指定该区域的标识类型。 数据来源：整网规划 取值范围： “LA(位置区)”：表示该区域标识类型为位置区。“RA(路由区)”：表示该区域标识类型为路由区。“SA(服务区)”：表示该区域标识类型为服务区。“TA(跟踪区)”：表示该区域标识类型为跟踪区。 默认值：无                                        |
| MCC      | 移动国家码   | 可选必选说明：必选参数 参数含义：该参数用于指定移动国家代码。 数据来源：整网规划 取值范围：3位的十进制数字 默认值：无                                                                                                                                   |
| MNC      | 移动网号    | 可选必选说明：必选参数 参数含义：该参数用于指定移动网号。 数据来源：整网规划 取值范围：2～3位的十进制数字 默认值：无                                                                                                                                   |
| LAC      | 位置区域码   | 可选必选说明：条件必选参数 参数含义：该参数用于指定位置区域码。 前提条件：该参数在“IDTYPE(标识类型)”设置为“LA(位置区)”、“RA(路由区)”或“SA(服务区)”时生效。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无                                                                 |
| LACRANGE | 位置区域码范围 | 可选必选说明：条件可选参数 参数含义：该参数用于指定位置区域码范围。该参数与“LAC”参数构成一个LAC区段，方便客户配置连续的位置区域。如果不输入，表示配置单个LAC。 前提条件：该参数在“IDTYPE(标识类型)”设置为“LA(位置区)”时生效。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无 配置原则：该参数的取值需要大于或等于“LAC”。       |
| RAC      | 路由区域码   | 可选必选说明：条件必选参数 参数含义：该参数用于指定路由区域码。 前提条件：该参数在“IDTYPE(标识类型)”设置为“RA(路由区)”时生效。 数据来源：整网规划 取值范围：0x00～0xFF 默认值：无                                                                                         |
| RACRANGE | 路由区域码范围 | 可选必选说明：条件可选参数 参数含义：该参数用于指定路由区域码范围。 前提条件：该参数在“IDTYPE(标识类型)”设置为“RA(路由区)”时生效。 数据来源：整网规划 取值范围：0x00～0xFF 默认值：无 配置原则：该参数的取值需要大于或等于“RAC”。  说明： 该参数与“RAC”参数构成一个RAC区段，方便客户配置连续的路由区域。如果不输入，表示配置单个RAC。     |
| SAC      | 服务区域码   | 可选必选说明：条件必选参数 参数含义：该参数用于指定服务区域码。 前提条件：该参数在“IDTYPE(标识类型)”设置为“SA(服务区)”时生效。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无                                                                                     |
| SACRANGE | 服务区域码范围 | 可选必选说明：条件可选参数 参数含义：该参数用于指定服务区域码范围。 前提条件：该参数在“IDTYPE(标识类型)”设置为“SA(服务区)”时生效。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无 配置原则：该参数的取值需要大于或等于“SAC”。  说明： 该参数与“SAC”参数构成一个SAC区段，方便客户配置连续的服务区域。如果不输入，表示配置单个SAC。 |
| TAC      | 跟踪区域码   | 可选必选说明：条件必选参数 参数含义：该参数用于指定该跟踪区域码。 前提条件：该参数在“IDTYPE(标识类型)”设置为“TA(跟踪区)”时生效。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无                                                                                    |
| TACRANGE | 跟踪区域码范围 | 可选必选说明：条件可选参数 参数含义：该参数用于指定跟踪区域码范围。 前提条件：该参数在“IDTYPE(标识类型)”设置为“TA(跟踪区)”时生效。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无 配置原则：该参数的取值需要大于或等于“TAC”。  说明： 该参数与“TAC”参数构成一个TAC区段，方便客户配置连续的跟踪区域。如果不输入，表示配置单个TAC。 |
| ZCN      | 区域名称    | 可选必选说明：可选参数 参数含义：该参数用于指定该区域名称。 数据来源：整网规划 取值范围：1～32位字符串 默认值：无                                                                                                                                    |

#### 使用实例

1. 增加一条位置区域码记录，区域码为0x1234，标识类型为LA，移动国家代码为123，移动网号为03，位置区域码为1，区域名称为test1：

   ADD ZC: ZC="0x1234", IDTYPE=LA, MCC="123", MNC="03", LAC="1", ZCN="test1";
2. 增加一条路由区域码记录，区域码为12，标识类型为RA，移动国家代码为123，移动网号为03，位置区域码为10，路由区域码为1，路由区域码范围为5，区域名称为test2：

   ADD ZC: ZC="12", IDTYPE=RA, MCC="123", MNC="03", LAC="10", RAC="1", RACRANGE="5", ZCN="test2";
