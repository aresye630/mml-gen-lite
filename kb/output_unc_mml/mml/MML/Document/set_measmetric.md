# 设置话统测量指标参数(SET MEASMETRIC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令为高危命令，执行将修改话统测量指标的参数，影响该话统指标的上报，请慎重执行。

该命令用于设置话统测量指标参数。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                                                           |
|:------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID        | 网元ID   | 可选必选说明：必选参数。 参数含义：标识网元ID，可以通过LST ME命令查询获取。 取值范围：0~65535。 默认值：无。 配置原则：无。                                                                                                                                                                                        |
| METRICID    | 测量指标ID | 可选必选说明：必选参数。 参数含义：测量指标ID，可以通过LST MEASUNIT命令查询获取。 取值范围：整数类型，取值范围为0~4294967294。 默认值：无。 配置原则：仅支持配置微服务指标。                                                                                                                                                          |
| TYPE        | 类型     | 可选必选说明：必选参数。 参数含义：支持变更的指标参数。 取值范围：枚举项。 METRIC_TYPE(指标分类) 默认值：无。 配置原则：无。                                                                                                                                                                                        |
| METRIC_TYPE | 指标分类   | 可选必选说明：当“类型”配置为“METRIC_TYPE(指标分类)”时为条件可选参数。 参数含义：指标的分类选项。 取值范围：位域项 NORTH(北向指标)BASIC(基础指标)EXTEND(扩展指标)KPI(KPI指标) 默认值：无。 配置原则： 不输入或“全部灰化”，表示指标分类恢复默认类型。“全部清空”，表示配置指标不属于任何指标分类。“全部选中”，表示配置指标属于取值范围四种指标分类。勾选取值范围中的多个，表示配置指标属于所勾选指标分类。指标分类去勾选或者非全部灰化，都表示指标不属于该指标分类。 |

## 使用实例

设置话统测量指标参数：

```
%%SET MEASMETRIC: MEID=800, METRICID=4100153, TYPE=METRIC_TYPE, METRIC_TYPE=KPI-1;%% 
RETCODE = 0  操作成功    

 ---    END
```
