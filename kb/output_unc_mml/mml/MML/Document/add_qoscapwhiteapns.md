# 增加不受SMFQOSCAP配置控制的APN白名单列表。（ADD QOSCAPWHITEAPNS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于增加不受SMFQOSCAP配置控制的APN白名单列表。

## 注意事项

- 命令执行后只对新接入用户生效。

- 最多可输入2048条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                               |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN      | APN    | 可选必选说明：必选参数  参数含义：该参数用于指定APN实例名。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无  配置原则：  该参数使用ADD APN命令配置生成。                                                                                                                                                                     |
| SUBRANGE | 用户范围   | 可选必选说明：必选参数  参数含义：该参数用于指定待增加QoS限制配置的用户范围。  数据来源：全网规划 取值范围： INVALIDSUBRANGE（无效的用户范围）IMSI_PREFIX（指定IMSI前缀的用户）VISITING（拜访用户）ROAMING（漫游用户）HOME_USER（本网用户）ALL_USER（所有用户）HOME_NOLOCAL_USER（本网非本省用户）  默认值：无  配置原则：  “SUBRANGE（用户范围）”的优先级从高到低为：“IMSI_PREFIX（指定IMSI前缀）”，“HOME_USER（本网用户）”或“ROAMING（漫游用户）”或“VISITING（拜访用户）”，“ALL_USER（所有用户）”。                                                                                |
| IMSIPRE  | IMSI前缀 | 可选必选说明：该参数在"SUBRANGE"配置为"IMSI_PREFIX"时为条件必选参数。  参数含义：该参数用于系统根据对用户的IMSI进行匹配，从而区分不同的用户群。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是5~15。  默认值：无  配置原则：  IMSI前缀取决于需要使用本条QoS限制的IMSI范围；  确定IMSI前缀时应遵循最大匹配原则。例如，对于IMSI号在308010700000000～308010700099999范围内的用户都需要将QoS信息限制为某一组数值，则应配置一条IMSI前缀为“3080107000”的记录；  当IMSI符合多条QoS限制配置的IMSI前缀时，采用匹配位数最多的记录。例如：用户IMSI号为308010700000001，有2条QoS限制配置的IMSI前缀分别为“30801”和“3080107”，则采用“3080107”的记录。 |

## 使用实例

增加不受QOSCAP配置控制的APN白名单列表，APN为“huawei.com”，用户范围为“IMSI\_PREFIX”，IMSI前缀为“3080107000”：

```
ADD QOSCAPWHITEAPNS:APN="huawei.com",SUBRANGE=IMSI_PREFIX, IMSIPRE="3080107000"
```
