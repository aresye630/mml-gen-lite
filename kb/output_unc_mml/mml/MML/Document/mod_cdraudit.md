#### 命令功能

**适用NF：NCG**

该命令用于修改某通道下或所有通道下第二份最终话单的稽核规则。

#### 注意事项

- 该命令执行后立即生效。
- 执行该命令后，可能会影响稽核文件的格式，比如：文件名、稽核参数等，修改后的格式将在第二天生成的正式文件中体现，第二天生成的正式文件的格式以最后一次修改的配置为准。 不能通过该命令修改“通道名称”。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

| CHLNAME       | 通道名称          | 可选必选说明：可选参数 参数含义：通道名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则： 通道名称需要通过执行DSP FEMPACKET来获取。所有通道下的话单稽核规则相同时，配置为“All”，表示一次性配置所有通道下的话单稽核规则。配置为具体的通道名，表示配置当前通道下的话单稽核规则。具体通道下话单的配置规则优先级高于值为“All”的通道配置。当配置了具体通道下的话单配置规则后，先前配置为“All”的话单稽核，就变为除具体通道外的其他通道下的话单稽核规则。二级通道之间的路径分割符为“/”。例如二级通道：scdr/mmr。通道名称不能被修改。不能输入的特殊字符请参考“特殊字符表”。 |

| AUDITFORMAT   | 稽核内容格式        | 可选必选说明：可选参数 参数含义：话单稽核文件内容的格式。 数据来源：本端规划 取值范围：枚举类型。 txt：Txt格式。csv：Csv格式。 默认值：无 配置原则： 目前支持txt与csv格式。 txt为定长格式，稽核参数均为定长，参数间以空格分隔。csv为变长格式，稽核参数以“，”分隔。 当选择“稽核参数分隔符”为“分号”或者“竖线”时，无论“稽核内容格式”为“txt格式”还是“csv格式”，稽核参数均为变长，参数间以分号或者竖线分隔。                                                                                                 |
| ISCOLLECTINFO | 是否汇总稽核信息      | 可选必选说明：可选参数 参数含义：是否汇总稽核信息。 数据来源：本端规划 取值范围：枚举类型。 NO：否。YES：是。 默认值：无 配置原则：当选择此参数为“是”，则在稽核文件尾部汇总当前稽核文件信息，包括话单文件总数、话单文件话单总张数和话单文件总大小等信息。                                                                                                                                                                                            |
| ISADDNOTES    | 是否添加文件抬头      | 可选必选说明：可选参数 参数含义：是否在稽核文件的第一行显示每列的含义。 数据来源：本端规划 取值范围：枚举类型。 NO：否。YES：是。 默认值：无 配置原则：当选择此参数为“是”，则在稽核文件的第一行根据配置显示每列的含义。                                                                                                                                                                                                             |
| AUDITPARA1    | 话单稽核参数1       | 可选必选说明：可选参数 参数含义：配置话单稽核文件统计的稽核指标。 数据来源：本端规划 取值范围：枚举类型。 CDRFileName：话单文件名。CDRNumber：话单文件话单张数。CDRFileSize：话单文件大小。CDRFileModifyTime：话单文件修改时间。 默认值：无 配置原则：各个话单稽核参数中必须有一个配置为“话单文件名”，且不同的稽核指标不能重复配置。                                                                                                                                 |
| AUDITPARA2    | 话单稽核参数2       | 可选必选说明：可选参数 参数含义：配置话单稽核文件统计的稽核指标。 数据来源：本端规划 取值范围：枚举类型。 CDRFileName：话单文件名。CDRNumber：话单文件话单张数。CDRFileSize：话单文件大小。CDRFileModifyTime：话单文件修改时间。 默认值：无 配置原则：各个话单稽核参数中必须有一个配置为“话单文件名”，且不同的稽核指标不能重复配置。                                                                                                                                 |

#### 使用实例

修改标识为“Audit”话单稽核任务中稽核文件保存天数。示例如下：

```
MOD CDRAUDIT: CDRAUDITID="Audit", AGID="PS_GROUP_1", AUDITSTORDAYS=10;
```
