# 查询QoS监测配置（LST QOSMONT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF**

该命令用于查询QoS监测配置。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询QoS监测配置，执行如下命令：

```
%%LST QOSMONT:;%%
RETCODE = 0  操作成功

结果如下
--------
           QoS监测开关 = 使能
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释           |
|:--------|:----------------|
| QoS监测开关 | 该参数用于配置QoS监测开关。 |
