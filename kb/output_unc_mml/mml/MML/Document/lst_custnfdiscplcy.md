# 查询自定义NF的服务发现策略（LST CUSTNFDISCPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF、CBC、CBCF**

该命令用于查询配置的自定义服务发现流程的策略。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询配置的自定义服务发现流程策略。

```
%%LST CUSTNFDISCPLCY:;%%
RETCODE = 0  操作成功

结果如下
--------
服务发现PCSCF策略  =  反亲和组
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称       | 输出项解释               |
|:------------|:--------------------|
| 服务发现PCSCF策略 | 该参数用于指定服务发现PCSCF策略。 |
