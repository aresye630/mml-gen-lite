# 查询省份性能统计对象（LST PERFPROVINCE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询省份性能统计对象的配置。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                      |
|:---------|:-------|:------------------------------------------------------------------------------------------|
| PROVINCE | 省份     | 可选必选说明：可选参数  参数含义：该参数用于标识基于省份性能统计对象名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。  默认值：无  配置原则：无 |

## 使用实例

查询名称为“BEIJING”的性能统计对象，执行如下命令：

```
%%LST PERFPROVINCE: PROVINCE="BEIJING";%%
RETCODE = 0  操作成功

结果如下
--------
       省份  =  BEIJING
   省份编号  =  01
(结果个数= 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                   |
|:--------|:------------------------|
| 省份      | 该参数用于标识基于省份性能统计对象名称。    |
| 省份编号    | 该参数用于标识省份性能统计对象对应的省份标号。 |
