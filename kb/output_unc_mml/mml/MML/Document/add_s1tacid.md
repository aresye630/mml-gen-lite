# 增加TAC组内绑定的S1TAC号段（ADD S1TACID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C**

该命令用来在TAC组内绑定TAC号段。当需要在指定TAC组内绑定某个TAC号段时，使用该命令。

## 注意事项

- 该命令执行后立即生效。

- 当一个TAC号段被绑定到某个TAC组内后，就不允许再绑定到其他的TAC组。TAC号段之间的TAC值不允许重叠。

- 最多可输入9000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                                                                                       |
|:-------------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TACSECNUM    | TAC段编号  | 可选必选说明：必选参数  参数含义：该参数用于指定TAC段编号。  数据来源：本端规划  取值范围：整数类型，取值范围是0~15999。  默认值：无  配置原则：无                                                                                                        |
| TACSTARTID   | TAC起始ID | 可选必选说明：必选参数  参数含义：该参数用于指定TAC起始ID。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是3~6。字符串类型，长度为3至6位。必须是0x/X开头的十六进制数，仅支持输入0x/X、0-9、a-f/A-F，字母不区分大小写，取值范围0x0~0xFFFF。  默认值：无  配置原则：  TACSTARTID一定要小于等于TACENDID。 |
| TACENDID     | TAC截止ID | 可选必选说明：必选参数  参数含义：该参数用于指定TAC截止ID。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是3~6。字符串类型，长度为3至6位。必须是0x/X开头的十六进制数，仅支持输入0x/X、0-9、a-f/A-F，字母不区分大小写，取值范围0x0~0xFFFF。  默认值：无  配置原则：  TACSTARTID一定要小于等于TACENDID。 |
| TACGROUPNAME | TAC组名   | 可选必选说明：必选参数  参数含义：该参数用于指定TAC组名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。不支持空格，不区分大小写。  默认值：无  配置原则：  本参数通过ADD TACGROUP命令进行配置，且TAC类型必须是S1TAC。                                                    |

## 使用实例

假设运营商需要在一个本地已经配置的TAC组绑定一个TAC号段：

```
ADD S1TACID:TACSECNUM=2,TACSTARTID="0x0001",TACENDID="0x0010",TACGROUPNAME="BEIJING";
```
