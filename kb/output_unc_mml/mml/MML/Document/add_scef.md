# 增加SCEF配置(ADD SCEF)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于配置SCEF信息。

#### 注意事项

- 该命令执行后立即生效。
- 该表最大记录数为256。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                                         |
|:--------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------|
| SCEFRLM | SCEF域名  | 可选必选说明：必选参数 参数含义：该参数用于指定SCEF域名。 数据来源：对端协商 取值范围：1~127位字符串 默认值：无 配置原则：不允许配置字符串“NULL”。不能为非法字符，只允许输入字母，数字，“.”和“-”，大小写不敏感。与对端SCEF配置的SCEF域名保持一致。   |
| SCEFHTN | SCEF主机名 | 可选必选说明：必选参数 参数含义：该参数用于指定SCEF主机名。 数据来源：对端协商 取值范围：1~127位字符串 默认值：无 配置原则：不允许配置字符串“NULL”。不能为非法字符，只允许输入字母，数字，“.”和“-”，大小写不敏感。与对端SCEF配置的SCEF主机名保持一致。 |

#### 使用实例

增加SCEF域名为example01.com，SCEF主机名为scef0701.example01.com的一条记录：

ADD SCEF: SCEFRLM="example01.com", SCEFHTN="scef0701.example01.com";
