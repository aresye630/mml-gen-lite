# 增加配额耗尽后的动作（ADD QUOTAEXHAUSTACT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于增加在线RG配额耗尽后的动作。

## 注意事项

- 该命令执行后只对新激活用户生效。

- 最多可输入101条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称        | 参数说明                                                                                                                                                                                                                                               |
|:------------|:------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CCTMPLTNAME | 融合计费模板名称    | 可选必选说明：必选参数  参数含义：该参数用于指定融合计费模板的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。不区分大小写。  默认值：无  配置原则：  该参数使用ADD CCT命令配置生成。                                                                                                                                  |
| ACTION      | 在线RG配额耗尽后动作 | 可选必选说明：可选参数  参数含义：该参数用于指定在线RG配置耗尽后动作。  数据来源：本端规划  取值范围：不配置此参数时值默认为0，表示不下发在线RG配额耗尽后动作。 “BLOCK（阻塞业务，使业务不能继续进行）”：阻塞业务，使业务不能继续进行。“REDIRECT（将当前业务重定向到指定的地址）”：将当前业务重定向到指定的地址。“FORWARD（允许继续转发业务）”：允许继续转发业务。  默认值：无  配置原则：  不配置此参数时值默认为0，表示不下发在线RG配置耗尽后动作。 |
| RDVIRTIP    | 重定向IPv4地址   | 可选必选说明：该参数在"ACTION"配置为"REDIRECT"时为条件可选参数。  参数含义：该参数用于指定在线RG配额耗尽后重定向动作的IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：  不配置此参数时值默认为0.0.0.0。                                                                                                        |
| RDVIRTIPV6  | 重定向IPv6地址   | 可选必选说明：该参数在"ACTION"配置为"REDIRECT"时为条件可选参数。  参数含义：该参数用于指定在线RG配额耗尽后重定向动作的IPv6地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：  不配置此参数时值默认为::。                                                                                                             |

## 使用实例

增加融合计费模板名为global的在线RG配额耗尽后动作为阻塞业务：

```
ADD QUOTAEXHAUSTACT: CCTMPLTNAME="global", ACTION=BLOCK;
```
