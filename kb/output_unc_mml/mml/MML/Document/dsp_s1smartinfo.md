# 显示S1模式用户信令状态(DSP S1SMARTINFO)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用网元：MME**

该命令用于查询S1模式下的用户信令状态。

#### 注意事项

- 该命令执行后立即生效。
- 该命令查询的请求次数显示为当前统计周期内的请求次数，统计周期为1小时。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                             |
|:-------|:-------|:---------------------------------------------------------------------------------|
| IMSI   | IMSI   | 可选必选说明：必选参数 参数含义：该参数用于指定用户的国际移动用户标识。 是否必选：必选 数据来源：本端规划 取值范围：1～15位十进制数字字符串。 默认值：无 |

#### 输出结果说明

| 输出项名称       | 输出项解释                                 |
|:------------|:--------------------------------------|
| IMSI        | 显示用户的国际移动用户标识。                        |
| 终端类型        | 显示用户的终端类型，由ADD IMEILIB命令配置。           |
| 附着抑制类型      | 显示用户的附着流程抑制状态。                        |
| 附着抑制策略      | 显示用户的附着流程抑制策略信息。取值范围：整系统、用户范围、无。      |
| 附着请求次数      | 显示当前统计周期内用户的附着请求次数。                   |
| 服务请求抑制类型    | 显示用户的服务请求流程抑制状态。                      |
| 服务请求抑制策略    | 显示用户的服务请求流程抑制策略信息。取值范围：整系统、用户范围、无。    |
| 服务请求次数      | 显示当前统计周期内用户的服务请求次数。                   |
| 控制面服务请求抑制类型 | 显示用户的控制面服务请求流程抑制状态。                   |
| 控制面服务请求抑制策略 | 显示用户的控制面服务请求流程抑制策略信息。取值范围：整系统、用户范围、无。 |
| 控制面服务请求次数   | 显示当前统计周期内用户的控制面服务请求次数。                |
| APN个数       | 显示用户的PDN连接流程使用的APN个数。                 |
| APN标识       | 显示用户的PDN连接流程使用的APN网络标识。               |
| PDN连接抑制类型   | 显示用户的APN粒度的PDN连接抑制状态。                 |
| PDN连接抑制策略   | 显示用户的PDN连接抑制策略信息。取值范围：整系统、用户范围、无。     |
| PDN连接请求次数   | 显示当前统计周期内用户的APN粒度的PDN连接请求次数。          |
