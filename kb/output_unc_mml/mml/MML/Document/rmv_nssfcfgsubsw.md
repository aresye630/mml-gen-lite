# 删除按签约NSSAI分配Configed NSSAI的PLMN级别开关（RMV NSSFCFGSUBSW）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NSSF**

该命令用于删除按签约NSSAI生成configuredNssai信元的PLMN级别开关。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                        |
|:-------|:-------|:--------------------------------------------------------------------------------------------|
| MCC    | 移动国家码  | 可选必选说明：必选参数  参数含义：该参数用于描述移动国家码。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。3位十进制数。  默认值：无  配置原则：无        |
| MNC    | 移动网号   | 可选必选说明：必选参数  参数含义：该参数用于描述移动网号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。2位或者3位十进制数。  默认值：无  配置原则：无 |

## 使用实例

假如运营商希望删除一条移动国家码为235、移动网号为36的记录，执行以下命令。

```
RMV NSSFCFGSUBSW: MCC="235", MNC="36";
```
