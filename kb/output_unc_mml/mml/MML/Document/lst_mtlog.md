# 查询维护类工具加载日志（LST MTLOG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于网元查询维护类工具的加载日志。

## 注意事项

无

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                      |
|:-------|:-------|:------------------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：可选参数。 参数含义：用于指示系统按照网元ID来查询维护类工具加载日志；若不输入则查询所有的维护类工具记载日志。 取值范围：0~1024 默认值：无。 配置原则：无 |

## 使用实例

1. 维护类工具的加载日志：

   ```
   %%LST MTLOG: MEID=0;%% 
   RETCODE = 0  操作成功  
   维护类工具加载日志 
   ------------------ 
   网元名称      网元ID  网元类型  基础版本     补丁版本  工具包名称                      操作类型  操作时间               
   csp           0       CSP       26.0.0.B210  26.0.0.1  maintenance_26.0.0.B210.tar.gz  安装      2025-08-31 23:14:23   
   csp           0       CSP       26.0.0.B210  26.0.0.1  maintenance_26.0.0.B210.tar.gz  回退      2025-09-01 21:16:23   
   (结果个数 = 2)  
   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回操作成功的提示信息和相关参数，各参数含义请参见表1 输出项说明所示。

该命令执行异常，会返回对应的错误码。常见错误码如表2 错误码列表所示。

| 输出项名称   | 输出项解释                                  |
|:--------|:---------------------------------------|
| 网元名称    | 网元名称。                                  |
| 网元ID    | 网元的ID信息。                               |
| 网元类型    | 网元的类型。                                 |
| 基础版本    | 维护类工具加载时网元的基线版本。                       |
| 补丁版本    | 维护类工具加载时网元的补丁版本号。                      |
| 工具包名称   | 维护类工具包的名称。                             |
| 操作类型    | 对维护类工具包操作的类型： 安装：安装维护类工具包。回退：回退维护类工具包。 |
| 操作时间    | 进行维护类工具加载的时间。                          |

|    错误码 | 错误码解释   | 原因分析           | 处理建议         |
|-------:|:--------|:---------------|:-------------|
| 112004 | 内部错误    | 升级工具处理MML命令异常。 | 请联系华为技术支持处理。 |
