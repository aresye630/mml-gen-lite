# 修改QosFlow QoS限制的配置（MOD SMFQOSCAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于修改QosFlow QoS限制的相关配置。

## 注意事项

- 命令执行后只对新接入用户生效。

- QOSIDTYPE为non-GBR时，只允许5QI在[5，9]，[69，70]，[79，80]范围内；若为GBR类型，则只允许[1，4]，[65，67]，[71，76]，[82，86]范围内；
- 上行保证带宽不能大于上行最大带宽；
- 下行保证带宽不能大于下行最大带宽。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称              | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                               |
|:----------|:------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE  | 用户范围              | 可选必选说明：必选参数  参数含义：该参数用于指定待增加QosFlow QoS限制配置的用户范围。  数据来源：全网规划 取值范围： INVALIDSUBRANGE（无效的用户范围）IMSI_PREFIX（指定IMSI前缀的用户）VISITING（拜访用户）ROAMING（漫游用户）HOME_USER（本网用户）ALL_USER（所有用户）HOME_NOLOCAL_USER（本网非本省用户）  默认值：无  配置原则：  “SUBRANGE（用户范围）”的优先级从高到低为：“IMSI_PREFIX（指定IMSI前缀）”，"HOME_NOLOCAL_USER"（本网非本省用户），“HOME_USER（本网用户）”或“ROAMING（漫游用户）”或“VISITING（拜访用户）”，“ALL_USER（所有用户）”。                                           |
| QOSIDTYPE | QoS资源类型           | 可选必选说明：必选参数  参数含义：该参数用于表示组成QosFlow QoS控制的QoS类型。  数据来源：全网规划 取值范围： NONGBR（指定QoS ID的资源类型为Non-GBR）GBR（指定QoS ID的资源类型为GBR）  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                |
| IMSIPRE   | IMSI前缀            | 可选必选说明：该参数在"SUBRANGE"配置为"IMSI_PREFIX"时为条件必选参数。  参数含义：该参数用于系统根据对用户的IMSI进行匹配，从而区分不同的用户群。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是5~15。  默认值：无  配置原则：  IMSI前缀取决于需要使用本条QoS限制的IMSI范围；  确定IMSI前缀时应遵循最大匹配原则。例如，对于IMSI号在308010700000000～308010700099999范围内的用户都需要将QoS信息限制为某一组数值，则应配置一条IMSI前缀为“3080107000”的记录；  当IMSI符合多条QoS限制配置的IMSI前缀时，采用匹配位数最多的记录。例如：用户IMSI号为308010700000001，有2条QoS限制配置的IMSI前缀分别为“30801”和“3080107”，则采用“3080107”的记录。 |
| AMBRUL    | 上行APN AMBR(千比特/秒) | 可选必选说明：该参数在"QOSIDTYPE"配置为"NONGBR"时为条件可选参数。  参数含义：该参数用于指定系统对用户的上行Session-AMBR限制。  数据来源：全网规划  取值范围：整数类型，取值范围是1~65000000。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                              |
| AMBRDL    | 下行APN AMBR(千比特/秒) | 可选必选说明：该参数在"QOSIDTYPE"配置为"NONGBR"时为条件可选参数。  参数含义：该参数用于指定系统对用户的下行Session-AMBR限制。  数据来源：全网规划  取值范围：整数类型，取值范围是1~65000000。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                              |
| QOS5QI    | 标准5QI             | 可选必选说明：可选参数  参数含义：该参数用于指定系统对用户的QosFlow的5QI限制。  数据来源：全网规划  取值范围：整数类型，取值范围是1~255。  默认值：无  配置原则：  取值范围是1~9，65~67，69~76，79~80，82~86；  当SMFQOSCAP命令中的QOSIDTYPE为non-GBR时，只允许5QI在[5，9]，[69，70]，[79，80]范围内；若为GBR类型，则只允许[1，4]，[65，67]，[71，76]，[82，86]范围内，否则报错；  如果网络下发扩展5QI，则采用QOSIDTYPE为NONGBR配置的5QI进行覆盖。                                                                                                                  |
| QOS5QIPL  | 5QI的优先级别          | 可选必选说明：可选参数  参数含义：该参数表示5QI优先级。  数据来源：全网规划  取值范围：整数类型，取值范围是1~127。  默认值：无  配置原则：  5QI Priority Level取值为0时，表示无效值。此时给RAN的“Non Dynamic 5QI Descriptor”中不携带“Priority Level”。                                                                                                                                                                                                                                             |
| ARPPRL    | ARP的优先级别          | 可选必选说明：可选参数  参数含义：该参数用于指定系统对用户的ARP优先级别限制。  数据来源：全网规划  取值范围：整数类型，取值范围是1~15。  默认值：无  配置原则：  取值越小，优先级越高。                                                                                                                                                                                                                                                                                                              |
| ARPPCI    | ARP的抢占能力          | 可选必选说明：可选参数  参数含义：该参数用于指定系统对用户的ARP抢占能力限制。  数据来源：全网规划 取值范围： INVALID（无效的ARPPCI）“MAY_PREEMPT（抢占）”：允许该承载抢占其他ARP的优先级别较低的承载的资源“NOT_PREEMPT（不抢占）”：不允许该承载抢占其他ARP的优先级别较低的承载的资源  默认值：无  配置原则：无                                                                                                                                                                                                                               |
| ARPPVI    | ARP的被抢占能力         | 可选必选说明：可选参数  参数含义：该参数用于指定系统对用户的ARP被抢占能力限制。  数据来源：全网规划 取值范围： INVALID（无效的ARPPVI）“PREEMPTABLE（可抢占）”：允许其他优先级别较高的承载抢占该承载的资源。“NOT_PREEMPTABLE（不可抢占）”：不允许其他优先级别较高的承载抢占该承载的资源  默认值：无  配置原则：无                                                                                                                                                                                                                               |
| MFBRUL    | 上行最大速率(千比特/秒)     | 可选必选说明：该参数在"QOSIDTYPE"配置为"GBR"时为条件可选参数。  参数含义：该参数用于指定组成QoS控制的GBR QoS Flow的上行最大速率。  数据来源：全网规划  取值范围：整数类型，取值范围是1~65000000。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                            |
| MFBRDL    | 下行最大速率(千比特/秒)     | 可选必选说明：该参数在"QOSIDTYPE"配置为"GBR"时为条件可选参数。  参数含义：该参数用于指定组成QoS控制的GBR QoS Flow的下行最大速率。  数据来源：全网规划  取值范围：整数类型，取值范围是1~65000000。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                            |
| GFBRUL    | 上行保证速率(千比特/秒)     | 可选必选说明：该参数在"QOSIDTYPE"配置为"GBR"时为条件可选参数。  参数含义：该参数用于指定组成QoS控制的GBR QoS Flow的上行保证速率。  数据来源：全网规划  取值范围：整数类型，取值范围是1~65000000。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                            |
| GFBRDL    | 下行保证速率(千比特/秒)     | 可选必选说明：该参数在"QOSIDTYPE"配置为"GBR"时为条件可选参数。  参数含义：该参数用于指定组成QoS控制的GBR QoS Flow的下行保证速率。  数据来源：全网规划  取值范围：整数类型，取值范围是1~65000000。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                            |
| QOSACTION | QoS协商动作           | 可选必选说明：可选参数  参数含义：该参数用于指定UNC接收到网络下发的QosFlow QoS参数的处理方法。  数据来源：全网规划 取值范围： “ACCEPT（接受QoS）”：使用网络侧下发的QoS信息进行相应的流程。“RESTRICT（限制QoS）”：系统综合考虑配置QoS和网络侧下发的QoS，除5QI直接替换外，其他参数选取两者中较为严格的QoS参数对用户的QoS进行限制。“REPLACE（替换QoS）”：使用本地配置替换QoS  默认值：无  配置原则：  默认值：ACCEPT（接受QoS）。                                                                                                                                                      |

## 使用实例

修改“用户范围”为“IMSI\_PREFIX”，“IMSI前缀”为“3080107000”，“QoS资源类型”为“NONGBR”的SMFQOSCAP配置，修改“上行APN AMBR”为“16600000”，“下行APN AMBR”为“20000”

```
MOD SMFQOSCAP:SUBRANGE=IMSI_PREFIX,IMSIPRE="3080107000",QOSIDTYPE=NONGBR,AMBRUL=16600000,AMBRDL=20000;
```
