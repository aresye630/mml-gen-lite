# 修改NRF局向性能统计对象识别标识（MOD NRFPERFPNFIID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于修改NRF局向性能统计对象识别标识。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称        | 参数说明                                                                                                                                                |
|:-----------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| INDEX      | 标识索引        | 可选必选说明：必选参数  参数含义：该参数用于表示NRF上局向性能统计对象的标识索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~2147483647。  默认值：无  配置原则：无                                                 |
| PEERNFNAME | 对端NF实例名称    | 可选必选说明：必选参数  参数含义：该参数用于表示对端网元的实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~255。  默认值：无  配置原则：  本参数的构成字符只能是字母A～Z或a～z、数字0～9、中划线"-"和下划线"_"，例如，AMF_Instance_0。 |
| PEERNFIPV4 | 对端NF的IPV4地址 | 可选必选说明：可选参数  参数含义：该参数用于表示对端网元的IPV4地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无                                                                     |
| PEERNFIPV6 | 对端NF的IPV6地址 | 可选必选说明：可选参数  参数含义：该参数用于表示对端网元的IPV6地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无                                                                     |
| PEERNFID   | 对端NF实例标识    | 可选必选说明：可选参数  参数含义：该参数用于表示对端网元的实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：  需与运营商规划的网元的实例标识一致。                                          |

## 使用实例

运营商需要将INDEX为1,PEERNFNAME 为AMF\_Instance\_0的性能统计标识的IPV4地址修改为“192.168.21.1”时，可执行如下配置：

```
MOD NRFPERFPNFIID: INDEX=1, PEERNFNAME="AMF_Instance_0", PEERNFIPV4="192.168.21.1";
```
