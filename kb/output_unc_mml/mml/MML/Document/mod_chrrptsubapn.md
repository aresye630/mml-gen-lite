# 修改基于APN的存储CHR表单（MOD CHRRPTSUBAPN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于修改基于APN的存储CHR表单。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称           | 参数说明                                                                                                                                                                                                                           |
|:------------|:---------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN         | APN            | 可选必选说明：必选参数  参数含义：该参数用于指定APN实例名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无  配置原则：  该参数必须已经通过命令ADD APN配置。 |
| TMPLIDX     | 流程模板索引         | 可选必选说明：可选参数  参数含义：该参数用于流程控制模板索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~127。该参数需要在ADD SESSNCHRPRCTMPL命令中已配置。  默认值：无  配置原则：无                                                                                                              |
| CHRFAILSAVE | 失败流程CHR单据的存储路径 | 可选必选说明：可选参数  参数含义：该参数用于指定失败流程CHR单据的存储路径。  数据来源：本端规划 取值范围： SAVE_OMU（保存到OMU）SAVE_UCF（保存到UCF）SAVE_OMU_AND_UCF（保存到OMU和UCF）  默认值：无  配置原则：无                                                                                          |
| CHRALLSAVE  | 成功流程CHR单据的存储路径 | 可选必选说明：可选参数  参数含义：该参数用于指定成功流程CHR单据的存储路径。  数据来源：本端规划 取值范围： SAVE_OMU（保存到OMU）SAVE_UCF（保存到UCF）SAVE_OMU_AND_UCF（保存到OMU和UCF）  默认值：无  配置原则：无                                                                                          |

## 使用实例

修改APN为“HUAWEI.COM”的绑定模板ID：

```
MOD CHRRPTSUBAPN: APN="HUAWEI.COM", TMPLIDX=1;
```
