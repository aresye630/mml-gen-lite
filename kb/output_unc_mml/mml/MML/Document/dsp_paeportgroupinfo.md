# 显示PAE端口组信息（DSP PAEPORTGROUPINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示PAE端口组信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                |
|:-------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CELLTYPE     | 微服务类型  | 可选必选说明：可选参数 参数含义：该参数用于指定微服务类型。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～63。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符。 默认值：无 配置原则：使用DSP PAENODE查看工作角色为数据转发对应的微服务类型。    |
| CELLINSTANCE | 微服务实例号 | 可选必选说明：可选参数 参数含义：该参数用于指定微服务实例号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～127。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符。 默认值：无 配置原则：使用DSP PAENODE查看工作角色为数据转发对应的微服务实例号。 |

#### 使用实例

- 显示微服务类型为“104”微服务实例为“csdb-pod-0172-16-1-200\_\_103\_\_0”的PAE端口组信息：

  ```
  %%DSP PAEPORTGROUPINFO: CELLTYPE="104", CELLINSTANCE="csdb-pod-0172-16-1-200__103__0";%%
  RETCODE = 0  操作成功

  结果如下:

  ---    END
  ```
