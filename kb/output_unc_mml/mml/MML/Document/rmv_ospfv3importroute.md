# 删除OSPFv3引入路由配置（RMV OSPFV3IMPORTROUTE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来删除引入到OSPFv3域中的外部路由。

#### 注意事项

- 该命令执行后立即生效。
- 只有配置了OSPFv3进程和引入外部路由后才能使用该命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称      | 参数说明                                                                                                         |
|:---------------|:----------|:-------------------------------------------------------------------------------------------------------------|
| PROCID         | OSPFv3进程号 | 可选必选说明：必选参数 参数含义：OSPFv3进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无                                     |
| TOPOID         | 拓扑标识      | 可选必选说明：可选参数 参数含义：拓扑标识。 数据来源：全网规划 取值范围：整数类型，取值范围为0。 默认值：无 配置原则：目前只支持默认拓扑0。                                    |
| PROTOCOL       | 协议号       | 可选必选说明：必选参数 参数含义：协议号。 数据来源：本端规划 取值范围：枚举类型。 direct：直连路由。static：静态路由。bgp：BGP协议。ospfv3：OSPFv3协议。wlr：无线路由。 默认值：无 |
| PROTOCOLPROCID | 协议进程号     | 可选必选说明：条件可选参数 前提条件：该参数在“PROTOCOL”配置为“ospfv3”时为可选参数。 参数含义：协议进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 |

#### 使用实例

将OSPFv3进程1下引入的OSPFv3进程2的路由删除：

```
RMV OSPFV3IMPORTROUTE: PROCID=1, TOPOID=0, PROTOCOL=ospfv3, PROTOCOLPROCID=2;
```
