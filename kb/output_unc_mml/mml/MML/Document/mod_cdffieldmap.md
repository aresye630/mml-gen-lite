# 修改话单中字段的映射值（MOD CDFFIELDMAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NCG**

该命令用于修改话单中字段值的映射关系。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

修改字段名称为PDUTRIGGER，trigger类型为QUOTATHRESHOLD的映射值为1001：

```
MOD CDFFIELDMAP: FIELDNAME=PDUTRIGGER, TRIGGERTYPE=QUOTATHRESHOLD, MAPVALUE=1001;
```
