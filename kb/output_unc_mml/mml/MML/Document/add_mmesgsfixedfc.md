# 增加VLR局向Sgs固定速率流控 (ADD MMESGSFIXEDFC)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SMSF**

此命令用于增加VLR局向Sgs固定速率流控相关参数。

#### 注意事项

此命令的最大记录数为2000。

#### 本地用户权限

manage-ug；system-ug；

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；

#### 参数说明

| 参数标识      | 参数名称                             | 参数说明                                                                                                                                            |
|:----------|:---------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------|
| MMEIDX    | MME索引                            | 可选必选说明：必选参数 参数含义：该参数用于指定一个MME实体，在全局范围内唯一。 数据来源：本端规划 取值范围：整数类型，取值范围为0~1999 默认值：无 配置原则： 该参数来源于ADD SGSMME中的"MMEX"参数。                               |
| LURTHD    | Location Update Request速率门限(个/秒) | 可选必选说明：可选参数 参数含义：该参数用于设置VLR接收Location Update Request速率门限。对应消息数量超过该门限值时，部分消息会被流控，不处理。 数据来源：全网规划 取值范围：整数类型，取值范围为1~1000000，单位是个每秒。 默认值：1500 配置原则：无 |
| DETACHTHD | Detach Indication速率门限(个/秒)       | 可选必选说明：可选参数 参数含义：该参数用于设置VLR接收Detach Indication速率门限。对应消息数量超过该门限值时，部分消息会被流控，不处理。 数据来源：全网规划 取值范围：整数类型，取值范围为1~1000000，单位是个每秒。 默认值：500 配置原则：无        |
| PAGINGTHD | Paging速率门限(个/秒)                  | 可选必选说明：可选参数 参数含义：该参数用于设置VLR发送Paging速率门限。对应消息数量超过该门限值时，部分消息会被流控，不处理。 数据来源：全网规划 取值范围：整数类型，取值范围为1~1000000，单位是个每秒。 默认值：2000 配置原则：无                  |

#### 使用实例

增加VLR局向Sgs固定速率流控，MMEIDX为1。

```
ADD MMESGSFIXEDFC: MMEIDX=1;
```
