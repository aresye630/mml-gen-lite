# 查询ICMP6统计（DSP ICMP6STAT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示ICMPv6报文统计计数。

若不指定IFNAME参数时，则显示所有接口的ICMPv6报文统计计数。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                |
|:-------|:-------|:----------------------------------------------------------------------------------------------------|
| IFNAME | 接口名    | 可选必选说明：可选参数 参数含义：该参数用于指定接口名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。 |

#### 使用实例

显示ICMPv6报文统计计数：

```
DSP ICMP6STAT:IFNAME="Ethernet65/0/8";
```


#### 输出结果说明

| 输出项名称   | 输出项解释         |
|:--------|:--------------|
| 收到NA    | 用于显示收到NA报文个数。 |
| 发送NA    | 用于显示发送NA报文个数。 |
| 收到RA    | 用于显示收到RA报文个数。 |
| 发送RA    | 用于显示发送RA报文个数。 |
| 收到NS    | 用于显示收到NS报文个数。 |
| 发送NS    | 用于显示发送NS报文个数。 |
| 收到RS    | 用于显示收到RS报文个数。 |
| 发送RS    | 用于显示发送RS报文个数。 |
