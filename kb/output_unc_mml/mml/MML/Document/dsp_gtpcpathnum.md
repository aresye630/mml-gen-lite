#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询指定节点的GTP-C路径数目。

#### 注意事项

- 该命令执行后立即生效。
- 该命令可用于SPP进程/UPP进程。
- 当“进程类型”未输入时，默认查询UPP进程上的路径数目信息。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                                                |
|:------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RUNAME      | RU名称   | 可选必选说明：可选参数 参数含义：该参数用于指定资源单元名称。该参数可以通过DSP RU命令查询。 取值范围：1~63位字符串 默认值：无                                                                                                                                                                               |
| PROCTP      | 进程类型   | 可选必选说明：可选参数 参数含义：该参数用于指定进程的进程类型。 取值范围： “SPP(SPP)”“UPP(UPP)” 默认值：无                                                                                                                                                                                   |
| PROCNO      | 进程号    | 可选必选说明：可选参数 参数含义：该参数用于指定进程的序号。 取值范围：0~20 默认值：无                                                                                                                                                                                                      |
| QRYTP       | 查询类型   | 可选必选说明：可选参数 参数含义：该参数用于指定查询类型。 取值范围：“MEMORY(内存)”“DDB(数据库)” 默认值：“MEMORY(内存)”  说明： 内存中的GTP-C路径数目是由本进程创建的路径数。DDB中的GTP-C路径数目是由UPP创建的路径数。                                                                                                                 |
| SERVICETYPE | 服务名称   | 可选必选说明：必选参数 参数含义：此参数用于指定待查询的服务名称，可以通过LST VNFC命令查询得到。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。数字“0~9”，大写字母“A~Z”，小写字母“a~z”，特殊字符“-”，“_”，其他均为非法字符，并且首字符必须为字母。 默认值：无 配置原则：如果要查询SPP进程上的GTPC路径，则SERVICETYPE需要填写USN的名称。如果要查询UPP进程上的GTPC路径，则SERVICETYPE需要填写LINK的名称。 |

#### 使用实例

查询资源单元为USN\_SP\_RU\_0064上的V2版本GTP-C路径数目：

DSP GTPCPATHNUM: RUNAME="USN\_SP\_RU\_0064",SERVICETYPE="USN\_VNFC";

```
%%DSP GTPCPATHNUM: RUNAME="USN_SP_RU_0064", SERVICETYPE="USN_VNFC";%%
RETCODE = 0  操作成功。

输出结果如下
--------------
                 RU名称 = USN_SP_RU_0064
               进程类型 = UPP
                进程号  = 0
             GTPC路径数 = 1

(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                           |
|:--------|:--------------------------------|
| RU名称    | 资源单元名称。                         |
| 进程类型    | GTP-C路径所在进程的类型。 取值说明：“SPP”“UPP” |
| 进程号     | GTP-C路径所在进程的序号。                 |
| GTPC路径数 | GTP-C路径数目。                      |
