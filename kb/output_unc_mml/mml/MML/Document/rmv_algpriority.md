# 删除算法优先级配置信息(RMV ALGPRIORITY)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用于删除算法优先级的信息。

#### 注意事项

- 该命令执行后立即生效。
- 删除某算法优先级后，如果SGSN还配有其他算法优先级，则以其他算法中优先级最高的算法为准；如果所有算法均未设置优先级，则随机排序。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                        |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ALGTYPE | 算法类型   | 可选必选说明：必选参数 参数含义：该参数于指定对何种算法设置优先级。目前有加密算法和完整性算法两种类型。 取值范围：“CIPH(UMTS加密算法)”“INTE(UMTS完整性算法)” 默认值：无                                                           |
| ALGCIPH | 加密算法   | 可选必选说明：条件必选参数 参数含义：该参数用于指定加密算法的类型。加密算法是用来保密用户身份，用户数据及信令通道。 前提条件：该参数在“ALGTYPE（算法类型）”设置为“CIPH（UMTS加密算法）”时生效。 取值范围：“NOCIPH(不加密)”“UEA1(UEA1)”“UEA2(UEA2)” 默认值：无 |
| ALGINTE | 完整性算法  | 可选必选说明：条件必选参数 参数含义：该参数用于指定完整性算法类型，只在IU模式下使用。完整性算法是用来保证信令源鉴权数据的完整性。 前提条件：该参数在“ALGTYPE（算法类型）”设置为“INTE（UMTS完整性算法）”时生效。 取值范围：“UIA1(UIA1)”“UIA2(UIA2)” 默认值：无     |

#### 使用实例

场景描述：如果SGSN与RNC协商采用UEA1加密算法，而SGSN侧配置的加密算法NOCIPH优先级别最高，可以删除该算法优先级。

删除算法类型为加密算法，算法为不加密的算法的优先级配置信息：

RMV ALGPRIORITY: ALGTYPE=CIPH, ALGCIPH=NOCIPH;
