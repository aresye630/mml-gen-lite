# 修改Iu模式用户漫游限制列表(MOD IUSUBRRLST)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用于修改Iu模式用户漫游限制列表。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:---------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：必选参数 参数含义：该参数用于指定用户范围。 数据来源：整网规划 取值范围：“IMSI_PREFIX（指定IMSI前缀）”“IMSI_RANGE（指定IMSI范围）”“FOREIGN_USER（外网用户）”“HOME_USER（本网用户）”“ALL_USER（所有用户）” 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件必选参数 参数含义：该参数用于系统对用户的IMSI进行匹配，从而区分不同的用户群。 前提条件：该参数在“用户范围”参数配置为“IMSI_PREFIX（指定IMSI前缀）”后生效。 数据来源：整网规划 取值范围：5～15位十进制字符串 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| IMSI     | IMSI   | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI，对该IMSI所在号段进行修改。 前提条件：只有“用户范围”为“IMSI_RANGE（指定IMSI范围）”时，该参数才有效。 数据来源：整网规划 取值范围：5～15位十进制字符串 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| NOID     | 运营商标识  | 可选必选说明：条件必选参数 参数含义：该参数用于指定运营商标识。 前提条件：该参数在“用户范围”参数配置为“外网用户”或“本网用户”后生效。 对于外网用户，该参数是外网用户对应的签订互联PLMN漫游协议的运营商标识，对于本网用户，该参数是本网用户对应的运营商标识。 数据来源：整网规划 取值范围：0～64，128～254 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                    |
| LARAGPID | 区域群标识  | 可选必选说明：可选参数 参数含义：该参数用于指定用户的区域群标识。 数据来源：整网规划 取值范围：1～2048 默认值：无 配置原则：该参数需要在ADD LARAGPMEM中事先配置，可执行LST LARAGPMEM进行查看。                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ARMODE   | 区域限制模式 | 可选必选说明：可选参数 参数含义：该参数用于指定用户的区域限制模式。 数据来源：整网规划 取值范围：“BLACKLST(黑名单)”：“区域群标识”指定的区域为禁止用户接入区域，“区域群标识”未指定的区域为允许用户接入区域；“WHITELST(白名单)”：“区域群标识”指定的区域为允许用户接入区域，“区域群标识”未指定的区域为禁止用户接入区域。 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                        |
| CAUSE    | 拒绝原因值  | 可选必选说明：可选参数 参数含义：该参数用于指定在“黑名单”或“白名单”模式中拒绝用户接入时使用的原因值。 数据来源：整网规划 取值范围：“CUSTOMER_DEFINED(自定义)”：表示拒绝用户接入时使用的原因值为自定义。“GPRS_SERVICE_NOT_ALLOWED(GPRS服务被禁止)”：表示拒绝用户接入时使用的指定原因值为GPRS服务被禁止。“GPRS_NONGPRS_SRV_NOT_ALLOWED(GPRS和非GPRS服务都被禁止)”：表示拒绝用户接入时使用的原因值为GPRS和非GPRS服务都被禁止。“PLMN_NOT_ALLOWED(PLMN被禁止)”：表示拒绝用户接入时使用的原因值为PLMN被禁止。“LA_NOT_ALLOWED(本地区域被禁止)”：表示拒绝用户接入时使用的原因值为本地区域被禁止。“ROAMING_NOT_ALLOWED_IN_LA(本地漫游被禁止)”：表示拒绝用户接入时使用的原因值为本地漫游被禁止。“GPRS_SRV_NOT_ALLOWED_IN_PLMN (本PLMN内GPRS服务被禁止)”：表示拒绝用户接入时使用的原因值为PLMN内GPRS服务被禁止。“NO_SUITABLE_CELLS_IN_LA(本地无合适小区)”：表示拒绝用户接入时使用的原因值为本地无合适单元。 默认值：无 |
| SDCAUSE  | 自定义原因值 | 可选必选说明：条件必选参数 参数含义：该参数用于指定自定义原因值。 前提条件：该参数在“CAUSE(原因值)”设置为“CUSTOMER_DEFINED(自定义)”时生效。 数据来源：整网规划 取值范围：1～254 默认值：无  说明： 当原因值为自定义时显示，根据3GPP TS 24.008填写。原因值为NAS消息里携带的拒绝原因值。                                                                                                                                                                                                                                                                                                                                                                                                                  |

#### 使用实例

修改一条Iu模式用户漫游限制列表记录，IMSI前缀为123456，区域限制模式修改为“BLACKLST(黑名单)”：

MOD IUSUBRRLST: SUBRANGE=IMSI\_PREFIX, IMSIPRE="123456", ARMODE=BLACKLST;
