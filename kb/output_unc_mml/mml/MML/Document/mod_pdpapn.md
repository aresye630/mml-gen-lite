# 修改本地APN NI配置(MOD PDPAPN)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

如果配置的APNNI不正确，可能因DNS解析失败而导致激活过程失败。

**适用网元：SGSN、MME**

该命令用于修改指定用户PDP类型与APN NI地址的映射关系。

#### 注意事项

- 该命令执行后立即生效。
- 如果配置的APNNI不正确，可能因DNS解析失败而导致激活过程失败。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称      | 参数说明                                                                                                                                                                                                                                                                           |
|:---------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围      | 可选必选说明：必选参数 参数含义：该参数用于指定签约用户的范围。 数据来源：整网规划 取值范围：“ALL_USER(所有用户)”“IMSI_PREFIX(指定IMSI前缀)”“IMSI_RANGE(指定IMSI范围)” 默认值：无                                                                                                                                                            |
| IMSIPRE  | IMSI前缀    | 可选必选说明：条件必选参数 参数含义：系统根据该参数值对用户的IMSI进行匹配，从而区分不同的用户群。 前提条件：该参数在“用户范围”参数设置为“IMSI_PREFIX(指定IMSI前缀)”时，才需要配置。 数据来源：整网规划 取值范围：1～15位数字 默认值：无  说明： 根据“IMSI前缀”、“PDP/PDN类型”映射唯一的“APN NI”。                                                                                                 |
| IMSI     | IMSI      | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI，对该IMSI所在号段进行修改。 前提条件：该参数在“用户范围”参数设置为“IMSI_RANGE(指定IMSI范围)”时，才需要配置。 数据来源：整网规划 取值范围：1～15位数字 默认值：无  说明： 根据“IMSI”、“PDP/PDN类型”映射唯一的“APN NI”。                                                                                                         |
| PDPTYPE  | PDP/PDN类型 | 可选必选说明：必选参数 参数含义：该参数用于指定PDP类型。 数据来源：整网规划 取值范围：“PT_IPV4(IPV4协议)”：表示用户激活的PDP类型为IPV4协议。“PT_IPV6(IPV6协议)”：表示用户激活的PDP类型为IPV6协议。“PT_PPP(点对点通信协议)”：表示用户激活的PDP类型为点对点通信协议。“PT_IPV4_IPV6(IPV4和IPV6协议)”：表示用户激活的PDP类型为IPV4和IPV6协议。“PT_ALL(所有类型)”：表示用户激活的PDP类型为所有类型，不包含Non-IP类型。 默认值：无      |
| APNNI    | APN网络标识   | 可选必选说明：可选参数 参数含义：该参数用于指定APN网络标识地址。 数据来源：整网规划 取值范围：1～62位字符串 默认值：无 配置原则：APN网络标识地址由一个或多个LABEL构成，各LABEL间用“.”间隔。每个LABEL的构成字符只能是字母A～Z或a～z、数字0～9和中划线“-”，字母不区分大小写。例如“HUAWEI.COM”。APN网络标识地址不能以“rac”、“lac”、“sgsn”或“rnc”开头，不能以“.gprs”结尾，不能取值为“*”。  说明： 如果配置的APNNI不正确，可能因DNS解析失败而导致激活过程失败。 |

#### 使用实例

修改“用户范围”为“所有用户”，“PDP/PDN类型”为“PT\_IPV4”，“APN网络标识”为“CMNET”：

MOD PDPAPN: SUBRANGE=ALL\_USER, PDPTYPE=PT\_IPV4, APNNI="CMNET";
