# 查询AMF策略控制参数（LST AMFPLCYCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询AMF策略控制参数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                       |
|:---------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：可选参数  参数含义：该参数用于指定AMF策略功能参数生效的用户范围。  数据来源：全网规划 取值范围： ALL_USER（所有用户）HOME_USER（本网用户）“IMSI_PREFIX（IMSI前缀）”：指定IMSI前缀SPECIFIC_IMSI（指定用户IMSI）  默认值：无  配置原则：无              |
| IMSIPRE  | IMSI前缀 | 可选必选说明：该参数在"SUBRANGE"配置为"IMSI_PREFIX"时为条件可选参数。  参数含义：该参数用于系统根据指定用户的IMSI前缀进行匹配，从而区分不同的用户群。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是5~14。  默认值：无  配置原则：  不可与“SPECIFIC_IMSI（特定IMSI）”相同。 |
| IMSI     | IMSI   | 可选必选说明：该参数在"SUBRANGE"配置为"SPECIFIC_IMSI"时为条件可选参数。  参数含义：该参数用于指定国际移动用户标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是14~15。  默认值：无  配置原则：  指定单用户范围时使用该参数，不可与“IMSIPRE（IMSI前缀）”相同。          |

## 使用实例

查询“用户范围”为“所有用户”的AMF策略控制，执行如下命令：

```
%%LST AMFPLCYCTRL: SUBRANGE=ALL_USER;%%
RETCODE = 0  操作成功

结果如下
------------------------
                         用户范围  =  所有用户
                         IMSI前缀  =  NULL
                             IMSI  =  NULL
基于UDM标识限制创建AM策略偶联开关  =  关闭
基于UDM标识限制发送运营商标识开关  =  关闭
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称               | 输出项解释                                |
|:--------------------|:-------------------------------------|
| 用户范围                | 该参数用于指定AMF策略功能参数生效的用户范围。             |
| IMSI前缀              | 该参数用于系统根据指定用户的IMSI前缀进行匹配，从而区分不同的用户群。 |
| IMSI                | 该参数用于指定国际移动用户标识。                     |
| 基于UDM标识限制创建AM策略偶联开关 | 该参数用于设置是否开启基于用户归属UDM标识限制创建AM策略偶联的功能。 |
| 基于UDM标识限制发送运营商标识开关  | 该参数用于设置是否开启基于UDM标识限制发送运营商标识的功能。      |
