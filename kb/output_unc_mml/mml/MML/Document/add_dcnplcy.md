# 增加DCN配置策略(ADD DCNPLCY)

#### 命令功能

**适用网元：MME**

该命令用于增加DCN的策略参数，即为用户配置DCN业务相关参数，以满足运营商灵活部署网络的需求。

#### 注意事项

- 此命令最大记录数为1024。
- 此配置涉及DECOR基础功能特性（特性编号：WSFD-208001，license部件编码：LKV2DECOR00）和DECOR特性（特性编号：WSFD-208002，license部件编码：LKV2DECOR01），执行命令请使用**DSP LICENSE**命令确认对应特性license是否得到授权，执行**LST LICENSESWITCH**命令确认特性开关状态为“打开”。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称              | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|:----------------|:------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE        | 用户范围              | 可选必选说明：必选参数 参数含义：该参数用于指定DCN策略的用户范围。 数据来源：本端规划 取值范围：“ALL_USER(所有用户)”“IMSI_PRE(指定IMSI前缀)” 默认值：无  说明： 用户接入时首先按照用户的IMSI在“IMSI_PRE（指定IMSI前缀）”进行查询，如果查询成功则使用该记录对应的配置；如果查询失败，则查询“ALL_USER(所有用户)”对应的配置记录。当“用户范围”设置为“IMSI_PRE(指定IMSI前缀)”时，如果匹配到多条记录，使用“IMSI前缀”最长匹配的记录。                                                                                                                                                                                                                                          |
| IMSIPRE         | IMSI前缀            | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI前缀以区分不同的用户群。 前提条件：该参数在“用户范围”配置为“IMSI_PRE(指定IMSI前缀)”后生效。 数据来源：本端规划 取值范围：5~15位十进制数字字符串 默认值：无                                                                                                                                                                                                                                                                                                                                                                               |
| DCNSW           | DCN开关             | 可选必选说明：必选参数 参数含义：该参数用于指定是否开启DCN功能。 数据来源：本端规划 取值范围：“OFF(关闭)”“ON(打开)” 默认值：无  说明： 此参数与DECOR基础功能特性（特性编号：WSFD-208001 ，license部件编码：LKV2DECOR00），DECOR特性（特性编号：WSFD-208002 ，license部件编码：LKV2DECOR01）共同作用开启DCN功能。                                                                                                                                                                                                                                                                                               |
| SRUEUSAGETYPE   | 源侧UE USAGE TYPE策略 | 可选必选说明：条件可选参数 参数含义：该参数用于指定新侧MME是否使用从源侧MME携带的UE USAGE TYPE。 前提条件: 该参数在“DCN开关”配置为“ON(打开)”后生效。 数据来源：本端规划 取值范围：“NO(否)”“YES(是)” 默认值：YES(是) 配置原则：如果源侧MME携带的UE USAGE TYPE不可信时，可以将此参数设置为“NO(否)”。  说明： 源侧MME可能会在Attach流程的Identification Response消息、TAU流程的Context Response消息或者Handover流程Forward Relocation Request消息中携带UE USAGE TYPE到新侧MME。如果此参数配置为“YES(是)”，系统会在收到源侧MME的UE USAGE TYPE后，如果可以查找到可服务的DCN，则认为查询成功；否则系统直接使用“UE USAGE TYPE获取策略”中的方式尝试查找DCN ID。如果此参数配置为“NO(否)”，系统直接使用“UE USAGE TYPE获取策略”中的方式尝试查找DCN ID。 |
| UEUSAGETYPEPLCY | UE USAGE TYPE获取策略 | 可选必选说明：条件可选参数 参数含义：该参数用于指定UE USAGE TYPE的获取策略。 前提条件: 该参数在“DCN开关”参数配置为“ON(打开)”后生效。 数据来源：本端规划 取值范围：“HSS(HSS获取)”“LOCAL(本地获取)” 默认值：“HSS(HSS获取)” 配置原则：如果HSS未配置用户的签约数据UE USAGE TYPE，可以将此参数设置为“LOCAL(本地获取)”。  说明： 配置为“HSS(HSS获取)”，系统会通过Authentication Info Request消息向HSS请求获取UE USAGE TYPE；需要在ADD S1USRSECPARA命令中设置用户的安全策略为鉴权并保护，否则由于无法通过Authentication Info Request消息获取UE USAGE TYPE，而导致业务流程失败。配置为“LOCAL(本地获取)”，系统会使用“UEUSAGETYPE”参数配置的UE USAGE TYPE值。                                                         |
| UEUSAGETYPE     | UE USAGE TYPE     | 可选必选说明：条件必选参数 参数含义：该参数用于指定UE USAGE TYPE。 前提条件: 该参数在“UE USAGE TYPE获取策略”配置为“LOCAL(本地获取)”后生效。 数据来源：本端规划 取值范围：0~255 默认值：无 配置原则：0-127为预留的标准值，128-255为运营商规划值。此参数建议在规划值范围内进行配置，以防将来和预留的标准值产生冲突。请参见3GPP TS 29.272。                                                                                                                                                                                                                                                                                             |
| GWSELPLCY       | 网关选择策略            | 可选必选说明：条件可选参数 参数含义：该参数用于控制MME在通过DNS查询网关时是否使用UE USAGE TYPE。 前提条件: 该参数在“DCN开关”参数配置为“ON(打开)”后生效。 数据来源：全网规划 取值范围：“NO(不使用)”：系统保持原有实现来查询网关。“YES(使用)”：专网中的用户接入到指定的网关。 默认值：“NO(不使用)” 配置原则：如果不期望将专网中的用户接入到指定的网关时，将此参数配置为“NO(不使用)”。如果期望将专网中的用户接入到指定的网关时，将此参数配置为“YES(使用)”。  说明： 当参数配置为“YES(使用)”时，必须根据用户的UE USAGE TYPE部署DNS NAPTR记录，否则会导致网关查询失败。                                                                                                                                                                   |

#### 使用实例

为“IMSI前缀”为“123003”的用户打开DCN功能，优先使用源侧MME携带的UE USAGE TYPE，在源侧未携带时使用本地配置为100的UE USAGE TYPE查找可服务的DCN：

ADD DCNPLCY: SUBRANGE=IMSI\_PRE, IMSIPRE="123003", DCNSW=ON, SRUEUSAGETYPE=YES, UEUSAGETYPEPLCY=LOCAL, UEUSAGETYPE=100, GWSELPLCY=YES;
