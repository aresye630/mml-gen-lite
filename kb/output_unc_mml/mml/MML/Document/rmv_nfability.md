# 删除配置NF的能力信息（RMV NFABILITY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于删除配置NF的能力信息。

## 注意事项

- 该命令执行后立即生效。

- 主备或双活组网的场景下，如果需要配置此命令，则两个NRF上均需执行此命令，且配置参数一致。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                        |
|:-------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFIDTYPE     | NF标识类型 | 可选必选说明：必选参数  参数含义：该参数用于表示NF标识类型。  数据来源：全网规划 取值范围： NF_ID（NF实例标识）NF_IP（NF IP地址）  默认值：无  配置原则：无                                                                |
| IPTYPE       | IP类型   | 可选必选说明：该参数在"NFIDTYPE"配置为"NF_IP"时为条件必选参数。  参数含义：该参数用于指定NF的客户端地址的IP类型。  数据来源：全网规划 取值范围： IPV4（IPv4地址）IPV6（IPv6地址）  默认值：无  配置原则：无                               |
| NFINSTANCEID | NF实例标识 | 可选必选说明：该参数在"NFIDTYPE"配置为"NF_ID"时为条件必选参数。  参数含义：该参数用于表示NF实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~40。该参数只能由字母（A-Z或者a-z）、数字（0-9）、中划线（-）组成。不区分大小写。  默认值：无  配置原则：无 |
| IPV4         | IPv4地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPV4"时为条件必选参数。  参数含义：该参数用于表示NF的客户端IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无                                                  |
| IPV6         | IPv6地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPV6"时为条件必选参数。  参数含义：该参数用于表示NF的客户端IPv6地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无                                                  |

## 使用实例

运营商希望在NRF上删除NF实例标识为123e4567-e89b-12d3-a456-426655440000的NF配置的能力信息时，执行此命令。

```
RMV NFABILITY: NFIDTYPE=NF_ID, NFINSTANCEID="123e4567-e89b-12d3-a456-426655440000";
```
