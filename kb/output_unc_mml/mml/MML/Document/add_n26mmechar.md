# 增加N26接口MME属性（ADD N26MMECHAR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于增加N26接口对端MME的属性信息。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入100条记录。
- 网段完全重叠的记录不能重复下发，网段有包含关系的记录可以同时下发。如果对端MME的IP与多个记录的网段都匹配，产品选择掩码最长的记录。
- 匹配优先级从高到低依次为：COMB\_MME（UAMF融合MME）>SPECIAL\_MME（指定MME）>ALL\_MME（所有MME）。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| RANGE   | IPTYPE   | IPV4            | MASKV4   | IPV6                                    |   MASKV6 | MMECAP     | PCFRFSPSW   | PCFNISW   | ITFTYPE    | MSISDNSW   | PVTMSISDNSW   |
|:--------|:---------|:----------------|:---------|:----------------------------------------|---------:|:-----------|:------------|:----------|:-----------|:-----------|:--------------|
| ALL_MME | INVALID  | 255.255.255.255 | 0.0.0.0  | 0000:0000:0000:0000:0000:0000:0000:0000 |        0 | NONIPPDN-1 | NO          | NO        | S10/N26MME | NO         | NO            |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称                           | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|:----------------|:-------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RANGE           | 对端设备范围                         | 可选必选说明：必选参数  参数含义：该参数用于指示对端MME设备范围。  数据来源：全网规划 取值范围： “ALL_MME（所有MME）”：所有MME“SPECIAL_MME（指定MME）”：指定MME“COMB_MME（UAMF融合MME）”：UAMF融合MME  默认值：无  配置原则：  系统开工时缺省增加了“所有MME”的记录，ADD命令中就不需要增加“所有MME”的记录。                                                                                                                                                                                                                                                                                                                        |
| IPTYPE          | IP地址类型                         | 可选必选说明：该参数在"RANGE"配置为"SPECIAL_MME"时为条件必选参数。  参数含义：该参数用于指定对端MME的信令面IP地址类型。  数据来源：全网规划 取值范围： “IPV4（IPv4）”：IPv4“IPV6（IPv6）”：IPv6  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                            |
| IPV4            | MME IPv4信令面地址                  | 可选必选说明：该参数在"IPTYPE"配置为"IPV4"时为条件必选参数。  参数含义：该参数用于指定对端MME的信令面IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：  有效的IPv4地址必须是A、B或者C类地址，且不能为环回地址（127.x.y.z）。                                                                                                                                                                                                                                                                                                                                                                |
| MASKV4          | IPv4掩码                         | 可选必选说明：该参数在"IPTYPE"配置为"IPV4"时为条件必选参数。  参数含义：该参数用于指定对端MME的信令面IPv4地址的掩码。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：  输入的掩码要求对应的二进制值1和1之间不允许存在0。例如：“255.255.0.0”是有效掩码；“123.123.123.123”是无效掩码。因为123对应的二进制为“1111011”，1之间存在0。                                                                                                                                                                                                                                                                                                   |
| IPV6            | MME IPv6信令面地址                  | 可选必选说明：该参数在"IPTYPE"配置为"IPV6"时为条件必选参数。  参数含义：该参数用于指定对端MME的信令面IPv6地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：  IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址（::1）、链路本地地址（FE80::/10）和组播地址（FF00::/8）。                                                                                                                                                                                                                                                                                                 |
| MASKV6          | IPv6子网前缀长度                     | 可选必选说明：该参数在"IPTYPE"配置为"IPV6"时为条件必选参数。  参数含义：该参数用于指定子网前缀的长度。  数据来源：全网规划  取值范围：整数类型，取值范围是1~128。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                            |
| MMECAP          | MME能力                          | 可选必选说明：可选参数  参数含义：该参数用于指定MME支持的能力。  数据来源：对端协商 取值范围： “NONIPPDN（支持non-IP类型的PDN）”：支持non-IP类型的PDN  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                            |
| PCFRFSPSW       | 是否传递AM-PCF签约RFSP               | 可选必选说明：可选参数  参数含义：该参数用于设置是否支持N26接口传递AM-PCF签约RFSP的功能。该参数已经通过SET AMFPLCYFUNC命令中的DYNRFSPSW参数配置。  数据来源：全网规划 取值范围： “YES（是）”：是“NO（否）”：否  默认值：无  配置原则：  只有满足如下条件，才允许设置本参数为“YES（是）”。  对端MME为华为设备，且支持PCRF签约RFSP功能。  客户网络中PGW与PCRF交互采用N7接口交互，且2345G业务在PCF上签约的RFSP信息完全一致时。                                                                                                                                                                                                                                                         |
| PCFNISW         | 是否传递AM-PCF签约NI                 | 可选必选说明：可选参数  参数含义：该参数用于设置是否支持N26接口传递AM-PCF签约NI的功能。该参数已经通过SET AMFPLCYFUNC命令中的DYNNISW参数配置。  数据来源：全网规划 取值范围： “YES（是）”：是“NO（否）”：否  默认值：无  配置原则：  只有满足如下条件，才允许设置本参数为“YES（是）”。  对端MME为华为设备，且支持PCRF签约NI功能。  客户网络中PGW与PCRF交互采用N7接口交互，且2345G业务在PCF上签约的NI信息完全一致时。                                                                                                                                                                                                                                                                 |
| ITFTYPE         | 接口类型                           | 可选必选说明：可选参数  参数含义：该参数用于设置AMF在发送N26接口消息时，控制面F-TEID中携带的接口类型。 接口消息为Forward Relocation Request/Forward Relocation Response信元名称为Sender's F-TEID for Control Plane、接口消息为Context Request信元名称为S3/S16/S10/N26 Address and TEID for Control Plane、接口消息为Context Response信元名称为Sender F-TEID for Control Plane。  数据来源：全网规划 取值范围： “S10/N26MME（S10/N26 MME）”：S10/N26 MME GTP-C接口“N26AMF（N26 AMF）”：N26 AMF GTP-C接口  默认值：无  配置原则：  与对端MME确认AMF N26接口消息中本端接口类型支持N26 AMF时，才允许设置本参数为“N26 AMF”；如果对端MME是华为设备，需要在对端MME将软参BYTE_EX_B27 BIT6值置为1。 |
| N26DATACONTRSSW | 互操作数据持续性信元传递开关                 | 可选必选说明：可选参数  参数含义：该参数用于指示当UAM开启基于位置的地址分配功能且4/5G归属同一IP区域群时，用户在4/5G互操作流程中是否传递数据业务不断流信元。  数据来源：全网规划 取值范围： “ForwardRelocationRequest（Forward Relocation Request）”：Forward Relocation Request“ContextResponse（Context Response）”：Context Response  默认值：无  配置原则：无                                                                                                                                                                                                                                                             |
| MSISDNSW        | 是否传递MSISDN                     | 可选必选说明：可选参数  参数含义：该参数用于控制AMF在发送Context Response和Forward Relocation Request消息时，是否支持携带MSISDN信元。  数据来源：全网规划 取值范围： “YES（是）”：是“NO（否）”：否  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                       |
| PVTMSISDNSW     | 是否在Private Extension信元传递MSISDN | 可选必选说明：可选参数  参数含义：该参数用于设置AMF在发送Identification Response消息时，是否支持通过私有信元传递MSISDN。  数据来源：全网规划 取值范围： “YES（是）”：是“NO（否）”：否  默认值：无  配置原则：  对端MME为华为设备，且支持私有信元携带MSISDN。                                                                                                                                                                                                                                                                                                                                                           |

## 使用实例

假设IP地址为192.168.0.1的MME支持non-IP功能，执行如下命令：

```
ADD N26MMECHAR: RANGE=SPECIAL_MME, IPTYPE=IPV4, IPV4="192.168.0.1", MASKV4="255.255.255.255", MMECAP=NONIPPDN-1;
```
