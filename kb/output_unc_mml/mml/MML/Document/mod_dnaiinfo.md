# 修改DNAI信息（MOD DNAIINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、PGW-C**

该命令用于修改DNAI信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称       | 参数说明                                                                                                                                                                                  |
|:--------------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DNAI          | 数据网络访问标识   | 可选必选说明：必选参数  参数含义：该参数用于指定数据网络访问标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。不支持空格，不区分大小写。  默认值：无  配置原则：无                                                                                    |
| SHUNTDIRECT   | 分流方向       | 可选必选说明：可选参数  参数含义：该参数用于控制分流的方向。  数据来源：全网规划 取值范围： “NORMAL（正向）”：正向分流“REVERSE（反向）”：反向分流  默认值：无  配置原则：  该参数配置为正向分流，园区业务分流到辅锚点；  该参数配置为反向分流，园区业务分流到主锚点。                                    |
| SHUNTLOC      | 分流位置       | 可选必选说明：可选参数  参数含义：该参数用于指示DNAI的分流位置。  数据来源：全网规划 取值范围： “HOME（归属地）”：归属地分流  默认值：无  配置原则：  该参数对I-SMF不生效。                                                                                   |
| ALWAYSSHUNTSW | Always分流开关 | 可选必选说明：可选参数  参数含义：该参数用于控制DNAI是否支持Always分流。  数据来源：全网规划 取值范围： “DISABLE（不使能）”：不支持Always分流“ENABLE（使能）”：支持Always分流  默认值：无  配置原则：  开关默认关闭，DNAI不支持Always分流；  当DNAI规划为整网范围内生效时，需打开Always分流开关。 |

## 使用实例

修改cmnet\_dnai的分流方向为正向分流，分流位置为归属地分流，关闭Always分流开关

```
MOD DNAIINFO: DNAI="cmnet_dnai", SHUNTDIRECT=NORMAL, SHUNTLOC=HOME, ALWAYSSHUNTSW=ENABLE;
```
