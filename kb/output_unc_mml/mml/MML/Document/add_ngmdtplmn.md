# 增加最小化路测的PLMN（ADD NGMDTPLMN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于增加基于管理的最小化路测（MDT）的PLMN。

## 注意事项

- 该命令执行后立即生效。

- 配置记录添加后，如果当前用户正在进行业务流程，配置限制不会实时生效，在下一个流程中生效。

- 最多可输入16条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------------------|
| PLMNIDX | PLMN索引 | 可选必选说明：必选参数  参数含义：该参数表示最小化路测（MDT）的PLMN。  数据来源：本端规划  取值范围：整数类型，取值范围是0~127。PLMNIDX通过ADD NGSRVPLMN进行配置。  默认值：无  配置原则：无 |

## 使用实例

增加最小化路测的PLMN，执行如下命令：

```
ADD NGMDTPLMN: PLMNIDX=1;
```
