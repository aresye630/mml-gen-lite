# 创建OSPFv3引入路由聚合配置（ADD OSPFV3ASBRSUMMARY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于设置自治系统边界路由器ASBR对OSPFv3引入的路由进行路由聚合。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为8000。
- 只有在执行ADD OSPFV3配置了OSPFv3进程后才能使用此命令。
- 当有大量聚合路由时，可以配置DISTRDELAYINTV参数设置延迟发布聚合路由的时间，使每次发布的聚合路由信息中包含更多的有效路由，避免网络振荡而出现路由信息不准确的现象。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识                 | 参数名称           | 参数说明                                                                                                                                                                                                                                                                                           |
|:---------------------|:---------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROCID               | OSPFv3进程号      | 可选必选说明：必选参数 参数含义：OSPFv3进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 配置原则：OSPFv3进程必须已经存在。请使用LST OSPFV3命令查看可用的OSPFv3进程。                                                                                                                                                                     |
| TOPOID               | 拓扑标识           | 可选必选说明：可选参数 参数含义：拓扑标识。 数据来源：全网规划 取值范围：整数类型，取值范围为0。 默认值：0 配置原则：目前只支持默认拓扑0。                                                                                                                                                                                                                      |
| IPADDRESS            | IPv6地址         | 可选必选说明：必选参数 参数含义：IPv6地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无                                                                                                                                                                                                                                        |
| IPV6MASKLEN          | IPv6前缀长度       | 可选必选说明：必选参数 参数含义：IPv6前缀长度。 数据来源：本端规划 取值范围：整数类型，取值范围为1～128。 默认值：无                                                                                                                                                                                                                               |
| CONFIGCOST           | 使能聚合路由的开销值     | 可选必选说明：可选参数 参数含义：使能聚合路由的开销值。 数据来源：本端规划 取值范围：枚举类型。 FALSE：不使能。TRUE：使能。 默认值：FALSE                                                                                                                                                                                                                 |
| COST                 | 聚合路由的开销        | 可选必选说明：条件必选参数 前提条件：该参数在“CONFIGCOST”配置为“TRUE”时为必选参数。 参数含义：当此参数缺省时，对于Type1类外部路由，取所有被聚合路由中的最大开销值作为聚合路由的开销；对于Type2类外部路由，则取所有被聚合路由中的最大开销值再加上1作为聚合路由的开销。 数据来源：本端规划 取值范围：整数类型，取值范围为0～16777214。 默认值：无 配置原则： 对于Type-1类型的外部路由，缺省的聚合路由的开销值是所有被聚合路由中的最大开销值。对于Type-2类型的外部路由，缺省的聚合路由的开销值是所有被聚合路由中的最大开销值再加上1。 |
| CONFIGDISTRDELAYINTV | 使能延迟发布聚合路由     | 可选必选说明：可选参数 参数含义：使能延迟发布聚合路由。 数据来源：本端规划 取值范围：枚举类型。 FALSE：不使能。TRUE：使能。 默认值：FALSE                                                                                                                                                                                                                 |
| DISTRDELAYINTV       | 延迟发布聚合路由的时间（s） | 可选必选说明：条件必选参数 前提条件：该参数在“CONFIGDISTRDELAYINTV”配置为“TRUE”时为必选参数。 参数含义：设置延迟发布聚合路由的时间。 数据来源：本端规划 取值范围：整数类型，取值范围为1～65535，单位是秒。 默认值：无                                                                                                                                                                 |
| NOTADVFLAG           | 不发布路由          | 可选必选说明：可选参数 参数含义：用来指定是否发布聚合路由，默认值是发布聚合路由。 数据来源：本端规划 取值范围：枚举类型。 DoNotAdvertise：不发布。Advertise：发布。 默认值：Advertise                                                                                                                                                                                  |
| CONFIGTAG            | 使能聚合路由的标记      | 可选必选说明：可选参数 参数含义：使能聚合路由的标记。 数据来源：本端规划 取值范围：枚举类型。 FALSE：不使能。TRUE：使能。 默认值：FALSE                                                                                                                                                                                                                  |
| TAG                  | 路由标签           | 可选必选说明：条件必选参数 前提条件：该参数在“CONFIGTAG”配置为“TRUE”时为必选参数。 参数含义：路由标签，用于通过路由策略控制路由发布。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无 配置原则：如果不配置此参数，则实际取值为1。                                                                                                                                               |

#### 使用实例

在OSPFv3进程1下引入2001:db8::的路由聚合，Cost值为100：

```
ADD OSPFV3ASBRSUMMARY:PROCID=1,TOPOID=0,IPADDRESS="2001:db8::",IPV6MASKLEN=64,CONFIGCOST=TRUE,COST=100,NOTADVFLAG=Advertise;
```
