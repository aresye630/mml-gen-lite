# 显示DNS服务器链路状态(DSP DNSLNK)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用网元：SGSN、MME**

该命令用于查看DNS服务器链路的状态。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                                                                            |
|:-------------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------|
| RUNAME       | RU名称     | 可选必选说明：可选参数 参数含义：该参数用于指定SPU资源单元名。该参数可以通过DSP RU命令查询。 数据来源：整网规划 取值范围：1~63 位字符串 默认值：无                                                              |
| IPTYPE       | IP地址类型   | 可选必选说明：可选参数 参数含义：该参数用于指定DNS链路的IP地址类型。 数据来源：整网规划 取值范围： “IPV4(IPV4)”“IPV6(IPV6)” 默认值：无                                                            |
| LOCIPV4ADDR  | 本端IPv4地址 | 可选必选说明：条件可选参数 参数含义：该参数用于指定DNS客户端IPV4地址。 前提条件：当“IP地址类型”设置为“IPV4(IPV4)”时，该参数有效。 数据来源：整网规划 取值范围：0.0.0.0~255.255.255.255 默认值：无                      |
| PEERIPV4ADDR | 对端IPv4地址 | 可选必选说明：条件可选参数 参数含义：该参数用于指定对端DNS服务器IPv4地址。 前提条件：当“IP地址类型”设置为“IPV4(IPV4)”时，该参数有效。 数据来源：整网规划 取值范围：0.0.0.0~255.255.255.255 默认值：无                    |
| LOCIPV6ADDR  | 本端IPv6地址 | 可选必选说明：条件可选参数 参数含义：该参数用于指定DNS客户端IPV6地址。 前提条件：当“IP地址类型”设置为“IPV6(IPV6)”时，该参数有效。 数据来源：整网规划 取值范围：::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无   |
| PEERIPV6ADDR | 对端IPv6地址 | 可选必选说明：条件可选参数 参数含义：该参数用于指定对端DNS服务器IPv6地址。 前提条件：当“IP地址类型”设置为“IPV6(IPV6)”时，该参数有效。 数据来源：整网规划 取值范围：::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 |

#### 使用实例

查询USN\_SP\_RU\_0064的DNS服务器链路信息：

DSP DNSLNK:RUNAME="USN\_SP\_RU\_0064";

#### 输出结果说明

| 输出项名称    | 输出项解释                                                                            |
|:---------|:---------------------------------------------------------------------------------|
| RU名称     | 参数含义：该参数用于指定SPU资源单元名。                                                            |
| IP地址类型   | DNS链路的IP地址类型。                                                                    |
| 本端IPv4地址 | DNS客户端IPV4地址。                                                                    |
| 对端IPv4地址 | 对端DNS服务器IPv4地址。                                                                  |

| 对端IPv6地址 | 对端DNS服务器IPv6地址。                                                                  |
| 本地端口号    | 本地端口号。                                                                           |
| DNS链路类型  | DNS链路类型。 取值说明：“TCP传输模式”“UDP传输模式”                                                 |
