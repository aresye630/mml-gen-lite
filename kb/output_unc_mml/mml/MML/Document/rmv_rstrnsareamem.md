# 删除TA级限制切片所属跟踪区成员（RMV RSTRNSAREAMEM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于从指定的TA级限制切片所属跟踪区删除跟踪区成员。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                                                  |
|:---------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AREACODE | 区域编码     | 可选必选说明：必选参数  参数含义：该参数用于标识TA级限制切片所属的某区域范围。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~128。该参数依赖于ADD RSTRNSAREACODE命令中的AREACODE参数。  默认值：无  配置原则：无                                  |
| MCC      | 移动国家码    | 可选必选说明：必选参数  参数含义：该参数用于表示组成TA级限制切片所属区域的位置区成员的移动国家码，与无线接入网的MCC一致。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                        |
| MNC      | 移动网号     | 可选必选说明：必选参数  参数含义：该参数用于表示组成TA级限制切片所属区域的位置区成员的移动网号，与无线接入网的MNC一致。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：  两条记录间的MCC相同时，2位MNC与3位MNC的前两个数字不能相同。 |
| BGNTAC   | 跟踪区编码起始值 | 可选必选说明：可选参数  参数含义：该参数用于表示跟踪区编码的起始值。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。TAC编码为16进制数，按照字符串格式输入，字符串长度为6，只能由数字（0-9），字母（A-F、a-f）组成。字母大小写不敏感。  默认值：无  配置原则：无                     |

## 使用实例

针对同一个区域（jq001.pd006.sh.mcc123.mnc45），将AMF上多定义的跟踪区（TAC="120101"）从该区域中删除，执行如下命令：

```
RMV RSTRNSAREAMEM:AREACODE="jq001.pd006.sh.mcc123.mnc45", MCC="460", MNC="03", BGNTAC="120101";
```
