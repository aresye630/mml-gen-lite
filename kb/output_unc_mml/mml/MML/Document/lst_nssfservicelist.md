# 查看NSSF功能实例服务列表（LST NSSFSERVICELIST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NSSF**

本命令用于查看NSSF功能实例服务列表。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询NSSF功能实体服务列表：

```
LST NSSFSERVICELIST;
```

|:--------|:----------|
