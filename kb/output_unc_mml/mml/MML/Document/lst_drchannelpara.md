# 查询容灾通道参数(LST DRCHANNELPARA)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询CSDB容灾通道参数，包括心跳间隔和消息重试次数。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                  |
|:----------|:-------|:--------------------------------------------------------------------------------------|
| CLUSTERID | 子集群标识  | 可选必选说明：可选参数。 参数含义：该参数用于指定唯一一个子集群，可以通过DSP DBCLUSTER命令查询获取。 数据来源：本端规划 取值范围：1～10。 默认值：无。 |

#### 使用实例

查询所有子集群的容灾通道参数：

```
%%LST DRCHANNELPARA:;%%
RETCODE = 0  操作成功
操作结果如下：
--------------
          子集群标识  =  1
    容灾通道心跳间隔  =  20
容灾通道消息重试次数  =  20
         
(结果个数 = 1)
---    END
```
