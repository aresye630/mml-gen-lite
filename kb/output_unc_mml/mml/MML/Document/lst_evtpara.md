# 查询策略参数值（LST EVTPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询策略参数值。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                   |
|:---------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICE  | 服务名称   | 可选必选说明：可选参数  参数含义：该参数表示策略模型绑定的服务名称，可以通过LST EVTPARA命令获取参数。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~16。  默认值：无  配置原则：无                                                                                                                                                                           |
| EVENTID  | 事件ID   | 可选必选说明：可选参数  参数含义：该参数表示服务名称对应的事件ID，可以通过LST EVTPARA命令获取参数。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：  只支持配置LST EVTPARA命令获取到的服务实例。                                                                                                                                          |
| PARANAME | 策略参数   | 可选必选说明：可选参数  参数含义：该参数用于表示策略对应的参数名称。  数据来源：本端规划 取值范围： “AssStatic-Suspect（关联诊断嫌疑实例数）”：关联诊断配置的嫌疑实例数量。“AssStatic-Proportion（关联诊断嫌疑实例比例）”：关联诊断配置的嫌疑实例比例。“CellReset-Delay（进程复位延迟时间）”：进程复位延迟执行时间。“CellReset-Retry（进程复位重试次数）”：进程复位重试次数。“CellReset-Interval（进程复位间隔时间）”：进程复位重试间隔。  默认值：无  配置原则：无 |

## 使用实例

查询配置表内事件1关联诊断中参数嫌疑实例数量的值

```
%%LST EVTPARA: SERVICE="SDRS", EVENTID=1, PARANAME=AssStatic-Suspect;%%
RETCODE = 0  操作成功

结果如下
-----------
  服务名称 = SDRS
    事件ID = 1
  策略参数 = 关联诊断嫌疑实例数
策略参数值 = 4
  事件名称 = sdrs link down1
(结果个数 = 1)

---    END
```
