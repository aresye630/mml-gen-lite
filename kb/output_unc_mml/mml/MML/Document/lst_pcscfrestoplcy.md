#### 命令功能

**适用网元：MME**

该命令用于查询P-CSCF故障恢复策略配置。该命令对应的业务功能暂未实现。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                               |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：可选参数 参数含义：该参数用于指定待进行网元重选的用户范围。 数据来源：整网规划 取值范围： ALL_USER（所有用户）：表示用户范围为系统内所有用户。HOME_USER（本网用户）：表示用户范围为本网用户。FOREIGN_USER（外网用户）：表示用户范围为外网用户。 IMSI_PREFIX（指定IMSI前缀）：表示用户范围通过IMSI前缀指定。SPECIFIC_IMSI（特定IMSI）：表示用户范围通过IMSI指定。 默认值：无 |
| NOID     | 运营商标识  | 可选必选说明：条件可选参数 参数含义：该参数用于指定运营商标识。 前提条件：该参数在“用户范围”参数配置为“HOME_USER(本网用户)”或“FOREIGN_USER(外网用户)”后生效。 数据来源：整网规划 取值范围：0～64，128～254 默认值：无                                                                                                  |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件可选参数 参数含义：该参数用于指定IMSI前缀以区分不同的用户群。 前提条件：该参数在“用户范围”参数配置为“指定IMSI前缀”后生效。 数据来源：整网规划 取值范围：5~14位十进制数字字符串 默认值：无                                                                                                                   |
| IMSI     | IMSI   | 可选必选说明：条件可选参数 参数含义：该参数用于指定IMSI。 前提条件：该参数在“用户范围”参数配置为“SPECIFIC_IMSI（特定IMSI）”后生效。 数据来源：整网规划 取值范围：14~15位十进制数字字符串 默认值：无                                                                                                                |

#### 使用实例

查询“用户范围”为“所有用户”的所有记录；

LST PCSCFRESTOPLCY: SUBRANGE=ALL\_USER;

```
%%LST PCSCFRESTOPLCY: SUBRANGE=ALL_USER;%%
RETCODE = 0  操作成功 

查询结果如下
------------
                        用户范围  =  所有用户         
                      运营商标识  =  NULL           
                        IMSI前缀  =  NULL        
PCO-based optional extension功能  =  开启
(结果个数 = 1)

---    END
```
