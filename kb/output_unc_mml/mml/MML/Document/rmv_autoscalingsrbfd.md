# 删除静态路由的动态BFD自动化配置模板（RMV AUTOSCALINGSRBFD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除静态路由的动态BFD自动化配置模板。

#### 注意事项

- 该命令执行后立即生效。
- 删除该BFD模板时，要保证该模板添加过，且没有被引用。
- 该命令在自动配置开关为关闭的状态下才能执行，请先使用SET AUTOCONFIG命令关闭自动配置开关。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                     |
|:------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------|
| SERVICENAME | 服务名称   | 可选必选说明：必选参数 参数含义：该参数用来表示接口自动化配置服务模板名称。要求和ADD AUTOSCALINGSERVICE命令中配置的SERVICENAME参数保持一致。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格和中文。 默认值：无 |
| IPVERSION   | 地址族    | 可选必选说明：可选参数 参数含义：该参数用来表示IP地址类型。 数据来源：本端规划 取值范围：枚举类型。 IPv4：IPv4地址族。IPv6：IPv6地址族。 默认值：无                                                    |

#### 使用实例

删除一个静态路由的动态BFD自动化配置模板：

```
RMV AUTOSCALINGSRBFD:SERVICENAME="abc";
```
