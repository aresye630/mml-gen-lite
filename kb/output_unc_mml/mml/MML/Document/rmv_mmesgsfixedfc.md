# 删除VLR局向Sgs固定速率流控 (RMV MMESGSFIXEDFC)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SMSF**

此命令用于删除VLR局向Sgs固定速率流控。删除后，Sgs固定速率流控不再生效。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                   |
|:-------|:-------|:---------------------------------------------------------------------------------------|
| MMEIDX | MME索引  | 可选必选说明：必选参数 参数含义：该参数用于指定一个MME实体，在全局范围内唯一。 数据来源：本端规划 取值范围：整数类型，取值范围为0~1999 默认值：无 配置原则：无 |

#### 使用实例

删除MMEIDX为1的VLR局向Sgs固定速率流控。

```
RMV MMESGSFIXEDFC: MMEIDX=1;
```
