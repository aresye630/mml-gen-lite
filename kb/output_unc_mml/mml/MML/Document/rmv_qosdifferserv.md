# 删除DS域（RMV QOSDIFFERSERV）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来删除用户自创建的DS域。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                      |
|:-------|:-------|:------------------------------------------------------------------------------------------|
| DSNAME | DS域名   | 可选必选说明：必选参数 参数含义：该参数用于指定DS域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：区分大小写，不支持空格。 |

#### 使用实例

删除一个DS域d1：

```
RMV QOSDIFFERSERV:DSNAME="d1";
```
