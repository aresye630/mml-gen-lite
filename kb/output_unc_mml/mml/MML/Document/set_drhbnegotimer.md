# 设置容灾定时器（SET DRHBNEGOTIMER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于配置容灾组中网元间发送心跳、协商消息的间隔时间及次数。

## 注意事项

- 该命令执行后立即生效。

- 该命令适用于支持热备或冷备容灾的网元执行。
- 在容灾运行期间执行命令，需要参考容灾配置指导书，避免主备容灾协商失败。
- 在容灾组中的两个网元中配置容灾定时器时，参数应保持一致。
- 在冷备容灾模式下，心跳超时时间的最小时间建议设置为6s。
- 使用**LST DRHBNEGOTIMER**查询容灾定时器时，只有当前容灾组的容灾定时器会被显示。

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称              | 参数说明                                                                                                                                                           |
|:--------------|:------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DRGROUPID     | 容灾组标识             | 可选必选说明：必选参数  参数含义：该参数用来标识一个容灾组，该标识必须存在于容灾组信息中，容灾组信息可以使用LST DRGROUPINFO命令查询。  数据来源：全网规划  取值范围：整数类型，取值范围是1~8。  默认值：无。  配置原则：无                                    |
| HELLOINTERVAL | 心跳消息传递间隔(100毫秒)   | 可选必选说明：可选参数  参数含义：该参数用于配置容灾组内网元间发送心跳消息的间隔时间。  数据来源：全网规划  取值范围：整数类型，取值范围是1~100。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST DRHBNEGOTIMER查询当前参数配置值。  配置原则：无        |
| NEGOINTERVAL  | 协商消息传递间隔(100毫秒)   | 可选必选说明：可选参数  参数含义：该参数用于配置容灾组内网元间发送协商消息的间隔时间。  数据来源：对端协商  取值范围：整数类型，取值范围是1~100。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST DRHBNEGOTIMER查询当前参数配置值。  配置原则：无        |
| TIMES         | 重传次数              | 可选必选说明：可选参数  参数含义：该参数用于配置容灾组内网元间发送心跳和协商消息的重传次数。  数据来源：全网规划  取值范围：整数类型，取值范围是1~60，单位是次。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST DRHBNEGOTIMER查询当前参数配置值。  配置原则：无 |
| OMHBTIMES     | OM通道心跳重传次数        | 可选必选说明：可选参数  参数含义：该参数用于配置容灾组内OM通道发送心跳的重传次数。  数据来源：本端规划  取值范围：整数类型，取值范围是1~30。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST DRHBNEGOTIMER查询当前参数配置值。  配置原则：无          |
| OMHBINTERVAL  | OM通道心跳探测时长(100毫秒) | 可选必选说明：可选参数  参数含义：该参数用于配置容灾组OM通道发送心跳消息的间隔时间。  数据来源：本端规划  取值范围：整数类型，取值范围是1~100。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST DRHBNEGOTIMER查询当前参数配置值。  配置原则：无        |

## 使用实例

设置容灾组标识为1的心跳重传间隔为1秒，协商消息重传的间隔为2秒，重传次数为3次:

```
%%SET DRHBNEGOTIMER: DRGROUPID=1, HELLOINTERVAL=10, NEGOINTERVAL=20, TIMES=3;%%
RETCODE = 0  操作成功

---    END
```
