# 显示PAE染色跟踪信息（DSP PAEDYETRACEINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示PAE染色跟踪信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                |
|:-------|:--------|:--------------------------------------------------------------------------------------------------------------------|
| CELLID | Cell ID | 可选必选说明：可选参数  参数含义：该参数表示PAE调试消息发送的CELL ID，可以通过使用命令DSP PAENODE获取。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~127。  默认值：无  配置原则：无 |

## 输出结果说明

| 输出项名称          | 输出项解释                                                             |
|:---------------|:------------------------------------------------------------------|
| Cell ID        | 该参数表示PAE调试消息发送的CELL ID，可以通过使用命令DSP PAENODE获取。                     |
| 染色全流控状态        | 该参数用于显示染色跟踪全流控状态。 取值说明： “TRUE（是）”：染色跟踪全流控已激活“FALSE（否）”：染色跟踪全流控未激活 |
| CPU负载 (千分比)    | 该参数用于显示CPU负载比例，千分比形式。                                             |
| 最大批收满比 (千分比)   | 该参数用于显示最大批收满比例，千分比形式。                                             |
| 染色消耗CPU比 (千分比) | 该参数用于显示染色模块消耗CPU比例，千分比形式。                                         |
