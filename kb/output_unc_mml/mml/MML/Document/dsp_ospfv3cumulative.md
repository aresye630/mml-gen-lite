# 查询OSPFv3统计信息（DSP OSPFV3CUMULATIVE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示OSPFv3统计信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                     |
|:-------|:----------|:-------------------------------------------------------------------------|
| PROCID | OSPFv3进程号 | 可选必选说明：可选参数 参数含义：OSPFv3进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 |

#### 使用实例

显示OSPFv3进程1的统计信息：

```
DSP OSPFV3CUMULATIVE:PROCID=1;
```
