#### 命令功能

**适用网元：SGSN、MME、AMF**

该命令用于查询GTPC本地实体。

#### 注意事项

- 本命令执行后立即生效。
- 所有参数不输入，表示查询所有已存在的GTPC本端实体记录。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                           |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GROUPID | 组号     | 可选必选说明：可选参数 参数含义：本参数用于指定GTPC本端实体对应的组号。组号用于组网规划时不同接口，或者不同用户范围使用独立的GTPC本端实体。 数据来源：本端规划 取值范围：0~32 默认值：无                                                           |
| IPTYPE  | IP地址类型 | 可选必选说明：可选参数 参数含义：本参数用于指定GTPC本端实体的IP地址类型。 数据来源：本端规划 取值范围：“TPTADDR_TYPE_IPV4(IPv4)”“TPTADDR_TYPE_IPV6(IPv6)” 默认值：无                                               |
| LEIPV4  | IPv4地址 | 可选必选说明：条件可选参数 参数含义：本参数用于指定GTPC本端实体的IPV4地址。 前提条件：该参数在“IP地址类型”参数配置为“TPTADDR_TYPE_IPV4(IPv4)”后生效。 数据来源：本端规划 取值范围：0.0.0.0~255.255.255.255 默认值：无                    |
| LEIPV6  | IPv6地址 | 可选必选说明：条件可选参数 参数含义：本参数用于指定GTPC本端实体的IPv6地址。 前提条件：该参数在“IP地址类型”参数配置为“TPTADDR_TYPE_IPV6(IPv6)”后生效。 数据来源：本端规划 取值范围：::~FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 |

#### 使用实例

1. 查询GTPC本地实体

   LST GTPCLE:;

   ```
   %%LST GTPCLE:;%%
   RETCODE = 0  执行成功。
   操作结果如下
   -------------------------
   组号     IP地址类型  IPv4地址          VPN名称   GTP-C本端实体标识   描述信息   资源标识

   11       IPv4        192.168.3.4       _abc_      0                  NULL       0
   3        IPv4        192.168.3.5       _abc_      1                  Gtpule     1
   (结果个数 = 2)

   ---    END
   ```

#### 输出结果说明

请参考**ADD GTPCLE**命令的参数标识。

| 输出项名称       | 输出项解释                                                                |
|:------------|:---------------------------------------------------------------------|
| GTP-C本端实体标识 | 参数含义：本参数用于指定本配置记录的索引。记录索引能够唯一标识一条GTPC本端实体的记录，在删除或修改操作时使用。 取值范围：0~255 |
| 资源标识        | 参数含义：本参数用于表示GTPC IP地址的唯一标识。GTPC LE中相同GTPC IP地址的资源标识相同。 取值范围：0~255    |
