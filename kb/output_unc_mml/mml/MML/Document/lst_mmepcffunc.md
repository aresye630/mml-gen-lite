#### 命令功能

**适用网元：MME**

该命令用于查询PCF策略功能。

#### 注意事项

无。

#### 本地用户权限

manage-ug;system-ug;monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无

#### 使用实例

查询PCF策略功能：

```
LST MMEPCFFUNC:;
```
