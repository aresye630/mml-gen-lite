# 查询BGP多源对等体地址族（LST BGPMULTIPEERAF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询使能BGP多源对等体的地址族信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                         |
|:-------------|:--------|:-------------------------------------------------------------------------------------------------------------|
| VRFNAME      | VPN实例名称 | 可选必选说明：可选参数 参数含义：该参数用于指定VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                                     |
| AFTYPE       | 地址族类型   | 可选必选说明：可选参数 参数含义：该参数用于指定地址族类型。 数据来源：本端规划 取值范围：枚举类型。 ipv4uni：IPv4地址族。ipv6uni：IPv6地址族。 默认值：无                   |
| PEERADDR     | 对等体地址   | 可选必选说明：可选参数 参数含义：该参数用于指定建立对等体的接口地址。 数据来源：对端协商 取值范围：IPv4地址类型。 默认值：无                                           |
| SOURCEIFNAME | 源接口名称   | 可选必选说明：可选参数 参数含义：该参数用于指定建立对等体的源接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：仅支持Ethernet及其子接口类型，不区分大小写。 |

#### 使用实例

查询BGP多源对等体地址族：

```
LST BGPMULTIPEERAF:;
```

```
RETCODE = 0   操作成功。

结果如下
------------------------
VPN实例名称 地址族类型  对等体地址  源接口名称          是否使能多源对等体

vrf1        IPV4        10.2.2.2    Ethernet66/0/3      TRUE
vrf1        IPV4        10.2.2.3    Ethernet66/0/4      TRUE
(结果个数 = 2)
---    END
```

#### 输出结果说明

| 输出项名称     | 输出项解释              |
|:----------|:-------------------|
| VPN实例名称   | 该参数用于指定VPN实例名称。    |
| 地址族类型     | 该参数用于指定地址族类型。      |
| 对等体地址     | 该参数用于指定建立对等体的接口地址。 |
| 源接口名称     | 用于表示建立对等体的源接口名称。   |
| 是否使能多源对等体 | 用于表示使能或去使能对等体。     |
