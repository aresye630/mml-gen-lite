# 设置SFE批量收取的报文数量（SET SFEPKTBATCHRCV）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

如果设置的批量收取的报文数量不合理，可能会导致VNRS侧转发性能下降。

该命令用来设置SFE批量收取的报文数量。

#### 注意事项

- 该命令仅适用于非池化场景。

该命令存在系统初始记录，参数的初始设置值如下表：

|   PKTNUM |
|---------:|
|      128 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                 |
|:-------|:---------|:-------------------------------------------------------------------------------------|
| PKTNUM | 批量收取报文数量 | 可选必选说明：必选参数 参数含义：该参数用于表示SFE批量收取的报文数量信息。 数据来源：本端规划 取值范围：整数类型，取值范围为1～128。 默认值：无 配置原则：无 |

#### 使用实例

```
设置SFE批量收取的报文数量为16：
SET SFEPKTBATCHRCV: PKTNUM=16;
```
