# 删除SCTP本地实体(RMV SCTPLE)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME、AMF**

该命令用于删除SCTP链路本地实体。

#### 注意事项

- 该命令执行后立即生效。
- 该命令执行后，会导致和此本地实体相连的gNodeB上的用户业务中断。
- 如果待删除的SCTP本地实体所属的实体组被NGAP本地实体或SFGAP本地实体引用，且是最后一个SCTP本地实体则不能被删除。
- 如果待删除的SCTP本地实体所属的实体组被NGAP本地实体或SFGAP本地实体引用，且是最后一个用户类型为NONUE或者BOTH的则不能被删除。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                 |
|:----------|:---------|:-----------------------------------------------------------------------------------------------------|
| SCTPLEIDX | 链路本地实体索引 | 可选必选说明：必选参数 参数含义：待删除的SCTP链路本地实体号。 取值范围：0～1023 默认值：无  说明： 可以通过LST SCTPLE命令查看已有配置，确认所要删除的SCTP链路本地实体索引。 |

#### 使用实例

删除链路本地实体号为1的SCTP链路：

```
%%RMV SCTPLE: SCTPLEIDX=1;%% 
RETCODE = 0  操作成功  

---    END
```
