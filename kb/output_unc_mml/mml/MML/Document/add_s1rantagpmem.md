# 增加4G TA群组成员（ADD S1RANTAGPMEM）

- 命令功能

#### 命令功能

**适用网元：MME**

该命令用于为****ADD S1RANTAGP****增加的跟踪区群组添加一条成员记录。

该命令的使用场景：当运营商希望只允许在白名单TAC区的基站接入时，可使用该命令配合**SET S1RANACCCTRL**命令开启对应功能。

#### 注意事项

- 该命令执行后立即生效。

- 不同的跟踪区群组相互独立，同一个跟踪区群组下的各跟踪区域不能有重叠。

- 最多可输入4096条记录。

#### 本地用户权限

manage-ug；system-ug；

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；

#### 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                         |
|:------------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| S1RANTAGPID | 跟踪区群组标识 | 可选必选说明：必选参数 参数含义：该参数用于指定跟踪区群组标识。 前提条件：“跟踪区群组标识”已经通过ADD S1RANTAGP配置。 数据来源：本端规划 取值范围：整数类型，取值范围是1~256。 默认值：无                                                    |
| TAC         | 跟踪区域码   | 可选必选说明：必选参数 参数含义：该参数用于指定跟踪区域码。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无                                                                                            |
| TACRANGE    | 跟踪区域码范围 | 可选必选说明：可选参数 参数含义：该参数用于指定跟踪区域码范围。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无 配置原则： 该参数的取值需要大于或等于“跟踪区域码”。  说明： 该参数与“跟踪区域码”参数构成一个TAC区段，方便维护人员配置连续的跟踪区域。如果不输入，表示配置单个TAC。 |

#### 使用实例

增加一个TA群组，跟踪区群组标识为1，其群组名称为“shanghai”，跟踪区域码为0x1234：

```
ADD S1RANTAGP: S1RANTAGPID=1, TANAME="shanghai";
ADD S1RANTAGPMEM: S1RANTAGPID=1, TAC="0x1234";
```
