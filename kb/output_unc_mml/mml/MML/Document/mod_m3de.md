# 修改M3UA目的实体(MOD M3DE)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME、SMSF**

该命令用于修改M3UA目的实体配置数据。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
|:-------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DEX    | 目的实体索引  | 可选必选说明：必选参数 参数含义：该参数用于指定唯一标识目的实体的索引。 数据来源：本端规划 取值范围：0~1279 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                               |
| SLSSM  | 链路集选择掩码 | 可选必选说明：可选参数 参数含义：该参数用于指定链路集选择掩码。链路集选择掩码用于路由选择，实现到同一个目的实体的多条路由之间的负荷分担。 数据来源：整网规划 取值范围：“B0000（B0000）”“B0001（B0001）”“B0010（B0010）”“B0011（B0011）”“B0100（B0100）”“B0101（B0101）”“B0110（B0110）”“B0111（B0111）”“B1000（B1000）”“B1001（B1001）”“B1010（B1010）”“B1011（B1011）”“B1100（B1100）”“B1101（B1101）”“B1110（B1110）”“B1111（B1111）” 默认值：无 配置原则：无  说明： 到一个目的实体的路由数目和链路集选择掩码的关系：1条路由，设置为全0；2条路由，设置1个BIT为1；3-4条路由，设置2个BIT为1；5-8条路由，设置3个BIT为1；9-16条路由，设置4个BIT为1； 到同一个目的实体，信令链路集选择掩码和信令链路选择掩码（LST M3LKS）不能够有相同的BIT位设置成1。 |
| DEN    | 目的实体名   | 可选必选说明：可选参数 参数含义：该参数用于标识目的实体。 数据来源：与对端网元协商 取值范围：长度不超过32的字符串 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                              |

#### 使用实例

将索引为1的M3UA目的实体链路集选择掩码修改为B0010，目的实体名修改为M3DE1：

```
MOD M3DE: DEX=1, SLSSM=B0010, DEN="M3DE1";
```
