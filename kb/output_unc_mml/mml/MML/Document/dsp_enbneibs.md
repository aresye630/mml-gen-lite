# 显示eNodeB邻接关系(DSP ENBNEIBS)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用网元：MME**

查询指定中心eNodeB的邻接eNodeB列表，对系统无影响。

#### 注意事项

此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                                    |
|:--------|:----------|:--------------------------------------------------------------------------------------------------------|
| ENBTYPE | eNodeB类型  | 可选必选说明：必选参数 参数含义：该参数用于指定中心eNodeB的类型。 取值范围： “HOME_ENODEB(Home_eNodeB)”“MACRO_ENODEB(Macro_eNodeB)” 默认值：无 |
| MCC     | 移动国家代码    | 可选必选说明：必选参数 参数含义：该参数用于指定中心eNodeB的移动国家码。 取值范围：3位数字 默认值：无                                                 |
| MNC     | 移动网号      | 可选必选说明：必选参数 参数含义：该参数用于指定中心eNodeB的移动网号。 取值范围：2～3位数字 默认值：无                                                |
| ENBID   | eNodeB 标识 | 可选必选说明：必选参数 参数含义：该参数用于指定中心eNodeB的标识。 取值范围：0～268435455(数值型) 默认值：无                                        |

#### 使用实例

查询移动国家码为123，移动网号为03，标识为326的中心eNodeB的邻接eNodeB列表：

DSP ENBNEIBS: ENBTYPE=HOME\_ENODEB, MCC="123", MNC="03", ENBID=326;

```
O&M  #61
%%DSP ENBNEIBS: ENBTYPE=HOME_ENODEB, MCC="123", MNC="03", ENBID=326;%%
RETCODE = 0  操作成功。

输出结果如下
--------------
     eNodeB类型    移动国家码    移动网号     eNodeB标识
     Home_eNodeB   123           03           327
     Home_eNodeB   123           03           328
(结果个数 = 2)

---    END
```

#### 输出结果说明

| 输出项名称    | 输出项解释                                                                                                                      |
|:---------|:---------------------------------------------------------------------------------------------------------------------------|
| eNodeB类型 | 查询出的邻接eNodeB类型。 取值说明: “HOME_ENODEB”“MACRO_ENODEB”  说明： HOME_ENODEB和MACRO_ENB分别为两种不同的eNodeB类型，该参数是eNodeB的基本信息，在eNodeB侧进行配置。 |
| 移动国家码    | 查询出的邻接eNodeB的移动国家码。                                                                                                        |
| 移动网号     | 查询出的邻接eNodeB的移动网号。                                                                                                         |
| eNodeB标识 | 查询出的邻接eNodeB标识。                                                                                                            |
