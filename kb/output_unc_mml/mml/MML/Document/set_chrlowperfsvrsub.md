# 设置低性能CHR服务器的单据订阅条件（SET CHRLOWPERFSVRSUB）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于进行CHR单据上报时，可以针对低性能CloudUDN设置单据订阅条件，订阅指定流程的单据上报到低性能CloudUDN。低性能CloudUDN是指处理部分业务流程CHR单据的CloudUDN。

#### 注意事项

- 系统初次运行时，会执行系统初始设置值。
- 本命令执行后立即生效。
- CHR冲突流程处理目前只对4G用户生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组
