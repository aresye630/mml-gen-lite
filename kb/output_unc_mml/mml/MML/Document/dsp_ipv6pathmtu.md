# 显示IPv6 Path MTU配置（DSP IPV6PATHMTU）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示IPv6路径MTU。

若不指定VRFNAME时，则显示本节点公网接口路径MTU信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                          |
|:------------|:-------|:------------------------------------------------------------------------------|
| VRFNAME     | VPN名称  | 可选必选说明：可选参数 参数含义：该参数用于表示VPN名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：_public_ |
| IPV6DSTADDR | IPv6地址 | 可选必选说明：可选参数 参数含义：该参数用于表示IPv6地址。 数据来源：全网规划 取值范围：IPv6地址类型。 默认值：无                |

#### 使用实例

显示IPv6 Path MTU：

```
DSP IPV6PATHMTU:VRFNAME="_public_";
```

```
       RETCODE = 0  操作成功。

   结果如下
   --------
               VPN名称  =  _public_
              IPv6地址  =  2001:db8::11
       路径MTU（byte）  =  1500
   表项超时时间（min）  =  NULL
           路径MTU类型  =  静态
              分片标记  =  0
  (结果个数 = 1)
   ---    END
```

#### 输出结果说明

| 输出项名称       | 输出项解释                |
|:------------|:---------------------|
| VPN名称       | 用于表示VPN名称。           |
| IPv6地址      | 用于表示IPv6地址。          |
| 路径MTU（byte） | 用于表示路径MTU。           |
| 表项超时时间（min） | 用于表示超时时间（NULL表示不超时）。 |
| 路径MTU类型     | 用于表示路径MTU类型（静态或动态）。  |
| 分片标记        | 用于表示分片标记（0表示不可分片）。   |
