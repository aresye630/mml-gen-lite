# 查询对端NF实例概述信息（LST PNFPROFILE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF、SMF、NSSF、SMSF、NCG、NRF、SGW-C、PGW-C、GGSN、CBC、CBCF**

该命令用于查询本地配置的对端NF实例的概述信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
|:--------------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCEID  | NF实例标识  | 可选必选说明：可选参数  参数含义：该参数用于指定NF实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~36。NFINSTANCEID参数必须满足以下约束规则：1.如果输入为uuid格式（格式例如：a6a61c6f-0d3a-4221-b1da-424eda3ccf67）只能为A-F、a-f、0-9和“-”的字符。2.如果输入不为uuid格式，长度不能超过18且不允许输入只包含0-9和“.”的字符串，例如：1.2.3.4、不允许输入只包含十六进制数（A-F、a-f、0-9）和“:”的字符串，例如：1::2、FBFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。3.不区分大小写。不支持配置单空格。  默认值：无  配置原则：  割接检查checklist要求以UUID格式配置。如果不为UUID格式，该参数被发送到对端网元且被使用时，可能出现异常。                                                                                                                                                                                                                                                                                                                                  |
| NFTYPE        | NF类型    | 可选必选说明：可选参数  参数含义：该参数用于指定NF类型。  数据来源：全网规划 取值范围： “NfInvalid（NfInvalid）”：NfInvalid“NfNRF（NfNRF）”：NfNRF“NfUDM（NfUDM）”：NfUDM“NfAMF（NfAMF）”：NfAMF“NfSMF（NfSMF）”：NfSMF“NfAUSF（NfAUSF）”：NfAUSF“NfNEF（NfNEF）”：NfNEF“NfPCF（NfPCF）”：NfPCF“NfSMSF（NfSMSF）”：NfSMSF“NfNSSF（NfNSSF）”：NfNSSF“NfUDR（NfUDR）”：NfUDR“NfLMF（NfLMF）”：NfLMF“NfGMLC（NfGMLC）”：NfGMLC“Nf5G_EIR（Nf5G_EIR）”：Nf5G_EIR“NfSEPP（NfSEPP）”：NfSEPP“NfUPF（NfUPF）”：NfUPF“NfN3IWF（NfN3IWF）”：NfN3IWF“NfAF（NfAF）”：NfAF“NfUDSF（NfUDSF）”：NfUDSF“NfBSF（NfBSF）”：NfBSF“NfCHF（NfCHF）”：NfCHF“NfCUSTOM_OCS（NfCUSTOM_OCS）”：NfCUSTOM_OCS“NfSCP（NfSCP）”：NfSCP“NfPCSCF（NfPCSCF）”：NfPCSCF“NfMBSMF（NfMBSMF）”：NfMBSMF“NfUDN（NfUDN）”：NfUDN“NfNWDAF（NfNWDAF）”：NfNWDAF“NfSCF（NfSCF）”：NfSCF“NfKMC（NfKMC）”：NfKMC  默认值：无  配置原则：无 |
| NFSTATUS      | NF状态    | 可选必选说明：可选参数  参数含义：该参数用于指定NF状态。  数据来源：全网规划 取值范围： “Invalid（Invalid）”：表示当前NF实例处于无效态，如果配置成该值，NF选择时不会选择此类NF。“Registered（Registered）”：表示当前NF实例处于注册态，如果配置成该值，NF选择时只会选择此类NF。“Suspend（Suspend）”：表示当前NF实例处于挂起态。当NF实例处于运维状态下，比如正在进行用户迁移等，不希望在NF发现流程中被选中时，可以置为此状态，迁移完毕后通过该命令对应的MOD命令修改为注册态即可。“DeRegistered（DeRegistered）”：表示当前NF实例处于去注册态，如果配置成该值，NF选择时不会选择此类NF。“UnDiscoverable（UnDiscoverable）”：表示当前NF实例处于不可被发现状态，如果配置成该值，NF选择时不会选择此类NF。  默认值：无  配置原则：  建议配置成Registered，如果配置成其它状态NF服务发现时不会被选中。                                                                                                                                                                                                                                                                   |
| FQDN          | 域名      | 可选必选说明：可选参数  参数含义：该参数用于指定NF的域名。本参数指定的域名中可以不包含PLMN信息，主要用于本网内的域名查询场景。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~255。不区分大小写。  默认值：无  配置原则： FQDN由一个或多个LABEL构成，各LABEL间用“.”间隔。每个LABEL的构成字符只能是字母A～Z或a～z、数字0～9和中划线“-”。例如，amf1.cluster1.net2.amf.5gc.mnc012.mcc345.3gppnetwork.org                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| IPADDRESSTYPE | IP地址类型  | 可选必选说明：可选参数  参数含义：该参数用于指定NF的IP地址类型。  数据来源：全网规划  取值范围：当NF类型为UPF时，IP地址类型不支持IPV4V6双栈类型，且IPV4或IPV6地址只能添加一个。 “IPTypeV4（IPTypeV4）”：IPv4“IPTypeV6（IPTypeV6）”：IPv6“IPTypeV4V6（IPTypeV4V6）”：IPv4v6  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| IPV4ADDRESS1  | IPV4地址1 | 可选必选说明：该参数在"IPADDRESSTYPE"配置为"IPTypeV4"时为条件必选参数。  参数含义：该参数用于指定NF的IPV4类型地址1。  数据来源：全网规划  取值范围：IPv4地址类型。IPv4支持A，B，C类地址及0.0.0.0。  默认值：无  配置原则：  如果相同的IP类型配置了多个IP地址，将随机使用其中的一个。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| IPV6ADDRESS1  | IPV6地址1 | 可选必选说明：该参数在"IPADDRESSTYPE"配置为"IPTypeV6"时为条件必选参数。  参数含义：该参数用于指定NF的IPV6类型地址1。  数据来源：全网规划  取值范围：IPv6地址类型。IPv6必须是全球单播地址；不能为“FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF”、环回地址(“::1”)、链路本地地址(“FE80::/10”)和组播地址(“FF00::/8”)。  默认值：无  配置原则：  如果相同的IP类型配置了多个IP地址，将随机使用其中的一个。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                            |
|:--------|:-----------------------------------------------------------------------------------------------------------------|
| NF实例标识  | 该参数用于指定NF实例标识。                                                                                                   |
| NF类型    | 该参数用于指定NF类型。                                                                                                     |
| NF状态    | 该参数用于指定NF状态。                                                                                                     |
| 域名      | 该参数用于指定NF的域名。本参数指定的域名中可以不包含PLMN信息，主要用于本网内的域名查询场景。                                                                |
| PLMN间域名 | 该参数用于指定PLMN间域名。当NF涉及跨PLMN网络间的NF发现时，需要为NF配置“PLMN间域名”。                                                             |
| IP地址类型  | 该参数用于指定NF的IP地址类型。                                                                                                |
| IPV4地址1 | 该参数用于指定NF的IPV4类型地址1。                                                                                             |
| IPV4地址2 | 该参数用于指定NF的IPV4类型地址2。                                                                                             |
| IPV4地址3 | 该参数用于指定NF的IPV4类型地址3。                                                                                             |
| IPV4地址4 | 该参数用于指定NF的IPV4类型地址4。                                                                                             |
| IPV6地址1 | 该参数用于指定NF的IPV6类型地址1。                                                                                             |
| IPV6地址2 | 该参数用于指定NF的IPV6类型地址2。                                                                                             |
| IPV6地址3 | 该参数用于指定NF的IPV6类型地址3。                                                                                             |
| IPV6地址4 | 该参数用于指定NF的IPV6类型地址4。                                                                                             |
| 端口号     | 该参数用于指定NF的端口号。                                                                                                   |
| 容量      | 本参数用于指定NF的相对权重（与其他同类型NF实例相比）。特别地，如果NF容量的绝对值不超过本参数的取值范围，那么本参数可以直接取用容量绝对值。例如AMF可接入的用户数是50000，那么该AMF的容量就可以用50000表示。 |
| 优先级     | 本参数用于指定NF的优先级（与其他同类型NF实例相比）。在NF选择过程中，NF会选择高优先级的NF，如果两个或多个NF的优先级一样，NF则会根据“容量”做进一步的判断。                             |
| 负载      | 本参数用于指定NF的负载。系统可能会将此参数作为NF选择的依据。                                                                                 |
| 位置信息    | 本参数用于指定NF的位置描述信息，比如NF所在的地域信息描述等。                                                                                 |
| NF描述名称  | 该参数用于表示NF实例的描述信息。                                                                                                |
| 协议模式    | 该参数用于指定协议模式。NFTYPE选择为SCP与SEPP时需要指定该参数。                                                                           |
