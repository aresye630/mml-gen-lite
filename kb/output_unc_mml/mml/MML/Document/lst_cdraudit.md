# 查询话单稽核（LST CDRAUDIT）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限

- 使用实例

#### 命令功能

**适用NF：NCG**

该命令用于查询当前系统已配置的话单稽核信息。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

| AUDITSTORDAYS | 话单稽核文件保存天数（天） | 可选必选说明：可选参数 参数含义：话单稽核文件的保存天数。 数据来源：本端规划 取值范围：整数类型，取值范围为0～180，单位是天。 默认值：无 配置原则：无                                                                                           |
| AUDITNAME     | 话单稽核文件命名规则    | 可选必选说明：可选参数 参数含义：话单稽核文件的命名规则。具体的配置规则及举例请参见表1。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～128。 默认值：无 配置原则：无                                                                             |

| AUDITPARA2    | 话单稽核参数2       | 可选必选说明：可选参数 参数含义：配置话单稽核文件统计的稽核指标。 数据来源：本端规划 取值范围：枚举类型。 CDRFileName：话单文件名。CDRNumber：话单文件话单张数。CDRFileSize：话单文件大小。CDRFileModifyTime：话单文件修改时间。 默认值：无 配置原则：无                   |
| AUDITPARA3    | 话单稽核参数3       | 可选必选说明：可选参数 参数含义：配置话单稽核文件统计的稽核指标。 数据来源：本端规划 取值范围：枚举类型。 ParaNotNeed：不需要参数。CDRFileName：话单文件名。CDRNumber：话单文件话单张数。CDRFileSize：话单文件大小。CDRFileModifyTime：话单文件修改时间。 默认值：无 配置原则：无 |
| AUDITPARA4    | 话单稽核参数4       | 可选必选说明：可选参数 参数含义：配置话单稽核文件统计的稽核指标。 数据来源：本端规划 取值范围：枚举类型。 ParaNotNeed：不需要参数。CDRFileName：话单文件名。CDRNumber：话单文件话单张数。CDRFileSize：话单文件大小。CDRFileModifyTime：话单文件修改时间。 默认值：无 配置原则：无 |

| GENINTERVAL   | 稽核文件生成时间间隔（分） | 可选必选说明：可选参数 参数含义：配置话单稽核文件生成的间隔时间。 数据来源：本端规划 取值范围：整数类型，取值范围为0～1440，单位是分钟。 默认值：0 配置原则： 当取值为0时，表示每天的零点生成话单稽核文件。当取值非0时，表示按指定的时间间隔生成话单稽核文件，同时每天的零点也会生成话单稽核文件。                  |
