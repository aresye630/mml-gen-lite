# 查询NF的订阅门限（LST NRFSUBTHRESHOLD）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NRF**

该命令用于查询NF的订阅个数的上限。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询NF的订阅门限：

```
LST NRFSUBTHRESHOLD:;
%%LST NRFSUBTHRESHOLD:;%%
RETCODE = 0  操作成功

结果如下
------------------------
   订阅门限  =  90
内部订阅门限 = 100
(结果个数 = 1)
```

## 输出结果说明

| 输出项名称   | 输出项解释                                |
|:--------|:-------------------------------------|
| 订阅门限    | 该参数用于表示NF的订阅个数的上限。                   |
| 内部订阅门限  | 该参数用于设置内部订阅个数的上限，仅在SCP和NRF联合部署场景下生效。 |
