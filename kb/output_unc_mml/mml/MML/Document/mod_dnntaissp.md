# 修改DNN的TAI和ServingScope映射（MOD DNNTAISSP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于修改DNN的TAI和ServingScope映射。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                            |
|:-------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DNNNI        | DNN网络标识 | 可选必选说明：必选参数  参数含义：该参数用于表示DNN网络标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。输入指定的DNN NI，可输入的字符有字母、十进制数字、“-”和“.”，并且开头和结尾只能是数字或者字母，不能出现连续两个“.”。字母大小写不敏感。  默认值：无  配置原则：无                                                                                                                                  |
| MCC          | MCC     | 可选必选说明：必选参数  参数含义：该参数用于表示组成商城区域的位置区成员的移动国家码，与无线接入网的MCC一致。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                                                                                                                                                         |
| MNC          | MNC     | 可选必选说明：必选参数  参数含义：该参数用于表示组成商城区域的位置区成员的移动网号，与无线接入网的MNC一致。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                                                                                                                                                      |
| BGNTAC       | 跟踪区起始编码 | 可选必选说明：必选参数  参数含义：该参数用于表示跟踪区编码起始值。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。TAC编码为16进制数，只能由数字（0-9），字母（A-F、a-f）组成。字母大小写不敏感。  默认值：无  配置原则：  如果组成商城的跟踪区编码是连续的，则可通过本参数以及“跟踪区结束编码”联合表示；如果跟踪区编码是离散的，那么仅使用本参数表示该跟踪区。                                                                                              |
| ENDTAC       | 跟踪区结束编码 | 可选必选说明：可选参数  参数含义：该参数用于表示跟踪区编码结束值。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。TAC编码为16进制数，只能由数字（0-9），字母（A-F、a-f）组成。字母大小写不敏感。本参数表示的跟踪区编码不能小于“跟踪区起始编码”。ENDTAC若不下发，则赋值为BGNTAC值。  默认值：无  配置原则：无                                                                                                                  |
| SERVINGSCOPE | 服务范围    | 可选必选说明：可选参数  参数含义：该参数用于描述锚点SMF的服务范围。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~64。如果输入多个服务范围，那么使用“:”作为分隔符，比如“pudong:puxi”。  默认值：无  配置原则：  如果用户不输入本参数，则默认使用本AMF的“服务范围”作为待选锚点SMF的“服务范围”；否则使用本参数值作为待选锚点SMF的“服务范围”。  NRF针对“服务范围”是按照“包含”的逻辑进行处理的，即锚点SMF能为发现请求中携带的所有服务范围提供服务，NRF才会认为其满足条件；故本参数在输入时应避免输入无效的服务范围。 |

## 使用实例

修改一条DNN的TAI和ServingScope映射关系，“DNN网络标识”为“huawei.com”，“移动网号”为“03”，“跟踪区编码起始值”为“000112”，“跟踪区编码结束值”为“000700”，“服务范围”为“puxi:pudong”，执行如下命令：

```
MOD DNNTAISSP: DNNNI="huawei.com", MCC="460", MNC="03", BGNTAC="000112", ENDTAC="000700", SERVINGSCOPE="puxi:pudong";
```
