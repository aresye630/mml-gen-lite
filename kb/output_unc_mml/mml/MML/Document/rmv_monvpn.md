# 删除监控VPN实例（RMV MONVPN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除监控VPN实例。

## 注意事项

- 该命令执行后立即生效。

- 该命令适用于支持热备容灾的网元执行。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                             |
|:------------|:--------|:-------------------------------------------------------------------------------------------------|
| DRGROUPID   | 容灾组标识   | 可选必选说明：必选参数  参数含义：该参数用于配置容灾组标识。  数据来源：全网规划  取值范围：整数类型，取值范围是1~8。  默认值：无  配置原则：无                   |
| VPNGRPID    | VPN组标识  | 可选必选说明：必选参数  参数含义：该参数用于配置VPN组标识。  数据来源：全网规划  取值范围：整数类型，取值范围是1~10。  默认值：无  配置原则：无                 |
| VPNINSTANCE | VPN实例名称 | 可选必选说明：必选参数  参数含义：该参数用于配置VPN实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~31。VPN实例名称禁止相同。  默认值：无  配置原则：无 |

## 使用实例

删除监控VPN实例:

```
%%RMV MONVPN:DRGROUPID=1,VPNGRPID=1,VPNINSTANCE="1";%%
```
