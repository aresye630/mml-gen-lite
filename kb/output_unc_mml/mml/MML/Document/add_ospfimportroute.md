# 创建OSPF引入路由配置（ADD OSPFIMPORTROUTE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来将外部路由引入到OSPF域中，并在OSPF域中发布引入的路由信息。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为8000。
- 只有执行ADD OSPF配置了OSPF进程才能使用此命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称      | 参数说明                                                                                                                           |
|:---------------|:----------|:-------------------------------------------------------------------------------------------------------------------------------|
| PROCID         | OSPF进程号   | 可选必选说明：必选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 配置原则： 设备支持OSPF特性。OSPF进程必须已经存在。请使用LST OSPF命令查看可用的OSPF进程。 |
| TOPOID         | 拓扑标识      | 可选必选说明：可选参数 参数含义：拓扑标识。 数据来源：全网规划 取值范围：整数类型，取值范围为0。 默认值：0 配置原则：目前只支持默认拓扑0。                                                      |
| PROTOCOL       | 协议分类      | 可选必选说明：必选参数 参数含义：用于指定OSPF引入外部路由的路由类型。 数据来源：本端规划 取值范围：枚举类型。 Direct：直连路由。OSPF：OSPF路由。Static：静态路由。BGP：BGP路由。wlr：无线路由。 默认值：无       |
| PROTOCOLPROCID | 协议进程号     | 可选必选说明：条件可选参数 前提条件：该参数在“PROTOCOL”配置为“OSPF”时为可选参数。 参数含义：引入路由协议的进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：1                |
| IMPTCOSTCFG    | 引入路由开销值配置 | 可选必选说明：可选参数 参数含义：标志是否设置路径开销值。 数据来源：本端规划 取值范围：枚举类型。 FALSE：不使能。TRUE：使能。 默认值：FALSE                                                |
| IMPTTAGCFG     | 引入路由标签配置  | 可选必选说明：可选参数 参数含义：标志是否设置类型的值。 数据来源：本端规划 取值范围：枚举类型。 FALSE：不使能。TRUE：使能。 默认值：FALSE                                                 |
| IMPTTYPECFG    | 引入路由类型配置  | 可选必选说明：可选参数 参数含义：标志是否置位外部LSA的标记。 数据来源：本端规划 取值范围：枚举类型。 FALSE：不使能。TRUE：使能。 默认值：FALSE                                             |
| COST           | 路径Cost值   | 可选必选说明：条件必选参数 前提条件：该参数在“IMPTCOSTCFG”配置为“TRUE”时为必选参数。 参数含义：该参数用于指定自治系统外部路径的开销。 数据来源：本端规划 取值范围：整数类型，取值范围为0～16777214。 默认值：无       |
| TAG            | 标签        | 可选必选说明：条件必选参数 前提条件：该参数在“IMPTTAGCFG”配置为“TRUE”时为必选参数。 参数含义：外部LSA中的标记。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无               |
| TYPE           | 引入路由类型    | 可选必选说明：条件必选参数 前提条件：该参数在“IMPTTYPECFG”配置为“TRUE”时为必选参数。 参数含义：外部LSA的度量类型。 数据来源：本端规划 取值范围：整数类型，取值范围为1～2。 默认值：无                      |
| ROUPOLINAME    | 路由策略名称    | 可选必选说明：可选参数 参数含义：路由策略名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无                                                              |
| PERMITIBGPCFG  | 允许BGP配置   | 可选必选说明：条件可选参数 前提条件：该参数在“PROTOCOL”配置为“BGP”时为可选参数。 参数含义：使能引入IBGP路由。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：FALSE          |

#### 使用实例

在OSPF进程下1下引入OSPF进程2的路由：

```
ADD OSPFIMPORTROUTE:PROCID=1,TOPOID=0,PROTOCOL=OSPF,PROTOCOLPROCID=2;
```
