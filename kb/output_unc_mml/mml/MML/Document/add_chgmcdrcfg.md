# 增加M-CDR计费配置(ADD CHGMCDRCFG)

- 命令功能

- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

本命令用于添加对特定PLMN用户生成M-CDR的配置。

#### 注意事项

- 该命令配置数据仅在软参**BYTE\_EX\_B76 BIT3**置为1时生效。
- 该命令控制效果与命令**SET CHGCHAR**的优先级相同。即：**ADD CHGMCDRCFG**配置了对应PLMN或者**SET CHGCHAR**开启时，均会生成M-CDR。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                               |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：必选参数 参数含义：该参数用于指定所包含的用户范围。 数据来源：整网规划 取值范围： “PLMNID（指定PLMNID）” 默认值：无                                         |
| MCC      | 移动国家码  | 可选必选说明：条件必选参数 参数含义：该参数用于表示PLMN的移动国家号码。 前提条件：该参数在“用户范围”参数设置为“PLMNID（指定PLMNID）”时生效。 数据来源：整网规划 取值范围：位数为3的十进制数字 默认值：无  |
| MNC      | 移动网号   | 可选必选说明：条件必选参数 参数含义：该参数用于表示PLMN的移动网号码。 前提条件：该参数在“用户范围”参数设置为“PLMNID（指定PLMNID）”时生效。 数据来源：整网规划 取值范围：位数为2或3的十进制数字 默认值：无 |

#### 使用实例

增加对MCC=460、MNC=03的用户生成M-CDR的配置。

```
ADD CHGMCDRCFG: SUBRANGE=PLMNID, MCC="460", MNC="03";
```
