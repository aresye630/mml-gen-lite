# 查询自动扩缩容配置（LST SCALINGCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此命令用于查询自动扩缩容的相关参数设置。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

无

## 使用实例

LST SCALINGCFG:;

```
%%LST SCALINGCFG:;%%
RETCODE = 0  操作成功 
结果如下 
-------- 
扩容门槛 = 81
缩容门槛 = 19
扩缩容步进方式 = PodNumber
扩缩容步长 = 48
(结果个数 = 1) 
---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                   |
|:--------|:----------------------------------------|
| 扩容阈值    | 该参数用于表示扩容阈值，CPU超过该阈值触发自动扩容。             |
| 缩容阈值    | 该参数用于表示缩容阈值，CPU低于该阈值则触发自动缩容。            |
| 扩缩容步进方式 | 该参数用于表示扩缩容步进方式，可以按照数量百分比弹性，也可以扩缩容指定个数。  |
| 扩缩容步长   | 该参数用于表示扩缩容步长，该参数取值依赖扩缩容步进方式，代表百分比值或者个数。 |
