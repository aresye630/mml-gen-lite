# 查询密码禁用词（LST PWDBLACKLIST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查看密码禁用词。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

无。

#### 使用实例

查询密码禁用词：

```
LST PWDBLACKLIST:;
```

```
RETCODE = 0  操作成功

结果如下:
-------------------------
密码禁用词 = a
(结果个数 = 1)

---    END
```
