# 恢复IKE历史信息清空状态（RTR IKEERRHISTORY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于清除IKE历史信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                              |
|:---------|:---------|:--------------------------------------------------------------------------------------------------|
| PODNAME  | Pod名称    | 可选必选说明：可选参数  参数含义：Pod名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~63。  默认值：无  配置原则：无                       |
| ADDRTYPE | 地址类型     | 可选必选说明：可选参数  参数含义：对端地址类型。  数据来源：对端协商 取值范围： IPV4（IPv4地址）IPV6（IPv6地址）  默认值：无  配置原则：无                |
| PEERIP   | 对端IPv4地址 | 可选必选说明：该参数在"ADDRTYPE"配置为"IPV4"时为条件可选参数。  参数含义：对端IPv4地址。  数据来源：对端协商  取值范围：IPv4地址类型。  默认值：无  配置原则：无 |
| PEERIP6  | 对端IPv6地址 | 可选必选说明：该参数在"ADDRTYPE"配置为"IPV6"时为条件可选参数。  参数含义：对端IPv6地址。  数据来源：对端协商  取值范围：IPv6地址类型。  默认值：无  配置原则：无 |
| VRFNAME  | VPN名称    | 可选必选说明：可选参数  参数含义：VRF名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~31。  默认值：无  配置原则：无                       |
| PORTNUM  | 端口号      | 可选必选说明：可选参数  参数含义：端口号。  数据来源：本端规划  取值范围：整数类型，取值范围是1~65535。  默认值：无  配置原则：无                         |

## 使用实例

清除IKE历史信息

```
RTR IKEERRHISTORY:ADDRTYPE=IPV4;
```
