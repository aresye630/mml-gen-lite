# 删除注册中心链路 (RMV RCAPLNK)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SMSF**

此命令用于删除注册中心链路配置。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                   |
|:-------|:-------|:---------------------------------------------------------------------------------------|
| LNK    | 链路索引   | 可选必选说明：必选参数 参数含义：该参数用于指定链路的索引。该参数用来在系统范围内部唯一标识一条Rcenter链路。 数据来源：整网规划 取值范围：0~1023 默认值：无 |

#### 使用实例

1. 删除链路索引为0的注册中心链路配置，可以用如下命令：

   ```
   RMV RCAPLNK: LNK=0;
   ```
