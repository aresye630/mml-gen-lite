# 增加HSS BYPASS最小用户签约数据配置 (ADD HSSBPUSRSUB)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

此命令用于新增HSS BYPASS最小用户签约数据配置。

用户处于HSS BYPASS状态之后，无法从HSS获取用户签约数据，如果系统内无用户历史签约数据，使用该命令手动配置用户最小签约数据，保证业务惯性运行。

#### 注意事项

- 该命令执行后立即生效。
- 此命令最大记录数为1024。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                |
|:-------------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE     | 用户范围      | 可选必选说明：必选参数 参数含义：该参数用于指定配置HSS BYPASS最小签约数据集的用户范围。 数据来源：本端规划 取值范围：“ALL_USER(所有用户)”“FOREIGN_USER(外网用户)”“HOME_USER(本网用户)”“IMSI_PREFIX(指定IMSI前缀)” 默认值：无 配置原则：对于指定的用户（群），HSS Bypass最小签约数据集的匹配优先级从高到低依次为：“IMSI_PREFIX(指定IMSI前缀)”，“FOREIGN_USER(外网用户)”或“HOME_USER(本网用户)”，“ALL_USER(所有用户)”。 |
| IMSIPRE      | IMSI前缀    | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI前缀以区分不同的用户群。 前提条件：该参数在“用户范围”参数配置为“IMSI_PREFIX(指定IMSI前缀)”后生效。 数据来源：本端规划 取值范围：5～15位十进制数字字符串 默认值：无 配置原则：无                                                                                                                                                |
| STNSR        | STN-SR    | 可选必选说明：可选参数 参数含义：该参数用于指定用户的STN-SR。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1-16位的十六进制数 默认值：无 配置原则：无  说明： 该参数会覆盖Forward Relocation Request消息携带的STN-SR信元。                                                                                                                                         |
| NETACCMODE   | 网络接入模式    | 可选必选说明：可选参数 参数含义：该参数用于指定用户支持的Network-Access-Mode。 数据来源：本端规划 取值范围： PS_CS（PS和CS域）：PS和CS域PS（仅PS域）：仅PS域 默认值：PS_CS（PS和CS域） 配置原则：无                                                                                                                                                        |
| ODB          | 运营商闭锁分组业务 | 可选必选说明：可选参数 参数含义：该参数表示用户的ODB业务类型。 数据来源：本端规划 取值范围： ALL_PACKET_SERVICES（禁止所有用户）：禁止用户所有分组域业务。 ROAMER_ACCESS_HPLMN_AP（禁止漫游用户使用Home Routed方式）：禁止漫游用户使用Home Routed方式进行分组域业务。 ROAMER_ACCESS_VPLMN_AP（禁止漫游用户使用Local Breakout方式）：禁止漫游用户使用Local Breakout方式进行分组域业务。 默认值：无 配置原则：无               |
| APNGRPID     | APN群组ID   | 可选必选说明：必选参数 参数含义：用于指定APN本地配置签约群组。 数据来源：本端规划 取值范围：0~511 默认值：无 配置原则：须先在ADD HSSBPAPNGRP中配置取值相同的“APNGRPID”参数。                                                                                                                                                                           |
| CHARGINGCHAR | 计费属性      | 可选必选说明：可选参数 参数含义：该参数用于指定用户的计费属性。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为0000~FFFF 默认值：无 配置原则：该参数生效优先级低于ADD HSSBPAPNSUB的“CHARGINGCHAR”参数。                                                                                                                                                       |

#### 使用实例

添加HSS BYPASS最小用户签约数据配置，可以用如下命令：

```
ADD HSSBPUSRSUB: SUBRANGE=IMSI_PREFIX, IMSIPRE="12134567", STNSR="FF123", NETACCMODE=PS_CS, ODB=ALL_PACKET_SERVICES-1&ROAMER_ACCESS_HPLMN_AP-1&ROAMER_ACCESS_VPLMN_AP-1, APNGRPID=0;
```
