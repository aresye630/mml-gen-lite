#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询TAILAI用户群的记录。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                         |
|:-------|:-------|:---------------------------------------------|
| SUBID  | 用户群标识  | 可选必选说明：可选参数 参数含义：待查询的用户群标识。 取值范围：1～100 默认值：无 |

#### 使用实例

查询一条用户群标识为1的TAILAI用户群记录：

LST TAILAISUBGP: SUBID=1;

```
%%LST TAILAISUBGP: SUBID=1;%%
RETCODE = 0  操作成功。

输出结果如下
--------------
用户群标识  =  1
用户群名称  =  NULL
(结果个数 = 1)
---    END
```
