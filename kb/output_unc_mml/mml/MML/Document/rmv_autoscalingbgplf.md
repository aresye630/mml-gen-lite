# 删除BGP入不转板自动化配置模板（RMV AUTOSCALINGBGPLF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除BGP入不转板自动化配置模板。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                     |
|:------------|:-------|:-------------------------------------------------------------------------------------------------------------------------|
| POLICYNAME  | 策略名称   | 可选必选说明：必选参数 参数含义：该参数用于指定BGP入不转板策略名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格和中文。 默认值：无                                    |
| SERVICENAME | 服务名称   | 可选必选说明：必选参数 参数含义：该参数用来表示接口自动化配置服务模板名称。该参数由ADD AUTOSCALINGSERVICE命令配置获得。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格和中文。 默认值：无 |

#### 使用实例

删除一个BGP入不转板自动化配置模板：

```
RMV AUTOSCALINGBGPLF:POLICYNAME="bgppolicy",SERVICENAME="s1";
```
