# 查询链路控制消息日志开关(LST LNKCTRLLOG)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明

- 输出结果说明

#### 命令功能

**适用NF：AMF**

该命令用于查询链路控制消息日志开关。

#### 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无

#### 使用实例

若要查询链路控制消息日志开关，可以用如下命令：

```
%%LST LNKCTRLLOG:;%%
RETCODE = 0  操作成功

操作结果如下
------------------------ 
SCTP  =  开启
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见SET LNKCTRLLOG的参数说明。
