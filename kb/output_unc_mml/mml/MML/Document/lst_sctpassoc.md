# 查询SCTP耦联测量对象（LST SCTPASSOC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-C、SMF**

此命令用于查询SCTP耦联测量对象。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称           | 参数说明                                                                                                                |
|:--------------|:---------------|:--------------------------------------------------------------------------------------------------------------------|
| OBJECTID      | SCTP偶联测量对象实例标识 | 可选必选说明：可选参数 参数含义：该参数用于指定SCTP耦联测量对象实例标识。 数据来源：本端规划 取值范围：整数类型，取值范围为1～200。 默认值：无 配置原则：无                                |
| IPVERSION     | IP版本           | 可选必选说明：可选参数 参数含义：该参数用于指定SCTP耦联测量对象的IP地址类型。 数据来源：对端协商 取值范围：枚举类型。 IPV4：IPv4地址类型。IPV6：IPv6地址类型。 默认值：无 配置原则：无           |
| LOCALADDRIPV4 | 本端主IPv4地址      | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPV4”时为可选参数。 参数含义：该参数用于指定SCTP耦联本端主IP地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无 配置原则：无 |
| PEERADDRIPV4  | 对端主IPv4地址      | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPV4”时为可选参数。 参数含义：该参数用于指定SCTP耦联对端主IP地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无 配置原则：无 |
| LOCALADDRIPV6 | 本端主IPv6地址      | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPV6”时为可选参数。 参数含义：该参数用于指定SCTP耦联本端主IP地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无 配置原则：无 |
| PEERADDRIPV6  | 对端主IPv6地址      | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPV6”时为可选参数。 参数含义：该参数用于指定SCTP耦联对端主IP地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无 配置原则：无 |

#### 使用实例

查询SCTP耦联测量对象：

```
LST SCTPASSOC: OBJECTID=1;
```
