# 查询基于管理的最小化路测的PLMN(LST MDTPLMN)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于查询基于管理的最小化路测（MDT）的PLMN。

#### 注意事项

无

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                       |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------|
| MCC    | 移动国家码  | 可选必选说明：可选参数 参数含义：该参数表示组成Serving PLMN的移动国家码信息。 数据来源：全网规划 取值范围：字符串类型，输入长度是3。只允许输入十进制数字（0-9）。 默认值：无 配置原则：无    |
| MNC    | 移动网号   | 可选必选说明：可选参数 参数含义：该参数表示组成Serving PLMN的移动网号信息。 数据来源：全网规划 取值范围：字符串类型，输入长度范围是2~3。只允许输入十进制数字（0-9）。 默认值：无 配置原则：无 |

#### 使用实例

查询所有最小化路测的PLMN，执行如下命令：

`LST MDTPLMN:;`

```
%%LST MDTPLMN:;%% 
RETCODE = 0  操作成功  
操作结果如下 
------------------------ 
移动国家码        移动网号              描述信息   
123                  030                  visit         
456                  030                  visit         
(结果个数 = 2)  
---    END
```
