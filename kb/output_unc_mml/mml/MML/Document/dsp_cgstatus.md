# 查询CG状态（DSP CGSTATUS）

- 命令功能
- 注意事项
- 操作用户权限

- 输出结果说明

#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

该命令用于查询所有CG或指定CG的工作状态。如果不输入要查询CG的IP地址，则显示所有CG信息。

#### 注意事项

返回的记录数超过300条时，可能不全。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                            |
|:------------|:----------|:----------------------------------------------------------------------------------------------------------------|
| CGIPVERSION | CG IP版本   | 可选必选说明：可选参数 参数含义：该参数用于指定CG IP类型。 数据来源：全网规划 取值范围：枚举类型。 IPV4：IPv4。IPV6：IPv6。 默认值：无 配置原则：无                         |
| CGIPV4ADDR  | CG IPv4地址 | 可选必选说明：条件必选参数 前提条件：该参数在“CGIPVERSION”配置为“IPV4”时为必选参数。 参数含义：指定CG服务器的IPv4地址。 数据来源：全网规划 取值范围：IPv4地址类型。 默认值：无 配置原则：无 |
| CGIPV6ADDR  | CG IPv6地址 | 可选必选说明：条件必选参数 前提条件：该参数在“CGIPVERSION”配置为“IPV6”时为必选参数。 参数含义：指定CG服务器的IPv6地址。 数据来源：全网规划 取值范围：IPv6地址类型。 默认值：无 配置原则：无 |

#### 使用实例

查询IP地址为192.168.61.60的CG的链路状态：

```
DSP CGSTATUS: CGIPVERSION=IPV4, CGIPV4ADDR="192.168.61.60";
```
