# 查询APN粒度的通用会话拓展功能控制（LST APNSMCOMFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于查询APN粒度的通用会话拓展功能控制。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                           |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN    | APN名称  | 可选必选说明：可选参数  参数含义：该参数用于指示APN名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“ ” ”、“ ` ”特殊字符，不区分大小写。  默认值：无  配置原则：  该参数使用ADD APN命令配置生成。 |

## 使用实例

- 显示“APN名称”为“huawei.com”的APN粒度通用会话拓展功能控制：

  ```
  %%LST APNSMCOMFUNC: APN="huawei.com";%%
  RETCODE = 0  操作成功

  结果如下
  --------
              APN名称  =  huawei.com
  在EPS是否先获取策略  =  使能
        VnGroupID来源  =  使能
  (结果个数 = 1)

  ---    END
  ```
- 显示全部APN的通用会话拓展功能控制：

  ```
  %%LST APNSMCOMFUNC:;%%
  RETCODE = 0  操作成功

  结果如下
  --------
  APN名称  	在EPS是否先获取策略  	VnGroupID来源
  huawei.com  	使能                    UDM
  huawei2.com    	使能                    UDM
  (结果个数 = 2)

  ---    END
  ```

## 输出结果说明

| 输出项名称       | 输出项解释                                             |
|:------------|:--------------------------------------------------|
| APN名称       | 该参数用于指示APN名称。                                     |
| 在EPS是否先获取策略 | 该参数用于指定当PGW-C对接PCF时，是否先跟PCF交互获取会话策略，再动态分配UE IP地址。 |
| VnGroupID来源 | 该参数用于指定在5G LAN场景下，SMF上VnGroupID的获取来源。             |
