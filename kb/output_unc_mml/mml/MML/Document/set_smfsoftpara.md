## 命令功能

**适用NF：SMF、SGW-C、PGW-C、GGSN**

该命令用于设置SMF的软件参数信息。

## 使用实例

- 设置SMF软件参数，数据类型是“Dw”，Dword索引是“1”，Dword值是“3”

  ```
  SET SMFSOFTPARA: DT=Dw, DWORDNUM=1, DWORDVALUE=3;
  ```
- 设置SMF软件参数，数据类型是“Bit”，Bit索引是“1”，Bit值是“1”

  ```
  SET SMFSOFTPARA: DT=Bit, BITNUM=1, BITVALUE=1;
  ```
- 设置SMF软件参数，数据类型是“Byte”，Byte索引是“1”，Byte值是“3”

  ```
  SET SMFSOFTPARA: DT=Byte, BYTENUM=1, BYTEVALUE=3;
  ```
- 设置SMF软件参数，数据类型是“String”，String索引是“1”，String值是“smf\_service”

  ```
  SET SMFSOFTPARA: DT=String, STRINGNUM=1, STRINGVALUE="smf_service";
  ```
