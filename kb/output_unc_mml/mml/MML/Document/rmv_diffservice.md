# 删除差异化服务接入门限(RMV DIFFSERVICE)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用于删除差异化服务配置信息，差异化服务是指针对不同优先级的用户，提供不同的接入控制策略，保证优先级别高的用户具有优先使用网络资源的权力。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AT     | 接入类型   | 可选必选说明：必选参数 参数含义：该参数用于设置待删除的用户接入门限或者PDP接入门限。 取值范围： “USER(用户接入)”：差异化服务触发类型为用户类型“PDP(PDP接入)”：差异化服务触发类型为PDP类型 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| USRPRI | 用户级别   | 可选必选说明：条件可选参数 参数含义：该参数用于指定待删除的用户签约QoS属性中的分配保留优先级（Allocation/Retention Priority）。 前提条件：此参数在“AT”设置为“USER(用户接入)”或“PDP(PDP接入)”时生效。 取值范围： “HIGHLEVELUSER(高端用户)”：分配保留优先级为1。“NORMALUSER(普通用户)”：分配保留优先级为2。“LOWLEVELUSER(低端用户)”：分配保留优先级为3。 默认值：无  说明： 不输入该参数时，按“接入类型”删除所有用户级别的接入门限。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| SRVLVL | 业务级别   | 可选必选说明：条件可选参数 参数含义：该参数用于指定待删除的业务级别，由用户PDP上下文QoS中的流量等级（Traffic class）、下行保证速率（Guaranteed bit rate for downlink）和发送控制优先级（Traffic handling priority）确定。 前提条件：此参数在“接入类型”选取为“PDP(PDP接入)”时生效。 取值范围：“CONVERSATION(Conversation)”：流量等级为Conversational class。“STREAMINGGBRMORE25KBPS(StreamGBRMore25kbps)”：流量等级为Streaming class，下行保证速率大于等于25kbit/s。“STREAMINGGBRLESS24KBPS(StreamGBRLess24kbps)”：流量等级为Streaming class，下行保证速率小于等于24kbit/s。“INTERACTIVETRAFFICPRI1(InteractiveTrafficPri1)”：流量等级为Interactive class，发送控制优先级为1。“INTERACTIVETRAFFICPRI2(InteractiveTrafficPri2)”：流量等级为Interactive class，发送控制优先级为2。“INTERACTIVETRAFFICPRI3(InteractiveTrafficPri3)”：流量等级为Interactive class，发送控制优先级为3。“BACKGROUND(Background)”：流量等级为Background class。“NONE(None)”：通用业务级别，表示该用户没有业务级别，设置的门限就是该用户级别所有业务级别的门限。 默认值：无  说明： 不输入该参数时，按“接入类型”删除所有业务级别的接入门限。 |

#### 使用实例

删除以PDP方式接入，用户级别为“高端用户”，业务级别为“Background”的差异化服务配置信息：

RMV DIFFSERVICE: AT=PDP, USRPRI=HIGHLEVELUSER, SRVLVL=BACKGROUND;
