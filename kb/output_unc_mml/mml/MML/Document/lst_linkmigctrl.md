# 查询链路迁移控制参数（LST LINKMIGCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C、SMF、GGSN**

该命令用于查询链路迁移控制参数，涉及的链路接口类型为Ga/Gx/Gy/S6b。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询链路迁移控制参数：

```
%%LST LINKMIGCTRL:;%%
RETCODE = 0  操作成功

结果如下
--------
     容器CPU阈值  = 65
链路均分时间间隔  = 2
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称    | 输出项解释                                                                      |
|:---------|:---------------------------------------------------------------------------|
| 容器CPU阈值  | 该参数用于设置判定链路拥塞的容器CPU阈值。                                                     |
| 均分链路时间间隔 | 该参数用于设置整机复位场景均分链路时间间隔。整机复位场景，进程启动后，间隔该参数配置的时长后，如果所有链路分配在同一个POD上，则执行一次链路均分。 |
