# 查询默认PLMN（LST DFTSRVNODEPLMN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C、GGSN**

该命令用于查看UNC设备默认的PLMN。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                      |
|:---------|:-------|:------------------------------------------------------------------------------------------|
| NODETYPE | 结点类型   | 可选必选说明：可选参数  参数含义：该参数用于指定网元类型。  数据来源：本端规划 取值范围： SGSN（SGSN）SGW（SGW）PGW（PGW）  默认值：无  配置原则：无 |

## 使用实例

查看PGW默认所属的PLMN：

```
%%LST DFTSRVNODEPLMN:;%%
RETCODE = 0  操作成功

结果如下
--------
结点类型  =  SGSN
PLMN标识  =  12345
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释          |
|:--------|:---------------|
| 结点类型    | 该参数用于指定网元类型。   |
| PLMN标识  | 该参数用于指定PLMN标识。 |
