# 设置CSLB分片重组优先级配置（SET LBFRAGRSCFG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

本命令属于高危命令，操作不当会导致业务受损，请谨慎使用并联系华为技术支持协助操作。

该命令用于设置CSLB分片重组优先级配置。

#### 注意事项

- 该命令仅在SET LBFRAGRSCFGSW配置独占资源池配置开关为开启后生效。

该命令存在系统初始记录，参数的初始设置值如下表：

| PRIORITY   |
|:-----------|
| NORMAL     |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                   |
|:----------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DSCPVALUE | DSCP值  | 可选必选说明：必选参数 参数含义：该参数用于配置DSCP值。 数据来源：本端规划 取值范围：整数类型，取值范围为0~63。 默认值：无 配置原则：无                                                                                             |
| PRIORITY  | 优先级    | 可选必选说明：必选参数 参数含义：该参数用于指定DSCP值对应的分片重组优先级高或低，仅高优先级报文才可以使用独占资源池，高低优先级报文都可以使用非独占资源池。 数据来源：本端规划 取值范围：枚举类型 HIGH(高)：DSCP值对应的分片重组优先级高。NORMAL(低)：DSCP值对应的分片重组优先级低。 默认值：无 配置原则：无 |

#### 使用实例

设置DSCP值为0，优先级为高，命令如下：

```
SET LBFRAGRSCFG: DSCPVALUE=0, PRIORITY=HIGH;
```
