# 删除PCF策略控制（RMV MMEPCFPLCY）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于删除PCF策略控制。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
|:----------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE  | 用户范围     | 可选必选说明：必选参数 参数含义：该参数用于表示MME上配置AM策略控制参数的用户范围。 数据来源：全网规划 取值范围： “ALL_USER（所有用户）”：所有用户 “HOME_USER（本网用户）”：本网用户 “FOREIGN_USER（外网用户）”：外网用户 “IMSI_PREFIX（IMSI前缀）”：IMSI前缀 “SPECIFIC_IMSI（特定IMSI）”：特定IMSI “MSISDN_PREFIX（MSISDN前缀）”：MSISDN前缀 “SPECIFIC_MSISDN（特定MSISDN）”：特定MSISDN 默认值：无 配置原则： 对于指定的用户（群），策略匹配的优先级从高到低依次为：“SPECIFIC_MSISDN（特定MSISDN）”,“SPECIFIC_IMSI（特定IMSI）”，“MSISDN_PREFIX（指定MSISDN前缀）”，“IMSI_PREFIX（指定IMSI前缀）”，“FOREIGN_USER（外网用户）”或“HOME_USER（本网用户）”，“ALL_USER（所有用户）”。 |
| NOID      | 运营商标识    | 可选必选说明：条件必选参数 参数含义：该参数用于指定运营商标识。 前提条件：该参数在“用户范围”参数配置为“HOME_USER（本网用户）”或“FOREIGN_USER（外网用户）”后生效。 数据来源：整网规划 取值范围：0~64，128~254 默认值：无 配置规则： 若该参数需要配置为0或128~254之间的值时，须先在ADD MNO中配置取值相同的“MNOID”参数。 若该参数需要配置为1~64之间的值时，须先在ADD MVNO中配置取值相同的“MVNOID”参数。                                                                                                                                                                                                                                  |
| IMSIPRE   | IMSI前缀   | 可选必选说明：该参数在“SUBRANGE”配置为“IMSI_PREFIX”时为条件必选参数。 参数含义：该参数用于指定应用AM策略和UE策略的用户的IMSI前缀。 数据来源：全网规划 取值范围：字符串类型，输入长度范围是5~14。只允许输入十进制数字（0-9）。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                |
| IMSI      | IMSI     | 可选必选说明：条件必选参数 参数说明：该参数用于指定国际移动用户标识。 前提条件：此参数在“用户范围”设置为“SPECIFIC_IMSI（特定IMSI）”后生效。 取值范围：14-15位十进制数字字符串 默认值：无                                                                                                                                                                                                                                                                                                                                                                     |
| MSISDNPRE | MSISDN前缀 | 可选必选说明：该参数在“SUBRANGE”配置为“MSISDN_PREFIX”时为条件必选参数。 参数含义：该参数用于指定应用AM策略和UE策略的用户的MSISDN前缀。 数据来源：全网规划 取值范围：字符串类型，输入长度范围是5~14。只允许输入十进制数字（0-9）。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                            |
| MSISDN    | MSISDN   | 可选必选说明：条件必选参数 参数说明：该参数用于指定移动台国际ISDN号码。 前提条件：此参数在“用户范围”设置为“SPECIFIC_MSISDN （特定MSISDN）”后生效。 取值范围：13-15位十进制数字字符串 默认值：无                                                                                                                                                                                                                                                                                                                                                             |

#### 使用实例

删除PCF策略控制，“用户范围”设置为“IMSI\_PREFIX”，IMSI前缀为46009876000001。

```
RMV MMEPCFPLCY: SUBRANGE=IMSI_PREFIX, IMSIPRE="46009876000001";
```
