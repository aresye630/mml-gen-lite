# 设置端口报文统计开关（SET MSSPMDMATCH）

- 命令功能

#### 命令功能

**须知** 

本命令用于使能端口按规则统计报文开关，开启会降低性能，且在用户指定的时间后自动去使能，默认时间是30分钟。

该命令用于设置端口报文规则匹配开关，是诊断开关命令。当端口收发报文异常或者端口流量不通的时候，可以开关打开规则匹配，协助问题定位。

使用包记录功能时，不能对记录的文件做迁移、删除操作，否则会导致包记录功能失效。如果需要清空文件重新记录，只需要关闭所有端口的包记录开关后再打开即可。

默认记录前64字节报文内容，记录文件默认路径/home，单个文件大小20MB，所有文件可占用磁盘空间100MB，可通过MANO注入修改默认配置，其中记录报文长度最大可配64字节。

#### 注意事项

- 该命令执行后立即生效。
- 本命令用于使能端口按规则统计报文开关，开启会降低性能，且在用户指定的时间后自动去使能，默认时间是30分钟。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组;

#### 参数说明

| 参数标识         | 参数名称          | 参数说明                                                                                                                                                                                                                                                                                            |
|:-------------|:--------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CELLTYPE     | 微服务类型         | 可选必选说明：必选参数 参数含义：该参数用于指定微服务类型。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～63。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符。 默认值：无 配置原则：使用DSP PAENODE查看工作角色为数据转发对应的微服务类型。                                                                                                                |
| CELLINSTANCE | 微服务实例号        | 可选必选说明：必选参数 参数含义：该参数用于指定微服务实例号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～127。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符。 默认值：无 配置原则：使用DSP PAENODE查看工作角色为数据转发对应的微服务实例号。                                                                                                             |
| PORTID       | 端口号           | 可选必选说明：必选参数 参数含义：该参数用于表示端口ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无 配置原则：使用DSP MSSPORTINFO查看端口号。                                                                                                                                                                                         |
| ENABLE       | 开关使能          | 可选必选说明：必选参数 参数含义：该参数用于表示开关使能。 数据来源：本端规划 取值范围：枚举类型。 FALSE：关闭。TRUE：打开。 默认值：无                                                                                                                                                                                                                      |
| RXTXTYPE     | 收发包类型         | 可选必选说明：必选参数 参数含义：该参数用于表示收包或发包。 数据来源：本端规划 取值范围：枚举类型。 rx：接收报文统计。tx：发送报文统计。 默认值：无                                                                                                                                                                                                                  |
| MODE         | 模式            | 可选必选说明：条件可选参数 前提条件：该参数在“ENABLE”配置为“TRUE”时为可选参数。 参数含义：该参数用于设置匹配模式。 数据来源：本端规划 取值范围：枚举类型。 TIME：按照时长进行统计。PACKETS-NUMBER：按照报文个数进行统计。 默认值：TIME                                                                                                                                                        |
| TIME         | 统计开关持续时间（min） | 可选必选说明：条件必选参数 前提条件：该参数在“MODE”配置为“TIME”时为必选参数。 参数含义：该参数用于表示统计时长，超时后开关自动关闭，单位为分钟。 数据来源：本端规划 取值范围：整数类型，取值范围为1～1440。 默认值：30                                                                                                                                                                         |
| PKTNUM       | 报文包数          | 可选必选说明：条件必选参数 前提条件：该参数在“MODE”配置为“PACKETS-NUMBER”时为必选参数。 参数含义：该参数用于表示统计包的个数，达到设定个数后开关自动关闭。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无                                                                                                                                                          |
| RECORD       | 记录报文功能使能      | 可选必选说明：条件可选参数 前提条件：该参数在“ENABLE”配置为“TRUE”时为可选参数。 参数含义：该参数用于使能报文记录功能。 数据来源：本端规划 取值范围：枚举类型。 FALSE：关闭。TRUE：打开。 默认值：FALSE                                                                                                                                                                            |
| RATELIMIT    | 报文记录限速开关      | 可选必选说明：条件可选参数 前提条件：该参数在“RECORD”配置为“TRUE”时为可选参数。 参数含义：该参数用于表示报文限速开关使能。 数据来源：本端规划 取值范围：枚举类型。 FALSE：关闭。TRUE：打开。 默认值：FALSE                                                                                                                                                                          |
| RATE         | 报文记录限速        | 可选必选说明：条件必选参数 前提条件：该参数在“RATELIMIT”配置为“TRUE”时为必选参数。 参数含义：该参数用于表示限速报文记录，单位为pps。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：10000                                                                                                                                                                  |
| RULELIST     | 规则列表          | 可选必选说明：条件可选参数 前提条件：该参数在“ENABLE”配置为“TRUE”时为可选参数。 参数含义：该参数用于规则ID列表，支持绑定多个规则ID，输入格式为“1,2,3”，匹配时按照输入的顺序进行，如果当前规则匹配不成功，则会继续匹配下一个规则，如果当前规则匹配成功后，那么不会继续匹配下一个规则。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～63。区分大小写。 默认值：无 配置原则： 输入单空格将删除该参数已有配置项。规则列表必须是DSP MSSRULEM获取到的一个或多个值。使用SET MSSRULEM配置规则列表。输入单空格，统计所有的报文。 |

#### 使用实例

打开微服务类型为104的微服务实例csdb-pod-0172-16-0-247\_\_103\_\_0的端口1的发送报文统计开关：

```
%%SET MSSPMDMATCH: CELLTYPE="104", CELLINSTANCE="csdb-pod-0172-16-0-247__103__0", PORTID=1, ENABLE=TRUE, RXTXTYPE=tx, MODE=TIME, TIME=30, RECORD=FALSE, RULELIST="1,2";%%
RETCODE = 0  操作成功

---    END
```
