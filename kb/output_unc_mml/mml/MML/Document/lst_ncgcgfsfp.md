#### 命令功能

**适用NF：NCG**

该命令用于查询当前配置的NCG大颗粒软参信息。

- 若需要查询全部软件参数信息，请不要输入任何参数。
- 若需要查询某一软件参数的详细信息，请输入“软参ID”。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                |
|:---------|:-------|:------------------------------------------------------------------------------------|
| SFPID    | 软参ID   | 可选必选说明：可选参数 参数含义：用于表示NCG大颗粒软参ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4999。 默认值：无 配置原则：无      |
| SFPVALUE | 软参值    | 可选必选说明：可选参数 参数含义：用于表示NCG大颗粒软参值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967294。 默认值：无 配置原则：无 |

#### 使用实例

查询“软参ID”为“1”的软参值：

```
LST NCGCGFSFP: SFPID=1;
```

```
RETCODE = 0  操作成功

结果如下:
```

```
软参ID  =  1
软参值  =  10
--------

(结果个数 = 1)
---    END
```
