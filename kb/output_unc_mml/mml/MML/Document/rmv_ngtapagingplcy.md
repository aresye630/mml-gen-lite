# 删除5G跟踪区列表的寻呼策略配置（RMV NGTAPAGINGPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除基于5G跟踪区列表的寻呼策略配置数据。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                 |
|:---------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
| TALISTID | 跟踪区列表标识 | 可选必选说明：必选参数  参数含义：该参数用于标识一个跟踪区列表，一个跟踪区列表由一个或若干个跟踪区组成。一个跟踪区列表最多可包含16个跟踪区。  数据来源：本端规划  取值范围：整数类型，取值范围是0~65534。  默认值：无  配置原则：  本参数配置前须先在ADD NGTALST中配置。 |

## 使用实例

删除一条5G跟踪区列表的寻呼策略配置，执行如下命令：

```
RMV NGTAPAGINGPLCY: TALISTID=1;
```
