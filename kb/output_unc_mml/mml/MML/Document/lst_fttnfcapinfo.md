# 查询AMF容灾网元剩余容量信息（LST FTTNFCAPINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令仅在调测场景下，用于查询AMF POOL内其它AMF网元的剩余容量信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                                                        |
|:-------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCEID | AMF实例标识 | 可选必选说明：可选参数  参数含义：该参数用于在UNC系统中唯一指定某个AMF实例。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~36。可输入的字符有字母A～Z或a～z、数字0～9、中划线"-"和下划线"_"，例如，AMF_Instance_0，不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

查询NF Instance ID为Amf\_Instance\_1的网元剩余容量信息，执行如下命令：

```
%%LST FTTNFCAPINFO:;%%
RETCODE = 0  操作成功

结果如下
--------
AMF实例标识  =  amf_instance_1
   资源类型  =  CPU资源
   资源名称  =  PBU_C-A
     资源值  =  0
(结果个数 = 1)

---    END
```
