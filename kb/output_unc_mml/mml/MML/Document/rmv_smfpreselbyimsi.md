# 删除基于IMSI优选指定SMF配置（RMV SMFPRESELBYIMSI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除基于IMSI优选指定SMF配置。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                           |
|:-------|:-------|:-----------------------------------------------------------------------------------------------|
| IMSI   | IMSI   | 可选必选说明：必选参数  参数含义：该参数用于指定进行优选指定SMF的用户IMSI。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是14~15。  默认值：无  配置原则：无 |

## 使用实例

删除IMSI为“123456789012345”的用户优选指定SMF配置，执行如下命令：

```
RMV SMFPRESELBYIMSI:IMSI="123456789012345";
```
