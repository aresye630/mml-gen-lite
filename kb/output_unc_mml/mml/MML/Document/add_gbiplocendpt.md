# 增加本端端点配置(ADD GBIPLOCENDPT)

#### 命令功能

**适用网元：SGSN**

该命令用于在Gb OVER IP时增加一个Gb接口本端端点配置。

#### 注意事项

- 该命令执行后立即生效。
- 本表最大记录数为8192。
- 配置本端端点时，必须通过**ADD NSE**命令先配置NSE，且NSE的承载类型为IP。
- SGSN仅支持一个NSE下配置10个IPv4类型的本端端点。
- SGSN仅支持一个NSE下配置10个IPv6类型的本端端点。
- 配置本端端点的时候需要使用**DSP IPNSVC**查看已有IPNSVC链路数，增加时考虑是否超过单进程和整系统的规格。SGSN支持每个进程上1024条IPNsvc链路，整系统16384条IPNsvc链路。
- 目前暂不支持IPv6。
- 如果新添加的本端端点的IP地址在Gb地址池中，且端口号与GBLOCPORTRGE的预置端口相等，则添加失败。
- 不能使用Gb自动配置的预配置端点作为手动配置NSE的本端端点。预配置端点的IP地址是通过**ADD GBEPPOOL**配置的，而其端口号是通过**SET GBLOCPORTRGE**设置的。
- IP地址和vpn名称必须在SERVICEIP表中已经配置，可以用**LST SERVICEIP**查询。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                                                                                               |
|:--------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NSEI    | NSE标识    | 可选必选说明：必选参数 参数含义：该参数用于指定端点所在的网络服务实体标识。 数据来源：整网规划 取值范围：0～65535 默认值：无  说明： 必须已经配置成IP承载类型的NSE。                                                                        |
| IPT     | IP地址类型   | 可选必选说明：必选参数 参数含义：该参数用于指定IP地址类型。 数据来源：整网规划 取值范围：“IPV4(IPv4)”“IPV6(IPv6)” 默认值：无                                                                                      |
| LIPV4   | 本端IPv4地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定本端使用的IPv4地址。 前提条件：该参数在“IP地址类型”设置为“IPV4(IPv4)”时才生效。 数据来源：整网规划 取值范围：0.0.0.0～255.255.255.255 默认值：无                                          |
| LIPV6   | 本端IPv6地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定本端使用的IPv6地址。 前提条件：该参数在“IP地址类型”设置为“IPV6(IPv6)”时才生效。 数据来源：整网规划 取值范围： ::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无  说明： 目前不支持IPV6地址的配置。 |
| LUP     | 本端UDP端口号 | 可选必选说明：必选参数 参数含义：该参数用于指定本端使用的UDP端口号。 数据来源：整网规划 取值范围：1024～65535 默认值：无                                                                                               |
| SW      | 信令权重     | 可选必选说明：可选参数 参数含义：该参数为保留参数，暂未实现。 数据来源：整网规划 取值范围：0～255 默认值：255 配置原则：数值越大，权重越大。  说明： 在NSE为IP动态配置类型时，信令权重可以通过相关流程下发PCU。                                                |
| DW      | 数据权重     | 可选必选说明：可选参数 参数含义：该参数为保留参数，暂未实现。 数据来源：整网规划 取值范围：0～255 默认值：255  说明： 在NSE为IP动态配置类型时，数据权重可以通过相关流程下发PCU。                                                                |
| DESC    | 描述       | 可选必选说明：可选参数 参数含义：该参数用于指定本端端点名称。 数据来源：整网规划 取值范围：长度不超过32的字符串 默认值：无                                                                                                   |
| VPNNAME | vpn名称    | 可选必选说明：可选参数 参数含义：VPN名称。 数据来源：全网规划 取值范围：1～31位字符串 默认值：无                                                                                                              |

#### 使用实例

增加一个本端端点，IPv4地址为192.168.2.1，UDP端口为2001，对应BSC1：

ADD GBIPLOCENDPT: NSEI=600, IPT=IPV4, LIPV4="192.168.2.1", LUP=2001, DESC="FOR BSC1";
