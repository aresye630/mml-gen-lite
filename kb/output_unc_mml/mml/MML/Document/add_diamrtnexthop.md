# 增加Diameter路由下一跳（ADD DIAMRTNEXTHOP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

此命令用于添加指定Diameter应用和realm的Diameter路由的下一跳。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1280。
- 一个指定域名和应用下最大允许配置80个下一跳主机。
- 下一跳列表中主机顺序依赖于序号值，下一跳顺序确定了主备路由（主备路由选择模式）以及路由被选择的顺序。主备路由选择模式下，如果主用下一跳被删除，则第一个备用下一跳升主。如需对主备关系进行调整，需要先删除该路由，再按照期望的路由主备顺序配置下一跳主机列表。
- 配置的下一跳主机要与此Diameter路由的应用类型一致，并且需要通过ADD DIAMCONNECTION配置UNC与该下一跳主机的Diameter链路。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称         | 参数说明                                                                                                                                                                            |
|:------------|:-------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| REALMNAME   | Diameter域名名称 | 可选必选说明：必选参数 参数含义：该参数用于指定Diameter路由的realm名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～127。不支持空格，必须是可见ASCII码，由软参BIT 150控制是否区分大小写。 默认值：无 配置原则： 该参数使用ADD DIAMRTREALM命令配置生成。如果配置为default则表示缺省路由。 |
| APPLICATION | Diameter应用   | 可选必选说明：必选参数 参数含义：该参数用于指定Diameter路由的Diameter应用。 数据来源：本端规划 取值范围：枚举类型。 GY：Gy接口应用。GX：Gx接口应用。S6B：S6b接口应用。 默认值：无 配置原则：无                                                               |
| NEXTHOP     | 下一跳          | 可选必选说明：必选参数 参数含义：该参数用于指定Diameter路由的下一跳。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～127。不支持空格，由软参BIT 150控制是否区分大小写。 默认值：无 配置原则： 该参数使用ADD DRA命令配置生成。UNC与DRA之间存在Diameter链路。                      |
| SEQUENCE    | 序号           | 可选必选说明：必选参数 参数含义：该参数用于指定Diameter路由下一跳的序号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～65535。 默认值：无 配置原则：同一个域名和应用的下一跳配置中，在主备模式下，序号值最小的最优先被选中。在轮询模式下，轮选按照序号从小到大的顺序选择路由。                            |

#### 使用实例

- 添加一个Gy接口的缺省Diameter路由的下一跳host1：

  ```
  ADD DIAMRTNEXTHOP: REALMNAME="default", APPLICATION=GY, NEXTHOP="host1", SEQUENCE=1;
  ```
- 添加指定realm名为example.com的Gx应用的两个Diameter路由下一跳，host1和host2：

  ```
  ADD DIAMRTNEXTHOP: REALMNAME="example.com", APPLICATION=GX, NEXTHOP="host1", SEQUENCE=1;
  ADD DIAMRTNEXTHOP: REALMNAME="example.com", APPLICATION=GX, NEXTHOP="host2", SEQUENCE=2;
  ```
