# 查询CDF token策略（LST CDFTOKENPOLICY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NCG**

该命令用于查询cdf token权重上报开关。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识            | 参数名称          | 参数说明                                                                                                                                                      |
|:----------------|:--------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
| WEIGHTSWITCH    | cdf token权重开关 | 可选必选说明：可选参数  参数含义：设置CDF token权重开关。  数据来源：本端规划 取值范围： “ENABLE（使能）”：需要上报cdf token权重时，需要配置权重开关为使能“DISABLE（不使能）”：不需要上报cdf token权重时，需要配置权重开关为不使能  默认值：无  配置原则：无 |
| WEIGHTREDUCTION | RU权重下降系数      | 可选必选说明：可选参数  参数含义：设置Bi接口性能与接入性能的比例，该值越大可接入的5G业务越少。  数据来源：本端规划  取值范围：整数类型，取值范围是0~100。  默认值：无  配置原则：无                                                       |

## 使用实例

查询cdf token权重开关配置和RU权重下降系数：

```
+++    UNC/*MEID:0 MENAME:UNC_VNF_ncg001*/        2022-05-24 20:27:32+8:00
O&M    #3936
%%LST CDFTOKENPOLICY:;%%
RETCODE = 0  操作成功

结果如下
--------
 cdf token权重开关  =  使能
     RU权重下降系数 = 20
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称         | 输出项解释                            |
|:--------------|:---------------------------------|
| cdf token权重开关 | 设置CDF token权重开关。                 |
| RU权重下降系数      | 设置Bi接口性能与接入性能的比例，该值越大可接入的5G业务越少。 |
