# 增加基于IMSI的5G缺省NI策略（ADD NGDFTNIIMSI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于配置AMF基于特定用户范围的缺省NI策略，即通过用户特征（如是否签约特定DNN）决策是否向UE下发缺省NI。

应用场景为：运营商希望配置的缺省NI不对所有UE下发，而是通过用户特征（是否签约特定DNN）决策是否向特定用户范围（如本网用户、指定IMSI前缀或指定IMSI）的UE下发，可以通过该命令实现。

## 注意事项

- 下一次移动性流程生效。

- 该命令最大记录数为1024。
- 该命令与SET NGDFTNIPLCY命令均可控制是否向特定用户下发缺省NI。系统会首先匹配本命令的配置记录，若发现系统中匹配不中本命令的配置记录才会匹配SET NGDFTNIPLCY命令的配置记录。
- SUBRANGE匹配的优先级从高到低依次为：“SPECIFIC\_IMSI（指定IMSI）”、“IMSI\_PREFIX(IMSI前缀)”、“HOME\_USER(本网用户)。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称            | 参数说明                                                                                                                                                                                                                                                                                                                                               |
|:-------------|:----------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE     | 用户范围            | 可选必选说明：必选参数  参数含义：该参数用于指定配置缺省NI（Network Identity）策略生效的用户范围。  数据来源：本端规划 取值范围： “HOME_USER（本网用户）”：本网用户“IMSI_PREFIX（指定IMSI前缀）”：指定IMSI前缀“SPECIFIC_IMSI（指定IMSI）”：指定IMSI  默认值：无  配置原则：无                                                                                                                                                                   |
| IMSIPRE      | IMSI前缀          | 可选必选说明：该参数在"SUBRANGE"配置为"IMSI_PREFIX"时为条件必选参数。  参数含义：该参数用于系统根据指定用户的IMSI前缀进行匹配，从而区分不同的用户群。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是5~14。只允许输入十进制数字（0-9）。  默认值：无  配置原则：  不可与“SPECIFIC_IMSI（指定IMSI）”相同。                                                                                                                                                         |
| IMSI         | IMSI            | 可选必选说明：该参数在"SUBRANGE"配置为"SPECIFIC_IMSI"时为条件必选参数。  参数含义：该参数用于指定国际移动用户标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是14~15。只允许输入十进制数字（0-9）。  默认值：无  配置原则：  不可与“IMSIPRE（IMSI前缀）”相同。                                                                                                                                                                                |
| AMFDNNSW     | 基于DNN下发缺省NI功能开关 | 可选必选说明：可选参数  参数含义：该参数用于控制AMF是否支持基于特定DNN关键字下发缺省NI功能。当本参数设置为"ON"时，AMF会根据配置的特定DNN关键字（ADD DFTNIDNN配置）匹配用户签约的DNN来判断是否向用户下发缺省NI；如果DNN匹配不成功，AMF不下发缺省NI。  数据来源：全网规划 取值范围： “OFF（关闭）”：关闭“ON（开启）”：开启  默认值：OFF  配置原则：无                                                                                                                                         |
| AMFDFTNI     | 缺省NI取值策略        | 可选必选说明：该参数在"AMFDNNSW"配置为"ON"时为条件可选参数。  参数含义：该参数用于控制AMF缺省NI取值策略。对于未勾选的缺省NI下发时，不考虑用户是否签约特定DNN，默认下发缺省NI。  数据来源：全网规划 取值范围： “NGMNO（NGMNO）”：ADD NGMNO配置的默认NI“NITZPLCY（NITZPLCY）”：ADD NITZPLCY配置的默认NI“AMFPLCYFUNC（AMFPLCYFUNC）”：SET AMFPLCYFUNC配置的默认NI  默认值：NGMNO-1&NITZPLCY-1&AMFPLCYFUNC-1  配置原则：  如果全部不勾选，相当于“基于DNN下发缺省NI功能”未开启。                       |
| UDMBYPASSDNN | 是否使用最小签约数据      | 可选必选说明：该参数在"AMFDNNSW"配置为"ON"时为条件可选参数。  参数含义：该参数用于控制是否使用最小签约数据（ADD UDMBYPASSSUB中SNSSAIINFOS参数）进行DNN关键字匹配。 当用户进入UDM BYPASS状态后，由于无法获取用户真实的签约数据，在开启“基于DNN下发缺省NI功能开关”时，DNN会匹配失败，用户始终不下发缺省NI，该参数用于控制是否使用最小签约数据替代真实签约数据进行DNN匹配。  数据来源：全网规划 取值范围： “YES（是）”：是“NO（否）”：否  默认值：NO  配置原则：  该开关开启时，需要ADD UDMBYPASSSUB中SNSSAIINFOS参数配合进行，建议只针对特定VIP用户配置特殊的最小签约数据。 |

## 使用实例

增加一个指定IMSI前缀的用户配置的缺省NI策略，其中，“用户范围”为：“IMSI\_PREFIX”，“IMSI前缀”为：“12345678910”，“基于DNN下发缺省NI功能开关”为：“ON”，“缺省NI取值策略”为：“NGMNO-0&NITZPLCY-1&AMFPLCYFUNC-0”，“是否使用最小签约数据”为：“NO”，执行如下命令：

```
ADD NGDFTNIIMSI: SUBRANGE=IMSI_PREFIX, IMSIPRE="12345678910", AMFDNNSW=ON, AMFDFTNI=NGMNO-0&NITZPLCY-1&AMFPLCYFUNC-0, UDMBYPASSDNN=NO;
```
