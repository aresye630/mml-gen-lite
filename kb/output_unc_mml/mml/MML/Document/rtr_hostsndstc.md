# 清除发送方向协议报文统计计数（RTR HOSTSNDSTC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于清除发送方向协议报文统计计数。

当不指定RUNAME参数时，清除所有资源单元的统计信息；当指定RUNAME参数时，可以清除指定资源单元的统计信息。

当不指定PROTTYPE参数时，清除所有协议类型的统计信息；当指定PROTTYPE参数时，可以清除指定协议类型的统计信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                   |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROTTYPE | 协议类型   | 可选必选说明：可选参数 参数含义：该参数用于表示协议类型。 数据来源：本端规划 取值范围：枚举类型。 ARP：ARP协议类型。ICMP：ICMP协议类型。OSPF：OSPF协议类型。SNMP：SNMP协议类型。UDP_OTHER：其它UDP协议类型。BGP：BGP协议类型。LDP：LDP协议类型。TCP_OTHER：其它TCP协议类型。ICMPV6：ICMPv6协议类型。OSPFV3：OSPFv3协议类型。IPV6UDP_OTHER：其它IPv6 UDP协议类型。IPV6TCP_OTHER：其它IPv6 TCP协议类型。 默认值：无 配置原则：如果不输入该参数，则表示所有协议类型。 |
| RUNAME   | RU名称   | 可选必选说明：可选参数 参数含义：该参数用于表示RU名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：请使用DSP RU命令查看可用接口。                                                                                                                                                                                                          |

#### 使用实例

- 清除发送方向指定协议的协议报文统计计数：

  ```
  RTR HOSTSNDSTC: PROTTYPE=TCP_OTHER;
  ```
- 清除发送方向指定资源单元指定协议类型的协议报文统计计数：

  ```
  RTR HOSTSNDSTC: RUNAME="VNODE_VNRS_VNFC_OMU_0001", PROTTYPE=TCP_OTHER;
  ```
