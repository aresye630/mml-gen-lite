# 查询主接口允许通过的VLAN（LST IFALLOWEDVLAN）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询主接口允许通过的VLAN。

#### 注意事项

- 该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询在接口Ethernet64/0/4上配置的允许通过的VLAN范围：

```
LST IFALLOWEDVLAN:;
```

```
RETCODE = 0  操作成功

结果如下:
---------
接口名1         接口名2         VLAN最小值  VLAN最大值  

Ethernet64/0/4  Ethernet64/0/5  50          100         
Ethernet64/0/4  Ethernet64/0/5  100         150         
(结果个数 = 2)

---    END
```
