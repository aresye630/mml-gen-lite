# 删除NF或NF服务支持的域名（RMV ALLOWEDNFDOMAIN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、NRF、NSSF、NCG、CBC、CBCF**

该命令用于删除NF或NF服务实例支持的域名。当NF或NF服务实例不再支持为某个域名服务时，需要对域名进行删除。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                             |
|:-------|:-------|:---------------------------------------------------------------------------------|
| INDEX  | 索引标识   | 可选必选说明：必选参数  参数含义：本参数用于指定索引标识。  数据来源：全网规划  取值范围：整数类型，取值范围是0~4095。  默认值：无  配置原则：无 |

## 使用实例

运营商A需要删除索引标识为0的域名支持信息。

```
RMV ALLOWEDNFDOMAIN: INDEX=0;
```
