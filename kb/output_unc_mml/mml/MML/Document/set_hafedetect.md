# 设置HAFETCD网络亚健康探测参数（SET HAFEDETECT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置HAFETCD网络亚健康探测功能的开关、探测间隔、亚健康阈值、租约到期阈值、统计周期等参数。

当开关参数设置为关闭时，不开启探测功能或将已开启的探测功能关闭。

当开关参数设置为开启时，根据探测间隔、亚健康阈值、租约到期阈值和统计周期等参数开启探测功能。

当探测功能已开启，修改探测间隔、亚健康阈值、租约到期阈值或统计周期等参数时，则根据新的参数重启探测功能。

当探测功能开启后，在统计周期结束时，会对链路的状态进行判定，若超过半数的HAFETCD备节点到HAFETCD主节点之间的链路状态异常，或者HAFETCD主节点与SDRE容器之间的链路状态异常，则计算HAFETCD备节点之间的链路两两互通的节点集合，若集合中节点数量超过HAFETCD节点数量的一半，则将HAFETCD主节点迁移到集合中节点通信地址最小的节点上。

## 注意事项

- 该命令执行后立即生效。

- 两个节点之间链路两两互通，指的是第一个节点向第二个节点发送探测报文能够收到响应报文，丢错包占比不超出亚健康阈值，并且第二个节点向第一个节点发送探测报文丢错包占比同样不超出亚健康阈值。
- 节点通信地址最小，指的是HAFETCD节点的通信IP与端口号拼接的字符串按自然排序后的第一个元素，可以使用指令**DSP ELECTION**查询节点的通信地址。
- 设置参数时，应考虑合理性，如探测间隔设置为5，亚健康阈值设置为10，统计周期设置为10，即每500毫秒发送一次探测报文，统计周期10秒，预期发送20个包，即使丢错包数量为1，丢错包占比也达到了百分之五，远远超出了设置的亚健康阈值千分之十，这种不合理的配置使得探测能力过于敏感，可能会导致HAFETCD主发生不必要的迁移。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| SUBHEALTHSW   |   DETECTINTERVAL |   THRESHOLD |   LEASETHRESHOLD |   STATISINTERVAL |
|:--------------|-----------------:|------------:|-----------------:|-----------------:|
| ON            |                5 |         300 |               50 |               30 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称        | 参数说明                                                                                                                                                                                                                                                                        |
|:---------------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBHEALTHSW    | 探测功能开关      | 可选必选说明：可选参数  参数含义：该参数用于开启或关闭HAFETCD的网络亚健康探测功能。  数据来源：本端规划 取值范围： “ON（开启）”：HAFETCD网络亚健康探测开启“OFF（关闭）”：HAFETCD网络亚健康探测关闭  默认值：ON。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST HAFEDETECT查询当前参数配置值。  配置原则：无                                                                                  |
| DETECTINTERVAL | 探测间隔(100ms) | 可选必选说明：该参数在"SUBHEALTHSW"配置为"ON"时为条件可选参数。  参数含义：该参数用于指定HAFETCD网络亚健康探测报文发送间隔。  数据来源：本端规划  取值范围：整数类型，取值范围是1~300。  默认值：5。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST HAFEDETECT查询当前参数配置值。  配置原则：无                                                                                         |
| THRESHOLD      | 亚健康阈值(千分比)  | 可选必选说明：该参数在"SUBHEALTHSW"配置为"ON"时为条件可选参数。  参数含义：该参数用于指定HAFETCD网络亚健康探测报文丢错包阈值。当在一个统计周期内，丢错包数量与发送的报文总数量比值超出该阈值时，则认为被探测的网络链路异常。  数据来源：本端规划  取值范围：整数类型，取值范围是1~1000。  默认值：300。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST HAFEDETECT查询当前参数配置值。  配置原则：无                                      |
| LEASETHRESHOLD | 租约到期阈值(%)   | 可选必选说明：该参数在"SUBHEALTHSW"配置为"ON"时为条件可选参数。  参数含义：该参数用于指定SDRE容器与HAFETCD服务之间租约到期的阈值。当在一个统计周期内，租约到期的数量与统计周期开始时记录的租约总数量的比值超出该阈值时，则认为HAFETCD主节点与各个SDRE容器之间的链路存在异常。  数据来源：本端规划  取值范围：整数类型，取值范围是1~100，单位是百分比。  默认值：50。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST HAFEDETECT查询当前参数配置值。  配置原则：无 |
| STATISINTERVAL | 统计周期(s)     | 可选必选说明：该参数在"SUBHEALTHSW"配置为"ON"时为条件可选参数。  参数含义：该参数用于指定一个统计周期的时长。  数据来源：本端规划  取值范围：整数类型，取值范围是1~1800，单位是秒。  默认值：30。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST HAFEDETECT查询当前参数配置值。  配置原则：无                                                                                             |

## 使用实例

- 关闭HAFETCD网络亚健康探测功能。

  ```
  %%SET HAFEDETECT: SUBHEALTHSW=OFF;%%
  RETCODE = 0  操作成功

  ---    END
  ```
- 开启HAFETCD网络亚健康探测功能，并设置探测发包间隔为500毫秒，亚健康阈值为千分之三百，租约到期阈值为百分之五十，统计周期为30秒。

  ```
  %%SET HAFEDETECT: SUBHEALTHSW=ON, DETECTINTERVAL=5, THRESHOLD=300, LEASETHRESHOLD=50, STATISINTERVAL=30;%%
  RETCODE = 0  操作成功

  ---    END
  ```
