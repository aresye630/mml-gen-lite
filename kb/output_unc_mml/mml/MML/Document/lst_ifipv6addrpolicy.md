# 查询IPv6地址策略（LST IFIPV6ADDRPOLICY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询IPv6地址策略。

#### 注意事项

- 该命令执行后立即生效。
- 如果用户没有配置任何地址选择策略表项，执行该命令时系统只显示缺省策略表项，即显示::1、::、2002::、FC00::、::FFFF:0.0.0.0地址前缀的选择策略表项信息。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                             |
|:--------|:-------|:---------------------------------------------------------------------------------|
| VPNNAME | VPN实例名 | 可选必选说明：可选参数 参数含义：该参数用于指定IPv6地址策略的VPN实例名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 |

#### 使用实例

显示IPv6地址策略：

```
LST IFIPV6ADDRPOLICY:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
VPN实例名称 IPv6地址               IPv6地址前缀长度     目的地址优先级                  源地址优先级

_public_    ::1                    128                  50                               0
_public_    ::FFFF:0.0.0.0         96                   10                               4
_public_    2002::                 16                   30                               2
_public_    FC00::                 7                    20                               3
(结果个数 = 5)
---   END
```
