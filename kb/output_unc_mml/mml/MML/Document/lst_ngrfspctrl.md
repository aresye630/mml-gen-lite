# 查询指定RFSP的传递策略（LST NGRFSPCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于对指定的用户（群）查询指定RFSP的传递策略。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                          |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：可选参数  参数含义：该参数用于指定控制RFSP传递策略的用户范围。  数据来源：全网规划 取值范围： “ALL_USER（所有用户）”：所有用户。“HOME_USER（本网用户）”：本网用户。“FOREIGN_USER（外网用户）”：外网用户。“IMSI_PREFIX（IMSI前缀）”：IMSI前缀。“SPECIFIC_IMSI（指定IMSI）”：指定IMSI。  默认值：无  配置原则：无 |
| IMSIPRE  | IMSI前缀 | 可选必选说明：该参数在"SUBRANGE"配置为"IMSI_PREFIX"时为条件可选参数。  参数含义：该参数用于指定控制RFSP传递策略的用户的IMSI前缀。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是5~14。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                                          |
| IMSI     | IMSI   | 可选必选说明：该参数在"SUBRANGE"配置为"SPECIFIC_IMSI"时为条件可选参数。  参数含义：该参数用于指定控制RFSP传递策略的用户的IMSI。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是14~15。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                                         |
| RFSP     | RFSP   | 可选必选说明：可选参数  参数含义：该参数用于指定RFSP ID。  数据来源：全网规划  取值范围：整数类型，取值范围是1~256。  默认值：无  配置原则：无                                                                                                                            |

## 使用实例

查询指定IMSI前缀的记录，执行如下命令：

```
%%LST NGM2MPLCY: SUBRANGE=IMSI_PREFIX, IMSIPRE="12345";%%
RETCODE = 0  操作成功

结果如下
------------------------
        用户范围  =  IMSI前缀
        IMSI前缀  =  12345
            IMSI  =  NULL
 5GS之间是否传递  =  否
5GS到EPS是否传递  =  是
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称       | 输出项解释                              |
|:------------|:-----------------------------------|
| 用户范围        | 该参数用于指定控制RFSP传递策略的用户范围。            |
| IMSI前缀      | 该参数用于指定控制RFSP传递策略的用户的IMSI前缀。       |
| IMSI        | 该参数用于指定控制RFSP传递策略的用户的IMSI。         |
| RFSP        | 该参数用于指定RFSP ID。                    |
| 5GS之间是否传递   | 该参数用于控制指定的RFSP ID是否在5GS之间传递。       |
| 5GS到EPS是否传递 | 该参数用于控制指定的RFSP ID是否在5GS到EPS的流程中传递。 |
