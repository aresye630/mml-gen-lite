# 查询通用模块跟踪控制功能（LST COMMTRCCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF、SMF、SMSF、NCG**

该命令用于查询通用模块跟踪功能控制参数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询通用模块跟踪控制功能，执行如下命令：

```
%%LST COMMTRCCTRL:;%%
RETCODE = 0  操作成功

结果如下
------------------------
     E2E跟踪不上报开关  =  NULL
    接口跟踪不上报开关  =  NULL
    用户跟踪不上报开关  =  NULL
    随机跟踪不上报开关  =  NULL
上报跟踪流控的消息开关  =  OFF
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称       | 输出项解释                                                    |
|:------------|:---------------------------------------------------------|
| E2E跟踪不上报开关  | 该参数用于指定系统是否不上报E2E跟踪消息。                                   |
| 接口跟踪不上报开关   | 该参数用于指定系统是否不上报接口跟踪消息。                                    |
| 用户跟踪不上报开关   | 该参数用于指定系统是否不上报用户跟踪消息。                                    |
| 随机跟踪不上报开关   | 该参数用于指定系统是否不上报随机跟踪消息。                                    |
| 上报跟踪流控的消息开关 | 该参数用于指定TOPO、GTP-C、LOCM所在进程是否上报跟踪流控消息。当开关为OFF时，不上报跟踪流控消息。 |
