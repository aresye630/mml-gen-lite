# 增加APN相关服务区域（ADD APNAREA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于增加APN相关服务区域。服务区域通常是企业园区所处的区域。在服务区域内，根据用户位置可以做APN粒度相关特性控制。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入16000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称      | 参数说明                                                                                                                                              |
|:---------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
| AREANAME | APN相关服务区域 | 可选必选说明：必选参数  参数含义：该参数用于配置APN相关服务区域名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~255。不能为非法字符，只允许输入字母，数字、“_”、“.”，并且开头和结尾只能是数字或者字母，不能出现连续两个“.”。  默认值：无  配置原则：无 |
| AREATYPE | APN服务区域类型 | 可选必选说明：必选参数  参数含义：该参数用于配置APN服务区域类型。  数据来源：全网规划 取值范围： “N2TAI（5G类型的TAI）”：5G类型的TAI  默认值：无  配置原则：无                                                    |

## 使用实例

增加5G类型的TAI服务区域：

```
ADD APNAREA: AREANAME="dnnarea1", AREATYPE=N2TAI;
```
