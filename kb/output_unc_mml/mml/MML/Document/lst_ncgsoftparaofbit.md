# 查询NCG软件参数比特位（LST NCGSOFTPARAOFBIT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NCG**

该命令用于查询NCG软件参数，查询结果以二进制形式输出。同时，该命令也支持查询指定软件参数中某个比特位的值。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                          |
|:---------|:--------|:--------------------------------------------------------------------------------------------------------------|
| DT       | 数据类型    | 可选必选说明：必选参数  参数含义：该参数表示软件参数的数据类型。  数据来源：本端规划 取值范围： Dw（双字）Byte（字节）  默认值：无  配置原则：无                              |
| DWORDNUM | Dword索引 | 可选必选说明：该参数在"DT"配置为"Dw"时为条件可选参数。  参数含义：该参数表示Dword类型软件参数的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~10000。  默认值：无  配置原则：无 |
| POSITION | 比特位     | 可选必选说明：可选参数  参数含义：该参数表示软件参数比特位的位置。  数据来源：本端规划  取值范围：整数类型，取值范围是1~32。  默认值：无  配置原则：无                            |

## 使用实例

查询当前软参记录索引为1，比特位为1的双字类型软参的设置情况：

```
LST NCGSOFTPARAOFBIT: DT=Dw, DWORDNUM=1,POSITION=1;
RETCODE = 0  操作成功

结果如下
--------
    数据类型  =  双字
软参记录索引  =  1
      比特位  =  1
  软参记录值  =  1
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释            |
|:--------|:-----------------|
| 数据类型    | 该参数表示软件参数的数据类型。  |
| 软参记录索引  | 该参数表示软件参数的索引。    |
| 比特位     | 该参数表示软件参数比特位的位置。 |
| 软参记录值   | 该参数表示软件参数的值。     |
