# 查询S-GW DNS域名策略（LST SGWDNS）

- 命令功能

#### 命令功能

**适用网元：SGSN、MME**

该命令用于配置多PLMNID共享时查询S-GW的域名中PLMNID的组装策略。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                             |
|:-------|:-------|:-------------------------------------------------------------------------------------------------|
| DNTYPE | 域名类型   | 可选必选说明：可选参数 参数含义：该参数用于指定DNS域名类型。 取值范围： “RAI(RAI)”“TAI(TAI)” 默认值：无                                |
| LAC    | 位置区域码  | 可选必选说明：可选参数 参数含义：该参数用于指定位置区域码 前提条件：该参数在“DNTYPE(域名类型)”设置为“RAI(RAI)”时生效。 取值范围：0x0000～0xFFFF 默认值：无  |
| RAC    | 路由区域码  | 可选必选说明：可选参数 参数含义：该参数用于指定路由区域码 前提条件：该参数在“DNTYPE(域名类型)”设置为“RAI(RAI)”时生效。 取值范围：0x00～0xFF 默认值：无      |
| TAC    | 跟踪区域码  | 可选必选说明：可选参数 参数含义：该参数用于指定跟踪区域码 前提条件：该参数在“DNTYPE(域名类型)”设置为“TAI(TAI)”时生效。 取值范围：0x0000～0xFFFF 默认值 ：无 |

#### 使用实例

1. 不输入查询条件，查询表中全部DNS域名策略的信息：

   LST SGWDNS:;

   ```
   %%LST SGWDNS:;%%
   RETCODE = 0  操作成功。

   输出结果如下
   --------------
    域名类型  位置区域码  路由区域码  路由区域码范围  跟踪区域码  跟踪区域码范围  移动国家码  移动网号   描述

    TAI       0x0         0x0         0x0             0x1         0x5             111         222        NULL   
    RAI       0x0         0x5         0x5             0x0         0x0             123         03         NULL   
   (结果个数 = 2)

   ---    END
   ```
2. 查询一条跟踪区域码为“1”的DNS域名策略记录：

   LST SGWDNS: DNTYPE=TAI, TAC="0x1";

   ```
   %%LST SGWDNS: DNTYPE=TAI, TAC="0x1";%%
   RETCODE = 0  操作成功。

   输出结果如下
   --------------
         域名类型  =  TAI
       位置区域码  =  0x0
       路由区域码  =  0x0
   路由区域码范围  =  0x0
       跟踪区域码  =  0x1
   跟踪区域码范围  =  0x5
       移动国家码  =  111
         移动网号  =  222
             描述  =  NULL
   (结果个数 = 1)

   ---    END
   ```
