# 删除小区(RMV CELL)

#### 命令功能

**须知** 

删除小区将导致基于该小区的所有业务被中断，请谨慎操作。

**适用网元：SGSN**

此命令用于删除指定的小区。

#### 注意事项

- 删除小区将导致基于该小区的所有业务被中断，请谨慎操作。
- 删除方式包括：若只输入“NSEI”，则删除该NSE下所有的小区；若同时输入“NSEI”和“BVCI”，则删除NSEI和BVCI唯一确定的小区；若只输入“CELLID”，则删除该CELLID对应的小区。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                          |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------|
| NSEI   | NSE标识  | 可选必选说明：可选参数 参数含义：此参数用于表示网络服务实体标识。 取值范围：0～65535 默认值：无                                                                          |
| BVCI   | BVCI   | 可选必选说明：可选参数 参数含义：此参数用于表示小区的BSSGP虚连接标识。 取值范围：0～65535 默认值：无                                                                     |
| CELLID | 小区号    | 可选必选说明：可选参数 参数含义：此参数用于表示小区的标识。CELLID = MCC + MNC + LAC + RAC + CI。 取值范围：15~16位十六进制数 默认值：无  说明： 说明：如果输入了小区号，则不允许输入NSE标识或者BVCI。 |

#### 使用实例

删除NSEI为12003，BVCI为1201的小区：

RMV CELL: NSEI=12003, BVCI=1201;
