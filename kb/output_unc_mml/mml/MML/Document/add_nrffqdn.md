# 增加NRF的FQDN（ADD NRFFQDN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NSSF**

该命令用于增加NRF的FQDN。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入10000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                          |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INDEX  | 索引     | 可选必选说明：必选参数  参数含义：该参数用于描述命令的索引值。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无                                                                      |
| MCC    | 移动国家码  | 可选必选说明：必选参数  参数含义：该参数用于描述移动国家码。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。3位十进制数。  默认值：无  配置原则：无                                                                          |
| MNC    | 移动网号   | 可选必选说明：必选参数  参数含义：该参数用于描述移动网号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。2位或者3位十进制数。  默认值：无  配置原则：无                                                                   |
| SST    | 切片服务类型 | 可选必选说明：必选参数  参数含义：该参数用于描述切片服务类型。  数据来源：全网规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无                                                                             |
| SD     | 切片细分标识 | 可选必选说明：可选参数  参数含义：该参数用于表示切片细分标识。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。该参数只能由字母（A-F或者a-f）、数字（0-9）组成。  默认值：无  配置原则：无                                                   |
| FQDN   | FQDN   | 可选必选说明：必选参数  参数含义：该参数用于描述NRF的FQDN。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~255。该参数只能由字母（A-Z或者a-z）、数字（0-9）、连字符（-）和点（.）组成，大小写不敏感，FQDN不能以“.”开始，也不能以“.”结束。  默认值：无  配置原则：无 |
| DESC   | 描述     | 可选必选说明：可选参数  参数含义：该参数用于描述信息。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无                                                                              |

## 使用实例

假如运营商希望增加一条INDEX为1、MCC为"460"、MNC为"03"、SST为1、FQDN为"TAC-LB01.TAC-HB71.TAC.EPC.MNC001.MCC308.3GPPNETWORK.ORG"的记录，执行下列命令。

```
ADD NRFFQDN: INDEX=1, MCC="460", MNC="03", SST=1, FQDN="TAC-LB01.TAC-HB71.TAC.EPC.MNC001.MCC308.3GPPNETWORK.ORG";
```
