# 删除SMF功能实例信息（RMV SMFFUNCTION）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于删除SMF功能实例信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                |
|:-----------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INSTANCEID | NF实例号  | 可选必选说明：必选参数  参数含义：NF实例号。用于SMF与北向网管对接使用，通过NFInstance ID可以实现与北向网管上与网元的话统、告警信息的关联。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~40。  默认值：无  配置原则：  该参数需要根据北向网管的要求来填写，例如，填写为在MANO上创建VNF时的InstanceID。 |

## 使用实例

删除SMF功能实体号为Instanceid01,SMF功能实例信息：

```
RMV SMFFUNCTION: INSTANCEID="Instanceid01";
```
