#### 命令功能

**适用网元：SGSN、MME**

此命令用于查询CBC下SBc链路的连接状态。

#### 注意事项

- 该命令执行后立即生效。
- 如果不输入CBC索引号，则显示所有CBC下SBc链路的连接状态。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                          |
|:-------|:-------|:--------------------------------------------------------------|
| CBCIDX | CBC索引  | 可选必选说明：可选参数 参数含义：该参数用于指定待查询的CBC索引。 数据来源：本端规划 取值范围：0~127 默认值：无 |

#### 使用实例

输入CBC索引，查询指定的CBC数据：

DSP CBC: CBCIDX=0;

```
%%DSP CBC: CBCIDX=0;%%
RETCODE = 0  操作成功。

输出结果如下：
-------------------------

      进程号  =  6
      RU名称  =  USN_SP_RU_0064

    本地地址1  =  10.2.62.20
```

#### 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                   |
|:--------|:------------------------------------------------------------------------------------------------------------------------|
| CBC索引   | SBc链路的索引，该参数用来在系统范围内部唯一标识一条SBc链路。                                                                                       |
| 进程号     | SBc链路所在SGP进程的进程号。                                                                                                       |
| RU名称    | 查询所在的资源单元名称。                                                                                                            |
| IP地址类型  | SBc链路IP地址类型。                                                                                                            |
| 本地地址1   | SBc链路第一个本地IP地址。                                                                                                         |
| 本地地址2   | SBc链路第二个本地IP地址。                                                                                                         |
| 本地端口号   | SBc链路本地端口号。                                                                                                             |
| 对端地址1   | SBc链路第一个对端IP地址。                                                                                                         |
| 对端地址2   | SBc链路第二个对端IP地址。                                                                                                         |
| 对端端口号   | SBc链路对端端口号。                                                                                                             |
| VPN名称   | SBc链路的VPN名称。                                                                                                            |
| 链路状态    | 查询SBc链路状态的查询结果。 取值说明：“正常”：表示MME网元与CBC网元间之间的通信在该链路上正常。“故障”：表示MME网元与CBC网元间之间的通信在该链路上中断，需要检查网络状况，分析故障原因。详细操作参见SBc链路故障告警处理。 |
