# 删除NRF信息（RMV NRF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、NRF、NSSF、SMSF、NCG、CBCF**

该命令用于删除NRF实例的信息。

## 注意事项

- 该命令执行后立即生效。

- 如果NRF的信息被删除，NF与NRF之间的通信将中断。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称    | 参数说明                                                                                                                                                                                              |
|:----------------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NRFINSTANCENAME | NRF实例名称 | 可选必选说明：必选参数  参数含义：该参数用于指定NRF实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~38。  默认值：无  配置原则： 本参数的构成字符只能是字母A～Z或a～z、数字0～9和下划线"_"和中划线"-"，例如，NRF_Instance_0。不允许配置前18位字符与数据库中所有存储的非UUID格式的NRFINSTANCENAME的相同记录。 |

## 使用实例

需要删除名称为NRF\_Instance\_0的NRF的对应信息。

```
RMV NRF: NRFINSTANCENAME="NRF_Instance_0";
```
