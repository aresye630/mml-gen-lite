# 修改APN DNS域名策略(MOD APNDNS)

- 本地用户权限
- 网管用户权限

- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于修改APN DNS域名策略。

当选择上游网元GGSN/PGW时，需要根据APNNI和UE允许的接入能力确定使用.gprs后缀还是.org后缀组装APN域名。同时，DNS查询时，根据APNNI域名类型选择最多8个IP地址组成备选列表，进行负荷分担。当可用的IP地址权重少于阈值时，选择低优先级IP地址进行补充。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                |
|:----------|:-----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APNNI     | APN网络标识    | 可选必选说明：必选参数 参数含义：该参数用于指定APN网络标识。 数据来源：整网规划 取值范围：1～62位字符串 默认值：无 配置原则：参见命令ADD APNDNS。  说明： “APNNI”和“UEACCCAP”作为索引查找记录，不能修改。                                                                                                                                                                           |
| UEACCCAP  | UE接入能力     | 可选必选说明：必选参数 参数含义：该参数用于指定UE接入2/3/4G网络的能力。 数据来源：整网规划 取值范围：“GERAN/UTRAN_UE（GERAN/UTRAN UE）”“EUTRAN_UE(EUTRAN UE)”“GERAN/UTRAN/EUTRAN_UE(GERAN/UTRAN/EUTRAN UE)”“ALL_UE(ALL UE)” 默认值：无  说明： “APNNI”和“UEACCCAP”作为索引查找记录，不能修改。                                                                            |
| DNSPOLICY | DNS域名策略    | 可选必选说明：必选参数 参数含义：该参数用于指定使用的DNS后缀模式。.gprs或者.org。 数据来源：整网规划 取值范围：“GPRS(GPRS)”，“ORG(ORG)” 默认值：无 配置原则：如果用户使用的APN和UE能力匹配记录的前两个参数，则该参数决定域名所使用的后缀类型。GPRS（.gprs）：该参数用来指定使用的DNS后缀模式为.gprs。格式如：HUAWEI11.MNC003.MCC123.GPRSORG（.org）：该参数用来指定NRI域名格式为.org。格式如：HUAWEI1.COM.APN.EPC.MNC003.MCC123.3GPPNETWORK.ORG |
| SELPOLICY | 根据UE接入能力选择 | 可选必选说明：可选参数 参数含义：该参数用于指定GGSN/P-GW选择策略。 数据来源：整网规划 取值范围：“NO(NO)”“YES(YES)” 配置原则：参见命令ADD APNDNS。                                                                                                                                                                                                       |

#### 使用实例

修改“APN网络标识”为“huawei.com”， “根据UE接入能力选择”为“EUTRAN\_UE(EUTRAN UE)”的UE，“ DNS域名策略 ”“GPRS(GPRS)”

**MOD APNDNS: APNNI="huawei.com", UEACCCAP=EUTRAN\_UE, DNSPOLICY=GPRS;**
