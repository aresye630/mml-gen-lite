# 查询目标NF实例IP地址（LST TNFINSIP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF、SMF、NSSF、SMSF、NCG、CBC、CBCF**

该命令用于查询目标NF实例IP地址配置。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                       |
|:------------|:---------|:---------------------------------------------------------------------------------------------------------------------------|
| TNFINSINDEX | 目标NF实例索引 | 可选必选说明：可选参数  参数含义：本参数用于指定目标NF实例索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~2047。  默认值：无  配置原则：  本参数需要与ADD TNFINS命令中的TNFINSINDEX值保持一致。 |
| IPTYPE      | IP地址类型   | 可选必选说明：可选参数  参数含义：本参数用于指定IP地址类型。  数据来源：全网规划 取值范围： “IPV4（IPv4）”：IPv4“IPV6（IPv6）”：IPv6“NONEIP（无IP）”：无IP  默认值：无  配置原则：无       |

## 使用实例

运营商A需要查询索引1的目标NF实例的所有地址信息。

```
%%LST TNFINSIP: TNFINSINDEX=1:;%%
RETCODE = 0  操作成功

结果如下
--------
目标NF实例索引  =  1
    IP地址类型  =  IPv4
  IPV4类型地址  =  10.254.255.10
  IPV6类型地址  =  ::
        端口号  =  60
(结果个数 = 1)

---    END
```
