# 删除EPS签约QoS配置（RMV EPSSUBQOS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C**

该命令用来删除用户的签约QoS属性的相关配置。

## 注意事项

该命令执行后只对新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                             |
|:------------|:--------|:---------------------------------------------------------------------------------|
| SUBQOSINDEX | 用户QoS索引 | 可选必选说明：必选参数  参数含义：该参数表示用户QoS索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无 |

## 使用实例

删除“SUBQOSINDEX”为“123”的记录：

```
RMV EPSSUBQOS: SUBQOSINDEX=123;
```
