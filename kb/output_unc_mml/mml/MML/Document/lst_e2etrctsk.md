# 查询端到端跟踪任务（LST E2ETRCTSK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF、MME**

该命令用于查询端到端跟踪任务。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识         | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                                                          |
|:-------------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI         | IMSI       | 可选必选说明：可选参数  参数含义：该参数用于指定用户的IMSI。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是5~15。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                                                                                                                                                                                                                                          |
| TRCID        | 跟踪参考号      | 可选必选说明：可选参数  参数含义：该参数用于全局唯一标识一个跟踪任务，由MCC、MNC和Trace ID三部分组成。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是12~13。本参数的格式是<MCC><MNC>-<Trace ID>，其中MCC是3个十进制数字，MNC是2或3个十进制数字，Trace ID则是使用字符串表示的3字节长的十六进制数。比如MCC是123，MNC是45，Trace ID是100，那么本参数表示为12345-000064。  默认值：无  配置原则：无                                                                                                      |
| NGRAN        | NGRAN      | 可选必选说明：可选参数  参数含义：该参数用于指定NGRAN是否上报跟踪消息。  数据来源：全网规划 取值范围： “NORPT（不上报）”：不上报“RPT（上报）”：上报  默认值：无  配置原则：无                                                                                                                                                                                                                                                          |
| TRCINTERFACE | NGRAN接口    | 可选必选说明：可选参数  参数含义：该参数用于指定NGRAN上报跟踪消息的接口列表。  数据来源：全网规划 取值范围： “NGC（NGC）”：NGC“XNC（XN-C）”：XN-C“UU（Uu）”：Uu“F1C（F1-C）”：F1-C“E1（E1）”：E1  默认值：无  配置原则：无                                                                                                                                                                                                               |
| TRCDPTH      | 跟踪深度       | 可选必选说明：可选参数  参数含义：该参数用于指定网元上报跟踪消息的级别。  数据来源：全网规划  取值范围：整数类型，取值范围是0~5。  默认值：无  配置原则：  取值为0时，采用解码方式记录信令消息中的特定信元以及厂商特定扩展内容。  取值为1时，采用解码方式记录信令消息中的特定信元、无线测量信元以及厂商特定扩展内容。  取值为2时，采用编码方式完整记录整个信令消息以及厂商特定扩展内容。  取值为3时，采用解码方式记录信令消息中的特定信元。  取值为4时，采用解码方式记录信令消息中的特定信元和无线测量信元。  取值为5时，采用编码方式完整记录整个信令消息。  建议配置值为2，可确保完整记录所有信令消息，包括厂商特定扩展内容。其他取值可能导致部分消息无法被记录。实际以无线侧能力为准。 |
| ENB          | ENODEB     | 可选必选说明：可选参数  参数含义：该参数用于指定eNodeB是否上报跟踪消息。  数据来源：全网规划 取值范围： “NORPT（不上报）”：不上报“RPT（上报）”：上报  默认值：无  配置原则：无                                                                                                                                                                                                                                                         |
| ENBINTERFACE | eNodeB接口   | 可选必选说明：可选参数  参数含义：该参数用于指定eNodeB上报跟踪消息的接口列表。  数据来源：全网规划 取值范围： “S1MME（S1-MME）”：S1-MME“X2（X2）”：X2“UU（Uu）”：Uu  默认值：无  配置原则：无                                                                                                                                                                                                                                      |
| ENBTRCDPTH   | eNodeB跟踪深度 | 可选必选说明：可选参数  参数含义：该参数用于指定网元上报跟踪消息的级别。  数据来源：全网规划  取值范围：整数类型，取值范围是0~5。  默认值：无  配置原则：  取值为0时，采用解码方式记录信令消息中的特定信元以及厂商特定扩展内容。  取值为1时，采用解码方式记录信令消息中的特定信元、无线测量信元以及厂商特定扩展内容。  取值为2时，采用编码方式完整记录整个信令消息以及厂商特定扩展内容。  取值为3时，采用解码方式记录信令消息中的特定信元。  取值为4时，采用解码方式记录信令消息中的特定信元和无线测量信元。  取值为5时，采用编码方式完整记录整个信令消息。  建议配置值为2，可确保完整记录所有信令消息，包括厂商特定扩展内容。其他取值可能导致部分消息无法被记录。实际以无线侧能力为准。 |

## 使用实例

- 查询所有的端到端跟踪任务，执行如下命令：

  ```
  %%LST E2ETRCTSK:;%%
  RETCODE = 0  操作成功

  结果如下
  --------
                  IMSI  =  123030912121001
            跟踪参考号  =  12345-000064
                 NGRAN  =  上报
             NGRAN接口  =  NGC&XN-C&Uu&F1-C&E1
              跟踪深度  =  1
                ENODEB  =  上报
            eNODEB接口  =  S1-MME&X2&Uu
        eNodeB跟踪深度  =  1
  跟踪任务有效时长(天)  =  1
      跟踪任务生效日期  =  2021-12-06 15:42:35
  (结果个数 = 1)

  ---    END
  ```
- 查询“IMSI”为“123030912121002”且“跟踪参考号”为“12345-000065”的端到端跟踪任务，执行如下命令：

  ```
  %%LST E2ETRCTSK: IMSI="123030912121002", TRCID="12345-000065";%%
  RETCODE = 0  操作成功

  结果如下
  --------
                  IMSI  =  123030912121002
            跟踪参考号  =  12345-000065
                 NGRAN  =  上报
             NGRAN接口  =  NGC
              跟踪深度  =  1
                ENODEB  =  上报
            eNODEB接口  =  S1-MME
        eNodeB跟踪深度  =  1
  跟踪任务有效时长(天)  =  1
      跟踪任务生效日期  =  2021-12-06 15:42:35
  (结果个数 = 1)

  ---    END
  ```

## 输出结果说明

| 输出项名称       | 输出项解释                                         |
|:------------|:----------------------------------------------|
| IMSI        | 该参数用于指定用户的IMSI。                               |
| 跟踪参考号       | 该参数用于全局唯一标识一个跟踪任务，由MCC、MNC和Trace ID三部分组成。     |
| NGRAN       | 该参数用于指定NGRAN是否上报跟踪消息。                         |
| NGRAN接口     | 该参数用于指定NGRAN上报跟踪消息的接口列表。                      |
| 跟踪深度        | 该参数用于指定网元上报跟踪消息的级别。                           |
| ENODEB      | 该参数用于指定eNodeB是否上报跟踪消息。                        |
| eNodeB接口    | 该参数用于指定eNodeB上报跟踪消息的接口列表。                     |
| eNodeB跟踪深度  | 该参数用于指定网元上报跟踪消息的级别。                           |
| 跟踪任务有效时长(天) | 该参数用于指定跟踪任务的有效时长。跟踪任务累计生效天数大于此参数设置的值时则跟踪任务失效。 |
| 跟踪任务生效日期    | 该参数用于指定跟踪任务的生效日期。                             |
