# 删除ADC参数（RMV ADCPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于删除ADC参数。当运营商希望删除指定ADC应用的流信息上报开关和重定向信息时，则执行该命令。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                             |
|:---------------|:-------|:-------------------------------------------------------------------------------------------------|
| FLOWFILTERNAME | 流过滤器名称 | 可选必选说明：必选参数 参数含义：该参数用于设置应用对应的流过滤器名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

假设运营商不希望ADC应用对应的流过滤器名称为testflowfiltername的应用进行流信息上报，可以执行该命令：

```
RMV ADCPARA:FLOWFILTERNAME="testflowfiltername";
```
