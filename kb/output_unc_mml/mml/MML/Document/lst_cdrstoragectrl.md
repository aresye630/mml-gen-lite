# 查询话单存储控制参数（LST CDRSTORAGECTRL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

命令用来查看配置的缓存话单文件的有效期。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询缓存话单文件的超期时间信息：

```
LST CDRSTORAGECTRL:;
```

```
RETCODE = 0  操作成功。

话单存储控制参数
----------------
话单缓存超期天数  =  3
话单缓存超期周数  =  1
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见SET CDRSTORAGECTRL的参数说明。
