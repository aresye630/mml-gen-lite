# 删除LAI与VLR号对应关系(RMV LAIVLR)

#### 命令功能

**须知** 

删除LAI与VLR的对应关系后，MME将无法找到该LAI所对应的MSC/VLR，CSFallback功能将失效。

**适用网元：SGSN、MME**

该命令用于删除LAI与VLR的对应关系。

#### 注意事项

- 该命令执行后立即生效。
- 删除LAI与VLR的对应关系后，MME将无法找到该LAI所对应的MSC/VLR，CSFallback功能将失效。
- LAI和VLR号至少要输入一个。
- 删除LAI与VLR的对应关系时，要确保待删除的LAI区间里的所有LAI均没有被命令**ADD TAILAI**配置，否则不允许删除。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                        |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
| BGNLAI | LAI    | 可选必选说明：可选参数 参数说明：该参数用于指定位置区标识，标识一个位置区，由“MCC”、“MNC”和“LAC”组成。 数据来源：整网规划 取值范围：9~10位字符串 默认值：无 配置原则： “MCC”由3个阿拉伯数字组成，“MNC”由2到3个阿拉伯数字组成。LAC编码为16进制数，固定为4位，不足前面补0。 |
| VLRNO  | VLR号   | 可选必选说明：可选参数 参数说明：该参数用于指定标识一个VLR。 数据来源：整网规划 取值范围： 1～15位十进制数字 默认值：无 配置原则： “LAI”和“VLR号”至少要输入一个。如果只输入“VLR号”，该命令会删除所有与此VLR号相关的LAI与VLR号对应关系的记录。                   |

#### 使用实例

1. 删除起始LAI号为"1000009999"的LAI区间与VLR号对应关系：

   输入的起始LAI为"1000009999"，VLR号不输入。

   RMV LAIVLR: BGNLAI="1000009999";
2. 删除VLR号为"100000000000100"所对应的所有LAI的对应关系：

   不输入起始LAI，输入VLR号为"100000000000100"。

   RMV LAIVLR: VLRNO="100000000000100";
