# 设置5G缺省NI策略（SET NGDFTNIPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于配置AMF的缺省NI（Network Identity）策略。

应用场景为：运营商希望配置的缺省NI不对所有UE下发，而是通过用户特征（如是否签约特定DNN）决策是否向UE下发，可以通过该命令实现。

## 注意事项

- 该命令执行后立即生效。

- 当存在以下场景时，本功能无法生效：
- （1）本功能中使用的DNN在系统中未配置但存在SMF选择签约数据（SNSSAIINFOS）DNN名称取值为通配符（\*）的ADD UDMBYPASSSUB配置记录；
- （2）本功能中使用的DNN未在UDM上签约但签约数据中存在通配符（\*）的DNN。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| AMFDNNSW   | AMFDFTNI                         | UDMBYPASSDNN   | NIPAGINGSW   |
|:-----------|:---------------------------------|:---------------|:-------------|
| OFF        | NGMNO-1&NITZPLCY-1&AMFPLCYFUNC-1 | NO             | OFF          |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称            | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
|:-------------|:----------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AMFDNNSW     | 基于DNN下发缺省NI功能开关 | 可选必选说明：可选参数  参数含义：该参数用于控制AMF是否支持基于特定DNN关键字下发缺省NI功能。当本参数设置为"ON"时，AMF会根据配置的特定DNN关键字（ADD DFTNIDNN配置）匹配用户签约的DNN来判断是否向用户下发缺省NI；如果DNN匹配不成功，AMF不下发缺省NI。  数据来源：全网规划 取值范围： “OFF（关闭）”：关闭“ON（开启）”：开启  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST NGDFTNIPLCY查询当前参数配置值。  配置原则：无                                                                                                                                                                                                                                                                                                                                                |
| AMFDFTNI     | 缺省NI取值策略        | 可选必选说明：该参数在"AMFDNNSW"配置为"ON"时为条件可选参数。  参数含义：该参数用于控制AMF缺省NI下发策略。 对于勾选的缺省NI下发时，AMF会根据配置的特定DNN关键字（ADD DFTNIDNN配置）匹配用户签约的DNN来判断是否向用户下发缺省NI；如果DNN匹配成功，AMF下发缺省NI。 对于未勾选的缺省NI下发时，不考虑用户是否签约特定DNN，默认下发缺省NI。 说明： 在开启基于PCF的动态NI功能的场景下，当PCF取消动态NI时，网络侧下发的缺省NI取值优先级如下：SET AMFPLCYFUNC>ADD NITZPLCY>ADD NGMNO; 在未开启基于PCF的动态NI功能的场景下，网络侧下发的缺省NI取值优先级如下：ADD NITZPLCY>ADD NGMNO。  数据来源：全网规划  取值范围：如果全部不勾选，相当于“基于DNN下发缺省NI功能”未开启。 “NGMNO（NGMNO）”：ADD NGMNO配置的默认NI“NITZPLCY（NITZPLCY）”：ADD NITZPLCY配置的默认NI“AMFPLCYFUNC（AMFPLCYFUNC）”：SET AMFPLCYFUNC配置的默认NI  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST NGDFTNIPLCY查询当前参数配置值。  配置原则：无 |
| UDMBYPASSDNN | 是否使用最小签约数据      | 可选必选说明：该参数在"AMFDNNSW"配置为"ON"时为条件可选参数。  参数含义：该参数用于控制是否使用最小签约数据（ADD UDMBYPASSSUB中SNSSAIINFOS参数）进行DNN关键字匹配。 当用户进入UDM BYPASS状态后，由于无法获取用户真实的签约数据，在开启“基于DNN下发缺省NI功能开关”时，DNN会匹配失败，用户始终不下发缺省NI，该参数用于控制是否使用最小签约数据替代真实签约数据进行DNN匹配。  数据来源：全网规划 取值范围： “YES（是）”：是“NO（否）”：否  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST NGDFTNIPLCY查询当前参数配置值。  配置原则：  该开关开启时，需要ADD UDMBYPASSSUB中SNSSAIINFOS参数配合进行，建议只针对特定VIP用户配置特殊的最小签约数据。                                                                                                                                                                                                       |
| NIPAGINGSW   | 空闲态用户寻呼开关       | 可选必选说明：可选参数  参数含义：该参数用于控制UDM签约数据变更DNN与DFTNIDNN匹配，且AMF开启基于DNN下发缺省UELogo时是否立即寻呼空闲态用户。 当本参数设置为"ON"时，AMF立即寻呼UE并通过Configuration Update Command消息通知UE缺省UELogo，否则AMF待后续移动管理流程通知UE。  数据来源：全网规划 取值范围： “OFF（关闭）”：关闭“ON（开启）”：开启  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST NGDFTNIPLCY查询当前参数配置值。  配置原则：  UDM签约数据变更DNN匹配DFTNIDNN，受SET NGDFTNIPLCY或ADD NGDFTNIIMSI控制需要下发缺省UELogo时，是否寻呼空闲态用户均受本参数控制。                                                                                                                                                                                                                            |

## 使用实例

运营商希望AMF能根据用户签约DNN是否含关键字“NeedDefaultUElogo”来控制下发默认NI，并且指定默认NI的范围为ADD NGMNO、ADD NITZPLCY、SET AMFPLCYFUNC配置的NI。

```
SET NGDFTNIPLCY: AMFDNNSW=ON, AMFDFTNI=AMFPLCYFUNC-1&NITZPLCY-1&NGMNO-1,UDMBYPASSDNN=NO;
ADD DFTNIDNN: DNNKEYWD="NeedDefaultUElogo";
```
