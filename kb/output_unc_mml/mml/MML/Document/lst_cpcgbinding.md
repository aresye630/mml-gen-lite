# 显示抄送CG绑定（LST CPCGBINDING）

#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

该命令用来显示UNC上已配置的抄送CG组信息。用户可以选择显示指定的抄送CG组信息，也可以显示所有已配置的抄送CG组信息。

#### 注意事项

当前版本不支持此命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                     |
|:----------|:--------|:-------------------------------------------------------------------------|
| CPCGGRPID | 抄送CG组ID | 可选必选说明：可选参数 参数含义：指定抄送CG组ID。 数据来源：本端规划 取值范围：整数类型，取值范围为1。整数1。 默认值：无 配置原则：无 |

#### 使用实例

查询抄送CG绑定关系，命令为：

```
LST CPCGBINDING:;
```

