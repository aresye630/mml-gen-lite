# 设置SCTP发送缓冲区参数(SET SCTPTXBUFFER)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限

- 使用实例

#### 命令功能

**适用NF：SGSN、MME、AMF**

该命令用于设置系统中SCTP发送端缓冲区参数。

#### 注意事项

- 该命令执行后需要重启SGP进程才能生效。
- 该命令会影响SCTP内存分布。
- 该命令可以分别设置共享模式、私有模式下的发送端缓冲区参数。
- 该命令配置的参数仅在SET SCTPBUFFCFG的参数源类型设置为自定义时才会生效。正常情况下，系统内置参数保证业务正常。如果使用自定义参数请联系华为。

#### 本地用户权限

manage-ug;system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                                                                                                                                                                               |
|:------------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MODE        | 模式选项       | 可选必选说明：必选参数 参数含义：该参数用于区分共享模式、私有模式下的参数配置。 数据来源：本端规划 取值范围：枚举类型 SHARE（共享模式）PRIVATE（私有模式） 系统初始设置值：无 配置原则： 在SET SCTPBUFFCFG的参数源类型设置为自定义，且SET SCTPBUFFERMODE中发送缓冲区模式为共享模式时，SHARE对应的参数将生效。在SET SCTPBUFFCFG的参数源类型设置为自定义，且SET SCTPBUFFERMODE中发送缓冲区模式为私有模式时，PRIVATE对应的参数将生效。 |
| MINTXSIZE   | 迷你端私有缓冲区大小 | 可选必选说明：可选参数 参数含义： 在共享模式下，该参数表示迷你端缓冲区发送缓冲区的总大小。在私有模式下，该参数表示迷你端缓冲区私有发送缓冲区的大小。 数据来源：本端规划 取值范围：整数类型，取值范围为1~70000。 系统初始设置值： 共享模式：20000私有模式：70000 配置原则：不建议超过70000。                                                                                                       |
| MINEXTXSIZE | 迷你端共享缓冲区大小 | 可选必选说明：可选参数 参数含义： 在共享模式下，该参数表示迷你端缓冲区自有缓冲区的总大小。在私有模式下，该参数不生效。 数据来源：本端规划 取值范围：整数类型，取值范围为1~70000。 系统初始设置值： 共享模式：50000 配置原则： 不建议超过50000。                                                                                                                               |
| MINEXTXNUM  | 迷你端共享缓冲区个数 | 可选必选说明：可选参数 参数含义： 在共享模式下，该参数表示迷你端共享缓冲区个数。在私有模式下，该参数不生效。 数据来源：本端规划 取值范围：整数类型，取值范围为1~3000。 系统初始设置值： 共享模式：600 配置原则：不建议超过600。                                                                                                                                          |

#### 使用实例

设置共享模式下的发送缓冲区参数，指定迷你端私有缓冲区大小为100、迷你端共享缓冲区大小为2048字节、迷你端共享缓冲区个数为30：

```
SET SCTPTXBUFFER: MODE=SHARE, MINTXSIZE=100, MINEXTXSIZE=2048, MINEXTXNUM=30;
```
