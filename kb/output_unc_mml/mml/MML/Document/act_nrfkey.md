# 激活NRF密钥（ACT NRFKEY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

执行该命令会使原来使用的密钥失效。

**适用NF：NRF**

该命令用于激活NRF的密钥信息。密钥信息需要先通过ADD NRFKEY配置，然后使用此命令激活才能生效。

## 注意事项

- 该命令执行后立即生效。

- 主备或双活组网的场景下，如果需要配置此命令，则两个NRF上均需执行此命令，且配置参数一致。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                      |
|:--------|:-------|:------------------------------------------------------------------------------------------|
| KEYNAME | 密钥名称   | 可选必选说明：必选参数  参数含义：该参数用于表示在NRF上配置的密钥名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。  默认值：无  配置原则：无 |

## 使用实例

激活密钥名称为keyname001的NRF密钥：

```
ACT NRFKEY: KEYNAME="keyname001";
```
