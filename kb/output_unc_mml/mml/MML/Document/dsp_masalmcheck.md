# 显示5G告警核查状态（DSP MASALMCHECK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询系统当前的告警核查状态。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                            |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ALMTYPE | 告警类型   | 可选必选说明：可选参数  参数含义：该参数用于指定告警类型。  数据来源：本端规划 取值范围： “HTTP_LINKDOWN（HTTP链路故障）”：表示ALM-100155 HTTP链路故障告警，对应的批量告警为ALM-100311 批量HTTP链路故障。“SUMMARY（汇总）”：表示批量告警的汇总信息。  默认值：SUMMARY  配置原则：无 |

## 使用实例

查询告警核查：

```
%%DSP MASALMCHECK: ALMTYPE=HTTP_LINKDOWN;%%
RETCODE = 0  操作成功

结果如下
--------
告警名称  =  HTTP链路故障
核查类型  =  无
核查状态  =  空闲
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                   |
|:--------|:--------------------------------------------------------------------------------------------------------|
| 告警名称    | 产生批量告警的原始告警的名称。 取值说明： “HTTP_LINKDOWN（HTTP链路故障）”：表示ALM-100155 HTTP链路故障告警，对应的批量告警为ALM-100311 批量HTTP链路故障。  |
| 核查类型    | 该参数用于输出核查类型。 取值说明： “AUTO（自动）”：当前的核查是系统自动运行的。“MANUAL（手动）”：当前的核查是通过STR MASALMCHECK命令触发的。“NO（无）”：当前没有核查任务。 |
| 核查状态    | 该参数用于输出核查状态。 取值说明： “CHECKING（正在核查）”：当前正在运行核查任务。“IDLE（空闲）”：当前没有核查任务。                                     |
