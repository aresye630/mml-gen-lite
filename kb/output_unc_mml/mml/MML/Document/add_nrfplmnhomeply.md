# 增加指定拜访地PLMN的归属地策略（ADD NRFPLMNHOMEPLY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于增加NRF作为归属地NRF时对指定拜访地PLMN的跨PLMN交互处理策略。

## 注意事项

- 该命令执行后立即生效。

- 若对某拜访地PLMN没有配置本命令中的策略，以SET NRFHOMEPLY配置的默认策略为准。

- 最多可输入1024条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
|:------------|:------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MCC         | 移动国家码       | 可选必选说明：必选参数  参数含义：该参数用于表示拜访地PLMN的移动国家码。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| MNC         | 移动网号        | 可选必选说明：必选参数  参数含义：该参数用于表示拜访地PLMN的移动网号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| INTERSUBSW  | 是否支持跨PLMN订阅 | 可选必选说明：可选参数  参数含义：该参数用于表示本NRF作为归属地NRF时，是否处理指定的拜访地PLMN的NF发起的对本PLMN内的NF订阅以及订阅更新请求。开关为FUNC_ON表示处理，开关为FUNC_OFF表示不处理，并返回403错误码。订阅更新请求仅最终处理的NRF会按照此开关进行控制，中间层NRF仅做透传处理。  数据来源：全网规划 取值范围： “FUNC_ON（打开）”：功能开关打开“FUNC_OFF（关闭）”：功能开关关闭  默认值：FUNC_ON  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                     |
| INFOHIDEPLY | 信息精简策略      | 可选必选说明：必选参数  参数含义：该参数用于表示NRF作为归属地NRF时，对于收到指定的拜访地PLMN的跨PLMN服务发现和通知中精简的NF Profile字段信息。 选择某一项表示该项被精简，不在消息中携带，不选择表示不精简。  数据来源：本端规划 取值范围： IP（IP）SERVINGSCOPE（servingScope）LOCALITY（locality）NFINFO（nfinfo）PORT（port）  默认值：无  配置原则：  如果选择IP和PORT，NF Profile不携带ipv4Addresses、ipv6Addresses 、NFService中ipEndPoints。  如果选择IP，未选择PORT，NF Profile将不携带ipv4Addresses、ipv6Addresses，NFService会携带ipEndPoints，但不携带ipEndPoints中ipv4Addresses、ipv6Addresses。  如果未选择IP，则不能选择PORT。  如果选择locality，NF Profile不携带locality。  如果选择servingScope，NF Profile中不携带servingScope。  如果选择nfInfo，针对supi号段、gpsi号段、dnn列表、tai列表等这些量比较大的信元，则采取以下策略：  对于服务发现，只携带匹配上的信元信息，对于通知，只保留这些信元数组的第一个值。 |

## 使用实例

新增一条指定拜访地PLMN的归属地策略，移动国家码为460，移动网号为03，支持跨PLMN订阅，信息精简策略选择IP。

```
ADD NRFPLMNHOMEPLY: MCC="466", MNC="03", INTERSUBSW=FUNC_ON, INFOHIDEPLY=IP-1&SERVINGSCOPE-0&LOCALITY-0&NFINFO-0;
```
