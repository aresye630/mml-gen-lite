# 修改CBC(MOD CBC)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

此命令用于修改CBC（Cell Broadcast Center）配置。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug;system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

修改一个CBC配置：该CBC索引号为0，地址类型为IPv4，IP1改为10.10.10.17，IP2为10.10.10.18。

`MOD CBC: CBCIDX=0, IPTYPE=IPV4, IPV4_1="10.10.10.17", IPV4_2="10.10.10.18";`
