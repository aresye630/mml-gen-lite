#### 命令功能

**适用网元：SGSN、MME**

此命令用于查询IMEI库记录。IMEI库为IMEI TAC和终端类型的对应关系表，用于按照IMEI识别智能终端。

#### 注意事项

此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|:--------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SELMODE | 选择方式     | 可选必选说明：可选参数 参数含义：该参数用于指定选择查询IMEI库记录的方式。 取值范围：“IMEI_TAC(设备型号核准号码)”“UE_TYPE(终端类型)”“ALL(所有)” 默认值：无                                                                                                                                                                                                                                                                                                                                                                |
| IMEITAC | 设备型号核准号码 | 可选必选说明：条件必选参数 参数含义：该参数用于指定查询IMEI库记录的设备型号核准号码。 前提条件：当“选择方式”配置为“IMEI_TAC(设备型号核准号码)”时，此参数才生效。 取值范围：8~15位十进制数 默认值：无                                                                                                                                                                                                                                                                                                                                                |
| UETYPE  | 终端类型     | 可选必选说明：条件必选参数 参数含义：该参数用于指定查询IMEI库记录的终端类型。 前提条件：当“选择方式”配置为“UE_TYPE(终端类型)”时，此参数才生效。 取值范围：“ANDROID(Android)”“BLACKBERRY(Black Berry)”“IOS(iOS)”“WINDOWS(Windows)”“CUSTOM_TYPE_1(自定义类型1)”“CUSTOM_TYPE_2(自定义类型2)”“CUSTOM_TYPE_3(自定义类型3)”“CUSTOM_TYPE_4(自定义类型4)”“CUSTOM_TYPE_5(自定义类型5)”“CUSTOM_TYPE_6(自定义类型6)”“CUSTOM_TYPE_7(自定义类型7)”“CUSTOM_TYPE_8(自定义类型8)”“CUSTOM_TYPE_9(自定义类型9)”“CUSTOM_TYPE_10(自定义类型10)”“CUSTOM_TYPE_11(自定义类型11)”“CUSTOM_TYPE_12(自定义类型12)” 默认值：无 |

#### 使用实例

查询所有IMEI库记录：

LST IMEILIB: SELMODE=ALL;

```
%%LST IMEILIB: SELMODE=ALL;%%
RETCODE = 0  操作成功。
```
