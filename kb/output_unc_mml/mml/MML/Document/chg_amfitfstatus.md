# 更改系统接口状态（CHG AMFITFSTATUS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

主备AMF间数据同步未完成打开系统接口可能会影响已经注册到O-AMF的用户在AMF切换后的移动性注册、业务请求等业务流程。

关闭系统接口会导致所有业务无法处理。

**适用NF：AMF**

该命令用于更改系统接口状态。

在热备容灾链路长时间故障且基站全断链再恢复场景下，通过本命令可以手动开启系统接口，防止系统接口长时间故障，影响用户业务。通过DSP AMFSYSITFINFO命令可以查询系统接口状态。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                                                                                              |
|:---------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SBIITFSW | 服务化接口开关 | 可选必选说明：可选参数  参数含义：该参数用于设置服务化接口状态。 当本参数设置为“ON（开启）”，打开AMF网元服务化接口，周边网元(如UDM、PCF、SMSF等)与AMF可通过服务化接口正常交互。 当本参数设置为“OFF（关闭）”，闭塞AMF网元服务化接口，周边网元(如UDM、PCF、SMSF等)无法通过服务化接口与AMF交互。  数据来源：本端规划 取值范围： “NULL（无效）”：开关状态无变更“OFF（关闭）”：关闭“ON（打开）”：打开  默认值：无  配置原则：无 |
| N2ITFSW  | N2接口开关  | 可选必选说明：可选参数  参数含义：该参数用于设置N2接口状态。 当本参数设置为“ON（开启）”，打开N2接口，正常处理基站上行建链消息。 当本参数设置为“OFF（关闭）”，闭塞N2接口，丢弃基站上行建链消息。  数据来源：本端规划 取值范围： “NULL（无效）”：开关状态无变更“OFF（关闭）”：关闭“ON（打开）”：打开  默认值：无  配置原则：无                                                               |
| N26ITFSW | N26接口开关 | 可选必选说明：可选参数  参数含义：该参数用于设置N26接口状态。 本参数为预留参数，功能暂未实现。  数据来源：本端规划 取值范围： “NULL（无效）”：开关状态无变更“OFF（关闭）”：关闭“ON（打开）”：打开  默认值：无  配置原则：无                                                                                                                      |

## 使用实例

开启SBI、N2系统接口，执行如下命令：

```
CHG AMFITFSTATUS:SBIITFSW=ON,N2ITFSW=ON;
```
