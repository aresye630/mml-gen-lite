#### 命令功能

**适用网元：SGSN、MME**

该命令用以查询USN\_VNFC业务进程上扩展VNFC插件的调试信息。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                       |
|:------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RU          | RU名称   | 可选必选说明：必选参数。 参数含义：该参数表示USN_VNFC上待查询的RU的名称。 数据来源：本端规划。 取值范围：0~63位字符串。 默认值：无。                                                                                                                |
| PROCTYPE    | 进程类型   | 可选必选说明：必选参数。 参数含义：该参数表示USN_VNFC上待查询的进程类型。 数据来源：本端规划。 取值范围：“SPP(SPP) ”“UPP(UPP) ” 默认值：无。                                                                                                    |
| PROCNO      | 进程号    | 可选必选说明：必选参数。 参数含义：该参数表示USN_VNFC上待查询的进程编号。 数据来源：本端规划。 取值范围：0~20。 默认值：无。                                                                                                                     |
| QUERYTYPE   | 查询类型   | 可选必选说明：必选参数。 参数含义：该参数表示待查询的调试信息类型。 数据来源：本端规划。 取值范围：“KEY(KEY信息)”“TOPO(拓扑信息)”“COUNT(计数信息)” 默认值：无                                                                                             |
| SERVICETYPE | 服务名称   | 可选必选说明：必选参数。 此参数用于指定待查询的服务名称，可以通过LST VNFC命令查询得到。 数据来源：本端规划。 取值范围：字符串类型，输入长度范围为1～31。数字“0~9”，大写字母“A~Z”，小写字母“a~z”，特殊字符“-”，“_”，其他均为非法字符，并且首字符必须为字母。 默认值：无 配置原则：SERVICETYPE需要填写LINK、USN或者GB的名称。 |

#### 使用实例

当需要查询USN\_SP\_RU\_0066上0号SPP进程的KEY信息时，可以使用如下命令：

```
DSP TTPLUGDBGINFO: RU="USN_SP_RU_0066", PROCTYPE=SPP, PROCNO=0, QUERYTYPE=KEY, SERVICETYPE="USN_VNFC";
```
