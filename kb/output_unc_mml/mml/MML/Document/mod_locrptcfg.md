# 修改位置上报配置信息(MOD LOCRPTCFG)

- 命令功能
- 注意事项
- 本地用户权限

- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于修改位置上报配置信息。

#### 注意事项

- 该命令执行后对修改配置前的上报任务不影响。
- 该表的最大元组数为1024。
- 该命令部分参数与相关特性license共同完成该特性的开启，请在设置参数前使用**DSP LICENSE**命令确认对应特性license是否得到授权，执行**LST LICENSESWITCH**命令确认特性开关状态为“ENABLE(打开)”，具体相关特性请参考参数的说明。
- 当P-GW的信令面地址为双栈时，优先匹配IPv4的记录，再匹配IPv6的记录。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称                | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:-------|:--------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RANGE  | 对端设备范围              | 可选必选说明：必选参数 参数含义：该参数用于指定需要位置上报配置信息的对端设备GGSN/P-GW范围。 数据来源：整网规划 取值范围：“ALL_GGSN/P-GW（所有GGSN/P-GW）”“HOME_GGSN/P-GW（本网GGSN/P-GW）”“FOREIGN_GGSN/P-GW（外网GGSN/P-GW）”“SPECIFIC_GGSN/P-GW（指定IP的GGSN/P-GW）” 默认值： 无 配置原则：系统中只能配置一条“ALL_GGSN/P-GW（所有GGSN/P-GW）”的记录。当系统中已存在一条“ALL_GGSN/P-GW（所有GGSN/P-GW）”的记录时，如果再增加一条“ALL_GGSN/P-GW（所有GGSN/P-GW）”的记录，新记录会将旧记录覆盖。系统中只能配置一条“HOME_GGSN/P-GW（本网GGSN/P-GW）”的记录。当系统中已存在一条“HOME_GGSN/P-GW（本网GGSN/P-GW）”的记录时，如果在客户端再增加一条“HOME_GGSN/P-GW（本网GGSN/P-GW）”的记录，新记录将添加失败。系统中只能配置一条“FOREIGN_GGSN/P-GW（外网GGSN/P-GW）”的记录。当系统中已存在一条“FOREIGN_GGSN/P-GW（外网GGSN/P-GW）”的记录时，如果在客户端再增加一条“FOREIGN_GGSN/P-GW（外网GGSN/P-GW）”的记录，新记录将添加失败。系统中可以配置多条“SPECIFIC_GGSN/P-GW（指定IP的GGSN/P-GW）”的记录，但是IP网段区间不能重叠。优先级关系：“SPECIFIC_GGSN/P-GW（指定IP的GGSN/P-GW）” >“HOME_GGSN/P-GW（本网GGSN/P-GW）” = “FOREIGN_GGSN/P-GW（外网GGSN/P-GW）” > “ALL_GGSN/P-GW（所有GGSN/P-GW）”。 |

#### 使用实例

修改记录，修改用户范围为“SPECIFIC\_GGSN/P-GW（指定IP的GGSN/P-GW）”，信令面IP地址为“10.10.10.18”，掩码为“255.255.255.255”的记录，将其修改成不支持实时上报，描述为“GGSN01”：

MOD LOCRPTCFG: RANGE=SPECIFIC\_GGSN/P-GW, IPT=IPV4, GWIPV4="10.10.10.18", MASKV4="255.255.255.255", LOCRPT=NO, DESC="GGSN01";
