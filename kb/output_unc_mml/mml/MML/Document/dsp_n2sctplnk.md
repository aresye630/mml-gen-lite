# 查询N2接口SCTP链路状态(DSP N2SCTPLNK)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：AMF**

此命令用于查询N2接口SCTP链路状态。

#### 注意事项

此命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识           | 参数名称             | 参数说明                                                                                                                                                                                                                                 |

#### 使用实例

查询所有N2接口SCTP链路状态，输出类型为统计信息，可以用如下命令：

DSP N2SCTPLNK: OUTPUTTYPE=SUMMARY;

```
%%DSP N2SCTPLNK: OUTPUTTYPE=SUMMARY;%%
RETCODE = 0  操作成功

操作结果如下
------------
        总的N2 SCTP链路数 = 1
     正常的N2 SCTP链路数  = 1
     故障的N2 SCTP链路数  = 1
    接入中的N2 SCTP链路数 = 1
(结果个数 = 1)

---    END
```

查询N2接口SCTP链路状态，输出类型为报告输出，RU名称为LINK\_SP\_RU\_0064，进程类型为SGP，进程号为0，可以用如下命令：

DSP N2SCTPLNK: OUTPUTTYPE=SCREEN, RUNAME="LINK\_SP\_RU\_0064", PROCTYPE=SGP, PROCID=0;


| 接入中的N2 SCTP链路数   | 查询出的N2 SCTP链路状态接入中的链路数。                                                                                             |
