# 查询ServingPlmn映射功能（LST SRVPLMNMAPFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF、MME**

该命令用于查询Serving PLMN映射功能。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询Serving PLMN映射功能参数：

```
%%LST SRVPLMNMAPFUNC:;%%
RETCODE = 0  操作成功

输出结果如下
------------------------
   	映射功能开关  =  关闭
   	用户范围控制  =  全部用户
     	  5G消息类型  =  UDM相关消息
      	  4G消息类型  =  HSS相关消息
PRA和MEC区域映射开关  =  关闭
(结果个数 = 1)
---    END
```

## 输出结果说明

| 输出项名称         | 输出项解释                                                                                                                                                          |
|:--------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 映射功能开关        | 该参数用于配置支持Serving PLMN映射功能控制开关。                                                                                                                                 |
| 用户范围控制        | 该参数用于控制支持Serving PLMN映射功能的用户范围。                                                                                                                                |
| 5G消息类型        | 该参数用于控制5G制式下进行Serving PLMN映射的消息类型。                                                                                                                             |
| 4G消息类型        | 该参数用于控制4G制式下进行Serving PLMN映射的消息类型。                                                                                                                             |
| PRA和MEC区域映射开关 | 该参数用于配置对于其他网元下发的PRA区域，以及AMF/MME通过命令配置的MEC/PRA区域，支持AMF/MME本地Serving PLMN映射之后再进行区域匹配。 AMF配置涉及：ADD MECAREATAI、ADD MECAREAGNB和ADD NGPRAMEM； MME配置涉及：ADD PRALSTMEM。 |
