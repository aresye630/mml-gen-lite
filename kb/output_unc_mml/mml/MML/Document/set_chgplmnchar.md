#### 命令功能

**适用网元：SGSN**

该命令用于设置某个PLMN类型的用户计费属性的参数配置。

#### 注意事项

- 系统初次运行时，会执行系统初始设置值。
- 该命令执行后立即生效。
- 如果该命令配置了禁止生成某种话单，不管**ADD CHGPLMNCFG**、**ADD CHGIMSICFG**、**SET CHGCHAR**配置何种类型的值，都不生成话单；如果本命令配置了允许生成某种话单，用户是否生成话单将由**ADD CHGPLMNCFG**、**ADD CHGIMSICFG**、**SET CHGCHAR**中的配置决定。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

设置本网用户的话单控制属性“生成S-SMO-CDR”为不生成，配置格式如下：

SET CHGPLMNCHAR: PLMN=HPLMN, SMOP=NO;
