# 显示会话管理的用户数（DSP SMUSERNUM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C、SMF、GGSN**

该命令用于查看SMF/PGW-C/SGW-C/GGSN-C的用户数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                           |
|:----------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| QRY_SCOPE | 查询范围   | 可选必选说明：可选参数  参数含义：该参数用于指示查询用户数的范围。  数据来源：本端规划 取值范围： “SUMMARY（汇总信息）”：查询汇总信息。以汇总方式呈现。“ALL_POD_INFO（所有POD信息）”：查询所有POD信息。以POD粒度呈现。“SPECIFIED_POD_INFO（指定POD信息）”：查询指定POD信息。  默认值：SUMMARY  配置原则：无                                                                                                                    |
| QRY_CLASS | 查询分类   | 可选必选说明：可选参数  参数含义：该参数用于指示查询用户数的分类条件。  数据来源：本端规划 取值范围： “APN（APN）”：查询使用该APN激活的当前在线用户数。“RAT（无线接入类型）”：查询不同无线接入类型的用户数。“SUMMARY（汇总信息）”：查询所有类型的汇总会话上下文数。“ALIASAPN（别名APN）”：查询使用该别名APN激活的当前在线用户数。  默认值：SUMMARY  配置原则：无                                                                                                  |
| APN       | APN    | 可选必选说明：该参数在"QRY_CLASS"配置为"APN"时为条件必选参数。  参数含义：该参数用于指示需要查询会话上下文的APN。使用用户请求的APN对应的上报属性中“上报给话统的APN名”参数的取值，即在SET APNREPORTATTR命令中设置的该APN的PERFORMANCE的取值，指定使用用户请求的APN还是真实的APN进行统计。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。  默认值：无  配置原则：无                                                                               |
| RAT       | 无线接入类型 | 可选必选说明：该参数在"QRY_CLASS"配置为"RAT"时为条件必选参数。  参数含义：该参数用于指示指定需要查询会话上下文的无线接入类型。  数据来源：全网规划 取值范围： “UTRAN（UTRAN）”：通用陆地无线接入网。“GERAN（GERAN）”：GSM/EDGE无线接入网。“EUTRAN（EUTRAN）”：演进型通用陆地无线接入网。“NGRAN（NGRAN）”：5G无线接入网。“EUTRAN_NB_IOT（EUTRAN-NB-IOT）”：演进型通用陆地无线接入网-窄带物联网。“WLAN（WLAN）”：无线局域网“REDCAP（REDCAP）”：轻量能力。  默认值：无  配置原则：无 |
| POD_ID    | POD名称  | 可选必选说明：该参数在"QRY_SCOPE"配置为"SPECIFIED_POD_INFO"时为条件必选参数。  参数含义：该参数用于指示需要查询会话上下文的POD名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~255。  默认值：无  配置原则：无                                                                                                                                                                       |
| ALIASAPN  | 别名APN  | 可选必选说明：该参数在"QRY_CLASS"配置为"ALIASAPN"时为条件必选参数。  参数含义：该参数用于指示需要查询会话上下文的别名APN。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。  默认值：无  配置原则：无                                                                                                                                                                                  |

## 使用实例

当需要查询系统的用户数时，使用如下命令：

```
%%DSP SMUSERNUM: QRY_SCOPE=SUMMARY, QRY_CLASS=SUMMARY;%%
RETCODE = 0  操作成功

结果如下
--------
                           查询分类  =  汇总信息
                        GTPv1用户数  =  0
  本网签约并在本网接入的GTPv1用户数  =  0
异网漫入并在拜访地接入的GTPv1用户数  =  0
  漫出并在回归属地激活的GTPv1用户数  =  0
                        GTPv2用户数  =  0
  本网签约并在本网接入的GTPv2用户数  =  0
异网漫入并在拜访地接入的GTPv2用户数  =  0
  漫出并在回归属地激活的GTPv2用户数  =  0
                           SA用户数  =  0
     本网签约并在本网接入的SA用户数  =  0
   异网漫入并在拜访地接入的SA用户数  =  0
     漫出并在回归属地激活的SA用户数  =  0
(结果个数 = 1)

---    END
```
