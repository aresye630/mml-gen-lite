# 设置CSLB使用轻量化CSDB插件的开关（SET LBCSDBLITEPLUGSW）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

本命令属于高危命令，操作不当会导致业务受损，请谨慎使用并联系华为技术支持协助操作。

该命令用于设置CSLB是否使用轻量化CSDB插件。

#### 注意事项

- 该命令的生效依赖环境变量CSLB\_USE\_CSDB\_LITE\_PLUG配置为1。

- 该命令执行后，需CSLB复位后生效。

该命令存在系统初始记录，参数的初始设置值如下表：

| SWFLAG    |
|:----------|
| SW_ENABLE |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称               | 参数说明                                                                                                                                                                               |
|:-------|:-------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SWFLAG | CSLB使用轻量化CSDB插件的开关 | 可选必选说明：必选参数 参数含义：该参数表示开启或关闭CSLB使用轻量化CSDB插件的开关。 数据来源：全网规划 取值范围：枚举类型: SW_ENABLE(CSLB使用轻量化CSDB插件开启)：CSLB使用轻量化CSDB插件开启。SW_DISABLE(CSLB使用轻量化CSDB插件关闭)：CSLB使用轻量化CSDB插件关闭。 默认值：无。 配置原则：无。 |

#### 使用实例

设置CSLB使用轻量化CSDB插件的开关关闭，命令如下：

```
SET LBCSDBLITEPLUGSW: SWFLAG=SW_DISABLE;
```
