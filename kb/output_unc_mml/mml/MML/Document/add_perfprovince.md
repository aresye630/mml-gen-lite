# 增加省份性能统计对象（ADD PERFPROVINCE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于手工增加省份性能统计对象的配置。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入64条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                         |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROVINCE | 省份     | 可选必选说明：必选参数  参数含义：该参数用于标识基于省份性能统计对象名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。  默认值：无  配置原则：无                                                                                    |
| NO       | 省份编号   | 可选必选说明：必选参数  参数含义：该参数用于标识省份性能统计对象对应的省份标号。  数据来源：本端规划  取值范围：字符串类型，输入长度是2。  默认值：无  配置原则：  需要由运营商设备规范统一定义UDM Instance ID的组成结构，当前固定获取UDM Instance ID中最后一个ID段（由“-”分隔）的第三字节代表省份编号。 |

## 使用实例

增加名称为“BEIJING”、对应的标识为“01”的性能统计对象，执行如下命令：

```
ADD PERFPROVINCE: PROVINCE="BEIJING", NO="01";
```
