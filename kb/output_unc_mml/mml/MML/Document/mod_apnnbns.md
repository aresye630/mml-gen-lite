# 修改APN的NBNS属性（MOD APNNBNS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、GGSN、SMF**

该命令用来修改APN实例的NBNS属性。

## 注意事项

- 该命令执行后立即生效。

- 配置该命令时至少输入一个可选参数，如果输入备NBNS服务器IP，必须输入主NBNS服务器IP。
- 允许同时设置主备NBNS服务器IP为0.0.0.0。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                                                                       |
|:----------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN             | APN名称  | 可选必选说明：必选参数  参数含义：该参数用于指定APN实例名。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”特殊字符，不区分大小写。  默认值：无  配置原则：无    |
| IPV4PRIMARYIP   | 主NBNS  | 可选必选说明：可选参数  参数含义：该参数用于指定主NBNS服务器IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。点分十进制IPv4地址，仅支持A、B、C类IP。0.0.0.0表示无效值。在MOD APNNBNS命令下，允许同时设置主备NBNS为0.0.0.0。  默认值：无  配置原则：无                                               |
| IPV4SECONDARYIP | 备NBNS  | 可选必选说明：可选参数  参数含义：该参数用于指定备NBNS服务器IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。点分十进制IPv4地址，仅支持A、B、C类IP。0.0.0.0表示无效值。在MOD APNNBNS命令下，允许同时设置主备NBNS为0.0.0.0。  默认值：无  配置原则：  在执行ADD APNNBNS时，不配置该参数时默认为NULL。               |
| IPV4PRIORFIRST  | 第一优先级  | 可选必选说明：可选参数  参数含义：该参数用于指定IPv4第一优先级属性。  数据来源：全网规划  取值范围：在执行ADD APNNBNS时，不配置该参数时默认为DHCP。 “LOCAL（local）”：指定本地配置优先。“RADIUS（radius）”：指定RADIUS服务器返回的NBNS属性优先。“DHCP（dhcp）”：指定DHCP服务器返回的NBNS属性优先。  默认值：无  配置原则：无   |
| IPV4PRIORSECOND | 第二优先级  | 可选必选说明：可选参数  参数含义：该参数用于指定IPv4第二优先级属性。  数据来源：全网规划  取值范围：在执行ADD APNNBNS时，不配置该参数时默认为RADIUS。 “LOCAL（local）”：指定本地配置优先。“RADIUS（radius）”：指定RADIUS服务器返回的NBNS属性优先。“DHCP（dhcp）”：指定DHCP服务器返回的NBNS属性优先。  默认值：无  配置原则：无 |

## 使用实例

修改APN为“huawei.com”NBNS属性的主备NBNS地址：

```
MOD APNNBNS: APN="huawei.com", IPV4PRIMARYIP="10.1.1.1", IPV4SECONDARYIP="10.2.2.2";
```
