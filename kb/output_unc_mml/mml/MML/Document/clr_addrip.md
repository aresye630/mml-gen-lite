# 清除地址（CLR ADDRIP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：GGSN、PGW-C、SMF**

该命令用于清除路由地址或静态地址缓存。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                         |
|:-----------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------|
| CLRTYPE    | 清除方式   | 可选必选说明：必选参数  参数含义：该命令用于指定清除路由地址或静态地址缓存的方式。  数据来源：本端规划 取值范围： DELETEALL（清除所有地址）DELETEALLBYAPN（清除该APN下的所有地址）DELETESINGLE（清除单条地址）  默认值：无  配置原则：无 |
| ADDRIPTYPE | 本地地址类型 | 可选必选说明：必选参数  参数含义：该参数用于指定本地地址类型。  数据来源：本端规划 取值范围： ROUTEIP（路由IP地址）STATICIP（静态IP地址）  默认值：无  配置原则：无                                             |
| APN        | APN名称  | 可选必选说明：该参数在"CLRTYPE"配置为"DELETEALLBYAPN"、"DELETESINGLE"时为条件必选参数。  参数含义：该参数用于指定APN实例名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。  默认值：无  配置原则：无      |
| IPVERSION  | IP地址类型 | 可选必选说明：该参数在"CLRTYPE"配置为"DELETESINGLE"时为条件必选参数。  参数含义：该参数用于指定IP地址类型。  数据来源：本端规划 取值范围： “IPv4（IPv4）”：IPv4“IPv6（IPv6）”：IPv6  默认值：无  配置原则：无       |
| IPV4       | IPV4地址 | 可选必选说明：该参数在"IPVERSION"配置为"IPv4"时为条件必选参数。  参数含义：该参数用于指定IPv4地址。  数据来源：本端规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无                                      |
| IPV4MASK   | IPV4掩码 | 可选必选说明：该参数在"IPVERSION"配置为"IPv4"时为条件可选参数。  参数含义：该参数用于指定IPv4地址的网络掩码。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无                   |
| IPV6       | IPV6地址 | 可选必选说明：该参数在"IPVERSION"配置为"IPv6"时为条件必选参数。  参数含义：该参数用于指定IPv6地址。  数据来源：本端规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无                                      |
| IPV6PREFIX | IPV6前缀 | 可选必选说明：该参数在"IPVERSION"配置为"IPv6"时为条件可选参数。  参数含义：该参数用于指定IPv6地址的前缀。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无                     |

## 使用实例

清除所有静态地址缓存。

```
CLR ADDRIP:CLRTYPE=DELETEALL,ADDRIPTYPE=STATICIP;
```
