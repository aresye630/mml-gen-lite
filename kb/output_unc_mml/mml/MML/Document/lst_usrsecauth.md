# 查看二次授权用户（LST USRSECAUTH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

查询所有支持二次授权的用户名。

#### 注意事项

无。

#### 参数说明

无。

#### 使用实例

查看二次授权用户：

```
%%LST USRSECAUTH:;%%
RETCODE = 0  操作成功

操作结果如下
------------
用户名    
  
admin     
test01   
(结果个数 = 2)

---    END
```

#### 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。输出结果说明如表1所示。

命令执行异常，请联系华为技术支持处理。输出结果说明如表2所示。

| 输出项名称   | 输出项解释        |
|:--------|:-------------|
| 用户名     | 可进行二次授权的用户名称 |

|    错误码 | 错误码解释   | 原因分析           | 处理建议           |
|-------:|:--------|:---------------|:---------------|
| 101009 | 未知的命令名称 | 输入的MML命令名称不存在。 | 请输入正确的MML命令名称。 |
| 101099 | 数据库执行失败 | 执行数据库操作失败。     | 请联系华为技术支持。     |
