# 增加Ocs组（ADD OCSGROUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

此命令用来增加ocs组，配置ocs组的组名信息。

此命令为在线计费的基本配置，ocs组用来绑定OcsInfo。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为100。
- 如果要使用该ocs组则必须绑定到dcc模板下。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                  |
|:-----------|:-------|:--------------------------------------------------------------------------------------|
| OCSGRPNAME | Ocs组名称 | 可选必选说明：必选参数 参数含义：ocs组的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

增加一条Ocs组名称为“OcsGroup1”的配置，其中“OcsGrpName”为“OcsGroup1”：

```
ADD OCSGROUP:OCSGRPNAME="OcsGroup1";
```
