# 增加MSC信令点(ADD MSCOPC)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SMSF**

该命令用于增加MSC信令点配置。

#### 注意事项

此命令的最大记录数为2。

#### 本地用户权限

manage-ug；system-ug;

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组;

#### 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                                                                                                                                                 |
|:-------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OPX    | MSC信令点索引 | 可选必选说明：必选参数 参数含义：该参数用于指定MSC本局信令点索引。 数据来源：本端规划 取值范围：1~2。 默认值：无 配置原则：无                                                                                                                                                                                                 |
| NI     | 网络指示语    | 可选必选说明：必选参数 参数含义：该参数用于指定网络指示语，区分不同的网络。 数据来源：整网规划 取值范围：“INT（国际网）”“INTB（国际备用网）”“NAT（国内网）”“NATB（国内备用网）” 默认值：无 配置原则： 该命令中的NI+OPC+MSCN需要先通过ADD SCCPOPC创建。  说明： 配置的网络指示语在信令属性表中应该配置为有效（SET SIGATTR）。                                                                       |
| OPC    | 本局信令点编码  | 可选必选说明：必选参数 参数含义：该参数用于指定本局信令点编码，可以采用24位信令点编码或14位信令编码。本局信令点编码在同一网络中唯一。 数据来源：整网规划 取值范围：字符串类型，输入长度范围为1~8 默认值：无 配置原则：配置的信令点编码结构需要和信令属性表中对应的信令网络的网络结构保持一致。取值为0x1~0x3FFF（对应14位编码）或0x1~0xFFFFFF（对应24位编码），不输入0x也取输入为十六进制值，即输入123等价于0x123。该命令中的NI+OPC+MSCN需要先通过ADD SCCPOPC创建。 |
| MSCN   | 本局MSC号   | 可选必选说明：必选参数 参数含义：该参数用于指定本局MSC号。该字段需要和SMSC协商，不能和ADD SMSFOPC的SMSFN重复，可以和ADD VLROPC的VLRN重复。 数据来源：整网规划 取值范围：长度不超过16的十进制数字 默认值：无 配置原则： 该命令中的NI+OPC+MSCN需要先通过ADD SCCPOPC创建。                                                                                                |
| MASTER | 主用信令点    | 可选必选说明：可选参数 参数含义：该参数用于是否为主用MSC，有且只能有一个MSC为主。 数据来源：本端规划 取值范围： “NO”“YES” 默认值：NO                                                                                                                                                                                        |

#### 使用实例

增加MSC信令点，MSC信令点索引为1，网络指示语为NAT，本局信令点编码为“340012”，本局MSC号为"861390340012",主用信令点为“NO”：

```
ADD MSCOPC: OPX=1, NI=NAT, OPC="340012", MSCN="861390340012", MASTER=NO;"
```
