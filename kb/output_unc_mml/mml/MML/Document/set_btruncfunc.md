# 设置宽带集群系统扩展功能(SET BTRUNCFUNC)

#### 命令功能

**适用NF：MME**

此命令用于设置专网中，宽带集群系统支持的扩展功能。

#### 注意事项

- 该命令执行后立即生效。
- 开关“是否支持集群业务”打开，对于TSN双备场景会向eNB同步MME设备能力为0，影响新用户接入。
- 开关“是否支持集群业务”打开时，MME会向TSN同步未同步的基站TA信息，导致TM接口消息突增。

#### 本地用户权限

manage-ug;system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                               |
|:-------|:---------|:-------------------------------------------------------------------------------------------------------------------|
| BTRUNC | 是否支持集群业务 | 可选必选说明：可选参数 参数含义：该参数当前系统是否支持宽带集群业务。在开启的情况下，系统需要与TSN网元交互，完成集群用户相关业务。 数据来源：全网规划 取值范围：“YES(是)”“NO(否)” 系统初始设置值：“NO(否)” |

#### 使用实例

系统开启宽带集群系统扩展功能，支持集群用户业务：

```
SET BTRUNCFUNC:BTRUNC=YES;
```
