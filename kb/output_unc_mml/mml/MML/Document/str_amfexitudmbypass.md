# 启动用户退出UDM Bypass状态任务（STR AMFEXITUDMBYPASS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

当启动用户退出UDM Bypass任务时，CPU和内存使用率会升高，和周边网元交互消息量增大，待用户退出UDM Bypass任务完成后，系统会恢复正常。

**适用NF：AMF**

该命令用于启动用户退出UDM Bypass任务。当UDM故障已恢复但用户尚未退出UDM Bypass状态时，可以执行该命令使用户退出UDM Bypass状态。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称               | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|:---------|:-------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| QUITTYPE | 退出方式               | 可选必选说明：必选参数  参数含义：该参数用于指定用户退出UDM Bypass的方式。  数据来源：本端规划 取值范围： “GRACEFUL_DEREG（优雅去注册）”：若用户处于连接态，AMF待用户进入空闲态后发起显式去注册流程，并标记用户退出UDM Bypass状态；若用户处于空闲态，AMF寻呼用户成功后发起显式去注册流程，并标记用户退出UDM Bypass状态；若用户处于去注册态，AMF标记用户退出UDM Bypass状态。“SUPPLEMENT_UDM_INTERACT（补充缺失的UDM流程）”：AMF补齐和UDM交互的注册、签约数据获取和订阅三次流程，若成功则标记用户退出UDM Bypass状态，否则继续标记用户处于UDM Bypass状态。“FORCED_DEREG（强制去注册）”：若用户处于连接态，AMF直接发起显式去注册流程，并标记用户退出UDM Bypass状态；若用户处于空闲态，AMF寻呼用户成功后发起显式去注册流程，并标记用户退出UDM Bypass状态；若用户处于去注册态，AMF标记用户退出UDM Bypass状态。  默认值：无  配置原则：无 |
| SCANRATE | 扫描速率(个/秒)          | 可选必选说明：必选参数  参数含义：该参数用于指定每个DS每秒扫描多少个用户，扫描到处于UDM Bypass的用户后，AMF根据QUITTYPE参数设置使用户退出UDM Bypass状态。  数据来源：全网规划  取值范围：整数类型，取值范围是1~20，单位是个每秒。  默认值：无  配置原则：  DS个数 × 扫描速率 = 整系统扫描速率。  DS个数来源于如下命令输出结果中记录个数：  DSP FRAMEDBG: DBGSTR="UeamCtrlSvc coordinator all";  如果结果没有分批显示，则记录个数为回显中“结果个数”字段的值减1；如果结果分批显示，则记录个数为最终的结果个数减1。                                                                                                                                                                                         |
| BAMFSW   | 备份用户退出UDM Bypass开关 | 可选必选说明：可选参数  参数含义：该参数用于控制AMF是否支持备份用户退出UDM Bypass，当本参数设置为“ON”时，UDM Bypass退出扫描任务对备份用户和非备份用户均生效。  数据来源：本端规划 取值范围： “OFF（关闭）”：关闭“ON（开启）”：开启  默认值：无  配置原则：  建议仅在O-AMF故障时，将本参数设置为“ON”。                                                                                                                                                                                                                                                                                                                              |

## 使用实例

如果希望进入到UDM Bypass状态的用户能够退出该状态，可以通过该命令使用户退出UDM Bypass状态，以退出方式为优雅去注册方式，扫描速率为1个/秒，执行如下命令：

```
STR AMFEXITUDMBYPASS:QUITTYPE=GRACEFUL_DEREG,SCANRATE=1;
```
