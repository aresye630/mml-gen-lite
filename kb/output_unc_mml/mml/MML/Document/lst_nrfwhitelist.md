# 查询NF白名单（LST NRFWHITELIST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NRF**

该命令用于查询NF白名单中的NF实例。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询白名单中的网元实例列表，执行如下命令：

```
LST NRFWHITELIST:;
%%LST NRFWHITELIST:;%%
RETCODE = 0  操作成功

结果如下
------------------------
NF实例标识  =  instance_01
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                    |
|:--------|:-------------------------|
| NF实例标识  | 该参数用于表示需要增加到白名单中的NF实例标识。 |
