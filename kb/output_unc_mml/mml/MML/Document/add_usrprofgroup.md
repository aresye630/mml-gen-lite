# 增加用户模板组（ADD USRPROFGROUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于配置一个用户模板组。可使用该用户模板组绑定多个PccProfile和UserProfile，并将该用户模板组绑定到用户APN。用户激活时，可根据APN选择到用户模板组，从而选择可用策略。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为10000。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                          |
|:--------------|:--------|:----------------------------------------------------------------------------------------------|
| USERPROFGNAME | 用户模板组名称 | 可选必选说明：必选参数 参数含义：该参数用于指定用户模板组的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

增加一个名为userprofg1的用户模板组配置：

```
ADD USRPROFGROUP:USERPROFGNAME="userprofg1";
```
