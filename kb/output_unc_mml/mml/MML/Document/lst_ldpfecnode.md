# 查询FEC节点配置（LST LDPFECNODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询FEC节点配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                      |
|:------------|:--------|:--------------------------------------------------------------------------|
| FECLISTNAME | FEC列表名称 | 可选必选说明：可选参数 参数含义：该参数用于指定FEC列表的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 |
| IPADDRESS   | IP地址    | 可选必选说明：可选参数 参数含义：该参数用于指定FEC的IP地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无          |

#### 使用实例

查询FEC节点配置：

```
LST LDPFECNODE:;
```

```
RETCODE = 0  操作成功。

结果如下
--------
FEC列表名称  =  name1
     IP地址  =  192.168.1.1
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释         |
|:--------|:--------------|
| FEC列表名称 | 用于指定FEC列表的名称。 |

其余输出项请参见ADD LDPFECNODE的参数说明。
