# 查询N2模式TALIST寻呼不重发TAC区间（LST NGTALISTPAGINGCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询N2模式TALIST寻呼不重发TAC区间。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                              |
|:---------|:--------|:----------------------------------------------------------------------------------------------------------------------------------|
| MCC      | MCC     | 可选必选说明：可选参数  参数含义：该参数用于表示组成PLMN的移动国家码信息。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。  默认值：无  配置原则：无                                            |
| MNC      | MNC     | 可选必选说明：可选参数  参数含义：该参数用于表示组成PLMN的移动网号信息。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。  默认值：无  配置原则：无                                         |
| TACSTART | 跟踪区域起始值 | 可选必选说明：可选参数  参数含义：该参数用于指定跟踪区域起始编码。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。  默认值：无  配置原则：  本参数由6位十六进制数组成，不区分大小写。MCC、MNC相同时，不同记录的TAC区间不能有交集。 |

## 使用实例

查询TALIST寻呼不重发TAC区间，执行如下命令：

```
%%LST NGTALISTPAGINGCFG:;%%
RETCODE = 0  操作成功

结果如下
------------
           MCC  =  123
           MNC  =  45
跟踪区域起始值  =  11BF85
跟踪区域结束值  =  11BF86
   语音寻呼开关 =  否
(结果个数 = 1)
---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                        |
|:--------|:-----------------------------------------------------------------------------------------------------------------------------|
| MCC     | 该参数用于表示组成PLMN的移动国家码信息。                                                                                                       |
| MNC     | 该参数用于表示组成PLMN的移动网号信息。                                                                                                        |
| 跟踪区域起始值 | 该参数用于指定跟踪区域起始编码。                                                                                                             |
| 跟踪区域结束值 | 该参数用于指定跟踪区域结束值。                                                                                                              |
| 语音寻呼开关  | 该参数用于配置“N2模式TALIST寻呼不重发”功能是否对IMS寻呼（含IMS语音及IMS短消息）有效。如果ADD NGVOICEDEPLOY配置了“语音业务DNN”，则以该DNN为准判断是否为IMS寻呼，否则以“IMS”为准判断是否为IMS寻呼。 |
