# 设置话单产生速率（SET CDRGENRATECTRL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

SET CDRGENRATECTRL此命令用来配置UNC计费数据产生速率。UNC会根据用户数和系统运行状况综合处理计费数据产生速率，如果认为系统默认计费数据产生速率不合适，可以通过此命令设置计费数据实际产生速率。如果CDRGENRATE参数设置为50，表示计费数据实际产生速率是系统默认值的50%。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：
- 当前版本不支持此命令。

| 参数标识   |   CDRGENRATE |
|:-------|-------------:|
| 初始值    |          100 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称       | 参数说明                                                                                           |
|:-----------|:-----------|:-----------------------------------------------------------------------------------------------|
| CDRGENRATE | CDR产生速率（%） | 可选必选说明：必选参数 参数含义：CDR产生速率(%)，标识话单产生速率和系统默认值的比例关系。 数据来源：本端规划 取值范围：整数类型，取值范围为50～500。 默认值：无 配置原则：无 |

#### 使用实例

修改计费话单产生速率：

```
SET CDRGENRATECTRL:CDRGENRATE=50;
```
