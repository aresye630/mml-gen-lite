# 删除Serving PLMN的映射关系（RMV SRVPLMNMAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：MME、AMF**

该命令用于删除Serving PLMN的映射关系。

## 注意事项

下一次移动性流程生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                        |
|:---------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SRCMCC   | 原始移动国家码 | 可选必选说明：必选参数  参数含义：该参数用于表示映射前的原始Serving PLMN移动国家码信息。  数据来源：本端规划  取值范围：字符串类型，输入长度是3。  默认值：无  配置原则：无                                                                           |
| SRCMNC   | 原始移动网号  | 可选必选说明：必选参数  参数含义：该参数用于表示映射前的原始Serving PLMN移动网号信息。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是2~3。  默认值：无  配置原则：无                                                                        |
| SUBRANGE | 用户范围    | 可选必选说明：必选参数  参数含义：该参数用于指定应用Serving PLMN映射的用户范围。  数据来源：全网规划 取值范围： “ALL_USER（所有用户）”：所有用户“SPECIFIED_IMSI_PRE（指定IMSI前缀）”：指定IMSI前缀“SPECIFIED_IMSI（指定IMSI）”：指定IMSI  默认值：无  配置原则：无 |
| IMSIPRE  | IMSI前缀  | 可选必选说明：该参数在"SUBRANGE"配置为"SPECIFIED_IMSI_PRE"时为条件必选参数。  参数含义：该参数用于指定应用Serving PLMN映射的IMSI前缀。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是5~14。  默认值：无  配置原则：无                              |
| IMSI     | IMSI    | 可选必选说明：该参数在"SUBRANGE"配置为"SPECIFIED_IMSI"时为条件必选参数。  参数含义：该参数用于指定应用Serving PLMN映射的IMSI。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是14~15。  默认值：无  配置原则：无                                   |

## 使用实例

删除Serving PLMN的映射关系，原始用户PLMN为12307，用户范围为所有用户，执行如下命令：

```
RMV SRVPLMNMAP: SRCMCC="123", SRCMNC="07", SUBRANGE=ALL_USER;
```
