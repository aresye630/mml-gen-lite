# 查询NRF大小写敏感策略（LST NRFCASESENSPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NRF**

该命令用于查询NRF注册和服务发现场景下大小写敏感策略。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

运营商希望显示当前NRF上注册和服务发现场景大小写敏感策略时，执行此命令。

```
%%LST NRFCASESENSPLCY:;%%
RETCODE = 0  操作成功

结果如下
------------------------
大小写敏感参数              NF参数大小写转换开关   大小写敏感匹配开关

ServingScope             ON                  ON
Locality                 ON                  ON
(结果个数 = 2)
```

## 输出结果说明

| 输出项名称       | 输出项解释                                                                        |
|:------------|:-----------------------------------------------------------------------------|
| 大小写敏感参数     | 该参数用于指定NF注册和服务发现时携带的需要做大小写敏感处理的参数。                                           |
| NF参数大小写转换开关 | 该参数用于表示是否对NF向NRF注册、服务发现消息中指定参数进行大小写转换处理。开关打开 ，表示将指定参数转换为小写；开关关闭，表示保存原始格式。    |
| 大小写敏感匹配开关   | 该参数用于表示NF携带指定参数服务发现时，NRF是否进行大小写敏感匹配。 开关打开，表示指定参数大小写不敏感匹配；开关关闭，表示指定参数大小写敏感匹配。 |
