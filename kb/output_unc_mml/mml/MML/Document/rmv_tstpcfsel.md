# 删除拨测用户与PCF服务区的绑定关系（RMV TSTPCFSEL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于删除用户和PCF服务区的绑定关系。

## 注意事项

该命令执行后只对新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                        |
|:-------|:--------|:----------------------------------------------------------------------------------------------------------------------------|
| IMSI   | 用户的IMSI | 可选必选说明：必选参数  参数含义：该参数用于指定用户IMSI。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是14~15。每个字符只能是十进制数字。  默认值：无  配置原则：  该参数表示用户完整的IMSI信息，不支持前缀匹配。 |

## 使用实例

删除IMSI是"123456789012345"的用户激活到特定PCF服务区域的PCF的配置。

```
RMV TSTPCFSEL: IMSI="123456789012345";
```
