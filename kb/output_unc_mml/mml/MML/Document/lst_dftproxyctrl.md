# 查询缺省代理控制配置（LST DFTPROXYCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C、SMF**

该命令用于查询缺省代理控制配置。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询缺省的代理控制配置：

```
%%LST DFTPROXYCTRL:;%%
RETCODE = 0  操作成功

结果如下
--------
支持语音业务回归属地功能开关  =  关闭
                         归属地接口模式  =   与左侧联动
       数据业务回归属地功能开关  =    关闭
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称          | 输出项解释               |
|:---------------|:--------------------|
| 支持语音业务回归属地功能开关 | 该参数用于控制运营商语音业务回归属地。 |
| 归属地接口模式        | 该参数用于指示归属地接口模式。     |
| 数据业务回归属地功能开关   | 该参数用于指示数据业务是否回归属地。  |
