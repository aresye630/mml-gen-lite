# 修改NF组标识路由（MOD NRFGRPIDRT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于修改指定NF组标识路由所归属的NRF实例组名称。

## 注意事项

- 该命令执行后立即生效。

- 主备或双活组网的场景下，如果需要配置此命令，则两个NRF上均需执行此命令，且配置参数一致。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                                                                                                                  |
|:---------------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFTYPE         | NF类型     | 可选必选说明：必选参数  参数含义：该参数用于表示通过NF组标识路由寻址的NF类型。  数据来源：全网规划 取值范围： AUSF（AUSF）UDM（UDM）UDR（UDR）PCF（PCF）CHF（CHF）CUSTOM_OCS（CUSTOM_OCS）SMSF（SMSF）  默认值：无  配置原则：  当前NRF仅支持NFTYPE为AUSF、UDM、PCF、CUSTOM_OCS、SMSF的路由转发功能，其他NF类型为预留功能。 |
| NFGROUPID      | NF组标识    | 可选必选说明：必选参数  参数含义：该参数用于表示被寻址NF所在的NF实例组标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~128。该参数只能由字母（A-Z或者a-z）、数字（0-9）、中划线（-）组成，不区分大小写。  默认值：无  配置原则：无                                                                              |
| NEXTNRFGRPNAME | 归属NRF组名称 | 可选必选说明：可选参数  参数含义：该参数用于表示当前NRF基于NF实例组标识寻址NF时的下一跳NRF实例组名称，被寻址的NF归属于该NRF实例组。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~64。  默认值：无  配置原则：  该参数需通过ADD NRFGROUP配置，可通过LST NRFGROUP命令获取。                                               |

## 使用实例

运营商网络规划变更，当前NRF上寻址NF组标识为“nfgroupid01”的PCF下一跳路由发生变化，PCF所归属的NRF实例组名称由“L-NRF1”变为“L-NRF2”，需要执行：

```
MOD NRFGRPIDRT:NFTYPE=PCF,NFGROUPID="nfgroupid01",NEXTNRFGRPNAME="L-NRF2";
```
