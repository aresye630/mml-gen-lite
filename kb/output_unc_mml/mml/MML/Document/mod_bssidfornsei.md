# 修改NSEI和BSSID值的对应关系(MOD BSSIDFORNSEI)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

此命令用于修改一个或一组NSEI和BSSID值的对应关系来指定BSSID的值。只适用于Gb over IP自动配置的场景。

#### 注意事项

- 此命令执行后立即生效。
- 此命令最大记录数为8192。
- 此命令所要修改的是与**ADD BSSIDFORNSEI**中对应的一个或一组NSEI指定的BSSID值。
- 此命令仅影响小部分话统，影响5个性能测量对象对应的性能测试指标，分别是“指定BSS附着”、“指定BSS SGSN内路由更新”、“指定BSS SGSN间路由更新”、“指定BSS无线资源”、“指定BSS GB接口流量”。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称            | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|:----------|:----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NSEI      | 起始NSE标识         | 可选必选说明：必选参数 参数含义：该参数用于指定待增加NSEI和BSSID值对应关系的网络服务实体起始标识。 数据来源：整网规划 取值范围：0～65535 默认值：无  说明： 本参数为ADD BSSIDFORNSEI中存在的起始NSE标识。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| BSSIDRULE | BSSID与NSEI的对应关系 | 可选必选说明：必选参数 参数含义：该参数用于指定自动上报NSE的BSSID与NSEI的对应关系。 数据来源：整网规划 取值范围： “NSEI(NSEI)”：BSSID值与NSEI值相同。“NSEI_EXCLUDE_LAST_DIGIT(NSEI去掉最后1位)”：BSSID值为NSEI值去掉最后1位。“NSEI_EXCLUDE_LAST_2_DIGITS(NSEI去掉最后2位)”：BSSID值为NSEI值去掉最后2位。“NSEI_EXCLUDE_LAST_3_DIGITS(NSEI去掉最后3位)”：BSSID值为NSEI值去掉最后3位。“NSEI_EXCLUDE_FIRST_DIGIT(NSEI去掉前1位)”：BSSID值为NSEI值去掉前1位。“NSEI_EXCLUDE_FIRST_2_DIGITS(NSEI去掉前2位)”：BSSID值为NSEI值去掉前2位。“NSEI_EXCLUDE_FIRST_3_DIGITS(NSEI去掉前3位)”：BSSID值为NSEI值去掉前3位。“NSEI_MAP_SPECIFIC_BSSID(指定BSSID)”：BSSID值由“BSS标识”指定。 默认值：无 配置原则：当无线侧不同厂商的设备，对核心网侧的BSSID值有要求时，根据NSE范围进行配置和关联。建议使用默认值。  说明： 当配置“起始NSE标识”为65535，“BSSID与NSEI的对应关系”为“NSEI(NSEI)”时，由于“BSS标识”的取值范围为0～65534，BSSID值为65534。 |
| BSSID     | BSS标识           | 可选必选说明：条件必选参数 参数含义：该参数用于指定待修改NSEI和BSSID值对应关系的BSS标识。 前提条件：该参数在“BSSID与NSEI的对应关系”为“NSEI_MAP_SPECIFIC_BSSID(指定BSSID)”时配置 数据来源：整网规划 取值范围：0～65534 默认值：无  说明： 一个BSS标识可以对应多个NSE标识。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |

#### 使用实例

修改一组NSEI和BSSID值的对应关系，“起始NSE标识 ”为“0”，“BSSID与NSEI的对应关系 ”为“NSEI\_MAP\_SPECIFIC\_BSSID(指定BSSID)”，“BSS标识”为“2”：

MOD BSSIDFORNSEI: NSEI=0, BSSIDRULE=NSEI\_MAP\_SPECIFIC\_BSSID, BSSID=2;
