# 删除对端NF的切片信息（RMV PNFNS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、NSSF、SMSF、NCG、PGW-C、SGW-C、CBC、CBCF**

该命令用于删除本地配置的对端NF实例支持的切片信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                    |
|:-------|:-------|:----------------------------------------------------------------------------------------|
| INDEX  | 索引     | 可选必选说明：必选参数  参数含义：该参数用于指定切片的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无 |

## 使用实例

删除对端NF实例的切片信息，NF实例标识为SMF\_Instance\_0，NF实例支持的SST为1，SD为000001。

```
RMV PNFNS: INDEX=1;
```
