# 修改NRF功能实例信息（MOD NRFFUNCTION）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于修改NRF功能实例基本信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称      | 参数说明                                                                                                            |
|:---------------|:----------|:----------------------------------------------------------------------------------------------------------------|
| INSTANCEID     | NRF功能实体号  | 可选必选说明：必选参数  参数含义：该参数用于表示特定NRF功能实例号。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~40。  默认值：无  配置原则：无                         |
| NAME           | NRF功能实体描述 | 可选必选说明：可选参数  参数含义：该参数用于表示特定NRF功能实体描述。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~64。  默认值：无  配置原则：无                        |
| ADMINSTATE     | 管理状态      | 可选必选说明：可选参数  参数含义：该参数用于表示特定NRF功能实体管理状态。  数据来源：本端规划 取值范围： Locked（锁定）Unlocked（未锁定）ShuttingDown（关机）  默认值：无  配置原则：无 |
| OPERATIONSTATE | 运行状态      | 可选必选说明：可选参数  参数含义：该参数用于表示特定NRF功能实体运行状态。  数据来源：本端规划 取值范围： Enabled（运行）Disabled（不运行）  默认值：无  配置原则：无                |
| FQDN           | FQDN      | 可选必选说明：可选参数  参数含义：该参数用于表示特定NRF功能实体FQDN。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~255。  默认值：无  配置原则：无                     |

## 使用实例

运营商想修改一条NRF功能实体号为Instanceid01的NRF功能实例信息。将其NRF功能实体描述修改为nfdescription02,管理状态修改为Locked,运行状态修改为Enabled,FQDN修改为fqdn02:

```
MOD NRFFUNCTION:INSTANCEID="Instanceid01",NAME="nfdescription02",ADMINSTATE=Locked,OPERATIONSTATE=Enabled,FQDN="fqdn02":
```
