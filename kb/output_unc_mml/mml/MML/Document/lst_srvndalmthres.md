# 查询业务节点资源不足告警阈值（LST SRVNDALMTHRES）

#### 命令功能

**适用NF：GGSN、SGW-C、PGW-C、SMF**

该命令用于查询业务节点告警阈值和恢复告警阈值。当业务节点资源使用率超过配置的告警门限时产生告警。当使用率低于配置的恢复门限时恢复告警。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

假如运营商想要查询业务节点的告警阈值和恢复告警阈值，使用此命令：

```
LST SRVNDALMTHRES:;
```

```
RETCODE = 0  操作成功

业务节点资源不足告警阈值信息

业务节点恢复告警阈值（%）  =  75

```
