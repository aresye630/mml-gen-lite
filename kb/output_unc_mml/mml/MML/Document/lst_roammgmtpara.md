# 查询漫游管理参数（LST ROAMMGMTPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF、SMF、CBC、CBCF**

该命令用于查询漫游管理参数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询漫游管理参数。

```
%%LST ROAMMGMTPARA:;%%
RETCODE = 0 操作成功

结果如下
------------------------
识别关口局NF开关 = OFF
避免网元混用开关 = OFF
（结果个数=1）

---- END
```

## 输出结果说明

| 输出项名称     | 输出项解释                                   |
|:----------|:----------------------------------------|
| 识别关口局NF开关 | 该参数用于指定漫游场景下是否根据对端NF的IP/FQDN识别是否为关口局NF。 |
| 避免网元混用开关  | 该参数用于指定是否避免混用本网网元和异网网元。                 |
