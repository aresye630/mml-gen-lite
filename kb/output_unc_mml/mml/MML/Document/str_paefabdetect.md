# 启动Fabric链路探测任务（STR PAEFABDETECT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于触发Fabric平面链路状态探测。

## 注意事项

- 该命令执行后立即生效。

- 该命令会增加Fabric平面链路报文转发开销，请谨慎执行。
- SRCPODNAME、DSTPODNAME任一不存在时，开启命令执行成功，但开启任务不生效。
- 下发命令前请确保两个端口之间存在链路（处在同一Fabric平面），可使用命令**DSP FABRICOAMPORT**或**DSP PAEFABRICLINK**查询链路信息。
- 正在探测时重复开启同一任务，原任务将被重置。
- 并行限制：一个pod不支持作为源端同时参与两个探测任务，其他场景支持并行。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                                                                      |
|:------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SRCPODNAME  | 源Pod名称  | 可选必选说明：必选参数  参数含义：该参数用于指定本端Pod名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。  默认值：无  配置原则：  使用DSP POD获取Pod名称。                                                                                                                                    |
| DSTPODNAME  | 目的Pod名称 | 可选必选说明：必选参数  参数含义：该参数用于指定远端Pod名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。  默认值：无  配置原则：  使用DSP POD获取Pod名称。                                                                                                                                    |
| SRCPORTNAME | 源端口名称   | 可选必选说明：必选参数  参数含义：该参数用于指定本端端口名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~20。  默认值：无  配置原则：  使用DSP PAEPORTINFO获取探测端口名称（仅支持Fabric端口）。                                                                                                               |
| DSTPORTNAME | 目的端口名称  | 可选必选说明：必选参数  参数含义：该参数用于指定远端端口名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~20。  默认值：无  配置原则：  使用DSP PAEPORTINFO获取探测端口名称（仅支持Fabric端口）。                                                                                                               |
| DURATION    | 探测时长    | 可选必选说明：可选参数  参数含义：该参数用于指定Fabric链路探测任务的持续时间。  数据来源：本端规划  取值范围：整数类型，取值范围是300~86400，单位是秒。  默认值：300  配置原则：无                                                                                                                                   |
| PKTLENGTH   | 探测包长度   | 可选必选说明：可选参数  参数含义：该参数用于指定发送的探测报文负载字节数。  数据来源：本端规划 取值范围： “PKTLENGTH_256（报文长度256字节）”：报文长度256字节“PKTLENGTH_512（报文长度512字节）”：报文长度512字节“PKTLENGTH_1024（报文长度1024字节）”：报文长度1024字节“PKTLENGTH_1500（报文长度1500字节）”：报文长度1500字节  默认值：PKTLENGTH_512  配置原则：无 |
| INTERVAL    | 间隔      | 可选必选说明：可选参数  参数含义：该参数用于指定发送探测报文的时间间隔。  数据来源：本端规划  取值范围：整数类型，取值范围是100~1000，单位是毫秒。  默认值：200  配置原则：无                                                                                                                                         |
| DYEFLAG     | 染色标记位   | 可选必选说明：可选参数  参数含义：指定发送探测报文的染色标记类型。  数据来源：本端规划 取值范围： ETHTYPE（以太类型）OAMTYPE（OAM类型）  默认值：ETHTYPE  配置原则：  如果交换机支持以太类型过滤规则，选择ETHTYPE。如果交换机不支持以太类型过滤规则，选择OAMTYPE。                                                                                |

## 使用实例

开启Fabric链路探测任务：

```
%%STR PAEFABDETECT: SRCPODNAME="vup-pod-1", DSTPODNAME="vusn-pod-0", SRCPORTNAME="uio0", DSTPORTNAME="uio0", PKTLENGTH=PKTLENGTH_512, DYEFLAG=ETHTYPE;%%
RETCODE = 0  操作成功

---    END
```
