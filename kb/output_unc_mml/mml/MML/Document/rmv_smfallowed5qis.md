# 删除5G用户允许的5QI列表（RMV SMFALLOWED5QIS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于删除5G用户允许的5QI列表。

## 注意事项

- 命令执行后只对新接入用户生效。

- 删除前请确认和"ISMFDFTQOSCTRL"命令及"SMFNONDFTQOSCTL"命令已不存在引用关系，否则不能删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                      |
|:------------|:---------|:------------------------------------------------------------------------------------------|
| QOSINDEX    | 用户QOS索引  | 可选必选说明：必选参数  参数含义：该参数表示允许用户接入的5QI列表索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~65535。  默认值：无  配置原则：无 |
| QOS5QISTART | 5QI范围起始值 | 可选必选说明：可选参数  参数含义：该参数用于指定允许接入的5QI范围的起始值。  数据来源：全网规划  取值范围：整数类型，取值范围是1~255。  默认值：无  配置原则：无 |
| QOS5QIEND   | 5QI范围结束值 | 可选必选说明：可选参数  参数含义：该参数用于指定允许接入的5QI范围的结束值。  数据来源：全网规划  取值范围：整数类型，取值范围是1~255。  默认值：无  配置原则：无 |

## 使用实例

如果想删除"用户QOS索引"为1, 的5G用户允许的5QI列表，执行如下命令:

```
%%RMV SMFALLOWED5QIS: QOSINDEX=4;%%
RETCODE = 0  Operation succeeded

---    END
```
