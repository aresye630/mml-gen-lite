# 查询HTTP状态码判定配置（LST HTTPSTATUS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询已有的HTTP状态码判定配置。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                          |
|:-------|:-------|:----------------------------------------------------------------------------------------------|
| INDEX  | 索引     | 可选必选说明：可选参数  参数含义：该参数用于指定HTTPSTATUS配置的索引信息。  数据来源：本端规划  取值范围：整数类型，取值范围是1~1024。  默认值：无  配置原则：无 |
| STATUS | 状态码    | 可选必选说明：可选参数  参数含义：该参数用于指定进行判定的状态码。  数据来源：本端规划  取值范围：整数类型，取值范围是100~699。  默认值：无  配置原则：无         |

## 使用实例

查询已有的HTTP状态码判定配置，可以用如下命令：

```
%%LST HTTPSTATUS:;%%
RETCODE = 0  操作成功

结果如下
------------------------
               索引  =  1
               场景  =  ERRNEXTHOP
           配置类型  =  WHITELIST
             状态码  =  604
               描述  =  NULL
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                     |
|:--------|:--------------------------|
| 索引      | 该参数用于指定HTTPSTATUS配置的索引信息。 |
| 场景      | 该参数用于表示当前状态码所对应的场景类型。     |
| 配置类型    | 该参数用于指定是否执行特定场景的动作。       |
| 状态码     | 该参数用于指定进行判定的状态码。          |
| 描述      | 该参数用于指定HTTPSTATUS配置的描述信息。 |
