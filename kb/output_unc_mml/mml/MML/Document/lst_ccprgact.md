# 查询融合计费Proxy基于RG处理动作（LST CCPRGACT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NCG**

该命令用于查询融合计费Proxy基于RG处理动作。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                        |
|:------------|:-------|:----------------------------------------------------------------------------------------------------------------------------|
| RGTYPE      | RG类型   | 可选必选说明：可选参数  参数含义：该参数用于指定RG的类型。  数据来源：本端规划 取值范围： DEFAULT（针对未指定的费率组设置处理动作）VALUE（针对费率组设置处理动作）  默认值：无  配置原则：无                  |
| RATINGGROUP | 费率组标识  | 可选必选说明：该参数在"RGTYPE"配置为"VALUE"时为条件可选参数。  参数含义：该参数用于指定费率组标识。  数据来源：本端规划  取值范围：整数类型，取值范围是0~9223372036854775807。  默认值：无  配置原则：无 |

## 使用实例

查询融合计费Proxy基于RG处理动作：

```
LST CCPRGACT:;
RETCODE = 0  操作成功

结果如下
--------
            RG类型  =  针对RG设置处理动作
       费率组标识  =  2000000009
   是否转发OCS  =  否
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释           |
|:--------|:----------------|
| RG类型    | 该参数用于指定RG的类型。   |
| 费率组标识   | 该参数用于指定费率组标识。   |
| 是否转发OCS | 该参数用于设置是否转发OCS。 |
