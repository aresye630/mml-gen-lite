# 测试GTP-C路径(TST GTPCPATH)

#### 命令功能

**适用网元：SGSN、MME**

该命令用于通过发送GTP Echo request消息的方法测试本局与对端GSN之间的GTP-C路径是否正常。

#### 注意事项

- 该命令执行后立即生效。
- 该命令只用于UPP进程。
- 该命令探测过程中临时会产生一条维护路径，探测结束后删除该维护路径。该命令探测只探测路径是否通断，与该路径上是否存在信令消息无关。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                                                                                                                                             |
|:-------------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GTPVER       | GTP版本    | 可选必选说明：必选参数 参数含义：该参数用于指定GTP-C路径的协议版本。 数据来源：整网规划 取值范围：“GTPv0(GTPv0)”“GTPv1(GTPv1)”“GTPv2(GTPv2)” 默认值：无  说明： 输入参数时，先选择“GTP版本”，先指明GTP-C路径的协议版本是“GTPv0(GTPv0)”，“GTPv1(GTPv1)”还是“GTPv2(GTPv2)”，其次选择对端的“IP类型”，再输入IP地址。 |
| IPTYPE       | IP地址类型   | 可选必选说明：必选参数 参数含义：该参数用于指定对端GSN的IP地址类型。 数据来源：整网规划 取值范围：“IPV4(IPV4)”“IPV6(IPV6)” 默认值：无                                                                                                                              |
| LOCIPV4ADDR  | 本端IPv4地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定本端GSN IPV4地址。 前提条件：当“IP类型”设置为“IPV4(IPV4)”时此参数有效。 数据来源：整网规划 取值范围：0.0.0.0～255.255.255.255 默认值：无                                                                                          |
| PEERIPV4ADDR | 对端IPv4地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定对端GSN IPV4地址。 前提条件：当“IP类型”设置为“IPV4(IPV4)”时此参数有效。 数据来源：整网规划 取值范围：0.0.0.0～255.255.255.255 默认值：无                                                                                          |
| LOCIPV6ADDR  | 本端IPv6地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定本端GSN IPV6地址。 前提条件：当“IP类型”设置为“IPV6(IPV6)”时此参数有效。 数据来源：整网规划 取值范围：::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无                                                                       |
| PEERIPV6ADDR | 对端IPv6地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定对端GSN IPV6地址。 前提条件：当“IP类型”设置为“IPV6(IPV6)”时此参数有效。 数据来源：整网规划 取值范围：::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无                                                                       |

#### 使用实例

测试GTP-C Path，路径版本GTPv1版本，本端IP地址为192.168.14.20，对端IP地址为192.168.9.20：

TST GTPCPATH: GTPVER=GTPv1, IPTYPE=IPV4, LOCIPV4ADDR="192.168.14.20", PEERIPV4ADDR="192.168.9.20";

```
%%TST GTPCPATH: GTPVER=GTPv1, IPTYPE=IPV4, LOCIPV4ADDR="192.168.14.20", PEERIPV4ADDR="192.168.9.20";%%
RETCODE = 0  操作成功。

输出结果如下
-----------
本端IPv4地址  =  192.168.14.20
对端IPv4地址  =  192.168.9.20
     GTP版本  =  GTPv1
(结果个数 = 1)

---    END
```
