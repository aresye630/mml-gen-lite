# 修改DCN(MOD DCN)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限

- 使用实例

#### 命令功能

**适用网元：MME**

此命令用于修改指定DCN的类型或描述。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                               |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DCNID   | DCN ID | 可选必选说明：必选参数 参数含义：该参数用来指定DCN标识。 数据来源：全网规划 取值范围：0~255 默认值：无 配置原则：DCN ID不可重复。                                                                                                                                                                                                                                                                                                         |
| MCC     | 移动国家代码 | 可选必选说明：必选参数 参数含义：该参数用于指定DCN所属PLMN的移动国家号码。 数据来源：全网规划 取值范围：3位十进制数 默认值：无                                                                                                                                                                                                                                                                                                              |
| MNC     | 移动网号   | 可选必选说明：必选参数 参数含义：该参数用于指定DCN所属PLMN的移动网号码。 数据来源：全网规划 取值范围：位数为2或3的十进制数 默认值：无                                                                                                                                                                                                                                                                                                          |
| DCNTYPE | DCN类型  | 可选必选说明：可选参数 参数含义：该参数用于指定DCN的类型。 数据来源：全网规划 取值范围：“COMMON(普通DCN)”“DEFAULT(默认DCN)” 默认值：无 配置原则：默认DCN在PLMN内只能配置一条。  说明： 当UNC判断专用核心网重选时，如果用户有规划普通DCN，将用户重选至普通DCN，否则将按照以下情况重选至默认DCN: 默认DCN通过ADD DCNMAP命令配置了UE USAGE TYPE范围：MME获取到用户的UE USAGE TYPE，当用户的UE USAGE TYPE在默认DCN配置的UE USAGE TYPE范围内，则用户接入默认DCN，否则不接入。 MME未获取到用户的UE USAGE TYPE，则用户直接接入默认DCN。 默认DCN未配置UE USAGE TYPE范围，用户直接重选至默认DCN。 |
| DESC    | 描述     | 可选必选说明：可选参数 参数含义：该参数用于指定DCN描述信息。 数据来源：全网规划 取值范围：0~32位字符串 默认值：无                                                                                                                                                                                                                                                                                                                     |

#### 使用实例

“MCC”为“123”，“MNC”为“01”的运营商将eMtc用户的“DCN类型”修改为“默认DCN”：

MOD DCN: DCNID=0, MCC="123", MNC="01", DCNTYPE=DEFAULT, DESC="eMtc";
