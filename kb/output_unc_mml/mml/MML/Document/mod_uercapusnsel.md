# 修改UE无线能力选择USN参数(MOD UERCAPUSNSEL)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于修改指定用户范围用户UE无线能力选择USN的参数。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                    |
|:----------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE  | 用户范围      | 可选必选说明：必选参数 参数含义：该参数用于指定待进行网元重选的用户范围。 数据来源：整网规划 取值范围： ALL_USER（所有用户）：表示用户范围为系统内所有用户。HOME_USER（本网用户）：表示用户范围为本网用户。FOREIGN_USER（外网用户）：表示用户范围为外网用户。 IMSI_PREFIX（指定IMSI前缀）：表示用户范围通过IMSI前缀指定。SPECIFIC_IMSI（指定IMSI）：表示用户范围通过IMSI指定。 默认值：无 配置原则：USN重选策略匹配优先级高到低为：“SPECIFIC_IMSI（指定IMSI）”，“IMSI_PREFIX（指定IMSI前缀）”，“FOREIGN_USER(外网用户)”或“HOME_USER(本网用户)”， “ALL_USER(所有用户)”。 系统优先匹配高优先级的配置记录，如果匹配不到，再匹配低优先级的配置记录。 |
| NOID      | 运营商标识     | 可选必选说明：条件必选参数 参数含义：该参数用于指定运营商标识。 前提条件：该参数在“用户范围”参数配置为“HOME_USER(本网用户)”或“FOREIGN_USER(外网用户)”后生效。 数据来源：整网规划 取值范围：0～64，128～254 默认值：无 配置原则：若该参数需要配置为0或128～254之间的值时，须先在ADD MNO中配置取值相同的“MNOID”参数。若该参数需要配置为1～64之间的值时，须先在中配置取值相同的“MVNOID”参数。                                                                                                                                                                    |
| IMSIPRE   | IMSI前缀    | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI前缀以区分不同的用户群。 前提条件：该参数在“用户范围”参数配置为“指定IMSI前缀”后生效。 数据来源：整网规划 取值范围：5~14位十进制数字字符串 默认值：无                                                                                                                                                                                                                                                                                        |
| IMSI      | IMSI      | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI以区分不同的用户群。 前提条件：该参数在“用户范围”参数配置为“指定IMSI”后生效。 数据来源：整网规划 取值范围：15位十进制数字字符串 默认值：无                                                                                                                                                                                                                                                                                              |
| USNSELSW  | USN重选开关   | 可选必选说明：必选参数 参数含义：该参数用于指定是否开启USN重选功能。 数据来源：整网规划 取值范围： OFF：关闭ON：开启 默认值：无                                                                                                                                                                                                                                                                                                                                  |
| UERCMEM   | 存储内存占用率阈值 | 可选必选说明：条件可选参数 参数含义：该参数用于指定根据UE无线能力重选USN的内存使用率阈值，UE无线能力长度小于“长度阈值(KB)”的用户在存储UE无线能力内存使用率超过该阈值后开始自动迁移到USN网元。 前提条件：该参数在“USN重选开关”参数配置为“ON(开启)”后生效。 数据来源：整网规划 取值范围：1~100 默认值：无                                                                                                                                                                                                                                 |
| UERCLEN   | 长度阈值(KB)  | 可选必选说明：条件可选参数 参数含义：该参数用于指定根据UE无线能力重选USN的UE无线能力长度， UE无线能力长度小于“长度阈值（KB）”的用户可以迁移到USN网元。 前提条件：该参数在“USN重选开关”参数配置为“ON(开启)”后生效。 数据来源：整网规划 取值范围：1~63 默认值：无                                                                                                                                                                                                                                                      |
| TMMEGPIDX | 目标MME组索引  | 可选必选说明：条件可选参数 参数含义：该参数用于指定根据UE无线能力进行USN选择时的目标MME群组的标识。 前提条件：该参数在“USN重选开关”参数配置为“ON(开启)”后生效。 数据来源：整网规划 取值范围：0~63的整数类型。 默认值：无 配置原则：该参数必须已经在ADD MMEGP配置。                                                                                                                                                                                                                                                    |
| USRTHD    | 迁移用户数百分比  | 可选必选说明：条件可选参数 参数含义：该参数用于指定SPP进程上实时用户数占SPP进程用户规格的百分比阈值，UNC上的用户数百分比低于本阈值后则停止自动迁移，防止USN9810/CloudUSN上用户过载。UNC上的用户数百分比高于本阈值则可以迁移。 前提条件：该参数在“USN重选开关”参数配置为“ON(开启)”后生效。 数据来源：整网规划 取值范围：0~100，0表示所有用户都可以迁移，100表示所有用户都不迁移。 配置原则：该参数需要根据MME POOL中的各个MME的规格配置，并且需要给USN9810/CloudUSN升级预留冗余资源。                                                                                                                      |

#### 使用实例

修改一条“用户范围”为“ALL\_USER(所有用户)”的记录；

```
MOD UERCAPUSNSEL: SUBRANGE=ALL_USER, USNSELSW=ON, UERCMEM=3, UERCLEN=62, TMMEGPIDX=0;
```
