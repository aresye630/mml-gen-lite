# 查询S11接口子网配置 (LST S11INTFSUBNET)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用网元：MME**

此命令用于查询S11或S11-U接口的子网配置。

#### 注意事项

- 无

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                           |
|:-------|:-------|:---------------------------------------------------------------|
| LNKIDX | 链路关联索引 | 可选必选说明：可选参数 参数含义：该参数用于指定本对端IP地址关联索引。 取值范围：0~65534 默认值：无 配置原则：无 |

#### 使用实例

1. 查询关联索引为0的S11接口子网配置，可以用如下命令：

   LST S11INTFSUBNET: LNKIDX=0;

   ```
   %%LST S11INTFSUBNET: LNKIDX=0;%%
   RETCODE = 0  操作成功。

   操作结果如下
   ------------
   链路关联索引  =  0
     远端实例ID  =  12
    S11接口类型  =  S11接口
     IP地址类型  =  IPV4
   本端IPV4地址  =  10.2.3.4
   对端IPV4地址  =  10.2.3.6
       IPV4掩码  =  255.255.255.0
   本端IPV6地址  =  ::
   对端IPV6地址  =  ::
       IPV6掩码  =  0
   (结果个数 = 1)

   ---    END
   ```
