# 显示SDAP实体重启计数(DSP SDAPRSTCNT)

- 注意事项

- 网管用户权限
- 参数说明

#### 命令功能

**适用网元：MME**

本命令用于查询SDAP(Sdup Application Protocol)实体的重启计数。

#### 注意事项

无

#### 本地用户权限

manage-ug；system-ug；monitor-ug；visit-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组；G\_4，来宾级别命令组

#### 参数说明

无。

#### 使用实例

显示SDAP实体重启计数信息：

DSP SDAPRSTCNT:;

#### 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                                           |
|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------|
| RU名称    | 参数含义：该参数用于指定资源单元名称。 取值范围：1~63位字符串                                                                                                               |
| 进程号     | 参数含义：本参数显示SDAP实体所在的SAP进程号。 取值范围：0～20                                                                                                            |
| 重启计数    | 参数含义：本参数显示SDAP实体重启计数。 取值范围：0～255                                                                                                                |
| 文件状态    | 参数含义：本参数显示SDAP实体重启计数存储文件的状态。 若从文件读取结果成功，输出结果为“正常”。 若从文件读取结果失败，输出结果为“异常”。 取值范围：正常异常  说明： 如果“文件状态”是“正常”，表明“重启计数”可信。如果“文件状态”是“异常”，此时“重启计数”会取一个随机值。 |
