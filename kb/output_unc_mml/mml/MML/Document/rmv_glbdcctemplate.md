# 删除计费属性与在线计费模板绑定关系（RMV GLBDCCTEMPLATE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于删除计费属性与在线计费模板的配置绑定关系。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CHARGECHARACT   | 计费属性   | 可选必选说明：必选参数 参数含义：该参数用于指定计费属性类型。 数据来源：本端规划 取值范围：枚举类型。 GLOBAL：指定计费属性为缺省全局计费属性。CHARGE_CHARACT：指定计费属性为配置的特殊计费属性值。 默认值：无 配置原则：无                                                                                   |
| SPECIFICCCVALUE | 计费属性值  | 可选必选说明：条件必选参数 前提条件：该参数在“CHARGECHARACT”配置为“CHARGE_CHARACT”时为必选参数。 参数含义：该参数用于指定特殊计费属性值。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～6。该参数为十六进制数据类型，仅支持输入0x/X、a-f/A-F 、0-9，允许不输入0x前缀，字母不区分大小写，取值范围0x0000~0xFFFF。 默认值：无 配置原则：无 |
| MASK            | 计费属性掩码 | 可选必选说明：条件可选参数 前提条件：该参数在“CHARGECHARACT”配置为“CHARGE_CHARACT”时为可选参数。 参数含义：该参数用于指定计费属性的掩码。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～6。该参数为十六进制数据类型，仅支持输入0x/X、a-f/A-F 、0-9，允许不输入0x前缀，字母不区分大小写，取值范围0x0001~0xFFFF。 默认值：无 配置原则：无 |

#### 使用实例

解除计费属性1314与在线计费模板之间的绑定关系：

```
RMV GLBDCCTEMPLATE:CHARGECHARACT=CHARGE_CHARACT,SPECIFICCCVALUE="0x1314";
```
