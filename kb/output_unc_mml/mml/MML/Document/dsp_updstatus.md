# 显示升级状态（DSP UPDSTATUS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示RU升级状态。

#### 注意事项

RU状态是offline且后台进程正常时，RU升级状态查询结果不是Null。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                   |
|:----------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RUNAME          | RU名称   | 可选必选说明：可选参数 参数含义：该参数用于表示资源单元名称。 数据来源：本端规划 取值范围：1-63位字符串，区分大小写，不支持空格。 默认值：无                                                                                                                                                                                                                                             |
| STATUS          | 状态     | 可选必选说明：可选参数 参数含义：该参数用于表示升级状态。 数据来源：本端规划 取值范围：枚举类型。 On(升级中)：开始升级。Off(升级结束)：结束升级。Null(单板状态未知): 单板状态未知。RollBackStart(回退开始)：无损回退开始。RollBackEnd(回退结束)：无损回退结束。 默认值：无  说明： 当“SERVINCEINSTANCE”参数为“0”时（“0”表示VNFP），该参数仅可配置“RollBackStart”、“RollBackEnd”、“Null”参数值。当“SERVINCEINSTANCE”参数为“0”之外的其他值时，该参数仅可配置“On”、“Off”、“Null”参数值。 |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。                                                                                                                                                                                                           |

#### 使用实例

显示RU升级状态：

```
DSP UPDSTATUS:SERVICEINSTANCE="vnfc";
```

```
RETCODE = 0  操作成功 

结果如下:  
-------------------------  
RU名称                     状态
VNODE_UGW_VNFC_OMU_0001    升级结束
VNODE_UGW_VNFC_OMU_0002    升级结束
VNODE_UGW_VNFC_SPU_0064    升级结束
VNODE_UGW_VNFC_SPU_0065    升级结束
(结果个数 = 4)  
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                                                                                 |
|:--------|:--------------------------------------------------------------------------------------|
| RU名称    | 表示资源单元名称。                                                                             |
| 状态      | 表示升级状态。 升级中：该资源单元正在升级中。升级结束：该资源单元升级已完成。单板状态未知：该资源单元状态未知。无损回退开始：无损回退开始。无损回退结束：无损回退已结束。 |
