# 增加黑名单命令（ADD CMDBLACKLIST）

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

#### 命令功能

**须知** 

本命令属于高危命令，执行后，被添加到命令黑名单的MML命令将无法使用，请谨慎操作。

本命令用于添加一条MML命令到命令黑名单中。

可以通过**LST CMDBLACKLIST**命令查询所有黑名单命令。

#### 注意事项

- 网元ID必须在系统中存在。
- 被添加的黑名单命令必须真实存在。
- 该命令仅限具有Administrators角色的用户可以执行。在扩展域，仅限系统管理员可以执行。
- 执行该命令后，被添加到命令黑名单的命令不允许被执行，执行时会报错：“100112，此命令已被添加到命令黑名单，执行LST CMDBLACKLIST可查看黑名单详情。”。

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                                        |
|:----------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID            | 网元ID   | 可选必选说明：必选参数 参数含义：网元ID。 取值范围：0～65535。 默认值：无。 配置原则：无。                                                                                                                         |
| COMMAND         | 命令名称   | 可选必选说明：必选参数 参数含义：MML命令名称。 取值范围：长度不超过100的英文字符串。 默认值：无。 配置原则：无。                                                                                                               |
| PRECAUTIONID    | 预警号    | 可选必选说明：必选参数 参数含义：预警号（现网出现问题发出的预警文档编号，或者预警申请的PRV编号）。 取值范围：长度不超过100的字符串（一个中文占两个字符）。 默认值：无。 配置原则：不支持逗号（,）、分号（;）、等号（=）、双引号（"）、单引号（'）、两个及以上的百分号（%%）、两个及以上的空格（ ）、mml报文起始符标识（+++）。 |
| SOLUTIONVERSION | 预期解决版本 | 可选必选说明：必选参数 参数含义：预期解决的版本。 取值范围：长度不超过100的字符串（一个中文占两个字符）。 默认值：无。 配置原则：不支持逗号（,）、分号（;）、等号（=）、双引号（"）、单引号（'）、两个及以上的百分号（%%）、两个及以上的空格（ ）、mml报文起始符标识（+++）。                           |

#### 使用实例

新增**LST ME**命令到命令黑名单中：

```
ADD CMDBLACKLIST: MEID=0, COMMAND="LST ME", PRECAUTIONID="1", SOLUTIONVERSION="1";
```

```
%%ADD CMDBLACKLIST: MEID=0, COMMAND="LST ME", PRECAUTIONID="1", SOLUTIONVERSION="1";%%
RETCODE = 0  操作成功

---    END
```
