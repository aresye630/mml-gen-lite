# 删除对端NF实例概述信息（RMV PNFPROFILE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、NSSF、SMSF、NCG、NRF、SGW-C、PGW-C、GGSN、CBC、CBCF**

该命令用于删除本地配置的对端NF实例的概述信息。

## 注意事项

- 该命令执行后立即生效。

- 当NF状态设置不为DeRegistered时，该命令不会删除此NF对应的HTTP链路和地址信息。
- 当NF状态设置为DeRegistered时，此时会删除此NF对应的所有HTTP链路。
- 删除最后一条SCP配置前，命令SET SCPFUNCSW所有记录的间接路由开关和服务发现代理开关需要先关闭。
- 当SMF软参Dword1044 Bit3设置为“0”，且NF类型为UPF时，执行该命令会导致删除对应UPF上的会话。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                |
|:-------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCEID | NF实例标识 | 可选必选说明：必选参数  参数含义：该参数用于指定NF实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~36。NFINSTANCEID参数必须满足以下约束规则：1.如果输入为uuid格式（格式例如：a6a61c6f-0d3a-4221-b1da-424eda3ccf67）只能为A-F、a-f、0-9和“-”的字符。2.如果输入不为uuid格式，长度不能超过18且不允许输入只包含0-9和“.”的字符串，例如：1.2.3.4、不允许输入只包含十六进制数（A-F、a-f、0-9）和“:”的字符串，例如：1::2、FBFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。3.不区分大小写。不支持配置单空格。  默认值：无  配置原则：  割接检查checklist要求以UUID格式配置。如果不为UUID格式，该参数被发送到对端网元且被使用时，可能出现异常。 |

## 使用实例

删除对端SMF实例的概述信息，NF实例标识为SMF\_Instance\_0。

```
RMV PNFPROFILE: NFINSTANCEID="SMF_Instance_0";
```
