# 修改Diameter域路由优先级权重(MOD DMRTPRI)

#### 命令功能

**适用网元：SGSN、MME**

该命令用于修改Diameter域路由优先级和权重，当Diameter域路由配置中“选路模式”是“SELMODE\_MASTER\_SLAVE(主从)”、“SELMODE\_PRIORITY\_WEIGHT(优先级权重)”或者“SELMODE\_IMSI\_PRIORITY(IMSI指定优选)”时，修改域路由中的对端优先级。当Diameter域路由配置中“选路模式”是“SELMODE\_PRIORITY\_WEIGHT(优先级权重)”时，修改域路由中的对端权重。

#### 注意事项

- 该命令执行后立即生效。
- 修改的记录必须要在**ADD DMRT**中添加。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                               |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ROUTEIDX | 路由索引   | 可选必选说明：必选参数 参数含义：该参数用于指定准备修改的Diameter路由索引。 数据来源：本端规划 取值范围：0～2047 默认值：无  说明： 可以通过LST DMRT命令查看已有配置，确认所要修改的Diameter路由的索引。                                                                                                                                             |
| PEERIDX  | 对端实体索引 | 可选必选说明：必选参数 参数含义：该参数用于指定对等端索引，用于标识目的对等端。 前提条件：在“MML命令行-UNC”窗口上执行命令ADD DMPE设置此参数。 数据来源：本端规划 取值范围：0～639 默认值：无  说明： 一个域路由下最多配置16个对端。                                                                                                                                  |
| PRIORITY | 优先级    | 可选必选说明：可选参数 参数含义：该参数用于指定域中对端的优先级。 前提条件：该参数只在ADD DMRT命令中的“选路模式”设置为“SELMODE_MASTER_SLAVE(主从)”、“SELMODE_PRIORITY_WEIGHT(优先级权重)”或者“SELMODE_IMSI_PRIORITY(IMSI指定优选)”时有效。 数据来源：全网规划 取值范围：0~255 默认值：无  说明： “SELMODE_MASTER_SLAVE(主从)”模式下，同一个域路由中不同对端的优先级不允许相同。数值越小，优先级越高。 |
| WEIGHT   | 权重     | 可选必选说明：可选参数 参数含义：该参数用于指定域路由中对端的权重。 前提条件：该参数只在ADD DMRT命令中的“选路模式”设置为“SELMODE_PRIORITY_WEIGHT(优先级权重)”时有效。 数据来源：全网规划 取值范围：1~255 默认值：无                                                                                                                                  |

#### 使用实例

修改Diameter域路由配置中路由索引为“0”，对端实体索引为“1”的优先级为“255”：

MOD DMRTPRI: ROUTEIDX=0, PEERIDX=1, PRIORITY=255;
