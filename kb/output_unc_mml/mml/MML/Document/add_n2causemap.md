# 增加5G N2原因值映射配置（ADD N2CAUSEMAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

配置下发的原因值可能会对终端或无线行为产生影响，该命令必须通过华为研发工程师评审后使用。

**适用NF：AMF**

该命令用于增加5G N2原因值映射配置。原因值映射即为AMF给基站下发的原因值映射成特定原因值。AMF在向基站发送Ue Context Release command时，如果需要对消息中携带的原因值进行修改，使用本命令进行原因值映射修改，控制下发给基站的原因值。

## 注意事项

- 该命令执行后立即生效。

- 该命令必须通过华为研发工程师评审后使用。
- 如果同时存在协议原因值和内部原因值的配置记录，内部原因值的配置记录优先级高于协议原因值的配置记录。
- 最多可输入127条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

增加一个5G N2原因值映射配置，流程类型为初始注册，原始原因值类型为协议原因值，原始原因值组为非接入层，原始原因值为27，目标原因值组为非接入层，目标原因值为50，执行如下命令：

```
ADD N2CAUSEMAP: PROT=INIT_REG, SCAUSETYPE=PROTOCOL_CAUSE, SCAUSEGRP=NAS, SCAUSE=27, TCAUSEGRP=NAS, TCAUSE=50;
```
