# 修改路由策略节点（MOD ROUTEPOLICYNODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改指定路由策略的路由策略节点信息。

#### 注意事项

- 该命令执行后立即生效。
- 配置该命令前，必须已经配置了该节点指定路由策略的名字，必须配置了要修改的节点。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                                |
|:-------------|:---------|:----------------------------------------------------------------------------------------------------|
| POLICYNAME   | 路由策略名字   | 可选必选说明：必选参数 参数含义：该参数用来指定路由策略的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无 配置原则：不支持输入空格，区分大小写。       |
| NODESEQUENCE | 路由策略节点号  | 可选必选说明：必选参数 参数含义：该参数用来指定路由策略的节点序列号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无                         |
| MATCHMODE    | 匹配模式     | 可选必选说明：可选参数 参数含义：该参数用来指定路由策略的匹配模式。 数据来源：本端规划 取值范围：枚举类型。 permit：允许。deny：拒绝。 默认值：无                    |
| DESCRIPTION  | 路由策略节点描述 | 可选必选说明：可选参数 参数含义：该参数用来指定路由策略节点的描述信息。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～80。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。 |

#### 使用实例

修改路由策略a的一个节点属性，节点号为10：

```
MOD ROUTEPOLICYNODE:NODESEQUENCE=10,MATCHMODE=permit,POLICYNAME="a",DESCRIPTION="111";
```
