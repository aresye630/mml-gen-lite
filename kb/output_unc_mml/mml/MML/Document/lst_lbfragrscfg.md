# 查询CSLB分片重组优先级配置（LST LBFRAGRSCFG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询CSLB分片重组优先级配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                       |
|:----------|:-------|:---------------------------------------------------------------------------|
| DSCPVALUE | DSCP值  | 可选必选说明：可选参数 参数含义：该参数用于配置DSCP值。 数据来源：本端规划 取值范围：整数类型，取值范围为0~63。 默认值：无 配置原则：无 |

#### 使用实例

查询CSLB分片重组优先级配置，命令如下：

```
LST LBFRAGRSCFG: DSCPVALUE=0;
```

```
%%LST LBFRAGRSCFG: DSCPVALUE=0;%%
RETCODE = 0  操作成功

操作结果如下：
--------------
DSCP值  =  0
优先级  =  高
(结果个数 = 1)

---    END
```
