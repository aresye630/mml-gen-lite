# 修改NSE属性模板(MOD GBNSECFGPARA)

- 命令功能

#### 命令功能

**适用网元：SGSN**

此命令用于修改NSE属性模板，以制定NSE的属性。

#### 注意事项

- 此命令执行后，参数“信令权重”和“数据权重”要在BSC重新发起动态建链流程后才能对自动配置的NSE生效，其他参数立即生效。
- 该命令部分参数与相关特性license共同完成该特性的开启，请在设置参数前使用**DSP LICENSE**命令确认对应特性license是否得到授权，执行**LST LICENSESWITCH**命令确认特性开关状态为“ENABLE(打开)”，具体相关特性请参考参数的说明。
- 执行本命令修改“PFC（是否支持PFC）”、“CBL（是否支持CBL）”、“INR（是否支持INR）”、“LCS（是否支持LCS）”、“RIM（是否支持RIM）”或者“MOCN（是否支持MOCN）”，SGSN会复位相关SIGBVC信令实体；但是如果这些功能在BSC侧是关闭的，在SGSN侧是开启的，这种情况下在SGSN侧关闭这些功能，SGSN不会复位SIGBVC信令实体。
- 如果修改NSE的任意一个或多个如下参数（“PFC（是否支持PFC）”、“CBL（是否支持CBL）”、“INR（是否支持INR）”、“LCS（是否支持LCS）”、“RIM（是否支持RIM）”）的取值，会导致SGSN主动发起针对该NSE的BVC-RESET流程，导致该NSE下的小区重新上报，引起业务短暂中断。但是如果这些功能在BSC侧是关闭的，在SGSN侧是开启的，这种情况下在SGSN侧关闭这些功能，SGSN不会复位SIGBVC信令实体。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| LCS           | 是否支持LCS             | 可选必选说明：可选参数 参数含义：该参数用于指定本网络服务实体是否支持LCS功能（Location Services）。 数据来源：与对端网元协商 取值范围：“NO(否)”“YES(是)” 默认值：无                                                                                                                                                                                                                                                                                                                                                                                      |
| RIM           | 是否支持RIM             | 可选必选说明：可选参数 参数含义：该参数用于指定本网络服务实体是否支持RIM功能（RAN Information Management）。 数据来源：与对端网元协商 取值范围：“NO(否)”“YES(是)” 默认值：无  说明： 如果NSE此参数的取值发生了改变，除了以下场景外，SGSN都会主动发起针对该NSE的BVC-RESET流程且在给BSC的BVC-RESET PDU中携带该参数值告知BSC。BSC会根据SGSN侧NSE是否支持RIM功能来决定是否将该NSE的RIM消息转发给SGSN。 在以下场景即使此参数取值发生变化SGSN也不会主动发起BVC-RESET流程： BSC侧配置NSE不支持RIM功能，且SGSN侧将该参数的取值由“YES(是)”修改为“NO(否)”。                                                                                                                                      |
| ARP           | 是否携带ARP信元           | 可选必选说明：可选参数 参数含义：该参数用于指定是否在CREATE-BSS-PFC消息中携带ARP（Allocation/Retention Priority）信元。 数据来源：与对端网元协商 取值范围：“NO(否)”“YES(是)” 默认值：无                                                                                                                                                                                                                                                                                                                                                               |
| RACAP         | 是否携带RA Capability信元 | 可选必选说明：可选参数 参数含义：该参数用于指定是否在CREATE-BSS-PFC消息中携带RACAP（RA Capability）信元。 数据来源：与对端网元协商 取值范围：“NO(否)”“YES(是)” 默认值：无                                                                                                                                                                                                                                                                                                                                                                             |
| GB_FLEX       | 是否支持Gb-Flex         | 可选必选说明：可选参数 参数含义：该参数用于指定本网络服务实体是否支持Gb-Flex功能。 数据来源：整网规划 取值范围：“NO(否)”“YES(是)” 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                        |
| SPECSRV       | 是否支持特殊业务类型          | 可选必选说明：可选参数 参数含义：该参数用于指定本网络服务实体是否支持特殊业务类型。 数据来源：与对端网元协商 取值范围：“NO(否)”“YES(是)” 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                        |
| BSSQOSVERSION | BSS支持的Qos版本         | 可选必选说明：可选参数 参数含义：该参数用于指定BSS支持的Qos版本。 数据来源：整网规划 取值范围：“R99(R99)”“R5(R5)” 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                              |

| SW            | 信令权重                | 可选必选说明：可选参数 参数含义：该参数用于指定自动配置的NSE下本端端点的信令权重，通过SNS CONFIG流程通知到BSC侧。在Pool组网下，某些BSC使用这个端点权重在Pool内的各个SGSN之间进行负荷分担。 数据来源：整网规划 取值范围：0～255 默认值：无                                                                                                                                                                                                                                                                                                                                                  |
| DW            | 数据权重                | 可选必选说明：可选参数 参数含义：该参数用于指定自动配置的NSE下本端端点的数据权重，通过SNS CONFIG流程通知到BSC侧。在Pool组网下，某些BSC使用这个端点权重在Pool内的各个SGSN之间进行负荷分担。 数据来源：整网规划 取值范围：0～255 默认值：无                                                                                                                                                                                                                                                                                                                                                  |
| MOCN          | 是否支持MOCN            | 可选必选说明：可选参数 参数含义：该参数用于标识自动配置NSE是否支持MOCN功能。 数据来源：整网规划 取值范围：“NO(否)”“YES(是)” 默认值：无  说明： 当参数设置为“YES(是)”时，“网络共享(MOCN)”特性的相关license授权并开启后，此参数配置才生效（特性编号：WSFD-207001，License部件编码：LKV2MOCN02）。只有BSC、SGSN同时支持MOCN功能时，该功能才会生效。                                                                                                                                                                                                                                                                      |

#### 使用实例

将一个“模板索引”为“0”的NSE属性模板的“FLUSH监控定时器（ms）”改为“100”：

MOD GBNSECFGPARA: PARAINDEX=0, FLUSTHT=100;
