# 查询OSPFv3区域过滤LSA配置（LST OSPFV3AREAFILTER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询OSPFv3区域过滤LSA配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                                                                           |
|:-----------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| PROCID     | OSPFv3进程号 | 可选必选说明：可选参数 参数含义：OSPFv3进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无                                                                       |
| AREAID     | OSPFv3区域号 | 可选必选说明：可选参数 参数含义：OSPFv3区域号。 数据来源：本端规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无                                                                             |
| FILTERTYPE | 过滤方向      | 可选必选说明：可选参数 参数含义：过滤方向。 数据来源：本端规划 取值范围：枚举类型。 import：引入方向的过滤。export：发布方向的过滤。 默认值：无                                                               |
| TYPE       | 过滤类型      | 可选必选说明：可选参数 参数含义：过滤规则类型(ACL名称或ACL号/IP前缀过滤策略名称)。 数据来源：本端规划 取值范围：枚举类型。 acl_name：ACL6名称。ip_prefix：IPv6前缀池列表。route_policy：路由策略。acl_num：ACL号。 默认值：无 |

#### 使用实例

查询OSPFv3区域过滤LSA配置：

```
LST OSPFV3AREAFILTER:;
```

```
RETCODE = 0  操作成功。

结果如下
------------------------
  OSPFv3进程号  =  1
  OSPFv3区域号  =  0.0.0.0
      拓扑标识  =  0
      过滤方向  =  引入方向的过滤
      过滤类型  =  路由策略
ACL名称或ACL号  =  NULL
        IP前缀  =  NULL
  路由策略名称  =  RtPolicy
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称      | 输出项解释                                          |
|:-----------|:-----------------------------------------------|
| OSPFv3进程号  | 该参数指定用户创建的OSPFv3进程号。                           |
| OSPFv3区域号  | 该参数指定用户创建的OSPFv3区域ID。                          |
| 拓扑标识       | 该参数指定用户创建的OSPFv3拓扑标识。                          |
| 过滤方向       | 该参数指定过滤方向，包括引入方向的过滤和发布方向的过滤。                   |
| 过滤类型       | 该参数指定过滤规则类型。                                   |
| ACL名称或ACL号 | 该参数用于指定ACL规则组名称或是编号，当过滤类型为acl_name或acl_num时生效。 |
| IP前缀       | 该参数指定IP前缀过滤策略名称，当过滤类型为ip_prefix时生效。            |
| 路由策略名称     | 该参数指定路由策略名称，当过滤类型为route_policy时生效。             |
