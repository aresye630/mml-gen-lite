# 删除MNC长度信息（RMV MNCLEN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于删除指定MCC号对应的MNC长度。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                      |
|:-------|:-------|:------------------------------------------------------------------------------------------|
| MCC    | 移动国家码  | 可选必选说明：必选参数  参数含义：该参数用于指定移动国家码。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。取值范围000～999。  默认值：无  配置原则：无 |

## 使用实例

删除当前UNC所属的MCC为460：

```
RMV MNCLEN:MCC="460";
```
