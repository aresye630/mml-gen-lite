# 设置RAN侧拥塞检测功能参数(SET SCTPCCTRLPARA)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME、AMF**

该命令用于配置SCTP链路拥塞控制相关参数信息。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称             | 参数说明                                                                                                                                                                                                                                                                                                                                                  |
|:----------------|:-----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CCTRLSW         | 拥塞控制功能           | 可选必选说明：可选参数 参数含义：该参数用于指示是否开启RAN侧SCTP层拥塞控制功能。 数据来源：本端规划 取值范围：“ON(开启)”“OFF(关闭)” 系统初始设置值：“OFF(关闭)”                                                                                                                                                                                                                                                       |
| CCTRLALGTYPE    | 拥塞控制算法           | 可选必选说明：条件可选参数 参数含义：该参数用于指定进行RAN侧SCTP层链路拥塞控制算法。 前提条件：该参数在“CCTRLSW（拥塞控制功能）”配置为“ON(开启)”后生效。 数据来源：本端规划 取值范围： “BBR（BBR拥塞控制算法）” 系统初始设置值：“BBR（BBR拥塞控制算法）” 配置原则：当前仅支持BBR拥塞控制算法并且对S1、N2接口同时生效。  说明： 配置“BBR（BBR拥塞控制算法）”后，SET S1APPARA命令的“CCTRL（拥塞控制功能）”参数控制的CUBIC拥塞控制功能不生效。                                                                                     |
| LOWOVLTHD       | 低优先级消息流控时延（ms）   | 可选必选说明：条件可选参数 参数含义：SCTP缓存中消息积压时延大于低优先级消息流控时延时，低优先级消息会被流控。 前提条件：该参数在“CCTRLSW（拥塞控制功能）”配置为“ON(开启)”且“CCTRLALGTYPE（拥塞控制算法）”配置为“BBR（BBR拥塞控制算法）”后生效。 数据来源：本端规划 取值范围：10~65535 系统初始设置值：300 配置原则：“低优先级消息流控时延（ms）”的配置值应小于“高优先级消息流控时延（ms）”的配置值。                                                                                                                   |
| HIGHOVLTHD      | 高优先级消息流控时延（ms）   | 可选必选说明：条件可选参数 参数含义：SCTP缓存中消息积压时延大于高优先级消息流控时延时，低优先级消息和高优先级消息均会被流控。 前提条件：该参数在“CCTRLSW（拥塞控制功能）”配置为“ON(开启)”且“CCTRLALGTYPE（拥塞控制算法）”配置为“BBR（BBR拥塞控制算法）”后生效。 数据来源：本端规划 取值范围：10~65535 系统初始设置值：450 配置原则：“高优先级消息流控时延（ms）”的配置值应大于“低优先级消息流控时延（ms）”的配置值。                                                                                                           |
| TXCACHEOVLTHD   | 发送缓存过载时延（ms）     | 可选必选说明：条件可选参数 参数含义：SCTP缓存中消息积压时延大于发送缓存过载时延时，该SCTP链路进入拥塞控制状态。 前提条件：该参数在“CCTRLSW（拥塞控制功能）”配置为“ON(开启)”且“CCTRLALGTYPE（拥塞控制算法）”配置为“BBR（BBR拥塞控制算法）”后生效。 数据来源：本端规划 取值范围：10~65535 系统初始设置值：800 配置原则：“发送缓存过载时延（ms）”的配置值应大于“发送缓存过载恢复时延（ms）”的配置值。                                                                                                                  |
| TXCACHEOVLNUM   | 连续过载次数（个）        | 可选必选说明：条件可选参数 参数含义：过载检测周期40ms，当连续过载次数大于此阈值时，进入流控状态。 前提条件：该参数在“CCTRLSW（拥塞控制功能）”配置为“ON(开启)”且“CCTRLALGTYPE（拥塞控制算法）”配置为“BBR（BBR拥塞控制算法）”后生效。 数据来源：本端规划 取值范围：1~255 系统初始设置值：5 配置原则：配置值越小越容易触发BBR拥塞控制流控，配置值越大拥塞控制效果越不明显。                                                                                                                                      |
| TXCACHERESTHD   | 发送缓存过载恢复时延（ms）   | 可选必选说明：条件可选参数 参数含义：SCTP发送缓存消息积压时延小于等于发送缓存过载恢复时延，该SCTP链路恢复正常状态，正常状态持续一段时间（通过“TXCACHENORTIME（发送缓存连续正常状态时长（ms））”参数指定）则退出拥塞控制状态。 前提条件：该参数在“CCTRLSW（拥塞控制功能）”配置为“ON(开启)”且“CCTRLALGTYPE（拥塞控制算法）”配置为“BBR（BBR拥塞控制算法）”后生效。 数据来源：本端规划 取值范围：10~65535 系统初始设置值：300 配置原则：“发送缓存过载恢复时延（ms）”的配置值应小于“发送缓存过载时延（ms）”的配置值。                                                  |
| TXCACHENORTIME  | 发送缓存连续正常状态时长（ms） | 可选必选说明：条件可选参数 参数含义：SCTP发送缓存处于正常状态时长超过此阈值，则退出流控。 前提条件：该参数在“CCTRLSW（拥塞控制功能）”配置为“ON(开启)”且“CCTRLALGTYPE（拥塞控制算法）”配置为“BBR（BBR拥塞控制算法）”后生效。 数据来源：本端规划 取值范围：10~4294967295 系统初始设置值：10000                                                                                                                                                                        |
| TXCACHEOVLPER   | 发送缓存过载比例门限（%）    | 可选必选说明：条件可选参数 参数含义：SCTP发送缓存占用率大于该门限后进入拥塞控制状态，低优先级消息和高优先级消息均会被流控。 前提条件：该参数在“CCTRLSW（拥塞控制功能）”配置为“ON(开启)”且“CCTRLALGTYPE（拥塞控制算法）”配置为“BBR（BBR拥塞控制算法）”后生效。 数据来源：本端规划 取值范围：1~99 系统初始设置值：80 配置原则：“发送缓存过载比例门限（%）”配置值应大于“发送缓存过载恢复比例门限（%）”配置值。                                                                                                                   |
| TXCACHERESPER   | 发送缓存过载恢复比例门限（%）  | 可选必选说明：条件可选参数 参数含义：SCTP发送缓存占用率小于该门限后退出拥塞控制状态。 前提条件：该参数在“CCTRLSW（拥塞控制功能）”配置为“ON(开启)”且“CCTRLALGTYPE（拥塞控制算法）”配置为“BBR（BBR拥塞控制算法）”后生效。 数据来源：本端规划 取值范围：1~99 系统初始设置值：60 配置原则：“发送缓存过载恢复比例门限（%）”配置值应小于“发送缓存过载比例门限（%）”配置值。                                                                                                                                      |
| STARTALARMTIMES | 告警上报周期数          | 可选必选说明：条件可选参数 参数含义：该参数用于设置连续几个1秒周期处于流控态时上报“ALM-80715 RAN侧SCTP层链路拥塞流控”告警。 前提条件：该参数在“CCTRLSW（拥塞控制功能）”配置为“ON(开启)”且“CCTRLALGTYPE（拥塞控制算法）”配置为“BBR（BBR拥塞控制算法）”后生效。 数据来源：本端规划 取值范围：1~60 系统初始设置值：10 配置原则：该参数设置过低会导致稳态运行时因部分基站链路拥塞而频繁触发“ALM-80715 RAN侧SCTP层链路拥塞流控”告警，设置过高会导致链路拥塞后长时间流控而不上报告警。  说明： 软参DWORD_EX_B85 BIT7可控制UNC是否上报“ALM-80715 RAN侧SCTP层链路拥塞流控”告警。 |

#### 使用实例

设置RAN侧拥塞检测功能参数，拥塞控制功能开启、拥塞控制算法为BBR、低优先级消息流控时延为300ms、高优先级消息流控时延为450ms、发送缓存过载时延为800ms、连续过载次数为5个、发送缓存过载恢复时延为300ms、发送缓存连续正常状态时长为10000ms、发送缓存过载比例门限为80%、发送缓存过载恢复比例门限为60%、告警上报周期数为10：

```
SET SCTPCCTRLPARA: CCTRLSW=ON, CCTRLALGTYPE=BBR, LOWOVLTHD=300, HIGHOVLTHD=450, TXCACHEOVLTHD=800, TXCACHEOVLNUM=5, TXCACHERESTHD=300, TXCACHENORTIME=10000, TXCACHEOVLPER=80, TXCACHERESPER=60, STARTALARMTIMES=10;
```
