# 增加基于ARP的DDN消息优先级配置（ADD DDNPRIORITYARP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、SMF**

该命令用于增加基于ARP的DDN消息优先级。

## 注意事项

- 该命令执行后立即生效。

- 该命令用于DDN流控场景下，UNC识别DDN消息的优先级。
- DDN Throttling功能使能时高优先级业务流触发的DDN消息不流控。当用户不配置DDNPRIORITYARP时，则默认为低优先级。

- 最多可输入15条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                            |
|:---------|:-------|:------------------------------------------------------------------------------------------------|
| ARP      | ARP数值  | 可选必选说明：必选参数  参数含义：该参数用于指定ARP。  数据来源：本端规划  取值范围：整数类型，取值范围是1~15。  默认值：无  配置原则：无                   |
| PRIORITY | 优先级    | 可选必选说明：必选参数  参数含义：该参数用于指定DDN消息的优先级。  数据来源：本端规划  取值范围：枚举类型。 DDN_LOW（低）DDN_HIGH（高）  默认值：无  配置原则：无 |

## 使用实例

设置ARP为1的DDN消息是高优先级：

```
ADD DDNPRIORITYARP: ARP=1, PRIORITY=DDN_HIGH;
```
