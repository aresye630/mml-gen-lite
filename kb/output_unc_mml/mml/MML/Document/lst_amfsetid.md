# 查询AMF集与切片的关系（LST AMFSETID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NSSF**

该命令用于查询AMF集所支持的S-NSSAI。

## 注意事项

查询条件都不填时，即查询所有。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识         | 参数名称      | 参数说明                                                                                                                                                                     |
|:-------------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INDEX        | 索引        | 可选必选说明：可选参数  参数含义：该参数用于描述命令的索引值。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无                                                                                 |
| SST          | 切片服务类型    | 可选必选说明：可选参数  参数含义：该参数用于描述切片服务类型。  数据来源：全网规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无                                                                                        |
| SD           | 切片细分标识    | 可选必选说明：可选参数  参数含义：该参数用于表示切片细分标识。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。该参数只能由字母（A-F或者a-f）、数字（0-9）组成。  默认值：无  配置原则：无                                                              |
| MCC          | 移动国家码     | 可选必选说明：可选参数  参数含义：该参数用于描述AmfSetId中移动国家码。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。3位十进制数。  默认值：无  配置原则：无                                                                            |
| MNC          | 移动网号      | 可选必选说明：可选参数  参数含义：该参数用于描述AmfSetId中移动网号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。2位或者3位十进制数。  默认值：无  配置原则：无                                                                     |
| REGIONID     | 区域ID      | 可选必选说明：可选参数  参数含义：该参数用于描述AMF区域ID。  数据来源：全网规划  取值范围：字符串类型，输入长度是2。按照十六进制输入，输入时不带0x，不足两位时需手动从左边补0，取值范围00~ff。  默认值：无  配置原则：无                                                 |
| AMFSETID     | AMF集合标识   | 可选必选说明：可选参数  参数含义：该参数用于描述AMF集合的标识。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。按照十六进制输入，输入时不带0x，不足三位时需手动从左边补0，取值范围000~3ff。  默认值：无  配置原则：无                                              |
| TACGROUPNAME | 跟踪区域码分组名称 | 可选必选说明：可选参数  参数含义：该参数用于描述跟踪区代码分组的名称。 执行此命令前需要通过ADD TACGROUPINNSSF命令将目标TAC配置进跟踪区代码分组，具体操作参考ADD TACGROUPINNSSF命令MML帮助。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无 |
| TAIMCC       | TAI中移动国家码 | 可选必选说明：可选参数  参数含义：该参数用于表示TAI中的移动国家码信息。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。3位十进制数。  默认值：无  配置原则：  多网号场景下，当TAI中MCC与主用PLMN中的MCC不一致时，配置此参数。当不输入该参数时，默认与参数MCC取值一致。                 |
| TAIMNC       | TAI中移动网号  | 可选必选说明：可选参数  参数含义：该参数用于表示TAI中的移动网号信息。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。2位或者3位十进制数。  默认值：无  配置原则：  多网号场景下，当TAI中MNC与主用PLMN中的MNC不一致时，配置此参数。当不输入该参数时，默认与参数MNC取值一致。          |

## 使用实例

若运营商希望查询所有的数据，执行下列命令。

```
LST AMFSETID:;
%%LST AMFSETID:;%%
RETCODE = 0  操作成功

结果如下
------------------------

      切片服务类型  =  1
      切片细分标识  =  010101
    移动国家码  =  460
        移动网号  =  03
            区域ID  =  01
       AMF集合标识  =  001
跟踪区域码分组名称  =  TACGROUP01
	TAI中移动国家码  = 460
	TAI中移动网号  = 03
(结果个数 = 1)

---    END
```
