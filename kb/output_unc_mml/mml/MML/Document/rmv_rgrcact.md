# 删除RG级异常返回码处理动作（RMV RGRCACT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于删除RG级异常返回码的处理动作配置。

## 注意事项

- 该命令执行后立即生效。

- 默认记录不可以删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                         |
|:------------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CCTMPLTNAME | 融合计费模板名称 | 可选必选说明：必选参数  参数含义：该参数用于指定融合计费模板名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。不区分大小写。  默认值：无  配置原则：  该参数使用ADD CCT命令配置生成。                                                                                                                                                                                             |
| RCCODE      | RG级异常返回码 | 可选必选说明：必选参数  参数含义：该参数用于指定RG级异常返回码。  数据来源：全网规划 取值范围： “DEFAULT（缺省值）”：当收到配置指定之外的结果码时需要执行的动作。“SERVICEDENIED（因终端用户限制拒绝服务）”：因为终端用户业务限制而拒绝服务。“QUOTAMNOTAPPL（转离线计费）”：业务不再做配额管理。“QUOTALIMITRCH（配额不足）”：配额不足。“SERVICEREJECT（拒绝服务）”：拒绝服务请求，以终止请求信用的服务。“USERUNKNOWN（未知用户）”：未知用户。“RATINGFAILED（计费失败）”：计费失败。  默认值：无  配置原则：无 |

## 使用实例

删除全局融合计费模板中RG级异常返回码“SERVICEDENIED”的处理动作：

```
RMV RGRCACT: CCTMPLTNAME="global", RCCODE=SERVICEDENIED;
```
