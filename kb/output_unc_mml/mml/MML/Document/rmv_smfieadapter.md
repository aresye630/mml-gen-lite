# 删除信元携带控制配置（RMV SMFIEADAPTER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

执行该命令，可能会导致SMF发送给周边网元的消息中的信元携带有误。

**适用NF：SMF**

该命令用于删除控制SMF与周边网元之间消息中的信元是否携带的配置。

## 注意事项

- 该命令执行后立即生效。

- 在删除某一条配置前，应先使用LST SMFIEADAPTER命令查询需要删除的配置IEADAPTERID，并通过IEADAPTERID删除该配置。
- 当删除信元控制携带配置时，产品会按照默认携带规则携带该信元，具体携带规则请使用命令DSP CURSMFIEADAPTER查询。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                        |
|:------------|:---------|:--------------------------------------------------------------------------------------------|
| IEADAPTERID | 信元控制配置标识 | 可选必选说明：必选参数  参数含义：该参数用于指定信元控制配置的标识。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无 |

## 使用实例

删除当前已有的配置，执行如下命令：

```
RMV SMFIEADAPTER: IEADAPTERID=0;
```
