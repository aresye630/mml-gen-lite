# 设置Log过滤或非抑制开关（SET MSSLOGRULE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

本命令属于高危命令，操作不当会导致性能下降，请谨慎使用并联系华为技术支持协助操作。

该命令用于设置日志过滤和抑制功能，是诊断开关命令；通过开关设置日志过滤和抑制来记录日志信息，协助问题定位；2小时后会自动关闭。

#### 注意事项

- 该命令执行后立即生效。
- 本命令用于使能日志过滤或日志非抑制开关，日志非抑制开启会降低性能，关闭后会恢复性能。开关状态将在2小时后自动恢复。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称            | 参数说明                                                                                                                |
|:-------------|:----------------|:--------------------------------------------------------------------------------------------------------------------|
| RUNAME       | RU名称            | 可选必选说明：必选参数 参数含义：该参数用于表示的RU名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：使用DSP RU查看RU名称。             |
| RULE         | 规则              | 可选必选说明：必选参数 参数含义：该参数用于表示要进行过滤或非抑制功能的设置。 数据来源：本端规划 取值范围：枚举类型。 filter：过滤。unsuppress：非抑制。 默认值：无                        |
| ENABLE       | 开关使能            | 可选必选说明：必选参数 参数含义：该参数用于表示开关使能。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无                                       |
| MODULEID     | 模块ID            | 可选必选说明：可选参数 参数含义：该参数用于表示模块的ID号。如果不输入该参数，则表示匹配向MSS注册日志的所有模块。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无            |
| LEVELID      | 日志级别            | 可选必选说明：可选参数 参数含义：该参数用于表示日志级别。如果不输入该参数，则表示匹配所有日志级别。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                     |
| LOGLEVELTYPE | 某日志级别以上或以下的所有级别 | 可选必选说明：可选参数 参数含义：该参数用于表示某日志级别以上或以下。如果不输入该参数，则表示只匹配指定的日志级别。 数据来源：本端规划 取值范围：枚举类型。 above：某日志级别及以上。below：某日志级别以下。 默认值：无 |

#### 使用实例

设置日志规则：

```
SET MSSLOGRULE: RULE=filter,MODULEID=2,LEVELID=1,LOGLEVELTYPE=above,ENABLE=TRUE,RUNAME="VNODE_VNRS_VNFC_IPU_0064";
```
