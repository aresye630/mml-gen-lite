# 查询OSPF错误LSA的信息（DSP OSPFERRORLSA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询OSPF错误LSA的信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                  |
|:-------|:--------|:------------------------------------------------------------------------------------------------------|
| PROCID | OSPF进程号 | 可选必选说明：可选参数 参数含义：该参数用于表示OSPF进程号，未指定OSPF进程号时默认查询所有OSPF进程。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 |

#### 使用实例

查询OSPF错误LSA的信息：

```
DSP OSPFERRORLSA:PROCID=1;
```
