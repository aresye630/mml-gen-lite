# 删除选路指示器路由（RMV NRFROUTINGINDRT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于删除指定NF类型的选路指示器路由信息。

## 注意事项

- 该命令执行后立即生效。

- 主备或双活组网的场景下，如果需要配置此命令，则两个NRF上均需执行此命令，且配置参数一致。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                             |
|:-----------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------|
| NFTYPE     | NF类型   | 可选必选说明：必选参数  参数含义：该参数用于表示在当前NRF上通过选路指示器路由寻址的NF类型。  数据来源：全网规划 取值范围： UDM（UDM）AUSF（AUSF）  默认值：无  配置原则：  当前NRF仅支持NFTYPE为UDM、AUSF的路由转发功能，其他NF类型为预留功能。 |
| ROUTINGIND | 选路指示器  | 可选必选说明：必选参数  参数含义：该参数用于表示支持ROUTIINGIND号段信息。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~4。取值范围0~9999。  默认值：无  配置原则：无                                         |

## 使用实例

运营商网络为三层组网，最高层PLMN-NRF，中间层H-NRF，最低层L-NRF。L-NRF1归属于H-NRF1，H-HRF1归属于PLMN-NRF。在H-NRF1和PLMN-NRF上分别执行如下命令，删除NF类型为“UDM”，选路指示器为“1111”的路由信息。

```
RMV NRFROUTINGINDRT: NFTYPE=UDM, ROUTINGIND="1111";
```
