# 查询自动弹性策略状态(DSP AUTOSCALEPOLICY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询自动弹性策略状态。

**说明** 

该命令仅在Full-stack裸机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                             |
|:-------|:-------|:-----------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：可选参数。 参数含义：网元ID，可以通过LST ME获取。 取值范围：0～65535 默认值：无。 配置原则：无。 |

## 使用实例

查询自动弹性策略状态：

```
%%DSP AUTOSCALEPOLICY: MEID=0;%% 
RETCODE = 0  操作成功  
操作结果如下 
------------     
弹性策略名称  =  csdb-pod-autopolicy 
弹性策略是否激活  =  是 
弹性策略执行阶段  =  采集
弹性策略执行状态  =  执行中 

 (结果个数 = 1)  ---    END
```

## 输出结果说明

命令执行正常，会返回弹性策略名称、弹性策略是否激活、弹性策略执行阶段和弹性策略执行状态信息，输出结果项信息项目如表1 输出项说明。

命令执行异常，会返回对应的错误码。输出错误码说明如表2所示。

| 输出项名称    | 输出项解释                                                                                   |
|:---------|:----------------------------------------------------------------------------------------|
| 弹性策略名称   | 用于返回查询的弹性策略名称。                                                                          |
| 弹性策略是否激活 | 用于标识弹性策略是否激活。 取值说明： 是：弹性策略激活。否：弹性策略未激活。                                                 |
| 弹性策略执行阶段 | 用于标识该弹性策略对应弹性任务所处阶段。 取值说明： 采集：采集阶段。弹性前检查：弹性前检查阶段。人工确认：人工确认阶段。弹性执行：执行弹性扩缩容任务阶段。NA：任务未启动。 |
| 弹性策略执行状态 | 用于标识该弹性任务不同阶段的执行状态。 取值说明： 执行中：任务正在执行。成功：任务执行成功。失败：任务执行失败。NA：任务未启动，暂无状态。                 |

|    错误码 | 错误码解释           | 原因分析          | 处理建议       |
|-------:|:----------------|:--------------|:-----------|
| 100031 | 命令下发失败、服务接口调用失败 | 调用服务接口失败。     | 请联系华为技术支持。 |
| 150021 | 当前模式不支持此命令      | 仅裸机场景支持该命令。   | 无需处理。      |
| 150042 | 查询自动弹性策略状态失败    | 查询自动弹性策略状态失败。 | 请联系华为技术支持。 |
