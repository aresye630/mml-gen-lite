# 删除HTTP染色配置（RMV HTTPLINKDSCP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除HTTP TCP头中的DSCP字段的染色配置。

## 注意事项

- 该命令执行后立即生效。

- 该命令只支持删除已存在的INDEX染色配置，可通过LST HTTPLINKDSCP查询 。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称           | 参数说明                                                                                         |
|:-------|:---------------|:---------------------------------------------------------------------------------------------|
| INDEX  | HTTPLINKDSCP索引 | 可选必选说明：必选参数  参数含义：该参数用于指定HTTPLINKDSCP的索引信息。  数据来源：本端规划  取值范围：整数类型，取值范围是1~128。  默认值：无  配置原则：无 |

## 使用实例

若需要删除一条索引为1的HTTP染色配置，可以用如下命令：

```
RMV HTTPLINKDSCP: INDEX=1;
```
