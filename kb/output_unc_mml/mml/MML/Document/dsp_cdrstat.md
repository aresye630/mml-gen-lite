#### 命令功能

**适用NF：NCG**

该命令根据所选话单统计操作类型不同用于查询显示话单统计任务的状态或者下发一个话单统计器。当话单统计操作类型选择PROGRESS（进度查询）时根据所选查询话单统计任务类型系统返回相应的话单统计任务状态值，当选择STRCDRSTAT（启动话单统计）时系统根据选择的过滤策略（按接入网元分组、按通道名称和按数据网络名称）提取每用户每会话各个RG的汇总流量信息，通过话单下载界面可获取汇总结果。

#### 注意事项

当话单统计操作类型为STRCDRSTAT（启动话单统计）时：

- 该命令执行后立即生效。
- 该命令允许下发的最大任务数为1。
- 当已存在ADD CDRSTAT话单统计记录后将无法执行DSP CDRSTAT下发话单统计任务。

#### 本地用户权限

manage-ug；

#### 网管用户权限

G\_1，管理员级别命令组；

#### 使用实例

启动话单统计，统计“通道名称”为“CHFCDR”且“数据网络名称”为“huawei.com”的话单信息，配置如下：

```
DSP CDRSTAT: OPTYPE=STRCDRSTAT, CDRSTATID="cdrstat1", AGID="PS1", CHLNAME="CHFCDR", DNN="huawei.com", CDRSTARTTIME=2025&09&02&11&56&24, CDRENDTIME=2025&09&04&11&56&23, STARTTIME=12&06, ENDTIME=13&00, ANONYMITY=OFF;
```

#### 输出结果说明

| 输出项名称    | 输出项解释                  |
|:---------|:-----------------------|
| 接入网元分组标识 | 表示当前统计任务的接入分组标识。       |
| RU的ID    | 表示当前统计任务的RU ID。        |
| 当前统计文件名  | 表示当前统计任务正在处理的文件名。      |
| 文件修改时间   | 表示当前统计任务正在处理文件的修改时间。   |
| 话单统计状态   | 表示当前统计任务的状态。 待启动进行中已完成 |

其余输出项请参见显示话单统计信息（DSP CDRSTAT）的参数说明。
