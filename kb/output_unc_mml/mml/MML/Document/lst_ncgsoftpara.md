# 查询NCG软参（LST NCGSOFTPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NCG**

该命令用于查询NCG的软件参数信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                            |
|:----------|:---------|:----------------------------------------------------------------------------------------------------------------|
| DT        | 数据类型     | 可选必选说明：必选参数  参数含义：该参数表示软件参数的数据类型。  数据来源：本端规划 取值范围： Dw（双字）Bit（比特）Byte（字节）String（字符串）  默认值：无  配置原则：无              |
| DWORDNUM  | Dword索引  | 可选必选说明：该参数在"DT"配置为"Dw"时为条件可选参数。  参数含义：该参数表示Dword类型软件参数的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~1500。  默认值：无  配置原则：无    |
| BITNUM    | Bit索引    | 可选必选说明：该参数在"DT"配置为"Bit"时为条件可选参数。  参数含义：该参数表示Bit类型软件参数的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~4000。  默认值：无  配置原则：无     |
| BYTENUM   | Byte索引   | 可选必选说明：该参数在"DT"配置为"Byte"时为条件可选参数。  参数含义：该参数表示Byte类型软件参数的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~1200。  默认值：无  配置原则：无   |
| STRINGNUM | String索引 | 可选必选说明：该参数在"DT"配置为"String"时为条件可选参数。  参数含义：该参数表示String类型软件参数的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~30。  默认值：无  配置原则：无 |

## 使用实例

- 查询NCG软件参数，数据类型是“Dw”，Dword索引是“1”

  ```
  LST NCGSOFTPARA: DT=Dw, DWORDNUM=1;
  RETCODE = 0  执行成功

  操作结果如下:
  -------------------------
       数据类型  =  双字
   软参记录索引  =  1
     软参记录值  =  3
  (结果个数 = 1)

  ---    END
  ```
- 查询NCG软件参数，数据类型是“Bit”，Bit索引是“1”

## 输出结果说明

| 输出项名称   | 输出项解释           |
|:--------|:----------------|
| 数据类型    | 该参数表示软件参数的数据类型。 |
| 软参记录索引  | 该参数表示软件参数的索引。   |
| 软参记录值   | 该参数表示软件参数的值。    |
