# 设置软件参数表比特位(SET SOFTPARAOFBIT)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限

- 使用实例

#### 命令功能

**须知** 

请参考软件参数说明书。

**适用网元：SGSN、MME**

该命令用于设置软件参数表比特位。

在设置产品功能开关或者流程开关时，需要执行此命令。

#### 注意事项

- 系统初次上电运行时，会执行系统初始设置值。
- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                        |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DT       | 参数类型   | 可选必选说明：必选参数 参数含义：软件参数的数据类型。 数据来源：本端规划 取值范围：“BYTE（单字节类型）”“DWORD（无符号整数类型）”“BYTE_EX（扩展单字节类型）”“DWORD_EX（扩展无符号整数类型）”“BYTE_EX_B（扩展单字节类型B）”“DWORD_EX_B（扩展无符号整数类型B）” 系统初始设置值：无                                                                                                                      |
| PARANUM  | 参数索引   | 可选必选说明：必选参数 参数含义：软件参数的索引。 数据来源：本端规划 取值范围：1~512 系统初始设置值：无 配置原则：当参数类型取值为“BYTE”时，参数索引的取值范围是“1~240”。当参数类型取值为“DWORD”时，参数索引的取值范围是“1~60”。当参数类型取值为“BYTE_EX”时，参数索引的取值范围是“1~224”。当参数类型取值为“DWORD_EX”时，参数索引的取值范围是“1~56”。当参数类型取值为“BYTE_EX_B”时，参数索引的取值范围是“1~464”。当参数类型取值为“DWORD_EX_B”时，参数索引的取值范围是“1~116”。 |
| VALUE    | 参数值    | 可选必选说明：必选参数 参数含义：软件参数比特位的值。 数据来源：本端规划 取值范围：VALUE_0(0)VALUE_1(1) 系统初始设置值：无                                                                                                                                                                                                                   |
| POSITION | 比特位    | 可选必选说明：必选参数 参数含义：软件参数比特位的位置。 数据来源：本端规划 取值范围：1~32 系统初始设置值：无 配置原则：当参数类型取值为“BYTE”，“BYTE_EX”或“BYTE_EX_B”时，比特位的取值范围是“1~8”。当参数类型取值为“DWORD”，“DWORD_EX”或“DWORD_EX_B”时，比特位的取值范围是“1~32”。                                                                                                              |

#### 使用实例

设置单字节类型1号软参Bit1值为0:

SET SOFTPARAOFBIT: DT=BYTE, PARANUM=1, VALUE=VALUE\_0, POSITION=1;
