# 查询指定归属地SMF实例标识（LST HOMESMFINSTID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF**

该命令用于在对接归属地SMF时，查询指定用户接入的SMF实例标识。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                            |
|:---------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：可选参数  参数含义：该参数用于指定用户范围。  数据来源：本端规划 取值范围： IMSI_PRE（IMSI前缀）MSISDN_PRE（MSISDN前缀）  默认值：无  配置原则：  IMSI_PRE和MSISDN_PRE记录的优先级受SET PROXYSMFFUNC命令中的QUERYTYPE参数控制。                                |
| PREFIX   | 前缀     | 可选必选说明：可选参数  参数含义：该参数用于指定用户号码前缀。当参数SUBRANGE为"IMSI_PRE"时，本参数表示IMSI号码前缀，当参数SUBRANGE为"MSISDN_PRE"时，本参数表示MSISDN号码前缀。使用时按照最长匹配进行查询。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~15。  默认值：无  配置原则：  取值范围为1~15位数字。 |

## 使用实例

假设运营商需要查询一个SUBRANGE为“IMSI\_PRE”、PREFIX为“3080107000”的HOMESMFINSTID配置。

```
LST HOMESMFINSTID:SUBRANGE=IMSI_PRE,PREFIX="3080107000";
```
