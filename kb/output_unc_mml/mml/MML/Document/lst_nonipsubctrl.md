# 查询Non-IP APNNI配置(LST NONIPSUBCTRL)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明

- 输出结果说明

#### 命令功能

**适用网元：MME**

该命令用于查询Non-IP APNNI配置。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                     |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：可选参数 参数含义：该参数用于指定配置生效的用户范围。 数据来源：全网规划 取值范围：“ALL_USER（所有用户）”“IMSI_PREFIX（指定IMSI前缀）” 默认值：无                          |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件可选参数 参数含义：该参数用于指定IMSI前缀以区分不同的用户群。 前提条件：该参数在“用户范围”参数配置为“IMSI_PREFIX”时，该参数才有效。 数据来源：全网规划 取值范围：1～15位十进制数字字符串 默认值：无 |

#### 使用实例

查询所有Non-IP APNNI的配置：

`LST NONIPSUBCTRL:;`

```
%%LST NONIPSUBCTRL:;%%
RETCODE = 0  操作成功。

输出结果如下
-------------------------
         用户范围  =  所有用户
         IMSI前缀  =  NULL
支持Non-IP的APNNI  =  所有APNNI
        APNNI组号  =  NULL
        缺省APNNI  =  NULL
(结果个数 = 1)

---    END
```
