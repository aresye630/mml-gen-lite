# 删除性能对象规则(RMV PERFOBJRULE)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

本命令用于删除特定对象的统计规则，当前仅支持TAI组规则。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                                                                                                                                                                       |
|:-------------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MOC          | 测量对象类型   | 可选必选说明：必选参数 参数含义：待删除规则的测量统计对象类型。 取值范围：“TAIGP(TAI组)” 默认值：无                                                                                                                                                                                  |
| TAIGPRULEIDX | TAI组规则索引 | 可选必选说明：条件必选参数 参数含义：待删除的TAI组规则的索引。 前提条件：该参数在“MOC(测量对象类型)”参数设置为“TAIGP(TAI组)”时，才需要配置。 取值范围：1~1500 默认值：无 配置原则：TAI组规则索引，可以通过LST PERFOBJRULE命令查询。  说明： 执行删除规则操作后，符合该规则的当前系统存在的TAI，将会增加为自动统计的TAI对象。系统最多能支持1500个TAI组对象的统计，当自动统计的TAI对象超出该规格后，将无法添加。 |

#### 使用实例

删除规则索引为1的TAI组规则：

RMV PERFOBJRULE: MOC=TAIGP, TAIGPRULEIDX=1;
