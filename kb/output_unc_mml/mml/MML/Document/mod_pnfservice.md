# 修改对端NF服务实例信息（MOD PNFSERVICE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、NSSF、SMSF、NCG、CBC、CBCF**

该命令用于修改本地配置的对端NF实例支持的服务实例信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

修改对端NF的服务实例信息，NF实例标识为SMF\_Instance\_0，服务实例标识为Service\_Instance\_0，服务名为NsmfPduSes，支持的协议为http。

```
MOD PNFSERVICE: NFINSTANCEID="SMF_Instance_0", SRVINSTANCEID="Service_Instance_0", SERVICENAME=NsmfPduSes, SCHEMA=http, NFSERVICESTATUS=REGISTERED;
```
