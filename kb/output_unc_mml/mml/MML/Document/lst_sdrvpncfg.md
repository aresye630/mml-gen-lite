# 查询SDR VPN配置信息（LST SDRVPNCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

查询SDR写在ACS数据库的VPN配置信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

使用如下命令查询SDR VPN配置信息：

```
%%LST SDRVPNCFG:;%%
RETCODE = 0  操作成功

结果如下
--------
VPN名  =  vpna
VPN索引  =  1
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释   |
|:--------|:--------|
| VPN名    | VPN名称。  |
| VPN索引   | VPN索引。  |
