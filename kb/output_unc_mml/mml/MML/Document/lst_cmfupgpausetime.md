# 查询灰度升级拨测发布暂停时长（LST CMFUPGPAUSETIME）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询在灰度升级拨测发布暂停期间，进程就绪超时时长。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询灰度升级拨测发布暂停时长。

```
%%LST CMFUPGPAUSETIME:;%%
RETCODE = 0  操作成功

结果如下
--------
灰度升级拨测发布暂停时长  =  180
(结果个数 = 1)
```

## 输出结果说明

| 输出项名称        | 输出项解释                         |
|:-------------|:------------------------------|
| 灰度升级拨测发布暂停时长 | 该参数用于设置灰度升级拨测发布暂停期间，进程就绪超时时长。 |
