#### 命令功能

**适用网元：SGSN**

该命令用于修改NSE网络服务实体参数。信令实体分别位于BSS侧和SGSN侧，用于提供GB接口操作所需的网络管理功能。请参考3GPP TS 48.016。

#### 注意事项

- 该命令部分参数与相关特性license共同完成该特性的开启，请在设置参数前使用**DSP LICENSE**命令确认对应特性license是否得到授权，执行**LST LICENSESWITCH**命令确认特性开关状态为“ENABLE(打开)”，具体相关特性请参考参数的说明。
- 执行本命令修改“PFC（是否支持PFC）”、“CBL（是否支持CBL）”、“INR（是否支持INR）”、“LCS（是否支持LCS）”、“RIM（是否支持RIM）”或者“MOCN（是否支持MOCN）”，SGSN会复位该SIGBVC信令实体；但是如果这些功能在BSC侧是关闭的，在SGSN侧是开启的，这种情况下在SGSN侧关闭这些功能，SGSN不会复位SIGBVC信令实体。
- 如果修改NSE的任意一个或多个如下参数（“PFC（是否支持PFC）”、“CBL（是否支持CBL）”、“INR（是否支持INR）”、“LCS（是否支持LCS）”、“RIM（是否支持RIM）”）的取值，会导致SGSN主动发起针对该NSE的BVC-RESET流程，导致该NSE下的小区重新上报，引起业务短暂中断。但是如果这些功能在BSC侧是关闭的，在SGSN侧是开启的，这种情况下在SGSN侧关闭这些功能，SGSN不会复位SIGBVC信令实体。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称                | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
|:--------------|:--------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SGSNINDEX     | SGSN索引              | 可选必选说明：可选参数 参数含义：该参数用于指定SGSN索引。 数据来源：整网规划 取值范围：0 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                               |
| NSEI          | NSE标识               | 可选必选说明：必选参数 参数含义：该参数用于指定网络服务实体标识。 数据来源：整网规划 取值范围：0～65535 默认值：无  说明： 和PCU侧取值保持一致，此标识符在SGSN范围内唯一，不能重复。                                                                                                                                                                                                                                                                                                                                                                                 |
| BSSID         | BSS编号               | 可选必选说明：可选参数 参数含义：该参数用于指定BSS的编号。 数据来源：整网规划 取值范围：0～65534 默认值：无  说明： 编号任意指定，但是同一个BSS编号下所有NSE的“是否支持Gb-Flex”属性配置必须一致。                                                                                                                                                                                                                                                                                                                                                                     |
| FLUSTHT       | FLUSH监控定时器（ms）      | 可选必选说明：可选参数 参数含义：该参数用于指定FLUSH监控定时器的时长，为SGSN发送FLUSH LL后等待FLUSH LL ACK的超时时长。 数据来源：整网规划 取值范围：50ms～2000ms 默认值：无 配置原则：建议值为50ms。  说明： 为了保证用户体验，这个值不要设得太大，一般情况下使用默认参数50。小区更新包括2G小区间切换和2G到3G小区间的切换，两种场景SGSN都会向原小区下发Flush LL。如果Flush LL没有正常下发，2G无线侧则判断TBF建链失败。                                                                                                                                                                                                                                |
| PFC           | 是否支持PFC             | 可选必选说明：可选参数 参数含义：该参数用于标识本网络服务实体是否支持PFC流程（Packet Flow Context procedure），参考协议3GPP TS 48.018。 数据来源：与对端网元协商 取值范围：“NO(否)”“YES(是)” 默认值：无 配置原则：建议值为“YES(是)”。  说明： 如果本端NSE支持PFC，并且BSC的NSE也支持PFC，则PFC流程才可以得到支持；如果BSC支持PFC，则本端SGSN的NSE配置必须要支持PFC；若BSC不支持PFC，则本端是否支持都可以。当参数设置为“YES(是)”时，“PFC(仅用于Gb模式)”特性的相关license授权并开启后，此参数配置才生效（特性编号：WSFD-105101，License部件编码：LKV2PFC02）。                                                                                                                     |
| CBL           | 是否支持CBL             | 可选必选说明：可选参数 参数含义：该参数用于标识本网络服务实体是否支持CBL功能（Current Bucket Level），参考协议3GPP TS 48.018。 数据来源：与对端网元协商 取值范围：“NO(否)”“YES(是)” 默认值：无 配置原则：建议值为“YES(是)”。                                                                                                                                                                                                                                                                                                                                        |
| INR           | 是否支持INR             | 可选必选说明：可选参数 参数含义：该参数用于标识本网络服务实体是否支持INR功能（Inter-NSE re-routing），参考协议3GPP TS 48.018。 数据来源：与对端网元协商 取值范围：“NO(否)”“YES(是)” 默认值：无 配置原则：建议值为“YES(是)”。                                                                                                                                                                                                                                                                                                                                        |
| LCS           | 是否支持LCS             | 可选必选说明：可选参数 参数含义：该参数用于标识本网络服务实体是否支持LCS功能（Location Services），参考协议3GPP TS 48.018。 数据来源：与对端网元协商 取值范围：“NO(否)”“YES(是)” 默认值：无 配置原则：建议值为“NO(否)”。                                                                                                                                                                                                                                                                                                                                            |
| RIM           | 是否支持RIM             | 可选必选说明：可选参数 参数含义：该参数用于标识本网络服务实体是否支持RIM功能（RAN Information Management），参考协议3GPP TS 48.018。 数据来源：与对端网元协商 取值范围：“NO(否)”“YES(是)” 默认值：无 配置原则：建议值为“NO(否)”。  说明： 当参数设置为“YES(是)”时，“NACC”特性的相关license授权并开启后，此参数配置才生效（特性编号：WSFD-104406，License部件编码：LKV2NACC02）。如果NSE此参数的取值发生了改变，除了以下场景外，SGSN都会主动发起针对该NSE的BVC-RESET流程且在给BSC的BVC-RESET PDU中携带该参数值告知BSC。BSC会根据SGSN侧NSE是否支持RIM功能来决定是否将该NSE的RIM消息转发给SGSN。 在以下场景即使此参数取值发生变化SGSN也不会主动发起BVC-RESET流程： BSC侧配置NSE不支持RIM功能，且SGSN侧将该参数的取值由“YES(是)”修改为“NO(否)”。 |
| OTHERNODE     | NSE连接方向             | 可选必选说明：可选参数 参数含义：该参数用于指定该NSE所连接的对端局点的名字。 数据来源：整网规划 长度范围：1～29位字符串 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                               |
| ARP           | 是否携带ARP信元           | 可选必选说明：条件可选参数 参数含义：该参数用于判断是否在CREATE-BSS-PFC消息中携带ARP（Allocation/Retention Priority）信元。 前提条件：该参数在参数“是否支持PFC”配置为“YES（是）”时生效。 数据来源：与对端网元协商 取值范围：“NO(否)”“YES(是)” 默认值：无 配置原则：建议值为“NO(否)”。                                                                                                                                                                                                                                                                                                  |
| RACAP         | 是否携带RA Capability信元 | 可选必选说明：条件可选参数 参数含义：该参数用于判断是否在CREATE-BSS-PFC消息中携带RACAP（RA Capability）信元。 前提条件：该参数在参数“是否支持PFC”配置为“YES（是）”时生效。 数据来源：与对端网元协商 取值范围：“NO(否)”“YES(是)” 默认值：无 配置原则：建议值为“NO(否)”。                                                                                                                                                                                                                                                                                                                |
| GB_FLEX       | 是否支持Gb-Flex         | 可选必选说明：可选参数 参数含义：标识本网络服务实体是否支持Gb-Flex功能。 数据来源：整网规划 取值范围：“NO(否)”“YES(是)” 默认值：无 配置原则：建议值为“NO(否)”。  说明： 当参数设置为“YES(是)”时，“Gb-flex”特性的相关license授权并开启后，此参数配置才生效（特性编号：WSFD-104204，License部件编码：LKV2GBFLEX02）。                                                                                                                                                                                                                                                                                |
| SPECSRV       | 是否支持特殊业务类型          | 可选必选说明：可选参数 参数含义：该参数用于标识本网络服务实体是否支持特殊业务类型。 数据来源：与对端网元协商 取值范围：“NO(否)”“YES(是)” 默认值：无 配置原则：建议值为“NO(否)”。  说明： 在该开关打开的情况下，BSSGP协议层会增加一个信元service-class-indicator，如果对端不支持该信元则会出现无法解析或丢包的情况。                                                                                                                                                                                                                                                                                                |
| BSSQOSVERSION | BSS支持的Qos版本         | 可选必选说明：可选参数 参数含义：该参数用于标识BSS支持的QoS版本。 数据来源：整网规划 取值范围：“R99(R99)”“R5(R5)” 默认值：无 配置原则：建议值为“R99(R99)”。  说明： BSSID编号相同记录的QoS要配置相同。                                                                                                                                                                                                                                                                                                                                                         |
| MOCN          | 是否支持MOCN            | 可选必选说明：可选参数 参数含义：该参数用于标识手动配置NSE是否支持MOCN功能。 数据来源：整网规划 取值范围：“NO(否)”“YES(是)” 默认值：无  说明： 当参数设置为“YES(是)”时，“网络共享(MOCN)”特性的相关license授权并开启后，此参数配置才生效（特性编号：WSFD-207001，License部件编码：LKV2MOCN02）。只有BSC、SGSN同时支持MOCN功能时，该功能才会生效。                                                                                                                                                                                                                                                                 |
| SPID          | 是否支持SPID            | 可选必选说明：可选参数 参数含义：该参数用于指定向BSS发送的消息中是否携带SPID。 数据来源：与对端网元协商 取值范围：“NO(否)”“YES(是)” 默认值：无  说明： SPID信元，是在3GPP TS R8 48.018协议引入的，由于无线侧设备可能是低协议版本的设备，提供此功能开关避免启用SPID功能时对无线侧设备产生接口兼容性影响。                                                                                                                                                                                                                                                                                                       |

#### 使用实例

修改NSEI为10的NSE，使BSSID为1，FLUSH监控定时器为1000，支持PFC，CBL，INR和MOCN，携带ARP信元、携带RACAP信元，支持特殊业务类型，BSS支持的QoS版本为R5：

MOD NSE: NSEI=10, BSSID=1, FLUSTHT=1000, PFC=YES, CBL=YES, INR=YES, ARP=YES, RACAP=YES, SPECSRV=YES, BSSQOSVERSION=R5, MOCN=YES;
