# 删除AMF容灾网元剩余容量信息（RMV FTTNFCAPINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令仅在调测场景下，用于删除AMF POOL内其它AMF网元的剩余容量信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                                                                                               |
|:-------------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCEID | AMF实例标识 | 可选必选说明：必选参数  参数含义：该参数用于在UNC系统中唯一指定某个AMF实例。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~36。可输入的字符有字母A～Z或a～z、数字0～9、中划线"-"和下划线"_"，例如，AMF_Instance_0，不区分大小写。  默认值：无  配置原则：无                                        |
| RESTYPE      | 资源类型    | 可选必选说明：必选参数  参数含义：本参数用于指定资源类型。  数据来源：本端规划 取值范围： “CPURES（CPU资源）”：CPU资源  默认值：无  配置原则：无                                                                                                               |
| RESNAME      | 资源名称    | 可选必选说明：必选参数  参数含义：本参数用于指定资源名称，如果资源类型为CPU则对应节点（VM或POD）名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~100。  默认值：无  配置原则：  如果资源类型为CPU则对应的资源名称为：虚机类型，例如PBU_C-A；裸机类型，如usn-pod。可以通过DSP NODE（虚机类型）或者DSP POD（裸机类型）查询。 |

## 使用实例

为NF Instance ID为Amf\_Instance\_1的网元删除VM为PBU\_C-A的CPU剩余容量的配置，执行如下命令：

```
RMV FTTNFCAPINFO: NFINSTANCEID="Amf_Instance_1", RESTYPE=CPURES, RESNAME="PBU_C-A";
```
