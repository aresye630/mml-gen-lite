# 设置流控队列信息(SET FLOWCTRLQUE)

- 命令功能
- 注意事项
- 本地用户权限

- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于设置不同业务类型的流控队列信息。

#### 注意事项

- 系统初次运行时，会执行系统初始设置值。
- 设置流控参数，设置不当会导致流控丢包，影响系统业务成功率。
- 此命令需要华为技术支持人员指导下才能执行，请慎重使用。

#### 本地用户权限

manage-ug;system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                   |
|:----------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APPTYPE   | 业务类型   | 可选必选说明： 必选参数 参数含义：该参数用于指定业务类型。 数据来源：整网规划 取值范围：“APP_2G(2G)”：表示2G业务类型。“APP_3G(3G)”：表示3G业务类型。“APP_4G(4G)”：表示4G业务类型。 系统初始设置值：见表1                                                                                                                                                                           |
| MSG2GTYPE | 2G消息类型 | 可选必选说明：条件必选参数 参数含义：该参数用于指定2G消息类型。 前提条件：该参数在“业务类型”参数配置为“APP_2G(2G)”后生效。 数据来源：整网规划 取值范围：“ATTACH(ATTACH)”：表示附着消息。“RAU(RAU)”：表示路由区更新消息。“PDP_ACT(PDP_ACT)”：表示激活消息。 系统初始设置值：见表1                                                                                                                              |
| MSG3GTYPE | 3G消息类型 | 可选必选说明：条件必选参数 参数含义：该参数用于指定3G消息类型。 前提条件：该参数在“业务类型”参数配置为“APP_3G(3G)”后生效。 数据来源：整网规划 取值范围：“ATTACH(ATTACH)”：表示附着消息。“RAU(RAU)”：表示路由区更新消息。“PDP_ACT(PDP_ACT)”：表示激活消息。“SERVICE_REQ(SERVICE_REQ)”：表示服务请求消息。 系统初始设置值：见表1                                                                                          |
| MSG4GTYPE | 4G消息类型 | 可选必选说明：条件必选参数 参数含义：该参数用于指定4G消息类型。 前提条件：该参数在“业务类型”参数配置为“APP_4G(4G)”后生效。 数据来源：整网规划 取值范围：“ATTACH(ATTACH)”：表示附着消息。“TAU(TAU)”：表示跟踪区更新消息。“SERVICE_REQ(SERVICE_REQ)”：表示服务请求消息。“ENCRYPT(ENCRYPT)”：表示加密消息。“EMM_VIP(EMM_VIP)”：表示VIP消息。“EMM_EMGC(EMM_EMGC)”：表示紧急呼叫消息。“EMM_VOICE(EMM_VOICE)”：表示4G语音消息。 系统初始设置值：见表1 |
| WEIGHT    | 业务权重   | 可选必选说明：条件必选参数 参数含义：该参数用于指定业务权重。 前提条件：该参数在“业务类型”参数配置为“APP_2G(2G)”后生效。该参数在“业务类型”参数配置为“APP_3G(3G)”后生效。该参数在“业务类型”参数配置为“APP_4G(4G)”后生效。 数据来源：整网规划 取值范围：0-100 系统初始设置值：见表1 配置原则：推荐系统初始设置值，如需修改，请联系华为技术支持。 说明： 此配置决定了流控消息队列每个调度周期的调度次数，数值越大表示被调度的次数越多。                                                         |
| QUELENTH  | 队列期望长度 | 可选必选说明：条件必选参数 参数含义：队列期望长度指不同业务类型流控消息队列的期望长度。该参数用于指定队列期望长度。 前提条件：该参数在“业务类型”参数配置为“APP_2G(2G)”后生效。该参数在“业务类型”参数配置为“APP_3G(3G)”后生效。该参数在“业务类型”参数配置为“APP_4G(4G)”后生效。 数据来源：整网规划 取值范围：0-10000 系统初始设置值：见表1 配置原则：推荐系统初始设置值，如需修改，请联系华为技术支持。                                                                        |

#### 使用实例

设置流控队列信息，业务类型为2G，消息类型为附着，业务权重数为2，队列期望长度是400：

SET FLOWCTRLQUE: APPTYPE=APP\_2G, MSG2GTYPE=ATTACH, WEIGHT=2, QUELENTH=400;

推荐系统初始设置值，如需修改，请联系华为技术支持。
