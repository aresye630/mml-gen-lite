# 设置流量控制缓存配置(SET FLOWCTRLBUF)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用于修改BSSGP流控缓存参数配置。

#### 注意事项

- 系统初次运行时，会执行系统初始设置值。
- 该命令执行后立即生效。
- 该命令需要华为技术支持人员指导下才能执行，请慎重使用。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称         | 参数说明                                                                                           |
|:-----------|:-------------|:-----------------------------------------------------------------------------------------------|
| MSSIGQL    | MS信令队列最大长度   | 可选必选说明：可选参数 参数含义：该参数用于设置MS信令队列最大长度，表示MS信令队列的最大节点数。 数据来源：整网规划 取值范围：1～32 系统初始设置值：32              |
| MSDATQL    | MS数据队列最大长度   | 可选必选说明：可选参数 参数含义：该参数用于设置MS数据队列最大长度，表示MS数据队列的最大节点数。 数据来源：整网规划 取值范围：1～512 系统初始设置值：512            |
| MSCONTHD   | MS拥塞门限（%）    | 可选必选说明：可选参数 参数含义：该参数用于设置MS拥塞门限。 数据来源：整网规划 取值范围：1～100 系统初始设置值：80 配置原则：该参数的取值一定要大于“MSCONRTHD”。   |
| MSCONRTHD  | MS拥塞恢复门限（%）  | 可选必选说明：可选参数 参数含义：该参数用于设置MS拥塞恢复门限。 数据来源：整网规划 取值范围：0～99 系统初始设置值：60 配置原则：该参数的取值一定要小于“MSCONTHD”。   |
| BVCSIGQL   | BVC信令队列最大长度  | 可选必选说明：可选参数 参数含义：该参数用于设置BVC信令队列最大长度，表示BVC信令队列的最大节点数。 数据来源：整网规划 取值范围：1～384 系统初始设置值：384          |
| BVCDATQL   | BVC数据队列最大长度  | 可选必选说明：可选参数 参数含义：该参数用于设置BVC数据队列最大长度，表示BVC数据队列的最大节点数。 数据来源：整网规划 取值范围：1～1536 系统初始设置值：1536        |
| BVCCONTHD  | BVC拥塞门限（%）   | 可选必选说明：可选参数 参数含义：该参数用于设置BVC拥塞门限。 数据来源：整网规划 取值范围：1～100 系统初始设置值：80 配置原则：该参数的取值一定要大于“BVCCONRTHD”。 |
| BVCCONRTHD | BVC拥塞恢复门限（%） | 可选必选说明：可选参数 参数含义：该参数用于设置BVC拥塞恢复门限。 数据来源：整网规划 取值范围：0～99 系统初始设置值：60 配置原则：该参数的取值一定要小于“BVCCONTHD”。 |

#### 使用实例

修改BSSGP流控缓存配置：

SET FLOWCTRLBUF: MSSIGQL=16, MSDATQL=100, MSCONTHD=60, MSCONRTHD=50, BVCSIGQL=200, BVCDATQL=500, BVCCONTHD=60, BVCCONRTHD=50;
