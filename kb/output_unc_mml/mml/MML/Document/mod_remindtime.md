# 修改证书到期提醒时间（MOD REMINDTIME）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于修改系统内所有证书到期提醒时间。证书即将到期时会产生ALM-5541 证书过期告警、ALM-136051 证书过期重要告警、ALM-136052 证书过期次要告警或ALM-136056 证书过期提示告警等告警，可在OM Portal菜单“安全>证书管理”中更换证书。

## 注意事项

该命令存在系统初始记录，参数REMINDTIME (证书到期提醒时间（天）)的初始设定值为180。

## 参数说明

| 参数标识       | 参数名称        | 参数说明                                                   |
|:-----------|:------------|:-------------------------------------------------------|
| REMINDTIME | 证书到期提醒时间（天） | 可选必选说明：必选参数 参数含义：证书到期提醒时间。 取值范围：30～180 默认值：180 配置原则：无。 |

## 使用实例

修改证书到期提醒时间。

```
%%MOD REMINDTIME: REMINDTIME=66;%% 
RETCODE = 0  操作成功  
---    END
```
