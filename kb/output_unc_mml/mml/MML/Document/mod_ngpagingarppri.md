# 修改基于ARP的Paging消息在流控期间放通的优先级（MOD NGPAGINGARPPRI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于修改基于ARP识别Paging消息在N2口固定速率流控期间放通的优先级。配置高优先级对应的Paging消息优先被放通，配置低优先级对应的Paging消息优先被流控。

## 注意事项

- 该命令执行后立即生效。

- 该命令只能配置基于APR识别Paging消息在流控期间放通的优先级，不保证一定不被流控。
- Paging消息流控优先顺序从高到低是NGPAGINGARPPRI，NGPAGINGDNNPRI。只有高优先级命令没有配置时，才会根据低优先级命令的配置识别DDN消息优先级。如果这两条命令都没有配置，所有的DDN消息都被识别为低优先级消息。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                  |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------|
| ARP      | ARP数值  | 可选必选说明：必选参数  参数含义：该参数用于指定ARP。  数据来源：本端规划  取值范围：整数类型，取值范围是1~15。  默认值：无  配置原则：无                                                         |
| PRIORITY | 优先级    | 可选必选说明：必选参数  参数含义：该参数用于指定Paging消息在流控期间放通的优先级。  数据来源：本端规划 取值范围： “PAGING_LOW（低）”：表示流控阶段放通概率低“PAGING_HIGH（高）”：表示流控阶段放通概率高  默认值：无  配置原则：无 |

## 使用实例

修改ARP为1的Paging消息在流控期间放通的优先级为高优先级，执行如下命令：

```
MOD NGPAGINGARPPRI: ARP=1, PRIORITY=PAGING_HIGH;
```
