# 查询容灾实例地址(LST DRCOMM)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询本端或对端容灾实例地址信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                           |
|:----------|:-------|:-----------------------------------------------------------------------------------------------|
| DRINSTID  | 容灾实例ID | 可选必选说明：可选参数。 参数含义：该参数用于配置容灾实例标识。 数据来源：全网规划。 取值范围：整型，0~63。 默认值：无。                               |
| IPVERSION | ip版本号  | 可选必选说明：必选参数。 参数含义：IP版本。 数据来源：本端规划。 取值范围：枚举类型。 COMM_IPV4：IP版本为IPv4。 COMM_IPV6：IP版本为IPv6。 默认值：无。 |

#### 使用实例

查询“ip版本号”为“COMM\_IPV4”的容灾实例地址：

```
%%LST DRCOMM: IPVERSION=COMM_IPV4;%%
RETCODE = 0  操作成功
操作结果如下
------------
容灾实例ID  ip版本号  ipv4通信地址  VPN名称   通信名称
0           IPV4类型  10.1.1.1       _public_  NULL
1           IPV4类型  10.2.2.2       _public_  NULL
(结果个数 = 2)
---    END
```

#### 输出结果说明

| 输出项名称             | 输出项解释                                            |
|:------------------|:-------------------------------------------------|
| 容灾实例ID            | 本端和对端容灾实例标识，本端容灾实例标识可以通过LST DRINST命令获取。          |
| ip版本号             | IP版本号。 取值范围： IPV4类型：IP版本为IPv4。 IPV6类型：IP版本为IPv6。 |
| ipv4通信地址/ipv6通信地址 | 通信IP地址。                                          |
| VPN名称             | VPN实例名称。                                         |
| 通信名称              | 通信名称。                                            |
