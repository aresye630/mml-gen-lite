# 显示会话惯性运行信息（DSP SESSIONIOINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF**

该命令用于查询5G会话上下文惯性运行信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识         | 参数名称          | 参数说明                                                                                                                               |
|:-------------|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------|
| QUERYTYPE    | 查询方式          | 可选必选说明：必选参数  参数含义：该参数用于指定查询方式。  数据来源：本端规划 取值范围： IMSI（用户IMSI号）MSISDN（用户MSISDN号）MEI（用户MEI号）  默认值：无  配置原则：无                           |
| IMSI         | 国际移动用户标识      | 可选必选说明：该参数在"QUERYTYPE"配置为"IMSI"时为条件必选参数。  参数含义：该参数用于指定用户永久标识或者国际移动用户标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是5~15。  默认值：无  配置原则：无         |
| MSISDN       | 移动台国际 ISDN 号码 | 可选必选说明：该参数在"QUERYTYPE"配置为"MSISDN"时为条件必选参数。  参数含义：该参数用于指定一般公共订阅标识或移动台国际 ISDN 号码。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~15。  默认值：无  配置原则：无 |
| MEI          | IMEI          | 可选必选说明：该参数在"QUERYTYPE"配置为"MEI"时为条件必选参数。  参数含义：该参数用于指定永久设备标识或国际移动设备标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~16。  默认值：无  配置原则：无           |
| PDUSESSIONID | PDU 会话标识      | 可选必选说明：必选参数  参数含义：该参数用于指定 PDU 会话 ID。  数据来源：本端规划  取值范围：整数类型，取值范围是1~15。  默认值：无  配置原则：无                                               |

## 使用实例

查询类型为IMSI，IMSI为123031100100001，PDUSESIONID为5的会话惯性运行信息：

```
%%DSP SESSIONIOINFO: QUERYTYPE=IMSI, IMSI="123038700100001", PDUSESSIONID=5;%%
RETCODE = 0  操作成功

Session IO Info
----------------
               国际移动用户标识  =  123038700100001
                           IMEI  =  NULL
           移动台国际 ISDN 号码  =  8613587000001
                   PDU 会话标识  =  5
                    惯性运行状态 =  PREINERTIALOPER
            进入(预)惯性运行时间 =  2021-11-11 01:57:36+00:00
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称         | 输出项解释                                                                                                                                   |
|:--------------|:----------------------------------------------------------------------------------------------------------------------------------------|
| 国际移动用户标识      | 该参数用于指定用户永久标识或者国际移动用户标识。                                                                                                                |
| 移动台国际 ISDN 号码 | 该参数用于指定一般公共订阅标识或移动台国际 ISDN 号码。                                                                                                          |
| IMEI          | 该参数用于指定永久设备标识或国际移动设备标识。                                                                                                                 |
| PDU 会话标识      | 该参数用于指定 PDU 会话 ID。                                                                                                                      |
| 惯性运行状态        | 该参数用于显示会话的惯性运行状态。NULL为非(预)惯性运行状态，INERTIALOPER为惯性运行状态，PREINERTIALOPER为预惯性运行状态。 取值说明： NULL（空）INERTIALOPER（惯性运行状态）PREINERTIALOPER（预惯性运行状态） |
| 进入(预)惯性运行时间   | 该参数用于显示会话进入(预)惯性运行状态的时间，SESSIONSTATUS为NULL时不显示，SESSIONSTATUS为IOSTATUS时显示进入惯性运行状态的时间，SESSIONSTATUS为PREIOSTATUS时显示进入预惯性运行状态的时间。           |
