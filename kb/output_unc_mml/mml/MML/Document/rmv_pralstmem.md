# 删除PRA列表成员(RMV PRALSTMEM)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于从指定的PRA区域删除位置成员。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称       | 参数说明                                                                                                                                                                                                                                                              |
|:-----------|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PRAID      | PRA标识      | 可选必选说明：必选参数 参数含义：该参数表示PRA区域的标识。 数据来源：整网规划 取值范围：0x800000～0xFFFFFF 默认值：无                                                                                                                                                                                            |
| LOCIDTYPE  | 位置区标识类型    | 可选必选说明：必选参数 参数含义：该参数表示PRA区域的位置成员的类型。 数据来源：整网规划 取值范围： “ALL(所有标识类型)”“TAI(跟踪区标识)”“MACRO_ENBID(宏基站标识)”“HOME_ENBID(家庭基站标识)”“ECGI(E-UTRAN小区全球标识)” 默认值：无                                                                                                                 |
| MCC        | 移动国家码      | 可选必选说明：条件必选参数 参数含义：该参数表示组成PRA区域的位置成员的移动国家码。 前提条件：该参数在“位置区标识类型”参数配置后生效 数据来源：整网规划 取值范围：3位十进制数字 默认值：无                                                                                                                                                                |
| MNC        | 移动网号       | 可选必选说明：条件必选参数 参数含义：该参数表示组成PRA区域的位置成员的移动网号。 前提条件：该参数在“位置区标识类型”参数配置后生效 数据来源：整网规划 取值范围：2～3位十进制数字 默认值：无                                                                                                                                                               |
| TACBEGIN   | 跟踪区起始编码    | 可选必选说明：条件必选参数 参数含义：该参数表示PRA区域的跟踪区起始编码。 前提条件：该参数在“位置区标识类型”参数配置为“TAI(跟踪区标识)”后生效。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无                                                                                                                                                 |
| ENBIDBEGIN | eNodeB起始标识 | 可选必选说明：条件必选参数 参数含义：该参数表示PRA区域的eNodeB起始标识。 前提条件：该参数在“位置区标识类型”参数配置为“MACRO_ENBID(宏基站标识)”或者“HOME_ENBID(家庭基站标识)”后生效。 数据来源：整网规划 取值范围：0～268435455 默认值：无 配置原则： 当“位置区标识类型”为“MACRO_ENBID(宏基站标识)”时，本参数的输入范围为0～1048575。当“位置区标识类型”为“HOME_ENBID(家庭基站标识)”时，本参数的输入范围为0～268435455。 |
| ECIBEGIN   | 小区起始标识     | 可选必选说明：条件必选参数 参数含义：该参数表示PRA区域的E-UTRAN小区起始标识。 前提条件：该参数在“位置区标识类型”参数配置为“ECGI(E-UTRAN小区全球标识)”后生效。 数据来源：整网规划 取值范围：0～268435455 默认值：无                                                                                                                                    |

#### 使用实例

删除PRA标识为“0x800001”的成员列表信息。

RMV PRALSTMEM: PRAID="0x800001", LOCIDTYPE=TAI, MCC="123", MNC="01", TACBEGIN="0x100";
