# 清除网元故障信息（CLR AMFNFFAULTINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

执行本命令后，AMF会停止针对指定网元的故障重选功能，用户业务可能无法及时恢复。

**适用NF：AMF**

该命令用于在AMF上清除指定的网元故障信息。在AMF或周边网元发生故障的场景下，可以执行本命令，停止AMF针对指定网元的故障重选功能。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                         |
|:-------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFTYPE       | 故障网元类型 | 可选必选说明：必选参数  参数含义：该参数用于指定故障网元类型。  数据来源：全网规划 取值范围： “AUSF（AUSF）”：AUSF“UDM（UDM）”：UDM“SMF（SMF）”：SMF“SMSF（SMSF）”：SMSF“PCF（PCF）”：PCF  默认值：无  配置原则：无                                                                                                                                                                                                |
| NFINSTANCEID | NF实例标识 | 可选必选说明：必选参数  参数含义：该参数用于指定NF实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~36。  默认值：无  配置原则：  NFINSTANCEID参数建议满足以下约束规则： 如果输入为uuid格式（格式例如：a6a61c6f-0d3a-4221-b1da-424eda3ccf67）只能为A-F、a-f、0-9和“-”的字符。如果输入不为uuid格式，长度不能超过18且不允许输入只包含0-9和“.”的字符串，例如：1.2.3.4；不允许输入只包含十六进制数（A-F、a-f、0-9）和“:”的字符串，例如：1::2、FBFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。该参数大小写不敏感。 |

## 使用实例

删除实例标识为“123456”的UDM的故障信息。执行如下命令：

```
CLR AMFNFFAULTINFO: NFTYPE=UDM, NFINSTANCEID="123456";
```
