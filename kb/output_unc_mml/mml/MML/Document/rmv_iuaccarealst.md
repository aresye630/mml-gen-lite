# 删除Iu模式区域漫游限制参数(RMV IUACCAREALST)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用于删除Iu模式区域漫游限制参数。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                   |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AREA     | 区域范围   | 可选必选说明：必选参数 参数含义：待删除的区域范围。 取值范围：“AG(区域组)”：表示该区域标识类型为区域组。“LA(指定位置区)”：表示该区域标识类型为指定位置区。“RA(指定路由区)”：表示该区域标识类型为指定路由区。“OTHER(其他)”：表示该区域标识类型为其他。 默认值：无  说明： 区域范围表示进行接入控制所适用的位置区域。区域范围按照粒度从粗到细分为以下几个级别： 区域组，指定位置区，指定路由区，其他。相同粒度区域范围的各记录的区域范围不能交迭。使用时先按照位置区域查找记录，然后按照用户的IMSI查找是否存在对应记录，查找不到再使用较粗的区域粒度进行查找。未配置在该表区域范围中的用户缺省允许接入。 |
| MCC      | 移动国家码  | 可选必选说明：条件必选参数 参数含义：待删除的移动国家代码。 前提条件：该参数在“AREA(区域范围)”参数设置为“LA(位置区)”或“RA(路由区)”时，才需要配置。 取值范围：3位的十进制数字 默认值：无                                                                                                                                                                                                               |
| MNC      | 移动网号   | 可选必选说明：条件必选参数 参数含义：待删除的移动网号。 前提条件：该参数在“AREA(区域范围)”参数设置为“LA(位置区)”或“RA(路由区)”时，才需要配置。 取值范围：2～3位的十进制数字 默认值：无                                                                                                                                                                                                               |
| LAC      | 位置区域码  | 可选必选说明：条件必选参数 参数含义：待删除的位置区域码。 前提条件：“AREA(区域范围)”参数设置为“LA(位置区)”或“RA(路由区)”时，才需要配置。 取值范围：0x0000～0xFFFF 默认值：无                                                                                                                                                                                                               |
| RAC      | 路由区域码  | 可选必选说明：条件必选参数 参数含义：待删除的路由区域码。 前提条件：该参数在“AREA(区域范围)”参数设置为“RA(路由区)”时，才需要配置。 取值范围：0x00～0xFF 默认值：无                                                                                                                                                                                                                         |
| AREAID   | 区域群标识  | 可选必选说明：条件必选参数 参数含义：待删除用户的区域群标识。 前提条件：该参数在“AREA(区域范围)”参数设置为“AG(区域组)”时，才需要配置。 取值范围：1～50 默认值：无  说明： 该区域ID必须已经通过ADD AREAGP命令添加成功，且在区域群成员表中的记录对应的IDTYPE只能为LA或RA。可执行LST AREAGP进行查看。                                                                                                                                          |
| SUBRANGE | 用户范围   | 可选必选说明：可选参数 参数含义：待删除的用户范围。 取值范围：“ALL_USER(所有用户)”：表示用户范围为所有用户。“SPECIAL_IMSIPRE(指定IMSI前缀)”：表示该用户范围为指定IMSI前缀。“USER_GROUP(用户群)”：表示用户范围为用户群。“SPECIAL_IMSI_RANGE(指定IMSI范围)”：表示该用户范围为指定IMSI范围。“UE_TYPE(终端类型)”：保留，暂未实现。 默认值：无                                                                                                  |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件必选参数 参数含义：待删除用户的IMSI前缀。使用时按照IMSI最长匹配进行查询。 前提条件：该参数在“SUBRANGE(用户范围)”参数设置为“SPECIAL_IMSIPRE(指定IMSI前缀)”时，才需要配置。 取值范围：1～15位的十进制数字 默认值：无  说明： 支持IMSI最长匹配的查询方式。该参数在用户群成员管理配置中不能存在对应记录，可执行LST SUBGPMEM进行查看。                                                                                                           |
| IMSI     | IMSI   | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI，对该IMSI所在的号段进行删除。 前提条件：该参数在“SUBRANGE(用户范围)”参数设置为“SPECIAL_IMSI_RANGE(指定IMSI范围)”时生效。 取值范围：1～15位的十进制数字 默认值：无                                                                                                                                                                                |
| SUBID    | 用户群标识  | 可选必选说明：条件必选参数 参数含义：待删除的用户群标识。 前提条件：该参数在“SUBRANGE(用户范围)”设置“USER_GROUP(用户群)”时，才需要配置。 取值范围：1～100 默认值：无                                                                                                                                                                                                                    |

#### 使用实例

删除一条Iu模式区域漫游限制参数记录，区域范围为区域组，区域群标识为1：

RMV IUACCAREALST: AREA=AG, AREAID=1;
