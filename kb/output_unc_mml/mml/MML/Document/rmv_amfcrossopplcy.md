# 删除AMF跨运营商交互策略（RMV AMFCROSSOPPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除本AMF和指定运营商的AMF/MME之间的跨运营商交互策略。

## 注意事项

- 下一次移动性流程生效。

- 该命令功能不可用，AMF的跨运营商交互策略控制请参考RMV N14N26INTOPPLCY。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称       | 参数说明                                                                                                          |
|:--------|:-----------|:--------------------------------------------------------------------------------------------------------------|
| PEERMCC | 对端运营商移动国家码 | 可选必选说明：必选参数  参数含义：该参数用于指定需要控制交互策略的对端运营商的Serving PLMN中的移动国家码。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。  默认值：无  配置原则：无    |
| PEERMNC | 对端运营商移动网号  | 可选必选说明：必选参数  参数含义：该参数用于指定需要控制交互策略的对端运营商的Serving PLMN中的移动网号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。  默认值：无  配置原则：无 |

## 使用实例

删除本AMF和运营商A之间的跨运营商交互策略，执行如下命令：

```
RMV AMFCROSSOPPLCY: PEERMCC="123", PEERMNC="45";
```
