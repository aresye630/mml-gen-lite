# 删除OSPFv3 IP FRR配置（RMV OSPFV3FRR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除OSPFv3 IP FRR（快速重路由）配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                     |
|:-------|:----------|:-------------------------------------------------------------------------|
| PROCID | OSPFv3进程号 | 可选必选说明：必选参数 参数含义：OSPFv3进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 |

#### 使用实例

删除OSPFv3进程号为1的IP FRR（快速重路由）配置：

```
RMV OSPFV3FRR: PROCID=1;
```
