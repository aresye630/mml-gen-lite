# 增加IP与NF区域映射关系配置（ADD NRFNFREGIONIP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于增加IP与NF区域的映射关系，用于在NF发现过程中，根据发现消费者与生产者的区域关系来执行对应的发现策略判断。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入1024条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                         |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------|
| IPTYPE   | IP类型   | 可选必选说明：必选参数  参数含义：该参数用于指定NF客户端地址的IP类型。  数据来源：本端规划 取值范围： IPV4（IPv4地址）IPV6（IPv6地址）  默认值：无  配置原则：无              |
| IPV4     | IPv4地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPV4"时为条件必选参数。  参数含义：该参数用于表示NF客户端的IPv4地址。  数据来源：本端规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无   |
| IPV6     | IPv6地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPV6"时为条件必选参数。  参数含义：该参数用于表示NF的客户端IPv6地址。  数据来源：本端规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无   |
| NFREGION | NF归属区域 | 可选必选说明：必选参数  参数含义：该参数用于表示NF归属区域。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~36。该字段大小写不敏感 。  默认值：无  配置原则：  NF归属区域由运营商规划。 |

## 使用实例

针对OCS已经打开区域关系精确匹配开关（SET NRFDISCREGNRULE的REGNEXTMACSW取为FUNC\_ON）。
增加发现请求CHF的客户端IP和NF区域映射关系。CHF发现OCS过程中，NRF会根据请求IP映射到CHF的区域。如果CHF与OCS同区域，则发现结果响应大包，否则响应小包。

```
ADD NRFNFREGIONIP: IPTYPE=IPV4, IPV4="10.10.10.10", NFREGION="ff";
```
