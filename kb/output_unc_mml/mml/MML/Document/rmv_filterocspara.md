# 删除需要过滤掉的OCS实例信息（RMV FILTEROCSPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NCG**

该命令用于删除需要过滤掉的OCS实例信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                             |
|:---------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------|
| FILTERID | OCS过滤标识 | 可选必选说明：必选参数  参数含义：该参数表示过滤的OCS标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~40。字符串类型，输入长度范围是1~40。该参数只能由字母（A-Z或者a-z）、数字（0-9）、中划线（-）、下划线（_）组成。  默认值：无  配置原则：无 |

## 使用实例

删除OCS过滤标识为"ocsid001"的OCS实例信息：

```
RMV FILTEROCSPARA:FILTERID="ocsid001";
```
