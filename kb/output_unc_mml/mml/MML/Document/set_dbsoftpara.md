# 设置CSDB软件调试参数表(SET DBSOFTPARA)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于设置CSDB功能开关。

#### 注意事项

系统初次上电运行时，已经存在初始记录，参数的初始记录值如下表：

|   PARAID |   PARAVALUE |
|---------:|------------:|
|        1 |           1 |

- 该命令执行后立即生效。

- 该命令参数的具体说明请参见产品文档中“CSDB软件参数”。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                |
|:----------|:-------|:--------------------------------------------------------------------|
| PARAID    | 参数标识   | 可选必选说明：必选参数。 参数含义：该参数用于指定唯一一个参数标识号。 数据来源：本端规划 取值范围：0～1023。 默认值：无。   |
| PARAVALUE | 参数值    | 可选必选说明：必选参数。 参数含义：该参数用于指定参数的取值。 数据来源：本端规划 取值范围：0～4294967295。 默认值：无。 |

#### 使用实例

设置“参数标识”为“1”、“参数值”为“1”的软调参数：

```
SET DBSOFTPARA: PARAID=1, PARAVALUE=1;
```
