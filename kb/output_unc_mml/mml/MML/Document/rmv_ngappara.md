# 删除NGAP协议参数（RMV NGAPPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除NGAP协议参数配置。

## 注意事项

- 该命令执行后立即生效。

- 不允许删除NGAP协议参数索引为0的默认配置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                    |
|:------------|:-----------|:--------------------------------------------------------------------------------------------------------|
| NGAPPARAIDX | NGAP协议参数索引 | 可选必选说明：必选参数  参数含义：该参数用于指定NGAP参数配置的索引。唯一表示一个NGAP实体的参数配置。  数据来源：本端规划  取值范围：整数类型，取值范围是0~31。  默认值：无  配置原则：无 |

## 使用实例

删除索引值为1的NGAP接口协议控制参数，执行如下命令：

```
RMV NGAPPARA: NGAPPARAIDX=1;
```
