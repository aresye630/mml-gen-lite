# 删除5G小区广播订阅信息（DEL NGCBSSUB）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

删除订阅可能导致CBCF接收不到预警结果通知。

**适用NF：AMF**

该命令用于删除CBCF下发的5G小区广播的订阅信息。小区广播场景下使用本命令达到删除残留订阅的效果。

若需要删除的记录不存在，仍会显示删除成功，可通过DSP NGCBSSUB查询是否删除成功。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称         | 参数说明                                                                                                                                                                        |
|:--------|:-------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DELTYPE | 删除订阅方式       | 可选必选说明：必选参数  参数含义：该参数用于指定删除订阅的方式。  数据来源：本端规划 取值范围： CBCID（CBCF实例标识）CBURI（Callback URI）  默认值：无  配置原则：无                                                                        |
| CBCID   | CBCF实例标识     | 可选必选说明：该参数在"DELTYPE"配置为"CBCID"时为条件必选参数。  参数含义：该参数用于指定发起订阅的CBCF的NF实例标识。若需要删除的订阅记录无CBCF的NF实例标识，建议使用输入参数CBURI删除订阅信息。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~40。不区分大小写。  默认值：无  配置原则：无 |
| CBURI   | Callback URI | 可选必选说明：该参数在"DELTYPE"配置为"CBURI"时为条件必选参数。  参数含义：该参数用于指定CBCF下发订阅时携带的Callback URI。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~512。  默认值：无  配置原则：无                                          |

## 使用实例

- 删除实例标识是“CBCF\_Instance\_0”的CBCF下发的订阅信息，执行如下命令：

  ```
  DEL NGCBSSUB: DELTYPE=CBCID, CBCID="CBCF_Instance_0";
  ```
- 删除Callback URI是“http://123.com”的CBCF下发的订阅信息，执行如下命令：

  ```
  DEL NGCBSSUB: DELTYPE=CBURI, CBURI="http://123.com";
  ```
