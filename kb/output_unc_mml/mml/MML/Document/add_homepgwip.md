# 增加归属地PGW-C IP地址（ADD HOMEPGWIP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C**

该命令用于Proxy S-GW特性中指定用户的归属地PGW-C IP地址。如果用户在本配置中指定了归属地PGW-C的IP地址，则不再通过DNS解析来获取归属地PGW-C的IP地址。

## 注意事项

- 该命令执行后只对新激活用户生效。

- 同一条IMSI/MSISDN记录最多配置8条IPv4地址和8条IPv6地址。

- 最多可输入70000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                                                                                                                         |
|:----------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE  | 用户范围     | 可选必选说明：必选参数  参数含义：该参数用于指定用户范围。  数据来源：本端规划 取值范围： IMSI_PRE（IMSI前缀	）MSISDN_PRE（MSISDN前缀）  默认值：无  配置原则：  IMSI_PRE和MSISDN_PRE记录的优先级受SET PROXYSGWFUNC命令中的QUERYTYPE参数控制。                                                                            |
| PREFIX    | 前缀       | 可选必选说明：该参数在"SUBRANGE"配置为"IMSI_PRE"、"MSISDN_PRE"时为条件必选参数。  参数含义：该参数用于指定用户号码前缀。当参数SUBRANGE为"IMSI_PRE"时，本参数表示IMSI号码前缀，当参数SUBRANGE为"MSISDN_PRE"时，本参数表示MSISDN号码前缀。使用时按照最长匹配进行查询。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~15。  默认值：无  配置原则：  取值范围为1~15位数字。 |
| IPVERSION | IP地址版本类型 | 可选必选说明：必选参数  参数含义：该参数用于指定归属地PGW的IP地址类型。  数据来源：全网规划 取值范围： “IPV4（IPV4）”：表示地址类型为IPv4“IPV6（IPV6）”：表示地址类型为IPv6  默认值：无  配置原则：无                                                                                                                     |
| HOMEIPV4  | IPv4地址   | 可选必选说明：该参数在"IPVERSION"配置为"IPV4"时为条件必选参数。  参数含义：该参数用于指定归属地PGW的IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：  IPv4地址不能配置为0.0.0.0、255.255.255.255和环回地址(127.x.y.z)。业务地址必须是A、B或者C类地址。                                                          |
| HOMEIPV6  | IPv6地址   | 可选必选说明：该参数在"IPVERSION"配置为"IPV6"时为条件必选参数。  参数含义：该参数用于指定归属地PGW的IPv6地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：  IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址(::1)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。                     |
| DESC      | 描述信息     | 可选必选说明：可选参数  参数含义：该参数用于指定本记录的描述信息。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~32。  默认值：无  配置原则：无                                                                                                                                                        |

## 使用实例

添加用户范围为IMSI\_PRE，前缀为27602，IP地址类型为IPV4，IPV4地址为10.0.0.0，描述信息为Vodafone的配置，执行如下命令：

```
ADD HOMEPGWIP: SUBRANGE=IMSI_PRE, PREFIX="27602", IPVERSION=IPV4, HOMEIPV4="10.0.0.0", DESC="Vodafone";
```
