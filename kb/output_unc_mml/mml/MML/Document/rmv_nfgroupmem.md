# 删除NF组成员（RMV NFGROUPMEM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于在NRF上删除NF实例组成员信息。

“NF组标识”添加多个“NF实例标识”时，需要每个NF实例对外提供相同的业务功能。

## 注意事项

- 该命令执行后立即生效。

- 主备或双活组网的场景下，如果需要配置此命令，则两个NRF上均需执行此命令，且配置参数一致。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                             |
|:-------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFGROUPID    | NF组标识  | 可选必选说明：必选参数  参数含义：该参数表示在NRF上配置的NF实例组标识，输入该参数时，可通过LST NFGROUP命令获取。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~128。该参数只能由字母（A-Z或者a-z）、数字（0-9）、中划线（-）组成，不区分大小写。  默认值：无  配置原则：无 |
| NFINSTANCEID | NF实例标识 | 可选必选说明：必选参数  参数含义：该参数表示在NRF上配置的NF实例组成员。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~40。该参数只能由字母（A-Z或者a-z）、数字（0-9）、中划线（-）组成，不区分大小写。  默认值：无  配置原则：无                            |
| NFNAME       | NF实例名称 | 可选必选说明：可选参数  参数含义：该参数用于表示在NRF上配置的NF实例组下的成员NF实例的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~64。  默认值：无  配置原则：无                                                            |

## 使用实例

在NRF上删除组标识为nfgroup001，实例标识为Instanceid01，实例名称为superom11-v6的NF实例组成员：

```
RMV NFGROUPMEM:NFGROUPID="nfgroup001",NFINSTANCEID="Instanceid01", NFNAME="superom11-v6";
```
