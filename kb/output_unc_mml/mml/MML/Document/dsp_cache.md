# 显示缓冲区话单数量（DSP CACHE）

#### 命令功能

**适用NF：NCG**

该命令用于显示缓冲区话单数量。该命令执行后，返回缓冲区话单数量。

在系统新安装、健康检查或者故障处理时，可以使用该命令进行检查。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                              |
|:-------|:---------|:----------------------------------------------------------------------------------------------------------------------------------|
| AGID   | 接入网元分组标识 | 可选必选说明：可选参数 参数含义：用于区分不同域的接入网元。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则： “接入网元分组标识”可以通过LST CDRPROC命令查询获取。不能输入的特殊字符请参考“特殊字符表”。 |
| MNAME  | 模块名      | 可选必选说明：可选参数 参数含义：用于表示一个业务模块对象，全局唯一。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～15。 默认值：无 配置原则： “模块名”可以通过LST MODULE命令查询获取。不能输入的特殊字符请参考“特殊字符表”。  |

#### 使用实例

显示缓冲区话单数量：

```
DSP CACHE:;
```

```
RETCODE = 0  操作成功

结果如下:
---------
        接入网元分组标识  =  PS_GROUP_1
                  模块名  =  AP66_1
原始话单缓冲区中话单数量  =  52
最终话单缓冲区中话单数量  =  3
(结果个数 = 1)

---    END
```

#### 输出结果说明

| 输出项名称        | 输出项解释                   |
|:-------------|:------------------------|
| 接入网元分组标识     | 用于区分不同域的接入网元。           |
| 模块名          | 用于表示一个业务模块对象，全局唯一。      |
| 原始话单缓冲区中话单数量 | 用于返回原始话单缓冲区中话单数量。单位为：张。 |
| 最终话单缓冲区中话单数量 | 用于返回最终话单缓冲区中话单数量。单位为：张。 |
