# 查看二次授权功能状态（LST SECAUTH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

查询二次授权功能状态，显示二次授权功能是否开启。

#### 注意事项

如果25.0.0之前版本开启二次授权功能，升级到25.0.0及之后版本， “是否打开免二次授权时间段”、“开始日期”、“结束日期”、“开始时间”及“结束时间”参数默认为NULL。

#### 参数说明

无。

#### 使用实例

查询二次授权功能状态：

```
%%LST SECAUTH:;%%
RETCODE = 0  操作成功

操作结果如下
------------
              二次授权状态  =  开启二次授权功能
  是否打开免二次授权时间段  =  否
                  开始日期  =  NULL
                  结束日期  =  NULL
                  开始时间  =  NULL
                  结束时间  =  NULL
(结果个数 = 1)

---    END
```

#### 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。输出结果说明如表1所示。

命令执行异常，请联系华为技术支持处理。输出结果说明如表2所示。

| 输出项名称        | 输出项解释                               |
|:-------------|:------------------------------------|
| 二次授权状态       | 二次授权功能的状态： OFF：关闭二次授权功能 ON：开启二次授权功能 |
| 是否打开免二次授权时间段 | 是否打开免二次授权时间段： NO： NO(否) YES： YES(是) |
| 开始日期         | 免二次授权开始日期                           |
| 结束日期         | 免二次授权结束日期                           |
| 开始时间         | 免二次授权开始时间                           |
| 结束时间         | 免二次授权结束时间                           |

|    错误码 | 错误码解释   | 原因分析           | 处理建议           |
|-------:|:--------|:---------------|:---------------|
| 101009 | 未知的命令名称 | 输入的MML命令名称不存在。 | 请输入正确的MML命令名称。 |
| 101099 | 数据库执行失败 | 执行数据库操作失败。     | 请联系华为技术支持。     |
