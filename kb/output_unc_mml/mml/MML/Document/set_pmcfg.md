## 命令功能

**须知** 

执行该命令会改变性能统计的配置，会对性能统计造成影响，请慎重执行。

执行该命令配置过性能统计参数，会优先使用配置参数，如需使默认参数生效，请使用此命令清除配置参数。

该命令用于设置性能统计的配置参数。

## 使用实例

设置最大结果指标量配置参数：

```
%%SET PMCFG: TYPE=MAX_METRIC_AFTER_CALC, ENABLE=ON, ALLMETRIC=2000;%%
RETCODE = 0  操作成功

---    END
```

设置信息收集(CSV)配置参数：

```
%%SET PMCFG: TYPE=PERF_COLLECT_CSV, ENABLE=ON, MUID_W_LIST="123", MUID_B_LIST="456", MOC_TIME_CFG="1:5:5", FLC="1000001", DIR_SP_M=MOC_LEVEL;%% 
RETCODE = 0  操作成功  

---    END
```

设置指标缓存配置参数：

```
%%SET PMCFG: TYPE=METRIC_CACHE_PARAM_CFG, OPER=ADD, RES_MU_L="11,22,33", NO_SUS_CHECK_MU_L="666,777,888";%%
RETCODE = 0  操作成功

---    END
```

设置话统存储配置参数：

```
%%SET PMCFG: TYPE=PERF_STORAGE_CFG, RECONSUME_ENABLE=OFF;%%
RETCODE = 0  操作成功

---    END
```
