# 增加本省UDM实例标识（ADD LOCALUDMINSTID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF**

该命令用于增加本省UDM实例标识。

## 注意事项

- 该命令执行后立即生效。

- 如果本省的UDM发生变更，需要同步更新本配置对应的本省UDM信息。

- 最多可输入200条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                    |
|:----------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UDMINSTID | UDM实例标识 | 可选必选说明：必选参数  参数含义：该参数用于指定UDM实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~36。UDMINSTID参数必须满足以下约束规则：1.如果输入为uuid格式（格式例如：a6a61c6f-0d3a-4221-b1da-424eda3ccf67）只能为A-F、a-f、0-9的字符。2.如果输入不为uuid格式，长度不能超过18且不允许输入只包含0-9和“.”的字符串，例如：1.2.3.4、不允许输入只包含十六进制数（A-F、a-f、0-9）和“:”的字符串，例如：1::2、FBFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。3.不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

增加本省UDM实例标识，UDM实例标识为UDM\_Instance\_0。

```
ADD LOCALUDMINSTID: UDMINSTID="UDM_Instance_0";
```
