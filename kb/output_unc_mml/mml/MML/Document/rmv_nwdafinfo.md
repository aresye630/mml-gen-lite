# 删除NWDAF信息（RMV NWDAFINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NWDAF、CBC、CBCF**

该命令用于删除NWDAF的实例信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称      | 参数说明                                                                                                                                                                                   |
|:-------------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INSTANCENAME | NWDAF实例名称 | 可选必选说明：必选参数  参数含义：该参数用于唯一指定某一个NWDAF实例。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~50。本参数的构成字符只能是字母A~Z或a~z、数字0~9、下划线“_”和中划线“-”，例如，NWDAF_Instance_0。  默认值：无  配置原则：  本参数来源于ADD NFUUID命令中的“NF实例名称”参数。 |

## 使用实例

删除NWDAF信息，NWDAF实例名称为nwdaf\_Instance\_1。

```
RMV NWDAFINFO: INSTANCENAME="nwdaf_Instance_1";
```
