# 删除MCC与MNC的归属关系（RMV PLMNMATCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C**

该命令用于删除MCC与MNC的归属关系。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                      |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------|
| MCC    | 移动国家码  | 可选必选说明：必选参数  参数含义：该参数用于表示组成PLMN的移动国家码信息。  数据来源：本端规划  取值范围：字符串类型，输入长度是3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无    |
| MNC    | 移动网号   | 可选必选说明：必选参数  参数含义：该参数用于表示组成PLMN的移动网号信息。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是2~3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无 |

## 使用实例

删除MCC为678下MNC为123的归属，执行如下命令：

```
RMV PLMNMATCH: MCC="123", MNC="678";
```
