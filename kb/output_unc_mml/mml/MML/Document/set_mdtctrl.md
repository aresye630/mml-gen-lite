# 设置MDT控制参数(SET MDTCTRL)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于设置MDT控制参数。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称                        | 参数说明                                                                                                                                                                                                                                               |
|:-----------|:----------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MDTSW      | MDT开关                       | 可选必选说明：可选参数 参数含义：该参数用于指定最小化路测（MDT）功能开关。 数据来源：全网规划 取值范围：“OFF(关闭)”“ON（打开）” 系统初始设置值：“OFF（关闭）” 配置原则：当用户需要最小化路测(MDT)功能时，可以通过设置该参数为“ON(打开)”来开启该功能。                                                                                                       |
| MDTCFGPLCY | 是否向新侧MME携带MDT-Configuration | 可选必选说明：条件可选参数 参数含义：指定是否向新侧MME携带MDT-Configuration。 前提条件：该参数在“MDT开关”设置为“ON(打开)”后生效。 数据来源：全网规划 取值范围：“OFF（关闭）”“ON（打开）” 系统初始设置值：“OFF（关闭）” 配置原则：为保证兼容性，当新侧MME支持MDT-Configuration且需要向新侧MME携带MDT-Configuration时，可以通过设置该参数为“ON(打开)”来开启该功能。  说明： 当前版本不支持此功能。 |

#### 使用实例

设置MDTCTRL参数，MDTSW为ON，MDTCFGPLCY为ON：

`SET MDTCTRL: MDTSW=ON, MDTCFGPLCY=ON;`
