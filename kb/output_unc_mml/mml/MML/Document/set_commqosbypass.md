# 设置BYPASS场景QoS描述的通用配置（SET COMMQOSBYPASS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于UDM全故障BYPASS场景下设置QoS描述的通用信息。

## 注意事项

- 该命令执行后只对新激活用户生效。

- 当本配置SET COMMQOSBYPASS与ADD APNQOSBYPASS同时配置时，优先生效指定APN的ADD APNQOSBYPASS。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| DEFSW   |
|:--------|
| DISABLE |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                       |
|:------------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DEFSW       | 通用QoS描述开关 | 可选必选说明：必选参数  参数含义：该参数用来指定是否开启通用QoS描述开关。  数据来源：本端规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无。  配置原则：无                                                                                                                            |
| SUBQOSINDEX | 5G用户QoS索引 | 可选必选说明：该参数在"DEFSW"配置为"ENABLE"时为条件必选参数。  参数含义：该参数表示用户QoS索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~255。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST COMMQOSBYPASS查询当前参数配置值。  配置原则：  该取值必须和ADD 5GCSUBQOS中配置的“用户QoS索引（SUBQOSINDEX）”参数取值相同。 |

## 使用实例

当UDM全故障进入BYPASS状态时，需要设置用户的QoS信息，此时增加SET COMMQOSBYPASS配置信息：

```
SET COMMQOSBYPASS: DEFSW=ENABLE, SUBQOSINDEX=1;
```
