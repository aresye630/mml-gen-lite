# 增加UPF和UPF组的绑定关系（ADD UPFBINDGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于添加UPF和UPF组的绑定关系。

## 注意事项

- 该命令执行后立即生效。

- 当UPF组的地址规划类型是Local或DHCP类型时，一个UPF实例只能绑定一个UPF组，但一个UPF组可以绑定多个UPF实例。
- 当UPF组的地址规划类型是UDM或Radius类型时，一个UPF实例可以绑定多个UPF组，但一个UPF组最多只能绑定两个UPF实例。

- 最多可输入3000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                                                                                                     |
|:-----------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UPFGRPNAME | UPF组名称  | 可选必选说明：必选参数  参数含义：该参数用于指定UPF组的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。不支持空格及特殊字符“#”、“$”和“&”等，由“-”、“_”、数字、字母和“.”组成，不能以“.”开头或结尾。  默认值：无  配置原则：  该参数使用ADD ADDRUPGROUP命令配置生成。 |
| UPFID      | UPF实例标识 | 可选必选说明：必选参数  参数含义：该参数用于指定UPF实例名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：  该参数使用ADD UPNODE命令配置生成。                                                             |
| PRIORITY   | 优先级     | 可选必选说明：可选参数  参数含义：该参数用于标识绑定的UPF的优先级，只有当UPFGRPNAME对应的类型为UDM或RADIUS时参数才生效，数值越小优先级越高。  数据来源：本端规划  取值范围：整数类型，取值范围是0~255。  默认值：255  配置原则：无                                    |

## 使用实例

添加UPF和UPF组的绑定关系，UPF组为upfgrp1，UPF为upf\_instance\_1：

```
ADD UPFBINDGRP: UPFGRPNAME="upfgrp1", UPFID="upf_instance_1";
```
