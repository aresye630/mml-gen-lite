# 查询5G Serving PLMN（LST NGSRVPLMN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C、AMF、SMF、NRF、NSSF、CBC、CBCF**

该命令用于查询Serving PLMN。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                    |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------|
| PLMNIDX | PLMN索引 | 可选必选说明：可选参数  参数含义：该参数用于在系统内唯一标识一个PLMN。  数据来源：本端规划  取值范围：整数类型，取值范围是0~127。  默认值：无  配置原则：无                 |
| NOID    | 运营商标识  | 可选必选说明：可选参数  参数含义：该参数用于指定本PLMN所归属的运营商。NOID通过ADD NGMNO进行配置。  数据来源：本端规划  取值范围：整数类型，取值范围为0。  默认值：无  配置原则：无 |

## 使用实例

- 查询运营商（NOID为0）的Serving PLMN信息，执行如下命令：

  ```
  %%LST NGSRVPLMN: NOID=0;%%
  RETCODE = 0  操作成功

  结果如下
  --------
    PLMN索引  =  0
  运营商标识  =  0
  移动国家码  =  460
    移动网号  =  03
    描述信息  =  NULL
  (结果个数 = 1)

  ---    END
  ```
- 查询系统中的Serving PLMN信息，执行如下命令：

  ```
  %%LST NGSRVPLMN:;%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
  PLMN索引  运营商标识  移动国家码  移动网号  描述信息  

  0           0         460         03        NULL         
  1           0         460         002       NULL         
  (结果个数 = 2)

  ---    END
  ```

## 输出结果说明

| 输出项名称   | 输出项解释                                    |
|:--------|:-----------------------------------------|
| PLMN索引  | 该参数用于在系统内唯一标识一个PLMN。                     |
| 运营商标识   | 该参数用于指定本PLMN所归属的运营商。NOID通过ADD NGMNO进行配置。 |
| 移动国家码   | 该参数表示组成Serving PLMN的移动国家码信息。             |
| 移动网号    | 该参数表示组成Serving PLMN的移动网号信息。              |
| 描述信息    | 该参数是对Serving PLMN的描述信息。                  |
