#### 命令功能

**须知** 

停止接收话单会导致NCG停止接收话单，把接收到的原始话单转换成最终话单。

**适用NF：NCG**

该命令用于停止NCG接收话单。

#### 注意事项

- 当用户执行了**STP CDRRECEIVE**命令时，NCG中满足输入参数的AP进程，主动停止话单接收。产生“**ALM-82014停止接收话单**”告警。
- 执行**RST VNFC**命令重启NCG网元后，此告警恢复，话单恢复正常接收。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                                                      |
|:-------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AGID   | 接入网元分组标识 | 可选必选说明：可选参数 参数含义：用于区分不同域的接入网元。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则： 该值需要执行LST CDRPROC命令查询“接入网元分组标识”。如果没有符合要求的“接入网元分组标识”，还需执行ADD CDRPROC命令增加。不能输入的特殊字符请参考“特殊字符表”。 |
| RUID   | RU的ID    | 可选必选说明：可选参数 参数含义：RU的ID。 数据来源：本端规划 取值范围：整数类型，取值范围为64～4294967294。 默认值：无 配置原则：该值需要执行LST SERVICERUSTATE命令，查询出存在的RU ID进行填写。                                                    |
| MNAME  | 模块名      | 可选必选说明：可选参数 参数含义：用于标识一个业务模块对象，全局唯一。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～15。 默认值：无 配置原则： 该值需要执行LST MODULE命令，查询出存在的MNAME进行填写。不能输入的特殊字符请参考“特殊字符表”。                                 |

#### 使用实例

停止NCG接收话单：

```
STP CDRRECEIVE:
RETCODE = 0  操作成功。

结果如下:
---------
接入网元分组标识    RU的ID    模块名    执行结果

PS1                 64        AP64_1    成功    
PS2                 65        AP65_1    成功    
(结果个数 = 2)
---    END
```
