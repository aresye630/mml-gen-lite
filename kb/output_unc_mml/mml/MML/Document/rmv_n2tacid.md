# 删除TAC组内绑定的N2TAC号段（RMV N2TACID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用来删除TAC组内绑定的TAC号段。

## 注意事项

立即生效

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                    |
|:-------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------|
| TACSECNUM    | TAC段编号 | 可选必选说明：必选参数  参数含义：该参数用于指定TAC段编号。  数据来源：本端规划  取值范围：整数类型，取值范围是0~15999。  默认值：无  配置原则：无                                                     |
| TACGROUPNAME | TAC组名  | 可选必选说明：必选参数  参数含义：该参数用于指定TAC组名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。不支持空格，不区分大小写。  默认值：无  配置原则：  本参数通过ADD TACGROUP命令进行配置，且TAC类型必须是N2TAC。 |

## 使用实例

假设运营商需要在本地删除一个要配置的TAC号段：

```
RMV N2TACID:TACGROUPNAME="beijing",TACSECNUM=2;
```
