# 修改IPv4地址前缀列表过滤器节点（MOD PREFIXFILTERNODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改前缀过滤器相关属性。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称       | 参数说明                                                                                                                                                                                                                     |
|:-------------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NAME         | IP前缀列表名字   | 可选必选说明：必选参数 参数含义：该参数用于指定IP前缀列表名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～169。 默认值：无 配置原则：不支持输入空格。                                                                                                                                 |
| NODESEQUENCE | IP前缀列表节点号  | 可选必选说明：必选参数 参数含义：该参数用于指定IP前缀列表节点号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无                                                                                                                                          |
| MATCHMODE    | IP前缀列表匹配模式 | 可选必选说明：必选参数 参数含义：该参数用于指定IP前缀列表匹配模式。 数据来源：本端规划 取值范围：枚举类型。 permit：允许。deny：拒绝。 默认值：无 配置原则：如果为permit则通过前缀过滤器为允许，否则为不允许。                                                                                                      |
| ADDRESS      | IP地址       | 可选必选说明：必选参数 参数含义：该参数用于指定IP地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无 配置原则：IPv4地址。                                                                                                                                                |
| MASKLENGTH   | 掩码长度       | 可选必选说明：必选参数 参数含义：该参数用于指定掩码长度。 数据来源：本端规划 取值范围：整数类型，取值范围为0～32。 默认值：无                                                                                                                                                       |
| GREATEREQUAL | 大于或等于      | 可选必选说明：可选参数 参数含义：该参数用于指定最小掩码长度。 数据来源：本端规划 取值范围：整数类型，取值范围为0～32。 默认值：无 配置原则： 长度范围是可以表达为MASKLENGTH <= GREATEREQUAL <= LESSEQUAL <= 32。如果只指定了GREATEREQUAL，前缀范围为[GREATEREQUAL，32]。当只指定LESSEQUAL时，前缀范围为[MASKLENGTH，LESSEQUAL]。 |
| LESSEQUAL    | 小于或等于      | 可选必选说明：可选参数 参数含义：该参数用于指定最大掩码长度。 数据来源：本端规划 取值范围：整数类型，取值范围为0～32。 默认值：无 配置原则： 长度范围是可以表达为MASKLENGTH <= GREATEREQUAL <= LESSEQUAL <= 32。如果只指定了LESSEQUAL，前缀范围为[MASKLENGTH，LESSEQUAL]。当只指定GREATEREQUAL时，前缀范围为[GREATEREQUAL，32]。 |
| MATCHNETWORK | 是否匹配网络     | 可选必选说明：可选参数 参数含义：该参数用于指定是否匹配IP地址前缀为0的网段路由。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无 配置原则：MATCHNETWORK参数只有在Ipv4地址为0.0.0.0时才可以配置，主要是用来指定是否匹配网段路由。                                                                   |

#### 使用实例

修改前缀过滤器，前缀过滤器名字为a，节点为1的过滤地址是10.1.1.1：

```
MOD PREFIXFILTERNODE:NAME="a",NODESEQUENCE=1,MATCHMODE=permit,ADDRESS="10.1.1.1", MASKLENGTH=32;
```
