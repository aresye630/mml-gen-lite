# 显示CRA控制参数（LST CRACTRL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于查询实时位置上报的开关和本地Trigger的功能。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询实时位置上报的开关和本地Trigger：

```
LST CRACtrl:;
```

```
RETCODE = 0  操作成功

CRA控制参数
-----------
CRA控制  =  LOCAL
    TAI  =  使能
   ECGI  =  使能
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见SET CRACTRL的参数说明。
