# 查询无线路由PAE使能状态（LST WLRPAESTATE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询PAE使能状态。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询PAE使能状态：

```
LST WLRPAESTATE:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
PAE使能状态 =  TRUE
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见SET WLRPAESTATE的参数说明。
