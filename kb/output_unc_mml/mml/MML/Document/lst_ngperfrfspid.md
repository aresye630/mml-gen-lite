# 查询5G RFSP ID性能统计对象（LST NGPERFRFSPID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询5G RFSP ID的性能统计对象。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询5G RFSP ID的性能统计对象，执行如下命令：

```
%%LST NGPERFRFSPID:;%%
RETCODE = 0  操作成功

结果如下
--------
RFSP索引  =  1
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                      |
|:--------|:---------------------------|
| RFSP索引  | 该参数用于标识基于RFSP ID的性能统计对象名称。 |
