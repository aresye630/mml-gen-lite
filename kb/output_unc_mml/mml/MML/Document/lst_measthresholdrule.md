# 查询话统阈值规则(LST MEASTHRESHOLDRULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询话统阈值规则。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                  |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------|
| MEID     | 网元ID   | 可选必选说明：可选参数。 参数含义：标识网元ID，可以通过LST ME命令查询获取。 取值范围：0~65535。 默认值：无。 配置原则：无。                                               |
| TRN      | 阈值规则名称 | 可选必选说明：可选参数。 参数含义：阈值规则名称。 取值范围：字符串类型，长度不超过160个字符。 默认值：无。 配置原则：仅支持“A-Z”、“a-z”、“0-9”、“-_”、“\u4e00-\u9fa5”中文字符组合，支持模糊查询。 |
| TRT      | 阈值规则类型 | 可选必选说明：可选参数。 参数含义：阈值规则类型。 取值范围：SIMPLE(简单阈值) 默认值：无。 配置原则：无。                                                            |
| PRD      | 测量周期   | 可选必选说明：可选参数。 参数含义：标识指标数据的周期。 取值范围： FIVE_SECOND(5秒) ONE_MINUTE(1分钟) 默认值：无。 配置原则：无。                                     |
| MOIID    | 对象实例ID | 可选必选说明：可选参数。 参数含义：对象实例ID，可以通过DSP MEASOBJ命令查询获取。 取值范围：字符串类型，长度不超过256个字符。 默认值：无。 配置原则：支持模糊查询。                           |
| METRICID | 测量指标ID | 可选必选说明：可选参数。 参数含义：测量指标ID，可以通过LST MEASUNIT命令查询获取。 取值范围：0~4294967294的整数。 默认值：无。 配置原则：无。                                 |
