# 查询Protocol Description参数（LST PROTODESCPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于查询Protocol Description参数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                              |
|:--------------|:-------|:--------------------------------------------------------------------------------------------------|
| PROTODESCNAME | 协议描述名称 | 可选必选说明：可选参数  参数含义：该参数用于指定协议描述的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。不支持空格，不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

查询名称为“name1”的协议描述参数配置信息。

```
%%LST PROTODESCPARA: PROTODESCNAME="name1";%%
RETCODE = 0  操作成功

结果如下
--------
            协议描述名称  =  name1
            传输协议类型  =  指定RTP协议类型
           RTP头扩展类型  =  PDU_SET_MARKING扩展类型
             RTP头扩展ID  =  4
              头扩展格式  =  LONG_FORMAT头拓展格式
RTP头是否携带PDU SET规格  =  未知
             RTP净荷格式  =  H265 RTP净荷格式
        RTP净荷类型列表1  =  3
        RTP净荷类型列表2  =  0
        RTP净荷类型列表3  =  0
        RTP净荷类型列表4  =  0
(结果个数 = 1)

---    END
```
