# 删除5G用户群成员（RMV NGUSRGRPMEM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

执行该命令，当仅输入USRGRPID时将删除所有5G用户群成员。

**适用NF：AMF**

该命令用于删除5G用户群成员。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                   |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------|
| USRGRPID | 用户群组标识 | 可选必选说明：必选参数  参数含义：该参数用于指定5G用户群标识。  数据来源：全网规划  取值范围：整数类型，取值范围是0~4294967294。  默认值：无  配置原则：无              |
| IMSIPRE  | IMSI前缀 | 可选必选说明：可选参数  参数含义：该参数用于指定用户的IMSI前缀。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是5~15。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无 |

## 使用实例

删除用户群成员记录，用户群标识为20，执行如下命令：

```
RMV NGUSRGRPMEM: USRGRPID=20;
```
