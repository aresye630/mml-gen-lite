# 流分类下查询ACL规则组（LST QOSRULEACL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询流分类下配置的所有ACL匹配规则。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                                 |
|:---------------|:-------|:-----------------------------------------------------------------------------------------------------|
| CLASSIFIERNAME | 分类名称   | 可选必选说明：可选参数 参数含义：该参数用于指定流分类名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：区分大小写，不支持空格。             |
| IPVERSION      | IP协议版本 | 可选必选说明：可选参数 参数含义：该参数用于指定ACL规则的IP协议版本。 数据来源：本端规划 取值范围：枚举类型。 IPv4：IPv4类型。IPv6：IPv6类型。 默认值：无            |
| ACLNAME        | ACL名称  | 可选必选说明：可选参数 参数含义：该参数用于指定基于IPv4或IPv6的ACL名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：区分大小写，不支持空格。 |
| ACLNUM         | ACL编号  | 可选必选说明：可选参数 参数含义：该参数用于指定基于IPv4或IPv6的ACL编号。 数据来源：本端规划 取值范围：整数类型，取值范围为2000～4999。 默认值：无                 |

#### 使用实例

查询当前所有在流分类下配置的ACL规则：

```
LST QOSRULEACL:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
分类名称    IP协议版本     ACL名称     ACL编号   
c1          IPv4           acl1        0          
c1          IPv6           NULL        2001       
(结果个数 = 2)
---    END
```

| 输出项名称   | 输出项解释                     |
|:--------|:--------------------------|
| 分类名称    | 该参数用于指定流分类名称。             |
| IP协议版本  | 该参数用于指定ACL规则的IP协议版本。      |
| ACL名称   | 该参数用于指定基于IPv4或IPv6的ACL名称。 |
| ACL编号   | 该参数用于指定基于IPv4或IPv6的ACL编号。 |
