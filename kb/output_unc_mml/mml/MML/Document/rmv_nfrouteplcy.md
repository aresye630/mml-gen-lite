# 删除NF路由策略（RMV NFROUTEPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、AMF、SMSF、NCG、NSSF、CBC、CBCF**

该命令用于删除对端NF路由策略。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                            |
|:-------|:-------|:--------------------------------------------------------------------------------|
| INDEX  | 索引     | 可选必选说明：必选参数  参数含义：该参数用于指定索引。  数据来源：全网规划  取值范围：整数类型，取值范围是0~65535。  默认值：无  配置原则：无 |

## 使用实例

删除到对端NF的路由策略，索引为1。

```
RMV NFROUTEPLCY: INDEX=1;
```
