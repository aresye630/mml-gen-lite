# 设置漫游管理参数（SET ROAMMGMTPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、CBC、CBCF**

该命令用于配置漫游管理参数。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| IDENTGATEWAYSW   | AVOIDNFMISUSESW   |
|:-----------------|:------------------|
| OFF              | OFF               |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称      | 参数说明                                                                                                                                                                                              |
|:----------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IDENTGATEWAYSW  | 识别关口局NF开关 | 可选必选说明：可选参数  参数含义：该参数用于指定漫游场景下是否根据对端NF的IP/FQDN识别是否为关口局NF。  数据来源：本端规划 取值范围： OFF（OFF）ON（ON）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST ROAMMGMTPARA查询当前参数配置值。  配置原则：  当存在NSA用户通过SA网络漫游接入时，需开启本开关。     |
| AVOIDNFMISUSESW | 避免网元混用开关  | 可选必选说明：可选参数  参数含义：该参数用于指定是否避免混用本网网元和异网网元。  数据来源：本端规划 取值范围： OFF（OFF）ON（ON）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST ROAMMGMTPARA查询当前参数配置值。  配置原则：  开启本开关后，本网用户只能从本地或缓存中发现本网网元，异网用户只能从本地或缓存中发现异网网元。 |

## 使用实例

设置开启识别关口局NF开关。

```
SET ROAMMGMTPARA:IDENTGATEWAYSW=ON;
```
