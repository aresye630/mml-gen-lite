# 建立M3UA信令链路（EST M3LNK）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME、SMSF**

该命令用于建立M3UA信令链路。链路处于“SCTP偶联未建立”状态，执行该命令，建立链路。

#### 注意事项

- 该命令执行后立即生效。
- 如果该链路之前以优雅方式释放，则链路建立后状态为“非激活”。
- 如果该链路之前以非优雅方式释放，则链路建立后状态为“激活”。
- 该命令只有在执行**ADD M3LNK**命令时配置的参数“C/S模式”为“C(客户端模式)”的情形下才能执行。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                               |
|:-------|:-------|:---------------------------------------------------|
| LNK    | 链路号    | 可选必选说明：必选参数 参数含义：该参数用于表示M3UA链路号。 取值范围：0~1279 默认值：无 |

#### 使用实例

建立链路号为1的M3UA链路：

EST M3LNK: LNK=1;
