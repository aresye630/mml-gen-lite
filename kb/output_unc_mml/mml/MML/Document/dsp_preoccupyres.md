# 显示预占RU资源（DSP PREOCCUPYRES）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：NCG**

该命令用于显示预占的RU资源。

#### 注意事项

该命令需等待**ACT PREOCCUPYRES**命令执行成功30秒后执行。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

显示预占的RU资源：

```
DSP PREOCCUPYRES:;
```

```
RETCODE = 0  操作成功。
结果如下:
---------

       预占数量  =  2

   命令返回结果  =  成功
(结果个数 = 1)

```

#### 输出结果说明

| 输出项名称        | 输出项解释              |
|:-------------|:-------------------|
| RU类型         | 用于指定预占RU的类型。       |
| 预占数量         | 用于指定预占RU的个数。       |
| RU所在的HOST ID | 用于指定预占RU所在的HostId。 |
| 命令返回结果       | 用于指定预占RU命令的返回结果。   |
