# 增加授权控制对象信息（ADD ALLOWEDOBJ）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于新增授权控制对象信息中的FQDN信息。

## 注意事项

- 该命令执行后立即生效。

- 主备或双活组网的场景下，如果需要配置此命令，则两个NRF上均需执行此命令，且配置参数一致。

- 最多可输入1024条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                    |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OBJNAME | 授权对象名称 | 可选必选说明：必选参数  参数含义：该参数表示设置访问授权控制策略的NF对象名称，该参数通过LST ALLOWEDOBJNAME命令获取。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。该字段值需要全系统唯一，只能由字母（A-Z或者a-z）、数字（0-9）组成，不能以数字开始。  默认值：无  配置原则：无  |
| FQDN    | FQDN   | 可选必选说明：必选参数  参数含义：该参数表示设置访问授权控制策略的NF对象的FQDN。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~255。该参数只能由字母（A-Z或者a-z）、数字（0-9）、连字符（-）和点（.）组成，大小写不敏感，FQDN不能以“.”开始，也不能以“.”结束。  默认值：无  配置原则：无 |

## 使用实例

运营商在NRF上配置对象名称为objname001，FQDN为huawei1.com.apn.epc.mnc456.mcc123.3gppnetwork.org的NF的访问授权控制策略，通过下面命令添加此NF对象。

```
ADD ALLOWEDOBJNAME: OBJNAME="objname001";
ADD ALLOWEDOBJ:OBJNAME="objname001",FQDN="huawei1.com.apn.epc.mnc456.mcc123.3gppnetwork.org";
```
