# 查询5G LAN组签约信息（LST NGLANGRPSUB）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF**

该命令用于查询5G LAN组签约信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                     |
|:--------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GROUPID | 5G LAN组ID | 可选必选说明：可选参数  参数含义：该参数用于指定5G LAN群组的ID。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是18~37。大小写不敏感且全局唯一。GROUPID以连字号分为4段，形式为GroupServiceID-MCC-MNC-LocalGroupID。其中，GroupServiceID长度为8，只能输入数字或者范围为A-F或a-f的字母；MCC长度为3，只能输入数字；MNC长度为2~3，只能输入数字；LocalGroupID长度为2~20的偶数，只能输入数字或者范围为A-F或a-f的字母。例如，A0000001-460-003-01，A0000001-460-003-A000000001。  默认值：无  配置原则：无 |

## 使用实例

查询所有5G LAN组签约信息。

```
%%LST NGLANGRPSUB:;%%
RETCODE = 0  操作成功
 
结果如下
--------
5G LAN组ID  	        DNN  
a0000001-460-003-01  	huawei.com                 
a0000001-460-003-02    	huawei.com          
(结果个数 = 2)
```

## 输出结果说明

| 输出项名称     | 输出项解释                            |
|:----------|:---------------------------------|
| 5G LAN组ID | 该参数用于指定5G LAN群组的ID。              |
| DNN       | 该参数用于指定5G LAN群组支持的DNN，即用户请求的DNN。 |
