# 设置AMF热备容灾数据冲突策略（SET DBCONFLICTFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于设置AMF热备容灾数据冲突策略。

在热备容灾特性使能的场景下，通过本命令可以设置开启用户冲突处理功能，通过主动寻呼数据冲突过的空闲态用户，确保用户签约数据和会话等关键信息的一致性和准确性。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| FUNCSW   |   INTERVAL |   SCANNUM | BAMFSCAN   |   RECOVERYDELAY | PAGINGFAILPLCY   |
|:---------|-----------:|----------:|:-----------|----------------:|:-----------------|
| OFF      |          1 |         1 | ON         |            7200 | DEFAULT          |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称              | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                 |
|:---------------|:------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FUNCSW         | 数据冲突扫描功能开关        | 可选必选说明：可选参数  参数含义：该参数用于控制开启AMF热备容灾数据冲突扫描功能开关。  数据来源：本端规划 取值范围： “OFF（关闭）”：关闭“ON（开启）”：开启  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST DBCONFLICTFUNC查询当前参数配置值。  配置原则：  本参数功能开关打开时冲突扫描任务默认仅对O-AMF生效。若期望扫描任务对B-AMF生效，需要打开本配置的B-AMF处理数据冲突用户功能开关。                                                                                                                                                              |
| INTERVAL       | 单位扫描时间(秒)         | 可选必选说明：可选参数  参数含义：该参数用于表示AMF对用户扫描的时间间隔。  数据来源：本端规划  取值范围：整数类型，取值范围是1~600，单位是秒。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST DBCONFLICTFUNC查询当前参数配置值。  配置原则：无                                                                                                                                                                                                                                             |
| SCANNUM        | 单位扫描个数            | 可选必选说明：可选参数  参数含义：该参数用于表示每个DS每间隔INTERVAL设置的时间扫描多少个用户，扫描到后对用户数据进行数据冲突处理。  数据来源：本端规划  取值范围：整数类型，取值范围是1~20，单位是个。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST DBCONFLICTFUNC查询当前参数配置值。  配置原则：  该参数值设置过大会导致系统负载过高，设置前请联系华为技术支持。  DS个数 × (单位扫描个数 / 单位扫描时间) = 整系统扫描速率。  DS个数来源于如下命令输出结果中记录个数：  DSP FRAMEDBG: DBGSTR="UeamCtrlSvc coordinator all";  如果结果没有分批显示，则记录个数为回显中“结果个数”字段的值减1；如果结果分批显示，则记录个数为最终的结果个数减1。 |
| BAMFSCAN       | B-AMF处理数据冲突用户功能开关 | 可选必选说明：可选参数  参数含义：该参数用于控制B-AMF是否处理冲突扫描任务。  数据来源：本端规划 取值范围： “OFF（关闭）”：关闭“ON（开启）”：开启  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST DBCONFLICTFUNC查询当前参数配置值。  配置原则：无                                                                                                                                                                                                                                         |
| RECOVERYDELAY  | 接口恢复扫描延迟生效时间(秒)   | 可选必选说明：可选参数  参数含义：该参数用于指定N2/SBI接口恢复后，数据冲突扫描任务延迟生效的时间。 在热备容灾特性使能的场景下，当容灾通道故障并且N2接口持续故障超过10分钟后，N2/SBI接口闭塞；在容灾通道恢复后并且等待数据核查完成后，N2/SBI接口恢复。  数据来源：本端规划  取值范围：整数类型，取值范围是0~65535，单位是秒。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST DBCONFLICTFUNC查询当前参数配置值。  配置原则：  当N2/SBI接口闭塞再恢复的时候，可能存在大量冲突的用户数据，数据冲突扫描任务可能会对后端造成冲击。建议延迟一段时间，等用户数据稳定后，再启动用户冲突扫描任务。                                                         |
| PAGINGFAILPLCY | 寻呼失败处理策略          | 可选必选说明：可选参数  参数含义：该参数用于设置数据冲突扫描任务寻呼用户流程失败的处理策略。  数据来源：本端规划 取值范围： “DEFAULT（默认方式）”：用户保持空闲态。“IMPLICIT_DEREG（隐式去注册）”：隐式去注册用户。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST DBCONFLICTFUNC查询当前参数配置值。  配置原则：无                                                                                                                                                                                                  |

## 使用实例

AMF开启数据冲突扫描功能，设置冲突扫描任务周期为1秒，设置每个周期扫描的用户数为1个，开启BAMF处理数据冲突用户功能，设置N2/SBI接口打开后冲突扫描的延时为7200秒，设置寻呼失败处理策略为隐式去注册用户，执行如下命令：

```
SET DBCONFLICTFUNC:FUNCSW=ON,INTERVAL=1,SCANNUM=1,BAMFSCAN=ON,RECOVERYDELAY=7200,PAGINGFAILPLCY=IMPLICIT_DEREG;
```
