# 设置软参（SET NCGCGFSFP）

- 命令功能

- 本地用户权限
- 网管用户权限

- 使用实例

#### 命令功能

**适用NF：NCG**

该命令用于设置NCG大颗粒软参。

#### 注意事项

- 该命令生效方式参考具体的软参说明。
- 该命令最大记录数为5000。
- 该命令存在系统初始设置记录，所有默认记录的软参值都为0。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                   |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------|
| SFPID    | 软参ID   | 可选必选说明：必选参数 参数含义：用于表示NCG大颗粒软参ID，可以使用LST NCGCGFSFP命令查询获得。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4999。 默认值：无 配置原则：无 |
| SFPVALUE | 软参值    | 可选必选说明：必选参数 参数含义：用于表示NCG大颗粒软参值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967294。 默认值：无 配置原则：无                    |

#### 使用实例

设置NCG大颗粒软参，将“软参ID”为“1”的“软参值”设置为“10”：

```
SET NCGCGFSFP: SFPID=1, SFPVALUE=10;
```
