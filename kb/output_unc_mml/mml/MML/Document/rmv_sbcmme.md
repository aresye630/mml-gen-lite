# 删除SBC MME实体(RMV SBCMME)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：CBCF**

此命令用于删除SBC MME实体配置。

#### 注意事项

- 该命令执行后立即生效。
- 执行该命令前，需要提前在UNC MML窗口上执行命令**RMV SBCAPLNK**，删除SBc链路中引用此SBC MME的链路。

#### 本地用户权限

manage-ug;system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                      |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------|
| MMEIDX | MME索引  | 可选必选说明：必选参数 参数含义：该参数用于指定待删除的MME的索引。 数据来源：本端规划 取值范围：0~127 默认值：无  说明： 可以通过LST SBCMME命令查看已有配置，确认所要删除的MME的索引。 |

#### 使用实例

删除一个索引为0的SBC MME配置:

```
RMV SBCMME: MMEIDX=0;
```
