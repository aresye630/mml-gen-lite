# 恢复APN的DNS属性（RTR UEDNSBINDAPN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用来删除指定APN实例的DNS属性和DNS64属性，恢复配置之前的状态。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                                                                                                                                                        |
|:--------------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN           | APN名称    | 可选必选说明：必选参数  参数含义：该参数用于指定APN实例名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”特殊字符，不区分大小写。  默认值：无  配置原则：  该参数使用ADD APN命令配置生成。 |
| DNSSERVERTYPE | DNS服务器类型 | 可选必选说明：必选参数  参数含义：该参数用于指定需要删除的IP地址类型。  数据来源：本端规划 取值范围： DNS_IPV4（IPv4 DNS Server）DNS_IPV6（IPv6 DNS Server）DNS_64（DNS64 Server）  默认值：无  配置原则：无                                                                                |

## 使用实例

删除APN实例huawei.com下的DNS地址：

```
RTR UEDNSBINDAPN:APN="huawei.com",DNSSERVERTYPE=DNS_IPV4-1&DNS_IPV6-1&DNS_64-1;
```
