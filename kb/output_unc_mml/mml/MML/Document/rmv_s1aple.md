# 删除S1AP本地实体(RMV S1APLE)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

删除S1AP本地实体会导致和此本地实体相连的eNodeB上的用户业务中断。

**适用网元：MME**

该命令用于删除S1AP链路本地实体。

#### 注意事项

- 该命令执行后立即生效。
- 该命令执行后，会导致和此本地实体相连的eNodeB上的用户业务中断。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                              |
|:---------|:--------|:--------------------------------------------------------------------------------------------------|
| LLEINDEX | 链路本地实体号 | 可选必选说明：必选参数 参数含义：待删除的S1AP链路本地实体号。 取值范围：0～63 默认值：无  说明： 可以通过LST S1APLE命令查看已有配置，确认所要删除的S1AP链路本地实体号。 |

#### 使用实例

删除链路本地实体号为0的S1AP链路：

RMV S1APLE: LLEINDEX=0;
