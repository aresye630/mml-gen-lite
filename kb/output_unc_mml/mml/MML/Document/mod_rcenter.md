# 修改注册中心 (MOD RCENTER)

- 命令功能

- 本地用户权限

#### 命令功能

**适用NF：SMSF**

此命令用于修改注册中心配置。在该命令中，系统通过“注册中心索引”参数来唯一标识一条中心注册记录。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                   |
|:-------|:-------|:-----------------------------------------------------------------------|
| RCX    | 注册中心索引 | 可选必选说明：必选参数 参数含义：该参数用于指定注册中心的索引。 数据来源：本端规划 取值范围：0~1 默认值：无              |
| RCM    | 注册中心名称 | 可选必选说明：可选参数 参数含义：该参数用于指定注册中心名称。 数据来源：整网规划 取值范围：字符串类型，输入长度范围为0~63 默认值：无 |

#### 使用实例

1. 修改注册中心索引为0的注册中心配置，可以用如下命令：

   ```
   MOD RCENTER: RCX=0, RCM="huawei";
   ```
