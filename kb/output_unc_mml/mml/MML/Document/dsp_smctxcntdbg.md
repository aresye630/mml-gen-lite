# 显示指定CS类型的上下文数量（DSP SMCTXCNTDBG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF、PGW-C、GGSN、SGW-C**

本命令用于显示指定CS类型的上下文数量。本命令的使用场景是系统调测。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                         |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CSTYPE | 指定CS类型 | 可选必选说明：必选参数  参数含义：本参数表示指定CS类型。  数据来源：本端规划 取值范围： SMC_SM（会话管理控制cell服务的会话管理模块）UESM（用户级会话管理cell服务）UPC（UP管理cell服务）SMC_UDM（会话管理控制cell服务的签约数据模块）SM5GPOLICY（5G会话管理策略cell服务）SM4GPOLICY（4G会话管理策略cell服务）AMPOLICY（接入移动管理策略cell服务）SM5GCM（会话管理5G融合计费cell服务）SM4GCM（会话管理4G计费cell服务）RADIUSACCT（会话管理AAA计费cell服务）S6B（会话管理Diameter AAA认证授权cell服务）  默认值：无  配置原则：无 |

## 使用实例

查询UESM的上下文数量。

```
%%DSP SMCTXCNTDBG: CSTYPE=UESM;%%
RETCODE = 0  操作成功

结果如下
--------
  指定CS类型  =  用户级会话管理cell服务
  上下文数量  =  0
无上下文标志  =  是
(结果个数 = 1)

---    END
```

|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
