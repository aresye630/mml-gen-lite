# 查询仲裁服务状态（DSP ELECTSERVICE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询仲裁服务状态。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

查询仲裁服务开关状态：

```
DSP ELECTSERVICE:SERVICEINSTANCE="vnfc";
```

```
RETCODE = 0  操作成功

结果如下:
-------------------------
       仲裁服务开关状态 =  使能
(结果个数 = 1)
 ---    END
```

#### 输出结果说明

| 输出项名称    | 输出项解释                                                                         |
|:---------|:------------------------------------------------------------------------------|
| 仲裁服务开关状态 | 该参数用于表示仲裁服务的开关状态。 使能：仲裁服务使能。去使能：仲裁服务去使能。未就绪：仲裁服务未就绪。当使用仲裁服务的部件未全部就绪时，会出现此种情况。 |
