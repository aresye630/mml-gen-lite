# 修改IGMP接口配置（MOD MGMDIF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来修改IGMP接口配置。

#### 注意事项

- 该命令执行后立即生效。
- ONDEMAND为TRUE只适用于IGMPv2和IGMPv3。
- ONDEMAND为TRUE时无法变更版本。
- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识              | 参数名称               | 参数说明                                                                                                                                                 |
|:------------------|:-------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
| IFNAME            | 接口名称               | 可选必选说明：必选参数 参数含义：该参数用于指定接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。                                                 |
| VRFNAME           | VPN实例名称            | 可选必选说明：必选参数 参数含义：该参数用来表示VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：通过LST L3VPNINST查看当前已存在的VPN实例。                                          |
| ADDRESSFAMILY     | 地址族                | 可选必选说明：必选参数 参数含义：该参数用于表示地址族类型。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。 默认值：无                                                                        |
| GMPENABLE         | 接口IGMP使能           | 可选必选说明：可选参数 参数含义：该参数用于指定接口IGMP使能。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无                                                                    |
| QUERYINTERVAL     | 配置的周期性普遍查询时间（s）    | 可选必选说明：可选参数 参数含义：该参数用于指定接口上IGMP普遍组查询消息的发送间隔。当查询器启动时，发送“健壮系数”次的普遍组查询消息，询问该网络中哪些组播组存在成员，该时间间隔即为周期性普遍查询时间。 数据来源：本端规划 取值范围：整数类型，取值范围为1～18000，单位是秒。 默认值：无 |
| QUERYRSPINTERVAL  | 普遍查询的最大响应时间（s）     | 可选必选说明：可选参数 参数含义：该参数用于指定接口上的IGMP查询报文的最大响应时间，通过设置最大响应时间，可以控制主机发送组成员关系报告的最后期限。 数据来源：本端规划 取值范围：整数类型，取值范围为1～125，单位是秒。 默认值：无                              |
| ROBUSTNESS        | 配置的鲁棒稳定系数          | 可选必选说明：可选参数 参数含义：该参数用于指定接口上的IGMP查询器的鲁棒稳定系数，即“健壮系数”，健壮系数用来弥补可能发生的网络丢包而设置的消息重传次数。 数据来源：本端规划 取值范围：整数类型，取值范围为2～5。 默认值：无                                  |
| VERSION           | 配置的IGMP版本号         | 可选必选说明：可选参数 参数含义：该参数用于指定配置的IGMP版本号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～3。 默认值：无                                                                              |
| LMQT              | 特定组查询的周期性时间（s）     | 可选必选说明：可选参数 参数含义：该参数用于指定特定组查询的周期性时间，用来在接口上设置IGMP查询器在收到主机发送的IGMP Leave报文时，发送IGMP最后组成员查询报文的时间间隔。 数据来源：本端规划 取值范围：整数类型，取值范围为1～25，单位是秒。 默认值：无             |
| OTHQUERIERPSTTIME | 其他查询器存在的时间（s）      | 可选必选说明：可选参数 参数含义：该参数用于指定其他查询器存在的时间。 数据来源：本端规划 取值范围：整数类型，取值范围为60～300，单位是秒。 默认值：无                                                                      |
| IMMEDIATELYLEAVE  | 是否配置立刻离开组          | 可选必选说明：可选参数 参数含义：该参数用于指定是否配置立刻离开组。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无                                                                   |
| ONDEMANDENABLE    | 动态加入的IGMP组记录是否永不超时 | 可选必选说明：可选参数 参数含义：该参数用于指定动态加入的IGMP组记录是否永不超时。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无                                                          |
| SSMAPENABLE       | 接口使能SSM映射功能        | 可选必选说明：可选参数 参数含义：该参数用于指定接口使能SSM映射功能。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无                                                                 |

#### 使用实例

修改IGMP接口鲁棒系数配置为4：

```
MOD MGMDIF:IFNAME="Ethernet64/0/3",VRFNAME="_public_",ADDRESSFAMILY=ipv4unicast,ROBUSTNESS=4;
```
