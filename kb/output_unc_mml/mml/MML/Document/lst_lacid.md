# 查询LAC组内绑定的LAC号段（LST LACID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：GGSN**

该命令用来查询指定LAC号段与LAC组的绑定关系或者配置的所有LAC号段和LAC组的绑定关系。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                               |
|:-------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------|
| LACSECNUM    | LAC段编号 | 可选必选说明：可选参数  参数含义：该参数用于指定LAC段编号。  数据来源：本端规划  取值范围：整数类型，取值范围是0~23999。  默认值：无  配置原则：无                                                |
| LACGROUPNAME | LAC组名  | 可选必选说明：可选参数  参数含义：该参数用于指定LAC组名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。不支持空格，不区分大小写。  默认值：无  配置原则：  该LACGROUPNAME必须已经由ADD LACGROUP配置过。 |

## 使用实例

假设运营商需要查看指定LAC号段与LAC组的绑定关系：“LAC组名”为“beijing”，“LAC号段”为2：

```
LST LACID: LACGROUPNAME="beijing", LACSECNUM=2;
RETCODE = 0 操作成功。

结果如下
--------
LAC段编号 = 2
LAC起始ID = 0x0001
LAC截止ID = 0x0010
LAC组名 = beijing
(结果个数 = 1)
--- END
```

## 输出结果说明

| 输出项名称   | 输出项解释           |
|:--------|:----------------|
| LAC段编号  | 该参数用于指定LAC段编号。  |
| LAC组名   | 该参数用于指定LAC组名。   |
| LAC起始ID | 该参数用于指定LAC起始ID。 |
| LAC截止ID | 该参数用于指定LAC截止ID。 |
