# 设置是否支持多SMFInfo场景下的PDU会话重建策略（SET MULSMFPDUREEPOL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令的错误设置可能会导致PDU会话被错误重建。

**适用NF：SMF**

该命令用于指定SMF是否支持多SMFInfo场景下的会话重建功能。

## 注意事项

- 随移动性流程生效

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| MULSMFPDUREESUP   |
|:------------------|
| NotSupport        |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称              | 参数说明                                                                                                                                                                       |
|:----------------|:------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MULSMFPDUREESUP | 是否支持多SMFInfo下会话重建 | 可选必选说明：可选参数  参数含义：该参数用于指定SMF是否支持多SMFInfo场景下的会话重建功能。  数据来源：本端规划 取值范围： NotSupport（不支持）Support（支持）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST MULSMFPDUREEPOL查询当前参数配置值。  配置原则：无 |

## 使用实例

以下命令用于指定SMF支持多SMFInfo场景下的会话重建功能。

```
SET MULSMFPDUREEPOL: MULSMFPDUREESUP=Support;
```
