# 删除S1模式接入限制参数(RMV S1ARD)

#### 命令功能

**适用网元：MME**

该命令用于删除S1模式接入限制参数。该命令先根据IMSI号段将用户进行分类，再对每一类用户按照用户签约的ARD信息、签约的APN信息进行区分而控制用户接入E-UTRAN网络。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                        |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：必选参数 参数含义：该参数用于清除指定用户范围的信息。 取值范围：“ALL_USER(所有用户)”：表示该指定用户范围为所有用户。“SPECIAL_IMSIPRE(指定IMSI前缀)”：表示该用户范围为指定IMSI前缀。“SPECIAL_IMSI_RANGE(指定IMSI范围)”：表示该用户范围为指定IMSI范围。 默认值：无 |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件必选参数 参数含义：该参数用于指定待清除用户的IMSI前缀的信息。使用时按照IMSI完全匹配进行查询。 前提条件：该参数在“SUBRANGE（用户范围）”设置为“SPECIAL_IMSIPRE(指定IMSI前缀)”时生效。 取值范围：1～15位数字 默认值：无                                 |
| IMSI     | IMSI   | 可选必选说明：条件必选参数 参数含义：该参数用于指定待清除用户的IMSI，对该IMSI所在号段进行删除。 前提条件：该参数在“SUBRANGE(用户范围)”设置为“SPECIAL_IMSI_RANGE(指定IMSI范围)”时生效。 取值范围：1～15位数字 默认值：无                                      |

#### 使用实例

1. 删除所有用户的S1模式接入限制记录：

   RMV S1ARD: SUBRANGE=ALL\_USER;
2. 删除IMSI前缀为123456的S1模式接入限制记录：

   RMV S1ARD: SUBRANGE=SPECIAL\_IMSIPRE, IMSIPRE="123456";
