# 配置OS增强认证 (SET OSENHANCEDAUTH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

- 该命令将影响节点安全配置，OS节点会开启增强认证模式，需要私钥以及口令才可以通过OS登录认证，请妥善保管口令以及私钥，丢失口令或私钥会导致无法登录系统。关闭增强认证模式仅通过口令认证，会导致OS节点安全性降低。请务必在华为技术工程师指导下，在深夜话务量低的时候（例如凌晨2:00～6:00）进行操作。
- 本章节执行过程中出现的“NODEIP”和“PASSWD”均为示例，非真实环境。
- 开启的OS增强认证包含用户名密码认证和公私钥认证。
- 节点重建或者节点进入bypass模式后叠加故障，需要重新开启OS增强认证。

该命令用于开启/关闭OS增强认证状态。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

- 环境处于升级、回退、补丁、观察期或备份状态，禁止执行该命令。
- 开启OS增强认证后，密钥文件会上传到OM Portal ，请通过“系统>文件传输>应用文件>OsAuthValue”下载对应节点的私钥文件压缩包，解压后获取名为id\_ed25519的私钥文件，请妥善保管口令以及私钥，丢失口令或私钥会导致无法登录系统。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                                                                     |
|:--------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NODEIP        | 节点IP   | 可选必选说明：必选参数。 参数含义：配置OS增强认证的节点IP。 取值范围：不超过128位的字符串。 默认值：无。 配置原则：按照DSP NODE命令查询的所有节点信息，选择实际存在的节点进行设置。                                                                                                                                      |
| SWITCH        | 开关     | 可选必选说明：必选参数。 参数含义：开关状态。 取值范围： “ON（开启）”：配置OS增强认证状态为开。 “OFF（关闭）”：配置OS增强认证状态为关。 默认值：无。 配置原则：无。                                                                                                                                              |
| PASSWD        | 密码     | 可选必选说明：条件必选参数，该参数在“开关”参数为“ON”时为必选参数。 参数含义：OS增强认证加密口令。 取值范围：10-128位字符。 默认值：无。 配置原则： 至少包括一个大写字母、一个小写字母、一个数字和一个特殊字符。输入长度不能小于10个字符。用户密码中不能出现连续三位以上（包括三位）的重复数字、字母与特殊字符，例如“111”、“aaa”、“\\\”。用户密码中不能出现连续三位以上（包括三位）的连续数字、字母，例如“123”、“abc”、“aBc”。 |
| CONFIRMPASSWD | 确认密码   | 可选必选说明：条件必选参数，该参数在“开关”参数为“ON”时为必选参数。 参数含义：OS增强认证加密口令。 取值范围：10-128位字符。 默认值：无。 配置原则：需和“PASSWD”参数保持一致。                                                                                                                                      |

## 使用实例

当“节点IP”为“10.0.0.0”，“SWITCH”选项为“ON”且密码符合要求时：

```
%%SET OSENHANCEDAUTH: NODEIP="10.0.0.0", SWITCH=ON, PASSWD="*****", CONFIRMPASSWD="*****";%%
RETCODE = 0  操作成功

下载地址
--------
下载链接  =  https://xxx:31943/fileserver/v1/web/download?filepath=/OsAuthValue/csp-arm-ipv4-os06-csp-b-arm-0_20250507075407316425240_10.0.0.0.zip&DirId=2
(结果个数 = 1)

---    END
```

当“节点IP”为“10.0.0.0”，“SWITCH”选项为“OFF”时：

```
%%SET OSENHANCEDAUTH: NODEIP="10.0.0.0", SWITCH=OFF;%% 
RETCODE = 0  操作成功 

---    END
```
