#### 命令功能

**适用NF：NCG**

该命令用于增加接入控制模块采用的IP地址和端口号。本网元的接入控制功能，由资源管理模块RCM（Resource Control Management）和全局控制模块GACM（Global Access Control Module）共同完成。它的功能是通过与话单产生网元协商，将其发送的话单分配到网元不同的接入网元分组上进行处理，平衡负载，提高可靠性。

PS域网元的IP和端口号要根据实际配置。

#### 注意事项

- 该命令执行后，需在“MML命令行 - UNC”窗口执行“**RST VNFC**”命令重新启动系统才能生效。
- 该命令最大记录数为256。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                            |
|:--------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ACID    | 接入控制标识    | 可选必选说明：必选参数 参数含义：用于在NCG中定义一条接入控制的数据记录。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：不能输入的特殊字符请参考“特殊字符表”。                                                                                                                                                                                                                                        |
| AGID    | 接入网元分组标识  | 可选必选说明：必选参数 参数含义：用于区分不同域的接入网元。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则： 该值需要执行LST CDRPROC命令查询“接入网元分组标识”。如果没有符合要求的“接入网元分组标识”，还需执行ADD CDRPROC命令增加。不能输入的特殊字符请参考“特殊字符表”。                                                                                                                                                                       |
| IPRID   | IP资源标识    | 可选必选说明：必选参数 参数含义：用于表示IP资源。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则： 该值需要执行LST IPRESOURCE命令查询“IP资源用途”为“Ga”的“IP资源标识”的值。如果没有符合要求的IP资源，还需执行ADD IPRESOURCE命令增加。NCG采用此IP与话单产生网元通信。不能输入的特殊字符请参考“特殊字符表”。                                                                                                                                           |
| PORT    | 端口        | 可选必选说明：必选参数 参数含义：用于表示接入控制模块采用的端口。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无 配置原则：建议配置的端口号大于1024，防止和操作系统使用的端口号冲突。                                                                                                                                                                                                                                  |
| RIPTYPE | 重定向IP地址类型 | 可选必选说明：可选参数 参数含义：用于表示重定向IP地址属于IPv4网络还是IPv6网络，需根据当前局点规划选择其中一种。 数据来源：对端协商 取值范围：枚举类型。 IPV4：IPv4。IPV6：IPv6。 默认值：无 配置原则：无                                                                                                                                                                                                                            |
| RIPV4   | 重定向IPv4   | 可选必选说明：条件必选参数 前提条件：该参数在“RIPTYPE”配置为“IPV4”时为条件必选参数。 参数含义：用于表示接入控制模块采用的重定向IPv4地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无 配置原则：当“IP资源标识”指定的IP或端口故障时，可以切换到“重定向IP”和“重定向端口”。                                                                                                                                                                                  |
| RIPV6   | 重定向IPv6   | 可选必选说明：条件必选参数 前提条件：该参数在“RIPTYPE”配置为“IPV6”时为条件必选参数。 参数含义：用于表示接入控制模块采用的重定向IPv6地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无 配置原则： 当“IP资源标识”指定的IP或端口故障时，可以切换到“重定向IP”和“重定向端口”。IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、2001:X:X:X:X:X::、环回地址(::1)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。该参数的掩码缺省为FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF，不可更改。 |
| RPORT   | 重定向端口     | 可选必选说明：可选参数 参数含义：用于接入控制模块采用的重定向端口。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无 配置原则：当“IP资源标识”指定的IP或端口故障时，可以切换到“重定向IP”和“重定向端口”。                                                                                                                                                                                                                      |

#### 使用实例

增加一个接入控制采用的IP示例：

```
ADD ACTRL: ACID="ps_actrl", AGID="PS_GROUP_1", IPRID="IP_Ga_CDRReceive_1st", PORT=9990, RIPTYPE=IPV4, RIPV4="192.168.3.5", RPORT=9999;
```
