# 修改位置区域DNS域名(MOD AREADNS)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于修改位置区域DNS域名。

#### 注意事项

该命令执行后立即生效。

区域名称的构成字符对大小写字母敏感。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

将与S-GW对应的“0x01”位置区下“0x01”到“0x05”路由区，修改为“0x01”到“0x09”路由区：

`MOD AREADNS: DNTYPE=SGW_RAI, LAC="0x01", RAC="0x01", RACRANGE="0x09";`
