#### 命令功能

该命令用于诊断不同节点间网络通断。PING是最常见的用于检测网络设备可访问性的调试工具，它使用ICMP报文来检测远程设备是否可用、远程主机通信的来回旅程的延迟以及包的丢失情况。

应用场景包括：

- 第一种场景：云设备内部，检测VNFC和VNFP的连通性。
- 第二种场景：设备的转发面，检测与其他配置IP业务设备的连通性。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识              | 参数名称     | 参数说明                                                                                                                      |
|:------------------|:---------|:--------------------------------------------------------------------------------------------------------------------------|
| RESNAME           | 资源名称     | 可选必选说明：必选参数 参数含义：该参数用于指定资源名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：当不输入时显示所有的资源的信息。使用DSP RES查看资源名称。   |
| IPVERSION         | IP协议版本号  | 可选必选说明：必选参数 参数含义：该参数用于指定发送ECHO-REQUEST报文的IP协议版本。 数据来源：本端规划 取值范围：枚举类型。 IPv4：IPv4协议族。IPv6：IPv6协议族。 默认值：无 配置原则：无             |
| PACKETCOUNT       | 发包数      | 可选必选说明：可选参数 参数含义：该参数用于指定发送ECHO-REQUEST报文次数。 数据来源：本端规划 取值范围：整数类型，取值范围为1～172800，单位是个数。 默认值：5 配置原则：无                         |
| PACKETSIZE        | 报文字节数    | 可选必选说明：可选参数 参数含义：该参数用于指定ECHO-REQUEST报文的有效载荷长度。 数据来源：本端规划 取值范围：整数类型，取值范围为20～9600，单位是字节。 默认值：56 配置原则：无                      |
| SOURCEIPV4ADDRESS | 源IPv4地址  | 可选必选说明：条件可选参数，该参数在“IPVERSION”配置为“IPv4”时为可选参数。 参数含义：该参数用于指定发送ECHO-REQUEST报文的源IPv4地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无 配置原则：无 |
| SOURCEIPV6ADDRESS | 源IPv6地址  | 可选必选说明：条件可选参数，该参数在“IPVERSION”配置为“IPv6”时为可选参数。 参数含义：该参数用于指定发送ECHO-REQUEST报文的源IPv6地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无 配置原则：无 |
| DESTIPV4ADDRESS   | 目的IPv4地址 | 可选必选说明：条件必选参数。该参数在“IPVERSION”配置为“IPv4”时为必选参数。 参数含义：该参数用于指定目的主机IPv4地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无 配置原则：无               |
| DESTIPV6ADDRESS   | 目的IPv6地址 | 可选必选说明：条件必选参数，该参数在“IPVERSION”配置为“IPv6”时为必选参数。 参数含义：该参数用于指定目的主机IPv6地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无 配置原则：无               |

#### 使用实例

检查IP地址为192.168.0.2的主机是否可达：

```
ACT RESNOSBASEPING: RESNAME="OMU1", IPVERSION=IPv4, PACKETCOUNT=1, DESTIPV4ADDRESS="192.168.0.2";
```
