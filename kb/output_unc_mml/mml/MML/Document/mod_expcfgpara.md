# 修改MML导入导出密钥（MOD EXPCFGPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于MML导入导出之前，下发对DB表中密码字段进行加解密的用户密钥。

#### 注意事项

该命令执行后立即生效，且针对指定的VNFC独立生效。加密导出数据前，建议对每个VNFC都运行该命令。

如果执行**EXP MML**命令导出带密码字段的配置时，参数“PWDKEY”则必须填写。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                               |
|:----------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
| PWDKEY          | 用户配置密钥 | 可选必选说明：可选参数。 参数含义：MML导入导出用户配置密钥。 数据来源：本端规划。 取值范围：密码类型，输入长度范围为6～16。当前仅支持明文密钥输入。 默认值：无 配置原则： 密码必须包含数字、大写字母、小写字母、特殊字符中至少两种字符的组合。输入单空格或不输入将删除该参数已有配置项。 |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数。 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划。 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。                                     |

#### 使用实例

下发MML导入导出用户密钥：

```
MOD EXPCFGPARA:PWDKEY="*****",SERVICEINSTANCE="vnfc";
```
