# 删除导入号段黑名单（RMV SEGBLACKLIST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令已废弃。

该命令用于删除指定NF类型，号段类型的导入号段黑名单，通过此命令删除的号段信息在对应导入号段信息中重新生效。

## 注意事项

- 该命令执行后立即生效。

- 主备或双活组网的场景下，如果需要配置此命令，则两个NRF上均需执行此命令，且配置参数一致。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                                                                                                                           |
|:---------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SEGTYPE  | 号段类型    | 可选必选说明：必选参数  参数含义：该参数用于表示号段黑名单作用的号段类型。  数据来源：本端规划 取值范围： IMSI（IMSI）MSISDN（MSISDN）IMSIRT（IMSIRT）MSISDNRT（MSISDNRT）  默认值：无  配置原则：无                                                                                                                                                |
| NFTYPE   | NF类型    | 可选必选说明：必选参数  参数含义：该参数用于表示号段黑名单作用的NF类型，即哪些NF类型支持号段文件中给出的号段信息。  数据来源：本端规划 取值范围： AUSF（AUSF）PCF（PCF）UDM（UDM）UDR（UDR）CHF（CHF）CUSTOM_OCS（CUSTOM_OCS）  默认值：无  配置原则：  该参数在“SEGTYPE”配置为“IMSI、IMSIRT”时，取值范围为上述所有NF类型，该参数在“SEGTYPE”配置为“MSISDN、MSISDNRT”时，取值范围为PCF、UDM、UDR、CHF、CUSTOM_OCS。 |
| SEGSTART | 号段起始字符串 | 可选必选说明：必选参数  参数含义：该参数用于表示号段黑名单起始字符串。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是5~15。十进制数字，号段的起始号码必须与结束号码长度保持一致，数值必须小于或等于结束号码的数值。  默认值：无  配置原则：无                                                                                                                                            |
| SEGEND   | 号段结束字符串 | 可选必选说明：必选参数  参数含义：该参数用于表示号段黑名单结束字符串。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是5~15。十进制数字，号段的结束号码必须与起始号码长度保持一致，数值大于或等于起始号码的数值。  默认值：无  配置原则：无                                                                                                                                              |
| GROUPID  | 组标识     | 可选必选说明：必选参数  参数含义：该参数用于表示待配置IMSI/MSISDN号段黑名单的NF组标识或配置IMSIRT/MSISDNRT路由转发号段黑名单的下一跳NRF组标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~128。该参数只能由字母（A-Z或者a-z）、数字（0-9），中划线（-）组成。当配置IMSI/MSISDN号段黑名单的NF组标识时，不区分大小写；当配置IMSIRT/MSISDNRT路由转发号段黑名单的下一跳NRF组标识时，则区分大小写。  默认值：无  配置原则：无               |

## 使用实例

NRF通过导入号段方式定义NF组标识为udm的UDM类型所支持的IMSI号段的范围为123456~234567，345678~456789，已配置UDM的IMSI黑名单范围为123456~234567，通过此命令删除黑名单：

```
RMV SEGBLACKLIST: SEGTYPE=IMSI, NFTYPE=UDM, SEGSTART="123456", SEGEND="234567", GROUPID="udm";
```
