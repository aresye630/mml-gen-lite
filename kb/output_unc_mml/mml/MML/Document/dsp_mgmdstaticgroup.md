# 显示IGMP静态加入信息（DSP MGMDSTATICGROUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示IGMP静态加入信息。

#### 注意事项

- 大量数据时命令会限制输出条数固定1000条，防止网管回显超时。
- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称    | 参数说明                                                                                                               |
|:----------------|:--------|:-------------------------------------------------------------------------------------------------------------------|
| ADDRESSFAMILY   | 地址族     | 可选必选说明：必选参数 参数含义：该参数用于指定地址族类型。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。 默认值：无                                      |
| VRFNAME         | VPN实例名称 | 可选必选说明：可选参数 参数含义：该参数用来表示VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：_public_ 配置原则：通过LST L3VPNINST查看当前已存在的VPN实例。 |
| MASTERSLAVETYPE | OMU类型   | 可选必选说明：可选参数 参数含义：该参数表示OMU类型。 数据来源：本端规划 取值范围：枚举类型。 MASTER：主。SLAVE：备。 默认值：MASTER                                     |
| IFNAME          | 接口名称    | 可选必选说明：可选参数 参数含义：该参数用于指定接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。               |

#### 使用实例

显示IGMP静态加入信息：

```
DSP MGMDSTATICGROUP:VRFNAME="_public_",ADDRESSFAMILY=ipv4unicast;
```

```
RETCODE = 0  操作成功。

结果如下
--------
   VPN实例名称  =  _public_
      接口名称  =  Ethernet64/0/5
    静态组地址  =  239.0.0.1
静态组的源地址  =  10.0.0.1
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释        |
|:--------|:-------------|
| VPN实例名称 | 用来表示VPN实例名称。 |
| 接口名称    | 用于指定接口名称。    |
| 静态组地址   | 用来指定静态组地址。   |
| 静态组的源地址 | 用来指定静态组的源地址。 |
