# 删除全局PCRF组绑定关系（RMV GLBPCRFGROUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、GGSN**

此命令用来删除PCRF分组和指定的号段绑定，以及绑定优先级。

#### 注意事项

- 该命令执行后只对新激活用户生效。
- 该命令支持批量删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称            | 参数说明                                                                                      |
|:--------------|:----------------|:------------------------------------------------------------------------------------------|
| IMSIMSISDNSEG | IMSI/MSISDN号段名称 | 可选必选说明：可选参数 参数含义：该参数用于设置绑定的IMSIMSISDN号段名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无 |

#### 使用实例

删除GLBPCRFGROUP：IMSIMSISDNSEG为“ims”：

```
RMV GLBPCRFGROUP:IMSIMSISDNSEG="ims";
```
