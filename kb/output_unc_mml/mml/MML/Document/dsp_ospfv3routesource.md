# 查询OSPFv3路由源信息（DSP OSPFV3ROUTESOURCE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询OSPFv3的路由源信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                   |
|:-------------|:---------|:-----------------------------------------------------------------------|
| PROCESSID    | 进程号      | 可选必选说明：必选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 |
| DESTIPV6ADDR | 目的IPv6地址 | 可选必选说明：必选参数 参数含义：目的IPv6地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无              |
| IPV6MASKLEN  | 前缀长度     | 可选必选说明：必选参数 参数含义：前缀长度。 数据来源：本端规划 取值范围：整数类型，取值范围为0～128。 默认值：无           |

#### 使用实例

查询OSPFv3进程1中目的IPv6地址为2001:db8::2、前缀长度为64的路由源信息：

```
DSP OSPFV3ROUTESOURCE:PROCESSID=1,DESTIPV6ADDR="2001:db8::2",IPV6MASKLEN=64;
```
