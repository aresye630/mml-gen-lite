# 修改IPv6安全配置（MOD IPV6ICMPSECURITY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改IPv6安全配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
|:-----------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ACTION     | 发送还是接收    | 可选必选说明：必选参数 参数含义：该参数用于表示对ICMP数据包采取的操作的类型。 数据来源：本端规划 取值范围：枚举类型。 rcvPkt：接收报文。sndPkt：发送报文。 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| CONFIGTYPE | 配置的类型     | 可选必选说明：必选参数 参数含义：该参数用于表示配置的类型。 数据来源：本端规划 取值范围：枚举类型。 USER：用户自定义。PKTTYPE：报文类型。 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ICMPTYPE   | 收发报文的TYPE | 可选必选说明：条件必选参数 前提条件：该参数在“CONFIGTYPE”配置为“USER”时为必选参数。 参数含义：该参数用于表示ICMP6报文类型。 数据来源：本端规划 取值范围：整数类型，取值范围为0～255。 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ICMPCODE   | 收发报文的CODE | 可选必选说明：条件必选参数 前提条件：该参数在“CONFIGTYPE”配置为“USER”时为必选参数。 参数含义：该参数用于表示ICMP6报文编码。 数据来源：本端规划 取值范围：整数类型，取值范围为0～255。 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| SWITCHOP   | 开关        | 可选必选说明：必选参数 参数含义：该参数用于表示是否使能开关。 数据来源：本端规划 取值范围：枚举类型。 disable：去使能。enable：使能。 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| PKTTYPE    | 报文类型      | 可选必选说明：条件必选参数 前提条件：该参数在“CONFIGTYPE”配置为“PKTTYPE”时为必选参数。 参数含义：该参数用于表示报文类型。 数据来源：本端规划 取值范围：枚举类型。 ECHO：PING请求报文（Type=128, Code=0）。ECHOREPLY：PING回应报文（Type=129, Code=0）。ERR_HEADER_FIELD：错误的报头字段（Type=4, Code=0）。FRAG_TIME_EXCEED：分片重组超时（Type=3, Code=1）。HOPLIMIT_EXCEED：TTL超时（Type=3, Code=0）。HOST_ADMIN_PROHIB：与目标的通信被管理策略禁止（Type=1, Code=1）。HOST_UNREACHABLE：主机不可达（Type=1, Code=3）。NEIGHBOR_ADVERTISEMENT：邻居应答报文（Type=136, Code=0）。NEIGHBOR_SOLICITATION：邻居请求报文（Type=135, Code=0）。NETWORK_UNREACHABLE：网络不可达报文（Type=1, Code=0）。PACKET_TOOBIG：报文超大（Type=2, Code=0）。PORT_UNREACHABLE：端口不可达（Type=1, Code=4）。REDIRECT：重定向（Type=137, Code=0）。ROUTER_ADVERTISEMENT：路由器通告报文（Type=134, Code=0）。ROUTER_SOLICITATION：路由器请求报文（Type=133, Code=0）。UNKNOWN_IPV6_OPT：不识别的IPv6选项报文（Type=4, Code=2）。UNKNOWN_NEXT_HDR：不识别的下一跳报文（Type=4, Code=1）。 默认值：无 |

#### 使用实例

修改IPv6安全配置：

```
MOD IPV6ICMPSECURITY:SWITCHOP=enable,ACTION=sndPkt,CONFIGTYPE=USER,ICMPTYPE=0,ICMPCODE=0;
```
