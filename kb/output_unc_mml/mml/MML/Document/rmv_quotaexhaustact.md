# 删除配额耗尽后的动作（RMV QUOTAEXHAUSTACT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于删除在线RG配额耗尽后的动作。

## 注意事项

该命令执行后只对新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                              |
|:------------|:---------|:------------------------------------------------------------------------------------------------------------------|
| CCTMPLTNAME | 融合计费模板名称 | 可选必选说明：必选参数  参数含义：该参数用于指定融合计费模板的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。不区分大小写。  默认值：无  配置原则：  该参数使用ADD CCT命令配置生成。 |

## 使用实例

删除融合计费模板名为global的在线RG配额耗尽后动作为阻塞业务：

```
RMV QUOTAEXHAUSTACT: CCTMPLTNAME="global";
```
