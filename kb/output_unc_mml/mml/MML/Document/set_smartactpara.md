# 设置激活抑制参数（SET SMARTACTPARA）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

此命令用于设置异常激活抑制参数，包括设置识别异常激活行为的门限，抑制唤醒定时器，假激活的Packing APNNI，分离异常用户的门限。

#### 注意事项

- 系统初次运行时，会执行系统初始设置值。
- 此命令执行后立即生效。
- "WSFD-206006 Smartphone异常信令节省"需要加载支持该特性的License，对应的License项为“Smartphone异常信令节省”。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识                   | 参数名称                              | 参数说明                                                                                                                                                                                                                            |
|:-----------------------|:----------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ABNORACTTHRESH         | 识别异常激活行为的门限（times/h）              | 可选必选说明：可选参数 参数含义：该参数为识别异常激活行为的门限，即在一个小时内如果PDP激活的次数超过了此参数的值，则认为此用户的激活行为异常。 数据来源：本端规划 取值范围：2times/h～1000times/h 系统初始设置值： 30times/h  说明： 只有当配置了ADD SMARTACT命令后，配置该参数才有效。                                                           |
| WAKEUPTIMER            | 抑制唤醒定时器（min）                      | 可选必选说明：可选参数 参数含义：该参数设置抑制唤醒定时器长度。执行抑制措施后，抑制唤醒定时器即启动，在定时器超时后，则执行唤醒措施。 数据来源：本端规划 取值范围：5min～600min 系统初始设置值： 60min 配置原则：该参数的值和实际唤醒时间有最多14分钟的误差。  说明： 只有当配置了ADD SMARTACT命令后，配置该参数才有效。                                                 |
| PARKINGAPN             | Parking APN                       | 可选必选说明：可选参数 参数含义：该参数设置激活抑制策略中假激活使用的Parking APNNI。 数据来源：本端规划 取值范围：1～62位字符串 系统初始设置值：NULL  说明： 只有当ADD SMARTACT命令中的“Parking APN假激活功能开关”打开后，配置该参数才有效。不支持输入*和其他字符组合。                                                                  |
| DETACHSERVREQTHRESH    | 分离异常用户的SERVICE REQUEST门限（times/h） | 可选必选说明：可选参数 参数含义：该参数为分离异常用户的Service Request门限，即Parking APN抑制状态下，在一个小时内如果用户的Service Request次数超过了此参数的值，则进行网络侧分离。 数据来源：本端规划 取值范围：2times/h～1000times/h 系统初始设置值： 100times/h  说明： 只有当ADD SMARTACT命令中的“Parking APN假激活功能开关”打开后，配置参数才有效。 |
| DETACHACTIVATIONTHRESH | 分离异常用户的激活行为门限（times/h）            | 可选必选说明：可选参数 参数含义：该参数为主动分离用户的门限，即在一个小时内如果用户的激活次数超过了此参数的值，则进行网络侧分离。 数据来源：本端规划 取值范围：2times/h～1000times/h 系统初始设置值： 100times/h  说明： 只有当ADD SMARTACT命令中的“主动分离用户功能开关”打开后，配置参数才有效。                                                      |
| WAKEUPSWINSPECIALCAUSE | 特定原因值拒绝激活唤醒开关                     | 可选必选说明：可选参数 参数含义：该参数用于设置“特定原因值拒绝激活唤醒开关”。 数据来源：整网规划 取值范围：“OFF(关)”“ON(开)” 系统初始设置值： OFF(关) 配置原则：当该开关开启时，SGSN在唤醒定时器即“抑制唤醒定时器(min)”超时后会执行唤醒用户的措施，即分离用户，分离类型为re-attach required。当该开关关闭时，SGSN在唤醒定时器超时后不会执行唤醒用户的措施。                     |
| WAKEUPSWINPARKING      | Parking APN假激活唤醒开关                | 可选必选说明：可选参数 参数含义：该参数用于设置“Parking APN假激活唤醒开关”。 数据来源：整网规划 取值范围：“OFF(关)”“ON(开)” 系统初始设置值： ON(开) 配置原则：当该开关开启时，SGSN在唤醒定时器即“抑制唤醒定时器(min)”超时后会执行唤醒用户的措施，即去激活Parking APN的PDP。当该开关关闭时，SGSN在唤醒定时器超时后不会执行唤醒用户的措施。                           |

#### 使用实例

设置激活抑制参数如下：“识别异常激活行为的门限”设置为10，“抑制唤醒定时器（min）”设置为60，“Parking APN”设置为huawei1，“分离异常用户的SERVICE REQUEST门限（times/h）”设置为50。

SET SMARTACTPARA: ABNORACTTHRESH=10, WAKEUPTIMER=60, PARKINGAPN="huawei1", DETACHSERVREQTHRESH=50;
