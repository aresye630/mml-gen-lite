# 修改SCCP目的信令点(MOD SCCPDPC)

#### 命令功能

**适用网元：SGSN、MME、SMSF**

此命令用来修改SCCP目的信令点表中指定的记录。

#### 注意事项

- 此命令执行后立即生效。
- 要修改的目的信令点记录已经存在。
- 备用/负荷分担信令点索引和目的信令点索引不能相同，且应该对应相同的本局信令点。
- 目的信令点编码在同一网络中是唯一的。
- 在DSP表中，目的信令点编码、本局信令点索引在表中唯一确定一条记录。
- OPC与DPC不能等于0。
- 当该SCCP目的信令点在多点负荷分担表中作为主SCCP DPC存在时，不允许将负荷分担类型从MULTIDPCLOADSHARE修改为其他的类型。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称        | 参数说明                                                                                                                                                      |
|:-------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
| DPX    | 目的信令点索引     | 可选必选说明：必选参数 参数含义：该参数用于指定SCCP目的信令点索引。 前提条件：此目的信令点索引记录必须在SCCP目的信令点表中存在，通过命令LST SCCPDPC查询。 数据来源：本端规划 取值范围：0~1279 默认值：无                                       |
| LDP    | 负荷分担类型      | 可选必选说明：可选参数 参数含义：该参数用于指定负荷分担类型，指示此目的信令点是否使用负荷分担或者主备用功能。 数据来源：整网规划 取值范围：“NOUSE(不使用)”“BACKUP(主备方式)”“LOADSHARE(动态负荷分担方式)”“MULTIDPCLOADSHARE(多点负荷分担方式)” 默认值：无 |
| SDPX   | 负荷分担目的信令点索引 | 可选必选说明：条件必选参数 参数含义：该参数用于指定负荷分担信令点对应的索引值。 前提条件：该参数在“负荷分担类型”参数设置为“LOADSHARE(动态负荷分担方式)”时，才需要配置。数据来源：整网规划 取值范围：0~1279 默认值：无                                   |
| BDPX   | 备用目的信令点索引   | 可选必选说明：条件必选参数 参数含义：该参数用于指定备用目的信令点索引。 前提条件：该参数在“负荷分担类型”参数设置为“BACKUP(主备方式)”时，才需要配置。 数据来源：整网规划 取值范围：0~1279 默认值：无                                             |
| DPN    | 目的信令点名      | 可选必选说明：可选参数 参数含义：该参数用于指定目的信令点名。 数据来源：与对端网元协商 取值范围：长度不超过32的字符串 默认值：无                                                                                       |

#### 使用实例

以下命令将SCCP目的信令点表中索引为1的记录的目的信令点名修改为beijing，备用目的信令点索引修改为3：

MOD SCCPDPC: DPX=1, LDP=BACKUP, BDPX=3, DPN="beijing";
