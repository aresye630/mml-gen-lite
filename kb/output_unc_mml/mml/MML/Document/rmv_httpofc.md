# 删除HTTP局向（RMV HTTPOFC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除HTTP局向。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                   |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------------|
| OFCTYPE | 局向类型   | 可选必选说明：可选参数  参数含义：该参数用于设置局向类型。  数据来源：本端规划 取值范围： “NFTYPE（基于网元类型）”：基于网元类型“IPGROUP（基于IP组）”：基于IP组  默认值：无  配置原则：  该参数不支持修改。 |
| OFCIDX  | 局向索引   | 可选必选说明：可选参数  参数含义：该参数用于设置局向索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4095。  默认值：无  配置原则：无                                       |

## 使用实例

- 按局向索引删除单条配置，可以用如下命令：

  ```
  RMV HTTPOFC: OFCIDX=1;
  ```
- 按局向类型删除配置，可以用如下命令：

  ```
  RMV HTTPOFC: OFCTYPE=NFTYPE;
  ```
- 删除所有局向配置，可以用如下命令：

  ```
  RMV HTTPOFC:;
  ```
