# 查询IFCM配置信息(DSP IFCMCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询IDRService配置信息。

## 注意事项

无。

## 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                                                                 |
|:---------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------|
| MEID           | 网元ID   | 可选必选说明：必选参数。 参数含义：指定要查看哪个网元的配置信息。 取值范围：0~65535。 默认值：无。 配置原则：无。                                                                       |
| THRESHOLD_TYPE | 阈值类型   | 可选必选说明：必选参数。 参数含义：指定要查看哪个类型的阈值。 取值范围： “byPool(网元容灾阈值)”：查看网元容灾倒换阈值。“byDiagnose(诊断阈值)”：查看故障诊断阈值。“byKPI(KPI栅栏)”：查看KPI栅栏。 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询容灾倒换阈值信息：

   ```
   %%DSP IFCMCFG: MEID=331, THRESHOLD_TYPE=byPool;%%
   RETCODE = 0  操作成功  
   操作结果如下： 
   --------------              
   网元ID   =  331                
   阈值(%)  =  70 
   (结果个数 = 1)  
   ---    END
   ```
2. 查询故障诊断阈值：

   ```
   %%DSP IFCMCFG: MEID=331, THRESHOLD_TYPE=byDiagnose;%%
   RETCODE = 0  操作成功  
   操作结果如下： 
   -------------- 
   网元ID  配置对象       阈值(%)    
   331     VNF            10     
   331     POD            21     
   331     umf-pod        10     
   331     umfacc-pod     100    
   (结果个数 = 4)  
    ---    END
   ```
3. 查询KPI栅栏：

   ```
   %%DSP IFCMCFG: MEID=331, THRESHOLD_TYPE=byKPI;%% 
   RETCODE = 0  操作成功  
   操作结果如下： 
   -------------- 
   网元ID  配置对象       指标ID      下界阈值(%) 上界阈值(%)    
   331     umf-pod        1000010000  78           99         
   331     umf-pod        1000010100  34           55         
   331     umf-pod        1000010200  34           55         
   331     VNF            1000010000  77           90         
   331     VNF            1000010100  22           46         
   331     VNF            1000010200  22           46         
   331     VNF            1916050000  22           46         
   331     resource-pod   1916050000  66           87         
   (结果个数 = 8)  
   ---    END
   ```

## 输出结果说明

命令执行正常，会返回命令执行成功的查询结果，输出结果说明如表1 输出项说明所示。

命令执行异常，请联系华为技术支持处理。输出错误码说明如表2所示。

| 输出项名称   | 输出项解释                                                                                                   |
|:--------|:--------------------------------------------------------------------------------------------------------|
| 网元ID    | 用于返回配置所属的网元ID。                                                                                          |
| 阈值(%)   | 用于返回配置的对应阈值，显示方式为百分比。                                                                                   |
| 配置对象    | 用于返回查询网元的配置对象。 取值范围： “VNF”: 配置对象为网元。“POD”：所有POD对象（排除已经单独设置过阈值的POD）。“POD关键字” ：配置文件中POD的实例化关键字（如umf-pod）。 |
| 指标ID    | 用于返回成功率指标（TOP KPI）的ID。                                                                                  |
| 下界阈值(%) | 用于返回成功率指标的栅栏下界，显示方式为百分比。                                                                                |
| 上界阈值(%) | 用于返回成功率指标的栅栏上界，显示方式为百分比。                                                                                |

|    错误码 | 错误码解释          | 原因分析                   | 处理建议         |
|-------:|:---------------|:-----------------------|:-------------|
| 140300 | 非法的命令          | IDRService不支持此命令。      | 请联系华为技术支持。   |
| 140302 | 内部处理错误         | 其他未知错误。                | 请联系华为技术支持。   |
| 140303 | 没有匹配的结果        | 内部没有找到符合要求的数据。         | 请联系华为技术支持。   |
| 140305 | 网元ID不存在        | 环境上没有该网元ID。            | 请检查网元ID输入参数。 |
| 140307 | 适配包不存在         | 当前网元不存在IDR的适配包，无法下发配置。 | 请联系华为技术支持。   |
| 140312 | 网元的静态topo信息不存在 | 内部没有找到静态topo信息。        | 请联系华为技术支持。   |
| 140313 | 获取网元名称失败       | 内部没有找到网元名称。            | 请联系华为技术支持。   |
