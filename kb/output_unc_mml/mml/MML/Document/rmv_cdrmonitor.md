# 删除话单监控（RMV CDRMONITOR）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

删除话单监控任务会导致话单采集提醒功能失效。

**适用NF：NCG**

该命令用于删除长时间未取话单监控任务。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                         |
|:----------|:-------|:-----------------------------------------------------------------------------|
| MONITORID | 话单监控标识 | 可选必选说明：必选参数 参数含义：监控任务标识，全局唯一。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：无 |

#### 使用实例

删除一个非自定义目录的话单监控任务示例：

```
RMV CDRMONITOR: MONITORID="MON_1";
```
