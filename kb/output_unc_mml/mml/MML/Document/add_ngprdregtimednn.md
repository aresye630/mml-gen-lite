# 增加基于DNN的周期性注册时长配置（ADD NGPRDREGTIMEDNN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令仅建议对低功耗用户签约的DNN进行配置，如果DNN配置错误可能会对其它用户造成影响。

**适用NF：AMF**

该命令用于增加基于DNN配置周期性注册时长。

在大网和园区共享RAN场景下，园区用户和大网用户周期性注册时长不同，可通过该命令单独给园区用户基于签约的园区DNN配置周期性注册时长。

如果用户签约的多个DNN均添加了本配置，则AMF随机使用一个配置。

## 注意事项

- 该命令执行后立即生效。

- 当添加本配置时，T3512在下一次用户注册时生效，移动可达定时器实时生效。
- UE请求的T3512暂不支持。
- 可以通过启动批量去注册任务（STR NGUSRBATCHDEREG）去注册指定DNN用户，以保证移动可达定时器在T3512定时器下发后生效。
- 当存在以下场景时，本功能无法生效：
- （1）本功能中使用的DNN在系统中未配置但存在SMF选择签约数据（SNSSAIINFOS）DNN名称取值为通配符（\*）的ADD UDMBYPASSSUB配置记录；
- （2）本功能中使用的DNN未在UDM上签约但签约数据中存在通配符（\*）的DNN。

- 最多可输入1024条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|:---------|:-------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DNNNI    | DNN网络标识      | 可选必选说明：必选参数  参数含义：该参数用于指定周期性注册时长的目标DNN网络标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。可输入的字符有字母、十进制数字、“-”和“.”，并且开头和结尾只能是数字或者字母。不能出现连续两个“.”。字母大小写不敏感。  默认值：无  配置原则：  “*”表示通配符，如果DNNNI为“*”，表示所有DNNNI都支持此配置的周期性注册时长。 使用DNNNI参数的配置值在用户签约数据smfSelData中所有切片下的DNN列表中进行匹配。                                                                                                                                                                            |
| TIMEPLCY | 周期性注册时长获取策略  | 可选必选说明：必选参数  参数含义：该参数用于指定周期性注册时长获取的策略。  数据来源：全网规划 取值范围： “UDMSUB（签约数据优先）”：若UDM签约subsRegTimer且小于本配置的移动可达定时器，则签约有效；否则AMF取本配置中的T3512。“LOCAL（本地配置优先）”：AMF取本配置中的T3512。  默认值：无  配置原则：无                                                                                                                                                                                                                                                        |
| T3512    | T3512(min)   | 可选必选说明：必选参数  参数含义：该参数用于设置本地配置的周期性注册时长；如果不配置，则本地配置取自SET NGMMPARA命令中的T3512。  数据来源：全网规划  取值范围：整数类型，取值范围是1~780。  默认值：无  配置原则：  该定时器的取值范围为离散值，根据3gpp规范24.008的10.5.7.4a章节中定义的取值规则如下：  当取值为1min，T3512信元的编码单位为2s；  当范围为2min-15min，编码单位为30s；  当范围为16min-31min，编码单位为1min；  当范围为32min-310min，编码单位为10min；  当范围为311min-780min，编码单位为1hour。  例如：当取值为2min时，T3512信元值为4，编码单位为30s。增加T3512(min)的值会减少CM-CONNECTED注册用户数、增加CM-IDLE注册用户数、减少周期性注册更新请求次数、增加寻呼次数。 |
| RCHTMR   | 移动可达定时器(min) | 可选必选说明：必选参数  参数含义：该定时器用于监测UE是否发起周期性注册更新流程。该定时器在UE的NAS信令连接释放时启动，在NAS信令连接建立时停止；超时后，如果UE还没有发起周期性注册更新流程，则启动不可达用户隐式去注册定时器（IMDTCHTMR），取自SET NGMMPARA命令中的IMDTCHTMR。  数据来源：全网规划  取值范围：整数类型，取值范围是2~792，单位是分钟。  默认值：无  配置原则： 此定时器时长应大于“T3512(min)”时长。增加“移动可达定时器(min)”的值会增加CM-IDLE注册用户数、减少DEREGISTERED态用户数、增加寻呼次数。                                                                                                                                |

## 使用实例

增加DNNNI为“abc”、周期性注册时长获取策略为本地配置优先、周期性注册时长780分钟、移动可达定时器792分钟的配置，执行如下命令：

```
ADD NGPRDREGTIMEDNN:DNNNI="abc",TIMEPLCY=LOCAL,T3512=780,RCHTMR=792;
```
