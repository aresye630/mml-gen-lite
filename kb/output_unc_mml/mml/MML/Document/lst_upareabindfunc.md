# 查询获取UPF服务区绑定TAI/LAI的方式（LST UPAREABINDFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、GGSN、SGW-C**

该命令用于查询获取UPF服务区绑定TAI/LAI的方式。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

以下命令用于查询获取UPF服务区绑定TAI/LAI的方式：
LST UPAREABINDFUNC:;

```
%%LST UPAREABINDFUNC:;%%
RETCODE = 0  操作成功

结果如下
--------
                  生效方式 = 采用前缀的方式
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                        |
|:--------|:-----------------------------|
| 生效方式    | 该参数用于标识获取UPF服务区绑定TAI/LAI的方式。 |
