# 增加Iu模式用户安全参数(ADD IUAUTHCIPH)

#### 命令功能

**须知** 

不开启鉴权功能将导致身份未被鉴别的UE接入系统，引发系统内UE发生串号，计费错误等问题。

**适用网元：SGSN**

该命令用于增加3G鉴权加密的配置。UNC可以结合运营商的配置要求和协议规范决定是否使用鉴权加密。针对SGSN节点可能遇到的所有需要鉴权的流程，UNC均设置了开关加以控制，运营商可以通过配置决定这些流程是否需要鉴权。

#### 注意事项

- 该命令执行后立即生效。
- 指定号段的用户群采用对应的安全配置参数，未指定的用户群采用默认的安全配置参数。
- 此命令最大记录数为1024。
- Uplink NAS类型的Detach不会鉴权。
- 系统中缺省生成一条记录用于控制所有用户的安全策略，配置导出时通过将IMSI前缀取值设置成ALL\_USER来表示缺省记录。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

增加IMSI前缀为＂012544＂的用户3G鉴权加密配置，加密算法选择UEA1，完整性算法选择UIA1-1：

ADD IUAUTHCIPH: IMSIPRE="012544", SECPLC=AUTHANDPROTECTED, CIPHALG=UEA1-1, INTALG=UIA1-1;
