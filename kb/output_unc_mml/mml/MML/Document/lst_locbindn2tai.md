# 查询UPF位置信息与UPF优先支持的5G TAI范围的绑定关系（LST LOCBINDN2TAI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF**

该命令用于查询UPF位置信息与UPF优先支持的TAI范围的绑定关系。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                         |
|:---------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------|
| LOCALITY | UPF位置区 | 可选必选说明：可选参数  参数含义：该参数用于标识UPF位置区。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~255。  默认值：无  配置原则：  该参数需要与ADD PNFPROFILE命令中 “LOCALITY”的取值保持一致，参数匹配时大小写不敏感。  |
| TAI      | TAI    | 可选必选说明：可选参数  参数含义：该参数用于查询单个TAI绑定的LOCALITY。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是11~12。不区分大小写。  默认值：无  配置原则：  字符串类型，输入长度范围是11~12。后6位为16进制数，其余为10进制数。 |

## 使用实例

- 查询所有的UPF位置信息与UPF优先支持的TAI范围的绑定关系
  LST LOCBINDN2TAI:;

  ```
  %%LST LOCBINDN2TAI:;%%
  RETCODE = 0  操作成功

  结果如下
  --------
  UPF位置区  移动国家码  移动网号  N2 TAC起始号段  N2 TAC终止号段  

  locality1  460         03        130101          130102          
  locality1  460         03        130103          130104          
  locality2  460         03        130105          130106          
  (结果个数 = 3)

  ---    END
  ```
- 查询特定的UPF位置信息与UPF优先支持的TAI范围的绑定关系，其中UPF位置区为“locality1”
  LST LOCBINDN2TAI: TAI="12303130101";

  ```
  %%LST LOCBINDN2TAI: TAI="12303130101";%%
  RETCODE = 0  操作成功

  结果如下
  --------
       UPF位置区  =  locality1
      移动国家码  =  460
        移动网号  =  03
  N2 TAC起始号段  =  130101
  N2 TAC终止号段  =  130102
  (结果个数 = 1)

  ---    END
  ```

## 输出结果说明

| 输出项名称      | 输出项解释              |
|:-----------|:-------------------|
| UPF位置区     | 该参数用于标识UPF位置区。     |
| 移动国家码      | 该参数用于指定对端NF的移动国家码。 |
| 移动网号       | 该参数用于指定对端NF的移动网号。  |
| N2 TAC起始号段 | 该参数用于指定TAC的起始号段。   |
| N2 TAC终止号段 | 该参数用于指定TAC的终止号段。   |
