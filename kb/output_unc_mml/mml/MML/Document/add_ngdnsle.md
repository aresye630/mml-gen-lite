# 增加DNS本端实体（ADD NGDNSLE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于增加DNS本端实体，以便和DNS服务器进行通信。该命令功能暂不生效。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入32条记录。
- 只有通过ADD NGDNSS添加了至少一个DNS服务器后，用ADD NGDNSLE增加对应IP类型的DNS本端实体才能起作用。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                                         |
|:--------|:----------|:-------------------------------------------------------------------------------------------------------------|
| IPTYPE  | IP地址类型    | 可选必选说明：必选参数  参数含义：该参数用于指定DNS本端实体的IP地址类型。  数据来源：全网规划 取值范围： IPV4（IPv4）IPV6（IPv6）  默认值：无  配置原则：无                |
| IPV4    | IPv4地址    | 可选必选说明：该参数在"IPTYPE"配置为"IPV4"时为条件必选参数。  参数含义：该参数用于指定DNS本端实体的IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无 |
| IPV6    | IPv6地址    | 可选必选说明：该参数在"IPTYPE"配置为"IPV6"时为条件必选参数。  参数含义：该参数用于指定DNS本端实体的IPv6地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无 |
| VPNNAME | VPN名称     | 可选必选说明：可选参数  参数含义：该参数用于指定DNS本端实体到DNS服务器间的链路所用的VPN名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~31。  默认值：无  配置原则：无      |
| LENAME  | DNS本端实体名称 | 可选必选说明：可选参数  参数含义：该参数用于指定DNS本端实体的名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~32。  默认值：无  配置原则：无                      |

## 使用实例

新增DNS本端实体：IPTYPE为IPV4，IP地址192.168.101.100，DNS本端实体名称dnsle01：

```
ADD NGDNSLE:IPTYPE=IPV4,IPV4="192.168.101.100",LENAME="dnsle01";
```
