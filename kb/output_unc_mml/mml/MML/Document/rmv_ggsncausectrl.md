# 删除GGSN-C原因值控制参数（RMV GGSNCAUSECTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：GGSN**

该命令用于删除GGSN-C的原因值控制参数。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                                                                    |
|:--------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROCEDURETYPE | 流程类型   | 可选必选说明：必选参数  参数含义：该参数用于指定流程类型，要根据场景来配置相应的流程。  数据来源：本端规划 取值范围： CRT_PDP_PROC（创建PDP流程）UPD_PDP_PROC（更新PDP流程）  默认值：无  配置原则：无                                                                                                                 |
| CAUSESOURCE   | 异常来源   | 可选必选说明：必选参数  参数含义：该参数用于描述发生异常的来源。  数据来源：本端规划 取值范围： UPF（UPF）POLICY_PCRF（PCRF策略）CHG_3GPP（3GPP计费）RADIUS_AUTH（Radius鉴权）INNER（内部异常）RADIUS_CHG（Radius计费）POLICY_PCF（PCF策略）CHF_3GPP（3GPP CHF）  默认值：无  配置原则：  POLICY_PCF以及CHF_3GPP网元类型仅在2G用户下生效。 |

## 使用实例

删除创建PDP流程UPF异常的流程控制配置。

```
RMV GGSNCAUSECTRL: PROCEDURETYPE=CRT_PDP_PROC, CAUSESOURCE=UPF;
```
