# 增加DNN群组（ADD DNNGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于配置DNN群组。AMF支持为具有相同属性（比如发现相同的目标SMF）的DNN配置到同一个群组。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入16条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                |
|:---------|:--------|:----------------------------------------------------------------------------------------------------|
| DNNGRPID | DNN群组标识 | 可选必选说明：必选参数  参数含义：该参数用于标识一个DNN群组。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。  默认值：无  配置原则：无                |
| DESC     | 描述信息    | 可选必选说明：可选参数  参数含义：该参数是对DNN群组的描述信息，在运维过程中起到助记的作用。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~32。  默认值：无  配置原则：无 |

## 使用实例

某集团旗下的企业使用了DNNa、DNNb等多个DNN，企业员工在使用上述DNN时都需要选择到指定服务范围的目标SMF，为了节省配置记录，将上述DNN配置到同一个群组。首先添加DNN群组标识，执行命令如下：

```
ADD DNNGRP: DNNGRPID="BIG_GROUP", DESC="for SMF selection";
```
