# 增加服务节点组（ADD SRVNODEGROUP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、GGSN**

该命令用来添加一个新的服务节点组。当需要用SGSN IP、SGW IP、PCF IP、TWAN IP、ePDG IP进行虚拟APN映射时，在不同的场景下需要使用该命令添加SGSN/SGW/PCF/TWAN/ePDG新的服务节点组，可以在该服务节点组下绑定服务节点IP地址。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入3000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                             |
|:----------|:--------|:-------------------------------------------------------------------------------------------------|
| GROUPNAME | 服务节点组名称 | 可选必选说明：必选参数  参数含义：该参数用于指定服务节点组名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。不支持空格，不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

在根据SGSN IP进行虚拟APN映射的时候，需要配置一个服务节点组，名称为“huawei”：

```
ADD SRVNODEGROUP:GROUPNAME="huawei";
```
