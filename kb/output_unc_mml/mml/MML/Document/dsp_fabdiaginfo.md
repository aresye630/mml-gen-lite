# 显示Fabric平面亚健康诊断结果（DSP FABDIAGINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

- 该命令用于显示Fabric平面亚健康诊断结果。
- Pod级Fabric亚健康：若本Fabric Pod与其他所有Fabric Pod之间产生的亚健康链路数与总链路数的比值大于POD亚健康阈值，则认为该Fabric Pod处于Pod级别的Fabric亚健康，可能是Fabric亚健康汇聚点。POD亚健康阈值可使用**SET FABDIAGPARA**设置，**LST FABDIAGPARA**查询。
- 节点级Fabric亚健康：若本节点上所有Fabric Pod都处于Pod级Fabric亚健康，则认为该节点处于节点级别的Fabric亚健康，可能是Fabric亚健康汇聚点。
- 主机级Fabric亚健康：若本主机上所有Fabric Pod都处于Pod级Fabric亚健康，则认为该主机处于主机级别的Fabric亚健康，可能是Fabric亚健康汇聚点。
- 若Pod、节点或主机不满足Pod级、节点级或主机级Fabric亚健康，但亚健康链路数排序在前10，也可通过此命令查询诊断结果。
- Fabric Pod可使用**DSP PAENODE**查询，输出结果中的服务地址表示Pod名称。

## 注意事项

- 当Fabric平面出现亚健康时，一般会上报“ALM-100339 Fabric链路出现亚健康”或者“ALM-100340 Fabric端口通信出现亚健康”。
- 亚健康诊断结果最长保留7天，不支持查询7天前的记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RESOURCE | 诊断对象类型 | 可选必选说明：必选参数  参数含义：该参数用于指定查询的诊断对象类型。  数据来源：本端规划 取值范围： “PORT（端口）”：显示bonding组网下Pod级别的Fabric亚健康诊断结果“POD（Pod）”：显示非bonding组网下Pod级别的Fabric亚健康诊断结果“NODE（节点）”：显示节点级别的Fabric亚健康诊断结果“HOST（主机）”：显示主机级别的Fabric亚健康诊断结果  默认值：无  配置原则：  若系统因Fabric链路出现亚健康产生“ALM-100339 Fabric链路出现亚健康”告警，则为非bonding组网。此场景查询Pod级别的Fabric亚健康诊断结果，请将输入参数中的“诊断对象类型”选择为“POD”。  若系统因Fabric端口通信出现亚健康产生“ALM-100340 Fabric端口通信出现亚健康”告警，则为bonding组网。此场景查询Pod级别的Fabric亚健康诊断结果，请将输入参数中的“诊断对象类型”选择为“PORT”。 |

## 输出结果说明

| 输出项名称      | 输出项解释                        |
|:-----------|:-----------------------------|
| 进程名称       | 该参数用于表示Fabric亚健康的进程名称。       |
| Pod名称      | 该参数用于表示Fabric亚健康的Pod的名称。     |
| 节点名称       | 该参数用于表示Fabric亚健康的节点名称。       |
| 主机名称       | 该参数用于表示Fabric亚健康的主机名称。       |
| 平面组ID      | 该参数用于表示Fabric亚健康的平面组ID。      |
| 平面ID       | 该参数用于表示Fabric亚健康的平面ID。       |
| 端口名称       | 该参数用于表示Fabric亚健康的端口名称。       |
| 端口通信方向     | 该参数用于表示Fabric亚健康的端口通信方向。     |
| 亚健康链路数     | 该参数用于表示Fabric亚健康的链路数量。       |
| 亚健康链路占比(%) | 该参数用于表示Fabric亚健康的链路数和总链路的比重。 |
| 亚健康诊断时间    | 该参数用于表示Fabric亚健康的诊断时间。       |
