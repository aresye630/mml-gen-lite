# 查询GU重定向策略（LST GUREDIRPLCY）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限

#### 命令功能

**适用网元：MME**

该命令用于查询GU重定向策略。

#### 注意事项

此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                   |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AREA   | 区域范围   | 可选必选说明：可选参数 参数含义：该参数用于指定区域的标识类型。 数据来源：整网规划 取值范围：“PLMN(PLMN)”：表示该区域标识类型为指定PLMN区域。“TA(指定跟踪区)”：表示该区域标识类型为指定跟踪区。 默认值：无  说明： 本表“区域范围”为“PLMN(PLMN)”的记录可以与“区域范围”为“TA(指定跟踪区)”的记录共存；“区域范围”为“TA(指定跟踪区)”的记录优先级更高。 |
| MCC    | 移动国家码  | 可选必选说明：条件可选参数 参数含义：该参数用于指定移动国家代码。 前提条件：该参数在“AREA(区域范围)”参数设置为“TA(指定跟踪区)”或者“PLMN(PLMN)”时，才需要配置。 数据来源：整网规划 取值范围：3位的十进制数字 默认值：无                                                                            |
| MNC    | 移动网号   | 可选必选说明：条件可选参数 参数含义：该参数用于指定移动网号。 前提条件：该参数在“AREA(区域范围)”参数设置为“TA(指定跟踪区)”或者“PLMN(PLMN)”时，才需要配置。 数据来源：整网规划 取值范围：2～3位的十进制数字 默认值：无                                                                            |
| TAC    | 跟踪区域码  | 可选必选说明：条件可选参数 参数含义：该参数用于指定跟踪区域码。 前提条件：该参数在“AREA(区域范围)”参数设置为“TA(指定跟踪区)”时，才需要配置。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无                                                                                      |

#### 使用实例

查询GU重定向策略:

LST GUREDIRPLCY:;

```
%%LST GUREDIRPLCY:;%%
RETCODE = 0  操作成功。

输出结果如下
------------
            区域范围  =  PLMN
          移动国家码  =  460
            移动网号  =  01
          跟踪区域码  =  NULL
      跟踪区域码范围  =  NULL
   redir-policy 取值  = Unsecured redirection to GERAN or UTRAN allowed
(结果个数 = 1)
---    END
```
