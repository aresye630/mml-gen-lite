# 查询GTP-C本地实体组成员（LST GTPCLEGRPMEM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C、AMF、GGSN**

该命令用于查询GTP-C本地实体组成员的信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                        |
|:--------|:-------|:----------------------------------------------------------------------------------------------------------------------------|
| GROUPID | 组号     | 可选必选说明：可选参数  参数含义：该参数用于指定GTP-C本地实体的组号。  数据来源：本端规划  取值范围：整数类型，取值范围是0~31。该参数需要从ADD GTPCLEGRP命令中已配置的GRPID参数中取值。  默认值：无  配置原则：无 |

## 使用实例

查询0号GTP-C本地实体组的信息。

```
%%LST GTPCLEGRPMEM: GROUPID=0;%%
RETCODE = 0  操作成功

结果如下
--------
组号  IP地址类型  IPv4地址  IPv6地址  VPN名称   描述信息  
    
0     IPv4        10.2.125.26     ::   _public_  s11          
0     IPv4        10.2.125.27     ::   _public_  s11   
(结果个数 = 2)

---    END
```

| 输出项名称   | 输出项解释                    |
|:--------|:-------------------------|
| 组号      | 该参数用于指定GTP-C本地实体的组号。     |
| IP地址类型  | 该参数用于指示GTP-C本地实体的IP地址类型。 |
| IPv4地址  | 该参数用于指示GTP-C本地实体的IPv4地址。 |
| IPv6地址  | 该参数用于指示GTP-C本地实体的IPv6地址。 |
| VPN名称   | 该参数用于指示GTP-C本地实体的VPN名称。  |
| 描述信息    | 该参数用于指示GTP-C本地实体的描述信息。   |
