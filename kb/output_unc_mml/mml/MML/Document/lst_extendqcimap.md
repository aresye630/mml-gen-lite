# 查询扩展QCI和标准QCI的映射关系（LST EXTENDQCIMAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C、SMF、GGSN**

该命令用于查询扩展QCI和标准QCI的映射关系，并查询扩展QCI的优先级。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                 |
|:----------|:--------|:---------------------------------------------------------------------------------------------------------------------|
| EXTENDQCI | 扩展QCI的值 | 可选必选说明：可选参数  参数含义：该参数用来指定扩展QCI。  数据来源：全网规划  取值范围：整数类型，取值范围是10~255。  默认值：无  配置原则：  该参数值不能与命令ADD STDQOSID中配置的QoS ID一致。 |

## 使用实例

查询“扩展QCI”与“标准QCI”的对应关系。指定“扩展QCI”为“133”：

```
%%LST EXTENDQCIMAP: EXTENDQCI=133;%%
RETCODE = 0  操作成功

结果如下
--------
    扩展QCI的值  =  133
    标准QCI的值  =  1
扩展QCI的优先级  =  1
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称     | 输出项解释                               |
|:----------|:------------------------------------|
| 扩展QCI的值   | 该参数用来指定扩展QCI。                       |
| 标准QCI的值   | 该参数用来指定标准QCI。                       |
| 扩展QCI的优先级 | 该参数用来指定EXTENDQCI的优先级，值越小业务转发的优先级越高。 |
