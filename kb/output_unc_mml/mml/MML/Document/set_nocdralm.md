# 设置未接收到话单告警参数（SET NOCDRALM）

- 命令功能

- 本地用户权限
- 网管用户权限

- 使用实例

#### 命令功能

**适用NF：NCG**

该命令用于设置**ALM-82021 NCG长时间未接收到话单**告警的管理参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始设置记录，参数的初始设置值如下表：

| SWITCHSTATE   |   TIMEOUT |
|:--------------|----------:|
| OFF           |         5 |

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                                                                                           |
|:------------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SWITCHSTATE | 告警开关       | 可选必选说明：必选参数 参数含义：该参数用于设置是否支持ALM-82021 NCG长时间未接收到话单告警上报，“OFF(关闭)”为禁止上报此告警，“ON(开启)”为支持上报此告警。 数据来源：全网规划 取值范围：枚举类型。 OFF：关闭。ON：开启。 默认值：无 配置原则：无                                     |
| TIMEOUT     | 告警检测周期（分钟） | 可选必选说明：条件可选参数 前提条件：该参数在“SWITCHSTATE”配置为“ON”时为条件可选参数。 参数含义：该参数用于设置NCG的ALM-82021 NCG长时间未接收到话单告警的检测周期。超过这个时间，NCG未接收到链路上的话单时，则发送此告警。 数据来源：全网规划 取值范围：整数类型，取值范围为1～1440。 默认值：无 配置原则：无 |

#### 使用实例

设置**ALM-82021 NCG长时间未接收到话单**的“告警开关”为“ON(开启)”，“告警检测周期（分钟）”为默认值“5”：

```
SET NOCDRALM: SWITCHSTATE=ON, TIMEOUT=5;
```
