#### 命令功能

**适用网元：MME**

该命令用于查询大端模式SCTP接收缓冲区参数。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询大端模式SCTP接收缓冲区参数：

LST BIGSCTPRXNUM:;

```
%%LST BIGSCTPRXNUM:;%%
RETCODE = 0  操作成功
输出结果如下
------------------------
私有模式max块数目  =  120
 私有模式耦连个数  =  144
共享模式max块数目  =  120
(结果个数 = 1)

---    END
```

#### 输出结果说明

请参考**SET BIGSCTPRXNUM**的参数标识。
