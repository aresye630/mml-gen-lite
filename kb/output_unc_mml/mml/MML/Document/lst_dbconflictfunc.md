# 查询AMF热备容灾数据冲突策略参数（LST DBCONFLICTFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询AMF热备容灾数据冲突策略参数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询AMF热备容灾数据冲突策略参数，执行如下命令：

```
%%LST DBCONFLICTFUNC:;%%
RETCODE = 0  操作成功

结果如下
--------
         数据冲突扫描功能开关 = 打开
             单位扫描时间(秒) = 1
                 单位扫描个数 = 1
B-AMF处理数据冲突用户功能开关 = 打开
 接口恢复扫描延迟生效时间(秒) = 7200
             寻呼失败处理策略 = 默认方式
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称             | 输出项解释                                                                                                                 |
|:------------------|:----------------------------------------------------------------------------------------------------------------------|
| 数据冲突扫描功能开关        | 该参数用于控制开启AMF热备容灾数据冲突扫描功能开关。                                                                                           |
| 单位扫描时间(秒)         | 该参数用于表示AMF对用户扫描的时间间隔。                                                                                                 |
| 单位扫描个数            | 该参数用于表示每个DS每间隔INTERVAL设置的时间扫描多少个用户，扫描到后对用户数据进行数据冲突处理。                                                                 |
| B-AMF处理数据冲突用户功能开关 | 该参数用于控制B-AMF是否处理冲突扫描任务。                                                                                               |
| 接口恢复扫描延迟生效时间(秒)   | 该参数用于指定N2/SBI接口恢复后，数据冲突扫描任务延迟生效的时间。 在热备容灾特性使能的场景下，当容灾通道故障并且N2接口持续故障超过10分钟后，N2/SBI接口闭塞；在容灾通道恢复后并且等待数据核查完成后，N2/SBI接口恢复。 |
| 寻呼失败处理策略          | 该参数用于设置数据冲突扫描任务寻呼用户流程失败的处理策略。                                                                                         |
