# 查询AMF重选控制策略（LST AMFRESELPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询AMF重选功能控制策略。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                       |
|:---------|:-------|:---------------------------------------------------------------------------------------------------------------------------|
| SUBGRPID | 用户群组标识 | 可选必选说明：可选参数  参数含义：该参数用于指定应用AMF重选功能的用户群组。  数据来源：全网规划  取值范围：整数类型，取值范围是0~4294967294。该用户群组标识通过ADD NGUSRGRP进行添加。  默认值：无  配置原则：无 |

## 使用实例

查询用户群组1对应的AMF重选策略，执行命令如下：

```
%%LST AMFRESELPLCY: SUBGRPID=1;%%
RETCODE = 0  操作成功

结果如下
------------------------
用户群组标识  =  1
 AMF实例标识  =  AMF-INSTANCEID-1
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                  |
|:--------|:-----------------------|
| 用户群组标识  | 该参数用于指定应用AMF重选功能的用户群组。 |
| AMF实例标识 | 本参数用于指定重定向目标AMF实例标识。   |
