# 删除QoS接口信任（RMV QOSIFTRUST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来删除绑定在以太主接口上的DS域。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                |
|:-------|:-------|:----------------------------------------------------------------------------------------------------|
| IFNAME | 接口名称   | 可选必选说明：必选参数 参数含义：该参数用于指定一个接口。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：使用LST INTERFACE命令查看可用接口。 |

#### 使用实例

删除配置在以太主接口Ethernet66/0/3上的DS域：

```
RMV QOSIFTRUST:IFNAME="Ethernet66/0/3";
```
