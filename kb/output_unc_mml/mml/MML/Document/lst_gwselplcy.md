# 查询GGSN/P-GW选择策略（LST GWSELPLCY）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询GGSN/P-GW选择策略。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                                                                                                                        |
|:------------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE    | 用户范围     | 可选必选说明：可选参数 参数含义：该参数用于指定待增加GGSN/P-GW选择策略的用户范围。 取值范围：“ALL_USER（所有用户）”“IMSI_PREFIX（指定IMSI前缀）”“IMSI_RANGE（指定IMSI范围）”“FOREIGN_USER（外网用户）”“HOME_USER（本网用户）”“MSISDN_PREFIX(指定MSISDN前缀)”“SPECIFIC_IMSI(特定IMSI)”“SPECIFIC_MSISDN(特定MSISDN)” 默认值：无                                   |
| IMSIPRE     | IMSI前缀   | 可选必选说明：条件可选参数 参数含义：该参数用于指定IMSI前缀。 前提条件：只有“用户范围”为“IMSI_PREFIX（指定IMSI前缀）”时，该参数才有效。 取值范围：1～15位十进制数字字符串 默认值：无                                                                                                                                                                   |
| BEGIMSI     | 起始IMSI   | 可选必选说明：条件可选参数 参数含义：该参数用于指定所要查询的IMSI。 前提条件：只有“用户范围”为“IMSI_RANGE（指定IMSI范围）”时，该参数才有效。 取值范围：1～15位十进制数字字符串 默认值：无                                                                                                                                                                 |
| NOID        | 运营商标识    | 可选必选说明：条件可选参数 参数含义：该参数用于指定运营商标识 前提条件：该参数在“SUBRANGE（用户范围）”配置为“FOREIGN_USER（外网用户）”或“HOME_USER（本网用户）”后生效。 对于外网用户，该参数用于指定与互联PLMN签订漫游协议的本局运营商标识，对于本网用户，该参数是本网用户对应的运营商标识。 数据来源：整网规划 取值范围：0～64，128～254 默认值：无                                                                       |
| USERSUBTYPE | 用户子类     | 可选必选说明：条件可选参数 参数含义：该参数用于指定本网用户的范围，本网用户范围可以是本网所有用户、本网本地用户或本网异地用户。 签约数据中心接口为Gr时，才能获取HLR Number，通过HLR Number来细分本网用户为本地用户或异地用户；当签约数据中心接口为S6d时，由于无法获取HLR Number，不能对本网用户细分为本地用户或异地用户。 前提条件：该参数在“SUBRANGE（用户范围）”参数配置为“HOME_USER（本网用户）”时生效。 数据来源：整网规划 取值范围：本网所有用户本网本地用户本网异地用户 默认值：无 |
| MSISDNPRE   | MSISDN前缀 | 可选必选说明：条件可选参数 参数含义：该参数用于指定MSISDN前缀。 前提条件: 只有“SUBRANGE（用户范围）”为“MSISDN_PREFIX(指定MSISDN前缀)”时，该参数才有效。 数据来源：整网规划 取值范围：1～15位十进制数字字符串 默认值：无                                                                                                                                        |
| IMSI        | IMSI     | 可选必选说明：条件可选参数 参数说明：该参数用于指定国际移动用户标识。 前提条件：此参数在“用户范围”设置为“SPECIFIC_IMSI(特定IMSI)”后生效。 取值范围：15位十进制数字字符串 默认值：无                                                                                                                                                                    |
| MSISDN      | MSISDN   | 可选必选说明：条件可选参数 参数说明：该参数用于指定移动台国际ISDN号码。 前提条件：此参数在“用户范围”设置为“SPECIFIC_MSISDN (特定MSISDN)”后生效。 取值范围：13位十进制数字字符串 默认值：无                                                                                                                                                            |
| APNNI       | APNNI    | 可选必选说明：可选参数 参数含义：该参数用于指定APNNI。 取值范围：1～62位字符串 默认值：无 配置原则：APN网络标识地址由一个或多个LABEL构成，各LABEL间用“.”间隔。每个LABEL的构成字符只能是字母A～Z或a～z、数字0～9和中划线“-”。APN网络标识地址不能以“rac”、“lac”、“sgsn”或“rnc”开头，不能以“.gprs”结尾符号“*”表示通配符，即不限制APNNI。 如果APNNI为“*”，表示该记录适用于所有的APNNI，否则该记录适用于指定的APNNI记录。                |
