# 删除IMS PCF的DNN（RMV NRFIMSDNN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

执行该命令后，NRF的号段防呆规则会过滤独立部署的语音PCF（该类PCF无号段），导致独立部署的语音PCF无法被服务发现，引起语音业务失败。若要删除，则需要明确独立部署的语音PCF不支持该DNN。

**适用NF：NRF**

如果运营商希望在NRF上删除IMS PCF的DNN信息，执行此命令。

## 注意事项

- 该命令执行后立即生效。

- 主备或双活组网的场景下，如果需要配置此命令，则两个NRF上均需执行此命令，且配置参数一致。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                 |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DNN    | 数据网络名称 | 可选必选说明：必选参数  参数含义：该参数用于表示IMS PCF的数据网络名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~64。字符串类型，输入长度范围是0~64。该参数不区分大小写。  默认值：无  配置原则：  PCF支持的DNN等于或包含了配置的DNN信息，即认为该DNN在配置中已生效。  NRF上认为PCF是独立部署的条件是，PCF携带的DNN信息全部在NRF上已配置。  例如：  PCF规划支持ims.xa和ims.gz两个DNN：  当只配置一条“ims”记录时，NRF认为其是独立部署的；  当配置两条“ims.xa”和“ims.gz”记录时，NRF认为其是独立部署的；  当只配置一条“ims.xa”记录时，NRF认为其是非独立部署的。 |

## 使用实例

删除DNN信息为“huawei.com”的记录，在NRF上执行：

```
RMV NRFIMSDNN: DNN="huawei.com";
```
