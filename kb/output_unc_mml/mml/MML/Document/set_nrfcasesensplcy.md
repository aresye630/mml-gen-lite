# 设置NRF大小写敏感策略（SET NRFCASESENSPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于设置NRF注册和服务发现场景下大小写敏感策略。

## 注意事项

- 该命令执行后立即生效。

- 该命令在CASESENSPARA设置为locality，MATCHSENSSW设置为OFF时不生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| CASESENSPARA   | PARALOWERCASESW   | MATCHSENSSW   |
|:---------------|:------------------|:--------------|
| ServingScope   | FUNC_ON           | FUNC_ON       |
| Locality       | FUNC_ON           | FUNC_ON       |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称        | 参数说明                                                                                                                                                                                                                                 |
|:----------------|:------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CASESENSPARA    | 大小写敏感参数     | 可选必选说明：必选参数  参数含义：该参数用于指定NF注册和服务发现时携带的需要做大小写敏感处理的参数。  数据来源：本端规划 取值范围： ServingScope（ServingScope）“Locality（Locality）”：服务发现场景下，该参数特指服务发现参数中的PreferredLocality。  默认值：无。  配置原则：无                                                         |
| PARALOWERCASESW | NF参数大小写转换开关 | 可选必选说明：可选参数  参数含义：该参数用于表示是否对NF向NRF注册、服务发现消息中指定参数进行大小写转换处理。开关打开 ，表示将指定参数转换为小写；开关关闭，表示保存原始格式。  数据来源：本端规划 取值范围： “FUNC_ON（打开）”：功能开关打开“FUNC_OFF（关闭）”：功能开关关闭  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST NRFCASESENSPLCY查询当前参数配置值。  配置原则：无    |
| MATCHSENSSW     | 大小写敏感匹配开关   | 可选必选说明：可选参数  参数含义：该参数用于表示NF携带指定参数服务发现时，NRF是否进行大小写敏感匹配。 开关打开，表示指定参数大小写不敏感匹配；开关关闭，表示指定参数大小写敏感匹配。  数据来源：本端规划 取值范围： “FUNC_ON（打开）”：功能开关打开“FUNC_OFF（关闭）”：功能开关关闭  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST NRFCASESENSPLCY查询当前参数配置值。  配置原则：无 |

## 使用实例

运营商希望NRF将收到的指定参数大小写敏感处理以及服务发现参数大小写敏感匹配，可执行如下命令：

```
SET NRFCASESENSPLCY: CASESENSPARA=ServingScope, PARALOWERCASESW=FUNC_OFF, MATCHSENSSW=FUNC_OFF;
```
