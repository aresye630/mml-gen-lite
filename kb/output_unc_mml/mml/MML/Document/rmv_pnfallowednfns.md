# 删除对端NF允许的切片信息（RMV PNFALLOWEDNFNS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、NSSF、SMSF、NCG、CBC、CBCF**

该命令用于删除对端NF服务支持的允许访问的切片信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                            |
|:--------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCEID  | NF实例标识  | 可选必选说明：必选参数  参数含义：该参数用于指定对端NF的实例标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~50。NFINSTANCEID参数必须满足以下约束规则：1.如果输入为uuid格式（格式例如：a6a61c6f-0d3a-4221-b1da-424eda3ccf67）只能为A-F、a-f、0-9和“-”的字符。2.如果输入不为uuid格式，长度不能超过18且不允许输入只包含0-9和“.”的字符串，例如：1.2.3.4、不允许输入只包含十六进制数（A-F、a-f、0-9）和“:”的字符串，例如：1::2、FBFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。3.该参数大小写不敏感。  默认值：无  配置原则：  本参数取值需要与ADD PNFPROFILE命令中的“NF实例标识”参数取值保持一致。 |
| SRVINSTANCEID | 服务实例标识  | 可选必选说明：必选参数  参数含义：该参数用于指定对端NF实例的服务实例标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~50。该参数大小写不敏感。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                            |
| SST           | 切片/服务类型 | 可选必选说明：必选参数  参数含义：该参数用于指定对端NF实例的切片/服务类型。  数据来源：本端规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                       |
| SD            | 切片区分码   | 可选必选说明：必选参数  参数含义：该参数用于指定对端NF的切片区分码。如果切片需要进一步细化子切片可配置该参数。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~50。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                    |

## 使用实例

删除对端NF支持的切片信息，NF实例标识为SMF\_Instance\_0，服务实例标识为Service\_Instance\_0，SST为1，SD为010101。

```
RMV PNFALLOWEDNFNS: NFINSTANCEID="SMF_Instance_0", SRVINSTANCEID="Service_Instance_0", SST=1, SD="010101";
```
