# 查询位置区域DNS域名(LST AREADNS)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询位置区域DNS域名。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称          | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|:-------|:--------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DNTYPE | 域名类型          | 可选必选说明：可选参数 参数含义：该参数用于指定域名类型。 取值范围：“SGW_RAI（根据路由区（RAI）查找SGW）”“SGW_TAI（根据跟踪区（TAI）查找SGW）”“SGSN_RAI（根据路由区（RAI）查找SGSN）”“MME_TAI（根据跟踪区（TAI）查找MME）”“GGSN/PGW_RAI（根据路由区（RAI）查找GGSN/PGW）”“PGW_TAI（根据跟踪区（TAI）查找PGW）”“MSC_RAI（根据路由区（RAI）查找MSC）”“MSC_LAI（根据位置区（LAI）查找MSC）”“GGSN/PGW_LAI（根据位置区（LAI）查找GGSN/PGW）”“SGW_LAI（根据位置区（LAI）查找SGW）”“SGSN_LAI（根据位置区（LAI）查找SGSN）”“MME_TAI_UUT（根据跟踪区（TAI）和UE USAGE TYPE查找MME）”“SGW_TAI_UUT（根据跟踪区（TAI）和UE USAGE TYPE查找SGW）”“MMEGI_TAI_UUT（根据跟踪区（TAI）和UE USAGE TYPE查找MMEGI）” 默认值：无 |
| LAC    | 位置区域码         | 可选必选说明：条件可选参数 参数含义：该参数用于指定位置区域码 前提条件：该参数在“域名类型”参数配置为“SGW_RAI（根据路由区（RAI）查找SGW）”或“SGSN_RAI（根据路由区（RAI）查找SGSN）”或“GGSN/PGW_RAI（根据路由区（RAI）查找GGSN/PGW）”或“MSC_RAI（根据路由区（RAI）查找MSC）”或“MSC_LAI（根据位置区（LAI）查找MSC）”或“SGW_LAI（根据位置区（LAI）查找SGW）”或“SGSN_LAI（根据位置区（LAI）查找SGSN）”或“GGSN/PGW_LAI（根据位置区（LAI）查找GGSN/PGW）”后显示。 取值范围：0x0000～0xFFFF 默认值：无 配置原则：该参数的值必须为已经在ADD AREADNS命令中配置的LAC字段的值  说明： 用户在输入值的时候，可以加上“0x”前缀，也可以不加此前缀，都会被处理为16进制的数字。                                                                             |
| RAC    | 路由区域码         | 可选必选说明：条件可选参数 参数含义：该参数用于指定路由区域码 前提条件：该参数在“DNTYPE”参数配置为“SGW_RAI（根据路由区（RAI）查找SGW）”或“SGSN_RAI（根据路由区（RAI）查找SGSN）”或“GGSN/PGW_RAI（根据路由区（RAI）查找GGSN/PGW）”或“MSC_RAI（根据路由区（RAI）查找MSC）”后显示。 取值范围：0x00～0xFF 默认值：无 配置原则：该参数的值必须为已经在ADD AREADNS命令中配置的RAC字段的值  说明： 用户在输入值的时候，可以加上“0x”前缀，也可以不加此前缀，都会被处理为16进制的数字。                                                                                                                                                                                                       |
| TAC    | 跟踪区域码         | 可选必选说明：条件可选参数 参数含义：该参数用于指定跟踪区域码 前提条件：该参数在“DNTYPE”参数配置为“SGW_TAI（根据跟踪区（TAI）查找SGW）”或“MME_TAI（根据跟踪区（TAI）查找MME）”后显示。 取值范围：0x0000～0xFFFF 默认值：无  说明： 用户在输入值的时候，可以加上"0x"前缀，也可以不加此前缀，都会被处理为16进制的数字。                                                                                                                                                                                                                                                                                                              |
| UUT    | UE USAGE TYPE | 可选必选说明：条件必选参数 参数含义：该参数用于指定UE USAGE TYPE。 前提条件： 该参数在“域名类型”参数配置为“根据跟踪区（TAI）和UE USAGE TYPE查找MME”后生效。 该参数在“域名类型”参数配置为“根据跟踪区（TAI）和UE USAGE TYPE查找SGW”后生效。 该参数在“域名类型”参数配置为“根据跟踪区（TAI）和UE USAGE TYPE查找MMEGI”后生效。 数据来源：全网规划 取值范围：整数类型，取值范围为0~255 默认值：无                                                                                                                                                                                                                                                          |
