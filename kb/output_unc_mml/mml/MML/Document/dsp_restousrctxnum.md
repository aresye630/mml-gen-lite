#### 命令功能

**适用网元：MME**

本命令用于查询系统内备份用户的数量。查询输出结果为查询时刻的备份用户数量。

输出结果分为2个报告，1个报表显示对应RU名称、进程的备份用户数；1个报表显示系统内总的备份用户数。

#### 注意事项

无

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                              |
|:-------|:-------|:----------------------------------------------------------------------------------|
| RUNAME | RU名称   | 可选必选说明：可选参数 参数含义：本参数显示备份用户处在的RU名称。该参数可以通过DSP RU命令查询。 数据来源：本端规划 取值范围：1~63字符串 默认值：无 |
| PRON   | 进程号    | 可选必选说明：可选参数 参数含义：本参数表示备份用户处在的进程序号。 数据来源：本端规划 取值范围：0~20 默认值：无                      |

#### 输出结果说明

| 输出项名称                | 输出项解释                                                                                                                                                                                            |
|:---------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RU名称                 | 参数含义：本参数显示RU名称。 取值范围：1~63字符串                                                                                                                                                                     |
| 进程号                  | 参数含义：本参数备份用户所在的SPP进程号。 取值范围：0~20                                                                                                                                                                 |
| MM上下文数               | 参数含义：本参数表示备份的MM上下文数量。 取值范围：0~4294967295                                                                                                                                                          |
| PDN连接数               | 参数含义：本参数表示备份的PDN上下文数量。 取值范围：0~4294967295                                                                                                                                                         |
| 承载上下文数               | 参数含义：本参数表示备份的承载数量。 取值范围：0~4294967295                                                                                                                                                             |
| MM签约上下文数             | 参数含义：本参数表示备份的MM签约上下文数量。  说明： 当用户分离，或者符合容灾APN特征的PDN连接去激活后，S-USN的签约上下文不会立即删除。显示的结果包含了在线备份用户的MM签约上下文数，也包含曾经备份过MM签约上下文，并且当前处于分离态，或者符合容灾APN特征的PDN连接已去激活的用户的MM签约上下文。 取值范围：0~4294967295                 |
| APN/PDP签约上下文数        | 参数含义：本参数表示备份的APN签约上下文数量。  说明： 当用户分离，或者符合容灾APN特征的PDN连接去激活后，S-USN的签约上下文不会立即删除。显示的结果包含了在线备份用户的APN/PDP签约上下文数，也包含曾经备份过APN/PDP签约上下文，并且当前处于分离态，或者符合容灾APN特征的PDN连接已去激活的用户的APN/PDP签约上下文。 取值范围：0~4294967295 |
| 在线备份用户的MM签约上下文数      | 参数含义：本参数表示在线备份用户的APN/PDP签约上下文数量。“在线备份用户的APN/PDP签约上下文数”小于等于“APN/PDP签约上下文数”。 取值范围：0~4294967295                                                                                                     |
| 在线备份用户的APN/PDP签约上下文数 | 参数含义：本参数表示在线备份用户的APN/PDP签约上下文数量。“在线备份用户的APN/PDP签约上下文数”小于等于“APN/PDP签约上下文数”。 取值范围：0~4294967295                                                                                                     |
