# 查询容灾定时器（LST DRHBNEGOTIMER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询容灾定时器。

## 注意事项

该命令适用于支持热备或冷备容灾的网元执行。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                       |
|:----------|:-------|:---------------------------------------------------------------------------------------------------------------------------|
| DRGROUPID | 容灾组标识  | 可选必选说明：可选参数  参数含义：该参数用来标识一个容灾组，该标识必须存在于容灾组信息中，容灾组信息可以使用LST DRGROUPINFO命令查询。  数据来源：全网规划  取值范围：整数类型，取值范围是1~8。  默认值：无  配置原则：无 |

## 使用实例

- 查询所有的容灾定时器:

  ```
  %%LST DRHBNEGOTIMER:;%%
  RETCODE = 0  操作成功

  结果如下
  --------
                   容灾组标识 = 1
    心跳消息重传时间(100毫秒) = 10
    协商消息重传时间(100毫秒) = 10
                     重传次数 = 30
           OM通道心跳重传次数 = 3
  OM通道心跳探测时长(100毫秒) = 10
  (结果个数 = 1)

  ---    END
  ```
- 查询指定容灾组的容灾定时器:

  ```
  %%LST DRHBNEGOTIMER: DRGROUPID=1;%%
  RETCODE = 0  操作成功

  结果如下
  --------
                   容灾组标识 = 1
    心跳消息重传时间(100毫秒) = 10
    协商消息重传时间(100毫秒) = 10
                     重传次数 = 30
           OM通道心跳重传次数 = 3
  OM通道心跳探测时长(100毫秒) = 10
  (结果个数 = 1)

  ---    END
  ```

## 输出结果说明

| 输出项名称             | 输出项解释                                                     |
|:------------------|:----------------------------------------------------------|
| 容灾组标识             | 该参数用来标识一个容灾组，该标识必须存在于容灾组信息中，容灾组信息可以使用LST DRGROUPINFO命令查询。 |
| 心跳消息传递间隔(100毫秒)   | 该参数用于配置容灾组内网元间发送心跳消息的间隔时间。                                |
| 协商消息传递间隔(100毫秒)   | 该参数用于配置容灾组内网元间发送协商消息的间隔时间。                                |
| 重传次数              | 该参数用于配置容灾组内网元间发送心跳和协商消息的重传次数。                             |
| OM通道心跳重传次数        | 该参数用于配置容灾组内OM通道发送心跳的重传次数。                                 |
| OM通道心跳探测时长(100毫秒) | 该参数用于配置容灾组OM通道发送心跳消息的间隔时间。                                |
