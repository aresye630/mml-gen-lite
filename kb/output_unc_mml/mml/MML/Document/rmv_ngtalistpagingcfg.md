# 删除N2模式TALIST寻呼不重发TAC区间（RMV NGTALISTPAGINGCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除N2模式TALIST寻呼不重发TAC区间。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                              |
|:---------|:--------|:----------------------------------------------------------------------------------------------------------------------------------|
| MCC      | MCC     | 可选必选说明：必选参数  参数含义：该参数用于表示组成PLMN的移动国家码信息。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。  默认值：无  配置原则：无                                            |
| MNC      | MNC     | 可选必选说明：必选参数  参数含义：该参数用于表示组成PLMN的移动网号信息。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。  默认值：无  配置原则：无                                         |
| TACSTART | 跟踪区域起始值 | 可选必选说明：必选参数  参数含义：该参数用于指定跟踪区域起始编码。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。  默认值：无  配置原则：  本参数由6位十六进制数组成，不区分大小写。MCC、MNC相同时，不同记录的TAC区间不能有交集。 |

## 使用实例

删除TAC起始为11BF85的跟踪区间，执行如下命令：

```
RMV NGTALISTPAGINGCFG: MCC="123", MNC="45",TACSTART="11BF85";
```
