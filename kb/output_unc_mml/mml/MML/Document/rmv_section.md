# 删除地址段（RMV SECTION）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

使用该命令后会将强制删除正在使用的地址，对应的正常在线用户将被去活。

**适用NF：SMF、PGW-C、GGSN**

该命令为删除地址池里的地址段，当某一地址段不再使用时，UNC可使用该命令将其删除。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                             |
|:-----------|:-------|:-----------------------------------------------------------------------------------------------------------------|
| POOLNAME   | 地址池名称  | 可选必选说明：必选参数  参数含义：该参数用于指定已配置的地址池的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~79。  默认值：无  配置原则：  该参数使用ADD ADDRPOOL命令配置生成。 |
| SECTIONNUM | 地址段号   | 可选必选说明：必选参数  参数含义：该参数用于指定配置Section的编号。  数据来源：本端规划  取值范围：整数类型，取值范围是0~63。  默认值：无  配置原则：无                           |

## 使用实例

当不使用地址池名为pool1中的序号为0的地址段时，可以删除该地址段。

```
RMV SECTION:POOLNAME="pool1",SECTIONNUM=0;
```
