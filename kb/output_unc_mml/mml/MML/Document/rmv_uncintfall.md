# 删除UNC所有接口名称（RMV UNCINTFALL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，操作此命令会导致已上报至北向的网元的接口信息全部被删除，影响北向上报。

**适用NF：SGSN、MME、SGW-C、AMF、PGW-C、SMF、NRF、NSSF、GGSN、SMSF、NCG**

该命令用于删除已经上报至网管北向UNC网元的所有业务或者管理接口的名称。

## 注意事项

- 该命令执行后立即生效。

- 如果需要执行此命令，删除所有上报给网管北向的接口信息，不配置输入参数即可。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                                                |
|:-----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NRMVNFTYPE | 北向网元类型 | 可选必选说明：可选参数  参数含义：该参数用于指定UNC网元的北向网元类型。  数据来源：本端规划 取值范围： AMF（AMF）MME（MME）SGSN（SGSN）SMF（SMF）PGWC（PGWC）SGWC（SGWC）GGSNC（GGSNC）ProxySGWC（ProxySGWC）NRF（NRF）NSSF（NSSF）SMSF（SMSF）CHF（CHF）ProxySMF（ProxySMF）  默认值：无  配置原则：无 |
| INTFTYPE   | 接口类型   | 可选必选说明：可选参数  参数含义：该参数用于指定UNC网元的接口名称。其中，Mgt为网元和网管的对接接口；DnsQry为SGSN、MME、AMF网元的DNS本端实体与DNS服务器进行通信的接口；Bx为NCG网元与计费账务域交互的文件接口；其他为协议定义的接口。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。  默认值：无  配置原则：无                              |

## 使用实例

删除已经上报至网管北向UNC网元的所有业务或者管理接口的名称，执行以下命令：

```
RMV UNCINTFALL:;
```
