# 系统状态查询（DSP SYSRUNNINGSTAT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询系统运行状态。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                              |
|:-------|:-------|:----------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：可选参数  参数含义：该参数用于标识网元ID。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~40。  默认值：无  配置原则：无 |

## 使用实例

DSP SYSRUNNINGSTAT;

```
DSP SYSRUNNINGSTAT;
%%DSP SYSRUNNINGSTAT:;%%
RETCODE = 0  操作成功

结果如下
--------
系统状态 = 系统状态正常
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                              |
|:--------|:-----------------------------------------------------------------------------------------------------------------------------------|
| 系统状态    | 该参数用于表示系统的运行状态。 取值说明： “Healing（自愈中）”：VNF正在执行自愈“Scaling（伸缩中）”：VNF正在执行伸缩“FeatureAltering（正在执行上下线）”：VNF正在执行上下线“Normal（系统状态正常）”：系统状态正常 |
