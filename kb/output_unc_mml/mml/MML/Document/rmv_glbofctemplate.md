# 删除全局离线计费模板（RMV GLBOFCTEMPLATE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

此命令用来删除基于CC配置的离线模板，或者恢复全局缺省离线模板。

#### 注意事项

- 该命令执行后立即生效。
- 离线计费模板绑定到全局离线计费模板不可删除，只能恢复成默认值。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称                   | 参数说明                                                                                                                                                                                                                |
|:-------------|:-----------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GLOBALFLAG   | 全局记录                   | 可选必选说明：必选参数 参数含义：可以为计费属性绑定离线计费模板，也可以为全局绑定离线计费模板。 数据来源：本端规划 取值范围：枚举类型。 GLOBAL：指定计费属性为缺省全局计费属性。CHARGE_CHARACT：指定计费属性为配置的特殊计费属性值。 默认值：无 配置原则：无                                                                         |
| CCVALUE      | Charge Characteristic值 | 可选必选说明：条件必选参数 前提条件：该参数在“GLOBALFLAG”配置为“CHARGE_CHARACT”时为必选参数。 参数含义：指定Charge Characteristic值。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～6。该参数为十六进制数据类型，仅支持输入0x/X、a-f/A-F 、0-9，允许不输入0x前缀，字母不区分大小写，取值范围0x0000~0xFFFF。 默认值：无 配置原则：无 |
| TEMPLATETYPE | 模板类型                   | 可选必选说明：条件可选参数 前提条件：该参数在“GLOBALFLAG”配置为“GLOBAL” 或 “CHARGE_CHARACT”时为可选参数。 参数含义：指定要删除的模板类型。 数据来源：本端规划 取值范围：枚举类型。 PGW_TEMPLATE：指定PGW离线计费模板。SGW_TEMPLATE：指定SGW离线计费模板。GGSN_TEMPLATE：指定GGSN离线计费模板。 默认值：无 配置原则：无           |

#### 使用实例

删除指定的基于CC配置的离线计费模板，GLOBALFLAG为CHARGE\_CHARACT，CCVALUE为0x0003，TEMPLATETYPE为SGW\_TEMPLATE的配置：

```
RMV GLBOFCTEMPLATE:GLOBALFLAG=CHARGE_CHARACT,CCVALUE="0x3",TEMPLATETYPE=SGW_TEMPLATE;
```
