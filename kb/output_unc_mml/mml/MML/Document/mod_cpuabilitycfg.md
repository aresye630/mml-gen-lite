# 修改不同CPU类型的能力系数和基础消耗。（MOD CPUABILITYCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

如果配置不合理会导致会动态权重失效以及token迁移不能处于稳态。

**适用NF：GGSN、SGW-C、SMF、PGW-C**

该命令用于修改不同CPU类型的能力系数和基础消耗。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                        |
|:-------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------|
| CPUTYPE      | CPU类型  | 可选必选说明：必选参数  参数含义：该参数用于指定CPU类型。  数据来源：本端规划 取值范围： X86_64（X86机器CPU类型）Aarch（ARM机器CPU类型）  默认值：无  配置原则：无                                         |
| CPUGENERATE  | CPU代际  | 可选必选说明：必选参数  参数含义：该参数用于指定CPU代际。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。当cpu类型是ARM时，固定字符“arch64”，其他字符不生效。  默认值：无  配置原则：无                        |
| CPUFREQUENCY | CPU主频  | 可选必选说明：必选参数  参数含义：该参数用于指定CPU主频。  数据来源：本端规划  取值范围：整数类型，取值范围是0~32767。  默认值：无  配置原则：无                                                          |
| COEFFICIENT  | 能力系数   | 可选必选说明：可选参数  参数含义：该参数用于指定CPU能力系数。  数据来源：本端规划  取值范围：整数类型，取值范围是500~32767。  默认值：无  配置原则：无                                                      |
| BASECOST     | 基础消耗   | 可选必选说明：可选参数  参数含义：该参数用于指定CPU基础消耗。  数据来源：本端规划  取值范围：整数类型，取值范围是0~15。  默认值：无  配置原则：  执行DSP PODCPUSTAT查看调整pod的CPU利用率，若查询所得CPU利用率小于基础消耗，动态权重不调整。 |

## 使用实例

修改一个服务类型为x86\_64、代际为1、主频为1的CPU的能力系数为32767、基础消耗为0，执行如下命令：

```
MOD CPUABILITYCFG: CPUTYPE=X86_64, CPUGENERATE="1", CPUFREQUENCY=1, COEFFICIENT=32767, BASECOST=0, CONFIRM=Y;
```
