# 删除选路指示器（RMV NFROUTINGIND）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于在NRF上删除选路指示器，例如应用于UDM割接的场景，需要在NRF上将原UDM配置的选路指示器删除。

## 注意事项

- 该命令执行后立即生效。

- 主备或双活组网的场景下，如果需要配置此命令，则两个NRF上均需执行此命令，且配置参数一致。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                  |
|:-----------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFGROUPID  | NF组标识  | 可选必选说明：必选参数  参数含义：该参数用于表示支持ROUTIINGIND号段的NF组标识，该参数可以通过LST NFGROUP命令查看。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~128。该参数只能由字母（A-Z或者a-z）、数字（0-9）、中划线（-）组成，不区分大小写。  默认值：无  配置原则：无 |
| ROUTINGIND | 选路指示器  | 可选必选说明：必选参数  参数含义：该参数用于表示支持ROUTIINGIND号段信息。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~4。取值范围0-9999。  默认值：无  配置原则：  当NF组支持ROUTINGIND为通配时，需要将ROUTINGIND设置为ALL。                    |

## 使用实例

对NF组标识为nfgroup001的NF组删除值为1000的选路指示器：

```
RMV NFROUTINGIND: NFGROUPID="nfgroup001", ROUTINGIND="1000";
```
