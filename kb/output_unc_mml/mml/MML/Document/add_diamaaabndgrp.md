# 增加Diameter AAA服务器到Diameter AAA服务器组（ADD DIAMAAABNDGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C**

此命令用于绑定指定的Diameter AAA到Diameter AAA组。当新建立的non-3GPP会话需要到某个Diameter AAA鉴权时，操作员可以执行此命令增加该绑定关系。

## 注意事项

- 该命令执行后对新接入的non-3GPP会话生效。

- 该命令最大记录数为20。
- 对于同一个服务器组，添加记录时，请先添加主用服务器再添加备用服务器；删除记录时，请先删除备用服务器再删除主用服务器。
- 对于同一个服务器组，主用服务器和备用服务器的VPN需要相同。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称           | 参数说明                                                                                                                                                                                                                                                                                                                                                    |
|:-----------|:---------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GROUPNAME  | Diameter AAA组名 | 可选必选说明：必选参数  参数含义：该参数用于指定Diameter AAA组名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。不区分大小写，不支持空格。  默认值：无  配置原则：  1、该参数使用ADD DIAMAAAGRP命令配置生成。                                                                                                                                                                                                                   |
| SERVERTYPE | 服务器类型          | 可选必选说明：必选参数  参数含义：该参数用于指定服务器类型。  数据来源：本端规划 取值范围： “PARA_3GPP（3GPP AAA服务器）”：表示使用遵循3GPP协议的服务器。  默认值：无  配置原则：无                                                                                                                                                                                                                                              |
| HOSTNAME   | 主机名            | 可选必选说明：必选参数  参数含义：该参数用于指定Diameter AAA。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~127。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，由软参BIT150控制是否区分大小写。BIT150值为0时，不区分大小写；值为1时，区分大小写，但不允许配置多个仅大小写不同的host-name或realm-name。BIT150详细信息请参见产品文档中的《UNC软件参数》。  默认值：无  配置原则：  1、该参数使用ADD DIAMETERAAA命令配置生成。 |
| PRIORSEC   | 主备用标记          | 可选必选说明：必选参数  参数含义：该参数用于指定服务器主备标记。  数据来源：本端规划 取值范围： “PRIMARY（主用）”：表示该服务器是主用服务器。“SECONDARY（备用）”：表示该服务器是备用服务器。  默认值：无  配置原则：无                                                                                                                                                                                                                              |

## 使用实例

根据网络规划，绑定名称为“diameteraaa1”的Diameter AAA到名称为“diametergroup”的Diameter AAA组下，指定服务器类型为3GPP，指定主备标记为PRIMARY：

```
ADD DIAMAAABNDGRP: GROUPNAME="diametergroup", SERVERTYPE=PARA_3GPP, HOSTNAME="diameteraaa1", PRIORSEC=PRIMARY;
```
