# 删除SDAP本地实体(RMV SDAPLE)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

本命令用于删除Sdup接口的业务IP地址。

#### 注意事项

- 该命令执行后立即生效。
- 若整系统的最后一条记录删除，将会导致“WSFD-201201 MME链式备份”特性不可用。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                    |
|:--------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DELTYPE | 删除方式   | 可选必选说明：可选参数 参数含义：本参数用于删除指定Sdup接口的删除方式 数据来源：全网规划 取值范围：“BYINDEX(BY INDEX)”“BYIP(BY IP)” 默认值：BYINDEX(BY INDEX)                                                                                                                                                                                                                             |
| INDEX   | 记录索引   | 可选必选说明：条件必选参数 参数含义：本参数用于删除指定Sdup接口的业务IP地址类型。 前提条件：该参数在“删除方式”参数配置为“BYINDEX(BY INDEX)”后生效 数据来源：全网规划 取值范围：0~65535 默认值：无                                                                                                                                                                                                                    |
| IPTYPE  | IP地址类型 | 可选必选说明：条件必选参数 参数含义：本参数用于删除指定Sdup接口的业务IP地址类型。 前提条件：该参数在“删除方式”参数配置为“BYIP(BY IP)”后生效 数据来源：全网规划 取值范围：“ITPTADDR_TYPE_IPV4(IPV4)”“TPTADDR_TYPE_IPV6(IPV6)” 默认值：无                                                                                                                                                                              |
| LEIPV4  | IPv4地址 | 可选必选说明：条件必选参数 参数含义：本参数用于删除指定Sdup接口的业务IP地址。 前提条件：该参数在“IP地址类型”参数配置为“TPTADDR_TYPE_IPV4(IPV4)”后生效。 数据来源：全网规划 取值范围：0.0.0.0~255.255.255.255 默认值：无 配置原则：业务地址不能配置为0.0.0.0、255.255.255.255和环回地址(127.x.y.z)。业务地址必须是A、B或者C类地址。该参数的掩码缺省为255.255.255.255，不可更改。                                                                                       |
| LEIPV6  | IPv6地址 | 可选必选说明：条件必选参数 参数含义：本参数用于删除指定Sdup接口的业务IP地址。 前提条件：该参数在“IP地址类型”参数配置为“TPTADDR_TYPE_IPV6(IPV6)”后生效。 数据来源：全网规划 取值范围：::~FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 配置原则：IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址(::1/128)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。该参数的掩码缺省为FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF，不可更改。 |

#### 使用实例

该命令用于删除Sdup接口的业务IP地址，执行如下命令：

RMV SDAPLE: DELTYPE=BYIP, IPTYPE=TPTADDR\_TYPE\_IPV4, LEIPV4="192.168.15.10";
