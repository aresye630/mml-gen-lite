#### 命令功能

**适用NF：NCG**

该命令用于查询长时间未取话单监控任务。

#### 注意事项

当前版本不支持Bi口SingleIP功能，请勿开启。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

|:------------|:------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MONITORID   | 话单监控标识            | 可选必选说明：可选参数 参数含义：监控任务标识，全局唯一。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：无                                                                                             |

| CDRDISTRID  | 分发任务标识            | 可选必选说明：条件可选参数 前提条件：该参数在“ISSINGLEBI”配置为“YES” 或 “NO”时为条件可选参数。暂不支持“ISSINGLEBI”配置为“YES”。 参数含义：该参数用于表示当前监控任务所监控的PULL分发任务。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：无      |
| ISCUSTOMDIR | 是否自定义目录           | 可选必选说明：条件可选参数 前提条件：该参数在“ISSINGLEBI”配置为“NO”时为条件可选参数。 参数含义：该参数用于表示监控的PULL任务开放给计费中心的目录是否是自定义目录。 数据来源：本端规划 取值范围：枚举类型。 NO：否。YES：是。 默认值：无 配置原则：无                               |
| MONSUBDIR   | 监控子目录             | 可选必选说明：条件可选参数 前提条件：该参数在“ISCUSTOMDIR”配置为“YES”时为条件可选参数。 参数含义：该参数用来表示PULL任务“开放给BS的目录”下面的子目录。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～128。 默认值：无 配置原则：无                                |
| AGID        | 接入网元分组标识          | 可选必选说明：条件可选参数 前提条件：该参数在“ISCUSTOMDIR”配置为“NO”时为条件可选参数。 参数含义：用于区分不同域的接入网元。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：无                                                   |
| MNAME       | 模块名               | 可选必选说明：条件可选参数 前提条件：该参数在“ISCUSTOMDIR”配置为“NO”时为条件可选参数。 参数含义：用于标识一个业务模块对象，全局唯一。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～15。 默认值：无 配置原则：无                                              |
| CHLNAME     | 通道名称              | 可选必选说明：条件可选参数 前提条件：该参数在“ISCUSTOMDIR”配置为“NO”时为条件可选参数。 参数含义：该参数表示长时间未取话单监控的通道名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：无                                             |
| TIMEOUT     | 长时间未取话单告警的监控时长（分） | 可选必选说明：条件可选参数 前提条件：该参数在“ISSINGLEBI”配置为“YES” 或 “NO”时为条件可选参数。暂不支持“ISSINGLEBI”配置为“YES”。 参数含义：该参数表示NCG检测计费中心未取话单的时间阈值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～259200，单位是分钟。 默认值：无 配置原则：无 |
