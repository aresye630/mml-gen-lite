# 查询标准QoS ID配置（LST STDQOSID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C、GGSN、SMF**

该命令用于查询标准QoS ID配置。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                               |
|:----------|:---------|:---------------------------------------------------------------------------------------------------|
| QOSIDTYPE | QoS ID类型 | 可选必选说明：可选参数  参数含义：该参数用于指定QoS ID类型。  数据来源：本端规划 取值范围： “QCI（QCI）”：QCI“FIVEQI（5QI）”：5QI  默认值：无  配置原则：无 |

## 使用实例

查询当前“标准QoS ID”配置：

```
%%LST STDQOSID:;%%
RETCODE = 0  操作成功
```
