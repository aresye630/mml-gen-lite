#### 命令功能

该命令用于查询IPv4静态路由的配置情况。

静态路由是一种需要管理员手工配置的特殊路由。

当网络结构比较简单时，只需配置静态路由就可以使网络正常工作。当设备不能使用动态路由协议或者不能建立到达目的网络时，也可以使用静态路由。合理的静态路由可以改进网络性能，并为重要业务保证带宽。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                                     |
|:-----------|:--------|:---------------------------------------------------------------------------------------------------------|
| AFTYPE     | 地址族     | 可选必选说明：可选参数 参数含义：该参数用来指定VPN实例的地址族信息。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。 默认值：ipv4unicast            |
| VRFNAME    | VPN实例名称 | 可选必选说明：可选参数 参数含义：该参数用来指定VPN实例的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：公网需要输入_public_，默认查询所有VPN。 |
| PREFIX     | 路由前缀    | 可选必选说明：可选参数 参数含义：该参数用来指定前缀信息。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无                                             |
| MASKLENGTH | 路由掩码长度  | 可选必选说明：可选参数 参数含义：该参数用来指定掩码长度。 数据来源：本端规划 取值范围：整数类型，取值范围为0～32。 默认值：无 配置原则：不可单独以掩码查询路由。掩码需要和前缀一起配置。         |

#### 使用实例

查询IPv4静态路由的配置情况：

```
LST SRROUTE: VRFNAME="_public_";
```
