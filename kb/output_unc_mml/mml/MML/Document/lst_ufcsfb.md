#### 命令功能

**适用网元：MME**

该命令用于查询预留功能策略。

#### 注意事项

- 此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                      |
|:---------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：可选参数 参数含义：该参数用于指定所包含的用户范围。 数据来源：全网规划 取值范围：“ALL_USER(所有用户)”“HOME_USER(本网用户)”“FOREIGN_USER(外网用户)”“IMSI_PREFIX(指定IMSI前缀)” 默认值：无  说明： 如果不输入该参数，系统会查询所有配置记录。                                                                            |
| NOID     | 运营商标识  | 可选必选说明：可选参数 参数含义：该参数用于指定运营商标识。 前提条件：该参数在“SUBRANGE（用户范围）”配置为“FOREIGN_USER（外网用户）”或“HOME_USER（本网用户）”后生效。 数据来源：全网规划 取值范围：0～64，128～254 默认值：无  说明： 如果不输入该参数，系统会查询所有的“SUBRANGE（用户范围）”配置为“FOREIGN_USER（外网用户）”或“HOME_USER（本网用户）”记录。NOID未配置时，显示为255 |
| IMSIPRE  | IMSI前缀 | 可选必选说明：可选参数 参数含义：该参数用于系统对用户的IMSI进行匹配，从而区分不同的用户群。 前提条件：此参数在“SUBRANGE（用户范围）”设置为“IMSI_PREFIX（指定IMSI前缀）”时有效。 数据来源：全网规划 取值范围：1～15位十进制数字字符串 默认值：无  说明： 如果不输入该参数，系统会查询所有“SUBRANGE（用户范围）”配置为“IMSI_PREFIX（指定IMSI前缀）”的配置记录。                         |

#### 使用实例

查询本网用户的预留功能策略：

LST UFCSFB: SUBRANGE=HOME\_USER;

```
%%LST UFCSFB: SUBRANGE=HOME_USER;%%
RETCODE = 0  操作成功。

操作结果如下：
--------------
    用户范围  =  本网用户
  运营商标识  =  0
    IMSI前缀  =  NULL
    预留功能  =  是
基于IMEI控制  =  白名单
IMEI群组标识  =  1
(结果个数 = 1)
---    END
```
