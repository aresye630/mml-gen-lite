# 增加Diameter链路集配置(ADD DMLKS)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于增加一条Diameter链路集。Diameter链路集是MME与HSS之间的链路集，用来唯一关联一个本端与一个对端。

#### 注意事项

- 该命令执行后立即生效。
- 该表最大记录数为640。
- 一个本端实体与一个对端实体之间只能配置一条链路集。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称          | 参数说明                                                                                                                                                                                                                                                                                                                                                                        |
|:----------|:--------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LINKSIDX  | Diameter链路集索引 | 可选必选说明：必选参数 参数含义：该参数用于在系统范围内部唯一标识一条Diameter链路集。 数据来源：本端规划 取值范围：0～639 默认值：无 配置原则：此链路索引在系统范围内唯一。建议从0开始顺序取值。                                                                                                                                                                                                                                                                   |
| LOCALIDX  | 本地实体索引        | 可选必选说明：必选参数 参数含义：该参数用于指定Diameter链路集对应的本地实体的索引。 前提条件：在“MML命令行-UNC”窗口上执行命令ADD DMLE设置此参数。 数据来源：本端规划 取值范围：0～31 默认值：无                                                                                                                                                                                                                                                            |
| PEERIDX   | 对端实体索引        | 可选必选说明：必选参数 参数含义：该参数用于指定Diameter链路集对应的对端实体的索引。 前提条件：在“MML命令行-UNC”窗口上执行命令ADD DMPE设置此参数。 数据来源：本端规划 取值范围：0～639 默认值：无                                                                                                                                                                                                                                                           |
| LSSELMODE | 选路模式          | 可选必选说明：可选参数 参数含义：该参数用于指定Diameter链路集采用何种方式选择Diameter链路进行业务。 数据来源：整网规划 取值范围：“SELMODE_ROUND_ROBIN(轮选)”：表示存在多条链路时，采用顺序选择的方式选取各条链路。“SELMODE_LOAD_BALAN(负荷分担模式)”：表示在链路集中所有处于激活状态的链路以负荷分担的方式传输业务。“SELMODE_MASTER_SLAVE(主从)”：表示1＋N备份模式。在这种模式中，业务仅在链路集中的一条链路上传输，其余链路均处于备份状态。“SELMODE_ACTIVE(激活)”：表示使用上次使用的链路。 默认值：“SELMODE_LOAD_BALAN(负荷分担模式)”配置原则：建议值为“SELMODE_LOAD_BALAN(负荷分担模式)”。 |
| LINKSNAM  | 链路集名称         | 可选必选说明：可选参数 参数含义：该参数用于指定链路集名称，标识Diameter链路集。 数据来源：本端规划 取值范围：0～32位字符串 默认值：noname 配置原则：建议取有实际意义的名称，以方便识别。例如“To-HSS0”。                                                                                                                                                                                                                                                         |

#### 使用实例

增加一条Diameter链路集索引为0，本地实体索引为0，对端索引为0，选路模式为轮选模式，链路集名称为To-HSS0的DIAMETER链路集：

ADD DMLKS: LINKSIDX=0, LOCALIDX=0, PEERIDX=0, LSSELMODE=SELMODE\_ROUND\_ROBIN, LINKSNAM="To-HSS0";
