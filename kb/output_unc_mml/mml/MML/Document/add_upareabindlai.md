# 增加UPF服务区名称绑定的LAI范围（ADD UPAREABINDLAI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：GGSN**

该命令用于增加UPF服务区名称绑定的LAI范围。

## 注意事项

- 该命令执行后立即生效。

- 此配置中LAI的结束值>=开始值，而且开始值和结束值长度需要相等，通过ADD UPAREABINDLAI和ADD SUFFIXLAIAREA配置的各AREANAME绑定的LAI范围不允许出现交集。

- 最多可输入16384条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称                 | 参数说明                                                                                                                                                                                                         |
|:---------|:---------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AREANAME | UPF服务区名称             | 可选必选说明：必选参数  参数含义：该参数用于配置UPF服务区的名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~255。不支持空格，不区分大小写。  默认值：无  配置原则：  该参数取值应与命令LST UPAREA查询结果中的AREANAME保持一致；且该AREANAME在命令LST UPAREA查询结果中对应的AREATYPE取值应为LAI。                   |
| BEGINLAI | UPF服务区名称绑定的LAI范围的起始值 | 可选必选说明：必选参数  参数含义：该参数用于标识UPF服务区名称绑定的LAI范围的起始值。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是9~10。前5位数或者6位数为移动国家号(MCC)+移动网号(MNC)，为10进制数；后4位数为位置区号码(LAC)，为16进制数。不区分大小写。  默认值：无  配置原则：  LAI范围的结束值需要不小于LAI范围的开始值，且结束值和开始值长度需相等。 |
| ENDLAI   | UPF服务区名称绑定的LAI范围的结束值 | 可选必选说明：必选参数  参数含义：该参数用于标识UPF服务区名称绑定的LAI范围的结束值。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是9~10。前5位数或者6位数为移动国家号(MCC)+移动网号(MNC)，为10进制数；后4位数为位置区号码(LAC)，为16进制数。不区分大小写。  默认值：无  配置原则：  LAI范围的结束值需要不小于LAI范围的开始值，且结束值和开始值长度需相等。 |

## 使用实例

增加UPF服务区名称为“UPAREA1”的LAI绑定范围460010001~460011111。

```
ADD UPAREABINDLAI: AREANAME="UPAREA1", BEGINLAI="460010001", ENDLAI="460011111";
```
