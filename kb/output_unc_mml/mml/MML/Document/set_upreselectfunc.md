# 设置UP重选功能（SET UPRESELECTFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、GGSN、PGW-C**

该命令用于修改UP重选相关的功能控制，如触发UP重选的场景。

## 注意事项

- 该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                |
|:-------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UPRESELSCENE | UP重选场景 | 可选必选说明：可选参数  参数含义：该参数用来配置触发UP重选的场景。  数据来源：全网规划 取值范围： SMFALLOCIPFAULT（SMF分配地址失败）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST UPRESELECTFUNC查询当前参数配置值。  配置原则：  当SMF、PGW-C或GGSN-C本地分配地址失败，期望进行UP重选时，则勾选“SMFALLOCIPFAULT”。 |

## 使用实例

设置触发UP重选的场景为C面分地址失败：

```
SET UPRESELECTFUNC:UPRESELSCENE=SMFALLOCIPFAULT-1;
```
