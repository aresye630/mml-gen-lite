# 查询HLR BYPASS故障状态码(LST HLRBPFAULTCODE)

#### 命令功能

**适用网元：SGSN**

该命令用于查询配置的HLR BYPASS故障状态码信息。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                   |
|:-------|:-------|:-------------------------------------------------------|
| RANGE  | 生效范围   | 可选必选说明：可选参数 参数含义：该参数用于指定特定故障码的生效范围。 取值范围： ALL（整系统）：整系统 |

#### 使用实例

查询已经配置的所有HLR BYPASS故障状态码数据。

```
%%LST HLRBPFAULTCODE:;%% 
RETCODE = 0  操作成功 
The result is as follows 
------------------------ 
  生效范围  =  整系统
    故障码  =  3002
(结果个数 = 1)  
---    END
```
