#### 命令功能

**适用网元：SGSN、MME**

本命令用于设置当系统中大量链路频繁闪断时是否上报告警提示，以及大量链路频繁闪断的告警上报条件。

当前仅支持S1链路的频繁闪断监控，其原理说明如下：当系统中的S1链路发生瞬间闪断，闪断时间小于防闪断定时器时长时，系统不会有告警提示。但当某条链路频繁闪断时，会上报此链路频繁闪断的异常事件，并记录文件。当短时间内系统中有大量链路发生频繁闪断时，对系统业务会有明显影响，需要告警提示。

**说明** 

- 防闪断定时器时长默认40s，可通过**SET S1APPARA**命令的“防闪断定时器(s)”参数进行配置。
- 频繁闪断指某条链路在T时间内闪断5次及以上，T的取值与“防闪断定时器(s)”取值有关：当“防闪断定时器(s)”小于等于1分钟时，T取5分钟；当“防闪断定时器(s)”超过1分钟时，T取5倍“防闪断定时器(s)”时长。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                      |
|:------------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LNKTYPE     | 链路类型     | 可选必选说明：必选参数 参数含义：本参数用于指定链路类型。 数据来源：本端规划 取值范围：“S1AP(S1AP 链路)” 系统初始设置值：“S1AP(S1AP 链路)” 配置原则：当前仅支持S1AP链路。                                                                                                                                                                                    |
| FLASHSWITCH | 瞬间闪断监控开关 | 可选必选说明：必选参数 参数含义：本参数用于决定是否开启瞬间闪断监控功能。 数据来源：本端规划 取值范围：“OFF(关闭)”“ON(开启)” 系统初始设置值：“ON(开启)”  说明： 当存在ALM-14025 批量链路频繁闪断告警时，若将该参数由“ON(开启)”设置为“OFF(关闭)”，告警恢复，且不再保存故障链路信息。                                                                                                                        |
| PERIOD      | 统计时长（s）  | 可选必选说明：可选参数 参数含义：本参数用于指定ALM-14025 批量链路频繁闪断告警的统计周期。 前提条件：该参数在“瞬间闪断监控开关”参数配置为“ON(开)”后生效。 数据来源：本端规划 取值范围：60～300 系统初始设置值：60 配置原则：建议使用初始设置值。  说明： 该参数和“统计门限”配合使用，组合后的含义是每隔“统计时长(s)”，系统对当前所有发生频繁闪断的链路数量进行统计，当其大于等于“统计门限”时，则上报ALM-14025 批量链路频繁闪断告警。该参数配置后需要等待下一周期才会生效，等待时间与该参数之前的配置有关。           |
| THRESHOLD   | 统计门限     | 可选必选说明：可选参数 参数含义：本参数用于指定ALM-14025 批量链路频繁闪断告警的统计门限。 前提条件：该参数在“瞬间闪断监控开关”参数配置为“ON(开)”后生效。 数据来源：本端规划 取值范围：1～1000 系统初始设置值：50 配置原则：建议使用初始设置值。  说明： 该参数和“统计时长(s)”配合使用，组合后的含义是每隔“统计时长(s)”，系统对当前所有发生频繁闪断的链路数量进行统计，当其大于等于“统计门限”时，则上报ALM-14025 批量链路频繁闪断告警。该参数配置后需要等待下一周期才会生效，等待时间与之前的“统计时长(s)”的配置有关。 |

#### 使用实例

设置S1AP链路频繁闪断监控信息，“链路类型”为“S1AP(S1AP 链路)”，“瞬间闪断监控开关”为“ON(开启)”，“统计时长(s)”为“60”，“统计门限”为“50”。

`SET LNKMONITOR: LNKTYPE=S1AP, FLASHSWITCH=ON, PERIOD=60, THRESHOLD=50;`
