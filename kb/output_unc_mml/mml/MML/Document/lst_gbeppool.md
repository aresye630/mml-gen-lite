#### 命令功能

**适用网元：SGSN**

此命令用于显示地址池中信息。

#### 注意事项

- 此命令执行后立即生效。
- 若不输入参数，则查询地址池中所有信息。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPTYPE | IP类型   | 可选必选说明：可选参数 参数含义：该参数用于指定待查询的IP地址类型。 取值范围：“IPV4(IPv4)”“IPV6(IPv6)” 默认值：无                                                                                                                                                                             |
| IPV4   | IPv4地址 | 可选必选说明：条件可选参数 参数含义：该参数用于指定地址池中待查询的IPv4地址。 前提条件：该参数在“ IP类型 ”设置为“IPV4(IPv4)”时生效。 取值范围：0.0.0.1～255.255.255.254 默认值：无 配置原则：有效的IPV4地址不能为环回地址(127.x.y.z)。有效的IPV4地址必须是A、B或者C类地址。                                                                           |
| IPV6   | IPv6地址 | 可选必选说明：条件可选参数 参数含义：该参数用于指定地址池中待查询的IPv6地址。 前提条件：该参数在“ IP类型 ”设置为“IPV6(IPv6)”时生效。 取值范围：::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 配置原则：IPV6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址(::1)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。 |

#### 使用实例

1. 查询地址池中的所有信息：

   LST GBEPPOOL:;

   ```
   %%LST GBEPPOOL:;%%
   RETCODE = 0  操作成功。

   操作结果如下
   --------------
    本端实体标识  IP类型  IP地址         描述信息    vpn名称    组号                         

     0            IPv4    192.168.4.102  GBEPPool1   _abc_    0                        
     1            IPv4    192.168.4.103  GBEPPool2   _abc_    0                         
   (结果个数 = 2)

   ---    END
   ```
2. 查询“IP类型”为“IPV4(IPv4)”且“IPv4地址”值为“192.168.4.102”的记录：

   LST GBEPPOOL: IPTYPE=IPV4, IPV4="192.168.4.102";

   ```
   %%LST GBEPPOOL: IPTYPE=IPV4, IPV4="192.168.4.102";%%
   RETCODE = 0  操作成功。

   操作结果如下
   --------------
   本端实体标识  =  0
         IP类型  =  IPv4
         IP地址  =  192.168.4.102
       描述信息  =  GBEPPool1
       VPN名称   =  _abc_
          组号 = 0
   (结果个数 = 1)

   ---    END
   ```
