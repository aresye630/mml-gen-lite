# 增加融合计费Proxy基于RG处理动作（ADD CCPRGACT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NCG**

该命令用于增加融合计费Proxy基于RG的处理动作。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入1010条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                        |
|:-------------|:--------|:----------------------------------------------------------------------------------------------------------------------------|
| RGTYPE       | RG类型    | 可选必选说明：必选参数  参数含义：该参数用于指定RG的类型。  数据来源：本端规划 取值范围： DEFAULT（针对未指定的费率组设置处理动作）VALUE（针对费率组设置处理动作）  默认值：无  配置原则：无                  |
| RATINGGROUP  | 费率组标识   | 可选必选说明：该参数在"RGTYPE"配置为"VALUE"时为条件必选参数。  参数含义：该参数用于指定费率组标识。  数据来源：本端规划  取值范围：整数类型，取值范围是0~9223372036854775807。  默认值：无  配置原则：无 |
| FWDOCSENABLE | 是否转发OCS | 可选必选说明：必选参数  参数含义：该参数用于设置是否转发OCS。  数据来源：本端规划  取值范围： TRUE(TRUE)FALSE(FALSE)  默认值：无  配置原则：无                                   |

## 使用实例

增加费率组标识为2000000009的融合计费Proxy基于RG处理动作，设置是否转发OCS为TRUE：

```
ADD CCPRGACT: RGTYPE=VALUE, RATINGGROUP=2000000009, FWDOCSENABLE=TRUE;
```
