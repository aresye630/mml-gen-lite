# 创建OSPF IP FRR配置（ADD OSPFFRR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来创建OSPF IP FRR（快速重路由）配置。

#### 注意事项

该命令最大记录数为8000。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                  |
|:------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROCID      | OSPF进程号   | 可选必选说明：必选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 配置原则：OSPF进程必须已经存在。请使用LST OSPF命令查看可用的OSPF进程。                                                                    |
| ISLFAENABLE | LFA是否使能   | 可选必选说明：可选参数 参数含义：LFA是否使能。 数据来源：本端规划 取值范围：枚举类型。 FALSE：不使能。TRUE：使能。 默认值：FALSE 配置原则：Loop Free Alternate（LFA）是实现IP FRR的一种方式，使能此参数后，OSPF IP FRR功能才会生效，生成无环备份路由。                            |
| NODEPROTECT | 节点保护优先级   | 可选必选说明：条件可选参数 前提条件：该参数在“ISLFAENABLE”配置为“TRUE”时为可选参数。 参数含义：该参数表示备份路径节点保护优先级。 数据来源：本端规划 取值范围：整数类型，取值范围为1～255。 默认值：40 配置原则： LDP联动最大开销路径优先级默认值为10。LDP联动最大开销路径和节点保护优先级及最小开销路径优先级，三者互不冲突。   |
| LOWESTCOST  | 最小开销路径优先级 | 可选必选说明：条件可选参数 前提条件：该参数在“ISLFAENABLE”配置为“TRUE”时为可选参数。 参数含义：该参数表示备份路径最小开销路径优先级。 数据来源：本端规划 取值范围：整数类型，取值范围为1～255。 默认值：20 配置原则： LDP联动最大开销路径优先级默认值为10。LDP联动最大开销路径和节点保护优先级及最小开销路径优先级，三者互不冲突。 |
| POLICYTYPE  | 路由策略类型    | 可选必选说明：可选参数 参数含义：该参数用来指定路由策略的类型。 数据来源：本端规划 取值范围：枚举类型。 none：无策略。route_policy：路由策略。 默认值：none                                                                                            |
| POLICYNAME  | 路由策略名称    | 可选必选说明：条件必选参数 前提条件：该参数在“POLICYTYPE”配置为“route_policy”时为必选参数。 参数含义：该参数用于指定一个路由策略的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无                                                           |

#### 使用实例

创建OSPF进程号为1的IP FRR（快速重路由）配置，并使能LFA：

```
ADD OSPFFRR: PROCID=1, ISLFAENABLE=TRUE;
```
