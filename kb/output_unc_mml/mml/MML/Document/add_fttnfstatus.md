# 增加AMF容灾网元状态信息（ADD FTTNFSTATUS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

调测结束后需要删除相关配置信息，否则网元级KPI异常检测与容灾功能不能正常生效。

**适用NF：AMF**

该命令用于添加AMF POOL内其它AMF网元的状态信息。

仅在调测场景下，通过本命令配置周边网元状态信息，AMF会优先使用本配置的信息判断周边网元状态能否满足容灾要求，从而可以实现网元级KPI异常检测与容灾功能。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入1024条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                                                        |
|:-------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCEID | AMF实例标识 | 可选必选说明：必选参数  参数含义：该参数用于在UNC系统中唯一指定某个AMF实例。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~36。可输入的字符有字母A～Z或a～z、数字0～9、中划线"-"和下划线"_"，例如，AMF_Instance_0，不区分大小写。  默认值：无  配置原则：无 |
| NFSTATUS     | NF状态    | 可选必选说明：可选参数  参数含义：该参数用于配置AMF网元状态。  数据来源：本端规划 取值范围： “INIT（初始态）”：初始态“NORMAL（正常态）”：正常态“FAULT（故障态）”：故障态“UNSTEADY（不稳态）”：不稳态“UNKNOWN（未知态）”：未知态  默认值：无  配置原则：无     |

## 使用实例

增加NF Instance ID为AMF\_INSTANCE\_0的网元状态信息，执行如下命令：

```
ADD FTTNFSTATUS: NFINSTANCEID="AMF_INSTANCE_0";
```
