# 增加控制缺省NI下发的APN(ADD DFTNIAPN)

#### 命令功能

**适用网元：MME**

该命令用于增加控制缺省NI下发的APN关键字。

应用场景：运营商希望配置的缺省NI不对所有UE下发，而是通过用户签约特定APN来决策是否向UE下发。用户签约中该特定APN使用的Context ID不能是用户签约APN中的最小值。

#### 注意事项

- 此命令执行后在下一次移动性流程触发EMM information消息时生效。
- 此命令最大记录数为10。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                           |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APNKEYWD | APN关键字 | 可选必选说明：必选参数。 参数含义：该参数用于设置下发缺省NI的特定APN关键字。 当用户签约的APN前缀匹配该参数配置的关键字时，则认为该用户可以下发缺省NI。 数据来源：全网规划 取值范围：字符串类型，输入长度范围是1~62。可输入的字符有字母、十进制数字、“-”和“.”，并且开头和结尾只能是数字或者字母。不能出现连续两个“.”。字母大小写不敏感。 默认值：无 配置原则：无 |

#### 使用实例

增加一条APN关键字为"`NeedDefaultUElogo`"的记录：

```
ADD DFTNIAPN: APNKEYWD="NeedDefaultUElogo";
```
