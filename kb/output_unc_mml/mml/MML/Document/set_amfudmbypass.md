# 设置AMF的UDM故障BYPASS功能（SET AMFUDMBYPASS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于设置AMF的UDM全故障Bypass功能。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| SWITCH   | RECOVERYACT             |   FAULTDETECTRATE |   SCANINTERVAL | RPTFAILCHR   | DEPLOYMENTMODE   | AUTOEXITSW   |
|:---------|:------------------------|------------------:|---------------:|:-------------|:-----------------|:-------------|
| OFF      | SUPPLEMENT_UDM_INTERACT |                 3 |            600 | ON           | CO_DEPLOYMENT    | ON           |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称             | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|:----------------|:-----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SWITCH          | UDM全故障Bypass开关   | 可选必选说明：可选参数  参数含义：该参数用于控制开启和关闭UDM全故障Bypass特性。  数据来源：全网规划 取值范围： “OFF（关闭）”：关闭“ON（打开）”：打开  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST AMFUDMBYPASS查询当前参数配置值。  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| RECOVERYACT     | 退出Bypass状态恢复动作   | 可选必选说明：可选参数  参数含义：该参数用于设置UDM全故障Bypass状态恢复动作。  数据来源：全网规划 取值范围： “DEREG（优雅去注册）”：AMF向UDM发送Nudm_UECM_RegistrationAMF3GppAccess Request消息，当UDM返回响应消息状态码符合退出Bypass条件时，AMF根据用户当前状态退出UDM Bypass，具体恢复动作为：若用户处于连接态，AMF待用户进入空闲态后发起显式去注册流程，并标记用户退出UDM Bypass状态；若用户处于空闲态，AMF寻呼用户成功后发起显式去注册流程，并标记用户退出UDM Bypass状态；若用户处于去注册态，AMF标记用户退出UDM Bypass状态。“SUPPLEMENT_UDM_INTERACT（补充缺失的UDM流程）”：AMF补齐和UDM交互的注册、签约数据获取和订阅三次流程，若成功则标记用户退出UDM Bypass状态，否则继续标记用户处于UDM Bypass状态。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST AMFUDMBYPASS查询当前参数配置值。  配置原则：无                                                                                                                                                                                           |
| FAULTDETECTRATE | 故障探测速率(个/秒)      | 可选必选说明：可选参数  参数含义：该参数用于指定故障探测速率，即每个DS每秒扫描多少个用户，扫描到后对符合条件的用户进行探测。  数据来源：全网规划  取值范围：整数类型，取值范围是1~20，单位是个每秒。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST AMFUDMBYPASS查询当前参数配置值。  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| SCANINTERVAL    | 扫描时间间隔(秒)        | 可选必选说明：可选参数  参数含义：该参数用于表示UDM Bypass后，允许用户连续两次向UDM发试探消息的最小时间间隔。  数据来源：全网规划  取值范围：整数类型，取值范围是1~600，单位是秒。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST AMFUDMBYPASS查询当前参数配置值。  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| RPTFAILCHR      | 上报异常CHR开关        | 可选必选说明：可选参数  参数含义：该参数用于设置当用户接入5G成功且进入UDM Bypass的流程（涉及首次注册、切换、服务请求等流程）时，是否上报异常CHR单据。 参数取值： ON：生成异常CHR单据。 OFF：生成正常CHR单据。是否上报单据取决于ADD NGACCCHRPRCTMPL配置。  数据来源：本端规划 取值范围： “OFF（关闭）”：关闭“ON（打开）”：打开  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST AMFUDMBYPASS查询当前参数配置值。  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| DEPLOYMENTMODE  | 部署模式             | 可选必选说明：可选参数  参数含义：该参数用于表示AUSF和UDM的部署模式。 该部署模式与现网UDM和AUSF的实际部署模式无关，仅用于判断当主备AUSF均故障后是否仍需要与UDM进行交互。  数据来源：全网规划 取值范围： “CO_DEPLOYMENT（合设）”：若主备AUSF均故障，AMF不进行UDM服务发现和向UDM发送注册、获取签约数据和订阅签约变更的三次交互流程，用户直接进入UDM Bypass状态。“SEPARATE_DEPLOYMENT（分设）”：若主备AUSF均故障，AMF仍进行UDM服务发现和向UDM发送注册、获取签约数据和订阅签约变更的三次交互流程，若主备UDM均故障，用户才进入UDM Bypass状态。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST AMFUDMBYPASS查询当前参数配置值。  配置原则：  当AMF未探测到AUSF和UDM故障时：  1）若设置为分设模式，主备AUSF均故障后，AMF仍尝试与UDM交互，主备UDM均故障后标记用户进入UDM Bypass状态，此过程可能导致UE因等待时间过长而断开网络接连；  2）若设置为合设模式，主备AUSF均故障后，AMF直接标记用户进入UDM Bypass状态，从而提升注册成功率；但仅主备AUSF故障而UDM正常场景下，用户签约业务无法及时生效，部分业务（例如被叫）受到影响。  当AMF已探测到AUSF和UDM故障时：  两种模式下UE均能迅速注册成功，但合设模式下，仅主备AUSF故障而UDM正常场景下，用户签约业务仍无法及时生效，部分业务受到影响。 |
| AUTOEXITSW      | UDM Bypass自动退出开关 | 可选必选说明：可选参数  参数含义：该参数用于控制是否开启用户自动退出UDM Bypass状态开关。  数据来源：全网规划 取值范围： “OFF（关闭）”：关闭“ON（打开）”：打开  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST AMFUDMBYPASS查询当前参数配置值。  配置原则：  若本参数设置为“OFF”，在UDM恢复后，用户无法及时退出UDM Bypass状态，可能导致用户业务持续受到影响。建议本参数设置“ON”。                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| CUNFSTATUSCODE  | 自定义网元状态码         | 可选必选说明：可选参数  参数含义：该参数用于设置AMF标识用户进入UDM Bypass状态时，对端AUSF/UDM返回的自定义网元状态码。 当本参数未设置时，当对端UDM/AUSF返回状态码大于等于500，AMF标识用户进入UDM Bypass状态。 当本参数已设置时，仅在对端UDM/AUSF返回状态码匹配本参数自定义状态码时，AMF标识用户进入UDM Bypass状态。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~128。每个状态码由3位十进制数字组成，并通过分割符“|”拼接。示例：“501|502|503”。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST AMFUDMBYPASS查询当前参数配置值。  配置原则：  输入单空格将删除该参数已有配置项。                                                                                                                                                                                                                                                                                                                                               |
| CUSCPSTATUSCODE | 自定义SCP状态码        | 可选必选说明：可选参数  参数含义：该参数用于设置Model D模式下AMF标识用户进入UDM Bypass状态时，对端SCP返回的自定义状态码。 当本参数未设置时，当对端SCP返回状态码大于等于500，AMF标识用户进入UDM Bypass状态。 当本参数已设置时，仅在对端SCP返回状态码匹配本参数自定义状态码时，AMF标识用户进入UDM Bypass状态。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~128。每个状态码由3位十进制数字组成，并通过分割符“|”拼接。示例：“501|502|503”。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST AMFUDMBYPASS查询当前参数配置值。  配置原则：  输入单空格将删除该参数已有配置项。                                                                                                                                                                                                                                                                                                                                                      |

## 使用实例

设置UDM全故障进入Bypass功能开启，退出Bypass恢复动作为去注册方式，故障探测速率为2个/秒，扫描时间间隔为10s，执行如下命令：

```
SET AMFUDMBYPASS:SWITCH=ON,RECOVERYACT=DEREG,FAULTDETECTRATE=2,SCANINTERVAL=10;
```
