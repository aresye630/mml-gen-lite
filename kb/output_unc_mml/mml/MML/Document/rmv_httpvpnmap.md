# 删除HTTP VPN映射关系（RMV HTTPVPNMAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除HTTP对端地址与本端VPN的映射关系。

## 注意事项

- 该命令执行后立即生效。

- 若删除的HTTP VPN映射关系已经被客户端HTTP实体引用，且该HTTP实体所在的HTTP实体组存在使用其他VPN的客户端HTTP实体，则不允许删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                       |
|:-------|:-------|:-------------------------------------------------------------------------------------------|
| INDEX  | 索引     | 可选必选说明：必选参数  参数含义：该参数用于指定HTTP VPN映射的索引信息。  数据来源：本端规划  取值范围：整数类型，取值范围是1~512。  默认值：无  配置原则：无 |

## 使用实例

若运营商要删除索引为1的HTTP VPN映射关系，可以用如下命令

```
RMV HTTPVPNMAP: INDEX=1;
```
