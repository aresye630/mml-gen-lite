# 查询IPv6 MPAC策略匹配统计（DSP MPACV6RULESTAT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示当前规则的匹配统计信息。

不指定RULENAME参数时，查询所有规则名字的统计信息；当指定RULENAME参数时，可以查询指定规则名字的统计信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                  |
|:-----------|:-------|:----------------------------------------------------------------------|
| POLICYNAME | 策略名称   | 可选必选说明：必选参数 参数含义：该参数用于指定策略名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 |
| RULENAME   | 规则名字   | 可选必选说明：可选参数 参数含义：该参数用于指定规则名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 |

#### 使用实例

显示当前规则的匹配统计信息：

```
DSP MPACV6RULESTAT:POLICYNAME="policyV6";
```

```
        RETCODE = 0  操作成功

        结果如下
        -------------------------
        策略名称  =  policyV6
        规则名字  =  name1
        匹配计数  =  0
        (结果个数 = 1)
        ---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释          |
|:--------|:---------------|
| 策略名称    | 用于指定策略名称。      |
| 规则名字    | 用于指定规则名称。      |
| 匹配计数    | 用于显示匹配规则的报文计数。 |
