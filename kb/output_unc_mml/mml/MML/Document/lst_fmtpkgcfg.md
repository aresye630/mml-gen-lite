# 查询格式引擎软参配置信息（LST FMTPKGCFG）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：NCG**

该命令用于查询格式引擎包中的软参配置信息。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                |
|:--------|:-------|:------------------------------------------------------------------------------------|
| PRFNAME | 格式引擎包名 | 可选必选说明：可选参数 参数含义：用于返回查询到的格式引擎配置包名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～255。 默认值：无 配置原则：无 |

#### 使用实例

查询指定的格式引擎软参配置情况：

```
LST FMTPKGCFG: PRFNAME="PS_R9_V940_M_RT.tar.gz";
```

```
RETCODE = 0  操作成功。

结果如下:
---------
格式引擎包名              格式引擎包软参名称    格式引擎软参类型 格式引擎软参值

PS_R9_V940_M_RT.tar.gz    MaxDuration           FEM_PARA_ENUM    0             
PS_R9_V940_M_RT.tar.gz    MaxVolume             FEM_PARA_UINT    0             
PS_R9_V940_M_RT.tar.gz    MergeCDRNum           FEM_PARA_UINT    0             
(结果个数 = 3)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释    |
|:--------|:---------|
| 格式引擎软参值 | 格式引擎软参值。 |

其余输出项请参见**ADD FMTPKGCFG**的参数说明。
