# 查询流控等级对应的流控参数（LST NRFFCPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NRF**

该命令用于查询流控等级对应的流控响应。

若要查询全部流控等级和对应的流控响应时，请不要输入任何参数。

若要查询特定流控等级或流控响应的相关信息时，请输入对应参数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                         |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FCLEVEL | 流控等级   | 可选必选说明：可选参数  参数含义：该参数用于表示CPU过载程度的分级。  数据来源：本端规划 取值范围： “LOW（轻度过载）”：轻度过载对应的CPU阈值范围为大于等于75%、小于80%。“MEDIUM（中度过载）”：中度过载对应的CPU阈值范围为大于等于80%、小于85%。“HIGH（重度过载）”：重度过载对应的CPU阈值范围为大于等于85%、小于100%。  默认值：无  配置原则：无                                        |
| FCRSP   | 流控响应   | 可选必选说明：可选参数  参数含义：该参数用于表示NRF对NF的服务发现请求如何响应。  数据来源：本端规划 取值范围： “TooManyRequest_429（请求过多）”：NRF收到NF的服务发现请求后直接回复响应，错误码为429。“ServiceUnavailable_503（服务不可用）”：NRF收到NF的服务发现请求后直接回复响应，错误码为503。“NoResponse（无响应）”：NRF收到NF的服务发现请求后直接将消息丢弃。  默认值：无  配置原则：无 |

## 使用实例

- 查询所有流控等级对应的流控响应类型：

  ```
  LST NRFFCPARA:;
  %%LST NRFFCPARA:;%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
  流控等级  流控响应  

  轻度过载  无响应        
  中度过载  无响应     
  重度过载  无响应             
  (结果个数 = 3)
  ```
- 查询流控等级为轻度过载对应的流控响应类型：

  ```
  LST NRFFCPARA: FCLEVEL=LOW;
  %%LST NRFFCPARA: FCLEVEL=LOW;%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
     流控等级  =  轻度过载
     流控响应  =  无响应
  (结果个数 = 1)
  ```

## 输出结果说明

|:--------|:--------------------------|
| 流控等级    | 该参数用于表示CPU过载程度的分级。        |
| 流控响应    | 该参数用于表示NRF对NF的服务发现请求如何响应。 |
