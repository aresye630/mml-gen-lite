# 删除AMF信息（RMV AMFINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

执行该命令将触发AMF到NRF的属性同步流程，导致本AMF无法被其它NF发现和选择，从而影响本AMF的功能可用性。

**适用NF：AMF**

该命令用于删除AMF实例信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称    | 参数说明                                                                                                                                    |
|:----------------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------|
| AMFINSTANCENAME | AMF实例名称 | 可选必选说明：必选参数  参数含义：该参数用于在UNC系统中唯一指定某个AMF实例。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~50。可输入的字符有字母、十进制数字、"_"和“-”，例如，AMF_Instance_0。  默认值：无  配置原则：无 |

## 使用实例

删除当前配置的某AMF，其实例名称为AMF\_Instance\_0：

```
RMV AMFINFO: AMFINSTANCENAME="AMF_Instance_0";
```
