#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询统一HTR（Hard to Reach）流控功能的相关参数。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询固定速率流控信息：LST UNIHTR:;

```
%%LST UNIHTR:;%%
RETCODE = 0  操作成功。

查询结果如下
--------------
    局向流控开关  =  开启
启控速率配置策略  =  系统缺省值
 流控恢复阈值(%)  =  85
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见**SET UNIHTR**的参数标识。
