# 查询VLR用户关键信息数据核查扫描参数（LST VLRKEYCHECK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMSF**

该命令用于查询VLR用户关键信息数据核查扫描速率和周期，以及数据有效时长。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

运营商希望查询VLR用户关键信息数据核查扫描速率和周期，以及数据有效时长，执行如下命令：

```
LST VLRKEYCHECK:;
%%LST VLRKEYCHECK:;%%
RETCODE = 0  操作成功

结果如下：
------------------------
       VLR用户关键信息核查功能开关        =  打开
       VLR用户关键信息核查速率(个每秒)    =  70
       VLR上用户关键信息核查周期(分钟)    =  60
       VLR用户关键信息有效时长开关        =  打开
       VLR上用户关键信息的有效时长(分钟) =  10080
(结果个数 = 1)
```

## 输出结果说明

| 输出项名称               | 输出项解释                   |
|:--------------------|:------------------------|
| VLR用户关键信息核查功能开关     | 该参数用于表示VLR用户关键信息核查功能开关。 |
| VLR用户关键信息核查速率(个每秒)  | 该参数用于表示VLR用户关键信息核查速率。   |
| VLR上用户关键信息核查周期(分钟)  | 该参数用于表示VLR上用户关键信息核查周期。  |
| VLR用户关键信息有效时长开关     | 该参数用于表示VLR用户关键信息有效时长开关。 |
| VLR上用户关键信息的有效时长(分钟) | 该参数用于表示VLR上用户关键信息的有效时长。 |
