# 增加Pre-R8 QoS控制动作配置（ADD PRER8QOSACTION）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：GGSN**

该命令用于配置QoS上下行保证带宽门限、最高带宽门限以及带宽超过门限值时对QoS用户的处理动作。

## 注意事项

- 该命令执行后只对新激活用户生效。

- 全局的QoS Profile不支持配置该功能。
- 带宽取值为4294967295时，表示无效值。

- 最多可输入4000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

配置“QOSPROFILENAME”为“test”的上下行保证带宽门限、最高带宽门限以及带宽超过门限值时对QoS用户的处理动作：

```
ADD PRER8QOSACTION: QOSPROFILENAME="test", TRAFFICCLASS=CONVERSATIONAL, GBRDL=121, GBRDLACTION=DEGRADE, GBRUL=44, GBRULACTION=DEGRADE, MBRDL=144, MBRDLACTION=REJECT, MBRUL=45, MBRULACTION=DEGRADE;
```
