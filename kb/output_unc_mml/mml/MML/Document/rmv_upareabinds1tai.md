# 删除UPF服务区名称绑定的4G TAI范围（RMV UPAREABINDS1TAI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C**

删除UPF服务区名称绑定的4G TAI范围。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称                  | 参数说明                                                                                                                                                                                        |
|:-----------|:----------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AREANAME   | UPF服务区名称              | 可选必选说明：必选参数  参数含义：该参数用于标识UPF服务区名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~255。不支持空格，不区分大小写。  默认值：无  配置原则：  该参数取值应与命令LST UPAREA查询结果中的AREANAME保持一致；且该AREANAME在命令LST UPAREA查询结果中对应的AREATYPE取值应为S1TAI。 |
| S1BEGINTAI | UPF服务区名称绑定4G TAI范围起始值 | 可选必选说明：必选参数  参数含义：该参数用于标识UPF服务区名称绑定4G TAI范围起始值。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是9~10。后4位为16进制数，其余为10进制数。不区分大小写。  默认值：无  配置原则：  TAI范围的结束值需要不小于TAI范围的开始值，且结束值和开始值长度需相等。                         |
| S1ENDTAI   | UPF服务区名称绑定4G TAI范围结束值 | 可选必选说明：必选参数  参数含义：该参数用于标识UPF服务区名称绑定4G TAI范围结束值。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是9~10。后4位为16进制数，其余为10进制数。不区分大小写。  默认值：无  配置原则：  TAI范围的结束值需要不小于TAI范围的开始值，且结束值和开始值长度需相等。                         |

## 使用实例

删除UPF服务区名称为“UPAREA1”的4G TAI绑定范围123010001~123011111：

```
RMV UPAREABINDS1TAI: AREANAME="UPAREA1", S1BEGINTAI="123010001", S1ENDTAI="123011111";
```
