# 查询SCCP新全局翻译码(LST SCCPNGT)

#### 命令功能

**适用网元：SGSN、MME、SMSF**

此命令用来查询SCCP新全局码表指定记录的信息。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                  |
|:-------|:-------|:------------------------------------------------------|
| NGTX   | 新GT码索引 | 可选必选说明：可选参数 参数含义：该参数用于指定新GT码对应的索引值。 取值范围：0~4095 默认值：无 |

#### 使用实例

查询SCCP新全局翻译码中的所有记录：

LST SCCPNGT:;

```
%%LST SCCPNGT:;%% 
RETCODE = 0  操作成功。

 2           ITU四类     0            NULL      数据编号计划       空闲            124       奇位数    FOR HLR2
(结果个数 = 2)

```
