# 设置NF私有信息格式（SET NRFNFINFOFMT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于设置服务发现、检索响应及通知请求中NF的私有信息字段格式。

## 注意事项

- 该命令执行后立即生效。

- 主备或双活组网的场景下，如果需要配置此命令，则两个NRF上均需执行此命令，且配置参数一致。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| NFTYPE   | NFINFOFMT   |
|:---------|:------------|
| BSF      | REGFMT      |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                                                       |
|:----------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFTYPE    | 网元类型     | 可选必选说明：必选参数  参数含义：该参数用于表示设置NF私有信息格式的目标网元类型。  数据来源：本端规划 取值范围： BSF（BSF）  默认值：无。  配置原则：  当前只支持设置BSF的私有信息格式。                                                                   |
| NFINFOFMT | NF私有信息格式 | 可选必选说明：可选参数  参数含义：该参数用于表示服务发现、检索响应及通知请求中NF的私有信息字段格式类型。  数据来源：本端规划 取值范围： ARRAY（ARRAY）REGFMT（REGFMT）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST NRFNFINFOFMT查询当前参数配置值。  配置原则：无 |

## 使用实例

设置BSF网元的私有信息格式为ARRAY。

```
SET NRFNFINFOFMT:NFTYPE=BSF,NFINFOFMT=ARRAY;
```
