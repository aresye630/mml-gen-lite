# 删除HTTP流控消息类型（RMV HTTPFCMSG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除HTTP流控消息类型。

## 注意事项

- 该命令执行后立即生效。

- 参数FCTYPE取值为TCPBPFC时，执行该命令会导致TCP CPU反压流控暂时停止。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

删除AMF网元所有流控方式下的全部流控消息。

```
RMV HTTPFCMSG: NFTYPE=NFTypeAMF;
```
