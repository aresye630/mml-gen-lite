# 查询话单通道一级目录类型映射表配置（LST NCGCHLMAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NCG**

该命令用于查询特定字段前缀与话单通道一级目录类型的映射关系。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识         | 参数名称              | 参数说明                                                                                                                     |
|:-------------|:------------------|:-------------------------------------------------------------------------------------------------------------------------|
| FIELDTYPE    | 决定话单通道一级目录类型的字段   | 可选必选说明：可选参数  参数含义：该参数用于指定决定话单通道类型的字段。  数据来源：本端规划 取值范围： GPSI（GPSI）  默认值：无  配置原则：无                                         |
| PREFIX       | 决定话单通道一级目录类型的字段前缀 | 可选必选说明：可选参数  参数含义：该参数用于指定决定话单通道类型的字段前缀。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~15。只允许输入由0~9的数字组成的字符串，字符串长度最大为15。  默认值：无  配置原则：无 |
| FIRSTDIRTYPE | 话单通道一级目录类型        | 可选必选说明：可选参数  参数含义：该参数用于指定话单一级目录类型。  数据来源：本端规划 取值范围： CBN2B（广电物联网场景下的分拣目录）  默认值：无  配置原则：无                                  |

## 使用实例

查询FIELDTYPE为GPSI的话单通道一级目录类型映射关系：

```
LST NCGCHLMAP: FIELDTYPE=GPSI:;
```
