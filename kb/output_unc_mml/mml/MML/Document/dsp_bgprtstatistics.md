# 查询BGP路由统计信息（DSP BGPRTSTATISTICS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询BGP路由统计信息，可用于查询BGP路由总数。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                                         |
|:--------|:---------|:-------------------------------------------------------------------------------------------------------------|
| VRFNAME | VPN实例名称  | 可选必选说明：可选参数 参数含义：该参数用于指定VPN名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：_public_ 配置原则：使用LST L3VPNINST命令查看可用VPN。 |
| AFTYPE  | BGP地址族类型 | 可选必选说明：可选参数 参数含义：该参数用于指定BGP地址族类型。 数据来源：本端规划 取值范围：枚举类型。 ipv4uni：IPv4地址族。ipv6uni：IPv6地址族。 默认值：ipv4uni          |

#### 使用实例

查询BGP路由统计信息：

```
DSP BGPRTSTATISTICS:VRFNAME="vrf1";
```

```
RETCODE = 0  操作成功。

结果如下
-------------------------
BGP路由统计信息  =
VPN-Instance           : vrf1
Router ID              : 10.1.1.1
Total Number of Routes : 4
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称     | 输出项解释          |
|:----------|:---------------|
| BGP路由统计信息 | 用于指定BGP路由统计信息。 |
