# 删除话单查询结果文件（DEL CDRQUERYFILE）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：NCG**

该命令用于删除话单查询结果文件。

#### 注意事项

- 该命令执行后即时生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                |
|:-------|:-------|:----------------------------------------------------------------------------------------------------|
| TASKID | 查询任务标识 | 可选必选说明：必选参数 参数含义：该参数用来表示查询任务标识。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～4。 默认值：无 配置原则： 该参数只能由字母、数字、“-”、“.”组成。 |

#### 使用实例

删除“查询任务标识”为“task”的话单查询结果文件。示例如下：

```
DEL CDRQUERYFILE: TASKID="task";
```
