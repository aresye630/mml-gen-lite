# 增加IMS PCF的DNN（ADD NRFIMSDNN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于配置IMS PCF支持的DNN信息。

独立部署的IMS PCF无号段信息（注册、配置和导入都无号段），即支持所有的号段。该PCF需使用此命令配置其支持的DNN，从而NRF认为PCF是独立部署的，可以正常处理业务。

如果不配置此命令，NRF可能会认为此PCF不是独立部署，没有支持的号段信息，从而屏蔽此PCF不被其他NF发现或检索以及在发生变更时通知已订阅的NF，并上报“ALM-100249 号段类NF无号段告警”，影响PCF的正常业务处理。NRF的上述判断通过SET NRFFUNCSW命令中NFNOSEGALARMSW开关控制。

## 注意事项

- 该命令执行后立即生效。

- 主备或双活组网的场景下，如果需要配置此命令，则两个NRF上均需执行此命令，且配置参数一致。

- 最多可输入64条记录。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| DNN   |
|:------|
| ims   |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                 |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DNN    | 数据网络名称 | 可选必选说明：必选参数  参数含义：该参数用于表示IMS PCF的数据网络名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~64。字符串类型，输入长度范围是0~64。该参数不区分大小写。  默认值：无  配置原则：  PCF支持的DNN等于或包含了配置的DNN信息，即认为该DNN在配置中已生效。  NRF上认为PCF是独立部署的条件是，PCF携带的DNN信息全部在NRF上已配置。  例如：  PCF规划支持ims.xa和ims.gz两个DNN：  当只配置一条“ims”记录时，NRF认为其是独立部署的；  当配置两条“ims.xa”和“ims.gz”记录时，NRF认为其是独立部署的；  当只配置一条“ims.xa”记录时，NRF认为其是非独立部署的。 |

## 使用实例

运营商规划IMS PCF用来进行IMS业务，此PCF是支持所有号段信息，为了避免NRF误判此PCF未进行号段配置，从而屏蔽该PCF不被使用，需要执行此命令，保证PCF的正常业务。在NRF上执行：

```
ADD NRFIMSDNN: DNN="huawei.com";
```
