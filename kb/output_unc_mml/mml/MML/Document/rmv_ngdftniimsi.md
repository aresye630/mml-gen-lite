# 删除基于IMSI的5G缺省NI策略（RMV NGDFTNIIMSI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除基于用户范围配置AMF的缺省NI策略。

## 注意事项

下一次移动性流程生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                       |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：必选参数  参数含义：该参数用于指定配置缺省NI（Network Identity）策略生效的用户范围。  数据来源：本端规划 取值范围： “HOME_USER（本网用户）”：本网用户“IMSI_PREFIX（指定IMSI前缀）”：指定IMSI前缀“SPECIFIC_IMSI（指定IMSI）”：指定IMSI  默认值：无  配置原则：无           |
| IMSIPRE  | IMSI前缀 | 可选必选说明：该参数在"SUBRANGE"配置为"IMSI_PREFIX"时为条件必选参数。  参数含义：该参数用于系统根据指定用户的IMSI前缀进行匹配，从而区分不同的用户群。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是5~14。只允许输入十进制数字（0-9）。  默认值：无  配置原则：  不可与“SPECIFIC_IMSI（指定IMSI）”相同。 |
| IMSI     | IMSI   | 可选必选说明：该参数在"SUBRANGE"配置为"SPECIFIC_IMSI"时为条件必选参数。  参数含义：该参数用于指定国际移动用户标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是14~15。只允许输入十进制数字（0-9）。  默认值：无  配置原则：  不可与“IMSIPRE（IMSI前缀）”相同。                        |

## 使用实例

删除指定IMSI前缀的用户配置的缺省NI策略，其中，“用户范围”为：“IMSI\_PREFIX”，“IMSI前缀”为：“12345678910”，执行如下命令：

```
RMV NGDFTNIIMSI:SUBRANGE=IMSI_PREFIX, IMSIPRE="12345678910";
```
