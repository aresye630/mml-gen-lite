# 增加NSE和属性模板的关联(ADD GBNSEGRP)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

此命令用于增加一组NSE到属性模板的关联，通过属性模板来制定NSE的属性。使用**LST GBNSECFGPARA**命令查询NSE属性模板，与该命令中配置的属性相关联。

此命令只适用于Gb over IP自动配置的场景。

#### 注意事项

- 此命令执行后立即生效。
- 此命令最大记录数为8192。
- 如果不执行此命令，自动配置的NSE则使用系统默认模板，其“模板索引”值为“0”。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称         | 参数说明                                                                                                        |
|:----------|:-------------|:------------------------------------------------------------------------------------------------------------|
| GRPINDEX  | 关联索引         | 可选必选说明：必选参数 参数含义：该参数用于指定待增加关联的索引 。 数据来源：整网规划 取值范围：0～65535 默认值：无                                             |
| NSEIBGN   | 起始NSEI       | 可选必选说明：必选参数 参数含义：该参数用于指定待增加关联的起始NSEI。 数据来源：整网规划 取值范围：0～65535 默认值：无 配置原则：起始NSEI不大于结束NSEI。NSEI范围不能相同，不能包含。    |
| NSEIEND   | 结束NSEI       | 可选必选说明：必选参数 参数含义：该参数用于指定待增加关联的结束NSEI。 数据来源：整网规划 取值范围：0～65535 默认值：无 配置原则：起始NSEI不大于结束NSEI。两组NSEI区域之间，不允许存在交集。 |
| PARAINDEX | 关联的NSE属性模板索引 | 可选必选说明：必选参数 参数含义：该参数用于指定待增加关联的NSE属性模板索引。 前提条件：该参数已增加，参见ADD GBNSECFGPARA。 数据来源：整网规划 取值范围：0～65535 默认值：无       |
| DESC      | 描述信息         | 可选必选说明：可选参数 参数含义：该参数用于指定待增加关联的描述信息。 数据来源：整网规划 取值范围： 1～33位字符串 默认值：无                                          |

#### 使用实例

增加一组NSE和属性模板的关联，“关联索引”为“0”，“起始NSEI ”为“1”，“结束NSEI ”为“3”，“关联的NSE属性模板索引”为“1”，“描述信息”为“DEFAULT”：

ADD GBNSEGRP: GRPINDEX=0, NSEIBGN=1, NSEIEND=3, PARAINDEX=1, DESC="DEFAULT";
