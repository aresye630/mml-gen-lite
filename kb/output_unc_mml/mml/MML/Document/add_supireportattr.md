# 增加SUPI的上报属性（ADD SUPIREPORTATTR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C、SMF**

该命令用于增加SUPI的上报属性。

## 注意事项

- 该命令执行后只对新激活用户生效。

- 最多可输入1000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称         | 参数说明                                                                                                                                                                                                                         |
|:---------|:-------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN      | APN名称        | 可选必选说明：必选参数  参数含义：该参数用于指示APN名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”特殊字符，不区分大小写。  默认值：无  配置原则：  该参数必须已经通过命令ADD APN配置。 |
| CGSUPI   | 上报给CG的SUPI   | 可选必选说明：必选参数  参数含义：该参数用于指定话单里使用的SUPI。  数据来源：本端规划 取值范围： SERVICE（真实的）HGUSERNAME（HG的用户名）  默认值：无  配置原则：无                                                                                                                          |
| OCSSUPI  | 上报给OCS的SUPI  | 可选必选说明：必选参数  参数含义：该参数用于指定与OCS交互的消息里使用的SUPI。  数据来源：本端规划 取值范围： SERVICE（真实的）HGUSERNAME（HG的用户名）  默认值：无  配置原则：无                                                                                                                   |
| CHFSUPI  | 上报给CHF的SUPI  | 可选必选说明：必选参数  参数含义：该参数用于指定与CHF交互的消息里使用的SUPI。  数据来源：本端规划 取值范围： SERVICE（真实的）HGUSERNAME（HG的用户名）  默认值：无  配置原则：无                                                                                                                   |
| PCRFSUPI | 上报给PCRF的SUPI | 可选必选说明：必选参数  参数含义：该参数用于指定与PCRF交互的消息里使用的SUPI。  数据来源：本端规划 取值范围： SERVICE（真实的）HGUSERNAME（HG的用户名）  默认值：无  配置原则：无                                                                                                                  |
| PCFSUPI  | 上报给PCF的SUPI  | 可选必选说明：必选参数  参数含义：该参数用于指定与PCF交互的消息里使用的SUPI。  数据来源：本端规划 取值范围： SERVICE（真实的）HGUSERNAME（HG的用户名）  默认值：无  配置原则：无                                                                                                                   |

## 使用实例

增加SUPI的上报属性，“APN名称”为“huawei.com”，“上报给CG的SUPI”为SERVICE，“上报给OCS的SUPI”为SERVICE，“上报给CHF的SUPI”为SERVICE，“上报给PCRF的SUPI”为SERVICE，“上报给PCF的SUPI”为SERVICE。

```
ADD SUPIREPORTATTR: APN="huawei.com", CGSUPI=SERVICE, OCSSUPI=SERVICE, CHFSUPI=SERVICE, PCRFSUPI=SERVICE, PCFSUPI=SERVICE;
```
