# 增加控制缺省NI下发的DNN（ADD DFTNIDNN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于配置控制缺省NI下发的DNN关键字。

应用场景为：运营商希望配置的缺省NI不对所有UE下发，而是通过用户签约特定DNN来决策是否向UE下发。

## 注意事项

- 该命令执行后立即生效。

- 当存在以下场景时，本功能无法生效：
- （1）本功能中使用的DNN在系统中未配置但存在SMF选择签约数据（SNSSAIINFOS）DNN名称取值为通配符（\*）的ADD UDMBYPASSSUB配置记录；
- （2）本功能中使用的DNN未在UDM上签约但签约数据中存在通配符（\*）的DNN。

- 最多可输入10条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                    |
|:---------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DNNKEYWD | DNN关键字 | 可选必选说明：必选参数  参数含义：该参数用于设置下发默认NI策略的特定DNN关键字。 当用户签约的DNN前缀匹配该参数配置的关键字时，则认为该用户需要下发默认NI。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。  默认值：无  配置原则：  字符串类型，输入长度范围是1~63。可输入的字符有字母、十进制数字、“-”和“.”，并且开头和结尾只能是数字或者字母。不能出现连续两个“.”。字母大小写不敏感。 |

## 使用实例

运营商希望AMF能根据用户签约DNN是否含关键字“NeedDefaultUElogo”来控制下发默认NI，并且指定默认NI的范围为ADD NGMNO、ADD NITZPLCY、SET AMFPLCYFUNC配置的NI。

```
SET NGDFTNIPLCY: AMFDNNSW=ON, AMFDFTNI=AMFPLCYFUNC-1&NITZPLCY-1&NGMNO-1,UDMBYPASSDNN=NO;
ADD DFTNIDNN: DNNKEYWD="NeedDefaultUElogo";
```
