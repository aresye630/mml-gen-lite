# 修改IMSI号段属性配置(MOD IMSICHAR)

#### 命令功能

**适用网元：SGSN、MME**

该命令用于修改IMSI号段属性配置。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                   |
|:---------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围    | 可选必选说明：必选参数 参数含义：该参数用于指定签约用户的范围。 数据来源：整网规划 取值范围：“ALL_USER(所有用户)”“IMSI_PREFIX(指定IMSI前缀)”“IMSI_RANGE(指定IMSI范围)” 默认值：无                                                                                                                                                                                                                                                    |
| IMSIPRE  | IMSI前缀  | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI前缀。 前提条件：该参数在“用户范围”参数设置为“IMSI_PREFIX(指定IMSI前缀)”时，才需要配置。 数据来源：整网规划 取值范围：1～15位十进制数字 默认值：无                                                                                                                                                                                                                                                  |
| BEGIMSI  | 起始IMSI  | 可选必选说明：条件必选参数 参数含义：该参数用于指定起始IMSI。 前提条件：该参数在“用户范围”参数设置为“IMSI_RANGE(指定IMSI范围)”时，才需要配置。 数据来源：整网规划 取值范围：1～15位十进制数字 默认值：无 配置原则：输入的起始IMSI必须小于或者等于终止IMSI。输入的起始IMSI和终止IMSI定义的IMSI号段范围不允许与其它记录定义的IMSI号段范围相互交叉、包含或重合。  说明： 判断起始IMSI和终止IMSI大小的原则是：对于输入IMSI的长度小于系统规定IMSI长度时，将该IMSI补足0到规定长度后进行大小比较，且起始IMSI必须小于终止IMSI。只有输入IMSI长度等于系统规定长度时，起始IMSI才能等于终止IMSI。对于系统规定IMSI长度为15的情况，如表1所示。 |
| ENDIMSI  | 终止IMSI  | 可选必选说明：条件必选参数 参数含义：该参数用于指定终止IMSI。 前提条件：该参数在“用户范围”参数设置为“IMSI_RANGE(指定IMSI范围)”时，才需要配置。 数据来源：整网规划 取值范围：1～15位十进制数字 默认值：无 配置原则：终止IMSI要大于起始IMSI。                                                                                                                                                                                                                             |
| SGSNNO   | 本局SGSN号 | 可选必选说明：可选参数 参数含义：该参数用于指定的服务GPRS支持节点（SGSN）号码，是SGSN的E.164地址。 前提条件：该参数已增加，参见ADD SCCPOPC。 数据来源：整网规划 取值范围：1～16位十进制数字 默认值：无  说明： 系统获取本端SGSN号的策略： 如果IMSICHAR表配置了，从IMSICHAR表中获取。如果IMSICHAR中没有配置，则从HNOINFO表中获取。如果IMSICHAR和HNOINFO都没有配置，则从SCCPOPC表中获取。                                                                                                                           |
| LOINDEX  | 本地实体索引  | 可选必选说明：可选参数 参数含义：该参数用于指定添加的本地实体的索引信息。 前提条件：在“MML命令行-UNC”窗口上执行命令ADD DMLE设置此参数。 数据来源：本端规划 取值范围：0～31 默认值：无  说明： 系统获取本地实体索引信息的策略： 如果IMSICHAR表配置了，从IMSICHAR表中获取。如果IMSICHAR中没有配置，则从HNOINFO表中获取。                                                                                                                                                                              |

#### 使用实例

修改一条IMSICHAR属性配置记录，“用户范围”为“指定IMSI前缀”，“IMSI前缀”为“123003”，“本局SGSN号”为“861390218601”：

MOD IMSICHAR: SUBRANGE=IMSI\_PREFIX, IMSIPRE="123003", SGSNNO="861390218601";
