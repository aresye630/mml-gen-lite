# 显示5G小区广播预警信息（DSP NGCBSWARN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询5G小区广播预警信息，包括CBCF发起的预警信息和取消预警信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                      |
|:---------|:---------|:--------------------------------------------------------------------------------------------------------------------------|
| CBCID    | CBCF实例标识 | 可选必选说明：可选参数  参数含义：该参数用于指定发送预警的CBCF实例标识。本参数输入为空时，返回的结果中包含所有预警信息。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~40。不区分大小写。  默认值：无  配置原则：无 |
| WARNTYPE | 预警类型     | 可选必选说明：可选参数  参数含义：该参数用于指定预警类型。  数据来源：对端协商 取值范围： Write-ReplaceWarning（下发预警）PWSCancel（取消预警）  默认值：无  配置原则：无                  |

## 使用实例

查询实例标识是“CBCF\_Instance\_0”的CBCF发起的预警信息，执行如下命令：

```
%%DSP NGCBSWARN:;%%
RETCODE = 0  操作成功

结果如下
------------------------
          CBCF实例标识  =  CBCF_Instance_0
              预警类型  =  下发预警
            预警消息ID  =  12303
            预警序列号  =  1
          预警创建时间  =  2025-01-02T15:04:05Z07:00
        待预警基站数量  =  10
  已发送预警的基站数量  =  0
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称      | 输出项解释                                                        |
|:-----------|:-------------------------------------------------------------|
| CBCF实例标识   | 该参数用于指定发送预警的CBCF实例标识。本参数输入为空时，返回的结果中包含所有预警信息。                |
| 预警类型       | 该参数用于指定预警类型。 取值说明： Write-ReplaceWarning（下发预警）PWSCancel（取消预警） |
| 预警消息ID     | 该参数用于指定预警消息标识。                                               |
| 预警序列号      | 该参数用于指定预警序列号。                                                |
| 预警创建时间     | 该参数用于指定预警的创建时间。                                              |
| 待预警基站数量    | 该参数用于指定待预警的基站数量。                                             |
| 已发送预警的基站数量 | 该参数用于指定已发送预警的基站数量。                                           |
