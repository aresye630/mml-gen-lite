# 设置SMF&UPF&CHF三方流量抽样审计参数（SET CHGVERIFYCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、GGSN、PGW-C**

该命令用于设置SMF&UPF&CHF三方流量抽样审计的参数。

## 注意事项

- 该命令执行后立即生效。

- 由于抽样开关关闭期间SMF不做流量统计，所以抽样开关关闭之后，如果session还没有释放，又重新将抽样开关打开，可能会导致 SMF 和UPF流量核查最终失败。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| CHGTRAFFVRFYSW   | N4TRAFFVRFYSW   | N40TRAFFVRFYSW   |   CHGTRAFFVRFYNUM |
|:-----------------|:----------------|:-----------------|------------------:|
| DISABLE          | DISABLE         | DISABLE          |                10 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称          | 参数说明                                                                                                                                                                                                                                                                             |
|:----------------|:--------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CHGTRAFFVRFYSW  | 计费流量抽样核查总开关   | 可选必选说明：可选参数  参数含义：该参数用于指示是否开启流量抽样核查。  数据来源：本端规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CHGVERIFYCTRL查询当前参数配置值。  配置原则：无                                                                                                                            |
| N4TRAFFVRFYSW   | N4接口流量抽样核查开关  | 可选必选说明：可选参数  参数含义：该参数用于指示是否开启N4接口流量抽样核查。  数据来源：本端规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CHGVERIFYCTRL查询当前参数配置值。  配置原则：  参数CHGTRAFFVRFYSW和N4TRAFFVRFYSW同时打开才能开启N4接口流量抽样核查功能。                                                                    |
| N40TRAFFVRFYSW  | N40接口流量抽样核查开关 | 可选必选说明：可选参数  参数含义：该参数用于指示是否开启N40接口流量抽样核查。  数据来源：对端协商 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CHGVERIFYCTRL查询当前参数配置值。  配置原则：  参数CHGTRAFFVRFYSW和N40TRAFFVRFYSW同时打开才能开启N40接口流量抽样核查功能。该功能与N40流量抹平功能冲突，开启CNVRGDCHGPARA命令的RPTBASEDONGU参数功能时，核查结果准确性无法保证。 |
| CHGTRAFFVRFYNUM | 计费流量抽样核查数量    | 可选必选说明：可选参数  参数含义：该参数用于设置计费流量抽样核查的会话数量。  数据来源：本端规划  取值范围：整数类型，取值范围是1~100，单位是个。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CHGVERIFYCTRL查询当前参数配置值。  配置原则：  参数CHGTRAFFVRFYNUM配置从大到小时，已经抽样的会话还是可以执行审查，等到被抽样会话自然释放至会话数小于新的门限之后才会重新抽样新会话。                                               |

## 使用实例

设置计费流量抽样核查总开关打开，N4接口流量抽样核查开关打开，N40接口流量抽样核查开关打开，计费流量抽样核查数量为10：

```
SET CHGVERIFYCTRL: CHGTRAFFVRFYSW=ENABLE, N4TRAFFVRFYSW=ENABLE, N40TRAFFVRFYSW=ENABLE, CHGTRAFFVRFYNUM=10;
```
