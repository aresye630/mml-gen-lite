# 查询等价PLMN组（LST EPLMNGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询等价PLMN组。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                     |
|:-------|:---------|:-------------------------------------------------------------------------------------------------------------------------|
| GRPIDX | 等价PLMN组号 | 可选必选说明：可选参数  参数含义：该参数用于在UNC系统内唯一标识一个等价PLMN组。  数据来源：本端规划  取值范围：整数类型，取值范围是0~127。  默认值：无  配置原则：  本命令不同的配置记录对应的等价PLMN组号不能相同。 |

## 使用实例

- 查询系统中“等价PLMN组号”为“0”的等价PLMN组信息，执行如下命令：

  ```
  %%LST EPLMNGRP: GRPIDX=0;%%
  RETCODE = 0  操作成功

  结果如下
  --------
  等价PLMN组号  =  0
      PLMN索引  =  0
  用户群组标识  =  0
  跟踪区域组ID  =  3
      描述信息  =  for ServingPLMN 12345
  (结果个数 = 1)

  ---    END
  ```
- 查询系统中配置的等价PLMN组信息，执行如下命令：

  ```
  %%LST EPLMNGRP:;%%
  RETCODE = 0  操作成功

  结果如下
  --------
  等价PLMN组号  =  0
      PLMN索引  =  0
  用户群组标识  =  0
  跟踪区域组ID  =  3
      描述信息  =  for ServingPLMN 12345
  (结果个数 = 1)

  ---    END
  ```

## 输出结果说明

| 输出项名称    | 输出项解释                                                    |
|:---------|:---------------------------------------------------------|
| 等价PLMN组号 | 该参数用于在UNC系统内唯一标识一个等价PLMN组。                               |
| PLMN索引   | 该参数表示配置等价PLMN列表的Serving PLMN的索引信息，需要通过ADD NGSRVPLMN提前配置。 |
| 用户群组标识   | 该参数用于标识EPLMN适用的用户群信息，需要通过ADD NGUSRGRP提前配置。               |
| 跟踪区域组ID  | 该参数用于标识等价PLMN适用的区域，需要通过ADD EPLMNAREAMEM提前配置。             |
| 描述信息     | 该参数用于对等价PLMN组的描述，在运维中起助记的作用。                             |
