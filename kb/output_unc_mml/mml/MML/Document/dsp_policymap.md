# 查询策略映射表（DSP POLICYMAP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

查询策略映射表，获取业务VNFC侧的策略ID。策略映射表中记录业务VNFC侧策略ID与CSLB侧策略ID的对应关系。

#### 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                                                  |
|:-----------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SRVVNFCID  | 业务VNFCID | 可选必选说明：可选参数 参数含义：该参数用于指定业务VNFC的唯一标识，通过在业务VNFC下执行LST NODE获得，所得NODEID即为服务VNFC ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0~4294967295。 默认值：无                                                                          |
| PLYTYPE    | 策略类型     | 可选必选说明：可选参数 参数含义：该参数用于指定策略类型。 数据来源：本端规划 取值范围：枚举类型“PLY_TYPE_LB：负载均衡策略”“PLY_TYPE_DP：流识别策略”“PLY_TYPE_NEXTHOP：下一跳策略”“PLY_TYPE_EXCHANGE：交换表策略”“PLY_TYPE_LB_EX：扩展负载均衡策略”“PLY_TYPE_NEXTHOP_EX：扩展下一跳策略” 默认值：无 |
| LBPOLICYID | LB策略ID   | 可选必选说明：可选参数 参数含义：该参数用于指定CSLB分配的策略标识。 数据来源：本端规划 取值范围：整数类型，取值范围为0~4294967295。 默认值：无                                                                                                                     |

#### 使用实例

查询策略映射表。

`DSP POLICYMAP:;`

```
%%DSP POLICYMAP: PLYTYPE=PLY_TYPE_NEXTHOP;%%
RETCODE = 0  操作成功 

结果如下:
-------------------------
业务VNFC ID    策略类型         APP策略ID     LB策略ID     

4             下一跳策略        1            1            
4             下一跳策略        0            0            
4             下一跳策略        2            2            
4             下一跳策略        4            4            
4             下一跳策略        3            3            
(结果个数 = 5)
---    END
```
