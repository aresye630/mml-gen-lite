# 显示网元级KPI异常检测与容灾功能的资源评估结果（DSP NFCAPINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示网元级KPI异常检测与容灾功能的资源评估结果，评估资源项是否满足业务迁移需求。

## 注意事项

- 该命令适用于适配包已配置参考剩余容量的场景。
- 若同组合类型资源实例仅部署在本网元，容灾网元未部署同组合类型资源实例，则不满足业务迁移需求，不可迁移。
- 若同组合类型资源实例在本网元和容灾网元均已部署，如果同组合类型本网元迁移容量之和小于等于容灾网元资源容量之和，可迁移，否则，不可迁移。
- 若CPU类型本网元迁移容量显示为0.00%，可能是本网元资源实例CPU使用率小于等于配置的空载阈值，或本网元不存在该类型资源实例。
- 若CPU类型容灾网元资源容量显示为0.00%，可能是容灾网元资源实例CPU使用率大于等于配置的过载阈值，或容灾网元不存在该类型资源实例。
- 适配包空载阈值和过载阈值配置可以通过LST NODEHEALCPUTHR（虚机场景）或LST PODHEALCPUTHR（裸机场景）查询。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

显示网元级KPI异常检测与容灾功能的资源评估结果。

```

RETCODE = 0  操作成功
```

## 输出结果说明

| 输出项名称    | 输出项解释                                                                        |
|:---------|:-----------------------------------------------------------------------------|
| 资源类型     | 该参数表示资源项的类型。 取值说明： CPU（CPU）LICENSE（LICENSE）                                  |
| 资源名称     | 该参数表示资源项的具体名称，包括Node类型（虚机场景）、Pod类型（裸机场景）和License ID。                         |
| 资源描述     | 该参数表示资源项的描述信息，License类型描述信息是License ID对应的License控制项。CPU类型描述信息是资源实例所属组合类型。    |
| 本网元资源迁移量 | 该参数表示本网元资源项需要迁移的容量。                                                          |
| 容灾网元资源容量 | 该参数表示容灾网元资源项可承载的容量。                                                          |
| 是否可迁移    | 该参数表示资源项是否可迁移。 取值说明： “TRUE（可迁移）”：容灾网元可承载本网元迁移量。“FALSE（不可迁移）”：容灾网元不可承载本网元迁移量。 |
