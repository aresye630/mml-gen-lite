# 增加Protocol Description参数（ADD PROTODESCPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于增加Protocol Description参数。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入1000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称              | 参数说明                                                                                                                                                                                                                 |
|:--------------|:------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROTODESCNAME | 协议描述名称            | 可选必选说明：必选参数  参数含义：该参数用于指定协议描述的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。不支持空格，不区分大小写。  默认值：无  配置原则：无                                                                                                                    |
| TRANSPROTO    | 传输协议类型            | 可选必选说明：可选参数  参数含义：该参数用于指定传输协议的类型。  数据来源：本端规划 取值范围： “NOT_SUPPORT（不支持）”：不支持指定协议类型“RTP（RTP协议类型）”：指定协议类型为RTP：Real-time Transport Protocol“SRTP（SRTP协议类型）”：指定协议类型为SRTP：Secure Real-time Transport Protocol  默认值：无  配置原则：无 |
| RTPHEADERTYPE | RTP头扩展类型          | 可选必选说明：可选参数  参数含义：该参数用于指定RTP头扩展类型。  数据来源：本端规划 取值范围： “NOT_SUPPORT（不支持指定RTP头扩展类型）”：不支持指定RTP头扩展类型“PDU_SET_MARKING（PDU_SET_MARKING头扩展类型）”：指定RTP头扩展类型为PDU_SET_MARKING  默认值：无  配置原则：无                                      |
| RTPHEADERID   | RTP头扩展ID          | 可选必选说明：可选参数  参数含义：该参数用于指定RTP头扩展ID。  数据来源：本端规划  取值范围：整数类型，取值范围是1~255。  默认值：无  配置原则：  不配置此参数时默认值为非法值0。                                                                                                                 |
| HEADERFORMAT  | 头扩展格式             | 可选必选说明：可选参数  参数含义：该参数用于指定头扩展格式。  数据来源：本端规划 取值范围： “UNKNOWN（未知头拓展格式）”：指定头拓展格式为未知格式。“SHORT_FORMAT（SHORT_FORMAT头拓展格式）”：指定头拓展格式为SHORT_FORMAT。“LONG_FORMAT（LONG_FORMAT头拓展格式）”：指定头拓展格式为LONG_FORMAT。  默认值：无  配置原则：无          |
| PDUSETSIZESW  | RTP头是否携带PDU SET规格 | 可选必选说明：可选参数  参数含义：该参数用于指定RTP头是否携带PDU SET规格。  数据来源：本端规划 取值范围： UNKNOWN（未知）DISABLE（不使能）ENABLE（使能）  默认值：无  配置原则：无                                                                                                        |
| RTPPAYLOADFMT | RTP净荷格式           | 可选必选说明：可选参数  参数含义：该参数用于指定RTP净荷格式。  数据来源：本端规划 取值范围： UNKNOWN（未知RTP净荷格式）H264（H264 RTP净荷格式）H265（H265 RTP净荷格式）  默认值：无  配置原则：无                                                                                             |
| RTPTYPELST1   | RTP净荷类型列表1        | 可选必选说明：可选参数  参数含义：该参数用于指定RTP净荷类型列表1-32。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：  该bit有值时代表对应bit的RTP净荷类型存在。例如，取值为3（0b11）时，代表RTP净荷类型1和2存在。                                                              |
| RTPTYPELST2   | RTP净荷类型列表2        | 可选必选说明：可选参数  参数含义：该参数用于指定RTP净荷类型列表33-64。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：  该bit有值时代表对应bit的RTP净荷类型存在。例如，取值为3（0b11）时，代表RTP净荷类型33和34存在。                                                           |
| RTPTYPELST3   | RTP净荷类型列表3        | 可选必选说明：可选参数  参数含义：该参数用于指定RTP净荷类型列表65-96。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：  该bit有值时代表对应bit的RTP净荷类型存在。例如，取值为3（0b11）时，代表RTP净荷类型65和66存在。                                                           |
| RTPTYPELST4   | RTP净荷类型列表4        | 可选必选说明：可选参数  参数含义：该参数用于指定RTP净荷类型列表97-127。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：  该bit有值时代表对应bit的RTP净荷类型存在。例如，取值为3（0b11）时，代表RTP净荷类型97和98存在。                                                          |

## 使用实例

增加协议描述名称为“name1”，传输协议类型为SRTP，RTP头扩展类型为PDU\_SET\_MARKING，RTP净荷格式为H265，且RTP净荷类型1和2存在的协议描述参数。

```
ADD PROTODESCPARA: PROTODESCNAME="name1", TRANSPROTO=SRTP, RTPHEADERTYPE=PDU_SET_MARKING, RTPPAYLOADFMT=H265, RTPTYPELST1=3;
```
