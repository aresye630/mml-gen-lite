#### 命令功能

**适用网元：MME**

此命令用于查询eNodeB群组记录。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称       | 参数说明                                                                            |
|:--------|:-----------|:--------------------------------------------------------------------------------|
| ENBGPID | eNodeB群组标识 | 可选必选说明：可选参数 参数含义：该参数用于指定eNodeB群组标识。 数据来源：本端规划 取值范围：1~2048 默认值：无                 |
| TYPE    | 类型         | 可选必选说明：可选参数 参数含义：用于指定该eNodeB群组的类型。 数据来源：整网规划 取值范围：“ENTRY(入口)”“INSIDE(内部)” 默认值：无 |

#### 使用实例

查询所有eNodeB群组记录：

LST ENBGP:;

```
%%LST ENBGP:;%%
RETCODE = 0  操作成功。

操作结果如下
--------------
eNodeB群组标识  =  1
          类型  =  入口
驻留时长（min） =  NULL
      接入次数  =  0
eNodeB群组名称  =  highspeed_usercheck_entry
(结果个数 = 1)

---    END
```
