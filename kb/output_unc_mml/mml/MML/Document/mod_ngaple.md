# 修改NGAP本端实体（MOD NGAPLE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于修改NGAP本端实体配置。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                                                                                                  |
|:------------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NGAPLEIDX   | NGAP本端实体索引 | 可选必选说明：必选参数  参数含义：该参数用于指定NGAP本端实体的索引，该索引作为NGAP本端实体的唯一标识。  数据来源：本端规划  取值范围：整数类型，取值范围是0~1023。  默认值：无  配置原则：无                                                                            |
| NGAPPARAIDX | NGAP参数索引   | 可选必选说明：可选参数  参数含义：该参数用于指定NGAP本端实体的NGAP协议参数配置索引。NGAP协议参数存在系统默认配置，如果NGAP本端实体默认使用系统默认参数可不指定该参数。如果NGAP本端实体需要使用其他配置值，则可以引用对应配置的NGAP协议参数索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~31。  默认值：无  配置原则：无 |

## 使用实例

将本端实体标识为1的本端实体的NGAP参数索引改为5，执行如下命令：

```
MOD NGAPLE: NGAPLEIDX=1, NGAPPARAIDX=5;
```
