# 设置ACS检查策略(SET ACSCHKPOLICY)

## 命令功能

用于设置ACS配置检查策略项。

## 注意事项

- 该命令执行后立即生效。

该命令存在系统初始记录，参数的初始设置值如下表：

| 策略      | 策略开关   |
|:--------|:-------|
| 检查微服务数据 | 打开     |

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                 |
|:-------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------|
| POLICY       | 策略     | 可选必选说明：必选参数。 参数含义：用于指定需要设置的配置检查策略。 取值范围：枚举类型。 Check_Service_Data(检查微服务数据)：凌晨定时检查ACS与远端配置数据。 默认值：Check_Service_Data(检查微服务数据)。 配置原则：无。 |
| POLICYSWITCH | 策略开关   | 可选必选说明：可选参数。 参数含义：用于设置指定策略的开关。 取值范围：枚举类型。 OFF(关闭)：策略关闭。ON(打开)：策略打开。 默认值：OFF(关闭)。 配置原则：默认关闭凌晨定时检查ACS与远端配置数据。                          |

## 使用实例

设置检查微服务数据“策略开关”为“OFF(关闭)”时，执行以下命令：

```
SET ACSCHKPOLICY: POLICY=Check_Service_Data, POLICYSWITCH=OFF;
```

```
%%SET ACSCHKPOLICY: POLICY=Check_Service_Data, POLICYSWITCH=OFF;%%

```
