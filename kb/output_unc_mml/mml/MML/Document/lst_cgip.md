# 查询CGIP测量对象（LST CGIP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

此命令用于查询CGIP测量对象。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询CGIP测量对象：

```
LST CGIP:;
```

```
RETCODE = 0  操作成功。

CGIP地址
--------
IP地址  =  192.168.1.12
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释       |
|:--------|:------------|
| IP地址    | 用于存放CGIP地址。 |
