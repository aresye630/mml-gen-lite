# 查询支持的S-NSSAI（LST CFGSNSSAI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NSSF**

该命令用于查询NSSF支持的S-NSSAI列表。

## 注意事项

查询条件都不填时，即查询所有。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称         | 参数说明                                                                                                                                                                      |
|:---------|:-------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INDEX    | 索引           | 可选必选说明：可选参数  参数含义：该参数用于描述命令的索引值。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无                                                                                  |
| MCC      | 移动国家码        | 可选必选说明：可选参数  参数含义：该参数用于描述移动国家码。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。3位十进制数。  默认值：无  配置原则：无                                                                                      |
| MNC      | 移动网号         | 可选必选说明：可选参数  参数含义：该参数用于描述移动网号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。2位或者3位十进制数。  默认值：无  配置原则：无                                                                               |
| SST      | 切片服务类型       | 可选必选说明：可选参数  参数含义：该参数用于描述切片服务类型。  数据来源：全网规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无                                                                                         |
| SD       | 切片细分标识       | 可选必选说明：可选参数  参数含义：该参数用于表示切片细分标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是4~6。该参数只能由字母（A-F或者a-f）、数字（0-9）组成。  默认值：无  配置原则：  SD与SD区间配置二选一，不能同时使用。SD、SDSTART以及SDEND都为空时SD会被自动填充为FFFFFF。 |
| PRIORITY | 优先级          | 可选必选说明：可选参数  参数含义：该参数用于描述优先级。  数据来源：本端规划  取值范围：整数类型，取值范围是1~65535。  默认值：无  配置原则：无                                                                                          |
| ISACTIVE | 激活状态         | 可选必选说明：可选参数  参数含义：该参数用于描述切片的激活状态。  数据来源：全网规划  取值范围： TRUE(TRUE)FALSE(FALSE)  默认值：无  配置原则：无                                                                                 |
| SDSTART  | 切片细分标识区间的起始值 | 可选必选说明：可选参数  参数含义：该参数用于表示切片细分标识区间的起始值。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是4~6。该参数只能由字母（A-F或者a-f）、数字（0-9）组成。  默认值：无  配置原则：  SD与SD区间配置二选一，不能同时使用。  SDSTART与SDEND必须同时有值或者同时为空。    |
| SDEND    | 切片细分标识区间的结束值 | 可选必选说明：可选参数  参数含义：该参数用于表示切片细分标识区间的结束值。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是4~6。该参数只能由字母（A-F或者a-f）、数字（0-9）组成。  默认值：无  配置原则：  SD与SD区间配置二选一，不能同时使用。  SDSTART与SDEND必须同时有值或者同时为空。    |

## 使用实例

- 若运营商希望查询所有的数据，执行下列命令。

  ```
  LST CFGSNSSAI:;
  %%LST CFGSNSSAI:;%%
  RETCODE = 0  Operation succeeded

  The result is as follows
  ------------------------
  索引  移动国家码  移动网号  切片服务类型  切片细分标识  优先级  激活状态  描述  切片细分标识区间的起始值  切片细分标识区间的结束值  

  1      460            05            1               NULL       1024     TRUE     NULL         111111          222222        
  2      460            03            1              111111      1024     TRUE     NULL         NULL            NULL          
  (结果个数 = 2)
  ```
- 若运营商希望查询移动国家码为"460"、移动网号为"03"，支持的切片或者切片区间，执行下列命令。

  ```
  LST CFGSNSSAI: MCC="460", MNC="03";
  %%LST CFGSNSSAI: MCC="460", MNC="03";%%
  RETCODE = 0  操作成功

  结果如下
  --------
          索引  =  1
    移动国家码  =  460
      移动网号  =  03
  切片服务类型  =  1
  切片细分标识  =  111111
      优先级为  =  1024
      激活状态  =  TRUE
  	    描述  =  NULL
  切片细分标识区间的起始值 = NULL
  切片细分标识区间的结束值 = NULL
  (结果个数 = 1)
  ```
