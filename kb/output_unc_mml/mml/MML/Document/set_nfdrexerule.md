# 设置容灾执行规则（SET NFDREXERULE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置容灾执行规则。

## 注意事项

- 该命令执行后立即生效。

- 该命令用于AMF网元根据业务场景配置容灾执行规则。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

|   EXECRULE |   WAITTIME |
|-----------:|-----------:|
|        nan |         30 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称           | 参数说明                                                                                                                                                                                                                                                                       |
|:---------|:---------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| EXECRULE | 容灾执行规则         | 可选必选说明：可选参数  参数含义：该参数用于表示容灾执行规则。  数据来源：本端规划 取值范围： “NULL（无规则）”：无规则“GRACEMIGRATION（优雅迁移）”：优雅迁移“BROKENLINK（断链路）”：断链路“ALL（先优雅迁移，再断链路）”：先优雅迁移，再断链路  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST NFDREXERULE查询当前参数配置值。  配置原则：  当容灾执行规则配置为"ALL"时，在等待时间内，优雅迁移完成则执行断链路；超时后优雅迁移未完成直接断链路。 |
| WAITTIME | 容灾执行规则等待时间(分钟) | 可选必选说明：该参数在"EXECRULE"配置为"ALL"时为条件可选参数。  参数含义：该参数用于设置容灾执行规则的等待时间。  数据来源：本端规划  取值范围：整数类型，取值范围是0~180。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST NFDREXERULE查询当前参数配置值。  配置原则：无                                                                                                  |

## 使用实例

设置容灾执行规则为优雅迁移。

```
%%SET NFDREXERULE: EXECRULE=GRACEMIGRATION;%%
RETCODE = 0  操作成功

---    END
```
