# 查询虚拟UPF实例标识（LST VIRTUALUPFID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF**

该命令用于查询虚拟UPF实例标识。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识           | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                                            |
|:---------------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UPFINSTANCEID  | UPF实例标识   | 可选必选说明：可选参数  参数含义：该参数用于指定UPF实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~36。该参数必须满足以下约束规则：1.如果输入为uuid格式（格式例如：a6a61c6f-0d3a-4221-b1da-424eda3ccf67）只能为A-F、a-f、0-9的字符。2.如果输入不为uuid格式，长度不能超过18且不允许输入只包含0-9和“.”的字符串，例如：1.2.3.4；不允许输入只包含十六进制数（A-F、a-f、0-9）和“:”的字符串，例如：1::2、FBFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。不区分大小写。  默认值：无  配置原则：  该参数取值应与ADD UPNODE中参数“NFINSTANCENAME”保持一致，使用该前需通过ADD UPNODE添加一组记录。 |
| VUPFINSTANCEID | 虚拟UPF实例标识 | 可选必选说明：可选参数  参数含义：该参数用于指定虚拟UPF实例标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~36。该参数必须满足以下约束规则：1.如果输入为uuid格式（格式例如：a6a61c6f-0d3a-4221-b1da-424eda3ccf67）只能为A-F、a-f、0-9的字符。2.如果输入不为uuid格式，长度不能超过18且不允许输入只包含0-9和“.”的字符串，例如：1.2.3.4；不允许输入只包含十六进制数（A-F、a-f、0-9）和“:”的字符串，例如：1::2、FBFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。不区分大小写。  默认值：无  配置原则：无                                                                 |

## 使用实例

- 查看UPF实例标识为upf1的虚拟UPF实例标识：

  ```
  %%LST VIRTUALUPFID:UPFINSTANCEID="upf1";%%
  RETCODE = 0  操作成功

  结果如下
  --------
      UPF实例标识  =  upf1
  虚拟UPF实例标识  =  v_upf2
  (结果个数 = 1)

  ---    END
  ```
- 查看所有虚拟UPF实例标识：

  ```
  %%LST VIRTUALUPFID:;%%
  RETCODE = 0  操作成功

  结果如下
  --------
  UPF实例标识         虚拟UPF实例标识

  upf1            	v_upf1     
  upf2            	v_upf2     
  (结果个数 = 2)

  ---    END
  ```
