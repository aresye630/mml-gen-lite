# 显示SMF相关的调试信息（DSP SMFDBGINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C、SMF、GGSN**

该命令用于查询和SMF相关的调试信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 使用实例

查询SMF相关调试信息时使用该命令：

```
DSP SMFDBGINFO: QRYTP=0;
```
