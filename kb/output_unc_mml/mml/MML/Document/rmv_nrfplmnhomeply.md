# 删除指定拜访地PLMN的归属地策略（RMV NRFPLMNHOMEPLY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于删除NRF作为归属地NRF时对指定拜访地PLMN的跨PLMN请求处理策略。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                     |
|:-------|:-------|:-----------------------------------------------------------------------------------------|
| MCC    | 移动国家码  | 可选必选说明：必选参数  参数含义：该参数用于表示拜访地PLMN的移动国家码。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。  默认值：无  配置原则：无    |
| MNC    | 移动网号   | 可选必选说明：必选参数  参数含义：该参数用于表示拜访地PLMN的移动网号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。  默认值：无  配置原则：无 |

## 使用实例

删除移动国家码为460，移动网号为03的指定拜访地PLMN的归属地策略。

```
RMV NRFPLMNHOMEPLY: MCC="466", MNC="03";
```
