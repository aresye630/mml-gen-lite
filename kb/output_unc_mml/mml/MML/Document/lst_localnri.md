# 查询本局NRI配置信息(LST LOCALNRI)

- 命令功能
- 注意事项
- 本地用户权限

- 输出结果说明

#### 命令功能

**适用网元：SGSN**

此命令用于查询本局NRI配置信息。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                                                                                                                  |
|:--------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| POOLID  | POOL区标识 | 可选必选说明：可选参数 参数含义：该参数用于指定POOL区标识。 取值范围：0～4095 默认值：无                                                                                                                                                                    |
| NRIVBGN | NRI起始值  | 可选必选说明：可选参数 参数含义：该参数用于指定NRI起始值，NRI（Net Resource Identify），网络资源标识，用于标识一个CN节点。RAN根据NRI将MS的消息路由到对应的SGSN。 取值范围：0～1023 默认值：无  说明： NRI的取值范围在0～(2n-1)，n为本Pool的NRI长度。若POOL表的NRI长度为10，则LOCALNRI表的NRI个数必须大于等于4， NRI起始值小于等于1020。 |

#### 使用实例

查询本局所有NRI属性信息：

LST LOCALNRI:;

```
%%LST LOCALNRI:;%%
RETCODE = 0  执行成功。

LOCALNRI表
----------
        POOL区标识  =  0
         NRI起始值  =  0
           NRI个数  =  1
           NRI状态  =  UNBLOCKED
(结果个数 = 1)
---    END
```
