# 查询MME POOL（LST MMEPOOL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C**

该命令用于查询MME POOL。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                |
|:------------|:-----------|:----------------------------------------------------------------------------------------------------|
| MMEPOOLNAME | MME POOL名称 | 可选必选说明：可选参数  参数含义：该参数用于指定MME POOL名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。不支持空格，不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

假设用户需要查询所有的MME POOL：

```
%%LST MMEPOOL:;%%
RETCODE = 0  操作成功

结果如下
--------
       MME POOL名称  =  mmepool1
       SGW POOL名称  =  NULL
指定备份MME功能开关  =  不使能
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称       | 输出项解释                          |
|:------------|:-------------------------------|
| MME POOL名称  | 该参数用于指定MME POOL名。              |
| SGW POOL名称  | 该参数用于指定与该MME POOL绑定的SGW POOL名。 |
| 指定备份MME功能开关 | 配置是否开启指定备份MME的功能。              |
