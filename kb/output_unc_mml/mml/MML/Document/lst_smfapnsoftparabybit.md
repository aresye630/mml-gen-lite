# 查询SMF APN软件参数比特位（LST SMFAPNSOFTPARABYBIT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF**

该命令用于查询SMF APN软件参数，查询结果以二进制形式输出。同时，该命令也支持查询指定软件参数中某个比特位的值。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                                                                      |
|:---------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN      | APN     | 可选必选说明：必选参数  参数含义：该参数用于指定APN实例名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”特殊字符，不区分大小写。  默认值：无  配置原则：无 |
| DT       | 数据类型    | 可选必选说明：必选参数  参数含义：该参数表示软件参数的数据类型。  数据来源：本端规划 取值范围： Dw（双字）Byte（字节）  默认值：无  配置原则：无                                                                                                                                          |
| DWORDNUM | Dword索引 | 可选必选说明：该参数在"DT"配置为"Dw"时为条件可选参数。  参数含义：该参数表示Dword类型软件参数的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~16。  默认值：无  配置原则：无                                                                                                                |
| BYTENUM  | Byte索引  | 可选必选说明：该参数在"DT"配置为"Byte"时为条件可选参数。  参数含义：该参数表示Byte类型软件参数的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~8。  默认值：无  配置原则：无                                                                                                                |
| POSITION | 比特位     | 可选必选说明：可选参数  参数含义：该参数表示软件参数比特位的位置。  数据来源：本端规划  取值范围：整数类型，取值范围是1~64。  默认值：无  配置原则：无                                                                                                                                        |

## 使用实例

查询APN为huawei.com数据类型为双字的软参值：

```
%%LST SMFAPNSOFTPARABYBIT: APN="huawei.com", DT=Dw;%%
RETCODE = 0  Operation succeeded

The result is as follows
------------------------
APN         Data Type  Soft para number  Bit position  Soft para value                          

huawei.com  Dword      1                 NULL          0000 0000 0000 0000 0000 0000 0000 0000  
huawei.com  Dword      2                 NULL          0000 0000 0000 0000 0000 0000 1111 1101  
(Number of results = 2)

---    END
```
