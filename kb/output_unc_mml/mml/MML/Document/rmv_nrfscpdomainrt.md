# 删除SCP Domain最长匹配后缀转发路由（RMV NRFSCPDOMAINRT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于删除基于SCP Domain的最长匹配后缀转发路由。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称         | 参数说明                                                                                                                                                                                 |
|:----------------|:-------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SCPDOMAINSUFFIX | SCP Domain后缀 | 可选必选说明：必选参数  参数含义：该参数用于表示SCP Domain后缀。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~255。  默认值：无  配置原则：无                                                                                           |
| NEXTNRFGRPNAME  | 归属NRF组名称     | 可选必选说明：必选参数  参数含义：该参数用于表示当前NRF基于SCP domain的最长后缀匹配寻址NF时的下一跳NRF实例组名称，即被寻址的NF归属于该NRF实例组。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~64。  默认值：无  配置原则：  该参数已通过ADD NRFGROUP配置，可通过LST NRFGROUP命令查询获取。 |

## 使用实例

删除一条SCP Domain后缀为32123ASDF，归属NRF组名称为azh0701的最长匹配后缀的转发路由配置，执行如下命令：

```
RMV NRFSCPDOMAINRT: SCPDOMAINSUFFIX="32123ASDF", NEXTNRFGRPNAME="azh0701";
```
