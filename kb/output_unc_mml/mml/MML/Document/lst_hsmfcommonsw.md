# 查询H-SMF通用控制开关（LST HSMFCOMMONSW）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF**

该命令用于查询H-SMF通用控制开关。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询H-SMF通用控制开关：

```
%%LST HSMFCOMMONSW:;%%
RETCODE = 0  操作成功

结果如下
------------------------
服务节点IP地址开关 =  不使能
```

## 输出结果说明

| 输出项名称      | 输出项解释                                  |
|:-----------|:---------------------------------------|
| 服务节点IP地址开关 | 该参数用于控制SEPP组网场景下，N40接口消息是否不携带服务节点IP地址。 |
