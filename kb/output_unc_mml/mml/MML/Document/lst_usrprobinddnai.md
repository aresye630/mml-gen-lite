# 查询用户模板关联的DNAI（LST USRPROBINDDNAI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF、PGW-C、GGSN**

该命令用于查询用户模板关联的DNAI。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                                                                                          |
|:-----------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USRPRONAME | 用户模板名称    | 可选必选说明：可选参数  参数含义：该参数用于指定用户模板名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。  默认值：无  配置原则：  该参数通过ADD USERPROFILE命令配置生成。                |
| DNAI       | 数据网络访问标识符 | 可选必选说明：可选参数  参数含义：该参数用于指定数据网络访问标识符。该参数的数据规划上需要和PNFDNAI命令中的“数据网络访问标识”参数保持一致。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

查询指定用户模板关联的所有DNAI。
2. 查询指定DNAI关联的所有用户模板。

```
LST USRPROBINDDNAI: USRPRONAME="userprofile1";
RETCODE = 0  操作成功

结果如下
--------
       DNAI  =  huawei1.com
```

## 输出结果说明

| 输出项名称     | 输出项解释                                                     |
|:----------|:----------------------------------------------------------|
| 用户模板名称    | 该参数用于指定用户模板名称。                                            |
| 数据网络访问标识符 | 该参数用于指定数据网络访问标识符。该参数的数据规划上需要和PNFDNAI命令中的“数据网络访问标识”参数保持一致。 |
