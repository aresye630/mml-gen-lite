# 删除RRC Inactive生效的TAI范围（RMV RRCINACTTAI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

本命令用于删除RRC Inactive生效的TAI范围。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                            |
|:-------|:--------|:--------------------------------------------------------------------------------------------------------------------------------|
| MCC    | MCC     | 可选必选说明：必选参数  参数含义：该参数用于指定移动国家代码。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                  |
| MNC    | MNC     | 可选必选说明：必选参数  参数含义：该参数用于指定移动网号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                |
| BGNTAC | 跟踪区起始编码 | 可选必选说明：必选参数  参数含义：该参数用于表示跟踪区编码的起始值。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。TAC编码为16进制数，只能由数字（0-9），字母（A-F、a-f）组成。字母大小写不敏感。  默认值：无  配置原则：无 |

## 使用实例

删除一条RRC Inactive生效的TAI范围，MCC为“123”，MNC为“00”，“跟踪区编码起始值”为“000112”，执行如下命令：

```
RMV RRCINACTTAI: MCC="123", MNC="00", BGNTAC="000112";
```
