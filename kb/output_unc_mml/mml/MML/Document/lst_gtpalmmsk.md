# 查询GTP路径断告警屏蔽记录(LST GTPALMMSK)

- 命令功能

- 本地用户权限

#### 命令功能

**适用网元：SGSN、MME**

该命令用于查看需要屏蔽的GTP路径断告警配置。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称          | 参数说明                                                                                                                                                                                                            |
|:----------|:--------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CFGTP     | 配置类型          | 可选必选说明：可选参数 参数含义：该参数用于指示配置屏蔽GTP路径告警的类型。 取值范围：“IPMASK(IP+掩码)”“SENDIP(起始IP+终止IP)”“IPV6MASK(IPv6+前缀)”“SENDIPV6(起始IPv6+终止IPv6)” 默认值：无                                                                               |
| IPV4ADDR  | 起始对端设备IP地址    | 可选必选说明：可选参数 参数含义：该参数用于指示对端设备起始IPv4地址。 前提条件：在“CFGTP”配置为“IPMASK(IP+掩码)”和“SENDIP(起始IP+终止IP)”时，才需要配置本参数 数据来源：整网规划 数据来源：整网规划 取值范围：0.0.0.0~255.255.255.255 默认值：无                                                      |
| EIPV4ADDR | 终止对端设备IP地址    | 可选必选说明：可选参数 参数含义：该参数用于指示对端设备终止IPv4地址。 前提条件：只有在“CFGTP”配置为“SENDIP(起始IP+终止IP)”时，才需要配置该类型的IP地址。 数据来源：整网规划 取值范围：0.0.0.0~255.255.255.255 默认值：无  说明： 本参数的取值应该大于等于“起始对端设备IP地址”的取值。                                      |
| MASKV4    | 掩码            | 可选必选说明：可选参数 参数含义：该参数用于指示对端设备的IPv4地址的掩码。 前提条件：只有在“CFGTP”配置为“IPMASK(IP+掩码)”时，才需要配置本参数。 取值范围：0.0.0.0~255.255.255.255 默认值：无                                                                                         |
| IPV6ADDR  | 起始对端设备IPv6地址  | 可选必选说明：可选参数 参数含义：该参数用于指示对端设备起始IPv6地址。 前提条件：在“CFGTP”配置为“IPV6MASK(IPv6+前缀)”和“SENDIPV6(起始IPv6+终止IPv6)”时，才需要配置本参数。 数据来源：整网规划 取值范围：::-FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无                                  |
| EIPV6ADDR | 终止对端设备IPv6地址  | 可选必选说明：可选参数 参数含义：该参数用于指示对端设备终止IPv6地址。 前提条件：只有在“CFGTP”配置为“SENDIPV6(起始IPv6+终止IPv6)”时，才需要配置本参数。 数据来源：整网规划 取值范围：0:0:0:0:0:0:0:0 ~ FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无  说明： 本参数的取值应该大于等于“起始对端设备IPv6地址”的取值。 |
| PRELEN    | 前缀长度          | 可选必选说明：可选参数 参数含义：该参数用于指示对端设备的IPv6地址的前缀长度。 前提条件：只有在“CFGTP”配置为“IPV6MASK(IPv6+前缀)”时，才需要配置本参数。 数据来源：整网规划 取值范围：0~128 默认值：无                                                                                           |
| SCRALM    | 屏蔽GTP路径告警控制开关 | 可选必选说明：可选参数 参数含义：该参数用于指定屏蔽GTP路径告警开关。 取值范围： “ON(启用)”：启用屏蔽GTP路径告警。“OFF(关闭)”：关闭屏蔽GTP路径告警。 默认值：无                                                                                                                    |

#### 使用实例

查询表项记录：

LST GTPALMMSK:;

```
%%LST GTPALMMSK:;%%
RETCODE = 0  执行成功。

输出结果如下
-------------------------
配置类型            起始对端设备IP地址    终止对端设备IP地址   掩码            屏蔽GTP路径告警控制开关

IP+掩码             192.168.5.5           192.168.5.255        255.255.255.0   启用          
起始IP+终止IP       192.168.5.5           192.168.0.0          0.0.0.0         关闭         
(结果个数 = 2)
---    END
```
