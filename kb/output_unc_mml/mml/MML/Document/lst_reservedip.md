#### 命令功能

**适用NF：NCG**

该命令用于查询预留IP资源的详细信息：

如果需要查询全部信息，请不要输入任何参数。

如果需要查询某方面的详细信息，请输入具体参数。例如，查询用于话单分发的预留IP资源的详细信息，请输入“预留IP资源用途”值为“Bi”。

#### 注意事项

- 无。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                   |
|:-----------|:---------|:-----------------------------------------------------------------------------------------------------------------------|
| IPRID      | 预留IP资源标识 | 可选必选说明：可选参数 参数含义：用于表示一个预留IP资源对象，全局唯一。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：无                                   |
| IPV4       | IPv4地址   | 可选必选说明：条件必选参数 参数含义：用于话单接收的IPv4地址。 数据来源：本端规划 取值范围：IPv4地址类型，0.0.0.0-255.255.255.255。 默认值：无 配置原则：无                        |
| IPV6       | IPv6地址   | 可选必选说明：可选参数 参数含义：用于话单接收的IPv6地址。 数据来源：本端规划 取值范围：IPv6地址类型。::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。 默认值：无 配置原则：无       |
| IPRPURPOSE | 预留IP资源用途 | 可选必选说明：可选参数 参数含义：预留IP资源用途。 数据来源：本端规划 取值范围：枚举类型。 Bi：BiOmi：OmiOmiAndBi：Omi&Bi 默认值：无 配置原则：无                               |
| PRFNAME    | 格式引擎包名   | 可选必选说明：可选参数 参数含义：格式引擎包定义了CG话单处理的业务规则，主要包括话单字段过滤配置、分拣条件配置、通道配置、话单处理脚本等。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～255。 默认值：无 配置原则：无 |
| MNAME      | 模块名称     | 可选必选说明：可选参数 参数含义：预留IP资源对应的模块。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～255。 默认值：无 配置原则：无                                          |
| RUID       | RU的ID    | 可选必选说明：可选参数 参数含义：RU的ID。 数据来源：本端规划 取值范围：整数类型，取值范围为64～4294967294。 默认值：无 配置原则：该值需要执行LST SERVICERUSTATE命令，查询出存在的RU ID进行填写。 |
| VPNNAME    | 虚拟网络名称   | 可选必选说明：可选参数 参数含义：该参数为VPN名称，是业务消息转发时的鉴权参数。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无                               |

#### 使用实例

查询预留IP资源，示例如下：

```
LST RESERVEDIP:;
```
