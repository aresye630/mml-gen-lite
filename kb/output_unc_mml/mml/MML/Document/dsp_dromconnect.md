# 显示OM控制通道状态（DSP DROMCONNECT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示OM控制通道状态。

## 注意事项

该命令适用于支持热备或冷备容灾的网元执行。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                    |
|:----------|:-------|:------------------------------------------------------------------------------------------------------------------------|
| DRGROUPID | 容灾组标识  | 可选必选说明：可选参数  参数含义：该参数用于指定容灾组标识。  数据来源：全网规划  取值范围：整数类型，取值范围是1~8。  默认值：无  配置原则：  可通过LST DRGROUPINFO命令获取返回结果中的容灾组标识作为参数输入。 |

## 使用实例

显示OM控制通道状态。

```
%%DSP DROMCONNECT:;%%
RETCODE = 0  操作成功

结果如下
--------
容灾组标识  =  1
OM链路状态  =  主备容灾实例之间连接成功
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                                          |
|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| 容灾组标识   | 该参数用于指定容灾组标识。                                                                                                                                  |
| OM链路状态  | 该参数用于表示OM链路状态。 取值说明： “NULL（未使能容灾功能或初始态，其状态无效）”：未使能容灾功能或初始态，其状态无效。“CONNECTED（主备容灾实例之间连接成功）”：主备容灾实例之间连接成功。“DISCONNECTED（主备容灾实例之间断连）”：主备容灾实例之间断连。 |
