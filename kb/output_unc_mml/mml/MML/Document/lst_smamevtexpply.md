# 查询SMF向AMF下发事件订阅时的老化策略（LST SMAMEVTEXPPLY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF**

该命令用于查询SMF向AMF下发事件订阅时的老化策略。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询SMF向AMF下发事件订阅时的老化策略：

```
%%LST SMAMEVTEXPPLY:;%%
RETCODE = 0  操作成功

结果如下
------------------------
 下发老化时间开关 =  使能
老化时间时长(min) =  1440
```

## 输出结果说明

| 输出项名称       | 输出项解释                               |
|:------------|:------------------------------------|
| 下发老化时间开关    | 该参数用于指定SMF向AMF下发事件订阅时，请求消息是否携带老化时间。 |
| 老化时间时长（min） | 该参数用于指定SMF向AMF下发事件订阅时携带老化时间的时长。     |
