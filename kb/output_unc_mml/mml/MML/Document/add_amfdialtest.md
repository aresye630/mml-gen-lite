# 增加AMF拨测用户配置（ADD AMFDIALTEST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：MME、AMF**

该命令用于新增拨测用户列表，通过起始IMSI和终止IMSI的方式，配置一组拨测用户。

## 注意事项

- 该命令执行后只对新激活用户生效。

- 该命令的匹配拨测用户的方式为全匹配，不支持IMSI前缀匹配。
- 该命令每条记录配置的拨测用户数不大于100。
- 起始IMSI和终止IMSI必须等长。
- 终止IMSI取值应大于等于起始IMSI。
- 该命令功能只在灰度升级期间生效。

- 最多可输入80条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                      |
|:----------|:-------|:--------------------------------------------------------------------------------------------------------------------------|
| BEGINIMSI | 起始IMSI | 可选必选说明：必选参数  参数含义：该参数用于配置拨测用户的起始IMSI。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是14~15。只允许输入十进制数字（0-9）。不同记录的起始IMSI不能相同。  默认值：无  配置原则：无 |
| ENDIMSI   | 终止IMSI | 可选必选说明：必选参数  参数含义：该参数用于配置拨测用户的终止IMSI。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是14~15。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                 |

## 使用实例

增加一条拨测用户配置，用户标识类型为IMSI，待拨测用户IMSI长度为15位，用户范围为460001111111111~460001111111122，执行如下命令：

```
ADD AMFDIALTEST: BEGINIMSI="460001111111111", ENDIMSI="460001111111122";
```
