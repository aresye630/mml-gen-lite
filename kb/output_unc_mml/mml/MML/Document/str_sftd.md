#### 命令功能

**适用网元：SGSN、MME**

该命令为专家维护命令，用于向主机发送软件调试命令。

#### 注意事项

- 该命令执行可能造成业务受损，需要慎重使用，必须在华为技术支持人员的指导下操作。
- 该命令执行须确保软调名称和参数输入准确，否则不会出现错误提示。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                |
|:--------------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SOFTDEBUGNAME | 软调命令名字  | 可选必选说明：必选参数 参数含义：该参数用于指定软件调试名称。 取值范围：1~31位字符串 默认值：无 配置原则：如果输入软件调试名称为GetRunTime，则会将进程的编译时间和运行时间记录到日志(目录为：/opt/USN_VNFC/*/*/vrpv8/logfile/)中。如果输入其他软件调试名称，则不会记录日志，不会对系统产生影响。                                                                                                                                                                                                                          |
| RUNAME        | RU名称    | 可选必选说明：可选参数 参数含义：该参数用于指定软件调试Ru的名称。 数据来源：该参数可以通过DSP RU命令查询获取。 取值范围：1~63位字符串 默认值：无 配置原则：如果输入RU名称，则对相应RU执行该软调命令。如果不输入该参数，则默认对所有RU执行该软调命令。                                                                                                                                                                                                                                                              |
| PROCESSTYPE   | 进程类型    | 可选必选说明：可选参数 参数含义：该参数用于指定软件调试进程类型。 数据来源：该参数可以通过DSP PROCESSGB、DSP PROCESSLINK或DSP PROCESSUSN命令查询获取。 取值范围： “SPP（SPP）”：表示在SPP进程上执行软调函数。“SGP（SGP）”：表示在SGP进程上执行软调函数。“GBP（GBP）”：表示在GBP进程上执行软调函数。“LCP（LCP）”：表示在LCP进程上执行软调函数。“UPP（UPP）”：表示在UPP进程上执行软调函数。“CDP（CDP）”：表示在CDP进程上执行软调函数。“OMP（OMP）”：表示在OMP进程上执行软调函数。“HSP（HSP）”：表示在HSP进程上执行软调函数。 默认值：无 配置原则：如果输入进程类型，则只对输入类型的进程执行该软调命令。如果不输入该参数，则默认对所有类型的进程执行该软调命令。 |

| PARAM1        | 参数1     | 可选必选说明：可选参数 参数含义：该参数用于指定软件调试函数的第一个参数。 取值范围：1~63位字符串 默认值：无                                                                                                                                                                                                                                                                                                                                           |
| PARAM2        | 参数2     | 可选必选说明：可选参数 参数含义：该参数用于指定软件调试函数的第二个参数。 取值范围：1~63位字符串 默认值：无                                                                                                                                                                                                                                                                                                                                           |
| PARAM3        | 参数3     | 可选必选说明：可选参数 参数含义：该参数用于指定软件调试函数的第三个参数。 取值范围：1~63位字符串 默认值：无                                                                                                                                                                                                                                                                                                                                           |
| PARAM4        | 参数4     | 可选必选说明：可选参数 参数含义：该参数用于指定软件调试函数的第四个参数。 取值范围：1~63位字符串 默认值：无                                                                                                                                                                                                                                                                                                                                           |
| SERVICETYPE   | 服务名称    | 可选必选说明：必选参数 参数含义：本参数用于指定服务名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。数字“0~9”，大写字母“A~Z”，小写字母“a~z”，特殊字符“-”，“_”，其他均为非法字符，并且首字符必须为字母。 默认值：无  说明： 该参数可以通过LST VNFC命令查询得到。                                                                                                                                                                                                                                       |

#### 使用实例

目前可执行的软调函数：

- 查看进程编译时间以及运行时间：

  当需要查看进程的编译和运行时间时可以使用该软调命令。执行后查询结果将打印到使用USN\_VNFC插件的网元的诊断日志(目录为：/opt/USN\_VNFC/\*/\*/vrpv8/logfile/)中。

  该软调函数入参说明：
  - “软件调试名称”固定为GetRunTime。
  - “Ru名称”为RU名称，可以通过**DSP RU**命令查询获取。
  - “进程类型”为进程类型，可以通过**DSP PROCESSGB、****DSP PROCESSLINK或DSP PROCESSUSN**命令查询获取。
  - “进程号”为进程号，可以通过**DSP PROCESSGB、****DSP PROCESSLINK或DSP PROCESSUSN**命令查询获取。
  - “参数1”、“参数2”、“参数3”、“参数4”为空。

  以查看OMP进程的运行时间举例：`STR SFTD:SOFTDEBUGNAME="GetRunTime",RUNAME="USN_OM_RU_0001",PROCESSTYPE=OMP,PROCESSNO=0,SERVICETYPE="USN_VNFC";`
