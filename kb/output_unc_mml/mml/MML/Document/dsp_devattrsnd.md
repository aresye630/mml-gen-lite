# 显示VNFC同步到VNFP的属性信息（DSP DEVATTRSND）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示VNFC同步到VNFP的属性信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称    | 参数说明                                                                                                         |
|:----------------|:--------|:-------------------------------------------------------------------------------------------------------------|
| VNFCID          | VNFC ID | 可选必选说明：可选参数 参数含义：该参数表示VNFC的ID。 数据来源：本端规划 取值范围：十六进制整数类型，取值范围为0x0～0xFFFFFFFF。 默认值：无                            |
| SERVICEINSTANCE | 服务实例    | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |
