# 查询日志自动备份策略（LST AUTOLOGPOLICY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询已创建的日志自动备份策略。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询系统当前的日志自动备份策略信息：

```
%%LST AUTOLOGPOLICY:;%%
RETCODE = 0  操作成功
 
操作结果如下
------------
    备份周期(分)  =  30
SFTP服务器IP类型  =  IPV4
SFTP服务器IP地址  =  10.0.0.0
      SFTP用户名  =  root
        目标目录  =  /opt/test
        日志类型  =  操作日志&安全日志&系统日志
(结果个数 = 1)
 
---    END
```

```
%%LST AUTOLOGPOLICY:;%%
RETCODE = 0  操作成功

没有查到相应结果
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET AUTOLOGPOLICY**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释   | 原因分析    | 处理建议       |
|-------:|:--------|:--------|:-----------|
| 101108 | 系统内部错误  | 系统内部错误。 | 请联系华为技术支持。 |
