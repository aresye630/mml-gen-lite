# 查询故障链路探测配置(LST FAULTLNKDETCFG)

- 命令功能
- 注意事项
- 本地用户权限

- 参数说明

- 输出结果说明

#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询故障链路探测功能配置。

#### 注意事项

无

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询故障链路探测配置：

LST FAULTLNKDETCFG:;

```
%%LST FAULTLNKDETCFG:;%%
RETCODE = 0  操作成功

操作结果如下
------------------
 控制开关  =  关
(结果个数 = 1)

---    END
```

#### 输出结果说明

请参考命令**SET FAULTLNKDETCFG**的参数标识。
