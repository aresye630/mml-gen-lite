# 清除NSSF局向内统概要数据（CLR NSSFIPSTAT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NSSF**

该命令用于清除NSSF局向内统概要数据。

## 注意事项

- 该命令执行后立即生效。

- 如果只清理特定IP的局向内统数据，必须指定IP，如果不指定，则会清理所有局向内统数据。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                  |
|:--------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------|
| IPADDRESSTYPE | IP类型   | 可选必选说明：可选参数  参数含义：该参数用于指定需清除的局向内统对应对端NF的客户端IP类型。不指定该参数时表示清除所有局向内统数据。  数据来源：本端规划 取值范围： IPTypeV4（IPV4类型）IPTypeV6（IPV6类型）  默认值：无  配置原则：无 |
| IPV4ADDRESS   | IPV4地址 | 可选必选说明：该参数在"IPADDRESSTYPE"配置为"IPTypeV4"时为条件必选参数。  参数含义：该参数用于指定对端NF的客户端IPv4地址。  数据来源：本端规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无               |
| IPV6ADDRESS   | IPV6地址 | 可选必选说明：该参数在"IPADDRESSTYPE"配置为"IPTypeV6"时为条件必选参数。  参数含义：该参数用于指定对端NF的客户端IPv6地址。  数据来源：本端规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无               |

## 使用实例

- 将IP为10.10.10.10的NF对应的局向内统数据清零：

  ```
  CLR NSSFIPSTAT:IPADDRESSTYPE=IPTypeV4,IPV4ADDRESS="10.10.10.10";
  ```
- 将所有局向内统数据清零：

  ```
  CLR NSSFIPSTAT:;
  ```
