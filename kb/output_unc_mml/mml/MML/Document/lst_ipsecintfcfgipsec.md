# 查询IPsec隧道接口（LST IPSECINTFCFGIPSEC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询IPsec隧道。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                        |
|:--------------|:-------|:----------------------------------------------------------------------------|
| INTERFACENAME | 接口名称   | 可选必选说明：可选参数  参数含义：配置接口名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。  默认值：无  配置原则：无 |

## 使用实例

查询接口名为“LoopBack4”的安全隧道：

```
LST IPSECINTFCFGIPSEC:INTERFACENAME=""LoopBack4"";
RETCODE = 0  操作成功

结果如下
-------------------------
        接口名称  =  LoopBack4
Tunnel口协议类型  =  IPv4IP安全
        策略名称  =  NULL
      源接口名称  =  NULL
(结果个数 = 1)
---    END
```

## 输出结果说明

| 输出项名称       | 输出项解释        |
|:------------|:-------------|
| 接口名称        | 配置接口名。       |
| Tunnel口协议类型 | Tunnel口协议类型。 |
| 策略名称        | 配置策略名。       |
| 源接口名称       | 地址借用接口名称。    |
