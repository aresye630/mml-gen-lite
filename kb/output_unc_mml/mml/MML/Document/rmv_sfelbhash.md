# 删除IP转发负载分担hash计算模式（RMV SFELBHASH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除IP转发负载分担hash计算模式。

#### 注意事项

- 该命令执行后立即生效。
- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。
- 该命令仅支持发往Fabric口方向的报文做负载分担hash。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                    |
|:--------|:-------|:----------------------------------------------------------------------------------------|
| PKTTYPE | 报文类型   | 可选必选说明：必选参数 参数含义：该参数用于表示负载分担hash模式的报文类型。 数据来源：本端规划 取值范围：枚举类型。 IP：IP报文做负载分担hash计算。 默认值：无 |

#### 使用实例

删除负载分担hash计算模式：

```
RMV SFELBHASH: PKTTYPE=IP;
```
