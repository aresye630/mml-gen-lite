# 修改基于APN的反向分流功能配置（MOD APNREVERSESHUNT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于修改指定APN的反向分流功能。

## 注意事项

该命令执行后只对新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                                               |
|:-------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN          | APN名称  | 可选必选说明：必选参数  参数含义：该参数用于指示APN名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“ ” ”、“ ` ”特殊字符，不区分大小写。  默认值：无  配置原则：  该参数必须已经通过命令ADD APN配置。 |
| REVERSESHUNT | 反向分流开关 | 可选必选说明：可选参数  参数含义：该参数用于控制开启和关闭基于APN的反向分流功能。当开启反向分流功能时，在ULCL/BP场景下，当UE离开MEC园区时，MEC业务从主锚点UPF出到Local DN，Internet业务从辅锚点UPF出到DN。当UE在MEC园区时，MEC业务仍然从辅锚点UPF出到Local DN，Internet业务从主锚点UPF出到DN。  数据来源：全网规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无  配置原则：无       |

## 使用实例

修改“APN名称”为"HUAWEI.COM"的反向分流功能:

```
MOD APNREVERSESHUNT: APN="HUAWEI.COM", REVERSESHUNT=ENABLE;
```
