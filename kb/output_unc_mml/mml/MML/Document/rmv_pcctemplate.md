# 删除PCC模板（RMV PCCTEMPLATE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于删除一个PCC模板配置。

#### 注意事项

该命令执行后只对新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                         |
|:------------|:--------|:-------------------------------------------------------------------------------------------------------------|
| PCCTEMPNAME | PCC模板名称 | 可选必选说明：必选参数 参数含义：该参数用于指定PCC模板的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写，不允许命名为“global”。 默认值：无 配置原则：无 |

#### 使用实例

因业务变更，APN下不再需要PCC功能，则可以删除已经配置的PCC模板：

```
RMV PCCTEMPLATE: PCCTEMPNAME="new_pcc_template";
```
