# 查询M-CDR计费配置(LST CHGMCDRCFG)

- 命令功能
- 注意事项

- 输出结果说明

#### 命令功能

**适用网元：SGSN**

本命令用于查询对特定PLMN用户生成M-CDR的配置。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                               |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：可选参数 参数含义：该参数用于指定所包含的用户范围。 数据来源：整网规划 取值范围： “PLMNID（指定PLMNID）” 默认值：无                                         |
| MCC      | 移动国家码  | 可选必选说明：条件可选参数 参数含义：该参数用于表示PLMN的移动国家号码。 前提条件：该参数在“用户范围”参数设置为“PLMNID（指定PLMNID）”时生效。 数据来源：整网规划 取值范围：位数为3的十进制数字 默认值：无  |
| MNC      | 移动网号   | 可选必选说明：条件可选参数 参数含义：该参数用于表示PLMN的移动网号码。 前提条件：该参数在“用户范围”参数设置为“PLMNID（指定PLMNID）”时生效。 数据来源：整网规划 取值范围：位数为2或3的十进制数字 默认值：无 |

#### 使用实例

查询对特定PLMN用户生成M-CDR的配置。

```
%%LST CHGMCDRCFG:;%% 
RETCODE = 0  操作成功 
操作结果如下 
------------------------ 
用户范围  移动国家码  移动网号    
PLMNID           460        03                    
PLMNID           460        04                   
(结果个数 = 2)  
---    END
```
