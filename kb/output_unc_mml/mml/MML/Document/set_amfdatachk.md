# 设置AMF数据核查相关参数（SET AMFDATACHK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于设置AMF数据核查相关参数。通过此命令AMF可以对存储的数据进行一致性校验。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| DATATYPE            | CHECKSW   |   INTERVAL |   SCANNUM |
|:--------------------|:----------|-----------:|----------:|
| UESR_INDEX_WITH_CTX | ON        |          1 |         1 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                     |
|:---------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DATATYPE | 数据类型      | 可选必选说明：必选参数  参数含义：该参数用于设置AMF待核查的数据类型。  数据来源：本端规划 取值范围： “UESR_INDEX_WITH_CTX（用户索引表与用户上下文表）”：核查用户索引表与用户上下文表数据的一致性  默认值：无。  配置原则：无                                                                                                                                                                                                                                                                                          |
| CHECKSW  | 核查开关      | 可选必选说明：可选参数  参数含义：该参数用于表示AMF数据一致性核查功能开关。当该开关打开时，AMF进行数据一致性核查，当该开关关闭时，AMF不进行数据一致性核查。  数据来源：本端规划 取值范围： “OFF（关闭）”：关闭“ON（打开）”：打开  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST AMFDATACHK查询当前参数配置值。  配置原则：无                                                                                                                                                                                                                       |
| INTERVAL | 扫描时间间隔(秒) | 可选必选说明：该参数在"CHECKSW"配置为"ON"时为条件可选参数。  参数含义：该参数用于表示AMF对用户扫描的时间间隔。  数据来源：本端规划  取值范围：整数类型，取值范围是1~600，单位是秒。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST AMFDATACHK查询当前参数配置值。  配置原则：无                                                                                                                                                                                                                                            |
| SCANNUM  | 扫描数量(个)   | 可选必选说明：该参数在"CHECKSW"配置为"ON"时为条件可选参数。  参数含义：该参数用于表示每个DS每间隔INTERVAL设置的时间扫描多少个用户，扫描到后对用户数据进行一致性核查处理。  数据来源：本端规划  取值范围：整数类型，取值范围是1~20，单位是个。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST AMFDATACHK查询当前参数配置值。  配置原则：  该参数值设置过大会导致系统负载过高，设置前请联系华为技术支持。  DS个数 × (扫描数量 / 扫描时间间隔) = 整系统扫描速率。  DS个数来源于如下命令输出结果中记录个数：  DSP FRAMEDBG: DBGSTR="UeamCtrlSvc coordinator all";  如果结果没有分批显示，则记录个数为回显中“结果个数”字段的值减1；如果结果分批显示，则记录个数为最终的结果个数减1。 |

## 使用实例

将AMF用户索引表与用户上下文表核查开关打开，执行如下命令：

```
SET AMFDATACHK: DATATYPE=UESR_INDEX_WITH_CTX, CHECKSW=ON, INTERVAL=1, SCANNUM=1;
```
