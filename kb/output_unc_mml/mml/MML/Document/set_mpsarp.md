# 设置MPS ARP配置(SET MPSARP)

#### 命令功能

**适用网元：MME**

此命令用于设置MPS ARP配置。即通过此命令打开MPS功能，并配置MPS的ARP优先级临界值。优先级高于临界值的用户在MPS功能打开的情况下，将不会被流控接入限制，并且可以在下发寻呼的时候获得较高的寻呼优先级。

#### 注意事项

- 系统初次运行时，会执行系统初始设置值。
- 此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                  |
|:--------|:--------|:--------------------------------------------------------------------------------------|
| MPSFUNC | MPS功能开关 | 可选必选说明：可选参数 参数含义：该参数用于表示MPS功能的开关。 数据来源：运营商规划 取值范围：OFF(关)ON(开) 系统初始设置值：“OFF(关)”。       |
| PRILVL  | 优先级     | 可选必选说明：可选参数 参数含义：该参数用于表示ARP优先级临界值。 数据来源：运营商规划 取值范围：0～15 系统初始设置值：“8”。 配置原则：数值越小，优先级越高。 |

#### 使用实例

设置MPS ARP配置，MPS功能开关为“OFF(关)”，优先级为“8”：

SET MPSARP: MPSFUNC=OFF, PRILVL=8;
