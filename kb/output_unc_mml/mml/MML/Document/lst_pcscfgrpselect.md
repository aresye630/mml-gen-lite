# 查询P-CSCF组选择模式（LST PCSCFGRPSELECT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于查询配置的P-CSCF-GROUP的选择模式。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询P-CSCF-GROUP的选择模式：

```
%%LST PCSCFGRPSELECT:;%%
RETCODE = 0  操作成功

结果如下
----------------
选择模式  =  主备
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                           |
|:--------|:--------------------------------|
| 选择模式    | 该参数用于配置APN或全局绑定的两个P-CSCF组的选择模式。 |
