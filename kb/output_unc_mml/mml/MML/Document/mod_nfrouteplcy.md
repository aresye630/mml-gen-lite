# 修改NF路由策略（MOD NFROUTEPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、AMF、SMSF、NCG、NSSF、CBC、CBCF**

该命令用于修改对端NF路由策略。

## 注意事项

- 该命令执行后立即生效。

- 对于Model A、Model B和Model C模式，此命令优先级高于SET SCPFUNCSW。
- 此命令对于Model D模式不生效。
- 该命令不支持国际漫游场景跨PLMN的NF之间的路由配置。
- 当配置使用Model C模式时，如果“SCPGROUP”为无效值，则会使用ADD PNFPROFILE里配置的未绑定ADD SCPBINDGRP中组号的SCP。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称                        | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
|:-------------|:----------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INDEX        | 索引                          | 可选必选说明：必选参数  参数含义：该参数用于指定索引。  数据来源：全网规划  取值范围：整数类型，取值范围是0~65535。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ROUTEPLCY    | 路由策略                        | 可选必选说明：必选参数  参数含义：该参数用于指定到对端NF的路由策略。  数据来源：全网规划 取值范围： “DIRECT（直连通信）”：通过直连通信“SCP（通过SCP通信）”：通过SCP Model C间接路由通信  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                      |
| SCPGROUP     | SCP组号                       | 可选必选说明：该参数在"ROUTEPLCY"配置为"SCP"时为条件可选参数。  参数含义：该参数用于指定SCP组号。该参数已经通过ADD SCPBINDGRP命令中的GROUPID参数配置。  数据来源：本端规划  取值范围：整数类型，取值范围是0，66~128。  默认值：无  配置原则：  该参数来源于ADD SCPBINDGRP命令中的GROUPID参数。该参数可以通过LST SCPBINDGRP查询。                                                                                                                                                                                                                                                                                                                   |
| TRGAPIPLCY   | 3gpp-sbi-Target-apiroot填写策略 | 可选必选说明：该参数在"ROUTEPLCY"配置为"SCP"时为条件可选参数。  参数含义：该参数用于指定通过SCP Model C间接路由通信时，3gpp-sbi-Target-apiroot的填写策略。  数据来源：本端规划 取值范围： USE_IP_FIRST（优先填写IP）USE_FQDN_FIRST（优先使用FQDN）  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                              |
| DIALTESTMODE | 拨测模式                        | 可选必选说明：该参数在"ROUTEPLCY"配置为"SCP"时为条件可选参数。  参数含义：该参数用于指定通过SCP Model C间接路由通信时的拨测模式。  数据来源：本端规划 取值范围： “INHERIT（继承）”：继承SCPFUNCSW拨测开关，若SET SCPFUNCSW开启SCP Model C拨测，当用户不属于拨测号段，直接走直连（忽略ADD NFROUTEPLCY配置的路由策略）；当用户属于拨测号段，ADD NFROUTEPLCY配置的路由策略为SCP Model C时，开启SCP Model C拨测，否则使用直连路由策略。“FORCE_OFF（强制关闭）”：无论SET SCPFUNCSW是否开启SCP Model C拨测，匹配到ADD NFROUTEPLCY配置为SCP Model C时，使用SCP Model C路由策略。“FORCE_ON（强制开启）”：无论SET SCPFUNCSW是否开启SCP Model C拨测，拨测用户匹配到ADD NFROUTEPLCY时开启SCP Model C拨测，非拨测用户匹配到ADD NFROUTEPLCY时使用直连路由策略。  默认值：无  配置原则：无 |

## 使用实例

修改到对端NF的路由策略，索引为1，路由策略改为直连。

```
MOD NFROUTEPLCY: INDEX=1, ROUTEPLCY=DIRECT;
```
