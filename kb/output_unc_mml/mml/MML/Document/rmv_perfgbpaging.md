# 删除Gb接口寻呼数据(RMV PERFGBPAGING)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用于删除指定Gb接口寻呼数据。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                                                     |
|:-------|:----------|:---------------------------------------------------------------------------------------------------------|
| LAI    | 寻呼范围位置区标识 | 可选必选说明：必选参数 参数含义：该参数用于指定路由区所在的位置区标识，与RAC共同构成路由区标识。LAI = MNC + MCC + LAC。 数据来源：整网规划 取值范围：9~10位十六进制数 默认值：无 |
| RAC    | 寻呼范围路由区编码 | 可选必选说明：必选参数 参数含义：该参数用于指定路由区在位置区内的标识，与LAI共同构成路由区标识。 数据来源：整网规划 取值范围：0x00~0xFF 默认值：无  说明： RAC是十六进制数，占1个字节。  |

#### 使用实例

删除Gb接口寻呼数据下记录：

RMV PERFGBPAGING: LAI="123031111",RAC="08";
