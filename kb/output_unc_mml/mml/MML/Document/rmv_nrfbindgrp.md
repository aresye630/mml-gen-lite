# 删除对端NRF实例组成员（RMV NRFBINDGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于删除对端NRF实例组的成员。

## 注意事项

- 该命令执行后立即生效。

- 主备或双活组网的场景下，如果需要配置此命令，则两个NRF上均需执行此命令，且配置参数一致。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                          |
|:------------|:--------|:----------------------------------------------------------------------------------------------|
| NRFINSTNAME | NRF实例名称 | 可选必选说明：必选参数  参数含义：该参数用于表示对端NRF实例组中NRF实例名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~38。  默认值：无  配置原则：无 |
| GROUPNAME   | 实例组名称   | 可选必选说明：必选参数  参数含义：该参数用于表示对端NRF实例组的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~64。  默认值：无  配置原则：无      |

## 使用实例

当实例组名为nrfgroup001的对端NRF组中，实例名为nrfinstname001的NRF实例不再提供服务时，配置此命令。

```
RMV NRFBINDGRP: NRFINSTNAME="nrfinstname001", GROUPNAME="nrfgroup001";
```
