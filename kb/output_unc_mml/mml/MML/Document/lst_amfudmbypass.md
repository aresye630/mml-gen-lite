# 查询AMF的UDM故障BYPASS功能（LST AMFUDMBYPASS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询AMF的UDM全故障Bypass功能。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询AMF的UDM全故障Bypass功能，执行如下命令：

```
%%LST AMFUDMBYPASS:;%%
RETCODE = 0  操作成功

结果如下
--------
    UDM全故障Bypass开关  =  关闭
 退出Bypass状态恢复动作  =  优雅去注册
    故障探测速率(个/秒)  =  2
       扫描时间间隔(秒)  =  60
        上报异常CHR开关  =  关闭
               部署模式  =  合设
 UDM Bypass自动退出开关  =  打开
       自定义网元状态码  =  NULL
        自定义SCP状态码  =  NULL
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称            | 输出项解释                                                                                                                                                                      |
|:-----------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UDM全故障Bypass开关   | 该参数用于控制开启和关闭UDM全故障Bypass特性。                                                                                                                                                |
| 退出Bypass状态恢复动作   | 该参数用于设置UDM全故障Bypass状态恢复动作。                                                                                                                                                 |
| 故障探测速率(个/秒)      | 该参数用于指定故障探测速率，即每个DS每秒扫描多少个用户，扫描到后对符合条件的用户进行探测。                                                                                                                             |
| 扫描时间间隔(秒)        | 该参数用于表示UDM Bypass后，允许用户连续两次向UDM发试探消息的最小时间间隔。                                                                                                                               |
| 上报异常CHR开关        | 该参数用于设置当用户接入5G成功且进入UDM Bypass的流程（涉及首次注册、切换、服务请求等流程）时，是否上报异常CHR单据。 参数取值： ON：生成异常CHR单据。 OFF：生成正常CHR单据。是否上报单据取决于ADD NGACCCHRPRCTMPL配置。                                        |
| 部署模式             | 该参数用于表示AUSF和UDM的部署模式。 该部署模式与现网UDM和AUSF的实际部署模式无关，仅用于判断当主备AUSF均故障后是否仍需要与UDM进行交互。                                                                                             |
| UDM Bypass自动退出开关 | 该参数用于控制是否开启用户自动退出UDM Bypass状态开关。                                                                                                                                           |
| 自定义网元状态码         | 该参数用于设置AMF标识用户进入UDM Bypass状态时，对端AUSF/UDM返回的自定义网元状态码。 当本参数未设置时，当对端UDM/AUSF返回状态码大于等于500，AMF标识用户进入UDM Bypass状态。 当本参数已设置时，仅在对端UDM/AUSF返回状态码匹配本参数自定义状态码时，AMF标识用户进入UDM Bypass状态。 |
| 自定义SCP状态码        | 该参数用于设置Model D模式下AMF标识用户进入UDM Bypass状态时，对端SCP返回的自定义状态码。 当本参数未设置时，当对端SCP返回状态码大于等于500，AMF标识用户进入UDM Bypass状态。 当本参数已设置时，仅在对端SCP返回状态码匹配本参数自定义状态码时，AMF标识用户进入UDM Bypass状态。        |
