# 查询IPv4地址前缀列表过滤器节点（LST PREFIXFILTERNODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询已配置的前缀过滤器信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                       |
|:-------|:---------|:---------------------------------------------------------------------------|
| NAME   | IP前缀列表名字 | 可选必选说明：可选参数 参数含义：该参数用于指定IP前缀列表名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～169。 默认值：无 |

#### 使用实例

查询前缀过滤器信息：

```
LST PREFIXFILTERNODE:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
    IP前缀列表名字  =  a
  IP前缀列表节点号  =  10
IP前缀列表匹配模式  =  拒绝
            IP地址  =  10.1.1.1
          掩码长度  =  32
        大于或等于  =  NULL
        小于或等于  =  NULL
      是否匹配网络  =  FALSE
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称    | 输出项解释         |
|:---------|:--------------|
| IP前缀列表名字 | 用于指定IP前缀列表名字。 |

其余输出项请参见ADD PREFIXFILTERNODE的参数说明。
