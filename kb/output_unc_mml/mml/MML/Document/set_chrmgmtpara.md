# 设置关键流程CHR上报管理参数（SET CHRMGMTPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、CBC、CBCF**

该命令用于设置关键流程CHR上报管理参数。

## 注意事项

- 该命令执行后立即生效。

- 功能启用时，系统会将产生的CHR单据存储到OMU。当OMU存储的CHR单据过多时，系统会删除部分早期存入的CHR单据。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| RPTFAILPROC             | RPTMECH                                                   |   PROCRPTRATE |   MECHRPTRATE |   DISCSUPRESSTIME |
|:------------------------|:----------------------------------------------------------|--------------:|--------------:|------------------:|
| NfDisc-1&CustomNfDisc-1 | NfCacheUpdate-1&LinkChange-1&RegisterUpdate-1&Subscribe-1 |            10 |            10 |                20 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称           | 参数说明                                                                                                                                                                                                |
|:----------------|:---------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RPTFAILPROC     | 失败时允许上报CHR的流程  | 可选必选说明：可选参数  参数含义：该参数用于指定失败时允许上报CHR的流程。  数据来源：本端规划 取值范围： NfDisc（NF服务发现）CustomNfDisc（定制化服务发现）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CHRMGMTPARA查询当前参数配置值。  配置原则：无                                 |
| RPTMECH         | 允许上报CHR的机制     | 可选必选说明：可选参数  参数含义：该参数用于指定允许上报CHR的机制。  数据来源：本端规划 取值范围： NfCacheUpdate（NF缓存更新）LinkChange（链路变更）RegisterUpdate（注册更新）Subscribe（订阅）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CHRMGMTPARA查询当前参数配置值。  配置原则：无 |
| PROCRPTRATE     | 流程触发的CHR上报速率阈值 | 可选必选说明：可选参数  参数含义：该参数用于指定流程触发的CHR上报速率阈值，用于控制整系统每秒允许上报的，由流程触发的CHR单据个数。  数据来源：本端规划  取值范围：整数类型，取值范围是0~128，单位是个每秒。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CHRMGMTPARA查询当前参数配置值。  配置原则：无               |
| MECHRPTRATE     | 机制触发的CHR上报速率阈值 | 可选必选说明：可选参数  参数含义：该参数用于指定机制触发的CHR上报速率阈值，用于控制整系统每秒允许上报的，由机制触发的CHR单据个数。  数据来源：本端规划  取值范围：整数类型，取值范围是0~128，单位是个每秒。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CHRMGMTPARA查询当前参数配置值。  配置原则：无               |
| DISCSUPRESSTIME | 服务发现上报CHR的抑制时间 | 可选必选说明：可选参数  参数含义：该参数用于指定每个Pod内同种服务发现条件组合的CHR上报抑制时间。  数据来源：本端规划  取值范围：整数类型，取值范围是0~600，单位是秒。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CHRMGMTPARA查询当前参数配置值。  配置原则：无                                  |

## 使用实例

将流程触发的CHR上报速率阈值设置为20。

```
SET CHRMGMTPARA: PROCRPTRATE=20;
```
