# 删除切片性能统计对象（RMV PERFNS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF**

该命令用于手工删除切片性能统计对象的配置。

## 注意事项

- 该命令执行后立即生效。

- 只能删除人工配置的切片性能统计对象，不能删除系统同步产生的切片性能统计对象。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                           |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SNSSAI | 网络切片   | 可选必选说明：必选参数  参数含义：该参数标识切片信息，由切片业务类型和切片细分标识组成。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是8~10。网络切片输入格式为SST-SD。SST输入长度范围是1~3，只允许输入十进制数字（0-9），除0之外不能以0开头，对应十进制数取值范围是0~255；SD输入长度为6，采用十六进制表示，只能由数字（0-9），字母（A-F、a-f）组成，字母大小写不敏感。  默认值：无  配置原则：  网络已支持的切片（ADD PLMNNS配置）会自动添加到PERFNS中，不需要人工配置。执行ADD PERFNS命令时只能配置ADD PLMNNS命令没有配置过的切片。若PERFNS记录数已达到最大规格，则随后执行ADD PLMNNS命令添加的新切片信息不会再自动同步到PERFNS中。 |

## 使用实例

当运营商不需要切片“1-010101”作为性能统计对象时，执行如下命令：

```
RMV PERFNS:SNSSAI="1-010101";
```
