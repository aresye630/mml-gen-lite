# 删除对端NF的TAI范围（RMV PNFTAIRANGE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、NSSF、SMSF、NCG、PGW-C、SGW-C、CBC、CBCF**

该命令用于删除本地配置的对端NF实例支持的TAI范围信息。当删除完一个NFINSTANCEID关联的所有的PNFTAI和PNFTAIRANGE后，该NF将会通配支持所有TAI。

## 注意事项

- 该命令执行后立即生效。

- 当删除一条PNFNSINDEX为0的记录时，必须满足记录中不存在与将删除记录的INDEX和BINDNWDAFINFOID一样且PNFNSINDEX不为0的记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称            | 参数说明                                                                                                                                                          |
|:----------------|:----------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INDEX           | 索引              | 可选必选说明：必选参数  参数含义：该参数用于指定TAI范围对应的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无                                                                  |
| PNFNSINDEX      | 对端NF的切片索引       | 可选必选说明：可选参数  参数含义：该参数用于指定对端NF实例支持以TAIRANGE为条件配置优先级与权重时所关联的切片索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：  当该值配置为空或0时，代表支持所有切片索引。                |
| BINDNWDAFINFOID | 绑定的NWDAFINFO ID | 可选必选说明：可选参数  参数含义：该参数用于指定绑定的PNFNWDAFEVENT记录。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~32。该参数大小写不敏感。  默认值：无  配置原则：  BINDNWDAFINFOID需要与ADD PNFNWDAFEVENT中的NWDAFINFOID一致。 |

## 使用实例

删除对端NF的TAI范围信息。

```
RMV PNFTAIRANGE: INDEX=1;
```
