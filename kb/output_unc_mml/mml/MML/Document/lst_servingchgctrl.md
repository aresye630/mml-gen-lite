# 查询I-SMF/SGW的计费模式和CHF选择参数（LST SERVINGCHGCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、SMF**

该命令用于查询UNC作为I-SMF/SGW时的计费模式和CHF选择参数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询UNC作为I-SMF/SGW时的计费模式和CHF选择参数：

```
%%LST SERVINGCHGCTRL:;%%
RETCODE = 0  操作成功

结果如下
--------
拜访地用户QBC计费开关  =  打开QBC计费功能
归属地用户QBC计费开关  =  打开QBC计费功能
  漫游用户QBC计费开关  =  打开QBC计费功能
        用户主用CHF组  =  CHFGRP1
        用户备用CHF组  =  CHFGRP2
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称        | 输出项解释                           |
|:-------------|:--------------------------------|
| 归属地用户QBC计费开关 | 该参数用于设置I-SMF/SGW上的归属地用户进行QBC计费。 |
| 漫游用户QBC计费开关  | 该参数用于设置I-SMF/SGW上的漫游用户进行QBC计费。  |
| 拜访地用户QBC计费开关 | 该参数用于设置I-SMF/SGW上的拜访地用户进行QBC计费。 |
| 用户主用CHF组     | 该参数用于设置I-SMF/SGW用户主CHF组的名称。     |
| 用户备用CHF组     | 该参数用于设置I-SMF/SGW用户备用CHF组的名称。    |
