# 增加跟踪区域码分组记录（ADD TACGROUPINNSSF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NSSF**

该命令用于将多个跟踪区域码合为一个跟踪区域码分组。

## 注意事项

- 该命令执行后立即生效。

- 跟踪区域码分组中的所有跟踪区域码必须属于同一个PLMN。
- 主备或双活组网的场景下，如果需要配置此命令，则两个NSSF上均需执行此命令，且配置参数一致。
- 最多可输入100000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称      | 参数说明                                                                                                                   |
|:-------------|:----------|:-----------------------------------------------------------------------------------------------------------------------|
| INDEX        | 索引        | 可选必选说明：可选参数  参数含义：该参数用于描述命令的索引值。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无                               |
| TACGROUPNAME | 跟踪区域码分组名称 | 可选必选说明：必选参数  参数含义：该参数用于描述跟踪区代码分组的名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无                               |
| TACSTART     | TAC起始字符   | 可选必选说明：必选参数  参数含义：该参数用于表示TAI路由的TAC起始字符。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是4~6。该参数只能由字母（A-F或者a-f）、数字（0-9）组成。  默认值：无  配置原则：无 |
| TACEND       | TAC结束字符   | 可选必选说明：必选参数  参数含义：该参数用于表示TAI路由的TAC结束字符。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是4~6。该参数只能由字母（A-F或者a-f）、数字（0-9）组成。  默认值：无  配置原则：无 |

## 使用实例

假如运营商希望增加一条索引为1，跟踪区域码分组名称为"TACGROUP01"，TAC起始字符为"010101"，TAC结束字符为"010102"的记录，执行下列命令。

```
ADD TACGROUPINNSSF: INDEX=1, TACGROUPNAME="TACGROUP01", TACSTART="010101", TACEND="010102";
```
