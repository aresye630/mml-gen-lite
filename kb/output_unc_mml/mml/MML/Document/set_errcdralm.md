# 设置错误话单告警参数（SET ERRCDRALM）

- 命令功能

- 本地用户权限

- 使用实例

#### 命令功能

**适用NF：NCG**

该命令用于设置NCG在话单处理过程中对错误话单的监控模式，根据不同的监控模式上报不同的错误话单告警。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始设置记录，参数的初始设置值如下表：

| MONITORMODE   |
|:--------------|
| PERIOD        |

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                                                     |
|:------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MONITORMODE | 监控模式   | 可选必选说明：必选参数 参数含义：用于选择NCG对错误话单的监控模式。 数据来源：本端规划 取值范围：枚举类型。 PERIOD：周期性。REAL-TIME：实时性。 默认值：无 配置原则： “PERIOD(周期性)”：表示NCG每隔5分钟监控一次异常话单的张数，如果5分钟之内异常话单张数超过100张，上报告警“ALM-82019 收到异常话单”。“REAL-TIME(实时性)”：表示NCG实时监控异常话单文件，当产生一个异常的最终话单文件时，上报告警“ALM-82020 发现异常话单文件”。 |

#### 使用实例

设置NCG对错误话单的“监控模式”为“PERIOD(周期性)”：

```
SET ERRCDRALM: MONITORMODE=PERIOD;
```
