# 增加APN智能分流配置 (ADD SMARTAPN)

#### 命令功能

**适用网元：MME**

该命令用于新增会话建立使用APN智能分流配置，智能分流用户使用的APN开启了专用PGW-C选择功能，会话建立时系统会选择专用PGW-C。

#### 注意事项

- 该命令执行后立即生效。
- 本表最大记录数为1024。
- 不配置该命令，智能分流用户会话使用所有的APN默认开启专用PGW-C选择功能。
- 配置该命令后，智能分流用户会话使用的APN是否使用专网以配置命令为准。
- 当BYTE\_EX\_B83 BIt6为“0”时，IMS语音不开启专用PGW-C选择功能。如果通过本命令开通了IMS语音的专用PGW-C选择功能，则本命令的配置优先生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称          | 参数说明                                                                                                                                                                                                                                                |
|:----------|:--------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APNNI     | 智能分流APNNI     | 可选必选说明：必选参数 参数含义：该参数用于指定智能分流的APNNI。 数据来源：全网规划 取值范围：字符串类型，输入长度范围是1~62。 默认值：无 配置原则： 智能分流APNNI由一个或多个LABEL构成，各LABEL间用“.”间隔。每个LABEL的构成字符只能是字母A～Z或a～z、数字0～9和中划线“-”，字母不区分大小写。例如“HUAWEI.COM”。 智能分流APNNI不能以“rac”、“lac”、“sgsn”或“rnc”开头，不能以“.gprs”结尾，不能取值为“*”。 |
| PGWCSELSW | 是否支持专用PGW-C选择 | 可选必选说明：必选参数 参数含义：该参数用于指定智能分流用户会话建立时使用的APN是否支持专用PGW-C选择。 数据来源：全网规划 取值范围： YES(是) NO(否) 默认值：无 配置原则：无                                                                                                                                                   |

#### 使用实例

1. 关闭APN1专用PGW-C选择功能，可以用如下命令：

   ```
   ADD SMARTAPN: APNNI="APN1", PGWCSELSW=NO;
   ```
