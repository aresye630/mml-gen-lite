# 删除本端端点配置(RMV GBIPLOCENDPT)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

该参数用于在Gb OVER IP时删除一个NSE下一个IP地址下的一条或者多条本端端点记录。

#### 注意事项

- 该命令执行立即生效。
- 删除后该本端端点对应的链路也自动删除，业务会切换到其它可用的链路上，对业务无影响，但会增加其它链路的负担，请谨慎操作。
- 如果删除本端最后一个端点之后，再次添加端点可能导致添加的端点不是BSC侧server地址，导致通信中断，请谨慎使用。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                |
|:-------|:---------|:------------------------------------------------------------------------------------------------------------------------------------|
| NSEI   | NSE标识    | 可选必选说明：必选参数 参数含义：该参数用于设置端点所在的网络服务实体标识。 取值范围：0～65535 默认值：无                                                                           |
| IPT    | IP地址类型   | 可选必选说明：必选参数 参数含义：该参数用于设置IP地址类型。 取值范围：“IPV4(IPv4)”“IPV6(IPv6)” 默认值：无                                                                 |
| LIPV4  | 本端IPv4地址 | 可选必选说明：条件必选参数 参数含义：该参数用于设置本端使用的IPv4地址。 前提条件：该参数在“IP地址类型”为“IPV4(IPv4)”时才生效。 取值范围：0.0.0.0～255.255.255.255 默认值：无                       |
| LIPV6  | 本端IPv6地址 | 可选必选说明：条件必选参数 参数含义：该参数用于设置本端PCU使用的IPv6地址。 前提条件：该参数在“IP地址类型”为“IPV6(IPv6)”时才生效。 取值范围：::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 |
| LUP    | 本端UDP端口号 | 可选必选说明：必选参数 参数含义：该参数用于设置本端使用的UDP端口号。 取值范围：1024～65535 默认值：无                                                                          |

#### 使用实例

1. 删除NSE为600的IPv4地址为192.168.2.1、UDP端口为2001的本端端点记录：

   RMV GBIPLOCENDPT: NSEI=600, IPT=IPV4, LIPV4="192.168.2.1", LUP=2001;
