# 删除运营商紧急呼叫功能配置（RMV EMGCFG）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于删除指定MNO/MVNO对应的紧急呼叫配置数据。

#### 注意事项

该命令执行后立即生效。

删除记录会导致此MNO/MVNO下的用户无法使用紧急呼叫业务。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                   |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------|
| NOID   | 运营商标识  | 可选必选说明：必选参数 参数含义：该参数用于指定运营商标识。 数据来源：运营商规划 取值范围： 0～64，128～254 默认值： 无 配置原则：“NOID”指定的记录已经通过ADD EMGCFG配置了。 |

#### 使用实例

删除“运营商标识”为“0”的运营商紧急呼叫功能的配置：

RMV EMGCFG: NOID=0;
