# 激活自定义Action重试次数和超时时长（ACT MODACTIONPOLICY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该操作会影响网元内生命周期任务的子任务（Action）重试次数和超时时长，设置时间过短可能会导致生命周期任务失败。

该命令用于激活（设置）自定义网元内生命周期任务的子任务（Action）重试次数和超时时长。

## 注意事项

- 如果Action所属任务已启动，执行该命令后需重新启动任务才能生效。

- 如果USEDEFAULT参数取值为TRUE，将会使Action的重试次数和超时时长恢复到系统初始设置值。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称          | 参数说明                                                                                                                                  |
|:-----------|:--------------|:--------------------------------------------------------------------------------------------------------------------------------------|
| USEDEFAULT | Action系统初始策略  | 可选必选说明：必选参数  参数含义：网元内生命周期任务的子任务（Action）是否使用系统初始的重试次数和超时时长。  数据来源：本端规划 取值范围： TRUE（是）FALSE（否）  默认值：无  配置原则：无                            |
| ACTIONNAME | Action名称      | 可选必选说明：该参数在"USEDEFAULT"配置为"TRUE"、"FALSE"时为条件必选参数。  参数含义：网元内生命周期任务的子任务（Action）名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~1024。  默认值：无  配置原则：无 |
| TIMEOUT    | Action超时时间（秒） | 可选必选说明：该参数在"USEDEFAULT"配置为"FALSE"时为条件必选参数。  参数含义：网元内生命周期任务的子任务（Action）超时时间。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967。  默认值：无  配置原则：无      |
| RETRY      | Action重试次数    | 可选必选说明：该参数在"USEDEFAULT"配置为"FALSE"时为条件必选参数。  参数含义：网元内生命周期任务的子任务（Action）重试次数。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无   |

## 使用实例

设置某网元内Action的相关配置，其中Action名称为ActionWaitScaleOutManager，超时时间490秒，重试次数2次。

```
%%ACT MODACTIONPOLICY: USEDEFAULT=FALSE, ACTIONNAME="ActionWaitScaleOutManager", TIMEOUT=490, RETRY=2;%%
RETCODE = 0  操作成功

---    END
```
