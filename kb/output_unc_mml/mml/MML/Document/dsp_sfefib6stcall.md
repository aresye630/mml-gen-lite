# 查询IPv6所有的路由表项的统计（DSP SFEFIB6STCALL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询IPv6所有的路由表项的统计。FIB6用于保存报文转发信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                               |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------|
| RUNAME | RU名称   | 可选必选说明：必选参数 参数含义：该参数用于指定资源单元名称，可使用命令DSP RU查询得到。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。区分大小写。 默认值：无 配置原则：使用DSP RU查看RU名称。 |

#### 使用实例

查询IPv6所有的路由表项的统计：

```
DSP SFEFIB6STCALL : RUNAME="VNODE_VNRS_VNFC_IPU_0066";
```

```
RETCODE = 0  操作成功。

结果如下
-------------------------
        路由总数   =  8
    公网路由数量   =  7
  FIB表规格容量   =  1048576
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称    | 输出项解释               |
|:---------|:--------------------|
| 路由总数     | 用于表示公网和私网路由的FIB表总数。 |
| 公网路由数量   | 用于表示公网路由数量。         |
| FIB表规格容量 | 用于表示FIB6表容量。        |
