# 查询BGP对等体条件路由匹配前缀（LST BGPPEERAFPRE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查看条件路由的缺省前缀。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                           |
|:--------------|:--------|:-------------------------------------------------------------------------------|
| VRFNAME       | VPN实例名称 | 可选必选说明：可选参数 参数含义：该参数用于指定VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无       |
| AFTYPE        | 地址族类型   | 可选必选说明：可选参数 参数含义：该参数用于给定VRF的地址族类型。 数据来源：本端规划 取值范围：枚举类型。 ipv4uni：IPv4地址族。 默认值：无 |
| REMOTEADDRESS | 对等体地址   | 可选必选说明：可选参数 参数含义：该参数用于指定路由器对等体的对端地址或地址段。 数据来源：对端协商 取值范围：IPv4地址类型。 默认值：无        |

#### 使用实例

查看条件路由的缺省前缀：

```
LST BGPPEERAFPRE:;
```

```
RETCODE = 0  操作成功。

结果如下
--------
                   VPN实例名称  =  vrf1
                    地址族类型  =  IPv4uni
                    对等体地址  =  10.2.2.2
指定一个缺省路由条件匹配的前缀  =  10.11.11.11
指定一个缺省路由条件匹配的掩码  =  32
(结果个数 = 1)
---    END
```
