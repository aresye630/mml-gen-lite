# 查询告警服务器相关配置信息（LST NCGALMSRV）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NCG**

该命令用于查询告警服务器相关配置信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询告警服务器相关配置信息：

```
LST NCGALMSRV:;
```

| 备用告警服务器IPv4地址    | 该参数用于指定备用告警服务器的IPv4地址。        |
