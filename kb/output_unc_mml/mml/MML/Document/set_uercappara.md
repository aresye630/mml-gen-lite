# 设置UE Radio Capability信元参数（SET UERCAPPARA）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于配置根据UE无线能力的参数，设置告警阈值。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                                                   |
|:----------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
| REPORTALM | 上报告警百分比 | 可选必选说明：可选参数。 参数含义：该参数表示上报ALM-80717 4G UE无线能力处理超出上限告警的百分比。 数据来源：全网规划 取值范围：整数类型，取值范围是1~100。 默认值：95。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过相关查询命令获取当前参数配置值。 配置原则：无 |

#### 使用实例

设置UE Radio Capability信元参数，“上报告警百分比”设置为20；

```
SET UERCAPPARA: REPORTALM=20;
```
