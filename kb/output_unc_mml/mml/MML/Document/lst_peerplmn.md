# 查询对等PLMN配置(LST PEERPLMN)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用网元：SGSN、MME**

此命令用于查询对等PLMN配置记录。

#### 注意事项

此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
|:---------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AREA     | 区域范围   | 可选必选说明：可选参数 参数含义：该参数用于显示指定区域的标识类型的信息。 取值范围：“ALL（所有区域）”：表示该区域标识类型为所有区域。“PLMN（指定PLMN区域）”：表示该区域标识类型为指定PLMN区域。“LA（指定位置区）”：表示该区域标识类型为指定位置区。“RA（指定路由区）”：表示该区域标识类型为指定路由区。“TA（指定跟踪区）”：表示该区域标识类型为指定跟踪区。“AREAGP（区域群）”：表示该区域标识类型为区域群。 默认值：无  说明： 本表“区域范围”为“AREAGP（区域群）”的记录不能与“区域范围”为“PLMN（指定PLMN区域）”、“LA（指定位置区）”、“RA（指定路由区）”或“TA（指定跟踪区）”的记录共存。区域范围按照粒度从粗到细分为以下几个级别： 所有区域，指定PLMN区域，区域群，指定位置区，指定路由区，指定跟踪区。相同粒度区域范围的各记录的区域范围不能交迭。使用时先按照用户IMSI查找记录是否存在，然后按照位置区域查找是否存在对应记录，查找不到再使用较粗的区域粒度进行查找。未配置在该表区域范围中的用户缺省不下发等价PLMN。 |
| MCC      | 移动国家码  | 可选必选说明：条件可选参数 参数含义：该参数用于显示指定移动国家代码的信息。 前提条件：该参数在当“AREA（区域范围）”不为“ALL（所有区域）”和“AREAGP（区域群）”时生效。 取值范围：位数为3的十进制数字 默认值：无                                                                                                                                                                                                                                                                                                                                                                                       |
| MNC      | 移动网号   | 可选必选说明：条件可选参数 参数含义：该参数用于显示指定移动网号的信息。 前提条件：该参数在当“AREA（区域范围）”不为“ALL（所有区域）”和“AREAGP（区域群）”时生效。 取值范围：位数为2或3的十进制数字 默认值： 无                                                                                                                                                                                                                                                                                                                                                                                      |
| LAC      | 位置区域码  | 可选必选说明：条件可选参数 参数含义：该参数用于显示指定位置区域码的信息。 前提条件：该参数在当“AREA（区域范围）”为“LA（指定位置区）”或“RA（指定路由区）”时生效。 取值范围：0x0000~0xFFFF 默认值：无                                                                                                                                                                                                                                                                                                                                                                                        |
| RAC      | 路由区域码  | 可选必选说明：条件可选参数 参数含义：该参数用于显示指定路由区域码的信息。 前提条件：该参数在当“AREA（区域范围）”为“RA（指定路由区）”时生效。 取值范围：0x00~0xFF 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                        |
| TAC      | 跟踪区域码  | 可选必选说明：条件可选参数 参数含义：该参数用于显示指定跟踪区域码的信息。 前提条件：该参数在当“AREA（区域范围）”为“TA（指定跟踪区）”时生效。 取值范围：0x0000~0xFFFF 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                    |
| AREAID   | 区域群标识  | 可选必选说明：条件可选参数 参数含义：该参数用于指定区域群标识。 前提条件：该参数在当“AREA（区域范围）”为“AREAGP（区域群）”时生效。 取值范围：1~50 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                |
| SUBRANGE | 用户范围   | 可选必选说明：可选参数 参数含义：该参数用于指定用户范围。 取值范围：“ALL_USER（所有用户）”“IMSI_PREFIX（指定IMSI前缀）”“IMSI_RANGE（指定IMSI范围）”“SUBGP（用户群）” 默认值：无                                                                                                                                                                                                                                                                                                                                                                                       |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件可选参数 参数含义：该参数用于指定IMSI前缀。使用时按照IMSI最长匹配进行查询。 前提条件：只有“用户范围”为“IMSI_PREFIX（指定IMSI前缀）”时，该参数才有效。 取值范围：1~15位十进制数字字符串 默认值：无                                                                                                                                                                                                                                                                                                                                                                              |
| IMSI     | IMSI   | 可选必选说明：条件可选参数 参数含义：该参数用于指定IMSI。 前提条件：只有“用户范围”为“IMSI_RANGE（指定IMSI范围）”时，该参数才有效。 取值范围：1~15位十进制数字字符串 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                   |
| SUBID    | 用户群标识  | 可选必选说明：条件可选参数 参数含义：该参数用于指定用户群标识 。 前提条件：只有“用户范围”为“SUBGP（用户群）”时，该参数才有效。 取值范围：1~100 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                   |
