# 修改VLR信令点(MOD VLROPC)

- 命令功能
- 注意事项
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SMSF**

该命令用于修改VLR信令点配置。

#### 注意事项

- 该命令执行后立即生效。

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                     |
|:--------|:---------|:-----------------------------------------------------------------------------------------|
| OPX     | VLR信令点索引 | 可选必选说明：必选参数 参数含义：该参数用于指定VLR本局信令点索引。 数据来源：本端规划 取值范围：0~1。 默认值：无                            |
| VLRNAME | 本局VLR名称  | 可选必选说明：可选参数 参数含义：该参数用于指定本局信令点名。该字段需要和MME协商。 数据来源：本端规划 取值范围： 字符串类型，输入长度范围为0~32 默认值：noname |
| SSN     | 子系统号     | 可选必选说明：可选参数 参数含义：该参数用于指定SMSF本局信令点的主用信令点。 数据来源：本端规划 取值范围： “VLR(7)” “MSC(8)” 默认值：VLR(7)    |

#### 使用实例

修改VLR本局信令点，本局信令点索引为1，子系统号为MSC：

```
MOD VLROPC: OPX=1, SSN=MSC;
```
