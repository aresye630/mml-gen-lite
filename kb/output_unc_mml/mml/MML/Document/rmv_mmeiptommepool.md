# 删除MME IP（RMV MMEIPTOMMEPOOL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C**

该命令用于删除MME POOL绑定的地址。假设该MME IP不需要再使用，使用该命令。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                                                                                                                                           |
|:------------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MMEPOOLNAME | MME POOL名称 | 可选必选说明：必选参数  参数含义：该参数用于指定MME POOL名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。不支持空格，不区分大小写。  默认值：无  配置原则：  该参数使用ADD MMEPOOL命令配置生成。                                                                                                   |
| IPVERSION   | IP版本       | 可选必选说明：必选参数  参数含义：该参数用于指定MME地址池的地址类型。  数据来源：本端规划 取值范围： IPV4（IPV4）IPV6（IPV6）IPV4V6（IPV4V6）  默认值：无  配置原则：  仅当“BACKUP”参数配置为TRUE时，该参数可配置为IPV4V6。                                                                                   |
| IPV4ADDRESS | MME的IPv4地址 | 可选必选说明：该参数在"IPVERSION"配置为"IPV4"、"IPV4V6"时为条件必选参数。  参数含义：该参数指定该地址类型为IPv4地址。  数据来源：本端规划  取值范围：IPv4地址类型。  默认值：无  配置原则：  有效的IPv4地址不能为环回地址(127.x.y.z)。  有效的IPv4地址必须是A、B或者C类地址。                                                      |
| IPV6ADDRESS | MME的IPv6地址 | 可选必选说明：该参数在"IPVERSION"配置为"IPV6"、"IPV4V6"时为条件必选参数。  参数含义：该参数指定该地址类型为IPv6地址。  数据来源：本端规划  取值范围：IPv6地址类型。  默认值：无  配置原则：  IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址(::1)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。 |

## 使用实例

假设用户需要删除“mmepool1”下绑定的IPv4地址“10.1.1.1”：

```
RMV MMEIPTOMMEPOOL:MMEPOOLNAME="mmepool1",IPVERSION=IPV4,IPV4ADDRESS="10.1.1.1";
```
