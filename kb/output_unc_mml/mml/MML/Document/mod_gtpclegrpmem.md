# 修改GTP-C本地实体组成员（MOD GTPCLEGRPMEM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C、AMF、GGSN**

该命令用于修改GTP-C本地实体组成员的描述信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GROUPID  | 组号     | 可选必选说明：必选参数  参数含义：该参数用于指定GTP-C本地实体的组号。  数据来源：本端规划  取值范围：整数类型，取值范围是0~31。  默认值：无  配置原则：  该参数需要从ADD GTPCLEGRP命令中已配置的GRPID参数中取值。                                                                                                                        |
| IPTYPE   | IP地址类型 | 可选必选说明：必选参数  参数含义：该参数用于指示GTP-C本地实体的IP地址类型。  数据来源：全网规划 取值范围： IPv4（IPv4）IPv6（IPv6）  默认值：无  配置原则：无                                                                                                                                                     |
| IPV4ADDR | IPv4地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPv4"时为条件必选参数。  参数含义：该参数用于指示GTP-C本地实体的IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：  业务地址不能配置为0.0.0.0、255.255.255.255和环回地址(127.x.y.z)。  业务地址必须是A、B或者C类地址。  IP地址不能与GTPCLE中已配置的IP地址相同。                                      |
| IPV6ADDR | IPv6地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPv6"时为条件必选参数。  参数含义：该参数用于指示GTP-C本地实体的IPv6地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：  IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址(::1)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。  IP地址不能与GTPCLE中已配置的IP地址相同。 |
| DESC     | 描述信息   | 可选必选说明：可选参数  参数含义：该参数用于指示GTP-C本地实体的描述信息。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~32。  默认值：无  配置原则：无                                                                                                                                                         |

## 使用实例

修改组号为0的GTP-C本地实体组成员的描述信息，成员IPv4地址为192.168.1.1。

```
MOD GTPCLEGRPMEM:GROUPID=0,IPTYPE=IPv4,IPV4ADDR="192.168.1.2",DESC="for s5";
```
