#### 命令功能

**适用网元：SGSN**

该命令用于查询3G寻呼信息，在触发3G寻呼时，利用此信息根据RAI定位RNC。系统根据MS原来的路由区是否在3G寻呼表（2G寻呼表）内存在来判定ATTACH、RAU、RELOCATION等流程是Inter-SGSN还是Intra-SGSN。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                 |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------|
| LAI      | 位置区标识  | 可选必选说明：可选参数 参数含义：该参数用于指定本SGSN管辖位置区的标识。 取值范围：9~10位字符串 默认值：无  说明： LAI = MCC + MNC + LAC。MCC由3个阿拉伯数字组成，MNC由2到3个阿拉伯数字组成，LAC是十六进制数，占2个字节。 |
| RAC      | 路由区编码  | 可选必选说明：可选参数 参数含义：该参数用于指定本SGSN管辖路由区的编码。 取值范围：0x00~0xFF 默认值：无  说明： RAC是十六进制数，占1个字节。                                                    |
| RNCINDEX | RNC索引  | 可选必选说明：可选参数 参数含义：该参数用于指定RNC索引，可查询RNC信息表获得。 取值范围：0~511 默认值：无                                                                          |

#### 使用实例

LST IUPAGING:;

