# 删除密码禁用词（RMV PWDBLACKLIST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除密码禁用词。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                      |
|:--------------|:-------|:------------------------------------------------------------------------------------------|
| FORBIDDENWORD | 密码禁用词  | 可选必选说明：必选参数 参数含义：密码禁用词。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～64。不区分大小写。不能包含一些特殊字符，如问号和分号等。 默认值：无 |

#### 使用实例

删除密码禁用词a：

```
RMV PWDBLACKLIST:FORBIDDENWORD="a";
```
