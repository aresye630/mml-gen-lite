# 增加GTP-C接口信息（ADD GTPCINTF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C、AMF、GGSN**

该命令用于增加GTP-C接口信息。

## 注意事项

- 命令执行后只对新接入用户生效。

- 4/5G互操作时如果是with N26场景则需要配置N26接口，如果是without N26场景则不需要配置N26接口。
- SGW-C/PGW-C合一场景下，S5-S和S5-P/Gn接口的配置都需要配置。
- S5-S和S8-S接口的组号允许相同。S5-P/Gn和S8-P/Gp接口的组号允许相同。其余接口的组号皆不允许相同。
- 同一接口类型只能配置一个组号。

- 最多可输入7条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                             |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INTFTYPE | 接口类型   | 可选必选说明：必选参数  参数含义：该参数用于指定GTP-C接口类型。  数据来源：全网规划 取值范围： E_GTPCINTF_ITFS11（S11接口）E_GTPCINTF_ITFN26（N26接口）E_GTPCINTF_ITFS5_S（S5-S接口）E_GTPCINTF_ITFS8_S（S8-S接口）S5_P_OR_GN（S5-P/GN接口）S8_P_OR_GP（S8-P/GP接口）PROXY_SGSN_GP（Proxy SGSN GP接口）  默认值：无  配置原则：无 |
| GROUPID  | 组号     | 可选必选说明：必选参数  参数含义：该参数用于指定GTP-C本地实体的组号。  数据来源：本端规划  取值范围：整数类型，取值范围是0~31。  默认值：无  配置原则：  该参数需要从ADD GTPCLEGRP以及ADD GTPCLEGRPMEM命令中已配置的组号参数中取值。                                                                                                      |

## 使用实例

增加S11 GTP-C接口，组号为已通过**ADD GTPCLEGRP**以及**ADD GTPCLEGRPMEM**命令配置的组号0：

```
ADD GTPCINTF:INTFTYPE=E_GTPCINTF_ITFS11,GROUPID=0;
```
