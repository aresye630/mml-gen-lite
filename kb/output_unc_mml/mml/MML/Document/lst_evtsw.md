# 查询事件开关状态（LST EVTSW）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询事件开关状态。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                       |
|:--------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICE | 服务名称   | 可选必选说明：可选参数  参数含义：该参数表示事件绑定的服务名称。可以通过LST EVTSW命令获取参数。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~16。  默认值：无  配置原则：无                                   |
| EVENTID | 事件ID   | 可选必选说明：可选参数  参数含义：该参数用于表示服务名称下的事件ID，可以通过LST EVTSW命令获取参数。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：  只支持配置LST EVTSW命令获取到的服务实例。 |

## 使用实例

查询配置表内事件1的开关状态。

```
%%LST EVTSW: SERVICE="SDRS", EVENTID=1;%%
RETCODE = 0  操作成功

结果如下
-----------
服务名称 = SDRS
  事件ID = 1
开关状态 = 打开
事件名称 = sdrs link down1
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                   |
|:--------|:----------------------------------------|
| 服务名称    | 该参数表示事件绑定的服务名称。可以通过LST EVTSW命令获取参数。     |
| 事件ID    | 该参数用于表示服务名称下的事件ID，可以通过LST EVTSW命令获取参数。  |
| 事件开关    | 该参数用于表示事件的开关状态。                         |
| 事件名称    | 该参数用于表示事件ID对应的事件名称，可以通过LST EVTSW命令获取参数。 |
