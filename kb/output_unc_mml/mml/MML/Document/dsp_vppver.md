#### 命令功能

**适用网元：SGSN、MME**

此命令用于查看产品使用SS7组件的版本信息。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                         |
|:-------|:-------|:---------------------------------------------------------------------------------------------|
| RUNAME | RU名称   | 可选必选说明：可选参数 参数含义：该参数用于指定SPU资源单元名。该参数可以通过DSP RU命令查询。 取值范围：0~63 位字符串 默认值：无                     |
| PT     | 进程类型   | 可选必选说明：可选参数 参数含义：该参数用于指定进程的进程类型。 取值范围： SPP(SPP)SGP(SGP) 默认值：无                                |
| PN     | 进程号    | 可选必选说明：可选参数 参数含义：该参数用于指定进程号。 取值范围：0～20 默认值：无                                                 |
| VPPT   | 组件类型   | 可选必选说明：必选参数 参数含义：该参数用于指定查询的组件类型。 取值范围：“M3UA(M3UA)”“SCTP(SCTP)”“TCAP(TCAP)”“SCCP(SCCP)” 默认值：无 |

#### 使用实例

查询组件M3UA的版本：

DSP VPPVER: VPPT=M3UA;

```
%%DSP VPPVER: VPPT=M3UA;%%
RETCODE = 0  操作成功。

查询组件版本
------------
组件类型  =  M3UA
组件版本  =  VPP V300R003C26SPC220 (M3UA) (RFC3332)       [10:33:49]
(结果个数 = 1)
---    END
```

| 组件版本    | 组件版本。                        |
