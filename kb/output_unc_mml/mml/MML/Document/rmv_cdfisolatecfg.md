# 删除CDF隔离配置（RMV CDFISOLATECFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

删除CDFISOLATECFG配置后对应的CDF容器会解除隔离。

**适用NF：NCG**

该命令用于删除CDF隔离配置。

## 注意事项

- 该命令执行后需要重启待恢复的CDF进程才能生效。

- 该命令需使用RST MSPROCESS重启CDF进程才能生效。其中进程ID可以通过DSP MSPROCESS进行查询，ARM环境和裸机环境一个CDF容器有两个进程。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                |
|:--------|:-------|:------------------------------------------------------------------------------------|
| PODNAME | pod 名称 | 可选必选说明：必选参数  参数含义：该参数用于描述pod名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无 |

## 使用实例

删除cgfa-pod-0的隔离配置.

```
RMV CDFISOLATECFG: PODNAME="cgfa-pod-0";
```
