# 增加PDU异常返回码动作（ADD PDUSCACT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于增加PDU异常返回码动作。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入2000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
|:------------|:-----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CCTMPLTNAME | 融合计费模板名称   | 可选必选说明：必选参数  参数含义：该参数用于指定融合计费模板的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。不区分大小写。  默认值：无  配置原则：  该参数使用ADD CCT命令配置生成。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| CODETYPE    | 返回码类型      | 可选必选说明：必选参数  参数含义：该参数用于指定PDU异常返回码类型。  数据来源：本端规划 取值范围： “DEFAULT（针对未指定的异常返回码设置处理动作）”：当收到配置指定之外的结果码时需要执行的动作“VALUE（针对指定异常返回码设置处理动作）”：当收到配置指定的结果码时需要执行的动作  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| STATUSCODE  | 状态码        | 可选必选说明：该参数在"CODETYPE"配置为"VALUE"时为条件必选参数。  参数含义：该参数用于配置PDU级异常状态返回码。  数据来源：本端规划  取值范围：整数类型，取值范围是300~999，65535。  默认值：无  配置原则：  返回码500,502,504,601,602,603,605的默认动作为FAILOVER。  返回码604的默认动作需参考ADD CCT命令中FHACTION的动作，FHACTION为CONTINUE时，604的默认动作为CONTINUE，其余情况的默认动作为TERM_WITH_REL。  内部异常码606默认动作：主备Chf在同一个SCP组时，动作同604，否则，默认动作为FAILOVER。  其他返回码的默认动作为TERM_WITH_REL。  异常码604/605，内部异常码606动作优先级：通过命令ADD PDUSCACT中的参数SCACT配置的异常码动作 > 上述的默认动作 > 通过命令ADD PDUSCACT中参数CODETYPE配置的DEFAULT动作 > 未配置的异常码默认动作。  其他异常码动作优先级：通过命令ADD PDUSCACT中的参数SCACT配置的异常码动作 > 通过命令ADD PDUSCACT中参数CODETYPE配置的DEFAULT动作 > 未配置的异常码默认动作。 |
| SCACT       | 处理动作       | 可选必选说明：必选参数  参数含义：该参数用于指定PDU异常返回码的处理动作。  数据来源：本端规划 取值范围： “FAILOVER（进行Failover处理）”：进行Failover处理时，优先按照CHF下发的sessionFailover与failureHandling信元处理，CHF无下发则通过SET FAILHANDLING命令配置的Failover动作处理。“CONTINUE（允许业务继续进行）”：允许业务继续进行，不再进行配额管理。SMF/PGW-C在PDU会话去活时向CHF上报执行continue动作之后的配额用量。“TERM_WITH_REL（去活PDU会话，发送Charging Data Request Release消息）”：去活PDU会话，发送Charging Data Request Release消息。“TERM_NO_REL（去活PDU会话，不发送Charging Data Request Release消息）”：去活PDU会话，不发送Charging Data Request Release消息。“BLOCK（阻塞业务，使业务不能继续进行）”：阻塞业务，使业务不能继续进行。“REDIRECT（将当前业务重定向到指定的地址）”：将当前业务重定向到指定的地址。  默认值：无  配置原则：无              |
| RDVIRTIP    | 重定向IPV4地址  | 可选必选说明：该参数在"SCACT"配置为"REDIRECT"时为条件可选参数。  参数含义：该参数用于指定PDU异常返回码重定向动作的IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：  不配置此参数时值默认为0.0.0.0。                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| RDVIRTIPV6  | 重定向IPV6地址  | 可选必选说明：该参数在"SCACT"配置为"REDIRECT"时为条件可选参数。  参数含义：该参数用于指定PDU异常返回码重定向动作的IPv6地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：  不配置此参数时值默认为::。                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| BLKTIMER    | 阻塞处理时间间隔   | 可选必选说明：该参数在"SCACT"配置为"BLOCK"、"REDIRECT"时为条件可选参数。  参数含义：该参数用于指定PDU异常返回码阻塞/重定向动作的业务阻塞/重定向时间，从阻塞/重定向开始经过配置时长以后，业务再来时可以重新触发配额申请。  数据来源：本端规划  取值范围：整数类型，取值范围是0~1440，单位是分钟。  默认值：无  配置原则：  不配置此参数时值默认为0。                                                                                                                                                                                                                                                                                                                                                                                                  |
| GTPV01CAUSE | 原因值GtpV0-1 | 可选必选说明：该参数在"SCACT"配置为"TERM_WITH_REL"、"TERM_NO_REL"时为条件可选参数。  参数含义：该参数用于配置当用户因PDU异常结果码被激活失败或更新失败时，在GTPv0或GTPv1消息中传递给左侧网元的Cause值。  数据来源：本端规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：  不配置此参数时值默认为0。                                                                                                                                                                                                                                                                                                                                                                                                      |
| GTPV2CAUSE  | 原因值GtpV2   | 可选必选说明：该参数在"SCACT"配置为"TERM_WITH_REL"、"TERM_NO_REL"时为条件可选参数。  参数含义：该参数用于配置当用户因PDU异常结果码被激活失败或更新失败时，在GTPv2消息中传递给左侧网元的Cause值。  数据来源：本端规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：  不配置此参数时值默认为0。                                                                                                                                                                                                                                                                                                                                                                                                            |
| REACTREQ    | 重新激活请求     | 可选必选说明：该参数在"SCACT"配置为"TERM_WITH_REL"、"TERM_NO_REL"时为条件可选参数。  参数含义：该参数用于指示当用户因PDU异常结果码被激活失败或更新失败时，SMF是否通知用户重新激活。  数据来源：本端规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无  配置原则：  不配置此参数时值默认为DISABLE（0）。                                                                                                                                                                                                                                                                                                                                                                                                       |

## 使用实例

增加PDU异常返回码动作配置CCT名称为“test”，指定异常返回码为300，动作为block，阻塞时长30分钟：

```
ADD PDUSCACT: CCTMPLTNAME="test", CODETYPE=VALUE, STATUSCODE=300, SCACT=BLOCK, BLKTIMER=30;
```
