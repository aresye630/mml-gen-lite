# 查询流控系统参数(LST FLOWCTRLPARA)

- 命令功能

#### 命令功能

**适用网元：SGSN、MME**

该命令用于显示某个进程上每秒数据流量的接入限制数。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                             |
|:---------|:-------|:-------------------------------------------------------------------------------------------------|
| PROCTYPE | 进程类型   | 可选必选说明：可选参数 参数含义：该参数用于指定进程的类型。 数据来源：整网规划 取值范围：“SPP(SPP)”“SGP(SGP)”“GBP(GBP)”“UPP(UPP)” 系统初始设置值：无 |

#### 使用实例

查询某个进程上每秒数据流量的接入限制数，进程类型为GBP：LST FLOWCTRLPARA: PROCTYPE=GBP;

LST FLOWCTRLPARA:;

```
%%LST FLOWCTRLPARA: PROCTYPE=GBP;%% 
RETCODE = 0  操作成功。

查询结果如下
```
