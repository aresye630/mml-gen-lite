# 显示PAE节点信息（DSP PAENODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示PAE节点信息，查询到的结果均是Fabric类型的POD。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                    |
|:-------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CELLTYPE     | 微服务类型  | 可选必选说明：可选参数 参数含义：该参数用于指定微服务类型。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～63。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符。 默认值：无 配置原则：使用DSP PAENODE查看微服务类型。    |
| CELLINSTANCE | 微服务实例号 | 可选必选说明：可选参数 参数含义：该参数用于指定微服务实例号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～127。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符。 默认值：无 配置原则：使用DSP PAENODE查看微服务实例号。 |

显示PAE节点信息：

```
DSP PAENODE:;
```

#### 输出结果说明

| 输出项名称   | 输出项解释                                            |
|:--------|:-------------------------------------------------|
| 微服务类型   | 用于指定微服务类型。                                       |
| 微服务实例号  | 用于指定微服务实例号。                                      |
| 工作角色    | 分为控制和数据转发节点。                                     |
| 主备角色    | 数据转发节点没有主备，控制节点分为主备节点。                           |
| 服务地址    | 用于指定微服务的实例标识，当前使用的是实例所在的POD名。                    |
| 资源ID    | 资源ID，为该实例内部通讯标识TB(Target Board)。                 |
| 服务类型集合  | 本POD内的服务类型集合，通过环境变量SVC_VFABRIC_LOCAL_SVC_SET配置而来 |
