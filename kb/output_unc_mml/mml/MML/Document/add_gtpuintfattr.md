#### 命令功能

**适用网元：SGSN、MME**

该命令用于指定GTPU IP地址在指定的接口使用，或者在指定的用户范围内使用，满足不同的组网部署要求。

本命令需和**ADD GTPULE**命令配合，通过**ADD GTPULE**命令的“组号”与本命令的{“接口类型”+“用户范围”}关联起来，满足各种组网规划的应用。

应用场景举例1：GnGp SGSN组网时，将GnGp接口与Iu接口隔离，通常划分独立的VPN，这就要求Iu接口上使用的GTPU IP地址能够独立指定，与GnGp接口的GTPU IP地址分开。数据规划时，将Iu接口的GTPU IP地址规划为32号组，其他接口的GTPU IP地址规划为0号组，通过本命令指定Iu接口与32号组关联，其他接口缺省与0号组关联。

#### 注意事项

- 该命令执行后立即生效。
- 指定IMSI前缀的记录最大支持1024。
- 指定运营商标识的记录最大支持128。
- 用户范围参数选择为所有用户时的记录数最大支持6。
- {“接口类型”+“用户范围”}唯一标识一条记录。
- 不同的{“接口类型”+“用户范围”}允许指定相同的组号。
- {“ALL\_INTERFACE(所有接口)”+“ALL\_USER(所有用户)”}为系统初始记录，指定**ADD GTPULE**配置的0号组，不允许指定为其他组号。
- {“ALL\_USER(所有用户)”+“Iu接口” }为系统初始记录，指定**ADD GTPULE**配置的32号组，不允许指定为其他组号。
- “IMSI前缀”长度不相等时，使用“IMSI前缀”最长匹配的记录。
- GTPU IP地址使用的优先级从高到低为：
- 指定接口类型+“SPECIAL\_IMSIPRE(指定IMSI前缀)”。
- “ALL\_INTERFACE(所有接口)”+“ SPECIAL\_IMSIPRE(指定IMSI前缀)” 。
- 指定接口类型+“SPECIAL\_NOID(指定运营商)” 。
- “ ALL\_INTERFACE(所有接口)” +“ SPECIAL\_NOID(指定运营商)”。
- 指定接口类型+“ALL\_USER(所有用户)”。
- “ALL\_INTERFACE(所有接口)”+“ALL\_USER(所有用户)”。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                     |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：必选参数 参数含义：该参数用于指定GTPU IP地址适用的用户范围。 数据来源：全网规划 取值范围：“ALL_USER(所有用户)”“SPECIAL_IMSIPRE(指定IMSI前缀)”“SPECIAL_NOID(指定运营商)” 默认值：无                                                                                                                                          |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件必选参数 参数含义：该参数用于指定用户的IMSI前缀。使用时按照IMSI最长匹配进行查询。 前提条件：该参数在“用户范围”参数配置为“SPECIAL_IMSIPRE(指定IMSI前缀)”后生效。 数据来源：全网规划 取值范围：1~15位十进制数 默认值：无                                                                                                                                |
| NOID     | 运营商标识  | 可选必选说明：条件必选参数 参数含义：该参数用于指定用户归属的运营商标识。 前提条件：该参数在“用户范围”参数配置为“SPECIAL_NOID(指定运营商)”后生效。 数据来源：全网规划 取值范围：0～64，128～254 默认值：无 配置原则：若该参数需要配置为0或128～254之间的值时，请先在ADD MNO中配置取值相同的“MNOID”参数。若该参数需要配置为1～64之间的值时，须先在ADD MVNO中配置取值相同的“MVNOID”参数。                                         |
| INTFTP1  | 接口类型   | 可选必选说明：条件必选参数 参数含义：该参数用于指定GTPU IP地址适用的接口类型。 前提条件：该参数在“用户范围”参数配置为“ALL_USER(所有用户)”后生效。 数据来源：本端规划 取值范围：“ALL_INTERFACE(所有接口)”“GN-GGSN/GP(Gn-GGSN/Gp)”“GN-SGSN/S16(Gn-SGSN/S16)”“Iu(IU)”“S11(S11)”“S4(S4)” 默认值：无  说明： “GN-SGSN(Gn-SGSN)”包含GnGp SGSN之间的接口以及GnGp SGSN与MME之间的接口。 |
| INTFTP2  | 接口类型2  | 可选必选说明：条件必选参数 参数含义：该参数用于指定GTPU IP地址适用的接口类型。 前提条件：该参数在“用户范围”参数配置为“SPECIAL_NOID(指定运营商)”/“SPECIAL_IMSIPRE(指定IMSI前缀)”后生效。 数据来源：本端规划 取值范围：“ALL_INTERFACE(所有接口)”“GN-GGSN/GP(Gn-GGSN/Gp)”“S11(S11)”“S4(S4)” 默认值：无                                                               |
| GRPID    | 组号     | 可选必选说明：必选参数 参数含义：该参数用于指定GTPU IP所属的组。 数据来源：本端规划 取值范围：1~31 默认值：无 配置原则：请先在ADD GTPULE中配置取值相同的“组号”参数。 说明： 该参数在命令ADD GTPULE中已配置。 逻辑接口获取本端GTPU IP组号的策略：如果是NB-IoT业务，GTPUINTFATTR表已配置，则从GTPUINTFATTR表中获取。如果是NB-IoT业务，GTPUINTFATTR表没有配置，则0号组作为选择本端GTPU IP的组号。                      |
| DESC     | 描述信息   | 可选必选说明：可选参数 参数含义：该参数用于指定描述信息。 数据来源：本端规划 取值范围：0~31位字符串 默认值：无                                                                                                                                                                                                              |

#### 使用实例

增加记录，配置SUBRANGE为ALL\_USER、INTFTP1为S11、GRPID为9、DESC为"huawei"的记录：

ADD GTPUINTFATTR: SUBRANGE=ALL\_USER, INTFTP1=S11, GRPID=9, DESC="huawei";
