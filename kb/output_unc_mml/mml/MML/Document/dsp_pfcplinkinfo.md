# 显示PFCP链路当前及历史状态（DSP PFCPLINKINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF、SGW-C、PGW-C、GGSN**

该命令用于查询PFCP链路当前及历史状态记录，包括接口类型、链路状态变更、变更时间戳、以及本端对端地址等信息。当前支持每个进程最多显示100条历史链路。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                  |
|:-------------|:-------|:----------------------------------------------------------------------------------------------------------------------|
| UPINSTANCEID | UP实例标识 | 可选必选说明：可选参数  参数含义：该参数用于指定UPF的实例标识。当需要查询指定UPF的路径信息时，可以指定该参数。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~50。不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

- 查询所有链路状态。
  DSP PFCPLINKINFO:;

  ```
  %%DSP PFCPLINKINFO: ;%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
              UP实例标识  =  upf_instance_1
                接口类型  =  N4
            本端IPv4地址  =  10.2.102.17
            本端IPv6地址  =  ::
            对端IPv4地址  =  192.168.208.11
            对端IPv6地址  =  ::
            链路状态变更  =  UP->DOWN
      链路状态变更时间戳  =  09:30:05 06/04/2021
                 POD名称  =  uncpod-0
  (结果个数 = 1)
  ```
- 查询UPF为“upf\_instance\_1”的UP链路状态。
  DSP PFCPLINKINFO: UPINSTANCEID="upf\_instance\_1".

  ```
  %%DSP PFCPLINKINFO: UPINSTANCEID="upf_instance_1";%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
              UP实例标识  =  upf_instance_1
                接口类型  =  N4
            本端IPv4地址  =  10.2.102.17
            本端IPv6地址  =  ::
            对端IPv4地址  =  192.168.208.11
            对端IPv6地址  =  ::
            链路状态变更  =  UP->DOWN
      链路状态变更时间戳  =  09:30:05 06/04/2021
  (结果个数 = 1)
  ```

## 输出结果说明

| 输出项名称     | 输出项解释                                     |
|:----------|:------------------------------------------|
| UP实例标识    | 该参数用于指定UPF的实例标识。当需要查询指定UPF的路径信息时，可以指定该参数。 |
| 接口类型      | 该参数用于指示接口类型。                              |
| 本端IPv4地址  | 该参数用于指示本端IPv4地址。                          |
| 本端IPv6地址  | 该参数用于指示本端IPv6地址。                          |
| 对端IPv4地址  | 该参数用于指示对端IPv4地址。                          |
| 对端IPv6地址  | 该参数用于指示对端IPv6地址。                          |
| 链路状态变更    | 该参数用于指示链路状态变更。                            |
| 链路状态变更时间戳 | 该参数用于指示链路状态变更时间戳。                         |
| POD名称     | 该参数用于显示POD名称。                             |
