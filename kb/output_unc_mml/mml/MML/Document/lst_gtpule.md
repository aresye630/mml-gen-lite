#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询GTPU本地实体。

#### 注意事项

本命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                        |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GROUPID | 组号     | 可选必选说明：可选参数 参数含义：本参数用于指定GTPU本端实体对应的组号。组号用于组网规划时不同接口，或者不同用户范围使用独立的GTPU本端实体。 数据来源：本端规划 取值范围：0~32 默认值：无                                                        |
| IPTYPE  | IP地址类型 | 可选必选说明：可选参数 参数含义：本参数用于指定GTPU本端实体的IP地址类型。 数据来源：全网规划 取值范围：“TPTADDR_TYPE_IPV4(IPV4)”“TPTADDR_TYPE_IPV6(IPV6)” 默认值：无                                            |
| LEIPV4  | IPv4地址 | 可选必选说明：条件可选参数 参数含义：本参数用于指定GTPU本端实体的IPv4地址 前提条件：该参数在“IP地址类型”参数配置为“TPTADDR_TYPE_IPV4(IPV4)”后生效。 数据来源：本端规划 取值范围：0.0.0.0~255.255.255.255 默认值：无                  |
| LEIPV6  | IPv6地址 | 可选必选说明：条件可选参数 参数含义：本参数用于指定GTPU本端实体的IPv6地址 前提条件：该参数在“IP类型”参数配置为“TPTADDR_TYPE_IPV6(IPV6)”后生效。 数据来源：本端规划 取值范围：::~FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 |

#### 使用实例

查询GTPU本地实体：

LST GTPULE:;

```
%%LST GTPULE:;%%
RETCODE = 0  操作成功。

操作结果如下
------------
组号    IP地址类型    IPv4地址          VPN名称    记录索引    描述信息    资源标识

0       IPV4          10.141.149.100    abc        2           NULL        2       
0       IPV4          10.141.149.101    abc        3           NULL        3       
仍有后续报告输出
---    END

%%LST GTPULE:;%%
RETCODE = 0  操作成功。

操作结果如下
------------
组号    IP地址类型    IPv6地址                          VPN名称    记录索引    描述信息    资源标识

0       IPV6          2001:db8:10:19:44:55:10:12        abc        0           NULL        0       
0       IPV6          2001:db8:10:19:44:55:10:13        abc        1           NULL        1       
(结果个数 = 4)
共有2个报告
---    END
```

#### 输出结果说明

请参考**ADD GTPULE**命令的参数标识。

| 输出项名称   | 输出项解释                                                                  |
|:--------|:-----------------------------------------------------------------------|
| 记录索引    | 参数含义：本参数用于指定本配置记录的索引。记录索引能够唯一标识一条GTPU本端实体的记录，在删除或修改操作时使用。 取值范围：0~65535 |
| 资源标识    | 参数含义：本参数用于表示GTPU IP地址的唯一标识。GTPU LE中相同GTPU IP地址的资源标识相同。 取值范围：0~65535    |
