# 增加基于apn的Gy接口重用字段的填写方式（ADD APNGY5GREUSEAVP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C**

该命令用于增加指定APN 5G用户接入时，Gy接口重用字段的填写方式。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入20000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                          |
|:----------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN             | APN名称  | 可选必选说明：必选参数  参数含义：该参数用于指示APN名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无  配置原则：  输入的APN名称需要符合APN命名规则，仅支持配置APN NI（Network Identifier），例如“huawei.com”；该参数取值应与ADD APN命令中参数“APN”保持一致，使用该前需通过ADD APN添加一组记录。 |
| RAT             | 无线接入技术 | 可选必选说明：可选参数  参数含义：该参数用于控制用户RAT为NR时，Gy接口是否通过支持通过3GPP-RAT-Type字段携带用户真实的RAT。  数据来源：本端规划 取值范围： “DISABLE（不使能）”：不携带用户信息“ENABLE（使能）”：携带用户真实信息(EUTRAN)  默认值：ENABLE  配置原则：无                                                                                                                                                            |
| ULI             | 用户位置信息 | 可选必选说明：可选参数  参数含义：该参数用于控制用户RAT为NR时，Gy接口是否支持通过3GPP-User-Location-Info字段携带用户真实的位置信息。  数据来源：本端规划 取值范围： “DISABLE（不使能）”：不携带用户信息“ENABLE（使能）”：携带转换后的用户4G位置信息  默认值：ENABLE  配置原则：无                                                                                                                                                     |
| SERVINGNODETYPE | 服务节点类型 | 可选必选说明：可选参数  参数含义：该参数用于控制用户RAT为NR时，Gy接口是否支持通过Serving-Node-Type字段携带用户真实的服务节点类型。  数据来源：本端规划 取值范围： “DISABLE（不使能）”：不携带用户信息“ENABLE（使能）”：携带用户真实服务节点类型(MME)  默认值：ENABLE  配置原则：无                                                                                                                                                      |

## 使用实例

对指定APN的5G用户，当需要配置其Gy接口重用字段的填写方式时，使用该命令。

```
ADD APNGY5GREUSEAVP: APN="APNGY", RAT=ENABLE, ULI=ENABLE, SERVINGNODETYPE=ENABLE;
```
