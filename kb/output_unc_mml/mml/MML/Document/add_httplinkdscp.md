# 增加HTTP染色配置（ADD HTTPLINKDSCP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令是高危命令，误开启可能会导致TCP性能下降，请谨慎使用并联系华为技术支持协助操作。

该命令用于增加HTTP TCP头中的DSCP字段的染色配置。

## 注意事项

- 该命令执行后立即生效。

- 若需要增加一条HTTP染色配置，源端口号和目的端口号必须同时配置，或同时为空。

- 最多可输入1条记录。

#### 操作用户权限

G\_1，管理员级别命令组

## 使用实例

若需要增加一条HTTP染色配置，索引为1，IP类型为IPv4，源地址为255.255.255.255，目的地址为192.168.0.0，源端口号为11，目的端口号为12，标记指定报文的DSCP值为15，可以用如下命令：

```
ADD HTTPLINKDSCP: INDEX=1, IPVERSION=IPv4, SIPV4="255.255.255.255", DIPV4="192.168.0.0", DPORT=12, SPORT=11, DSCPVALUE=15;
```
