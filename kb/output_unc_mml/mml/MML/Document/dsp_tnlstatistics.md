# 查询隧道统计信息（DSP TNLSTATISTICS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询隧道统计信息。

#### 注意事项

只有配置隧道才能使用该命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询隧道统计信息：

```
DSP TNLSTATISTICS:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
  隧道类型  =  Gre
  隧道数目  =  1
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释     |
|:--------|:----------|
| 隧道类型    | 用于表示隧道类型。 |
| 隧道数目    | 用于表示隧道数目。 |
