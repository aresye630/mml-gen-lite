# 修改基于APN的DDN消息优先级配置（MOD DDNPRIORITYAPN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、SMF**

该命令用于修改基于APN的DDN消息优先级配置。

## 注意事项

- 该命令执行后立即生效。

- 该命令用于DDN流控场景下，UNC识别DDN消息的优先级。
- DDN Throttling功能使能时高优先级业务流触发的DDN消息不流控。
- DDN Throttling功能使能时，当低优先级业务流触发的DDN消息被全部或部分流控时，最低优先级业务流触发的DDN消息会被全部流控。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                      |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN      | APN名称  | 可选必选说明：必选参数  参数含义：该参数用于指定用户请求的APN。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”特殊字符，不区分大小写。  默认值：无  配置原则：无 |
| PRIORITY | 优先级    | 可选必选说明：必选参数  参数含义：该参数用于指定DDN优先级。  数据来源：本端规划  取值范围：枚举类型。 DDN_LOW（低）DDN_HIGH（高）DDN_LOWEST（最低）  默认值：无  配置原则：无                                                                                                |

## 使用实例

修改APN为IMS的DDN消息优先级是高优先级：

```
MOD DDNPRIORITYAPN: APN="IMS", PRIORITY=DDN_HIGH;
```
