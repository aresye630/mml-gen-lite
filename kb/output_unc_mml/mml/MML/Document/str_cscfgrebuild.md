# 启动对特定配置的缓存重建（STR CSCFGREBUILD）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SGW-C、AMF、SMF、GGSN、CBC、CBCF**

该命令用于启动业务进程对特定配置的缓存重建。

当发现本地配置缓存和OM的配置数据不一致时，可以使用该命令。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                         |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------|
| MMLNAME | 配置命令名称 | 可选必选说明：必选参数  参数含义：该参数表示配置命令的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~64。  默认值：无  配置原则：  该参数表示配置命令的名称，比如PLMNNS，不要输入ADD/RMV/MOD/LST等操作字符，优先LST命令名称。 |

## 使用实例

启动业务进程对PLMNNS配置的缓存重建，执行如下命令：

```
STR CSCFGREBUILD: MMLNAME="PLMNNS";
```
