# 创建OSPF域标识配置（ADD OSPFDOMAINID）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于配置OSPF域标识符。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为8000。
- 只有在执行ADD OSPF配置了OSPF进程后才能使用此命令。
- 每一个OSPF域都有一个或多个域标识符，其中有一个是主标识符，其它为从标识符。
- 如果OSPF实例没有明确域标识符，则认为它的标识符为NULL。
- 域标识符的值为0时不能配置secondary参数。
- 每个OSPF进程上domain-id secondary的最大条目数是1000条。
- 此命令不允许在公网中配置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称     | 参数说明                                                                                                                                       |
|:----------------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| PROCID          | 进程号      | 可选必选说明：必选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 配置原则：OSPF进程必须已经存在。请使用LST OSPF命令查看可用的OSPF进程。                         |
| DOMAINID        | 域标识      | 可选必选说明：必选参数 参数含义：域标识。 数据来源：本端规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无                                                                               |
| DOMAINTYPEVALUE | 域标识符类型的值 | 可选必选说明：可选参数 参数含义：指定OSPF域标识符类型的值。 数据来源：本端规划 取值范围：十六进制整数类型，取值范围为0x0～0xFFFF。 默认值：0                                                            |
| DOMAINIDTYPE    | 域标识符的类型  | 可选必选说明：可选参数 参数含义：指定OSPF域标识符的类型。 数据来源：本端规划 取值范围：枚举类型。 Type0005：Type0005。Type0105：Type0105。Type0205：Type0205。Type8005：Type8005。 默认值：Type0005 |
| DOMAINIDSECFLG  | 次级域标识符   | 可选必选说明：可选参数 参数含义：指定次级域标识符。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：FALSE                                                             |

#### 使用实例

配置OSPF进程1 VPN扩展中的VPN域标识符：

```
ADD OSPFDOMAINID:PROCID=1,DOMAINIDSECFLG=FALSE,DOMAINID="10.1.1.1",DOMAINTYPEVALUE="100",DOMAINIDTYPE=Type0005;
```
