# 设置NCG软件参数比特位（SET NCGSOFTPARAOFBIT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NCG**

该命令用于设置NCG软件参数比特位。

## 注意事项

- 该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                       |
|:---------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DT       | 数据类型    | 可选必选说明：必选参数  参数含义：该参数表示软件参数的数据类型。  数据来源：本端规划 取值范围： Dw（双字）Byte（字节）  默认值：无。  配置原则：无                                                                                          |
| DWORDNUM | Dword索引 | 可选必选说明：该参数在"DT"配置为"Dw"时为条件必选参数。  参数含义：该参数表示Dword类型软件参数的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~10000。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST NCGSOFTPARAOFBIT查询当前参数配置值。  配置原则：无 |
| VALUE    | 软参记录值   | 可选必选说明：必选参数  参数含义：该参数表示软件参数的值。  数据来源：本端规划 取值范围： VALUE_0（0）VALUE_1（1）  默认值：无。  配置原则：无                                                                                       |
| POSITION | 比特位     | 可选必选说明：必选参数  参数含义：该参数表示软件参数比特位的位置。  数据来源：本端规划  取值范围：整数类型，取值范围是1~32。  默认值：无。  配置原则：无                                                                                        |

## 使用实例

设置双字类型1号软参Bit1值为0:

```
SET NCGSOFTPARAOFBIT: DT=Dw, DWORDNUM=1, VALUE=VALUE_0, POSITION=1;
```
