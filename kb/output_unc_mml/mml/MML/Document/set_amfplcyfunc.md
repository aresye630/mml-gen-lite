# 设置AMF策略功能（SET AMFPLCYFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

若开启下发缺省配置UE Logo功能时，“MML命令行”中“默认运营商全称”和“默认运营商简称”参数配置错误，会影响终端UE Logo显示。

**适用NF：AMF**

该命令用于设置AMF策略功能。

## 注意事项

- 该命令执行后立即生效。

- 当运营商希望配置的缺省NI（Network Identity）不对所有UE下发，而是通过用户特征（如是否签约特定DNN）决策是否向UE下发，需要通过SET NGDFTNIPLCY配置缺省NI策略。
- 如果ADD NITZPLCY/ADD NGMNO配置运营商全称（FULLNAME）和运营商简称（SHORTNAME），建议本配置中默认运营商全称（FULLNAME）和默认运营商简称（SHORTNAME）与ADD NITZPLCY/ADD NGMNO配置保持一致。否则，AM-PCF清除VIP UELogo时，AMF优先将本配置中默认运营商全称和默认运营商简称下发给UE，后续移动性管理流程中AMF再将ADD NITZPLCY/ADD NGMNO配置中运营商全称和运营商简称下发给UE。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

G\_1，管理员级别命令组；G\_2，操作员级别命令组
