# 删除用户的SMS上下文（RMV SMSCTX）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

删除SMS上下文将影响用户正在进行的短消息业务。

**适用NF：SMSF**

该命令用于删除用户的SMS上下文。当功能调测或拨测过程中需要手动删除用户的SMS上下文时，使用该命令。

## 注意事项

- 该命令执行后立即生效。

- 删除SMS上下文将影响用户正在进行的短消息业务，请慎重使用此命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                              |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------|
| SUPI   | SUPI   | 可选必选说明：必选参数  参数含义：该参数用于指定用户的SUPI，在本命令中，可以按指定SUPI删除对应用户的SMS上下文。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是5~15。只允许输入十进制数字(0-9)。  默认值：无  配置原则：无 |

## 使用实例

操作员在功能调测过程中手动删除值为460023500100001的SUPI对应的用户的SMS上下文。

```
RMV SMSCTX: SUPI="460023500100001";
```
