# 修改5G模式移动网络运营商信息（MOD NGMNO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

执行该命令配置的运营商信息配置不合理将导致用户无法驻留网络，影响用户业务。

若开启下发缺省配置UE Logo功能时，“MML命令行”中“运营商全称”和“运营商简称”参数配置错误，会影响终端UE Logo显示。

**适用NF：SGW-C、PGW-C、AMF、SMF、NRF、NSSF、CBC、CBCF**

该命令用于修改移动网络运营商基本信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                    |
|:----------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NOID      | 运营商标识  | 可选必选说明：必选参数  参数含义：该参数用于在系统内唯一标识移动网络运营商。  数据来源：本端规划  取值范围：整数类型，取值范围为0。  默认值：无  配置原则：无                                                                                                    |
| FULLNAME  | 运营商全称  | 可选必选说明：可选参数  参数含义：该参数用于指定移动网络运营商的全称。AMF发送给UE的Configuration Update Command消息中携带的“Full name for network”信元值来源于本参数。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：  输入单空格将删除该参数已有配置项。  |
| SHORTNAME | 运营商简称  | 可选必选说明：可选参数  参数含义：该参数用于指定移动网络运营商的简称。AMF下发给UE的Configuration Update Command消息中携带的“Short name for network”信元值来源于本参数。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：  输入单空格将删除该参数已有配置项。 |
| DESC      | 描述信息   | 可选必选说明：可选参数  参数含义：该参数表示对移动网络运营商的描述信息，在运维过程中起到助记的作用。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~32。  默认值：无  配置原则：  输入单空格将删除该参数已有配置项。                                                                |

## 使用实例

修改标识为1的运营商名称，执行如下命令：

```
MOD NGMNO: NOID=0, FULLNAME="Operator B", SHORTNAME="OB";
```
