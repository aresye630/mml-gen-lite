# 增加APN与Profile Space的绑定关系（ADD APNPROFSPACE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

本命令用于配置APN与ProfileSpace的绑定关系。

#### 注意事项

- 该命令执行后只对新激活用户生效。
- 该命令最大记录数为3000。
- 每个APN最多可以绑定一个ProfileSpace。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称            | 参数说明                                                                                                                                                                 |
|:--------------|:----------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN           | APN名称           | 可选必选说明：必选参数 参数含义：该参数用于指定APN实例名。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：配置的APN必须是系统已经存在的APN对象名称。                                                                |
| PROFSPACENAME | Profile Space名称 | 可选必选说明：必选参数 参数含义：该参数用于指定ProfileSpace实例名。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数使用ADD PROFILESPACE命令配置生成。配置的ProfSpaceName必须是ProfileSpace的对象名。 |

#### 使用实例

将Profile Space名称为“profilespace1”的Profile Space绑定到指定APN “apn1”下：

```
ADD APNPROFSPACE:APN="apn1",PROFSPACENAME="profilespace1";
```
