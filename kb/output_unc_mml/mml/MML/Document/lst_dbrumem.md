# 查询CSDB RU内存信息(LST DBRUMEM)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询CSDB RU内存信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                            |
|:------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------|
| CLUSTERTYPE | 集群类型   | 可选必选说明：可选参数 参数含义: 该参数用于指定集群类型，分为普通集群和XSF集群。 数据来源：本端规划 取值范围： “COMMON_CLUSTER”：普通集群。“XSF_CLUSTER”：XSF集群。 默认值：无 配置原则：无             |
| RUTYPE      | RU类型   | 可选必选说明：可选参数 参数含义：该参数用于指定RU类型，可以通过DSP RU: SERVICEINSTANCE="CSDB_VNFC_999";命令查询获取。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无 |

#### 使用实例

查询**“集群类型”**为“COMMON\_CLUSTER”，“**RU类型**”为“CSDB\_SD\_RU”的RU内存信息：

```
LST DBRUMEM: CLUSTERTYPE=COMMON_CLUSTER, RUTYPE="CSDB_SD_RU";
```

#### 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD DBRUMEM**命令的参数说明。
