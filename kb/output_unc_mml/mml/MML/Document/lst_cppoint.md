# 查询CP端点信息（LST CPPOINT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF、SGW-C、PGW-C、GGSN**

该命令用于查询CP端点信息，根据CP端点的索引等信息来查询。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                 |
|:-------------|:-------|:-------------------------------------------------------------------------------------|
| CPPOINTINDEX | CP端点索引 | 可选必选说明：可选参数  参数含义：该参数用于指定这个CP端点的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无 |

## 使用实例

- 查询有的CP端点：
  LST CPPOINT:;

  ```
  %%LST CPPOINT:;%%
  RETCODE = 0  操作成功

  结果如下
  --------
  CP端点索引  =  0
  CP节点索引  =  0
      IP类型  =  IPv4
    IPv4地址  =  192.168.0.20
    IPv6地址  =  NULL
     VPN名称  =  _public_
  (结果个数 = 1)

  ---    END
  ```
- 查询CP端点索引为0的CP端点：
  LST CPPOINT: CPPOINTINDEX=0;

  ```
  %%LST CPPOINT: CPPOINTINDEX=0;%%
  RETCODE = 0  操作成功

  结果如下
  --------
  CP端点索引  =  0
  CP节点索引  =  0
      IP类型  =  IPv4
    IPv4地址  =  192.168.0.20
    IPv6地址  =  NULL
     VPN名称  =  _public_
  (结果个数 = 1)

  ---    END
  ```

## 输出结果说明

| 输出项名称   | 输出项解释                                              |
|:--------|:---------------------------------------------------|
| CP端点索引  | 该参数用于指定这个CP端点的索引。                                  |
| CP节点索引  | 该参数用于指定这个CP端点所属的CP节点的索引。其中CP节点的索引可以通过LST CPNODE查询。 |
| IP类型    | 该参数用于指定这个CP端点的IP地址类型。                              |
| IPv4地址  | 该参数用于指定这个CP端点的IPv4地址。该地址标识N4接口IPv4地址。              |
| IPv6地址  | 该参数用于指定这个CP端点的IPv6地址。该地址标识N4接口IPv6地址。              |
| VPN名称   | 该参数用于指定VPN名称。                                      |
