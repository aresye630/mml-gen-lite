# 查询SMF&UPF&CHF三方流量抽样审计参数（LST CHGVERIFYCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF、GGSN、PGW-C**

该命令用于查询SMF&UPF&CHF三方流量抽样审计的参数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询SMF&UPF&CHF三方流量抽样审计参数：

```
%%LST CHGVERIFYCTRL:;%%
RETCODE = 0  操作成功

结果如下
--------
 计费流量抽样核查总开关  =  使能
 N4接口流量抽样核查开关  =  使能
N40接口流量抽样核查开关  =  使能
   计费流量抽样核查数量  =  10
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称         | 输出项解释                   |
|:--------------|:------------------------|
| 计费流量抽样核查总开关   | 该参数用于指示是否开启流量抽样核查。      |
| N4接口流量抽样核查开关  | 该参数用于指示是否开启N4接口流量抽样核查。  |
| N40接口流量抽样核查开关 | 该参数用于指示是否开启N40接口流量抽样核查。 |
| 计费流量抽样核查数量    | 该参数用于设置计费流量抽样核查的会话数量。   |
