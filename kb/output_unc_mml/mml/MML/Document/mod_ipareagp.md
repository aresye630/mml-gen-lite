# 修改IP区域群(MOD IPAREAGP)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明

#### 命令功能

**适用网元：SGSN、MME**

该命令用于修改IP区域群的属性。

#### 注意事项

- 此命令执行后立即生效。
- 此配置涉及License（License部件编码：LKV2IPRL01），执行命令请使用**DSP LICENSE**命令确认对应特性license是否得到授权，执行**LST LICENSESWITCH**命令确认特性开关状态为“ENABLE(打开)”。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称          | 参数说明                                                                                                                                                                                           |
|:--------------|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AREAID        | 区域群标识         | 可选必选说明：必选参数 参数含义：该参数用于标识待修改的区域群。 数据来源：整网规划 取值范围：1~256 默认值：无                                                                                                                                    |
| IPAREASW      | IP区域开关        | 可选必选说明：可选参数 参数含义：该参数用于指定打开或者关闭IP区域管理功能。 数据来源：整网规划 取值范围：“OFF(关闭)”“ON(开启)” 默认值：无 配置原则：建议值为“OFF(关闭)”。                                                                                             |
| ROAMUSRSW     | 漫游用户开关        | 可选必选说明：条件可选参数 参数含义：该参数用于设置漫游用户限制接入开关。 前提条件：该参数在“IPAREASW(IP区域开关)”参数设置为“ON(开启)”时，该参数才有效。 数据来源：整网规划 取值范围：“OFF(关闭)”“ON(开启)” 默认值：无 配置原则：建议值为“OFF(关闭)”。                                             |
| NONLOCALUSRSW | 本网异地用户开关      | 可选必选说明：条件可选参数 参数含义：该参数用于设置本网异地用户限制接入开关。 前提条件：该参数在“IPAREASW(IP区域开关)”参数设置为“ON(开启)”时，该参数才有效。 数据来源：整网规划 取值范围：“OFF(关闭)”“ON(开启)” 默认值：无 配置原则：建议值为“OFF(关闭)”。                                           |
| AREAN         | 区域群名称         | 可选必选说明：可选参数 参数含义：该参数用于修改区域群名称。 数据来源：整网规划 取值范围：0~32位字符串 默认值：无                                                                                                                                   |
| DATACONSW     | 45G互操作数据持续性开关 | 可选必选说明：条件可选参数 参数含义：该参数用于指示当UAM开启基于位置的地址分配功能且4/5G归属同一IP区域群时，用户在4/5G互操作流程中是否支持数据业务不断流。 数据来源：全网规划 取值范围：“OFF(关闭)” “ON(开启)” 默认值：OFF(关闭)。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST IPAREAGP查询当前参数配置值。 配置原则：无 |

#### 使用实例

若对标识为1的IP区域群中漫游用户和本网异地用户限制接入，则将IP区域群记录修改如下：

MOD IPAREAGP: AREAID=1, IPAREASW=ON, ROAMUSRSW=ON, NONLOCALUSRSW=ON;
