# 删除弱口令字典成员（RMV WEAKPWDDICMEM）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：NCG**

该命令用于删除弱口令字典中的成员。

#### 注意事项

- 该命令执行后即时生效。

- 执行该命令删除的配置项是已经泄露的口令时，请谨慎操作。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                            |
|:--------|:-------|:--------------------------------------------------------------------------------|
| WEAKPWD | 弱口令    | 可选必选说明：必选参数 参数含义：用于删除弱口令字典中的成员。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：无。 |

#### 使用实例

在弱口令字典中删除“弱口令”“qazQAZ123!@#”。示例如下：

```
RMV WEAKPWDDICMEM: WEAKPWD="qazQAZ123!@#";
```
