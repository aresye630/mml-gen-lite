#### 命令功能

**须知** 

本命令属于高危命令，会激活或者删除系统补丁，并忽略过程中的系统异常，涉及冷补丁时，会重启系统，请谨慎使用并联系华为技术支持协助操作。

该命令用于校正补丁包，默认恢复会将补丁恢复到最近一次操作的状态，如果指定补丁版本号，则恢复到指定版本补丁。当补丁删除失败有残留，或者系统存在补丁相关告警时，可以尝试使用该命令进行恢复。

#### 注意事项

- 该命令执行后立即生效。
- 该命令执行后，涉及重启的，需要在重启后参数RBKTIMER所设置的时间内立即登录，并通过**DSP PATCHDETAILINFO**或者**DSP PATCHINFO**查询该操作是否成功。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| RBTMODE         | 重启模式   | 可选必选说明：可选参数 参数含义：该参数用于指定允许的重启模式。 数据来源：本端规划 取值范围：枚举类型。 NO：不重启。SOFT：软重启，不需要重启资源。 默认值：NO                        |
| VERSIONID       | 补丁版本号  | 可选必选说明：可选参数 参数含义：该参数用于指定需要恢复的补丁版本号，范围为系统中包含的补丁版本号；如果无此参数，则执行默认恢复。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无    |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

校正补丁包：

```
CLB PATCH:VERSIONID="V100R005SPH001",SERVICEINSTANCE="vnfc";
```
