# 删除AMF区域标识和集合标识的关联关系（RMV NRFREGIDSETIDREL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于在NRF上删除AMF区域标识和集合标识的关联关系。

## 注意事项

- 该命令执行后立即生效。

- 主备或双活组网的场景下，如果需要配置此命令，则两个NRF上均需执行此命令，且配置参数一致。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                  |
|:---------|:--------|:----------------------------------------------------------------------------------------------------------------------|
| AMFREGID | AMF区域标识 | 可选必选说明：必选参数  参数含义：该参数用于表示AMF区域标识。  数据来源：全网规划  取值范围：字符串类型，输入长度是2。按照十六进制输入，输入时不带0x，不足两位时从左边补0，取值范围0~ff。  默认值：无  配置原则：无  |
| AMFSETID | AMF集合标识 | 可选必选说明：必选参数  参数含义：该参数用于表示AMF集合标识。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。按照十六进制输入，输入时不带0x，不足三位时从左边补0，取值范围0~3ff。  默认值：无  配置原则：无 |

## 使用实例

运营商想在PLMN-NRF上删除AMF区域标识和集合标识的关联关系，配置此命令。

```
RMV NRFREGIDSETIDREL: AMFREGID="09", AMFSETID="123";
```
