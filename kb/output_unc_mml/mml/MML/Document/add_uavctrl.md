# 增加无人机控制管理（ADD UAVCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于为增加无人机控制管理。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入20000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称                    | 参数说明                                                                                                                                                                                                                                                                                                        |
|:---------------|:------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DNN            | 数据网络名称                  | 可选必选说明：必选参数  参数含义：该参数用于表示指定的网络切片支持的数据网络名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~63。  默认值：无  配置原则：  只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。                                                                                         |

## 使用实例

为eMBB切片（假设索引为0）配置DNN名称为huawei.com：

```
ADD UAVCTRL: DNN="huawei.com", NSIDX=0;
```
