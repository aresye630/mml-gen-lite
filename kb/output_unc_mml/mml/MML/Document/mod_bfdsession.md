# 修改BFD会话参数（MOD BFDSESSION）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改已存在的BFD会话配置参数。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称              | 参数说明                                                                                                                                                                                                                             |
|:-------------|:------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SESSNAME     | 会话名称              | 可选必选说明：必选参数 参数含义：会话名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～64。不区分大小写，不支持空格。 默认值：无                                                                                                                                                      |
| MINTXINT     | 最小发送间隔（ms）        | 可选必选说明：可选参数 参数含义：会话最小发送报文间隔。 数据来源：本端规划 取值范围：整数类型，取值范围为30～1000，单位是毫秒。 默认值：无                                                                                                                                                       |
| MINRXINT     | 最小接收间隔（ms）        | 可选必选说明：可选参数 参数含义：会话最小接收报文间隔。 数据来源：本端规划 取值范围：整数类型，取值范围为30～1000，单位是毫秒。 默认值：无                                                                                                                                                       |
| DETECTMULTI  | 检测倍数              | 可选必选说明：可选参数 参数含义：会话检测倍数，如果BFD会话在设置的检测周期内没有收到对端发来的BFD报文，则认为链路发生了故障，BFD会话的状态将会置为Down。检测周期＝对端配置的BFD检测倍数×MAX { 对端配置的发送时间间隔，本地配置的接收时间间隔 }。 数据来源：本端规划 取值范围：整数类型，取值范围为3～50。 默认值：无                                                       |
| WTRTIMERINT  | 等待恢复时间（min）       | 可选必选说明：可选参数 参数含义：等待恢复时间。如果配置了WTR，会话变为Up状态的事件在WTR超时后才上报给应用程序。其它状态变化的事件仍立即上报，不受WTR影响。当BFD会话震荡时，设置等待恢复时间可以避免应用程序在主备之间来回切换。如果使用WTR，用户需要手工在两端配置相同的WTR。否则，当一端会话状态变化时，两端应用程序感知到的BFD会话状态将不一致。 数据来源：本端规划 取值范围：整数类型，取值范围为0～60，单位是分钟。 默认值：无 |
| TOSEXP       | 报文优先级             | 可选必选说明：可选参数 参数含义：报文优先级。根据BFD绑定的业务的重要性，来设置BFD会话的优先级。在系统堵塞的情况下优先发送优先级高的BFD报文。 数据来源：本端规划 取值范围：整数类型，取值范围为0～7。 默认值：无 配置原则：取值越大，BFD报文优先级越高。                                                                                            |
| ADMINDOWN    | 管理DOWN            | 可选必选说明：可选参数 参数含义：会话管理Down。用于不需要BFD检测的场景里，手工将会话置Down，不影响业务。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无                                                                                                                       |
| DESCRIPTION  | 描述信息              | 可选必选说明：可选参数 参数含义：会话描述信息，一般用于描述该静态会话检测的链路等。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～51。区分大小写，支持空格。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。                                                                                                             |
| MINECHORXINT | 单臂Echo会话的收包间隔（ms） | 可选必选说明：可选参数 参数含义：单臂Echo最小接收报文间隔。 数据来源：本端规划 取值范围：整数类型，取值范围为30～1000，单位是毫秒。 默认值：无                                                                                                                                                   |
| PROCESSPST   | 是否操作PST           | 可选必选说明：可选参数 参数含义：会话状态变化是否操作PST（Port State Table）的标志。如果允许操作PST，当BFD检测到接口状态变为Down时，将更改PST，底层转发流量就能够通过PST了解接口是否发生故障。每个接口只允许1个BFD会话配置该参数。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无                                            |

#### 使用实例

将会话名字为Huawei123的会话改为启动等待恢复时间为10分钟、管理DOWN状态：

```
MOD BFDSESSION:SESSNAME="Huawei123",WTRTIMERINT=10,ADMINDOWN=TRUE;
```
