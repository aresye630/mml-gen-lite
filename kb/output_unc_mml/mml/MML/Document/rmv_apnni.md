# 删除APNNI(RMV APNNI)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用来删除特定组中的APNNI成员。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                                                                         |
|:-------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GRPID  | APNNI组号 | 可选必选说明：必选参数 参数含义：该参数用于指定APNNI组号。 数据来源：本端规划 取值范围：0～15 默认值：无 配置原则：该ID必须是ADD APNNIGROUP命令中已配置的ID记录。                                                                                                             |
| APNNI  | APNNI   | 可选必选说明：必选参数 参数含义：该参数用来设置APNNI信息。 数据来源：本端规划 取值范围：1～62位字符串 默认值：无 配置原则：APN网络标识地址由一个或多个LABEL构成，各LABEL间用“.”间隔。每个LABEL的构成字符只能是字母A～Z或a～z、数字0～9和中划线“-”，字母不区分大小写。APN网络标识地址不能以“rac”、“lac”、“sgsn”或“rnc”开头，不能以“.gprs”结尾。 |

#### 使用实例

删除组号为2的“APNNI组号”，“APNNI”为“HUAWEI.COM”。运行如下命令：

RMV APNNI: GRPID=2, APNNI="HUAWEI.COM";
