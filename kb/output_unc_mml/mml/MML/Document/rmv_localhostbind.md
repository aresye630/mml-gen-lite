# 删除Diameter本端主机与Diameter本端主机组的关联关系（RMV LOCALHOSTBIND）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

此命令用于从Diameter本地主机分组中删除指定的Diameter本地主机。

#### 注意事项

- 该命令执行后立即生效。
- 当不指定主机时，是删除整个Diameter本地主机组。当指定主机时，是从指定组中移除该主机。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称           | 参数说明                                                                                                                    |
|:------------|:---------------|:------------------------------------------------------------------------------------------------------------------------|
| LOCGRPNAME  | Diameter本端信息组名 | 可选必选说明：必选参数 参数含义：该参数用于指定Diameter本端主机组名。要求在系统内唯一，数据来源为运营商规划。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无 |
| LOCHOSTNAME | Diameter本端主机名  | 可选必选说明：可选参数 参数含义：本参数指定Diameter本端主机名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～127。不支持空格。 默认值：无 配置原则：无                              |

#### 使用实例

删除主机与Diameter本端主机分组的关联关系，删除Diameter本端主机分组为“abc”的记录：

```
RMV LOCALHOSTBIND: LOCGRPNAME="abc";
```
