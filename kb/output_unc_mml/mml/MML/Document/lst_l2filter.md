# 查询层二过滤器（LST L2FILTER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF**

该命令用于查询层二过滤器。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                              |
|:-----------|:--------|:--------------------------------------------------------------------------------------------------|
| FILTERNAME | 层二过滤器名称 | 可选必选说明：可选参数  参数含义：该参数用于指定层二过滤器名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。不支持空格，不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

- 查询所有的层二过滤器：

  ```
  LST L2FILTER: FILTERNAME="filter1";
  RETCODE = 0  操作成功

  结果如下
  --------
    过滤器名称  =  filter1
     源MAC地址  =  00E0-FC12-3456
   目的MAC地址  =  00E0-FC12-3457
    VLAN标识符  =  1
  优先级编码点  =  1
    丢弃指示器  =  ENABLE
      以太类型  =  PROFINET
  (结果个数 = 1)

  ---    END
  ```
- 查询层二过滤器名称为“filter1”的层二过滤器：

  ```
  LST L2FILTER:;
  RETCODE = 0  操作成功

  结果如下
  --------
    过滤器名称  =  filter1
     源MAC地址  =  00E0-FC12-3456
   目的MAC地址  =  00E0-FC12-3457
    VLAN标识符  =  1
  优先级编码点  =  1
    丢弃指示器  =  ENABLE
      以太类型  =  PROFINET
  (结果个数 = 1)

  ---    END
  ```
