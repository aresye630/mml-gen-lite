# 删除UPF和规则的绑定关系（RMV UPFBINDSELRULE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、PGW-C、SGW-C**

该命令用于删除UPF和规则的绑定关系。

## 注意事项

该命令执行后只对新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                             |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------|
| INDEX  | 索引     | 可选必选说明：必选参数  参数含义：该参数用于指定UPF和规则的绑定关系的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4999。  默认值：无  配置原则：  该参数取值不能重复，建议从0开始顺序取值。 |

## 使用实例

删除UPF和规则的绑定关系，UPF实例名称为"UPF1"，规则名称为"rulename1"：

```
RMV UPFBINDSELRULE: INDEX=0;
```
