# 增加LCSAP链路配置(ADD LCSAPLNK)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

此命令用于增加LCSAP链路配置。

#### 注意事项

- 此命令执行后立即生效。
- 此命令最大记录数为24。
- 对指定E-SMLC配置链路，每个E-SMLC最大4条链路。
- IP地址和VPN实例名称必须在SERVICEIP表中已经配置，可以用**LST SERVICEIP**查询。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

增加一条“链路索引”为“1”，“E-SMLC 标识”为“1”，“IP地址类型”为“IPV4(IPV4)”，“本地IPv4地址1 ”为“10.10.10.18”，“对端IPv4地址1”为“10.10.10.19”，“SCTP协议参数索引”为“0”，“VPN实例名称”为“UNC”的LCSAP链路配置记录：

ADD LCSAPLNK: LINKIDX=1, ESMLCID=1, IPTYPE=IPV4, LOCALIPV4\_1="10.10.10.18", PEERIPV4\_1="10.10.10.19", SCTPINDX=0, VPNNAME="UNC";
