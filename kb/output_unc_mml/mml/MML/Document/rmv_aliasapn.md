# 删除别名APN配置(RMV ALIASAPN)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于删除APN（Access Point Name）转换配置。在需要调整APN别名映射规则时使用。

#### 注意事项

- 该命令在运营商调整网络时使用，对于已有连接的APN不即时生效。
- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                                                                   |
|:---------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围    | 可选必选说明：必选参数 参数含义：该参数用于指定签约用户的范围。 取值范围：“ALL_USER(所有用户)”“IMSI_PREFIX(指定IMSI前缀)”“IMSI_RANGE(指定IMSI范围)” 默认值：无                                                                                                              |
| IMSIPRE  | IMSI前缀  | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI前缀。 前提条件：该参数在“用户范围”参数设置为“IMSI_PREFIX(指定IMSI前缀)”时，才需要配置。 取值范围：1～15位数字 默认值：无  说明： 根据IMSI、“原始APNNI”映射唯一的“转换APNNI”。                                                                          |
| IMSI     | IMSI    | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI，对该IMSI所在号段进行删除。 前提条件：该参数在“用户范围”参数设置为“IMSI_RANGE(指定IMSI范围)”时，才需要配置。 取值范围：1～15位数字 默认值：无  说明： 根据IMSI、“原始APNNI”映射唯一的“转换APNNI”。                                                              |
| OLDAPN   | 原始APNNI | 可选必选说明：必选参数 参数含义：该参数用于指定签约数据进行匹配后的APN NI。 取值范围：1～62 默认值：无  说明： “原始APNNI”由一个或多个LABEL构成，各LABEL间用“.”间隔。每个LABEL的构成字符只能是字母A～Z或a～z、数字0～9和中划线“-”，字母不区分大小写。例如“HUAWEI.COM”。APN网络标识地址不能以“rac”、“lac”、“sgsn”或“rnc”开头，不能以“.gprs”结尾。 |

#### 使用实例

删除“用户范围”为“ALL\_USER(所有用户)”、“原始APNNI”为“WCDMA”的APN别名配置记录。

RMV ALIASAPN: SUBRANGE=ALL\_USER, OLDAPN="WCDMA";
