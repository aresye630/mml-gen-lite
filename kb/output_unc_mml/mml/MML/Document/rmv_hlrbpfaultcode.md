# 删除HLR BYPASS故障状态码(RMV HLRBPFAULTCODE)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用于删除HLR BYPASS故障状态码。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                           |
|:----------|:-------|:---------------------------------------------------------------|
| RANGE     | 生效范围   | 可选必选说明：必选参数 参数含义：该参数用于指定特定故障码的生效范围。 取值范围： ALL（整系统）：整系统         |
| FAULTCODE | 故障码    | 可选必选说明：必选参数 参数含义：该参数用于指定进入HLR BYPASS状态的原因值。 取值范围：0-65535 默认值：无 |

#### 使用实例

删除HLR BYPASS故障状态码配置，生效范围为ALL（整系统），故障码为3002。

```
RMV HLRBPFAULTCODE: RANGE=ALL, FAULTCODE=3002;
```
