# 增加MCC与MNC归属关系（ADD PLMNMATCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C**

该命令用于增加MCC与MNC归属关系。

## 注意事项

- 该命令执行后立即生效。

- 此配置会优先于ADD MNCLEN命令、DWORD1023 BIT22和DWORD1023 BIT21软参生效。当无法通过此配置从IMSI中判断PLMN时，会依次按DWORD1023 BIT22、DWORD1023 BIT21、ADD MNCLEN的配置逻辑从IMSI中获取PLMN。

- 最多可输入2000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                      |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------|
| MCC    | 移动国家码  | 可选必选说明：必选参数  参数含义：该参数用于表示组成PLMN的移动国家码信息。  数据来源：本端规划  取值范围：字符串类型，输入长度是3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无    |
| MNC    | 移动网号   | 可选必选说明：必选参数  参数含义：该参数用于表示组成PLMN的移动网号信息。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是2~3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无 |

## 使用实例

增加MCC为678下MNC为123的归属，执行如下命令：

```
ADD PLMNMATCH: MCC="123", MNC="678";
```
