# 查询服务化接口热备接管流控参数（LST SBITAKEOVERFC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询服务化接口热备接管流控参数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                |
|:-------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SBIITF | 服务化接口名称 | 可选必选说明：可选参数  参数含义：该参数表示热备接管场景进行流控的服务化接口名称。  数据来源：全网规划 取值范围： “N8（N8接口）”：AMF和UDM之间的服务化接口。“N11（N11接口）”：AMF和SMF之间的服务化接口。“N15AM（N15 AM策略接口）”：AMF和AM策略所属PCF之间的服务化接口。“N15UE（N15 UE策略接口）”：AMF和UE策略所属PCF之间的服务化接口。“N20（N20接口）”：AMF和SMSF之间的服务化接口。  默认值：无  配置原则：  N11、N15AM、N15UE、N20接口为参数预留取值，功能暂未实现。  AMF向UDM热备接管一次会发送四条消息。  AMF向SMF热备接管，每个会话会发送一条消息。  AMF向SMSF热备接管一次会发送一条消息。  AMF向PCF热备接管，AM策略和UE策略各会发送一条消息。 |

## 使用实例

查询服务化接口热备接管流控参数，执行如下命令：

```
%%LST SBITAKEOVERFC:;%%
RETCODE = 0  操作成功

结果如下
--------
         服务化接口名称  =  N8接口
           流控功能开关  =  开启
       流控阈值作用范围  =  单POD
接管次数速率门限(次/秒)  =  300
         告警上报周期数  =  3
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称         | 输出项解释                                                      |
|:--------------|:-----------------------------------------------------------|
| 服务化接口名称       | 该参数表示热备接管场景进行流控的服务化接口名称。                                   |
| 流控功能开关        | 该参数用于控制是否开启服务化接口热备接管流控功能。                                  |
| 流控阈值作用范围      | 该参数用于设置消息流控阈值的作用范围。                                        |
| 接管次数速率门限(次/秒) | 该参数用于设置服务化接口接管次数速率门限。                                      |
| 告警上报周期数       | 该参数用于设置连续几个5秒周期处于流控态上报“ALM-100793 SBI服务化接口热备接管固定速率流控起控”告警。 |
