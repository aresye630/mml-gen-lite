# 显示调度组工作类型信息（DSP MSSSCHWORKGROUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示调度组工作类型信息。

#### 注意事项

- 该命令执行后立即生效。
- 使用此命令前需要使用**SET MSSDEBUGSWITCHM**打开MSS维测统计信息开关。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                                                                                |
|:-------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CELLTYPE     | 微服务类型   | 可选必选说明：必选参数 参数含义：该参数用于指定微服务类型。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～63。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符。 默认值：无 配置原则：使用DSP PAENODE查看工作角色为数据转发对应的微服务类型。    |
| CELLINSTANCE | 微服务实例号  | 可选必选说明：必选参数 参数含义：该参数用于指定微服务实例号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～127。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符。 默认值：无 配置原则：使用DSP PAENODE查看工作角色为数据转发对应的微服务实例号。 |
| GROUPID      | 调度组ID   | 可选必选说明：必选参数 参数含义：该参数用于表示调度组ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无 配置原则：使用DSP MSSSCHSUMTAILM查看当前调度的调度组号。                                                                   |
| QOSID        | 优先级队列ID | 可选必选说明：必选参数 参数含义：该参数用于表示优先级队列ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                                                                                       |

#### 使用实例

显示微服务类型为aa的微服务实例bb内调度组2，优先级队列ID为0的信息：

```
DSP MSSSCHWORKGROUP: CELLTYPE="aa", CELLINSTANCE="bb", GROUPID=2, QOSID=0;%
```
