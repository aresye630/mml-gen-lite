# 删除OCS组绑定关系（RMV OCSGRPBINDING）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用来删除OCS组绑定关系。支持批量删除，给DCCTMPLTNAME字段赋值，删除指定DCCTMPLTNAME的记录；给DCCTMPLTNAME、PRIORSEC和OCSGRPNAME字段赋值，删除满足条件的记录。

#### 注意事项

- 该命令执行后只对新激活用户生效。
- 删除OCS组绑定关系后，对应新激活在线计费用户立即生效，可能导致该用户激活失败。
- 删除OCS组绑定关系后，对应已经选择该OCS组中的OCS服务器的在线计费用户，如果链路正常的话，仍然会选择该OCS服务器发送消息。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                              |
|:-------------|:--------|:------------------------------------------------------------------------------------------------------------------|
| DCCTMPLTNAME | DCC模板名称 | 可选必选说明：必选参数 参数含义：该参数用于指定操作的DCC在线计费模板的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无                           |
| PRIORSEC     | 主备用标记   | 可选必选说明：可选参数 参数含义：该参数用于指定OCS组的主备标记。 数据来源：本端规划 取值范围：枚举类型。 PRIMARY：表示该服务器是主用服务器。SECONDARY：表示该服务器是备用服务器。 默认值：无 配置原则：无 |
| OCSGRPNAME   | OCS组名   | 可选必选说明：可选参数 参数含义：该参数用于指定OCS组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格。 默认值：无 配置原则：无                              |

#### 使用实例

删除OCS组绑定关系（DCC模板为dcc1，OCS组为ocsgroup1，服务器为主用），命令为：

```
RMV OCSGRPBINDING: DCCTMPLTNAME="dcc1", PRIORSEC=PRIMARY, OCSGRPNAME="ocsgroup1";
```
