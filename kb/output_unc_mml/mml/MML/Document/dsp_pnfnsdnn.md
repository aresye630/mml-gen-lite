# 显示对端NF实例支持的网络切片和DNN（DSP PNFNSDNN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、AMF、SMF、NSSF、GGSN、SMSF、NCG、SGW-C、CBC、CBCF**

查询对端NF实例支持的网络切片和DNN。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                           |
|:-------|:--------|:-------------------------------------------------------------------------------------------------------------------------------|
| SST    | 切片/服务类型 | 可选必选说明：必选参数  参数含义：该参数用于指定对端NF的切片/服务类型。  数据来源：本端规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无                                        |
| SD     | 切片分类器   | 可选必选说明：可选参数  参数含义：该参数用于指定对端NF的切片区分码。如果切片需要进一步细化子切片可配置该参数。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~8。  默认值：无  配置原则：  该值若不设置，默认值为FFFFFF。 |

## 使用实例

运营商A需要显示对端NF实例支持的网络切片和DNN，NF实例标识为SMF\_Instance\_0。

```
%%DSP PNFNSDNN: SST=1, SD="1";%%
RETCODE = 0 操作成功

结果如下
------------------------
        对端NF的切片索引  =  3
对端NF的数据网络名称索引  =  334
              NF实例标识  =  nf1
           切片/服务类型  =  1
              切片分类器  =  1
            数据网络名称  =  dnn1
          优先级功能开关  =  继承
                  优先级  =  0
            容量功能开关  =  继承
                    容量  =  0
                切片描述  =  desc1
（结果个数 = 1）

---    END
```

## 输出结果说明

| 输出项名称         | 输出项解释                                                                          |
|:--------------|:-------------------------------------------------------------------------------|
| 对端NF的切片索引     | 该参数用于指定ADD PNFNS配置的对端NF实例支持的DNN的归属切片的索引。                                       |
| 对端NF的数据网络名称索引 | 该参数用于指定ADD PNFDNN配置的对端NF实例支持的数据网络名称的索引。                                        |
| NF实例标识        | 该参数用于指定对端NF实例标识。                                                               |
| 切片/服务类型       | 该参数用于指定对端NF的切片/服务类型。                                                           |
| 切片分类器         | 该参数用于指定对端NF的切片区分码。如果切片需要进一步细化子切片可配置该参数。                                        |
| 数据网络名称        | 该参数用于指定对端NF实例支持的数据网络名。                                                         |
| 优先级功能开关       | 该参数用于指定对端UPF实例支持的DNN与其归属切片为条件的优先级选择功能是否启用。 取值说明： INHERIT（继承）SPECIFIC（指定）       |
| 优先级           | 本参数用于指定对端UPF实例支持的DNN与其归属切片为条件的优先级。在UPF选择过程的优选阶段中，会按照优先级高低排序待选列表，结合其他优选条件做综合选择。 |
| 容量功能开关        | 该参数用于指定对端UPF实例支持的DNN与其归属切片为条件的权重选择功能是否启用。 取值说明： INHERIT（继承）SPECIFIC（指定）        |
| 容量            | 本参数用于指定对端UPF实例支持的DNN与其归属切片为条件的相对权重。特别地，如果NF容量的绝对值不超过本参数的取值范围，那么本参数可以直接取用容量绝对值。 |
| 切片描述          | 该参数用于指定描述信息。                                                                   |
