#### 命令功能

**适用NF：NCG**

该命令用于查询NCG RU上的业务模块信息。

常见的查询方式有：

不输入参数，查询RU上添加的所有模块信息。

输入“模块名”参数，查询指定业务模块信息。

输入“接入网元分组标识”参数，查询与指定网元分组标识关联的所有业务模块信息。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                         |
|:-------|:---------|:---------------------------------------------------------------------------------------------|
| MNAME  | 模块名      | 可选必选说明：可选参数 参数含义：用于表示一个业务模块对象，全局唯一。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～15。 默认值：无 配置原则：无           |
| AGID   | 接入网元分组标识 | 可选必选说明：可选参数 参数含义：用于区分不同域的接入网元。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：无                |
| RUROLE | RU角色     | 可选必选说明：可选参数 参数含义：用于指定当前RU角色。 数据来源：本端规划 取值范围：枚举类型。 CONVERGE：汇聚RU。SERVICE：业务RU。 默认值：无。 配置原则：无。 |

#### 使用实例

查询RU上添加的业务模块，示例如下：

```
LST MODULE:;
```

```
RETCODE = 0  操作成功。

结果如下:
--------
          模块名  =  AP66_1
接入网元分组标识  =  PS_GROUP_1
          RU角色  =  NULL
(结果个数 = 1)
---    END
```
