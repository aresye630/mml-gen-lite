# 查询HTTP本端实体组（LST HTTPLEGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询HTTP本端实体组。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                   |
|:-------|:-------|:---------------------------------------------------------------------------------------|
| INDEX  | 索引     | 可选必选说明：可选参数  参数含义：该参数用于指定HTTP本端实体组的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~64。  默认值：无  配置原则：无 |

## 使用实例

- 若想查询一组索引为1的HTTP本端实体组的相关信息：

  ```
  %%LST HTTPLEGRP: INDEX=1;%%
  RETCODE = 0  操作成功

  结果如下
  --------
  索引  =  1
  描述  =  AMF
  (结果个数 = 1)

  ---    END
  ```
- 若想查询所有的配置的HTTP本端实体组的相关信息：

  ```
  %%LST HTTPLEGRP:;%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
  索引  描述  

  1      AMF          
  3      NRF          
  4      NSSF         
  5      BSF          
  (结果个数 = 4)

  ---    END
  ```

## 输出结果说明

| 输出项名称   | 输出项解释                |
|:--------|:---------------------|
| 索引      | 该参数用于指定HTTP本端实体组的索引。 |
| 描述      | 该参数用于指定HTTP本端实体组的描述。 |
