# 删除原因值映射配置(RMV CAUSEMAP)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于删除一个原因值映射配置记录。原因值映射就是将原接口消息中的原因值直接映射到目标接口消息中下发的原因值。

#### 注意事项

- 该命令执行后立即生效。
- 当删除一个CAUSEMAP时，不会影响GMMPROCTRL，PMMPROCTRL，EMMPROCTRL，GBSMPROCTRL，IUSMPROCTRL命令的设置。
- 执行该命令，可能会改变通过该映射配置进行原因值控制的异常场景中下发给终端的拒绝原因值，从而导致相应拒绝类话统指标的变化。
- 当软参“BYTE\_EX\_B86”BIT5、“BYTE\_EX\_B86”BIT6、“BYTE\_EX\_B86”BIT7、“BYTE\_EX\_B86”BIT8、“BYTE\_EX\_B87”BIT1、“BYTE\_EX\_B87”BIT2中的任意一个设置为“1”时，如果使用了该配置，进行配置增删改操作时需要同时考虑软参控制的场景。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                                                                                              |
|:-----------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CAUSEGRPID | 原因值组标识  | 可选必选说明：必选参数 参数含义：该参数用于指定表示一个原因值映射规则集合的唯一数字ID。 取值范围：1～127 默认值：无  说明： 所删除原因值组标识必须在CAUSEGRP中存在，否则系统提示没有此原因值标识。建议在RMV CAUSEMAP之前可以先执行LST CAUSEGRP来确定“CAUSEGRPID”是否存在。 |
| CAUSERANGE | 原因值范围   | 可选必选说明：必选参数 参数含义：该参数用于指定原因值范围。 取值范围： “DEFAULT(缺省)”“SPECIAL(特定)” 默认值：无                                                                                             |
| BGCAUSE    | 起始原始原因值 | 可选必选说明：条件必选参数 参数含义：该参数用于指定起始原始原因值。 前提条件：该参数在“CAUSERANGE(原因值范围)”设置为“SPECIAL(特定)”时，才需要配置。 取值范围：1～65535 默认值：无                                                        |

#### 使用实例

删除CAUSEGRPID（原因值组标识）为126，CAUSERANGE（原因值范围）为DEFAULT（缺省）的原因值映射记录：

RMV CAUSEMAP: CAUSEGRPID=126, CAUSERANGE=DEFAULT;
