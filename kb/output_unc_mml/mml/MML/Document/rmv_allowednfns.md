# 删除NF或NF服务支持的切片（RMV ALLOWEDNFNS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、NRF、NSSF、NCG、CBC、CBCF**

该命令用于删除NF或NF服务实例支持的服务切片信息。当NF或NF服务实例不再支持为某个切片服务时，需要对切片进行删除。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                             |
|:-------|:-------|:---------------------------------------------------------------------------------|
| INDEX  | 索引标识   | 可选必选说明：必选参数  参数含义：本参数用于指定索引标识。  数据来源：全网规划  取值范围：整数类型，取值范围是0~2047。  默认值：无  配置原则：无 |

## 使用实例

运营商A需要删除索引标识为0的服务切片的支持。

```
RMV ALLOWEDNFNS: INDEX=0;
```
