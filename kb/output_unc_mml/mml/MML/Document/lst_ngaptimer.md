# 查询N2定时器参数（LST NGAPTIMER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询N2定时器参数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询N2定时器参数，执行如下命令：

```
%%LST NGAPTIMER:;%%
RETCODE = 0  操作成功

结果如下
------------------------
基站释放广播会话超时时长(秒)  =  4
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称           | 输出项解释                                        |
|:----------------|:---------------------------------------------|
| 基站释放广播会话超时时长(秒) | 该参数用于指定基站主动发起广播会话释放请求后，AMF通知基站释放广播会话需要等待的时长。 |
