# 删除PLMN计费配置(RMV CHGPLMNCFG)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用来删除话单生成策略配置信息。

#### 注意事项

该命令执行后立即生效。执行后会影响新激活用户的话单生成策略。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                               |
|:---------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：必选参数 参数含义：该参数用于指定所包含的用户范围。 取值范围：“ALL_USER（所有用户）”“CELL_PLMNID（指定CELL_PLMNID）” 默认值：无                                                                                                          |
| MCC      | 移动国家码  | 可选必选说明：条件必选参数 参数含义：该参数用于表示PLMN的移动国家号码。 取值范围：位数为3的十进制数字 默认值：无                                                                                                                                       |
| MNC      | 移动网号   | 可选必选说明：条件必选参数 参数含义：该参数用于表示PLMN的移动网号码。 取值范围：位数为2或3的十进制数字 默认值：无                                                                                                                                      |
| APNNI    | APNNI  | 可选必选说明：必选参数 参数含义：该参数用于指定APN网络标识。 取值范围：1～62位字符串 默认值：无  说明： APN网络标识地址由一个或多个LABEL构成，各LABEL间用“.”间隔。每个LABEL的构成字符只能是字母A～Z或a～z、数字0～9和中划线“-”，字母不区分大小写。APN网络标识地址不能以“rac”、“lac”、“sgsn”或“rnc”开头，不能以“.gprs”结尾。 |

#### 使用实例

删除SUBRANGE= CELL\_PLMNID，MCC="123", MNC="001"，APNNI="huawei"的话单生成策略：

RMV CHGPLMNCFG: SUBRANGE=CELL\_PLMNID, MCC="123", MNC="001", APNNI="huawei";
