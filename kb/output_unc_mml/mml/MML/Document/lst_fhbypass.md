# 查询失败旁路处理配置（LST FHBYPASS）

- 命令功能

#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

该命令用来查看当前的全局旁路设置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询当前的全局旁路设置：

```
LST FHBYPASS:;
```
