# 删除UE-TNLA（RMV UETNLA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除UE-TNLA。NG-RAN与AMF之间支持多偶联，UE-TNLA表示UE与传输偶联之间的关联关系。该命令仅用于测试场景。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                           |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------|
| IMSI   | IMSI   | 可选必选说明：必选参数  参数含义：该参数用于指定被删除UE-TNLA的用户IMSI。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~15。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无 |

## 使用实例

删除IMSI为460071104000955的用户的UE-TNLA，执行如下命令：

```
RMV UETNLA:  IMSI="460071104000955";
```
