# 查询OSPFv3 GTSM配置（LST OSPFV3GTSM）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询OSPFv3 GTSM配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                             |
|:--------|:-------|:-----------------------------------------------------------------|
| VRFNAME | VPN实例名 | 可选必选说明：可选参数 参数含义：VPN实例名。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 |
| TTL     | TTL值   | 可选必选说明：可选参数 参数含义：TTL值。 数据来源：本端规划 取值范围：整数类型，取值范围为1～255。 默认值：无     |

#### 使用实例

查询OSPFv3 GTSM配置：

```
LST OSPFV3GTSM:;
```

```
RETCODE = 0  操作成功。

结果如下
------------------------
VPN实例名  =  _public_
    TTL值  =  10
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                |
|:--------|:---------------------|
| VPN实例名  | 该参数指定虚拟专用网(VPN)实例名称。 |
| TTL值    | 该参数指定TTL值。           |
