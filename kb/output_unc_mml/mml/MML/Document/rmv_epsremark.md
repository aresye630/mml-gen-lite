# 删除EPS QoS到TOS/DSCP的映射规则（RMV EPSREMARK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C**

该命令用来恢复在SAE架构下，QoS参数到IP DSCP（区别服务编码点）/TOS（服务类型）的映射配置。

## 注意事项

命令执行后只对新接入用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称          | 参数说明                                                                                                                                                                                    |
|:---------------|:--------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| QOSPROFILENAME | QoS Profile名称 | 可选必选说明：必选参数  参数含义：该参数指定QoS Profile的名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。不区分大小写。  默认值：无  配置原则：  QOSPROFILENAME字段值必须先在QOSPROFILE或QOSGLOBAL对象中添加成功，可以通过LST QOSPROFILE或LST QOSGLOBAL命令查询。 |
| QCI            | QCI           | 可选必选说明：必选参数  参数含义：该参数表示QoS流量级别。  数据来源：全网规划  取值范围：整数类型，取值范围是1~255。  默认值：无  配置原则：无                                                                                                        |
| ARPPL          | ARP的优先级别      | 可选必选说明：必选参数  参数含义：该参数表示ARP的优先级别。  数据来源：全网规划  取值范围：整数类型，取值范围是0~15。  默认值：无  配置原则： 0：General，通用用户。如果某业务级别各个优先级的用户都没有配置DSCP，则用General配置的值。1~15：用户的优先级，其中1的优先级最高。                            |

## 使用实例

删除Qos Profile名称为“qosprofile1”，QCI为“1”，ARP Priority Level为“15”的配置实例：

```
RMV EPSREMARK: QOSPROFILENAME="qosprofile1", QCI=1, ARPPL=15;
```
