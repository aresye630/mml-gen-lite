# 增加APN计费属性(ADD CHGAPN)

#### 命令功能

**适用网元：SGSN**

该命令用于配置基于APN的计费属性信息。当要求忽略HLR签约的APN计费属性时（通过命令**SET CHGCDR**设置参数“IGNOREFLG”的取值），可以用该命令根据APN配置其计费属性。

#### 注意事项

- 该命令执行后立即生效，但该配置只对之后激活的用户有效。
- 本表最大记录数为1000。
- 各记录的APNNI字段不能重复。
- S-CDR中填写的计费属性按照如下的优先等级进行选择：

  1. 通过**LST CHGGNCCCFG** 查看按照用户的IMSI匹配上的“SPECIAL\_USER(指定用户)”的记录，如果没有匹配的“SPECIAL\_USER(指定用户)”的记录则查看“ALL\_USER(所有用户)”的记录，其中的“S-CDR中的计费属性”参数取值如果为是，则表示S-CDR中填写的计费属性必须与发送给GGSN的计费属性保持一致，否则按本优先级列表选择下一项。
  2. APN级签约数据中的计费属性，可通过**SET CHGCDR**命令的“IGNOREFLG”参数配置忽略APN级签约计费属性。如果根据“IGNOREFLG”参数的取值，该用户忽略APN级签约计费属性，则按本优先级列表选择下一项。如果HLR中该用户未签约APN级计费属性，或该用户签约的APN级计费属性为无效值，也按本优先级列表选择下一项。
  3. 忽略APN级签约计费属性情况下，**ADD CHGAPN**命令配置的计费属性，通过**LST CHGAPN**命令查看。如果该PDP的APNNI没有对应的配置，则按本优先级列表选择下一项。
  4. 用户级签约数据中的计费属性，可通过**SET CHGCDR**命令的“IGNOREFLG”参数配置忽略用户级签约计费属性。如果根据“IGNOREFLG”参数的取值，该用户忽略用户级签约计费属性，则按本优先级列表选择下一项。如果HLR中该用户未签约用户级计费属性，或该用户签约的用户级计费属性为无效值，也按本优先级列表选择下一项。
  5. 不忽略APN级签约计费属性情况下，**ADD CHGAPN**命令配置的计费属性，通过**LST CHGAPN**命令查看，如果该PDP的APNNI没有对应的配置，则按本优先级列表选择下一项。
  6. **ADD CHGDCHAR**命令配置的计费属性，此命令只对外网用户生效，包括漫游用户和拜访用户。通过**LST CHGDCHAR**命令查看，如果按照用户类型、移动国家码、移动网号，该外网用户没有对应的配置，则按本优先级列表选择下一项。
  7. **SET CHGCDR**命令配置的计费属性。
- M-CDR中填写的计费属性按照如下的优先等级进行选择：
  1. 用户级签约数据中的计费属性，可通过**SET CHGCDR**命令的“IGNOREFLG”参数配置忽略用户级签约计费属性。如果根据“IGNOREFLG”参数的取值，该用户忽略用户级签约计费属性，则按本优先级列表选择下一项。如果HLR中该用户未签约用户级计费属性，或该用户签约的用户级计费属性为无效值，也按本优先级列表选择下一项。
  2. **ADD CHGDCHAR**命令配置的计费属性，此命令只对外网用户生效，包括漫游用户和拜访用户。通过**LST CHGDCHAR**命令查看，如果按照用户类型、移动国家码、移动网号，该外网用户没有对应的配置，则按本优先级列表选择下一项。
  3. **SET CHGCDR**命令配置的计费属性。
- SGSN发送给GGSN的计费属性由CHGGNCCCFG配置进行控制，请参考**ADD CHGGNCCCFG**。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                  |
|:-------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APNNI  | APN网络标识 | 可选必选说明：必选参数 参数含义：该参数用于指定APN网络标识。 数据来源：整网规划 取值范围：长度不超过62的字符串 默认值：无 配置原则：APN网络标识地址由一个或多个LABEL构成，各LABEL间用“.”间隔。每个LABEL的构成字符只能是字母A～Z或a～z、数字0～9和中划线“-”。APN网络标识地址不能以“rac”、“lac”、“sgsn”或“rnc”开头，不能以“.gprs”结尾。  说明： 按照3GPP协议，APN网络标识不区分大小写。为统一格式起见，APN网络标识的字母部分全部以大写格式保存。                                                                     |
| CC     | 计费属性    | 可选必选说明：可选参数 参数含义：该参数用于指定当忽略HLR签约的APN计费属性时，应该对该APN的用户按何种计费方式收费。 数据来源：整网规划 取值范围：“NORMAL(普通计费)”：表示普通计费属性，按照此种方式计费的用户按照常规的方式支付费用。“PREPAID(预付费)”：表示预付费计费属性，按照此种方式计费的用户在获取某种服务之前需要预支付一定的费用。“FLATRATE(包月制)”：表示包月制计费属性，按照此种方式计费的用户在一个月内的收费是固定的。“HOTBILLING(实时计费)”：表示实时计费属性，按照此种方式计费的用户将在短时间或流量达到某个值时及时生成话单，保证运营商对此类用户及时收费。 默认值：“NORMAL(普通计费)” |

#### 使用实例

配置APNNI为"huawei1.com"的用户的计费属性为预付费：

ADD CHGAPN: APNNI="huawei1.com", CC=PREPAID;
