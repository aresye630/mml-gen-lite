# 删除QoS监测规则（RMV QOSMONTRULE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于删除QoS监测规则。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

删除IMSI为"460030123456789"的QoS监测：

```
RMV QOSMONTRULE:MATCHMODE=IMSI,IMSI="460030123456789";
```
