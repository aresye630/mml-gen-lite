# 设置QoS PHB（SET QOSPHB）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

当接口上使能简单流分类，并且报文在接口下行转发检查PHB时，可以使用该命令配置当前域的下行IP报文的服务等级和颜色映射成对应的DSCP值，或者下行VLAN报文在路由器内部的服务等级和报文颜色对应路由器外部的802.1p的值。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                   |
|:-------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DSNAME       | DS域名   | 可选必选说明：必选参数 参数含义：该参数用于指定差分服务域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则： 区分大小写，不支持空格。需要先使用ADD QOSDIFFERSERV命令配置DS域。                                             |
| PHBTYPE      | PHB类型  | 可选必选说明：必选参数 参数含义：该参数用于指定修改的差分服务域下行映射类型。 数据来源：本端规划 取值范围：枚举类型。 8021p：对出方向的VLAN报文8021p值进行修改。ip_dscp：对出方向的IP报文DSCP(差分服务码点)值进行修改。mpls_exp：对出方向的MPLS报文EXP(实验比特位)值进行修改。 默认值：无 |
| PHBVALUE     | PHB值   | 可选必选说明：必选参数 参数含义：该参数用于指定需要映射的优先级。 数据来源：本端规划 取值范围：整数类型，取值范围为0～63。802.1p的取值范围是0到7;DSCP值的范围是0到63。取值越大优先级越高。 默认值：无                                                         |
| SERVICECLASS | 服务分类   | 可选必选说明：必选参数 参数含义：该参数用于指定映射前的内部服务等级。 数据来源：本端规划 取值范围：枚举类型。 be：尽力而为。af1：确保转发等级1。af2：确保转发等级2。af3：确保转发等级3。af4：确保转发等级4。ef：加速转发。cs6：类选择码6。cs7：类选择码7。 默认值：无                    |
| COLOR        | 颜色分类   | 可选必选说明：必选参数 参数含义：该参数用于指定映射前报文的着色。 数据来源：本端规划 取值范围：枚举类型。 green：报文颜色，绿色报文的丢弃优先级最低。yellow：报文颜色，黄色报文的丢弃优先级介于绿色红色之间。red：报文颜色，红色报文的丢弃优先级最高。 默认值：无                             |

#### 使用实例

修改DS域default的路由器内部服务等级be，报文着色为green的下行VLAN报文，映射为外部优先级3：

```
SET QOSPHB:DSNAME="default",PHBTYPE=8021p,PHBVALUE=3,SERVICECLASS=be,COLOR=green;
```
