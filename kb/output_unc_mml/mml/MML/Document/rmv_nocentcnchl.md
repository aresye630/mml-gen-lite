# 删除RU通道过滤规则（RMV NOCENTCNCHL）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：NCG**

该命令用于删除RU对应的通道过滤规则。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                   |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------------|
| RUID    | RU的ID  | 可选必选说明：必选参数 参数含义：RU的ID。 数据来源：本端规划 取值范围：整数类型，取值范围为64～4294967294。 默认值：无 配置原则：该值需要执行LST SERVICERUSTATE命令，查询出存在的RU ID进行填写。 |
| CHLNAME | 通道名称   | 可选必选说明：必选参数 参数含义：通道名称的取值为具体的通道名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则： 通道名称需要通过执行DSP FEMPACKET来获取。             |

#### 使用实例

删除RUID为64，通道名称为00/ABNORMAL的过滤规则，示例如下：

```
RMV NOCENTCNCHL: RUID=64, CHLNAME="00/ABNORMAL";
```
