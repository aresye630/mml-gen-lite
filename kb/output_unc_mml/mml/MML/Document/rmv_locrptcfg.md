# 删除位置上报配置信息(RMV LOCRPTCFG)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于删除位置上报配置信息记录。

#### 注意事项

该命令执行后对修改配置前的上报任务不影响。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称                | 参数说明                                                                                                                                                                                                                                                        |
|:-------|:--------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RANGE  | 对端设备范围              | 可选必选说明：必选参数 参数含义：该参数用于指定需要位置上报配置信息的对端设备GGSN/P-GW范围。 数据来源：整网规划 取值范围：“ALL_GGSN/P-GW（所有GGSN/P-GW）”“HOME_GGSN/P-GW（本网GGSN/P-GW）”“FOREIGN_GGSN/P-GW（外网GGSN/P-GW）”“SPECIFIC_GGSN/P-GW（指定IP的GGSN/P-GW）” 默认值： 无 配置原则： “ALL_GGSN/P-GW（所有GGSN/P-GW）”的记录不能被删除。         |
| IPT    | IP地址类型              | 可选必选说明：条件必选参数 参数含义：该参数用于指定GGSN/P-GW信令面IP地址类型。 前提条件：只有在“RANGE”配置为“SPECIFIC_GGSN/P-GW（指定IP的GGSN/P-GW）”时，该参数有效。 数据来源：整网规划 取值范围：“IPV4(IPV4)”“IPV6(IPV6)” 默认值：无                                                                                                  |
| GWIPV4 | GGSN/P-GW的信令面IPv4地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定GGSN/P-GW信令面IPv4地址。 前提条件：只有在“IPT”配置为“IPV4”时，该参数有效。 数据来源：整网规划 取值范围：0.0.0.1～255.255.255.254 默认值：无  说明： 有效IPv4地址不能为0.0.0.0、255.255.255.255和环回地址（127.x.y.z）。有效的IPv4地址必须是A、B或者C类地址。                                                    |
| MASKV4 | 掩码                  | 可选必选说明：条件必选参数 参数含义：该参数用于指定对端GGSN/P-GW的信令面IPv4地址的掩码。 前提条件：只有在“IPT”配置为“IPV4”时，该参数有效。 数据来源：整网规划 取值范围：0.0.0.0～255.255.255.255 默认值： 无  说明： “0.0.0.0”是无效掩码。输入的掩码要求对应的二进制值1和1之间不允许存在0。例如：“255.255.0.0”是有效掩码；“123.123.123.123”是无效掩码。因为123对应的二进制为“1111011”，1之间存在0。   |
| GWIPV6 | GGSN/P-GW的信令面IPv6地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定GGSN/P-GW信令面IPv6地址。 前提条件：只有在“IPT”配置为“IPV6”时，该参数有效。 数据来源：整网规划 取值范围：::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无  说明： IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址（::1）、链路本地地址（FE80::/10）和组播地址（FF00::/8）。 |
| MASKV6 | 子网前缀长度              | 可选必选说明：条件必选参数 参数含义：该参数用于指定子网前缀的长度。 前提条件：只有在“IPT”配置为“IPV6”时，该参数有效。 数据来源：整网规划 取值范围：1～128（数值型） 默认值： 无                                                                                                                                                          |

#### 使用实例

删除本网GGSN/P-GW的数据：

RMV LOCRPTCFG: RANGE=HOME\_GGSN/P-GW;

删除特定IP地址GGSN/P-GW的数据：

RMV LOCRPTCFG: RANGE=SPECIFIC\_GGSN/P-GW, IPT=IPV4, GWIPV4="10.10.10.10", MASKV4="255.255.0.0";
