#### 命令功能

**适用网元：MME**

该命令用于显示MME群组。

#### 注意事项

- 此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称    | 参数说明                                                           |
|:---------|:--------|:---------------------------------------------------------------|
| MMEGPIDX | MME群组索引 | 可选必选说明：可选参数 参数含义：该参数用于指定MME群组索引。 数据来源：全网规划 取值范围：0～63 默认值：无     |
| MCC      | 移动国家码   | 可选必选说明：可选参数 参数含义：该参数用于指定移动国家码 数据来源：全网规划 取值范围：3位十进制数 默认值：无      |
| MNC      | 移动网号    | 可选必选说明：可选参数 参数含义：该参数用于指定移动网号。 数据来源：全网规划 取值范围：位数为2或3的十进制数 默认值：无 |
| MMEGI    | MME组识别码 | 可选必选说明：可选参数 参数含义：该参数用于指定MME组识别码。 数据来源：全网规划 取值范围：4位16进制编码 默认值：无 |

#### 使用实例

查询所有MME群组配置记录

`LST MMEGP:;`

```
%%LST MMEGP:;%%
RETCODE = 0  操作成功。

输出结果如下
--------------
MME群组索引  =  1
 移动国家码  =  123
   移动网号  =  001
MME组识别码  =  0001
   描述信息  =  NULL
(结果个数 = 1)

---    END
```
