# 修改MVNO功能配置信息(MOD MVNOFUN)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

此命令用于修改这个MVNO用户功能信息。

#### 注意事项

此命令执行后立即生效。

#### 本地用户权限

manage-ug;system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称        | 参数说明                                                                                                                                                                            |
|:-------|:------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MVNOID | MVNO标识      | 可选必选说明：必选参数 参数含义：该参数用于表示修改这个MVNO用户的功能配置。 数据来源：整网规划 取值范围：1～64 建议值：无                                                                                                              |
| SMS    | 是否支持短消息     | 可选必选说明：可选参数 参数含义：该参数用于表示此MVNO用户是否支持短消息业务。 数据来源：整网规划 取值范围：“NO(否)”“YES(是)” 建议值：无 配置原则：如果填写“YES(是)”，此MVNO用户可以使用短消息业务。如果填写“NO(否)”，系统将限制此MVNO用户不能使用短消息业务。                            |
| LCS    | 是否支持LCS     | 可选必选说明：可选参数 参数含义：该参数用于表示此MVNO用户是否支持LCS业务。 数据来源：整网规划 取值范围：“NO(否)”“YES(是)” 建议值：无 配置原则：如果填写“YES(是)”，此MVNO用户可以使用LCS业务。如果填写“NO(否)”，系统将限制此MVNO用户不能使用LCS业务。                            |
| CMP    | 是否支持SNDCP压缩 | 可选必选说明：可选参数 参数含义：该参数用于表示此MVNO用户是否支持Gb接口的SNDCP压缩功能。 数据来源：整网规划 取值范围：“NO(否)”“YES(是)” 建议值：无 配置原则：如果填写“YES(是)”，此MVNO用户可以使用Gb接口的SNDCP压缩功能。如果填写“NO(否)”，系统将限制此MVNO用户不能使用Gb接口的SNDCP压缩功能。 |

#### 使用实例

修改标识为1的MVNO的功能，支持SMS功能：

MOD MVNOFUN: MVNOID=1, SMS=YES;
