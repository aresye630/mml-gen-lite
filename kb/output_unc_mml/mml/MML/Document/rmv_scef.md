# 删除SCEF配置(RMV SCEF)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于删除SCEF配置。

#### 注意事项

- 此命令执行后立即生效。
- 删除后，将导致系统无法找到指定的SCEF。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称    | 参数说明                                                            |
|:--------|:--------|:----------------------------------------------------------------|
| SCEFHTN | SCEF主机名 | 可选必选说明：必选参数 参数含义：该参数用于指定SCEF主机名。 数据来源：对端协商 取值范围：1~127位字符串 默认值：无 |

#### 使用实例

删除SCEF配置：

RMV SCEF: SCEFHTN="scef0701.huawei01.com";
