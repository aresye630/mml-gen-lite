# 查询定时器全局信息（DSP MSSTIMERINFOHEAD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询定时器全局信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                          |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------|
| RUNAME | RU名称   | 可选必选说明：必选参数 参数含义：该参数用于表示该参数用于指定RU名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：使用DSP RU查看RU名称。 |

#### 使用实例

查询定时器全局信息：

```
DSP MSSTIMERINFOHEAD:RUNAME = "VNODE_VNRS_VNFC_IPU_0064";
```

```
RETCODE = 0  操作成功。

结果如下
-------------------------
              定时器总数  =  8192
      当前使用定时器数量  =  6
              定时器峰值  =  6
          启动定时器次数  =  6
          停止定时器次数  =  0
同一时刻触发的定时器峰值  =  12
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称        | 输出项解释             |
|:-------------|:------------------|
| 定时器总数        | 用于表示定时器总数。        |
| 当前使用定时器数量    | 用于表示当前使用定时器数量。    |
| 定时器峰值        | 用于表示定时器峰值。        |
| 启动定时器次数      | 用于表示启动定时器次数。      |
| 停止定时器次数      | 用于表示停止定时器次数。      |
| 同一时刻触发的定时器峰值 | 用于表示同一时刻触发的定时器峰值。 |
