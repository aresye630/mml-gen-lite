# 显示属性值信息（DSP DEVATTRCACHE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示资源单元上指定组件的设备属性信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                           |
|:----------------|:-------|:---------------------------------------------------------------------------------------------------------------|
| COMPTYPE        | 组件类型   | 可选必选说明：必选参数。 参数含义：该参数表示组件类型。 数据来源：本端规划。 取值范围：枚举类型，LDEVM：LDEVM组件，该组件用于给APP提供设备属性订阅功能。 默认值：无                     |
| DEVID           | 设备ID   | 可选必选说明：可选参数。 参数含义：该参数表示设备ID。 数据来源：本端规划。 取值范围：十六进制整数类型，取值范围为0x0～0xFFFFFFFF。 默认值：无                               |
| ATTRID          | 属性ID   | 可选必选说明：可选参数。 参数含义：该参数表示属性ID。 数据来源：本端规划。 取值范围：十六进制整数类型，取值范围为0x0～0xFFFFFFFF。 默认值：无                               |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数。 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划。 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

- 显示资源单元上指定组件的所有属性信息：

  ```
  DSP DEVATTRCACHE:COMPTYPE=LDEVM,SERVICEINSTANCE="vnfc";
  ```

  ```
  RETCODE = 0  操作成功

  结果如下:
  --------
  设备ID    属性ID    属性长度    超时次数    属性源PID     同步状态    属性值                               
    
  0x4       0x13      4           0           0x1           SYN         01 00 00 00  
  0x1C      0x2D      8           0           0x40          SYN         00 E4 0B 54 02 00 00 00              
  0x1D      0x2D      8           0           0x40          SYN         00 E4 0B 54 02 00 00 00              
  0x1E      0x2D      8           0           0x40          SYN         00 E4 0B 54 02 00 00 00              
  0x1F      0x2D      8           0           0x40          SYN         00 E4 0B 54 02 00 00 00 
  (结果个数 = 4)
  ---    END
  ```
- 显示资源单元上指定组件的指定设备对象的所有属性信息：

  ```
  DSP DEVATTRCACHE:COMPTYPE=LDEVM,DEVID="4",SERVICEINSTANCE="vnfc";
  ```

  ```
  RETCODE = 0  操作成功

  结果如下:
  --------
     设备ID  =  0x4
     属性ID  =  0x29
   属性长度  =  4
   超时次数  =  0
  属性源PID  =  0x1
   同步状态  =  SYN
     属性值  =  01 00 00 00
  (结果个数 = 1)
  ---    END
  ```
- 显示资源单元上指定组件的指定设备对象的某一个设备属性信息：

  ```
  DSP DEVATTRCACHE:COMPTYPE=LDEVM,DEVID="4",ATTRID="29",SERVICEINSTANCE="vnfc";
  ```

  ```
  RETCODE = 0  操作成功

  结果如下:
  --------
     设备ID  =  0x4
     属性ID  =  0x29
   属性长度  =  4
   超时次数  =  0
  属性源PID  =  0x1
   同步状态  =  SYN
     属性值  =  01 00 00 00
  (结果个数 = 1)
  ---    END
  ```

#### 输出结果说明

| 输出项名称   | 输出项解释                            |
|:--------|:---------------------------------|
| 设备ID    | 表示设备ID。                          |
| 属性ID    | 表示属性ID。                          |
| 属性长度    | 表示属性长度。                          |
| 超时次数    | 表示订阅属性无法同步时的重传超时次数。              |
| 属性源PID  | 表示属性来源组件的PID。                    |
| 同步状态    | 表示属性的同步状态。 SYN：同步态。NOT_SYN：非同步态。 |
| 属性值     | 表示属性值。                           |
