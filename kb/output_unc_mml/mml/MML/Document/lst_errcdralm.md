#### 命令功能

**适用NF：NCG**

该命令用于查询NCG上报错误话单告警时对错误话单采用的监控模式。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询NCG对错误话单的监控模式：

```
LST ERRCDRALM:;
```

```
RETCODE = 0  操作成功。

结果如下:
------------
监控模式  =  周期性
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见**SET ERRCDRALM**的参数说明。
