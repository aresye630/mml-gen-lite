# 删除DNN智能分流配置（RMV DNNSMARTPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除会话创建使用的DNN智能分流配置。

## 注意事项

- 该命令执行后立即生效。

- 删除该配置，如果用户是智能分流用户则配置中的DNN默认支持专用SMF选择功能。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                      |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
| DNN    | DNN    | 可选必选说明：必选参数  参数含义：该参数用于指定用户会话创建使用的DNN名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。可输入的字符有字母、十进制数字、“-”和“.”，并且开头和结尾只能是数字或者字母。不能出现连续两个“.”。字母大小写不敏感。  默认值：无  配置原则：无 |

## 使用实例

删除DNN“huawei.com”智能分流配置，执行如下命令：

```
RMV DNNSMARTPLCY: DNN="huawei.com";
```
