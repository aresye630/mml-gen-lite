# 删除用于策略控制的网络切片群组（RMV PLCYNSGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除应用于AM策略或者UE策略控制的网络切片群组。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                               |
|:--------|:---------|:---------------------------------------------------------------------------------------------------|
| NSGRPID | 网络切片群组标识 | 可选必选说明：必选参数  参数含义：该参数用于标识应用于AM策略或者UE策略控制参数的网络切片群组。  数据来源：本端规划  取值范围：整数类型，取值范围是1~16。  默认值：无  配置原则：无 |

## 使用实例

运营商不再需要针对群组1内的网络切片进行特殊的AM策略或者UE策略控制，故删除网络切片群组1，执行命令如下：

```
RMV PLCYNSGRP: NSGRPID=1;
```
