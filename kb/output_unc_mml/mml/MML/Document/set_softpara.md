# 设置软件参数表(SET SOFTPARA)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

请参考软件参数说明书。

**适用网元：SGSN、MME**

该命令用于配置软件参数信息。

#### 注意事项

- 该命令执行后立即生效。
- 系统初次上电运行时，会执行系统初始设置值。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                    |
|:--------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DT      | 参数类型   | 可选必选说明：必选参数 参数含义：软件参数的数据类型。 数据来源：本端规划。 取值范围：“BYTE(单字节类型)”“DWORD(无符号整数类型)”“STR(字符串类型)”“BYTE_EX(扩展单字节类型)”“DWORD_EX(扩展无符号整数类型)”“STR_EX(扩展字符串类型)”“BYTE_EX_B(扩展单字节类型B)”“DWORD_EX_B(扩展无符号整数类型B)”“STR_EX_B(扩展字符串类型B)” 系统初始设置值：无                                                                                                                                                                |
| PARANUM | 参数索引   | 可选必选说明：必选参数 参数含义：软件参数的索引。 数据来源：本端规划。 取值范围:1~512 系统初始设置值：无 配置原则：当参数类型取值为“BYTE”时，参数索引的取值范围是“1~240”。当参数类型取值为“DWORD”时，参数索引的取值范围是“1~60”。当参数类型取值为“STR”时，参数索引的取值是“1”。当参数类型取值为“BYTE_EX”时，参数索引的取值范围是“1~224”。当参数类型取值为“DWORD_EX”时，参数索引的取值范围是“1~56”。当参数类型取值为“STR_EX”时，参数索引的取值是“1”。当参数类型取值为“BYTE_EX_B”时，参数索引的取值范围是“1~464”。当参数类型取值为“DWORD_EX_B”时，参数索引的取值范围是“1~116”。当参数类型取值为“STR_EX_B”时，参数索引的取值范围是“1”。 |
| VALUE   | 参数值    | 可选必选说明：必选参数 参数含义：软件参数的取值。 数据来源：本端规划。 取值范围：当参数类型取值为“BYTE”，“BYTE_EX”或“BYTE_EX_B”时，参数值的取值范围是“0~255”。当参数类型取值为“DWORD”，“DWORD_EX”或“DWORD_EX_B”时，参数值的取值范围是“0~4294967295”。当参数类型取值为“STR”，“STR_EX”或“STR_EX_B”时，参数值的取值范围是“1~31个字符”。 系统初始设置值：0                                                                                                                                                      |

#### 使用实例

设置软参，参数类型是“BYTE”，参数索引为“181”，参数值为“3”：

`SET SOFTPARA: DT=BYTE, PARANUM=181, VALUE="3";`
