# 修改eNodeB群组(MOD ENBGP)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

此命令用于修改eNodeB群组记录。

#### 注意事项

此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                 |
|:-----------|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ENBGPID    | eNodeB群组标识 | 可选必选说明：必选参数 参数含义：该参数用于指定eNodeB群组标识。 数据来源：本端规划 取值范围：1~2048 默认值：无                                                                                                                                                                                                                                                      |
| TYPE       | 类型         | 可选必选说明：必选参数 参数含义：用于指定该eNodeB群组的类型。 数据来源：整网规划 取值范围：“ENTRY(入口)”“INSIDE(内部)” 默认值：无 配置原则：ENTRY(入口)：入口eNodeB群组用于定义在MME覆盖边界专用网络区域和高铁站候车厅配置专网入口的eNodeB群组。对于从入口eNodeB进入内部eNodeB群组覆盖区域的用户，当其驻留时长超过三倍“驻留时长（min）”时，UNC将其从该区域迁出。INSIDE(内部)：内部eNodeB群组用于定义低速区域专用网络的eNodeB群组。对于在内部eNodeB群组覆盖区域的用户，当驻留时长超过“驻留时长（min）”时，UNC将其从该区域迁出。 |
| STICK_TIME | 驻留时长（min）  | 可选必选说明：条件可选参数 参数含义：该参数用于设置UE在内部eNodeB群组覆盖区域的驻留时间阈值，当UE在区域内的驻留时间超过配置值，或者UE在该参数配置的周期内接入次数超过参数“接入次数”配置值时，UNC将其从该区域迁出。 前提条件：该参数在“TYPE（类型）”参数配置为“INSIDE(内部)”后生效。 数据来源：本端规划 取值范围：10min~120min 默认值：无                                                                                                                        |
| ACC_TIMES  | 接入次数       | 可选必选说明：条件可选参数 参数含义：该参数用于设置UE在内部eNodeB群组覆盖区域的接入次数阈值。如果在“驻留时长（min）”参数配置的时间里，UE连续接入内部eNodeB群组次数超过配置值，UNC将其从该区域迁出。 前提条件：该参数在“TYPE（类型）”参数配置为“INSIDE(内部)”后生效。 数据来源：本端规划 取值范围：0,3~100 默认值：无 配置原则：参数设置为0时，依据接入次数迁出功能不生效。                                                                                                     |
| ENBGPNAME  | eNodeB群组名称 | 可选必选说明：可选参数 参数含义：该参数用于指定eNodeB群组名称。 数据来源：本端规划 取值范围：0~32位字符串 默认值：无                                                                                                                                                                                                                                                    |

#### 使用实例

修改一个eNodeB群组，eNodeB群组标识为“1”，类型为“入口”，群组名称为“highspeed\_usercheck\_entry”:

MOD ENBGP: ENBGPID=1, TYPE=ENTRY, ENBGPNAME="highspeed\_usercheck\_entry";
