## 命令功能

该命令用于查询网元与VNFM的对接信息。

**说明** 

该命令仅在非TCA场景下支持。

## 注意事项

VNFM组网信息为IPV6+IPV4双栈场景时，该命令中的主节点IP、备节点IP为IPV6的地址信息。

## 参数说明

无。

## 使用实例

查询网元与VNFM对接信息。

```
%%LST VNFMINFO:;%%
RETCODE = 0  操作成功
操作结果如下
    VNFM地址  =  https://10.10.10.10:30000
  VNFM用户名  =  restuser_xxx
VNFM主站点IP  =  10.10.10.10
VNFM备站点IP  =  10.10.10.11
(结果个数 = 1)
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息及VNFM信息，输出结果项信息项目如表1。

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

| 输出项名称     | 输出项解释                                                                    |
|:----------|:-------------------------------------------------------------------------|
| VNFM地址    | 用于返回查询的VNFM地址，包括VNFM的浮动IP地址和端口等信息。 VNFM组网信息为IPV6+IPV4双栈场景时，IP为IPV6的地址信息。 |
| VNFM用户名   | 用于返回查询的VNFM用户名。                                                          |
| VNFM主站点IP | 用于返回查询的VNFM主节点IP地址。 VNFM组网信息为IPV6+IPV4双栈场景时，主节点IP为IPV6的地址信息。             |
| VNFM备站点IP | 用于返回查询的VNFM备节点IP地址。 VNFM组网信息为IPV6+IPV4双栈场景时，备节点IP为IPV6的地址信息。             |

|    错误码 | 错误码解释      | 原因分析                   | 处理建议         |
|-------:|:-----------|:-----------------------|:-------------|
| 150020 | 查询VNFM信息失败 | 查询相关数据到数据库操作结果为空或出现异常。 | 请联系华为技术支持处理。 |
| 150021 | 当前模式不支持此命令 | TCA场景无VNFM，不支持该命令。     | 无需处理。        |
