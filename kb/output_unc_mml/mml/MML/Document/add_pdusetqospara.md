# 增加PDU SET QOS参数（ADD PDUSETQOSPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：GGSN、SMF、PGW-C**

该命令用于增加PDU SET QOS参数。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入1000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称            | 参数说明                                                                                                                                                                                                 |
|:--------------|:----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PDUSETQOSNAME | PDU SET QOS参数名称 | 可选必选说明：必选参数  参数含义：该参数用于指定PDU SET QOS参数的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。  默认值：无  配置原则：无                                                                                                        |
| PSDB          | PDU SET QOS时延   | 可选必选说明：可选参数  参数含义：该参数用于指定PDU SET QOS的时延参数。  数据来源：本端规划  取值范围：整数类型，取值范围是0~20000000。整数类型，取值范围为0～20000000，单位是0.01毫秒。  默认值：无  配置原则：  若未配置此参数，参数默认值为非法值0。                                                  |
| PSER          | PDU Set误码率      | 可选必选说明：可选参数  参数含义：该参数用于指定PDU SET QOS的误码率参数。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。  默认值：无  配置原则：  误码率以连字号分为2段，形式为scalar x 10-k，其中scalar和k均为单位的十进制整数。例如误码率为4x10-6应当配置为"4E-6"。正则表达式为'^([0-9]E[-][0-9])$'。 |
| PSIHI         | PDU Set处理指示     | 可选必选说明：可选参数  参数含义：该参数用于指定PDU SET QOS的处理指示参数。  数据来源：本端规划 取值范围： NOT_SUPPORT（不支持）ALL_PDUS_NEEDED（需要配置）ALL_PDUS_NOT_NEEDED（无需配置）  默认值：无  配置原则：无                                                          |

## 使用实例

增加PDU SET QOS参数名称为“name1”，PDU Set误码率为“4E-6”的PDU SET QOS参数。

```
ADD PDUSETQOSPARA: PDUSETQOSNAME="name1", PSER="4E-6";
```
