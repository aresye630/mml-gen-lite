# 删除eNodeB群组成员(RMV ENBGPMEM)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于删除eNodeB群组成员记录。

#### 注意事项

- 此命令执行后立即生效。
- 此命令执行后起始eNodeB标识对应的一组记录都将被删除。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称       | 参数说明                                                                                                                                                                                     |
|:---------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ENBGPID  | eNodeB群组标识 | 可选必选说明：必选参数 参数含义：该参数用于指定eNodeB群组标识。 数据来源：本端规划 取值范围：1～2048 默认值：无                                                                                                                          |
| ENBTYPE  | eNodeB类型   | 可选必选说明：必选参数 参数含义：该参数用于指定eNodeB类型。 数据来源：整网规划 取值范围：“HOME_ENODEB(Home_eNodeB)”“MACRO_ENODEB(Macro_eNodeB)” 默认值：无                                                                            |
| MCC      | 移动国家码      | 可选必选说明：必选参数 参数含义：该参数用于指定移动国家码。 数据来源：整网规划 取值范围：3位的十进制数字 默认值：无                                                                                                                             |
| MNC      | 移动网号       | 可选必选说明：必选参数 参数含义：该参数用于指定移动网号。 数据来源：整网规划 取值范围：2～3位的十进制数字 默认值：无                                                                                                                            |
| BGNENBID | 起始eNodeB标识 | 可选必选说明：必选参数 参数含义：该参数用于指定起始eNodeB标识。 数据来源：整网规划 取值范围：0～268435455 默认值：无  说明： 若参数“eNodeB类型”取值为“HOME_ENB(HOME_ENB)”，则该参数最大取值268435455。若参数“eNodeB类型”取值为“MACRO_ENB(MACRO_ENB)”，则该参数最大取值1048575。 |

#### 使用实例

删除一个eNodeB群组，eNodeB群组标识为“1”，群组成员的eNodeB类型为“Macro\_eNodeB”，移动国家码为“456”，移动网号为“12”，起始eNodeB标识为“1234”：

RMV ENBGPMEM: ENBGPID=1, ENBTYPE=MACRO\_ENODEB, MCC="456", MNC="12", BGNENBID=1234;

RMV ENBGP: ENBGPID=1;
