# 查询RSN规则（LST RSNRULE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF**

该命令用于查询RSN规则。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                           |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| SST    | 切片业务类型 | 可选必选说明：可选参数  参数含义：该参数用于指定切片业务类型。网络切片标识（S-NSSAI）由切片业务类型（SST）和切片细分标识（SD）两部分组成，其中切片细分标识（SD）是可选的。  数据来源：本端规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无 |
| SD     | 切片细分标识 | 可选必选说明：可选参数  参数含义：该参数用于指定切片细分标识。  数据来源：本端规划  取值范围：字符串类型，输入长度是6。  默认值：无  配置原则：无                                                                 |
| DNN    | DNN    | 可选必选说明：可选参数  参数含义：该参数用于指定DNN。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~63。  默认值：无  配置原则：无                                                               |

## 使用实例

查询SST为1，SD为010101，DNN为huawei.com的RSN规则：

```
LST RSNRULE:SST=1,SD="010101",DNN="huawei.com";
```
