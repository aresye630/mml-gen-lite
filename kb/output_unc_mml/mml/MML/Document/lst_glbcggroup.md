# 查询全局CG组（LST GLBCGGROUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

本条命令用于查询全局CG组。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询全局CG组：

```
LST GLBCGGROUP:;
```

```
RETCODE = 0  操作成功

全局CG组
--------
CG组ID  =  1
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见SET GLBCGGROUP的参数说明。
