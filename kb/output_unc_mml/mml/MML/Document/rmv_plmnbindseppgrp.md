# 删除PLMN与SEPP组的绑定关系（RMV PLMNBINDSEPPGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF**

该命令用于删除PLMN与SEPP组的绑定关系。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                        |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------|
| MCC    | 移动国家码  | 可选必选说明：必选参数  参数含义：该参数用于指定移动国家码。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~3。  默认值：无  配置原则：  本参数只能由3个十进制数字组成或者配置为“*”。  |
| MNC    | 移动网号   | 可选必选说明：必选参数  参数含义：该参数用于指定移动网号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~3。  默认值：无  配置原则：  本参数只能由2~3个十进制数字组成或者配置为“*”。 |

## 使用实例

删除目标PLMN为12303与SEPP组的绑定关系。

```
RMV PLMNBINDSEPPGRP: MCC="123", MNC="03";
```
