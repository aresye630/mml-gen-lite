# 设置SMSF用户关键信息数据核查扫描参数（SET SMSFKEYCHECK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMSF**

该命令用于设置SMSF用户关键信息数据核查扫描速率和周期，以及数据有效时长。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| KEYCHECKSW   |   KEYCHECKRATE |   KEYCHECKPERIOD | VALIDTIMESW   |   VALIDTIME |
|:-------------|---------------:|-----------------:|:--------------|------------:|
| FUNC_ON      |             70 |               60 | FUNC_ON       |        1440 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称                   | 参数说明                                                                                                                                                                            |
|:---------------|:-----------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| KEYCHECKSW     | SMSF用户关键信息表核查功能开关      | 可选必选说明：可选参数  参数含义：该参数用于表示SMSF用户关键信息核查功能开关。  数据来源：本端规划 取值范围： “FUNC_ON（打开）”：功能开关打开“FUNC_OFF（关闭）”：功能开关关闭  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST SMSFKEYCHECK查询当前参数配置值。  配置原则：无   |
| KEYCHECKRATE   | SMSF用户关键信息核查速率(个每秒)    | 可选必选说明：可选参数  参数含义：该参数用于表示SMSF用户关键信息核查时的扫描速率。  数据来源：本端规划  取值范围：整数类型，取值范围是1~1000，单位是个每秒。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST SMSFKEYCHECK查询当前参数配置值。  配置原则：无                  |
| KEYCHECKPERIOD | SMSF用户关键信息核查周期(分钟)     | 可选必选说明：可选参数  参数含义：该参数用于表示SMSF用户关键信息核查扫描周期。  数据来源：本端规划  取值范围：整数类型，取值范围是1~1440，单位是分钟。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST SMSFKEYCHECK查询当前参数配置值。  配置原则：无                     |
| VALIDTIMESW    | SMSF用户关键信息有效时长开关       | 可选必选说明：可选参数  参数含义：该参数用于表示SMSF用户关键信息有效时长生效开关。  数据来源：本端规划 取值范围： “FUNC_ON（打开）”：功能开关打开“FUNC_OFF（关闭）”：功能开关关闭  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST SMSFKEYCHECK查询当前参数配置值。  配置原则：无 |
| VALIDTIME      | SMSF上用户关键信息数据的有效时长(分钟) | 可选必选说明：可选参数  参数含义：该参数用于表示SMSF上用户关键信息数据的有效时长。  数据来源：本端规划  取值范围：整数类型，取值范围是1~43200，单位是分钟。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST SMSFKEYCHECK查询当前参数配置值。  配置原则：无                  |

## 使用实例

运营商希望设置“SMSF用户关键信息表核查功能开关”为“打开”，“SMSF用户关键信息核查速率(个每秒)”为“70”，“SMSF用户关键信息核查周期(分钟)”为“60”，“SMSF用户关键信息有效时长开关”为“打开”，“SMSF上用户关键信息数据的有效时长(分钟)”为“1440”，执行如下命令：

```
SET SMSFKEYCHECK: KEYCHECKSW=FUNC_ON, KEYCHECKRATE=70, KEYCHECKPERIOD=60, VALIDTIMESW=FUNC_ON, VALIDTIME=1440;
```
