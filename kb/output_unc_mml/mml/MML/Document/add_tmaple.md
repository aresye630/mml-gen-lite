# 增加TMAP本地实体(ADD TMAPLE)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

本命令用于增加TMAP本地实体，当启用宽带集群系统时，需要配置Tm1接口本地实体。

#### 注意事项

- 该命令执行后立即生效。
- 每个接口只能配置1个IP地址。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                    |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TMINTFTP | Tm接口类型 | 可选必选说明：必选参数 参数含义：宽带集群业务Tm接口类型。 数据来源：全网规划 取值范围：“Tm1(用户会话接口)” 默认值 ：无 配置原则：Tm1接口需要配置不同的IP地址，作为本端服务IP地址，否则将配置失败。                                                                                                                                                                                                                                            |
| IPT      | IP地址类型 | 可选必选说明：必选参数 参数含义：本参数用于指定TMAP本地实体的IP地址类型。 数据来源：全网规划 取值范围：“IPV4(IPV4)”“IPV6(IPV6)” 默认值 ：无  说明： 系统暂不支持IPV6地址。                                                                                                                                                                                                                                              |
| IPV4     | IPv4地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IP地址类型”参数配置为“IPV4”后生效。 参数含义：本参数用于指定TMAP本地实体的IPv4地址。 数据来源：全网规划 取值范围：0.0.0.0~255.255.255.255 默认值 ：无 配置原则：业务地址不能配置为0.0.0.0、255.255.255.255和环回地址(127.x.y.z)。业务地址必须是A、B或者C类地址。  说明： IP地址必须在SERVICEIP表中已经配置，可以用LST SERVICEIP查询。                                                                                                       |
| IPV6     | IPv6地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IP地址类型”参数配置为“IPV6”后生效。 参数含义：本参数用于指定TMAP本地实体的IPv6地址。 数据来源：全网规划 取值范围：::~FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值 ：无 配置原则：IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址(::1)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。IP地址不能与GTPCLEGRPMEM中已配置的IP地址相同。  说明： IP地址必须在SERVICEIP表中已经配置，可以用LST SERVICEIP查询。系统暂不支持IPV6地址。 |
| VPNNAME  | VPN名称  | 可选必选说明：可选参数 参数含义：本参数用于指定TMAP本地实体对应的VPN名称。 数据来源：全网规划 取值范围：0~31位字符串 默认值 ：无  说明： VPN名称必须在SERVICEIP表中已经配置，可以用LST SERVICEIP查询。                                                                                                                                                                                                                               |
| DESC     | 描述信息   | 可选必选说明：可选参数 参数含义：本参数用于指定描述信息。 数据来源：本端规划 取值范围：0~32位字符串 默认值 ：无                                                                                                                                                                                                                                                                                            |

#### 使用实例

当现网需要启用宽带集群系统时，“Tm接口类型”为“Tm1”，“IPv4地址”为“10.10.10.1”的本地实体时，执行命令。

```
ADD TMAPLE: TMINTFTP=Tm1,IPT=IPV4, IPV4="10.10.10.1";
```
