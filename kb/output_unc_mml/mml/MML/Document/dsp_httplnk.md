# 显示HTTP链路信息（DSP HTTPLNK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示HTTP服务端链路信息，包括HTTP服务端链路的源目的IP地址和源目的端口号，以及该链路所在的POD名称和关联的资源ID等。可用于查询HTTP服务端链路的分布情况，协助定位HTTP服务端链路分布相关问题。

## 注意事项

推荐使用IP地址作为筛选条件查询。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                                                           |
|:--------|:---------|:-------------------------------------------------------------------------------------------------------------------------------|
| PODNAME | POD名称    | 可选必选说明：可选参数  参数含义：该参数用于指定HTTP服务端链路所在的POD名称。该POD名称可通过DSP HTTPPROCESS命令查询获取。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无 |
| IPTYPE  | IP类型     | 可选必选说明：可选参数  参数含义：该参数用于指定配置的地址的IP类型。  数据来源：全网规划 取值范围： “IPv4（IPv4地址）”：IPv4地址“IPv6（IPv6地址）”：IPv6地址  默认值：无  配置原则：无                |
| DSTIPV4 | 目的IPv4地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPv4"时为条件必选参数。  参数含义：该参数用于显示HTTP服务端链路的目的IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无               |
| DSTIPV6 | 目的IPv6地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPv6"时为条件必选参数。  参数含义：该参数用于显示HTTP服务端链路的目的IPv6地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无               |

## 使用实例

若运营商想要查询HTTP服务端链路信息，可使用如下命令：

```
%%DSP HTTPLNK:;%%
RETCODE = 0  操作成功

结果如下
------------------------
POD名称                  资源ID  源IPv4地址   源IPv6地址    源端口号      目的IPv4地址    目的IPv6地址     目的端口号   

sbim-pod-569ffb9dc5-nrgl6  127    172.16.0.1         ::    5001         172.16.0.2         ::            31105    
sbim-pod-569ffb9dc5-nrgl6  127    172.16.0.3         ::    5001         172.16.0.4         ::            31105    
(结果个数 = 2)

---    END
```
