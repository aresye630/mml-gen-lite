# 查询特殊随机TLLI配置(LST SPCTLLI)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用网元：SGSN**

该命令用于查询特殊RANDOM TLLI的配置记录。

#### 注意事项

- 无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                   |
|:-------|:-------|:---------------------------------------------------------------------------------------|
| TLLI   | TLLI   | 可选必选说明：可选参数 参数含义：该参数用于指定RANDOM TLLI。 数据来源：网上问题 取值范围： 0x00000000～0xffffffff(十六进制) 默认值：无 |

#### 使用实例

查询特殊RANDOM TLLI的配置记录：

**LST SPCTLLI:;**

```
%%LST SPCTLLI:;%%
RETCODE = 0  操作成功。

操作结果如下
--------------
    TLLI  =  0x71234ABC
手机信息  =  none
(结果个数 = 1)

---    END
```
