#### 命令功能

**适用NF：NCG**

该命令用于显示当前生效的格式引擎软参配置信息。该命令执行后，系统会显示当前生效的格式引擎软参信息，返回相应的格式引擎包文件名和软参信息。

在系统新安装、系统调测或者故障时，可以使用该命令进行检查。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                                                      |
|:-------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AGID   | 接入网元分组标识 | 可选必选说明：可选参数 参数含义：用于区分不同域的接入网元。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则： 该值需要执行LST CDRPROC命令查询“接入网元分组标识”。如果没有符合要求的“接入网元分组标识”，还需执行ADD CDRPROC命令增加。不能输入的特殊字符请参考“特殊字符表”。 |
| RUID   | RU的ID    | 可选必选说明：可选参数 参数含义：RU的ID。 数据来源：本端规划 取值范围：整数类型，取值范围为64～4294967294。 默认值：无 配置原则：该值需要执行LST SERVICERUSTATE命令，查询出存在的RU ID进行填写。                                                    |

#### 使用实例

查询所有模块组的格式引擎软参配置：

```
DSP FMTPKGCFG:;
```

#### 输出结果说明

| 输出项名称    | 输出项解释                                                                                                         |
|:---------|:--------------------------------------------------------------------------------------------------------------|
| 接入网元分组标识 | 用于区分不同域的接入网元。                                                                                                 |
| RU的ID    | RU的ID。                                                                                                        |
| 格式引擎包软参值 | 用于返回查询到的格式引擎软参配置的值。  说明： 在执行ADD FMTPKGCFG命令添加格式引擎包软参时，如果配置的“格式引擎软参值”为小写字母，但通过DSP FMTPKGCFG命令查询到的结果是大写，对业务无影响。 |

其余输出项请参见**ADD FMTPKGCFG**的参数说明。
