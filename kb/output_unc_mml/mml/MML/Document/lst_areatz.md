# 查询区域时区参数(LST AREATZ)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用网元：SGSN、MME**

此命令用于查询区域时区记录。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                   |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------|
| AREA   | 区域范围   | 可选必选说明：可选参数 参数含义：该参数用于指定该区域的标识类型。 取值范围： “LA(位置区)”：表示该区域标识类型为位置区。“RA(路由区)”：表示该区域标识类型为路由区。“TA(跟踪区)”：表示该区域标识类型为跟踪区。 默认值：无 |
| MCC    | 移动国家代码 | 可选必选说明：可选参数 参数含义：该参数用于指定移动国家代码。 取值范围：3位的十进制数字 默认值：无                                                                    |
| MNC    | 移动网号   | 可选必选说明：可选参数 参数含义：该参数用于指定移动网号。 取值范围：2～3位的十进制数字 默认值：无                                                                    |
| LAC    | 位置区域码  | 可选必选说明：可选参数 参数含义：该参数用于指定位置区域码 取值范围：0x0000～0xFFFF 默认值：无  说明： 该参数在“AREA(区域范围)”设置为“LA(位置区)”或“RA(路由区)”时生效。                 |
| RAC    | 路由区域码  | 可选必选说明：可选参数 参数含义：该参数用于指定路由区域码 取值范围：0x00～0xFF 默认值：无  说明： 该参数在“AREA(区域范围)”设置为“RA(路由区)”时生效。                               |
| TAC    | 跟踪区域码  | 可选必选说明：可选参数 参数含义：该参数用于指定该跟踪区域码。 取值范围：0x0000～0xFFFF 默认值：无  说明： 该参数在“AREA(区域范围)”设置为“TA(跟踪区)”时生效。                         |

#### 使用实例

查询一条“区域范围”为“LA(位置区)”，“移动国家代码”为“123”，“移动网号”为“03”，“位置区域码”为“200”的区域时区记录：

LST AREATZ: AREA=LA, MCC="123", MNC="03", LAC="200";

```
%%LST AREATZ: AREA=LA, MCC="123", MNC="03", LAC="200";%%
RETCODE = 0  操作成功。

输出结果如下
--------------
      区域范围  =  位置区
  移动国家代码  =  123
      移动网号  =  03
    位置区域码  =  0x0112
位置区域码范围  =  0x0350
    路由区域码  =  NULL
路由区域码范围  =  NULL
    跟踪区域码  =  NULL
跟踪区域码范围  =  NULL
      时区标识  =  1
(结果个数 = 1)

---    END
```

LST AREATZ:;

```
%%LST AREATZ:;%%
RETCODE = 0  操作成功。

 位置区    123           03        0x5501      0x5501          NULL        NULL            NULL        NULL            1       
 位置区    123           03        0x5502      0x5502          NULL        NULL            NULL        NULL            2
```
