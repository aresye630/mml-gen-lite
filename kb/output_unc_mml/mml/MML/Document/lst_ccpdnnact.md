# 查询融合计费Proxy基于DNN处理动作（LST CCPDNNACT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NCG**

该命令用于查询融合计费Proxy基于DNN处理动作。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                 |
|:--------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DNNTYPE | DNN类型  | 可选必选说明：可选参数  参数含义：该参数用于指定DNN的类型。  数据来源：本端规划 取值范围： DEFAULT（针对未指定的DNN设置处理动作）VALUE（针对DNN设置处理动作）  默认值：无  配置原则：无                                                                                                                          |
| DNNID   | 数据网络名称 | 可选必选说明：该参数在"DNNTYPE"配置为"VALUE"时为条件可选参数。  参数含义：该参数用于指定数据网络名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

查询融合计费Proxy基于DNN处理动作：

```
LST CCPDNNACT:;
RETCODE = 0  操作成功

结果如下
--------
          DNN类型  =  针对DNN设置处理动作
   数据网络名称  =  IMS
   是否转发OCS  =  否
(结果个数 = 1)

---    END
```
