# 修改NITZ策略（MOD NITZPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

若开启下发缺省配置UE Logo功能时，“MML命令行”中“运营商全称”和“运营商简称”参数配置错误，会影响终端UE Logo显示。

**适用NF：AMF**

该命令用于修改已配置的NITZ策略，如网络名称。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                                                                 |
|:----------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AREARANGE | 区域范围   | 可选必选说明：必选参数  参数含义：该参数用于指定AMF服务的某些区域范围。  数据来源：全网规划 取值范围： “ALL_AREA（所有区域）”：所有区域“AREA_CODE（指定区域编码）”：指定区域编码  默认值：无  配置原则：无                                                                                                                                               |
| AREACODE  | 区域编码   | 可选必选说明：该参数在"AREARANGE"配置为"AREA_CODE"时为条件必选参数。  参数含义：该参数用于唯一标识AMF服务的某个区域，该区域由一个或者若干个跟踪区组成。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~128。该区域编码必须已经通过ADD AREACODE命令添加成功，可执行LST AREACODE进行查看，区域编码中的成员由ADD AREAMEM添加。  默认值：无  配置原则：无                                               |
| SUBRANGE  | 用户范围   | 可选必选说明：必选参数  参数含义：该参数用于表示应用NITZ策略的用户群标识。  数据来源：全网规划 取值范围： “ALL_USER（所有用户）”：所有用户“HOME_USER（本网用户）”：本网用户“FOREIGN_USER（外网用户）”：外网用户“USER_GROUP（用户群）”：用户群“IMSI_PREFIX（IMSI前缀）”：指定IMSI前缀  默认值：无  配置原则：无                                                                     |
| IMSIPRE   | IMSI前缀 | 可选必选说明：该参数在"SUBRANGE"配置为"IMSI_PREFIX"时为条件必选参数。  参数含义：该参数用于指定应用NITZ策略的用户的IMSI前缀。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是5~15。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                                                                                                   |
| USRGRPID  | 用户群组标识 | 可选必选说明：该参数在"SUBRANGE"配置为"USER_GROUP"时为条件必选参数。  参数含义：该参数用于指定应用NITZ策略的用户群标识。  数据来源：全网规划  取值范围：整数类型，取值范围是0~4294967294。该用户群标识必须已经通过ADD NGUSRGRP命令添加成功，可执行LST NGUSRGRP进行查看，用户群中的用户可通过ADD NGUSRGRPMEM添加。  默认值：无  配置原则：  当USRGRPID未输入取值时，系统会为此参数赋无效值4294967295(0xFFFFFFFF)。 |
| FULLNAME  | 运营商全称  | 可选必选说明：可选参数  参数含义：该参数用于指定移动网络运营商的全称。AMF发送给UE的Configuration Update Command消息中携带的“Full name for network”信元值来源于本参数。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~255。字母大小写敏感。  默认值：无  配置原则：  输入单空格将删除该参数已有配置项。  不允许使用“NULL”作为网络名称。  当网络名称发生变化后，对于符合指定条件的用户，需要在触发一次服务请求后才会生效。         |
| SHORTNAME | 运营商简称  | 可选必选说明：可选参数  参数含义：该参数用于指定移动网络运营商的简称。AMF下发给UE的Configuration Update Command消息中携带的“Short name for network”信元值来源于本参数。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~255。字母大小写敏感。  默认值：无  配置原则：  输入单空格将删除该参数已有配置项。  不允许使用“NULL”作为网络名称。  当网络名称发生变化后，对于符合指定条件的用户，需要在触发一次服务请求后才会生效。        |
| DESC      | 描述信息   | 可选必选说明：可选参数  参数含义：该参数表示对某区域范围内应用NITZ策略的用户群的描述信息，在运维中起助记作用。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~32。  默认值：无  配置原则：  输入单空格将删除该参数已有配置项。                                                                                                                                      |

## 使用实例

针对区域编码为SomeCity的所有用户，修改网络名称的全称为ABC，简称为abc，执行如下命令：

```
MOD NITZPLCY: AREARANGE=AREA_CODE, AREACODE="SomeCity", SUBRANGE=ALL_USER, FULLNAME="ABC", SHORTNAME="abc";
```
