# 查询PLMN与SEPP组的绑定关系（LST PLMNBINDSEPPGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF、SMF**

该命令用于查询PLMN与SEPP组的绑定关系。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                        |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------|
| MCC     | 移动国家码  | 可选必选说明：可选参数  参数含义：该参数用于指定移动国家码。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~3。  默认值：无  配置原则：  本参数只能由3个十进制数字组成或者配置为“*”。  |
| MNC     | 移动网号   | 可选必选说明：可选参数  参数含义：该参数用于指定移动网号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~3。  默认值：无  配置原则：  本参数只能由2~3个十进制数字组成或者配置为“*”。 |
| GROUPID | 组号     | 可选必选说明：可选参数  参数含义：该参数用于指定SEPP组号。  数据来源：全网规划  取值范围：整数类型，取值范围是2~65。  默认值：无  配置原则：无                            |

## 使用实例

查询PLMN与SEPP组的绑定关系。

```
%%LST PLMNBINDSEPPGRP:;%%
RETCODE = 0 操作成功

结果如下
------------------------
  移动国家码 = 123
    移动网号 = 03
        组号 = 3
（结果个数 = 1）

----    END
```

| 输出项名称   | 输出项解释          |
|:--------|:---------------|
| 移动国家码   | 该参数用于指定移动国家码。  |
| 移动网号    | 该参数用于指定移动网号。   |
| 组号      | 该参数用于指定SEPP组号。 |
