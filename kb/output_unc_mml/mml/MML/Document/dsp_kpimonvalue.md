# 显示KPI检测历史数据（DSP KPIMONVALUE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示KPI检测历史数据。

## 注意事项

- 输出结果中，测量指标值后缀包含“NC”时，表示为无效指标值，包含“E”时，表示为同比检测异常指标值，包含“C”时，表示为环比检测异常指标值，包含“A”时，表示为同比和环比检测均异常的指标值。
- 命令返回的时间为UTC时间。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                     |
|:-----------|:-------|:-----------------------------------------------------------------------------------------|
| METRICTYPE | 指标类型   | 可选必选说明：必选参数  参数含义：该参数用于指定指标类型。  数据来源：本端规划 取值范围： KPI（KPI）  默认值：无  配置原则：无                  |
| METRICID   | 测量指标ID | 可选必选说明：必选参数  参数含义：该参数用于指定测量指标ID。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无 |
| MOIID      | 对象实例ID | 可选必选说明：可选参数  参数含义：该参数用于指定对象实例ID。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无     |
