# 删除S1接口用户连接(RMV USRS1CONN)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

此命令用于删除处于连接态用户的S1口链接。

#### 注意事项

- 此命令执行后立即生效。
- 仅当用户处于连接态时可以使用该命令。该命令会导致指定用户暂时中断业务，等用户再次请求业务后恢复。
- 如果用户处于非连接态时使用该命令，会导致命令执行失败。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                     |
|:----------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------|
| RMVOPTION | 删除方式   | 可选必选说明：可选参数 参数含义：待删除用户的识别码类型。 取值范围： “BYIMSI(指定IMSI)”“BYMSISDN(指定MSISDN)”“BYGUTI(指定GUTI)” 默认值：“BYIMSI(指定IMSI)”  说明： 在多IMSI功能开启的情况下，不支持根据MSISDN来删除用户S1口链接。 |
| IMSI      | IMSI   | 可选必选说明：条件必选参数 参数含义：待删除用户的国际移动用户识别码。由MCC、MNC和MSIN组成，在PLMN中唯一标识用户。 前提条件：该参数在“删除方式”配置为“BYIMSI(指定IMSI)”时生效。 取值范围：1~15位数字 默认值：无                               |
| MSISDN    | MSISDN | 可选必选说明：条件必选参数 参数含义：待删除用户的国际移动用户电话号码。由CC、NDC和SN组成，用于从CloudEPSN呼叫移动用户。 前提条件：该参数在“删除方式”配置为“BYMSISDN(指定MSISDN)”时生效。 取值范围：1~15位数字 默认值：无                       |
| GUTI      | GUTI   | 可选必选说明：条件必选参数 参数含义：该参数用于指定GUTI号。 前提条件：该参数在“删除方式”配置为“BYGUTI(指定GUTI)”后生效。 取值范围：19~20位16进制码字符串 默认值：无                                                        |

#### 使用实例

删除IMSI为123071104000955的用户的S1口连接：

RMV USRS1CONN: RMVOPTION= BYIMSI, IMSI="123071104000955";
