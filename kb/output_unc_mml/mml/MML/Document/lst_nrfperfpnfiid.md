# 查询NRF局向性能统计对象识别标识（LST NRFPERFPNFIID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NRF**

该命令用于NRF局向性能统计对象识别标识。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                |
|:-----------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| PEERNFNAME | 对端NF实例名称 | 可选必选说明：可选参数  参数含义：该参数用于表示对端网元的实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~255。  默认值：无  配置原则：  本参数的构成字符只能是字母A～Z或a～z、数字0～9、中划线"-"和下划线"_"，例如，AMF_Instance_0。 |

## 使用实例

查看NRF上对端实例名称为AMF\_Instance\_0的标识信息。

```
LST NRFPERFPNFIID: PEERNFNAME="AMF_Instance_0";
%%LST NRFPERFPNFIID: PEERNFNAME="AMF_Instance_0";%%
RETCODE = 0  操作成功

结果如下
--------
        标识索引  =  1
  对端NF实例名称  =  AMF_Instance_0
  对端NF实例标识  =  192.168.52.1
对端NF的IPV4地址  =  ::
对端NF的IPV6地址  =  NULL
(结果个数 = 1)

---    END
```
