# 触发设备对账（ACT DEVVERIFICATION）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于触发设备对账。当设备订阅信息或者属性信息发生异常时，可以使用该命令触发设备对账进行恢复。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                  |
|:----------------|:-------|:----------------------------------------------------------------------------------------------------------------------|
| VERIFYTYPE      | 对账类型   | 可选必选说明：必选参数 参数含义：用于表示对账的类型。 数据来源：本端规划 取值范围：枚举类型。 SUB：订阅信息。ATTR：属性信息。 默认值：无                                            |
| SRCPID          | 源组件ID  | 可选必选说明：必选参数 参数含义：用于表示对账的源组件ID。 数据来源：本端规划 取值范围：十六进制整数类型，取值范围为0x0～0xFFFFFFFF。 默认值：无                                     |
| DSTPID          | 目的组件ID | 可选必选说明：必选参数 参数含义：用于表示对账的目的组件ID。 数据来源：本端规划 取值范围：十六进制整数类型，取值范围为0x0～0xFFFFFFFF。 默认值：无                                    |
| DEVID           | 设备ID   | 可选必选说明：条件可选参数，该参数在“VERIFYTYPE”配置为“ATTR”时为可选参数。 参数含义：用于表示对账的设备ID。 数据来源：本端规划 取值范围：十六进制整数类型，取值范围为0x0～0xFFFFFFFF。 默认值：无   |
| ATTRID          | 属性ID   | 可选必选说明：条件可选参数，该参数在“VERIFYTYPE”配置为“ATTR”时为可选参数。 参数含义：用于表示对账的目的属性ID。 数据来源：本端规划 取值范围：十六进制整数类型，取值范围为0x0～0xFFFFFFFF。 默认值：无 |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。          |

#### 使用实例

- 对账订阅信息，指定源组件ID为FB0005，目的组件ID为80FC0012：

  ```
  ACT DEVVERIFICATION:VERIFYTYPE=SUB,SRCPID="FB0005",DSTPID="80FC0012",SERVICEINSTANCE="vnfc";
  ```
- 对账属性信息，指定源组件ID为80FC0012，目的组件ID为FB0005：

  ```
  ACT DEVVERIFICATION:VERIFYTYPE=ATTR,SRCPID="80FC0012",DSTPID="FB0005",SERVICEINSTANCE="vnfc";
  ```
- 对账属性信息，指定源组件ID为80FC0012，目的组件ID为FB0005，指定设备对象和设备属性：

  ```
  ACT DEVVERIFICATION:VERIFYTYPE=ATTR,SRCPID="80FC0012",DSTPID="FB0005",DEVID="9",ATTRID="172",SERVICEINSTANCE="vnfc";
  ```
