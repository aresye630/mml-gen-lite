# 删除PCF选择策略（RMV PCFSELPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于对指定的用户群删除PCF的选择策略。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                              |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：必选参数  参数含义：该参数用于指定应用PCF选择策略的用户范围。  数据来源：全网规划 取值范围： “ALL_USER（所有用户）”：所有用户“HOME_USER（本网用户）”：本网用户“FOREIGN_USER（外网用户）”：外网用户“USER_GROUP（用户群）”：用户群“IMSI_PREFIX（IMSI前缀）”：IMSI前缀  默认值：无  配置原则：  对于指定的用户（群），PCF选择策略的匹配优先级从高到低依次为：“IMSI_PREFIX(指定IMSI前缀)”，“USER_GROUP(用户群)”，“FOREIGN_USER(外网用户)”或“HOME_USER(本网用户)”，“ALL_USER(所有用户)”。 |
| IMSIPRE  | IMSI前缀 | 可选必选说明：该参数在"SUBRANGE"配置为"IMSI_PREFIX"时为条件必选参数。  参数含义：该参数用于指定应用PCF策略的用户的IMSI前缀。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是5~15。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                                                                                                                                                                 |

## 使用实例

删除为漫游用户配置的目标PCF选择策略，恢复到默认的选择策略，执行如下命令：

```
RMV PCFSELPLCY: SUBRANGE=FOREIGN_USER;
```
