#### 命令功能

**适用网元：SGSN**

该命令用于查询并显示所有待处理的NSEI列表。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                 |
|:-------|:-------|:-----------------------------------------------------|
| NSEI   | NSE标识  | 可选必选说明：可选参数 参数含义：该参数用于指定网络服务实体标识。 取值范围：0～65535 默认值：无 |

#### 使用实例

查询NSE列表中所有记录：

LST NSELST:;

```
%%LST NSELST:;%%
RETCODE = 0  操作成功。

NSE列表
-------
 NSE标识

 110
 111
(结果个数 = 2)

---    END
```
