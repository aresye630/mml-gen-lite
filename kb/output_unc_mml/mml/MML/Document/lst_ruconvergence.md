#### 命令功能

**适用NF：NCG**

该命令用于查询RU分配信息。

#### 注意事项

- 2345G混合部署的汇聚RU，不会分配业务RU。
- LST命令只会查出MOD命令设置的分配规则。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询汇聚RU信息：

```
LST RUCONVERGENCE:;
```

```
RETCODE = 0  操作成功。
```
