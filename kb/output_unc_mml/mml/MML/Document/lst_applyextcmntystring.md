# 查询扩展团体属性值设置（LST APPLYEXTCMNTYSTRING）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于列出应用扩展团体属性值。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                     |
|:-----------|:-------|:-------------------------------------------------------------------------|
| POLICYNAME | 路由策略名字 | 可选必选说明：可选参数 参数含义：该参数用于指定路由策略名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无 |

#### 使用实例

查询设置扩展团体属性的操作值：

```
LST APPLYEXTCMNTYSTRING:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
      路由策略名字  =  a
    路由策略节点ID  =  10
扩展团体属性字符串  =  1:1
(结果个数 = 1)
---    END
```
