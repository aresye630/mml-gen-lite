# 查询团体属性过滤器（LST COMMUNITYFILTER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询团体属性过滤器。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识           | 参数名称        | 参数说明                                                                                                                                                                                                   |
|:---------------|:------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CMNTYNAMEORNUM | 团体属性过滤器名字或号 | 可选必选说明：可选参数 参数含义：该参数用于指定团体属性过滤器名字或团体属性过滤器号。 数据来源：本端规划 取值范围：字符串类型，团体属性过滤器名称其长度范围是1～51。 默认值：无 配置原则：团体属性过滤器号为整数形式，其中基本团体属性过滤器号的取值范围为1～99，高级团体属性过滤器号的取值范围为100～199。团体属性过滤器名称为字符串形式，区分大小写，长度范围是1～51，且不能都是数字。 |

#### 使用实例

查询团体属性过滤器：

```
LST COMMUNITYFILTER:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
团体属性过滤器类型    团体属性过滤器名字或号
高级                  100
基础                  a
(结果个数 = 2)
---    END
```
