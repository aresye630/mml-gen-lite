# 增加5G接入用户数控制参数（ADD NGUSERNUMCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

执行该命令，ROAMNUMUPLIMIT参数设置不合理，可能会影响外网用户的接入。

**适用NF：AMF**

该命令用于为指定的Serving PLMN配置5G接入用户数控制参数。

## 注意事项

- 新增接入用户数相关控制参数，仅对新接入用户生效，已接入用户不受影响。参数配置错误会影响用户接入。

- 参数配置错误会影响用户接入。
- 仅在用户首次进入本AMF的移动性流程中进行用户数检查和控制。

- 最多可输入128条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                |
|:---------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PLMNIDX        | PLMN索引    | 可选必选说明：必选参数  参数含义：该参数表示需要限制接入漫游用户数的Serving PLMN。  数据来源：全网规划  取值范围：整数类型，取值范围是0~127。  默认值：无  配置原则：  PLMNIDX已通过ADD NGSRVPLMN进行配置。                                                                                                                                                                                      |
| ROAMNUMUPLIMIT | 漫游用户接入数上限 | 可选必选说明：必选参数  参数含义：该参数用于限制指定Serving PLMN下允许接入的最大漫游用户数。 Serving PLMN下漫游用户数超过本参数的限制，拒绝新的漫游用户接入时，注册拒绝原因值受SET NGMMPROCTRL命令的ROAMRST参数控制。  数据来源：本端规划  取值范围：整数类型，取值范围是0~8000000。  默认值：无  配置原则：  当漫游用户接入AMF时，漫游用户数会同时受特性License和本参数控制。License控制整系统的漫游用户数，本参数按ServingPLMN控制漫游用户数。  建议本参数的取值小于或等于特性License规格。  该命令下发后在20秒内生效。 |

## 使用实例

索引为1的Serving PLMN已通过ADD NGSRVPLMN配置，该Serving PLMN下最多允许接入10万漫游用户，执行如下命令：

```
ADD NGUSERNUMCTRL:PLMNIDX=1,ROAMNUMUPLIMIT=100000;
```
