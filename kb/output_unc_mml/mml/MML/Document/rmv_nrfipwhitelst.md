# 删除NF IP白名单（RMV NRFIPWHITELST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

客户端IP在被删除的IP段内的NF将无法正常注册、去注册、更新以及维持到NRF的心跳。

**适用NF：NRF**

该命令用于删除NF IP白名单内的IP段。

客户端IP在被删除的IP段内的NF将无法正常注册、去注册、更新以及维持到NRF的心跳。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                         |
|:----------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------|
| IPTYPE    | IP类型     | 可选必选说明：必选参数  参数含义：该参数表示NF IP白名单内的IP段类型。  数据来源：本端规划 取值范围： IPV4（IPv4地址）IPV6（IPv6地址）  默认值：无  配置原则：无                                             |
| IPV4START | IPV4地址起始 | 可选必选说明：该参数在"IPTYPE"配置为"IPV4"时为条件必选参数。  参数含义：该参数表示NF IP白名单内的IPV4类型IP段起始值。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：  IPV4地址起始值必须小于等于IPV4地址结束值。 |
| IPV4END   | IPV4地址结束 | 可选必选说明：该参数在"IPTYPE"配置为"IPV4"时为条件必选参数。  参数含义：该参数表示NF IP白名单内的IPV4类型IP段结束值。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无                           |
| IPV6START | IPv6起始地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPV6"时为条件必选参数。  参数含义：该参数表示NF IP白名单内的IPV6类型IP段起始值。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：  IPv6起始地址必须小于等于IPV6结束地址。   |
| IPV6END   | IPV6结束地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPV6"时为条件必选参数。  参数含义：该参数表示NF IP白名单内的IPV6类型IP段结束值。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无                           |

## 使用实例

将IP地址类型为IPV4，且IPV4地址起始值为10.1.1.1，IPV4地址结束为10.7.7.7的地址段从IP白名单中删除，执行如下命令：

```
RMV NRFIPWHITELST: IPTYPE=IPV4, IPV4START="10.1.1.1", IPV4END="10.7.7.7";
```
