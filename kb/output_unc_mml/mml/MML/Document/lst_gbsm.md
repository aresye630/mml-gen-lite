#### 命令功能

**适用网元：SGSN**

该命令用于查看GBSM协议配置信息，包括QoS参数、定时器参数、流程执行控制标志等。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询GBSM协议配置信息：

LST GBSM:;

```
%%LST GBSM:;%%
RETCODE = 0  操作成功。

2G SM协议配置表
---------------
                        T3385(s)  =  8
                    N3385(times)  =  4
                        T3386(s)  =  8
                    N3386(times)  =  4
                        T3395(s)  =  8
                    N3395(times)  =  4
                     是否启用PFT  =  Yes
       BSS保留PFC的时长定时器(s)  =  40
(结果个数 = 1)

---    END
```
