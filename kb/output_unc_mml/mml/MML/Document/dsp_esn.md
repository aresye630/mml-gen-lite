# 查询ESN(DSP ESN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询设备ESN。

## 注意事项

无

## 参数说明

无。

## 使用实例

查询设备ESN：

```
%%DSP ESN:;%%
RETCODE = 0  操作成功

设备序列号
----------
设备序列号  =  0123456789
(结果个数 = 1)

---    END
```
