# 修改虚拟通道映射（MOD VIRTUALCHL）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：NCG**

该命令用于修改虚拟通道映射。

#### 注意事项

- 该命令执行后立即生效。
- 修改虚拟通道后，本地备份和本地分发的目的路径的旧虚拟通道目录下如果存在文件，不会自动删除，会占用NCG的磁盘空间。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                              |
|:-----------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SOURCECHL  | 源通道名称    | 可选必选说明：必选参数 参数含义：需要映射的通道名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则： 源通道名称需要通过执行DSP FEMPACKET命令来获取。同一个接入分组的一个源通道只能配置一个虚拟通道映射。                                                |
| AGID       | 接入网元分组标识 | 可选必选说明：必选参数 参数含义：用于区分不同域的接入网元。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则： 该值需要执行LST CDRPROC命令查询“接入网元分组标识”。如果没有符合要求的“接入网元分组标识”，还需执行ADD CDRPROC命令增加。不能输入的特殊字符请参考“特殊字符表”。         |
| VIRTUALCHL | 虚拟通道名称   | 可选必选说明：必选参数 参数含义：映射后的虚拟通道名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则： 长度不超过32的字符串，且只能为大小写英文字母、数字、字符“-”、字符“/”及字符“_”，且不能包含连续的“/”。虚拟通道不能和该接入分组的格式引擎包通道重复。虚拟通道不能和该接入分组的其他虚拟通道重复。 |

#### 使用实例

修改接入分组PS1的"98/OFFLINE"通道的虚拟通道映射为“100/OFFLINE”，配置举例如下：

```
MOD VIRTUALCHL: SOURCECHL="98/OFFLINE", AGID="PS1", VIRTUALCHL="100/OFFLINE";
```
