# 查询IKE提议（LST IKEPROPOSAL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询IKE安全提议配置。

## 注意事项

通过软参方式配置不安全算法MD5、DES、3DES时，**LST IKEPROPOSAL**命令显示仍为该命令原先配置的算法，不会显示MD5或DES或3DES。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                           |
|:---------------|:-------|:-----------------------------------------------------------------------------------------------|
| PROPOSALNUMBER | 安全提议号  | 可选必选说明：可选参数  参数含义：提议编号。  数据来源：本端规划  取值范围：整数类型，取值范围是1~4294967295。101不支持配置，但可以查询。  默认值：无  配置原则：无 |

## 使用实例

查询IKE安全提议号为1的IKE安全提议：

```
LST IKEPROPOSAL:PROPOSALNUMBER=1;
RETCODE = 0  操作成功

结果如下
-------------------------
     安全提议号  =  1
       认证方法  =  预共享
       认证算法  =  Sha2-256算法
       加密算法  =  256位AES算法
     完整性算法  =  Sha2-256算法
           DH组  =  无
重认证间隔（s）  =  86400
SA持续长度（s）  =  86400
(结果个数 = 1)
---    END
```
