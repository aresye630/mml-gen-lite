# 设置AMF HTTP相关定时器参数（SET AMFHTTPTIMER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于设置AMF HTTP相关定时器参数。

当AMF与对端网元交互定时器设置不合理时，可通过本命令调整相关消息的定时器时长，确保业务端到端流程的合理性。

当前版本仅支持参数“TSMF”、“TSMFSMCRT”、“TSMFSMUPD”功能，其余参数功能暂不支持。

## 注意事项

- 该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

设置AMF HTTP相关定时器参数，其中，等待UDM响应定时器时长为6秒、等待AUSF响应定时器时长为6秒、等待UE策略所属PCF响应定时器时长为6秒，执行如下命令：

```
SET AMFHTTPTIMER: TIMERTYPE=InterfaceTimer, TUDM=6, TAUSF=6, TUEPCF=6;
```
