# 删除DNAI粒度的UPF选择策略（RMV DNAIUPSELPLY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于删除DNAI粒度的UPF选择策略。

## 注意事项

- 该命令执行后立即生效。

- 删除本配置后，在此DNAI内的UPF选择策略由更粗粒度的配置(UPSELECTFLAG、APNUPSEPLY)控制。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                               |
|:-------|:---------|:---------------------------------------------------------------------------------------------------|
| DNAI   | 数据网络访问标识 | 可选必选说明：必选参数  参数含义：该参数用于指定数据网络访问标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。不支持空格，不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

删除指定DNAI的UPF选择策略，DNAI名称为huawei.com。

```
RMV DNAIUPSELPLY:DNAI="huawei.com";
```
