# 查询流控策略（LST PCCUSRFLOWCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF**

该命令用于查询流控策略。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称        | 参数说明                                                                                           |
|:----------------|:------------|:-----------------------------------------------------------------------------------------------|
| USRFLOWCTRLNAME | Update流控策略名 | 可选必选说明：可选参数  参数含义：该参数用于指定Update流控策略名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。区分大小写。  默认值：无  配置原则：无 |

## 使用实例

查询流控策略

```
LST PCCUSRFLOWCTRL:;
```
