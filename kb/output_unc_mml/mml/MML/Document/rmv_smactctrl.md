# 删除激活过程控制参数（RMV SMACTCTRL）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于删除在PDN连接建立流程中使用签约数据匹配的纠正功能涉及到的相关参数。

#### 注意事项

- 该命令执行后立即生效。
- 删除后影响签约数据匹配纠正功能。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|:---------|:-----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围       | 可选必选说明：必选参数 参数含义：该参数用于指定启用功能的用户范围。 取值范围：“ALL_USER(所有用户)”“SPECIAL_USER(指定用户)”“SPECIAL_UETYPE(指定终端类型)” 默认值：无  说明： “用户范围”+“IMSI前缀”+“请求APNNI”不能重复。“用户范围”+“终端类型”+“请求APNNI”不能重复。                                                                                                                                                                                                                                                                                                                                                              |
| IMSIPRE  | IMSI前缀     | 可选必选说明：条件必选参数 参数含义：待删除的IMSI前缀。 前提条件：该参数在“用户范围”参数设置为“SPECIAL_USER(指定用户)”时，才需要配置。 取值范围：5~15位十进制数字 默认值：无  说明： 使用时按照IMSI最长匹配进行查询，相同IMSI前缀的原始原因值配置不能相同。                                                                                                                                                                                                                                                                                                                                                                                      |
| UETYPE   | 终端类型       | 可选必选说明：条件必选参数 参数含义：该参数用于指定终端类型。UNC需要为这些类型终端设置特定请求信息纠正策略。 前提条件：该参数在“用户范围”参数设置为“SPECIAL_UETYPE(指定终端类型)”时，才需要配置。 数据来源：整网规划 取值范围：“ANDROID(Android)”“BLACKBERRY(Black Berry)”“IOS(iOS)”“WINDOWS(Windows)”“CUSTOM_TYPE_1(自定义类型1)”“CUSTOM_TYPE_2(自定义类型2)”“CUSTOM_TYPE_3(自定义类型3)”“CUSTOM_TYPE_4(自定义类型4)”“CUSTOM_TYPE_5(自定义类型5)”“CUSTOM_TYPE_6(自定义类型6)”“CUSTOM_TYPE_7(自定义类型7)”“CUSTOM_TYPE_8(自定义类型8)”“CUSTOM_TYPE_9(自定义类型9)”“CUSTOM_TYPE_10(自定义类型10)”“CUSTOM_TYPE_11(自定义类型11)”“CUSTOM_TYPE_12(自定义类型12)” 默认值：无  说明： “终端类型”需要在ADD SMACTIMEILIB中配置。 |
| APNTYPE  | UE请求的APNNI | 可选必选说明：必选参数 参数含义：该参数用于指定请求APNNI类型。 取值范围：“ALL_APN(所有APN)”“NULL_APN(空APN)”“NOT_NULL_APN(非空APN)”“SPECIAL_APN(指定APN)” 默认值：无  说明： 请求APNNI为空时，选择“NULL_APN”。请求APNNI为非空时，选择“NOT_NULL_APN”。请求APNNI为指定APN时，选择“SPECIAL_APN”。请求APNNI包括空APN和非空APN时，选择“ALL_APN”。                                                                                                                                                                                                                                                                                      |
| APNNI    | APNNI      | 可选必选说明：条件必选参数 参数含义：该参数用于指定APN网络标识。 前提条件：该参数在“APNTYPE”参数设置为“SPECIAL_APN(指定APN)”时，才需要配置。 取值范围：1~62位字符串 默认值：无  说明： APN网络标识地址由一个或多个LABEL构成，各LABEL间用“.”间隔。每个LABEL的构成字符只能是字母A～Z或a～z、数字0～9和中划线“-”。APN网络标识地址不能以“rac”、“lac”、“sgsn”或“rnc”开头，不能以“.gprs”结尾。                                                                                                                                                                                                                                                                                         |

#### 使用实例

删除一条“用户范围”为“SPECIAL\_USER(指定用户)”，“IMSI前缀”为“12300”，“UE请求的APNNI”为“SPECIAL\_APN(指定APN)”，“APNNI”为“huawei.com”的记录：

RMV SMACTCTRL: SUBRANGE=SPECIAL\_USER, IMSIPRE="12300", APNTYPE=SPECIAL\_APN, APNNI="huawei.com";
