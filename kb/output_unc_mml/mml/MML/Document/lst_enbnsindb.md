#### 命令功能

**适用网元：MME**

此命令用于查询中手动添加的eNodeB邻接关系。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                                                                                             |
|:--------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ENBTYPE | eNodeB类型 | 可选必选说明：可选参数 参数含义：待查询邻接关系的中心eNodeB的类型。 取值范围：“HOME_ENODEB(Home_eNodeB)”：表示中心eNodeB类型为家庭基站，其标志长度为28位。“MACRO_ENODEB(Macro_eNodeB)”：表示中心eNodeB类型为宏基站，其标识长度为20位。 默认值：无 |
| MCC     | 移动国家码    | 可选必选说明：可选参数 参数含义：待查询邻接关系的中心eNodeB和邻接eNodeB共用的移动国家码。 取值范围：3位十进制数字 默认值：无                                                                                           |
| MNC     | 移动网号     | 可选必选说明：可选参数 参数含义：待查询邻接关系的中心eNodeB和邻接eNodeB共用的移动网号。 取值范围：2～3位十进制数字 默认值：无                                                                                          |
| ENBID   | eNodeB标识 | 可选必选说明：可选参数 参数含义：待查询邻接关系的中心eNodeB的ID。 取值范围：0～268435455 默认值：无                                                                                                     |

#### 使用实例

查询所有手动添加的eNodeB邻接关系：

LST ENBNSINDB:;

```
%%LST ENBNSINDB:;%%
RETCODE = 0  操作成功。

输出结果如下
--------------
    eNodeB类型  =  Home_eNodeB
    移动国家码  =  123
      移动网号  =  01
    eNodeB标识  =  327697
邻接eNodeB个数  =  3
邻接eNodeB列表  =  327696&327698&327699
(结果个数 = 1)

---    END
```
