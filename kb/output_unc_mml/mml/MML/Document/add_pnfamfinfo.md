# 增加对端AMF信息（ADD PNFAMFINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、NSSF、SMSF、NCG、CBC、CBCF**

该命令用于增加本地配置对端AMF的信息。该命令用于在网络中没有部署NRF，或对端NF没有注册到NRF，或网络中存在NRF但需基于运营商策略本地配置周边NF的场景下，配置对端NF实例相关的信息。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入64条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                     |
|:-------------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCEID | NF实例标识  | 可选必选说明：必选参数  参数含义：该参数用于指定对端AMF的NF实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~38。NFINSTANCEID参数建议满足以下约束规则：1.如果输入为uuid格式（格式例如：a6a61c6f-0d3a-4221-b1da-424eda3ccf67）只能为A-F、a-f、0-9和“-”的字符。2.如果输入不为uuid格式，长度不能超过18且不允许输入只包含0-9和“.”的字符串，例如：1.2.3.4；不允许输入只包含十六进制数（A-F、a-f、0-9）和“:”的字符串，例如：1::2、FBFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。3.该参数大小写不敏感。  默认值：无  配置原则：  本参数取值与ADD PNFPROFILE命令中的“NF实例标识”参数取值保持一致时，关联关系生效。 |
| AMFREGIONID  | AMF区域标识 | 可选必选说明：必选参数  参数含义：该参数用于指定对端AMF所在区域的标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~50。本参数的构成字符建议由字母A～F或a～f、数字0～9组成。  默认值：无  配置原则：  大小写不敏感。                                                                                                                                                                                                                                                                           |
| AMFSETID     | AMF组标识  | 可选必选说明：必选参数  参数含义：该参数用于指定对端AMF所在集合（即Pool）的标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~50。本参数的构成字符建议是字母A～F或a～f、数字0～9，且第一个字符是数字0-3。  默认值：无  配置原则：  大小写不敏感。                                                                                                                                                                                                                                                         |

## 使用实例

增加对端AMF信息，NF实例标识为AMF\_Instance\_1，AMF区域标识为00，AMF组标识为001。

```
ADD PNFAMFINFO: NFINSTANCEID="AMF_Instance_1", AMFREGIONID="00", AMFSETID="001";
```
