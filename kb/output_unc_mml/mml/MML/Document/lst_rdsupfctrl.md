# 查询RADIUS服务器使用的UP列表中UP的功能属性（LST RDSUPFCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF、PGW-C、GGSN**

该命令用来查询指定UP列表中指定UP的功能属性。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                          |
|:-------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UPLISTNAME   | UP列表名称 | 可选必选说明：必选参数  参数含义：该参数用于指定UP列表名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。该参数需要是UPLIST4RDS配置中已添加的UPLISTNAME的值。不区分大小写。  默认值：无  配置原则：  该参数使用ADD UPLIST4RDS命令配置生成。     |
| UPINSTANCEID | UP实例标识 | 可选必选说明：可选参数  参数含义：该参数用于指定UP实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~36。该参数取值需要是UPLIST4RDS配置中已添加的UPINSTANCEID的值。不区分大小写。  默认值：无  配置原则：  该参数使用ADD UPLIST4RDS命令配置生成。 |

## 使用实例

显示UP列表名为“uplist1”，UP名为“up1”的配置信息：

```
LST RDSUPFCTRL: UPLISTNAME="uplist1",UPINSTANCEID="up1";
            RETCODE = 0  操作成功

            UPF列表信息
            -----------
            UP列表名称  =  uplist1
            UP实例标识  =  up1
            优先级 =  1
            锁定 =  关
            (结果个数 = 1)

            ---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                    |
|:--------|:---------------------------------------------------------|
| UP列表名称  | 该参数用于指定UP列表名称。                                           |
| UP实例标识  | 该参数用于指定UP实例标识。                                           |
| 优先级     | 该参数用于指定UP的优先级。                                           |
| 锁定      | 该参数用于对该UPF进行锁定操作，当取值为ENABLE时，SMF无法选择该UPF创建UPF中转RADIUS会话。 |
