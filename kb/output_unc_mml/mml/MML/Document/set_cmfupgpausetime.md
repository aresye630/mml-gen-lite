# 设置灰度升级拨测发布暂停时长（SET CMFUPGPAUSETIME）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令参数配置若小于历史配置值或配置小于180分钟，可能会导致某些进程复位。

该命令用于设置在灰度升级拨测发布暂停期间，进程就绪超时时长。若进程超过此时长未就绪，会产生复位。

## 注意事项

- 该命令执行后立即生效。

- 仅灰度升级拨测发布期间配置生效，其他场景命令可配置，但参数不生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

|   PAUSETIME |
|------------:|
|         180 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称         | 参数说明                                                                                                       |
|:----------|:-------------|:-----------------------------------------------------------------------------------------------------------|
| PAUSETIME | 灰度升级拨测发布暂停时长 | 可选必选说明：必选参数  参数含义：该参数用于设置灰度升级拨测发布暂停期间，进程就绪超时时长。  数据来源：本端规划  取值范围：整数类型，取值范围是60~10080，单位是分钟。  默认值：无。  配置原则：无 |

## 使用实例

设置灰度升级拨测发布暂停时长为180分钟。

```
%%SET CMFUPGPAUSETIME: PAUSETIME=180;%%
RETCODE = 0  操作成功

---    END
```
