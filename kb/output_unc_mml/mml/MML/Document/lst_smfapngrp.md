# 查询DNS关联的APN组（LST SMFAPNGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于查询DNS关联的APN组。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                      |
|:--------|:-------|:------------------------------------------------------------------------------------------|
| GRPNAME | APN组名  | 可选必选说明：可选参数  参数含义：该参数用于指定APN组名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

查询DNS关联的APN组：

```
LST SMFAPNGRP:GRPNAME="grp1";
```

## 输出结果说明

| 输出项名称     | 输出项解释                             |
|:----------|:----------------------------------|
| APN组名     | 该参数用于指定APN组名。                     |
| APN组的描述信息 | 该参数用于指定对APN群组的描述信息，在运维过程中起到助记的作用。 |
