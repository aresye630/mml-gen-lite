# 查询性能指标上报范围（LST PERFRPTRANGE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF、PGW-C、GGSN、AMF**

该命令用于查询AMF或SMF性能统计指标的上报范围。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:----------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MOC       | 测量对象类型   | 可选必选说明：可选参数  参数含义：该参数用于指定测量对象类型。  数据来源：本端规划 取值范围： “APN_GW（APN_GW）”：表示SMF网元的APN_GW性能统计对象类型。“DNN（DNN）”：表示SMF网元的DNN性能统计对象类型。“TAILIST（TAILIST）”：表示SMF网元的TAI组性能统计对象类型。“AMFTAIGRP（AMFTAIGRP）”：表示AMF网元的TAI组性能统计对象类型。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                              |
| RULERANGE | 规则生效范围   | 可选必选说明：可选参数  参数含义：该参数用于指定本记录生效的范围。  数据来源：本端规划 取值范围： “ALL（所有）”：表示该记录配置的上报规则针对指定MOC的所有对象实例和所有测量单元生效。“SPECIFICMU（指定测量单元）”：表示该记录配置的上报规则针对指定MOC的指定测量单元生效。“SPECIFICMOI（指定测量对象实例）”：表示该记录配置的上报规则针对指定MOC的指定测量对象实例生效。  默认值：无  配置原则：  三种生效范围的优先级为：“指定测量对象实例”>“指定测量单元”>“所有测量对象实例”。                                                                                                                                                                                                                                    |
| NMMUID    | 测量单元ID   | 可选必选说明：该参数在"RULERANGE"配置为"SPECIFICMU"时为条件可选参数。  参数含义：该参数用于指定测量单元的网管ID。  数据来源：本端规划  取值范围：整数类型，取值范围是1~4294967294。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                            |
| MOIID     | 测量对象实例ID | 可选必选说明：该参数在"RULERANGE"配置为"SPECIFICMOI"时为条件可选参数。  参数含义：该参数用于指定测量对象实例。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~128。  默认值：无  配置原则：  当“测量对象类型”设置为APN_GW时，本参数设置的APN需要是ADD APN命令配置的APN。  当“测量对象类型”设置为DNN时，本参数设置的DNN需要满足“MCC:MNC:SST-SD:DNN”的格式，MNC和MCC需要是ADD NGSRVPLMN命令配置的MNC和MCC，SST和SD需要是ADD PLMNNS命令配置的SST和SD，其中Plmn索引为MCC和MNC在ADD NGSRVPLMN命令配置中的索引，DNN需要是ADD APN命令配置的APN。  当“测量对象类型”设置为TAILIST时，本参数设置的“测量对象实例ID”需要通过ADD PERFTAIGROUP命令进行配置。  当“测量对象类型”设置为AMFTAIGRP时，本参数设置的“测量对象实例ID”需要通过ADD PERFNGTAIGROUP命令进行配置。 |

## 使用实例

查询所有性能指标上报范围：

```
%%LST PERFRPTRANGE: RULERANGE=ALL;%%
RETCODE = 0  操作成功

结果如下
--------
  测量对象类型  =  APN_GW
  规则生效范围  =  所有
    测量单元ID  =  NULL
测量对象实例ID  =  NULL
      上报范围  =  全部
(结果个数 = 1)

---    END
```
