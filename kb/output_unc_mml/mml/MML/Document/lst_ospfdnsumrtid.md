# 查询特定路由器禁止检查Summary-LSA的DN比特位配置（LST OSPFDNSUMRTID）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询特定路由器禁止检查Summary-LSA的DN比特位配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                   |
|:---------|:--------|:-----------------------------------------------------------------------|
| PROCID   | OSPF进程号 | 可选必选说明：可选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 |
| ROUTERID | 路由器标识   | 可选必选说明：可选参数 参数含义：路由器标识。 数据来源：全网规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无         |

#### 使用实例

查询特定路由器禁止检查Summary-LSA的DN比特位配置：

```
LST OSPFDNSUMRTID:;
```

```
RETCODE = 0  操作成功。

结果如下
------------------------
OSPF进程号  =  1
 路由器标识 =  10.6.6.6
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                |
|:--------|:---------------------|
| OSPF进程号 | 该参数指定用户创建的OSPF进程号。   |
| 路由器标识   | 该参数指定用户创建的OSPF路由器标识。 |
