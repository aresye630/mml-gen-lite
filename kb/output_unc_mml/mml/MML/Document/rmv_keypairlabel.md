# 删除DSA/ECC密钥对标签（RMV KEYPAIRLABEL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除DSA/ECC密钥对标签。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                     |
|:-------------|:-------|:-----------------------------------------------------------------------------------------|
| KEYTYPE      | 公钥类型   | 可选必选说明：必选参数 参数含义：公钥类型。 数据来源：本端规划 取值范围：枚举类型。 DSA：DSA公钥。ECC：ECC公钥。 默认值：无                   |
| KEYPAIRLABEL | 密钥对标签名 | 可选必选说明：必选参数 参数含义：公钥的名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～35。名称只能使用数字、字母和下划线，不区分字母大小写。 默认值：无 |

#### 使用实例

删除DSA/ECC密钥对标签，名称为hw\_key，类型为DSA：

```
RMV KEYPAIRLABEL:KEYTYPE=DSA,KEYPAIRLABEL="hw_key";
```
