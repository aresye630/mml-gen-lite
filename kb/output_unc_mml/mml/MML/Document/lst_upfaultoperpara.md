# 显示UP故障处理系统参数（LST UPFAULTOPERPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF**

该命令用于显示UP故障处理的系统参数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询UP故障处理的系统参数：
LST UPFAULTOPERPARA:;

```
%%LST UPFAULTOPERPARA:;%%
RETCODE = 0  操作成功

结果如下
------------------------
故障迁移速率(个/秒)  =  1000
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称       | 输出项解释                                 |
|:------------|:--------------------------------------|
| 故障迁移速率(个/秒) | 该参数用于控制副锚点UPF故障时，系统批量迁移或者批量删除分流业务的速率。 |
