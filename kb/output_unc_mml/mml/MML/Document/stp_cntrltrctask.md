# 停止跨层统一联动跟踪任务（STP CNTRLTRCTASK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于停止跨层统一联动跟踪任务。

## 注意事项

- 该命令执行后立即生效。

- 该命令仅在虚机场景下支持，并且仅支持FusionSphere用户态EVS和用户态OVS组网。
- 该命令会触发PAE和FusionSphere跟踪任务停止，当PAE或FusionSphere的停止跟踪任务返回失败时，如PAE或FusionSphere跟踪任务已经异常停止，该命令会执行失败。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                   |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------|
| TASKID | 任务ID   | 可选必选说明：必选参数  参数含义：该参数用于表示停止跨层统一联动跟踪任务的任务ID。  数据来源：本端规划  取值范围：字符串类型，输入长度是14。  默认值：无  配置原则：  该参数可通过DSP CNTRLTRCTASK命令查询。 |

## 使用实例

停止跨层统一联动跟踪任务：

```
%%STP CNTRLTRCTASK: TASKID="20220301223015";%%
RETCODE = 0  操作成功

---    END
```
