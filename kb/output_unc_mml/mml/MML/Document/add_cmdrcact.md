# 增加命令层异常返回码处理动作（ADD CMDRCACT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于增加命令层异常返回码的处理动作配置。当OCS返回的CCA消息携带命令层异常返回码时，根据此配置进行处理。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为2020。
- 该命令基于在线计费模板设置命令层异常返回码的动作配置，单个在线计费模板中最多配置20个命令层异常返回码处理动作。
- 当命令层异常返回码处理动作配置为重定向时，CMDRDVIRTIP和CMDRDVIRTIPV6之间至少配置一个参数。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

如果希望OCS返回命令层异常返回码5012时，去活PDP上下文且不发送CCR-T消息，可以在全局在线计费模板中配置命令层异常返回码5012的动作为TERM\_NO\_CCRT：

```
ADD CMDRCACT:DCCTMPLTNAME="global",CMDRC="5012",CMDRCACT=TERM_NO_CCRT;
```
