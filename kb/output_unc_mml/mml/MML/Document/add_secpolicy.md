# 增加防攻击策略（ADD SECPOLICY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于添加安全策略。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为30。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                              |
|:------------|:-------|:------------------------------------------------------------------|
| POLICYID    | 安全策略编号 | 可选必选说明：必选参数 参数含义：策略编号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～30。 默认值：无       |
| DESCRIPTION | 策略描述   | 可选必选说明：可选参数 参数含义：防攻击策略描述。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～64。 默认值：无 |

#### 使用实例

添加安全策略：

```
ADD SECPOLICY:POLICYID=1;
```
