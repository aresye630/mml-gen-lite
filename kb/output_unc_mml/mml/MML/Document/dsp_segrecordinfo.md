# 显示NRF已导入号段数据（DSP SEGRECORDINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NRF**

该命令用于查询所有导入号段数据的A、B表信息。

当需要通过号段配置文件方式刷新NF支持的号段信息时，可以通过此命令查看导入号段数据的信息。

## 注意事项

该命令支持查询的最大记录数为1000。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                            |
|:-------------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SEGTYPE      | 号段类型    | 可选必选说明：必选参数  参数含义：该参数用于表示号段类型。其中ALL代表IMSI、MSISDN、IMSIRT、MSISDNRT。  数据来源：本端规划 取值范围： IMSI（IMSI）MSISDN（MSISDN）IMSIRT（IMSIRT）MSISDNRT（MSISDNRT）ALL（ALL）  默认值：无  配置原则：无                                                                                                                                                                                              |

| NFTYPEMSISDN | NF类型    | 可选必选说明：该参数在"SEGTYPE"配置为"MSISDN"、"MSISDNRT"时为条件必选参数。  参数含义：该参数用于表示MSISDN、MSISDNRT号段作用的NF类型，即哪些NF类型支持号段文件中给出的MSISDN、MSISDNRT号段信息。  数据来源：本端规划 取值范围： PCF（PCF）UDM（UDM）UDR（UDR）CHF（CHF）CUSTOM_OCS（CUSTOM_OCS）ALL（ALL）  默认值：无  配置原则：无                                                                                                                                  |
| NFTYPEALL    | NF类型    | 可选必选说明：该参数在"SEGTYPE"配置为"ALL"时为条件必选参数。  参数含义：该参数用于表示IMSI、MSISDN、IMSIRT和MSISDNRT号段作用的NF类型，即哪些NF类型支持号段文件中给出的所有号段信息。  数据来源：本端规划 取值范围： AUSF（AUSF）PCF（PCF）UDM（UDM）UDR（UDR）CHF（CHF）CUSTOM_OCS（CUSTOM_OCS）AUSFUDM（AUSFUDM）ALL（ALL）  默认值：无  配置原则：无                                                                                                                       |
| TBLTYPE      | 号段表类型   | 可选必选说明：必选参数  参数含义：该参数用于表示号段的号段表类型，用于区分主、备两个表。  数据来源：本端规划 取值范围： ATABLE（A表）BTABLE（B表）  默认值：无  配置原则：无                                                                                                                                                                                                                                                              |
| SEGSTART     | 号段起始字符串 | 可选必选说明：可选参数  参数含义：该参数用于表示号段起始字符串。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是5~15。十进制数字，号段的起始号码必须与结束号码长度保持一致，数值必须小于或等于结束号码的数值。  默认值：无  配置原则：无                                                                                                                                                                                                                                |
| SEGEND       | 号段结束字符串 | 可选必选说明：可选参数  参数含义：该参数用于表示号段结束字符串。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是5~15。十进制数字，号段的结束号码必须与起始号码长度保持一致，数值大于或等于起始号码的数值。  默认值：无  配置原则：无                                                                                                                                                                                                                                  |
| NFGROUPID1   | NF组标识1  | 可选必选说明：该参数在"NFTYPEALL"配置为"AUSF"、"PCF"、"UDM"、"UDR"、"CHF"、"CUSTOM_OCS"、"AUSFUDM"、"ALL"时为条件可选参数。该参数在"NFTYPEIMSI"配置为"AUSF"、"PCF"、"AUSFUDM"、"UDM"、"UDR"、"CHF"、"CUSTOM_OCS"、"ALL"时为条件可选参数。该参数在"NFTYPEMSISDN"配置为"PCF"、"UDM"、"UDR"、"CHF"、"CUSTOM_OCS"、"ALL"时为条件可选参数。  参数含义：该参数用于表示特定号段配置的NF组标识，可以通过LST NFGROUP进行查询。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~128。  默认值：无  配置原则：无 |
| NFGROUPID2   | NF组标识2  | 可选必选说明：该参数在"NFTYPEALL"配置为"AUSFUDM"、"ALL"时为条件可选参数。该参数在"NFTYPEIMSI"配置为"AUSFUDM"、"ALL"时为条件可选参数。  参数含义：该参数用于表示特定号段配置的NF组标识，可以通过LST NFGROUP进行查询。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~128。  默认值：无  配置原则：无                                                                                                                                                                 |
| RECNUM       | 记录条数    | 可选必选说明：可选参数  参数含义：该参数用于表示指定NF类型和号段类型对应导入文件的返回记录条数。  数据来源：本端规划  取值范围：整数类型，取值范围是1~1000，单位是条。  默认值：无  配置原则：无                                                                                                                                                                                                                                                       |

## 使用实例

查询NRF上已经通过号段导入的AUSF支持的IMSI信息的A表信息。

```
%%DSP SEGRECORDINFO: SEGTYPE=IMSI, NFTYPEIMSI=AUSF, TBLTYPE=BTABLE, RECNUM=5;%%
RETCODE = 0  操作成功

结果如下
------------------------

IMSI       ausf     B表         861520330000000    861520389999999   ausf-04    NULL           
IMSI       ausf     B表         861520300000000    861520359999999   ausf-01    NULL           
IMSI       ausf     B表         861520310000000    861520369999999   ausf-02    NULL           
(结果个数 = 4)
```
