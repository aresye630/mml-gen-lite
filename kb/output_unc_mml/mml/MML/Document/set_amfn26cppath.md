# 设置AMF N26消息抄送路径（SET AMFN26CPPATH）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME、AMF**

该命令用于4/5G融合部署时，对于AMF/MME内部的4/5G互操作流程，AMF/MME支持通过该命令配置的路径，抄送一条重复N26消息报文。

#### 注意事项

- 该命令执行后立即生效。
- 该功能只在特定局点生效，请联系华为技术支持确认是否可以使用。

#### 本地用户权限

manage-ug；system-ug。

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组。

#### 参数说明

| 参数标识      | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                                                                            |
|:----------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CPPATHSW  | 抄送路径开关     | 可选必选说明：可选参数 参数含义：本参数用于指示AMF/MME是否开启抄送路径功能。开关开启后，对于AMF/MME内部4/5G互操作产生的N26接口消息，AMF/MME会通过该命令配置的路径抄送一条重复N26消息报文。 数据来源：全网规划 取值范围： “OFF（关闭）”“ON（打开）” 系统初始设置值：“OFF（关闭）” 默认值：无。 执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过相关查询命令获取当前参数配置值。 配置原则：无                                                                                                                                                  |
| IPTYPE    | IP地址类型     | 可选必选说明：条件必选参数 参数含义：本参数用于指定抄送路径的IP地址类型。 前提条件：该参数在“抄送路径开关”参数配置为“ON（打开）”后生效。 数据来源：全网规划 取值范围： “TPTADDR_TYPE_IPV4(IPv4)”“TPTADDR_TYPE_IPV6(IPv6)”“TPTADDR_TYPE_IPV4IPV6(IPv4IPv6)” 默认值：无  说明： 当本参数设置为“TPTADDR_TYPE_IPV4IPV6”时，抄送路径按照原始消息的IP地址类型选择对应的IP地址类型。                                                                                                                          |
| MMECPIPV4 | MME侧IPv4地址 | 可选必选说明：条件必选参数 参数含义：本参数用于指定抄送路径的MME侧N26接口IPv4地址。 前提条件：该参数在“IP地址类型”参数配置为“TPTADDR_TYPE_IPV4(IPv4)”或“TPTADDR_TYPE_IPV4IPV6(IPv4IPv6)”后生效。 数据来源：全网规划 取值范围：0.0.0.0~255.255.255.255 默认值：无 配置原则： 业务地址不能配置为0.0.0.0、255.255.255.255和环回地址(127.x.y.z)。业务地址必须是A、B或者C类地址。IP地址请确保为外部不可用地址，避免消息发给该地址后产生非预期影响。比如：收到非预期消息导致过载、拥塞、甚至复位等。                                                           |
| MMECPIPV6 | MME侧IPv6地址 | 可选必选说明：条件必选参数 参数含义：本参数用于指定抄送路径的MME侧N26接口IPv6地址。 前提条件：该参数在“IP地址类型”参数配置为“TPTADDR_TYPE_IPV6(IPv6)”或“TPTADDR_TYPE_IPV4IPV6(IPv4IPv6)”后生效。 数据来源：全网规划 取值范围：::~FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 配置原则： IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址(::1)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。IP地址请确保为外部不可用地址，避免消息发给该地址后产生非预期影响。比如：收到非预期消息导致过载、拥塞、甚至复位等。 |
| AMFCPIPV4 | AMF侧IPv4地址 | 可选必选说明：条件必选参数 参数含义：本参数用于指定抄送路径的AMF侧N26接口IPv4地址。 前提条件：该参数在“IP地址类型”参数配置为“TPTADDR_TYPE_IPV4(IPv4)”或“TPTADDR_TYPE_IPV4IPV6(IPv4IPv6)”后生效。 数据来源：全网规划 取值范围：0.0.0.0~255.255.255.255 默认值：无 配置原则： 业务地址不能配置为0.0.0.0、255.255.255.255和环回地址(127.x.y.z)。业务地址必须是A、B或者C类地址。IP地址请确保为外部不可用地址，避免消息发给该地址后产生非预期影响。比如：收到非预期消息导致过载、拥塞、甚至复位等。                                                           |
| AMFCPIPV6 | AMF侧IPv6地址 | 可选必选说明：条件必选参数 参数含义：本参数用于指定抄送路径的AMF侧N26接口IPv6地址。 前提条件：该参数在“IP地址类型”参数配置为“TPTADDR_TYPE_IPV6(IPv6)”或“TPTADDR_TYPE_IPV4IPV6(IPv4IPv6)”后生效。 数据来源：全网规划 取值范围：::~FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 配置原则： IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址(::1)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。IP地址请确保为外部不可用地址，避免消息发给该地址后产生非预期影响。比如：收到非预期消息导致过载、拥塞、甚至复位等。 |
| VPNNAME   | VPN名称      | 可选必选说明：条件可选参数 参数含义：本参数用于指定N26接口对应的VPN名称。MME侧与AMF侧N26接口应为相同VPN。 数据来源：全网规划 取值范围：0~31位字符串 默认值：无 配置原则： 本参数必须与MME侧N26接口（ADD GTPCLE）的VPN名称配置一致。输入单空格将删除该参数已有配置项。                                                                                                                                                                                                                      |
| CPEN      | 抄送增强       | 可选必选说明：条件可选参数 参数含义：本参数用于控制开启N26消息报文抄送功能增强处理，功能开启后可有效减少网络报文的乱序发生。 数据来源：全网规划 取值范围： “OFF（关闭）” “ON（打开）” 默认值：无 配置原则：无                                                                                                                                                                                                                                                                |

#### 使用实例

开启AMF N26消息抄送路径功能，抄送路径使用IPv4地址，MME侧地址为192.168.1.1，AMF侧地址为192.168.2.2，VPN名称为\_abc\_执行如下命令：

```
SET AMFN26CPPATH: CPPATHSW=ON, IPTYPE=TPTADDR_TYPE_IPV4, MMECPIPV4="192.168.1.1", AMFCPIPV4="192.168.2.2", VPNNAME="_abc_";
```
