# FEI报文、进程日志开关（SET SFEFEIDEBUG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来开关fei报文日志或进程日志功能。

#### 注意事项

该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                      |
|:----------|:-------|:----------------------------------------------------------------------------------------------------------|
| RUNAME    | 资源单元名称 | 可选必选说明：必选参数 参数含义：该参数用于表示资源单元名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则： 区分大小写，不支持空格。使用DSP RU查看RU名称。 |
| DBGVALUE  | 日志类型   | 可选必选说明：必选参数 参数含义：该参数用于指定日志类型。 数据来源：本端规划 取值范围：枚举类型。 PACKET_LOG：报文日志。PROCESS_LOG：进程日志。 默认值：无                |
| DBGOPTION | 使能开关   | 可选必选说明：可选参数 参数含义：该参数用于开关日志调试功能。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无 配置原则：如果不设置该参数，则不指定使能开关。   |

#### 使用实例

开关指定可用RU的fei报文日志或进程日志功能：

```
SET SFEFEIDEBUG:RUNAME="VNODE_VNRS_VNFC_IPU_0067", DBGVALUE=PACKET_LOG, DBGOPTION=TRUE; 操作成功。
```
