# 显示人工倒回恢复动作执行结果（DSP NFSWOVERRES）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示网元级KPI异常检测与容灾功能的人工倒回恢复动作执行结果。

## 注意事项

- 该命令适用于适配包已配置人工倒回恢复的场景，若未配置，则返回无数据。
- 在网元级KPI异常检测与容灾功能开启时，执行**STR NFDRSWOVER**启动容灾倒回后，可通过本命令查看人工倒回恢复动作执行结果，若未执行**STR NFDRSWOVER**，则返回无数据。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

显示网元级KPI异常检测与容灾功能的人工倒回恢复动作执行结果。

```
%%DSP NFSWOVERRES:;%%
RETCODE = 0  操作成功
```

## 输出结果说明

| 输出项名称    | 输出项解释                                                            |
|:---------|:-----------------------------------------------------------------|
| 人工倒回恢复动作 | 该参数表示网元级KPI异常检测与容灾功能的人工倒回恢复动作。                                   |
| 执行时间     | 该参数表示人工倒回恢复动作的执行时间。                                              |
| 执行结果     | 该参数表示人工倒回恢复动作的执行结果。 取值说明： FAILURE（失败）SUCCESS（成功）NOTEXECUTED（未执行） |
