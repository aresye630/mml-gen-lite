# 查询目标NF实例绑定组（LST TNFBINDGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF、NCG、SMSF、CBC、CBCF**

该命令用于查询目标NF组绑定信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                       |
|:------------|:---------|:---------------------------------------------------------------------------------------------------------------------------|
| TNFGRPINDEX | 目标NF组索引  | 可选必选说明：可选参数  参数含义：本参数用于指定目标NF组索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~511。  默认值：无  配置原则：  本参数需要与ADD TNFGRP命令中的TNFGRPINDEX值保持一致。   |
| TNFINSINDEX | 目标NF实例索引 | 可选必选说明：可选参数  参数含义：本参数用于指定目标NF实例索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~2047。  默认值：无  配置原则：  本参数需要与ADD TNFINS命令中的TNFINSINDEX值保持一致。 |

## 使用实例

运营商A需要查询索引为0的目标NF组的绑定信息。

```
%%LST TNFBINDGRP:;%%
RETCODE = 0 操作成功

结果如下：
------------------------
    目标NF组索引 = 0
  目标NF实例索引 = 1
          优先级 = 1
            权重 = 50
（结果个数 = 1）

----    END
```

## 输出结果说明

| 输出项名称    | 输出项解释                                                                                  |
|:---------|:---------------------------------------------------------------------------------------|
| 目标NF组索引  | 本参数用于指定目标NF组索引。                                                                        |
| 目标NF实例索引 | 本参数用于指定目标NF实例索引。                                                                       |
| 优先级      | 本参数用于指定目标NF的优先级（与其他同类型NF实例相比）。在NF选择过程中，NF会选择高优先级的NF，如果两个或多个NF的优先级一样，NF则会根据“权重”做进一步的判断。 |
| 权重       | 本参数用于指定目标NF的相对权重（与其他同类型NF实例相比）。特别地，如果NF权重的绝对值不超过本参数的取值范围，那么本参数可以直接取用权重绝对值。             |
