# 删除匹配AS路径过滤器（RMV MATCHASPATHFILTER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来删除基于AS路径过滤器的匹配规则。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称        | 参数说明                                                                                                            |
|:-------------|:------------|:----------------------------------------------------------------------------------------------------------------|
| POLICYNAME   | 路由策略名字      | 可选必选说明：必选参数 参数含义：该参数用于指定路由策略名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无                                        |
| NODESEQUENCE | 路由策略节点号     | 可选必选说明：必选参数 参数含义：该参数用于指定路由策略节点号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无                                        |
| ASPATHNAME   | AS路径过滤器名字或号 | 可选必选说明：必选参数 参数含义：该参数用于指定AS路径过滤器号或名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～51。 默认值：无 配置原则：区分大小写，不支持空格。如果是数字则取值范围为1-256。 |

#### 使用实例

删除基于AS路径过滤器的匹配规则：

```
RMV MATCHASPATHFILTER:POLICYNAME="a",NODESEQUENCE=10, ASPATHNAME="a";
```
