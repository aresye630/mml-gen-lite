# 设置VNRS MAC表项老化时间（SET VNRSMACAGING）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来设置VNRS MAC表项的老化时间。

#### 注意事项

- 该命令执行后立即生效。

- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

该命令存在系统初始记录，参数的初始设置值如下表：

|   TIME |
|-------:|
|      5 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                             |
|:-------|:-------|:-------------------------------------------------------------------------------------------------|
| TIME   | 老化时间   | 可选必选说明：必选参数 参数含义：该参数用于指定设置的VNRS MAC表项的老化时间，单位：分钟。 数据来源：本端规划 取值范围：整数类型，取值范围为1~11999。 默认值：5 配置原则：无 |

#### 使用实例

设置VNRS MAC表项的老化时间为20分钟：

```
SET VNRSMACAGING: TIME=20;
```
