# 设置SFE透传GRE分片报文使能配置（SET SFEPASSGREFRAG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来设置SFE透传GRE分片报文使能配置。

该功能开启后，重组板不是本板的GRE分片报文，会立刻被SFE发送至目标重组板上，进行GRE分片报文重组。

#### 注意事项

- 该命令执行后立即生效。
- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。
- 该命令适用于非池化和池化场景。（池化：将VNRS、CSLB、网元转发面合并部署，将物理分散的资源整合为逻辑统一池，提升系统资源利用率）

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称          | 参数说明                                                                                                 |
|:--------------|:--------------|:-----------------------------------------------------------------------------------------------------|
| PASSGREFRAGEN | 透传GRE分片报文使能标记 | 可选必选说明：必选参数 参数含义：SFE透传GRE分片报文使能标记。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 初始值：FALSE 默认值：无 配置原则：无。 |

#### 使用实例

设置SFE透传GRE分片报文使能配置：

```
SET SFEPASSGREFRAG: PASSGREFRAGEN=TRUE;
```
