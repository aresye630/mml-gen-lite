# 增加虚拟UPF实例标识的DNAI（ADD VUPFIDBINDDNAI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于增加虚拟UPF实例标识的DNAI。

在主锚点和辅锚点会话共部署或者多辅锚点会话共部署的场景下，SMF给虚拟UPF实例标识配置DNAI，并在辅锚点会话中下发到U面，U面根据该DNAI给辅锚点会话分配相应的VPN。

## 注意事项

- 该命令执行后立即生效。

- 同一VUPFINSTANCEID下的DNAI不要重复。

- 最多可输入20480条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                        |
|:---------------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VUPFINSTANCEID | 虚拟UPF实例标识 | 可选必选说明：必选参数  参数含义：该参数用于虚拟UPF实例标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~36。该参数必须满足以下约束规则：1.如果输入为uuid格式（格式例如：a6a61c6f-0d3a-4221-b1da-424eda3ccf67）只能为A-F、a-f、0-9的字符。2.如果输入不为uuid格式，长度不能超过18且不允许输入只包含0-9和“.”的字符串，例如：1.2.3.4、不允许输入只包含十六进制数（A-F、a-f、0-9）和“:”的字符串，例如：1::2、FBFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。不区分大小写。  默认值：无  配置原则：  该参数取值应与ADD VIRTUALUPFID中参数“VUPFINSTANCEID”保持一致，使用该前需通过ADD VIRTUALUPFID添加一组记录。 |
| DNAI           | 数据网络访问标识符 | 可选必选说明：必选参数  参数含义：该参数表示虚拟UPF实例标识的DNAI。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~50。不能为非法字符，只允许输入字母，数字、“_”、“.”，并且开头和结尾只能是数字或者字母，不能出现连续两个“.”，不区分大小写。  默认值：无  配置原则：无                                                                                                                                                                                                                                                    |

## 使用实例

增加虚拟UPF实例标识为v\_upf1的DNAI为huawei.com：

```
ADD VUPFIDBINDDNAI:VUPFINSTANCEID="v_upf1",DNAI="huawei.com";
```
