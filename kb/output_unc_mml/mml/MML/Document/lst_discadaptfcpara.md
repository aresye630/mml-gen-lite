# 查询服务发现自适应流控全局配置（LST DISCADAPTFCPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF、SMF、NSSF、SMSF、NCG、CBC、CBCF**

该命令用于查询服务发现自适应流控全局配置。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询服务发现自适应流控全局配置

```
%%LST DISCADAPTFCPARA:;%%
RETCODE = 0  操作成功

结果如下
--------
自适应流控NRF返回码  =  429-503-504-604-605
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称       | 输出项解释                                                                                   |
|:------------|:----------------------------------------------------------------------------------------|
| 自适应流控NRF返回码 | 该参数用于指定自适应流控NRF返回码。如果服务发现的NRF返回码匹配这里的配置，则认为本次服务发现处于流控状态；系统会根据这些返回码的统计信息动态调整到NRF服务发现的速率。 |
