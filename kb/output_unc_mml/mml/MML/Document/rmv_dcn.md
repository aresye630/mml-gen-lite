# 删除DCN(RMV DCN)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

此命令用于删除一条DCN记录。例如运营商为合理规划网络，将原有DCN划分删除，删除后将不能通过UE USAGE TYPE映射到此DCN。

#### 注意事项

该命令执行后立即生效。

执行该命令前需要删除同一“DCN ID”下的DCN映射关系和DCN成员，请执行**LST DCNMAP**和**LST DCNMEMBER**查询记录是否存在。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                      |
|:-------|:-------|:----------------------------------------------------------|
| DCNID  | DCN ID | 可选必选说明：必选参数 参数含义：该参数用来指定DCN标识。 数据来源：全网规划 取值范围：0~255 默认值：无 |

#### 使用实例

MCC为123，MNC为01的运营商为合理规划网络，将eMtc用户所属DCN ID为0的网络删除：

RMV DCN: DCNID=0;
