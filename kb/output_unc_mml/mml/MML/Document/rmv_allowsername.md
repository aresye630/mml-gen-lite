# 删除基于地址的白名单（RMV ALLOWSERNAME）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除基于服务地址的指定NF的服务的白名单信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                              |
|:-------|:-------|:----------------------------------------------------------------------------------|
| INDEX  | 索引     | 可选必选说明：必选参数  参数含义：该参数用于指定白名单索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~2047。  默认值：无  配置原则：无 |

## 使用实例

删除标识为SMF\_Instance\_0的NF实例服务白名单信息:索引为0。

```
RMV ALLOWSERNAME: INDEX=0;
```
