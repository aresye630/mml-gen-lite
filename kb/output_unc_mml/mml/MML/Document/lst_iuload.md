#### 命令功能

**适用网元：SGSN**

该命令用于查询Iu接口负荷在SGP进程间分担的控制参数。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询IU接口负荷参数：

LST IULOAD:;

```
%%LST IULOAD:;%%
RETCODE = 0  操作成功。

IU负荷配置表
------------
           是否支持Iu负荷分担  =  是
    周期性通知定时器长度(min)  =  5
发送OVERLOAD消息定时器长度(s)  =  40
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见**SET IULOAD**的参数说明。
