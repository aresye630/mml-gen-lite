# 增加4G TA群组（ADD S1RANTAGP）

#### 命令功能

**适用网元：MME**

该命令用于增加跟踪区群组记录。跟踪区群组用于定义一组TA组成的区域，以该区域为粒度进行业务策略控制。需要结合**ADD S1RANTAGPMEM**命令为跟踪区群组添加成员。

该命令的使用场景：当运营商希望只允许在白名单TAC区的基站接入时，可使用该命令配合**SET S1RANACCCTRL**命令开启对应功能。

#### 注意事项

- 该命令执行后立即生效。
- 该命令的最大记录数为256。

#### 本地用户权限

manage-ug；system-ug；

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；

#### 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                          |
|:------------|:--------|:------------------------------------------------------------------------------|
| S1RANTAGPID | 跟踪区群组标识 | 可选必选说明：必选参数 参数含义：该参数用于指定跟踪区群组标识。 数据来源：本端规划 取值范围：整数类型，取值范围是1~256。 默认值：无        |
| TANAME      | 跟踪区群组名称 | 可选必选说明：可选参数 参数含义：该参数用于指定跟踪区群组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围是0~32。 默认值：noname |

#### 使用实例

增加一个TA群组，跟踪区群组标识为1，其群组名称为“shanghai”。

```
ADD S1RANTAGP: S1RANTAGPID=1, TANAME="shanghai";
```
