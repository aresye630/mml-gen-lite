# 查询全局默认CHF组（LST GLBDFTCHFGROUP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于查询全局默认CHF组。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询全局CHF组配置：

```
%%LST GLBDFTCHFGROUP:;%%
RETCODE = 0  操作成功

结果如下
--------
主CHF组  =  NULL
备CHF组  =  NULL
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释            |
|:--------|:-----------------|
| 主CHF组   | 该参数用于设置主CHF组的名称。 |
| 备CHF组   | 该参数用于设置备CHF组的名称。 |
