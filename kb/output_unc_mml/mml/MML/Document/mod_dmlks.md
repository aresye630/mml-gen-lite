# 修改Diameter链路集配置(MOD DMLKS)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于修改一条Diameter链路集配置。当需要修改Diameter链路集的“本地实体索引”，“对端实体索引”，“选路模式”和“链路集名称”的全部或部分信息时，用此命令进行修改。

#### 注意事项

- 该命令执行后立即生效。
- 该命令不能修改Diameter链路集索引。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称          | 参数说明                                                                                                                                                                                                                                                                                                                                                       |
|:----------|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LINKSIDX  | Diameter链路集索引 | 可选必选说明：必选参数 参数含义：该参数用于指定准备修改的Diameter链路集的索引。 数据来源：本端规划 取值范围：0～639 默认值：无  说明： 可以通过LST DMLKS命令查看已有配置，确认所要修改的Diameter链路集的索引。                                                                                                                                                                                                                                  |
| LOCALIDX  | 本地实体索引        | 可选必选说明：可选参数 参数含义：该参数用于指定Diameter链路集的本地实体索引。 前提条件：在“MML命令行-UNC”窗口上执行命令 ADD DMLE设置此参数。 数据来源：本端规划 取值范围：0～31 默认值：无                                                                                                                                                                                                                                             |
| PEERIDX   | 对端实体索引        | 可选必选说明：可选参数 参数含义：该参数用于指定Diameter链路集的对端实体索引。 前提条件：在“MML命令行-UNC”窗口上执行命令 ADD DMPE设置此参数。 数据来源：本端规划 取值范围：0～639 默认值：无  说明： 修改后，该链路集上业务将倒换到新的对端实体进行。与原对端实体间业务将中断。                                                                                                                                                                                                 |
| LSSELMODE | 选路模式          | 可选必选说明：可选参数 参数含义：该参数用于指定选路模式，用于表示Diameter链路集采用何种方式选择Diameter链路进行业务。 数据来源：整网规划 取值范围：“SELMODE_ROUND_ROBIN(轮选)”：表示存在多条链路时，采用顺序选择的方式选取各条链路。“SELMODE_LOAD_BALAN(负荷分担模式)”：表示在链路集中所有处于激活状态的链路以负荷分担的方式传输业务。“SELMODE_MASTER_SLAVE(主从)”：表示1＋N备份模式。在这种模式中，业务仅在链路集中的一条链路上传输，其余链路均处于备份状态。“SELMODE_ACTIVE(激活)”：表示使用上次使用的链路。 默认值：无 配置原则：建议值为“SELMODE_LOAD_BALAN(负荷分担模式)”。 |
| LINKSNAM  | 链路集名称         | 可选必选说明：可选参数 参数含义：该参数用于指定链路集名称，标识Diameter链路集。 数据来源：本端规划 取值范围：0～32位字符串 默认值：无 配置原则：建议取有实际意义的名称，以方便识别。例如“To-HSS0”。                                                                                                                                                                                                                                             |

#### 使用实例

将Diameter链路集索引为0的链路集的对端实体索引修改为1，选路模式修改为SELMODE\_MASTER\_SLAVE:

MOD DMLKS:LINKSIDX=0,PEERIDX=1,LSSELMODE=SELMODE\_MASTER\_SLAVE;
