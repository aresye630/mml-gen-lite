# 增加LAC组内LAC号段（ADD ADDRLACID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用来在LAC组内绑定LAC号段。当需要在指定LAC组内绑定某个LAC号段时，使用该命令。

## 注意事项

- 该命令执行后只对新激活用户生效。

- 当一个LAC号段被绑定到某个LAC组内后，就不允许再绑定到其他的LAC组。LAC号段之间的LAC值不允许重叠。

- 最多可输入24000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                                                                                      |
|:-------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LACGROUPNAME | LAC组名   | 可选必选说明：必选参数  参数含义：该参数用于指定LAC组名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。  默认值：无  配置原则：  该参数使用ADD ADDRLACGROUP命令配置生成。                                                                           |
| LACSECNUM    | LAC段编号  | 可选必选说明：必选参数  参数含义：该参数用于指定LAC段编号。  数据来源：本端规划  取值范围：整数类型，取值范围是0~23999。  默认值：无  配置原则：无                                                                                                       |
| LACSTARTID   | LAC起始ID | 可选必选说明：必选参数  参数含义：该参数用于指定LAC起始ID。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~10。十六进制，仅支持输入0x/X、a-f/A-F 、0-9，允许不输入0x前缀，字母不区分大小写，取值范围0x0001~0xFFFD，0xFFFF。  默认值：无  配置原则：  LACSTARTID的取值应小于或等于LACENDID。 |
| LACENDID     | LAC终止ID | 可选必选说明：必选参数  参数含义：该参数用于指定LAC终止ID。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~10。十六进制，仅支持输入0x/X、a-f/A-F 、0-9，允许不输入0x前缀，字母不区分大小写，取值范围0x0001~0xFFFD，0xFFFF。  默认值：无  配置原则：  LACENDID的取值应大于或等于LACSTARTID。 |

## 使用实例

在一个本地已经配置的LAC组绑定一个LAC号段：

```
ADD ADDRLACID:LACGROUPNAME="beijing",LACSECNUM=2,LACSTARTID="0x0001",LACENDID="0x0010";
```
