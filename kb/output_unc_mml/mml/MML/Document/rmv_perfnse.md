# 删除NSE标识(RMV PERFNSE)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用于删除指定的NSE标识。

#### 注意事项

- 该命令执行后立即生效。
- 若未输入参数，表示删除所有记录。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                   |
|:-------|:-------|:---------------------------------------------------------------------------------------|
| NSEI   | NSE标识  | 可选必选说明：可选参数 参数含义：该参数用于指定网络服务实体标识。 取值范围：0～65535 默认值：无  说明： 输入的NSEI必须能够通过LST PERFNSE查询到。 |

#### 使用实例

1. 删除NSE列表下所有记录：

   RMV PERFNSE:;
2. 删除NSEI为10的NSE：

   RMV PERFNSE: NSEI=10;
