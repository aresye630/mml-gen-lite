# 显示ucfexec-pod的磁盘空间大小（DSP UCFDISKSIZE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此命令用于查询ucfexec-pod的磁盘空间大小。

## 注意事项

执行命令前请确认UCF服务处于上线状态。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询ucfexec-pod的磁盘空间：

```
%%DSP UCFDISKSIZE: ;%%
RETCODE = 0  操作成功

结果如下
--------
UCF Pod Id      UCF可用磁盘总空间(GB)

ucfexec-pod-0   64         
ucfexec-pod-1   64    
(结果个数 = 2)       

---    END
```

## 输出结果说明

| 输出项名称          | 输出项解释                        |
|:---------------|:-----------------------------|
| UCF Pod Id     | 该参数用于表示UCF服务的Pod Id。         |
| UCF可用磁盘总空间(GB) | 该参数用于表示UCF服务当前可用磁盘总空间，单位为GB。 |
