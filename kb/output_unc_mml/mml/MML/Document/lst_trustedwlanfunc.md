# 查询可信Non-3GPP接入开关（LST TRUSTEDWLANFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于查询可信Non-3GPP接入开关。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询可信Non-3GPP接入开关：

```
%%LST TRUSTEDWLANFUNC:;%%
RETCODE = 0  操作成功

结果如下
--------
可信Non-3GPP接入开关  =  不使能
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称          | 输出项解释                      |
|:---------------|:---------------------------|
| 可信Non-3GPP接入开关 | 本参数用于控制是否使能可信Non-3GPP接入功能。 |
