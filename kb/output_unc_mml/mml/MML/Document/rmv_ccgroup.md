# 删除计费特征组（RMV CCGROUP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、GGSN**

该命令用于删除计费特征组。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                  |
|:------------|:--------|:----------------------------------------------------------------------------------------------------------------------|
| CCGROUPNAME | 计费特征组名称 | 可选必选说明：必选参数  参数含义：该参数用于计费特征组的名字，在系统内唯一。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。由英文字母（大小写）、数字、下划线构成，不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

删除“计费特征组名称”为“c1”的计费特征组配置：

```
RMV CCGROUP: CCGROUPNAME="c1";
```
