# 显示AMF冲突规则生效状态（DSP AMFCONFLICTRULE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于显示AMF冲突规则生效状态。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                        |
|:------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------|
| CSTYPE      | CS类型   | 可选必选说明：必选参数  参数含义：该参数用于指定CS类型。  数据来源：本端规划 取值范围： UEAM（UEAM模块）LOCM（LOCM模块）UEM（UEM模块）AMPOLICY（AMPOLICY模块）  默认值：无  配置原则：无                       |
| PROCTYPE    | 流程内部标识 | 可选必选说明：必选参数  参数含义：该参数用于指定流程内部类型。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~64。不能为非法字符，只允许输入字母，数字，区分大小写。例如：ProcTypeIntraAmfInitialReg。  默认值：无  配置原则：无  |
| INITEVENTID | 初始事件类型 | 可选必选说明：必选参数  参数含义：该参数用于指定触发新流程的初始事件类型。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~64。不能为非法字符，只允许输入字母，数字，区分大小写。例如：InitIntraRegistration。  默认值：无  配置原则：无 |

## 使用实例

查询该条规则是否生效，规则如下: 在IntraAmfHandover流程中，如果收到了NG-RAN的“RRC Inactive Transition Report”消息，则执行抢占策略。

```
DSP AMFCONFLICTRULE: CSTYPE=UEAM, PROCTYPE="IntraAmfHandover", INITEVENTID="InitN2NotifyEvent";
```

## 输出结果说明

| 输出项名称    | 输出项解释                                                |
|:---------|:-----------------------------------------------------|
| 冲突流程规则   | 该参数用于指定冲突流程规则。                                       |
| 冲突规则是否生效 | 该参数用于显示AMF配置的冲突规则是否生效，如果生效，则显示YES；如果未生效，则显示NO和未生效原因。 |
