# 配置ARP系统信息（SET ARPSYS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于配置系统老化时间、全局ARP严格学习使能、ARP日志告警上报时间间隔和免费ARP发送类型。

#### 注意事项

- 该命令执行后立即生效。
- 全局配置ARP表项老化时间，接口下ARP表项老化时间配置为默认值时，全局配置生效。全局和接口下同时配置ARP表项老化时间，接口下配置生效。
- 至少要配置一个参数。
- 该命令存在系统初始记录，参数的初始设置值如下表：

|   EXPIRETIME | LEARNSTRICTENABLE   |   LOGTRAPINTERVAL | GRATTYPE   |
|-------------:|:--------------------|------------------:|:-----------|
|         1200 | False               |                 0 | Request    |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识              | 参数名称             | 参数说明                                                                                                                                          |
|:------------------|:-----------------|:----------------------------------------------------------------------------------------------------------------------------------------------|
| EXPIRETIME        | 表项老化时间（s）        | 可选必选说明：可选参数 参数含义：该参数用于指定动态ARP表项生存时间。 数据来源：本端规划 取值范围：整数类型，取值范围为60～86400，单位是秒。 默认值：无                                                            |
| LEARNSTRICTENABLE | 全局ARP严格学习使能      | 可选必选说明：可选参数 参数含义：该参数用于指定全局ARP严格学习是否使能。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无                                                        |
| LOGTRAPINTERVAL   | ARP日志告警上报时间间隔（s） | 可选必选说明：可选参数 参数含义：该参数用于指定ARP写日志和发送告警的时间间隔。 数据来源：本端规划 取值范围：整数类型，取值范围为0～1200，单位是秒。 默认值：无 配置原则： 当该参数初始值为0时，将抑制告警。如果需要上报告警，建议配置ARP日志告警上报时间间隔为300s。 |
| GRATTYPE          | 免费ARP发送类型        | 可选必选说明：可选参数 参数含义：该参数用于指定发送免费ARP报文的类型。 数据来源：本端规划 取值范围：枚举类型。 Request：请求。Reply：应答。 默认值：无                                                         |

#### 使用实例

配置ARP全局老化时间为80秒，免费ARP发送类型为应答：

```
SET ARPSYS:EXPIRETIME=80,GRATTYPE=Reply;
```
