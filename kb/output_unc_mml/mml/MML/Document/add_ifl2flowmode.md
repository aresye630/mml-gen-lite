# 配置主接口二层透传模式（ADD IFL2FLOWMODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来配置接口的二层透传模式。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为7。
- 该命令目前只支持主接口配置，不支持子接口。
- 配置该命令后，接口下配置的其它命令将不生效，转发不再走3层转发流程，而走2层透传。
- 入接口和出接口均需要配置该命令，这样才能实现报文透传。
- 同一个VPN不能同时绑定多个配置了该命令的接口。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                          |
|:-------|:-------|:----------------------------------------------------------------------------------------------|
| IFNAME | 接口名称   | 可选必选说明：必选参数 参数含义：接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～47。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。 |

#### 使用实例

配置指定主接口的二层透传模式：

```
ADD IFL2FLOWMODE:IFNAME="Ethernet66/0/5";
```
