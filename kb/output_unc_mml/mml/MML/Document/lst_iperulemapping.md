# 查询智能规则和智能业务编码组的绑定关系（LST IPERULEMAPPING）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于查询智能规则和智能业务编码组的绑定关系。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                                                                                                         |
|:-----------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RULENAME   | 智能规则名称  | 可选必选说明：可选参数  参数含义：该参数用于设置规则名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。不支持空格，不区分大小写。  默认值：无  配置原则：  该参数的取值来源于已经配置的ADD RULE命令的“RULENAME”参数，且该命令的“NWDAFEVENTS”参数必须配置为“IPE_SERVICE”。 |
| SRVCODEGRP | 智能业务编码组 | 可选必选说明：可选参数  参数含义：该参数用于指定业务编码组的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。不支持空格，不区分大小写。  默认值：无  配置原则： 该参数使用ADD SRVCODEGRP命令配置生成。配置的SRVCODEGRP必须是系统已经存在的SrvCodeGrp对象名称。           |

## 使用实例

查询智能规则“intelligent”和智能业务编码组的绑定关系：

```
%%LST IPERULEMAPPING: RULENAME="intelligent";%%
RETCODE = 0  操作成功

结果如下
------------------------
  智能规则名称  =  intelligent
智能业务编码组  =  codegrp
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释            |
|:--------|:-----------------|
| 智能规则名称  | 该参数用于设置规则名称。     |
| 智能业务编码组 | 该参数用于指定业务编码组的名称。 |
