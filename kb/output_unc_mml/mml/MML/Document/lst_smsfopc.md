# 查询SMSF本局信令点(LST SMSFOPC)

- 命令功能
- 注意事项
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SMSF**

该命令用于查询配置的SMSFOPC本局信令点。

#### 注意事项

无。

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                  |
|:-------|:----------|:----------------------------------------------------------------------|
| OPX    | SMSF信令点索引 | 可选必选说明：可选参数 参数含义：该参数用于指定SMSF本局信令点索引。 数据来源：本端规划 取值范围：1～10 默认值：无 配置原则：无 |

#### 使用实例

查询已经配置的所有的SMSFOPC记录。

```
%%LST SMSFOPC:;%%
RETCODE = 0  操作成功 
The result is as follows 
------------------------ 
SMSF信令点索引  网络指示语     本局信令点编码 本局SMSF号     本局信令点名  是否主用信令点

1               国内网         0x17701  861390211101          noname         YES
2               国际网         0x1      861                   noname         NO
(结果个数 = 2)
```
