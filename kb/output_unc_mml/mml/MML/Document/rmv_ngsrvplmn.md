# 删除5G Serving PLMN（RMV NGSRVPLMN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

删除Serving PLMN可能影响AMF给无线侧广播的PLMN信息。

**适用NF：SGW-C、PGW-C、AMF、SMF、NRF、NSSF、CBC、CBCF**

该命令用于删除指定的Serving PLMN。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                    |
|:--------|:-------|:----------------------------------------------------------------------------------------|
| PLMNIDX | PLMN索引 | 可选必选说明：必选参数  参数含义：该参数用于在系统内唯一标识一个PLMN。  数据来源：本端规划  取值范围：整数类型，取值范围是0~127。  默认值：无  配置原则：无 |

## 使用实例

为运营商A删除Serving PLMN信息（索引为0），执行如下命令：

```
RMV NGSRVPLMN: PLMNIDX=0;
```
