#### 命令功能

**适用网元：MME**

此命令用于查看MMEID配置表。

#### 注意事项

此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查看MMEID配置表：

LST MMEID:;

```
%%LST MMEID:;%%
RETCODE = 0  操作成功。

操作结果如下
--------------
       移动国家码  =  308
         移动网码  =  01
      MME组识别码  =  8001
 MME编码（起始值） =  01
      MME编码数目  =  1
(结果个数 = 1)

---    END
```
