# 查询NF类型白名单（LST NFTYPEWHITELIST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NRF**

该命令用于查询NF类型白名单中的NF类型。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询白名单中的网元类型列表，执行如下命令：

```
LST NFTYPEWHITELIST:;

%%LST NFTYPEWHITELIST:;%%
RETCODE = 0  操作成功

结果如下
------------------------
NF类型 =  AMF
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                  |
|:--------|:-----------------------|
| NF类型    | 该参数用于表示需要增加到白名单中的NF类型。 |
