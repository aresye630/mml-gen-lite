# 查询路由开销值设置（LST APPLYCOST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询设置路由开销值的配置结果。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                     |
|:-----------|:-------|:-------------------------------------------------------------------------|
| POLICYNAME | 路由策略名字 | 可选必选说明：可选参数 参数含义：该参数用于指定路由策略名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无 |

#### 使用实例

查询设置路由开销值配置信息：

```
LST APPLYCOST:;
```

```
RETCODE = 0  操作成功

结果如下
--------
      应用选择  =  代替路由的原有开销值
  路由策略名字  =  1
路由策略节点号  =  1
        Cost值  =  10
(结果个数 = 1)
---    END
```
