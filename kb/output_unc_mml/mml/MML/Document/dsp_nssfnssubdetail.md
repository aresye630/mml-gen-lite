# 显示切片可用性订阅详细信息（DSP NSSFNSSUBDETAIL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NSSF**

该命令用于显示切片可用性订阅详细信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                 |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBID  | 订阅标识   | 可选必选说明：必选参数  参数含义：该参数表示订阅标识，通过该参数指定需要查询的订阅，该参数可通过DSP NSSFNSSUBINFO命令获取。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~40。该参数只能由小写字母（a-z）、数字（0-9）组成。  默认值：无  配置原则：无 |

## 使用实例

运营商想要查询切片可用性订阅详细信息时，执行此命令。

```
DSP NSSFNSSUBDETAIL: SUBID="0004c7d76079f5a24517a4e03d90e484975c";
```

## 输出结果说明

| 输出项名称        | 输出项解释                                                                                                |
|:-------------|:-----------------------------------------------------------------------------------------------------|
| 订阅标识         | 该参数表示订阅标识，通过该参数指定需要查询的订阅，该参数可通过DSP NSSFNSSUBINFO命令获取。                                                |
| 订阅通知URI      | 该参数表示订阅信息中的通知URI。                                                                                    |
| 移动国家码        | 该参数用于描述移动国家码。                                                                                        |
| 移动网号         | 该参数用于描述移动网号。                                                                                         |
| 跟踪区域码        | 该参数用于描述跟踪区域码。                                                                                        |
| AMF集合标识      | 该参数用于描述订阅适用的AMF集合。                                                                                   |
| 过期时间         | 该参数用于表示该订阅的过期时间，若当前时间超过过期时间则该订阅失效。                                                                   |
| 从本NSSF生成标识   | 该参数表示该订阅是否从本NSSF生成，取值范围为TRUE和FALSE，TRUE表示从本NSSF生成，FALSE表示从容灾的另一个NSSF生成。 取值说明： TRUE(TRUE)FALSE(FALSE) |
| HTTP请求的via头域 | 该参数表示HTTP请求的via头域。                                                                                   |
