# 修改注册中心链路 (MOD RCAPLNK)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SMSF**

此命令用于修改注册中心的链路配置。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|:------------|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LNK         | 链路索引       | 可选必选说明：必选参数 参数含义：该参数用于指定链路的索引。在系统范围内部唯一标识一条Rcenter链路。 数据来源：整网规划 取值范围：0~1023 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| RCAPLNKNM   | RCAP链路名称   | 可选必选说明：可选参数 参数含义：该参数用于指定Rcenter链路的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1~63 默认值：NONAME 配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| SCTPINDX    | SCTP协议参数索引 | 可选必选说明：可选参数 参数含义：该参数用于指定所引用的SCTP协议参数索引。 前提条件：该SCTP协议参数已在ADD SCTPPARA命令中配置。 数据来源：整网规划 取值范围：0~65534 默认值：无  说明： 修改“SCTP协议参数索引”影响请参见ADD SCTPPARA。                                                                                                                                                                                                                                                                                                                                                                                          |
| CROSSIPFLAG | 交叉路径是否可用   | 可选必选说明：可选参数 参数含义：该参数用于指定SCTP双归属的交叉路径是否可用。 数据来源：整网规划 取值范围：“NO(否)”“YES(是)” 默认值：无 配置原则： 交叉路径会增加组网的复杂度，建议配置为交叉路径不可用。SCTP双归属下配置交叉路径不可用时，“本地IPv4地址1”与“RCAP IPv4地址1”，“本地IPv4地址2”与“RCAP IPv4地址2”两条路径可用，“本地IPv4地址1”与“RCAP IPv4地址2”，“本地IPv4地址2”与“RCAP IPv4地址1”两条路径不可用。SCTP双归属下配置交叉路径可用时，“本地IPv4地址1”与“RCAP IPv4地址1”，“本地IPv4地址1”与“RCAP IPv4地址2”，“本地IPv4地址2”与“RCAP IPv4地址1”，“本地IPv4地址2”与“RCAP IPv4地址2”四条路径均可用。  说明： 修改交叉路径是否可用将使链路的可靠性受到影响。若之前交叉路径可用，且“本地IPv4地址1”与“RCAP IPv4地址1”，“本地IPv4地址2”与“RCAP IPv4地址2”两条路径故障，正在使用交叉路径进行通信，修改为交叉路径不可用时，将导致链路中断。 |

#### 使用实例

1.将链路索引为1的交叉路径是否可用改为是：

MOD RCAPLNK: LNK=1, CROSSIPFLAG=Yes;
