# 查询CMPCC调试命令（LST CMPCCDBGDATA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C、SMF、GGSN**

该命令用于查询SMF网元上计费策略组件的调试信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                              |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CSTYPE | 指定CS类型 | 可选必选说明：可选参数  参数含义：该参数用于指定CS的类型。  数据来源：本端规划 取值范围： SM4GCM（会话管理4G计费cell服务）RADIUSACCT（会话管理AAA计费cell服务）SM4GPOLICY（会话管理4G策略cell服务）GA（会话管理Ga链路cell服务）GY（会话管理Ga链路cell服务）GX（会话管理Gx链路cell服务）  默认值：无  配置原则：无 |

## 使用实例

查询指定CsType为SM4GCM的调试信息

```
%%LST CMPCCDBGDATA:CSTYPE = SM4GCM;%%
RETCODE = 0  操作成功

结果如下
------------------------
指定CS类型 = 	会话管理4G计费cell服务
调试信息 = cmcore cnt excpcnt
调试信息参数 = clean
(结果个数 = 1)

---    END
```

| 输出项名称   | 输出项解释               |
|:--------|:--------------------|
| 指定CS类型  | 该参数用于指定CS的类型。       |
| 调试信息    | 该参数用于表示调试信息。        |
| 调试信息参数  | 该参数用于指定软件调试命令下发的参数。 |
