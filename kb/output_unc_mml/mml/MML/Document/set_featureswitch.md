# 设置特性开关（SET FEATURESWITCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置网元的特性开关。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| NAME                    | STATUS   |
|:------------------------|:---------|
| VMPODINCONSISTENCYALARM | ON       |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                    |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------|
| NAME   | 名称     | 可选必选说明：必选参数  参数含义：该参数表示特性功能的名称。  数据来源：本端规划 取值范围： VMPODINCONSISTENCYALARM（VM POD关系不一致告警）  默认值：无。  配置原则：无 |
| STATUS | 状态     | 可选必选说明：必选参数  参数含义：该参数表示特性功能的状态。  数据来源：本端规划 取值范围： ON（开启）OFF（关闭）  默认值：无。  配置原则：无                          |

## 使用实例

当运营商需要关闭“VM POD关系不一致告警”特性，可使用该命令进行设置。

```
%%SET FEATURESWITCH: NAME=VMPODINCONSISTENCYALARM, STATUS=OFF;%%
```
