# 显示SGs链路状态(DSP SGSLNK)

- 命令功能

- 本地用户权限

#### 命令功能

**适用网元：MME**

此命令用于查看SGs链路状态。

#### 注意事项

无

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                              |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SRT    | 查询方式   | 可选必选说明：可选参数 参数含义：该参数用于指定查询SGs链路状态的方式。 取值范围：“ALL(所有)”：查询所有SGs链路的状态。“LNK(链路)”：通过指定链路索引查询SGs链路的状态。“LSX(链路集)”：通过指定链路集查询SGs链路的状态。“VLR(VLR号)”：通过指定VLR号查询SGs链路的状态。 默认值：无 |
| LNK    | 链路索引   | 可选必选说明：条件可选参数 参数含义：待查询链路的索引。 前提条件：该参数在“查询方式”设置为“LNK(链路)”时生效。 取值范围：0~511 默认值：无                                                                                     |
| LSX    | 链路集索引  | 可选必选说明：条件可选参数 参数含义：待查询链路所属链路集的索引。 前提条件：该参数在“查询方式”设置为“LSX(链路集)”时生效。 取值范围：0~255 默认值：无                                                                               |
| VN     | VLR号   | 可选必选说明：条件可选参数 参数含义：待查询链路的VLR号。 前提条件：该参数在“查询方式”设置为“VLR(VLR号)”时生效。 取值范围：1~15位十进制数字 默认值：无                                                                            |

#### 使用实例

1. 查询系统内所有的SGs链路状态信息：

   DSP SGSLNK: SRT=ALL;

   ```
   USN_SP_RU_0064    0              5             5                NULL        86139064208    故障
   ```

2. 查询指定VLR号的SGs链路状态信息：

   DSP SGSLNK: SRT=VLR, VN="1230301";

   ```

   RETCODE = 0  操作成功。

   操作结果如下
   ```

#### 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                            |
|:--------|:---------------------------------------------------------------------------------------------------------------------------------|
| RU名称    | SGs链路的资源单位名称。 取值说明：1～63位字符串                                                                                                      |
| 进程号     | SGs链路的进程号。 取值说明：0~11                                                                                                             |
| 链路索引    | SGs链路的索引。 取值说明：0~511                                                                                                             |
| 链路集索引   | SGs链路所属链路集的索引。 取值说明：0~255                                                                                                        |
| VPN名称   | SGs链路的VPN名称。 取值说明：1～31位字符串                                                                                                       |
| VLR号    | SGs链路的VLR号。 取值说明：1~15位十进制数字                                                                                                      |
| SGs链路状态 | SGs链路所处状态。 取值说明：正常：表示UNC与MSC/VLR之间的通信在该链路上正常。故障：表示UNC与MSC/VLR之间的通信在该链路上中断，需要检查网络状况，分析故障原因。详细操作参见SGs链路故障告警处理。去激活：表示该SGs链路处于去激活状态。 |
