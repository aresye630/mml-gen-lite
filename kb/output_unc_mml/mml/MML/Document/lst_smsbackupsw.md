# 查询SMSF热备容灾功能开关状态（LST SMSBACKUPSW）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMSF**

该命令用于查询SMSF热备容灾功能开关状态。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

运营商希望查询SMSF热备容灾功能开关状态时，执行如下命令：

```
LST SMSBACKUPSW:;
%%LST SMSBACKUPSW:;%%
RETCODE = 0  操作成功

结果如下：
--------------
 SMSF热备容灾功能开关  =  打开	

(结果个数 = 1)
```

## 输出结果说明

| 输出项名称        | 输出项解释                |
|:-------------|:---------------------|
| SMSF热备容灾功能开关 | 该参数用于表示SMSF热备容灾功能开关。 |
