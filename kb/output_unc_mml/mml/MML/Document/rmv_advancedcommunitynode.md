# 删除高级团体属性过滤器节点（RMV ADVANCEDCOMMUNITYNODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来删除高级团体属性过滤器节点。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称        | 参数说明                                                                                        |
|:---------------|:------------|:--------------------------------------------------------------------------------------------|
| CMNTYNAMEORNUM | 团体属性过滤器名字或号 | 可选必选说明：必选参数 参数含义：该参数用于指定团体属性过滤器名字或团体属性过滤器号。 数据来源：本端规划 取值范围：字符串类型，团体属性过滤器名称其长度范围是1～51。 默认值：无 |
| NODESEQUENCE   | 团体属性过滤器节点ID | 可选必选说明：必选参数 参数含义：团体属性过滤器节点ID。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无                  |
| REGULAR        | 正则表达式       | 可选必选说明：可选参数 参数含义：正则表达式。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～1024。 默认值：无 配置原则：支持空格。                |

#### 使用实例

删除高级团体属性过滤器节点：

```
RMV ADVANCEDCOMMUNITYNODE:NODESEQUENCE=1,CMNTYNAMEORNUM="ab";
```
