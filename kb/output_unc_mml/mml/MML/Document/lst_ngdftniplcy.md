# 查询5G缺省NI策略（LST NGDFTNIPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询AMF的缺省NI（Network Identity）策略。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询5G缺省NI策略，执行如下命令：

```
%%LST NGDFTNIPLCY:;%%
RETCODE = 0  操作成功

结果如下
------------------------
 基于DNN下发缺省NI功能开关  =  开启
            缺省NI取值策略  =  NGMNO&NITZPLCY&AMFPLCYFUNC
      是否使用最小签约数据  =  是
        空闲态用户寻呼开关  =  关闭
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称           | 输出项解释                                                                                                                                                                                                                                                                                                               |
|:----------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 基于DNN下发缺省NI功能开关 | 该参数用于控制AMF是否支持基于特定DNN关键字下发缺省NI功能。当本参数设置为"ON"时，AMF会根据配置的特定DNN关键字（ADD DFTNIDNN配置）匹配用户签约的DNN来判断是否向用户下发缺省NI；如果DNN匹配不成功，AMF不下发缺省NI。                                                                                                                                                                                      |
| 缺省NI取值策略        | 该参数用于控制AMF缺省NI下发策略。 对于勾选的缺省NI下发时，AMF会根据配置的特定DNN关键字（ADD DFTNIDNN配置）匹配用户签约的DNN来判断是否向用户下发缺省NI；如果DNN匹配成功，AMF下发缺省NI。 对于未勾选的缺省NI下发时，不考虑用户是否签约特定DNN，默认下发缺省NI。 说明： 在开启基于PCF的动态NI功能的场景下，当PCF取消动态NI时，网络侧下发的缺省NI取值优先级如下：SET AMFPLCYFUNC>ADD NITZPLCY>ADD NGMNO; 在未开启基于PCF的动态NI功能的场景下，网络侧下发的缺省NI取值优先级如下：ADD NITZPLCY>ADD NGMNO。 |
| 是否使用最小签约数据      | 该参数用于控制是否使用最小签约数据（ADD UDMBYPASSSUB中SNSSAIINFOS参数）进行DNN关键字匹配。 当用户进入UDM BYPASS状态后，由于无法获取用户真实的签约数据，在开启“基于DNN下发缺省NI功能开关”时，DNN会匹配失败，用户始终不下发缺省NI，该参数用于控制是否使用最小签约数据替代真实签约数据进行DNN匹配。                                                                                                                                        |
| 空闲态用户寻呼开关       | 该参数用于控制UDM签约数据变更DNN与DFTNIDNN匹配，且AMF开启基于DNN下发缺省UELogo时是否立即寻呼空闲态用户。 当本参数设置为"ON"时，AMF立即寻呼UE并通过Configuration Update Command消息通知UE缺省UELogo，否则AMF待后续移动管理流程通知UE。                                                                                                                                                           |
