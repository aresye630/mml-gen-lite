# 清除异常信息记录（RMV DEBUGRECORD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于清除异常信息记录。

#### 注意事项

- 该命令执行后立即生效。
- 本操作会删除异常记录信息。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                                                                                     |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RUNAME          | RU名称   | 可选必选说明：可选参数 参数含义：该参数用于表示RU名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则： 当不输入时显示所有的资源单元或资源的信息。当本命令在VNFP上使用时，需要先使用DSP RES查到“资源名称”，然后将“资源名称”的取值配置到本参数。当本命令在VNFC上使用时，需要先使用DSP RU查到“RU名称”，然后将“RU名称”的取值配置到本参数。 |
| RECORDTYPE      | 记录类型   | 可选必选说明：必选参数 参数含义：该参数用于表示异常类型。 数据来源：本端规划 取值范围：枚举类型。 EXCEPTION：异常。ASSERT：断言。DEADLOOP：死循环。REPORTFAILURE：组件上报故障。STARVATION：消息调度不及时。MEMERROR：内存错误。PROCESSRESET：进程复位信息。 默认值：无                                                  |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。                                                                                                             |

#### 使用实例

清除异常类信息：

```
RMV DEBUGRECORD:RECORDTYPE=EXCEPTION,SERVICEINSTANCE="vnfc";
```
