# 增加5G RFSP ID性能统计对象（ADD NGPERFRFSPID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于增加5G RFSP ID的性能统计对象。

若需要统计AMF下发给基站的指定RFSP ID的用户数，可通过本命令配置指定RFSP ID的性能统计对象。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入256条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                        |
|:---------|:-------|:------------------------------------------------------------------------------------------------------------|
| NGRFSPID | RFSP索引 | 可选必选说明：必选参数  参数含义：该参数用于标识基于RFSP ID的性能统计对象名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~3。参数取值范围为1~256。  默认值：无  配置原则：无 |

## 使用实例

增加5G RFSP ID为1的性能统计对象，执行如下命令：

```
ADD NGPERFRFSPID: NGRFSPID="1";
```
