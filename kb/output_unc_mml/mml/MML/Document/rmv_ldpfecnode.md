# 删除FEC节点（RMV LDPFECNODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除FEC节点。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                      |
|:------------|:--------|:--------------------------------------------------------------------------|
| FECLISTNAME | FEC列表名称 | 可选必选说明：必选参数 参数含义：该参数用于指定FEC列表的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 |
| IPADDRESS   | IP地址    | 可选必选说明：必选参数 参数含义：该参数用于指定FEC的IP地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无          |

#### 使用实例

删除FEC节点：

```
RMV LDPFECNODE:FECLISTNAME="name1",IPADDRESS="192.168.1.1";
```
