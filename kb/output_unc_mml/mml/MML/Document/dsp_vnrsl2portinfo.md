# 显示二层外联口信息（DSP VNRSL2PORTINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来显示二层外联口信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                            |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------|
| IFNAME | 接口名    | 可选必选说明：可选参数。 参数含义：该参数用于指定主接口名称。 数据来源：本端规划。 取值范围：字符串类型，输入长度范围为1～63。接口名称由接口类型+接口编号组成。 默认值：无。 配置原则：请使用LST INTERFACE命令查看可用二层接口。当不输入本参数时，查询全部二层接口信息。 |

#### 使用实例

显示二层外联口信息：

```
DSP VNRSL2PORTINFO: IFNAME="Ethernet64/0/4";
```
