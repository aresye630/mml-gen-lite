# 增加APN粒度的通用会话拓展功能控制（ADD APNSMCOMFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于增加APN粒度的通用会话拓展功能控制。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入20000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                                                         |
|:---------------|:------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN            | APN名称       | 可选必选说明：必选参数  参数含义：该参数用于指示APN名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“ ” ”、“ ` ”特殊字符，不区分大小写。  默认值：无  配置原则：  该参数使用ADD APN命令配置生成。                                                                                                               |
| GETPOLICYFIRST | 在EPS是否先获取策略 | 可选必选说明：可选参数  参数含义：该参数用于指定当PGW-C对接PCF时，是否先跟PCF交互获取会话策略，再动态分配UE IP地址。  数据来源：本端规划 取值范围： “ENABLE（使能）”：表示PGW-C先跟PCF交互获取会话策略，再动态分配UE IP地址。“DISABLE（不使能）”：表示保持原有实现，即PGW-C先动态分配UE IP地址，再跟PCF交互获取会话策略。  默认值：DISABLE  配置原则：无                                                                                                                           |
| VNGRPIDSRC     | VnGroupID来源 | 可选必选说明：可选参数  参数含义：该参数用于指定在5G LAN场景下，SMF上VnGroupID的获取来源。  数据来源：本端规划 取值范围： “UDM（UDM）”：表示SMF从UDM签约处获取VnGroupID。“Radius（Radius）”：表示SMF从Radius签约处获取VnGroupID。  默认值：UDM  配置原则：  当DWORD1083 BIT3软参设置为“0”时，若配置了VnGroupID的获取来源，则不会使用其他来源的VnGroupID；当软参设置为“1”时，且配置了VnGroupID的获取来源为Radius，若Radius下发VnGroupID，则使用Radius下发的VnGroupID，否则使用UDM下发的VnGroupID。 |

## 使用实例

增加“APN名称”为“HUAWEI.COM”的APN粒度通用会话拓展功能控制，在EPS中先获取策略。

```
ADD APNSMCOMFUNC: APN="HUAWEI.COM",GETPOLICYFIRST=ENABLE;
```
