# 设置N26 RFSP老化时长(SET N26RFSPPLCY)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于设置新侧MME从N26/S10接口收到老侧AMF/MME传递的RFSP的老化时长。

#### 注意事项

- 系统初次运行时，会执行系统初始设置值。
- 此命令执行后立即生效。
- 老化功能受**ADD RFSPTRSCTRL**配置的**RFSPAGESW**参数控制，默认不开启。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                        |
|:---------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RFSPTIME | RFSP老化时长 | 可选必选说明：可选参数 参数含义：该参数表示从N26/S10接口传递的RFSP老化时长，单位为分钟。 数据来源：全网规划 取值范围：0~1440 系统初始设置值：60。                                                                                                                                                                                                                        |
| DFTRFSP  | 默认RFSP   | 可选必选说明：可选参数 参数含义：该参数用于设置从N26/S10接口传递的RFSP被老化后，MME给基站下发的RFSP。 数据来源：全网规划 取值范围：0~256 系统初始设置值：0。 配置原则： 取0时，该参数是无效值。 1~128为运营商自定义值。129~256为协议(3GPP TS 36.300)指定值，其中256表示的优先级从高到低为：E-UTRAN，UTRAN，GERAN。255表示的优先级从高到低为：UTRAN，GERAN，E-UTRAN。254表示的优先级从高到低为：GERAN，UTRAN，E-UTRAN。HSS签约数据或者ADD RFSP配置的RFSP决策结果优先该参数配置。 |

#### 使用实例

设置从N26/S10接口传递的RFSP老化时长为60分钟：

SET N26RFSPPLCY: RFSPTIME=60;
