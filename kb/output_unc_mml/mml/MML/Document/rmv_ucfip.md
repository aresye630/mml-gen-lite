# 删除UCF报表本地IP资源池（RMV UCFIP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除UCF的报表本地IP地址池。

## 注意事项

- 该命令执行后立即生效。

- 执行命令前请确认UCF服务处于上线状态。
- 删除报表的IP资源池后，报表数据将无法上报至服务器。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                    |
|:-------|:-------|:----------------------------------------------------------------------------------------|
| INDEX  | 索引号    | 可选必选说明：必选参数  参数含义：该参数用于标识记录索引号。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无 |

## 使用实例

运营商A不再使用索引为3的本地IP资源池记录，将该条记录删除：

```
RMV UCFIP: INDEX=3;
```
