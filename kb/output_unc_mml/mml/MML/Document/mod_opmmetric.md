# 修改话统指标优化公式(MOD OPMMETRIC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

执行该命令会修改话统指标的优化公式，影响该话统指标的测量结果值，请慎重执行。

该命令用于修改网元的话统指标的优化公式。

## 注意事项

该命令有高危提示，请谨慎执行。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                                                                                                           |
|:-----------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID       | 网元ID     | 可选必选说明：必选参数。 参数含义：标识网元ID，可以通过LST ME命令查询获取。 取值范围：0~65535。 默认值：无。 配置原则：无。                                                                                                                                                                                        |
| METRICID   | 测量指标ID   | 可选必选说明：必选参数。 参数含义：测量指标ID，可以通过LST MEASUNIT命令查询获取。 取值范围：整数类型，取值范围为0~4294967294。 默认值：无。 配置原则：无。                                                                                                                                                                   |
| OPMFORMULA | 测量指标优化公式 | 可选必选说明：必选参数。 参数含义：指标优化公式。 取值范围：字符串类型，长度不超过512个字符。 默认值：无。 配置原则：计算公式填写规范如下： 当前的运算符号包括“+”、“-”、“*”、“/”、“(”、“)”。指标ID是以“[]” 括起的形式表示，并且符号之间不能有空格。常数是以"{}"括起的浮点类型数字的形式表示。粒度周期是以“{GP}”的形式表示，为秒值，表示参与运算的各个指标的粒度周期，不允许不同粒度周期的测量指标进行运算。示例： [1929937501]+{123.23}*{GP}/{60} |

## 使用实例

修改话统指标优化公式：

```
%%MOD OPMMETRIC: MEID=10, METRICID=24100151, OPMFORMULA="[24100151]+{200}";%%
RETCODE = 0  操作成功

---    END
```
