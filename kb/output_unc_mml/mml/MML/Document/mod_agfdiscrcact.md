# 修改AGF基于TOPO异常响应处理动作（MOD AGFDISCRCACT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NCG**

该命令用于修改AGF基于TOPO异常响应处理动作。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称         | 参数说明                                                                                                                            |
|:---------|:-------------|:--------------------------------------------------------------------------------------------------------------------------------|
| RCTYPE   | RC类型         | 可选必选说明：必选参数  参数含义：该参数用于指定RC的类型。  数据来源：本端规划 取值范围： DEFAULT（针对未指定的异常返回码设置处理动作）VALUE（针对指定异常返回码设置处理动作）TIMEOUT（等待响应超时）  默认值：无  配置原则：无 |
| CODETYPE | 指定异常返回码类型    | 可选必选说明：该参数在"RCTYPE"配置为"VALUE"时为条件必选参数。  参数含义：该参数用于指定异常返回码的类型。  数据来源：本端规划  取值范围：整数类型，取值范围是300~999，0~10。  默认值：无  配置原则：无           |
| FOTNM    | Failover模板标识 | 可选必选说明：可选参数  参数含义：该参数用于指定融合计费Proxy Failover模板的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。  默认值：无  配置原则：无                            |

## 使用实例

修改指定异常返回码类型为“900”的结果码处理动作，设置Failover模板标识为“ccpfot2”：

```
MOD AGFDISCRCACT: RCTYPE=VALUE, CODETYPE=900, FOTNM="ccpfot2";
```
