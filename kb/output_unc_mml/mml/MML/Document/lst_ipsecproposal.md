# 查询IPsec提议（LST IPSECPROPOSAL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询IP安全提议。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称       | 参数说明                                                                        |
|:-------------|:-----------|:----------------------------------------------------------------------------|
| PROPOSALNAME | Proposal名称 | 可选必选说明：可选参数 参数含义：Proposal名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～15。不区分大小写。 默认值：无 |

#### 使用实例

查询IP安全提议：

```
LST IPSECPROPOSAL:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
 Proposal名称  =  asdf2
  ESP认证算法  =  sha2-256算法
  ESP加密算法  =  256位AES算法
IPsec安全协议  =  ESP协议
   AH认证算法  =  NULL
     封装模式  =  传输模式
(结果个数 = 1)
---    END
```
