# 增加SCP绑定组关系（ADD SCPBINDGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF**

该命令用于增加SCP绑定组关系，支持将不同的SCP绑定到不同分组中，但同一SCP只能绑定到一个分组中。

## 注意事项

- 该命令执行后立即生效。

- 同一个组号最多绑定32个SCP。

- 最多可输入64条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                   |
|:-------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCEID | NF实例标识 | 可选必选说明：必选参数  参数含义：该参数用于指定NF实例标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~36。NFINSTANCEID参数必须满足以下约束规则：1.如果输入为uuid格式（格式例如：a6a61c6f-0d3a-4221-b1da-424eda3ccf67）只能为A-F、a-f、0-9和“-”的字符。2.如果输入不为uuid格式，长度不能超过18且不允许输入只包含0-9和“.”的字符串，例如：1.2.3.4、不允许输入只包含十六进制数（A-F、a-f、0-9）和“:”的字符串，例如：1::2、FBFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。3.不区分大小写。不支持配置单空格。  默认值：无  配置原则：无 |
| GROUPID      | 组号     | 可选必选说明：必选参数  参数含义：该参数用于指定SCP组号。  数据来源：本端规划  取值范围：整数类型，取值范围是66~128。  默认值：无  配置原则：  先通过本命令配置该SCP的NF实例标识对应的组号，再通过ADD PNFPROFILE配置该SCP的NF实例概述信息。                                                                                                                                                                                                           |

## 使用实例

支持对接专网AMF的SCP实例标识为SCP\_Instance\_1，规划该SCP绑定到组号66。

```
ADD SCPBINDGRP: NFINSTANCEID="SCP_Instance_1", GROUPID=66;
```
