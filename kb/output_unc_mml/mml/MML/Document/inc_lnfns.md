# 增加本端NF支持的网络切片（INC LNFNS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF**

该命令用以增加本端NF支持的网络切片，仅用于生成ADD PLMNNS、ADD NFNS、ADD NSDNN的配置记录。

## 注意事项

- 该命令执行后立即生效。

- 如果ADD PLMNNS、ADD NFNS、ADD NSDNN任一记录数达到最大规格，则随后执行INC LNFNS命令不会生成ADD PLMNNS、ADD NFNS、ADD NSDNN。
- 在执行此命令前必须存在PLMNIDX为0的ADD NGSRVPLMN配置记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
|:--------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SST     | 切片业务类型   | 可选必选说明：必选参数  参数含义：该参数表示切片的业务类型，如eMBB（1）、URLLC（2）、MIoT（3）等协议定义的标准SST，或者运营商自定义的SST。  数据来源：全网规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| SD      | 切片细分标识   | 可选必选说明：可选参数  参数含义：该参数表示根据网络切片所提供的服务特点、所服务的对象差异，对某种网络切片的进一步细分。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。采用十六进制表示（无须输入“0x”前缀），只能由数字（0-9），字母（A-F、a-f）组成。字母大小写不敏感。  默认值：无  配置原则：  该值若不设置，默认值为FFFFFF。                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| STATE   | 状态       | 可选必选说明：可选参数  参数含义：该参数表示网络切片的状态：未激活或者已激活。只有处于激活状态的网络切片才能被UE使用。  数据来源：全网规划 取值范围： “INACTIVE（未激活）”：网络切片未激活“ACTIVE（激活）”：网络切片已激活  默认值：ACTIVE  配置原则：  当由于切片用户欠费、网络运维等原因需要临时停止使用指定的网络切片时，将本参数值设置为“INACTIVE”；当指定的网络切片可用时，将本参数值设置为“ACTIVE”。  另，切片状态及其变化不影响NF到NRF的注册过程，不影响SMF的会话管理但影响MB-SMF的广播会话管理和组播会话管理。                                                                                                                                                                                                                                                                                                                                                  |
| NSSCOPE | 网络切片生效范围 | 可选必选说明：可选参数  参数含义：该参数用于表示网络切片的生效范围。  数据来源：全网规划 取值范围： “GLOBALNW（全局网络）”：网络切片在运营商全网范围内生效。“CAMPUSNW（园区网络）”：网络切片在运营商网络的局部范围内生效，具体的范围依赖于运营商的网络切片规划。  默认值：GLOBALNW  配置原则：  根据运营商对网络切片的规划进行配置。                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| NFTYPE  | NF类型     | 可选必选说明：必选参数  参数含义：该参数用于表示NF类型。  数据来源：本端规划 取值范围： “NfInvalid（NfInvalid）”：无效的NF“NfNRF（NfNRF）”：NRF“NfUDM（NfUDM）”：UDM“NfAMF（NfAMF）”：AMF“NfSMF（NfSMF）”：SMF“NfAUSF（NfAUSF）”：AUSF“NfNEF（NfNEF）”：NEF“NfPCF（NfPCF）”：PCF“NfSMSF（NfSMSF）”：SMSF“NfNSSF（NfNSSF）”：NSSF“NfUDR（NfUDR）”：UDR“NfLMF（NfLMF）”：LMF“NfGMLC（NfGMLC）”：GMLC“Nf5G_EIR（Nf5G_EIR）”：5G_EIR“NfSEPP（NfSEPP）”：SEPP“NfUPF（NfUPF）”：UPF“NfN3IWF（NfN3IWF）”：N3IWF“NfAF（NfAF）”：AF“NfUDSF（NfUDSF）”：UDSF“NfBSF（NfBSF）”：BSF“NfCHF（NfCHF）”：CHF“NfNWDAF（NfNWDAF）”：NWDAF“NfTypeMAX（NfTypeMAX）”：NfTypeMAX“NfMBSMF（NfMBSMF）”：MBSMF“NfCBCF（NfCBCF）”：NfCBCF“NfSCF（NfSCF）”：NfSCF“NfSPF（NfSPF）”：NfSPF  默认值：无  配置原则：无 |
| DNN     | 数据网络名称   | 可选必选说明：该参数在"NFTYPE"配置为"NfSMF"时为条件可选参数。  参数含义：该参数用于表示指定的网络切片支持的数据网络名称。 仅当NFTYPE为NfSMF时有效，来源为ADD NSDNN。当NFTYPE为非NfSMF时，该参数无效，显示为NULL。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&amp;”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。可配置通配DNN，即“*”，表示支持所有DNN。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                          |
| DESC    | 描述信息     | 可选必选说明：可选参数  参数含义：该参数表示对网络切片的描述，在运维中起助记作用。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~32。  默认值：无  配置原则：  输入单空格将删除该参数已有配置项。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |

## 使用实例

增加本端NF支持的网络切片，网络切片为eMBB（SST=1），网元类型为AMF，执行如下命令：

```
INC LNFNS: SST=1, NFTYPE=NfAMF, DESC="test";
```
