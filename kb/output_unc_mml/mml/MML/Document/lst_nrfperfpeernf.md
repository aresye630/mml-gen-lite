# 查询NRF上局向性能统计对象（LST NRFPERFPEERNF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NRF**

该命令用于查询NRF上的局向性能指标对象。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|:-------------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PEERNFNAME   | 对端NF实例名称 | 可选必选说明：可选参数  参数含义：该参数用于表示对端网元的实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~255。  默认值：无  配置原则：  1.本参数的构成字符只能是字母A～Z或a～z、数字0～9、中划线"-"和下划线"_"，例如，AMF_Instance_0。                                                                                                                                                                                                                                                                                                   |
| TARGETNFTYPE | 目的NFTYPE | 可选必选说明：可选参数  参数含义：该参数用于指定NRF局向性能指标统计的目的NF类型。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~20。  默认值：无  配置原则： 该参数支持如下类型：ALL/NRF/UDM/AMF/SMF/AUSF/NEF/PCF/SMSF/NSSF/UDR/LMF/GMLC/EIR\_5G/SEPP/UPF/N3IWF/AF/UDSF/BSF/CHF/NWDAF/PCSCF/CUSTOM\_OCS/SCP/DRA/CBCF/HSS/UCMF/SOR\_AF/SPAF/MME/SCSAS/SCEF/NSSAAF/ICSCF/SCSCF/IMS\_AS/AANF/DDNMF\_5G/NSACF/MFAF/EASDF/DCCF/MB\_SMF/TSCTSF/ADRF/GBA\_BSF/CEF/MB\_UPF/NSWOF/PKMF/MNPF/SMS\_GMSC/SMS\_IWMSC/MBSF 其中ALL表示支持所有目的的NF类型 |

## 使用实例

若需要查看当前NRF上的局向性能统计对象，可执行如下配置：

```
LST NRFPERFPEERNF:;
%%LST NRFPERFPEERNF:;%%
RETCODE = 0  操作成功

结果如下
--------
对端NF实例名称  =  AMF_Instance_0
    目的NFTYPE  =  SMF
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称    | 输出项解释                      |
|:---------|:---------------------------|
| 对端NF实例名称 | 该参数用于表示对端网元的实例名称。          |
| 目的NFTYPE | 该参数用于指定NRF局向性能指标统计的目的NF类型。 |
