# 增加GGSN属性配置信息(ADD GGSNCHARACT)

- 命令功能

- 本地用户权限

#### 命令功能

**适用网元：SGSN**

该命令用于增加GGSN的属性信息。如果不配置此命令，则SGSN默认QoS版本为R99，不发送私有信息。

#### 注意事项

- 该命令执行后立即生效。
- 该表的最大元组数为1024。
- 该命令配置前需要确认GGSN功能的详细信息，以免因与实际设备不兼容而导致流程失败。
- 软件安装完成后，系统默认存在一条“对端设备范围”为“ALL\_GGSN(所有GGSN)”的默认配置，此默认配置的各参数取值请通过执行**LST GGSNCHARACT**命令查询
- 该命令部分参数与相关特性license共同完成该特性的开启，请在设置参数前使用**DSP LICENSE**命令确认对应特性license是否得到授权，执行**LST LICENSESWITCH**命令确认特性开关状态为“ENABLE(打开)”，具体相关特性请参考参数的说明。
- DT与UDG GWFD-012100 Single IP特性交互时，需要通过**ADD GGSNCHARACT**命令配置GGSN的Gn接口的SPU Group IP和SPU Instance IP。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| RANGE          | 对端设备范围               | 可选必选说明：必选参数 参数含义：该参数用于指定需要设置属性信息的对端GGSN范围。 数据来源：本端规划 取值范围： “ALL_GGSN（所有GGSN）”“Gn_GGSN（Gn接口GGSN）”“Gp_GGSN（Gp接口GGSN）”、“SPECIAL_GGSN（指定GGSN）” 默认值： ALL_GGSN 配置原则： “ALL_GGSN”、“Gn_GGSN”和“Gp_GGSN”分别只能配置一条记录。“SPECIAL_GGSN”可以配置多条记录，但是IP网段区间不能重叠。  说明： 当系统中已存在一条“ALL_GGSN”的记录时，如果在客户端再增加一条“ALL_GGSN”的记录，新记录会将旧记录覆盖。当系统中已存在一条“Gn_GGSN”或“Gp_GGSN”的记录时，如果在客户端再增加一条“Gn_GGSN”或“Gp_GGSN”的记录，新记录将添加失败。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

#### 使用实例

1. 增加记录，配置用户范围为“SPECIAL\_GGSN”，信令面IP地址为"192.168.168.12" ，掩码为“255.255.255.255”的GGSN属性，不上报GCDR/e-GCDR信息，GGSN是否支持VIP为“YES”：

   ```
   ADD GGSNCHARACT: RANGE=SPECIAL_GGSN, IPT=IPV4, GGSNIPV4="192.168.168.12", MASKV4="255.255.255.255", EGCDR=PLMN-0&RAT_TYPE-0&USER_LOCATION_INFO-0&MS_TIME_ZONE-0&IMEI_SV-0&RAI-0&MS_TIME_ZONE_DST-0, VIP=YES;
   ```
2. 增加记录，配置用户范围为“Gn接口GGSN”，GGSN是否支持DirectTunnel为“YES”，GGSN支持的QoS版本为“R99QOS”，上报RAT\_Type信息，GGSN是否支持VIP为“NO”：

   ```
   ADD GGSNCHARACT: RANGE=Gn_GGSN, OTS=YES, QOSVER=R99QOS, EGCDR=RAT_TYPE-1&USER_LOCATION_INFO-1&IMEI_SV-1&RAI-1&MS_TIME_ZONE_DST-1, VIP=NO;
   ```
3. 增加记录，配置用户范围为“Gp接口GGSN”，GGSN是否支持DirectTunnel为“YES”，GGSN支持的QoS版本为“R99QOS”，上报所有GCDR/e-GCDR信息，GnGp接口的GTP-C路径版本规则为“V1”，GGSN是否支持Smart Paging为“YES”，GGSN是否支持VIP为“YES”：

   ```
   ADD GGSNCHARACT: RANGE=Gp_GGSN, OTS=YES, QOSVER=R99QOS, EGCDR=RAT_TYPE-1&USER_LOCATION_INFO-1&IMEI_SV-1&RAI-1&MS_TIME_ZONE_DST-1, GNGPPATHVER=V1, SMARTPAGING=YES, VIP=YES;
   ```
