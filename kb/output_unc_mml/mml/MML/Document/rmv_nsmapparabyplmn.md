# 删除指定PLMN的网络切片映射参数（RMV NSMAPPARABYPLMN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除指定PLMN用户的网络切片映射相关参数配置。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                        |
|:-------|:-------|:--------------------------------------------------------------------------------------------|
| MCC    | 移动国家码  | 可选必选说明：必选参数  参数含义：该参数用于配置用户归属PLMN的移动国家码信息。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。  默认值：无  配置原则：无    |
| MNC    | 移动网号   | 可选必选说明：必选参数  参数含义：该参数用于配置用户归属PLMN的移动网号信息。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。  默认值：无  配置原则：无 |

## 使用实例

删除MCC为“123”、MNC为“45”的用户的网络切片映射相关参数策略，执行如下命令：

```
RMV NSMAPPARABYPLMN: MCC="123", MNC="45";
```
