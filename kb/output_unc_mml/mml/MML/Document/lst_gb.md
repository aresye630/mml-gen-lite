#### 命令功能

**适用网元：SGSN**

该命令用于查询GB通用信息。

#### 注意事项

此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询GB通用参数:

LST GB:;

```
%%LST GB:;%%
RETCODE = 0  操作成功。

操作结果如下
--------------
    启用Gb over IP资源分配功能  =  是
启用Gb动态 over IP自动配置功能  =  否
  启用Gb over IP接口UDP校验功能 =  是
(结果个数 = 1)

---    END
```

#### 输出结果说明
