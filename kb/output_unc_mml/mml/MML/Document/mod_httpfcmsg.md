# 修改HTTP流控消息类型（MOD HTTPFCMSG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

新增流控消息需谨慎，建议只针对业务流程首消息开启流控，避免影响E2E业务成功率。

该命令用于修改HTTP流控消息类型。

## 注意事项

- 该命令执行后立即生效。

- 参数FCTYPE取值为TCPBPFC时，执行该命令会导致TCP CPU反压流控暂时停止。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

例如当AMF作为Server端接收消息时，基于SBIProtocolAMF29518协议消息索引为1的固定速率流控，修改流控索引为1，流控组为2

```
MOD HTTPFCMSG: NFTYPE=NFTypeAMF, SBIPROTOCOL=SBIProtocolAMF29518, MSGINDEX=1, ROLE=SERVER, DIRECTION=RECV, FCTYPE=FIXSPDFCGRP, FCSWITCH=ON, IPINDEX=1, GROUP=2;
```
