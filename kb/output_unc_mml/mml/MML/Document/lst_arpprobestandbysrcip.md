# 查询备用成员口ARP探测源地址（LST ARPPROBESTANDBYSRCIP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询备用成员口ARP探测的源地址。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                       |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| IFNAME | 接口名称   | 可选必选说明：可选参数 参数含义：该参数用于指定ARP探测会话的接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：该参数必须先由ADD INTERFACE命令定义，才能在此处索引。并且只能为捆绑口或其子接口，子接口必须是vlan-type dot1q类型。 |

#### 使用实例

查询备用成员口ARP探测的源地址：

```
LST ARPPROBESTANDBYSRCIP:IFNAME="Eth-Trunk1.1";
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
         接口名称  =  Eth-Trunk1.1
ARP探测源IPv4地址  =  10.10.10.10
(结果个数 = 1)
---    END
```

|:-------------|:---------------------------|
| 接口名称         | 该参数用于指定ARP探测会话的接口名称。       |
| ARP探测源IPv4地址 | 该参数用于指定备用成员口ARP探测的源IPv4地址。 |
