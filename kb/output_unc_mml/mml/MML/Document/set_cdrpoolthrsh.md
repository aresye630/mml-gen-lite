# 设置话单池空间告警阈值（SET CDRPOOLTHRSH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

该命令用来设置话单池空间不足告警阈值。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 告警恢复阈值必须小于告警产生阈值。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   |   ALARMTHRESHOLD |   ALARMCLRTHRSH |
|:-------|-----------------:|----------------:|
| 初始值    |               80 |              75 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称      | 参数说明                                                                                |
|:---------------|:----------|:------------------------------------------------------------------------------------|
| ALARMTHRESHOLD | 告警产生阈值（%） | 可选必选说明：可选参数 参数含义：该参数用于指定话单池空间不足告警阈值大小。 数据来源：本端规划 取值范围：整数类型，取值范围为2～100。 默认值：无 配置原则：无 |
| ALARMCLRTHRSH  | 告警恢复阈值（%） | 可选必选说明：可选参数 参数含义：该参数指定话单池空间不足告警恢复阈值大小。 数据来源：本端规划 取值范围：整数类型，取值范围为1～99。 默认值：无 配置原则：无  |

#### 使用实例

设置当占用话单池容量超过80%时，产生81005话单池空间不足告警，当占用话单池容量下降到70%时，恢复81005话单池空间不足告警：

```
SET CDRPOOLTHRSH:ALARMTHRESHOLD=80,ALARMCLRTHRSH=70;
```
