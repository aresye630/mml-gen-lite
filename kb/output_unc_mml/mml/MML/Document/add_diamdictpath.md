# 增加Diameter字典加载路径（ADD DIAMDICTPATH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于增加Diameter字典加载路径。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为5。
- 只有为某应用增加第二套字典加载路径时，才会使用该命令。
- 目前只支持GY应用设置第二套字典加载路径。
- 该命令执行后，再执行加载字典命令（LOD DIAMDICT）。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | APPLICATION   |   DICTNO | DICTPATH        |
|:-------|:--------------|---------:|:----------------|
| 初始值    | GY            |        1 | EPC_STANDARD    |
| 初始值    | GX            |        1 | EPC970_STANDARD |
| 初始值    | S6B           |        1 | EPC_STANDARD    |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                          |
|:------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APPLICATION | 应用     | 可选必选说明：必选参数 参数含义：该参数用于指定字典的Diameter应用。 数据来源：本端规划 取值范围：枚举类型。 GY：Gy接口字典。GX：Gx接口字典。S6B：S6b接口字典。 默认值：无 配置原则：无                                                                     |
| DICTNO      | 字典序号   | 可选必选说明：必选参数 参数含义：该参数用于指定字典编号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～2。 默认值：无 配置原则：无                                                                                                      |
| DICTPATH    | 字典加载路径 | 可选必选说明：必选参数 参数含义：该参数用于指定字典加载路径。 数据来源：本端规划 取值范围：枚举类型。 EPC_STANDARD：EPC标准字典路径。GU_STANDARD：GU标准字典路径。CUSTOM1：定制字典路径1。CUSTOM2：定制字典路径2。EPC970_STANDARD：EPC 970 标准字典路径。 默认值：无 配置原则：无 |

#### 使用实例

当需要为GY应用增加第二套字典加载路径时：

```
ADD DIAMDICTPATH: APPLICATION=GY,DICTNO=2,DICTPATH=CUSTOM2;
```
