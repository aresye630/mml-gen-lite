# 删除计费相关的IP配置参数(RMV CHGCDPIP)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用于删除CDP进程上指定的IP地址。

#### 注意事项

该命令在版本升级过程中禁止执行。若升级强制执行将导致话单发送不出而被保存在硬盘。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                            |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPT      | IP地址类型 | 可选必选说明：必选参数 参数含义：该参数用于指定IP地址类型。 数据来源：整网规划 取值范围：“IPv4(IPv4地址)”“IPv6(IPv6地址)” 默认值： 无                                                                                                                                                                                              |
| IPV4ADDR | IPv4地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定CDP的IPv4地址。 前提条件：该参数在“IPT”设置为“IPv4(IPv4地址)”时有效。 数据来源：整网规划 取值范围：0.0.0.1～255.255.255.254 默认值：无  说明： “0.0.0.0”和“255.255.255.255”是无效的IP地址。 配置原则：IPv4地址不能为0.0.0.0、255.255.255.255和0.x.y.z。IPv4地址不能为组播地址（如：224.x.y.z）和环回地址(如：127.x.y.z)。IPv4地址必须是A、B或者C类地址。 |
| IPV6ADDR | IPv6地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定CDP的IPv6地址。 前提条件：该参数在“IPT”设置为“IPv6(IPv6地址)”时有效。 数据来源：整网规划 取值范围：::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无                                                                                                                                       |
| PORTBGN  | 起始端口号  | 可选必选说明：必选参数 参数含义：该参数用于指定起始端口号。 数据来源：整网规划 取值范围：1024～65534 默认值：无  说明： 端口号不可使用下述知名端口：2123(GTPCv1)，2152(GTPUv1)，3784(BFD)，3785(BFD)，4784(BFD)，4500(IKEv2)。                                                                                                                          |
| PORTEND  | 结束端口号  | 可选必选说明：必选参数 参数含义：该参数用于指定结束端口号。 数据来源：整网规划 取值范围：1024～65534 默认值：无  说明： 端口号不可使用下述知名端口：2123(GTPCv1)，2152(GTPUv1)，3784(BFD)，3785(BFD)，4784(BFD)，4500(IKEv2)。                                                                                                                          |

#### 使用实例

删除CDP IP地址，IP地址类型为IPv4地址，IP地址为172.22.5.50，起始端口号3699，结束端口号3700：

RMV CHGCDPIP: IPT=IPv4, IPV4ADDR="172.22.5.50", PORTBGN=3699, PORTEND=3700;
