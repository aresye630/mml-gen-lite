# 增加服务节点IP（ADD SRVNODEIP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、GGSN**

该命令用来增加一个新的服务节点IP。当需要用SGSN IP、SGW IP、PCF IP、TWAN IP、ePDG IP进行虚拟APN映射时，在不同的场景下需要使用该命令增加SGSN/SGW/PCF/TWAN/ePDG的服务节点组绑定的服务节点IP地址段。

## 注意事项

- 该命令执行后立即生效。

- 一个服务节点组最多绑定1000个服务节点IP地址段。
- 地址段不能重叠。

- 最多可输入3000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称             | 参数说明                                                                                                                                                                                                                                               |
|:--------------|:-----------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GROUPNAME     | 服务节点组名称          | 可选必选说明：必选参数  参数含义：该参数用于指定服务节点组名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~32。不支持空格，不区分大小写。  默认值：无  配置原则：  本参数通过ADD SRVNODEGROUP命令进行配置。                                                                                                                      |
| IPSECTIONID   | 服务节点IP地址段编号      | 可选必选说明：必选参数  参数含义：该参数用于指定服务节点IP地址段的编号。  数据来源：本端规划  取值范围：整数类型，取值范围是0~2999。  默认值：无  配置原则：无                                                                                                                                                           |
| IPV4ADDRSTART | 服务节点IPV4地址段的起始地址 | 可选必选说明：该参数在"IPVERSION"配置为"IPV4"时为条件必选参数。  参数含义：该参数用于设定服务节点IP地址段的IPv4起始IP地址。  数据来源：本端规划  取值范围：IPv4地址类型。点分十进制格式。具体取值范围为：1.0.0.1-126.255.255.254，128.1.0.1-191.255.255.254，192.0.1.1-223.255.255.254。  默认值：无  配置原则：  IPV4ADDRSTART一定要小于等于IPV4ADDREND。 |
| IPV4ADDREND   | 服务节点IPV4地址段的结束地址 | 可选必选说明：该参数在"IPVERSION"配置为"IPV4"时为条件必选参数。  参数含义：该参数用于设定服务节点IP地址段的IPv4结束IP地址。  数据来源：本端规划  取值范围：IPv4地址类型。点分十进制格式。  默认值：无  配置原则：  IPV4ADDRSTART一定要小于等于IPV4ADDREND。                                                                                     |
| IPV6ADDRSTART | 服务节点IPV6地址段的起始地址 | 可选必选说明：该参数在"IPVERSION"配置为"IPV6"时为条件必选参数。  参数含义：该参数用于设定服务节点IP地址段的IPv6起始IP地址。  数据来源：本端规划  取值范围：IPv6地址类型。冒号分隔十六进制格式。  默认值：无  配置原则：  IPV6ADDRSTART一定要小于等于IPV6ADDREND。                                                                                  |
| IPV6ADDREND   | 服务节点IPV6地址段的结束地址 | 可选必选说明：该参数在"IPVERSION"配置为"IPV6"时为条件必选参数。  参数含义：该参数用于设定服务节点IP地址段的IPv6结束IP地址。  数据来源：本端规划  取值范围：IPv6地址类型。冒号分隔十六进制格式。  默认值：无  配置原则：  IPV6ADDRSTART一定要小于等于IPV6ADDREND。                                                                                  |
| IPVERSION     | IP版本             | 可选必选说明：必选参数  参数含义：该参数用于指定地址段的IP版本。  数据来源：本端规划 取值范围： “IPV4（IPV4）”：IPv4地址类型“IPV6（IPV6）”：IPv6地址类型  默认值：无  配置原则：无                                                                                                                                      |

## 使用实例

在根据SGSN IP进行虚拟APN映射的时候，需要绑定服务节点IP地址时使用如下命令：

```
ADD SRVNODEIP:GROUPNAME="huawei",IPSECTIONID=1,IPVERSION=IPV4,IPV4ADDRSTART="192.168.1.10",IPV4ADDREND="192.168.1.120";
```
