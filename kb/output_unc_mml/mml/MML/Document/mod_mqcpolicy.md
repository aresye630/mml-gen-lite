# 修改流策略配置（MOD MQCPOLICY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改流策略配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                            |
|:-----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------|
| POLICYNAME | 策略名称   | 可选必选说明：必选参数 参数含义：指定流策略的名称，不允许为系统预定义策略default。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                                           |
| STCENABLE  | 统计使能标志 | 可选必选说明：可选参数 参数含义：该参数用于使能或去使能流策略的统计状态。NP卡场景下不支持流策略的统计功能。 数据来源：本端规划 取值范围：枚举类型。 disable：去使能流策略统计。enable：使能流策略统计。 默认值：无             |
| SHAREMODE  | 共享模式   | 可选必选说明：可选参数 参数含义：该参数用于配置某一个流策略的共享模式。 数据来源：本端规划 取值范围：枚举类型。 unshared-mode：非共享模式，只统计该接口的策略统计。shared-mode：共享模式，累加应该相同策略的接口统计。 默认值：无 |

#### 使用实例

修改流策略p1的配置：

```
MOD MQCPOLICY:POLICYNAME="p1",STCENABLE=enable,SHAREMODE=unshared-mode;
```
