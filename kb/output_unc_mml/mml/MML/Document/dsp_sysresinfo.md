#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询系统资源使用信息。当前仅支持查询UE Radio Capability信元内存使用信息。

#### 注意事项

该命令在查询UE Radio Capability信元内存使用信息时，仅用于查询UE Radio Capability信元超过132字节时的内存使用信息。UE Radio Capability信元不超过132字节时，系统会将该信元直接保存在用户上下文中，不需要额外占用内存进行保存。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                           |
|:------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RESTYPE     | 资源类型   | 可选必选说明：必选参数 参数含义：该参数用于指定需要查询的资源类型 数据来源：本端规划 取值范围：“E_SYSRESINFO_UERADIOCAP”：UE Radio Capability信元内存使用信息。 默认值：无                                                                                                  |
| RUNAME      | RU名称   | 可选必选说明：条件可选参数 参数含义：该参数用于指定SPU资源单元名称。该参数可以通过DSP RU命令查询。 前提条件：该参数在“资源类型”配置为“UE Radio Capability信元内存使用信息”后生效。 数据来源：本端规划 取值范围：1～63位字符串 默认值：无                                                                       |
| PROCTYPE    | 进程类型   | 可选必选说明：条件可选参数 参数含义：该参数用于指定需要查询的进程类型 前提条件：该参数在“资源类型”配置为“UE Radio Capability信元内存使用信息”后生效。 数据来源：本端规划 取值范围：“SPP(SPP)”“SGP(SGP)”“GBP(GBP)”“CDP(CDP)”“LCP(LCP)”“OMP(OMP)”“UPP(UPP)” 默认值：无  说明： 进程类型和进程号必须同时输入或同时不输入。 |
| PRON        | 进程号    | 可选必选说明：条件可选参数 参数含义：参数用于指定需要查询的进程号 前提条件：该参数在“资源类型”配置为“UE Radio Capability信元内存使用信息”后生效。 数据来源：本端规划 取值范围：整数类型，取值范围为0~20。 默认值：无  说明： 当需要按进程号查询时，必须要输入对应的RU名称。                                                       |
| SERVICETYPE | 服务名称   | 可选必选说明：必选参数 参数含义：本参数用于指定服务名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。数字“0~9”，大写字母“A~Z”，小写字母“a~z”，特殊字符“-”，“_”，其他均为非法字符，并且首字符必须为字母。 默认值：无  说明： 该参数可以通过VNFP上的LST VNFC命令查询得到。                                            |

#### 使用实例

按照“E\_SYSRESINFO\_UERADIOCAP”显示UE Radio Capability信元内存使用信息：

DSP SYSRESINFO: RESTYPE=E\_SYSRESINFO\_UERADIOCAP, SERVICETYPE="USN\_VNFC";

```
%%DSP SYSRESINFO: RESTYPE=E_SYSRESINFO_UERADIOCAP, SERVICETYPE="USN_VNFC";%%
RETCODE = 0  操作成功

查询结果如下
--------------
资源类型                                RU名称            进程类型     进程号     资源总量     资源已使用量     资源使用率

UE Radio Capability信元内存使用信息     USN_SP_RU_0064    SPP          0          6375000      0                0             
UE Radio Capability信元内存使用信息     USN_SP_RU_0065    SPP          0          6375000      0                0 
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                                                                     |
|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 资源类型    | 该参数用于指定需要查询的资源类型。 取值范围：E_SYSRESINFO_UERADIOCAP：表示UE Radio Capability信元内存使用信息。                                                                                             |
| RU名称    | 该参数用于显示进程所属的资源单元名称。                                                                                                                                                       |
| 进程类型    | 该参数用于指定需要查询的进程类型。 取值范围：“SPP(SPP)”“SGP(SGP)”“GBP(GBP)”“CDP(CDP)”“LCP(LCP)”“OMP(OMP)”“UPP(UPP)”                                                                             |
| 进程号     | 该参数用于显示进程序号。 取值范围：0~20                                                                                                                                                    |
| 资源总量    | 该参数用于显示相应系统资源的资源总量。 对于UE Radio Capability信元内存使用信息，该参数显示SPP进程上用于保存UE Radio Capability信元的总内存。（注意事项：SPP进程上用于保存UE Radio Capability信元的总内存受软参DWORD_EX35 BIT5-BIT6控制，查询结果单位为字节。） |
| 资源已使用量  | 该参数用于显示相应系统资源的资源已使用量。 对于UE Radio Capability信元内存使用信息，该参数显示SPP进程上用于保存UE Radio Capability信元的已使用内存，查询结果单位为字节。                                                                 |
| 资源使用率   | 该参数用于显示相应系统资源的资源使用率。 对于UE Radio Capability信元内存使用信息，该参数显示SPP进程上用于保存UE Radio Capability信元的内存使用率。（注意事项：该资源使用率向下取整。软参DWORD_EX35 BIT5-BIT6修改后，该使用率可能超过100%）                    |
