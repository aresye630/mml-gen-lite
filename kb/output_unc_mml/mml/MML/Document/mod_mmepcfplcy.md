# 修改PCF策略控制（MOD MMEPCFPLCY）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于修改PCF策略控制。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；

#### 使用实例

修改PCF策略控制，“用户范围”设置为“IMSI\_PREFIX”，IMSI前缀为46009876000001，是否建立AM策略偶联设置为NO，基于APN的创建AM策略偶联开关设置为YES，将APN关键字修改为“huawei.abc”。

```
MOD MMEPCFPLCY: SUBRANGE=IMSI_PREFIX, IMSIPRE="46009876000001", ISAMASSOC=NO, APNAMPLCYSW=YES, APNAMPLCYKEYWD="huawei.abc";
```
