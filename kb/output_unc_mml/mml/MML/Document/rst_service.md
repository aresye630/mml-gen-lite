#### 命令功能

**须知** 

复位业务属于危险操作。如果参数配置有误，重启后会导致业务故障。建议不要在业务繁忙时进行此项操作。

**适用NF：NCG**

该命令用于将UNC上的所有业务重新启动。系统会去激活所有的业务进程。

在更改了不能动态生效的参数后，需要复位业务，使参数生效。

#### 注意事项

- 复位业务属于危险操作。如果参数配置有误，重启后会导致业务故障。建议不要在业务繁忙时进行此项操作。
- 进行复位时会停止接收处理话单，复位时间一般小于1分钟（不超过5分钟）。
- 复位之后可以使用**DSP SERVICE**查询业务进程状态，查看重启后业务进程状态是否正常。
- 系统初始化配置完成以后，执行**RST VNFC**命令使配置生效。
- 系统正常运行的过程中，修改NCG配置需要执行**RST SERVICE**使修改生效。
- 系统正常运行的过程中，如果新增了RU，需要执行**RST RU**命令复位新增RU使配置生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                   |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------|
| RUID   | RU的ID  | 可选必选说明：可选参数 参数含义：RU的ID。 数据来源：本端规划 取值范围：整数类型，取值范围为64～4294967294。 默认值：无 配置原则：该值需要执行LST SERVICERUSTATE命令，查询出存在的RU ID进行填写。 |

#### 使用实例

重启所有的业务：

```
RST SERVICE:;
RETCODE = 0  操作成功。

---    END
```
