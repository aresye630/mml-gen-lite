# 设置融合计费惯性运行参数（SET CHGIOPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于控制融合计费惯性运行参数。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| N40USAGERPTSW   | FINALRPTSW   | VTRPTSW   | CHFREAUTHRPTSW   |
|:----------------|:-------------|:----------|:-----------------|
| ENABLE          | ENABLE       | DISABLE   | DISABLE          |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称                   | 参数说明                                                                                                                                                                                                                                                                                           |
|:---------------|:-----------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| N40USAGERPTSW  | N40用量上报开关              | 可选必选说明：可选参数  参数含义：该参数用于控制SMF惯性运行期间是否计费。  数据来源：本端规划 取值范围： “ENABLE（使能）”：SMF惯性运行期间计费，计费使用量在惯性运行恢复后上报CHF。“DISABLE（不使能）”：SMF惯性运行期间不计费，计费使用量丢弃，不上报CHF。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CHGIOPARA查询当前参数配置值。  配置原则：无                                                                          |
| FINALRPTSW     | 惯性运行FINAL上报开关          | 可选必选说明：可选参数  参数含义：该参数用于控制SMF进入惯性运行时是否向CHF上报所有RG和QF的FINAL用量容器。  数据来源：本端规划 取值范围： “DISABLE（不使能）”：事件发生，不生成流量容器，不上报CHF。“ENABLE（使能）”：事件发生，不下查用量，SMF构造零用量容器，并上报CHF。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CHGIOPARA查询当前参数配置值。  配置原则：无                                                              |
| VTRPTSW        | 惯性运行期间VT触发上报开关         | 可选必选说明：该参数在"FINALRPTSW"配置为"DISABLE"时为条件可选参数。  参数含义：该参数用于控制SMF惯性运行期间VT定时器超时是否上报CHF。  数据来源：本端规划 取值范围： “DISABLE（不使能）”：事件发生，不生成流量容器，不上报CHF。“ENABLE（使能）”：事件发生，不下查用量，SMF构造零用量容器，并上报CHF。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CHGIOPARA查询当前参数配置值。  配置原则：  当参数FINALRPTSW配置为ENABLE时，该参数不生效。         |
| CHFREAUTHRPTSW | 惯性运行期间CHF REAUTH触发上报开关 | 可选必选说明：该参数在"FINALRPTSW"配置为"DISABLE"时为条件可选参数。  参数含义：该参数用于控制SMF惯性运行期间收到CHF REAUTH请求时是否上报CHF。  数据来源：本端规划 取值范围： “DISABLE（不使能）”：事件发生，不生成流量容器，不上报CHF。“ENABLE（使能）”：事件发生，不下查用量，SMF构造零用量容器，并上报CHF。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CHGIOPARA查询当前参数配置值。  配置原则：  当参数FINALRPTSW配置为ENABLE时，该参数不生效。 |

## 使用实例

设置SMF惯性运行期间计费，不上报FINAL，使能VT到上报和CHF REAUTH上报：

```
SET CHGIOPARA: N40USAGERPTSW=ENABLE, FINALRPTSW=DISABLE, VTRPTSW=ENABLE, CHFREAUTHRPTSW=ENABLE;
```
