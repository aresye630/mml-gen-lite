# 显示APP详细订阅信息（DSP WLRSUBINFOVERBOSE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示APP订阅详细信息。

#### 注意事项

只有建立无线路由对端peer后才能使用该命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                         |
|:-------|:-------|:-----------------------------------------------------------------------------|
| PEER   | PEER地址 | 可选必选说明：可选参数 参数含义：该参数用于表示PEER地址。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～64。IP地址。 默认值：无 |

#### 使用实例

显示APP订阅详细信息：

```
DSP WLRSUBINFOVERBOSE:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
  PEER地址  =  10.1.1.100
   VPN名字  =  vpna
  订阅信息  =  0x41
重传定时器  =  FALSE
      状态  =  NULL
(结果个数 = 1)
---    END
```

| 输出项名称   | 输出项解释       |
|:--------|:------------|
| PEER地址  | 用于表示PEER地址。 |

| 订阅信息    | 用于表示订阅信息。   |
| 重传定时器   | 用于表示重传定时器。  |
| 状态      | 用于表示状态。     |
