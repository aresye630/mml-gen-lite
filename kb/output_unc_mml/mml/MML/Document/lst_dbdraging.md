# 查询CSDB容灾数据老化开关(LST DBDRAGING)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询CSDB容灾数据老化开关。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                        |
|:----------|:---------|:------------------------------------------------------------------------------------------------------------|
| LDRINSTID | 本端容灾实例ID | 可选必选说明：可选参数。 参数含义：本端容灾实例ID，可使用LST DRINST命令查询获取。如果不输入本参数，则表示查询所有本端容灾实例ID的容灾老化开关。 数据来源：全网规划 取值范围：0～63。 默认值：无。 |
| PDRINSTID | 对端容灾实例ID | 可选必选说明：可选参数。 参数含义：对端容灾实例ID，可使用LST DRCOMM命令查询获取。如果不输入本参数，则表示查询所有对端容灾实例ID的容灾老化开关。 数据来源：全网规划 取值范围：0~63。 默认值：无。 |

#### 使用实例

查询所有容灾数据老化开关：

```
%%LST DBDRAGING:;%%
RETCODE = 0  执行成功

操作结果如下:
-------------------------
本端容灾实例ID  =  0
对端容灾实例ID  =  1
容灾老化开关    =  关闭容灾老化功能
(结果个数 = 1)

--- END
```

#### 输出结果说明

| 输出项名称    | 输出项解释                           |
|:---------|:--------------------------------|
| 本端容灾实例ID | 本端容灾实例标识。                       |
| 对端容灾实例ID | 对端容灾实例标识。                       |
| 容灾老化开关   | 容灾老化开关。 取值范围：关闭容灾老化功能。开启容灾老化功能。 |
