# 查询网络切片支持的DNN（LST NSDNN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF**

该命令用于查询网络切片支持的DNN列表。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                          |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NSIDX  | 网络切片索引 | 可选必选说明：可选参数  参数含义：该参数用于指定网络切片，可以使用LST PLMNNS命令查询获取。  数据来源：全网规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：  本参数通过ADD NFNS命令进行配置，且NF类型必须是NfSMF。                                                                                                                                |
| DNN    | 数据网络名称 | 可选必选说明：可选参数  参数含义：该参数用于表示指定的网络切片支持的数据网络名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。可配置通配DNN，即“*”，表示支持所有DNN。  默认值：无  配置原则：  确保为S-NSSAI增加其支持的DNN在LST APN中能够查询到。 |

## 使用实例

查询eMBB切片支持的DNN列表：

```
%%LST NSDNN: NSIDX=0, DNN="huawei.com";%%
RETCODE = 0  操作成功

结果如下
--------
         网络切片索引  =  0
         数据网络名称  =  huawei.com
EPS互操作默认切片指示  =  否
绑定的SMFINFO ID = null
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称         | 输出项解释                                |
|:--------------|:-------------------------------------|
| 网络切片索引        | 该参数用于指定网络切片，可以使用LST PLMNNS命令查询获取。    |
| 数据网络名称        | 该参数用于表示指定的网络切片支持的数据网络名称。             |
| EPS互操作默认切片指示  | 该参数用于指定PDN连接建立流程中根据DNN为用户分配的互操作默认切片。 |
| 绑定的SMFINFO ID | 该参数用于指定绑定的SMFINFOEXT记录。              |
