# 查询NRF国际漫游连接策略（LST NRFCONNPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NRF**

此命令用于查询NRF对接NF/NRF时的国际漫游的连接策略。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                                                                                                                           |
|:-----------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PEERNFTYPE | 对端NF类型   | 可选必选说明：可选参数  参数含义：该参数用于表示对端NF类型。  数据来源：本端规划 取值范围： NRF（NRF）NF（NF）  默认值：无  配置原则：无                                                                                                                                                                                                |
| CONNPOLICY | 国际漫游连接策略 | 可选必选说明：可选参数  参数含义：该参数用于表示国际漫游连接策略。  数据来源：全网规划 取值范围： “DIRECT（DIRECT）”：与对端NF直接通信，不通过SEPP。“SBI_TARGET_APIROOT（SBI_TARGET_APIROOT）”：与对端NF通过SEPP交互，在http头中携带对端NF的地址信息。“HTTP_PROXY（HTTP_PROXY）”：与对端NF通过SEPP交互，在URI中携带对端NF的地址信息。  默认值：无  配置原则：  建议本PLMN内NF与SEPP的连接和NRF与SEPP的连接策略保持一致。 |

## 使用实例

使用以下命令查询NRF对接NF/NRF时的国际漫游的连接策略。

```
LST NRFCONNPLCY
%%LST NRFCONNPLCY:;%%
RETCODE = 0  操作成功

结果如下
--------
      对端NF类型  =  NRF
国际漫游连接策略  =  DIRECT
(结果个数 = 1)

---    END
```
