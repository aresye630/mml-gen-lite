# 查询网络开放事件订阅功能参数（LST EVTSUBFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询网络开放事件订阅功能参数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询网络开放事件订阅功能参数，执行如下命令：

```
%%LST EVTSUBFUNC:;%%
RETCODE = 0  操作成功

结果如下
--------
                        事件订阅使能开关  =  开启
                        重复订阅清除开关  =  关闭
                        无效订阅清除开关  =  关闭
                        时区事件上报开关  =  关闭
                    接入类型事件上报开关  =  关闭
位置事件非立即上报空闲态用户位置获取开关  =  关闭
                    事件订阅通知上报策略  =  分开通知
                      周期性订阅上报开关  =  关闭
                  最大支持周期性订阅数量  =  500
                          UE趋势上报开关  =  关闭
                          GNBLST上报开关  =  关闭
                          存储UE位置数量  =  50
                可达状态变更上报增强开关  =  关闭
              UE连接丢失事件上报增强开关  =  关闭
                通信失败事件上报增强开关  =  关闭
                    
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称                | 输出项解释                                                                                                                                                                                                            |
|:---------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 事件订阅使能开关             | 该参数用于表示AMF是否开启事件订阅功能。 当本参数设置为“ON”时，AMF支持处理对端NF发送的事件订阅请求消息或Inter AMF传递的事件订阅相关信元。 当本参数设置为“OFF”时，收到对端NF发送事件订阅请求消息，AMF回复状态码403，cause为UNSPECIFIED；针对Inter AMF场景下，源侧AMF不会将事件订阅相关信元传递新侧AMF，同时新侧AMF也不保存源侧AMF传递的事件订阅相关信元。 |
| 重复订阅清除开关             | 该参数用于控制开启重复事件订阅清除功能。 当本参数设置为“ON（开启）”，同一服务消费者NF向AMF重复订阅了某事件时，AMF会删除用户上下文中旧的网络开放事件订阅信息。 当本参数设置为“OFF（关闭）”，同一服务消费者NF向AMF重复订阅了某事件时，AMF在用户上下文中同时保存新旧事件订阅信息。                                                            |
| 无效订阅清除开关             | 该参数用于控制开启无效事件订阅清除功能。 当本参数设置为“ON（开启）”，若AMF上报事件通知时收到了服务消费者NF返回的404错误码或400错误码且ProblemDetails为“RESOURCE_CONTEXT_NOT_FOUND”，AMF立即删除用户上下文中保存的事件订阅信息。 当本参数设置为“OFF（关闭）”，AMF仅在服务消费者NF发送事件订阅删除场景下删除用户上下文中保存的事件订阅信息。        |
| 时区事件上报开关             | 该参数用于控制AMF是否支持用户事件订阅类型为时区的事件上报功能。 本参数设置为ON，对端NF向AMF订阅用户事件类型为时区的事件上报（TIMEZONE_REPORT），当AMF感知用户所在时区发生变化时向对端NF上报事件。 本参数设置为OFF，对端NF向AMF订阅用户事件类型为时区的事件上报（TIMEZONE_REPORT），AMF不处理时区的事件上报。                              |
| 接入类型事件上报开关           | 该参数用于控制AMF是否支持用户事件订阅类型为接入类型的事件上报功能。 本参数设置为ON，对端NF向AMF订阅用户事件类型为接入类型的事件上报（ACCESS_TYPE_REPORT），当AMF感知用户所在接入类型发生变化时向对端NF上报事件。 本参数设置为OFF，对端NF向AMF订阅用户事件类型为接入类型的事件上报（ACCESS_TYPE_REPORT），AMF不处理接入类型事件上报。               |
| 位置事件非立即上报空闲态用户位置获取开关 | 该参数用于控制用户事件订阅类型为位置事件上报且非立即上报场景下，AMF是否针对空闲态用户进行寻呼获取用户最新位置信息。 本参数设置为ON，对端NF向AMF订阅用户事件，其中订阅类型为位置事件上报（LOCATION_REPORT）且非立即上报场景下，AMF针对空闲态用户进行寻呼获取用户实时位置信息。                                                            |
| 事件订阅通知上报策略           | 该参数用于表示当AMF同时满足多个事件上报时，AMF向对端订阅NF上报事件订阅通知的策略。                                                                                                                                                                    |
| 周期性订阅上报开关            | 该参数用于控制AMF是否支持事件周期性上报功能。 当本参数设置为“ON”，对端NF向AMF的订阅事件中trigger字段为PERIODIC时，AMF会处理此类事件订阅。                                                                                                                             |
| 最大支持周期性订阅数量          | 该参数用于控制单DS最大支持的周期性事件上报个数。 当DS上保存的事件订阅个数（用户粒度）超过本参数阈值的80%时，AMF会上报ALM-100293关键资源过载。                                                                                                                                |
| UE趋势上报开关             | 该参数用于控制AMF是否支持UE_LOCATION_TRENDS事件。 当本参数设置为“OFF”，AMF收到UE_LOCATION_TRENDS事件时，AMF向对端NF回复状态码501 UNSUPPORTED_EVENT_TYPE。                                                                                             |
| GNBLST上报开关           | 该参数用于控制AMF在UE_LOCATION_TRENDS事件订阅中是否支持上报globalGnbList信元。 当本参数设置为“OFF”，AMF收到UE_LOCATION_TRENDS事件并携带globalGnbList信元时，AMF向对端NF回复状态码501 UNSUPPORTED_EVENT_TYPE。                                                      |
| 存储UE位置数量             | 该参数用于设置AMF存储单个UE的最大gNodeB数量，当UE经过的gNodeB数量达到设置值时AMF向订阅者上报UE_LOCATION_TRENDS事件。                                                                                                                                   |
| 可达状态变更上报增强开关         | 该参数用于控制NF向AMF订阅用户可达状态变更时，AMF是否需要立即上报当前用户可达状态事件。 本参数设置为ON时，AMF立即上报用户当前可达状态事件。 本参数设置为OFF时，AMF仅在immediateFlag取值为true时上报用户当前可达状态事件。                                                                                  |
| UE连接丢失事件上报增强开关       | 该参数用于控制NF向AMF订阅UE连接丢失事件（LOSS_OF_CONNECTIVITY）且AMF发起Purge流程时是否上报UE连接丢失事件。                                                                                                                                         |
| 通信失败事件上报增强开关         | 该参数用于控制NF向AMF订阅通信失败事件（COMMUNICATION_FAILURE_REPORT）且满足以下场景时，AMF是否上报通信失败事件。 （1）除UDM签约数据变更之外核心网向UE发起的去注册流程； （2）移动注册更新流程或服务请求流程中由于ODB限制、CAG限制、5G黑名单限制（SET USRBLACKLSTFUN）、IP地址细分导致的接入失败流程。                          |
