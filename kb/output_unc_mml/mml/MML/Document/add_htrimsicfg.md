# 增加HTR号段(ADD HTRIMSICFG)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用于添加一个HTR局向的具体IMSI号段。只有当HTROFC配置表中“HTR局向索引”对应的“局向流控开关”为“YES”时，本命令所配置的各个IMSI号段才进行流控，可执行**LST HTROFC**进行查看。

#### 注意事项

- 该命令执行后立即生效。
- 该表的最大记录数为5000。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                   |
|:------------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSIPRE     | IMSI前缀  | 可选必选说明：必选参数 参数含义：该参数用于系统根据指定用户的IMSI进行匹配，从而区分不同的用户群。 数据来源：整网规划 取值范围：5~15位十进制数字字符串 默认值：无  说明： 按照IMSI最长匹配进行查询，相同IMSI前缀只能配置一条记录。IMSI前缀的匹配方式采取由前向后的最长匹配，即若对于用户可以匹配到多个用户群，则使用IMSI前缀最长的用户群配置。 |
| HTROFCINDEX | HTR局向索引 | 可选必选说明：必选参数 参数含义：该参数用于指定HTR局向索引。 前提条件：该参数必须在HTROFC表中事先配置。可使用LST HTROFC命令查询。 数据来源：整网规划 取值范围：0~9 默认值：无                                                                                   |

#### 使用实例

增加记录，添加IMSI前缀为“123030001”，HTR局向索引为5：

ADD HTRIMSICFG: IMSIPRE="123030001", HTROFCINDEX=5;
