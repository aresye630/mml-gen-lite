# 删除UPF和DNS关联的UPF组的绑定关系（RMV UEDNSUPFBINDGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于删除UPF和DNS关联的UPF组的绑定关系。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

## 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                                                     |
|:-----------|:--------|:-------------------------------------------------------------------------------------------------------------------------|
| UPFGRPNAME | UPF组名称  | 可选必选说明：必选参数  参数含义：该参数用于指定UPF组的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。不区分大小写。  默认值：无  配置原则：  该参数使用ADD UEDNSUPGROUP命令配置生成。 |
| UPFID      | UPF实例标识 | 可选必选说明：必选参数  参数含义：该参数用于指定UPF实例名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。不区分大小写。  默认值：无  配置原则：  该参数使用ADD UPNODE命令配置生成。      |

## 使用实例

删除UPF和UPF组的绑定关系, UPFID为upf\_instance\_1：

```
RMV UEDNSUPFBINDGRP: UPFGRPNAME="upfgrp1", UPFID="upf_instance_1";
```
