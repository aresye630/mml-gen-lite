# 删除TA级限制切片（RMV AMFRSTRNSSAI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除TA级限制切片。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                         |
|:--------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RSTRAREARANGE | 限制区域范围 | 可选必选说明：必选参数  参数含义：该参数用于配置TA级限制切片所属区域的范围：所有区域或者指定区域编码。  数据来源：全网规划 取值范围： “ALL_AREA（所有区域）”：所有区域“AREA_CODE（指定区域编码）”：指定区域编码  默认值：无  配置原则：无                                                                                                                                                        |
| RSTRAREACODE  | 限制区域编码 | 可选必选说明：该参数在"RSTRAREARANGE"配置为"AREA_CODE"时为条件必选参数。  参数含义：该参数用于配置TA级限制切片所属的具体区域信息。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~128。该限制区域编码必须通过ADD RSTRNSAREACODE命令成功添加，可执行LST RSTRNSAREACODE进行查看。区域编码内的成员由ADD RSTRNSAREAMEM添加。  默认值：无  配置原则：无                                                              |
| SUBRANGE      | 用户范围   | 可选必选说明：必选参数  参数含义：该参数用于指定TA级限制切片应用的用户范围。  数据来源：全网规划 取值范围： “ALL_USER（所有用户）”：所有用户“HOME_USER（本网用户）”：本网用户“FOREIGN_USER（外网用户）”：外网用户“IMSI_PREFIX（IMSI前缀）”：指定IMSI前缀  默认值：无  配置原则：  对于指定的用户（群），AMF选择策略的匹配优先级从高到低依次为：“IMSI_PREFIX(指定IMSI前缀)”，“FOREIGN_USER(外网用户)”或“HOME_USER(本网用户)”，“ALL_USER(所有用户)”。 |
| IMSIPRE       | IMSI前缀 | 可选必选说明：该参数在"SUBRANGE"配置为"IMSI_PREFIX"时为条件必选参数。  参数含义：该参数用于指定应用TA级限制切片的用户的IMSI前缀。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~15。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                                                                                                                          |
| SST           | 切片业务类型 | 可选必选说明：可选参数  参数含义：该参数表示切片的业务类型，如eMBB（1）、URLLC（2）、MIoT（3）等协议定义的标准SST，或者运营商自定义的SST。  数据来源：全网规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无                                                                                                                                                           |
| SD            | 切片细分标识 | 可选必选说明：可选参数  参数含义：该参数表示根据网络切片所提供的服务特点、所服务的对象差异，对某种网络切片的进一步细分。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。采用十六进制表示（无须输入“0x”前缀），只能由数字（0-9），字母（A-F、a-f）组成。字母大小写不敏感。  默认值：无  配置原则：  该值若不设置，默认值为FFFFFF。                                                                                                        |

## 使用实例

删除在所有区域中，限制指定外网的用户使用eMBB切片，执行如下命令：

```
RMV AMFRSTRNSSAI:RSTRAREARANGE=ALL_AREA,SUBRANGE=FOREIGN_USER;
```
