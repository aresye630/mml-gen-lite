#### 命令功能

**适用NF：NCG**

该命令用于查询RU对应的通道过滤规则：

如果需要查询全部信息，请不要输入任何参数。

如果需要查询某方面的详细信息，请输入具体参数。例如，查询具体RU的过滤规则，请输入具体的RUID值。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                   |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------------|
| RUID    | RU的ID  | 可选必选说明：可选参数 参数含义：RU的ID。 数据来源：本端规划 取值范围：整数类型，取值范围为64～4294967294。 默认值：无 配置原则：该值需要执行LST SERVICERUSTATE命令，查询出存在的RU ID进行填写。 |
| CHLNAME | 通道名称   | 可选必选说明：可选参数 参数含义：通道名称的取值为具体的通道名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：无。                                       |

#### 使用实例

查询RUID为64的通道过滤规则，示例如下：

```
LST NOCENTCNCHL: RUID=64;
```

```
RETCODE = 0  操作成功
结果如下:
---------
  RU的ID  =  64
通道名称  =  00/ABNORMAL
(结果个数 = 1)
---    END
```
