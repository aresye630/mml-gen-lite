# 删除PDU会话激活控制参数（RMV PDUACTCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除基于DNN配置PDU会话激活处理策略。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                       |
|:---------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围     | 可选必选说明：必选参数  参数含义：该参数用于指定用户范围。  数据来源：全网规划 取值范围： “ALL_USER（所有用户）”：所有用户。“HOME_USER（本网用户）”：本网用户。“FOREIGN_USER（外网用户）”：外网用户。“IMSI_PREFIX（IMSI前缀）”：IMSI前缀。“SPECIFIC_IMSI（指定IMSI）”：指定IMSI。  默认值：无  配置原则：无                                                                                                                         |
| IMSIPRE  | IMSI前缀   | 可选必选说明：该参数在"SUBRANGE"配置为"IMSI_PREFIX"时为条件必选参数。  参数含义：该参数用于指定IMSI前缀。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是5~14。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                                                                                                                                                                     |
| IMSI     | IMSI     | 可选必选说明：该参数在"SUBRANGE"配置为"SPECIFIC_IMSI"时为条件必选参数。  参数含义：该参数用于指定IMSI。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是14~15。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                                                                                                                                                                    |
| DNNTYPE  | DNN类型    | 可选必选说明：必选参数  参数含义：该参数用于指定请求DNN类型。  数据来源：全网规划 取值范围： “ALL_DNN（所有DNN）”：表示请求DNN为任意DNN。“NOT_NULL_DNN（非空DNN）”：表示请求DNN为非空DNN。“NULL_DNN（空DNN）”：表示请求DNN为空DNN。“SPECIAL_DNN（指定DNN）”：表示请求DNN为指定DNN。  默认值：无  配置原则：  请求DNN为空时，选择“NULL_DNN”。  请求DNN为非空时，选择“NOT_NULL_DNN”。  请求DNN为指定DNN时，选择“SPECIAL_DNN”。  请求DNN包括空DNN和非空DNN时，选择“ALL_DNN”。 |
| DNN      | 用户请求的DNN | 可选必选说明：该参数在"DNNTYPE"配置为"SPECIAL_DNN"时为条件必选参数。  参数含义：该参数用于指定用户请求的DNN。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。可输入的字符有字母、十进制数字、“-”和“.”，并且开头和结尾只能是数字或者字母。不能出现连续两个“.”。字母大小写不敏感。  默认值：无  配置原则：无                                                                                                                                      |

## 使用实例

解除限定使用DNN为“huawei.com”，IMSI为“123456789012345”的用户PDU会话激活，执行如下命令：

```
RMV PDUACTCTRL:SUBRANGE=SPECIFIC_IMSI,IMSI="123456789012345",DNNTYPE=SPECIAL_DNN,DNN="huawei.com";
```
