# 查询SDR传输能力（LST SDRTRANS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询SDR传输能力。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                      |
|:-------------|:-------|:--------------------------------------------------------------------------------------------------------------------------|
| FLATTYPE     | 通信平面类型 | 可选必选说明：可选参数  参数含义：该参数用于标识SDR通信平面类型。  数据来源：本端规划 取值范围： “BASE（Base）”：Base平面“FABRIC（Fabric）”：Fabric平面  默认值：无  配置原则：无          |
| TRANSABILITY | 传输能力类型 | 可选必选说明：可选参数  参数含义：该参数用于标识SDR传输能力类型。  数据来源：本端规划 取值范围： “RELIABILITY（可靠传输能力）”：可靠传输能力“SECURITY（安全传输能力）”：安全传输能力  默认值：无  配置原则：无 |

## 使用实例

查询SDR的BASE平面RELIABILITY传输能力：

```
%%LST SDRTRANS: FLATTYPE=BASE, TRANSABILITY=RELIABILITY;%%
RETCODE = 0  操作成功

结果如下
--------
通信平面类型  =  Base
传输能力类型  =  可靠传输能力
    选项开关  =  不设置该传输能力
(结果个数 = 1)

---    END
```

| 输出项名称   | 输出项解释                |
|:--------|:---------------------|

| 传输能力类型  | 该参数用于标识SDR传输能力类型。    |
| 选项开关    | 该参数用于标识SDR传输能力的选项开关。 |
