# 删除DCN映射关系(RMV DCNMAP)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

此命令用于删除DCN与UE USAGE TYPE的映射关系。删除后该DCN不再服务于通过**ADD DCNMAP**配置的UE USAGE TYPE范围内的用户。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称            | 参数说明                                                                |
|:---------------|:----------------|:--------------------------------------------------------------------|
| DCNID          | DCN ID          | 可选必选说明：必选参数 参数含义：该参数用于指定DCN ID。 数据来源：全网规划 取值范围：0~255 默认值：无          |
| BGNUEUSAGETYPE | 起始UE USAGE TYPE | 可选必选说明：必选参数 参数含义：该参数用于指定起始UE USAGE TYPE。 数据来源：全网规划 取值范围：0~255 默认值：无 |

#### 使用实例

删除DCN ID是1的DCN所服务的用户范围：

RMV DCNMAP: DCNID=1, BGNUEUSAGETYPE=150;
