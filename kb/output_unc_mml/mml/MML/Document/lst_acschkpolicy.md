# 查询ACS检查策略(LST ACSCHKPOLICY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明
- 参考信息

## 命令功能

用于查询ACS配置检查策略项。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                             |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------------|
| POLICY | 策略     | 可选必选说明：可选参数。 参数含义：用于指定需要查询的策略。 取值范围：枚举类型。 Check_Service_Data(检查微服务数据)：凌晨定时检查ACS与远端配置数据。 默认值：Check_Service_Data(检查微服务数据)。 配置原则：无。 |

## 使用实例

查询“检查微服务数据”时，执行以下命令：

```
LST ACSCHKPOLICY: POLICY=Check_Service_Data;
```

```
%%LST ACSCHKPOLICY: POLICY=Check_Service_Data;%%
RETCODE = 0  操作成功

操作结果如下
------------
    策略  =  检查微服务数据
策略开关  =  关闭
(结果个数 = 1)

---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。输出结果说明如下表所示。

| 输出项名称   | 输出项解释                                   |
|:--------|:----------------------------------------|
| 策略      | 策略项名称。                                  |
| 策略开关    | 策略开关状态，有如下2种状态： 打开。表示该策略使能。关闭。表示该策略不使能。 |
