# 停止位置上报（STOP LOCATEREPORT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于设置停止用户位置上报参数。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                                                                     |
|:-------------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI         | 用户标识    | 可选必选说明：必选参数  参数含义：该参数用于指定用户标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~100。  默认值：无  配置原则：无                                                                                       |
| PDUSESSIONID | PDU会话ID | 可选必选说明：必选参数  参数含义：该参数用于指定PDU会话ID。  数据来源：本端规划  取值范围：整数类型，取值范围是1~15。  默认值：无  配置原则：无                                                                                        |
| REPORTSTATUS | 上报状态    | 可选必选说明：必选参数  参数含义：该参数用于启动或停止位置上报。  数据来源：本端规划 取值范围： “Start（开始）”：开始位置上报“Stop（停止）”：停止位置上报  默认值：无  配置原则：  在STR LOCATEREPORT命令中应选择配置“Start”，在STOP LOCATEREPORT命令中应选择配置“Stop”。 |

## 使用实例

停止上报用户位置时使用该命令：

```
STOP LOCATEREPORT:IMSI="12",PDUSESSIONID=2,REPORTSTATUS=Stop;
```
