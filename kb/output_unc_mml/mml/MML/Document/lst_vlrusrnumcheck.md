# 查询VLR非短信用户数核查扫描参数（LST VLRUSRNUMCHECK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMSF**

该命令用于查询VLR非短信用户数核查扫描参数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

运营商希望查询VLR非短信用户数核查扫描参数，执行如下命令：

```
LST VLRUSRNUMCHECK:;
%%LST VLRUSRNUMCHECK:;%%
RETCODE = 0  操作成功

结果如下：
------------------------
VLR非短信用户数核查开关= 打开
VLR非短信用户数核查速率 (个每秒) = 20
VLR非短信用户数核查周 期(小时) = 168

(结果个数 = 1)
```

## 输出结果说明

| 输出项名称               | 输出项解释                      |
|:--------------------|:---------------------------|
| VLR非短信用户数核查开关       | 该参数用于开启/关闭VLR非短信用户数核查功能。   |
| VLR非短信用户数核查速率 (个每秒) | 该参数用于表示VLR核查非短信用户数记录的扫描速率。 |
| VLR非短信用户数核查周期(小时)   | 该参数用于表示VLR非短信用户数核查周期。      |
