# 查询软件参数表(LST SOFTPARA)

#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询软参配置记录。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                       |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DT      | 参数类型   | 可选必选说明：必选参数 参数含义：待查询软件参数的数据类型。 取值范围：“BYTE(单字节类型)”“DWORD(无符号整数类型)”“STR(字符串类型)”“BYTE_EX(扩展单字节类型)”“DWORD_EX(扩展无符号整数类型)”“STR_EX(扩展字符串类型)”“BYTE_EX_B(扩展单字节类型B)”“DWORD_EX_B(扩展无符号整数类型B)”“STR_EX_B(扩展字符串类型B)” 默认值：无                                                                                                                                                               |
| PARANUM | 参数索引   | 可选必选说明：可选参数 参数含义：待查询软件参数索引。 取值范围：1~512 默认值：无 配置原则：当参数类型取值为“BYTE”时，参数索引的取值范围是“1~240”。当参数类型取值为“DWORD”时，参数索引的取值范围是“1~60”。当参数类型取值为“STR”时，参数索引的取值是“1”。当参数类型取值为“BYTE_EX”时，参数索引的取值范围是“1~224”。当参数类型取值为“DWORD_EX”时，参数索引的取值范围是“1~56”。当参数类型取值为“STR_EX”时，参数索引的取值是“1”。当参数类型取值为“BYTE_EX_B”时，参数索引的取值范围是“1~464”。当参数类型取值为“DWORD_EX_B”时，参数索引的取值范围是“1~116”。当参数类型取值为“STR_EX_B”时，参数索引的取值范围是“1”。 |

#### 使用实例

查询当前参数索引为1的单字节类型软参的设置情况：

LST SOFTPARA: DT=BYTE, PARANUM=1;

```
%%LST SOFTPARA: DT=BYTE, PARANUM=1;%%
RETCODE = 0  操作成功。
查询软件参数表
--------------
参数类型  =  单字节类型
参数索引  =  1
  参数值  =  0x00(0)
(结果个数 = 1)
---    END
```
