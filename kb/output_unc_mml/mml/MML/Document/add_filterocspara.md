# 增加需要过滤掉的OCS实例信息（ADD FILTEROCSPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NCG**

该命令用于增加需要过滤掉的OCS实例信息。

## 注意事项

- 该命令执行后立即生效。

- 当NCGSOFTPARA软参Dword23Bit31的值为1时，该命令的OCS过滤标识参数需遵循CC\_index格式配置原则，CC值为四位十六进制数，可参考命令LST CCPCCACT的指定计费属性值配置，index为配置标识序号，可以为多位整数。
- NF实例ID参数值必须在MML命令LST PNFPROFILE的NF实例标识参数参数中已配置。

- 最多可输入256条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

|:--------------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FILTERID      | OCS过滤标识 | 可选必选说明：必选参数  参数含义：该参数表示过滤的OCS标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~40。字符串类型，输入长度范围是1~40。该参数只能由字母（A-Z或者a-z）、数字（0-9）、中划线（-）、下划线（_）组成。  默认值：无  配置原则：无                           |
| NFINSTANCEID  | NF实例ID  | 可选必选说明：必选参数  参数含义：该参数表示NF实例ID。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~40。字符串类型，输入长度范围是1~40。该参数只能由字母（A-Z或者a-z）、数字（0-9）、中划线（-）、下划线（_）组成。"NF实例ID"可以通过DSP NFCACHE命令查询。  默认值：无  配置原则：无 |
| SERINSTANCEID | 业务实例ID  | 可选必选说明：可选参数  参数含义：该参数表示业务实例ID。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~40。字符串类型，输入长度范围是1~40。该参数只能由字母（A-Z或者a-z）、数字（0-9）、中划线（-）、下划线（_）组成。  默认值：无  配置原则：无                             |

## 使用实例

增加OCS过滤标识为ocsid001，NF实例ID为88888888-4444-1234-5678-123456789ABC，业务实例ID为service\_instance\_0的OCS实例信息：

```
ADD FILTEROCSPARA:FILTERID="ocsid001",NFINSTANCEID="88888888-4444-1234-5678-123456789ABC",SERINSTANCEID="service_instance_0";
```
