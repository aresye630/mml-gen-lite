# 查询服务发现Service负载均衡功能（LST NFDISCSRVLBSW）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF、SMF、NSSF、SMSF、NCG、CBC、CBCF**

该命令用于查询服务发现时的NF Service负载均衡功能。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询服务发现时的NF Service负载均衡功能。

```
%%LST NFDISCSRVLBSW:;%%
RETCODE = 0  操作成功

结果如下
------------------------
对端NF类型    =  NfUDM
负载均衡开关  =  ON
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                        |
|:--------|:-----------------------------|
| 对端NF类型  | 该参数用于指定对端NF类型。               |
| 负载均衡开关  | 该参数用于指定是否开启NF Service负载均衡功能。 |
