# 查询5QI到标准QCI的映射（LST QOS5QI2QCIMAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于查询5QI到标准QCI的映射。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                            |
|:------------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------|
| CTRLTYPE    | 控制类型     | 可选必选说明：可选参数  参数含义：该参数用于指定QoS控制的类型。  数据来源：全网规划 取值范围： APN_LEVEL（APN级别）GLOBAL_LEVEL（整系统级别）  默认值：无  配置原则：无                                          |
| APN         | APN      | 可选必选说明：该参数在"CTRLTYPE"配置为"APN_LEVEL"时为条件可选参数。  参数含义：该参数用于指定APN实例名。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~63。不区分大小写。  默认值：无  配置原则：  该参数使用ADD APN命令配置生成。 |
| QOS5QISTART | 5QI范围起始点 | 可选必选说明：可选参数  参数含义：该参数用于指定5QI范围的起始值。  数据来源：全网规划  取值范围：整数类型，取值范围是1~255。  默认值：无  配置原则：无                                                            |
| QOS5QIEND   | 5QI范围结束值 | 可选必选说明：可选参数  参数含义：该参数用于指定5QI范围的结束值。  数据来源：全网规划  取值范围：整数类型，取值范围是1~255。  默认值：无  配置原则：无                                                            |
| QCI         | QCI      | 可选必选说明：可选参数  参数含义：该参数用于指定标准QCI。  数据来源：全网规划  取值范围：整数类型，取值范围是1~255。  默认值：无  配置原则：  该参数值为1~9或命令ADD STDQOSID中配置的QoS ID值，除此以外都属于扩展QCI/5QI。           |

## 使用实例

查询所有QOS5QI2QCIMAP配置：

```
LST QOS5QI2QCIMAP:;
```

| 5QI范围结束值 | 该参数用于指定5QI范围的结束值。 |
