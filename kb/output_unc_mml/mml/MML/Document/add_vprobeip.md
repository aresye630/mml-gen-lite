# 增加vProbe报表本地IP资源池（ADD VPROBEIP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于添加vProbe的报表本地IP资源池。

## 注意事项

- 该命令执行后立即生效。

- 执行命令前请确认vProbe服务处于上线状态，可通过DSP FUNCTIONSETINFO命令查询确认。
- 每种协议类型VPROBEIP只能配置一条记录，配置的端口范围需要大于等于VPROBEEXEC服务实例数，最多可配置64个。
- 当前版本不支持参数“协议类型”取值为“UDP(UDP)”。
- 当vProbe本端IP和其他服务相同时，端口不能冲突，若存在冲突，请检查网设规划。

- 最多可输入1000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                                                  |
|:-------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INDEX        | 索引号    | 可选必选说明：必选参数  参数含义：该参数用于指定记录索引号。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无                                                                                                                                                               |
| PROTOCOLTYPE | 协议类型   | 可选必选说明：必选参数  参数含义：该参数用于指定vProbe报表使用的协议类型。  数据来源：全网规划 取值范围： TCP（TCP）SFTP（SFTP）UDP（UDP）  默认值：无  配置原则：无                                                                                                                                                  |
| IPTYPE       | IP类型   | 可选必选说明：必选参数  参数含义：该参数用于指定IP地址的类型。  数据来源：全网规划 取值范围： IPv4（IPv4）IPv6（IPv6）  默认值：无  配置原则：无                                                                                                                                                                |
| IPV4         | IPv4地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPv4"时为条件必选参数。  参数含义：该参数用于指定vProbe本端的IPv4地址。  数据来源：本端规划  取值范围：IPv4地址类型。  默认值：无  配置原则：  IPv4地址必须是A、B或者C类地址，不能为环回地址（127.x.y.z）、组播地址（240.x.y.z）或（255.0.0.0）。  IP地址不能和vProbe报表服务器地址在同一网段。                                          |
| IPV6         | IPv6地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPv6"时为条件必选参数。  参数含义：该参数用于指定vProbe本端的IPv6地址。  数据来源：本端规划  取值范围：IPv6地址类型。  默认值：无  配置原则：  IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址(::1)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。  IPv6地址不能和vProbe报表服务器地址在同一网段。 |
| PORTSTART    | 起始端口号  | 可选必选说明：该参数在"PROTOCOLTYPE"配置为"TCP"、"SFTP"、"UDP"时为条件必选参数。  参数含义：该参数用于指定vProbe报表地址的起始端口号。  数据来源：本端规划  取值范围：整数类型，取值范围是1025~65534。  默认值：无  配置原则：无                                                                                                          |
| PORTEND      | 结束端口号  | 可选必选说明：该参数在"PROTOCOLTYPE"配置为"TCP"、"SFTP"、"UDP"时为条件必选参数。  参数含义：该参数用于指定vProbe报表地址的结束端口号。  数据来源：本端规划  取值范围：整数类型，取值范围是1025~65534。  默认值：无  配置原则：  结束端口号需大于或等于起始端口号，结束端口号与起始端口号之差不能大于等于64。                                                                  |
| VPNNAME      | VPN名称  | 可选必选说明：可选参数  参数含义：该参数用于指定报表传输使用的VPN名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~31。  默认值：_public_  配置原则：无                                                                                                                                                      |
| DESC         | 描述     | 可选必选说明：可选参数  参数含义：该参数用于指定报表IP资源池的描述信息。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~32。  默认值：无  配置原则：无                                                                                                                                                             |

## 使用实例

运营商A为vProbe配置简单组网，添加TCP单据上报的本地IP资源池，索引为1，协议类型为TCP，IP类型为IPv4，地址为“10.185.23.253”，端口为6000到6002：

```
ADD VPROBEIP: INDEX=1, PROTOCOLTYPE=TCP, IPTYPE=IPv4, IPV4="10.185.23.253", PORTSTART=6000, PORTEND=6002;
```
