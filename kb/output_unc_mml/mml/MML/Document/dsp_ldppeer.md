# 显示LDP邻居（DSP LDPPEER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示LDP邻居。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                            |
|:----------|:---------|:--------------------------------------------------------------------------------------------------------------------------------|
| VRFNAME   | VPN实例名称  | 可选必选说明：可选参数 参数含义：该参数用于表示VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                                                        |
| PEERLSRID | 邻居LDP ID | 可选必选说明：可选参数 参数含义：该参数用于表示对等体的LDP标识符，格式为<LSR ID>：<标签空间>。标签空间取值： “0”表示全局标签空间。 “1”表示接口标签空间。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 |

#### 使用实例

显示LDP邻居：

```
DSP LDPPEER:;
```

#### 输出结果说明

| 输出项名称               | 输出项解释                                                                                                                  |
|:--------------------|:-----------------------------------------------------------------------------------------------------------------------|
| VPN实例名称             | 用于表示VPN实例名称。                                                                                                           |
| 邻居LDP ID            | 用于表示对等体的LDP标识符，格式为<LSR ID>：<标签空间>。标签空间取值： “0”表示全局标签空间。 “1”表示接口标签空间。                                                    |
| 邻居最大PDU长度           | 用于表示邻居最大PDU长度。LDP对等体之间通过LDP会话连接上传送的LDP协议报文（PDU）维持LDP会话。该参数描述PDU最大长度。                                                   |
| 邻居环路探测状态            | 用于表示邻居环路探测状态。设备在LDP会话初始化阶段通告本地是否具有环路检测能力。                                                                              |
| 邻居FT标志              | 用于表示邻居FT标志。FT为TRUE时，表示LSR具有GR能力。FT为FALSE时，表示LSR不具有GR能力。                                                                |
| 邻居传输地址              | 用于表示邻居传输地址。用于建立TCP连接。                                                                                                  |
| 邻居路径向量限制值           | 用于表示邻居路径向量限制值。                                                                                                         |
| 邻居keepalive定时器时间（s） | 用于表示邻居keepalive定时器时间。LDP会话建立以后，LSR启动KeepAlive发送定时器周期性地发送KeepAlive消息，用于保持LDP会话。                                         |
| 邻居recovery定时器的值（s）  | 用于表示邻居recovery定时器的值。LDP会话重新建立后，GR Helper启动Recovery定时器，等待LSP的恢复。                                                        |
| 邻居reconnect定时器值（s）  | 用于表示邻居reconnect定时器的值。GR Restarter发生主备倒换后，GR Helper检测到和GR Restarter的LDP会话失败，将启动Reconnect定时器，等待LDP会话的重新建立。               |
| 邻居标签发布方式            | 用于表示邻居标签发布方式。在MPLS体系中，由下游LSR决定将标签分配给特定FEC，再通知上游LSR。即标签由下游指定，标签的分配按从下游到上游的方向分发。 具有标签分发邻接关系的上游LSR和下游LSR必须对使用的标签发布方式达成一致。 |
| 邻居动态协商能力            | 用于表示邻居动态协商能力。                                                                                                          |
