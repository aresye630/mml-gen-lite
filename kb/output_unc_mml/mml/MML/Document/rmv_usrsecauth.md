# 删除二次授权用户（RMV USRSECAUTH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

用于取消用户的二次授权功能。

#### 注意事项

- 用户名称必须已存在。
- 该命令仅限具有Administrators角色的用户可以执行。在扩展域，仅限系统管理员可以执行。

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                          |
|:--------|:-------|:----------------------------------------------------------------------------------------------|
| USRNAME | 用户名称   | 可选必选说明：必选参数 参数含义：用户名称，在OM Portal的“安全 > 用户管理”或通过MML命令创建时的用户名称。 取值范围：长度不超过32个字符。 默认值：无。 配置原则：无。 |

#### 使用实例

删除二次授权用户：

```
%%RMV USRSECAUTH: USRNAME="test01";%%
RETCODE = 0  操作成功

---    END
```

#### 输出结果说明
