#### 命令功能

**适用网元：MME**

本命令用于查询端到端用户跟踪参数。

#### 注意事项

- 此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询端到端用户跟踪参数：

`LST E2ETRCCFG:;`

```
%%LST E2ETRCCFG:;%%
RETCODE = 0  操作成功。

输出结果如下
--------------
 是否上报SGs接口消息  =  是
  是否上报Sv接口消息  =  是
基站上报寻呼消息开关  =  关
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见**SET E2ETRCCFG**的参数说明。
