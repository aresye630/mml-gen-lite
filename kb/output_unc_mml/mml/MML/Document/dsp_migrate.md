# 异构迁移查询（DSP MIGRATE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于网元由X86单板架构切换至ARM单板架构时查询迁移子任务执行状态。

**说明** 

该命令仅在Full-stack虚机场景下支持。

#### 注意事项

无。

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                         |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| EVENT    | 事件类型   | 可选必选说明：必选参数。 参数含义：异构迁移场景查询某个任务状态的任务类型。 取值范围： GAUSSDB_TASK_QUERY（GAUSSDB任务查询）VA_TASK_QUERY（VA任务查询） 默认值：无。 配置原则：无。                                                             |
| SUBEVENT | 子事件类型  | 可选必选说明：必选参数。 参数含义：异构迁移场景查询某个任务状态的子任务类型。 取值范围： BACKUP（数据导出查询）SYNCFILE（数据迁移查询）RESTORE（数据导入查询）OMADAPTERDLD（适配包下载状态查询）OSPKGDLD（OS包下载状态查询） 默认值：无。 配置原则：无。                         |
| PARAM1   | 参数1    | 可选必选说明：必选参数。 参数含义：包含网元pod名称，omutype参数。示例： {#podname#:#gaussdb-9cbed835-1#&#omutype#:#omu#} 取值范围：字符或字母（a～z或A～Z），不超过512个字符长度，“omutype”是枚举类型，枚举值是“omu”和“omu-ex”。 默认值：无。 配置原则：无。 |

#### 使用实例

查询GAUSSDB数据库数据导出任务状态。

```
%%DSP MIGRATE: EVENT=GAUSSDB_TASK_QUERY, SUBEVENT=BACKUP, PARAM1="{#podname#:#gaussdb-9cbed835-1#&#omutype#:#omu#}";%%
RETCODE = 0  操作成功
DSP MIGRATE
-----------
  事件类型  =  GAUSSDB_TASK_QUERY
子事件类型  =  BACKUP
     参数1  =  {#podname#:#gaussdb-9cbed835-1#& #omutype#:#omu#}
      状态  =  success
(结果个数 = 1)
---    END
```

| 参数1     | 用于返回参数1的详细信息，包含网元pod名称，omutype参数。 |
