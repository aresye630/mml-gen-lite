# 查询手工恢复GGSN地址(LST USRCTLGGSN)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用网元：SGSN**

此命令用于查询配置的手工恢复GGSN地址。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询配置的手工恢复GGSN地址列表：

LST USRCTLGGSN:;

```
%%LST USRCTLGGSN:;%%
RETCODE = 0  操作成功。

输出结果如下
----------------
 IP地址类型  =  IPv4
   IPv4地址  =  192.168.123.123
       描述  =  123
(结果个数 = 1)

---    END
```

#### 输出结果说明

请参考命令**ADD USRCTLGGSN**的参数标识。
