# 查询本端端点配置(LST GBIPLOCENDPT)

#### 命令功能

**适用网元：SGSN**

该命令用于在GB OVER IP查询本端端点配置。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                  |
|:-------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------|
| NSEI   | NSE标识    | 可选必选说明：可选参数 参数含义：该参数用于指定端点所在的网络服务实体标识。 取值范围：0～65535 默认值：无                                                                             |
| IPT    | IP地址类型   | 可选必选说明：可选参数 参数含义：该参数用于指定IP地址类型。 取值范围：“IPV4(IPv4)”“IPV6(IPv6)” 默认值：无                                                                   |
| LIPV4  | 本端IPv4地址 | 可选必选说明：条件可选参数 参数含义：该参数用于指定本端使用的IPv4地址。 前提条件：该参数在“IP地址类型”设置为“IPV4(IPv4)”时才生效。 取值范围：0.0.0.0～255.255.255.255 默认值：无                       |
| LIPV6  | 本端IPv6地址 | 可选必选说明：条件可选参数 参数含义：该参数用于指定本端PCU使用的IPv6地址。 前提条件：该参数在“IP地址类型”设置为“IPV6(IPv6)”时才生效。 取值范围：::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 |
| LUP    | 本端UDP端口号 | 可选必选说明：可选参数 参数含义：该参数用于指定本端使用的UDP端口号。 取值范围：1024～65535 默认值：无                                                                            |
