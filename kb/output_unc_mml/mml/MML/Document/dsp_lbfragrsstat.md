# 查询CSLB分片重组统计信息（DSP LBFRAGRSSTAT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询CSLB分片重组统计信息。

#### 注意事项

仅在SET LBFRSTATCFG配置的基于对端IP的统计开关开启时，“统计类型”设置为“TOP\_IP\_ADDR”，查询使用分片资源top50高的对端ip地址才有查询结果。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                                                            |
|:-----------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RUNAME     | RU名称     | 可选必选说明：必选参数 参数含义：查询资源单元的名称。 默认值：无 数据来源：通过DSP RU命令可以查询资源单元名称。 取值范围：字符串形式，不支持空格和符号'?'，区分大小写，字符串长度为1～63 配置原则：无                                                                                                     |
| STATTYPE   | 统计类型     | 可选必选说明：必选参数 参数含义：查询类型 默认值：无 数据来源：整网规划 取值范围：枚举类型“DSCP(分片缓存中的高低优先级报文数量)”：查询分片缓存中的高低优先级报文数量。“RESOURCE_USAGE(分片资源使用率)”：查询分片资源使用率“TOP_IP_ADDR(使用分片资源topN高的对端ip地址)”：查询使用分片资源top50高的对端ip地址 配置原则：无                      |
| STATPRDIDX | 统计周期相对序号 | 可选必选说明：当STATPRDIDX配置为“TOP_IP_ADDR(使用分片资源topN高的对端ip地址)”时，为条件必选参数。 参数含义：该参数用于表示相对系统当前统计周期的序号，0表示查询当前周期的统计。 默认值：无 数据来源：本端规划 取值范围：整数类型，取值范围为0～24。 配置原则：无                                                            |
| ORDERITEM  | 用于排序的统计项 | 可选必选说明：当STATPRDIDX配置为“TOP_IP_ADDR(使用分片资源topN高的对端ip地址)”时，为条件必选参数。 参数含义：该参数用于表示统计项的排序方式。 默认值：无 数据来源：本端规划 取值范围：枚举类型“FRAG_PKT_NUM(分片报文数)” ：查询结果按分片报文数降序排序。“AGED_FRAG_PKT_NUM(被老化的分片报文数)”：查询结果按被老化的分片报文数降序排序。 配置原则：无 |

#### 使用实例

查询资源单元CSLB\_IP\_RU2\_0064的分片资源使用率的统计信息:

```
DSP LBFRAGRSSTAT: RUNAME="CSLB_IP_RU2_0064", STATTYPE=RESOURCE_USAGE;
```

```
%%DSP LBFRAGRSSTAT: RUNAME="CSLB_IP_RU2_0064", STATTYPE=RESOURCE_USAGE;%%
```
