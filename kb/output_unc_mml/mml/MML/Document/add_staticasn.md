# 增加静态ASN（ADD STATICASN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SGW-C、GGSN**

该命令用来增加SGSN、SGW-C信令地址和ASN映射的本地表项。

## 注意事项

- 该命令执行后只对新激活用户生效。

- 最多可输入1000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称               | 参数说明                                                                                           |
|:----------|:-------------------|:-----------------------------------------------------------------------------------------------|
| SRVNODEIP | Service Node信令IP地址 | 可选必选说明：必选参数  参数含义：该参数用于设置SGSN、SGW-C的信令IP。  数据来源：本端规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无            |
| MASK      | IP掩码               | 可选必选说明：必选参数  参数含义：该参数用于设置SGSN、SGW-C信令IP的掩码。  数据来源：本端规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无          |
| ASN       | ASN                | 可选必选说明：必选参数  参数含义：该参数用于设置SGSN、SGW-C对应的ASN值。  数据来源：本端规划  取值范围：整数类型，取值范围是1~65535。  默认值：无  配置原则：无 |

## 使用实例

增加一个sgsn-ip为10.13.13.0，掩码类型为掩码长度的ASN配置：

```
ADD STATICASN: SRVNODEIP="10.13.13.0", MASK="255.255.255.0", ASN=1;
```
