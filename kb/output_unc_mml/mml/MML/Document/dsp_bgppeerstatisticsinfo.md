# 查询BGP对等体统计信息（DSP BGPPEERSTATISTICSINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示BGP IPv4对等体统计信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                                   |
|:-------------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------|
| VRFNAME      | VPN实例名称 | 可选必选说明：可选参数 参数含义：该参数用于指定用户所配置的VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：使用LST L3VPNINST命令查看可用VPN。                          |
| AFTYPE       | 地址族类型   | 可选必选说明：可选参数 参数含义：该参数用于指定VRF的地址族类型。 数据来源：本端规划 取值范围：枚举类型。 ipv4uni：IPv4地址族。ipv4vpn：VPNv4地址族。ipv6uni：IPv6地址族。ipv6vpn：VPNv6地址族。 默认值：ipv4uni |
| SOURCEIFNAME | 多源接口名称  | 可选必选说明：可选参数 参数含义：该参数用来给定多源对等体的接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：仅支持Ethernet及其子接口类型，不区分大小写。                            |

#### 使用实例

显示BGP IPv4对等体统计信息：

```
DSP BGPPEERSTATISTICSINFO:;
```

#### 输出结果说明

| 输出项名称        | 输出项解释                |
|:-------------|:---------------------|
| 对等体地址        | 用于指定路由器对等体的对端地址或地址段。 |
| 多源接口名称       | 用来给定多源对等体的接口名称。      |
| 可达路由数量       | 用于指定可达路由数量。          |
| 不可达路由数量      | 用于指定不可达路由数量。         |
| 过策略前路由数量     | 用于指定过策略前路由数量。        |
| 过策略后路由数量     | 用于指定过策略后路由数量。        |
| 最优路由数量       | 用于指定最优路由数量。          |
| 策略拒绝路由数量     | 用于指定策略拒绝路由数量。        |
| AS环路路由数量     | 用于指定AS环路路由数量。        |
| AS联盟环路路由数量   | 用于指定AS联盟环路路由数量。      |
| 簇环路路由数量      | 用于指定簇环路路由数量。         |
| 无效源路由器ID路由数量 | 用于指定无效源路由器ID路由数量。    |

其余输出项请参见ADD BGPMULTIPEER、ADD FILTERPOLICY的参数说明。
