# 查询基于漫游属性的计费接口选择方式（LST ROAMCHGMODE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SMF、GGSN、SGW-C**

该命令用于查询不同DNN、不同漫游属性、不同类型终端接入不同网络时所选择的计费接口。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|:------------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TMACCTYPE   | 指定终端和接入类型 | 可选必选说明：可选参数  参数含义：该参数用于指定终端和接入类型。  数据来源：本端规划 取值范围： “UE5G_RAT4G（5G终端4G接入）”：5G终端4G接入是指在4G接入的PDN激活流程中，激活消息的PCO中携带5G PDU Session ID信息。“UE5G_RAT5G（5G终端5G接入）”：5G终端5G接入是指在5G接入的PDU激活流程。“UENON5G_RAT4G（非5G终端4G接入）”：非5G终端4G接入是指在4G接入的PDN激活流程。“RAT2G（2G接入）”：2G接入是指在2G接入的一次PDP激活流程。“RATNBIOT（NB-IoT接入）”：NB-IoT接入是指NB-IoT用户接入。“NON_3GPP（非3GPP接入）”：非3GPP接入是指用户从非3GPP网络接入。“RATLTEM（LTE-M接入）”：LTE-M接入是指LTE-M用户接入。“RAT3G（3G接入）”：3G接入是指在3G接入的PDP一次激活流程。  默认值：无  配置原则：无 |
| ROAMINGTYPE | 漫游属性      | 可选必选说明：可选参数  参数含义：该参数用于指定用户漫游属性。  数据来源：本端规划 取值范围： ROAMING（漫游用户）VISITING（拜访用户）HOME（本地用户）  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                 |
| CTRLTYPE    | 控制类型      | 可选必选说明：可选参数  参数含义：该参数用于指定计费接口选择的类型。  数据来源：全网规划 取值范围： APN_LEVEL（APN级别）GLOBAL_LEVEL（整系统级别）  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                |
| APN         | APN名称     | 可选必选说明：该参数在"CTRLTYPE"配置为"APN_LEVEL"时为条件可选参数。  参数含义：该参数用于指示APN名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“ ” ”、“ ` ”特殊字符，不区分大小写。  默认值：无  配置原则：  该参数必须已经通过命令ADD APN配置。                                                                                                                                                                    |

## 使用实例

查询所有基于漫游属性的计费接口选择方式，执行如下命令：

```
%%LST ROAMCHGMODE:;%%
RETCODE = 0  操作成功

结果如下
------------------------
指定终端和接入类型  控制类型     APN名称   漫游属性    按5GS互操作指示选择计费接口  指定的计费接口  作为SGW计费模式  作为V-SMF计费模式  按5GC无限制接入标识选择计费接口

5G终端4G接入        整系统级别   null      漫游用户    False                        GaGy模式        GaGy模式         Nchf模式           False
(结果个数 = 1)

---    END
```
