# 删除IP与NF区域映射关系配置（RMV NRFNFREGIONIP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于删除IP与NF区域的映射关系。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                       |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------|
| IPTYPE | IP类型   | 可选必选说明：必选参数  参数含义：该参数用于指定NF客户端地址的IP类型。  数据来源：本端规划 取值范围： IPV4（IPv4地址）IPV6（IPv6地址）  默认值：无  配置原则：无            |
| IPV4   | IPv4地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPV4"时为条件必选参数。  参数含义：该参数用于表示NF客户端的IPv4地址。  数据来源：本端规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无 |
| IPV6   | IPv6地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPV6"时为条件必选参数。  参数含义：该参数用于表示NF的客户端IPv6地址。  数据来源：本端规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无 |

## 使用实例

删除IP类型为IPV4，IPV4值为"10.10.10.10"的IP与NF区域的映射关系。

```
RMV NRFNFREGIONIP: IPTYPE=IPV4, IPV4="10.10.10.10";
```
