#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询P-GW组信息。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询P-GW组信息:

LST PGWGROUP:;

```
%%LST PGWGROUP:;%%
RETCODE = 0  操作成功。

操作结果如下
--------------
P-GW组号  =  2
    描述  =  M2M P-GW Group
(结果个数 = 1)

---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                          |
|:--------|:-------------------------------|
| P-GW组号  | 参数含义：P-GW组编号。 取值范围：0～15        |
| 描述      | 参数含义：P-GW组描述信息。 取值范围：0～256位字符串 |
