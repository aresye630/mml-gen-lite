# 删除AMF重选功能区域编码（RMV RESELAREACODE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除AMF重选功能的区域编码。

## 注意事项

- 该命令执行后立即生效。

- 删除前请确保RESELAREACODE在ADD RESELAREAMEM和ADD NGAREARESELPLCY中没有被引用。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称        | 参数说明                                                                                                        |
|:--------------|:------------|:------------------------------------------------------------------------------------------------------------|
| RESELAREACODE | AMF重选功能区域编码 | 可选必选说明：必选参数  参数含义：该参数用于唯一标识AMF服务的某个区域，该区域由一个或者若干个跟踪区组成。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~128。  默认值：无  配置原则：无 |

## 使用实例

删除编码为“ReSelZone”的区域定义，执行如下命令：

```
RMV RESELAREACODE: RESELAREACODE="ReSelZone";
```
