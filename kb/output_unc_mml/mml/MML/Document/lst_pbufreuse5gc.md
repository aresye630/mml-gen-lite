# 查询pbuf重用检测开关状态（LST PBUFREUSE5GC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询MSS服务的pbuf重用检测开关状态。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                |
|:---------|:-------|:------------------------------------------------------------------------------------|
| PODTYPE  | pod类型  | 可选必选说明：可选参数  参数含义：该参数用于指定pod类型。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~127。  默认值：无  配置原则：无 |
| POOLNAME | 内存池名称  | 可选必选说明：可选参数  参数含义：该参数用于指定内存池名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~31。  默认值：无  配置原则：无  |

## 使用实例

查询MSS服务的PAE内存池pbuf重用检测开关状态：

```
%%LST PBUFREUSE5GC: PODTYPE="isu-pod",POOLNAME="PAE";%%
RETCODE = 0  操作成功

结果如下
--------
   pod类型  =  isu-pod
内存池名称  =  PAE
  开关标记  =  开关关闭
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                    |
|:--------|:-------------------------------------------------------------------------|
| pod类型   | 该参数用于指定pod类型。                                                            |
| 内存池名称   | 该参数用于指定内存池名称。                                                            |
| 开关标记    | 该参数用于指定pbuf重用检测开关的状态。 如果开关取值是Enable，则表示检测开关打开； 如果开关取值是Disable，则表示检测开关关闭。 |
