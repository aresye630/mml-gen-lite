# 增加NF组（ADD NFGROUP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于在NRF上新增NF实例组信息。

NF组是由一个或者多个NF实例组成的容灾/负荷分担的集群，组内NF实例对外提供相同的业务功能。

## 注意事项

- 该命令执行后立即生效。

- 主备或双活组网的场景下，如果需要配置此命令，则两个NRF上均需执行此命令，且配置参数一致。

- 最多可输入1024条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                  |
|:----------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFGROUPID | NF实例组标识 | 可选必选说明：必选参数  参数含义：该参数用于表示在NRF上配置的NF实例组的标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~128。该参数只能由字母（A-Z或者a-z）、数字（0-9），中划线（-）组成，不区分大小写。  默认值：无  配置原则：无                                                                                                                                                             |
| NFTYPE    | NF类型    | 可选必选说明：必选参数  参数含义：该参数用于表示在NRF上配置的NF类型。  数据来源：全网规划 取值范围： NRF（NRF）UDM（UDM）AMF（AMF）SMF（SMF）AUSF（AUSF）NEF（NEF）PCF（PCF）SMSF（SMSF）NSSF（NSSF）UDR（UDR）LMF（LMF）GMLC（GMLC）EIR_5G（EIR_5G）SEPP（SEPP）UPF（UPF）N3IWF（N3IWF）AF（AF）UDSF（UDSF）BSF（BSF）CHF（CHF）NWDAF（NWDAF）CUSTOM_OCS（CUSTOM_OCS）SCP（SCP）  默认值：无  配置原则：无 |
| GROUPDESC | NF实例组描述 | 可选必选说明：可选参数  参数含义：该参数用于表示在NRF上配置的NF实例组的概要描述。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~256。  默认值：无  配置原则：无                                                                                                                                                                                                      |

## 使用实例

在NRF上新增NF标识为nfgroup001，NF类型为CHF，组描述为nfdescription001的实例组：

```
ADD NFGROUP: NFGROUPID="nfgroup001", NFTYPE=CHF, GROUPDESC="nfdescription001";
```
