# 删除UPF位置信息与UPF优先支持的LAI范围的绑定关系（RMV LOCBINDLAI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：GGSN**

该命令用于删除UPF位置信息与UPF优先支持的LAI范围的绑定关系。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                         |
|:---------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------|
| LOCALITY | UPF位置区  | 可选必选说明：必选参数  参数含义：该参数用于标识UPF位置区。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~255。  默认值：无  配置原则：  该参数需要与ADD PNFPROFILE命令中 “LOCALITY”的取值保持一致，参数匹配时大小写不敏感。  |
| MCC      | 移动国家码   | 可选必选说明：必选参数  参数含义：该参数用于指定对端NF的移动国家码。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。  默认值：无  配置原则：  本参数由3个十进制数字组成。                                            |
| MNC      | 移动网号    | 可选必选说明：必选参数  参数含义：该参数用于指定对端NF的移动网号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。  默认值：无  配置原则：  本参数由2~3个十进制数字组成。                                       |
| LACSTART | LAC起始号段 | 可选必选说明：必选参数  参数含义：该参数用于指定LAC的起始号段。  数据来源：全网规划  取值范围：字符串类型，输入长度是4。不区分大小写。  默认值：无  配置原则：  字符串类型，4位16进制数。  LAC的终止号段需要不小于LAC的起始号段，且结束值和开始值长度需相等。 |
| LACEND   | LAC终止号段 | 可选必选说明：必选参数  参数含义：该参数用于指定LAC的终止号段。  数据来源：全网规划  取值范围：字符串类型，输入长度是4。不区分大小写。  默认值：无  配置原则：  字符串类型，4位16进制数。  LAC的终止号段需要不小于LAC的起始号段，且结束值和开始值长度需相等。 |

## 使用实例

删除UPF位置区与UPF优先支持的LAI范围的绑定关系，其中UPF位置区为“locality1”，MCC为460, MNC为03，LAC起始号段为1301，LAC终止号段为1302。

```
RMV LOCBINDLAI: LOCALITY="locality1", MCC="460", MNC="03", LACSTART="1301", LACEND="1302";
```
