# 查询允许访问的切片（LST ALLOWEDNSSAIS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NRF**

该命令用于查询指定NF对象允许访问的切片信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                    |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------------------|
| OBJNAME | 授权对象名称 | 可选必选说明：可选参数  参数含义：该参数表示设置访问授权控制的NF对象名称，该参数可通过LST ALLOWEDOBJNAME命令获取。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。  默认值：无  配置原则：无 |

## 使用实例

- 查询OBJNAME为objname001的NF对象的切片信息：

  ```
  LST ALLOWEDNSSAIS：OBJNAME="objname001";
  %%LST ALLOWEDNSSAIS: OBJNAME="objname001";%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
         授权对象名称 =  objname001
  允许访问该对象的SST =  2
   允许访问该对象的SD =  010101
             记录状态 =  添加未提交
  (结果个数 = 1)
  ```
- 查询所有NF对象的切片信息：

  ```
  LST ALLOWEDNSSAIS：;
  %%LST ALLOWEDNSSAIS:;%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
  授权对象名称   允许访问该对象的SST  允许访问该对象的SD  记录状态

  objname001     2                    010101              提交状态       
  objname002     2                    010111              添加未提交       
  (结果个数 = 2)
  ```

## 输出结果说明

| 输出项名称       | 输出项解释                                                       |
|:------------|:------------------------------------------------------------|
| 授权对象名称      | 该参数表示设置访问授权控制的NF对象名称，该参数可通过LST ALLOWEDOBJNAME命令获取。          |
| 允许访问该对象的SST | 该参数用于表示指定NF对象所允许访问的SST。SST表示切片业务类型。                         |
| 允许访问该对象的SD  | 该参数用于表示指定NF对象所允许访问的SD。SD表示切片差异描述，即针对上述相同SST再根据用户群等进一步细分的标识。 |
| 记录状态        | 该参数用于表示记录的提交状态。                                             |
