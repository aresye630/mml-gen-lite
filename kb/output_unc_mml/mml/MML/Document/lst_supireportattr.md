# 查询SUPI的上报属性（LST SUPIREPORTATTR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C、SMF**

该命令用于查询SUPI的上报属性。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                         |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN    | APN名称  | 可选必选说明：可选参数  参数含义：该参数用于指示APN名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”特殊字符，不区分大小写。  默认值：无  配置原则：  该参数必须已经通过命令ADD APN配置。 |

## 使用实例

查询所有SUPI的上报属性，执行如下命令：

```
%%LST SUPIREPORTATTR:;%%
RETCODE = 0  操作成功

结果如下
------------------------
APN名称             上报给CG的SUPI  上报给OCS的SUPI  上报给CHF的SUPI  上报给PCRF的SUPI  上报给PCF的SUPI

huawei.com          真实的          真实的           真实的           真实的            真实的 
huawei1.com         真实的          真实的           真实的           真实的            真实的 
(结果个数 = 2)

---    END
```

## 输出结果说明

| 输出项名称        | 输出项解释                      |
|:-------------|:---------------------------|
| APN名称        | 该参数用于指示APN名称。              |
| 上报给CG的SUPI   | 该参数用于指定话单里使用的SUPI。         |
| 上报给OCS的SUPI  | 该参数用于指定与OCS交互的消息里使用的SUPI。  |
| 上报给CHF的SUPI  | 该参数用于指定与CHF交互的消息里使用的SUPI。  |
| 上报给PCRF的SUPI | 该参数用于指定与PCRF交互的消息里使用的SUPI。 |
| 上报给PCF的SUPI  | 该参数用于指定与PCF交互的消息里使用的SUPI。  |
