# 查询TMAP本地实体(LST TMAPLE)

- 命令功能

- 本地用户权限

#### 命令功能

**适用网元：MME**

该命令用于查询配置的TMAP本端实体信息。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                       |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------|
| TMINTFTP | Tm接口类型 | 可选必选说明：必选参数 参数含义：集群业务Tm接口类型。 数据来源：全网规划 取值范围：“Tm1(用户会话接口)” 默认值 ：无 配置原则：Tm1接口需要配置不同的IP地址，作为本端服务IP地址，否则将配置失败。 |

#### 使用实例

查询TMAP本地实体Tm1接口记录：

LST TMAPLE:TMINTFTP=Tm1;

```
%%LST TMAPLE:TMINTFTP=Tm1;%%

```
