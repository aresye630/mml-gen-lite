#### 命令功能

**须知** 

该命令为高危命令，该操作会从服务器下载软件包到系统中，占用一定的系统资源。请谨慎使用或联系华为技术支持协助操作。

该命令用于下载升级软件包。版本升级一般先后执行下载，加载和激活命令。

#### 注意事项

- 该命令执行后立即生效。
- VNFP支持VNF级和VNFC级下载路径，VNFC支持VNFC级下载路径。
- 如果是VNF级路径，命令执行后通过**DSP SOFTWARE**查询是否下载成功。如果是VNFC级路径，命令执行后通过**DSP PACKAGE**查询是否下载成功。
- 如果软件仓中存在与目标下载的软件包同版本号，同VNFC类型的软件包，执行**LOD PACKAGE**命令，加载的是软件仓中的软件包。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识         | 参数名称      | 参数说明                                                                                                                                                                     |
|:-------------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPVERSION    | 服务器IP版本   | 可选必选说明：可选参数 参数含义：该参数用于指定服务器地址族。 数据来源：对端协商 取值范围：枚举类型。 IPv4：IPv4地址。IPv6：IPv6地址。 默认值：IPv4                                                                                   |
| SERVERIP     | 服务器IPv4地址 | 可选必选说明：条件必选参数，该参数在“IPVERSION”配置为“IPv4”时为必选参数。 参数含义：该参数用于指定服务器端的IP地址。 数据来源：对端协商 取值范围：IPv4地址类型。 默认值：无                                                                      |
| SERVERPORT   | 服务器端口号    | 可选必选说明：必选参数 参数含义：该参数用于指定服务器端的服务端口。 数据来源：对端协商 取值范围：整数类型，取值范围为1～65535。 默认值：无                                                                                               |
| USERNAME     | 服务器用户名    | 可选必选说明：必选参数 参数含义：该参数用于指定服务器端的用户名。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～63。 默认值：无                                                                                                |
| PASSWORD     | 服务器密码     | 可选必选说明：必选参数 参数含义：该参数用于指定服务器端的密码。 数据来源：对端协商 取值范围：密码类型，输入长度范围为1～127。 默认值：无                                                                                                 |
| UPDOBJECT    | 升级对象      | 可选必选说明：必选参数 参数含义：该参数用于指定升级对象。 数据来源：对端协商 取值范围：枚举类型。 BaseSoftware：只升级基础版本。Patch：只升级补丁。All：升级基础版本和补丁。 默认值：无                                                                 |
| BASICPKGDIR  | 基础软件包路径   | 可选必选说明：条件必选参数，该参数在“UPDOBJECT”配置为“BaseSoftware” 或 “All”时为必选参数。 参数含义：该参数用于指定服务器端基础软件包存放路径，VNFP支持VNF级路径和VNFC级路径两种模式，VNFC支持VNFC级路径。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～255。 默认值：无 |
| PATCHDIR     | 补丁路径      | 可选必选说明：条件必选参数，该参数在“UPDOBJECT”配置为“Patch” 或 “All”时为必选参数。 参数含义：该参数用于指定服务器端补丁包存放路径，VNFP支持VNF级路径和VNFC级路径两种模式，VNFC支持VNFC级路径。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～255。 默认值：无          |
| TRANSFERPRTL | 传输协议      | 可选必选说明：可选参数 参数含义：该参数用于指定下载软件包使用的传输协议。 数据来源：对端协商 取值范围：枚举类型。 SFTP：使用SFTP协议下载文件。 默认值：SFTP                                                                                   |
| SERVERIPV6   | 服务器IPv6地址 | 可选必选说明：条件必选参数，该参数在“IPVERSION”配置为“IPv6”时为必选参数。 参数含义：该参数用于指定服务器IPv6地址，服务器需要提前放置新的软件包。 数据来源：对端协商 取值范围：IPv6地址类型。 默认值：无                                                       |

#### 使用实例

下载升级软件包：

```
DLD PACKAGE: SERVERIP="192.168.0.15",SERVERPORT=22,USERNAME="HUAWEI-123",PASSWORD="*****",UPDOBJECT=Patch,PATCHDIR="/home/patch",TRANSFERPRTL=SFTP;
```
