# 删除省份性能统计对象（RMV PERFPROVINCE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除省份性能统计对象的配置。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                      |
|:---------|:-------|:------------------------------------------------------------------------------------------|
| PROVINCE | 省份     | 可选必选说明：必选参数  参数含义：该参数用于标识基于省份性能统计对象名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。  默认值：无  配置原则：无 |

## 使用实例

将名称为“BEIJING”的性能统计对象删除，执行如下命令：

```
RMV PERFPROVINCE: PROVINCE="BEIJING";
```
