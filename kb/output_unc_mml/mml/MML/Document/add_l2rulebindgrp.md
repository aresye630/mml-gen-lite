# 增加层二规则与层二规则组的绑定关系（ADD L2RULEBINDGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于增加层二规则与层二规则组的绑定关系。

## 注意事项

- 该命令执行后只对新接入的会话生效。

- 同一个层二规则组下最多可绑定16个层二规则。

- 最多可输入10000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称    | 参数说明                                                                                                                          |
|:----------------|:--------|:------------------------------------------------------------------------------------------------------------------------------|
| L2RULEGROUPNAME | 层二规则组名称 | 可选必选说明：必选参数  参数含义：该参数用于指定层二规则组名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。不支持空格，不区分大小写。  默认值：无  配置原则：  该参数使用ADD L2RULEGROUP命令配置生成。 |
| L2RULENAME      | 层二规则名称  | 可选必选说明：必选参数  参数含义：该参数用于指定层二规则名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。不支持空格，不区分大小写。  默认值：无  配置原则：  该参数使用ADD L2RULE命令配置生成。       |

## 使用实例

如果运营商需要将层二规则“rule1”与层二规则组"rulegrp1"绑定：

```
ADD L2RULEBINDGRP: L2RULEGROUPNAME="rulegrp1", L2RULENAME="rule1";
```
