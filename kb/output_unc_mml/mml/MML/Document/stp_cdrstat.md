# 停止话单统计（STP CDRSTAT）

#### 命令功能

**适用NF：NCG**

该命令用于停止话单统计任务。

#### 注意事项

- 该命令仅能用于停止DSP CDRSTAT命令下发的话单统计任务。
- 执行停止操作后，会删除话单统计任务生成的结果文件，在执行停止操作之前，需确保结果文件已取走。

#### 本地用户权限

manage-ug；

#### 网管用户权限

G\_1，管理员级别命令组；

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                          |
|:----------|:---------|:--------------------------------------------------------------------------------------------------------------|
| CDRSTATID | 话单统计任务标识 | 可选必选说明：必选参数 参数含义：话单统计任务标识，全局唯一。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则： 该参数不能包含“\”。不能输入的特殊字符请参考“特殊字符表”。 |

#### 使用实例

停止标识为"cdrstat1"的话单统计任务，配置如下：

```
STP CDRSTAT: CDRSTATID="cdrstat1";
```
