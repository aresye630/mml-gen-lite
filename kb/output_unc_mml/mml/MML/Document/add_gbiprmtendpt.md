#### 命令功能

**适用网元：SGSN**

该命令用于增加一个Gb接口对端端点。对端端点权重表用来配置对端IP端点的数据权重和信令权重，在IP网络NSVC链路负荷分担时根据数据权重或者信令权重来选择对端IP端点。

#### 注意事项

- 本命令执行立即生效。
- 本表可以动态设定。
- 本表最大记录数为8192。
- 配置对端端点时，NSE必须已经配置。
- SGSN仅支持一个NSE下配置512个IPv4类型的对端端点。
- SGSN仅支持一个NSE下配置512个IPv6类型的对端端点。
- 配置对端端点的时候需要考虑当前IPNsvc链路的数目。SGSN支持每个进程上1024条IPNsvc链路，整系统16384条IPNsvc链路。
- 目前暂不支持IPv6。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                                               |
|:-------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPT    | IP地址类型   | 可选必选说明：必选参数 参数含义：该参数用于指定IP地址类型。 数据来源：整网规划 取值范围：“IPV4(IPv4)”“IPV6(IPv6)” 默认值：无                                                                                      |
| RIPV4  | 对端IPv4地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定对端PCU使用的IPv4地址。 前提条件：该参数在“IP地址类型”设置为“IPV4(IPv4)”时才生效。 数据来源：整网规划 取值范围：0.0.0.0~255.255.255.255 默认值：无 配置原则：IPv4地址不能为0.0.0.0，255.255.255.255 |
| RIPV6  | 对端IPv6地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定对端PCU使用的IPv6地址。 前提条件：该参数在“IP地址类型”设置为“IPV6(IPv6)”时才生效。 数据来源：整网规划 取值范围： ::~FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无                   |
| RUP    | 对端UDP端口号 | 可选必选说明：必选参数 参数含义：该参数用于指定对端PCU使用的UDP端口号。 数据来源：整网规划 取值范围：0~65535 默认值：无                                                                                               |
| NSEI   | NSE标识    | 可选必选说明：必选参数 参数含义：该参数用于指定端点所在的网络服务实体标识。 数据来源：整网规划 取值范围：0~65535 默认值：无                                                                                                |
| DW     | 数据权重     | 可选必选说明：可选参数 参数含义：该参数用于指定该对端端点的数据权重。数据权重越大，NS发送数据消息时根据IP网络NSVC链路负荷分担功能选择该对端IP端点的概率就越大。 数据来源：整网规划 取值范围：0~255 默认值：255                                                 |
| SW     | 信令权重     | 可选必选说明：可选参数 参数含义：该参数用于指定该对端端点的信令权重。信令权重越大，NS发送信令消息时根据IP网络NSVC链路负荷分担功能选择该对端IP端点的概率就越大。 数据来源：整网规划 取值范围：0~255 默认值：255                                                 |
| DESC   | 描述       | 可选必选说明：可选参数 参数含义：该参数用于指定对端端点名称。 数据来源：整网规划 取值范围：长度不超过32的字符串 默认值：无                                                                                                   |

#### 使用实例

增加一个对端端点记录，对端IPv4地址为"172.22.44.66"，UDP端口为4000，对应BSC1：

ADD GBIPRMTENDPT: IPT=IPV4, RIPV4="172.22.44.66", RUP=4000, NSEI=200, DW=50, SW=100, DESC="FOR BSC1";
