# 增加自动部署RU黑名单（ADD AUTOSCALINGRUBLACKLIST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于向自动化配置RU黑名单中添加成员，所有自动化配置将不会在黑名单列表里的RU上生成。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为16。
- 该命令在自动化配置开关为关闭的状态下才能执行，请先使用SET AUTOCONFIG命令关闭自动配置开关。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                   |
|:-------|:-------|:-----------------------------------------------------------------------|
| RUID   | RU ID  | 可选必选说明：必选参数 参数含义：该参数用于指定RU ID。 数据来源：本端规划 取值范围：整数类型，取值范围为64～9999。 默认值：无 |

#### 使用实例

将ID为66的RU添加到黑名单列表中：

```
ADD AUTOSCALINGRUBLACKLIST: RUID=66;
```
