# 查询OS增强认证状态 (DSP OSENHANCEDAUTH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询OS增强认证状态。

## 注意事项

无

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                  |
|:-------|:-------|:------------------------------------------------------------------------------------------------------|
| NODEIP | 节点IP   | 可选必选说明：必选参数。 参数含义：查询OS增强认证状态的节点IP。 取值范围：不超过128位的字符串。 默认值：无。 配置原则：按照DSP NODE命令查询的所有节点信息，选择确实存在的节点进行设置。 |

## 使用实例

当“节点IP”为“10.0.0.0”且节点OS增强认证状态为关闭时：

```
%%DSP OSENHANCEDAUTH: NODEIP="10.0.0.0";%%
RETCODE = 0  操作成功

操作结果如下
------------
  节点IP  =  10.0.0.0
    状态  =  关闭
文件名称  =  NULL
(结果个数 = 1)

---    END
```

当“节点IP”为“10.0.0.0”且节点OS增强认证状态为开启时：

```
%%DSP OSENHANCEDAUTH: NODEIP="10.0.0.0";%%
RETCODE = 0  操作成功

操作结果如下
------------
  节点IP  =  10.0.0.0
    状态  =  开启
文件名称  =  csp-arm-ipv4-os06-csp-c-arm-ex-0_20250507053259763073570_10.0.0.0.zip
(结果个数 = 1)

---    END
```
