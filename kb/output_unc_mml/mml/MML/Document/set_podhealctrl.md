# 设置自愈功能开关状态（SET PODHEALCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置是否启动pod自愈，若开关打开，则按照**SET PODHEALPLY**命令配置的pod自愈策略进行自愈；若开关关闭，则不进行pod自愈。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| SWITCH   |
|:---------|
| ENABLE   |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                         |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------|
| SWITCH | 自愈开关   | 可选必选说明：必选参数  参数含义：该参数用于表示自愈开关。  数据来源：本端规划 取值范围： “ENABLE（打开）”：自愈使能“DISABLE（不使能）”：自愈不使能  默认值：无。  配置原则：  升级时建议关闭，升级结束运行正常后建议开启。 |

## 使用实例

关闭自愈功能开关。

```
SET PODHEALCTRL: SWITCH=DISABLE;
```
