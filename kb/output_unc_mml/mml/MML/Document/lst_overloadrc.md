#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

此命令用来查询各个接口配置的过载返回码列表。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询当前各个接口配置的过载返回码列表：

```
LST OVERLOADRC:;
```

