# 设置话统测量单元模型(SET MEASMU)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于设置话统测量单元模型参数。

**须知** 

该命令为高危命令，执行将修改话统测量单元的参数，影响该话统指标的上报，请慎重执行。

## 注意事项

该命令通过修改测量单元是否默认测量属性，可从网管侧关闭默认测量任务。升级、回退、补丁、补丁回退场景下会自动同步任务，任务最终状态由默认测量属性和网管侧任务状态共同决定。

## 参数说明

| 参数标识               | 参数名称   | 参数说明                                                                                                          |
|:-------------------|:-------|:--------------------------------------------------------------------------------------------------------------|
| MEID               | 网元ID   | 可选必选说明：必选参数。 参数含义：标识网元ID。 取值范围：0~65535。 默认值：无。 配置原则：可以通过LST ME命令查询获取。                                         |
| MUID               | 测量单元ID | 可选必选说明：必选参数。 参数含义：测量单元ID。 取值范围：整数类型，取值范围为0~4294967294。 默认值：无。 配置原则：可以通过LST MEASMU命令查询获取。                      |
| TYPE               | 类型     | 可选必选说明：必选参数。 参数含义：支持变更的参数。 取值范围：枚举项 SWITCH_CREDIBLE(开关可信)DEF_MEAS(默认测量) 默认值：无。 配置原则：无。                        |
| SW_CREDIBLE_ENABLE | 支持开关可信 | 可选必选说明：当“类型”选择“SWITCH_CREDIBLE(开关可信)”时，为必选参数。 参数含义：是否支持开关可信。 取值范围：枚举 DEFAULT(默认配置) YES(是)NO(否) 默认值：无。 配置原则：无。 |
| DEFMEAS            | 默认测量   | 可选必选说明：当“类型”选择“DEF_MEAS(默认测量)”时，为必选参数。 参数含义：任务是否默认测量。 取值范围：枚举 DEFAULT(默认配置) YES(是)NO(否) 默认值：无。 配置原则：无。        |

## 使用实例

设置话统测量单元可信开关：

```
%%SET MEASMU: MEID=12, MUID=1929379844, TYPE=SWITCH_CREDIBLE, SW_CREDIBLE_ENABLE=YES;
%% RETCODE = 0  操作成功
 
---    END
```
