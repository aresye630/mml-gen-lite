# 查询日志流控开关（LST CSLOGFC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此命令用于查询日志流控开关。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询日志留空开关：

```
%%LST CSLOGFC:;%%
RETCODE = 0  操作成功

结果如下
--------
流控开关  =  打开
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释          |
|:--------|:---------------|
| 流控开关    | 该参数用于表示日志流控开关。 |
