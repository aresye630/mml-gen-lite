# 删除LinkModule表记录（RMV LINKMODULE）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

该命令为高危命令，执行不当会导致链路丢失。

**适用NF：NCG**

该命令用于删除LinkModule表中的残留记录。

#### 注意事项

- 该命令执行后立即生效。
- 该命令用于删除**DSP ACTRL**命令查询结果和ALM-82008 GSN对vCG无响应告警之外的残留记录 。
- 如果删除记录为有效记录，5分钟之后会自动恢复有效记录。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                        |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPTYPE | IP地址类型 | 可选必选说明：必选参数 参数含义：该参数用于表示LinkModule表的IP类型。 数据来源：本端规划 取值范围：枚举类型。 IPV4：IPv4。IPV6：IPv6。 默认值：无 配置原则：无。                                                                                                                           |
| IPV4   | IPv4地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPTYPE”配置为“IPV4”时为条件必选参数。 参数含义：该参数用于表示LinkModule表的IPv4地址。可以通过OPR DBGCMDPRXY调测命令“vcg show linkmodule”查询要删除的IPv4地址。 数据来源：本端规划 取值范围：IPv4地址类型。0.0.0.0-255.255.255.255。 默认值：无 配置原则：无。                    |
| IPV6   | IPv6地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPTYPE”配置为“IPV6”时为条件必选参数。 参数含义：该参数用于表示LinkModule表的IPv6地址。 可以通过OPR DBGCMDPRXY调测命令“vcg show linkmodule”查询要删除的IPv6地址。数据来源：本端规划 取值范围：IPv6地址类型。::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。 默认值：无 配置原则：无。 |

#### 使用实例

删除LinkModule表中指定IP的记录：

```
RMV LINKMODULE: IPTYPE=IPV4, IPV4="10.31.14.3";
```
