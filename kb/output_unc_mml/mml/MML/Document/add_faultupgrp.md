# 增加N3接口故障UPF组（ADD FAULTUPGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、SMF**

该命令用于添加N3接口故障UPF组，当N3接口出现故障，如果该故障UPF组与故障RAN组绑定，SMF在为通过RAN组内的RAN接入的用户选择UPF时，会自动过滤掉该UPF组内的UPF。

## 注意事项

- 该命令执行后只对新激活用户生效。

- 最多可输入1024条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                              |
|:-----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
| UPFGRPNAME | UPF组名  | 可选必选说明：必选参数  参数含义：该参数用于指定UPF组名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。不支持空格及特殊字符“#”、“$”和“&”等，由“-”、“_”、数字、字母和“.”组成，不能以“.”开头或结尾，不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

增加一个N3接口故障UPF组:

```
ADD FAULTUPGRP: UPFGRPNAME="group1";
```
