# 增加IMSI对应的Diameter兼容性(ADD DMCMPTBYIMSI)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于设置Diameter兼容性参数，用于保证网元间支持信元的兼容性。

该命令支持针对外网用户、本网用户、IMSI号段来配置兼容性参数。

#### 注意事项

- 该命令最大记录数为8192。
- 该命令执行后立即生效。
- 该命令与**SET DMCMPT**命令均可对Diameter兼容性参数进行配置。系统会首先匹配本命令的配置记录，若发现系统中不存在或不匹配本命令的配置记录才会匹配**SET DMCMPT**命令的配置记录。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

- 对IMSI前缀为12303的用户配置为支持携带UE SRVCC Capability信元，支持P-CSCF故障时的语音恢复功能，“P-GW ID类型”为“FQDN(MIP-Home-Agent-Host)”，“切换后P-GW ID更新策略”为“NOUPDATE(不更新)”，“NOR消息更新参数”为“IMS\_VOPS(IMS VoPS参数)”，“S6a/S6d-Indicator”为“COMBINED(融合SGSN/MME支持)”，“Homogeneous Support of IMS VoPS信元”为“BY\_SYS\_CAP(按照设备能力携带)”，“T-ADS查询结果与IMS PDN连接状态相关”为“NO(否)”时，运行以下命令：

  ADD DMCMPTBYIMSI: SUBRANGE=IMSI\_PREFIX, IMSIPRE="12303", UESRVCC=SUPPORT, SF2=FLSTID2\_BIT16-1, PGWIDTYPE=FQDN, UPDATEPGWID=NOUPDATE, NORPARA=IMS\_VOPS-1, S6AS6DIND=COMBINED, HSIMSVOPS=BY\_SYS\_CAP, TADSIMSPDN=NO;
