# 复位S1AP连接(RST S1APLNK)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

此命令用于复位S1AP连接。

#### 注意事项

- 此命令执行后立即生效。
- 执行此命令会导致S1AP链路连接中断，该eNodeB下所有的业务中断，请慎重使用。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                                       |
|:-----------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RESETTYPE  | 复位类型     | 可选必选说明:可选参数 参数含义：待复位的S1AP连接的类型。 取值范围：“ALL”：复位该eNodeB下的所有用户的S1AP连接信息。“PART”：随机选择该eNodeB下一部分用户的S1AP连接信息，进行复位。 默认值：“ALL” 说明： 用户的S1AP连接指的是每个用户在附着、路由更新等流程中建立的S1逻辑连接，当连接释放时，此用户状态就切换到EMM_IDLE态。 |
| MCC        | 移动国家码    | 可选必选说明：必选参数 参数含义：待复位的S1AP连接的eNodeB的移动国家码。 取值范围：3位十进制数 默认值：无  说明： 在“MML命令行-UNC”窗口上执行命令DSP S1APLNK查看当前系统里面已经存在的S1AP连接信息。                                                                     |
| MNC        | 移动网号     | 可选必选说明：必选参数 参数含义：待复位的S1AP连接的eNodeB的移动网号。 取值范围：位数为2或3的十进制数字 默认值：无  说明： 在“MML命令行-UNC”窗口上执行命令DSP S1APLNK查看当前系统里面已经存在的S1AP连接信息。                                                                |
| ENODEBTYPE | eNodeB类型 | 可选必选说明：必选参数 参数含义：待复位的S1AP连接的eNodeB的类型。 取值范围：“HOME_ENB(HOME_ENB)”“MACRO_ENB(MACRO_ENB)” 默认值：无  说明： 在“MML命令行-UNC”窗口上执行命令DSP S1APLNK查看当前系统里面已经存在的S1AP连接信息。                                    |
| ENODEBID   | eNodeB标识 | 可选必选说明：必选参数 参数含义：待复位的S1AP连接的eNodeB的标识。 取值范围：0～268435455 默认值：无  说明： 在“MML命令行-UNC”窗口上执行命令DSP S1APLNK查看当前系统里面已经存在的S1AP连接信息。                                                                   |

#### 使用实例

复位移动国家码为308，移动网号为07，id为2的home eNodeB的偶联上的部分用户的s1连接：

RST S1APLNK: RESETTYPE=PART, MCC="308", MNC="07", ENODEBTYPE=HOME\_ENB, ENODEBID=2;
