#### 命令功能

**适用网元：SGSN**

该命令用于查询NS层系统参数。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询NS参数：

LST NS:;

```
%%LST NS:;%%
RETCODE = 0  操作成功。

操作结果如下
--------------
                   Block定时器(s)   =  120
                    Block重试次数   =  3
                  Unblock重试次数   =  3
                    复位定时器(s)   =  10
                     复位重试次数   =  3
                    测试定时器(s)   =  30
                   Alive定时器(s)   =  3
                     Alive重试次数  =  10
                       Prov定时器   =  5
                     Prov重试次数   =  3
    自动配置的NSE的上报速率(个/秒)  =  5
自动配置的NSE的故障删除时长（分钟） =  0
            自动配置的NSE的分布策略 =  整系统分布

(结果个数 = 1)
---    END
```
