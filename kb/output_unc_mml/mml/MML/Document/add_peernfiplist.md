# 增加对端局向连接列表（ADD PEERNFIPLIST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、SMSF**

本命令用于增加对端局向连接列表，本命令用于与北向网管连接以及对应性能统计相关的功能。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入1000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称      | 参数说明                                                                            |
|:-------------|:----------|:--------------------------------------------------------------------------------|
| NFINSTANCEID | 对端局向NF实例号 | 可选必选说明：必选参数  参数含义：对端局向NF实例号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~40。  默认值：无  配置原则：无 |
| LOCALIP      | 本端IP地址    | 可选必选说明：必选参数  参数含义：本端IP地址。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~63。  默认值：无  配置原则：无    |
| PEERIP       | 对端IP地址    | 可选必选说明：必选参数  参数含义：对端IP地址。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~63。  默认值：无  配置原则：无    |
| MASK         | 掩码        | 可选必选说明：可选参数  参数含义：掩码。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~63。  默认值：无  配置原则：无        |

## 使用实例

若运营商想增加一条对端局向连接记录，可用如下命令：

```
ADD PEERNFIPLIST: NFINSTANCEID="bf33a517-7789-4637-b675-b3591b0d706b", LOCALIP="10.20.3.4", PEERIP="10.20.3.5";
```
