# 增加GGSN与Gn/Gp接口或PGW-U与S5/S8接口的绑定关系（ADD UPBINDGNGP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：GGSN、PGW-C**

该命令用于增加GGSN与Gn/Gp接口或PGW-U与S5/S8接口的绑定关系。

该命令必须配置符合实际组网的GGSN与Gn/Gp接口或PGW-U与S5/S8接口的绑定关系，否则GW-U故障隔离功能不可用。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入2048条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称               | 参数说明                                                                                                                                                                                                                                                                            |
|:---------------|:-------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCENAME | GGSN或PGW-U实例名称     | 可选必选说明：必选参数  参数含义：该参数标识GGSN或PGW-U实例名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~36。不区分大小写。  默认值：无  配置原则：  该参数需要在ADD PNFPROFILE中事先配置，可执行LST PNFPROFILE进行查看。注意查询结果是NF类型为UPF的“NF实例标识”。                                                                                                      |
| GNGPIPTYPE     | Gn/Gp或S5/S8口地址类型   | 可选必选说明：必选参数  参数含义：该参数标识Gn/Gp或S5/S8口IP类型。  数据来源：本端规划 取值范围： IPv4（IPv4类型地址）IPv6（IPv6类型地址）ALL（通配类型）  默认值：无  配置原则：  配置为ALL时，表示该NFINSTANCE支持所有的Gn/Gp或S5/S8口IP地址。                                                                                                                      |
| GNGPIPV4       | Gn/Gp或S5/S8口IPv4地址 | 可选必选说明：该参数在"GNGPIPTYPE"配置为"IPv4"时为条件必选参数。  参数含义：该参数标识Gn/Gp或S5/S8口IPv4地址。  数据来源：本端规划  取值范围：IPv4地址类型。  默认值：无  配置原则：  Gn/Gp或S5/S8口IPv4地址不能为“0.0.0.0”、“255.255.255.255”和“0.x.y.z”。  Gn/Gp或S5/S8口IPv4地址不能为组播地址(“224.x.y.z”)和环回地址(“127.x.y.z”)；Gn/Gp或S5/S8口IPv4地址必须是A、B或者C类地址。        |
| GNGPIPV6       | Gn/Gp或S5/S8口IPv6地址 | 可选必选说明：该参数在"GNGPIPTYPE"配置为"IPv6"时为条件必选参数。  参数含义：该参数标识Gn/Gp或S5/S8口IPv6地址。  数据来源：本端规划  取值范围：IPv6地址类型。:: ~ FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。  默认值：无  配置原则：  必须是全球单播地址。  不能为“::”、“FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF”、环回地址(“::1”)、链路本地地址(“FE80::/10”)和组播地址(“FF00::/8”)。 |
| PRIORITY       | Gn/Gp或S5/S8口优先级    | 可选必选说明：可选参数  参数含义：该参数标识Gn/Gp或S5/S8口优先级，该值越小，优先级越高。  数据来源：本端规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无                                                                                                                                                                             |

## 使用实例

新增GGSN与Gn/Gp口的绑定关系，其中GGSN唯一标识为"UPF1"，Gn/Gp口地址类型为IPv4，IPv4地址为“192.168.1.2”。

```
ADD UPBINDGNGP: NFINSTANCENAME="UPF1",GNGPIPTYPE=IPv4,GNGPIPV4="192.168.1.2";
```
