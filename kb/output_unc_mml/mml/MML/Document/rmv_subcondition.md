# 删除NF订阅条件（RMV SUBCONDITION）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、NRF、NSSF、SMSF、NCG、CBC、CBCF**

该命令用于删除订阅的目标NF类型的订阅条件等信息。

## 注意事项

- 该命令执行后立即生效。

- 该命令只删除订阅条件，对于已经生成的订阅无法生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

删除目标NF类型为NfAMF的订阅条件信息。

```
RMV SUBCONDITION: NFTYPE=NfAMF;
```
