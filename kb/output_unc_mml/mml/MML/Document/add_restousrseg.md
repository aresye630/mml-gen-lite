# 增加容灾用户号段参数 (ADD RESTOUSRSEG)

- 命令功能

- 本地用户权限

#### 命令功能

**适用网元：MME**

此命令用于增加容灾用户号段参数配置。当“WSFD-201201 MME链式备份”功能仅对指定用户范围内的用户生效，即设置容灾功能(SET RESTOFUNC)的“号段匹配（RESTOSEG）”参数设置为“YES”时，通过此命令增加功能生效的用户范围。

#### 注意事项

- 此命令的最大记录数为3000。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                     |
|:---------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：必选参数 参数含义：该参数用于指定链式备份功能服务的用户范围。 取值范围： IMSI_PREFIX(指定IMSI前缀) 默认值：无 配置原则：无                                                                                                                          |
| IMSIPRE  | IMSI前缀 | 必选说明：条件必选参数 参数含义：该参数用于指定链式备份功能服务的用户范围的IMSI前缀。 前提条件：该参数在“用户范围”参数配置为“IMSI_PREFIX(指定IMSI前缀)”后生效。 数据来源：全网规划 取值范围：5～15位十进制数字字符串。 默认值：无 配置原则：无  说明： IMSI前缀的匹配方式采取由前向后的最长匹配，即若对于用户可以匹配到多个用户群，则使用IMSI前缀最长的用户群配置。 |
| ISRESTO  | 是否备份用户 | 可选必选说明：可选参数 参数含义：该参数用于指定是否备份指定用户号段的用户信息。 取值范围： YES (是)NO (否) 默认值：YES (是) 配置原则：无                                                                                                                          |

#### 使用实例

1. 当“WSFD-201201 MME链式备份”功能仅对指定用户范围内的用户生效时，执行如下命令增加功能生效的用户范围：

   ```
   ADD RESTOUSRSEG: SUBRANGE=IMSI_PREFIX, IMSIPRE="12345", ISRESTO=NO;
   ```
