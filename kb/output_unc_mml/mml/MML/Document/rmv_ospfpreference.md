# 删除OSPF协议路由的优先级配置（RMV OSPFPREFERENCE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于恢复OSPF协议路由的优先级默认配置。

#### 注意事项

- 该命令执行后立即生效。
- 当前OSPF路由优先级的两种路由类型ASE和default不支持删除操作。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                           |
|:----------|:-------|:---------------------------------------------------------------------------------------------------------------|
| PROCID    | 进程号    | 可选必选说明：必选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 配置原则：OSPF进程必须已经存在。                      |
| TOPOID    | 拓扑标识   | 可选必选说明：可选参数 参数含义：拓扑标识。 数据来源：全网规划 取值范围：整数类型，取值范围为0。 默认值：无 配置原则：目前只支持默认拓扑0。                                      |
| ROUTETYPE | 路由类型   | 可选必选说明：必选参数 参数含义：路由类型。 数据来源：本端规划 取值范围：枚举类型。 default：区域内和区域间路由。ase：AS-External路由。intra：区域内路由。inter：区域间路由。 默认值：无 |

#### 使用实例

恢复OSPF进程1的区域内路由的默认优先级：

```
RMV OSPFPREFERENCE:PROCID=1,TOPOID=0,ROUTETYPE=intra;
```
