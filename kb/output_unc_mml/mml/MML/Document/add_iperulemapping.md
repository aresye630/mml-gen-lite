# 增加智能规则和智能业务编码组的绑定关系（ADD IPERULEMAPPING）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于增加智能规则和智能业务编码组的绑定关系。

## 注意事项

- 该命令执行后立即生效。

- 此配置受ADD RULE规格影响，当前版本实际支持最大记录数为100。

- 最多可输入1000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                                                                                                         |
|:-----------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RULENAME   | 智能规则名称  | 可选必选说明：必选参数  参数含义：该参数用于设置规则名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。不支持空格，不区分大小写。  默认值：无  配置原则：  该参数的取值来源于已经配置的ADD RULE命令的“RULENAME”参数，且该命令的“NWDAFEVENTS”参数必须配置为“IPE_SERVICE”。 |
| SRVCODEGRP | 智能业务编码组 | 可选必选说明：必选参数  参数含义：该参数用于指定业务编码组的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。不支持空格，不区分大小写。  默认值：无  配置原则： 该参数使用ADD SRVCODEGRP命令配置生成。配置的SRVCODEGRP必须是系统已经存在的SrvCodeGrp对象名称。           |

## 使用实例

增加智能规则名称为“intelligent”，智能业务编码组为“codegrp”的配置：

```
ADD IPERULEMAPPING: RULENAME="intelligent", SRVCODEGRP="codegrp";
```
