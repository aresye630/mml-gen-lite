# 设置校验和开关（SET CHKSUM）

- 本地用户权限

#### 命令功能

**适用NF：NCG**

该命令用于设置UDP校验和校验开关，当需要开启或者关闭接收、发送UDP报文的校验和开关，可以使用这个命令。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令的默认记录为打开UDP校验和校验开关。
- 该命令存在系统初始设置记录，参数的初始设置值如下表：

| NETPURPOSE   | RCVUDPCHKSW   | SENDUDPCHKSW   |
|:-------------|:--------------|:---------------|
| Ga           | ON            | ON             |

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称         | 参数说明                                                                                                                   |
|:-------------|:-------------|:-----------------------------------------------------------------------------------------------------------------------|
| NETPURPOSE   | 网络用途         | 可选必选说明：必选参数 参数含义：网络资源用途。 数据来源：本端规划 取值范围：枚举类型。 Ga：Ga。 默认值：无 配置原则：无                                                      |
| RCVUDPCHKSW  | 接收UDP校验和校验开关 | 可选必选说明：条件可选参数 前提条件：该参数在“NETPURPOSE”配置为“Ga”时为条件可选参数。 参数含义：接收UDP校验和校验开关。 数据来源：本端规划 取值范围：枚举类型。 OFF：关闭。ON：开启。 默认值：无 配置原则：无 |
| SENDUDPCHKSW | 发送UDP校验和校验开关 | 可选必选说明：条件可选参数 前提条件：该参数在“NETPURPOSE”配置为“Ga”时为条件可选参数。 参数含义：发送UDP校验和校验开关。 数据来源：本端规划 取值范围：枚举类型。 OFF：关闭。ON：开启。 默认值：无 配置原则：无 |

#### 使用实例

设置UDP校验和开关关闭：

```
SET CHKSUM: NETPURPOSE=Ga, RCVUDPCHKSW=OFF, SENDUDPCHKSW=OFF;
```
