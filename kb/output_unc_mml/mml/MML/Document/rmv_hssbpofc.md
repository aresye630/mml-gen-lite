# 删除故障状态HSS(RMV HSSBPOFC)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于删除故障状态HSS配置。

#### 注意事项

- 该命令执行后立即生效。
- 删除局向HSS Bypass配置时，用户在后续业务流程恢复与HSS的交互，请确保主备HSS局向同时删除。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                               |
|:---------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
| HOSTNAME | 对端主机名  | 可选必选说明：必选参数 参数含义：该参数用于指定进入故障状态的HSS主机名。 数据来源：全网规划 取值范围：字符串类型，输入长度范围是1~127 默认值：无 配置原则：该参数只能由字母（A-Z或者a-z）、数字（0-9）、连字符（-）和点（.）组成或者配置为通配符（*）。该参数不区分大小写。 |

#### 使用实例

删除对端主机名为"huawei"的故障状态HSS。

```
RMV HSSBPOFC: HOSTNAME="huawei";
```
