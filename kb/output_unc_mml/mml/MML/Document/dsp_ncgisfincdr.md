# 查询NCG是否有最终话单文件（DSP NCGISFINCDR）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：NCG**

该命令用于查询指定业务模块下各通道是否有最终话单文件。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                               |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------|
| MNAME  | 模块名称   | 可选必选说明：可选参数 参数含义：用于标识一个业务模块对象，全局唯一。该参数必须先由ADD MODULE命令定义，然后才能在此处索引。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～15。 默认值：无 配置原则：无 |

#### 使用实例

查询NCG是否有最终话单文件：

```
DSP NCGISFINCDR:;
```

```
RETCODE = 0  操作成功。
结果如下:
---------
模块名  通道名称  是否有最终话单    
AP64_1  sgwcdr     否               
AP64_1  pgwcdr     否               
AP64_1  ABNORMAL1  是    
(结果个数 = 3)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                |
|:--------|:---------------------|
| 模块名     | 用于返回当前通道所属业务模块的名称。   |
| 通道名称    | 用于返回当前最终话单文件所在的通道名称。 |
| 是否有最终话单 | 用于返回当前通道名下是否有最终话单文件。 |
