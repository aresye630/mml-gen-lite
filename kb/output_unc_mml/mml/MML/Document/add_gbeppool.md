# 增加IP地址到地址池(ADD GBEPPOOL)

#### 命令功能

**适用网元：SGSN**

此命令用于增加IP地址到Gb地址池，作为自动配置功能的Gb业务IP使用，地址池整系统唯一。

此地址池中的IP地址既可以作为NSE动态流程协商的地址，也可以作为NSE的本端端点进行业务传输。

此命令只适用于Gb over IP自动配置的场景。

#### 注意事项

- 此命令执行后立即生效。
- 此命令最大记录数为16。
- 如果要使用自动配置功能，至少配置端点池中一个IP地址。
- 如果新添加的IP地址是Gb本端端点的IP地址，且Gb本端端点的端口与**SET GBLOCPORTRGE**的预置端口相同，则添加失败。
- IP地址和vpn名称必须在SERVICEIP表中已经配置，可以用**LST SERVICEIP**查询。
- 一个Gb IP地址只能配置一条记录，且只能归属一个分组。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPTYPE  | IP类型   | 可选必选说明：必选参数 参数含义：该参数用于指定待添加的IP地址类型。 数据来源：整网规划 取值范围：“IPV4(IPv4)”“IPV6(IPv6)” 默认值：无                                                                                                                                                                                                   |
| IPV4    | IPv4地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定待添加到地址池中的IPv4地址。 前提条件：该参数在“ IP类型 ”设置为“IPV4(IPv4)”时生效。 数据来源：整网规划 取值范围：0.0.0.1～255.255.255.254 默认值：无 配置原则：有效的IPV4地址不能为环回地址(127.x.y.z)。有效的IPV4地址必须是A、B或者C类地址。                                                                                                |
| IPV6    | IPv6地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定待添加到地址池中的IPv6地址。 前提条件：该参数在“ IP类型 ”设置为“IPV6(IPv6)”时生效。 数据来源：整网规划 取值范围：::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 配置原则：IPV6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址(::1)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。  说明： 目前不支持IPV6地址的配置。 |
| DESC    | 描述信息   | 可选必选说明：可选参数 参数含义：该参数用于指定待添加到地址池中的IP地址描述信息。 数据来源：整网规划 取值范围：0～33位字符串 默认值：无                                                                                                                                                                                                            |
| VPNNAME | vpn名称  | 可选必选说明：可选参数 参数含义：VPN名称。 数据来源：全网规划 取值范围：0～31位字符串。 默认值：无                                                                                                                                                                                                                              |
| GROUPID | 组号     | 可选必选说明：可选参数 参数含义：本参数用于指定Gb IP地址的组号，用于不同的BSC设备需要使用不同网段的USN侧Gb IP地址场景。BSC侧将预置端点的IP地址配置为期望使用的USN侧对应分组下的任一Gb IP地址，USN将在此分组下分配SGSN侧的Gb本端IP端点给该BSC服务。 数据来源：本端规划 取值范围：0～15。 默认值：0                                                                                                          |

#### 使用实例

增加一个“IP类型”为“IPV4(IPv4)”，“IPv4地址”为“192.168.4.101”，“描述信息”为“DEFAULT”的IP到地址池：

ADD GBEPPOOL: IPTYPE=IPV4, IPV4="192.168.4.101", DESC="DEFAULT";
