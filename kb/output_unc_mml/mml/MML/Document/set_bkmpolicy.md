# 设置自动备份策略（SET BKMPOLICY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令为高危命令，设置自动备份策略参数，可能存在安全风险及影响SFTP服务器通信，具体参考参数说明，请谨慎执行。

该命令用于设置备份服务的自动备份策略。

## 注意事项

- 由于需要下载公钥， 这里不提供公钥校验开关的参数。
- 执行命令时没配置的可选参数，在自动备份策略中对应参数值保持不变。

## 参数说明

| 参数标识              | 参数名称             | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|:------------------|:-----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SCHEDULEFLAG      | 自动备份开关           | 可选必选说明：必选参数。 参数含义：是否开启自动备份功能。 取值范围： ON(开)：开启自动备份。OFF(关)：不自动备份。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| PERIOD            | 自动备份周期（天）        | 可选必选说明：该参数在“SCHEDULEFLAG(自动备份开关)”为“ON(开)”时，为条件可选参数。 参数含义：系统自动备份的间隔时间。 取值范围：整数类型，取值范围为1~7。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| STARTTIME         | 自动备份时间           | 可选必选说明：该参数在“SCHEDULEFLAG(自动备份开关)”为“ON(开)”时，为条件可选参数。 参数含义：系统开始自动备份的时间点。 取值范围：24小时制时间，格式HH:MM。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| VALIDPERIOD       | 本地备份包存留数（个）      | 可选必选说明：该参数在“SCHEDULEFLAG(自动备份开关)”为“ON(开)”时，为条件可选参数。 参数含义：系统本地存留的备份包数量。  说明： 默认在每次备份任务完成后会清除存留数之外的备份包。若此时存在异常无法清除，则在23:10清除存留数量之外的数据包。 取值范围：整数类型，取值范围为1~7。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| REMOTEFLAG        | 是否进行网络备份         | 可选必选说明：该参数在“SCHEDULEFLAG(自动备份开关)”为“ON(开)”时，为条件可选参数。 参数含义：可选择是否进行SFTP存储。 取值范围： ON(开)：进行网络备份，并展开SFTP服务器参数配置界面。OFF(关)：不进行网络备份。DEFAULT(默认)：使用原有的网络备份配置信息。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| COMPATIBLE        | 是否支持不安全算法        | 可选必选说明：该参数在“SCHEDULEFLAG(自动备份开关)”为“ON(开)”时，为条件可选参数。 参数含义：是否支持不安全算法。 支持的安全算法为：curve25519-sha256@libssh.org，curve25519-sha256，curve448-sha512，ecdh-sha2-nistp521，ecdh-sha2-nistp384，ecdh-sha2-nistp256，diffie-hellman-group18-sha512，diffie-hellman-group17-sha512，diffie-hellman-group16-sha512，diffie-hellman-group15-sha512。支持的不安全算法为：diffie-hellman-group-exchange-sha256，diffie-hellman-group14-sha256，diffie-hellman-group-exchange-sha1，diffie-hellman-group14-sha1，diffie-hellman-group1-sha1。 取值范围： ON(开)：支持不安全算法。OFF(关)：不支持不安全算法。 默认值：无。 配置原则：根据SFTP服务器支持的算法选择打开或关闭开关。  说明： 打开“是否支持不安全算法”开关，可能会存在安全风险。非必要情况下建议关闭此开关。 |
| CHECKNETWORKALARM | 网络备份能力检查开关       | 可选必选说明：该参数在“SCHEDULEFLAG(自动备份开关)”为“ON(开)”时，为条件可选参数。 参数含义：是否支持网络备份能力检查。 取值范围： ON(开)：支持网络备份能力检查。OFF(关)：不支持网络备份能力检查。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| REMOTEVALIDPERIOD | SFTP服务器备份包存留数（个） | 可选必选说明：该参数在“REMOTEFLAG(是否进行网络备份)”为“ON(开)”时，为条件可选参数。 参数含义：SFTP服务器上存留的备份包数量。 取值范围：整数类型，取值范围为-1和3~30，-1代表不控制SFTP服务器备份包存留数。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| SFTPIPTYPE        | SFTP服务器IP地址类型    | 可选必选说明：该参数在“REMOTEFLAG(是否进行网络备份)”为“ON(开)”时，为条件必选参数。 参数含义：SFTP服务器的IP地址的类型。 取值范围： IPV4(IPV4)：IPV4类型的SFTP服务器IP地址。IPV6(IPV6)：IPV6类型的SFTP服务器IP地址。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| IPV4              | SFTP服务器IP地址      | 可选必选说明：该参数在“SFTPIPTYPE(SFTP服务器IP地址类型)”为“IPV4(IPV4)”时，为条件必选参数。 参数含义：远端SFTP服务器的IPv4地址。 取值范围：点分十进制格式，即X.X.X.X，其中X为0~255的数，如10.119.147.178。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| IPV6              | SFTP服务器IP地址      | 可选必选说明：该参数在“SFTPIPTYPE(SFTP服务器IP地址类型)”为“IPV6(IPV6)”时，为条件必选参数。 参数含义：远端SFTP服务器的IPv6地址。 取值范围：冒号分割的16进制格式，即X:X:X:X:X:X:X:X或者为压缩的格式X::X，如果其中X出现连续为0的情况允许出现压缩格式，即将连续为0的两段或多段可以压缩成连续两个冒号，连续冒号只允许出现一次，其中X为0~FFFF的十六进制数，如fc00:0:0:0:0:0:0:7344或者fc00::7344。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                            |
| SFTPPORT          | SFTP服务器端口号       | 可选必选说明：该参数在“REMOTEFLAG(是否进行网络备份)”为“ON(开)”时，为条件必选参数。 参数含义：远端SFTP服务器的端口号。 取值范围：整数类型，取值范围为0~65535。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| USERNAME          | SFTP用户名          | 可选必选说明：该参数在“REMOTEFLAG(是否进行网络备份)”为“ON(开)”时，为条件必选参数。 参数含义：登录远端SFTP服务器的用户名。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| USERPSWD          | SFTP密码           | 可选必选说明：该参数在“REMOTEFLAG(是否进行网络备份)”为“ON(开)”时，为条件必选参数。 参数含义：登录远端SFTP服务器的密码。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| REMOTEPATH        | 目标目录             | 可选必选说明：该参数在“REMOTEFLAG(是否进行网络备份)”为“ON(开)”时，为条件必选参数。 参数含义：备份数据包保存在远端SFTP服务器的具体路径，填写的SFTP用户名需要有访问该路径的权限，否则网络备份设置失败。 取值范围：长度不超过256的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |

## 使用实例

1. 设置自动备份策略：

   ```
   %%SET BKMPOLICY: SCHEDULEFLAG=ON, PERIOD=1, STARTTIME=03&00, VALIDPERIOD=7, REMOTEFLAG=ON, COMPATIBLE=ON, CHECKNETWORKALARM=ON, REMOTEVALIDPERIOD=30, SFTPIPTYPE=IPV4, IPV4="10.0.0.0", SFTPPORT=22, USERNAME="user", USERPSWD="*****", REMOTEPATH="/home";%%
   RETCODE = 0  操作成功

   ---    END
   ```
