# 检查链路分配信息（CHK ACTRL）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：NCG**

用于查看CGF模块为对端分配AP的具体情况。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                             |
|:-------|:---------|:-------------------------------------------------------------------------------------------------|
| AGID   | 接入网元分组标识 | 可选必选说明：可选参数 参数含义：用于区分不同域的接入网元。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：不能输入的特殊字符请参考“特殊字符表”。 |

#### 使用实例

查询对端的AP分配情况，示例如下：

```
CHK ACTRL:; 
RETCODE = 0  操作成功。

结果如下:
--------
接入控制标识    协议类型    接入网元分组标识    Ga IP地址         Ga端口号        AP模块编号 

actrl           GTP'        PS2                 192.168.99.78       6009             651        
actrll          GTP'        PS1                 192.168.99.78       6001             641        
(结果个数 = 2)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                    |
|:--------|:-------------------------|
| 协议类型    | 用于返回使用的协议类型。             |
| Ga IP地址 | 用于返回对端网元与CGF模块通信采用的IP地址。 |
| Ga端口号   | 用于返回对端网元与CGF模块通信采用的端口号。  |
| AP模块编号  | 用于返回CGF给对端分配的AP模块编号。     |

其余输出项请参见**ADD ACTRL**的参数说明。
