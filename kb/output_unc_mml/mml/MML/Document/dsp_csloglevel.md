# 查询日志级别（DSP CSLOGLEVEL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此命令用于查询日志级别。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                               |
|:---------|:-------|:-----------------------------------------------------------------------------------|
| CELLTYPE | 进程类型   | 可选必选说明：可选参数  参数含义：该参数用于表示进程类型。  数据来源：本端规划  取值范围：整数类型，取值范围是0~65535。  默认值：无  配置原则：无  |
| CELLID   | 进程标识   | 可选必选说明：可选参数  参数含义：该参数用于表示进程标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~255。  默认值：无  配置原则：无 |

## 使用实例

查询日志级别：

```
%%DSP CSLOGLEVEL: CELLTYPE=110, CELLID="haf-pod-d69365cc-vk4c5192-168-0-134__108__0";%%
RETCODE = 0  操作成功

结果如下
--------
进程类型  =  110
进程标识  =  haf-pod-d69365cc-vk4c5192-168-0-134__108__0
日志级别  =  调试级别
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                        |
|:--------|:-----------------------------------------------------------------------------------------------------------------------------|
| 进程类型    | 该参数用于表示进程类型。                                                                                                                 |
| 进程标识    | 该参数用于表示进程标识。                                                                                                                 |
