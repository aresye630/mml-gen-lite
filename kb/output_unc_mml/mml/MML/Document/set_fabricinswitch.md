# 设置Fabric-In功能开关（SET FABRICINSWITCH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于设置Fabric-In功能开关。Fabric-In对应是内置FullMesh卡，内置FullMesh卡负责框内流量交换。

#### 注意事项

该命令本版本不再支持生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                       |
|:-------|:-------|:-------------------------------------------------------------------------------------------|
| ENABLE | 功能是否开启 | 可选必选说明：必选参数 参数含义：该参数表示是否开启和关闭Fabric-In功能。数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE” 默认值：TRUE |

#### 使用实例

- 设置Fabric-In功能开启：

  ```
  %%SET FABRICINSWITCH: ENABLE=TRUE;%%
  RETCODE = 0  操作成功

  ---    END
  ```
