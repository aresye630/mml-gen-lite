# 查询SMSC黑名单记录(LST SMSCBLACKLIST)

#### 命令功能

**适用网元：SGSN**

该命令用于查询SMSC黑名单记录。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询SMSC黑名单记录：

LST SMSCBLACKLIST:;

```
%%LST SMSCBLACKLIST:;%%
RETCODE = 0  操作成功。

输出结果如下
--------------
 SMSC地址  

 8613951701
 8613951998
(结果个数 = 2)

---    END
```

#### 输出结果说明

参见**ADD SMSCBLACKLIST**的参数说明。
