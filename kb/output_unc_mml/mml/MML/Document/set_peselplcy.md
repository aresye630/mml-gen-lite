# 设置SGSN/MME选择策略（SET PESELPLCY）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

如果SGSN/MME选择策略参数设置不正确，可能导致大量234G间的切换业务失败。

**适用网元：SGSN、MME**

该命令用于设置SGSN/MME选择策略，选择策略用来识别对端网元是SGSN还是MME。

#### 注意事项

- 系统初次运行时，会执行系统初始设置值。
- 该命令执行后立即生效。
- 该命令最大记录数为1。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称           | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:-----------|:---------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PEIDMODE   | 对等网元识别模式       | 可选必选说明：可选参数 参数含义：该参数用于设置指定的“PEIDMODE（对等网元识别模式）”，提供识别对端网元是SGSN还是MME的方法。缺省使用协议规定的方法：根据LAC/MME Group ID的最高bit位进行区分。 数据来源：整网规划 取值范围：“MASK_MODE（掩码模式）”， “SECTION_MODE（区段模式）” ，“DOMAIN_ROLLBACK_MODE（域名回退模式）” 系统初始设置值：MASK_MODE（掩码模式） 配置原则： “MASK_MODE（掩码模式）”：用掩码模式来识别对端网元是SGSN还是MME。“SECTION_MODE（区段模式）”：用区段模式来识别对端网元是SGSN还是MME。“DOMAIN_ROLLBACK_MODE（域名回退模式）”：用域名回退模式来识别对端网元是SGSN还是MME。  说明： 如果配置为回退模式，则在识别UE的标识是否为本网元分配的时： 如果UE携带的标识位为GUTI，并且携带了Additional GUTI，则主用标识为GUTI映射的PTMSI/RAI，备选标识为GUTI。如果UE携带的标识位为GUTI，但是没有携带Additional GUTI，则按照MMEGI/LAC最高bit位确定主用和备用标识。若最高bit位为1，主用标识为MMEGI，备用标识为LAC；若最高bit位为0，主用标识为LAC，备用标识为MMEGI。如果UE携带的标识位为PTMSI/RAI，并且携带了Additional PTMSI/RAI，则主用标识为PTMSI/RAI映射的GUTI，备选标识为PTMSI/RAI。如果UE携带的标识位为PTMSI/RAI，但是没有携带Additional PTMSI/RAI，则按照MMEGI/LAC最高bit位确定主用和备用标识。若最高bit位为1，主用标识为MMEGI，备用标识为LAC；若最高bit位为0，主用标识为LAC，备用标识为MMEGI。 然后根据主用标识和备用标识进行处理。 如果主用标识为GUTI，通过GUTI判断为非本网元分配后，需要使用PTMSI/RAI再进行一次判断。如果主用标识为PTMSI/RAI，通过PTMSI/RAI判断为非本网元分配后，需要使用GUTI再进行一次判断。如果UE携带的标识判断为非本网元分配，则使用主用标识进行DNS查询失败后，使用备用标识再进行一次DNS查询。即：使用MMEC域名查询失败后重试RAI域名，或使用RAI域名查询失败后重试MMEC域名。 |
| BITMASK    | 比特掩码           | 可选必选说明：条件可选参数 参数含义：该参数用于设置指定的比特掩码。 前提条件：当“PEIDMODE（对等网元识别模式）”为“MASK_MODE（掩码模式）”时显示。 数据来源：整网规划 取值范围：0～0xffff（十六进制数字） 系统初始设置值 ：0x8000 配置原则： LAC/MME Group ID与“BITMASK（比特掩码）”进行比特“与”操作之后，如果等于“BITMASK（比特掩码）”，则认为该标识是MME Group ID。缺省取值是协议规定的LAC/MME Group ID区分方式。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| MMEGI      | MME Group ID   | 可选必选说明：条件必选参数 参数含义：该参数用于设置指定的MMEGI（MME Group ID）。 前提条件：当“PEIDMODE（对等网元识别模式）”为“SECTION_MODE（区段模式）”时显示。 数据来源：整网规划 取值范围：0x0000～0xffff 系统初始设置值 ：0                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| MMEGIRANGE | MME Group ID范围 | 可选必选说明：条件可选参数 参数含义：该参数用于设置指定的“MME Group ID范围”。 前提条件：当“PEIDMODE（对等网元识别模式）”为“SECTION_MODE（区段模式）”时显示。 数据来源：整网规划 取值范围：0x0000～0xffff（十六进制数值型） 系统初始设置值 ：0 配置原则： 要求大于或等于“ MMEGI（MME Group ID）”。与“ MMEGI（MME Group ID）”参数构成一个MME Group ID区段，可以配置连续的位置区域。如果不输入，表示配置单个MME Group ID。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| RNCID      | 使用RNC ID域名     | 可选必选说明：可选参数 参数含义：该参数用于设置指定的使用RNC ID域名。 数据来源：整网规划 取值范围： “NO(NO)”“YES(YES)” 系统初始设置值 ： “YES(YES)” 配置原则： 在Handover/Relocation流程中是否使用“ RNCID（RNC ID域名）”进行查询，如果不使用“ RNCID（RNC ID域名）”，系统会组装RAI域名进行查询。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| IDTYPE     | 使用ID TYPE      | 可选必选说明：可选参数 参数含义：该参数用于控制UNC是否通过UE携带的GUTI Type/PTMSI Type信元来识别对端网元类型。 数据来源：整网规划 取值范围： “NO(NO)” ：系统直接按照“PEIDMODE（对等网元识别模式）”的配置判断对端设备是MME还是SGSN。“YES(YES) ”：如果UE携带了GUTI Type/PTMSI Type，系统会根据携带信息确定移动性管理业务流程中的对端网元是MME还是SGSN；如果UE未携带GUTI Type/PTMSI Type，系统按照“PEIDMODE（对等网元识别模式）”的配置判断对端设备是MME还是SGSN。 系统初始设置值 ： “YES(YES) ” 配置原则： UNC作为MME或融合的MME/SGSN，可以通过S10/S3/S16/Gn接口与其它MME或SGSN进行移动管理业务流程的交互，即需要区分对端设备是MME或SGSN，建议配置为YES。UNC作为GnGp SGSN，只能通过Gn接口与其它MME或SGSN进行移动管理业务流程的交互，即不区分对端设备是MME还是SGSN，建议配置为NO。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |

#### 使用实例

使用PEIDMODE（对等网元识别模式）为DOMAIN\_ROLLBACK\_MODE（域名回退模式），RNCID（使用RNC ID域名）为NO（否），IDTYPE(使用ID TYPE )为YES（是）的SGSN/MME选择策略：

SET PESELPLCY: PEIDMODE=DOMAIN\_ROLLBACK\_MODE, RNCID=NO, IDTYPE=YES;
