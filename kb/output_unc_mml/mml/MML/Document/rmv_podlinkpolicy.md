# 删除Pod级链路策略（RMV PODLINKPOLICY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此命令用于删除Pod级链路策略。

## 注意事项

- 该命令执行后立即生效。

- 删除本网元的Pod级链路策略，会导致本网元与SEPP之间的SBI链路数扩大2~4倍，需要综合评估对接的SEPP网元的SBI链路数规格是否足够。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                           |
|:-----------|:-------|:---------------------------------------------------------------------------------------------------------------|
| PEERNFTYPE | 对端网元类型 | 可选必选说明：必选参数  参数含义：该参数用于指定使用Pod级链路策略的NF类型。  数据来源：本端规划 取值范围： “SEPP（SEPP）”：该参数用于指定使用Pod级链路策略的NF类型。  默认值：无  配置原则：无 |

## 使用实例

删除对端网元类型为SEPP的Pod级链路策略。

```
RMV PODLINKPOLICY:PEERNFTYPE=SEPP;
```
