# 查询容灾用户号段参数 (LST RESTOUSRSEG)

#### 命令功能

**适用网元：MME**

此命令用于查询容灾用户号段参数配置。

#### 注意事项

- 无

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                     |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：可选参数 参数含义：该参数用于指定链式备份功能服务的用户范围。 取值范围： IMSI_PREFIX(指定IMSI前缀) 默认值：无 配置原则：无                                                          |
| IMSIPRE  | IMSI前缀 | 必选说明：条件必选参数 参数含义：该参数用于指定链式备份功能服务的用户范围的IMSI前缀。 前提条件：该参数在“用户范围”参数配置为“IMSI_PREFIX(指定IMSI前缀)”后生效。 数据来源：全网规划 取值范围：5～15位十进制数字字符串。 默认值：无 配置原则：无 |

#### 使用实例

1. 查询容灾用户号段参数配置，可以用如下命令：

   LST RESTOUSRSEG:;

   ```
   %%LST RESTOUSRSEG:;%%
   RETCODE = 0  操作成功。

   操作结果如下
   ------------
        用户范围  =  指定IMSI前缀
        IMSI前缀  =  12345
    是否备份用户  =  是
   (结果个数 = 1)

   ---    END
   ```
