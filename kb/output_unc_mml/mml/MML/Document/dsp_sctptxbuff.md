# 查询SCTP发送缓冲区(DSP SCTPTXBUFF)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGSN、MME、AMF**

此命令用于查询SCTP发送缓冲区信息。

#### 注意事项

此命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                          |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SRT    | 查询方式   | 可选必选说明：可选参数 参数含义：该参数用于指定查询方式。 取值范围： PROC（按进程查询）INTYPE（按接口类型查询） 默认值：“PROC（按进程查询）”                                                                              |
| RUNAME | RU名称   | 可选必选说明：条件可选/必选参数 参数含义：该参数用于指定待查询的RU名称。该参数可以通过DSP RU命令查询。 取值范围：1~63位字符串 默认值 ：无 配置原则：“查询方式”参数设置为“PROC（按进程查询）”时，该参数为可选参数；“查询方式”参数设置为“INTYPE（按接口类型查询）”时，该参数为必选参数。 |
| PN     | 进程号    | 可选必选说明：条件可选/必选参数 参数含义：该参数用于指定查询的SGP的进程号。 取值范围： 0~11 默认值 ：无 配置原则：“查询方式”参数设置为“PROC（按进程查询）”时，该参数为可选参数；“查询方式”参数设置为“INTYPE（按接口类型查询）”时，该参数为必选参数。                    |
| IFTYPE | 接口类型   | 可选必选说明：条件必选参数 参数含义：该参数用于指定查询的接口类型。 前提条件：“查询方式”参数设置为“INTYPE（按接口类型查询）”时，该参数必选。 取值范围： S1（S1）N2（N2） 默认值 ：S1 配置原则：无                                                |

#### 使用实例

查询N2接口SCTP发送缓冲区，可以用如下命令：

DSP SCTPTXBUFF: SRT=INTYPE, RUNAME="LINK\_SP\_RU\_0064", PN=0, IFTYPE=N2;

```
%%DSP SCTPTXBUFF: SRT=INTYPE, RUNAME="LINK_SP_RU_0064", PN=0, IFTYPE=N2;%%

```

DSP SCTPTXBUFF: SRT=PROC;

#### 输出结果说明

| 输出项名称        | 输出项解释                           |
|:-------------|:--------------------------------|
| RU名称         | 查询出的SPU资源单元名。 取值范围：1~63位字符串     |
| 进程号          | 查询出的发送缓冲区所在的SGP进程的进程号。          |
| S1共享发送缓冲区占用块 | 查询出的SGP进程上的S1共享发送缓冲区占用块。        |
| N2共享发送缓冲区占用块 | 查询出的SGP进程上的N2共享发送缓冲区占用块。        |
| 迷你端共享区总块     | 查询出的SGP进程上的迷你端共享区总块。            |
| 迷你端共享区占用率    | 查询出的SGP进程上的迷你端共享区占用率。           |
| 偶联ID         | 查询出的SCTP链路的偶联ID。                |
| 对端IP地址1      | 查询出的SCTP链路中gNodeB/eNodeB的IP地址1。 |
| 对端IP地址2      | 查询出的SCTP链路中gNodeB/eNodeB的IP地址2。 |
| 对端端口号        | 查询出的SCTP链路中gNodeB/eNodeB的端口号。   |
| 私有发送缓冲区总大小   | 查询出的SCTP链路的私有发送缓冲区总大小。          |
| 私有发送缓冲区占用大小  | 查询出的SCTP链路的私有发送缓冲区占用大小。         |
| 扩展发送缓冲区总大小   | 查询出的SCTP链路的扩展发送缓冲区总大小。          |
| 扩展发送缓冲区占用大小  | 查询出的SCTP链路的扩展发送缓冲区占用大小。         |
| 发送缓冲区占用率     | 查询出的SCTP链路的发送缓冲区占用率。            |
