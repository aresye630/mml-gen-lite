# 删除智能规则和智能业务编码组的绑定关系（RMV IPERULEMAPPING）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于删除智能规则和智能业务编码组的绑定关系。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                         |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RULENAME | 智能规则名称 | 可选必选说明：必选参数  参数含义：该参数用于设置规则名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。不支持空格，不区分大小写。  默认值：无  配置原则：  该参数的取值来源于已经配置的ADD RULE命令的“RULENAME”参数，且该命令的“NWDAFEVENTS”参数必须配置为“IPE_SERVICE”。 |

## 使用实例

删除智能规则名称为“intelligent”的配置：

```
RMV IPERULEMAPPING: RULENAME="intelligent";
```
