# 删除基于UDM标识控制创建AMF策略（RMV AMFPLCYBYUDM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除基于UDM标识控制创建AMF策略。

## 注意事项

下一次移动性流程生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                     |
|:----------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UDMIDTYPE | UDM标识类型 | 可选必选说明：必选参数  参数含义：该参数用于指定UDM标识类型。  数据来源：全网规划 取值范围： UDMINSTANCEID（UDM实例标识）  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                 |
| UDMINSTID | UDM实例标识 | 可选必选说明：该参数在"UDMIDTYPE"配置为"UDMINSTANCEID"时为条件必选参数。  参数含义：该参数用于指定UDM实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~36。  默认值：无  配置原则：  参数必须满足以下约束规则：1.如果输入为uuid格式（格式例如：a6a61c6f-0d3a-4221-b1da-424eda3ccf67）只能为A-F、a-f、0-9的字符。2.如果输入不为uuid格式，长度不能超过18且不允许输入只包含0-9和“.”的字符串，例如：1.2.3.4、不允许输入只包含十六进制数（A-F、a-f、0-9）和“:”的字符串，例如：1::2、FBFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。3.该参数大小写不敏感。 |

## 使用实例

删除基于UDM标识限制策略控制的配置，其中UDM标识类型为UDM实例标识，UDM实例标识为"12345678-1234-1234-1234-123456789123"，执行如下命令：

```
RMV AMFPLCYBYUDM: UDMIDTYPE=UDMINSTANCEID, UDMINSTID="12345678-1234-1234-1234-123456789123";
```
