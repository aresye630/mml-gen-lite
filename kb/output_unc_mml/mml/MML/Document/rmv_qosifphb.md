# 删除禁止QoS优先级映射的类型（RMV QOSIFPHB）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除接口下的禁止PHB映射的实例。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称            | 参数说明                                                                                                |
|:--------|:----------------|:----------------------------------------------------------------------------------------------------|
| IFNAME  | 接口名称            | 可选必选说明：必选参数 参数含义：该参数用于设置接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：使用LST INTERFACE命令查看可用接口。 |
| PHBTYPE | 出接口报文的优先级字段映射类型 | 可选必选说明：必选参数 参数含义：该参数用于设置出接口报文的优先级字段映射类型。 数据来源：本端规划 取值范围：枚举类型。 dscp：IP报文的DSCP。 默认值：无                 |

#### 使用实例

在接口Ethernet66/0/3下删除禁止DSCP映射：

```
RMV QOSIFPHB : IFNAME="Ethernet66/0/3",PHBTYPE=dscp;
```
