# 查询IPv4 MPAC策略规则（LST MPACIPV4RULE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询MPAC策略规则。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                          |
|:-----------|:-------|:----------------------------------------------------------------------------------------------|
| POLICYNAME | 策略名称   | 可选必选说明：可选参数 参数含义：该参数用于指定创建规则的策略名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。大小写敏感，英文字母开头，不支持空格。 默认值：无 |
| RULENAME   | 规则名字   | 可选必选说明：可选参数 参数含义：该参数用于指定规则的名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。大小写敏感，英文字母开头，不支持空格。 默认值：无     |

#### 使用实例

查询MPAC策略规则：

```
LST MPACIPV4RULE:POLICYNAME="policyV4",RULENAME="name-test";
```
