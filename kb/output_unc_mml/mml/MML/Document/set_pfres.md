# 设置带宽资源管理参数(SET PFRES)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于设置支持用户面GTP-U转发的资源管理需要的参数。

#### 注意事项

- 系统初次运行时，会执行系统初始设置值。
- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明
