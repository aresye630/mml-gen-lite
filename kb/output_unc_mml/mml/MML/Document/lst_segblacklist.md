# 查询导入号段黑名单（LST SEGBLACKLIST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NRF**

该命令已废弃。

该命令用于查询NRF导入号段的黑名单。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                                                                                                                           |
|:---------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SEGTYPE  | 号段类型    | 可选必选说明：可选参数  参数含义：该参数用于表示号段黑名单作用的号段类型。  数据来源：本端规划 取值范围： IMSI（IMSI）MSISDN（MSISDN）IMSIRT（IMSIRT）MSISDNRT（MSISDNRT）  默认值：无  配置原则：无                                                                                                                                                |
| NFTYPE   | NF类型    | 可选必选说明：可选参数  参数含义：该参数用于表示号段黑名单作用的NF类型，即哪些NF类型支持号段文件中给出的号段信息。  数据来源：本端规划 取值范围： AUSF（AUSF）PCF（PCF）UDM（UDM）UDR（UDR）CHF（CHF）CUSTOM_OCS（CUSTOM_OCS）  默认值：无  配置原则：  该参数在“SEGTYPE”配置为“IMSI、IMSIRT”时，取值范围为上述所有NF类型，该参数在“SEGTYPE”配置为“MSISDN、MSISDNRT”时，取值范围为PCF、UDM、UDR、CHF、CUSTOM_OCS。 |
| SEGSTART | 号段起始字符串 | 可选必选说明：可选参数  参数含义：该参数用于表示号段黑名单起始字符串。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是5~15。十进制数字，号段的起始号码必须与结束号码长度保持一致，数值必须小于或等于结束号码的数值。  默认值：无  配置原则：无                                                                                                                                            |
| SEGEND   | 号段结束字符串 | 可选必选说明：可选参数  参数含义：该参数用于表示号段黑名单结束字符串。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是5~15。十进制数字，号段的结束号码必须与起始号码长度保持一致，数值大于或等于起始号码的数值。  默认值：无  配置原则：无                                                                                                                                              |
| GROUPID  | 组标识     | 可选必选说明：可选参数  参数含义：该参数用于表示待配置IMSI/MSISDN号段黑名单的NF组标识或配置IMSIRT/MSISDNRT路由转发号段黑名单的下一跳NRF组标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~128。该参数只能由字母（A-Z或者a-z）、数字（0-9），中划线（-）组成。当配置IMSI/MSISDN号段黑名单的NF组标识时，不区分大小写；当配置IMSIRT/MSISDNRT路由转发号段黑名单的下一跳NRF组标识时，则区分大小写。  默认值：无  配置原则：无               |

## 使用实例

- 查询所有NRF导入号段的黑名单。

  ```
  LST SEGBLACKLIST:;
  %%LST SEGBLACKLIST:;%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
  号段类型      NF类型      号段起始字符串                  号段起始字符串                组标识

  MSISDN        CUSTOM_OCS  110101                          110102                        test01    
  MSISDNRT      UDM         111111                          111111                        test01    
  MSISDNRT      CUSTOM_OCS  110101                          110102                        test01    
  IMSI          UDM         111111000000000                 111111999999999               test01    
  IMSI          UDM         111111000000000                 111113999999999               test01    
  (结果个数 = 5)
  ```
- 查询UDM类型所支持的IMSI号段黑名单。

  ```
  LST SEGBLACKLIST: SEGTYPE=IMSI, NFTYPE=UDM;
  %%LST SEGBLACKLIST: SEGTYPE=IMSI, NFTYPE=UDM;%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
  号段类型      NF类型      号段起始字符串               号段起始字符串                组标识

  IMSI          UDM      111111000000000                 111111999999999               test01    
  IMSI          UDM      111111000000000                 111113999999999               test01    
  (结果个数 = 2)
  ```
