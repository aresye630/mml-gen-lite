# 修改智能业务后缀（MOD IPEN7SUFFIX）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、PGW-C**

该命令用于修改智能业务后缀。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                              |
|:--------------|:-------|:--------------------------------------------------------------------------------------------------|
| INTELLISUFFIX | 智能业务后缀 | 可选必选说明：必选参数  参数含义：该参数用于设置智能业务后缀。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。  默认值：无  配置原则：  不支持空格，不区分大小写。 |
| INTELLINAME   | 智能业务名称 | 可选必选说明：可选参数  参数含义：该参数用于设置智能业务名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~64。  默认值：无  配置原则：无               |

## 使用实例

修改智能业务后缀为“intelligent”配置的智能业务名称为“video”：

```
MOD IPEN7SUFFIX: INTELLISUFFIX="intelligent",INTELLINAME="video";
```
