#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于向AAA服务器发送探测消息，根据回显来推断UNC和AAA服务器之间的连接是否正常。

#### 注意事项

- 该命令执行后立即生效。
- 在执行该命令前需要先使用ADD RDSSVR命令配置要探测的鉴权服务器或者计费服务器，否则探测命令会执行失败。
- 该命令执行的过程中不能执行其他命令，等待该命令执行完成后才能执行其他命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| USERNAME    | 用户名                | 可选必选说明：条件可选参数 前提条件：该参数在“SERVERTYPE”配置为“ACCOUNTING” 或 “AUTHENTICATION”时为可选参数。 参数含义：该参数用于设置发送探测消息中携带的用户名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：AAAtester 配置原则：无   |

| IPVERSION   | IP Address Version | 可选必选说明：必选参数 参数含义：用于指定IP地址类型。 数据来源：本端规划 取值范围：枚举类型。 IPV4：表示地址类型为IPv4。IPV6：表示地址类型为IPv6。 默认值：无 配置原则：无                                                                |

| IPV6ADDRESS | 服务器IPv6地址          | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV6”时为必选参数。 参数含义：指定IPv6类型的地址。 数据来源：本端规划 取值范围：IPv6地址类型。采用冒号分十六进制X:X:X:X:X:X:X:X格式。 默认值：无 配置原则：无                            |

#### 使用实例

假设运营商需要向AAA服务器发送探测消息，根据回显来推断UNC和AAA服务器之间的连接是否正常，则执行如下命令：

```
TST AAA: SERVERTYPE=ACCOUNTING, IPVERSION=IPV4, IPADDRESS="192.168.1.1";
```
