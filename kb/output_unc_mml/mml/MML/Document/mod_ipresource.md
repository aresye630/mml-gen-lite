#### 命令功能

**须知** 

- 执行此命令后立即出现IP不通，请谨慎操作。
- 此命令不能动态生效，需要执行“RST VNFC”重启服务，并且修改IP资源需重新对接IP，否则影响业务使用。

**适用NF：NCG**

该命令用于修改CG侧话单接收、分发和备份时所使用的IP地址等信息。

#### 注意事项

- 该命令执行后，需在“MML命令行 - UNC”窗口执行“**RST VNFC**”命令重新启动系统才能生效。
- 如果参数“IP地址类型”发生变化，会导致已配置在Bi、Omi或OmiAndBi接口的话单分发、话单备份和话单路由失效，或者导致配置在Ga接口的话单路由失效，请修改IP地址类型相关配置，并与相应接口的IP地址类型保持一致。
- IPv4或者IPv6类型的Ga口地址，必须配置相应的接入控制模块之后，IP地址才能生效。
- NCG不支持IPv6以下格式地址下发：FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、::、::1、FE80::/10、FF00::/8、2001:X:X:X:X:X:: 。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                     |
|:-----------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPRID      | IP资源标识 | 可选必选说明：必选参数 参数含义：用于表示一个IP资源对象，全局唯一。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：不能输入的特殊字符请参考“特殊字符表”。                                                                                                                                                                                                                                                    |
| IPRPURPOSE | IP资源用途 | 可选必选说明：必选参数 参数含义：IP资源用途。 数据来源：本端规划 取值范围：枚举类型。 Bi：Bi。Omi：Omi。OmiAndBi：Omi&Bi。Ga：Ga。 默认值：无 配置原则： Bi 计费接口，用于话单分发。当CG分发话单到计费中心或者计费中心到CG取话单时，选择此选项。 Omi 备份接口，用于话单备份。当CG需备份话单到第三方服务器/UDN服务器时，选择此选项。 OmiAndBi 计费和备份接口，用于话单分发和备份。当分发和备份采用同一IP资源时，选择此选项。 Ga Ga接口，用于接收话单。当CG需要从SMF网元接收话单时，选择此选项。 用于修改IP资源对应的接口。一般情况下，在开局和扩容前已规划好，不能修改。不能输入的特殊字符请参考“特殊字符表”。         |
| RUID       | RU的ID  | 可选必选说明：条件可选参数 前提条件：该参数在“IPRPURPOSE”配置为“Bi”、“Omi” 或 “OmiAndBi”时为条件可选参数。 参数含义：RU的ID。 数据来源：本端规划 取值范围：整数类型，取值范围为64～4294967294。 默认值：无 配置原则：该值需要执行LST SERVICERUSTATE命令，查询出存在的RU ID进行填写。                                                                                                                                                                        |
| IPTYPE     | IP地址类型 | 可选必选说明：可选参数 参数含义：用于表示Ga、Bi、Omi、OmiAndBi口IP地址属于IPv4网络还是IPv6网络，需根据当前局点规划选择其中一种。 数据来源：对端协商 取值范围：枚举类型。 IPV4：IPv4。IPV6：IPv6。 默认值：无 配置原则：当且仅当选择开关型参数“IP资源用途”的值为“Ga(Ga)”、“Bi(Bi)”、“Omi(Omi)”或“OmiAndBi(Omi&Bi)”时，此参数有效。                                                                                                                                         |
| IPV4       | IPv4地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPTYPE”配置为“IPV4”时为条件必选参数。 参数含义：用于话单接收的IPv4地址。 数据来源：本端规划 取值范围：IPv4地址类型。0.0.0.0-255.255.255.255。 默认值：无 配置原则： 业务地址不能配置为0.x.y.z、255.255.255.255和环回地址(127.x.y.z)。业务地址必须是A、B或者C类地址。不能配置与外联口IP地址相同的IP地址。                                                                                                                                |
| IPV6       | IPv6地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPTYPE”配置为“IPV6”时为条件必选参数。 参数含义：用于话单接收的IPv6地址。 数据来源：本端规划 取值范围：IPv6地址类型。::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。 默认值：无 配置原则： IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、2001:X:X:X:X::、环回地址(::1)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。该参数的掩码缺省为FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF，不可更改。不能配置与外联口IP地址相同的IP地址。 |
| VPNNAME    | 虚拟网络名称 | 可选必选说明：可选参数 参数含义：该参数为VPN名称，是业务消息转发时的鉴权参数。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：该参数区分大小写，不支持空格。                                                                                                                                                                                                                                                   |

#### 使用实例

修改标识为“1st\_to\_BS”的IP资源，示例如下：

```
MOD IPRESOURCE: IPRID="IP_Bi_CDRDistribution_1st", IPRPURPOSE=Bi, RUID=66, IPTYPE=IPV4, IPV4="10.70.148.89", VPNNAME="_public_";
```
