# 查询APN的MBR删除PCC回滚空闲上下文配置（LST APNPCRFEMEREATTACH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C**

该命令用于查询指定APN的MBR消息删除idle态的PCC回滚上下文的功能。

## 注意事项

当前版本不支持此命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                         |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN    | APN名称  | 可选必选说明：可选参数  参数含义：该参数用于指定APN实例名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无  配置原则：  该参数使用ADD APN命令配置生成。 |

## 使用实例

查询“APN名称”为“isp”，删除PCC回滚的idle上下文的功能是否开启。

```
%%LST APNPCRFEMEREATTACH: APN="isp";%%
RETCODE = 0  操作成功

结果如下
------------------------------
              APN名称  =  isp
APN MBR 删除承载配置  =  ENABLE
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称          | 输出项解释                                     |
|:---------------|:------------------------------------------|
| APN名称          | 该参数用于指定APN实例名。                            |
| APN MBR 删除承载配置 | 该参数用于指定APN控制开启和关闭MBR消息删除PCC回滚的idle上下文的功能。 |
