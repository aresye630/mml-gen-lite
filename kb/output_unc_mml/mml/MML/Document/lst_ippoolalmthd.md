# 查询本地地址池组使用率告警阈值（LST IPPOOLALMTHD）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、GGSN、SMF**

此命令用于查询本地地址池组使用率告警的产生阈值和恢复阈值。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询本地地址池组使用率告警的产生阈值和恢复阈值，执行命令如下：
LST IPPOOLALMTHD:;

```
%%LST IPPOOLALMTHD:;%%
RETCODE = 0  操作成功。

结果如下
--------------------
告警产生阈值 （%）  =  80
告警恢复阈值 （%）  =  70
(结果个数 = 1)
---    END
```

## 输出结果说明

| 输出项名称      | 输出项解释                     |
|:-----------|:--------------------------|
| 告警产生阈值 (%) | 该参数用于指定本地地址池组的使用率的告警产生阈值。 |
| 告警恢复阈值 (%) | 该参数用于指定本地地址池组的使用率的告警恢复阈值。 |
