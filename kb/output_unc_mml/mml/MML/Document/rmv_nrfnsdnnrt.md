# 删除DNN和网络切片路由（RMV NRFNSDNNRT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于删除目标DNN和网络切片的路由信息。如果删除后，将影响分层互联功能。

## 注意事项

- 该命令执行后立即生效。

- 主备或双活组网的场景下，如果需要配置此命令，则两个NRF上均需执行此命令，且配置参数一致。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                                               |
|:---------------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
| DNN            | 数据网络名称   | 可选必选说明：必选参数  参数含义：该参数用于表示数据网络名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~50。该参数不区分大小写。  默认值：无  配置原则：  当前NRF仅支持NFTYPE为SMF的路由转发功能，其他NF类型为预留功能。               |
| SST            | 切片服务类型   | 可选必选说明：必选参数  参数含义：该参数用于表示切片服务类型，标识网络切片所具备的特性和服务类型。  数据来源：本端规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无                                                |
| SD             | 切片描述     | 可选必选说明：必选参数  参数含义：该参数用于表示切片描述，是对相同SST的网络切片实例的差异化描述。  数据来源：本端规划  取值范围：字符串类型，输入长度是6。该参数只能由字母（A-F或者a-f）、数字（0-9）组成。  默认值：无  配置原则：无                     |
| NEXTNRFGRPNAME | 归属NRF组名称 | 可选必选说明：必选参数  参数含义：该参数用于表示DNN和网络切片归属的NRF实例组名称，此NRF实例组作为当前NRF的下一跳路由，该参数需要输入时，可通过LST NRFGROUP命令获取。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~64。  默认值：无  配置原则：无 |

## 使用实例

运营商需要删除数据网络名称为huawei.com，切片服务类型为0，切片描述为000001的路由时，执行此命令。

```
RMV NRFNSDNNRT: DNN="huawei.com", SST=0, SD="000001", NEXTNRFGRPNAME="H-NRF1";
```
