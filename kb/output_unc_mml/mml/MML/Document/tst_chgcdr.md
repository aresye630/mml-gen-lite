#### 命令功能

**适用网元：SGSN**

该命令用于模拟生成SGSN话单。话单由SPP或UPP进程生成，生成后发往CDP进程，并存储在SPU硬盘或者发往CG。在新建局时，需要对本局点的计费网络及计费功能进行调测，用以验证SGSN与CG之间对接数据配置的正确性及接口状态是否正常，保证SGSN与CG之间接口可以正常工作。

#### 注意事项

- 该命令执行后立即生效。
- 要模拟生成话单必须满足以下几个条件：
  - 至少存在一个状态正常的CDP进程。
  - SPU硬盘没有满。
  - 与CG通讯正常。
  - 当**SET CHGCHAR**中配置的生成话单类型为“YES(Generate)”。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                                                                                                                                                   |
|:--------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CDRTYPE | 话单类型      | 可选必选说明：必选参数 参数含义：该参数用于指定要生成的话单类型。 数据来源：整网规划 取值范围： “MCDR(MCDR)”“SCDR(SCDR)”“SSMOCDR(SSMOCDR)”“SSMTCDR(SSMTCDR)”“LCSMOCDR(LCSMOCDR)”“LCSMTCDR(LCSMTCDR)”“LCSNICDR(LCSNICDR)” 默认值：无  说明： “系统类型”为“GPRS”时，不能生成LCSMOCDR模拟话单。 |
| SYSTYPE | 系统类型      | 可选必选说明：可选参数 参数含义：该参数用于指定要生成话单的系统类型。 数据来源：整网规划 取值范围：“GPRS(GPRS)”“UMTS(UMTS)”“GERAN(GERAN)” 默认值：“UMTS”                                                                                                                   |
| IMSI    | IMSI      | 可选必选说明：可选参数 参数含义：该参数用于指定模拟话单中包含的IMSI。 数据来源：整网规划 取值范围：5～15位十进制数字 默认值：无                                                                                                                                                  |
| MSISDN  | MSISDN    | 可选必选说明：可选参数 参数含义：该参数用于指定模拟话单中包含的MSISDN。 数据来源：整网规划 取值范围：5～15位十进制数字 默认值：无                                                                                                                                                |
| CC      | 计费属性      | 可选必选说明：可选参数 参数含义：该参数用于指定模拟话单的计费属性字段。 数据来源：整网规划 取值范围：“NORMAL(普通计费)”“PREPAID(预付费)”“FLATRATE(包月制)”“HOTBILLING(实时计费)” 默认值：“NORMAL(普通计费)”                                                                                   |
| LAC     | 位置区域码     | 可选必选说明：可选参数 参数含义：该参数用于指定模拟话单的位置区信息。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无 配置原则： 该参数的值必须大于等于“位置区域码”的值。 新添加的位置区域码范围不能与原有的位置区域码范围出现重叠。 如果该参数不输入，表示配置单个LAC。  说明： 用户在输入值的时候，可以加上“0x”前缀，也可以不加此前缀，都会被处理为16进制的数字。                 |
| RAC     | 寻呼范围路由区域码 | 可选必选说明：可选参数 参数含义：该参数用于指定模拟话单的路由区信息。 数据来源：整网规划 取值范围：1～2位十六进制数 默认值：无                                                                                                                                                     |
| CI      | 小区标识      | 可选必选说明：可选参数 参数含义：该参数用于指定模拟话单的小区标识信息。 数据来源：整网规划 取值范围：1～4位十六进制数 默认值：无                                                                                                                                                    |
| RUNAME  | RU名称      | 可选必选说明：可选参数 参数含义：该参数用于指定要查询的资源单元名称。该参数可以通过DSP RU命令查询。 数据来源：整网规划 取值范围：1 ~ 63位字符串 默认值：无                                                                                                                                  |
| PID     | 进程号       | 可选必选说明：可选参数 参数含义：该参数用于指定要模拟生成话单的SPP/UPP进程号。S-CDR话单只能由UPP进程生成。LCS-NI-CDR、LCS-MT-CDR、LCS-MO-CDR、S-SMT-CDR、S-SMO-CDR、M-CDR话单只能由SPP进程生成。 数据来源：整网规划 取值范围：0～20 默认值：无 配置原则：无                                                  |

#### 使用实例

模拟生成一张M-CDR话单：

TST CHGCDR: CDRTYPE=MCDR;
