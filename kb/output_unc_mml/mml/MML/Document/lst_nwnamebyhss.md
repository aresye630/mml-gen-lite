# 查询不发送运营商名称的HSS(LST NWNAMEBYHSS)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于查询不发送运营商名称的HSS。该命令对应的业务功能暂未实现。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                           |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INDEX   | 索引     | 可选必选说明：可选参数 参数含义：该参数用于指定配置记录的索引。 数据来源：本端规划 取值范围：整数范围1~1000 默认值： 无 配置原则：无                                                                                                                                       |
| SELMODE | 匹配模式   | 可选必选说明：可选参数 参数含义：该参数用于表示选择不发送运营商名称的HSS的匹配模式。 数据来源：全网规划 取值范围： “LABEL(标识)”：匹配HSS主机名标识的用户“HOST(主机名)”：匹配HSS主机名的用户“REALM(域名)”：匹配HSS域名的用户 默认值：无 配置原则：无。                                                              |
| LABEL   | 标识     | 可选必选说明：条件可选参数 参数含义：该参数用于指定匹配用户的HSS网元标识的字符串。 前提条件：该参数在“匹配模式”设置为“LABEL(标识)”后生效。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～127。 默认值：无 配置原则： 输入字符串中不能含有非法字符，只允许输入字母，数字和“-”，不区分大小写。例如：UDMm、MHSS。不允许配置以“null”开头的字符串。             |
| HOST    | 主机名    | 可选必选说明：条件可选参数 参数含义：该参数用于指定用户的HSS的主机名。 前提条件：该参数在“匹配模式”设置为“HOST(主机名)”后生效。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～127。 默认值：无 配置原则： 不能为非法字符，只允许输入字母，数字，“.”和“-”。例如：hss.epc.mnc123.mcc123.3gppnetwork.org 不允许配置以“null”开头的字符串。 |
| REALM   | 域名     | 可选必选说明：条件可选参数 参数含义：该参数用于指定用户的HSS的域名。 前提条件：该参数在“匹配模式”设置为“REALM(域名)”后生效。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～127。 默认值：无 配置原则： 不能为非法字符，只允许输入字母，数字，“.”和“-”。例如：epc.mnc123.mcc123.3gppnetwork.org 不允许配置以“null”开头的字符串。      |

#### 使用实例

1. 查询所有记录：

   LST NWNAMEBYHSS:;
2. 查询索引为1的记录：

   LST NWNAMEBYHSS: INDEX=1;
3. 查询“匹配模式”为“LABEL(标识)”的记录：

   LST NWNAMEBYHSS: SELMODE=LABEL;
4. 查询HSS主机名为“hss.epc.mnc123.mcc123.3gppnetwork.org”的记录：

   LST NWNAMEBYHSS: SELMODE=HOST, HOST="hss.epc.mnc123.mcc123.3gppnetwork.org";
