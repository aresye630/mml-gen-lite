- 命令功能

#### 命令功能

该命令用来查询ND快回使能配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询ND快回使能配置：

```
LST SECND:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
使能标记    是
(结果个数 = 1)
---    END
```
