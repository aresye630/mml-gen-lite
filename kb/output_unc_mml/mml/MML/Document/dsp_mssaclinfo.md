# 查询软转发支撑访问控制列表模块全局信息（DSP MSSACLINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询访问控制列表全局信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                   |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------|
| RUNAME | RU名称   | 可选必选说明：必选参数 参数含义：该参数用于指定RU名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：使用DSP RU查看RU名称。 |

#### 使用实例

查询软转发支撑访问控制列表全局信息：

```
DSP MSSACLINFO:RUNAME="VNODE_VNRS_VNFC_IPU_0064";
```

```
RETCODE = 0  操作成功。

结果如下
--------
          访问控制列表模块初始化标识  =  TRUE
                最大访问控制列表个数  =  526466
              已使用访问控制列表个数  =  4
访问控制列表模块内存使用量（K byte）  =  255344
(结果个数 = 1)
---    END
```

|:----------------------|:--------------------------|

| 最大访问控制列表个数            | 用于表示最大访问控制列表个数。           |
| 已使用访问控制列表个数           | 用于表示已使用了访问控制列表个数。         |
