# 删除DNAI支持的服务区域（RMV DNAIBINDDNAREA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、SMF、GGSN、PGW-C**

该命令用于删除DNAI支持的服务区域。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称       | 参数说明                                                                                                                                                    |
|:---------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------|
| DNAI     | 数据网络访问标识   | 可选必选说明：必选参数  参数含义：该参数用于指定数据网络访问标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~63。不区分大小写。  默认值：无  配置原则：无                                                            |
| AREANAME | DNAI服务区域名称 | 可选必选说明：必选参数  参数含义：该参数用于指定DNAI服务区域名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~255。不能为非法字符，只允许输入字母，数字、“_”、“.”，并且开头和结尾只能是数字或者字母，不能出现连续两个“.”。不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

删除数据网络访问标识为“ulcl”绑定的服务区域“DNAREA1”。

```
RMV DNAIBINDDNAREA: DNAI="ulcl", AREANAME="dnarea1";
```
