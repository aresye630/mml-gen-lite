# 查询接口全局配置（LST IFGLOBALCONFIG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示接口全局属性。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询全局的流量统计间隔和接口首次Down告警上报的使能状态：

```
LST IFGLOBALCONFIG:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
   全局流量统计间隔（s） = 5
使能接口首次Down告警上报 = FALSE
(结果个数 = 1)
---   END
```
