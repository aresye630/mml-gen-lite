# 删除区域码(RMV ZC)

#### 命令功能

**适用网元：SGSN、MME**

此命令用于删除区域码记录。区域码用于定义允许或者禁止用户漫游的位置区域，借助一个完全的区域码列表，运营商可以确定用户是否能在此区域漫游。

#### 注意事项

- 此命令执行后立即生效。
- 此命令执行后会导致签约了本ZC（区域码）的用户不能从本记录的位置接入系统。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                      |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------|
| ZC     | 区域码    | 可选必选说明：必选参数 参数含义：待删除的区域码信息。 取值范围：0x0000~0xFFFF 默认值：无                                                                                      |
| IDTYPE | 标识类型   | 可选必选说明：必选参数 参数含义：待删除的区域标识类型。 取值范围： “LA(位置区)”：表示该区域标识类型为位置区。“RA(路由区)”：表示该区域标识类型为路由区。“SA(服务区)”：表示该区域标识类型为服务区。“TA(跟踪区)”：表示该区域标识类型为跟踪区。 默认值：无 |
| MCC    | 移动国家码  | 可选必选说明：必选参数 参数含义：待删除的移动国家码的信息。 取值范围：位数为3的十进制数字字符串 默认值：无                                                                                   |
| MNC    | 移动网号   | 可选必选说明：必选参数 参数含义：待删除的移动网号的信息。 取值范围：位数为2或3的十进制数字字符串 默认值：无                                                                                  |
| LAC    | 位置区域码  | 可选必选说明：条件必选参数 参数含义：待删除的位置区域码的信息。 前提条件：该参数在“IDTYPE(标识类型)”设置为“LA(位置区)”、“RA(路由区)”或“SA(服务区)”时生效。 取值范围：0x0000~0xFFFF 默认值：无                     |
| RAC    | 路由区域码  | 可选必选说明：条件必选参数 参数含义：待删除的路由区域码的信息。 前提条件：该参数在“IDTYPE(标识类型)”设置为“RA(路由区)”时生效。 取值范围：0x00~0xFF 默认值：无                                             |
| SAC    | 服务区域码  | 可选必选说明：条件必选参数 参数含义：待删除的服务区域码的信息。 前提条件：该参数在“IDTYPE(标识类型)”设置为“SA(服务区)”时生效。 取值范围：0x0000~0xFFFF 默认值：无                                         |
| TAC    | 跟踪区域码  | 可选必选说明：条件必选参数 参数含义：待删除的跟踪区域码的信息。 前提条件：该参数在“IDTYPE(标识类型)”设置为“TA(跟踪区)”时生效。 取值范围：0x0000~0xFFFF 默认值：无                                         |

#### 使用实例

删除一条区域码为0x1234，标识类型为位置区，移动国家码为123，移动网号为03，位置区域码为1的记录：

RMV ZC: ZC="0x1234", IDTYPE=LA, MCC="123", MNC="03", LAC="1";
