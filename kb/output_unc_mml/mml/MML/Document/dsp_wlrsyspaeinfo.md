# 显示系统PAE信息（DSP WLRSYSPAEINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示系统PAE信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

显示系统PAE信息：

```
DSP WLRSYSPAEINFO:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
FEI PID     Partner状态      TB high    TB low    TP      状态     剩余时间      PAE延时定时器

0x7f4661    Avail            0          64        4098    S        0              FALSE
0x7f4666    Avail            0          65        4098    S        0              FALSE
(结果个数 = 2)
---    END
```

#### 输出结果说明

| 输出项名称     | 输出项解释          |
|:----------|:---------------|
| FEI PID   | 用于表示FEI PID。   |
| Partner状态 | 用于表示Partner状态。 |
| TB high   | 用于表示TB high。   |
| TB low    | 用于表示TB low。    |
| TP        | 用于表示TP。        |
| 状态        | 用于表示状态。        |
| 剩余时间      | 用于表示剩余时间。      |
| PAE延时定时器  | 用于表示PAE延时定时器。  |
