# 增加基于APN的QoS策略(ADD QOSPLCYBYAPN)

#### 命令功能

**适用网元：MME**

该命令用于增加一条QoS策略配置，制定特定用户群基于APN的QoS策略。

#### 注意事项

- 该命令执行后对于新接入的EPS承载立即生效。如果当前用户已经激活了EPS承载，该命令的限制会在用户下一次会话管理业务流程中生效。

- 本命令最大记录数为1024。

当

“用户范围”

设置为

“IMSI\_PREFIX（指定IMSI前缀）”

，使用时按照IMSI最长匹配进行查询，相同IMSI前缀的

“APNNI（APNNI）”

配置不能相同。在IMSI最长匹配的记录中，如果有

“APNNI（APNNI）”

匹配的记录，使用该记录的配置；如果没有

“APNNI（APNNI）”

匹配的记录，则查找IMSI次长匹配的记录。如果IMSI和APNNI的组合同时匹配到多条记录，

“IMSI前缀”

长度不相等时，使用

“IMSI前缀”

最长匹配的记录；

“IMSI前缀”

长度相等时，使用

“APNNI”

非\*的记录。例如用户123030000000001使用HUAWEI1.COM，在表1 示例1所示场景下，匹配到记录2；在表2 示例2所示场景下，匹配到记录1；在表3 示例3所示场景下，匹配到记录2。

manage-ug；system-ug

#### 网管用户权限

#### 参数说明

| 参数标识            | 参数名称                 | 参数说明                                                                                                                                                                                                                                                                                                                                                                             |
|:----------------|:---------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RATTYPE         | RAT类型                | 可选必选说明：必选参数 参数含义：该参数用于指定用户的接入类型，系统优先匹配与当前用户所处网络类型相同的配置数据，当相同RAT类型配置中不包含该用户时，再进行“ALL”类型的匹配。 数据来源：整网规划 取值范围：“ALL(ALL)”“GERAN(GERAN)”“UTRAN(UTRAN)”“E-UTRAN(E-UTRAN)”“NB-IoT(NB-IoT)” 默认值：“E-UTRAN(E-UTRAN)”                                                                                                                                                                        |
| SUBRANGE        | 用户范围                 | 可选必选说明：必选参数 参数含义：该参数用于指定基于APN的QoS策略配置的用户范围。 数据来源：整网规划 取值范围： “IMSI_PREFIX(指定IMSI前缀)”：指网络中与指定的IMSI前缀匹配的用户。“HOME_USER(本网用户)”：指网络中的本网签约用户。“FOREIGN_USER(外网用户)”：指网络中的漫游用户。“ALL_USER(所有用户)”：指网络中的所有用户。 默认值：“IMSI_PREFIX(指定IMSI前缀)” 配置原则：“SUBRANGE（用户范围）”的优先级从高到低为：“IMSI_PREFIX（指定IMSI前缀）”，“FOREIGN_USER（外网用户）”或“HOME_USER（本网用户）”，“ALL_USER（所有用户）”。系统优先查找高优先级的配置记录，如果查找不到，再查找低优先级的配置记录。 |
| NOID            | 运营商标识                | 可选必选说明：条件必选参数 参数含义：该参数用于指定运营商标识。 前提条件：该参数在“SUBRANGE（用户范围）”配置为“FOREIGN_USER（外网用户）”或“HOME_USER（本网用户）”后生效。 对于外网用户，该参数用于指定与互联PLMN签订漫游协议的本局运营商标识，对于本网用户，该参数是本网用户对应的运营商标识。 数据来源：整网规划 取值范围：0～64，128～254。 默认值：无 配置原则：若该参数需要配置为0或128～254之间的值时，须先在ADD MNO中配置取值相同的“MNOID”参数。若该参数需要配置为1～64之间的值时，须先在ADD MVNO中配置取值相同的“MVNOID”参数。                                                               |
| IMSIPRE         | IMSI前缀               | 可选必选说明：条件必选参数 参数含义：该参数用于指定进行匹配的IMSI前缀。系统根据该参数值对用户的IMSI进行匹配，从而区分不同的用户群。 前提条件：该参数在“SUBRANGE（用户范围）”配置为“IMSI_PREFIX（指定IMSI前缀）”后生效。 数据来源：整网规划 取值范围：5~15位十进制数字字符串 默认值：无                                                                                                                                                                                                                |
| APNNI           | APNNI                | 可选必选说明：必选参数 参数含义：该参数用于指定APNNI。 数据来源：整网规划 取值范围：1～62位字符串 默认值：无 配置原则：APN网络标识地址由一个或多个LABEL构成，各LABEL间用“.”间隔。每个LABEL的构成字符只能是字母A～Z或a～z、数字0～9和中划线“-”，字母不区分大小写。APN网络标识地址不能以“rac”、“lac”、“sgsn”或“rnc”开头，不能以“.gprs”结尾。符号“*”表示通配符，即不限制APNNI。 如果APNNI为“*”，表示该记录适用于所有的APNNI，否则该记录适用于指定的APNNI记录。                                                                                                 |
| NONGBRPLCY      | NonGBR承载QOS是否受本地策略控制 | 可选必选说明：可选参数 参数含义：该参数用于指定用户QOS是否受ADD QOSCAP配置控制。 数据来源：整网规划 取值范围： “NO(否)”“YES(是)” 默认值：“YES(是)”  说明： 运营商希望部分用户不受ADD QOSCAP控制时，可以将该参数配置为“NO（否）”，例如对所有漫游用户QOS做限制，但是不希望对VoLTE的业务做限制。 ADD QOSCAP配置的“UEAMBRULK”和“UEAMBRDLK”不受此参数影响。                                                                                                                                                      |
| QCIPLCY         | 基于QCI的QOS是否受本地策略控制   | 可选必选说明：可选参数 参数含义：该参数用于指定用户QOS是否受ADD QOSCAPBYQCI配置控制。 数据来源：整网规划 取值范围： “NO(否)”“YES(是)” 默认值：“YES(是)”  说明： 运营商希望部分用户不受ADD QOSCAPBYQCI控制时，可以将该参数配置为“NO（否）”，例如对所有漫游用户QOS做限制，但是不希望对VoLTE的业务做限制。                                                                                                                                                                                         |
| GBRPLCY         | GBR承载QOS是否受本地策略控制    | 可选必选说明：可选参数 参数含义：该参数用于指定用户QOS是否受ADD QOSCAPGBR配置控制。 数据来源：整网规划 取值范围： “NO(否)”“YES(是)” 默认值：“YES(是)”  说明： 运营商希望部分用户不受ADD QOSCAPGBR控制时，可以将该参数配置为“NO（否）”，例如对所有漫游用户QOS做限制，但是不希望对VoLTE的业务做限制。                                                                                                                                                                                             |
| REJSPECQCI      | 是否控制特定QCI的专载建立       | 可选必选说明：可选参数 参数含义：该参数用于指定用户是否拒绝某一特定QCI的专载建立。 数据来源：整网规划 取值范围： “NO(否)”“YES(是)” 默认值：“NO(否)”  说明： 运营商希望拒绝特定QCI（如QCI=2）的专载建立时，可以将该参数配置为“YES(是)”。 该参数仅用于测试场景，不建议现网使用。如需使用该功能，请联系华为技术支持。                                                                                                                                                                                                 |
| QCI             | QCI值                 | 可选必选说明：条件必选参数 参数含义：该参数表示用户请求或网关下发的GBR承载的QCI。 前提条件：该参数在“REJSPECQCI（是否控制特定QCI的专载建立）”配置为“YES（是）”后生效。 数据来源：整网规划 取值范围：1~4 默认值：无                                                                                                                                                                                                                                                       |
| GBRREJNASCAUSE  | 拒绝GBR承载建立NAS原因值      | 可选必选说明：条件可选参数 参数含义：该参数指定了系统因为QoS策略拒绝UE请求的GBR承载资源建立时使用的NAS原因值。 前提条件：该参数在“REJSPECQCI（是否控制特定QCI的专载建立）”配置为“YES（是）”后生效。 数据来源：整网规划 取值范围：1~127 默认值：37  说明： 系统作为MME，在发送给UE的Bearer Resource Allocation Reject消息的ESM Cause信元中携带该原因值，请参见3GPP TS 24.301。                                                                                                                                     |
| GBRGTPCREJCAUSE | 拒绝GBR承载建立GTPC原因值     | 可选必选说明：条件可选参数 参数含义：该参数指定了系统因为QoS策略拒绝网络侧请求的GBR承载建立时使用的GTPC原因值。 前提条件：该参数在“REJSPECQCI（是否控制特定QCI的专载建立）”配置为“YES（是）”后生效。 数据来源：整网规划 取值范围：1~255 默认值：88  说明： 系统作为MME，在发送给S-GW/P-GW的Create Bearer Response消息的Cause信元中携带该原因值，请参见3GPP TS 29.274。                                                                                                                                             |

#### 使用实例

增加一条基于APN的QoS策略配置，对于“RAT类型”为“E-UTRAN”，“用户范围”为“IMSI\_PREFIX”，“IMSI前缀”为“3080107000”（即IMSI号范围在308010700000000~308010700099999内），“APNNI”为“HUAWEI1.COM”的用户，设置其QoS不受**ADD QOSCAP**、**ADD QOSCAPBYQCI**、**ADD QOSCAPGBR**的控制，且不允许建立“QCI”为“2”的专载。

```
ADD QOSPLCYBYAPN: RATTYPE=E-UTRAN, SUBRANGE=IMSI_PREFIX, IMSIPRE="3080107000", APNNI="HUAWEI1.COM", NONGBRPLCY=NO, QCIPLCY=NO, GBRPLCY=NO, REJSPECQCI=YES, QCI=2;
```
