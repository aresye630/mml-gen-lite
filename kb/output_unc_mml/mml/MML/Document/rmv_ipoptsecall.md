# 删除IP全局选项安全配置（RMV IPOPTSECALL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除IP全局选项安全配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                              |
|:---------|:-------|:----------------------------------------------------------------------------------|
| SWITCHOP | IP过滤规则 | 可选必选说明：必选参数 参数含义：该参数表明IP全局报文过滤规则状态。 数据来源：本端规划 取值范围：枚举类型。 permit：允许。deny：拒绝。 默认值：无 |

#### 使用实例

删除IP全局选项安全配置：

```
RMV IPOPTSECALL:SWITCHOP=permit;
```
