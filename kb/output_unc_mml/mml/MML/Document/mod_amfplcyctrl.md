# 修改AMF策略控制参数（MOD AMFPLCYCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于修改AMF策略控制参数。

## 注意事项

下一次移动性流程生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称                | 参数说明                                                                                                                                                                                                                                                       |
|:-----------|:--------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE   | 用户范围                | 可选必选说明：必选参数  参数含义：该参数用于指定AMF策略功能参数生效的用户范围。  数据来源：全网规划 取值范围： ALL_USER（所有用户）HOME_USER（本网用户）“IMSI_PREFIX（IMSI前缀）”：指定IMSI前缀SPECIFIC_IMSI（指定用户IMSI）  默认值：无  配置原则：  优先级从高到低依次为：“SPECIFIC_IMSI（特定IMSI）”、“IMSI_PREFIX(IMSI前缀)”、“HOME_USER(本网用户)”、“ALL_USER(所有用户)”。 |
| IMSIPRE    | IMSI前缀              | 可选必选说明：该参数在"SUBRANGE"配置为"IMSI_PREFIX"时为条件必选参数。  参数含义：该参数用于系统根据指定用户的IMSI前缀进行匹配，从而区分不同的用户群。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是5~14。  默认值：无  配置原则：  不可与“SPECIFIC_IMSI（特定IMSI）”相同。                                                                                 |
| IMSI       | IMSI                | 可选必选说明：该参数在"SUBRANGE"配置为"SPECIFIC_IMSI"时为条件必选参数。  参数含义：该参数用于指定国际移动用户标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是14~15。  默认值：无  配置原则：  指定单用户范围时使用该参数，不可与“IMSIPRE（IMSI前缀）”相同。                                                                                          |
| AMCRTBYUDM | 基于UDM标识限制创建AM策略偶联开关 | 可选必选说明：可选参数  参数含义：该参数用于设置是否开启基于用户归属UDM标识限制创建AM策略偶联的功能。  数据来源：全网规划 取值范围： “OFF（关闭）”：关闭“ON（打开）”：打开  默认值：无  配置原则：  若运营商期望通过UDM标识区分人网用户和物网用户时，对物网用户群组或特定用户不创建AM策略偶联，可将本参数设置为ON。  该功能需要和ADD AMFPLCYBYUDM命令共同配置实现基于UDM标识限制创建AM策略偶联。                               |
| NISNDBYUDM | 基于UDM标识限制发送运营商标识开关  | 可选必选说明：可选参数  参数含义：该参数用于设置是否开启基于UDM标识限制发送运营商标识的功能。  数据来源：全网规划 取值范围： “OFF（关闭）”：关闭“ON（打开）”：打开  默认值：无  配置原则：  若运营商期望通过UDM标识区分人网用户和物网用户时，对物网用户群组或特定用户限制发送运营商标识，可将本参数设置为ON。  该功能需要和ADD AMFPLCYBYUDM命令共同配置实现基于UDM标识限制发送运营商标识。                                     |

## 使用实例

修改AMF策略控制参数，用户范围为所有用户，基于UDM标识创建AMF策略偶联开关关闭，执行如下命令设置策略参数：

```
MOD AMFPLCYCTRL: SUBRANGE=ALL_USER, AMCRTBYUDM=OFF;
```
