# 设置上送报文总体速率等级（SET SECPOLICYALLPKTLEVEL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 参考信息

#### 命令功能

该命令用来添加上送报文总体速率等级设置。

#### 注意事项

- 该命令执行后立即生效。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| SECRATELEVEL   |
|:---------------|
| high           |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                            |
|:-------------|:-------|:----------------------------------------------------------------------------------------------------------------|
| SECPOLICYID  | 安全策略编号 | 可选必选说明：必选参数 参数含义：策略编号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～30。 默认值：无 配置原则：需要先添加安全策略，下发本MML命令前可使用LST SECPOLICY查看已添加的安全策略。 |
| SECRATELEVEL | 上报速率等级 | 可选必选说明：必选参数 参数含义：上报速率标识。 数据来源：本端规划 取值范围：枚举类型。 low：3000pps。middle：4500pps。high：6000pps。 默认值：无                    |

#### 使用实例

添加上送报文总体速率等级设置：

```
SET SECPOLICYALLPKTLEVEL:SECPOLICYID=1, SECRATELEVEL=middle;
```

#### 参考信息

需要先添加安全策略。
