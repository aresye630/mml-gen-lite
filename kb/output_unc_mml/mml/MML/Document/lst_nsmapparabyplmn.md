# 查询指定PLMN的网络切片映射参数（LST NSMAPPARABYPLMN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询指定PLMN用户的网络切片映射相关参数配置。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                        |
|:-------|:-------|:--------------------------------------------------------------------------------------------|
| MCC    | 移动国家码  | 可选必选说明：可选参数  参数含义：该参数用于配置用户归属PLMN的移动国家码信息。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。  默认值：无  配置原则：无    |
| MNC    | 移动网号   | 可选必选说明：可选参数  参数含义：该参数用于配置用户归属PLMN的移动网号信息。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。  默认值：无  配置原则：无 |

## 使用实例

查询MCC为“123”、MNC为“45”的用户的网络切片映射相关参数策略，执行如下命令：

```
%%LST NSMAPPARABYPLMN: MCC="123", MNC="45";%%
RETCODE = 0  操作成功

结果如下
--------
                 移动国家码  =  123
                   移动网号  =  45
           本地切片映射开关  =  打开
漫游用户CFG切片增强功能开关  =  打开
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称           | 输出项解释                                                                                                                           |
|:----------------|:--------------------------------------------------------------------------------------------------------------------------------|
| 移动国家码           | 该参数用于配置用户归属PLMN的移动国家码信息。                                                                                                        |
| 移动网号            | 该参数用于配置用户归属PLMN的移动网号信息。                                                                                                         |
| 本地切片映射开关        | 该参数用于控制AMF是否为UE提供本地切片映射服务。                                                                                                      |
| 漫游用户CFG切片增强功能开关 | 该参数用于控制当漫游用户在Registration Request消息中Requested NSSAI信元携带的切片映射关系与核心网不一致或者未携带映射关系时，AMF在Registration Accept消息中是否下发Configured NSSAI。 |
