# 增加扩展QCI和标准QCI的映射关系（ADD EXTENDQCIMAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C、SMF、GGSN**

该命令用于配置扩展QCI和标准QCI的映射关系，并用于指定扩展QCI的优先级。

## 注意事项

- 该命令执行后立即生效。

- EXTENDQCI的取值要与STDQOSID中配置的QOSIDSV-QOSIDEV的取值范围互斥。
- 从20.6.2版本之前的版本升级到20.6.2及之后的版本，EXTENDQCIMAP中删除了参数MAPMODE和RESOURCETYPE，并映射到参数STANDARDQCI。映射方式如下：
- (1) 升级前，MAPMODE配置为STANDQCI，则升级后STANDARDQCI不变。
- (2) 升级前，MAPMODE配置为RESTYPE，若RESOURCETYPE配置为GBR，则升级后STANDARDQCI配置为4。
- (3) 升级前，MAPMODE配置为RESTYPE，若RESOURCETYPE配置为NONGBR，则升级后STANDARDQCI配置为9。

- 最多可输入246条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                  |
|:------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------|
| EXTENDQCI   | 扩展QCI的值   | 可选必选说明：必选参数  参数含义：该参数用来指定扩展QCI。  数据来源：全网规划  取值范围：整数类型，取值范围是10~255。  默认值：无  配置原则：  该参数值不能与命令ADD STDQOSID中配置的QoS ID一致。                  |
| STANDARDQCI | 标准QCI的值   | 可选必选说明：必选参数  参数含义：该参数用来指定标准QCI。  数据来源：全网规划  取值范围：整数类型，取值范围是1~255。  默认值：无  配置原则：  该参数值为1~9或命令ADD STDQOSID中配置的QoS ID值，除此以外都属于扩展QCI/5QI。 |
| PRIORITY    | 扩展QCI的优先级 | 可选必选说明：可选参数  参数含义：该参数用来指定EXTENDQCI的优先级，值越小业务转发的优先级越高。  数据来源：全网规划  取值范围：整数类型，取值范围是1~255。  默认值：无  配置原则：  默认值与EXTENDQCI取值保持一致。           |

## 使用实例

运营商可对本地用户定义金、银、铜级别用户及免费用户通过对3GPP定义的“标准QCI”（1～9）进行扩展，将表示同一业务类型的“标准QCI”扩展为具有用户等级的多个“扩展QCI”，而每个“扩展QCI”分别属于不同的用户级别。 不同类型的业务对时延、丢包、带宽及资源分配等有不同的需求，通过对不同的业务类别提供不同的QCI设置，可以达到提供不同业务类别体验质量的目的。 增加“扩展QCI”和“标准QCI”的对应关系，“EXTENDQCI”为“133”，“STANDARDQCI”为“1”，“PRIORITY”为“1”：

```
ADD EXTENDQCIMAP:EXTENDQCI=133,STANDARDQCI=1,PRIORITY=1;
```
