# 显示网关故障信息(DSP GWFAULTINF)

#### 命令功能

**适用网元：MME**

该命令用于查看系统内记录的网关故障信息，包含故障类型、故障时间、故障IP地址。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                 |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------|
| DT     | 查询方式   | 可选必选说明：可选参数 参数含义：该参数用于指定查询方式。 取值范围：“PROCESS_NO(进程标识)” 默认值：无  说明： 如果不设置本参数，则表示查询所有业务进程上故障信息的数目。                       |
| RUNAME | RU名称   | 可选必选说明：条件必选参数 参数含义：该参数用于指定节点的RU名称。该参数可以通过DSP RU命令查询。 前提条件: 该参数在“查询方式”参数配置为“PROCESS_NO(进程标识)”后生效。 取值范围：0～63位字符串 默认值：无 |
| PN     | 进程号    | 可选必选说明：条件必选参数 参数含义：该参数用于指定需要查看SPP进程的进程号。 前提条件: 该参数在“查询方式”参数配置为“PROCESS_NO(进程标识)”后生效。 取值范围：0~20 默认值：无                 |

#### 使用实例

1. 显示所有SPP进程上的故障信息：

   DSP GWFAULTINF:;

   ```
   %%DSP GWFAULTINF:;%%
   RETCODE = 0  操作成功。

   操作结果如下
   ------------
   RU名称           进程号  接口故障个数  网关重启个数

   USN_SP_RU_0064   1       0             0           
   USN_SP_RU_0064   0       0             0           
   (结果个数 = 2)

   ---    END
   ```
2. 显示指定SPP进程上的故障信息：

   DSP GWFAULTINF:DT=PROCESS\_NO, RUNAME="USN\_SP\_RU\_0064", PN=0:;

   ```
   %%DSP GWFAULTINF: DT=PROCESS_NO, RUNAME="USN_SP_RU_0064", PN=0;%%
   RETCODE = 0  操作成功。

   接口故障信息
   ------------
     接口类型  =  S11
     故障时间  =  2014-11-25 21:07:52
   本端IP地址  =  192.168.24.48
   对端IP地址  =  10.10.10.10
   (结果个数 = 1)

   ---    END
   ```

#### 输出结果说明

| 输出项名称   | 输出项解释                                                                                           |
|:--------|:------------------------------------------------------------------------------------------------|
| 接口故障个数  | 参数含义：显示接口故障个数。 取值范围：0~512                                                                       |
| 网关重启个数  | 参数含义：显示网关重启个数。 取值范围：0~512                                                                       |
| 接口类型    | 参数含义：显示故障接口类型（S11或S5接口）。 取值范围： S11(S11)S5(S5)                                                   |
| 网关类型    | 参数含义：显示重启网关类型（S-GW或P-GW重启）。 取值范围： SGW(S-GW)PGW(P-GW)                                            |
| 故障时间    | 参数含义：显示故障发生的时间。 取值范围：日期时间字符串。                                                                   |
| 本端IP地址  | 参数含义：此参数用于显示本端IP地址。 当S11接口故障或S-GW重启时，为MME的S11接口地址； 当S5接口故障或P-GW重启时，为S-GW的S11接口地址。 取值范围：0~64位字符串 |
| 对端IP地址  | 参数含义：此参数用于显示对端IP地址。 当S11接口故障或S-GW重启时，为S-GW的S11接口地址； 当S5接口故障或P-GW重启时，为P-GW的S5接口地址。 取值范围：0~64位字符串 |
