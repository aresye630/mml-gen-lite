# 更新NF注册信息（ACT NFUPDATE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、NRF、NSSF、NCG、SMSF、CBC、CBCF**

该命令用于手动更新NF注册信息。在NF信息更新异常情况下，也可以尝试通过此命令进行手动更新。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                                                                                                                                                                                                   |
|:---------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SWITCHTYPE     | 更新类型   | 可选必选说明：必选参数  参数含义：该参数用于指定更新注册信息的类型。  数据来源：对端协商 取值范围： PUTSWITCH（PUTSWITCH）PATCHSWITCH（PATCHSWITCH）  默认值：无  配置原则： PUTSWITCH(PUTSWITCH)：NF向NRF发起NF信息的全量更新。即使NF只有部分信息修改，也会将全部NF信息推送到NRF。PATCHSWITCH(PATCHSWITCH)：NF向NRF发起NF信息的部分更新。即，只更新NF变更的信息到NRF。为减轻NRF的负担，推荐采用部分更新的方式。 |
| NFINSTANCENAME | NF实例名称 | 可选必选说明：必选参数  参数含义：该参数用于指定要更新注册信息的NF的实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~50。该参数需要与ADD NFPROFILE命令中的NFINSTANCENAME值保持一致。  默认值：无  配置原则：  该参数需要与ADD NFPROFILE命令中的NFINSTANCENAME值保持一致。                                                                                    |

## 使用实例

需要全量更新实例名为AMF\_Instance\_0的NF注册信息：

```
ACT NFUPDATE: SWITCHTYPE=PUTSWITCH, NFINSTANCENAME="AMF_Instance_0";
```
