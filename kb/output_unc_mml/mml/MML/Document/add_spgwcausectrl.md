# 增加SGW-C/PGW-C原因值控制参数（ADD SPGWCAUSECTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SGW-C**

该命令用于增加PGW-C或融合的SGW-C/PGW-C的原因值控制参数。当用户接入PGW-C或融合的SGW-C/PGW-C时，可通过该命令控制SM流程特殊场景下发送的原因值，以满足运营商实现对现网设备兼容性特殊控制的需求。

## 注意事项

- 该命令执行后立即生效。

- 配置下发的原因值可能会对MME或SGW-C行为产生影响，在配置前请参见协议3GPP TS 29.274评估影响。

- 最多可输入18条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

增加会话创建流程，UPF响应超时导致流程拒绝原因值为#26 insufficient resources，执行如下命令：

```
ADD SPGWCAUSECTRL: PROCEDURETYPE=CRT_SES_PROC, CAUSESOURCE=UPF, CAUSEEXPIRATION=26;
```
