# 修改Keychain Key ID的配置（MOD KEYCHAINKEYID）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改Keychain Key ID的各种属性。

#### 注意事项

- 该命令执行后立即生效。
- 为了保证更好的安全性，建议使用SHA-256算法或者HMAC-SHA-256算法。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

修改Keychain ospf Key ID为1的配置，时间模式每周，发送时间修改为每周一到周五，接收时间修改为每周一至周日：

```
MOD KEYCHAINKEYID:KEYCHAINNAME="ospf",KEYID=1,MODE=WEEKLY,SENDWEEKLY=MON-1&TUE-1&WED-1&THU-1&FRI-1,RCVWEEKLY=MON-1&TUE-1&WED-1&THU-1&FRI-1&SAT-1&SUN-1;
```
