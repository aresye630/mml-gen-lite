# 设置HTTP性能参数（SET HTTPPERFPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，可能导致HTTP模块性能受到影响，严重时可能造成业务受损，请谨慎操作并联系华为技术人员支持。

该命令用于设置HTTP性能参数。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

|   SELFHOLDFCTHRES |   SLEEPTIME |   BATCHRCVNUM |
|------------------:|------------:|--------------:|
|                85 |         100 |            16 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称             | 参数说明                                                                                                                                                      |
|:----------------|:-----------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
| SELFHOLDFCTHRES | HTTP自保流控起控阈值     | 可选必选说明：可选参数  参数含义：该参数用于配置HTTP自保流控起控阈值。  数据来源：本端规划  取值范围：整数类型，取值范围是80~85，单位是百分比。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST HTTPPERFPARA查询当前参数配置值。  配置原则：无   |
| SLEEPTIME       | HTTP收包线程睡眠时间（微秒） | 可选必选说明：可选参数  参数含义：该参数用于配置HTTP收包线程睡眠时间。  数据来源：本端规划  取值范围：整数类型，取值范围是50~300。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST HTTPPERFPARA查询当前参数配置值。  配置原则：无         |
| BATCHRCVNUM     | 批量处理包数阈值         | 可选必选说明：可选参数  参数含义：该参数用于配置HTTP进程批量包数处理数量阈值。  数据来源：本端规划  取值范围：整数类型，取值范围是1~16，单位是包数。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST HTTPPERFPARA查询当前参数配置值。  配置原则：无 |

## 使用实例

设置HTTP性能参数：

```
%%SET HTTPPERFPARA: SELFHOLDFCTHRES=85, SLEEPTIME=100, BATCHRCVNUM=16;%%
RETCODE = 0  操作成功

---    END
```
