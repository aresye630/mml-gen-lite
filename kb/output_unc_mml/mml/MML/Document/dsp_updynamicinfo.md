# 显示UP节点动态信息（DSP UPDYNAMICINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C、SMF、GGSN**

该命令用于显示UP节点动态信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识           | 参数名称    | 参数说明                                                                                                                                |
|:---------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------|
| QUERYTYPE      | 查询类型    | 可选必选说明：必选参数  参数含义：该参数用于指示查询UP动态信息或根据UPF实例名称查询指定UPF的动态信息。  数据来源：本端规划 取值范围： ALL（所有）NFINSTANCENAME（UPF实例名称）  默认值：无  配置原则：无             |
| NFINSTANCENAME | UPF实例名称 | 可选必选说明：该参数在"QUERYTYPE"配置为"NFINSTANCENAME"时为条件必选参数。  参数含义：该参数用于表示UPF的实例名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

- 查询实例名为upf1的UPF的动态信息，需要执行以下命令：

  ```
  %%DSP UPDYNAMICINFO: QUERYTYPE=NFINSTANCENAME, NFINSTANCENAME="upf1";%%
  RETCODE = 0  操作成功

  结果如下
  ----------------
            UPF实例名称  =  upf1
                  LCI值  =  0
                  OCI值  =  0
            OCI解除时间  =  1970-01-01 00:00:00
            故障APN列表  =  []
            故障RAN列表  =  []
           智能单元状态  =  正常
       质差智能业务状态  =  正常
       体验智能业务状态  =  正常
            UPF服务信息  =  TimeStamp:2024-05-23T15:59:27+08:00 ValueSessionNum:20 UpServices:[ServiceType:Relay Capacity:100 Load:20 Status:Fault]
  (结果个数 = 1)

  ---    END
  ```
- 查询所有UPF的动态信息，需要执行以下命令：

  ```
  %%DSP UPDYNAMICINFO: QUERYTYPE=ALL;%%
  RETCODE = 0  操作成功

  结果如下
  ----------------
  UPF实例名称     LCI值    OCI值    OCI解除时间           故障APN列表       故障RAN列表    智能单元状态    质差智能业务状态    体验智能业务状态    UPF服务信息
  upf1            0        0        1970-01-01 00:00:00   []                []             正常            正常                正常                TimeStamp:2024-05-23T15:59:27+08:00 ValueSessionNum:0 UpServices:[]
  upf2            0        0        1970-01-01 00:00:00   []                []             正常            正常                正常                TimeStamp:2024-05-23T15:59:27+08:00 ValueSessionNum:0 UpServices:[]                    
  (结果个数 = 2)

  ---    END
  ```

## 输出结果说明

| 输出项名称       | 输出项解释                                                                                           |
|:------------|:------------------------------------------------------------------------------------------------|
| UPF实例名称     | 该参数用于表示UPF的实例名。                                                                                 |
| LCI值        | 该参数用于表示UPF上报的LCI值。                                                                              |
| OCI值        | 该参数用于表示UPF上报的OCI值。                                                                              |
| OCI解除时间     | 该参数用于表示UPF的OCI值的解除时间。                                                                           |
| 故障APN列表     | 该参数用于表示UPF上报的故障APN。                                                                             |
| 故障RAN列表     | 该参数用于表示UPF上报的故障RAN。                                                                             |
| UPF智能单元状态   | 该参数用于表示UPF智能单元状态。 取值说明： “NORMAL（正常）”：UPF智能单元状态正常“ABNORMAL（异常）”：UPF智能单元状态异常                      |
| UPF质差智能业务状态 | 该参数用于表示UPF质差智能业务状态。 取值说明： “UNKNOWN（无效）”：智能UPF业务无效“NORMAL（正常）”：智能UPF业务正常“OVERLOAD（过载）”：智能UPF业务过载 |
| UPF体验智能业务状态 | 该参数用于表示UPF体验智能业务状态。 取值说明： “UNKNOWN（无效）”：智能UPF业务无效“NORMAL（正常）”：智能UPF业务正常“OVERLOAD（过载）”：智能UPF业务过载 |
| UPF服务信息     | 该参数用于表示UPF上报的服务信息。                                                                              |
