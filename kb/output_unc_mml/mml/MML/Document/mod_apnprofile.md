# 修改APN配置（MOD APNPROFILE）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限

- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用于修改APN的APN的概要信息，如QOS，计费属性等。

当用户使用GPRS/UMTS接入网接入并进行PDP激活时，如果使用ADD SMACTCTRL命令纠正用户激活的APNNI为回落APNNI时，如果回落APNNI未签约，可以使用本配置修改该APN的概要信息。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

修改一条APNNI的概要配置，APNNI为INTERNET，QoS优先级为高优先级，QoS延迟等级为DC1，可以用如下命令：

```
MOD APNPROFILE: APNNI="INTERNET", PRI=HPRI, DC=DC1;
```
