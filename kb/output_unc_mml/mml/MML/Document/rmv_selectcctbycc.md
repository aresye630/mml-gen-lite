# 删除基于CC配置融合计费模板处理（RMV SELECTCCTBYCC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF、SGW-C**

该命令用于删除基于CC配置融合计费模板处理。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称                   | 参数说明                                                                                                                                                                                   |
|:--------|:-----------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CCTYPE  | CC类型                   | 可选必选说明：必选参数  参数含义：该参数用于指定计费属性。  数据来源：全网规划 取值范围： DEFAULT（未指定Charge Characteristic的值）VALUE（指定Charge Characteristic的值）  默认值：无  配置原则：无                                                     |
| CCVALUE | Charge Characteristic值 | 可选必选说明：该参数在"CCTYPE"配置为"VALUE"时为条件必选参数。  参数含义：该参数用于指定特殊的CC值。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~6。该参数为十六进制数据类型，仅支持输入0x/X、a-f/A-F 、0-9，允许不输入0x前缀，字母不区分大小写，取值范围0x0000~0xFFFF。  默认值：无  配置原则：无 |

## 使用实例

删除基于CC值为1234配置融合计费模板：

```
RMV SELECTCCTBYCC: CCTYPE=VALUE, CCVALUE="1234";
```
