## 命令功能

**适用NF：AMF**

该命令用于设置AMF的软件参数信息。

## 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                                                                                                      |
|:-----------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DT         | 数据类型    | 可选必选说明：必选参数  参数含义：该参数表示软件参数的数据类型。  数据来源：本端规划 取值范围： Dw（双字）Byte（字节）  默认值：无。  配置原则：  DT参数暂不支持Byte（字节）。                                                                       |
| DWORDNUM   | Dword索引 | 可选必选说明：该参数在"DT"配置为"Dw"时为条件必选参数。  参数含义：该参数表示Dword类型软件参数的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~1500。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST AMFSOFTPARA查询当前参数配置值。  配置原则：无      |
| DWORDVALUE | Dword值  | 可选必选说明：该参数在"DT"配置为"Dw"时为条件必选参数。  参数含义：该参数表示Dword类型软件参数的值。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST AMFSOFTPARA查询当前参数配置值。  配置原则：无 |

## 使用实例

设置AMF软件参数，数据类型是“Dw”，Dword索引是“1”，Dword值是“3”

```
SET AMFSOFTPARA: DT=Dw, DWORDNUM=1, DWORDVALUE=3;
```
