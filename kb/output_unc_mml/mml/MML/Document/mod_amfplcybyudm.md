# 修改基于UDM标识控制创建AMF策略（MOD AMFPLCYBYUDM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于修改基于UDM标识控制创建AMF策略。

## 注意事项

下一次移动性流程生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                                                                                                     |
|:-------------|:-------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UDMIDTYPE    | UDM标识类型      | 可选必选说明：必选参数  参数含义：该参数用于指定UDM标识类型。  数据来源：全网规划 取值范围： UDMINSTANCEID（UDM实例标识）  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                 |
| UDMINSTID    | UDM实例标识      | 可选必选说明：该参数在"UDMIDTYPE"配置为"UDMINSTANCEID"时为条件必选参数。  参数含义：该参数用于指定UDM实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~36。  默认值：无  配置原则：  参数必须满足以下约束规则：1.如果输入为uuid格式（格式例如：a6a61c6f-0d3a-4221-b1da-424eda3ccf67）只能为A-F、a-f、0-9的字符。2.如果输入不为uuid格式，长度不能超过18且不允许输入只包含0-9和“.”的字符串，例如：1.2.3.4、不允许输入只包含十六进制数（A-F、a-f、0-9）和“:”的字符串，例如：1::2、FBFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。3.该参数大小写不敏感。 |
| MATCHPLCY    | 匹配策略         | 可选必选说明：该参数在"UDMIDTYPE"配置为"UDMINSTANCEID"时为条件可选参数。  参数含义：该参数用于指定UDM实例标识的匹配策略。 本参数取值MATCH_RANGE匹配策略为预埋取值，功能暂未实现。  数据来源：全网规划 取值范围： MATCH_ALL（全匹配）MATCH_RANGE（区间匹配）  默认值：无  配置原则：无                                                                                                                                                                                           |
| UDMINSTBEGIN | 区域标识起始位置     | 可选必选说明：该参数在"MATCHPLCY"配置为"MATCH_RANGE"时为条件必选参数。  参数含义：该参数用于指定UDM实例标识的起始字符位置。假设其取值为N,N表示NF Instance ID中node标识中的第N个字符。 当“匹配策略”设置为MATCH_RANGE时，该参数配置才生效。 本参数为预留参数，功能暂未实现。  数据来源：全网规划  取值范围：整数类型，取值范围是1~12。  默认值：无  配置原则：  UDM的NF Instance ID需要遵守UUID版本4的格式，运营商需要在node部分中使用固定的字符表示指定的区域。系统会针对UDM的NF Instance ID中node部分的第UDMINSBEGIN~UDMINSTEND个字符进行匹配。                       |
| UDMINSTEND   | 区域标识终止位置     | 可选必选说明：该参数在"MATCHPLCY"配置为"MATCH_RANGE"时为条件必选参数。  参数含义：该参数用于指定UDM实例标识的终止字符位置。假设其取值为N，N表示NF Instance ID中node标识中的第N个字符。 当“匹配策略”设置为MATCH_RANGE时，该参数配置才生效。 本参数为预留参数，功能暂未实现。  数据来源：全网规划  取值范围：整数类型，取值范围是1~12。  默认值：无  配置原则：  该参数的取值需要大于等于“区域标识起始位置”，请参见“区域标识起始位置”参数的说明。                                                                                                        |
| AMCRTSW      | 限制创建AM策略偶联开关 | 可选必选说明：可选参数  参数含义：该参数用于设置是否开启基于用户归属UDM标识限制创建AM策略偶联的功能。  数据来源：全网规划 取值范围： “YES（是）”：是“NO（否）”：否  默认值：无  配置原则：  若运营商期望通过UDM标识区分人网用户和物网用户时，对物网用户群组或特定用户限制创建AM策略偶联，可将本参数设置为YES。  该功能需要和ADD AMFPLCYCTRL命令共同配置实现基于UDM标识限制创建AM策略偶联。                                                                                                                                                |
| NISNDSW      | 限制发送运营商标识开关  | 可选必选说明：可选参数  参数含义：该参数用于设置是否开启基于UDM标识限制发送运营商标识的功能。  数据来源：全网规划 取值范围： “YES（是）”：是“NO（否）”：否  默认值：无  配置原则：  若运营商期望通过UDM标识区分人网用户和物网用户时，对物网用户群组或特定用户限制发送运营商标识，可将本参数设置为YES。  该功能需要和ADD AMFPLCYCTRL命令共同配置实现基于UDM标识限制发送运营商标识。                                                                                                                                                       |

## 使用实例

运营商希望修改本网的物网用户不开启AMF策略相关功能，且人网和物网用户能通过特定的UDM标识区分时，配置物网对应的UDM识别标识为"12345678-1234-1234-1234-123456789123"，执行如下命令：

```
MOD AMFPLCYBYUDM: UDMIDTYPE=UDMINSTANCEID, UDMINSTID="12345678-1234-1234-1234-123456789123", AMCRTSW=YES;
```
