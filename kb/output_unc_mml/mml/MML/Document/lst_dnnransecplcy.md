# 查询DNN RAN侧安全策略（LST DNNRANSECPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF**

该命令用于查询DNN的RAN侧用户面安全策略。策略用于明确是否需要对RAN侧用户面进行完整性保护和加密保护。

## 注意事项

当根据DNN、SST和SD能查询到本配置时，使用本配置的策略，否则使用SET RANSECPLCY中的策略。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                         |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DNN    | 数据网络名称 | 可选必选说明：可选参数  参数含义：该参数用于表示数据网络名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无  配置原则：  该参数使用ADD APN命令配置生成。 |
| NSIDX  | 网络切片索引 | 可选必选说明：可选参数  参数含义：该参数用于指定网络切片索引。  数据来源：全网规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：  本参数通过ADD PLMNNS命令进行配置。                                                                                                              |

## 使用实例

查询基于DNN的RAN侧用户面安全策略，执行如下命令：

```
%%LST DNNRANSECPLCY: DNN="huawei.com", NSIDX=0;%%
RETCODE = 0  操作成功

结果如下
--------
      数据网络名称  =  huawei.com
    完整性保护策略  =  优先从签约数据获取
本地完整性保护指示  =  优选
 完整性保护PDU策略  =  限速
      加密保护策略  =  优先从签约数据获取
  本地加密保护指示  =  优选
      网络切片索引  =  0
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称      | 输出项解释                                                     |
|:-----------|:----------------------------------------------------------|
| 数据网络名称     | 该参数用于表示数据网络名称。                                            |
| 完整性保护策略    | 该参数用于指定RAN侧用户面完整性保护策略。                                    |
| 本地完整性保护指示  | 该参数是本地配置，用于指示RAN侧是否要执行用户面完整性保护策略。                         |
| 完整性保护PDU策略 | 该参数用于指定完整性保护指示为“REQUIRED”，但是会话AMBR大于UE支持的完整性保护最大速率时的处理策略。 |
| 加密保护策略     | 该参数用于指定RAN侧用户面加密保护策略。                                     |
| 本地加密保护指示   | 该参数是本地配置，用于指示RAN侧是否要执行用户面加密保护策略。                          |
| 网络切片索引     | 该参数用于指定网络切片索引。                                            |
