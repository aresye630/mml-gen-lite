# 增加5G LAN组签约信息（ADD NGLANGRPSUB）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于增加5G LAN组签约信息。

## 注意事项

- 该命令执行后立即生效。

- 一个5G LAN组ID只能对应一个DNN，不同5G LAN组ID可以对应同一个DNN。
- 仅在通过ADD APNSMCOMFUNC配置VnGroupID来源为Radius时，才对Radius下发的VnGroupID进行校验。

- 最多可输入1000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                     |
|:--------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GROUPID | 5G LAN组ID | 可选必选说明：必选参数  参数含义：该参数用于指定5G LAN群组的ID。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是18~37。大小写不敏感且全局唯一。GROUPID以连字号分为4段，形式为GroupServiceID-MCC-MNC-LocalGroupID。其中，GroupServiceID长度为8，只能输入数字或者范围为A-F或a-f的字母；MCC长度为3，只能输入数字；MNC长度为2~3，只能输入数字；LocalGroupID长度为2~20的偶数，只能输入数字或者范围为A-F或a-f的字母。例如，A0000001-460-003-01，A0000001-460-003-A000000001。  默认值：无  配置原则：无 |
| DNN     | DNN       | 可选必选说明：必选参数  参数含义：该参数用于指定5G LAN群组支持的DNN，即用户请求的DNN。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~31。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&amp;”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无  配置原则：  该参数使用ADD APN命令配置生成。                                                                                       |

## 使用实例

增加5G LAN组签约信息，“5G LAN组ID”为“A0000001-460-003-01”，“DNN”为“huawei.com”。

```
ADD NGLANGRPSUB: GROUPID="A0000001-460-003-01",DNN="huawei.com";
```
