# 设置手工倒换开关（SET MANUSWAPSW）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

当NRF服务化接口阻断控制开关设置为开启时，NRF服务化接口被阻断，导致NRF业务不可用。

**适用NF：NRF**

该命令用于设置手工倒换开关，通过阻断NRF服务化接口，隔绝NRF与NF之间的业务交互。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| NRFSBILINKBKSW   |
|:-----------------|
| FUNC_OFF         |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称           | 参数说明                                                                                                                                                              |
|:---------------|:---------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NRFSBILINKBKSW | NRF服务化接口阻断控制开关 | 可选必选说明：必选参数  参数含义：该参数用于表示是否阻断NRF服务化接口。开关打开后，将导致现有的NRF服务化接口链路断连，并且阻止新的接口链路建立，NRF整体业务中断。  数据来源：本端规划 取值范围： “FUNC_ON（打开）”：功能开关打开“FUNC_OFF（关闭）”：功能开关关闭  默认值：无。  配置原则：无 |

## 使用实例

运营商想要进行容灾倒换操作，需要断开NRF与NF之间的业务交互，执行如下命令：

```
SET MANUSWAPSW: NRFSBILINKBKSW=FUNC_ON;
```
