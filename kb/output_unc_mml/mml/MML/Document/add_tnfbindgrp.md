# 增加目标NF实例绑定组（ADD TNFBINDGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、NCG、SMSF、CBC、CBCF**

该命令用于增加目标NF实例绑定目标NF组的配置。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入4096条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                |
|:------------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TNFGRPINDEX | 目标NF组索引  | 可选必选说明：必选参数  参数含义：本参数用于指定目标NF组索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~511。  默认值：无  配置原则：  本参数需要与ADD TNFGRP命令中的TNFGRPINDEX值保持一致。                                            |
| TNFINSINDEX | 目标NF实例索引 | 可选必选说明：必选参数  参数含义：本参数用于指定目标NF实例索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~2047。  默认值：无  配置原则：  本参数需要与ADD TNFINS命令中的TNFINSINDEX值保持一致。                                          |
| PRIORITY    | 优先级      | 可选必选说明：可选参数  参数含义：本参数用于指定目标NF的优先级（与其他同类型NF实例相比）。在NF选择过程中，NF会选择高优先级的NF，如果两个或多个NF的优先级一样，NF则会根据“权重”做进一步的判断。  数据来源：全网规划  取值范围：整数类型，取值范围是1~255。值越小优先级越高。  默认值：10  配置原则：无 |
| WEIGHT      | 权重       | 可选必选说明：可选参数  参数含义：本参数用于指定目标NF的相对权重（与其他同类型NF实例相比）。特别地，如果NF权重的绝对值不超过本参数的取值范围，那么本参数可以直接取用权重绝对值。  数据来源：全网规划  取值范围：整数类型，取值范围是1~65535。值越大表示权重越大。  默认值：无  配置原则：无           |

## 使用实例

运营商A需要将索引1的目标NF添加到索引为0的目标NF组中，优先级为1，权重为50。

```
ADD TNFBINDGRP: TNFGRPINDEX=0, TNFINSINDEX=1, PRIORITY=1, WEIGHT=50;
```
