# 查询等价PLMN组成员（LST EPLMNGRPMEM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询等价PLMN组成员。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                        |
|:-------|:---------|:------------------------------------------------------------------------------------------------------------|
| GRPIDX | 等价PLMN组号 | 可选必选说明：可选参数  参数含义：该参数用于标识等价PLMN组，通过命令ADD EPLMNGRP进行配置。  数据来源：本端规划  取值范围：整数类型，取值范围是0~127。  默认值：无  配置原则：无     |
| MCC    | 移动国家码    | 可选必选说明：可选参数  参数含义：该参数用于表示组成等价PLMN的移动国家码信息。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无    |
| MNC    | 移动网号     | 可选必选说明：可选参数  参数含义：该参数用于表示组成等价PLMN的移动网号信息。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无 |

## 使用实例

- 查询系统中“等价PLMN组号”为“0”的等价PLMN成员信息，执行如下命令：

  ```
  %%LST EPLMNGRPMEM: GRPIDX=0;%%
  RETCODE = 0  操作成功

  结果如下
  --------
  等价PLMN组号  =  0
    移动国家码  =  123
      移动网号  =  89
      描述信息  =  add eplmn 12389 for 12345L
  (结果个数 = 1)

  ---    END
  ```
- 查询系统中配置的等价PLMN成员信息，执行如下命令：

  ```
  %%LST EPLMNGRPMEM:;%%
  RETCODE = 0  操作成功

  结果如下
  --------
  等价PLMN组号  =  0
    移动国家码  =  460
      移动网号  =  01
      描述信息  =  NULL
  (结果个数 = 1)

  ---    END
  ```

## 输出结果说明

| 输出项名称    | 输出项解释                                |
|:---------|:-------------------------------------|
| 等价PLMN组号 | 该参数用于标识等价PLMN组，通过命令ADD EPLMNGRP进行配置。 |
| 移动国家码    | 该参数用于表示组成等价PLMN的移动国家码信息。             |
| 移动网号     | 该参数用于表示组成等价PLMN的移动网号信息。              |
| 描述信息     | 该参数用于对等价PLMN组成员的描述，在运维中起助记作用。        |
