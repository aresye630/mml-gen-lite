# 删除APN和Pcrf组关联关系（RMV PCRFGRPBNDAPN）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、GGSN**

此命令用来删除APN和Pcrf组关联关系。

给APN字段赋值，删除指定APN的记录；给APN和DEFAULTFLAG字段赋值，删除满足条件的记录。

如果DEFAULTFLAG字段的值为DEFAULT，删除APN的缺省PCRFGroup；如果DEFAULTFLAG字段的值为IMSI\_MSISDN\_SEG，用于解除PCRF组与APN的绑定关系。不指定号段，删除APN下缺省PCRF组名称绑定关系；指定号段，删除指定号段的PCRF组名称绑定。删除PCRF组与APN的绑定关系，不会影响已经建立的IP-CAN Session状态。如果删除APN绑定的PCRF组之后未重新予以绑定，之后新的IP-CAN Session将因为无法关联到PCRF而建立失败。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称            | 参数说明                                                                                                                                                     |
|:--------------|:----------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN           | APN名称           | 可选必选说明：必选参数 参数含义：该参数用于指定APN名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格。 默认值：无 配置原则：无                                                                      |
| DEFAULTFLAG   | 缺省标记            | 可选必选说明：可选参数 参数含义：该参数用于指定缺省标记。 数据来源：本端规划 取值范围：枚举类型。 DEFAULTIMSI_MSISDN_SEG 默认值：无 配置原则：无                                                                   |
| IMSIMSISDNSEG | IMSI/MSISDN号段名称 | 可选必选说明：条件必选参数 前提条件：该参数在“DEFAULTFLAG”配置为“IMSI_MSISDN_SEG”时为必选参数。 参数含义：该参数用于指定IMSI/MSISDN号段名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

删除APN和Pcrf组关联关系，APN为“aaa”：

```
RMV PCRFGRPBNDAPN:APN="aaa";
```
