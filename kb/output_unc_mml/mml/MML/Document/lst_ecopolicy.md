# 查询全局的CPU调频和休眠策略（LST ECOPOLICY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

使用CPU节能功能时，通过此命令可以查询全局的调频和休眠策略。

## 注意事项

此命令仅在虚机场景下支持。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询全局CPU节能策略：

```
%%LST ECOPOLICY:;%%
RETCODE = 0  操作成功

结果如下
------------------------
CPU休眠策略 = 深休眠
CPU调频策略 = 开启
DPDK核调频策略 = 开启
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称     | 输出项解释                 |
|:----------|:----------------------|
| CPU休眠策略   | 该参数用于指定虚拟机的CPU休眠策略。   |
| CPU调频策略   | 该参数用于指定虚拟机的CPU调频策略。   |
| DPDK核调频策略 | 该参数用于指定虚拟机的DPDK核调频策略。 |
