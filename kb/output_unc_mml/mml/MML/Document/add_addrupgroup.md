# 增加UPF组（ADD ADDRUPGROUP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用来增加UPF组。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入3000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                                           |
|:-----------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UPFGRPNAME | UPF组名称 | 可选必选说明：必选参数  参数含义：该参数用于指定UPF组名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。不支持空格及特殊字符“#”、“$”和“&”等，由“-”、“_”、数字、字母和“.”组成，不能以“.”开头或结尾，不区分大小写。  默认值：无  配置原则：无                                                             |
| UPFGRPTYPE | UPF组类型 | 可选必选说明：可选参数  参数含义：该参数用于指定UPF组的UE地址规划类型。  数据来源：本端规划 取值范围： “Local（本地）”：通过5GC（SMF或UPF）或AAA服务器分配动态地址。“UDM（UDM）”：通过UDM签约分配静态地址。“Radius（RADIUS）”：通过外部AAA服务器分配静态地址。“DHCP（DHCP）”：通过外部DHCP服务器分配静态地址。  默认值：Local  配置原则：无 |

## 使用实例

增加UPF组, 名称是upfgrp1：

```
ADD ADDRUPGROUP: UPFGRPNAME="upfgrp1";
```
