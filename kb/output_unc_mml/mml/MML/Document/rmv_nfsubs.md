# 删除NF的订阅上下文（RMV NFSUBS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、NRF、NSSF、NCG、CBC、CBCF**

该命令用于向NRF发起去订阅流程及删除指定的订阅上下文信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称    | 参数说明                                                                                                                                    |
|:---------------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------|
| SUBSCRIPTIONID | 订阅上下文标识 | 可选必选说明：必选参数  参数含义：该参数用于指定要发起去订阅的NF订阅上下文的标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~512。  默认值：无  配置原则：  该参数需要与DSP NFSUBCONDITIONS命令中的订阅标识值保持一致。 |

## 使用实例

当前NF不再订阅SUBSCRIPTIONID为0相关的订阅条件。

```
RMV NFSUBS: SUBSCRIPTIONID="0";
```
