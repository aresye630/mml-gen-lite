# 设置分片方式（SET IFMTUFRAGMODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来配置Label+IP分片方式。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                 |
|:---------|:-------|:---------------------------------------------------------------------------------------------------------------------|
| FRAGMODE | 分片方式   | 可选必选说明：必选参数 参数含义：该参数用于表示分片方式信息。 数据来源：本端规划 取值范围：枚举类型。 FRACHECKMODE_IP：IP分片方式。FRACHECKMODE_LABELANDIP：标签加IP分片方式。 默认值：无 |

#### 使用实例

配置接口Label+IP分片方式：

```
SET IFMTUFRAGMODE:FRAGMODE=FRACHECKMODE_LABELANDIP;
```
