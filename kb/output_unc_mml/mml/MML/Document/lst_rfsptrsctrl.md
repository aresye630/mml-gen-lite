# 查询RFSP是否传递控制(LST RFSPTRSCTRL)

#### 命令功能

**适用网元：MME**

该命令用于查看RFSP是否传递控制策略。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称    | 参数说明                                                              |
|:-------|:--------|:------------------------------------------------------------------|
| RFSP   | RFSP ID | 可选必选说明：可选参数 参数含义：该参数用于指定RFSP ID。 数据来源：全网规划 取值范围：1~256，65535 默认值：无 |

#### 使用实例

查询RFSP是否传递控制策略：

LST RFSPTRSCTRL:;

```
%%LST RFSPTRSCTRL:;%%
RETCODE = 0  操作成功。

输出结果如下
--------------
            RFSP ID  =  1
       EPS内是否传递  =  否
    EPS到5GS是否传递  =  是
        RFSP是否使用  =  是
        RFSP是否老化  =  否
(结果个数 = 1)

---    END
```
