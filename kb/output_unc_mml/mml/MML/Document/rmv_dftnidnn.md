# 删除控制缺省NI下发的DNN（RMV DFTNIDNN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除控制缺省NI下发的DNN。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                    |
|:---------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DNNKEYWD | DNN关键字 | 可选必选说明：必选参数  参数含义：该参数用于设置下发默认NI策略的特定DNN关键字。 当用户签约的DNN前缀匹配该参数配置的关键字时，则认为该用户需要下发默认NI。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。  默认值：无  配置原则：  字符串类型，输入长度范围是1~63。可输入的字符有字母、十进制数字、“-”和“.”，并且开头和结尾只能是数字或者字母。不能出现连续两个“.”。字母大小写不敏感。 |

## 使用实例

删除关键字为NeedDefaultUElogo的控制默认NI下发的DNN，执行命令如下：

```
RMV DFTNIDNN: DNNKEYWD="NeedDefaultUElogo";
```
