# 查询PDU SET QOS参数（LST PDUSETQOSPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：GGSN、SMF、PGW-C**

该命令用于查询PDU SET QOS参数配置信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识          | 参数名称            | 参数说明                                                                                          |
|:--------------|:----------------|:----------------------------------------------------------------------------------------------|
| PDUSETQOSNAME | PDU SET QOS参数名称 | 可选必选说明：可选参数  参数含义：该参数用于指定PDU SET QOS参数的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。  默认值：无  配置原则：无 |

## 使用实例

查询名称为“name1”的PDU SET QOS参数配置信息。

```
%%LST PDUSETQOSPARA: PDUSETQOSNAME="name1";%%
RETCODE = 0  操作成功

结果如下
--------
PDU SET QOS参数名称  =  name1
    PDU SET QOS时延  =  100
      PDU Set误码率  =  4e-6
    PDU Set处理指示  =  不支持
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称           | 输出项解释                      |
|:----------------|:---------------------------|
| PDU SET QOS参数名称 | 该参数用于指定PDU SET QOS参数的名称。   |
| PDU SET QOS时延   | 该参数用于指定PDU SET QOS的时延参数。   |
| PDU Set误码率      | 该参数用于指定PDU SET QOS的误码率参数。  |
| PDU Set处理指示     | 该参数用于指定PDU SET QOS的处理指示参数。 |
