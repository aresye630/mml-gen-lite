# 设置Tm接口参数(SET TMAPINTF)

- 命令功能
- 注意事项
- 本地用户权限
- 操作用户权限

- 使用实例

#### 命令功能

**适用NF：MME**

本命令用于控制Tm接口的管理参数。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识              | 参数名称           | 参数说明                                                                                                                                                                                                     |
|:------------------|:---------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LPORT             | Tm接口侦听端口号      | 可选必选说明：可选参数 参数含义：本参数用于指定Tm接口的侦听端口号。 数据来源：全网规划 取值范围：20001~65534 系统初始设置值：29527 配置原则：该参数需要和对端协商，避免两端设置不一致。                                                                                                  |
| TUDPCHK           | Tm接口UDP校验功能    | 可选必选说明：可选参数 参数含义：本参数用于控制Tm接口的UDP层启用或关闭校验功能。 数据来源：全网规划 取值范围：“OFF(关闭)”“ON(开启)” 系统初始设置值：ON 配置原则：当需要提升Tm接口消息的传输可靠性，建议将参数设为ON。                                                                                |
| ECHOSIG           | ECHO Request探测 | 可选必选说明：可选参数 参数含义：该参数控制是否发送Echo Request进行路径管理。 数据来源：全网规划 取值范围：“OFF(关闭)”“ON(开启)” 系统初始设置值：ON                                                                                                                |
| TMEI              | ECHO探测间隔（s）    | 可选必选说明：可选参数 参数含义：该参数定义了Tm接口路径上发送Echo Request的间隔时间。 数据来源：本端规划 取值范围：60~3600s 系统初始设置值：60s                                                                                                                   |
| PEERRECOVERYSW    | 对端Recovery处理开关 | 可选必选说明：可选参数 参数含义：该参数用于控制对端Recovery值变化时，是否通知业务层进行处理。 数据来源：全网规划 取值范围：“OFF(关闭)”“ON(开启)” 系统初始设置值：ON                                                                                                          |
| DNSTMPATHFILTERSW | 过滤故障状态的Tm路径开关  | 可选必选说明：可选参数 参数含义：该参数用于针对DNS解析的IP地址列表，是否根据Tm路径状态过滤故障状态的对端地址。当Tm路径不存在时，不进行Tm路径状态的判断。 数据来源：全网规划 取值范围：“OFF(关闭)”“ON(开启)” 系统初始设置值：ON 配置原则：开关开启时，DNS解析结果只使用非故障状态的Tm路径的IP地址列表(目前只支持一个对端IP地址)；开关关闭时，不进行Tm路径状态的判断。 |
| NESTATUSTHRESHOLD | 容灾探测故障门限       | 可选必选说明：可选参数 参数含义：该参数定义了MME主动探测TSN容灾状态的故障门限。MME发起容灾探测，期间持续接收不到TSN的响应，当连续探测周期数大于该门限值时，则认为TSN故障。 数据来源：全网规划 取值范围：1~100 系统初始设置值：4                                                                             |
| SWDURATION        | TSN倒换等待时长（秒）   | 可选必选说明：可选参数 参数含义：TSN发生主备倒换时，MME等待TSN升主通知的时长。 数据来源：全网规划 取值范围：1s~900s 系统初始设置值：120s                                                                                                                         |

#### 使用实例

当现网需要使用宽带集群系统时，本命令用于设置Tm接口的管理参数，可执行此命令：

```
SET TMAPINTF:LPORT=29527;
```
