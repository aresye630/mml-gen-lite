# 删除漫游切片默认映射配置（RMV NSSFDFTNSMAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NSSF**

该命令用于删除漫游切片默认映射配置。

## 注意事项

- 该命令执行后立即生效。

- 由于当前协议标准没有通知AMF变更的机制，当NSSF上配置的切片映射规则发生变更时，需要NSSF管理的所有AMF重新从NSSF获取变更后的切片映射关系。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                     |
|:---------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------|
| CTRLMODE | 控制模式     | 可选必选说明：可选参数  参数含义：该参数用于指定基于用户归属PLMN还是拜访地PLMN进行切片映射。  数据来源：全网规划 取值范围： “VPLMN（拜访地PLMN）”：拜访地PLMN“HPLMN（归属地PLMN）”：归属地PLMN  默认值：VPLMN  配置原则：无 |
| VMCC     | 拜访地移动国家码 | 可选必选说明：该参数在"CTRLMODE"配置为"VPLMN"时为条件必选参数。  参数含义：该参数用于描述拜访地移动国家码。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。3位十进制数。  默认值：无  配置原则：无                     |
| VMNC     | 拜访地移动网号  | 可选必选说明：该参数在"CTRLMODE"配置为"VPLMN"时为条件必选参数。  参数含义：该参数用于描述拜访地移动网号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。2位或者3位十进制数。  默认值：无  配置原则：无              |
| HMCC     | 归属地移动国家码 | 可选必选说明：该参数在"CTRLMODE"配置为"HPLMN"时为条件必选参数。  参数含义：该参数用于指定归属地移动国家码。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。  默认值：无  配置原则：无                            |
| HMNC     | 归属地移动网号  | 可选必选说明：该参数在"CTRLMODE"配置为"HPLMN"时为条件必选参数。  参数含义：该参数用于指定归属地移动网号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。  默认值：无  配置原则：无                         |

## 使用实例

如果需要删除“拜访地移动国家码”为“123”、“拜访地移动网号”为“45”的漫游切片默认映射配置，执行如下命令：

```
RMV NSSFDFTNSMAP: CTRLMODE=VPLMN, VMCC="123", VMNC="45";
```
