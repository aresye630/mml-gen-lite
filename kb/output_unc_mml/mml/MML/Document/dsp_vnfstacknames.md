# 显示网元下所有堆栈名称（DSP VNFSTACKNAMES）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示网元下所有堆栈名称。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

假如操作员想知道网元下有哪些堆栈，可以调用一下命令显示网元下所有的堆栈名称。

```
%%DSP VNFSTACKNAMES:;%%
RETCODE = 0  操作成功

结果如下
--------
堆栈名称               

om-service-fst-manage  
unc-to                 
(结果个数 = 2)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释        |
|:--------|:-------------|
| 堆栈名称    | 该参数用于标识堆栈名称。 |
