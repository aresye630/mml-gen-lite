# NCC模板

- 命令功能

- 基本概念

#### 命令功能

该组命令用于在系统中管理网络能力配置NCC（Network Capability Configuration）模板数据。

运营商根据VLR/SGSN实际所支持的业务和MAP版本，在UDM中设置VLR/SGSN相应的NCC数据，使UDM能根据VLR/SGSN实际所支持的业务和MAP版本，进行相关业务与相关MAP流程的处理，提高UDM与VLR/SGSN网络的兼容性。

VLR/SGSN的NCC模板数据的配置原则是：先执行**ADD NCCTPL**命令定义NCC模板数据，然后通过执行**ADD VLRTYP**/**ADD SGSNTYP**命令给具体的VLR/SGSN设置相应的NCC模板ID，具体请参见VLR类型和SGSN类型。由于存在**VLR类型表**/**SGSN类型表**没有配置所有的VLR/SGSN号码的情况，会出现VLR/SGSN号码与数据库中的**VLR类型表**/**SGSN类型表**不能匹配而无法获取NCC模板数据，这时UDM会按照缺省NCC模板进行业务和MAP流程的处理，具体请参见缺省的NCC模板。

#### 注意事项

无。

#### 基本概念

**PDP地址类型**

NCC模板可以设置PDP地址类型，UDM会将该参数和用户签约的GPRS或EPS业务数据中的PDP地址类型进行比较，来决定如何下发PDP地址。

可以设置的PDP地址类型如下：

- DualStack：双栈地址都允许下发。即完全按照用户签约数据中的PDP地址进行下发。
- IPv4：只允许下发IPv4地址。
  - 当用户签约的PDP地址类型为IPv4时，直接下发。
  - 当用户签约的PDP地址类型为IPv6静态IP时，不下发该PDP地址。
  - 当用户签约的PDP地址类型为IPv6动态IP时，将地址类型改为IPv4动态IP，并进行下发。
  - 当用户签约的PDP地址类型为IPv4IPv6时，只下发其中的IPv4地址。
- IPv6：只允许下发IPv6地址。
  - 当用户签约的PDP地址类型为IPv6时，直接下发。
  - 当用户签约的PDP地址类型为IPv4静态IP时，不下发该PDP地址。
  - 当用户签约的PDP地址类型为IPv4动态IP时，将地址类型改为IPv6动态IP，并进行下发。
  - 当用户签约的PDP地址类型为IPv4IPv6时，只下发其中的IPv6地址。
- IPv4orIPv6：下发IPv4地址或IPv6地址中的一个。
  - 当用户签约的PDP地址类型为IPv4或IPv6时，直接下发。
  - 当用户签约的PDP地址类型为IPv4IPv6时，将IPv4和IPv6的地址拆分，分别进行下发。
- IPv4\_DYN：只允许下发IPv4地址，当用户签约的PDP地址类型为IPv6静态IP时，将地址类型改为IPv4动态IP，并进行下发。其他场景和取值为“IPv4”时相同。
- IPv6\_DYN：只允许下发IPv6地址，当用户签约的PDP地址类型为IPv4静态IP时，将地址类型改为IPv6动态IP，并进行下发。其他场景和取值为“IPv6”时相同。
- IPv4\_ONLY：只允许下发IPv4地址，当用户签约的PDP地址类型为IPv6动态IP时，不下发该PDP地址。其他场景和取值为“IPv4”时相同。
- IPv6\_ONLY：只允许下发IPv6地址，当用户签约的PDP地址类型为IPv4动态IP时，不下发该PDP地址。其他场景和取值为“IPv6”时相同。
