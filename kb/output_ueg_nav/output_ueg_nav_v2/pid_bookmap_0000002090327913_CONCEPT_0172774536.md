# 适配测量对象管理

- 功能描述
- 相关概念
- 注意事项

#### 功能描述

此组命令用于添加、删除、修改、查询适配测量对象。

适配测量对象用于用户需要对业务发放命令进行统计时配置使用。

#### 相关概念

无。

#### 注意事项

无。

#### 配置原则

本命令组无特殊配置原则。

## 目录内容

- 适配测量对象管理
  - 查询适配测量对象(LST ADPSTATOBJ)
  - 修改适配测量对象(MOD ADPSTATOBJ)
  - 删除适配测量对象(RMV ADPSTATOBJ)
  - 添加适配测量对象(ADD ADPSTATOBJ)
