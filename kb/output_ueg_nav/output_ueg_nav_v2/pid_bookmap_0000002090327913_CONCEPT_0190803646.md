# ISDNPRE/GT号码模板

- 功能描述
- 基本概念

#### 功能描述

该组命令用于增加、删除、修改或查询ISDNPRE/GT号码模板，ISDNPRE/GT号码模板支持设置用户ISDN前缀和USSD中心GT号码的对应关系。

该模板可用于USSD控制数据的配置。

#### 基本概念

无。

## 目录内容

- ISDNPRE/GT号码模板
  - 删除ISDNPRE/GT号码模板(RMV ISDNPREGT)
  - 修改ISDNPRE/GT号码模板(MOD ISDNPREGT)
  - 增加ISDNPRE/GT号码模板(ADD ISDNPREGT)
  - 查询ISDNPRE/GT号码模板(LST ISDNPREGT)
