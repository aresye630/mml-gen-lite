# 数据变更通知分发管理

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于管理数据变更通知分发规则的数据信息。

在USCDB的MCI（Message
Call Interface）订阅通知机制中，对于用户数据的变化，在多个FE共用一个BE的情况下，BE会将所有的通知消息都发送到高优先级的FE，导致高优先级的FE和信令资源消耗过高。为了减轻高优先级的FE承载压力，BE提供了一套新的通知机制，可以将特定号段/HLRSN用户的MCI订阅通知消息通过FE标识发送到特定的FE。本组命令用于管理与特定FE标识相关的数据信息，以便于适配BE完成新的订阅通知机制功能。

#### 注意事项

无。

#### 基本概念

**MCI**

MCI（Message Call Interface）是USCDB对外提供的消息通信接口，当USCDB完成用户数据修改后，将变更通知发送给启用了订阅通知的FE。
