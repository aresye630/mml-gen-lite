# Diameter漫游限制模板

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于设置基于Diameter服务节点的漫游限制数据。操作员执行**MOD DIAMRRS**命令使EPS（Evolved Packet System）用户通过签约Diameter漫游限制模板签约Diameter漫游限制业务，签约后运营商不需要添加任何附加网络设备，可以限定用户允许或禁止访问的MME/S4-SGSN/AAA服务范围，从而灵活高效的对用户进行移动性管理。例如，通过设置Diameter服务节点的漫游限制数据，可将用户的访问范围限制在某个地区、某个省或者某个城市。通过该组命令，操作员可以定义一个或者多个Diameter服务节点的主机名或域名，运营商可根据Diameter服务节点的主机名或域名来限制用户接入网络或根据Diameter服务节点的主机名或域名过滤不同的Diameter服务节点，从而限制用户接入网络。即定义Diameter服务节点的黑名单和白名单。

#### 注意事项

无。

#### 基本概念

**Diameter**

Diameter协议是由IETF（Internet
Engineering Task Force）开发的AAA（Authentication，Authorization and Accounting）协议，用于给众多的接入技术提供AAA服务。HSS通过Diameter协议完成EPS用户签约数据和鉴权向量下发，位置信息管理和更新等。

**Diameter服务节点**

Diameter服务节点即Diameter实体所在服务的网络节点。
