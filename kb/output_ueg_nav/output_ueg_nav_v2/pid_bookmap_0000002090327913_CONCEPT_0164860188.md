# 对端设备组配置

- 功能描述
- 注意事项

#### 功能描述

该组命令用于管理对端设备组配置，在设备组内保存的是具体的对端设备配置信息，包含IP类型、IP地址等，用于统计符合该IP的对端消息。对端设备组配置提供设备组的添加、删除、修改、查询功能。

#### 注意事项

对端设备配置组有一条默认记录如下，操作中不要随意修改。

```
对端设备组名称       对端设备组备注  
DEFAULTAPPGROUP      NULL
```

## 目录内容

- 对端设备组配置
  - 增加对端设备组配置(ADD PAPPIPGRP)
  - 查询对端设备组配置(LST PAPPIPGRP)
  - 删除对端设备组配置(RMV PAPPIPGRP)
  - 修改对端设备组配置(MOD PAPPIPGRP)
