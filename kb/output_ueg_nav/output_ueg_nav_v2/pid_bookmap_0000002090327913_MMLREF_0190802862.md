# 电路域数据业务管理

- 命令功能
- 注意事项

## 命令功能

电路域数据业务的管理主要是指对传真业务、GSM承载业务和UMTS承载业务的管理。

## 注意事项

无

## 目录内容

- 电路域数据业务管理
  - GSM承载业务
    - 用户自定义承载能力
      - 查询用户自定义承载能力(LST ISDNBCALIAS)
      - 设置用户自定义承载能力(SET ISDNBCALIAS)
    - 语音数据交替业务
      - 修改承载业务BS61（MOD BS61）
    - PAD接入CA业务
      - 修改承载业务BS45(MOD BS45)
      - 修改承载业务BS46(MOD BS46)
      - 修改承载业务BS42(MOD BS42)
      - 修改承载业务BS43(MOD BS43)
      - 修改承载业务BS41(MOD BS41)
      - 修改承载业务BS44(MOD BS44)
    - 数据CDS业务
      - 修改承载业务BS32(MOD BS32)
      - 修改承载业务BS34(MOD BS34)
      - 修改承载业务BS31(MOD BS31)
      - 修改承载业务BS33(MOD BS33)
    - 承载能力别名
      - 删除承载能力别名(RMV BCALIAS)
      - 增加承载能力别名(ADD BCALIAS)
      - 查询承载能力别名(LST BCALIAS)
      - 查询数据业务承载能力别名(LST DSBCALIAS)
      - 修改承载能力别名(MOD BCALIAS)
    - 数据CDA业务
      - 修改承载业务BS26(MOD BS26)
      - 修改承载业务BS23(MOD BS23)
      - 修改承载业务BS25(MOD BS25)
      - 修改承载业务BS22(MOD BS22)
      - 修改承载业务BS21(MOD BS21)
      - 修改承载业务BS24(MOD BS24)
    - 语音数据业务
      - 修改承载业务BS81（MOD BS81）
    - 数据PDS业务
      - 修改承载业务BS52（MOD BS52）
      - 修改承载业务BS51（MOD BS51）
      - 修改承载业务BS53（MOD BS53）
  - 查询承载业务(LST BS)
  - 修改承载业务(MOD BS)
  - UMTS承载业务
    - 修改承载业务BS30(MOD BS30)
    - 修改承载业务BS20(MOD BS20)
