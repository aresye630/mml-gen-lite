# PCRF对端PCEF能力字典项管理

- 术语解释
- 功能描述
- 能力字典项
- 注意事项

#### 术语解释

无。

#### 功能描述

PCRF对端PCEF能力字典项管理包括对端PCEF能力字典项配置和维护。配置包括修改对端PCEF能力字典项值。维护包括查询对端PCEF能力字典项信息。
