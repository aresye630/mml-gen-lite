# GWFD-021401 系统过载控制功能

系统过载控制，是指通过控制系统接入业务量来保证系统过载情况下业务的正常进行，避免造成整系统瘫痪。目前通过对系统过载情况下接入的业务量控制，实现UEG产品对业务处理的稳定性，并保证高优先级业务的成功率。
