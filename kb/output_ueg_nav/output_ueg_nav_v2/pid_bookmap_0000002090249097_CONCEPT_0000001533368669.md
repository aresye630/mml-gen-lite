# UEG软件安装（已预安装）

UEG支持在生产环节预安装CSP和VNF软件，从而提高安装效率。

查阅现场到货设备附带的文档，可获知设备的软件安装状态。

- 若设备已附带生产预安装报告，说明设备已经预安装软件。
- 若设备没附带生产预安装报告，说明设备没有预安装软件。

由华为员工登录网站https://humep.huawei.com/ipreinstall/report，输入合同号，**从LLD文档中获得预安装参数**。

根据软件预装信息，进行后续操作：

- 如果已经预安装VNF，请参考本文档后续章节，将预安装的参数修改为局方规划值。
- 如果没有预安装VNF，请联系华为工程师获取《UEG软件安装（机架服务器-ARM）》安装CSP和UEG。
