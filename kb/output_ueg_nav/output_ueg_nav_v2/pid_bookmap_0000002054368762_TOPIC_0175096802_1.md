# 组网路由配置

VNF与运营商网络互通对接组网的路径中，每条路径的路由IP类型一致，如表1所示。例如若逻辑接口组网规划为IPv4类型，则该逻辑接口对外互通的网络路径中的节点（如外联口地址、网关侧下一跳端口地址等），都要支持IPv4类型路由。不同逻辑接口的对外通信路径的IP类型独立，互相没有影响，如逻辑接口1通信路径规划为IPv4类型，逻辑接口2通信路径规划为IPv6类型。

| 逻辑接口                                                     | 逻辑接口                                                     | 逻辑接口       | 逻辑接口       | 逻辑接口       | 逻辑接口       | 逻辑接口       |
| 业务接口数据                                                   | 逻辑接口                                                     | IPv4       | IPv6       | IPv4v6双栈   | 一致         | -          |

**说明** 

- OM操作维护接口的组网IP类型支持IPv4、IPv6和IPv4v6双栈。
- 与外部DN网络连接的Gi/SGi/N6接口使用vNIC外联口，其组网IP类型与接入的用户IP类型相关。若IPv4v6双栈用户接入，则与外部DN网络连接的路径使用IPv4v6双栈组网；若IPv4/IPv6单栈用户接入，则与外部DN网络连接的路径使用IPv4/IPv6单栈组网。
- 一条对外的网络路径中每个节点绑定的VPN实例要一致。
