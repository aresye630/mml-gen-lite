# CAMEL限制业务键模板

- 功能描述
- 基本概念

#### 功能描述

该组命令用于管理CAMEL限制业务键模板数据。通过该组命令实现CAMEL限制业务键模板的增加、修改、删除、查询的功能。

在UDM上通过执行**ADD SERRESTTPL**命令签约CAMEL限制业务键模板，当位置更新流程或Restore流程触发ISD（Insert Subscriber Data）消息时，UDM需要根据CAMEL限制模板数据判断是否在ISD中下发相关的CAMEL业务数据。

#### 基本概念

**业务键**

业务键是HLR与SCP的对接参数之一，用于在CAP/INAP消息中唯一标识一种智能业务，gsmSCF用它来识别需要采用的业务逻辑。

业务键是一种号码资源，需要由运营商向本国的电信主管部门申请获得。
