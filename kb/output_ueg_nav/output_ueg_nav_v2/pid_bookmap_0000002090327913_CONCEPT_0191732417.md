#### 基本概念

**HTTP Digest**

HTTP Digest鉴权是对固网SIP终端用户接入IMS网络时进行认证的一种机制。对于采用HTTP Digest鉴权的固网SIP终端用户，通过User name和Password鉴权成功后接入IMS网络。

**SIP Digest**

SIP Digest鉴权是对SIP终端用户接入IMS网络时进行认证的一种鉴权机制。为了支持SIP终端用户接入IMS网络，对其采用SIP
Digest鉴权机制。

SIP Digest是HTTP Digest的升级版本，两者有如下关系：

- 网络侧：当MAR消息指示鉴权类型为HTTP Digest时，对于签约SIP Digest的用户，HSS在MAA消息中返回鉴权信息给S-CSCF；当MAR消息指示鉴权类型为SIP Digest时，对于签约HTTP Digest的用户，HSS在MAA消息中返回鉴权不支持信息给S-CSCF。
- 业务发放系统侧：HTTP Digest和SIP Digest的鉴权模式分开，签约不兼容。一个用户只能签约SIP Digest和HTTP Digest中的一种。
