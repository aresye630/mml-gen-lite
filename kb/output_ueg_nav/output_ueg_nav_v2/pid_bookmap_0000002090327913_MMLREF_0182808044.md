# 优化GPRS/EPS模板

- 命令功能
- 注意事项

## 命令功能

原来华为UDM把所有的GPRS数据都写到用户数据中，为了对GPRS/EPS数据进行灵活的管理，华为UDM中对原有的GPRS/EPS数据进行优化，允许操作员对用户的所有GPRS/EPS相关参数进行独立配置。

优化GPRS/EPS数据按照模板的方式进行管理，操作员签约GPRS/EPS业务时，只需要签约优化GPRS/EPS模板ID即可。

## 注意事项

无。

## 目录内容

- 优化GPRS/EPS模板
  - 查询优化GPRS/EPS模板(LST OPTGPRSTPL)
  - 增加优化GPRS/EPS模板(ADD OPTGPRSTPL)
  - 修改优化GPRS/EPS模板(MOD OPTGPRSTPL)
  - 删除优化GPRS/EPS模板(RMV OPTGPRSTPL)
