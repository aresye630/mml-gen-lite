# 业务规则管理

## 目录内容

- 业务规则管理
  - DNS规则
    - 修改DNS规则（MOD DNSRULE）
    - 删除DNS规则（RMV DNSRULE）
    - 添加DNS规则（ADD DNSRULE）
    - 显示DNS规则（LST DNSRULE）
  - 规则检测
    - 查询规则检测结果（DSP RULECHECK）
  - 规则
    - 增加规则（ADD RULE）
    - 增加黑名单规则（ADD BLACKLISTRULE）
    - 修改规则（MOD RULE）
    - 查询规则（LST RULE）
    - 删除规则（RMV RULE）
  - 用户模板
    - 增加用户模板（ADD USERPROFILE）
    - 查询用户模板（LST USERPROFILE）
    - 删除用户模板（RMV USERPROFILE）
  - 规则绑定
    - 增加用户模板和规则的绑定关系（ADD RULEBINDING）
    - 删除用户模板和规则的绑定关系（RMV RULEBINDING）
    - 查询用户模板和规则的绑定关系（LST RULEBINDING）
  - 本地用户组
    - 删除本地用户组（RMV LOCALUSERPROF）
    - 增加本地用户组（ADD LOCALUSERPROF）
    - 显示本地用户组（LST LOCALUSERPROF）
