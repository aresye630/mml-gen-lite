# 软件管理

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

无。

#### 功能描述

软件管理：提供对软件系统的相关管理操作，主要包括网元管理、版本查询、补丁管理、升级控制、系统备份、驱动管理等。

#### 注意事项

无。

## 目录内容

- 软件管理
  - 平面管理
    - 平面合并(CBN PLANE)
    - 检查网元版本(CHK MEVER)
  - PID信息
    - 查询PID信息(DSP PIDINF)
  - 性能测量管理
    - 导出性能统计资源信息(EXP TRFINFO)
    - 设置性能插件(SET PMPLUG)
  - OMU软参管理
    - 设置OMU软参(SET OMUSFTD)
  - 模块管理
    - 主机HA
      - 显示仲裁PMU信息(DSP HAMDU)
      - 设置仲裁PMU信息(SET HAMDU)
    - 内存
      - 查询进程内存数据信息(DSP MEM)
  - 工作区管理
    - 解锁网元工作区(ULK WKSP)
  - 命令统计
    - 查询跨网元命令开关(LST CMSWITCH)
  - 软件调试
    - 开始软件调试(STR SFTD)
  - 资源组
    - 查询资源组状态(DSP RG)
  - 备份管理
    - 导入网元数据(IMP MES)
