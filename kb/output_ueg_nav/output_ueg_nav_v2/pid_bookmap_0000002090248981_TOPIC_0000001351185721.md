# 配置用户数据同步

**注意** 

用户数据同步适用于5G签约用户、4G签约用户（包含NB-IoT用户）。

- 对于园区5G用户：
  - 园区5G用户在中心UDM开户，园区UDM从中心UDM同步数据时需要配置。
  - 园区5G用户在园区UDM（UEG设备）开户时，请参考用户数据配置（5G SA网络）进行配置配置。

- 对于园区4G用户：
  - 园区4G用户在中心UDM开户，园区UDM从中心UDM同步数据时需要配置。
  - 园区4G用户在园区UDM（UEG设备）开户时，请参考用户数据配置（EPS网络）进行配置配置。
