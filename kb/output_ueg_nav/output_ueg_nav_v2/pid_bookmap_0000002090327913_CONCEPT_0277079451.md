# PCRF对端OCS能力字典项管理

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

无。

#### 功能描述

PCRF对端OCS能力字典项管理包括对端OCS能力字典项配置和维护。配置包括修改对端OCS能力字典项值。维护包括查询对端OCS能力字典项信息。

**说明** 

OCS能力字典项支持与UPCF直连的OCS配置，不支持通过DRA与UPCF连接OCS的配置。

#### 注意事项

无。

## 目录内容

- PCRF对端OCS能力字典项管理
  - 查询PCRF对端OCS能力字典项的配置信息（LST OCSABIITEM）
  - 修改PCRF对端OCS能力字典项(MOD OCSABIITEM)
