# 一卡多号ISDN和IMSI映射关系管理

- 命令功能
- 基本概念

#### 命令功能

该组命令用于管理虚拟HLR上的特殊一卡多号业务用户的MSISDN前缀和IMSI前缀的映射关系。

该映射定义了短消息流程中消息携带的MSISDN和IMSI之间的关系，其中，MSISDN为MAP Server发送给UDM的SRI-SM消息中携带的信元，IMSI为UDM返回给MAP Server的响应消息中携带的信元。

**说明** 

IMSI：IMSI前缀+去掉国家码的主MSISDN号码

#### 基本概念

**多MSISDN业务**

多MSISDN号码功能是指系统为各种不同数据业务提供不同MSISDN号码，不同的MSISDN号码对应不同的数据业务。需要进行某种业务的呼叫时，直接呼叫该业务对应的MSISDN号码。一张卡最多支持255个MSISDN号码，其中可以支持最多254个辅MSISDN号码和一个主MSISDN号码。

**特殊一卡多号业务**

特殊一卡多号业务是指用户可通过一张SIM/USIM卡关联多个MSISDN号码。当用户需要使用一张SIM卡在多个不同运营商网络中漫游时，运营商可以为用户签约特殊一卡多号业务，其中多个号码采用相同Profile（同一份用户数据）。一张卡最多支持9个MSISDN号码，其中可以支持一个主MSISDN号码和最多8个辅MSISDN号码。
