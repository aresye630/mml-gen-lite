# T-CSI模板

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于管理系统中T-CSI（Terminating CAMEL Subscription Information）模板数据。用户可以通过签约T-CSI模板ID签约T-CSI业务。

T-CSI是被叫CAMEL签约信息，在移动用户做被叫的SRI流程，T-CSI数据由HLR传递给GMSC，T-CSI智能业务将被触发。

相对于呼叫普通用户，呼叫签约T-CSI模板的CAMEL用户时，GMSC将向用户归属HLR发起两次SRI（Send Routing Information）请求消息，HLR在第一次SRI响应消息中返回T-CSI数据，然后GMSC在第二次SRI请求消息中带上抑制T-CSI信元（即suppress-T-CSI），HLR检查到该信元后才向用户当前所在VLR取漫游号码，并在第二次SRI响应消息中返回取到的漫游号码。

#### 注意事项

无。

#### 基本概念

**DP**

DP（Detection Point）即检出点，用于触发智能业务和在智能业务过程中检测出与呼叫相关的事件，例如收集信息、号码分析、应答或挂机。DP的配置是为了通知“智能业务逻辑实例”遇到了DP，从而使智能业务逻辑实例影响随后的呼叫处理。如果DP没有配置，则继续原来的业务处理，不会涉及到智能业务。

不同的CAMEL阶段支持不同的DP，对于T-CSI具体支持情况如表1所示。

| CAMEL阶段   | 支持的DP                                                                 |
|:----------|:----------------------------------------------------------------------|
| Phase 1   | TAA（Terminating Attempt Authorised）（DP12）                             |
| Phase 2   | TAA（Terminating Attempt Authorised）（DP12）                             |
| Phase 3   | TAA（Terminating Attempt Authorised）（DP12），TBUSY（DP13），TNOANSWER（DP14） |
| Phase 4   | TAA（Terminating Attempt Authorised）（DP12），TBUSY（DP13），TNOANSWER（DP14） |

**说明** 

执行**ADD TCSITPL**/**MOD TCSITPL**命令时如果选择CAMEL阶段不支持的DP会返回错误。

**DP触发准则**

- TAA（DP12）

  该DP点只有基本业务码触发准则，最多存储5组基本业务码或基本业务码组。如果呼叫的基本业务码匹配5组中的任意一组基本业务码或基本业务码组中的一个成员， 则认为该呼叫满足基本业务码触发准则。该触发准则不是必须要配置的，如果未配置则默认满足触发条件。
- TBUSY（DP13）

  该DP点只包括呼叫释放原因触发准则，呼叫释放原因触发准则存储最多5个呼叫释放原因值，当GMSC从ISUP（Integrated Services Digital Network User Part）层接收到的呼叫释放原因值与5个中任一个呼叫释放原因值相同，则认为满足触发条件。该触发准则不是必须要配置的，如果未配置则默认满足触发条件。
- TNOANSWER（DP14）

  该DP点的触发准则同TBUSY（DP13）。该触发准则不是必须要配置的，如果未配置则默认满足触发条件。

不同的CAMEL阶段支持不同的DP触发准则，对于T-CSI具体支持情况如表2所示。

| CAMEL阶段   | 支持的触发准则              |
|:----------|:---------------------|
| Phase 1   | 不支持触发准则              |
| Phase 2   | 基本业务码触发准则            |
| Phase 3   | 基本业务码触发准则、呼叫释放原因触发准则 |
| Phase 4   | 基本业务码触发准则、呼叫释放原因触发准则 |

**说明** 

执行**ADD TCSITPL**/**MOD TCSITPL**命令时如果选择CAMEL阶段不支持的DP触发准则会返回错误。

**T-CSI签约信息定制下发**

HLR根据以下四个方面来灵活控制CAMEL签约信息的下发。

- SRI请求消息携带的GMSC是否在归属网络

  HLR根据SRI请求消息携带的GMSC地址，结合系统配置的VLR类型表来区分GMSC是在归属网络还是非归属网络中。VLR类型表通过**ADD VLRTYP**命令配置。
- GMSC与HLR是否有CAMEL查询协议

  HLR根据SRI请求消息带上的GMSC地址，结合系统配置的CAMEL查询协议表来确定GMSC与HLR是否有CAMEL查询协议。通过**ADD CAMELINTERTPL**命令将GMSC的号码前缀添加到CAMEL查询协议模板中，就认为该GMSC与HLR有查询协议。
- 当前网络对CAMEL业务的支持情况

  用户做被叫时，SRI请求消息中会携带GMSC所支持的CAMEL业务处理能力，HLR将此CAMEL业务处理能力和T-CSI模板中定义的CAMEL业务处理能力作对比，取两者的交集，得到当前GMSC对CAMEL业务的支持情况。
- T-CSI模板使用范围

  通过设置T-CSI模板使用范围，可以控制用户在特定的网络做被叫时，HLR才下发T-CSI信息。T-CSI模板的使用范围可以是归属网络、非归属网络、所有网络、归属国家、国际漫游的网络。
