# 跟踪配置管理

## 目录内容

- 跟踪配置管理
  - 信令采集
    - 查询用户消息统计功能配置(LST IMRFUNC)
    - 修改用户消息统计功能配置(MOD IMRFUNC)
    - 增加用户消息统计功能配置(ADD IMRFUNC)
    - 删除用户消息统计功能配置(RMV IMRFUNC)
  - 端到端用户跟踪管理
    - 查询端到端用户跟踪参数(LST E2ETRCCFG)
    - 设置端到端用户跟踪参数(SET E2ETRCCFG)
  - 跟踪重定向管理
    - 跟踪重定向查询
      - 显示重定向跟踪任务(DSP RDTTRCTASK)
  - 跟踪参数管理
    - 查询跟踪参数(LST TRC_CFG)
    - 设置跟踪参数(SET TRC_CFG)
