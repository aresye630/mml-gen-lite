# 用户管理

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

HLR的主要功能是用户数据管理和业务管理、统计和移动性管理。HLR的用户管理主要包括：用户数据管理、锁管理、号码查询、各种业务管理等。

#### 注意事项

无。

#### 基本概念

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**IMSI/MSISDN文件格式**

文件包含IMSI号码和MSISDN号码，每个IMSI号码与其对应的MSISDN号码组成一行。

```
IMSI1 MSISDN1
IMSI2 MSISDN2
……
IMSIn MSISDNn
```

每行的IMSI、MSISDN之间由一个空格分隔，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**SIDFILE文件格式**

SIDFILE文件包含多个SID号码，格式如下所示：

```
SID1
SID2
SID3
SID4
……
SIDn
```

SIDn为1～16位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。

## 目录内容

- 用户管理
  - 用户PID管理
    - 查询用户的归属分区(LST USERPID)
    - 修改用户的归属分区(MOD USERPID)
  - 用户统计
    - 查询用户数据(LST SUBDATA)
    - 批量查询用户数据(LST CONSUBDATA)
  - 多样性命令
    - 查询格式1用户数据(LST SUBBYFORMAT1)
  - 改号
    - 删除改号表数据(RMV CHANGEDISDN)
    - 改号（MOD ISDN）
  - 用户数据查询
    - 查询用户动态数据(LST DYNSUB)
    - 查询CMCC用户静态数据(LST CMCCSUB)
    - 查询用户静态数据(LST SUB)
    - 查询终端状态及位置信息(GET TERMSTATE)
    - 查询用户开户时间(LST CREATETIME)
  - IMSI用户路由配置
    - 增加IMSI用户路由数据(ADD IMSIRTSUB)
    - 修改IMSI用户路由数据(MOD IMSIRTSUB)
    - 查询IMSI用户路由数据(LST IMSIRTSUB)
    - 删除IMSI用户路由数据(RMV IMSIRTSUB)
  - IMSI/MSISDN管理
    - 查询MSISDN（LST ISDN）
    - 查询IMSI(LST IMSI)
  - 锁管理
    - 修改用户申请锁(MOD SABLCK)
    - 查询用户申请锁(LST SABLCK)
    - 修改GPRS锁(MOD GPRSLCK)
    - 查询LCK锁(LST LCK)
    - 修改LCK锁(MOD LCK)
    - 查询GPRS锁(LST GPRSLCK)
  - 开户
    - 开户(ADD SUB)
    - 多MSISDN用户开户(SET MULTISDN)
    - 统一模板开户(ADD TPLUSCSUB)
    - 增加VoWIFI/VoLTE辅卡（ADD SCARD）
    - CSPS开户(ADD CSPSSUB)
    - 模板开户(ADD TPLSUB)
    - CSPS模板开户(ADD TPLCSPSSUB)
  - 5G签约自动迁移PID管理
    - 查询4升5迁移指令PID规则(LST SINGLEUSERMOVEPIDS)
    - 删除4升5迁移指令PID规则(RMV SINGLEUSERMOVEPIDS)
    - 增加4升5迁移指令PID规则(ADD SINGLEUSERMOVEPIDS)
  - 销户
    - 统一销户(RMV USCSUB)
    - 销户(RMV SUB)
    - CSPS销户(RMV CSPSSUB)
  - 短消息下发路径
    - 查询短消息下发路径(LST SMDP)
    - 修改短消息下发路径(MOD SMDP)
  - 用户类型
    - 查询用户类型(LST CATEGORY)
    - 修改用户类型(MOD CATEGORY)
  - APN信息管理
    - 新增或修改APN信息(SET APNLIST)
    - 查询APN信息(LST APNLIST)
  - VLR号码
    - 修改VLR号码(MOD VLRNUM)
    - 查询VLR号码(LST VLRNUM)
  - 用户全局计费特性管理
    - 查询用户全局计费特性(LST CCGLOBAL)
    - 修改用户全局计费特性(MOD CCGLOBAL)
  - 网络接入模式
    - 查询网络接入模式(LST NAM)
    - 修改网络接入模式(MOD NAM)
  - MME地址管理
    - 修改MME地址信息(MOD MMEINFO)
    - 查询MME地址信息(LST MMEINFO)
  - 补卡
    - 补卡(MOD IMSI)
  - S4SGSN地址管理
    - 查询S4SGSN地址信息(LST S4SGSNINFO)
    - 修改S4SGSN地址信息(MOD S4SGSNINFO)
  - SID管理
    - 查询SID与IMSI对应关系(LST SIDIMSI)
    - 设置新SID(SET NEWSID)
  - 用户数据修改管理
    - 模板修改用户数据（MOD TPLSUB）
  - SGSN号码
    - 修改SGSN号码(MOD SGSNNUM)
    - 查询SGSN号码(LST SGSNNUM)
  - MSC号码
    - 查询MSC号码(LST MSCNUM)
    - 修改MSC号码(MOD MSCNUM)
