# EPS用户数据管理

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于管理用户的EPS（Evolved Packet System）业务数据。

#### 注意事项

无。

#### 基本概念

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。

**SRVCC**

单待语音连续SRVCC（Single Radio Voice Call Continuity）业务是指用户在通话过程中从E-UTRAN（Evolved Universal Terrestrial Radio Access Network）漫游到UTRAN（UMTS Terrestrial Radio Access Network）/GERAN（GSM EDGE Radio Access Network）时，经过UE和网络设备的切换过程，保持用户的通话不中断。

**锚定功能**

为了使采用各种传统接入方式的终端用户能够享受IMS带来的多媒体融合业务，需要将这些用户的呼叫路由到IMS网络，这个将呼叫路由到IMS网络的过程称为锚定（Anchoring）。

**ICS**

ICS（IMS Centralized Services）是将传统CS域核心网络演进到以IMS为中心的FMC（Fixed Mobile Convergence）网络，以实现用户在GSM/UMTS/LTE等网络下，会话和业务体验的一致性和连续性。

在VoLTE（Voice over Long Term Evolution）解决方案中，VoLTE用户从LTE漫游到CS网络，或经过SRVCC（Single Radio Voice Call Continuity）从LTE切换到CS网络后，为了保持业务连续性，通过使用ICS技术，将业务集中到IMS。在LTE网络建设初期覆盖不全的情况下，支持ICS的MSC Server为签约ICS业务的用户提供注册代理功能，使得用户可以体验由IMS所提供的丰富业务。主要应用于以下两种场景：

- CS用户签约ICS业务，可以在不改变原有号码前提下体验IMS所提供的业务。
- VoLTE用户漫游或通过SRVCC切换到CS网络后，可继续保持IMS提供的业务体验。

**HSS与HLR互操作**

HSS支持与HLR互操作，是一种可以应用于GSM/UMTS/LTE叠加组网场景下的业务功能。当GSM/UMTS用户开通LTE业务后，该特性支持通过Gr'接口将现网HLR中的用户数据同步到LTE网络中的HSS，从而实现GSM/UMTS网络和新建LTE网络间的互通，使用户在不换卡、不换号的情况下，体验LTE网络业务。
