# 隐式注册集管理

- 注意事项

## 命令功能

该特性用于设置隐式注册集。隐式注册集用于IMPU或PUSI以隐式方式进行注册。

通过IRS（Implicitly Registered Set）即隐式注册集管理，可为一个IRS设置一个缺省IMPU。S-CSCF使用缺省IMPU实现呼叫和会话控制。当HSS通过SAA消息发送签约数据给S-CSCF时，同时也在该消息中携带隐式注册集的缺省IMPU。

IRS具有以下属性：

- 至少包含两个IMPU或PUSI。
- 可以指定一个缺省IMPU。

IRS中的IMPU具有下列属性：

- 属于相同的IMPI。
- 漫游权限相同。
- 注册权限相同。
- 共享属性相同。
- 如果是缺省IMPU，必须不是闭锁状态。根据系统配置要求，缺省IMPU可以采用SIP URI或TEL URI格式。

IRS中的PUSI具有下列属性：

属于相同的PISI。
