# 数据优化管理

- 命令功能
- 基本概念

#### 命令功能

该组命令用于优化管理用户存储在数据库中的SIFC（Shared Initial Filter Criteria）数据记录。

#### 基本概念

**SIFC**

iFC指初始过滤规则，是一种业务触发原则，描述了能够提供给用户的应用签约信息，作为用户配置存储在IMS-HSS中，在用户注册时可以下载到S-CSCF。

共享iFC是指一组被多个service profile共享的iFC的集合。在IMS-HSS和S-CSCF的数据库中都保存一份相同的共享iFC数据，数据的内容包括共享iFC的内容和对应的“共享iFC模板ID”。S-CSCF仅向IMS-HSS下载“共享iFC模板ID”，并根据“共享iFC模板ID”从本地数据库中取到具体的iFC内容。运营商可以通过共享iFC来避免S-CSCF从IMS-HSS下载并存储冗余的iFC数据，从而减少Cx接口流量负载，节省S-CSCF和IMS-HSS存储空间，提高S-CSCF的系统性能。有助于运营商降低设备成本。
