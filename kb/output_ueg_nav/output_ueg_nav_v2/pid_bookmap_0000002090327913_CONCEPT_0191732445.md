# 能力集管理

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于修改和查询用户所需要的业务能力，例如iFC业务、通配PSI业务等 。

#### 注意事项

无。

#### 基本概念

**能力集**

当一个用户发起SIP注册请求时，I-CSCF需要为该用户分配一个S-CSCF，即选择能够满足该用户业务要求的S-CSCF，I-CSCF通过向HSS查询用户的能力集来选择S-CSCF。

**必选/可选能力**

必选/可选能力是指用户所能具有的业务能力，例如，iFC业务、语音业务等。I-CSCF能够从HSS接收用户所需的S-CSCF的必选能力和可选能力列表，然后根据S-CSCF所具有的业务能力选择相应的S-CSCF。

I-CSCF选择具有用户所需的所有必选能力和可选能力的S-CSCF。如果没有，I-CSCF将使用最大匹配原则，先匹配必选能力，后匹配可选能力。如果有多个S-CSCF具有用户所需的所有必选能力，I-CSCF将根据可选能力选择S-CSCF。
