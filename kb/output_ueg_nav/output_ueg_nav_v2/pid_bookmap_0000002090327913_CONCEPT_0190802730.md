# VLR/SGSN漫游区域模板

- 功能描述
- 基本概念

#### 功能描述

该组命令用于在UDM中管理VLR/SGSN漫游区域模板数据。

VLR/SGSN漫游区域模板设置了VLR/SGSN漫游区域数据，当**ADD VSLIST**命令中参数“漫游区域配置方式”设置为“VSAREA\_TPL\_TYPE”时，用户可以通过执行**MOD VSRR**命令签约VLR/SGSN漫游限制业务，来限制用户只能或不能在模板指定的区域范围内漫游。

在设置VLR/SGSN模板时，可以把运营商规划的某些属性相近的VLR/SGSN的号码通过号码前缀集合起来，在限制用户漫游的时候，把用户限制在这些VLR/SGSN号码区域范围之内，从而灵活高效地对用户移动性管理。

#### 基本概念

无。
