# 本地用户数据同步

- 本地用户数据同步
  - 数据同步客户端

  - 园区UDM的IP地址

    - 查询数据同步服务器公钥（LST RSFTPPUBLICKEY）
    - 创建数据同步服务器公钥（ADD RSFTPPUBLICKEY）
    - 删除数据同步服务器公钥（RMV RSFTPPUBLICKEY）
