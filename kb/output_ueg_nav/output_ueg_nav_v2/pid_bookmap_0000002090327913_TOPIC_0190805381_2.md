# 二次授权用户管理

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

二次授权：

二次授权功能开启后，对于需要进行二次授权的MML命令将需要输入可以二次授权的用户名和密码进行授权后，才能继续执行。

需要进行二次授权的MML命令可以通过LST SECAUTHMEM命令查询。

#### 功能描述

二次授权用户管理包括对于二次授权的用户进行新增，删除和查看。用户可以根据需要调整哪些用户可以进行二次授权。

#### 注意事项

无。

## 目录内容

- 二次授权用户管理
  - 查看二次授权用户（LST USRSECAUTH）
  - 增加二次授权用户（ADD USRSECAUTH）
  - 删除二次授权用户（RMV USRSECAUTH）
