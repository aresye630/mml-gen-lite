#### 功能描述

此组命令用于采集网元设备的相关配置数据并生成设备档案文件，同时将设备档案文件上传到网管服务器，以便于维护人员能直接从网管系统对所有华为设备进行统一维护，提升维护效率。设备档案的操作场景和交互流程如下：

1. 采集并生成设备档案文件。

   USCDB网元在接收到网管下发的设备档案生成命令后：
   1. 首先根据命令的参数到系统中收集所需要的配置数据。
   2. 完成所有数据的收集后，将配置数据以XML的形式保存到文件中，网元使用默认文件名（devfile.xml）来生成档案文件（该文件保存在“\opt\HUAWEI\cgp\workshop\omu\share\devicefile\nms\nexxx”目录下，其中“xxx”为网元ID）。
2. 上传设备档案到网管。

   在设备档案界面，操作员选择CGP或CSP子网元从网元上传到网管，网管下发命令给CSP，由CSP导出设备档案后上传并通知网管，网管将其解析入库、并对文件中某字段做修改。

#### 相关概念

**IMSI**

IMSI（International Mobile Subscriber Identity）是为唯一标识一个移动用户的号码，通常被存放在SIM卡中，由手机发送给网络。IMSI可用于获取存储在本地位置寄存器中的移动用户的其他信息，或复制在当地拜访位置寄存器中。为了防止通过无线接口对用户进行窃听和跟踪，IMSI很少被发送，而是由一个随机生成的TMSI（Temporary Mobile Subscriber Identity）代替发送。IMSI由MCC（Mobile Country Code），MNC（Mobile Network Code）及MSIN（Mobile Subscriber Identification Number）组成。

内存数据库

内存数据库即Pod内部基于内存存储的数据库，保存最新的用户数据、路由数据及全局数据。

**PDP地址**

PDP（Packet Data Protocol）地址是GPRS用户的网络层地址，与标准的网络层地址(如：IPv4地址、IPv6地址、X. 121地址)建立了临时或永久性的关联。PDP地址可以有3种方式分配给MS（Mobile Station）。

- 静态PDP地址：HPLMN（Home Public Land Mobile Network）将一个PDP地址永久性地分配给MS。
- 动态HPLMN PDP地址：当激活一个PDP上下文时，HPLMN才将一个PDP地址临时分配给MS。
- 动态VPLMN PDP地址：当激活一个PDP上下文时，VPLMN（Visited Public Land Mobile Network）才将一个PDP地址临时分配给MS。

**设备档案**

设备档案是指运营商的设备文件，包含如下配置数据：设备基本信息、设备连接信息、模块信息、设备配置信息、对端设备信息、主机版本信息、Pod信息、模块及模块Flash电子标签信息、天线信息。
