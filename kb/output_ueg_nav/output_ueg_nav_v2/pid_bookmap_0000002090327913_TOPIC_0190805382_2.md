# 二次授权状态管理

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

二次授权：

二次授权功能开启后，对于需要进行二次授权的MML命令将需要输入可以二次授权的用户名和密码进行授权后，才能继续执行。

需要进行二次授权的MML命令可以通过LST SECAUTHMEM命令查询。

#### 功能描述

二次授权状态管理包括对于二次授权功能的开启，关闭和查看。用户可以根据需要打开二次授权功能或关闭二次授权功能。

#### 注意事项

默认二次授权功能为关闭状态。
