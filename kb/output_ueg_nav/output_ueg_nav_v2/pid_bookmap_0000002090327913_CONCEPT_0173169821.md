#### 功能描述

本组命令用于局点安装USCDB软件、升级、割接扩容操作等场景进行系统调测。系统调测指产品在完成系统硬件及软件安装、升级、割接扩容等操作后，对系统进行一系列的调试与验证，以确保系统按设计要求投入使用，并能稳定、可靠、安全地运行。

#### 相关概念

**IMEI**

IMEI（International Mobile Equipment Identity）是用于标识每一台GSM（Global System for Mobile Communications）和UMTS（Universal Mobile Telecommunications System）手机的数字，具有唯一性。该标识通常位于手机内部的电池下方，也可以通过在手机中输入字符串（如\*#06#，不同厂商的手机输入的字符串不同，同一厂商不同手机所需输入的字符串也可能不同）来查看该手机的IMEI。IMEI由TAC（Type Approval Code）、FAC（Final Assembly Code）、SNR（Serial Number）及SP组成。IMEISV（International Mobile station Equipment Identity and Software Version）是IMEI的软件版本，由TAC、FAC、SNR及SVN（Software Version Number）四部分组成。其中TAC用于唯一标识无线设备，FAC用于表明生产地或者最后组装地，SNR用于大批量生产的产品上的系列编号，SP为检验码（通常是“0”），SVN用于表明软件版本。

**IMSI**

IMSI（International Mobile Subscriber Identity）是为唯一标识一个移动用户的号码，通常被存放在SIM卡中，由手机发送给网络。IMSI可用于获取存储在本地位置寄存器中的移动用户的其他信息，或复制在当地拜访位置寄存器中。为了防止通过无线接口对用户进行窃听和跟踪，IMSI很少被发送，而是由一个随机生成的TMSI（Temporary Mobile Subscriber Identity）代替发送。IMSI由MCC（Mobile Country Code），MNC（Mobile Network Code）及MSIN（Mobile Subscriber Identification Number）组成。

内存数据库

内存数据库即虚拟机（裸机Pod）内部基于内存存储的数据库，保存最新的用户数据、路由数据及全局数据。

**TAC**

IMEI中的一个组成部分，指型号批准码，由欧洲型号批准中心分配。

**主/备平面**

为了保证升级无损，在虚拟机场景下将网元进程以虚拟机为单位分成主、备两个平面，在裸机场景下将网元进程以主机为单位分成主、备两个平面在一个平面升级过程中，另一个平面承接业务。在升级时，先升级备平面，再升级主平面。主、备平面的划分原则如下：

- 在虚拟机场景下，主备进程所属两个虚拟机，虚拟框槽号小的为主平面，大的为备平面。在裸机场景下，主备进程所属两个主机，主机框槽号小的为主平面，大的为备平面。
- 在虚拟机场景下，对于其他负载均衡进程所在的虚拟机中，以虚拟框槽号从小到大排序，进行对半分。虚拟框槽号小的为主平面，虚拟框槽号大的为备平面。在裸机场景下，对于其他负载均衡进程所在的主机中，以主机框槽号从小到大排序，进行对半分。主机框槽号小的为主平面，主机框槽号大的为备平面。

#### 注意事项

本组命令需要在开局、升级、割接扩容等操作时使用，如果该局点已经正常运行业务，执行本组命令前请务必事先和华为技术工程师确认再执行操作。

#### 配置原则

本组命令无特殊配置原则。
