# PMS PmCLI任务管理

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

POP：即策略管理平台（ Policy Operation Platform ），用来与PCRF、PCEF及IT系统等对接，通过丰富的策略管理功能，让PCC业务的上线时间更短。

#### 功能描述

PmCLI任务管理用于查询PmCLI任务（即UPCF通过Pm接口从POP对端获取CLI脚本）中策略文件的执行信息，包含策略文件的名称、策略文件执行的开始时间、结束时间以及策略文件执行的状态等。

#### 注意事项

无。
