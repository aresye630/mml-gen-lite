# OTS管理

## 目录内容

- OTS管理
  - EDR管理
    - 导出EDR日志(EXP EDRLOG)
    - 查询EDR导出日志任务状态(DSP EDRLOG)
  - 离线业务参数配置
    - 设置离线业务参数(SET SCANSW)
    - 查询离线业务参数(LST SCANSW)
  - 离线任务管理
    - 停止遍历任务(STP SCAN)
    - 查询当前遍历任务状态(DSP SCANSTATUS)
    - 设置遍历任务参数(SET SCANPARA)
    - 启动遍历任务(STR SCAN)
    - 查询遍历任务参数(LST SCANPARA)
  - 冗余会话备份数据审计任务管理
    - 查询冗余会话备份数据审计任务状态(DSP OTSSESSADT)
    - 启动冗余会话备份数据审计任务(STR OTSSESSADT)
    - 停止冗余会话备份数据审计任务(STP OTSSESSADT)
