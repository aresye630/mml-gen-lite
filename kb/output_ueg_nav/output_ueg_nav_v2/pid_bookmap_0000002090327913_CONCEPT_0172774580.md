# 平台资源监控管理

- 功能描述
- 注意事项
- 配置原则

#### 功能描述

在日常维护过程中，需要对USCDB平台的资源进行监控管理，以便能及时发现并处理平台系统存在的隐患，保证平台的稳定运行。USCDB平台资源监控管理包括以下几个部分：

1. 磁盘空间占用率是否超过90%。
2. 数据库是否可以连接。

当资源监控的开关打开后，USCDB默认会进行1项的检测，而2、3项是否需要检测可通过执行**MOD MONITOR**命令对监控类型进行设置。当监控的平台资源出现异常时，系统会上报对应的告警，在OM Portal“监控分析 > 告警管理 > 活动告警”界面查询即可。

**磁盘空间占用率**

如果硬盘分区或磁阵存储空间使用率超过90％，硬盘分区或磁阵随时会写满，此时如果不及时清理，会造成硬盘分区或磁阵的操作失败，导致系统处于异常状态。

无。
