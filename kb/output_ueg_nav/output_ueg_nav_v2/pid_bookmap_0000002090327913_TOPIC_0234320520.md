# NRF配置管理

## 目录内容

- NRF配置管理
  - NF与NRF注册关系
    - 修改本端NF和对端NRF实例的注册关系（MOD NFREGNRF）
    - 删除本端NF和对端NRF实例的注册关系（RMV NFREGNRF）
    - 增加本端NF和对端NRF实例的注册关系（ADD NFREGNRF）
    - 查询本端NF和对端NRF实例的注册关系（LST NFREGNRF）
  - NRF实例配置管理
    - 修改NRF信息（MOD NRF）
    - 显示当前NRF实例信息（DSP CURNRFINFO）
    - 删除NRF信息（RMV NRF）
    - 增加NRF信息（ADD NRF）
    - 查询NRF信息（LST NRF）
