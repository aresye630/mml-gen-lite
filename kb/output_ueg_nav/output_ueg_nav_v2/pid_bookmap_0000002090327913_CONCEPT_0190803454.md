# EPS QoS模板替代配置

- 功能描述
- 基本概念

#### 功能描述

该组命令用于在UDM数据库中，对EPS QoS模板替代配置信息进行设置和管理。

由于某些MME/S4-SGSN/3GPP AAA Server功能所限，无法支持用户签约的EPS QoS模板对应的QoS数据。因此UDM支持使用指定的EPS QoS模板替代用户签约的EPS QoS模板进行下发，从而提高UDM与MME/S4-SGSN/3GPP AAA Server在网络中的兼容性。

通过该组命令可以为数据库中指定的EPS QoS模板设置替代关系。当用户漫游到指定的MME/S4-SGSN/3GPP AAA Server下，并需要下发QoS数据时，UDM会检测用户签约的EPS QoS模板是否设置了替代配置：

- 用户签约的EPS QoS模板通过**SET DEFREPEPSQOSID**命令设置了缺省的替代配置，并且没有通过**ADD REPEPSQOSID**命令，为用户漫游所在的MME/S4-SGSN/3GPP AAA Server设置替代配置，UDM会使用**SET DEFREPEPSQOSID**命令设置的EPS QoS替代模板代替用户签约的EPS QoS模板进行下发。
- 用户签约的EPS QoS模板通过**ADD REPEPSQOSID**命令，为用户漫游所在的MME/S4-SGSN/3GPP AAA Server设置了替代配置，**SET DEFREPEPSQOSID**命令为该模板设置的替代配置将不生效，UDM会使用**ADD REPEPSQOSID**命令设置的EPS QoS替代模板代替用户签约的EPS QoS模板进行下发。

#### 基本概念

**QoS**

QoS（Quality of Service）指对IP网络投递分组服务能力的评估。通常以对延迟、延迟抖动、丢包率等服务需求提供支持的能力作为核心评估对象。当网络过载或拥塞时，QoS能保证重要业务量不受延迟或丢弃，同时保证网络的高效运行，从而提高服务质量。

**GPRS**

GPRS（General Packet Radio Service）业务是一种为用户提供端到端的移动分组数据业务，通过在GSM（Global System for Mobile Communications）网络中引入分组交换的功能实体，完成用分组方式进行的数据传输业务。GPRS在现有GSM移动通信网络基础上建立，能有效地利用网络资源，降低网络成本，同时具有实时在线、按量计费、快捷登录、高速传输、自如切换的优点。

**QoS数据下发**

在以下情况下，UDM会将用户签约的EPS QoS模板对应的QoS数据下发给用户漫游所在的MME/S4-SGSNN/3GPP AAA Server：

- 当用户在EPS域进行位置更新时：
  - 用户附着于MME/S4-SGSN，UDM下发ULA消息给MME/S4-SGSN，在ULA消息的Subscription-Data.APN-Configuration-Profile.EPS-Subscribed-Qos-Profile AVP中携带QoS数据。
  - 用户附着于3GPP AAA Server，UDM下发SAA消息给3GPP AAA Server，在SAA消息的Non-3GPP-User-Data.APN-Configuration.EPS-Subscribed-Qos-Profile AVP中携带QoS数据。
- 当在网签约或修改EPS域的QoS模板时（通过**ADD SUB**、**MOD OPTGPRS**或**MOD EPSSER**等命令）：
  - 用户附着于MME/S4-SGSN，UDM下发IDR消息给MME/S4-SGSN，在IDR消息的Subscription-Data.APN-Configuration-Profile.EPS-Subscribed-Qos-Profile AVP中携带QoS数据。
  - 用户附着于3GPP AAA Server，UDM下发PPR消息给3GPP AAA Server，在PPR消息的Non-3GPP-User-Data.APN-Configuration.EPS-Subscribed-Qos-Profile AVP中携带QoS数据。

**Diameter服务节点**

Diameter节点是一个实现了Diameter协议的功能实体，可以为MME/S4-SGSN/3GPP AAA Server所服务的接入网络。
