# 配置UPF

**说明** 

- 逻辑接口（N3、N4、N9、S1-U、Sa、Sc、Pa等）的IP不能和外联口IP在同一网段，也不能和对端的物理接口IP在同一网段。
- Sa/N3/S1-U：这类表达意思是支持使用抽象接口Saif，也支持独立接口N3if/S1-Uif。
- N4(N4/Sxa/Sxb)：这类表达意思是仅支持使用抽象接口N4if，不支持独立接口。
