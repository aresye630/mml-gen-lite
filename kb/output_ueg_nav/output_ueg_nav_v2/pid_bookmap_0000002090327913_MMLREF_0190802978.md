## 命令功能

CUG (Closed User Group) 补充业务是用户可以连接到PLMN和其它网络来建立一个CUG-闭合用户群，出入该CUG的呼叫会受到限制。一个用户可以成为一个或多个CUG的成员。指定CUG的成员可以与群内的用户通信，但在通常情况下，不能与群外的用户通信。

CUG index: 由网络分配，用来识别一个CUG的ID（由MS使用）。

CUG Interlock Code (IC): 用来唯一标识一个CUG。

preferential CUG: 优先CUG，当系统没有收到CUG index时，优先CUG被系统用来作为缺省的CUG。

群外呼入允许：具有本特性的用户，允许接收群外用户的呼叫。

呼出群外允许：具有本特性的用户，允许发起到群外用户的呼叫。

群内呼入禁止： 具有本特性的用户，不允许接收群内其他用户的呼叫，但可以呼叫群内其他的用户。

群内呼出禁止：具有本特性的用户，不允许发起到群内其他用户的呼叫，但可以接收群内其他用户的呼叫。

CUG呼叫: CUG用户群内发起的呼叫。
