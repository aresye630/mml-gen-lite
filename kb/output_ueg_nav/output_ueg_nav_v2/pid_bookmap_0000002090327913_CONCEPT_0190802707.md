# IMSI/MSISDN管理

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于查询用户的IMSI号码和MSISDN号码。

#### 注意事项

无。

#### 基本概念

**备选IMSI号码**

一个MSISDN号码可以对应用户的一个主用IMSI号码和一个备选IMSI号码。

当主用IMSI号码不可用（SIM/USIM卡丢失或损坏）时，可以进行换卡操作，启用备选IMSI号码，换卡后用户的MSISDN号码不变。自动换卡场景如下：

- 如果用户在自动换卡的有效日期之内一直没有使用新卡，则旧卡仍能正常使用。一旦使用了一次新卡，则换卡完成，旧卡不能再使用。在自动换卡的有效期之内可以执行**MOD IMSI**命令去签约自动换卡业务。
- 如果用户超过了有效日期仍没有使用新卡，换卡会自动完成，旧卡不能再使用。

**多MSISDN号码**

多MSISDN号码功能是指系统为各种不同数据业务提供不同MSISDN号码，不同的MSISDN号码对应不同的数据业务。需要进行某种业务的呼叫时，直接呼叫该业务对应的MSISDN号码。

主叫发起数据呼叫，必须通过某种方式通知被叫用户，才能实现预期的呼叫。对于移动主叫，在发起SETUP时，携带的承载能力指示主叫的业务要求，GMSC在取路由信息请求中把该承载能力传递给HLR，HLR检测到取路由信息请求中携带有承载能力，在取漫游号码请求中又传递给VMSC/VLR，这样就实现了主叫业务要求到被叫的传递。

但对于PSTN用户，由于TUP信令不能携带承载能力，这时需要多MSISDN号码功能实现主叫业务要求到被叫的传递。当GMSC发出的取路由信息请求到达HLR后，HLR检测到请求消息中未携带承载能力，则取出数据库中该号码对应的承载能力，并在取漫游号码请求消息中传递给VMSC/VLR，从而实现主叫业务要求的传递。

多MSISDN用户有一个主号码和多个辅号码。辅号码定义了对应的承载能力，主号码定义了一个缺省的承载能力。主号码的缺省承载能力也使得用户在对主号码进行数据业务呼叫时，如果主叫没有带承载能力，HLR也可以针对主号码下发一个用户要求的缺省承载能力。

一张卡最多支持255个MSISDN号码，其中可以支持最多254个为辅号和一个主MSISDN号码。

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
