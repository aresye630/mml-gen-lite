# 主叫号码识别限制业务

- 命令功能
- 注意事项

## 命令功能

CLIR（Calling Line Identification Restriction）是指主叫移动用户的补充业务，移动用户作主叫时，不允许网络向被叫用户提示主叫用户的号码。例如：甲移动用户呼叫乙用户，如果甲选择了本业务，那么当乙用户被接通时，乙用户的手机在振铃时，不会显示甲用户的电话号码。

CLIP和CLIR是互为排斥的业务。当被叫用户激活CLIP，而主叫用户也激活了CLIR时，一般情形下，CLIR的优先级要高于CLIP，所以网络也不会向被叫用户提供主叫用户的号码；但是，当被叫用户CLIP的属性为OVERRIDECATEGORY（超越级别）时，CLIP会发生作用，网络会向被叫用户提供主叫的用户号码。
