# NT-U-CSI模板

- 命令功能
- 基本概念
- 注意事项

#### 命令功能

该组命令用于灵活管理系统中U-CSI（USSD CAMEL Subscription Information）模板数据。在NT-U-CSI模板中定义多个U-CSI模板后，再通过开户模板进行关联，然后执行**ADD TPLSUB**命令实现模板开户时直接签约U-CSI业务。

#### 基本概念

U-CSI是USSD（Unstructured Supplementary Service Data） CAMEL签约信息，该数据由HLR保存，不发送给其他网元。U-CSI包含用来为服务的用户调用USSD应用的触发信息。USSD智能应用时，MSC将USSD请求路由到用户归属的HLR，由HLR路由到相应的SCP进行处理。

#### 注意事项

无。
