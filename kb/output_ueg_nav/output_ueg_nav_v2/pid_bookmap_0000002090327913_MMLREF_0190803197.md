## 命令功能

FollowMe业务又称为功能号码寻址，它允许用户A更改功能号码B的FM数据，使得对功能号码B的呼叫都转移给A，执行效果类似于无条件前转（CFU），与CFU的不同之处在于，这里由前转方A来管理被前转方B的FM业务数据。

HLR提供FM相关数据存储、修改、查询的能力，提供通过手机/营业厅登记、删除、查询FM业务的能力，提供以功能号码取路由时将呼叫前转到其对应的初始用户的能力，提供FM数据的安全管理能力。

- 初始用户：能够修改远端用户FM业务数据，使得对远端用户的呼叫前转到自己的移动用户。一个初始用户可以与多个远端用户相关联。也就是说对多个远端用户的呼叫可以前转到同一初始用户。
- 远端用户：是运营商定义的一个号码，做为进行FM呼叫时的被叫用户。它一般是一个虚拟用户，特殊情况是远端用户是一个移动用户。远端用户最多可以与五个初始用户相关联，对远端用户的呼叫会前转到当前与它关联的初始用户。
- 初始号码：初始用户的MSISDN号码，所有指向远端用户的呼叫都会被转移到该号码。MSISDN号码必须是用户的基本MSISDN号码。
- 远端号码：与初始用户相关联的功能号码。通常情况下不指向任何一个实际用户，可以认为是一个"虚拟号码"。特殊情况下远端用户就是一个PLMN的GSM用户，这时远端号码就是该用户的基本MSISDN号码。
- 潜在初始用户：为了安全，并不能让任意用户成为远端用户的初始用户，所以运营商可以在FM功能节点设置远端用户的潜在初始用户，只有被授权的用户才可以成为远端用户关联的初始用户。
- FM业务管理者：是一个特殊的初始用户，他可以撤销指定的远端用户和其初始用户的前转关联。FM业务管理员需要运营商在FM功能节点设置。
- 功能节点FFN（FollowMe Function Node）：是PLMN运营商定义的一个网络节点。远端用户的FM数据就存放在这里。
