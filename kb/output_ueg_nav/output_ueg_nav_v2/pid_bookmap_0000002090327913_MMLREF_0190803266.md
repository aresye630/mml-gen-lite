# 呼叫等待业务

- 命令功能
- 注意事项

## 命令功能

CW（Call Waiting）业务允许移动用户在如下情况得到入呼叫通知：

- 入呼叫没有空闲的业务信道。
- 移动用户正在通话或保持呼叫。

移动用户对这个等待的呼叫可以选择接收、拒绝或不理睬。等待呼叫的另一方在呼叫等待期间将收到等待通知。

每个用户只能有一个等待呼叫，当用户已经有了一个等待呼叫后，系统将对以后的入呼叫立即拆线。
