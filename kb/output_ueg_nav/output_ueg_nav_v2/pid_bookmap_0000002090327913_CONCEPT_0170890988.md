# PCRF与容灾PCRF之间链路管理

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

无。

#### 功能描述

PCRF与容灾PCRF之间链路的管理用于配置和维护Hb接口下，PCRF与容灾PCRF实体之间链路的配置信息和状态信息。如增加、删除、查询、修改等相关操作。

#### 注意事项

无。

## 目录内容

- PCRF与容灾PCRF之间链路管理
  - 增加PCRF容灾PCRF链路(ADD RPCRFL)
  - 修改PCRF容灾PCRF链路信息(MOD RPCRFL)
  - 查询PCRF容灾PCRF链路状态信息(DSP RPCRFL)
  - 删除PCRF容灾PCRF链路(RMV RPCRFL)
  - 查询PCRF容灾PCRF链路配置信息(LST RPCRFL)
