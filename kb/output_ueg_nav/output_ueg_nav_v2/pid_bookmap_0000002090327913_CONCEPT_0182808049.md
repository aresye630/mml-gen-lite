# EPS模板

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于设置EPS模板数据，EPS模板定义了EPS用户的APN数据信息、QoS数据信息和PDN数据信息。用户若需要签约EPS（Evolved Packet System）业务，通过签约EPS模板，可减少操作的复杂性。

#### 注意事项

无。

#### 基本概念

**PDN类型**

对于每个会话，需要规定一种数据业务的类型，称之为PDN类型。PDN类型分两大类，分别由ETSI和IETF两个组织制定，目前使用IETF制定的标准。固定分配时，MS必须先签约，由网络分配相应的固定地址，同时写入该用户的USIM卡和用户数据库，PDN地址类型也必须在签约时说明，否则系统对不签约的PDN地址予以拒绝。

会话即为了数据交换在网络的两个节点设备间建立的逻辑连接，也指任何两台数据设备间的任意链路。
