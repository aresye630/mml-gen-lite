# 资源管理

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

无。

#### 功能描述

资源管理包括Pod管理和虚拟设备资源管理。在系统运行阶段，资源管理提供命令，供维护人员查询虚拟资源状态，并调整和维护虚拟资源。

#### 注意事项

无。

## 目录内容

- 资源管理
  - 脱机模式管理
    - 结束脱机模式(FIN LOFMODE)
    - 数据加载开关（SET DATASWITCH）
  - Pod管理
    - 修改Pod信息(MOD PODINFO)
    - 增加Pod信息(ADD PODINFO)
    - 删除Pod信息(RMV PODINFO)
