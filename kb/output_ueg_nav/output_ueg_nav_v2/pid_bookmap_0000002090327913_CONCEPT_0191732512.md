# AS主机名管理

- 功能描述
- 基本概念

#### 功能描述

该组命令用于管理AS对端实体和数据库中的ASID间的对应关系。

通过**ADD DMPE**命令增加对端实体时，IMS-HSS会按照顺序自动为对端实体分配ID。IMS-HSS和AS间的PNR/PNA和SNR/SNA消息基于ASID进行处理，因此为了避免容灾倒换后因主用局和容灾局增加AS对端实体的顺序不一致导致的业务异常，需要通过该组命令对AS对端实体和ASID间的对应关系进行管理。

#### 基本概念

**ASID**

ASID是在通过**ADD DMPE**命令配置AS类型的Diameter对端实体时，IMS-HSS自动为对端AS分配的ID，在数据库中唯一标识一个Diameter对端实体。
