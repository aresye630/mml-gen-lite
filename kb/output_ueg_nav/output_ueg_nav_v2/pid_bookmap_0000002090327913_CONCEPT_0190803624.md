# 前转号码变换

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于运营商对登记的国内格式前转号码的前缀根据前转号码变换表进行简单的变换。

对于用户通过营业厅登记或是直接通过手机登记的国内格式前转号码，运营商可以根据业务开展的需要和依据前转号码变换表，进行前转号码变换，对前转号码进行统一规整。例如：把01XXX变换成1XXX，把900129变换成661900129。

#### 注意事项

前转号码变换只对号码属性为国内格式的前转号码有效，对于国际号码格式的前转号码不进行号码变换。

#### 基本概念

**前转号码变换表**

前转号码变换表是反映旧前转号码前缀和新前转号码前缀对应关系的记录表，它一般有多条记录，通过管理前转号码变换表中的记录，运营商就可以实现对前转号码按照统一的规划实行变换。
