# 体验分级

## 目录内容

- 体验分级
  - 体验分级全局参数
    - 高带宽用户功能控制参数
      - 查询高带宽用户功能控制参数（LST HBUSRCTRL）
      - 设置高带宽用户功能控制参数（SET HBUSRCTRL）
    - 低时延业务开关
      - 设置低时延业务开关（SET LOWLATENCYSW）
      - 查询低时延业务开关（LST LOWLATENCYSW）
  - 体验分级用户匹配
    - 高带宽用户属性
      - 查询高带宽用户属性（LST HBUSRATTRCONF）
      - 新增高带宽用户属性（ADD HBUSRATTRCONF）
      - 删除高带宽用户属性（RMV HBUSRATTRCONF）
