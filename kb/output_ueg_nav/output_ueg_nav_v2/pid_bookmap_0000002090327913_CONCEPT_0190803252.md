#### 基本概念

**呼叫前转业务**

呼叫前转业务是指系统根据运营商、网络或用户的要求，将呼叫转接到第三方用户的业务。具体包括以下4类：

- 无条件呼叫前转业务CFU（Call Forwarding–Unconditional）

  当移动用户作被叫时，不管被叫用户的终端处于何种状态，所有呼叫都将被前转到第三方用户。这里第三方用户可以是PLMN（Public Land Mobile Network）、PSTN（Public Switched Telephone Network）、ISDN（Integrated Services Digital Network）等网络的任意用户，也可以是语音邮箱等服务台。
- 遇忙呼叫前转业务CFB（Call Forwarding on mobile subscriber Busy）

  当用户忙时，允许用户将来话转接到预先设置的另一个电话号码上或用户的语音信箱中。
- 无应答呼叫前转业务CFNRy（Call Forwarding No Reply）

  被叫移动用户收到网络振铃消息后久不摘机应答，无应答时长定时器超时，呼叫将被前转到第三方用户。
- 不可及呼叫前转业务CFNRc（Call Forwarding on mobile subscriber Not Reachable）

  当网络与移动用户的无线信道连接中断的情况下，移动用户作被叫时，呼叫将被前转到第三方用户。不可及条件包括：寻呼无响应、无线信道指配失败、用户关机等。

**早前转和晚前转**

早前转：GMSC/主叫侧MSC和被叫侧MSC之间（主叫侧MSC和被叫侧MSC可能是同一个MSC）建立话路之前发生的前转。如：无条件前转CFU。

晚前转：GMSC/主叫侧MSC和被叫侧MSC之间（主叫侧MSC和被叫侧MSC可能是同一个MSC）建立话路之后发生的前转。如：遇忙呼叫前转CFB、无应答呼叫前转CFNRy、不可及呼叫前转CFNRc。

**前转号码格式说明**

前转号码格式有以下几种：

- 号码属性为国内号码格式
  - 移动号码（如：13700000001）
  - 本地固话号码（如：28421111）
  - 国内长途前缀 + 区号 + 本地固话号码（如：0 755 28421111）
  - 国内长途前缀 + 区号 + 移动号码（如：0 755 13700000001）
- 号码属性为国际号码格式
  - 国家码 + 移动号码（如：86 13700000001）
  - 国际号码前缀 + 国家码 + 移动号码（如：00 86 13700000001）
  - 国家码 + 区号 + 本地固话号码（如：86 755 28421111）
  - 国际号码前缀 + 国家码 + 区号 + 本地固话号码（如：00 86 755 28421111）

**短消息业务**

短消息业务SMS（Short Message Service）是电信业务的一种，它允许用户通过短消息中心SMC（Short Message Center）发送和接收少量的字符信息，如文字、图片以及声音。短消息业务包括2类：

- 短消息终结业务

  短消息终结业务是指SMC发送短消息给移动用户，移动用户向SMC返回一个关于短消息发送成功或者失败的报告的过程。
- 短消息始发业务

  短消息始发业务是指MS通过SMC把短消息转发到目的用户，SMC向MS返回短消息发送成功或者失败的报告的过程。

**NCC模板**

NCC（Network Capability Configuration）即网络能力配置，是指运营商根据VLR或SGSN实际所支持的业务和MAP版本，对HLR进行设置，使HLR能根据VLR或SGSN实际所支持的业务和MAP版本，进行相关业务与相关MAP流程的处理，提高HLR与VLR/SGSN的兼容性。

NCC模板用于设置VLR或SGSN所支持的业务和MAP版本。使用**ADD NCCTPL**命令预先设置NCC模板，在进行业务和MAP流程的处理时，HLR根据NCC模板中配置的相应业务和MAP版本的支持能力进行处理。例如，NCC模板中的参数“Cancel location中的私有信元”设置为“NR”，则在HLR上对指定的VLR添加该NCC模板后，HLR在下发业务数据时，Cancel location消息中的私有信元不下发到该VLR。

**呼叫闭锁**

呼叫闭锁类补充业务分为呼出闭锁BO（Barring of outgoing calls）和呼入闭锁BI（Barring of incoming calls）两大类。

BO业务包括：

- 闭锁所有呼出业务BAOC（Barring of All Outgoing Calls）
- 闭锁所有国际呼出业务BOIC（Barring of All Outgoing International Calls）
- 闭锁所有除归属国PLMN外的国际呼出业务BOIC-exHC（Barring of Outgoing International Calls except those directed to the Home PLMN Country）

BI业务包括：

- 闭锁所有呼入业务BAIC（Barring of All Incoming Calls）
- 当漫游出归属PLMN国时闭锁呼入业务BIC-ROAM（Barring of Incoming Calls When Roaming Outside Home PLMN Country）

**ODB业务**

ODB（Operator Determined Barring）即运营商决定的闭锁，是指用户接入UMTS或GSM网络的业务能力是由PLMN网络运营商来决定的。ODB业务可分为以下5大类：

- 闭锁出呼叫或移动始发短消息
- 闭锁入呼叫或移动终结短消息
- 闭锁漫游
- 闭锁补充业务接入
- 闭锁分组业务

**非结构化补充业务数据**

非结构化补充业务数据USSD（Unstructured Supplementary Service Data）指用户通过移动终端输入符合USSD格式的非标准的补充业务操作命令，向网络发起特定的业务请求，或者由网络侧向移动终端发起USSD命令以完成某种特定的业务。USSD业务具有交互性高、时延小、服务扩展性强等特点，能够提供移动网上98%以上的扩展数据业务，主要包括3大类：

- 获取公共信息

  常见的应用有：查询火车、飞机、轮船等航班情况，查询金融、股票信息，查询外汇交易信息，获取体育比赛结果，查询影院等订票信息，查询银行账务信息，获取彩票业务信息，查询天气情况。
- 移动银行等电子商务

  常见的应用有：购买彩票、交纳水电费、订票、股票、外汇交易等。
- 与智能业务结合

  常见的应用有：UCB（USSD Call Back）业务。

**鉴权五元组**

鉴权五元组是UMTS鉴权过程中用于完成网络合法性验证的参数，五元组包括以下五个参数：

- RAND：由随机数发生器产生，是网络提供给UE的不可预知的随机数，UE用它来计算XRES及IK、CK。RAND长度为16字节。
- AUTN：用于提供信息给UE，使得UE可以用它来对网络进行鉴权。AUTN的长度为16字节。
- XRES：用于与UE返回得鉴权响应消息中的SRES比较，以确定网络对UE的鉴权是否通过。XRES的长度为4～16字节。
- CK：UMTS的加密密钥。CK长度为16字节。
- IK：UMTS的完整性保护密钥。IK长度为16字节。

**鉴权三元组**

鉴权三元组是GSM鉴权过程中用于完成网络合法性验证的参数，包括以下三个参数：

- RAND：由随机数发生器产生，作为计算三元组中其他两个参数的基础。长度为16字节。
- SRES：RAND和KI用A3算法计算得出，用来判断鉴权是否通过。长度为4字节。
- Kc：RAND和KI用A8算法计算得出，用于空中无线信道加密的密钥。长度为8字节。

**Line2号码**

在线路选择业务中，网络允许移动用户使用一个移动终端、一张SIM卡，设置两个MSISDN号码且两个MSISDN号码分别计费，此时两个MSISDN分别对应Line1和Line2。

- 通过在终端上进行线路设置，Line1和Line2之间的切换可将办公号码和私人号码分开。
- 针对两个MSISDN号码签约不同的业务，用户也可以将不同类型的业务分开使用。

**位置定位业务**

位置定位业务，简称LCS（LoCation Services），是指移动网络通过特定的定位技术获取移动终端的地理位置信息（经纬度坐标），提供给移动用户本人、通信系统或第三方，并借助一定的电子地图信息的支持，为移动用户提供与其位置相关的业务。

LCS业务可以涵盖从安全到计费、从信息服务到跟踪管理等多个方面的应用，如公共安全业务（紧急业务、紧急警报业务）、基于定位的计费和跟踪业务、基于定位的信息业务（导航、城市观光、定点内容广播）等。

LCS业务包括三种类别，分别是：商务LCS（Commercial LCS）、内部LCS（Internal LCS）和紧急呼叫LCS（Emergency LCS）。

1. Commercial LCS

   商务LCS又叫增值业务LCS，指运营商可以通过LCS为用户提供各种增值业务。例如：向签约用户提供本地区域内某个餐厅所处的地理位置、从当前位置前往该餐厅的路线图等。
2. Internal LCS

   内部LCS业务指接入网利用移动台的位置信息进行某些系统内部操作。比如，可以利用LCS实现基于位置信息的切换，移动网从微观上跟踪手机移动，使网络可以更好的决定手机从当前小区切换到下一个小区。宏观上，长时间跟踪手机位置可以更好地配置网络结构，优化网络资源。
3. Emergency LCS

   指移动用户拨打紧急呼叫号码时，网络侧可以发起LCS业务，通过接入侧定位用户的位置信息。

**CAMEL发展阶段**

CAMEL的发展经历了CAMEL phase 1、CAMEL phase 2、CAMEL phase 3和CAMEL phase 4 四个阶段，每个阶段提供一定的功能集，在相应的功能集中可以提供相应的业务。在CAMEL发展的四个阶段，CAMEL特性的应用如下：

- CAMEL phase 1：CAMEL特性应用于与移动始发和移动终结的呼叫相关的业务。
- CAMEL phase 2：CAMEL特性应用于与补充业务调用相关的业务，同时是CAMEL phase 1 的增强。
- CAMEL Phase 3：CAMEL特性应用于始发短消息业务（SMS MO）、GPRS会话和PDP上下文、HLR用户数据的控制和网络信令负荷，同时是CAMEL phase 2 的增强。
- CAMEL Phase 4：CAMEL特性应用于终结短消息业务（SMS MT）、呼叫路由优化、IP多媒体子系统控制，同时是CAMEL phase 3 的增强。

**多MSISDN业务**

多MSISDN号码功能是指系统为各种不同数据业务提供不同MSISDN号码，不同的MSISDN号码对应不同的数据业务。需要进行某种业务的呼叫时，直接呼叫该业务对应的MSISDN号码。

主叫发起数据呼叫，必须通过某种方式通知被叫用户，才能实现预期的呼叫。对于移动主叫，在发起SETUP时，携带的承载能力指示主叫的业务要求，GMSC在取路由信息请求中把该承载能力传递给HLR，HLR检测到取路由信息请求中携带有承载能力，在取漫游号码请求中又传递给VMSC/VLR，这样就实现了主叫业务要求到被叫的传递。

但对于PSTN用户，由于TUP信令不能携带承载能力，这时需要多MSISDN号码功能实现主叫业务要求到被叫的传递。当GMSC发出的取路由信息请求到达HLR后，HLR检测到请求消息中未携带承载能力，则取出数据库中该号码对应的承载能力，并在取漫游号码请求消息中传递给VMSC/VLR，从而实现主叫业务要求的传递。

多MSISDN用户有一个主号码和多个辅号码。辅号码定义了对应的承载能力，主号码定义了一个缺省的承载能力。主号码的缺省承载能力也使得用户在对主号码进行数据业务呼叫时，如果主叫没有带承载能力，HLR也可以针对主号码下发一个用户要求的缺省承载能力。

一张卡最多支持255个MSISDN号码，其中可以支持最多254个为辅号和一个主MSISDN号码。

**Cancel Location消息**

通过向VLR/SGSN发送Cancel Location消息，可以删除HSS/HLR中指定用户在相应VLR/SGSN中的用户信息。

以下情况，HSS/HLR会向VLR/SGSN发送Cancel Location消息：

- 在用户的位置更新过程中，HSS/HLR在新的VLR/SGSN中成功插入用户数据后，会自动向原VLR/SGSN发送Cancel Location消息，原VLR/SGSN收到此消息后，会将该用户的数据删除。
- 在PGW Web LMT上，执行**SND CANCELC**命令，向指定VLR/SGSN发送Cancel Location消息。
- 用户补卡和销户时，HSS/HLR会自动向用户所在的VLR/SGSN发送Cancel Location消息，VLR/SGSN收到此消息后删除原来的用户数据。
- 用户漫游到一个VLR/SGSN时，如果该用户签约该VLR/SGSN的漫游限制业务，HSS/HLR会自动向该用户当前所在的VLR/SGSN发送Cancel Location消息，使该用户不能在该区域漫游。

**语音组呼业务**

语音组呼业务VGCS（Voice Group Call Service）可以建立到属于某一给定服务区（组呼区域）的一组业务用户的群组语音呼叫，呼叫采用半双工模式。呼叫期间任何业务用户都可以成为讲者，但任一时刻只允许一个业务用户讲话，其他业务用户为听者。

VGCS在建立业务用户的群组呼叫时，还可以同时建立到调度员用户的专有连接，该连接采用全双工模式，调度员用户可以随时接收组呼的语音信息，也可以随时向整个组发布语音信息。

如果VGCS呼叫组呼区域跨越多个MSC，则需要指定其中某一个MSC为锚定MSC（ANCHOR MSC），其他的MSC称为中继MSC（RELAY MSC）。呼叫的建立和释放，调度员的接入均由ANCHOR MSC处理，RELAY MSC仅负责建立本MSC下小区的组呼通道，并向ANCHOR MSC传递本MSC下业务用户的组呼信令。

VGCS呼叫可以由业务用户发起，也可以由在GCR中签约了组呼发起权限的调度员发起。

- 调度员：每个VGCS呼叫都可以在GCR中签约最多5个调度员。调度员可以是固定用户或移动用户，通过网络为其建立的专有通道参与组呼的语音通信。
- 业务用户：在HLR中签约VGCS业务的移动用户，每个业务用户都可以同时签约最多50个VGCS呼叫。业务用户通过组呼区域内每个小区分配的组呼通道参与组呼的语音通信。业务用户可以在ANCHOR MSC或者RELAY MSC下发起/结束VGCS呼叫。

VGCS呼叫可以由发起呼叫的业务用户结束，也可以由在GCR中签约了组呼结束权限的调度员结束。

组呼发起后，所有业务用户均通过本小区分配的组呼通道接收语音，当业务用户占用上行成为讲者时，则占用上行通道发送自己的语音给其他用户。讲者用户占用的上行通道可以是组呼语音通道的上行信道（称为1.0上行占用），也可以是网络为其分配的专有信道（称为1.5上行占用）。其中，1.0方式上行又分为单信道和多信道，即组呼采用1.0方式上行占用时，组呼初始发起阶段，网络是否为主叫业务用户分配专有信道。多信道方式会给主叫业务用户分配专有信道，待主叫业务用户第一次释放上行之后，所有业务用户占用上行时，才会使用所在小区的组呼通道的上行信道；而单信道方式会在组呼初始发起阶段使主叫业务用户占用其所在小区的组呼通道的上行信道。

**语音广播业务**

语音广播业务VBS（Voice Broadcast Service）可以建立到属于某一给定服务区（组呼区域）的一组业务用户的群组语音广播呼叫，呼叫期间仅发起者可以讲话，加入广播呼叫的其他用户都只能作为听者。语音广播业务可以视为语音组呼业务的一种特例：只有主叫业务用户可以讲话的组呼。

VGCS在建立业务用户的广播呼叫时，还可以同时建立到调度员用户的专有连接，调度员用户通过专有连接接收发起者的语音信息。

如果VGCS呼叫组呼区域跨越多个MSC，则需要指定其中某一个MSC为锚定MSC（ANCHOR MSC），其他的MSC称为中继MSC（RELAY MSC）。呼叫的建立和释放，调度员的接入均由ANCHOR MSC处理，RELAY MSC仅负责建立本MSC下小区的组呼通道。

VBS呼叫可以由业务用户发起，也可以由在GCR中签约了组呼发起权限的调度员发起。

- 调度员：每个VBS呼叫都可以在GCR中签约最多5个调度员。调度员可以是固定用户或移动用户，通过网络为其建立的专有通道参与组呼的语音通信。
- 业务用户：在HLR中签约VBS业务的移动用户，每个业务用户都可以同时签约最多50个VBS呼叫。业务用户通过组呼区域内每个小区分配的组呼通道参与组呼的语音通信。业务用户可以在ANCHOR MSC或者RELAY MSC下发起/结束VGCS呼叫。

VBS呼叫可以由发起呼叫的业务用户结束，也可以由在GCR中签约了组呼结束权限的调度员结束。

VBS呼叫也可以配置1.5方式，业务表现和1.0多信道相同。

**一号多卡业务**

一号多卡业务（又称多IMSI业务或者MIMSI业务）指一个MSISDN号码对应多个IMSI号码的业务，即多个MS可以使用不同的（U）SIM卡而共用一个MSISDN号码。当这些MS作为主叫时，其业务流程与普通的主叫业务流程一样；而当这些MS作为被叫时，其业务流程分为主辅卡、顺振、同振和平等卡四种流程。

- 主辅卡流程：当某主叫用户呼叫被叫MSISDN号码时候，系统仅对呼叫序号最高且在网的IMSI进行呼叫。
- 顺振流程：当某主叫用户呼叫被叫MSISDN号码时候，系统将按照被叫用户在HLR中设置呼叫序号的优先级，先振铃第一个被叫MS；如果第一个被叫MS没有接通，则按顺序振铃下一个被叫MS，直至有一个被叫MS应答。
- 同振流程：当某主叫用户呼叫被叫MSISDN号码时候，系统将同时振铃所有的被叫MS，当其中的任意一个被叫MS应答时，系统将立即停止振铃其他被叫MS。
- 平等卡流程：当某主叫用户呼叫被叫MSISDN号码时候，系统将振铃当前HLR中登记有位置信息的MS。

**主叫号码识别限制业务（CLIR）**

主叫线识别限制CLIR（Calling Line Identification Restriction）。该业务是一种向主叫用户提供的补充业务，它限制将主叫用户号码识别提供给被叫用户。 作为一个选项，运营商可以向用户提供永久限制、临时允许、临时限制三种模式的CLIR业务。

- 永久模式：对每个呼叫都调用CLIR业务。
- 临时允许模式：缺省状态下不调用CLIR业务，但可以通过手机操作对某个呼叫临时调用CLIR业务。
- 临时限制模式：缺省状态下调用CLIR业务，但可以通过手机操作对某个呼叫临时屏蔽CLIR业务。

**被叫号码识别限制业务（COLR）**

被接线识别限制COLR（Connected Line Identification Restriction）。该业务是一种向被叫用户提供的补充业务，当签约用户为被叫用户时，限制向主叫用户提供被接用户号码识别。

**VGCS业务**

VGCS（Voice Group Call Service）业务是指实现多对多的话音呼叫业务，允许同时有至多6个人讲话，包括5个调度员和1个业务用户，听者数量无限制。参与VGCS呼叫的成员包括两类：调度员和业务用户：

- 调度员

  VGCS呼叫的调度员可以是固定用户或移动用户，每个调度员通过网络为其建立的专用通道参与组呼的话音通信，所以呼叫期间所有调度员都可以随时讲话。
- 业务用户

  业务用户是签约VGCS的移动用户，被叫业务用户通过组呼区域内的组呼通道参与组呼的话音通信，即所有的业务用户抢占一个上行链路。业务用户抢占上行链路可以通过eMLPP（Enhanced Multi-Level Precedence and Pre-emption service）优先级方式实现。

**VBS业务**

VBS（Voice Broadcast Service）业务与VGCS业务基本类似，主要不同之处在于：在VBS呼叫期间只有组呼发起者可以讲话，其他成员始终处于听者状态。简单地说，VBS就是实现一对多的话音业务。讲话者只能有一个，可以是主叫调度员或业务用户，听者数量无限制。参与VBS呼叫的成员包括两类：调度员和业务用户：

- 调度员

  VBS呼叫中最多可以有5个调度员，VBS呼叫的调度员可以是固定用户或移动用户，通过网络为其建立的专用通道参与VBS呼叫的话音通信。
- 业务用户

  业务用户为签约VBS业务的移动用户，被叫业务用户通过组呼区域内的组呼通道参与VBS呼叫的话音通信。

**ADD业务**

ADD（Automatic Device Detection）业务，即自动设备检测业务，是指当HLR检测到用户的IMEI（International Mobile Equipment Identity）/IMEISV （International Mobile Equipment Identity Software Version）、IMSI、MSISDN或者用户类型（预付费或者后付费）发生改变时，将相关信息发送给第三方业务平台ADD server，ADD server根据运营商设定的业务需求，将用户数据通过短消息或者USSD消息更新到用户终端。例如，GPRS业务数据设置非常复杂，对终端用户的技能要求较高，使用ADD业务简化了终端用户的业务配置操作，当用户更换终端时，ADD server会自动获取用户新的终端信息，然后通过短消息或者USSD消息发送给终端，更新数据业务配置信息，从而提高了客户满意度。

**Super-Charger业务**

Super-Charger业务的主要功能是用来减少网络中的信令流量。具体来说，当一个用户从支持Super-Charger功能的网络实体（例如MSC/VLR）漫游到一个新的网络实体中进行位置更新，HLR不需要向之前的网络实体发送位置取消消息。当用户再次漫游到保留有用户数据的网络实体中时，仅当用户数据无效时，HLR才需要下发插入用户数据消息，从而减少网络中的信令流量。

Super-Charger业务要求HLR提供一种可以判断保存在网络实体中的用户数据是否有效的机制。HLR通过引用“年龄指数”参数来实现该机制。具体业务实现原理请参见产品手册中的Super-Charger业务特性描述。

**DIC业务**

用户平时所呼叫的对象一般都可以分为几大类，比如家人，同事，同学等。用户想知道他最近一段时间对每一类(或者某一类)对象呼叫所花的费用，为了满足这个需求而引入了DIC（Dial Identification Code）业务。签约了DIC业务的用户在进行呼叫时，在拨号数字中可以携带DIC码，拨号码为“被叫号码+#+DIC码”，用于区分对不同用户的呼叫，于是MSC出的话单中就可以显示对每一类(或者某一类)对象呼叫所消耗的费用。

**欢迎短消息业务**

欢迎短消息业务是指用户在漫游状态时，提示用户当前的漫游地欢迎信息及对此漫游地进行简要的介绍并推出本地特色宣传的一项业务。运营商为了提高客户满意度和用户体验，需要提供一种友好的提醒业务，如天气情况、欢迎、辞别以及当地的酒店信息等。

**业务区域限制**

业务区域限制是运营商通过对HLR的设置以达到限制指定用户使用指定业务的功能。例如，在发生了恶性社会群体事件，为了防止负面影响迅速扩大，可以在特殊情况下对除党、政、医以外的普通用户分别停止短信、语音、GPRS等业务。

**LINKED SIM业务**

LINKED SIM业务是通过对两个独立的用户（两对独立的IMSI与ISDN）建立关联的方式，控制其中一个用户作为激活状态的用户，当对未激活状态的用户进行寻呼或发短消息时，呼叫接续到激活状态用户，短消息被激活状态用户接收。

当处于未激活状态的用户进行了任意一个呼叫操作，该用户将被切换为激活状态，而原来处于激活状态的用户切换为未激活状态。

**RZONE业务**

RZONE业务又称增强区域漫游限制业务(“RZONE”是用户增强区域漫游限制业务的区域码)，用于对用户的漫游区域进行限制。使用**ADD SUB**命令给用户开户时可以为用户签约该业务。如果开户时没有签约，则可以使用**MOD RZONE**命令为用户签约。

**CCBS业务**

CCBS（Completion of Calls to Busy Subscriber）业务，即遇忙呼叫回拨业务。签约该业务的用户A在拨打用户B时，如果用户B忙，则在用户B变成空闲以后，网络会向主叫用户振铃，主叫用户A可直接接听电话，即网络会让用户A自动完成呼叫，不需要用户A再次拨打用户B。

**ATM业务**

ATM(Any Time Modification)业务即任意时刻用户信息修改功能，ATM是由SCP向HLR发起的，用于修改用户的CF/CB/ODB/CSI信息的流程。当前HLR仅支持修改用户的MCSI信息。

**ATSI业务**

ATSI(Any Time Subscription Interrogation)业务即任意时刻用户信息查询功能，ATSI是由SCP向HLR发起的，用于查询用户的CF/CB/ODB/CSI信息以及VLR/SGSN支持的CAMEL版本信息的流程。当前HLR支持查询用户的O-CSI，T-CSI以及ODB信息。

**CUG业务**

CUG（Closed User Group）业务，即闭合用户群业务。该业务是一种补充业务，用户可以连接到PLMN和其他网络来建立一个CUG闭合用户群，出入该用户群的呼叫会受到限制。一个用户可以成为一个或多个CUG的成员，可以设定CUG的成员与群内的用户通信还是与群外的用户通信。

用户群的呼叫限制分为群内呼叫限制和群外呼叫限制。

- 群内呼叫限制分为以下几种：
  - 群内呼叫无限制：允许用户接收群内其他用户的呼叫，也允许用户呼叫群内其他的用户。
  - 群内呼入禁止：不允许用户接收群内其他用户的呼叫，但允许用户呼叫群内其他的用户。
  - 群内呼出禁止：不允许发起到群内其他用户的呼叫，但可以接收群内其他用户的呼叫。
- 群外呼叫限制分为以下几种：
  - 群外呼入允许：允许接收群外用户的呼叫，但不允许呼叫群外用户。
  - 群外呼出允许：允许发起到群外用户的呼叫，但不能接收其他群用户的呼叫。
  - 群外呼入呼出禁止：只允许发起到群内用户的呼叫，不能发起到群外用户的呼叫，不能接收群外用户的呼叫。
  - 群外呼入呼出允许：允许用户接收群外用户的呼叫，也允许用户发起到群外用户的呼叫。

**功能号码**

功能号码用于表示一个工作岗位而不是一个真实的用户。当前在岗人员通过将MSISDN号码登记到功能号码上，建立起功能号码和真实用户之间的联系。调度台通过呼叫功能号码对当前在岗的真实用户进行调度和指挥。当岗位人员轮换时，真实用户的MSISDN号码发生变化，但岗位的功能号码不变，可以通过拨打该功能号码呼叫岗位目前的在岗人员。

**鉴权AUC**

为了帮助运营商高效地管理卡号资源，华为提出鉴权AUC的解决方案，帮助运营商解决在迁移用户到新的HLR时，划分号段混乱和卡号对应关系混乱的问题。鉴权AUC的主要功能如下：

- 鉴权功能：负责用户的鉴权，实现鉴权与业务分开。
  - 鉴权消息发送到AUC中，如果AUC中保存了用户的鉴权数据KI(Individual Subscriber Authentication Key)，则直接在AUC中进行鉴权。
  - 如果AUC中没有保存用户的鉴权数据KI，则会根据AUC配置的FNR（Flexible Number Routing）支持能力转发到目标HLR中完成用户鉴权。
- 信令转发功能：负责将以IMSI寻址的业务消息转发到目标HLR处理。例如：位置更新、补充业务操作、非结构化补充业务（USSD）操作、PurgeMS等。
  - 如果鉴权数据KI存在于鉴权AUC中，则业务消息根据鉴权AUC中的鉴权数据对应的HLRSN查找HLRNO（HLRSN和HLRNO的对应关系通过执行**ADD HLRSN**命令配置），然后将消息转发到该HLRNO。
  - 如果鉴权数据KI在鉴权AUC不存在，则会根据AUC配置的FNR（Flexible Number Routing）支持能力转发给目标HLR处理。

  **说明** 

  鉴权AUC提供FNR功能，支持IMSI灵活路由。需要配置的数据为：
  - 执行**SET MAPCONF**命令，配置参数“是否支持FNR功能”为“TRUE”。
  - 执行**ADD IMSIRTINFO**命令，增加IMSI全局路由数据，即配置IMSI号段与/HLR的对应关系。
  - 执行**ADD IMSIRTSUB**命令，增加IMSI用户路由数据，即配置IMSI号码与HLR的对应关系。

**CFD业务**

CFD（Call Forwarding Default）业务又称缺省呼叫前转业务，是对遇忙呼叫前转（CFB）、无应答呼叫前转（CFNRy）、不可及呼叫前转（CFNRc）这三个前转业务的补充，是指允许用户在某些情况下将来电转接到用户自己预先设置的另一个电话号码、语音邮箱或秘书台上。一旦用户的CFD业务被激活，则当任意用户呼叫该用户时，若出现下述任一情况，呼叫就会转移到该用户预先设置的另一个电话号码、语音邮箱或秘书台上：

- 用户忙。
- 系统寻呼MS失败或长时间振铃后用户无应答。
- 用户处于去激活状态。
- 系统不知道用户的当前位置。
- 用户当前不可接入。

CFD业务不能由移动用户操作，只能由运营商通过数据管理系统给用户进行设置。

**CW业务**

CW（Call Waiting）业务又称呼叫等待业务，是指被叫用户对主叫用户正在等待的呼叫可以选择接收、拒绝或不处理。主叫用户在呼叫等待期间将收到等待通知，允许主叫用户在如下情况收到入呼叫通知：

- 入呼叫没有空闲的业务信道可使用
- 移动用户正在通话
- 移动用户正在保持呼叫

每个用户只能有一个等待呼叫，当用户已经有了一个等待呼叫后，系统将不会接入下一个呼叫。

通常呼叫保持和呼叫等待一起使用，需要在HLR同时签约。当被叫用户已接听电话，要接通新的来电，就要求具有呼叫等待的功能，而在新的呼叫接通后，要把现有呼叫保持住才能在新老呼叫间自由切换。

**功能号码寻址业务**

FM（Follow Me）业务是功能号码寻址业务，功能号码用于表示一个工作岗位而不是一个真实的用户。当前在岗人员通过将MSISDN号码登记到功能号码上，建立起功能号码和真实用户之间的联系。调度台通过呼叫功能号码对当前在岗的真实用户进行调度和指挥。当岗位人员轮换时，真实用户的MSISDN号码发生变化，但岗位的功能号码不变，可以通过拨打该功能号码呼叫岗位目前的在岗人员。

与FM业务相关的基本概念如下：

- 初始用户

  初始用户可修改远端用户的FM业务数据，使对远端用户的呼叫前转到本用户。一个初始用户可以与多个远端用户相关联，对多个远端用户的呼叫可以前转到同一初始用户。
- 远端用户

  远端用户由运营商定义，是进行FM呼叫时的被叫用户，一般是一个虚拟用户，特殊情况可以是真实用户。远端用户最多可以与五个初始用户相关联，对远端用户的呼叫会前转到与它关联的初始用户。
- 初始号码

  初始号码是初始用户的MSISDN号码，所有对远端用户发起的呼叫都会转移到该号码。
- 远端号码

  远端号码是远端用户的功能号码，与初始号码相关联，是进行FM呼叫时的被叫号码。一般是一个运营商定义的虚拟号码，特殊情况可以是真实用户的MSISDN号码。
- 潜在初始用户

  出于安全考虑，为了不让任意用户都能成为远端用户的初始用户，运营商可以在FM业务的功能节点FFN（FollowMe Function Node）设置远端用户的潜在初始用户，只有潜在初始用户才能登记为远端用户的初始用户。
- FM业务管理者

  管理者可以撤销指定远端用户和初始用户的前转关联。
- 功能节点FFN

  功能节点FFN是运营商定义的一个网络节点，远端用户的FM数据存放在该节点。由该节点完成功能号码到初始用户的呼叫前转，呼叫前转可以通过CFU、CAMEL等业务实现。

**自动换卡功能**

自动换卡功能是指用户可以在“有效期限”内任意时刻换卡，换卡后保持用户的MSISDN号码不变。用户在有效期内，如果一直没有使用新卡，则旧卡仍能正常使用；一旦使用了一次新卡，则换卡完成，旧卡就不能再使用。如果超过了有效日期，用户仍没有使用新卡，换卡会自动完成，旧卡就不能再使用。该功能相当于提供了一个灵活的补卡方式，通过先为用户备份一张与原MSISDN号码相同的卡，一旦用户的SIM卡或USIM卡丢失或损坏，可以快速换卡使用。

**ALS业务**

ALS（Alternative Line Service）业务又称双线路可选业务。通过该业务，网络允许移动用户使用一个移动终端、一张SIM卡，设置两个MSISDN号码且两个MSISDN号码分别计费，此时两个MSISDN分别对应Line1和Line2。

- 通过在终端上进行线路设置，Line1和Line2之间的切换可将办公号码和私人号码分开。
- 针对两个MSISDN号码签约不同的业务，用户也可以将不同类型的业务分开使用。

**多SIM业务**

多SIM业务是指将最多9个用户绑定到一个群组，其中这9个成员用户都有自己的IMSI和MSISDN号码。这9个成员用户都有自己的签约数据，可以通过各自的IMSI或MSISDN号码来独立管理。群组内存在一个主用户和一个激活用户。主用户为群组成员提供统一的签约数据；激活用户用于接收群组内所有成员的入呼叫（语音和短信）。如果用户漫游地支持多SIM业务，则群组成员出呼叫（语音和短信）使用主用户的MSISDN号码。如果用户漫游地不支持多SIM业务，群组成员出呼叫（语音和短信）使用自己的MSISDN号码。

**T-CSI业务**

T-CSI是被叫CAMEL签约信息，在移动用户做被叫的SRI流程，T-CSI数据由HLR传递给GMSC，T-CSI智能业务将被触发。

T-CSI的CAMEL数据包括：

- TDP（Triger DP）清单

  TDP清单指示所应触发的DP。T-CSI采用DP12、DP13和DP14。
- gsmSCF地址

  对某个特定用户，用来接入到gsmSCF的地址。该地址为E.164格式号码，用来进行路由寻址。不同的gsmSCF地址和不同的TDP相关联。
- 业务键

  由gsmSCF用来识别需要采用的业务逻辑。
- 缺省呼叫处理

  当gsmSSF与gsmSCF之间的对话出现差错时或者呼叫受限于gsmSSF里的CallGap时，缺省呼叫处理指示出对呼叫应给予释放还是继续。
- DP触发准则

  指示SSP是否应向gsmSCF请求指令。
- CAMEL能力处理

  指示gsmSCF所要求的CAMEL业务阶段。

**多SIM增强业务**

多SIM增强业务是指将最多9个用户绑定到一个群组，其中这9个成员用户都有自己的IMSI和MSISDN号码。这9个成员用户都有自己的签约数据，可以通过各自的IMSI或MSISDN号码来独立管理。群组内存在一个主用户和一个激活用户。主用户是通过**MOD MSIM**签约多SIM增强业务时绑定的用户；激活用户通过**MOD COMISDN**添加和设置，用于接收群组内所有成员的入呼叫（语音和短信）。

**IMS动态数据同步功能**

IMS动态数据同步功能是指主用局处理业务的时候，需要判断业务请求消息是否修改了动态数据，如果动态数据被修改，则在业务处理成功后，主用局UDM会将变化的数据通过PPR（Push-Profile-Request）消息发送到容灾局，容灾局接收到同步请求后，将PPR消息中携带的变更数据更新到数据库。

**IP-SM-GW**

IP-SM-GW即IP短消息网关，实现IMS域和CS域的短消息互通功能。短消息业务SMS（Short Message Service）是CS域的基本电信业务之一，它允许用户通过短消息中心SMSC（Short Message Service Center）发送和接收字符信息。LTE用户在IMS域下发送的IP短消息通过IP-SM-GW转换成CS短消息，经由SMSC存储和转发，实现IMS域和CS域的短消息互通。

**LCK锁业务**

用于用户欠费停机/复机的场景下，限制或允许用户的呼入、呼出，CS/PS域的位置更新以及对GPRS/EPS业务和NON3GPP业务的使用。

当给欠费的用户停机或对已停机的用户取消停机时，可以使用**MOD LCK**命令给用户加锁或解锁：

- 通过加锁，禁止用户的呼入、呼出、CS/PS域的位置更新以及对GPRS/EPS业务和NON3GPP业务的使用，即给用户停机。
- 通过解锁，恢复用户的呼入、呼出、CS/PS域的位置更新以及对GPRS/EPS业务和NON3GPP业务的使用，即给用户复机。

**GROUPSIM用户组业务**

GROUPSIM用户组业务是指将最多8个用户绑定到一个群组，共用一个组MSISDN。组MSISDN是虚拟用户，8个成员用户可以是本HLR的用户，也可以不是，成员用户有独立的签约数据。GROUPSIM用户组可以设置成员号码作为短消息接收号码、语音接收号码、多媒体短消息接收号码和LCS接收号码。在UDM中支持管理GROUPSIM用户组信息和用户组成员。操作员可以通过**MOD GROUPSIM**命令新增一个GROUPSIM用户组，通过**MOD GROUPUSER**新增该GROUPSIM用户组成员，或修改该GROUPSIM用户组成员的数据。
