# STE业务

- 功能描述
- 基本概念

#### 功能描述

该组命令用于修改和查询2G/3G用户的Spatial Triggers业务数据。

#### 基本概念

**Spatial Triggers**

当终端用户在MSC上进行位置更新、呼叫、短消息或者补充业务等操作时，可以通过Spatial Triggers业务触发通知消息，发往LCS（Location Services）客户端。通过这种机制，运营商可以为用户提供更多基于用户当前位置的竞争性服务，比如基于区域的儿童安全跟踪、当前位置附近的服务主动推送等。

**LCS**

LCS（Location Services），是指移动网络通过特定的定位技术获取移动终端的地理位置信息（经纬度坐标），提供给移动用户本人、通信系统或第三方，并借助一定的电子地图信息的支持，为移动用户提供与其位置相关的业务。

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**IMSI/IMEI文件格式**

IMSI/IMEI文件包含不连续的IMSI号码和IMEI号码，每个IMSI与其对应的IMEI组成一行，格式如下所示：

```
IMSI1 IMEI1
IMSI2 IMEI2
IMSI3 IMEI3
IMSI4 IMEI4
……
IMSIn IMEIn
```

IMSIn为6～15位的十进制数字，IMEIn为14位十进制数字。每行的IMSI、IMEI之间由一个空格分隔，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**MSISDN/IMEI文件格式**

MSISDN/IMEI文件包含不连续的MSISDN号码和IMEI号码，每个MSISDN与其对应的IMEI组成一行，格式如下所示：

```
MSISDN1 IMEI1
MSISDN2 IMEI2
MSISDN3 IMEI3
MSISDN4 IMEI4
……
MSISDNn IMEIn
```

MSISDNn为1～15位十进制数字，IMEIn为14位十进制数字。每行的MSISDN、IMEI之间由一个空格分隔，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
