# IP Spoofing攻击防护

## 目录内容

- IP Spoofing攻击防护
  - IPSpoof攻击防护
    - 展示IP防攻击功能状态（LST IPSPOOFFUNC）
    - 设置IP防护开关（SET IPSPOOFFUNC）
  - 反嗅探告警
    - 查询IP Spoofing攻击告警阈值（LST IPSPOOFALMTHD）
    - 设置IP Spoofing攻击告警阈值控制（SET IPSPOOFALMTHD）
  - 攻击用户去活的报文一分钟内个数门限
    - 设置攻击用户去活报文的阈值（SET ANTISPOOFINGTHD）
    - 查询攻击用户去活报文的阈值（LST ANTISPOOFINGTHD）
