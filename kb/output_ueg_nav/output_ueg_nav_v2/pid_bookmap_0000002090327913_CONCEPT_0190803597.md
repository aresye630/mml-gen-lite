# 优选漫游限制业务

- 命令功能
- 基本概念

#### 命令功能

在HLR中增加对PLMN的定义，同时定义隶属于该PLMN的VLR/SGSN前缀，并设置在该PLMN内的优选漫游方式。

当用户漫游出归属网络时，根据其带上的VLR/SGSN号码前缀，识别其当前漫游的PLMN。再根据该PLMN的优选漫游方式进行位置更新处理。若该PLMN需要按IMSI检查用户是否允许漫游，则再根据用户的IMSI去IMSI前缀列表里匹配，若匹配到了，则按该IMSI前缀对应的规则处理；若没有匹配到，则按该PLMN的缺省处理方式处理。

#### 基本概念

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。

## 目录内容

- 优选漫游限制业务
  - 查询某个优选模板下对应网络漫游用户数（LST TPLROAMNUM）
  - 修改优选漫游业务（MOD TPLROAMPER）
  - 查询运营商的VLR/SGSN号码前缀(LST ROAMPREFIX)
  - 删除PLMN信息（RMV PLMN）
  - 查询优选漫游模板（LST ROAMPERTPL）
  - 查询国家分组和运营商信息(LST ROAMPER)
  - 查询优选漫游业务（LST TPLROAMPER）
  - 查询PLMN信息（LST PLMN）
  - 查询运营商的PLMN标识(LST ROAMPLMN)
  - 查询对应网络漫游用户数(LST ROAMNUM)
  - 配置运营商的PLMN标识(SET ROAMPLMN)
  - 配置运营商的VLR/SGSN号码前缀(SET ROAMPREFIX)
  - 设置国家分组中运营商的漫游比例(SET ROAMPER)
  - 设置优选漫游模板（SET ROAMPERTPL）
  - 修改PLMN信息（MOD PLMN）
  - 增加PLMN信息（ADD PLMN）
