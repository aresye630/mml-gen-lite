#### 命令功能

该组命令用于管理用户的DND（Do Not Disturb）业务。

#### 注意事项

无。

#### 基本概念

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。

**DND业务**

DND业务是一种业务类型。当用户登记该业务后，其他用户呼叫该用户时，将会听到免打扰提示音或忙音。用户不希望有来话干扰时，可以使用该业务，对呼出没有影响。

DND业务与其他业务的冲突关系如表1所示。

| 业务   | 冲突规则                                                                         |
|:-----|:-----------------------------------------------------------------------------|
| CFU  | DND业务优先级高于CFU业务。 当呼叫一个用户时，如果该被叫用户的DND和CFU业务均处于激活状态，呼叫进行拒绝处理，而不会进行CFU前转。      |
| 锚定   | DND业务优先级高于锚定功能。 当呼叫一个用户时，如果该被叫用户的DND和锚定功能均处于激活状态，呼叫进行拒绝处理，而不会进行锚定。           |
| TCSI | DND业务优先级高于TCSI业务。 当呼叫一个用户时，如果该被叫用户的DND和TCSI业务均处于激活状态，呼叫进行拒绝处理，而不会触发TCSI智能业务。 |
