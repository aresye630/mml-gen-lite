# PCRF与对端AF之间链路管理

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

无。

#### 功能描述

PCRF与对端AF之间链路管理包括对端AF链路配置和维护。配置包括增加、修改或删除对端AF链路ID、IP地址、对端端口号、协议类型和链路管理状态。维护包括查询对端AF链路配置和状态信息。

#### 注意事项

无。

## 目录内容

- PCRF与对端AF之间链路管理
  - 查询PCRF对端AF链路配置信息(LST PAFL)
  - 增加PCRF对端AF链路(ADD PAFL)
  - 修改PCRF对端AF链路信息(MOD PAFL)
  - 删除PCRF对端AF链路(RMV PAFL)
  - 查询PCRF对端AF链路状态信息(DSP PAFL)
