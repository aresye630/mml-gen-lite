#### 功能描述

该命令用于对GMDB内存数据库的数据进行查询操作。

#### 基本概念

**节点**

对象树中的一个节点，是树中最基本的单位，由一系列属性构成。

**属性**

描述对象的特征。一个属性由属性类型和一个或多个属性值构成。

**唯一标识名**

在一个对象树中唯一标识一个节点的名字（全局）。

**Schema**

节点中存储数据的规则集合，决定节点存放什么，设置数据的尺寸、取值范围、数据值的格式，防止数据混乱。

**OML语句**

OML（object manipulate language），对象操作语言，是USCDB提供的一种类SQL语言，可以通过oml接口进行对象查询功能，具体语法规则如下：

**SELECT \***

- 语法

  SELECT \* FROM T\_010203

  [ FILTER t01 WHERE id IN (1, 2, 3) ]

  [ FILTER t0102 WHERE id > 100 AND id < 200 ]

  [ FILTER t010203 WHERE cost < 100 ]
- 约束

  - OML语言大小写不敏感，标识符外和字符串的值除外。
  - SELECT和FROM之间只能是\*，即支持整节点查询。
  - FROM后边指定待查询的目标节点。
  - FILTER需要按其目标节点在Schema中的深度由根节点到叶子节点排列，不能颠倒顺序。
  - 标识符不超过32个字符，只能由“a～z”、“A～Z”、“0～9”或“\_”组成。
  - 支持“/\*”或者“--”注释。
  - 字符串使用单引号表示，例如：'abc'。
  - WHERE条件说明：
    - 支持如下比较操作：>、<、=、 >=、 <=、in、like、is null、is not null，其中：
      - like支持'%abc%'、'a\_b'和'ab\*'三种模式。
        - “%”表示0个或多个字符。
        - “\_”表示1个字符。
        - 'ab\*'模式仅对raw和varraw类型的字段有效，支持在尾部使用且只使用1个“\*”号，“\*”号前必须有字符且只能是十六进制字符，表示结尾匹配任意多个“\*”号前的字符。如“b\*”表示匹配0或多个b。
      - like支持使用ESCAPE提供转义字符，转义字符仅能用于string类型的字段。在模式串中，转义字符后面只能是转义字符本身、%、\_三者之一。例如: name LIKE 'Hua#\_wei' ESCAPE '#'，此处“#”为转义字符，则“#”后面的“\_”不作为通配符，此处匹配的字符串是'Hua\_wei'。
      - in支持in (1, 2, 3)格式，in和括号之间可以有空格分隔，也可以没有空格分隔。
    - 支持条件“与（AND）”、“或（OR）”操作，AND优先级高于OR，即“A OR B AND C”会理解为“A OR (B AND C)”，支持通过“（）”强制改变优先级，建议应用实现时使用“（）”明确优先级。
    - 支持如下运算操作“+”、“-”、“\*”和“/”，不支持“&”和“|”。
  - FILTER指定过滤条件时，不同的FILTER的节点名字不允许相同。FILTER后的节点必须在同一条路径上。
