# PMS对端服务器管理

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

无。

#### 功能描述

对端服务器管理用于管理UPCF的策略管理服务对端服务器的配置和查询。配置包括增加、修改或删除对端服务器的对端服务器ID、对端服务器名称和应用类型。

#### 注意事项

无。

## 目录内容

- PMS对端服务器管理
  - 删除策略管理服务对端服务器(RMV PMSPEER)
  - 查询策略管理服务对端服务器配置信息(LST PMSPEER)
  - 增加策略管理服务对端服务器(ADD PMSPEER)
  - 修改策略管理服务对端服务器配置信息(MOD PMSPEER)
