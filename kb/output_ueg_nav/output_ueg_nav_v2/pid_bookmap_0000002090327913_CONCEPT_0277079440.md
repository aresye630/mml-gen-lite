# PCRF对端OCS接入点管理

- 功能描述
- 基本概念
- 注意事项

#### 功能描述

PCRF对端OCS接入点的管理用于配置和维护Sy接口下，对端OCS接入点的配置信息。如增加、删除、查询、修改等相关操作。

#### 基本概念

**OCS**

Online Charge System，由3GPP组织提出的具有开放性和通用性，支持基于承载、会话和内容事件统一计费的实时计费系统（3GPP32.296）。这一系统将设备的话务控制功能与计费功能相分离，并建立了计费体制与会话/服务控制的直接交互，使计费完全参与服务的使用过程。3GPP32.299、IETF RFC3588、RFC4006定义了各网元与OCS的接口协议，使用Diameter协议来实时交互计费信息、批价、反算预留，完成对用户的信用控制。

#### 注意事项

无。
