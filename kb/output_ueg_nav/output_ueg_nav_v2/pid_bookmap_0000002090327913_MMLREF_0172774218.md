# 设备管理

- 命令功能
- 注意事项

## 命令功能

实现了对模块、本网元IP地址、LDAP配置和维护相关的功能。

## 注意事项

无。

## 目录内容

- 设备管理
  - IP管理
    - 删除网元业务IP地址(RMV SRVIPADDR)
    - 增加网元业务IP地址(ADD SRVIPADDR)
    - 查询网元业务IP地址(LST SRVIPADDR)
  - 设备档案管理
    - 查询号段范围(LST NUMRANGE)
    - 查询北向关联配置(LST NORTHFUNC)
    - 设置业务配置信息(SET FUNCCFG)
    - 删除号段范围(RMV NUMRANGE)
    - 修改号段范围(MOD NUMRANGE)
    - 增加号段范围(ADD NUMRANGE)
    - 设置北向关联配置(SET NORTHFUNC)
    - 查询业务配置信息(DSP FUNCCFG)
  - 模块管理
    - 修改模块(MOD MODULE)
    - 增加模块(ADD MODULE)
    - 倒换模块(SWP MODULE)
    - 激活模块(ACT MODULE)
    - 删除模块(RMV MODULE)
    - 复位模块(RST MODULE)
    - 停止模块(STP MODULE)
    - 启动模块(STR MODULE)
    - 查询模块(LST MODULE)
    - 去激活模块(DEA MODULE)
  - 隔离状态管理
    - 修改隔离状态(MOD SEGSTATE)
    - 查询隔离状态(LST SEGSTATE)
  - FE插件管理
    - 启用指定的FE插件(ACT FEPLUG)
    - 添加FE插件(LOD FEPLUG)
    - 查询FE插件包信息(LST FEPLUG)
    - 查看FE插件列表和状态(DSP FEPLUG)
    - 删除FE插件(CLR FEPLUG)
    - 加载MML插件(LOD MMLPLUG)
  - 适配插件管理
    - 添加适配插件(LOD ADPPLUG)
    - 查看适配插件包加载状态(DSP ADPPLUG)
    - 删除适配插件(CLR ADPPLUG)
  - 适配包管理
    - 加载适配包(LOD ADPPKG)
    - 查询适配包(LST ADPPKG)
    - 显示适配包(DSP ADPPKG)
    - 删除适配包(CLR ADPPKG)
  - LDAP服务端端口管理
    - 设置LDAP端口号(SET LDAPPORT)
    - 查询LDAP端口号(LST LDAPPORT)
  - LDAP客户端用户管理
    - 查询LDAP客户端用户名及其对应的描述(LST LDAPUSER)
    - 修改LDAP客户端用户名和密码（MOD LDAPUSER）
    - 增加LDAP客户端用户名和密码（ADD LDAPUSER）
    - 删除LDAP客户端用户(RMV LDAPUSER)
  - LDAP应用视图管理
    - 加载LDAP视图（LOD LDAPVIEW）
    - 删除LDAP视图(CLR LDAPVIEW)
  - LDAP连接数阈值管理
    - 查询LDAP连接数阈值(LST LDAPCONNTHD)
    - 设置LDAP连接数阈值(SET LDAPCONNTHD)
