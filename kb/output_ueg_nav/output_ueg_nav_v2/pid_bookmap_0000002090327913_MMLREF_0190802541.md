## 命令功能

承载业务提供在终端接入参考点间传递信息的能力，它是以一组与OSI参考模型的1～3层相对应的低层属性为特征。承载业务为移动通信系统提供数据业务创造了必要条件。

承载业务包含一系列独立的承载业务，用户可以单独签约任意一种承载业务，也可以同时签约多种承载业务。每个承载业务有一种承载业务码。

UDM支持的GSM承载业务包括以下几种：BS21～26、 BS31～34、BS41～46、BS51～53、BS61和BS81。承载业务包含的业务组和业务类别如表1所示。

| 承载业务子类   | 子类含义                                                               |
|:---------|:-------------------------------------------------------------------|
| BS21     | Bearer service 21，data circuit duplex asynchronous (CDA)-300 bit/s |
| BS22     | Bearer service 22，data CDA-1200 bit/s                              |
| BS23     | Bearer service 23，data CDA-1200-75 bit/s                           |
| BS24     | Bearer service 24，data CDA-2400 bit/s                              |
| BS25     | Bearer service 25，data CDA-4800 bit/s                              |
| BS26     | Bearer service 26，data CDA-9600 bit/s                              |
| BS31     | Bearer service 31，data circuit duplex synchronous (CDS)-1200 bit/s |
| BS32     | Bearer service 32，data CDS-2400 bit/s                              |
| BS33     | Bearer service 33，data CDS-4800 bit/s                              |
| BS34     | Bearer service 34，data CDS-9600 bit/s                              |
| BS41     | Bearer service 41，PAD Access CA-300 bit/s，异步PAD存取电路业务-300bit/s。    |
| BS42     | Bearer service 42，PAD Access CA-1200-75 bit/s                      |
| BS43     | Bearer service 43，PAD Access CA-1200 bit/s                         |
| BS44     | Bearer service 44，PAD Access CA-2400 bit/s                         |
| BS45     | Bearer service 45，PAD Access CA-4800 bit/s                         |
| BS46     | Bearer service 46，PAD Access CA-9600 bit/s                         |
| BS51     | Bearer service 51，data PDS-2400 bit/s                              |
| BS52     | Bearer service 52，data PDS-4800 bit/s                              |
| BS53     | Bearer service 53，data PDS-9600 bit/s                              |
| BS61     | Bearer service 61，Alternate Speech/Data，语音/数据交替业务。                 |
| BS81     | Bearer Service 81，Speech followed by Data，语音后紧跟数据业务，可以为所有数据业务。     |

速率1200-75bit/s是指数据传输时，一个方向的用户速率为1200bit/s，另一个方向为75bit/s，主要用于MS到BTS。MS到BTS为75bit/s信令，BTS到MS为1200bit/s应答。
