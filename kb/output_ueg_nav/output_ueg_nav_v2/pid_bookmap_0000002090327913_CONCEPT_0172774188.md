# 业务发放统计规则管理

- 功能描述
- 注意事项
- 配置原则

#### 功能描述

此组命令用于管理业务发放统计对象的匹配规则信息，支持增加、删除、修改和查询对象匹配规则。

业务发放统计规则用来对业务发放统计对象增加具体的匹配规则，当系统在处理业务发放请求消息过程中检测到能和该统计规则匹配时，对该对象进行统计。

一个业务发放统计对象下可以配置不同业务发放请求消息的匹配规则，一个业务发放请求消息也可以在不同的业务发放统计对象中配置相同的规则。

每个业务发放请求消息都有唯一的MML命令与之对应，一个业务发放统计规则所对应的业务发放请求消息是通过其MML命令名与之关联的，还支持配置3个不同的匹配参数及对应的参数值来细化匹配规则。

#### 注意事项

- 一个业务发放统计对象下最多可建立128个匹配规则，所有的业务发放统计对象最多可建立1024个匹配规则。
- 系统中默认存在“业务发放统计对象索引”为“0”，“业务发放统计对象名称”为“ALL Commands Statistic”的业务发放统计对象，该对象可以查询，但不能被修改和删除，也不能添加匹配规则。

#### 配置原则

本命令组无特殊配置原则。

## 目录内容

- 业务发放统计规则管理
  - 删除业务发放统计规则(RMV PROVSTATRULE)
  - 修改业务发放统计规则(MOD PROVSTATRULE)
  - 增加业务发放统计规则(ADD PROVSTATRULE)
  - 查询业务发放统计规则(LST PROVSTATRULE)
