# 安全管理

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

无。

#### 功能描述

安全管理：提供对系统用户、用户组、命令组、对象组、权限等相关管理操作，主要包括用户管理、用户组管理、命令组管理、权限管理、工作站管理、当前对象组、对象组容量、对象组管理、安全策略管理、安全传输管理等。

#### 注意事项

无。

## 目录内容

- 安全管理
  - 证书管理
    - 同步证书 (SYN CERT)
    - 查询证书应用场景信息 (LST CERSCENE)
    - 新增证书应用场景信息 (ADD CERSCENE)
    - 删除证书应用场景信息 (RMV CERSCENE)
  - 安全传输管理
    - 一般文件上传 (ULD GENFILE)
  - 机机用户安全策略管理
    - 修改CGPLite机机用户密码(MOD SUPWD)
  - 模块通讯跟踪
    - 查询运行日志记录级别 (LST LOGLEVEL)
    - 设置运行日志记录级别 (SET LOGLEVEL)
  - FTP安全策略管理
    - 修改内网FTP用户密码(MOD INFTPPWD)
