# HLRSN与云分区数据配置

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

在云部署场景下，操作员通过该组命令可以增加、删除、查询HLRSN与云分区的映射关系。

在云部署场景下，用户数据按照HLRSN存储在不同的云分区上。云分区为云部署环境中的数据存储单元，每个云分区由一套独立的主用/容灾BE构成，有一个唯一的编号。

一个HLRSN只能对应一个云分区；一个云分区可以有多个与其对应的HLRSN。

#### 注意事项

无。

#### 基本概念

**云部署**是指将不同地域间的硬件设备资源逻辑的组合在一起通过USCDB多地灵活部署的方式，逻辑上形成一个统一的用户数据中心，统一对外提供服务。具有无限制容量和服务能力，为运营商提供基于云的用户数据存储和服务。

**图1** 云部署组网图

云部署引入Partition（云分区）的概念：

- Service Partition

  每个Service Partition中BE按IMSI号段存储本服务区的用户数据；FE侧的信令消息就近访问本地Service Partition，实现信令的就近接入。
- Routing Partition

  Routing Partition中的BE（即Root BE）存储所有Service Partition中用户数据的路由信息，即存储用户标识和Service Partition的对应关系。Routing Partition通常与某个Service Partition合设在一起。
