# HTTP管理

## 目录内容

- HTTP管理
  - HLB TLS配置管理
    - 增加HLB TLS协议配置 (ADD UDMHLBTLSCFG)
    - 修改HLB TLS协议配置 (MOD UDMHLBTLSCFG)
    - 查询HLB TLS协议配置 (LST UDMHLBTLSCFG)

    - 删除远端服务器链路集参数配置（RMV HTTPLKSPARA）
