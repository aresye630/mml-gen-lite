# 日志管理

#### 功能描述

本命令用于对PGW操作日志和容灾同步执行失败日志进行管理。

#### 相关概念

**IMSI**

国际移动用户识别码（International Mobile Subscriber Identity），在全球范围唯一标识一个移动用户。IMSI保存在HLR、VLR和SIM卡中，在无线接口及MAP接口上传送。它的总长不超过15位数，采用十进制编码。由MCC（Mobile Country Code）、MNC（Mobile Network
Code）和MSIN（Mobile Subscriber Identification Number）组成。

**MSISDN**

移动台国际ISDN号码（Mobile Station International ISDN Number），是用户为呼叫GSM PLMN中的一个移动用户所需拨的号码。它的总长不超过15位数，采用十进制编码。MSISDN保存在HLR和VLR卡中，在无线接口及MAP接口上传送。由CC（Country
Code）、NDC（National Destination Code）和SN（Subscriber Number）组成。

#### 注意事项

无。

本命令组无特殊配置原则。
