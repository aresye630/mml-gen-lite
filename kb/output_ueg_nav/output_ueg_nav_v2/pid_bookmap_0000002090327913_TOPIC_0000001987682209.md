# HTTP HTR流控管理

## 目录内容

- HTTP HTR流控管理
  - HTTP HTR流控安全边界管理
    - 删除HTR流控安全边界配置（RMV HTTPHTRMS）
    - 增加HTR流控安全边界配置（ADD HTTPHTRMS）
    - 查询HTR流控安全边界配置（LST HTTPHTRMS）
    - 修改HTR流控安全边界配置（MOD HTTPHTRMS）
  - HTTP HTR全局配置管理
    - 设置HTR流控全局配置（SET HTTPHTRCFG）
    - 查询HTR流控全局配置（LST HTTPHTRCFG）
  - HTTP HTR流控状态管理
    - 显示HTR信息（DSP HTTPHTRINFO）
