# 导出任务管理

- 功能描述
- 相关概念
- 注意事项

#### 功能描述

此组命令用于对导出任务进行增加、停止或查看。

#### 相关概念

无。

#### 注意事项

DMA生成的导出文件为UTF-8格式，如果导出数据中包含除ASCII可显示字符外的其他字符，默认导出格式会出现乱码，需要转码为UTF-8格式才能正常显示。

## 目录内容

- 导出任务管理
  - 修改导出任务(MOD EXPTASK)
  - 添加导出任务(ADD EXPTASK)
  - 停止导出任务(STP EXPTASK)
  - 显示导出任务(DSP EXPTASK)
  - 删除导出任务(RMV EXPTASK)
