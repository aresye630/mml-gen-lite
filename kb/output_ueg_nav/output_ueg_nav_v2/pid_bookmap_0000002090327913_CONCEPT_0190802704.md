# CAMEL查询协议模板

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于设置支持CAMEL（Customized Applications for Mobile network Enhanced Logic）查询协议的GMSC（Gateway Mobile Switching Center）号码前缀。

运营商可以针对用户漫游的不同网络，对CAMEL智能业务的触发进行灵活控制，从而提供丰富的增值业务。在具有CAMEL特征的移动网络上，运营商能够提供自定义业务，甚至当用户漫游出归属网络后仍然能够提供这项业务。

CAMEL查询协议表示用户当前漫游所在的非归属网络是否支持该用户归属网络定义的CAMEL业务，并且能够进行网间结算。在HLR中CAMEL查询协议用于用户在非归属网络漫游时，做被叫的SRI流程中控制用户签约的O-CSI和T-CSI数据的下发。非归属网络与归属网络是否有CAMEL查询协议由运营商确定。

#### 注意事项

无。

#### 基本概念

**O-CSI**

O-CSI是主叫CAMEL签约信息。当用户位置更新时，O-CSI数据将被插入用户当前所在的VPLMN（VLR）；在移动用户作被叫（接收从GMSC转发的来电）的SRI流程中，O-CSI数据将被传给IPLMN（Interrogating PLMN）。

O-CSI包含用来调用CAMEL业务逻辑的触发信息。当移动用户在VMSC中做主叫时，或移动用户在VMSC或GMSC中发生前转时，O-CSI智能业务将被触发。

**T-CSI**

T-CSI是被叫CAMEL签约信息，在移动用户做被叫的SRI流程，T-CSI数据由HLR传递给GMSC，T-CSI智能业务将被触发。按照用户签约的T-CSI模板中的信息进行业务逻辑处理。

相对于呼叫普通用户，呼叫签约T-CSI模板的CAMEL用户时，GMSC将向用户归属HLR发起两次SRI（Send Routing Information）请求消息，HLR在第一次SRI响应消息中返回T-CSI数据，然后GMSC在第二次SRI请求消息中带上抑制T-CSI信元（即suppress-T-CSI），HLR检查到该信元后才向用户当前所在VLR取漫游号码，并在第二次SRI响应消息中返回取到的漫游号码。
