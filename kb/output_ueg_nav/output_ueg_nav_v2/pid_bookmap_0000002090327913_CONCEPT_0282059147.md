# NEF订阅事件管理

- 功能描述
- 注意事项
- 基本概念

#### 功能描述

该组命令用于查询和删除用户的NEF监视事件。

#### 注意事项

无。

#### 基本概念

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。

## 目录内容

- NEF订阅事件管理
  - 删除NEF订阅事件记录(RMV EESUBSCRIPTION)
  - 删除NEF全局订阅信息(RMV NEFANYUEINFO)
  - 查询NEF检查策略配置(LST NEFCHKPOLICY)
  - 查询NEF订阅事件记录(LST EESUBSCRIPTION)
  - NEF漫游状态事件通知PLMN黑白名单管理
    - 修改NEF漫游状态事件通知PLMN黑白名单(MOD NEFROAMNTFPLMNWBLIST)
    - 删除NEF漫游状态事件通知PLMN黑白名单(RMV NEFROAMNTFPLMNWBLIST)
    - 查询NEF漫游状态事件通知PLMN黑白名单(LST NEFROAMNTFPLMNWBLIST)
    - 增加NEF漫游状态事件通知PLMN黑白名单(ADD NEFROAMNTFPLMNWBLIST)
  - 增加NEF检查策略配置(ADD NEFCHKPOLICY)
  - 删除NEF检查策略配置(RMV NEFCHKPOLICY)
  - 查询NEF全局订阅信息(LST NEFANYUEINFO)
