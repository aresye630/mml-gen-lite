# 开户

- 命令功能
- 基本概念

#### 命令功能

PGW提供强大的开户功能，不仅可以为单个用户开户，而且可以同时为多个用户批开户。为了简化操作，还提供了模板开户功能。

常见的开户方法有两种：

- 执行**ADD SUB**命令开户，适用于为单个用户开户或大量用户批开户的情况。
- 事先设置各种开户模板，执行ADD TPLSUB命令进行模板开户。此种开户方式适用于有约定功能的用户进行开户的情况。同时，为了简化操作，增加/修改各种业务也可以通过事先设置业务模板，然后采用模板进行增加/修改。

#### 基本概念

**M2M**

M2M是机器与机器之间的连接与通信，以机器终端智能交互为核心、提供网络化的应用与服务。

**MSISDN-less用户**

MSISDN-Less用户是指为节省MSISDN号码资源，用户的IMSI与MSISDN相同且仅以IMSI为唯一标识的M2M用户。

**M2M Common MSISDN用户**

M2M Common MSISDN用户是指一个用户的多个IMSI号码使用相同的MSISDN号码的M2M用户。

**M2M普通用户**

普通M2M用户是指非MSISDN-Less且非Common MSISDN用户的用户。

**开户批操作文件格式**

文件包含IMSI号码和MSISDN号码，每个IMSI号码与其对应的MSISDN号码组成一行。

```
IMSI1 MSISDN1
IMSI2 MSISDN2
……
IMSIn MSISDNn
```

每行的IMSI、MSISDN之间由一个空格分隔，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。

**双线路可选业务**

ALS（Alternative Line Service）即双线路可选业务。通过该业务，用户使用一个移动终端、一张SIM卡，可以设置两个MSISDN号码，两个号码分开计费。提供ALS业务需要MSC/VLR的支持，同时移动终端支持设置线路1和线路2（Line1＆Line2）。

**多MSISDN业务**

多MSISDN号码功能是指系统为各种不同数据业务提供不同MSISDN号码，不同的MSISDN号码对应不同的数据业务。需要进行某种业务的呼叫时，直接呼叫该业务对应的MSISDN号码。

多MSISDN用户一张卡最多支持一个主MSISDN号码和最多254个辅号码。辅号码定义了对应的承载能力，主号码定义了一个缺省的承载能力。主号码的缺省承载能力也使得用户在对主号码进行数据业务呼叫时，如果主叫没有带承载能力，HLR也可以针对主号码下发一个用户要求的缺省承载能力。

**特殊一卡多号业务**

特殊一卡多号业务是指用户可通过一张SIM/USIM卡关联多个MSISDN号码。当用户需要使用一张SIM卡在多个不同运营商网络中漫游时，运营商可以为用户签约特殊一卡多号业务，其中多个号码采用相同Profile（同一份用户数据）。一张卡最多支持9个MSISDN号码，其中可以支持一个主MSISDN号码和最多8个辅MSISDN号码。

**VoWiFi预开户用户**

VoWiFi预开户和正常VoWiFi用户开户的区别在于VoWiFi预开户只有在IMS网络注册后才能使用IMS业务，给用户设置锚定标记为“PRE\_FALSE”或“PRE\_TRUE”标识VoWiFi预开户的激活状态，在处理锚定相关业务时根据设置的锚定标记决定是否将被叫业务锚定到IMS域处理。
