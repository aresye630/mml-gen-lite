# 配置VNF侧IP路由（SDN）

SDN场景，支持通过自动部署和手工部署两种方式配置VNF侧IP路由数据。

推荐采用自动部署。采用自动部署时，请参考本节点下的BGP over静态路由+BFD(IPv4)、BGP over静态路由+BFD(IPv6)、BGP over静态路由+BFD(IPv4v6)进行配置。

手动部署比较复杂。如确实需采用手工部署方式，请参考手动部署进行配置。手动部署时，SDN场景与非SDN场景的配置差异点如下：

- SDN场景 ，VNF的外联口IP采用DHCP动态获取。
- SDN场景，**SET IFIPV6ENABLE**命令的“自动生成链路层地址标志（AUTOLINKLOCAL）”参数必须设置为“TRUE”。
- SDN场景，采用单臂BFD echo探测。
- SDN场景，**ADD SRROUTE**/**ADD SRROUTE6**命令的“DHCP使能标识（DHCPENABLE）”参数必须设置为“TRUE”。
