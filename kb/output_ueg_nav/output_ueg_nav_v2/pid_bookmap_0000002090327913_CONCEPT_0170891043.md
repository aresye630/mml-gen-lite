# PCRF与对端PCEF之间链路管理

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

无。

#### 功能描述

PCRF与对端PCEF之间链路管理包括链路配置和维护。配置包括增加、修改或删除对端PCEF链路ID、对端端口号和链路管理状态。维护包括查询对端PCEF配置和状态信息。

#### 注意事项

无。

## 目录内容

- PCRF与对端PCEF之间链路管理
  - 修改PCRF对端PCEF链路信息(MOD PPCEFL)
  - 增加PCRF对端PCEF链路(ADD PPCEFL)
  - 删除PCRF对端PCEF链路(RMV PPCEFL)
  - 查询PCRF对端PCEF链路状态信息(DSP PPCEFL)
  - 查询PCRF对端PCEF链路配置信息(LST PPCEFL)
