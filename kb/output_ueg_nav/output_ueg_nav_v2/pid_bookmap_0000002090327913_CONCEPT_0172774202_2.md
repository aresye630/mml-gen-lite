# PGW静态流控控制管理

- 功能描述
- 注意事项
- 配置原则

#### 功能描述

此组命令用于管理PGW静态流控配置，包括修改和查询静态流控参数。PGW静态流控是指PGW根据设置的静态流控阈值丢弃超出部分的命令，以限制超载的命令进入系统，减少系统超负荷运行对业务的冲击。

- 流控周期内平均每秒发送的命令数大于PGW的静态流控阈值时，PGW开启静态流控。
- 流控周期内平均每秒发送的命令数少于PGW的静态流控阈值时，PGW解除静态流控。

#### 注意事项

无。

#### 配置原则

本命令组无特殊配置原则。

## 目录内容

  - 查询静态流控参数(LST STCFLOWCTRL)
