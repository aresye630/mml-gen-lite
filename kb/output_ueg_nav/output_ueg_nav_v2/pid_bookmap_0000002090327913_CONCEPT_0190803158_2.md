# Diameter漫游限制配置

- 命令功能
- 基本概念

#### 命令功能

该组命令用于管理全局的Diameter漫游限制业务数据。

Diameter漫游限制业务是指系统根据运营商、网络或用户的要求，对指定HLRSN中所有用户的移动性进行管理，限定是否允许该HLRSN中的用户访问指定的Diameter节点。Diameter节点是一个实现了Diameter协议的功能实体，可以为MME/S4-SGSN/3GPP
AAA所服务的接入网络。通过本组命令设置全局的Diameter漫游限制业务数据可以将指定HLRSN中用户的访问范围限制在某个区域。

#### 基本概念

**Diameter服务节点**

Diameter服务节点即Diameter实体所在服务的网络节点，是一个实现了Diameter协议的功能实体。

## 目录内容

- Diameter漫游限制配置
  - 设置全局Diameter缺省漫游限制(SET DEFGLOBALDIAMRRS)
  - 查询全局Diameter漫游限制(LST GLOBALDIAMRRS)
  - 设置全局Diameter漫游限制(MOD GLOBALDIAMRRS)
