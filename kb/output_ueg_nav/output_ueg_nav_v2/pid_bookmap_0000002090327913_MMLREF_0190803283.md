# 呼叫保持业务

- 命令功能
- 注意事项

## 命令功能

CH（Call Hold）业务允许移动用户中断现有的呼叫，而在随后有需要时重新建立该呼叫。在中断呼叫期间，系统会保留原有呼叫分配的业务信道。

在一个呼叫被保持且未建立一个激活呼叫时，用户可以选择：

- 恢复保持的呼叫
- 建立一个激活呼叫
- 拆除保持的呼叫

在一个呼叫被保持且已建立一个激活呼叫时，用户可以选择：

- 两个呼叫进行交替
- 拆除激活的呼叫
- 拆除保持的呼叫
- 拆除两个呼叫

每个用户只能有一个保持呼叫。
