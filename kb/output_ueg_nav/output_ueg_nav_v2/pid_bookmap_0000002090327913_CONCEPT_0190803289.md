# 计费特性和EPS数据对应关系配置

- 功能描述
- 基本概念

#### 功能描述

该组命令用于在UDM中设置计费特性和EPS数据的对应关系，包含计费特性和OPTGPRS模板、UE最大上行带宽、UE最大下行带宽、Diameter漫游限制模板、PLMN漫游限制模板的对应关系。

在（Vo）LTE自动开户时，UDM从用户的GPRS数据中获取到计费特性信息，再根据该组命令已配置的数据去获取对应的EPS数据。

#### 基本概念

无。

## 目录内容

- 计费特性和EPS数据对应关系配置
  - 增加计费特性和EPS数据对应关系(ADD CCEPS)
  - 查询计费特性和EPS数据对应关系(LST CCEPS)
  - 修改计费特性和EPS数据对应关系(MOD CCEPS)
  - 删除计费特性和EPS数据对应关系(RMV CCEPS)
