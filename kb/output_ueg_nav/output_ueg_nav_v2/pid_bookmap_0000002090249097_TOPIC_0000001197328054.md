# 配置UDM/HSS

**说明** 

- UDM（UEG）部署在园区网络，该场景下，需要参考本章节配置UDM/HSS。
- 采用中心的UDM时，园区不部署UDM。该场景下，不需要配置本章节。
- UDM/HSS部署在中心网络+UDM/HSS部署在园区网络时，中心网络的UDM/HSS正常时，UEG与中心网络的UDM/HSS进行业务交互；中心网络的UDM/HSS全故障或承载网故障时，UEG与园区网络的UDM/HSS进行业务交互。该场景下，需要参考本章节配置UDM/HSS。
- 开局时，双DC场景，请按照如下章节的顺序及具体内容进行配置。

  本章节描述的双DC，指的是园区内部署两台UEG。本章节描述的DC1对应UEG 1；DC2对应UEG 2。
- 开局时，单DC场景（不支持商用），请按照如下章节的顺序及具体内容进行配置，区别点如下：
  - 不需要配置DC2的数据。
  - 不需要配置AMF02和MME02相关的数据。
  - 不需要配置USCDB和USCDB对接数据。
  - 不需要配置容灾参数。
- 使用到的IP等数据均为样例值，请修改为局点实际规划的数据。

UDM从逻辑上划分为FE（Front End）和BE（Back End）两个业务网元：

- FE（Front End）网元也称为UDM/HSS网元，实现UDM/HSS功能实体的功能，包括协议处理、业务处理以及数据管理。
- BE（Back End）网元也称为USCDB网元（Unified Subscriber Center DataBase），实现UDR（Unified Data Repository）功能实体的功能，提供用户数据的增加、删除、更新和查询服务，为FE提供数据存储、数据管理、数据服务等功能支撑。
