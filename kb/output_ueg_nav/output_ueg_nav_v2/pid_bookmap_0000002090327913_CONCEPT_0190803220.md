# 短消息前转业务

- 命令功能
- 基本概念

#### 命令功能

短消息前转业务SMSCF（Short Message Service Call Forwarding）是指允许用户将发向自己的所有短消息转接到一个预先设置的号码上。

一旦用户A激活了自己的SMSCF业务，则当任意用户给用户A发短消息时，所有的短消息都会先试图前转至用户A设置的前转号码上。当用户A设置的前转号码由于某些原因（如没有签约MT业务或停机）导致不能接收短消息时，短消息将会发给用户A。

#### 基本概念

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。

**短消息前转业务和ODB/CB业务冲突关系**

- 短消息前转业务和ODB业务冲突关系
  - 用户签约ODB-BAOC，则ODB和短消息前转冲突。
  - 用户签约ODB-BAIC，则ODB和短消息前转冲突。
  - 用户签约ODB-BOCROAM，且用户所在的MSC类型为国际，则ODB和短消息前转冲突。
  - 用户签约ODB-BICROAM，且用户所在的MSC类型为国际，则ODB和短消息前转冲突。
  - 用户签约ODB-INFO，且前转的前转号码为信息台号码，则ODB和短消息前转冲突。
  - 用户签约ODB-ENTE，且短消息前转的前转号码为娱乐台号码，则ODB和短消息前转冲突。
  - 用户签约ODB-BOIC，且短消息前转的前转号码不为本国号码，则ODB和短消息前转冲突。
  - 用户签约ODB-BOICEXHC，且短消息前转的前转号码不为归属国号码，则ODB和短消息前转冲突。
  - 用户签约了ODB-POS，且用户的接入模式为onlySGSN，则ODB和短消息前转冲突。
- 短消息前转业务和CB业务冲突关系
  - 短消息前转业务与CB业务中BAIC均为激活，则CB和短消息前转冲突。
  - 短消息前转业务与CB业务中BAOC均为激活，则CB和短消息前转冲突。
  - 短消息前转业务与CB业务中BORO均为激活，则CB和短消息前转冲突。
  - 短消息前转业务与CB业务中BOIC均为激活，且短消息前转的前转号码不为本国号码，则CB和短消息前转冲突。
  - 短消息前转业务与CB业务中BOICEXHC均为激活，且短消息前转的前转号码不为本国号码，则CB和短消息前转冲突。

**前转号码格式说明**

正确的前转号码格式有以下几种：

- 号码属性为国内号码格式
  - 移动号码（如：13700000001）
  - 本地固话号码（如：28421111）
  - 国内长途前缀 + 区号 + 本地固话号码（如：0 755 28421111）
  - 国内长途前缀 + 区号 + 移动号码（如：0 755 13700000001）
- 号码属性为国际号码格式
  - 国家码 + 移动号码（如：86 13700000001）
  - 国际号码前缀 + 国家码 + 移动号码（如：00 86 13700000001）
  - 国家码 + 区号 + 本地固话号码（如：86 755 28421111）
  - 国际号码前缀 + 国家码 + 区号 + 本地固话号码（如：00 86 755 28421111）
