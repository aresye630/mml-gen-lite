# 短消息

## 目录内容

- 短消息
  - SMSC黑名单
    - 删除SMSC黑名单记录(RMV SMSCBLACKLIST)
    - 增加SMSC黑名单记录(ADD SMSCBLACKLIST)
    - 查询SMSC黑名单记录(LST SMSCBLACKLIST)
  - SMSC转换
    - 增加SMSC转换配置记录(ADD SMSCCONVERT)
    - 查询SMSC转换配置记录(LST SMSCCONVERT)
    - 删除SMSC转换配置记录(RMV SMSCCONVERT)
    - 修改SMSC转换配置记录(MOD SMSCCONVERT)
  - 短消息配置
    - 设置SMS配置信息(SET SMS)
    - 查询SMS配置信息(LST SMS)
