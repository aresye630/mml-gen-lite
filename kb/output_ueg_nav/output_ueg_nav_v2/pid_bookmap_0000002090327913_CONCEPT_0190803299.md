# O-CSI模板

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于管理系统中O-CSI（Originating CAMEL Subscription Information）模板数据。用户可以通过签约O-CSI模板ID签约O-CSI业务。

O-CSI是主叫CAMEL签约信息。当用户位置更新时，O-CSI数据将被插入用户当前所在的VPLMN（VLR）；在移动用户作被叫（接收从GMSC转发的来电）的SRI流程中，O-CSI数据将被传给IPLMN（Interrogating PLMN）。

O-CSI包含用来调用CAMEL业务逻辑的触发信息。当移动用户在VMSC中做主叫时，或移动用户在VMSC或GMSC中发生前转时，O-CSI智能业务将被触发。

#### 注意事项

无。

#### 基本概念

**DP**

DP（Detection Point）即检出点，用于触发智能业务和在智能业务过程中检测出与呼叫相关的事件，例如收集信息、号码分析、应答或挂机。DP的配置是为了通知“智能业务逻辑实例”遇到了DP，从而使智能业务逻辑实例影响随后的呼叫处理。如果DP没有配置，则继续原来的业务处理，不会涉及到智能业务。

不同的CAMEL阶段支持不同的DP，对于O-CSI具体支持情况如表1所示。

| CAMEL阶段   | 支持的DP                       |
|:----------|:----------------------------|
| PHASE 1   | 收集信息检出点（DP2）                |
| PHASE 2   | 收集信息检出点（DP2）                |
| PHASE 3   | 收集信息检出点（DP2），路由选择失败检出点（DP4） |
| PHASE 4   | 收集信息检出点（DP2），路由选择失败检出点（DP4） |

**说明** 

执行**ADD OCSITPL**/**MOD OCSITPL**命令时如果选择CAMEL阶段不支持的DP会返回错误。

**DP触发准则**

- 收集信息检出点（DP2）

  该DP点有目标号码、基本业务码和呼叫类型三种触发准则。这三种DP触发准则不是必须要配置的，可以都不配置。如果某种触发准则没有配置则默认该触发准则是满足CAMEL业务触发条件的，只有三种DP触发准则都满足，该O-CSI在这个DP点才可以触发对应的CAMEL业务。

  - 目标号码：最多存储10个目标号码、3个号码长度和一个匹配类型。当匹配类型配置为“ENABLING”时，只要被叫号码匹配上10个目标号码中的任一号码，或被叫号码长度匹配上3个目标号码长度中的任一长度就认为满足目标号码触发准则。当匹配类型配置为“INHIBITING”时，只有当被叫号码匹配不上10个号码中的任一号码、并且被叫号码匹配不上3个目标号码长度中的任一长度，才认为满足目标号码触发准则。
  - 基本业务码：最多存储5组基本业务码或基本业务码组。如果呼叫的基本业务码匹配5组中的任意一组基本业务码或基本业务码组中的一个成员， 则认为该呼叫满足基本业务码触发准则。
  - 呼叫类型：有“notForwarded”和“forwarded”两个取值。如果设置为“notForwarded”，则非前转的呼叫才认为满足触发准则；如果设置为“forwarded”，则当发生呼叫前转时才认为满足触发准则。
- 路由选择失败检出点（DP4）

  该DP点只包括呼叫释放原因触发准则。该触发准则不是必须要配置的，如果未配置则默认满足触发条件。

不同的CAMEL阶段支持不同的DP触发准则，对于O-CSI具体支持情况如表2所示。

| CAMEL阶段   | 支持的触发准则                                |
|:----------|:---------------------------------------|
| Phase 1   | 不支持触发准则                                |
| Phase 2   | 目标号码触发准则、基本业务码触发准则、呼叫类型触发准则            |
| Phase 3   | 目标号码触发准则、基本业务码触发准则、呼叫类型触发准则、呼叫释放原因触发准则 |
| Phase 4   | 目标号码触发准则、基本业务码触发准则、呼叫类型触发准则、呼叫释放原因触发准则 |

**说明** 

执行**ADD OCSITPL**/**MOD OCSITPL**命令时如果选择CAMEL阶段不支持的DP触发准则会返回错误。

**O-CSI签约信息定制下发**

HLR根据以下三个方面来灵活控制CAMEL签约信息的下发。

- 漫游用户当前所在的网络是否是归属网络

  HLR根据位置更新消息中携带的VLR号码，结合系统配置的VLR类型表来区分用户是在本网还是非本网中漫游。VLR类型表通过**ADD VLRTYP**命令配置。
- 当前网络是非归属网络时是否有CAMEL漫游协议和CAMEL查询协议

  CAMEL漫游协议和CAMEL查询协议表示用户当前漫游所在的非归属网络是否支持该用户归属网络定义的CAMEL业务，并且能够进行网间结算。非归属网络与归属网络HLR是否有CAMEL漫游协议、CAMEL查询协议由运营商确定。

  - 通过**ADD CAMELROAMTPL**命令将VLR的号码前缀添加到CAMEL漫游协议模板中，就认为该VLR与HLR有漫游协议。
  - 通过**ADD CAMELINTERTPL**命令将GMSC的号码前缀添加到CAMEL查询协议模板中，就认为该GMSC与HLR有查询协议。
- 当前网络对CAMEL业务的支持情况

  用户在网络中漫游时，位置更新或被叫取路由请求消息中会携带用户当前漫游所在的VLR或GMSC所支持的CAMEL业务处理能力，HLR将此CAMEL业务处理能力和O-CSI模板中定义的CAMEL业务处理能力作对比，取两者的交集得到当前网络对CAMEL业务的支持情况。
