# 系统不支持业务的替代功能

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于当用户漫游所在的MSC/VLR/MME/S4SGSN不支持用户所签约的某种业务时，系统使用该MSC/VLR/MME/S4SGSN所支持的业务替代原来业务。

#### 注意事项

无。

#### 基本概念

**ODB业务**

ODB（Operator
Determined Barring）即运营商决定的闭锁，是指用户接入GSM/UMTS/EPS网络的业务能力是由PLMN网络运营商来决定的。ODB业务可分为以下5大类：

- 闭锁出呼叫或移动始发短消息
- 闭锁入呼叫或移动终结短消息
- 闭锁漫游
- 闭锁补充业务接入
- 闭锁分组业务

ODB业务的详细分类如表1所示。

| ODB业务大类       | ODB业务小类                            | 业务描述                                                                                |
|:--------------|:-----------------------------------|:------------------------------------------------------------------------------------|
| 闭锁出呼叫或移动始发短消息 | 闭锁所有出呼叫业务（ODB-BAOC）                | 闭锁用户所有出呼叫或移动始发短消息。                                                                  |
| 闭锁出呼叫或移动始发短消息 | 闭锁所有国际出呼叫业务（ODB-BOIC）              | 当用户在HPLMN国家漫游时，闭锁用户对国外用户的出呼叫或移动始发短消息；当用户漫游出HPLMN国家时，闭锁出呼叫或移动始发短消息。                  |
| 闭锁出呼叫或移动始发短消息 | 闭锁除HPLMN国家外的国际出呼叫业务（ODB-BOICExHC）  | 当用户在HPLMN国家漫游时，闭锁用户对国外用户的出呼叫或移动始发短消息；当用户漫游出HPLMN国家时，只能对归属国的用户出呼叫或移动始发短消息。           |
| 闭锁出呼叫或移动始发短消息 | 闭锁当漫游出HPLMN国家时所有出呼叫（ODB-BOCROAM）   | 当用户漫游出HPLMN国家时，闭锁所有出呼叫或移动始发短消息。                                                     |
| 闭锁出呼叫或移动始发短消息 | 对国内长途呼叫的限制（HPLMN自定义类型1）（ODBPB1）    | 闭锁用户对国内长途用户的呼叫或移动始发短消息。                                                             |
| 闭锁出呼叫或移动始发短消息 | 闭锁高额费率信息类出呼叫（ODB-Information）      | 用于闭锁用户对高额费率信息类业务的呼叫。                                                                |
| 闭锁出呼叫或移动始发短消息 | 闭锁高额费率娱乐类出呼叫（ODB-Entertaiment）     | 用于闭锁用户对高额费率娱乐类业务的呼叫。                                                                |
| 闭锁入呼叫或移动终结短消息 | 闭锁所有入呼叫（ODB-BAIC）                  | 闭锁用户所有入呼叫或移动终结短消息。                                                                  |
| 闭锁入呼叫或移动终结短消息 | 闭锁当漫游出HPLMN国家时所有入呼叫（ODB-BICROAM）   | 当用户漫游出HPLMN国家时，闭锁所有入呼叫或移动终结短消息。                                                     |
| 闭锁漫游          | 闭锁漫游出HPLMN（BROHPLMN）               | 当用户漫游出HPLMN时，不允许用户漫游。                                                               |
| 闭锁漫游          | 闭锁漫游出HPLMN国家（BROHPLMNC）            | 当用户漫游出HPLMN国家时，不允许用户漫游。                                                             |
| 闭锁漫游          | 闭锁漫游出HPLMN国家的GPRS业务（BROHPLMNCGPRS） | 当用户漫游出HPLMN国家时，不允许用户GPRS漫游。                                                         |
| 闭锁补充业务接入      | 闭锁补充业务(ODB-SS)                     | 用于限制用户在MS/UE中对所签约补充业务的操作权限。提供该业务的用户不能在MS/UE中进行以下补充业务的操作： 登记去登记激活去激活                 |
| 闭锁补充业务接入      | 闭锁用户登记前转业务（ODB-RCF）                | 用于限制用户在MS/UE中登记前转业务的操作权限。运营商可闭锁以下前转号码的用户登记操作： 闭锁所有前转号码登记闭锁国际前转号码登记闭锁除归属国以外的国际前转号码登记 |
| 闭锁补充业务接入      | 显式呼叫转移调用闭锁业务（ODBECT）               | 用于限制用户显式呼叫转移业务（ECT）的使用权限。                                                           |
| 闭锁分组业务        | 闭锁分组业务（ODB-POS）                    | 用于限制用户分组数据业务的使用权限。运营商可闭锁用户的以下2种分组数据业务：闭锁MS发起的PDP上下文激活闭锁网络发起的PDP上下文激活                |

**CUG业务**

CUG（Closed User Group）业务，即闭合用户群业务，是一种补充业务，用户可以连接到PLMN或其他网络来建立一个CUG群，出入该用户群的呼叫会受到限制。一个用户可以成为一个或多个CUG的成员。指定CUG的成员可以与群内的用户通信，但在通常情况下，不能与群外的用户通信。

用户群的呼叫限制分为:

- 群内呼叫限制
- 群间呼叫限制

**IST业务**

IST（Immediate Service Termination）业务，即立即业务终止业务，运营商可以通过IST业务立即终止用户在当前MSC/VLR或GMSC区域正在进行的所有操作。该业务可以终止除紧急呼叫以外的所有用户承载业务和电信业务。

**DIC业务**

DIC（Dial Identification Code）业务，即计费帐户业务，主要是为了满足移动用户对某一类对象呼叫所花费用进行查询的需要。签约了DIC业务的用户在进行呼叫时，在拨打的号码后可以携带DIC码，所拨号码为：被叫号码+#+DIC码，用于区分对不同用户的呼叫。

对于在HLR签约激活DIC业务的移动用户，MSC允许该移动用户始发呼叫时在被叫号码后加拨“#+DIC码”。用户在HLR中可以签约强制检查DIC码或非强制检查两种方式：

- DIC\_DICR：表示用户签约强制检查DIC码的方式。用户输入的被叫号码后一定要加拨“#+DIC码”，如果用户签约的DIC码长度与用户输入时的DIC码长度相等，则检查通过，MSC接通后续呼叫，并且在主叫话单中记录该DIC码；如果长度不相等，则检查失败，拒绝呼叫。
- DIC\_DICV：表示用户签约非强制检查方式。用户输入的被叫号码后可以加拨“#+DIC码”，也可以不加拨。被叫号码后包含DIC码时，如果DIC码验证通过，处理方式与上述相同，即接通呼叫，记录该DIC码；无论包不包含DIC码，如果DIC码验证不通过，仍然接通呼叫，话单中记录用户输入的DIC码或记录为空。

DIC\_DICR和DIC\_DICV的区别还表现在用户签约的长度。如果长度的取值是0或1～16，则表示DIC\_DICR；如果长度的取值是127，则表示DIC\_DICV。DIC长度可以通过**MOD DIC**的参数“DIC长度”来设置。
