# 对端设备配置

- 功能描述
- 注意事项

#### 功能描述

该组命令用于管理对端设备配置信息，提供对端设备配置参数添加、删除、修改、查询功能。

#### 注意事项

对端设备配置有两条默认记录如下，操作中不要随意修改。

```
对端设备名称    对端设备组名称   IP地址类型   IPV4地址   IPV6地址              备注 

DEFAULTIPV4APP  DEFAULTAPPGROUP  IPV4         0.0.0.0    NULL                  NULL
DEFAULTIPV6APP  DEFAULTAPPGROUP  IPV6         NULL       0:0:0:0:0:0:0:0       NULL
```

## 目录内容

- 对端设备配置
  - 查询对端设备配置(LST PAPPIP)
  - 删除对端设备配置(RMV PAPPIP)
  - 修改对端设备配置(MOD PAPPIP)
  - 增加对端设备配置(ADD PAPPIP)
