# PMS管理员IP地址管理

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

无。

#### 功能描述

管理员IP地址管理包括添加、查询和删除管理员登录策略管理服务的IP地址信息。管理员只能使用已添加的IP地址访问策略管理服务界面。

#### 注意事项

无。

## 目录内容

- PMS管理员IP地址管理
  - 添加策略管理服务管理员IP地址(ADD PMSADMINIP)
  - 解锁PMS用户WEB客户端IP(ULK PMSUSERIP)
  - 查询策略管理服务管理员IP地址(LST PMSADMINIP)
  - 删除策略管理服务管理员IP地址(RMV PMSADMINIP)
