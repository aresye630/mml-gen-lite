# 号码前缀和国家码数据管理

- 功能描述
- 基本概念

#### 功能描述

该组命令用于增加、删除、修改或查询号码前缀和国家码数据相关信息。

#### 基本概念

**本地号码格式**

- 移动号码（如：13700000001）
- 本地固话号码（如：28421111）
- 国内长途前缀 + 区号 + 本地固话号码（如：0 755 28421111）
- 国内长途前缀 + 区号 + 移动号码（如：0 755 13700000001）

**国际号码格式**

- 国家码 + 移动号码（如：86 13700000001）
- 国际号码前缀 + 国家码 + 移动号码（如：00 86 13700000001）
- 国家码 + 区号 + 本地固话号码（如：86 755 28421111）
- 国际号码前缀 + 国家码 + 区号 + 本地固话号码（如：00 86 755 28421111）

## 目录内容

- 号码前缀和国家码数据管理
  - 增加号码前缀和国家码数据(ADD NUMBERCCODE)
  - 删除号码前缀和国家码数据(RMV NUMBERCCODE)
  - 修改号码前缀和国家码数据(MOD NUMBERCCODE)
  - 查询号码前缀和国家码数据(LST NUMBERCCODE)
