# 区域漫游模板

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于管理区域漫游限制模板。

用户签约区域漫游模板中设置的区域码后，系统根据此模板设置的区域来限制用户漫游状态。通过设置该模板可减少实现区域漫游限制操作的复杂性，同时可以灵活控制移动用户允许漫游的位置范围。

#### 注意事项

无。

#### 基本概念

**漫游地区码**

漫游地区码是由运营商规划的区域代码。运营商将某地区划分为若干个区域，并设置对应的地区码，便于运营商对系统精细化管理，同时用户也可以根据自身需求，自由签约对应的目的地区域代码，方便用户在漫游地使用移动网络。
