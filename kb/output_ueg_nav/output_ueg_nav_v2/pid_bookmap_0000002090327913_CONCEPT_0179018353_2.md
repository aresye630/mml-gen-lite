# License管理

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

License：即许可证，是供应商与客户对所销、购买的产品使用范围、期限等进行授权、被授权的一种合约形式，通过License，客户同时也获得供应商所承诺的相应服务。

#### 功能描述

用于提供License管理相关的命令。License管理主要针对系统的用户容量，功能开放等方面进行控制；当整个系统需要增加用户容量或增加某项功能时，可以通过加载License文件方式来实现。鉴于安全问题，只有系统管理员有权对License文件进行管理。

#### 注意事项

如果USCDB容灾局License超限，会同时影响主用局业务。

## 目录内容

  - 设置产品名称(SET PRODUNAME)
  - 显示License统计校验任务状态(DSP LICCHECK)
  - 启动License统计校验任务(STR LICCHECK)
  - 查询TPS使用信息（DSP TPSINFO）
