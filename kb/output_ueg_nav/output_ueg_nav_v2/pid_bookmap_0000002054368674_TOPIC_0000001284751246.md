# 安全配置（裸机容器）

## 目录内容

- 安全配置（裸机容器）
  - 安全配置建议
    - 必选配置
      - 运维安全配置
        - 修改硬件对接用户密码
      - 业务安全配置
        - 激活NAS信令加密与完整性保护（适用于5G）
        - 激活用户身份保密性功能（适用于5G）
        - 激活鉴权功能（适用于5G）
        - 配置禁止UE互访功能
        - 配置APN上下行防欺诈
        - 配置禁止UE向逻辑接口发起PING报文
      - 系统安全配置
        - 数据库安全加固
          - 修改GaussDB数据库用户密码
      - 网络安全配置
        - 配置证书到期提醒时间
    - 可选配置
      - 数据安全配置
        - 配置USCDB内存库备份文件加密
        - 配置跟踪匿名化功能（通过OM Portal）（UPF/GW-U）
        - 配置CHR假名化本地策略（通过MML）（AMF/MME/SMF/GW-C）
      - 业务安全配置
        - 激活SBI接口加密特性(CERT)
        - 配置ACL防止UE或用户PDN/DN对运营商网络设备攻击
        - 激活防DDoS功能
        - 配置ACL防止UE之间的互访
        - 激活接入控制
        - 配置CP白名单功能
        - 配置互访流量的重定向功能
        - 配置IP Spoofing防攻击
        - 配置大流量防攻击
      - 网络安全配置
        - 配置GaussDB数据库TLS功能
      - 运维安全配置
        - 更新GaussDB数据库弱口令字典
        - 配置USCDB管理弱口令
      - 系统安全配置
        - 配置系统安全策略
          - 配置OM网络访问控制策略
