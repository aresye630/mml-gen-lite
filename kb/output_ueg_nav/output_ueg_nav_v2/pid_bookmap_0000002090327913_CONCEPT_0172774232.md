# Remote DPU IP管理

- 功能描述

- 配置原则

#### 功能描述

此组命令用于配置远端Location DPU/业务IP索引的IP地址，包括增加、删除、修改和查询操作。该地址用于和本端Location DPU/业务IP索引相联来实现通信。远端Location DPU/业务IP索引的IP信息是在远端网元客户端执行**ADD SRVIPADDR**命令增加后在此引用。

#### 相关概念

**远端Location**

远端Location与本端Location是相对的，远端location和远端网元一一对应。例如，对于主用局USCDB，它的远端Location指主用局FE、容灾局FE、容灾局USCDB的Location。对于容灾局USCDB，它的远端Location指容灾局FE、主用局FE、主用局USCDB的Location。

#### 注意事项

- IP地址与网关必须在同一网段，否则，会导致通信失败。
- IP地址不能与已使用的IP地址重复，否则，会导致通信失败。
- 执行**SYN RIPADDR**后，如果通过**EXP MML**导出MML命令配置数据文件，则导出的MML命令配置数据文件中没有**SYN RIPADDR**命令，由**ADD RIPADDR**命令代替。

#### 配置原则

本命令组无特殊配置原则。

## 目录内容

- Remote DPU IP管理
  - 删除远端网元IP地址(RMV RIPADDR)
  - 增加远端网元IP地址(ADD RIPADDR)
  - 查询远端网元IP地址(LST RIPADDR)
  - 加载远端IP信息(LOD RIPADDR)
  - 同步远端IP信息到本端(SYN RIPADDR)
  - 修改远端网元IP地址(MOD RIPADDR)
