# 割接策略配置

- 命令功能
- 基本概念

#### 命令功能

该组命令用于管理UDM割接现网用户的割接策略数据，包括提供、修改、撤销和查询功能。操作员通过**MOD MIGPOLICY**命令与**割接策略模板配置**这组命令配套使用为用户签约相应的割接策略信息，UDM对用户MAP消息按照系统配置转发到指定待割接设备进行处理，最终实现对现网用户按IMSI或MSISDN号段分批割接的功能。

#### 基本概念

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**IMPIFILE文件格式**

IMPIFILE文件包含不连续的IMPI号码，格式如下所示：

```
IMPI1
IMPI2
IMPI3
IMPI4
……
IMPIn
```

IMPIn为不超过127位的字符串，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**IMPUFILE文件格式**

IMPUFILE文件包含不连续的IMPI号码，格式如下所示：

```
IMPU1
IMPU2
IMPU3
IMPU4
……
IMPUn
```

IMPUn为不超过127位的字符串，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
