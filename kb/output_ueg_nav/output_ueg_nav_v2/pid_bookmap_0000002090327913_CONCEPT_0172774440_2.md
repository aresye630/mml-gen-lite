#### 功能描述

此组命令用于管理PGW自动设备检测配置，包括增加、删除和查询操作。ADD（Automatic Device Detection）业务是指当USCDB检测到用户的IMEI/IMEISV，IMSI或一些签约数据发生变化时，将相关信息发送给第三方业务平台ADD服务器。ADD服务器根据运营商设定的业务需求，将用户数据通过短消息或者USSD消息更新到用户终端。

#### 相关概念

**IMEI**

IMEI（International Mobile Equipment Identity）是用于标识每一台GSM（Global System for Mobile Communications）和UMTS（Universal Mobile Telecommunications System）手机的数字，具有唯一性。该标识通常位于手机内部的电池下方，也可以通过在手机中输入字符串（如\*#06#，不同厂商的手机输入的字符串不同，同一厂商不同手机所需输入的字符串也可能不同）来查看该手机的IMEI。IMEI由TAC（Type
Approval Code）、FAC（Final Assembly Code）、SNR（Serial Number）及SP组成。IMEISV（International Mobile station Equipment Identity and Software Version）是IMEI的软件版本，由TAC、FAC、SNR及SVN（Software Version Number）四部分组成。其中TAC用于唯一标识无线设备，FAC用于表明生产地或者最后组装地，SNR用于大批量生产的产品上的系列编号，SP为检验码（通常是“0”），SVN用于表明软件版本。

**IMSI**

IMSI（International Mobile Subscriber Identity）是为唯一标识一个移动用户的号码，通常被存放在SIM卡中，由手机发送给网络。IMSI可用于获取存储在本地位置寄存器中的移动用户的其他信息，或复制在当地拜访位置寄存器中。为了防止通过无线接口对用户进行窃听和跟踪，IMSI很少被发送，而是由一个随机生成的TMSI（Temporary
Mobile Subscriber Identity）代替发送。IMSI由MCC（Mobile Country Code），MNC（Mobile Network Code）及MSIN（Mobile Subscriber Identification Number）组成。

**USSD**

USSD（Unstructured Supplementary Service Data）是一种新型的基于GSM网络的交互式数据业务，客户使用移动设备输入一些网络预先制定的数字或者符号(如\*#)，再按发送键向系统发送一条指令，系统根据指令选择需要的服务提供给客户。
