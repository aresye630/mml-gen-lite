# 手动流控策略管理

- 功能描述
- 注意事项
- 基本概念

#### 功能描述

该组命令用于配置和管理手动流控策略信息。

当UIM网元中的话务量超过系统允许的最大容量，会对系统稳定运行产生重大影响。UIM根据手动流控策略可以对指定类型的消息进行流控，控制业务处理消息的数量，保证系统稳定运行。

#### 注意事项

无。

#### 基本概念

无。

## 目录内容

- 手动流控策略管理
  - 删除手动流控策略(RMV HDFCPOL)
  - 查询手动流控策略(LST HDFCPOL)
  - 增加手动流控策略(ADD HDFCPOL)
  - 修改手动流控策略(MOD HDFCPOL)
