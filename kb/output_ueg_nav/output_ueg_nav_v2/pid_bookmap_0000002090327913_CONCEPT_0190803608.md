# SCP地址模板

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于管理UDM中SCP（Service Control Point）地址模板数据。SCP地址模板用于设置O-CSI模板和T-CSI模板中的SCP配置信息。用户可以通过签约SCP地址模板实现当漫游到不同的网络位置时，进行OCSI/TCSI业务的SCP数据的定制下发。

#### 注意事项

无。

#### 基本概念

**O-CSI**

O-CSI是主叫CAMEL签约信息。当用户位置更新时，O-CSI数据将被插入用户当前所在的VPLMN（VLR）；在移动用户作被叫（接收从GMSC转发的来电）的SRI流程中，O-CSI数据将被传给IPLMN（Interrogating PLMN）。

O-CSI包含用来调用CAMEL业务逻辑的触发信息。当移动用户在VMSC中做主叫时，或移动用户在VMSC或GMSC中发生前转时，O-CSI智能业务将被触发。

**T-CSI**

T-CSI是被叫CAMEL签约信息，在移动用户做被叫的SRI流程，T-CSI数据由HLR传递给GMSC，T-CSI智能业务将被触发。

T-CSI的CAMEL数据包括：

- TDP（Triger DP）清单

  TDP清单指示所应触发的DP。T-CSI采用DP12、DP13和DP14。
- gsmSCF地址

  对某个特定用户，用来接入到gsmSCF的地址。该地址为E.164格式号码，用来进行路由寻址。不同的gsmSCF地址和不同的TDP相关联。
- 业务键

  由gsmSCF用来识别需要采用的业务逻辑。
- 缺省呼叫处理

  当gsmSSF与gsmSCF之间的对话出现差错时或者呼叫受限于gsmSSF里的CallGap时，缺省呼叫处理指示出对呼叫应给予释放还是继续。
- DP触发准则

  指示SSP是否应向gsmSCF请求指令。
- CAMEL能力处理

  指示gsmSCF所要求的CAMEL业务阶段。

**GSM业务交换功能（gsmSSF）**

gsmSSF是MSC/GMSC与gsmSCF进行连接的功能实体，在gsmSCF的指示下控制MSC/GMSC中的呼叫。

**GSM业务控制功能（gsmSCF）**

gsmSCF存储了具体CAMEL业务的业务逻辑实现，实现对呼叫业务的灵活控制。gsmSCF通常就是SCP网元实体。

**CallGap**

CallGap：呼叫间隙。
