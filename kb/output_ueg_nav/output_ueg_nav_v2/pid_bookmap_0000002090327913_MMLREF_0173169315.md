## 命令功能

操作员通过Web浏览器管理和维护业务发放网关PGW，无需另外安装客户端。在PGW的WebUI上通过MML命令为PGW提供近端维护方式。

PGW Web LMT具有文件管理、用户管理和业务发放功能。随着互联网技术的迅速发展，基于Web的互联网应用越来越广泛，Web应用也引起了黑客的强烈关注，Web应用安全也越来越受到重视。为了防止系统重要信息被截取或被破解，USCDB提供了相应的安全机制保证运营商客户系统以及数据安全。详细描述请参见产品文档的《安全管理描述》手册。该组命令可通过设置系统帐号和密码安全策略、手工锁定操作员以及修改超级管理员名称等方式，保证PGW Web LMT系统的安全。

## 目录内容

- 安全管理
  - 查询超级管理员信息（LST SUINFO）
  - 查询系统安全策略（LST SECPOLICY）
  - 修改超级管理员信息（MOD SUINFO）
  - 手动解锁用户（SET UNLCK）
  - 设置系统安全策略（SET SECPOLICY）
