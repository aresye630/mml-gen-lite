#### 命令功能

本组命令用于管理USCDB系统中的Cluster。在局点部署和扩容期间，提供添加、删除、查询、校验和修改Cluster信息的命令。

这些命令仅对DRU和DSU模块有效。将多个DRU或DSU作为节点添加到DRU或DSU Cluster，从而提高了USCDB系统的可靠性。Cluster管理和其他命令组之间的关系如图1所示。

#### 术语解释

**Cluster**

- Cluster是共同提供某种业务的一组节点。 通常，一个Cluster仅包含一个master节点和若干slave节点。
  - Master节点：可以提供增加、删除、修改、查询数据服务的节点。
  - Slave节点：仅可以提供查询数据服务的节点。
- Cluster分为DRU和DSU Cluster。DSU Cluster仅存储用户数据。DRU Cluster依据存储的数据分为三种类型：
  - GLOBAL\_DATA: 该类型DRU Cluster仅存储全局数据。
  - ROUTE\_DATA: 该类型DRU Cluster仅存储路由数据。
  - GLOBAL\_ROUTE\_DATA: 该类型DRU存储全局数据和路由数据。

**全局数据**

- 全局数据是与整个系统相关、不与特定用户相关的数据，包括业务模板数据、操作员数据等（用于登录操作终端的账号和密码）。
- 全局数据存储在全局DRU模块中。
- 全局数据分为BE相关和FE相关的全局数据。
  - BE相关的全局数据存储在Cluster为1的DRU中。Cluster 1是USCDB自动配置的。BE相关的数据包括PGW Web本地维护终端(LMT)操作员配置数据，PGW Web LMT权限管理数据，以及PGW批操作结果。
  - 存储FE相关全局数据的Cluster需要手工配置。FE相关全局数据包括FE提供服务过程中需要的操作员数据和操作权限数据，例如Web UI操作数据。

**路由数据**

- 路由数据指的是数据中心用户数据的分布信息。路由数据包括用户标识和DSU Cluster标识之间的映射关系。
- 路由数据存储在路由DRU模块中。
- DRU模块收到用户数据请求后，根据负载均衡策略将其分发到DSU Cluster。DSU处理用户数据并返回响应给DRU。DRU模块收到响应后完成路由数据的处理。

**用户数据**

- 用户数据包括用户标识和签约数据。
- 用户数据存储在DSU模块中。
- 用户数据依据变化的频度分为两类：
  - 动态数据：用户活动相关的数据，例如，接入位置信息。动态数据经常更新且有较短生命周期。
  - 静态数据: 与用户相关与用户活动无关的数据。静态数据包括国际移动用户识别码（IMSI），移动台ISDN号码（MSISDN），以及用户服务签约数据。静态数据几乎不更新且有较长生命周期。
