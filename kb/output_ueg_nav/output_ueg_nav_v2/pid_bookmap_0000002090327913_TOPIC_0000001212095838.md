# 硬件管理

## 目录内容

- 硬件管理
  - 硬件信息
    - 查询电子标签（DSP ELABEL）
    - 增加硬件设备信息（ADD HW）
    - 查询硬件设备信息（LST HW）
    - 删除硬件设备信息（RMV HW）
  - 密码管理
    - 修改BMC默认账户密码 (MOD BMCPWD)
  - 交换机
    - 查询以太网交换机(LST LSW)
    - 删除以太网交换机(RMV LSW)
    - 增加以太网交换机(ADD LSW)
  - 端口管理
    - 查询端口（DSP PORTINFO）
    - 复位端口（RST PORT）
    - 启用端口（ACT PORT）
    - 禁用端口（DEA PORT）
  - 服务器
    - 查询服务器 (LST SERVER)
