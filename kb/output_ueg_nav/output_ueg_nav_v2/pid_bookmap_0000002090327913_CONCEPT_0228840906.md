# 会话备份数据审计任务管理

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

无。

#### 功能描述

会话备份数据审计任务用于UPCF与USCDB间的会话数据审计和USCDB中冗余会话数据清理。

#### 注意事项

无。

## 目录内容

- 会话备份数据审计任务管理
  - 设置会话备份数据审计任务参数（SET SESSADT）
  - 启动会话备份数据审计任务（STR SESSADT）
  - 查询会话备份数据审计任务状态（DSP SESSADT）
  - 查询会话备份数据审计任务参数（LST SESSADT）
  - 停止会话备份数据审计任务（STP SESSADT）
