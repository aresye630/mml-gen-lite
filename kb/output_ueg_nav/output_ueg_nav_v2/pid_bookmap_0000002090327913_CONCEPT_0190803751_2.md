#### 命令功能

GPRS（General Packet Radio Service）是为用户提供端到端的分组方式（分组交换和分组传输）的数据业务，它能有效地利用网络资源。GPRS业务具有如下的特点：

- GPRS适用于突发性的数据业务（非周期性的），突发性是指两次连续的数据传输之间的时间间隔要大于平均传输时延。
- GPRS适用于频繁传送少量数据，适用于每分钟传送几次小于500字节的短数据业务。
- 非频繁传送大量数据，GPRS也适用每小时内传送几次几千字节的长数据业务。
- GPRS所能提供的业务本质上是一种数据承载业务，GPRS所能提供的其他业务，如：网络应用业务，只是在承载业务基础上所能开展的应用业务。

#### 注意事项

此组命令只适用于在特殊局点为用户签约GPRS业务，在普通局点为用户签约GPRS业务时，请使用GPRS/EPS业务优化管理中相关命令。

#### 基本概念

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
