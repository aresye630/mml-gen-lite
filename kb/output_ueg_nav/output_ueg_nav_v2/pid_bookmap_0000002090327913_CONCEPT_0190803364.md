# LU-CSI模板

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于管理系统中LU-CSI（Location Upgrade
Services CAMEL Subscription Information）模板数据。用户可以通过签约LU-CSI模板ID签约LU-CSI业务。

LU-CSI是一种CAMEL签约数据，用户在进行位置更新时，HLR在插入用户信息消息中下发LU-CSI数据给VLR。目前只用于LBS（Location
Based Services）业务，该业务是通过用户签约的LU-CSI数据，由MSC或HLR触发INAP（Intelligent Network
Application Part）消息到智能网络，智能网络基于INAP消息实现不同业务逻辑，譬如欢迎短消息、OTA Roaming
list更新和欢迎消息可以包含套餐资费宣传信息等。

#### 注意事项

无。

#### 基本概念

**DP**

DP（Detection Point）即检出点，用于触发智能业务和在智能业务过程中检测出与呼叫相关的事件，例如收集信息、号码分析、应答或挂机。DP的配置是为了通知“智能业务逻辑实例”遇到了DP，从而使智能业务逻辑实例影响随后的呼叫处理。如果DP没有配置，则继续原来的业务处理，不会涉及到智能业务。
