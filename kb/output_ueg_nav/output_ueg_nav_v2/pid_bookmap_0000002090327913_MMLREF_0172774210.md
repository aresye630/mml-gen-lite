# 营帐设备登录类型管理

- 命令功能
- 注意事项

## 命令功能

用于添加、删除、修改和查询营帐客户端登录类型。

营帐客户端登录PGW有“HW”和“TELNET”两种类型。当营帐客户端登录PGW时，PGW根据营帐客户端的IP与PGW端的接入端口查询营帐客户端登录类型。如果登录类型为“HW”，则不触发交互式登录流程。如果登录类型为“TELNET”，则触发交互式登录流程。如果没有配置该营帐客户端的登录类型，则使用其默认登录类型“HW”。

## 注意事项

无。
