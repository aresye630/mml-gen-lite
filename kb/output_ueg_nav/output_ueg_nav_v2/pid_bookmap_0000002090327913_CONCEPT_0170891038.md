# PCRF对端PCEF管理

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

无。

#### 功能描述

PCRF对端PCEF管理包括对端PCEF配置和维护。配置包括增加、修改或删除对端PCEF设备ID、设备名称、域名、主机名和IP地址。维护包括查询对端PCEF配置信息。

#### 注意事项

无。

## 目录内容

- PCRF对端PCEF管理
  - 查询PCRF对端PCEF实体配置信息(LST PPCEF)
  - 删除PCRF对端PCEF实体(RMV PPCEF)
  - 修改PCRF对端PCEF实体信息(MOD PPCEF)
  - 增加PCRF对端PCEF实体(ADD PPCEF)
