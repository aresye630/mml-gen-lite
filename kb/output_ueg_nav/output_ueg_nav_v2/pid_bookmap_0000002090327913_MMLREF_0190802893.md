# 业务区域限制模板

- 命令功能
- 注意事项

## 命令功能

业务区域限制实现的基本机制是定义一些业务区域限制模板，模板中设置一些需要受限的业务。如果某个用户签约了一个业务区域限制模板，可以在特殊情况下对用户分别停短信、语音、GPRS等业务，短信可以按收、发分别限制。

业务区域限制模板由操作员预先定义，并且业务区域限制模板的ID是唯一的。

## 注意事项

无。

## 目录内容

- 业务区域限制模板
  - 删除业务区域限制模板(RMV OKSCTPL)
  - 查询业务区域限制模板(LST OKSCTPL)
  - 修改业务区域限制模板(MOD OKSCTPL)
  - 增加业务区域限制模板(ADD OKSCTPL)
