# 容灾/虚拟HLR管理

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于在开局阶段管理虚拟HLR的功能配置信息，根据不同地区PGW的支持能力可将各虚拟HLR配置为具有不同功能（虚拟HLR功能/容灾功能）的HLR，使操作人员可以更好的实现对业务的管理。

#### 注意事项

系统HLR用于管理一个或多个虚拟HLR，唯一标识一个局点。只有系统HLR被添加之后才能添加虚拟HLR及管理虚拟HLR信息，因此在管理虚拟HLR的功能配置信息前请确保对应的系统HLR及虚拟HLR已被添加。

#### 基本概念

无。
