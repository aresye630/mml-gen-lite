# 承载网质量管理

#### 功能描述

该组命令用于查询各FE和BE之间（含容灾系统）的承载网质量指标（包括时延和丢包情况），从而评估FE网元和BE网元之间的承载网质量状况。

承载网质量主要通过IP QoS衡量。IP QoS是指IP网络的一种能力，即在跨越多种底层网络技术（FR、ATM、Ethernet、SDH等）的IP网络上，为特定的业务提供其所需要的服务。通过IP承载网来传输数据，IP承载网的质量直接影响到通信业务的质量。要保证业务正常运行，IP承载网的质量要达到一定标准。

IP承载网质量采用如下表1中4个参数来度量，为关键业务提供服务质量保证，使其获得可预期的服务水平。

| 指标   | 对承载网的要求                                                                                                                                                                    |
|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 带宽   | 带宽是指网络的两个节点之间特定应用业务流的平均速率。保证QoS最好的办法是增加网络的带宽。现网中规划QoS的主要目的是用来应对带宽拥塞的情况。                                                                                                    |
| 时延   | 时延是指一个报文或分组从一个网络的一端传送到另一端所需要的时间，传输的距离、承载设备转发能力都会影响端到端时延。对一般应用来说，时延越小越好。该指标常和“抖动”结合起来使用。                                                                                    |
| 抖动   | 抖动是指周期信号的不规则变化，通常是指这个周期信号和参考时钟之间的差异。抖动可以表现为周期信号的脉冲之间的频率，振幅，相位变化。所有传输系统都有抖动，只要抖动在规定容差之内就不会影响服务质量。利用缓存可以克服过量的抖动，但这将增加时延。某些业务类型，特别是话音和视像等实时业务是对抖动容忍性较低，分组到达时间的差异将在话音或视像中造成断续。 |
| 丢包率  | 少量丢包对业务没有明显影响。大量的和持续的丢包会影响传输效率，所以，QoS更关注的是丢包的统计数据--丢包率。丢包率是指在网络传输过程中丢失报文占传输报文的百分比。                                                                                         |

表2是对于几种常见业务QoS指标的经验值。

| 常见业务   | 业务类别   | 时延      | 抖动     | 丢包    |
|:-------|:-------|:--------|:-------|:------|
| 语音     | 媒体     | ≤50ms   | ≤10ms  | ≤1%   |
| 语音     | 信令     | ≤100ms  | ≤10ms  | ≤0.1% |
| IPTV   | 组播     | ≤1s     | ≤200ms | ≤0.1% |
| IPTV   | 点播     | ≤10s    | ≤200ms | ≤0.1% |
| FTP下载  | nan    | nan     | nan    | nan   |
| Http下载 | nan    | nan     | nan    | nan   |
| Http浏览 | ≤10s   | nan     | nan    | nan   |
| 游戏     | UDP    | ≤1000ms | ≤50ms  | ≤5%   |
| 游戏     | TCP    | ≤500ms  | ≤50ms  | ≤5%   |
