# OCS映射管理

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

无。

#### 功能描述

OCS映射管理用于配置用户扩展属性或消息属性OCS映射，包括增加、修改、删除和查询OCS映射。

此组命令可以管理用户扩展属性或消息属性与OCS的映射关系，从而实现用户上线时根据用户扩展属性或消息属性（APN/IMSI/MSISDN等）选择OCS的目的。

- 用户上线：PCRF发送Sy消息，根据用户扩展属性或消息属性、OCS优先级、OCS链路故障情况等选择OCS；在与此OCS连接的所有链路间进行轮询处理，选择链路将Sy消息发给OCS。
- 用户在线：若修改了用户扩展属性与OCS映射关系，PCRF将根据最新的属性找到相应的OCS域名，先发送STR消息给原OCS释放Sy会话，再发送SLR-Initial消息给新的OCS新建Sy会话。修改消息属性不影响当前会话。

此组命令可以通在OCS混合组网场景（例如，PCRF与多个OCS之间对接，一部分OCS对接采用直连方式，另一部分OCS对接采用准直连方式）下，进行OCS映射管理。

- 直连方式：PCRF根据用户扩展属性或消息属性映射到直连OCS，发送Sy消息到对应的OCS。
- 准直连方式：PCRF根据用户扩展属性映射到DRA，发送Sy消息到DRA。
