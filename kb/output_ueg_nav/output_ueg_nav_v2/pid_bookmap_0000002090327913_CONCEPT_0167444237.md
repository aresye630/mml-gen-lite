# HLB设备地址管理

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

HLB（HTTP Load Balance）是支持HTTP协议接入管理的微服务，主要用于5G网络SA架构中N7/N15接口的业务消息处理，支持HTTP2.0协议。

#### 功能描述

HLB设备地址管理用于配置和维护HLB对外的业务IP地址。

#### 注意事项

无。

## 目录内容

- HLB设备地址管理
  - 添加HLB设备地址(ADD HLBDEVADDR)
  - 修改HLB设备地址(MOD HLBDEVADDR)
  - 删除HLB设备地址(RMV HLBDEVADDR)
  - 查询HLB设备地址(LST HLBDEVADDR)
