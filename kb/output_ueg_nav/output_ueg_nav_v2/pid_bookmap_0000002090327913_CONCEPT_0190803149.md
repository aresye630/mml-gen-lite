#### 命令功能

OFA（Origin for Forwarded-to number Analysis）即前转号码分析。OFA模板由操作员预先定义，在OFA模板中设置哪些号码前缀允许被前转到，哪些不允许。

如果用户为某项前转业务签约了OFA模板，登记前转号码时，系统将该号码与签约OFA模板中的号码前缀进行最大匹配，根据匹配到的前转规则确定该前转号码FTN（Forwarded-to Number）是否允许被登记。同时OFA模板还支持缺省前转规则的设置，该规则标识没有匹配到记录的前转号码是否允许被登记。

OFA的功能与全局表中的“禁止前转号码表”的功能类似，但是该表是在全局生效的，对所有用户都是一致的。而OFA模板有多个，运营商可以根据当地的实际情况定制禁止的前转号码前缀，每个用户可以根据自身需要签约OFA模板，所以OFA更灵活。UDM中每个前转业务（CFU、CFB、CFNRy、CFNRc）都可以单独签约一个OFA模板，模板ID在用户签约前转业务时进行指定。

#### 基本概念

**前转号码格式**

为手机登记前转号码时，正确的前转号码格式有以下几种：

- 国内号码格式

  - 移动号码（如：13700000001）
  - 本地固话号码（如：28421111）
  - 国内长途前缀 + 区号 + 本地固话号码（如：0 755 28421111）
  - 国内长途前缀 + 区号 + 移动号码（如：0 755 13700000001）
- 国际号码格式

  - 国家码 + 移动号码（如：86 13700000001）
  - 国际号码前缀 + 国家码 + 移动号码（如：00 86 13700000001）
  - 国家码 + 区号 + 本地固话号码（如：86 755 28421111）
  - 国际号码前缀 + 国家码 + 区号 + 本地固话号码（如：00 86 755 28421111）
