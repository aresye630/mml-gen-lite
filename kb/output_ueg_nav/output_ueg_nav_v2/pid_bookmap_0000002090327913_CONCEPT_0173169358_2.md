# 操作员虚拟运营商管理

- 功能描述
- 相关概念
- 注意事项
- 配置原则

#### 功能描述

此组命令用于对操作员虚拟运营商进行管理，包括对操作员虚拟运营商的添加、删除、查询操作。操作员虚拟运营商是指针对每一个操作员设置允许该操作员操作的虚拟运营商的范围。系统通过对每一个虚拟运营商设置不同的号段完成对操作员允许操作号段的统一管理。

#### 相关概念

**简单模式**

简单模式是PGW的一种应用模式，指整个系统只允许存在一个“系统序列号”，处于简单模式下的系统不支持业务层容灾功能。通过将软参“APPLICATIONTYPE（应用模式）”设为“0”将PGW的应用模式设为简单模式。

**完整模式**

完整模式是PGW的另一种应用模式，指整个系统允许存在多个“系统序列号”，处于完整模式下的系统支持业务层容灾功能。通过将软参“APPLICATIONTYPE（应用模式）”设为“1”将PGW的应用模式设为完整模式。

#### 注意事项

无。

#### 配置原则

本命令组无特殊配置原则。
