# NTS设备地址管理

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

无。

#### 功能描述

NTS设备地址管理用于配置和维护NTS对外提供的业务IP地址。

#### 注意事项

修改IP地址实时生效说明：

- 当未配置IP地址时，NTS能够启动，但不能提供服务。此时配置IP地址后，NTS不用重启，使用该IP地址提供服务。
- 当已经配置IP地址时，NTS使用该IP提供服务。此时删除该IP地址，NTS自动重启，且重启后不再提供服务。
- 当已经配置IP地址时，NTS使用该IP提供服务。此时修改该IP地址（支持IPV4地址和IPV6地址互相修改），NTS自动重启。重启后，使用新的IP地址提供服务。

## 目录内容

- NTS设备地址管理
  - 添加NTS设备地址(ADD NTSDEVADDR)
  - 修改NTS设备地址(MOD NTSDEVADDR)
  - 查询NTS设备地址(LST NTSDEVADDR)
  - 删除NTS设备地址(RMV NTSDEVADDR)
