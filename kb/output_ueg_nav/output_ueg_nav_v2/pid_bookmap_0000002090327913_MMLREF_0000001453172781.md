# DUS管理

## 目录内容

- DUS管理
  - 数据校验管理
    - 停止迁移残留分片清理任务(STP CLRRSDSHARD)
    - 启动迁移残留分片清理任务(STR CLRRSDSHARD)
    - 显示迁移残留分片清理状态(DSP CLRRSDSHARD)
  - 实例管理
    - 显示DUS服务分片信息（DSP DUSSHARD）
    - 显示DUS ID（DSP DUSID）
    - 显示DUS实例状态（DSP DUSSTAT）
  - 内存数据库管理
    - 操作内存数据库(EXC KVOML)
    - 清除集群数据（CLR CCDBCLUSTER）
