# PS的APN和EPS数据的对应关系配置

- 功能描述
- 基本概念

#### 功能描述

该组命令用于在UDM中设置PS的APN和EPS数据的对应关系，包含APN和APN模板ID、是否是默认APN、EPS QoS模板ID、PDP/PDN类型、是否允许用户从VPLMN访问PDP/PDN网络、计费特性和标准计费特性。

在LTE自动开户时，UDM从用户的PS数据中获取到APN信息，再根据该组命令已配置的数据去获取对应的EPS数据。

#### 基本概念

无。

  - 删除PS的APN和EPS数据对应关系(RMV PSAPNEPS)
  - 查询PS的APN和EPS数据对应关系(LST PSAPNEPS)
  - 增加PS的APN和EPS数据对应关系(ADD PSAPNEPS)
