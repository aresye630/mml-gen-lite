# 配置VNF侧IP路由数据

- 操作场景

## 操作场景

为实现VNF与运营商网络互通，需要在VNF上进行相关接口的路由配置，打通VNF与下一跳设备的通信路径。VNF上IP路由数据配置有两种方式：

- 自动部署（推荐）
- 手动部署

相比传统手动部署方式，自动部署只需用户预先指定业务规划参数（IP地址段分配、目的地址、下一跳网关等），即可在系统新增RU时自动生成接口IP路由配置，无需再依次为每个接口手动配置。同时系统扩容时，可以实现资源按模板规划直接分配使用，无需手动增加配置。总之，自动部署方式能大大简化部署操作，节省运维成本，因此推荐采用自动部署方式。
