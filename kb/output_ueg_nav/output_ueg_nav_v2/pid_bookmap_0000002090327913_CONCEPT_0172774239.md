# 隔离状态管理

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

此组命令用于配置DRU/DSU进程的隔离状态，操作员可以通过此组命令修改、查询DRU/DSU进程的隔离状态。

- 当一个DRU/DSU进程被隔离后，新业务处理请求将不会分发到该DRU/DSU进程上来，而会分发到其他没被隔离的DRU/DSU进程上。
- 当隔离一个DRU/DSU进程后，相当于系统中减少一个DRU/DSU进程，因此在隔离前需要确保剩下的DRU/DSU进程能够满足系统的用户数规格，否则将导致部分业务请求处理失败。
- 正常情况下，维护人员不能修改DRU/DSU进程的隔离状态。如果维护人员不合理地修改了DRU/DSU进程的隔离状态，会影响CloudDB正常运行情况。
- 如果维护人员误操作，修改了DRU/DSU进程的隔离状态，请立即恢复正确的配置数据，或在华为公司技术服务人员的指导下恢复正确的配置数据。

#### 注意事项

无。

#### 基本概念

**隔离**

在局点缩容中，CloudDB需要隔离掉某个DRU/DSU进程的业务，使得以前的DRU/DSU进程不再进行业务处理，从而达到缩容的目的。若是扩容，则需要通过本命令将处于隔离状态的DRU/DSU进程设置为非隔离状态，这样系统对业务的处理能力就会增强。
