# 激活Untrusted Non-3GPP网络用户接入功能

- 操作场景
- 操作流程

## 操作场景

UEG作为PGW-U部署Untrusted Non-3GPP接入EPC网络，Untrusted Non-3GPP用户可以通过PGW-U接入运营商网络，使用基本的数据业务。

**说明** 

适用于PGW-U。

## 操作流程

部署Untrusted Non-3GPP接入EPC网络的配置流程如图1所示。本场景仅介绍UEG作为P-GW部署Untrusted Non-3GPP接入EPC网络的最小配置，在最小配置完成后，常用的可选功能/特性配置可按如图1所示执行。

**图1** Untrusted Non-3GPP接入EPC网络配置流程

部署Untrusted Non-3GPP接入EPC网络时，需要操作员在UEG上进行数据配置实现以下要求：

- 用户接入运营商网络，使用基本的数据业务。
- UEG到OM网络使用配置到OM网络的数据。
- UEG到Untrusted Non-3GPP GW，参考配置PGW-U到Untrusted Non-3GPP GW的数据（VPN+OSPF动态路由组网）（虚机容器）和配置PGW-U到Untrusted Non-3GPP GW的数据（VPN缺省路由组网）进行配置。
- UEG上到PDN使用配置PGW-U到PDN的数据。
- 用户地址分配方式为本地地址池分配IPv4地址，参考激活用户面地址分配。
- UEG使用整机缺省的DNS对用户访问地址进行域名解析。
