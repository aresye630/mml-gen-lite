# 短消息Short-Code类型

- 命令功能
- 基本概念

#### 命令功能

该组命令用于在HLR中添加短消息Short-Code前缀对应的短消息类型，用于短消息取路由流程中分析判断该短消息的类型。

#### 基本概念

Short-Code：短消息类型码，是在短消息取路由请求消息中携带，用来标识该短消息的类型。

## 目录内容

- 短消息Short-Code类型
  - 增加短消息Short-Code类型(ADD SCTYPE)
  - 修改短消息Short-Code类型(MOD SCTYPE)
  - 查询短消息Short-Code类型(LST SCTYPE)
  - 删除短消息Short-Code类型(RMV SCTYPE)
