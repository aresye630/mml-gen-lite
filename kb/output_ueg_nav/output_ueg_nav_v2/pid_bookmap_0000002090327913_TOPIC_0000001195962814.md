# CSP机机接口命令（虚机容器）

## 目录内容

- CSP机机接口命令（虚机容器）
  - 系统调测
    - 软件管理
      - 工作区管理
        - 结束升级观察期(FIN UPGWATCH)
        - 查询升级观察期(LST UPGWATCH)
      - 平面管理
        - 同步更新网元版本(SYN MEVER)
      - 版本补丁管理
        - 校验静默补丁(CHK SPATCH)
  - 软件管理
    - 监控任务管理
      - 设置告警统计功能开关 (SET ALMMSGSTAT)
      - 查询告警统计结果 (LST ALMMSGSTAT)
      - 查询告警日志(LST ALMLOG)
      - 手工清除告警(RMV ALMFLT)
    - 模块管理
      - 模块
        - 查询进程模式(LST PROMODE)
        - 修改进程模式(MOD PROMODE)
    - 网元管理
      - 查询网元信息(GET ME)
      - 改变网元(USE ME)
      - 查询网元配置信息(DSP ME)
      - 锁定网元(LCK ME)
      - 修改网元信息(MOD ME)
      - 增加网元(ADD ME)
      - 升级网元实例(UPG ME)
      - 删除网元(RMV ME)
      - 解锁网元(ULK ME)
    - 平面管理
      - 平面激活(ACT PLANE)
      - 划分平面(DEF PLANECFG)
      - 平面定义(DEF PLANE)
      - 升级预处理(STR CBK)
      - 查询平面定义(LST PLANE)
      - 平面切换(SWP PLANE)
    - 备份管理
      - 快速导出网元数据(FEXP MES)
      - 显示EXP MES的执行状态(DSP MESSTAT)
      - 备份系统(BKP SYS)
    - 命令统计
      - 设置维护命令统计开关(SET MMSWITCH)
      - 查询命令执行时间(LST CMDEXECTIME)
      - 查询对象联想参数(LST MOCASS)
      - 设置配置命令统计开关(SET CMDSTAT)
      - 查询对象配置标签(LST MOCLABEL)
      - 设置时区和夏令时(SET LITETZ)
    - 备份状态管理
      - 备份进度检查(CHK BKSTATS)
    - 加载进度管理
      - 查询在线加载进度(DSP ONLINELOAD)
      - 查询初始加载进度(DSP INITIALLOAD)
    - 版本信息管理
      - 查询补丁回退版本(LST PTHRBKVER)
      - 查询目标版本(LST DSTVER)
      - 查询补丁网元(LST PTHME)
      - 删除补丁记录(RMV PTHHSYRCD)
      - 数据同步(LOD VER)
    - 性能测量管理
      - 导出性能测量结果(DMP TRFRST)
      - 设置网元的性能管理数据(SET PMMEDATA)
    - 升级状态管理
      - 开始进入升级观察期(STR UPGWATCH)
      - 磁盘空间检查(CHK UPGDISK)
    - 批命令管理
      - 删除MML批处理任务(RMV MMLTSK)
      - 增加MML批处理任务(ADD MMLTSK)
    - 节点管理
      - 查询CGPLite容器信息(LST OMU)
    - 包管理
      - 向指定的ftp下载指定的介质包到omu(PUS PKG)
    - 平台管理
      - 平台网元升级(UPG PLATFORM)
  - 配置管理
    - 配置同步
      - 网管配置同步（GET LITECFGFILE）
      - 对象通知标签查询（LST LABEL）
    - 跨网元命令管理
      - 查询跨网元命令的操作记录(LST MCDLOG)
    - 数据格式化
      - 刷新数据字典(FRSH FMT)
    - 配置导出管理
      - 导出MML文件(EXP LITEMML)
  - 系统日志管理
    - 查询日志统计结果(LST LOGMSGSTAT)
    - 设置日志统计功能开关(SET LOGMSGSTAT)
  - CSP双机
    - CSP管理
      - 设置CGPLite倒换状态(SET SWAPSTATE)
  - 资源管理
    - 脱机模式管理
      - 结束脱机模式(FIN LOFMODE)
      - 数据加载开关（SET DATASWITCH）
    - Pod管理
      - 修改Pod信息(MOD PODINFO)
      - 增加Pod信息(ADD PODINFO)
      - 删除Pod信息(RMV PODINFO)
  - 安全管理
    - 安全传输管理
      - 查询TLS/SSL支持能力(LST SSLCPB)
      - 一般文件下载 (DLD GENFILE)
