# PEER与PREALMRT关联关系管理

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

**PEER**

该命令组的PEER是指DRA。

**PREALMRT**

该命令组的PREALMRT是指Gx、Rx、Sy和Sd的域路由。

#### 功能描述

PEER与PREALMRT关联关系管理包括PEER与PREALMRT关联关系的配置和维护。

#### 注意事项

无。

## 目录内容

- PEER与PREALMRT关联关系管理
  - 增加PEER与PREALMRT关联关系（ADD PREALMPEERREL）
  - 删除PEER与PREALMRT关联关系（RMV PREALMPEERREL）
  - 查询PEER与PREALMRT关联关系（LST PREALMPEERREL）
