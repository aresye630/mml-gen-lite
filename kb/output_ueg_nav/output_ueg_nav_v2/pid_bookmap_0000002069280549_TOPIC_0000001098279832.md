# 动态分流（MPF/UPF）

**图1** 动态分流规则总体流程

端到端来看，动态分流规则即动态Traffic Rule和动态DNS Rule，从下发到生效可以划分为三个阶段：

- **动态分流规则下发**：管理面MEPM动态下发动态Traffic Rule和动态DNS Rule到MPF，MPF支持修改动态Traffic Rule和动态DNS Rule的状态，并将ACTIVE状态的动态Traffic Rule和动态DNS Rule推送到UPF。
- **动态分流规则安装**：当用户发起PDU会话创建，UPF收到SMF下发的PDR后，UPF本地通过配置决定动态Traffic Rule和动态DNS Rule的安装生效是否根据PDR携带的Application ID生效。默认APP所有动态规则需要根据PDR携带的Application ID生效。
- **动态分流规则匹配**：当用户发起业务访问，业务报文到达UL CL UPF后，匹配动态Traffic Rule和动态DNS Rule，命中后可进行本地分流，将业务流通过辅锚点PSA2 UPF送到APP。
