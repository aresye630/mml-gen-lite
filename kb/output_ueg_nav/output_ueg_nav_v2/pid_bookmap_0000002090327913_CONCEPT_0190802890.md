# 缺省前转通知主叫用户属性

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于设置缺省前转业务中缺省前转通知主叫用户的属性。通过设置缺省前转通知主叫用户的属性，当某前转号码是未定义通知主叫用户属性的前转号码且有呼叫前转到该号码时，运营商可以决定是否通知主叫用户。

#### 注意事项

无。

#### 基本概念

**缺省前转业务**

缺省前转业务（Call forwarding default）是指当基于某一种基本业务组的CFU没有激活且某一种条件前转没有激活时，呼叫将前转到CFD登记的前转号码，从而保证对用户的每一次呼叫都能接通。

缺省前转业务是对三个条件前转业务（遇忙呼叫前转业务、无应答呼叫前转业务、不可及前转业务）的补充，具体的应用如语音信箱。
