# 归属网络运营商管理

## 目录内容

- 归属网络运营商管理
  - MNO管理
    - MNO配置表
      - 修改MNO配置信息(MOD MNO)
      - 删除MNO配置信息(RMV MNO)

      - 修改本地PLMN(MOD HPLMN)

      - 增加MVNO资源配置信息(ADD MVNORES)
      - 修改MVNO资源配置信息(MOD MVNORES)
      - 查询MVNO资源配置信息(LST MVNORES)

      - 查询MVNO配置信息(LST MVNO)
      - 增加MVNO配置信息(ADD MVNO)
      - 修改MVNO配置信息(MOD MVNO)

    - 删除不发送运营商名称的HSS(RMV NWNAMEBYHSS)

    - 修改归属网络信息(MOD HNOINFO)
