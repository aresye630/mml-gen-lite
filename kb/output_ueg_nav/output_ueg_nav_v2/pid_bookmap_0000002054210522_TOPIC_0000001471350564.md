# NB-IoT功能配置

仅当存在NB-IoT终端接入时，需要执行本配置，否则无需执行本任务。

NB-IoT（Narrowband Internet of Things）即窄带物联网，是3GPP定义的一种新型窄带无线技术，是在LTE基础上的一种特殊网络，具备广覆盖、多连接、低功耗、低成本等特点。

## 目录内容

- NB-IoT功能配置
  - GW-U配置
    - 激活NB-IoT终端标准接入
  - MME&GW-C配置
    - 激活NB-IoT终端标准接入（适用于S/PGW-C）
    - 激活支持M2M长周期性定时器
    - 激活NB-IoT终端标准接入（适用于MME）
