# Pod管理命令

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

无。

#### 功能描述

系统运行中，Pod管理提供内部命令接口，以便于查询Pod运行状态，解决Pod错误，恢复正常的工作和完善系统。

#### 注意事项

无。

## 目录内容

- Pod管理命令
  - Pod管理
    - 修改Pod信息(MOD PODINFO)
    - 增加Pod信息(ADD PODINFO)
    - 删除Pod信息(RMV PODINFO)
  - POD模块配置
    - 刷新POD模块配置（FLU PODMDU）
    - 增加POD模块配置(ADD PODMDU)
    - 修改POD模块配置(MOD PODMDU)
    - 删除POD模块配置(RMV PODMDU)
