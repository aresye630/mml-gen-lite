#### 命令功能

该组命令用于用户数据配置及维护，在特殊场景下使用，具体请参见各个命令的命令功能。

#### 注意事项

无。

#### 基本概念

**索引化压缩存储**

原有的GPRS动态数据存储是新增一条动态数据就往表中插入一条数据，通常一个局点中的用户使用的APN分别是固定的几个APN，QoS/VPLMN/CHARGE等参数也是相同的，PDP地址通常是动态类型的，即PDP地址标识为动态通常情况下是没有意义的，但是又会占用一定的固定内存，因此采用新增用户表的方式，里面只存储新增动态数据模板的ID，通过此ID可以反查到原业务表中的数据，这样既不占用固定内存，又可以查到相应的信息，这种存储方式就叫做GPRS动态数据索引化压缩存储。

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过**LST SYSHLRSN**命令进行查询。

## 目录内容

- 用户数据维护
  - 清除VOLTE用户IMS域动态信息(CLR VOLTEIMSSTATE)
  - 查询用户静态数据(LST STATICSUB)
  - 清除垃圾数据(CLR SUBDATA)
  - 更新携入用户的HLRSN(UPG NPHLRSN)
  - 修改APN数据存储信息(MOD APNSTORAGE)
  - 短信中心号码扩展(MOD SCISDN)
  - 数据迁移和整改 (SET TRANSDATA)
  - 清除APN动态数据(CLR APNDYNDATA)
  - 查询APN数据存储信息(LST APNSTORAGE)
  - 清除CCBS动态数据(CLR CCBSDATA)
  - 查询动态用户数(LST DYNSUBDATA)
  - 用户FTN扩展(MOD FTN)
  - 清除GPRS数据(CLR GPRSDATA)
