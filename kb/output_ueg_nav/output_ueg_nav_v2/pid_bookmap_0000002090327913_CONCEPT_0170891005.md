# PCRF的Diameter对端管理

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

无。

#### 功能描述

PCRF的Diameter对端管理包括Diameter对端的配置和维护。配置包括增加、修改或删除Diameter对端标识、名称、域名和主机名。维护包括查询Diameter对端的配置信息。

#### 注意事项

无。

## 目录内容

- PCRF的Diameter对端管理
  - 修改PCRF的Diameter对端(MOD PEER)
  - 查询PCRF的Diameter对端(LST PEER)
  - 增加PCRF的Diameter对端(ADD PEER)
  - 删除PCRF的Diameter对端(RMV PEER)
