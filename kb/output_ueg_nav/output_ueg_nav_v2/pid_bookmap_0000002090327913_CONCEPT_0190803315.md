# 无线频率选择优先级管理

- 命令功能
- 基本概念

#### 命令功能

无线频率选择优先级管理提供无线频率选择优先级的修改和查询功能。

#### 基本概念

**无线频率选择优先级**

无线频率选择优先级指的是无线接入网分配和维护无线信道时所采用的无线资源管理策略。

如在附着流程中，HSS通过S6a接口下发签约的无线频率选择优先级给MME，为了实现E-UTRAN网络中的无线资源管理，MME通过S1接口下发无线频率选择优先级给eNodeB，eNodeB将无线频率选择优先级映射到本地配置数据来执行指定的无线资源管理策略。

在插入用户数据流程中，为实现GERAN/UTRAN网络中的无线资源管理，当SGSN支持无线频率选择优先级的下发时（通过**ADD NCCTPL**命令参数“是否支持下发无线频率选择优先级”设置），HSS通过Gr接口下发签约的无线频率选择优先级给SGSN。

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
