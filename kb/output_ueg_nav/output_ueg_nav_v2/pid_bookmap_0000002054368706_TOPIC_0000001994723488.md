# 裸机容器模式UEG安全加固

## 目录内容

- 裸机容器模式UEG安全加固
  - 安全配置建议
    - 可选配置
      - 业务安全配置
        - 配置ACL防止UE或用户PDN/DN对运营商网络设备攻击
        - 激活防DDoS功能
        - 配置ACL防止UE之间的互访
        - 激活接入控制
        - 配置CP白名单功能
        - 配置互访流量的重定向功能
        - 配置IP Spoofing防攻击
        - 配置大流量防攻击
      - 网络安全配置
        - 配置IPSec功能
          - 激活IPsec功能（指定本端接口建立IPsec隧道）
          - 上传IPsec证书
          - 激活IPsec功能（IPv4 IPsec主备隧道）
          - 激活IPsec功能（多Sequence的IPsec策略）
          - 激活IPsec功能（普通IPv6 IPsec隧道）
          - 激活IPsec功能（GRE over IPsec）
      - 数据安全配置
        - 配置跟踪匿名化功能（通过OM Portal）（UPF/GW-U）
      - 系统安全配置
        - 配置系统安全策略
          - 配置OM网络访问控制策略
    - 必选配置
      - 业务安全配置
        - 配置禁止UE互访功能
        - 配置APN上下行防欺诈
        - 配置禁止UE向逻辑接口发起PING报文
      - 运维安全配置
        - 修改硬件对接用户密码
      - 系统安全配置
        - 数据库安全加固
          - 修改GaussDB数据库用户密码
      - 网络安全配置
        - 配置证书到期提醒时间
