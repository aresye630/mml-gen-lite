# TCP链路管理

- 命令功能
- 注意事项

## 命令功能

用于添加、删除和查询TCP链路。

TCP链路为订阅通知提供了TCP消息通道，通过本组命令可以配置TCP链路的服务器端IP，服务器端口，客户端IP和服务器URL等基本信息。一条或两条TCP链路组成一个TCP链路集，使用命令**ADD SUBSCRIBER**添加订阅者时，需要指定该订阅者关联的链路集。当需要给订阅者发送订阅通知消息时，使用该订阅者关联的链路集的一条链路作为消息通道。
