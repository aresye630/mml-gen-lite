# QoS模板替代配置

- 功能描述
- 基本概念

#### 功能描述

该组命令用于在配置数据库中，对QoS模板替代配置信息进行设置和管理。

当用户在PS域进行位置更新时，或者在网签约或修改PS域的QoS模板时（通过**ADD SUB**、**MOD OPTGPRS**或**MOD PSSER**等命令），UDM都会下发ISD消息给用户漫游所在的SGSN，在ISD消息中携带用户签约的QoS模板对应的QoS数据。

由于某些SGSN功能所限，无法支持用户签约的QoS模板对应的QoS数据。因此UDM支持在特定的SGSN下，使用固定的QoS模板替代用户签约的QoS模板进行下发，从而提高UDM与SGSN在网络中的兼容性。

通过该组命令可以为数据库中指定的QoS模板设置替代关系。当UDM检测到用户签约的QoS模板设置了替代关系，并且用户漫游在指定的SGSN下时，如果需要下发QoS数据，UDM会使用设置的QoS替代模板代替用户签约的QoS模板进行下发。

#### 基本概念

**QoS**

QoS（Quality of Service）指对IP网络投递分组服务能力的评估。通常以对延迟、延迟抖动、丢包率等服务需求提供支持的能力作为核心评估对象。当网络过载或拥塞时，QoS能保证重要业务量不受延迟或丢弃，同时保证网络的高效运行，从而提高服务质量。

**GPRS**

GPRS（General Packet Radio Service）业务是一种为用户提供端到端的移动分组数据业务，通过在GSM（Global System for Mobile Communications）网络中引入分组交换的功能实体，完成用分组方式进行的数据传输业务。GPRS在现有GSM移动通信网络基础上建立，能有效地利用网络资源，降低网络成本，同时具有实时在线、按量计费、快捷登录、高速传输、自如切换的优点。
