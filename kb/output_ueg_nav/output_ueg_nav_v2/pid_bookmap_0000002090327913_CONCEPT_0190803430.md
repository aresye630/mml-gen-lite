# 全局软参管理

- 功能描述
- 基本概念

#### 功能描述

该组命令用于管理全局软参，包括设置、查询全局软参配置。

#### 基本概念

**FNR业务**

FNR（Flexible Number Routing），即灵活号码路由功能，可以实现在SAE-HSS与HLR分设场景下用户的信令转发，用以解决2G/3G用户需要升级LTE（Long Term Evolution）业务时，因SAE-HSS与HLR分设而引起的鉴权数据重同步和用户单域注册问题，满足运营商在不升级HLR的情况下不换卡、不换号为拥有USIM卡的2G/3G客户开通LTE业务。

**NPHLR**

NPHLR用来管理和存储携入用户数据、它网互携用户以及它网非携转用户数据，在呼叫过程中指明这些用户的归属运营商，同时能够帮助运营商有效的管理本网数据和其他数据。

**NPMSC**

NPMSC用来管理和存储携出用户数据，在归属HLR获取漫游号码的同时指明用户携出的运营商路由码RN（Routing Number）。同时，为携出用户提供短信转发功能。

**鉴权AUC**

鉴权AUC主要帮助运营商高效地管理卡号资源，帮助运营商解决在迁移用户到新的HLR时，划分号段混乱和卡号对应关系混乱的问题。鉴权AUC主要完成鉴权和信令转发的功能。鉴权AUC能够处理开户和开卡未开户用户的鉴权，能将消息转发到各自的归属HLR处理，解决用户的IMSI和MSISDN关系不规整的问题，帮助运营商高效的管理卡、号资源。

**Partition**

一个Partition是由一个或多个互相有关联关系的USCDB组成的逻辑局点。Partition运用于USCDB的云部署组网。在USCDB的云部署组网下，用户信息是以号段进行分类，存储到对应的USCDB。为了便于识别和管理，对每一个USCDB都进行Partition的编号。

云部署通过USCDB多地灵活部署的方式，多个USCDB组成一个逻辑USCDB，统一对外提供数据服务，引入Service Partition、Routing
Partition和Routing\_Service Partition的概念。

- Routing Partition：存储全部用户的路由数据（用户标识与用户归属Partition ID之间的对应关系），主要进行数据的路由和分发。Provisioning System统一接入Routing Partition，实现统一业务发放系统。
- Service Partition：只存储本USCDB下面的用户数据，对外提供数据服务。FE侧的信令消息就近访问本地的Service Partition，实现信令的就近接入。
- Routing\_Service Partition：Routing Partition和Service Partition合一的部署形态。Routing\_Service Partition既可以接入Provisioning System，实现统一业务发放，也可以用于与FE对接，处理FE侧的信令消息。
