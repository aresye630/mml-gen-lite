# 配置实例（裸机容器）

本实例仅适用于风筝L中的SMF仅选择本UEG内的UPF的场景。

**说明** 

UDM/HSS部署在园区网络时，

- UEG与基站对接的逻辑接口（N2/S1-MME/N3/S1-U）的IP地址支持共用，也支持不共用。默认不共用。如需要共用，可通过**SET CUSINGLEIPATTR**设置。
- 与基站对接的逻辑接口（N2/S1-MME/N3/S1-U）的IP地址规划为共用时，UPF上须使用Saif接口进行配置。
