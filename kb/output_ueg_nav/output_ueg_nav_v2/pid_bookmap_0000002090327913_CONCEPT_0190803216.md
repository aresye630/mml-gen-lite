# 补卡

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该命令用于为单个用户或多个用户进行补卡。

SIM卡或USIM卡丢失或损坏后，用户通过补卡可以使用和原来相同的手机号码（即MSISDN号码），补卡的前提是新IMSI号码在操作员管理的IMSI号段中，并且新IMSI对应的KI（Individual Subscriber Authentication Key）已经加载（使用**ADD KI**命令加载KI）。查询操作员管理的IMSI号段的方法如下：

登录System Management界面，执行**LST OPRHLRSN**命令查询出该操作员所能操作的虚拟HLR，然后通过**LST VHLRRANGE**命令查询出该虚拟HLR对应的IMSI号段，此号段即该操作员管理的IMSI号段。

#### 注意事项

无。

#### 基本概念

**补卡批操作文件格式**

补卡批操作文件可以是MSISDN+NEWIMSI格式或OLDIMSI+NEWIMSI格式。

- MSISDN+NEWIMSI格式

  文件包含旧的MSISDN号码和新的IMSI号码，每个MSISDN号码与其对应的新IMSI号码组成一行。

  ```
  MSISDN1 NEWIMSI1
  MSISDN2 NEWIMSI2
  ……
  MSISDNn NEWIMSIn
  ```

  MSISDNn为用户旧的MSISDN，NEWIMSIn为用户新的IMSI号码。

  每行的MSISDN、NEWIMSI之间由一个空格分隔，行结束为回车换行符，行与行之间不能存在空行。

  第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。
- OLDIMSI+NEWIMSI格式

  文件包含旧的IMSI号码和新的IMSI号码，每个旧IMSI号码与其对应的新IMSI号码组成一行。

  ```
  OLDIMSI1 NEWIMSI1
  OLDIMSI2 NEWIMSI2
  ……
  OLDIMSIn NEWIMSIn
  ```

  OLDIMSIn为用户旧的IMSI号码，NEWIMSIn为用户新的IMSI号码。

  每行的OLDIMSI、NEWIMSI之间由一个空格分隔，行结束为回车换行符，行与行之间不能存在空行。

  第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。

**鉴权算法**

鉴权算法属于SIM卡和USIM卡上的鉴权参数，用来计算鉴权三元组和鉴权五元组中的相关数据。

**个人身份鉴权密钥KI**

KI即个人身份鉴权密钥，保存在AUC和用户移动台中，在鉴权过程中使用。一个IMSI号码唯一地对应一个KI值，但一个KI值可能被多个IMSI使用。
