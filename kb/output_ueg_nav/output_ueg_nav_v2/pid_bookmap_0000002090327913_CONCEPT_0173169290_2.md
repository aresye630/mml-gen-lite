#### 功能描述

该命令用于对GMDB内存数据库的数据进行查询和更新操作。

#### 基本概念

**节点**

对象树中的一个节点，是树中最基本的单位，由一系列属性构成。

**属性**

描述对象的特征。一个属性由属性类型和一个或多个属性值构成。

**唯一标识名**

在一个对象树中唯一标识一个节点的名字（全局）。

**Schema**

节点中存储数据的规则集合，决定节点存放什么，设置数据的尺寸、取值范围、数据值的格式，防止数据混乱。

**OML语句**

OML（object manipulation language），对象操作语言，是CLOUDDB提供的一种类SQL语言，可以通过oml接口进行对象查询、更新、插入、和删除功能。具体语法规则如下：

**SELECT \***

- 语法

  SELECT \* FROM T\_010203

  [ FILTER t01 WHERE id IN (1, 2, 3) ]

  [ FILTER t0102 WHERE create\_time > SYSDATE - 2 AND create\_time <= SYSDATE – 1 ]

  [ FILTER t010203 WHERE cost < 100 ]

  SELECT COUNT(\*) FROM T\_010203

  [ FILTER t01 WHERE id IN (1, 2, 3) ]

  [ FILTER t0102 WHERE create\_time > SYSDATE - 2 AND create\_time <= SYSDATE – 1 ]

  [ FILTER t010203 WHERE cost < 100 ]
- 约束

  - OML语言大小写不敏感，标识符外和字符串的值除外。
  - SELECT和FROM之间只能是\*，即支持整节点查询。
  - FROM后边指定待查询的目标节点。
  - FILTER指定节点的过滤条件，不带FILTER时表示全表查询。FILTER后边携带过滤条件所在的节点。WHERE后指定该节点的过滤条件。
  - FILTER指定过滤条件时，不同的FILTER的节点名字不允许相同。FILTER后的节点必须在同一条路径上且指定树层级顺序由低到高。
  - 标识符不超过30个字符，只能由“a～z”、“A～Z”、“0～9”或“\_”组成。
  - 支持“/\*”或者“--”注释。
  - 字符串使用单引号表示，例如：'abc'。
  - WHERE条件说明：
    - 支持如下比较操作：>、<、=、<>、>=、<=、in、like、is null、is not null，其中：
      - 对于字符串和Raw类型的比较采用字典序的方式，字典序相同则长度短的小。
      - like支持'%abc%'、'a\_b'和'ab\*'三种模式。
        - “%”表示0个或多个字符。
        - “\_”表示1个字符。
        - 'ab\*'模式仅对raw和varraw类型的字段有效，支持在尾部使用且只使用1个“\*”号，“\*”号前必须有字符且只能是十六进制字符，表示结尾匹配任意多个“\*”号前的字符。如“b\*”表示匹配0或多个b。
      - like支持使用ESCAPE提供转义字符，转义字符仅能用于string类型的字段。在模式串中，转义字符后面只能是转义字符本身、%、\_三者之一。例如: name LIKE 'Hua#\_wei' ESCAPE '#'，此处“#”为转义字符，则“#”后面的“\_”不作为通配符，此处匹配的字符串是'Hua\_wei'。
      - in支持in (1, 2, 3)格式，in和括号之间可以有空格分隔，也可以没有空格分隔。
      - 对于字段与NULL值的比较，只能采用is null和is not null，不能采用“=”等比较符号。
    - 支持关键字“null”、“true”和“false”。
    - 支持条件“与（AND）”、“或（OR）”操作，AND优先级高于OR，即“A OR B AND C”会理解为“A OR (B AND C)”，支持通过“（）”强制改变优先级，建议应用实现时使用“（）”明确优先级。
    - 支持如下运算操作：“+”、“-”、“\*”、“/”、“&”和“|”。

      Raw类型或者VarRaw类型进行“&”或“|”运算：运算符两侧长度相同，且不能和整型数值进行运算。
    - 内置函数支持：
      - hextoraw函数，用于将字符串转化为二进制类型。
      - upper函数，用于将字符串转化成大写。
      - lower函数，用于将字符串转化成小写。

**UPDATE**

- 语法

  UPDATE T\_010203 SET cost = cost + 1，status = 2

  [ FILTER t01 WHERE id IN (1, 2, 3) ]

  [ FILTER t0102 WHERE create\_time > SYSDATE - 2 AND create\_time <= SYSDATE – 1]

  [ FILTER t010203 WHERE cost < 100 ]
- 约束
  - SET后最多可以加256个更新字段对。
  - 其他条件约束请参考SELECT语句约束。

**INSERT**

- 语法

  INSERT INTO T\_010203(cost, status) VALUES(1, 2)

  [ FILTER t01 WHERE id IN (1, 2, 3) ]

  [ FILTER t0102 WHERE create\_time > SYSDATE - 2 AND create\_time <= SYSDATE – 1 ]
- 约束：请参考SELECT语句约束

**DELETE**

- 语法
