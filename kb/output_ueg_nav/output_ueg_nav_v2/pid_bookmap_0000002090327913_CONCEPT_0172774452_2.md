# 服务状态管理

- 功能描述
- 相关概念
- 注意事项
- 配置原则

#### 功能描述

此组命令用于对系统提供数据服务的状态进行管理。由于内存数据库数据异常或者其他异常情况导致数据服务异常，需要USCDB网元去激活系统，停止提供数据服务；USCDB网元故障修复后，需要激活系统，恢复数据服务。

#### 相关概念

**LDAP**

LDAP是轻量级目录访问协议的简称，是用于访问目录服务的一个标准可扩展的Internet协议。LDAP协议中部分协议是基于X.500标准，更简单、更精炼，可扩展性更好。

LDAP特点如下：

- 数据按目录结构组织
- 对外提供一个统一的访问点
- 支持数据的分布式存储
- 数据读取快

#### 注意事项

无。

本命令组无特殊配置原则。
