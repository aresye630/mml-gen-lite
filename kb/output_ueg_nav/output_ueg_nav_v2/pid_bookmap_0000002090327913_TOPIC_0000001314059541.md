# 用户面机机接口命令

## 目录内容

- 用户面机机接口命令
  - 集中配置
    - 公共配置核查是否需要导出MML判定(GET PUBCFGUPDATEFLAG)
    - 获取摘要(GET PUBCFGDIGEST)
  - 机机接口命令
    - 用户面功能管理
      - 系统调测管理
        - 升级操作管理
          - 升级阶段管理
            - 查询升级启动阶段（LST UPGSTAGE）
            - 设置升级启动阶段（SET UPGSTAGE）
          - 升级服务申请
            - 查询升级服务申请状态（DSP UPGSRVREQSTATUS）
            - 下发升级服务申请（ACT UPGSRVREQ）
      - 集中配置管理
        - 配置摘要信息
          - 公共配置核查是否需要导出MML判定(GET PUBCFGUPDATEFLAG)
          - 获取摘要(GET PUBCFGDIGEST)
  - License控制管理
    - 设置License开关（SET DFTLICSWITCH）
