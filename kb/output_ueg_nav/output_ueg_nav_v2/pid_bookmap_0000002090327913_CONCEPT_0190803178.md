#### 命令功能

该组命令用于管理用户的VGCS（Voice Group Call Service）业务数据。

VGCS可以建立到属于某一给定服务区的一组业务用户的广播呼叫，呼叫采用半双工模式，呼叫期间任何业务用户都可以成为讲话者，但任一时刻只允许一个讲话者，其他业务用户为听者。VGCS在建立到业务用户的广播呼叫时，还同时建立到调度员的专有连接，该连接采用全双工模式，调度员可以接收组呼的信息，也可以向整个组发布语音信息。

VGCS呼叫可以由业务用户发起，也可以由授权的调度员发起。参与VGCS呼叫的成员包括两类：调度员和业务用户。

- 调度员

  VGCS呼叫中最多可以有5个调度员，VGCS呼叫的调度员可以是固定用户或移动用户，通过网络为其建立的专用通道参与组呼的话音通信。
- 业务用户

  签约VGCS业务的移动用户，被叫业务用户通过组呼区域内的组呼通道参与组呼的话音通信。

VGCS与VBS的差别在于，VBS在整个呼叫期间，只有呼叫发起者可以讲话，其他用户只能为听者；而VGCS呼叫在整个呼叫期间，除调度员可以随时讲话外，所有业务用户可通过抢占上行信道讲话。因此，VBS与VGCS相比，没有上行信道的管理、控制部分。

#### 基本概念

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
