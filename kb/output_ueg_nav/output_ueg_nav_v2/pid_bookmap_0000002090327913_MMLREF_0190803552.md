# 多SIM业务

- 命令功能
- 注意事项

## 命令功能

多SIM业务是指将最多9个用户绑定到一个群组，其中群组内的成员用户都有自己的IMSI、MSISDN、鉴权数据和动态数据，群组内存在一个主用户和一个激活用户。仅支持通过激活用户修改补充业务数据，激活用户修改的补充业务数据到非激活卡的数据同步通过****SET MAPCONF****命令的“是否支持VoLTE Multi-SIM群组成员间的补充业务同步”参数取值处理。激活用户用于接收群组内所有成员的入呼叫（语音和短信）。如果用户漫游地支持多SIM业务，则群组成员出呼叫（语音和短信）使用主用户的MSISDN号码。如果用户漫游地不支持多SIM业务，群组成员出呼叫（语音和短信）使用自己的MSISDN号码。

## 注意事项

1、用户签约多SIM业务后，需要通过**MOD COMISDN**命令向多SIM群组中添加成员。

2、如果执行**MOD COMISDN**命令时，如果主用户未签约多SIM业务，则默认主用户签约的是普通COMISDN业务。
