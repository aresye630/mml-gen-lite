# 业务条件批操作管理

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

业务条件批操作用于按照业务条件批量执行MML命令。传统批操作所批量执行的命令是事先确定的；而业务条件批操作批量执行的命令，是通过判断业务条件批操作命令入参范围内的每一个用户是否满足入参指定的业务条件，并根据判断结果生成业务条件批操作的MML命令。可以使用**LST LOG**命令查询业务条件批操作任务执行的所有MML命令的执行结果。

#### 注意事项

- 业务条件批操作最大保存100条详细结果记录。
- 由于**LST LOG**命令保存结果文件时只能支持最大100万条记录返回，要想得到所有的业务条件批操作的MML命令执行结果，需要按时间分段多次查询。

#### 基本概念

- **CONIMSIFILE文件格式**

  CONIMSIFILE文件包含不连续的IMSI号码，格式如下所示：

  ```
  IMSI1
  IMSI2
  IMSI3
  IMSI4
  ……
  IMSIn
  ```

  IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

  第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。
- **CONISDNFILE文件格式**

  CONISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

  ```
  MSISDN1
  MSISDN2
  MSISDN3
  MSISDN4
  ……
  MSISDNn
  ```

  MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

  第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。
- **批操作资源文件存放位置**

  在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

  批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

  例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

  其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
