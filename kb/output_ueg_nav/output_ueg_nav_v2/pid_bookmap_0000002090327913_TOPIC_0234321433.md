# AMF

## 目录内容

- AMF
  - AMF信息管理
    - 增加AMF信息（ADD AMFINFO）
    - 修改AMF信息（MOD AMFINFO）
    - 查询AMF信息（LST AMFINFO）
    - 删除AMF信息（RMV AMFINFO）
  - AMF的N2接口信息管理
    - 查询AMF的N2接口信息（LST N2INFAMFINFO）
    - 增加AMF的N2接口信息（ADD N2INFAMFINFO）
    - 删除AMF的N2接口信息（RMV N2INFAMFINFO）
  - AMF全局标识符管理
    - 查询AMF全局标识（LST GUAMI）
    - 删除AMF全局标识（RMV GUAMI）
    - 修改AMF全局标识（MOD GUAMI）
    - 增加AMF全局标识（ADD GUAMI）
  - 备用GUAMI列表管理
    - 增加供备GUAMI信息（ADD BACKUPGUAMI）
    - 删除供备GUAMI信息（RMV BACKUPGUAMI）
    - 修改供备GUAMI信息（MOD BACKUPGUAMI）
    - 查询供备GUAMI信息（LST BACKUPGUAMI）
  - 本地数据网络管理
    - 查询本地数据网络（LST LADN）
    - 增加本地数据网络（ADD LADN）
    - 修改本地数据网络（MOD LADN）
    - 删除本地数据网络（RMV LADN）
