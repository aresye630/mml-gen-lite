# 导出日志任务管理

- 功能描述
- 相关概念
- 注意事项

#### 功能描述

此组命令用于对业务发放系统日志导出任务配置信息进行增加、删除、查看或查看日志状态。

#### 相关概念

无。

#### 注意事项

PGW生成的导出文件为UTF-8格式，如果导出数据中包含除ASCII可显示字符外的其他字符，默认导出格式会出现乱码，需要转码为UTF-8格式才能正常显示。

## 目录内容

- 导出日志任务管理
  - 删除导出日志任务(RMV EXPLOGTASK)
  - 查询导出日志任务(LST EXPLOGTASK)
  - 添加导出日志任务(ADD EXPLOGTASK)
  - 显示导出日志任务(DSP EXPLOGTASK)
