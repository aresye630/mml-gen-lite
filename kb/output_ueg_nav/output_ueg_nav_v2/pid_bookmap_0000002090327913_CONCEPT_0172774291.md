# IP Dispatch管理

- 功能描述
- 相关概念
- 注意事项
- 配置原则

#### 功能描述

此命令用于管理IP Dispatch，包括激活IP链路。

#### 相关概念

**远端DSG**

远端DSG是远端网元上的DSG模块，与本端DSG是相对的。例如，对于主用局USCDB，它的远端DSG指主用局FE容灾局FE、容灾局USCDB的DSG模块；对于容灾局USCDB，它的远端DSG指容灾局FE、主用局FE、主用局USCDB的DSG模块。

#### 注意事项

无。

#### 配置原则

本命令无特殊配置原则。

## 目录内容

- IP Dispatch管理
  - 设置DSG五元组分发类型（SET DSGTUPDISPTYP）
  - 查询DSG五元组分发类型（LST DSGTUPDISPTYP）
  - 激活IP链路(ACT IPDISP)
