# 用户统计

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于查询满足指定条件的用户数据，并将查询结果以文本格式保存在指定目录下。

#### 注意事项

无。

#### 基本概念

**网络接入模式**

网络接入模式定义了允许用户接入本网的网络类型，包括三类：

- 允许接入电路域、分组域、EPS网络和5GS网络
- 允许接入电路域和EPS网络
- 允许接入分组域、EPS网络和5GS网络

可通过**LST NAM**命令查询用户的网络接入模式。

**QoS模板**

QoS模板是业务模板的一种，用于配置PS域的QoS信息。可通过**LST QOSTPL**命令查询已增加的QoS模板的相关信息。

**增强路由业务**

增强路由业务是指无论用户作为主叫、被叫还是被设置为前转用户，系统都会将呼叫先路由到service nodes，service nodes会对该用户进行合法性检查，检查通过后再继续后续的呼叫。可通过**LST ROUTECATEGORY**命令查询用户签约增强路由业务的相关数据。

**闭锁所有出呼叫业务**

闭锁所有出呼叫业务是ODB（Operator Determined Barring）业务的一种，该业务激活后，用户将不能进行除紧急呼叫以外的所有呼叫。可通过**LST ODBDAT**命令查询闭锁所有出呼叫业务的签约情况。

**呼叫重定向业务**

呼叫重定向业务是指当用户做主叫时，系统会将呼叫路由到相应的放音平台。该业务是CS域的特性，只能为CS域的用户签约。可通过**LST CR**命令查询用户签约呼叫重定向业务的相关数据。

**LCK锁**

LCK锁是指通过改变用户的锁状态来限制或允许用户对网络的使用，实现对用户的开机或停机。可通过**LST LCK**命令查询锁的签约情况。

**区域漫游限制**

区域漫游限制是指限制用户只能在指定的某些区域内进行漫游。可通过**LST RSZI**命令查询区域漫游限制情况。

**NRBT业务**

NRBT（National Ring Back Tone）业务是指NRBT彩铃业务。可通过**LST NRBT**命令查询用户签约该业务的相关信息。
