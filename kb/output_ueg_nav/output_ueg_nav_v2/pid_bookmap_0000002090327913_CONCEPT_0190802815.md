# USSD控制数据

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于管理非结构化补充业务数据USSD（Unstructured Supplementary Service Data）的控制数据。用户可以通过配置USSD控制数据实现移动终端与网络实时交互信息。

#### 注意事项

无。

#### 基本概念

**USSD业务**

非结构化补充业务数据USSD，允许用户通过移动终端输入符合USSD格式的非标准的补充业务操作命令向网络发起特定的业务请求，或者由网络侧向移动终端发起USSD命令以完成某种特定的业务。USSD业务组网图如图1所示。

**图1** USSD业务组网图

如图1所示，USSD业务组网在GSM、UMTS、TD-SCDMA网络外增加了两个部分：USSD网关和USSD中心。

USSD网关通过七号信令的MAP部分与GSM、UMTS、TD-SCDMA网络相连，USSD网关通过TCP/IP与USSD中心连接。USSD中心主要提供各种应用接口，与气象台、股票交易所、银行等应用中心连接在一起。

USSD业务的处理主要在各种应用中心完成，应用中心处理完成后通过HLR或者MSC将处理结果传到MS。实际组网应用中，USSD网关通常内置在USSD中心里。

USSD业务与短消息业务相比，主要是移动终端与网络能实时交互信息，非常适合于开展天气预报、股票查询、银行服务等增值业务。CAMEL业务与USSD业务相结合可以满足用户多方面的信息查询需求。

**CAMEL**

CAMEL是在GSM/TD-SCDMA/WCDMA协议族中提出的一整套智能网解决方案。

CAMEL提供了一种机制，使得TD-SCDMA/WCDMA网络能够提供独立于服务网络的业务，运营商定义的业务能够很容易从服务网络以外实现对业务的控制。CAMEL并非提供一项新的补充业务，而应被视为一种网络特征。在具有CAMEL特征的移动网络上，网络运营商能够提供网络运营商自定义业务，甚至当用户漫游出归属网络后仍然能够提供这项业务。

**U-CSI模板**

该组命令用于管理系统中U-CSI（USSD CAMEL Subscription
Information）模板数据。用户可以通过签约U-CSI模板ID签约U-CSI业务。

U-CSI是USSD CAMEL签约信息，该数据由HLR保存，不发送给其他网元。U-CSI包含用来为服务的用户调用USSD应用的触发信息。USSD智能应用时，MSC将USSD请求路由到用户归属的HLR，由HLR路由到相应的SCP进行处理。
