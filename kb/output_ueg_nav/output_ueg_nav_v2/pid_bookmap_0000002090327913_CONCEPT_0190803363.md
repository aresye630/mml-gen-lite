# CAMEL漫游协议模板

- 功能描述
- 基本概念

#### 功能描述

该组命令用于增加、删除、修改或查询CAMEL漫游协议模板相关信息，对VLR/SGSN使用的CAMEL漫游协议进行管理。通过**ADD CAMELROAMTPL**命令将VLR的号码前缀添加到CAMEL漫游协议模板中，就认为该VLR/SGSN与UDM签约有CAMEL漫游协议。

运营商可以针对用户漫游的不同网络，对CAMEL智能业务的触发进行灵活控制，从而提供丰富的增值业务。用户签约CAMEL漫游协议模板后，在具有CAMEL特征的移动网络上，运营商能够提供自定义业务，甚至当用户漫游出归属网络后仍然能够提供这项业务。

CAMEL漫游协议表示用户当前漫游所在的非归属网络是否支持该用户归属网络定义的CAMEL业务，并且能够进行网间结算。在HLR中CAMEL漫游协议用于用户在非归属网络漫游，当用户发起位置更新时控制O-CSI，在用户做被叫的SRI流程中控制T-CSI的下发。非归属网络与归属网络是否有CAMEL漫游协议由运营商确定。

CAMEL漫游协议模板可以被**ADD OCSITPL**或**ADD TCSITPL**引用。当UDM下发O-CSI或T-CSI信息时，如果用户不在本网漫游，则会判断用户当前所在的VLR/SGSN是否设置了CAMEL漫游协议以及是否支持CAMEL功能，如是则根据用户签约的O-CSI或T-CSI漫游模板进行相应的处理。

#### 基本概念

**CAMEL业务**

CAMEL是在GSM/TD-SCDMA/WCDMA协议族中提出的一整套智能网解决方案。

CAMEL提供了一种机制，使得TD-SCDMA/WCDMA网络能够提供独立于服务网络的业务，运营商定义的业务能够很容易从服务网络以外实现对业务的控制。CAMEL并非提供一项新的补充业务，而应被视为一种网络特征。在具有CAMEL特征的移动网络上，网络运营商能够提供网络运营商自定义业务，甚至当用户漫游出归属网络后仍然能够提供这项业务。

CAMEL的发展经历了四个阶段：

CAMEL phase 1、CAMEL phase 2、CAMEL phase 3和CAMEL phase 4。

在CAMEL发展的四个阶段，CAMEL特性的应用范围不同。

CAMEL phase 1：CAMEL特性应用于与移动始发和移动终结的呼叫相关的业务。

CAMEL phase 2：CAMEL特性应用于与补充业务调用相关的业务。

CAMEL Phase 3：CAMEL特性应用于始发短消息业务（SMS MO）、GPRS会话和PDP上下文、HLR用户数据的控制和网络信令负荷。

CAMEL phase 4：CAMEL特性应用于终结短消息业务（SMS MT）。

**O-CSI**

O-CSI是主叫CAMEL签约信息。当用户位置更新时，O-CSI数据将被插入用户当前所在的VPLMN（VLR）；在移动用户作被叫（接收从GMSC转发的来电）的SRI流程中，O-CSI数据将被传给IPLMN（Interrogating PLMN）。

O-CSI包含用来调用CAMEL业务逻辑的触发信息。当移动用户在VMSC中做主叫时，或移动用户在VMSC或GMSC中发生前转时，O-CSI智能业务将被触发。

**T-CSI**

T-CSI是被叫CAMEL签约信息，在移动用户做被叫的SRI流程，T-CSI数据由HLR传递给GMSC，T-CSI智能业务将被触发。按照用户签约的T-CSI模板中的信息进行业务逻辑处理。

相对于呼叫普通用户，呼叫签约T-CSI模板的CAMEL用户时，GMSC将向用户归属HLR发起两次SRI（Send Routing Information）请求消息，HLR在第一次SRI响应消息中返回T-CSI数据，然后GMSC在第二次SRI请求消息中带上抑制T-CSI信元（即suppress-T-CSI），HLR检查到该信元后才向用户当前所在VLR取漫游号码，并在第二次SRI响应消息中返回取到的漫游号码。
