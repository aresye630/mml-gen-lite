# 数据订阅配置管理

#### 功能描述

此组命令用于给第三方FE发送订阅信息，管理数据层订阅通知的数据订阅。

#### 相关概念

**数据层订阅通知**

FE/第三方设备可以通过USCDB提供的订阅通知特性，订阅关注的数据。当USCDB中存储的数据发生变更时，USCDB可以将变更的数据通知到FE/第三方设备，以支撑运营商的相关业务。数据层订阅通知存在数据的发布者和订阅者，只有发布者发布了数据集，订阅者才能订阅到被发布的数据集。订阅者通过数据订阅配置管理方便选择和变更关注的数据集。

#### 注意事项

无。

#### 配置原则

本命令组无特殊配置原则。

  - 删除订阅配置信息(RMV SUBSCRIPTION)
  - 查询订阅配置信息(LST SUBSCRIPTION)
