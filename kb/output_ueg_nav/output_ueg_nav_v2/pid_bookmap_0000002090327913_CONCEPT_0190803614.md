# 锁管理

- 命令功能
- 注意事项

#### 命令功能

该组命令用于修改和查询LCK锁、GPRS锁和用户申请锁的状态。

可以通过改变用户锁的状态来限制或允许用户对网络的使用，即限制或允许用户呼入、呼出以及使用GPRS上网。

UDM支持的用户锁包括：

- LCK（Lock）锁：用于用户欠费停机/复机的场景下，限制或允许用户的呼入、呼出，CS/PS域的位置更新以及对CS/PS/EPS业务和NON3GPP业务的使用。
- GPRS（General Packet Radio Service）锁：用于限制/允许用户使用GPRS网络的场景下，限制或允许“网络接入模式”为“SGSN”或“BOTH”的用户使用GPRS业务。
- SAB（Subscriber Application Barring）锁：用于用户主动申请停机/复机的场景下，限制或允许“网络接入模式”为“MSC”或“BOTH”的用户的呼入、呼出。

可以通过**LST NAM**命令查询用户的网络接入模式。
