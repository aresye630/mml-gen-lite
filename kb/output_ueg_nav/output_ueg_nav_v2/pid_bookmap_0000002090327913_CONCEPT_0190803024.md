# 割接策略模板配置

- 功能描述
- 基本概念

#### 功能描述

该组命令用于在UDM中设置割接策略模板信息。当系统对用户消息进行批量割接时，系统签约割接策略模板，用户通过**MOD MIGPOLICY**签约割接策略与系统配置的割接策略模板关联，UDM根据消息中携带的用户标识及用户签约的割接策略配置对用户的MAP消息进行转发处理。提升UDM平滑搬迁能力。

#### 基本概念

无。

## 目录内容

- 割接策略模板配置
  - 查询割接策略模板(LST MIGPOLICYCFG)
  - 删除割接策略模板(RMV MIGPOLICYCFG)
  - 修改割接策略模板(MOD MIGPOLICYCFG)
  - 增加割接策略模板(ADD MIGPOLICYCFG)
