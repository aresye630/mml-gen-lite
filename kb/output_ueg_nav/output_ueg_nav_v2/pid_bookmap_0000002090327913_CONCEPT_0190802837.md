# VT-CSI模板

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于管理系统中VT-CSI（VMSC Terminating
CAMEL Subscription Information）模板数据。用户可以通过签约VT-CSI模板ID签约VT-CSI业务。

VT-CSI是VMSC被叫CAMEL签约信息，当用户签约VT-CSI业务或进行位置更新流程时，HLR通过插入用户数据消息将VT-CSI数据下发给MSC/VLR。当移动用户在VMSC做被叫时，VT-CSI智能业务将被触发，按照用户签约的VT-CSI模板中的信息进行业务逻辑处理。

#### 注意事项

无。

#### 基本概念

**DP**

DP（Detection
Point）即检出点，用于触发智能业务和在智能业务过程中检测出与呼叫相关的事件，例如收集信息、号码分析、应答或挂机。DP的配置是为了通知“智能业务逻辑实例”遇到了DP，从而使智能业务逻辑实例影响随后的呼叫处理。如果DP没有配置，则继续原来的业务处理，不会涉及到智能业务。

不同的CAMEL阶段支持不同的DP，对于VT-CSI具体支持情况如表1所示。

| CAMEL阶段   | 支持的DP                                                                 |
|:----------|:----------------------------------------------------------------------|
| Phase 1   | TAA（Terminating Attempt Authorised）（DP12）                             |
| Phase 2   | TAA（Terminating Attempt Authorised）（DP12）                             |
| Phase 3   | TAA（Terminating Attempt Authorised）（DP12），TBUSY（DP13），TNOANSWER（DP14） |
| Phase 4   | TAA（Terminating Attempt Authorised）（DP12），TBUSY（DP13），TNOANSWER（DP14） |

**说明** 

执行**ADD
VTCSITPL**/**MOD VTCSITPL**命令时如果选择CAMEL阶段不支持的DP会返回错误。

**DP触发准则**

- TAA（DP12）

  该DP点只有基本业务码触发准则，最多存储5组基本业务码或基本业务码组。如果呼叫的基本业务码匹配5组中的任意一组基本业务码或基本业务码组中的一个成员，
  则认为该呼叫满足基本业务码触发准则。该触发准则不是必须要配置的，如果未配置则默认满足触发条件。
- TBUSY（DP13）

  该DP点只包括呼叫释放原因触发准则，呼叫释放原因触发准则存储最多5个呼叫释放原因值，当GMSC从ISUP（Integrated
  Services Digital Network User Part）层接收到的呼叫释放原因值与5个中任一个呼叫释放原因值相同，则认为满足触发条件。该触发准则不是必须要配置的，如果未配置则默认满足触发条件。
- TNOANSWER（DP14）

  该DP点的触发准则同TBUSY（DP13）。该触发准则不是必须要配置的，如果未配置则默认满足触发条件。

不同的CAMEL阶段支持不同的DP触发准则，对于VT-CSI具体支持情况如表2所示。

| CAMEL阶段   | 支持的触发准则              |
|:----------|:---------------------|
| Phase 1   | 不支持触发准则              |
| Phase 2   | 基本业务码触发准则            |
| Phase 3   | 基本业务码触发准则、呼叫释放原因触发准则 |
| Phase 4   | 基本业务码触发准则、呼叫释放原因触发准则 |

**说明** 

执行**ADD
VTCSITPL**/**MOD VTCSITPL**命令时如果选择CAMEL阶段不支持的DP触发准则会返回错误。
