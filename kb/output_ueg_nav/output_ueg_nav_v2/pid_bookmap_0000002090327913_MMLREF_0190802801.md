# 补充业务管理

- 命令功能
- 注意事项

## 命令功能

补充业务包括以下业务：

- 呼叫前转类补充业务

  用户的前转业务实现移动用户作被叫时，在满足一定的条件下，接通指定的号码而不是被叫号码的功能。
- 呼叫闭锁类补充业务

  呼叫闭锁类补充业务包括闭锁出呼叫和闭锁入呼叫。
- 号码识别类补充业务

  号码识别类补充业务包括主、被叫号码识别显示和主、被叫号码识别限制。
- 其他补充业务

  其他补充业务包括计费信息通知业务、实时计费通知业务、呼叫等待业务、呼叫保持业务、多方通话业务、显式呼叫转移业务。
- 闭合用户群

  CUG(Closed User Group)补充业务是用户可以连接到PLMN和其它网络来建立一个CUG-闭合用户群，出入该CUG的呼叫会受到限制。一个用户可以成为一个或多个CUG的成员。指定CUG的成员可以与群内的用户通信，但在通常情况下，不能与群外的用户通信。
- PLMN自定义补充业务

  PLMNSS（PLMN Specific Supplementary Services）业务即运营商自定义补充业务，如热计费业务和个性化回铃音业务等。
