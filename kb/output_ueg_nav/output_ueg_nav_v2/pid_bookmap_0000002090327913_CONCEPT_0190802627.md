# 改号

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于更改用户的MSISDN号码，并删除改号表中的用户数据。

#### 注意事项

无。

#### 基本概念

**改号批操作文件格式**

- 改号批操作文件包含旧MSISDN号码和新的MSISDN号码时，每个旧的MSISDN号码与新的MSISDN号码占一行，格式如下：

  ```
  MSISDN1 NEWMSISDN1
  MSISDN2 NEWMSISDN2
  ……
  MSISDNn NEWMSISDNn
  ```

  MSISDNn为用户旧的MSISDN，NEWMSISDNn为用户新的MSISDN号码。

  每行的MSISDN、NEWMSISDN之间由一个空格分隔，行结束为回车换行符，行与行之间不能存在空行。

  第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。
- 改号批操作文件包含IMSI号码和新的MSISDN号码时，每个IMSI号码与新的MSISDN号码占一行，格式如下：

  ```
  IMSI1 NEWMSISDN1
  IMSI2 NEWMSISDN2
  ……
  IMSIn NEWMSISDNn
  ```

  IMSIn为用户的IMSI，NEWMSISDNn为用户新的MSISDN号码。

  每行的IMSI、NEWMSISDN之间由一个空格分隔，行结束为回车换行符，行与行之间不能存在空行。

  第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
