# 模块管理

- 功能描述
- 基本概念

#### 功能描述

模块管理用于指导操作员对USCDB网元内的模块进行增加、删除、查询、修改等相关操作，主要在开局、扩容、升级等场景使用。

**图1** 命令组关系图

**说明** 

如图1所示，模块管理与Pod管理、数据服务管理、数据存储管理等是相关的，举例说明如下：

- 当需要添加模块时，一定要保证待添加模块所在Pod已经添加；当需要删除Pod前，也需要先删除模块。
- 当模块添加成功后，才能对已添加的模块进行对应的管理。如：只有添加了DRU、DSU模块，才能对该类模块进行Cluster管理、节点管理等操作。

#### 基本概念

**模块**

模块是Pod内运行的进程，USCDB网元内的模块有DPU、NDF、DSG、DBG、DRU、DSU、PGW、CAG、DMA。模块的基本概念如表1所示。

| 模块名称   | 解释说明                                                                                                                                                                                                                                                                                                                                                                |
|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DPU    | 消息转发单元（DisPatching Unit）。 USCDB网元内的DPU模块配置在USPGW、USRSU、USPID3 Pod中。DPU模块可以配置为主备工作方式，也可以不配置为主备工作方式。DPU模块具有以下功能：对外提供FTP/SFTP通信的功能。DPU模块提供FTP/SFTP通信代理功能，数据通过DPU模块与容灾BE、业务发放系统、第三方FTP/SFTP服务器进行FTP/SFTP通信。提供PGW全局数据加载串行化控制功能。PGW模块进行全局数据加载时，对DPU模块发送请求，接收到DPU模块的响应后，方可进行全局数据加载。  说明： 当前版本中DPU模块不再提供IP数据包汇聚功能，及消息转发功能。                                                  |
| NDF    | 网络数据库管理单元（Network Data Function）。NDF模块配置在USPID3 Pod中。NDF模块需要配置成主备工作方式。NDF模块具有以下功能：物理数据库管理功能，提供物理数据库的备份、恢复、密码修改、升级和回退。平台资源监控功能，支持监控平台资源包括数据库状态、集群服务状态及虚拟机磁盘（裸机磁盘）分区状态，当监控资源故障时上报告警。                                                                                                                                                                                  |
| DSG    | 数据服务网关（Data Service Gateway）。USCDB网元内的DSG模块配置在USRSU Pod中。DSG模块在DCI（Data Service Call Interface）接口层提供服务，用于主用BE和容灾BE、BE和FE之间的互连。DSG模块具有以下功能：负责收集和维护BE内部DRU Cluster和DSU Cluster内每个节点的状态，作为与外部通信的入口，对外屏蔽节点。负责汇聚和转发到对端的数据访问请求和响应，并将接收到的数据访问请求根据操作类型（查询或更新）分发给Cluster内的节点。向FE的DSG广播DRU Cluster状态（不包括Cluster内部节点的状态）。向其他BE广播DRU Cluster和DSU Cluster的状态（不包括Cluster内部节点的状态）。 |
| DBG    | 数据库网关（DataBase Gateway）。DBG模块配置在USPID3 Pod中。DBG模块具有以下功能：负责与BE内部每一个DRU和DSU相连接，实现连接的汇聚。实现来自DRU和DSU的内部消息和物理数据库接口消息之间的转换。                                                                                                                                                                                                                                               |
| DRU    | 数据路由单元（Data Routing Unit）。DRU模块配置在USRSU Pod中。DRU模块具有以下功能：负责用户数据的路由功能，保存全局数据和路由数据。根据负载均衡策略选择DSU Cluster中的一个DSU节点提供数据查询服务，但提供数据消息更新服务时只能选择Master节点。                                                                                                                                                                                                                   |
| DSU    | 数据服务单元（Data Service Unit）。DSU模块配置在USRSU Pod中。DSU模块的功能：负责用户数据的存储，向DRU提供用户数据的查询、增加、删除、更新服务。                                                                                                                                                                                                                                                                           |
| PGW    | 业务发放网关（Provisioning Gateway）。PGW模块配置在USPGW Pod中。只配置一对主备PGW进程，其它PGW模块配置成负载均衡。根据配置的工作方式，PGW模块功能差异点如下：主备模式的PGW模块有以下额外的功能：处理PGW Web LMT的消息。管理、分发批操作任务。 主备和负载均衡的PGW模块具有以下公共的功能：处理业务发放系统的消息。与FE交互，完成订阅消息等处理。通过DSG与DRU\DSU交互，完成用户数据、全局数据和公共数据的修改。与物理数据库交互，完成操作日志的存储。执行批操作任务。                                                                                               |
| CAG    | 融合访问网关（Convergence Access Gateway）。CAG模块配置在USRSU Pod中，用于第三方FE访问数据。CAG模块具有以下作用：负责收集和维护BE内部DRU Cluster和DSU Cluster内每个节点的状态，作为与外部通信的入口，对外屏蔽节点。负责汇聚和转发到对端的数据访问请求和响应，并将接收到的数据访问请求根据操作类型（查询或更新）分发给Cluster内的节点。向FE的DSG广播DRU Cluster状态（不包括Cluster内部节点的状态）。向其他BE广播DRU Cluster和DSU Cluster的状态（不包括Cluster内部节点的状态）。                                                             |
| DMA    | 数据管理代理（Data Management Agent）。DMA模块在添加DRU和DSU模块时自动添加。DMA模块具有以下作用：从内存数据库将用户数据导出到第三方设备。导入用户数据到内存数据库。在DSU Cluster之间进行数据迁移。节点状态为Slave的DSU模块对应的DMA模块提供用户数统计功能。节点状态为Slave的DSU模块对应的DMA模块提供License统计功能。                                                                                                                                                                     |
