# 其他补充业务

- 命令功能
- 注意事项

## 命令功能

其他业务管理主要用来管理如下的补充业务：

- 计费信息通知业务
- 实时计费通知业务
- 呼叫等待业务
- 呼叫保持业务
- 多方通话业务
- 显式呼叫转移业务

## 注意事项

无。

## 目录内容

- 其他补充业务
  - 查询其他补充业务(LST OSS)
  - 修改其他补充业务(MOD OSS)
  - 实时计费通知业务
    - 修改AOCC业务(MOD AOCC)
    - 查询AOCC业务(LST AOCC)
  - 显式呼叫转移业务
    - 修改ECT业务(MOD ECT)
    - 查询ECT业务(LST ECT)
  - 多方通话业务
    - 查询MPTY业务(LST MPTY)
    - 修改MPTY业务(MOD MPTY)
  - 呼叫等待业务
    - 激活CW业务(ACT CWAIT)
    - 查询CW业务(LST CWAIT)
    - 修改CW业务(MOD CWAIT)
    - 去激活CW业务(DEA CWAIT)
  - 完成遇忙用户呼叫补充业务
    - 查询CCBS业务（LST CCBS）
    - 修改CCBS业务(MOD CCBS)
  - 计费信息通知业务
    - 查询AOCI业务(LST AOCI)
    - 修改AOCI业务(MOD AOCI)
  - 呼叫保持业务
    - 查询HOLD业务(LST HOLD)
    - 修改HOLD业务(MOD HOLD)
  - 多呼业务
    - 修改MC业务(MOD MC)
    - 查询MC业务(LST MC)
