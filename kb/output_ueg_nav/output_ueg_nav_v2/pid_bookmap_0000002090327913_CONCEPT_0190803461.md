# VLR/SGSN漫游限制模板

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于在HLR中管理VLR/SGSN区域漫游限制模板数据。

VLR/SGSN漫游限制模板设置了VLR/SGSN区域漫游限制数据，用户可以通过执行**MOD VSRR**命令签约VLR/SGSN漫游限制业务，来限制用户只能或不能在模板指定的区域范围内漫游。

在设置VLR/SGSN模板时，可以把地理位置相近或者运营商规划的某些属性相近的VLR/SGSN的号码集合起来，在限制用户漫游的时候，把用户限制在这些VLR/SGSN号码区域范围之内，从而灵活高效的对用户移动性管理，用户也可根据需要灵活签约该业务，提升业务体验。
