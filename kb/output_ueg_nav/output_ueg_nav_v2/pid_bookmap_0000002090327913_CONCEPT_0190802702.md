# 网络维护管理

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

网络维护管理有以下功能：

- 一致性校验:单个用户数据进行一致性校验。
- 模拟Cancel Location消息：模拟Cancel Location操作是在用户数据管理台上人为的模拟HLR发送Cancel Location消息，以此来删除HLR中指定用户在相应的VLR/SGSN中的用户信息。
- 模拟Reset消息：模拟Reset消息通常在HLR割接时进行，使原来的用户找到新割接的HLR，在新HLR中存储用户的位置信息（VLR号码/SGSN号码），以保证用户能够正常呼叫。
- 模拟FMNotify消息：模拟FMNotify消息通常是在网络和手机的FM数据不一致时，操作员发送模拟的USSD Notify操作通知手机，以便手机修改FM数据，和网络的FM数据保持一致。
- 模拟Update Location消息：模拟Update Location消息是为携出用户发送模拟位置更新消息，以便获取用户的HLRNUM，同时将NPMSC NUMBER更新到HLR中。
- 模拟Reset Update Location消息：模拟Reset Update Location消息是处理NPMSC收到reset消息后，由于系统的某些异常原因导致未能完成的该HLR下用户的位置更新操作。
- 清除短消息地址列表：清除短消息地址列表用于清除用户所有短消息相关的动态信息。

#### 注意事项

发CANCEL Location或发RESET消息，需要熟悉设备的UDM系统管理员在话务量较低的时候才进行。一般情况下，不要向所有VLR/SGSN发RESET消息。

#### 基本概念

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。

## 目录内容

- 网络维护管理
  - 发送模拟Reset消息（SND RESET）
  - 清除短消息地址列表（CLR SUBMWD）
  - 发送模拟Update Location消息（SND UPL）
  - 修改AAA动态信息（MOD AAAINFO）
  - 发送模拟Reset Update Location消息（RST UPL）
  - 校验用户数据一致性（CHK CONSY）
  - 发送模拟Cancel Location消息(SND CANCELC)
  - 发送模拟USSD Notify操作（SND FMNOTIFY）
  - 获取Reset消息数据（GET RESETDATA）
  - 指定Service Partition发送模拟Cancel Location消息（SND SPCANCEL）
