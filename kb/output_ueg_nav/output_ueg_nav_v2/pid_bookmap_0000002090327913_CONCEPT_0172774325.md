# 数据传输管理

- 功能描述
- 相关概念

#### 功能描述

提供对PGW或DMA数据的文件传输配置信息进行管理，包括增加、删除和查询PGW或DMA数据传输配置。

#### 相关概念

**FTP**

FTP（File Transfer Protocol）为文件传输协议，是一种TCP/IP协议，该协议使文件可以通过网络从一台计算机传送到另一台计算机。在FTP传输中，两台计算机必须支持它们各自的FTP角色：一台必须是FTP客户端，另一台是FTP服务器。

**SFTP**

SFTP（Secret
File Transfer Protocol）为安全文件传输协议，是一个基于SSH（Secure Shell）提供安全文件传输的网络协议。SFTP与FTP有几乎一样的语法和功能，由于SFTP使用了加/解密技术，其传输效率比普通的FTP要低得多，当客户对网络安全性要求更高时，可以使用SFTP代替FTP。

第三方SFTP服务器端（客户端）和USCDB的SFTP客户端（服务器端）的密钥加密算法必须兼容，若不兼容，则无法互相连接。

- 若第三方SFTP客户端下述算法均不支持，则无法连接USCDB的SFTP服务器端。

  - ecdh-sha2-nistp256
  - ecdh-sha2-nistp384
  - ecdh-sha2-nistp521
  - diffie-hellman-group-exchange-sha256
  - diffie-hellman-group1-sha1
  - diffie-hellman-group14-sha1
  - diffie-hellman-group-exchange-sha1
- 若第三方SFTP服务器端下述算法均不支持，则无法连接USCDB的SFTP客户端。

  - diffie-hellman-group1-sha1
  - diffie-hellman-group14-sha1
  - diffie-hellman-group-exchange-sha1

## 目录内容

- 数据传输管理
  - 远端SFTP服务器管理
    - 删除远端SFTP服务器(RMV RSFTPSERVER)
    - 查询远端SFTP服务器(LST RSFTPSERVER)
    - 添加远端SFTP服务器(ADD RSFTPSERVER)
  - SFTP路径配置管理
    - 查询SFTP配置信息(LST SFTPPATHCFG)
  - SFTP用户管理
    - 修改SFTP用户(MOD SFTPUSER)
    - 查询SFTP用户(LST SFTPUSER)
    - 删除SFTP用户(RMV SFTPUSER)
    - 添加SFTP用户(ADD SFTPUSER)
  - 定制导出配置
    - 查询定制导出配置(LST CUSEXPCFG)
    - 添加定制导出配置(ADD CUSEXPCFG)
    - 修改定制导出配置(MOD CUSEXPCFG)
    - 删除定制导出配置(RMV CUSEXPCFG)
  - FTP用户管理
    - 删除FTP用户(RMV FTPUSER)
    - 修改FTP用户(MOD FTPUSER)
    - 查询FTP用户(LST FTPUSER)
    - 添加FTP用户(ADD FTPUSER)
  - 远端FTP服务器管理
    - 查询远端FTP服务器(LST RFTPSERVER)
    - 添加远端FTP服务器(ADD RFTPSERVER)
    - 删除远端FTP服务器(RMV RFTPSERVER)
  - FTP服务器管理
    - 删除FTP服务器(RMV FTPSERVER)
    - 查询FTP服务器(LST FTPSERVER)
    - 添加FTP服务器(ADD FTPSERVER)
  - SFTP客户端本地路径配置管理
    - 查询SFTP工作目录(LST SFTPWORKDIR)
  - FTP客户端本地路径配置管理
    - 查询FTP工作目录(LST FTPWORKDIR)
  - FTP路径配置管理
    - 查询FTP配置信息(LST FTPPATHCFG)
