# PCRF对端PCEF类别管理

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

无。

#### 功能描述

PCRF对端PCEF类别管理包括对端PCEF类别配置和维护。配置包括增加、修改或删除PCRF对端PCEF类别标识、名称和会话超时后的处理方式。维护包括查询PCRF对端PCEF类别标识、名称和会话超时后的处理方式。

#### 注意事项

无。

## 目录内容

- PCRF对端PCEF类别管理
  - 修改PCRF对端PCEF类别(MOD PPCEFCAT)
  - 增加PCRF对端PCEF类别(ADD PPCEFCAT)
  - 删除PCRF对端PCEF类别(RMV PPCEFCAT)
  - 查询PCRF对端PCEF类别的配置信息(LST PPCEFCAT)
