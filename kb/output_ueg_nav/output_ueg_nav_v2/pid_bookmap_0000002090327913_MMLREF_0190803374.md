## 命令功能

GPRS（General Packet Radio Service），是为用户提供端到端的分组方式（分组交换和分组传输）的数据业务，它能有效地利用网络资源。GPRS业务具有如下的特点：

- GPRS适用于突发性的数据业务（非周期性的），突发性是指两次连续的数据传输之间的时间间隔要大于平均传输时延。
- GPRS适用于频繁传送少量数据，适用于每分钟传送几次小于500字节的短数据业务。
- 非频繁传送大量数据，GPRS也适用每小时内传送几次几千字节的长数据业务。

GPRS所能提供的业务本质上是一种数据承载业务，GPRS所能提供的其他业务，如：网络应用业务，只是在承载业务基础上所能开展的应用业务。

APN（Acess Point Name）：APN实际上就是IP地址或一个逻辑名字，在GGSN中用于表征外部数据网络。用户可以通过不同的APN选择GGSN，这就是说用户可以多次激活。用户选择不同的APN目的就是通过不同的GGSN选择外部网络，因为只有通过GGSN才能访问外部的PDN（Packet Data Network）。一个APN的例子是：huawei.com，这个APN需要通过DNS（Domain Name Server）进行解析才能获取GGSN的真实的IP地址。

PDP（Packet Data Protocol）地址：PDP地址即分组协议的地址。MS由IMSI标识，为完成分组数据功能，还应具有PDP地址，PDP地址可为：

- IP地址（IPV4地址或IPV6地址）
- x.121地址（对于X.25业务）
- OCSIHOSS
- PPP

PDP地址可以固定分配，也可以动态临时分配。固定分配时，MS必须先签约，由网络分配相应的固定地址，同时写入该用户的SIM或USIM卡和用户数据中（HDU），PDP地址类型也必须在签约时说明，否则系统对不签约的PDP地址予以拒绝。

PDP上下文：PDP Context，是PDP地址在MS和SGSN中存储的信息集。

用户每次激活SGSN、GGSN时都要创建PDP Context，在SGSN中每个MM Context可以包含多个PDP Context。PDP Context包括会话管理的一些内容：

- SGSN：PDP状态、PDP类型、PDP地址、APN（Access Point Name）、NSAPI、TI、GGSN地址、发送的N-PDU号码、接收的N-PDU号码、协商QoS模板。
- GGSN：IMSI、NSAPI、MSISDN、PDP类型、PDP地址、Dynamic地址、APN、协商QoS模板。

网络服务质量：QoS（Quality of Service），是决定业务的用户满意度的业务性能的综合效果。这些性能参数可以在用户接入的业务点直接观察和测量。性能测量有三个标准：速度、准确度和依赖性。

每一个PDP上下文都有一套服务质量参数与其关联。有以下几个参数：

- 优先等级

  此参数指明继续GPRS业务时相关的优先级。例如：当发生异常（如网络拥塞）时，优先级低的包将首先被丢弃。
- 延时等级

  表明在GPRS网络中传输SDUs时的端到端的时延的级别。

  延迟级别分为四级，级别越高，延迟时间越长。
- 可靠性等级

  指明一个应用需要的传输特性。可靠性级别定义了SDUs丢失、重复、错序或发生不可检测的错误的可能性。
- 峰值吞吐量

  描述单位时间内传递的数据位的最大值。
- 平均吞吐量

  单位时间内传递数据位的平均值。

  其中，缺省等级是由GPRS运营商决定的服务质量，HLR对此不做处理。

扩展QoS：扩展QoS是WCDMA/TD-SCDMA网络特有的参数，GSM/GPRS网络不提供此参数。

- ARPRIORITY （Allocation/Retention Priority）

  此参数表征指定承载与WCDMA/TD-SCDMA其它承载比较，相对的重要性。在对承载进行分配和保持的过程中，（系统）根据优先级别对承载进行划分。在资源不足的情况下，相关网元将根据分配/保持优先级来进行准入控制，先处理优先级高的承载，然后再处理级别低的承载。
- ERRSDU （Delivery of error SDUs）

  表征当SDUs被检测到出错时，SDUs将继续传递，还是被丢弃。
- DELIVERY（Delivery order）：表征WCDMA/TD-SCDMA是否按顺序传递SDU。
- TRAFFICCLS（Traffic Class）

  用来区分事务流对时延的敏感程度。事务级别分为4个级别。

  CONVER（conversational class）：对话级别，此级别对时延最敏感，适用于视像、电话等实时业务。

  STREAM（streaming class）：流动级别，此级别对时延比较敏感，适用于实时业务。

  INTERACT（interactive class）：互动级别，此级别对时延不敏感，误码率较低，适用于传统的INTERNET业务，如WWW、EMAIL、FTP、TELNET等。互动级别主要适用于互动的EMAIL或WEB浏览等。

  BACKGRD（background class） ：背景级别，此种级别对时延最不敏感，但误码率很低，适用于非互动型的INTERNET下载或文件下载等非实时业务。
- MAXSDUSIZE （Maximum SDU Size）：SDU的最大尺寸为多少个Octet。
- MAXBRUPL（Maximum bitrate-uplink）：单位时间内在WCDMA/TD-SCDMA的信令接入点传递的最大比特位数。单位：kbit/s。
- MAXBRDWL（Maximum bitrate-downlink）：最大下行比特率。单位：kbit/s。
- RESBER（Residual BER）：表征在SDUs传递过程中，未被发现的误码率。
- SDUERR （SDU error ratio）：SDU出错率，SDU在传递过程中，丢失或错误的比率。主要用来在UTRAN内配置协议、算法和错误检测方案。
- TRANSFERDEL（Transfer Delay）：传输延迟。
- TRAFFICPRI（Traffic Handling Priority）：事务处理的优先级。
- MAXGBRUPL（Maximum Guaranteed bitrate-Uplink）：可以保证的最大上行比特率。单位：kbit/s。
- MAXGBRDWL （Maximum Guaranteed bitrate-Downlink）：可以保证的最大下行比特率。单位：kbit/s。
