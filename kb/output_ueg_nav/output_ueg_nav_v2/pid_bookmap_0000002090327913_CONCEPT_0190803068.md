# Diameter对端类型管理

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于在UDM中设置MME/S4SGSN相对于本地UDM的MME/S4SGSN类型，即MME/S4SGSN相对于本地UDM的位置信息。

在用户发生位置更新时，UDM判断用户是通过MME还是S4SGSN发起的位置更新，然后根据系统设置的Diameter对端位置类型信息，判断Diameter对端（MME/S4SGSN）的类型，并将其记录在用户动态数据表中。根据此位置信息，UDM会定期统计并上报漫游用户数。

UDM存储了网络中所有与用户相关的数据，它在不同网络中承担不同的网元功能，通过信令消息与对端网元完成数据对接。

#### 注意事项

无。

#### 基本概念

**闭锁漫游业务**

闭锁业务ODB（Operator Determined Barring）即运营商决定的闭锁，是指用户接入GSM/UMTS/EPS网络的业务能力是由PLMN网络运营商来决定的。ODB业务可分为以下5大类：

- 闭锁出呼叫或移动始发短消息
- 闭锁入呼叫或移动终结短消息
- 闭锁漫游
- 闭锁补充业务接入
- 闭锁分组业务

闭锁漫游是指当用户漫游出HPLMN、HPLMN国家时，不允许用户漫游或者GPRS漫游。
