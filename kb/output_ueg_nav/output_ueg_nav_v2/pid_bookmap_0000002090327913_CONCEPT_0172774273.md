# 节点管理

- 功能描述
- 基本概念

#### 功能描述

节点管理用于指导操作员对Cluster内的节点进行增加、删除、查询、设置、备份等相关操作，主要在开局、扩容等场景使用。

节点管理只针对于DRU和DSU模块，USCDB将多个DRU、DSU模块以节点的形式添加到对应类型的Cluster中，从而达到提高系统的软件可靠性的目的。因此节点管理是依赖于Cluster管理和模块管理的，命令组关系如图1所示：

#### 基本概念

**Node**

Node即节点，是Cluster内提供业务的单元。正常情况下，一个Cluster有一个Master节点，其余都是Slave节点。

**Master节点**

Master节点是能够提供数据的增加、删除、修改和查询服务的节点

**Slave节点**

Slave节点是只提供数据的查询服务的节点

## 目录内容

- 节点管理
  - 查看节点的主表记录数(DSP NODECOUNT)
  - 删除节点信息(RMV NODE)
  - 查询节点加载的信息(DSP LOADINFO)
  - 查看节点状态(DSP NODE)
  - 去激活节点(DEA NODE)
  - 设置节点状态(SET NODE)
  - 重启节点(RST NODE)
  - 增加节点信息(ADD NODE)
  - 加载节点数据(LOD NODE)
  - 激活节点(ACT NODE)
  - 查询节点的配置信息(LST NODE)
  - 备份节点数据(BKP NODE)
