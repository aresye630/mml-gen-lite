# FE插件管理

- 功能描述
- 注意事项

#### 功能描述

FE插件是指由FE网元提供并安装在USCDB上的插件包。通过安装FE插件包，在USCDB的数据库中创建FE业务相关的数据表，从而使USCDB能够作为BE存储用户数据，为FE提供用户数据的增加、删除、修改和查询等服务。

在配置USCDB的模块、Cluster、节点数据之前，需要安装FE插件包。通过OM Portal，安装FE插件包到USCDB Pod上，使USCDB能为FE提供服务。FE插件的管理功能包括以下几项：

- 加载FE插件。
- 显示已经加载的FE插件。
- 查询OMU侧和主机侧的FE插件加载信息和校验结果。

FE插件和适配插件的区别在于：

- FE插件主要用于同为华为提供的FE设备和USCDB之间的适配和互通。
- 适配插件主要用于第三方业务应用和USCDB之间的适配和互通。

#### 注意事项

无。
