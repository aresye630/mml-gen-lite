# 升级补丁管理

## 目录内容

- 升级补丁管理
  - 观察期管理
    - 结束升级观察期(FIN UPGRADEWATCH)
    - 设置升级观察期(SET UPGRADEWATCH)
    - 查询升级观察期(LST UPGRADEWATCH)
  - 升级补丁参数管理
    - 查询升级补丁定时器（LST UPGPATTIMER）
    - 修改升级补丁定时器（SET UPGPATTIMER）
  - 任务管理
    - 停止升级/补丁任务(STP UPGTSK)
  - 热补丁管理
    - 删除热补丁(RMV HPATCH)
    - 查询热补丁信息(DSP HPATCH)
