# 鉴权数据管理

- 命令功能
- 注意事项

## 命令功能

在GSM网络和WCDMA/TD-SCDMA网络中，鉴权是由MS、VLR/SGSN、HLR/AuC协同工作完成，都是由MS和AuC分别计算出鉴权参数，由VLR/SGSN比较双方的计算结果，完成网络对MS合法性的验证。

WCDMA/TD-SCDMA增加了MS对网络合法性的验证功能，从而实现MS与网络双向认证。

UDM鉴权功能包括GSM鉴权和WCDMA/TD-SCDMA鉴权。

**说明** 

由于鉴权密钥KI是用户鉴权的重要数据，因此在数据操作时建议使用K2、K4、K7和私有密钥对其进行多重加密保障其安全性，这些密钥的含义如下：

- KI：用户鉴权密钥，用于对用户数据进行鉴权时使用。
- K2：存储密钥，在添加KI值时使用，用于对KI值进行加密，保证鉴权密钥KI在存储过程中的安全性。
- K4：传输密钥，在添加KI值时使用，用于对KI值进行加密，保证鉴权密钥KI在传输过程中的安全性。
- K7：在添加K2或K4密钥时使用，用来对K2或K4密钥进行加密。
- 私有密钥：在添加K7密钥时使用，用来对K7密钥进行加密。
