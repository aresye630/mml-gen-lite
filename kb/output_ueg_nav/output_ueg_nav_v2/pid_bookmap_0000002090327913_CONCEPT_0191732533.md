# 系统参数管理

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于在开局阶段对系统参数进行管理，包括设置和查询操作，通过设置这些系统参数的值可以使系统按照设置的方案实现IMS网络中HSS网元的功能，包括AKA鉴权认证，数据支持能力设置等。

#### 注意事项

无。

#### 基本概念

**别名透明数据**

别名透明数据是指被别名IMPU组中的IMPU所共享的透明数据。

**SDA鉴权**

SDA（SIP Digest）鉴权是对SIP终端用户接入IMS网络时进行认证的一种鉴权机制。对于SIP终端用户，由于没有SIM/USIM/ISIM卡，不支持IMS
AKA鉴权机制和Early IMS鉴权机制。为了支持SIP终端用户接入IMS网络，对其采用SIP Digest鉴权机制

**AKA鉴权**

AKA（Authentication and Key Agreement）鉴权是指终端用户接入IMS网络时进行认证的一种鉴权机制。

**HDA鉴权**

HDA（HTTP Digest）鉴权是对固网SIP终端用户接入IMS网络时进行认证的一种机制。对于固网SIP终端，由于没有SIM/USIM（UMTS
Subscriber Identity Module）/ISIM卡，所以不支持IMS AKA鉴权机制或者Early IMS鉴权机制。对于采用HTTP Digest鉴权的固网SIP终端用户，通过User name和Password鉴权成功后接入IMS网络。

**鉴权五元组**

- RAND：随机数，由随机数发生器产生，是网络提供给UE的不可预知的随机数，UE用它来计算XRES及IK、CK。RAND长度为16字节。
- AUTN：鉴权标记，用于提供鉴权信息给UE，使得UE可以用它来对网络进行鉴权。AUTN的长度为16字节。
- XRES：期望响应，用于与UE返回的鉴权响应消息中的SRES比较，以确定网络对UE的鉴权是否通过。XRES的长度为4～16字节。
- CK：UMTS的加密密钥。CK长度为16字节。
- IK：UMTS的完整性保护密钥。IK长度为16字节。
