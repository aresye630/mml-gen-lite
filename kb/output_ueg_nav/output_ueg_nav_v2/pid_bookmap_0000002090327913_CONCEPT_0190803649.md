# 批操作管理

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

批操作用于批量执行MML命令。该组命令用于管理批操作任务。

#### 注意事项

在执行批操作前，应预先编辑好批操作文件，批操作文件的后缀名为“txt”。

#### 基本概念

**批操作文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编辑的批操作文件到PGW Server的指定目录。

批操作文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
