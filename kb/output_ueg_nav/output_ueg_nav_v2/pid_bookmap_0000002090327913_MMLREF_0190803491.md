# 呼叫前转类补充业务

- 命令功能
- 注意事项

## 命令功能

用户的前转业务实现移动用户作被叫时，在满足一定的条件下，接通指定的号码而不是被叫号码的功能。

主叫用户：发起呼叫的用户。

前转用户：前转号码所属的用户。

被前转用户：也称被叫用户，登记前转号码的用户。

前转业务分为无条件前转和条件前转，无条件前转指CFU业务，条件前转指CFB、CFNRy、CFNRc和CFD业务。

- CFU（Call Forwarding Unconditional）

  CFU业务是指移动用户收到的所有呼叫，将被无条件前转到事先登记的另一个电话号码或语音信箱中。
- CFB（Call Forwarding On Mobile Subscriber Busy）

  CFB是指当用户忙时，允许用户将它的来话转接到预先设置的另一个电话号码上或用户的语音信箱中。

  移动用户忙分为网络决定的忙和用户决定的忙。网络决定的忙是指由网络记录的用户状态为忙，如用户正通话等；而用户决定的忙是指用户收到呼叫振铃通知，直接拒绝应答。
- CFNRy（Call Forwarding On No Reply）

  CFNRy是指被叫移动用户收到网络振铃消息后久不摘机应答，无应答设定时间到时呼叫将被前转到第三方用户。
- CFNRc（Call Forwarding On Mobile Subscriber Not Reachable）

  CFNRc是指当被叫移动用户不可及时（如：移动用户不在服务区），呼叫将被前转到第三方用户。
- CFD（Call forwarding default）

  CFD是指当基于某一种基本业务组的CFU没有激活且某一种条件前转没有激活时，呼叫将前转到CFD登记的前转号码，从而保证对用户的每一次呼叫都能接通。

## 目录内容

- 呼叫前转类补充业务
  - 修改前转业务(MOD CF)
  - 无条件呼叫前转业务
    - 修改CFU业务(MOD CFU)
    - 去登记CFU业务(ERA CFU)
    - 登记CFU业务(REG CFU)
  - 不可及前转业务
    - 去登记CFNRc业务(ERA CFNRC)
    - 修改CFNRc业务(MOD CFNRC)
    - 登记CFNRc业务(REG CFNRC)
  - 缺省呼叫前转业务
    - 激活CFD业务(ACT CFD)
    - 去激活CFD业务(DEA CFD)
    - 修改CFD业务(MOD CFD)
  - 遇忙呼叫前转业务
    - 去登记CFB业务(ERA CFB)
    - 修改CFB业务(MOD CFB)
    - 登记CFB业务(REG CFB)
  - 无应答呼叫前转业务
    - 修改CFNRy业务(MOD CFNRY)
    - 去登记CFNRy业务(ERA CFNRY)
    - 登记CFNRy业务(REG CFNRY)
  - 查询CFALL业务(LST CFALL)
