# 5G签约自动迁移PID管理

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于配置4升5迁移指令PID规则，支持多个SP（CloudDB版本或ATCA版本的HSS）演进到UDM，实现NFV HSS组网平滑演进到UDM的功能。

#### 注意事项

无。

#### 基本概念

无。

## 目录内容

- 5G签约自动迁移PID管理
  - 查询4升5迁移指令PID规则(LST SINGLEUSERMOVEPIDS)
  - 删除4升5迁移指令PID规则(RMV SINGLEUSERMOVEPIDS)
  - 增加4升5迁移指令PID规则(ADD SINGLEUSERMOVEPIDS)
