# PLMN区域漫游限制配置

- 命令功能
- 基本概念

#### 命令功能

该组命令用于管理全局的PLMN区域漫游限制业务数据。

PLMN区域漫游限制业务是指系统根据运营商、网络或用户的要求，对指定HLRSN中所有用户的移动性进行管理，限定用户允许或禁止访问其他运营商网络。通过本组命令设置全局PLMN区域漫游限制业务数据可以将用户的访问范围限制在与本运营商签约了漫游协议的其他运营商网络范围内。

#### 基本概念

无。

## 目录内容

- PLMN区域漫游限制配置
  - 设置全局PLMN区域漫游限制(MOD GLOBALPLMNRSZI)
  - 查询全局PLMN区域漫游限制(LST GLOBALPLMNRSZI)
  - 设置全局PLMN区域缺省漫游限制(SET DEFGLOBALPLMNRSZI)
