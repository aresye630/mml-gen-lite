# 无条件呼叫前转业务

- 命令功能
- 注意事项

## 命令功能

无条件呼叫前转CFU（Call Forwarding-Unconditional）允许用户将它的所有来话转接到预先设置的另一个电话号码上或用户的语音邮箱中。

一旦CFU业务被激活，则当任意用户呼叫用户A时，无论用户A处在何种状态，所有呼叫都会前转至用户B或者用户C或者某一语音邮箱。若用户A同时签约了前转提示功能，则用户A的MS上将收到一个前转提示音。
