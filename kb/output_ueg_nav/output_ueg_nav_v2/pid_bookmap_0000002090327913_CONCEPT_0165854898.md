# 软件管理

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

无。

#### 功能描述

软件管理：提供对软件系统的相关管理操作，主要包括网元管理、版本查询、补丁管理、升级控制、系统备份、驱动管理等。

#### 注意事项

无。

## 目录内容

- 软件管理
  - 工作区管理
    - 删除工作区(RMV WKSP)
    - 切换工作区(SWP WKSP)
    - 查询工作区(LST WKSP)
  - 包管理
    - 删除包(RMV PKG)
    - 加载包(LOD PKG)
    - 查询包(LST PKG)
    - 校验包(CHK PKG)
  - 版本补丁管理
    - 加载补丁(LOD PATCH)
    - 同步冷补丁(SYN CPATCH)
    - 激活补丁(ACT PATCH)
    - 确认补丁(CON PATCH)
    - 查询服务器补丁(DSP CPATCH)
    - 回退补丁(ROL PATCH)
    - 查询OMU侧补丁信息(LST PATCH)
    - 去激活补丁(DEA PATCH)
    - 删除补丁(RMV PATCH)
    - 校验冷补丁程序CRC(CHK CPATCHCRC)
    - 回退服务器补丁(ROL CPATCH)
    - 查询补丁信息(DSP PATCH)
    - 加载服务器补丁(LOD CPATCH)
  - 备份管理
    - 导出网元数据(EXP MES)
    - 更新证书吊销列表文件(UPT CRL)
    - 查询网元导出信息(LST EXPINFO)
  - 模块管理
    - 模块
      - 修改模块(MOD MODULE)
      - 倒换模块(SWP MODULE)
      - 复位指定类型的模块(RST MDUTYPE)
      - 复位模块(RST MODULE)
      - 显示模块(DSP MODULE)
      - 停止模块(STP MODULE)
      - 启动模块(STR MODULE)
      - 查询模块配置(LST MODULE)
    - 组件版本
      - 查询组件版本配置(LST COMVER)
      - 查询组件版本(DSP COMVER)
    - 模块备份管理
      - 设置备份模式(SET BAKMODE)
      - 查询备份模式(DSP BAKMODE)
    - 进程
      - 查询进程配置(LST PROCESS)
      - 查询进程(DSP PROCESS)
    - 异常系统资源
      - 查询异常系统资源(DSP ABNMSYSRES)
  - 系统参数配置
    - 回退MML配置脚本(ROL MMLCONF)
    - 查询MML配置脚本(LST MMLCONF)
    - 查询系统参数配置(LST SYSCONF)
    - 设置系统参数配置(MOD SYSCONF)
    - 加载MML配置脚本(LOD MMLCONF)
  - 性能测量管理
    - 查询性能插件(LST PMPLUG)
    - 查询性能统计任务信息（LST TRFTASK）
  - 组件管理
    - 加载组件模块(LOD COMMDU)
    - 删除组件模块(RMV COMMDU)
    - 查询组件模块信息（LST COMMDU）
  - 系统信息
    - 获取系统信息(GET SYSINFO)
  - 系统资源
    - 清理OMU磁盘空间(CLR OMUDISK)
    - 设置文件删除策略(SET FILEDELPOLICY)
    - 查询文件删除策略(LST FILEDELPOLICY)
    - 查询系统资源(DSP SYSRES)
  - CHR传输管理
    - 查询CHR传输策略(LST CHRPOLICY)
    - 查询CHR存储空间信息(DSP CHRSTORAGE)
    - 设置CHR传输策略(SET CHRPOLICY)
  - 主机时间
    - 查询时间(DSP INTIME)
  - 网元管理
    - 启动网元(STR ME)
    - 复位网元(RST ME)
    - 停止网元(STP ME)
  - 查询CM状态
    - 查询CM状态(LST CMSTS)
  - 版本信息管理
    - 版本信息的配套检查(CHK VER)
    - 查询版本信息(DSP VER)
    - 查询版本配套信息(LST VERINFO)
  - 命令统计
    - 设置跨网元命令开关(SET CMSWITCH)
