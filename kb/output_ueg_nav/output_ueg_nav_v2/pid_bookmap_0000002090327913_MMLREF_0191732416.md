# 批操作管理

- 命令功能
- 注意事项

## 命令功能

批操作用于批量执行MML命令。

在执行批操作前，应预先编辑好批操作文件，批操作文件的后缀名为“txt”。批操作文件可以通过PGW主界面上的“文件管理器”提前上传到系统中。

## 注意事项

无。

## 目录内容

- 批操作管理
  - 批处理系统命令管理
    - 中止批操作(ABT BAT)
    - 文件批操作(BAT)
    - 查询批操作(CHK BATSTAT)
  - 批处理业务命令管理
    - 批量销户(RMV HSUBBAT)
    - 批量删除IMPI的SIP Digest鉴权信息(RMV HSDABAT)
    - 批量设置紧急服务路由号码(SET HESRNBAT)
    - 批量修改共享iFC(MOD HSIFCBAT)
