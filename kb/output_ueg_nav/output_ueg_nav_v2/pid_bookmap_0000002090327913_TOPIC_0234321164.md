# RFSP管理

## 目录内容

- RFSP管理
  - 扩展RFSP策略管理
    - 修改扩展RFSP策略组成员(MOD EXTRFSP)
    - 查询扩展RFSP策略组成员(LST EXTRFSP)
    - 删除扩展RFSP策略组成员(RMV EXTRFSP)
    - 增加扩展RFSP策略组成员(ADD EXTRFSP)
  - 特征RFSP管理
    - 特征RFSP取值范围管理
      - 增加特征RFSP取值(ADD SPECRFSPVALUE)
      - 查询特征RFSP取值(LST SPECRFSPVALUE)
      - 删除特征RFSP取值(RMV SPECRFSPVALUE)
  - RFSP策略管理
    - RFSP参数配置
      - 查询RFSP配置(LST RFSP)
      - 增加RFSP配置(ADD RFSP)
      - 修改RFSP配置(MOD RFSP)
      - 删除RFSP配置(RMV RFSP)
