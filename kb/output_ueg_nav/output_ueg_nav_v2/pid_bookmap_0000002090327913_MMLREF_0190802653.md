# 缺省呼叫前转业务

- 命令功能
- 注意事项

## 命令功能

缺省呼叫前转CFD（Call forwarding default）是指当基于某一种基本业务组的CFU没有激活且某一种条件前转没有激活时，呼叫将前转到CFD登记的前转号码，从而保证对用户的每一次呼叫都能接通。

CFD是对三个条件前转业务（CFB、CFNRy、CFNRc）的补充，具体的应用如语音信箱。

## 注意事项

CFD业务可以由操作员在管理平台上进行签约、撤销、激活和去激活。在签约和撤销的过程中可以登记、去登记CFD替代的CFB、CFNRy或CFNRc前转号码。

CFD业务不能在MS上登记、去登记CFD替代的CFB、CFNRy或CFNRc前转号码。可以由MS通过USSDDAT业务码（通过**ADD USSDDAT**命令中参数“USSD类型”取值为“CFD\_MNG”来设置）来激活、去激活CFD业务。
