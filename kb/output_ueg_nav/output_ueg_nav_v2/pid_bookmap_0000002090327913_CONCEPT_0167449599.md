# PCRF对端PCEF能力字典管理

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

能力字典：表示PCRF与PCEF对端配合时所支持的能力，PCRF根据对端PCEF使用的能力字典的选择和字典项取值，提供对应的业务功能，以支持和多种功能的PCEF对端对接。

#### 功能描述

PCRF对端PCEF能力字典管理包括对端PCEF能力字典配置和维护。配置包括增加、删除对端PCEF能力字典。维护包括查询对端PCEF能力字典配置信息。

#### 注意事项

无。

## 目录内容

- PCRF对端PCEF能力字典管理
  - 增加PCRF对端PCEF能力字典(ADD PCEFABIDICT)
  - 查询PCRF对端PCEF能力字典配置信息(LST PCEFABIDICT)
  - 删除PCRF对端PCEF能力字典(RMV PCEFABIDICT)
