# 电信业务管理

- 命令功能
- 注意事项

## 命令功能

电信业务包括语音传输业务、数据业务和短消息业务。每种业务又分为不同的子业务。具体如表1所示。

| 电信业务的种类   | 各业务包含的子类              |
|:----------|:----------------------|
| 语音传输业务    | TS11：电话业务             |
| 语音传输业务    | TS12：紧急呼叫业务           |
| 数据业务      | TS61：自动语音传真交替业务       |
| 数据业务      | TS62：自动3类传真业务         |
| 短消息业务     | TS21：MT-PP，点对点短消息接收业务 |
| 短消息业务     | TS22：MO-PP，点对点短消息始发业务 |

## 注意事项

无。
