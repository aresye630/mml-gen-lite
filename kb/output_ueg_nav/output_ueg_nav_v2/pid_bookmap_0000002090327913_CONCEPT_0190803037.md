# 前转号码属性

- 命令功能

#### 命令功能

该组命令用于在呼叫前转补充业务中，设置前转号码是否通知主叫用户的属性。

#### 注意事项

无。

#### 基本概念

**呼叫前转补充业务**

呼叫前转补充业务是指系统根据运营商或用户的要求，将呼叫转接到第三方用户的业务。该业务实现移动用户作被叫时，在满足一定的条件下，接通指定的号码而不是被叫号码的功能。

前转业务分为无条件前转和条件前转，无条件前转指无条件呼叫前转业务，条件前转指遇忙呼叫前转业务、无应答呼叫前转业务、不可及前转业务和缺省呼叫前转业务。

- 无条件呼叫前转业务CFU（Call Forwarding Unconditional）

  无条件呼叫前转业务是指移动用户收到的所有呼叫，将被无条件前转到事先登记的另一个电话号码或语音信箱中。
- 遇忙呼叫前转业务CFB（Call Forwarding On Mobile Subscriber Busy）

  遇忙呼叫前转业务是指当用户忙时，允许用户将它的来话转接到预先设置的另一个电话号码上或用户的语音信箱中。用户忙有两种类型，具体含义如下：
  - 网络决定的用户忙NDUB（Network Determined User Busy）：是指由网络记录的用户状态为忙，如用户正通话等。
  - 用户决定的用户忙UDUB（User Determined User Busy）：是指用户收到呼叫振铃通知，直接拒绝应答。
- 无应答呼叫前转业务CFNRy（Call Forwarding On No Reply）

  无应答呼叫前转业务是指被叫移动用户收到网络振铃消息后久不摘机应答，无应答设定时间到时呼叫将被前转到第三方用户。
- 不可及前转业务CFNRc（Call Forwarding On Mobile Subscriber Not Reachable）

  不可及前转业务是指当被叫移动用户不可及时（如：移动用户不在服务区），呼叫将被前转到第三方用户。
- 缺省呼叫前转业务CFD（Call Forwarding Default）

  缺省呼叫前转业务是指当基于某一种基本业务组的CFU没有激活且某一种条件前转没有激活时，呼叫将前转到CFD登记的前转号码，从而保证对用户的每一次呼叫都能接通。
