# 5G用户管理

## 目录内容

- 5G用户管理
  - 取消5G融合用户的5G业务（RMV NGSSUB）
  - 5G虚拟网络组成员管理
    - 添加5G虚拟网络组成员 (ADD GROUPID)
    - 查询虚拟网络组成员所属组 (LST GROUPID)
    - 删除5G虚拟网络组成员 (RMV GROUPID)
  - 开户管理
    - 查询5G自动开户用户粒度黑白名单(LST NGCAUTOIMSI)
    - 查询5G自动开户用户粒度黑白名单数量(LST COUNTNGCAUTOIMSI)
    - 修改5G自动开户用户粒度黑白名单(MOD NGCAUTOIMSI)
