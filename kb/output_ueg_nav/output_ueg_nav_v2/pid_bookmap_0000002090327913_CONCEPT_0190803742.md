# CAMEL业务管理

- 命令功能
- 基本概念

#### 命令功能

CAMEL是在GSM/TD-SCDMA/WCDMA协议族中提出的一整套智能网解决方案。

CAMEL提供了一种机制，使得TD-SCDMA/WCDMA网络能够提供独立于服务网络的业务，运营商定义的业务能够很容易从服务网络以外实现对业务的控制。CAMEL并非提供一项新的补充业务，而应被视为一种网络特征。在具有CAMEL特征的移动网络上，网络运营商能够提供网络运营商自定义业务，甚至当用户漫游出归属网络后仍然能够提供这项业务。

CAMEL的发展经历了四个阶段：

CAMEL phase 1、CAMEL phase 2、CAMEL phase 3和CAMEL phase 4。

在CAMEL发展的四个阶段，CAMEL特性的应用范围不同。

CAMEL phase 1：CAMEL特性应用于与移动始发和移动终结的呼叫相关的业务。

CAMEL phase 2：CAMEL特性应用于与补充业务调用相关的业务。

CAMEL Phase 3：CAMEL特性应用于始发短消息业务（SMS MO）、GPRS会话和PDP上下文、HLR用户数据的控制和网络信令负荷。

CAMEL phase 4：CAMEL特性应用于终结短消息业务（SMS MT）。

支持CAMEL phase 4的VPLMN（Visited PLMN）网络和网络实体同时支持CAMEL phase 3、CAMEL phase 2和CAMEL phase 1。

在移动智能网中，智能业务的触发根据用户数据中的CSI（CAMEL Subscription Information）数据或MSC中的N-CSI（Network CAMEL Subscription Information）进行。CAMEL签约信息包括O-CSI、D-CSI、T-CSI、VT-CSI、M-CSI、MOSMS-CSI、MTSMS-CSI、SS-CSI、TIF-CSI、IM-O-CSI、IM-VT-CSI等，用户可以根据需要选择其中的一种或几种。

#### 基本概念

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
