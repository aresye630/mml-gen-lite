# MM流程管理

- MM流程管理

  - 5G N26接口原因值映射配置
    - 查询5G N26接口原因值映射配置（LST NGN26CAUSEMAP）
    - 删除5G N26接口原因值映射配置（RMV NGN26CAUSEMAP）
    - 增加5G N26接口原因值映射配置（ADD NGN26CAUSEMAP）
  - 5G移动性管理流程控制参数
    - 设置5G移动性管理流程控制参数（SET NGMMPROCTRL）
    - 查询5G移动性管理流程控制参数（LST NGMMPROCTRL）
