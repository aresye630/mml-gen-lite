# 报表服务器管理

## 目录内容

- 报表服务器管理
  - 报表服务器地址
    - 显示报表服务器接入点配置（LST RPTSVRADDR）
    - 查询报表服务器状态（DSP RPTSVRSTATUS）
    - 删除报表服务器接入点配置（RMV RPTSVRADDR）
    - 修改报表服务器接入点配置（MOD RPTSVRADDR）
    - 添加报表服务器接入点配置（ADD RPTSVRADDR）
  - 报表服务器
    - 显示报表服务器（LST RPTSVR）
    - 删除报表服务器（RMV RPTSVR）
    - 修改报表服务器（MOD RPTSVR）
    - 配置报表服务器（ADD RPTSVR）
