# 多IMSI业务管理

- 功能描述
- 基本概念

#### 功能描述

该组命令用于管理用户的多IMSI业务数据。

为了使用户的通信更顺畅、行动更自由，UDM提供了多IMSI业务，即用户可以签约一个MSISDN号码和多个IMSI号码（一号多卡业务），或用户可以同时签约多个IMSI和多个MSISDN号码（多卡多号业务）。

#### 基本概念

**多卡多号批操作文件格式**

文件包含IMSI号码和MSISDN号码，每个IMSI号码与其对应的MSISDN号码组成一行。

```
IMSI1 MSISDN1
IMSI2 MSISDN2
……
IMSIn MSISDNn
```

每行的IMSI、MSISDN之间由一个空格分隔，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**IMSIFILE文件格式**

IMSI文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字组成的字符串，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

MSISDN文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字组成的字符串，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。

**一号多卡**

一号多卡业务（又称多IMSI业务或者MIMSI业务）指一个MSISDN号码对应多个IMSI号码的业务，即多个MS可以使用不同的（U）SIM卡而共用一个MSISDN号码。每张卡都是一张独立的（U）SIM，可以拥有自己独立的鉴权数据和独立的动态数据。当这些MS作为主叫时，其业务流程与普通的主叫业务流程一样。当这些MS作为被叫时，其业务流程分为主辅卡、顺振、同振和平等卡四种流程。华为UDM支持一个MSISDN最多对应9个IMSI。

**多卡多号**

多卡多号业务是指用户可以同时签约多个IMSI和多个MSISDN号码。当一个本国用户频繁跨国旅行时，可以给该用户签约各个国家的本地IMSI号码（在SIM/USIM卡中烧入其他有漫游许可的运营商IMSI号码）。当跨国漫游时，用户可以使用该国本地IMSI号码接入网络（SIM/USIM卡自动选择本地IMSI号码），且按照当地费率进行通信计费，可以节省漫游费用。同时，可以给该用户不同国家的IMSI号码绑定相应的MSISDN号码，跨国漫游时激活本地IMSI号码绑定的MSISDN号码作为主叫MSISDN号码。
