# 模块管理

#### 术语解释

**模块号**

增加模块时由用户指定或分配给模块的编号。同一网元下模块的模块号是唯一的。其中PMU模块的模块号由系统根据模块所在Pod的位置，自动分配。

**平台模块**

平台模块是指部署在业务Pod上的PMU模块，主要完成业务网元的进程监控、主备仲裁等功能。

- **PMU模块**

  管理系统可靠性的进程，主要负责应用层业务进程高可靠性HA（High Availability）仲裁，并协助完成应用层业务进程初始部署，并担任应用进程与后台管理模块间各种通信的桥梁。
- **仲裁PMU模块**

  具有仲裁功能的PMU进程。系统内部选举出仲裁PMU，由其完成应用层业务进程健康检测，并根据业务进程心跳和业务关键资源触发主备进程仲裁倒换。

**业务模块**

业务模块部署在业务Pod上，完成网元的业务功能。

#### 功能描述

用于提供模块管理相关的命令。用户可以对平台模块和业务模块执行维护操作相关的命令，如查询系统中各个网元配置的模块以及模块的工作状态、模块的备份状态和设置模块的备份开关、复位模块等。

#### 注意事项

请注意该组命令应由专业维护人员小心使用。

- 模块管理

    - 显示模块(DSP MODULE)

    - 启动模块(STR MODULE)

    - 查询组件版本配置(LST COMVER)
    - 查询组件版本(DSP COMVER)
  - 模块备份管理
    - 设置备份模式(SET BAKMODE)
    - 查询备份模式(DSP BAKMODE)
  - 进程
    - 查询进程配置(LST PROCESS)
    - 查询进程(DSP PROCESS)
  - 异常系统资源
    - 查询异常系统资源(DSP ABNMSYSRES)
