# MSISDN与云分区数据配置

- 命令功能
- 注意事项

## 命令功能

在云部署场景下，操作员通过该组命令可以增加、删除、查询MSISDN号段与云分区的映射关系。

在云部署场景下，用户按照号段存储在不同的云分区上。云分区为云部署环境中的数据存贮单元，每个云分区由一套独立的主用/容灾BE构成，有一个唯一的编号。

一个MSISDN号段只能对应一个云分区；一个云分区可以有多个与其对应的MSISDN号段。

无。
