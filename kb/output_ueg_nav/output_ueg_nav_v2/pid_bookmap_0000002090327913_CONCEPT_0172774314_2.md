# 信息收集

- 功能描述

- 配置原则

#### 功能描述

此组命令用于维护和故障处理场景下收集节点信息，便于故障定位。

#### 相关概念

**心跳消息管理**

当节点收到其他节点的心跳消息后，会用消息中携带的信息更新节点信息表。节点管理模块会定时去检查节点信息表，查看是否有节点心跳超时。当发现心跳超时，就检查节点信息表中该节点是否已被删除。如果没有删除，则表明两个节点之间通讯异常，将该节点的状态置为异常后发送节点心跳超时告警。

**全局数据**

全局数据是和整个系统相关的数据，包括业务处理用到的模板数据、操作员数据等。全局数据保存在DRU（Data Routing Unit）模块的内存数据库中。

**Redo日志文件**

在内存库数据导出过程中或导出后，发生的业务更新会记录到Redo日志文件中。

**全量导出备份文件**

通过自动备份或手工备份方式生成，将节点内存中的数据全部导出并保存到虚拟机硬盘（裸机硬盘）。

**FDB文件**

内存库数据文件，包括增量Redo日志文件和全量导出备份文件。

#### 注意事项

无。

#### 配置原则

本命令组无特殊配置原则。
