# Gb接口管理

## 目录内容

- Gb接口管理
  - MS上下文管理
    - 基于NSE的MS上下文管理
      - 删除NSE列表下的用户(RMV NSEUSR)
      - 删除NSE列表(RMV NSELST)
      - 显示删除NSE列表下的用户任务运行状态(DSP NSEUSR)
      - 增加NSE列表(ADD NSELST)
      - 查询NSE列表(LST NSELST)
  - 信令实体管理
    - 增加信令实体(ADD NSE)
    - 删除所有信令实体（RMV NSEALL）
  - Gb接口寻呼数据
    - 查询Gb接口寻呼数据(LST GBPAGING)
