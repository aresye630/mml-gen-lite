# 费率切换

## 目录内容

- 费率切换
  - 工作日
    - 删除计费星期表（RMV WEEKDAY）
    - 查询计费星期表（LST WEEKDAY）
    - 修改计费星期表（MOD WEEKDAY）
    - 配置计费星期表（ADD WEEKDAY）
  - 费率切换组
    - 配置费率切换组（ADD TARIFFGROUP）
    - 查询费率切换组（LST TARIFFGROUP）
    - 删除费率切换组（RMV TARIFFGROUP）
  - 节假日
    - 删除计费节假日表（RMV FESTIVAL）
    - 增加计费节假日表（ADD FESTIVAL）
    - 查询计费节假日表（LST FESTIVAL）
  - 全局费率切换组
    - 查询全局费率切换组（LST GLBTARIFFGROUP）
    - 配置全局费率切换组（SET GLBTARIFFGROUP）
