# APN运营商标识符模板

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于对GPRS业务中的APNOI（APN Operator ID）模板信息进行增加、删除、修改和查询操作。

UDM以APNOI模板的方式对APNOI数据进行管理，加强了对GPRS数据管理的灵活性，操作员签约APNOI数据时，只需要签约APNOI模板即可，然后通过该模板对其数据进行管理。

#### 注意事项

无。

#### 基本概念

APN运营商标识符（APNOI）：用于标识GPRS业务接入点归属网络，通过此标识符，用户可以选择接入的运营商网络。

## 目录内容

- APN运营商标识符模板
  - 修改APN运营商标识符模板(MOD APNOITPL)
  - 删除APN运营商标识符模板(RMV APNOITPL)
  - 增加APN运营商标识符模板(ADD APNOITPL)
  - 查询APN运营商标识符模板(LST APNOITPL)
