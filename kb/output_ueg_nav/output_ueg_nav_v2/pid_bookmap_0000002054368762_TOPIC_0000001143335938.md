# 配置VNF侧IP路由数据（NP卡）

NP卡直连DC-GW/PE场景，不支持自动部署，须通过手动部署进行配置。

UEG部署在带NP卡服务器上时，只需要两块刀片的NP卡接口出线与DC-GW/PE互连，用于传输业务报文。

- 4块刀片时：从下往上数，第3块和第4块刀片出线。
- 3块刀片时：从下往上数，第2块和第3块刀片出线。

用于传输业务报文的外联口与接口位置的对应关系如图1和表1所示。

**图1** NP卡接口（1~8位置）

|   接口位置 | 外联口名称      |
|-------:|:-----------|
|      1 | 100GEX/0/9 |
|      2 | 100GEX/0/8 |
|      3 | 100GEX/0/7 |
|      4 | 100GEX/0/6 |
|      5 | 25GEX/0/11 |
|      6 | 25GEX/0/10 |
|      7 | 25GEX/0/13 |
|      8 | 25GEX/0/12 |

**说明** 

*X*=**63**+*Y*，*“Y”*表示从下往上数第几块刀片。例如，第3块刀片上的外联口名称中，Y=3。
