# 计费地址管理

- 命令功能
- 注意事项

## 命令功能

该特性用于设置和查询计费地址。HSS可以为IMPI或PISI的每种计费网元保存两个地址，即“主”地址和“备”地址。

IMS支持如下计费地址管理功能：

- 在线计费

  在线计费是计费信息实时影响业务提供的一种计费机制，和网络资源使用的控制直接交互。根据用户帐户上的余额决定允许或拒绝会话；在会话过程中进行实时计费并从用户帐户上扣除费用；在用户帐户余额不足时终止会话，如预付费业务就是应用了在线计费功能。

  计费系统在用户进行会话之前：
  - 检查用户帐户。
  - 根据用户帐户上的余额决定允许或拒绝会话。

  计费系统在用户进行会话过程中:

  - 进行实时计费并从用户帐户上扣除费用。
  - 在用户帐户余额不足时终止会话。

  如预付费业务就是应用了在线计费功能。
- 离线计费

  离线计费是计费信息不实时影响业务提供的一种计费机制。用户使用网络资源一段时间内的计费信息被计费系统收集起来，运营商在这段时间结束时将话单寄给用户进行缴费。

在IMS-HSS中，IMPI的计费地址是通过计费地址ID来配置的。计费地址ID在OM Portal上配置，每个计费地址ID对应一个计费网元。

计费网元分为在线计费网元和离线计费网元，计费网元上存储主计费地址和备计费地址。
