# RCS业务数据管理

- 命令功能
- 注意事项

## 命令功能

该特性提供RCS（Rich Communication Suite）业务数据的增加、删除、修改和查询操作。

RCS是指一组业务的集合，具体包括：语音通话、视频通话、IM类业务（Message（通知消息）、状态呈现、地址本同步文件共享、即时通信）、共享类业务（图片共享、视频共享）。

## 注意事项

无。

## 目录内容

- RCS业务数据管理
  - 查询RCS业务(LST HRCSSERVICE)
  - 修改RCS业务状态(MOD HRCSSTATUS)
  - 增加RCS业务(ADD HRCSSERVICE)
  - 删除RCS业务(RMV HRCSSERVICE)
