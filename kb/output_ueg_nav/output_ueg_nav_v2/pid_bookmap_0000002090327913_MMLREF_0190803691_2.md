# 模板管理

- 命令功能
- 注意事项

## 命令功能

模板管理用于设置各种模板，包括：开户模板、OFA模板、LCS模板、CSI模板、GPRS模板、漫游限制模板，方便开户和设置各项业务。

## 注意事项

批量操作模板数据，请避免在业务高峰时使用。
