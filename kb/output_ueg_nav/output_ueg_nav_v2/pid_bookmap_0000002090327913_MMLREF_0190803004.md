# 防欺诈模板

- 命令功能
- 注意事项

## 命令功能

HLR和MSC配合实现防欺诈。对于可疑用户，限制其下列活动：

- 始发呼叫最大时长。
- 前转呼叫最大时长。
- 在一个时间周期内手机侧登记前转的最大次数。

HLR上定义防欺诈模板。运营商可以对可疑用户签约防欺诈模板。HLR在UPL/ISD/RST/DSD/SRI响应时将防欺诈数据插入VLR或者从VLR中删除，同时控制周期内手机最大登记前转次数。MSC控制始发呼叫和前转呼叫最大时长。
