# ETCSI限制模板管理

- 命令功能
- 基本概念

#### 命令功能

该组命令用于管理ETCSI限制模板。通过该组命令实现ETCSI限制模板的增加、修改、删除、查询的功能。

在UDM上通过**ADD VLRTYP**命令对VLR关联ETCSI限制模板，UDM在SRI消息处理中通过ETCSI限制模板中的配置数据，判断是否限制下发ETCSI业务给GMSC。

#### 基本概念

**ETCSI**

ETCSI即增强TCSI（Terminating CAMEL Subscription Information）业务，通过该业务GMSC将可以实现呼叫路由其他网络节点进行呼叫判断。

T-CSI是被叫CAMEL签约信息，在移动用户做被叫的SRI流程，T-CSI数据由HLR传递给GMSC，T-CSI智能业务将被触发。

**业务键**

业务键是HLR与SCP的对接参数之一，用于在CAP/INAP消息中唯一标识一种智能业务，gsmSCF用它来识别需要采用的业务逻辑。

业务键是一种号码资源，需要由运营商向本国的电信主管部门申请获得。
