# 应用优先级管理

#### 功能描述

此组命令用于对与USCDB网元对接的多个第三方FE的应用优先级进行设置、查询操作。在系统启动流控时，为了最大限度的保障重要业务的正常进行，运营商根据自身情况对各FE设定对应的应用优先级。USCDB可以将已对接的第三方FE划分成四个等级：低、中、高、最高，优先级越高消息处理的成功率越高。

#### 相关概念

**第三方FE**

第三方FE是专指通过LDAP（Lightweight Directory Access Protocol）接口，经由CAG（Convergence Access Gateway）模块访问USCDB数据的FE设备。

#### 注意事项

本命令组仅适用于由其他厂商提供的通过CAG模块接入的第三方FE。

#### 配置原则

本命令组无特殊配置原则。
