# 短消息转发平台地址管理

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于设置SMS Forwarding业务的短消息转发平台地址信息。

#### 注意事项

无。

#### 基本概念

**SMS Forwarding业务**

SMS Forwarding业务流程中，UDM处理SRI-for-SM消息时，直接通过响应消息返回**ADD SMFWDPLT**命令配置的短消息转发平台地址。

## 目录内容

- 短消息转发平台地址管理
  - 删除短消息转发平台地址(RMV SMFWDPLT)
  - 修改短消息转发平台地址(MOD SMFWDPLT)
  - 增加短消息转发平台地址(ADD SMFWDPLT)
  - 查询短消息转发平台地址(LST SMFWDPLT)
