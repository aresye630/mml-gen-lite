# Sy/N28结果码映射管理

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

无。

#### 功能描述

用于配置Sy/N28结果码映射，包括增加、修改、删除和查询Sy/N28结果码映射。

- 此命令可以管理Sy接口结果码与Gx接口结果码或原因码的映射关系，从而实现基于Sy结果码控制Gx会话响应的目的。
- 此命令可以管理N28接口结果码与Gx接口结果码或原因码的映射关系，从而实现基于N28结果码控制Gx会话响应的目的。
- 此命令可以管理N28接口结果码与N7接口结果码或原因码的映射关系，从而实现基于N28结果码控制N7会话响应的目的。

#### 注意事项

无。

## 目录内容

- Sy/N28结果码映射管理
  - 修改Sy/N28结果码映射（MOD SYTOGXRCMAP）
  - 查询Sy/N28结果码映射（LST SYTOGXRCMAP）
  - 删除Sy/N28结果码映射（RMV SYTOGXRCMAP）
  - 添加Sy/N28结果码映射（ADD SYTOGXRCMAP）
