# PCRF对端AF管理

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

无。

#### 功能描述

PCRF对端AF管理包括对端AF配置和维护。配置包括增加、修改或删除对端AF设备ID、名称、域名称、主机名、链路选择方式、业务绑定方式、业务保活时长、审计开关和设备间审计时长。维护包括查询对端AF配置信息。

#### 注意事项

无。

## 目录内容

- PCRF对端AF管理
  - 增加PCRF对端AF实体(ADD PAF)
  - 查询PCRF对端AF实体配置信息(LST PAF)
  - 修改PCRF对端AF实体信息(MOD PAF)
  - 删除PCRF对端AF实体(RMV PAF)
