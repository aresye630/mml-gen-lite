# 强制允许SK列表管理

- 命令功能
- 基本概念

#### 命令功能

该组命令用于对需要强制允许的SK列表进行配置和查询。

#### 基本概念

**TCSI**

T-CSI是被叫CAMEL签约信息，在移动用户做被叫的SRI流程，T-CSI数据由HLR传递给GMSC，T-CSI智能业务将被触发。TCSI业务下发流程如图1所示。

**图1** TCSI业务下发流程

**ETCSI**

ETCSI即增强TCSI业务，通过该业务GMSC将可以实现呼叫路由其他网络节点进行呼叫判断。ETCSI业务下发流程如图2所示。

**图2** ETCSI业务下发流程

**SK**

业务键是HLR与SCP的对接参数之一，用于在CAP/INAP消息中唯一标识一种智能业务，gsmSCF用它来识别需要采用的业务逻辑。

业务键是一种号码资源，需要由运营商向本国的电信主管部门申请获得。
