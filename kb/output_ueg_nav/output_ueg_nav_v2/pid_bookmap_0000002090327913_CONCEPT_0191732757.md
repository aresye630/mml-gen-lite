# MVNO用户号段管理

- 命令功能
- 基本概念

#### 命令功能

该组命令用于对MVNO（Mobile Virtual Network
Operator）用户号段进行管理，通过该组命令可以添加、删除或查询IMS用户标识的号段前缀信息，对IMPI或IMPU号段进行管理。

#### 基本概念

**IMPI**

IMPI（IP Multimedia
Private Identity）即多媒体私有标识。IMPI是一个由归属网络运营商定义的具有全球唯一性的身份标识，用于在归属网络中从网络的角度唯一地标识用户的签约关系。

通常IMPI格式为：用户名＋“@”＋域名，如“username@huawei.com”。VoLTE用户的IMPI格式为：IMSI@域名，如“40000055555@huawei.com”。

**IMPU**

IMPU（IP Multimedia Public Identity）即用户公有标识，是用户对外可寻址的标识，用于请求和其他用户通信，其命名在全局唯一。

IMPU采用SIP URI（Session Initiation Protocol Uniform Resource Identifier）或TEL
URI格式。

- SIP URI格式：“sip:”+用户信息+“@”+主机，如“sip:user@huawei.com”。用户信息部分，可由用户名和密码组成，密码可选。主机部分可以是一个完整的域名，也可以是一个IPv4或IPv6的地址。
- TEL URI格式：“tel:”+号码，如“tel:+865551234567”。号码有两种格式，国际号码格式和本地号码格式。国际号码格式的TEL
  URI必须在号码前加符号“+”，如“tel:+36120012345678”；本地号码格式的TEL URI需要带参数phone-context表明其所在的区域，如“tel:12345678;phone-context:+361200”。

**超级管理员帐户**

PGW Web LMT默认的超级管理员帐户为admin，具有PGW
Web LMT最高的操作权限，主要包括以下权限：

- 创建其他帐户并授予其他帐户操作权限。
- 能够执行PGW Web LMT提供的全部命令操作。
- 该帐户不能删除，帐户信息只有自身才能修改，其他帐户不能修改。

系统安装完后PGW Web LMT默认存在该帐户。在开局过程中，允许使用该帐户进行操作和配置；该帐户具有最高的操作权限，开局结束后，为了安全起见，请使用普通帐号对系统进行操作和维护。

**简单模式**

简单模式是PGW的一种应用模式，指整个系统只允许存在一个“系统序列号”，处于简单模式下的系统不支持业务层容灾功能。

**完整模式**

完整模式是PGW的另一种应用模式，指整个系统允许存在多个“系统序列号”，处于完整模式下的系统支持业务层容灾功能。
