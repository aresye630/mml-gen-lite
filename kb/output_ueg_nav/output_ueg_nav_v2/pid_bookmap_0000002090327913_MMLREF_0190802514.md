# 显式呼叫转移业务

- 命令功能
- 注意事项

## 命令功能

ECT（Explicit Call Transfer）业务允许被服务用户（用户A）在拥有两个呼叫（A-B呼叫和A-C呼叫）时，将两个呼叫连接成两个呼叫对方之间的呼叫（B-C呼叫）而自身退出服务。

A-B呼叫和A-C呼叫可以是入呼叫，也可以是出呼叫。在前转前，A-B呼叫必须已经建立，A-C呼叫可以是已经建立的状态，也可以是用户C处于振铃状态。

## 注意事项

被服务用户（Served Mobile Subscriber）是指调用ECT操作的移动用户。
