#### 命令功能

该组命令用于设置MAP业务参数或查询MAP业务参数的设置情况。

#### 注意事项

无。

#### 基本概念

**呼叫前转业务**

呼叫前转业务是指系统根据运营商、网络或用户的要求，将呼叫转接到第三方用户的业务。这里第三方用户可以是PLMN、PSTN、ISDN等网络的任意用户，也可以是语音邮箱等服务台。具体包括以下4类：

- 无条件呼叫前转业务（CFU）

  当移动用户作被叫时，不管被叫用户的终端处于何种状态，所有呼叫都将被前转到第三方用户。
- 遇忙呼叫前转业务（CFB）

  当用户忙时，允许用户将来话转接到预先设置的另一个电话号码上或用户的语音信箱中。
- 无应答呼叫前转业务（CFNRy）

  被叫移动用户收到网络振铃消息后长时间不摘机应答，无应答时长定时器超时，呼叫将被前转到第三方用户。
- 不可及呼叫前转业务（CFNRc）

  当网络与移动用户的无线信道连接中断的情况下，移动用户作被叫时，呼叫将被前转到第三方用户。不可及条件包括：寻呼无响应、无线信道指配失败、用户关机等。

**前转号码格式说明**

正确的前转号码格式有以下几种：

- 号码属性为国内号码格式
  - 移动号码（如：13700000001）
  - 本地固话号码（如：28421111）
  - 国内长途前缀 + 区号 + 本地固话号码（如：0 755 28421111）
  - 国内长途前缀 + 区号 + 移动号码（如：0 755 13700000001）
- 号码属性为国际号码格式
  - 国家码 + 移动号码（如：86 13700000001）
  - 国际号码前缀 + 国家码 + 移动号码（如：00 86 13700000001）
  - 国家码 + 区号 + 本地固话号码（如：86 755 28421111）
  - 国际号码前缀 + 国家码 + 区号 + 本地固话号码（如：00 86 755 28421111）

**非结构化补充业务数据**

非结构化补充业务数据USSD（Unstructured Supplementary Service Data）指用户通过移动终端输入符合USSD格式的非标准的补充业务操作命令，移动终端向网络发起特定的业务请求，或者由网络侧向移动终端发起USSD格式的命令以完成某种特定的业务。USSD业务具有交互性高、时延小、服务扩展性强等特点，能够提供移动网98%以上的扩展数据业务，主要包括3大类：

- 获取公共信息

  常见的应用有：查询火车、飞机、轮船等航班情况；查询金融、股票信息；查询外汇交易信息；获取体育比赛结果；查询影院等订票信息；查询银行账务信息；获取彩票业务信息；查询天气情况。
- 移动银行等电子商务

  常见的应用有：购买彩票、交纳水电费、订票、股票、外汇交易等。
- 与智能业务结合

  常见的应用有：UCB（USSD Call Back）业务。

**短消息业务**

短消息业务SMS（Short Message Service）是电信业务的一种，它允许用户通过短消息中心SMC（Short Message Center）发送和接收少量的字符信息，如文字、图片以及声音。短消息业务包括2类：

- 短消息终结业务

  短消息终结业务是指从SMC把短消息发送到移动用户，移动用户向SMC返回一个关于短消息发送成功或者失败的报告的过程。
- 短消息始发业务

  短消息始发业务是指MS通过SMC把短消息转发到目的用户，并且SMC向MS返回短消息发送成功或者失败的报告的过程。

**VP双号业务**

VP双号业务，即话音/可视双号码业务。通过该业务，用户可以分别为话音电话业务和可视电话业务设置不同的号码，针对不同的呼叫类型，开通来电显示业务的被叫用户的来电将显示不同的号码。如用户发起话音呼叫，被叫终端将显示该用户的话音电话业务号码；如用户发起视频呼叫，被叫终端将显示该用户的可视电话业务号码。

如果用户签约了VP双号业务，则该用户同时拥有2个MSISDN号码：

- 基本的MSISDN号码
- VP双号业务的MSISDN号码

**呼叫闭锁业务**

呼叫闭锁业务分为呼出闭锁BO（Barring of Outgoing Calls）和呼入闭锁BI（Barring of Incoming Calls）两大类。

BO业务包括：

- 闭锁所有出呼叫业务BAOC（Barring of All Outgoing Calls）：该业务激活后，用户将不能进行除紧急呼叫以外的所有呼叫。
- 闭锁所有国际出呼叫业务BOIC（Barring of All Outgoing International Calls）：该业务激活后，移动用户无法呼叫该用户当前所在国以外国家的用户，被叫用户可以是移动用户，也可以是固定用户。
- 闭锁所有除归属PLMN国家外的国际出呼叫业务BOIC-exHC（Barring of Outgoing International Calls except those directed to the Home PLMN Country）：该业务激活后，当移动用户在归属PLMN国家漫游时，作为主叫不能呼叫国外用户；当移动用户漫游出归属PLMN国家时，作为主叫只能呼叫归属国和当前所在国的用户，被叫用户可以是移动用户，也可以是固定用户。

BI业务包括：

- 闭锁所有入呼叫业务BAIC（Barring of All Incoming Calls）：该业务激活后，用户将不能接收所有入呼叫。
- 当漫游出归属PLMN国家时闭锁所有入呼叫业务BIC-ROAM（Barring of Incoming Calls When Roaming Outside Home PLMN Country）：该业务激活后，移动用户漫游出归属PLMN国家时无法接收呼叫。

**NCC模板**

NCC即网络能力配置，是指运营商根据VLR或SGSN实际所支持的业务和MAP版本，对HLR进行设置，使HLR能根据VLR或SGSN实际所支持的业务和MAP版本，进行相关业务与相关MAP流程的处理，提高HLR与VLR/SGSN的兼容性。

NCC模板用于设置VLR或SGSN所支持的业务和MAP版本。使用**ADD NCCTPL**命令预先设置NCC模板，在进行业务和MAP流程的处理时，HLR根据NCC模板中配置的相应业务和MAP版本的支持能力进行处理。例如，NCC模板中的参数“Cancel location中的私有信元”设置为“NR”，那么在HLR上对指定的VLR添加该NCC模板后，HLR在下发业务数据时，Cancel Location消息中的私有信元不下发到该VLR。

**Cancel Location消息**

HSS/HLR通过向VLR/SGSN发送Cancel Location消息，可以删除HSS/HLR中指定用户在相应VLR/SGSN中的用户信息。

以下情况，HSS/HLR会向VLR/SGSN发送Cancel Location消息：

- 在用户的位置更新过程中，HSS/HLR在新的VLR/SGSN中成功插入用户数据后，会自动向原VLR/SGSN发送Cancel Location消息，原VLR/SGSN收到此消息后，会将该用户的数据删除。
- 在PGW Web LMT上，执行**SND CANCELC**命令，向指定VLR/SGSN发送Cancel Location消息。
- 用户补卡和销户时，HSS/HLR会自动向用户所在的VLR/SGSN发送Cancel Location消息，VLR/SGSN收到此消息后删除原来的用户数据。
- 用户漫游到一个VLR/SGSN时，如果该用户签约该VLR/SGSN的漫游限制业务，HSS/HLR会自动向该用户当前所在的VLR/SGSN发送Cancel Location消息，使该用户不能在该区域漫游。

**定制CAMEL功能**

定制CAMEL功能用于HSS/HLR实现用户在位置更新流程和被叫取路由流程中，对基于网络级和用户级的O-CSI/T-CSI数据的下发进行控制处理。HSS/HLR根据以下条件对O-CSI/T-CSI数据的下发进行控制处理：

- 用户当前所在的VLR/SGSN和GMSC是否是归属网。
- 用户当前所在的VLR/SGSN和GMSC是否有CAMEL漫游协议和CAMEL查询协议。
- 用户当前所在的VLR/SGSN和GMSC是否支持CAMEL。

**说明** 

- CAMEL漫游协议：CAMEL roaming agreement，即HSS/HLR配置的用于约束用户漫游时如何控制O-CSI/T-CSI数据下发的协议规则。
- CAMEL查询协议：CAMEL interrogation agreement，即HSS/HLR配置的用于约束查询路由时如何控制O-CSI/T-CSI数据下发的协议规则。

**鉴权五元组**

- RAND：由随机数发生器产生，是网络提供给UE的不可预知的随机数，UE用它来计算XRES及IK、CK。RAND长度为16字节。
- AUTN：用于提供鉴权信息给UE，使得UE可以用它来对网络进行鉴权。AUTN的长度为16字节。
- XRES：用于与UE返回的鉴权响应消息中的SRES比较，以确定网络对UE的鉴权是否通过。XRES的长度为4～16字节。
- CK：UMTS的加密密钥。CK长度为16字节。
- IK：UMTS的完整性保护密钥。IK长度为16字节。

**CAMEL发展阶段**

CAMEL的发展经历了CAMEL phase 1、CAMEL phase 2、CAMEL phase 3和CAMEL phase 4四个阶段，每个阶段提供一定的功能集，在相应的功能集中可以提供相应的业务。在CAMEL发展的四个阶段，CAMEL特性的应用如下：

- CAMEL phase 1：CAMEL特性应用于与移动始发和移动终结的呼叫相关的业务。
- CAMEL phase 2：CAMEL特性应用于与补充业务调用相关的业务，同时是CAMEL phase 1的增强。
- CAMEL Phase 3：CAMEL特性应用于始发短消息业务（SMS MO）、GPRS会话、PDP上下文、HSS/HLR用户数据的控制和网络信令负荷，同时是CAMEL phase 2的增强。
- CAMEL Phase 4：CAMEL特性应用于终结短消息业务（SMS MT）、呼叫路由优化、IP多媒体子系统控制，同时是CAMEL phase 3的增强。

**FM业务**

FM（Follow Me）业务是功能号码寻址业务，功能号码用于表示一个工作岗位而不是一个真实的用户。当前在岗人员通过将MSISDN号码登记到功能号码上，建立起功能号码和真实用户之间的联系。调度台通过呼叫功能号码对当前在岗的真实用户进行调度和指挥。当岗位人员轮换时，真实用户的MSISDN号码发生变化，但岗位的功能号码不变，可以通过拨打该功能号码呼叫岗位目前的在岗人员。

**DIC业务**

用户平时所呼叫的对象一般都可以分为几大类，比如家人，同事，同学等。用户想知道他最近一段时间对每一类（或者某一类）对象呼叫所花的费用，为了满足这个需求而引入了DIC（Dial Identification Code）业务。签约了DIC业务的用户在进行呼叫时，在拨号数字中可以携带DIC码，拨打的号码为“被叫号码+#+DIC码”，用于区分对不同用户的呼叫，于是MSC出的话单中就可以显示对每一类（或者某一类）对象呼叫所消耗的费用。

**多IMSI业务**

多IMSI业务是指一个MSISDN号码可以支持多张不同的SIM/USIM卡，即一个MSISDN号码对应多个IMSI号码。

UDM的多IMSI业务有如下特性：

- 一个MSISDN号码最多可以支持9张不同的SIM/USIM卡。
- 每张卡都拥有独立的鉴权数据和动态数据，所有的卡具有同样的业务签约数据。
- 每张卡都可以做主叫和被叫。
- 只有一张卡可以接收短消息。

**CUG业务**

CUG（Closed User Group）业务，即闭合用户群业务。该业务是一种补充业务，用户可以连接到PLMN和其他网络来建立一个CUG闭合用户群，出入该用户群的呼叫会受到限制。一个用户可以成为一个或多个CUG的成员，可以设定CUG的成员与群内的用户通信还是与群外的用户通信。

用户群的呼叫限制分为群内呼叫限制和群外呼叫限制。

- 群内呼叫限制分为以下几种：
  - 群内呼叫无限制：允许用户接收群内其他用户的呼叫，也允许用户呼叫群内其他的用户。
  - 群内呼入禁止：不允许用户接收群内其他用户的呼叫，但允许用户呼叫群内其他的用户。
  - 群内呼出禁止：不允许用户发起到群内其他用户的呼叫，但可以接收群内其他用户的呼叫。
- 群外呼叫限制分为以下几种：
  - 群外呼入允许：允许用户接收群外用户的呼叫，但不允许呼叫群外用户。
  - 群外呼出允许：允许用户发起到群外用户的呼叫，但不能接收群外用户的呼叫。
  - 群外呼入呼出禁止：只允用户许发起到群内用户的呼叫，不能发起到群外用户的呼叫，不能接收群外用户的呼叫。
  - 群外呼入呼出允许：允许用户接收群外用户的呼叫，也允许用户发起到群外用户的呼叫。

**CCBS业务**

CCBS（Completion of Calls to Busy Subscriber）业务，即遇忙呼叫回拨业务。签约该业务的用户A在拨打用户B时，如果用户B忙，则在用户B变成空闲以后，网络会向主叫用户振铃，主叫用户A可直接接听电话，即网络会让用户A自动完成呼叫，不需要用户A再次拨打用户B。

**短消息重定向业务**

短消息重定向业务作为传统短消息业务的一种增强，最显著的变化在于更改了短消息的终呼流程。更改后，短消息先发送到被叫的归属网络，然后由归属网络将短消息传达给目标网络（VPLMN）。

在3GPP R7中定义了一个新实体为SMS-Router。该实体的核心作用是让短消息流程经过本网的SMS-Router处理，帮助用户接收并存储合法的短消息，为用户提供多种短消息到达的解决方案。HSS/HLR需要和SMS-Router一起完成短消息重定向业务。

**CLIP业务**

CLIP（Calling Line Identification Presentation）业务，即主叫号码识别显示业务。该业务是一种向被叫用户提供的补充业务，它能够向被叫用户提供主叫用户的号码。用户签约了该业务后，当用户作被叫时，系统会向被叫用户提供主叫用户的号码，被叫用户可根据MS显示的号码来识别主叫用户，从而决定是否接听。同时，对于未接或不便接听的情况，被叫用户可以根据显示的号码在以后自主选择回复。

**CLIR业务**

CLIR（Calling Line Identification Restriction）业务，即主叫号码识别限制业务。该业务是一种向主叫用户提供的补充业务，它能够限制将主叫用户号码显示给被叫用户。用户签约了该业务后，当用户作主叫时，系统不会向被叫用户显示主叫用户的号码，即使该被叫用户签约了CLIP业务。可满足用户对自身号码保密的目的。运营商可以向用户提供永久调用、临时调用、临时屏蔽三种模式的CLIR业务：

- 永久调用模式：对每次呼叫都调用CLIR业务，即每次主叫用户呼叫其他用户，都不会显示主叫用户的号码。
- 临时调用模式：缺省状态下不调用CLIR业务，但可以通过在手机上进行操作，对某个呼叫临时调用CLIR业务。
- 临时屏蔽模式：缺省状态下调用CLIR业务，但可以通过在手机上进行操作，对某个呼叫临时屏蔽CLIR业务。

**优选漫游业务**

优选漫游业务是指当用户漫游出归属PLMN，当存在多个PLMN供接入时，可以根据需要选择某一个PLMN作为用户漫游的最优网络，设置的原则可以是低资费、高可靠性或者友好合作关系等。通过**ADD PLMN**命令设置各个PLMN的优选漫游标志：

- PREFERRED：首选的，优选漫游网络，表示直接允许用户在此网络漫游。
- ALLOWED：允许的，非优选漫游网络，表示用户漫游到此网络时，被拒绝N次位置更新后，再允许其位置更新成功，拒绝次数N可配置。
- RESTRICTED：总是受限的，非漫游网络，表示用户漫游到此网络时，总是拒绝其位置更新。

**防欺诈业务**

防欺诈业务分为用户级防欺诈和全局性防欺诈：

- 用户级防欺诈业务的主要功能是对可疑用户的下列活动进行限制：始发呼叫最大时长、前转呼叫最大时长、在一个时间周期内手机侧登记前转的最大次数。
- 全局性防欺诈业务的主要功能是对本HSS/HLR内所有用户的活动进行监控，包括对用户的鉴权、位置更新、登记前转和登记国际前转的发生频率进行监控，如以上活动发生过于频繁，则系统认为此用户的SIM/USIM卡存在被克隆的可能，及时把相关信息通知运营商。

**ARD业务**

ARD（Access Restriction Data）业务又称接入类型限制功能，是提供给运营商控制移动用户接入不同网络权限的一种功能。移动用户开户时，运营商根据用户选择的接入类型在HSS/HLR上配置用户的ARD数据，从而实现控制移动用户接入不同类型的网络。

接入类型可分为：

- UTRAN（Universal Terrestrial Radio Access Network）
- GERAN（GSM/EDGE Radio Access Network）
- GAN（Generic Access Network）
- I-HSPA-Evolution（Internet High Speed Packet Access-Evolution）
- EUTRAN（Evolved Universal Terrestrial Radio Access Network）
- HO-To-Non3GPP-Access（HO To Non 3rd Generation Partnership Project Access）

**GPRS动态数据索引化压缩存储**

原有的GPRS动态数据存储时是新增一条动态数据就往表中插入一条数据，而动态字段的值通常情况下是没有意义的，但是又会占用一定的固定内存，因此采用新增用户表的方式，里面只存储新增动态数据模板的ID，通过此ID可以反查到原业务表中的数据，这样既不占用固定内存，又可以查到相应的信息，这种存储方式就叫做GPRS动态数据索引化压缩存储。

**短消息前转业务和ODB/CB业务冲突关系**

- 短消息前转业务和ODB业务冲突关系
  - 用户签约ODB-BAOC，则ODB和短消息前转冲突。
  - 用户签约ODB-BAIC，则ODB和短消息前转冲突。
  - 用户签约ODB-BOCROAM，且用户所在的MSC类型为国际，则ODB和短消息前转冲突。
  - 用户签约ODB-BICROAM，且用户所在的MSC类型为国际，则ODB和短消息前转冲突。
  - 用户签约ODB-INFO，且前转的前转号码为信息台号码，则ODB和短消息前转冲突。
  - 用户签约ODB-ENTE，且短消息前转的前转号码为娱乐台号码，则ODB和短消息前转冲突。
  - 用户签约ODB-BOIC，且短消息前转的前转号码不为本国号码，则ODB和短消息前转冲突。
  - 用户签约ODB-BOICEXHC，且短消息前转的前转号码不为归属国号码，则ODB和短消息前转冲突。
  - 用户签约了ODB-POS，且用户的接入模式为onlySGSN，则ODB和短消息前转冲突。
- 短消息前转业务和CB业务冲突关系
  - 短消息前转业务与CB业务中BAOC均为激活，则CB和短消息前转冲突。
  - 短消息前转业务与CB业务中BAIC均为激活，则CB和短消息前转冲突。
  - 短消息前转业务与CB业务中BORO均为激活，则CB和短消息前转冲突。
  - 短消息前转业务与CB业务中BOIC均为激活，且短消息前转的前转号码不为本国号码，则CB和短消息前转冲突。
  - 短消息前转业务与CB业务中BOICEXHC均为激活，且短消息前转的前转号码不为本国号码，则CB和短消息前转冲突。

**位置定位业务（LCS）**

位置定位业务，简称LCS（Location Services），是指移动网络通过特定的定位技术获取移动终端的地理位置信息（经纬度坐标），提供给移动用户本人、通信系统或第三方，并借助一定的电子地图信息的支持，为移动用户提供与其位置相关的业务。
