# 远端Provisioning站点规则管理

- 功能描述
- 注意事项
- 配置原则

#### 功能描述

该组命令用于管理远端业务发放站点规则的相关数据。当系统需要对收到的业务发放系统指令（如开户、签约等）进行数据采集，并进行用户数据的变化趋势或行为特点分析等用途时，需要通过远端业务发放站点管理命令和本组命令配置远端业务发放站点和相关规则数据。当收到业务发放系统下发的指令后，USCDB的业务发放网关（PGW）在将业务发放系统指令转发给远端的业务发放站点处理的同时，还可以将相关用户数据收集保存在系统数据库用于对数据进行分析和挖掘。如图1所示。

**图1** 远端业务发放原理图

在图1中：

1. 业务发放系统向系统的PGW发起登录请求。
2. PGW通过对业务发放系统的身份信息进行鉴权认证，认证通过后返回响应消息和会话ID。
3. 业务发放系统收到响应消息和会话ID后访问PGW并下发业务发放指令。
4. PGW收到业务发放指令后，根据配置匹配拆分和转发规则，将满足条件的指令拆分为本地执行指令和转发指令。其中本地执行指令由系统处理后记录到数据库中；转发指令则由系统根据指令中的用户号码信息（例如号段类型、号段信息等）和远端业务发放站点之间的关联关系转发到对应的远端业务发放站点进行后续处理。

#### 注意事项

- 在业务发放系统向PGW发起登录请求前，远端业务发放站点对应的适配插件包必须已经完成定制且在系统上加载生效。适配插件包的状态可通过**DSP ADPPLUG**命令进行查询。
- PGW与远端业务发放站点之间的连接必须正常可用，否则系统会上报ALM-14024 与远端业务发放站点存在链路故障告警，造成业务发放指令执行失败。

#### 配置原则

本命令组必须与远端业务发放站点管理命令组都配置完毕后，系统才会按照图1所示将业务发放指令进行转发处理。
