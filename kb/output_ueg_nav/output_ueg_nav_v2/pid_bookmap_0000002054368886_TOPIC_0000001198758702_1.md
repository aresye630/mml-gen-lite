# 可选配置

## 目录内容

- 可选配置
  - 业务安全配置
    - 配置ACL防止UE或用户PDN/DN对运营商网络设备攻击
    - 激活防DDoS功能
    - 配置ACL防止UE之间的互访
    - 激活接入控制
    - 配置CP白名单功能
    - 配置互访流量的重定向功能
    - 激活支持APP认证鉴权
    - 配置IP Spoofing防攻击
    - 配置大流量防攻击
    - 激活SBI接口加密特性(CERT)
  - 运维安全配置
    - 更新GaussDB数据库弱口令字典
    - 配置USCDB管理弱口令
  - 数据安全配置
    - 配置USCDB内存库备份文件加密
    - 配置跟踪匿名化功能（通过OM Portal）（UPF/GW-U）
    - 配置CHR假名化本地策略（通过MML）（AMF/MME/SMF/GW-C）
  - 网络安全配置
    - 配置GaussDB数据库TLS功能
  - 系统安全配置
    - 配置系统安全策略
      - 配置OM网络访问控制策略
