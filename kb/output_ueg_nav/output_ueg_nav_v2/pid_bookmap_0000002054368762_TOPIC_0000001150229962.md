# 安全配置建议

随着网络演进，网络及业务的安全愈发重要，UEG面临的安全威胁也更为多样化，例如系统数据异常或丢失、密码被盗取、用户越权访问、操作系统漏洞等。一旦出现安全问题，将面临业务中断，甚至系统崩溃的危险，因此建议运营商根据现网实际情况配置所需的产品安全功能，保障应用系统在安全环境下的正常运行，从多个层次构建整个应用系统的安全屏障，提前发现并处理各种可能存在的安全问题，以确保产品在安全的环境下正常运行。
