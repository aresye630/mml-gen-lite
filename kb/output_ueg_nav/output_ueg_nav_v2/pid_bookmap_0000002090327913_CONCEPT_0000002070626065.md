# SOAP客户端白名单管理

- 功能描述
- 注意事项

#### 功能描述

用于管理系统中SOAP客户端的IP地址信息。

#### 注意事项

不添加SOAP客户端IP地址信息时，系统不会对接入的SOAP客户端的IP地址进行检查。如果在系统中添加了某个SOAP客户端IP地址，则系统只容许已添加的SOAP客户端IP地址接入系统。

## 目录内容

- SOAP客户端白名单管理
  - 修改SOAP客户端IP地址(MOD SOAPNAFIP)
  - 增加SOAP客户端IP地址(ADD SOAPNAFIP)
  - 删除SOAP客户端IP地址(RMV SOAPNAFIP)
  - 查询SOAP客户端IP地址(LST SOAPNAFIP)
