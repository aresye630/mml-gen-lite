# PGW TPS管理

- 命令功能
- 注意事项

## 命令功能

用于设置和查询TPS（Transactions Per Second）控制参数，包括控制开关、上报周期和控制周期。

为合理的给营帐客户端分配资源，防止客户端之间出现资源抢夺的情况，可以根据操作员对客户端的指令进行TPS控制。即在一个控制周期内，对于某指定操作员，只允许发送最多N条（N为TPS与控制周期的乘积）命令请求。TPS的值通过PGW的**ADD OPR**命令或**MOD OPR**命令设置。
