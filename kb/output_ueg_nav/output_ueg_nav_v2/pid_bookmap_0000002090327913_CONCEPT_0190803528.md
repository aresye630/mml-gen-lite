# 业务限制模板

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于在UDM中设置业务限制模板，用于减少在签约VLR/SGSN漫游限制模板时的复杂性。相比较直接在漫游限制模板中添加需要限制的业务，业务限制模板将需要限制的业务在模板中集中起来，在签约VLR/SGSN区域漫游限制业务时直接引用需要的业务限制模板，不需要在模板中的逐个定义需要限制的业务。

VLR/SGSN漫游限制模板用于VLR/SGSN区域漫游限制业务，在此业务中，设置用户允许漫游的VLR/SGSN范围。在允许漫游的区域之外，对用户的业务进行限制。当在**ADD VSLIST**命令中设置“漫游限制状态”为“CUSTOMIZED”时，可以选择设置“业务限制模板ID”，选择对应的业务限制模板，限制业务的使用。

#### 注意事项

无。

#### 基本概念

**CFU**

即无条件前转。当移动用户作被叫时，不管被叫用户的终端处于何种状态，所有呼叫都将被前转到第三方用户。这里第三方用户可以是PLMN、PSTN、ISDN等网络的任意用户，也可以是语音邮箱等服务台。

**CFB**

即遇忙呼叫前转。当用户忙时，允许用户将来话转接到预先设置的另一个电话号码上或用户的语音信箱中。

**CFNRY**

即无应答呼叫前转。当被叫移动用户收到网络振铃消息后久不摘机应答，无应答时长定时器超时，呼叫将被前转到第三方用户。

**CFNRC**

即不可及呼叫前转。当网络与移动用户的无线信道连接中断的情况下，移动用户作被叫时，呼叫将被前转到第三方用户。

**CFD**

即缺省呼叫前转CFD（Call forwarding default）业务。当基于某一种基本业务组的CFU没有激活且某一种条件前转没有激活时，呼叫将前转到CFD登记的前转号码，从而保证对用户的每一次呼叫都能接通。

CFD是对三个条件前转业务（CFB、CFNRy、CFNRc）的补充，具体的应用如语音信箱。

**CW**

即呼叫等待（Call Waiting）业务。允许主叫用户在如下情况收到等待通知：

- 被叫用户没有空闲的业务信道可使用
- 被叫用户正在通话
- 被叫用户正在保持呼叫

被叫用户对这个等待的呼叫可以选择接收、拒绝或不处理。

**BAIC**

即闭锁所有入呼叫。当该业务激活时，用户将不能接收所有呼入呼叫。

**BICROAM**

即闭锁当漫游出HPLMN(Home Public Land Mobile Network)国家时所有入呼叫。当移动用户在激活本业务时，移动用户漫游出归属PLMN国家时无法接收呼叫。

**CH**

即呼叫保持。当移动用户中断现有的呼叫，而在随后有需要时重新建立该呼叫。在中断呼叫期间，系统会保留原有呼叫分配的业务信道。

**ODB-BOIC**

即ODB闭锁所有国际呼出。该业务激活时，若移动用户在归属PLMN国家漫游，不允许呼叫国外用户。

**MPTY**

即多方通话。提供一个用户进行多连接呼叫的能力。即三个或更多的用户（与会者）可以同时进行通信。

**ODB-BAOC**

即ODB闭锁所有出呼叫。该业务激活时，用户将不能进行除紧急呼叫以外的所有呼叫。

**ODB-BOICEXHC**

即ODB闭锁除到归属国以外的国际出呼叫。该业务激活时，用户将不能呼叫除归属国以外的国际长途呼叫。

**ODB-BOCROAM**

即ODB漫游出归属PLMN国家以外时，闭锁出呼叫业务。

**ODB-INFO**

即运营商决定的闭锁-闭锁高额费率声讯业务出局呼叫。

**ODB-ENTE**

即运营商决定的闭锁-闭锁高额费率娱乐业务出局呼叫。

**EOCSI**

即EOCSI业务，即增强OCSI业务，通过该业务MSC可以实现将呼叫路由至其他网络节点进行呼叫判断。

**PREFERROAM**

即优选漫游业务，指当用户漫游出HPLMN(Home PLMN)，存在多个PLMN供接入时，运营商可以根据需要选择某一PLMN作为用户漫游的最优网络，设置的原则可以是低资费、高可靠性或者友好合作关系等。优选漫游的算法可以实现漫游用户在漫游比例高的运营商有更高的接入成功率。

**OPTGPRS**

即优化GPRS业务，指为了对GPRS/EPS数据进行灵活的管理，UDM对原有的GPRS/EPS数据进行优化，允许操作员对用户的所有GPRS/EPS相关参数进行独立配置。

**ETCSI**

即ETCSI业务，即增强TCSI业务，通过该业务GMSC将可以实现呼叫路由其他网络节点进行呼叫判断。

T-CSI是被叫CAMEL签约信息，在移动用户做被叫的SRI流程，T-CSI数据由HLR传递给GMSC，T-CSI智能业务将被触发。

**BAOC**

闭锁所有呼出业务BAOC（Barring of All Outgoing Calls）。该业务激活时，用户将不能进行除紧急呼叫以外的所有呼叫。

**BOIC**

闭锁所有国际呼出业务BOIC（Barring of All Outgoing International Calls）。该业务激活时，若移动用户在归属PLMN国家漫游，不允许呼叫国外用户。

**BOICEXHC**

闭锁所有除归属国PLMN外的国际呼出业务BOIC-exHC（Barring of Outgoing International Calls except those directed to the Home PLMN Country）。该业务激活时，用户将不能呼叫除归属国以外的国际长途呼叫。

**ODB-PB1**

即闭锁国内长途呼叫。该业务激活时，用户将不能进行除用户归属地以外的国内长途呼叫。

**ODB-PB2**

即ODB-PB2业务。

**ODB-PB3**

即ODB-PB3业务。

**ODB-PB4**

即ODB-PB4业务。

**CLIR**

即主叫号码识别限制业务。该业务是一种向主叫用户提供的补充业务，它限制将主叫用户号码识别提供给被叫用户。

**COLP**

即被叫号码识别显示业务。该业务是一种向主叫用户提供的补充业务，它能够向主叫用户提供被接用户号码识别。

**TS11**

即Telephony Service，电话业务。

**TS21**

即Mobile Terminated Point-to-Point Short Message Service，MT-PP点对点短消息接收业务。

**TS22**

即Mobile Originated Point-to-Point Short Message Service，MO-PP点对点短消息始发业务。
