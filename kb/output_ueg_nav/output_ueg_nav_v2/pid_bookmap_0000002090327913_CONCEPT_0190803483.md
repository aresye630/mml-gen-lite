# VLR类型

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于在HLR中添加VLR相对于本地HLR的网络类型，并设置指定的VLR是否支持业务受限功能以及是否根据NCC（Network Capability Configuration）模板和CAMEL（Customized Applications for Mobile network Enhanced Logic）模板设置的能力分别对MAP流程和相关业务进行处理。

#### 注意事项

无。

#### 基本概念

**NCC模板**

NCC即网络能力配置，是指运营商根据VLR或SGSN实际所支持的业务和MAP版本，对HLR进行设置，使HLR能根据VLR或SGSN实际所支持的业务和MAP版本，进行相关业务与相关MAP流程的处理，提高HLR与VLR/SGSN的兼容性。

NCC模板用于设置VLR或SGSN所支持的业务和MAP版本。使用**ADD NCCTPL**命令预先设置NCC模板，在进行业务和MAP流程的处理时，HLR根据NCC模板中配置的相应业务和MAP版本的支持能力进行处理。例如，NCC模板中的参数“Cancel location中的私有信元”设置为“NR（CancelLocation请求中的私有信元不下发到VLR）”，那么在HLR上对指定的VLR添加该NCC模板后，HLR在下发业务数据时，Cancel location消息中的私有信元不下发到该VLR。

**CAMEL能力模板**

CAMEL是在GSM/TD-SCDMA/WCDMA协议族中提出的一整套智能网解决方案，使网络运营商在具有CAMEL特征的移动网络上能够提供自定义业务。在移动智能网中，智能业务的触发根据用户数据中的CSI（CAMEL Subscription Information）数据或MSC中的N-CSI（Network CAMEL Subscription Information）进行。CAMEL签约信息包括O-CSI、D-CSI、T-CSI、VT-CSI、M-CSI、MOSMS-CSI、MTSMS-CSI、SS-CSI、TIF-CSI等，用户可以根据需要选择其中的一种或几种，具体请参见CAMEL业务管理。

CAMEL能力模板用于设置VLR或SGSN所支持的CAMEL业务和CAMEL版本。使用**ADD CAMELCAPTPL**命令预先设置CAMEL能力模板，在进行CAMEL业务处理时，HLR根据CAMEL能力模板中配置的相应业务和CAMEL版本的支持能力进行处理。例如，CAMEL能力模板中的参数“O\_CSI支持能力”设置为“PHASE4”，即VLR或SGSN支持以CAMEL phase 4版本进行O-CSI业务处理，那么在HLR上对指定的VLR添加该CAMEL能力模板后，HLR在下发O-CSI业务数据到该VLR时，会以CAMEL phase 4版本进行处理。

**业务区域限制**

业务区域限制是指针对特定区域用户的短信、语音、GPRS等业务按照要求进行限制。当用户需要签约此业务时，操作员可以先通过**MOD OKSC**命令为用户签约业务区域限制，然后通过**ADD VLRTYP**命令设置HLR对指定的VLR进行业务限制。

**VLR和本地HLR的位置关系示意图**

VLR和本地HLR的位置关系如图1所示。

**图1** VLR和本地HLR的位置关系示意图

位置关系说明：

- VLR1和本地HLR在同一地区，对应的VLR网络类型为“LOCAL（本地）”。
- VLR2和本地HLR在同一个省和PLMN（Public Land Mobile Network）内，对应的VLR网络类型为“LOCALAREA（省内本网）”。
- VLR3和本地HLR在同一个省内，但在不同的PLMN内，对应的VLR网络类型为“CROSSAREA（省内跨网）”。
- VLR4和本地HLR在同一个国家，且在同一个PLMN内，对应的VLR网络类型为“LOCALDOMESTIC（国内本网）”。
- VLR5和本地HLR在同一个国家，但在不同的PLMN内，对应的VLR网络类型为“CROSSDOMESTIC（国内跨网）”。
- VLR6和本地HLR不在同一个国家，但在相同的PLMN内，对应的VLR网络类型为“LOCALINTERNATIONAL（国际本网）”。
- VLR7和本地HLR不在同一个国家，也不在同一个PLMN内，对应的VLR网络类型为“CROSSINTERNATIONAL（国际跨网）”。

**说明** 

- 上述的地区、省是国家行政区域的划分，不同国家有不同的区分。例如，有些国家可能划分为州、大区等。
- 如果某些国家不区分省、州、大区等这类概念，则上述VLR2和VLR4与本地HLR的位置关系相同，对应的VLR网络类型为“LOCALDOMESTIC（国内本网）”；VLR3和VLR5与本地HLR的位置关系相同，对应的VLR网络类型为“CROSSDOMESTIC（国内跨网）”。
