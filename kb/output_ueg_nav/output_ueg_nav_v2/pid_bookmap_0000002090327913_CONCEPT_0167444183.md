# NF信息管理

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

NF：Network Function，网络功能。

FQDN：fully qualified domain name，全量域名。

#### 功能描述

NF信息管理用于配置和维护网络功能实例信息。配置用于增加、删除网络功能实例信息，修改网络功能实例的配置信息。维护用于查询网络功能实例的配置信息。PCF可以通过配置这些信息触发注册、更新或去注册流程，并将信息登记到NRF。

#### 注意事项

无。

## 目录内容

- NF信息管理
  - 查询NF信息(LST NFPROFILE)
  - 添加NF信息(ADD NFPROFILE)
  - 删除NF信息(RMV NFPROFILE)
  - 修改NF信息(MOD NFPROFILE)
