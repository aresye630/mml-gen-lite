# 系统调测

## 目录内容

- 系统调测
  - 策略调测
    - 交换信息
      - 查询负载均衡交换表（DSP EXCHANGE）
    - 负载均衡策略
      - 查询负载均衡策略（DSP LBPLY）
    - 策略跟踪
      - 查询策略跟踪（DSP PLYTRACE）
    - 下一跳策略
      - 查询负载均衡下一跳（DSP NEXTHOP）
  - 流控参数
    - 设置流控开关（SET LBFC）
    - 查询流控开关（LST LBFC）
  - 转发面流控参数
    - 查询转发面流控参数（LST FWDFCPARA）
    - 设置转发面流控参数（SET FWDFCPARA）
  - 公共调测
    - 调试信息
      - 查询调试信息（DSP DBGSTAT）
    - 软件参数管理
      - 设置CSLB软件调试参数表（SET LBSOFTPARA）
      - 查询CSLB软件调试参数表（LST LBSOFTPARA）
  - 系统参数
    - 设置转发参数（SET FWDPARA）
    - 查询转发参数（LST FWDPARA）
