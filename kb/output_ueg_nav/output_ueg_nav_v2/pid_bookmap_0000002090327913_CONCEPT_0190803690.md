# 禁止前转号码

- 命令功能
- 注意事项
- 基本概念

#### 命令功能

该组命令用于管理系统中禁止前转号码数据。禁止前转的号码存储在**禁止前转号码表**中，在号码规整流程中按照完全匹配方式进行业务处理，当用户登记到禁止前转的号码时操作不能成功。

在中国通常会设置下列号码为禁止前转号码：

- 紧急呼叫号码：如119（火灾求救）、120（医疗求救）等，遇到紧急情况需要拨打此类号码求救，不能将呼叫随意前转到此类号码，避免引起不良后果。
- 热线号码：如10086（移动热线）、114（号码查询）等，此类号码通常提供热线专业服务，为避免“恶意玩笑”，禁止前转到热线号码。
