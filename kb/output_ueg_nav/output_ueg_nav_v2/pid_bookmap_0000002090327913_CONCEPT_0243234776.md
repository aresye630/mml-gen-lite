# 模块

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

无。

#### 功能描述

用于提供模块维护和模块状态查询相关的命令。

#### 注意事项

请注意该组命令应由专业维护人员小心使用。

## 目录内容

- 模块
  - 修改模块(MOD MODULE)
  - 倒换模块(SWP MODULE)
  - 复位指定类型的模块(RST MDUTYPE)
  - 复位模块(RST MODULE)
  - 显示模块(DSP MODULE)
  - 停止模块(STP MODULE)
  - 启动模块(STR MODULE)
  - 查询模块配置(LST MODULE)
