# 网元实例信息

- 功能描述
- 注意事项
- 基本概念

#### 功能描述

该组命令用于设置网元实例的信息。

#### 注意事项

无。

#### 基本概念

“网元实例信息”符合JSON格式。名称和类型如下：

- nfInstanceID：NF实例标识。字符串格式，必选参数。
- nfType：允许访问该服务实例的网元实例类型。必选参数。
- scpInfo：表示SCP信息，SCP注册时携带。可选参数，参数个数为0或1个。
  - “ScpInfo”的名称和类型如下：
    - scpDomainInfoList：定义scpDomain的特定信息，用于区分NFProfile中携带的信息。Key是scpDomain标识。数组格式，可选参数，参数个数为1或多个。
    - scpPrefix：表示scp前缀，给SCP发消息时拼接在apiRoot中。字符串格式，可选参数，参数个数为0或1个。
    - scpPorts：表示scp端口号。数组格式，条件必选参数，参数个数为1或多个。
    - addressDomains：表示SCP支持的域名信息。字符串格式，可选参数，参数个数为1或多个。
    - ipv4Addresses：表示SCP支持的IPV4地址信息。可选参数，参数个数为1或多个。
    - ipv6Prefixes：表示SCP支持的IPV6前缀地址信息。可选参数，参数个数为1或多个。
    - ipv4AddrRanges：表示SCP支持的IPV4地址段信息。可选参数，参数个数为1或多个。
    - ipv6PrefixRanges：表示SCP支持的IPV6前缀地址段信息。可选参数，参数个数为1或多个。
    - servedNfSetIdList：表示SCP支持的Set列表。可选参数，参数个数为1或多个。
    - remotePlmnList：表示经SCP可达的远端PLMNlist。可选参数，参数个数为1或多个。
    - ipReachability：表示IP可达性，SCP域内的支持的IP地址类型。可选参数，参数个数为0或1个。
- plmnList：网元实例所处的PLMN。PlmnId数组格式，可选参数，参数个数为0或多个。
  - PlmnId：PLMN的标识，字符串格式。
- sNssais：网元实例所属的切片。SNSSAI数组格式，可选参数，参数个数为0或多个。
  - SNSSAI：切片信息ID。对象格式，参数个数为0或多个，取值可以是：
    - sst：取值范围0～255。
    - sd：长度为6的字符串，只允许包括0～9和A～F，举例：“143A5D”。
- nsiList：网元实例的NSI identities。数组格式，可选参数，参数个数为0或1个。
- heartBeatTimer：网元实例的心跳周期。整型格式，可选参数，参数个数为0或1个。
- allowedPlmns：允许访问该网元实例的PLMN集合。数组格式，可选参数，参数个数为0或多个。
- allowedNfTypes：允许访问该网元实例的网元实例类型。数组格式，可选参数，参数个数为0或多个。
- allowedDomains：允许访问该网元实例的网元实例域名。数组格式，可选参数，参数个数为0或多个。
- allowedNssais：允许访问该网元实例的NSSAI切片集合。数组格式，可选参数，参数个数为0或多个。
- fqdn：网元实例的全量域名。Fqdn格式，可选参数，参数个数为0或1个，与Ipv4地址，Ipv6地址三者之间至少存在一个。
- interPlmnFqdn：和其它网络交互时体现的全量域名。Fqdn格式，可选参数，参数个数为0或1个。
- ipv4Addresses：网元实例的Ipv4地址。数组格式，可选参数，参数个数为0或多个，与fqdn，Ipv6地址三者之间至少存在一个。
  - ipv4Address：ipv4地址，格式为以“.”分割的4组十进制数，例如：“192.168.111.111”。
- ipv6Addresses：网元实例的Ipv6地址。ipv6Address数组格式，可选参数，参数个数为0或多个，与fqdn，Ipv4地址三者之间至少存在一个。
  - ipv6Address：ipv6地址，格式为以冒号分割的八组十六进制数，例如：“fc00:2222:3333:aaaa:bbbb:cccc:dddd:eeee”。
- priority：优先级，数字越小优先级越高。整型格式，取值范围：0～65535，可选参数，参数个数为0或1个。
- capacity：处理能力权重。整型格式，取值范围：0～65535，可选参数，参数个数为0或1个。
- load：标识网元实例的当前负载。整型格式，取值范围：0～100，可选参数，参数个数为0或1个。
- locality：地理位置信息。字符串格式，可选参数，参数个数为0或1个。
- recoveryTime：网元实例被启动或重启时的时间戳。DateTime格式，可选参数，参数个数为0或1个，例如：“2018-10-25T20:20:20Z”。
- nfServicePersistence：服务实例可访问标识。布尔格式，可选参数，默认值为false，参数个数为0或1个。
- udmInfo：号段信息，UDM注册时携带，携带该参数不允许携带ausfInfo，UdmInfo格式。可选参数，参数个数为0或1个。
  - “UdmInfo”的名称和类型如下：
    - groupId：UDM分组信息。字符串格式，可选参数，参数个数为0或1个。
    - supiRanges：号段范围列表。SupiRange数组格式，可选参数，参数个数为0或多个。
      - “SupiRange”的名称和类型如下：
        - start：起始SUPI号段，此参数和end一起携带。字符串格式，可选参数，参数长度：5～15位，只允许包含数字，参数个数为0或1个。
        - end：结束SUPI号段，此参数和start一起携带。字符串格式，可选参数，参数长度：5～15位，只允许包含数字，参数个数为0或1个。
        - pattern：正则表达式表示号码范围。字符串格式，可选参数，参数个数为0或1个，携带此参数时不允许携带start和end参数。
    - gpsiRanges：号码范围列表。数组格式，可选参数，参数个数为0或1个。
    - externalGroupIdentityfiersRanges：外部组标识的分组信息。数组格式，可选参数，参数个数为0或多个。
    - routingIndicators：SUCI对应的routingIndicators。字符串数组格式，可选参数，参数个数为0或多个。
- ausfInfo：号段信息，AUSF注册时携带，携带该参数不允许携带udmInfo，AusfInfo格式，可选参数，参数个数为0或1个。
  - “AusfInfo”的名称和类型如下：
    - groupId：AUSF组标识。字符串格式，可选参数，参数个数为0或1个。
    - supiRanges：号段范围列表。SupiRange数组格式，可选参数，参数个数为0或多个。
    - routingIndicators：SUCI对应的routingIndicators。字符串数组格式，可选参数，参数个数为0或多个。
- nfServices：nf服务。NFService数组格式，可选参数，参数个数为0或多个。
  - “NFService”的名称和类型如下：
    - serviceInstanceId：服务实例标识。字符串格式，必选参数。
    - serviceName：服务实例的名称。字符串格式，必选参数，允许的取值："nudm-sdm"，"nudm-uecm"，"nausf-auth"。
    - versions：网元实例服务支持的API版本。数组格式，必选参数，参数个数为1或多个。
    - scheme：协议模式。字符串格式，必选参数，允许的取值："http"，"https"。
    - nfServiceStatus：网元实例服务状态。字符串格式，必选参数，参数个数为0或1个，允许的取值："REGISTERED"，"SUSPENDED"、"UNREGISTERED"。
    - fqdn：服务宿主网元实例的FQDN。字符串格式，可选参数，参数个数为0或1个。
    - interPlmnFqdn：和其它网络交互时体现的全量域名。Fqdn格式，可选参数，参数个数为0或1个。
    - ipEndPoints：网元实例服务侦听来访服务请求的IP地址和端口信息。IpEndPoint数组格式，可选参数，参数个数为0或多个。
      - ipv4Address：网元实例的Ipv4地址。可选参数，参数个数为0或1个。
      - ipv6Address：网元实例的Ipv6地址。可选参数，参数个数为0或1个。
      - transport：传输协议。可选参数，取值为“TCP”，参数个数为0或1个。
      - port：端口号。整型格式，可选参数，参数个数为0或1个。
    - apiPrefix：可选路段。字符串格式，可选参数，参数个数为0或1个。
    - defaultNotificationSubscriptions：默认通知类型的通知端点。数组格式，可选参数，参数个数为0或多个。
    - capacity：静态容量信息。整型格式，可选参数，参数个数为0或1个。
    - allowedPlmns：允许访问该服务实例的PLMN集合。数组格式，可选参数，参数个数为0或多个。
    - allowedNfTypes：允许访问该服务实例的网元实例类型。数组格式，可选参数，参数个数为0或多个。
    - allowedDomains：允许访问该服务实例的网元实例域名。数组格式，可选参数，参数个数为0或多个。
    - allowedNssais：允许访问该服务实例的NSSAI切片集合。数组格式，可选参数，参数个数为0或多个。
    - capacity：处理能力权重。整型格式，取值范围：0～65535，可选参数，参数个数为0或1个。
    - load：服务负载情况。整型格式，取值范围：0～100，可选参数，参数个数为0或1个。
    - priority：被用做选择网元实例和服务的优先级。整型格式，取值范围：0～65535，可选参数，参数个数为0或1个。
    - recoveryTime：网元实例服务被启动或重启时的时间戳。DateTime格式，可选参数，参数个数为0或1个，例如：“2018-10-25T20:20:20Z”。
    - supportedFeatures：网元实例服务支持的特性。字符串格式，可选参数，参数个数为0或1个。
- nfServiceList：nf服务列表。MAP格式，可选参数，参数个数为0或多个。
  - “NFService”的名称和类型如下：
    - serviceInstanceId：服务实例标识。字符串格式，必选参数。
    - serviceName：服务实例的名称。字符串格式，必选参数，允许的取值："nudm-sdm"，"nudm-uecm"，"nausf-auth"。
    - versions：网元实例服务支持的API版本。数组格式，必选参数，参数个数为1或多个。
    - scheme：协议模式。字符串格式，必选参数，允许的取值："http"，"https"。
    - nfServiceStatus：网元实例服务状态。字符串格式，必选参数，参数个数为0或1个，允许的取值："REGISTERED"，"SUSPENDED"，"UNREGISTERED"。
    - fqdn：服务宿主网元实例的FQDN。字符串格式，可选参数，参数个数为0或1个。
    - interPlmnFqdn：和其它网络交互时体现的全量域名。Fqdn格式，可选参数，参数个数为0或1个。
    - ipEndPoints：网元实例服务侦听来访服务请求的IP地址和端口信息。IpEndPoint数组格式，可选参数，参数个数为0或多个。
      - ipv4Address：网元实例的Ipv4地址。可选参数，参数个数为0或1个。
      - ipv6Address：网元实例的Ipv6地址。可选参数，参数个数为0或1个。
      - transport：传输协议。可选参数，取值为“TCP”，参数个数为0或1个。
      - port：端口号。整型格式，可选参数，参数个数为0或1个。
    - apiPrefix：可选路段。字符串格式，可选参数，参数个数为0或1个。
    - defaultNotificationSubscriptions：默认通知类型的通知端点。数组格式，可选参数，参数个数为0或多个。
    - capacity：静态容量信息。整型格式，可选参数，参数个数为0或1个。
    - allowedPlmns：允许访问该服务实例的PLMN集合。数组格式，可选参数，参数个数为0或多个。
    - allowedNfTypes：允许访问该服务实例的网元实例类型。数组格式，可选参数，参数个数为0或多个。
    - allowedDomains：允许访问该服务实例的网元实例域名。数组格式，可选参数，参数个数为0或多个。
    - allowedNssais：允许访问该服务实例的NSSAI切片集合。数组格式，可选参数，参数个数为0或多个。
    - capacity：处理能力权重。整型格式，取值范围：0～65535，可选参数，参数个数为0或1个。
    - load：服务负载情况。整型格式，取值范围：0～100，可选参数，参数个数为0或1个。

    - supportedFeatures：网元实例服务支持的特性。字符串格式，可选参数，参数个数为0或1个。
- seppInfo：表示SEPP的HTTP端口号。可选参数，参数个数为0或1个。
  - “SeppInfo”的名称和类型如下：
    - seppPorts：表示SEPP端口号。key是"http" 或 "https"。数组格式，条件必选参数，参数个数为1或多个。
    - remotePlmnList：表示经SEPP可路由到的PLMN。可选参数，参数个数为1或多个。
