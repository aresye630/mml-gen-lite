# 激活PCC基本功能（动态PCC）

- 背景信息

#### 背景信息

此处激活的PCC基本功能，适用于如下场景：业务采用动态PCC，需要从PCF获取策略。

**说明** 

动态PCC包括动态规则和预定义规则：

- 当采用动态规则时，规则的内容（流匹配条件和动作）是在PCF上配置或动态生成的。

  详细配置请参见部署PCF和配置动态PCC功能（SMF）。
- 当采用预定义规则时，规则的内容（流匹配条件和动作）是提前在UPF上配置出来。

  详细配置请参见部署PCF、配置动态PCC功能（SMF）和部署UPF。
