# 用户数据查询

- 命令功能
- 基本概念

#### 命令功能

该组命令用于查询用户的静态数据、动态数据、终端状态及位置信息。

#### 基本概念

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。

****GET TERMSTATE**命令中的IMSIFILE文件格式**

IMSIFILE文件包含“IMSI”、“是否查询终端位置信息”、“是否查询终端状态信息”和“消息来源”，格式如下所示：

```
IMSI1 LOCATION1 STATUS1 OnHLR1
IMSI2 LOCATION2 STATUS2 OnHLR2
IMSI3 LOCATION3 STATUS3 OnHLR3
IMSI4 LOCATION4 STATUS4 OnHLR4
……
IMSIn LOCATIONn STATUSn OnHLRn
```

IMSIn为6～15位的十进制数字，LOCATIONn、STATUSn、OnHLRn只能为1或0。

行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

****GET TERMSTATE**命令中的ISDNFILE文件格式**

ISDNFILE文件包含“MSISDN”、“是否查询终端位置信息”、“是否查询终端状态信息”和“消息来源”，格式如下所示：

```
ISDN1 LOCATION1 STATUS1 OnHLR1
ISDN2 LOCATION2 STATUS2 OnHLR2
ISDN3 LOCATION3 STATUS3 OnHLR3
ISDN4 LOCATION4 STATUS4 OnHLR4
……
ISDNn LOCATIONn STATUSn OnHLRn
```

ISDNn为1～15位的十进制数字，LOCATIONn、STATUSn、OnHLRn只能为1或0。

行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。
