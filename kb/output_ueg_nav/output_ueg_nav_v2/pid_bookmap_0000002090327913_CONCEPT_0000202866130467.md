# 数据库管理

## 目录内容

- 数据库管理
  - 数据校验
    - 整表校验(STR CRC)
    - 发送CRC校验失败的数据(SND CRCERR)
    - 删除CRC错误数据(RMV CRCERR)
    - 记录校验(CHK DATA)
    - 查询CRC校验失败的数据(LST CRCERR)
    - 设置是否停止最近一次自动CRC校验(SET AUTOCRC)
  - 数据发送
    - 查询超时数据(LST USD)
    - 发送整表数据(SND SPD)
    - 发送超时数据(SND USD)
    - 设置是否显示成功记录(MOD SETRST)
  - 事务模式
    - 停止事务(STP TRAN)
    - 回退事务(RBK TRAN)
    - 开始事务(BGN TRAN)
    - 提交事务(CMT TRAN)
  - 通配符信息
    - 查询通配符值(LST WILDCARD)
  - 试运行模式
    - 取消试运行(CNL TST)
    - 确认试运行(CFM TST)
    - 修改自动确认时间(MOD CMTTM)
    - 查询自动确认时间(LST CMTTM)
    - 回退试运行(RBK TST)
    - 停止试运行(STP TST)
  - 系统参数校验
    - 启动软参CRC校验(STR SPCRC)
  - 开关控制
    - 设置格式化开关(SET FMT)
    - 查询配置开关状态(LST CMSTS)
    - 设置联机状态(LON)
    - 设置脱机状态(LOF)
  - 数据格式化
    - 格式化数据(FMT)
