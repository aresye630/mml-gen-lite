# MPF流策略

## 目录内容

- MPF流策略
  - MTP策略组
    - 查询MTP策略组（LST MTPPOLICYGRP）
    - 增加MTP策略组（ADD MTPPOLICYGRP）
    - 修改MTP策略组（MOD MTPPOLICYGRP）
    - 删除MTP策略组（RMV MTPPOLICYGRP）
  - MTP动作属性
    - 修改MTP动作属性（MOD MTPACTIONPROP）
    - 增加MTP动作属性（ADD MTPACTIONPROP）
    - 查询MTP动作属性（LST MTPACTIONPROP）
    - 删除MTP动作属性（RMV MTPACTIONPROP）
