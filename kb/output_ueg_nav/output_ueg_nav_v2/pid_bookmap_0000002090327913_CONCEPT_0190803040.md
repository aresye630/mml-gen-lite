#### 基本概念

**号码规整**

前转号码有两种格式以及这两种格式号码的组成请参见前转号码格式。登记前转号码时一般输入的都是国内格式的前转号码，但是HLR保存在数据库中和下发到VLR中的前转号码都要是国际格式。因此HLR在收到登记前转号码的请求后，要把它归整为国际格式的号码，保存到数据库中并在逻辑触发时下发到VLR。归整后的前转号码，才能判断它的前转号码属性，比如是否是本地号码、国内长途、国际号码、PLMN号码等。前转号码规整请参见图1。

**前转号码格式**

为手机登记前转号码时，正确的前转号码格式有以下几种：

- 国内号码格式

  - 移动号码（如：13700000001）
  - 本地固话号码（如：28421111）
  - 国内长途前缀 + 区号 + 本地固话号码（如：0 755 28421111）
  - 国内长途前缀 + 区号 + 移动号码（如：0 755 13700000001）
- 国际号码格式

  - 国家码 + 移动号码（如：86 13700000001）
  - 国际号码前缀 + 国家码 + 移动号码（如：00 86 13700000001）
  - 国家码 + 区号 + 本地固话号码（如：86 755 28421111）
  - 国际号码前缀 + 国家码 + 区号 + 本地固话号码（如：00 86 755 28421111）
