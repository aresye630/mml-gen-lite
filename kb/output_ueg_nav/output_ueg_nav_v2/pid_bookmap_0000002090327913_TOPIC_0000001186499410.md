# UDM Bypass管理

## 目录内容

- UDM Bypass管理
  - 退出UDM Bypass
    - 启动会话退出UDM Bypass状态任务（STR SMFEXITUDMBYPASS）
    - 停止会话退出UDM Bypass状态任务（STP SMFEXITUDMBYPASS）
  - UDM Bypass策略管理
    - 查询SMF的UDM全故障Bypass相关功能（LST SMFUDMBYPASS）
    - 设置SMF的UDM全故障Bypass相关功能（SET SMFUDMBYPASS）
  - 查询UDM Bypass会话
    - 显示会话UDM Bypass信息（DSP SMUDMBYPASS）
