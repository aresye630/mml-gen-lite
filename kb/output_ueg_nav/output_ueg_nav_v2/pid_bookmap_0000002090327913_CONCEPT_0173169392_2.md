#### 功能描述

此组命令用于对虚拟运营商进行管理，包括对虚拟运营商的添加、删除、修改、查询操作。实体运营商通过把额外的网络资源划分为多个部分，为其他需要提供电信服务的客户提供资源出租服务。虚拟运营商通过租用实体运营商网络资源，无需组建独立的通信网络，也可以为终端用户提供和实体运营商相似的各种业务服务。

虚拟运营商使不同地区的本地网能够共享一个物理设备，设备维护在物理上统一，而系统维护和用户数据管理在逻辑上分开，支持分权分域管理和按照虚拟运营商提供差异化业务，便于运营商的网络规划和设备维护。虚拟运营商可以减少物理网元的数量，降低运营商设备投资以及设备升级、维护带来的人力投入和费用。

#### 相关概念

**IMEI**

IMEI（International Mobile Equipment Identity）是用于标识每一台GSM（Global System for Mobile Communications）和UMTS（Universal Mobile Telecommunications System）手机的数字，具有唯一性。该标识通常位于手机内部的电池下方，也可以通过在手机中输入字符串（如\*#06#，不同厂商的手机输入的字符串不同，同一厂商不同手机所需输入的字符串也可能不同）来查看该手机的IMEI。IMEI由TAC（Type Approval Code）、FAC（Final Assembly Code）、SNR（Serial Number）及SP组成。IMEISV（International Mobile station Equipment Identity and Software Version）是IMEI的软件版本，由TAC、FAC、SNR及SVN（Software Version Number）四部分组成。其中TAC用于唯一标识无线设备，FAC用于表明生产地或者最后组装地，SNR用于大批量生产的产品上的系列编号，SP为检验码（通常是“0”），SVN用于表明软件版本。

**IMSI**

IMSI（International Mobile Subscriber Identity）是唯一标识一个移动用户的号码，保存在HLR、VLR和SIM卡中，在无线接口及MAP接口上传送。但通常被存放在SIM卡中，由手机发送给网络。IMSI可用于获取存储在本地位置寄存器中的移动用户的其他信息，或复制在当地拜访位置寄存器中。为了防止通过无线接口对用户进行窃听和跟踪，IMSI很少被发送，而是由一个随机生成的TMSI（Temporary Mobile Subscriber Identity）代替发送。IMSI的总长不超过15位数，采用十进制编码。由MCC（Mobile Country Code），MNC（Mobile Network Code）及MSIN（Mobile Subscriber Identification Number）组成。

**MSISDN**

MSISDN（Mobile Station International ISDN Number）是用户为呼叫GSM PLMN（Public Land Mobile Network）中的一个移动用户所需拨的号码。它的总长不超过15位数，采用十进制编码。MSISDN保存在HLR（Home Location Register）和VLR（Visitor Location Register）中，在无线接口及MAP接口上传送，由CC（Country Code）、NDC（National Destination Code）和SN（Subscriber Number）组成。

**简单模式**

简单模式是PGW的一种应用模式，指整个系统只允许存在一个“系统序列号”，处于简单模式下的系统不支持业务层容灾功能。通过将软参“APPLICATIONTYPE（应用模式）”设为“0”将PGW的应用模式设为简单模式。

**完整模式**

完整模式是PGW的另一种应用模式，指整个系统允许存在多个“系统序列号”，处于完整模式下的系统支持业务层容灾功能。通过将软参“APPLICATIONTYPE（应用模式）”设为“1”将PGW的应用模式设为完整模式。
