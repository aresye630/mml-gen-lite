# 事务模式

- 术语解释
- 功能描述
- 注意事项

#### 术语解释

- 事务：事务是OMU的一种运行模式，用户显式开始事务后可以下发一系列的配置命令，然后显式提交该事务，提交事务之前的配置命令不会生效。OMU保证该事务内的配置命令的原子性（所有配置命令要么都被提交，要么都不提交）、一致性（事务模式下能保证OMU配置数据的一致性约束）、隔离性（事务之间是隔离的，由于目前OMU不允许事务并发，因此不必考虑这个特性）和持久性（OMU确保已提交的事务对配置数据的更新是持久的）（即：ACID）。
- 开始事务：用户可以使用**BGN TRAN**命令开始一个事务，执行完该命令后，该网元就进入了事务模式，该客户端对该网元下发的后续配置命令都被作为事务中的一条命令，直到该用户使用**RBK TRAN**回退事务或**CMT TRAN**提交事务为止，admin用户还可以用**STP TRAN**命令强行中止任何用户开始的事务。
- 提交事务：用户使用**CMT TRAN**提交事务，该事务中的配置命令进行修改此时生效，这时会自动进入试运行模式，主机会使用被本事务修改过了的配置数据试运行一段时间以验证配置的正确性，试运行阶段本事务进行修改仍可回退。
- 回退事务：放弃本事务中所做的修改称为事务“回退”，普通用户可以使用**RBK TRAN**回退自己开始的事务，admin用户还可以使用**STP TRAN**命令回退任何用户开始的事务。
- 事务状态转换关系：开始事务后，网元进入事务模式；提交事务后进入试运行模式；回退事务或者由管理员停止事务后进入正常模式。

#### 功能描述

提供配置事务的相关命令。

#### 注意事项

无。
