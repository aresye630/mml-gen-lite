# SPN业务管理

- 命令功能
- 基本概念

#### 命令功能

该组命令用于新增、修改、撤销和查询SPN（Single Personal Number）业务数据，SPN业务与缺省呼叫前转CFD（Call Forwarding Default）业务类似，CFD业务是指当基于某一种基本业务组的CFU业务没有激活且某一种条件前转没有激活时，呼叫将前转到CFD登记的前转号码，从而保证对用户的每一次呼叫都能接通。

SPN业务和CFD业务的主要区别在于MSC的CDR（Charging Data Record）话单，如果用户使用的是SPN业务做的前转，则在MSC话单生成时，会带有SPN的标志位。计费系统会根据CDR话单中的SPN的标志做不同的计费处理。

#### 基本概念

**号码规整**

登记前转号码时一般输入的都是国内格式的前转号码，但是HLR保存在数据库中和下发到VLR中的前转号码都要是国际格式。因此HLR在收到登记前转号码的请求后，要把它归整为国际格式的号码，保存到数据库中并在逻辑触发时下发到VLR。归整后的前转号码，才能判断它的前转号码属性，比如是否是本地号码、国内长途、国际号码、PLMN号码等。前转号码规整请参见图1。

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
