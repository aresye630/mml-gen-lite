# 强制下线操作员 (KIK ONLINEOPR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，强制操作员下线会造成操作员被下线，连接被断开，该操作员正在执行的命令会受到影响，可能会造成业务数据不准确。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于强制下线在线的操作员。

## 注意事项

该命令只支持PGW Web LMT登录的操作员进行操作。

操作员的级别为“ADMINISTRATOR”操作员或通过命令被赋予该命令权限时，才具有执行本命令的权限，可通过执行**LST OPR**命令查看操作员的级别。

当操作员对自己登录用户执行下线操作后，将会直接断开连接。

该命令不允许进行批操作。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                       |
|:-----------|:-------|:-----------------------------------------------------------------------------------------------------------|
| KIKTYPE    | 强制下线方式 | 用于指示系统需要按照哪种方式强制下线在线用户。 取值范围： OPERATOR：表示按照操作员名称强制下线在线用户。 IP：表示按照IP地址强制下线在线用户。 默认值：无。                      |
| SYSNO      | 系统序列号  | 用于指示系统需要按照哪个系统来强制下线在线用户。当“强制下线方式”为“OPERATOR”时，此参数为必选参数。 取值范围：1～255 默认值：无。                                  |
| OPNAME     | 操作员名称  | 用于指示系统需要按照哪个操作员来强制下线在线用户。当“强制下线方式”为“OPERATOR”时，此参数为必选参数。 取值范围：长度不超过32位的字母和数字组成的字符串，且首字符必须为字母。 默认值：无。       |
| SERVERIP   | 服务端IP  | 用于指示系统需要按照哪个服务端IP来强制下线在线用户，服务端IP可以通过LST LINKSTATE命令查找。当“强制下线方式”为“IP”时，此参数为必选参数。 取值范围：有效的IPv4或IPv6地址 默认值：无。 |
| SERVERPORT | 服务端端口  | 用于指示系统需要按照哪个服务端端口来强制下线在线用户，服务端端口可以通过LST LINKSTATE命令查找。当“强制下线方式”为“IP”时，此参数为必选参数。 取值范围：1～65535 默认值：无。        |
| CLIENTIP   | 客户端IP  | 用于指示系统需要按照哪个客户端IP来强制下线在线用户。若不输入，则表示强制下线指定“服务端IP”和“服务端端口”以及“客户端端口”下对应的所有用户。 取值范围：有效的IPv4或IPv6地址 默认值：无。      |
| CLIENTPORT | 客户端端口  | 用于指示系统需要按照哪个客户端端口来强制下线在线用户。若不输入，则表示强制下线指定“服务端IP”和“服务端端口”以及“客户端IP”下对应的所有用户。 取值范围：1～65535 默认值：无。             |

## 使用实例

1. 通过操作员强制下线，“强制下线方式”为“OPERATOR”，“系统序列号”为“9”，“操作员名称”为“admin”，命令如下：

   ```
   KIK ONLINEOPR: KIKTYPE=OPERATOR, SYSNO=9, OPNAME="admin";
   ```

   输出结果如下：

   ```
   %%KIK ONLINEOPR: KIKTYPE=OPERATOR, SYSNO=9, OPNAME="admin";%%
   RETCODE = 0 操作成功

   (结果个数 = 1)

   ---    END
   ```
2. 通过IP强制下线，“强制下线方式”为“IP”，“服务端IP”为“192.168.1.114”，“服务端端口”为“7776”：

   ```
   KIK ONLINEOPR: KIKTYPE=IP, SERVERIP="192.168.1.114", SERVERPORT=7776;
   ```

   输出结果如下：

   ```
   %%KIK ONLINEOPR: KIKTYPE=IP, SERVERIP="192.168.1.114", SERVERPORT=7776;%%
   RETCODE = 0 操作成功

   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                      | 原因分析                      | 处理建议                |
|------:|:---------------------------|:--------------------------|:--------------------|
|  1141 | 无权限执行本命令，请在PGW Web LMT上执行。 | 该命令只能在PGW Web LMT执行。      | 请在PGW Web LMT执行此命令。 |
|  1156 | 同一时刻只能执行一条KIK ONLINEOPR命令。 | 该命令不支持批操作，该命令在同一时刻只能执行一次。 | 请分批执行此命令。           |
