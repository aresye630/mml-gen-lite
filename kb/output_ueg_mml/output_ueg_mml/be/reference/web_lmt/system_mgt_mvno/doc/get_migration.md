# 获取跨分区用户迁移文件（GET MIGRATION）

- 输出结果说明

## 命令功能

该命令用于获取迁移回退失败用户的列表文件或因异常原因终止的用户迁移任务的列表文件。

- 当执行迁移回退任务时，如果存在迁移回退失败的用户，可以通过执行该命令收集回退失败用户列表文件并上传到PGW Web LMT“文件管理器”供工程师下载。
- 当执行迁移任务时，如果存在异常场景，例如模块故障，重启等，可以通过执行该命令收集用户迁移任务的列表文件并上传到PGW Web LMT“文件管理器”供工程师下载。

## 注意事项

- 该命令执行后，通常2分钟内完成列表文件收集。完成后登录文件管理获取列表文件，列表文件名如下：
  - 迁移任务列表文件：**GET MIGRATION**命令开始时间戳\_migration\_任务id\_打包时间戳.tar.gz。
  - 迁移回退任务列表文件：**GET MIGRATION**命令开始时间戳\_rbkMigration\_任务id\_打包时间戳.tar.gz 。

- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                            |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------|
| TASKID | 任务ID   | 可选必选说明：必选参数 参数含义：用于指定需要获取迁移列表文件或迁移回退列表文件的任务ID。 取值范围：1~4294967295。 默认值：无。 配置原则：任务ID需要通过执行DSP MIGRATION命令查询后在此输入。 |

## 使用实例

获取“任务ID”为“5”的跨分区用户迁移任务列表文件。

```
GET MIGRATION: TASKID=5;
```


## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释             | 原因分析                              | 处理建议                                                                                                                  |
|------:|:------------------|:----------------------------------|:----------------------------------------------------------------------------------------------------------------------|
|  1038 | 记录不存在。            | 指定“任务ID”参数时，该任务不存在或者满足条件的任务记录不存在。 | 执行DSP MIGRATION命令查询已存在的“任务ID”后，重新执行本命令获取列表文件。                                                                         |
|  5072 | 该命令只能通过WebLMT接入。  | 通过WebLMT之外的方式访问PGW，执行此命令。         | 请通过WebLMT访问PGW执行该命令。                                                                                                  |
|  5225 | 模块状态异常。           | 指定FE类型下存在故障或异常状态的DMA模块。           | 请在故障或异常模块恢复后重新执行该命令。                                                                                                  |
|  5251 | 不允许对正在运行的任务进行该操作。 | 指定的“任务ID”是正在运行的迁移或回退任务。           | 执行DSP MIGRATION命令查询指定的任务ID，确保该任务的“Status”为“Completed”或“Terminated unexpectedly”或“Terminated manually”后，重新执行本命令获取列表文件。 |
