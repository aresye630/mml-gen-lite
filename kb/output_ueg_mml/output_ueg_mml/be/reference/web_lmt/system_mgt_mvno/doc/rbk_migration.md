# 启动跨分区用户迁移回退任务（RBK MIGRATION）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，执行时会弹出提示：即将执行迁移回退操作，回退过程中可能存在业务呼损，请确认是否继续操作。

该命令用于执行用户迁移回退操作，当用户跨分区迁移过程中出现异常场景需要回退时，执行该命令将已迁出的用户恢复到原来迁出的分区，同时删除已迁移到迁入分区的用户数据。

## 注意事项

- 对系统的影响：
  - 执行该命令进行用户迁移回退操作将影响系统性能，请结合现网资源使用情况通过“CROSSREGIONRBKSPEED（用户跨区迁移回退速度）”软参调整最大迁移回退速率。
- 命令执行成功需要满足以下条件：
  - 周期性校验开关已关闭，包括软参“FWDRTVFYSWT（正向路由校验开关）”、“REVVFYSWT（反向校验开关）”、“FWDVFYSWT（正向校验开关）”、“REVRTVFYSWT（反向路由校验开关）”取值设置为“0”。
  - 用户数据统计开关已关闭，即软参“USERDATAMEASUREFLAG（定时用户数据统计开关）”取值设置为“0”。
  - 周期性备份开关已关闭，即软参“TIMEBACKUPFLAG（定时备份开关）”取值设置为“0”。
  - 局间复制开关已打开，即软参“REDUNDANCYSWITCH（容灾开关）”取值设置为“0”或“1”。
  - 批操作挂起开关已打开，即软参“BATSUSPENDSWITCH（批操作挂起开关）”取值设置为“1”。
  - 支持混合组网的目标态组网。即软参“NETWORKMODE（组网模式）”取值设置为“2”。
  - 在主用局执行该命令，非主用局不允许执行迁移回退操作。
  - 命令指定FE类型下是否有故障状态的DMA/DSG/DRU/DSU模块，若存在故障状态的模块，则不允许启动迁移回退操作。
  - 没有跨分区迁移或回退任务，或者局内迁移任务正在运行，如果有，则不允许再执行迁移回退任务。
  - 当前组网是混合组网，非混合组网不支持迁移回退操作。
  - 用户数据导出任务正在运行，不允许执行迁移回退任务。
  - 不允许在升级状态下执行用户迁移回退操作。
  - 检查当前是否处于接管状态，若处于接管状态则报错。
  - 如果存在迁移回退失败的用户，可以通过执行**GET MIGRATION**命令收集回退失败用户列表文件并上传到PGW WebLMT“文件管理器”供工程师下载。

- 该命令不允许进行批操作。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                  |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------|
| TASKID  | 任务ID   | 可选必选说明：必选参数 参数含义：用于指定需要执行用户迁移回退的任务ID。 取值范围：1~4294967295。 默认值：无。 配置原则：任务ID需要通过执行DSP MIGRATION命令查询后在此输入。                                                |
| ISFORCE | 是否强制回退 | 可选必选说明：可选参数 参数含义：用户迁移回退时，可能因为路由冲突导致用户迁移回退失败，针对这种因为路由冲突的场景，如果选择YES，则用户会强制回退成功，然后通过异常路由校验修正路由；如果选择NO，则用户回退失败。 取值范围： YES：表示强制回退NO：表示不强制回退 默认值：无。 配置原则：无。 |

## 使用实例

当需要执行迁移回退任务，“任务ID”为“1”时。

```
RBK MIGRATION: TASKID=1;
```

```
%%RBK MIGRATION: TASKID=1;%%
RETCODE = 0 操作成功

There is together 1 report

---    END
```
