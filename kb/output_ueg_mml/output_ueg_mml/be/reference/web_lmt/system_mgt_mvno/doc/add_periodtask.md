# 添加周期性任务（ADD PERIODTASK）

- 命令功能

## 命令功能

**须知** 

该命令属于高危命令，添加周期性任务可能造成系统过载，影响业务的正常功能。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于添加一个周期性任务。

该命令的使用场景：当需要周期性执行MML命令时，可通过本命令进行添加或启动。

## 注意事项

- 该命令仅支持通过PGW Web LMT接入。
- 该命令仅支持超级管理员、ADMINISTRATOR级别的操作员和CUSTOM级别的操作员执行。
- 当前版本仅支持将**EXC OML**或**STR CMPDB**命令添加到周期性任务中。
- 同一个“FE类型”下，相同的**EXC OML**或**STR CMPDB**命令最多只能添加一个。
- 系统只允许在容灾局执行本命令。
- 若系统处于升级实施阶段（即软参“UPGRADESTATUS（升级状态）”取值为“2”）时，周期性任务不会被主动拉起。
- 执行本命令前，需要提前申请“数据异常智能检测和修复”License。
- 执行本命令时，将不可避免的涉及到用户的个人数据，因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护，并在操作完成后及时清理结果文件。
- 任务启动时间的设置使用的是CSP系统时间而不是本地时间，如果PGW Web LMT和CSP不在同一个时区，PGW Web LMT添加周期性任务的任务启动时间需折算成CSP的系统时间。
- 当任务启动时间位于夏令时跳变的时间范围内，任务启动时间以夏令时跳变结束后的时间为准。例如夏令时从4点跳到5点，设置任务启动时间为4点30分，系统会将任务启动时间修正为5点。
- 当任务启动时间设置于夏令时跳出的区域，系统会将任务启动时间作为夏令时时间处理。例如退出夏令时时，系统时间从5点跳回到4点，代表这天会有两个4点30分，设置任务启动时间为4点30分，系统只会在第一次经过4点30分运行任务。
- 当任务启动时间设置在夏令时跳出时间点，则任务将在跳出夏令时后的该时间点启动。例如夏令时跳出时间点为5:00，跳变到4:00，则设置为5:00的任务在第一次到达5:00后不会被执行，系统时间从4:00再次到5:00时才会被执行。
- 在OM Portal“CSP MML命令”界面使用**SET TZ**命令修改系统时区或夏令时，会导致之前配置的周期性任务不在预期时间进行启动，此种情况需重新设置历史任务的第一次启动时间，详细设置方法请联系华为工程师。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
|:-----------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TASKID     | 任务ID   | 可选必选说明：必选参数。 参数含义：用于指定周期性任务的任务ID。 取值范围：1～512。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                     |
| FETYPE     | FE类型   | 可选必选说明：必选参数。 参数含义：用于指定添加哪个FE类型的周期性任务。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：此参数在USCDB下唯一，通过“MML命令行 - USCDB”的LOD FEPLUG命令加载FE插件后在此引用。                                                                                                                                                                                                                                                                                                                                    |
| CMD        | MML命令  | 可选必选说明：必选参数。 参数含义：用于指定周期性任务中的MML命令。 取值范围：长度不超过512的字符串。 默认值：无。 配置原则： 如果MML命令中存在“'”字符，则需要输入转义字符“/q”。如果MML命令中存在“=”字符，则需要输入转义字符“/e”。如果MML命令中存在“,”字符，则需要输入转义字符“/c”。如果MML命令中存在“;”字符，则需要输入转义字符“/s”。如果MML命令中存在“\"”字符，则需要输入转义字符“/Q”。如果MML命令中存在“/”字符，则需要输入转义字符“//”。                                                                                                                                                                                                        |
| TASKTYPE   | 任务类型   | 可选必选说明：必选参数。 参数含义：用于指定周期性任务的任务类型。 取值范围： ONCE：一次性任务 CYCLE：周期性任务 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                    |
| CYCLEUNIT  | 周期单位   | 可选必选说明：条件必选参数。 参数含义：用于指定任务执行周期的单位。 取值范围： HOUR：小时 DAY：天 WEEK：周 MONTH：月 MONTHLASTDAY：月末最后一天  说明： 当“周期单位”为“MONTHLASTDAY”时，如果当天不是月末最后一天，请输入“任务启动时间”并设置为月末最后一天的时间，否则会导致周期性任务第一次启动时间不是月末最后一天。 默认值：无。 配置原则： 仅当“任务类型”参数取值为“CYCLE”时该参数有效。该参数和“周期值”一起确定任务周期的时长。例如“周期单位”设置为“小时”，“周期值”设置为“2”，则表示从“任务启动时间”起，每隔2个小时执行一次任务。                                                                                                                                                     |
| CYCLEVALUE | 周期值    | 可选必选说明：条件必选参数。 参数含义：用于指定周期性任务的执行周期。 取值范围：1～128。 默认值：无。 配置原则： 仅当“任务类型”参数取值为“CYCLE”且“周期单位”取值为“HOUR”、“DAY”、“WEEK”、“MONTH”或“MONTHLASTDAY”时该参数有效。该参数和“周期单位”一起确定周期性任务周期的时长。例如，“周期单位”设置为“小时”，“周期值”设置为“2”，则表示从“任务启动时间”起，每隔2个小时执行一次任务。                                                                                                                                                                                                                                    |
| TIME       | 任务启动时间 | 可选必选说明：可选参数。 参数含义：用于指定周期性任务的启动时间。 取值范围：晚于当前命令提交执行的时间至少1分钟，格式为YYYY&MM&DD&HH&MM&SS。 默认值：无。 配置原则： 当“任务类型”参数设置为“ONCE”时：当该参数输入时，表示该任务为定时任务。在时间未到时，任务不会启动，时间到则执行一次该任务。 当该参数不输入时，表示立即执行该任务且只执行一次。 当“任务类型”参数设置为“CYCLE”时，表示该任务为周期性任务。当该参数输入时，表示该周期性任务的第一次启动时间，可以使用DSP OML或DSP CMPDB获取本周期执行任务的任务状态。当本周期的任务“STATUS”为“COMPLETED”，“ABNORMAL”或“ABORTED”时，则生成下一个周期任务，生成的周期任务相当于一次定时任务。可以使用STP OML或STP CMPDB单独停止本周期任务，单独停止一个周期任务，并不影响下一个周期的任务执行。 当该参数不输入时，该周期性任务的第一次启动时间为当前系统时间。 |
| DESC       | 任务描述   | 可选必选说明：可选参数。 参数含义：用于描述任务的信息。 取值范围：由数字(0～9)、字母(a～z和A～Z)、空格和下划线组成的不超过128位的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                      |

## 使用实例

1. 添加一个一次性任务。
   - “任务ID”为“3”
   - “FE类型”为“USCDB”
   - “MML命令”为“EXC OML: FETYPE/e/QUSCDB/Q/c OBJNAME/e/QPGW\_PERIODTASK\_SUMMARY/Q/c OML/e/Qselect \* from PGW\_PERIODTASK\_SUMMARY/Q/s”
   - “任务类型”为“一次性任务”
   - “任务描述”为“EXC OML PERIOD TASK”

   ```
   ADD PERIODTASK: TASKID=3, FETYPE="USCDB", CMD="EXC OML: FETYPE/e/QUSCDB/Q/c OBJNAME/e/QPGW_PERIODTASK_SUMMARY/Q/c OML/e/Qselect * from PGW_PERIODTASK_SUMMARY/Q/s", TASKTYPE=ONCE, DESC="EXC OML PERIOD TASK";
   ```
2. 添加一个周期性任务。
   - “任务ID”为“2”
   - “FE类型”为“SUP-FE”
   - “MML命令”为“STR CMPDB: FETYPE/e/QSUP-FE/Q/c FDBTYPE/eCUR/c TABLENAME/e/QSUID\_DATA/Q/c FIELDNAME/e/QSUID/Q/c KEYTYPE/e/QSUID/Q/s”
   - “任务类型”为“周期性任务”
   - “周期单位”为“天”
   - “周期值”为“2”
   - “任务描述”为“STR CMPDB PERIOD TASK”

   ```
   ADD PERIODTASK: TASKID=2, FETYPE="SUP-FE", CMD="STR CMPDB: FETYPE/e/QSUP-FE/Q/c FDBTYPE/eCUR/c TABLENAME/e/QSUID_DATA/Q/c FIELDNAME/e/QSUID/Q/c KEYTYPE/e/QSUID/Q/s", TASKTYPE=CYCLE, CYCLEUNIT=DAY, CYCLEVALUE=2, DESC="STR CMPDB PERIOD TASK";
   ```
