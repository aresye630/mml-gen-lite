# 删除指定命令的白名单参数(RMV SOAPRPTPARA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，删除指定命令的白名单参数列表会造成PGW和营帐系统对接失败。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除指定命令的白名单参数的配置数据。

## 注意事项

- 删除指定命令的白名单参数列表会造成PGW和营帐系统对接失败，请谨慎执行本命令。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                     |
|:--------|:-------|:-------------------------------------------------------------------------|
| CMDNAME | 命令名    | 标识一条指定命令白名单参数记录的关键字段，用于指定需要删除哪一条命令的白名单参数记录，操作员可以使用LST SOAPRPTPARA命令查询获得。 |

## 使用实例

删除“命令名”为“CHK CONBATSTAT”的记录。

```
RMV SOAPRPTPARA: CMDNAME="CHK CONBATSTAT";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释   | 原因分析                         | 处理建议                                                 |
|------:|:--------|:-----------------------------|:-----------------------------------------------------|
|  1004 | 无效的参数值。 | 输入的参数值不在其取值范围内或者输入的参数值不符合要求。 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                     |
|  1038 | 记录不存在。  | 输入的“命令名”参数所对应的记录不存在。         | 请确保输入的“命令名”参数所对应的记录存在。已存在的记录可以通过LST SOAPRPTPARA命令查询。 |
