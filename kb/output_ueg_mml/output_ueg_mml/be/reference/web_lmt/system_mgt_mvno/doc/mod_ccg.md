## 命令功能

**须知** 

该命令属于高危命令，修改命令组会造成操作员失去或者增加一些命令的执行权限，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改命令组中包含的命令（弹出的窗口中已经被勾选的命令）。系统可以通过本命令添加和删除命令组中的命令，其中要添加的则选中，要删除的则不选。

## 注意事项

- 软参“OPRCMDGMGRSWT”取值为“1”时，只有ADMINISTRATOR级别的操作员具有本命令的操作权限。软参“OPRCMDGMGRSWT”取值为“0”时，ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员具有本命令的操作权限。
- 如果执行该命令在已有的命令组中增加系统序列号管理、虚拟运营商管理、虚拟运营商号段管理中除了**LST OPRRANGE**以外的命令，在将此命令组赋给操作员时要慎重考虑，该操作员拥有此命令组中命令的权限后，将等同于admin的执行权限，可对系统序列号、虚拟运营商、虚拟运营商号段进行相应的管理。
- 软参“OPRCMDGMGRSWT”取值为“1”时，修改后的“命令组”对应的“命令名”中，不允许包含权限管理方面的命令，即不允许包含**ADD CCG**、**RMV CCG**、**MOD CCG**、**LST CCG**、**SET CCGN**或**LST CCGN**。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                    |
|:-------|:-------|:------------------------------------------------------------------------|
| SYSNO  | 系统序列号  | 标识一条命令组数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪一个命令组进行修改或调整，操作员可以使用LST CCG命令查询获得。 |
| CG     | 命令组    | 标识一条命令组数据记录的关键字段之一，用于指定需要对哪一条命令组的数据记录进行修改或调整，操作员可以使用LST CCG命令查询获得。      |
| CMD    | 命令名    | 用于说明命令集合的命令名，命令集合中命令与命令之间使用&连接。                                         |

## 使用实例

系统通过本命令修改命令组，其“SYSNO”为“1”，“CG”为“G\_8”，“CMD”为“LST\_LOG”：

```
MOD CCG: SYSNO=1, CG=G_8, CMD=LST_LOG;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                                    | 原因分析                                                                                                                                       | 处理建议                                                          |
|------:|:-----------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------|
|  5246 | 当前OPRCMDGMGRSWT开关已打开，不允许给帐号分配权限管理方面的命令组。 | 软参“OPRCMDGMGRSWT”取值为“1”时，修改的“命令组”对应的“命令名”中，包含了权限管理方面命令，即包含了ADD CCG、RMV CCG、MOD CCG、LST CCG、SET CCGN或LST CCGN。                              | 软参“OPRCMDGMGRSWT”取值为“1”时，重新执行该命令，确保修改的命令组对应的命令名中不包含权限管理方面的命令。 |
|  1006 | 没有权限执行此命令。                               | 当前操作员没有操作权限。 软参“OPRCMDGMGRSWT”取值为“1”时，只有ADMINISTRATOR级别的操作员具有本命令的操作权限。软参“OPRCMDGMGRSWT”取值为“0”时，ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员具有本命令的操作权限。 | 建议使用更高级别或者拥有该命令执行权限的帐号处理。                                     |
