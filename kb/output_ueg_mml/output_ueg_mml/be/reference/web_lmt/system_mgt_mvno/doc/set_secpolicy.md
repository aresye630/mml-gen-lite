## 命令功能

**须知** 

该命令属于高危命令，如果禁用账号锁定功能和密码安全策略，将会带来安全风险。因此执行该命令前，需要与华为技术支持确认后才可以实施。

本命令用于设置PGW Web LMT和DMS WebUI的安全策略。

当USCDB与业务发放系统均完成硬件数据和基础数据的配置后，需要配置PGW Web LMT和DMS WebUI的安全策略。PGW Web LMT和DMS WebUI的安全策略包括以下两个方面：

- 完善的密码安全措施，通过限制登录次数和返回固定错误消息等方式防止非授权人员进行密码暴力破解、非授权人员非法接入系统和密码遭盗窃。
- 用户登录PGW Web LMT和DMS WebUI时的安全性检查和配置，用于防止非法用户登录PGW Web LMT和DMS WebUI，保证系统的安全访问。

具有该命令权限的操作员包括：

- ADMINISTRATOR管理员。
- 通过**ADD OPR**命令添加为ADMINISTRATOR级别的操作员。
- 通过**ADD CCG**命令添加具有本命令权限的命令组，然后通过**ADD OPR**命令将已具有本命令权限的命令组添加给CUSTOM级别的操作员。

## 注意事项

- ADMINISTRATOR级别的操作员或被赋予该命令权限的操作员才具有本命令的操作权限。
- 系统默认启用系统安全策略。如果操作员选择非安全的配置，将会带来安全风险，请谨慎操作。
- 该命令设置成功后，针对所有用户生效，不区分用户级别。
- 对于低版本升级上来的账号，账号类型默认为人机、机机账号合一，存在安全风险，系统会上报“ALM-10031 系统存在不安全的配置项”告警。故必须使用**MOD OPR**命令将其账号类型修改为“人机账号”或“机机账号”。
- 密码长期使用会增加被盗窃和破解的风险，而且使用的时间越长，被盗窃和破解的风险越高。定期修改密码可以有效防范这种情况的发生，因此强烈建议您定期修改密码。

## 参数说明

| 参数标识            | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                    |
|:----------------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OPLCK           | 账号锁定功能     | 用于设置系统是否具有帐号锁定功能。帐号被锁定后，可以在超过本命令设置的“帐号锁定时间”后由系统自动解锁，也可以由ADMINISTRATOR级别的操作员手工解锁。 各参数选项的含义是：TRUE：启用帐号锁定功能，选中该选项后，如果操作员连续尝试登录PGW Web LMT和DMS WebUI客户端失败，系统将对该操作员帐号进行锁定，在“帐号锁定时间”范围内无法再次登录，可有效防止非授权人员非法接入系统。FALSE：关闭帐号锁定功能，选中该选项时，操作员可以一直尝试登录PGW Web LMT和DMS WebUI客户端，无法保证系统安全，请不要关闭。 默认值：无。 系统初始设置值：TRUE。 |
| TRYTIME         | 密码尝试次数     | 用于设置操作员可以连续尝试登录的最大次数。当登录失败次数达到该限制时，帐号将被自动锁定。 取值范围：1～5（次） 默认值：5次。 系统初始设置值：5次。                                                                                                                                                                                                                            |
| CLEAR           | 密码错误次数超时清零 | 用于设置在一定时间后将操作员登录时“密码尝试次数”的记录清零。 各参数取值的含义是：TRUE：对操作员登录失败次数超时后清零。FALSE：对操作员登录失败次数超时后不清零。 默认值：无。 系统初始设置值：TRUE。                                                                                                                                                                                             |
| INTERVAL        | 超时时间间隔     | 用于设置操作员尝试登录次数范围内的时间间隔，若在该时间范围内，操作员登录失败次数达到“密码尝试次数”，系统将锁定操作员帐户；而在超过该时间后，操作员登录失败次数未达到“密码尝试次数 ”，系统将操作员之前登录失败次数记录清零。 取值范围：1～60（分钟） 默认值：无。 系统初始设置值：10分钟。                                                                                                                                                     |
| AUTOUNLCK       | 支持超时自动解锁   | 用于设置帐号被锁定后是否支持超时自动解锁。 各参数取值的含义是：TRUE：启用超时自动解锁，操作员在连续尝试登录失败后帐号被系统自动锁定，在超过“超时时间间隔”之后，操作员登录触发自动解锁。FALSE：关闭超时自动解锁，操作员在连续尝试登录失败后被系统自动锁定，需向ADMINISTRATOR级别操作员申请手工解锁。 默认值：无。 系统初始设置值：TRUE。                                                                                                                     |
| LCKTIME         | 账号锁定时间     | 用于设置帐号因在“超时时间间隔”范围内，登录失败次数超过“密码尝试次数”而被锁定的时间。如果“支持超时自动解锁”参数取值为“TRUE”，则当操作员帐号在超出该时间限制后，系统会自动解锁该帐户。 取值范围：1～1440（分钟） 默认值：无。 系统初始设置值：30分钟。                                                                                                                                                                   |
| SECURITY        | 密码安全策略     | 用于设置是否启用密码安全策略。 各参数取值的含义是：TRUE：启用密码安全策略，可有效防止非法授权人员非法接入系统，从而有效保护系统安全。FALSE：关闭密码安全策略，密码策略过于简单，容易被非法授权人员破解密码后非法接入，存在安全隐患，请不要关闭。 默认值：无。 系统初始设置值：TRUE。                                                                                                                                                      |
| FSTLOG          | 修改初始密码     | 用于设置是否修改操作员帐户的初始密码。 各参数取值的含义是：TRUE：修改初始密码。产品文档的《安全管理描述》手册有各帐户初始密码的说明，请操作员在完成软件调测后，修改帐户的初始密码，以保证帐户的安全。FALSE：不修改初始密码。 默认值：无。 系统初始设置值：TRUE。                                                                                                                                                                |
| HISRECORD       | 历史密码记录保留个数 | 用于设置历史密码的保留个数。设置的新密码不能与保留的历史密码相同。 取值范围：0～10（个） 默认值：无。 系统初始设置值：5个。                                                                                                                                                                                                                                       |
| MINLEN          | 人机密码最小长度   | 用于设置人机帐户的最小密码长度。密码长度太短，容易被非法授权人员破解，然后非法接入系统。密码长度太长，不容易记忆。请根据实际情况，设置一定长度的密码，以保证帐户安全。 取值范围：8～64 默认值：无。 系统初始设置值：10。                                                                                                                                                                                        |
| MMMINLEN        | 机机密码最小长度   | 用于设置机机帐户的最小密码长度。 取值范围：16～64 默认值：无。 系统初始设置值：16。                                                                                                                                                                                                                                                          |
| COMPLEX         | 密码复杂度      | 用于设置密码的复杂度。设置合理复杂度的密码，可有效防止帐户密码被非法授权人员破解。 取值范围如下，可复选：CHAR：密码包含字符集。NOID：密码不得包含帐户ID，同时也不允许为帐户ID的逆序形式且不区分大小写的各种组合。例如：帐户ID为ABC，则密码不能包含ABC、CBA、Abc、abc、cba、Cba等字符串。NOORD：密码不允许为顺序字符串。 默认值：无。 系统初始设置值：包含字符集+不包含帐户ID+不允许顺序字符串。                                                                                 |
| CNUMS           | 密码字符集组合数   | 用于修改密码时设置密码至少包含的字符集组合的个数。例如，该参数设置为3，“密码字符集”选择为“LOWER”和“NUMBER”只有2个子项，则命令执行失败。操作员登录PGW Web LMT时，密码字符集组合数不受该参数限制。 取值范围：1～4（个） 默认值：无。 系统初始设置值：3个。                                                                                                                                                          |
| CHARTYPE        | 密码字符集      | 用于设置密码包含的字符集。 各参数取值的含义是：UPPER：大写字母LOWER：小写字母NUMBER：数字SPECIAL：特殊字符，是指` ~ ! @ # $ % ^ * ( ) _ + - { } | [ ] : > ? . \ / （包含空格）。 默认值：无。 系统初始设置值：大写字母+小写字母+数字+特殊字符。                                                                                                                                         |
| TIMEMOD         | 密码有效期策略    | 用于设置是否对密码的有效期进行限制。 参数取值的含义是：TRUE：启用，选中该选项后，帐户的密码在到达“密码有效期天数”后将会失效，必须重新修改密码后才能重新登录PGW Web LMT和DMS WebUI。FALSE：关闭，选中该选项时，帐号的密码可以一直有效。 默认值：无。 系统初始设置值：FALSE。                                                                                                                                               |
| VALIDDAY        | 密码有效期天数    | 用于设置密码的有效期天数。 取值范围：1～180（天） 默认值：无。 系统初始设置值：90天。                                                                                                                                                                                                                                                         |
| PROMPTDAY       | 密码过期前提示天数  | 用于设置系统提示操作员帐户密码过期前的天数。当操作员帐户的密码有效天数小于等于该时间，在操作员每次登录PGW Web LMT和DMS WebUI系统时，系统将会提示操作员修改密码。 取值范围：1～30（天） 默认值：无。 系统初始设置值：5天。                                                                                                                                                                              |
| CONTSAMECHARNUM | 相同字符连续个数限制 | 用于设置密码相同字符连续个数限制。密码不允许有大于或等于此参数取值个数的连续相同字符，大小写敏感。例如，本参数设定为3，密码如果为包含AAA的字符串，则密码检查不通过。 取值范围：2～32 默认值：无。 系统初始设置值：3。                                                                                                                                                                                        |
| SHOWBANNER      | 显示Banner   | 用于设置操作员每次成功登录PGW Web LMT和DMS WebUI系统时，是否显示设置的Banner信息。 取值范围： TRUE：登录成功时显示设置的banner信息。FALSE：登录成功时不显示任何banner信息。 默认值：无。 系统初始设置值：TRUE。                                                                                                                                                                     |
| BANNERINFO      | Banner信息   | 仅当“显示Banner”参数取值为“是”时该参数有效，用于设置操作员每次成功登录PGW Web LMT和DMS WebUI系统时，界面显示的Banner信息。 当“显示Banner”由“FALSE”修改为“TRUE”时，需要重新设置该参数值，成功登录PGW Web LMT和DMS WebUI系统后才会显示设置的Banner信息。 当“显示Banner”为“TRUE”且不输入该参数时，成功登录PGW Web LMT和DMS WebUI系统后不会显示Banner信息。 默认值：无。 系统初始设置值：无。                                            |

## 使用实例

完成软件调测后，ADMINISTRATOR操作员设置帐户和密码策略，“帐户锁定功能”为“TRUE”，“密码安全策略”为“TRUE”，命令如下：

```
SET SECPOLICY: OPLCK=TRUE, SECURITY=TRUE;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                          | 原因分析                                        | 处理建议                                     |

|  1076 | 密码过期前提示天数必须小于等于密码有效期天数。        | 输入的“密码过期前提示天数”必须小于等于“密码有效期天数”，否则密码过期提示没有意义。 | 输入的“密码过期前提示天数”小于“密码有效期天数”，然后重新执行本命令。     |
|  1081 | 密码复杂度选择字符集时，密码字符集组合数和密码字符集才有效。 | 当“密码复杂度”选择“CHAR”时，“密码字符集组合数”和“密码字符集”才有效。    | “密码复杂度”选择“CHAR”，然后执行本命令。                 |
|  1082 | 密码字符集组合数不能大于密码字符集选择的子项数。       | 输入的“密码字符集组合数”不能大于“密码字符集”选择的子项数。             | 输入“密码字符集组合数”小于等于“密码字符集”选择的子项数，然后重新执行本命令。 |
