## 命令功能

**须知** 

该命令属于高危命令，指定用户数据在线恢复属于高危动作，如果指定用户数据有误会导致用户数据脏写。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为维护命令，用于在线恢复指定用户或指定用户列表的内存库数据。管理员可通过**DSP DB**命令查看内存库数据在线恢复任务，**STP RCVDB**终止内存库数据在线恢复任务。

该命令主要用于紧急数据恢复场景，当现网存在用户数据异常或脏读脏写的情况时，为内存库数据紧急恢复提供在线恢复手段。

**说明** 

该命令支持恢复由于误操作删除的用户数据。

## 注意事项

- 在线恢复内存库数据，以历史FDB数据为准，历史到当前的增量数据（如信令动态数据，营帐增量数据）会被丢弃，执行该命令前需要联系华为技术支持。
- 执行该命令前，需要通过**BKP DB**命令备份内存库数据，将文件备份到本地或紧急恢复目录。
- “用户号码”或“用户列表文件名”是可选参数，必须有且只能有一个参数出现。
- 当正在通过**BKP DB**命令下发内存数据库整局批量备份任务时，或当系统周期性备份开关打开（即软参**TIMEBACKUPFLAG（定时备份开关）**取值为“1”），系统开始定时备份内存数据库时，不能同时执行本命令进行内存库数据在线恢复任务。
- 当正在通过**ADD EXPTASK**命令下发的导出任务时，不能同时执行本命令进行内存库数据在线恢复任务。
- 当正在通过**EXC OML**命令下发内存库数据操作任务时，不能同时执行本命令进行内存库数据在线恢复任务。
- 当正在通过**STR CMPDB**命令下发启动数据比对分析任务时，不能同时执行本命令进行内存库数据在线恢复任务。
- 当进行在线恢复指定用户列表的内存库数据任务时，指定用户列表中的用户数不能超过“RCVUSERLISTNUM（在线指定用户指定表数据恢复的单次最大用户列表指定数量）”软参设置的值，且恢复数据时是按照用户列表中实际用户进行恢复。
- 当进行在线恢复指定用户列表的内存库数据任务时，系统通过“RCVUSERSPEED（在线指定用户指定表数据恢复的恢复速率）”软参的取值控制恢复的速率。如果速率设置过快会引起CPU占用率过大，导致系统流控，产生业务呼损。
- 当系统正在进行升级操作时，不能同时执行本命令进行内存库数据在线恢复任务。
- 执行本命令时，将不可避免的涉及到用户的个人数据，因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护，并在操作完成后及时清理结果文件。
- 该命令仅支持通过PGW Web LMT接入。
- 系统将恢复的结果文件打包成RCV\_DB\_RESULT\_YYYYMMDDHHMMSS.tar.gz格式，存放置到文件管理器。系统最多保留50份，超过数量的旧文件将会被自动删除。
- 该命令仅支持超级管理员、ADMINISTRATOR级别的操作员和CUSTOM级别的操作员执行。
- RCV DB会将备份数据加载至正在提供业务的数据库，执行会使用户数据被恢复至历史时刻，丢失动态数据和增量数据。执行该命令前，需要与华为技术支持确认后才可以实施。
- 执行本命令时，需设置软参“RCVDBEXECSW（RCV DB命令执行开关）”的取值为“1”。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                        |
|:------------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FDBTYPE     | FDB类型   | 可选必选说明：必选参数 参数含义：用于标识恢复备份FDB文本信息的源数据。 取值范围： CUR：获取最近一次备份数据作为修改源，一般指获取最近一小时的备份数据。NEW：获取次新一次备份数据作为修改源，一般指获取当天凌晨的备份数据。OLD：获取最老的一次备份数据作为修改源，一般指获取昨天凌晨的备份数据。 EMG: 采用紧急恢复目录中最新的一份备份数据作为修改源。紧急恢复目录路径为/opt/uscdb/emgRst。 默认值：无。 配置原则：无。                                                                                             |
| TABLENAME   | 表对象名称   | 可选必选说明：可选参数 参数含义：用于指定表名称，实际对应一颗用户树的节点。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                    |
| SERVICETYPE | 业务类型    | 可选必选说明：必选参数 参数含义：用于指定恢复局点的业务类型。 取值范围：长度不超过128字符。 默认值：无。 配置原则：此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。                                                                                                                                                                                                                        |
| KEYTYPE     | 键值类型    | 可选必选说明：必选参数 参数含义：用于指定查找用户键值的类型，该键值只支持指定辅键。 取值范围：长度不超过128的字符。 默认值：无。 配置原则：该参数的取值与业务类型有关，需要与对应业务类型的键值类型保持一致。                                                                                                                                                                                                                  |
| UN          | 用户号码    | 可选必选说明：可选参数 参数含义：用于指定一个待恢复的用户号码。 取值范围：长度不超过1536字符。  说明： 用户号码需要加双引号。 默认值：无。 配置原则： “用户号码”和用户列表文件名是条件参数，两者有且只能出现一个。如果该参数中存在“\"”字符，则需要输入转义字符“/Q”。                                                                                                                                                                               |
| USERFILE    | 用户列表文件名 | 可选必选说明：可选参数 参数含义：用于指定待恢复的用户列表文件名。 取值范围：长度不超过128的字符串，可由字母、数字或字符“_”、“.”组成。数据文件支持“.txt”一种格式，数据文件不能超过512M。  说明： 用户列表文件内容格式：每行一个用户的号码即用户的辅键键值，如中间遇到空行则跳过。用户号码都需要加双引号。 默认值：无。 配置原则： “用户号码”和用户列表文件名是条件参数，两者有且只能出现一个。该参数指定的用户数不能超过“RCVUSERLISTNUM（在线指定用户指定表数据恢复的单次最大用户列表指定数量）”软参限制。用户列表文件必须在执行本命令之前通过PGW Web LMT客户端上的“文件管理器”上传到PGW。 |
| RCVMODE     | 恢复模式    | 可选必选说明：可选参数 参数含义：用于指定恢复模式。 取值范围： MERGEMODE：合并模式，即将内存库数据与FDB数据进行合并处理，如果内存库中数据比FDB中数据多，内存库中多的数据仍保留。REPLACEMODE：替换模式，即以FDB数据为准恢复内存库数据，如果内存库中数据比FDB中数据多，内存库中多的数据将被删除。 默认值：MERGEMODE 配置原则：无。                                                                                                                                     |

## 使用实例

指定用户指定表的在线恢复任务。

- “FDB类型”为“CUR”
- “表对象名称”为“AUC1\_DATA”
- “FE业务类型”为“SUP-FE”
- “键值类型”为“AUC1”
- “用户列表文件名”为“1.txt”

```
RCV DB: FDBTYPE=CUR, TABLENAME="AUC1_DATA", SERVICETYPE="SUP-FE", KEYTYPE="AUC1", USERFILE="1.txt";
```
