# 添加指定命令的白名单参数(ADD SOAPRPTPARA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于添加指定命令的白名单参数。PGW在组装SOAP报文时，根据“命令名”参数在全局数据中查找该命令的白名单参数，如果当前命令配置了白名单参数，则SOAP报文里只组装白名单里指定的参数。

## 注意事项

- 当命令配置文件中GROUP的“displayforsoap”属性为“false”时，即使执行该命令将GROUP下的参数添加为了白名单参数，SOAP报文里也不组装GROUP下的参数。命令配置文件中GROUP的“displayforsoap”属性取值可联系华为技术支持查看。
- 请在华为技术支持指导下执行该命令。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                              |
|:---------|:-------|:------------------------------------------------------------------------------------------------------------------|
| CMDNAME  | 命令名    | 用于指定添加白名单参数的命令的命令名。 取值范围：长度不超过64的字符串。 默认值：无。                                                                      |
| PARALIST | 参数列表   | 用于指定白名单参数的参数列表。 配置原则：该参数的值由“命令名”参数指定命令的输出参数组成，不同的输出参数以“&”符号作为分隔符进行分隔。详细配置原则请联系华为技术支持。 取值范围：长度不超过16000的字符串。 默认值：无。 |

## 使用实例

为“命令名”为“CHK CONBATSTAT”命令添加白名单参数，“参数列表”为“TASK ID&HLR INDEX&OPERATOR NAME&START TIME&END TIME&STATUS&TOTAL&EXECUTED&MML CMD&NODATA”。

```
ADD SOAPRPTPARA: CMDNAME="CHK CONBATSTAT", PARALIST="TASK ID&HLR INDEX&OPERATOR NAME&START TIME&END TIME&STATUS&TOTAL&EXECUTED&MML CMD&NODATA";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释   | 原因分析                         | 处理建议                                                          |
|------:|:--------|:-----------------------------|:--------------------------------------------------------------|
|  1004 | 无效的参数值。 | 输入的参数值不在其取值范围内或者输入的参数值不符合要求。 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                              |
|  1037 | 记录已存在。  | 输入的“命令名”和“参数列表”参数所对应的记录已经存在。 | 执行LST SOAPRPTPARA命令查询已存在的记录，重新执行本命令添加新的配置，确保新添加的记录与查询到的记录不重复。 |
