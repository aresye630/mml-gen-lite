# 修改系统序列号（MOD SYSNO）

## 命令功能

**须知** 

该命令属于高危命令，修改系统序列号可能会造成该系统序列号下所有操作员、号段等信息不可用。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一条系统序列号数据记录的某些参数进行修改或调整。在该命令中，系统通过“系统序列号”参数来唯一标识一条系统序列号的数据记录。

## 注意事项

- ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员具有本命令的操作权限。
- 除了输入“系统序列号”，还需要输入“系统名称”和“状态”的其中一个参数，该命令才能执行成功。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                   |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SYSNO   | 系统序列号  | 标识一条系统序列号数据记录的关键字段（其取值不能被修改），用于指定需要对哪一个系统序列号数据记录的参数进行修改或调整，操作员可以使用LST SYSNO命令查询获得。                                                                                                                                                     |
| SYSNAME | 系统名称   | 用于指定系统名称。 取值范围：1～255位的数字或字符组成的字符串。                                                                                                                                                                                                     |
| STATUS  | 状态     | 用于指定系统的状态。 各参数选项的含义是：INACTIVE：不激活ACTIVE：激活MASTER：主用 该参数的配置原则是：如果“系统序列号”的值和OMU上设置的系统序列号相同，则“状态”只能选择“MASTER”。如果“系统序列号”的值和OMU上设置的系统序列号不同，则“状态”只能选择“INACTIVE”或“ACTIVE”。  说明： 获取OMU上设置的系统序列号方法如下： 登录“USCDB MML命令”界面。使用LST SYSNO命令查询“系统序列号”。 |

## 使用实例

修改一个系统序列号的“状态”为“INACTIVE”：

```
MOD SYSNO: SYSNO=1, STATUS=INACTIVE;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释         | 原因分析               | 处理建议                                                                                                                                               |
|------:|:--------------|:-------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
|  1128 | 新添加的系统设备号状态错误 | 添加的系统序列号的“状态”设置错误。 | 在USCDB MML命令界面执行LST SYSNO命令查询“系统序列号”。 如需添加的“系统序列号”和OMU上设置的一致，将“状态”设置为“MASTER”后重新执行本命令。如需添加的“系统序列号”和OMU上设置的不一致，将“状态”设置为“INACTIVE”或“ACTIVE”后重新执行本命令。 |
