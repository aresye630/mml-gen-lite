# 查询操作员虚拟运营商（LST OPRMVNO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询系统序列号下的操作员所能操作的虚拟运营商的范围。

- 若需要查询全部操作员虚拟运营商的概要信息，请不要输入任何参数。
- 若需要查询某条操作员虚拟运营商的详细信息，请输入“系统序列号”或“操作员名称”或这些参数的组合。

## 注意事项

操作员的级别为“ADMINISTRATOR”或操作员被赋给该命令权限时，才具有查询其他操作员所能操作虚拟运营商范围的权限。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                           |
|:-------|:-------|:-----------------------------------------------|
| SYSNO  | 系统序列号  | 用于指示系统需要按照哪个系统序列号来查询操作员虚拟运营商；若不输入，则表示所有的系统序列号。 |
| OPNAME | 操作员名称  | 用于指示系统需要按照哪个操作员名称来查询操作员虚拟运营商；若不输入，则表示所有的操作员名称。 |

## 使用实例

在“系统序列号”为“1”的局点中查询操作员test管理的虚拟运营商范围，命令和结果如下：

```
LST OPRMVNO: SYSNO=1, OPNAME="test";
```

输出结果如下：

```
%%LST OPRMVNO: SYSNO=1, OPNAME="test";%%
RETCODE = 0 操作成功

                         SYSNO = 1
                        OPNAME = test
                          MVNO = 3
                         

Total count = 3
There is together 1 report

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD OPRMVNO**命令参数说明。
