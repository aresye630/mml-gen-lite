# 内存库整局批量备份(BKP DB)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护命令，用于备份内存数据库。

该命令主要用于紧急数据恢复场景，在升级流程准备阶段使用该命令备份指定局点的内存库，为紧急数据恢复提供恢复源。

## 注意事项

- 当正在通过**RCV DB**命令下发的内存库数据在线恢复任务时，不能同时执行本命令进行内存库数据整局批量备份任务。
- 该命令仅支持通过PGW Web LMT接入。
- 该命令仅支持超级管理员、ADMINISTRATOR级别的操作员和CUSTOM级别的操作员执行。
- 若该命令执行异常，且通过**DSP DB**命令查询存在“State”为“TASK ABNORMAL”的任务，可能是与软参**“TIMEBACKUPFLAG（定时备份开关）”**控制的内存数据库定时备份任务发生冲突。需要执行**DSP NODE**命令查询所有节点的“备份状态”都不是“备份中”后，重新执行该命令。

## 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                                             |
|:--------------|:---------|:-----------------------------------------------------------------------------------------------------------------|
| SERVICETYPE   | 业务类型     | 用于指定待备份局点的业务类型。此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。 取值范围：长度不超过128的字符串。 默认值：无。                                 |
| DIRECTORY     | 目录       | 用于设置备份目录。 取值范围： PERIODSNP：周期备份目录 EMGRST：紧急恢复目录 默认值：PERIODSNP                                                     |
| LOCINFO       | 位置信息     | 用于设置局点位置信息。 取值范围： Local：表示备份本局的内存数据。 Remote：表示备份远端局点的内存数据。 默认值：Local                                             |
| LOCID         | 位置标识     | 仅当本命令中的“位置信息”参数选择为“Remote”时该参数有效，用于指示远端局点的位置标识，即远端局点的Location标识。 取值范围：1～512 默认值：无。                               |
| UPSELFSPACE   | 上传自带空间   | 仅当本命令中的“位置信息”参数选择为“Local”时该参数有效，用于指示是否备份本局的内存数据到自带空间，即网关类型为DMA的DPU模块所在虚拟机（裸机Pod）的磁盘空间。 取值范围： YES：是。 NO：否。 默认值：NO |
| UPTHIRDSERVER | 上传第三方服务器 | 仅当本命令中的“位置信息”参数选择为“Local”时该参数有效，用于指示是否备份本局的内存数据到第三方服务器。 取值范围： YES：是。 NO：否。 默认值：NO                                |

## 使用实例

1. 在升级流程准备阶段备份指定局点的内存库，“业务类型”为“SUP-FE”，“目录”为“EMGRST”，“位置信息”为“Remote”，“位置标识”为“1”：

   ```
   BKP DB: SERVICETYPE="SUP-FE", DIRECTORY=EMGRST, LOCINFO=Remote, LOCID=1;
   ```
2. 在升级流程准备阶段备份指定局点的内存库到自带空间，“业务类型”为“SUP-FE”，“目录”为“EMGRST”，“位置信息”为“Local”，“上传自带空间”为“YES”：

   ```
   BKP DB: SERVICETYPE="SUP-FE", DIRECTORY=EMGRST, LOCINFO=Local, UPSELFSPACE=YES;
   ```
