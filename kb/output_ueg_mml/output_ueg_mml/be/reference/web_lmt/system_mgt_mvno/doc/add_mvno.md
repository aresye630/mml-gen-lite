# 添加虚拟运营商（ADD MVNO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于添加虚拟运营商。当系统中需要虚拟运营商管理号段IMEI、IMSI或MSISDN和操作员虚拟运营商管理时，需要通过本命令增加虚拟运营商。

## 注意事项

ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员具有本命令的操作权限。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                    |
|:---------|:---------|:------------------------------------------------------------------------------------------------------------------------|
| SYSNO    | 系统序列号    | 用于指定系统的序列号，该参数通过ADD SYSNO命令添加后在此引用。该参数的配置原则是： 当PGW为简单模式时，系统会自动补充“系统序列号”，不需要设置。当PGW为完整模式时，“系统序列号”需要设置。 取值范围：1～255 默认值：无。 |
| MVNO     | 虚拟运营商序列号 | 用于指定虚拟运营商的序列号。 取值范围：1～255 默认值：无。                                                                                        |
| MVNONAME | 虚拟运营商名称  | 用于说明虚拟运营商的名称。 取值范围：1～255位的数字或字符组成的字符串。 默认值：无。                                                                           |

## 使用实例

1. 系统需要添加一个虚拟运营商管理号段，其“虚拟运营商序列号”为“1”，“虚拟运营商名称”为“huawei”，PGW为简单模式：

   ```
   ADD MVNO: MVNO=1, MVNONAME="huawei";
   ```
2. 系统需要添加一个虚拟运营商管理号段，其“虚拟运营商序列号”为“1”，“虚拟运营商名称”为“huawei”，PGW为完整模式：

   ```
   ADD MVNO: SYSNO=1, MVNO=1, MVNONAME="huawei";
   ```
