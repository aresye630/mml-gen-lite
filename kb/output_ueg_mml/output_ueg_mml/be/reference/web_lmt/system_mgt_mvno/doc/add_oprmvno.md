# 增加操作员虚拟运营商（ADD OPRMVNO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于添加操作员虚拟运营商。当需要管理系统下的操作员所能操作的虚拟运营商范围时，需要使用本命令增加操作员虚拟运营商。

## 注意事项

- 操作员的级别为“ADMINISTRATOR”或操作员被赋给该命令权限时，才具有增加其他操作员所能操作虚拟运营商范围的权限。
- 需要增加操作号段的操作员或需要增加的虚拟运营商必须已经定义。
- 系统能够支持一个用户最多设置255个虚拟运营商。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                               |
|:-------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------|
| SYSNO  | 系统序列号    | 用于指定系统的序列号。该参数通过ADD SYSNO命令添加后在此引用。该参数的配置原则是：当PGW为简单模式时，操作界面不会显示此参数，系统会自动补充“系统序列号”，不需要设置。当PGW为完整模式时，“系统序列号”需要设置。 取值范围：1～255 默认值：无。 |
| OPNAME | 操作员名称    | 用于指定操作员登录的名称，可通过执行LST OPR命令查询。 取值范围：不超过32位的数字、字母和下划线组成的字符串，且首字符必须为字母。 默认值：无。                                                       |
| MVNO   | 虚拟运营商序列号 | 用于指定虚拟运营商的序列号，可通过执行LST MVNO命令查询。 取值范围：1～255 默认值：无。                                                                                 |

## 使用实例

为“系统序列号”为“1”的局点中增加操作员user管理的虚拟运营商，“虚拟运营商序列号”为“2”，命令如下：

```
ADD OPRMVNO: SYSNO=1, OPNAME="user", MVNO=2;
```
