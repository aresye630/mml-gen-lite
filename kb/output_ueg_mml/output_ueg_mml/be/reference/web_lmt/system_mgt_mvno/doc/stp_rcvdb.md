# 停止内存库数据在线恢复(STP RCVDB)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，停止指定用户在线数据恢复会导致正在恢复的任务停止，恢复数据不可回滚，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为维护命令，用于停止内存库数据在线恢复。

## 注意事项

- 该命令只能通过WebLMT接入执行。
- 当前没有正在运行的恢复任务。
- 该命令仅支持超级管理员、ADMINISTRATOR级别的操作员和CUSTOM级别的操作员执行。

## 参数说明

无。

## 使用实例

停止正在执行的内存库数据在线恢复任务。

```
STP RCVDB:;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释            | 原因分析               | 处理建议                                                      |
|------:|:-----------------|:-------------------|:----------------------------------------------------------|
|  1006 | 没有权限执行此命令。       | 当前操作员没有操作权限。       | 请使用超级管理员、ADMINISTRATOR级别的操作员或CUSTOM级别的操作员账号执行本命令。         |
|  5072 | 该命令只能通过WebLMT接入。 | 该命令只能通过WebLMT接入执行。 | 根据实际情况，请通过WebLMT接入执行命令。                                   |
|  5180 | 没有正在运行的任务。       | 当前没有正在运行的恢复任务。     | 执行DSP DB命令，查看系统正在运行的恢复任务。根据实际情况，对需要停止的正在进行的恢复任务执行此命令停止恢复。 |
