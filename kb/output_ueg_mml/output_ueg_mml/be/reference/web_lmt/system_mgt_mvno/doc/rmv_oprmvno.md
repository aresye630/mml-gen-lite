# 删除操作员虚拟运营商（RMV OPRMVNO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令属于高危命令，删除操作员虚拟运营商会造成该操作员不能继续操作该虚拟运营商序列号。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用来删除系统序列号下的操作员所能操作的虚拟运营商的范围。

## 注意事项

- 操作员的级别为“ADMINISTRATOR”或操作员被赋给该命令权限时，才具有删除其他操作员所能操作虚拟运营商范围的权限。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                      |
|:-------|:---------|:--------------------------------------------------------------------------|
| SYSNO  | 系统序列号    | 标识一条操作员虚拟运营商数据记录的关键字段之一，用于指定需要删除哪一条操作员虚拟运营商数据记录，操作员可以使用LST OPRMVNO命令查询获得。 |
| OPNAME | 操作员名称    | 标识一条操作员虚拟运营商数据记录的关键字段之一，用于指定需要删除哪一条操作员虚拟运营商数据记录，操作员可以使用LST OPRMVNO命令查询获得。 |
| MVNO   | 虚拟运营商序列号 | 标识一条操作员虚拟运营商数据记录的关键字段之一，用于指定需要删除哪一条操作员虚拟运营商数据记录，操作员可以使用LST OPRMVNO命令查询获得。 |

## 使用实例

在“系统序列号”为“1”的局点中删除操作员user管理的虚拟运营商，“虚拟运营商序列号”为“2”，命令如下：

```
RMV OPRMVNO: SYSNO=1, OPNAME="user", MVNO=2;
```
