# 查询数据比对分析任务（DSP CMPDB）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询最近一次执行的历史备份数据和内存库数据的比对分析任务。

## 注意事项

- 本命令仅支持超级管理员、ADMINISTRATOR级别的操作员和CUSTOM级别的操作员执行。
- 本命令仅支持通过PGW Web LMT接入。

## 参数说明

无。

## 使用实例

查询最近一次执行的数据比对分析任务。

```
DSP CMPDB:;
```

```
%%DSP CMPDB:;%%
RETCODE = 0 操作成功

```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

当该命令返回的

“STATUS”

为

“ABNORMAL”

时，请联系华为技术支持处理。

| 输出项名称      | 输出项解释                                                                                                                                                                              |
|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FETYPE     | 用于返回操作数据对应的FE类型。                                                                                                                                                                   |
| CID        | 用于返回执行数据比对分析任务的DRU/DSU Cluster ID。                                                                                                                                                 |
| MID        | 用于返回执行数据比对分析任务的DMA模块号。                                                                                                                                                             |
| STATUS     | 用于返回数据比对分析任务的执行状态。 PREPROCESSING：准备阶段，系统正在解析备份文件。NOFDBFILE：无对应用户的备份文件。RUNNING：运行。 UPLOADING：上传结果文件阶段。COMPLETED：完成。 ABNORMAL：异常终止，对应过程中DMA重启等异常场景。 ABORTED：手工终止，执行STP CMPDB命令终止任务。  |
| STARTTIME  | 用于表示最近一次任务起始时间，如果没有开始，则用NULL表示。                                                                                                                                                    |
| ENDTIME    | 用于表示最近一次任务结束时间，如果没有结束，则用NULL表示。                                                                                                                                                    |
| TOTAL      | 用于返回该节点需要分析的数据总记录数。 在准备阶段和无对应用户的备份文件阶段，需要分析的数据总记录数是“0”。在其他阶段，需要分析的数据总记录数均一致。                                                                                                       |
| ANALYZED   | 用于返回该节点已经完成分析的数据总记录数。 在准备阶段和无对应用户的备份文件阶段，已经完成分析的数据总记录数是“0”。在运行阶段，已经完成分析的数据总记录数在0~需要分析的数据总记录数之间。上传结果文件阶段和完成阶段，已经完成分析的数据总记录数等于需要分析的数据总记录数。异常终止和手工终止阶段，已经完成分析的数据总记录数在0~需要分析的数据总记录数之间。 |
| DIFFERENCE | 用于返回数据比对分析任务执行结束后有差异的数据记录数。                                                                                                                                                        |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释            | 原因分析                            | 处理建议                                              |
|------:|:-----------------|:--------------------------------|:--------------------------------------------------|
|  1006 | 没有权限执行此命令。       | 当前操作员没有操作权限。                    | 请使用超级管理员、ADMINISTRATOR级别的操作员或CUSTOM级别的操作员账号执行本命令。 |
|  5072 | 该命令只能通过WebLMT接入。 | 不是通过PGW Web LMT来执行该命令。          | 请通过PGW Web LMT执行本命令。                              |
|  5178 | 没有历史任务信息。        | PGW模块当前为初始化状态，未执行STR CMPDB命令操作。 | 待有STR CMPDB命令执行完后，再重新执行本命令查询。                     |
