## 命令功能

本命令用于查询PGW操作日志记录。

- 若需要查询全部操作日志的概要信息，请不要输入任何参数。
- 若需要查询某条操作日志的详细信息，请输入“系统序列号”或其他参数或这些参数的组合。

**说明** 

“保存文件名”参数指定的文件，可以通过“PGW Web LMT”界面左上角的“文件管理器”下载。

“保存文件名”参数指定的文件存放在主备PGW模块所在容器上，容器目录为“/opt/pgw/pgwtmpfile/*SYSNO+OPNAME*”。SYSNO默认为3位数字，不足3位时前面补0。如：SYSNO=1，OPNAME=admin时，最后一层目录为001admin。只有在使用操作员名称*OPNAME*登录过系统序列号*SYSNO*的PGW Web LMT并打开“文件管理器”界面后才会生成最后一层目录*SYSNO+OPNAME*。

## 注意事项

- 查询日志操作主要用于日志审计，将不可避免涉及用户的个人信息，如IMSI、MSISDN等。因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护。例如：
  1. 采用安全的文件传输协议（如SFTP）传输文件。
  2. 并严格控制文件的访问权限。
  3. 及时清理数据文件。

  在从运营商网络获取数据前，必须要获得运营商的授权。

  若需从运营商网络中获取必要的数据，需要运营商维护人员对其中的个人数据进行匿名化处理，匿名化后的数据由运营商维护人员审核后提供，以防止个人数据泄露。匿名化处理工具可以在https://support.huawei.com/获取，获取方法请参见产品手册“匿名化工具安全策略”页面。
- 如果“保存文件名”参数没有输入值，则不会保存为文件，查询结果显示在“PGW Web LMT”界面上，最大记录数为150条操作日志，超过150条则不显示。
- 如果“保存文件名”参数有输入值，则会保存为文件，文件中保存的操作日志最大记录数为100万条。

  **说明** 

  - 查询结果保存在文件中，文件内容以“end of file”结尾。
  - 若所查询的时间段数据小于等于100万条，文件内容完整，则文件的第一行将显示“The result file contains all data in the queried period.”（意为：结果文件已包含所查询时间段内所有数据）。
  - 若所查询的时间段数据大于100万条，则文件内容将只包含前100万条数据，文件的第一行将显示“The result file does not contain all data in the query period.”（意为：结果文件未包含所查询时间段内所有数据）。
  - 文件的第二行为输出该文件的完整命令。
- 如果“是否显示详细操作时间”参数输入值为空或者为“NO”，则该命令的结果按照秒级排序并显示，同一秒内执行的命令无法保证显示顺序的正确性，可能出现乱序。
- 如果“是否显示详细操作时间”参数输入值为“YES”，则该命令的结果按照毫秒级排序并显示，可以保证执行的命令显示顺序的正确性。
- 操作日志的保存周期由软参控制，保存周期之外的操作日志会被删除。具体设置保存周期，详见产品手册中“PGWOPLOGCYC”软参说明。
- **LST LOG**命令仅支持串行执行，当操作日志数目较多，执行该命令时建议输入“开始时间”与“结束时间”，否则会导致该命令执行时间较长，影响后续**LST LOG**的执行。
- 在主用局将软参“PGWLOGTOREMOTE（操作日志同步远端开关）”设置为“打开”，然后在容灾局中通过本命令查询，当“消息类型”为“SYNC”，表示主用局同步到容灾局的操作日志，包含所有接口消息类型，不是容灾局原始的操作日志。
- **LST LOG**命令不支持批操作方式执行。
- 执行本命令时，将不可避免的涉及到用户的个人数据，因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护，并在操作完成后及时清理结果文件。
- 混合组网场景下，如果要同时显示ISDN和IMSI的查询结果，需要在SP或vSP局点将软参“FWDLOGINFOSWITCH”设置为“1”。
- DMA生成的导出文件为UTF-8格式，如果导出数据中包含除ASCII可显示字符外的其他字符，默认导出格式会出现乱码，需要转码为UTF-8格式才能正常显示。

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称        | 输出项解释                       |
|:-------------|:----------------------------|
| PARTITION ID | 用于返回命令执行所在局点的Partition标识。   |
| SYSNO        | 用于返回命令执行所在局点的系统序列号。         |
| MOD NO       | 用于返回命令执行的模块号。               |
| OPR NAME     | 用于返回命令执行所在局点的操作员名称。         |
| IP           | 用于返回命令执行所在客户端的IP地址。         |
| PORT         | 用于返回命令执行所在客户端的端口号。          |
| TIME         | 用于返回命令执行的时间。                |
| BEGIN TIME   | 用于返回命令开始执行的时间。              |
| END TIME     | 用于返回命令结束执行的时间。              |
| SUB ID       | 用于返回操作日志中每条记录对应的用户SUB ID号码。 |
| IMSI         | 用于返回操作日志中每条记录对应的用户IMSI号码。   |
