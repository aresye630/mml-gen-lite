# 手动解锁用户（SET UNLCK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于操作员手动解锁系统中被锁定的操作员。

具有该命令权限的操作员包括：

- ADMINISTRATOR管理员。
- 通过**ADD OPR**命令添加为ADMINISTRATOR级别的操作员。
- 通过**ADD CCG**命令添加具有本命令权限的命令组，然后通过**ADD OPR**命令将已具有本命令权限的命令组添加给CUSTOM级别的操作员。

## 注意事项

- ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员才具有执行本命令的权限。
- 软参“HRCPMSMGR（分层权限管理）”值设置为“1”时，会限制相同“操作员级别”账号的相互管理，账户管理操作需由比自身级别高且拥有账户管理权限的账号执行。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                  |
|:-------|:-------|:--------------------------------------------------------------------------------------|
| SYSNO  | 系统序列号  | 用于指定需要解锁的操作员对应的系统序列号。 取值范围：1～255。                                                     |
| OPNAME | 操作员名称  | 用于指定需要解锁的操作员名称。该参数由ADD OPR命令定义然后才能在此引用。 取值范围：不超过32位的数字、字母和下划线组成的字符串，且首字符必须为字母。 默认值：无。 |

## 使用实例

为“系统序列号”为“1”的“opr1”操作员解锁，执行命令如下：

```
SET UNLCK: SYSNO=1, OPNAME="opr1";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释      | 原因分析         | 处理建议                      |
|------:|:-----------|:-------------|:--------------------------|
|  1006 | 没有权限执行此命令。 | 当前操作员没有操作权限。 | 建议使用更高级别或者拥有该命令执行权限的账号处理。 |
