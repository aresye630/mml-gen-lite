# 查询虚拟运营商（LST MVNO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询虚拟运营商。

- 若需要查询全部虚拟运营商的概要信息，请不要任何输入参数。
- 若需要查询某个虚拟运营商的详细信息，请输入“系统序列号”或“虚拟运营商序列号”或这两个参数的组合。

## 注意事项

ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员具有本命令的操作权限。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                 |
|:-------|:---------|:-----------------------------------------------------|
| SYSNO  | 系统序列号    | 用于指示系统需要按照哪个系统序列号来查询虚拟运营商的信息；若不输入，则表示所有的系统序列号。       |
| MVNO   | 虚拟运营商序列号 | 用于指示系统需要按照哪个虚拟运营商序列号来查询虚拟运营商的信息；若不输入，则表示所有的虚拟运营商序列号。 |

## 使用实例

1. 查询所有虚拟运营商信息：

   ```
   LST MVNO;
   ```

   ```
   %%LST MVNO: SYSNO=1;%%
   RETCODE = 0 操作成功

          "SYSNO"          "MVNO"           "MVNO Name"
           1                2                mvno1
           3                4                mvno3

   Total count = 2

   There is together 1 report

   ---    END
   ```
2. 查询被“系统序列号”为“1”管理的虚拟运营商信息：

   ```
   LST MVNO: SYSNO=1;
   ```

   ```
   %%LST MVNO: SYSNO=1;%%
   RETCODE = 0 操作成功

           "SYSNO"          "MVNO"           "MVNO Name"
           1                2                mvno1

   Total count = 1

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令操作成功的提示信息和相关参数，各参数含义请参见**ADD MVNO**命令的参数说明。
