# 查询日志用户号码（LST LOGUSER）

## 命令功能

本命令用于查询营帐操作日志中操作的用户号码。

## 注意事项

- 查询日志用户号码主要用于数据误删除快速恢复，将不可避免涉及用户的个人信息，如IMSI、MSISDN等。因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护。例如：
  - 采用安全的文件传输协议（如SFTP）传输文件。
  - 严格控制文件的访问权限。
  - 及时清理数据文件。

  在从运营商网络获取数据前，必须要获得运营商的授权。

  若需从运营商网络中获取必要的数据，需要运营商维护人员对其中的个人数据进行匿名化处理，匿名化后的数据由运营商维护人员审核后提供，以防止个人数据泄露。匿名化处理工具可以在https://support.huawei.com/获取，获取方法请参见产品手册“匿名化工具安全策略”页面。
- **LST LOGUSER**命令仅支持串行执行，当操作日志数目较多，执行该命令时建议输入“开始时间”与“结束时间”，否则会导致该命令执行时间较长，影响后续**LST LOGUSER**的执行。
- 操作日志的保存周期由软参“PGWOPLOGCYC（操作日志保存周期）”控制，保存周期之外的操作日志会被删除。具体设置保存周期，详见产品手册中“PGWOPLOGCYC（操作日志保存周期）”软参说明。
- 本命令一次最多查询50万条用户号码。

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                                                                                          |
|:----------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USERTYPE  | 用户号码类型  | 可选必选说明：必选参数。 参数含义：用于指示输出的号码类型。 取值范围： IMSI：输出IMSI。ISDN：输出MSISDN。IMPU：输出IMPU。IMPI：输出IMPI。SUBID：输出SUBID。 默认值：无。 配置原则：无。                                                                          |
| SYSNO     | 系统序列号   | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个“系统序列号”来查询操作日志中的用户号码。若不输入，则表示查询所有系统序列号的操作日志中的用户号码。 取值范围：1～255 默认值：无。 配置原则：该参数通过ADD SYSNO命令添加后在此引用。                                                              |
| OPNAME    | 操作员名称   | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个“操作员名称”来查询操作日志中的用户号码。若不输入，默认只查询自己的操作日志中的用户号码。如果登录的是超级管理员，在不输入操作员名称时，可查询所有的操作日志。操作员的日志审计权限可以通过LST OPR命令查询。 取值范围：不超过32位的数字、字母和下划线组成的字符串，且首字符必须为字母。 默认值：无。 配置原则：无。 |
| STARTTIME | 开始时间    | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照指定的“开始时间”来查询操作日志中的用户号码。若不输入，则表示该参数不作为查询的限制条件。 取值范围：格式为“YYYY&MM&DD&HH&MM&SS”的字符串。 默认值：无。 配置原则：该参数指定的时间点需要为系统本地时间。                                                  |
| ENDTIME   | 结束时间    | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照指定的“结束时间”来查询操作日志中的用户号码。若不输入，则表示该参数不作为查询的限制条件。 取值范围：格式为“YYYY&MM&DD&HH&MM&SS”的字符串。 默认值：无。 配置原则：该参数指定的时间点需要为系统本地时间。                                                  |
| CMDLIST   | 营帐指令    | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照指定的命令名称来查询操作日志中的用户号码。若不输入，则表示查询所有营帐指令的操作日志中的用户号码。 取值范围：长度不超过1024的字符串。 默认值：无。 配置原则：该参数不能包含多余空格且多个指令之间使用“&”隔开，正确输入如“ADD USER&MOD USER”。                             |
| TASKID    | 批操作任务ID | 可选必选说明：可选参数。 参数含义：用于指示系统按照指定的“批操作任务ID”来查询操作日志中的用户号码。若不输入，则查询的结果中不包含批操作中执行的命令。 取值范围：1～4294967295 默认值：无。 配置原则：可以使用CHK BATSTAT命令来查询“批操作任务ID”。                                                    |
| RESULT    | 执行结果    | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照指定的“执行结果”来查询操作日志中的用户号码；若不输入，则表示查询所有执行结果的操作日志中的用户号码。 SUCCESS：操作成功的操作日志。ERROR：操作失败的操作日志。 默认值：无。 配置原则：无。                                                             |

## 使用实例

查询指定类型的用户号码，此处以“IMSI”为例。

```
LST LOGUSER: USERTYPE=IMSI;
```

```
+++    USCDB        2024-02-06 15:06:25
PGW    #002310
%%LST LOGUSER: USERTYPE=IMSI;%%
RETCODE = 0 操作成功
There is together 1 report
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息，输出文件可在文件管理器中查看，成功文件名为Success\_LogUser\_YYYYMMDDHHMMSS\_随机数.txt，失败文件名为Fail\_LogUser\_YYYYMMDDHHMMSS\_随机数.txt。
