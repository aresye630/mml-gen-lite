# 删除命令组（RMV CCG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，删除命令组会造成使用此命令组的操作员失去该命令组中命令的执行权限。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除已添加的命令组。

## 注意事项

- 系统中默认添加的命令组G\_0～G\_7不能被删除。
- 软参“OPRCMDGMGRSWT”取值为“1”时，只有ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员具有本命令的操作权限。软参“OPRCMDGMGRSWT”取值为“0”时，ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员具有本命令的操作权限。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                         |
|:-------|:-------|:-------------------------------------------------------------|
| SYSNO  | 系统序列号  | 标识一条命令组数据记录的关键字段之一，用于指定需要删除哪一个命令组，操作员可以使用LST CCG命令查询获得。      |
| CG     | 命令组    | 标识一条命令组数据记录的关键字段之一，用于指定需要删除哪一条命令组的数据记录，操作员可以使用LST CCG命令查询获得。 |

## 使用实例

系统通过本命令删除已添加的命令组，其“系统序列号”为“1”，“命令组”为“G\_8”：

```
RMV CCG: SYSNO=1, CG=G_8;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释      | 原因分析                                                                                                                                       | 处理建议                                          |
|------:|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------|
|  1015 | 命令组已经使用。   | 该命令组已经被赋给了操作员。                                                                                                                             | 执行RMV OPR命令删除该命令组的操作员，确保成功删除后，再重新执行本命令删除该命令组。 |
|  1006 | 没有权限执行此命令。 | 当前操作员没有操作权限。 软参“OPRCMDGMGRSWT”取值为“1”时，只有ADMINISTRATOR级别的操作员具有本命令的操作权限。软参“OPRCMDGMGRSWT”取值为“0”时，ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员具有本命令的操作权限。 | 建议使用更高级别或者拥有该命令执行权限的帐号处理。                     |
