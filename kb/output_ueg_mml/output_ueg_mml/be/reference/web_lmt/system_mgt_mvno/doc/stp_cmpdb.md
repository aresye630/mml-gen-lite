# 停止数据比对分析任务（STP CMPDB）

## 命令功能

**说明** 

该命令属于高危命令，终止数据对比分析操作会导致正在执行的任务停止。因此执行该命令前，需要与华为技术支持确认后才可以实施。

本命令用于停止当前正在执行的历史备份数据和内存库数据的比对分析任务。

## 注意事项

- 本命令用于异常场景下的数据分析比对任务快速终止。
- 本命令仅支持超级管理员、ADMINISTRATOR级别的操作员和CUSTOM级别的操作员执行。
- 本命令仅支持通过PGW Web LMT接入。

## 参数说明

无。

## 使用实例

停止数据比对分析任务。

```
STP CMPDB:;
```

```
%%STP CMPDB:;%%
RETCODE = 0 操作成功

There is together 1 report

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释            | 原因分析                   | 处理建议                                                                                    |
|------:|:-----------------|:-----------------------|:----------------------------------------------------------------------------------------|
|  1006 | 没有权限执行此命令。       | 当前操作员没有操作权限。           | 请使用超级管理员、ADMINISTRATOR级别的操作员或CUSTOM级别的操作员账号执行本命令。                                       |
|  5072 | 该命令只能通过WebLMT接入。 | 不是通过PGW Web LMT来执行该命令。 | 请通过PGW Web LMT执行本命令。                                                                    |
|  5180 | 没有正在运行的任务。       | 没有正在运行的数据比对分析任务。       | 请执行DSP CMPDB命令查询数据比对分析任务，当返回的“STATUS”有“RUNNING”、“PREPROCESSING”或“UPLOADING ”时，再重新执行本命令。 |
