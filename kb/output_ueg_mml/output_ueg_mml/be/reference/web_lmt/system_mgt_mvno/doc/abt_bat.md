# 终止批操作（ABT BAT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令属于高危命令，终止批操作会导致定时执行的或正在执行的某个批操作任务停止。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于终止定时执行的或正在执行的某个批操作。

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                 |
|:-------|:--------|:---------------------------------------------------------------------|
| TASKID | 批操作任务ID | 用于指定批操作任务号。可通过CHK BATSTAT命令查询批操作任务号。 取值范围：1～4294967295 缺省值：无 说明：必选参数 |

## 使用实例

客户需要终止一个批操作任务，其中“批操作任务ID”为“56”：

```
ABT BAT: TASKID=56;
```
