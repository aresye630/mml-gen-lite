## 命令功能

**须知** 

该命令属于高危命令，执行时会弹出提示：即将执行用户迁移操作，迁移过程中可能存在业务呼损，用户迁移后，用户在本分区被销户，在目标分区开户，请确认是否继续操作。

数据导出文件包含用户的个人数据，如：IMSI、MSISDN等，因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护。例如：

1. 采用安全的文件传输协议（如SFTP）传输导出文件。
2. 严格控制导出文件的访问权限。
3. 及时清理数据导出文件。

在从运营商网络获取数据前，必须要获得运营商的授权。

若需从运营商网络中获取必要的数据，需要运营商维护人员对其中的个人数据进行匿名化处理，匿名化后的数据由运营商维护人员审核后提供，以防止个人数据泄露。匿名化处理工具可以在https://support.huawei.com/上获取。在“产品软件”页签中浏览或搜索“LogAnonymity”，获取最新版本的工具。

该命令用于执行跨分区用户迁移操作，支持批量用户从UDR分区迁移至另一UDR分区。迁移方式支持按用户数迁移、号段迁移、用户列表迁移和条件迁移。

## 注意事项

- 对系统的影响：
  - 执行该命令进行用户迁移操作将影响系统性能，请结合现网资源使用情况，通过“CROSSREGIONMIGRATESPEED（用户跨区迁移速度）”软参调整最大迁移速率。
  - 当出现异常场景导致迁移失败时，如迁出分区和迁入分区通信异常等，系统会自动对用户进行回滚处理。回滚后数据在迁出和迁入分区可能都存在，维护人员需基于日志文件，决定删除迁出分区用户数据或迁入分区用户数据。
  - 若执行该命令从UDR高版本迁移用户到UDR低版本，可能会导致高版本中独有数据丢失，影响业务。
- 命令执行成功需要满足以下条件：
  - 周期性校验开关已关闭，包括软参“FWDRTVFYSWT（正向路由校验开关）”、“REVVFYSWT（反向校验开关）”、“FWDVFYSWT（正向校验开关）”、“REVRTVFYSWT（反向路由校验开关）”取值设置为“0”。
  - 用户数据统计开关已关闭，即软参“USERDATAMEASUREFLAG（定时用户数据统计开关）”取值设置为“0”。
  - 周期性备份开关已关闭，即软参“TIMEBACKUPFLAG（定时备份开关）”取值设置为“0”。
  - 局间复制开关已打开，即软参“REDUNDANCYSWITCH（容灾开关）”取值设置为“0”或“1”。
  - 批操作挂起开关已打开，即软参“BATSUSPENDSWITCH（批操作挂起开关）”取值设置为“1”。
  - 支持混合组网的目标态组网。即软参“NETWORKMODE（组网模式）”取值设置为“2”。
  - 在主用局执行该命令，同时主用局不能存在“主备标识”为“Redundancy”的Cluster，非主用局不允许执行迁移操作。
  - 迁移目标分区的“Partition标识”不能跟本分区“Partition标识”相同，也不能是vRP分区的“Partition标识”。
  - 命令指定FE类型下是否有故障状态的DMA/DSG/DRU/DSU模块，若存在故障状态的模块，则不允许启动迁移操作。
  - 没有跨分区迁移或回退任务，或者局内迁移任务正在运行，如果有，则不允许再执行迁移任务。
  - 当前组网是混合组网，非混合组网不支持迁移操作。
  - 用户数据导出任务正在运行，不允许执行迁移任务。
  - 不允许在升级状态下执行用户迁移操作。
  - 检查当前是否处于接管状态，若处于接管状态则报错。
  - 检查DSU模块所在虚拟机（裸机Pod）磁盘可用空间是否小于5GB，小于5G则报错。
  - 当采用按号段迁移时，需要提前将号段列表文件上传到PGW WebLMT“文件管理器”：
    - 号段列表文件支持“.zip”、“.txt”、“.tar.gz”三种格式，且“.zip”和“.tar.gz”两种格式压缩包解压后有且只有一个“.txt”文件；
    - “.txt”文件大小不能超过50M；压缩文件不能超过5M；
    - 最多允许有20万个号段，号段列表文件一行一个号段，号段长度不能超过号码本身的最大长度，且长度不能超过255。
  - 当采用用户列表迁移时，需要提前将用户列表文件上传到PGW WebLMT“文件管理器”：
    - 用户列表文件支持“.zip”、“.txt”、“.tar.gz”三种格式，且“.zip”和“.tar.gz”两种格式压缩包解压后有且只有一个“.txt”文件；
    - “.txt”文件大小不能超过2G；压缩文件不能超过100M；
    - 用户列表文件一行一个号码，用户号码长度不能超过号码本身的最大长度，且长度不能超过255。
  - 当采用条件迁移时，需要提前执行**LOD ADPPKG**命令加载“MIGRATE”类型的适配包。
- 完成用户迁移操作后，可通过PGW Web LMT界面打开文件管理器获取迁移列表。为防止文件管理器存储空间过满，可将迁移列表文件下载后，在文件管理器上删除。
- 不允许从5G局点迁移到4G局点。
- 该命令不允许进行批操作。

| PERIODTIME  | 迁移时长            | 可选必选说明：条件可选参数，仅当参数“迁移类型”取值为“CONDITION”时，该参数生效。 参数含义：用于指定本次迁移任务的运行时长，任务运行至该参数设置的时长时会停止。 取值范围：1~1440（单位：分钟） 默认值：无。即不指定本次迁移任务的运行时长，直到任务运行完成。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |

## 使用实例

当需要执行迁移任务，“FE类型”为“SUP-FE”，“键值类型”为“SUID”，迁入分区“PARTITIONID”为“11”，通过“用户数迁移”迁移“100”个用户时。

```
STR MIGRATION: FETYPE="SUP-FE", KEYTYPE="SUID", PARTITIONID=11, TRANSTYPE=USERNUM, USERNUM=100;
```

```
%%STR MIGRATION: FETYPE="SUP-FE", KEYTYPE="SUID", PARTITIONID=11, TRANSTYPE=USERNUM, USERNUM=100;%% 
RETCODE = 0 操作成功 Task ID: 68. DSP MIGRATION can be used to obtain the task status  
There is together 1 report  
---    END
```
