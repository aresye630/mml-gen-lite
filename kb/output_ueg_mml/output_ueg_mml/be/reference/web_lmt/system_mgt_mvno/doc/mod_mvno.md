# 修改虚拟运营商（MOD MVNO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令属于高危命令，修改虚拟运营商会导致当前虚拟运营商不可用。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一条虚拟运营商数据记录的某些参数进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一条虚拟运营商：

- 系统序列号
- 虚拟运营商序列号

## 注意事项

- ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员具有本命令的操作权限。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                   |
|:---------|:---------|:-----------------------------------------------------------------------|
| SYSNO    | 系统序列号    | 标识一条虚拟运营商数据记录的关键字段之一（其取值不能被修改），用于指定需要修改哪一个系统序列号，操作员可以使用LST MVNO命令查询获得。 |
| MVNO     | 虚拟运营商序列号 | 标识一条虚拟运营商数据记录的关键字段之一（其取值不能被修改），用于指定需要修改哪一个系统序列号，操作员可以使用LST MVNO命令查询获得。 |
| MVNONAME | 虚拟运营商名称  | 用于说明虚拟运营商的名称。 取值范围：1～255位的数字或字符组成的字符串。                                 |

## 使用实例

当前存在一个虚拟运营商，其“系统序列号”为“1”，“虚拟运营商序列号”为“1”，现将“虚拟运营商名称”修改为“test\_1”：

```
MOD MVNO: SYSNO=1, MVNO=1, MVNONAME="test_1";
```
