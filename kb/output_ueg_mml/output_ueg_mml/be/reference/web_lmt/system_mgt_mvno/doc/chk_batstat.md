# 查询批操作状态（CHK BATSTAT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询批操作状态。默认情况下，将显示所有批操作的信息。

## 注意事项

- 参数“起始时间”和“结束时间”必须同时指定或同时不指定。
- 当“起始时间”和“结束时间”同时指定时，“结束时间”的取值必须大于“起始时间”的取值。
- 当“是否提供详细信息”取值为“TRUE”时，必须输入“批操作任务ID”。
- 当指定“批操作任务ID”时，“起始时间”、“结束时间”和“执行状态”不允许指定。
- 当指定“查询任务类型”时，“起始时间”和“结束时间”需同时指定。
- 导入批操作进度每一百个用户更新一次。

| STATE     | 执行状态     | 用于指定要查询的批操作的状态。该参数与“批操作任务ID”不能同时存在。 取值范围： READY：准备RUNNING：运行COMPLETED：完成ABORTED：中止，可能原因如下：在执行批操作时，检查文件不存在读写文件异常执行ABT BAT命令停止过当前批操作执行ABT CONBAT命令停止过当前批操作内存耗尽存储故障 说明： 检查文件不存在时，请重新上传文件并下发批操作任务。其余异常场景，请联系华为技术支持。 PENDING：等待UPLDFAIL：上传文件失败，导入批操作结果文件从负载PGW上传到主备PGW失败。 说明： 当该参数取值为“UPLDFAIL”时，输出项“MODULE ID”表示上传文件失败的负载PGW模块ID，如需获取上传失败的导入批操作结果文件，请联系华为技术支持。 DWLDING：下载文件中，导入文件正在从主备PGW下载到负载PGW中。DWLDFAIL：下载文件失败，导入文件从主备PGW下载到负载PGW失败。CFGFAIL：执行导入批操作BAT IMP命令时，参数“配置文件名”对应文件内容不合法。 默认值：无。 |

| SAVEAS    | 保存文件名    | 仅当该命令中的“是否提供详细信息”参数取值为“TRUE”时该参数有效，用于指定保存查询结果的文件名。如果指定“保存文件名”，命令执行结果保存在文件内，不在WebUI显示命令执行结果。操作员可以通过“PGW Web LMT”界面左上角的“文件管理器”下载该文件。 如果不指定“保存文件名”，且显示的记录超过250条，则在WebUI显示前250条记录信息。 如果不指定“保存文件名”，且显示的记录不超过250条，则在WebUI显示所有记录信息。 如果指定“保存文件名”和“批操作任务ID”，需同时指定“是否提供详细信息”为“TRUE”。 取值范围：1～20位字符串，可由字母、数字或字符组成，字符不能包含“>”、“/”、“?”、“\”、“:”、“*”、“"”、“<”、“|”、“,”、“;”、“=”和“'”。 默认值：无。                                                                                                                  |
| TASKTYPE  | 查询任务类型   | 用于指定查询进度的任务类型。 取值范围： IMP：导入批操作任务 BAT：普通批操作任务 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                      |

## 使用实例

客户需要查询一个“批操作任务ID”为“56”的批操作任务状态，不保存查询结果。

```
CHK BATSTAT: TASKID=56;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。各参数含义请参见表 输出项解释的参数说明。

| 输出项名称                       | 输出项解释                                                   |
|:----------------------------|:--------------------------------------------------------|
| TASK ID                     | 用于返回批操作任务的任务ID。                                         |
| SYSNO                       | 用于返回执行批操作任务的操作员归属的系统序列号，即LST OPR命令查询结果中操作员对应的“SYSNO”的值。 |
| MODULE ID                   | 用于返回批操作任务的模块ID。                                         |
| OPERATOR NAME               | 用于返回操作员的名称。                                             |
| START TIME                  | 用于返回批操作任务的起始时间。                                         |
| END TIME                    | 用于返回批操作任务的结束时间。                                         |
| STATUS                      | 用于返回批操作任务的任务状态。                                         |
| TOTAL                       | 用于返回批操作任务的总记录数。                                         |
| SUCCESS                     | 用于返回批操作任务的成功记录数。                                        |
| FAILURE                     | 用于返回批操作任务的失败记录数。                                        |
| PROGRESS                    | 用于返回批操作任务的进度。                                           |
| RESTTIME                    | 用于返回批操作任务的剩余时间。                                         |
| DB SUCCEED BUT NETWORK FAIL | 用于返回批操作任务的数据库更新成功网络侧更新失败数。                              |
| MML CMD                     | 用于返回批操作任务的MML命令内容。                                      |
