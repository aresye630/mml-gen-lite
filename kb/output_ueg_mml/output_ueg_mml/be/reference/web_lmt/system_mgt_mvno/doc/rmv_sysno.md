# 删除系统序列号（RMV SYSNO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令属于高危命令，删除系统序列号会造成删除该系统序列号下所有操作员、号段等信息。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除已添加的系统序列号。

## 注意事项

- ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员具有本命令的操作权限。
- 请谨慎执行本命令，在删除系统序列号时，不管该系统序列号当前是否有被用户使用，都会被强制删除。删除系统序列号的同时，系统会删除与该系统序列号相关联的所有内容，如与该系统序列号相关的虚拟运营商、操作员等。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                         |
|:-------|:-------|:-------------------------------------------------------------|
| SYSNO  | 系统序列号  | 标识一条系统序列号的关键字段，用于指定需要删除哪一个系统序列号的数据记录，操作员可以使用LST SYSNO命令查询获得。 |

## 使用实例

删除一个“SYSNO”为“1”的系统序列号：

```
RMV SYSNO: SYSNO=1;
```
