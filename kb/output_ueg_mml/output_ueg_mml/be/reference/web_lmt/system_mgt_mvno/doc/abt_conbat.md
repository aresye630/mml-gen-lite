# 终止业务条件批操作（ABT CONBAT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令属于高危命令，终止业务条件批操作会导致正在执行的业务条件批操作任务停止。因此执行该命令前，需要与华为技术支持确认后才可以实施。

本命令用于终止正在执行的业务条件批操作任务。

## 注意事项

- 本命令会终止正在执行的业务条件批操作任务。未执行完成的业务条件批操作命令将不会继续执行，已经执行完成的命令不可回退。可通过**CHK CONBATSTAT**命令查询正在执行的业务条件批操作任务。
- 该命令不允许进行批操作。

## 参数说明

无。

## 使用实例

终止当前正在执行的业务条件批操作任务。

```
ABT CONBAT:;
```
