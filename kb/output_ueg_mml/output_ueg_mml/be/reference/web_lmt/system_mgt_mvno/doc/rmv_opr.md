# 删除操作员（RMV OPR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，删除操作员会造成此操作员失效。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用来删除PGW操作员数据。

## 注意事项

- 操作员的级别为“ADMINISTRATOR”或操作员被赋予该命令权限时，才具有删除其他操作员的权限。
- 删除操作员成功后，需执行**KIK ONLINEOPR**命令下线被删除的操作员。
- 该命令不允许进行批操作。
- 软参“HRCPMSMGR（分层权限管理）”值设置为“1”时，会限制相同“操作员级别”账号的相互管理，账户管理操作需由比自身级别高且拥有账户管理权限的账号执行。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                        |
|:-------|:-------|:------------------------------------------------------------|
| SYSNO  | 系统序列号  | 标识一条操作员数据记录的关键字段之一，用于指定需要删除哪一条操作员数据记录，操作员可以使用LST OPR命令查询获得。 |
| OPNAME | 操作员名称  | 标识一条操作员数据记录的关键字段之一，用于指定需要删除哪一条操作员数据记录，操作员可以使用LST OPR命令查询获得。 |

## 使用实例

在“系统序列号”为“1”的局点中删除“操作员名称”为“pgwuser”的用户，命令如下：

```
RMV OPR: SYSNO=1, OPNAME="pgwuser";
```

该命令执行正常，会返回命令执行成功的提示信息。
