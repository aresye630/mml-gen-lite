# 查询业务条件批操作状态（CHK CONBATSTAT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询业务条件批操作的状态：

- 若需要查询全部业务条件批操作的概要信息，请不要输入任何参数。
- 若需要查询某条业务条件批操作的详细信息，请输入“批操作任务ID”或其他参数或这些参数的组合。

## 注意事项

- 参数“起始时间”和“结束时间”必须同时指定或同时不指定。
- 当“起始时间”和“结束时间”同时指定时，“结束时间”的取值必须大于“起始时间”的取值。
- 系统最多纪录最近100个任务的结果信息。
- 必须明确指定“执行状态”的取值为“READY”，才能够查看系统缓存的业务条件批操作任务。

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                 |
|:----------|:--------|:---------------------------------------------------------------------------------------------------------------------|
| TASKID    | 批操作任务ID | 用于指示系统需要按照哪个批操作任务ID来查询业务条件批操作状态；若不输入，则表示所有的批操作任务ID。 取值范围：1879048192～2147483647 默认值：无。                                |
| OPNAME    | 操作员名称   | 用于指示系统需要按照哪个操作员名称来查询业务条件批操作状态；若不输入，默认只查询自己的业务条件批操作状态。 取值范围：不超过32位的数字、字母和下划线组成的字符串，且首字符必须为字母。 默认值：无。                  |
| BEGINTIME | 起始时间    | 用于指示系统需要按照指定的开始时间来查询操作日志；若不输入，则表示查询所有时间。该参数与“批操作任务ID”不能同时存在。 取值范围：格式为“YYYY&MM&DD&HH&MM&SS”的字符串。 默认值：无。               |
| ENDTIME   | 结束时间    | 用于指示系统需要按照指定的结束时间来查询操作日志；若不输入，则表示查询所有时间。该参数与“批操作任务ID”不能同时存在。 取值范围：格式为“YYYY&MM&DD&HH&MM&SS”的字符串。 默认值：无。               |
| STATE     | 执行状态    | 用于指示系统需要按照指定的执行状态来查询操作日志；若不输入，则表示查询所有执行状态。该参数与“批操作任务ID”不能同时存在。 取值范围： READY：准备RUNNING：运行COMPLETED：完成ABORTED：终止 默认值：无。 |

## 使用实例

查询“批操作任务ID”为“1879048192”的批操作任务状态。

```
CHK CONBATSTAT: TASKID=1879048192;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称         | 输出项解释                 |
|:--------------|:----------------------|
| TASK ID       | 用于返回业务条件批操作的批操作任务ID。  |
| SYSNO         | 用于返回业务条件批操作的操作员系统序列号。 |
| OPERATOR NAME | 用于返回业务条件批操作的操作员名称。    |
| START TIME    | 用于返回业务条件批操作的开始时间。     |
| END TIME      | 用于返回业务条件批操作的结束时间。     |
| STATUS        | 用于返回业务条件批操作的执行状态。     |
| TOTAL         | 用于返回业务条件批操作的命令执行总次数。  |
| EXECUTED      | 用于返回业务条件批操作的命令执行成功次数。 |
| MML CMD       | 用于返回业务条件批操作下发的MML命令。  |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释           | 原因分析                                     | 处理建议                                         |
|------:|:----------------|:-----------------------------------------|:---------------------------------------------|
|  1009 | 参数丢失。           | 参数“起始时间”和“结束时间”要求同时存在。                   | 请重新输入“起始时间”和“结束时间”，确保两参数同时存在。                |
|  1010 | 参数冲突。           | 参数“批操作任务ID”存在，“结束时间”、“起始时间”和“执行状态”不允许存在。 | 当已输入参数“批操作任务ID”，请不要输入参数“结束时间”、“起始时间”或“执行状态”。 |
|  1026 | 结束参数应大于/晚于起始参数。 | “起始时间”应小于“结束时间”。                         | 请重新输入“起始时间”或“结束时间”，确保“起始时间”小于“结束时间”          |
