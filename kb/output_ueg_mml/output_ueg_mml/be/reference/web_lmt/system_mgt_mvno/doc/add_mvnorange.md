# 添加虚拟运营商号段（ADD MVNORANGE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令属于高危命令，增加虚拟运营商号段会造成扩大既有操作员的号段范围。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于添加虚拟运营商的号段。当系统中需要对IMEI/PEI、IMSI/SUPI或MSISDN/GPSI号段进行管理时，需要通过执行本命令添加。

## 注意事项

- ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员具有本命令的操作权限。
- 添加虚拟运营商号段之前必须先通过**ADD SYSNO**命令和**ADD MVNO**添加系统序列号以及虚拟运营商。
- 只有当“PROVRIGHTSWITCH”参数值为“1”和“SERVICERIGHTSWITCH”参数值为“0”时，通过该命令添加成功的数据才能生效。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                    |
|:----------|:---------|:------------------------------------------------------------------------------------------------------------------------|
| SYSNO     | 系统序列号    | 用于指定系统序列号，该参数通过ADD SYSNO命令添加后在此引用。该参数的配置原则是： 当PGW为简单模式时，系统会自动补充系统序列号，不需要用户设置。当PGW为完整模式时参数系统序列号需要用户设置。 取值范围：1～255 默认值：无。 |
| MVNO      | 虚拟运营商序列号 | 用于指定虚拟运营商序列号，该参数通过ADD MVNO命令添加后在此引用。 取值范围：1～255 默认值：无。                                                                  |
| RANGETYPE | 可操作范围类型  | 用于指定可操作范围类型。 取值范围： IMSIMSISDNIMEI 默认值：无。                                                                                |
| PREFIX    | 号码前缀     | 用于指定号码前缀。 取值范围：1～15位的数字。 默认值：无。                                                                                         |

## 使用实例

在OM Portal的“USCDB MML命令”界面执行**LST INSP**命令查询PGW为简单模式还是完整模式。

```
LST INSP: INSPT=PGW, INSPN=APPLICATIONTYPE;
```

1. 当PGW为完整模式时，执行本命令添加虚拟运营商号段，其“系统序列号”为“1”，“虚拟运营商序列号”为“1”，“可操作范围类型”为“IMSI”，“号码前缀”为“131”：

   ```
   ADD MVNORANGE: SYSNO=1, MVNO=1, RANGETYPE=IMSI, PREFIX="131";
   ```
2. 当PGW为简单模式时，执行本命令添加虚拟运营商号段，其“虚拟运营商序列号”为“1”，“可操作范围类型”为“IMSI”，“号码前缀”为“131”：

   ```
   ADD MVNORANGE: MVNO=1, RANGETYPE=IMSI, PREFIX="131";
   ```
