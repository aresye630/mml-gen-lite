# 添加系统序列号（ADD SYSNO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加系统序列号。当系统中需要添加操作员或虚拟运营商时，需要使用本命令添加系统序列号。

## 注意事项

ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员具有本命令的操作权限。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                           |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SYSNO   | 系统序列号  | 用于唯一标识本局的系统序列号。 取值范围：1～255 默认值：无。                                                                                                                                                                                                              |
| SYSNAME | 系统名称   | 用于指定系统名称。 取值范围：1～255位的数字或字符组成的字符串。 默认值：无。                                                                                                                                                                                                      |
| STATUS  | 状态     | 用于指定系统的状态。 各参数选项的含义是：INACTIVE：不激活，ACTIVE：激活MASTER：主用 该参数的配置原则是：如果“系统序列号”的值和OMU上设置的系统序列号相同，则“状态”只能选择“MASTER”。如果“系统序列号”的值和OMU上设置的系统序列号不同，则“状态”只能选择“INACTIVE”或“ACTIVE”。  说明： 获取OMU上设置的系统序列号方法如下： 登录“USCDB MML命令”界面。使用LST SYSNO命令查询“系统序列号”。 默认值：无。 |

## 使用实例

1. 添加一个值为“1”的“系统序列号”且OMU上设置的系统序列号为“1”：

   ```
   ADD SYSNO: SYSNO=1, SYSNAME="MASTERNO1", STATUS=MASTER;
   ```
2. 添加一个值为“1”的“系统序列号”且OMU上设置的系统序列号不为“1”：

   ```
   ADD SYSNO: SYSNO=1, SYSNAME="INACTIVENO1", STATUS=INACTIVE;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释         | 原因分析               | 处理建议                                                                                                                                                 |
|------:|:--------------|:-------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
|  1128 | 新添加的系统设备号状态错误 | 添加的系统序列号的“状态”设置错误。 | 在“USCDB MML命令”界面执行LST SYSNO命令查询“系统序列号”。 如需添加的“系统序列号”和OMU上设置的一致，将“状态”设置为“MASTER”后重新执行本命令。如需添加的“系统序列号”和OMU上设置的不一致，将“状态”设置为“INACTIVE”或“ACTIVE”后重新执行本命令。 |
