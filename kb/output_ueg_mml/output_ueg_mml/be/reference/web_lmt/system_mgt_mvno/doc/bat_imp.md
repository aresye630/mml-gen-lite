## 命令功能

**须知** 

该命令是批处理命令，在执行导入过程中，会占用系统较多资源，因此执行命令前，请确保业务处于低峰期。

该命令用于启动对用户数据进行批量导入。

导入批操作执行原理如图1所示。

**图1** 导入批操作执行流程

1. 用户预先准备好批量导入的用户数据文件并通过Web LMT的“文件管理器”将文件上传到批操作文件存放目录，并启动批操作。
2. PGW自动执行批操作文件，对用户数据进行批量导入。

## 注意事项

- 使用该命令导入的批操作文件支持“.zip”、“.txt”、“.tar.gz”三种格式。
- 单个压缩包文件最大不能超过2GB，解压成批操作文件后单个文件大小不超过2GB且文件总大小不超过9GB。
- 请不要修改文件后缀，强行修改文件后缀会导致执行命令失败。
- 压缩包内只能是文件，文件个数不为0且不超过100，该文件必须是可编辑的文本文件。
- 单个用户数据大小限制如下：
  - 当软参“INNERMSGSENDPATH”取值为“0”时，单个用户数据大小不能超过64KB。
  - 当软参“INNERMSGSENDPATH”取值为“1”时，单个用户数据大小不能超过1MB。
- 导入前必须有可用的DMA模块。
- 导入批操作在所有PGW模块上控制，在DMA模块上执行，同时执行的批操作的最大任务个数建议为10个，超过10个可能会出现系统负荷升高，进而任务失败。

  可以同时执行的导入批操作的最大个数在10～200之间，具体个数依据PGW模块个数和单个PGW支持的最大导入批操作数而定。单个PGW支持的最大导入批操作数由软参“MAXIMPNUMBER”决定。
  - 当（PGW模块个数×单个PGW支持的最大导入批操作数）小于10时，可以同时执行的导入批操作个数为10。
  - 当（PGW模块个数×单个PGW支持的最大导入批操作数）大于等于10且小于等于200时，可以同时执行的导入批操作个数为（PGW模块个数×单个PGW支持的最大导入批操作数）。
  - 当（PGW模块个数×单个PGW支持的最大导入批操作数）大于200时，可以同时执行的导入批操作个数为200。

    **说明** 

    当（PGW模块个数×单个PGW支持的最大导入批操作数）小于10时，单个PGW支持的最大导入批操作数不受软参“MAXIMPNUMBER”限制，只需要保证可同时执行的导入批操作个数为10。
- 当导入类型的适配包加载不成功或者主备PGW、DMA任一模块加载不成功时，执行**BAT IMP**失败。
- 该命令的导入结果可通过**CHK BATSTAT**命令查看。如果存在导入失败的用户，可将**CHK BATSTAT**命令的参数“是否提供详细信息”设置为“TRUE”，同时指定“保存文件名”来查询失败用户的详细信息。
- 该命令不允许进行批操作。
- 该命令不支持将多个导入任务同时导入同一个用户，可能导致导入失败。当导入失败时，导入失败的文件需要重新执行该命令逐个导入进行修复。
- 执行该命令导入批操作过程中，不允许执行PGW主备倒换命令**SWP MODULE**，否则在执行**CHK BATSTAT**命令查询本次导入批操作任务详细信息时，可能会有部分信息丢失。
- 执行该命令后，系统会先判断“文件管理器”目录下文件是否存在，如果不存在则会去/opt/pgw/upload目录下检查文件是否存在。/opt/pgw/upload目录下存在文件，则将文件移动至“文件管理器”目录下进行导入批操作，/opt/pgw/upload目录下不存在文件则会导致导入失败。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                         |
|:------------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TYPE        | 导入类型    | 用于指定批量导入文件的导入方式或处理方式。 取值范围：COMPLETE：全量导入。INCREMENT：增量导入。CHECK：数据对比。MML：MML增量导入。 默认值：COMPLETE。  说明： 当取值为“CHECK”时，用于对比导入后的数据和需要导入的数据是否一致。                                      |
| FETYPE      | FE类型    | 用于指定导入哪个FE类型的批操作任务，此参数在USCDB下唯一，通过“USCDB MML命令”界面的LOD FEPLUG加载FE插件后在此引用。 取值范围：长度不超过128的字符串。 默认值：无。 说明：该参数是联想参数，不能手动输入，必须选择加载后的插件类型。                                          |
| FILE        | 文件名     | 用于指定批量导入文件的名称，文件名区分大小写，必须与实际文件名保持一致。批操作文件通过Web LMT的“文件管理器”上传到批操作文件存放目录，具体的操作请参考产品文档中的“管理文件”。与“文件名过滤条件”参数二选一。 取值范围：5～128位字符串，可由字母、数字或字符“_”、“.”、“-”组成。 默认值：无。                  |
| CUSTOMPARA  | 定制参数    | 用于指定定制参数。 取值范围：长度不超过256的字符串。 默认值：无。                                                                                                                                          |
| CUSTOMPARA2 | 定制参数2   | 用于指定定制参数。 取值范围：长度不超过256的字符串。 默认值：无。                                                                                                                                          |
| CUSTOMPARA3 | 定制参数3   | 用于指定定制参数。 取值范围：长度不超过2048的字符串。 默认值：无。                                                                                                                                         |
| TPLNAME     | 模板名称    | 仅当本命令中的“导入类型”参数为“INCREMENT”时该参数有效，用于指定导入使用的模板名称。该参数必须为通过“USCDB MML命令”界面的LOD ADPPKG命令加载成功的模板的模板名称。 说明：该参数是联想参数，不能手动输入，必须先选择“FE类型”，然后选择加载成功的模板。                                |
| CFGFILE     | 配置文件名   | 用于指定批量导入的配置文件名称，文件名区分大小写，必须与实际文件名保持一致。批操作文件通过Web LMT的“文件管理器”上传到批操作文件存放目录，具体的操作请参考产品文档中的“管理文件”。 取值范围：5～128位字符串，可由字母、数字或字符“_”、“.”、“-”组成，并且文件后缀只能为ini或txt。 默认值：无。               |
| FILEFILTER  | 文件名过滤条件 | 用于模糊匹配场景下，配置导入批操作文件的过滤条件，与“文件名”参数二选一。需要使用如下格式：[前缀]*[后缀]，如：BAT*.txt。非必选参数。 取值范围：5～128位字符串，可由字母、数字或字符“_”、“.”、“-”、“*”组成。 默认值：无。  说明： 本参数能力在25.1.RC1版本不支持，执行命令携带本参数配置时将导致命令执行失败。 |

## 使用实例

客户执行“导入类型”为“INCREMENT”，“FE类型”为“SUP-FE”，“文件名”为“import\_6.tar.gz”，“定制参数”为“SUB”，“模板名称”为“sup\_import002”的批操作文件。

```
BAT IMP: TYPE=INCREMENT, FETYPE="SUP-FE", FILE="import_6.tar.gz", CUSTOMPARA="SUB", TPLNAME="sup_import002";
```

```
%%BAT IMP: TYPE=INCREMENT, FETYPE="SUP-FE", FILE="import_6.tar.gz", CUSTOMPARA="SUB", TPLNAME="sup_import002";%%
RETCODE = 0 操作成功 批操作ID：218103812. 使用CHK BATSTAT指令可查看此批操作的执行情况

There is together 1 report

---    END
```
