# 设置命令组名（SET CCGN）

- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

该命令用于设置命令组的名称。

## 注意事项

软参“OPRCMDGMGRSWT”取值为“1”时，只有ADMINISTRATOR级别的操作员具有本命令的操作权限。软参“OPRCMDGMGRSWT”取值为“0”时，ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员具有本命令的操作权限。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                    |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------|
| SYSNO  | 系统序列号  | 用于指定系统序列号，该参数通过ADD SYSNO命令添加后在此引用。该参数的配置原则是： 当PGW为简单模式时，系统会自动补充SYSNO，不需要用户设置。当PGW为完整模式时参数SYSNO需要用户设置。 取值范围：1～255 默认值：无。 |
| CG     | 命令组    | 用于唯一标识命令组ID。 取值范围：G_0～G_127 默认值：无。                                                                                      |
| CGNAME | 命令组名   | 用于唯一标识命令组的名称。 取值范围：32位以内的字符串。 默认值：无。                                                                                    |

## 使用实例

系统通过本命令设置命令组名，其“SYSNO”为“1”，“CG”为“G\_8”，“CGNAME”为“NormalUser”：

```
SET CCGN: SYSNO=1, CG=G_8, CGNAME="NormalUser";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释      | 原因分析                                                                                                                                       | 处理建议                      |
|------:|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------|
|  1006 | 没有权限执行此命令。 | 当前操作员没有操作权限。 软参“OPRCMDGMGRSWT”取值为“1”时，只有ADMINISTRATOR级别的操作员具有本命令的操作权限。软参“OPRCMDGMGRSWT”取值为“0”时，ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员具有本命令的操作权限。 | 建议使用更高级别或者拥有该命令执行权限的帐号处理。 |
