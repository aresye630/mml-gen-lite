# 删除导出任务(RMV EXPTASK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一个导出任务。

## 注意事项

- 该命令仅支持操作管理员执行。
- 无法删除正在执行中的一次性导出任务，即当待删除的一次性导出任务的“任务状态”为“RUNNING”时，请先执行**STP EXPTASK**命令，停止该任务后，重新执行本命令。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                        |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------|
| TASKID | 任务ID   | 可选必选说明：必选参数。 参数含义：标识一个导出任务的关键字段，用于指定需要对哪一个导出任务的设置进行修改，操作员可以使用DSP EXPTASK命令查询获得。 取值范围：1～65535 默认值：无。 配置原则：无。 |

## 使用实例

删除“任务ID”为“1”的导出任务。

```
RMV EXPTASK: TASKID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                                 | 原因分析                              | 处理建议                                             |
|------:|:--------------------------------------|:----------------------------------|:-------------------------------------------------|
|  5077 | 任务不存在。                                | 指定的“任务ID”对应的任务不存在。                | 请先执行DSP EXPTASK命令查询所有的导出任务及状态，确认待删除任务的ID后再执行本命令。 |
|  5218 | 待删除任务状态为“RUNNING”,需要先执行STP EXPTASK命令。 | 待删除的“任务状态”为“RUNNING”，不能删除正在执行的任务。 | 执行STP EXPTASK命令，输入需要删除的任务的“任务ID”，停止该任务后，重新执行本命令。 |
