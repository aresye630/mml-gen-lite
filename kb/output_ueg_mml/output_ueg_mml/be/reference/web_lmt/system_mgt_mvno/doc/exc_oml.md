## 命令功能

**须知** 

该命令属于高危命令，操作内存数据库可能导致数据被损坏且无法回退。因此执行该命令前，务必联系华为技术支持确认后方可操作。

该命令用于对GMDB内存数据库的数据进行查询和更新操作。当数据库中某些节点或某些表、字段的数据出现异常，需要进行快速修复时，可以通过该命令在线批量查询或更新GMDB内存库中的数据。

## 注意事项

- 同一时间只允许一条该命令在执行。
- 用户可以通过PGW Web LMT界面打开文件管理器获取操作结果信息文件。
  - 对于不指定“键值”的EXC OML的详细结果，系统将操作结果信息文件打包成“ExcOMLQueryResult\_时间戳.tar.gz”或者“ExcOMLQueryResult\_{RuleName}\_时间戳.tar.gz”或者“ExcOMLUpdateResult\_时间戳.tar.gz”格式。以时间戳为批次，最多保留50个批次，超过数量的旧文件将会被周期性（1分钟）自动删除。如果文件大小超过2G，会被拆分成“ExcOMLQueryResult\_时间戳\_{NO}.tar.gz”或者“ExcOMLQueryResult\_{RuleName}\_时间戳\_{NO}.tar.gz”或者“ExcOMLUpdateResult\_时间戳\_{NO}.tar.gz”格式。
  - 对于指定“键值”的EXC OML的详细结果，系统将操作结果信息文件打包成“ExcOMLQueryKeyResult\_OBJKEY\_时间戳.tar.gz”或者“ExcOMLQueryKeyResult\_OBJKEY\_{RuleName}\_时间戳.tar.gz”或者“ExcOMLUpdateKeyResult\_OBJKEY\_时间戳.tar.gz”格式，每100份文件系统会进行二次压缩打包成“ExcOMLKeyResult\_时间戳.tar.gz”，然后对于二次压缩的文件保留100份，超过数量的旧文件将会被周期性（1分钟）自动删除。

  该操作结果信息文件.tar.gz包中包含“ExcOmlLog时间戳.txt”日志文件，文件中“state”参数包含两种状态：
  - normal：表示查询或更新成功。
  - abnormal：表示查询或更新失败。失败结果是由于DS返回DCI错误码或者模块异常而导致的。
- “过滤条件文件”中的过滤条件，用于过滤用户，而“对象操作语言”中的过滤条件，不仅可以过滤用户，还用于过滤具体的节点。
- 对于单用户查询，如果不输入“对象操作语言”和“过滤条件文件”，则表示查询用户的路由数据。
- 该命令仅支持通过PGW Web LMT接入。
- 该命令仅支持超级管理员、ADMINISTRATOR级别的操作员和CUSTOM级别的操作员执行。
- 系统不支持通过本命令插入路由数据。
- 执行本命令时，将不可避免的涉及到用户的个人数据，因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护，并在操作完成后及时清理结果文件。
- EXC OML会对用户数据进行更新和删除等操作，误执行会导致部分或整局用户数据异常。
- 执行本命令时，需设置软参“EXCOMLEXECSW（EXC OML命令执行开关）”的取值为“1”。
- 当正在通过**STR CMPDB**命令下发启动数据比对分析任务时，不能同时执行本命令操作内存数据库。

| FILTERFILE | 过滤条件文件   | 用于指定对象树过滤条件的文件名。 过滤文件必须在执行该命令之前通过PGW Web LMT客户端上的“文件管理器”上传到PGW。 过滤文件支持“.xml”、“ .XML”或“.zip”格式，由字母、数字或字符“_”、“.”组成，且XML文件大小不超过8KB，压缩包大小不超过1M，解压后的XML文件大小不超过10M。 一个压缩包对应一个解压后文件，两者同名，仅后缀不同，如sup.zip和sup.xml。 取值范围：5～128位字符串。 输入原则： EXCOML为“过滤条件文件”的起始标签，仅包含子节点TreeList，用于定义过滤条件的树编号。TreeList节点包含子节点Tree，Tree节点包含一个属性Id，表示该逻辑树的树编号；Tree节点包含子节点Filter，用于配置模板支持的过滤条件。Filter节点包含子节点Filter，Filter节点包含如下属性。一个属性Relation，用于表示Filter子节点Filter之间的关系，可配置为“OR”或“AND”，如果Filter只有一个子节点，则该属性可不配置。Output、Node、Field为Relation的配置项，它们的属性表示输出的节点属性。Output配置该模板需要实际输出到文件的节点，Node节点和dbschema中的Node节点相同，Node和Field可配置多个。如不配置Output或者Output下不配置Node，表示输出该对象树下所有节点。如果不配置Field节点，表示输出该节点下的所有属性。  说明： Output节点存在Mode属性，属性取值仅支持配置为QUERY或COUNT，不区分大小写。QUERY表示走查询流程，COUNT表示走统计流程。不配置Mode属性时，默认走查询流程，当配置为统计模式时，OutPut节点下的OutNode子节点不可配置。 一个属性NodeID，用于表示该节点所在物理树根节点的ID。当NodeID属性未配置时，则直接使用Tree节点上的ID属性作为过滤节点构造过滤条件。如果配置了NodeID，则以NodeID配置的节点作为过滤节点构造过滤条件。 一个属性GMDBFILTER，用于配置过滤条件。GMDBFILTER字段里面不能包含一棵树的KEY字段，GMDBFILTER过滤条件遵循过滤条件在同一路径下的要求。属性Operation，用于表示过滤操作符，支持UNEQUAL（不等于）、EQUAL（等于）、NOTIN（不包含）、EXIST（存在）、NOTEXIST（不存在）和COUNT（计数）。属性RefNodeID，用于表示参照节点ID。属性RefField，用于表示参照字段名。属性FilterField，用于表示过滤字段。属性FilterValue，用于表示过滤字段值。属性ExtOperation，用于表示比较关系。属性RuleName，用于表示过滤规则。  说明： Operation和GMDBFILTER冲突，不能同时配置。RefNodeID需要和配置NodeID属于同一颗逻辑树。RefField需要归属于RefNodeID中的字段。Field和RefField需要类型一致。当Operation="UNEQUAL"时，NodeID、Field、RefNodeID和RefField必须配置。当Operation="EQUAL"时，NodeID、Field、RefNodeID、RefField必须配置。当Operation="NOTIN"时，NodeID、RefNodeID必须配置，Field、RefField、FilterField、FilterValue为可选配置。FilterField和FilterValue只在Operation="NOTIN"且配置Field和RefField时，能同时配置或者都不配置。FilterField需要归属于NodeID中的字段。当Operation="EXIST"，NodeID必须配置，Field、RefNodeID、RefField均不需配置。当Operation="NOTEXIST"，NodeID必须配置，Field、RefNodeID、RefField均不需配置。配置的NodeID必须和TreeId归属同一逻辑树。当Operation="COUNT"时，NodeID、ExtOperation、FilterValue必须配置。ExtOperation，当前版本仅支持配置为GREATER（大于），即ExtOperation="GREATER" 。RuleName只能配置在Filter节点，不可以配置在子节点Filter下。其中RuleName必须是英文字母、数字或特殊字符“-”、“_”、“.”的组合，不能包含两个连续的“.”，不能为空，取值不能重复，长度不能大于30个字符。当Filter节点个数大于1时，则每个Filter节点都必须配置RuleName属性。 Output、Node、Field为配置项，它们的属性表示输出的节点属性。Output配置该模板需要实际输出到文件的节点，Node节点和dbschema中的Node节点相同，Node和Field可配置多个。如不配置Output或者Output下不配置Node，表示输出该对象树下所有节点。如果不配置Field节点，表示输出该节点下的所有属性。 Operation标签包含如下属性：属性OP，用于表示操作类型，支持配置INSERT（表示插入）、UPDATE（表示更新）、DELETE（表示删除）属性DestNode，用于表示待更新节点。 Operation包含子标签Field，包含如下属性：属性DestField，用于表示待更新字段名。属性SrcNode，用于表示源节点ID。属性SrcField，用于表示源节点名。属性SrcValue，用于表示源数据值。属性ParamValue，支持PARAM1～PARAM6。属性ReplaceField，针对单条记录点对点更新成目标值。  说明： ParamValue和SrcValue、SrcNode+SrcField冲突，三种取值方式只能配置一种。ParamValue支持配合OriginOml使用，表示取值不需要转义直接为原生OML参数值。配置ParamValue属性时，需同时配置“数据文件”参数。放开UPDATE操作的Operation节点个数限制，不支持INSERT/DELETE/UPDATE混合操作配置。同一个Operation下ReplaceField和DestField不能同时配置。ReplaceField中Name只能配置相同名称，不同名称需要分开多个Operation。ReplaceField中OldValue如果配置重复，以最后配置的覆盖更新。 Union节点，包含子节点UnionNode。子节点UnionNode，它包含如下属性：Id：用于表示用户数据节点ID。Field：用于表示用户数据字段名，查找Field取值等于RefField的对应用户数据。GlobalNode：用于表示用户列表全局数据节点ID。GlobalField：用于表示用户列表全局数据字段名。RefField：用于表示全局数据关联字段名。  说明： ## 使用实例

1. 查询“模块ID”为“1097”，“FE类型”为“SUP-FE”，“对象名”为“SUID\_DATA”，“键值类型”为“AUC1”，“键值”为“100”，“对象操作语言”为“select \* from SUID\_DATA filter SUID\_DATA where USC\_INDEX/e29”的内存数据库用户数据记录，执行下面的命令（**EXC OML**命令执行结果文件可以从文件管理器中获取，其中仅单用户操作时可直接显示报文）：

   ```
   EXC OML: MID=1097, FETYPE="SUP-FE", OBJNAME="SUID_DATA", KEYTYPE="AUC1", OBJKEY="100", OML="select * from SUID_DATA filter SUID_DATA where USC_INDEX/e29";
   ```
2. 查询“模块ID”为“1098”，“FE类型”为“SUP-FE”，“对象名”为“SUID\_DATA”，“键值类型”为“AUC1”，“键值”为“101”，“对象操作语言”为“select count(\*) from SUID\_DATA filter SUID\_DATA where USC\_INDEX/e29”的内存数据库用户数据记录，执行下面的命令（**EXC OML**命令执行结果文件可以从文件管理器中获取，其中仅单用户操作时可直接显示报文）：

   ```
   EXC OML: MID=1098, FETYPE="SUP-FE", OBJNAME="SUID_DATA", KEYTYPE="AUC1", OBJKEY="101", OML="select count(*) from SUID_DATA filter SUID_DATA where USC_INDEX/e29";
   ```
3. 更新“模块ID”为“1042”，“FE类型”为“SUP-FE”，“对象名”为“SUID\_DATA”，“对象操作语言”为“update AUC1\_DATA set AUC1/ehextoraw(/q1000001FFFFFFFFF/q)”的内存数据库数据记录，执行下面的命令（**EXC OML**命令执行结果文件可以从文件管理器中获取，其中仅单用户操作时可直接显示报文）：

   ```
   EXC OML: MID=1042, FETYPE="SUP-FE", OBJNAME="SUID_DATA", OML="update AUC1_DATA set AUC1/ehextoraw(/q1000001FFFFFFFFF/q)";
   ```
4. 插入“模块ID”为“1043”，“FE类型”为“SUP-FE”，“对象名”为“SUID\_DATA”，“键值”为“400000001”，“对象操作语言”为“insert into SUID\_DATA(USC\_INDEX/c SEQUENCE) values(29/c 5)”的内存数据库数据记录，执行下面的命令（**EXC OML**命令执行结果文件可以从文件管理器中获取，其中仅单用户操作时可直接显示报文）：

   ```
   EXC OML: MID=1043, FETYPE="SUP-FE", OBJNAME="SUID_DATA", OBJKEY="400000001", OML="insert into SUID_DATA(USC_INDEX/c SEQUENCE) values(29/c 5)";
   ```
5. 删除“模块ID”为“1102”，“FE类型”为“SUP-FE”，“对象名”为“SUID\_DATA”，“键值类型”为“SUID”，“键值”为“1000000000000145”，“对象操作语言”为“delete from SUID\_DATA”的内存数据库数据记录，执行下面的命令（**EXC OML**命令执行结果文件可以从文件管理器中获取，其中仅单用户操作时可直接显示报文）：

   ```
   EXC OML: MID=1102, FETYPE="SUP-FE", OBJNAME="SUID_DATA", KEYTYPE="SUID", OBJKEY="1000000000000145", OML="delete from SUID_DATA";
   ```

**说明** 

当“EXCOMLSHIELDSWITCH”取值为“1”时，如果FE在插件包的文件dataSecCfg.xml中设置了屏蔽字段且屏蔽标识位Excoml为1，则在该命令的命令回显、结果文件和操作日志中，被屏蔽字段的值会以6个\*号代替。
