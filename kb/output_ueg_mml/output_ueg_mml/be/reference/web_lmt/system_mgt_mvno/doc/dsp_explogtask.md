# 显示导出日志任务(DSP EXPLOGTASK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询操作日志导出任务的运行状态。

- 若需要查询所有操作日志导出任务的状态，则不输入任何参数。
- 若需要查询某个操作日志导出任务的状态，请输入“任务ID”。

## 注意事项

该命令仅支持操作管理员执行。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                             |
|:----------|:-------|:-------------------------------------------------|
| EXPTASKID | 任务ID   | 用于指示系统需要按照哪个任务ID来查询操作日志导出任务状态，若不输入，则查询所有导出任务的状态。 |

## 使用实例

1. 查询所有操作日志导出任务的状态。

   ```
   DSP EXPLOGTASK:;
   ```

   ```
   %%DSP EXPLOGTASK:;%%
   RETCODE = 0 操作成功

   <Export task ID>   <Task mode>   <FE type>   <Status>       <Export file number>   <Successfully exported number>   <Start time>          <End time>            <Upload time>
   201                AUDIT         NULL        COMPLETED      1                      6                                2020-09-09 12:40:37   2020-09-09 12:40:40   2020-09-09 12:40:40
   210                COMMON        SUP-FE      UPLOADFAILED   1                      6                                2020-09-09 11:04:21   2020-09-09 11:04:29   2020-09-09 11:04:23

   Total count = 2

   There is together 1 report

   ---    END
   ```
2. 查询操作日志导出任务状态，“任务ID”为“201”。

   ```
   DSP EXPLOGTASK: EXPTASKID=201;
   ```

   ```
   %%DSP EXPLOGTASK: EXPTASKID=201;%%
   RETCODE = 0 操作成功

                   Export task ID = 201
                        Task mode = AUDIT
                          FE type = NULL
                           Status = COMPLETED
               Export file number = 1
     Successfully exported number = 6
                       Start time = 2020-09-09 12:40:37
                         End time = 2020-09-09 12:40:40
                      Upload time = 2020-09-09 12:40:40

   Total count = 9

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称                        | 输出结果解释                                                                                                                                                                                                                                                                                                                                                                      |
|:-----------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Export task ID               | 用于返回操作日志导出任务的任务ID                                                                                                                                                                                                                                                                                                                                                           |
| Task mode                    | 用于返回操作日志导出任务的模式。                                                                                                                                                                                                                                                                                                                                                            |
| FE type                      | 用于返回操作日志导出任务对应的FE类型。                                                                                                                                                                                                                                                                                                                                                        |
| Status                       | 用于返回操作日志导出任务执行的状态。 取值说明： NOTSTART：标识导出任务未开始。RUNNING：标识导出任务正在执行。ABNORMAL：标识导出任务异常终止。COMPLETED：标识导出任务完成。UPLOADING：标识执行导出任务后的结果文件正在上传到FTP/SFTP服务器端。UPLOADFAILED：标识执行导出任务后的结果文件上传到FTP/SFTP服务器端失败。SERVERNOTEXIST： 标识远端服务器配置不存在，需要通过在“USCDB MML命令”界面执行ADD RFTPSERVER或ADD RSFTPSERVER命令添加远端服务器配置。EXCMAXTASKNUM：标识已经有一个导出任务正在运行，系统每次只能运行一个任务，超出了导出任务的最大个数。STPBYUPGRADE：标识导出任务因升级停止。 |
| Export file number           | 用于返回导出文件的个数。在导出结果中，一个压缩包内会包含多个导出文件。 DMA导出的数据文件大小限制在2G以内，数据过大的情况下，会被分割成多个文件。                                                                                                                                                                                                                                                                                                 |
| Successfully exported number | 用于返回导出成功的数据记录数。                                                                                                                                                                                                                                                                                                                                                             |
| Start time                   | 用于返回开始导出数据的时间点。 若任务未开始，则不显示。                                                                                                                                                                                                                                                                                                                                                |
| End time                     | 用于返回任务结束的时间点。 若任务未结束，则不显示。                                                                                                                                                                                                                                                                                                                                                  |
| Upload time                  | 用于返回上传数据的时间点。 若未配置上传服务器，则显示为NULL。                                                                                                                                                                                                                                                                                                                                           |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释   | 原因分析                | 处理建议                                                     |
|------:|:--------|:--------------------|:---------------------------------------------------------|
|  1038 | 记录不存在。  | 输入的“任务ID”所对应的记录不存在。 | 执行LST EXPLOGTASK命令查询已存在的“任务ID”后，重新执行本命令查询，确保查询的任务在系统中存在。 |
