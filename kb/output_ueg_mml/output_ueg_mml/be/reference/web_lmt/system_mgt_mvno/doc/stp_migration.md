# 停止跨分区用户迁移任务（STP MIGRATION）

- 命令功能

## 命令功能

**须知** 

该命令属于高危命令，执行时会弹出提示：即将终止正在执行的迁移或回退操作，请确认是否继续操作。

该命令用于停止正在执行的跨分区用户迁移或回退任务。

- 当执行用户迁移操作时执行该命令，部分用户迁移至迁入分区，剩余用户保留在原迁出分区。对用户业务无影响。
- 当执行用户迁移回退操作时执行该命令，部分用户回退至原迁出分区，剩余用户保留在当前迁入分区。对用户业务无影响。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                             |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------|
| TASKID | 任务ID   | 可选必选说明：必选参数 参数含义：用于指定需要停止正在执行跨分区用户迁移或回退任务的任务ID。 取值范围：1~4294967295。 默认值：无。 配置原则：任务ID需要通过执行DSP MIGRATION命令查询后在此输入。 |

## 使用实例

停止“任务ID”为“5”的跨分区用户迁移任务。

```
STP MIGRATION: TASKID=5;
```

```
%%STP MIGRATION: TASKID=5;%%
RETCODE = 0 操作成功

There is together 1 report

---    END
```

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释               | 原因分析                                                          | 处理建议                                         |
|------:|:--------------------|:--------------------------------------------------------------|:---------------------------------------------|
|  5072 | 该命令只能通过WebLMT接入。    | 通过WebLMT之外的方式访问PGW，执行此命令。                                     | 请通过WebLMT访问PGW执行该命令。                         |
|  5244 | 指定任务不是正在运行的迁移或回退任务。 | 执行该命令停止的任务ID不是运行状态，即通过DSP MIGRATION命令查询到的“Status”不是“Running”。 | 通过DSP MIGRATION命令查看任务状态，只能停止状态为“Running”的任务。 |
