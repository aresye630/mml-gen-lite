# 查询虚拟HLR号段（LST VHLRRANGE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询虚拟HLR的号段。

- 若需要查询全部虚拟HLR号段的概要信息，请输入“系统HLR序列号”和“可操作范围类型”参数，其它不需要输入任何参数。
- 若需要查询某个虚拟HLR号段的详细信息，请输入“系统HLR序列号”和“可操作范围类型”与其它另外一个参数。

## 注意事项

- ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员具有本命令的操作权限。
- “号码前缀”和“虚拟HLR序列号”不能同时存在，查询存在如下三种情况：
  - 没有指定“号码前缀”和“虚拟HLR序列号”：查询某“系统HLR序列号”下的所有IMEI/PEI、IMSI/SUPI或MSISDN/GPSI号段信息。
  - 指定了“号码前缀”：查询某“系统HLR序列号”下指定“号码前缀”的IMSI、MSISDN或IMEI号段信息。
  - 指定了“虚拟HLR序列号”：查询某系统HLR序列号中，同一个“虚拟HLR序列号”下的所有IMSI、MSISDN或IMEI号段信息。

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                                                                                                      |
|:----------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SYSHLRSN  | 系统HLR序列号 | 用于指示系统需要按照哪个系统HLR序列号来查询号段信息。                                                                                                                                                                                              |
| HLRSN     | 虚拟HLR序列号 | 用于指示系统需要按照哪个虚拟HLR序列号来查询号段信息；若不输入则表示所有的虚拟HLR序列号。                                                                                                                                                                           |
| RANGETYPE | 可操作范围类型  | 用于指示系统需要按照哪个可操作范围类型来查询号段信息。                                                                                                                                                                                               |
| PREFIX    | 号码前缀     | 用于指示系统需要按照哪个号码前缀来查询号段信息；若不输入则表示所有的号码前缀。                                                                                                                                                                                   |
| SAVEAS    | 保存文件名    | 用于指示系统需要按照指定的“保存文件名”来保存号段到文件。 取值范围：1～20位字符串，可由字母、数字或字符“_”、“.”组成。 默认值：无。 如果指定“保存文件名”，命令执行结果保存在文件内，不在WebUI显示命令执行结果。操作员可以通过WebUI的文件下载功能获取该文件。 如果不指定“保存文件名”，且显示的记录超过1000条，则返回错误。 如果不指定“保存文件名”，且显示的记录不超过1000条，则在WebUI显示所有记录信息。 |

## 使用实例

查询虚拟HLR号段，其“系统HLR序列号”为“1”，“可操作范围类型”为“IMSI”：

```
LST VHLRRANGE: SYSHLRSN=1, RANGETYPE=IMSI;
```

输出结果如下：

```
%%LST VHLRRANGE: SYSHLRSN=1, RANGETYPE=IMSI;%%
RETCODE = 0 操作成功

                      SYSHLRSN = 1
                         HLRSN = 1
                        PREFIX = 123

Total count = 3

There is together 1 report

---    END
```

## 输出结果说明

该命令执行正常，会返回命令操作成功的提示信息和相关参数，各参数含义请参见**ADD VHLRRANGE**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。
