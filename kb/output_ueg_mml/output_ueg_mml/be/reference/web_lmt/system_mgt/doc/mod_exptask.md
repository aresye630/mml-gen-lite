# 修改导出任务(MOD EXPTASK)

## 命令功能

该命令用于修改一个导出任务。

用户可通过**DSP EXPTASK**命令查看任务，**STP EXPTASK**命令终止任务，**RMV EXPTASK**命令删除任务。

**须知** 

执行本命令修改导出任务时，如果服务器选择“OM-SERVER”代表的CSP-Lite服务器，CSP-Lite目录“/opt/HUAWEI/cgp/workshop/omu/share/nefile/autoexport/FE类型/”每一小时扫描一次。如果子目录下有总和大于1G或超过60个导出任务的结果文件，则从老到新进行删除该目录下的文件，直到大小小于或等于1G且小于或等于60个导出任务的结果文件。

## 注意事项

- 该命令仅支持操作管理员执行。
- 执行本命令时，将不可避免的涉及到用户的个人数据，因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护，并在操作完成后及时清理结果文件。
- 修改用户列表导出任务或号段列表导出任务时，参数“列表文件”必须指定，参数“P1”～“P6”不能指定。
- 当待修改的导出任务的“任务类型”为“ONCE”时，只能修改“任务状态”为“NOTSTART”的任务。
- 当待修改的导出任务的“任务类型”为“CYCLE”时，只能修改周期性任务的根任务，根任务和“任务状态”为“NOTSTART”的子任务的“MML CMD”会显示修改后的导出任务设置。“Export time”变更不会在修改后立刻显示，而是在下一个“NOTSTART”任务对应的“Export time”显示。如果修改“CYCLE”任务时，同时修改了参数“导出启动时间”，则“NOTSTART”任务的“Export time” 会立刻变更（导出任务的“MML CMD”和“Export time”等信息可以通过**DSP EXPTASK**命令查询）。
- 任务导出开始时间的设置使用的是CSP系统时间而不是本地时间，如果PGW Web LMT和CSP不在同一个时区，PGW Web LMT修改导出任务的导出开始时间需折算成CSP的系统时间。
- 当任务导出开始时间位于夏令时跳变的时间范围内，任务的导出开始时间以夏令时跳变结束后的时间为准。例如夏令时从4点跳到5点，设置任务的导出开始时间为4点30分，系统会将任务的导出启动时间修正为5点。
- 当任务的导出开始时间设置于夏令时跳出的区域，系统会将导出开始时间作为夏令时时间处理。例如退出夏令时时，系统时间从5点跳回到4点，代表这天会有两个4点30分，设置任务的导出开始时间为4点30分，系统只会在第一次经过4点30分运行任务。
- 当任务设置在夏令时跳出时间点导出，则任务将在跳出夏令时后的该时间点启动。例如夏令时跳出时间点为5:00，跳变到4:00，则设置为5:00的任务在第一次到达5:00后不会被执行，系统时间从4:00再次到5:00时才会被执行。
- 在OM Portal“CSP MML命令”界面使用**SET TZ**命令修改系统时区或夏令时，会导致之前配置的导出任务不在预期时间进行导出，此种情况需重新设置历史任务的导出开始时间，详细设置方法请联系华为工程师。
- 执行本命令启动SQL模板导出任务前，需要先在“USCDB MML命令”界面执行**STR INSTENV**命令在物理库创建全局数据表。
- SQL模板导出任务同一时间只能运行一个。
- SQL模板导出任务不支持导出USCDB的全局数据。
- 导出文件目录为DPU模块（网关类型为DMA）所在USCDB容器下的“/opt/dpu/export/download”：
  - 该目录下只能保存最近20个导出任务的结果。
  - 虚机场景下，当该目录下所有文件大小总和大于等于20G时，会依次删除老的目录直到小于20G或者只剩两个目录。
  - Full-stack裸机场景下，当该目录下所有文件大小总和大于等于60G时，会依次删除老的目录直到小于60G或者只剩两个目录。

    **说明** 

    网关类型为DMA的DPU模块号可通过在“USCDB MML命令” 界面执行**LST SRVIPADDR**命令查询，即“业务IP类型”为“DMA”对应的“DPU模块号”的值。
- 执行本命令修改导出任务时，如果服务器选择“OM-SERVER”代表的CSP-Lite服务器，需注意以下：
  - 导出任务完成后，导出文件上传至CSP-Lite目录“/opt/HUAWEI/cgp/workshop/omu/share/nefile/autoexport/FE类型/”下，FE类型为EXPTASK中选择的，如“/opt/HUAWEI/cgp/workshop/omu/share/nefile/autoexport/SUP-FE/”。该目录将作为特殊目录，不允许上传其他文件，否则存在误删除风险。
  - 如需在CSP Portal获取导出文件，登录CSP Portal，进入“系统”> “文件传输”页面，在路径“文件传输 > CGPLite文件 > 网元文件 > autoexport > FE类型”下获取导出文件，文件名称与CSP-Lite目录“/opt/HUAWEI/cgp/workshop/omu/share/nefile/autoexport/FE类型/”下文件名称一致。
  - 用户华标数据导出场景应避免选择“OM-SERVER”代表的CSP-Lite服务器，系统每小时一次的周期扫描任务会对非OK\_前缀的文件进行删除，而导出任务文件上传过程中是非OK\_前缀的文件，因此存在误删风险。为避免误删，用户华标数据导出场景推荐以下方式：
    - 导出文件上传到第三方服务器，具体请参考产品手册《配置用户数据导出至第三方服务器》。
    - 导出文件保存在本地，并配置FTP服务器，通过FTP客户端登录到本地的FTP服务器下载导出文件，具体请参考产品手册《配置用户数据导出至本端服务器》。
- 导出文件上传到远端FTP/SFTP服务器时，文件压缩格式及文件名格式说明如下：
  - 当用户在模板中配置导出文件合并时，文件压缩格式为“tar.gz”，文件名格式为“OK\_FE类型名\_导出任务ID\_开始导出的时间\_文件序号.tar.gz”，如“OK\_SUP-FE\_26\_20221013112639\_1.tar.gz”。
  - 当用户在模板中配置导出文件不合并时，文件压缩格式为“zip”，文件名格式为“OK\_MemExpFile\_FE类型名\_导出任务ID\_开始导出的时间\_DMA模块号\_TREEID\_文件序号.zip”，如“OK\_MemExpFile\_SUP-FE\_2\_20221024122600\_1043\_221\_1.zip”。

## 使用实例

1. 修改“任务ID”为“25”的导出任务的“FE类型”为“SUP-FE1”。
   - “任务ID”为“25”
   - “模板名称”为“3GUsertTemplate\_hw1”
   - “任务类型”为“ONCE”
   - “过滤参数1”～“过滤参数3”均为“1”

   ```
   MOD EXPTASK:  TASKID=25, FETYPE="SUP-FE1", TPLNAME="3GUsertTemplate_hw1", TASKTYPE=ONCE, P1="1", P2="1", P3="1";
   ```
2. 修改“任务ID”为“26”的周期性导出任务的导出周期为2天，“周期单位”设置为“DAY”，“周期值”设置为“2”。

   - “任务ID”为“26”
   - “FE类型”为“SUP-FE2”
   - “模板名称”为“3GUsertTemplate1”
   - “任务类型”为“CYCLE”
   - “导出启动时间”为“2022&03&28&12&00&00”
   - “过滤参数1”～“过滤参数3”均为“1”

   ```
   MOD EXPTASK: TASKID=26, FETYPE="SUP-FE2", TPLNAME="3GUsertTemplate1", TASKTYPE=CYCLE, CYCLEUNIT=DAY, CYCLEVALUE=2, TIME=2022&03&28&12&00&00, P1="1", P2="1", P3="1";
   ```
3. 修改“任务ID”为“27”的一次性导出任务的“导出启动时间”为“2022&03&28&11&00&00”。
   - “任务ID”为“27”
   - “FE类型”为“SUP-FE3”
   - “模板名称”为“3GUsertTemplate2”
   - “任务类型”为“ONCE”
   - “过滤参数1”～“过滤参数3”均为“1”

   ```
   MOD EXPTASK: TASKID=27, FETYPE="SUP-FE3", TPLNAME="3GUsertTemplate2", TASKTYPE=ONCE,TIME=2022&03&28&11&00&00, P1="1", P2="1", P3="1";
   ```
4. 修改任务ID为“28”的列表导出任务，“列表文件”修改为“msisdn1.txt”。

   - “任务ID”为“28”
   - “FE类型”为“SUP-FE4”
   - “模板名称”为“FULLEXPORT”
   - “任务类型”为“ONCE”

   ```
   MOD EXPTASK: TASKID=28, FETYPE="SUP-FE4", TPLNAME="FULLEXPORT", TASKTYPE=ONCE, USERFILE="msisdn1.txt";
   ```
