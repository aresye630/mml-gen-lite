# 更新加密数据（UPD CRPTDATA）

- 命令功能
- 注意事项

## 命令功能

该命令用于更新涉及加密字段数据的MML命令。在数据紧急修复过程导入增量营帐MML的时候，对于加密字段，先用假的值构造MML命令，PGW执行时写入数据库，然后再执行此命令对表的加密字段进行更新。

## 注意事项

- 该命令每次只能更新一条记录，如果更新多条记录，需要执行多次MML命令。
- 该命令仅支持超级管理员、ADMINISTRATOR级别的操作员和被赋给该命令权限的CUSTOM级别操作员执行。

## 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                                                                                                                              |
|:-------------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INFO         | 加密信息     | 用于指示系统需要对哪些表的哪些加密字段进行更新。该参数必须包含完整的路由，表和字段信息，按照先后顺序包括“路由键类型”，“路由键值”，“路由键数据库类型”，“表ID”，“字段名”，“字段值”，“字段数据库的类型”。其中“字段名”，“字段值”，“字段数据库的类型”为字段信息，可以有多个字段按顺序排列。 取值范围：长度不超过65535的字符串。 默认值：无。  说明： 该参数为必选参数。 |
| FILTER       | 过滤条件字段名称 | 用于指示系统需要对“加密信息”添加过滤条件的字段名称。 取值范围：长度不超过255的字符串。 默认值：无。                                                                                                                                             |
| FILTERTABLE  | 过滤条件表ID  | 用于指示系统需要对“加密信息”添加过滤条件的表ID。 取值范围：1～6553500。 默认值：无。                                                                                                                                                 |
| FILTERSTRING | 过滤条件语句   | 用于指示系统需要对“加密信息”添加过滤条件的过滤语句。 取值范围：长度不超过1024的字符串。 默认值：无。                                                                                                                                            |

## 使用实例

更新表ID为2021的密码字段的加密数据，其中过滤条件为：“过滤条件字段名称”为“PIID”，“过滤条件表ID”为“2008”，“过滤条件语句”为“PI ='12345678'”：

```
UPD CRPTDATA:INFO="12 12345678 string_def 2021 ABCDEFGHIJKLMN bcd_string_def",FILTER="PIID",FILTERTABLE=2008,FILTERSTRING="PI ='12345678'";
```

输出结果说明
