## 命令功能

**须知** 

- 该命令不允许进行批操作。
- 在执行批操作的过程中，如果主备PGW发生双机倒换或复位，可能导致批操作详细结果文件中部分信息丢失。
- 执行定时批操作的时间点不能设置在夏令时跳变的时间段内，否则可能会造成定时批操作延期等异常。
- 批操作中包含涉及全局数据增加/修改/删除的命令时，为防止引起FE模块大量加载全局数据，导致全局DRU流控，请联系华为技术支持确认。全局数据命令请参见产品手册中“PGW Web LMT命令”页面。
- 批操作中包含涉及全局数据查询的命令时，为防止引起PGW模块大量加载全局数据，导致PGW流控，请联系华为技术支持确认。全局数据命令请参见产品手册中“PGW Web LMT命令”页面。
- 执行本命令时，将不可避免的涉及到用户的个人数据，因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护，并在操作完成后及时清理结果文件。

该命令用于批操作处理MML命令。PGW的MML命令用于实现整个PGW的操作维护功能，批操作处理MML命令可提高运营商业务发放的效率，减少人工维护成本，降低了运营商的运营成本。

批操作分为立即执行和定时执行：

批操作定时执行原理如图1所示。

**图1** 批操作定时执行流程

1. 在USCDB中预先配置FTP服务器信息及从FTP服务器获取批操作文件的预定时间。
2. 运营商需要定时进行业务发放操作时，预先制作批操作文件并将文件上传到FTP服务器。
3. 当预定的时间到达时，USCDB从FTP服务器中获取批操作文件。
4. USCDB获取到批操作文件后，自动执行该批操作文件。

## 注意事项

- 批操作文件中的命令数不能超过单个批操作支持的最大命令条数。单个批操作支持的最大命令条数由软参“MAXCMDNUMPERBAT”决定。
- 可以同时执行的批操作的最大个数在10～200之间，具体个数依据PGW模块个数和单个PGW支持的最大批操作数而定。单个PGW支持的最大批操作数由软参“MAXBATNUMBER”决定。
  - 当（PGW模块个数×单个PGW支持的最大批操作数）小于10时，可以同时执行的批操作个数为10。
  - 当（PGW模块个数×单个PGW支持的最大批操作数）大于等于10且小于等于200时，可以同时执行的批操作个数为（PGW模块个数×单个PGW支持的最大批操作数）。
  - 当（PGW模块个数×单个PGW支持的最大批操作数）大于200时，可以同时执行的批操作个数为200。

    **说明** 

    当（PGW模块个数×单个PGW支持的最大批操作数）小于10时，单个PGW支持的最大批操作数不受软参“MAXBATNUMBER”限制，只需要保证可同时执行的批操作个数为10。
- 批操作文件根据上传或获取的方式不同而存放路径也不同，主要分为以下几类：
  - PGW作为客户端，主动从第三方服务器下载格式为BAT\_YYYYMMDD\_HH\_MM\_SS\_NNNNNNNNNN\_XXXX\_WWWW\_SNZZZ.dat的批操作文件，下载的批操作文件存放于目录"/opt/pgw/clientdownload/BAT\_YYYYMMDD\_HH\_MM\_SS\_NNNNNNNNNN\_XXXX\_WWWW\_SNZZZ.dat"，USCDB获取到文件后，每5秒从该目录下自动扫描执行批操作处理。

    **说明** 

    从第三方服务器下载的批操作文件格式为固定格式，文件命名规则为：BAT\_YYYYMMDD\_HH\_MM\_SS\_NNNNNNNNNN\_XXXX\_WWWW\_SNZZZ.dat，其中BAT为前缀，YYYYMMDD\_HH\_MM\_SS分别为年月日\_时\_分\_秒，NNNNNNNNNN为10个字符的标识符，XXXX为四位的Location ID（本局的locationID），WWWW为四位的MID（PGW模块的ID），ZZZ为HLRSN（当前局点的系统HLRSN），默认为3位数字，不足3位时前面补0，.dat为后缀。
  - PGW作为客户端，从第三方服务器定时下载批操作文件，文件为自定义格式的.dat文件，下载的批操作文件存放于目录"/opt/pgw/clientdownload/timingftp/"下，USCDB获取到文件后，每5秒从该目录下自动扫描执行批操作处理。
  - USCDB同步DPU模块下载的批操作文件到PGW模块，文件格式由lib库自定义，从DPU目录"/opt/dpu/upload/SUP-FE/"下将文件同步至PGW目录"/opt/pgw/upload/SUP-FE/"下，USCDB获取到文件后，每5秒从该目录下自动扫描执行批操作处理。
  - PGW作为服务端，通过**ADD FTPUSER**命令配置用户类型、用户名、密码等信息，用于第三方客户端登录并上传批操作文件到PGW服务器。成功上传的文件存放在“/opt/pgw/upload/”目录下。
  - 登录PGW Web LMT后，批操作文件通过“文件管理器”上传，存放在主备PGW模块所在容器上，容器目录为“/opt/pgw/pgwtmpfile/*SYSHLRSN+OPNAME*”。其中SYSHLRSN为“系统HLR序列号”，默认为3位数字，不足3位时前面补0；OPNAME为“操作员名称”。如：SYSHLRSN=1，OPNAME=admin时，最后一层目录为001admin。只有在使用操作员名称*OPNAME*登录过系统HLR序列号*SYSHLRSN*的PGW Web LMT并打开“文件管理器”界面后才会生成最后一层目录*SYSHLRSN+OPNAME*。
- 指定“文件名”参数，执行该命令后，系统会先判断“文件管理器”目录下文件是否存在，如果不存在则会去/opt/pgw/upload目录下检查文件是否存在。/opt/pgw/upload目录下存在文件，则将文件移动至“文件管理器”目录下进行批操作，/opt/pgw/upload目录下不存在文件则会导致批操作失败。
- 当批操作文件中包含多条不同命令名称的行时，建议将相同命令名称的行连续放在一起，同时保证命令执行的时序性，以便提高批操作的执行速度。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                              |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
| FILE   | 文件名    | 用于指定批处理文件的名称，文件名区分大小写，必须与实际文件名保持一致。批操作文件通过Web LMT的“文件管理器”上传到批操作文件存放目录，具体的操作请参考产品文档中的“管理文件”。 取值范围：1～128位字符串，可由字母、数字或字符“_”、“-”、“.”组成。 缺省值：无 说明：必选参数 |
| TIME   | 执行时间   | 用于指定执行批操作的起始时间，格式为YYYY&MM&DD&HH&MM&SS。 取值范围：必须大于当前系统时间，当前系统时间加1分钟～2880分钟。                                                                         |

## 使用实例

客户执行“文件名”为“file.txt”的批操作文件，“执行时间”为“2009年6月23日10点”。

```
BAT: FILE="file.txt", TIME=2009&06&23&10&00&00;
```
