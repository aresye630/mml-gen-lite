# 查看命令组（LST CCG）

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

该命令用于查询设置的命令组中包含的命令。

- 若需要查询全部命令组的概要信息，请输入“系统HLR序列号”。
- 若需要查询某个命令组的详细信息，请输入“系统HLR序列号”和“命令组ID”这两个参数的组合，若需要将查询的结果按应用类型显示，则需要输入参数“按应用类型显示”。

## 注意事项

- 软参“OPRCMDGMGRSWT”取值为“1”时，只有ADMINISTRATOR级别的操作员具有本命令的操作权限。软参“OPRCMDGMGRSWT”取值为“0”时，ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员具有本命令的操作权限。
- G\_0～G\_7默认的8个命令组受限FE插件包影响，可能存在执行命令查询命令组时不包含命令的情况。此为正常现象，表示当前FE插件包未配置对应命令组。

## 参数说明

| 参数标识             | 参数名称     | 参数说明                                                                                                 |
|:-----------------|:---------|:-----------------------------------------------------------------------------------------------------|
| SYSHLRSN         | 系统HLR序列号 | 用于指示系统需要按照哪个系统HLR序列号来查询命令组的信息。该参数通过ADD SYSHLRSN命令添加后在此引用。 取值范围：1～255 默认值：无。                          |
| CG               | 命令组      | 用于指示系统需要按照哪个命令组来查询命令组的信息；若不输入，则表示所有的命令组ID。 取值范围：G_0～G_127 默认值：无。                                     |
| DISPLAYBYAPPTYPE | 按应用类型显示  | 仅当“命令组”设置为“G_0”时该参数有效，用于指示LST CCG命令的结果报文是否按照应用类型显示。 取值范围： YES：结果报文按照应用类型显示。NO：结果报文不按照应用类型显示。 默认值：NO。 |

## 使用实例

1. 查询系统HLR序列号为20的局点中命令组G\_0包含的命令：

   ```
   LST CCG: SYSHLRSN=20, CG=G_0, DISPLAYBYAPPTYPE=YES;
   ```

   输出结果如下：

   ```
   %%LST CCG: SYSHLRSN=20, CG=G_0, DISPLAYBYAPPTYPE=YES;%%
   RETCODE = 0 操作成功

                         SYSHLRSN = 20
                               CG = G_0
                         CCGDetail
                           FETYPE = GU-HLR
                              CMD = ADD HLRSN&RMV HLRSN

                         CCGDetail
                           FETYPE = USCDB
                              CMD = BAT&LST LOG

                         CCGDetail
                           FETYPE = UPA
                              CMD = ADD UPASUB&RMV UPASUB

   Total count = 8

   There is together 1 report

   ---    END
   ```
2. 查询系统HLR序列号为20的局点中已经添加的命令组：

   ```
   LST CCG: SYSHLRSN=20;
   ```

   输出结果如下：

   ```
   %%LST CCG: SYSHLRSN=20;%%
   RETCODE = 0 操作成功

                  SYSHLRSN     CG        CGNAME
                  20           G_0       G_0
                  20           G_1       G_1
                  20           G_2       G_2
                  20           G_3       G_3
                  20           G_4       G_4
                  20           G_5       G_5
                  20           G_6       G_6
                  20           G_7       G_7

   Total count = 8

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

| 输出项名称    | 输出项解释           |
|:---------|:----------------|
| SYSHLRSN | 用于表示系统HLR序列号。   |
| CG       | 用于表示命令组ID。      |
| FETYPE   | 用于表示命令所属应用类型。   |
| CMD      | 用于表示命令集合，使用&连接。 |
| CGNAME   | 用于表示命令组的名称。     |

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释       | 原因分析                                                                                                                                       | 处理建议                      |
|------:|:------------|:-------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------|
|  1129 | CCG中没有任何命令。 | “命令组”中没有任何命令。                                                                                                                              | 请不要将没有任何命令的命令组赋给操作员。      |
|  1006 | 没有权限执行此命令。  | 当前操作员没有操作权限。 软参“OPRCMDGMGRSWT”取值为“1”时，只有ADMINISTRATOR级别的操作员具有本命令的操作权限。软参“OPRCMDGMGRSWT”取值为“0”时，ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员具有本命令的操作权限。 | 建议使用更高级别或者拥有该命令执行权限的帐号处理。 |
