# 删除未处理的批操作文件（RMV BATFILE）

- 参数说明

## 命令功能

**须知** 

该命令属于高危命令，删除操作如果没有指定具体的文件名或者输入文件名为“\*”号，将会删除业务类型下所有未处理批操作文件。因此执行该命令前，请确认是否需要删除业务类型的所有未处理批操作文件。

该命令用于删除未处理的批操作和未处理的导入批操作文件。

## 注意事项

- 若指定“业务类型”为“USCDB”，则只删除主用PGW模块所在容器的“/opt/pgw/upload”目录下的未处理文件；
- 若指定“业务类型”为其他FE类型（如“SUP-FE”），则删除主用PGW模块所在容器的指定FE类型目录（如“/opt/pgw/upload/SUP-FE”）下的未处理文件；
- 若没有指定“业务类型”，则删除主用PGW模块所在容器的“/opt/pgw/upload”目录及其子目录所有符合条件的未处理文件。其中子目录为当前加载的FE类型的目录，非FE类型的目录不会操作；
- 由于删除的时候，有些文件可能进入批操作处理阶段，实际删除的文件可能与之前执行**LST BATFILE**查询的文件结果不一致。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                  |
|:------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 业务类型   | 用于指示系统需要删除哪个业务类型的未处理的批操作文件，若不输入，表示所有的业务类型。 取值范围：长度不超过32的字符串。 默认值：无。                                                                                                                                   |
| FILENAME    | 文件名称   | 用于指示系统需要删除哪个名称的未处理的批操作文件。 取值范围：长度不超过255的字符串。  说明： 该参数支持使用通配符进行文件名的模糊匹配，所使用的特殊字符包括： “*”表示匹配所有字符。“?”表示匹配任意单个字符。“[seq]”表示匹配任意seq中的字符。“[!seq]”或者“[^seq]”表示匹配任意不在seq中的字符。 如果文件名包含特殊字符，请在字符前添加“\”转义。 默认值：无。 |

## 使用实例

1. 删除“业务类型”为“SUP-FE”的未处理的所有批操作文件：

   ```
   RMV BATFILE: SERVICETYPE="SUP-FE";
   ```
2. 使用通配符删除所有文件名以“example”开头，最后一个字符为非小写字母的“.dat”后缀文件，那么命令的“文件名称”为“example[!a-z].dat”：

   ```
   RMV BATFILE: FILENAME="example[!a-z].dat";
   ```
