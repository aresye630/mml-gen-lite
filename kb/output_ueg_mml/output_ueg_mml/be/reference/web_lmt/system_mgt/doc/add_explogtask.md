## 命令功能

**须知** 

数据导出文件包含用户的个人数据，因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护。

该命令用于增加业务发放系统操作日志导出任务的配置数据。

**说明** 

数据导出文件包含用户的个人数据，如：IMSI、MSISDN等，因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护。例如：

1. 采用安全的文件传输协议（如SFTP）传输导出文件。
2. 严格控制导出文件的访问权限。
3. 及时清理数据导出文件。

在从运营商网络获取数据前，必须要获得运营商的授权。

若需从运营商网络中获取必要的数据，需要运营商维护人员对其中的个人数据进行匿名化处理，匿名化后的数据由运营商维护人员审核后提供，以防止个人数据泄露。匿名化处理工具可以在https://support.huawei.com/获取，获取方法请参见产品手册“匿名化工具安全策略”页面。

主PGW每分钟扫描一次用户导出任务状态表，发现有需要执行的日志导出任务则启动导出任务。

启动导出任务必须满足以下条件：

- 已到达任务开始时间。
- 任务状态是NOTSTART。
- 不存在任务状态是RUNNING的任务。

**说明** 

任务状态可通过**DSP EXPLOGTASK**命令查询。

## 注意事项

- 每写入500条记录，返回一次当前记录数和文件数。
- 增加导出任务的时间请避开集中业务数据发放时间段，否则会影响系统运行。
- 任务导出开始时间的设置使用的是OMU系统时间而不是本地时间，如果LMT和OMU不在同一个时区，LMT添加导出任务的导出开始时间需折算成OMU的系统时间。
- 导出日志目录为网关类型为DMA的DPU模块所在虚拟机下容器（裸机容器）的“/opt/dpu/export/downloadexplog”：
  - 该目录下只能保存最近20个导出任务的结果。
  - 当该目录下的所有文件大小总和大于等于20G时，会依次删除老的目录直到小于20G或者只剩两个目录。
  - 当该目录下的所有文件大小总和大于等于20G且只剩两个目录时，会依次删除子目录下老的文件直到小于20G或者只剩两个文件。
- 只支持对单表操作日志的导出结果进行排序。
- 一次性导出的审计日志任务和周期性导出的审计日志任务不建议同时执行。同时执行时，一次性导出的审计日志任务会影响周期性导出的审计日志任务的正常执行，可能造成周期性导出的审计日志任务导出不及时或部分周期无法执行；周期性导出的审计日志任务会影响一次性导出的审计日志任务的运行，造成一次性导出的审计日志任务停止。
- “任务模式”为“COMMON”的普通日志导出任务与“任务模式”为“AUDIT”的审计日志导出任务可以同时执行，当一个普通日志导出任务正在运行时，同时可以执行一个审计日志导出任务，两者均可正常运行。
- 操作日志导出结果文件压缩后最大不超过2G，超过2G请指定“过滤条件”进行导出。
- 周期性导出日志任务会使CPU占用率周期性升高，建议谨慎执行。
- 执行本命令会造成CPU占用率升高，建议在业务不繁忙时段执行。
- 如果需要不带过滤条件导出日志（该命令参数“过滤条件”不设置取值），需要修改“PHYDBMAXMEMORYSIZE（物理数据库最大内存 (GB)）”软参值不小于“3”。

## 使用实例

1. 增加一次性操作日志导出任务。

   - “任务ID”为“1”
   - “任务模式”为“COMMON”
   - “FE类型”为“SUP-FE”
   - “任务类型”为“ONCE”
   - “过滤条件”为“OPERATION\_TIME >/e toDateTime(/q2021-12-30 00:00:00/q) and OPERATION\_TIME </e toDateTime(/q2022-12-30 00:00:00/q)”
   - “文件名”为“pgw\_exp\_list”

   ```
   ADD EXPLOGTASK: EXPTASKID=1, TASKMODE=COMMON, FETYPE="SUP-FE", TASKTYPE=ONCE, FILTER="OPERATION_TIME >/e toDateTime(/q2021-12-30 00:00:00/q) and OPERATION_TIME </e toDateTime(/q2022-12-30 00:00:00/q)", FILENAME="pgw_exp_list";
   ```
2. 增加周期性操作日志导出任务。

   - “任务ID”为“2”
   - “服务器名称”为“FTPSERVER1”
   - “FE类型”为“SUP-FE1”
   - “任务类型”为“CYCLE”
   - “周期单位”为“DAY”
   - “导出周期”为“1”
   - “开始时间”为“2017&04&15&12&00&00”
