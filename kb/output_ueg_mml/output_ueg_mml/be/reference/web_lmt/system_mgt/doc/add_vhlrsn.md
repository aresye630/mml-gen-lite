# 添加虚拟HLR（ADD VHLRSN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于添加虚拟HLR。当系统中需要虚拟HLR管理号段IMEI、IMSI或MSISDN和操作员虚拟HLR管理时，需要通过本命令添加虚拟HLR。

## 注意事项

- ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员具有本命令的操作权限。
- 添加虚拟HLR之前必须先添加系统HLR。具体操作参见ADD SYSHLRSN命令。
- 需要添加的HLR中“虚拟HLR序列号”不能与系统中已有的“虚拟HLR序列号”重复，否则会返回错误码1037，报错“记录已存在”。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                               |
|:---------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------|
| SYSHLRSN | 系统HLR序列号 | 用于指定系统HLR序列号，该参数通过ADD SYSHLRSN命令添加后在此引用。该参数的配置原则是： 当PGW为简单模式时，系统会自动补充“系统HLR序列号”，不需要设置。当PGW为完整模式时，“系统HLR序列号”需要设置。 取值范围：1～255 默认值：无。 |
| HLRSN    | 虚拟HLR序列号 | 用于指定虚拟HLR的序列号。 取值范围：1～255 默认值：无。                                                                                                   |
| HLRNAME  | 虚拟HLR名称  | 用于说明虚拟HLR的名称。 取值范围：1～255位的数字或字符组成的字符串。 默认值：无。                                                                                      |

## 使用实例

1. 系统需要添加一个虚拟HLR管理号段，其“虚拟HLR序列号”为“1”，“虚拟HLR名称”为“huawei”，PGW为简单模式：

   ```
   ADD VHLRSN: HLRSN=1, HLRNAME="huawei";
   ```
2. 系统需要添加一个虚拟HLR管理号段，其“虚拟HLR序列号”为“1”，“虚拟HLR名称”为“huawei”，PGW为完整模式：

   ```
   ADD VHLRSN: SYSHLRSN=1, HLRSN=1, HLRNAME="huawei";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释   | 原因分析                                    | 处理建议                                                                                 |
|------:|:--------|:----------------------------------------|:-------------------------------------------------------------------------------------|
|  1037 | 记录已存在   | 需要添加的HLR中“虚拟HLR序列号”与系统中已有的“虚拟HLR序列号”重复。 | 执行LST VHLRSN命令查询系统中已有的“虚拟HLR序列号”，再执行ADD VHLRSN命令添加“虚拟HLR序列号”与系统中已有的“虚拟HLR序列号”不同的HLR。 |
