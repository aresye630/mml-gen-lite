## 命令功能

该命令用于添加PGW操作员组，一个操作员组仅允许关联一个本地操作员。

当PGW Web LMT使用SSO（Single Sign On）功能时，如果在网管登录页面使用的网管用户在本地不存在，则可使用该命令添加一个操作员组，“组名称”输入网管用户的角色名，“操作员名称”输入本地存在的操作员名称。添加后在网管登录页面使用该网管用户即可登录成功。

## 注意事项

- 操作员的级别为“ADMINISTRATOR”或操作员被赋给该命令权限时，才具有执行该命令的权限。
- 软参“HRCPMSMGR（分层权限管理）”值设置为“1”时，会限制相同“操作员级别”账号的相互管理，添加操作员组操作需由比自身级别高的账号执行。
- 软参“HRCPMSMGR（分层权限管理）”值设置为“1”且操作员组待添加的“操作员名称”为“admin”时，只能由admin账号执行。

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                                                            |
|:----------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SYSHLRSN  | 系统HLR序列号 | 可选必选说明：必选参数 参数含义：用于指定系统HLR序列号，该参数通过ADD SYSHLRSN命令添加后在此引用。 取值范围：1～255 默认值：无。 配置原则： 当PGW为简单模式时，操作界面不会显示此参数，系统会自动补充系统HLR序列号，不需要用户设置该参数。当PGW为完整模式时，该参数需要用户设置。                       |
| GROUPNAME | 组名称      | 可选必选说明：必选参数 参数含义：用于指定组名称。 取值范围：长度不超过96字节。 默认值：无。 配置原则：该参数输入网管上操作员的角色名。网管上操作员角色名查看方法： 在MAE主界面单击“公共”，进入公共界面。在主菜单中选择“安全管理 > 用户管理”。在左侧导航树中选择“用户”，在右侧打开使用的网管用户的详细信息，即可查看使用的网管用户的角色名。 |
| OPNAME    | 操作员名称    | 可选必选说明：必选参数 参数含义：用于指定操作员的名称，该参数可填写为admin或通过ADD OPR命令添加后在此引用，可通过执行LST OPR命令查询。 取值范围：不超过32位的数字、字母和下划线组成的字符串，且首字符必须为字母。 默认值：无。 配置原则：无。                                             |

## 使用实例

添加操作员组，“系统HLR序列号”为“12”，“组名称”为“test”，“操作员名称”为“test1”。

```
ADD OPRGROUP: SYSHLRSN=12, GROUPNAME="test", OPNAME="test1";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释   | 原因分析                                 | 处理建议                                                                   |
|------:|:--------|:-------------------------------------|:-----------------------------------------------------------------------|
|  1037 | 记录已存在。  | 输入的“组名称”和“系统HLR序列号”参数所对应的记录在系统中已经存在。 | 执行LST OPRGROUP命令查询已存在的记录，重新执行本命令，确保“组名称”和“系统HLR序列号”参数所对应的记录与查询到的记录不重复。 |
|  1012 | 操作员未定义。 | 输入的“操作员名称”在系统中不存在。                   | 执行LST OPR命令查询已存在的操作员名称，确保输入的“操作员名称”存在后再执行该命令。                          |

## 参考信息

**简单模式**

简单模式是PGW的一种应用模式，指整个系统只允许存在一个“系统HLR序列号”，处于简单模式下的系统不支持业务层容灾功能。通过将软参“APPLICATIONTYPE（应用模式）”设为“0”将PGW的应用模式设为简单模式。

**完整模式**

完整模式是PGW的另一种应用模式，指整个系统允许存在多个“系统HLR序列号”，处于完整模式下的系统支持业务层容灾功能。通过将软参“APPLICATIONTYPE（应用模式）”设为“1”将PGW的应用模式设为完整模式。
