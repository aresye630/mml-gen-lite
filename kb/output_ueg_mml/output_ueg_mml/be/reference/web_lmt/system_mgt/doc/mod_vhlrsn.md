# 修改虚拟HLR（MOD VHLRSN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令属于高危命令，修改虚拟HLR可能会导致当前虚拟HLR不可用。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一条虚拟运营商数据记录的某些参数进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一条虚拟运营商：

- 系统HLR序列号
- 虚拟HLR序列号

## 注意事项

- ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员具有本命令的操作权限。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                        |
|:---------|:---------|:----------------------------------------------------------------------------|
| SYSHLRSN | 系统HLR序列号 | 标识一条虚拟HLR数据记录的关键字段之一（其取值不能被修改），用于指定需要修改哪一个系统HLR序列号，操作员可以使用LST VHLRSN命令查询获得。 |
| HLRSN    | 虚拟HLR序列号 | 标识一条虚拟HLR数据记录的关键字段之一（其取值不能被修改），用于指定需要修改哪一个虚拟HLR序列号，操作员可以使用LST VHLRSN命令查询获得。 |
| HLRNAME  | 虚拟HLR名称  | 用于说明虚拟HLR的名称。 取值范围：1～255位的数字或字符组成的字符串。                                      |

## 使用实例

当前存在一个虚拟HLR，其“系统HLR序列号”为“1”，“虚拟HLR序列号”为“1”，现将“虚拟HLR名称”修改为“test\_1”：

```
MOD VHLRSN: SYSHLRSN=1, HLRSN=1, HLRNAME="test_1";
```
