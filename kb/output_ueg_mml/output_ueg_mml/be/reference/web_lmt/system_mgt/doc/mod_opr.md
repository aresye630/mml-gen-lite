## 命令功能

**须知** 

该命令属于高危命令，修改操作员会造成此操作员失效。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一条PGW操作员数据记录的某些参数进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一条PGW操作员：

- “系统HLR序列号”
- “操作员名称”

## 注意事项

- 操作员的级别为“ADMINISTRATOR”或操作员被赋给该命令权限时，才具有修改其他操作员数据的权限。
- 如果修改操作员的级别为“CUSTOM”，而且需要添加“G\_8～G\_127”之间的“命令组”时，该命令组必须在系统中已经存在。请参见**ADD CCG**命令添加“G\_8～G\_127”间的命令组。
- 本命令不能用于修改自己的密码。
- 在安全策略开关打开的情况下，使用本命令重置某个操作员的密码后，如果没有通过执行**MOD PWD**更改该操作员的密码，则在操作员首次登录Web LMT的时候，强制其修改该操作员的密码。同时，如果该操作员是业务发放系统用户，需要通知业务发放系统同步修改，否则会影响业务发放系统的业务。
- 如果操作员的“日志审计”为“TRUE”，则该操作员可以使用**LST LOG**查看其他操作员的操作日志，出于信息安全考虑，请谨慎赋予操作员日志审计权限。
- 重置某个操作员的密码后，需执行**KIK ONLINEOPR**命令下线被重置的操作员。
- 对于低版本升级上来的账号，账号类型默认为人机、机机账号合一，存在安全风险，系统会上报“ALM-10031 系统存在不安全的配置项”告警。故必须使用该命令将其账号类型修改为“人机账号”或“机机账号”。
- 人机账号只能访问PGW/DMS Web LMT，机机账号只能访问营帐端口。
- 修改“账号类型”或“操作员状态”成功后，需执行**KIK ONLINEOPR**命令下线被修改的操作员。
- 该命令不允许进行批操作。
- 软参“HRCPMSMGR（分层权限管理）”值设置为“1”时，会限制相同“操作员级别”账号的相互管理，账户管理操作需由比自身级别高且拥有账户管理权限的账号执行。
- 软参“OPRCMDGMGRSWT”取值为“1”时，修改“操作员级别”为“CUSTOM”的操作员时，选择的“命令组”中不能含有**ADD CCG**、**RMV CCG**、**MOD CCG**、**LST CCG**、**SET CCGN**或**LST CCGN**命令。选择的“命令组”中包含哪些命令可通过**LST CCG**查询。
- 密码长期使用会增加被盗窃和破解的风险，而且使用的时间越长，被盗窃和破解的风险越高。定期修改密码可以有效防范这种情况的发生，因此强烈建议您定期修改密码。

## 使用实例

在“系统HLR序列号”为“1”的局点中修改“操作员名称”为“pgwuser”的用户，“操作员级别”改为“GUEST”，“日期限制开关”为“LIMIT”，“起始日期”为“2009&08&10”，“结束日期”为“2009&12&31”，“时间限制开关”为“LIMIT”，“起始时间”为“10&22&30”，“结束时间”为“20&22&32”，“星期限制开关”为“LIMIT”，“星期限制”为“SUN&TUE&THU&SAT”，“操作员状态”改为“INACTIVE”，“账号类型”为“MAN-MACHINE”：

```
MOD OPR: SYSHLRSN=1, OPNAME="pgwuser", UG=GUEST, DATE=LIMIT, STARTDATE=2009&08&10, ENDDATE=2009&12&31, TIME=LIMIT, STARTTIME=10&22&30, ENDTIME=20&22&32, WEEK=LIMIT, WK=SUN&TUE&THU&SAT, STATUS=INACTIVE, ATP=MAN-MACHINE;
```
