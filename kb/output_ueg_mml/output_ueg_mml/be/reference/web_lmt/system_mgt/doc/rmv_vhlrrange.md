# 删除虚拟HLR号段（RMV VHLRRANGE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令属于高危命令，删除虚拟HLR号段会造成缩小既有操作员的号段范围。因此执行该命令前，需要与华为技术支持确认后才可以实施。

本命令用于删除虚拟HLR的号段。当系统需要删除IMEI/PEI、IMSI/SUPI或MSISDN/GPSI号段时，执行本命令。

## 注意事项

- ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员具有本命令的操作权限。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                  |
|:----------|:---------|:----------------------------------------------------------------------|
| SYSHLRSN  | 系统HLR序列号 | 标识一条虚拟HLR号段数据记录的关键字段之一，用于指定需要删除哪一个系统HLR序列号，操作员可以使用LST SYSHLRSN命令查询获得。 |
| RANGETYPE | 可操作范围类型  | 标识一条虚拟HLR号段数据记录的关键字段之一，用于指定需要删除哪一个可操作范围类型。                            |
| PREFIX    | 号码前缀     | 标识一条虚拟HLR号段数据记录的关键字段之一，用于指定需要删除哪一个号码前缀。                               |

## 使用实例

系统通过本命令删除虚拟HLR号段，其“系统HLR序列号”为“1”，“可操作范围类型”为“IMSI”，“号码前缀”为“131”：

```
RMV VHLRRANGE: SYSHLRSN=1, RANGETYPE=IMSI, PREFIX="131";
```
