# 查询未处理的批操作文件（LST BATFILE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询未处理的批操作和未处理的导入批操作文件。

## 注意事项

- 若指定“业务类型”为“USCDB”，则只查询主用PGW模块所在容器的“/opt/pgw/upload”目录下的未处理文件；
- 若指定“业务类型”为其他FE类型（如“SUP-FE”），则查询主用PGW模块所在容器的指定FE类型目录（如“/opt/pgw/upload/SUP-FE”）下的未处理文件；
- 若没有指定“业务类型”，则查询主用PGW模块所在容器的“/opt/pgw/upload”目录及其子目录下所有符合条件的未处理文件。其中子目录为当前加载的FE类型的目录，非FE类型的目录不会查询；
- 如果“保存文件名”参数没有输入值，则不会保存为文件，查询结果显示在“PGW Web LMT”界面上，最大记录数为200条操作日志，超过200条则不显示。
- 如果“保存文件名”参数有输入值，则会保存为文件，查询结果保存在文件中。操作员可以通过“PGW Web LMT”界面左上角的“文件管理器”下载该文件。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                      |
|:------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 业务类型   | 用于指示系统需要按照哪个业务类型来查询未处理的批操作文件，若不输入，表示所有的业务类型。 取值范围：长度不超过32的字符串。 默认值：无。                                                                                                                                     |
| FILENAME    | 文件名称   | 用于指示系统需要按照哪个文件名称来查询未处理的批操作文件。 取值范围：长度不超过255的字符串。 默认值：无。  说明： 该参数支持使用通配符进行文件名的模糊匹配，所使用的特殊字符包括： “*”表示匹配所有字符。“?”表示匹配任意单个字符。“[seq]”表示匹配任意seq中的字符。“[!seq]”或者“[^seq]”表示匹配任意不在seq中的字符。 如果文件名包含特殊字符，请在字符前添加“\”转义。 |
| SAVEAS      | 保存文件名  | 用于指示系统需要按照指定的保存文件名来保存查询结果到文件。 取值范围：1～20位字符串，可由字母、数字或字符组成，字符不能包含“>”、“/”、“?”、“\”、“:”、“*”、“"”、“<”、“|”、“,”、“;”、“=”和“'”。 默认值：无。                                                                                |

## 使用实例

1. 查询“业务类型”为“SUP-FE”的未处理的批操作文件：

   ```
   LST BATFILE: SERVICETYPE="SUP-FE";
   ```

   输出结果如下：

   ```
   %%LST BATFILE: SERVICETYPE="SUP-FE";%%
   RETCODE = 0 操作成功

                       SERVICETYPE = SUP-FE
                          FILENAME = example.txt
                              SIZE = 108B
                          MODIFIED = 2023-10-30 11:49:07

   Total count = 4

   There is together 1 report

   ---    END
   ```
2. 使用通配符查询所有文件名以“example”开头，最后一个字符为非小写字母的“.dat”后缀文件，那么命令的“文件名称”为“example[!a-z].dat”：

   ```
   LST BATFILE: FILENAME="example[!a-z].dat";
   ```

   输出结果如下：

   ```
   %%LST BATFILE: FILENAME="example[!a-z].dat";%%
   RETCODE = 0 操作成功

   SERVICETYPE           FILENAME       SIZE        MODIFIED 
   USCDB                 example1.dat   26B         2023-10-30 11:50:53 
   USCDB                 example1.dat   258B        2023-10-30 11:49:07 
   USCDB                 example3.dat   438B        2023-10-30 11:49:07

   Total count = 3

   There is together 1 report

   ---    END
   ```
