# 删除周期性任务（RMV PERIODTASK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除周期性任务。

## 注意事项

- 该命令仅支持通过PGW Web LMT接入。
- 该命令仅支持超级管理员、ADMINISTRATOR级别的操作员和CUSTOM级别的操作员执行。
- 执行本命令时，请至少指定一个参数。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                          |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------|
| TASKID | 任务ID   | 可选必选说明：可选参数。 参数含义：标识一条周期性任务的关键字段之一，用于指定删除哪个任务ID的周期性任务，可以使用LST PERIODTASK命令查询获得。 取值范围：1～512。 默认值：无。 配置原则：无。                    |
| FETYPE | FE类型   | 可选必选说明：可选参数。 参数含义：用于指定删除哪个FE类型的周期性任务。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：此参数在USCDB下唯一，通过“MML命令行 - USCDB”的LOD FEPLUG命令加载FE插件后在此引用。 |

## 使用实例

- 删除“任务ID”为“1”的周期性任务。

  ```
  RMV PERIODTASK: TASKID=1;
  ```
- 删除“FE类型”为“USCDB”的周期性任务。

  ```
  RMV PERIODTASK: FETYPE="USCDB";
  ```
