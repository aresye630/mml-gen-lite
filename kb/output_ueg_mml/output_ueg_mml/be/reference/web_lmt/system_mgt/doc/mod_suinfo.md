# 修改超级管理员信息（MOD SUINFO）

## 命令功能

**须知** 

该命令属于高危命令，修改超级管理员信息，会造成当前已经登录的超级管理员不可用。因此执行该命令前，需要与华为技术支持确认后才可以实施。

本命令用于修改超级管理员的信息。

## 注意事项

- 此命令只有超级管理员才能执行。
- 在PGW Web LMT上执行此命令修改了超级管理员的名称之后，请单击右上角的用户图标，再单击“Logout”退出，再使用新的超级管理员名称进行登录，并执行**KIK ONLINEOPR**命令下线修改前的超级管理员。
- 在PGW Web LMT上执行此命令修改除超级管理员名称之外的信息，不需要退出并重新登录。
- 人机账号只能访问PGW/DMS Web LMT，机机账号只能访问营帐端口。
- 该命令不允许进行批操作。
- 密码长期使用会增加被盗窃和破解的风险，而且使用的时间越长，被盗窃和破解的风险越高。定期修改密码可以有效防范这种情况的发生，因此强烈建议您定期修改密码。

## 参数说明

| 参数标识      | 参数名称      | 参数说明                                                                                                                                                |
|:----------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| NEWOPNAME | 超级管理员的新名称 | 用于指定超级管理员的新名称。 输入的值不能为超级管理员密码中包含的字段，同时也不允许为密码的逆序形式且不区分大小写的各种组合。例如：密码为ABC，则名称不能包含ABC、CBA、Abc、abc、cba、Cba等字符串。 取值范围：不超过32位的数字、字母和下划线组成的字符串，且首字符必须为字母。 |
| RELGI     | 重复登录限制开关  | 用于指定是否限制超级管理员重复登录服务器。系统初始设置值为“NOLIMIT”。 各参数选项的含义是：NOLIMIT：不限制LIMIT：限制                                                                               |
| ATP       | 账号类型      | 用于指定本命令设置的信息所属账号的类型。 参数选项的含义是： MAN-MACHINE：人机账号。 默认值：无。                                                                                             |
| PWD       | 密码        | 用于输入超级管理员的当前密码。当指定“超级管理员的新名称”时，此参数输入不能为空。 取值范围：6～64位的字符串。                                                                                           |

## 使用实例

将超级管理员的名称修改为“newadmin”，将超级管理员的重复登录限制开关修改为“LIMIT”，将超级管理员的“账号类型”修改为“MAN-MACHINE”，输入超级管理员的“密码”，执行命令如下：

```
MOD SUINFO: NEWOPNAME="newadmin", RELGI=LIMIT, ATP=MAN-MACHINE, PWD="*****";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释     | 原因分析                                                 | 处理建议                                                                      |
|------:|:----------|:-----------------------------------------------------|:--------------------------------------------------------------------------|
|  1011 | 操作员已经存在。  | 输入的“超级管理员的新名称”与系统中某个已存在的普通操作员的名称相同。                  | 执行LST OPR命令查询系统中所有已存在的普通操作员。 输入与步骤1中查询到的任何操作员名称不同的新名称，然后重新执行MOD SUINFO命令。 |
|  1009 | 参数丢失。     | 执行MOD SUINFO命令，但是没有输入任何参数。当输入“超级管理员的新名称”时，输入的“密码”为空。 | 参数“超级管理员的新名称”、“重复登录限制开关”和“账号类型”至少输入一个。当输入“超级管理员的新名称”时，请正确输入“密码”。          |
|  1013 | 用户名或密码错误。 | 输入的“超级管理员的新名称”不符合要求，或输入的“密码”错误。                      | 请重新输入符合要求的“超级管理员的新名称”，输入的“超级管理员的新名称”不能为“密码”中包含的字段。请输入正确的“密码”。             |
