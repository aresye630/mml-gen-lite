# 添加命令组（ADD CCG）

## 命令功能

该命令用于为PGW中的命令分组。G\_0～G\_7为默认的8个命令组，包含系统中可以执行的所有命令（除ADMINISTRATOR级别可以执行的命令）。其中命令组G\_0～G\_7具有的功能分别为：

- G\_0:用户数据查询。
- G\_1:用户数据修改。
- G\_2:全局数据查询。
- G\_3:全局数据修改。
- G\_4:鉴权数据查询。
- G\_5:鉴权数据操作。
- G\_6:业务数据查询。
- G\_7:业务数据修改。

而G\_8～G\_127的命令组只有ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员可以添加。

- 软参“OPRCMDGMGRSWT”取值为“1”时，只有ADMINISTRATOR级别的操作员可以添加G\_8～G\_127的命令组。
- 软参“OPRCMDGMGRSWT”取值为“0”时，ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员可以添加G\_8～G\_127的命令组。当将多个命令组通过**ADD OPR**或**MOD OPR**命令赋给某个操作员后，该操作员即拥有了执行该命令组中所有命令的权限。同时，不同的命令组中的命令可以重复。

## 注意事项

- 软参“OPRCMDGMGRSWT”取值为“1”时，只有ADMINISTRATOR级别的操作员具有本命令的操作权限。软参“OPRCMDGMGRSWT”取值为“0”时，ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员具有本命令的操作权限。
- 如果执行该命令添加的命令组中包含系统HLR管理、虚拟HLR管理、虚拟HLR号段管理中除了**LST OPRRANGE**以外的命令，在将此命令组赋给操作员时要慎重考虑，该操作员拥有此命令组中命令的权限后，将等同于admin的执行权限，可对系统HLR、虚拟HLR、虚拟HLR号段进行相应的管理。
- 软参“OPRCMDGMGRSWT”取值为“1”时，添加的“命令组”对应的“命令名”中，不允许包含权限管理方面的命令，即不允许包含**ADD CCG**、**RMV CCG**、**MOD CCG**、**LST CCG**、**SET CCGN**或**LST CCGN**。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                |
|:---------|:---------|:------------------------------------------------------------------------------------------------------------------------------------|
| SYSHLRSN | 系统HLR序列号 | 用于指定系统HLR序列号，该参数通过ADD SYSHLRSN命令添加后在此引用。该参数的配置原则是： 当PGW为简单模式时，系统会自动补充SYSHLRSN，不需要用户设置。当PGW为完整模式时参数SYSHLRSN需要用户设置。 取值范围：1～255 默认值：无。 |
| CG       | 命令组      | 用于指定系统的命令组ID。 取值范围：G_8～G_127 默认值：无。                                                                                                 |
| CMD      | 命令名      | 用于指定命令集合的命令名，命令集合中命令与命令之间使用&连接。 默认值：无。                                                                                              |

## 使用实例

系统通过本命令为PGW中的命令分组，其“系统HLR序列号”为“1”，“命令组”为“G\_8”，“命令名”为“LST\_LOG”：

```
ADD CCG: SYSHLRSN=1, CG=G_8, CMD=LST_LOG;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                                    | 原因分析                                                                                                                                       | 处理建议                                                          |
|------:|:-----------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------|
|  5246 | 当前OPRCMDGMGRSWT开关已打开，不允许给帐号分配权限管理方面的命令组。 | 软参“OPRCMDGMGRSWT”取值为“1”时，添加的“命令组”对应的“命令名”中，包含了权限管理方面的命令，即包含了ADD CCG、RMV CCG、MOD CCG、LST CCG、SET CCGN或LST CCGN。                             | 软参“OPRCMDGMGRSWT”取值为“1”时，重新执行该命令，确保添加的命令组对应的命令名中不包含权限管理方面的命令。 |
|  1006 | 没有权限执行此命令。                               | 当前操作员没有操作权限。 软参“OPRCMDGMGRSWT”取值为“1”时，只有ADMINISTRATOR级别的操作员具有本命令的操作权限。软参“OPRCMDGMGRSWT”取值为“0”时，ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员具有本命令的操作权限。 | 建议使用更高级别或者拥有该命令执行权限的帐号处理。                                     |
