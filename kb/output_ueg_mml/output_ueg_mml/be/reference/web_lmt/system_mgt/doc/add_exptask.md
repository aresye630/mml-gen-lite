## 命令功能

**须知** 

数据导出文件包含用户的个人数据，因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护。

该命令用于增加或启动一个导出任务。

该命令执行成功后，PGW会返回本次任务的任务ID，用户可通过**DSP EXPTASK**命令查看任务，**STP EXPTASK**终止任务。

**须知** 

- 数据导出文件包含用户的个人数据，如：IMSI、MSISDN等，因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护。例如：
  1. 采用安全的文件传输协议（如SFTP）传输导出文件。
  2. 严格控制导出文件的访问权限。
  3. 及时清理数据导出文件。
- 在从运营商网络获取数据前，必须要获得运营商的授权。
- 若需从运营商网络中获取必要的数据，需要运营商维护人员对其中的个人数据进行匿名化处理，匿名化后的数据由运营商维护人员审核后提供，以防止个人数据泄露。匿名化处理工具可以在https://support.huawei.com/获取，获取方法请参见产品手册“匿名化工具安全策略”页面。
- 执行本命令添加导出任务时，如果服务器选择“OM-SERVER”代表的CSP-Lite服务器，CSP-Lite目录“/opt/HUAWEI/cgp/workshop/omu/share/nefile/autoexport/FE类型/”每一小时扫描一次。如果子目录下有总和大于1G或超过60个导出任务的结果文件，则从老到新进行删除该目录下的文件，直到大小小于或等于1G且小于或等于60个导出任务的结果文件。

## 注意事项

- 同一FE类型同一数据类型的导出任务，支持同时启动的最大导出任务个数为节点个数最小的Cluster的节点数。例如，同一数据类型的导出任务中存在3个Cluster，每个Cluster配置的节点数目分别为2个、3个、4个，则支持同时启动的最大导出任务个数为2个。
- 导出任务信息最多可以保存300条，超过300条记录则删除最老的记录。

  **说明** 

  以下两种状态的导出任务不会被清理最老记录时清除。

  - “NOTSTART”
  - “CYCLERUNNING”

  任务状态可通过**DSP EXPTASK**命令查询获得。
- 增加导出任务的时间请避开集中业务数据发放时间段，否则会影响系统运行。
- 增加导出任务之前，必须在“MML命令行 - USCDB”上通过执行**ADD SRVIPADDR**命令增加“业务IP类型”为“DMA”的IP地址，否则导出任务失败。
- 增加用户列表导出任务或号段列表导出任务时，参数“列表文件”必须指定，参数“P1”～“P6”不能指定。
- 任务导出开始时间的设置使用的是CSP系统时间而不是本地时间，如果PGW Web LMT和CSP不在同一个时区，PGW Web LMT添加导出任务的导出开始时间需折算成CSP的系统时间。
- 当任务导出开始时间位于夏令时跳变的时间范围内，任务的导出开始时间以夏令时跳变结束后的时间为准。例如夏令时从4点跳到5点，设置任务的导出开始时间为4点30分，系统会将任务的导出启动时间修正为5点。
- 当任务的导出开始时间设置于夏令时跳出的区域，系统会将导出开始时间作为夏令时时间处理。例如退出夏令时时，系统时间从5点跳回到4点，代表这天会有两个4点30分，设置任务的导出开始时间为4点30分，系统只会在第一次经过4点30分运行任务。
- 当任务设置在夏令时跳出时间点导出，则任务将在跳出夏令时后的该时间点启动。例如夏令时跳出时间点为5:00，跳变到4:00，则设置为5:00的任务在第一次到达5:00后不会被执行，系统时间从4:00再次到5:00时才会被执行。
- 在OM Portal“CSP MML命令”界面使用**SET TZ**命令修改系统时区或夏令时，会导致之前配置的导出任务不在预期时间进行导出，此种情况需重新设置历史任务的导出开始时间，详细设置方法请联系华为工程师。
- 执行本命令启动SQL模板导出任务前，需要先在“USCDB MML命令”界面执行****STR INSTENV****命令在物理库创建全局数据表。
- SQL模板导出任务同一时间只能运行一个。
- SQL模板导出任务不支持导出USCDB的全局数据。
- 导出文件目录为DPU模块（网关类型为DMA）所在容器下的“/opt/dpu/export/download”：
  - 该目录下只能保存最近20个导出任务的结果。
  - 虚机场景下，当该目录下所有文件大小总和大于等于20G时，会依次删除老的目录直到小于20G或者只剩两个目录。
  - Full-stack裸机场景下，当该目录下所有文件大小总和大于等于60G时，会依次删除老的目录直到小于60G或者只剩两个目录。

    **说明** 

    网关类型为DMA的DPU模块号可通过在“USCDB MML命令” 界面执行**LST SRVIPADDR**命令查询，即“业务IP类型”为“DMA”对应的“DPU模块号”的值。
- **ADD EXPTASK**添加导出任务时，如果服务器选择“OM-SERVER”代表的CSP-Lite服务器，需注意以下：

  **说明** 

  仅导出UPCF策略数据时，服务器可以选择“OM-SERVER”，其他场景不允许选择“OM-SERVER”服务器。

  - 导出任务完成后，导出文件上传至CSP-Lite目录“/opt/HUAWEI/cgp/workshop/omu/share/nefile/autoexport/FE类型/”下，FE类型为EXPTASK中选择的，如“/opt/HUAWEI/cgp/workshop/omu/share/nefile/autoexport/SUP-FE/”。该目录将作为特殊目录，不允许上传其他文件，否则存在误删除风险。
  - 如需在CSP Portal获取导出文件，登录CSP Portal，进入“系统”> “文件传输”页面，在路径“文件传输 > CGPLite文件 > 网元文件 > autoexport > FE类型”下获取导出文件，文件名称与CSP-Lite目录“/opt/HUAWEI/cgp/workshop/omu/share/nefile/autoexport/FE类型/”下文件名称一致。
  - 用户华标数据导出场景应避免选择“OM-SERVER”代表的CSP-Lite服务器，系统每小时一次的周期扫描任务会对非OK\_前缀的文件进行删除，而导出任务文件上传过程中是非OK\_前缀的文件，因此存在误删风险。为避免误删，用户华标数据导出场景推荐以下方式：
    - 导出文件上传到第三方服务器，具体请参考产品手册《配置用户数据导出至第三方服务器》。
    - 导出文件保存在本地，并配置FTP服务器，通过FTP客户端登录到本地的FTP服务器下载导出文件，具体请参考产品手册《配置用户数据导出至本端服务器》。
- 导出文件上传到远端FTP/SFTP服务器时，文件压缩格式及文件名格式说明如下：
  - 当用户在模板中配置导出文件合并时，文件压缩格式为“tar.gz”，文件名格式为“OK\_FE类型名\_导出任务ID\_开始导出的时间\_文件序号.tar.gz”，如“OK\_SUP-FE\_26\_20221013112639\_1.tar.gz”。
  - 当用户在模板中配置导出文件不合并时，文件压缩格式为“zip”，文件名格式为“OK\_MemExpFile\_FE类型名\_导出任务ID\_开始导出的时间\_DMA模块号\_TREEID\_文件序号.zip”，如“OK\_MemExpFile\_SUP-FE\_2\_20221024122600\_1043\_221\_1.zip”。
- 该命令仅支持操作管理员执行。
- 执行本命令时，将不可避免的涉及到用户的个人数据，因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护，并在操作完成后及时清理结果文件。
- 执行SQL模板导出任务时，建议修改“PHYDBMAXMEMORYSIZE（物理数据库最大内存 (GB)）”软参值不小于“3”。
- 需要导出营帐日志时建议使用**ADD EXPLOGTASK**命令进行导出；若使用**ADD EXPTASK**命令导出营帐日志，导出过程中系统可能上报告警“ALM-14034 目录大小超过最大值”，此告警对当前导出任务与导出结果无影响，完成导出后告警自动消除。

取值范围：长度不超过256位字符组成的字符串，取值为“选项:值&选项:值”的形式，其中“&”为选项之间的间隔符，冒号“:”为选项及其值之间的间隔符，选项和值最终会去掉首尾的空格符。“选项”为固定取值，仅可为“FETYPE”、“FILENAMETYPE”、“MERGETARTYPE”、“PGWSPLITSIZE”、“ISNEEDMERGEFILE”和“COMPRESSTYPE”，说明如下： FETYPE:VALUE，其中VALUE需为由大小写字母、数字0-9、下划线“_”、横线“-”组成的字符串，长度不超32。FILENAMETYPE:UDB，标识5G USCDB导出模板中未配置FileListCfg的导出文件名格式，与4G USCDB（ATCA UDB或NFV UDB）版本的保持一致。FILENAMETYPE:PDB，标识5G USCDB导出模板中配置FileListCfg的导出文件名格式，与4G USCDB（ATCA UDB或NFV UDB）版本的保持一致，导出文件名中不携带网元模块号。FILENAMETYPE:DISTRIBUTE，标识5G USCDB导出模板中配置了FileListCfg的导出文件名格式，与4G USCDB（ATCA UDB或NFV UDB）版本的保持一致。MERGETARTYPE:Single，只有Single一个固定取值，其他值非法。当填写该参数时，表示将导出的文件分别压缩，即每一个导出文件形成一个压缩包；当不填写该参数时，表示将导出的文件合并压缩，即全部导出文件形成一个压缩包。PGWSPLITSIZE:VALUE，其中VALUE取值范围说明如下，单位M。如果模板中配置了SplitSize，VALUE取值范围：SplitSize的取值～15360。如果模板中未配置SplitSize，VALUE取值范围：2048～15360。 ISNEEDMERGEFILE:TRUE，导出文件合并。该参数配置的导出文件是否合并功能优先级高于导出模板中配置的导出文件是否合并功能。ISNEEDMERGEFILE:FALSE，导出文件不合并。该参数配置的导出文件是否合并功能优先级高于导出模板中配置的导出文件是否合并功能。COMPRESSTYPE:VALUE，其中VALUE取值范围为tar.gz、gz。当配置该参数时，表示将每个导出文件按照VALUE设置的格式进行单独压缩。单个压缩包文件大小超过或等于2G时，导出任务会异常终止，任务状态显示为“FILEEXC2GB”。  说明： PGWSPLITSIZE仅在导出模板中打开了合并文件标识功能时生效。MERGETARTYPE仅在导出模板为SQL导出或者模板中打开了合并文件标识功能时生效。园区导出任务有独有的文件名命名规范，不允许配置“格式化选项”参数。如果导出任务文件名已在导出模板中定制，则不允许配置“格式化选项”参数。FILENAMETYPE:DISTRIBUTE仅在导出模板中配置了FileListCfg配置项且没有打开导出文件合并功能时生效。FILENAMETYPE:PDB仅在导出模板中配置了FileListCfg配置项且打开导出文件合并功能时生效。配置“格式化选项”参数取值为FILENAMETYPE:PDB时，导出结果不输出空文件。COMPRESSTYPE:VALUE仅在导出模板中打开了导出文件合并功能、配置了FileListCfg配置项且FileListCfg配置的文件名无目录时生效。如果导出模板中已经配置了buildSummaryFileFunc和FileListCfg配置项，则不允许配置ISNEEDMERGEFILE:TRUE。如果配置了ISNEEDMERGEFILE:TRUE，则导出模板中IsTarCompress配置项不生效。如果导出模板为sql导出或日志导出模板时，则不允许配置ISNEEDMERGEFILE:TRUE。COMPRESSTYPE:VALUE和ISNEEDMERGEFILE:FALSE不可同时配置。PGWSPLITSIZE:VALUE和ISNEEDMERGEFILE:FALSE不可同时配置。FILENAMETYPE:PDB和ISNEEDMERGEFILE:FALSE不可同时配置。如果导出模板中配置了CampusFileMerge为False时，则不允许配置ISNEEDMERGEFILE:FALSE。如果配置了ISNEEDMERGEFILE:FALSE，则导出模板中CustomizeTarName配置项不生效。 默认值：无。 |
