# 删除操作员虚拟HLR（RMV OPRHLRSN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令属于高危命令，删除操作员虚拟HLR会造成该操作员不能继续操作该虚拟HLR序列号。因此执行该命令前，需要与华为技术支持确认后才可以实施。

本命令用来删除系统HLR下的操作员所能操作的虚拟HLR的范围。

## 注意事项

- 操作员的级别为ADMINISTRATOR或操作员被赋给该命令权限时，才具有删除其他操作员所能操作虚拟HLR范围的权限。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                   |
|:---------|:---------|:---------------------------------------------------------------------------------------|
| SYSHLRSN | 系统HLR序列号 | 系统HLR序列号。当PGW为简单模式时，系统会自动补充SYSHLRSN，不需要用户设置；完整模式时参数SYSHLRSN需要用户设置。 取值范围：1～255。 说明：必选参数 |
| OPNAME   | 操作员名称    | 操作员登录的名称。 取值范围：不超过32位的数字、字母和下划线组成的字符串，且首字符必须为字母。 说明：必选参数                               |
| HLRSN    | 虚拟HLR序列号 | 虚拟HLR序列号 取值范围：1～255。 说明：必选参数                                                           |

## 使用实例

删除系统HLR为1的局点中操作员user管理的虚拟HLR，虚拟HLR序列号为2，命令如下：

**RMV OPRHLRSN: SYSHLRSN=1, OPNAME="user", HLRSN=2;**
