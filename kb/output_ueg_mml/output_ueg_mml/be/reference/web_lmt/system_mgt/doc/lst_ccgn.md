# 查询命令组名（LST CCGN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询命令组的名称。若需要查询命令组名的信息，请输入“系统HLR序列号”和“命令组”这两个参数的组合。

## 注意事项

软参“OPRCMDGMGRSWT”取值为“1”时，只有ADMINISTRATOR级别的操作员具有本命令的操作权限。软参“OPRCMDGMGRSWT”取值为“0”时，ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员具有本命令的操作权限。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                            |
|:---------|:---------|:--------------------------------|
| SYSHLRSN | 系统HLR序列号 | 用于指示系统需要按照哪个系统HLR序列号来查询命令组名的信息。 |
| CG       | 命令组      | 用于指示系统需要按照哪个命令组来查询命令组的信息。       |

## 使用实例

查询系统HLR序列号为1的局点下的命令组G\_3的名称：

```
LST CCGN: SYSHLRSN=1, CG=G_3;
```

输出结果如下：

```
%%LST CCGN: SYSHLRSN=1, CG=G_3;%%
RETCODE = 0 操作成功

                            CG = G_3
                        CGNAME = G_3

Total count = 2

There is together 1 report

---    END
```

## 输出结果说明

该命令执行正常，会返回命令操作成功的提示信息和相关参数，各参数含义请参见**SET CCGN**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释      | 原因分析                                                                                                                                       | 处理建议                      |
|------:|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------|
|  1006 | 没有权限执行此命令。 | 当前操作员没有操作权限。 软参“OPRCMDGMGRSWT”取值为“1”时，只有ADMINISTRATOR级别的操作员具有本命令的操作权限。软参“OPRCMDGMGRSWT”取值为“0”时，ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员具有本命令的操作权限。 | 建议使用更高级别或者拥有该命令执行权限的帐号处理。 |
