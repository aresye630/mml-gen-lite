# 清理跨分区用户迁移文件（CLR MIGRATION）

- 命令功能

- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，执行时会弹出提示：即将删除指定迁移或回退任务的用户数据备份文件和用户列表文件，删除后该任务无法执行回退操作，请确认是否继续操作。

该命令用于删除跨分区用户迁移或迁移回退时产生的用户数据备份文件和用户列表文件。

跨分区用户迁移或迁移回退操作执行过程中，生成迁移用户数据备份文件和用户列表文件会占用磁盘空间，若连续进行多次迁移操作，确认无需进行回退，则可以人工删除，避免导致磁盘空间不足。

## 注意事项

- 检查命令指定FE类型下否有故障状态的DMA、DRU、DSU模块，若存在异常状态的模块，则不允许执行删除操作。
- 检查是否已经有迁移或回退任务在运行，若有迁移或回退任务正在运行，则不允许执行删除操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                       |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------|
| TASKID | 任务ID   | 可选必选说明：必选参数 参数含义：用于指定需要清理跨分区用户迁移或回退的任务ID。 取值范围：1~4294967295。 默认值：无。 配置原则：任务ID需要通过执行DSP MIGRATION命令查询后在此输入。 |

## 使用实例

当需要清理跨分区用户迁移或回退文件，“任务ID”为“1”时。

```
CLR MIGRATION: TASKID=1;
```

```
%%CLR MIGRATION: TASKID=1;%%
RETCODE = 0 操作成功

There is together 1 report

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释             | 原因分析                              | 处理建议                                                                                                                  |
|------:|:------------------|:----------------------------------|:----------------------------------------------------------------------------------------------------------------------|
|  1038 | 记录不存在。            | 指定“任务ID”参数时，该任务不存在或者满足条件的任务记录不存在。 | 执行DSP MIGRATION命令查询已存在的“任务ID”后，重新执行本命令清理文件。                                                                           |
|  5072 | 该命令只能通过WebLMT接入。  | 通过WebLMT之外的方式访问PGW，执行此命令。         | 请通过WebLMT访问PGW执行该命令。                                                                                                  |
|  5225 | 模块状态异常。           | 系统存在故障或异常状态的DMA/DRU/DSU/DSG模块。    | 请在故障或异常模块恢复后重新执行该命令。                                                                                                  |
|  5248 | 操作失败。             | 执行该命令时全部或部分DRU/DSU/DMA模块故障。       | 请在故障模块恢复后重新执行该命令。                                                                                                     |
|  5251 | 不允许对正在运行的任务进行该操作。 | 指定的“任务ID”是正在运行的迁移或回退任务。           | 执行DSP MIGRATION命令查询指定的任务ID，确保该任务的“Status”为“Completed”、“Terminated unexpectedly”或“Terminated manually”后，重新执行本命令清理备份文件。 |
