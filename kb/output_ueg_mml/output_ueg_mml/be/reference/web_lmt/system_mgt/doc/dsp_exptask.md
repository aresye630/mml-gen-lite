# 显示导出任务(DSP EXPTASK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询导出任务状态。

- 若需要查询所有导出任务的状态，则不输入任何参数。
- 若需要查询某个导出任务的状态，请输入“任务ID”或“任务ID”与其他参数的组合。

## 注意事项

- 导出成功记录数显示的是满足导出模板中配置的过滤条件的记录总数，当节点数据量较大，满足条件的记录数较小时，可能导致导出成功记录数长期不变。
- 该命令仅支持操作管理员执行。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
|:-----------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TASKID     | 任务ID   | 用于指示系统需要按照哪个任务ID来查询导出任务状态，若不输入，则查询所有导出任务的状态。 ADD EXPTASK命令执行成功后，PGW会返回本次任务的任务ID。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| FETYPE     | FE类型   | 用于指示系统需要按照哪个FE类型来查询导出任务状态，若不输入，则查询所有FE类型的导出任务的状态。 FE业务类型需要通过“MML命令行 - USCDB”的LOD FEPLUG命令加载对应的FE插件包之后，在此引用。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| STATUS     | 任务状态   | 用于指示系统需要按照哪个任务状态来查询导出任务状态，若不输入，则查询所有状态的导出任务。 取值范围： NOTSTART：标识导出任务未开始。RUNNING：标识导出任务正在执行。ABORTED：标识使用STP EXPTASK命令停止的导出任务。ABNORMAL：标识导出过程中出现异常中止的任务。COMPLETED：标识导出任务完成。UPLOADING：标识执行导出任务后的结果文件正在上传到FTP/SFTP服务器端。UPLOADFAILED：标识执行导出任务后的结果文件上传到FTP/SFTP服务器端失败。TEMPLETNOTEXIST：标识导出模板不存在，需要在“MML命令行 - USCDB”上执行LOD ADPPKG命令加载模板。SERVERNOTEXIST： 标识远端服务器配置不存在，需要通过在“MML命令行 - USCDB”上执行ADD RFTPSERVER或ADD RSFTPSERVER命令添加远端服务器配置。PARAINCONSIST：标识执行导出任务失败，输入的参数“过滤参数1”～“过滤参数6”与通过LOD ADPPKG命令加载的模板配置参数不一致。EXCMAXTASKNUM：标识导出任务超出最大个数。CYCLERUNNING：标识周期性导出任务正在执行。STPBYUPGRADE：标识导出任务因升级停止。STPBYFLOWCTRL：标识导出任务因流控停止。PREPROCESSING：标识列表导出任务正在做导出预处理。PREPARESQLDATA：标识正在构造物理库中的数据，即DMA模块从DRU查询全局数据并插入到物理库。TABLENOTCREATED：标识任务导出时物理库没有全局数据表。STPBYMIGTASK：标识导出任务因跨分区迁移或回退任务正在运行而停止。FILEEXC2GB：标识单个导出文件的压缩包大小大于或等于2G。CHECKFAILED：标识导出任务因检查失败而停止。 默认值：无。 |
| TASKTYPE   | 任务类型   | 用于指示系统需要按照哪个任务类型来查询导出任务状态，若不输入，则查询所有导出任务的状态。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| TPLNAME    | 模板名称   | 用于指示系统需要按照哪个模板名称来查询导出任务状态，若不输入，则查询所有模板的导出任务的状态。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| SERVERNAME | 服务器名称  | 用于指示系统需要按照哪个FTP/SFTP服务器名称来查询导出任务状态，若不输入，则查询所有FTP/SFTP服务器的导出任务的状态。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| CYCRELID   | 关联ID   | 用于指示系统按照哪个周期性任务ID来查询周期性导出任务状态，若不输入，则查询所有导出任务的状态。 该参数为周期性任务第一次启动时的“任务ID”。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称                        | 输出结果解释                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
|:-----------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TASK ID                      | 用于返回导出任务的任务ID，ADD EXPTASK命令执行成功后，PGW会返回本次任务的任务ID。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Service type                 | 用于返回定制导出模板的业务类型。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Status                       | 用于返回任务执行的状态。 取值说明： NOTSTART：标识导出任务未开始。RUNNING：标识导出任务正在执行。ABORTED：标识使用STP EXPTASK命令停止的导出任务。ABNORMAL：标识导出过程中出现异常中止的任务。COMPLETED：标识导出任务完成。UPLOADING：标识执行导出任务后的结果文件正在上传到FTP/SFTP服务器端。UPLOADFAILED：标识执行导出任务后的结果文件上传到FTP/SFTP服务器端失败。TEMPLETNOTEXIST：标识导出模板不存在，需要在“MML命令行 - USCDB”上执行LOD ADPPKG命令加载模板。SERVERNOTEXIST： 标识远端服务器配置不存在，需要通过在“MML命令行 - USCDB”上执行ADD RFTPSERVER或ADD RSFTPSERVER命令添加远端服务器配置。PARAINCONSIST：标识执行导出任务失败，输入的参数“过滤参数1”～“过滤参数6”与通过LOD ADPPKG命令加载的模板配置参数不一致。EXCMAXTASKNUM：标识导出任务超出最大个数。CYCLERUNNING：标识周期性导出任务正在执行。STPBYUPGRADE：标识导出任务因升级停止。STPBYFLOWCTRL：标识导出任务因流控停止。PREPROCESSING：标识列表导出任务正在做导出预处理。PREPARESQLDATA：标识正在构造物理库中的数据，即DMA模块从DRU查询全局数据并插入到物理库。TABLENOTCREATED：标识任务导出时物理库没有全局数据表。STPBYMIGTASK：标识导出任务因跨分区迁移或回退任务正在运行而停止。FILEEXC2GB：标识单个导出文件的压缩包大小大于或等于2G。CHECKFAILED：标识导出任务因检查失败停止。 |
| Task type                    | 用于返回导出任务的类型。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Export file number           | 用于返回导出文件的个数。在导出结果中，一个压缩包内会包含一个导出文件。 DMA导出的数据文件大小限制在2G以内，数据过大的情况下，会被分割成多个文件，此项标识导出文件的个数。  说明： 当导出模板中配置合并项时，PGW会将各个DMA导出的数据文件进行合并，可能会导致最终导出文件数量小于或等于导出过程中导出文件数量，属于正常情况。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Successfully exported number | 用于返回导出成功的数据记录数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Failed exported number       | 用于返回失败的数据记录数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Cycle unit                   | 用于返回指定任务执行周期的单位。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Cycle value                  | 用于返回执行指定任务导出周期的时长。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Correlation ID               | 用于返回周期性任务的任务ID，该ID为周期性导出任务第一次启动时生成的任务ID。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Export time                  | 用于返回指定导出任务的启动时间。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Start time                   | 用于返回开始导出数据的时间点。 若任务未开始，则不显示。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Upload time                  | 用于返回上传数据的时间点。 若未配置上传服务器，则不显示。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Finish time                  | 用于返回任务结束的时间点。 若任务未结束，则不显示。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| DMA module number            | 用于返回因DMA自身流控或者异常导致任务中止（即导出“任务状态”为“STPBYFLOWCTRL”或者“ABNORMAL”）的DMA模块号。当存在多个DMA模块引起导出任务中止时，仅显示第一个导致任务中止的DMA模块号。 若任务执行成功，或者非因为DMA模块导致任务中止的场景，则不显示。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| MML CMD                      | 用于返回增加导出任务的MML命令。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
