# 查询文件信息（LST FILEINFO）

## 命令功能

该命令用于查询指定文件的信息。

## 注意事项

如果“文件类型”为“IMPORT”时，该命令会优先查询文件管理器目录下的文件，如果找不到指定文件，再去/opt/pgw/upload目录下进行查询。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                               |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FILETYPE | 文件类型   | 可选必选说明：必选参数 参数含义：用于指定系统查询的文件类型。 取值范围： IMPORT：表示用于查询导入文件的信息。 默认值：无。 配置原则：无。                                                                                         |
| FILENAME | 文件名称   | 可选必选说明：必选参数 参数含义：用于指示系统需要按照哪个文件名称来查询文件信息。 取值范围：长度为1～128的字符串，可由字母、数字或字符“_”、“.”、“-”组成。 默认值：无。 配置原则：当文件类型为“IMPORT”时，文件必须是.tar.gz或.zip文件，并且文件前缀带“OK”。例如：OK_example.zip |

## 使用实例

查询“文件类型”为“IMPORT”，“文件名称”为“OK\_MemExpFile\_SUP-FE\_1\_20231030115053\_1099\_5200\_1.zip”的文件：

```
LST FILEINFO: FILETYPE=IMPORT,FILENAME="OK_MemExpFile_SUP-FE_1_20231030115053_1099_5200_1.zip";
```

输出结果如下：

```
%%LST FILEINFO: FILETYPE=IMPORT,FILENAME="OK_MemExpFile_SUP-FE_1_20231030115053_1099_5200_1.zip";%% 
RETCODE = 0 操作成功

                       FILENAME = OK_MemExpFile_SUP-FE_1_20231030115053_1099_5200_1.zip
                       FILESIZE = 258
                      SHA256SUM = b69e02a09078e0090c6f96758173f9dd3c29c5083ab3a3f9a9c5277c61e0526f  

Total count = 3  

There is together 1 report  

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称     | 输出项解释                |
|:----------|:---------------------|
| FILENAME  | 用于返回文件名称。            |
| FILESIZE  | 用于返回文件大小，文件大小的单位为字节。 |
| SHA256SUM | 用于返回文件的哈希值。          |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释   | 原因分析                    | 处理建议                                              |
|------:|:--------|:------------------------|:--------------------------------------------------|
|  1004 | 无效的参数值。 | 输入的“文件名称”不在取值范围内或不符合要求。 | 请重新输入正确的文件名后再执行此命令。                               |
|  1005 | 文件未找到。  | 指定的“文件名称”不存在。           | 请重新输入正确的文件名后再执行此命令。可以通过执行LST BATFILE命令查询文件名称是否存在。 |
