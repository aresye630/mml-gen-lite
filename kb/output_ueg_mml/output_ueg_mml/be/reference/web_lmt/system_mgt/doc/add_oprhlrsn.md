# 增加操作员虚拟HLR（ADD OPRHLRSN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用来增加系统HLR下的操作员所能操作的虚拟HLR的范围。

## 注意事项

- 操作员的级别为ADMINISTRATOR或操作员被赋给该命令权限时，才具有增加其他操作员所能操作虚拟HLR范围的权限。
- 需要增加操作号段的操作员必须已经定义，需要增加的虚拟HLR也必须已经定义。
- 系统能够支持一个用户最多设置255个虚拟HLR。
- 当执行该命令的用户为机机用户时，即使该用户所具有的权限级别是ADMINISTRATOR也无法执行此命令，必须首先通过**ADD VHLRRANGE**增加虚拟HLR号段后，才能执行此命令。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                |
|:---------|:---------|:----------------------------------------------------------------------------------------------------|
| SYSHLRSN | 系统HLR序列号 | 系统HLR序列号。当PGW为简单模式时，操作界面不会显示此参数，系统会自动补充SYSHLRSN，不需要用户设置；完整模式时参数SYSHLRSN需要用户设置。 取值范围：1～255。 说明：必选参数。 |
| OPNAME   | 操作员名称    | 操作员登录的名称，可通过LST OPR查询。 取值范围：不超过32位的数字、字母和下划线组成的字符串，且首字符必须为字母。 说明：必选参数。                              |
| HLRSN    | 虚拟HLR序列号 | 虚拟HLR序列号，可通过LST VHLRSN查询。 取值范围：1～255。 说明：必选参数。                                                      |

## 使用实例

为系统HLR为1的局点中增加操作员user管理的虚拟HLR，虚拟HLR序列号为2，命令如下：

**ADD OPRHLRSN: SYSHLRSN=1, OPNAME="user", HLRSN=2;**
