# 删除导出日志任务(RMV EXPLOGTASK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除已存在的操作日志导出任务的配置数据。

## 注意事项

- 该命令仅支持操作管理员执行。
- 该命令不允许进行批操作。
- 当待删除的任务状态为RUNNING，则通过该命令删除任务后，还需要发送停止消息给导出自动机。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                              |
|:----------|:-------|:------------------------------------------------------------------|
| EXPTASKID | 任务ID   | 标识一条日志导出任务配置数据的关键字段，用于指示系统需要删除那一条配置数据，操作员可使用LST EXPLOGTASK命令查询获得。 |

## 使用实例

删除“任务ID”为“1”的配置数据。

```
RMV EXPLOGTASK: EXPTASKID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释   | 原因分析                | 处理建议                                                             |
|------:|:--------|:--------------------|:-----------------------------------------------------------------|
|  1038 | 记录不存在。  | 输入的“任务ID”所对应的记录不存在。 | 执行LST EXPLOGTASK命令不输入任何参数，查询已存在的“任务ID”后，确认待删除的“任务ID”后，重新执行本命令删除。 |
