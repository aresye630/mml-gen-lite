# 增加操作员（ADD OPR）

## 命令功能

该命令用来为系统HLR增加操作员。在PGW系统中，每个系统HLR中只有一个名字为admin的超级操作员，可以有多个ADMINISTRATOR、OPERATOR、USER、OBSERVER、CUSTOM、GUEST级操作员。

## 注意事项

- 操作员的级别为“ADMINISTRATOR”或操作员被赋给该命令权限时，才具有增加其他操作员的权限。
- 添加操作员之前需要添加系统HLR，具体操作参见**ADD SYSHLRSN**命令。
- 本命令仅设置了操作员的级别和命令组属性，操作员要能够完成指定的操作，还必须设置操作员的虚拟HLRSN属性，具体操作请参见**ADD OPRHLRSN**命令。
- 如果添加操作员的级别为“CUSTOM”，而且需要添加“G\_8～G\_127”之间的“命令组”时，该“命令组”必须在系统中已经存在。请参见**ADD CCG**命令添加“G\_8～G\_127”间的“命令组”。
- 如果在“命令输入区”输入命令后再输入各参数，“密码”和“确认密码”出于安全原因，仅显示“\*”。
- 如果在“MML命令编辑区”直接输入带参数的命令，命令中的“密码”和“确认密码”以明文显示。
- 如果操作员的“日志审计”为“TRUE”，则该操作员可以使用**LST LOG**查看其他操作员的操作日志，出于信息安全考虑，请谨慎赋予操作员日志审计权限。
- 新增账号需要区分该账号为“人机账号”或“机机账号”，不允许创建合一帐号。
- 人机账号只能访问PGW/DMS Web LMT，机机账号只能访问营帐端口。
- 软参“HRCPMSMGR（分层权限管理）”值设置为“1”时，会限制相同“操作员级别”账号的相互管理，账户管理操作需由比自身级别高且拥有账户管理权限的账号执行。
- 软参“OPRCMDGMGRSWT”取值为“1”时，添加“操作员级别”为“CUSTOM”的操作员时，选择的“命令组”中不能含有**ADD CCG**、**RMV CCG**、**MOD CCG**、**LST CCG**、**SET CCGN**或**LST CCGN**命令。选择的“命令组”中包含哪些命令可通过**LST CCG**查询。
- 密码长期使用会增加被盗窃和破解的风险，而且使用的时间越长，被盗窃和破解的风险越高。定期修改密码可以有效防范这种情况的发生，因此强烈建议您定期修改密码。

## 使用实例

在“系统HLR序列号”为“1”的HLR下添加“操作员名称”为“pgwuser”，“操作员描述”为“user in pgw system”，“密码”为“\*\*\*\*\*”，“操作员级别”为“USER”，“操作员状态”为“ACTIVE”，“账号类型”为“MAN-MACHINE”的用户，步骤如下：

1. 执行**LST SYSHLRSN**命令查询“系统HLR序列号”是否为“1”。
   - 是 => 3
   - 否 => 2
2. 执行**ADD SYSHLRSN**命令添加系统HLR序列号，其中“操作员状态”为“INACTIVE”。

   ```
   ADD SYSHLRSN: SYSHLRSN=1, SYSNAME="MASTERNO1", STATUS=INACTIVE;
   ```
3. 执行本命令添加操作员。

   ```
   ADD OPR: SYSHLRSN=1, OPNAME="pgwuser", DESC="user in pgw system", PWD="*****", CFM="*****", UG=USER, STATUS=ACTIVE, ATP=MAN-MACHINE;
   ```
