# 停止内存数据库任务（STP OML）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，终止OML操作会导致正在执行的OML任务停止，已处理数据不可回退。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于停止当前正在执行的内存数据库任务。

## 注意事项

- 该命令仅支持通过PGW Web LMT接入。
- 该命令仅支持超级管理员、ADMINISTRATOR级别的操作员和CUSTOM级别的操作员执行。

## 参数说明

无。

## 使用实例

停止正在执行的内存数据库任务。

```
STP OML:;
```

```
%%STP OML:;%%
RETCODE = 0 操作成功

There is together 1 report

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                                           | 原因分析                                                | 处理建议                                                                   |
|------:|:------------------------------------------------|:----------------------------------------------------|:-----------------------------------------------------------------------|
|  5179 | 只有超级管理员、ADMINISTRATOR级别的操作员和CUSTOM级别的操作员可执行该命令。 | 当前执行命令的操作员不是超级管理员、ADMINISTRATOR级别的操作员或CUSTOM级别的操作员。 | 请使用超级管理员、ADMINISTRATOR级别的操作员或CUSTOM级别的操作员账号执行本命令。                      |
|  5180 | 没有正在运行的任务。                                      | 没有正在运行的内存数据库任务。                                     | 执行DSP OML命令查询内存数据库任务状态，当返回的“执行状态”有“RUNNING”或“PREPROCESSING”时，再重新执行本命令。 |
|  5072 | 该命令只能通过WebLMT接入。                                | 不是通过PGW Web LMT来执行该命令。                              | 请通过PGW Web LMT执行本命令。                                                   |
