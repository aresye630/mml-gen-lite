# 停止内存库整局批量备份(STP BKPDB)

## 命令功能

**须知** 

该命令属于高危命令，停止内存库整局批量备份会导致正在备份任务停止。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为维护命令，用于停止内存库整局批量备份。

## 注意事项

- 该命令只能通过WebLMT接入执行。
- 该命令仅支持停止正在运行的定时**BKP DB**命令启动的整局批量备份任务，即**DSP DB**命令查询结果中“Type”取值为“TIMER”的备份任务。不支持停止DRU/DSU启动的备份任务或者手动通过**BKP DB**命令启动的整局批量备份任务。
- 该命令仅支持超级管理员、ADMINISTRATOR级别的操作员和CUSTOM级别的操作员执行。

## 参数说明

无。

## 使用实例

停止正在执行的内存库整局批量备份任务。

```
STP BKPDB:;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
