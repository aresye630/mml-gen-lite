# 查询在线连接信息（LST LINKSTATE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询当前连接到PGW服务器的连接相关信息。

当参数“查询类型”设置为“LGIINFO”时：

- 如果要查询全部连接的登录概要信息，请不要输入其他参数。
- 如果要查询某条连接的登录详细信息，请输入“系统HLR序列号”或其他参数或这些参数的组合。
- 可查询的连接类型：
  - 业务发放系统直接连接PGW服务器。
  - 操作员通过PGW Web LMT连接PGW服务器。

当参数“查询类型”设置为“LINKINFO”时：

- 如果要查询全部连接的概要信息，请不要输入除“保存文件名”以外的其他参数。
- 如果要查询某条连接的详细信息，请输入“保存文件名”与“服务端端口”。
- 可查询的连接类型：PGW服务器上所有活动的网络连接，包括参数“查询类型”设置为“LGIINFO”时的两种连接类型。

## 注意事项

- 操作员的级别为ADMINISTRATOR操作员或被赋予该命令权限时，才具有执行本命令的权限，可通过执行**LST OPR**命令查看操作员的级别。
- 存储故障时，不能将查询结果保存到文件中，即不能设置参数“保存文件名”。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|:-----------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TYPE       | 查询类型     | 可选必选说明：必选参数。 参数含义：用于指示系统需要按照哪种连接类型来查询连接信息。 取值范围： LGIINFO：业务发放系统直接连接PGW服务器、操作员通过PGW Web LMT连接PGW服务器。LINKINFO：PGW服务器上所有活动的网络连接。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| SYSHLRSN   | 系统HLR序列号 | 可选必选说明：条件可选参数。仅当参数“查询类型”取值为“LGIINFO”时，该参数生效。 参数含义：用于指示系统需要按照哪个系统HLR序列号来查询连接信息；若不输入，则表示查询所有系统HLR序列号。 取值范围：1～255 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| OPNAME     | 操作员名称    | 可选必选说明：条件可选参数。仅当参数“查询类型”取值为“LGIINFO”时，该参数生效。 参数含义：用于指示系统需要按照哪个操作员来查询连接信息；若不输入，则表示查询所有操作员名称。 取值范围：不超过32位的数字、字母和下划线组成的字符串，且首字符必须为字母。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| SERVERPORT | 服务端端口    | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个服务端端口来查询连接信息；若不输入，则表示查询所有服务端端口。 取值范围：1～65535 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| SAVEAS     | 保存文件名    | 可选必选说明：条件可选/必选参数： 当参数“查询类型”配置为“LGIINFO”时为可选参数。当参数“查询类型”配置为“LINKINFO”时为必选参数。 参数含义：用于指示系统需要按照指定的保存文件名来保存在线连接信息。  说明： 如果该参数没有设置，连接的查询结果不会保存在文件中，直接在“PGW Web LMT”界面中显示；如果连接的记录数超过300条，需要将查询结果保存到文件中，此时该参数必须设置。如果指定的文件名已经存在，则会覆盖文件中的内容。 “保存文件名”参数指定的文件，可以通过“PGW Web LMT”界面左上角的“文件管理器”下载。 “保存文件名”参数指定的文件存放在主备PGW模块所在容器上，容器目录为“/opt/pgw/pgwtmpfile/SYSHLRSN+OPNAME”。SYSHLRSN默认为3位数字，不足3位时前面补0。如：SYSHLRSN=1，OPNAME=admin时，最后一层目录为001admin。只有在使用操作员名称OPNAME登录过系统HLR序列号SYSHLRSN的PGW Web LMT并打开“文件管理器”界面后才会生成最后一层目录SYSHLRSN+OPNAME。 取值范围：不超过20个字符的字符串。 默认值：无。 配置原则： 当参数“查询类型”取值为“LGIINFO”时，该参数的后缀名之前不能为空。当参数“查询类型”取值为“LINKINFO”时，该参数必须是英文字母、数字或特殊字符“-”、“_”、“.”的组合，且以字母或数字开头，不能包含空格以及两个连续的“.”，后缀名必须是.txt。 |

## 使用实例

1. 查询PGW当前在线连接的登录概要信息，命令和结果如下：

   ```
   LST LINKSTATE:;
   ```

   输出结果如下：

   ```
   %%LST LINKSTATE:;%%
   RETCODE = 0 操作成功

   <SYSHLRSN> <OPNAME>                         <CLIENTIP>      <CLIENTPORT> <SERVERIP>         <SERVERPORT> <PORTTYPE> <LINKTIME>          <LOGINSTATE>
   79         admin                            192.168.0.13    3135         192.168.21.71      80           WEBLMT     2012-03-23 12:21:40 Logged-in
   79         admin                            192.168.0.13    3152         192.168.21.71      7776         MML        2012-03-23 12:22:12 Logged-in
   NULL       NULL                             192.168.0.13    3151         192.168.21.71      7776         MML        2012-03-23 12:22:09 Non-logged-in

   Total count = 3

   There is together 1 report

   ---    END
   ```

2. 查询PGW当前全部在线连接的概要信息，设置“保存文件名”为“a123.txt”，命令和结果如下：

   ```
   LST LINKSTATE: TYPE=LINKINFO, SAVEAS="a123.txt";
   ```

   输出结果如下：

   ```
   %%LST LINKSTATE: TYPE=LINKINFO, SAVEAS="a123.txt";%%
   RETCODE = 0 操作成功

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称      | 输出项解释                                                                                                                                                 |
|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------|
| SYSHLRSN   | 系统HLR序列号。该连接中，如果业务发放系统未登录PGW服务器或操作员未登录进PGW Web LMT，该输出项显示为“NULL”。                                                                                     |
| OPRNAME    | 用于返回连接到PGW服务器上的操作员名称。该连接中，如果业务发放系统未登录PGW服务器或操作员未登录进PGW Web LMT，该输出项显示为“NULL”。                                                                         |
| CLIENTIP   | 客户端连接到PGW服务器时使用的IP地址。                                                                                                                                 |
| CLIENTPORT | 客户端连接到PGW服务器时使用的端口号。  说明： WEBLMT类型的连接中，客户端端口号会在一个连接过程中不断发生变化。对于该连接，客户端的端口号显示为操作员登录时的端口号。                                                              |
| SERVERIP   | 客户端连接到PGW服务器时，PGW服务器使用的IP地址。                                                                                                                          |
| SERVERPORT | 客户端连接到PGW服务器时，PGW服务器使用的端口号。  说明： 当客户端通过SSH连接PGW服务器时，端口显示为22。                                                                                          |
| PORTTYPE   | 客户端连接到PGW服务器时，PGW服务器使用的端口类型。有3种端口类型：WEBLMT：操作员通过PGW Web LMT连接到PGW服务器时显示该端口类型。MML：业务发放系统使用MML协议连接到PGW服务器时显示该端口类型。SOAP：业务发放系统使用SOAP协议连接到PGW服务器时显示该端口类型。 |
| LINKTIME   | 客户端连接到PGW服务器的时间。                                                                                                                                      |
| LOGINSTATE | 该连接中，操作员或业务发放系统的登录状态。有2种登录状态：Non-logged-in：操作员未登录进PGW Web LMT或业务发放系统未登录PGW服务器。Logged-in：操作员已登录进PGW Web LMT或业务发放系统已登录PGW服务器。                           |
