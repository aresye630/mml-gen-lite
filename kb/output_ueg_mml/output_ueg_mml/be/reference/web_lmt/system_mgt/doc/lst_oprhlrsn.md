# 查询操作员虚拟HLR（LST OPRHLRSN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用来查询系统HLR下的操作员所能操作的虚拟HLR的范围。

## 注意事项

- 操作员的级别为ADMINISTRATOR或操作员被赋给该命令权限时，才具有查询其他操作员所能操作虚拟HLR范围的权限。
- 如果不输入操作员名称，则查询某一系统HLR下的所有操作员所能操作的虚拟HLR的范围。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                   |
|:---------|:---------|:---------------------------------------------------------------------------------------|
| SYSHLRSN | 系统HLR序列号 | 系统HLR序列号。当PGW为简单模式时，系统会自动补充SYSHLRSN，不需要用户设置；完整模式时参数SYSHLRSN需要用户设置。 取值范围：1～255。 说明：必选参数 |
| OPNAME   | 操作员名称    | 操作员登录的名称。 取值范围：不超过32位的数字、字母和下划线组成的字符串，且首字符必须为字母。 说明：可选参数                               |

## 使用实例

查询系统HLR为1的局点中操作员test管理的虚拟HLR范围，命令和结果如下：

**LST OPRHLRSN: SYSHLRSN=1, OPNAME="test";**

输出结果如下：

```
%%LST OPRHLRSN: SYSHLRSN=1, OPNAME="test";%%
RETCODE = 0 操作成功

                      SYSHLRSN = 1
                        OPNAME = test
                         HLRSN = 3

Total count = 3

There is together 1 report

---    END
```

## 输出结果说明

| 输出项名称    | 输出项解释              |
|:---------|:-------------------|
| SYSHLRSN | 系统HLR序列号。          |
| OPNAME   | 操作员名称。             |
| HLRSN    | 此操作员所能操作的虚拟HLR序列号。 |
