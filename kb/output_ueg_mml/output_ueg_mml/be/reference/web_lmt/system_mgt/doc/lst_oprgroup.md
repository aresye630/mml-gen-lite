# 查询操作员组（LST OPRGROUP）

## 命令功能

该命令用于查询PGW操作员组。

- 若要查询系统HLR序列号下的全部操作员组的配置信息，请只输入“系统HLR序列号”。
- 若要查询系统HLR序列号下某个操作员组的配置信息，请输入“系统HLR序列号”和“组名称”。

## 注意事项

操作员的级别为“ADMINISTRATOR”或操作员被赋给该命令权限时，才具有执行该命令的权限。

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                                      |
|:----------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
| SYSHLRSN  | 系统HLR序列号 | 可选必选说明：必选参数 参数含义：用于指定系统HLR序列号，该参数通过ADD SYSHLRSN命令添加后在此引用。 取值范围：1～255 默认值：无。 配置原则： 当PGW为简单模式时，操作界面不会显示此参数，系统会自动补充系统HLR序列号，不需要用户设置该参数。当PGW为完整模式时，该参数需要用户设置。 |
| GROUPNAME | 组名称      | 可选必选说明：可选参数 参数含义：用于指定组名称。 取值范围：长度不超过96字节。 默认值：无。 配置原则：无。                                                                                                  |

## 使用实例

1. 查询操作员组，“系统HLR序列号”为“5”。

   ```
   LST OPRGROUP: SYSHLRSN=5;
   ```

   ```
   %%LST OPRGROUP: SYSHLRSN=5;%%
   RETCODE = 0 操作成功

   <Group name>   <System HLR serial number>   <Operator name>
   test           5                            test1
   testgroup      5                            test2

   Total count = 2

   There is together 1 report

   ---    END
   ```
2. 查询操作员组，“系统HLR序列号”为“5”，“组名称”为“test”。

   ```
   LST OPRGROUP: SYSHLRSN=5, GROUPNAME="test";
   ```

   ```
   %%LST OPRGROUP: SYSHLRSN=5, GROUPNAME="test";%%
   RETCODE = 0 操作成功

                       Group name = test
         System HLR serial number = 5
                    Operator name = test1

   Total count = 3

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释   | 原因分析                                | 处理建议                                                          |
|------:|:--------|:------------------------------------|:--------------------------------------------------------------|
|  1038 | 记录不存在。  | 输入的“组名称”和“系统HLR序列号”参数所对应的记录在系统中不存在。 | 执行LST OPRGROUP命令查询已存在的记录，重新执行本命令，确保输入的“组名称”和“系统HLR序列号”在系统中存在。 |

## 参考信息

**简单模式**

简单模式是PGW的一种应用模式，指整个系统只允许存在一个“系统HLR序列号”，处于简单模式下的系统不支持业务层容灾功能。通过将软参“APPLICATIONTYPE（应用模式）”设为“0”将PGW的应用模式设为简单模式。

**完整模式**

完整模式是PGW的另一种应用模式，指整个系统允许存在多个“系统HLR序列号”，处于完整模式下的系统支持业务层容灾功能。通过将软参“APPLICATIONTYPE（应用模式）”设为“1”将PGW的应用模式设为完整模式。
