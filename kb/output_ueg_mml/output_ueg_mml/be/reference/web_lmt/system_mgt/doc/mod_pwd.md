# 修改操作员密码（MOD PWD）

## 命令功能

**须知** 

该命令属于高危命令，修改操作员密码会导致该操作员的旧密码不可用。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改操作员密码。

## 注意事项

- “系统HLR序列号”和“操作员名称”为可选参数，如果不输入，则认为修改当前登录的操作员密码。
- 超级管理员除能修改自身密码外，还能修改其他操作员密码。非超级管理员只能修改自身密码。
- 修改密码成功后，需执行**KIK ONLINEOPR**命令下线被修改的操作员。
- 该命令不允许进行批操作。
- 密码长期使用会增加被盗窃和破解的风险，而且使用的时间越长，被盗窃和破解的风险越高。定期修改密码可以有效防范这种情况的发生，因此强烈建议您定期修改密码。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|:-------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN  | 系统HLR序列号 | 标识一条操作员数据记录的关键字段之一，用于指定需要对哪一条操作员数据记录进行修改或调整。 取值范围：1～255                                                                                                                                                                                                                                                                                                                                                                                                                     |
| OPNAME | 操作员名称    | 标识一条操作员数据记录的关键字段之一，用于指定需要对哪一条操作员数据记录进行修改或调整。 取值范围：不超过32位的数字、字母和下划线组成的字符串，且首字符必须为字母。                                                                                                                                                                                                                                                                                                                                                                                         |
| OLD    | 旧密码      | 用于指定操作员的旧密码。 取值范围：6～64位的字符串。                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| NEW    | 新密码      | 用于指定操作员的新密码。密码安全策略可通过执行LST SECPOLICY命令查看。 取值范围：8～64位的字符串。 说明：如果未执行过SET SECPOLICY命令或执行SET SECPOLICY时，密码安全策略均采用默认值时，密码安全策略如下。 密码区分大小写，其复杂度需同时满足下列条件： 密码至少包含以下四个类别中的三类：英文大写字母。英文小写字母。数字：0～9。特殊字符：` ~ ! @ # $ % ^ * ( ) _ + - { } | [ ] : > ? . \ / （包含空格）。 不允许使用三个或三个以上连续的字母或数字（例如：ABC、123）。密码不能和用户名或者用户名的逆序一样，且不能包含用户名或者用户名的逆序。不允许使用三个或三个以上连续的相同字符（例如：AAA）。密码长度最长为64个字符，人机账号的密码默认最短长度为10个字符，机机账号的密码默认最短长度为16个字符。密码不能与最近的5个历史密码重复。 如果已执行SET SECPOLICY命令修改了密码安全策略，则密码策略以修改后的为准。 |
| CFM    | 确认密码     | 用于指定操作员的确认密码。确认密码应与新密码保持一致 取值范围：8～64位的字符串。                                                                                                                                                                                                                                                                                                                                                                                                                                  |

## 使用实例

修改操作员密码，将旧密码“\*\*\*\*\*”修改为新密码“\*\*\*\*\*”：

```
MOD PWD: OLD="*****", NEW="*****", CFM="*****";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|  1013 | 用户名或密码错误。            | 输入的“操作员名称”或“旧密码”错误。          | 请重新输入正确的“操作员名称”或“旧密码”。                                                      |
|  1018 | 密码不匹配。               | “新密码”和“确认密码”不相同。             | 请重新输入“新密码”和“确认密码”，确保“新密码”和“确认密码”相同。                                         |
|  1077 | 密码中包含的字符不符合密码复杂度。    | 密码中包含的字符不符合密码复杂度要求。          | 请重新输入合适的“新密码”和“确认密码”。                                                       |
|  5193 | 已被添加为弱口令，不允许设置为帐号口令。 | 当前设置的口令已经被添加为弱口令，不允许设置为帐号口令。 | 执行LST WEAKPWD命令查询已经存在的弱口令记录信息，检查命令输入的口令是否被添加为弱口令，并根据查询结果，重新输入一个未被设置为弱口令的口令。 |
