# 删除虚拟HLR（RMV VHLRSN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，删除虚拟HLR会导致虚拟HLR管理号段不可用。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除虚拟HLR。当系统中没有操作员关联该虚拟HLR，或不再需要该虚拟HLR管理号段（IMSI，MSISDN或IMEI）时，使用本命令删除虚拟HLR。

## 注意事项

- ADMINISTRATOR级别的操作员或被赋给该命令权限的操作员具有本命令的操作权限。
- 只有当该虚拟HLR没有被使用的时候才能被删除，如果已经被使用（例如：有操作员关联该虚拟HLR），则无法成功删除。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                              |
|:---------|:---------|:------------------------------------------------------------------|
| SYSHLRSN | 系统HLR序列号 | 标识一条虚拟HLR数据记录的关键字段之一，用于指定需要删除哪一个系统HLR，操作员可以使用LST VHLRSN命令查询获得。    |
| HLRSN    | 虚拟HLR序列号 | 标识一条虚拟HLR数据记录的关键字段之一，用于指定需要删除哪一个虚拟HLR序列号，操作员可以使用LST VHLRSN命令查询获得。 |

## 使用实例

系统不再需要“虚拟HLR序列号”为“1”，“系统HLR序列号”为“1”的虚拟HLR管理号段：

```
RMV VHLRSN: SYSHLRSN=1, HLRSN=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释      | 原因分析                                        | 处理建议   |
|------:|:-----------|:--------------------------------------------|:-------|
|  1127 | 虚拟设备号已经被使用 | “虚拟HLR序列号”已被ADD VHLRRANGE或ADD OPRHLRSN命令引用。 | 无需处理。  |
