## 命令功能

**须知** 

该命令属于高危命令，进行数据比对分析操作可能造成系统过载，影响业务的正常功能。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于支持根据输入的参数进行历史备份数据和内存库数据的比对分析，比对分析的逻辑是以FDB类型的数据为准与内存库数据进行比对分析。管理员可通过**DSP CMPDB**命令查询数据比对分析任务，**STP CMPDB**停止数据比对分析任务。

该命令的操作场景一般为：当需要获取异常的离散数据时，可使用该命令。

## 注意事项

- 本命令仅支持通过PGW Web LMT接入。
- 本命令仅支持超级管理员、ADMINISTRATOR级别的操作员和CUSTOM级别的操作员执行。
- 本命令同一时间只允许一条命令在执行，不允许同时执行多条相同命令，不支持批操作。
- 若本命令输入“表对象名称”和“字段名称”参数，则表示此次数据分析仅判断该表字段值在备份数据和内存库数据中是否一致，若需要对更多的表或字段进行数据分析，请使用“过滤条件文件”参数，通过XML文件输入相关的表和字段。
- 执行本命令时，将不可避免的涉及到用户的个人数据，因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护，并在操作完成后及时清理结果文件。
- 当进行启动数据比对分析任务时，系统通过“CMPDBSPEED（数据比对分析任务速率）”软参的取值控制比对的速率。如果速率设置过快会引起CPU占用率过大，可能会导致任务终止。
- 执行本命令时系统会根据命令参数的设置获取需要解析的备份文件，并将解析的备份文件存储在本地，在比对分析结束后会上传结果文件到文件管理器。
- 系统将比对分析的结果文本文件打包成CmpDbResult\_{RuleName}\_YYYYMMDDHHMMSS.tar.gz格式，存放在文件管理器。系统最多保留50份，超过数量的旧文件将会被自动删除。
- 当正在通过**EXC OML**下发内存库数据操作任务时，不能同时执行本命令进行启动数据比对分析任务。
- 当正在通过**RCV DB**下发内存库数据在线恢复任务时，不能同时执行本命令进行启动数据比对分析任务。
- 本命令默认只能在容灾局执行，在主用局执行时，需设置软参“CMPDBEXECSW（STR CMPDB命令主用局执行开关）”的取值为“1”。
- 在本命令执行过程中，若系统处于升级实施阶段（即软参“UPGRADESTATUS（升级状态）”值为“2”）或本局点之前为容灾局现在倒换为主用局，则PGW模块主动通知DMA停止本次任务。
- 当系统流控或存储故障的时候，不能同时执行本命令进行数据比对分析任务。
- 在本命令执行过程中，当虚机节点或容器（裸机POD或容器）CPU大于70%时，会导致本命令异常终止。
- 使用CUR类型的FDB启动数据对比分析任务前，需要设置软参“TIMEBACKUPFLAG（定时备份开关）”取值为“0”。

  **说明** 

  软参“TIMEBACKUPFLAG（定时备份开关）”取值为“1”时，每小时都会自动重新进行备份，如果本命令在FDB解析过程中触发了每小时自动备份，就会导致CUR类型的FDB备份目录被删除，进而导致任务失败。

## 使用实例

- 执行“Cluster标识”为“1097”，“FE类型”为“SUP-FE”，“FDB类型”为“CUR”，“任务模式”为“COMMON”，“表对象名称”为“SUID\_DATA”，“字段名称”为“AUC1\_DATA”，“键值类型”为“SUID”的启动数据比对分析任务命令。

  ```
  STR CMPDB: CID=1097, FETYPE="SUP-FE", FDBTYPE=CUR, TASKMODE=COMMON, TABLENAME="SUID_DATA", FIELDNAME="AUC1_DATA", KEYTYPE="SUID";
  ```

- 执行“FE类型”为“SUP-FE”，“FDB类型”为“CUR”，“任务模式”为“COMMON”，“表对象名称”为“G\_SUB2\_INFO1\_TPL\_SON1\_1”，“字段名称”为“INT8\_1”的启动数据比对分析任务命令。

  ```
  STR CMPDB: FETYPE="SUP-FE", FDBTYPE=CUR, TASKMODE=COMMON, TABLENAME="G_SUB2_INFO1_TPL_SON1_1", FIELDNAME="INT8_1";
  ```

- 执行“FE类型”为“SUP-FE”，“FDB类型”为“CUR”，“任务模式”为“FILE”，“过滤条件文件”为“testFilterFile.xml”的启动数据比对分析任务命令。

  ```
  STR CMPDB: FETYPE="SUP-FE", FDBTYPE=CUR, TASKMODE=FILE, FILTERFILE="testFilterFile.xml";
  ```
