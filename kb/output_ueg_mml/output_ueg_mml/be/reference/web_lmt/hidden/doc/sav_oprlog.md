# 保存MAP操作日志(SAV OPRLOG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于保存MAP消息中的操作指令或者记录容灾文件。

## 注意事项

执行本命令时，将不可避免的涉及到用户的个人数据，因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护。例如：

1. 采用安全的文件传输协议（如SFTP）传输导出的文件。
2. 并严格控制文件的访问权限。
3. 及时清理文件。

在从运营商网络获取数据前，必须要获得运营商的授权。

若需从运营商网络中获取必要的数据，需要运营商维护人员对其中的个人数据进行匿名化处理，匿名化后的数据由运营商维护人员审核后提供，以防止个人数据泄露。匿名化处理工具可以在https://support.huawei.com/获取，获取方法请参见产品手册“匿名化工具安全策略”页面。

## 参数说明

| 参数标识         | 参数名称        | 参数说明                                                               |
|:-------------|:------------|:-------------------------------------------------------------------|
| SYSNO        | 系统序列号       | 用于唯一标识本局的系统序列号。 取值范围：1～255 默认值：无。                                  |
| MMLCOMMAND   | MML命令       | 用于配置需要记录到容灾文件的MML指令或者需要记录到操作日志的MML指令。 取值范围：长度为1～16384的字符串。 默认值：无。  |
| COMMANDNO    | 命令码         | 用于记录MMLCOMMAND对应的命令码。 取值范围：0～2147483647 默认值：无。                     |
| RESULT       | 执行结果        | 用于记录命令执行结果。 取值范围： 0：表示操作成功。1：表示操作失败。 默认值：无。                        |
| ERRORCODE    | 错误码         | 用于记录返回执行结果的错误码。 取值范围：0～2147483647 默认值：无。                           |
| IMSI_NO      | IMSI号码      | 用于记录对应的IMSI码。 取值范围：长度为6～15的字符串。 默认值：无。                             |
| MSISDN_NO    | MSISDN号码    | 用于记录对应的MSISDN的码。 取值范围：长度为1～15的字符串。 默认值：无。                          |
| SAVEREDUFILE | 容灾文件记录开关    | 用于指定是否将MML命令保存到容灾文件。 取值范围： 0：不记录到容灾文件。1：记录到容灾文件。 默认值：无。            |
| HLRSN        | HLR序列号      | 用于记录HLR的序列号。 取值范围：1～255 默认值：无。                                     |
| SUBID        | SUBID       | 用于记录对应的IMS用户的SUBID值。 取值范围：长度不超过127的字符串。 默认值：无。                     |
| IMPI         | IMPI        | 用于记录对应的IMS用户的IMPI值。 取值范围：长度不超过127的字符串。 默认值：无。                      |
| IMPU         | IMPU        | 用于记录对应的IMS用户的IMPU值。 取值范围：长度不超过127的字符串。 默认值：无。                      |
| SAVLOG       | 日志记录开关      | 用于指定是否将MML命令保存到独立的空口日志表中。 取值范围： 0：记录到操作日志表中。1：记录到独立的空口日志表中。 默认值：0。 |
| PID          | Partition标识 | 用于标识执行MML命令的Partition分区。 取值范围：1～250 默认值：无。                         |
