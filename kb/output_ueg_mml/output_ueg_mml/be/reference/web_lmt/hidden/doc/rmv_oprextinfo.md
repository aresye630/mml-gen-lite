# 删除从账号额外信息（RMV OPREXTINFO）

- 命令功能
- 注意事项
- 参数说明

## 命令功能

该命令用于管理员在管控平台上执行删除应用资源侧的从账号额外信息操作。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                     |
|:-------|:-------|:-----------------------------------------------------------------------------------------|
| ACCID  | 从账号ID  | 用于指定需要删除哪条从账号额外信息，此参数是从账号额外信息的唯一标识。操作员可以使用LST OPREXTINFO命令查询获得。 取值范围：长度不超过64的字符串。 默认值：无。 |
