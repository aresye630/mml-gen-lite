# 导出全局数据(EXP GLOBALDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于导出PGW模块保存在内存中的全局数据。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                        |
|:---------|:-------|:--------------------------------------------|
| TBLNAME  | 表名     | 用于指定需要导出的全局数据的表的名称。 取值范围：1～128位的字符串 默认值：无。  |
| FILENAME | 文件名    | 用于指定保存导出的全局数据的文件的名称。 取值范围：1～256位的字符串 默认值：无。 |

无。
