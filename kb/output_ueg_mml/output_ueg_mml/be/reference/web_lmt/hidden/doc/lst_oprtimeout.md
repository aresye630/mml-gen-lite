# 查询用户超时时间(LST OPRTIMEOUT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询用户超时时间。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                             |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SYSNO  | 系统序列号  | 可选必选说明：可选参数 参数含义：用于指定查询哪一个系统序列号的用户超时时间。 取值范围：1～255 默认值：无。 配置原则：操作员登录PGW Web LMT或DMS WebUI时如果输入了系统序列号，则执行该命令时，该参数需设置为操作员登录PGW Web LMT或DMS WebUI时输入的系统序列号，否则不需要设置。 |
| OPNAME | 操作员名称  | 可选必选说明：必选参数 参数含义：用于指定查询哪一个操作员的超时时间。 取值范围：不超过32位的数字、字母和下划线组成的字符串，且首字符必须为字母。 默认值：无。 配置原则：无。                                                                        |

## 使用实例

查询用户超时时间，“系统序列号”为1，“操作员名称”为“test1”。

```
LST OPRTIMEOUT: SYSNO=1, OPNAME="test1";
```
