# 修改用户超时时间(MOD OPRTIMEOUT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于修改用户登录PGW Web LMT和DMS WebUI的超时时间。

用户登录PGW Web LMT或DMS WebUI后设置的自动注销时间，通过发送该命令到PGW修改，从而实现当某一用户退出当前登录再重新登录后能够继承上一次的自动注销时间设置。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称        | 参数说明                                                                                                                                                                  |
|:--------------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SYSNO         | 系统序列号       | 可选必选说明：可选参数 参数含义：用于指定需要对哪一个系统序列号的用户超时时间进行修改。 取值范围：1～255 默认值：无。 配置原则：操作员登录PGW Web LMT或DMS WebUI时如果输入了系统序列号，则执行该命令时，该参数需设置为操作员登录PGW Web LMT或DMS WebUI时输入的系统序列号，否则不需要设置。 |
| OPNAME        | 操作员名称       | 可选必选说明：必选参数 参数含义：用于指定需要对哪一个操作员的超时时间进行修改。 取值范围：不超过32位的数字、字母和下划线组成的字符串，且首字符必须为字母。 默认值：无。 配置原则：无。                                                                        |
| DMSTIMEOUT    | DMS超时时间     | 可选必选说明：可选参数 参数含义：用于指定登录DMS WebUI后的自动注销时间。 取值范围：0～30，单位为分钟。 默认值：10。 配置原则：取值为“0”表示没有自动注销时间。                                                                             |
| WEBLMTTIMEOUT | WEB LMT超时时间 | 可选必选说明：可选参数 参数含义：用于指定登录PGW Web LMT后的自动注销时间。 取值范围：1～600，单位为分钟。 默认值：10。 配置原则：无。                                                                                         |

## 使用实例

修改DMS WebUI的超时时间，“系统序列号”为“1”，“操作员名称”为“test1”，“DMS超时时间”为“11”。

```
MOD OPRTIMEOUT: SYSNO=1, OPNAME="test1", DMSTIMEOUT=11;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
