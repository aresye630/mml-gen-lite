# 添加从账号额外信息（ADD OPREXTINFO）

- 命令功能
- 注意事项
- 参数说明

## 命令功能

该命令用于管理员在管控平台上执行添加应用资源侧的从账号额外信息操作。

该命令的使用场景：管控平台需要对应用资源进行接入，对资源中的从账号进行全生命周期管理，即支持资源从账号的统一管理和维护。

**说明** 

添加的从账户数目最大限制为32个。

## 注意事项

无。
