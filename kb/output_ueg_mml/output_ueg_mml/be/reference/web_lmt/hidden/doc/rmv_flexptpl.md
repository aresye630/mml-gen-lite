# 删除灵活导出模板(RMV FLEXPTPL)

- 命令功能
- 注意事项
- 参数说明

## 命令功能

本命令用于删除灵活导出模板。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                  |
|:--------|:-------|:------------------------------------------------------------------------------------------------------|
| FETYPE  | FE类型   | 用于指定删除哪个FE类型的灵活导出模板，此参数在USCDB下唯一，通过“USCDB MML命令”界面的LOD FEPLUG命令加载FE插件后在此引用。 取值范围：长度不超过128的字符串。 默认值：无。 |
| TPLNAME | 模板名称   | 用于指定待删除的导出模板名称。 取值范围：长度不超过128的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。                                     |
