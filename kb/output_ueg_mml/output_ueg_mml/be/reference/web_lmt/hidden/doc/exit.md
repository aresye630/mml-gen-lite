# 操作员退出(EXIT)

- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

本命令用于当前操作员从PGW退出。执行此操作后，操作员帐号会登出并断开与PGW的链接。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                               |
|:-------|:-------|:---------------------------------------------------|
| RSP    | 响应消息   | 用于指定操作员执行退出后的状态信息。 取值范围：0：表示退出失败。 1：表示退出成功。 默认值：无。 |

## 使用实例

当需要操作员登出且断开与PGW连接时，执行此命令：

```
EXIT:;
```

## 输出结果说明

无。
