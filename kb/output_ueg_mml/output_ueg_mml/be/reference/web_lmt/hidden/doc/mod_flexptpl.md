# 修改灵活导出模板(MOD FLEXPTPL)

- 命令功能
- 注意事项
- 参数说明

## 命令功能

本命令用于修改灵活导出模板。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                  |
|:-----------|:-------|:------------------------------------------------------------------------------------------------------|
| FETYPE     | FE类型   | 用于指定修改哪个FE类型的灵活导出模板，此参数在USCDB下唯一，通过“USCDB MML命令”界面的LOD FEPLUG命令加载FE插件后在此引用。 取值范围：长度不超过128的字符串。 默认值：无。 |
| TPLNAME    | 模板名称   | 用于指定待修改的导出模板名称。 取值范围：长度不超过128的字符串。此参数FE下唯一， 可由数字、字母、下划线(_)和“@”组成。 默认值：无。                              |
| TPLDESC    | 模板描述   | 用于描述该模板用途，便于用户区分。 取值范围：长度不超过128的字符串。可由数字、字母、下划线(_)和空格组成。 默认值：无。                                       |
| TPLCONTENT | 模板内容   | 用于指定修改后的导出模板内容。 取值范围：长度不超过60*1024的十六进制字符串。 默认值：无。                                                     |
| NODENAME   | 节点名    | 用于指定待修改的用户列表导出模板的节点名称。 取值范围：长度不超过128的字符串。 默认值：无。                                                      |
| KEYNAME    | 键值名    | 用于指定待修改的用户列表导出模板的键值名称。 取值范围：长度不超过128的字符串。 默认值：无。                                                      |
| MINLENTH   | 最小长度   | 用于指定待修改的用户列表导出模板中键值的最小长度。 取值范围：1～1536。 默认值：无。                                                         |
| MAXLENTH   | 最大长度   | 用于指定待修改的用户列表导出模板中键值的最大长度。 取值范围：1～1536。 默认值：无。                                                         |
