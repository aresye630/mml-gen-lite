# 操作员登录(LGI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于操作员登录PGW。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称      | 参数说明                                                                                                                            |
|:--------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------|
| OPNAME        | 操作员名称     | 用于指定登录的操作员的名称。 取值范围：不超过32位的数字、字母或下划线组成的字符串，且首字符必须为字母。 默认值：无。                                                                    |
| PWD           | 登录密码      | 用于指定登录的操作员对应的登录密码。 取值范围：1～255位的字符串 默认值：无。                                                                                       |
| HLRSN         | HLR序列号    | 用于指定操作员登录的HLR序列号。 取值范围：1～255 默认值：无。                                                                                             |
| IP            | PGW客户端IP  | 用于指定操作员登录的客户端的IP。 取值范围：符合IPv4或IPv6格式要求 默认值：无。                                                                                   |
| PORT          | PGW客户端端口号 | 用于指定操作员登录的客户端的端口号。 取值范围：1～65535 默认值：无。                                                                                          |
| WEBSERVERIP   | PGW服务器IP  | 用于指定PGW服务器的IP。 取值范围：符合IPv4或IPv6格式要求 默认值：无。                                                                                      |
| WEBSERVERPORT | PGW服务器端口号 | 用于指定PGW服务器的端口号。 取值范围：1～65535 默认值：无。                                                                                             |
| SSHCLIENTIP   | SSH客户端IP  | 用于指定SSH客户端的IP。 取值范围：符合IPv4或IPv6格式要求 默认值：无。                                                                                      |
| SSHCLIENTPORT | SSH客户端端口号 | 用于指定SSH客户端的端口号。 取值范围：1～65535 默认值：无。                                                                                             |
| SSHSERVERIP   | SSH服务器IP  | 用于指定SSH服务器的IP。 取值范围：符合IPv4或IPv6格式要求 默认值：无。                                                                                      |
| SSHSERVERPORT | SSH服务器端口号 | 用于指定SSH服务器的端口号。 取值范围：1～65535 默认值：无。                                                                                             |
| LGIDMS        | 登录DMSWEB  | 用于指定是否为DMS WebUI发出的操作员登录请求。 取值范围：0，表示非DMS WebUI发出的操作员登录请求。1，表示DMS WebUI发出的操作员登录请求。 默认值：无。 说明：为减少对PGW的影响，最多允许10个用户同时登录DMS WebUI。 |
| USERNAME      | 用户名称      | 用于指定登录使用的用户名称。 当PGW Web LMT使用SSO（Single Sign On）功能时，该参数用于指定在网管登录页面使用的网管用户名称。 取值范围：不超过32位的数字、字母或下划线组成的字符串，且首字符必须为字母。 默认值：无       |

## 使用实例

当操作员需要登录进行业务发放时，需要执行此命令进行登录操作。“操作员名称”为“A”，“登录密码”为“\*\*\*\*\*”:

```
LGI:OPNAME="A",PWD="*****";
```

```
%%LGI:OPNAME="A",PWD="*****";%%
RETCODE = 0 操作成功

There is together 1 report

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释     | 原因分析                                | 处理建议                                                                                                            |
|------:|:----------|:------------------------------------|:----------------------------------------------------------------------------------------------------------------|
|  1013 | 用户名或密码错误。 | 输入的账号所属“账号类型”错误。输入的“操作员名称”或“旧密码”错误。 | 请使用正确“账号类型”的账号登录。“账号类型”请执行LST OPR命令查询。登录账号规则如下：“人机账号”只能访问PGW/DMS Web LMT。“机机账号”只能访问营账端口。 请重新输入正确的“操作员名称”或“旧密码”。 |
