# 查询升级启动阶段（LST UPGSTAGE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于查询无损升级所处的阶段。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询无损升级所处的阶段：

```
LST UPGSTAGE:;
```

```
RETCODE = 0 操作成功

升级阶段
-------------
升级阶段 = 启动
(结果个数 = 1)

--- 结束
```

#### 输出结果说明

参见SET UPGSTAGE的参数说明。
