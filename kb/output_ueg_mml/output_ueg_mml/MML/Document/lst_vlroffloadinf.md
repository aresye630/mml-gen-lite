# 查询VLR迁移配置信息(LST VLROFFLOADINF)

#### 命令功能

**适用网元：SGSN、MME**

该命令用来查询与本局UNC相连的MSC POOL中VLR的迁移配置信息。

#### 注意事项

第二阶段迁移速度为每个SPP进程上每秒迁移的最大用户数。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询迁移配置信息：

LST VLROFFLOADINF:;

```
%%LST VLROFFLOADINF:;%%
RETCODE = 0  操作成功。

输出结果如下
---------
 第一阶段迁移时长(分钟) = 40   
第二阶段迁移速度(个/秒) = 30
      

(结果个数 = 1)
---    END
```

#### 输出结果说明

参见**SET VLROFFLOADINF**的参数标识。
