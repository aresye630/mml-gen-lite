# 配置软件生命周期预警策略（SET SWLCALMPOLICY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于配置软件生命周期预警策略，包含预警开关及预警阈值。

## 注意事项

该命令如果未执行，系统会使用默认参数，默认值如下：

| 参数标识      | 参数默认值   |
|:----------|:--------|
| ALMSWITCH | OFF     |
| ALMTHRESH | 270     |

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                  |
|:----------|:--------|:--------------------------------------------------------------------------------------|
| ALMSWITCH | 预警开关    | 可选必选说明：必选参数。 参数含义：用于指定是否开启预警功能。 取值范围： ON：启动生命周期预警检查。OFF：不启动生命周期预警检查。 默认值：OFF。 配置原则：无。 |
| ALMTHRESH | 预警阈值（天） | 可选必选说明：可选参数。 参数含义：用于指定在开启预警的前提下，上报该告警的阈值，单位：天。 取值范围：30~270。 默认值：270。 配置原则：无。          |

## 使用实例

配置软件生命周期预警策略：

```
%%SET SWLCALMPOLICY: ALMSWITCH=OFF, ALMTHRESH=30;%% 
RETCODE = 0  操作成功  

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码列表如表2所示。

|   错误码 | 错误码解释          | 原因分析                  | 处理建议      |
|------:|:---------------|:----------------------|:----------|
|   500 | 系统内部错误，请联系管理员。 | 可能存在网络故障或者服务不可用等异常因素。 | 等待几分钟后重试。 |
