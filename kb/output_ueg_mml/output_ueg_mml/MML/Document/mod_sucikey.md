# 修改SUCI密钥(MOD SUCIKEY)

- 注意事项

## 命令功能

**须知** 

- 本命令属于高危命令，执行不当会造成用户鉴权失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于修改SUCI私钥。在该命令中，系统通过“Key名称”关键参数来唯一标识一条SUCI私钥数据。

## 注意事项

- 该命令不允许进行批操作。
- 修改后的数据中“SUCI 密钥类型”、“SUCI 密钥ID”、“归属网络标识”、“路由指示符”四个参数取值的组合必须唯一。

## 参数说明

| 参数标识         | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                               |
|:-------------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| KEYNAME      | Key名称     | 可选必选说明：必选参数 参数含义：标识一条SUCI私钥记录的关键字段，用于指定需要对哪一条SUCI私钥记录的参数进行修改或调整，操作员可以使用LST SUCIKEY命令查询获得。 取值范围：1～16个字母、数字或特殊字符组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                               |
| KEYTYPE      | SUCI 密钥类型 | 可选必选说明：可选参数 参数含义：用于标识SUCI私钥的加密方式类型。 取值范围： PROFILEA（SUCI密钥类型A）PROFILEB（SUCI密钥类型B） 默认值：无。 配置原则：无。                                                                                                                                                                                                                                    |
| KEYID        | SUCI 密钥ID | 可选必选说明：可选参数 参数含义：用于标识SUCI的私钥ID。 取值范围：1～255 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                          |
| HNIDENTIFIER | 归属网络标识    | 可选必选说明：可选参数 参数含义：用于标识SUCI私钥的归属网络标识，由移动国家码和移动网络码组成。 取值范围：5~6位的十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                           |
| RTINDICATOR  | 路由指示符     | 可选必选说明：可选参数 参数含义：用于标识SUCI私钥的路由指示符，通过配置该参数确定归属的UDM/AUSF。 取值范围：1~4位的十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                      |
| SAVEMODE     | 保存方式      | 可选必选说明：可选参数 参数含义：用于标识SUCI私钥的保存方式。 取值范围： LOCAL(SUCIKEY保存在本地)：SUCI私钥保存在本地。HSM(SUCIKEY保存在HSM)：SUCI私钥保存在HSM。 默认值：无。 配置原则：修改该参数时，必须确保HSM和UDM上的私钥值一致，否则可能导致鉴权失败，影响用户校验。                                                                                                                                                                  |
| KEYVALUE     | SUCI密钥值   | 可选必选说明：条件必选参数 参数含义：用于标识SUCI私钥的取值。 取值范围：64位的十六进制数字组成的字符串。 默认值：无。 配置原则： 当“保存方式”参数取值为“LOCAL(SUCIKEY保存在本地)”时本参数必选，当“保存方式”参数取值为“HSM(SUCIKEY保存在HSM)”时本参数不生效。界面上输入该参数，以"*****"方式匿名显示。                                                                                                                                                     |
| HSMKEYINDEX  | HSM密钥索引   | 可选必选说明：条件必选参数 参数含义：用于标识保存在HSM上的私钥索引。 取值范围：5位~60位的字符串。 默认值：无。 配置原则：当“保存方式”参数取值为“HSM(SUCIKEY保存在HSM)”时本参数必选；当“保存方式”参数取值为“LOCAL(SUCIKEY保存在本地)”时本参数不生效。该参数由组名称+参数名称+ID组成，中间使用“:”分开：组名称和参数名称为字符串形式，且不为空，分别对应导入私钥时的Object group和Object name参数；ID为十进制数字，取值范围是0～2147483647，对应导入私钥时的Object specifier参数。例如：mnts:myParam:1。该参数取值包含字母时，字母区分大小写。 |

## 使用实例

修改“Key名称”为“key1”的SUCI私钥记录，将“SUCI 密钥类型”修改为“PROFILEB（SUCI密钥类型B）”。

```
MOD SUCIKEY: KEYNAME="key1", KEYTYPE=PROFILEB;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见的错误码如表1所示。

|-------:|:-------------|:-----------------------------------------------------------------|:--------------------------------------|
|    505 | 当前操作的配置数据不存在 | 输入的“Key名称”不存在。                                                   | 执行LST SUCIKEY命令查询已存在的“Key名称”，确保其值已存在。 |
| 300022 | SUCI秘钥不合法    | 可能的原因为如下之一： 参数“SUCI密钥值”的取值不是十六进制数字组成的字符串。参数“SUCI密钥值”的长度不等于64个字符。 | 根据实际情况，重新输入“SUCI密钥值”的取值，确保其取值符合要求。    |
| 360041 | 参数值不合法       | 输入的提示参数不合法。                                                      | 根据实际情况，请重新输入，确保输入的参数符合取值范围。           |
