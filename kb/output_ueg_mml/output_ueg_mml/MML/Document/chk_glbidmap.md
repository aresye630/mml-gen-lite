# 检查全局数据ID映射（CHK GLBIDMAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于检查全局数据ID映射数据正确性。

在PCRF接入PCF组成N：1组网演进过程中，当在UPCF Web UI的“全局数据ID映射”执行增加全局数据ID映射操作后，可执行本命令检查全局数据ID映射数据正确性。

## 注意事项

无。

## 参数说明

| 参数ID       | 参数名称   | 参数描述                                                                                                                                                                                                                                                                                                                                                                      |
|:-----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INSTANCENO | PES实例号 | 可选必选说明：必选参数 参数含义：用于指定业务模块类型对应的PES实例号。可通过DSP SERVICEINFO命令查询。 取值范围：长度不超过256的字符串。 默认值： 无。                                                                                                                                                                                                                                                                                   |
| OPTTYPE    | 操作类型   | 可选必选说明：可选参数 参数含义：用于指示操作类型。 取值范围： Check_IDMAP(检查ID映射)Display_Result(查看检查结果) 默认值： Check_IDMAP(检查ID映射)  说明： 该参数为“Check_IDMAP(检查ID映射)”时：如果系统不存在全局数据映射ID数据，则返回错误码。如果“VRM_GLBDATAIDMAPSWITCH”为“0”，则检查ID映射中PCRF全局数据ID是否存在。如果“VRM_GLBDATAIDMAPSWITCH”为“1”，则检查ID映射中PCF全局数据ID是否存在。 该参数为“Display_Result(查看检查结果)”时，显示最近一次“Check_IDMAP(检查ID映射)”的结果，显示“ID映射”含不存在的全局数据ID的记录，且最多显示前10条记录。 |

## 使用实例

检查“PES实例号”为“4222383”的全局数据ID映射数据正确性。

```
CHK GLBIDMAP: INSTANCENO="4222383", OPTTYPE=Display_Result;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见的表1参数说明。

| 输出项名称   | 输出项解释                                                                                                                       |
|:--------|:----------------------------------------------------------------------------------------------------------------------------|
| 内容类型    | 全局数据ID映射失败样例。 取值范围：长度为1～64字节的字符串。                                                                                           |
| 数量      | 全局数据ID映射失败的样例数量，仅返回前10条记录。                                                                                                  |
| 名称      | 全局数据名称。 取值范围：长度为1～128字节的字符串。                                                                                                |
| 类型      | 全局数据类型。 取值范围：长度为1-32字节的字符串。 取值范围： Service：业务ID映射类型。 Quota：配额ID映射类型。 Template：通知模板ID映射类型。 Notify：通知ID映射类型。 Package：套餐ID映射类型。 |
| ID映射    | ID映射。 取值范围：长度为1～64字节的字符串。 格式：PCRF全局数据ID-PCF全局数据ID，中间用英文中横线连接。                                                               |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释             | 原因分析             | 处理建议                                                                |
|------:|:------------------|:-----------------|:--------------------------------------------------------------------|
|  3003 | 无效的PES实例号。        | 输入的PES实例号无效。     | 执行DSP SERVICEINFO命令查询所有实例号，重新执行本命令，确保输入的“PES实例号”为PES对应的“实例号”。       |
|  3090 | 不存在全局ID映射。        | 系统不存在全局数据ID映射数据。 | 确认是否需要进行全局ID映射。如果是，请在UPCF Web UI的“全局数据ID映射”执行增加全局数据ID映射操作后再重新执行本命令。 |
| 11790 | 已经有任务在执行中，请稍后再尝试。 | 系统中已有核查任务在执行。    | 请稍后执行CHK GLBIDMAP: INSTANCENO="xxx", OPTTYPE=Display_Result;查看检查结果。 |
