# 查询前缀限制（LST PREFIXLIMIT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查看当前配置的前缀限制情况。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                                       |
|:--------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| VRFNAME | VPN实例名称 | 可选必选说明：可选参数 参数含义：该参数用于指定VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：默认查询所有VPN。                                                   |
| AFTYPE  | 地址族     | 可选必选说明：可选参数 参数含义：该参数用于指定地址族类型。支持IPv4和IPv6单播地址族。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。ipv6unicast：IPv6单播。 默认值：无 配置原则：默认查询IPv4和IPv6单播地址族。 |

#### 使用实例

查询IPv4前缀限制情况：

```
LST PREFIXLIMIT: AFTYPE=ipv4unicast;
```
