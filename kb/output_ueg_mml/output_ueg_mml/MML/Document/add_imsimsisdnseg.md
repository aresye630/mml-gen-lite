# 增加IMSI和MSISDN号段（ADD IMSIMSISDNSEG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于配置IMSI/MSISDN号码段。设置号段后，可以通过ADD SUBSCRIBERIDSEGGRP命令配置到号段组。最终可以达到根据号段组选择USERPROFILE作为本地策略、根据号段选择OCS、根据号段选择OCS组以及在线计费模板、根据号段选择CG组、根据号段选择SGW离线计费方式等业务功能。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为12000。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称            | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                       |
|:------------|:----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SEGMENTNAME | IMSI/MSISDN号段名称 | 可选必选说明：必选参数 参数含义：该参数用于指定IMSI/MSISDN号段名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                       |
| SEGMENTTYPE | IMSI/MSISDN号段类型 | 可选必选说明：必选参数 参数含义：该参数用于指定IMSI/MSISDN号段类型。 数据来源：全网规划 取值范围：枚举类型。 IMSI：单个IMSI。MSISDN：单个MSISDN。IMSIWILDCARD：IMSI含通配符，可匹配多个IMSI。MSISDNWILDCARD：MSISDN含通配符，可匹配多个MSISDN。 默认值：无 配置原则：无                                                                                                                                                                                                                              |
| SEGSTART    | 号段起始字符串         | 可选必选说明：条件必选参数 前提条件：该参数在“SEGMENTTYPE”配置为“IMSI” 或 “MSISDN”时为必选参数。 参数含义：该参数用于指定起始号段。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～17。 默认值：无 配置原则： SEGMENTTYPE等于IMSI时，SEGSTART取值范围为1~15位数字。不足15位，系统匹配时自动在末尾补0。SEGMENTTYPE等于MSISDN时，SEGSTART取值范围为1~15位数字，如果开头是19，则取值范围1~17位数字。在配置MSISDN时开头可以输入19，SEGSTART截取19之后的字符串存储。SEGSTART过滤开头19后不足15位，系统匹配时自动在末尾补0。如果使用19开头的号码段进行匹配，必须在输入时携带国家码，如号码段191900000000000。SEGSTART必须小于等于SEGEND。 |
| SEGEND      | 号段结束字符串         | 可选必选说明：条件必选参数 前提条件：该参数在“SEGMENTTYPE”配置为“IMSI” 或 “MSISDN”时为必选参数。 参数含义：该参数用于指定结束号段。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～17。 默认值：无 配置原则： SEGMENTTYPE等于IMSI时，SEGEND取值范围为1~15位数字。不足15位，系统匹配时自动在末尾补9。SEGMENTTYPE等于MSISDN时，SEGEND取值范围为1~15位数字，如果开头是19，则取值范围1~17位数字。在配置MSISDN时开头可以输入19，SEGEND截取19之后的字符串存储。SEGEND过滤开头19后不足15位，系统匹配时自动在末尾补9。如果使用19开头的号码段进行匹配，必须在输入时携带国家码，如号码段191900000000000。SEGEND必须大于等于SEGSTART。         |
| WILDCARDSEG | 通配号段字符串         | 可选必选说明：条件必选参数 前提条件：该参数在“SEGMENTTYPE”配置为“IMSIWILDCARD” 或 “MSISDNWILDCARD”时为必选参数。 参数含义：该参数用于指定号段通配。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～47。仅支持“*”、“?”和数字。 默认值：无 配置原则： “?”可代替一个字符，“*”可代替零个或多个字符。SEGMENTTYPE等于IMSIWILDCARD时，WILDCARDSEG中最多只能携带一个“*”，其中“?”需要输入为%3f，IMSI的最大长度为15。SEGMENTTYPE等于MSISDNWILDCARD时，WILDCARDSEG中最多只能携带一个“*”，其中“?”需要输入为%3f，当MSISDN的开头两位为19时，MSISDN的最大长度为17，否则MSISDN的最大长度为15。                  |

#### 使用实例

增加IMSI和MSISDN号段: SEGMENTNAME为huawei，SEGMENTTYPE为IMSI，SEGSTART为130，SEGEND为139：

```
ADD IMSIMSISDNSEG:SEGMENTNAME="huawei",SEGMENTTYPE=IMSI,SEGSTART="130",SEGEND="139";
```
