# 测试HTTP链路可达性 (TST UDMHTTPLNK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于请求系统测试本端到对端的HTTP链路配置，检查HTTP链路是否可达，即防火墙的端口是否放通。

系统尝试建立HTTP链路，建链成功则说明对端可达，即防火墙的端口已放通。

## 注意事项

- 系统只支持逐个探测对端，不支持同时探测多个对端，即只能串行执行该探测命令。
- 该探测命令只支持HTTP链路，不支持HTTPS链路。
- 当对端是HTTPS类型时，执行本命令探测结果显示成功仅表示对端IP端口可达。

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                                          |
|:----------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPVER     | IP地址类型   | 可选必选说明：必选参数 用于标识待探测的HTTP链路的IP地址类型。 取值范围： IPV4(IPV4) IPV6(IPV6) 默认值：无                                                                                          |
| LOCALIPV4 | 本端IPV4地址 | 可选必选说明：条件必选参数 用于标识待探测的HTTP链路的本端IPV4地址。 取值范围：IPV4地址格式的字符串，最大长度为40位。 默认值：无。 配置原则： 仅当本命令中的参数“IP地址类型”取值为“IPV4(IPV4)”时，该参数有效。不支持取值为0.0.0.0或255.255.255.255的IPV4地址。 |
| LOCALIPV6 | 本端IPV6地址 | 可选必选说明：条件必选参数 用于标识待探测的HTTP链路的本端IPV6地址。 取值范围：IPV6地址格式的字符串，最大长度为40位。 默认值：无。 配置原则：仅当本命令中的参数“IP地址类型”取值为“IPV6(IPV6)”时，该参数有效。不支持取值为全0或全F的IPV6地址。                    |
| LOCALPORT | 本端端口     | 可选必选说明：可选参数 用于标识待探测的HTTP链路的本端端口。 取值范围：10000～65535 默认值：无。 配置原则：本端端口不填写时，DCS会自动分配端口，推荐优先选择本端端口自动分配方式。                                                           |
| PEERIPV4  | 对端IPV4地址 | 可选必选说明：条件必选参数 用于标识待探测的HTTP链路的对端IPV4地址。 取值范围：IPV4格式的地址。 默认值：无。 配置原则：仅当本命令中的参数“IP地址类型”取值为“IPV4(IPV4)”时，该参数有效。不支持取值为0.0.0.0或255.255.255.255的IPV4地址。              |
| PEERIPV6  | 对端IPV6地址 | 可选必选说明：条件必选参数 用于标识待探测的HTTP链路的对端IPV6地址。 取值范围：IPV6格式的地址。 默认值：无。 配置原则：仅当本命令中的参数“IP地址类型”取值为“IPV6(IPV6)”时，该参数有效。不支持取值为全0或全F的IPV6地址。                                |
| PEERPORT  | 对端端口     | 可选必选说明：必选参数 用于标识待探测的HTTP链路的对端端口。 取值范围：1～65535 默认值：无。 配置原则：无。                                                                                                  |

## 使用实例

- 测试HTTP链路可达性，链路探测正常场景：

  ```
  TST UDMHTTPLNK: IPVER=IPV4, LOCALIPV4="10.98.102.15", LOCALPORT=10002, PEERIPV4="10.12.202.67", PEERPORT=6060;
  ```

  返回结果如下：

  ```
  %%TST UDMHTTPLNK: IPVER=IPV4, LOCALIPV4="10.98.102.15", LOCALPORT=10002, PEERIPV4="10.12.202.67", PEERPORT=6060;%%
  RETCODE = 0  操作成功
  结果如下
  --------
    IP地址类型  =  IPV4
  本端IPV4地址  =  10.98.102.15
      本端端口  =  10002
  对端IPV4地址  =  10.12.202.67
      对端端口  =  6060
      探测结果  =  正常
  (结果个数 = 1)
  ---    END
  ```
- 测试HTTP链路可达性，链路探测异常场景：

  ```
  TST UDMHTTPLNK: IPVER=IPV4, LOCALIPV4="10.98.102.15", LOCALPORT=10002, PEERIPV4="10.12.202.69", PEERPORT=6060;
  ```

  返回结果如下：

  ```
  %%TST UDMHTTPLNK: IPVER=IPV4, LOCALIPV4="10.98.102.15", LOCALPORT=10002, PEERIPV4="10.12.202.69", PEERPORT=6060;%%
  RETCODE = 0  操作成功
  结果如下
  --------
    IP地址类型  =  IPV4
  本端IPV4地址  =  10.98.102.15
      本端端口  =  10002
  对端IPV4地址  =  10.12.202.69
      对端端口  =  6060
      探测结果  =  异常
      错误信息  =  链路状态故障
  (结果个数 = 1)
  ---    END
  ```
