#### 命令功能

**适用网元：SGSN**

此命令用于查询Iu模式移动性管理流程控制参数。

#### 注意事项

- 此命令执行后立即生效。
- 若不输入流程类型，则将显示所有流程类型的原因值。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                    |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROT   | 流程类型   | 可选必选说明：可选参数 参数含义：待查询的流程类型。 取值范围：“ATTACH(附着流程)”“INTER_RAU(USN间路由区域更新流程)”“INTRA_RAU(USN内路由区域更新流程)”“UPDATE_LOCATION(位置更新流程)”“IU_RELEASE(Iu连接释放流程)”“AIR(获取鉴权集流程)”“AUTHENTICATION(鉴权流程)”“CHECK_IMEI(检查IMEI流程)”“PAGING(寻呼流程)”“CANCEL_LOCATION(位置取消流程)”“NET_SHARE(网络共享)” 默认值：无 |

#### 使用实例

查询流程类型为UPDATE\_LOCATION（位置更新流程）的Iu模式移动性管理流程控制参数：

LST PMMPROCTRL: PROT=UPDATE\_LOCATION;

```
%%LST PMMPROCTRL: PROT=UPDATE_LOCATION;%%
RETCODE = 0  操作成功。

操作结果如下

```
