# 显示基于APN的应用参数（LST APNAPPPARA）

- 命令功能
- 注意事项
- 操作用户权限

- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于显示基于APN的应用参数配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                 |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN    | APN    | 可选必选说明：可选参数 参数含义：用于指定APN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”特殊字符，不区分大小写。 默认值：无 配置原则：不指定APN时，显示所有APN的参数配置。 |

#### 使用实例

显示基于APN的应用参数：

```
LST APNAPPPARA: APN="apn1";
```

```
RETCODE = 0  操作成功。

APN的应用参数
-------------------------------
APN  =  apn1
APP规则生效条件  =  INHERIT
(结果个数 = 1)

---    END
```
