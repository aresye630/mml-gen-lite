# 显示注册的服务名称（DSP SERVICENAME）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询在CMF上注册的服务名称。

若要查询所有网元在CMF上注册的服务名称，请不要输入任何参数。

若要查询某个网元在CMF上注册的服务名称，请输入“网元ID”参数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                          |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：可选参数  参数含义：该参数用于指定网元来查询在CMF上注册的服务名称，可通过LST ME命令查询获取。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~40。  默认值：无  配置原则：  该参数若不输入，则表示查询所有网元在CMF上注册的服务名称。 |

## 使用实例

用户查询在CMF上注册且网元ID为0的服务名称。

```
%%DSP SERVICENAME: MEID="0";%%
RETCODE = 0  操作成功

结果如下
--------
服务名称        网元ID
CellWall        0
SDRS            0
SCFM            0
(结果个数 = 3)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                     |
|:--------|:------------------------------------------|
| 服务名称    | 该参数用于表示服务名称。                              |
| 网元ID    | 该参数用于指定网元来查询在CMF上注册的服务名称，可通过LST ME命令查询获取。 |
