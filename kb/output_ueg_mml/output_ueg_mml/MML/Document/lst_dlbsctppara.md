# 查询DLB服务SCTP参数配置信息(LST DLBSCTPPARA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询SCTP协议参数信息。

如果需要查询所有SCTP协议参数信息，请不要输入任何参数。

## 注意事项

无。

## 参数说明

无。

## 使用实例

假如运营商需要查询SCTP协议参数。

```
LST DLBSCTPPARA:;
```

```
%%LST DLBSCTPPARA:;%%
RETCODE = 0  操作成功

操作结果如下:
------------
            报文重发间隔初始值  =  200
            报文重发间隔最小值  =  200
            报文重发间隔最大值  =  1000
            偶联最大重传次数  =  10
            路径最大重传次数  =  2
            初始化最大重传次数  =  4
            心跳消息间隔  =  2000
            Rto Alpha值  =  2
            Rto Beta值  =  25
            无拥塞级阈值  =  40
            低拥塞级阈值  =  60
            高拥塞级阈值  =  80
            拥塞控制开关  =  FALSE
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见SET DLBSCTPPARA命令的参数说明。
