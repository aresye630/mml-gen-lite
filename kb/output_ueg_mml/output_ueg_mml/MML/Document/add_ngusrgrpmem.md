# 增加5G用户群成员（ADD NGUSRGRPMEM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于为5G用户群增加一条用户群成员记录。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入10000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                            |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------|
| USRGRPID | 用户群组标识 | 可选必选说明：必选参数  参数含义：该参数用于指定5G用户群标识。  数据来源：全网规划  取值范围：整数类型，取值范围是0~4294967294。  默认值：无  配置原则：无                       |
| IMSIPRE  | IMSI前缀 | 可选必选说明：必选参数  参数含义：该参数用于指定用户的IMSI前缀。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是5~15。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无          |
| DESC     | 描述信息   | 可选必选说明：可选参数  参数含义：该参数表示用户群的描述信息，在运维中起助记作用。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~32。  默认值：无  配置原则：  输入单空格将删除该参数已有配置项。 |

## 使用实例

增加一条用户群成员记录，用户群标识为20，IMSI前缀为123456，描述信息为“SomeTown”，执行如下命令：

```
ADD NGUSRGRPMEM: USRGRPID=20, IMSIPRE="123456", DESC="SomeTown";
```
