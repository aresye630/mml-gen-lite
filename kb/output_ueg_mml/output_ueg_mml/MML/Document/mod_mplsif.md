# 修改MPLS接口（MOD MPLSIF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改MPLS接口。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称          | 参数说明                                                                                                      |
|:---------|:--------------|:----------------------------------------------------------------------------------------------------------|
| IFNAME   | 接口名           | 可选必选说明：必选参数 参数含义：该参数用于指定接口名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。       |
| MTUVALUE | 接口配置的MPLS MTU | 可选必选说明：必选参数 参数含义：该参数用于指定接口配置的MPLS MTU。MTU的大小决定了发送端一次能够发送报文的最大字节数。 数据来源：本端规划 取值范围：整数类型，取值范围为46～9600。 默认值：无 |

#### 使用实例

修改MPLS接口：

```
MOD MPLSIF:IFNAME="Ethernet64/0/7",MTUVALUE=1500;
```
