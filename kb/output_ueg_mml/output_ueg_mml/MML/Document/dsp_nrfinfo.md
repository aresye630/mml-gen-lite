## 命令功能

该命令用于显示NRF运行状态信息。

- **命令作用**：
  - 若需要显示某个组中NRF的信息，请输入“NRF所属组信息”参数。
  - 若需要显示所有NRF的信息，不输入任何参数。
- **该命令的使用场景**：
  - 例行健康检查：日常运维过程中，例行检查NRF状态信息是否正常。
  - 异常问题定位：NRF注册心跳链路异常发生后定位NRF与PCF对接配置是否正常，需检查NRF注册实例所有关联MML的配置状态是否异常。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                                                     |
|:---------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NRFGROUP | NRF所属组信息 | 可选必选说明：可选参数 参数含义：用于PCF在本端标识系统需要按照哪个“NRF所属组信息”来显示NRF数据；若不输入，则表示所有的NRF。 取值范围：长度不超过32的字符串，只允许输入：0～9，a～z，A～Z，“-”和“_”。 参数来源：该参数仅由本端PCF自行定义，可通过LST NRFINFO命令查询系统已有配置列表。 默认值：无。 |

## 使用实例

对于局点例行检查或者PCF与NRF心跳链路异常检查场景，均可参考如下详细检查示例：

1. 执行**LST NRFINFO**查询当前NRF配置的全量信息。

   ```
   LST NRFINFO:;
   ```

   ```
   %%LST NRFINFO:;%%
   RETCODE = 0  操作成功  
   操作结果如下 
   ------------ 
   NRF所属组信息  NRF名称  NRF URI                   优先级  超时时长  失败次数  编码方式
   nrfgroup-01    nrf-01   https://192.168.1.1:8080  2       5         3          NULL
   nrfgroup-02    nrf-02   https://192.168.1.2:8080  3       5         3          NULL
   (结果个数 = 2)  
   ---    END
   ```
2. 选择目标“NRF名称”，进一步执行**DSP NRFINFO**命令查询对应NRF状态是否异常。

   ```
   DSP NRFINFO: NRFGROUP="nrfgroup-01";
   ```

   ```
   %%DSP NRFINFO: NRFGROUP="nrfgroup-01";%%
   RETCODE = 0  操作成功  
   操作结果如下 
   ------------ 
   NRF所属组信息  =  nrfgroup-01
         NRF名称  =  nrf-01
         NRF URI  =  https://192.168.1.1:8080
         NRF状态  =  空闲
    网元实例名称  =  NULL
   (结果个数 = 1)  
   ---    END
   ```

   判断第2步显示目标“NRF状态”是否异常。
   - “激活”>表示当前NRF状态正常，结束检查。
   - “空闲”>表示当前NRF状态异常，继续进行步骤3。
3. 参见产品文档“UPCF与NRF对接配置”页面一一检查配置内容是否完整。
   - 是>请进行步骤4。
   - 否>请参考“UPCF与NRF对接配置”页面完成NRF注册内容配置。
4. 查看是否有“ALM-34226 NRF心跳故障”告警产生。
   - 是>请参考告警可能根因一一排查。
   - 否>请继续进行步骤5
5. 请联系华为技术工程师解决问题。

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见ADD NRFINFO命令的参数说明。表1列出的是未包含在ADD NRFINFO命令参数含义中的输出项。

| 输出项名称    | 输出项解释                                                                                                                            |
|:---------|:---------------------------------------------------------------------------------------------------------------------------------|
| NRF所属组信息 | 参数含义：该参数仅用于PCF本端标识PCF当前注册的NRF所有组信息，该参数在执行ADD NFSRV命令进行NRF注册信息实例化时，用于关联目标NRF的URI、优先级等信息。 参数来源：该参数仅由本端PCF通过ADD NRFINFO命令自行定义并添加。   |
| NRF名称    | 参数含义：用于PCF在本端标识NRF在系统中的名称，由于在实际组网中会存在多个NRF的场景，PCF可通过此参数标识具体向哪个NRF发起的注册请求。 参数来源：该参数全局唯一且需PCF与NRF端协商获取此参数名，可通过ADD NRFINFO命令初始配置添加。 |
| NRF URI  | 参数含义：用于PCF端标识待注册NRF的URI。 参数来源：该参数由待PCF发起注册的NRF端提供，全局规划，且唯一。                                                                      |
| NRF状态    | 参数含义：该参数主要用于判断当前NRF注册场景NRF状态是否正常，包括“空闲”和“激活”两种状态。 空闲：NRF处于没有被使用的状态。激活：NRF处于被使用的状态，该状态也表明PCF与NRF之间心跳链路正常。 参数来源：该参数仅由当前命令查询输出。     |
| 网元实例名称   | 参数含义：用于PCF端向该NRF注册的网元实例名称。 参数来源：该参数可通过当前命令查询输出。                                                                                  |
