# 加载软件包（LOD PACKAGE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于加载升级软件包。

#### 注意事项

- 该命令执行后立即生效。
- 只有下载新版本后，才能执行该命令加载新版本。
- 如果软件仓中存在该VNFC同版本的软件包，执行**LOD PACKAGE**命令，加载的是软件仓中的软件包。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识              | 参数名称     | 参数说明                                                                                                                            |
|:------------------|:---------|:--------------------------------------------------------------------------------------------------------------------------------|
| UPDOBJECT         | 升级对象     | 可选必选说明：必选参数 参数含义：该参数用于指定升级对象。 数据来源：本端规划 取值范围：枚举类型。 BaseSoftware：只升级基础版本。Patch：只升级补丁。All：升级基础版本和补丁。 默认值：无                        |
| BASICPKGVERSIONID | 基础软件包版本号 | 可选必选说明：条件必选参数，该参数在“UPDOBJECT”配置为“BaseSoftware” 或 “All”时为必选参数。 参数含义：该参数用于指定要加载的基础软件包版本号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 |
| PATCHPKGVERSIONID | 补丁版本号    | 可选必选说明：条件必选参数，该参数在“UPDOBJECT”配置为“Patch” 或 “All”时为必选参数。 参数含义：该参数用于指定要加载的补丁版本。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无            |
| UPDMODE           | 升级模式     | 可选必选说明：可选参数 参数含义：该参数用于指定升级模式。 数据来源：本端规划 取值范围：枚举类型。 SU：普通升级，一般需要整系统重启。 默认值：SU                                                    |
| SERVICEINSTANCE   | 服务实例     | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。                    |

#### 使用实例

加载升级软件包：

```
LOD PACKAGE:UPDOBJECT=All,BASICPKGVERSIONID="V100R005C00B021",PATCHPKGVERSIONID="SPH0020",SERVICEINSTANCE="vnfc";
```
