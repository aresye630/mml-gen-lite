# 增加Iu接口RNC信息(ADD RNC)

- 命令功能

#### 命令功能

**适用网元：SGSN**

该命令用于增加Iu接口RNC信息。

#### 注意事项

- 该命令执行后立即生效。
- 该表最大记录数为512。
- 输入“NI”和“SPC”确定的信令点必须在SCCP目的信令点表中已经配置。SCCP目的信令点表请参考**ADD SCCPDPC**命令。
- 该命令部分参数与相关特性license共同完成该特性的开启，请在设置参数前使用**DSP LICENSE**命令确认对应特性license是否得到授权，执行**LST LICENSESWITCH**命令确认特性开关状态为“ENABLE(打开)”，具体相关特性请参考参数的说明。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

增加一个RNC，索引为1，RNC名称为TEST，移动国家代码为460，移动网号为00，RNC的标识为1，网络指示语为国内网，信令点编码是0x123，其余参数采用缺省值：

ADD RNC: RNCX=1, RNCN="TEST", RNCMCC="460", RNCMNC="00", RNCID=1, NI=NATB, SPC="123";
