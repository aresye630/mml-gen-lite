# 查询DBS路由目的Location(DSP DBSROUTING)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于请求系统显示目前FE网元的各DBS服务发送消息的目的Location：

- 若要查询所有DBS服务发送消息的目的Location，请不要输入任何参数。
- 若要查询某个DBS服务发送消息的目的Location，请输入“服务模块号”参数。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                       |
|:----------|:-------|:-------------------------------------------------------------------------------------------|
| SERVICENO | 服务模块号  | 可选必选说明：可选参数 参数含义：用于请求系统显示哪个DBS服务发送消息的目的Location；若不输入，则表示所有的DBS服务。 取值范围：1～1024 默认值：无 配置原则：无 |

## 使用实例

查询所有DBS服务发送消息的目的Location。

```
DSP DBSROUTING:;
```

```
%%DSP DBSROUTING:;%%
RETCODE = 0  操作成功

操作结果如下
------------
服务模块号    目的Location标识  最高优先级Location标识  业务类型  操作结果
40            88                88                      SUP-FE    操作成功   
41            89                88                      SUP-FE    操作成功
(结果个数 = 2)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1的参数说明。

| 输出项名称           | 输出结果解释                        |
|:----------------|:------------------------------|
| 服务模块号           | 用于返回DBS服务模块号。                 |
| 目的Location标识    | 用于返回目前消息发送的Location。          |
| 最高优先级Location标识 | 用于返回DBS服务当前状态正常的高优先级Location。 |
| 业务类型            | 表示返回FE的业务类型。                  |
| 操作结果            | 操作结果。 操作成功操作失败                |
