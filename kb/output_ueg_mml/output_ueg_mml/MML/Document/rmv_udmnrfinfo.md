## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除一个NRF网元的数据信息。

- **命令作用**：该命令用于配置UDM需要注册到的NRF信息时，当组网中部署了多个NRF网元，支持删除配置目标NRF的所属组及优先级等信息。
- **命令索引关系**：该命令的参数索引关系如图1所示。

  **图1** 命令参数的索引关系图

## 注意事项

- 如果NRF所属的组被某个NFSRV引用，则应该保证数据删除后此组内至少还剩下一个NRF。操作员可以先使用**LST UDMNFSRV**命令查询NRF所属组是否被NFSRV引用，若被引用，则使用**LST UDMNRFINFO**命令查询NRF所属组内NRF的个数。
- 当凌晨自动校验或执行**VRY NRFDATA**命令手动校验NRFClient内存数据时，在校验该MML命令的过程中，无法执行该命令，若运行该命令，则提示“360155 该MML数据正在校验中，请稍后再试”。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                            |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------|
| NRFNAME | NRF名称  | 可选必选说明：必选参数 参数含义：标识一条NRF数据记录的关键字段，用于指定需要删除哪一条NRF数据记录。 取值范围：长度不超过32位的字符串。 参数来源：该参数全局唯一且需UDM与NRF端协商获取此参数名，可通过执行LST UDMNRFINFO命令查询获得。 默认值：无 配置原则：无 |

## 使用实例

当在测试场景下网元上不带业务时，由于在使用**ADD UDMNRFINFO**命令添加NRF注册信息时，错误配置了UDM需要发起注册的“NRF名称”参数，此时须执行如下步骤进行操作：

1. 执行**RMV UDMNRFINFO**命令删除错误配置记录之前，须先使用**LST UDMNFSRV**命令查询NRF所属组是否被网元实例引用：

   ```
   %%LST UDMNFSRV: NFINSNAME="udm-application-001";%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------

       网元实例标识  =  f716585a-cb75-474c-9202-6e8ce59d3651
      NRF所属组信息  =  udm-nrfgroup-01
           网元类型  =  统一数据管理
           网元状态  =  正常工作状态
           配置方式  =  命令模式
         PLMN组名称  =  nfplmn1
      S-NSSAI组名称  =  UDM
            NSI列表  =  NULL
               位置  =  NULL
   网元公共信息标识  =  cominfo_01
       网元信息标识  =  cominfo_01
     网元服务持续性  =  是
         网元服务组  =  UDM1
       上报网管标志  =  不上报网管
           更新方法  =  PUT更新
           心跳周期  =  0
           更新标识  =  触发更新
           恢复时间  =  2020-08-31 10:36:20
       网元实例信息  =  NULL
   (结果个数 = 1)

   ---    END
   ```
2. 继续执行**LST UDMNRFINFO**命令查询待删除NRF注册信息中“NRF所属组信息”参数的取值。

   ```
   %%LST UDMNRFINFO: NRFNAME="nrf-01";%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
               NRF所属组信息  =  nrfgroup-01
                     NRF名称  =  nrf-01
                     NRF URI  =  http://192.168.1.1:8080
                      优先级  =  2
   NF注册消息是否启用Gzip压缩 =  不启用
   (结果个数 = 1)

   ---    END
   ```
3. 根据1，2步执行结果判断第1步的查询结果中的“NRF所属组信息”参数的取值是否与步骤2中查询“NRF所属组信息”参数的取值一致：
   - 若一致，请执行a，b两步完成NRF注册信息删除操作。
     1. 执行**RMV UDMNFSRV**删除网元实例：

        ```
        RMV UDMNFSRV: NFINSNAME="udm-application-001";
        ```
     2. 执行**RMV UDMNRFINFO**删除NRF网元，“NRF名称”为“nrf-01”：

        ```
        RMV UDMNRFINFO: NRFNAME="nrf-01";
        ```
   - 若不一致，请直接执行**RMV UDMNRFINFO**删除NRF网元，“NRF名称”为“nrf-01”：

     ```
     RMV UDMNRFINFO: NRFNAME="nrf-01";
     ```
4. 删除配置错误的NRF注册信息后，重新根据正确规划的NRF注册信息完成NRF注册信息添加。

   ```
   ADD UDMNRFINFO: NRFGROUP="nrfgroup-01", NRFNAME="nrf-02", NRFURI="https://192.168.1.2:8080", PRI=2;
   ```
5. 再次执行**LST UDMNRFINFO**命令查询当前配置与其规划是否一致。

   ```
   %%LST UDMNRFINFO: NRFNAME="nrf-02";%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
               NRF所属组信息  =  nrfgroup-01
                     NRF名称  =  nrf-02
                     NRF URI  =  http://192.168.1.1:8080
                      优先级  =  2
   NF注册消息是否启用Gzip压缩 =  不启用
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                    | 原因分析                                        | 处理建议                                                            |
|-------:|:-----------------------------------------|:--------------------------------------------|:----------------------------------------------------------------|
|    505 | 当前操作的配置数据不存在                             | “NRF名称”不存在。                                 | 使用LST UDMNRFINFO命令查询获得“NRF名称”，确保其值已存在。                          |
| 300015 | 被删除的NRF网元是组内的最后一个NRF网元，当有网元实例向其注册时，不能被删除 | 该NRF的“NRF所属组信息”被某一NFSRV引用，且该NRF所属组只包含一个NRF。 | 先删除NFSRV对该NRF所属组的引用，再删除该NRF，可通过命令LST UDMNFSRV查询引用该NRF所属组的NFSRV。 |
| 360155 | 该MML数据正在校验中，请稍后再试                        | NRFClient内存数据校验正在进行中，对该命令的校验结束后才可执行该命令。     | 请稍后重试。                                                          |
