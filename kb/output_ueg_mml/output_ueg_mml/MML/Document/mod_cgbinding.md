# 修改CG绑定关系（MOD CGBINDING）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

该命令用来修改CG绑定关系。

#### 注意事项

- 该命令执行后立即生效。
- 修改CG绑定关系，仅允许修改绑定的优先级。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                          |
|:------------|:----------|:--------------------------------------------------------------------------------------------------------------|
| CGGRPID     | CG组ID     | 可选必选说明：必选参数 参数含义：指定CG组ID。 数据来源：本端规划 取值范围：整数类型，取值范围为1～32。 默认值：无 配置原则：该参数使用ADD CGGROUP命令配置生成。                   |
| CGIPVERSION | CG IP版本   | 可选必选说明：必选参数 参数含义：该参数用于指定CG IP类型。 数据来源：全网规划 取值范围：枚举类型。 IPV4：IPv4。IPV6：IPv6。 默认值：无 配置原则：无                       |
| CGIPV4ADDR  | CG IPv4地址 | 可选必选说明：条件必选参数 前提条件：该参数在“CGIPVERSION”配置为“IPV4”时为必选参数。 参数含义：CG服务器IPv4地址。 数据来源：全网规划 取值范围：IPv4地址类型。 默认值：无 配置原则：无  |
| CGIPV6ADDR  | CG IPv6地址 | 可选必选说明：条件必选参数 前提条件：该参数在“CGIPVERSION”配置为“IPV6”时为必选参数。 参数含义：CG服务器的IPv6地址。 数据来源：全网规划 取值范围：IPv6地址类型。 默认值：无 配置原则：无 |
| CGPORT      | CG端口号     | 可选必选说明：必选参数 参数含义：CG服务器端口号。 数据来源：全网规划 取值范围：整数类型，取值范围为1024～65535。 默认值：无 配置原则：无                                  |
| PRIORITY    | 等级        | 可选必选说明：必选参数 参数含义：CG服务器的等级。值越小优先级越高，即0的优先级最高，100的优先级最低。 数据来源：本端规划 取值范围：整数类型，取值范围为0～100。 默认值：无 配置原则：无           |

#### 使用实例

修改CG绑定关系，CG组ID为1，CG的IP地址为192.168.0.2，CG的端口号为25009，CG优先级修改为2：

```
MOD CGBINDING: CGGRPID=1, CGIPVERSION=IPV4, CGIPV4ADDR="192.168.0.2", CGPORT=25009, PRIORITY=2;
```
