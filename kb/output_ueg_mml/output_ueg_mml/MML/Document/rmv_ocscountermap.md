# 删除OCS Counter映射(RMV OCSCOUNTERMAP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响UPCF与OCS相关的业务的正常使用，需联系华为技术支持确认后再执行。

该命令用于在UPCF配置数据库中删除一条配额名称与配额状态的OCS Counter映射记录。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称   | 参数描述                                                                                                         |
|:----------|:-------|:-------------------------------------------------------------------------------------------------------------|
| QUOTANAME | 配额名称   | 可选必选说明：必选参数 参数含义：用于指定要删除OCS Counter映射关系的配额名称。操作员可通过LST OCSCOUNTERMAP命令查询获得。 取值范围：长度不超过32的字符串。 默认值：无。 配置原则：无。 |

## 使用实例

删除一条OCS Counter映射记录，“配额名称”为“PackName”。

```
RMV OCSCOUNTERMAP: QUOTANAME="PackName";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
