#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询原因值映射配置。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                                        |
|:-----------|:--------|:------------------------------------------------------------------------------------------------------------|
| CAUSEGRPID | 原因值组标识  | 可选必选说明：可选参数 参数含义：该参数用于指定表示一个原因值映射规则集合的唯一数字ID。 取值范围：1～127 默认值：无                                              |
| CAUSERANGE | 原因值范围   | 可选必选说明：可选参数 参数含义：该参数用于指定原因值范围。 取值范围： “DEFAULT(缺省)”“SPECIAL(特定)” 默认值：无                                       |
| BGCAUSE    | 起始原始原因值 | 可选必选说明： 条件可选参数 参数含义：该参数用于指定起始原始原因值。 前提条件：该参数在“CAUSERANGE(原因值范围)”设置为“SPECIAL(特定)”时，才需要配置。 取值范围：1～65535 默认值：无 |

#### 使用实例

查询原因值组标识为126，原因值范围设置为缺省的原因值映射配置：

LST CAUSEMAP: CAUSEGRPID=126, CAUSERANGE=DEFAULT;

```
%%LST CAUSEMAP: CAUSEGRPID=126, CAUSERANGE=DEFAULT;%%
RETCODE = 0  操作成功。

输出结果如下
--------------
  原因值组标识  =  126
    原因值范围  =  缺省
起始原始原因值  =  NULL
终止原始原因值  =  NULL
    目标原因值  =  37
（结果个数 = 1）

---    END
```
