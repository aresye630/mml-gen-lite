# 显示隧道协议（DSP TNLPROTOCOL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示隧道协议。

#### 注意事项

只有配置隧道才能使用该命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

显示隧道协议：

```
DSP TNLPROTOCOL:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
接口名字    隧道类型
Tunnel0     Gre
Tunnel1     Gre
(结果个数 = 2)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释     |
|:--------|:----------|
| 接口名字    | 用于表示接口名字。 |
| 隧道类型    | 用于表示隧道类型。 |
