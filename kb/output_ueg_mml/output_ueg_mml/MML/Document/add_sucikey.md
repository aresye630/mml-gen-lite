# 增加SUCI密钥(ADD SUCIKEY)

## 命令功能

该命令用于增加一条SUCI私钥，用于在鉴权功能中将UE端加密生成的SUCI值在UDM侧解密生成SUPI。

## 注意事项

“SUCI密钥类型”、“SUCI密钥ID”、“归属网络标识”和“路由指示符”四个参数取值的组合必须唯一。

## 参数说明

| 参数标识         | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                               |
|:-------------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| KEYNAME      | Key名称     | 可选必选说明：必选参数 参数含义：用于标识SUCI私钥的名称。 取值范围：1～16个字母、数字或特殊字符组成的字符串。 默认值：无。 配置原则：该参数是SUCI私钥记录的唯一索引。该参数全局唯一，不能重复。                                                                                                                                                                                                                            |
| KEYTYPE      | SUCI 密钥类型 | 可选必选说明：必选参数 参数含义：用于标识SUCI私钥的加密方式类型，目前针对SUCI的加密算法有两种，一种是PROFILEA类型，一种是PROFILEB类型。 取值范围： PROFILEA（SUCI密钥类型A）PROFILEB（SUCI密钥类型B） 默认值：无。 配置原则：无。                                                                                                                                                                                       |
| KEYID        | SUCI 密钥ID | 可选必选说明：必选参数 参数含义：用于标识SUCI私钥的ID。 取值范围：1～255 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                          |
| HNIDENTIFIER | 归属网络标识    | 可选必选说明：可选参数 参数含义：用于标识SUCI私钥的归属网络标识，由移动国家码和移动网络码组成。 取值范围：5~6位的十进制数字组成的字符串。 默认值：无。 配置原则：执行该命令并且不输入该参数时，系统会设置初始值“FFFFFF”。                                                                                                                                                                                                             |
| RTINDICATOR  | 路由指示符     | 可选必选说明：可选参数 参数含义：用于标识SUCI私钥的路由指示符，通过配置该参数确定归属的UDM/AUSF。 取值范围：1~4位的十进制数字组成的字符串。 默认值：无。 配置原则：执行该命令并且不输入该参数时，系统会设置初始值“FFFF”。                                                                                                                                                                                                          |
| SAVEMODE     | 保存方式      | 可选必选说明：必选参数 参数含义：用于标识SUCI私钥的保存方式。 取值范围： LOCAL(SUCIKEY保存在本地)：SUCI私钥保存在本地。HSM(SUCIKEY保存在HSM)：SUCI私钥保存在HSM。 默认值：LOCAL(SUCIKEY保存在本地) 配置原则：无。                                                                                                                                                                                           |
| KEYVALUE     | SUCI密钥值   | 可选必选说明：条件必选参数 参数含义：用于标识SUCI私钥的取值。 取值范围：64位的十六进制数字组成的字符串。 默认值：无。 配置原则： 当“保存方式”参数取值为“LOCAL(SUCIKEY保存在本地)”时本参数必选，当“保存方式”参数取值为“HSM(SUCIKEY保存在HSM)”时本参数不生效。界面上输入该参数，以"*****"方式匿名显示。                                                                                                                                                     |
| HSMKEYINDEX  | HSM密钥索引   | 可选必选说明：条件必选参数 参数含义：用于标识保存在HSM上的私钥索引。 取值范围：5位~60位的字符串。 默认值：无。 配置原则：当“保存方式”参数取值为“HSM(SUCIKEY保存在HSM)”时本参数必选；当“保存方式”参数取值为“LOCAL(SUCIKEY保存在本地)”时本参数不生效。该参数由组名称+参数名称+ID组成，中间使用“:”分开：组名称和参数名称为字符串形式，且不为空，分别对应导入私钥时的Object group和Object name参数；ID为十进制数字，取值范围是0～2147483647，对应导入私钥时的Object specifier参数。例如：mnts:myParam:1。该参数取值包含字母时，字母区分大小写。 |

## 使用实例

当运营商需要增加一条SUCI私钥，用于在鉴权功能中将UE端加密生成的SUCI值在UDM侧解密生成SUPI，设置“Key名称”为“key1”的SUCI私钥记录，其中“SUCI密钥类型”为“PROFILEA（SUCI密钥类型A）”，“SUCI密钥ID”为1，“归属网络标识”为“35621”，“路由指示符”为“1342”，“保存方式”为“LOCAL(SUCIKEY保存在本地)”，“SUCI密钥值”为“77076d0a7318a57d3c16c17251b26645df4c2f87ebc0992ab177fba51db92c2a”。

```
ADD SUCIKEY: KEYNAME="key1", KEYTYPE=PROFILEA, KEYID=1, HNIDENTIFIER="35621", RTINDICATOR="1342", SAVEMODE=LOCAL, KEYVALUE="*****";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见的错误码如表1所示。

## 参考信息

**SUCI**

SUCI（Subscription concealed identifier）是一次性使用的用户隐藏标识，用于确保用户标识在传输过程中的安全。

**SUPI**

SUPI（Subscription permanent identifier）是UE的永久身份标识，用来唯一标识UE。
