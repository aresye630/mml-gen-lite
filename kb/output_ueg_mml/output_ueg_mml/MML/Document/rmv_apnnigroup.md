# 删除APNNI组(RMV APNNIGROUP)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于删除APNNI组信息。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                             |
|:-------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------|
| GRPID  | APNNI组号 | 可选必选说明：必选参数 参数含义：该参数用于指定APNNI组号。 数据来源：本端规划 取值范围：0～15 默认值：无  说明： 当SET PGWBACKOFF命令开启时，不能删除SET PGWBACKOFF命令中配置的APNNI组号。不能删除ADD APNNI命令中配置的APNNI组号。 |

#### 使用实例

删除组号为“2”的APNNI组号，则设置“APNNI组号”参数为“2”。运行如下命令：

RMV APNNIGROUP: GRPID=2;
