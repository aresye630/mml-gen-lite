# 设置服务接口过滤参数(SET SBIFILTERPARA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令用于设置服务接口过滤参数。

使用场景：在安全加固场景下，通过**ADD SBIFILTERLST**可以设置允许接入或者禁止访问的每个服务的IP地址列表。然后通过该命令参数的“StatCheck(静态检查参数)”来设置系统的黑名单过滤或白名单过滤。从而实现在UPCF提供服务前，对白名单内的服务访问者进行静态授权检查，对黑名单内的服务访问者禁止接入和授权。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                       |
|:----------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| STATCHECK | 静态检查参数 | 可选必选说明：必选参数 参数含义：用于标识服务化接口静态授权检查的策略。 取值范围： OFF(OFF)：不进行静态授权检查WHITELIST(WHITELIST)：使用白名单过滤功能，即只处理源IP属于白名单列表的请求消息。通过ADD SBIFILTERLST命令可以设置白名单，参数“操作类型”需设置为“WHITELIST(白名单)”。BLACKLIST(BLACKLIST)：使用黑名单过滤功能，即只过滤源IP属于黑名单列表的请求消息。通过ADD SBIFILTERLST命令可以设置黑名单，参数“操作类型”需设置为“BLACKLIST(黑名单)”。 默认值：无。 配置原则：无。  说明： 当该参数取值为非“OFF(OFF)”时，若黑白名单配置达到最大配置数，HLB服务性能将会下降15%，如需开启请联系华为技术支持。 |
| DYNCHECK  | 动态检查参数 | 可选必选说明：可选参数 参数含义：用于标识服务化接口动态授权检查的策略。 取值范围： OFF(OFF)：不进行动态授权检查ON(ON)：进行动态授权检查 默认值：无。 配置原则：无。  说明： 当使用HTTPS协议进行通信且该参数设置为“ON(ON)”时，HLB服务性能将会下降20%，如需开启请联系华为技术支持。                                                                                                                                                                                                              |

## 使用实例

UPCF作为服务端时，若已经配置允许接入的服务访问者的IP地址白名单，然后设置静态授权检查使用白名单检查，并且关闭动态检查参数检查。即“静态检查参数”设置为“WHITELIST”，“动态检查参数”设置为“OFF”。

```
SET SBIFILTERPARA: STATCHECK=WHITELIST, DYNCHECK=OFF;
```
