# 修改服务发现条件信息（MOD DISCCONDCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致系统异常，影响业务处理，需联系华为技术支持确认后再执行。

该命令用于修改一条服务发现条件信息。

在该命令中，系统通过以下关键参数的组合来唯一标识服务发现条件一条信息：

- “网元类型”
- “CHF参数”、“BSF参数”、“SCP参数”、“AMF参数”、"NWDAF参数"或“PCF参数”

## 注意事项

无。

## 使用实例

修改BSF参数。“网元类型”为“BSF(BSF)”，“BSF参数”为“IPV6PREFIX”：

```
MOD DISCCONDCFG: NFTYPE=BSF, BSFPARA=IPV4ADDR-0&IPV4DNN-0&IPV4IPDOMAIN-0&IPV6PREFIX-1;
```
