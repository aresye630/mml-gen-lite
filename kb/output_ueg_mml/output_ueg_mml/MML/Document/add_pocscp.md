# 增加PCRF对端OCS接入点实体(ADD POCSCP)

## 命令功能

该命令用于在UPCF网元下增加一个对端OCS接入点。

该命令的使用场景：开局场景下，UPCF需要通过Sy接口与OCS对接的时候，必须先使用本命令增加对端OCS接入点。

在该命令中，“对端域名”和“对端主机名”参数的配置需要与对端OCS接入点协商一致。

## 参数说明

| 参数ID          | 参数名称        | 参数描述                                                                                                                                                                                                                    |
|:--------------|:------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PCRFID        | PCRF标识      | 用于标识PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围：1 默认值：无。                                                                                                                                                                 |
| CPID          | 接入点标识       | 用于标识对端OCS的接入点标识。 该参数的配置原则：全局唯一，与对端OCS接入点实体对应。实际可配置的最大值受系统软参“VRM_MAXPOCSCPNUM”的限制（VRM_MAXPOCSCPNUM-1），系统软参当前值可通过LST PCFINSP命令进行查询，具体软参功能及使用方法请参见《UPCF软件参数》。 取值范围：0～15 默认值：无。                                             |
| CPN           | 接入点名称       | 用于标识对端OCS接入点的名称。 取值范围：长度不超过128的字符串。 默认值：无。                                                                                                                                                                              |
| DN            | 对端域名        | 用于标识对端OCS接入点的域名。 该参数的配置原则：该参数需要PCRF与OCS接入点协商一致。该参数的取值不区分大小写，建议使用小写。若使用大写输入，系统会默认以小写的方式进行处理。 取值范围：长度不超过64的字符串。 默认值：无。                                                                                                    |
| HN            | 对端主机名       | 用于标识对端OCS接入点的主机名。 该参数的配置原则：该参数全网唯一，由运营商统一规划。该参数需要PCRF与OCS接入点协商一致。该参数的取值不区分大小写，建议使用小写。若使用大写输入，系统会默认以小写的方式进行处理。 取值范围：长度不超过127的字符串。 默认值：无。                                                                                 |
| DASWITCH      | 审计开关        | 用于标识PCRF与对端OCS接入点对接设备间的审计开关。 取值说明： OFF(关闭定时审计)ON(打开定时审计) 默认值：OFF(关闭定时审计)                                                                                                                                                |
| DATIME        | 设备间审计时长 （m） | 用于标识PCRF与对端OCS接入点对接设备间的审计的时长。当设备间审计开关为ON时，需要输入设备间审计时长。 单位：分钟。 取值范围：15～1440 默认值：无。                                                                                                                                       |
| CPP           | 接入点优先级      | 用于配置OCS接入点的优先级，优先级值越小，优先级越高。 取值范围：0～255 默认值：0。  说明： 在多个OCS对端上配置优先级，若优先级相同则是轮询关系，优先级不同则是主备关系，UPCF优先将消息发往优先级高的OCS。当OCS上已经存在会话，此时修改OCS对端优先级，导致多个OCS对端的优先级排序与修改前不一样，原OCS上已经存在的会话将保持现有处理，不会迁移到优先级较高的对端。同时，后续新会话按照新优先级排序选择对端。 |
| ABILITYDICTID | 能力字典ID      | 用于配置OCS能力字典。 取值范围：0~15 默认值：无。  说明： 该参数仅支持与UPCF直连的OCS配置，不支持通过DRA与UPCF连接OCS的配置。                                                                                                                                           |

## 使用实例

在开局或其他场景中UPCF需要与OCS对接的时候，添加对端OCS接入点时需要进行如下配置。

1. 向运营商处获取对端域名和对端主机名。例如：对端域名为“huawei.com”，对端主机名为“ocs.huawei.com”。
2. 执行**ADD POCSCP**增加PCRF对端OCS接入点实体。待增加OCS接入点实体的其它参数配置信息如下：“接入点标识”为“0”，“接入点名称”为“UPCF\_OCS”，“审计开关”为“ON”，“设备间审计时长”为“720”。

   ```
   ADD POCSCP: PCRFID=1, CPID=0, CPN="UPCF_OCS", DN="huawei.com", HN="ocs.huawei.com", DASWITCH=ON, DATIME=720;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                                    | 原因分析                                    | 处理建议                                                                                        |
|------:|:-----------------------------------------|:----------------------------------------|:--------------------------------------------------------------------------------------------|
| 57843 | CPID非法: CPID值超出范围(0～VRM_MAXPOCSCPNUM-1)。 | 输入的“接入点标识”取值不在0～ VRM_MAXPOCSCPNUM-1范围内。 | 执行LST PCFINSP命令进行查询“VRM_MAXPOCSCPNUM”软参当前值，然后重新执行本命令确保要添加的“接入点标识”取值范围为0～VRM_MAXPOCSCPNUM-1。 |
