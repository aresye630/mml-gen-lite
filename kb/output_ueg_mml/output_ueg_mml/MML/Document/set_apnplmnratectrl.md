# 设置APN Serving PLMN速率控制配置（SET APNPLMNRATECTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

配置基于APN的Serving PLMN速率控制功能，可能会导致用户业务丢包。

**适用NF：PGW-C、SGW-C**

该命令用于配置基于APN的Serving PLMN速率控制功能，用于限制终端的数据传输速率。

## 注意事项

- 该命令执行后立即生效。

- 在每次执行ADD CPAPN命令时会自动为本命令增加一条记录，记录中参数的初始设置值如下：PLMNRATECTRLSW：DISABLE。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称                   | 参数说明                                                                                                                                                                                                                            |
|:---------------|:-----------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN            | APN名称                  | 可选必选说明：必选参数  参数含义：该参数用于指定APN实例名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无。  配置原则：  该参数使用ADD CPAPN命令配置生成。 |
| PLMNRATECTRLSW | APN Serving PLMN速率控制开关 | 可选必选说明：必选参数  参数含义：该参数用于基于APN控制开启和关闭Serving PLMN速率控制功能。  数据来源：本端规划 取值范围： “ENABLE（使能）”：使能“DISABLE（不使能）”：不使能“INHERIT（继承全局）”：继承全局  默认值：无。  配置原则：无                                                                                   |

## 使用实例

APN名称为test下的PLMN速率控制开关配置为ENABLE：

```
SET APNPLMNRATECTRL:APN="test",PLMNRATECTRLSW=ENABLE;
```
