# 启动会话备份数据审计任务（STR SESSADT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为维护类命令，用于任意时间启动审计任务。

## 注意事项

在没有设置审计任务的情况下，执行该命令时，将使用系统缺省的会话审计任务配置来启动审计任务。

**说明** 

系统有以下2个缺省的会话审计任务：

```
审计类型    启动时间    审计周期     会话过期时长     审计速度     任务状态     审计失败告警     告警阈值（万分之一）    PS_IPADDR表审计功能
UPCF        03:00:00    12           NULL             10           打开         上报告警               20                不开启审计
USCDB       03:00:00    24           48               30           打开         不上报告警             20                不开启审计
```

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                              |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------|
| TYPE   | 审计类型   | 指定审计任务的类型。 取值范围： UPCF (UPCF与USCDB间的会话数据审计)USCDB(USCDB的会话备份冗余数据清理审计) 说明： 当需要启动USCDB的会话备份冗余数据清理审计任务时，执行STR OTSSESSADT命令启动任务。 默认值：无。 |

## 使用实例

启动“审计类型”为“UPCF”会话备份数据审计任务操作。执行命令如下：

```
STR SESSADT: TYPE=UPCF;
```
