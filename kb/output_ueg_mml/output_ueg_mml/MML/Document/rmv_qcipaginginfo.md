# 删除QCI寻呼策略参数配置(RMV QCIPAGINGINFO)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于删除特定QCI（QoS Class Identifier）对应的寻呼策略配置。

#### 注意事项

- 该命令执行后立即生效。
- 该命令执行后，特定QCI消息出发的Paging策略使用系统默认的参数配置(通过**SET EMM**设定)。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                         |
|:-------|:-------|:-------------------------------------------------------------|
| QCI    | 标准QCI值 | 可选必选说明：必选参数 参数含义：该参数用于指定需要删除的寻呼策略对应的标准QCI值。 取值范围：1～254 默认值：无 |

#### 使用实例

删除标准QCI为1的寻呼策略参数配置：

RMV QCIPAGINGINFO: QCI=1;
