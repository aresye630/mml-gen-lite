# 查询APN组（LST BSFAPNGROUP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询APN组。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                               |
|:--------|:-------|:-----------------------------------------------------------------------------------|
| GRPNAME | APN组名  | 可选必选说明：可选参数  参数含义：该参数用于指定APN组名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。  默认值：无  配置原则：无 |

## 使用实例

查询APN组"apngroup1"中的APN信息：

```
%%LST BSFAPNGROUP: GRPNAME="apngroup1";%%
RETCODE = 0  操作成功

结果如下
--------
APN组名  =  apngroup1
APN名称  =  huawei.com
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释         |
|:--------|:--------------|
| APN组名   | 该参数用于指定APN组名。 |
| APN名称   | 该参数用于指定APN名称。 |
