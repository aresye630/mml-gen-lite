# 查询PAE批量收包的数量（LST PAEBATCHRECVNUM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询PAE批量收包的数量。

## 注意事项

- 该命令查询结果为记录在OM DB中的值，即**SET PAEBATCHRECVNUM**命令所配置的原始值。
- 查询实际生效值请使用**DSP PAEBATCHRECVNUM**命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询PAE批量收包数量：

```
+++    UNC/*MEID:0 MENAME:project-v6*/        2024-01-24 14:39:30
O&M    #172
%%LST PAEBATCHRECVNUM:;%%
RETCODE = 0  操作成功

结果如下
--------
PAE批收数量  =  批收数224
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释            |
|:--------|:-----------------|
| PAE批收数量 | 该参数表示PAE批量收包的数量。 |
