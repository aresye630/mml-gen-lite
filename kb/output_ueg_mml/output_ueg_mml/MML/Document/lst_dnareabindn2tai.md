# 查询DNAI服务区名称绑定的5G TAI范围（LST DNAREABINDN2TAI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、SMF、GGSN、PGW-C**

该命令用于查询DNAI服务区名称绑定的5G TAI范围。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称       | 参数说明                                                                                                                                                                                                                 |
|:---------|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AREANAME | DNAI服务区域名称 | 可选必选说明：可选参数  参数含义：该参数用于标识DNAI服务区域名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~255。不能为非法字符，只允许输入字母，数字、“_”、“.”，并且开头和结尾只能是数字或者字母，不能出现连续两个“.”，不区分大小写。  默认值：无  配置原则：  该参数取值应与命令LST DNAREA查询结果中的AREANAME保持一致，且对应的AREATYPE取值应为N2TAI。 |

## 使用实例

- 查询UPF服务区名称为"DNAREA1"的区域绑定的TAI。
  LST DNAREABINDN2TAI: AREANAME="DNAREA1";

  ```
  %%LST DNAREABINDN2TAI: AREANAME="DNAREA1";%%
  RETCODE = 0  操作成功

  结果如下
  --------
                     DNAI服务区域名称  =  dnarea1
  DNAI服务区名称支持5G TAI范围的起始值  =  46001000001
  DNAI服务区名称支持5G TAI范围的结束值  =  46001123456
  (结果个数 = 1)
  ```
- 查询所有UPF服务区名称绑定的LAI。
  LST DNAREABINDN2TAI:;

  ```
  %%LST DNAREABINDN2TAI:;%%
  RETCODE = 0  操作成功

  结果如下
  --------
  DNAI服务区域名称  DNAI服务区名称支持5G TAI范围的起始值  DNAI服务区名称支持5G TAI范围的结束值  

  dnarea1           46001000001                          46001123456                          
  dnarea3           46001123457                          46001234567                          
  (结果个数 = 2)
  ```

## 输出结果说明

| 输出项名称                   | 输出项解释                                                |
|:------------------------|:-----------------------------------------------------|
| DNAI服务区域名称              | 该参数用于标识DNAI服务区域名称。                                   |
| DNAI服务区名称支持5G TAI范围的起始值 | 该参数用于标识DNAI服务区名称支持5G TAI范围的起始值，TAI = MCC+ MNC + TAC。 |
| DNAI服务区名称支持5G TAI范围的结束值 | 该参数用于标识DNAI服务区名称支持5G TAI范围的结束值，TAI = MCC+ MNC + TAC。 |
