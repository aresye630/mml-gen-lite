# 修改应用性能统计（MOD APPPERFSTAT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、PGW-U**

该命令用于修改应用性能统计。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                                                                 |
|:--------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APPNAME       | 应用名称   | 可选必选说明：必选参数 参数含义：该参数用来指定应用名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                                                                            |
| FILTERMODE    | 过滤器模式  | 可选必选说明：必选参数 参数含义：该参数用于指定过滤器模式。 数据来源：本端规划 取值范围：枚举类型。 PROTOCOLGROUP：协议组级别。 默认值：无 配置原则：无                                                                                                                                                |
| PROTGROUPNAME | 协议组名称  | 可选必选说明：条件必选参数 前提条件：该参数在“FILTERMODE”配置为“PROTOCOLGROUP”时为必选参数。 参数含义：该参数用来指定协议组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则： 仅支持绑定自定义协议组，不支持绑定默认协议组。该取值必须和ADD PROTOCOLGROUP中配置的“ProtGroupName”参数取值相同。输入单空格将删除该参数已有配置项。 |
| PRIORITY      | 优先级    | 可选必选说明：可选参数 参数含义：该参数用于设置优先级。优先级1-65535，越小优先级越高。 数据来源：本端规划 取值范围：整数类型。 默认值：无 配置原则：不允许重复，以免同时匹配中多个。                                                                                                                                     |
| CFGDOMAINNAME | 配置域名称  | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。                                                                                                                                   |

#### 使用实例

假如需要修改应用性能统计，则命令如下：

```
MOD APPPERFSTAT: APPNAME="test", FILTERMODE=PROTOCOLGROUP, PROTGROUPNAME="test";
```
