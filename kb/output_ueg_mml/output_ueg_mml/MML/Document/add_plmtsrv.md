# 添加受限业务配置(ADD PLMTSRV)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响业务处理，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于在配置数据库中增加受限业务的数据记录。

## 注意事项

- 添加受限业务数据后，关联该受限业务新上线用户的受限业务直接生效；关联该受限业务的已在线用户的受限业务需执行**SET PUDR**命令才生效。
- 该命令不支持配置AF方式激活的业务。

## 参数说明

| 参数ID     | 参数名称   | 参数描述                                                                                                        |
|:---------|:-------|:------------------------------------------------------------------------------------------------------------|
| LMTSRVID | 受限业务ID | 可选必选说明：必选参数 参数含义：用于标识受限业务的ID编号。 取值范围：1～255 默认值：无。 配置原则：无。                                                   |
| SRVNAME  | 业务名称   | 可选必选说明：必选参数 参数含义：用于标识受限业务的名称。 取值范围：长度不超过64的字符串 默认值：无。 配置原则：无。  说明： 受限业务的名称不区分大小写，且添加的受限业务名称不能与已存在的受限业务名称相同。 |
| STATUS   | 状态     | 可选必选说明：必选参数 参数含义：用于标识受限业务的状态。 取值说明： NORMAL（正常）FROZEN（冻结） 默认值：无。 配置原则：无。                                     |

## 使用实例

增加受限业务。“受限业务ID”为“1”，“业务名称”为“service01”，“状态”为“FROZEN(冻结)”。

```
ADD PLMTSRV: LMTSRVID=1, SRVNAME="service01", STATUS=FROZEN;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释        | 原因分析                 | 处理建议                                                                    |
|------:|:-------------|:---------------------|:------------------------------------------------------------------------|
| 57495 | 受限业务ID已经被使用。 | 输入的“受限业务ID”在系统中已经存在。 | 执行LST PLMTSRV命令查询已经存在的“受限业务ID”，然后重新执行本命令确保要添加的“受限业务ID”和已存在的“受限业务ID”不相同。 |
| 57497 | 业务名称已经被使用。   | 输入的“业务名称”在系统中已经存在。   | 执行LST PLMTSRV命令查询已经存在的“业务名称”，然后重新执行本命令确保要添加的“业务名称”和已存在的“业务名称”不相同。       |
