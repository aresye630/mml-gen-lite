# 查询策略管理服务软件参数（LST PMSINSP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询PMS系统软件参数的配置信息。

- 若需要查询全部软参数据记录的概要信息，请不要输入任何参数。
- 若需要查询某条参数数据记录的详细信息，请输入“参数名”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                            |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INSPN  | 参数名    | 可选必选说明：可选参数 参数含义：标识软件参数名称，用于指定需要对哪一类软参数据记录的参数进行查询。 取值范围： VRM_FIRSTLOGINSWITCH(机机账户初始口令检查开关)VRM_CHKPRIVATEKEYPASSWDSWITCH(检查证书私钥口令开关)VRM_CHKWEBHOSTSWITCH(UPCF WebUI Host头校验开关)VRM_UPCCPLYCAPSWITCH(UPCC全局数据容量开关) 默认值：无。 配置原则：无。 |

## 使用实例

查询机机账户初始口令检查开关软参，参数名为VRM\_FIRSTLOGINSWITCH(机机账户初始口令检查开关)。

```
LST PMSINSP: INSPN=VRM_FIRSTLOGINSWITCH;
```

```
%%LST PMSINSP: INSPN=VRM_FIRSTLOGINSWITCH;%%
RETCODE = 0    操作成功

操作结果如下:
------------
        参数名 = 机机账户初始口令检查开关
        参数值 = 1
软件参数默认值 = 1
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET PMSINSP**命令的参数说明。
