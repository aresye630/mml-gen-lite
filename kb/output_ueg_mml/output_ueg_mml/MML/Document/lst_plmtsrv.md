# 查询受限业务配置(LST PLMTSRV)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令是维护类命令，用于在配置数据库中查询受限业务配置。

- 如果需要查询全部受限业务配置，请不要输入任何参数。
- 如果需要查询某个受限业务配置，请依据参数说明输入查询条件。

## 注意事项

无。

## 参数说明

| 参数ID     | 参数名称   | 参数描述                                                                              |
|:---------|:-------|:----------------------------------------------------------------------------------|
| LMTSRVID | 受限业务ID | 可选必选说明：可选参数 参数含义：用于标识受限业务的ID编号。 取值范围：1～255 默认值：无。 配置原则：无。                         |
| SRVNAME  | 业务名称   | 可选必选说明：可选参数 参数含义：用于标识受限业务的名称。 取值范围：长度不超过64的字符串 默认值：无。 配置原则：无。  说明： 受限业务的名称不区分大小写。 |
| STATUS   | 状态     | 可选必选说明：可选参数 参数含义：用于标识受限业务的状态。 取值说明： NORMAL（正常）FROZEN（冻结） 默认值：无。 配置原则：无。           |

## 使用实例

1. 查询所有的受限业务配置。

   ```
   LST PLMTSRV:;
   ```

   ```
   %%LST PLMTSRV:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
    受限业务ID  业务名称        状态 

    1           service01       正常
    100         service0100     冻结
    200         service0200     冻结
   (结果个数 = 3)

   ---    END
   ```
2. 查询一个受限业务配置。“受限业务ID”为“1”。

   ```
   LST PLMTSRV: LMTSRVID=1;
   ```

   ```
   %%LST PLMTSRV: LMTSRVID=1;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   受限业务ID  =  1
     业务名称  =  service01
         状态  =  正常
   (结果个数 = 1)

   ---    END
   ```
