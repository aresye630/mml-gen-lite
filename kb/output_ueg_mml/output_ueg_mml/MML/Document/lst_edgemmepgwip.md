# 查询MME和PGW IP地址(LST EDGEMMEPGWIP)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于查询MME和PGW IP地址对应关系。

#### 注意事项

无

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称       | 参数说明                                                                                                                                                                                                                             |
|:-------------|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MMEIPVERSION | MME IP版本   | 可选必选说明：可选参数 参数含义：该参数用于指定配置的MME IP地址的版本。 数据来源：本端规划 取值范围： “IPV4(IPv4)”：IPv4地址“IPV6(IPv6)”：IPv6地址“IPV4V6(IPv4v6)”：IPv4v6地址 默认值：无 配置原则：根据选择的IP版本，输入相应格式的IP地址。                                                                        |
| MMEIPV4      | MME IPv4地址 | 可选必选说明：条件必选参数 参数含义：该参数用于配置MME的IPv4地址。 前提条件：该参数在“MMEIPVERSION”配置为“IPV4或IPV4V6”后生效。 数据来源：全网规划 取值范围：IPv4地址类型。 默认值：无 配置原则：业务地址不能配置为0.0.0.0、255.255.255.255和环回地址(127.x.y.z)。业务地址必须是A、B或者C类地址。该参数的掩码缺省为255.255.255.255，不可更改。           |
| MMEIPV6      | MME IPv6地址 | 可选必选说明：条件必选参数 参数含义：该参数用于配置MME的IPv6地址。 前提条件：该参数在“MMEIPVERSION”配置为“IPV6或IPV4V6”后生效。 数据来源：全网规划 取值范围：IPv6地址类型。 默认值：无 配置原则： IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址(::1)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。 |

#### 使用实例

查询一条MME和PGW IP地址对应关系，MME IP类型为IPV4，MME IPV4地址为“10.192.57.15”，执行如下命令：

```
%%LST EDGEMMEPGWIP: MMEIPVERSION=IPV4, MMEIPV4="10.192.57.15";%%
RETCODE = 0  操作成功

结果如下
------------------------
  MME IP版本  =  IPv4
MME IPV4地址  =  10.192.57.15
MME IPV6地址  =  ::
  PGW IP版本  =  IPv4
PGW IPV4地址  =  10.182.57.32
PGW IPV6地址  =  ::
        描述  =  NULL
(结果个数 = 1)

---    END
```
