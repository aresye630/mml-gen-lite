# 删除网元集合配置信息(RMV NFSET)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响会话重定向功能。需联系华为技术支持确认后再执行。

该命令用于删除一条PCF向NRF注册时携带的网元集合配置信息。

## 注意事项

删除数据时，如果指定“索引”所在组的“组名称”已在**ADD NFSRV**的“网元集合组名称”中引用，且是所在组下最后一条记录，则不允许删除。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                            |
|:--------|:-------|:----------------------------------------------------------------------------------------------------------------|
| GRPNAME | 组名称    | 可选必选说明：必选参数 参数含义：用于标识一个网元集合配置信息的关键字段之一；操作员可以使用LST NFSET命令查询获得。 取值范围：由数字、字母、“-”或“_”组成的长度不超过32的字符串 默认值：无。 配置原则：无。 |
| INDEX   | 索引     | 可选必选说明：必选参数 参数含义：用于标识一个网元集合配置信息的关键字段之一；操作员可以使用LST NFSET命令查询获得。 取值范围：1~1024 默认值：无。 配置原则：无。                       |

## 使用实例

删除一条网元集合配置信息。“组名称”为“nfset1”，“索引”为“1”。

```
RMV NFSET: GRPNAME="nfset1", INDEX=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释              | 原因分析                 | 处理建议                                                                                         |
|------:|:-------------------|:---------------------|:---------------------------------------------------------------------------------------------|
|   505 | 当前操作的配置数据不存在。      | 输入的“索引”不存在。          | 使用命令LST NFSET查询获得“索引”，确保其值已存在。                                                               |
| 58129 | NFSET对象被引用，不能删除记录。 | 该网元集合所属组名称被某一网元实例引用。 | 通过命令LST NFSRV查询引用该网元集合所属组名称的网元实例，然后执行RMV NFSRV删除网元实例对该网元集合所属组名称的引用，再次执行RMV NFSET删除该网元集合配置信息。 |
