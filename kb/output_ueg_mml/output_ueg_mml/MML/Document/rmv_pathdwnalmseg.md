# 删除单条路径断告警抑制参数的分段配置（RMV PATHDWNALMSEG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于删除指定eNodeB/gNodeB地址段内的单条路径断告警抑制的配置。

#### 注意事项

- 该命令执行后立即生效。
- 执行该删除操作，将不会产生指定eNodeB/gNodeB地址段内的单条路径断告警抑制的现象。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称                 | 参数说明                                                                                                                                                 |
|:-------------|:---------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
| V4STARTIP    | IPv4类型的eNodeB地址段起始地址 | 可选必选说明：条件必选参数 前提条件：该参数在“ENBIPVERSION”配置为“IPV4”时为必选参数。 参数含义：指定IPv4类型的eNodeB地址段的起始地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无 配置原则：无                            |
| V4ENDIP      | IPv4类型的eNodeB地址段终止地址 | 可选必选说明：条件必选参数 前提条件：该参数在“ENBIPVERSION”配置为“IPV4”时为必选参数。 参数含义：指定IPv4类型的eNodeB地址段的终止地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无 配置原则：无                            |
| V6STARTIP    | IPv6类型的eNodeB地址段起始地址 | 可选必选说明：条件必选参数 前提条件：该参数在“ENBIPVERSION”配置为“IPV6”时为必选参数。 参数含义：指定IPv6类型的eNodeB地址段的起始地址。 数据来源：本端规划 取值范围：IPv6地址类型。采用冒号分十六进制X:X:X:X:X:X:X:X格式。 默认值：无 配置原则：无 |
| V6ENDIP      | IPv6类型的eNodeB地址段终止地址 | 可选必选说明：条件必选参数 前提条件：该参数在“ENBIPVERSION”配置为“IPV6”时为必选参数。 参数含义：指定IPv6类型的eNodeB地址段的终止地址。 数据来源：本端规划 取值范围：IPv6地址类型。采用冒号分十六进制X:X:X:X:X:X:X:X格式。 默认值：无 配置原则：无 |
| ENBIPVERSION | IP地址版本               | 可选必选说明：必选参数 参数含义：该参数用于设置地址版本类型。 数据来源：本端规划 取值范围：枚举类型。 IPV4：表示地址类型为IPv4。IPV6：表示地址类型为IPv6。 默认值：无 配置原则：无                                                 |

#### 使用实例

不需要配置单条路径断告警抑制参数的分段配置时,，删除单条路径断指定eNodeB/gNodeB地址段的告警抑制参数配置：

```
RMV PATHDWNALMSEG: ENBIPVERSION=IPV4, V4STARTIP="10.1.1.1", V4ENDIP="10.1.1.1";
```
