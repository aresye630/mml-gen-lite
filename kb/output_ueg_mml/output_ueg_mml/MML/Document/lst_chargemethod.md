#### 命令功能

**适用NF：PGW-C、SMF**

此命令用来查询基于用户计费属性配置在线计费和离线计费方式。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询所有用户的在线计费和离线计费方式信息：

```
LST CHARGEMETHOD:;
```

