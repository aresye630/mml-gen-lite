# 查询服务信息（DSP SERVICEINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询PES服务信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

日常维护管理，查询PES服务信息。

```
DSP SERVICEINFO:;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项解释请参见表1

| 输出项名称   | 输出项解释                                                                                                      |
|:--------|:-----------------------------------------------------------------------------------------------------------|
| 实例号     | 用于返回服务的实例号。 取值范围：长度不超过256的字符串。                                                                             |
| 服务类型    | 用于返回服务类型，当前固定取值为“pes”。                                                                                     |
| 命名空间    | 用于返回服务的命名空间。 取值范围：长度不超过64的字符串。                                                                             |
| 虚拟机     | 用于返回服务所在的虚拟机。 取值范围：长度不超过128的字符串。                                                                           |
| 虚拟机IP   | 用于返回服务所在的虚拟机IP。 取值范围：长度不超过64的字符串。                                                                          |
| 容器名称    | 用于返回服务的容器名称。 取值范围：长度不超过128的字符串。                                                                            |
| 容器IP    | 用于返回服务的容器IP。 取值范围：长度不超过64的字符串。                                                                             |
| 容器运行时间  | 用于返回服务的容器运行时间。 运行时间小于1小时，显示格式为“mm:ss”。运行时间大于1小时且小于24小时，显示格式为“hh:mm:ss”。运行时间大于24小时，显示格式为“X-hh:mm:ss”，X代表天数。 |
| 通信实例号   | 用于返回服务的通信实例号。 取值范围：长度不超过128的字符串。                                                                           |
