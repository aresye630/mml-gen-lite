# 修改DNS NAPTR记录（MOD NGDNSN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本次修改可能会更新本主机名的其他关联记录。可通过LST NGIPV4DNSH、LST NGIPV6DNSH查询。

**适用NF：AMF、SMF**

该命令用于修改FQDN与网元接口的对应关系。

对于Proxy SGW特性，作为调测目的，可以通过添加网元类型为MME、接口类型为N26的记录来实现本地解析域名获取归属地PGW-C地址的功能。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                 |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FQDN     | FQDN   | 可选必选说明：必选参数  参数含义：该参数用于表示由RAI、TAI、APN、MME等构建的域名，用来进行网元查询。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~255。该参数只能由字母（A-Z或者a-z）、数字（0-9）、连字符（-）和点（.）组成，大小写不敏感，FQDN不能以“.”开始，也不能以“.”结束。  默认值：无  配置原则：无 |
| HSINDEX  | 主机名索引  | 可选必选说明：必选参数  参数含义：该参数用于指定主机名的索引。  数据来源：全网规划  取值范围：整数类型，取值范围是1~2048。  默认值：无  配置原则：  该参数需要先通过ADD NGIPV4DNSH或ADD NGIPV6DNSH命令完成配置。                                                      |
| ENTITY   | 网元类型   | 可选必选说明：必选参数  参数含义：该参数用于指定接口网元的类型。  数据来源：全网规划 取值范围： MME（MME）NG（5G网元）  默认值：无  配置原则：无                                                                                                   |
| INTYPE   | 接口类型   | 可选必选说明：必选参数  参数含义：该参数用来指定接口对应的类型。  数据来源：全网规划 取值范围： N26（N26）SBI（SBI）  默认值：无  配置原则：  网元类型和接口类型间存在配置约束关系如下，具体配置哪种接口需要依据组网情况而定： “MME”:“N26”。“NG”：“SBI”。                                  |
| PRIORITY | 优先级    | 可选必选说明：可选参数  参数含义：该参数用来指定接口网元对应的优先级。  数据来源：全网规划  取值范围：整数类型，取值范围是0~65535。  默认值：无  配置原则： 优先级数值配置越小，代表优先级越高。IP地址的优先级越高，则顺序越靠前。                                                          |
| WEIGHT   | 权重     | 可选必选说明：可选参数  参数含义：该参数用来指定接口网元对应的权重。  数据来源：全网规划  取值范围：整数类型，取值范围是0~65535。  默认值：无  配置原则： 权重数值配置越大，代表权重越大。对于同优先级的IP地址，进行随机选择，IP地址的权重越大，被选中的概率就越高。                                        |
| DESC     | 描述     | 可选必选说明：可选参数  参数含义：该参数用于描述该命令的文字说明，目的是在配置的时候可以将对象属性、配置原因、背景等进行描述，以便在查询时能够在大量配置数据中清晰的掌握配置的原因。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~1024。  默认值：无  配置原则：无                                     |

## 使用实例

修改FQDN为mmec22.mmegi8001.mme.epc.mnc123.mcc456.3gppnetwork.org，HSINDEX为100，网元类型MME，接口类型为N26的一条NAPTR记录，将该记录优先级修改为2，权重修改为50，描述改为“到华为的MME02”：

```
MOD NGDNSN: FQDN="mmec22.mmegi8001.mme.epc.mnc123.mcc456.3gppnetwork.org", HSINDEX=100, ENTITY=MME, INTYPE=N26, PRIORITY=2, WEIGHT=50, DESC="To huawei MME02";
```
