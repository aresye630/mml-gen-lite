# 删除S1-U IP地址黑名单记录(RMV S1UBLACKLST)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

暂不支持本命令。该命令用于删除S1-U IP地址黑名单记录。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                         |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------|
| IPTYPE | IP类型   | 可选必选说明：必选参数 参数含义：该参数用于指定IP地址类型，标识S1-U黑名单IP地址的类型。 数据来源：整网规划 取值范围：“IPV4(IPv4)”“IPV6(IPv6)” 默认值：无               |
| IPV4   | IPv4地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定需要配置的S1-U IPv4黑名单地址。 前提条件：该参数在"IP类型"参数配置为"IPV4"后生效。 数据来源：整网规划 取值范围：IPv4地址类型。 默认值：无 |
| IPV6   | IPv6地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定需要配置的S1-U IPv6黑名单地址。 前提条件：该参数在"IP类型"参数配置为"IPV6"后生效。 数据来源：整网规划 取值范围：IPv6地址类型。 默认值：无 |

#### 使用实例

删除一条S1-U黑名单记录，IP地址为10.1.1.1：

RMV S1UBLACKLST: IPTYPE=IPV4, IPV4="10.1.1.1";
