# 设置服务发现网元类型信息（SET DISCNFTYPECFG）

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致系统异常，影响业务处理，需联系华为技术支持确认后再执行。

该命令用于设置PCF到CHF/BSF/UDR/NWDAF的服务发现网元类型信息。当PCF通过指定网元类型发现远端服务时，需要配置此命令。

UPCF支持基于条件的服务发现（通过命令ADD DISCCONDCFG配置）和基于网元类型的服务发现（通过本命令配置），若同时配置系统会优先做基于条件的服务发现，而服务发现缓存清理依赖于服务发现，清理不进行服务发现的缓存信息。服务发现和服务发现缓存清理的处理逻辑详细可参见表1。

- 若系统做基于条件的服务发现，则会清理基于网元类型服务发现的缓存数据。
- 若系统做基于网元类型的服务发现，则会清理基于条件服务发现的缓存数据。
- 若系统不做服务发现，则会清理所有的服务发现缓存数据。

| CHF/BSF/UDR/NWDAF业务功能   | 条件服务发现   | 网元类型服务发现   | 服务发现处理逻辑    | 服务发现缓存清理逻辑       |
|:------------------------|:---------|:-----------|:------------|:-----------------|
| 关闭                      | 打开/关闭    | 打开/关闭      | 不做服务发现      | 清理所有的服务发现缓存      |
| 开启                      | 打开       | 打开         | 基于条件做服务发现   | 清理基于网元类型做服务发现的缓存 |
| 开启                      | 关闭       | 打开         | 基于网元类型做服务发现 | 清理基于条件做服务发现的缓存   |
| 开启                      | 打开       | 关闭         | 基于条件做服务发现   | 清理基于网元类型做服务发现的缓存 |
| 开启                      | 关闭       | 关闭         | 不做服务发现      | 清理所有的服务发现缓存      |

**说明** 

- CHF功能开启/关闭方式：
  - 业务功能通过软参“VRM\_SYSWITCH”设置。开启时设置为非“0”值，关闭时设置为“0”。
  - 条件服务发现通过ADD DISCCONDCFG命令设置。将“网元类型”设置为“CHF”，打开时“CHF参数”设置为“GPSI”，关闭时“CHF参数”不为“GPSI”或ADD DISCCONDCFG命令不存在“网元类型”设置为“CHF”的记录。
  - 网元类型服务发现通过本命令设置。将“网元类型”设置为“CHF”，打开时“开关”设置为“ON”，关闭时“开关”设置为“OFF”。
- BSF功能开启/关闭方式：
  - 业务功能通过命令SET BSFCFG设置。开启时“Switch”设置为“Support”，关闭时“Switch”设置为“Unsupport”。
  - 条件服务发现通过ADD DISCCONDCFG命令设置。将“网元类型”设置为“BSF”，打开时“BSF参数”设置为“IPV4ADDR”，“IPV4DNN”，“IPV4IPDOMAIN”或“IPV6PREFIX”，关闭时“BSF参数”不为“IPV4ADDR”，“IPV4DNN”，“IPV4IPDOMAIN”或“IPV6PREFIX”，或ADD DISCCONDCFG命令不存在“网元类型”设置为“BSF”的记录。
  - 网元类型服务发现通过本命令设置。将“网元类型”设置为“BSF”，打开时“开关”设置为“ON”，关闭时“开关”设置为“OFF”。
- UDR功能开启/关闭方式：
  - 业务功能通过软参“VRM\_N36INTERFACESW”设置。开启时设置为“1”，关闭时设置为“0”。
  - 当前版本只支持按网元类型服务发现UDR，暂不支持条件服务发现UDR。
  - 网元类型服务发现通过本命令设置。将“网元类型”设置为“UDR”，打开时“开关”设置为“ON”，关闭时“开关”设置为“OFF”。
- NWDAF功能开启/关闭方式：
  - 业务功能通过软参“VRM\_N23SWITCH”设置。开启时设置为“1”，关闭时设置为“0”。
  - 条件服务发现通过ADD DISCCONDCFG命令设置。将“网元类型”设置为“NWDAF”，打开时“NWDAF参数”设置为“TAI”或“EVENT”，关闭时“NWDAF参数”不为“TAI”或“EVENT”，或ADD DISCCONDCFG命令不存在“网元类型”设置为“NWDAF”的记录。
  - 网元类型服务发现通过本命令设置。将“网元类型”设置为“NWDAF”，打开时“开关”设置为“ON”，关闭时“开关”设置为“OFF”。

## 注意事项

该命令存在系统初始记录，参数的初始设置值如表2。

| 网元类型   | 开关   |
|:-------|:-----|
| CHF    | ON   |
| BSF    | ON   |
| UDR    | OFF  |
| NWDAF  | OFF  |

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                 |
|:-------|:-------|:-------------------------------------------------------------------------------------|
| NFTYPE | 网元类型   | 可选必选说明：必选参数 参数含义：用于标识网元类型。 取值范围： CHF(CHF)BSF(BSF)UDR(UDR)NWDAF(NWDAF) 默认值：无。 配置原则：无。 |
| SWITCH | 开关     | 可选必选说明：必选参数 参数含义：用于设置服务发现网元类型的开关。 取值范围： ON(打开)OFF(关闭) 默认值：无。 配置原则：无。                 |

## 使用实例

设置服务发现网元类型信息。“网元类型”为“CHF”，“开关”为“ON”：

```
SET DISCNFTYPECFG: NFTYPE=CHF, SWITCH=ON;
```
