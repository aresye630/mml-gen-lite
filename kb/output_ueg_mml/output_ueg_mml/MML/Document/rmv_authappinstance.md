# 删除APP实例授权（RMV AUTHAPPINSTANCE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

**须知** 

本命令属于高危命令，删除APP实例授权信息会导致MEP平台为本APP实例所属的APPID所签发的token失效，其需要使用该APPID的APP重新申请token才能继续访问，请谨慎删除。

该命令用于删除APP实例和APPID的绑定关系，删除该绑定关系后，则该APP实例无法访问为该APPID所添加的授权服务列表中的服务。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                |
|:--------------|:--------|:----------------------------------------------------------------------------------------------------|
| APPINSTANCEID | APP实例ID | 可选必选说明：必选参数 参数含义：该参数用于指定APP实例标识。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“_”组成。 默认值：无 配置原则：无 |

#### 使用实例

删除APP实例授权信息，APP实例ID为"appInstance1"：

```
RMV AUTHAPPINSTANCE: APPINSTANCEID="appInstance1";
```
