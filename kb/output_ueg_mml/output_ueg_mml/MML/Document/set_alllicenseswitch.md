# 设置所有License项的开关（SET ALLLICENSESWITCH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

**须知** 

本命令属于高危命令，本命令用于统一设置所有license项的开关，执行不当会影响业务，执行前确保符合需要。

该命令用于设置所有可用的License项。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令不支持导出，执行后立即生效。请使用LST LICENSESWITCH命令查询执行效果。
- 使用此命令后，可能会出现LST LICENSESWITCH命令显示“没有查到相应结果”，10分钟左右后可恢复正常显示。
- 请勿频繁操作该命令，建议两次执行该命令之间至少间隔10分钟。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称         | 参数说明                                                                                                                                        |
|:-------|:-------------|:--------------------------------------------------------------------------------------------------------------------------------------------|
| SWITCH | License项统一开关 | 可选必选说明：必选参数 参数含义：该参数用于使能/去使能所有可用License项。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则： ENABLE为开启所有License项。DISABLE为关闭所有License项。 |

#### 使用实例

客户首次安装，为了正确运行业务，激活所有可用的License项：

```
SET ALLLICENSESWITCH:SWITCH=ENABLE;
```
