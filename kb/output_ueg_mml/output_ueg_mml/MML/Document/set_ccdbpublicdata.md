# 设置CCDB公共配置数据（SET CCDBPUBLICDATA）

## 命令功能

**须知** 

该命令属于高危命令。该操作执行后会修改系统的DUS数量配置，如和实际不符会影响DUS和CUS的启动，请谨慎操作，操作前请务必联系华为技术支持确认。

该命令用于修改CCDB公共配置表数据值。

## 注意事项

- 只有ADMINISTRATOR权限级别或被赋予该命令执行权限的用户可执行该命令。
- 对于公共配置项，系统初始会赋予对应配置项取值。请务必确认需要修改配置项取值再执行该命令。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                    |
|:-------|:-------|:------------------------------------------------------------------------|
| ID     | 配置项ID  | 可选必选说明：必选参数 参数含义：用于指定系统中需要修改的公共配置项。 取值范围：0~4294967295 默认值：无。 配置原则：无。    |
| CFGVAL | 配置项取值  | 可选必选说明：必选参数 参数含义：用于指定系统中需要修改后的公共配置项取值。 取值范围：0~4294967295 默认值：无。 配置原则：无。 |

## 使用实例

修改DUS的配置数量配置。

```
SET CCDBPUBLICDATA: ID=0, CFGVAL=8;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
