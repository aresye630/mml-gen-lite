# 修改基于跟踪区的MME相对权重配置(MOD MMECAPBYTA)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

此命令用于修改指定跟踪区下，本MME在MME Pool区内的相对权重值。

#### 注意事项

- 此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                          |
|:-------|:-------|:----------------------------------------------------------------------------------------------|
| MCC    | 移动国家码  | 可选必选说明：必选参数 参数含义：该参数用于指定移动国家代码。 数据来源：整网规划 取值范围：3位的十进制数字 默认值：无                                 |
| MNC    | 移动网号   | 可选必选说明：必选参数 参数含义：该参数用于指定移动网号。 数据来源：整网规划 取值范围：2～3位的十进制数字 默认值：无                                 |
| TAC    | 跟踪区域码  | 可选必选说明：必选参数 参数含义：该参数用于指定跟踪区域码。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无                             |
| CAP    | 相对权重   | 可选必选说明：可选参数 参数含义：该参数用于指定此跟踪区下，MME负荷能力在MME Pool区中的相对权重值。 数据来源：整网规划 取值范围：整数类型，取值范围为0~255。 默认值：无 |

#### 使用实例

修改跟踪区123030200的相对权重为100：

MOD MMECAPBYTA: MCC="123", MNC="03", TAC="0x200", CAP=100;
