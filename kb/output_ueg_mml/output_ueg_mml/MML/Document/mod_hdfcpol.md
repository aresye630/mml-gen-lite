# 修改手动流控策略(MOD HDFCPOL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在配置数据库中修改一条手动流控策略数据记录。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                                                                                                                                                                                                |
|:-------------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ID           | 手动流控策略ID | 可选必选说明：必选参数 标识一条手动流控策略数据记录的关键字段（其取值不能被修改），用于指定需要对哪一条手动流控策略记录进行修改，操作员可以使用LST HDFCPOL命令查询获得。 默认值：无。                                                                                                                                                                   |
| FCSWITCH     | 流控开关     | 可选必选说明：可选参数 用于标识流控功能状态为关闭或开启。 取值范围： OFF(OFF) ON(ON) 默认值：无。                                                                                                                                                                                                          |
| MSGTYPE      | 流控消息类型   | 可选必选说明：可选参数 用于标识系统需要对哪种类型的消息进行流控。 取值范围： HTTP(HTTP) SOAP(SOAP-TLS) 默认值：无。                                                                                                                                                                                            |
| FCMODE       | 手动流控模式   | 可选必选说明：可选参数 用于标识手动流控的模式。 取值范围：ALL(整体流控)：对指定的某一种类型的所有消息进行流控。 HTTPLINKIDMODE(HTTP链路名称)：根据HTTP链路名称进行消息流控。仅当“流控消息类型”参数取值为“HTTP(HTTP)”时，该枚举值有效。 SOAPPEID(SOAP对端ID)：根据局向（SOAP对端和SOAP对端地址段）进行流控。仅当“流控消息类型”参数取值为“SOAP(SOAP-TLS)”时，该枚举值有效。 默认值：无。                            |
| HTTPLSERNAME | 本端服务器名称  | 可选必选说明：条件必选参数 仅当本命令的“手动流控模式”参数为“HTTPLINKIDMODE(HTTP链路名称)”时该参数有效。用于标识一个本端HTTP服务端的名称。该参数必须先由ADD HTTPLSERVER命令定义才能在此处引用。 取值范围：长度不超过128的由数字和字母组成的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 说明：该参数取值不能与已有的流控策略中配置的“本端服务器名称”重复。                                                |
| SOAPPEID     | SOAP对端ID | 可选必选说明：条件必选参数 仅当本命令的“手动流控模式”参数为“SOAPPEID(SOAP对端ID)”时该参数有效。用于标识SOAP对端ID号。该参数必须先由ADD SOAPPE命令定义才能在此处引用。 取值范围：1～255 默认值：无。                                                                                                                                             |
| MAXPROCNUM   | 最大处理能力   | 可选必选说明：可选参数 用于标识周期时间（1秒）内单个HTTP进程允许处理业务的最大数量。若周期时间内，HTTP进程处理的业务数超过该参数的值，且流控功能开启时，UIM会对指定类型的消息数进行流控，根据系统内部的流控算法丢弃部分消息，降低HTTP进程的业务处理数量。 取值范围：0～65535 默认值：无。 说明： 对于GBA业务，该参数值对应HTTP进程上，Ut接口TCP建链的次数；消息类型为SOAP时，该参数值对应HTTP进程上，Zn接口收到SOAP-BIR消息的次数。该参数取值为“0”时，表示不启动手动流控。 |

## 使用实例

修改一条流控策略记录，携带以下参数：

- “手动流控策略ID”为“1”
- “流控消息类型”为“HTTP”
- “手动流控模式”为“HTTPLINKIDMODE”
- “本端服务器名称”为"LSERVER1"
- “最大处理能力”为“50000”

```
MOD HDFCPOL: ID=1, MSGTYPE=HTTP, FCMODE=HTTPLINKIDMODE, HTTPLSERNAME="LSERVER1", MAXPROCNUM=50000;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释         | 原因分析                                | 处理建议                                                 |
|-------:|:--------------|:------------------------------------|:-----------------------------------------------------|
| 360251 | SOAP对端ID不存在。  | 输入的“SOAP对端标识”参数值没有在ADD SOAPPE命令中定义。 | 执行LST SOAPPE命令查询已存在的“SOAP对端标识”，重新输入该参数后执行本命令添加。      |
| 360252 | SOAP对端ID不能重复。 | 输入的“SOAP对端标识”参数值已配置了手动流控策略。         | 执行LST HDFCPOL命令查询已配置的“SOAP对端标识”，重新输入未配置的该参数后执行本命令添加。 |
