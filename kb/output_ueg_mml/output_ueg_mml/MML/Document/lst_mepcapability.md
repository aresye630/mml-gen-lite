# 查询MEP能力信息（LST MEPCAPABILITY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF、MPF**

该命令用于查询是否支持MEP能力。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询当前网元是否支持MEP能力：

```
LST MEPCAPABILITY:;
```

```
RETCODE = 0  操作成功

MEP能力信息
-----------
支持MEP功能  =  是
(结果个数 = 1)

---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释          |
|:--------|:---------------|
| 支持MEP功能 | 用于显示是否支持MEP功能。 |
