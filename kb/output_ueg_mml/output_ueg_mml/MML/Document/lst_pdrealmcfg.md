## 命令功能

该命令用于查询PCRF目的域名配置信息：

- 若需要查询所有已配置的目的域名配置信息，不用输入任何参数。
- 若需要符合指定条件的目的域名配置信息，则在对应参数下输入对应取值即可。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称     | 参数描述                                                                                                                                                        |
|:--------------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PCRFID        | PCRF标识   | 用于指示系统需要按照哪个PCRF标识查询TDF域名配置数据；若不输入，则表示该参数不作为系统查询的筛选条件。 取值范围：1 默认值：无。                                                                                        |
| REALMID       | 目的域名ID   | 用于指示系统需要按照哪个目的域名ID查询TDF域名配置数据；若不输入，则表示该参数不作为系统查询的筛选条件。 取值范围：0～511 默认值：无。                                                                                    |
| APPTYPE       | 目的域应用类型  | 用于指示系统需要按照哪个应用类型查询TDF域名配置数据；若不输入，则表示该参数不作为系统查询的筛选条件。 取值范围：TDF（TDF）：当使用的TDF种类都不同时，应用类型可以配置为“TDF”，此时必须要输入目的域名。DefaultTDF（DefaultTDF）：TDF都是一类，不用配置目的域名。 默认值：无。 |
| DEN           | 对端名称     | 用于指示系统需要按照哪个对端名称查询TDF域名配置数据；若不输入，则表示该参数不作为系统查询的筛选条件。 取值范围：长度不超过128的字符串 默认值：无。                                                                               |
| DRN           | 目的域名     | 用于指示系统需要按照哪个目的域名查询TDF域名配置数据；若不输入，则表示该参数不作为系统查询的筛选条件。 取值范围：长度不超过64的字符串 默认值：无。                                                                                |
| ABILITYDICTID | 能力字典ID   | 用于指示系统需要按照哪个能力字典ID查询TDF域名配置数据；若不输入，则表示该参数不作为系统查询的筛选条件。 取值范围：0～127 默认值：无。                                                                                    |
| PCEFCAT       | 对端PCEF类别 | 用于指示系统需要按照哪个对端PCEF类别查询TDF域名配置数据；若不输入，则表示该参数不作为系统查询的筛选条件。 取值范围：长度不超过16字节的字符串 默认值：无。                                                                          |

## 使用实例

- 查询所有的TDF域名配置数据：

  ```
  %%LST PDREALMCFG:;%%
  RETCODE = 0  操作成功

  操作结果如下:
  ------------------------
   PCRF标识  目的域名ID  目的域应用类型          对端名称                  目的域名                能力字典ID               对端PCEF类别

   1         0           TDF                     NULL                      tdf.huawei.com          68                       MPCEF01           
   1         1           DefaultTDF              NULL                      NULL                    67                       NULL              
   1         50          TDF                     NULL                      Huawei_01               60                       NULL              
  (结果个数 = 3)

  ---    END
  ```

- 查询“目的域应用类型”为“TDF（TDF）”的目的域名配置记录：

  ```
  %%LST PDREALMCFG: APPTYPE=TDF;%%
  RETCODE = 0  操作成功

  操作结果如下:
  ------------------------
   PCRF标识  目的域名ID  目的域应用类型           对端名称                  目的域名                能力字典ID               对端PCEF类别

   1         0           TDF                     NULL                      tdf.huawei.com          68                       MPCEF01           
   1         50          TDF                     NULL                      Huawei_01               60                       NULL              
  (结果个数 = 2)

  ---    END
  ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD PDREALMCFG**命令的参数说明。
