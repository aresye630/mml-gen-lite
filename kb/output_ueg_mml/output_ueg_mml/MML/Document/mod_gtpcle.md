# 修改GTP-C本地实体(MOD GTPCLE)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME、AMF**

本命令用于修改已存在的GTPC本端实体的描述信息。

#### 注意事项

- 本命令执行后立即生效。
- 同一个IP地址不能配置不同的VPN名称。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称        | 参数说明                                                                                                                                                                            |
|:--------|:------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MODTYPE | 修改类型        | 可选必选说明：必选参数 参数含义：本参数用于指定修改GTPC本端实体的操作类型。 数据来源：本端规划 取值范围：“BYINDEX(根据记录索引)”“BYIP(根据IP地址)” 默认值：无                                                                                   |
| LEINDEX | GTP-C本端实体标识 | 可选必选说明：条件必选参数 参数含义：本参数用于指定GTPC本端实体的记录索引。 前提条件：该参数在“修改类型”参数配置为“BYINDEX(根据记录索引)”后生效。 数据来源：本端规划 取值范围：0~255 默认值：无  说明： 使用LST GTPCLE查询记录的索引。                                         |
| GROUPID | 组号          | 可选必选说明：条件必选参数 参数含义：本参数用于指定GTPC本端实体对应的组号。组号用于组网规划时不同接口，或者不同用户范围使用独立的GTPC本端实体。 前提条件：该参数在“修改类型”参数配置为“BYIP(根据IP地址)”后生效。 数据来源：本端规划 取值范围：0~32 默认值：无  说明： 组号的应用参考ADD GTPCINTFATTR命令帮助。 |
| IPTYPE  | IP地址类型      | 可选必选说明：条件必选参数 参数含义：本参数用于指定GTPC本端实体的IP地址类型。 前提条件：该参数在“修改类型”参数配置为“BYIP(根据IP地址)”后生效。 数据来源：本端规划 取值范围： “TPTADDR_TYPE_IPV4(IPv4)”“TPTADDR_TYPE_IPV6(IPv6)” 默认值：无                      |
| LEIPV4  | IPv4地址      | 可选必选说明：条件必选参数 参数含义：本参数用于指定GTPC本端实体的IPv4地址。 前提条件：该参数在“IP地址类型”参数配置为“TPTADDR_TYPE_IPV4(IPv4)”后生效。 数据来源：本端规划 取值范围：0.0.0.0~255.255.255.255 默认值：无                                     |
| LEIPV6  | IPv6地址      | 可选必选说明：条件必选参数 参数含义：本参数用于指定GTPC本端实体的IPv6地址。 前提条件：该参数在“IP地址类型”参数配置为“TPTADDR_TYPE_IPV6(IPv6)”后生效。 数据来源：本端规划 取值范围：::~FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无                  |
| VPNNAME | VPN名称       | 可选必选说明：可选参数 参数含义：本参数用于指定新的VPN名称。 数据来源：本端规划 取值范围：0~31位字符串 默认值：无 配置原则：支持输入的字符为字母、数字、下划线。vpn名称区分英文字母的大小写。当输入字符为空时，表示vpn名称不修改。                                                      |
| DESC    | 描述信息        | 可选必选说明：可选参数 参数含义：本参数用于指定新的描述信息。新的描述信息将会覆盖原描述信息。 数据来源：本端规划 取值范围：0~32位字符串 默认值：无                                                                                                   |

#### 使用实例

修改索引为1的GTPC本地实体的描述信息：

MOD GTPCLE: MODTYPE=BYINDEX, LEINDEX=1, DESC="private";
