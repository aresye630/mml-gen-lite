# 删除位置区域地址分配用户白名单（RMV SMFADDRLOCWL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于删除按照区域地址分配用户白名单。

## 注意事项

该命令执行后只对新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                     |
|:-------|:-------|:-----------------------------------------------------------------------------------------|
| MSISDN | MSISDN | 可选必选说明：必选参数  参数含义：该参数用于指定用户的MSISDN信息。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~15。  默认值：无  配置原则：无 |

## 使用实例

删除用户MSISDN为123456的区域地址分配白名单：

```
RMV SMFADDRLOCWL: MSISDN="123456";
```
