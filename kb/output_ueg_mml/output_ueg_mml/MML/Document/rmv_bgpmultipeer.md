# 删除BGP多源对等体（RMV BGPMULTIPEER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除BGP多源对等体。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                           |
|:-------------|:--------|:---------------------------------------------------------------------------------------------------------------|
| VRFNAME      | VPN实例名称 | 可选必选说明：可选参数 参数含义：该参数用于指定VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：_public_ 配置原则：使用LST L3VPNINST命令查看可用VPN。 |
| PEERADDR     | 对等体地址   | 可选必选说明：必选参数 参数含义：该参数用于指定建立对等体的接口地址。 数据来源：对端协商 取值范围：IPv4地址类型。 默认值：无                                             |
| SOURCEIFNAME | 源接口名称   | 可选必选说明：必选参数 参数含义：该参数用于指定建立对等体的源接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：仅支持Ethernet及其子接口类型，不区分大小写。   |

#### 使用实例

删除BGP多源对等体：

```
RMV BGPMULTIPEER:VRFNAME="vrf1",PEERADDR="10.2.2.2",SOURCEIFNAME="Ethernet66/0/3";
```
