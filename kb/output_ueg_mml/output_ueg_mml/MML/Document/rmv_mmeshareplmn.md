# 删除MME的共享PLMN（RMV MMESHAREPLMN）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于删除一条MME的共享PLMN记录。

#### 注意事项

- 该命令执行后立即生效。
- 系统支持的PLMN变少。
- 删除后该PLMN网络下的用户会附着，路由更新，网络切换失败。
- 如果待删除记录被**ADD SHAREPLMNMEM**配置引用，则不能删除。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                               |
|:-------|:-------|:-------------------------------------------------------------------|
| MCC    | 移动国家码  | 可选必选说明：必选参数 参数含义：该参数用于指定由ITU-T统一分配的移动网络所在国家的标识符。 取值范围：3位十进制数 默认值：无 |
| MNC    | 移动网号   | 可选必选说明：必选参数 参数含义：该参数用于指定一个国家内的PLMN标识符。 取值范围：位数为2或3的十进制数 默认值：无      |

#### 使用实例

删除一个“移动国家码”为“123”、“移动网号”为“01” 的MME的共享PLMN：

RMV MMESHAREPLMN: MCC="123", MNC="01";
