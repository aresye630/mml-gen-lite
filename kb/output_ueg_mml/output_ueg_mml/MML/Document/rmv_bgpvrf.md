# 删除BGP VPN实例（RMV BGPVRF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来删除已创建的BGP VPN实例。

**须知** 

本命令属于高危命令，该操作会删除BGP所有该VPN实例下的关联配置。

#### 注意事项

- 该命令执行后立即生效。
- 该命令会删除BGP所有该VPN实例下的关联配置。
- 删除BGP VPN实例会同时删除该VPN实例下的配置内容和业务。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                   |
|:--------|:--------|:-------------------------------------------------------------------------------------------------------|
| VRFNAME | VPN实例名称 | 可选必选说明：必选参数 参数含义：该参数用于指定BGP VPN实例。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：使用LST BGPVRF命令查看可用VPN。 |

#### 使用实例

删除名称为“vrf1”的BGP VPN实例：

```
RMV BGPVRF:VRFNAME="vrf1";
```
