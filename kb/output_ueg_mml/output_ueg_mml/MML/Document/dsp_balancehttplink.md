# 查询均衡HTTP链路信息(DSP BALANCEHTTPLINK)

- 输出结果说明

## 命令功能

该命令用于查询HLB的链路均衡信息。

DCS在每日凌晨02时08分定时均衡服务端链路，或执行**STR BALANCEHTTPLINK**命令后广播查询HLB相关负载信息，HLB在响应消息中上报24小时内的“平均CPU”、“实例平均 TPS”、“平均链路数” ，DCS接收到所有HLB响应或等待10秒超时后，对满足以下两个条件的HLB发送链路均衡请求：

- 该HLB的“平均CPU”大于由**MOD UDMSOFTPARA**命令设置的“服务端链路均衡CPU门限”
- 该HLB的“与所有实例平均CPU比例”达到由**MOD UDMSOFTPARA**命令设置的“服务端链路均衡CPU比例”

HLB收到请求后， 根据链路的消息数峰值从大到小排序，对消息数大的链路进行删除操作，删除链路的比例为**MOD UDMSOFTPARA**命令设置的“服务端链路均衡百分比”。

当使用该命令查询时会查询到DCS记录的最近一次链路均衡操作和HLB上报的信息，DCS不对该数据进行持久化处理，当DCS服务重启后，收集到的信息丢失，此时执行该命令时，输出项中的“执行均衡操作时间”取值将为“NULL”

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                 |
|:-------|:-------|:-------------------------------------------------------------------------------------|
| TYPE   | 链路类型   | 可选必选说明：必选参数 参数含义：用于指定进行查询均衡操作信息的链路类型。 取值范围：SERVER(SERVER) 默认值：SERVER(SERVER) 配置原则：无。 |

## 使用实例

查询服务端链路的均衡操作信息。

```
DSP BALANCEHTTPLINK: TYPE=SERVER;
```

```
%%DSP BALANCEHTTPLINK: TYPE=SERVER;%%
RETCODE = 0  操作成功

操作结果如下:
-------------

```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，输出项如表1所示。

| 输出项名称        | 输出项解释                                     |
|:-------------|:------------------------------------------|
| HLB实例ID      | 用于显示HLB的实例ID。                             |
| 执行均衡操作时间     | 用于显示最近一次执行均衡操作时间。                         |
| 删除链路个数       | 用于显示执行均衡操作而删除的链路个数。                       |
| 平均CPU        | 用于显示HLB的平均CPU使用率。                         |
| 与所有实例平均CPU比例 | 用于显示该HLB的平均CPU使用率与所有实例的平均CPU使用率的比例。       |
| 实例平均TPS      | 用于显示HLB实例的平均TPS（Transactions Per Second）。 |
| 平均链路数        | 用于显示每日凌晨02时08分到当前查询时间点的HLB的平均链路数。         |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释           | 原因分析                        | 处理建议                                            |
|-------:|:----------------|:----------------------------|:------------------------------------------------|
| 360131 | 查询服务类型实例不存在     | 当前查询的HLB服务不存在服务实例。          | 联系华为技术支持，检查HLB服务状态是否正常。                         |
| 360176 | 正在执行链路均衡中，请稍后再试 | 链路均衡操作未结束，系统正在处理中。          | 需要等待均衡操作结束后才可以执行命令。                             |
| 360177 | 校验未执行           | DCS没有进行过任何校验，DCS未收集到HLB的数据。 | 请执行STR BALANCEHTTPLINK命令后，或在次日凌晨02时20分后再次执行该命令。 |
