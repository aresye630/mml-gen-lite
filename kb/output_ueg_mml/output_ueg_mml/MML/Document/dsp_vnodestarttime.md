# 显示虚拟节点启动时间信息（DSP VNODESTARTTIME）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示虚拟节点启动时间信息，包括Guest OS启动时间点，Guest OS启动完成时间点，软件启动时间点，软件启动完成时间点。

当发现系统缓慢时，可在系统启动之后查看各阶段用了多少时间。

**说明** 

该命令仅在虚机场景下支持。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                               |
|:----------|:-------|:---------------------------------------------------------------------------------------------------|
| VNODENAME | 虚拟节点名称 | 可选必选说明：可选参数 参数含义：该参数用于指定虚拟节点名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无                            |
| VNFCNAME  | VNFC名称 | 可选必选说明：可选参数 参数含义：该参数用于指定VNFC实例名称。请使用LST VNFC命令查询存在的VNFC名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 |

#### 使用实例

显示名所有虚拟节点的启动时间信息：

```
DSP VNODESTARTTIME:;
```
