# 删除PLMN-CG配置参数(RMV CHGPLMNCG)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

执行后影响新激活用户。

**适用网元：SGSN**

该命令用于删除为PLMN配置的CG IP地址。如果没有为某个PLMN配置CG IP地址，SGSN会将该PLMN的话单发给其他链路正常的CG，并优先选择CG配置表中“PLMNFLG”属性为“NO”的CG。请参见**ADD CHGCG**命令说明。

#### 注意事项

- 该命令执行后立即生效。 执行后影响新激活用户。
- 删除PLMN-CG配置参数后，请检查相关CG的配置是否需要删除。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                        |
|:-------|:-------|:------------------------------------------------------------|
| MCC    | 移动国家码  | 可选必选说明：必选参数 参数含义：该参数用于表示PLMN的移动国家号码。 取值范围：位数为3的十进制数字 默认值：无  |
| MNC    | 移动网号   | 可选必选说明：必选参数 参数含义：该参数用于表示PLMN的移动网号码。 取值范围：位数为2或3的十进制数字 默认值：无 |

#### 使用实例

删除PLMN为123001的优先发送话单的CG IP地址：

RMV CHGPLMNCG: MCC="123", MNC="001";
