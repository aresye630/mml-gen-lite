# 增加5G区域时区参数（ADD NGAREATZ）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

此命令用于增加5G区域时区记录。即增加特定区域与时区标识的映射关系。该时区标识对应的时区和夏令时信息通过ADD NGTZLST命令配置。

## 注意事项

- 该命令执行后只对新激活用户生效。

- MCC/MNC相同的情况下，不同记录的TAC不允许重叠。

- 最多可输入1024条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                                                                  |
|:-------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MCC    | MCC      | 可选必选说明：必选参数  参数含义：该参数用于指定移动国家代码。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。3位的十进制数字。  默认值：无  配置原则：无                                                                                               |
| MNC    | MNC      | 可选必选说明：必选参数  参数含义：该参数用于指定移动网号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。2～3位的十进制数字。  默认值：无  配置原则：无                                                                                           |
| BGNTAC | 跟踪区编码起始值 | 可选必选说明：必选参数  参数含义：该参数用于表示跟踪区编码的起始值。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。字符串类型，输入长度是6。TAC编码为16进制数，按照字符串格式输入，字符串长度为6，只能由数字（0-9），字母（A-F、a-f）组成。字母大小写不敏感。  默认值：无  配置原则：无                        |
| ENDTAC | 跟踪区编码结束值 | 可选必选说明：可选参数  参数含义：该参数用于表示跟踪区编码的结束值。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。字符串类型，输入长度是6。TAC编码为16进制数，按照字符串格式输入，字符串长度为6，只能由数字（0-9），字母（A-F、a-f）组成。字母大小写不敏感。ENDTAC若不下发，则赋值为BGNTAC值。  默认值：无  配置原则：无 |
| TZID   | 时区标识     | 可选必选说明：必选参数  参数含义：该参数用于指定该区域的时区标识。  数据来源：本端规划  取值范围：整数类型，取值范围是1~24。该参数需要从ADD NGTZLST命令中已配置的TZID参数中取值。  默认值：无  配置原则：无                                                                  |

## 使用实例

增加一条5G区域时区记录，“移动国家代码”为“460”，“移动网号”为“03”，“跟踪区编码起始值”为“000112”，“跟踪区编码结束值”为“000350”，“时区标识”为“1”，执行如下命令：

```
ADD NGAREATZ: MCC="460", MNC="03", BGNTAC="000112", ENDTAC="000350", TZID=1;
```
