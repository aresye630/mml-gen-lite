# 增加PGW重定向配置(ADD PGWRNSI)

#### 命令功能

**适用网元：SGSN、MME**

该命令用于MME在选择网关时开启PGW重定向功能，当用户在4G切换到5G场景下，需要保证业务连续性时开启该功能。

#### 注意事项

- 本表最大记录数为256条。
- 本功能会影响已有的网关规划，可能导致用户使用非配置或签约指定的其他网关。
- 本功能开启后，无法保证P-GW和S-GW合一。
- 本功能需要PGW支持并开启PGW重定向功能才能生效。
- 当该命令配置了多条记录时，系统按“SUBRANGE（用户范围）”的优先级的匹配记录，如果匹配不到，再匹配低优先级的记录。“SUBRANGE（用户范围）”的优先级从高到低为：“IMSI\_PREFIX（指定IMSI前缀）”，“FOREIGN\_USER（外网用户）”或“HOME\_USER（本网用户）”，“ALL\_USER（所有用户）”。

#### 本地用户权限

manage-ug；system-ug；

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；

#### 参数说明

| 参数标识      | 参数名称                      | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
|:----------|:--------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE  | 用户范围                      | 可选必选说明：必选参数 参数含义：该参数用于指定支持PGW重定向的用户范围。 数据来源：整网规划 取值范围： “IMSI_PREFIX(指定IMSI前缀)”:指网络中与指定的IMSI前缀匹配的用户。“HOME_USER(本网用户)”:指网络中的本网签约用户。“FOREIGN_USER(外网用户)”:指网络中的漫游用户。“ALL_USER(所有用户)”：指网络中的所有用户。默认值：无                                                                                                                                                                                                                                                                                    |
| NOID      | 运营商标识                     | 可选必选说明：条件必选参数 参数含义：该参数用于指定运营商标识。 前提条件：该参数在"用户范围"参数配置为"本网用户"或"外网用户"后生效。 数据来源：整网规划 取值范围：整数类型，取值范围为0~64,128~254。 默认值：无 配置原则： 当用户为MNO用户时，该参数需要配置为0或128～254之间的值，该取值必须和ADD MNO中配置的“MNOID”参数取值相同。当用户为MVNO用户时，该参数需要配置为1～64之间的值，该取值必须和ADD MVNO中配置的“MVNOID”参数取值相同。对于外网用户，该参数是与其归属运营商签订可漫游协议，为其提供服务的MNO/MVNO运营商标识。对于本网用户，该参数是该用户归属的MNO/MVNO运营商标识。                                                                                                                                              |
| IMSIPRE   | IMSI前缀                    | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI前缀以区分不同的用户群。 前提条件：该参数在“用户范围”参数配置为“IMSI_PREFIX(指定IMSI前缀)”后生效。 数据来源：整网规划 取值范围：1～15位十进制数字字符串 默认值：无  说明： 当该参数配置生效时，按照IMSI最长匹配进行查询，如果匹配到记录，使用该记录的配置；如果没有匹配的记录，则查找IMSI次长匹配的记录。                                                                                                                                                                                                                                                                              |
| APNNI     | APNNI                     | 可选必选说明：必选参数 参数含义：该参数用于指定APNNI。 数据来源：整网规划 取值范围：1～62位字符串 默认值：无 配置原则：该APNNI需要与打开PGW重定向功能的用户携带的APNNI一致。 说明： 紧急呼叫的APN不建议配置PGWRNSI功能，如果端到端规划不合理，可能导致紧急呼叫失败。                                                                                                                                                                                                                                                                                                                               |
| PGWRNSISW | 是否开启PGWRNSI               | 可选必选说明：可选参数 参数含义：该参数用于控制是否开启PGW重定向(PGWRNSI，PGW Redirection due to mismatch with Network Slice subscribed by UE Support Indication)功能。 数据来源：整网规划 取值范围： “YES(是)”：表示功能开启。“NO(否)”：表示功能禁止。 默认值：NO（否）  说明： 参数设置为“YES（是）”时，发送给S-GW的Create Session Request消息的“Indication Flags”信元中“PGWRNSI”比特设置为1，表示MME支持接收原因为“PGW redirection due to mismatch with network slice subscribed by the UE”的响应，并能通过Create Session Response消息中“Alternative PGW-C/SMF”信元信息重新选择PGW发送Create Session Request创建PDN连接。 |
| PGWRPLCY  | PGW-C/SMF同时携带FQDN和IP时处理策略 | 可选必选说明：条件可选参数 参数含义：控制开启PGWRNSI功能后，PGW-C/SMF返回Create Session Response消息中同时携带“Alternative PGW-C/SMF FQDN”和“ Alternative PGW-C/SMF IP”信元时的处理策略。 前提条件：该参数在“是否开启PGWRNSI”配置为“YES(是)”后生效。 数据来源：整网规划 取值范围： “REJECT(REJECT)”：表示响应按失败处理，拒绝会话创建。“FQDN(FQDN)”：表示选取FQDN。“IP(IP)”：表示选取IP。 默认值：REJECT(REJECT)  说明： 29274(i30)协议定义“Alternative PGW-C/SMF FQDN”和“Alternative PGW-C/SMF IP”信元只能二选一携带，为了兼容老版本协议同时携带的场景，以及避免用户持续上线失败，提供兼容性处理。                                                           |

#### 使用实例

增加SUBRANGE为ALL\_USER，APNNI为HUAWEI.COM，PGWRNSISW为NO的PGW重定向配置记录：

```
ADD PGWRNSI: SUBRANGE=ALL_USER, APNNI="HUAWEI.COM", PGWRNSISW=NO;
```
