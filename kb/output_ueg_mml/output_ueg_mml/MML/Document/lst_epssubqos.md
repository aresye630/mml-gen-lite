# 查询EPS签约QoS配置（LST EPSSUBQOS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C**

该命令用来查询用户的签约QoS属性。

## 注意事项

当不输入参数时，系统查询所有配置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                             |
|:------------|:--------|:---------------------------------------------------------------------------------|
| SUBQOSINDEX | 用户QoS索引 | 可选必选说明：可选参数  参数含义：该参数表示用户QoS索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无 |

## 使用实例

- 查询“SUBQOSINDEX”为“123”的记录：

  ```
  %%LST EPSSUBQOS: SUBQOSINDEX=123;%%
  RETCODE = 0  操作成功

  EPS用户QoS配置信息
  ------------------
               用户QoS索引  =  123
                   标准QCI  =  5
             ARP的优先级别  =  10
  下行APN AMBRR(千比特/秒)  =  564110
  上行APN AMBRR(千比特/秒)  =  300000
  (结果个数 = 1)

  ---    END
  ```
- 查询所有的记录：

  ```
  %%LST EPSSUBQOS:;%%
  RETCODE = 0  操作成功

  EPS用户QoS配置信息
  ------------------
  用户QoS索引    标准QCI    ARP的优先级别    下行APN AMBRR(千比特/秒)    上行APN AMBRR(千比特/秒)

  1              5          1                2                             5                         
  123            5          10               564110                        300000                    
  (结果个数 = 2)

  ---    END
  ```

## 输出结果说明

| 输出项名称              | 输出项解释                 |
|:-------------------|:----------------------|
| 用户QoS索引            | 该参数表示用户QoS索引。         |
| 标准QCI              | 该参数表示QoS业务类型参数。       |
| ARP的优先级别           | 该参数表示分配优先级。           |
| 下行APN AMBRR(千比特/秒) | 该参数用于设置下行APN-AMBR比特率。 |
| 上行APN AMBRR(千比特/秒) | 该参数用于设置上行APN-AMBR比特率。 |
