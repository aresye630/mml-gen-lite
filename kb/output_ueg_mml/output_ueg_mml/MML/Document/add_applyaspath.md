# 增加AS路径设置（ADD APPLYASPATH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来增加AS路径属性的操作。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为65535。
- 配置该命令前，必须已经通过ADD ROUTEPOLICY配置了指定路由策略的名字以及通过ADD ROUTEPOLICYNODE配置了该策略下的节点。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                                                                                                                        |
|:--------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| POLICYNAME    | 路由策略名字  | 可选必选说明：必选参数 参数含义：该参数用于指定路由策略名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无 配置原则：区分大小写。                                                                                                                        |
| NODESEQUENCE  | 路由策略节点号 | 可选必选说明：必选参数 参数含义：该参数用于指定路由策略节点号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无                                                                                                                                    |
| OPERATIONTYPE | 操作类型    | 可选必选说明：必选参数 参数含义：该参数用于指定AS属性值的应用方式，支持4种方式： 追加：配置的AS属性将追加到路由原有AS属性上。 替换：配置的AS属性值将替换路由原有AS属性。 删除：将路由原有AS属性全部删除。 删除指定：删除指定的AS属性。 数据来源：本端规划 取值范围：枚举类型。 delete：删除。replace：替换。additive：相加。delSpecial：删除特定的。 默认值：无 |

#### 使用实例

增加AS路径属性的操作：

```
ADD APPLYASPATH:POLICYNAME="a",NODESEQUENCE=10,OPERATIONTYPE=replace;
```
