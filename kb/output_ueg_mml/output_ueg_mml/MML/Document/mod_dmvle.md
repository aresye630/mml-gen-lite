# 修改Diameter虚拟本地实体(MOD DMVLE)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于修改Diameter虚拟本地实体的“产品名”和“本地实体名”。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                           |
|:-----------|:-------|:---------------------------------------------------------------------------------------------------------------|
| LOINDEX    | 本地实体索引 | 可选必选说明：必选参数 参数含义：该参数用于指定虚拟本地实体的索引，在Diameter链路中唯一标识一个虚拟本地实体。 数据来源：本端规划 取值范围：32~63 默认值：无                         |
| PDTNAME    | 产品名    | 可选必选说明：可选参数 参数含义：该参数用于指定产品名，用于标识本端产品信息。 数据来源：本端规划 取值范围：0～32位字符串 默认值：无 配置原则：该参数用来标识本端的产品信息，一般可直接填写产品的名称。如填写UNC。 |
| LOINFONAME | 本地实体名  | 可选必选说明：可选参数 参数含义：该参数用于指定虚拟本地实体名称，标识虚拟本地实体。 数据来源：本端规划 取值范围：0～32位字符串 默认值：无 配置原则：用来标识虚拟本地实体时，一般配置为DMVLE。          |

#### 使用实例

修改索引为32的实体记录，产品名修改为MME1，本地实体名修改为DMVLE：

MOD DMVLE: LOINDEX=32, PDTNAME="MME1", LOINFONAME="DMVLE";
