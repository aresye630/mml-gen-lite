# 查询APN智能分流关键词（LST APNINTELSHUNT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C**

该命令用于查询APN智能分流关键词。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                                                                                                                                                                                 |
|:-----------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN        | APN     | 可选必选说明：可选参数  参数含义：该参数用于指定2B2C双DNN特性中通用DNN会话的APN实例名。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“ ” ”、“ ` ”特殊字符，不区分大小写。  默认值：无  配置原则：  该参数使用ADD CPAPN命令配置生成。 |
| INTELSHUNT | 智能分流关键词 | 可选必选说明：可选参数  参数含义：该参数用于指定智能分流关键词。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“ ” ”、“ ` ”特殊字符，不区分大小写。  默认值：无  配置原则：无                                         |

## 使用实例

- 显示“APN”为“huawei.com”的智能分流关键词：

  ```
  %%LST APNINTELSHUNT: APN="huawei.com";%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
            APN  =  huawei.com
  智能分流关键词  =  huawei1
  (结果个数 = 1)

  ---    END
  ```
- 显示全部的APN智能分流关键词：

  ```
  %%LST APNINTELSHUNT:;%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
  APN          智能分流关键词

  huawei.com   huawei1
  huawei2.com  huawei3       
  (结果个数 = 2)

  ---    END
  ```
