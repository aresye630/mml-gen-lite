# 删除MSC信令点(RMV MSCOPC)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SMSF**

该命令用于删除MSC本局信令点指定配置。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；

#### 参数说明

| 参数标识   | 参数名称     | 参数说明                                                         |
|:-------|:---------|:-------------------------------------------------------------|
| OPX    | MSC信令点索引 | 可选必选说明：必选参数 参数含义：该参数用于指定MSC本局信令点索引。 数据来源：本端规划 取值范围：1~2 默认值：无 |

#### 使用实例

删除MSC信令点索引为1的MSC信令点。

```
RMV MSCOPC: OPX=1;
```
