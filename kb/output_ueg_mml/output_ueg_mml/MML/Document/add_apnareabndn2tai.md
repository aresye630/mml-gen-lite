# 增加APN相关服务区域绑定的5G TAI范围（ADD APNAREABNDN2TAI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于增加APN相关服务区域绑定的5G TAI范围。服务区域通常是企业园区所处的区域。在服务区域内，根据用户位置可以做APN粒度相关特性控制。

## 注意事项

- 该命令执行后立即生效。

- 同一个AREANAME下TAI区域不能有交叠，不同AREANAME下TAI区域不做限制。

- 最多可输入32000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称                | 参数说明                                                                                                                                                                                |
|:-----------|:--------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AREANAME   | APN相关服务区域           | 可选必选说明：必选参数  参数含义：该参数用于配置APN相关服务区域名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~255。不能为非法字符，只允许输入字母，数字、“_”、“.”，并且开头和结尾只能是数字或者字母，不能出现连续两个“.”。  默认值：无  配置原则：  与APNAREA配置中的AREANAME取值对应。         |
| N2BEGINTAI | 服务区域名称支持5GTAI范围的起始值 | 可选必选说明：必选参数  参数含义：该参数用于标识APN相关服务区域支持5GTAI范围的起始值，TAI = MCC+ MNC + TAC。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是11~12。后6位为16进制数，其余为10进制数。  默认值：无  配置原则：  TAI范围的结束值需要不小于TAI范围的开始值，且结束值和开始值长度需相等。 |
| N2ENDTAI   | 服务区域名称支持5GTAI范围的结束值 | 可选必选说明：必选参数  参数含义：该参数用于标识APN相关服务区域支持5GTAI范围的结束值，TAI = MCC+ MNC + TAC。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是11~12。后6位为16进制数，其余为10进制数。  默认值：无  配置原则：  TAI范围的结束值需要不小于TAI范围的开始值，且结束值和开始值长度需相等。 |

## 使用实例

增加APN相关服务区域“dnnarea1”的TAI绑定范围46001000001~46001123456。

```
ADD APNAREABNDN2TAI: AREANAME="dnnarea1", N2BEGINTAI="46001000001", N2ENDTAI="46001123456";
```
