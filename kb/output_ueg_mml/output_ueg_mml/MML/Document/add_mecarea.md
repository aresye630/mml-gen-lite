# 增加5G MEC区域信息（ADD MECAREA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于增加5G MEC区域信息，位于特定区域的用户可以访问本地特色业务。

## 注意事项

- 下一次移动性流程生效。

- 区域类型为“HIGH\_RAIL\_AREA”的MEC区域仅支持增加跟踪区成员。

- 最多可输入1024条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                           |
|:-------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AREAID       | 区域标识   | 可选必选说明：必选参数  参数含义：该参数用于唯一标识AMF服务的某个区域（例如：商场）。其服务范围可以通过ADD MECAREATAI或ADD MECAREAGNB进行配置。  数据来源：全网规划  取值范围：整数类型，取值范围是1~1024。  默认值：无  配置原则：  当通过RMV MECAREA命令删除“AREAID”区域成员时，请执行LST MECAREATAI和LST MECAREAGNB命令，确保中“AREAID”未被索引。 |
| SERVINGSCOPE | 服务范围   | 可选必选说明：必选参数  参数含义：该参数用于描述目标PCF的服务范围。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~64。如果输入多个服务范围，那么使用“:”作为分隔符，比如“pudong:puxi”。  默认值：无  配置原则：  NRF针对“服务范围”是按照“包含”的逻辑进行处理的，即目标PCF能为发现请求中携带的所有服务范围提供服务，NRF才会认为其满足条件；故本参数在输入时应避免输入无效的服务范围。       |
| AREATYPE     | 区域类型   | 可选必选说明：可选参数  参数含义：该参数用于标识当前区域的区域类型。  数据来源：全网规划 取值范围： PUBLIC_AREA（公网区域）HIGH_RAIL_AREA（高铁区域）  默认值：PUBLIC_AREA  配置原则：  若本参数发生变更，可能会使已建立AM策略的用户无法应用变更后的AM策略。                                                                       |
| DESC         | 描述信息   | 可选必选说明：可选参数  参数含义：该参数用于描述区域信息。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~32。  默认值：无  配置原则：无                                                                                                                                              |

## 使用实例

针对标识为“1”的区域（例如：西湖景区）的用户，可以访问本地特性业务，执行如下命令：

```
ADD MECAREA: AREAID=1, SERVINGSCOPE="West Lake", DESC="West Lake";
```
