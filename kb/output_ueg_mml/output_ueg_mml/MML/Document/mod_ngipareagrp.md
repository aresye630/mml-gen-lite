# 修改5G IP区域群（MOD NGIPAREAGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于修改5G IP区域群的属性。

## 注意事项

命令执行后只对新接入用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                          |
|:----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AREAID    | 区域群标识  | 可选必选说明：必选参数  参数含义：该参数用于指定区域群标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~64。  默认值：无  配置原则：无                                                                                                                            |
| IPAREASW  | IP区域开关 | 可选必选说明：可选参数  参数含义：该参数用于指定打开或者关闭IP区域群管理功能。 “IPAREASW(IP区域开关)”开启后，用户移动符合如下情况时，用户的PDU会话将会被强制释放： 从IP区域群外移动到IP区域群内。 从IP区域群内移动到IP区域群外。 从一个IP区域群移动到另一个IP区域群。  数据来源：全网规划 取值范围： “OFF（关闭）”：关闭“ON（开启）”：开启  默认值：无  配置原则：无 |
| ROAMUSRSW | 漫游用户开关 | 可选必选说明：该参数在"IPAREASW"配置为"ON"时为条件可选参数。  参数含义：该参数用于设置漫游用户接入限制开关。如果设置为ON，漫游用户在本区域不允许接入。  数据来源：全网规划 取值范围： “OFF（关闭）”：关闭“ON（开启）”：开启  默认值：无  配置原则：无                                                                  |

## 使用实例

若对标识为SomeCity的IP区域群，关闭IP区域管理功能，执行如下命令：

```
MOD NGIPAREAGRP: AREAID="SomeCity", IPAREASW=OFF;
```
