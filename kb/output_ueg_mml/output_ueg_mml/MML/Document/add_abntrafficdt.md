# 新增异常流量检测开关（ADD ABNTRAFFICDT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用来使能APN下终端异常下行流量检测功能。

#### 注意事项

- 该命令执行后只对新激活用户生效。
- 系统最多支持配置10000条ABNTRAFFICDT。
- Normal用户不支持异常流检测。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识                  | 参数名称       | 参数说明                                                                                                                                                                                                                                                      |
|:----------------------|:-----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN                   | APN名称      | 可选必选说明：必选参数 参数含义：该参数用于指定APN名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”特殊字符，不区分大小写。 默认值：无 配置原则： 该参数使用ADD UPAPN命令配置生成。该APN必须是系统已经配置的APN，此功能不支持别名APN的配置使能。 |
| SWITCH                | 开关         | 可选必选说明：必选参数 参数含义：该参数用于指定终端异常下行流量检测是否使能。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则： ENABLE：开启指定APN下终端异常下行流量检测功能。DISABLE：关闭开启指定APN下终端异常下行流量检测功能。                                                                                               |
| TRAFFICBEHAVIORSWITCH | 基于流行为的检测开关 | 可选必选说明：条件可选参数 前提条件：该参数在“SWITCH”配置为“ENABLE”时为可选参数。 参数含义：该参数用于指定基于流行为的终端异常下行流量检测是否使能。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：DISABLE 配置原则： 如果运营商需要开启基于流行为检测开关时，需要配置该参数。ENABLE：开启指定APN下基于流行为的终端异常下行流量检测功能。DISABLE：关闭开启指定APN下基于流行为的终端异常下行流量检测功能。     |

#### 使用实例

假如运营商需使能名称为“apn1.com”的APN的终端异常下行流量检测功能：

```
ADD ABNTRAFFICDT: APN="apn1.com", SWITCH=ENABLE;
```
