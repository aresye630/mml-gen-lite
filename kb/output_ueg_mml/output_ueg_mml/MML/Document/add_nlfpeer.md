# 添加NLF对端(ADD NLFPEER)

- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中增加一条NLF对端服务器的数据记录。

该命令的使用场景：NLF服务支持通知日志文件上传或下载，当NLF作为SFTP客户端，向DRS服务上传通知日志文件。

## 注意事项

NLF作为SFTP客户端时，基于是否使用兼容密钥算法，需要考虑软参“VRM\_NLFSFTPCLIENTACSWITCH”的设置值。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                  |
|:---------|:-------|:------------------------------------------------------------------------------------------------------|
| PEERID   | 对端ID   | 可选必选说明：必选参数 参数含义：用于标识一条NLF对端服务器的数据记录。 取值范围：0～31 默认值：无。 配置原则：对端服务器ID不能重复。                              |
| PEERNAME | 对端名称   | 可选必选说明：必选参数 参数含义：用于具体描述一个NLF对端服务器的名称，以便于识别。值域类型为字符串，区分大小写。 取值范围：长度不超过128的字符串 默认值：无。 配置原则：对端服务器名称不能重复。 |
| PEERTYPE | 对端类型   | 可选必选说明：必选参数 参数含义：用于标识NLF对端服务器的应用类型。 取值范围： SFTP(SFTP) 默认值：无。 配置原则：无。                                   |

## 使用实例

增加一个NLF对端服务器。“对端ID”为“1”，“对端名称”为“SFTP\_SER”，“对端类型”为“SFTP(SFTP)”。

```
ADD NLFPEER: PEERID=1, PEERNAME="SFTP_SER", PEERTYPE=SFTP;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释     | 原因分析          | 处理建议                                                                            |
|------:|:----------|:--------------|:--------------------------------------------------------------------------------|
| 58012 | 对端名称已经存在。 | 输入的“对端名称”已存在。 | 执行LST NLFPEER命令查询全部NLF对端服务器配置信息，记录已存在的对端名称。 执行本命令，重新设置“对端名称”，并确保和已存在的“对端名称”不相同。 |
