# 显示会话中NETCONF和其它组件的消息交互信息（DSP NCSDIAGLOG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示会话中NETCONF和其它组件的消息交互信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                                          |
|:----------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DATATYPE        | 数据类型   | 可选必选说明：必选参数 参数含义：数据类型。 数据来源：本端规划 取值范围：枚举类型。 SESSIONHISTORY：历史信息。STCOVERTIME：超时信息。MESSAGE：消息信息。SESSIONFSM：状态机信息。STCPERFORMANCE：性能信息。ERRORMESSAGE：错误信息。INNERMESSAGE：内部信息。 默认值：无 |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。                                                                  |

#### 使用实例

显示会话中NETCONF和其它组件的消息交互信息：

```
DSP NCSDIAGLOG:DATATYPE=SESSIONHISTORY,SERVICEINSTANCE="vnfc";
```
