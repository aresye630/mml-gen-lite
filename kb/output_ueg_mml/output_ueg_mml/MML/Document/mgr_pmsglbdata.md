# PMS迁移全局数据(MGR PMSGLBDATA)

## 命令功能

**须知** 

- 此命令是高危命令，如果执行不当会导致系统异常，影响业务处理，需联系华为技术支持确认后再执行。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令为配置类命令，仅升级场景使用。用于迁移PMS微服务的全局数据。

## 注意事项

全局数据迁移过程中，禁止执行CLI命令或在UPCF WebUI界面修改全局数据，否则，可能会导致迁移完成后，迁移过程中修改的全局数据丢失。

## 参数说明

无。

## 使用实例

迁移PMS微服务的全局数据。

```
MGR PMSGLBDATA:;
```

```
%%MGR PMSGLBDATA: CONFIRM=Y;%%
RETCODE = 0  操作成功

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                                | 原因分析                       | 处理建议                                                   |
|------:|:-------------------------------------|:---------------------------|:-------------------------------------------------------|
| 58132 | 已经有迁移任务在执行中，请稍后再试。                   | 已经有迁移任务在执行中。               | 执行DSP PMSGLBDATA命令查看数据迁移结果，待迁移任务的“状态”不为“运行中”时，重新执行该命令。 |
| 58133 | 软参VRM_VOLTEGLOBALDATA取值为1时，不允许执行该命令。 | 软参VRM_VOLTEGLOBALDATA取值为1。 | 请联系华为技术支持。                                             |
| 58134 | 未加载VOLTE插件包，不允许执行该命令。                | 未加载VOLTE插件包。               | 请联系华为技术支持。                                             |
| 57815 | 服务器内部错误。                             | 服务器内部错误。                   | 请联系华为技术支持。                                             |
