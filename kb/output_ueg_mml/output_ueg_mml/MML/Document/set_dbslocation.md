# 设置DBS Location信息(SET DBSLOCATION)

## 命令功能

**须知** 

该命令属于高危命令，该操作可能会产生致命错误，并且要使修改生效，必须重新启动服务。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置Location信息。

该命令的使用场景：当新建网元需要对接配置时，此时通过该命令设置Location信息。Location唯一标识一个网元。

## 注意事项

- 执行本命令之后，请登录“OM Portal MML命令”界面，选择FE网元执行如下命令重启DBS服务使Location标识生效（此时会出现链路断开等问题，禁止随意执行）。

  ```
  RST MSPROCESS: PROCOBJECT=PROCNAME, PROCNAME="CELL_UdrDbbroker";
  ```
- 不同网元的Location标识必须不一样，否则会被认为是同一网元。

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                                                         |
|:-------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LOCID  | Location标识 | 可选必选说明：必选参数 参数含义：用于标识一个网元，所有的网元标识唯一。 取值范围：1～512 默认值：无。 配置原则：Location标识在以下网元中需要配置：主用局FE、主用局USCDB、容灾局FE、容灾局USCDB。                                                                                                                                                                                                                                              |
| CNFM   | 是否确认修改     | 可选必选说明：可选参数 参数含义：用于确认是否强制设置“Location标识”。 取值范围： YES(是)：表示不管当前网元是否已经设置“Location标识”，此次都会强制设置成功。NO(否)：表示如果当前网元没有设置“Location标识”，则本次设置成功。如果当前网元已经设置了“Location标识”，则本次设置无效并返回错误码“302596 Location标识已设置”。 默认值：NO(否) 配置原则：“Location标识”为网元唯一标识，如果随意修改会造成FE和BE间对接失败，从而导致致命的业务影响，因此请确保在非商用局点进行修改设置，如新建部署网元在调测阶段设置“Location标识”与规划取值不一致，需重新修改为规划的取值，则可将该参数设置为“YES”，商用局点禁止修改。 |

## 使用实例

在开局场景下，设置Location信息，“Location标识”为“12”:

```
SET DBSLOCATION: LOCID=12;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                                     | 原因分析                             | 处理建议                                                                                                                      |
|-------:|:----------------------------------------------------------|:---------------------------------|:--------------------------------------------------------------------------------------------------------------------------|
| 302000 | 参数Location标识指定的本地Location标识与远端Location配置中的远端Location标识重复。 | 输入的“Location标识”与远端location的标识重复。 | 请执行LST DBSRLOCATION命令查询“远端Location标识”，重新执行本命令时输入的“Location标识”确保与“远端Location标识”不一致。                                        |
| 302596 | Location标识已设置。                                            | 当前网元已设置了“Location标识”。            | “Location标识”为网元唯一标识，如果随意修改会造成网元间对接失败，从而导致致命的业务影响，因此请确保在非商用局点进行修改设置。如确认需要修改当前网元的“Location标识”，请重新执行本命令，将参数“是否确认修改”设置为“YES”。 |
