# 查询冲突配置（LST SESCOLLISIONCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询已配置的冲突配置信息。

## 注意事项

无。

## 参数说明

| 参数标识         | 参数名称         | 参数说明                                                                                                                                                                                                          |
|:-------------|:-------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ID           | ID           | 可选必选说明：可选参数 参数含义：用于指定系统按照记录标识查询同用户下N7会话冲突检测参数。 取值范围：1。 默认值：无。 配置原则：无。                                                                                                                                         |
| PDUSESSIONID | PduSessionId | 可选必选说明：可选参数 参数含义：用于指定系统按照是否支持通过PduSessionId进行同用户下N7会话冲突检测进行查询。 取值范围： Support（支持）：UPCF对同一用户相同PduSessionId的N7会话进行检测，并释放掉检测冲突的老的N7会话，保留较新的N7会话。Unsupport（不支持）：UPCF不开启同一用户相同PduSessionId的N7会话冲突检测。 默认值：无。 配置原则：无。 |

## 使用实例

查询已配置的冲突配置参数信息。

```
LST SESCOLLISIONCFG:;
```

```
%%LST SESCOLLISIONCFG:;%% 
RETCODE = 0  操作成功             

          ID  =  1 
PduSessionId  =  Unsupport 
(结果个数 = 1)  

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息，各参数含义请参见参数说明。
