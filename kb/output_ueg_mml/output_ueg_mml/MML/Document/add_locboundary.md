# 配置位置边界点信息（ADD LOCBOUNDARY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于添加用户位置可达的区域配置。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为5000。
- 配置该命令时，位置边界点的范围与SequenceId的顺序有关系，SequenceId的顺序不同，绘制的位置边界点范围可能会有所不同。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称           | 参数说明                                                                                                                           |
|:------------|:---------------|:-------------------------------------------------------------------------------------------------------------------------------|
| AREAID      | 区域标识           | 可选必选说明：必选参数 参数含义：该参数用于设置边界区域标识。 数据来源：本端规划 取值范围：0~4294967295。 默认值：无 配置原则：无                                                      |
| MAPID       | 地图标识           | 可选必选说明：必选参数 参数含义：该参数用于配置地图标识。 数据来源：本端规划 取值范围：int64位字符串，取值范围：-9223372036854775808~9223372036854775807。 默认值：无 配置原则：无             |
| SEQUENCEID  | 坐标点序号          | 可选必选说明：必选参数 参数含义：该参数用于配置坐标点序号，基于序号来绘制边界区域。 数据来源：本端规划 取值范围：1~100。 默认值：无 配置原则：无                                                  |
| POSITIONX   | 边界点相对位置X信息（厘米） | 可选必选说明：必选参数 参数含义：该参数用于设置边界点相对位置X信息，单位：厘米。 数据来源：本端规划 取值范围：int64位字符串，取值范围：-9223372036854775808~9223372036854775807。 默认值：无 配置原则：无 |
| POSITIONY   | 边界点相对位置Y信息（厘米） | 可选必选说明：必选参数 参数含义：该参数用于配置边界点相对位置Y信息，单位：厘米。 数据来源：本端规划 取值范围：int64位字符串，取值范围：-9223372036854775808~9223372036854775807。 默认值：无 配置原则：无 |
| DESCRIPTION | 描述信息           | 可选必选说明：可选参数 参数含义：该参数用于设置边界点配置描述信息。 数据来源：本端规划 取值范围：字符串类型，输入长度1~32。 默认值：无 配置原则：无                                                 |

#### 使用实例

配置用户位置可达区域，区域标识为123，地图区域标识为123，坐标点序号为12，点坐标为(123, 123)，描述为this is a demo：

```
ADD LOCBOUNDARY: AREAID=123, MAPID="123", SEQUENCEID=12, POSITIONX="123", POSITIONY="123", DESCRIPTION="this is a demo";
```
