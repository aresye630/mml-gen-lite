# 增加PCC组业务属性绑定（ADD SRVPBINDPCCPG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

此命令用于新增PCC策略组业务属性绑定组合。可以通过命令，配置包含业务属性的非默认组合，非默认组合还可以包括计费属性、PCC动作属性、扩展属性等。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为100000。
- 每个PCC策略组可以配置十个基于业务属性的非默认组合。
- 配置PCC策略组基于业务属性的非默认组合，可以包含计费属性、PCC动作属性、监控属性ID、Session级FUP累计标识、扩展属性等，所有参数都是可选，如果一个都没有选，则配置一个空的PCC策略组业务属性绑定组合。
- 如果每个PCC策略组配置了多种非默认组合，则匹配优先级取决于SrvPBindPccPG下配置的ServiceProp优先级。默认组合的优先级最低。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称            | 参数说明                                                                                                                                                                                                                                                                                         |
|:---------------|:----------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PCCPOLICYGRPNM | PCC策略组名称        | 可选必选说明：必选参数 参数含义：设置PCC策略组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD PCCPOLICYGRP命令配置生成。                                                                                                                                                                          |
| SRVPROPNAME    | 业务属性名称          | 可选必选说明：必选参数 参数含义：设置业务属性名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数使用ADD SERVICEPROP命令配置生成。如果运营商需要定义该PCC策略组基于业务属性的非默认策略组合时，需要配置业务属性对象名称，只有签约了该业务属性才可以选择本策略组合中的各种策略进行业务处理。                                                                                              |
| URRGROUPNAME   | URR组名称          | 可选必选说明：可选参数 参数含义：设置计费属性名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数使用ADD URRGROUP命令配置生成。如果运营商需要定义该PCC策略组基于该业务属性的计费策略时，建议配置用于计费处理的计费属性对象名称。                                                                                                                             |
| PCCACTPROPNAME | PCC动作属性名称       | 可选必选说明：可选参数 参数含义：设置PCC动作属性名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数使用ADD PCCACTIONPROP命令配置生成。如果运营商需要定义该PCC策略组基于该业务属性的PCC动作策略时，建议配置用于控制处理的PCC动作属性对象名称。                                                                                                               |
| EXTENDPROPNAME | 扩展属性名称          | 可选必选说明：可选参数 参数含义：设置扩展属性名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数使用ADD EXTENDPROP命令配置生成。如果运营商需要定义该PCC策略组基于该业务属性的扩展属性时，建议配置相应的扩展属性对象名称。                                                                                                                               |
| FUPSESSIONEXC  | Session级FUP累计标识 | 可选必选说明：可选参数 参数含义：设置Session级FUP流量累计标识。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能，表明该PccPolicyGrp对应的业务流量计入Session级流量。ENABLE：使能，表明该PccPolicyGrp对应的业务流量不计入Session级流量。 默认值：DISABLE 配置原则：如果运营商需要定义该PCC策略组基于该业务属性的业务级FUP流量累计时，是否同时累计到Session级流量，建议配置Session级FUP流量累计标识。该参数会用于控制Gx接口向PCRF上报业务级和Session的流量累计方式。 |

#### 使用实例

假如运营商需要为PCC策略组TestPccPolicyGrpName增加一个基于名称为TestServicePropName的业务属性的策略组合，要求在该PCC策略组合中包含计费策略、PCC动作策略、业务级FUP流量累计标识且不需要累计到Session级流量中进行上报。
增加PCC策略组业务属性绑定组合，设置包括业务属性、计费属性、PCC动作属性的默认组合；“PCCPOLICYGRPNM”为“TestPccPolicyGrpName”，“SRVPROPNAME”为“TestServicePropName”，“CHARGEPROPNAME”为“TestChargePropName”，“PCCACTPROPNAME”为“TestPccActPropName”，“FUPSESSIONEXC”为“ENABLE”：

```
ADD SRVPBINDPCCPG:PCCPOLICYGRPNM="TestPccPolicyGrpName",SRVPROPNAME="TestServicePropName",URRGROUPNAME="TestChargePropName",PCCACTPROPNAME="TestPccActPropName",FUPSESSIONEXC=ENABLE;
```
