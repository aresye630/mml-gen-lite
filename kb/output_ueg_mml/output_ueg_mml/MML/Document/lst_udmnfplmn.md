# 查询网元PLMN信息（LST UDMNFPLMN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询网元的PLMN信息。

- 若需要查询全部PLMN的信息，请不要输入任何参数。
- 若需要查询某个PLMN的详细信息，请输入“组名称”参数或“索引”参数，或者同时输入“组名称”参数和“索引”参数。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                               |
|:--------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GRPNAME | 组名称    | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个组名称标识来查询网元PLMN信息；若不输入，则表示查询所有的组名称。 取值范围：长度不超过32的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 参数来源：该参数由本端UDM自行定义。 默认值：无。 配置原则：该参数和“索引”参数组成全局唯一对象关键字段。 |
| INDEX   | 索引     | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个索引标识查询网元PLMN信息；若不输入，则表示查询所有的索引。 取值范围：1~1024 参数来源：该参数由本端UDM自行定义。 默认值：无。 配置原则：该参数和“组名称”参数组成全局唯一对象关键字段。                                  |

## 使用实例

1. 查询所有网元PLMN信息：

   ```
   LST UDMNFPLMN:;
   ```

   ```
   %%LST UDMNFPLMN:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   组名称    索引  移动国家码  移动网络码  

   nfplmn    1     001         03        
   nfplmn1   3     001         03        
   plmn2345  7     012         456   
   (结果个数 = 3)

   ---    END
   ```
2. 查询“组名称”为“nfplmn”,“索引”为“1”的网元PLMN信息：

   ```
   LST UDMNFPLMN: GRPNAME="nfplmn", INDEX=1;
   ```

   ```
   %%LST UDMNFPLMN: GRPNAME="nfplmn", INDEX=1;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
       组名称  =  nfplmn
         索引  =  1
   移动国家码  =  003
   移动网络码  =  11
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD UDMNFPLMN**命令的参数说明。
