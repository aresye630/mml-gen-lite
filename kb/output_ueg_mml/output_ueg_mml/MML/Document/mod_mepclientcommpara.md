# 修改MEP HTTP客户端通信参数（MOD MEPCLIENTCOMMPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

该命令用于修改指定的MEP HTTP客户端通信参数。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称          | 参数说明                                                                                                                   |
|:---------------|:--------------|:-----------------------------------------------------------------------------------------------------------------------|
| PARANAME       | HTTP客户端通信参数名称 | 可选必选说明：必选参数 参数含义：该参数用于指定HTTP客户端通信参数名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“.”组成，且只能以字母或者数字开头。 默认值：无 配置原则：无 |
| CONNTIMEOUT    | 与服务端建立连接超时时间  | 可选必选说明：可选参数 参数含义：该参数用于指定客户端与服务端建立TCP连接时的超时时间。 数据来源：本端规划 取值范围：整数类型，取值范围为1-60。 默认值：无 配置原则：无                              |
| SENDREQTIMEOUT | 发送请求超时时间      | 可选必选说明：可选参数 参数含义：客户端向服务端发送请求的超时时间，指客户端发送请求时的两个连续写操作之间的超时时间。 数据来源：本端规划 取值范围：整数类型，取值范围为1-300。 默认值：无 配置原则：无               |
| WAITRSPTIMEOUT | 读取服务端响应超时时间   | 可选必选说明：可选参数 参数含义：客户端从服务端读取响应的超时时间，指客户端读取响应时的两个连续读操作之间的超时时间。 数据来源：本端规划 取值范围：整数类型，取值范围为1-300.。 默认值：无 配置原则：无              |

#### 使用实例

修改MEPCLIENTCOMMPARA对象，修改的MEPCLIENTCOMMPARA对象名称为"cli-comm-para"，修改与服务端建立连接超时时间为"40"，修改发送请求超时时间为"40"，修改读取服务端响应超时时间为"40"：

```
MOD MEPCLIENTCOMMPARA: PARANAME="cli-comm-para", CONNTIMEOUT=40, SENDREQTIMEOUT=40, WAITRSPTIMEOUT=40;
```
