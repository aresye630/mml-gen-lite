# 设置FE序号(SET FESN)

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致业务中断，需联系华为技术支持确认后再执行。

该命令用于设置FE序号，以便根据FE序号确定FE使用的License控制项。命令操作场景如下：

- 在多FE合一组网场景下，使用命令配置FE的序号。
- 在扩容操作需要增加FE场景下，使用命令配置FE编号。

## 注意事项

- 数据库中最多有一条配置记录，当数据库中已经存在配置记录时，此命令的执行会修改原来的配置信息。
- 当多FE改造成单FE且不申请新的License时，才使用“FE序号”为“255”，其他情况下不能使用。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                         |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SN     | FE序号   | 可选必选说明：必选参数 参数含义：用于设置FE序号。 取值范围：0～20，255 默认值：无。  说明： 单FE组网下FE序号设置为0。 多FE合一组网下FE序号由工程设计输出。 当“FE序号”为“255”时，系统的每个License资源项按照如下方式进行控制（对“SPR用户和签约信息存储和管理”资源项无效，对其他资源项有效）： 改造后的单FE资源控制项，等于原来各FE的资源项之和。 改造前各FE的资源项都是最大值时，改造后只累积一个最大值，部分是最大值时当做0处理。 |

## 使用实例

在多FE合一组网时，根据规划配置FE的序号，设置FE序号为“0”，对应的License控制项为FE0。

```
SET FESN:SN=0;
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。
