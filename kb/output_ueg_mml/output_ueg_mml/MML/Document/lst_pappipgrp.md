# 查询对端设备组配置(LST PAPPIPGRP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询数据库中对端设备组配置数据。

- 若需要查询全部对端设备组配置信息，请不要输入任何参数。
- 若需要查询某个对端设备组配置信息，请输入“对端设备组名称”参数。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                             |
|:----------|:--------|:---------------------------------------------------------------------------------------------------------------------------------|
| PAPPGRPNM | 对端设备组名称 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个对端设备组名称来查询对端设备组配置数据；若不输入，则表示查询所有的对端设备组名称。 取值范围：长度不超过63的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询所有对端设备组配置数据信息：

   ```
   LST PAPPIPGRP:;
   ```

   ```
   %%LST PAPPIPGRP:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   对端设备组名称    对端设备组备注         

   PeerIpGroup       TestRemark
   PeerIpGroup2      TestRemark2
   (结果个数 = 2)

   ---    END
   ```
2. 查询“对端设备组名称”为“PeerIpGroup”的信息：

   ```
   LST PAPPIPGRP: PAPPGRPNM="PeerIpGroup";
   ```

   ```
   %%LST PAPPIPGRP: PAPPGRPNM="PeerIpGroup";%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   对端设备组名称  =  PeerIpGroup
   对端设备组备注  =  TestRemark
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD PAPPIPGRP**命令的参数说明。
