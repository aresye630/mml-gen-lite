# 删除网关转发地址（RMV PAEPORTGATEWAY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

删除网关地址后，可能会导致内联口报文无法跨子网通信，业务会出现呼损。同时会产生告警“ALM-100338 Fabric平面状态为Down”。请联系华为技术支持协助操作。

该命令用于删除指定网段索引下内联口的网关地址。

## 注意事项

- 该命令执行后立即生效。

- 当有内联口在使用该网段时，不允许删除。可以通过**DSP PAEPORTGATEWAY**命令查询。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                   |
|:-------------|:-------|:---------------------------------------------------------------------------------------|
| NETWORKINDEX | 网段索引   | 可选必选说明：必选参数  参数含义：该参数用于指定网段索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~4294967295。  默认值：无  配置原则：无 |

## 使用实例

删除网段索引为1的内联口的网关地址：

```
RMV PAEPORTGATEWAY: NETWORKINDEX=1;
```
