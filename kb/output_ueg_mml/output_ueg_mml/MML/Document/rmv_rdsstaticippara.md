# 删除园区用户IP地址信息（RMV RDSSTATICIPPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于删除Radius静态IP地址信息、UDM静态IP地址信息或5G LAN组信息。

## 注意事项

该命令执行后只对新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                                                                                          |
|:-------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI   | 用户IMSI号 | 可选必选说明：必选参数  参数含义：用户的IMSI信息。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是5~15。  默认值：无  配置原则：无                                                                                                                                               |
| APN    | APN名称   | 可选必选说明：必选参数  参数含义：该参数用于指定APN实例名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“ ” ”、“ ` ”特殊字符，不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

删除Radius静态IP地址信息，IMSI值为123456789012345，APN值为huawei.com：

```
RMV RDSSTATICIPPARA: IMSI="123456789012345", APN="huawei.com";
```
