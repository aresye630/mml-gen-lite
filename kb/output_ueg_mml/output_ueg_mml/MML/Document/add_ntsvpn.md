## 命令功能

该命令用于在配置数据库中增加一条NTS接入CSLB时业务IP地址的VPN数据记录。

使用场景：

UPCF支持在特定场景（例如用户流量达到阈值、配额充值）给用户发送通知，提醒用户当前业务的使用状态；或将通知发送到第三方服务器上，由第三方服务器决定后续的处理。

- 与短消息中心对接，可以通过短消息中心发送短信通知给终端用户。
- 与邮件服务器对接，可以通过邮件服务器发送邮件通知给终端用户。
- 与SOAP服务器对接，可以发送SOAP通知到SOAP服务器上，由SOAP服务器决定后续的处理（如以短信、邮件或PUSH通知方式通知给终端用户）。

通知发送前配置UPCF与对端的对接数据为必选操作之一。需执行本命令增加UPCF负责通知任务服务（NTS）的接入CSLB时业务IP地址的VPN。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                           |
|:------------|:-------|:---------------------------------------------------------------------------------------------------------------|
| VPNINDEX    | VPN索引  | 可选必选说明：必选参数 参数含义：用于标识一条NTS接入CSLB时业务IP地址的VPN数据记录。 取值范围：0～15 默认值：无。 配置原则：无。                                      |
| VPNNAME     | VPN名称  | 可选必选说明：必选参数 参数含义：用于标识CSLB业务IP的VPN名称。 该参数取值需要与ADD L3VPNINST命令中“VPN实例名称”参数值保持一致。 取值范围：长度不超过31的字符串 默认值：无。 配置原则：无。 |
| DESCRIPTION | 描述     | 可选必选说明：可选参数 参数含义：用于描述CSLB业务IP的VPN用途。 取值范围：长度不超过32的字符串 默认值：无。 配置原则：无。                                           |

## 使用实例

增加一条NTS VPN数据记录，“VPN索引”为“0”，“VPN名称”为“VPN\_20”，“描述”为“NTS\_VPN”。

```
ADD NTSVPN: VPNINDEX=0, VPNNAME="VPN_20", DESCRIPTION="NTS_VPN";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释     | 原因分析           | 处理建议                                                                                                                          |
|------:|:----------|:---------------|:------------------------------------------------------------------------------------------------------------------------------|
| 57909 | VPN名称已存在。 | 输入的“VPN名称”已存在。 | 执行LST NTSVPN命令查询全部NTS VPN配置信息，记录已存在的“VPN名称”。 执行本命令，重新设置“VPN名称”，并确保VPN名称与已存在的NTS VPN数据记录不相同且与ADD L3VPNINST命令中“VPN实例名称”参数值保持一致。 |
