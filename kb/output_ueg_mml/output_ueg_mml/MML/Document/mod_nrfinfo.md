## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致系统异常，影响业务处理，需联系华为技术支持确认后再执行。

该命令用于修改NRF的信息。在该命令中，系统通过“NRF名称”关键参数来唯一标识一条NRF信息。

- **命令作用**：该命令用于配置PCF需要注册到的NRF信息时，当组网中部署了多个NRF网元时，支持修改目标NRF的所属组及优先级等信息。

## 注意事项

- **对系统的影响**：无。
- **命令生效条件**：执行该命令立即生效。
- **其他注意事项**：
  1. 如果修改NRF所属的Group，且旧Group被某个网元实例引用，则应该保证数据修改后旧Group下至少还剩下一个NRF，否则不能执行此操作。操作员可以先使用**LST NFSRV**命令查询旧Group是否被网元实例引用，若被引用，则执行**RMV NFSRV**删除该网元实例，然后执行**MOD NRFINFO**修改该NRF。
  2. 如果修改NRF的PRI（优先级），且修改后的NRF成为最高优先级，则**MOD NRFINFO**命令执行完成后，将会自动触发PCF注册到最高优先级的NRF上。

     举例：假设当前有NRF1（优先级为5）和NRF2（优先级为10）共两个NRF，此时PCF会优先向NRF1注册。若此时将NRF2的优先级由10修改为3，修改生效后，系统中NRF1（优先级为5），NRF2（优先级为3），此时会自动触发注册PCF注册到更高优先级的NRF2上。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                                                                                                                     |
|:-----------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NRFGROUP   | NRF所属组信息 | 可选必选说明：可选参数 参数含义：该参数仅用于PCF本端标识PCF当前注册的NRF所有组信息，该参数在执行ADD NFSRV命令进行NRF注册信息实例化时，用于关联目标NRF的URI、优先级等信息。 取值范围：长度不超过32的字符串，只允许输入：0～9，a～z，A～Z，“-”和“_”。 参数来源：该参数仅由本端PCF通过ADD NRFINFO命令自行定义并添加，可通过执行LST NRFINFO命令获取详细“NRF所属组信息”配置情况。 默认值：无。 配置原则：无。                               |
| NRFNAME    | NRF名称    | 可选必选说明：必选参数 参数含义：PCF在本端标识一条NRF数据记录的关键字段（其取值不能被修改），用于指定需要对哪一条NRF数据记录的参数进行修改或调整。 取值范围：长度不超过32的字符串，只允许输入：0～9，a～z，A～Z，“-”和“_”。 参数来源：该参数全局唯一且需PCF与NRF端协商获取此参数名。操作员可以使用LST NRFINFO命令查询获得。 默认值：无。 配置原则：无。                                                                       |
| NRFURI     | NRF URI  | 可选必选说明：可选参数 参数含义：用于标识NRF的URI。 取值范围：长度不超过128位的字符串，包含协议类型(http/https)、IP、端口等信息。举例：https://192.168.1.1:8080。 参数来源：该参数由待PCF发起注册的NRF端提供，全局规划，且唯一。 默认值：无。 配置原则：一般由NRF对端或运营商规划，需要NRF与PCF协商一致，若不一致，可能会导致PCF注册失败。                                                                 |
| PRI        | 优先级      | 可选必选说明：可选参数 参数含义：用于PCF本端标识NRF的优先级。PCF在注册时，优先向高优先级的NRF注册。由于在实际组网中会存在多个NRF的场景，PCF本端能通过标识可注册的不同NRF的优先级，便于PCF注册时，优先向高优先级的NRF注册。 取值范围：1～15 参数来源：该参数由运营商根据组网实际情况进行规划，该参数仅由PCF自行根据取值范围进行定义。 默认值：无。 配置原则： 同一个“NRF所属组信息”组内NRF的优先级不允许重复，反之，则会上报300012错误码。数字越大优先级越低。                |
| DURATION   | 超时时长     | 可选必选说明：可选参数 参数含义：该参与主要用于PCF主动通过心跳消息进行PCF与NRF之间链路状态探测时，本端自定义的一个超时时长参数。该参数用于标识PCF向NRF发送心跳请求消息时，对端NRF在正常时间段内没有回响应，那么超过正常回响应的时长即为超时时长。 取值范围：5～10 单位：秒（s）。 参数来源：该参数由本端通过ADD NRFINFO命令自行定义，可直接通过LST NRFINFO命令查询获取详细配置。 默认值：5。 配置原则：无。                                          |
| TIMES      | 失败次数     | 可选必选说明：可选参数 参数含义：用于标识PCF向NRF发起注册后，会主动通过心跳消息进行链路探测，当NRF响应PCF的心跳消息达到超时时长则PCF本地标记为一次响应失败，而此参数用于统计从NRF注册开始PCF累计的心跳消息的失败次数。 取值范围：3～10 默认值：3。 参数来源：该参数由本端通过ADD NRFINFO命令自行定义，可直接通过LST NRFINFO命令查询获取详细配置。 配置原则：无。  说明： 若PCF向NRF发送心跳消息的失败次数大于设定的次数时，PCF将上报“ALM-34226 NRF心跳故障”告警。 |
| ENCODETYPE | 编码方式     | 可选必选说明：可选参数 参数含义：用于标识PCF与NRF之间通信消息内容的编码方式。 取值范围： NULL(NULL)：表示不编码。GZIP(GZIP)：表示消息内容以GZIP格式压缩后再发送。 参数来源：该参数由本端通过ADD NRFINFO命令自行定义，可直接通过LST NRFINFO命令查询获取详细配置。 默认值：无。 配置原则：无。  说明： GZIP编码方式相比NULL编码方式能够在一定程度节省网元内存消耗。当PCF端选择GZIP编码方式时，要求NRF对端支持GZIP格式的解码能力。                |

## 使用实例

该命令仅用于除“NRF名称”参数外的其他参数修改场景（“NRF名称”参数修改请参见**RMV NRFINFO**配置示例），参数修改配置示例步骤如下：

1. 执行**MOD NRFINFO**命令修改错误配置记录之前，须先使用**LST NFSRV**命令查询NRF所属组被网元实例引用：

   ```
   %%LST NFSRV: NFTYPE=PCF;%% 
   RETCODE = 0  操作成功          
          网元实例名称  =  pcf-application-02
          网元实例标识  =  4947a69a-f61b-4bc1-b9da-47c9c5d14b66
         NRF所属组信息  =  nrfgroup-01
              网元类型  =  策略控制功能
              网元状态  =  正常工作状态
              配置方式  =  命令模式
            PLMN组名称  =  NULL
         S-NSSAI组名称  =  NULL
               NSI列表  =  NULL
                  位置  =  NULL
      网元公共信息标识  =  cominfo_01
          网元信息标识  =  NULL
        网元服务持续性  =  NULL
            网元服务组  =  NULL
    网元服务范围组名称  =  NULL
          上报网管标志  =  不上报网管
              更新方法  =  PUT更新
              心跳周期  =  0
          网元实例信息  =  NULL
    (结果个数 = 1)
     ---    END
   ```
2. 继续执行**LST NRFINFO**命令查询待修改的NRF注册信息中“NRF所属组信息”参数的取值，

   ```
   %%LST NRFINFO:;%% 
   RETCODE = 0  操作成功  
   操作结果如下 
   ------------ 
   NRF所属组信息  =  nrfgroup-01       
   NRF名称  =  nrf-01       
   NRF URI  =  https://192.168.1.1:8080        
   优先级  =  2      
   超时时长  =  5      
   失败次数  =  3 
   编码方式 = NULL
   (结果个数 = 1)  
   ---    END
   ```
3. 根据1，2步执行结果判断第1步的查询结果中的“NRF所属组信息”参数的取值是否与步骤2中查询“NRF所属组信息”参数的取值一致，
   - 若一致，请执行a，b两步完成NRF注册信息修改操作。
     1. 执行**RMV NFSRV**删除网元实例：

        ```
        %%RMV NFSRV: NFINSNAME="pcf-application-02";%% 
        RETCODE = 0  操作成功
        ---    END
        ```
     2. 执行**MOD NRFINFO**修改目标参数，如将**NRF所属组信息**参数由nrfgroup-01修改为nrfgroup-02：

        ```
        MOD NRFINFO: NRFNAME="nrf-01", NRFGROUP="nrfgroup-02";
        ```
   - 若不一致，执行**MOD NRFINFO**修改目标参数，如将**NRF所属组信息**参数由nrfgroup-01修改为nrfgroup-02：

     ```
     MOD NRFINFO: NRFNAME="nrf-01", NRFGROUP="nrfgroup-02";
     ```
4. 再次执行**LST NRFINFO**命令查询当前配置与其规划是否一致。

   ```
   %%LST NRFINFO:;%%
   RETCODE = 0  操作成功  
   操作结果如下 
   ------------
   NRF所属组信息  =  nrfgroup-02       
   NRF名称  =  nrf-01       
   NRF URI  =  https://192.168.1.1:8080        
   优先级  =  2      
   超时时长  =  5      
   失败次数  =  3 
   编码方式 = NULL
   (结果个数 = 1)  
   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                               | 原因分析                                                     | 处理建议                                                                            |
|-------:|:----------------------------------------------------|:---------------------------------------------------------|:--------------------------------------------------------------------------------|
|    505 | 当前操作的配置数据不存在                                        | “NRF名称”不存在。                                              | 使用LST NRFINFO命令查询并重新输入“NRF名称”，确保该“NRF名称”存在。                                     |
| 300010 | NRF URI取值无效                                         | “NRF URI”格式错误。                                           | 参考参数“NRF URI”的举例内容并重新输入“NRF URI”，确保格式正确。                                        |

|  58239 | VRM_MULTIPCFLOGICINSTSW取值为1时，NRFGROUP的取值不能为NULL字符串。 | 当“VRM_MULTIPCFLOGICINSTSW”取值为“1”时，“NRF所属组信息”的参数值为“NULL”。 | 请参考“NRF所属组信息”的取值范围重新输入，此时确保其参数值不为“NULL”。                                        |
