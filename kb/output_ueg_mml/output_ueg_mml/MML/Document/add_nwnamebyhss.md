# 增加不发送运营商名称的HSS(ADD NWNAMEBYHSS)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MME**

本命令用于增加不发送运营商名称的HSS。该命令对应的业务功能暂未实现。

#### 注意事项

- 该命令执行后立即生效。
- 此命令最大记录数为1000。
- 参数LABEL、HOST和REALM不区分大小写，统一转大写存储。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                               |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INDEX   | 索引     | 可选必选说明：必选参数 参数含义：该参数用于指定配置记录的索引。 数据来源：本端规划 取值范围：整数范围1~1000 默认值： 无 配置原则：无                                                                                                                                                           |
| SELMODE | 匹配模式   | 可选必选说明：必选参数 参数含义：该参数用于表示选择不发送运营商名称的HSS的匹配模式。 数据来源：全网规划 取值范围： “LABEL(标识)”：匹配HSS主机名标识的用户“HOST(主机名)”：匹配HSS主机名的用户“REALM(域名)”：匹配HSS域名的用户 默认值：无 配置原则：当用户能够匹配多条选择模式时，优先级顺序从高到低如下：LABEL(标识)、HOST(主机名)、REALM(域名)。                           |
| LABEL   | 标识     | 可选必选说明：条件必选参数 参数含义：该参数用于指定匹配用户的HSS网元标识的字符串。 前提条件：该参数在“匹配模式”设置为“LABEL(标识)”后生效。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～127。 默认值：无 配置原则： 该字符串应取值为HSS主机名的第一个label字符串中的子串。 输入字符串中不能含有非法字符，只允许输入字母，数字和“-”，不区分大小写。例如：UDMm、MHSS。不允许配置以“null”开头的字符串。 |
| HOST    | 主机名    | 可选必选说明：条件必选参数 参数含义：该参数用于指定用户的HSS的主机名。 前提条件：该参数在“匹配模式”设置为“HOST(主机名)”后生效。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～127。 默认值：无 配置原则： 不能为非法字符，只允许输入字母，数字，“.”和“-”。例如：hss.epc.mnc123.mcc123.3gppnetwork.org 不允许配置以“null”开头的字符串。                     |
| REALM   | 域名     | 可选必选说明：条件必选参数 参数含义：该参数用于指定用户的HSS的域名。 前提条件：该参数在“匹配模式”设置为“REALM(域名)”后生效。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～127。 默认值：无 配置原则： 不能为非法字符，只允许输入字母，数字，“.”和“-”。例如：epc.mnc123.mcc123.3gppnetwork.org 不允许配置以“null”开头的字符串。                          |

#### 使用实例

1、增加“匹配模式”为“LABEL(标识)”，HSS网元标识的字符串为“UDMm”的配置项。

ADD NWNAMEBYHSS: INDEX=1, SELMODE=LABEL, LABEL="UDMm";

2、增加“匹配模式”为“HOST(主机名)”，HSS主机名为“hss.epc.mnc123.mcc123.3gppnetwork.org”的配置项。

ADD NWNAMEBYHSS: INDEX=2, SELMODE=HOST, HOST="hss.epc.mnc123.mcc123.3gppnetwork.org";
