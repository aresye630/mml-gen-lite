# 增加默认PLMN（ADD DFTSRVNODEPLMN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C、GGSN**

该命令用于配置UNC设备默认的PLMN，PLMN由MCC（Mobile Country Code，移动国家代码）和MNC（Mobile Network Code，移动网络码）组成。

## 注意事项

- 该命令执行后立即生效。

- 在判断接入用户为拜访或者漫游用户时，通过IP映射的方式获取不到用户接入的对端PLMN标识时，会获取该命令配置的默认PLMN标识作为该IP对应的PLMN标识。

- 最多可输入3条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                        |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------|
| NODETYPE | 结点类型   | 可选必选说明：必选参数  参数含义：该参数用于指定网元类型。  数据来源：本端规划 取值范围： SGSN（SGSN）SGW（SGW）PGW（PGW）  默认值：无  配置原则：无                                                   |
| PLMNCODE | PLMN标识 | 可选必选说明：必选参数  参数含义：该参数用于指定PLMN标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是5~6。PLMN字符串的格式为长度5-6的MCC+MNC，MCC长度为3个字符，MNC长度为2或者3个字符。字符：0~9。  默认值：无  配置原则：无 |

## 使用实例

设置PGW默认所属的PLMN为46001（MCC=460, MNC=01）：

```
ADD DFTSRVNODEPLMN:NODETYPE=PGW,PLMNCODE="46001";
```
