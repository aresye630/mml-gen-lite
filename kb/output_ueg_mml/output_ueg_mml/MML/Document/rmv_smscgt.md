# 删除SMSC的GT（RMV SMSCGT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMSF**

该命令用于删除SMSC的GT。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                 |
|:-------|:--------|:-----------------------------------------------------------------------------------------------------|
| GT     | SMSC的GT | 可选必选说明：必选参数  参数含义：该参数用于表示SMSC的GT。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~20。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无 |

## 使用实例

当运营商希望删除SMSC的GT为“123456”的记录时，执行以下命令：

```
RMV SMSCGT: GT="123456";
```
