# 查询SGmb心跳配置。（LST SGMBHEARTBEATFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C**

该命令用来查询SGmb心跳配置。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询SGmb心跳配置：

```
LST SGMBHEARTBEATFUNC:;
```

## 输出结果说明

| 输出项名称     | 输出项解释                    |
|:----------|:-------------------------|
| 心跳配置开关    | 该参数用于设置SGmb心跳配置开关。       |
| 心跳重发间隔    | 该参数用于设置心跳重发间隔。           |
| 发送心跳消息的次数 | 该参数用于设置需要去活用户时所需的超时心跳次数。 |
| 去激活标志     | 该参数用于设置是否去活已激活的上下文。      |
