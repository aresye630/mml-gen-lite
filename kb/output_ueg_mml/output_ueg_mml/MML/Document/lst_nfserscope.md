# 查询服务范围配置信息(LST NFSERSCOPE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询网元服务范围配置信息。

- 若需要查询所有网元服务范围配置信息，不输入任何参数。
- 若需要查询某个组的网元服务范围配置信息，请输入“组名称”参数。
- 若需要查询某个网元服务范围配置信息，请输入“索引”参数。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                          |
|:---------|:-------|:------------------------------------------------------------------------------------------------------------------------------|
| GRPNAME  | 组名称    | 可选必选说明：可选参数 参数含义：用于指示系统按照组名称来查询网元服务范围配置信息；若不输入，则表示所有的组名称。 取值范围：由数字、字母、“-”或“_”组成的长度不超过32的字符串 默认值：无。 配置原则：无。                    |
| INDEX    | 索引     | 可选必选说明：可选参数 参数含义：用于指示系统按照索引来查询网元服务范围配置信息；若不输入，则表示所有的索引。 取值范围：1~1024 默认值：无。 配置原则：该参数在不同的组名称下可以重复，但和组名称组合以后成为全局唯一对象关键字段，组合不能重复。 |
| SERSCOPE | 服务范围   | 可选必选说明：可选参数 参数含义：用于指示系统按照服务范围来查询网元服务范围配置信息；若不输入，则表示所有的服务范围。 取值范围：长度不超过64的字符串 默认值：无。 配置原则：无。                                   |

## 使用实例

1. 查询所有的网元服务范围配置信息：

   ```
   LST NFSERSCOPE:;
   ```

   ```
   %%LST NFSERSCOPE:;%%
   RETCODE = 0  操作成功

   操作结果如下 
   ------------------------
   组名称      索引  服务范围     
   CHAR        4     CHAR        
   nfserscope  1     guangdong   

   (结果个数 = 2)   
   ---    END
   ```
2. 查询“组名称”为“nfserscope”的网元服务范围配置信息：

   ```
   LST NFSERSCOPE: GRPNAME="nfserscope";
   ```

   ```
   %%LST NFSERSCOPE: GRPNAME="nfserscope";%%
   RETCODE = 0  操作成功 
      
   操作结果如下 
   ------------------------
       组名称  =  nfserscope
         索引  =  1   
     服务范围  =  guangdong 
   (结果个数 = 1)  

   ---    END
   ```
3. 查询“索引”为“1”的网元服务范围配置信息：

   ```
   LST NFSERSCOPE: INDEX=1;
   ```

   ```
   %%LST NFSERSCOPE: INDEX=1;%%
   RETCODE = 0  操作成功

   操作结果如下 
   ------------------------
       组名称  =  nfserscope
         索引  =  1   
     服务范围  =  guangdong
    
   (结果个数 = 1)  

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD NFSERSCOPE**命令的参数说明。
