#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

此命令用来查询指定的CG组。

#### 注意事项

- 如果查询一个CG组，需要输入CG组的ID。
- 如果查询所有的CG组，则不需要输入参数。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                    |
|:--------|:-------|:----------------------------------------------------------------------------------------|
| CGGRPID | CG组ID  | 可选必选说明：可选参数 参数含义：CG组的ID。 数据来源：本端规划 取值范围：整数类型，取值范围为1～32。 默认值：无 配置原则：如果不输入该参数则是要查询所有的CG组。 |

#### 使用实例

查询所有的CG组：

```
LST CGGROUP:;
```

```
RETCODE = 0  操作成功。

CG组信息
--------------------
CG组ID  =  1
CG组描述  =  CGGroup1
(结果个数 = 1)
---END
```
