#### 命令功能

**适用网元：SGSN**

该命令用于查看2G寻呼配置参数。

#### 注意事项

- 不输入参数，表示查询所有参数。
- 输入参数“LAI”时，查询所有属于该LAI的参数。
- 输入参数“LAI”＋“RAC”，则查询由LAI和RAC唯一确定的参数。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称        | 参数说明                                                                                                                                      |
|:--------|:------------|:------------------------------------------------------------------------------------------------------------------------------------------|
| LAI     | 寻呼范围位置区标识   | 可选必选说明：可选参数 参数含义：该参数用于指定路由区所在的位置区标识，与RAC共同构成路由区标识。LAI = MNC + MCC + LAC。 数据来源：整网规划 取值范围：9~10位十六进制数 默认值：无                                  |
| RAC     | 寻呼范围路由区编码   | 可选必选说明：可选参数 参数含义：该参数用于指定路由区在位置区内的标识，与LAI共同构成路由区标识。 数据来源：整网规划 取值范围：0x00~0xFF 默认值：无 说明： RAC是十六进制数，占1个字节。                                    |
| RAITYPE | 寻呼范围路由区上报类型 | 可选必选说明：可选参数 参数含义：待查询的Gb模式路由区号测量对象的类型。 数据来源：整网规划 取值范围：“MANU(手动配置)”：通过ADD PERFGBPAGING命令创建的Gb模式路由区号对象。“AUTO(自动配置)”：系统动态上报的Gb模式路由区号对象。 默认值：无 |

#### 使用实例

查询Gb接口所有寻呼数据：

LST PERFGBPAGING:;

```
%%LST PERFGBPAGING:;%%
RETCODE = 0  操作成功。

操作结果如下
-------------------------
寻呼范围位置区标识    寻呼范围路由区编码    寻呼范围路由区上报类型    
123031111             0x02                  手动配置                        
123032111             0x01                  手动配置                 
(结果个数 = 2)
---    END
```

#### 输出结果说明

| 输出项名称     | 输出项解释                                            |
|:----------|:-------------------------------------------------|
| 寻呼范围位置区标识 | 路由区所在的位置区标识，与RAC共同构成路由区标识。LAI = MNC + MCC + LAC。 |
| 寻呼范围路由区编码 | 路由区在位置区内的标识，与LAI共同构成路由区标识。                       |
