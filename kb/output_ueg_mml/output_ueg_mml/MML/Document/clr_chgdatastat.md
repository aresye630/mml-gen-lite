# 清除计费数据统计信息（CLR CHGDATASTAT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于清除计费数据统计信息，比如预定义URR流量上报信息、UserProfile安装次数、整体转发和计费流量差异比例信息、缺省费率流量增量信息、子协议Top30的流量增量信息、预定义规则Top20的匹配次数增量信息、URR Top20的流量增量信息。

#### 注意事项

- 该命令执行后立即生效。
- 执行该命令后会清空已保存的统计数据，导致历史数据无法查询。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称            | 参数说明                                                                                                                                                                                                                                                                                             |
|:----------------|:----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| STATTYPE        | 统计类型            | 可选必选说明：必选参数 参数含义：该参数用于指定要显示计费数据的统计类型。 数据来源：本端规划 取值范围：ENUM。 UPINSTALL：查询UserProfile安装次数。URRVOLUME：查询URR流量统计信息。WHOLE_VOLUME_CONDITION：整体转发和计费流量差异比例信息。TOPN_URR_VOLUME：URR流量增量Top20信息。RULE_MATCH_NUM：预定义规则Top20的匹配次数增量信息。PROTOCOL_VOLUME：协议Top30的流量增量信息。DEFAULT_URR_VOLUME：缺省费率流量增量信息。 默认值：无 配置原则：无 |
| URRID           | URRID(Predef)   | 可选必选说明：条件可选参数 前提条件：该参数在“STATTYPE”配置为“URRVOLUME”时为可选参数。 参数含义：用于指示URR标识（预定义）。 数据来源：本端规划 取值范围：整数类型，取值范围为0～2147483646。 默认值：无 配置原则：无                                                                                                                                                                  |
| USERPROFILENAME | UserProfileName | 可选必选说明：条件可选参数 前提条件：该参数在“STATTYPE”配置为“UPINSTALL”时为可选参数。 参数含义：该参数用于指定用户模板名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1~63。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                                                                                           |

#### 使用实例

清除URR流量统计数据：

```
%%CLR CHGDATASTAT: STATTYPE=URRVOLUME;%%
RETCODE = 0  Operation succeeded
```
