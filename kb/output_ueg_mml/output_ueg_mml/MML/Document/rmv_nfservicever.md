# 删除NF服务版本信息（RMV NFSERVICEVER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、NSSF、NRF、SMSF、NCG、NEF、NWDAF、SCF**

该命令用于删除NF服务实例下的版本信息。当服务实例不再支持某个版本时，需要对版本信息进行删除。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称    | 参数说明                                                                                                                                                                                                                                      |
|:---------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCENAME | NF实例名称  | 可选必选说明：必选参数  参数含义：该参数用于指定NFS实例所归属的NF实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~50。  默认值：无  配置原则：  本参数需要与ADD NFUUID命令中的NFINSTANCENAME值保持一致。                                                                                                     |
| SRVINSTANCEID  | 服务实例标识  | 可选必选说明：必选参数  参数含义：本参数用于指定NFS实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~50。  默认值：无  配置原则：  本参数与ADD CPNFSERVICE命令中的SRVINSTANCEID值一致时生效。                                                                                                          |
| APIFULLVERSION | API版本信息 | 可选必选说明：必选参数  参数含义：本参数用于指定NFS的全量版本信息。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~50。  默认值：无  配置原则： 本参数的构成字符建议是字母A～Z或a～z、数字0～9、点“.”、加号“+”，和中划线“-”，例如1.0.0，1.0.0-alpha.1，3.0.1+orange.2020-09。此参数点分格式的第一段即为注册到NRF的API缩略版本信息，即例如此参数为1.0.0，则API缩略版本信息为v1。 |

## 使用实例

运营商A需要在NFINSTANCENAME为AMF\_Instance\_0,SRVINSTANCEID为Service\_Instance\_0的服务实例下删除1.0.0版本号。

```
RMV NFSERVICEVER:NFINSTANCENAME="AMF_Instance_0", SRVINSTANCEID="Service_Instance_0", APIFULLVERSION="1.0.0";
```
