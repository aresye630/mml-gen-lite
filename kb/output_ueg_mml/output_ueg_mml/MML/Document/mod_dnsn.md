# 修改DNS NAPTR记录(MOD DNSN)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

本次修改可能会更新本主机名的其他关联记录。

**适用网元：SGSN、MME**

该命令用于修改“FQDN”（全称标准规范域名）与网元接口的对应关系。

#### 注意事项

- 该命令执行后立即生效。
- 本次修改可能会更新本主机名的其他关联记录。

#### 本地用户权限

manage-ug

#### 网管用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识          | 参数名称              | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                  |
|:--------------|:------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FQDN          | FQDN              | 可选必选说明：必选参数 参数含义：该参数用于标识由RAI、TAI、APN、MME等构建的域名，用来进行网元查询。详见命令ADD DNSN。 数据来源：整网规划 取值范围：1~255位字符串 默认值：无  说明： 该参数同 “主机名索引”、“网元类型”、“接口类型”、“UE USAGE TYPE策略” 、“支持DCNR”、“融合PGW-C/SMF” 一起唯一确定一条记录，不能修改。FQDN不能以“.”开始，也不能以“.”结束。                                                                                                                                                                                                |
| HSINDEX       | 主机名索引             | 可选必选说明：必选参数 参数含义：该参数用于指定FQDN对应网元的索引。 数据来源：整网规划 取值范围：1~2048 默认值：无  说明： 该参数同 “FQDN”、“网元类型”、“接口类型”、“UE USAGE TYPE策略”、“支持DCNR”、“融合PGW-C/SMF” 一起唯一确定一条记录，不能修改。                                                                                                                                                                                                                                                             |
| ENTITY        | 网元类型              | 可选必选说明：必选参数 参数含义：该参数用来指定接口网元的类型。 数据来源：整网规划 取值范围：“SGSN(SGSN)”“GGSN(GGSN)”“MME(MME)”“SGW(SGW)”“PGW(PGW)”“MSC(MSC)”“IWS(IWS)”“AMF(AMF)” 默认值：无  说明： 该参数同 “FQDN”、“主机名索引”、“接口类型”、“UE USAGE TYPE策略” 、“支持DCNR”、“融合PGW-C/SMF”一起唯一确定一条记录，不能修改。                                                                                                                                                                                  |
| INTYPE        | 接口类型              | 可选必选说明：必选参数 参数含义：该参数用来指定网元对应的接口类型。 数据来源：整网规划 取值范围：“Gn(Gn)”“Gp(Gp)”“S3(S3)”“S4(S4)”“S5(S5)”“S8(S8)”“S10(S10)”“S11(S11)”“S16(S16)”“Sv(Sv)”“S102(S102)”“Sdup(Sdup)”“N26(N26)” 默认值：无  说明： 该参数同 “FQDN”、“主机名索引”、“网元类型”、“UE USAGE TYPE策略” 、“支持DCNR”、“融合PGW-C/SMF”一起唯一确定一条记录，不能修改。当该配置数据用于链式备份网元寻址时，需要选Sdup枚举，Sdup接口华为私有接口，是MME和MME之间的接口，用于实现MME间的数据备份。                                                                       |
| S5PROTOCOL    | S5接口协议类型          | 可选必选说明：可选参数 参数含义：该参数用来配置网元S-GW/P-GW的S5接口协议。 前提条件：该参数在“ENTITY”参数配置为“SGW”或“PGW”后为有效。 数据来源：整网规划 取值范围：“GTP(GTP)”“PMIP(PMIP)”“GTP_PMIP(GTP_PMIP)” 默认值：无                                                                                                                                                                                                                                                                    |
| S8PROTOCOL    | S8接口协议类型          | 可选必选说明：可选参数 参数含义：该参数用来配置网元S-GW/P-GW的S8接口协议。 前提条件：该参数在“ENTITY”参数配置为“SGW”或“PGW”后为有效。 数据来源：整网规划 取值范围：“GTP(GTP)”“PMIP(PMIP)”“GTP_PMIP(GTP_PMIP)” 默认值：无                                                                                                                                                                                                                                                                    |
| UEUSGTYPEPLCY | UE USAGE TYPE策略   | 可选必选说明：必选参数 参数含义：该参数用来指定专用核心网选择时，查询对应网关是否需要携带UE USAGE TYPE。 数据来源：全网规划 取值范围：“NO（否）”“YES（是）” 默认值：“无” 配置原则：当DECOR功能开启，需要通过UE USAGE TYPE进行DNS查询时，将此参数配置为“YES（是）”的DNS NAPTR记录。当前特性支持使用UE USAGE TYPE查询的网元包括MME，SGW和PGW。使用DECOR功能需要开启DECOR基础功能特性（特性编号：WSFD-208001，license部件编码：LKV2DECOR00）和DECOR特性（特性编号：WSFD-208002 ，license部件编码：LKV2DECOR01）。 说明： 该参数同 “FQDN”、“主机名索引”、“网元类型”、“接口类型” 、“支持DCNR”、“融合PGW-C/SMF”一起唯一确定一条记录，不能修改。 |
| UEUSGTYPEGPID | UE USAGE TYPE群组标识 | 可选必选说明：条件必选参数 参数含义：该参数用来指定UE USAGE TYPE群组标识。 前提条件：该参数在“UE USAGE TYPE策略”参数配置为“是”后生效。 数据来源：本端规划 取值范围：0~1023 默认值：无 配置原则：此参数已经通过ADD UEUSGTYPEGP进行UE Usage Type群组配置。                                                                                                                                                                                                                                                       |
| DCNR          | 支持DCNR            | 可选必选说明：必选参数 参数含义：该参数用于控制是否支持DCNR接入。 数据来源：全网规划 取值范围：“NO(否)”“YES(是)” 默认值：无  说明： 该参数同 “FQDN”、“主机名索引”、“网元类型”、“接口类型”、“UE USAGE TYPE策略”、“融合PGW-C/SMF”一起唯一确定一条记录，不能修改。                                                                                                                                                                                                                                                       |
| SMF           | 融合PGW-C/SMF       | 可选必选说明：必选参数 参数含义：该参数用于控制是否支持融合的PGW-C/SMF。 数据来源：整网规划 取值范围：“NO（否）”“YES（是）” 默认值：无 配置原则：该参数仅在“网元类型”配置为“PGW”时，才能配置为“YES”。  说明： 该参数同 “FQDN”、“主机名索引”、“网元类型”、“接口类型”、“UE USAGE TYPE策略”、“支持DCNR”一起唯一确定一条记录，不能修改。                                                                                                                                                                                                                |
| PRIORITY      | 优先级               | 可选必选说明：可选参数 参数含义：该参数用来指定接口网元对应的优先级。 数据来源：整网规划 取值范围：0~65535 默认值：无 配置原则：优先级数值配置越小，代表优先级越高。                                                                                                                                                                                                                                                                                                                              |
| WEIGHT        | 权重                | 可选必选说明：可选参数 参数含义：该参数用来指定接口网元对应的权重。 数据来源：整网规划 取值范围：0~65535 默认值：无 配置原则：权重数值配置越大，代表权重越大。                                                                                                                                                                                                                                                                                                                                 |
| DESC          | 描述                | 可选必选说明：可选参数 参数含义：该参数用于描述该命令的文字说明，目的是在配置的时候可以将对象属性、配置原因、背景等进行描述，以便在查询时能够在大量配置数据中清晰的掌握配置的原因。 数据来源：整网规划 取值范围：0~32位字符串 默认值：无                                                                                                                                                                                                                                                                                              |

#### 使用实例

修改FQDN为TAC-LB01.TAC-HB71.TAC.EPC.MNC001.MCC308.3GPPNETWORK.ORG，HSINDEX为100，网元类型为S-GW，接口类型为S11的一条NAPTR记录，将该记录接口协议类型修改为GTP\_PMIP，UE USAGE TYPE群组标识改为2，优先级修改为2，权重修改为50，描述为到华为的SGW01：

MOD DNSN: FQDN="TAC-LB01.TAC-HB71.TAC.EPC.MNC001.MCC308.3GPPNETWORK.ORG", HSINDEX=100, ENTITY=SGW, INTYPE=S11, S5PROTOCOL=GTP\_PMIP, S8PROTOCOL=GTP\_PMIP, UEUSGTYPEPLCY=YES, UEUSGTYPEGPID=2, DCNR=NO, SMF=NO, PRIORITY=2, WEIGHT=50, DESC="To huawei SGW01";
