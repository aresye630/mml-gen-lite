# 查询流量备份配置（LST TRAFFICBACKUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于查询流量备份配置的信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询流量备份配置：

```
LST TRAFFICBACKUP:;
```

```
RETCODE = 0  操作成功。

流量备份配置
------------
   流量备份开关  =  允许
备份间隔 (分钟)  =  30
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见SET TRAFFICBACKUP的参数说明。
