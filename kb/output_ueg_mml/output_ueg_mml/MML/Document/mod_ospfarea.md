# 修改OSPF区域配置（MOD OSPFAREA）

#### 命令功能

该命令用于修改OSPF进程下区域配置。

**须知** 

本命令属于高危命令，如果指定修改区域类型，可能会使此区域的OSPF邻接关系中断。

#### 注意事项

- 该命令执行后立即生效。
- 修改参数AREATYPE可能会使此区域的OSPF邻接关系中断。
- 只有配置了OSPF进程才能使用此命令。
- 如果AREATYPE为NSSA，则必须配置Loopback地址并在OSPF进程中发布出去，否则会造成负载分担不生效，极端情况下会造成业务受损。
- 当删除OSPF进程下最后一个普通区域（非Stub区域，非NSSA区域）时，在LSA洪泛区域中，本端路由器上的已经没用的Type-5 LSA会立即删除。但本端路由器仍会保留来自其他路由器的已经没用的Type-5 LSA，这些LSA必须等到老化时间到达3600秒后才会被删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

修改OSPF进程下1区域0.0.0.0的描述：

```
MOD OSPFAREA: PROCID=1, AREAID="0.0.0.0", DESCRIPTIONTEXT="HUAWEI";
```

#### 参考信息

OSPF采用分区域计算，将网络中所有OSPF路由器划分成不同的区域，每个区域负责各自区域精确的LSA传递与路由计算，然后再将一个区域的LSA简化和汇总之后转发到另外一个区域。
