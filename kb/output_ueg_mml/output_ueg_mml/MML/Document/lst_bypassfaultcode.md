# 查询BYPASS故障状态码（LST BYPASSFAULTCODE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF、SMF**

该命令用于查询BYPASS故障状态码。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                |
|:-------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PEERNFTYPE   | 对端网元类型 | 可选必选说明：可选参数  参数含义：该参数用于指定对端网元类型。  数据来源：全网规划 取值范围： “UDM（UDM）”：UDM“AUSF（AUSF）”：AUSF  默认值：无  配置原则：无                                                                                                                    |
| NFINSTANCEID | 网元实例标识 | 可选必选说明：可选参数  参数含义：该参数用于指定网元实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~36。  默认值：无  配置原则：  该参数只能由字母（A-Z或者a-z）、数字（0-9）、中划线（-）、下划线（_）组成或者配置为通配符（*）。该参数不区分大小写。配置为“*”时，表示针对所有的网元实例生效，如果用户所在的网元实例标识在配置表中无法匹配到对应的记录，则使用“*”对应的记录。 |

## 使用实例

若查询网元类型为UDM、网元实例标识为instanceid01的BYPASS故障状态码配置，执行如下命令：

```
%%LST BYPASSFAULTCODE: PEERNFTYPE=UDM, NFINSTANCEID="instanceid01";%%
RETCODE = 0  操作成功

结果如下
--------
 对端网元类型  =  UDM
 网元实例标识  =  instanceid01
 自定义故障码  =  504|509|602
     错误信息  =  NF_FAILOVER
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                             |
|:--------|:--------------------------------------------------|
| 对端网元类型  | 该参数用于指定对端网元类型。                                    |
| 网元实例标识  | 该参数用于指定网元实例标识。                                    |
| 自定义故障码  | 该参数用于指定自定义的对端网元故障状态码。                             |
| 错误信息    | 该参数用于指定自定义的故障码对应的Protocol or application Error信息。 |
