# 查询HLB系统软参(LST HLBSSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询HLB系统软件参数的配置信息。

- 若需要查询全部软参数据记录的概要信息，请不要输入任何参数。
- 若需要查询某条参数数据记录的详细信息，请输入“系统配置参数”和“参数名”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                   |
|:-------|:--------|:-------------------------------------------------------------------------------------------------------|
| SCP    | 系统配置参数  | 可选必选说明：可选参数 参数含义：用于指示系统按照系统配置参数来查询HLB系统软参；若不输入，则表示所有的系统配置参数。 默认值：无。 配置原则：无。                            |
| SPN    | 参数名     | 可选必选说明：可选参数 参数含义：用于指示系统按照参数名来查询HLB系统软参；若不输入，则表示所有的参数名。详细信息请参考产品手册的“UPCF软件参数 > HLB系统软参”。 默认值：无。 配置原则：无。 |
| SPV    | 参数值     | 可选必选说明：可选参数 参数含义：用于指示系统按照参数值来查询HLB系统软参；若不输入，则表示所有的参数值。详细信息请参考产品手册的“UPCF软件参数 > HLB系统软参”。 默认值：无。 配置原则：无。 |
| DFTV   | 软件参数默认值 | 可选必选说明：可选参数 参数含义：用于指示系统按照软件参数默认值来查询HLB系统软参；若不输入，则表示所有的软件参数默认值。 默认值：无。 配置原则：无。                          |

## 使用实例

1. 查询HLB服务全部软参配置信息。

   ```
   LST HLBSSP:;
   ```

   ```
   %%LST HLBSSP:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   系统配置参数  参数名                             参数值  软件参数默认值  

   系统参数      设备证书域名校验                   1       1               
   系统参数      HLB数字证书CRL处理策略             1       1               
   系统参数      HTTP2空闲拆链超时时间              1800    1800            
   系统参数      HTTP请求参数校验开关               0       0               
   系统参数      单个HLB和一个NF IP的最大链路数     0       0   
   系统参数      设置UPCF作为Consumer是否生成CCA    0       0 
   系统参数      设置UPCF作为Consumer时CCA的有效期  86400   86400 
   系统参数      设置UPCF作为Producer是否检查CCA    0       0
   系统参数      信令E2E跟踪功能开关    		 0       0  
   (结果个数 = 9)

   ---    END
   ```
2. 查询设备证书域名校验。“系统配置参数”为“SYSPARAMETER(系统参数)”，“参数名”为“VRM\_CHKCERTURL(设备证书域名校验)”。

   ```
   LST HLBSSP: SCP=SYSPARAMETER, SPN=VRM_CHKCERTURL;
   ```

   ```
   %%LST HLBSSP: SCP=SYSPARAMETER, SPN=VRM_CHKCERTURL;%%
   RETCODE = 0    操作成功

   操作结果如下:
   ------------
     系统配置参数 = 系统参数
           参数名 = 设备证书域名校验
           参数值 = 1
   软件参数默认值 = 1
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**MOD HLBSSP**命令的参数说明。
