#### 命令功能

**须知** 

该命令设置影响系统基本功能，请根据各参数联机帮助具体描述，谨慎执行。

**适用网元：SGSN、MME**

该命令用于设置系统的基本参数。

#### 注意事项

- 系统初次上电运行时，会执行系统初始设置值。
- 当本MME正在执行由**STR OFFLOADBYMME**或者**STR OFFLOADBYTA**命令启动的迁移任务时，禁止使用此命令修改本MME的“设备能力”为非零值，若需立即修改，可先执行**STP OFFLOAD**命令停止迁移任务。
- 当有eNodeB正在进行由**STR OFFLOADBYENODEB**启动的用户迁移时，执行此命令不会立即修改该eNodeB上本MME的“设备能力”，在迁移结束后，才会做修改。
- 此命令修改影响重大，请谨慎执行。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

| CAP           | 设备能力       | 可选必选说明：可选参数 参数含义：该参数用于指定MME负荷能力在MME Pool区中的相对权重值。 数据来源：整网规划 取值范围：0～255 系统初始设置值：“255”。 配置原则：当UNC支持MME POOL时，在启动迁移任务时，需将此参数设置为0，避免新用户进行接入；当迁移任务结束后，需要恢复MME原权重。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| TMSIALLOC     | TMSI资源分配方式 | 可选必选说明：可选参数 参数含义：该参数用于指定系统中PTMSI和GUTI的分配算法。其中非增强算法是指V100R002版本的算法；增强算法是指V100R017版本新增的算法，该算法用于提升用户标识的随机性和安全性。 数据来源：本端规划 取值范围： “ENHAN：（增强TMSI分配方式）”“UNENHAN：（非增强TMSI分配方式）” 系统初始设置值：“ENHAN（增强TMSI分配方式）” 配置原则：系统初始使用增强算法，一般情况下使用增强算法。只有当增强算法存在无法解决的问题时，才使用非增强算法。  说明： 该参数属于高危参数，TMSI分配算法修改后必须复位VNF才能生效。 链式备份功能开启时，不允许使用非增强TMSI分配方式。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| SUBSTORAG     | 签约数据存储     | 可选必选说明：可选参数 参数含义：该参数用于指定部分用户级GPRS签约数据和EPS签约数据在系统中的存储方式。支持该功能的字段包括：Subscriber-Status、Network-Access-Mode、Operator-Determined-Barring、HPLMN-ODB、Regional-Subscription-Zone-Code、Access-Restriction-Data、3GPP-Charging-Characteristics、Roaming-Restricted-Due-To-Unsupported-Feature。 数据来源：本端规划 取值范围： “MERGE(合并存储)”：使用同一字段存储。“SEPARATE(分开存储)”：使用不同字段存储。 系统初始设置值：“SEPARATE(分开存储)”。 配置原则： 当现网用户级GPRS签约数据和EPS签约数据不一致时，需要将本参数设置为"SEPARATE(分开存储)"。  说明： 本参数与软参DWORD_EX38 BIT25共同控制3GPP-Charging-Characteristics的存储方式。当本参数配置为“MERGE(合并存储)”并且DWORD_EX38 BIT25配置为0时，系统将GPRS和EPS签约数据的3GPP-Charging-Characteristics存储到同一字段，其他配置下，存储为不同字段。本参数从“MERGE(合并存储)”修改为“SEPARATE(分开存储)”后，分开存储方式对新接入的用户立即生效，对已经接入的用户在下次进行移动性管理流程时生效。本参数从“MERGE(合并存储)”修改为“SEPARATE(分开存储)”后，Gr和S6a/S6d接口的位置更新消息将会有所增加。本参数从“SEPARATE(分开存储)”修改为“MERGE(合并存储)”后，合并存储方式对新接入的用户立即生效，对已经接入的用户逐步生效，约在10分钟内可全部生效。 |
| VERINCS11FLAG | S11标识      | 可选必选说明：可选参数 参数说明：该参数用于指定S11标识 数据来源：本端规划 取值范围：1～7位字符串 系统初始设置值：INVALID                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| NRICLFLAG     | NRI容量限制开关  | 可选必选说明：可选参数 参数含义：该参数用于指定4G用户的接入是否受到NRI容量的限制。2G、3G用户的接入不受此参数控制，会受到NRI容量的限制。 数据来源：整网规划 取值范围： “ON(开启)”：4G用户的接入受到NRI容量的限制，参见ADD LOCALNRI命令参考信息。 “OFF(关闭)”：4G用户的接入不受NRI容量的限制。 系统初始设置值：“ON(开启)” 配置原则：建议值为“ON(开启)”。  说明： 本参数为高危参数，需要ADD LOCALNRI/RMV LOCALNRI命令配合使用，操作不当会导致用户无法正常接入，请谨慎使用并联系华为技术支持协助操作。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |

#### 使用实例

设置系统的名称为“UNC”，协议版本为R99：

SET CPSYS: NM="UNC", PROVER=R99;
