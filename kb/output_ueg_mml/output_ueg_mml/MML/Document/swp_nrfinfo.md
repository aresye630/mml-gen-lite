# 倒换NRF信息(SWP NRFINFO)

- 命令功能
- 注意事项

- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致系统异常，影响业务处理，需联系华为技术支持确认后再执行。

该命令用于倒换NRF信息。

**该命令的使用场景**：当软参“VRM\_NRFAUTOSWAPSWITCH（NRF自动倒换开关）”取值为“0”，同时UPCF注册到低优先级NRF时，需要执行该命令手动使UPCF向所属组最高优先级的NRF发起注册请求。如果该命令执行成功，则表示当前UPCF已经成功注册到最高优先级的NRF。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                          |
|:----------|:---------|:------------------------------------------------------------------------------------------------------------------------------|
| NRFGROUP  | NRF所属组信息 | 可选必选说明：必选参数 参数含义：用于PCF在本端标识系统需要按照哪个“NRF所属组信息”来倒换NRF信息。 取值范围：长度不超过32的字符串，只允许输入：0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。             |
| NFINSNAME | 网元实例名称   | 可选必选说明：可选参数 参数含义：用于标识需要倒换NRF的PCF实例名称。 取值范围：长度不超过32的字符串，只允许输入：0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：该参数必须先由ADD NFSRV命令定义，然后才能在此处引用。 |

## 使用实例

1. 倒换特定NRF信息，“NRF所属组信息”为“nrfgroup-01”，“网元实例名称”为“pcf-application-002”，执行结果为“成功”的场景：

   ```
   SWP NRFINFO: NRFGROUP="nrfgroup-01",NFINSNAME="pcf-application-002";
   ```

   ```
   %%SWP NRFINFO: NRFGROUP="nrfgroup-01",NFINSNAME="pcf-application-002";%% 
   RETCODE = 0  操作成功  

   操作结果如下 
   - - - - - -
   执行结果  =  成功 
   (结果个数 = 1)  

   ---    END
   ```
2. 倒换特定NRF信息，“NRF所属组信息”为“nrfgroup-01”，“网元实例名称”为“pcf-application-002”，执行结果为“只有一个NRFINFO”的场景：

   ```
   SWP NRFINFO: NRFGROUP="nrfgroup-01",NFINSNAME="pcf-application-002";
   ```

   ```
   %%SWP NRFINFO: NRFGROUP="nrfgroup-01",NFINSNAME="pcf-application-002";%% 
   RETCODE = 0  操作成功  

   操作结果如下 
   - - - - - -
   执行结果  =  只有一个NRFINFO 
   (结果个数 = 1)  

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。输出项说明如表1所示。

| 输出项名称   | 输出项解释                                                                                                                        |
|:--------|:-----------------------------------------------------------------------------------------------------------------------------|
| 执行结果    | 用于返回执行SWP NRFINFO命令成功后返回的提示信息： 成功只有一个NRFINFO未配置NFSRVPCF实例未注册成功已经注册到最高优先级的NRF上一个SWP NRFINFO触发的倒换流程还未结束倒换时长超过3分钟到最高优先级的NRF注册失败 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释                                        | 原因分析                                                 | 处理建议                                                 |
|------:|:---------------------------------------------|:-----------------------------------------------------|:-----------------------------------------------------|
| 58218 | 指定的网元实例名称未关联指定的NRF所属组。                       | 指定的网元实例名称未关联指定的NRF所属组。                               | 根据指定的“网元实例名称”执行LST NFSRV，获取报文结果“NRF所属组信息”，然后重新执行本命令。 |
| 58240 | VRM_MULTIPCFLOGICINSTSW=1时，NFINSNAME参数值不能为空。 | 当“VRM_MULTIPCFLOGICINSTSW”为“1”时，执行本命令的“网元实例名称”参数值为空。 | 请重新输入的“网元实例名称”参数值后再重新执行本命令，确保其值不为空。                  |
