# 添加基于NG-RAN的定位去使能开关（ADD LCSPOSDEANRSW）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于添加基于NG-RAN的LMF消息控制配置。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为100。
- 新增基站标识段时，基站起始标识，基站结束标识范围不能与已有的基站标识段范围重叠。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称                           | 参数说明                                                                                                            |
|:---------------|:-------------------------------|:----------------------------------------------------------------------------------------------------------------|
| NGRANIDSEGNAME | 基站标识段名称                        | 可选必选说明：必选参数 参数含义：该参数用于指定基站标识段名称。 数据来源：全网规划 取值范围：字符串类型，不区分大小写，不能包含空格，输入长度范围为1～31。 默认值：无 配置原则：无                   |
| NGRANIDSTART   | 基站起始标识                         | 可选必选说明：必选参数 参数含义：该参数用于配置基站起始标识。 数据来源：全网规划 取值范围：整型数字类型，取值范围为0~4294967295。 默认值：无 配置原则：无                           |
| NGRANIDEND     | 基站结束标识                         | 可选必选说明：必选参数 参数含义：该参数用于配置基站结束标识。 数据来源：全网规划 取值范围：整型数字类型，取值范围为0~4294967295。 默认值：无 配置原则：无                           |
| LMFPOSDEASW    | 发送Positioning Deactivation消息开关 | 可选必选说明：必选参数 参数含义：该参数用于配置是否发送Positioning Deactivation消息。 数据来源：全网规划 取值范围： DISABLE：开关去使能。ENABLE：开关使能。 默认值：无 配置原则：无 |

#### 使用实例

新增基站起始标识、基站结束标识和设置发送Positioning Deactivation消息开关打开：

```
ADD LCSPOSDEANRSW: NGRANIDSEGNAME="1", NGRANIDSTART=1, NGRANIDEND=2, LMFPOSDEASW=ENABLE;
```
