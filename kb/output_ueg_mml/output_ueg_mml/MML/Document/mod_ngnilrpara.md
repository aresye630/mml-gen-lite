# 修改NI-LR功能参数（MOD NGNILRPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于基于运营商修改NI-LR功能的参数。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称           | 参数说明                                                                                                                                                                                                                                                                                          |
|:------------|:---------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NOID        | 运营商标识          | 可选必选说明：必选参数  参数含义：该参数用于在UNC系统内唯一标识移动网络运营商。  数据来源：全网规划  取值范围：整数类型，取值范围为0。  默认值：无  配置原则：  该参数取值必须和ADD NGMNO中配置的“NOID”参数取值相同。                                                                                                                                                                    |
| NILR        | 是否允许网络触发定位功能   | 可选必选说明：必选参数  参数含义：该参数用于AMF控制紧急呼叫场景是否发起定位流程。  数据来源：全网规划 取值范围： “YES（是）”：是“NO（否）”：否  默认值：无  配置原则：  如果运营商需要开启紧急呼叫定位流程，则需要设置该参数为“YES”；。                                                                                                                                                            |
| NILRPLCY    | 网络触发的定位策略      | 可选必选说明：可选参数  参数含义：该参数用于AMF配置紧急呼叫场景的定位策略。  数据来源：全网规划 取值范围： “PROTOCOL_POSITION（协议模式定位）”：协议模式定位“NO_LMF_POSITION（无LMF定位）”：无LMF的定位  默认值：无  配置原则：  当取值为“PROTOCOL_POSITION（协议模式定位）”时，系统按照3GPP协议定义的标准规范进行LCS定位。  当取值为“NO_LMF_POSITION(无LMF定位)”时，适用于没有部署LMF网元场景的LCS定位。此种策略下定位上报结果是NCGI信息而不是经纬度信息，精度较低。 |
| RLSRPT      | 紧急呼叫释放是否上报位置   | 可选必选说明：可选参数  参数含义：该参数用于AMF控制紧急呼叫释放场景是否上报位置。  数据来源：全网规划 取值范围： “YES（是）”：是“NO（否）”：否  默认值：无  配置原则：  如果运营商期望AMF在紧急呼叫释放流程向GMLC上报用户的位置信息，则将该参数设置为“YES”。                                                                                                                                              |
| HA          | 水平精度           | 可选必选说明：可选参数  参数含义：该参数用于AMF配置定位请求的水平精度。  数据来源：全网规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：  根据协议3GPP TS 23.032 V15.1.0，水平距离r（米）和K（水平精度）之间的关系为r = 10 * (1.1K - 1)。例如，当K设置为19时，r的取值为51米。                                                                                                     |
| RESPTIME    | 响应时间           | 可选必选说明：可选参数  参数含义：该参数用于AMF配置定位请求消息的Response Time。  数据来源：全网规划 取值范围： “LOW_DELAY（低时延）”：低时延“DELAY_TOLERANT（时延可接受）”：时延可接受  默认值：无  配置原则：无                                                                                                                                                           |
| GMLCRESEND  | 是否对GMLC进行重发    | 可选必选说明：可选参数  参数含义：该参数用于指定AMF在NI-LR定位释放流程中，当AMF向GMLC发送Namf_Location_EventNotify Request消息，且GMLC返回5xx原因值时，AMF是否向该GMLC重发1次业务请求。  数据来源：本端规划 取值范围： “YES（是）”：是“NO（否）”：否  默认值：无  配置原则：无                                                                                                              |
| GMLCRESEL   | 是否重选GMLC       | 可选必选说明：可选参数  参数含义：该参数用于指定当AMF在NI-LR定位触发位置上报流程中，当首次交互的GMLC返回5xx时，AMF是否重新选择新的GMLC进行业务请求。  数据来源：本端规划 取值范围： “YES（是）”：是“NO（否）”：否  默认值：无  配置原则：无                                                                                                                                                    |
| HORPT       | 紧急会话切换的位置连续性开关 | 可选必选说明：可选参数  参数含义：该参数用于控制AMF是否支持紧急会话切换的位置连续性。  数据来源：全网规划 取值范围： “YES（是）”：是“NO（否）”：否  默认值：无  配置原则：  运营商期望AMF在紧急呼叫切换流程向GMLC上报用户的位置信息，则将该参数设置为“YES”。  用户发生切换流程，若期望由源侧AMF/MME上报紧急呼叫切换通知，则将“HORPTTYPE”配置成“SOURCE”；若期望由目标AMF/MME上报紧急呼叫切换通知，则将“HORPTTYPE”配置成“TARGET”。                                 |
| HORPTTYPE   | 切换上报类型         | 可选必选说明：该参数在"HORPT"配置为"YES"时为条件必选参数。  参数含义：该参数用于控制切换流程中由源侧AMF/MME还是目标侧AMF/MME上报切换通知信息。 对于Intra AMF N2切换流程，不受本参数控制。  数据来源：全网规划 取值范围： “SOURCE（源侧上报）”：由源侧AMF/MME上报“TARGET（目标侧上报）”：由目标侧AMF/MME上报  默认值：无  配置原则：  协议规定源侧或者目标侧只能有一侧进行上报，该参数在整网AMF/MME中需要配置一致。MME的配置请参考ADD LCSPARAEX命令的“HORPTTYPE”参数。  |
| LCSQOSCLASS | LCS QoS Class  | 可选必选说明：可选参数  参数含义：该参数用于配置AMF定位请求是否携带lcsQosClass。  数据来源：全网规划 取值范围： INVALID（无效值）BESTEFFORT（尽力而为类）ASSURED（保证类）MULTIPLEQOS（多QoS类）  默认值：无  配置原则：无                                                                                                                                                  |
| DESC        | 描述信息           | 可选必选说明：可选参数  参数含义：该参数用于设置NI-LR参数的描述信息。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~32。  默认值：无  配置原则：无                                                                                                                                                                                                     |

## 使用实例

关闭NOID为0的运营商的NI-LR功能，执行如下命令：

```
MOD NGNILRPARA: NOID=0, NILR=NO;
```
