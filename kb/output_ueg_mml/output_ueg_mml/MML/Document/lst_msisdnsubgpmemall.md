# 查询所有MSISDN用户群成员（LST MSISDNSUBGPMEMALL）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

本命令用于查询所有MSISDN用户群成员。

#### 注意事项

- 该命令执行后立即生效。
- 本命令在导航树不显示，仅可批量执行。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询所有MSISDN用户群成员。

```
%%LST MSISDNSUBGPMEMALL:;%%
```
