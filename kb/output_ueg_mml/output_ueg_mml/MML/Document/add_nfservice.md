## 命令功能

**须知** 

此命令配置有风险，HTTP协议不安全，推荐使用安全的HTTPS协议进行对接。

该命令用于增加网元的服务信息，当系统向NRF发起服务注册时，NFService包含该命令中配置的信息。

该命令的参数索引关系如图1所示。

**图1** 命令参数的索引关系图

## 注意事项

- 同一“组名称”的服务类型，要属于同一种网元类型。
- 同一“组名称”下新增服务类型，如果“组名称”已在NRF中注册，则需要发送更新请求到NRF，按照**ADD NFSRV**命令中指定的更新模式60秒内发送Nnrf\_NFManagement\_NFUpdate Request消息请求更新。

## 参数说明

| 参数标识            | 参数名称      | 参数说明                                                                                                                                                                                                                                                               |
|:----------------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GRPNAME         | 组名称       | 可选必选说明：必选参数 参数含义：用于标识已全部信息所属组的名称。 取值范围：长度不超过32位的字符串，字符串由数字、字母、“-”或“_”组成。 默认值：无。 配置原则： 若该“组名称”不存在，则创建该组名称。该参数配置时不能取值为“NULL”，否则无法被正常索引。                                                                                                                              |
| SERVICEID       | 服务标识      | 可选必选说明：必选参数 参数含义：用于标识网元服务信息标识。 取值范围：长度不超过32位的字符串，字符串由数字、字母、“-”或“_”组成。 默认值：无。 配置原则：该参数网元内唯一，不能重复。                                                                                                                                                                   |
| SERVICEINSTID   | 服务实例标识    | 可选必选说明：必选参数 参数含义：用于标识网元服务实例在系统中的序号，该参数为UUIDv4格式。 UUIDv4格式为“xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx”，例如：4947a69a-f61b-4bc1-b9da-47c9c5d14b64。 取值范围：有效的UUIDv4格式，只允许输入0～9，a～f，A～F，“-”。 默认值：无。 配置原则：无。                                                                    |
| SERVICENAME     | 服务名称      | 可选必选说明：必选参数 参数含义：用于标识网元服务名称。 取值范围：npcf-am-policy-control(PCF AM策略控制服务)npcf-smpolicycontrol(PCF SM策略控制服务)npcf-policyauthorization(PCF SM策略鉴权服务)npcf-bdtpolicycontrol(PCF BDT策略控制服务)npcf-eventexposure(PCF事件发布服务)npcf-ue-policy-control(PCF UE策略控制服务) 默认值：无。 配置原则：无。 |
| NFSRVVERGRP     | 服务版本组名称   | 可选必选说明：必选参数 参数含义：用于标识网元服务的服务版本组名称。 取值范围：由数字、字母、“-”或“_”组成的长度不超过32的字符串 默认值：无。 配置原则：该参数必须先由ADD NFSRVVER命令中的参数“组名称”定义，然后才能在此处引用。                                                                                                                                       |
| SCHEME          | 方案        | 可选必选说明：必选参数 参数含义：用于标识该网元支持的协议类型。 取值范围：http(http)https(https) 默认值：https(https) 配置原则：无。                                                                                                                                                                              |
| STATUS          | 状态        | 可选必选说明：必选参数 参数含义：用于标识该网元的工作状态。 取值范围：REGISTERED(正常工作状态)SUSPENDED(服务暂停状态) 默认值：REGISTERED(正常工作状态) 配置原则：无。                                                                                                                                                             |
| APIPREFIX       | API前缀     | 可选必选说明：可选参数 参数含义：用于标识网元服务的API前缀。 取值范围：长度不超过512位的URL格式，包含协议类型(http/https)、域名/IP、端口(可选)等信息。 默认值：无。 配置原则：无。                                                                                                                                                           |
| NFNOTIFSUBGRP   | 默认通知订阅组名称 | 可选必选说明：可选参数 参数含义：用于标识网元服务的默认订阅通知组名称。 取值范围：由数字、字母、“-”或“_”组成的长度不超过32的字符串 默认值：无。 配置原则：该参数必须先由ADD NFNOTIFSUB命令中的参数“组名称”定义，然后才能在此处引用。                                                                                                                                   |
| NFCOMINFOID     | 网元公共信息标识  | 可选必选说明：可选参数 参数含义：用于标识网元公共信息标识。 取值范围：长度不超过32位的字符串，字符串由数字、字母、“-”或“_”组成 默认值：无。 配置原则：该参数必须先由ADD NFCOMINFO命令定义，然后才能在此处引用。                                                                                                                                               |
| SUPPORTFEATURES | 支持特性      | 可选必选说明：可选参数 参数含义：用于标识API所支持的功能特性。 取值范围：长度不超过1024位的十六进制数字组成的字符串，只允许输入0～9，a～f，A～F。 默认值：无。 配置原则：无。                                                                                                                                                                    |

## 使用实例

增加一条网元服务信息。“组名称”为“srvgrp1”，“服务标识”为“srv1”，“服务实例标识”为“4947a69a-f61b-4bc1-b9da-47c9c5d14b64”，“服务名称”为“npcf-am-policy-control(PCF AM策略控制服务)”，“服务版本组名称”为“srvver-group-01”，“方案”为“https(https)”，“状态”为“REGISTERED(正常工作状态)”，“默认通知订阅组名称”为“notifsub-group-01”，“网元公共信息标识”为“cominfo\_01”，“支持特性”为“001”：

```
ADD NFSERVICE: GRPNAME="srvgrp1", SERVICEID="srv1", SERVICEINSTID="4947a69a-f61b-4bc1-b9da-47c9c5d14b64", SERVICENAME=npcf-am-policy-control, NFSRVVERGRP="srvver-group-01", SCHEME=https, STATUS=REGISTERED, NFNOTIFSUBGRP="notifsub-group-01", NFCOMINFOID="cominfo_01", SUPPORTFEATURES="001";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                | 原因分析                                      | 处理建议                                                                                                                                                                |
|-------:|:---------------------|:------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|    503 | 配置数据已存在              | 数据库中已有相同“服务标识”配置。                         | 使用LST NFSERVICE命令查询并重新输入“服务标识”，确保其值不存在。                                                                                                                             |
|  58092 | 同一服务组中，服务实例标识存在冲突。   | 输入的“服务实例标识”参数值与同一服务组中的其他服务实例标识重复。         | 通过LST NFSERVICE命令查询“服务实例标识”。重新执行该命令，输入“服务实例标识”，确保输入的“服务实例标识”与1中查询结果不一样。                                                                                             |
| 360041 | 参数值不合法               | 界面输入的参数不在相应的参数取值范围内。                      | 重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                                                           |
| 360043 | 参数值未配置               | 输入的“服务版本组名称”、“默认通知订阅组名称”或“网元公共信息标识”参数未定义。 | 根据实际情况，重新输入参数，确保输入的“服务版本组名称”、“默认通知订阅组名称”或“网元公共信息标识”参数已定义。 可通过LST NFSRVVER命令查询已定义的“服务版本组名称”。可通过LST NFNOTIFSUB命令查询已定义的“默认通知订阅组名称”。可通过LST NFCOMINFO命令查询已定义的“网元公共信息标识”。 |
| 360047 | 同一服务组中，服务名称必须为同一网元类型 | 同一“服务组”中增加的数据记录中的参数“服务名称”不属于同一个网元类型。      | 根据实际情况，重新输入参数，确保同一“服务组”中增加的数据记录中的参数“服务名称”属于同一个网元类型，可通过LST NFSERVICE查询已存在的网元服务数据记录。                                                                                  |
|  57947 | 服务名称已存在              | 相同“组名称”下不允许添加相同的“服务名称”。                   | 根据“组名称”执行LST NFSERVICE命令，查看报文结果“服务名称”。重新输入该参数后执行本命令。                                                                                                                |
