# 设置CHR输出策略(SET PCFCHRPLCY)

## 命令功能

**须知** 

此命令是高危命令，打开CHR功能会导致系统性能下降，建议只配置记录失败的CHR，配置记录成功的CHR需要经过评估后开启。

该命令用于设置呼叫Rx会话和注册Rx会话的CHR（Call History Record）单据输出策略。

该命令的使用场景：VoLTE场景下，在使用CHR单据实现故障定位时，管理员可以执行本命令设置呼叫Rx会话和注册Rx会话的CHR单据输出场景，缩小问题定位范围。

## 注意事项

数据库中最多有一条配置记录，当数据库中已经存在配置记录时，此命令的执行会修改原来的配置信息。

## 参数说明

| 参数ID        | 参数名称      | 参数描述                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
|:------------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ID          | ID        | 可选必选说明：必选参数 参数含义：用于指定一条CHR单据输出策略配置记录，因为只有一条记录，此属性的值只能为1。 取值范围：1 默认值：1 配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| REGCHRPLCY  | 注册CHR输出策略 | 可选必选说明：可选参数 参数含义：指定要输出CHR单据的注册Rx会话场景。 取值范围： “全部选中”：表示所有Rx注册会话场景都要输出CHR单据。“全部清空”：表示所有Rx注册会话场景都不输出CHR单据。“全部灰化”：用于同时灰化所有输出CHR单据的Rx注册会话场景。灰化掉的参数在执行SET CHRPLCY命令时不被修改，若只需修改某一项，而其它几项保持不变，可以将其它不用修改的选项灰化。例如：仅“FAILEDREG(失败的注册会话)”场景下输出CHR单据，“SUCCESSREG(成功的注册会话)”、“REGUPDATE(注册会话主动更新)”、“REGTERM(注册会话正常终止)”和“REGABNORMAL(注册会话异常终止)”场景维持现状，可以先选中全部灰化，然后将“FAILEDREG(失败的注册会话)”去勾选，这种方式比一项项勾选更加便捷。SUCCESSREG(成功的注册会话)：表示AF向UPCF发送AAR消息用于建立/更新注册Rx会话，UPCF向AF返回成功AAA消息时输出CHR单据。FAILEDREG(失败的注册会话)：表示AF向UPCF发送AAR消息用于建立/更新注册Rx会话，UPCF向AF返回失败AAA消息时输出CHR单据。REGUPDATE(注册会话主动更新)：表示UPCF向AF主动发送RAR消息用于更新注册Rx会话时输出CHR单据。REGTERM(注册会话正常终止)：表示用户注册Rx会话正常结束，AF向UPCF发送STR消息用于终止注册Rx会话时输出CHR单据。REGABNORMAL(注册会话异常终止)：表示用户注册Rx会话异常终止，AF向UPCF发送ASR消息用于终止注册Rx会话时输出CHR单据。 默认值：无 配置原则：无             |
| CALLCHRPLCY | 呼叫CHR输出策略 | 可选必选说明：可选参数 参数含义：用于指定输出CHR单据的呼叫Rx会话场景。 取值范围： “全部选中”：表示所有呼叫Rx会话场景都要输出CHR单据。“全部清空”：表示所有呼叫Rx会话场景都不输出CHR单据。“全部灰化”：用于同时灰化所有输出CHR单据的呼叫Rx会话场景。灰化掉的参数在执行SET CHRPLCY命令时不被修改，若只需修改某一项，而其它几项保持不变，可以将其它不用修改的选项灰化。例如：仅“FAILEDCALL(失败的呼叫会话)”场景下输出CHR单据，“SUCCESSCALL(成功的呼叫会话)”、“CALLUPDATE(呼叫会话主动更新)”、“CALLTERM(呼叫会话正常终止)”和“CALLABNORMAL(呼叫会话异常终止)”场景维持现状，可以先选中全部灰化，然后将“FAILEDCALL(失败的呼叫会话)”去勾选，这种方式比一项项勾选更加便捷。SUCCESSCALL(成功的呼叫会话)：表示AF向UPCF发送AAR消息用于建立/更新呼叫Rx会话，UPCF向AF返回成功AAA消息时输出CHR单据。FAILEDCALL(失败的呼叫会话)：表示AF向UPCF发送AAR消息用于建立/更新呼叫Rx会话，UPCF向AF返回失败AAA消息时输出CHR单据。CALLUPDATE(呼叫会话主动更新)：表示UPCF向AF主动发送RAR消息用于更新呼叫Rx会话时输出CHR单据。CALLTERM(呼叫会话正常终止)：表示用户呼叫Rx会话正常结束，AF向UPCF发送STR消息用于终止呼叫Rx会话时输出CHR单据。CALLABNORMAL(呼叫会话异常终止)：表示用户呼叫Rx会话异常终止，AF向UPCF发送ASR消息用于终止呼叫Rx会话时输出CHR单据。 默认值：无 配置原则：无 |

## 使用实例

设置CHR输出策略，“注册CHR输出策略”为“FAILEDREG(失败的注册会话)”，“呼叫CHR输出策略”为“FAILEDCALL(失败的呼叫会话)”，命令如下：

```
SET PCFCHRPLCY: ID=1, REGCHRPLCY=FAILEDREG, CALLCHRPLCY=FAILEDCALL;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释              | 原因分析                                    | 处理建议                                         |
|------:|:-------------------|:----------------------------------------|:---------------------------------------------|
| 57805 | 配置未修改，请至少指定一个设置参数。 | 设置该命令时，“注册CHR输出策略”和“呼叫CHR输出策略”参数均未携带取值。 | 设置该命令时，“注册CHR输出策略”和“呼叫CHR输出策略”参数至少有一个需要携带取值。 |
