# 修改I-SMF支持的DNAI（MOD ISMFDNAI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于修改I-SMF支持的DNAI。

## 注意事项

该命令执行后只对新接入该设备且把该设备作为I-SMF的PDU会话生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称              | 参数说明                                                                                                                                                                                                                                                     |
|:----------------|:------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DNAI            | 数据网络访问标识符         | 可选必选说明：必选参数  参数含义：该参数用于指定I-SMF支持的DNAI。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。不支持空格，不区分大小写。  默认值：无  配置原则：无                                                                                                                                                   |
| DNAITYPE        | DNAI类型            | 可选必选说明：可选参数  参数含义：该参数用于指定DNAI的类型。  数据来源：全网规划 取值范围： DNN_LEVEL（DNN级别）GLOBAL_LEVEL（整系统级别）  默认值：无  配置原则：无                                                                                                                                                    |
| DNN             | DNN               | 可选必选说明：该参数在"DNAITYPE"配置为"DNN_LEVEL"时为条件必选参数。  参数含义：该参数用于指定该DNAI关联的DNN，即用户请求的DNN。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无  配置原则：无 |
| AUXDNAISELECTSW | 仅使用DNAI查询辅锚点的控制开关 | 可选必选说明：可选参数  参数含义：该参数用于控制基于当前DNAI查询辅锚点时，是否支持仅使用DNAI来查询。该开关开启时，I-SMF查询辅锚点时，仅使用该DNAI来查询。开关关闭时，I-SMF查询辅锚点时，使用DNN+DNAI来查询。  数据来源：全网规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无  配置原则：  I-SMF开启仅使用DNAI来查询辅锚点功能，需要端到端规划。该功能当前仅支持测试。                                 |

## 使用实例

将DNAI为“huawei.com.dnai”,DNAITYPE为DNN\_LEVEL的I-SMF DNAI，修改为GLOBAL\_LEVEL的DNAI，执行如下命令：

```
MOD ISMFDNAI: DNAI="huawei.com.dnai", DNAITYPE=GLOBAL_LEVEL, AUXDNAISELECTSW=ENABLE;
```
