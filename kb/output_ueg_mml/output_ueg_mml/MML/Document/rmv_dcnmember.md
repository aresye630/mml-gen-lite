# 删除DCN成员(RMV DCNMEMBER)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于删除指定DCN下的MME组成员。删除后，当专用核心网重选时，DCN将不能重选至被删除的MME组。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                            |
|:-------|:--------|:--------------------------------------------------------------------------------|
| DCNID  | DCN ID  | 可选必选说明：必选参数 参数含义：该参数用来指定DCN标识。 数据来源：全网规划 取值范围：0~255 默认值：无                       |
| MMEGI  | MME组识别码 | 可选必选说明：必选参数 参数含义：该参数用于配置指定DCN的MME组。 数据来源：全网规划 取值范围：4位16进制编码，范围为0000~FFFF。 默认值：无 |

#### 使用实例

运营商调整规划不再将“MMEGI”为“A1B3”的MME组成员划分到“DCN ID”为“0”的DCN下：

RMV DCNMEMBER: DCNID=0, MMEGI="A1B3";
