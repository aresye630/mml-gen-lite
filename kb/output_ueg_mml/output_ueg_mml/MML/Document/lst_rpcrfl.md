# 查询PCRF容灾PCRF链路配置信息(LST RPCRFL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护命令，用于查询PCRF实体和容灾PCRF实体的链路配置信息：

- 如果需要查询全部容灾PCRF实体的链路配置信息，请不要输入任何参数。
- 如果需要查询某个容灾PCRF实体的链路配置信息，请依据参数说明输入相应的参数作为查询的限制条件。

## 注意事项

IPv6类型的IP地址不支持混合方式表达，即xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:d.d.d.d，其中x表示一个十六进制数（0～9或A～F），而d.d.d.d表示一个IPv4地址。

## 参数说明

| 参数标识      | 参数名称        | 参数说明                                                                                                                                                                                                                                                                      |
|:----------|:------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PCRFID    | 本端PCRF标识    | 用于标识PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围：1 默认值：无。                                                                                                                                                                                                                   |
| RPCRFID   | 容灾PCRF标识    | 用于指定一个容灾PCRF实体，该参数必须先由ADD RPCRF命令定义，然后才能在此处索引。 取值范围：0～5 默认值：无。                                                                                                                                                                                                            |
| LNKID     | 链路标识        | 用于在UPCF的配置库中定义一个容灾PCRF实体链路。 取值范围：0～65 默认值：无。  说明： 当本地PCRF的工作模式为 “服务端”时，执行本命令时“链路标识”支持配置的最大链路数不能超过DLB实例总个数。当本地PCRF的工作模式为 “客户端”时，执行本命令时“链路标识”支持配置的最大链路数不能超过DLB实例总个数*6。                                                                                                      |
| TPTYPE    | 传输协议类型      | 用于指定链路的传输协议类型。 取值说明： SCTP（流量控制传输协议）TCP（传输控制协议） 默认值：无。                                                                                                                                                                                                                     |
| DUALHOME  | 双归属开关       | 双归属开关。“传输协议类型”为“SCTP”时，才可以配置该参数。 取值说明： OFF(关闭)ON(打开) 默认值： 无。                                                                                                                                                                                                              |
| CROSSPATH | 交叉路径        | 双归属时的交叉路径配置。当“双归属开关”为“ON(打开)”时，需要设置此参数。 取值说明： OFF(关闭)：表示关闭交叉路径功能。ON(打开)：表示打开交叉路径功能。 默认值：无。                                                                                                                                                                                |
| DIPVER    | 双归属地址IP版本   | 当双归属开关打开时，需要设置此参数。用于指定本端和对端IP地址、双归属本端和对端IP地址的IP版本类型。 取值范围： IPV4IPV6 默认值：无。                                                                                                                                                                                                |
| IPVER     | IP版本        | 用于指定本端IP地址、对端IP地址的IP版本 取值范围： IPV4IPV6 默认值：无。                                                                                                                                                                                                                              |
| DLIP      | 双归属本端IPV4地址 | PCRF与容灾PCRF对接的参数之一，用于指定链路使用的双归属本端IPV4地址。需要PCRF与容灾PCRF协商一致；若不一致，可能会导致两者之间的链路无法正常建立。该参数必须已经通过ADD DLBDEVADDR命令添加。 取值范围：IPv4地址 默认值：无。  说明： 当“双归属地址IP版本”选择“IPV4”时，可设置该参数。                                                                                                      |
| DLIPV6    | 双归属本端IPV6地址 | PCRF与容灾PCRF对接的参数之一，用于指定链路使用的双归属本端IPV6地址。需要PCRF与容灾PCRF协商一致；若不一致，可能会导致两者之间的链路无法正常建立。该参数必须已经通过ADD DLBDEVADDR命令添加。 取值范围：IPv6地址 默认值：无。  说明： 当“双归属地址IP版本”选择“IPV6”时，可设置该参数。当前UPCF只支持Gx和Rx两种信令接口配置该参数。                                                                            |
| LIP       | 本端IPV4地址    | PCRF与容灾PCRF对接的参数之一，用于指定链路使用的本端IPV4地址。需要PCRF与容灾PCRF协商一致；若不一致，可能会导致两者之间的链路无法正常建立。该参数必须已经通过ADD DLBDEVADDR命令添加。 取值范围：IPv4地址 默认值：无。  说明： 当“IP版本”选择“IPV4”时，可设置该参数。当“双归属开关”为“ON(打开)”，且“双归属地址IP版本”选择“IPV4”时，本参数作为PCRF侧diameter链路端点的主IP地址，与“PIP”组成主路径。                             |
| LIPV6     | 本端IPV6地址    | PCRF与容灾PCRF对接的参数之一，用于指定链路使用的本端IPV6地址。需要PCRF与容灾PCRF协商一致；若不一致，可能会导致两者之间的链路无法正常建立。该参数必须已经通过ADD DLBDEVADDR命令添加。 取值范围：IPv6地址 默认值：无。  说明： 当“IP版本”选择“IPV6”时，可设置该参数。当前UPCF只支持Gx和Rx两种信令接口配置该参数。当“双归属开关”为“ON(打开)”，且“双归属地址IP版本”选择“IPV6”时，本参数作为PCRF侧diameter链路端点的主IP地址，与“PIPV6”组成主路径。 |
| LPT       | 本地端口        | UPCF内部用于与指定的容灾PCRF建立链路的端口。 当本地PCRF的工作模式为 “服务端”时，本地端口不能配置为0。 取值范围：0～65534 默认值：无。  说明： 当参数“传输协议类型”为“TCP（传输控制协议）”时，参数“本地端口”配置的端口必须大于或者等于1024，否则可能会导致建链失败。                                                                                                                    |
| DPIP      | 双归属对端IPV4地址 | PCRF与容灾PCRF对接的参数之一，用于指定连接使用的双归属对端IPV4地址。需要PCRF与容灾PCRF协商一致；若不一致，可能会导致两者之间的链路无法正常建立。 取值范围：IPv4地址 默认值：无。  说明： 当“双归属地址IP版本”选择“IPV4”时，可设置该参数。                                                                                                                                  |
| DPIPV6    | 双归属对端IPV6地址 | PCRF与容灾PCRF对接的参数之一，用于指定连接使用的双归属对端IPV6地址。需要PCRF与容灾PCRF协商一致；若不一致，可能会导致两者之间的链路无法正常建立。 取值范围：IPv6地址 默认值：无。  说明： 当“双归属地址IP版本”选择“IPV6”时，可设置该参数。当前UPCF只支持Gx和Rx两种信令接口配置该参数。                                                                                                        |
| PIP       | 对端IPV4地址    | PCRF与容灾PCRF对接的参数之一，用于指定连接使用的对端IPV4地址。需要PCRF与容灾PCRF协商一致；若不一致，可能会导致两者之间的链路无法正常建立。 取值范围：IPv4地址 默认值：无。  说明： 当“IP版本”选择“IPV4”时，可设置该参数。当“双归属开关”为“ON(打开)”，且“双归属地址IP版本”选择“IPV4”时，系统把本参数作为容灾PCRF侧diameter链路端点的主IP地址，与“LIP”组成主路径。                                                    |
| PIPV6     | 对端IPV6地址    | PCRF与容灾PCRF对接的参数之一，用于指定连接使用的对端IPV6地址。需要PCRF与容灾PCRF协商一致；若不一致，可能会导致两者之间的链路无法正常建立。 取值范围：IPv6地址 默认值：无。  说明： 当“IP版本”选择“IPV6”时，可设置该参数。当前UPCF只支持Gx和Rx种信令接口配置该参数。当“双归属开关”为“ON(打开)”，且“双归属地址IP版本”选择“IPV6”时，系统把本参数作为容灾PCRF侧diameter链路端点的主IP地址，与“LIPV6”组成主路径。                         |
| PPT       | 对端端口        | PCRF与容灾PCRF产品对接的参数之一，用于指定连接使用的对端端口，需要PCRF与容灾PCRF协商一致；若不一致，可能会导致两者之间的链路无法正常建立。当对端端口为0时，表示不对对端端口做限制，可以接受对端任意端口的连接。 当本地PCRF的工作模式为 “客户端”时，对端端口不能配置为0。 取值范围：0～65534 默认值：无。                                                                                                     |
| ADSTS     | 链路管理状态      | 用于指定链路的管理状态。 当链路管理状态为去使能时，建立的链路是无法连通的，通过DSP RPCRFL命令查询出来的该链路状态为“LINKDOWN（离线）”。同时会产生ALM-34089 PCRF与容灾PCRF链路故障的告警。 建议添加链路的时候该参数使用默认值。 取值说明： DISABLE（去使能）ENABLE（使能） 默认值：无。                                                                                                   |
