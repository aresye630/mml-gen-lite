# 删除GTP-C本地实体组（RMV GTPCLEGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C、AMF、GGSN**

该命令用于删除GTP-C本地实体组。

## 注意事项

- 该命令执行后立即生效。

- 如果需要删除本地实体组，需要删除该组号对应的接口和本地实体组成员，当组号被ADD GTPCINTF或者ADD GTPCLEGRPMEM引用时，先删除其引用关系再删除本地实体组。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                    |
|:--------|:-------|:----------------------------------------------------------------------------------------|
| GROUPID | 组号     | 可选必选说明：必选参数  参数含义：该参数用于指定GTP-C本地实体所属的组。  数据来源：本端规划  取值范围：整数类型，取值范围是0~31。  默认值：无  配置原则：无 |

## 使用实例

删除0号GTP-C本地实体组：

```
RMV GTPCLEGRP:GROUPID=0;
```
