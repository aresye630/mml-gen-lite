# 修改网络切片支持的DNN（MOD NSDNN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于修改指定的网络切片属性。

## 注意事项

- 该命令执行后立即生效。

- 该命令无法用于修改BINDSMFINFOID。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称          | 参数说明                                                                                                                                                                                                                                                                            |
|:--------------|:--------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NSIDX         | 网络切片索引        | 可选必选说明：必选参数  参数含义：该参数用于指定网络切片，可以使用LST PLMNNS命令查询获取。  数据来源：全网规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：  本参数通过ADD NFNS命令进行配置，且NF类型必须是NfSMF。                                                                                                                                  |
| DNN           | 数据网络名称        | 可选必选说明：必选参数  参数含义：该参数用于表示指定的网络切片支持的数据网络名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。可配置通配DNN，即“*”，表示支持所有DNN。  默认值：无  配置原则：  确保为S-NSSAI增加其支持的DNN在LST CPAPN中能够查询到。 |
| DEFIWKIND     | EPS互操作默认切片指示  | 可选必选说明：可选参数  参数含义：该参数用于指定PDN连接建立流程中根据DNN为用户分配的互操作默认切片。  数据来源：本端规划 取值范围： “YES（是）”：是“NO（否）”：否  默认值：无  配置原则：  5G用户在EPS网络建立PDN连接时，当运营商希望SMF本地根据DNN配置用于N26互操作流程的切片时，需要设置该参数为"YES"。当运营商希望SMF通过UDM获取签约信息分配切片时，可以设置该参数为"NO"。为了避免发生SMF通过UDM获取不到签约的切片的异常场景，强烈建议设置该参数为"YES"。               |
| BINDSMFINFOID | 绑定的SMFINFO ID | 可选必选说明：可选参数  参数含义：该参数用于指定绑定的SMFINFOEXT记录。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~32。  默认值：无  配置原则： 默认为空，表示在SmfInfo及SmfInfoList中所有SmfInfo里都携带。如果期望仅在SmfInfoList中某个SmfInfo中携带，该参数取值需要与通过与ADD SMFINFOEXT命令配置的SMFINFOID一致。如果期望仅在SmfInfo中携带，取值应为“bind_smf_info”时。                           |

## 使用实例

将DNN为"huawei.com"的eMBB切片（假设索引为0）修改为EPS互操作默认切片：

```
MOD NSDNN: NSIDX=0, DNN="huawei.com", DEFIWKIND=YES;
```
