# 设置遍历任务参数(SET SCANPARA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置遍历任务的参数。

## 注意事项

- 数据库中最多有一条配置记录，当数据库中已经存在配置记录时，此命令的执行会修改原来的配置信息。
- 遍历任务参数在系统中已预置缺省值：“启动时间”为“08:00:00”，“离线业务处理时间间隔”为“5”。
- 设置相关参数需要满足条件：从00:00:00到“启动时间”的时间间隔+“离线业务处理时间间隔”+1小时（预留遍历时间）≤24小时，这样一轮数据库遍历可以在当天24:00:00前完成。
- 离线业务处理每秒扫描的用户数和扫描间隔、OTES个数相关，最大每秒处理200个用户，需要根据局点用户数设置离线扫描周期。
- 当启动用户签约数据改造任务时，不会启动离线扫描任务。
- 避免对系统性能造成影响，建议将任务启动时间设置在配额复位时间点之后。

## 参数说明

| 参数标识      | 参数名称       | 参数说明                                            |
|:----------|:-----------|:------------------------------------------------|
| SSTRTIME  | 启动时间       | 用于标识每日遍历任务启动的时间。 取值范围：00:00:00–20:00:00 默认值： 无。 |
| SINTERVAL | 离线业务处理时间间隔 | 用于标识每轮离线业务处理的时间间隔，单位为小时。 取值范围： 1～23 默认值： 无。     |

## 使用实例

设置遍历任务的相关参数，“启动时间”为“12:59:59”，“离线业务处理时间间隔”为“8”。

```
SET SCANPARA: SSTRTIME=12&59&59, SINTERVAL=8;
```
