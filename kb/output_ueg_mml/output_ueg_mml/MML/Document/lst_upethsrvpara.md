# 查询用户面以太业务参数配置（LST UPETHSRVPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询用户面以太业务相关参数配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询用户面以太业务相关参数配置：

```
LST UPETHSRVPARA:;
```

```
RETCODE = 0 操作成功。

用户面以太业务参数配置
-----------------
用户面以太业务开关  =  ENABLE          
用户面以太业务MAC地址  =  10-11-11-11-11-11
(结果个数 = 1)
--- END
```

#### 输出结果说明

参见SET UPETHSRVPARA的参数说明。
