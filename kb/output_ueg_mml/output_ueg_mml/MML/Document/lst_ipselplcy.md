# 查询IP地址选择策略(LST IPSELPLCY)

- 命令功能

#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询S10、S11、Gn/Gp、S5/S8、S3、S4、Sv接口IP地址选择策略。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                 |
|:----------|:-------|:---------------------------------------------------------------------------------------------------------------------|
| CTRLRANGE | 控制范围   | 可选必选说明：可选参数 参数含义：该参数用于指定命令生效的范围。 数据来源：整网规划 取值范围：“DEFAULT(缺省策略)”“SPECIFY(指定IMSI)” 默认值：无                               |
| IMSI      | IMSI   | 可选必选说明：条件可选参数 参数含义：该参数用于指定用户的IMSI。 前提条件：该参数在“CTRLRANGE(控制范围)”设置为“SPECIFY(指定IMSI)”有效。 数据来源：整网规划 取值范围：0~15位十进制数字 默认值：无 |

#### 使用实例

场景参见**ADD IPSELPLCY**的命令使用实例。

- 查询S10、S11、Gn/Gp、S5/S8、S3、S4、Sv接口的IP地址选择策略：

  LST IPSELPLCY:;
