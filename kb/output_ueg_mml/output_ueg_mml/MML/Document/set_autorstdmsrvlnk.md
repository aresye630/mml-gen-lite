# 设置自动重置Diameter服务端链路(SET AUTORSTDMSRVLNK)

## 命令功能

该命令仅针对故障链路进行重置,用于定时重置处理处于故障状态的Diameter服务端链路。

该命令的使用场景：如果现网存在故障时间较长的diameter服务端链路，开启该功能后系统会定时重置Diameter服务端链路尝试自愈。

**说明** 

该命令为通用维护功能，执行本命令后链路重建时间依赖于对端。

## 注意事项

- 每次执行本命令成功，先按照新的设置重置一次故障链路，然后按照设置的时间定时重置。

- 再次执行本命令相同的配置参数，当前的命令配置参数不会生效，还是以上一次命令的配置参数为生效条件继续重置故障链路。

## 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                                                                  |
|:---------------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AUTORSTLNKSW   | 自动重置开关   | 可选必选说明：必选参数 参数含义：用于设置是否开启自动重置Diameter服务端链路。 取值范围： Disable：关闭Enable：打开 默认值：无。 配置原则：无。                                                                                  |
| AUTORSTLNKTIME | 自动重置时间间隔 | 可选必选说明：可选参数 参数含义：用于设置自动重置Diameter服务端链路的时间间隔，当参数“自动重置开关”取值为“Enable”时参数可配。 取值范围：1~1440，单位为分钟。 默认值：如果首次不设置该参数，默认为10分钟。如果首次设置该参数，再次执行本命令时不设置该参数，则默认以上一次设置的该参数值生效。 配置原则：无。 |
| PEERTYPE       | 对端类型     | 可选必选说明：必选参数 参数含义：用于设置自动重置Diameter对端类型，若不输入，则表示所有的对端类型。 取值范围： PCEFAFDRA 默认值：无。 配置原则：无。                                                                                 |

## 使用实例

设置自动重置Diameter服务端链路相关参数，“自动重置开关”为“Enable”，“自动重置时间间隔”为“12”，“对端类型”为“PCEF”。

```
SET AUTORSTDMSRVLNK: AUTORSTLNKSW=Enable, AUTORSTLNKTIME=12, PEERTYPE=PCEF-1&AF-0&DRA-0;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
