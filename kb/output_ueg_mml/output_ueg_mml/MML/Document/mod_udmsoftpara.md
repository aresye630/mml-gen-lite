# 修改业务参数(MOD UDMSOFTPARA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致系统异常，影响业务处理，需联系华为技术支持确认后再执行。

该命令用于HTTP链路管理策略配置，修改参数包括配置类型，配置项名称和配置项值。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                  |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------|
| TYPE   | 配置类型   | 可选必选说明：必选参数 参数含义：用于标识按功能模块划分的业务参数名称所归属的大类。详细信息请参考产品手册的“业务参数”。                                                                         |
| ITEMN  | 配置项名称  | 可选必选说明：条件必选参数 参数含义：标识一条业务参数数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪一个业务参数名称进行修改或调整，操作员可以使用LST UDMSOFTPARA命令查询获得。 配置原则：当参数“配置类型”取值为任意类型取值时该参数有效。 |
| VALUE  | 配置项值   | 可选必选说明：必选参数 参数含义：用于标识需要修改的业务参数的参数值，该参数值的取值范围由业务参数名称确定。各业务参数取值及取值具体含义请参见产品手册的“业务参数”。                                                   |

## 使用实例

修改一条业务参数配置数据。“配置类型”为“HttpConfig(HTTP参数配置)”，“配置项名称”为“HttpLink(HTTP链路策略)”，“配置项值”为“1”。

```
MOD UDMSOFTPARA: TYPE=HttpConfig, ITEMN=HttpLink, VALUE="1";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释       | 原因分析                                                                          | 处理建议              |
|-------:|:------------|:------------------------------------------------------------------------------|:------------------|
| 360066 | 整数不在取值范围之内  | 配置项值为整形，取值不在配置项设定的最大最小值范围之内。                                                  | 重新填入在取值范围之内的整数值。  |
| 360067 | 字符串不在取值列表之内 | 配置项值为列表类型，配置的字符串不在列表范围之内。                                                     | 重新填入在取值列表之内的字符串值。 |
| 360068 | 字符串不符合校验规则  | 配置项值为字符串，配置值不符合字符串的校验规则。                                                      | 重新填入符合校验规则的字符串。   |
| 360195 | 该软参在本版本不生效。 | 软参“SdkLinkRefreshPeriod(Sdk链路信息刷新周期)”和“SDKRegisterRate(DCS接收SDK注册速率)”在本版本不生效。 | 无需处理。             |
