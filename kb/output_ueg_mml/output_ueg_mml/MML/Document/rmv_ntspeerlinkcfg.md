# 删除通知服务对端链路配置信息(RMV NTSPEERLINKCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令用于删除在配置数据库中的一条通知任务服务对端链路配置信息的数据记录。

## 注意事项

- 删除通知任务服务对端链路信息数据时，如果“链路ID”所在的“链路组”被短信/邮件模板关联，且是该链路组最后一条记录，则该链路不允许删除。需要在短信/邮件模板中取消关联后，才能通过本命令删除该链路配置信息。
- 当执行本命令删除通知任务服务对端链路配置记录后，系统可能会上报ALM-34013 短信/邮件通知链路配置异常告警，请检查UPCF Web UI的通知配置模板后，等待告警消除。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                    |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------|
| LINKID | 链路ID   | 可选必选说明：必选参数 参数含义：标识一条通知任务服务对端链路配置信息的数据记录的关键字段，用于指定需要删除哪一条通知任务服务对端链路配置信息的数据记录，操作员可以使用LST NTSPEERLINKCFG命令查询获得。 取值范围：1～255 默认值：无。 配置原则：无。 |

## 使用实例

删除一条通知任务服务对端链路配置信息的数据记录，“链路ID”为“4”。

```
RMV NTSPEERLINKCFG: LINKID=4;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释               | 原因分析                                           | 处理建议                                                                                                                                                   |
|------:|:--------------------|:-----------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
|  3032 | 该链路已经被通知模板引用，无法被删除。 | “链路ID”所在的“链路组”被通知模板关联，且该链路是该链路组最后一条记录，不允许直接删除。 | 执行LST NTSPEERLINKCFG命令，查询该链路ID所在的链路组。登录UPCF Web UI界面，选择“通知管理”>“短信/邮件模板”，确认待删除的链路所在链路组被“短信/邮件”引用，此时仍需要删除该链路，则删除“短信/邮件模板”或修改“短信/邮件”所引用的链路组。重新执行本命令删除该链路。 |
