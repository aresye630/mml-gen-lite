## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于微服务添加一个对外提供的信令HTTP IP地址。

## 注意事项

- 由本命令配置的IP地址和**ADD IPADDR**/**MOD IPADDR**配置的IP地址不能重复，否则会导致IP地址冲突，影响业务。
- 最大支持16条HTTP IP配置。

## 参数说明

| 参数标识        | 参数名称         | 参数说明                                                                                                                                                                                              |
|:------------|:-------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPNAME      | IP名称         | 可选必选说明：必选参数。 参数含义：用于标识一个微服务对外提供的信令IP地址名称。 取值范围：长度不超过128的由数字和字母组成的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。                                                                                     |
| IPVER       | IP地址类型       | 可选必选说明：必选参数。 参数含义：用于标识一个微服务对外提供的信令IP地址类型。 取值范围： IPV4(IPV4开关)IPV6(IPV6开关) 默认值：无。 配置原则：无。                                                                                                           |
| IPV4IP1     | IPV4地址       | 可选必选说明：条件必选参数。 参数含义：用于标识微服务对外提供的IPV4地址。 取值范围：有效的IPV4地址。IPV4格式为“xxx.xxx.xxx.xxx”，例如：192.168.164.22。 默认值：无。 配置原则：仅当本命令的参数“IP地址类型”取值为“IPV4(IPV4开关)”时，该参数有效。                                          |
| IPV6IP1     | IPV6地址       | 可选必选说明：条件必选参数。 参数含义：用于标识微服务对外提供的IPV6地址。 取值范围：有效的IPV6地址。IPV6格式为“x.x.x.x.x.x.x.x”，例如：fc00:EF01:2345:6789:ABCD:EF01:2345:6789。 默认值：无。 配置原则：仅当本命令的参数“IP地址类型”取值为“IPV6”时，该参数有效。                         |
| VPNINFONAME | VPNINFO名称    | 可选必选说明：必选参数。 参数含义：用于标识IP使用的VPN信息，该参数必须先由ADD VPNINFO命令定义，然后才能在此处索引。 取值范围：长度不超过128的由数字和字母组成的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。                                                            |
| MTU         | 最大传输单元（byte） | 可选必选说明：可选参数。 参数含义：用于标识该IP支持处理的最大传输单元。 取值范围：576～9600 默认值：无。 配置原则：正常通信情况下，建议MTU的值不要随意更改，由于部分协议对最小报文有限制，如果配置过小会导致协议邻居无法建立。配置为IPV4地址时，系统初始设置值为1500。配置为IPV6地址时，系统初始设置值为1280。该参数的取值要求小于虚拟网口vNIC定义的MTU值。 |
| DSCP        | DSCP值        | 可选必选说明：可选参数。 参数含义：用于标识从该链路上发送的消息在IP层被封装为IP数据包时，IP消息头中TOS域表示为DSCP（差异服务代码点）的值。路由器会根据DSCP值对应的优先级对报文进行转发，DSCP值取值越小代表优先级越低。 取值范围：0～63 默认值：0 配置原则：修改DSCP值后已经建立的链路不会立即生效，需要链路重建后才能生效。                    |

## 使用实例

在UDM初始配置阶段，增加微服务对外HTTP IP地址。“IP名称”为“ipv4”，“IP地址类型”为“IPV4(IPV4开关)”，“IPV4地址”为“192.168.105.100”，“VPNINFO名称”为“vpn1”；

```
ADD HTTPIP: IPNAME="ipv4", IPVER=IPV4, IPV4IP1="192.168.105.100", VPNINFONAME="vpn1";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释        | 原因分析                           | 处理建议                                             |
|-------:|:-------------|:-------------------------------|:-------------------------------------------------|
| 360006 | 参数取值无效       | “IPV4地址”或“IPV6地址”参数的取值是无效IP地址。 | 使用正确的“IPV4地址”或“IPV6地址”。                          |
| 360017 | HTTP IP名称不合法 | “IP名称”只支持数字，字母，下划线和连字符。        | 使用数字、字母、下划线和连线组成的HTTP “IP名称”。                    |
| 360070 | VPNINFO未定义   | 输入的“VPNINFO 名称”不存在。            | 使用LST VPNINFO命令查询已经添加的VPN信息，引用已经添加的“VPNINFO 名称”。 |
| 360024 | IPV6地址输入不合法  | “IPV6地址”参数的取值是非法IP地址。          | 使用正确的“IPV6地址”。                                   |
| 360110 | MTU参数值不合法    | “最大传输单元(byte)”参数取值不在要求的范围内。    | 根据实际情况，重新输入参数，确保参数取值在要求范围内。                      |
