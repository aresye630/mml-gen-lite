# 查询位置区群组成员(LST LARAGPMEM)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用网元：SGSN**

此命令用于查询位置区域群成员记录。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                  |
|:---------|:--------|:----------------------------------------------------------------------------------------------------------------------|
| LARAGPID | 区域群标识   | 可选必选说明：可选参数 参数含义：该参数用于指定位置区和路由区的区域群标识。 数据来源：整网规划 取值范围：1～2048 默认值：无                                                    |
| IDTYPE   | 标识类型    | 可选必选说明：可选参数 参数含义：该参数用于指定该区域的标识类型。 数据来源：整网规划 取值范围： “LA(位置区)”：表示该区域标识类型为位置区。“RA(路由区)”：表示该区域标识类型为路由区 默认值：无               |
| MCC      | 移动国家码   | 可选必选说明：条件可选参数 参数含义：该参数用于指定移动国家码。 前提条件：该参数在“IDTYPE(标识类型)”设置为“LA(位置区)”或“RA(路由区)”时生效。 数据来源：整网规划 取值范围：3位的十进制数字 默认值：无      |
| MNC      | 移动网号    | 可选必选说明：条件可选参数 参数含义：该参数用于指定移动网号。 前提条件：该参数在“IDTYPE(标识类型)”设置为“LA(位置区)”或“RA(路由区)”时生效。 数据来源：整网规划 取值范围：2～3位的十进制数字 默认值：无     |
| LAC      | 位置区域码   | 可选必选说明：条件可选参数 参数含义：该参数用于指定位置区域码。 前提条件：该参数在“IDTYPE(标识类型)”设置为“LA(位置区)”或“RA(路由区)”时生效。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无 |
| LACRANGE | 位置区域码范围 | 可选必选说明：可选参数 参数含义：该参数用于指定位置区域码范围。 前提条件：该参数在“IDTYPE(标识类型)”设置为“LA(位置区)”时生效。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无           |
| RAC      | 路由区域码   | 可选必选说明：条件可选参数 参数含义：该参数用于指定路由区域码。 前提条件：该参数在“IDTYPE(标识类型)”设置为“RA(路由区)”时生效。 数据来源：整网规划 取值范围：0x00～0xFF 默认值：无               |
| RACRANGE | 路由区域码范围 | 可选必选说明：可选参数 参数含义：该参数用于指定路由区域码范围。 前提条件：该参数在“IDTYPE(标识类型)”设置为“RA(路由区)”时生效。 数据来源：整网规划 取值范围：0x00～0xFF 默认值：无               |

#### 使用实例

查询所有位置区群组成员：

LST LARAGPMEM:;

```
%%LST LARAGPMEM:;%%
RETCODE = 0  操作成功。

输出结果如下
--------------
    区域群标识  =  55
      标识类型  =  位置区
    移动国家码  =  123
      移动网号  =  05
    位置区域码  =  0x20
位置区域码范围  =  0x20
    路由区域码  =  NULL
路由区域码范围  =  NULL
(结果个数 = 1)

---    END
```
