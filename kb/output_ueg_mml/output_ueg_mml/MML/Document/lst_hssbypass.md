#### 命令功能

**适用网元：MME**

该命令用于查询HSS故障Bypass功能控制参数。

#### 注意事项

无。

#### 本地用户权限

manage-ug;system-ug;monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无

#### 使用实例

查询HSS故障Bypass功能控制参数信息：

```
LST HSSBYPASS:;
```

```
查询结果如下
-------------------------
    HSS Bypass功能开关  =  关闭
        MSISDN检查开关  =  是
退出Bypass状态恢复动作  =  补充缺失流程
 整系统扫描速率(个/秒)  =  0
      扫描时间间隔(秒)  =  600
       上报异常CHR开关  =  开启
HSS Bypass自动退出开关  =  开启
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见SET HSSBYPASS的参数说明。
