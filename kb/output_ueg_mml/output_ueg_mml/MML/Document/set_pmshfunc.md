## 命令功能

该命令为配置类命令，用于控制是否启用系统的Pm接口或Rest接口功能。

- UPCF与POP通过Pm接口对接时，若需要通过Pm接口从POP获取CLI策略脚本数据时，需执行本命令将功能项“PmCLIPolicy”值设置为“1”。
- UPCF与SMT通过Rest接口对接，若需要启用此接口时，需执行本命令将功能项“RestPolicy”值设置为“1”。

## 注意事项

- 当启用Pm接口获取CLI的功能时，需要将“VRM\_PMWORKMODE”软参设置为非“0”。

- 当启用Pm接口获取CLI的功能后，通过营帐系统发放从Pm接口获取的业务时，需先执行**DSP PMSPMTASK**命令查看策略文件的执行状态，确保策略文件的“状态”均为“End”后才进行业务发放。

该命令存在系统初始记录，参数的初始设置值如下：

| 功能ID        |   值 |
|:------------|----:|
| PmCLIPolicy |   0 |
| RestPolicy  |   0 |

- 混合组网场景下，PoP优先对接UPCF，不建议同时对接4G/5G版本。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                              |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FUNCID | 功能ID   | 可选必选说明：必选参数 参数含义：用于表示系统支持的功能项标识。 取值范围： PmCLIPolicyRestPolicy 默认值：无。 配置原则：无。                                                                                                                                       |
| VALUE  | 值      | 可选必选说明：必选参数 参数含义：用于表示系统支持的功能项值。 取值范围：0～1 当“功能ID”为“PmCLIPolicy”时，取值范围如下：0：表示不支持Pm接口获取策略脚本。1：表示支持Pm接口获取策略脚本。 当“功能ID”为“RestPolicy”时，取值范围如下：0：表示不启用Rest接口。1：表示启用Rest接口。 默认值：无。 配置原则：PmCLIPolicy和RestPolicy的值不能同时设置为1。 |

## 使用实例

UPCF与POP通过Pm接口对接时，运营商若需要通过Pm接口从POP获取CLI策略脚本数据，需要先执行**MOD PMSSSP**命令将“VRM\_PMWORKMODE”软参值设置为“1”，再执行本命令，设置“功能ID”为“PmCLIPolicy”，“值”为“1”。

```
SET PMSHFUNC: FUNCID=PmCLIPolicy, VALUE=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                           | 原因分析                                                     | 处理建议                                                          |
|------:|:--------------------------------|:---------------------------------------------------------|:--------------------------------------------------------------|
| 57820 | VALUE参数取值非法。                    | “功能ID”为“PmCLIPolicy”或“RestPolicy”时，功能项对应的“值”未设置为“0”或“1”。 | “功能ID”为“PmCLIPolicy”或“RestPolicy”时，功能项对应的“值”设置为“0”或“1”。       |
| 58056 | PmCLIPolicy和RestPolicy不能同时设置为1。 | PMS服务的Pm接口和Rest接口功能不能同时开启。                               | 执行LST PMSHFUNC命令查看各接口取值。执行本命令时，PmCLIPolicy和RestPolicy不同时配置为1。 |

## 参考信息

SMT：当所有用户使用VAS（第三方业务系统）的某个sponsor业务时，SMT作为UPCF与VAS的中间件，通过Rest接口起到接口适配和分发功能。
