# 修改IMSI Direct Tunnel配置(MOD IMSIDT)

#### 命令功能

**适用网元：SGSN**

此命令用于修改IMSI DT属性信息表中的某个IMSI的DT属性信息。

#### 注意事项

- 此命令执行后立即生效。
- 用户要使用DT功能还需满足RNC、GGSN和APNNI支持DT功能。
- 该命令部分参数与相关特性license共同完成该特性的开启，请在设置参数前使用**DSP LICENSE**命令确认对应特性license是否得到授权，执行**LST LICENSESWITCH**命令确认特性开关状态为“ENABLE(打开)”，具体相关特性请参考参数的说明。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称            | 参数说明                                                                                                                                                                                                                                                                     |
|:---------|:----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围            | 可选必选说明：必选参数 参数含义：该参数用于指定签约用户的范围。 数据来源：整网规划 取值范围：“ALL_USER（所有用户）”“IMSI_PREFIX（指定IMSI前缀）”“IMSI_RANGE（指定IMSI范围）” 默认值：无 配置原则：使用时首先按照用户的IMSI在“IMSI_PREFIX（指定IMSI前缀）”或“IMSI_RANGE（指定IMSI范围）”进行查询，如果查询成功则使用该记录对应的配置；如果查询失败，则查询“所有用户”对应的配置记录，如果查询成功则使用“所有用户”的配置，如果查询还失败，则默认支持DT。 |
| IMSIPRE  | IMSI前缀          | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI前缀。 前提条件：当“用户范围”为“IMSI_PREFIX（指定IMSI前缀）”时，该参数才有效。 数据来源：整网规划 取值范围：1～15位十进制字符串 默认值：无                                                                                                                                                         |
| IMSI     | IMSI            | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI，对该IMSI所在号段进行修改。 前提条件：当“用户范围”为“IMSI_RANGE（指定IMSI范围）”时，该参数才有效。 数据来源：整网规划 取值范围：1～15位十进制字符串 默认值：无                                                                                                                                             |
| DT       | 启用Direct Tunnel | 可选必选说明：可选参数 参数含义：该参数用于指定是否启用基于IMSI的DT功能。 数据来源：整网规划 取值范围：“NO(否)”“YES(是)” 默认值：无 配置原则：取值为“NO(否)”时，表示不启用基于IMSI的DT功能。取值为“YES(是)”时，表示启用基于IMSI的DT功能。  说明： 当参数设置为“YES(是)”时，“支持Direct Tunnel功能”特性的相关license授权并开启后，此参数配置才生效（特性编号：WSFD-104506，License部件编码：LKV2DIRTUN02）。            |

#### 使用实例

修改一条“用户范围”为“指定IMSI前缀”，“IMSI前缀”为“123456”，“启用Direct Tunnel”为“YES”的IMSI DT权限属性记录：

MOD IMSIDT: SUBRANGE=IMSI\_PREFIX, IMSIPRE="123456", DT=YES;
