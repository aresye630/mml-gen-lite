# 查询服务类型分配权重的管理策略（LST TOKENALLOCWT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C、SMF、GGSN、AMF**

该命令用于查询负载均衡策略。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                   |
|:------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 服务类型   | 可选必选说明：可选参数  参数含义：该参数用于指定服务类型，开启对应的负载均衡策略。  数据来源：本端规划  取值范围：1、UAM会话管理组（UEAM与UEM） 2、USM会话管理服务（UESM、SMC、UPC、SM5GCM、STG、SM5GPOLICY） “UAM_0（UAM_0）”：涉及如下类型POD：接入/移动性管理POD。“USM_0（USM_0）”：涉及如下类型POD：会话管理POD。  默认值：无  配置原则：无 |

## 使用实例

查询所有服务类型的负载均衡策略：

```
LST TOKENALLOCWT:;
```

## 输出结果说明

| 输出项名称   | 输出项解释                    |
|:--------|:-------------------------|
| 服务类型    | 该参数用于指定服务类型，开启对应的负载均衡策略。 |
| 权重策略    | 该参数用于配置指定服务类型的负载均衡策略。    |
