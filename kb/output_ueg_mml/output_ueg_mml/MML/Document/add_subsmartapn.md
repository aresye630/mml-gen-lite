# 增加智能分流APN (ADD SUBSMARTAPN)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于增加智能分流APN，当用户签约APN与该APN完全匹配时，系统标记用户为智能分流用户。

#### 注意事项

- 该命令执行后立即生效。
- 本表最大记录数为1024。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                                                                                                                                                                                              |
|:-------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APNNI  | 智能分流APNNI | 可选必选说明：必选参数 参数含义：该参数用于指定智能分流的APNNI。 数据来源：全网规划 取值范围：字符串类型，输入长度范围是1~62 默认值：无 配置原则： 智能分流APNNI由一个或多个LABEL构成，各LABEL间用“.”间隔。每个LABEL的构成字符只能是字母A～Z或a～z、数字0～9和中划线“-”，字母不区分大小写。例如“HUAWEI.COM” 智能分流APNNI不能以“rac”、“lac”、“sgsn”或“rnc”开头，不能以“.gprs”结尾，不能取值为“*”。 |

#### 使用实例

1. 添加一条智能分流APNNI，可以用如下命令：

   ```
   ADD SUBSMARTAPN: APNNI="APN1";
   ```
