# 显示无线路由黑匣子信息（DSP WLRBLACKBOX）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示无线路由黑匣子信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AFTYPE | 地址族    | 可选必选说明：必选参数 参数含义：该参数用于指定地址族。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。ipv6unicast：IPv6单播。 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| BOXID  | 黑匣子ID  | 可选必选说明：必选参数 参数含义：该参数用于指定黑匣子ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无 配置原则： 当前黑匣子ID： 组件级黑匣子，黑匣子ID：1。组件API调用失败信息，黑匣子ID：2。组件收到错误消息，黑匣子ID：3。组件内警告信息，黑匣子ID：4。消息重传信息，黑匣子ID：5。MPF发送PAEG信息，黑匣子ID：6。FEI通知PAE信息，黑匣子ID：7。发给MPF的订阅更新信息，黑匣子ID：8。MPF发送路由前缀信息，黑匣子ID：9。路由前缀老化信息，黑匣子ID：10。PAEG老化信息，黑匣子ID：11。Peer表项状态机信息，黑匣子ID：12。WLRv6向WLRv4订阅PAEG，黑匣子ID：13。FES组件partner状态信息，黑匣子ID：14。与FES收发消息，黑匣子ID：15。与FES更新引流表信息，黑匣子ID：16。与FES更新PAE信息，黑匣子ID：17。引流表组更新信息，黑匣子ID：18。引流表老化信息，黑匣子ID：19。Diameter组件partner状态信息，黑匣子ID：20。与RM更新路由前缀信息，黑匣子ID：21。RM组件partner状态信息，黑匣子ID：22。下发信令无线路由信息，黑匣子ID：23。 |

#### 使用实例

显示无线路由黑匣子信息：

```
DSP WLRBLACKBOX: AFTYPE=ipv4unicast,BOXID=1;
```
