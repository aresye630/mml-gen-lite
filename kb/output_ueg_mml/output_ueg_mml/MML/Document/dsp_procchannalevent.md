# 查询逻辑链路事件（DSP PROCCHANNALEVENT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询逻辑链路事件。

#### 注意事项

- 该命令执行后立即生效。
- 该命令需要在UIPC协议的环境上使用。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称    | 参数说明                                                                                                         |
|:----------------|:--------|:-------------------------------------------------------------------------------------------------------------|
| PLANEID         | 平面ID    | 可选必选说明：必选参数 参数含义：该参数表示平面ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～3。 默认值：无                                              |
| SRCPROCID       | 源端进程ID  | 可选必选说明：必选参数 参数含义：该参数表示源端进程ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                   |
| DSTPROCID       | 目的端进程ID | 可选必选说明：可选参数 参数含义：该参数表示目的端进程ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                  |
| SERVICEINSTANCE | 服务实例    | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

显示资源逻辑链路事件，指定目的端进程最多查询最近5条记录：

```
DSP PROCCHANNALEVENT:SRCPROCID=10002,PLANEID=0,DSTPROCID=10001,SERVICEINSTANCE="vnfc";
```

```
RETCODE = 0  操作成功

结果如下:
-------------------------
平面ID  源端进程ID  目的端进程ID   事件发生时间                    事件类型            原因值                         
0       10002       10001          2014-10-1 18：32：12            发生故障            心跳丢失                         
0       10002       10001          2014-10-1 18：32：13            链路恢复            收到复位消息

(结果个数 = 2)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                                                             |
|:--------|:------------------------------------------------------------------|
| 平面ID    | 表示平面ID。                                                           |
| 源端进程ID  | 表示源端进程ID。                                                         |
| 目的端进程ID | 表示目的端进程ID。                                                        |
| 事件发生时间  | 表示事件发生时间。                                                         |
| 事件类型    | 表示事件类型。链路恢复；发生故障；其它事件。                                            |
| 原因值     | 表示事件发生原因。链路恢复；链路发送受阻；链路报文乱序；链路收不到对端任何报文；链路收不到应答；收到复位消息；心跳丢失；其它原因。 |
