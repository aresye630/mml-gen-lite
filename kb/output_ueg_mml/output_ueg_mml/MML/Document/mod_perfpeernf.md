# 修改NF局向性能统计对象（MOD PERFPEERNF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、SMSF、NCG**

该命令用于修改NF局向性能统计对象。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                                                        |
|:--------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INTERFACETYPE | 接口类型   | 可选必选说明：可选参数  参数含义：该参数表示对端局向服务化接口类型。  数据来源：全网规划 取值范围： “N7（N7）”：N7“N8（N8）”：N8“N10（N10）”：N10“N11（N11）”：N11“N12（N12）”：N12“N15（N15）”：N15“N17（N17）”：N17“N20（N20）”：N20“N21（N21）”：N21“N40（N40）”：N40“Nocs（Nocs）”：Nocs  默认值：无  配置原则：无 |
| NFINSTANCEID  | NF实例号  | 可选必选说明：必选参数  参数含义：该参数表示对端局向NF实例号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~40。  默认值：无  配置原则：无                                                                                                                                        |
| DESC          | 描述     | 可选必选说明：可选参数  参数含义：该参数用于描述对端局向信息。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~64。  默认值：无  配置原则：无                                                                                                                                         |

## 使用实例

修改“NF实例号”为“AMF\_INSTANCE\_001”的NF局向性能统计对象：

```
MOD PERFPEERNF: INTERFACETYPE=N8, NFINSTANCEID="AMF_INSTANCE_001", DESC="amf instance";
```
