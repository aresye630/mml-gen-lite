# 查询NF服务实例（LST UPNFSERVICE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询NF实例下的NFS实例信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

运营商A需要查询配置的服务实例信息：

```
LST UPNFSERVICE:;
```

```
RETCODE = 0  操作成功

服务实例标识  =  Service_Instance_0

      优先级  =  0
        容量  =  100
        负载  =  0
(结果个数 = 1)

```
