# 查询通知服务对端服务器配置信息(LST NTSPEER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询通知任务服务对端服务器的配置信息。

- 如果需要查询全部通知任务服务对端服务器信息，请不要输入任何参数。
- 如果需要查询指定通知任务服务对端服务器信息，请依据参数说明输入查询的条件。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                 |
|:---------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------|
| PEERID   | 对端服务器ID | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个对端服务器ID来查询通知任务服务对端服务器信息；若不输入，则表示所有的对端服务器ID。 取值范围：1～255 默认值：无。 配置原则：无。                                   |
| PEERNAME | 对端服务器名称 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个对端服务器名称来查询通知任务服务对端服务器信息，值域类型为字符串，区分大小写；若不输入，则表示所有的对端服务器名称。 取值范围：长度不超过128的字符串 默认值：无。 配置原则：无。             |
| PEERTYPE | 对端服务器类型 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个对端服务器类型来查询通知任务服务对端服务器信息；若不输入，则表示所有的对端服务器类型。 取值范围： SMS(SMS协议)E-MAIL(E-MAIL协议)SOAP(SOAP协议) 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询所有的通知任务服务对端服务器配置信息。

   ```
   LST NTSPEER:;
   ```

   ```
   %%LST NTSPEER:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   ------------
   对端服务器ID	对端服务器名称	对端服务器类型	
   1               NTSMS1          SMS议       
   2               NTEMAIL2        E-MAIL协议    	
   (结果个数 = 2)

   ---    END
   ```
2. 查询一条通知任务服务对端服务器配置信息，“对端服务器”标识为“1”。

   ```
   LST NTSPEER: PEERID=1;
   ```

   ```
   %%LST NTSPEER: PEERID=1;%%
   RETCODE = 0  操作成功

   操作结果如下:
   ------------
     对端服务器ID = 1
   对端服务器名称 = NTSMS1
   对端服务器类型 = SMS协议
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD NTSPEER**命令的参数说明。
