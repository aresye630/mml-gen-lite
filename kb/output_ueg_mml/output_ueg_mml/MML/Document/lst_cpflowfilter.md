# 查询CP流过滤器（LST CPFLOWFILTER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF、PGW-C、SGW-C、GGSN**

该命令用于查询SMF和UPF之间的消息流过滤器。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询所有SMF和UPF之间的消息流过滤器：

```
%%LST CPFLOWFILTER:;%%
RETCODE = 0  操作成功

结果如下
------------------------
流过滤器名称  =  RS
流过滤器类别  =  IPv6路由器通告
(Number of results = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                      |
|:--------|:---------------------------|
| 流过滤器名称  | 该参数用于指定SMF和UPF之间的消息流过滤器名称。 |
| 流过滤器类别  | 该参数用于指定SMF和UPF之间的消息流过滤器类别。 |
