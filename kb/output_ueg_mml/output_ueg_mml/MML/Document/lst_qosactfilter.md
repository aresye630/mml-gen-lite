# 查询流行为规则（LST QOSACTFILTER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询流行为过滤设置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                      |
|:-------------|:-------|:----------------------------------------------------------------------------------------------------------|
| BEHAVIORNAME | 行为名称   | 可选必选说明：可选参数 参数含义：该参数用于指定流行为。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：区分大小写，不支持空格。                    |
| FILTER       | 行为状态   | 可选必选说明：可选参数 参数含义：该参数用于指定动作为permit还是deny。 数据来源：本端规划 取值范围：枚举类型。 permit：满足规则的所有报文通过。deny：满足规则的所有报文不通过。 默认值：无 |

#### 使用实例

查询当前所有流动作的过滤设置：

```
LST QOSACTFILTER:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
行为名称  =  b1
行为状态  =  拒绝
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释         |
|:--------|:--------------|
| 行为名称    | 该参数用于表示流行为名称。 |
| 行为状态    | 该参数用于表示过滤动作。  |
