# 删除等价PLMN组成员（RMV EPLMNGRPMEM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于在指定的等价PLMN组内删除等价PLMN成员。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                        |
|:-------|:---------|:------------------------------------------------------------------------------------------------------------|
| GRPIDX | 等价PLMN组号 | 可选必选说明：必选参数  参数含义：该参数用于标识等价PLMN组，通过命令ADD EPLMNGRP进行配置。  数据来源：本端规划  取值范围：整数类型，取值范围是0~127。  默认值：无  配置原则：无     |
| MCC    | 移动国家码    | 可选必选说明：必选参数  参数含义：该参数用于表示组成等价PLMN的移动国家码信息。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无    |
| MNC    | 移动网号     | 可选必选说明：必选参数  参数含义：该参数用于表示组成等价PLMN的移动网号信息。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无 |

## 使用实例

为PLMN为12345的Serving PLMN删除等价PLMN 12389，其中Serving PLMN 12345使用的等价PLMN组号为0，执行如下命令：

```
RMV EPLMNGRPMEM: GRPIDX=0, MCC="123", MNC="89";
```
