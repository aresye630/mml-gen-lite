#### 命令功能

**适用网元：SGSN**

此命令用于查询位置区和路由区的区域群。

#### 注意事项

- 无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                               |
|:---------|:-------|:-------------------------------------------------------------------|
| LARAGPID | 区域群标识  | 可选必选说明：可选参数 参数含义：该参数用于指定位置区和路由区的区域群标识。 数据来源：整网规划 取值范围：1～2048 默认值：无 |

#### 使用实例

查询所有位置区群组记录：

LST LARAGP:;

```
%%LST LARAGP:;%%
RETCODE = 0  操作成功。

输出结果如下
------------
区域群标识  =  55
区域群名称  =  shanghai
(结果个数 = 1)
---    END
```
