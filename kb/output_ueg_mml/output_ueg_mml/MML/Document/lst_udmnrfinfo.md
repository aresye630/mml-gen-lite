# 查询NRF信息(LST UDMNRFINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询NRF的信息。

- 若需要查询某个NRF的详细信息，请输入“NRF名称”参数；
- 若需要查询某个组中NRF的信息，请输入“NRF所属组信息”参数；
- 若需要查询所有NRF的信息，不输入任何参数。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                                            |
|:---------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NRFNAME  | NRF名称    | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个“NRF名称”来查询NRF数据；若不输入，则表示所有的NRF名称。 取值范围：长度不超过32位的字符串。 参数来源：该参数全局唯一且需UDM与NRF端协商获取此参数名，通过ADD UDMNRFINFO命令配置初始添加。 默认值：无。 配置原则：无。       |
| NRFGROUP | NRF所属组信息 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个“NRF所属组信息”来查询NRF数据；若不输入，则表示所有的NRF所属组信息。 取值范围：长度不超过32位的字符串。 参数来源：该参数全局唯一且需UDM与NRF端协商获取此参数名，通过ADD UDMNRFINFO命令配置初始添加。 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询所有NRF信息：

   ```
   LST UDMNRFINFO:;
   ```

   ```
   %%LST UDMNRFINFO:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   NRF所属组信息  NRF名称    NRF URI                   NRF URI2                                      优先级  NF注册消息是否启用Gzip压缩  Nfservices字段使用MAP格式  

   nrfgroup-01    nrf-01     http://192.168.1.1:8080   NULL                                          2       不启用                      否                         
   nrfgroup-02    nrftest00  http://10.10.10.10:8080   http://[fc03::fc10:fc23:fc56:fc63:fc71]:8080  1       不启用                      否                         
   nrfgroup-03    nrftest01  http://10.11.12.13:8080   NULL                                          2       不启用                      否                         
   (结果个数 = 3)
   ---    END
   ```
2. 查询特定NRF信息，“NRF名称”为“nrf-01”：

   ```
   LST UDMNRFINFO: NRFNAME="nrf-01";
   ```

   ```
   %%LST UDMNRFINFO: NRFNAME="nrf-01", NRFGROUP="nrfgroup-01";%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
                NRF所属组信息  =  nrfgroup-01
                      NRF名称  =  nrf-01
                      NRF URI  =  https://192.168.1.1:8080
                     NRF URI2  =  http://[fc03::fc10:fc23:fc56:fc63:fc71]:8080
                       优先级  =  1
   NF注册消息是否启用Gzip压缩  =  不启用
    Nfservices字段使用MAP格式  =  否
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD UDMNRFINFO**命令的参数说明。
