# 查询APN内容过滤开关（LST APNCFFUNC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询APN内容过滤开关。如果不输入APN名称，则查询所有APN内容过滤开关。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                            |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APNNAME | APN名称  | 可选必选说明：可选参数 参数含义：该参数用于设置APN名称。 数据来源：本端规划 取值范围：只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”特殊字符，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

查询名为huawei.com的APN上的内容过滤开关：

```
LST APNCFFUNC: APNNAME="huawei.com";
```

```

```
