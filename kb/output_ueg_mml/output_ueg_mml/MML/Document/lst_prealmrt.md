# 查询PCRF的域路由记录（LST PREALMRT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于在配置数据库中查询PCRF的域路由记录。如果需要查询全部域路由的配置信息，请不要输入任何参数；如果需要查询某个域路由的配置信息，请依据参数说明输入查询条件。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                                              |
|:-------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PCRFID | PCRF标识  | 用于标识PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围：1 默认值：无。                                                                                                                           |
| RID    | 路由标识    | 用于在UPCF的配置库中定义一个域路由。该参数的配置原则：如果配置多个对端域路由，从0开始顺序配置。 取值范围：0～29 默认值：无。                                                                                                               |
| RTN    | 域路由名称   | 域路由的名称。 取值范围：长度不超过128的字符串 默认值：无。                                                                                                                                                  |
| ITYPE  | 接口类型    | 用于指示路由对应的接口类型。 取值说明： GxRx(Gx&Rx&Sd)Sy(Sy) 默认值：无。                                                                                                                                  |
| ISDFT  | 是否是默认路由 | 是否是默认路由，每种“接口类型”只能配置一条默认路由。 取值说明： YES(是)NO(否)  说明： 当从非默认路由修改为默认路由时，不支持“域名”配置。 默认值：无。                                                                                              |
| RN     | 域名      | 域名。 取值范围：长度不超过64的字符串 默认值：无。                                                                                                                                                       |
| PSMODE | 对端选择方式  | 对端选择方式。 取值说明： MASTER_SLAVE（主备模式）：UPCF优选选择发送消息到主用DRA，当主用DRA故障时，发送消息到备用DRA。ROUND_ROBIN（轮询模式）：UPCF轮流选择DRA发送消息。USER_CTL（用户模式）：UPCF优先选择发送消息到原发送CCR消息的DRA，当原DRA故障时，再轮流选择其他正常DRA。 默认值：无。 |

## 使用实例

1. 查询所有的PCRF的域路由的配置信息。

   ```
   LST PREALMRT:;
   ```

   ```
   %%LST PREALMRT:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
    PCRF标识  路由标识  域路由名称  接口类型  是否是默认路由  域名    对端选择方式

    1         1         Route       Gx&Rx&Sd  否              dra     主备模式
    1         2         DRARoute    Sy        否              huawei  主备模式
   (结果个数 = 2)
   ---    END
   ```
2. 查询一条PCRF的域路由的配置信息。“PCRF标识”为“1”，“路由标识”为“2”。

   ```
   LST PREALMRT: PCRFID=1, RID=2;
   ```

   ```
   %%LST PREALMRT: PCRFID=1, RID=2;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
         PCRF标识  =  1
         路由标识  =  2
       域路由名称  =  DRARoute
         接口类型  =  Gx&Rx&Sd
   是否是默认路由  =  否
             域名  =  huawei
     对端选择方式  =  主备模式
   (结果个数 = 1)

   ---    END
   ```
