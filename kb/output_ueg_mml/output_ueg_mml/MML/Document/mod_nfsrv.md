# 修改网元实例信息(MOD NFSRV)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致系统异常，影响业务处理，需联系华为技术支持确认后再执行。

该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于修改网元实例信息。在该命令中，系统通过“网元实例名称”关键参数来唯一标识一条网元实例信息。

## 注意事项

- 网元实例信息被修改后，若“更新开关”打开，则立刻按指定的更新模式向NRF发起注册更新请求，仍旧需要维持周期心跳注册。心跳周期以更新响应中的“心跳周期”为准；“上报网管标志”、“更新方法”修改后，不需要发送注册更新请求。
- “网元公共信息标识”、“网元信息标识”和“网元服务组”这三个参数所定义的“网元类型”与修改的网元实例信息的“网元类型”必须相同。
- 当要删除参数“PLMN组名称”、“S-NSSAI组名称”、“网元信息标识”、“网元服务组”、“网元服务范围组名称”、“网元SCP域组名称”、“网元集合组名称”、“NSI列表”或“位置”时，需要在本命令中将对应参数的取值设置为“NULL”。

## 使用实例

修改“网元实例名称”为“pcf-application-002”网元实例信息，将“PLMN组名称”修改为“nfplmn02”，将“号段配置检查开关”修改为“FALSE(FALSE)”：

```
MOD NFSRV: NFINSNAME="pcf-application-002", CONFMODE=COMMAND, NFPLMNGRP="nfplmn02", RANGEGRPCHK=FALSE;
```
