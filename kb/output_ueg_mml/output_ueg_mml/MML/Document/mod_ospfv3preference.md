# 修改OSPFv3路由优先级配置（MOD OSPFV3PREFERENCE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改OSPFv3协议路由的优先级。

#### 注意事项

- 该命令执行后立即生效。
- 只有配置了OSPFv3进程后才能使用该命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称      | 参数说明                                                                                                                                  |
|:----------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------|
| PROCID          | OSPFv3进程号 | 可选必选说明：必选参数 参数含义：OSPFv3进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 配置原则：OSPFv3进程必须已经存在。请使用LST OSPFV3命令查看可用的OSPFv3进程。            |
| TOPOID          | 拓扑标识      | 可选必选说明：必选参数 参数含义：拓扑标识。 数据来源：全网规划 取值范围：整数类型，取值范围为0。 默认值：无 配置原则：目前只支持默认拓扑0。                                                             |
| ROUTETYPE       | 路由类型      | 可选必选说明：必选参数 参数含义：路由类型。 数据来源：本端规划 取值范围：枚举类型。 non-ase：非AS-External路由。ase：AS-External路由。 默认值：无                                           |
| PREFERENCEVALUE | 优先级       | 可选必选说明：可选参数 参数含义：优先级。 数据来源：本端规划 取值范围：整数类型，取值范围为1～255。 默认值：无 配置原则：PREFERENCEVALUE和ROUTEPOLICYNAME参数必须至少配置其中一个。                         |
| ROUTEPOLICYNAME | 路由策略名称    | 可选必选说明：可选参数 参数含义：路由策略名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无 配置原则： 输入单空格将删除该参数已有配置项。PREFERENCEVALUE和ROUTEPOLICYNAME参数必须至少配置其中一个。 |

#### 使用实例

修改OSPFv3进程1的路由优先级为150：

```
MOD OSPFV3PREFERENCE:PROCID=1,TOPOID=0,ROUTETYPE=ase,PREFERENCEVALUE=150;
```
