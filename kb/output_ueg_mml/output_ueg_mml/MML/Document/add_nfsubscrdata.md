# 增加网元订阅信息(ADD NFSUBSCRDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加一条订阅信息，如果NCS(NRFClientService)需要收到符合以下限制条件的网元发生变更时对其发送通知，可执行此命令。

- NCS订阅的网元实例在NRF上完成注册时。
- NCS订阅的网元实例在NRF上完成去注册时。
- NCS订阅的网元实例在NRF上更新nfProfile时。

## 注意事项

- 执行该命令，如果“订阅状态”为“SUBSCRIBED”，NCS向NRF发送订阅请求，以便NRF将满足订阅条件的网元实例发送通知消息给NCS。
- 该命令为调测命令，仅适用于开局阶段调测或者维护的操作场景。

## 使用实例

增加一个网元订阅信息。“订阅名称”为“SUBSCRIBED1”，“通知URL”为“http://192.168.48.31:8080/v1”，“订阅条件”为“NFTYPECOND”，“目标网元类型”为“AMF”,“有效时间”为“2022&04&16&19&33&24”，“通知事件类型”为“ALL”,“网元类型”为“PCF”，“PLMN标识”为“{"mcc":"460","mnc":"08"}”,“通知条件”为“{"monitoredAttributes":["/ipv4Addresses","/allowedNfTypes"]}”,“订阅状态”为“SUBSCRIBED”:

```
ADD NFSUBSCRDATA: SUBSCRNAME="SUBSCRIBED1", NOTIFURL="http://192.168.48.31:8080/", SUBSCRCOND=NFTYPECOND, TARGETNFTYPE=AMF, VALIDITYTIME=2022&04&16&19&33&24, NOTIFEVENTS=ALL, NFTYPE=PCF, PLMNID="{\"mcc\":\"460\",\"mnc\":\"08\"}", NOTIFCOND="{\"monitoredAttributes\":[\"/ipv4Addresses\",\"/allowedNfTypes\"]}", SUBSCRSTATUS=SUBSCRIBED;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。
