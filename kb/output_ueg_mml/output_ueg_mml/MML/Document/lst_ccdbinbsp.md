# 查询基础软件参数的配置信息（LST CCDBINBSP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询基础软件参数的配置信息：

- 若需要查询全部基础软件参数数据记录的概要信息，请不要输入任何参数。
- 若需要查询某条基础软件参数数据记录的详细信息，请输入“基础软件参数名称”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称       | 参数说明                                                                                                                           |
|:---------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------|
| INBSPN   | 基础软件参数名称   | 可选必选说明：可选参数。 用于指示系统需要按照哪个基础软件参数名称来查询基础软件参数的配置信息；若不输入，则表示所有的基础软件参数名称。 取值范围：请参考产品手册的“CCDB软件参数” 默认值：无。 配置原则：无。                    |
| INBSPMOD | 基础软件参数修改标志 | 可选必选说明：可选参数 用于指示系统需要按照哪个基础软件参数修改标志来查询基础软件参数的配置信息；若不输入，则表示所有的基础软件参数修改标志。 取值范围：TRUE(是)：被修改过的软参。FALSE(否)：没有被修改过的软参。 默认值：无 配置原则：无。 |

## 使用实例

查询“校验操作总定时器”基础软件参数的配置信息。

```
LST CCDBINBSP: INBSPN=DBSRV_TVERIFYOPER;
```

```
%%LST CCDBINBSP: INBSPN=DBSRV_TVERIFYOPER;%%
RETCODE = 0  操作成功

操作结果如下
------------------------
            基础软件参数名称  =  校验操作总定时器
              基础软件参数值  =  2500
          基础软件参数最小值  =  500
          基础软件参数默认值  =  2500
          基础软件参数最大值  =  4500
        基础软件参数修改标志  =  否
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见

**MOD CCDBINBSP**

命令的参数说明。表1列出的是未包含在

命令参数含义中的输出项。

| 输出项名称      | 输出项解释                                   |
|:-----------|:----------------------------------------|

| 基础软件参数默认值  | 用于返回基础软件参数的默认值。                         |
| 基础软件参数最大值  | 用于返回基础软件参数的最大值。                         |
| 基础软件参数修改标志 | 用于返回基础软件参数值的修改标志。是：被修改过的软参。否：没有被修改过的软参。 |
