# 删除网元默认通知订阅信息(RMV NFNOTIFSUB)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致系统异常，影响业务处理，需联系华为技术支持确认后再执行。

该命令用于删除一条网元默认通知订阅信息数据。

## 注意事项

- 若该网元默认通知订阅信息被**ADD NFSERVICE**命令引用了，则检查是否是GRPNAME下最后一条记录，是则该网元信息不能被删除。
- 若该网元默认通知订阅信息可以被删除时，检查当前GRPNAME是否被**ADD NFSERVICE**命令引用，若在**ADD NFSERVICE**中引用，还需要检查**ADD NFSERVICE**是否在**ADD NFSRV**中引用，如果在**ADD NFSRV**中有引用，且NFSRV当前已注册，则按NFSRV中指定的更新模式60秒内向NRF发送Nnrf\_NFManagement\_NFUpdate Request消息请求更新。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                            |
|:--------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GRPNAME | 组名称    | 可选必选说明：必选参数 参数含义：标识一组网元默认通知订阅信息所属组名称的关键字段之一，用于指定需要删除哪一组网元默认通知订阅信息，操作员可以使用LST NFNOTIFSUB命令查询获得。和索引组成全局唯一对象关键字段。 取值范围：由数字、字母、“-”或“_”组成的长度不超过32的字符串 默认值：无。 配置原则：无。 |
| INDEX   | 索引     | 可选必选说明：必选参数 参数含义：标识一条网元默认通知订阅信息的关键字段，用于指定需要删除哪一条网元默认通知订阅信息记录，操作员可以使用LST NFNOTIFSUB命令查询获得。和组名称组成全局唯一对象关键字段。 取值范围：1~1024 默认值：无。 配置原则：无。                           |

## 使用实例

删除网元默认通知订阅信息，“组名称”为“notifsub-group-01”，“索引”为“1010”：

```
RMV NFNOTIFSUB: GRPNAME="notifsub-group-01", INDEX=1010;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释              | 原因分析                                        | 处理建议                                |
|-------:|:-------------------|:--------------------------------------------|:------------------------------------|
|    505 | 当前操作的配置数据不存在。      | “索引”不存在。                                    | 使用LST NFNOTIFSUB命令查询获得“索引”，确保其值已存在。 |
| 360044 | 当前记录在其他命令中引用，无法删除。 | 指定“索引”所在组的“组名称”被NFSERVICE引用，只剩一条记录时无法被删除报错。 | 先删除引用该组的NFSERVICE信息，再删除该组。          |
