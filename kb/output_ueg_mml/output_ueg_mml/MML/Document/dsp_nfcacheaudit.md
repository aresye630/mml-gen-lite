# 查询网元缓存审计结果（DSP NFCACHEAUDIT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询主NCS与备NCS、主NCS与PES服务之间上一次的网元缓存信息审计结果。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询网元缓存审计结果。

```
DSP NFCACHEAUDIT: ;
```

```
%%DSP NFCACHEAUDIT: ;%%
RETCODE = 0  操作成功

操作结果如下：
------------
服务类型  实例号                开始时间             结束时间             结果 
NCS       11590312098855114855  2023-02-20 09:29:59  2023-02-20 09:29:59  成功
PES       11577996731105246976  2023-02-20 09:29:59  2023-02-20 09:29:59  成功
PES       11577996731105401908  2023-02-20 09:29:59  2023-02-20 09:29:59  成功
(结果个数 = 3)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义如表1。

| 输出项名称   | 输出项解释                                                                                                                              |
|:--------|:-----------------------------------------------------------------------------------------------------------------------------------|
| 服务类型    | 表示上一次审计的网元缓存信息属于具体哪个服务类型。 取值范围： PESNCS                                                                                             |
| 实例号     | 表示服务的实例号。                                                                                                                          |
| 开始时间    | 表示主NCS上一次向PES或者备用NCS请求审计MD5的时间。 取值范围：格式为“YYYY-MM-DD HH:MM:SS”的字符串。例如：2022-09-15 11:18:04。                                          |
| 结束时间    | 表示主NCS上一次向PES或者备NCS同步完网元缓存信息后的时间。如果主NCS上一次向PES或者备用NCS请求审计MD5超时，则表示是超时时间。 取值范围：格式为“YYYY-MM-DD HH:MM:SS”的字符串。例如：2022-09-15 11:20:04。 |
| 结果      | 表示上一次审计的结果。 取值范围： 成功失败                                                                                                             |
