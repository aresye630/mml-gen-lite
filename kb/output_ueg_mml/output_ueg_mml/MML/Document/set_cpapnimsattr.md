# 设置APN的IMS属性（SET CPAPNIMSATTR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于建立IMS承载时，设置APN绑定的IMS相关属性。

## 注意事项

- 该命令执行后立即生效。

- 在每次执行ADD CPAPN命令时会自动为本命令增加一条记录，记录中参数的初始设置值如下：IMSSWITCH：INHERIT，SIGNALRADIOPRE：DISABLE。
- 当前版本不支持此命令的SIGNALRADIOPRE参数。
- 当IMSSWITCH的值为INHERIT时，GLOBALIMS必须要配置缺省P-CSCF组。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                                                                                                                            |
|:---------------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN            | APN名称    | 可选必选说明：必选参数  参数含义：该参数用于指定APN实例名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无。  配置原则：  该参数使用ADD CPAPN命令配置生成。 |
| IMSSWITCH      | IMS开关    | 可选必选说明：可选参数  参数含义：该参数用于配置IMS互通相关的设置。  数据来源：本端规划 取值范围： “DISABLE（不使能）”：关闭IMS。“ENABLE（使能）”：打开IMS。“INHERIT（继承）”：设置IMS功能，设置后继承GLOBALIMS的IMSSWITCH参数配置。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CPAPNIMSATTR查询当前参数配置值。  配置原则：无       |
| SIGNALRADIOPRE | 信令空口增强开关 | 可选必选说明：该参数在"IMSSWITCH"配置为"ENABLE"时为条件可选参数。  参数含义：该参数用于设置IMS信令空口增强开关。  数据来源：本端规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CPAPNIMSATTR查询当前参数配置值。  配置原则：  该参数已弃用。                                    |

## 使用实例

需要设置“APN名称”为“HUAWEI.COM”的IMS属性，打开IMS功能和IMS信令空口增强开关。

```
SET CPAPNIMSATTR:APN="huawei.com",IMSSWITCH=ENABLE,SIGNALRADIOPRE=ENABLE;
```
