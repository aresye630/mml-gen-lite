# 删除PCRF的Diameter对端(RMV PEER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致相关业务中断，请联系华为技术支持确认后再执行。

该命令为配置类命令，用于在配置数据库中删除一条与PCRF直连的Diameter对端实体数据记录。

## 注意事项

- 如果此对端已经配置链路，则必须先执行**RMV PEERL**命令删除此对端的所有链路，再删除此对端。
- 如果此对端是DRA，并且已经配置域路由记录，则必须先执行**RMV PREALMRT**命令删除此对端的所有域路由记录，再删除此对端。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                      |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------|
| PCRFID | PCRF标识 | 用于标识PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围：1 默认值：无。                                                   |
| PEERID | 对端标识   | 用于在UPCF的配置库中定义一个Diameter对端实体。 取值范围：0～127 默认值：无。 说明： 对端类型选择DRA时，对端标识的取值范围是0～15。对端类型选择TDF时，对端标识的取值范围是0～127。 |
| PT     | 对端类型   | 用于定义对端类型。 取值范围： DRA(DRA)TDF(TDF) 默认值：无。                                                                   |

## 使用实例

删除PCRF对端实体配置信息。“PCRF标识”为“1”，“对端标识”为“0”，“对端类型”为“DRA”。

```
RMV PEER: PCRFID=1, PEERID=0, PT=DRA;
```
