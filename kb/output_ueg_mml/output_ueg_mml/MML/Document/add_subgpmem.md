# 增加用户群成员(ADD SUBGPMEM)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

此命令用于增加用户群成员记录。

#### 注意事项

- 此命令执行后立即生效。
- 此命令最大记录数为20000。
- 此命令配置的“SUBID（用户群标识）”参数值不能在**ADD MSISDNSUBGPMEM**配置中使用。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                      |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------|
| SUBID   | 用户群标识  | 可选必选说明：必选参数 参数含义：该参数用于指定用户群标识。 前提条件：在“MML命令行-UEG”窗口上执行命令ADD SUBGP设置此参数。 数据来源：整网规划 取值范围：1～100 默认值：无 配置原则：配置的参数值不能在ADD MSISDNSUBGPMEM配置中使用。 |
| IMSIPRE | IMSI前缀 | 可选必选说明：必选参数 参数含义：该参数用于指定IMSI前缀。 数据来源：整网规划 取值范围：5～15位十进制数字 默认值：无                                                                           |

#### 使用实例

增加一条用户群成员记录，用户群标识为30，IMSI前缀为12345：

ADD SUBGPMEM: SUBID=30, IMSIPRE="12345";
