# 删除主接口二层透传模式（RMV IFL2FLOWMODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来删除接口的二层透传模式。

#### 注意事项

- 该命令执行后立即生效。
- 该命令会将接口的转发模式从二层透传修改三层转发，同时接口下其他配置会开始生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                          |
|:-------|:-------|:----------------------------------------------------------------------------------------------|
| IFNAME | 接口名称   | 可选必选说明：必选参数 参数含义：接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～47。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。 |

#### 使用实例

删除指定主接口的二层透传模式：

```
RMV IFL2FLOWMODE:IFNAME="Ethernet66/0/5";
```
