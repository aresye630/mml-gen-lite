# 删除DLB VPN(RMV DLBVPN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在配置数据库中删除一条DLB接入CSLB时业务IP地址的VPN数据记录。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                    |
|:---------|:-------|:----------------------------------------------------------------------------------------|
| VPNINDEX | VPN索引  | 可选必选说明：必选参数 参数含义：本参数用于标识CSLB业务IP的VPN索引，操作员可以使用LST DLBVPN命令查询获得。 取值范围：0-15 默认值：无 配置原则：无。 |

## 使用实例

删除一条VPN数据记录。“VPN索引”为“0”。

```
RMV DLBVPN: VPNINDEX=0;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
