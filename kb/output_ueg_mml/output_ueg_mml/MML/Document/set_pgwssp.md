# 设置PGW系统软参(SET PGWSSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令不实际用于修改PGW系统软参取值，仅用于在割接等重大操作场景下，通过CSP OM Portal执行**EXP MML**命令在原有能力基础上支持导出PGW系统软参配置记录。

## 注意事项

- PGW系统软参值的修改仅能通过PGW Web LMT执行**SET PSYSPARA**命令修改生效，无法通过本命令执行生效**。**
- 若执行此命令对PGW系统软参值进行修改，则修改不生效。

## 参数说明

| 参数标识              | 参数名称   | 参数说明                                                                                                                                                                       |
|:------------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SYSPARAMETER      | 参数名    | 指定PGW系统软参名。 取值说明：详细信息请参考产品手册的“参考 > PGW Web LMT用户数据和全局数据管理 > PGW Web LMT命令 > 全局数据命令组 > 系统参数管理 > 设置系统参数（SET PSYSPARA）”中“参数标识”列描述的枚举值。 默认值：无。                                 |
| SYSPARAMETERVALUE | 参数值    | 用于对指定的PGW系统软参设置参数值。 取值范围：0～2147483647  说明： 详细信息请参考产品手册的“参考 > PGW Web LMT用户数据和全局数据管理 > PGW Web LMT命令 > 全局数据命令组 > 系统参数管理 > 设置系统参数（SET PSYSPARA）”中“参数说明”列描述的取值范围、取值功能。 默认值：无。 |

## 使用实例

无需提前执行该命令即可在CSP OM Portal下执行**EXP MML**导出PGW软参配置。

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
