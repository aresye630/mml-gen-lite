# 增加GTP-C V2协议兼容性(ADD GTPCV2CMPT)

#### 命令功能

**适用网元：SGSN、MME**

该命令用于配置GTP-C V2消息是否携带特性信元以及定义相关信元格式。主要用于因UNC产品进行了协议升级，或对端设备对3GPP TS 29.274标准协议定义的消息和信元理解不一致而产生兼容性问题的场景。

#### 注意事项

- 此命令执行后立即生效。
- 此命令最大记录数为512条。
- 一般情况下，如果未配置GTP消息中是否允许携带特定的可选信元时，系统缺省按协议定义携带，特殊情况在参数描述中进行说明。
- “消息分类”、“消息类型”和“信元类型”三个参数唯一确定一条记录。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

加一条增加GTP-C V2协议兼容性的配置，设置消息分类为MM（移动管理），消息类型为FWD\_RLC\_REQ（Forward Relocation Request）的消息， 按协议定义携带Serving Network信元：

ADD GTPCV2CMPT: IDX=0, MSGCLS=MM, MMMSGTYPE=FWD\_RLC\_REQ, FWDRLCREQ=SERNET, INCLUDE=PRO\_DEFINE;
