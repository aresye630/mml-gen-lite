# 增加DBS链路中心(ADD DBSLINKCTRL)

- 命令功能

- 参数说明
- 使用实例

## 命令功能

该命令用于增加DBS链路中心。

该命令的使用场景：当BE网元与FE网元使用链路中心方式对接时，使用该命令增加FE网元的DBS链路中心。

BE网元设置一个DSG链路中心，FE网元设置一个DBS链路中心，链路中心负责将自身网元的DBS（DSG）和IP信息发送到对端局点，同时接收对端局点发送的配置信息。

配置对接通常有以下步骤：

1. 通过本组命令增加DBS链路中心。
2. 通过**ADD DBSRLOCATION**命令增加远端Location标识。
3. 通过**ADD DBSRLINKCTRL**命令增加远端DSG链路中心。
4. 通过**SYN DBSRDSG**同步对端DSG信息到本端数据库。
5. 通过**SYN DBSRIPADDR**同步对端IP信息到本端数据库。

在对接双方都经过以上配置之后，通过**ACT DBSIPDISP**命令激活链路，完成对接配置。

DBS链路中心：DBS链路中心负责将自身网元的DBS和IP信息发送到对端局点，同时接收对端局点发送的配置信息。链路中心指定IP，端口号固定为1999。同时配置对端网元的DSG链路中心的IP，链路中心将使用配置的IP和固定端口建立网元间的通讯通道，发送配置信息。

## 注意事项

- DBS链路中心需要存在DBS服务。
- “本地链路中心IPV4地址”或“本地链路中心IPV6地址”参数必须先由**ADD DBSIPADDR**命令定义，然后才能通过该命令配置DBS链路中心。
- 通过“本地链路中心校验码”参数指定的本端链路中心校验码，必须与在远端网元执行**ADD RDSGLINKCTRL**或**MOD RDSGLINKCTRL**指定的校验码一致，否则会导致本网元无法接收该远端的配置消息。
- “本地链路中心校验码”不支持查询，如无法获取，可执行**RMV DBSRLINKCTRL**删除已存在的远端DSG链路中心，然后执行**ADD DBSLINKCTRL**和**ADD DBSRLINKCTRL**重新设置“本地链路中心校验码”和“远端链路中心校验码”后增加DBS的本端和远端链路中心。
- 本命令配置的“本地链路中心校验码”参数检查在USCDB网元侧进行，禁止配置的“本地链路中心校验码”可以通过**ADD WEAKPWD**命令配置或通过**LST WEAKPWD**命令查询。

## 参数说明

| 参数标识      | 参数名称         | 参数说明                                                                                                                                                                                                                                                                 |
|:----------|:-------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICENO | 服务模块号        | 可选必选说明：必选参数 参数含义：用于指定网元的DBS服务模块号。 取值范围：1～1024 默认值：无。 配置原则：DBS服务模块号先由ADD DBSSERVICENO命令定义，然后才能在此处索引。                                                                                                                                                                  |
| IPVER     | IP类型         | 可选必选说明：必选参数 参数含义：用于指定IP地址类型。 取值范围： IPV4：当系统要求使用IPv4类型的IP地址时选择此选项。IPV6：当系统要求使用IPv6类型的IP地址时选择此选项。 默认值：无。 配置原则：无                                                                                                                                                        |
| IPV4IP    | 本地链路中心IPV4地址 | 可选必选说明：条件必选参数 参数含义：用于指定IPV4类型的本地IP地址。 该参数必须先由ADD DBSIPADDR命令定义才能在此处引用。 取值范围：IPV4格式的地址。 默认值：无。 配置原则：仅当本命令中的“IP类型”参数设置为“IPV4(IPV4)”时该参数有效。                                                                                                                             |
| IPV6IP    | 本地链路中心IPV6地址 | 可选必选说明：条件必选参数 参数含义：用于指定IPV6类型的本地IP地址。格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如：2001:DB8:8432:4098:4782:5784::。 该参数必须先由ADD DBSIPADDR命令定义才能在此处引用。 取值范围：IPV6格式的地址。 默认值：无。 配置原则：仅当本命令中的“IP类型”参数设置为“IPV6(IPV6)”时该参数有效。                                              |
| PASSWORD  | 本地链路中心校验码    | 可选必选说明：必选参数 参数含义：用于指定本端链路中心的校验码。 取值范围：符合校验码复杂度的字符串。 默认值：无。 配置原则：校验码区分大小写，其复杂度需同时满足下列条件：必须至少包含以下四个类别中的三类：英文大写字母。英文小写字母。数字：0～9。特殊字符：~ ! # % ^ * ( ) _ - + [ ] { } | < > . ?。 不允许使用三个或三个以上连续的字母或数字（例如：ABC、123）。不允许使用三个或三个以上连续的相同字符（例如：AAA）。长度最短8个字符，最长30个字符。第一个字符必须是字母。 |

## 使用实例

在开局场景下，增加DBS链路中心，“服务模块号”为“111”，“IP类型”为“IPV4”，“本地链路中心IPV4地址”为“192.168.39.40”，“本地链路中心校验码”为“\*\*\*\*\*\*”。命令示例如下：

```
ADD DBSLINKCTRL: SERVICENO=111, IPVER=IPV4, IPV4IP="192.168.39.40", PASSWORD="******";
```

**说明** 

“本地链路中心校验码”使用密码控件，每一个校验码字符在命令行输入区域均显示为“\*”。
