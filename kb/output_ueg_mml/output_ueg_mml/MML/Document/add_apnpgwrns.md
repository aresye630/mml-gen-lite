# 增加PGW重定向功能设置（ADD APNPGWRNS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C**

该命令用于增加PGW重定向功能设置。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入20000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                    |
|:-------------|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN          | APN名称      | 可选必选说明：必选参数  参数含义：该参数用于指定APN实例名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无  配置原则：  输入的APN名称需要符合APN命名规则，仅支持配置APN NI（Network Identifier），例如“huawei.com”。一般情况下用真实APN进行配置，但若开启虚拟APN映射功能，则使用请求APN进行配置。 |
| PGWRNSSWITCH | PGW重定向功能开关 | 可选必选说明：必选参数  参数含义：该参数用于指示是否支持PGW重定向功能。  数据来源：本端规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无  配置原则：  如果打开本开关，即便关闭SMFFUNC中的REPSNSSAI，或关闭软参APN_DWORD_1 BIT9，PGW也会与UDM交互。                                                                                                                                                         |

## 使用实例

增加APN为“HUAWEI.COM”的PGW重定向功能配置：

```
ADD APNPGWRNS: APN= "huawei.com", PGWRNSSWITCH= ENABLE;
```
