# 查询流控配置(LST DLBFLOWCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询DLB流控参数信息。

- 如果需要查询所有DLB流控参数信息，请不要输入任何参数。
- 如果需要查询指定DLB流控参数信息，请依据参数说明输入查询的条件。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称         | 参数说明                                                                                                             |
|:----------|:-------------|:-----------------------------------------------------------------------------------------------------------------|
| FLWCTRFLG | 流量控制开关       | 可选必选说明：可选参数 参数含义：用于指示系统按照是否开启“流量控制开关”来查询流控参数；若不输入，则表示所有的流量控制开关。 取值范围： ON(打开流控) OFF(关闭流控) 默认值：无。 配置原则：无。          |
| CPUFLWSTR | CPU启控阈值      | 可选必选说明：可选参数 参数含义：用于指示系统按照“CPU启控阈值”的值来查询流控参数；若不输入，则表示所有的CPU启控阈值。 取值范围：10-100 单位：％ 默认值：无。 配置原则：无。                  |
| CPUFLWEND | CPU解控阈值      | 可选必选说明：可选参数 参数含义：用于指示系统按照“CPU解控阈值”的值来查询流控参数；若不输入，则表示所有的CPU解控阈值。 取值范围：0-90 单位：％ 默认值：无。 配置原则：无。                    |
| MINMSGNUM | 启动流量控制的最小消息量 | 可选必选说明：可选参数 参数含义：用于指示系统按照“启动流量控制的最小消息量”的值来查询流控参数；若不输入，则表示所有的启动流量控制的最小消息量。 取值范围：100-65535 单位：TPS 默认值：无。 配置原则：无。   |
| TSSTR     | 时延启控阈值       | 可选必选说明：可选参数 参数含义：用于指示系统按照“时延启控阈值”的值来查询流控参数；若不输入，则表示所有的时延启控阈值。 取值范围：1-2500 单位：毫秒 默认值：无。 配置原则：无。                   |
| TSEND     | 时延解控阈值       | 可选必选说明：可选参数 参数含义：用于指示系统按照“时延解控阈值”的值来查询流控参数；若不输入，则表示所有的时延解控阈值。 取值范围：0-1000，取值为“0”表示关闭时延流控功能。 单位：毫秒 默认值：无。 配置原则：无。 |

## 使用实例

假如运营商需要修改DLB流量控制开关、启控条件等参数，需要先查询DLB流控配置。

```
LST DLBFLOWCTRL:;
```

```
%%LST DLBFLOWCTRL:;%%
RETCODE = 0  操作成功

操作结果如下 
------------
            流量控制开关  =  打开流控
             CPU启控阈值  =  90
             CPU解控阈值  =  85
启动流量控制的最小消息量  =  1350
            时延启控阈值  =  50
            时延解控阈值  =  30
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**MOD DLBFLOWCTRL**命令的参数说明。
