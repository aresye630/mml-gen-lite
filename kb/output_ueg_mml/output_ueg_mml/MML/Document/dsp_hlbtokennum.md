# 查询Token分配数量（DSP HLBTOKENNUM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询HLB作为服务端或客户端时各微服务实例的Token分配数量。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                     |
|:----------|:--------|:-------------------------------------------------------------------------------------------------------------------------|
| TOKENTYPE | Token类型 | 可选必选说明：必选参数 参数含义：查询Token分配信息的关键字段，用于标识根据哪种类型查询Token分配数量。 取值范围： Client_token(客户端Token)Server_token(服务端Token) 默认值：无 配置原则：无 |

## 使用实例

查询客户端Token的分配数量。

```
DSP HLBTOKENNUM: TOKENTYPE=Client_token;
```

```
%%DSP HLBTOKENNUM: TOKENTYPE=Client_token;%%
RETCODE = 0  操作成功

操作结果如下:

(结果个数 = 2)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参考本命令参数说明，表1列出的是未包含在参数说明中的输出项。

| 输出项名称   | 输出项解释         |
|:--------|:--------------|
| 微服务实例ID | 微服务实例ID。      |
| Pod名称   | Pod的名称。       |
| Token数量 | 分配到的Token的数量。 |
