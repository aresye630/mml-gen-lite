## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响系统性能，需联系华为技术支持确认后再执行。

该命令用于启动导出单用户EDR日志记录，通过导出的日志记录来定位问题分析，增强产品的可维护性和服务性。

**说明** 

执行本命令建议在非话务高峰期导出，否则对ADD-N虚拟机（pcf-addn-pod）性能最大下降25%。

对于“正则表达式”，使用不当会导致生成文件过大，导致筛选内容过多影响性能。需要用到“正则表达式”参数时，请联系华为技术工程师处理。

## 注意事项

- “用户标识”和“正则表达式”至少输入一个，且“开始时间”和“结束时间”必须同时输入或者都不输入。
- 如果输入“开始时间”和“结束时间”，则基于输入的时间范围段内的EDR记录进行过滤，反之则默认查询近3天以内的EDR记录。
- 若同时输入“用户标识”和“正则表达式”，“用户标识”优先级高于“正则表达式”，会以“用户标识”为EDR日志筛选导出的生效条件。
- 每次执行本命令只能生成100M左右的一个EDR文件，如果重新执行，新生成的文件会覆盖掉原来的文件。
- 在本命令执行过程中，生成过滤后的EDR文件在100M左右会截断处理，不会继续生成。（说明：EDR记录过滤是按照行粒度搜索，所以存在些许误差，会在100M上下浮动）
- 筛选出来的单用户EDR日志存留期默认为4小时，保存时长超过存留期的日志则删除该文件。
- 过滤导出EDR文件参考时长与现网话务情况相关，导出最大时长约25分钟。
- 日志文件获取方法：

  1、在OM Portal上选择“应用管理>MML”，选择“UPCF”网元，在“ OTS管理>EDR管理>导出EDR日志”进入命令执行界面。输入“用户标识”或“正则表达式”，日志记录的“开始时间”和“结束时间”，单击“执行”按钮。

  **说明** 

  此处“开始时间”和“结束时间”需要设置为预期导出的EDR日志时间段。

  2、在“监控分析>运行日志>服务日志收集"页面，“应用名称”选择UPCF网元对应的应用，勾选“UcfEDRCollect”服务日志，单击“开始收集”按钮。在完成日志收集后，单击“日志下载地址”的链接进行下载。

  **说明** 

  由于服务日志收集机制，在执行**EXP EDRLOG**命令后，若“服务日志收集”下无“UcfEDRCollect”服务日志选项，请等待5分钟后重新查看并收集下载。
- 日志文件输出到UCF服务所在容器的 "/opt/container/productlog/edrcollect/result/”路径目录下。生成的EDR文件名包含EDR\_UPCF<网元ID>\_**TASKID**\_YYYYMMDDHHMMSSMSS.csv.gz和EDR\_UPCC<网元ID>\_MPU<模块号>\_SequenceCounter\_**TASKID**\_YYYYMMDDHHMMSS.csv.gz这两种格式，其中"TASKID"标识是生成的哪个EDR日志任务。其他组成部分代表含义可参见EDR日志。
- 如果SET EDRCONFIG命令中参数“匿名化开关”设置为“ON”，开启EDR匿名化功能后，通过本命令导出的EDR字段SubscriberIdentifier、IMSI、MSISDN、Trans-in Subscriber ID、GroupSubID和OldGroupSubID会存在匿名化的情况。
- 导出的日志包含用户的个人数据，如：IMSI、MSISDN等。因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护。例如：
  1. 采用安全的文件传输协议（如SFTP）传输文件。
  2. 并严格控制文件的访问权限。
  3. 及时清理数据文件。

  在从运营商网络获取数据前，必须要获得运营商的授权。

  若需从运营商网络中获取必要的数据，需要运营商维护人员对其中的个人数据进行匿名化处理，匿名化后的数据由运营商维护人员审核后提供，以防止个人数据泄露。匿名化处理工具可以在https://support.huawei.com/获取，获取方法请参见产品手册“匿名化工具安全策略”页面。

## 参数说明

| 参数标识              | 参数名称   | 参数说明                                                                                                             |
|:------------------|:-------|:-----------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER     | 用户标识   | 可选必选说明：可选参数。 参数含义：用于指定某一用户的唯一标识，系统可根据此唯一标识筛选导出该用户的EDR日志文件。 取值范围：长度不超过255的字符串。 默认值：无。                             |
| REGULAREXPRESSION | 正则表达式  | 可选必选说明：可选参数。 参数含义：主要是用于按照EDR记录的trigger type或者号段进行筛选。 取值范围：只允许“^ [ ] - + : . { } 0–9 a-z A-Z _”，最大255的字符串。 默认值：无。 |
| STARTTIME         | 开始时间   | 可选必选说明：可选参数。 参数含义：用于指定查询该单用户EDR日志的起始时间。 取值范围：格式为“YYYY&MM&DD&HH&MM&SS”的字符串。 默认值：无。                                |
| ENDTIME           | 结束时间   | 可选必选说明：可选参数。 参数含义：用于指定查询该单用户EDR日志的结束时间。 取值范围：格式为“YYYY&MM&DD&HH&MM&SS”的字符串。 默认值：无。                                |

## 使用实例

导出某单用户的EDR日志文件，执行命令如下：

```
EXP EDRLOG:;
```

```
%%EXP EDRLOG: USRIDENTIFIER="41236542001";%%
RETCODE = 0  操作成功
---    END
```
