# 查询LDAP链路配置信息(LST LDAPLNK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询LDAP服务与外置SPR数据库的链路数据记录。

- 若需要查询全部LDAP链路数据记录的概要信息，请不要输入任何参数。
- 若需要查询某条LDAP链路数据记录的详细信息，请输入“链路ID”或其他参数或这些参数的组合。
- 当TLS功能设置为“ON(打开)”时，LDAP服务性能将会下降20%，如需开启请联系华为技术支持。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                          |
|:----------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LINKID    | 链路ID     | 可选必选说明：可选参数 参数含义：用于标识一条LDAP与对端外置SPR数据库的链路配置信息的数据记录。 取值范围：0～31 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                  |
| LNKNAME   | 链路名称     | 可选必选说明：可选参数 参数含义：用于描述LDAP与对端外置SPR链路的名称。 取值范围：长度不超过32的字符串 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                       |
| IPVER     | IP版本     | 可选必选说明：可选参数 参数含义：用于指定IP地址的IP版本类型。 取值范围：IPV4(IPV4) 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                              |
| LOCALIP   | 本端IPV4地址 | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV4(IPV4)”时该参数需配置，用于指定链路使用的本端LDAP设备的IPv4地址。 取值范围：IPv4地址 默认值：无。 配置原则：此IP地址必须是本地实际的IP地址且必须先由ADD LDAPDEVADDR命令定义，然后才能在此处引用。                                                                                                                                                                                                                                                                         |
| LOCALPORT | 本端端口     | 可选必选说明：可选参数 参数含义：用于描述LDAP链路的本端设备端口号。 取值范围：1～65534 默认值：无。 配置原则：运营商统一规划，必须是本端实际的设备端口号。                                                                                                                                                                                                                                                                                                                                          |
| PEERIP    | 对端IPV4地址 | 可选必选说明：可选参数 参数含义：LDAP服务与对端对接的参数之一，仅当“IP版本”选择“IPV4”时该参数有效，用于指定链路使用的对端IPv4地址。 取值范围：IPv4地址 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。                                                                                                                                                                                                                                                                                                     |
| PEERPORT  | 对端端口     | 可选必选说明：可选参数 参数含义：LDAP服务与对端对接的参数之一，用于指定链路使用的对端端口。 取值范围：1～65534 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。                                                                                                                                                                                                                                                                                                                               |
| USERNAME  | 用户名      | 可选必选说明：可选参数 参数含义：描述LDAP与外置SPR数据库连接时的登录用户，用于访问SPR数据库时进行校验。 取值范围：长度不超过64的字符串 默认值：无。 配置原则：与SPR数据库登录用户名相同。                                                                                                                                                                                                                                                                                                                        |
| DSPRI     | 数据源优先级   | 可选必选说明：可选参数 参数含义：描述一条LDAP链路的优先级，数字越大优先级越高。选路到对端时，优先选择高优先级的，当高优先级的链路全部不可用时，才会选择低优先级的。当对端有主备时，通常配置到主的链路的优先级高于到备的。 取值范围：1～16 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                      |
| ADSTS     | 链路管理状态   | 可选必选说明：可选参数 参数含义：描述LDAP链路的管理状态，包括：使能、去使能。不选择管理状态为去使能的链路进行业务消息交互。 取值范围： DISABLE(去使能)： 配置链路但不用来进行业务消息交互。ENABLE(使能)： 配置链路可以用来进行业务消息交互。 默认值： 无。 配置原则：无。                                                                                                                                                                                                                                                                           |
| TLSFUNC   | TLS功能    | 可选必选说明：可选参数 参数含义：表示是否启用TLS证书。 取值范围： ON(打开)：表示启用TLS证书。OFF(关闭)：表示不启用TLS证书。 默认值：无。 升级场景：默认值为OFF(关闭) 配置原则：无。  说明： TLS协议支持TLS1.3和TLS1.2。支持如下TLS加密算法：TLS_AES_128_GCM_SHA256TLS_AES_256_GCM_SHA384TLS_CHACHA20_POLY1305_SHA256TLS_AES_128_CCM_SHA256TLS_AES_128_CCM_8_SHA256TLS_ECDHE_ECDSA_WITH_AES_128_GCM_SHA256TLS_ECDHE_ECDSA_WITH_AES_256_GCM_SHA384TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384 |
| CERTSCENE | 证书应用场景   | 可选必选说明：条件可选参数 参数含义：表示注册LDAP服务的TLS证书应用场景，仅当“TLS功能”配置为“ON(打开)”时该参数可配置。 取值范围：UPCF_LDAP_certForLDAPLNK(LDAP接口链路客户端证书) 默认值：无。 配置原则：无。  说明： 证书应用场景下关联的证书文件，必须是CA证书文件。                                                                                                                                                                                                                                                               |
| CRLPOLICY | CRL策略    | 可选必选说明：条件可选参数 参数含义：表示是否进行数字证书被吊销检查。仅当“TLS功能”配置为“ON(打开)”时该参数可配置。 取值范围： Check(检查)：表示根据CRL文件对对端数字证书进行检查。NoCheck(不检查)：表示直接将CRL文件存到本地后，不需要根据CRL文件对对端数字证书进行检查。 默认值：无。 配置原则：无。  说明： 当对对端数字证书进行检查时，如果系统检查到对端数字证书序列号（serial number）没有包含在CRL文件中则认为证书状态正常；否则系统会认为此证书已被吊销，中断与对端链路连接，并记录日志和上报ALM-34249数字证书安全性风险告警。                                                                                                                         |
| TLSCFGID  | TLS配置ID  | 可选必选说明：条件可选参数 参数含义：用于在配置库中定义一条TLS配置记录，取值不能重复。仅当“TLS功能”配置为“ON(打开)”时该参数可配置。 取值范围：1～128 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                           |

## 使用实例

1. 查询所有的LDAP服务和外置SPR的链路信息。

   ```
   LST LDAPLNK:;
   ```

   ```

   RETCODE = 0  操作成功

   操作结果如下:
   -------------
    链路ID  链路名称  IP版本    本端IPV4地址       本端端口   对端IPV4地址       对端端口  用户名  密码   数据源优先级 链路管理状态   TLS功能  证书应用场景               CRL策略    TLS配置ID

    4       LDAPNAME  IPV4      10.207.198.33        2020      10.207.198.3       2030     upcf    *****   1            使能          打开     LDAP接口链路客户端证书     检查       1
    10      NULL      IPV4      10.207.198.33        5060      10.207.198.3       5061     upcf    *****   5            使能          打开     LDAP接口链路客户端证书     检查       1

   ---    END
   ```
