# 清除远端用户数据同步用户密钥文件（RMV RDATASYNUSERKEY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于清除远端用户数据同步服务器用户已加载身份认证密钥文件。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                             |
|:-----------|:-------|:-------------------------------------------------------------------------------------------------|
| SERVERNAME | 服务器名称  | 可选必选说明：必选参数 参数含义：远端用户数据同步服务器名称。 数据来源：本端规划 取值范围：与LST RdataSynServer中的servername保持一致。 默认值：无 配置原则：无 |
| USERNAME   | 用户名称   | 可选必选说明：必选参数 参数含义：用于指定SFTP用户名。 数据来源：对端协商 取值范围：与远端SFTP服务器的用户名保持一致。 默认值：无 配置原则：无                    |
| KEYNAME    | 密钥名称   | 可选必选说明：必选参数 参数含义：用于创建用户加载密钥的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～128。 默认值：无 配置原则：无                  |

#### 使用实例

清除远端用户数据同步用户密钥文件，服务器名称为rdata1，用户名为abc，密钥名称key1：

```
RMV RDATASYNUSERKEY: SERVERNAME="rdata1", USERNAME="abc", KEYNAME = "key1";
```
