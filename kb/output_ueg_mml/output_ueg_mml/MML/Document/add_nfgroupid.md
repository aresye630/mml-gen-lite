# 增加NF群组信息（ADD NFGROUPID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMSF、NWDAF、NEF、SCF**

该命令用于增加NF实例支持的群组信息。当NF实例向NRF注册时，将实例的群组信息带给NRF，为业务流程中其他NF发现该NF时提供选择信息。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入1条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                                                                                                                          |
|:---------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCENAME | NF实例名称 | 可选必选说明：必选参数  参数含义：该参数用于指定NF实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~50。本参数的构成字符只能是字母A～Z或a～z、数字0～9、中划线"-"和下划线"_"，例如，SMSF_Instance_0。  默认值：无  配置原则：  本参数取值与ADD NFUUID命令中的“NF实例名称”参数取值保持一致时，关联关系生效。 |
| GROUPID        | 群组标识   | 可选必选说明：必选参数  参数含义：该参数用于指定NF服务的群组标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~50。  默认值：无  配置原则：无                                                                                                        |

## 使用实例

新增NF实例标识为SMSF\_Instance\_0，规划该NF支持的群组标识为GROUP01。

```
ADD NFGROUPID: NFINSTANCENAME="SMSF_Instance_0", GROUPID="GROUP01";
```
