# 增加话单统计（ADD CDRSTAT）

#### 命令功能

**适用NF：NCG**

该命令根据配置添加一个话单统计器，并根据选择的过滤策略（按接入网元分组、按通道名称和按数据网络名称）提取每用户每会话各个RG的汇总流量信息，通过话单下载界面可获取汇总结果。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识             | 参数名称         | 参数说明                                                                                                                                         |
|:-----------------|:-------------|:---------------------------------------------------------------------------------------------------------------------------------------------|
| CDRSTATID        | 话单统计任务标识     | 可选必选说明：必选参数 参数含义：话单统计任务标识，全局唯一。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则： 该参数不能包含“\”。不能输入的特殊字符请参考“特殊字符表”。                                |
| AGID             | 接入网元分组标识     | 可选必选说明：必选参数 参数含义：用于区分不同域的接入网元。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：“接入网元分组标识”可通过执行LST CDRPROC查询。                                    |
| CHLNAME          | 通道名称         | 可选必选说明：可选参数 参数含义：表示用于指定的要统计的通道名，区分大小写。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～2048。 默认值：无 配置原则： 不指定通道则不按通道过滤。多个通道采用“|”来分隔。具体通道信息可通过执行DSP FEMPACKET查询。 |
| DNN              | 数据网络名称       | 可选必选说明：可选参数 参数含义：表示用于指定的要统计的网络数据名称，不区分大小写。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～4096。 默认值：无 配置原则： 不指定网络数据名称则不按网络数据名称过滤。多个网络数据名称采用“|”来分隔。            |
| STATSTOREDAYS    | 统计结果保存天数     | 可选必选说明：可选参数 参数含义：用来设置话单统计结果的保存天数，单位为天。 数据来源：本端规划 取值范围：整数类型，取值范围为3 ~ 180。 默认值：30 配置原则：无                                                       |
| CDRSTARTTIME     | 话单文件开始时间     | 可选必选说明：必选参数 参数含义：用来设置话单统计文件的开始时间。 数据来源：本端规划 取值范围：日期时间类型 默认值：无 配置原则：无                                                                         |
| CDRENDTIME       | 话单文件结束时间     | 可选必选说明：必选参数 参数含义：用来设置话单统计文件的结束时间。 数据来源：本端规划 取值范围：日期时间类型 默认值：无 配置原则：无                                                                         |
| STARTTIME        | 在指定时间点开始话单统计 | 可选必选说明：可选参数 参数含义：用来指定话单统计任务的开始时间。 数据来源：本端规划 取值范围：时间类型，取值范围为00：00 ~ 23：59。 默认值：00：30 配置原则：无                                                   |
| ENDTIME          | 在指定时间点停止话单统计 | 可选必选说明：可选参数 参数含义：用来指定话单统计任务的结束时间。 数据来源：本端规划 取值范围：时间类型，取值范围为00：00 ~ 23：59。 默认值：05：00 配置原则：无                                                   |
| RESINTERV        | 结果文件输出时间阈值   | 可选必选说明：可选参数 参数含义：用来设置话单统计结果文件的输出时间阈值，单位为分钟。 数据来源：本端规划 取值范围：整数类型，取值范围为1 ~ 10080。 默认值：1440 配置原则：无                                              |
| SCANINTERV       | 文件定时扫描间隔     | 可选必选说明：可选参数 参数含义：用来设置话单统计在定时扫描期间的扫描间隔时长，单位为秒。 数据来源：本端规划 取值范围：整数类型，取值范围为1 ~ 86400。 默认值：3600 配置原则：无                                            |
| SESSIONAGINGTIME | 会话老化时长       | 可选必选说明：可选参数 参数含义：用来设置话单统计中会话的老化时长，单位为秒。 数据来源：本端规划 取值范围：整数类型，取值范围为60 ~ 259200。 默认值：21600 配置原则：无                                               |
| ANONYMITY        | 是否开启匿名化      | 可选必选说明：可选参数 参数含义：用来控制话单统计结果是否开启匿名功能。 数据来源：本端规划 取值范围：枚举类型。 OFF：关闭。ON：开启。 默认值：OFF 配置原则：无                                                       |

#### 使用实例

增加话单统计，统计通道“CHFCDR”且数据网络名称为“huawei.com”的话单信息，配置举例如下：

```
ADD CDRSTAT: CDRSTATID="cdrstat1", AGID="PS1", CHLNAME="CHFCDR", DNN="huawei.com", CDRSTARTTIME=2024&06&12&21&45&54, CDRENDTIME=2024&06&13&21&45&56, ANONYMITY=OFF;
```
