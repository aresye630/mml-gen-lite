# 查询微服务消息包申请测试配置信息(LST MSMSGALLOCTESTCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询Dopra消息包申请测试的配置信息

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                            |
|:-------|:-------|:--------------------------------------------------------------------------------|
| ST     | 服务类型   | 可选必选说明：必选参数 参数含义：用于标识对哪个服务的Dopra消息包进行业务处理。 取值范围：ENS(EnumService) 默认值：无。 配置原则：无。 |

## 使用实例

- 查询“服务类型”为“EnumService”的消息包申请测试配置信息。

  ```
  LST MSMSGALLOCTESTCFG: ST=ENS;
  ```

  ```
  %%LST MSMSGALLOCTESTCFG: ST=ENS;%%
  RETCODE = 0  操作成功

  操作结果如下
  ------------
                服务类型  =  EnumService
  大小消息包检测功能开关  =  开启
          消息包大小阈值  =  0
        大消息包测试周期  =  1000
        大消息包测试次数  =  60
    大消息包重试失败比例  =  100
        大消息包复位策略  =  复位
        小消息包测试周期  =  1000

    小消息包重试失败比例  =  100
        小消息包复位策略  =  复位
  (结果个数 = 1)

  ---    END
  ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
