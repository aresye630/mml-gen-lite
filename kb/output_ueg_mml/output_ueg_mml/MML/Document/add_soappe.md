# 增加SOAP对端(ADD SOAPPE)

## 命令功能

该命令用于在系统中添加一条SOAP对端记录。

BSF与AP间通过Zn接口交互时，若使用SOAP协议，则通过本命令添加SOAP对端记录，通过统计Zn接口上的消息总数，可获知Zn接口的业务量是否超过系统支撑的业务量。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

- 系统默认添加一条“SOAP对端标识”为“0”的默认对端记录，该条记录不可以修改、删除，可以通过执行**LST SOAPPE**命令查询。如未执行本命令配置SOAP对端，则此默认配置信息代表所有SOAP对端。
- 通过本命令最多可以在系统中添加255条SOAP对端记录。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                               |
|:-------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
| ID     | SOAP对端标识 | 可选必选说明：必选参数 用于标识待添加的SOAP对端ID，该标识唯一指定一条记录。 取值范围：1～255 默认值：无。                                                                                        |
| FQDN   | FQDN     | 可选必选说明：可选参数 用于标识待配置网络应用功能的全量域名（Fully Qualified Domain Name），在本命令中用于标识AP的FQDN。 取值范围：长度不超过127的字符串。 默认值：无。 说明：该参数不区分大小写，在执行LST SOAPPE命令查询出的报文中为全小写形式。 |

## 使用实例

为系统添加一条“SOAP对端标识”为“1”的记录：

```
ADD SOAPPE: ID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示

|    错误码 | 错误码解释      | 原因分析                | 处理建议                                            |
|-------:|:-----------|:--------------------|:------------------------------------------------|
| 360258 | 当前ID记录已存在。 | 输入的“SOAP对端标识”取值已存在。 | 执行LST SOAPPE命令查询已配置的“SOAP对端标识”，重新输入该参数后执行本命令添加。 |
