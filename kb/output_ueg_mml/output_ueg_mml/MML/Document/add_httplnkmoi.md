# 增加HTTP链路测量对象实例(ADD HTTPLNKMOI)

- 注意事项

- 输出结果说明

## 命令功能

本命令用于增加一条HTTP链路测量对象实例记录。

当DCS服务感知到HLB服务上线时，DCS服务将此HLB服务的实例ID增加到HTTPLNKMOI配置中。后续DCS服务每分钟校验HLB服务实例ID，校验时同时刷新HTTPLNKMOI配置，对于新增的HLB服务实例ID，则增加到HTTPLNKMOI配置中。

本命令主要用于在系统异常情况下进行维护，执行本命令时不检查HLB服务实例ID是否真实存在，如果不存在则不会上报话统。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                          |
|:-------|:-------|:------------------------------------------------------------------------------|
| INSID  | 服务实例ID | 可选必选说明：必选参数 参数含义：用于指定一条HTTP链路测量对象实例记录的关键字段。 取值范围：长度不超过255的字符串。 默认值：无。 配置原则：无。 |

## 使用实例

增加一条“服务实例ID”为“13564655801154191991”的HTTP链路测量对象实例。

```
ADD HTTPLNKMOI: INSID="13564655801154191991";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
