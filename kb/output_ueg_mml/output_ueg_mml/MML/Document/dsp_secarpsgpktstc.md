# 显示ARP双向分离报文统计（DSP SECARPSGPKTSTC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示ARP双向分离报文统计信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                    |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------|
| RUNAME | RU名称   | 可选必选说明：可选参数 参数含义：该参数表示资源单元名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～49。 默认值：无 配置原则： 区分大小写，不支持空格。使用DSP RU查看RU名称。 |

#### 使用实例

- 显示ARP双向分离报文统计信息：

  ```
  DSP SECARPSGPKTSTC:;
  ```

  ```
  RETCODE = 0  操作成功。

  结果如下
  ------------------------
  RU 名称                     ARP请求上送CPU报文个数    ARP请求丢弃报文个数    ARP应答发送报文个数    ARP应答上送CPU报文个数    ARP应答丢弃报文个数

  VNODE_VNRS_VNFC_IPU_0066    3                         0                      0                      0                         0
  VNODE_VNRS_VNFC_IPU_0067    0                         0                      0                      0                         0
  (结果个数 = 2)
  ---    END
  ```
- 显示指定资源单元的ARP双向分离报文统计信息：

  ```
  DSP SECARPSGPKTSTC:RUNAME="VNODE_VNRS_VNFC_IPU_0066";
  ```

  ```
  RETCODE = 0  操作成功。

  结果如下
  ------------------------
                 RU 名称  =  VNODE_VNRS_VNFC_IPU_0066
  ARP请求上送CPU报文个数  =  3
     ARP请求丢弃报文个数  =  0
     ARP应答发送报文个数  =  0
  ARP应答上送CPU报文个数  =  0
     ARP应答丢弃报文个数  =  0
  (结果个数 = 1)
  ---    END
  ```
