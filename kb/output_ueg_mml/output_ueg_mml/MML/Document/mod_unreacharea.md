# 修改不可达区域（MOD UNREACHAREA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于修改用户位置不可达的区域配置。

#### 注意事项

- 该命令执行后立即生效。
- 该命令设定后的数据，需要通过LST UNREACHAREA命令进行查看。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称                | 参数说明                                                                                                                                                |
|:------------|:--------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| AREAID      | 区域标识                | 可选必选说明：必选参数 参数含义：该参数用于配置不可达区域标识。 数据来源：本端规划 取值范围：0~4294967295。 默认值：无 配置原则：该参数使用LST UNREACHAREA命令配置生成。                                                |
| MAPID       | 地图标识                | 可选必选说明：必选参数 参数含义：该参数用于配置地图标识。 数据来源：本端规划 取值范围：int64位字符串，取值范围：-9223372036854775808~9223372036854775807。 默认值：无 配置原则：该参数使用LST UNREACHAREA命令配置生成。        |
| SEQUENCEID  | 坐标点序号               | 可选必选说明：必选参数 参数含义：该参数用于配置坐标点序号，基于序号来绘制不可达区域。 数据来源：本端规划 取值范围：1~100。 默认值：无 配置原则：该参数使用LST UNREACHAREA命令配置生成。                                            |
| POSITIONX   | 不可达区域位置点相对位置X信息（厘米） | 可选必选说明：可选参数 参数含义：该参数用于设置不可达区域位置点相对位置X信息，单位：厘米。 数据来源：本端规划 取值范围：int64位字符串，取值范围：-9223372036854775808~9223372036854775807。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。 |
| POSITIONY   | 不可达区域位置点相对位置Y信息（厘米） | 可选必选说明：可选参数 参数含义：该参数用于设置不可达区域位置点相对位置Y信息，单位：厘米。 数据来源：本端规划 取值范围：int64位字符串，取值范围：-9223372036854775808~9223372036854775807。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。 |
| DESCRIPTION | 描述信息                | 可选必选说明：可选参数 参数含义：该参数用于设置不可达区域配置描述信息。 数据来源：本端规划 取值范围：字符串类型，输入长度1~32。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。                                                    |

#### 使用实例

修改区域标识为123，地图区域标识为123，点坐标序号为12的用户位置不可达区域，将点坐标POSITIONX改为123：

```
MOD UNREACHAREA: AREAID=123, MAPID="123", SEQUENCEID=12, POSITIONX="123";
```
