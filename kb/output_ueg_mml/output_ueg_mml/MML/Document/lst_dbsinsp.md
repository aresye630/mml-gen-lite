# 查询DBS软件参数的配置信息(LST DBSINSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，查询DBS软件参数的配置信息。

- 若需要查询全部DBS软参数据记录的概要信息，请不要输入任何参数。
- 若需要查询某条参数数据记录的详细信息，请输入“软件参数名称”或“软件参数值”或这两个参数的组合。

## 注意事项

无。

## 参数说明

| 参数ID   | 参数名称   | 参数描述                                                                                                                        |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------|
| INSPN  | 软件参数名称 | 可选必选说明：可选参数。 参数含义：标识一条软参数据记录的关键字段之一，用于指示系统需要按照哪个软件参数名称来查询软件参数的配置信息；若不输入，则表示所有的软件参数名称。 取值范围：请参考产品手册的“DBS软件参数” 默认值：无。 配置原则：无。 |
| INSPV  | 软件参数值  | 可选必选说明：可选参数。 参数含义：标识一条软参数据记录的关键字段之一，用于指示系统需要按照哪个软件参数值来查询软件参数的配置信息；若不输入，则表示所有的软件参数值。 取值范围：请参考产品手册的“DBS软件参数”。 默认值：无。 配置原则：无。  |

## 使用实例

查询DBS软参，“软件参数名称”为“OUTERHEARTBEATTIMEOUT”的配置信息。

```
LST DBSINSP: INSPN=OUTERHEARTBEATTIMEOUT;
```

```
%%LST DBSINSP: INSPN=OUTERHEARTBEATTIMEOUT;%%
RETCODE = 0  操作成功

操作结果如下
------------
软件参数名称  =  局间心跳超时时长
  软件参数值  =  16000
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。
