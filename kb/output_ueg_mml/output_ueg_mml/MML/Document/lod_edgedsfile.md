# 导入园区用户数据文件（LOD EDGEDSFILE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UDM**

该命令用于CSP Portal手动加载导入的数据文件，支持加载Manual或SFTP导入的文件，支持手动导入指定文件名的数据文件，或者手动导入时间戳最新的数据文件。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                             |
|:---------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DATASRC  | 数据来源    | 可选必选说明：必选参数 参数含义：该参数用于设置手动导入用户数据文件的数据来源。 数据来源：本端规划 取值范围： SFTP：表示加载SFTP自动同步备份到OMU的文件。Manual：表示加载通过网管手动同步到OMU的文件。 默认值：无 配置原则：无                                                                                                                                                                                                                                     |
| UDMMODE  | UDM模式   | 可选必选说明：必选参数 参数含义：该参数用于指定数据同步UDM模式。 数据来源：全网规划 取值范围： SINGLE：单UDM模式。MULTI：多UDM模式。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                      |
| LOADMODE | 文件导入方式  | 可选必选说明：必选参数 参数含义：该参数用于设置手动导入用户数据文件的方式。 数据来源：本端规划 取值范围： SPECIFIED：指定版本。LATEST：最新版本。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                  |
| FILENAME | 用户数据文件名 | 可选必选说明：条件必选参数 前提条件：该参数在“LOADMODE”配置为“SPECIFIED”时为必选参数。 参数含义：该参数用于设置手动导入的用户数据文件名。 数据来源：本端规划 取值范围：字符串，输入长度范围为1～255。不支持空格。 默认值：无 配置原则：1.中移动用户数据文件名称：”园区描述”+分隔符+“序号”+分隔符+“导出时间戳（格式YYYYMMDDHHMMSS）” 联通用户数据文件名称：“省份标识”+分隔符+”园区描述”+分隔符+“序号”+分隔符+“导出时间戳（格式YYYYMMDDHHMMSS）” 2.上传用户数据文件：登录CSP Portal，选择“系统”> “文件传输”，在文件传输页面切换到ueg网元，点击“园区UDM数据手动备份”>“添加文件”，从本地上传文件，点击“确定”。 |

#### 使用实例

手动加载网管导入的时间戳最新数据文件：

```
LOD EDGEDSFILE: DATASRC=Manual, UDMMODE=SINGLE, LOADMODE=LATEST, CONFIRM=Y;
```
