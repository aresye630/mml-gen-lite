# 查询LCS资源状态(DSP LCS)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询LCS的资源状态。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug；visit-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组；G\_4，来宾级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                        |
|:-------|:-------|:--------------------------------------------------------------------------------------------|
| RUNAME | RU名称   | 可选必选说明：可选参数 参数含义：该参数用于指定SPU资源单元名。该参数可以通过DSP RU命令查询。 数据来源：整网规划。 取值范围：0~63 位字符串 默认值：无         |
| PROCNO | 进程号    | 可选必选说明：可选参数 参数含义：该参数用于指定需要查询的SPP进程的进程号。 数据来源：整网规划。 取值范围：0~20 默认值：无  说明： 输入该参数时必须输入“RU名称”参数。 |

#### 使用实例

查询LCS控制表的占用情况：

DSP LCS: RUNAME="USN\_SP\_RU\_0064", PROCNO=0;

```
%%DSP LCS: RUNAME="USN_SP_RU_0064", PROCNO=0;%%
RETCODE = 0  操作成功。

输出结果如下
------------
          RU名称 = USN_SP_RU_0064
          进程号 = 0
     LCS资源总量 = 500
   LCS资源使用量 = 0
  4G LCS资源总量 = 800
4G LCS资源使用量 = 0
 (结果个数 = 1)
 
--- END
```

#### 输出结果说明

| 输出项名称       | 输出项解释                      |
|:------------|:---------------------------|
| RU名称        | 查询所在的资源单元名称。               |
| 进程号         | 查询所在的SPP进程的进程号。            |
| LCS资源总量     | 查询所在的SPP进程的2G/3G LCS资源总量。  |
| LCS资源使用量    | 查询所在的SPP进程的2G/3G LCS资源使用量。 |
| 4G LCS资源总量  | 查询所在的SPP进程的4G LCS资源总量。     |
| 4G LCS资源使用量 | 查询所在的SPP进程的4G LCS资源使用量。    |
