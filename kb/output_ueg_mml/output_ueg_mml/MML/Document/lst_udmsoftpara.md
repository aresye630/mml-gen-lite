# 查询业务参数(LST UDMSOFTPARA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询业务参数内容，可查出参数配置类型，配置项名称、配置项值及该配置项的默认值。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                             |
|:-------|:-------|:-------------------------------------------------------------------------------------------------|
| TYPE   | 配置类型   | 可选必选说明：可选参数 参数含义：用于指示系统查询哪种配置类型的业务参数；若不选择，则表示查询所有类型的所有业务参数。                                      |
| ITEMN  | 配置项名称  | 可选必选说明：条件可选参数 参数含义：用于指示系统查询对应配置类型的哪个业务参数；若不选择，则表示查询指定配置类型的所有业务参数。 配置原则：当参数“配置类型”取值为任意类型取值时该参数有效。 |

## 使用实例

查询业务参数配置信息，“配置类型”为“HttpConfig(HTTP参数配置)”，“配置项名称”为“CycValidateTime(周期性校验时间)”:

```
LST UDMSOFTPARA: TYPE=HttpConfig, ITEMN=CycValidateTime;
```

```
%%LST UDMSOFTPARA: TYPE=HttpConfig, ITEMN=CycValidateTime;%%
RETCODE = 0  操作成功

操作结果如下:
-------------
    配置类型  =  HTTP参数配置
  配置项名称  =  周期性校验时间
    配置项值  =  10
配置项默认值  =  10
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**MOD UDMSOFTPARA** 命令的参数说明。
