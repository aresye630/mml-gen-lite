# 删除URL过滤白名单列表（RMV CFWHITEURLLST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于删除一个URL过滤白名单列表。

#### 注意事项

该命令执行后60s生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称       | 参数说明                                                                                            |
|:--------------|:-----------|:------------------------------------------------------------------------------------------------|
| WHITELISTNAME | URL过滤白名单名称 | 可选必选说明：必选参数 参数含义：该参数用于设置URL过滤白名单名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

删除一个URL过滤白名单列表：

```
RMV CFWHITEURLLST: WHITELISTNAME="whitelist1";
```
