# 删除DNN群组（RMV DNNGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除指定的DNN群组。

## 注意事项

- 该命令执行后立即生效。

- 在执行本命令前请先执行LST DNNGRPMEM确保该群组下的DNN成员已经删除，再执行LST NGPARKPLCY确保该群组下的园区策略已经删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                 |
|:---------|:--------|:-------------------------------------------------------------------------------------|
| DNNGRPID | DNN群组标识 | 可选必选说明：必选参数  参数含义：该参数用于标识一个DNN群组。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。  默认值：无  配置原则：无 |

## 使用实例

删除群组名称为“ABC”的DNN群组，执行如下命令：

```
RMV DNNGRP: DNNGRPID="ABC";
```
