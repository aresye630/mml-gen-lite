#### 命令功能

**适用网元：MME**

该命令用于查询S1 TAI组对象寻呼异常监控功能的参数。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无

#### 使用实例

查询S1 TAI组寻呼异常监控配置。

`LST S1TAIPAGMONPARA:;`

```
%%LST S1TAIPAGMONPARA:;%%
RETCODE = 0  操作成功。

输出结果如下
--------------

      S1模式TAI组寻呼成功率降幅阈值（%）  =  5
S1模式TAI组二次寻呼请求次数增幅阈值（%）  =  50
         TAI寻呼消息启控连续异常周期个数  =  1

                                告警开关  =  开启

```
