# 删除本地P-GW重选策略(RMV PGWRESEL)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于删除一条本地P-GW重选策略的配置记录。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                                                                                                            |
|:-------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APNNI  | APN网络标识 | 可选必选说明：必选参数 参数含义：该参数用于指定APN网络标识。当PDN使用了该APN网络标识，系统对其进行本地P-GW重选的识别和处理。 数据来源：全网规划 取值范围：1~62位字符串 默认值：无  说明： APN网络标识由一个或多个LABEL构成，各LABEL间用“.”间隔。每个LABEL的构成字符只能是字母A～Z或a～z、数字0～9和中划线“-”，字母不区分大小写。APN网络标识地址不能以“rac”、“lac”、“sgsn”或“rnc”开头，不能以“.gprs”结尾。 |

#### 使用实例

删除“APN网络标识”为HUAWEI的本地P-GW重选配置记录：

RMV PGWRESEL: APNNI="HUAWEI";
