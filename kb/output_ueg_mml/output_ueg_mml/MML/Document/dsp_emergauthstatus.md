# 显示应急授权状态（DSP EMERGAUTHSTATUS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询系统当前惯性运行/应急接入状态。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

显示当前惯性运行/应急接入状态：

```
DSP EMERGAUTHSTATUS:;
```

```
RETCODE = 0  操作成功。

应急授权状态
------------------------------
惯性运行/应急接入授权状态  =  Standby
                 剩余时间  =  0
(结果个数 = 1)

---    END
```

#### 输出结果说明

| 输出项名称         | 输出项解释                                                                                                                                                                                                     |
|:--------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 惯性运行/应急接入授权状态 | 表示惯性运行/应急接入授权状态，有备用，锁定和惯性运行/应急接入三种状态。系统初始为备用状态。 备用状态表示系统与大网SMF的N4链路状态正常，UPF允许所有用户接入。 惯性运行/应急接入状态表示系统与大网SMF之间的N4路径断，用户只能通过应急SMF接入。 锁定状态表示UPF处于惯性运行/应急接入状态的时间超过SET EMERGAUTHTIMER设置的授权时长，UPF会拒绝从应急SMF接入新用户。 |
| 剩余时间          | 表示剩余授权时长。                                                                                                                                                                                                 |
