# 增加5G M2M策略参数（ADD NGM2MPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于增加5G M2M的策略参数，即为不同范围的用户、不同的DNN和切片业务配置M2M业务相关参数，以满足运营商灵活部署网络的需求。

## 注意事项

- 下一次注册流程生效。

- 最多可输入3000条记录。
- 用户注册流程从UDM获取签约数据后，使用IMSI以及用户签约的DNN匹配M2M策略，优先按照用户范围（指定IMSI>IMSI前缀>本网/外网>所有用户）匹配，IMSI前缀长度不相等时使用IMSI前缀最长匹配的记录；相同用户范围内，优先匹配指定DNN的记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

为IMSI前缀为123456且签约DNN列表包含DNNa的用户开通eDRX功能，eDRX参数协商时优先使用签约的eDRX参数，无签约时使用UE请求的eDRX参数，执行如下命令：

```
ADD NGM2MPLCY: SUBRANGE=IMSI_PREFIX, IMSIPRE="123456", FEATURECOND=DNN, DNNNI="DNNa", EDRXSW=ON, NREDRXSUBPRI=YES, NRECL=USE_UE_REQUEST, NRPTW=USE_UE_REQUEST;
```
