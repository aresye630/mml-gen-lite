# 修改HTTP流控组（MOD HTTPFCIPGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于修改HTTP固定速率流控组的IP地址组信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                        |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------|
| INDEX  | IP地址索引 | 可选必选说明：必选参数  参数含义：该参数用于标识具有相同前缀的一组IP地址。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4095。  默认值：无  配置原则：无                                   |
| DESC   | 描述     | 可选必选说明：可选参数  参数含义：该参数用于填写HTTP固定速率流控地址组的描述信息，建议包含NF类型，实例名等，例如UDM_UDM001。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无 |

## 使用实例

修改索引为1的HTTP固定速率流控地址组信息，描述信息由"HTTPFCIPGRP"改为"MODHTTPFCIPGRP"：

```
MOD HTTPFCIPGRP:INDEX=1,DESC="MODHTTPFCIPGRP";
```
