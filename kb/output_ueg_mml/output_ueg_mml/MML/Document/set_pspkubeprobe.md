# 设置是否放通管道大颗粒readiness就绪探测（SET PSPKUBEPROBE）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于设置是否放通管道大颗粒readiness就绪探测。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称     | 参数说明                                                                                                                                                                                     |
|:----------------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| READINESSRU     | RU就绪状态检测 | 可选必选说明：可选参数 参数含义：该参数用于表示放通管道大颗粒就绪状态检测。 数据来源：本端规划 取值范围： DISABLE（放通检测） ENABLE（真实检测） 默认值：DISABLE。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过相关查询命令获取当前参数配置值。 配置原则： 在FST裸机滚动升级场景下配置ENABLE值，其他场景保持DISABLE。 |
| SERVICEINSTANCE | 服务实例     | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。                                                                             |

#### 使用实例

设置服务实例“CSDB\_VNFC”的readiness就绪探测状态为放通检测：

```
%%SET PSPKUBEPROBE: READINESSRU=DISABLE, SERVICEINSTANCE="CSDB_VNFC";%% 
RETCODE = 0  操作成功 
 
---    END
```
