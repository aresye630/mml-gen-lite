## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成UDM在NRF上的注册信息中的服务信息发生错误，从而导致周边网元无法访问UDM提供的服务，造成业务失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于增加网元的服务信息，当系统向NRF发起服务注册时，NFService包含该命令中配置的信息。

## 注意事项

- 同一“组名称”的服务类型，要属于同一种网元类型。
- 同一“组名称”下新增服务类型，如果“组名称”已在NRF中注册，则需要发送更新请求到NRF，按照**ADD UDMNFSRV**命令中指定的更新模式发送请求。
- 当凌晨自动校验或执行**VRY NRFDATA**命令手动校验NRFClient内存数据时，在校验该MML命令的过程中，无法执行该命令，若运行该命令，则提示“360155 该MML数据正在校验中，请稍后再试”。

## 参数说明

| 参数标识            | 参数名称      | 参数说明                                                                                                                                                                                                                                 |
|:----------------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GRPNAME         | 组名称       | 可选必选说明：必选参数 参数含义：用于标识网元服务信息所属组的名称。 取值范围：长度不超过32位的字符串，字符串由数字、字母、“-”或“_”组成。 默认值：无。 配置原则：若该“组名称”不存在，则创建该组名称。                                                                                                                            |
| SERVICEID       | 服务标识      | 可选必选说明：必选参数 参数含义：用于标识网元服务信息标识。 取值范围：长度不超过32位的字符串，字符串由数字、字母、“-”或“_”组成。 默认值：无。 配置原则：该参数全局唯一，不能重复。                                                                                                                                      |
| SERVICEINSTID   | 服务实例标识    | 可选必选说明：可选参数 参数含义：用于标识网元服务实例在系统中的序号。 取值范围：长度不超过36位的字符串，字符串由数字、字母、“-”或“_”组成。 默认值：无。 配置原则： 该参数全局唯一，不能重复。当不输入该参数时，系统自动生成UUIDv4格式的标识。UUIDv4格式为“xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx”，例如：4947a69a-f61b-4bc1-b9da-47c9c5d14b64。             |
| SERVICENAME     | 服务名称      | 可选必选说明：必选参数 参数含义：用于标识网元服务名称。 取值范围：nudm-sdm(UDM订阅数据管理服务)nudm-uecm(UDM UE上下文管理服务)nudm-ueau(UDM UE鉴权服务)nudm-ee(UDM事件发布服务)nudm-pp(UDM参数提供服务)nausf-auth(AUSF UE鉴权服务)nausf-sorprotection(AUSF SoR保护服务)n5g-eir-eic(设备身份校验服务) 默认值：无。 配置原则：无。 |

| NFNOTIFSUBGRP   | 默认通知订阅组名称 | 可选必选说明：可选参数 参数含义：用于标识网元服务的默认通知订阅组名称。 取值范围：由数字、字母、“-”或“_”组成的长度不超过32的字符串。 默认值：无。 配置原则：该参数必须先由ADD UDMNFNOTIFSUB命令中的参数“组名称”定义，然后才能在此处引用。                                                                                                 |
| NFCOMINFOID     | 网元公共信息标识  | 可选必选说明：可选参数 参数含义：用于标识网元公共信息标识。 取值范围：长度不超过32位的字符串，字符串由数字、字母、“-”或“_”组成。 默认值：无。 配置原则：该参数必须先由ADD UDMNFCOMINFO命令定义，然后才能在此处引用。                                                                                                             |

## 使用实例

在开局场景下配置本局数据时，增加一条网元服务信息。“组名称”为“srvgrp1”，“服务标识”为“srv1”，“服务实例标识”为“4947a69a-f61b-4bc1-b9da-47c9c5d14b64”，“服务名称”为“nudm-sdm(UDM订阅数据管理服务)”，“服务版本组名称”为“grp1”，“方案”为“http(http)”，“状态”为“REGISTERED(正常工作状态)”，“默认通知订阅组名称”为“grp1”，“网元公共信息标识”为“cominfo1”，“支持特性”为“001”：

```
ADD UDMNFSERVICE: GRPNAME="srvgrp1", SERVICEID="srv1", SERVICEINSTID="4947a69a-f61b-4bc1-b9da-47c9c5d14b64", SERVICENAME=nudm-sdm, NFSRVVERGRP="grp1", SCHEME=http, STATUS=REGISTERED, NFNOTIFSUBGRP="grp1", NFCOMINFOID="cominfo1", SUPPORTFEATURES="001";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                | 原因分析                                      | 处理建议                                                                                                                                                                         |
|-------:|:---------------------|:------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|    503 | 配置数据已存在              | 数据库中已有相同“服务标识”配置。                         | 使用LST UDMNFSERVICE命令查询并重新输入“服务标识”，确保其值不存在。                                                                                                                                   |
| 360041 | 参数值不合法               | 界面输入的参数不在相应的参数取值范围内。                      | 重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                                                                    |
| 360042 | 参数值已存在               | 输入的“服务实例标识”在数据库中已存在。                      | 使用LST UDMNFSERVICE命令查询并重新输入“服务实例标识”，确保其值不存在。                                                                                                                                 |
| 360043 | 参数值未配置               | 输入的“服务版本组名称”、“默认通知订阅组名称”或“网元公共信息标识”参数未定义。 | 根据实际情况，重新输入参数，确保输入的“服务版本组名称”、“默认通知订阅组名称”或“网元公共信息标识”参数已定义。 可通过LST UDMNFSRVVER命令查询已定义的“服务版本组名称”。可通过LST UDMNFNOTIFSUB命令查询已定义的“默认通知订阅组名称”。可通过LST UDMNFCOMINFO命令查询已定义的“网元公共信息标识”。 |
| 360046 | 参数的网元类型不匹配           | 同一“组名称”下输入的“网元公共信息标识”参数所定义的“网元类型”不同。      | 根据实际情况，重新输入参数，确保同一“组名称”下输入的“网元公共信息标识”参数所定义的“网元类型”相同。                                                                                                                         |
| 360047 | 同一服务组中，服务名称必须为同一网元类型 | 同一“服务组”中增加的数据记录中的参数“服务名称”不属于同一个网元类型。      | 根据实际情况，重新输入参数，确保同一“服务组”中增加的数据记录中的参数“服务名称”属于同一个网元类型，可通过LST UDMNFSERVICE查询已存在的网元服务数据记录。                                                                                        |
