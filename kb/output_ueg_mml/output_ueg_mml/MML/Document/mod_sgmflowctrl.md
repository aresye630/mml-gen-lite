# 修改SGM流控参数（MOD SGMFLOWCTRL）

- 命令功能

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响系统性能与业务处理，需联系华为技术支持确认后再执行。

该命令用于修改SGM流量控制开关、启控条件等。流控功能会根据当前SGM服务接收PES的负荷状态和配置的流控参数信息，自动开启流控和解除流控。

该命令的使用场景：当出现系统不稳定，如频繁启控解控，操作员可以使用本命令修改SGM流控参数以使系统保持健康的运行状态，始终提供最大能力的消息响应服务。

**说明** 

产品暂不支持该命令功能，预埋显示此命令。

## 注意事项

- 启动流控的条件：CPU占用率超过CPU流量控制启控阈值，会启动SGM流控。
- 解除流控的条件：CPU占用率低于CPU流量控制解控阈值，会解除SGM流控。
- 该命令存在系统初始记录，参数的初始设置值如下：
  - “流量控制开关”为“ON”。
  - “CPU启控阈值”为“90”。
  - “CPU解控阈值”为“80”。
  - “USCDB协控开关”为“ON”。
  - “USCDB协控起控比率”为“10”。
  - “USCDB协控解控比率”为“5”。

## 参数说明

| 参数标识      | 参数名称        | 参数说明                                                                                                                                                                                                            |
|:----------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FLWCTRFLG | 流量控制开关      | 可选必选说明：必选参数 参数含义：该参数用于设置是否启动SGM流量控制。 取值范围： ON(打开流控)OFF(关闭流控) 默认值：无。 系统初始设置值：ON(打开流控)                                                                                                                            |
| CPUFLWSTR | CPU启控阈值     | 可选必选说明：必选参数 参数含义：该参数用于设置需要启动流控时的CPU占用率，仅当本命令中的“流量控制开关”参数为“ON(打开流控)”时该参数有效。  说明： CPU解控阈值不能比CPU启控阈值大，否则系统产生错误码，配置失效。 取值范围：10~100 单位：％ 默认值：无。 系统初始设置值：90                                                           |
| CPUFLWEND | CPU解控阈值     | 可选必选说明：可选参数 参数含义：该参数用于设置需要解除流量控制时的CPU占用率，仅当本命令中的“流量控制开关”参数为“ON(打开流控)”时该参数有效。  说明： CPU解控阈值不能比CPU启控阈值大，否则系统产生错误码，配置失效。 取值范围：0~90 单位：％ 默认值：无。 系统初始设置值：80                                                           |
| ASSBECF   | USCDB协控开关   | 可选必选说明：可选参数 参数含义：该参数用于设置是否需要开启SGM对USCDB协控功能，仅当本命令中“流量控制开关”取值为“ON（打开流控）”时该参数有效。 取值范围： ON(打开USCDB协控)OFF(关闭USCDB协控) 默认值：无。 系统初始设置值：ON(打开USCDB协控) 配置原则：无。                                                           |
| RSUFCSTR  | USCDB协控起控比率 | 可选必选说明：可选参数 参数含义：该参数用于设置SGM对USCDB协控起控阈值，当路由DRU、DSU或DSG起控模块占比超过该阈值时，触发FE协同流控功能。仅当本命令中“USCDB协控开关”取值为“ON(打开USCDB协控)”时该参数有效。  说明： DRU/DSU/DSG协控解控比率必须低于DRU/DSU/DSG协控起控比率。 取值范围：1~100 单位：％ 默认值：无。 系统初始设置值：10 配置原则：无。 |
| RSUFCSTP  | USCDB协控解控比率 | 可选必选说明：可选参数 参数含义：该参数用于设置SGM对USCDB协控解控阈值，当路由DRU、DSU或DSG解控模块占比低于该阈值时，解除FE协同流控功能。仅当本命令中“USCDB协控开关”取值为“ON(打开USCDB协控)”时该参数有效。  说明： DRU/DSU/DSG协控解控比率必须低于DRU/DSU/DSG协控起控比率。 取值范围：0~99 单位：％ 默认值：无。 系统初始设置值：5 配置原则：无。   |

## 使用实例

修改SGM流控配置。“流量控制开关”为“ON”，“CPU启控阈值”为“75”，“CPU解控阈值”为“70”，“USCDB协控开关”为“ON”，“USCDB协控起控比率 ”为“15”，“USCDB协控解控比率 ”为“10”。

```
MOD SGMFLOWCTRL: FLWCTRFLG=ON, CPUFLWSTR=75, CPUFLWEND=70, ASSBECF=ON, RSUFCSTR=15, RSUFCSTP=10;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                       | 原因分析                            | 处理建议                                   |
|------:|:----------------------------|:--------------------------------|:---------------------------------------|
| 57904 | CPU解控阈值不能比CPU启控阈值大。         | “CPU启控阈值”必须大于或等于“CPU解控阈值”。      | 请将“CPU启控阈值”的值设置为大于或等于“CPU解控阈值”的值。      |
| 58040 | USCDB协控解控比率不能比USCDB协控起控比率大。 | “USCDB协控解控比率”必须低于“USCDB协控起控比率”。 | 请将“USCDB协控解控比率”的值设置为小于“USCDB协控起控比率”的值。 |
