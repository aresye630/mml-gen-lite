# 删除网络切片（RMV PLMNNS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、SMSF、NEF、NWDAF、SCF**

该命令用于删除指定的网络切片。

## 注意事项

- 该命令执行后立即生效。

- 删除网络切片之前，需要首先删除引用该网络切片的其它配置记录，如NFNS。
- 如果NSSF上的网络切片可用性信息只来自配置，在执行本命令前要确保NSSF的本地配置更新到最新。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                           |
|:-------|:-------|:-----------------------------------------------------------------------------------------------|
| NSIDX  | 网络切片索引 | 可选必选说明：必选参数  参数含义：该参数用以在系统内唯一标识某个网络切片。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无 |

## 使用实例

原网络切片（在系统内的切片索引为9）提供的业务下线，删除该网络切片，执行如下命令：

```
RMV PLMNNS: NSIDX=9;
```
