# 查询FQDN信息(LST FQDNINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询本地静态配置域名和IP对应关系。

- 如果需要查询所有本地静态配置域名和IP对应关系，请不要输入任何参数。
- 如果需要查询指定本地静态配置域名和IP对应关系，请依据参数说明输入查询的条件。

## 注意事项

无，

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                |
|:------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INDEX       | 索引     | 可选必选说明：可选参数 参数含义：用于指示系统按照索引来查询本地静态配置域名和IP对应关系；若不输入，则表示所有的索引。 取值范围：1～1024 默认值：无。 配置原则：无。                                                                                             |
| FQDN        | FQDN   | 可选必选说明：可选参数 参数含义：用于指示系统按照FQDN来查询本地静态配置域名和IP对应关系；若不输入，则表示所有的FQDN。 取值范围：长度不超过128位的字符串 默认值：无。 配置原则：无。                                                                                  |
| IPVER       | IP版本   | 可选必选说明：可选参数 参数含义：用于指示系统按照IP版本来查询本地静态配置域名和IP对应关系；若不输入，则表示所有的IP版本。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。                                                                          |
| IP          | IPV4地址 | 可选必选说明：可选参数 参数含义：用于指示系统按照具体IPV4地址来查询本地静态配置域名和IP对应关系；若不输入，则表示所有的IPV4地址。 取值范围： 除“255.255.255.255”、“0.0.0.0”及“127.0.0.1”以外的IPV4地址。 默认值：无。 配置原则：无。                                      |
| IPV6        | IPV6地址 | 可选必选说明：可选参数 参数含义：用于指示系统按照具体IPV6地址来查询本地静态配置域名和IP对应关系；若不输入，则表示所有的IPV6地址。 取值范围：除“FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF”、“0:0:0:0:0:0:0:0”及“0:0:0:0:0:0:0:1”以外的IPV6地址。 默认值：无。 配置原则：无。 |
| DESCRIPTION | 描述     | 可选必选说明：可选参数 参数含义：用于指示系统按照描述来查询本地静态配置域名和IP对应关系；若不输入，则表示所有的描述。 取值范围：长度不超过32位的字符串。 默认值：无。 配置原则：无。                                                                                      |

## 使用实例

- 查询本地所有静态配置域名与IP的对应关系。

```
%%LST FQDNINFO:;%% 
RETCODE = 0  操作成功  
操作结果如下 
------------ 
索引  FQDN         IP版本  IPV4地址     IPV6地址  描述    
1     huawei.com   IPV4    192.168.0.3  NULL      NULL   
2     huawei1.com  IPV4    192.168.0.3  NULL      NULL    
(结果个数 = 2) 
---    END
```

- 查询本地制定参数类型的静态配置域名与IP对应关系，如查询“索引”值为1的静态配置域名与IP的对应关系。

```
%%LST FQDNINFO: INDEX=1;%%
RETCODE = 0  操作成功  

操作结果如下 
------------     
    索引  =  1     
    FQDN  =  huawei.com   
  IP版本  =  IPV4 
IPV4地址  =  192.168.0.3 
IPV6地址  =  NULL     
    描述  =  NULL 
(结果个数 = 1)  

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD FQDNINFO**命令的参数说明。
