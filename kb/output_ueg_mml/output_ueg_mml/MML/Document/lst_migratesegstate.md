# 查询迁移隔离状态（LST MIGRATESEGSTATE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

用于查询Pod的迁移隔离状态的信息。

- 若需要查询全部Pod名称的迁移隔离状态信息，请不要输入任何参数。
- 若需要查询某个Pod名称的迁移隔离状态信息，请输入“Pod名称”。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                             |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PODNAME | Pod名称  | 可选必选说明：可选参数 参数含义：用于请求系统显示哪个Pod名称的迁移隔离状态信息。若不输入，则表示所有的Pod名称。 取值范围：长度为3～255的字符串。 默认值：无。 配置原则：输入的“Pod名称”对应的Pod类型必须为“pcf-srvra-pod”、“pcf-srvrb-pod”、“pcf-srvra-arm-pod”、“pcf-srvrb-arm-pod”、“pcf-srvra-x86-pod”或“pcf-srvrb-x86-pod”。 |

## 使用实例

1. 查询所有Pod名称的迁移隔离状态信息。

   ```
   LST MIGRATESEGSTATE:;
   ```

   ```
   %%LST MIGRATESEGSTATE:;%%
   RETCODE = 0  操作成功 

   操作结果如下 
   ------------------------
   Pod名称                  

   pcf-srvra-pod232-0  
   pcf-srvrb-pod232-0  
   (结果个数 = 2)

   ---    END
   ```
2. 查询指定Pod名称的迁移隔离状态信息，“Pod名称”为“pcf-srvra-pod232-0”。

   ```
   LST MIGRATESEGSTATE: PODNAME="pcf-srvra-pod232-0";
   ```

   ```
   %%LST MIGRATESEGSTATE: PODNAME="pcf-srvra-pod232-0";%%
   RETCODE = 0  操作成功
   操作结果如下
   ------------------------
   Pod名称  =  pcf-srvra-pod232-0
   (结果个数 = 1)
   ---    END
   ```

**说明** 

如果所有Pod或指定Pod未被隔离，则返回“RETCODE = 20111 数据库表中没有数据。”。

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，参数含义请参见**ADD MIGRATESEGSTATE**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                 | 原因分析                                                                                                                                 | 处理建议                                                                                                                                                                           |
|------:|:----------------------|:-------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|   317 | "PODNAME"取了非法的值"xxx"。 | 输入的“Pod名称”对应的Pod类型不是“pcf-srvra-pod”、“pcf-srvrb-pod”、“pcf-srvra-arm-pod”、“pcf-srvrb-arm-pod”、“pcf-srvra-x86-pod”或“pcf-srvrb-x86-pod”。 | 在“CSP MML命令”界面执行DSP POD命令查询“Pod类型”为“pcf-srvra-pod”、“pcf-srvrb-pod”、“pcf-srvra-arm-pod”、“pcf-srvrb-arm-pod”、“pcf-srvra-x86-pod”或“pcf-srvrb-x86-pod”的Pod名称，输入正确的“Pod名称”后重新执行该命令。 |
