# 删除园区NF（RMV EDGENF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除园区NF（network function）信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                |
|:-------------|:-------|:----------------------------------------------------------------------------------------------------|
| NFTYPE       | Nf类型   | 可选必选说明：必选参数  参数含义：NF类型。  数据来源：本端规划 取值范围： “NfUDM（NfUDM）”：NfUDM“NfAUSF（NfAUSF）”：NfAUSF  默认值：无  配置原则：无 |
| NFINSTANCEID | NF实例标识 | 可选必选说明：必选参数  参数含义：NF实例标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~36。不区分大小写。  默认值：无  配置原则：无                 |

## 使用实例

假如运营商需要删除一个园区NF配置，NF类型为NfUDM，NF实例标识为“udm\_instance\_0”，执行如下命令：

```
RMV EDGENF: NFTYPE=NfUDM, NFINSTANCEID="udm_instance_0";
```
