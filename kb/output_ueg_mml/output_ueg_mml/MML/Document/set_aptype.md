# 设置AP功能体本局信息(SET APTYPE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在配置数据库中设置AP（Authentication Proxy）功能体的本局信息。

当UIM采用GBA架构对用户进行认证，BSF作为GBA认证流程中Bootstrapping流程的实现实体，在GBA认证过程中通过与UE和HSS之间消息的交互，完成UE合法性认证，并生成终端侧和网络侧的共享访问密钥；AP作为业务访问认证代理和转发实体，基于BSF和UE之间生成的共享访问密钥完成对用户业务访问认证，将通过认证的消息转发给AS（Application Server）。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

- 执行该命令配置AP功能体本局信息时，“UIM标识”和“AP类型”参数取值需要与**LST LOCALINFO**命令查询数据库中已配置的AP本局信息保持一致。
- 执行本命令增加AP功能体本局信息时，最多支持配置一条AP类型的功能体本局信息记录。如果配置了多次该命令，系统以最新配置记录为准。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UIMID  | UIM标识  | 用于指定UIM实体，由运营商进行规划。 取值范围：0～127。 默认值：无。 注意：该参数为必选参数。                                                                                                                                                 |
| APTYPE | AP类型   | 用于指定AP功能体的类型是认证&转发AP还是转发AP。 取值范围：FORWARD(转发)：转发AP用于将从认证&转发AP收到的HTTP请求消息转给AS。AUTH/FORWARD(认证/转发)：认证&转发AP需要和BSF交互，对UE进行认证，然后将用户访问AS服务器的HTTP请求消息转发给转发AP。 默认值：无。 系统预设值：AUTH/FORWARD(认证/转发) 注意：该参数为可选参数。 |

## 使用实例

增加一条AP功能体本局数据，携带以下参数：

- “UIM标识”为“1”
- “AP类型”为“AUTH/FORWARD(认证/转发)”

执行命令如下：

```
SET APTYPE: UIMID=1, APTYPE=AUTH/FORWARD;
```
