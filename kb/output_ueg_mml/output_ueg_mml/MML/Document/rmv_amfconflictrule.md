# 删除冲突规则（RMV AMFCONFLICTRULE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，删除冲突规则可能影响现有业务对冲突场景的判断和解决策略，如果需要使用该命令，请联系华为技术支持。

**适用NF：AMF**

该命令用于删除AMF特定的冲突场景下的冲突处理规则。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                        |
|:------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------|
| CSTYPE      | CS类型   | 可选必选说明：必选参数  参数含义：该参数用于指定CS的类型。  数据来源：本端规划 取值范围： UEAM（UEAM模块）LOCM（LOCM模块）UEM（UEM模块）AMPOLICY（AMPOLICY模块）  默认值：无  配置原则：无                      |
| PROCTYPE    | 流程内部标识 | 可选必选说明：必选参数  参数含义：该参数用于指定流程内部标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~64。不能为非法字符，只允许输入字母，数字，区分大小写。例如：ProcTypeIntraAmfInitialReg。  默认值：无  配置原则：无  |
| INITEVENTID | 初始事件类型 | 可选必选说明：必选参数  参数含义：该参数用于指定触发新流程的初始事件类型。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~64。不能为非法字符，只允许输入字母，数字，区分大小写。例如：InitIntraRegistration。  默认值：无  配置原则：无 |

## 使用实例

在IntraAmfHandover流程中，收到了NG-RAN的“RRC Inactive Transition Report”消息，如果希望删除该冲突场景下的冲突规则，则执行如下命令。

```
RMV AMFCONFLICTRULE: CSTYPE=UEAM, PROCTYPE="IntraAmfHandover", INITEVENTID="InitN2NotifyEvent";
```
