# 增加迁移隔离状态（ADD MIGRATESEGSTATE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加Pod的迁移隔离状态。

在缩容场景下，执行**STR SHARDTRANS**命令前需要先执行该命令指定Pod名称将Pod上所有DUS微服务进行隔离，标识该Pod上的DUS微服务需要逐步退出服务。迁移控制中心根据服务的隔离与否识别当前迁移操作是扩容还是缩容。

## 注意事项

该命令对MANO下发的自动缩容任务无影响，即MANO下发的自动缩容任务不需要执行该命令。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PODNAME | Pod名称  | 可选必选说明：必选参数 参数含义：用于指定待隔离的Pod名称。可通过在“CSP MML命令”界面执行DSP POD命令查询。 取值范围：长度为3～255的字符串。 默认值：无。 配置原则：输入的“Pod名称”对应的Pod类型必须为“pcf-srvra-pod”、“pcf-srvrb-pod”、“pcf-srvra-arm-pod”、“pcf-srvrb-arm-pod”、“pcf-srvra-x86-pod”或“pcf-srvrb-x86-pod”。 |

## 使用实例

增加迁移隔离状态，“Pod名称”为“pcf-srvra-pod232-0”。

```
ADD MIGRATESEGSTATE: PODNAME="pcf-srvra-pod232-0";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|------:|:----------------------|:-------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|    17 | MIGRATESEGSTATE已经存在。  | 输入的“Pod名称”已被隔离。                                                                                                                      | 执行LST MIGRATESEGSTATE命令查询已被隔离的Pod名称，然后在“CSP MML命令”界面执行DSP POD命令查询并选择尚未隔离的Pod，重新执行该命令。                                                                                          |
|   317 | "PODNAME"取了非法的值"xxx"。 | 输入的“Pod名称”对应的Pod类型不是“pcf-srvra-pod”、“pcf-srvrb-pod”、“pcf-srvra-arm-pod”、“pcf-srvrb-arm-pod”、“pcf-srvra-x86-pod”或“pcf-srvrb-x86-pod”。 | 在“CSP MML命令”界面执行DSP POD命令查询“Pod类型”为“pcf-srvra-pod”、“pcf-srvrb-pod”、“pcf-srvra-arm-pod”、“pcf-srvrb-arm-pod”、“pcf-srvra-x86-pod”或“pcf-srvrb-x86-pod”的Pod名称，输入正确的“Pod名称”后重新执行该命令。 |
