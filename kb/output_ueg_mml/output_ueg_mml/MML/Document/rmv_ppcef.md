# 删除PCRF对端PCEF实体(RMV PPCEF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致相关业务中断，请联系华为技术支持确认后再执行。

该命令为配置类命令，用于从配置数据库中删除一条对端PCEF实体数据记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                            |
|:-------|:---------|:--------------------------------------------------------------------------------|
| PCRFID | PCRF标识   | 用于标识PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围： 1 默认值： 无。                       |
| PCEFID | 对端PCEF标识 | 用于在UPCF的配置库中定义一个对端PCEF实体。该参数的配置原则：如果配置多个对端PCEF实体，从0开始顺序配置。 取值范围： 0-1023 默认值： 无。 |

## 使用实例

删除PCRF对端PCEF实体配置信息。PCRF实体标识为1，对端PCEF实体标识为0。

```
RMV PPCEF: PCRFID=1, PCEFID=0;
```
