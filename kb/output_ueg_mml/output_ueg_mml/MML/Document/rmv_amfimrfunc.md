# 删除用户消息统计功能配置（RMV AMFIMRFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除用户消息统计功能配置。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                 |
|:---------|:-------|:-------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：必选参数  参数含义：该参数用于指定用户范围。  数据来源：本端规划 取值范围： “ALL_USER（所有用户）”：所有用户  默认值：无  配置原则：无 |

## 使用实例

删除“用户范围”是“所有用户”的记录：

```
RMV AMFIMRFUNC:SUBRANGE=ALL_USER;
```
