# 查询遍历任务参数(LST SCANPARA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询遍历任务的参数。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询遍历任务参数。

```
LST SCANPARA:;
```

```
%%LST SCANPARA:;%%
RETCODE = 0  操作成功

操作结果如下:
-------------
            启动时间  =  08:00:00
离线业务处理时间间隔  =  5
(结果个数 = 1)

---    END
```

## 输出结果说明

请参见**SET SCANPARA**命令的参数说明。
