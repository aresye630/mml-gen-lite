# 删除用户APN与消息交互使用APN的映射关系（RMV CPSPECIFICAPNVAL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、PGW-C、GGSN**

该命令用于删除用户APN与消息交互使用APN的映射关系。在用户需要删除已有的用户APN与消息交互使用APN的映射关系时使用该命令。

## 注意事项

该命令执行后只对新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                             |
|:--------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBSCRIBERAPN | 用户APN  | 可选必选说明：必选参数  参数含义：该参数用于指定用户使用的别名APN、虚拟APN或真实APN名称。用户APN的优先级从高到低为：别名APN、虚拟APN、真实APN。软参DWORD1040 BIT28用于控制在AAA鉴权流程中是否使用ADD CPSPECIFICAPNVAL配置中的别名APN对用户使用的别名APN进行转换。软参DWORD1040 BIT29控制在AAA鉴权流程中，获取ADD CPSPECIFICAPNVAL配置所使用用户APN的优先级。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”特殊字符，不区分大小写。  默认值：无  配置原则：  必须是系统已经配置的APN或APN别名。 |

## 使用实例

删除一个名为“huawei.com”的用户APN和与之对应的上报APN之间的映射关系：

```
RMV CPSPECIFICAPNVAL:SUBSCRIBERAPN="huawei.com";
```
