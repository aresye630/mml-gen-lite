# 查询User Profile的计费配置（LST UPUSRPROFCHG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询在线计费用户模板默认使能开关。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                   |
|:------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------|
| USRPROFNAME | 用户模板名称 | 可选必选说明：可选参数 参数含义：该参数用于指定用户模板名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格及“,”、“;”、“"”等特殊字符，不区分大小写。 默认值：无 配置原则：该参数使用ADD USERPROFILE命令配置生成。 |

#### 使用实例

查询用户模板默认配额使能开关：

```
LST UPUSRPROFCHG: USRPROFNAME="userprofile1";
```

```
RETCODE = 0 操作成功

显示用户模板默认使能开关
------------------------
　　　　　　　　用户模板名称 = userprofile1
                   默认配额使能开关 = 开启
　　　新业务默认配额使能开关 = 继承
非新业务场景默认配额使能开关 = 关闭
(结果个数 = 1)
--END
```
