# 查询链路分配情况（DSP LINKASSIGN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询DLB/LDAP链路的分配情况。

- 如果需要查询全部DLB/LDAP链路的分配情况，请不要输入任何参数。
- 如果需要查询指定链路的分配情况，请依据参数说明输入查询条件。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数描述                                                                                     |
|:------------|:-------|:-----------------------------------------------------------------------------------------|
| SERVICETYPE | 服务类型   | 可选必选说明：可选参数 参数含义：用于指示系统按照服务类型来查询链路的分配情况；若不输入，则表示所有的服务类型。 取值范围： DLBLDAP 默认值：无。 配置原则：无。    |
| INSTID      | 实例号    | 可选必选说明：可选参数 参数含义：用于指示系统按照实例号来查询链路的分配情况；若不输入，则表示所有的实例号。 取值范围：长度不超过256的字符串。 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询所有链路的分配情况。

   ```
   DSP LINKASSIGN:;
   ```

   ```
   %%DSP LINKASSIGN:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   服务类型   实例号                对端类型  对端标识  链路标识   链路状态  

   DLB        12502831364644069374  AF        0         0          在线
   DLB        12502831364644069374  AF        9         0          在线
   DLB        12502831364644069374  AF        10        0          离线
   DLB        12502831364644069374  AF        11        0          离线
   DLB        12502831364644069374  AF        12        0          离线
   DLB        12502831364644069374  PCEF      101       0          离线
   LDAP       13220681783200997060  SPR       0         1          在线
   (结果个数 = 7)

   ---    END
   ```
2. 查询LDAP链路的分配情况。

   ```
   DSP LINKASSIGN: SERVICETYPE=LDAP;
   ```

   ```
   %%DSP LINKASSIGN: SERVICETYPE=LDAP;%% 
   RETCODE = 0  操作成功  

   操作结果如下： 
   ------------------------ 
   服务类型  =  LDAP  
     实例号  =  13220681783200997060    
   对端类型  =  SPR      
   对端标识  =  0      
   链路标识  =  1   
   链路状态  =  在线 
   (结果个数 = 1)  

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项解释请参见表1的参数说明。

| 输出项名称   | 输出项解释                                                                             |
|:--------|:----------------------------------------------------------------------------------|
| 服务类型    | 表示链路的服务类型。 取值范围： DLBLDAP                                                          |
| 实例号     | 表示链路的服务实例号。 取值范围：长度不超过256的字符串。                                                    |
| 对端类型    | 用于标识对端服务器的应用类型。 当“服务类型”为“DLB”时，取值范围为：PCEFAFOCSDRAPCRFTDF 当“服务类型”为“LDAP”时，取值范围为SPR |
| 对端标识    | 用于标识对端PCEF/AF/OCS/DRA/PCRF/SPR的ID编号。 取值范围：0～1023                                  |
| 链路标识    | 用于标识一条链路的ID编号。 取值范围：0～135                                                         |
| 链路状态    | 用于标识链路的状态。 取值范围： 离线在线                                                             |
