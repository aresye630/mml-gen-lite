# 删除HSS BYPASS最小APN签约数据配置 (RMV HSSBPAPNSUB)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

此命令用于删除最小APN签约数据群组对应的最小APN签约数据。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称      | 参数说明                                                                   |
|:----------|:----------|:-----------------------------------------------------------------------|
| APNSUBIDX | APN本地签约索引 | 可选必选说明：必选参数 参数含义：该参数用于指定APN本地签约数据索引。 数据来源：全网规划 取值范围：0~255 默认值：无 配置原则：无 |

#### 使用实例

删除HSS BYPASS最小APN签约数据配置，可以用如下命令：

```
RMV HSSBPAPNSUB: APNSUBIDX=1;
```
