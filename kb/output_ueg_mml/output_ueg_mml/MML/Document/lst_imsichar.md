# 查询IMSI号段属性配置(LST IMSICHAR)

#### 命令功能

**适用网元：SGSN、MME**

此命令用于查询IMSI号段对应的属性配置。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                               |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：可选参数 参数含义：待查询签约用户的范围。 取值范围：“ALL_USER(所有用户)”“IMSI_PREFIX(指定IMSI前缀)”“IMSI_RANGE(指定IMSI范围)” 默认值：无              |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件可选参数 参数含义：待查询IMSI前缀。 前提条件：该参数在“用户范围”参数设置为“IMSI_PREFIX(指定IMSI前缀)”时，才需要配置。 取值范围：1～15位数字 默认值：无               |
| IMSI     | IMSI   | 可选必选说明：条件可选参数 参数含义：待查询IMSI，对该IMSI所在号段进行查询 前提条件：该参数在“用户范围”参数设置为“IMSI_RANGE(指定IMSI范围)”时，才需要配置。 取值范围：1～15位十进制数字 默认值：无 |

#### 使用实例

查询所有IMSI号段对应的属性配置记录：

LST IMSICHAR:;

```
%%LST IMSICHAR:;%%
RETCODE = 0  操作成功。

输出结果如下
--------------
       用户范围  =  所有用户
       IMSI前缀  =  NULL
       起始IMSI  =  NULL
       终止IMSI  =  NULL
     本局SGSN号  =  NULL
   本地实体索引  =  NULL
(结果个数 = 1)

---    END
```
