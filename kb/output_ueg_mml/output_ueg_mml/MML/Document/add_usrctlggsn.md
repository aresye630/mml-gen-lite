#### 命令功能

**适用网元：SGSN**

该命令用于增加需手工恢复的GGSN地址。

如果由于网络等原因导致到某个GGSN的通信经常中断，为了避免业务的频繁切换，可以通过此命令屏蔽该GGSN，在确认故障完全排除后，再恢复到该GGSN的业务。

当UNC检测到本表中配置的GGSN故障恢复后，产生ALM-12605 GTPC路径恢复正常需手工启动新业务接入告警，并且只有在经过操作员人工确认（**RES USRCTLGGSN**）后，才选择故障恢复后的GGSN业务。

#### 注意事项

- 本命令执行后立即生效。
- 执行本命令添加一条记录后，指定的GGSN故障恢复后，必须要通过执行**RES USRCTLGGSN**命令才能使GGSN重新被启用。
- 本表最大记录数为20。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                 |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPT    | IP地址类型 | 可选必选说明：必选参数 参数含义：此参数用于指定GGSN网元的IP地址类型。 数据来源：与对端网元协商 取值范围： “IPV4(IPv4)”“IPV6(IPv6)” 默认值：无                                                                                                                                                             |
| IPV4   | IPv4地址 | 可选必选说明：条件必选参数 参数含义：此参数用于指定GGSN网元的IPv4类型的地址。 数据来源：与对端网元协商 取值范围：0.0.0.0~255.255.255.255 默认值：无  说明： “0.0.0.0”和“255.255.255.255”是无效的IP地址。 配置原则：IPv4地址不能为0.0.0.0、255.255.255.255和0.x.y.z。IPv4地址不能为组播地址（如：224.x.y.z）和环回地址(如：127.x.y.z)。IPv4地址必须是A、B或者C类地址。 |
| IPV6   | IPv6地址 | 可选必选说明：条件必选参数 参数含义：此参数用于指定GGSN网元的IPv6类型地址。 数据来源：与对端网元协商 取值范围： ::~FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无                                                                                                                                       |
| DESC   | 描述     | 可选必选说明：可选参数 参数含义：此参数用于指定记录的描述信息。 取值范围：0~32位字符串 默认值：无 配置原则：描述信息应该是有意义的字符串。                                                                                                                                                                            |

#### 使用实例

增加GGSN地址192.168.66.6为需手工恢复：

ADD USRCTLGGSN: IPT=IPV4, IPV4="192.168.66.6";
