# 查询通知服务对端链路配置信息(LST NTSPEERLINKCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询通知任务服务对端链路的配置信息。

- 若需要查询全部通知任务服务对端链路的配置信息，请不要输入任何参数。
- 若需要查询指定通知任务服务对端链路的配置信息，请依据参数说明输入查询条件。

## 注意事项

无。

## 参数说明

| LOCALIP     | 本端IP地址     | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV4(IPV4)”时该参数有效，用于指示系统需要按照哪个本端IPv4地址来查询通知任务服务对端链路配置信息；若不输入，则表示所有的本端IPv4地址。 取值范围：IPv4地址 默认值：无。 配置原则：无。                                                                                                                                    |
| LOCALIPV6   | 本端IPV6地址   | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV6(IPV6)”时该参数有效，用于指示系统需要按照哪个本端IPv6地址来查询通知任务服务对端链路配置信息；若不输入，则表示所有的本端IPv6地址。 取值范围：IPV6地址 默认值：无。 配置原则：无。                                                                                                                                    |
| PEERIP      | 对端IP地址     | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV4(IPV4)”时该参数有效，用于指示系统需要按照哪个对端IPv4地址来查询通知任务服务对端链路配置信息；若不输入，则表示所有的对端IPv4地址。 取值范围：IPv4地址 默认值：无。 配置原则：无。                                                                                                                                    |
| PEERIPV6    | 对端IPV6地址   | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV6(IPV6)”时该参数有效，用于指示系统需要按照哪个对端IPv6地址来查询通知任务服务对端链路配置信息；若不输入，则表示所有的对端IPv6地址。 取值范围：IPv6地址 默认值：无。 配置原则：无。                                                                                                                                    |

| SENDER      | 发送人        | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个发送人来查询通知任务服务对端链路配置信息；若不输入，则表示所有的发送人。 取值范围：长度不超过96的字符串 默认值：无。 配置原则：无。                                                                                                                                                                      |
| USRNAME     | 用户名        | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个用户名来查询通知任务服务对端链路配置信息；若不输入，则表示所有的用户名。 取值范围：长度不超过96的字符串 默认值：无。 配置原则：无。                                                                                                                                                                      |
| LOGONURL    | 认证服务器URL   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个认证服务器URL来查询通知任务服务对端链路配置信息；若不输入，则表示所有的认证服务器URL。 仅当“WSDL文件”选择“NwT(NwT)”时，可设置此参数。 取值范围：长度不超过128的字符串 默认值：无。 配置原则：无。                                                                                                                           |
| DEFLINK     | 默认链路       | 可选必选说明：可选参数 参数含义：用于指示系统需要按照是否默认链路来查询通知任务服务对端链路配置信息；若不输入，则表示所有的链路。 当“WSDL文件”选择“Common(Common)”或“IdnX(IdnX)”时，可设置此参数。 取值范围： NO(否)YES(是) 默认值：无。 配置原则：无。                                                                                                                   |
| LINKGRP     | 链路组        | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个链路组来查询通知任务服务对端链路配置信息；若不输入，则表示所有的链路组。 当“本地角色”为“CMPPClient(CMPP客户端)”或“SMPPClient(SMPP客户端)”时，可设置此参数。 取值范围： NULL(NULL)：表示该链路不属于任何链路组。Group1(Group1)～Group16(Group16)。 默认值：无。 配置原则：无。                                                          |

| ISENCRYPTED | 是否支持加密     | 可选必选说明：可选参数 参数含义：用于指示系统需要按照是否支持加密来查询通知任务服务对端链路配置信息；若不输入，则表示所有的加密场景。仅当“本地角色”配置为“CMPPClient(CMPP客户端)”、“SMPPClient(SMPP客户端)”和“SMTPClient(SMTP客户端)”时，可设置此参数。 取值范围： YES(支持加密)：支持加密NO(不支持加密)：不支持加密 默认值：无。 配置原则：无。                                                            |
| TLSCFGID    | TLS配置ID    | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个TLS配置ID来查询通知任务服务对端链路配置信息；若不输入，则表示所有的TLS配置ID。 取值范围：1～128 默认值：无。 配置原则：无。                                                                                                                                                                    |
| PRECEDENCE  | 优先级        | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个优先级来查询通知任务服务对端链路配置信息；若不输入，则表示所有的优先级。 当“WSDL文件”选择“Common(Common)”或“IdnX(IdnX)”时，可设置此参数。 取值范围：0～255 默认值：无。 配置原则：无。                                                                                                                          |
