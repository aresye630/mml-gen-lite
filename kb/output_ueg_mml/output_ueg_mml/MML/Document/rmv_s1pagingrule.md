# 删除S1寻呼规则(RMV S1PAGINGRULE)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

此命令用于删除全部或者指定的S1寻呼规则。

#### 注意事项

- 此命令执行后立即生效。
- 如果不输入任何参数，则提示：请输入"Rule Index"参数。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                        |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RECID  | 规则索引   | 可选必选说明：可选参数 参数含义：该参数用于指定待删除的S1寻呼规则的索引。 取值范围：1～1001 默认值：无  说明： 当执行ADD S1PAGINGRULE命令增加S1寻呼规则时，系统会自动为该规则分配一个1～1001之间未使用的最小的索引，以唯一的标识该S1寻呼规则。可以通过LST S1PAGINGRULE命令查询系统分配的索引值。 |

#### 使用实例

删除一条“规则索引”为“1”的S1寻呼规则：

```
RMV S1PAGINGRULE: RECID=1;
```
