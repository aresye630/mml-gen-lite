# 添加LDAP设备地址（ADD LDAPDEVADDR）

## 命令功能

该命令用于在配置数据库中增加一条LDAP（Lightweight Directory Access Protocol）设备地址数据记录。

该命令的使用场景：

当运营商的一些数据信息（例如全部用户数据和签约数据）存储在外置SPR时，UPCF支持通过基于LDAP协议的Sp接口与外置SPR对接，从而获取用户数据。

获取用户数据前，必须配置UPCF与外置SPR的对接数据。操作员可通过执行本命令增加UPCF负责获取用户数据服务的设备地址。

**说明** 

LDAP是轻量级目录访问协议的简称，是用于访问目录服务的一个标准可扩展的Internet协议。LDAP协议中部分协议是基于X.500标准，更简单、更精炼，可扩展性更好。

LDAP特点如下：

- 数据按目录结构组织
- 对外提供一个统一的访问点
- 支持数据的分布式存储
- 数据读取快

## 注意事项

PMS/NTS/DRS/HLB/DLB/NLF/LDAP设备的IP地址（包括IPv4地址和IPv6地址）需要唯一，任意两种设备的IP地址不能重复。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                    |
|:------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DEVAID      | 设备地址标识 | 可选必选说明：必选参数 参数含义：用于标识一条LDAP设备地址数据记录。 取值范围：0～7 默认值：无。 配置原则：无。                                                                                                            |
| VPNNAME     | VPN名称  | 可选必选说明：必选参数 参数含义：用于标识CSLB的业务IP的VPN名称。 取值范围：长度不超过31位的字符串。 默认值：无。 配置原则：需要与ADD L3VPNINST命令中“VPN实例名称”参数值保持一致，通过LST L3VPNINST命令查询得到。                                         |
| IPVER       | IP版本   | 可选必选说明：必选参数 参数含义：用于指定LDAP设备地址的IP版本类型。 取值范围：IPV4(IPV4) 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。                                                                                 |
| IP          | IPV4地址 | 可选必选说明：可选参数 参数含义：用于表示LDAP的设备IPv4地址，仅当“IP版本”选择“IPV4(IPV4)”时该参数必须配置。 取值范围：IPv4地址 默认值：无。 配置原则：IPv4类型的IP地址不能配置如下非法IP地址：“127.0.0.1”、“0.0.0.0”、“255.255.255.255”、“224.0.0.1”。 |
| DESCRIPTION | 描述     | 可选必选说明：可选参数 参数含义：用于描述LDAP设备地址的用途。 取值范围：长度不超过32的字符串 默认值：无。 配置原则：无。                                                                                                       |

## 使用实例

增加IPv4类型的LDAP设备地址信息。“设备地址标识”为“1”，“VPN名称”为“VPN1”，“IP版本”为“IPV4(IPV4)”，“IPV4地址”为“192.168.0.130”，“描述”为“LDAP\_IPV4”。

```
ADD LDAPDEVADDR: DEVAID=1, VPNNAME="VPN1", IPVER=IPV4, IP="192.168.0.130", DESCRIPTION="LDAP_IPV4";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如下表1所示。

|   错误码 | 消息解释    | 原因分析                                                     | 处理建议                                                                                                   |
|------:|:--------|:---------------------------------------------------------|:-------------------------------------------------------------------------------------------------------|
| 56015 | IP地址非法。 | 输入的“IPV4地址”参数值非法。                                        | 遵循“IPV4地址”参数配置原则，重新输入“IPV4地址”参数值 。                                                                     |
| 53358 | IP已经存在。 | 输入的“IPV4地址”参数值已经存在。                                      | 执行命令LST LDAPDEVADDR，查询LDAP设备地址信息，获取已经存在的“IPV4地址”信息。重新执行该命令，输入“IPV4地址”参数值 ，确保输入的“IPV4地址”参数值 与1中查询结果不相同。 |
| 58107 | 设备地址冲突。 | PMS/NTS/DRS/HLB/DLB/NLF/LDAP设备的IP地址需要唯一，任意两种设备的IP地址不能重复。 | 修改IP地址，重新执行本命令增加设备地址。                                                                                  |
