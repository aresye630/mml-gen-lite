# 查询AppID动态信息(DSP APPIDINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示系统内存中的AppID信息。

- 若需要显示所有的AppID信息，请不要输入任何参数。
- 若需要显示单个的AppID信息，请输入“App ID”参数或其他参数，或者“App ID”和其他参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称        | 参数说明                                                                                                          |
|:--------|:------------|:--------------------------------------------------------------------------------------------------------------|
| APPID   | App ID      | 可选必选说明：可选参数 参数含义：用于指定需要显示哪个App ID对应的AppID动态信息，若不输入，则表示显示所有的App ID。 取值范围：1～65535 默认值：无。 配置原则：无。                |
| APPTYPE | App Type    | 可选必选说明：可选参数 参数含义：用于指定需要显示哪个App Type对应的AppID动态信息，若不输入，则表示显示所有的App Type。 取值范围：1～65535 默认值：无。 配置原则：无。            |
| INSTID  | Instance ID | 可选必选说明：可选参数 参数含义：用于指定需要显示哪个Instance ID对应的AppID动态信息，若不输入，则表示显示所有的Instance ID。 取值范围：长度不超过20位的字符串 默认值：无。 配置原则：无。 |

## 使用实例

1. 显示所有的AppID信息：

   ```
   DSP APPIDINFO:;
   ```

   ```
   %%DSP APPIDINFO:;%% 
   RETCODE = 0  操作成功  
     
   App ID  App Type  Instance ID             
   32000   3006      13579981867965655234   
   32001   3006      13579981867965663245   

   (结果个数 = 2)  
   ---    END
   ```
2. 显示“App ID”为“32000”的信息：

   ```
   DSP APPIDINFO: APPID=32000;
   ```

   ```
   %%DSP APPIDINFO: APPID=32000;%% 
   RETCODE = 0  操作成功 
       
         App ID  =  32000
       App Type  =  3006 
    Instance ID  =  13579981867965655234 

   (结果个数 = 1)  
   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请如表1所示。

| 输出项名称       | 输出项解释                                   |
|:------------|:----------------------------------------|
| App ID      | 用于返回微服务对应的App ID。                       |
| App Type    | 用于返回微服务类型。 3006：表示该微服务类型为UdmTcpService。 |
| Instance ID | 用于返回微服务实例ID。                            |
