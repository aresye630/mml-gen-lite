# 查询SMS CHR流程控制模板（LST SMSCHRPRCTMPL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMSF**

该命令用于查询SMS CHR流程控制模板。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                |
|:--------|:---------|:------------------------------------------------------------------------------------|
| TMPLIDX | 流程控制模板索引 | 可选必选说明：可选参数  参数含义：该参数用于表示流程控制模板索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~127。  默认值：无  配置原则：无 |

## 使用实例

运营商希望查询SMS CHR流程控制模板，执行如下命令 ：

```
LST SMSCHRPRCTMPL:;
%%LST SMSCHRPRCTMPL:;%%
RETCODE = 0  操作成功

结果如下：
------------------------
流程控制模板索引 =  1
短信CHR失败流程上报选项  =  其他流程需要上报CHR单据
       
(结果个数 = 1)
```

## 输出结果说明

| 输出项名称           | 输出项解释                   |
|:----------------|:------------------------|
| SMS CHR失败流程上报选项 | 该参数用于表示SMS CHR失败流程上报选项。 |
| 流程控制模板索引        | 该参数用于表示流程控制模板索引。        |
