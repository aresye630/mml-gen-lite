# 删除基于管理的最小化路测的PLMN(RMV MDTPLMN)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于删除基于管理的最小化路测（MDT）的PLMN。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                       |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------|
| MCC    | 移动国家码  | 可选必选说明：必选参数 参数含义：该参数表示组成Serving PLMN的移动国家码信息。 数据来源：全网规划 取值范围：字符串类型，输入长度是3。只允许输入十进制数字（0-9）。 默认值：无 配置原则：无    |
| MNC    | 移动网号   | 可选必选说明：必选参数 参数含义：该参数表示组成Serving PLMN的移动网号信息。 数据来源：全网规划 取值范围：字符串类型，输入长度范围是2~3。只允许输入十进制数字（0-9）。 默认值：无 配置原则：无 |

#### 使用实例

删除一条移动国家码为123、移动网号为030的MDT PLMN配置：

`RMV MDTPLMN: MCC="460", MNC="030";`
