# 查询Token分配策略(LST TOKENASSIGNPLY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询Token分配策略信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

直接执行**LST TOKENASSIGNPLY**命令，可查询到当前配置的“分配阈值”、“故障缄默时长”、“就绪缄默时长”、“就绪缄默步长”信息，实例如下。

```
LST TOKENASSIGNPLY:;
```

```
%%LST TOKENASSIGNPLY:;%%
RETCODE = 0  操作成功

操作结果如下:
------------------------
     分配阈值 =  30
 故障缄默时长 =  0
 就绪缄默时长 =  5000
 就绪缄默步长 =  5
(结果个数  = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项解释请参见如下表1。

| 输出项名称   | 输出项解释                                                     |
|:--------|:----------------------------------------------------------|
| 分配阈值    | 参数含义：用于设置启动分配Token的HLB/PES/SGM就绪实例比例。 取值范围：0~100 单位：%     |
| 故障缄默时长  | 参数含义：用于设置HLB/PES/SGM实例故障后Token迁移的缄默时长。 取值范围：0~15000 单位：毫秒 |
| 就绪缄默时长  | 参数含义：用于设置HLB/PES/SGM实例就绪后Token迁移的缄默时长。 取值范围：0~60000 单位：毫秒 |
| 就绪缄默步长  | 参数含义：用于设置HLB/PES/SGM实例就绪后Token迁移的缄默步长。 取值范围：0~10          |
