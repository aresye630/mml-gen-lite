#### 命令功能

**适用网元：SGSN、MME**

该命令用于为扩展RFSP策略组增加一条策略。使用扩展RFSP策略就是根据终端移动行为等更精细化地为用户指定不同的RFSP ID。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为2049。
- 只允许添加一条“ARETYPE（区域类型）”为“TAGP(跟踪区群组)”的记录。
- 当“ARETYPE（区域类型）”为“ENBGP(eNodeB Group)”时只允许添加“类型”为“INSIDE(内部)”类型的eNodeB群组。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称            | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                |
|:------------|:----------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TYPE        | 类型              | 可选必选说明：必选参数 参数含义：该参数用于指定该扩展RFSP策略的类型。 数据来源：整网规划 取值范围：“SPEC_MOVE_SUB(指定的移动用户)” 默认值：无  说明： SPEC_MOVE_SUB(指定的移动用户)：该扩展RFSP策略适用于从指定跟踪区范围移出的用户。指定的跟踪区范围通过“TAGPID（跟踪区群组标识）”参数配置。                                                                                                                                                                                                                                          |
| ARETYPE     | 区域类型            | 可选必选说明：条件可选参数 参数含义：该参数用于指定扩展RFSP策略控制区域范围类型。 前提条件：该参数在“TYPE（类型）”参数配置为“SPEC_MOVE_SUB(指定的移动用户)”后生效。 数据来源：整网规划 取值范围：“TAGP(跟踪区群组)”“ENBGP(eNodeB群组)” 默认值：TAGP(跟踪区群组) 配置原则： TAGP(跟踪区群组)：用来配置用户从指定跟踪区范围移出时的扩展RFSP策略；ENBGP(eNodeB群组)：用来配置用户在指定eNodeB覆盖范围内长时间驻留时的扩展RFSP策略。                                                                                                                                                    |
| TAGPID      | 跟踪区群组标识         | 可选必选说明：条件必选参数 参数含义：该参数用于指定跟踪区群组标识。 前提条件：该参数在“ARETYPE（区域类型）”参数配置为“TAGP(跟踪区群组)”后生效。 数据来源：整网规划 取值范围：1~2048 默认值：无 配置原则： 该参数需要已经通过ADD TAGP配置。                                                                                                                                                                                                                                                                            |
| ENBGPID     | eNodeB群组标识      | 可选必选说明：条件必选参数 参数含义：该参数用于指定eNodeB群组标识。 前提条件: 该参数在“ARETYPE（区域类型）”参数配置为“ENBGP(eNodeB群组)”后生效。 数据来源：整网规划 取值范围：1~2048 默认值：无 配置原则： 该参数需要已经通过ADD ENBGP配置。                                                                                                                                                                                                                                                                   |
| TRFSP       | 目标RFSP          | 可选必选说明：必选参数 参数含义：该参数用于指定目标RFSP ID。 数据来源：整网规划 取值范围：1~256 默认值：无 配置原则： 1~128为运营商自定义值。129~256为协议(3GPP TS 36.300)指定值，其中256表示的优先级从高到低为：E-UTRAN，UTRAN，GERAN。255表示的优先级从高到低为：UTRAN，GERAN，E-UTRAN。254表示的优先级从高到低为：GERAN，UTRAN，E-UTRAN。  说明： 目标RFSP的用途，详见表1。                                                                                                                                                                    |
| RFSPRC      | 目标RFSP重发次数      | 可选必选说明：条件可选参数 参数含义：该参数用于指定重复下发目标RFSP ID的次数。 前提条件：该参数在“ARETYPE（区域类型）”参数配置为“TAGP(跟踪区群组)”后生效。 数据来源：本端规划 取值范围：0~10 默认值：2 配置原则： 当用户通过TAU流程从指定的跟踪区群组覆盖的区域移出导致MME向eNodeB下发“TRFSP（目标RFSP）”后，如果UE在此区域外从IDLE态通过Service Request或TAU流程进入到Connect态时，终端自动清除之前从eNodeB接收到的“TRFSP（目标RFSP）”对应的专有优先级信息；为了避免上述问题，需要设置此参数来实现在后续流程中的重发“TRFSP（目标RFSP）”。  说明： MME将会在TAU和Service Request流程中重发“TRFSP（目标RFSP）”；当重发时，MME将不考虑UE当前是否处于该跟踪区群组覆盖范围。 |
| SEND_CTRL   | 目标RFSP发送抑制      | 可选必选说明：条件可选参数 参数含义：该参数用于设置在低速检测区是否针对目标RFSP的下发次数进行抑制。 前提条件：该参数在“ARETYPE（区域类型）”参数配置为“ENBGP(eNodeB群组)”后生效。 数据来源：本端规划 取值范围：“NO(否)”“YES(是)” 默认值：NO(否)  说明： 当需要抑制迁出RFSP下发次数，从而减少用户频繁在检测区和周边网络切换时，将该参数设置为“YES(是)”。                                                                                                                                                                                                         |
| CTRL_PERIOD | 抑制周期            | 可选必选说明：条件必选参数 参数含义：该参数用于设置控制目标RFSP发送次数时间周期。 前提条件：该参数在“SEND_CTRL(目标RFSP发送抑制)”参数配置为“YES(是)”后生效。 数据来源：本端规划 取值范围：10min~120min 默认值：无                                                                                                                                                                                                                                                                                     |
| RFSPSNDCUNT | 抑制周期内目标RFSP重发次数 | 可选必选说明：条件必选参数 参数含义：该参数用于设置在“抑制周期”设定的时间内最大下发迁出RFSP次数。 前提条件：该参数在“SEND_CTRL(目标RFSP发送抑制)”参数配置为“YES(是)”后生效。 数据来源：本端规划 取值范围：1~10 默认值：无                                                                                                                                                                                                                                                                                    |

#### 使用实例

运营商定义扩展RFSP策略组策略：希望针对指定的移动用户，从跟踪区群组“1”所在的跟踪区移出时，为该用户下发RFSP ID为“2”对应的频点优先级，指示用户按下发的频点优先级重新接入。

ADD EXTRFSP: TYPE=SPEC\_MOVE\_SUB, TAGPID=1, TRFSP=2;

运营商定义扩展RFSP策略组策略：希望针对指定的移动用户，在低速区域eNodeB群组“2”驻留时长超过阈值时，为该用户下发RFSP ID为“3”对应的频点优先级，指示用户迁出低速区域eNodeB群组。

ADD EXTRFSP: TYPE=SPEC\_MOVE\_SUB, ARETYPE=ENBGP, ENBGPID=2, TRFSP=3;

#### 参考信息

| 类型                     | 区域类型     | 目标RFSP用途                                      |
|:-----------------------|:---------|:----------------------------------------------|
| SPEC_MOVE_SUB(指定的移动用户) | 跟踪区群组    | 配置专网具有较高接入优先级的目标RFSP ID，用于将飘入公网的专网用户迁回专网      |
| SPEC_MOVE_SUB(指定的移动用户) | eNodeB群组 | 配置公网具有较高接入优先级的目标RFSP ID，用于将公网用户从该eNodeB群组区域迁出 |
