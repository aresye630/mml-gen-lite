# 查询服务模块号(LST DBSSERVICENO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询服务模块号的配置信息：

- 若需要查询网元的全部服务模块号概要信息，请不要输入任何参数。
- 若需要查询网元的某个服务模块号配置的详细信息，请输入对应的“服务模块号”或其他参数或这些参数的组合 。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                          |
|:--------------|:-------|:--------------------------------------------------------------------------------------------------------------|
| SERVICENO     | 服务模块号  | 可选必选说明：必选参数 参数含义：用于指示系统需要按照哪个服务模块号来查询服务模块号配置信息；若不输入，则表示查询所有服务模块号所对应的服务模块号配置信息。 取值范围：1～1024 默认值：无。 配置原则：无      |
| PODNAME       | POD名称  | 可选必选说明：必选参数 参数含义：用于指示系统需要按照哪个POD名称来查询服务模块号配置信息；若不输入，则表示查询所有POD名称的服务模块号配置信息。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无  |
| CONTAINERFLAG | 容器标志   | 可选必选说明：可选参数 参数含义：当一个POD中存在4个容器时，该参数用于指定网元所属的容器标志；若不输入，则表示查询所有容器标志的服务模块号配置信息。 取值范围：长度不超过32的字符串。 默认值：无。 配置原则：无。 |
| PROCESSID     | 进程号    | 可选必选说明：可选参数 参数含义：用于指定网元所属的dbbroker微服务进程号。 取值范围：0～1 默认值：0 配置原则：虚拟机场景下，“进程号”的取值范围为“0”。裸机场景下“进程号”的取值范围为“0～1”。    |

## 使用实例

1. 查询网元的服务模块号配置信息：

   ```
   LST DBSSERVICENO:;
   ```

   返回结果如下:

   ```
   %%LST DBSSERVICENO:;%% 
   RETCODE = 0  操作成功  
   操作结果如下 
   ------------ 
   服务模块号  POD名称                容器标志  进程号
   1           udrdbbroker24-0        NULL      1        
   2           udrdbbroker24-0        NULL      0                 
   3           udrdbbroker24-1        NULL      0       
   4           udrdbbroker24-1        NULL      1
   (结果个数 = 4)  

   ---    END
   ```
2. 查询指定服务模块号的服务模块号配置信息，设置“服务模块号”为“1”：

   ```
   LST DBSSERVICENO: SERVICENO=1;
   ```

   返回结果如下:

   ```
   %%LST DBSSERVICENO: SERVICENO=1;%% 
   RETCODE = 0  操作成功  
   操作结果如下 
   ------------ 
   服务模块号  =  1    
      POD名称  =  udrdbbroker24-0 
     容器标志  =  P1 
       进程号  =  1
   (结果个数 = 1)  

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，参数含义请参见**ADD DBSSERVICENO**命令的参数说明。
