# 删除Gb模式接入限制参数(RMV GBARD)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限

- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用于删除Gb模式接入限制记录。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                  |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：必选参数 参数含义：待删除记录的用户范围。 取值范围：“ALL_USER(所有用户)”：表示该指定用户范围为所有用户。“SPECIAL_IMSIPRE(指定IMSI前缀)”：表示该用户范围为指定IMSI前缀。“SPECIAL_IMSI_RANGE(指定IMSI范围)”：表示该用户范围为指定IMSI范围。 默认值：无 |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件必选参数 参数含义：该参数用于指定用户的IMSI前缀的信息。使用时按照IMSI完全匹配进行查询。 前提条件：该参数在“SUBRANGE(用户范围)”设置为“SPECIAL_IMSIPRE(指定IMSI前缀)”时生效。 取值范围：1～15位数字 默认值：无                              |
| IMSI     | IMSI   | 可选必选说明：条件必选参数 参数含义：该参数用于删除指定IMSI所在号段的记录。 前提条件：该参数在“SUBRANGE(用户范围)”设置为“SPECIAL_IMSI_RANGE(指定IMSI范围)”时生效。 取值范围：1～15位数字 默认值：无                                            |

#### 使用实例

1. 删除所有用户的接入限制记录：

   RMV GBARD: SUBRANGE=ALL\_USER;
2. 删除IMSI前缀为123456的接入限制记录：

   RMV GBARD: SUBRANGE=SPECIAL\_IMSIPRE, IMSIPRE="123456";
