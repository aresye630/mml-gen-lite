# 查询OSPFv3接口认证配置（LST OSPFV3INTERFACEAUTH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询OSPFv3接口认证配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                         |
|:-----------|:----------|:---------------------------------------------------------------------------------------------|
| PROCID     | OSPFv3进程号 | 可选必选说明：可选参数 参数含义：OSPFv3进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无                     |
| AREAID     | OSPFv3区域号 | 可选必选说明：可选参数 参数含义：OSPFv3区域号。 数据来源：对端协商 取值范围：IPv4地址类型。点分十进制格式。 默认值：无                           |
| IFNAME     | 接口名       | 可选必选说明：可选参数 参数含义：接口名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。 |
| INSTANCEID | 实例号       | 可选必选说明：可选参数 参数含义：实例号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～255。 默认值：无                                  |

#### 使用实例

查询OSPFv3接口认证配置：

```
LST OSPFV3INTERFACEAUTH:;
```

```
RETCODE = 0  操作成功。

结果如下
------------------------
    OSPFv3进程号  =  1
    OSPFv3区域号  =  0.0.0.0
          接口名  =  Ethernet64/0/8
    认证密码类型  =  Cipher
        认证模式  =  HMAC-SHA256
    密文验证密码  =  *****
密文验证字标识符  =  1000
          实例号  =  0
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称     | 输出项解释                                |
|:----------|:-------------------------------------|
| OSPFv3进程号 | 该参数用于表示OSPFv3进程号。                    |
| OSPFv3区域号 | 该参数用于表示OSPFv3区域号。                    |
| 接口名       | 该参数用于表示OSPFv3接口名称。                   |
| 认证密码类型    | 该参数指定OSPFv3认证模式认证密码类型，支持cipher类型。    |
| 认证模式      | 该参数指定OSPFv3认证模式，支持HMAC-SHA256密文验证模式。 |
| 密文验证密码    | 该参数指定密文验证密码。                         |
| 密文验证字标识符  | 该参数指定密文验证字标识符，标识符需要跟对端保持一致。          |
| 实例号       | 该参数用于表示OSPFv3实例号。                    |
