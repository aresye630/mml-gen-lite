# 修改DNAI区域优选规则（MOD NRFDNAIRGNPREF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于修改DNAI区域优选规则。该命令功能暂不生效。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                                                                                                       |
|:-----------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DNN        | 数据网络名称    | 可选必选说明：必选参数  参数含义：该参数用于表示数据网络名称。该参数功能暂不生效。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~50。  默认值：无  配置原则：  该参数配置为*时表示通配。                                                                |
| DNAI       | 数据网络访问标识符 | 可选必选说明：必选参数  参数含义：该参数用于表示数据网络访问标识符。该参数功能暂不生效。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~50。  默认值：无  配置原则：无                                                                           |
| PREFERRULE | 区域优选规则    | 可选必选说明：必选参数  参数含义：该参数用于表示区域优选规则。该参数功能暂不生效。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~1024。  默认值：无  配置原则：  该参数配置格式如下：原区域标识-优选目的区域标识。原区域标识与优选目的区域标识为一对一关系，多个区域优选规则间以冒号（:）分隔。原区域标识不能重复。 |

## 使用实例

当需要修改DNN为ims，DNAI为huawei.com的优选规则为区域01优选区域02，区域03优选区域05：

```
MOD NRFDNAIRGNPREF: DNN="ims", DNAI="huawei.com", PREFERRULE="01-02:03-05";
```
