# 删除服务接口过滤列表(RMV SBIFILTERLST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令用于在配置数据库中删除一个服务接口过滤列表。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                  |
|:-----------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FILTERNAME | 过滤器名称  | 可选必选说明：必选参数 参数含义：标识某服务化客户端过滤名单的过滤器名称，它唯一标识一条过滤记录。用于指定数据库中需要删除哪一条服务化接口过滤名单，操作员可以使用LST SBIFILTERLST命令查询获得。 取值范围：长度不超过127位的字符串，只允许输入：0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。 |

## 使用实例

删除一个“过滤器名称”为“aaa”的服务接口过滤列表。

```
RMV SBIFILTERLST: FILTERNAME="aaa";
```
