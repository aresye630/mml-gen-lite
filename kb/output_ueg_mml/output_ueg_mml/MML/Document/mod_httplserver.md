# 修改本端服务器配置(MOD HTTPLSERVER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改数据库中本端服务器配置数据记录。在该命令中，系统通过“本端服务器名称”参数来唯一标识一条本端服务器配置信息。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                      |
|:------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LSERVERNANE | 本端服务器名称 | 可选必选说明：必选参数。 参数含义：标识一条本端服务器配置数据的关键字段（其取值不能被修改），用于指定需要对哪一条本端服务器配置数据记录的参数进行修改，操作员可以使用LST HTTPLSERVER命令查询获得。 取值范围：长度不超过128的由数字和字母组成的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。             |
| HTTPSFUNC   | 开启HTTPS | 可选必选说明：可选参数 参数含义：用于标识是否开启HTTPS，即修改后的本端服务器支持的链路。 取值范围： TRUE(开启HTTPS)FALSE(不开启HTTPS) 默认值：无。 配置原则：SET UDMSERV命令中“默认发送模式”参数取值必须和本参数保持一致，如不一致，请执行SET UDMSERV命令修改。“默认发送模式”参数值可以通过LST UDMSERV查询。 |
| CERTID      | 证书应用场景  | 可选必选说明：条件可选参数 参数含义：用于标识证书应用场景。该参数必须先由证书组管理命令定义 ，然后才能在此处引用。 取值范围：UDM_HLB_Cert(HLB证书应用场景) 默认值：无。 配置原则：仅当“开启HTTPS”参数取值为“TRUE(开启HTTPS)”时该参数有效。                                                |
| TLSCFGID    | TLS配置ID | 可选必选说明：条件可选参数 参数含义：用于标识一条TLS协议配置记录ID，该参数必须先由ADD UDMHLBTLSCFG命令定义，然后才能在此处引用。 取值范围：1~128。 默认值：无。 配置原则：仅当“开启HTTPS”参数取值为“TRUE(开启HTTPS)”时，该参数有效。                                               |

## 使用实例

修改一条本端服务器配置数据。“本端服务器名称”为“LSERVER1”，“开启HTTPS”为“FALSE(不开启HTTPS)”；

```
MOD HTTPLSERVER: LSERVERNANE="LSERVER1", HTTPSFUNC=FALSE;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释         | 原因分析                         | 处理建议                                                          |
|------:|:--------------|:-----------------------------|:--------------------------------------------------------------|
|   505 | 当前操作的配置数据不存在。 | 输入修改信息错误，需要输入正确的“本端服务器名称”信息。 | 使用LST HTTPLSERVER查询本端服务器配置信息，找到要修改唯一标识本端服务器名称，并重新输入“本端服务器名称”。 |
