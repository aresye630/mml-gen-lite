# 修改远端服务器扩展配置(MOD HTTPRSERVEREX)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

本命令用于修改已配置的远端服务器扩展记录。

## 注意事项

- 执行本命令将非SSG链路修改为SSG链路时，如果**DSP HTTPLNK**命令在客户端模式下查询的结果中已经存在相同对端IP地址和对端端口号且对端网元类型为非SSG的链路，执行本命令后需要执行**RMV HTTPLINK**命令删除该非SSG链路，操作完成后新建链路10分钟左右生效。
- 执行本命令修改配置记录时，相同“网元实例标识”中配置的“网元组名称”、“网元类型”必须相同。

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                              |
|:------------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RSERVERNAME | 远端服务器名称  | 可选必选说明：必选参数 参数含义：标识一个远端SSG服务器名称的关键字段，用于指定需要修改哪一个远端服务器名称的记录，操作员可以使用命令LST HTTPRSERVEREX查询获得。 取值范围：长度不超过128的由数字和字母组成的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。                    |
| NFINSID     | 网元实例标识   | 可选必选说明：可选参数 参数含义：用于指定修改后的网元实例在系统中的序号。 取值范围：有效的UUIDv4格式，只允许输入0～9，a～f，A～F，“-”。 默认值：无。 配置原则：UUIDv4格式为“xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx”，例如：4947a69a-f61b-4bc1-b9da-47c9c5d14b64。 |
| NFPRIORITY  | 网元优先级    | 可选必选说明：可选参数 参数含义：用于指定修改后网元的优先级。 取值范围：0～65535 默认值：无。 配置原则： 该参数取值越小，网元优先级越高。修改后，相同网元实例的优先级不同时，取其中的最高优先级。                                                                            |
| NFGRPNAME   | 网元组名称    | 可选必选说明：可选参数 参数含义：用于指定修改后网元所在组的组名称。 取值范围：长度不超过128的由数字和字母组成的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：修改后相同网元实例的网元组名称配置必须相同。                                                        |
| NFTYPE      | 网元类型     | 可选必选说明：可选参数 参数含义：用于指定修改后网元实例的类型。 取值范围：SSG(信令安全网关) 默认值：无。 配置原则：无。                                                                                                                  |
| FQDN        | 全量域名     | 可选必选说明：可选参数 参数含义：用于指定修改后信令安全网关的全量域名。 取值范围：长度不超过255位的字符串，字符串由数字、字母、“-”、“_”或“.”组成。 默认值：无。 配置原则：无。                                                                                   |
| PIPVER      | 对端IP地址类型 | 可选必选说明：可选参数 参数含义：用于指定修改后的对端IP地址类型。 取值范围： IPV4(IPV4) IPV6(IPV6) 默认值：无。 配置原则：无。                                                                                                     |
| PIPV4IP     | 对端IPv4地址 | 可选必选说明：条件必选参数 参数含义：用于指定修改后的对端IPv4地址。 取值范围：有效的IPv4地址 默认值：无。 配置原则：当“对端IP地址类型”参数取值为“IPV4(IPV4)”时，必须输入本参数。                                                                            |
| PIPV6IP     | 对端IPv6地址 | 可选必选说明：条件必选参数 参数含义：用于指定修改后的对端IPv6地址。 取值范围：有效的IPv6地址 默认值：无。 配置原则：当“对端IP地址类型”参数取值为“IPV6(IPV6)”时，必须输入本参数。                                                                            |
| PPORT       | 对端端口号    | 可选必选说明：可选参数 参数含义：用于指定修改后的对端端口号。 取值范围：1~65535 默认值：无。 配置原则：无。                                                                                                                       |

## 使用实例

修改“远端服务器名称”为“ssg\_1”的配置记录中“对端IPv4地址”为“192.168.91.106”：

```
MOD HTTPRSERVEREX: RSERVERNAME="ssg_1", PIPVER=IPV4, PIPV4IP="192.168.91.106";
```
