# 增加DNN群组成员（ADD DNNGRPMEM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于为DNN群组添加DNN成员，一次执行添加一个群组成员。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入1024条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                   |
|:---------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
| DNNGRPID | DNN群组标识 | 可选必选说明：必选参数  参数含义：该参数用于指定DNN群组标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。该参数依赖于DNNGRP对象，请确保相应DNNGRP已创建。  默认值：无  配置原则：无                                     |
| DNN      | DNN     | 可选必选说明：必选参数  参数含义：该参数用于指定配置到群组的DNN名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。可输入的字符有字母、十进制数字、“-”和“.”，并且开头和结尾只能是数字或者字母。不能出现连续两个“.”。字母大小写不敏感。  默认值：无  配置原则：无 |

## 使用实例

将DNNa添加到名称为“BIG\_GROUP”的DNN群组中，执行如下命令：

```
ADD DNNGRPMEM: DNNGRPID="BIG_GROUP", DNN="DNNa";
```
