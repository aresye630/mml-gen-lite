# 查询DRS设备地址(LST DRSDEVADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于在配置数据库中查询DRS设备地址信息。

- 若需要查询全部设备地址信息，请不要输入任何参数。
- 如果需要查询某条设备地址信息，请依据参数说明输入查询条件。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                   |
|:------------|:-------|:-----------------------------------------------------------------------------------------------------------------------|
| DEVAID      | 设备地址标识 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个设备地址标识来查询DRS设备地址信息；若不输入，则表示所有的设备地址标识。 取值范围：0~7 默认值：无。 配置原则：无。                             |
| VPNNAME     | VPN名称  | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个VPN名称来查询DRS设备地址信息；若不输入，则表示所有的VPN名称。 取值范围：长度不超过31的字符串 默认值：无。 配置原则：无。                       |
| IPVER       | IP版本   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个IP版本来查询DRS设备地址信息；若不输入，则表示所有的IP版本。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。               |
| IP          | IPV4地址 | 可选必选说明：可选参数 参数含义：当“IP版本”选择“IPV4”时该参数可配置。用于指示系统需要按照哪个IPV4地址来查询DRS设备地址信息；若不输入，则表示所有的IPV4地址。 取值范围：IPv4地址 默认值：无。 配置原则：无。   |
| IPV6        | IPV6地址 | 可选必选说明：可选参数 参数含义：当“IP版本”选择“IPV6”时该参数可配置。用于指示系统需要按照哪个IPV6地址来查询DRS设备地址信息；若不输入，则表示所有的IPV6地址。 取值范围：IPv6地址 默认值：无。 配置原则：无。   |
| FTP         | FTP    | 可选必选说明：可选参数 参数含义：用于标识是否作为与POP-D对接的FTP客户端；若不输入，则表示所有的FTP。 取值范围： YES(是)NO(否) 默认值：无。 配置原则：只有采用FTP协议场景时，本参数的取值才能为“YES(是)”。 |
| DESCRIPTION | 描述     | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个描述来查询DRS设备地址信息；若不输入，则表示所有的描述。 取值范围：长度不超过32位的字符串 默认值：无。 配置原则：无。                            |

## 使用实例

1. 查询DRS设备地址的配置信息。

   ```
   LST DRSDEVADDR:;
   ```

   ```
   %%LST DRSDEVADDR:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   设备地址标识  =  0
        VPN名称  =  DRS_VPN
         IP版本  =  IPV6
       IPV4地址  =  NULL
       IPV6地址  =  2001:0db8:3586:1000:1000:1111:1010:ffff
            FTP  =  No
           描述  =  DRSDeviceAddress
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD DRSDEVADDR**命令的参数说明。
