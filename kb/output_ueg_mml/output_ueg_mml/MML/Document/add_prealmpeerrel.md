# 增加PEER与PREALMRT关联关系（ADD PREALMPEERREL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条“对端标识”与“路由标识”关联关系的数据记录。

该命令的使用场景：当PCRF要向对端发送RAR消息时，需要先通过ADD PREALMPEERREL命令添加“对端标识”与“路由标识”的关联关系。

## 注意事项

- 当命令**ADD PREALMRT**中“对端选择方式”选择为“MASTER\_SLAVE”，并且“对端标识”与“路由标识”关联关系记录中，所有记录的“是否为Master对端”属性都为Fasle，则以PEERID最小的对端作为Master对端；如果“对端标识”与“路由标识”关联关系记录中，有多条记录的“是否为Master对端”属性为True，则以“是否为Master对端”属性为True的记录中PEERID最小的对端作为Master对端。
- 当命令**ADD PREALMRT**中“对端选择方式”选择为“ROUND\_ROBIN”，则本命令中的参数“是否为Master对端”设置为“True”或者“False”，系统都将判断对端为Master对端，按轮选方式选择路由。

## 参数说明

| 参数标识     | 参数名称        | 参数说明                                                                     |
|:---------|:------------|:-------------------------------------------------------------------------|
| RID      | 路由标识        | 用于标识域路由。该参数必须先由ADD PREALMRT命令定义，然后才能在此处索引。 取值范围：0～29 默认值：无。              |
| PEERID   | 对端标识        | 用于标识Diameter对端实体。该参数必须先由ADD PEER命令定义，然后才能在此处索引。 取值范围：0～15 默认值：无。         |
| ISMASTER | 是否为Master对端 | 用于设置是否为Master对端。 取值范围：True（True）：是Master对端False（False）：不是Master对端 默认值：无。 |

## 使用实例

增加一条“对端标识”与“路由标识”的关联关系记录。“路由标识”为“0”，“对端标识”为“0”，“是否为Master对端”为“True”。

```
ADD PREALMPEERREL: RID=0, PEERID=0, ISMASTER=True;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                       | 原因分析                                               | 处理建议                                                         |
|------:|:----------------------------|:---------------------------------------------------|:-------------------------------------------------------------|
| 58226 | ISBSF参数取值为TRUE的对端不允许被域路由关联。 | 如果对端DRA配置为是BSF对端，即参数“是否BSF对端”设置为“TRUE”，则不允许被域路由关联。 | 通过命令LST PEER查询对端DRA参数“是否BSF对端”的取值，如果该参数设置为“TRUE”，则不允许被域路由关联。 |
