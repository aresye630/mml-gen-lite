# 删除网元服务版本信息(RMV UDMNFSRVVER)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成UDM在NRF上的注册信息中的服务版本信息发生错误，从而导致周边网元无法访问UDM提供的服务，造成业务失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除一条网元服务的版本信息数据。

- **命令作用**：该命令用于某条网元服务版本信息记录错误或不再需要时，支持删除已配置的网元服务版本信息。
- **命令索引关系**：该命令的参数索引关系如图1所示。

  **图1** 命令参数索引关系图

## 注意事项

- 若该网元服务版本信息被**ADD UDMNFSERVICE**命令引用了，则检查是否是GRPNAME下最后一条记录，是则该网元信息不能被删除。
- 若该网元服务版本信息可以被删除时，检查当前GRPNAME是否被**ADD UDMNFSERVICE**命令引用，若在**ADD UDMNFSERVICE**中引用，还需要检查**ADD UDMNFSERVICE**是否在**ADD UDMNFSRV**中引用，如果在**ADD UDMNFSRV**中有引用，且NFSRV当前已注册，则按NFSRV中指定的更新模式立即向NRF发送更新请求。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                   |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GRPNAME | 组名称    | 可选必选说明：必选参数 参数含义：标识一条网元服务版本信息的关键字段之一，用于指定需要删除哪个组名称对应的网元服务版本信息。 取值范围：由数字、字母、“-”或“_”组成的长度不超过32的字符串。 参数来源：该参数由本端UDM自行定义。操作员可以通过LST UDMNFSRVVER命令查询获得。 默认值：无。 配置原则：该参数和“索引”参数组成全局唯一对象关键字段。 |
| INDEX   | 索引     | 可选必选说明：必选参数 参数含义：标识一条网元服务版本信息的关键字段之一，用于指定需要删除哪个索引对应的网元服务版本信息。 取值范围：1~1024 参数来源：该参数由本端UDM自行定义。操作员可以通过LST UDMNFSRVVER命令查询获得。 默认值：无。 配置原则：该参数和“组名称”参数组成全局唯一对象关键字段。                        |

## 使用实例

当在测试场景下网元上不带业务时，需要删除某个配置错误的网元服务版本信息记录时，可以执行如下步骤进行操作：

1. 执行**RMV UDMNFSRVVER**命令删除“组名称”为“UDM1”，“索引”为“1”配置记录之前，须先使用**LST UDMNFSRV**命令和**LST UDMNFSERVICE**命令查询该网元服务组是否被网元实例引用：

   ```
   LST UDMNFSRV: NFINSNAME="udm-application-001";
   ```

2. 根据查询结果判断该服务版本组是否被引用：
   - 若未被引用，请直接执行**RMV UDMNFSRVVER**命令删除网元服务版本信息，“组名称”为“UDM1”，“索引”为“1”。

     ```
     RMV UDMNFSRVVER: GRPNAME="UDM1", INDEX=1;
     ```
   - 若被引用，请执行a，b，c三步完成网元服务版本信息删除操作。
     1. 执行**RMV UDMNFSERVICE**命令删除网元服务信息：

        ```
        RMV UDMNFSERVICE: SERVICEID="UDM1";
        ```
     2. 执行**RMV UDMNFSRV**命令删除网元实例：

        ```
        RMV UDMNFSRV: NFINSNAME="udm-application-001";
        ```
     3. 执行**RMV UDMNFSRVVER**命令删除网元服务版本信息，“组名称”为“UDM1”，“索引”为“1”。

        ```
        RMV UDMNFSRVVER: GRPNAME="UDM1", INDEX=1;
        ```
3. 删除配置错误的网元服务版本信息后，重新根据正确规划的信息完成网元服务版本信息添加。

   ```
   ADD UDMNFSRVVER: GRPNAME="srvver-group-01", INDEX=1, APIVERSIONINURI="v2", APIFULLVERSION="2.1.0";
   ```
4. 再次执行**LST UDMNFSRVVER**命令查询当前配置与其规划是否一致。

   ```
   %%LST UDMNFSRVVER:  GRPNAME="srvver-group-01", INDEX=1;%% 
   RETCODE = 0  操作成功

    接口全部版本号  =  2.1.0        
          到期时间  =  NULL 
   (结果个数 = 1)  

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释              | 原因分析                                        | 处理建议                                 |
|-------:|:-------------------|:--------------------------------------------|:-------------------------------------|
|    505 | 当前操作的配置数据不存在。      | “索引”不存在。                                    | 使用LST UDMNFSRVVER命令查询获得“索引”，确保其值已存在。 |
| 360044 | 当前记录在其他命令中引用，无法删除。 | 指定“索引”所在组的“组名称”被NFSERVICE引用，只剩一条记录时无法被删除报错。 | 先删除引用该组引用NFSERVICE信息，再删除该组。          |
