# 修改FQDN信息（MOD UDMFQDNINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改某个FQDN信息的备注。在该命令中，系统通过以下关键参数的组合来唯一标识一条FQDN信息：

- “FQDN名称”
- “IP地址”

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                       |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| NAME    | FQDN名称 | 可选必选说明：必选参数 参数含义：标识FQDN信息数据的关键字段之一（其取值不能被修改），用于指定需要对哪个FQDN名称对应的FQDN信息数据记录的参数进行修改，操作员可以使用LST UDMFQDNINFO命令查询获得。 取值范围：长度不超过255位的字符串，需要符合域名格式。 默认值：无。 配置原则：无。 |
| IPADDR  | IP地址   | 可选必选说明：必选参数 参数含义：标识FQDN信息数据的关键字段之一（其取值不能被修改），用于指定需要对哪个IP地址对应的FQDN信息数据记录的参数进行修改，操作员可以使用LST UDMFQDNINFO命令查询获得。 取值范围：IPV4地址/IPV6地址。 默认值：无。 配置原则：无。            |
| COMMENT | 备注     | 可选必选说明：可选参数 参数含义：用于标识FQDN信息的备注。 取值范围：1~32位字节组成的字符串。 默认值：无。 配置原则：无。                                                                                         |

## 使用实例

修改“FQDN名称”为“udm1.huawei.com”，“IP地址”为“192.168.13.67”的FQDN信息的备注。

```
MOD UDMFQDNINFO: NAME="udm1.huawei.com", IPADDR="192.168.13.67", COMMENT="Huawei";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                    | 原因分析                                                   | 处理建议                                          |
|-------:|:-------------------------|:-------------------------------------------------------|:----------------------------------------------|
|    505 | 当前操作的配置数据不存在             | 输入的“FQDN名称”与IP地址的组合未通过ADD UDMFQDNINFO添加，修改时无法找到FQDN信息。 | 使用LST UDMFQDNINFO命令查询已存在的FQDN信息，然后再使用此命令修改备注。 |
| 360121 | IPADDR参数必须是IPv4地址或IPv6地址 | 输入的“IP地址”不是IPv4或IPv6地址。                                | 根据实际情况重新输入符合IP地址要求的参数。                        |
