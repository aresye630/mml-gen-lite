# 设置PFCP接口兼容性参数（SET PFCPCMPT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C、SMF、GGSN**

该命令用于设置PFCP接口兼容性参数。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| BAR         | POOLPLACEHOLDER   | NWINTVPN   |
|:------------|:------------------|:-----------|
| NOT_SUPPORT | False             | False      |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称        | 参数说明                                                                                                                                                                                                                                         |
|:----------------|:------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| BAR             | 是否支持BAR信元   | 可选必选说明：可选参数  参数含义：该参数用于控制PFCP接口是否支持BAR（Buffering Action Rule）信元。  数据来源：全网规划 取值范围： “SUPPORT（支持）”：支持BAR信元“NOT_SUPPORT（不支持）”：不支持BAR信元  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST PFCPCMPT查询当前参数配置值。  配置原则：无                                       |
| POOLPLACEHOLDER | 是否携带地址池占位符  | 可选必选说明：可选参数  参数含义：该参数用于指定PFCP接口消息是否支持携带地址池占位符。UNC向UDG申请双栈地址的时候，如果只有IPv6类型的地址池，则将IPv4地址池的位置用*代替，即为占位符。 以免对端将IPv6类型的地址池识别成IPv4类型。  数据来源：对端协商  取值范围： TRUE(TRUE)FALSE(FALSE)  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST PFCPCMPT查询当前参数配置值。  配置原则：无 |
| NWINTVPN        | 路由实例是否填写VPN | 可选必选说明：可选参数  参数含义：该参数用于控制PFCP接口中N6口PDR的Network Instance信元是否填写VPN。  数据来源：全网规划  取值范围： TRUE(TRUE)FALSE(FALSE)  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST PFCPCMPT查询当前参数配置值。  配置原则：无                                                               |

## 使用实例

设置PFCP接口兼容性，执行如下命令：

```
SET PFCPCMPT:BAR = NOT_SUPPORT,POOLPLACEHOLDER=FALSE;NWINTVPN=FALSE;
```
