# 清除话单缓存目录状态（CLR CDRSTRGSTATUS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

该命令用来清除话单缓存目录状态的记录。对于目录状态是锁定的目录不会清除，请执行前将预期清除的记录先置为解锁状态。

#### 注意事项

- 该命令执行后立即生效。
- 目录状态被标记位“锁定”的记录不会被清除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                          |
|:--------|:-------|:------------------------------------------------------------------------------|
| PODNAME | POD名称  | 可选必选说明：必选参数 参数含义：该参数用于指定POD名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无 |

#### 使用实例

清除话单缓存目录状态记录：

```
CLR CDRSTRGSTATUS: PODNAME="PodName";
```
