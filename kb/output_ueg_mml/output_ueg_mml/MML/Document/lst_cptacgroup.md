# 查询TAC组（LST CPTACGROUP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SMF**

该命令用来查看指定TAC组或者所有TAC组的配置信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                            |
|:-------------|:-------|:------------------------------------------------------------------------------------------------|
| TACGROUPNAME | TAC组名  | 可选必选说明：可选参数  参数含义：该参数用于指定TAC组名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~32。不支持空格，不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

假设运营商需要去查询指定TAC组beijing：

```
LST CPTACGROUP: TACGROUPNAME="beijing";
RETCODE = 0  操作成功。

结果如下
--------
指定TAC组名  =  beijing
    Tac类型  =  S1Tac
(结果个数 = 1)
---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释         |
|:--------|:--------------|
| TAC组名   | 该参数用于指定TAC组名。 |
| TAC类型   | TAC类型。        |
