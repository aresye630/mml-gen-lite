# 增加Voice Centric终端接入接口地址（ADD VCFUNCIP）

- 命令功能

- 本地用户权限
- 网管用户权限

- 使用实例

#### 命令功能

**适用网元：MME、AMF**

此命令用于增加Voice Centric终端接入接口地址。

#### 注意事项

- 此命令执行后立即生效。
- 此命令最大记录数为4条。
- IP地址和VPN名称必须已在****ADD SERVICEIP****中配置的一条记录，可以用****LST SERVICEIP****查询。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                   |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPVER   | IP版本   | 可选必选说明：必选参数 参数含义：该参数用于配置IP版本。 数据来源：本端规划 取值范围：枚举类型 “IPv4(IPv4地址)” “IPv6(IPv6地址)” 默认值：无 配置原则：根据选择的IP版本，输入相应格式的IP地址。                                                                                                                                                                                                                                                      |
| IPV4    | IPv4地址 | 可选必选说明：条件必选参数 参数含义：该参数用于配置业务IPv4地址。 前提条件：该参数在“IP版本”配置为“IPv4”后生效。 数据来源：全网规划 取值范围：0.0.0.0～255.255.255.255 默认值：无 配置原则： IPv4地址不能配置为0.0.0.0、255.255.255.255和环回地址(127.x.y.z)。 业务地址必须是A、B或者C类地址。 该参数的掩码缺省为255.255.255.255，不可更改。 该参数配置的IPv4地址必须和ADD SERVICEIP命令配置中的IPv4地址一致，可以用LST SERVICEIP查询。                                                                                |
| IPV6    | IPv6地址 | 可选必选说明：条件必选参数 参数含义：该参数用于配置业务IPv6地址。 前提条件：该参数在“IP版本”配置为“IPv6”后生效。 数据来源：全网规划 取值范围：::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 配置原则： IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址(::1)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。 该参数的掩码缺省为FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF，不可更改。 该参数配置的IPv6地址必须和ADD SERVICEIP命令配置中的IPv6地址一致，可以用LST SERVICEIP查询。 |
| VPNNAME | VPN名称  | 可选必选说明：可选参数 参数含义：本参数用于指定IP对应的VPN名称。 数据来源：全网规划 取值范围：1~31位字符串 默认值 ：无 配置原则： VPN名称必须和ADD SERVICEIP命令配置中的VPN一致，可以用LST SERVICEIP查询。                                                                                                                                                                                                                                          |

#### 使用实例

1. 增加Voice Centric终端接入的接口地址：“IP版本”为“IPV4”，“IPv4地址”为“192.168.52.100”：

   ```
   ADD VCFUNCIP: IPVER=IPV4, IPV4="192.168.52.100";
   ```
