#### 命令功能

**须知** 

该命令影响用户会话Qos的协商结果。

**适用网元：SGSN、MME**

此命令用于设置QoS兼容性配置信息。兼容性配置是为了满足不同的运营商对协议的不同要求而作的配置。

#### 注意事项

- 此命令执行后立即生效。
- 此命令与**SET R8QOSMAP**结合使用，配置出QoS的相关映射参数。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

设置“QoS映射规则”选择“STANDARD”，“QoS纠正”选择“NO”，“流量等级调整”选择“NO”，“Iu模式Service Handover”选择“NOT\_SUPPORT”，“发送EPS QoS Extended-2”选择“YES”，配置格式如下：

SET COMPATIBILITY: QOSMAP=STANDARD, QOSCRCT=NO, TCADJST=NO, SRVHANDOVER3G=NOT\_SUPPORT, EPSQOSEXT2=YES;
