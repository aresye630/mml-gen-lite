# 显示设备间审计状态（DSP DEVAUDIT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询设备间审计状态。

## 注意事项

- 如果返回结果结束时间与下次开始时间相同，代表软参“VRM\_DEVAUDITACCELERATION”的取值为“0”。
- 如果返回结果开始时间与结束时间都为NULL，代表此类型对端还未开始首轮设备间审计。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                          |
|:---------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PEERTYPE | 对端类型   | 可选必选说明：必选参数 参数含义：用于标识待查询的对端类型。 取值范围： PCEF(PCEF)AF(AF)OCS(OCS)DRA(DRA)TDF(TDF)SMF(SMF)CHF(CHF)BSF(BSF) 默认值：无。 配置原则：无。  说明： AF对端审计开关可以通过增加PCRF对端AF实体(ADD PAF)命令进行配置。OCS对端审计开关可以通过增加PCRF对端OCS接入点实体(ADD POCSCP)命令进行配置。PCEF对端审计开关可以通过增加PCRF对端PCEF实体(ADD PPCEF)命令进行配置。TDF、DRA对端审计开关可以通过增加PCRF的Diameter对端(ADD PEER)命令进行配置。SMF、CHF、BSF设备间审计可以通过设置SBI接口设备间审计参数（SET SBIDEVAUDIT）命令进行配置。 |
| PEERID   | 对端ID   | 可选必选说明：该参数在“对端类型”配置的类型为“PCEF”、“AF”、“OCS”、“DRA”、“TDF”时为必选参数 参数含义：用于标识待查询的对端ID。 取值范围：0~1023。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                     |

## 使用实例

1. 查询“对端类型”为“DRA”的设备间审计状态：

   ```
   DSP DEVAUDIT: PEERTYPE=DRA, PEERID=0;
   ```

   ```
   %%DSP DEVAUDIT: PEERTYPE=DRA, PEERID=0;%%
   RETCODE = 0  操作成功

   操作结果如下：
   -------------
   实例号   状态    开始时间             结束时间  下次开始时间      
   4205999  处理中  2026-12-15 07:02:02  NULL      2026-12-15 07:17:02  
   4218287  处理中  2026-12-15 07:02:01  NULL      2026-12-15 07:17:01  
   (结果个数 = 2)

   ---    END
   ```
2. 查询“对端类型”为“CHF”的设备间审计状态：

   ```
   DSP DEVAUDIT: PEERTYPE=CHF;
   ```

   ```
   %%DSP DEVAUDIT: PEERTYPE=CHF;%%
   RETCODE = 0  操作成功

   操作结果如下：
   -------------
   实例号   状态  开始时间             结束时间             下次开始时间      
   4205999  空闲  2026-12-14 06:40:25  2026-12-14 06:40:29  2026-12-14 06:55:25  
   4218287  空闲  2026-12-14 06:40:24  2026-12-14 06:40:29  2026-12-14 06:55:24  
   (结果个数 = 2)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项解释请参见表1。

| 输出项名称   | 输出项解释                                                              |
|:--------|:-------------------------------------------------------------------|
| 实例号     | 用于标识当前查询结果中的实例号。                                                   |
| 状态      | 用于标识当前PES服务中设备间审计的状态。状态包括： 空闲：表示当前没有设备间审计任务在执行。 处理中：表示设备间审计任务正在执行。 |
| 开始时间    | 用于标识设备间审计开始时间。                                                     |
| 结束时间    | 用于标识设备间审计结束时间。                                                     |
| 下次开始时间  | 用于标识下次设备间审计开始时间。                                                   |

该命令执行异常，会返回对应的错误码。常见错误码请参见表2。

|   错误码 | 错误码解释                 | 原因分析                            | 处理建议                                                                                                      |
|------:|:----------------------|:--------------------------------|:----------------------------------------------------------------------------------------------------------|
| 58249 | 该类型的PEERID不存在，请确认配置。  | 不存在一条对端类型的实体数据记录，与输入的PEERID相匹配。 | 根据待查询的“对端类型”，执行对应的命令配置一条对端类型的实体数据记录。各类型对应的配置命令请参考“对端类型”中的说明。                                              |
| 58250 | 该对端的设备间审计开关未打开，请确认配置。 | 该对端的设备间审计开关未打开。                 | 若有需要，可以根据“对端类型”打开对应的审计开关。 说明： “对端类型”为“SMF”、“CHF”、“BSF”的审计任务由开启状态调整为关闭时，本轮任务仍会继续执行直到结束，但此时本命令返回结果会报错58250。 |
