# 删除DNAI区域优选规则（RMV NRFDNAIRGNPREF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于删除DNAI区域优选规则。该命令功能暂不生效。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                                                        |
|:-------|:----------|:------------------------------------------------------------------------------------------------------------|
| DNN    | 数据网络名称    | 可选必选说明：必选参数  参数含义：该参数用于表示数据网络名称。该参数功能暂不生效。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~50。  默认值：无  配置原则：  该参数配置为*时表示通配。 |
| DNAI   | 数据网络访问标识符 | 可选必选说明：必选参数  参数含义：该参数用于表示数据网络访问标识符。该参数功能暂不生效。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~50。  默认值：无  配置原则：无            |

## 使用实例

当需要删除DNN为ims，DNAI为huawei.com的区域优选规则：

```
RMV NRFDNAIRGNPREF: DNN="ims", DNAI="huawei.com";
```
