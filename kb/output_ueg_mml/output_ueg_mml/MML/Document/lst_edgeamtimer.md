# 查询通用接入和移动扩展定时器（LST EDGEAMTIMER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询通用接入和移动扩展定时器。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询通用接入和移动扩展定时器，执行如下命令：

```
%%LST EDGEAMTIMER:;%%
RETCODE = 0  操作成功

结果如下
------------------------
  对端NF类型  =  SMF
 SMF消息类型  =  PDUSessionCreate
消息超时时间  =  12
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                          |
|:--------|:-------------------------------|
| 对端NF类型  | 该参数用于指定对端NF的类型。                |
| SMF消息类型 | 当PNFTYPE取值为SMF时该参数必选，用于指定消息类型。 |
| 消息超时时间  | 该参数用于指定消息超时时长。                 |
