# 查询LDAP链路状态信息(DSP LDAPLNK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于请求系统按照链路号或链路状态显示指定的LDAP链路状态信息，若参数都没有输入，则显示所有LDAP链路状态信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                 |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LINKID | 链路ID   | 可选必选说明：可选参数 参数含义：用于请求系统显示哪条链路的链路信息，若链路ID没有输入，则表示所有的链路。 取值范围：0～31 默认值：无。 配置原则：无。                                                                                      |
| STATE  | 链路状态   | 可选必选说明：可选参数 参数含义：用于请求系统显示哪种链路状态的链路信息，若链路状态没有输入，则表示所有的链路状态。 取值范围： “LINKDOWN(离线)”：链路不能进行通信。“LINKUP(在线)”：链路可以进行通信。“UNKNOWN(未知)” ：当链路未关联上DLB实例时，无法获取链路状态。 默认值：无。 配置原则：无。 |

## 使用实例

查询LDAP和外置SPR间Sp接口的LDAP链路状态信息。“链路ID”为“4”，其他参数不填。

```
DSP LDAPLNK: LINKID=4;
```

```
%%DSP LDAPLNK: LINKID=0;%%
RETCODE = 0  操作成功

操作结果如下:
-------------
   链路ID  =  4
   实例号  =  539515099
 链路状态  =  离线
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1。

| 输出项名称   | 输出项解释                                                                                                   |
|:--------|:--------------------------------------------------------------------------------------------------------|
| 链路ID    | 用于描述链路号。 取值范围：0～31                                                                                      |
| 实例号     | 用于描述链路所属实例的实例名称。 取值范围：长度不超过256的字符串                                                                      |
| 链路状态    | 用于描述链路的链路状态。 取值范围： “LINKDOWN(离线)”：链路不能进行通信。“LINKUP(在线)”：链路可以进行通信。“UNKNOWN(未知) ”：当链路未关联上DLB实例时，无法获取链路状态。 |
