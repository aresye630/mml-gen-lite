# 开始跟踪参数检查(STR TRCPARACHK)

#### 命令功能

该命令用于开始跟踪参数检查。

该命令的使用场景为：创建跟踪任务时，调用这个命令进行跟踪参数合法性校验。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                            |
|:------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TRCNAME     | 跟踪名称   | 用于指定需要检查的跟踪名称 取值范围：长度不超过63个英文字符。 默认值：无。                                                                                                                                                                         |
| TRCPARA     | 跟踪参数   | 用于指定需要检查的跟踪参数。 取值范围:长度不超过255个英文字符 默认值：无。                                                                                                                                                                        |
| SERVICETYPE | 服务类型   | 可选必选说明：必选参数 参数含义：VNFC名字。此参数用于指定待查询的VNFC，可以通过VNFP上的LST VNFC命令查询得到。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。数字“0~9”，大写字母“A~Z”，小写字母“a~z”，特殊字符“-”，“_”，其他均为非法字符，并且首字符必须为字母。 默认值：无 配置原则：VNFC名称的填写根据进程类型填写。进程和VNFC的对应关系如下表所示： |

#### 使用实例

校验UNC IP接口跟踪参数：

STR TRCPARACHK:TRCNAME="UNCIP",TRCPARA="traceType=4135,ProcType=33,ProcNo=255,ProtocolType=0,sLocalIp=4-10.20.30.34,sDstGsnIp=4-10.20.30.40,v4Mask=4294967295,DstIPv4Mask=4294967295", SERVICETYPE="USN\_VNFC";
