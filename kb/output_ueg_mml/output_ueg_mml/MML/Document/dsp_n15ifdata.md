# 显示N15接口数据(DSP N15IFDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于请求系统显示指定用户永久标识的N15接口数据信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                     |
|:-------|:-------|:-------------------------------------------------------------------------|
| SUPI   | 用户永久标识 | 可选必选说明：必选参数 参数含义：用于指示系统需要按照哪个用户永久标识来查询N15接口数据。 取值范围：0～255 默认值：无。 配置原则：无。 |

## 使用实例

显示指定用户永久标识的N15接口数据信息。

```
DSP N15IFDATA: SUPI="0";
```

```
%%DSP N15IFDATA: SUPI="0";%% 
RETCODE = 0  操作成功
    
操作结果如下:
-------------
请求数据  =  NULL 
响应数据  =  NULL 
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义如表1。

| 输出项名称   | 输出项解释           |
|:--------|:----------------|
| 请求数据    | 用于返回N15接口的请求数据。 |
| 响应数据    | 用于返回N15接口的响应数据。 |
