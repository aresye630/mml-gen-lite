#### 命令功能

**适用网元：MME**

该命令用于向指定的PRA区域配置位置成员，在MME上，PRA区域内可用的位置区标识包括TAI、宏基站（Macro eNodeB）标识、家庭基站（Home eNodeB）标识和E-UTRAN小区标识。

#### 注意事项

- 该命令执行后立即生效。
- 该命令可配置的最大位置成员数是20000。
- 如果以位置区的起始标识和结束标识配置位置成员，同一个位置区内任意两条记录的位置成员不允许重叠交叉。
- 此配置涉及基于指定区域的策略控制功能特性（特性编号：WSFD-106010，license项：LKV2PRA01），执行命令请使用**DSP LICENSE**命令确认对应特性license是否得到授权，执行**LST LICENSESWITCH**命令确认特性开关状态为“ENABLE(打开)”。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                            |
|:-------------|:-----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PRAID        | PRA标识      | 可选必选说明：必选参数 参数含义：该参数表示PRA区域的标识。 数据来源：整网规划 取值范围：0x800000～0xFFFFFF 默认值：无 配置原则：PRA区域标识通过ADD PRAID命令定义。                                                                                                                                                                                                             |
| LOCATIONTYPE | 位置区标识类型    | 可选必选说明：必选参数 参数含义：该参数表示定义PRA区域的位置成员的类型。 数据来源：整网规划 取值范围： “TAI(跟踪区标识)”“MACRO_ENBID(宏基站标识)”“HOME_ENBID(家庭基站标识)”“ECGI(E-UTRAN小区全球标识)” 默认值：无                                                                                                                                                                          |
| MCC          | 移动国家码      | 可选必选说明：条件必选参数 参数含义：该参数表示组成PRA区域的位置成员的移动国家码。 前提条件：该参数在“位置区标识类型”参数配置后生效 数据来源：整网规划 取值范围：3位十进制数字 默认值：无 配置原则：同一个PRA区域内的位置成员的移动国家码必须相同。                                                                                                                                                                               |
| MNC          | 移动网号       | 可选必选说明：条件必选参数 参数含义：该参数表示组成PRA区域的位置成员的移动网号。 前提条件：该参数在“位置区标识类型”参数配置后生效 数据来源：整网规划 取值范围：2～3位十进制数字 默认值：无 配置原则：同一个PRA区域内的位置成员的移动网号必须相同。                                                                                                                                                                               |
| TACBEGIN     | 跟踪区起始编码    | 可选必选说明：条件必选参数 参数含义：该参数表示PRA区域的跟踪区起始编码。 前提条件：该参数在“位置区标识类型”参数配置为“TAI(跟踪区标识)”后生效。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无                                                                                                                                                                                               |
| TACEND       | 跟踪区结束编码    | 可选必选说明：条件可选参数 参数含义：该参数表示PRA区域的跟踪区结束编码。 前提条件：该参数在“位置区标识类型”参数配置为“TAI(跟踪区标识)”后生效。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无 配置原则：本参数与跟踪区起始编码配合使用，表示配置从跟踪区起始编码到本参数之间的一段范围。                                                                                                                                                 |
| ENBIDBEGIN   | eNodeB起始标识 | 可选必选说明：条件必选参数 参数含义：该参数表示PRA区域的eNodeB起始标识。 前提条件：该参数在“位置区标识类型”参数配置为“MACRO_ENBID(宏基站标识)”或者“HOME_ENBID(家庭基站标识)”后生效。 数据来源：整网规划 取值范围：0～268435455 默认值：无 配置原则： 当“位置区标识类型”为“MACRO_ENBID(宏基站标识)”时，本参数的输入范围为0～1048575。当“位置区标识类型”为“HOME_ENBID(家庭基站标识)”时，本参数的输入范围为0～268435455。                                               |
| ENBIDEND     | eNodeB结束标识 | 可选必选说明：条件可选参数 参数含义：该参数表示PRA区域的eNodeB结束标识。 前提条件：该参数在“位置区标识类型”参数配置为“MACRO_ENBID(宏基站标识)”或者“HOME_ENBID(家庭基站标识)”后生效。 数据来源：整网规划 取值范围：0～268435455 默认值：无 配置原则： 当“位置区标识类型”为“MACRO_ENBID(宏基站标识)”时，本参数的输入范围为0～1048575。当“位置区标识类型”为“HOME_ENBID(家庭基站标识)”时，本参数的输入范围为0～268435455。本参数与eNodeB起始标识配合使用，表示配置从eNodeB起始标识到本参数之间的一段范围。 |
| ECIBEGIN     | 小区起始标识     | 可选必选说明：条件必选参数 参数含义：该参数表示PRA区域的E-UTRAN小区起始标识。 前提条件：该参数在“位置区标识类型”参数配置为“ECGI(E-UTRAN小区全球标识)”后生效。 数据来源：整网规划 取值范围：0～268435455 默认值：无                                                                                                                                                                                  |
| ECIEND       | 小区结束标识     | 可选必选说明：条件可选参数 参数含义：该参数表示PRA区域的E-UTRAN小区结束标识。 前提条件：该参数在“位置区标识类型”参数配置为“ECGI(E-UTRAN小区全球标识)”后生效。 数据来源：整网规划 取值范围：0～268435455 默认值：无 配置原则：本参数与E-UTRAN小区起始标识配合使用，表示配置从E-UTRAN小区起始标识到本参数之间的一段范围。                                                                                                                        |

#### 使用实例

在标识为“0x800001”的PRA区域中添加101个跟踪区，其中跟踪区的编码从0x100到0x200。

ADD PRALSTMEM: PRAID="0x800001", LOCATIONTYPE=TAI, MCC="460", MNC="01", TACBEGIN="0x100", TACEND="0x200";
