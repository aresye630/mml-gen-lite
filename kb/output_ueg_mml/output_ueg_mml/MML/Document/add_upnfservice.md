# 增加NF服务实例（ADD UPNFSERVICE）

- 命令功能

- 操作用户权限

- 使用实例

#### 命令功能

**适用NF：UPF**

1、该命令用于添加NF的服务实例信息，即NFS（Network Function Service）。当前NF实例向NRF注册时，同时需要配置其所支持的NFS实例。

2、SBA架构下的每个NF可以具备多种能力，例如会话创建、数据订阅等。NF的这些能力就是通过NFS（Network Function Service，网络功能服务）来承载的。

3、ADD UPNFPROFILE命令用于配置NF整体实例信息，本命令则用于配置NF内具体的NFS实例信息。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为16。
- "Registered"：NF服务实例已在NRF中注册，并且可以被其他NF发现。
- "Suspend"：NF服务实例已在NRF中注册，但无法运行，无法被其他NF发现。在ADD时需要配置为可用的记录，须将NfServiceStatus配置为REGISTERED。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                           |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCENAME  | NF实例名称 | 可选必选说明：必选参数 参数含义：该参数用于指定NF实例名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围是1~64。 默认值：无 配置原则：本参数来源于ADD UPNFUUID命令中的“NF实例名称”参数。                                                                                                                                                                                                                                                                 |
| SRVINSTANCEID   | 服务实例标识 | 可选必选说明：必选参数 参数含义：本参数用于指定NF服务实例标识。 数据来源：全网规划 取值范围：字符串类型，输入长度范围是1~50。 默认值：无 配置原则：本参数构成字符只能是字母A～Z或a～z、数字0～9、中划线“-”和下划线“_”，例如，Service_Instance_0。                                                                                                                                                                                                                                  |
| SERVICENAME     | 服务名称   | 可选必选说明：必选参数 参数含义：该参数用于指定服务名称。 数据来源：全网规划 取值范围： NudmSdm：UDM提供的Nudm_SDM服务。NudmUecm：UDM提供的Nudm_UEContextManagement服务。NamfComm：AMF提供的Namf_Communication Service服务。NamfLoc：AMF提供的Namf_Location服务。NlmfLoc：LMF提供的Nlmf_Location服务。 默认值：无 配置原则：无                                                                                                                                         |
| NFSERVICESTATUS | 服务实例状态 | 可选必选说明：可选参数 参数含义：该参数用于指定服务实例状态。 数据来源：全网规划 取值范围： Invalid：表示当前NF实例处于无效态，如果配置成该值，NF选择时不会选择此类NF。Registered：表示当前NF实例处于注册态，如果配置成该值，NF选择时只会选择此类NF。Suspended：表示当前NF实例处于挂起态。当NF实例处于运维状态下，比如正在进行用户迁移等，不希望在NF发现流程中被选中时，可以置为此状态，迁移完毕后通过该命令对应的MOD命令修改为注册态即可。UnDiscoverable：表示当前NF实例处于不可被发现状态，如果配置成该值，NF选择时不会选择此类NF。DeRegistered：表示当前NF实例处于去注册态，如果配置成该值，NF选择时不会选择此类NF。 默认值：Registered 配置原则：无 |
| PRIORITY        | 优先级    | 可选必选说明：可选参数 参数含义：本参数用于指定服务实例的优先级（与其他同类型NF实例的NFS相比）。 数据来源：全网规划 取值范围：整数类型，取值范围是0~65535。值越小优先级越高。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                    |
| CAPACITY        | 容量     | 可选必选说明：可选参数 参数含义：本参数用于指定NFS的相对权重（与其他同类型NF实例的NFS相比）。 数据来源：全网规划 取值范围：整数类型，取值范围是0~65535。值越大表示容量越大。 默认值：100 配置原则：无                                                                                                                                                                                                                                                                 |
| LOAD            | 负载     | 可选必选说明：可选参数 参数含义：本参数用于指定服务实例的负载。 数据来源：全网规划 取值范围：整数类型，取值范围是0~100。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                  |

#### 使用实例

运营商A需要在标识为LMF\_Instance\_0的NF实例下配置服务实例：服务实例名称为Service\_Instance\_0，服务名为NlmfLoc：

```
ADD UPNFSERVICE: NFINSTANCENAME="LMF_Instance_0", SRVINSTANCEID="Service_Instance_0", SERVICENAME=NlmfLoc, NFSERVICESTATUS=Registered;
```
