# 查询DBS分组开关(LST DBSGRPSWITCH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询DBS支持多应用共存的业务分组控制信息：

- 若要查询全部分组中的开关状态信息，请不要输入任何参数。
- 若要查询某个分组中的开关状态信息，请输入“分组名称”参数。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                           |
|:----------|:-------|:-------------------------------------------------------------------------------------------------------------------------------|
| GROUPNAME | 分组名称   | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照分组名称来查询业务分组控制信息；若不输入，则表示查询所有分组的业务分组控制信息。 取值范围：长度不超过128的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 配置原则：无， |

## 使用实例

1. 查询所有分组的开关状态信息。

   ```
   LST DBSGRPSWITCH:;
   ```

   ```
   %%LST DBSGRPSWITCH:;%% 
   RETCODE = 0  操作成功  

   操作结果如下 
   ------------ 
   分组名称  =  GU-SUP-DNS
       开关  =  关闭 
   (结果个数 = 1)  

   ---    END
   ```
2. 查询分组名称为“GU-SUP-DNS”的开关状态信息。

   ```
   LST DBSGRPSWITCH: GROUPNAME="GU-SUP-DNS";
   ```

   ```
   %%LST DBSGRPSWITCH: GROUPNAME="GU-SUP-DNS";%% 
   RETCODE = 0  操作成功  

   操作结果如下 
   ------------ 
   分组名称  =  GU-SUP-DNS
       开关  =  关闭 
   (结果个数 = 1)  

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET DBSGRPSWITCH**命令的参数说明。
