## 命令功能

**须知** 

- 此命令是高危命令，如果执行不当会影响业务处理，需联系华为技术支持确认后再执行。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令为维护类命令，用于设置HLB服务的系统运行模式，系统运行模式用于指示HLB服务是否可以提供业务服务。

UPCF虚拟机（裸机Pod）存储使用远端共享存储，如果存储故障会导致所有虚拟机（裸机Pod）无法提供服务，但是在存储BYPASS模式时，可以通过此命令设置HLB系统运行模式为激活模式，主用UPCF继续处理业务，也可以设置HLB系统运行模式为去激活模式将业务切换到容灾UPCF处理。

## 注意事项

- 执行此命令和**SET DLBSYSRM**命令，用于设置UPCF网元的系统运行模式。HLB和DLB重启后，该设置不再生效。
- 执行此命令将主用UPCF退服时，需要信令对端（比如SMF、AMF等）支持将链路自动切换到容灾UPCF，否则需要通知各对端及时将链路切换到容灾UPCF。
- 该命令不允许进行批处理操作。
- 只有在虚拟机（裸机Pod）存储故障时才允许使用**SET HLBSYSRM**命令。

**说明** 

执行本命令，将参数“FS”修改为“DEACTIVE(去激活模式)”后，可以通过执行命令“DSP MSPROCESS”查询此时的服务状态为“Unknown（未知状态）”。如果服务状态长时间不恢复，会上报“ALM-100595 进程状态未就绪”告警。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                           |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------|
| FS     | 系统运行状态 | 可选必选说明：必选参数 参数含义：用于指定系统的运行模式。 取值范围：ACTIVE(激活模式)：表示可提供业务服务。 DEACTIVE(去激活模式)：即退服，表示不可提供业务服务。 默认值：无。 系统初始设置值：ACTIVE(激活模式) 配置原则：无。 |

## 使用实例

1. 虚拟机（裸机Pod）存储故障时，设置“系统运行状态”为“DEACTIVE(去激活模式)”，不提供业务服务。

   ```
   SET HLBSYSRM: FS=DEACTIVE;
   ```
2. 虚拟机（裸机Pod）存储故障时，设置“系统运行状态”为“ACTIVE(激活模式)”，继续提供业务服务。

   ```
   SET HLBSYSRM: FS=ACTIVE;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

## 参考信息

BYPASS模式：虚拟机（裸机Pod）在初始安装时分配有充足的磁盘，正常运行时处于有盘模式。当存储故障时，系统自动把运行文件都加载在内存中，转为无盘模式运行。
