# 删除PCRF目的主机配置（RMV PDHOSTCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于删除业务处理中需要与目的主机相关的配置。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                    |
|:-------|:-------|:--------------------------------------------------------|
| PCRFID | PCRF标识 | 用于标识PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围：1 默认值：无。 |
| HOSTID | 目的主机ID | 目的主机ID。 取值范围：0～511 默认值：无。                               |

## 使用实例

删除PCRF目的主机配置信息。“PCRF实体标识”为“1”，“目的主机ID”为“0”。

```
RMV PDHOSTCFG: PCRFID=1, HOSTID=0;
```
