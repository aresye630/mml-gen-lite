# 删除NF对端参数（RMV PEERNFCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致系统异常，影响业务处理，需联系华为技术支持确认后再执行。

该命令用于在配置数据库中删除一条NF对端参数配置信息数据记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                        |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFTYPE | NF类型   | 可选必选说明：必选参数 参数含义：标识PCF对端NF类型，用于指定需要删除哪一条NF对端参数配置信息数据记录；操作员可以使用LST PEERNFCFG命令查询获得。 取值范围：NRF(NRF)AMF(AMF)SMF(SMF)BSF(BSF)CHF(CHF)AF(AF)SCP(SCP)UDR(UDR)NWDAF(NWDAF)HPCF(HPCF) 默认值：无。 配置原则：当某个NF的配置记录被删除时，该对端参数配置信息按照系统默认值进行处理，即： 对于AMF/SMF/SCP默认可配置的最大个数为256；NRF/NWDAF/HPCF默认按照可配置的最大个数为64，对于AF/BSF/CHF默认可配置的最大个数为32，对于UDR默认可配置的最大个数为16。该NF默认按照每个HLB建立一条链路处理。该NF默认老化时长24为小时。 |

## 使用实例

删除NF对端参数。“NF类型”为“SMF”。

```
RMV PEERNFCFG: NFTYPE=SMF;
```
