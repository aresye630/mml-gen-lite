# 查询NSA用户的RAT值（LST NSARATVALUE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C**

该命令用于查询终端作为NSA用户时，UNC给周边网元发送消息中RAT信元携带的值。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询终端作为NSA用户时，UNC给周边网元发送的消息中RAT信元携带的值：

```
LST NSARATVALUE:;
```
