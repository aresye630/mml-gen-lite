# 设置静态地址段在锁定UPF的用户处理（SET STATICIPINLCKUP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、SGW-C、PGW-C、GGSN**

该命令用于设置静态地址段在锁定UPF的用户处理。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| ESTLOCKUPF   |
|:-------------|
| DISABLE      |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称            | 参数说明                                                                                                                                                                                                             |
|:-----------|:----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ESTLOCKUPF | 静态用户在锁定UPF的激活处理 | 可选必选说明：可选参数  参数含义：该参数用于指定用户的IP所属的地址段被分配到了锁定的UPF时，是否允许静态用户在锁定的UPF激活。  数据来源：本端规划 取值范围： DISABLE（静态用户不可以在锁定的UPF激活）ENABLE（静态用户可以在锁定的UPF激活）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST STATICIPINLCKUP查询当前参数配置值。  配置原则：无 |

## 使用实例

设置静态用户在锁定UPF的激活处理为ENABLE：

```
SET STATICIPINLCKUP: ESTLOCKUPF=ENABLE;
```
