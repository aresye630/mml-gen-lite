# 查询LDAP证书更新配置(LST LDAPUPDCERCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

用于查询LDAP证书更新后的链路重建相关配置。

#### 注意事项

无。

#### 参数说明

无。

#### 使用实例

查询LDAP证书更新配置。

```
LST LDAPUPDCERCFG:;
```

```
%%LST LDAPUPDCERCFG:;%%
RETCODE = 0  操作成功

操作结果如下
------------------------
 LDAP重建链时间间隔  =  3
    TLS协商时间间隔  =  2
(结果个数 = 1)

---    END
```

#### 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见SET LDAPUPDCERCFG命令的参数说明。
