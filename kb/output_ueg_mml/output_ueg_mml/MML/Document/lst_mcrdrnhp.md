# 查询组播报文重定向策略（LST MCRDRNHP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 输出结果说明
- 使用实例

#### 命令功能

该命令用来查询组播报文重定向策略配置。

#### 注意事项

NA

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称      | 参数说明                                                                                                          |
|:--------------|:----------|:--------------------------------------------------------------------------------------------------------------|
| VPNNAME       | VPN名称     | 可选必选说明：可选参数 参数含义：该参数用来表示VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。默认值：无。 配置原则：通过LST L3VPNINST查看当前已存在的VPN实例信息。 |
| IPVERSION     | 地址类型      | 可选必选说明：可选参数 参数含义：该参数用于指定下一跳地址为IPv4类型或IPv6类型。 数据来源：本端规划 取值范围：枚举类型。 IPv4：IPv4类型。IPv6：IPv6类型。 默认值：IPv4 配置原则：无    |
| NEXTHOPADDRV4 | IPv4下一跳地址 | 可选必选说明：可选参数 参数含义：该参数用于指定下一跳IPv4地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无 配置原则：无                                      |
| NEXTHOPADDRV6 | IPv6下一跳地址 | 可选必选说明：可选参数 参数含义：该参数用于指定下一跳IPv6地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无 配置原则：无                                      |

#### 输出结果说明

| 输出项名称     | 输出项解释      |
|:----------|:-----------|
| VPN名称     | VPN实例名称。   |
| 地址类型      | 地址类型。      |
| IPv4下一跳地址 | 下一跳IPv4地址。 |
| IPv6下一跳地址 | 下一跳IPv6地址。 |

#### 使用实例

查询组播报文重定向策略配置：

```
%%LST MCRDRNHP: IPVERSION=IPv4;%%
RETCODE = 0  操作成功  
结果如下: 
---------
        VPN名称  =  vrf1
       地址类型  =  IPv4
 IPv4下一跳地址  =  192.168.0.1
 IPv6下一跳地址  =  :: 
(结果个数 = 1)
 ---    END
```
