# 设置EDR上报特性列表(SET EDRREPORT)

## 命令功能

该命令用于设置EDR上报特性列表。

当需要修改信令EDR、业务发放系统EDR、动态用户组EDR、N7信令EDR、Rx信令EDR、Sy信令EDR、N28信令EDR、N23信令EDR、N15信令EDR、N24信令EDR是否上报时，会使用**SET EDRREPORT**命令配置EDR上报特性列表。

## 注意事项

- 执行本命令时，可能会导致用户个人数据泄露，请谨慎使用。

- 数据库中最多有一条配置记录，当数据库中已经存在配置记录时，此命令的执行会修改原来的配置信息。

该命令存在系统初始记录，参数的初始设置值如下：

|   ID |   EDR上报特性列表 |   强制EDR记录开关 |
|-----:|------------:|------------:|
|    1 |         nan |         nan |

- 信令EDR、N7信令EDR、业务发放系统EDR、动态用户组EDR、Rx信令EDR、Sy信令EDR、N28信令EDR、N23信令EDR、N15信令EDR、N24信令EDR默认均不会上报。

- 打开“N7信令EDR”开关的同时建议打开“信令EDR”开关，以记录系统产生的EDR。

## 使用实例

设置EDR上报特性列表标识为1，EDR上报特性列表为信令EDR、N7信令EDR、业务发放系统EDR、动态用户组EDR和Rx信令EDR，同时强制打开规则的EDR记录上报开关。

```
SET EDRREPORT: ID=1, SWITCH=SignalingEDR-1&ProvisioningEDR-1&SubscriberGroupEDR-1&RxSignalingEDR-1&SySignalingEDR-1&N7SignalingEDR-1, FORCEEDRSW=ForceRuleEDR-1;
```

```
%%SET EDRREPORT: ID=1, SWITCH=SignalingEDR-1&ProvisioningEDR-1&SubscriberGroupEDR-1&RxSignalingEDR-1&SySignalingEDR-1&N7SignalingEDR-1, FORCEEDRSW=ForceRuleEDR-1;%%
RETCODE = 0  操作成功

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释             | 原因分析                                                                                         | 处理建议                                                                             |
|------:|:------------------|:---------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------|
| 57647 | FORCEEDRSW参数值配置冲突 | “强制EDR记录开关”参数同时选中了“ForceQuotaValueChange(强制配额值改变EDR)”和“ForceQuotaStatusChange(强制配额状态改变EDR)”。 | 取消同时选中“ForceQuotaValueChange(强制配额值改变EDR)”和“ForceQuotaStatusChange(强制配额状态改变EDR)”。 |
