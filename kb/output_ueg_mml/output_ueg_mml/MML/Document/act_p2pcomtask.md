# 激活SDR点对点通信质量检测任务（ACT P2PCOMTASK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令是高危命令，操作不当可能会影响性能，请谨慎使用并联系华为技术支持协助操作。

该命令用于激活SDR点对点通信质量检测任务。

## 注意事项

- 该命令执行后立即生效。

- 执行此激活命令前需要确保DTP开关处于开启状态，执行**LST SDRPARAMS**命令查询DTP开关状态，执行**SET SDRPARAMS**命令设置DTP开关。
- 只有PROTOCOLTYPE选择UDP可以探测丢包率，选择TCP或TLS测出的丢包率始终为0。
- SRCID不存在时，激活命令执行成功，但激活任务不生效。
- FLATTYPE为BASE时不支持PROTOCOLTYPE为TLS的通信探测。

#### 操作用户权限

G\_1，管理员级别命令组

## 参数说明

| 参数标识         | 参数名称        | 参数说明                                                                                                                                                                                                                                                                         |
|:-------------|:------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FLATTYPE     | 通信平面类型      | 可选必选说明：必选参数  参数含义：该参数用于标识SDR传输平面类型。  数据来源：本端规划 取值范围： “BASE（Base）”：Base平面“FABRIC（Fabric）”：Fabric平面  默认值：无  配置原则：无                                                                                                                                                             |
| PATHTYPE     | 路径类型        | 可选必选说明：必选参数  参数含义：该参数用于标识SDR点对点通信质量检测的路径类型。  数据来源：本端规划 取值范围： “INTERPOD（Pod间测量）”：SDR点对点检测任务在Pod间测量，探测两个Pod间的网络质量。“INTERPROC（进程间测量）”：SDR点对点检测任务在进程间测量，探测两个进程间的网络质量。  默认值：无  配置原则：无                                                                                             |
| PROTOCOLTYPE | 协议类型        | 可选必选说明：必选参数  参数含义：该参数用于标识SDR点对点通信质量检测的协议类型。探测是否有丢包时优选UDP，探测时延则根据消息实际走的通道选择UDP、TCP或TLS。  数据来源：本端规划 取值范围： “UDP（UDP协议）”：SDR点对点检测任务使用UDP协议，表示非可靠传输。“TCP（TCP协议）”：SDR点对点检测任务使用TCP协议，表示可靠传输。“TLS（TLS协议）”：SDR点对点检测任务使用TLS协议，表示加密传输。  默认值：无  配置原则：无                                   |
| SRCID        | 源端ID        | 可选必选说明：必选参数  参数含义：该参数用于标识SDR点对点通信质量检测的源端ID。PATHTYPE为INTERPROC时，该ID为Cell ID，可以通过使用命令DSP MSPROCESS命令输出结果中的Process ID获取。但是Cell ID不能选为SDRE进程类型的Process ID。PATHTYPE为INTERPOD时，该ID为Pod Name(PaaS分配的Pod ID)，可以通过使用命令DSP POD获取。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无  |
| DSTID        | 目的端ID       | 可选必选说明：必选参数  参数含义：该参数用于标识SDR点对点通信质量检测的目的端ID。PATHTYPE为INTERPROC时，该ID为Cell ID，可以通过使用命令DSP MSPROCESS命令输出结果中的Process ID获取。但是Cell ID不能选为SDRE进程类型的Process ID。PATHTYPE为INTERPOD时，该ID为Pod Name(PaaS分配的Pod ID)，可以通过使用命令DSP POD获取。  数据来源：对端协商  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无 |
| PKGLENMODE   | 检测报文长度的模式   | 可选必选说明：必选参数  参数含义：该参数用于标识SDR点对点通信质量检测报文长度的模式。  数据来源：本端规划 取值范围： “MIXEDLEN（混合包长模式）”：探测报文的长度模式为混合模式，自动按预定的包长发包，覆盖不同包长，包长为1024、1500、2000，循环发送这些长度的包。 “FIXEDLEN（指定包长模式）”：探测报文的长度模式为指定长度模式，包长由参数PKGLEN指定，取值范围为1024~10000，单位是字节。  默认值：无  配置原则：无                                     |
| PKGLEN       | 检测报文的长度(字节) | 可选必选说明：该参数在"PKGLENMODE"配置为"FIXEDLEN"时为条件必选参数。  参数含义：该参数用于标识SDR点对点通信质量检测报文的长度。  数据来源：本端规划  取值范围：整数类型，取值范围是1024~10000，单位是字节。  默认值：1024  配置原则：无                                                                                                                                 |
| DURATION     | 检测时长(秒)     | 可选必选说明：可选参数  参数含义：该参数用于标识SDR点对点通信质量检测时长。  数据来源：本端规划  取值范围：整数类型，取值范围是10~86400，单位是秒。  默认值：10  配置原则：无                                                                                                                                                                           |
| PKGRATE      | 检测包速率(个/秒)  | 可选必选说明：可选参数  参数含义：该参数用于标识SDR点对点通信质量检测的检测包速率。  数据来源：本端规划  取值范围：整数类型，取值范围是1~1000，单位是包每秒。  默认值：1  配置原则：无                                                                                                                                                                        |

## 使用实例

激活SDR点对点通信质量检测任务：

```
%%ACT P2PCOMTASK: FLATTYPE=BASE, PATHTYPE=INTERPOD, PROTOCOLTYPE=UDP, SRCID="vsm-pod-6b4c899fc9-6rxzp", DSTID="vusn-pod-0", PKGLENMODE=MIXEDLEN, DURATION=30;%%
RETCODE = 0 操作成功

--- END
```
