# 删除全局Diameter域（RMV UPGLBDIAMREALM）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

**须知** 

本命令属于高危命令，该操作会删除系统缺省的Diameter域，可能会影响DRA选择。

该命令用于删除全局Diameter域。

#### 注意事项

该命令执行后只对新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                             |
|:------------|:-----------|:-----------------------------------------------------------------------------------------------------------------|
| APPLICATION | Diameter应用 | 可选必选说明：必选参数 参数含义：该参数用于指定全局Diameter域所属的Diameter应用。 数据来源：全网规划 取值范围：枚举类型。 SWM：SWM接口应用。 默认值：无 配置原则：根据实际应用场景选择对应的枚举值。 |

#### 使用实例

如果SWM应用不再使用Diameter域，则使用命令删除SWM应用的Diameter域：

```
RMV UPGLBDIAMREALM: APPLICATION=SWM;
```
