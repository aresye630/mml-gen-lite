# 查询HTTP链路测量对象实例(LST HTTPLNKMOI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询所有HTTP链路测量对象实例。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                          |
|:-------|:-------|:----------------------------------------------------------------------------------------------|
| INSID  | 服务实例ID | 可选必选说明：可选参数 参数含义：用于查询指定HTTP链路测量对象实例，若不输入，则查询所有HTTP链路测量对象实例。 取值范围：长度不超过255的字符串。 默认值：无。 配置原则：无。 |

## 使用实例

查询所有HTTP链路测量对象实例。

```
LST HTTPLNKMOI:;
```

```
%%LST HTTPLNKMOI:;%%
RETCODE = 0  操作成功

操作结果如下;
-------------------------
服务实例ID            

1                     
13773741346063040045  
(结果个数 = 2)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD HTTPLNKMOI**命令的参数说明。
