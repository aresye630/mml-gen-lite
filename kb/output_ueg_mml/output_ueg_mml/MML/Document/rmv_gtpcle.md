# 删除GTP-C本地实体(RMV GTPCLE)

#### 命令功能

**须知** 

删除GTP-C本地实体可能导致大量业务失败。

**适用网元：SGSN、MME、AMF**

该命令用于删除GTPC本地实体。

#### 注意事项

- 该命令在版本升级过程中不能执行。
- 非0号组的记录执行删除时，若该记录是本组的最后一个IP地址记录，且被GTP-C IP地址接口属性表（**LST GTPCINTFATTR**）引用，则删除失败。
- 若删除的记录的IP地址被GTP-C路径白名单表（**LST GTPCWHITELIST**）引用，则删除失败。
- 若删除的记录的IP地址被S11接口子网配置（**LST S11INTFSUBNET**）引用，则删除失败。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称        | 参数说明                                                                                                                                                                            |
|:--------|:------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DELTYPE | 删除类型        | 可选必选说明：可选参数 参数含义：本参数用于指定删除GTPC本端实体的Key类型。 数据来源：本端规划 取值范围：“BYINDEX(根据记录索引)”“BYIP(根据IP地址)” 默认值：“BYINDEX(根据记录索引)”                                                                  |
| LEINDEX | GTP-C本端实体标识 | 可选必选说明：条件必选参数 参数含义：本参数用于指定删除GTPC本端实体的记录索引。 前提条件：该参数在“删除类型”参数配置为“BYINDEX(根据记录索引)”后生效。 数据来源：本端规划 取值范围：0~255 默认值：无  说明： 使用LST GTPCLE查询记录的索引。                                       |
| GROUPID | 组号          | 可选必选说明：条件必选参数 参数含义：本参数用于指定GTPC本端实体对应的组号。组号用于组网规划时不同接口，或者不同用户范围使用独立的GTPC本端实体。 前提条件：该参数在“删除类型”参数配置为“BYIP(根据IP地址)”后生效。 数据来源：本端规划 取值范围：0~32 默认值：无  说明： 组号的应用参考ADD GTPCINTFATTR命令帮助。 |
| IPTYPE  | IP地址类型      | 可选必选说明：条件必选参数 参数含义：本参数用于指定GTPC本端实体的IP地址类型。 前提条件：该参数在“删除类型”参数配置为“BYIP(根据IP地址)”后生效。 数据来源：本端规划 取值范围： “TPTADDR_TYPE_IPV4(IPv4)”“TPTADDR_TYPE_IPV6(IPv6)” 默认值：无                      |
| LEIPV4  | IPv4地址      | 可选必选说明：条件必选参数 参数含义：本参数用于指定GTPC本端实体的IPv4地址。 前提条件：该参数在“IP地址类型”参数配置为“TPTADDR_TYPE_IPV4(IPv4)”后生效。 数据来源：本端规划 取值范围：0.0.0.0~255.255.255.255 默认值：无                                     |
| LEIPV6  | IPv6地址      | 可选必选说明：条件必选参数 参数含义：本参数用于指定GTPC本端实体的IPv6地址。 前提条件：该参数在“IP地址类型”参数配置为“TPTADDR_TYPE_IPV6(IPv6)”后生效。 数据来源：本端规划 取值范围：::~FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无                  |

#### 使用实例

删除索引为1的GTPC本地实体：

RMV GTPCLE: DELTYPE=BYINDEX, LEINDEX=1;
