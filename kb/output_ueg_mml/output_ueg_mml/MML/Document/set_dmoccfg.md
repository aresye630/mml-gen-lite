# 设置Diameter流控控制参数(SET DMOCCFG)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于设置Diameter流控控制参数。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称                             | 参数说明                                                                                                                                                                                                                                        |
|:---------|:---------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SNTHD    | Diameter流控Sequence Number有效变化门限值 | 可选必选说明：可选参数 参数含义：该参数用于设置Diameter流控判断Overload Report中Sequence Number有效变化的门限值。 数据来源：本端规划 取值范围: 1~1000000 系统初始值：10000 配置原则：无 默认值：无                                                                                                             |
| ULRCAUSE | Diameter流控导致ULR拒绝原因值             | 可选必选说明：可选参数。 参数含义：该参数用于设置因S6a接口Diameter流控而导致ULR流程失败时，下发给UE的原因值。 数据来源：整网规划。 取值范围：整数取值范围0~111。 系统初始值：0。 默认值：无 配置原则：参数取值为0，表示不使用特殊指定原因值，系统默认下发#22（Congestion）原因值。 原因值为1表示非协议定义原因值，不建议配置。 参数修改为非0值，可能会改变此参数所控制的场景中下发给终端的拒绝原因值，从而导致相应拒绝类话统指标的变化。 |
| AIRCAUSE | Diameter流控导致AIR拒绝原因值             | 可选必选说明：可选参数。 参数含义：该参数用于设置因S6a接口Diameter流控而导致AIR流程失败时，下发给UE的原因值。 数据来源：整网规划。 取值范围：整数取值范围0~111。 默认值：无 系统初始值：0。 配置原则：参数取值为0，表示不使用特殊指定原因值，系统默认下发#22（Congestion）原因值。 原因值为1表示非协议定义原因值，不建议配置。 参数修改为非0值，可能会改变此参数所控制的场景中下发给终端的拒绝原因值，从而导致相应拒绝类话统指标的变化。 |

#### 使用实例

Diameter流控导致ULR流程失败时，预期下发#15（No suitable cells in ta）：

SET DMOCCFG: ULRCAUSE=15;

Diameter流控导致AIR流程失败时，预期下发#17（Network failure）：

SET DMOCCFG: AIRCAUSE=17;
