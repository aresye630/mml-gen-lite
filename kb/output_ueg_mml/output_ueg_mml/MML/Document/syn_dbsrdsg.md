# 同步远端DSG(SYN DBSRDSG)

## 命令功能

**须知** 

该命令属于高危命令，该操作将修改本端的远端DSG配置。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于手工同步对端DSG信息到本端网元。

当本端的远端DSG配置信息与远端的DSG配置信息不一致时，需要执行该命令同步远端DSG配置信息到本端网元。

## 注意事项

- 首先通过**ADD DBSRLOCATION**命令配置远端Location后，才能通过该命令同步对端DSG信息。
- 在手工同步对端DSG信息到本端配置之后，通过**ACT DBSIPDISP**命令激活链路，配置才能生效。
- 执行本命令后，必须在“CSP MML命令”界面执行**SYN CMDATA**命令并确认同步配置数据完成后，再继续其他操作。

## 参数说明

| 参数标识   | 参数名称         | 参数说明                                                                                                                                      |
|:-------|:-------------|:------------------------------------------------------------------------------------------------------------------------------------------|
| RLOCID | 远端Location标识 | 可选必选说明：必选参数 参数含义：标识一条远端DSG配置记录的关键字段，用于指定需要同步哪一条远端Location标识的远端DSG记录。 取值范围：1～512 默认值：无。 配置原则：操作员可以使用LST DBSRDSG命令查询获得。远端Location和远端网元一一对应。 |
| RDSGST | 远端DSG业务类型    | 可选必选说明：可选参数 参数含义：用于标识远端DSG业务类型。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：该参数为联想参数列表，不能手动输入，其取值为LST DBSSRVGROUP命令查询获得的“业务类型名称”输出参数。                  |

## 使用实例

当本端与远端DSG配置记录不一致时，手工同步远端DSG信息到本端，“远端Location标识”为“77”，“远端DSG业务类型”为“SUP-FE”：

```
SYN DBSRDSG: RLOCID=77, RDSGST="SUP-FE";
```
