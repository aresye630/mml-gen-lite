# 修改上传日志文件配置（MOD ULDLOGFILECFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于修改一条上传日志文件的配置信息。在该命令中，系统通过“链路ID”关键参数来唯一标识一条上传日志文件的配置信息。

## 注意事项

本命令必须与软参*VRM\_PMSOPTLOGSW*配合使用，“周期”配置为“FIXED\_PERIOD(固定时间段)”时，建议软参取值为60分钟；“周期”配置为“CYCLIC\_PERIOD(周期时间段)”时，上传周期参数取值需要与软参值配置相同。若增加了多条“周期”配置为“CYCLIC\_PERIOD(周期时间段)”的链路时，建议软参取值为最小的“CYCLIC\_PERIOD(周期时间段)”。

## 参数说明

| 参数标识     | 参数名称          | 参数说明                                                                                                                                                                                           |
|:---------|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LINKID   | 链路ID          | 可选必选说明：必选参数。 参数含义：标识一条链路数据记录的关键字段，用于指定需要对哪一条链路数据记录的参数进行修改或调整，操作员可以使用LST ULDLOGFILECFG命令查询获得。 取值范围：0~15。 默认值：无。 配置原则：无。                                                                         |
| TYPE     | 日志类型          | 可选必选说明：必选参数。 参数含义：用于标识需要上传的日志文件类型。 取值范围： PMSOPTLOG(PMS操作日志)：PMS操作日志。 默认值：无。 配置原则：无。                                                                                                            |
| DSTF     | 目的目录          | 可选必选说明：可选参数。 参数含义：用于指定SFTP服务器上的目标文件路径。 取值范围：长度不超过256位的字符串。 默认值：无。 配置原则：参数中不能包含英文分号、英文反斜线、英文冒号、英文问号、英文引号、英文尖括号和英文星号。                                                                            |
| IPVER    | SFTP服务器IP地址类型 | 可选必选说明：可选参数。 参数含义：用于指定SFTP服务器地址。 取值范围： IPV4(IPV4) IPV6(IPV6) 默认值：无。 配置原则：IP地址是SFTP传输时的重要参数，需要与SFTP服务器协商一致；若不一致，文件上传会失败。                                                                        |
| IP       | SFTP服务器IPv4地址 | 可选必选说明：条件可选参数。 参数含义：用于指定SFTP服务器IPV4地址，仅当“SFTP服务器IP地址类型”配置为“IPV4”时，该参数有效。 取值范围：IPv4地址。 默认值：无。 配置原则：无。                                                                                           |
| IPV6     | SFTP服务器IPv6地址 | 可选必选说明：条件可选参数。 参数含义：用于指定SFTP服务器IPV6地址，仅当“SFTP服务器IP地址类型”配置为“IPV6”时，该参数有效。 取值范围：IPv6地址。 默认值：无。 配置原则：无。                                                                                           |
| PORT     | SFTP服务器端口     | 可选必选说明：可选参数。 参数含义：用于标识SFTP服务器端口。 取值范围：22~65535。 默认值：无。 配置原则：无。                                                                                                                                 |
| USR      | SFTP用户名       | 可选必选说明：可选参数。 参数含义：用于指定SFTP用户名。 取值范围：长度不超过32位的字符串。 默认值：无。 配置原则：用户名是SFTP传输时的重要参数，需要与SFTP服务器协商一致；若不一致，文件上传会失败。                                                                                    |
| PWD      | SFTP密码        | 可选必选说明：可选参数。 参数含义：用于指定SFTP密码。 取值范围：长度不超过32位的字符串。 默认值：无。 配置原则： 密码是SFTP传输时的重要参数，需要与SFTP服务器协商一致；若不一致，文件上传会失败。密码中不能含如下字符串：“%%”、“+++”。密码中不能包含英文分号、英文双引号和英文反斜杠。密码中不能包含空格。                            |
| CFM      | 确认密码          | 可选必选说明：可选参数。 参数含义：用于确认SFTP用户密码。 取值范围：长度不超过32位的字符串。 默认值：无。 配置原则：该参数与“SFTP密码”保持一致。                                                                                                               |
| PRD      | 周期            | 可选必选说明：可选参数。 参数含义：用于标识上传日志文件的周期类型。 取值范围： FIXED_PERIOD(固定时间段)：固定时间段。CYCLIC_PERIOD(周期时间段)：周期时间段。 默认值：无。 配置原则：固定时间段和周期时间段范围采用前闭后开，即开始时间<= 日志文件生成时间<结束时间。                                          |
| ST       | 开始时间          | 可选必选说明：条件可选参数。 参数含义：用于指定开始时间，过滤日志文件时使用。仅当“周期”配置为“FIXED_PERIOD(固定时间段)”时，该参数有效。 取值范围：01/01/1990 00:00:00～31/12/2037 23:59:59。 默认值：无。 配置原则：当“周期”配置为“FIXED_PERIOD(固定时间段)”时，需要填写此参数，若没有填写，则该参数取最小值。 |
| ET       | 结束时间          | 可选必选说明：条件可选参数。 参数含义：用于指定结束时间，过滤日志文件时使用。仅当“周期”配置为“FIXED_PERIOD(固定时间段)”时，该参数有效。 取值范围：01/01/1990 00:00:00～31/12/2037 23:59:59。 默认值：无。 配置原则：当“周期”配置为“FIXED_PERIOD(固定时间段)”时，需要填写此参数，若没有填写，则该参数取最大值。 |
| ULDTIMER | 上传周期          | 可选必选说明：条件可选参数。 参数含义：用于标识日志文件上传周期，仅当“周期”配置为“CYCLIC_PERIOD(周期时间段)”时，该参数有效。 取值范围：1~1440。 单位：分钟。 默认值：5。 配置原则：无。                                                                                    |

## 使用实例

修改一条上传日志文件配置。“链路ID”为“1”，“日志类型”为“PMSOPTLOG(PMS操作日志)”，“目的目录”为“/sftp”，“SFTP服务器IP地址类型”为“IPV4(IPV4)”，“SFTP服务器IPv4地址”为“10.225.225.225”，“SFTP服务器端口”为“22”，“SFTP用户名”为“user”，“SFTP密码”为“\*\*\*\*\*”，“确认密码”为“\*\*\*\*\*”，“周期”为“CYCLIC\_PERIOD(周期时间段)”。

```
MOD ULDLOGFILECFG: LINKID=1, TYPE=PMSOPTLOG, DSTF="/sftp", IPVER=IPV4, IP="10.225.225.225", PORT=22, USR="user", PWD="*****", CFM="*****", PRD=CYCLIC_PERIOD;
```
