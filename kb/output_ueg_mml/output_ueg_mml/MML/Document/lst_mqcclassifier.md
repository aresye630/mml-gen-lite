# 查询流分类（LST MQCCLASSIFIER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询已经创建的流分类信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                                              |
|:---------------|:-------|:------------------------------------------------------------------------------------------------------------------|
| CLASSIFIERNAME | 分类名称   | 可选必选说明：可选参数 参数含义：指定流分类的名称。类名不允许为系统预定义类的名称default-class。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：区分大小写，不支持空格。 |
| CREATETYPE     | 创建类型   | 可选必选说明：必选参数 参数含义：该参数用于指定各规则之间的逻辑运算符关系。 数据来源：本端规划 取值范围：枚举类型。 system-defined：系统默认。user-defined：用户自定义。 默认值：无         |
| OPERATOR       | 关系类型   | 可选必选说明：可选参数 参数含义：该参数用于指定各规则之间的逻辑运算符关系。 数据来源：本端规划 取值范围：枚举类型。 or：或操作。 默认值：无                                         |

#### 使用实例

查询已经创建的流分类信息：

```
LST MQCCLASSIFIER:CREATETYPE=user-defined,CLASSIFIERNAME="c1";
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
分类名称  =  c1
创建类型  =  用户自定义
关系类型  =  或
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释       |
|:--------|:------------|
| 分类名称    | 该参数表示流分类名称。 |
| 创建类型    | 该参数表示创建方式。  |
| 关系类型    | 该参数表示逻辑关系。  |
