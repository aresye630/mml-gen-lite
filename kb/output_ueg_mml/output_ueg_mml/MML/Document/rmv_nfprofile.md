# 删除NF信息(RMV NFPROFILE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响网管或者北向接口的业务处理，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于从配置数据库中删除一条网络功能信息的数据记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                     |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------|
| ID     | 索引     | 可选必选说明：必选参数 参数含义：标识一条NF信息数据记录的关键字段，用于指定需要删除哪一条NF信息数据记录，操作员可以使用LST NFPROFILE命令查询获得。 取值范围：1 默认值：无。 配置原则：无。 |

## 使用实例

删除一条NF配置信息。“索引”为“1”。

```
RMV NFPROFILE: ID=1;
```
