# 删除5GC QoS控制动作配置（RMV 5GCQOSACTION）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于删除5G用户QoS上下行保证带宽门限、最高带宽门限以及带宽超过门限值时对QoS用户的处理动作。

## 注意事项

命令执行后只对新接入用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称          | 参数说明                                                                                                                                            |
|:---------------|:--------------|:------------------------------------------------------------------------------------------------------------------------------------------------|
| QOSPROFILENAME | QoS Profile名称 | 可选必选说明：必选参数  参数含义：该参数用于指定QoS Profile的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。不区分大小写。  默认值：无  配置原则：  该参数需要先通过ADD QOSPROFILE或者SET CPQOSGLOBAL命令配置。 |
| FIVEQI         | 5QI值          | 可选必选说明：必选参数  参数含义：该参数表示5G QoS identifier。  数据来源：本端规划  取值范围：整数类型，取值范围是1~255。  默认值：无  配置原则：无                                                      |

## 使用实例

删除QoS Profile名称为“test”的5GC QoS Action配置，5QI值为2：

```
RMV 5GCQOSACTION:QOSPROFILENAME="test",FIVEQI=2;
```
