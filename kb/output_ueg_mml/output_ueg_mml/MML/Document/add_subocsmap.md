## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响业务处理，需联系华为技术支持确认后再执行。

该命令用于在UPCF配置数据库中增加一条用户扩展属性或消息属性的OCS映射记录。

通过此命令可以添加用户扩展属性与OCS的映射关系，从而实现用户上线时根据用户扩展属性选择OCS的目的；也可以添加用户消息属性与OCS的映射关系，从而实现用户上线时根据消息属性（APN/IMSI/MSISDN等）选择OCS的目的。

在OCS混合组网场景（例如，UPCF与多个OCS之间对接，一部分OCS对接采用直连方式，另一部分OCS对接采用准直连方式）：

- 直连方式：UPCF根据用户扩展属性或消息属性映射到直连OCS，发送Sy消息到对应的OCS。
- 准直连方式：UPCF根据用户扩展属性映射到DRA，发送Sy消息到DRA。

## 注意事项

- 如果系统配置了OCS映射，则说明开启了OCS映射功能，用户上线时根据用户扩展属性或消息属性选择OCS。如果UPCF根据用户扩展属性或消息属性找不到映射关系，则认为没有配置OCS对端，不发起Sy会话消息，UPCF使用配置的Sy配额缺省状态计算下发策略。

  **说明** 

  - UPCF根据用户扩展属性找不到映射关系时，如果配置了DRA，则发送Sy消息到DRA，否则，需要配置默认OCS映射，以保证没有设置扩展属性的用户数据 ，可以路由到原来的OCS；默认OCS映射的用户扩展属性值为255或4294967295。
  - UPCF根据消息属性携带的APN、MSISDN，IMSI，MSISDN\_APN，IMSI\_APN找不到OCS映射关系时，则使用消息属性值配置为Default的OCS映射。
- Sy消息在主用局与容灾局之间转发处理时，如果支持OCS映射功能，则主用局和容灾局的OCS映射配置保持一致。
- OCS路由类型选择消息属性时，系统支持同一个消息属性取不同值，映射不同的OCS域名。
- OCS路由类型选择用户扩展属性时，系统不支持多个用户属性都配置OCS映射，但支持同一个用户属性取不同值时，映射不同的OCS域名。
- 执行本命令时，系统参数“ExtendAttriStrProcessModeEx”不允许设置为非0。

## 使用实例

1. 配置一条消息属性OCS映射记录：UPCF根据消息属性映射到直连OCS，发送Sy消息到对应的OCS。“映射ID”为“1”，“OCS路由类型”为“MessageAttribute（Message Attribute）”，“消息属性类型”为“APN”，“APN名称”为“aaa”，“OCS ID”为“0”。

   ```
   ADD SUBOCSMAP: MAPID=1, OCSRT=MessageAttribute, MSGATRRT=APN, APNNAME="aaa", OCSID=0;
   ```
2. 配置一条用户扩展属性OCS映射记录：UPCF根据用户属性映射到DRA，发送Sy消息到DRA。“OCS路由类型”为“SubscriberAttribute（Subscriber Attribute）”，“用户属性”为“usrExAttr1”，“用户属性值”为“4”，“对端类型”为“DRA”，“OCS域名”为“DRA1domain”。

   ```
   ADD SUBOCSMAP: MAPID=2, OCSRT=SubscriberAttribute, SUBATTR=usrExAttr1, ATTRVALUE=4, PEERTYPE=DRA, REALM="DRA1domain";
   ```
