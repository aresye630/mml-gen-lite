# 查询HTTP链路测量对象(LST HTTPLNKOBJ)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询HTTP2/HTTP1.1链路测量对象。

- 若需要查询全部HTTP2/HTTP1.1链路测量对象信息，请不要输入任何参数。
- 若需要查询某个HTTP2/HTTP1.1链路测量对象信息，可根据需要输入“工作模式”，“本端IP地址”，“本端端口”，“对端IP地址”, “对端端口”中一个或多个参数。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                     |
|:----------|:-------|:---------------------------------------------------------------------------------------------------------|
| WORKMODE  | 工作模式   | 可选必选说明：可选参数 参数含义：用于标识待查询的HTTP2/HTTP1.1链路测量对象的工作模式。 取值范围： SERVER(SERVER) CLIENT(CLIENT) 默认值：无。 配置原则：无。    |
| LOCALIP   | 本端IP地址 | 可选必选说明：可选参数 参数含义：用于标识系统按照本端哪个IP地址来查询HTTP2/HTTP1.1链路测量对象。 取值范围：IPV4/IPV6地址格式的字符串，最大长度为40位。 默认值：无。 配置原则：无。 |
| LOCALPORT | 本端端口   | 可选必选说明：可选参数 参数含义：用于标识待查询的HTTP2/HTTP1.1链路测量对象的本端端口。 取值范围：0~65535。 默认值：无。 配置原则：无。                          |
| PEERIP    | 对端IP地址 | 可选必选说明：可选参数 参数含义：用于标识系统按照对端哪个IP地址来查询HTTP2/HTTP1.1链路测量对象。 取值范围：IPV4/IPV6地址格式的字符串，最大长度为40位。 默认值：无。 配置原则：无。 |
| PEERPORT  | 对端端口   | 可选必选说明：可选参数 参数含义：用于标识待查询的HTTP2/HTTP1.1链路测量对象的对端端口。 取值范围：0~65535。 默认值：无。 配置原则：无。                          |

## 使用实例

1. 查询所有链路数据信息：

   ```
   LST HTTPLNKOBJ:;
   ```

   ```
   %%LST HTTPLNKOBJ:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   工作模式        本端IP地址                 本端端口          对端IP地址                 对端端口    

   CLIENT          192.168.121.183            31                192.168.121.184            32
   CLIENT          192.168.121.187            87                192.168.121.188            88
   CLIENT          192.168.121.191            10067             192.168.121.192            6061
   CLIENT          192.168.121.193            10081             192.168.121.194            6059

   (结果个数 = 4)

   ---    END
   ```
2. 查询“工作模式”为“CLIENT”，“本端IP地址”为“192.168.121.183”，“本端端口”为“31”，“对端IP地址”为“192.168.121.184”, “对端端口”为“32”的链路测量对象

   ```
   LST HTTPLNKOBJ: WORKMODE=CLIENT, LOCALIP="192.168.121.183", LOCALPORT=31, PEERIP="192.168.121.184", PEERPORT=32;
   ```

   ```
   %%LST HTTPLNKOBJ: WORKMODE=CLIENT, LOCALIP="192.168.121.183", LOCALPORT=31, PEERIP="192.168.121.184", PEERPORT=32;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
     工作模式    =  CLIENT              
     本端IP地址  =  192.168.121.183
     本端端口    =  31                 
     对端IP地址  =  192.168.121.184                
     对端端口    =  32    

   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD HTTPLNKOBJ**命令的参数说明。
