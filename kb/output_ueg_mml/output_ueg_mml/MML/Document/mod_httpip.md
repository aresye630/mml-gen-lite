# 修改HTTP IP(MOD HTTPIP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于微服务修改一个对外提供的信令HTTP IP地址的DSCP值。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                            |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPNAME | IP名称   | 可选必选说明：必选参数。 参数含义：用于标识一个微服务对外提供的信令IP地址名称。 取值范围：长度不超过128的由数字和字母组成的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。                                                                   |
| DSCP   | DSCP值  | 可选必选说明：必选参数。 参数含义：用于标识从该链路上发送的消息在IP层被封装为IP数据包时，IP消息头中TOS域表示为DSCP（差异服务代码点）的值。路由器会根据DSCP值对应的优先级对报文进行转发，DSCP值取值越小代表优先级越低。 取值范围：0～63 默认值：无。 配置原则：修改DSCP值后已经建立的链路不会立即生效，需要链路重建后才能生效。 |

## 使用实例

修改微服务对外HTTP IP地址。“IP名称”为“ipv4”，“DSCP值”为“0”：

```
MOD HTTPIP: IPNAME="ipv4", DSCP=0;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释        | 原因分析                    | 处理建议                          |
|-------:|:-------------|:------------------------|:------------------------------|
| 360017 | HTTP IP名称不合法 | “IP名称”只支持数字，字母，下划线和连字符。 | 使用数字、字母、下划线和连线组成的HTTP “IP名称”。 |
