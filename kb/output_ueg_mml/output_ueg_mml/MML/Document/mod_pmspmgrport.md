## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致CLI命令执行失败，需联系华为技术支持确认后再执行。

该命令用于修改策略数据管理端口配置。

## 注意事项

- 打开非安全端口存在安全风险，建议关闭非安全端口，使用安全的UPCF Web UI CLI导入功能，或者打开端口的同时使用软参“VRM\_CLIWORKMODE”修改取值为“1”，开启SCLI接口，采用SCLI方式安全传输。
- UPCF Web UI的CLI导入功能在导航栏的位置：系统管理 > 批处理 > CLI导入。
- 当使用SCLI安全传输方式时，PMS作为服务端，通过命令**MOD PMSFUNC**命令配置TLS参数、加密套件参数和数字证书参数。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                          |
|:-----------|:-------|:--------------------------------------------------------------------------------------------------------------|
| ENABLEPORT | 端口激活状态 | 可选必选说明：可选参数 参数含义：用于标识端口是否激活。 取值说明： ACTIVE（ACTIVE）INACTIVE（INACTIVE） 默认值：无。 系统初始设置值：INACTIVE（INACTIVE） 配置原则：无。 |
| ALIVETIME  | 保活时长   | 可选必选说明：可选参数 参数含义：用于定义服务端链路的保活时长。当客户端在保活时长内没有任何操作时，服务端需要主动断开客户端的连接。 单位：分钟。 取值范围： 1-20160 默认值： 无。 配置原则：无。       |

## 使用实例

修改策略数据管理端口为激活状态，保活时长为30分钟。

```
MOD PMSPMGRPORT: ENABLEPORT=ACTIVE, ALIVETIME=30;
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。
