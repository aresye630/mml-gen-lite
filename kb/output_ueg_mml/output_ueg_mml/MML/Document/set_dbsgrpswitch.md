# 设置DBS分组开关(SET DBSGRPSWITCH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，该操作涉及业务分组功能的控制，配置错误会导致DBS访问BE业务失败。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置DBS支持多应用共存的业务分组的开关状态。

该命令的使用场景：需要对DBS多应用共存的配置和维护时，使用此命令设置DBS支持多应用共存的业务分组的开关状态。

## 注意事项

- 执行本命令打开分组开关前，请确认DBS是否需要支持多应用共存。
- 执行本命令关闭分组开关前，请确认DBS是否不需要支持多应用共存。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                            |
|:------------|:-------|:------------------------------------------------------------------------------------------------|
| GROUPNAME   | 分组名称   | 可选必选说明：必选参数 参数含义：用于指定DBS支持多应用共存的分组名称。 取值范围：长度不超过128的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 配置原则：无。 |
| GROUPSWITCH | 开关     | 可选必选说明：必选参数 参数含义：DBS支持多应用共存的业务分组开关，表示分组功能是否打开。 取值范围：OPEN（打开）CLOSE（关闭） 默认值：CLOSE（关闭） 配置原则：无。     |

## 使用实例

1. 当DBS需要支持多应用时，通过设置分组开关打开分组功能，设置“分组名称”为“GU-SUP-DNS”的开关为“OPEN”：

   ```
   SET DBSGRPSWITCH: GROUPNAME="GU-SUP-DNS", GROUPSWITCH=OPEN;
   ```
2. 当DBS不需要支持多应用时，通过设置分组开关关闭分组功能，设置“分组名称”为“GU-SUP-DNS”的开关为“CLOSE”：

   ```
   SET DBSGRPSWITCH: GROUPNAME="GU-SUP-DNS", GROUPSWITCH=CLOSE;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                      | 原因分析                                                               | 处理建议                                                                                                                                                          |
|-------:|:---------------------------|:-------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
|    505 | 当前操作的配置数据不存在。              | 输入的“分组名称”对应的记录不存在。                                                 | 重新输入“分组名称”，确保其对应的记录已存在。可通过LST DBSSRVGROUP命令查询。                                                                                                                |
| 302536 | 存在分组中的多种业务类型远端配置，需要先删除再关闭。 | DBSRDSG、DBSRIPADDR或DBSRLINKCTRL配置中存在分组内业务类型不同但“远端Location标识”相同的记录。 | 先执行LST DBSRDSG、LST DBSRIPADDR、LST DBSRLINKCTRL命令查询是否存在分组内多种业务类型对应的记录，如果存在，执行RMV DBSRDSG、RMV DBSRIPADDR、RMV DBSRLINKCTRL命令删除多余的远端配置，再执行SET DBSGRPSWITCH命令关闭分组。 |
