# 设置转发面流控参数（SET FWDFCPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

可能会影响流控设置，请谨慎使用并联系华为技术支持协助操作。

该命令用于设置CSLB转发面流控参数。

#### 注意事项

- 该命令执行后立即生效。

- 该命令执行时，FCTHDLEVLE1，FCTHDLEVEL2参数必须选择一个及以上才能执行，否则执行失败（错误码：0x1ce3）。仅设置FCTHDLEVEL1时，FCTHDLEVEL1值更新，FCTHDLEVEL2保持原有值不变；仅设置FCTHDLEVEL2时，FCTHDLEVEL2值更新，FCTHDLEVEL1保持原有值不变。

- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

该命令存在系统初始记录，参数的初始设置值如下表：

| FCTYPE     |   FCTHDLEVEL1 |   FCTHDLEVEL2 |
|:-----------|--------------:|--------------:|
| ICMP       |          1024 |            60 |
| IPS_DETECT |          3200 |           800 |
| TCP_SYN    |           200 |            10 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；

#### 参数说明

| 参数标识        | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                 |
|:------------|:------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FCTYPE      | 流控类型        | 可选必选说明：必选参数 参数含义：该参数用于表示流控类型。 数据来源：本端规划 取值范围：枚举类型: ICMP ：对ICMP协议报文的流控；IPS_DETECT ：对IPS主动探测报文的流控；TCP_SYN ：对TCP协议SYN报文的流控； 默认值：无 配置原则：无                                                                                                                                                                |
| FCTHDLEVEL1 | 一级流控阈值(pps) | 可选必选说明：该参数在FCTYPE为ICMP、IPS_DETECT或TCP_SYN时为可选参数。 参数含义：一级流控阈值。 FCTYPE为ICMP时，为每个RU每秒能通过的ICMP报文数。FCTYPE为IPS_DETECT时，为每个RU每秒能通过的IPS探测报文数。FCTYPE为TCP_SYN时，为每个RU每秒能通过的TCP协议SYN报文数。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535，单位是包每秒(pps)。其中，0代表不限制。 默认值：无 配置原则：无                                                    |
| FCTHDLEVEL2 | 二级流控阈值(pps) | 可选必选说明：该参数在FCTYPE为ICMP、IPS_DETECT或TCP_SYN时为可选参数。 参数含义：二级流控阈值。 FCTYPE为ICMP时，为每个ICMP流（源IP、目的IP、协议类型）每秒能通过的报文数。FCTYPE为IPS_DETECT时，为每个IPS探测链路（源IP、目的IP、协议类型）每秒能通过的报文数。FCTYPE为TCP_SYN时，为每个TCP连接（源IP、目的IP、源端口、目的端口、协议类型）每秒能通过的SYN报文数。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535，单位是包每秒（pps）。其中，0代表不限制。 默认值：无 配置原则：无 |

#### 使用实例

设置ICMP协议报文的流控，对每个RU设置流控级别为2000pps，对每个流设置流控级别为60pps，命令如下：

```
SET FWDFCPARA: FCTYPE=ICMP, FCTHDLEVEL1=2000, FCTHDLEVEL2=60;
```
