## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成UDM在NRF上的注册信息中的PLMN信息发生错误，从而导致周边网元无法访问UDM提供的服务，造成业务失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于增加一个网元的PLMN信息。

- **命令作用**：通过本命令可以配置网元设备所属的国家以及所属网络的运营商。
- **该命令的使用场景**：该命令主要用于网元新开局场景下，配置本网元设备的移动国家码以及移动网络码，在UDM向NRF发起注册时也可以标明本网元设备所属运营商，同时其他网元也可以通过PLMN识别用户是否为本网签约用户。
- **命令可选/必选说明**：该命令在NRF注册场景是必选配置命令。

## 注意事项

- 添加数据成功，如果当前“组名称”已在****ADD UDMNFSRV****命令的“PLMN组名称”中引用，且**ADD UDMNFSRV**命令中的“网元状态”为“REGISTERED”时，将按照**ADD UDMNFSRV**命令的“更新方法”中指定的更新模式立即向NRF发送更新请求。

- 添加数据成功，如果当前“组名称”已在**ADD UDMNFCOMINFO**命令的“允许的PLMN组”中引用，且**ADD UDMNFCOMINFO**命令的“公共信息标识”在**ADD UDMNFSRV**命令的“网元公共信息标识”中引用，且**ADD UDMNFSRV**命令中的“网元状态”为“REGISTERED”时，将按照**ADD UDMNFSRV**命令的“更新方法”中指定的更新模式立即向NRF发送更新请求。

- 添加数据成功，如果当前“组名称”已在**ADD UDMNFCOMINFO**命令的“允许的PLMN组”中引用，且**ADD UDMNFCOMINFO**命令的“公共信息标识”在**ADD UDMNFSERVICE**命令的“网元公共信息标识”中引用，且**ADD UDMNFSERVICE**命令的“组名称”在**ADD UDMNFSRV**命令的“网元服务组”中引用，且**ADD UDMNFSRV**命令中的“网元状态”为“REGISTERED”时，将按照**ADD UDMNFSRV**命令的“更新方法”中指定的更新模式立即向NRF发送更新请求。
- 当凌晨自动校验或执行**VRY NRFDATA**命令手动校验NRFClient内存数据时，在校验该MML命令的过程中，无法执行该命令，若运行该命令，则提示“360155 该MML数据正在校验中，请稍后再试”。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                 |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GRPNAME | 组名称    | 可选必选说明：必选参数 参数含义：用于标识一个网元PLMN信息所属组的名称。该参数在执行ADD UDMNFSRV命令进行NRF注册信息实例化时，用于关联本网元PLMN组信息，以及在执行ADD UDMNFCOMINFO命令时，用于配置网元允许接入的PLMN组信息。 取值范围：长度不超过32的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 参数来源：该参数由本端UDM自行定义。 默认值：无。 配置原则：该参数和“索引”参数组成全局唯一对象关键字段。               |
| INDEX   | 索引     | 可选必选说明：必选参数 参数含义：用于指定一个网元PLMN信息组内的索引。 取值范围：1~1024 参数来源：该参数由本端UDM自行定义。 默认值：无。 配置原则：该参数和“组名称”参数组成全局唯一对象关键字段。                                                                                                                                           |
| MCC     | 移动国家码  | 可选必选说明：必选参数 参数含义：用于指定移动国家码。移动国家码由ETSI（European Telecommunications Standards Institute）在世界范围内统一分配，标识用户漫游移动网络所属的国家，例如中国为460，英国为234等。 取值范围：3位十进制数字组成的字符串。 参数来源：该参数由运营商根据实际情况进行规划。 默认值：无。 配置原则： 每个PLMN区域漫游模板最多可以包含200个“移动国家码”。同一网元PLMN信息所属组中“移动国家码”不能重复。 |
| MNC     | 移动网络码  | 可选必选说明：必选参数 参数含义：用于指定移动网络码。移动网络码用来在一个国家内唯一标识一个移动网络，它由本国电信主管部门在本国范围内统一分配，如中国移动为00，中国联通为01等。 取值范围：2位或3位的十进制数字组成的字符串。 参数来源：该参数由运营商根据实际情况进行规划。 默认值：无。 配置原则： 每个移动国家码最多可以包含200个“移动网络码”。同一网元PLMN信息所属组中“移动网络码”不能重复。                                          |

## 使用实例

对于5G场景下的新建局，增加一条UDM网元的PLMN信息是网元向NRF发起注册且能正常实现业务功能的必配信息之一。详细操作步骤如下：

1. 执行**LST UDMNFPLMN**，确认当前系统未配置任何PLMN信息。
2. 规划增加一条UDM网元PLMN信息所需参数取值，详细参数规划示例如下，
   - “组名称”：本端自行规划名字为“plmngroup-01”。
   - “索引”：本端自行规划记录索引为“1”。
   - “移动国家码”：根据运营商所属国家确定移动国家码为“123”。
   - “移动网络码”：根据运营商实际情况确定移动网络码为“00”。

   **脚本示例如下**：

   ```
   ADD UDMNFPLMN: GRPNAME="plmngroup-01", INDEX=1, MCC="123", MNC="00";
   ```
3. 继续执行**LST UDMNFPLMN**查看配置信息与规划内容是否一致，若不一致可执行 **RMV UDMNFPLMN**命令删除配置错误的记录，再重新执行步骤2中的**ADD UDMNFPLMN**命令添加UDM网元的PLMN信息。

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释             | 原因分析                                      | 处理建议                                                                                         |
|-------:|:------------------|:------------------------------------------|:---------------------------------------------------------------------------------------------|
|    503 | 配置数据已存在           | 输入的记录与已有记录中同一个“组名称”的参数“索引”相同。             | 执行LST UDMNFPLMN命令进行查询已存在的数据记录后，重新输入“索引”值，确保与已有记录中同一个“组名称”的“索引”值不同。                           |
| 360041 | 参数值不合法            | 指定参数值不合法。                                 | 参考参数的定义或举例内容，重新输入提示错误的参数，确保取值符合要求。                                                           |
| 360042 | 参数值已存在            | 输入的记录与已有记录中同一个“组名称”的参数“移动国家码”和“移动网络码”都相同。 | 执行LST UDMNFPLMN命令进行查询已存在的数据记录后，重新输入“移动国家码”和“移动网络码”值，确保与已有记录中同一个“组名称”的“移动国家码”和“移动网络码”至少有一个不同。 |
| 360155 | 该MML数据正在校验中，请稍后再试 | NRFClient内存数据校验正在进行中，对该命令的校验结束后才可执行该命令。   | 请稍后重试。                                                                                       |
