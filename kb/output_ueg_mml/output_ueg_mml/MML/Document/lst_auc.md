# 查询AUC(LST AUC)

- 注意事项

## 命令功能

该命令用于查询外置AUC设备配置记录。

- 若需要查询所有外置AUC设备配置记录，不输入任何参数。
- 若需要查询某个外置AUC设备的详细信息，请输入“AUC名称”参数。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                |
|:--------|:-------|:----------------------------------------------------------------------------------------------------|
| AUCNAME | AUC名称  | 可选必选说明：可选参数 参数含义：用于标识一个外置AUC设备的名称。 取值范围：长度不超过64位的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：该参数全局唯一。 |

## 使用实例

1. 查询所有外置AUC设备配置记录：

   ```
   LST AUC:;
   ```

   ```
   %%LST AUC:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
    AUC名称        IP地址类型       IPv4地址             IPv6地址       端口号       优先级
    auc1           IPV4             192.168.10.33        NULL           80           0     
    auc2           IPV4             192.168.10.34        NULL           82           0 

   (结果个数 = 2)
   ---    END
   ```
2. 查询“AUC名称”为“auc1”的外置AUC设备配置信息：

   ```
   LST AUC: AUCNAME="auc1";
   ```

   ```
   %%LST AUC: AUCNAME="auc1";%%
   RETCODE = 0  操作成功
   操作结果如下: 
   -------------     
      AUC名称  =  auc1     
   IP地址类型  =  IPV4    
     IPv4地址  =  192.168.10.33         
     IPv6地址  =  NULL         
       端口号  =  80         
       优先级  =  0

   (结果个数 = 1)
   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD AUC**命令的参数说明。
