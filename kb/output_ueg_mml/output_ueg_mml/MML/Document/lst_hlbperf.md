# 查询HTTP2基准负荷(LST HLBPERF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询HLB服务的基准负荷。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询HLB服务的基准负荷信息：

```
LST HLBPERF:;
```

```
%%LST HLBPERF:;%%
RETCODE = 0  操作成功

操作结果如下:
-------------
         HLB基准负荷  =  9000
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET HLBPERF**命令的参数说明。
