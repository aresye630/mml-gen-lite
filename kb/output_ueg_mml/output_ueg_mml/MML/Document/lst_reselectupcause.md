# 查询重选UPF故障原因值（LST RESELECTUPCAUSE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C、SMF、GGSN**

该命令用于查询重选UPF故障原因值。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询重选UPF故障原因值。

```
LST RESELECTUPCAUSE:
```

## 输出结果说明

| 输出项名称   | 输出项解释               |
|:--------|:--------------------|
| 故障原因值   | 该参数用于指定UPF重选的故障原因值。 |
