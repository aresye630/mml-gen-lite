# 显示微服务全局数据状态(DSP SRVGDREF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询某个UdmSubService/UdmAuthService的全局数据状态。

## 注意事项

该命令支持在存储bypass时使用。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                       |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------------|
| ST      | 服务类型   | 可选必选说明：必选参数 参数含义：用于标识系统显示哪个服务类型的全局数据。 取值范围： UdmSubServiceUdmAuthService 默认值：无。 配置原则：无。                                     |
| MSINSID | 服务实例ID | 可选必选说明：必选参数 参数含义：用于标识系统显示哪个服务实例ID对应实例的全局数据。 取值范围：长度不超过36位的字符串。 默认值：无。 配置原则：该参数可通过命令DSP UDMSERVICE查询，查询结果中“SF实例号”即为此参数的参数值。 |

## 使用实例

查询全局数据状态，“服务类型”为“UdmSubService”，“服务实例ID”为“11821840686132933153”,。

```
DSP SRVGDREF: ST=UdmSubService, MSINSID="11821840686132933153";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义如表1所示。

| 输出项名称   | 输出项解释                     |
|:--------|:--------------------------|
| 表名称     | 用于返回加载表的表名。               |
| 数据加载结果  | 用于返回最近一次加载全局数据的结果。 成功 失败  |
| 数据加载时间  | 用于返回最近一次加载全局数据的时间。        |
| 数据刷新结果  | 用于返回最近一次刷新全局数据表的结果。 成功 失败 |
| 数据刷新时间  | 用于返回最近一次刷新全局数据表的时间。       |
| 强制刷新标记  | 用于返回是否设置了强制刷新标记。 是 否      |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释          | 原因分析               | 处理建议                                 |
|-------:|:---------------|:-------------------|:-------------------------------------|
| 360145 | 调试任务服务类型实例不存在。 | “服务实例ID”输入错误或者不存在。 | 请通过DSP UDMSERVICE查询“服务实例ID”，重新执行该命令。 |
