# 清除LCS指纹数据（CLR LCSFPDATA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

**须知** 

本命令属于高危命令，此操作会清除LCS指纹信息，可能导致定位精度下降。

该命令用于清除LCS指纹数据。

#### 注意事项

- 该命令执行后立即生效。
- 本命令属于高危命令。
- 执行该命令，会清除LCS指纹数据，可能导致定位精度下降。
- 若执行该命令过程中发生LMFCenterExec复位，则需要重新执行该命令。
- 执行该命令，仅会清除当前内存中的指纹数据，不会删除通过网管/MAE的“网元文件传输”功能或者OM Portal的“文件传输”功能上传的指纹数据文件，如果LMFCenterExec发生复位，复位后会重新自动加载指纹数据文件的内容。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

无。

#### 使用实例

清除LCS指纹数据：

```
CLR LCSFPDATA:;
```
