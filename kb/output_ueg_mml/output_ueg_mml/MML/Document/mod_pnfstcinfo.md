# 修改对端网元静态信息（MOD PNFSTCINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改一条对端网元静态信息。

在该命令中，系统通过“ID”参数来唯一标识一条NF对端网元静态信息的数据记录。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                   |
|:------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ID          | ID     | 可选必选说明：必选参数 参数含义：用于识别一条对端网元静态信息记录的关键字段（其取值不能被修改），用于指定需要对哪一条对端网元静态信息记录的参数进行修改或调整，可以使用LST PNFSTCINFO命令查询获取。 取值范围：0~2000 默认值：无。 配置原则：无。                                   |
| NFTYPE      | 网元类型   | 可选必选说明：可选参数 参数含义：用于标识对端网元类型。 取值范围： SMF(SMF) AMF(AMF) BSF(BSF) CHF(CHF) SCP(SCP) AF(AF)NWDAF(NWDAF)HPCF(HPCF)NRF(NRF) 默认值：无。 配置原则：无。                                    |
| IPVER       | IP版本   | 可选必选说明：可选参数 参数含义：用于指定对端网元的IP地址的IP版本类型。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。                                                                                       |
| IPV4IP      | IPv4地址 | 可选必选说明：条件必选参数 参数含义：当“IPVER”选择“IPV4(IPV4)”时该参数必须配置，用于表示对端网元的IPv4地址。 取值范围：IPv4地址 默认值：无。 配置原则：无。                                                                          |
| IPV6IP      | IPv6地址 | 可选必选说明：可选参数 参数含义：当“IPVER”选择“IPV6(IPV6)”时该参数必须配置，用于表示对端网元的IPv6地址。 取值范围：IPv6地址 默认值：无。 配置原则：无。                                                                            |
| NFINSTNAME  | 网元实例名称 | 可选必选说明：条件必选参数 参数含义：用于标识对端网元的名称。 取值范围：长度不超过64的字符串。不允许输入字符，；=‘“和两个以及两个以上的空格。 默认值：无。 配置原则：无。  说明： 当SET HTTPCLIENTCFG中“LINKCTLMODE”参数取值为“OLD(旧模式）”时，上报的告警不支持携带本参数“网元实例名称”。 |
| DESCRIPTION | 描述     | 可选必选说明：可选参数 参数含义：用于描述对端网元的IP地址的用途。 取值范围：0~128位字符串 默认值：无。 配置原则：无。                                                                                                       |

## 使用实例

1. 修改“ID”为“1”的对端网元静态信息。“网元类型”为“BSF”,“IP版本”为“IPV4(IPV4)”，“IPv4地址”为“192.168.0.130”，“网元实例名称”为“bsf0”。

   ```
   MOD PNFSTCINFO: ID=1, NFTYPE=BSF, IPVER=IPV4, IPV4IP="192.168.0.130",NFINSTNAME="bsf0";
   ```
2. 修改“ID”为“9”的对端网元静态信息。“网元类型”为“SMF”,“IP版本”为“IPV6(IPV6)”，“IPv6地址”为“fc00:ffff:7834:ffff:ffff:ffff:ffff:ffff”，“网元实例名称”为“smf6”。

   ```
   MOD PNFSTCINFO: ID=9, NFTYPE=SMF, IPVER=IPV6, IPV6IP="fc00:ffff:7834:ffff:ffff:ffff:ffff:ffff",NFINSTNAME="smf6";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释       | 原因分析            | 处理建议                                                                                                                                              |
|------:|:------------|:----------------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
| 58230 | 相同的IP地址已存在。 | 输入的IP地址和已配置的重复。 | 执行LST PNFSTCINFO命令查询IP地址。重新输入IP地址，确保取值与查询结果中不重复。                                                                                                  |
| 58231 | IP版本不允许修改。  | 输入的“IP版本”不支持修改。 | 参数“IP版本”不允许修改，如需修改这个参数，可以采用如下方式进行修改： 执行LST PNFSTCINFO命令，查询对端网元静态信息。执行RMV PNFSTCINFO命令，删除错误“IP版本”的对端网元静态信息。执行ADD PNFSTCINFO命令，增加正确“IP版本”的对端网元静态信息。 |
