# 查询发送通知的NTS实例个数(LST NTSNFNUM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询NTS通知配置信息。

- 如果需要查询全部通知类型的配置信息，请不要输入任何参数。
- 如果需要查询某种通知类型的配置信息，请依据参数说明输入相应的参数作为查询的限制条件。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                     |
|:-------|:-------|:-----------------------------------------------------------------------------------------|
| TYPE   | 通知类型   | 可选必选说明：可选参数 参数含义：用于设置NTS的通知类型。 取值范围： SMS（短消息通知）EMAIL（Email通知）SOAP（SOAP通知） 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询所有的NTS通知配置信息。

   ```
   LST NTSNFNUM:;
   ```

   返回结果如下:

   ```
   %%LST NTSNFNUM:;%% 
   RETCODE = 0  操作成功  
   操作结果如下: 
   -------------  
   通知类型    发送通知的NTS实例个数   
   短消息通知  8        
   Email通知   8   
   SOAP通知    2   
   (结果个数 = 3)  

   ---    END
   ```
2. 查询特定通知类型的NTS通知配置信息。其中“通知类型”为“短消息通知”。

   ```
   LST NTSNFNUM: TYPE=SMS;
   ```

   返回结果如下:

   ```
   %%LST NTSNFNUM: TYPE=SMS;%% 
   RETCODE = 0  操作成功  
   操作结果如下: 
   ------------- 
   通知类型  =  短消息通知  
   发送通知的NTS实例个数  =  5 
   (结果个数 = 1) 

    ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见SET NTSNFNUM命令的参数说明。
