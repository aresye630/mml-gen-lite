# 设置组合规则黑名单（SET COMBRULEBKLST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于配置如果同时存在组合rule和拆分rule，组合rule type中未配置，且组合rule优先级低，则网关当做是的blacklist的策略类型。

#### 注意事项

- 该命令执行后只对新激活用户生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   |   BLPOLICYTYPE |
|:-------|---------------:|
| 初始值    |            nan |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                                                                                              |
|:-------------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| BLPOLICYTYPE | 黑名单策略类型 | 可选必选说明：必选参数 参数含义：该参数用来设置组合rule中未配置的策略作为黑名单策略处理的策略类型。 数据来源：本端规划 取值范围：位域类型。 SMARTREDIRECT：指定url重定向策略在组合rule中未配置时作为黑名单策略。ADC：指定ADC策略在组合rule中未配置时作为黑名单策略。QOS：指定Qos策略在组合rule中未配置时作为黑名单策略。 默认值：无 配置原则：无 |

#### 使用实例

设置组合规则黑名单为ADC：

```
SET COMBRULEBKLST: BLPOLICYTYPE=SMARTREDIRECT-0&ADC-1&QOS-0;
```
