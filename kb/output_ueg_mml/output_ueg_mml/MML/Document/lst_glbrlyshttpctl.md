# 查询媒体中继全局业务HTTP控制（LST GLBRLYSHTTPCTL）

- 命令功能
- 注意事项
- 操作用户权限

#### 命令功能

**适用NF：UPF、PGW-U**

该命令用于查询媒体中继全局业务HTTP控制。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询媒体中继全局业务HTTP控制：

```
LST GLBRLYSHTTPCTL:;
```

```
RETCODE = 0  操作成功

The result is as follows
------------------------
HTTP连接空闲时间（秒） =  60
(结果个数 = 1)

---    END
```
