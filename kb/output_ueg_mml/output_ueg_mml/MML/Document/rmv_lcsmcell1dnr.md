# 删除LCS宏站算法参数（RMV LCSMCELL1DNR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

删除LCS宏站算法参数。

#### 注意事项

执行该命令后，重新发起定位请求时修改生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                |
|:---------|:-------|:------------------------------------------------------------------------------------------------------------------------------------|
| GNODEBID | 基站标识   | 可选必选说明：必选参数 参数含义：该参数用于设置基站标识。 数据来源：全网规划 取值范围：整型数字类型，取值范围为0~4294967295。 默认值：无 配置原则：无                                                 |
| CELLID   | 小区标识   | 可选必选说明：可选参数 参数含义：该参数用于配置小区标识。 数据来源：全网规划 取值范围：整型数字类型，取值范围为0~65534。 默认值：无 配置原则：如果需要删除基站粒度的一维算法开关，不用输入该属性；如果需要删除基站小区粒度的一维算法开关，需要输入该属性。 |

#### 使用实例

删除LCS宏站算法参数：

```
RMV LCSMCELL1DNR: GNODEBID=190041;
```
