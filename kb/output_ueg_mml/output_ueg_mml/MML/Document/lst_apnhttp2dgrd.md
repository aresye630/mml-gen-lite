# 查询APN HTTP2.0协议回落开关（LST APNHTTP2DGRD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用来查询APN下的HTTP2.0协议回落开关信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                              |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN    | APN名称  | 可选必选说明：可选参数 参数含义：该参数用于指定APN名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”特殊字符，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

查询名称为“huawei.com”的APN的HTTP2.0协议回落开关信息：

```
LST APNHTTP2DGRD:APN="huawei.com";
```

```
RETCODE = 0  操作成功。

APN HTTP2协议回落开关信息
-------------------------
              APN名称  =  huawei.com
APN HTTP2协议回落开关  =  继承
(结果个数 = 1)
---    END
```
