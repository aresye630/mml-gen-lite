#### 命令功能

**适用网元：MME**

该命令用来显示实际生效的业务IP地址与VPN实例，以及VPN实例ID的所属关系。

#### 注意事项

无

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                 |
|:------------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPVERSION   | IP版本     | 可选必选说明：可选参数 参数含义：该参数用于指定需要查询的业务IP地址的IP版本。 数据来源：本端规划 取值范围：“IPv4(IPv4地址)”“IPv6(IPv6地址)” 默认值：无 配置原则：根据选择的IP版本，输入相应格式的IP地址。                                                                                                                                                                                              |
| SERVICEIPV4 | 业务IPv4地址 | 可选必选说明：条件可选参数 参数含义：该参数用于指定需要查询的业务IPv4地址。 前提条件：该参数在IP版本配置为“IPv4(IPv4地址)”后生效。 数据来源：全网规划 取值范围：0.0.0.0~255.255.255.255 默认值：无 配置原则：业务地址不能配置为0.0.0.0、255.255.255.255和环回地址(127.x.y.z)。业务地址必须是A、B或者C类地址。该参数的掩码缺省为255.255.255.255，不可更改。                                                                                       |
| SERVICEIPV6 | 业务IPv6地址 | 可选必选说明：条件可选参数 参数含义：该参数用于指定需要查询的业务IPv6地址。 前提条件：该参数在IP版本配置为“IPv6(IPv6地址)”后生效。 数据来源：全网规划 取值范围：::~FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 配置原则：IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址(::1/128)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。该参数的掩码缺省为FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF，不可更改。 |

#### 使用实例

显示业务IP以及业务IP与VPN实例的所属关系的配置记录：

**DSP SERVICEIPMCR:;**

```
%%DSP SERVICEIPMCR: IPVERSION=IPv4;%%
RETCODE = 0  执行成功

操作结果如下
-------------------------
业务IPv4地址             业务IPv6地址          VPN实例名称      VPN实例ID      
192.168.57.1             ::                     _public_            0        
192.168.57.2             ::                     _public_            0        
(结果个数 = 2)

---    END
```

#### 输出结果说明

| 输出项名称    | 输出项解释                   |
|:---------|:------------------------|
| 业务IPv4地址 | 显示查询出的业务IPv4地址。         |
| 业务IPv6地址 | 显示查询出的业务IPv6地址。         |
| VPN实例名称  | 显示查询出的业务IP地址对应的VPN实例名称。 |
| VPN实例ID  | 显示查询出的业务IP地址对应的VPN实例ID。 |
