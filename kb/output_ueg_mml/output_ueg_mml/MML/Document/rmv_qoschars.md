# 删除QoS特征（RMV QOSCHARS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于删除QoS特征。

## 注意事项

- 该命令执行后立即生效。

- 如果本命令中的5QI的值与QOSPROP中5QI的值相同，并且QOSPROP正在被线上的用户使用，则删除此配置可能会导致该用户业务触发创建专载失败。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                      |
|:-------|:--------|:----------------------------------------------------------------------------------------------------------|
| FQI    | 5QI或QCI | 可选必选说明：必选参数  参数含义：该参数用于配置5QI或QCI，不同的5QI或QCI的业务流需使用不同的承载。  数据来源：全网规划  取值范围：整数类型，取值范围是1~255。  默认值：无  配置原则：无 |

## 使用实例

删除5QI为“10”的QoS特征。

```
RMV QOSCHARS: FQI=10;
```
