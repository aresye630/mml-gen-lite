# 修改DNS关联的APN组的描述信息（MOD SMFAPNGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于修改DNS关联的APN组的描述信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                                   |
|:--------|:----------|:-------------------------------------------------------------------------------------------------------|
| GRPNAME | APN组名     | 可选必选说明：必选参数  参数含义：该参数用于指定APN组名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。不区分大小写。  默认值：无  配置原则：无              |
| DESC    | APN组的描述信息 | 可选必选说明：可选参数  参数含义：该参数用于指定对APN群组的描述信息，在运维过程中起到助记的作用。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~32。  默认值：无  配置原则：无 |

## 使用实例

修改DNS关联的APN组的描述信息，APN组为grp1：

```
MOD SMFAPNGRP:GRPNAME="grp1",DESC="M2M";
```
