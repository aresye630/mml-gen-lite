# 查询AMF自运行授权配置（LST EDGEAMSELFRUNAUTH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询AMF自运行授权开关及自运行定时器小时数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询AMF自运行授权开关及自运行定时器小时数，执行如下命令：

```
LST EDGEAMSELFRUNAUTH:;
RETCODE = 0  操作成功

结果如下
--------
  自运行授权开关  =  ENABLE
    时长（小时）  =  2
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                 |
|:--------|:------------------------------------------------------|
| 自运行授权开关 | 该参数用于设置是否开启自运行授权功能。                                   |
| 时长（小时）  | 该参数用于设置自运行定时器小时数。（当自运行授权开关为DISABLE时，自运行定时器小时数的值没有意义）。 |
