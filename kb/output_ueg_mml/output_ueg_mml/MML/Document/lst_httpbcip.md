# 查询HTTP均衡控制IP(LST HTTPBCIP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询HTTP链路均衡控制IP的记录。

- 若需要查询所有的HTTP链路均衡控制IP的记录，请不要输入任何参数。
- 若需要查询某个HTTP链路均衡控制IP的记录，请输入“均衡控制IP名称”。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                    |
|:---------|:---------|:------------------------------------------------------------------------------------------------------------------------|
| BCIPNAME | 均衡控制IP名称 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个均衡控制IP名称来查询HTTP链路均衡控制IP的记录。若不输入，则表示查询所有的HTTP链路均衡控制IP的记录。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询所有的HTTP链路均衡控制IP记录。

   ```
   LST HTTPBCIP:;
   ```

   ```
   %%LST HTTPBCIP:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   均衡控制IP名称  IP地址类型  IPV4地址     IPV6地址  

   bcipname_1      IPV4        192.168.0.3  NULL      
   bcipname_2      IPV4        192.168.0.4  NULL      
   (结果个数 = 2)

   ---    END
   ```
2. 查询“均衡控制IP名称”为“bcipname\_1”的HTTP链路均衡控制IP记录。

   ```
   LST HTTPBCIP: BCIPNAME="bcipname_1";
   ```

   ```
   %%LST HTTPBCIP: BCIPNAME="bcipname_1";%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   均衡控制IP名称  =  bcipname_1
       IP地址类型  =  IPV4
         IPV4地址  =  192.168.0.3
         IPV6地址  =  NULL
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**LST HTTPBCIP**命令的参数说明。
