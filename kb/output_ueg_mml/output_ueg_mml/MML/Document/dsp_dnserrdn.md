#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询UNC检查出的DNS错误域名信息。导致这些错误的原因包括DNS服务器配置错误、配置不完整等。当UNC检测出有DNS查询失败时，会将相关信息记录在系统中，使用该命令可以查询出相关错误信息；当UNC检测出DNS查询成功后，再将相关错误信息从系统中清除。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                       |
|:------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERRTYPE     | 错误类型   | 可选必选说明：可选参数 参数含义：本参数用于指定要查询的错误类型。 数据来源：本端规划 取值范围：“SVR_RSP_FAIL（服务器响应失败）”“SERVICE_MISS（服务名称缺失）” 默认值：无  说明： “服务器响应失败”，表示服务器返回查询失败。“服务名称缺失”，表示DNS服务器或者UNC本地没有配置业务需要的网元类型、接口类型、S5/S8接口协议类型。    |
| RUNAME      | RU名称   | 可选必选说明：可选参数 参数含义：本参数用于指定要查询的SPU资源单元名。该参数可以通过DSP RU命令查询。 数据来源：本端规划 取值范围：1~63 位字符串 默认值：无                                                                                                     |
| PROCESSNO   | 进程号    | 可选必选说明：条件可选参数 参数含义：本参数用于指定要查询的SPP的进程序号。通过DSP PROCESSUSN获取。 前提条件：该参数在“错误类型”参数配置为“服务名称缺失”后生效。 数据来源：本端规划 取值范围：0~20 默认值：无                                                                      |
| SERVICETYPE | 服务名称   | 可选必选说明：必选参数 参数含义：此参数用于指定待查询的服务名称，可以通过LST VNFC命令查询得到。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。数字“0~9”，大写字母“A~Z”，小写字母“a~z”，特殊字符“-”，“_”，其他均为非法字符，并且首字符必须为字母。 默认值：无 配置原则：需要填写LINK_VNFC或USN_VNFC对应的名称。 |

#### 使用实例

显示错误类型为SVR\_RSP\_FAIL的DNS错误域名信息：

DSP DNSERRDN: ERRTYPE=SVR\_RSP\_FAIL,SERVICETYPE="USN\_VNFC";

```
%%DSP DNSERRDN: ERRTYPE=SVR_RSP_FAIL,SERVICETYPE="USN_VNFC";%%
RETCODE = 0  操作成功。
```

#### 输出结果说明

| 输出项名称       | 输出项解释                                                                                                                        |
|:------------|:-----------------------------------------------------------------------------------------------------------------------------|
| DNS域名       | 标识查询出现错误的DNS域名字符串。                                                                                                           |
| 查询类型        | 标识向DNS服务器查询的类型。 取值说明：“A类型查询”“SRV查询”“NAPTR类型查询”“无效查询类型”                                                                       |
| 错误类型        | 标识查询错误的类型。 取值说明：“服务器响应失败”“服务名称缺失”                                                                                            |
| 域名信息来源      | 标识域名信息的来源。 取值说明：“本地配置”“DNS 服务器”“NULL”                                                                                        |
| 失败参考信息      | 标识查询失败的域名的参考信息，不同的错误类型，参考信息代表不同的含义。  说明： 如果错误类型为“服务器响应失败”，则表示查询失败的域名的关联初始查询域名。 如果错误类型为“服务名称缺失”，则表示未配置的网元类型、接口类型、S5/S8接口协议类型。 |
| 第一次查询失败的时间  | 标识第一次检查出DNS查询失败的时间。                                                                                                          |
| 最近一次查询失败的时间 | 标识最近一次检查出DNS查询失败的时间。                                                                                                         |
| 查询失败次数      | 标识检查出DNS查询失败的次数。                                                                                                             |
