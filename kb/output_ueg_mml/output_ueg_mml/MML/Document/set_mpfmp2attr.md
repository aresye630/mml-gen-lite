# 设置MPF Mp2属性配置（SET MPFMP2ATTR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于设置MPF上Mp2链路探测开关和链路探测周期，支持以下两种配置：

（1）链路探测开关，设置开启和关闭链路探测功能。

（2）链路探测周期，设置链路探测的时间周期。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | MP2DETECTSW   |   MP2DETECTTIME |
|:-------|:--------------|----------------:|
| 初始值    | DISABLE       |              60 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称         | 参数说明                                                                                                                                              |
|:--------------|:-------------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
| MP2DETECTSW   | Mp2链路探测开关    | 可选必选说明：可选参数 参数含义：该参数用于配置是否开启Mp2链路探测功能。 数据来源：全网规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：该参数只在Mp2链路正常情况下控制探测消息的发送，链路故障后系统会主动发起探测消息，不受该开关控制。  |
| MP2DETECTTIME | Mp2链路探测周期（秒） | 可选必选说明：可选参数 参数含义：该参数用于设置Mp2链路探测的周期。 数据来源：全网规划 取值范围：整数类型，取值范围为30～1800，单位是秒。取值范围在30到1800之间的整数。 默认值：无 配置原则：设置探测周期后，先按照原探测周期进行探测，下一次探测消息按照修改后的探测周期发送。 |

#### 使用实例

设置MPF Mp2属性配置：

```
SET MPFMP2ATTR: MP2DETECTSW=DISABLE, MP2DETECTTIME=60;
```
