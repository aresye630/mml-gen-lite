# 查询NLF白名单(LST NLFWHITELIST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询NLF白名单信息。

- 如果需要查询全部NLF白名单信息，请不要输入任何参数。
- 如果需要查询指定NLF白名单信息，请输入“索引”或其他参数或这些参数的组合。

## 注意事项

如果查询NLF白名单没有记录，且软参“VRM\_WHITELISTSWITCH”打开，则表示所有的IP都不允许接入。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                     |
|:------------|:-------|:-------------------------------------------------------------------------------------------------------------------------|
| ID          | 索引     | 可选必选说明：可选参数 参数含义：用于查询指定索引的NLF白名单数据记录。 取值范围：0～255 默认值：无。 配置原则：无。                                                          |
| IPVER       | IP版本   | 可选必选说明：可选参数 参数含义：用于查询指定IP版本类型的NLF白名单数据记录。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。                                      |
| IP          | IPV4地址 | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV4(IPV4)”时该参数可配置，用于查询指定IPV4地址的NLF白名单数据记录；若不输入，则表示按照所有的IPV4地址查询。 取值范围：IPv4地址 默认值：无。 配置原则：无。 |
| IPV6        | IPV6地址 | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV6(IPV6)”时该参数可配置，用于查询指定IPV6地址的NLF白名单数据记录；若不输入，则表示按照所有的IPV6地址查询。 取值范围：IPv6地址 默认值：无。 配置原则：无。 |
| DESCRIPTION | 描述     | 可选必选说明：可选参数 参数含义：用于查询指定描述的NLF白名单数据记录；若不输入，则表示按照所有的描述查询。 取值说明：长度不超过32的字符串 默认值：无。 配置原则：无。                                  |

## 使用实例

1. 查询所有的NLF白名单的配置信息。

   ```
   LST NLFWHITELIST:;
   ```

   ```
   %%LST NLFWHITELIST:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   索引  IP版本  IPV4地址      IPV6地址                                 描述                                     

   1     IPV4    10.168.0.130  NULL                                     test                                     
   2     IPV6    NULL          2001:0db8:3fff:ffff:ffff:ffff:ffff:ffff  test    
   (结果个数 = 2)

   ---    END
   ```
2. 查询IPv4类型的NLF白名单的配置信息，“IP版本”为“IPV4(IPV4)”。

   ```
   LST NLFWHITELIST: IPVER=IPV4;
   ```

   ```
   %%LST NLFWHITELIST: IPVER=IPV4;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
       索引  =  1
     IP版本  =  IPV4
   IPV4地址  =  10.168.0.130
   IPV6地址  =  NULL
       描述  =  test
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见ADD NLFWHITELIST命令的参数说明。
