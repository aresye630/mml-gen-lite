# 查询触发重选路由的错误码(LST DMFOVERCODE)

- 本地用户权限

#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询触发重选路由的错误码。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询触发重选路由的错误码:

LST DMFOVERCODE;

```
%%LST DMFOVERCODE:;%%
RETCODE = 0  执行成功。

操作结果如下
-------------------------
  触发重选路由的错误码

  3002
  3004
(结果个数 = 2)

---    END
```

#### 输出结果说明

参见**ADD DMFOVERCODE**的参数标识。
