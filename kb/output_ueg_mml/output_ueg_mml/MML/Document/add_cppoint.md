# 增加CP端点信息（ADD CPPOINT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、SGW-C、PGW-C、GGSN**

在初始配置时，该命令用于在建立会话前增加一个CP端点即控制面SMF端点，包含了该CP端点的信息以及所属的CP节点即控制面SMF节点的索引。一个CP端点归属于一个CP节点，一个CP节点下可以有多个CP端点。比如CP节点相当于一个主机，那么CP端点就相当于其中的一个端口。

## 注意事项

- 该命令执行后立即生效。

- 该命令需要和ADD CPNODE命令配合使用，先使用命令ADD CPNODE，再使用ADD CPPOINT，两个命令都执行后才能生效。
- 该命令配置的本端IP地址与N2接口（ADD SCTPLE）、HTTP接口（ADD HTTPLE）中配置的本端IP地址不能重复。否则，会导致路由不通。

- 最多可输入256条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                                             |
|:-------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CPPOINTINDEX | CP端点索引 | 可选必选说明：必选参数  参数含义：该参数用于指定这个CP端点的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无                                                                                                                                                             |
| CPNODEINDEX  | CP节点索引 | 可选必选说明：必选参数  参数含义：该参数用于指定这个CP端点所属的CP节点的索引。其中CP节点的索引可以通过LST CPNODE查询。  数据来源：本端规划  取值范围：整数类型，取值范围为0。该参数取值只能为0。  默认值：无  配置原则：无                                                                                                                      |
| IPVERSION    | IP类型   | 可选必选说明：必选参数  参数含义：该参数用于指定这个CP端点的IP地址类型。  数据来源：本端规划 取值范围： IPv4（IPv4）IPv6（IPv6）  默认值：无  配置原则：无                                                                                                                                                     |
| IPV4         | IPv4地址 | 可选必选说明：该参数在"IPVERSION"配置为"IPv4"时为条件必选参数。  参数含义：该参数用于指定这个CP端点的IPv4地址。该地址标识N4接口IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。IPv4地址类型。业务地址不能配置为0.0.0.0、255.255.255.255和环回地址(127.x.y.z)。业务地址必须是A、B或者C类地址。  默认值：无  配置原则：无                                        |
| IPV6         | IPv6地址 | 可选必选说明：该参数在"IPVERSION"配置为"IPv6"时为条件必选参数。  参数含义：该参数用于指定这个CP端点的IPv6地址。该地址标识N4接口IPv6地址。  数据来源：全网规划  取值范围：IPv6地址类型。IPv6地址类型。IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址(::1)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。  默认值：无  配置原则：无 |
| VPNNAME      | VPN名称  | 可选必选说明：可选参数  参数含义：该参数用于指定VPN名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~31。区分大小写。  默认值：_public_  配置原则：无                                                                                                                                                  |

## 使用实例

在进行初始配置时为索引为0的CP节点添加一个CP端点：索引号为0，IPv4地址为192.168.0.20：

```
ADD CPPOINT:CPPOINTINDEX=0,CPNODEINDEX=0,IPVERSION=IPv4,IPV4="192.168.0.20";
```
