# 设置PAE寻呼反压流控启动/恢复阈值(SET REVERSEFCPARA)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MME、AMF**

该命令用于设置系统反压流控检测门限参数。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称    | 参数说明                                                                                                                                                                                                                                       |
|:----------------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CTRLPLCY        | 控制策略    | 可选必选说明：必选参数 参数含义：该参数用于指定系统进入反压流控状态的判断方式。 数据来源：本端规划 取值范围： PERCENT（百分比） INSTANCENUM（实例个数） 默认值：PERCENT（百分比） 配置原则：当取值为“PERCENT(百分比)”时，则按照过载的link-pod实例个数占系统中所有link-pod实例个数的百分比进行过载恢复阈值配置。当取值为“INSTANCENUM（实例个数）”时，则按照过载link-pod实例个数进行过载恢复阈值配置。 |
| PERCENTTRGTHD   | 过载阈值（%） | 可选必选说明：条件可选参数 参数含义：该参数用于指定系统启动反压流控的阈值。 前提条件：该参数在“CTRLPLCY”配置为“PERCENT（百分比）”后生效。 数据来源：本端规划 取值范围：整数类型，取值范围为1～99。 默认值：50 配置原则： 无                                                                                                              |
| PERCENTRESUMTHD | 恢复阈值（%） | 可选必选说明：条件可选参数 参数含义：该参数用于指定系统停止反压流控的阈值。 前提条件：该参数在“CTRLPLCY”配置为“PERCENT（百分比）”后生效。 数据来源：本端规划 取值范围：整数类型，取值范围为0～99。 默认值：5 配置原则： 无                                                                                                               |
| INSTTRIGTHD     | 过载阈值（个） | 可选必选说明：条件可选参数 参数含义：该参数用于指定系统启动反压流控的阈值。 前提条件：该参数在“CTRLPLCY”配置为“INSTANCENUM（实例个数）”后生效。 数据来源：本端规划 取值范围：整数类型，取值范围为1～255。 默认值：1 配置原则： 无                                                                                                         |
| INSTRESUMTHD    | 恢复阈值（个） | 可选必选说明：可选参数 参数含义：该参数用于指定系统停止反压流控的阈值。 前提条件：该参数在“CTRLPLCY”配置为“INSTANCENUM（实例个数）”后生效。 数据来源：本端规划 取值范围：整数类型，取值范围为0～255。 默认值：0 配置原则： 过载恢复阈值需要小于过载阈值。                                                                                             |

#### 使用实例

设置PAE寻呼反压流控启动/恢复阈值的控制策略为百分比，过载阈值（%）为50，恢复阈值（%）为5：

```
SET REVERSEFCPARA: CTRLPLCY=PERCENT, PERCENTTRGTHD=50, PERCENTRESUMTHD=5;
```
