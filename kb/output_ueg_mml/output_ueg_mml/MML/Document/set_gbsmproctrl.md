# 设置Gb模式SM流程控制参数（SET GBSMPROCTRL）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

通过该命令配置不合适的原因值下发给MS后，可能导致MS无法进行业务。

**适用网元：SGSN**

该命令用于设置Gb模式SM流程控制参数。在用户接入Gb模式时，UNC可通过该命令控制SM流程进行特殊处理以及特殊场景下指定的原因值下发，以满足运营商实现对现网设备兼容性特殊控制的需求。

#### 注意事项

- 系统初次运行时，会执行系统初始设置值。
- 该命令执行后立即生效。
- 通过该命令配置不合适的原因值下发给MS后，可能导致MS无法进行业务。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称            | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                         |
|:-------------|:----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROT         | 流程类型            | 可选必选说明：必选参数 参数含义：该参数用于指定流程类型，要根据场景来配置相应的流程。 数据来源：整网规划 取值范围：“ACT_PROC(激活流程)”“MOD_PROC(修改流程)”“PFC_PROC(PFC流程)”“HSS_INIT_SUB_QOS_MOD_PROC(HSS发起的签约QoS修改流程)” 系统初始设置值：无                                                                                                                                                                                                                                                           |
| ACTGGSNTMOUT | 激活拒绝原因值（GGSN超时） | 可选必选说明：条件可选参数 参数含义：该参数用于当GGSN超时，激活拒绝原因值。 前提条件：该参数在“流程类型”参数设置为“激活流程”时，才需要配置。 数据来源：整网规划 取值范围： 0～112 系统初始设置值：0  说明： 0表示清除原有的配置。1~7为非协议定义原因值，不建议使用。                                                                                                                                                                                                                                                                              |
| ACTGGSNREJ   | 激活拒绝原因值（GGSN拒绝） | 可选必选说明：条件可选参数 参数含义：该参数用于当GGSN拒绝时，激活一个拒绝原因值映射规则。 前提条件：该参数在“流程类型”参数设置为“激活流程”时，才需要配置。 数据来源：整网规划 取值范围：0～127 系统初始设置值：0  说明： 0表示清除原有的配置。如果该参数取值不为0，必须为CAUSEGRP中已经存在的CAUSEGRPID 。                                                                                                                                                                                                                                                   |
| MODGGSNREJ   | 修改拒绝原因值（GGSN拒绝） | 可选必选说明：条件可选参数 参数含义：该参数用于当GGSN拒绝时，修改一个拒绝原因值映射规则。 前提条件：该参数在“流程类型”参数设置为“修改流程”时，才需要配置。 数据来源：整网规划 取值范围：0～127 系统初始设置值：0  说明： 0表示清除原有的配置。如果该参数取值不为0，必须为CAUSEGRP中已经存在的CAUSEGRPID 。                                                                                                                                                                                                                                                   |
| PFC          | PFC流程处理         | 可选必选说明：条件可选参数 参数含义：该参数用于指定“PFC流程处理”。 前提条件：该参数在“流程类型”参数设置为“PFC流程”时，才需要配置。 数据来源：整网规划 取值范围：“PROTOCOL_DEFINE(协议定义)”“SELF_DEFINE(自定义)” 系统初始设置值：“PROTOCOL_DEFINE(协议定义)”  说明： “PROTOCOL_DEFINE(协议定义)”：BSS发起的Download BSS PFC Request流程，PFC流程按照协议描述进行。“SELF_DEFINE(自定义)”：BSS发起的Download BSS PFC Request流程，增加QoS重新协商部分。                                                                                                               |
| SUBQOSCMP    | 签约QoS变更判断策略     | 可选必选说明：条件可选参数 参数含义：该参数用于控制HSS发起签约QoS修改时，SGSN决定是否发起承载修改流程的判断策略。 前提条件：该参数在“流程类型”参数设置为“HSS发起的签约QoS修改流程”时，才需要配置。 数据来源：整网规划 取值范围：“QOS_IN_USE(与正在使用的QoS比较)”“QOS_SUB(与原签约QoS比较)” 系统初始设置值：“QOS_IN_USE(与正在使用的QoS比较)”  说明： “QOS_IN_USE(与正在使用的QoS比较)”:用新的签约EPS QoS与正在使用的EPS QoS进行比较，如果有变化就发起承载修改流程。如果不希望签约EPS QoS变更对已经存在的EPS承载实时生效，以避免对正在进行的业务产生影响，可以选择该取值。“QOS_SUB(与原签约QoS比较)”:用新的签约EPS QoS与原签约QoS进行比较，如果有变化就发起承载修改流程，3GPP协议定义的标准处理方式。 |

#### 使用实例

设置“PROT（流程类型）”为“MOD\_PROC（修改流程）”，“修改拒绝原因（GGSN拒绝）”为“3”的Gb模式SM流程控制参数：

SET GBSMPROCTRL: PROT=MOD\_PROC, MODGGSNREJ=3;
