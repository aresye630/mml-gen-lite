# 增加5G Home PLMN（ADD NGHPLMN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、NRF、SGW-C、PGW-C、GGSN、NSSF、SMSF、NWDAF、NEF、SCF**

该命令用于增加运营商的Home PLMN。所谓Home PLMN是指签约用户的归属PLMN。一个大型运营商可能有多个Home PLMN。该命令属于基础配置，AMF、SMF、SGW-C、PGW-C、GGSN、NRF、NSSF、SMSF通过用户标识（SUPI/SUCI）中的PLMN和本命令配置数据，识别用户是否本网签约用户。

## 注意事项

- 该命令执行后立即生效。

- 若MCC相同，MNC有效长度为2位和MNC有效长度为3位的记录，前两位不允许相同。
- 对于同一个运营商，Home PLMN与Connect PLMN不允许重复；并且如果Home PLMN与Connect PLMN的MCC相同且MNC位数不同，那么MNC前两位不允许相同。
- 对于同一个运营商，Home PLMN建议全网规划一致，否则，在跨PLMN的Inter流程中（如N2切换流程），若目标侧AMF所在的Serving PLMN不属于老侧AMF的Home PLMN，则跨PLMN会被误判为跨运营商，进而导致两个AMF之间消息发送失败。

- 最多可输入768条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                       |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------|
| NOID   | 运营商标识  | 可选必选说明：必选参数  参数含义：该参数用于唯一标识某个运营商。  数据来源：本端规划  取值范围：整数类型，取值范围为0。  默认值：无  配置原则：无                                             |
| MCC    | 移动国家码  | 可选必选说明：必选参数  参数含义：该参数用于表示组成Home PLMN的移动国家码信息。  数据来源：本端规划  取值范围：字符串类型，输入长度是3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                |
| MNC    | 移动网号   | 可选必选说明：必选参数  参数含义：该参数用于表示组成Home PLMN的移动网号信息。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是2~3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无             |
| DESC   | 描述信息   | 可选必选说明：可选参数  参数含义：该参数是对配置的Home PLMN的描述信息，在运维过程中起助记作用。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~32。  默认值：无  配置原则：  输入单空格将删除该参数已有配置项。 |

## 使用实例

为标识为0的运营商新增Home PLMN 12368，执行如下命令：

```
ADD NGHPLMN: NOID=0, MCC="123", MNC="68", DESC="new homeplmn 12368";
```
