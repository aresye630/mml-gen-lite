# 修改NTS设备地址(MOD NTSDEVADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

- 此命令是高危命令，如果执行不当会导致系统异常，需联系华为技术支持确认后再执行。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于修改在配置数据库中的一条NTS设备地址信息数据记录。在该命令中，系统通过“设备地址标识”来唯一标识一条NTS设备地址信息数据记录。

## 注意事项

- 修改设备地址会使得所有使用该地址的在线连接断线。

- IPv4类型的IP地址不能配置如下非法IP地址：“127.0.0.1”、“0.0.0.0”、“255.255.255.255”、“224.0.0.1”。
- IPv6类型的IP地址不支持混合方式表达，即xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:d.d.d.d，其中x表示一个十六进制数（0～9或A～F），而d.d.d.d表示一个IPv4地址。
- IPv6类型的IP地址不支持以下特殊地址的配置，其中x表示一个十六进制数（0～9或A～F）：

  - 0000:0000:0000:0000:0000:0000:0000:0000
  - FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF
  - 0000:0000:0000:0000:0000:0000:0000:0001
  - FFxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE8x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE9x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEAx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEBx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
- 当已经配置IP地址时，NTS使用该IP提供服务。此时修改该IP地址（支持IPV4地址和IPV6地址互相修改），NTS自动重启。重启后，使用新的IP地址提供服务。
- PMS/NTS/DRS/HLB/DLB/NLF/LDAP设备的IP地址（包括IPv4地址和IPv6地址）需要唯一，任意两种设备的IP地址不能重复。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                     |
|:------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------|
| DEVAID      | 设备地址标识 | 可选必选说明：必选参数 参数含义：标识一条NTS设备地址信息数据记录的关键字段（其取值不能被修改），用于指定需要对哪一条NTS设备地址信息数据记录的参数进行修改或调整，操作员可以使用LST NTSDEVADDR命令查询获得。 取值范围：0～7 默认值：无。 配置原则：无。 |
| VPNINDEX    | VPN索引  | 可选必选说明：可选参数 参数含义：用于指定一个NTS VPN实体，该参数必须先由ADD NTSVPN命令定义，然后才能在此索引。 取值范围：0～15 默认值：无。 配置原则：无。                                                |
| IPVER       | IP版本   | 可选必选说明：可选参数 参数含义：用于指定NTS设备地址的IP版本类型。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。                                                           |
| IP          | IPV4地址 | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV4(IPV4)”时该参数必须配置，用于表示NTS的设备IPv4地址。 取值范围：IPv4地址 默认值：无。 配置原则：无。                                             |
| IPV6        | IPV6地址 | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV6(IPV6)”时该参数必须配置，用于表示NTS的设备IPv6地址。 取值范围：IPv6地址 默认值：无。 配置原则：无。                                             |
| DESCRIPTION | 描述     | 可选必选说明：可选参数 参数含义：用于描述NTS设备地址的用途。 取值范围：长度不超过32的字符串 默认值：无。 配置原则：无。                                                                         |

## 使用实例

1. 修改IPv4类型的NTS设备地址信息，“设备地址标识”为“0”，“IP版本”为“IPV4(IPV4)”，“IPV4地址”为“192.168.0.130”。

   ```
   MOD NTSDEVADDR: DEVAID=0, IPVER=IPV4, IP="192.168.0.130";
   ```
2. 修改IPv6类型的NTS设备地址信息，“设备地址标识”为“0”，“IP版本”为“IPV6(IPV6)”，“IPV6地址”为“fc00:222f:ffff:ffff:ffff:ffff:ffff:ffff”。

   ```
   MOD NTSDEVADDR: DEVAID=0, IPVER=IPV6, IPV6="fc00:222f:ffff:ffff:ffff:ffff:ffff:ffff";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                              | 原因分析                                                     | 处理建议                                                                                                 |
|------:|:-----------------------------------|:---------------------------------------------------------|:-----------------------------------------------------------------------------------------------------|
| 57912 | NTSVPN对象不存在。                       | 输入的“VPN索引”不存在。                                           | 执行LST NTSVPN命令查询全部NTS VPN配置信息，记录已存在的“VPN索引”。 执行本命令，重新设置“VPN索引”，并确保和已存在的NTS“VPN索引”相同。                 |
| 58027 | 该记录被NTSPEERLINKCFG对象引用，不能删除或者修改记录。 | 输入的“设备地址标识”对应的IP地址已被其他对象引用。                              | 执行LST NTSPEERLINKCFG命令，查询引用该IP地址对象的通知服务对端链路。执行RMV NTSPEERLINKCFG命令，删除引用该IP对象的通知服务对端链路。重新执行本命令修改设备地址。 |
| 58107 | 设备地址冲突。                            | PMS/NTS/DRS/HLB/DLB/NLF/LDAP设备的IP地址需要唯一，任意两种设备的IP地址不能重复。 | 修改IP地址，重新执行本命令修改设备地址。                                                                                |
