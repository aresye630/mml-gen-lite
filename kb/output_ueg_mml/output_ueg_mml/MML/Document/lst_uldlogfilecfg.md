# 查询上传日志文件配置（LST ULDLOGFILECFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询上传日志文件的配置信息。

- 若要查询全部上传日志文件的配置信息，请不要输入任何参数。
- 若要查询某个上传日志文件的配置信息，请输入“链路ID”或其他参数，或者“链路ID”和其他参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                              |
|:-------|:-------|:--------------------------------------------------------------------------------------------------|
| LINKID | 链路ID   | 可选必选说明：可选参数。 参数含义：用于标识一条链路配置信息的数据记录；若不输入，则表示所有链路。 取值范围：0~15。 默认值：无。 配置原则：无。                       |
| TYPE   | 日志类型   | 可选必选说明：可选参数。 参数含义：用于标识日志文件的类型；若不输入，则表示所有日志文件的类型。 取值说明： PMSOPTLOG(PMS操作日志)：PMS操作日志。 默认值：无。 配置原则：无。 |
