# 显示M3UA信令链路状态(DSP CPM3LNK)

#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询M3UA信令链路状态。

#### 注意事项

- 查询M3UA信令链路状态的方式有四种：全部(ALL)、链路(LINK)、目的实体(DSP)、链路状态(STATUS)。
- 如果不输入任何参数，则表示查询系统内所有SGP进程上的M3UA信令链路。
- 按照目的实体方式查询时，输入参数中的网络指示语、目的实体编码、本地实体编码必须同时输入，或者同时不输入。
- 在一次查询多条链路状态时，如果查询结果中某条链路的状态信息全部显示为NULL，则表明这条链路所在的SGP进程故障。
- 按照链路状态方式查询时，如果返回“RU状态或类型不对”，则说明所有正常SGP进程上都没有符合查询状态的链路，或者所有SGP进程故障。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                 |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SRT      | 查询方式   | 可选必选说明：可选参数 参数含义：该参数用于指定查询方式。 取值范围：“ALL(全部)”“LINK(链路)”“DSP(目的实体)”“STATUS(链路状态)” 默认值：“ALL(全部)”                                                                                                                                                        |
| RUNAME   | RU名称   | 可选必选说明：条件可选参数 参数含义：该参数用于指定SPU资源单元名。该参数可以通过DSP RU命令查询。 前提条件：此参数在“SRT”参数配置为“LINK(链路)”值后生效。 数据来源：整网规划。 取值范围：0~63 位字符串 默认值：无                                                                                                                             |
| LNK      | 链路号    | 可选必选说明：条件可选参数 参数含义：该参数用于指定M3UA链路号。 前提条件：此参数在“SRT”参数配置为“LINK(链路)”值后生效。 数据来源：本端规划 取值范围：0~1279（数值型） 默认值：无  说明： 此链路号在系统范围内唯一。                                                                                                                            |
| LSX      | 链路集索引  | 可选必选说明：条件可选参数 参数含义：该参数用于设定M3UA链路所属的M3UA链路集。 前提条件：此参数在“SRT”参数配置为“LINK(链路)”值后生效。 取值范围：0~1279（数值型） 默认值：无                                                                                                                                                |
| LKN      | 链路名    | 可选必选说明：条件可选参数 参数含义：该参数用于设置链路名称，标识M3UA链路。 前提条件：此参数在“SRT”参数配置为“LINK(链路)”值后生效。 取值范围：长度不超过32的字符串 默认值：无                                                                                                                                                   |
| DEX      | 目的实体索引 | 可选必选说明：条件可选参数 参数含义：该参数用于设定待查询链路所到达的目的实体索引。 前提条件：此参数在“SRT”参数配置为“DSP(目的实体)”值后生效。 取值范围：0~1279（数值型） 默认值：无                                                                                                                                                |
| NI       | 网络指示语  | 可选必选说明：条件可选参数 参数含义：该参数用于设定待查询链路所到达目的实体所属的信令网。 前提条件：此参数在“SRT”参数配置为“DSP(目的实体)”值后生效。 取值范围：“INT(国际网)”“INTB(国际备用网)”“NAT(国内网)”“NATB(国内备用网)” 默认值：无                                                                                                          |
| DPC      | 目的实体编码 | 可选必选说明：条件可选参数 参数含义：该参数用于设定目的实体编码。 前提条件：此参数在“SRT”参数配置为“DSP(目的实体)”值后生效。 取值范围：长度不超过8的字符串 默认值：无                                                                                                                                                          |
| OPC      | 本地实体编码 | 可选必选说明：条件可选参数 参数含义：该参数用于设定本地实体编码。 前提条件：此参数在“SRT”参数配置为“DSP(目的实体)”值后生效。 取值范围：长度不超过8的字符串 默认值：无                                                                                                                                                          |
| LNKSTATE | 链路状态   | 可选必选说明：条件可选参数 参数含义：该参数用于查询M3UA链路时需要匹配的状态，即只有符合该状态的链路才显示。 前提条件：此参数在“SRT”参数配置为“STATUS(链路状态)”值后生效。 取值范围：“ACT(激活)”“INACT(去活)”“DOWN(SCTP偶联已建立)”“UNEST(SCTP偶联未建立)”“CONG(拥塞)”“MANLOC(人工锁定)”“MANREL(人工释放)” 默认值：无  说明： 这些链路状态都是常态，在异常的常态下参考ALM 80633告警帮助进行处理。 |
