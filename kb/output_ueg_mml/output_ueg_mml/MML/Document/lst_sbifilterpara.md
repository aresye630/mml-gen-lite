# 查询服务接口过滤参数(LST SBIFILTERPARA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询服务接口过滤参数。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询服务接口过滤参数。

```
%%LST SBIFILTERPARA:;%% 
RETCODE = 0  操作成功 
   
操作结果如下;
-------------------------
静态检查参数  =  白名单 
动态检查参数  =  关闭 
(结果个数 = 1)  
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET SBIFILTERPARA**命令的参数说明。
