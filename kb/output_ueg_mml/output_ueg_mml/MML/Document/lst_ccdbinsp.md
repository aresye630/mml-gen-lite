# 查询软件参数的配置信息(LST CCDBINSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，查询软件参数的配置信息。

- 若需要查询全部软参数据记录的概要信息，请不要输入任何参数。
- 若需要查询某条参数数据记录的详细信息，请输入“软件参数名称”，或者“软件参数名称”和其他参数的组合。

## 注意事项

无。

## 参数说明

| 参数ID       | 参数名称      | 参数描述                                                                                                                            |
|:-----------|:----------|:--------------------------------------------------------------------------------------------------------------------------------|
| INSPN      | 软件参数名称    | 可选必选说明：可选参数。 参数含义：标识一条软参数据记录的关键字段之一，用于指示系统需要按照哪个软件参数名称来查询软件参数的配置信息；若不输入，则表示所有的软件参数名称。 取值范围：请参考产品手册的“CCDB软件参数” 默认值：无。 配置原则：无。    |
| FETYPENAME | 应用类型      | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个应用类型来查询软件参数的配置信息；若不输入，则表示所有的应用类型。 取值范围：长度不超过255的字符串。 默认值：无 配置原则：无。                                 |
| INSPMOD    | 软件参数值修改标志 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个软件参数值修改标志来查询软件参数的配置信息；若不输入，则表示所有的软件参数值修改标志。 取值范围：TRUE(是)：被修改过的软参。FALSE(否)：没有被修改过的软参。 默认值：无 配置原则：无。 |

## 使用实例

查询软件参数，“软件参数名称”为“LDRSOURCE”的配置信息。

```
LST CCDBINSP: INSPN=LDRSOURCE;
```

```
%%LST CCDBINSP: INSPN=LDRSOURCE;%%
RETCODE = 0  操作成功

操作结果如下
------------------------

              软件参数值  =  0
                应用类型  =  SUP-DUS

          软件参数最大值  =  2
      软件参数值修改标志  =  否
(结果个数 = 1)

---    END
```
