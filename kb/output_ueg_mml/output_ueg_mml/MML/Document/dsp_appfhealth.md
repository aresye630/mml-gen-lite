# 健康状态检查（DSP APPFHEALTH）

- 输出结果说明

#### 命令功能

**适用NF：UPF、MPF**

服务例行维护，或需要检查APPF服务的健康状态时，可使用此命令查询APPF下各服务的健康状态。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询MPF下各服务的健康状态：

```
DSP APPFHEALTH:;
```

```
RETCODE = 0  操作成功

appf服务健康状态
----------------
服务名  状态   

apigw   Normal  
asr     Normal  
etcd    Normal  
(结果个数 = 3)

---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                                                                           |
|:--------|:--------------------------------------------------------------------------------|
| 服务名     | 服务名称。                                                                           |
| 状态      | 服务的状态。Normal表示服务正常，Abnormal表示服务异常。Abnormal情况请查看是否有该服务相关告警，参考告警手册消除告警，或参考应急手册操作。 |
