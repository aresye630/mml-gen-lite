# 查询网元实例信息(LST NFSRV)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询网元实例数据。

- 若需要查询所有网元实例的信息，不输入任何参数。
- 若需要查询某个网元实例的详细信息，请输入“网元实例名称”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识           | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |

| NFINSID        | 网元实例标识    | 可选必选说明：可选参数 参数含义：用于标识网元实例信息中的网元实例标识，该参数为UUIDv4格式。 UUIDv4格式为“xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx”，例如：4947a69a-f61b-4bc1-b9da-47c9c5d14b64。 取值范围：长度固定为36位的字符串，只允许输入0～9，a～f，A～F，“-”。 默认值：无。 配置原则： 若“网元实例标识”存在，“节点”不存在，将“网元实例标识”取值作为NF instance ID。若“网元实例标识”和“节点”都存在，将“网元实例标识”取值作为NF instance ID。同时检查“网元实例标识”与“节点”参数值一致性，如果不一致，返回错误码58057。若“网元实例标识”不存在，“节点”存在，系统随机生成UUIDv4格式字符串后，将“节点”的取值覆盖该字符串的最后12位，用覆盖后的UUIDv4格式字符串作为NF instance ID。若“网元实例标识”和“节点”都不存在，将系统随机生成的UUIDv4格式字符串作为NF instance ID。 |
| NFTYPE         | 网元类型      | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个网元类型来查询网元实例信息数据；若不输入，则表示所有网元类型的网元实例信息。 取值范围：PCF(策略控制功能) 默认值：PCF(策略控制功能) 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                |

| NFSERSCOPEGRP  | 网元服务范围组名称 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个网元服务范围组名称来查询网元实例信息数据；若不输入，则表示所有网元服务范围组的网元实例信息。 取值范围：由数字、字母、“-”或“_”组成的长度不超过32的字符串 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                |

| NFSETGRP       | 网元集合组名称   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个网元集合组名称来查询网元实例信息数据；若不输入，则表示所有网元集合组的网元实例信息。 取值范围：由数字、字母、“-”或“_”组成的长度不超过32的字符串 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                    |
