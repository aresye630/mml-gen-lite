# 修改用户消息统计功能配置(MOD IMRFUNC)

#### 命令功能

**适用网元：SGSN、MME**

该命令用于修改消息统计任务，配置消息统计的用户范围和接口范围，以方便问题定位。

#### 注意事项

- 开启消息统计功能会增加系统负荷。
- 该命令执行后对正在进行流程处理的用户暂不生效，系统会在用户的任意新的流程，根据最新的配置进行用户消息统计。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                   |
|:--------------|:-------|:-------------------------------------------------------------------------------------------------------|
| SUBRANGE      | 用户范围   | 可选必选说明：必选参数 参数含义：该参数用于指定用户范围。 数据来源：全网规划 取值范围：“ALL_USER(所有用户)”“SPECIAL_USER(指定用户)” 默认值 ：无               |
| IMSIPRE       | IMSI前缀 | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI前缀。 前提条件：该参数在“用户范围”参数配置为“SPECIAL_USER”后生效。 数据来源：全网规划 取值范围：5~15位数字 默认值 ：无 |
| INTERFACETYPE | 接口类型   | 可选必选说明：可选参数 参数含义：该参数用于指定接口类型。 数据来源：全网规划 取值范围：“S11(S11接口)”“S6a(S6a接口)”“SGs(SGs接口)”“Sv(Sv接口)” 默认值 ：无     |

#### 使用实例

修改一条“用户范围”为“SPECIAL\_USER”，“IMSI前缀”为“123000”，“接口类型”为“S11-0&S6a-0&SGs-0&Sv-0”的IMRFUNC配置记录：

MOD IMRFUNC: SUBRANGE=SPECIAL\_USER, IMSIPRE="123000", INTERFACETYPE=S11-0&S6a-0&SGs-0&Sv-0;
