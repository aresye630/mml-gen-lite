# 增加服务接口过滤列表(ADD UDMSBIFILTERLST)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于增加服务接口过滤列表。在安全加固场景下，通过该命令可以设置允许或者禁止访问每个服务的IP地址列表。允许访问服务的IP地址，系统处理对应业务请求消息，否则不处理。该功能通过**MOD UDMSOFTPARA**命令参数的“SBIFilterPara(服务接口过滤参数)”的“StatCheck(静态检查)”来设置系统的黑名单过滤或白名单过滤。

## 注意事项

系统中增加的服务接口过滤列表记录数不能超过1024条。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                                                                              |
|:-----------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FILTERNAME | 过滤器名称    | 可选必选说明：必选参数 参数含义：用于标识一服务化接口过滤名单的过滤器名称，它唯一标识一条过滤记录。 取值范围：长度不超过128位的字符串，只允许输入：0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。                                                                                                                   |
| SERVERNAME | 服务名称     | 可选必选说明：必选参数 参数含义：用于标识需要进行过滤的服务名称。 取值范围： nausf(鉴权服务功能) nausf-auth(AUSF UE鉴权)nausf-sorprotection(AUSF SoR保护)nudm(统一数据管理)nudm-sdm(UDM订阅数据管理)nudm-uecm(UDM UE上下文管理)nudm-ueau(UDM UE鉴权)nudm-ee(UDM事件发布)nudm-pp(UDM参数提供) 默认值：无。 配置原则：无。 |
| IPVER      | IP版本     | 可选必选说明：必选参数 参数含义：用于标识IP地址类型。 取值范围： IPV4(IPV4)：IPv4地址。 IPV6(IPV6)：IPv6地址。 默认值：无。 配置原则：无。                                                                                                                                           |
| IPADDRV4   | IPv4地址   | 可选必选说明：条件必选参数 参数含义：用于指定一个IPv4格式的IP地址。 取值范围：IPv4地址 默认值：无。 配置原则：仅当“IP版本”为“IPV4(IPV4)”时，该参数有效。                                                                                                                                       |
| IPADDRV6   | IPv6地址   | 可选必选说明：条件必选参数 参数含义：用于指定一个IPv6格式的IP地址。 取值范围：IPv6地址，例如，2001:0db8:0266:0000:0000:0000:7864:0266 默认值：无。 配置原则：仅当“IP版本”为“IPV6(IPV6)”时，该参数有效。                                                                                            |
| MASKV4     | IPv4掩码位数 | 可选必选说明：条件必选参数 参数含义：用于指定IPv4格式的IP地址所使用的子网掩码位数。 取值范围：1～32 默认值：无。 配置原则： 仅当“IP版本”为“IPV4(IPV4)”时，该参数有效。 如果配置IPV4掩码位数是1～31，则代表一个IP地址网段。 如果配置IPV4掩码位数是32，则代表一条IP地址记录。                                                                    |
| MASKV6     | IPv6前缀长度 | 可选必选说明：条件必选参数 参数含义：用于指定IPv6格式的IP地址所使用的IPv6前缀长度。 取值范围：1～128 默认值：无。 配置原则： 仅当“IP版本”为“IPV6(IPV6)”时，该参数有效。 如果配置IPV6前缀长度是1～127，则代表一个IP地址网段。 如果配置IPV6前缀长度是128，则代表一条IP地址记录。                                                               |
| OPTYPE     | 操作类型     | 可选必选说明：必选参数 参数含义：用于指定配置的IP地址所属操作类型。 取值范围： WHITELIST(白名单)：允许接入的IP地址或地址网段的列表。 BLACKLIST(黑名单)：不允许接入的IP地址或地址网段的列表。 默认值：无。 配置原则：无。                                                                                                     |

## 使用实例

在安全加固场景下，通过该命令设置允许或者禁止访问每个服务的IP地址列表。“过滤器名称”为“auth4”，“服务名称”为“nausf(鉴权服务功能)”，“IP版本”为“IPV4(IPV4)”，“IPV4地址”为“10.5.26.8”，“IPV4掩码位数”为“24”，“操作类型”为“WHITELIST(白名单)”：

```
ADD UDMSBIFILTERLST: FILTERNAME="auth4", SERVERNAME=nausf, IPVER=IPV4, IPADDRV4="10.5.26.8", MASKV4=24, OPTYPE=WHITELIST;
```
