# 删除PCRF对端PCEF类别(RMV PPCEFCAT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

用于在配置数据库中删除一条PCRF对端PCEF类别的数据记录。

## 注意事项

- 当要删除的PCEF类别标识在某一个PCEF实体数据记录中被使用时，则不允许被删除。
- 增加、删除和修改对端PCEF的“APN标识”对在线会话不生效。

## 参数说明

| 参数标识      | 参数名称       | 参数说明                                                                   |
|:----------|:-----------|:-----------------------------------------------------------------------|
| PCRFID    | PCRF标识     | 用于标识PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围： 1 默认值： 无。              |
| PCEFCATID | 对端PCEF类别标识 | 用于指定要删除的对端为PCEF、BBERF或TDF类别。 取值范围： 1～16 默认值： 无。  说明： 当前UPCF不支持BBERF对端。 |

## 使用实例

删除PCRF对端PCEF类别。PCRF实体标识为1，对端PCEF类别标识为1。

```
RMV PPCEFCAT: PCRFID=1, PCEFCATID=1;
```
