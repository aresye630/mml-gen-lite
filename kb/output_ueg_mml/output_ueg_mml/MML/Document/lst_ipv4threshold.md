# 查询IPv4阈值（LST IPV4THRESHOLD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询IPv4阈值，在整机路由前缀数量超过阈值时，上报告警，提示用户检查是否存在异常，提前干预。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询IPv4阈值：

```
LST IPV4THRESHOLD:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
最大百分比（%） =  80
最小百分比（%） =  70
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见SET IPV4THRESHOLD的参数说明。
