# 设置APN IPv6接口ID配置（SET CPAPNIPV6INFID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、GGSN、SMF**

该命令用于控制为用户分配IPv6地址时，APN下是否开启IMSI作为用户的IPv6地址Interface ID功能。

## 注意事项

- 该命令执行后立即生效。

- APN的值是由ADD CPAPN命令添加，参数IMSI的初始值为INHERIT。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称                      | 参数说明                                                                                                                                                                                                                                                 |
|:-------|:--------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN    | APN名称                     | 可选必选说明：必选参数  参数含义：该参数用于指定APN实例名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“ ” ”、“ ` ”特殊字符，不区分大小写。  默认值：无。  配置原则：  该参数使用ADD CPAPN命令配置生成。 |
| IMSI   | 配置IMSI作为IPv6 Interface ID | 可选必选说明：必选参数  参数含义：该参数用于控制开启和关闭IMSI作为用户的IPv6地址Interface ID功能。  数据来源：本端规划 取值范围： DISABLE（不使能）INHERIT（继承全局）ENABLE（使能）  默认值：无。  配置原则：无                                                                                                                    |

## 使用实例

配置APN名称为apn1，IMSI作为用户的IPv6地址Interface ID功能使能：

```
SET CPAPNIPV6INFID: APN="apn1", IMSI=ENABLE;
```
