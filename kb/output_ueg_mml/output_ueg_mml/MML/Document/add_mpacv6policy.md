# 增加IPv6 MPAC策略（ADD MPACV6POLICY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于在设备上创建管理平面接入控制策略（IPv6）。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为16。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                               |
|:------------|:-------|:-------------------------------------------------------------------------------------------------------------------|
| POLICYNAME  | 策略名称   | 可选必选说明：必选参数 参数含义：该参数用于指定创建策略的策略名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。大小写敏感，英文字母开头，不支持空格。 默认值：无 配置原则：字符串形式，必须指定策略名字。 |
| STEP        | 规则间步长  | 可选必选说明：可选参数 参数含义：该参数用于指定创建策略的规则间步长。 数据来源：本端规划 取值范围：整数类型，取值范围为1～20。 默认值：5                                           |
| DESCRIPTION | 描述信息   | 可选必选说明：可选参数 参数含义：该参数用于指定创建策略的策略描述信息。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～255。字符串区分大小写。 默认值：无                             |

#### 使用实例

创建管理平面接入控制策略：

```
ADD MPACV6POLICY:POLICYNAME="policyV6",STEP=19,DESCRIPTION="a test desc";
```
