# 查询BGP对等体BFD检测（LST BGPPEERBFD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查看IPv4或IPv6对等体的BFD参数。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                            |
|:------------|:----------|:----------------------------------------------------------------------------------------------------------------|
| VRFNAME     | VPN实例名称   | 可选必选说明：可选参数 参数含义：该参数用于指定VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                                        |
| ADDRESSTYPE | 地址类型      | 可选必选说明：可选参数 参数含义：该参数用于指定对等体的地址类型。 数据来源：本端规划 取值范围：枚举类型。 ipv4：IPv4。ipv6：IPv6。 默认值：无                               |
| PEERADDR    | IPv4对等体地址 | 可选必选说明：条件可选参数 前提条件：该参数在“ADDRESSTYPE”配置为“ipv4”时为可选参数。 参数含义：该参数用于指定连接对等体的IPv4接口地址。 数据来源：对端协商 取值范围：IPv4地址类型。 默认值：无 |
| PEERADDRV6  | IPv6对等体地址 | 可选必选说明：条件可选参数 前提条件：该参数在“ADDRESSTYPE”配置为“ipv6”时为可选参数。 参数含义：该参数用于指定连接对等体的IPv6接口地址。 数据来源：对端协商 取值范围：IPv6地址类型。 默认值：无 |

#### 使用实例

- 查看名称为“vrf1”的BGP VPN实例下IPv4对等体10.2.2.2的BFD参数：

  ```
  LST BGPPEERBFD: VRFNAME="vrf1",ADDRESSTYPE=ipv4,PEERADDR="10.2.2.2";
  ```

  ```
  RETCODE = 0  操作成功。

  结果如下
  --------
             VPN实例名称  =  vrf1
                地址类型  =  IPv4
          IPv4对等体地址  =  10.2.2.2
       使能BFD Block功能  =  FALSE
            检测时间倍数  =  3
                 使能BFD  =  TRUE
  最小接收间隔时间（ms）  =  200
  最小发送间隔时间（ms）  =  200
            使能单跳模式  =  TRUE
  (结果个数 = 1)
  ---    END
  ```
- 查看名称为“vrf1”的BGP VPN实例下IPv6对等体2001:db8:1:1:1:1:1:1的BFD参数：

  ```
  LST BGPPEERBFD: VRFNAME="vrf1",ADDRESSTYPE=ipv6,PEERADDRV6="2001:db8:1:1:1:1:1:1";
  ```

  ```
  RETCODE = 0  操作成功。

  结果如下
  --------
             VPN实例名称  =  vrf1
                地址类型  =  IPv6
          IPv6对等体地址  =  2001:db8:1:1:1:1:1:1
       使能BFD Block功能  =  FALSE
            检测时间倍数  =  3
                 使能BFD  =  TRUE
  最小接收间隔时间（ms）  =  200
  最小发送间隔时间（ms）  =  200
            使能单跳模式  =  TRUE
  (结果个数 = 1)
  ---    END
  ```
