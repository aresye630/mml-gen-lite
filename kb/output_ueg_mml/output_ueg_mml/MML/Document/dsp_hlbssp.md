# 查询HLB未生效软参(DSP HLBSSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询HLB系统中未生效软参的信息，包括未生效软参名、未生效软参所属实例号、软参的修改值、生效值和默认值等信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询当前HLB服务中所有未生效的软参。

```
DSP HLBSSP:;
```

```
%%DSP HLBSSP:;%%
RETCODE = 0  操作成功

操作结果如下
------------
          实例号  =  539655151
          参数名  =  HLB数字证书CRL处理策略
          参数值  =  1
          生效值  =  0
  软件参数默认值  =  1 
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1。

| 输出项名称   | 输出项解释                                 |
|:--------|:--------------------------------------|
| 实例号     | 用于描述未生效软参所属实例的实例名称。 取值范围：长度不超过64的字符串。 |
| 参数名     | 用于描述未生效软参的软参名。 详细信息请参考产品手册的“HLB系统软参”  |
| 参数值     | 用于描述软参修改后的值。                          |
| 生效值     | 用于描述软参在HLB系统中生效的值。                    |
| 软件参数默认值 | 用于描述软参初始设定的值。                         |
