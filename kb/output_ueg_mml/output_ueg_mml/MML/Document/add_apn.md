## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响业务处理，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于在配置数据库中增加一条APN数据记录。

- 用于控制Gx/N7接口Revalidation-Time AVP/revalidationTime的下发：
  - 当对端PCEF支持IPSessRevalidation能力，且软参**VRM\_SESSIONCHECKINTERVAL**取值不为0时，若本命令中设置的APN与Gx会话的APN相同时，根据软参**VRM\_SESSIONCHECKINTERVAL**取值下发RevalidationTimeout事件和Revalidation-Time AVP。
  - 当软参**VRM\_SESSIONCHECKINTERVAL**取值不为0时，若命令中设置的APN与N7会话的APN相同时，根据软参**VRM\_SESSIONCHECKINTERVAL**取值下发RE\_TIMEOUT事件和revalidationTime。
- 在Multi-PCEF场景下，当命令**SET BINDCFG**的参数“IPv4Dnn”或“IPv6Dnn”设置为“支持”时，且**Multi-PCEF**和**Multi-Service APN**的License开启时，如果某对端不携带APN，可以使用此命令添加**Multi-PCEF-APN**类型APN进行绑定。
  - IP重复会话的APN不能配置在APN列表中，否则会带来绑定错误。
  - 单PCEF场景不需要配置APNList，可能导致处理出错。
- 在VoLTE场景下，若VoLTE业务配置该类型的APN，“APN”参数需要与该命令下的“APN名称”参数取值保持一致，则对VoLTE会话生效；若VoLTE业务没有配置该类型的APN，则对VoLTE会话不生效。

**说明** 

- 对端PCEF是否支持IPSessRevalidation能力，可通过执行**LST PCEFABIITEM**命令查询。
- 软参**VRM\_SESSIONCHECKINTERVAL**的取值，可通过执行**LST PCFINSP**命令查询。
- **SET BINDCFG**命令参数“IPv4Dnn”、“IPv6Dnn”的取值，可通过**LST BINDCFG**命令查询。
- License是否开启，可通过执行**DSP LICENSE**命令查询。

## 注意事项

- 在同一个APNID下的APNNAME不允许重复。
- **VRM\_VIRTUALSUBIDSWITCH**取值为“1”时，不建议增加VoLTE-APN类型的APN配置。如果要增加配置，则需要在配置后清理Session备份数据，启动会话备份数据审计。
- 当命令**SET BINDCFG**参数“IPv4PcefGroup”设置为“支持”时，且用户携带VoLTE-APN时，用户携带IP地址不能重复。

## 使用实例

1. 增加一条APN数据记录。“PCRF标识”为“1”，“APN标识”为“0”，“APN名称”为“CMIMS”，“APN类型”为“Revalidation-APN”，“APN匹配类型”为“FullMatching”。

   ```
   ADD APN: PCRFID=1, APNID=0, APNNAME="CMIMS", APNTYPE=Revalidation-APN, APNMATCHTYPE=FullMatching;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
