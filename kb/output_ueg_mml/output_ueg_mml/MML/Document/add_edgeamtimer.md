# 增加通用接入和移动扩展定时器（ADD EDGEAMTIMER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于增加一个通用接入和移动扩展定时器。

## 注意事项

- 该命令执行后立即生效。

- 本命令配置时，PDUSessionCreate消息的超时时长采用本命令配置的TIMER参数值，否则采用SET HTTPCONF命令中的CLIENTRCVRSPTMT参数值。

- 最多可输入8条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                                                                                                                                                |
|:-----------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PNFTYPE    | 对端NF类型  | 可选必选说明：必选参数  参数含义：该参数用于指定对端NF的类型。  数据来源：全网规划 取值范围： “SMF（SMF）”：NF类型为SMF  默认值：无  配置原则：无                                                                                                                               |
| SMFMSGTYPE | SMF消息类型 | 可选必选说明：该参数在"PNFTYPE"配置为"SMF"时为条件必选参数。  参数含义：当PNFTYPE取值为SMF时该参数必选，用于指定消息类型。  数据来源：全网规划 取值范围： “PDUSessionCreate（PDUSessionCreate）”：消息类型为PDU Session Create  默认值：无  配置原则：  SMF消息类型为PDUSessionCreate时，消息超时时间仅对5G用户激活生效。 |
| TIMER      | 消息超时时间  | 可选必选说明：必选参数  参数含义：该参数用于指定消息超时时长。  数据来源：全网规划  取值范围：整数类型，取值范围是1~20，单位是秒。  默认值：无  配置原则：无                                                                                                                               |

## 使用实例

假如运营商需要增加一个通用接入和移动扩展定时器，要求对端NF类型为SMF，消息类型为PDUSessionCreate，消息超时时间为12，执行如下命令：

```
ADD EDGEAMTIMER: PNFTYPE=SMF, SMFMSGTYPE=PDUSessionCreate, TIMER=12;
```
