# 增加L3VPN实例（ADD L3VPNINST）

- 命令功能

- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于创建L3VPN实例。

创建VPN可以使用户获得专用虚拟的网络。

专用：VPN网络与底层承载网络之间保持资源独立，即VPN资源不被网络中非该VPN的用户所使用；且VPN能够提供足够的安全保证，确保VPN内部信息不受外部侵扰。

虚拟：VPN用户内部的通信是通过公共网络进行的，而这个公共网络同时也可以被其他非VPN用户使用，VPN用户获得的只是一个逻辑意义上的专网。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为4096。
- 不能增加VPN实例 \_public\_、\_\_mpp\_vpn\_inner\_\_、\_\_mpp\_vpn\_inner\_server\_\_。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称    | 参数说明                                                                                        |
|:---------------|:--------|:--------------------------------------------------------------------------------------------|
| VRFNAME        | VPN实例名称 | 可选必选说明：必选参数 参数含义：该参数用于指定L3VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                  |
| VRFDESCRIPTION | VPN实例描述 | 可选必选说明：可选参数 参数含义：该参数用于描述L3VPN实例。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～242。 默认值：无 配置原则：可以带空格的描述性语句。 |

#### 使用实例

新建名称为“vrf1”的VPN实例：

```
ADD L3VPNINST: VRFNAME="vrf1", VRFDESCRIPTION="vpn for test";
```
