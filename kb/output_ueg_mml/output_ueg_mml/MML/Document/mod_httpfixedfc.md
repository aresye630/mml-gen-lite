# 修改HTTP流控组固定速率流控信息（MOD HTTPFIXEDFC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令中是否携带Retry-After消息头参数可能会导致对端网元不发请求消息，需慎用。

该命令用于修改HTTP固定速率流控门限值信息。

## 注意事项

- 该命令执行后立即生效。

- 流控阈值不支持修改为零，如果涉及流控模式的切换，支持在原有模式基础上新增流控模式，不支持删除原有模式基础上新增流控模式。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称               | 参数说明                                                                                                                                                                                                                                                                                                                                                                          |
|:---------------|:-------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GROUP          | 流控组                | 可选必选说明：必选参数  参数含义：该参数用于指定HTTP固定速率流控组的唯一标识。该参数来源于ADD HTTPFCIPGRP命令的“流控组”参数，可通过LST HTTPFCIPGRP命令查询获取。  数据来源：全网规划  取值范围：整数类型，取值范围是0~4095。  默认值：无  配置原则：无                                                                                                                                                                                                                         |
| SENDTHD        | 单链路发送消息流控门限(条/秒)   | 可选必选说明：可选参数  参数含义：该参数用于指定发送消息流控门限。该门限按HTTP链路粒度设置。  数据来源：全网规划  取值范围：整数类型，取值范围是1~1000000。  默认值：无  配置原则：  该参数在本端发送请求时生效。门限值由对端网元的消息处理能力决定。设置过低会导致消息被丢弃，设置过高起不到保护对端网元不过载的作用。                                                                                                                                                                                                      |
| RECVTHD        | 单链路接收消息流控门限(条/秒)   | 可选必选说明：可选参数  参数含义：该参数用于指定接收消息流控门限。该门限按HTTP链路粒度设置。  数据来源：全网规划  取值范围：整数类型，取值范围是1~1000000。  默认值：无  配置原则：  该参数在本端接收请求时生效。门限值由本端网元的消息处理能力决定。设置过低会导致消息被丢弃，设置过高起不到保护本端网元不过载的作用。                                                                                                                                                                                                      |
| GLBSENDTHD     | 整系统发送消息流控门限(条/秒)   | 可选必选说明：可选参数  参数含义：该参数用于指定发送消息流控门限。该门限按网元整系统粒度设置。  数据来源：全网规划  取值范围：整数类型，取值范围是1~4294967295。  默认值：无  配置原则：  该参数在本端发送请求时生效。门限值由对端网元的消息处理能力决定。设置过低会导致消息被丢弃，设置过高起不到保护对端网元不过载的作用。                                                                                                                                                                                                    |
| GLBRECVTHD     | 整系统接收消息流控门限(条/秒)   | 可选必选说明：可选参数  参数含义：该参数用于指定接收消息流控门限。该门限按网元整系统粒度设置。  数据来源：全网规划  取值范围：整数类型，取值范围是1~4294967295。  默认值：无  配置原则：  该参数在本端接收请求时生效。门限值由本端网元的消息处理能力决定。设置过低会导致消息被丢弃，设置过高起不到保护本端网元不过载的作用。                                                                                                                                                                                                    |
| STATUSCODE     | 状态码                | 可选必选说明：可选参数  参数含义：该参数用于指定接收消息速率超过流控门限时，给对端网元响应的HTTP消息中的Status Code。该参数可以和“是否携带Retry-After消息头”参数配合使用，告知对端本端的过载情况的同时携带Retry-After来指示对端多久后再发送请求。  数据来源：全网规划 取值范围： “TooManyRequests（Too Many Requests）”：当NF服务生产者检测到给定NF服务消费者发送过多的流量时，可以发送该状态代码告知NF服务消费者生产者端即将过载。“ServiceUnavailable（Service Unavailable）”：当NF服务生产者检测到给定NF服务消费者发送过多的流量时，可以发送该状态代码告知NF服务消费者生产者端已经过载。  默认值：无  配置原则：无 |
| RETRYAFTERFLAG | 是否携带Retry-After消息头 | 可选必选说明：可选参数  参数含义：该参数用于指定接收消息速率超过流控门限时，给对端网元响应的HTTP消息中是否携带Retry-After消息头。该参数可以和“状态码”参数配合使用，告知对端本端的过载情况的同时携带Retry-After来指示对端多久后再发送请求。  数据来源：全网规划 取值范围： “YES（YES）”：携带Retry-After消息头“NO（NO）”：不携带Retry-After消息头  默认值：无  配置原则：  携带Retry-After消息头可能会使对端网元不发请求消息给本端网元，导致业务受损。需谨慎使用该参数。如需设置Retry-After消息头，请联系华为技术支持。                                                                  |
| TIMER          | Retry-After时长(秒)   | 可选必选说明：该参数在"RETRYAFTERFLAG"配置为"YES"时为条件可选参数。  参数含义：该参数用于指定Retry-After的时长。  数据来源：全网规划  取值范围：整数类型，取值范围是0~3600。  默认值：无  配置原则：无                                                                                                                                                                                                                                                   |
| DESC           | 描述                 | 可选必选说明：可选参数  参数含义：该参数由于填写流控的描述信息，建议包含NF类型，实例名等，例如UDM_UDM001。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无                                                                                                                                                                                                                                                              |

## 使用实例

修改HTTP单链路粒度固定速率流控门限值，将发送消息流控门限从1000改为100：

```
MOD HTTPFIXEDFC: GROUP=1, SENDTHD=100;
```
