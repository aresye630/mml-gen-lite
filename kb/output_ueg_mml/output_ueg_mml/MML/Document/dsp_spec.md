#### 命令功能

**适用网元：SGSN、MME**

本命令用于查询USN\_SP\_RU、SPP/SGP/GBP/UPP进程的业务规格。查询结果为由于内存资源限制而允许接入的业务最大数量。

#### 注意事项

具体局点单个RU、进程的业务接入能力，还受限于License、话务模型等因素，可能达不到此命令显示的规格数量。

接入USN\_SP\_RU、SPP进程的2G/3G PDP和4G承载共享内存资源。USN\_SP\_RU、SPP进程能够接入的2G/3G PDP和4G承载总量不超过其4G承载规格。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                          |
|:------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SPECTYPE    | 输入信息   | 可选必选说明：可选参数 参数含义：按RU或者进程显示信息。 数据来源：本端规划 取值范围：枚举类型。RU(RU)。PROC(PROC)：进程。 默认值：RU(RU)                                                                            |
| SERVICETYPE | 服务名称   | 可选必选说明：必选参数 参数含义：本参数用于指定服务名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。数字“0~9”，大写字母“A~Z”，小写字母“a~z”，特殊字符“-”，“_”，其他均为非法字符，并且首字符必须为字母。 默认值：无  说明： 该参数可以通过LST VNFC命令查询得到。 |

#### 使用实例

查询USN\_SP\_RU的业务规格信息：

DSP SPEC: SERVICETYPE="USN\_VNFC";

```
%%DSP SPEC: SERVICETYPE="USN_VNFC";%%
RETCODE = 0 操作成功。

查询结果如下
------------------------
查询结果 =
		RU information
		RU type:          USN_SP_RU
		user size:        200000
		2G/3G PDP size:   200000
		4G size:          600000

（结果个数 = 1）
---    END
```

#### 输出结果说明

| 输出项名称          | 输出项解释            |
|:---------------|:-----------------|
| RU type        | 信息所属RU的类型。       |
| process type   | 信息所属进程的类型。       |
| user size      | 支持的用户数规格。        |
| 2G/3G PDP size | 支持的2G/3G PDP数规格。 |
| 4G size        | 支持的4G承载数规格。      |
| eNodeB size    | 支持的eNodeB数规格。    |
