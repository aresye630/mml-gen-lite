# 设置对Gy接口的cea消息中的Origin-Host检查开关（SET CEAORIGHOSTCHK）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

为了实现某运营商的特定需求。该命令用于配置Diameter对Gy接口的cea消息中的Origin-Host检查开关。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | CEAORIGHOSTCHK   |
|:-------|:-----------------|
| 初始值    | ENABLE           |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称                    | 参数说明                                                                                                         |
|:---------------|:------------------------|:-------------------------------------------------------------------------------------------------------------|
| CEAORIGHOSTCHK | 检查Gy的CEA消息中的Origin-Host | 可选必选说明：可选参数 参数含义：该参数用于配置UNC是否检查Gy接口CEA消息中的Origin-Host。 数据来源：本端规划 取值范围：枚举类型。 ENABLE：是。DISABLE：否。 默认值：无 配置原则：无 |

#### 使用实例

配置Diameter对Gy接口的cea消息中的Origin-Host检查开关，则可按如下配置：

```
SET CEAORIGHOSTCHK:CEAORIGHOSTCHK=DISABLE;
```
