# 增加通知服务对端服务器(ADD NTSPEER)

## 命令功能

该命令用于在配置数据库中增加一条通知任务服务对端服务器的数据记录。

使用场景：

UPCF支持在特定场景（例如用户流量达到阈值、配额充值）给用户发送通知，提醒用户当前业务的使用状态；或将通知发送到第三方服务器上，由第三方服务器决定后续的处理。

- 与短消息中心对接，可以通过短消息中心发送短信通知给终端用户。
- 与邮件服务器对接，可以通过邮件服务器发送邮件通知给终端用户。
- 与SOAP服务器对接，可以发送SOAP通知到SOAP服务器上，由SOAP服务器决定后续的处理（如以短信、邮件或PUSH通知方式通知给终端用户）。

通知发送前配置UPCF与对端的对接数据为必选操作之一。需执行本命令增加UPCF负责通知任务服务（NTS）的对端服务器类型，如SMS协议，通过指定“对端服务器类型”参数来实现。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                           |
|:---------|:--------|:-------------------------------------------------------------------------------------------------------------------------------|
| PEERID   | 对端服务器ID | 可选必选说明：必选参数 参数含义：用于标识一条通知任务服务对端服务器的数据记录。 取值范围：1～255 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。                                          |
| PEERNAME | 对端服务器名称 | 可选必选说明：必选参数 参数含义：用于具体描述一个通知任务服务对端服务器的名称，以便于识别。值域类型为字符串，区分大小写。 取值范围：长度不超过128的字符串 默认值：无。 配置原则： 运营商统一规划，本端须与对端服务协商配置。对端服务器名称不能重复。 |
| PEERTYPE | 对端服务器类型 | 可选必选说明：必选参数 参数含义：用于标识通知任务服务对端服务器的应用类型。 取值范围： SMS(SMS协议)E-MAIL(E-MAIL协议)SOAP(SOAP协议) 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。          |

## 使用实例

增加一个SMS类型的通知任务服务对端服务器。“对端服务器ID”为“1”，“对端服务器名称”为“NTSSMS1”，“对端服务器类型”为“SMS(SMS协议)”。

```
ADD NTSPEER: PEERID=1, PEERNAME="NTSSMS1", PEERTYPE=SMS;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释         | 原因分析             | 处理建议                                                                                        |
|------:|:--------------|:-----------------|:--------------------------------------------------------------------------------------------|
| 57822 | 对端服务器名称已经被使用。 | 输入的“对端服务器名称”已存在。 | 执行LST NTSPEER命令查询全部通知任务服务对端服务器配置信息，记录已存在的对端服务器名称。 执行本命令，重新设置“对端服务器名称”，并确保和已存在的“对端服务器名称”不相同。 |
