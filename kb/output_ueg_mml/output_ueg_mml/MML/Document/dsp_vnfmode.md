# 查询VNF部署模式（DSP VNFMODE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询VNF部署模式。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组

## 参数说明

无

## 使用实例

查询VNF部署模式。

```
%%DSP VNFMODE:;%%
RETCODE = 0  操作成功

结果如下
------------------------
VNF容器模式  =  VM_CONTAINER
裸机部署模式  =  DomainHost
Vnfm接口模式 =  stack
附加模式     =  0
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称    | 输出项解释                                                                                    |
|:---------|:-----------------------------------------------------------------------------------------|
| VNF容器模式  | 该参数表示VNF的容器模式。 取值说明： - "VM_CONTAINER"：虚机容器。 - "BARE_CONTAINER"：裸机容器。                     |
| 裸机部署模式   | 该参数表示VNF的裸机部署模式。 取值说明： - "ResourceBoxHost"：ResourceBoxHost部署模式。 - "DomainHost"：历史裸机部署模式。 |
| Vnfm接口模式 | 该参数表示Vnfm接口模式。 取值说明： - "stack"：历史stack接口模式。 - "release"：release接口模式。                     |
| 附加模式     | 该参数表示附加模式。                                                                               |
