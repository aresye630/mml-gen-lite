# 获取日志文件(GET LOGFILE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于获取业务虚拟机（裸机Pod）上指定类别的日志文件。

通用场景下，此命令由网管侧的信息收集自动触发，无需手动执行。

**说明** 

- 基于兼容性考虑，执行本命令收集的日志，UPCF会通过普通的Socket连接方式与SFTP服务器建链并上传。
- 执行本命令前，需要将VRM\_PMSSFTPCLIENTACSWITCH（PMS SFTP客户端算法兼容开关）软参打开设置为“1”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称          | 参数说明                                                                                                                                                                      |
|:-------|:--------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TYPE   | 信息类型          | 可选必选说明：必选参数 参数含义：用于标识需要获取的日志文件类型。 取值范围： ALL(所有信息) ：所有日志，包括CLI日志、HTTP日志和信息导入日志。CLI_LOG(CLI日志)：CLI日志。HTTP_LOG(HTTP日志)：HTTP日志。INFOIMPORT_LOG(信息导入日志)：信息导入日志。 默认值：无。 配置原则：无。  |
| ST     | 起始时间          | 可选必选说明：可选参数 参数含义：用于指定开始获取文件的时间。 取值范围：YYYY&MM&DD&HH&MM&SS，1970&01&01&00&00&00～系统当前时间 默认值：无。 配置原则：无。                                                                        |
| DAYS   | 天数            | 可选必选说明：可选参数 参数含义：用于指定从开始时间开始需要获取几天内的文件。 取值范围：1～366 默认值：无。 配置原则：无。                                                                                                         |
| DSTF   | 目的目录          | 可选必选说明：必选参数 参数含义：用于指定SFTP服务器上的目标文件路径，该参数不能为空。 取值范围：长度不超过256位的字符串。 默认值：无。 配置原则：该参数不能为空且参数中不能包含英文分号、英文反斜线、英文冒号、英文问号、英文引号、英文尖括号和英文星号。                                        |
| IPVER  | IP版本          | 可选必选说明：必选参数 参数含义：用于指定SFTP服务器地址。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：IP地址是SFTP传输时的重要参数，需要与SFTP服务器协商一致；若不一致，文件上传会失败。                                                     |
| IP     | SFTP服务器IPV4地址 | 可选必选说明：可选参数 参数含义：用于指定SFTP服务器IPV4地址，仅当“IP版本”设置为“IPV4(IPV4)”时，该参数有效。 取值范围：IPV4地址。 默认值：无。 配置原则：需要与SFTP服务器协商一致。                                                               |
| IPV6   | SFTP服务器IPV6地址 | 可选必选说明：可选参数 参数含义：用于指定SFTP服务器IPV6地址，仅当“IP版本”设置为“IPV6(IPV6)”时，该参数有效。 取值范围：IPV6地址。 默认值：无。 配置原则：需要与SFTP服务器协商一致。                                                               |
| USR    | SFTP用户名       | 可选必选说明：必选参数 参数含义：用于指定SFTP用户名。 取值范围：长度不超过32位的字符串。 默认值：无。 配置原则：用户名是SFTP传输时的重要参数，需要与SFTP服务器协商一致；若不一致，文件上传会失败。                                                                |
| PWD    | SFTP密码        | 可选必选说明：必选参数 参数含义：用于指定SFTP密码。 取值范围：长度不超过32位的字符串。 默认值：无。 配置原则： 密码是SFTP传输时的重要参数，需要与SFTP服务器协商一致；若不一致，文件上传会失败。密码不能为空。密码中不能含如下字符串：“%%”、“+++”。密码中不能包含英文分号、英文双引号和英文反斜杠。密码中不能包含空格。 |

## 使用实例

获取虚拟机（裸机Pod）上的进程CLI日志文件。

```
%%GET LOGFILE: TYPE=CLI_LOG, ST=2020&01&20&16&05&01, DAYS=2, DSTF="/pmslog", IPVER=IPV4, IP="10.194.4.130", USR="user", PWD="*****";%%
```
