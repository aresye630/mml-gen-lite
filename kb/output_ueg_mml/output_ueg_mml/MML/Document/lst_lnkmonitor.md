# 查询链路频繁闪断监控配置（LST LNKMONITOR）

#### 命令功能

**适用网元：SGSN、MME**

本命令用于查询链路频繁闪断监控功能的参数配置。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                             |
|:--------|:-------|:-----------------------------------------------------------------|
| LNKTYPE | 链路类型   | 可选必选说明：可选参数 参数含义：本参数用于指定待查询的链路类型。 数据来源：本端规划 取值范围：“S1AP(S1AP 链路)” |

#### 使用实例

查询“链路类型”为“S1AP(S1AP 链路)”时，链路频繁闪断的监控和告警上报的参数配置：

`LST LNKMONITOR: LNKTYPE=S1AP;`

```
%%LST LNKMONITOR: LNKTYPE=S1AP;%%
RETCODE = 0  操作成功。

操作结果如下
------------
瞬间闪断监控开关  =  开启
   统计时长（s）  =  60
        统计门限  =  50
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见**SET LNKMONITOR**的参数说明。
