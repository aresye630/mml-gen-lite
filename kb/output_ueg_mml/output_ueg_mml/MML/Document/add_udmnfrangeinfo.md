## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成号段信息不一致，从而导致业务失败，MML批处理时会造成CPU波动，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于增加一个网元的号段信息。该命令可用于指定服务注册信息NFProfile中的udrInfo、udmInfo的supiRanges、gpsiRanges、externalGroupIdentifiersRanges，ausfInfo、pcfInfo的supiRanges，当系统向NRF发起服务注册时使用此数据。

该命令的参数索引关系如图1所示。

**图1** 命令参数的索引关系图

**说明** 

- 当前版本不支持为UDM、AUSF网元增加“GPSI号段组”和“外部组标识范围组”配置信息。
- 当前版本不支持为5G-EIR网元增加“外部组标识范围组”配置信息。

## 注意事项

- “开始”和“结束”参数的组合与“模式”参数有且只能配置一个。
- 当配置“开始”和“结束”参数时，参数取值的长度应保持一致。
- 当“CheckNumSegOverlap(NRF号段重叠检查)”软参取值为“1”时，输入的“开始”和“结束”对应的号段，不能和本号段组已添加的号段有重叠。
- 相同“组名称”，“号段类型”必须相同。
- 添加数据成功，如果指定“组名称”已在**ADD UDMNFINFO**的“SUPI号段组”、“GPSI号段组”或“外部组标识范围组”中引用，且**ADD UDMNFINFO**的“网元信息标识”在**ADD UDMNFSRV**命令的“网元信息标识”中引用，且**ADD UDMNFSRV**命令中的“网元状态”为“REGISTERED”时，将按照**ADD UDMNFSRV**命令中“更新方式”参数中指定的更新模式立即向NRF发送更新请求。
- 最多增加100000条网元号段信息，且每个组最多添加40960个实例数。
- 当凌晨自动校验或执行**VRY NRFDATA**命令手动校验NRFClient内存数据时，在校验该MML命令的过程中，无法执行该命令，若运行该命令，则提示“360155 该MML数据正在校验中，请稍后再试”。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                     |
|:-----------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GRPNAME    | 组名称    | 可选必选说明：必选参数 参数含义：用于标识一个网元号段信息所属组的信息。 取值范围：长度不超过32的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则： 若该“组名称”不存在，则创建该组名称。该参数和“索引”参数组成全局唯一对象关键字段。                                                                                                                                                                  |
| INDEX      | 索引     | 可选必选说明：必选参数 参数含义：用于标识一个网元号段信息数据记录的索引。 取值范围：1~100000。 默认值：无。 配置原则：该参数和“组名称”参数组成全局唯一对象关键字段。                                                                                                                                                                                                                |
| RANGETYPE  | 号段类型   | 可选必选说明：必选参数 参数含义：用于标识一个网元号段信息的类型。 取值范围： SUPI(用户永久标识)GPSI(通用公共用户标识)EXGROUP(外部组) 默认值：无。 配置原则：无。                                                                                                                                                                                                            |
| STARTVALUE | 开始     | 可选必选说明：可选参数 参数含义：用于指定号段起始的SUPI或GPSI，该参数取值为组成SUPI的IMSI字符串或GPSI的MSISDN字符串。 取值范围：5~15位的十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                          |
| ENDVALUE   | 结束     | 可选必选说明：可选参数 参数含义：用于指定号段结束的SUPI或GPSI，该参数取值为组成SUPI的IMSI字符串或GPSI的MSISDN字符串。 取值范围：5~15位的十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                          |
| PATTERN    | 模式     | 可选必选说明：可选参数 参数含义：用于指定号段的正则表达式。正则表达式以“^imsi-”开始，以$结尾，正则表达式包含3个字段以标识连续号段，第一个字段表示连续号段的前几位的固定取值。第二个字段标识连续号段后几位的每位的取值，此字段以“[”和“]”为开始和结尾。第三个字段用以标识连续号段后几位的位数，此字段以“{”和“}”为开始和结尾。 例如输入“模式”参数为：“^imsi-12345678904[0-9]{4}$”，则表示123456789040000~123456789049999的所有号段 取值范围：长度不超过128的字符串 默认值：无。 配置原则：“模式”参数需符合正则表达式。 |

## 使用实例

1. 在开局场景下配置本局数据时，增加一个网元号段信息。“组名称”为“supi-group-01”，“索引”为“1”，“号段类型”为“SUPI”，“开始”为“123456789040000”，“结束”为“123456789059999”：

   ```
   ADD UDMNFRANGEINFO: GRPNAME="supi-group-01", INDEX=1, RANGETYPE=SUPI, STARTVALUE="123456789040000", ENDVALUE="123456789059999";
   ```
2. 在开局场景下配置本局数据时，增加一个网元号段信息。“组名称”为“supi-group-02”，“索引”为“2”，“号段类型”为“SUPI”，“模式”为“^imsi-12345678904[0-9]{4}$”：

   ```
   ADD UDMNFRANGEINFO: GRPNAME="supi-group-02", INDEX=2, RANGETYPE=SUPI, PATTERN="^imsi-12345678904[0-9]{4}$";
   ```
