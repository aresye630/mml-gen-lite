# 显示UDM各种存储模式用户数(DSP USERSTORAGECT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于请求显示数据库中不同鉴权数据的存储模式下的用户数目。

## 注意事项

无。

## 参数说明

无。

## 使用实例

显示数据库中不同鉴权数据的存储模式下的用户数目。

```
DSP USERSTORAGECT:;
```

```
%%DSP USERSTORAGECT:;%%
RETCODE = 0  操作成功
结果如下
--------
用户模式  用户数  
模式1     0       
模式2     0       
模式3     0       
模式4     0       
模式5     0       
模式6     0       
模式7     0       
模式8     0       
模式9     0       
模式10    0       
模式11    0       
模式12    0       
模式13    0       
模式14    0       
模式15    0       
模式16    0       
(结果个数 = 16)
---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                    |
|:--------|:-------------------------|
| 用户模式    | 用于返回不同鉴权用户数据下的存储模式。      |
| 用户数     | 用于返回不同鉴权用户数据的存储模式对应的用户数。 |
