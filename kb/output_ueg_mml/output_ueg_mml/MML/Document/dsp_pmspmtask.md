# 查询策略管理服务PmCLI任务信息(DSP PMSPMTASK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询UPCF的策略管理服务PmCLI任务（即UPCF通过Pm接口获取CLI脚本）中策略文件的执行信息。

## 注意事项

如果PmCLI任务中存在“状态”不为“End”的策略文件，则不允许通过营帐系统进行业务发放。

## 参数说明

无。

## 使用实例

查询PmCLI任务信息，执行命令如下：

```
DSP PMSPMTASK:;
```

```
%%DSP PMSPMTASK:;%%
RETCODE = 0  操作成功

操作结果如下:
------------
  文件名  =  12345010100000000000000000000000_Shanghai_HW_20200618114454.txt
 Pod标识  =  pcf-addn-pod217-5cb799b7f-gjc5f 
开始时间  =  2020-07-16 19:34:28
结束时间  =  2020-07-16 19:34:28
    状态  =  End
(结果个数 = 1) 

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义如表1。

| 输出项名称   | 输出项解释                                                                                                                                                                                                        |
|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 文件名     | 用于显示PmCLI任务中执行的策略文件名称。 取值范围：长度不超过128的字符串。                                                                                                                                                                    |
| Pod标识   | 用于显示PmCLI任务中执行的策略文件的Pod标识。 取值范围：长度不超过64的字符串。                                                                                                                                                                 |
| 开始时间    | 用于显示PmCLI任务中执行策略文件的开始时间，显示格式为：yyyy-mm-dd hh:mm:ss。当任务执行的“状态”为“Waiting”时，显示为空。                                                                                                                                |
| 结束时间    | 用于显示PmCLI任务中执行策略文件的结束时间，显示格式为：yyyy-mm-dd hh:mm:ss。当任务执行的“状态”为“Waiting”或“Running”时，显示为空。                                                                                                                      |
| 状态      | 用于显示PmCLI任务中策略文件的执行状态。 取值说明：End：表示文件执行完毕，包括命令全部执行成功和命令部分执行失败但回滚成功。Running：表示文件正在执行中。Waiting：表示文件待执行。Abnormal：表示文件执行异常。包含如下三种情况：文件下载失败，未被执行。文件内容超过500行，未被执行。处于“Running”或“Waiting”执行状态的文件，因PMS重启导致文件被执行或未执行完毕。 |
