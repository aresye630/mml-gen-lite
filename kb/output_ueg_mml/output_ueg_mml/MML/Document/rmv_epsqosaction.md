# 删除EPS QoS控制动作配置（RMV EPSQOSACTION）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C**

该命令用于删除4G用户QoS上下行保证带宽门限、最高带宽门限以及带宽超过门限值时对QoS用户的处理动作。

## 注意事项

命令执行后只对新接入用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称         | 参数说明                                                                                                                                            |
|:---------------|:-------------|:------------------------------------------------------------------------------------------------------------------------------------------------|
| QOSPROFILENAME | QoS Profile名 | 可选必选说明：必选参数  参数含义：该参数用于指定QoS Profile的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。不区分大小写。  默认值：无  配置原则：  该参数需要先通过ADD QOSPROFILE或者SET CPQOSGLOBAL命令配置。 |
| QCI            | QCI值         | 可选必选说明：必选参数  参数含义：该参数表示QoS流量级别。  数据来源：全网规划  取值范围：整数类型，取值范围是1~255。  默认值：无  配置原则：无                                                                |

## 使用实例

删除“QOSPROFILENAME”为“test”，“QCI”为“2”的上下行保证带宽门限、最高带宽门限以及带宽超过门限值时对QoS用户的处理动作：

```
RMV EPSQOSACTION:QOSPROFILENAME="test",QCI=2;
```
