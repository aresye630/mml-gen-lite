# 添加链路告警过滤黑白名单(ADD LNKALMBWADDRLST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于配置客户端动态链路告警过滤黑白名单记录。当“LinkAlmFilterMode(链路告警过滤方式)”软参开启时，按照本命令配置的黑白名单中的IP过滤“18407 HTTP客户端链接故障”和“18704 客户端链路亚健康”告警。

## 注意事项

本命令最多可以配置512条客户端动态链路告警过滤黑白名单记录。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                       |
|:-----------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FILTERNAME | 过滤器名称    | 可选必选说明：必选参数 参数含义：用于指定一条客户端动态链路告警过滤黑白名单记录的名称，它唯一标识一条客户端动态链路告警过滤记录。 取值范围：长度不超过128位的字符串，只允许输入：0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。                                             |
| IPVER      | IP地址类型   | 可选必选说明：必选参数 参数含义：用于指定客户端IP地址类型。 取值范围：IPV4(IPV4)：IPv4地址格式，需要过滤的IP地址类型为IPv4时使用。IPV6(IPV6)：IPv6地址格式，需要过滤的IP地址类型为IPv6时使用。 默认值：无。 配置原则：无。                                       |
| IPV4ADDR   | IPV4地址   | 可选必选说明：条件必选参数 参数含义：用于指定一个IPv4格式的客户端IP地址。 取值范围：IPv4地址。 默认值：无。 配置原则：仅当“IP地址类型”为“IPV4(IPV4)”时，该参数有效。                                                                          |
| MASKV4     | IPV4掩码   | 可选必选说明：条件可选参数 参数含义：用于指定IPv4格式的客户端地址所使用的子网掩码位数。 取值范围：1~32 默认值：32 配置原则：仅当“IP地址类型”为“IPV4(IPV4)”时，该参数有效。如果配置的IPv4掩码位数是32，则代表一条客户端IP地址记录。如果配置IPv4掩码位数是1～31，则代表一个客户端IP地址网段。      |
| IPV6ADDR   | IPV6地址   | 可选必选说明：条件必选参数 参数含义：用于指定一个IPv6格式的客户端地址。 取值范围：IPv6地址。 默认值：无。 配置原则：仅当“IP地址类型”为“IPV6(IPV6)”时，该参数有效。                                                                            |
| MASKV6     | IPV6前缀长度 | 可选必选说明：条件可选参数 参数含义：用于指定IPv6格式的客户端地址所使用的IPv6前缀长度。 取值范围：1~128 默认值：128 配置原则：仅当“IP地址类型”为“IPV6(IPV6)”时，该参数有效。如果配置IPv6前缀长度是128，则代表一条客户端IP地址记录。如果配置IPv6前缀长度是1～127，则代表一个客户端IP地址网段。 |
| FLAG       | 操作类型     | 可选必选说明：必选参数 参数含义：用于指定配置的IP地址所属的操作类型。 取值范围：WHITELIST(白名单)：允许上报告警的IP地址或地址网段的列表。BLACKLIST(黑名单)：禁止上报告警的IP地址或地址网段的列表。 默认值：无。 配置原则：无。                                            |

## 使用实例

通过本命令配置允许上报“18407 HTTP客户端链接故障”和“18704 客户端链路亚健康”告警的IP地址列表，其中“过滤器名称”为“file01”、“IP地址类型”为“IPV4(IPV4)”、“IPV4地址”为“10.144.118.1”、“IPV4掩码”为“24”、“操作类型”为“WHITELIST(白名单)”:

```
ADD LNKALMBWADDRLST: FILTERNAME="file01", IPVER=IPV4, IPV4ADDR="10.144.118.1", MASKV4=24, FLAG=WHITELIST;
```
