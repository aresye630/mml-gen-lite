# 删除接口IPv4借用地址（RMV IFIPV4UNNUMIPSEC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于去配置接口的借用IPv4地址。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                              |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------|
| IFNAME | 接口名    | 可选必选说明：必选参数  参数含义：该参数用于指定接口名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。接口名称由接口类型+接口编号组成。  默认值：无  配置原则：  请使用LST INTERFACEIPSEC命令查看可用接口。 |

## 使用实例

删除tunnel口借用的IPv4地址：

```
RMV IFIPV4UNNUMIPSEC:IFNAME="tunnel1";
```
