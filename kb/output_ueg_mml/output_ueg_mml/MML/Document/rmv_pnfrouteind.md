# 删除对端NF的路由指示信息（RMV PNFROUTEIND）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、NSSF、SMSF、NCG、NEF、NWDAF、SCF**

该命令用于删除本地配置对端NF实例支持的路由指示信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                               |
|:-------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCEID | NF实例标识 | 可选必选说明：必选参数  参数含义：该参数用于指定NF实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~36。NFINSTANCEID参数建议满足以下约束规则：1.如果输入为uuid格式（格式例如：a6a61c6f-0d3a-4221-b1da-424eda3ccf67）只能为A-F、a-f、0-9和“-”的字符。2.如果输入不为uuid格式，长度不能超过18且不允许输入只包含0-9和“.”的字符串，例如：1.2.3.4、不允许输入只包含十六进制数（A-F、a-f、0-9）和“:”的字符串，例如：1::2、FBFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。3.该参数大小写不敏感。  默认值：无  配置原则：  本参数取值与ADD PNFPROFILE命令中的“NF实例标识”参数取值保持一致时，关联关系生效。 |
| ROUTINGIND   | 路由指示   | 可选必选说明：必选参数  参数含义：该参数用于指定对端NF的路由指示信息。路由指示器是SUCI组成的一部分，用于使用SUCI进行AUSF和UDM的选择。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~4。取值范围0-9999。  默认值：无  配置原则：无                                                                                                                                                                                                                                                          |

## 使用实例

删除对端NF路由指示信息，NF实例标识为AUSF\_Instance\_0，路由指示信息为0001。

```
RMV PNFROUTEIND: NFINSTANCEID="AUSF_Instance_0", ROUTINGIND="0001";
```
