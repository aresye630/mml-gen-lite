# 设置SCP校验方式(SET SCPCHECK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于设置SCP校验方式。

该命令的使用场景：当PCF与SCP对接的场景下，可使用本命令设置SCP校验方法，用于判断接收到的NF消息是否经过SCP。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                                                                          |
|:-------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| METHOD | SCP校验方法 | 可选必选说明：必选参数 参数含义：用于设置SCP校验方法。 取值范围： IPADDRESS(IPADDRESS)：消息头域“Via”携带SCP的IP地址。FQDN(FQDN)：消息头域“Via”携带SCP的FQDN。INSTANCEID(INSTANCEID)：消息头域“Via”携带SCP的实例标识。 默认值：无。 配置原则：参数取值需要提前规划，与SCP协商一致。  说明： 同一时间只能存在一个参数取值。 |

## 使用实例

设置SCP校验方式，“SCP校验方法”为“FQDN(FQDN)”。

```
SET SCPCHECK: METHOD=FQDN;
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。
