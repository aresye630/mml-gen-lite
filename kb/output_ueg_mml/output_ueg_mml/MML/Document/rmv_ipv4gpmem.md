# 删除IPv4群组成员(RMV IPV4GPMEM)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于删除IP群组成员配置。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                                                                                                                                                                    |
|:--------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPGPID  | IP群组标识   | 可选必选说明：必选参数 参数含义：该参数用于指定IP群组标识。 前提条件：“IP群组标识”已经通过ADD IPGP配置。 数据来源：本端规划 取值范围：1-255 默认值：无                                                                                                                                                 |
| IPV4    | IPv4地址   | 可选必选说明：条件必选参数 参数含义：该参数用于指定IPv4地址。 数据来源：本端规划 取值范围：0.0.0.1～255.255.255.254 默认值：无  说明： “0.0.0.0”和“255.255.255.255”是无效的IP地址。 配置原则：IPv4地址不能为0.0.0.0、255.255.255.255和0.x.y.z。IPv4地址不能为组播地址（如：224.x.y.z）和环回地址（如：127.x.y.z）。IPv4地址必须是A、B或者C类地址。 |
| IPV4MSK | IPV4地址掩码 | 可选必选说明：条件必选参数 参数含义：该参数用于指定IPv4地址的掩码。 数据来源：全网规划 取值范围：0.0.0.1~255.255.255.255 默认值：无 配置原则：输入的掩码要求对应的二进制值1和1之间不允许存在0。例如：“255.255.0.0”是有效掩码；“123.123.123.123”是无效掩码。因为123对应的二进制为“1111011”，1之间存在0。                                             |

#### 使用实例

删除IPv4群组成员，IP群组标识为1，IP地址为172.22.5.50，IPV4地址掩码为255.255.255.0：

RMV IPV4GPMEM: IPGPID=1, IPV4="172.22.5.50", IPV4MSK="255.255.255.0";
