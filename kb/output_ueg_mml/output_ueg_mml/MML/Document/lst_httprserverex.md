# 查询远端服务器扩展配置(LST HTTPRSERVEREX)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询已配置的远端服务器扩展记录。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                 |
|:------------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
| RSERVERNAME | 远端服务器名称 | 可选必选说明：可选参数 参数含义：标识一个远端SSG服务器名称的关键字段，用于指定需要查询哪一个远端服务器名称的记录，不输入时表示查询所有远端服务器名称下的远端服务器扩展记录。 取值范围：长度不超过128的由数字和字母组成的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 |

## 使用实例

1. 查询所有远端服务器名称下的远端服务器扩展记录：

   ```
   LST HTTPRSERVEREX:;
   ```

   ```
   %%LST HTTPRSERVEREX:;%%
   RETCODE = 0  操作成功

   结果如下
   --------
   远端服务器名称  网元实例标识                          网元优先级  网元组名称  网元类型      全量域名         对端IP地址类型  对端IPv4地址    对端IPv6地址  对端端口号  

   ssg_1           11111111-1111-1111-1111-111111111111  1           001         信令安全网关  NULL             IPV4            192.168.91.105  NULL          8800        
   ssg_2           11111111-1111-1111-1111-111111111112  2           002         信令安全网关  udm1.huawei.com  NULL            NULL            NULL          8808        
   (结果个数 = 2)

   ---    END
   ```
2. 查询“远端服务器名称”为“ssg\_1”的配置记录：

   ```
   LST HTTPRSERVEREX: RSERVERNAME="ssg_1";
   ```

   ```
   %%LST HTTPRSERVEREX: RSERVERNAME="ssg_1";%%
   RETCODE = 0  操作成功

   结果如下
   --------
   远端服务器名称  =  ssg_1
     网元实例标识  =  11111111-1111-1111-1111-111111111111
       网元优先级  =  1
       网元组名称  =  001
         网元类型  =  信令安全网关
         全量域名  =  NULL
   对端IP地址类型  =  IPV4
     对端IPv4地址  =  192.168.91.105
     对端IPv6地址  =  NULL
       对端端口号  =  8800
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。参数含义请参见**ADD HTTPRSERVEREX**命令。
