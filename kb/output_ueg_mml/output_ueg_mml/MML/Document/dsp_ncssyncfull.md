# 显示全量同步操作的诊断信息（DSP NCSSYNCFULL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示全量同步操作的诊断信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

显示全量同步操作的诊断信息：

```
DSP NCSSYNCFULL:SERVICEINSTANCE="vnfc";
```

#### 输出结果说明

| 输出项名称               | 输出项解释                |
|:--------------------|:---------------------|
| 文件传输标识              | 全量同步文件的传输标识。         |
| 标志是否收到测试文件          | 是否收到测试文件的标识。         |
| 标志测试文件是否传输结束        | 测试文件是否传输结束的标识。       |
| 标志是否收到全量同步文件        | 是否收到全量同步文件的标识。       |
| 标志全量同步文件是否传输结束      | 全量同步文件是否传输结束的标识。     |
| 全量同步文件夹名称           | 全量同步文件所在文件夹的名称。      |
| 全量同步文件名称（文件大小，单位字节） | 全量同步文件的名称。           |
| 文件传输进度              | 全量同步文件的实际传输进度。       |
| 传输方法                | 全量同步文件的传输方法。         |
| 传输协议                | 全量同步文件的传输协议。         |
| 操作标识                | 全量同步文件的操作标识。         |
| 全量同步文件SHA1码         | 全量同步文件的SHA1码，该字段已失效。 |
| 流控ID                | 全量同步文件的流控标识。         |
