# 查询Channel数据（LST CHANNEL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示当前系统的Channel数据信息。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                         |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------------|
| APPTYPE  | 应用类型   | 可选必选说明：可选参数 用于标识Channel所属的FE应用类型。FE应用类型可通过LST APPTYPE查询。 取值范围：长度不超过128位的字符串。 默认值：无 配置原则：该参数取值必须与通过LST APPTYPE查询到的“应用类型”保持一致。 |
| DATATYPE | 数据类型   | 可选必选说明：可选参数 用于标识Channel分片所属的数据类型，将相同业务属性的数据归为一种数据类型。 取值范围： GLOBAL(全局数据)USER(用户数据)ROUTE(路由数据) 默认值：无 配置原则：无                    |
| SHARDID  | 分片ID   | 可选必选说明：可选参数 用于标识Channel所属的分片ID。 取值范围：0~65535 默认值：无 配置原则：无                                                                    |

## 使用实例

查询“应用类型”为“SUP-DUS”的Channel数据信息。

```
LST CHANNEL: APPTYPE="SUP-DUS", DATATYPE=USER, SHARDID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1的参数说明。

| 输出项名称     | 输出项解释                                                                                                                                                                                                                                            |
|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 应用类型      | 用于标识当前Channel所属的应用类型。                                                                                                                                                                                                                            |
| 数据类型      | 用于标识当前Channel分片所属的数据类型。                                                                                                                                                                                                                          |
| 分片ID      | 用于标识当前Channel中的分片标识。                                                                                                                                                                                                                             |
| 服务类型      | 用于标识当前服务的服务类型。                                                                                                                                                                                                                                   |
| 主DUS服务ID  | 标识当前分片的主服务实例。                                                                                                                                                                                                                                    |
| 备DUS服务ID  | 标识当前分片的备服务实例。                                                                                                                                                                                                                                    |
| 迁移服务ID    | 标识当前分片的迁移服务实例。“迁移服务ID”取值由“服务类型”+“主DUS服务ID”或“备DUS服务ID”拼接而成。例如： “服务类型”为十进制的“3013801540”，转换成十六进制“B3A2F644”。“主DUS服务ID”为十进制的“540396921”，转换成十六进制“2035CD79”。将十六进制的“B3A2F644”和“2035CD79”拼接为“B3A2F6442035CD79”，再转换成十进制“12944179051474832761”即为“迁移服务ID”取值。 |
| Channel状态 | 用于标识当前Channel的状态。                                                                                                                                                                                                                                |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释         | 原因分析               | 处理建议                                 |
|------:|:--------------|:-------------------|:-------------------------------------|
| 67822 | 指定的应用类型不存在    | 系统中没有该“应用类型”的数据信息。 | 执行LST APPTYPE命令查询到正确的“应用类型”后重新执行该命令。 |
| 67886 | 指定的数据类型的数据不存在 | 系统中没有该“数据类型”的数据信息。 | 执行LST APPTYPE命令查询到正确的“数据类型”后重新执行该命令。 |
| 67887 | 指定的分片ID的数据不存在 | 系统中没有该“分片ID”的数据信息。 | 执行LST APPTYPE命令查询到正确的“分片ID”后重新执行该命令。 |
