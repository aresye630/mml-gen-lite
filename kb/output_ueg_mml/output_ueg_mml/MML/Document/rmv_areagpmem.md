# 删除区域群成员(RMV AREAGPMEM)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

此命令用于删除区域群成员记录。

#### 注意事项

此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                          |
|:---------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AREAID   | 区域群标识   | 可选必选说明：必选参数 参数含义：待删除的区域群标识。 取值范围：1~50 默认值：无                                                                                                                                   |
| IDTYPE   | 标识类型    | 可选必选说明：必选参数 参数含义：待删除的区域的标识类型。 取值范围： “LA(位置区)”：表示该区域标识类型为位置区。“RA(路由区)”：表示该区域标识类型为路由区。“TA(跟踪区)”：表示该区域标识类型为跟踪区。 默认值：无  说明： 同一个“AREAID”下的“IDTYPE”必须相同。                            |
| MCC      | 移动国家码   | 可选必选说明：必选参数 参数含义：待删除的移动国家码。 取值范围：3位的十进制数字 默认值：无                                                                                                                               |
| MNC      | 移动网号    | 可选必选说明：必选参数 参数含义：待删除的移动网号。 取值范围：2~3位的十进制数字 默认值：无                                                                                                                              |
| LAC      | 位置区域码   | 可选必选说明：条件必选参数 参数含义：待删除的位置区域码。 前提条件：该参数在“IDTYPE(标识类型)”设置为“LA(位置区)”、“RA(路由区)”时生效。 取值范围：0x0000~0xFFFF 默认值：无                                                                      |
| LACRANGE | 位置区域码范围 | 可选必选说明：条件可选参数 参数含义：待删除的位置区域码范围。 前提条件：该参数在“IDTYPE(标识类型)”设置为“LA(位置区)”时生效。 取值范围：0x0000~0xFFFF 默认值：无  说明： 该参数的取值需要大于或等于“LAC”。该参数与“LAC”参数构成一个LAC区段，会删除包含该LAC区段的记录。如果不输入，表示配置单个LAC。 |
| RAC      | 路由区域码   | 可选必选说明：条件必选参数 参数含义：待删除的路由区域码。 前提条件：该参数在“IDTYPE(标识类型)”设置为“RA(路由区)”时生效。 取值范围：0x00~0xFF 默认值：无                                                                                    |
| RACRANGE | 路由区域码范围 | 可选必选说明：条件可选参数 参数含义：待删除的路由区域码范围。 前提条件：该参数在“IDTYPE(标识类型)”设置为“RA(路由区)”时生效。 取值范围：0x00~0xFF 默认值：无  说明： 该参数的取值需要大于或等于“RAC”。该参数与“RAC”参数构成一个RAC区段，会删除包含该RAC区段的记录。如果不输入，表示配置单个RAC。     |
| TAC      | 跟踪区域码   | 可选必选说明：条件必选参数 参数含义：待删除的跟踪区域码。 前提条件：该参数在“IDTYPE(标识类型)”设置为“TA(跟踪区)”时生效。 取值范围：0x0000~0xFFFF 默认值：无                                                                                |
| TACRANGE | 跟踪区域码范围 | 可选必选说明：条件可选参数 参数含义：待删除的跟踪区域码范围。 前提条件：该参数在“IDTYPE(标识类型)”设置为“TA(跟踪区)”时生效。 取值范围：0x0000~0xFFFF 默认值：无  说明： 该参数的取值需要大于或等于“TAC”。该参数与“TAC”参数构成一个TAC区段，会删除包含该TAC区段的记录。如果不输入，表示配置单个TAC。 |

#### 使用实例

删除一条区域群标识为1，标识类型为LA，移动国家码为111，移动网号为222，位置区域码为0x3333的区域群成员记录：

RMV AREAGPMEM: AREAID=1, IDTYPE=LA, MCC="111", MNC="222", LAC="0x3333";
