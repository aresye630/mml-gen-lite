# 查询NRF注册结果码（LST NRFREGRC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询NRF注册结果码信息。

- 如果需要查询全部NRF注册结果码，请不要输入任何参数。
- 如果需要查询指定NRF注册结果码，请输入参数“结果码”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                              |
|:-------|:-------|:--------------------------------------------------------------------------------------------------|
| RC     | 结果码    | 可选必选说明：可选参数 参数含义：用于指定系统需要按照哪个NRF注册结果码来查询；若不输入，则表示所有的NRF注册结果码。 取值范围：100～199，202～999 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询全部NRF注册结果码的配置信息。

   ```
   LST NRFREGRC:;
   ```

   ```
   %%LST NRFREGRC:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   结果码      

   150
   202
   (结果个数 = 2)

   ---    END
   ```
2. 查询指定NRF注册结果码，“结果码”为“202”。

   ```
   LST NRFREGRC: RC=202;
   ```

   ```
   %%LST NRFREGRC: RC=202;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   结果码  =  202
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见命令**ADD NRFREGRC**的参数说明。
