# 删除Home Group（RMV HOMEGROUP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

执行不当会导致系统异常。

**适用NF：PGW-C、GGSN**

该命令用于删除Home Group配置。

## 注意事项

- 该命令执行后立即生效。

- HOEMNGROUPINDX不输入时表示删除所有的记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称         | 参数说明                                                                                     |
|:--------------|:-------------|:-----------------------------------------------------------------------------------------|
| HOMEGROUPINDX | Home Group编号 | 可选必选说明：必选参数  参数含义：该参数用于设置Home Group的编号。  数据来源：本端规划  取值范围：整数类型，取值范围是1~128。  默认值：无  配置原则：无 |

## 使用实例

删除“Home Group编号”为“2”的Home Group配置：

```
RMV HOMEGROUP: HOMEGROUPINDX=2, CONFIRM=Y;
```
