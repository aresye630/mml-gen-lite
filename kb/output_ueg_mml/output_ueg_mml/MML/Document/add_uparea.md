# 增加UPF服务区（ADD UPAREA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、GGSN、SGW-C、PGW-C**

该命令用于增加UPF服务区域，并指定服务区域的名称与类型。后续指定UPF支持的服务范围时需要以本配置中的服务区域为粒度进行分配。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入49152条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                                   |
|:---------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
| AREANAME | UPF服务区名称 | 可选必选说明：必选参数  参数含义：该参数用于配置UPF服务区的名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~255。不支持空格，不区分大小写。  默认值：无  配置原则：  该参数取值应与LST PNFSMFSERAREA查询结果中的SMFSERVINGAREA保持一致。 |
| AREATYPE | UPF服务区类型 | 可选必选说明：必选参数  参数含义：该参数用于配置UPF服务区的类型。  数据来源：全网规划 取值范围： S1TAI（4G类型的TAI）N2TAI（5G类型的TAI）LAI（23G类型的LAI）  默认值：无  配置原则：无                                       |

## 使用实例

增加4G类型的UPF服务区：

```
ADD UPAREA: AREANAME="UPAREA1", AREATYPE=S1TAI;
```
