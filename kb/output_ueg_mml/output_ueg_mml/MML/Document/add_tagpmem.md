# 增加TA群组成员(ADD TAGPMEM)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

此命令用于为**ADD TAGP**增加的跟踪区群组添加一条成员记录。

#### 注意事项

- 此命令最大记录数为10000。
- 此命令执行后立即生效。
- 不同的跟踪区群组相互独立，同一个跟踪区群组下的各跟踪区域不能有重叠。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                  |
|:---------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TAGPID   | 跟踪区群组标识 | 可选必选说明：必选参数 参数含义：该参数用于指定跟踪区群组标识。 前提条件：“跟踪区群组标识”已经通过ADD TAGP配置。 数据来源：本端规划 取值范围：1~2048 默认值：无                                                                            |
| MCC      | 移动国家码   | 可选必选说明：必选参数 参数含义：该参数用于指定移动国家码。 数据来源：整网规划 取值范围：3位的十进制数字 默认值：无                                                                                                          |
| MNC      | 移动网号    | 可选必选说明：必选参数 参数含义：该参数用于指定移动网号。 数据来源：整网规划 取值范围：2～3位的十进制数字 默认值：无                                                                                                         |
| TAC      | 跟踪区域码   | 可选必选说明：必选参数 参数含义：该参数用于指定跟踪区域码。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无                                                                                                     |
| TACRANGE | 跟踪区域码范围 | 可选必选说明：可选参数 参数含义：该参数用于指定跟踪区域码范围。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无 配置原则：该参数的取值需要大于或等于“TAC（跟踪区域码）”。  说明： 该参数与“TAC（跟踪区域码）”参数构成一个TAC区段，方便维护人员配置连续的跟踪区域。如果不输入，表示配置单个TAC。 |

#### 使用实例

增加一个TA群组，跟踪区群组标识为1，其群组名称为“shanghai”，群组成员的移动国家码为456，移动网号为12，跟踪区域码为0x1234：

ADD TAGP: TAGPID=1, TANAME="shanghai";

ADD TAGPMEM: TAGPID=1, MCC="456", MNC="12", TAC="0x1234";
