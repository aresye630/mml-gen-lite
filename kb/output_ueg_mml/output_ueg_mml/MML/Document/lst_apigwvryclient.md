#### 命令功能

**适用NF：UPF、MPF**

该命令用于查询API GW是否校验对端证书。

#### 注意事项

- 该命令执行后立即生效。
- 该命令的查询结果仅适用于未配置反向代理的场景。当通过LST MEPREVERSEPROXY命令查询当前环境已配置反向代理时，LST APIGWVRYCLIENT命令的查询结果不具有参考意义。此时，校验对端证书功能开关以LST MEPTLSPARA中“校验对端证书”参数配置为准。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询API GW校验对端证书配置：

```
LST APIGWVRYCLIENT:;
```

```
RETCODE = 0 操作成功

API GW校验对端证书
-------------------
校验对端证书开关  =  使能
(结果个数 = 1)

---    END
```
