## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响业务处理，需联系华为技术支持确认后再执行。

用于设置Diameter接口的配置信息。

**说明** 

产品暂不支持该命令功能，预埋显示此命令。

## 注意事项

无。

## 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                                                                                            |
|:-------------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PEERTYPE     | 对端类型     | 可选必选说明：必选参数 参数含义：用于指定Diameter接口的对端类型。 取值范围：PCEF(PCEF)AF(AF)OCS(OCS)TDF(TDF)DRA(DRA) 默认值：无。 配置原则：无。                                                              |
| MSGINVRSTLNK | 消息非法重置开关 | 可选必选说明：可选参数 参数含义：用于控制设置Diameter接口的消息长度非法重置开关是否打开。若开关打开情况下，会对Diameter接口的非法消息长度进行拆链处理，反之开关关闭时不进行拆链处理。 取值范围：Disable：(关闭)Enable：(打开) 默认值：无。 系统初始设置值：Enable。 配置原则：无。 |

## 使用实例

设置Diameter接口的配置信息，“对端类型”为“PCEF”，“消息非法重置开关”为“Enable”。

```
SET DIAMCFG: PEERTYPE=PCEF, MSGINVRSTLNK=Enable;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
