# 查询ND黑匣子信息（DSP NDBLACKBOX）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询ND的黑匣子记录的信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称         | 参数说明                                                                                                                                                      |
|:-------|:-------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
| TYPE   | IPv6 ND黑匣子类型 | 可选必选说明：必选参数 参数含义：该参数指定IPv6 ND黑匣子类型。 数据来源：本端规划 取值范围：枚举类型。 COMP：黑匣子组件信息。HA：黑匣子HA状态信息。PIPE：黑匣子组件管道信息。PACKET：黑匣子组件包信息。ASSERT：黑匣子组件异常信息。MSG：黑匣子组件消息记录信息。 默认值：无 |
| PID    | ND PID       | 可选必选说明：必选参数 参数含义：该参数用来指定ND组件PID。 数据来源：本端规划 取值范围：十六进制整数类型，取值范围为0x0～0xFFFFFFFF。 默认值：无                                                                       |
