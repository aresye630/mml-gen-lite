# 查询SSO链路(LST SSOLINK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询SSO链路的配置信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                 |
|:-------|:-------|:-------------------------------------------------------------------------------------|
| LINKID | 链路ID   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个链路ID来查询SSO链路配置信息；若不输入，则表示所有的链路ID。 取值范围：1 默认值：无。 配置原则：无。 |

## 使用实例

查询SSO链路的配置信息。

```
LST SSOLINK:;
```

```
%%LST SSOLINK:;%%
RETCODE = 0  操作成功

操作结果如下
------------
        链路ID  =  1
        IP类型  =  IPV4
    本地IP地址  =  192.168.2.119
  本地IPV6地址  =  NULL
客户端授权人ID  =  /saml/SSO     
      链路描述  =  NULL
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD SSOLINK**命令的参数说明。
