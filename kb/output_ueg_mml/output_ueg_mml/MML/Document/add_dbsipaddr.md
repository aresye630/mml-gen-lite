# 增加网元IP地址(ADD DBSIPADDR)

## 命令功能

**须知** 

该命令属于高危命令，该操作可能会导致业务中断。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于增加IP地址。

该命令的使用场景：使用该命令设置微服务的外出IP地址，通过网络互连，实现对外通信。

## 注意事项

- 当“IP类型”为“IPV4(IPV4)”时，地址、网关和子网掩码匹配的IP类型必须为IPv4。
- 当“IP类型”为“IPV6(IPV6)”时，地址、网关和前缀长度匹配的IP类型必须为IPv6。
- 当HLR/HSS服务和dbbroker共Location部署时，dbbroker上**ADD DBSIPADDR**添加的IP地址与IP索引和FE上**ADD SRVIPADDR**添加的DSG IP地址与IP索引一致才能确保链路正常。
- IP地址不能与已使用的IP地址重复，否则会导致通信失败。
- 在执行本命令前，请执行**LST L3VPNINST**、**LST VPNINSTAF**和**LST AUTOSCALINGSERVICE**命令查询待配置的VPN名称是否在报文中存在，如果**LST L3VPNINST**、**LST VPNINSTAF**和**LST AUTOSCALINGSERVICE**报文中不存在，请使用**ADD L3VPNINST**、**ADD VPNINSTAF**和**ADD AUTOSCALINGSERVICE**命令进行配置。
- 使用该命令增加IP地址时，IP个数需根据交换机是否支持“SCTP协议基于端口号的ECMP负载均衡”功能确定：

  **说明** 

  当交换机不是华为设备时，请联系对应厂商确认交换机是否支持“SCTP协议基于端口号的ECMP负载均衡”功能。

  - 当交换机不支持“SCTP协议基于端口号的ECMP负载均衡”功能时，IP个数需根据IPU虚拟机（裸机场景为IPU POD，UDM和UPCF为cslbipc8-pod，USC为cslbip-pod）个数决定，IPU个数为偶数时，IP数量与IPU个数相同。IPU个数为奇数时，IP数量则为IPU个数加一。
  - 当交换机支持“SCTP协议基于端口号的ECMP负载均衡”功能时，申请1个IP地址。

## 使用实例

在某开局场景，增加网元IP地址，“Dbbroker IP索引”为“1”，“IP类型”为“IPV4(IPV4)”，“IP地址1的VPN名称”为“V1”，“本地Location IPV4地址1”为“192.168.100.1”，“本地Location IPV4网关1”为“192.168.100.0”，“本地Location IPV4子网掩码1”为“255.255.255.255”，“IP地址2的VPN名称”为“V2”，“本地Location IPV4地址2”为“192.168.200.1”，“本地Location IPV4网关2”为“192.168.200.0”，“本地Location IPV4子网掩码2”为“255.255.255.255”：

```
ADD DBSIPADDR: DBSIPINDEX=1, IPVER=IPV4, IP1VPNNAME="V1", IPV4IP1="192.168.100.1", IPV4GW1="192.168.100.0", IPV4MASK1="255.255.255.255", IP2VPNNAME="V2", IPV4IP2="192.168.200.1", IPV4GW2="192.168.200.0", IPV4MASK2="255.255.255.255";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 332602 | 该IP地址已存在。 | 输入的“本地Location IPV4地址1”/“本地Location IPV4地址2”或“本地Location IPV6地址1”/“本地Location IPV6地址2”已存在。 | 执行LST DBSIPADDR命令查询已存在的“本地Location IPV4地址”/“本地Location IPV4地址2”或“本地Location IPV6地址”/“本地Location IPV6地址2”。重新输入“本地Location IPV4地址”/“本地Location IPV4地址2”或“本地Location IPV6地址”/“本地Location IPV6地址2”，确保取值与查询结果中不重复。 |
