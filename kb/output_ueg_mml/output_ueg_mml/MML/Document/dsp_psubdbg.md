# 查询用户日志跟踪（DSP PSUBDBG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令通过指定用户标识显示当前跟踪的用户信息。

- 若查询全部的用户跟踪信息，“用户标识”请保持默认值。
- 若查询指定用户的跟踪信息，请在“用户标识”中输入对应用户标识。

用户的日志文件输出到服务所在容器的“opt/csplog/{appid}/PcfPolicyEngineService/export/log/”目录下，例如“/opt/csplog/20/PcfPolicyEngineService/export/log/”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                     |
|:-------|:-------|:-------------------------------------------------------------------------|
| SUBID  | 用户标识   | 可选必选说明：可选参数。 参数含义：系统按照指定用户标识显示当前跟踪的用户信息。 取值范围：长度不超过255的字符串。 默认值：无 配置原则：无 |

## 使用实例

显示指定用户标识为86136\*\*\*\*的用户日志跟踪信息。

```
DSP PSUBDBG: SUBID="86136****";
```

```
%%DSP PSUBDBG: SUBID="86136****";%%
RETCODE = 0  操作成功

操作结果如下：
--------------
实例号     用户标识       日志类型  创建时间             有效时间  

538245136  86136****      全部日志  2020-02-29 14:56:34  1         
538292472  86136****      全部日志  2020-02-29 14:56:34  1         
(结果个数 = 2)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                                       |
|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------|
| 实例号     | 用于标识用户所在服务的实例号。                                                                                                                             |
| 用户标识    | 用于标识用户日志跟踪的用户标识。                                                                                                                            |
| 日志类型    | 用于控制输出单用户的日志类型。 显示范围：全部日志：同时输出单用户的调试日志和策略日志；或者同时输出单用户的调试日志、策略日志和会话日志 调试日志：只输出单用户的调试日志；或者只输出单用户的调试日志和会话日志策略日志：只输出单用户的策略日志；或者只输出单用户的策略日志和会话日志 |
| 创建时间    | 用于标识用户日志跟踪的创建时间。                                                                                                                            |
| 有效时间    | 用于标识用户日志跟踪的有效时间。 单位：天。                                                                                                                      |
