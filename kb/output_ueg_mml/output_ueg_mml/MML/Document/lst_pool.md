#### 命令功能

**适用网元：SGSN**

该命令用于查询POOL配置信息。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                              |
|:-------|:-------|:--------------------------------------------------|
| POOLID | POOL标识 | 可选必选说明：可选参数 参数含义：该参数用于表示POOL标识。 取值范围：0~4095 默认值：无 |

#### 使用实例

查询POOL配置信息：

LST POOL:;

```
%%LST POOL:;%%
RETCODE = 0  执行成功。

查询POOL配置信息
-------------------------
 POOL标识  =  0
  NRI长度  =  2
(结果个数 = 1)
---    END
```
