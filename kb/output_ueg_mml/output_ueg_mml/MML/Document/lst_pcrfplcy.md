#### 命令功能

**适用网元：MME**

该命令用于查询PCRF策略。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询设置的PCRF策略：

`LST PCRFPLCY:;`

```
%%LST PCRFPLCY:;%%
RETCODE = 0  操作成功。

操作结果如下
--------------
  灵活选频功能开关  =  YES
          默认RFSP  =  1
是否使用对等口RFSP  =  YES
是否开启动态NI功能  =  YES
        运营商全称  =  aaa
        运营商简称  =  a
  是否使用对等口NI  =  NO
(结果个数 = 1)

---    END
```

#### 输出结果说明

请参见SET PCRFPLCY的参数说明。
