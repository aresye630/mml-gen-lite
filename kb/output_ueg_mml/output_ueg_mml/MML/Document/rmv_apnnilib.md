# 删除APNNI库记录（RMV APNNILIB）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用于删除APNNI的库记录。APNNI库是用户请求的APNNI或签约数据中的APNNI和终端类型的对应关系表，用于通过APNNI识别智能终端类型。

#### 注意事项

此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SELMODE | 选择方式   | 可选必选说明：必选参数 参数含义：该参数用于选择删除APNNI库记录的方式。 取值范围：“APNNI(APNNI)”“UE_TYPE(终端类型)”“ALL(所有)” 默认值：无                                                                                                                                                                                                                                                                                                                                                                      |
| APNNI   | APNNI  | 可选必选说明：条件必选参数 参数含义：该参数用于指定待删除的用户请求的APNNI或签约数据中的APNNI。 取值范围：1~62位字符串 默认值：无  说明： 当“SELMODE（选择方式）”选择为“APNNI(APNNI)”时，此参数才生效。“APNNI”（APN网络标识地址）由一个或多个LABEL构成，各LABEL间用“.”间隔。每个LABEL的构成字符只能是字母A～Z或a～z、数字0～9和中划线“-”，字母不区分大小写。APN网络标识地址不能以“rac”、“lac”、“sgsn”或“rnc”开头，不能以“.gprs”结尾，不能取值为“*”。                                                                                                                                                                           |
| UETYPE  | 终端类型   | 可选必选说明：条件必选参数 参数含义：该参数为用于删除APNNI库记录的终端类型。 取值范围：“ANDROID(Android)”“BLACKBERRY(Black Berry)”“IOS(iOS)”“WINDOWS(Windows)”“CUSTOM_TYPE_1(自定义类型1)”“CUSTOM_TYPE_2(自定义类型2)”“CUSTOM_TYPE_3(自定义类型3)”“CUSTOM_TYPE_4(自定义类型4)”“CUSTOM_TYPE_5(自定义类型5)”“CUSTOM_TYPE_6(自定义类型6)”“CUSTOM_TYPE_7(自定义类型7)”“CUSTOM_TYPE_8(自定义类型8)”“CUSTOM_TYPE_9(自定义类型9)”“CUSTOM_TYPE_10(自定义类型10)”“CUSTOM_TYPE_11(自定义类型11)”“CUSTOM_TYPE_12(自定义类型12)” 默认值：无  说明： 当“选择方式”选择“UE_TYPE(终端类型)”时，此参数才生效。 |

#### 使用实例

删除所有终端类型为Android用户APNNI库记录：

RMV APNNILIB: SELMODE=UE\_TYPE, UETYPE=ANDROID;
