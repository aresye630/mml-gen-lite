#### 命令功能

**适用网元：SGSN**

本命令用于查询本地GGSN地址。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                          |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPT    | IP地址类型 | 可选必选说明：可选参数 参数含义：该参数用于指定待查询的记录的IP地址类型。 数据来源：整网规划 取值范围：枚举类型“IPV4(IPv4)”“IPV6(IPv6)” 默认值：无                                                                                                                      |
| IP     | IPv4地址 | 可选必选说明：条件可选参数 参数定义：该参数用于指定待查询的记录内的任一IPv4地址。 取值范围：0.0.0.0～255.255.255.255 默认值：无 配置原则：有效的IPv4地址不能为 0.0.0.0,255.255.255.255，或0.x.y.z。有效的IPv4地址不能为环回地址(127.x.y.z)，或组播地址(224.x.y.z)。有效的IPv4地址必须是A、B或者C类地址。         |
| IPV6   | IPv6地址 | 可选必选说明：条件可选参数 参数含义：该参数用于指定待查询的记录内的任一IPv6地址。 取值范围：::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 配置原则：IPv6地址必须是全球单播地址，不能为FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址(::1)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。 |

LST LOCALGGSN:;

```
起始IP+终止IP    IPv4          10.10.0.0       10.10.10.255    0.0.0.0            NULL
(结果个数 = 2)
---    END
```
