# 查询DBS SCTP偶联配置(LST DBSSCTPASSOC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于请求系统显示DBS服务的SCTP偶联配置信息。

## 注意事项

如果链路配置发生变化，在执行**ACT DBSIPDISP**命令后，请执行**DSP DBSSCTPASSOC**命令更新SCTP偶联话统统计对象信息。

## 参数说明

无。

## 使用实例

查询所有SCTP偶联配置信息。

```
LST DBSSCTPASSOC:;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称       | 输出项解释                 |
|:------------|:----------------------|
| 测量对象ID      | 用于返回SCTP偶联测量对象标识。     |
| SCTP偶联本地IP1 | 用于返回SCTP偶联本端设备的IP地址1。 |
| SCTP偶联本地IP2 | 用于返回SCTP偶联本端设备的IP地址2。 |
| SCTP偶联本地端口号 | 用于返回SCTP偶联本端设备的端口号。   |
| SCTP偶联对端IP1 | 用于返回SCTP偶联远端设备的IP地址1。 |
| SCTP偶联对端IP2 | 用于返回SCTP偶联远端设备的IP地址2。 |
| SCTP偶联对端端口号 | 用于返回SCTP偶联远端设备的端口号。   |
