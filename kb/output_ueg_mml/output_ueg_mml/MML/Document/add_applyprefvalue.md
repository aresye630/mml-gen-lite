# 增加BGP路由首选值设置（ADD APPLYPREFVALUE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于增加BGP路由首选值设置。使用ADD APPLYPREFVALUE命令配置优先级后，在不同协议发现到达同一目的地的不同路由时，优先级高的路由协议发现的路由将作为当前的有效路由。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 配置该命令前，必须首先配置ADD ROUTEPOLICYNODE命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                              |
|:---------------|:---------|:--------------------------------------------------------------------------------------------------|
| POLICYNAME     | 路由策略名字   | 可选必选说明：必选参数 参数含义：该参数用于表示路由策略名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无                          |
| NODESEQUENCE   | 路由策略节点号  | 可选必选说明：必选参数 参数含义：该参数用于表示路由策略节点号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无                          |
| PREFERREDVALUE | BGP路由首选值 | 可选必选说明：必选参数 参数含义：该参数用于表示BGP路由的首选值。在选择路由时，优选协议首选值最高的BGP路由。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无 |

#### 使用实例

配置abc路由策略1节点下，首选值设置为1：

```
ADD APPLYPREFVALUE:POLICYNAME="abc",NODESEQUENCE=1,PREFERREDVALUE=1;
```
