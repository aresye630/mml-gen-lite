# 查询LDAP设备地址（LST LDAPDEVADDR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询配置数据库中LDAP（Lightweight Directory Access Protocol）设备地址信息。

- 如果需要查询全部LDAP设备地址信息，请不要输入任何参数。
- 如果需要查询某条LDAP设备地址信息，请依据参数说明输入查询条件。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                            |
|:------------|:-------|:------------------------------------------------------------------------------------------------|
| DEVAID      | 设备地址标识 | 可选必选说明：可选参数 参数含义：用于指示系统按照设备地址标识来查询LDAP设备地址信息；若不输入，则表示所有的设备地址标识。 取值范围：0～7 默认值：无。 配置原则：无。         |
| VPNNAME     | VPN名称  | 可选必选说明：可选参数 参数含义：用于指示系统按照VPN名称来查询LDAP设备地址信息；若不输入，则表示所有的VPN名称。 取值范围：长度不超过31位的字符串。 默认值：无。 配置原则：无。 |
| IPVER       | IP版本   | 可选必选说明：可选参数 参数含义：用于指示系统按照IP版本来查询LDAP设备地址信息；若不输入，则表示所有的IP版本。 取值范围：IPV4(IPV4) 默认值：无。 配置原则：无。      |
| IP          | IPV4地址 | 可选必选说明：可选参数 参数含义：用于指示系统按照IPV4地址来查询LDAP设备地址信息；若不输入，则表示所有的IPV4地址。 取值范围：IPv4地址 默认值：无。 配置原则：无。      |
| DESCRIPTION | 描述     | 可选必选说明：可选参数 参数含义：用于指示系统按照描述来查询LDAP设备地址信息；若不输入，则表示所有的描述。 取值范围：长度不超过32的字符串 默认值：无。 配置原则：无。         |

## 使用实例

1. 查询所有的LDAP设备地址的配置信息。

   ```
   LST LDAPDEVADDR:;
   ```

   ```
   %%LST LDAPDEVADDR:;%% 
   RETCODE = 0  操作成功  

   操作结果如下: 
   ------------- 
   设备地址标识  VPN名称  IP版本  IPV4地址       描述    
   1             VPN1     IPV4    172.16.27.94   NULL   
   2             VPN2     IPV4    192.168.0.131  TEST   
   (结果个数 = 2) 
    
   ---    END
   ```
2. 查询一条LDAP设备地址的配置信息。“设备地址标识”为“2”。

   ```
   LST LDAPDEVADDR: DEVAID=2;
   ```

   ```
   %%LST LDAPDEVADDR: DEVAID=2;%% 
   RETCODE = 0  操作成功  
   操作结果如下 
   ------------ 
   设备地址标识  =  2
        VPN名称  =  VPN2 
         IP版本  =  IPV4     
       IPV4地址  =  192.168.0.131            
           描述  =  TEST 
   (结果个数 = 1)  

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见ADD LDAPDEVADDR命令的参数说明。
