# 设置SGM软件调试信息（SET SGMDBG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响系统性能与业务处理，需联系华为技术支持确认后再执行。

该命令用于设置SGM服务的调试参数。

## 注意事项

软件调试会影响系统性能，仅限于华为工程师使用。

## 参数说明

| 参数标识             | 参数名称   | 参数说明                                                                                                                                                       |
|:-----------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| CMDTYPE          | 命令类型   | 可选必选说明：必选参数。 参数含义：用于指定业务模块调试命令的操作类型。 取值范围： SET_DISTRIBUTE(设置分发数据)：用于指定用户的分发数据CLR_DISTRIBUTE(清除分发数据)：用于清除指定用户的分发数据。CLR_USER(清除用户)：用于清除指定用户的控制块 默认值：无 配置原则：无 |
| SUBID            | 用户标识   | 可选必选说明：必选参数。 参数含义：用于指定调试哪个用户的数据。 取值范围：长度不超过255的字符串。 默认值：无。 配置原则：无                                                                                          |
| COMMUNINSTANCENO | 通信实例号  | 可选必选说明：当“CMDTYPE”设置为“SET_DISTRIBUTE”时，显示参数“COMMUNINSTANCENO”，参数为必选。 参数含义：用于指定调试命令对应的实例号。 取值范围：长度不超过256的字符串。 默认值：无。 配置原则：执行DSP SGMINFO命令获取返回服务的实例号。         |

## 使用实例

以清除分发数据举例如下：其中“SUBID”为“12345645”。

```
SET SGMDBG: CMDTYPE=CLR_DISTRIBUTE, SUBID="12345645";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
