# 增加IMEI库记录（ADD SMACTIMEILIB）

#### 命令功能

**适用网元：SGSN、MME**

此命令用于增加终端IMEI记录。终端IMEI记录为IMEI TAC和终端类型的对应关系表，用于按照IMEI TAC识别智能终端类型。

#### 注意事项

- 此命令最大记录为1000条。
- 此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                             |
|:--------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMEITAC | 设备型号核准号码 | 可选必选说明：必选参数 参数含义：该参数用于设置用户的设备型号核准号码。 数据来源：本端规划 取值范围：8位十进制数 默认值：无                                                                                                                                                                                                                                                                                                                                                                 |
| UETYPE  | 终端类型     | 可选必选说明：必选参数 参数含义：该参数用于设置设备型号核准号码对应的终端类型。 数据来源：本端规划 取值范围： “ANDROID(Android)”“BLACKBERRY(Black Berry)”“IOS(iOS)”“WINDOWS(Windows)”“CUSTOM_TYPE_1(自定义类型1)”“CUSTOM_TYPE_2(自定义类型2)”“CUSTOM_TYPE_3(自定义类型3)”“CUSTOM_TYPE_4(自定义类型4)”“CUSTOM_TYPE_5(自定义类型5)”“CUSTOM_TYPE_6(自定义类型6)”“CUSTOM_TYPE_7(自定义类型7)”“CUSTOM_TYPE_8(自定义类型8)”“CUSTOM_TYPE_9(自定义类型9)”“CUSTOM_TYPE_10(自定义类型10)”“CUSTOM_TYPE_11(自定义类型11)”“CUSTOM_TYPE_12(自定义类型12)” 默认值：无 |
| UEDESC  | 终端详细信息   | 可选必选说明：可选参数 参数含义：该参数是对用户终端类型的详细描述。 数据来源：本端规划 取值范围：长度为32位的字符串 默认值：无                                                                                                                                                                                                                                                                                                                                                               |

#### 使用实例

配置针对BLACKBERRY终端类型，如果请求消息未携带APN，不进行请求信息纠正，且在用户签约野卡的情况下不进行纠错，拒绝该用户的激活请求，可以按照如下描述操作：

- 执行**ADD SMACTIMEILIB**配置IMEI TAC与终端类型的映射关系；
- 执行**ADD SMACTCTRL**配置针对黑莓类型终端不进行请求信息纠正。

ADD SMACTIMEILIB: IMEITAC="12345678", UETYPE=BLACKBERRY;

ADD SMACTIMEILIB: IMEITAC="22345678", UETYPE=BLACKBERRY;

ADD SMACTCTRL: SUBRANGE=SPECIAL\_UETYPE, UETYPE=BLACKBERRY, APNTYPE=NULL\_APN, POLICY=MATCH\_FAIL\_NOTCORRECT, WILDCARDPLCY=REJECT;
