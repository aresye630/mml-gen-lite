#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

LST CDRGENRATECTRL命令用来查询计费数据产生速率控制信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询系统计费数据产生速率控制信息：

```
LST CDRGENRATECTRL:;
```

```
RETCODE = 0  操作成功。

话单产生速率控制
----------------
CDR产生速率（%）  =  50
(结果个数 = 1)
---    END
```
