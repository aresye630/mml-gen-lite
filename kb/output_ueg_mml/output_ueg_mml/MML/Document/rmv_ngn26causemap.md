# 删除5G N26接口原因值映射配置（RMV NGN26CAUSEMAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除5G N26接口原因值映射配置。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                 |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROT   | 流程类型   | 可选必选说明：必选参数  参数含义：该参数用于指定流程类型，根据场景来确认是否需要配置相应的流程。  数据来源：全网规划 取值范围： LTE_TO_NR_HO（EPC到5GC切换）NR_TO_LTE_ATTACH（5GS到LTE附着）NR_TO_LTE_TAU（5GS到LTE TAU）ALL（所有的失败流程）RESERV_PROC1（预留字段1）RESERV_PROC2（预留字段2）  默认值：无  配置原则：  指定流程和“ALL”类型同时配置时，指定流程配置的原因值映射优先级高于“ALL”类型配置的原因值映射。 |
| SCAUSE | 原始原因值  | 可选必选说明：必选参数  参数含义：该参数用于指定下发到MME的原始原因值。  数据来源：全网规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无                                                                                                                                                                              |

## 使用实例

删除流程类型为5GS到LTE附着，原始原因值为96的5G N26接口原因值映射配置，执行如下命令：

```
RMV NGN26CAUSEMAP:PROT=NR_TO_LTE_ATTACH,SCAUSE=96;
```
