# 查询5G紧急服务功能（LST NGEMGSRVFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询5G紧急服务功能。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询5G紧急服务功能，执行如下命令：

```
%%LST NGEMGSRVFUNC:;%%
RETCODE = 0  操作成功

结果如下
--------
本网用户是否允许紧急呼叫业务  =  NR接入的紧急呼叫回落
本网用户紧急号码列表下发开关  =  是
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称          | 输出项解释                                                                   |
|:---------------|:------------------------------------------------------------------------|
| 本网用户是否允许紧急呼叫业务 | 该参数用于指定是否允许本网用户使用紧急呼叫业务。                                                |
| 本网用户紧急号码列表下发开关 | 该参数用于控制AMF在给本网用户发送Registration Accept消息时，是否将配置的MCC的紧急呼叫号码列表携带在消息中发送给UE。 |
