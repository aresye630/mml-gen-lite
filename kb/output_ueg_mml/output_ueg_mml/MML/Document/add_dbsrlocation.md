# 增加远端DBS Location信息(ADD DBSRLOCATION)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加一个远端Location。

该命令的使用场景：当需要为本端网元设备设置对接的远端网元设备时，需要通过本命令增加远端网元设备的location信息。

本端网元设备和远端网元设备之间的容灾关系如图1所示。

**图1** 本端网元设备与远端网元设备关系图

在图1中：

- 对于主用FE，它的远端网元设备指主用USCDB、容灾USCDB。
- 对于主用USCDB，它的远端网元设备指主用局FE、容灾局FE、容灾局USCDB。
- 对于容灾FE，它的远端网元设备指容灾USCDB、主用USCDB。
- 对于容灾USCDB，它的远端网元设备指容灾局FE、主用局FE、主用局USCDB。

本端网元设备：相对于远端网元设备而言，在本局点配置的网元设备称为本端网元设备。与远端网元设备组成容灾网络。

远端网元设备：相对于本端网元设备而言，在对端或远端局点配置的网元设备称为远端网元设备。与本端网元设备组成容灾网络。

## 注意事项

- FE的Location信息需要在FE CSP客户端执行**SET DBSLOCATION**增加后才能在此引用。
- 容灾局USCDB网元设备的远端Location信息需要在容灾局的USCDB MML界面执行**SET LOCATION**增加后才能在此引用。
- 当系统中存在未通过**ADD DBSSERVICENO**命令配置服务模块号的dbbroker服务实例时，执行**ADD DBSRLOCATION**命令增加远端DBS Location信息会返回错误码302589。

## 参数说明

| 参数标识   | 参数名称         | 参数说明                                                                                                                                                         |
|:-------|:-------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RLOCID | 远端Location标识 | 可选必选说明：必选参数 参数含义：用于指定本端网元设备对应的远端网元设备的Location的标识，一个远端Location标识唯一对应一个远端网元。 取值范围：1～512 默认值：无。 配置原则：无                                                          |
| RMT    | 远端网元类型       | 可选必选说明：必选参数 参数含义：用于指定本端网元设备对应的远端网元设备的类型。 取值范围：USCDB(USCDB) 默认值：无。 配置原则：必须与对端设备的实际类型保持一致。                                                                     |
| LP     | 位置ID优先级      | 可选必选说明：必选参数 参数含义：用于指定远端网元设备Location优先级。优先级值越小，优先级越高。如果一个本端网元设备对应多个远端网元设备，则本端网元会按照优先级从高到低的顺序选择远端网元设备进行访问。 取值范围： 1～512 默认值： 无。 配置原则：主备地理容灾场景中，配置主用局位置优先级高于容灾局。 |

## 使用实例

增加远端Location，“远端Location标识”为“3”，“远端网元类型”为“USCDB”，“位置ID优先级”为“1”：

```
ADD DBSRLOCATION: RLOCID=3, RMT=USCDB, LP=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                 | 原因分析                                | 处理建议                                                                                                                                                                                    |
|-------:|:--------------------------------------|:------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 301251 | 远端Location中该网元类型已经存在相同的优先级。           | 输入的“位置ID优先级”已存在。                    | 执行LST DBSRLOCATION命令查看已存在的“位置ID优先级”。重新输入“位置ID优先级”，确保取值与查询结果中的不重复。                                                                                                                       |
| 302001 | 远端location已存在。                        | 输入的“远端Location标识”已存在。               | 执行LST DBSRLOCATION命令查询“远端Location标识”，重新执行本命令，确保输入的“远端Location标识”与查询结果中的不重复。                                                                                                             |
| 302002 | 参数RLID指定的远端location标识与本地location标识重复。 | 输入的参数“远端location标识”与本地location标识重复。 | 执行LST DBSLOCATION命令查询本地Location标识，重新执行本命令，确保输入的“远端location标识”参数与查询结果中的不重复。                                                                                                              |
| 302589 | DBSSERVICENO未配置。                      | DBS服务模块号信息未配置。                      | 请执行ADD DBSSERVICENO命令配置dbbroker服务模块号信息，确保dbbroker的每个服务实例都已配置服务模块号后，重新执行本命令。（例如：如果存在有两个服务实例的dbbroker，那么这两个服务实例都需要通过ADD DBSSERVICENO命令配置服务模块号后，才能执行ADD DBSRLOCATION命令增加远端DBS Location信息。） |
