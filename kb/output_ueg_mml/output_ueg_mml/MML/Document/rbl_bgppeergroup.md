# 复位BGP对等体组（RBL BGPPEERGROUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

本命令属于高危命令，操作不当会导致邻居断连，请谨慎使用并联系华为技术支持协助操作。

该命令用于复位与指定对等体组的BGP连接。

#### 注意事项

- 该命令执行后立即生效。
- 该命令用于复位与指定对等体组的BGP连接。
- 执行该命令会导致对等体断连。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                             |
|:----------|:--------|:---------------------------------------------------------------------------------------------------------------------------------|
| VRFNAME   | VPN实例名称 | 可选必选说明：可选参数 参数含义：该参数用于指定用户所配置的VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：_public_ 配置原则：使用LST L3VPNINST命令查看可用VPN。             |
| AFTYPE    | 地址族类型   | 可选必选说明：必选参数 参数含义：该参数用于指定VRF的地址族类型。 数据来源：本端规划 取值范围：枚举类型。 ipv4uni：IPv4地址族。ipv4vpn：VPNv4地址族。ipv6uni：IPv6地址族。ipv6vpn：VPNv6地址族。 默认值：无 |
| GROUPNAME | 对等体组名称  | 可选必选说明：可选参数 参数含义：该参数用于指定对等体组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～47。 默认值：无 配置原则：使用LST BGPPEERGROUP命令查看可用对等体组名。                      |

#### 使用实例

重置IPv4单播地址族下的对等体组：

```
RBL BGPPEERGROUP: VRFNAME="_public_", AFTYPE=ipv4uni;
```
