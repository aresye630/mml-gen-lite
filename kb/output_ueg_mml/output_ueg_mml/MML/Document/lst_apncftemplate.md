# 查询APN内容过滤模板（LST APNCFTEMPLATE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于显示APN的内容过滤模板。如果不指定APN名称或内容过滤模板名称，则查询所有的APN内容过滤模板。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                                                                                               |
|:---------------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APNNAME        | APN名称    | 可选必选说明：可选参数 参数含义：该参数用于设置APN名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。 默认值：无 配置原则：无 |
| CFTEMPLATENAME | 内容过滤模板名称 | 可选必选说明：可选参数 参数含义：该参数用于设置内容过滤模板名称。 数据来源：本端规划 取值范围：NA。 默认值：无 配置原则：无                                                                                                                                  |

#### 使用实例

显示APN的内容过滤模板：

```
LST APNCFTEMPLATE:;
```
