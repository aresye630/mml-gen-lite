# 删除DRS设备地址(RMV DRSDEVADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致系统异常，影响业务处理，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于在配置数据库中删除一条DRS设备地址数据记录。

## 注意事项

- 当已经配置IP地址时，DRS使用该IP提供服务。此时删除该IP地址，必须重启DRS服务，且重启后不再提供服务。
- 当执行ADD DRSDEVADDR/MOD DRSDEVADDR/RMV DRSDEVADDR增加、修改、删除IP地址时，都必须重启DRS服务，具体操作为：
  1. 登录“UPCF MML命令”界面；
  2. 执行**RST MSPROCESS**命令重启DRS服务：

     ```
     RST MSPROCESS: PROCOBJECT=PROCNAME, PROCNAME="CELL_PcfDrs";
     ```

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------|
| DEVAID | 设备地址标识 | 可选必选说明：必选参数 参数含义：标识一条本地设备地址信息数据记录的关键字段，用于指定需要删除哪一条本地设备地址信息数据记录，操作员可以使用LST DRSDEVADDR命令查询获得。 取值范围：0~7 默认值：无。 配置原则：无。 |

## 使用实例

删除一条DRS设备地址信息。“设备地址标识”为“0”。

```
RMV DRSDEVADDR: DEVAID=0;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                | 原因分析                                    | 处理建议                                                                                               |
|------:|:---------------------|:----------------------------------------|:---------------------------------------------------------------------------------------------------|
| 58023 | 该IP地址已被使用，不允许修改或者删除。 | 输入的“设备地址标识”对应的IP地址已被DRSPEERLINKCFG对象引用。 | 执行LST DRSPEERLINKCFG命令，查询引用该IP地址的报表服务对端链路。执行RMV DRSPEERLINKCFG命令，删除引用该IP地址的报表服务对端链路。重新执行本命令删除设备地址。 |
