# 查询TW定时器（LST TWTIMER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明

- 输出结果说明

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于查询Diameter TW定时器。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询Diameter TW定时器，则可按如下配置：

```
LST TWTIMER:;
```

```
RETCODE = 0  操作成功。

TW定时器配置
------------
      TW定时器时长（秒）  =  3
 DWR消息响应超时次数上限  =  3
超时次数达到上限复位连接  =  复位TCP
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见SET TWTIMER的参数说明。
