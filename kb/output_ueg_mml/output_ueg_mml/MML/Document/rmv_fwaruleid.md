# 删除FWA用户规则ID配置（RMV FWARULEID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响FWA用户识别。

该命令用于删除一条FWA用户规则ID配置记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                           |
|:-------|:-------|:---------------------------------------------------------------|
| ID     | ID     | 可选必选说明：必选参数。 参数含义：表示FWA用户规则ID配置的记录标识。 取值范围：0～19 默认值：无。 配置原则：无。 |

## 使用实例

删除一条FWA用户规则ID配置。“ID”为“0”。

```
RMV FWARULEID: ID=0;
```
