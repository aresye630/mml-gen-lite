# 查询HLB对端链路(LST HLBPEERL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于在配置数据库中查询HLB和对端实体的链路配置信息。

- 如果需要查询所有链路配置信息，请不要输入任何参数。
- 如果需要查询某条链路配置信息，请依据参数说明输入查询条件。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                         |
|:----------|:---------|:-------------------------------------------------------------------------------------------------------------|
| PEERID    | 对端标识     | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个对端标识来查询HLB对端链路信息。若不输入，则表示所有的对端标识。 取值范围：0～63 默认值：无。 配置原则：无。                      |
| LINKID    | 链路标识     | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个链路标识来查询HLB对端链路信息。若不输入，则表示所有的链路标识。 取值范围：0 默认值：无。 配置原则：无。                         |
| IPVER     | IP版本     | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个IP地址版本来查询HLB对端链路信息。若不输入，则表示所有的IP地址类型。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。 |
| LOCALIP   | 本端IPV4地址 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个本端IPV4地址来查询HLB对端链路信息。若不输入，则表示所有的本端IPV4地址。 取值范围：IPV4地址 默认值：无。 配置原则：无。            |
| LOCALIPV6 | 本端IPV6地址 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个本端IPV6地址来查询HLB对端链路信息。若不输入，则表示所有的本端IPV6地址。 取值范围：IPV6地址 默认值：无。 配置原则：无。            |
| PEERIP    | 对端IPV4地址 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个对端IPV4地址来查询HLB对端链路信息。若不输入，则表示所有的对端IPV4地址。 取值范围：IPV4地址 默认值：无。 配置原则：无。            |
| PEERIPV6  | 对端IPV6地址 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个对端IPV6地址来查询HLB对端链路信息。若不输入，则表示所有的对端IPV6地址。 取值范围：IPV6地址 默认值：无。 配置原则：无。            |
| PEERPORT  | 对端端口号    | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个对端端口来查询HLB对端链路信息。若不输入，则表示所有的对端端口。 取值范围：1~65535 默认值：无。 配置原则：无。                   |

## 使用实例

查询所有的HLB和对端设备的链路配置信息。

```
LST HLBPEERL:;
```

```
%%LST HLBPEERL:;%%
RETCODE = 0  操作成功
 
操作结果如下
------------
对端标识  链路标识  IP版本  本端IPV4地址  本端IPV6地址  对端IPV4地址    对端IPV6地址  对端端口号  
 
2         0         IPV4    10.205.145.13  NULL          10.222.221.111  NULL          222         
4         0         IPV4    10.205.145.13  NULL          10.168.25.65    NULL          7878        
(结果个数 = 2)
 
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD HLBPEERL**命令的参数说明。
