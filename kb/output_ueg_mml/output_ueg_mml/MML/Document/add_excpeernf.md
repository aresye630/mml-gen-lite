# 增加例外对端NF（ADD EXCPEERNF）

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响业务处理，需联系华为技术支持确认后再执行。

该命令用于增加一个例外对端NF信息。

## 注意事项

- 该命令只支持配置的对端NF类型为SMF、AMF、AF，如果配置了其他类型对端NF的IP可以通过CHK EXCPEERNF命令进行检查，可通过RMV EXCPEERNF命令删除配置非SMF/AMF/AF对端的IP地址。
- 若不同NF类型设备地址是相同IP，上述设备不允许使用本命令添加到例外对端NF。
- 如果HTTP客户端链路的“链路管理状态”设置为“DISABLE”后，再执行该命令增加例外对端NF，ALM-34163 PCF与NF之间的HTTP链路故障告警不会自动清除。
- 执行该命令后，对业务处理会有如下影响：
  - 系统将无法感知与例外对端NF的HTTP客户端链路状态，若系统发送消息选择了故障链路，会导致业务受损。
  - 系统与例外对端NF的HTTP客户端链路故障时，不会上报ALM-34163 PCF与NF之间的HTTP链路故障告警。
- 该命令最大支持配置4096条记录。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                              |
|:------------|:-------|:----------------------------------------------------------------------------------|
| IPADDR      | IP地址   | 可选必选说明：必选参数 参数含义：用于配置例外对端NF的IP地址。 取值范围：IPv4/IPv6地址类型，长度不超过40位的字符串。 默认值：无。 配置原则：无。 |
| DESCRIPTION | 描述     | 可选必选说明：可选参数 参数含义：用于描述例外对端NF的IP地址的用途。 取值范围：长度不超过255位的字符串。 默认值：无。 配置原则：无。           |

## 使用实例

增加一个例外对端NF信息，“IP地址”为“192.168.21.71”。

```
ADD EXCPEERNF: IPADDR="192.168.21.71";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释   | 原因分析               | 处理建议                                    |
|-------:|:--------|:-------------------|:----------------------------------------|
|  58033 | IP地址非法。 | 参数“IP地址”配置的IP地址非法。 | 根据实际情况，请重新输入，确保输入的参数符合取值范围。             |
| 360042 | 参数值已存在  | 已有相同的“IP地址”配置。     | 使用LST EXCPEERNF命令查询并重新输入“IP地址”，确保其值不存在。 |
