# 删除5G LAN实例绑定双发选收结对配置（RMV NGBINDDFSRPAIR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于删除双发选收结对与5G LAN会话实例绑定关系。

#### 注意事项

- 该命令执行后立即生效。
- 双发选收结对已绑定该5G LAN会话实例。
- 双发选收结对未加入到静态组播组中。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称       | 参数说明                                                                                  |
|:-----------|:-----------|:--------------------------------------------------------------------------------------|
| VNINSTANCE | 5G LAN实例名称 | 可选必选说明：必选参数 参数含义：该参数用于指定5G LAN会话实例名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为18～37。 默认值：无 配置原则：无 |
| DFSRPAIRID | 双发选收结对ID   | 可选必选说明：可选参数 参数含义：该参数用于配置双发选收结对ID。 数据来源：本端规划 取值范围：整数类型，取值范围1-2048。 默认值：无 配置原则：无        |

#### 使用实例

把双发选收结对1与5G LAN会话实例a0000001-460-01-01解绑：

```
RMV NGBINDDFSRPAIR: VNINSTANCE="a0000001-460-01-01", DFSRPAIRID=1;
```
