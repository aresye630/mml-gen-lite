# 设置UPC DS粒度N4请求等待超时异常的告警恢复阈值（SET UPCALMRSTVAL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、PGW-C、SGW-C、GGSN**

该命令用于设置UPC DS粒度N4请求等待超时异常的告警恢复阈值。

## 注意事项

- 该命令执行后立即生效。

- 当前版本不支持此命令。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

|   UPCALMRSTVAL |
|---------------:|
|             60 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称         | 参数说明                                                                                                                                                          |
|:-------------|:-------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UPCALMRSTVAL | UPC告警恢复阈值(秒) | 可选必选说明：可选参数  参数含义：UPC DS粒度N4请求等待超时异常的恢复告警阈值。  数据来源：本端规划  取值范围：整数类型，取值范围是1~4294967295。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST UPCALMRSTVAL查询当前参数配置值。  配置原则：无 |

## 使用实例

设置UPC DSDS粒度N4请求等待超时异常的告警恢复阈值为10秒：

```
SET UPCALMRSTVAL:UPCALMRSTVAL=10;
```
