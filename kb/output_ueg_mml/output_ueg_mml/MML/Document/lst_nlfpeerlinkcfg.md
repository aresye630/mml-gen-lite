# 查询NLF对端链路(LST NLFPEERLINKCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询NLF对端链路的配置信息。

- 若需要查询全部NLF对端链路的配置信息，请不要输入任何参数。
- 若需要查询指定NLF对端链路的配置信息，请依据参数说明输入查询条件。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                       |
|:------------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| LINKID      | 链路ID     | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个链路ID来查询NLF对端链路配置信息；若不输入，则表示所有的链路ID。 取值范围：0～254 默认值：无。 配置原则：无。                                                 |
| PEERID      | 对端ID     | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个对端ID来查询NLF对端链路配置信息；若不输入，则表示所有的对端ID。 取值范围：0～31 默认值：无。 配置原则：无。                                                  |
| LOCALROLE   | 本地角色     | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个本地角色来查询通NLF对端链路配置信息；若不输入，则表示所有的本地角色。 取值说明： SFTPClient(SFTP客户端) 默认值：无。 配置原则：无。                                 |
| IPVER       | IP版本     | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个IP版本类型来查询NLF对端链路配置信息；若不输入，则表示所有的IP版本类型。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。                             |
| LOCALIP     | 本地IP地址   | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV4(IPV4)”时该参数可配置，用于指示系统需要按照哪个本地IPv4地址来查询NLF对端链路配置信息；若不输入，则表示所有的本地IPv4地址。 取值范围：IPv4地址 默认值：无。 配置原则：无。          |
| LOCALIPV6   | 本地IPV6地址 | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV6(IPV6)”时该参数可配置，用于指示系统需要按照哪个本地IPv6地址来查询NLF对端链路配置信息；若不输入，则表示所有的本地IPv6地址。 取值范围：IPV6地址 默认值：无。 配置原则：无。          |
| PEERIP      | 对端IP地址   | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV4(IPV4)”时该参数可配置，用于指示系统需要按照哪个对端IPv4地址来查询NLF对端链路配置信息；若不输入，则表示所有的对端IPv4地址。 取值范围：IPv4地址 默认值：无。 配置原则：无。          |
| PEERIPV6    | 对端IPV6地址 | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV6(IPV6)”时该参数可配置，用于指示系统需要按照哪个对端IPv6地址来查询NLF对端链路配置信息；若不输入，则表示所有的对端IPv6地址。 取值范围：IPv6地址 默认值：无。 配置原则：无。          |
| PEERPORT    | 对端端口     | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个对端端口来查询NLF对端链路配置信息；若不输入，则表示所有的对端端口。 取值范围：1～65534 默认值：无。 配置原则：无。                                               |
| USRNAME     | 用户名      | 可选必选说明：可选参数 参数含义：当“本地角色”选择为“SFTPClient(SFTP客户端)”时，该参数可配置。用于指示系统需要按照哪个用户名来查询NLF对端链路配置信息；若不输入，则表示所有的用户名。 取值范围：长度不超过96的字符串 默认值：无。 配置原则：无。     |
| PATH        | 对端路径     | 可选必选说明：可选参数 参数含义：当“本地角色”选择为“SFTPClient(SFTP客户端)”时，该参数可配置。用于指示系统需要按照哪个对端路径来查询NLF对端链路配置信息；若不输入，则表示所有的对端路径。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。 |
| DESCRIPTION | 描述       | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个描述来查询NLF对端链路配置信息；若不输入，则表示所有的描述。 取值范围：长度不超过32的字符串 默认值：无。 配置原则：无。                                               |
