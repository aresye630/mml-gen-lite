# 查询DNAI支持的服务区域（LST DNAIBINDDNAREA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、SMF、GGSN、PGW-C**

该命令用于查询DNAI支持的服务区域信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                         |
|:-------|:---------|:---------------------------------------------------------------------------------------------|
| DNAI   | 数据网络访问标识 | 可选必选说明：可选参数  参数含义：该参数用于指定数据网络访问标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~63。不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

- 查询数据网络访问标识为"ulcl"的区域绑定的服务区域。
  LST DNAIBINDDNAREA: DNAI="ulcl";

  ```
  %%LST DNAIBINDDNAREA: DNAI="ulcl";%%
  RETCODE = 0  操作成功

  结果如下
  --------
  数据网络访问标识  DNAI服务区域名称  

  ulcl              dnarea1           
  ulcl              dnarea2           
  (结果个数 = 2)
  ```
- 查询所有数据网络访问标识绑定的服务区域。
  LST DNAIBINDDNAREA:;

  ```
  %%LST DNAIBINDDNAREA:;%%
  RETCODE = 0  操作成功

  结果如下
  --------
  数据网络访问标识  DNAI服务区域名称  

  ulcl              dnarea1           
  ulcl              dnarea2           
  bp                dnarea3           
  (结果个数 = 3)
  ```

## 输出结果说明

| 输出项名称      | 输出项解释              |
|:-----------|:-------------------|
| 数据网络访问标识   | 该参数用于指定数据网络访问标识。   |
| DNAI服务区域名称 | 该参数用于指定DNAI服务区域名称。 |
