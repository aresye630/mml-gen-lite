# 查询Bypass配置(LST BYPASS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询业务放通的配置信息。若需要查询所有配置信息，请不要输入任何参数。

## 注意事项

无。

## 参数说明

| 参数ID        | 参数名称      | 参数描述                                                                                                                         |
|:------------|:----------|:-----------------------------------------------------------------------------------------------------------------------------|
| TYPE        | 放通业务类型    | 用于指定需要放通的业务类型。 取值范围： VOLTE(语音业务)：放通语音业务。N15POLICY(N15接口策略)：放通N15接口策略。N24POLICY(N24接口策略)：放通N24接口策略。 默认值：无。                    |
| VOLTEMETHOD | VoLTE应急手段 | 用于指定UPCF处理VoLTE呼叫异常时的应急手段。仅当参数“放通业务类型”选择“VOLTE(语音业务)”时，该参数可显。 取值范围： REFUSEVONRN7(拒绝VONR N7会话)：表示UPCF拒绝N7会话的IMS信令承载建立。 默认值：无。 |
| POLICYTYPE  | 策略类型      | 用于指定N15接口需要放通的策略类型。仅当参数“放通业务类型”选择“N15POLICY(N15接口策略)”时，该参数可显。 取值范围： AMPOLICY(AM策略)UEPOLICY(UE策略)ALL(全部策略) 默认值：无。             |

## 使用实例

1. 查询所有业务放通的配置信息：

   ```
   LST BYPASS:;
   ```

   ```
   %%LST BYPASS:;%%
   RETCODE = 0  操作成功

   操作结果如下: 
   ------------------------
   放通业务类型         VoLTE应急手段        策略类型  

   语音业务             拒绝VONR N7会话      NULL         
   N15接口策略          NULL                 AM策略    
   N24接口策略          NULL                 NULL         
   (结果个数 = 3)

   ---    END
   ```
2. 查询放通语音业务的配置信息，“放通业务类型”为“VOLTE(语音业务)”。

   ```
   LST BYPASS: TYPE=VOLTE;
   ```

   ```
   %%LST BYPASS: TYPE=VOLTE;%% 
   RETCODE = 0  操作成功
     
   操作结果如下: 
   -------------  
    放通业务类型  =  语音业务 
   VoLTE应急手段  =  拒绝VONR N7会话
        策略类型  =  NULL

   (结果个数 = 1)  

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见ADD BYPASS命令的参数说明。
