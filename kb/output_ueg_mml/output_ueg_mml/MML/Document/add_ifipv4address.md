# 增加接口IPv4地址（ADD IFIPV4ADDRESS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于配置接口的IP地址，包括逻辑接口及物理接口。物理接口是真实存在的接口。逻辑接口是指能够实现数据交换功能但物理上不存在、需要通过配置建立的接口。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为65535。
- 该接口需要支持配置IP地址。
- 该命令在版本升级过程中禁止执行。
- 每个主用接口最大允许配置256个接口IP地址：1个主IP地址和255个从IP地址。
- 该命令的必选参数IFNAME可通过LST INTERFACE命令查询到。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                               |
|:-----------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IFNAME     | 接口名      | 可选必选说明：必选参数 参数含义：该参数用于指定需要配置IP地址的接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。接口名称由接口类型+接口编号组成。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。                                                                                                                                                                                                     |
| IFIPADDR   | IPv4地址   | 可选必选说明：必选参数 参数含义：该参数用于指定需要配置的接口IP地址。 数据来源：本端规划 取值范围：IPv4地址类型。0.0.0.0～255.255.255.255。 默认值：无 配置原则： IPv4地址不能配置为0.0.0.0、255.255.255.255和环回地址(127.0.0.1)。IPv4地址必须是A、B或者C类地址。IPv4地址在系统内必须唯一。本参数参与自动化配置，请在下发本命令前使用DSP OPSASSISTSTATE命令查询自动化配置维护助手autoscaling_autoconfig.py，确认当前设备是否在自动化配置过程中。如果当前正在自动化配置过程中，不要做本业务的增删改操作，否则最终生效的配置将不可预期。 |
| SUBNETMASK | IPv4地址掩码 | 可选必选说明：必选参数 参数含义：该参数用于指定需要配置的接口IPv4地址的网络掩码。 数据来源：本端规划 取值范围：IPv4地址类型。0.0.0.0～255.255.255.255。 默认值：无 配置原则： 使用网络规划的接口IP所属网段的掩码。除Loopback接口，Tunnel接口外，其它接口不能配置255.255.255.255的掩码。本参数参与自动化配置，请在下发本命令前使用DSP OPSASSISTSTATE命令查询自动化配置维护助手autoscaling_autoconfig.py，确认当前设备是否在自动化配置过程中。如果当前正在自动化配置过程中，不要做本业务的增删改操作，否则最终生效的配置将不可预期。           |
| ADDRTYPE   | IPv4地址类型 | 可选必选说明：可选参数 参数含义：该参数用于指定地址类型。 数据来源：本端规划 取值范围：枚举类型。 main：主地址。sub：从地址。 默认值：main                                                                                                                                                                                                                                                      |

#### 使用实例

配置LoopBack4的地址为192.168.1.1，地址掩码为255.255.255.0，类型为主地址：

```
ADD IFIPV4ADDRESS: IFNAME="LoopBack4", IFIPADDR="192.168.1.1", SUBNETMASK="255.255.255.0", ADDRTYPE=main;
```
