# 修改PCRF的域路由记录（MOD PREALMRT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于在配置数据库中修改一条PCRF实体的域路由记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
|:-------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PCRFID | PCRF标识  | 用于标识PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围：1 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                              |
| RID    | 路由标识    | 用于在UPCF的配置库中定义一个域路由。该参数的配置原则：如果配置多个对端域路由，从0开始顺序配置。 取值范围：0～29 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                  |
| RTN    | 域路由名称   | 域路由的名称。 取值范围：长度不超过128的字符串 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ITYPE  | 接口类型    | 用于指示路由对应的接口类型。 取值说明： GxRx(Gx&Rx&Sd)Sy(Sy) 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ISDFT  | 是否是默认路由 | 是否是默认路由，每种“接口类型”只能配置一条默认路由。 取值说明： YES(是)NO(否)  说明： 当从非默认路由修改为默认路由时，不支持“域名”配置。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                 |
| RN     | 域名      | 域名。 当“接口类型”配置为“GxRx(Gx&Rx&Sd)”时，该参数表示为PCEF/AF/TDF域名。当“接口类型”配置为“Sy(Sy)”时，该参数表示为OCS域名。 取值范围：长度不超过64的字符串 默认值：无。                                                                                                                                                                                                                                                                                                                                                                         |
| PSMODE | 对端选择方式  | 对端选择方式。 取值说明： MASTER_SLAVE（主备模式）：UPCF优选选择发送消息到主用DRA，当主用DRA故障时，发送消息到备用DRA。ROUND_ROBIN（轮询模式）：UPCF轮流选择DRA发送消息。USER_CTL（用户模式）：UPCF优先选择发送消息到原发送CCR消息的DRA，当原DRA故障时，再轮流选择其他正常DRA。 说明： 当参数“接口类型”取值为“GxRx(Gx&Rx&Sd)”时，“对端选择方式”才能设置为“USER_CTL”，其中Sd接口的“对端选择方式”不能设置为“USER_CTL”。当参数“是否是默认路由”取值为“YES”时，该参数不能设置为“USER_CTL”。当参数“对端选择方式”取值为“USER_CTL”时，不需要通过命令ADD PREALMPEERREL配置“对端标识”与“路由标识”关联关系。当参数“对端选择方式”取值为“USER_CTL”，会话从BSF的对端接入，即LST PEER查询到指定对端参数“是否BSF对端”为“TRUE”，“USER_CTL”取值将不会生效。 默认值：无。 |

## 使用实例

1. 修改PCRF的域路由记录。“PCRF标识”为“1”，“路由标识”为“0”，“域路由名称”改为“Route”。

   ```
   MOD PREALMRT: PCRFID=1, RID=0, RTN="Route";
   ```
2. 修改PCRF的域路由记录。“PCRF标识”为“1”，“路由标识”为“1”，“域路由名称”改为“Route0”，“是否是默认路由”改为“YES”，“对端选择方式”改为“ROUND\_ROBIN”。

   ```
   MOD PREALMRT: PCRFID=1, RID=1, RTN="Route0", ISDFT=YES, PSMODE=ROUND_ROBIN;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释           | 原因分析               | 处理建议                |
|------:|:----------------|:-------------------|:--------------------|
| 58139 | 参数“PSMODE”取值非法。 | “PSMODE”参数取值不符合要求。 | 检查参数取值，确保该取值遵循配置原则。 |
