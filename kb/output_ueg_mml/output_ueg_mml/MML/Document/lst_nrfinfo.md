# 查询NRF信息(LST NRFINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询NRF的信息。

**命令作用**：

- 若需要查询某个NRF的详细信息，请输入“NRF名称”参数；
- 若需要查询某个组中NRF的信息，请输入“NRF所属组信息”参数；
- 若需要查询所有NRF的信息，不输入任何参数。

## 注意事项

**命令生效条件**：执行该命令立即生效。

**其他注意事项**：无。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                                        |
|:-----------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NRFNAME    | NRF名称    | 可选必选说明：可选参数 参数含义：该参数在此场景下用于PCF在本端标识系统需要按照哪个“NRF名称”来查询NRF数据；若不输入，则表示所有的NRF。 取值范围：长度不超过32的字符串，只允许输入：0～9，a～z，A～Z，“-”和“_”。 参数来源：该参数全局唯一且需PCF与NRF端协商获取此参数名，通过ADD NRFINFO命令配置初始添加。 默认值：无。 配置原则：无。 |
| NRFGROUP   | NRF所属组信息 | 可选必选说明：可选参数 参数含义：用于PCF在本端标识系统需要按照哪个“NRF所属组信息”来查询NRF数据；若不输入，则表示所有的NRF。 取值范围：长度不超过32的字符串，只允许输入：0～9，a～z，A～Z，“-”和“_”。 参数来源：该参数仅由本端PCF自行定义，通过ADD NRFINFO命令配置初始添加。 默认值：无。 配置原则：无。                 |
| DURATION   | 超时时长     | 可选必选说明：可选参数 参数含义：用于指示系统需要按照“超时时长”来查询NRF数据；若不输入，则表示所有的NRF。 取值范围：5～10 单位：秒（s） 参数来源：该参数仅由本端PCF自行定义，通过ADD NRFINFO命令配置初始添加。 默认值：5。 配置原则：无。                                                       |
| TIMES      | 失败次数     | 可选必选说明：可选参数 参数含义：用于指示系统需要按照“失败次数”来查询NRF数据；若不输入，则表示所有的NRF。 取值范围：3～10 单位：次 参数来源：该参数仅由本端PCF自行定义，通过ADD NRFINFO命令配置初始添加。 默认值：3。 配置原则：无。                                                          |
| ENCODETYPE | 编码方式     | 可选必选说明：可选参数 参数含义：用于标识PCF与NRF之间通信消息内容的编码方式。 取值范围： NULL(NULL)：表示不编码。GZIP(GZIP)：表示消息内容以GZIP格式压缩后再发送。 参数来源：该参数仅由本端PCF自行定义，通过ADD NRFINFO命令配置初始添加。 默认值：无。 配置原则：无。                                 |

## 使用实例

1. 查询所有NRF信息：

   ```
   LST NRFINFO:;
   ```

   ```
   %%LST NRFINFO:;%% 
   RETCODE = 0  操作成功  
   操作结果如下 
   ------------ 
   NRF所属组信息  NRF名称  NRF URI                   优先级  超时时长  失败次数  编码方式
   nrfgroup-01    nrf-01   https://192.168.1.1:8080  2       5         3          NULL
   nrfgroup-01    nrf-02   https://192.168.1.1:8080  1       5         3          NULL
   nrfgroup-01    nrf-03   https://192.168.2.1:8080  3       5         3          NULL
   (结果个数 = 3)  
   ---    END
   ```
2. 查询特定NRF信息，“NRF名称”为“nrf-01”：

   ```
   LST NRFINFO: NRFNAME="nrf-01";
   ```

   ```
   %%LST NRFINFO: NRFNAME="nrf-01";%% 
   RETCODE = 0  操作成功  
   操作结果如下 
   ------------ 
   NRF所属组信息  =  nrfgroup-01       
   NRF名称  =  nrf-01       
   NRF URI  =  https://192.168.1.1:8080        
   优先级  =  2      
   超时时长  =  5      
   失败次数  =  3 
   编码方式 = NULL
   (结果个数 = 1)  
   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD NRFINFO**命令的参数说明。
