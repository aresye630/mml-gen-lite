# 增加对端网元静态信息（ADD PNFSTCINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于添加一条对端网元静态信息。

该命令的使用场景：当PCF与对端对接场景下上报ALM-34163 PCF与NF之间的HTTP链路故障、ALM-34231 PCF和NF通信故障告警时，该命令用于增加NF对端网元静态信息，以显示对端网元名称。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                       |
|:------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ID          | ID     | 可选必选说明：必选参数 参数含义：可用于标识对端网元ID。 取值范围：0~2000 默认值：无。 配置原则：本端统一规划。                                                                                                              |
| NFTYPE      | 网元类型   | 可选必选说明：必选参数 参数含义：用于标识对端网元类型。 取值范围： SMF(SMF) AMF(AMF) BSF(BSF) CHF(CHF) SCP(SCP) AF(AF)NWDAF(NWDAF)HPCF(HPCF)NRF(NRF) 默认值：无。 配置原则：无。                                        |
| IPVER       | IP版本   | 可选必选说明：必选参数 参数含义：用于指定对端网元的IP地址的IP版本类型。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。                                                                                           |
| IPV4IP      | IPv4地址 | 可选必选说明：条件必选参数 参数含义：当“IPVER”选择“IPV4(IPV4)”时该参数必须配置，用于表示对端网元的IPv4地址。 取值范围：IPv4地址 默认值：无。 配置原则：无。                                                                              |
| IPV6IP      | IPv6地址 | 可选必选说明：条件必选参数 参数含义：当“IPVER”选择“IPV6(IPV6)”时该参数必须配置，用于表示对端网元的IPv6地址。 取值范围：IPv6地址 默认值：无。 配置原则：无。                                                                              |
| NFINSTNAME  | 网元实例名称 | 可选必选说明：必选参数 参数含义：可用于标识对端网元的名称。 取值范围：长度不超过64的字符串。不允许输入字符，；=‘“和两个以及两个以上的空格。 默认值：无。 配置原则：本端统一规划。  说明： 当SET HTTPCLIENTCFG中“LINKCTLMODE”参数取值为“OLD(旧模式）”时，上报的告警不支持携带本参数“网元实例名称”。 |
| DESCRIPTION | 描述     | 可选必选说明：可选参数 参数含义：用于描述对端网元的IP地址的用途。 取值范围：0~128位字符串 默认值：无。 配置原则：无。                                                                                                           |

## 使用实例

1. 增加一条对端网元静态信息。“ID”为“0”，“网元类型”为“BSF”,“IP版本”为“IPV4(IPV4)”，“IPv4地址”为“192.168.0.130”，“网元实例名称”为“bsf0”。

   ```
   ADD PNFSTCINFO: ID=0, NFTYPE=BSF, IPVER=IPV4, IPV4IP="192.168.0.130",NFINSTNAME="bsf0";
   ```
2. 增加一条对端网元静态信息。“ID”为“6”，“网元类型”为“SMF”,“IP版本”为“IPV6(IPV6)”，“IPv6地址”为“2001:0db8:11ff:ffff:ffff:ffff:ffff:ffff”，“网元实例名称”为“smf6”。

   ```
   ADD PNFSTCINFO: ID=6, NFTYPE=SMF, IPVER=IPV6, IPV6IP="2001:0db8:11ff:ffff:ffff:ffff:ffff:ffff",NFINSTNAME="smf6";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释       | 原因分析            | 处理建议                                             |
|------:|:------------|:----------------|:-------------------------------------------------|
| 58230 | 相同的IP地址已存在。 | 输入的IP地址和已配置的重复。 | 执行LST PNFSTCINFO命令查询IP地址。重新输入IP地址，确保取值与查询结果中不重复。 |
