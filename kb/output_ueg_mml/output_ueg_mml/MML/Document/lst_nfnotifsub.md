# 查询网元默认通知订阅信息(LST NFNOTIFSUB)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询网元订阅通知信息。

- 若需要查询所有订阅通知信息，不输入任何参数。
- 若需要查询某个订阅通知的详细信息，请输入“索引”参数。
- 若需要查询某个组的订阅通知信息，请输入“组名称”参数。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                             |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------|
| GRPNAME | 组名称    | 可选必选说明：可选参数 参数含义：用于指示系统按照组名称标识来查询网元订阅通知信息；若不输入，则表示查询所有网元订阅通知信息。 取值范围：由数字、字母、“-”或“_”组成的长度不超过32的字符串 默认值：无。 配置原则：无。 |
| INDEX   | 索引     | 可选必选说明：可选参数 参数含义：用于指示系统按照索引标识来查询网元订阅通知信息；若不输入，则表示查询所有网元订阅通知信息。 取值范围：1~1024 默认值：无。 配置原则：无。                        |

## 使用实例

1. 查询所有的网元订阅通知信息：

```
LST NFNOTIFSUB:;
```

```
%%LST NFNOTIFSUB:;%% 
RETCODE = 0  操作成功
 
操作结果如下 
------------------------
组名称             索引  通知类型  回调URI                      N1消息类型  N2信息类型    
notifsub-group-01  1010  N1消息    https://192.168.16.5:31943   NULL        NULL         
nfnotifsub_01      101   N1消息    https://192.168.16.10:31943  NULL        NULL         

(结果个数 = 2)  
---    END
```

2. 查询“索引”为“101”的网元订阅通知信息：

```
LST NFNOTIFSUB: INDEX=101;
```

```
%%LST NFNOTIFSUB: INDEX=101;%% 
RETCODE = 0  操作成功   
  
操作结果如下 
------------------------
    组名称  =  nfnotifsub_01       
      索引  =  101   
  通知类型  =  N1消息    
   回调URI  =  https://192.168.16.10:31943 
N1消息类型  =  NULL 
N2信息类型  =  NULL 
(结果个数 = 1)  

---    END
```

3. 查询“组名称”为“101”的网元订阅通知信息：

```
LST NFNOTIFSUB: GRPNAME="nfnotifsub_01";
```

```
%%LST NFNOTIFSUB: GRPNAME="nfnotifsub_01";%%
RETCODE = 0  操作成功

操作结果如下 
------------------------
    组名称  =  nfnotifsub_01
      索引  =  101   
  通知类型  =  N1消息
   回调URI  =  https://192.168.16.10:31943 
N1消息类型  =  NULL 
N2信息类型  =  NULL 
(结果个数 = 1)  

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD NFNOTIFSUB**命令的参数说明。
