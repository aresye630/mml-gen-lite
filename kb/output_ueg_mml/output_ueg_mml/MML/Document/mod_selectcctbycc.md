# 修改基于CC配置融合计费模板处理（MOD SELECTCCTBYCC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF、SGW-C**

该命令用于修改基于CC配置融合计费模板处理。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称                       | 参数说明                                                                                                                                                                                                                                                      |
|:------------|:---------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CCTYPE      | CC类型                       | 可选必选说明：必选参数  参数含义：该参数用于指定计费属性。  数据来源：全网规划 取值范围： DEFAULT（未指定Charge Characteristic的值）VALUE（指定Charge Characteristic的值）  默认值：无  配置原则：无                                                                                                                        |
| CCVALUE     | Charge Characteristic值     | 可选必选说明：该参数在"CCTYPE"配置为"VALUE"时为条件必选参数。  参数含义：该参数用于指定特殊的CC值。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~6。该参数为十六进制数据类型，仅支持输入0x/X、a-f/A-F 、0-9，允许不输入0x前缀，字母不区分大小写，取值范围0x0000~0xFFFF。  默认值：无  配置原则：无                                                                    |
| MASK        | Charge Characteristic特定值掩码 | 可选必选说明：该参数在"CCTYPE"配置为"VALUE"时为条件可选参数。  参数含义：该参数用于指定CC的掩码，通过配置掩码可以实现全匹配CC值，还是只匹配部分bit位。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~6。该参数为十六进制数据类型，仅支持输入0x/X、a-f/A-F 、0-9，允许不输入0x前缀，字母不区分大小写，取值范围0x0001~0xFFFF。配置的计费属性掩码计费属性值参数做与运算后，需要等于计费属性值，否则配置失败。  默认值：无  配置原则：无 |
| PRIORITY    | Charge Characteristic优先级   | 可选必选说明：该参数在"CCTYPE"配置为"VALUE"时为条件可选参数。  参数含义：该参数用于设置优先级。配置mask时必须指定优先级，不允许指定相同的优先级。  数据来源：全网规划  取值范围：整数类型，取值范围是1~65535。  默认值：无  配置原则：  不配置此参数时值默认为0。                                                                                                      |
| CCTMPLTNAME | 融合计费模板名称                   | 可选必选说明：可选参数  参数含义：该命令用于指定融合计费模板（Converged Charging Template）名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。不区分大小写。  默认值：无  配置原则：  该参数使用ADD CCT命令配置生成。                                                                                                             |
| SERVINGCCT  | I-SMF/SGW使用的融合计费模板名称       | 可选必选说明：可选参数  参数含义：该命令用于指定I-SMF/SGW使用的融合计费模板（Converged Charging Template）名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~63。不区分大小写。  默认值：无  配置原则：  该参数使用ADD CCT命令配置生成。                                                                                                 |

## 使用实例

修改基于CC值为1234配置融合计费模板global处理：

```
MOD SELECTCCTBYCC: CCTYPE=VALUE, CCVALUE="1234", CCTMPLTNAME="global";
```
