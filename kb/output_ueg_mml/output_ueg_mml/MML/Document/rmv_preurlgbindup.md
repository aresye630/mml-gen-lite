# 删除用户模板的前缀URL组绑定关系（RMV PREURLGBINDUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，可能会影响业务。

该命令用于删除用户模板与前缀URL组的绑定关系。

#### 注意事项

- 本命令修改后对所有用户生效，大概五分钟之后生效。
- 如果不输入前缀URL组，则代表删除该UserProfile对应的所有前缀URL组。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称     | 参数说明                                                                                        |
|:----------------|:---------|:--------------------------------------------------------------------------------------------|
| USERPROFILENAME | 用户模板名称   | 可选必选说明：必选参数 参数含义：该参数用于设置用户模板名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无 |
| PREURLGRPNAME   | 前缀URL组名称 | 可选必选说明：可选参数 参数含义：该参数用于指定前缀URL组名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不区分大小写。 默认值：无 配置原则：无     |

#### 使用实例

删除前缀URL组与UserProfile的绑定关系，USERPROFILENAME为“testprofile1”，PREURLGRPNAME为“testurlgroup”：

```
RMV PREURLGBINDUP:USERPROFILENAME="testprofile",PREURLGRPNAME="testurlgroup";
```
