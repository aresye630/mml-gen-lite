# 查询Diameter接口配置(LST DIAMCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该用于查询DLB服务的Diameter接口配置信息。

- 若要查询全部对端的Diameter接口的配置信息，请不要输入任何参数。
- 若要查询某个对端的Diameter接口的配置信息，请输入“对端类型”。

**说明** 

产品暂不支持该命令功能，预埋显示此命令。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                  |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------|
| PEERTYPE | 对端类型   | 可选必选说明：可选参数 参数含义：用于指定Diameter接口的对端类型；若不输入，则表示查询所有的对端类型。 取值范围： PCEF(PCEF)AF(AF)OCS(OCS)TDF(TDF)DRA(DRA) 默认值：无。 配置原则：无。 |

## 使用实例

查询全部对端的Diameter接口的配置信息。

```
LST DIAMCFG:;
```

```
%%LST DIAMCFG:;%% 
RETCODE = 0  操作成功  
操作结果如下
------------------------ 
对端类型             消息非法重置开关
 AF                  Enable     
 PCEF                Enable
 OCS                 Enable
 DRA                 Enable
 TDF                 Enable
(结果个数 = 5) 
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，参数含义请参见参数说明。
