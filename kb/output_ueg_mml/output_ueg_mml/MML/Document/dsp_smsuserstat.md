# 显示CS粒度或DS粒度的用户数（DSP SMSUSERSTAT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMSF**

该命令用于显示CS粒度或DS粒度的用户数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识            | 参数名称        | 参数说明                                                                                                                                                                                            |
|:----------------|:------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| STATFUNCTYPE    | 统计目标的逻辑功能类型 | 可选必选说明：必选参数  参数含义：该参数用于表示统计目标的逻辑功能类型。  数据来源：本端规划 取值范围： “SMSF（短消息服务功能）”：短消息服务功能“VLR（拜访地位置寄存器）”：拜访地位置寄存器  默认值：无  配置原则：无                                                                           |
| STATGRANULARITY | 统计粒度的类型     | 可选必选说明：必选参数  参数含义：该参数用于表示统计粒度的类型。  数据来源：本端规划 取值范围： “CS（Cell服务）”：Cell服务“DS（Domain服务）”：Domain服务  默认值：无  配置原则：无                                                                                    |
| USERTYPE        | 用户类型        | 可选必选说明：该参数在"STATFUNCTYPE"配置为"VLR"时为条件可选参数。  参数含义：该参数用于表示查询的用户类型。  数据来源：本端规划 取值范围： “MOMT（签约MO或MT业务的用户）”：VLR全量用户表中签约MOMT业务的用户数“NON-MOMT（未签约MO和MT业务的用户）”：VLR全量用户表既未签约MO也未签约MT业务的用户数  默认值：无  配置原则：无 |

## 使用实例

当运营商希望查询CS粒度的VLR用户数，执行如下命令：

```
DSP SMSUSERSTAT: STATFUNCTYPE=VLR, STATGRANULARITY=CS;
%%DSP SMSUSERSTAT: STATFUNCTYPE=VLR, STATGRANULARITY=CS;%%
RETCODE = 0  操作成功

结果如下：
------------------------
                    统计结果对应的实体  =  CS1
                    统计实体上的用户数(个)  =  50

(结果个数 = 1)
```

## 输出结果说明

| 输出项名称        | 输出项解释             |
|:-------------|:------------------|
| 统计结果对应的实体    | 该参数用于表示统计结果对应的实体。 |
| 统计实体上的用户数(个) | 该参数用于表示统计实体上的用户数。 |
