## 命令功能

**须知** 

- 本命令属于高危命令，执行不当会造成业务全损，因此执行本命令前， 必须得到华为技术支持确认后才可以实施。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

客户端凭据断言（CCA）是由Consumer签名的令牌，接收端（NRF、Producer）可以通过服务请求中的CCA对Consumer进行身份验证。

本命令用于配置UDM作为Consumer时是否生成CCA、CCA的有效期以及UDM作为Producer时是否校验CCA。

## 注意事项

- UDM生成CCA依赖HLB证书中的实例ID，CCA的claim中参数不全或者错误，以及证书文件不满足3GPP 33.210中关于服务化接口证书的特有要求，都会使对端验证失败，导致接收端拒绝所有服务请求消息，因此生成CCA前请务必联系华为工程师确认影响。
- 校验CCA可能导致UDM拒绝对端的所有服务请求消息，校验CCA前请务必联系华为工程师确认影响。
- 生成CCA、校验CCA都会消耗HLB微服务的CPU和内存资源，生成CCA或校验CCA前请务必确保HLB微服务的CPU和内存资源足够。
- 生成的CCA携带证书套，会导致http消息包长度增加（至少增加证书套的长度，证书套长度由客户配置，可以达到正常消息的10倍以上），因此生成CCA前请务必确认周边网元支持超长http消息包并且带宽规划足够。

## 参数说明

| 参数标识              | 参数名称    | 参数说明                                                                                                                      |
|:------------------|:--------|:--------------------------------------------------------------------------------------------------------------------------|
| GENCCA            | 是否生成CCA | 可选必选说明：可选参数 参数含义：用于设置UDM作为Consumer时是否生成CCA。 取值范围： NotGen(不生成CCA)Gen(生成CCA) 系统初始设置值：NotGen(不生成CCA) 配置原则：无。                 |
| CCAVALIDITYPERIOD | CCA的有效期 | 可选必选说明：可选参数 参数含义：用于设置UDM作为Consumer时CCA的有效期。 取值范围：10~864000 单位：秒 系统初始设置值：86400 配置原则：该参数在“是否生成CCA”取值为“Gen(生成CCA)”时生效。       |
| CHECKCCA          | 是否检查CCA | 可选必选说明：可选参数 参数含义：用于设置UDM作为Producer时是否检查Consumer携带CCA。 取值范围： NotCheck(不校验CCA)Check(校验CCA) 系统初始设置值：NotCheck(不校验CCA) 配置原则：无。 |

## 使用实例

配置UDM作为Consumer时生成CCA：

```
SET CCACONF: GENCCA=Gen;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 100016 | 参数 CCAVALIDITYPERIOD 的值不在指定范围内 | 参数值不在参数定义的取值范围内。 | 请输入取值范围之内的参数值后重新执行本命令。 |
