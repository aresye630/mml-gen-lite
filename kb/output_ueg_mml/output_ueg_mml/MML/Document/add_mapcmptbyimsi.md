# 增加MAP协议接口兼容性IMSI号段配置(ADD MAPCMPTBYIMSI)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

- 该命令用于设置MAP协议接口兼容性IMSI号段配置。

#### 注意事项

- 该命令最大记录数为8192。
- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称             | 参数说明                                                                                                                                                                                                                                                                                                                                                      |
|:---------|:-----------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围             | 可选必选说明：必选参数 参数含义：该参数用于指定MAP兼容性参数策略的用户范围。 数据来源：全网规划 取值范围：“FOREIGN_USER(外网用户)”“HOME_USER(本网用户)”“IMSI_PREFIX(指定IMSI前缀)” 默认值：无 配置原则：MAP参数策略优先级从高到低为：“IMSI_PREFIX(指定IMSI前缀)”，“FOREIGN_USER(外网用户)”或“HOME_USER(本网用户)”，“ALL_USER(所有用户)”。系统优先查找高优先级的配置记录，如果查找不到，再查找低优先级的配置记录。  说明： 系统开工时缺省增加了“ALL_USER(所有用户)”的记录。                                                  |
| NOID     | 运营商标识            | 可选必选说明：条件必选参数 参数含义：该参数用于指定运营商标识。 前提条件：该参数在“用户范围”参数配置为“FOREIGN_USER(外网用户)”或“HOME_USER(本网用户)”后生效。 数据来源：全网规划 取值范围：0～64，128～254 默认值：无 配置原则：当用户为MNO用户时，该参数需要配置为0或128～254之间的值，该取值必须和ADD MNO配置的“MNOID”参数取值相同。当用户为MVNO用户时，该参数需要配置为1～64之间的值，该取值必须和ADD MVNO中配置的“MVNOID”参数取值相同。  说明： 对于外网用户，该参数是与其归属运营商签订可漫游协议，为其提供服务的MNO/MVNO运营商标识。对于本网用户，该参数是为该用户归属的MNO/MVNO运营商标识。 |
| IMSIPRE  | IMSI前缀           | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI前缀。 前提条件：该参数在“用户范围”参数配置为“IMSI_PREFIX(指定IMSI前缀)”后生效。 数据来源：全网规划 取值范围：1～15位十进制数字字符串。 默认值：无  说明： IMSI前缀的匹配方式采取由前向后的最长匹配，即若对于用户可以匹配到多个用户群，则使用IMSI前缀最长的用户群配置。                                                                                                                                                                     |
| SF       | 特性列表             | 可选必选说明：可选参数 参数含义：该参数表示SGSN给HLR发送的Update Location Request消息中的Supported-Features信元中设置的比特位，每个比特位表示SGSN支持的一种功能（目前仅支持第39比特“支持DCNR”），详细说明请参照3GPP 29.002。 数据来源：全网规划 取值范围：“NR_AS_SECONDARY_RAT(支持双连接)” 默认值：“NR_AS_SECONDARY_RAT (支持双连接)”                                                                                                                          |
| NODCNR   | 未签约DCNR是否支持高速用户面 | 可选必选说明：可选参数 参数含义：该参数用于控制是否支持选择高速用户面。 数据来源：全网规划 取值范围：“NO（否）”“YES（是）” 默认值：“NO（否）”                                                                                                                                                                                                                                                                           |

#### 使用实例

配置方式：添加一条“用户范围”为“IMSI\_PREFIX(指定IMSI前缀)”，“IMSI前缀”为“123456789”，“特性列表”为“NR\_AS\_SECONDARY\_RAT(支持双连接)”，“未签约DCNR是否支持高速用户面”为“NO（否）”的记录。

ADD MAPCMPTBYIMSI: SUBRANGE=IMSI\_PREFIX, IMSIPRE="123456789", SF=NR\_AS\_SECONDARY\_RAT-1, NODCNR=NO;
