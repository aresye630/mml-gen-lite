# 删除引入路由聚合配置（RMV OSPFASBRSUMMARY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于取消ASBR对OSPF引入的路由进行路由聚合。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                      |
|:------------|:-------|:------------------------------------------------------------------------------------------|
| PROCID      | 进程号    | 可选必选说明：必选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 配置原则：OSPF进程必须已经存在。 |
| TOPOID      | 拓扑标识   | 可选必选说明：必选参数 参数含义：拓扑标识。 数据来源：全网规划 取值范围：整数类型，取值范围为0。 默认值：无 配置原则：目前只支持默认拓扑0。                 |
| IPADDRESS   | IP地址   | 可选必选说明：必选参数 参数含义：IP地址。 数据来源：本端规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无                             |
| ADDRESSMASK | 地址掩码   | 可选必选说明：必选参数 参数含义：地址掩码。 数据来源：本端规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无                             |

#### 使用实例

取消OSPF进程1下引入10.1.0.0的路由聚合：

```
RMV OSPFASBRSUMMARY:PROCID=1,TOPOID=0,IPADDRESS="10.1.0.0",ADDRESSMASK="255.255.0.0";
```
