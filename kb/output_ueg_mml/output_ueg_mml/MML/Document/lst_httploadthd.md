# 查询HTTP2链路负荷过载阈值(LST HTTPLOADTHD)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询HLB服务实例负荷过载告警的上报阈值和恢复阈值。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询HLB服务实例负荷过载告警的上报阈值和恢复阈值信息：

```
LST HTTPLOADTHD:;
```

```
%%LST HTTPLOADTHD:;%%
RETCODE = 0  操作成功

操作结果如下:
-------------
HLB服务负荷过载阈值(%)  =  80
HLB服务过载恢复阈值(%)  =  75

(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET HTTPLOADTHD**命令的参数说明。
