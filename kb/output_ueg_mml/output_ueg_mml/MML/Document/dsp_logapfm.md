# 显示日志代理性能统计信息（DSP LOGAPFM）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示日志代理性能统计信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| PROCESSID       | 进程ID   | 可选必选说明：可选参数 参数含义：用来表示进程ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                      |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

显示日志代理性能统计信息：

```
DSP LOGAPFM:SERVICEINSTANCE="vnfc";
```


#### 输出结果说明

| 输出项名称      | 输出项解释               |
|:-----------|:--------------------|
| 进程ID       | 用来表示进程ID。           |
| 日志数量       | 用来表示日志数量。           |
| 日志处理时间（毫秒） | 用来表示日志处理时间，单位为毫秒。   |
| 消息数量       | 用来表示发送消息数量。         |
| 消息处理时间（毫秒） | 用来表示发送消息处理时间，单位为毫秒。 |
