# 修改MEP HTTP客户端（MOD MEPHTTPCLIENT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

该命令用于修改MEP HTTP客户端。

#### 注意事项

- 该命令执行后立即生效。
- 如果本客户端已被关联至某个反向代理对象，修改会对关联本客户端的所有反向代理对象生效。
- 修改IP地址信息时，需确保修改后的IP地址在MPF逻辑接口信息中存在，可以通过LST MPFLOGICINF命令查询具体MPF逻辑接口信息。否则，修改MEP HTTP客户端命令会因IP地址不存在而下发失败。
- 当MPF逻辑接口由配置IPv4和IPv6变更为仅配置IPv4或者IPv6时，需要使用本命令将MEP HTTP客户端中的IP地址修改为新配置的IP地址。同时，需要在不再支持的“IPv4地址”或“IPv6地址”项处输入“0”清空原有配置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识               | 参数名称          | 参数说明                                                                                                                                                                                                                                                                         |
|:-------------------|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CLIENTNAME         | MEP HTTP客户端名称 | 可选必选说明：必选参数 参数含义：该参数用于指定MEP HTTP客户端名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“.”组成，且只能以字母或者数字开头。 默认值：无 配置原则：无                                                                                                                                                       |
| MEPHTTPCLIENTGRP   | MEP HTTP客户端组  | 可选必选说明：可选参数 参数含义：该参数用于指定本MEP HTTP客户端所属MEP HTTP客户端组的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则： 该参数使用ADD MEPHTTPCLIENTGRP命令配置生成。输入单空格将删除该参数已有配置项。                                                                                                                       |
| IPV4               | IPv4地址        | 可选必选说明：可选参数 参数含义：该参数用于指定IPv4地址。 数据来源：全网规划 取值范围：IPv4地址类型。0.0.0.0～255.255.255.255。 默认值：无 配置原则： 对于“TO_CONNECT_EXTERNAL_NE”类型的MEP HTTP客户端而言IPV4和IPV6最少配置一个，地址配置必须通过运行ADD MPFLOGICINF命令来完成。其余场景不需要配置IP。输入0将删除该参数已有配置项。                                                            |
| IPV6               | IPv6地址        | 可选必选说明：可选参数 参数含义：该参数用于指定IPv6地址。 数据来源：全网规划 取值范围：IPv6地址类型。冒号分十六进制，格式为X:X:X:X:X:X:X:X。除了组播地址、链路本地地址、环回地址或未指定的地址为非法地址外，其他都为合法地址。 默认值：无 配置原则： 对于“TO_CONNECT_EXTERNAL_NE”类型的MEP HTTP客户端而言IPV4和IPV6最少配置一个，地址配置必须通过运行ADD MPFLOGICINF命令来完成。其余场景不需要配置IP。输入0将删除该参数已有配置项。                |
| TLSFLG             | 是否启用TLS       | 可选必选说明：可选参数 参数含义：该参数用于指定MEP HTTP客户端是否启用加密传输功能。 数据来源：对端协商 取值范围： ENABLE：使能TLS。DISABLE：不使能TLS。 默认值：无 配置原则：建议设置为ENABLE。如果设置为DISABLE，则报文将会以明文进行传输，存在信息泄露的风险，请谨慎设置。                                                                                                                |
| TLSPARANAME        | TLS参数名称       | 可选必选说明：条件必选参数 前提条件：该参数在“TLSFLG”配置为“ENABLE”时为必选参数。 参数含义：该参数用于指定MEP HTTP客户端所使用的TLS参数名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“.”组成，且只能以字母或者数字开头。 默认值：无 配置原则：该参数使用ADD MEPTLSPARA命令配置生成。                                                                               |
| CLIENTCOMMPARANAME | HTTP客户端通信参数名称 | 可选必选说明：可选参数 参数含义：该参数用于指定本客户端所使用的HTTP客户端通信参数的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“.”组成，且只能以字母或者数字开头。 默认值：无 配置原则： 该参数使用ADD MEPCLIENTCOMMPARA命令配置生成。输入单空格将删除该参数已有配置项。                                                                                            |

#### 使用实例

修改MEPHTTPCLIENT对象，修改的MEPHTTPCLIENT对象名称为"client"，隶属的客户端组名修改为"clientgrp"，IPV4地址修改为"192.168.1.1"，TLS参数是否使用修改为"ENABLE"，使用的TLS参数名修改为"tls"，修改HTTP客户端通信参数为"DefaultClientPara"，修改对端服务标签为"MEPSERVICE"：

```
MOD MEPHTTPCLIENT: CLIENTNAME="client", MEPHTTPCLIENTGRP="clientgrp", IPV4="192.168.1.1", TLSFLG=ENABLE, TLSPARANAME="tls", CLIENTCOMMPARANAME="DefaultClientPara", PEERSERVICETAG=MEPSERVICE;
```
