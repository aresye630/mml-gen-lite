# 显示AMF自运行授权状态（DSP EDGEAMSELFRUNAUTHSTAT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于显示AMF自运行授权状态。

## 注意事项

仅当状态为自运行时，剩余时间才有意义。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

显示AMF自运行授权状态，执行如下命令：

```
DSP EDGEAMSELFRUNAUTHSTAT:;
RETCODE = 0  操作成功

结果如下
------------------------
     状态  =  未启动自运行
 剩余时间  =  15
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                     |
|:--------|:--------------------------------------------------------------------------|
| 状态      | 自运行状态。 取值说明： “NotSelfRun（未启动自运行）”：未启动自运行“SelfRun（自运行）”：自运行“Locked（锁定）”：锁定 |
| 剩余时间    | 自运行授权剩余时长。                                                                |
