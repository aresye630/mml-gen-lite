# 查询APN Serving PLMN速率控制配置（LST APNPLMNRATECTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SGW-C**

该命令用于查询基于APN的Serving PLMN速率控制功能配置信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                           |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN    | APN名称  | 可选必选说明：可选参数  参数含义：该参数用于指定APN实例名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无  配置原则：  该参数使用ADD CPAPN命令配置生成。 |

## 使用实例

查询APN名称为test下的PLMN速率显示：

```
%%LST APNPLMNRATECTRL: APN="test";%%
RETCODE = 0  操作成功

结果如下
--------
                         APN  =  test
APN Serving PLMN速率控制开关  =  不使能
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称                  | 输出项解释                                |
|:-----------------------|:-------------------------------------|
| APN名称                  | 该参数用于指定APN实例名。                       |
| APN Serving PLMN速率控制开关 | 该参数用于基于APN控制开启和关闭Serving PLMN速率控制功能。 |
