# 增加FWA用户规则ID配置（ADD FWARULEID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响FWA用户识别。

本命令用于增加一条FWA用户规则ID配置记录。

该命令的使用场景：部署“FWA license统计”特性后，UPCF需要根据本命令的设置识别FWA用户。UPCF在识别FWA用户时，会根据“匹配类型”的设置将用户签约业务中生效规则的pccRuleId与本命令中的“关键字”进行匹配，如果匹配成功，则判断为FWA用户。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                      |
|:------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ID          | ID     | 可选必选说明：必选参数。 参数含义：表示FWA用户规则ID配置的记录标识。 取值范围：0～19 默认值：无。 配置原则：无。                                                                                                                                                            |
| KEYWORD     | 关键字    | 可选必选说明：必选参数。 参数含义：表示识别FWA用户的匹配字段。 取值范围：长度不超过255的字符串 默认值：无。 配置原则：无。                                                                                                                                                        |
| MATCHTYPE   | 匹配类型   | 可选必选说明：必选参数。 参数含义：表示识别FWA用户的匹配类型。 取值范围： FULL(全匹配)：UPCF会将用户签约业务中生效规则的pccRuleId与“关键字”进行全匹配（忽略大小写），如果完全一致，则全匹配成功。SUBSTRING(子字符串匹配)：UPCF会将用户签约业务中生效规则的pccRuleId与“关键字”进行子字符串匹配（忽略大小写），如果pccRuleId包含“关键字”，则匹配成功。 默认值：无。 配置原则：无。 |
| DESCRIPTION | 描述     | 可选必选说明：可选参数。 参数含义：用于对FWA用户规则ID配置记录的描述。 取值范围：长度不超过128的字符串 默认值：无。 配置原则：无。                                                                                                                                                   |

## 使用实例

增加FWA用户规则ID配置。“ID”为“0”，“关键字”为“fwa123”，“匹配类型”为“SUBSTRING(子字符串匹配)”。

```
ADD FWARULEID: ID=0, KEYWORD="fwa123", MATCHTYPE=SUBSTRING;
```
