# 同步外置SPR数据(SYN SPRDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于同步外置SPR的用户数据到UPCF。系统通过该命令可以触发查询和更新外置SPR数据，提升UPCF产品可维护能力。

## 注意事项

- 该命令不允许进行批操作。
- 如果在某用户上线期间执行了本命令，参数为该用户标识，可能会导致用户连接数据网失败，此时用户重新上线即可恢复正常。
- 对某用户执行本命令后，会立即将该用户的用户数据从外置SPR同步到本地SPR，但此操作不会触发MCI消息去通知UPCF进行用户数据的策略更新。用户数据的策略更新以外置SPR中的数据为准。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                     |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBID  | 用户标识   | 可选必选说明：必选参数 参数含义：用于指示系统需要同步哪个用户标识的外置SPR数据。 取值范围：长度不超过255的字符串。 默认值：无。 配置原则：该参数必须先由ADD PSUB命令定义，然后才能在此处使用。  说明： 用户可通过登录PGW Web LMT MML命令界面，执行LST PSUB查询外置SPR用户数据是否同步到UPCF。 |

## 使用实例

同步“用户标识”为“861234567\*\*\*\*”的外置SPR数据。

```
SYN SPRDATA: SUBID="861234567****";
```

```
%%SYN SPRDATA: SUBID="861234567****";%%
RETCODE = 0  操作成功  

---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                       | 原因分析            | 处理建议                                                                                  |
|------:|:----------------------------|:----------------|:--------------------------------------------------------------------------------------|
| 58068 | 加载的SPR配置文件不支持SYN SPRDATA命令。 | 没有加载正确的SPR配置文件。 | 执行命令DSP SPRCFG查询是否已加载正确的外置SPR配置文件。是 => 请联系华为技术工程师。否 => 请执行命令LOD SPRCFG加载正确的外置SPR配置文件。 |
