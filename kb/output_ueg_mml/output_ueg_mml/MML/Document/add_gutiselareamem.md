# 增加GUTI选网功能区域成员（ADD GUTISELAREAMEM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

一个GUTI选网功能的区域由若干个跟踪区组成，该命令用于为指定的区域增加跟踪区成员。

在大网和园区共享RAN场景下，大网AMF可以通过本地配置将园区用户在大网AMF注册成功后，通过分配给园区用户的GUTI中携带园区AMF的SET ID和POINTER的方式将园区用户重新注册到园区AMF上。

## 注意事项

- 该命令执行后立即生效。

- GUTISELAREAMEM重叠是指两条GUTISELAREAMEM记录中MCC和MNC都相等，且TAC范围有重叠。
- 不同配置记录的GUTISELAREAMEM记录之间不能重叠。
- 最多可输入4096条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称         | 参数说明                                                                                                                                                                                                |
|:----------------|:-------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GUTISELAREACODE | GUTI选网功能区域编码 | 可选必选说明：必选参数  参数含义：该参数用于标识AMF服务的某区域范围。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~128。  默认值：无  配置原则：  GUTISELAREACODE参数依赖于GUTISELAREACODE命令的GUTISELAREACODE参数。                                                  |
| MCC             | MCC          | 可选必选说明：必选参数  参数含义：该参数用于表示组成通用区域的位置区成员的移动国家码，与无线接入网的MCC一致。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                                                             |
| MNC             | MNC          | 可选必选说明：必选参数  参数含义：该参数用于表示组成通用区域的位置区成员的移动网号，与无线接入网的MNC一致。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：  两条记录间的MCC相同时，2位MNC与3位MNC的前两个数字不能相同。                                      |
| BGNTAC          | 跟踪区编码起始值     | 可选必选说明：必选参数  参数含义：该参数用于表示跟踪区编码的起始值。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。TAC编码为16进制数，按照字符串格式输入，字符串长度为6，只能由数字（0-9），字母（A-F、a-f）组成。字母大小写不敏感。  默认值：无  配置原则：无                                                   |
| ENDTAC          | 跟踪区编码结束值     | 可选必选说明：可选参数  参数含义：该参数用于表示跟踪区编码的结束值。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。TAC编码为16进制数，按照字符串格式输入，字符串长度为6，只能由数字（0-9），字母（A-F、a-f）组成。字母大小写不敏感。本参数表示的跟踪区编码不能小于“跟踪区编码起始值”。当本参数不输入时，系统默认赋值为BGNTAC值。  默认值：无  配置原则：无 |
| DESC            | 描述信息         | 可选必选说明：可选参数  参数含义：该参数是对区域成员的描述信息，在运维中起到助记的作用。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~32。  默认值：无  配置原则：无                                                                                                    |

## 使用实例

为编码为“GUTISelZone”的区域增加一个跟踪区（MCC="123", MNC="45", TAC="120101"），执行如下命令：

```
ADD GUTISELAREAMEM: GUTISELAREACODE="GUTISelZone", MCC="123", MNC="45", BGNTAC="120101";
```
