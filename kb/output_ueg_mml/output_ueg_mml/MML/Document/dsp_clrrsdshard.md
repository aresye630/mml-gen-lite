# 显示迁移残留分片清理状态(DSP CLRRSDSHARD)

## 命令功能

该命令用于显示清理迁移残留分片数据任务状态信息。

## 注意事项

执行该命令前，需确保DUS微服务实例的“实例状态”均为“初始化完成”。可通过**DSP DUSSTAT**命令查看DUS微服务实例的“实例状态”。

## 参数说明

| 参数ID    | 参数名称      | 参数描述                                                                                                                                               |
|:--------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
| APPTYPE | 应用类型      | 可选必选说明：必选参数 参数含义：用于请求系统显示哪个应用类型的迁移残留分片数据清理任务的状态信息。 取值范围：需要与LST APPTYPE的“应用类型”对应。 默认值：无。 配置原则：无。                                                    |
| CID     | Cluster标识 | 可选必选说明：可选参数。 参数含义：用于请求系统显示哪个DUS Cluster标识的迁移残留分片数据清理任务的状态信息；若不输入，则表示所有的DUS Cluster标识。DUS Cluster标识可以通过DSP DUSSTAT进行查看。 取值范围：1～65535 默认值：无。 配置原则：无。 |

DSP CLRRSDSHARD: APPTYPE="SUP-DUS";

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。各输出项含义请参见表1输出项解释的参数说明。

| 输出项名称     | 输出项解释                                          |
|:----------|:-----------------------------------------------|
| Cluster标识 | 用于返回迁移残留分片数据清理任务的Cluster标识。                    |
| 应用类型      | 用于返回迁移残留分片数据清理任务的应用类型。                         |
| 实例ID      | 用于返回迁移残留分片数据清理任务的实例ID。                         |
| 启动时间      | 用于返回迁移残留分片数据清理任务的启动时间。                         |
| 命令执行结果    | 用于返回迁移残留分片数据清理任务的命令执行结果。 取值范围：成功失败             |
| 残留分片清理状态  | 用于返回迁移残留分片数据清理任务的残留分片清理状态。 取值范围：已清理正在清理正在校验未启动 |
| 表名        | 用于返回迁移残留分片数据清理任务清理的表名。                         |
| 总对象数量     | 用于返回迁移残留分片数据清理任务中对应表的总对象数量。                    |
| 已清理对象数量   | 用于返回迁移残留分片数据清理任务中对应表的已清理对象数量。                  |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释       | 原因分析               | 处理建议                                                             |
|------:|:------------|:-------------------|:-----------------------------------------------------------------|
| 67996 | 服务未全部就绪。    | DUS状态异常。           | 执行DSP DUSSTAT命令查看“实例状态”，确保所有“实例状态”均为“初始化完成”后再执行该命令。              |
| 68003 | Cluster不存在。 | 输入的“Cluster标识”不存在。 | 执行DSP DUSSTAT命令查询系统中存在的DUS Cluster标识，输入已存在的“Cluster标识”然后重新执行该命令。 |
| 67822 | 指定的应用类型不存在。 | 输入的“应用类型”不存在。      | 执行LST APPTYPE命令查询已存在的“应用类型”，输入已存在的“应用类型”然后重新执行该命令。               |
