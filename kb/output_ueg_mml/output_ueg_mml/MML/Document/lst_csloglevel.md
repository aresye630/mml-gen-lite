# 查询日志输出级别（LST CSLOGLEVEL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此命令用于查询日志输出级别。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询日志输出级别：

```
%%LST CSLOGLEVEL:;%%
RETCODE = 0  操作成功

结果如下
--------
日志级别  =  调试级别
(结果个数 = 1)

---    END
```
