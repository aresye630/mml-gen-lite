# 删除CP节点信息（RMV CPNODE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

在执行此命令前必须先使用RMV CPPOINT命令删除所有相关CPPOINT。

删除CP节点会造成在此CP节点上建立的连接断开，造成会话中断。

**适用NF：SMF、PGW-C、SGW-C、GGSN**

该命令用于删除指定索引编号的CP节点。

## 注意事项

- 该命令执行后立即生效。

- 在执行此命令前必须先使用RMV CPPOINT命令删除所有相关CPPOINT。
- 删除CP节点会造成在此CP节点上建立的连接断开，造成会话中断。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                          |
|:------------|:-------|:------------------------------------------------------------------------------|
| CPNODEINDEX | CP节点索引 | 可选必选说明：必选参数  参数含义：该参数用于指定CP节点索引。  数据来源：全网规划  取值范围：整数类型，取值范围为0。  默认值：无  配置原则：无 |

## 使用实例

删除索引为0的CP节点：

```
RMV CPNODE:CPNODEINDEX=0;
```
