# 删除SM上下文（RMV SMCTX）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C、SMF、GGSN**

该命令用于删除SM上下文。

## 注意事项

- 该命令执行后立即生效。

- 该命令仅用于内部调测，不对外使用。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称       | 参数说明                                                                                                                              |
|:-------------|:-----------|:----------------------------------------------------------------------------------------------------------------------------------|
| IMSI         | 国际移动用户识别码  | 可选必选说明：该参数在"RMVTYPE"配置为"IMSI"时为条件必选参数。  参数含义：该参数用于指示国际移动用户标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是5~15。  默认值：无  配置原则：无                  |
| KEYTYPE      | 键值类型       | 可选必选说明：可选参数  参数含义：该参数用于指定会话删除类型。  数据来源：本端规划 取值范围： NSAPI（网络层服务接入点标识）LBI（4G缺省承载ID）PDUSESSIONID（PDU会话ID）  默认值：无  配置原则：无              |
| NSAPI        | 网络层服务接入点标识 | 可选必选说明：该参数在"KEYTYPE"配置为"NSAPI"时为条件必选参数。  参数含义：该参数用于指示网络层服务接入点标识。  数据来源：本端规划  取值范围：整数类型，取值范围是1~15。  默认值：无  配置原则：无                  |
| LBI          | LBI        | 可选必选说明：该参数在"KEYTYPE"配置为"LBI"时为条件必选参数。  参数含义：该参数用于指示链接的EPS承载标识。  数据来源：全网规划  取值范围：整数类型，取值范围是1~15。  默认值：无  配置原则：无                    |
| PDUSESSIONID | PDU会话ID    | 可选必选说明：该参数在"KEYTYPE"配置为"PDUSESSIONID"时为条件必选参数。  参数含义：该参数用于指示PDU会话标识。  数据来源：全网规划  取值范围：整数类型，取值范围是1~15。  默认值：无  配置原则：无              |
| NOTIFYUE     | 是否通知终端     | 可选必选说明：可选参数  参数含义：该参数用于指示是否通知终端。  数据来源：本端规划  取值范围： TRUE(TRUE)FALSE(FALSE)  默认值：无  配置原则：无                                          |
| FORCEDEL     | 指定用户删除方式   | 可选必选说明：可选参数  参数含义：该参数用于指定删除用户的方式。  数据来源：本端规划  取值范围： TRUE(TRUE)FALSE(FALSE)  默认值：无  配置原则：无                                         |
| IMEI         | IMEI       | 可选必选说明：该参数在"RMVTYPE"配置为"IMEI"时为条件必选参数。  参数含义：该参数用于指定国际移动设备标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是15~16。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无 |
| RMVTYPE      | 删除方式       | 可选必选说明：可选参数  参数含义：该参数用于指定删除的类型。  数据来源：本端规划 取值范围： “IMSI（IMSI）”：按IMSI删除用户“IMEI（IMEI）”：按IMEI删除用户  默认值：IMSI  配置原则：无                   |

## 使用实例

删除指定IMSI的PDUSESSION

```
RMV SMCTX:RMVTYPE = IMSI,  IMSI="351521004992889";
```
