# 查询N15策略优先级（LST N15SRVPRIO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询N15策略优先级。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                     |
|:-----------|:-------|:---------------------------------------------------------|
| POLICYTYPE | 策略类型   | 可选必选说明：可选参数。 参数含义：用于设置策略类型。 取值范围：AM(AM策略) 默认值：无。 配置原则：无。 |

## 使用实例

查询已配置的N15策略优先级参数信息。

```
LST N15SRVPRIO:;
```

```
%%LST N15SRVPRIO:;%% 
RETCODE = 0  操作成功 

结果如下
------------------------ 
归属地AM策略优先 = UELOGO
        策略类型 = AM策略
(结果个数 = 1)

 ---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。

各参数含义请参见设置N15策略优先级（SET N15SRVPRIO）命令的参数说明。
