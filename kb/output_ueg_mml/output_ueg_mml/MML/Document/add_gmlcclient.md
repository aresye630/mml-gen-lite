# 增加GMLC和LCS Client对照关系(ADD GMLCCLIENT)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

此命令用于增加GMLC和LCS CLIENT的对照关系。在移动始发的位置业务中，SGSN根据手机发送信息中携带的LCS CLIENT信息，查询此表，获得对应的GMLC。

#### 注意事项

- 此命令执行后立即生效。
- 此命令最大记录数是8192。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                                     |
|:----------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------|
| CLIENTNUM | LCS客户端号码 | 可选必选说明：必选参数 参数含义：该参数用于指定LCS Client Number，是LCS客户端的E.164地址。 数据来源：整网规划 取值范围：1～16位十进制数字 默认值：无 配置原则：一个LCS CLIENT号码只能对应一个GMLC号码，但一个GMLC号码可以与多个LCS CLIENT号码对应。 |
| GMLCNUM   | GMLC号码   | 可选必选说明：必选参数 参数含义：该参数用于指定GMLC号码。 数据来源：整网规划 取值范围：1～16位十进制数 默认值：无                                                                                           |

#### 使用实例

增加GMLC和LCS CLIENT的对照关系，LCS CLIENT的号码为861380123456789，GMLC的号码为861390123456789：

ADD GMLCCLIENT: CLIENTNUM="861380123456789", GMLCNUM="861390123456789";
