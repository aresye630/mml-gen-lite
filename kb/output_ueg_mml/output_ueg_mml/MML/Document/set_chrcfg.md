# 设置CHR配置（SET CHRCFG）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于系统在上报CHR单据时，配置单据采集及订阅的流程。

#### 注意事项

- 系统初次运行时，会执行系统初始设置值。
- 本命令执行后立即生效。
- CHR冲突流程处理目前只对4G用户生效。
- 当软参BYTE\_EX\_B53 BIT2设置为“1”时，NSA协商失败的流程都会上报CHR，上报流程不受该命令控制。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组
