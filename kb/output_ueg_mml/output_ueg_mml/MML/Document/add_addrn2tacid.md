# 增加N2TAC组内N2TAC号段（ADD ADDRN2TACID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：GGSN、SMF、PGW-C**

该命令用来在N2TAC组内绑定N2TAC号段。当需要在指定N2TAC组内绑定某个N2TAC号段时，使用该命令。

## 注意事项

- 该命令执行后只对新激活用户生效。

- 当一个N2TAC号段被绑定到某个N2TAC组内后，就不允许再绑定到其他的N2TAC组。
- N2TAC号段之间的N2TAC值不允许重叠。

- 最多可输入16000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称      | 参数说明                                                                                                                                                                                     |
|:-------------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TACGROUPNAME | N2TAC组名   | 可选必选说明：必选参数  参数含义：该参数用于指定N2TAC组名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。  默认值：无  配置原则：  该参数使用ADD ADDRTACGROUP命令配置生成。                                                                        |
| TACSECNUM    | N2TAC段编号  | 可选必选说明：必选参数  参数含义：该参数用于指定N2TAC段编号。  数据来源：本端规划  取值范围：整数类型，取值范围是0~15999。  默认值：无  配置原则：无                                                                                                    |
| TACSTARTID   | N2TAC起始ID | 可选必选说明：必选参数  参数含义：该参数用于指定N2TAC起始ID。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~10。十六进制，仅支持输入0x/X、a-f/A-F 、0-9，允许不输入0x前缀，字母不区分大小写，取值范围0x000000~0xFFFFFF。  默认值：无  配置原则：  TACSTARTID的取值应小于或等于TACENDID。 |
| TACENDID     | N2TAC终止ID | 可选必选说明：必选参数  参数含义：该参数用于指定N2TAC终止ID。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~10。十六进制，仅支持输入0x/X、a-f/A-F 、0-9，允许不输入0x前缀，字母不区分大小写，取值范围0x000000~0xFFFFFF。  默认值：无  配置原则：  TACENDID的取值应大于或等于TACSTARTID。 |

## 使用实例

在一个本地已经配置的N2TAC组绑定一个N2TAC号段：

```
ADD ADDRN2TACID:TACGROUPNAME="wz-sq",TACSECNUM=2,TACSTARTID="0x000001",TACENDID="0x00001F";
```
