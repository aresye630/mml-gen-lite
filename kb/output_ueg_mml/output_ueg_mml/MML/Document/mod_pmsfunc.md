# 修改策略管理服务功能配置(MOD PMSFUNC)

- 命令功能

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响PMS业务处理，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于修改或调整策略管理服务功能配置信息，如通过该命令可以配置FTP协议参数、WebUI会话锁定自动注销超时时间参数、监控信息参数、和服务器安全认证参数。

## 注意事项

- 一般情况下，操作员使用默认值。如果操作员确实需要修改参数配置，请咨询华为公司技术服务工程师，禁止随意修改。
- 在缺省的情况下，系统在初始化的时候已经预置了配置数据表中的全部数据。操作员可以通过执行**LST PMSFUNC**命令，查询预置的配置信息。

## 使用实例

修改一个PMS的功能配置数据。

1. 执行命令**MOD PMSFUNC**，“配置类型”设置为“Server”，“配置项名称”设置为“ciphers”，“配置项值”设置为“TLS\_DHE\_RSA\_WITH\_AES\_128\_GCM\_SHA256&TLS\_DHE\_RSA\_WITH\_AES\_256\_GCM\_SHA384&TLS\_ECDHE\_ECDSA\_WITH\_AES\_128\_GCM\_SHA256&TLS\_ECDHE\_ECDSA\_WITH\_AES\_256\_GCM\_SHA384&TLS\_ECDHE\_RSA\_WITH\_AES\_128\_GCM\_SHA256&TLS\_ECDHE\_RSA\_WITH\_AES\_256\_GCM\_SHA384”。

   ```
   MOD PMSFUNC: TYPE=Server, ITEMN=ciphers, VALUE="TLS_DHE_RSA_WITH_AES_128_GCM_SHA256&TLS_DHE_RSA_WITH_AES_256_GCM_SHA384&TLS_ECDHE_ECDSA_WITH_AES_128_GCM_SHA256&TLS_ECDHE_ECDSA_WITH_AES_256_GCM_SHA384&TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256&TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384";
   ```
2. 登录“OM Portal”，在界面上选择“应用管理 > MML”，在CSP网元下，执行**DSP POD**命令，查询pcf中的所有Pod类型。

   命令示例如下：

   ```
   DSP POD: TYPE=byType, PODTYPE="pcf";
   ```
3. 执行**RST POD**命令，重启PMS服务。

   **须知** 

   重启服务时，输入的Pod类型需与2中查询结果保持一致。

   命令示例如下：

   ```
   /*重启PMS服务*/
   RST POD: TYPE=byType, PODTYPE="pcf-addp-pod231", FORCEFLAG=true, MEID="20";
   ```
