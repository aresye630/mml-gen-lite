# 查询AMF的N2接口信息（LST N2INFAMFINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询当前AMF的N2接口信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                                                         |
|:---------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCENAME | NF实例名称 | 可选必选说明：可选参数  参数含义：本参数用于指定NF实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~50。  默认值：无  配置原则：  本参数需要与ADD NFUUID命令中的NFINSTANCENAME值保持一致。 |

## 使用实例

运营商A需要查询当前AMF的N2接口信息。

```
%%LST N2INFAMFINFO:;%%
RETCODE = 0  操作成功

结果如下
------------------------
     NF实例名称  =  AMF_Instance_0
     IP地址类型  =  IPTypeV4
  IPV4类型地址1  =  192.168.0.1
  IPV4类型地址2  =  192.168.0.2
  IPV4类型地址3  =  0.0.0.0
  IPV4类型地址4  =  0.0.0.0
  IPV6类型地址1  =  ::
  IPV6类型地址2  =  ::
  IPV6类型地址3  =  ::
  IPV6类型地址4  =  ::
        AMF名称  =  amf1.cluster1.net2.3gppnetwork.org
(结果个数 = 1)

---    END
```
