# 删除定位NR邻区（RMV NRCELLNEIGHBOR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于删除定位NR邻区。

#### 注意事项

- 该命令执行后立即生效。
- 只有在执行该命令后发起的定位请求才会不携带新删除的邻区信息。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称          | 参数说明                                                                             |
|:------------|:--------------|:---------------------------------------------------------------------------------|
| GNODEBID    | 基站标识          | 可选必选说明：必选参数 参数含义：该参数用于设置基站标识。 数据来源：全网规划 取值范围：0~4294967295。 默认值：无 配置原则：无          |
| NRCELLID    | NR小区标识        | 可选必选说明：必选参数 参数含义：该参数表示小区的标识。 数据来源：全网规划 取值范围：0~65534。 默认值：无 配置原则：无                |
| NEIGBGNBID  | 邻区所在的gNodeB标识 | 可选必选说明：必选参数 参数含义：该参数表示定位邻区所在的gNodeB标识。 数据来源：全网规划 取值范围：0~4294967295。 默认值：无 配置原则：无 |
| NEIGBCELLID | 邻区的NR Cell标识  | 可选必选说明：必选参数 参数含义：该参数表示定位邻区的小区标识。 数据来源：全网规划 取值范围：0~65534。 默认值：无 配置原则：无            |

#### 使用实例

删除定位NR邻区：

```
RMV NRCELLNEIGHBOR: GNODEBID=1, NRCELLID=3, NEIGBGNBID=1, NEIGBCELLID=4;
```
