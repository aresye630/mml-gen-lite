# 删除IMSI号段与CHF组的绑定关系（RMV SELCHFGBIMSISEG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于删除IMSI号段与CHF组的绑定关系。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                           |
|:---------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SEGSTART | 号段起始字符串 | 可选必选说明：必选参数  参数含义：该参数用于设置绑定的IMSI号段的起始字符串。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是5~15。号段起始字符串长度为15位，不足15位时系统自动在末尾补0。十进制数字，号段的起始号码数值必须小于或等于号段结束号码的数值，且号段的起始号码不能以0开始，全0除外。  默认值：无  配置原则：无 |
| SEGEND   | 号段结束字符串 | 可选必选说明：必选参数  参数含义：该参数用于设置绑定的IMSI号段的结束字符串。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是5~15。号段结束字符串长度为15位，不足15位时系统自动在末尾补9。十进制数字，号段的结束号码数值必须大于或等于起始号码的数值，且号段的结束号码不能以0开始。  默认值：无  配置原则：无        |

## 使用实例

删除基于IMSI号段选择CHF处理：

```
RMV SELCHFGBIMSISEG: SEGSTART="12345678901", SEGEND="12345678905";
```
