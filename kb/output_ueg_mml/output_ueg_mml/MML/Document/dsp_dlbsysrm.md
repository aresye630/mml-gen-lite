# 查询DLB系统运行状态(DSP DLBSYSRM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于请求DLB显示系统运行的状态。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询DLB系统运行状态。

```
DSP DLBSYSRM:;
```

```
%%DSP DLBSYSRM:;%% 
RETCODE = 0  操作成功  
操作结果如下
------------------------ 
实例号           系统运行状态    
540161307        激活模式                 
540165202        激活模式                 
(结果个数 = 2)
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义参见表1。

| 输出项名称   | 输出项解释                                                                            |
|:--------|:---------------------------------------------------------------------------------|
| 实例号     | 用于指示查询结果中DLB的实例号。 取值范围：长度不超过256的字符串。 默认值：无。                                      |
| 系统运行状态  | 用于指定系统的运行模式。 取值范围：ACTIVE(激活模式)：表示可提供业务服务。 DEACTIVE(去激活模式)：即退服，表示不可提供业务服务。 默认值：无。 |
