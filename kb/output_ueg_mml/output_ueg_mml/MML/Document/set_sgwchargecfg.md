# SGW计费配置（SET SGWCHARGECFG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-C**

**须知** 

本命令属于高危命令，修改配置可能导致无可用CG，SGW话单无法被正常处理，从而导致用户无法计费。

SET SGWCHARGECFG命令用来修改SGW计费配置，包括本地离线计费、漫游离线计费、拜访离线计费、使用本地CG或使用PGW携带的CG。

#### 注意事项

- 该命令执行后只对新激活用户生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | HOMEOFFLINE   | ROAMOFFLINE   | VISITOFFLINE   | SGWCGFLAG   |
|:-------|:--------------|:--------------|:---------------|:------------|
| 初始值    | DISABLE       | ENABLE        | ENABLE         | USE_LOCAL   |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称        | 参数说明                                                                                                                                                                            |
|:-------------|:------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HOMEOFFLINE  | 本地用户离线计费开关  | 可选必选说明：可选参数 参数含义：本地用户离线计费开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：否。ENABLE：是。 默认值：无 配置原则： ENABLE：打开本地离线计费。DISABLE：关闭本地离线计费。                                                             |
| ROAMOFFLINE  | 漫游用户离线计费开关  | 可选必选说明：可选参数 参数含义：漫游用户离线计费开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：否。ENABLE：是。 默认值：无 配置原则： ENABLE：打开漫游离线计费。DISABLE：关闭漫游离线计费。                                                             |
| VISITOFFLINE | 拜访用户离线计费开关  | 可选必选说明：可选参数 参数含义：拜访用户离线计费开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：否。ENABLE：是。 默认值：无 配置原则： ENABLE：打开拜访离线计费。DISABLE：关闭拜访离线计费。                                                             |
| SGWCGFLAG    | SGW CG IP选择 | 可选必选说明：可选参数 参数含义：SGW CG选择。 数据来源：本端规划 取值范围：枚举类型。 USE_LOCAL：使用本地CG IP。该参数使用ADD CG命令配置生成。USE_PGW：使用PGW携带的CG IP。 默认值：无 配置原则： USE_LOCAL：使用本地CG。该参数使用ADD CG命令配置生成。USE_PGW：使用PGW携带的CG。 |

#### 使用实例

SGW计费配置，关闭本地离线计费，打开漫游离线计费，打开拜访离线计费，使用本地CG：

```
SET SGWCHARGECFG:HOMEOFFLINE=DISABLE,ROAMOFFLINE=ENABLE,VISITOFFLINE=ENABLE,SGWCGFLAG=USE_LOCAL;
```
