# 查询HTTP链路状态(DSP UDMHTTPLNK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询链路动态状态信息。

## 注意事项

- 当查询到的信息过多时，可能出现报文显示异常，因此推荐输入“IP地址类型”和“对端IPV4地址”的组合，或“IP地址类型”和“对端IPV6地址”的组合精确查询。
- 在链路均衡过程中会出现链路变更，若在均衡过程中执行本命令，查询的结果会与链路均衡前后查询的结果不一致。
- GBA场景下，执行该命令无法查询短连接的链路状态信息。（仅虚机场景涉及）

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                        |
|:-----------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------|
| WMODE      | 工作模式     | 可选必选说明：必选参数 参数含义：用于指示系统按照本端的哪个工作模式来查询HTTP链路状态数据。 取值范围： SERVER(服务端)CLIENT(客户端) 默认值：无。 配置原则：无。                                                |
| PEERIPVER  | IP地址类型   | 可选必选说明：可选参数 参数含义：用于指示系统按照对端哪个IP地址类型来查询HTTP链路状态数据；若不输入，则表示所有的对端IP地址类型。 取值范围：IPV4(IPV4开关)IPV6(IPV6开关) 默认值：无。 配置原则：无。                          |
| PEERIPV4   | 对端IPV4地址 | 可选必选说明：条件必选参数 参数含义：用于指示系统按照对端哪个IPv4地址来查询HTTP链路状态数据。 取值范围：标准IPV4地址。 默认值：无。 配置原则：仅当本命令中的“IP地址类型”参数为“IPV4(IPV4开关)”时该参数有效。                      |
| PEERIPV6   | 对端IPV6地址 | 可选必选说明：条件必选参数 参数含义：用于指示系统按照对端哪个IPv6地址来查询HTTP链路状态数据。 取值范围：标准IPV6地址。 默认值：无。 配置原则：仅当本命令中的“IP地址类型”参数为“IPV6(IPV6开关)”时该参数有效。                      |
| PEERNFTYPE | 对端网元类型   | 可选必选说明：可选参数 参数含义：用于指示系统按照对端网元类型来查询HTTP链路状态数据。 取值范围： OTHER(OTHER)SCP(SCP)SEPP(SEPP)AUC(AUC) 默认值：无。 配置原则： 当本命令中的“工作模式”参数为“CLIENT(客户端)”时该参数有效。 |

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。表1列出的是各输出项的解释说明。

| 输出项名称   | 输出结果解释                                                                                                                                                                                                                                         |
|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLB实例ID | 用于返回链路所在的HLB服务的实例ID。                                                                                                                                                                                                                           |
| 链路ID    | 用于返回链路ID。 该输出项仅在“工作模式”为“CLIENT”，且通过MOD UDMSOFTPARA命令设置的“HttpLink(HTTP链路策略)”软参值为“0”时，返回NULL，其他场景下都返回链路ID。                                                                                                                                       |
| 链路设置类型  | 用于返回链路设置方式。 取值范围：静态设置动态设置 说明：静态设置的链路，此参数为“静态设置”；动态设置的链路，此参数为“动态设置”。                                                                                                                                                                            |
| 工作模式    | 用于返回链路中UDM的工作模式。 取值范围：客户端服务端                                                                                                                                                                                                                   |
| 协议类型    | 用于返回链路的网络协议类型。 取值范围：HTTPHTTPS                                                                                                                                                                                                                  |
| 本端IP地址  | 用于返回链路的本端IP地址。                                                                                                                                                                                                                                 |
| 本端端口    | 用于返回链路的本端端口。                                                                                                                                                                                                                                   |
| 对端IP地址  | 用于返回链路的对端IP地址。                                                                                                                                                                                                                                 |
| 对端端口    | 用于返回链路的对端端口。                                                                                                                                                                                                                                   |
| 流数目     | 用于返回链路已产生的流数目。                                                                                                                                                                                                                                 |
| 链路选择模式  | 用于返回链路集的工作模式，该输出项为通过ADD HTTPLKSPARA命令配置的“链路选择模式”参数值。 当通过MOD UDMSOFTPARA命令设置的“HttpLink(HTTP链路策略)”软参值为“1”时，该输出项的取值范围：优先级：按照优先级进行选链。轮询：对路由组下的所有对端实体轮流选择，即在可用对端之间循环选择。权重：按照权重进行选择。 当通过MOD UDMSOFTPARA命令设置的“HttpLink(HTTP链路策略)”软参值为“0”时，该输出项返回NULL。 |
| 链路权重    | 用于返回链路设置的权重信息。 当“工作模式”为“CLIENT”且“链路选择模式”取值为“优先级”时，“链路权重”返回NULL。                                                                                                                                                                                |
| 链路优先级   | 用于返回链路设置的优先级信息。 当“工作模式”为“CLIENT”且“链路选择模式”取值为“权重”时，“链路优先级”返回NULL。                                                                                                                                                                               |
| 链路状态    | 用于返回链路连接状态信息。 取值范围：ACTIVEDOWN 说明：链路处于激活状态，此参数为“ACTIVE”；链路处于待激活状态，此参数为“DOWN”。                                                                                                                                                                   |
| 对端网元类型  | 用于返回对端网元类型。 取值范围： OTHER(OTHER)SCP(SCP)SEPP(SEPP)AUC(AUC) 该输出项仅在“工作模式”取值为“CLIENT(客户端)”且对端网元类型为“SCP(SCP)”、“SEPP(SEPP)”或“AUC(AUC)”时，返回对端网元类型，其他情况返回“OTHER”。                                                                                       |
| 均衡控制标记  | 用于返回链路创建时是否采用均衡控制策略。当使用SET HTTPBCCFG命令关闭均衡开关后，如果链路保持正常惯性运行，则查询结果中的“均衡控制标记”不刷新。 取值范围： 是：使用均衡控制标记。否：不使用均衡控制标记。                                                                                                                                   |
| 平均消息数   | 用于返回查询链路在5秒周期内的平均消息数。                                                                                                                                                                                                                          |
| 创建时间    | 用于返回链路创建的时间。                                                                                                                                                                                                                                   |
