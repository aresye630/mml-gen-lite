## 命令功能

该命令用于向ACS配置客户端发送调试操作。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                              |
|:------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------|
| DEBUGTYPE   | 调试类型   | 可选必选说明：必选参数。 参数含义：用于指定需要调试操作的类型。 取值范围：枚举类型。 saveNextSyncdata(保存下次对账文件)：保存客户端下次对账的配置文件。saveDb(保存客户端数据库)：保存客户端侧DB文件。 默认值：无。 配置原则：无。 |
| DEBUGVALUE  | 调试内容   | 可选必选说明：可选参数。 参数含义：自定义调试操作内容。 取值范围：字符串类型，长度为1~255。 默认值：无。 配置原则：无。                                                                  |
| SERVICENAME | 服务名称   | 可选必选说明：条件必选参数，该参数在“DEBUGTYPE”配置为“saveNextSyncdata”或“saveDb”时为必选参数。 参数含义：用于指定需要执行调试操作的微服务名称。 取值范围：字符串类型，长度为1~255。 默认值：无。 配置原则：无。   |
| INSTANCEID  | 实例ID   | 可选必选说明：条件必选参数，该参数在“DEBUGTYPE”配置为“saveNextSyncdata”或“saveDb”时为必选参数。 参数含义：用于指定需要执行调试操作的微服务实例ID。 取值范围：字符串类型，长度为1~255。 默认值：无。 配置原则：无。 |

## 使用实例

向ACS配置客户端发送保存下次对账文件调试操作时，执行以下命令：

```
OPR ACSCLIENTDBG: DEBUGTYPE=saveNextSyncdata, SERVICENAME="101", INSTANCEID="hafetcd-pod12-0__104__0";
```

```
%%OPR ACSCLIENTDBG: DEBUGTYPE=saveNextSyncdata, SERVICENAME="101", INSTANCEID="hafetcd-pod12-0__104__0";%% 
RETCODE = 0  操作成功  

---    END
```

命令执行异常，请联系华为技术支持处理。常见异常场景如表1 错误码列表所示。

|   错误码 | 错误码解释   | 原因分析              | 处理建议       |
