# 设置链路分配参数（SET LINKASSIGNPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令用于设置主用DLB服务分配的比例。

## 注意事项

- 执行该命令前，需要保证所有DLB服务处于正常状态。
- 该命令存在系统初始记录，参数的初始设置值如下：

  “DLB比例”为“1/2”。
- 当DLB微服务个数小于或等于4个时，该命令设置的“DLBRATE”取值无效，系统将强制按“1/2”处理。
- 执行该命令设置主用DLB服务分配比例后，需要执行ACT LINKASSIGN命令或者复位DLB服务，该命令设置的分配比例才会生效。

## 参数说明

| 参数ID    | 参数名称   | 参数描述                                                                                                                                                                                                                                                               |
|:--------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DLBRATE | DLB比例  | 可选必选说明：可选参数 参数含义：用于设置主用DLB服务分配的比例。 取值范围： 1/2(1/2)：表示主用DLB服务分配的比例为1/2。2/3(2/3)：表示主用DLB服务分配的比例为2/3。 默认值：无。 配置原则：无。  说明： 使用该参数计算主用DLB服务分配的数量时，如果计算结果为非整数，则向上取整。 假设DLB服务总数为10： 如果该参数设置为“1/2”，使用DLB服务总数乘以1/2，则主用DLB服务数为5。如果该参数设置为“2/3”，使用DLB服务总数乘以2/3，再向上取整，则主用DLB服务为7。 |

## 使用实例

1. 设置主用DLB服务分配的比例。“DLB比例”为“2/3(2/3)”。

   ```
   SET LINKASSIGNPARA: DLBRATE=2/3;
   ```
2. 重新均衡分配DLB链路。

   ```
   ACT LINKASSIGN: ASSIGNTYPE=REASSIGN, SERVICETYPE=DLB;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
