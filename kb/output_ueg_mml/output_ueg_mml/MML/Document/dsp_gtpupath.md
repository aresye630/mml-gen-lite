#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询GTP-U路径信息，如果输入的路径在系统中已经存在则输出这条路径的信息。

#### 注意事项

- 该命令执行后立即生效。
- 当GTP-U路径数较多时，命令执行时长可能会持续几分钟。建议通过“本端IPv4地址”/“本端IPv6地址”、“对端IPv4地址”/“对端IPv6地址”、“对端IPv4地址掩码”、“路径状态筛选”、“网元间接口类型筛选”参数的组合来进行分类查询，减少一次查询的GTP-U路径数，提高每次查询的效率。（GTP-U路径数可通过**DSP GTPUPATHNUM**命令查询获得）。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

| GTPVER       | GTP版本      | 可选必选说明：必选参数 参数含义：该参数用于指定GTP-U路径的协议版本。 数据来源：整网规划 取值范围：“GTPv0（GTPv0）”“GTPv1（GTPv1）” 默认值：无                                                                                                                                                                                |
| IPTYPE       | IP地址类型     | 可选必选说明：必选参数 参数含义：该参数用于指定GTP-U路径的IP地址类型。 数据来源：整网规划 取值范围：“IPV4(IPV4)”“IPV6(IPV6)” 默认值：无                                                                                                                                                                                  |
| LOCIPV4ADDR  | 本端IPv4地址   | 可选必选说明：条件可选参数 参数含义：该参数用于指定GTP-U路径的本端IPv4地址。 数据来源：整网规划 前提条件：该参数在“IP地址类型”设置为“IPV4(IPv4)”时有效。 取值范围：0.0.0.0~255.255.255.255 默认值：无  说明： 若本参数没有输入，则不以本参数作为筛选条件来查询所有的GTP-U路径。若本参数输入，则以输入的值作为筛选条件来查询所有的GTP-U路径。 GTP-U路径的本端IPv4地址可以使用LST GTPULE查询。                              |
| PEERIPV4ADDR | 对端IPv4地址   | 可选必选说明：条件可选参数 参数含义：该参数用于指定GTP-U路径的对端IPv4地址，与“对端IPv4地址掩码”参数一起指定查询GTP-U路径的对端IPv4地址的网段。 数据来源：整网规划 前提条件：该参数在“IP地址类型”设置为“IPV4(IPv4)”时有效。 取值范围：0.0.0.0~255.255.255.255 默认值：无  说明： 若本参数没有输入，则不以本参数作为筛选条件来查询所有的GTP-U路径。若本参数输入，则以输入的值与“对端IPv4地址掩码”组成的网段作为筛选条件来查询所有的GTP-U路径。     |
| PEERIPV4MSK  | 对端IPv4地址掩码 | 可选必选说明：条件可选参数 参数含义：该参数用于指定GTP-U路径的对端IPv4地址的掩码，与“对端IPv4地址”参数一起指定查询GTP-U路径的对端IPv4地址的网段。 数据来源：整网规划 前提条件：当“IP类型”设置为“IPV4(IPV4)”时此参数有效。 取值范围：0.0.0.0~255.255.255.255 默认值：255.255.255.255                                                                                    |
| LOCIPV6ADDR  | 本端IPv6地址   | 可选必选说明：条件可选参数 参数含义：该参数用于指定GTPU路径的本端IPv6地址。 数据来源：整网规划 前提条件：该参数在“IP地址类型”设置为“IPV6(IPv6)”时有效。 取值范围：::~FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无  说明： 若本参数没有输入，则不以本参数作为筛选条件来查询所有的GTP-U路径。若本参数输入，则以输入的值作为筛选条件来查询所有的GTP-U路径。 GTP-U路径的本端IPv6地址可以使用LST GTPULE查询。            |
| PEERIPV6ADDR | 对端IPv6地址   | 可选必选说明：条件可选参数 参数含义：该参数用于指定GTP-U路径的对端IPv6地址。 数据来源：整网规划 前提条件：该参数在“IP地址类型”设置为“IPV6(IPv6)”时有效。 取值范围：::~FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无  说明： 若本参数没有输入，则不以本参数作为筛选条件来查询所有的GTP-U路径。若本参数输入，则以输入的值作为筛选条件来查询所有的GTP-U路径。                                             |
| MAXDSPNUM    | 最大显示路径数目   | 可选必选说明：可选参数 参数含义：该参数用于指定查询结果最大显示的路径数目。若实际匹配的查询路径数大于指定的最大显示路径条目，多出的路径数不会显示。 数据来源：整网规划 取值范围：1~8000 默认值：5000  说明： 当GTP-U路径数较多时，本参数的取值越大，命令执行的时长越长。建议保持系统默认值不变。                                                                                                            |
| PATHST       | 路径状态筛选     | 可选必选说明：可选参数 参数含义：该参数用于指定查询GTP-U路径的状态。 数据来源：整网规划 取值范围：“NORMAL（正常）”“ERROR（故障）”“ALL（所有）” 默认值：“ERROR(故障)”  说明： 若本参数没有输入，系统缺省查询“ERROR（故障）”状态的GTP-U路径。                                                                                                                       |
| PEERINTF     | 网元间接口类型筛选  | 可选必选说明：可选参数 参数含义：该参数用于指定查询GTP-U路径的网元间接口类型。 数据来源：整网规划 取值范围：Gn（Gn），Gp（Gp），S4（S4），S16（S16），Iu（Iu），S11(S11) 默认值：无  说明： 若本参数没有输入，系统缺省查询所有网元间接口类型的GTP-U路径。若GTP-U路径同时存在多个网元间接口类型时，输出结果为包含指定输入的网元间接口类型的GTP-U路径。 举例：GTP-U路径上同时存在“Gn”、“S16”接口类型，输入“Gn”筛选条件可以查询，输入“S16”筛选条件也可以查询。 |

#### 使用实例

1. 查询资源单元为USN\_SP\_RU\_0066上的GTP-U路径信息：

   ```
   %%DSP GTPUPATH: RUNAME="USN_SP_RU_0066", GTPVER=GTPv1, IPTYPE=IPV4;%%
   RETCODE = 0  操作成功。

   操作结果如下:
   -------------------------
     资源单元名称 = USN_SP_RU_0066
         进程类型 = UPP
         进程序号 = 0
   To be continued...
   ---    END

   %%DSP GTPUPATH: RUNAME="USN_SP_RU_0066", GTPVER=GTPv1, IPTYPE=IPV4;%%
   RETCODE = 0  操作成功。

   操作结果如下:
   -------------------------
   GTP路径数目  =  1
   To be continued...
   ---    END

   %%DSP GTPUPATH: RUNAME="USN_SP_RU_0066", GTPVER=GTPv1, IPTYPE=IPV4;%%
   RETCODE = 0  操作成功。

   操作结果如下:
   -------------------------
              GTP版本 = GTPv1
           本端IP地址 = 192.168.9.20
           对端IP地址 = 192.168.14.20
          GTP路径状态 = 故障
          GTP路径属性 = 路径管理
       GTP路径上PDP数 = 0
   剩余生存时间（秒） = 955
     PLMN网元间的接口 = Gn接口
   (结果数目 = 3)
   共有3个报告
   ---    END
   ```

#### 输出结果说明

| 输出项名称      | 输出项解释                                                                                            |
|:-----------|:-------------------------------------------------------------------------------------------------|
| RU名称       | 资源单元名称。                                                                                          |
| 进程类型       | GTP-U路径所在进程的类型。 取值说明： UPP                                                                        |
| 进程序号       | GTP-U路径所在进程的序号。                                                                                  |
| GTP路径数目    | 按照输入条件查询出来的GTP-U路径数量。                                                                            |
| GTP版本      | 说明本路径的GTP版本，目前是GTPv0或GTPv1。 取值说明： GTPv0GTPv1                                                     |
| 本端IP地址     | 无。                                                                                               |
| 对端IP地址     | 无。                                                                                               |
| GTP路径状态    | 描述该路径是处于正常状态或是路径断的状态。 取值说明： 正常故障                                                                 |
| GTP路径属性    | 路径种类，说明此路径的属性。 取值说明： 空到GGSN的路径 说明： 当“PLMN网元间的接口”为“S4接口”时，GGSN代表SGW设备。 到SGSN的路径到RNC的路径到SGW的路径路径管理 |
| GTP路径上PDP数 | 描述该路径上的PDP上下文数量。                                                                                 |
| 剩余生存时间（秒）  | 描述该路径在系统中还能存在多久。                                                                                 |
| PLMN网元间的接口 | 说明UNC与对端网元间的接口类型。 取值说明： 未确定接口Gn接口Gp接口S4接口S16接口Iu接口S11接口                                          |
