# 查询Qos特征（LST QOSCHARS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SMF**

该命令用来查询QoS特征，其中包括资源类型、5QI优先级、包时延预算、包错误率、平均窗口、最大数据突发。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                      |
|:-------|:--------|:----------------------------------------------------------------------------------------------------------|
| FQI    | 5QI或QCI | 可选必选说明：可选参数  参数含义：该参数用于配置5QI或QCI，不同的5QI或QCI的业务流需使用不同的承载。  数据来源：全网规划  取值范围：整数类型，取值范围是1~255。  默认值：无  配置原则：无 |

## 使用实例

查询5QI为“10”的QoS特征的信息。

```
LST QOSCHARS: FQI=10;
```

## 输出结果说明

| 输出项名称       | 输出项解释                                                      |
|:------------|:-----------------------------------------------------------|
| 5QI或QCI     | 该参数用于配置5QI或QCI，不同的5QI或QCI的业务流需使用不同的承载。                     |
| QoS资源类型     | 该参数用于表示QoS流是“NON_GBR”、 “Critical_GBR”还是“NON_CRITICAL_GBR”。 |
| 5QI优先级      | 该参数用于表示5QI或QCI优先级。                                         |
| 包时延预算(毫秒)   | 该参数用于指示数据包延迟预算。                                            |
| 包错误率        | 该参数用于表示数据包错误率。                                             |
| 平均窗口(毫秒)    | 该参数用于指示平均窗口。                                               |
| 最大数据突发量(字节) | 该参数用于指示最大数据突发量。                                            |
