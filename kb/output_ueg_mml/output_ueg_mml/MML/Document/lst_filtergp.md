# 查询过滤组（LST FILTERGP）

- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF**

此命令用于查询过滤组，可以指定过滤组的ID或名称来查询，也可以同时指定过滤组ID和名称。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                       |
|:-------------|:-------|:-------------------------------------------------------------------------------------------|
| FILTERGPID   | 过滤组ID  | 可选必选说明：可选参数  参数含义：该参数用于指定过滤组唯一标识。  数据来源：本端规划  取值范围：整数类型，取值范围是0~1023。  默认值：无  配置原则：无        |
| FILTERGPNAME | 过滤组名   | 可选必选说明：可选参数  参数含义：该参数用于指定过滤组的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~100。区分大小写。  默认值：无  配置原则：无 |

## 使用实例

- 运营商希望查看所有过滤组信息。

  ```
  %%LST FILTERGP:;%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
  过滤组ID  =  1
  过滤组名  =  UPFILTER
  (结果个数 = 1)

   ----     END
  ```
- 运营商希望查看过滤组ID为1的过滤组信息。

  ```
  %%LST FILTERGP: FILTERGPID=1;%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
  过滤组ID  =  1
  过滤组名  =  UPFILTER
  (结果个数 = 1)

   ----     END
  ```
