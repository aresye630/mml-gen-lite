# 显示插件信息（DSP PLUGIN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

可以通过该命令查看已加载插件的类型和状态信息。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                           |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APPTYPE | 应用类型   | 可选必选说明：可选参数 用于标识插件所属的FE应用类型，FE应用类型可通过LST APPTYPE查询。 取值范围：长度不超过128位的字符串。 默认值：无 配置原则：该参数取值必须与通过LST APPTYPE查询到的“应用类型”保持一致。                                                                                                                                        |
| STATUS  | 状态     | 可选必选说明：可选参数 用于标识某个应用类型下的FE插件状态。 取值范围： INVALID(无效状态)：插件被加载之前为无效状态。INIT(初始化状态)：注册过程中为初始化状态。NORMAL(正常状态)：注册并加载成功且备份完成后为正常状态。UPDATE(更新状态)：该功能预留。ABNORMAL(异常状态)：该命令执行异常时为异常状态。INCOMPACTUPDATE(非兼容更新状态)：该功能预留。BACKUP(备份状态)：插件加载完成之后会自动备份到本地，备份过程中为备份状态。 默认值：无 配置原则：无 |

## 使用实例

显示已加载插件的类型和状态信息。

```
DSP PLUGIN:;
```

```
%%DSP PLUGIN:;%%
RETCODE = 0  操作成功
 
操作结果如下
------------------------
应用类型      插件名称        插件类型        格式      版本    状态        
 
SUP-DUS       DBSCHEMA        DBSCHEMA        XML       1       初始化状态  
SUP-DUS       DATAPUBLISH     PUBLISH         Unknown   0       异常状态      
(结果个数 = 2)
 
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见本命令的参数说明。表1列出的是未包含在本命令参数含义中的输出项。

| 输出项名称   | 输出项解释        |
|:--------|:-------------|
| 插件名称    | 用于标识当前插件的名称。 |
| 插件类型    | 用于标识当前插件的类型。 |
| 格式      | 用于标识当前插件的格式。 |
| 版本      | 用于标识当前插件的版本。 |
