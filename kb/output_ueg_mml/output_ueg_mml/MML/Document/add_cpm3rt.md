# 增加M3UA信令路由(ADD CPM3RT)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME、SMSF**

该命令用于增加M3UA信令路由。

#### 注意事项

- 该命令执行后立即生效。
- 此命令的最大记录数为1280。
- 目的实体对应的本地实体和链路集对应的本地实体必须一致。
- 每个M3UA目的实体最多只能配置16条路由。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                    |
|:-------|:-------|:----------------------------------------------------------------------------------------|
| RTX    | 路由索引   | 可选必选说明：必选参数 参数含义：该参数用于指定唯一标识一个路由的索引。 数据来源：本端规划 取值范围：0~1279 默认值：无                        |
| DEX    | 目的实体索引 | 可选必选说明：必选参数 参数含义：该参数用于指定该M3UA路由的目的实体。 数据来源：本端规划 取值范围：0~1279 默认值：无                       |
| LSX    | 链路集索引  | 可选必选说明：必选参数 参数含义：该参数用于指定到达该的目的实体的M3UA链路集。 数据来源：本端规划 取值范围：0~1279 默认值：无                   |
| PRI    | 优先级    | 可选必选说明：可选参数 参数含义：该参数用于指定M3UA路由的选路优先级。 数据来源：整网规划 取值范围：0~254 默认值：0  说明： 0是最高优先级，254是最低优先级 |
| RTN    | 信令路由名  | 可选必选说明：可选参数 参数含义：该参数用于指定M3UA路由名称，标识M3UA路由。 数据来源：本端规划 取值范围：长度不超过32的字符串 默认值：noname        |

#### 使用实例

增加路由索引为1，目的实体索引为1，链路集索引为1，优先级为0（默认值），路由名为“TEST”的M3UA路由：

ADD CPM3RT: RTX=1, DEX=1, LSX=1, RTN="TEST";
