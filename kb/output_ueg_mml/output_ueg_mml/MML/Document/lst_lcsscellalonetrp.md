# 查询LCS小站独立定位TRP配置（LST LCSSCELLALONETRP）

- 注意事项
- 操作用户权限

- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询LCS小站独立定位的TRP配置。

#### 注意事项

不填参数时会查询全部配置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                |
|:---------|:-------|:------------------------------------------------------------------------------------|
| GNODEBID | 基站标识   | 可选必选说明：可选参数 参数含义：该参数用于设置基站标识。 数据来源：全网规划 取值范围：整型数字类型，取值范围为0~4294967295。 默认值：无 配置原则：无 |

#### 使用实例

查询LCS小站独立定位的TRP配置：

```
LST LCSSCELLALONETRP: GNODEBID=190041;
```

```
RETCODE = 0  操作成功

LCS小站独立定位TRP配置
----------------------
基站标识  =  190041
 TRP标识  =  4
(结果个数 = 1)

---    END
```
