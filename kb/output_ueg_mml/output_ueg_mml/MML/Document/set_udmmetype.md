# 设置UDM网元类型（SET UDMMETYPE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会影响网元与网管对接，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置网元在网管上的形态类型。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                    |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| METYPE | 网元类型   | 可选必选说明：必选参数 参数含义：用于指定网元在网管上的形态类型。 取值范围： UDM(UDM)UDM-IWF(UDM-IWF)UDM-EIR(UDM-EIR)UDM-ENS(UDM-ENS)UDM-UIM(UDM-UIM) 默认值：无。 配置原则：无。                                                                                                                                                         |
| FORCE  | 是否强制设置 | 可选必选说明：必选参数 参数含义：用于设置是否强制修改网元在网管上的形态类型。 取值范围： NO(否)YES(是) 默认值：NO(否)。 配置原则： 如果参数“是否强制设置”取值为“NO(否)”，则系统会判断本次配置的“网元类型”是否与已经设置了“网元类型”一致：如果本次命令配置的“网元类型”与该网元已经设置的“网元类型”一致，则会返回错误码360122。如果本次命令配置的“网元类型”与该网元已经设置的“网元类型”不一致，则会返回错误码360123。 如果参数“是否强制设置”取值为“YES(是)”，不用判断是否已经设置了“网元类型”，系统直接进行配置。 |

## 使用实例

配置UDM与U2020/MAE网管服务器的对接数据时：

- 若需配置为UDM网元类型，设置“网元类型”为“UDM(UDM)”，并且强制设置：

  ```
  SET UDMMETYPE: METYPE=UDM, FORCE=YES;
  ```
- 若需配置为UTA网元类型，设置“网元类型”为“UDM-IWF（UDM-IWF）”，并且强制设置：

  ```
  SET UDMMETYPE: METYPE=UDM-IWF, FORCE=YES;
  ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                  | 原因分析                                                         | 处理建议                                                         |
|-------:|:---------------------------------------|:-------------------------------------------------------------|:-------------------------------------------------------------|
| 360122 | 已配置相同的METYPE，不需要重复配置。                  | 本次操作输入的“网元类型”与已经设置的“网元类型”一致。                                 | 根据实际情况判断是否确认需要修改“网元类型”：若需要则重新输入“是否强制设置”参数，且取值为“YES(是)”后进行配置。 |
| 360123 | 已配置不同的METYPE，如果确认要修改配置，请携带FORCE=YES参数。 | 本次操作输入的“网元类型”与已经设置的“网元类型”不一致，同时“是否强制设置”参数取值为“NO(否)”或者未携带该参数。 | 根据实际情况判断是否确认需要修改“网元类型”：若需要则必须输入“是否强制设置”参数，且取值为“YES(是)”后重新配置。 |
| 360124 | 设置网元METYPE信息失败。                        | CSP组件返回失败。                                                   | 请联系华为技术支持进行处理。                                               |
