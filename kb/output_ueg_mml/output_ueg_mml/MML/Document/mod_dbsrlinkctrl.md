# 修改远端DSG链路中心(MOD DBSRLINKCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改远端DSG链路中心。在该命令中，系统通过以下关键参数的组合来唯一标识一远端DSG链路中心信息：

- “配置索引”
- “远端Location标识”

## 注意事项

- 通过“远端链路中心校验码”参数指定的远端链路中心的校验码，必须与在远端网元执行**ADD DSGLINKCTRL**或**MOD DSGLINKCTRL**指定的校验码一致，否则会导致配置消息无法发送到该远端。
- 本命令配置的“远端链路中心校验码”参数检查在USCDB网元侧进行，禁止配置的“远端链路中心校验码”可以通过**ADD WEAKPWD**命令配置或通过**LST WEAKPWD**命令查询。

## 参数说明

| 参数标识     | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                 |
|:---------|:-------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INDEX    | 配置索引         | 可选必选说明：必选参数 参数含义：标识一条远端网元DSG链路中心配置信息的关键字段之一，用于指定需要对哪一条远端DSG链路中心配置信息进行修改或调整。操作员可以通过LST DBSRLINKCTRL命令查询获得。                                                                                                                                                                            |
| RLOCID   | 远端Location标识 | 可选必选说明：必选参数 参数含义：标识一个远端网元DSG链路中心的关键字段之一，用于指定需要对哪一个远端Location的网元DSG链路中心进行修改或调整。操作员可以通过LST DBSRLINKCTRL命令查询获得。                                                                                                                                                                         |
| IPVER    | IP类型         | 可选必选说明：可选参数 参数含义：用于指定IP地址类型。 取值范围： IPV4：当系统要求使用IPv4类型的IP地址时选择此选项。IPV6：当系统要求使用IPv6类型的IP地址时选择此选项。 默认值：无。 配置原则：无                                                                                                                                                                        |
| IPV4IP   | 远端链路中心IPV4地址 | 可选必选说明：可选参数 参数含义：用于指定远端网元的Location IPv4地址。这个地址必须在对接的远端USCDB网元或者FE网元中已经配置完毕。 取值范围：IPV4格式的地址。 默认值：无。 配置原则：仅当本命令中的“IP类型”参数取值为“IPV4”时该参数有效。  须知： 当FE使用该命令与BE对接时，对于不同业务类型的BE DSG，此参数的取值必须不同。                                                                                              |
| IPV6IP   | 远端链路中心IPV6地址 | 可选必选说明：可选参数 参数含义：用于指定远端网元的Location IPv6地址。这个地址必须在对接的远端USCDB网元或者FE网元中已经配置完毕。 IPv6格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如：2001:0DB8:02de:0000:0000:0000:0000:0e13。 取值范围：IPV6格式的地址。 默认值：无。 配置原则：仅当本命令中的“IP类型”参数取值为“IPV6”时该参数有效。  须知： 当FE使用该命令与BE对接时，对于不同业务类型的BE DSG，此参数的取值必须不同。 |
| PASSWORD | 远端链路中心校验码    | 可选必选说明：可选参数 参数含义：用于指定远端链路中心的校验码。 取值范围：符合校验码复杂度的字符串。 默认值：无。 配置原则： 校验码区分大小写，其复杂度需同时满足下列条件必须至少包含以下四个类别中的三类：英文大写字母。英文小写字母。数字：0～9。特殊字符：~ ! # % ^ * ( ) _ - + [ ] { } | < > . ?。 不允许使用三个或三个以上连续的字母或数字（例如：ABC、123）。不允许使用三个或三个以上连续的相同字符（例如：AAA）。长度最短8个字符，最长30个字符。第一个字符必须是字母。                 |
| RDSGST   | 远端DSG业务类型    | 可选必选说明：可选参数 参数含义：用于设置远端DSG网元的业务类型。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：该参数为联想参数列表，不能手动输入，其取值为LST DBSSRVGROUP命令查询获得的“业务类型名称”输出参数。                                                                                                                                                          |

## 使用实例

修改远端DSG链路中心，“配置索引”为“3”，“远端Location标识”为“77”，“IP类型”为“IPV4”，“远端链路中心IPV4地址”为“172.21.128.25”，“远端DSG业务类型”为“SUP-FE”。命令示例如下：

```
MOD DBSRLINKCTRL: INDEX=3, RLOCID=77, IPVER=IPV4, IPV4IP="172.21.128.25", RDSGST="SUP-FE";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                         | 原因分析                                | 处理建议                                                         |
|-------:|:------------------------------|:------------------------------------|:-------------------------------------------------------------|
| 302532 | 输入的业务类型不属于业务分组内，请输入正确的业务类型参数。 | 业务分组功能开关打开时，输入的“远端DSG业务类型”不属于业务分组内。 | 执行LST DBSSRVGROUP命令查询“业务类型名称”，输入查询到的结果，然后重新执行本命令。            |
| 302533 | 分组开关未打开，不能输入与本网元类型不同的业务类型。    | 分组开关未打开，当前网元不支持DBS多应用共存的业务类型。       | 执行LST DBSSRVGROUP命令查询“业务类型名称”，输入与本网元类型相同的“业务类型名称”，然后重新执行本命令。 |
