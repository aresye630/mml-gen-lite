# 显示UFP时延度量统计结果（DSP UFPLATENCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示UFP逐包转发时延统计信息，包括最大值、最小值、平均值、包数以及分段统计结果。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                               |
|:-------|:--------|:-------------------------------------------------------------------------------------------------------------------|
| CELLID | Cell ID | 可选必选说明：可选参数  参数含义：该参数表示PAE调试消息发送的CELLID，可以通过使用命令DSP PAENODE获取。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~127。  默认值：无  配置原则：无 |

| 输出项名称   | 输出项解释                                          |
