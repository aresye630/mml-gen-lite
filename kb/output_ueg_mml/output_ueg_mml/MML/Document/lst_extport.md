# 查询协议扩展端口号(LST EXTPORT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于查询UIM应用协议的扩展端口信息。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数描述                                             |
|:---------|:-------|:-------------------------------------------------|
| PORTTYPE | 端口类型   | 用于指示系统需要按照哪个应用协议类型来查询扩展端口信息；若不输入，则表示查询所有的扩展端口信息。 |

## 使用实例

1. 查询扩展端口信息：

   ```
   LST EXTPORT:;
   ```

   ```
   %%LST EXTPORT:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    端口类型  扩展端口号

    SOAP      8081                
    SOAP_TLS  8002 
   (结果个数 = 2)

   ---    END
   ```
2. 查询扩展端口信息，“端口类型”为“SOAP(SOAP)”：

   ```
   LST EXTPORT: PORTTYPE=SOAP;
   ```

   ```
   %%LST EXTPORT: PORTTYPE=SOAP;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
     端口类型  =  SOAP
   扩展端口号  =  8081
   (结果个数 = 1)

   ---    END
   ```
