# 修改PCRF实体(MOD PCRF)

- 注意事项

## 命令功能

**须知** 

- 此命令是高危命令，如果执行不当会导致系统异常，影响业务处理，需联系华为技术支持确认后再执行。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令为配置类命令，用于修改或调整配置数据库中本端PCRF功能实体的名称。在该命令中，系统通过“PCRF标识”来唯一标识一条本端PCRF实体数据记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                   |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PCRFID | PCRF标识 | 用于在UPCF配置库中定义一个PCRF功能实体。 取值范围：1 默认值：无。                                                                                                                                 |
| EN     | 实体名称   | 用于具体描述本端PCRF实体的名称，以便于识别。其值域类型为字符串，区分大小写。 取值范围：长度不超过128的字符串 默认值：无。                                                                                                      |
| DN     | 本地域名   | 用于标识本端实体域名。该参数在配置和查询时都不区分大小写。 取值范围：长度不超过64的字符串 默认值：无。                                                                                                                  |
| HN     | 本地主机名  | 用于在UPCF配置库中定义本端实体主机名，必须全网唯一。该参数在配置和查询时都不区分大小写。 取值范围：长度不超过127的字符串 默认值：无。  说明： “本地主机名”必须配置为实体名称+本地域名的形式。例如：“实体名称”为“pcrf”，“本地域名”为“huawei.com”，则“本地主机名”为“pcrf.huawei.com”。 |

## 使用实例

修改本端PCRF实体名称。PCRF实体标识为1，PCRF实体名称改为PCRF1，PCRF域名为huawei.com，PCRF主机名为pcrf1.huawei.com。

```
MOD PCRF: PCRFID=1, EN="PCRF1", DN="huawei.com", HN="pcrf1.huawei.com";
```
