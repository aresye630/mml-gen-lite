#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询APN（Access Point Name）转换配置。如果用户激活请求消息中携带的APN和本配置命令“OLDAPN（请求APNNI）”匹配，则用户激活请求消息中携带的APN将被替换为“NEWAPN（转换APNNI）”后再进行签约数据匹配。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                                                                  |
|:---------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围    | 可选必选说明：可选参数 参数含义：该参数用于指定签约用户的范围。 取值范围：“ALL_USER(所有用户)”“IMSI_PREFIX(指定IMSI前缀)”“IMSI_RANGE(指定IMSI范围)” 默认值：无                                                                                                             |
| IMSIPRE  | IMSI前缀  | 可选必选说明：可选参数 参数含义：该参数用于指定IMSI前缀。 前提条件：该参数在“用户范围”参数设置为“IMSI_PREFIX(指定IMSI前缀)”时，才需要配置。 取值范围：1~15位数字 默认值：无  说明： 根据IMSI、“请求APNNI”映射唯一的“转换APNNI”。                                                                           |
| IMSI     | IMSI    | 可选必选说明：可选参数 参数含义：该参数用于指定所查询的IMSI。 前提条件：该参数在“用户范围”参数设置为“IMSI_RANGE(指定IMSI范围)”时，才需要配置。 取值范围：1~15位数字 默认值：无  说明： 根据IMSI、“请求APNNI”映射唯一的“转换APNNI”。                                                                          |
| OLDAPN   | 请求APNNI | 可选必选说明：可选参数 参数含义：该参数用于指定激活请求消息中携带的APNNI。 取值范围：1~62 默认值：无  说明： “请求APNNI”由一个或多个LABEL构成，各LABEL间用“.”间隔。每个LABEL的构成字符只能是字母A~Z或a~z、数字0~9和中划线“-”。例如“HUAWEI.COM”。APN网络标识地址不能以“rac”、“lac”、“sgsn”或“rnc”开头，不能以“.gprs”结尾，不能取值为“*”。 |

#### 使用实例

查询所有APN NI转换配置记录：

LST IMSIAPNCONVERT:;

```
%%LST IMSIAPNCONVERT:;%%
RETCODE = 0  操作成功。

---------

指定IMSI前缀    12345       WCDMA        对号段内的用户都启用         EFG          NULL
(结果个数 = 2)
---    END
```
