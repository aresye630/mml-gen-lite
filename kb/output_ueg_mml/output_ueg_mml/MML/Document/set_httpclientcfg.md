# 设置HTTP客户端配置（SET HTTPCLIENTCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响业务处理，需联系华为技术支持确认后再执行。

该命令用于设置HTTP客户端配置信息。

该命令的使用场景：当PCF作为HTTP客户端与对端NRF/SMF/AMF/AF/BSF/CHF/SCP/UDR/NWDAF/HPCF建立HTTP链路时，可使用本命令设置HTTP链路的链路管理模式、心跳发送间隔、心跳发送次数、链路重建时长、链路状态同步时长、链路拆除模式、链路重建模式、NRF链路探测、链路告警过滤方式。

## 注意事项

该命令存在系统初始记录，参数的初始设置值如下：

- “链路管理模式”为“新模式”
- “心跳发送间隔”为“60”
- “心跳发送次数”为“3”
- “链路重建时长”为“60”
- “链路状态同步时长”为“300”
- “链路拆除模式”为“复位拆除”
- “链路重建模式”为“不更换端口”
- “NRF链路探测”为“YES”
- “链路告警过滤方式”为“不生效”

## 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
|:--------------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LINKCTLMODE   | 链路管理模式   | 可选必选说明：可选参数 参数含义：用于设置HTTP客户端链路的管理模式。 取值范围： OLD(旧模式)NEW(新模式) 默认值：NEW(新模式)。 配置原则： 该参数取值为“OLD(旧模式)”时，表示HTTP客户端链路由HLB管理。该参数取值为“NEW(新模式)”时，表示HTTP客户端链路由NCS管理。                                                                                                                                                                                                                                                                                             |
| HBINTERVAL    | 心跳发送间隔   | 可选必选说明：可选参数 参数含义：用于设置HLB发送HTTP PING的时间间隔。 取值范围：0～3600，0表示不发心跳 单位：秒 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                    |
| HBSENDTIMES   | 心跳发送次数   | 可选必选说明：可选参数 参数含义：用于设置HLB发送HTTP PING的次数。 取值范围：0～10，0表示不发心跳 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                             |
| RECONNECTTIME | 链路重建时长   | 可选必选说明：可选参数 参数含义：用于设置HLB对故障HTTP链路的重建时长。 取值范围：0～3600，0表示不重建 单位：秒 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                       |
| SYNCLINKTIME  | 链路状态同步时长 | 可选必选说明：可选参数。仅当“LINKCTLMODE”参数取值为“NEW(新模式)”时，该参数可配置。 参数含义：用于设置HLB向NCS同步链路状态和NCS向PES同步对端/链路状态的时长。 取值范围：0，30～3600，0表示不同步 单位：秒 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                            |
| SHUTDOWNMODE  | 链路拆除模式   | 可选必选说明：可选参数 参数含义：用于设置拆除HTTP链路的模式。 取值范围： RESET(复位拆除)GRACE(优雅拆除) 默认值：无。 配置原则： 该参数取值为“RESET(复位拆除)”时，表示HTTP客户端链路拆除时无需等待对端响应。该参数取值为“GRACE(优雅拆除)”时，表示HTTP客户端链路拆除时需等待对端返回响应后拆除。                                                                                                                                                                                                                                                                             |
| RECONNMODE    | 链路重建模式   | 可选必选说明：可选参数 参数含义：用于设置HTTP链路重建时是否更换本端端口。 取值范围： NOCHANGE(不更换端口)CHANGEPORT(更换端口) 默认值：无。 配置原则：该参数取值为“CHANGEPORT(更换端口)”时，每次HTTP链路重建时会重新上报“ALM-34163 PCF与NF之间的HTTP链路故障”告警。                                                                                                                                                                                                                                                                                 |
| NRFLINKPING   | NRF链路探测  | 可选必选说明：条件可选参数 参数含义：用于设置HTTP客户端是否支持NRF链路探测。仅当“链路管理模式”选择“NEW(新模式)”时，该参数可选。 取值范围： NO(否)YES(是) 默认值：无。 配置原则：无。  说明： 系统升级到高版本后或者初始部署时默认支持NRF链路探测： 当“LINKCTLMODE”取值为“OLD(旧模式)”时，兼容低版本的处理，不使用NRF链路探测功能。当“LINKCTLMODE”取值为“NEW(新模式)”时，且“NRFLINKPING”取值为“NO(否)”时，兼容低版本的处理，不使用NRF链路探测功能。当“LINKCTLMODE”取值为“NEW(新模式)”时，且“NRFLINKPING”取值为“YES(是)”时，使用新版本的NRF链路探测功能。                                                                                                 |
| LINKALMFILTER | 链路告警过滤方式 | 可选必选说明：条件可选参数 参数含义：用于设置HTTP链路告警的过滤方式。仅当“链路管理模式”选择“NEW(新模式)”时，该参数可选。 取值范围： DISABLE(不生效)WHITELIST(白名单)BLACKLIST(黑名单) 默认值：无。 配置原则：无。  说明： 通过该参数，可以按照增加HTTP链路告警过滤黑白名单(ADD LNKALMBWADDR)命令配置的黑白名单中的IP过滤ALM-34163 PCF与NF之间的HTTP链路故障和ALM-34231 PCF和NF通信故障告警。当该参数设置为“WHITELIST(白名单)”，但并未通过增加HTTP链路告警过滤黑白名单(ADD LNKALMBWADDR)命令设置过白名单信息，则UPCF会过滤所有ALM-34163 PCF与NF之间的HTTP链路故障和ALM-34231 PCF和NF通信故障告警。被黑白名单过滤掉的告警信息，也无法通过CSP OM Portal的“监控分析 > 信息收集”等方式收集告警信息。 |

## 使用实例

设置HTTP客户端配置信息，“链路管理模式”为“NEW(新模式)”，“心跳发送间隔”为“60”，“心跳发送次数”为“3”，“链路重建时长”为“60”，“链路状态同步时长”为“300”，“链路拆除模式”为“RESET(复位拆除)”，“链路重建模式”为“NOCHANGE(不更换端口)”，“NRF链路探测”为“YES(是)”，“链路告警过滤方式”为“DISABLE(不生效)”：

```
SET HTTPCLIENTCFG: LINKCTLMODE=NEW, HBINTERVAL=60, HBSENDTIMES=3, RECONNECTTIME=60, SYNCLINKTIME=300, SHUTDOWNMODE=RESET, RECONNMODE=NOCHANGE, NRFLINKPING=YES, LINKALMFILTER=DISABLE;
```
