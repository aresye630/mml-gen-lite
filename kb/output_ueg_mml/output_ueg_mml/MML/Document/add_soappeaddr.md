# 增加SOAP对端地址段(ADD SOAPPEADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在系统中增加一条SOAP对端IP地址段记录。

BSF与AP间通过Zn接口交互时，若使用SOAP协议，则通过本命令添加SOAP对端地址段记录，通过统计Zn接口上的消息总数，可获知Zn接口的业务量是否超过系统可支撑的业务量。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

通过本命令最多可以在系统中添加2048条SOAP对端IP地址段记录。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                              |
|:---------|:---------|:--------------------------------------------------------------------------------------------------|
| ID       | SOAP对端标识 | 可选必选说明：必选参数 用于标识待添加的SOAP对端地址段的ID号，该标识唯一指定一条记录。该参数必须先由ADD SOAPPE命令定义，然后才能在此处引用。 取值范围：1～255 默认值：无。  |
| ADDRID   | 网段编号     | 可选必选说明：必选参数 用于标识待添加的SOAP对端地址段的网段ID，该参数和“SOAP对端标识”参数唯一指定一条记录。 取值范围：0～7 默认值：无。                      |
| IPVER    | IP版本     | 可选必选说明：必选参数 用于标识待添加的SOAP对端地址段的IP地址类型。 取值范围： IPV4(IPV4) IPV6(IPV6) 默认值：无。                          |
| IPV4     | IPv4地址段  | 可选必选说明：条件必选参数 仅当本命令的“IP版本”参数取值为“IPV4(IPV4)”时，该参数必选。用于标识SOAP对端IPv4地址段。 取值范围：有效的IPv4地址。 默认值：无。      |
| MASK     | IPv4掩码   | 可选必选说明：条件必选参数 仅当本命令的“IP版本”参数取值为“IPV4(IPV4)”时，该参数必选。用于标识SOAP对端的IPv4地址段的子网掩码。 取值范围：有效的IPv4地址 默认值：无。 |
| IPV6     | IPv6地址段  | 可选必选说明：条件必选参数 仅当本命令的“IP版本”参数取值为“IPV6(IPV6)”时，该参数必选。用于标识SOAP对端IPv6地址段。 取值范围：有效的IPv6地址。 默认值：无。      |
| PRELENV6 | IPv6前缀长度 | 可选必选说明：条件必选参数 仅当本命令的“IP版本”参数取值为“IPV6(IPV6)”时，该参数必选。用于标识SOAP对端IPv6前缀长度。 取值范围：0～128 默认值：无。          |

## 使用实例

1. 在系统中添加一条SOAP对端IPv4地址段，其中“SOAP对端标识”为“1”、“网段编号”为“1”、“IPv4地址段”为“192.168.10.0”、“IPv4掩码”为“255.255.255.0”：

   ```
   ADD SOAPPEADDR: ID=1, ADDRID=1, IPVER=IPV4, IPV4="192.168.10.0", MASK="255.255.255.0";
   ```
2. 在系统中添加一条SOAP对端IPv6地址段，其中“SOAP对端标识”为“2”、“网段编号”为“2”、“IPv6地址段”为“2001:0DB8:02de:0000:0000:0000:0000:1e13”、“IPv6前缀长度”为“2”：

   ```
   ADD SOAPPEADDR: ID=2, ADDRID=2, IPVER=IPV6, IPV6="2001:DB8:2DE::1E13", PRELENV6=2;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                       | 原因分析                                                           | 处理建议                                                                                     |
|-------:|:--------------------------------------------|:---------------------------------------------------------------|:-----------------------------------------------------------------------------------------|
| 360262 | 当前记录已存在。                                    | 输入的“SOAP对端标识”参数值已存在。                                           | 执行LST SOAPPEADDR命令查询已存在的“SOAP对端标识”，重新输入未配置的该参数后执行本命令添加。                                  |
| 360261 | 指定的SOAP对端标识不存在。请执行LST SOAPPE查询已存在的SOAP对端标识。 | 输入的“SOAP对端标识”参数值没有在ADD SOAPPE命令中定义。                            | 执行LST SOAPPE命令查询已存在的“SOAP对端标识”，重新输入该参数后执行本命令添加。                                          |
| 360263 | IPv4地址段与IPv4掩码(IPv6地址段与IPv6前缀长度)已经存在。       | 输入的参数“IPv4地址段”与“IPv4掩码”的组合或者“IPv6地址段”与“IPv6前缀长度”的组合与系统中已定义的重复。 | 执行LST SOAPPEADDR命令查询，重新输入“IPv4地址段”与“IPv4掩码”的组合或者“IPv6地址段”与“IPv6前缀长度”的组合，确保其取值与查询结果中的不重复。 |
| 360264 | IPv4地址段255.255.255.255是非法值。                 | 参数“IPv4地址段”不能取值为“255.255.255.255”。                             | 重新输入“IPv4地址段”参数，确保其取值不为“255.255.255.255”。                                                |
| 360265 | IPv6地址段全F是非法值。                              | 参数“IPv6地址段”不能取值为“FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF”。     | 重新输入“IPv6地址段”参数，确保其取值不为“FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF”。                        |
