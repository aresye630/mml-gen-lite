# 创建OSPFv3进程配置（ADD OSPFV3）

#### 命令功能

该命令用于增加OSPFv3特性的进程。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为8016。
- 设备的一个接口只能属于某一个OSPFv3进程。
- 如果指定了VPN实例，OSPFv3进程属于此实例，否则属于全局实例。进程实例不可更改，只能在第一次使能该进程时指定。
- 只有在OSPFv3进程下配置了Router ID，OSPFv3进程才能正常运行，否则只能看到该进程，但无法生成LSA。
- OSPFv3进程实例数规格默认为整机2000，实际以服务规格文件为准。
- 建议配置协议相关认证，增强协议安全性，否则可能存在协议安全风险。认证可以通过ADD OSPFV3AUTH、ADD OSPFV3AREAAUTH或ADD OSPFV3INTERFACEAUTH命令进行配置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

创建进程号为1的OSPFv3进程：

```
ADD OSPFV3: PROCID=1,ROUTERID="10.1.1.1";
```

#### 参考信息

OSPFv3支持多进程，不同的OSPFv3进程，它们之间的路由功能互不影响，彼此独立。不同OSPFv3进程之间的路由交互相当于不同路由协议之间的路由交互。一个OSPFv3进程可以包含多个接口，但一个接口只能属于某一个OSPFv3进程。多进程可以用来隔离不同接口的路由区域。

SPF智能定时器的时间间隔的计算方法如下：（1）初次计算SPF的间隔时间由SPF计算初始间隔时间参数指定。（2）第n（n≥2）次计算SPF的间隔时间为SPF计算基数间隔时间×2^(n-2)。（3）当SPF计算基数间隔时间×2^(n-2)达到指定的SPF计算最长间隔时间时，OSPFv3连续三次计算SPF的时间间隔都是最长间隔时间，之后，再次返回步骤1，按照SPF计算初始间隔时间计算SPF。
