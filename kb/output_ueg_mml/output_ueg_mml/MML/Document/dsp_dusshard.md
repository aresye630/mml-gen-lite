# 显示DUS服务分片信息（DSP DUSSHARD）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询指定DUS服务的数据分片信息。维护和服务人员可以通过对DUS服务的数据分片进行信息分析解决数据不一致问题。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                           |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| INSTID   | 实例标识   | 可选必选说明：必选参数。 参数含义：用于指示系统按照指定DUS服务实例显示DUS服务分片信息。 取值范围：长度不超过20的字符串，用10进制或者16进制的字符串（16进制字符串必须以0x或者0X开头）表示。 默认值：无。 配置原则：实例标识可以通过执行DSP DUSSTAT进行查看。 |
| DATATYPE | 数据类型   | 可选必选说明：必选参数。 参数含义：用于指示系统按照指定数据类型的分片显示DUS服务分片信息。 取值范围： GLOBAL（全局数据）USER（用户数据）ROUTE（路由数据） 说明： “全局数据”和“路由数据”选项在该版本暂不支持。 默认值：无。 配置原则：无。            |
| TREENAME | 树名称    | 可选必选说明：必选参数。 参数含义：用于指示系统按照指定服务分片所在的物理树名称显示DUS服务分片信息。 取值范围：长度不超过30的字符串。 默认值：无。 配置原则：无。                                                          |
| SHARDID  | 分片ID   | 可选必选说明：可选参数。 参数含义：用于指示系统按照指定服务分片ID显示DUS服务分片信息。 取值范围：0~65535。 默认值：无。 配置原则：无。                                                                    |

## 使用实例

查询DUS服务的“实例标识”为“13014401066685213577”的数据分片信息。

```
DSP DUSSHARD: INSTID="13014401066685213577", DATATYPE=USER, TREENAME="SUP_GXSESSION", SHARDID=811;
```

```
%%DSP DUSSHARD: INSTID="13014401066685213577", DATATYPE=USER, TREENAME="SUP_GXSESSION", SHARDID=811;%%
RETCODE = 0  操作成功  

操作结果如下
------------------------
数据类型  分片ID Channel状态 分片状态  加载方式     树名称            物理表ID   对象数量
用户数据  811    主用状态    正常状态  空库加载     SUP_GXSESSION     0          1
(结果个数 = 1) 
 
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。各输出项含义请参见表1输出项解释的参数说明。

| 输出项名称     | 输出项解释                                                        |
|:----------|:-------------------------------------------------------------|
| 数据类型      | 用于标识当前数据分片所属的数据类型。                                           |
| 分片ID      | 用于标识当前指定的DUS中可服务的系统自动生成的数据分片标识。                              |
| Channel状态 | 用于标识当前数据分片在Channel中的主、备状态。 取值范围： 主用备用                        |
| 分片状态      | 用于标识当前分片所处的状态。 取值范围： 无效状态异常状态去激活状态初始化状态加载状态正常状态备份状态迁移状态      |
| 加载方式      | 用于标识当前分片的加载方式。 取值范围： 没有加载源Master加载空库加载                       |
| 树名称       | 用于标识当前分片所属的物理树名称。 取值范围：长度不超过30的字符串。                          |
| 物理表ID     | 用于标识当前分片所属的物理表ID。 取值范围：0~65535 “0”：不采用物理树拆分。具体物理表ID：采用物理树拆分。 |
| 对象数量      | 用于标识当前数据分片下的对象记录数。 取值范围：0~4294967295                         |

该命令执行异常，会返回对应的错误码。常见错误码如表2错误码列表所示。

|   错误码 | 错误码解释         | 原因分析                  | 处理建议                                     |
|------:|:--------------|:----------------------|:-----------------------------------------|
| 67886 | 指定的数据类型的数据不存在 | 当前未加载所选择的“数据类型”的数据模型。 | 修改“数据类型”后重新执行。“数据类型”可以通过LST APPTYPE命令获取。 |
| 67887 | 指定的分片ID的数据不存在 | 当前指定了无效的“分片ID”。       | 修改“分片ID”后重新执行。分片标识可以通过LST APPTYPE命令获取。   |
| 67778 | 指定的表不存在       | 当前指定了无效的“树名称”。        | 修改“树名称”后重新执行。“树名称”可以通过检查Schema配置获取。      |
