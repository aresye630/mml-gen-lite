# 修改BYPASS场景QoS描述配置（MOD APNQOSBYPASS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于修改APNQOSBYPASS的配置信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                         |
|:------------|:----------|:-----------------------------------------------------------------------------------------------------------------------------|
| APN         | APN名称     | 可选必选说明：必选参数  参数含义：该参数用来指定APN名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。  默认值：无  配置原则：  该参数使用ADD CPAPN命令配置生成。                     |
| SUBQOSINDEX | 5G用户QoS索引 | 可选必选说明：可选参数  参数含义：该参数表示用户QoS索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：  该取值必须和ADD 5GCSUBQOS中配置的“SUBQOSINDEX”参数取值相同。 |

## 使用实例

当UDM全故障进入ByPass状态时，需要修改用户的QoS信息，此时修改APNQOSBYPASS配置信息：

```
MOD APNQOSBYPASS:APN="huawei.com",SUBQOSINDEX=5;
```
