## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响系统性能与业务处理，需联系华为技术支持确认后再执行。

该命令主要用于业务模块调测与维护。具有以下功能：

- 输出PES实例的用户数据、承载会话数据、应用会话数据。
- 清除PES服务数据文件。
- 导出全局数据，即：从PES内存中导出全局数据。
- 支持Session备份维护能力，包括：
  - 根据用户ID查询或删除该用户关联的Gx/Rx/Sd/Sy/N7/N15 AM/N15 UE/N28/N5/N23接口会话备份数据。
  - 根据用户IP/APN/IPDOMAIN标识查询或删除关联用户的Gx/Rx/Sd/Sy/N7/N28/N5/N23接口会话备份数据。
  - 根据SUBID和接口类型查询或删除该会话备份数据。
  - 根据用户IP+SUBID查询或删除会话备份数据。

  **说明** 

  - 查询会话时，支持模糊查询，系统会自动查询出所有和当前会话有关联关系的会话数据。
  - 删除会话时，系统将遵循以下删除规则：
    - 当用户只存在一个Gx/N7会话，用指定Gx/N7接口的会话标识删除会话数据时，系统会同步把用户关联的Rx、Sy、N28、N5和N23接口会话数据删除。
    - 当用户存在多个Gx/N7会话，用指定的Gx/N7接口的会话标识删除会话数据时，则系统只会删除指定的会话标识的Gx/N7会话。
    - 当用户删除Rx/Sy/N15 AM/N15 UE/N28/N5接口会话数据时，系统只会删除指定会话标识的Rx/Sy/N15 AM/N15 UE/N28/N5接口会话。
    - 当用户同时存在Gx和Sd会话，根据SESSIONID会话标识删除某Gx会话时，不会同时删除其关联的Sd会话。
    - 当用户同时存在N7和N23会话，不支持单独删除N23会话，仅支持删除某N7会话时，同时删除其关联的N23会话。
    - 当用户上线N15 AM会话触发了N24会话时，不支持单独删除N24会话，仅支持删除该N15 AM会话时，同时删除其关联的N24会话。
    - 当用户上线N24会话时，可以通过参数“接口类型”取值为“N15AM”和参数“会话标识”取值为“N24会话”删除该N24会话数据。
  - 查询到的备份数据字段的具体含义请参见备份文件末尾的“Reference Information”。
- 统计所有PES实例的2G会话数、3G会话数、4G会话数（不含VoLTE）、VoLTE会话数以及5G会话数。

  **说明** 

  - 对于执行命令输出结果文件输出到本地目录：/opt/csplog/{appID}/{service name}/export/log的，可以通过OM Portal下载。
  - 日志下载步骤参考服务日志收集，勾选“PcfPolicyEngineService”服务创建日志收集任务后进行下载。
- 输出共享关联关系。

## 注意事项

- 多FE组网场景下，需要先在PGW Web LMT MML命令界面执行**LST PDYNINFO**命令查询“Serving PCRF”，再根据“Serving PCRF”的信息到对应的PCRF命令配置界面执行本命令，才能导出用户在线会话信息。
- 当“命令类型”为“EXP\_GLB\_DATA(导出全局数据)”时，若需要在现网使用命令导出的数据进行定位或维护，请在华为技术工程师的指导下使用该命令。
- 当“命令类型”为“STR\_STAT\_SUBLIST(启动查询在线用户列表任务)”时，系统同时只支持一个任务的处理。请先执行查询命令**SET SERDBG:CMDTYPE=DSP\_SUBLIST\_FILE;**查看是否有任务正在执行中，如果有，请等正在执行的任务完成后再选择该命令类型执行，否则正在执行任务的实例会忽略对新任务的处理。
- 当“命令类型”为“PRT\_DATA(查询数据)”、“EXP\_SES\_DATA(导出全量会话数据)”时，若“SUBID”或“SESSIONID”不存在，则会返回一个空记录。若“SUBID”或“SESSIONID”存在，系统会先检查原文件大小。大于20M时，先删除原文件，并可能导致先前导出的数据丢失。
- 当“命令类型”为“EXP\_GLB\_DATA”时，输出结果返回报文SEQSUM，表示当前导出的全局数据的序列号。序列号不一致时，说明部分PES还没有刷新到最新的全局数据，反之序列号一致时说明PES已全部刷新到了最新的全局数据。导出全局数据失败时，则SEQSUM返回为“NULL”。
- 当“命令类型”为“DSP\_GLBDATAMD5”时，输出结果返回报文MD5，表示返回全局数据一致性MD5校验结果，对于同样内容的全局数据，MD5值是相同的；MD5校验不一致的PES则可能是全局数据刷新异常的PES，可能造成业务处理异常，需要联系华为技术支持。
- 当“命令类型”为“DSP\_GLBDATAMD5”时，输出结果返回报文File Name，表示返回计算MD5成功时的目标全局数据文件名称,其文件名称命名格式和参数说明EXP\_GLB\_DATA命令导出的文件名命名格式一致，导出的全局数据名称包含时间戳，以便识别最新导出的目标全局数据，导出的目标全局数据失败时或执行**EXP\_GLB\_DATA**命令选择“数据类型”的“PolicyData（策略数据）”为空时，则File Name返回为“NULL”。
- 可通过命令**SET SERDBG: CMDTYPE=PRT\_DATA, SMTYPE=UPM, PTYPE=SUBID, PVALUE="\*\*\*\*";**查询共享关联关系。对于关联关系较多时，输出结果只支持显示前20条。

  如果是主用户，输出结果显示“Master Relation: ”；如果是组用户，输出结果显示“Group Relation: ”；如果是父节点用户，输出结果显示“Parent Relation: ”。
- 当“命令类型”为“STR\_ERR\_TRACE（启动错误码跟踪）”时，DIAMETER返回响应消息包含“协议模块返回”和“业务模块（ALC和BLC）返回”两种情况，当前版本进行错误码跟踪时，只有业务模块返回指定错误码时，“STR\_ERR\_TRACE（启动错误码跟踪）”才跟踪输出会话信息。

  - 支持业务模块所有取值输出会话信息的错误码如下：

    - ABNU\_DIAMETER\_SUCCESS 2001
    - ABNU\_DIAMETER\_AUTHORIZATION\_REJECTED 5003

    - ABNU\_DIAMETER\_GQ\_INSUFFICIENT\_RESOURCES 5143

- 查询到的结果包含用户的个人数据，如：IMSI、MSISDN等。因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护。例如：
  1. 采用安全的文件传输协议（如SFTP）传输文件。
  2. 并严格控制文件的访问权限。
  3. 及时清理数据文件。

  若需从运营商网络中获取必要的数据，需要运营商维护人员对其中的个人数据进行匿名化处理，匿名化后的数据由运营商维护人员审核后提供，以防止个人数据泄露。匿名化处理工具可以在https://support.huawei.com/获取，获取方法请参见产品手册“匿名化工具安全策略”页面。
