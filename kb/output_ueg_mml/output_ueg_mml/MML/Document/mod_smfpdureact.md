# 修改跨区域PDU会话重建策略（MOD SMFPDUREACT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于修改一条跨区域PDU会话重建策略。

## 注意事项

- 该命令执行后立即生效。

- 本命令仅能修改参数“区域标识起始位置”和“区域标识终止位置”。
- 执行修改命令不配置SD时，默认修改SD值为“FFFFFF”的记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                   |
|:--------|:------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DNN     | DNN         | 可选必选说明：必选参数  参数含义：该参数用于指定跨区域PDU会话重建的DNN，即用户请求的DNN。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无  配置原则：无                                                                                                                                                                             |
| ISNSSAI | 是否匹配S-NSSAI | 可选必选说明：必选参数  参数含义：该参数用于表示跨区域PDU会话重建时是否匹配S-NSSAI。  数据来源：全网规划 取值范围： “YES（是）”：是“NO（否）”：否  默认值：无  配置原则：  如果运营商期望根据S-NSSAI和DNN的方式选择需要重建的PDU会话，则设置为“YES”；如果运营商期望仅根据DNN选择需要重建的PDU会话，则设置为“NO”。                                                                                                                                                                                                                 |
| SST     | 切片业务类型      | 可选必选说明：该参数在"ISNSSAI"配置为"YES"时为条件必选参数。  参数含义：该参数用于表示跨区域PDU会话重建时的网络切片业务类型。网络切片标识（S-NSSAI）由切片业务类型（SST）和切片细分标识（SD）两部分组成，其中切片细分标识是可选的。  数据来源：全网规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无                                                                                                                                                                                                                     |
| SD      | 切片细分标识      | 可选必选说明：该参数在"ISNSSAI"配置为"YES"时为条件可选参数。  参数含义：该参数用于表示跨区域PDU会话重建时的网络切片细分标识。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。只能由数字（0-9），字母（A-F、a-f）组成。字母大小写不敏感。  默认值：无  配置原则：无                                                                                                                                                                                                                                               |
| NBEGIN  | 区域标识起始位置    | 可选必选说明：可选参数  参数含义：该参数用于指定区域标识的起始字符位置。假设其取值为N，N表示NF Instance ID中node标识中的第N个字符。  数据来源：全网规划  取值范围：整数类型，取值范围是1~12。  默认值：无  配置原则：  I-SMF和SMF的NF Instance ID需要遵守UUID版本4的格式，运营商需要在node部分中使用固定的字符表示指定的区域。系统会针对I-SMF和SMF的NF Instance ID中node部分的第Nbegin~Nend个字符进行匹配：  如果完全相同，说明用户接入的I-SMF与SMF属于相同区域，否则，说明I-SMF与SMF属于不同的区域。  对于I-SMF和SMF不在相同区域PDU会话，当会话内只有缺省QoS Flow时，系统会发起PDU会话释放流程，并要求UE重新发起PDU会话激活，以尝试选择本地SMF。 |
| NEND    | 区域标识终止位置    | 可选必选说明：可选参数  参数含义：该参数用于指定区域标识的终止字符位置。假设其取值为N，N表示NF Instance ID中node标识中的第N个字符。  数据来源：全网规划  取值范围：整数类型，取值范围是1~12。  默认值：无  配置原则：  该参数的取值需要大于等于“区域标识起始位置”，请参见“区域标识起始位置”参数的说明。                                                                                                                                                                                                                               |

## 使用实例

修改一条“DNN”为IMS的跨区域PDU会话重建策略，其中“区域标识起始位置”修改为3、“区域标识终止位置”修改为6、“HR场景是否支持重建”修改为不支持：

```
MOD SMFPDUREACT: DNN="IMS", ISNSSAI=NO, NBEGIN=3, NEND=6;
```
