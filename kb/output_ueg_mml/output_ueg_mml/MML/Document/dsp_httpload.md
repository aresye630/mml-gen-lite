# 查询HTTP消息负载信息(DSP HTTPLOAD)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询当前所有HLB实例的链路负载信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                    |
|:-------|:-------|:----------------------------------------------------------------------------------------|
| TYPE   | 链路类型   | 可选必选说明：必选参数 参数含义：用于指定系统按照哪种链路类型查询均衡操作信息。 取值范围：SERVER(SERVER) 默认值：SERVER(SERVER) 配置原则：无。 |

## 使用实例

查询服务端链路的均衡操作信息。

```
DSP HTTPLOAD: TYPE=SERVER;
```

```
%%DSP HTTPLOAD: TYPE=SERVER;%%
RETCODE = 0  操作成功
操作结果如下:
-------------
HLB实例ID             平均CPU   与所有实例平均CPU比例  实例平均TPS  链路平均TPS  平均链路数  均衡控制链路数
11787404355612245023  68%       168%                   5600         320          31254       100 
11787404355612056795  31%       62%                    2100         100          1600        50
(结果个数 = 2)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，输出项如表1所示。

| 输出项名称        | 输出项解释                                       |
|:-------------|:--------------------------------------------|
| HLB实例ID      | 用于显示HLB的实例ID。                               |
| 平均CPU        | 用于显示HLB的平均CPU使用率。                           |
| 与所有实例平均CPU比例 | 用于显示该HLB的平均CPU使用率与所有HLB实例平均CPU使用率的比例。       |
| 链路平均TPS      | 用于显示所有HLB链路的平均TPS（Transactions Per Second）。 |
| 实例平均TPS      | 用于显示HLB实例的平均TPS（Transactions Per Second）。   |
| 平均链路数        | 用于显示每日凌晨02时08分到当前查询时间点的HLB的平均链路数。           |
| 均衡控制链路数      | 用于显示当前HLB实例使用均衡控制机制建链的链路数。                  |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释           | 原因分析                                        | 处理建议                             |
|-------:|:----------------|:--------------------------------------------|:---------------------------------|
|    520 | 部分成功            | 查询结果中存在部分失败数据。                              | 等待5分钟后，重新执行本命令；如果重试失败，请联系华为技术支持。 |
| 360131 | 查询服务类型实例不存在     | 当前查询的HLB服务不存在服务实例。                          | 联系华为技术支持，检查HLB服务状态是否正常。          |
| 360175 | 内部数据生成中，请稍后再试   | HLB内部的平均数据“平均CPU”、“实例平均TPS”、“平均链路数”等参数还未生成。 | 等待5分钟后，重新执行本命令。                  |
| 360176 | 正在执行链路均衡中，请稍后再试 | 链路均衡操作未结束，系统正在处理中。                          | 需要等待均衡操作结束后才可以执行命令。              |
