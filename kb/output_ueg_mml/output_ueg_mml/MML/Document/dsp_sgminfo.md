# 查询SGM服务信息（DSP SGMINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于SGM服务状态信息查询与显示。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数描述                                                                                                                                                                                                                                                                    |
|:-----------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CMDTYPE    | 命令类型   | 可选必选说明：必选参数 参数含义：用于指定业务模块调试命令的操作类型。 取值范围： DSP_MEMINFO(查询内存信息)：用于查询指定的SGM服务的内存占用情况。DSP_CBINFO(查询控制块信息)：用于请求按指定条件显示服务控制块资源的使用信息。DSP_SERVICEINFO(查询服务信息)：用于查询SGM服务的服务信息。DSP_TOKENINFO (查询服务Token信息)：用于查询SGM服务的Token信息。DSP_INAT(查询内部审计任务报告)：用于查询SGM服务内部审计任务报告。 默认值：无 配置原则：无 |
| INSTANCENO | SGM实例号 | 可选必选说明：可选参数 参数含义：用于指定调试命令对应的实例号。 取值范围：长度不超过256的字符串。 默认值：无。 配置原则：执行DSP SGMINFO命令获取返回服务的实例号。                                                                                                                                                                              |
| RESULTTYPE | 结果类型   | 可选必选说明：当“CMDTYPE”选择“DSP_INAT”时，显示参数“RESULTTYPE”，此时“RESULTTYPE”为必选参数。 参数含义：用于请求系统按照哪种结果类型显示内部审计任务信息。 取值范围： CURRENT(当前审计任务信息)：查看当前审计任务。HISTORY(查看历史审计任务)：查看历史审计任务。 默认值：无。                                                                                                 |
| ATTYPE     | 审计类型   | 可选必选说明：当“CMDTYPE”选择“DSP_INAT”时，显示参数“ATTYPE”，此时“ATTYPE”为可选参数。 参数含义：用于标识审计类型。 取值范围： OTMODULE(设备间审计)：用于SGM服务内用户控制块审计。HASH(哈希审计)：用于SGM服务内哈希表的审计。 默认值：OTMODULE(设备间审计)。                                                                                                       |

## 使用实例

日常维护管理，“CMDTYPE”取值为“DSP\_SERVICEINFO”时，查询SGM服务信息，实例如下。

```
DSP SGMINFO: CMDTYPE=DSP_SERVICEINFO;
```
