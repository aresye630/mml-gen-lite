# 修改HLB系统软参(MOD HLBSSP)

- 命令功能
- 注意事项

- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致系统异常，影响业务处理，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于修改HLB系统软件参数的配置信息。

## 注意事项

- 在缺省的情况下，系统在初始化的时候已经预置了软参数据表中的全部数据。
- 操作员应使用默认值。如果操作员确实需要修改软件参数，请联系华为公司技术服务工程师处理，禁止随意修改。
- 修改软件参数后，执行DSP HLBSSP命令检查软件参数值是否生效。若修改软参值未生效，请参考产品手册的“HLB系统软参”，查看修改软参值的生效方式。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SCP    | 系统配置参数 | 可选必选说明：必选参数 参数含义：系统配置参数标识。 取值范围： SYSPARAMETER(系统参数) 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| SPN    | 参数名    | 可选必选说明：必选参数 参数含义：标识软件参数名称，用于指定需要对哪一类软参数据记录的参数进行修改。 取值范围： VRM_CHKCERTURL(设备证书域名校验)VRM_HLBCRLPOLICY(HLB数字证书CRL处理策略)VRM_HTTP2IDLETIME（HTTP2空闲拆链超时时间）VRM_CHKHTTPREQPARASWITH（HTTP请求参数校验开关）VRM_LINKOFNFIPPERHLB（单个HLB和一个NF IP的最大链路数）VRM_GENCCA（设置UPCF作为Consumer是否生成CCA）VRM_CCAVALIDITYPERIOD（设置UPCF作为Consumer时CCA的有效期）VRM_CHECKCCA（设置UPCF作为Producer是否检查CCA）VRM_DISABLESIGNALE2ETRACE（信令E2E跟踪功能开关） 详细信息请参考产品手册的“UPCF软件参数 > HLB系统软参”。 默认值：无。 配置原则：无。  说明： VRM_LINKOFNFIPPERHLB（单个HLB和一个NF IP的最大链路数）和VRM_HTTP2IDLETIME（HTTP2空闲拆链超时时间）软参在当前版本已废弃。 |
| SPV    | 参数值    | 可选必选说明：必选参数 参数含义：标识软件参数的值，此处取值应在软件参数的取值范围内取值。详细信息请参考产品手册的“UPCF软件参数 > HLB系统软参”。 取值范围：0～2147483647 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                          |

## 使用实例

修改HLB系统软参。为保证对接设备间数字证书使用的安全性，在系统检查到对端数字证书存在CRL中，则中断对端链路：设置“系统配置参数”为“SYSPARAMETER(系统参数)”，“参数名”为“VRM\_HLBCRLPOLICY(HLB数字证书CRL处理策略)”，“参数值”软参设置为“1”。

```
MOD HLBSSP: SCP=SYSPARAMETER, SPN=VRM_HLBCRLPOLICY, SPV=1;
```
