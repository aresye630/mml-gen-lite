#### 命令功能

**适用网元：MME**

本命令用于查询系统内正在使用的Sdup接口链路详细信息。

输出结果分为两个报表，报表1显示每条链路的状态以及链路指向的对端MME；报表2显示正常与故障状态的链路数量。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug；visit-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组；G\_4，来宾级别命令组

#### 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                       |
|:---------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SCOPE    | 查询范围    | 可选必选说明：可选参数 参数含义：本参数用于指示查询Sdup链路信息的范围 数据来源：本端规划。 取值范围：“ALL(所有信息)”“SPECIFIED_MME(指定对端MME)” 默认值：“ALL(所有信息)”                                                                  |
| PEERMMEC | 对端MME编码 | 可选必选说明：条件必选参数 参数含义：本参数用于指示目标MME编码。 系统按MME编码匹配对应的MME，并获取该MME下的Sdup IP地址，输出结果为包含这些IP地址的Sdup链路信息。 前提条件：此参数在“查询范围”参数配置为“SPECIFIED_MME(指定对端MME)”后生效。 数据来源：本端规划 取值范围：0～255 默认值：无 |
| SPECPROC | 指定进程    | 可选必选说明：可选参数 参数含义：本参数用于指示是否按指定进程查询Sdup链路信息。 数据来源：本端规划 取值范围：“UNSPECIFIED(不指定)”：系统将自动选择支持链路探测的进程查询。“SPECIFIED(指定)”：系统只向指定的进程查询。 默认值：“UNSPECIFIED”                             |
| RUNAME   | RU名称    | 可选必选说明：条件必选参数 参数含义：该参数用于指定资源单元名称。 前提条件：该参数在“指定进程”参数配置为“SPECIFIED(指定)”后生效。 数据来源：该参数可以在MCR_VNFC的CLI中通过DSP RU命令查询。 取值范围：1~63位字符串 默认值：无                                        |
| PRON     | 进程号     | 可选必选说明：条件必选参数 参数含义：本参数用于指示查询的SAP进程号。 前提条件：该参数在“指定进程”参数配置为“SPECIFIED(指定)”后生效。 数据来源：本端规划 取值范围：0～20 默认值：无                                                                     |

#### 使用实例

显示Sdup链路信息：

DSP SDAPLNK: SCOPE=ALL, SPECPROC=UNSPECIFIED;

```
%%DSP SDAPLNK: SCOPE=ALL, SPECPROC=UNSPECIFIED;%%
RETCODE = 0  操作成功

操作结果如下：
------------------------
     对端MME编码  =  53
         RU名称   =  MCR_SP_RU_0064
         进程号   =  0
        链路状态  =  正常
      本端IP地址  =  192.168.15.10
      对端IP地址  =  192.168.16.10
仍有后续报告输出
---    END

+++    mcr        2017-02-15 13:55:47
O&M   #HWHandle=172
%%DSP SDAPLNK: SCOPE=ALL, SPECPROC=UNSPECIFIED;%%
RETCODE = 0  操作成功

操作结果如下：
------------------------
正常状态Sdup链路数  =  1
故障状态Sdup链路数  =  0
(结果个数 = 2)
共有2个报表
---    END
```

#### 输出结果说明

| 输出项名称       | 输出项解释                                                                                   |
|:------------|:----------------------------------------------------------------------------------------|
| 对端MME编码     | 参数含义：该参数指示查询的Sdup链路对端的MME编码。 取值范围：0~255  说明： 本参数属于报表1。                                  |
| RU名称        | 参数含义：该参数用于指定资源单元名称。 取值范围：1~63位字符串  说明： 本参数属于报表1。                                        |
| 进程号         | 参数含义：该参数指示查询的SAP进程的进程号。 取值范围：0~20  说明： 本参数属于报表1。                                        |
| 本端IP地址      | 参数含义：该参数指示查询的Sdup链路本端IP。 取值范围：0.0.0.0~255.255.255.255  说明： 本参数属于报表1。                    |
| 对端IP地址      | 参数含义：该参数指示查询的Sdup链路对端IP。 取值范围：0.0.0.0~255.255.255.255  说明： 本参数属于报表1。                    |
| 链路状态        | 参数含义：本参数表示Sdup链路的状态。 取值范围：“NORMAL(正常)”“FAULT(故障)”（故障状态下，系统上报SDUP链路故障 告警）  说明： 本参数属于报表1。 |
| 正常状态Sdup链路数 | 参数含义：本参数表示处于正常状态的Sdup链路数量。 取值范围：0~4294967295  说明： 本参数属于报表2。                             |
| 故障状态Sdup链路数 | 参数含义：本参数表示处于故障状态的Sdup链路数量。 取值范围：0~4294967295  说明： 本参数属于报表2。                             |
