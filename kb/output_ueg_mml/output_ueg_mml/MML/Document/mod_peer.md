# 修改PCRF的Diameter对端(MOD PEER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

用于修改配置数据库中一条与PCRF直连的Diameter对端实体数据记录。

该命令的使用场景：当UPCF与DRA对接的场景下，该命令用于修改与PCRF连接的DRA实体信息。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                     |
|:--------------|:------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PCRFID        | PCRF标识      | 用于定义PCRF实体标识，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围：1 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                |
| PEERID        | 对端标识        | 用于定义UPCF的配置库中的一个Diameter对端实体。该参数的配置原则：如果配置多个Diameter对端实体，从0开始顺序配置。 取值范围：0～127 默认值：无。 说明： 对端类型选择DRA时，对端标识的取值范围是0～15。对端类型选择TDF时，对端标识的取值范围是0～（VRM_MAXTDFNUM–1）。软参VRM_MAXTDFNUM用于设置PCRF中允许配置的TDF对端个数的最大值，默认值为16。可以通过MOD PCFINSP命令进行修改，取值范围是1～128。                                                                                                                                                                                            |
| PT            | 对端类型        | 用于定义对端类型。 取值范围： DRA(DRA)TDF(TDF) 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                  |
| PN            | 对端名称        | 用于定义对端的名称，以便于识别。 取值范围：长度不超过128的字符串 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                |
| DN            | 对端域名        | 用于定义对端域名，该参数需要与对端协商一致。 取值范围：长度不超过64的字符串 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                           |
| HN            | 对端主机名       | 用于定义对端的主机名称，该参数需要与对端协商一致。 取值范围：长度不超过127的字符串 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                       |
| SKA           | 业务保活时长 （s）  | 用于定义业务保活时间。当与对端通讯出现故障时，在业务保活时间内，会话是不会释放的。 单位：秒。 取值范围：0～3600 默认值： 无。  说明： 若软参“VRM_SESSIONBACKUPSWITCH”取值为非0，则该参数不生效。                                                                                                                                                                                                                                                                                                                      |
| DASWITCH      | 审计开关        | 用于定义设备间的Gx、Rx、Sy、Sd会话定时审计开关。 取值说明： 全部选中（打开Gx、Rx、Sy、Sd定时审计）全部清空（关闭Gx、Rx、Sy、Sd定时审计）全部灰化（用于同时灰化Gx、Rx、Sy、Sd定时审计，灰化掉的参数表示不被修改，在执行MOD PEER命令时被灰化掉的参数保持原有值。）GxON (打开Gx定时审计)RxON (打开Rx定时审计)SdON (打开Sd定时审计)SyON (打开Sy定时审计) 默认值：无。  说明： 当“对端类型”设置为“TDF”时，仅能打开Sd定时审计。当“审计开关”设置为“全部选中”或“GxON”时，以下软参控制只应用于Gx接口会话：当软参“VRM_DEVAUDITSTARTTIME”取值为“5”时，表示系统对创建时间未超过5分钟的会话不发起设备间审计。当软参“VRM_DEVAUDITSTARTTIME”取值为“X（5＜X≤1440）”时，表示系统对更新时间未超过X分钟的会话不发起设备间审计。 |
| ABILITYDICTID | 能力字典ID      | 对端类型为TDF时，可以设置该参数。用于设置对端能力字典。 取值范围：0～127 取值说明：能力字典ID的具体取值由ADD PCEFABIDICT命令定义。 默认值： 无                                                                                                                                                                                                                                                                                                                                                    |
| PEERCAT       | 对端类别        | 对端类型为TDF时，可以设置该参数。用于选择对端类别。 取值说明：由ADD PPCEFCAT命令定义的对端类别。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                          |
| DATIME        | 设备间审计时长 （m） | 用于定义设备间会话审计的时长。 该参数的配置原则： 若设备间“审计开关”全部关闭时，“设备间审计时长”必须为空。若设备间“审计开关”有一项或多项打开时，“设备间审计时长”必须不为空。 单位：分钟。 取值范围：15～1440 默认值：无。                                                                                                                                                                                                                                                                                                                   |
| PLSMODE       | 对端链路选择方式    | 对端类型为DRA时，可以设置该参数。用于指定UPCF和一个DRA建立多条链路时的链路选择方式。 取值说明： ROUND_ROBIN（轮询模式）MASTER_SLAVE（主备模式） 默认值：无。  说明： 该参数取值为“MASTER_SLAVE（主备模式）”时，同一个对端将按“对端链路标识”的取值选择主链路，“对端链路标识”的取值越小则优先级越高。                                                                                                                                                                                                                                                           |

## 使用实例

1. 修改PCRF对端实体配置信息。“PCRF标识”为“1”，“对端标识”为“0”，“对端类型”为“DRA”，“对端名称”改为“DRA1”。

   ```
   MOD PEER: PCRFID=1, PEERID=0, PT=DRA, PN="DRA1";
   ```
2. 修改PCRF对端实体配置信息。“PCRF标识”为“1”，“对端标识”为“0”，“对端类型”为“DRA”，“对端名称”为“DRA1”，“对端域名”为“DRA1domain”，“对端主机名”为“DRA1host”，“业务保活时长”为“90”，“审计开关”为“GxON”，“设备间审计时长”为“720”。

   ```
   MOD PEER: PCRFID=1, PEERID=0, PT=DRA, PN="DRA1", DN="DRA1domain", HN="DRA1host", SKA=90, DASWITCH=GxON-1, DATIME=720;
   ```
3. 修改PCRF对端实体配置信息。“PCRF标识”为“1”，“对端标识”为“0”，“对端类型”为“DRA”，“对端名称”为“DRA1”，“对端域名”为“DRA1domain”，“对端主机名”为“DRA1host”，“业务保活时长”为“90”，“审计开关”为“GxON”，“设备间审计时长”为“720”，“对端链路选择方式”为“MASTER\_SLAVE”。

   ```
   MOD PEER: PCRFID=1, PEERID=0, PT=DRA, PN="DRA1", DN="DRA1domain", HN="DRA1host", SKA=90, DASWITCH=GxON-1, DATIME=720, PLSMODE=MASTER_SLAVE;
   ```
