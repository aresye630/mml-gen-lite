# 查询策略管理服务管理员IP地址(LST PMSADMINIP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询登录策略管理服务的管理员的IP地址信息。

- 若需要查询全部管理员IP地址信息，请不要输入任何参数。
- 若需要查询某个管理员IP地址信息，请依据参数说明输入查询的条件。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                                  |
|:------------|:-----------|:----------------------------------------------------------------------------------------------------------------------|
| IPID        | IP地址索引     | 可选必选说明：可选参数 参数含义：用于指示UPCF需要按照哪个IP地址索引来查询策略管理服务的管理员IP地址配置信息；若不输入，则表示所有的IP地址索引。 取值范围：1～256 默认值：无。 配置原则：无。               |
| IPVER       | IP版本       | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个IP版本类型来查询策略管理服务的管理员IP地址配置信息；若不输入，则表示所有的IP版本类型。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。 |
| IP          | IP地址       | 可选必选说明：可选参数 参数含义：用于指示UPCF需要按照哪个IPv4地址来查询策略管理服务的管理员IP地址配置信息；若不输入，则表示所有的IPv4地址。 取值范围：IPv4地址 默认值：无。 配置原则：无。              |
| NETMASK     | 子网掩码       | 可选必选说明：可选参数 参数含义：用于指示UPCF需要按照哪个子网掩码来查询策略管理服务的管理员IP地址配置信息；若不输入，则表示所有的子网掩码。 取值范围：IPv4地址 默认值：无。 配置原则：无。                  |
| IPV6        | IPV6地址     | 可选必选说明：可选参数 参数含义：用于指示UPCF需要按照哪个IPv6地址来查询策略管理服务的管理员IP地址配置信息；若不输入，则表示所有的IPv6地址。 取值范围：IPv6地址 默认值：无。 配置原则：无。              |
| IPV6MASK    | IPV6地址前缀长度 | 可选必选说明：可选参数 参数含义：用于指示UPCF需要按照哪个IPV6前缀长度来查询策略管理服务的管理员IP地址配置信息；若不输入，则表示所有的IPV6前缀长度。 取值范围：1~128 默认值：无。 配置原则：无。           |
| DESCRIPTION | 描述         | 可选必选说明：可选参数 参数含义：用于指示UPCF需要按照哪个描述来查询策略管理服务的管理员IP地址配置信息；若不输入，则表示所有的描述。 取值范围：长度不超过48的字符串 默认值：无。 配置原则：无。                 |

## 使用实例

1. 查询全部的策略管理服务管理员IP地址信息。

   ```
   LST PMSADMINIP:;
   ```

   输出结果如下：

   ```
   %%LST PMSADMINIP:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   IP地址索引  IP版本  IP地址           子网掩码       IPV6地址                                  IPV6地址前缀长度  描述  

   12          IPV4    192.168.123.111  255.255.255.0  NULL                                      NULL              IPv4 
   15          IPV6    NULL             NULL           2001:0db8:80ff:fa01:0000:0000:0000:1515   64                IPv6   
   (结果个数 = 2)

   ---    END
   ```
2. 查询一个策略管理服务管理员的IP地址信息。“IP地址索引”为“12”。

   ```
   LST PMSADMINIP: IPID=12;
   ```

   ```
   %%LST PMSADMINIP: IPID=12;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
         IP地址索引  =  12
             IP版本  =  IPV4
             IP地址  =  192.168.123.111
           子网掩码  =  255.255.255.0
           IPV6地址  =  NULL
   IPV6地址前缀长度  =  NULL
               描述  =  IPv4
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD PMSADMINIP**命令的参数说明。
