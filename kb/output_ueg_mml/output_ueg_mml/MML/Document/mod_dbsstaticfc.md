# 修改DBS静态流控配置(MOD DBSSTATICFC)

## 命令功能

**须知** 

该命令属于高危命令，执行不当将导致DBS无法启控或过早起控，引起业务受损。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于DBS启动静态流控特性时，修改DBS静态流控参数。

当单个DBS收到的请求消息速率过快，超过系统设置的“限制请求速率”，且突发请求的消息数达到系统设置的“突发请求数 ”时，产生**ALM-22908 DBS静态流控启动**告警。操作人员可通过**LST DBSSTATICFC**命令查询系统设置的阈值。

**说明** 

DBS收到的请求消息的速率超过“限制请求速率”值后，系统不会立即丢弃消息，而是继续处理消息，当处理的消息达到系统配置“突发请求数”值后，开始丢弃消息并上报流控告警。

## 注意事项

- 当开启静态流控后，系统将自动丢弃超过系统设置阈值的消息，导致与这些消息相关的业务处理失败。
- 该命令不允许进行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                           |
|:-------------|:-------|:-----------------------------------------------------------------------------------------------|
| LIMITREQRATE | 限制请求速率 | 可选必选说明：必选参数 参数含义：用于指定单个DBS启动静态流控特性系统限制接收请求消息的速率。 取值范围：1000～100000 默认值：无。 配置原则：系统初始设置值为“30000”。 |
| BURSTREQNUM  | 突发请求数  | 可选必选说明：必选参数 参数含义：用于指定单个DBS启动静态流控特性系统限制接收突发请求消息的数目。 取值范围：100～1000 默认值：无。 配置原则：系统初始设置值为“500”。    |

## 使用实例

某局点的FE侧发送命令的速度过快，设置DBS静态流控参数，将“限制请求速率”修改为“1000”，“突发请求数”修改为“100”：

```
MOD DBSSTATICFC: LIMITREQRATE=1000, BURSTREQNUM=100;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
