## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于启动HLB的链路均衡操作。

执行该命令后DCS广播查询HLB相关负载信息，HLB在响应消息中上报24小时内的“平均CPU”、“实例平均 TPS”、“平均链路数” ，DCS接收到所有HLB响应或等待10秒超时后，对同时满足以下两个条件的HLB发送链路均衡请求：

- 该HLB的“平均CPU”大于由**MOD UDMSOFTPARA**命令设置的“服务端链路均衡CPU门限”
- 该HLB的“与所有实例平均CPU比例”达到由**MOD UDMSOFTPARA**命令设置的“服务端链路均衡CPU比例”

HLB收到请求后， 根据链路的消息数峰值从大到小排序，对消息数大的链路进行删除操作，删除链路的比例为**MOD UDMSOFTPARA**命令设置的“服务端链路均衡百分比”。

系统除了支持通过该命令进行手动均衡之外，还可以通过命令**MOD UDMSOFTPARA**控制软参“服务端链路定时均衡开关”来设置定时链路均衡操作，定时操作的时间是每日凌晨02时08分。

## 注意事项

当系统正处于升级状态时，该命令无法执行。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                             |
|:-------|:-------|:---------------------------------------------------------------------------------|
| TYPE   | 链路类型   | 可选必选说明：必选参数 参数含义：用于指定进行均衡操作的链路类型。 取值范围：SERVER(SERVER) 默认值：SERVER(SERVER) 配置原则：无。 |
| MODE   | 均衡方法   | 可选必选说明：可选参数 参数含义：用于指定启动链路的均衡操作方法。 取值范围：LINKNUMCTRL(链路数控制) 默认值：无。 配置原则：无。         |

## 使用实例

对服务端链路进行均衡操作。

```
STR BALANCEHTTPLINK: TYPE=SERVER,MODE=LINKNUMCTRL;
```

```
%%STR BALANCEHTTPLINK: TYPE=SERVER, MODE=LINKNUMCTRL, CONFIRM=Y;%%
RETCODE = 0  操作成功
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，输出项如表1所示。

| 输出项名称   | 输出项解释                                      |
|:--------|:-------------------------------------------|
| HLB实例ID | 用于显示HLB的实例ID。                              |
| 执行均衡操作  | 用于显示是否执行了链路均衡操作。                           |
| 删除链路个数  | 用于显示执行均衡操作而删除的链路个数。                        |
| 平均CPU   | 用于显示该HLB的平均CPU使用率。                         |
| 实例平均TPS | 用于显示该HLB实例的平均TPS（Transactions Per Second）。 |
| 平均链路数   | 用于显示每日凌晨02时08分到当前查询时间点的HLB的平均链路数。          |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释           | 原因分析                                       | 处理建议                                                     |
|-------:|:----------------|:-------------------------------------------|:---------------------------------------------------------|
| 360174 | 升级过程中无法执行，请稍后再试 | 系统正处于升级状态。                                 | 执行MOD UDMSOFTPARA命令查看“系统状态”软参，确保软参取值为0，即系统为正常状态，则可执行该命令。 |
| 360175 | 内部数据生成中，请稍后再试   | HLB内部的平均数据“平均CPU”、“平均 TPS”、“平均服务端链路数”还未生成。 | 等待5分钟后，执行DSP HTTPLOAD命令，确认HLB上报的平均数据存在后执行该命令。            |
| 360176 | 链路均衡正在执行中，请稍后再试 | 上一次执行的链路均衡操作未结束，系统正在处理中。                   | 需要等待上一次操作结束后才可以执行命令进行下一次均衡操作。                            |
