# 查询被禁用网关配置(LST BLKGWLST)

- 适用网元
- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 适用网元

SGSN，MME

#### 命令功能

该命令用于查询被禁用网关列表。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                          |
|:---------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GWTYPE   | 网关类型   | 可选必选说明：可选参数 参数含义：该参数表示被禁用网关的逻辑形态。 数据来源：全网规划 取值范围：枚举类型“GGSN（GGSN）”“S-GW（S-GW）”“P-GW（P-GW）” 默认值：无。 配置原则：无。                                                                                                                                                                      |
| GWIPTYPE | 网关IP类型 | 可选必选说明：可选参数 参数含义：该参数表示被禁用网关的业务地址类型。 数据来源：全网规划 取值范围：枚举类型。“IPv4（IPv4）”“IPv6（IPv6）” 默认值：无 配置原则：无。                                                                                                                                                                                |
| GWIPV4   | IPv4地址 | 可选必选说明：条件可选参数 参数含义：该参数表示被禁用网关的IPv4地址。 前提条件：该参数在“网关IP类型”参数配置为“IPv4（IPv4）”后生效。 数据来源：全网规划 取值范围：0.0.0.1~255.255.255.254 默认值：无 配置原则：有效的IPv4地址不能为环回地址(127.x.y.z)。有效的IPv4地址必须是A、B或者C类地址。                                                                                             |
| GWIPV6   | IPv6地址 | 可选必选说明：条件可选参数 参数含义：该参数表示被禁用网关的IPv6地址。 前提条件：该参数在“网关IP类型”参数配置为“IPv6（IPv6）”后生效。 数据来源：全网规划 取值范围：::~FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 配置原则：IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址（::1）、链路本地地址（FE80::/10）、组播地址（FF00::/8）、IPv4映射地址及IPv4兼容地址。 |

#### 使用实例

不输入查询条件，查询表中全部信息：

LST BLKGWLST:;

```
%%LST BLKGWLST:;%%

```
