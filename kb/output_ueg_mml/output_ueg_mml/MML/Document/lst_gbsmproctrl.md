# 查询Gb模式SM流程控制参数（LST GBSMPROCTRL）

#### 命令功能

**适用网元：SGSN**

该命令用于查询Gb模式SM流程控制参数。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                               |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROT   | 流程类型   | 可选必选说明：可选参数 参数含义：该参数用于指定流程类型，要根据场景来配置相应的流程。 取值范围：“ACT_PROC(激活流程)”“MOD_PROC(修改流程)”“PFC_PROC(PFC流程)”“HSS_INIT_SUB_QOS_MOD_PROC(HSS发起的签约QoS修改流程)” 默认值：无  说明： 若不输入流程类型，则将显示所有流程类型的原因值。 |

#### 使用实例

查询“流程类型”为“修改流程”的Gb模式SM流程控制参数：

LST GBSMPROCTRL: PROT=MOD\_PROC;

```
%%LST GBSMPROCTRL: PROT=MOD_PROC;%%
RETCODE = 0  操作成功。

操作结果如下
--------------
修改拒绝原因值（GGSN拒绝）  =  3
(结果个数 = 1)

---    END
```
