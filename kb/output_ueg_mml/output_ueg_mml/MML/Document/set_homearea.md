# 设置UPCF归属地信息(SET HOMEAREA)

- 注意事项

## 命令功能

该命令为配置类命令，用于设置UPCF归属地信息。

UPCF支持通过DRS服务将本端报表信息上传到远端POP-D服务器，本命令用于标识本端PCF的归属地信息（由运营商定义），以便POP-D服务器可以识别不同归属地PCF上报的报表信息。

## 注意事项

无。

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                         |
|:-------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------|
| PROVINCECODE | 省份代号   | 可选必选说明：必选参数 参数含义：用于标识PCF策略统计数据来源的省份代号。 取值范围：2位英文大写字母。 默认值：无。 配置原则：各省份缩写，如ZB（总部），AH(安徽)。当出现重复的省份缩写或者省份缩写超出2位等特殊情况时，可参考表2进行配置。 |
| PCFID        | PCF编号  | 可选必选说明：必选参数 参数含义：用于标识PCF策略统计数据来源的PCF编号。 取值范围：长度不超过32的字符串。字符串只能由数字、字母和“_”组成。 默认值：无。 配置原则：一般由地理标识、网元标识、网元序号、网元属性、厂家标识五部分组成。    |

## 使用实例

设置UPCF归属地信息为北京。

```
SET HOMEAREA: PROVINCECODE="BJ", PCFID="JNPCRFPLS01BHW";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                   | 原因分析                    | 处理建议                               |
|------:|:------------------------|:------------------------|:-----------------------------------|
| 58054 | PCFID取值只能是数字、大小写字母、下划线。 | PCFID取值只能是数字、大小写字母、下划线。 | 重新输入“PCFID”，确保取值只有0～9，a～z，A～Z和“_”。 |
