# 删除NRF管理的ProxySMF（RMV NRFPROXYSMF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于删除NRF管理的ProxySMF。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                             |
|:-------------|:-------|:-------------------------------------------------------------------------------------------------|
| NFINSTANCEID | NF实例标识 | 可选必选说明：必选参数  参数含义：该参数用于表示本NRF管理的ProxySMF实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~36。  默认值：无  配置原则：无 |

## 使用实例

删除NF实例标识为Nfinstanceid01的NF的信息。

```
RMV NRFPROXYSMF: NFINSTANCEID="Nfinstanceid01";
```
