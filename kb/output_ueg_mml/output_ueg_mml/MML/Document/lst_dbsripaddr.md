# 查询远端网元IP地址(LST DBSRIPADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询远端网元IP地址：

- 若需要查询全部远端网元IP地址的概要信息，请不要输入任何参数。
- 若需要查询某条远端网元IP地址的详细信息，请输入“远端Location标识”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称               | 参数说明                                                                                                                                                                                    |
|:--------|:-------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RLOCID  | 远端Location标识       | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个远端Location来查询远端网元IP地址信息；若不输入，则表示查询所有Location的远端网元IP地址信息。 取值范围：1～512 默认值：无。 配置原则：无                                                                          |
| ID      | 远端业务IP的索引          | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个远端业务IP的索引来查询远端网元IP地址信息；若不输入，则表示查询所有远端业务IP的索引对应的远端网元IP地址信息。 取值范围：1～4080 默认值：无。 配置原则：无                                                                       |
| IPVER   | IP类型               | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个IP类型来查询远端网元IP地址信息；若不输入，则表示查询所有IP类型所对应的远端网元IP地址信息。 取值范围： IPV4IPV6 默认值：无。 配置原则：无                                                                             |
| IPV4IP1 | 远端Location IPV4地址1 | 可选必选说明：条件可选参数 参数含义：用于指示系统需要按照哪个远端Location IPV4地址1来查询远端网元IP地址；若不输入，则表示查询所有远端Location IPV4地址1对应的远端网元IP地址信息。 取值范围：IPV4地址。 默认值：无。 配置原则：仅当本命令中的“IP类型”参数取值为“IPV4(IPV4)”时该参数有效。                |
| IPV4IP2 | 远端Location IPV4地址2 | 可选必选说明：条件可选参数 参数含义：用于指示系统需要按照哪个远端Location IPV4地址2来查询远端网元IP地址；若不输入，则表示查询所有远端Location IPV4地址2对应的远端网元IP地址信息。 取值范围：IPV4地址。 默认值：无。 配置原则：仅当本命令中的“IP类型”参数取值为“IPV4(IPV4)”时该参数有效。                |
| IPV6IP1 | 远端Location IPV6地址1 | 可选必选说明：条件可选参数 参数含义：用于指示系统需要按照哪个远端Location IPV6地址1来查询远端网元IP地址；若不输入，则表示查询所有远端Location IPV6地址1对应的远端网元IP地址信息。 取值范围：IPV6地址。 默认值：无。 配置原则：仅当本命令中的“IP类型”参数取值为“IPV6(IPV6)”时该参数有效。                |
| IPV6IP2 | 远端Location IPV6地址2 | 可选必选说明：条件可选参数 参数含义：用于指示系统需要按照哪个远端Location IPV6地址2来查询远端网元IP地址；若不输入，则表示查询所有远端Location IPV6地址2对应的远端网元IP地址信息。 取值范围：IPV6地址。 默认值：无。 配置原则：仅当本命令中的“IP类型”参数取值为“IPV6(IPV6)”时该参数有效。                |
| RIPST   | 远端IP地址业务类型         | 可选必选说明：条件可选参数 参数含义：用于指示系统需要按照哪个远端网元IP地址的业务类型来查询远端网元IP地址信息，若不输入，则表示查询所有远端IP地址业务类型对应的远端网元IP地址信息。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：该参数为联想参数列表，不能手动输入，其取值为LST DBSSRVGROUP命令查询获得的“业务类型名称”输出参数。 |

## 使用实例

1. 查询所有远端网元IP地址：

   ```
   LST DBSRIPADDR:;
   ```

   ```
   %%LST DBSRIPADDR:;%%
   RETCODE = 0  操作成功

    远端Location标识  远端业务IP的索引  IP类型  远端Location IPV4地址1  远端Location IPV4地址2  远端Location IPV6地址1  远端Location IPV6地址2  远端IP地址业务类型

    10                11                IPV4    192.168.21.150           192.168.21.151          NULL                    NULL                   SUP-FE
    11                11                IPV4    192.168.21.152           192.168.21.153          MULL                    MULL                   SUP-FE
   (结果个数 = 2)

   ---    END
   ```
2. 查询某个远端网元IP地址，“远端Location标识”为“11”，“远端业务IP的索引”为“11”：

   ```
   LST DBSRIPADDR: RLOCID=11, ID=11;
   ```

   ```
   %%LST DBSRIPADDR: RLOCID=11, ID=11;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
         远端Location标识  =  11
         远端业务IP的索引  =  11
                   IP类型  =  IPV4
   远端Location IPV4地址1  =  192.168.21.152
   远端Location IPV4地址2  =  192.168.21.153
   远端Location IPV6地址1  =  NULL
   远端Location IPV6地址2  =  NULL
       远端IP地址业务类型  =  SUP-FE
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD DBSRIPADDR**命令的参数说明。
