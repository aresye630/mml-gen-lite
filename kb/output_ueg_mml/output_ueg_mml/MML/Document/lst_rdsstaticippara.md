# 查询园区用户IP地址信息（LST RDSSTATICIPPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于查询Radius静态IP地址信息、UDM静态IP地址信息或5G LAN组信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                        |
|:--------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI    | 用户IMSI号   | 可选必选说明：可选参数  参数含义：用户的IMSI信息。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是5~15。  默认值：无  配置原则：无                                                                                                                                                                                                                                                             |
| APN     | APN名称     | 可选必选说明：可选参数  参数含义：该参数用于指定APN实例名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“ ” ”、“ ` ”特殊字符，不区分大小写。  默认值：无  配置原则：无                                                                                                               |
| GROUPID | 5G LAN组ID | 可选必选说明：可选参数  参数含义：该参数用于指定5G LAN群组的ID。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是18~37。字母大小写不敏感且全局唯一。  默认值：无  配置原则：  GROUPID以连字号分为4段，形式为GroupServiceID-MCC-MNC-LocalGroupID。其中，GroupServiceID长度为8，只能输入数字或者范围为A到F或a-f的字母；MCC长度为3，只能输入数字；MNC长度为2~3，只能输入数字；LocalGroupID长度为2~20的偶数，只能输入数字或者范围为A到F或a-f的字母。例如，A0000001-460-003-01，A0000001-460-003-A000000001。 |

## 使用实例

查询Radius静态IP地址信息：

```
%%LST RDSSTATICIPPARA:;%%
RETCODE = 0  操作成功

结果如下
--------
  用户IMSI号  =  123456789012345
     APN名称  =  huawei.com
    地址类型  =  IPV4
    IPv4地址  =  192.168.10.10
    IPv6地址  =  ::
   5G LAN组ID = NULL
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称     | 输出项解释               |
|:----------|:--------------------|
| 用户IMSI号   | 用户的IMSI信息。          |
| APN名称     | 该参数用于指定APN实例名。      |
| 地址类型      | 地址类型。               |
| IPv4地址    | IPv4地址。             |
| IPv6地址    | 该参数用于指定IPV6类型地址。    |
| 5G LAN组ID | 该参数用于指定5G LAN群组的ID。 |
