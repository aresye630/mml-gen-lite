# 设置软件参数配置导出模式(SET SOFTPARAEXP)

- 命令功能
- 注意事项
- 本地用户权限

- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于控制软件参数导出。控制执行导出命令后，导出的MML配置文件中**SET SOFTPARA**命令是包括全部软件参数值，还是只包括与系统初始默认值不一致的软件参数值。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                                                                                                  |
|:-----------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| EXPORTTYPE | 软件参数导出模式 | 可选必选说明：可选参数 参数含义：控制导出的MML文件中，SET SOFTPARA是包括全部软件参数值，还是只包括与系统初始值不一致的软件参数。 数据来源：整网规划 取值范围：枚举类型。“ALL_VALUE(全部软件参数值)”：执行导出命令，生成的mml文件中SET SOFTPARA包括所有软参参数值。“NOT_INIT_VALUE(非缺省默认软件参数值)”：执行导出命令，生成的mml文件中SET SOFTPARA只包括与系统初始值不同的软件参数值。 系统初始设置值：ALL_VALUE |

#### 使用实例

设置软件参数配置导出模式为“非缺省默认软件参数值”：

`SET SOFTPARAEXP: EXPORTTYPE=NOT_INIT_VALUE;`
