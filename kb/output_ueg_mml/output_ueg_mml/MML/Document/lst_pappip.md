# 查询对端设备配置(LST PAPPIP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询数据库中的对端设备配置数据。

- 若需要查询全部对端设备配置数据，请不要输入任何参数。
- 若需要查询某条对端设备配置数据，请输入“对端设备名称”或“对端设备组名称”参数。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                      |
|:----------|:--------|:--------------------------------------------------------------------------------------------------------------------------|
| PAPPIPNM  | 对端设备名称  | 可选必选说明：可选参数 用于指示系统需要按照哪个对端设备名称来查询对端设备配置数据；若不输入，则表示查询所有的对端设备名称。 取值范围：长度不超过63的字符串。 默认值：无。 配置原则：无。                           |
| PAPPGRPNM | 对端设备组名称 | 可选必选说明：可选参数 用于指示系统需要按照哪个对端设备组名称来查询对端设备配置数据；若不输入，则表示查询所有的对端设备组名称。 取值范围：长度不超过63的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询所有对端配置数据信息：

   ```
   LST PAPPIP:;
   ```

   ```
   %%LST PAPPIP:;%%
   RETCODE = 0  操作成功

   对端设备名称  对端设备组名称   IP地址类型  IPV4地址         IPV6地址     备注 

   PeerIp        PeerIPGroup      IPV4        10.100.100.100   NULL         remark
   PeerIp1       PeerIPGroup      IPV4        10.100.100.101   NULL         remark1    
   PeerIp2       PeerIPGroup1     IPV4        10.100.100.102   NULL         remark2
   PeerIp3       PeerIPGroup2     IPV4        10.100.100.103   NULL         remark3      
   (结果个数 = 4)

   ---    END
   ```
2. 查询“对端设备名称”为“PeerIp”的设备配置信息：

   ```
   LST PAPPIP: PAPPIPNM="PeerIp";
   ```

   ```
   %%LST PAPPIP: PAPPIPNM="PeerIp";%%
   RETCODE = 0  操作成功

     对端设备名称  =  PeerIp
   对端设备组名称  =  PeerIPGroup
       IP地址类型  =  IPV4
         IPV4地址  =  10.100.100.100
         IPV6地址  =  NULL
             备注  =  remark
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD PAPPIP**命令的参数说明。
