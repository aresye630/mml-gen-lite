# 测试HTTP客户端链路（TST HTTPCLINK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于本端HLB做为HTTP客户端和指定的服务端进行建链，测试链路的连通性，该命令仅为维护测试命令。

## 注意事项

- 执行该命令时，本端IP和对端IP的IP类型必须相同，否则无法进行建链。
- 如果本地配置了HTTPS协议，对端也必须支持HTTPS，否则无法进行建链。
- 命令执行过程中，参数“HLB实例ID”不做校验控制，需要操作员保证输入的正确性，如果输入的实例ID不存在，该命令也能正常执行。
- 执行该命令时，如果创建的链路已存在，则返回链路的当前状态。
- 执行命令时在未返回结果前，不能再次执行相同命令，需要等待上一次任务结束。如果在等待期间需要执行其他命令，可以新开CSP OM Portal执行其他命令。
- 该命令的最大超时时间为10秒，如果超过10秒未响应将强制结束链路测试任务。
- 该命令建议在局点正式商用前进行链路测试时使用。
- 该命令建立的链路只是做网络连通测试使用，命令执行完之后，系统会强制释放链路。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                                                    |
|:-------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INSTID | HLB实例ID | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个HLB实例ID来查询HLB缓存中的HTTP客户端链路信息；若不输入，则表示所有的HLB实例ID。操作员可以使用DSP SDRSERVICE命令查询获得，“APPTYPE”参数取值为“3501”。 如果参数未输入，则由系统自动匹配一个HLB实例ID。 取值范围：不超过32的字符串 默认值：无。 配置原则：无。 |
| DEVAID | 设备地址标识  | 可选必选说明：必选参数 参数含义：用于设置本地需要进行测试的HTTP客户端的HLB设备地址标识，操作员可以使用LST HLBDEVADDR命令查询获得。 取值范围：0～31 默认值：无。 配置原则：无。                                                                                   |
| PIP    | 对端IP    | 可选必选说明：必选参数 参数含义：用于设置需要进行建链检测的HTTP服务器端的IP地址。 取值范围：符合IPV4或者IPV6格式的IP地址。 默认值：无 配置原则：对端IP类型需和本端IP类型保持一致，否则无法正常建链。 本端IP类型操作员可以使用LST HLBDEVADDR命令查询获得。                                       |
| PPORT  | 对端端口    | 可选必选说明：必选参数 参数含义：用于设置需要进行建链检测的HTTP服务器端的端口。 取值范围：1～65535 默认值：无。 配置原则：无。                                                                                                                  |

## 使用实例

测试一条HTTP客户端和指定HTTP服务器端之间网络是否可以正常连接。

```
TST HTTPCLINK: INSTID="18436291759697829293", DEVAID=1, PIP="10.10.10.10", PPORT=10501;
```

```
%%TST HTTPCLINK: INSTID="18436291759697829293", DEVAID=1, PIP="10.10.10.10", PPORT=10501;%%
RETCODE = 0  操作成功

操作结果如下
------------------------
HTTP链路状态  =  链路建立成功
    本端信息  =  http://10.10.10.11:40004
  服务端信息  =  http://10.10.10.10:10501
(结果个数  = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义如表1。

通过该命令进行建链时系统会记录HLB服务日志，登录CSP OM Portal后选择

“监控分析 > 运行日志 > 服务日志收集 > 应用名称（upcf\_xxx\_xxx） > PcfHttpLoadBalanceService”

，可以收集HLB服务日志，然后联系华为技术支持进一步分析。

| 输出项名称    | 输出项解释                                                  |
|:---------|:-------------------------------------------------------|
| HTTP链路状态 | 用于表示HTTP建链结果。 取值范围： 链路建立成功链路建立失败链路建立超时                 |
| 本端信息     | 用于表示发起建链测试使用的本端IP和端口信息。 本端信息输出结果格式：http(s)://IP:Port   |
| 服务端信息    | 用于表示发起建链测试使用的服务端IP和端口信息。 服务端信息输出结果格式：http(s)://IP:Port |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释                               | 原因分析                           | 处理建议                                       |
|------:|:------------------------------------|:-------------------------------|:-------------------------------------------|
| 58196 | DEVAID不存在。                          | 输入的“设备地址标识”不存在。                | 使用LST HLBDEVADDR命令查询获得正确的“设备地址标识”，重新执行该命令。 |
| 51500 | 本端IP地址和对端IP地址的IP类型需要一致，都为IPV4或IPV6。 | 输入的“对端IP”和本端IP的IP类型不一致，无法正常建链。 | 重新选择IP地址类型相同的本端和对端进行链路测试。                  |
| 58143 | IP地址非法。                             | 输入的“对端IP”参数值不合法。               | 重新执行本命令，确保输入的IP地址合法。                       |
