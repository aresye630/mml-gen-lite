# 修改对端NF的通配策略（MOD PNFWILDCARD）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、NRF、NSSF、SMSF、NCG、NEF、NWDAF、SCF**

该命令用于修改对端NF的通配策略。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

```
MOD PNFWILDCARD: NFTYPE=NfSMSF, DNNSWITCH=OFF;
```
