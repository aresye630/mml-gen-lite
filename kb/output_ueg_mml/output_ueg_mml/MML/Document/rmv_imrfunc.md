# 删除用户消息统计功能配置(RMV IMRFUNC)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于删除用户消息统计功能配置。

#### 注意事项

- 该命令执行后对正在进行流程处理的用户暂不生效，系统会在用户的任意新的流程，根据最新的配置进行用户消息统计。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                   |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：必选参数 参数含义：该参数用于指定用户范围。 数据来源：全网规划 取值范围：“ALL_USER(所有用户)”“SPECIAL_USER(指定用户)” 默认值 ：无               |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI前缀。 前提条件：该参数在“用户范围”参数配置为“SPECIAL_USER”后生效。 数据来源：全网规划 取值范围：5~15位数字 默认值 ：无 |

#### 使用实例

删除一条“用户范围”为“ALL\_USER”的IMRFUNC配置记录：

RMV IMRFUNC: SUBRANGE=ALL\_USER;
