# 修改NLF服务系统软参(MOD NLFSSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于修改NLF系统软件参数的配置信息。

## 注意事项

- 在缺省的情况下，系统在初始化的时候已经预置了软参数据表中的全部数据。
- 操作员应使用默认值。如果操作员确实需要修改软件参数，请联系华为技术服务工程师处理，禁止随意修改。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                           |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SCP    | 系统配置参数 | 可选必选说明：必选参数 参数含义：系统配置参数标识。 取值范围： SYSPARAMETER(系统参数) 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                             |
| SPN    | 参数名    | 可选必选说明：必选参数 参数含义：标识软件参数名称，用于指定需要对哪一类软参数据记录的参数进行修改。 取值范围： VRM_RETENTIONNOTIFYLOG(通知历史文件存留期)VRM_WHITELISTSWITCH(白名单功能开关)VRM_MAXSESSIONNUMPERUSER(单个用户最大SFTP会话个数)VRM_KEEPALIVESWITCH(SFTP保活开关)VRM_EDRSTATSWITCH(EDR统计开关)VRM_NLFSFTPCLIENTACSWITCH(NLF SFTP客户端算法兼容开关)VRM_NLFSFTPSERVERACSWITCH(NLF SFTP服务端算法兼容开关) 详细信息请参考产品手册的“UPCF软件参数 > NLF系统软参”。 默认值：无。 配置原则：无。 |
| SPV    | 参数值    | 可选必选说明：必选参数 参数含义：标识软件参数的值。 取值范围：0～2147483647 详细信息请参考产品手册的“UPCF软件参数 > NLF系统软参”。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                  |

## 使用实例

设置“系统配置参数”为“SYSPARAMETER(系统参数)”，“参数名”为“VRM\_RETENTIONNOTIFYLOG(通知历史文件存留期)”，“参数值”软参设置为“200”。

```
MOD NLFSSP: SCP=SYSPARAMETER, SPN=VRM_RETENTIONNOTIFYLOG, SPV=200;
```
