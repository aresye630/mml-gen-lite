# 查询服务发现网元实例信息(LST DISCNFPROFILE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询服务发现网元实例数据。

- 若需要查询所有网元实例的信息，不输入任何参数。
- 若需要查询某个网元实例的详细信息，请输入“网元实例名称”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                                               |
|:----------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSNAME | 网元实例名称 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个网元实例名称来查询网元实例信息数据；若不输入，则表示所有网元实例名称的网元实例信息。 取值范围：长度不超过64的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。                                                                                                                  |
| NFINSID   | 网元实例标识 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个网元实例标识来查询网元实例信息数据；若不输入，则表示所有网元实例标识的网元实例信息。 取值范围：长度固定为36位的字符串，只允许输入0～9，a～f，A～F，“-”。 默认值：无。 配置原则：无。                                                                                                                     |
| NFTYPE    | 网元类型   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个网元类型来查询网元实例信息数据；若不输入，则表示所有网元类型的网元实例信息。 取值范围：UDM(统一数据管理)AUSF(鉴权服务功能)PCF(策略控制功能)UDR(统一数据存储库)AMF(接入和移动性管理功能)SMF(会话管理功能)NEF(网络能力开放功能实体)AF(应用功能)SMSF(短消息业务功能)BSF(绑定支持功能)CHF(计费功能)SCP(服务通信代理)NWDAF(网络数据分析功能） 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询所有用于服务发现的网元实例信息：

```
LST DISCNFPROFILE:;
```

```
%%LST DISCNFPROFILE:;%%
RETCODE = 0  操作成功

操作结果如下 
------------------------
网元实例名称  网元实例标识                          网元类型          网元实例信息
                                                                                                                        
pcf           11111111-1111-1111-1111-111111111111  策略控制功能      {"nfInstanceId":"11111111-1111-1111-1111-111111111111","nfType":"PCF","nfStatus":"REGISTERED","ipv4Addresses":["192.168.91.105"]}  
(结果个数 = 1)

---    END
```

2. 查询“网元实例名称”为“pcf”的网元实例信息：

```
LST DISCNFPROFILE: NFINSNAME="pcf";
```

```
%%LST DISCNFPROFILE: NFINSNAME="pcf";%%
RETCODE = 0  操作成功    

操作结果如下 
------------------------
网元实例名称  =  pcf 
网元实例标识  =  11111111-1111-1111-1111-111111111111     
    网元类型  =  策略控制功能 
网元实例信息  =  {"nfInstanceId":"11111111-1111-1111-1111-111111111111","nfType":"PCF","nfStatus":"REGISTERED"}
(结果个数 = 1)  

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD DISCNFPROFILE**命令的参数说明。
