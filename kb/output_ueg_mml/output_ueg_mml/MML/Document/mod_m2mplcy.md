# 修改M2M策略参数(MOD M2MPLCY)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限

#### 命令功能

**适用网元：SGSN、MME**

该命令用于修改M2M的策略参数。

#### 注意事项

该命令执行后对已经附着的用户不立即生效。用户下次RAU/TAU流程再生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组
