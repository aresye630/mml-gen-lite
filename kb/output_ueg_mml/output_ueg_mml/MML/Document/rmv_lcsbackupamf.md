# 删除LCS备用AMF配置（RMV LCSBACKUPAMF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除本地配置的AMF主备信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                  |
|:--------------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AMFINSTANCEID | AMF实例标识 | 可选必选说明：必选参数 参数含义：该参数用于指定主用AMF实例标识。 数据来源：本端规划 取值范围：字符串类型，输入长度范围是1~36。参数必须满足以下约束规则： 1.如果输入为uuid格式（格式例如：a6a61c6f-0d3a-4221-b1da-424eda3ccf67）只能为A-F、a-f、0-9的字符。 2.如果输入不为uuid格式，长度不能超过18且不允许输入只包含0-9和“.”的字符串，例如：10.107.65.183、不允许输入只包含十六进制数（A-F、a-f、0-9）和“:”的字符串，例如：FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。 默认值：无 配置原则：无 |

#### 使用实例

删除一对AMF主备关系。将本地配置的主用AMF Instance ID为AmfInstanceId的AMF主备关系信息删除：

```
RMV LCSBACKUPAMF: AMFINSTANCEID="amf_instance_0";
```
