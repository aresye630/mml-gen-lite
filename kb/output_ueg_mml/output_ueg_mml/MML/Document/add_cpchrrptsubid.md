# 增加CHR本地存盘用户（ADD CPCHRRPTSUBID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、PGW-C、SGW-C、GGSN**

该命令用于增加指定某个用户本地存储CHR表单。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入64条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------------------|
| IMSI    | IMSI   | 可选必选说明：必选参数  参数含义：该参数用于指示用户的IMSI。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~15。  默认值：无  配置原则：无                                |
| TMPLIDX | 流程模板索引 | 可选必选说明：必选参数  参数含义：该参数用于指示流程控制模板索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~127。该参数需要在ADD SESSNCHRPRCTMPL命令中已配置。  默认值：无  配置原则：无 |

## 使用实例

指定某个用户本地存储CHR表单，用户的IMSI为123030123456789：

```
ADD CPCHRRPTSUBID: IMSI="123030123456789", TMPLIDX=0;
```
