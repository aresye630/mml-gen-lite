# 查询基于位置区地址分配的开关（LST CPIPALLOCBYLOCSW）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、GGSN、SMF**

该命令查询指定位置区组或所有的基于位置区地址分配的开关信息。

## 注意事项

- 该命令指定位置区组类型和名称时，表示查询指定位置区组基于位置区地址分配的开关信息。
- 指定位置区组的类型而不指定名称时，表示查询指定类型位置区组基于位置区地址分配的开关信息。
- 不指定位置区组的类型和名称时，表示查询所有基于位置区组地址分配的开关信息。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                                          |
|:----------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LOCATIONGRPNAME | 位置区组名称 | 可选必选说明：可选参数  参数含义：该参数用于标识位置区组名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。  默认值：无  配置原则：  该参数使用ADD ADDRTACGROUP或ADD ADDRLACGROUP命令配置生成。                                             |
| LOCATIONGRPTYPE | 位置区组类型 | 可选必选说明：可选参数  参数含义：该参数用于指定位置区组类型。  数据来源：本端规划 取值范围： LAC（LAC）TAC（TAC）  默认值：无  配置原则： 配置类型为TAC，LOCATIONGRPNAME必须由ADD ADDRTACGROUP新增。配置类型为LAC，LOCATIONGRPNAME必须由ADD ADDRLACGROUP新增。 |

## 使用实例

查询名为tac1的TAC-GROUP基于位置区地址分配的开关信息：

```
%%LST CPIPALLOCBYLOCSW: LOCATIONGRPTYPE=TAC;%%
RETCODE = 0 操作成功

结果如下
-------
位置区组类型  =  TAC
位置区组名称  =  1
    IPv4开关  =  去使能
    IPV6开关  =  去使能
(结果个数 = 1)

--- END
```
