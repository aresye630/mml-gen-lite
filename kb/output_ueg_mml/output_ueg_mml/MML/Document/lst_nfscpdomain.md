# 查询SCP域配置信息(LST NFSCPDOMAIN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询PCF向NRF注册时携带的SCP域配置信息。

- 若需要查询所有SCP域配置信息，不输入任何参数。
- 若需要查询某个组的SCP域配置信息，请输入“组名称”参数。
- 若需要查询某个SCP域配置信息，请输入“索引”参数。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                       |
|:----------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| GRPNAME   | 组名称    | 可选必选说明：可选参数 参数含义：用于指示系统按照组名称来查询SCP域配置信息；若不输入，则表示所有的组名称。 取值范围：由数字、字母、“-”或“_”组成的长度不超过32的字符串 默认值：无。 配置原则：无。                                   |
| INDEX     | 索引     | 可选必选说明：可选参数 参数含义：用于指示系统按照索引来查询SCP域配置信息；若不输入，则表示所有的索引。 取值范围：1~1024 默认值：无。 配置原则：无。                                                           |
| SCPDOMAIN | SCP域   | 可选必选说明：可选参数 参数含义：用于指示系统按照SCP域来查询SCP域配置信息；若不输入，则表示所有的SCP域。 取值范围：由数字、字母、“-”、“_”或“.”组成的长度不超过128的字符串（不能以“.”开始，也不能以“.”结束），大小写敏感。 默认值：无。 配置原则：无。 |

## 使用实例

查询所有的SCP域配置信息：

```
LST NFSCPDOMAIN:;
```

```
%%LST NFSCPDOMAIN:;%%
RETCODE = 0  操作成功

操作结果如下 
------------------------ 
    组名称  =  nfscpdomain
      索引  =  1   
     SCP域  =  abcde 
(结果个数 = 1)  

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见命令**ADD NFSCPDOMAIN**的参数说明。
