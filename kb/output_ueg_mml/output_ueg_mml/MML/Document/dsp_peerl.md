# 查询PCRF与Diameter对端的链路状态（DSP PEERL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为维护类命令，用于在配置数据库中查询PCRF实体和Diameter对端的链路状态信息。如果需要查询所有链路状态信息，请不要输入任何参数；如果需要查询某条链路状态信息，请依据参数说明输入查询条件。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                 |
|:-------|:-------|:---------------------------------------------------------------------|
| PCRFID | PCRF标识 | 用于标识PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围：1 默认值：无。              |
| PT     | 对端类型   | 用于定义对端类型。 取值范围： DRA(DRA)TDF(TDF) 默认值：无。                              |
| PEERID | 对端标识   | 用于指定一个对端，该参数必须先由ADD PEER命令定义，然后才能在此处索引。 取值范围：0～127 默认值：无。            |
| LNKID  | 对端链路标识 | 用于在UPCF的配置库中定义一个对端链路。该参数的配置原则：如果配置多个对端链路，从0开始顺序配置。 取值范围：0～135 默认值：无。 |
| STATE  | 链路状态   | 用于指定链路状态。 取值范围： LINKDOWN(离线)LINKUP(在线)UNKNOWN(未知) 默认值：无。             |

## 使用实例

1. 查询所有的PCRF实体和Diameter对端链路的状态信息。

   ```
   DSP PEERL:;
   ```

   ```
   %%DSP PEERL:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
    PCRF标识  对端类型  对端标识  对端链路标识   DLB实例号             链路状态

    1         DRA       0         0              12851153534470311709  离线
    1         DRA       0         1              12851153534470311709  离线   
   (结果个数 = 2)

   ---    END
   ```
2. 查询一条PCRF实体和Diameter对端链路的状态信息。“PCRF标识”为“1”，“对端类型”为“DRA”，“对端标识”为“1”，“对端链路标识”为“0”，其他参数使用缺省值。

   ```
   DSP PEERL: PCRFID=1, PT=DRA, PEERID=1, LNKID=0;
   ```

   ```
   %%DSP PEERL: PCRFID=1, PT=DRA, PEERID=1, LNKID=0;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
       PCRF标识  =  1
       对端类型  =  DRA
       对端标识  =  1
   对端链路标识  =  0
      DLB实例号  =  12851153534470311709
       链路状态  =  离线
   (结果个数 = 1)

   ---    END
   ```
