# 增加对端网元静态信息(ADD PNFSTATICINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于向配置数据库中增加一条对端网元的静态信息，系统可通过配置数据库中的信息在上报的相关客户端告警中显示产生告警的对端设备名称。

相关客户端告警如下：

- ALM-18407 HTTP客户端链接故障

- ALM-18602 NRF链路故障
- ALM-18704 客户端链路亚健康

## 注意事项

最大支持配置2000条记录。

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                                                                               |
|:------------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| STNAME      | 静态配置名称   | 可选必选说明：必选参数。 参数含义：用于标识待增加的一个对端网元静态信息的名称，该参数唯一。 取值范围：长度不超过32字节的字符串，只允许输入：0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。                                                                                                                        |
| NFTYPE      | 网元类型     | 可选必选说明：必选参数 参数含义：用于标识对端网元实例的类型。 取值范围：AMF(AMF)SMF(SMF)SMSF(SMSF)NRF(NRF)NEF(NEF)SCP(SCP)SEPP(SEPP) 默认值：无。 配置原则：无。                                                                                                                   |
| IPVER       | 网元IP地址类型 | 可选必选说明：可选参数 参数含义：用于表示对端网元的IP地址类型。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。                                                                                                                                                        |
| IPV4IP      | 网元IPV4地址 | 可选必选说明：条件可选参数 参数含义：用于指定对端网元IPv4类型的本地IP地址，由运营商统一规划。 取值范围：IPv4格式的地址。 默认值：无。 配置原则： 仅当本命令中的“网元IP地址类型”参数取值为“IPV4(IPV4)”时该参数有效。该参数全局唯一，不能重复。                                                                                             |
| IPV6IP      | 网元IPV6地址 | 可选必选说明：条件可选参数 参数含义：用于指定对端网元IPv6类型的本地IP地址，由运营商统一规划。IPv6格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如：2001:0DB8:02de:0000:0000:0000:0000:0e13。 取值范围：IPv6格式的地址。 默认值：无。 配置原则： 仅当本命令中的“网元IP地址类型”参数取值为“IPV6(IPV6)”时该参数有效。该参数全局唯一，不能重复。 |
| NFINSNAME   | 网元实例名称   | 可选必选说明：可选参数 参数含义：用于标识一个对端网元实例的名称。 取值范围：由数据、字母、下划线、特殊字符组成的长度不超过64的字符串，不允许填需转义类字符“[]”、“{}”、“/”、“\”、“"”、“:”。 默认值：无。 配置原则：当本命令中“网元IPV4地址”或“网元IPV6地址”配置了取值时，该参数不能为空。                                                                    |
| DESCRIPTION | 描述信息     | 可选必选说明：可选参数 参数含义：用于指定园区的配置描述。 取值范围：由数字、字母、下划线、特殊字符组成的长度不超过128的字符串，不允许填需转义类字符“[]”、“{}”、“/”、“\”、“"”、“:”。 默认值：无。 配置原则：无。                                                                                                              |

## 使用实例

增加一条对端网元静态信息，“静态配置名称”为“udm01”，“网元类型”为“SMF”，“网元IP地址类型”为“IPV4(IPV4)”，“网元IPV4地址”为“192.168.31.43”，“网元实例名称”为“udm-application-001”：

```
ADD PNFSTATICINFO: STNAME="udm01", NFTYPE=SMF, IPVER=IPV4, IPV4IP="192.168.31.43", NFINSNAME="udm-application-001";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                      | 原因分析                                      | 处理建议                                                                                        |
|-------:|:---------------------------|:------------------------------------------|:--------------------------------------------------------------------------------------------|
|    503 | 配置数据已存在。                   | 新增的数据记录在数据库中已经存在。                         | 执行LST PNFSTATICINFO命令查询对端网元静态信息，根据实际情况，重新输入参数，确保新增的数据记录在数据库中不存在。                            |
| 360041 | 参数值不合法。                    | 错误响应消息中携带的参数不合法。                          | 修改错误提示中携带的参数后重新运行命令，参考参数说明中对应参数的格式。                                                         |
| 360042 | 参数值已存在。                    | 输入的“网元IPV4地址”或“网元IPV6地址”对应的数据已存在。         | 通过LST PNFSTATICINFO命令查询已定义的“网元IPV4地址”或“网元IPV6地址”。重新输入参数，确保输入的“网元IPV4地址”或“网元IPV6地址”不与查询结果重复。 |
| 360214 | IPVER参数配置时，NFINSNAME也必须配置。 | 输入“网元IPV4地址”或“网元IPV6地址”的取值，但“网元实例名称”未输入值。 | “网元IPV4地址”或“网元IPV6地址”配置了取值时，“网元实例名称”不能为空。                                                   |
