# 删除VXLAN隧道端点绑定隧道组（RMV VTEPBINDGRP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，删除最后一个VTEP时，会导致使用该Vxlan组的数据业务不通。

该命令用于删除VXLAN隧道端点与隧道组的绑定关系。

#### 注意事项

- 该命令执行后立即生效。
- 执行该命令时，如果删除的是最后一个VTEP，会导致使用该Vxlan组的数据业务不通。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                                                    |
|:-------------|:---------|:------------------------------------------------------------------------------------------------------------------------|
| VXLANGRPNAME | VXLAN组名称 | 可选必选说明：必选参数 参数含义：该参数用于指定VXLAN隧道组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用 ADD VXLANGRP命令配置生成。 |
| VTEPNAME     | VTEP名称   | 可选必选说明：可选参数 参数含义：该参数用于指定VXLAN隧道端点名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用 ADD VTEP命令配置生成。    |

#### 使用实例

删除所有隧道端点与VXLAN隧道组vxlangrp的绑定关系：

```
RMV VTEPBINDGRP: VXLANGRPNAME="vxlangrp";
```
