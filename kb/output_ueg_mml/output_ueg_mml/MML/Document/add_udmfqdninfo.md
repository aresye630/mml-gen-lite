# 增加FQDN信息（ADD UDMFQDNINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

当UDM主动发送的消息中携带的是FQDN（Fully Qualified Domain Name）域名时，本命令用于增加FQDN信息，UDM可以通过FQDN域名找到对端的IP地址，然后针对此IP地址建立链路。

## 注意事项

当同一FQDN域名对应多个IP地址时，可以使用此命令多次添加，但同一FQDN域名最多添加1024条记录。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                          |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------------|
| NAME    | FQDN名称 | 可选必选说明：必选参数。 参数含义：用于标识FQDN名称。 取值范围：长度不超过255位的字符串。 默认值：无。 配置原则： 需要符合域名格式。由“.”分隔的多个Label组成，其中Label由字母、数字、-和_组成。 |
| IPADDR  | IP地址   | 可选必选说明：必选参数。 参数含义：用于标识FQDN域名对应的IP地址。 取值范围：IPV4地址/IPV6地址。 默认值：无。 配置原则：无。                                       |
| COMMENT | 备注     | 可选必选说明：可选参数。 参数含义：用于标识FQDN信息的备注。 取值范围：1~32位字节组成的字符串。 默认值：无。 配置原则：无。                                           |

## 使用实例

设置UDM可以通过FQDN域名找到对端的IP地址时，需要执行如下操作，其中“FQDN名称”为“udm1.huawei.com”，“IP地址”为“192.168.13.67”。

```
ADD UDMFQDNINFO: NAME="udm1.huawei.com", IPADDR="192.168.13.67";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                    | 原因分析                    | 处理建议                   |
|-------:|:-------------------------|:------------------------|:-----------------------|
| 360121 | IPADDR参数必须是IPv4地址或IPv6地址 | 输入的“IP地址”不是IPv4或IPv6地址。 | 根据实际情况重新输入符合IP地址要求的参数。 |
