# 增加双发选收结对配置（ADD DFSRPAIR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于新增双发选收结对配置。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为2048。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称     | 参数说明                                                                                                                        |
|:----------------|:---------|:----------------------------------------------------------------------------------------------------------------------------|
| DFSRPAIRID      | 双发选收结对ID | 可选必选说明：必选参数 参数含义：该参数用于配置双发选收结对ID。 数据来源：本端规划 取值范围：整数类型，取值范围1-2048。 默认值：无 配置原则：无                                              |
| DFSRPAIRMODE    | 双发选收模式   | 可选必选说明：必选参数 参数含义：该参数用于配置双发选收模式。 数据来源：对端协商 取值范围：枚举类型。 FRER_SRC_MAC：基于源MAC的FRER双发选收模式。FRER_PAIR：基于结对的FRER双发选收模式。 默认值：无 配置原则：无 |
| PAIRDESCRIPTION | 结对描述     | 可选必选说明：可选参数 参数含义：该参数用于配置结对的描述信息。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无                                |

#### 使用实例

增加一个双发选收结对配置，结对id是1，结对模式是源mac模式：

```
ADD DFSRPAIR: DFSRPAIRID=1, DFSRPAIRMODE=FRER_SRC_MAC;
```
