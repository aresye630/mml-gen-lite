# 删除SMF的非Default QoS Flow配置（RMV SMFNONDFTQOSCTL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用来删除SMF的非Default QoS Flow配置。

## 注意事项

命令执行后只对新接入用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                       |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| MCC      | 移动国家码  | 可选必选说明：必选参数  参数含义：该参数用于表示组成QoS控制的用户归属地网络的移动国家码信息。  数据来源：本端规划  取值范围：字符串类型，输入长度是3。  默认值：无  配置原则：无                                            |
| MNC      | 移动网号   | 可选必选说明：必选参数  参数含义：该参数用于表示组成QoS控制的用户归属地网络的移动网号信息。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是2~3。  默认值：无  配置原则：无                                         |
| CTRLTYPE | 控制类型   | 可选必选说明：必选参数  参数含义：该参数用于指定QoS控制的类型。  数据来源：全网规划 取值范围： DNN_LEVEL（DNN级别）GLOBAL_LEVEL（整系统级别）  默认值：无  配置原则：无                                     |
| DNN      | DNN    | 可选必选说明：该参数在"CTRLTYPE"配置为"DNN_LEVEL"时为条件必选参数。  参数含义：该参数用于指定组成QoS控制的DNN，即用户请求的DNN。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

- 删除“移动国家码”为“460”，“移动网号”为“00”，控制类型为GLOBAL\_LEVEL的QoS Flow配置，执行如下命令：

  ```
  RMV SMFNONDFTQOSCTL:MCC="460",MNC="00",CTRLTYPE=GLOBAL_LEVEL;
  ```
- 删除“移动国家码”为“460”，“移动网号”为“00”，控制类型为DNN\_LEVEL，“数据网络名称”为“ims”的QoS Flow配置，执行如下命令：

  ```
  RMV SMFNONDFTQOSCTL:MCC="460",MNC="00",CTRLTYPE=DNN_LEVEL,DNN="ims";
  ```
