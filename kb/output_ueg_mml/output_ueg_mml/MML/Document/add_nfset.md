# 增加网元集合配置信息(ADD NFSET)

## 命令功能

该命令用于PCF向NRF注册时增加网元集合配置信息。

该命令的使用场景：通过此命令可以配置一个PCF的网元集合配置信息（由各运营商自行规划），实现同一网元集合访问。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                   |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GRPNAME | 组名称    | 可选必选说明：必选参数 参数含义：用于标识一个网元集合配置信息所属组的名称。 取值范围：由数字、字母、“-”或“_”组成的长度不超过32的字符串 默认值：无。 配置原则： 该参数可以重复，但和索引组合以后成为全局唯一对象关键字段，组合不能重复。该参数配置时不能取值为“NULL”，否则无法被正常索引。                                                                                                                                                                                 |
| INDEX   | 索引     | 可选必选说明：必选参数 参数含义：用于标识一个网元集合配置信息在组内的唯一一条记录。 取值范围：1~1024 默认值：无。 配置原则：该参数在不同的组名称下可以重复，但和组名称组合以后成为全局唯一对象关键字段，组合不能重复。                                                                                                                                                                                                                       |
| SETID   | 集合ID   | 可选必选说明：必选参数 参数含义：用于标识一个本端集合ID。 取值范围：由数字、字母或“-”组成且以数字或字母结尾的长度不超过100的字符串，大小写不敏感 默认值：无。 配置原则：该参数设置的取值为NF Set ID（即set<Set ID>.<nftype>set.5gc.mnc<MNC>.mcc<MCC>）当中的Set ID。                                                                                                                                                                 |
| MCC     | 移动国家码  | 可选必选说明：必选参数 参数含义：用于标识移动国家码。移动国家码由ETSI（European Telecommunications Standards Institute）在世界范围内统一分配，标识用户漫游移动网络所属的国家。 取值范围：3位十进制数字组成的字符串 默认值：无。 配置原则： 该参数设置的取值为NF Set ID（即set<Set ID>.<nftype>set.5gc.mnc<MNC>.mcc<MCC>）当中的MCC。网元集合配置信息当中的MCC+MNC要求唯一。                                                                                     |
| MNC     | 移动网络码  | 可选必选说明：必选参数 参数含义：用于标识移动网络码。移动网络码用来在一个国家内唯一标识一个移动网络，它由本国电信主管部门在本国范围内统一分配。 取值范围：2位或3位的十进制数字组成的字符串 默认值：无。 配置原则： 该参数设置的取值为NF Set ID（即set<Set ID>.<nftype>set.5gc.mnc<MNC>.mcc<MCC>）当中的MNC。网元集合配置信息当中的MCC+MNC要求唯一。若新增配置的MCC和系统已存在记录的MCC相同时，MNC有效长度为2位与MNC有效长度为3位的记录配置的前两位不允许相同。比如，当系统已存在MCC为460、MNC为023的记录，此时新增配置MCC为460、MNC为02是不被允许的，反之亦然。 |

## 使用实例

增加一条网元集合配置信息。“组名称”为“nfset1”，“索引”为“1”，“集合ID”为“xyz”，“移动国家码”为“460”，“移动网络码”为“012”。

```
ADD NFSET: GRPNAME="nfset1", INDEX=1, SETID="xyz", MCC="460", MNC="012";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                                  | 原因分析                                     | 处理建议                                                         |
|------:|:---------------------------------------|:-----------------------------------------|:-------------------------------------------------------------|
|   503 | 配置数据已存在。                               | 数据库中已有相同“索引”配置。                          | 使用命令LST NFSET查询并重新输入“索引”，确保其值不存在。                            |
| 58136 | 每个PLMN下最多支持1个NF Set ID。                | 输入参数“移动国家码”和“移动网络码”取值在系统中已存在。            | 使用命令LST NFSET查询并重新输入“移动国家码”和“移动网络码”，确保输入的MCC+MNC取值在当前系统中不存在。 |
| 58137 | 此MNC值的前两位不能与所属同一MCC但位数不同的其他MNC值的前两位一致。 | 若MCC相同，MNC有效长度为2位和MNC有效长度为3位的记录的前两位不能相同。 | 使用命令LST NFSET查询并重新输入“移动网络码”，确保输入的取值与已有记录中的MNC不冲突。            |
