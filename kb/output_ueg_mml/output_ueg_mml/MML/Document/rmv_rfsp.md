# 删除RFSP配置(RMV RFSP)

- 命令功能
- 注意事项
- 本地用户权限

#### 命令功能

**适用网元：SGSN、MME**

此命令用于删除RFSP ID配置记录。

#### 注意事项

此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                            |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：必选参数 参数含义：该参数用于指定配置RFSP ID的用户范围。 取值范围：“ALL_IMSI(所有用户)”“SPECIAL_IMSI(指定用户)”“FOREIGN_USER（外网用户）”“HOME_USER（本网用户）” 默认值：无                                                                                                    |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件必选参数 参数含义：该参数用于指定用户群的IMSI前缀。 前提条件：此参数在“SUBRANGE（用户范围）”设置为“SPECIAL_IMSI(指定用户)”时有效。 取值范围：5～15位数字 默认值：无                                                                                                                   |
| NOID     | 运营商标识  | 可选必选说明：条件必选参数 参数含义：该参数用于指定运营商标识。 前提条件： 该参数在“SUBRANGE（用户范围）”配置为“FOREIGN_USER（外网用户）”或“HOME_USER（本网用户）”后生效。 数据来源：整网规划 取值范围：0～64，128～254 默认值：无  说明： 对于外网用户，该参数是与其归属运营商签订可漫游协议，为其提供服务的MNO/MVNO运营商标识。对于本网用户，该参数是为该用户归属的MNO/MVNO运营商标识。 |

#### 使用实例

场景参见**ADD RFSP**的命令使用实例。

删除NOID为0对应的漫游用户的RFSP ID，使NOID为0的漫游用户按照用户范围ALL\_IMSI(业务优先级策略)配置的数据RFSP ID为3对应的频点优先级进行驻留控制：

RMV RFSP: SUBRANGE=FOREIGN\_USER, NOID=0;
