# 设置匹配规则（SET MSSRULEM）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于设置匹配规则。

用户只有设置规则后，才能绑定该规则对消息或者报文进行匹配，匹配规则是从消息、报文的偏移类型对应的位置加上偏移大小开始，比较“规则内容&规则掩码”和“报文内容&规则掩码”是否一致。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组;

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                |
|:-------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CELLTYPE     | 微服务类型  | 可选必选说明：必选参数 参数含义：该参数用于指定微服务类型。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～63。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符。 默认值：无 配置原则：使用DSP PAENODE查看工作角色为数据转发对应的微服务类型。    |
| CELLINSTANCE | 微服务实例号 | 可选必选说明：必选参数 参数含义：该参数用于指定微服务实例号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～127。数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符。 默认值：无 配置原则：使用DSP PAENODE查看工作角色为数据转发对应的微服务实例号。 |
| ENABLE       | 使能     | 可选必选说明：必选参数 参数含义：该参数用于表示增加或者减少一条规则，增加规则时如果输入的规则ID已存在则覆盖该规则。 数据来源：本端规划 取值范围：枚举类型。 FALSE：关闭。TRUE：打开。 默认值：无                                                                            |
| RULEID       | 规则ID   | 可选必选说明：必选参数 参数含义：该参数用于表示规则ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～31。 默认值：无                                                                                                                  |
| OFFSETTYPE   | 偏移类型   | 可选必选说明：条件必选参数 前提条件：该参数在“ENABLE”配置为“TRUE”时为必选参数。 参数含义：该参数用于表示偏移类型。 数据来源：本端规划 取值范围：枚举类型。 ufp-pkt-ctrl：UFP包控制块。ufp-pkt-data：UFP包数据区。 默认值：无                                             |
| OFFSET       | 偏移     | 可选必选说明：条件必选参数 前提条件：该参数在“ENABLE”配置为“TRUE”时为必选参数。 参数含义：该参数用于表示偏移大小。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                                                      |
| PATTERN      | 规则     | 可选必选说明：条件必选参数 前提条件：该参数在“ENABLE”配置为“TRUE”时为必选参数。 参数含义：该参数用于表示规则内容。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～128。 默认值：无                                                                          |
| MASK         | 掩码     | 可选必选说明：条件必选参数 前提条件：该参数在“ENABLE”配置为“TRUE”时为必选参数。 参数含义：该参数用于表示掩码。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～128。 默认值：无                                                                            |

#### 使用实例

设置微服务类型为104的微服务实例csdb-pod-0172-16-0-247\_\_103\_\_0的匹配规则：

```
%%SET MSSRULEM: CELLTYPE="104", CELLINSTANCE="csdb-pod-0172-16-0-247__103__0", ENABLE=TRUE, RULEID=1, OFFSETTYPE=ufp-pkt-ctrl, OFFSET=0, PATTERN="0000", MASK="ffff";%%
RETCODE = 0  操作成功

---    END
```
