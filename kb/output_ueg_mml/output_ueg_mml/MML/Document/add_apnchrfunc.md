# 增加APN CHR功能配置（ADD APNCHRFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：GGSN、SGW-C、PGW-C、SMF**

该命令用于增加基于APN的CHR功能配置。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入20000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                                                             |
|:------------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN         | APN     | 可选必选说明：必选参数  参数含义：该参数用于指定APN实例名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无  配置原则：  该参数必须已经通过命令ADD CPAPN配置。 |
| CHRREPORTSW | CHR上报开关 | 可选必选说明：可选参数  参数含义：该参数用于基于APN控制开启和关闭CHR上报功能。  数据来源：本端规划 取值范围： “INHERIT（继承全局）”：表示使用SET GLBCHRFUNC中配置的开关。“ENABLE（使能）”：表示基于APN控制开启CHR上报功能。“DISABLE（不使能）”：表示基于APN控制关闭CHR上报功能。  默认值：INHERIT  配置原则：无                                    |

## 使用实例

增加“APN”为"HUAWEI.COM"的CHR功能配置：

```
ADD APNCHRFUNC: APN="HUAWEI.COM", CHRREPORTSW=ENABLE;
```
