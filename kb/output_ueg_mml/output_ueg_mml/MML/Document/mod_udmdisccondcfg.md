# 修改服务发现条件信息(MOD UDMDISCCONDCFG)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会导致业务通信链路发生变更，造成业务呼损或系统崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改某一类型网元实例的服务发现条件信息。在该命令中，系统通过“网元类型”参数来唯一标识所有SCP网元实例的类型。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                     |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFTYPE  | 网元类型   | 可选必选说明：必选参数 参数含义：标识服务发现条件信息数据的关键字段。用于指定对哪个类型的网元实例的服务发现条件信息进行修改。操作员可以使用LST UDMDISCCONDCFG命令查询获得。 取值范围： SCP：服务通信代理 默认值：无。 配置原则：无。                                                                                                                                                                                                          |
| SCPPARA | SCP参数  | 可选必选说明：条件可选参数 参数含义：用于标识SCP向NRF发起服务发现请求时，携带的参数值。 取值范围： 全部选中全部清空全部灰化 SERVINGSCOPE(SERVINGSCOPE)：表示SCP服务发现携带参数servingScope。SCPDOMAINS(SCPDOMAINS)：表示SCP服务发现携带参数scpDomains。 默认值：无。 配置原则： 仅当本命令中的“网元类型”参数取值为“SCP”时，该参数有效。该参数取值支持多选，但不支持同时选择“SERVINGSCOPE(SERVINGSCOPE)”和“SCPDOMAINS(SCPDOMAINS)”，多选仅用于后续扩展其他发现参数。不配置则表示SCP服务发现时只携带nftype=SCP。 |

## 使用实例

修改所有SCP网元实例的服务发现条件信息为“SERVINGSCOPE(SERVINGSCOPE)”：

```
MOD UDMDISCCONDCFG: NFTYPE=SCP, SCPPARA=SERVINGSCOPE-1&SCPDOMAINS-0;
```
