# 查询GMLC选择策略(LST GMLCSELPLCY)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用网元：MME**

该命令用于查询GMLC选择策略。

#### 注意事项

- 无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称        | 参数说明                                                                                                                                                                                                                                                                      |
|:--------------|:------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GMLCGRPID     | GMLC选择策略组索引 | 可选必选说明：可选参数 参数含义：该参数在系统内唯一标识一个GMLC组。 数据来源：本端规划 取值范围：0~191 默认值：无 配置原则：该参数需要在ADD GMLCSELGRP中事先配置，可执行LST GMLCSELGRP进行查看。                                                                                                                                                     |
| LCSCLIENTTYPE | LCS客户端类型    | 可选必选说明：可选参数 参数含义：该参数用于标识LCS客户端类型。 数据来源：整网规划 取值范围：枚举类型。目前就紧急呼叫类型触发的NI-LR流程会选择GMLC，其他参数预留使用。 取值范围： “EMERGENCY_SERVICES(紧急业务)”“VALUE_ADDED_SERVICES(增值业务)”“PLMN_OPERATOR_SERVICES(运营商业务)”“LAWFUL_INTERCEPT_SERVICES(合法定位)” 默认值：无 配置原则：目前就紧急呼叫类型触发的NI-LR流程会选择GMLC，其他参数取值预留使用。 |
| LOCATIONTYPE  | 位置区标识类型     | 可选必选说明：可选参数 参数含义：该参数标识位置标识类型。 数据来源：整网规划 取值范围： “ECI(小区标识)”“TAC(跟踪区编码)” 默认值：无                                                                                                                                                                                               |
| TACBEGIN      | 跟踪区起始编码     | 可选必选说明：条件可选参数 参数含义：该参数表示跟踪区起始编码 前提条件：该参数在"位置区标识类型"参数配置为"跟踪区编码"后生效。 数据来源：整网规划 取值范围：0x0000~0xFFFF 默认值：无                                                                                                                                                                     |
| ECIBEGIN      | 小区起始标识      | 可选必选说明：条件可选参数 参数含义：该参数表示E-UTRAN小区起始标识。 前提条件：该参数在"位置区标识类型"参数配置为"小区标识"后生效。 数据来源：整网规划 取值范围：0~268435455 默认值：无                                                                                                                                                                 |

#### 使用实例

1. 查询索引为0的GMLC选择策略组内的所有选择策略。

   LST GMLCSELPLCY: GMLCGRPID=0;

   ```
   %%LST GMLCSELPLCY:;%%
   RETCODE = 0  操作成功。

    0                   紧急业务       跟踪区编码      0x0A            0x0A            NULL          NULL          huawei.com  0                   noname
    0                   紧急业务       小区标识        NULL            NULL            0             0             huawei.com  0                   noname
   (结果个数 = 2)

   ```
