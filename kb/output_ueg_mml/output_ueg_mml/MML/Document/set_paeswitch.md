# 设置PAE隔离核统计状态（SET PAESWITCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置PAE隔离核查询开关，若打开，则计算VM/容器CPU利用率包括PAE隔离核；若关闭，则计算VM/容器CPU利用率不包括PAE隔离核。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| SWITCH   |
|:---------|
| DISABLE  |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                                                                  |
|:-------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------|
| SWITCH | PAE隔离核统计开关 | 可选必选说明：必选参数  参数含义：该参数表示计算节点CPU利用率是否包含PAE隔离核。  数据来源：本端规划 取值范围： “ENABLE（包括PAE隔离核）”：包括PAE隔离核“DISABLE（去除PAE隔离核）”：去除PAE隔离核  默认值：无。  配置原则：无 |

## 使用实例

开启PAE隔离核查询。

```
SET PAESWITCH: SWITCH=ENABLE;
```
