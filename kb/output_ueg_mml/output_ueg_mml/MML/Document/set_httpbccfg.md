## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置是否启用HTTP负载均衡功能开关。

- 当“开关”取值为“ON(开启)”时，DCS、TCP、HTTP各服务需要做如下处理。
  - 执行**ADD HTTPBCIP**或者**ADD HTTPLSERVER**命令触发DCS服务下发首包均衡策略，DCS服务的策略下发、策略校验、核查功能恢复。
  - TCP、HTTP服务针对HTTP链路增强的功能恢复。
- 当“开关”取值为“OFF(关闭)”时，DCS、TCP、HTTP各服务会做如下处理。
  - DCS服务的处理策略如下：
    - DCS服务删除五元组转发策略和首包均衡策略，并且在策略重启、策略校验、策略核查场景下不再下发首包均衡策略和五元组策略。
    - DCS服务的定时链路信息收集以及DCS启动场景下的链路信息收集功能关闭。
    - DCS不再做链路决策，异常场景下收到TCP SYN消息直接丢弃。
  - TCP服务不再对TCP SYN消息进行解析，不做删除残留策略的动作。
  - HTTP服务在链路状态开启时不再上报链路确认消息，链路状态关闭时不再通知DCS服务删除策略。

链路均衡功能开启或者关闭的过程中，对业务功能有以下影响。

- 链路均衡功能从开启到关闭过程中，DCS服务直接删除了相关策略，触发对端HTTP服务重新建链，导致原有链路残留，在此过程会有业务呼损现象。
- 链路均衡功能从关闭到开启过程中，CSLB收到DCS服务提供的首包均衡策略的消息，此时CSLB会把收到的消息丢弃，CSLB等待对端HTTP服务重传后重新建链，此过程中也存在业务呼损。

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                         |
|:-------|:-------|:-----------------------------------------------------------------------------|
| SWITCH | 开关     | 可选必选说明：必选参数 参数含义：用于指定HTTP链路均衡功能是否启用。 取值范围： OFF(关闭)ON(开启) 默认值：ON(开启)。 配置原则：无。 |

## 使用实例

1. 设置HTTP负载均衡功能“开关”为“ON(开启)”。

   ```
   SET HTTPBCCFG:SWITCH=ON;
   ```
2. 设置HTTP负载均衡功能“开关”为“OFF(关闭)”。

   ```
   SET HTTPBCCFG:SWITCH=OFF;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释           | 原因分析               | 处理建议                    |
