# 查询用于策略控制的网络切片群组成员（LST PLCYNSGRPMEM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询应用于AM策略或者UE策略控制的网络切片群组成员。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                                                     |
|:--------|:---------|:-------------------------------------------------------------------------------------------------------------------------|
| NSGRPID | 网络切片群组标识 | 可选必选说明：可选参数  参数含义：该参数用于指定网络切片群组标识。  数据来源：本端规划  取值范围：整数类型，取值范围是1~16。本参数通过ADD PLCYNSGRP命令进行配置。  默认值：无  配置原则：无              |
| NSIDX   | 网络切片索引   | 可选必选说明：可选参数  参数含义：该参数用于指定控制AM策略或UE策略的网络切片。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。本参数通过ADD PLMNNS命令进行配置。  默认值：无  配置原则：无 |

## 使用实例

- 查询系统中当前配置的用于AM策略或者UE策略控制的网络切片群组成员（网络切片群组标识=1、网络切片索引=0），执行命令如下：

  ```
  %%LST PLCYNSGRPMEM: NSGRPID=1, NSIDX=0;%%
  RETCODE = 0  操作成功

  结果如下
  --------
  网络切片群组标识   =  1
       网络切片索引  =  0
  (结果个数 = 1)

  ---    END
  ```
- 查询系统中当前配置的用于AM策略或者UE策略控制的网络切片群组成员，执行命令如下：

  ```
  %%LST PLCYNSGRPMEM:;%%
  RETCODE = 0  操作成功

  结果如下
  --------
  网络切片群组标识   =  1
       网络切片索引  =  0
  (结果个数 = 1)

  ---    END
  ```

## 输出结果说明

| 输出项名称    | 输出项解释                    |
|:---------|:-------------------------|
| 网络切片群组标识 | 该参数用于指定网络切片群组标识。         |
| 网络切片索引   | 该参数用于指定控制AM策略或UE策略的网络切片。 |
