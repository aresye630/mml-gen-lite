# 查询S1模式IMEI配置(LST S1IMEICFG)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用网元：MME**

该命令用于查询EUTRAN用户获取和检查IMEI的策略。

#### 注意事项

无

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                   |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：可选参数 参数含义：该参数用于指定签约用户的范围。 数据来源：整网规划。 取值范围：“ALL_USER（所有用户）”、“IMSI_PREFIX（指定IMSI前缀）”、“IMSI_RANGE（指定IMSI范围）” 默认值：无 |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件可选参数 参数含义：该参数用于指定IMSI前缀。 前提条件：只有“用户范围”为“IMSI_PREFIX（指定IMSI前缀）”时，该参数才有效。 数据来源：整网规划。 取值范围：1~15位十进制字符串 默认值：无     |
| IMSI     | IMSI   | 可选必选说明：条件可选参数 参数含义：该参数用于指定所要查询的IMSI。 前提条件：只有“用户范围”为“IMSI_RANGE（指定IMSI范围）”时，该参数才有效。 数据来源：整网规划 取值范围：1~15位十进制字符串 默认值：无    |
