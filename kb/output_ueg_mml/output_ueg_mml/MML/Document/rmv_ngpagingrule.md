# 删除5G寻呼规则（RMV NGPAGINGRULE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

此命令用于删除全部或者指定的5G寻呼规则。

## 注意事项

- 该命令执行后立即生效。

- 在不指定规则索引参数的情况下，执行本命令将删除所有已配置的5G寻呼规则，从而导致精准寻呼功能不可用，请慎重操作。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                  |
|:--------|:-------|:--------------------------------------------------------------------------------------|
| RULEIDX | 规则索引   | 可选必选说明：必选参数  参数含义：该参数用于指定5G寻呼规则的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~1000。  默认值：无  配置原则：无 |

## 使用实例

删除一条“规则索引”为“1”的5G寻呼规则，执行如下命令：

```
RMV NGPAGINGRULE: RULEIDX=1;
```
