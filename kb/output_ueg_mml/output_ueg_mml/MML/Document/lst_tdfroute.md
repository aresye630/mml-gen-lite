## 命令功能

该命令为维护类命令，用于在配置数据库中查询TDF对端路由记录。如果需要查询全部域路由的配置信息，请不要输入任何参数；如果需要查询某个TDF对端路由的配置信息，请依据参数说明输入查询条件。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称   | 参数描述                                                                                                                                                                                |
|:----------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ROUTEID   | 路由ID   | 用于在UPCF的配置库中定义一条TDF路由数据。该参数的配置原则：如果配置多个TDF对端路由，从0开始顺序配置。 取值范围：0～511 默认值：无。                                                                                                          |
| ROUTETYPE | 路由类型   | 用于在UPCF的配置库中定义一个路由数据的类型。 取值说明： PcefHostName(PCEF主机名)PcefRealmName(PCEF域名) 默认值：无。                                                                                                    |
| ROUTEKEY  | 路由键    | 用于具体描述一个TDF路由键。其值域类型为字符串，该参数在配置时不区分大小写，在查询时区分大小写。当ROUTETYPE参数选择“PcefHostName(PCEF主机名)”时，此参数为PCEF对端主机名。当ROUTETYPE参数选择“PcefRealmName(PCEF域名)”时，此参数为PCEF对端域名。 取值范围：长度不超过127的字符串 默认值：无。 |
| PEERID    | 对端标识   | 用于具体描述一个TDF路由键映射的TDF对端ID。该参数必须先由ADD PEER命令定义，并且对端类型为TDF，然后才能在此处索引。 取值范围：0～127 默认值：无。                                                                                                |
| TDFRN     | TDF域名  | 用于指示系统需要按照哪个“TDF域名”来查询命令组的信息；若不输入，则表示所有的命令组ID。 取值范围：长度不超过64的字符串 默认值：无。                                                                                                              |

## 使用实例

1. 查询所有的TDF对端路由的配置信息。

   ```
   LST TDFROUTE:;
   ```

   ```
   %%LST TDFROUTE:;%% 
   RETCODE = 0  操作成功  

   操作结果如下: 
   -------------
   路由ID  路由类型    路由键  对端标识  TDF域名       
   0       PCEF主机名  PCEF00  0         NULL       
   1       PCEF主机名  PCEF01  1         NULL      
   (结果个数 = 2)  

   ---    END
   ```
2. 查询一条TDF对端路由的配置信息。TDF的“路由ID”为“1”，“路由类型”为“PcefHostName(PCEF主机名)”。

   ```
   LST TDFROUTE: ROUTEID=1, ROUTETYPE=PcefHostName;
   ```

   ```
   %%LST TDFROUTE: ROUTEID=1, ROUTETYPE=PcefHostName;%% 
   RETCODE = 0  操作成功  

   操作结果如下: 
   -------------   
   路由ID  =  1 
   路由类型  =  PCEF主机名   
   路由键  =  PCEF01 
   对端标识  =  1  
   TDF域名  =  NULL   
   (结果个数 = 1)  

   ---    END
   ```
