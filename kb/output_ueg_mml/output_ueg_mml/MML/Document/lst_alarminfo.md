# 查询告警信息（LST ALARMINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于基于告警ID查询告警信息，包括告警级别、屏蔽状态和抑制时间等信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| ALARMID         | 告警ID   | 可选必选说明：必选参数 参数含义：告警ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                          |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

基于告警ID（135602186）查询告警属性信息，可通过如下命令查询：

```
LST ALARMINFO:ALARMID=135602186,SERVICEINSTANCE="ACS";
```

#### 输出结果说明

| 输出项名称       | 输出项解释                                                                   |
|:------------|:------------------------------------------------------------------------|
| 告警ID        | 告警ID。                                                                   |
| 告警名称        | 告警名称。                                                                   |
| 告警产生抑制周期（秒） | 告警产生抑制周期。当告警全局属性告警抑制使能开关为开时，该参数值有效，即告警产生后会被抑制一定的时间（该时间就是告警产生抑制周期）才上报终端。 |
| 告警清除抑制周期（秒） | 告警清除抑制周期。当告警全局属性告警抑制使能开关为开时，该参数值有效，告警恢复后会被抑制一定的时间（该时间就是告警清除抑制周期）才上报终端。  |
| 告警级别        | 告警级别。                                                                   |
| 告警屏蔽状态      | 告警屏蔽状态。                                                                 |
| 告警类别        | 告警类别分为故障告警和事件告警，故障告警有产生和恢复两种状态，事件告警仅有产生一种状态。                            |
| 默认告警级别      | 默认告警级别，告警级别分为紧急、重要、次要、提示。                                               |
| 默认告警屏蔽状态    | 默认告警屏蔽状态，有开和关两种状态。                                                      |
