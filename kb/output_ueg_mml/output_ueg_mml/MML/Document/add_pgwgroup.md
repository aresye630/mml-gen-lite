# 增加P-GW组(ADD PGWGROUP)

- 注意事项

#### 命令功能

**适用网元：SGSN、MME**

该命令用于增加P-GW组。使用P-GW组是更精细化的管理P-GW局向。MME支持基于P-GW Back-off timer的APN级流控功能会使用到本命令。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为16。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                 |
|:-------|:-------|:---------------------------------------------------------------------|
| GRPID  | P-GW组号 | 可选必选说明：必选参数 参数含义：该参数用于指定P-GW组号。 数据来源：本端规划 取值范围：0～15 默认值：无            |
| DESC   | 描述     | 可选必选说明：可选参数 参数含义：该参数用于P-GW组描述信息。 数据来源：本端规划 取值范围：0～256位字符串 默认值：noname |

#### 使用实例

运营商希望增加新的组号为2的P-GW组号来管理P-GW局向，描述为“M2M P-GW Group”，则设置“P-GW组号”参数为“2”、“描述”参数为“M2M P-GW Group”。运行如下命令：

ADD PGWGROUP: GRPID=2, DESC="M2M P-GW Group";
