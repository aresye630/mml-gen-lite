# 修改SCCP新全局翻译码(MOD CPSCCPNGT)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME、SMSF**

此命令用来修改SCCP新全局码表指定记录的信息。

#### 注意事项

此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                                                                                                     |
|:--------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NGTX    | 新GT码索引  | 可选必选说明：必选参数 参数含义：该参数用于指定新GT码对应的索引值。 数据来源：本端规划 取值范围：0~4095 默认值：无                                                                                                                                          |
| GTEXP   | GT码表示语  | 可选必选说明：必选参数 参数含义：该参数用于指定GT码表示语。 数据来源：整网规划 取值范围：“FOUR(ITU四类)”“SIX(ANSI二类)” 默认值：无                                                                                                                          |
| ITUTT   | ITU翻译类型 | 可选必选说明：条件可选参数 参数含义：该参数用于指定ITU模式的翻译类型。 前提条件：该参数在“GT码表示语”参数设置为“FOUR(ITU四类)”时，才需要配置。 数据来源：整网规划 取值范围：0~255 默认值：无 配置原则：当运营商需要使用STP基于GT码的Translation Type再次进行分类路由转发时，配置此参数。                                    |
| TT      | 翻译类型    | 可选必选说明：条件可选参数 参数含义：该参数用于指定翻译类型。 前提条件：该参数在“GT码表示语”参数设置为“SIX(ANSI二类)”时，才需要配置。 数据来源：整网规划 取值范围：“ANSI9(ANSI 9类)”“ANSI10(ANSI 10类)” 默认值：无                                                                      |
| NP      | 编号计划    | 可选必选说明：条件可选参数 参数含义：该参数用于指定编号计划。 前提条件：该参数在“GT码表示语”参数设置为“FOUR(ITU四类)”时，才需要配置。 数据来源：整网规划 取值范围：“ISDNP(ISDN/电话编号计划)”“DATA(数据编号计划)”“TELEX(Telex编号计划)”“SMS(海事移动编号计划)”“PMS(陆地移动编号计划)”“ISDNMS(ISDN/移动编号计划)” 默认值：无 |
| ADDREXP | 地址性质表示语 | 可选必选说明：条件可选参数 参数含义：该参数用于指定地址性质表示语。 前提条件：该参数在“GT码表示语”参数设置为“FOUR(ITU四类)”时，才需要配置。 数据来源：整网规划 取值范围：“FREE(空闲)”“SUBDN(用户号码)”“NSU(国内备用号码)”“NVU(国内有效号码)”“INTDN(国际号码)” 默认值：无                                       |
| ADDR    | 地址信息    | 可选必选说明：可选参数 参数含义：该参数用于指定地址信息。 数据来源：整网规划 取值范围：长度不超过20的十进制数字字符串 默认值：无                                                                                                                                      |
| DESC    | 描述      | 可选必选说明：可选参数 参数含义：该参数用于指定SCCP新全局码表的记录名称。 数据来源：本端规划 取值范围：长度不超过32的字符串 默认值：无                                                                                                                                 |

#### 使用实例

参考**ADD CPSCCPNGT**的场景1，修改“新GT码索引”为“2”和“3”的记录的“ITU翻译类型”为“20”：

MOD CPSCCPNGT: NGTX=2, GTEXP=FOUR, ITUTT=20;

MOD CPSCCPNGT: NGTX=3, GTEXP=FOUR, ITUTT=20;
