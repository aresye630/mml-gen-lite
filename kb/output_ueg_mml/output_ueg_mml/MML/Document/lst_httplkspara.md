# 查询远端服务器链路集参数配置（LST HTTPLKSPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询远端服务器链路集参数配置。

- 若需要查询所有链路集参数配置，请不输入任何参数。
- 若需要查询某个链路集参数配置，请输入“链路集参数ID”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                            |
|:-------|:--------|:------------------------------------------------------------------------------------------------|
| PARAID | 链路集参数ID | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个链路集参数ID来查询链路集参数配置信息；若不输入，则表示查询所有的链路集参数ID。 取值范围：1~255。 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询所有的链路集参数配置：

   ```
   LST HTTPLKSPARA:;
   ```

   ```
   %%LST HTTPLKSPARA:;%% 
   RETCODE = 0  操作成功

   链路集参数ID   链接数目      流数目数组    链路选择模式       初始链路优先级数组   初始链路权重数组
   1              8             2147483647    轮询方式           NULL                 NULL
   2              8             1024,2048     基于优先级         1,2                  NULL      
   3              8             512,1024      基于权重的轮询方式 NULL                 50,51                        
   (结果个数 = 3)  

   ---    END
   ```

2. 查询“链路集参数ID”为“1”的链路集参数配置：

   ```
   LST HTTPLKSPARA: PARAID=1;
   ```

   ```
   %%LST HTTPLKSPARA: PARAID=1;%% 
   RETCODE = 0  操作成功

         链路集参数ID = 1
             链接数目 = 8
           流数目数组 = 2147483647
         链路选择模式 = 轮询方式
   初始链路优先级数组 = NULL
     初始链路权重数组 = NULL
   (结果个数 = 1)  

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD HTTPLKSPARA**命令的参数说明。
