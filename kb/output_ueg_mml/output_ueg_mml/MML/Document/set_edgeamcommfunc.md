# 设置通用接入和移动扩展功能（SET EDGEAMCOMMFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

此命令用于设置通用接入和移动扩展功能。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| SECSELECTUDMSW   | UDMDEPMODE     |
|:-----------------|:---------------|
| DISABLE          | SEP_DEPLOYMENT |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|:---------------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SECSELECTUDMSW | 二次重选UDM开关 | 可选必选说明：可选参数  参数含义：该参数用于设置AMF是否开启二次重选UDM功能。  数据来源：全网规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST EDGEAMCOMMFUNC查询当前参数配置值。  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| UDMDEPMODE     | UDM部署模式   | 可选必选说明：该参数在"SECSELECTUDMSW"配置为"ENABLE"时为条件可选参数。  参数含义：当SECSELECTUDMSW为ENABLE时，该参数用于表示AUSF和UDM的部署模式。该参数仅用于配置当大网主备AUSF均故障后是否仍需要与大网UDM进行交互，与现网UDM和AUSF的实际部署模式无关。  数据来源：全网规划 取值范围： “SEP_DEPLOYMENT（分设）”：若大网主备AUSF均故障并且使用园区AUSF时，AMF仍与大网主备UDM交互，在交互流程失败时再选择园区UDM，向园区UDM发送注册、获取签约数据和订阅签约变更的三次交互流程。“CO_DEPLOYMENT（合设）”：若大网主备AUSF均故障并且使用园区AUSF时，AMF不与大网主备UDM交互，直接选择园区UDM，向园区UDM发送注册、获取签约数据和订阅签约变更的三次交互流程。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST EDGEAMCOMMFUNC查询当前参数配置值。  配置原则：  当AMF未探测到大网AUSF和UDM故障时：  1）若设置为分设模式，大网主备AUSF均故障并且使用园区AUSF时，AMF仍尝试与大网UDM交互，大网主备UDM均故障后再选择园区UDM，此过程可能导致UE因等待时间过长而断开网络接连；  2）若设置为合设模式，大网主备AUSF均故障并且使用园区AUSF时，AMF直接选择园区UDM，从而提升注册成功率。  当AMF已探测到大网AUSF和UDM故障时：  两种模式下UE均能迅速注册成功。 |

## 使用实例

设置开启二次重选UDM功能，并将UDM部署模式设置为合设，执行如下命令：

```
SET EDGEAMCOMMFUNC: SECSELECTUDMSW=ENABLE, UDMDEPMODE=CO_DEPLOYMENT;
```
