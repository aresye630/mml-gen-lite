# 删除容灾实例(RMV DRINST)

- 命令功能

- 操作用户权限

#### 命令功能

**须知** 

该操作将删除容灾配置，影响容灾数据备份，操作前请先确保已经关闭容灾激活开关。

该命令用于删除本端容灾实例信息。

#### 注意事项

- 执行该命令之前，请先确保已经关闭容灾激活开关。
- 本命令执行后，只有当执行命令**DSP DRINFO**查询到被删除的容灾实例“数据备份状态”为“容灾配置表已删除”时，才可重新配置新容灾实例。
- 执行该命令后，三分钟内请勿使用**ADD DRINST**和**ADD DRCOMM**等添加容灾配置的命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                           |
|:---------|:-------|:-----------------------------------------------------------------------------------------------|
| DRINSTID | 容灾实例ID | 可选必选说明：必选参数。 参数含义：该参数用于配置容灾实例标识。可使用LST DRINST命令查询本端已配置的容灾实例ID。 数据来源：全网规划。 取值范围：整型，0~63。 默认值：无。 |

#### 使用实例

删除“容灾实例ID”为“2”的容灾实例：

```
RMV DRINST: DRINSTID=2;
```
