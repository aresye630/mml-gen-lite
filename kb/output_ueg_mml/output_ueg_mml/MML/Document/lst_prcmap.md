# 查询PCRF结果码映射（LST PRCMAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询PCRF的结果码映射记录。

- 若需要查询全部PCRF的结果码映射记录，请不要输入任何参数。
- 若需要查询某条PCRF的结果码映射记录的详细信息，请输入“接口类型”、“源结果码”、"目的结果码”或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                         |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------|
| IFTYPE | 接口类型   | 可选必选说明：可选参数 参数含义：用于指示UPCF需要按照哪个接口类型来查询PCRF的结果码映射记录；若不输入，则表示所有的接口类型。取值范围：Gx(Gx)Rx(Rx) 默认值：无 配置原则：无                                            |
| SRCRC  | 源结果码   | 可选必选说明：可选参数 参数含义：用于指示UPCF需要按照哪个源结果码来查询PCRF的结果码映射记录；若不输入，则表示所有的源结果码。仅当设置了“接口类型”参数的取值后，才出现该参数。 取值范围：与ADD PRCMAP命令中的源结果码参数值一致。 默认值：无 配置原则：无     |
| DSTRC  | 目的结果码  | 可选必选说明：可选参数 参数含义：用于指示UPCF需要按照哪个目的结果码来查询PCRF的结果码映射记录；若不输入，则表示所有的目的结果码。 仅当设置了“接口类型”参数的取值后，才出现该参数。 取值范围：与ADD PRCMAP命令中的目的结果码参数值一致。 默认值：无 配置原则：无 |

## 使用实例

查询PCRF的“接口类型”为“Gx(Gx)”的结果码映射记录。

```
LST PRCMAP: IFTYPE=Gx;
```

```
%%LST PRCMAP: IFTYPE=Gx;%%
RETCODE = 0  操作成功

操作结果如下:
------------------------
 接口类型        源结果码                               目的结果码   

 Gx              DIAMETER_MULTI_ROUND_AUTH              DIAMETER_MULTI_ROUND_AUTH  
 Gx              DIAMETER_SUCCESS                       DIAMETER_SUCCESS           
 Gx              DIAMETER_LIMITED_SUCCESS               DIAMETER_LIMITED_SUCCESS   
 Gx              DIAMETER_ERROR_CONFLICTING_REQUEST     DIAMETER_NO_COMMON_SECURITY
(结果个数 = 4)

---    END
```
