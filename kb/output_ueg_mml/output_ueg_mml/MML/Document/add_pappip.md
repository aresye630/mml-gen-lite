# 增加对端设备配置(ADD PAPPIP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中增加一条对端设备配置记录。UDM局点根据运营商业务要求，需要对某个IP进行话统统计，则使用**ADD PAPPIPGRP**和**ADD PAPPIP**命令完成配置，系统将按照此IP进行HTTP2消息统计。

## 注意事项

对端设备配置的最大记录数为100，添加时勿超过此上限值。

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                              |
|:----------|:--------|:----------------------------------------------------------------------------------------------------------------------------------|
| PAPPIPNM  | 对端设备名称  | 可选必选说明：必选参数 参数含义：用于标识待增加的对端设备名称。 取值范围：长度不超过63的字符串。 默认值：无。 配置原则：无。                                                                 |
| PAPPGRPNM | 对端设备组名称 | 可选必选说明：必选参数 参数含义：用于标识待增加的对端设备配置所属设备组名称。 取值范围：长度不超过63的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 配置原则：该参数必须先由ADD PAPPIPGRP命令定义，然后才能在此处引用。 |
| IPVER     | IP地址类型  | 可选必选说明：必选参数 参数含义：用于标识待增加的对端设备IP地址类型。 取值范围：IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。                                                     |
| IPV4IP    | IPV4地址  | 可选必选说明：条件必选参数 参数含义：用于标识待增加的对端设备IPV4地址。 取值范围：标准IPV4地址 默认值：无。 配置原则：仅当本命令中的“IP地址类型”参数为“IPV4(IPV4)”时该参数有效。                            |
| IPV6IP    | IPV6地址  | 可选必选说明：条件必选参数 参数含义：用于标识待增加的对端设备IPV6地址。 取值范围：标准IPV6地址 默认值：无。 配置原则：仅当本命令中的“IP地址类型”参数为“IPV6(IPV6)”时该参数有效。                            |
| REMARK    | 备注      | 可选必选说明：可选参数 参数含义：用于标识对端设备的备注信息。 取值范围：长度不超过63的字符串。 默认值：无。 配置原则：无。                                                                  |

## 使用实例

运营商根据业务需求，统计对端设备HTTP2消息时，需要通过本命令增加对端设备。“对端设备名称”为“PeerIp”，“对端设备组名称”为“PeerIpGroup”，“IP地址类型”为“IPV4”，“IPV4地址”为“10.100.100.100”，“备注”为“remark”

```
ADD PAPPIP: PAPPIPNM="PeerIp", PAPPGRPNM="PeerIPGroup", IPVER=IPV4, IPV4IP="10.100.100.100",REMARK="remark";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                          | 原因分析                         | 处理建议                                                                                                                          |
|-------:|:-------------------------------|:-----------------------------|:------------------------------------------------------------------------------------------------------------------------------|
|    504 | 当前配置记录数达到上限                    | 对端设备配置数据已达上限，无法添加。           | 使用LST PAPPIP查询对端设备配置信息，删除无效数据并重新添加。                                                                                           |
| 360035 | 对端设备配置已存在                      | 添加的“对端设备名称”已存在，不允许重复添加。      | 重新添加“对端设备名称”，不要与已存在的对端设备名称重复。可通过LST PAPPIP查询已添加的对端设备配置，若已存在则勿重复添加。                                                            |
| 360036 | 对端设备配置IP已存在                    | 添加的对端设备IP地址已存在，不允许重复添加。      | 重新添加对端设备IP地址，不要与已存在的IP地址重复。 可通过LST PAPPIP查询已添加的对端IP地址，若已存在则勿重复添加。                                                             |
| 360037 | 对端设备组配置的IP已经达到上限，设备组无法添加对端设备IP | 每个设备组允许添加的设备配置（设备IP）上限是64条。  | 将对端设备添加到其他对端设备配置组，或新添加对端设备配置组。                                                                                                |
| 360038 | 对端设备组名称不存在，需要先添加对端设备组          | 增加对端设备时使用的“对端设备组名称”不存在。      | 可通过以下两种方式处理： 需要监控指定的设备或者IP时，通过ADD PAPPIPGRP增加相应的对端设备组，然后执行该命令添加对端设备配置数据。添加到已存在的“对端设备组名称”的设备组内，填写错误时设备组名称可通过LST PAPPIPGRP查询获得。 |
| 360093 | 默认配置数据的添加、删除、修改受限。             | 默认对端设备组只能有默认IPV4，IPV6两条配置数据。 | 不允许向默认对端设备组内添加新的对端设备配置数据，若需要添加可加至其他对端设备组。                                                                                     |
