## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在数据库增加一条本端服务器配置相关记录。

## 注意事项

- 最大支持255条本端服务器配置。
- 选择链路类型时，使用HTTP链路存在安全风险，建议使用HTTPS链路传输。HTTPS链路传输相对于HTTP链路传输，单HLB模块性能处理能力最多可能下降20%，使用HTTPS前请联系华为技术支持评估性能影响后再进行配置。
- 当前系统支持的HTTP负载均衡策略数量上限为20480条，HTTP负载均衡策略数量等于通过**ADD HTTPBCIP**添加的HTTP均衡控制IP记录数和通过本命令添加的本端服务器配置记录数的乘积。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                        |
|:------------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LSERVERNANE | 本端服务器名称 | 可选必选说明：必选参数。 参数含义：用于标识一个本端HTTP服务端的名称。 取值范围：长度不超过128的由数字和字母组成的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。                                                                                                                                                                                                                   |
| IPNAME      | IP名称    | 可选必选说明：必选参数。 参数含义：用于标识一个微服务对外提供的信令IP地址名称，该参数必须由ADD HTTPIP命令配置后才能在此使用。 取值范围：长度不超过128的由数字和字母组成的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。                                                                                                                                                                                   |
| PORT        | 端口      | 可选必选说明：必选参数。 参数含义：用于标识一个提供服务的端口。 取值范围：1~9999 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                 |
| HTTPSFUNC   | 开启HTTPS | 可选必选说明：必选参数。 参数含义：用于标识是否开启HTTPS，即配置本端服务器支持的链路。 取值范围： TRUE(开启HTTPS)FALSE(不开启HTTPS) 默认值：TRUE(开启HTTPS)。 配置原则：SET UDMSERV命令中“默认发送模式”参数取值必须和本参数保持一致，如不一致，请执行SET UDMSERV命令修改。“默认发送模式”参数值可以通过LST UDMSERV查询。HTTP链路的处理性能远高于HTTPS链路，但HTTPS链路在信息传输方面具有更高的安全性。HTTPS链路传输相对于HTTP链路传输，单HLB模块性能处理能力最多可能下降20%，使用HTTPS前请联系华为技术支持评估性能影响后再进行配置。 |
| CERTID      | 证书应用场景  | 可选必选说明：条件必选参数。 参数含义：用于标识证书应用场景。 取值范围：UDM_HLB_Cert(HLB证书应用场景) 默认值：无。 配置原则：仅当“开启HTTPS”参数取值为“TRUE(开启HTTPS)”时该参数有效。                                                                                                                                                                                                             |
| TLSCFGID    | TLS配置ID | 可选必选说明：条件必选参数。 参数含义：用于标识一条TLS协议配置记录ID，该参数必须先由ADD UDMHLBTLSCFG命令定义，然后才能在此处引用。 取值范围：1~128 默认值：无。 配置原则：仅当“开启HTTPS”参数取值为“TRUE(开启HTTPS)”时，该参数有效。                                                                                                                                                                                 |

## 使用实例

1. 在UDM初始配置阶段，增加一条本端服务器配置数据。“本端服务器名称”为“LSERVER1”，“IP名称”为“IP1”,“端口”为“8080”，“开启HTTPS”为“FALSE(不开启HTTPS)”：

   ```
   ADD HTTPLSERVER: LSERVERNANE="LSERVER1", IPNAME="IP1", PORT=8080, HTTPSFUNC=FALSE;
   ```
2. 执行该命令配置HLB服务端数字证书，以确保UDM通过HTTPS接口与对端设备进行通信时的安全性。“本端服务器名称”为“LSERVER2”，“IP名称”为“IP2”,“端口”为“8080”，“开启HTTPS”为“TRUE(开启HTTPS)”，“证书应用场景”为“UDM\_HLB\_Cert”，“TLS配置ID”为“2”：

   ```
   ADD HTTPLSERVER: LSERVERNANE="LSERVER2", IPNAME="IP2", PORT=8080, HTTPSFUNC=TRUE, CERTID=UDM_HLB_Cert, TLSCFGID=2;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释               | 原因分析                         | 处理建议                                                                                                      |
|-------:|:--------------------|:-----------------------------|:----------------------------------------------------------------------------------------------------------|
| 360072 | 无效的本端服务器名称。         | 增加本端服务器配置时使用的“本端服务器名称”参数不合法。 | 请确保输入的“本端服务器名称”参数的取值符合取值范围。                                                                               |
| 360073 | IPNAME未定义。          | 增加本端服务器配置时使用的“IP 名称”未定义。     | 使用LST HTTPIP命令查询已经配置的HTTPIP数据，增加本端服务器配置时引用已经配置的IPNAME。                                                    |
|    504 | 当前配置记录数达到上限。        | 本端服务器配置数据已达上限，无法新增。          | 使用LST HTTPLSERVER查询本端服务器配置信息，删除无效的本端服务器数据并重新添加。                                                           |
| 360209 | HTTP负载均衡策略数量超过最大限制。 | HTTP负载均衡策略数量已经超过20480条。      | 通过LST HTTPBCIP查询HTTP均衡控制IP记录数，通过LST HTTPLSERVER查询本端服务器配置记录数，删除无效的数据，确保HTTP均衡控制IP记录数和本端服务器配置记录数乘积不超过20480。 |
