# 显示FES诊断信息（DSP FESDIAGINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示FES诊断信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

| 参数标识         | 参数名称    | 参数说明                                                                                                                                                                                                                                                                             |

| PARTNERID    | 对端组件PID | 可选必选说明：条件必选参数 前提条件：该参数在“TYPE”配置为“MESSAGE-STATISTICS”时为必选参数。 可选必选说明：条件可选参数 前提条件：该参数在“TYPE”配置为“MC-GROUP-STATE” 或 “DATA-SYNCHRONIZE-STATE”时为可选参数。 参数含义：该参数用于表示对端组件PID。 数据来源：本端规划 取值范围：十六进制整数类型，取值范围为0x0～0xFFFFFFFF。 默认值：无                                                           |

#### 使用实例

显示FES诊断信息：

```
DSP FESDIAGINFO:TYPE=LOCAL-DATA,MID=1;
```

```
RETCODE = 0  Operation Success.

结果如下
------------------------
查询返回结果  =
MSG_Diagnose:
(结果个数 = 1)
---    END
```
