## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令用于重新均衡分配DLB/LDAP链路。

该命令的应用场景如下：

- DCS通过VNFMAdaptor获取DLB/LDAP部署实例数失败且通过OM数据库获取DLB/LDAP部署实例数也失败时
- 扩容或者缩容场景下需要重新均衡分配DLB/LDAP链路时
- DLB/LDAP链路负荷不均时

在以上三种应用场景中，可以先执行该命令（“分配类型”设置为“INSTNUMBER”）重新设置DLB/LDAP部署实例数，然后再次执行该命令（“分配类型”设置为“REASSIGN”）重新均衡分配链路，在重新均衡分配链路的过程中，会导致链路中断，可能会上报**“ALM-30021 PCRF与AF通讯故障”**、**“ALM-30023 PCRF与AF链路故障”**、**“ALM-30025 PCRF与PCEF通讯故障”**、**“ALM-30027 PCRF与PCEF链路故障”**、**“ALM-30047 PCRF与Diameter对端通讯故障”**、**“ALM-30049 PCRF与Diameter对端链路故障”**、**“ALM-34077 PCRF与OCS接入点通讯故障”**、**“ALM-34078 PCRF与OCS链路故障”**、**“ALM-34088 PCRF与容灾PCRF通讯故障”**或 **“ALM-34089 PCRF与容灾PCRF链路故障”**告警。

## 注意事项

执行该命令前，需要保证所有DLB/LDAP服务处于正常状态。

## 参数说明

| 参数ID        | 参数名称   | 参数描述                                                                                                                                              |
|:------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
| ASSIGNTYPE  | 分配类型   | 可选必选说明：必选参数 参数含义：用于链路重新均衡分配。 取值范围： REASSIGN(REASSIGN)：强制将DLB/LDAP链路按照在线的DLB/LDAP服务重新均衡分配。INSTNUMBER(INSTNUMBER)：重新设置DLB/LDAP部署实例数。 默认值：无。 配置原则：无。 |
| SERVICETYPE | 服务类型   | 可选必选说明：条件必选参数 参数含义：用于重新指定链路的服务类型。仅当“分配类型”设置为“REASSIGN(REASSIGN)”时，该参数显示且为必选参数。 取值范围： DLBLDAP 默认值：无。 配置原则：无。                                       |

## 使用实例

1. 重新均衡分配DLB链路。“分配类型”为“REASSIGN”，“服务类型”为“DLB”。

   ```
   ACT LINKASSIGN: ASSIGNTYPE=REASSIGN, SERVICETYPE=DLB;
   ```
2. 重新设置DLB/LDAP部署实例数。“分配类型”为“INSTNUMBER”。

   ```
   ACT LINKASSIGN: ASSIGNTYPE=INSTNUMBER;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
