# 修改整机Trunk Remark配置（MOD GLBTRUNKREMARK）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U**

该命令用于修改已有的整机Trunk Remark配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                                                                                               |
|:-----------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| QCI        | QCI      | 可选必选说明：必选参数 参数含义：该参数表示QoS流量级别。 数据来源：本端规划 取值范围：整数类型，取值范围为1~9，65~66，69~70。 默认值：无 配置原则：无                                                                                                                                                              |
| ARPPL      | ARP的优先级别 | 可选必选说明：必选参数 参数含义：该参数表示ARP的优先级别。 数据来源：全网规划 取值范围：整数类型，取值范围为0～15。 默认值：无 配置原则：无                                                                                                                                                                        |
| REMARKTYPE | 标记类型     | 可选必选说明：必选参数 参数含义：该参数用于表示映射到DSCP或者TOS。 数据来源：全网规划 取值范围：枚举类型。 DSCP：映射到DSCP。TOS：映射到TOS。 默认值：无 配置原则：无                                                                                                                                                   |
| DSCP       | DSCP     | 可选必选说明：条件必选参数 前提条件：该参数在“REMARKTYPE”配置为“DSCP”时为必选参数。 参数含义：该参数用于表示DSCP。 数据来源：全网规划 取值范围：枚举类型。 EF：对应的DSCP的值为101110。AF：对应的DSCP的值由参数AfClass和AfDropPrec界定。BE：对应的DSCP的值为000000。CS6：对应的DSCP的值为110000。CS7：对应的DSCP的值为111000。DSCP_VALUE：映射的DSCP值。 默认值：无 配置原则：无 |
| AFCLASS    | AF级别     | 可选必选说明：条件必选参数 前提条件：该参数在“DSCP”配置为“AF”时为必选参数。 参数含义：该参数用于表示AF队列序号。 数据来源：全网规划 取值范围：整数类型，取值范围为1～4。 默认值：无 配置原则：无                                                                                                                                         |
| AFDROPPREC | AF丢弃优先级  | 可选必选说明：条件必选参数 前提条件：该参数在“DSCP”配置为“AF”时为必选参数。 参数含义：该参数表示AF丢弃优先级。 数据来源：全网规划 取值范围：整数类型，取值范围为1～3。 默认值：无 配置原则：无                                                                                                                                          |
| TOSVALUE   | TOS值     | 可选必选说明：条件必选参数 前提条件：该参数在“REMARKTYPE”配置为“TOS”时为必选参数。 参数含义：该参数表示映射到TOS的值，分别对应IP优先级的8个队列ID，优先值高的报文先于优先值低的报文发送。 数据来源：全网规划 取值范围：整数类型，取值范围为0～7。 默认值：无 配置原则：无                                                                                              |
| DSCPVALUE  | DSCP值    | 可选必选说明：条件必选参数 前提条件：该参数在“DSCP”配置为“DSCP_VALUE”时为必选参数。 参数含义：该参数用于表示映射的DSCP值。 数据来源：全网规划 取值范围：整数类型，取值范围为0～63。 默认值：无 配置原则：无                                                                                                                              |

#### 使用实例

将整机中Trunk Remark配置是QCI为1，ARP优先级为1，Remark类型为TOS，且TOS值为3的数据修改为TOS值为5：

```
MOD GLBTRUNKREMARK: QCI=1, ARPPL=1, REMARKTYPE=TOS, TOSVALUE=5;
```
