# 增加层二规则（ADD L2RULE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于添加层二规则。在以太网会话流程中，SMF根据层二规则绑定的QOSPROP和L2FILTER配置中的参数创建专载。

## 注意事项

- 该命令执行后只对新接入的会话生效。

- 最多可输入10000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                                                          |
|:-------------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| L2RULENAME   | 层二规则名称  | 可选必选说明：必选参数  参数含义：该参数用于指定层二规则名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。不支持空格，不区分大小写。  默认值：无  配置原则：无                                                              |
| QOSPROPNAME  | QoS属性名称 | 可选必选说明：必选参数  参数含义：该参数用于指定QoS属性名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。不支持空格，不区分大小写。  默认值：无  配置原则：  该参数使用ADD CPQOSPROP命令配置生成，且只允许指定QOSTYPE为QOS_L2_PARA的Qos属性记录。 |
| L2FILTERNAME | 层二过滤器名称 | 可选必选说明：必选参数  参数含义：该参数用于指定层二过滤器名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。不支持空格，不区分大小写。  默认值：无  配置原则：  该参数使用ADD L2FILTER命令配置生成。                                    |

## 使用实例

某运营商需要定义一个层二规则，要求规则绑定的Qos属性名称为“qosprop1”，层二过滤器名称为“filter1”：

```
ADD L2RULE: L2RULENAME="rule1", QOSPROPNAME="qosprop1", L2FILTERNAME="filter1";
```
