# 删除MDT上下文(RMV MDTCTX)

- 使用实例

#### 命令功能

**须知** 

MDT任务正常运行时，删除本地的MDT配置参数会导致该任务异常。正常场景下请慎用本功能。

**适用网元：MME**

用于在异常场景下本地残留MDT配置参数时需要删除用户在MME上的MDT信息的情况下使用。

#### 注意事项

- 该命令执行后立即生效。
- MDT任务正常运行时，删除本地的MDT配置参数会导致该任务异常。正常场景下请慎用本功能。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                  |
|:----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------|
| RMVOPTION | 删除方式   | 可选必选说明：可选参数 参数含义：该参数用于指定被删除用户的识别码类型。 取值范围：枚举类型。“BYIMSI(指定IMSI)。” 默认值： “BYIMSI(指定IMSI)。”                                               |
| IMSI      | IMSI   | 可选必选说明：条件必选参数 参数含义：该参数用于指定被删除用户的国际移动用户识别码，由MCC，MNC，MSIN组成，在PLMN中唯一标识用户。 前提条件：该参数在“删除方式”设置为“BYIMSI(指定IMSI)”时有效。 取值范围：0~15位十进制数字。 默认值：无 |

#### 使用实例

删除IMSI号为123032201000001的用户的MDT上下文的相关信息

RMV MDTCTX: RMVOPTION=BYIMSI, IMSI="123032201000001";
