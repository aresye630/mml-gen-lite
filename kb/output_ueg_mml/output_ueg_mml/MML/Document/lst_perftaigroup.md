# 查询TAI组性能统计对象（LST PERFTAIGROUP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C、SMF**

该命令用于查询TAI组性能统计对象信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                            |
|:-------------|:-------|:----------------------------------------------------------------------------------------------------------------|
| TAIGROUPNAME | TAI组名  | 可选必选说明：可选参数  参数含义：该参数用于指定TAI组的性能统计名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~255。不区分大小写，不支持空格及“\”且全局唯一。  默认值：无  配置原则：无 |

## 使用实例

当需要查询所有TAI组性能统计对象，执行如下命令：

```
LST PERFTAIGROUP:;
RETCODE = 0  操作成功。

结果如下
------------------------
TAI组名  =  huawei
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释               |
|:--------|:--------------------|
| TAI组名   | 该参数用于指定TAI组的性能统计名称。 |
