# 设置间接路由功能（SET UPSCPFUNCSW）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

**须知** 

本命令属于高危命令，是

该命令用于设置间接路由功能。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为3。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | LNFType   | PNFType   | SCPRouteSw   |
|:-------|:----------|:----------|:-------------|
| 初始值    | NfGMLC    | NfUDM     | OFF          |
| 初始值    | NfGMLC    | NfAMF     | OFF          |
| 初始值    | NfLMF     | NfAMF     | OFF          |

- SCP网元添加完成（通过命令ADD UPPNFPROFILE添加）以后才允许设置间接路由开关为ON；。
- 删除最后一条SCP配置前（通过命令RMV UPPNFPROFILE删除），所有记录的间接路由开关需要先设置为OFF。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                        |
|:-----------|:---------|:------------------------------------------------------------------------------------------------------------|
| LNFTYPE    | 本端NF类型   | 可选必选说明：必选参数 参数含义：该参数用于指定本端NF的类型。 数据来源：全网规划 取值范围： NfLMF：NfLMF。NfGMLC：NfGMLC。 默认值：无 配置原则：无                    |
| PNFTYPE    | 对端NF类型   | 可选必选说明：必选参数 参数含义：该参数用于指定对端NF的类型。 数据来源：全网规划 取值范围： NfUDM：NfUDM。NfAMF：NfAMF。 默认值：无 配置原则：无                      |
| SCPROUTESW | 间接路由功能开关 | 可选必选说明：可选参数 参数含义：该参数用于设置间接路由功能，如果设置为ON，则指定的本端和对端类型的NF之间通过SCP转发。 数据来源：全网规划 取值范围： OFF：OFF。ON：ON。 默认值：无 配置原则：无 |

#### 使用实例

修改GMLC与UDM的间接路由开关为打开：

```
SET UPSCPFUNCSW: LNFTYPE=NfGMLC, PNFTYPE=NfUDM, SCPROUTESW=ON;
```
