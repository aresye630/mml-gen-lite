# 显示GTP-U路径个数(DSP GTPUPATHNUM)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用网元：SGSN**

该参数用于查询系统内的GTP-U路径数目。

#### 注意事项

该命令只用于查询SPU节点上的UPP进程。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                  |
|:-------|:-------|:----------------------------------------------------------------------|
| RUNAME | RU名称   | 可选必选说明：可选参数 参数含义：该参数用于指定资源单元名称。该参数可以通过DSP RU命令查询。 取值范围：1~63位字符串 默认值：无 |
| PROCTP | 进程类型   | 可选必选说明：可选参数 参数含义：该参数用于指定进程的进程类型。 取值范围： “UPP” 默认值：无                    |
| PROCNO | 进程号    | 可选必选说明：可选参数 参数含义：该参数用于指定进程的序号。 取值范围：0~20 默认值：无                        |

#### 使用实例

1. 查询资源单元为USN\_SP\_RU\_0064上的GTP-U路径数：

   DSP GTPUPATHNUM: RUNAME="USN\_SP\_RU\_0064";

   ```
   %%DSP GTPUPATHNUM: RUNAME="USN_SP_RU_0064";%%
   RETCODE = 0  操作成功。

   输出结果如下
   -------------------------
       RU名称 = USN_SP_RU_0064
     进程类型 = UPP
       进程号 = 0
   GTPU路径数 = 6
   (结果个数 = 1)

   ---    END
   ```

#### 输出结果说明

| 输出项名称   | 输出项解释                      |
|:--------|:---------------------------|
| RU名称    | 资源单元名称。                    |
| 进程类型    | GTP-U路径所在进程的类型。 取值说明：“UPP” |
| 进程号     | GTP-U路径所在进程的序号。            |
| GTPU路径数 | GTP-U路径数目。                 |
