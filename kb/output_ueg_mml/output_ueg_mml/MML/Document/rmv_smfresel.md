# 删除本地SMF重选策略（RMV SMFRESEL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除一条本地SMF重选策略的配置记录。

## 注意事项

- 该命令执行后立即生效。

- 执行删除命令不配置SD时，默认删除SD值为“FFFFFF”的记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称        | 参数说明                                                                                                                                                                               |
|:--------|:------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DNN     | DNN         | 可选必选说明：必选参数  参数含义：该参数用于表示SMF重选目标DNN。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。可输入的字符有字母、十进制数字、“-”和“.”，并且开头和结尾只能是数字或者字母。不能出现连续两个“.”。字母大小写不敏感。  默认值：无  配置原则：无                              |
| ISNSSAI | 是否匹配S-NSSAI | 可选必选说明：必选参数  参数含义：该参数用于表示SMF重选时是否匹配S-NSSAI。  数据来源：全网规划 取值范围： “YES（是）”：是“NO（否）”：否  默认值：无  配置原则：  如果运营商期望根据S-NSSAI和DNN的方式选择需要重建的PDU会话，则设置为“YES”；如果运营商期望仅根据DNN选择需要重建的PDU会话，则设置为“NO”。  |
| SST     | 切片业务类型      | 可选必选说明：该参数在"ISNSSAI"配置为"YES"时为条件必选参数。  参数含义：该参数用于表示组成SMF重选目标网络切片的业务类型信息。网络切片标识（S-NSSAI）由切片业务类型（SST）和切片细分标识（SD）两部分组成，其中切片细分标识是可选的。  数据来源：全网规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无 |
| SD      | 切片细分标识      | 可选必选说明：该参数在"ISNSSAI"配置为"YES"时为条件可选参数。  参数含义：该参数用于表示组成SMF重选目标网络切片的细分标识。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。采用十六进制表示（无须输入“0x”前缀），只能由数字（0-9），字母（A-F、a-f）组成。字母大小写不敏感。  默认值：无  配置原则：无        |

## 使用实例

删除“DNN”为IMS的本地SMF重选配置记录：

```
RMV SMFRESEL: DNN="IMS", ISNSSAI=NO;
```
