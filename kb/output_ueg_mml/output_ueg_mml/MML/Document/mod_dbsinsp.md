# 修改DBS软件参数的配置信息(MOD DBSINSP)

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致业务中断，需联系华为技术支持确认后再执行。

该命令用于在配置DBS软参数据时，修改DBS软件参数的值，包括局内心跳超时时长、局间心跳超时时长、升级状态等。在该命令中，系统通过以下关键参数的组合来唯一标识一条DBS软件参数的配置信息：

- “软件参数名称”
- “软件参数值”

## 注意事项

- 该命令用于在配置DBS软参数据时，只需要对DBS软参作适当修改以得到所需要的配置数据，而不需要添加或删除软参的操作。
- 在缺省的情况下，系统在初始化的时候已经预置了DBS软参数据表中的全部数据。
- 一般情况下，操作员使用默认值。如果操作员确实需要修改软件参数，请联系华为公司技术服务工程师处理，禁止随意修改。

## 参数说明

| 参数ID   | 参数名称   | 参数描述                                                                                                                           |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------|
| INSPN  | 软件参数名称 | 可选必选说明：必选参数 参数含义：标识一条软参数据记录的关键字段（其取值不能被修改），用于指定需要对哪一个软件参数名称进行修改。 取值范围：请参考产品手册的“DBS软件参数”。 默认值：无。 配置原则：操作员可以通过LST DBSINSP命令查询获得。 |
| INSPV  | 软件参数值  | 可选必选说明：必选参数 参数含义：用于标识需要修改的软件参数的参数值。 取值范围：请参考产品手册的“DBS软件参数”。 默认值：无。 配置原则：无。                                                     |

## 使用实例

修改DBS软参。“软件参数名称”为“OUTERHEARTBEATTIMEOUT”，“软件参数值”为“20000”。

```
MOD DBSINSP: INSPN=OUTERHEARTBEATTIMEOUT, INSPV=20000;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
