# 添加通知服务对端链路配置信息(ADD NTSPEERLINKCFG)

- 参数说明

- 输出结果说明

## 命令功能

该命令用于增加一条通知任务服务对端链路配置信息。

使用场景：

UPCF支持在特定场景（例如用户流量达到阈值、配额充值）给用户发送通知，提醒用户当前业务的使用状态；或将通知发送到第三方服务器上，由第三方服务器决定后续的处理。

- 与短消息中心对接，可以通过短消息中心发送短信通知给终端用户。
- 与邮件服务器对接，可以通过邮件服务器发送邮件通知给终端用户。
- 与SOAP服务器对接，可以发送SOAP通知到SOAP服务器上，由SOAP服务器决定后续的处理（如以短信、邮件或PUSH通知方式通知给终端用户）。

通知发送前配置UPCF与对端的对接数据为必选操作之一。需执行本命令增加UPCF负责通知任务服务（NTS）与对端的链路信息，如CMPP链路，通过指定“本地角色”参数来实现。

在该命令中，以下关键参数需要与对端服务器协商：

- “对端IP地址”
- “对端IPV6地址”
- “对端端口”

## 注意事项

- 系统支持不同协议的链路共存。
- 对端为“SMS”和“E-MAIL”服务器的物理链路数总和不能超过8条。
- 当“PSRVID”对应的应用类型为“SOAP”时，对于“WSDL文件”参数取值为“Common(Common)”和“IdnX(IdnX)”的物理链路加起来最多只允许存在16条。
- “WSDL文件”参数取值为“FrB(FrB)”的物理链路最多只允许存在1条且不支持与其他“本地角色”为“SOAP客户”的物理链路同时存在。
- 如果只配置了SMS的JMS链路，则UPCF只能发送SMS给JMS服务器；如果只配置了E-MAIL的JMS链路，则UPCF只能发送E-MAIL给JMS服务器；如果UPCF既要发短信又要发送Email给JMS服务器，则要配置两条JMS链路。
- “本地角色”的配置取决于“对端服务器类型”：
  - 当对端服务器的“对端服务器类型”为“SMS协议”时，“本地角色”只能为“SOAP客户端”、“JMS客户端”、“CMPP客户端”、“SMPP客户端”或“SGIP客户端”。
  - 当对端服务器的“对端服务器类型”为“E-MAIL协议”时，“本地角色”只能为“SMTP客户端”或“JMS客户端”。
  - 当对端服务器的“对端服务器类型”为“SOAP协议”时，“本地角色”只能为“SOAP客户端”。
- 当“本地角色”选择为“SOAP客户端”，需要设置“WSDL文件”。
  - 当“WSDL文件”选择为“NwT(NwT)”、“NlK(NlK)”和“IrZ(IrZ)”时，对端服务器的“对端服务器类型”为“SMS协议”。
  - 当“WSDL文件”选择为“Common(Common)”、“FrB(FrB)”和“IdnX(IdnX)”时，对端服务器的“对端服务器类型”必须为“SOAP协议”。
- 参数“对端IP地址”（或“对端IPV6地址”）和“对端端口”必须与参数“SOAP服务器URL”及“认证服务器URL”中包含的IP地址和端口保持一致。
- “本地角色”为“CMPP客户端”、“SMPP客户端”和“SMTP客户端”的物理链路和虚拟链路的总数不能超过64条。
- 设置“本端IP地址”后，NTS与对端服务器的通信只能使用该命令配置的“本端IP地址”，不能再使用**ADD NTSDEVADDR**命令定义的其他IP地址。
- IPv4类型的IP地址不能配置如下非法IP地址：“127.0.0.1”、“0.0.0.0”、“255.255.255.255”、“224.0.0.1”。
- IPv6类型的IP地址不支持混合方式表达，即xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:d.d.d.d，其中x表示一个十六进制数（0～9或A～F），而d.d.d.d表示一个IPv4地址。
- IPv6类型的IP地址不支持以下特殊地址的配置，其中x表示一个十六进制数（0～9或A～F）：

  - 0000:0000:0000:0000:0000:0000:0000:0000
  - FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF
  - 0000:0000:0000:0000:0000:0000:0000:0001
  - FFxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE8x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE9x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEAx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEBx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
- 当前版本不支持“WSDL文件”取值为“NwT(NwT)”、“NlK(NlK)”、“IrZ(IrZ)”、“FrB(FrB)”、“IdnX(IdnX)”，仅做命令预埋。
- 当前版本不支持“本地角色”取值为“JMSClient(JMS客户端)”、“SGIPClient(SGIP客户端)”，仅做命令预埋。
- 当NTS服务与短信服务器对接时，需短信服务端能支持至少n\*m个连接处理，其中n表示NTS实例个数，m表示配置的通知链路数量。

## 使用实例
