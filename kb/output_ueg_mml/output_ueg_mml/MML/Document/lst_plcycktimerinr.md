# 查询策略类型和核查间隔（LST PLCYCKTIMERINR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询策略类型和核查间隔。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询策略类型和核查间隔，内部策略用inner strategy，外部策略用outer strategy，核查间隔单位为分钟。

```
%%LST PLCYCKTIMERINR:;%%
RETCODE = 0  操作成功

结果如下
------------------------             
策略类型   策略核查时间间隔 (分钟) 
内部策略           1
外部通信策略    10
(结果个数 = 2)

---    END
```

## 输出结果说明

| 输出项名称         | 输出项解释                                |
|:--------------|:-------------------------------------|
| 策略类型          | 该参数用于设置策略类型，Inner表示内部策略，Outer表示外部策略。 |
| 策略核查时间间隔 (分钟) | 该参数用于设置策略核查时间间隔，单位分钟。                |
