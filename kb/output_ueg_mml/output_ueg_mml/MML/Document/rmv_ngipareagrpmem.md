# 删除5G IP区域群成员（RMV NGIPAREAGRPMEM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除5G IP区域群成员。

## 注意事项

命令执行后只对新接入用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                           |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| AREAID | 区域群标识  | 可选必选说明：必选参数  参数含义：该参数用于指定区域群标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~64。此AREAID要与NGIPAREAGRP中的AREAID保持一致，受NGIPAREAGRP中的IPAREASW开关控制。  默认值：无  配置原则：无 |
| TAC    | 跟踪区域码  | 可选必选说明：可选参数  参数含义：该参数用于指定跟踪区域码。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。TAC编码为16进制数，按照字符串格式输入，字符串长度为6，只能由数字（0-9），字母（A-F、a-f）组成。字母大小写不敏感。  默认值：无  配置原则：无  |

## 使用实例

删除一条IP区域群成员记录，区域群标识为SomeCity，跟踪区域码为0x123456，执行如下命令：

```
RMV NGIPAREAGRPMEM: AREAID="SomeCity", TAC="123456";
```
