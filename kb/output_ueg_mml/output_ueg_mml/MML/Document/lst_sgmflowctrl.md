# 查询SGM流控参数（LST SGMFLOWCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询SGM流控参数信息。

- 如果需要查询所有SGM流控参数信息，请不要输入任何参数。
- 如果需要查询指定SGM流控参数信息，请依据参数说明输入查询的条件。

  **说明** 

  产品暂不支持该命令功能，预埋显示此命令。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称        | 参数说明                                                                                                                   |
|:----------|:------------|:-----------------------------------------------------------------------------------------------------------------------|
| FLWCTRFLG | 流量控制开关      | 可选必选说明：可选参数 参数含义：用于指示系统按照是否开启“流量控制开关”来查询流控参数；若不输入，则表示所有的流量控制开关。 取值范围：ON(打开流控) OFF(关闭流控) 默认值：无。 配置原则：无。                 |
| CPUFLWSTR | CPU启控阈值     | 可选必选说明：可选参数 参数含义：用于指示系统按照“CPU启控阈值”的值来查询流控参数；若不输入，则表示所有的CPU启控阈值。 取值范围：10~100 单位：％ 默认值：无。 配置原则：无。                        |
| CPUFLWEND | CPU解控阈值     | 可选必选说明：可选参数 参数含义：用于指示系统按照“CPU解控阈值”的值来查询流控参数；若不输入，则表示所有的CPU解控阈值。 取值范围：0~90 单位：％ 默认值：无。 配置原则：无。                          |
| ASSBECF   | USCDB协控开关   | 可选必选说明：可选参数 参数含义：用于指示系统按照是否开启“USCDB协控开关”来查询流控参数；若不输入，则表示所有的USCDB协控开关。 取值范围： ON(打开USCDB协控)OFF(关闭USCDB协控) 默认值：无。 配置原则：无。 |
| RSUFCSTR  | USCDB协控起控比率 | 可选必选说明：可选参数 参数含义：用于指示系统按照 “USCDB协控起控比率 ”的值来查询流控参数；若不输入，则表示所有的USCDB协控起控比率。 取值范围：1~100 单位：％ 默认值：无。 配置原则：无。               |
| RSUFCSTP  | USCDB协控解控比率 | 可选必选说明：可选参数 参数含义：用于指示系统按照 “USCDB协控解控比率” 的值来查询流控参数；若不输入，则表示所有的USCDB协控解控比率。 取值范围：0-99 单位：％ 默认值：无。 配置原则：无。                |

## 使用实例

假如运营商需要修改SGM流量控制开关、启控条件等参数，需要先查询SGM流控配置。

```
LST SGMFLOWCTRL:;
```

```
%%LST SGMFLOWCTRL:;%%
RETCODE = 0  操作成功

操作结果如下 
------------
            流量控制开关  =  打开流控
             CPU启控阈值  =  75
             CPU解控阈值  =  70
           USCDB协控开关  =  打开USCDB协控
       USCDB协控起控比率  =  15
       USCDB协控解控比率  =  10
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**MOD SGMFLOWCTRL**命令的参数说明。
