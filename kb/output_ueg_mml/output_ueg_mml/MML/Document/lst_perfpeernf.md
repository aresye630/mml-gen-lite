# 查询NF局向性能统计对象（LST PERFPEERNF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF、SMF、SMSF、NCG**

该命令用于查询NF局向性能统计对象。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                                                        |
|:--------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INTERFACETYPE | 接口类型   | 可选必选说明：可选参数  参数含义：该参数表示对端局向服务化接口类型。  数据来源：全网规划 取值范围： “N7（N7）”：N7“N8（N8）”：N8“N10（N10）”：N10“N11（N11）”：N11“N12（N12）”：N12“N15（N15）”：N15“N17（N17）”：N17“N20（N20）”：N20“N21（N21）”：N21“N40（N40）”：N40“Nocs（Nocs）”：Nocs  默认值：无  配置原则：无 |
| NFINSTANCEID  | NF实例号  | 可选必选说明：可选参数  参数含义：该参数表示对端局向NF实例号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~40。  默认值：无  配置原则：无                                                                                                                                        |

## 使用实例

查询所有的NF局向性能统计对象：

```
%%LST PERFPEERNF:;%%
RETCODE = 0  操作成功

结果如下
--------
接口类型  =  N8
NF实例号  =  AMF_INSTANCE_001
    描述  =  NULL
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释             |
|:--------|:------------------|
| 接口类型    | 该参数表示对端局向服务化接口类型。 |
| NF实例号   | 该参数表示对端局向NF实例号。   |
| 描述      | 该参数用于描述对端局向信息。    |
