# 删除DNS Client IP与DNS实体的绑定关系(RMV DNSLE)

- 命令功能
- 注意事项
- 本地用户权限
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGSN、MME、AMF**

该命令用于删除DNS本端实体。

#### 注意事项

- 该命令执行后立即生效。
- 当同时配置了IPv4地址和IPv6地址时，需要保证配置的IPv4地址和IPv6地址数量相同。

#### 本地用户权限

manage-ug；system-ug

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                                                                    |
|:--------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------|
| IPT     | IP地址类型    | 可选必选说明：必选参数 参数含义：该参数用于指定IP地址类型。 数据来源：整网规划 取值范围：“IPV4(IPV4)”“IPV6(IPV6)” 默认值：无                                                           |
| IPV4    | IPv4地址    | 可选必选说明：条件必选参数 参数含义：该参数用于指定IPv4地址。 前提条件：当“IP地址类型”设置为“IPV4(IPV4)”时，该参数有效。 数据来源：整网规划 取值范围：0.0.0.0～255.255.255.255 默认值：无                    |
| IPV6    | IPv6地址    | 可选必选说明：条件必选参数 参数含义：该参数用于指定IPv6地址。 前提条件：当“IP地址类型”设置为“IPV6(IPV6)”时，该参数有效。 数据来源：整网规划 取值范围：::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 |
| LOCPORT | 本地端口号     | 可选必选说明：必选参数 参数含义：该参数用于指定本端端口号。 数据来源：整网规划 取值范围：15000~65535 默认值：无                                                                         |
| VPNNAME | VPN名称     | 可选必选说明：可选参数 参数含义：该参数用于指定DNS本端实体到DNS服务器间的链路所用的VPN名称。 数据来源：整网规划 取值范围：0~31个字符。 默认值：无                                                       |
| LENAME  | DNS本端实体名称 | 可选必选说明：可选参数 参数含义：该参数用于指定DNS本端实体的名称。 数据来源：整网规划 取值范围：0~32个字符。 默认值：无                                                                       |

#### 使用实例

删除DNS本端实体：IP地址192.168.97.26；本端端口号15001。

RMV DNSLE:IPT=IPV4,IPV4="192.168.97.26",LOCPORT=15001;
