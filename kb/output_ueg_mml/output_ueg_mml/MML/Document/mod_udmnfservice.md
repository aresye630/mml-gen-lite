## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成UDM在NRF上的注册信息中的服务信息发生错误，从而导致周边网元无法访问UDM提供的服务，造成业务失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一条网元服务信息数据记录的某些参数进行修改或调整。在该命令中，系统通过“服务标识”关键参数来唯一标识一条网元服务信息。

## 注意事项

- 任一参数被修改后，如果当前“服务标识”所在的“组名称”被**ADD UDMNFSRV**引用，且**ADD UDMNFSRV**命令中的“网元状态”为“REGISTERED”时，则按“更新方式”中指定的更新模式立即向NRF发送更新请求。
- 修改“服务名称”时，只能在同一种网元类型的服务名称间修改，如修改的与之前服务名称不是同一个网元，则提示用户，修改失败。
- 当凌晨自动校验或执行**VRY NRFDATA**命令手动校验NRFClient内存数据时，在校验该MML命令的过程中，无法执行该命令，若运行该命令，则提示“360155 该MML数据正在校验中，请稍后再试”。

## 使用实例

在开局场景下配置本局数据时，修改“服务标识”为“srv1”网元服务信息，将“方案”修改为“https(https)”，“支持特性”修改为“003”：

```
MOD UDMNFSERVICE: SERVICEID="srv1", SCHEME=https, SUPPORTFEATURES="003";
```

## 输出结果说明
