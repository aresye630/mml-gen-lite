# 设置Token分配策略(SET TOKENASSIGNPLY)

## 命令功能

本命令用于设置Token分配策略，实现Token分配时灵活控制启动分配Token的HLB/PES/SGM就绪状态实例比例和Token迁移的缄默等待时长。

缄默等待时间计算公式：

- 故障缄默等待时间=“故障缄默时长”
- 就绪缄默等待时间=“就绪缄默时长”\*i

  当**i**/“就绪缄默步长”>=N/M时，系统自动计算出**i**的取值（0<=i<=“就绪缄默步长”），向上取整。

  **说明** 

  - N/M=当前已分配token的实例个数/服务部署的实例总数。
  - 就绪缄默等待时间是随着就绪的实例数增加而拉长的，最短等待时间为0，最长等待时间为“就绪缄默时长”\*“就绪缄默步长”。
  - 缄默时间内，所有实例达到就绪状态时DCF会立即分配Token。

该命令存在系统初始记录，参数的初始设置值如下：

|   ID |   分配阈值 |   故障缄默时长 |   就绪缄默时长 |   就绪缄默步长 |
|-----:|-------:|---------:|---------:|---------:|
|    1 |     30 |        0 |     5000 |        5 |

## 注意事项

无。

## 参数说明

| 参数标识             | 参数名称   | 参数描述                                                                                 |
|:-----------------|:-------|:-------------------------------------------------------------------------------------|
| ID               | ID     | 可选必选说明：必选参数 参数含义：该参数用于标识一条Token分配策略数据记录。 取值范围：1 默认值：无。 配置原则：无。                       |
| ASSIGNTHRESHOLD  | 分配阈值   | 可选必选说明：可选参数 参数含义：用于设置启动分配Token的HLB/PES/SGM就绪实例比例。 取值范围：0~100 单位：% 默认值：无。 配置原则：无。     |
| FAULTSILENTTIME  | 故障缄默时长 | 可选必选说明：可选参数 参数含义：用于设置HLB/PES/SGM实例故障后Token迁移的缄默时长。 取值范围：0~15000 单位：毫秒 默认值：无。 配置原则：无。 |
| NORMALSILENTTIME | 就绪缄默时长 | 可选必选说明：可选参数 参数含义：用于设置HLB/PES/SGM实例就绪后Token迁移的缄默时长。 取值范围：0~60000 单位：毫秒 默认值：无。 配置原则：无。 |
| NORMALSILENTSTEP | 就绪缄默步长 | 可选必选说明：可选参数 参数含义：用于设置HLB/PES/SGM实例就绪后Token迁移的缄默步长。 取值范围：0~10 默认值：无。 配置原则：无。          |

## 使用实例

设置Token分配策略，“ASSIGNTHRESHOLD”取值为40%时启动分配Token，实例如下

```
SET TOKENASSIGNPLY: ID=1, ASSIGNTHRESHOLD=40;
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。
