# 删除AMF的N2接口信息（RMV N2INFAMFINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除当前AMF的N2接口信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                                                         |
|:---------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCENAME | NF实例名称 | 可选必选说明：必选参数  参数含义：本参数用于指定NF实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~50。  默认值：无  配置原则：  本参数需要与ADD NFUUID命令中的NFINSTANCENAME值保持一致。 |

## 使用实例

运营商A需要删掉当前AMF的N2接口信息。

```
RMV N2INFAMFINFO: NFINSTANCENAME="AMF_Instance_0";
```
