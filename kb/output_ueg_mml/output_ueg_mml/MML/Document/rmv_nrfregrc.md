# 删除NRF注册结果码（RMV NRFREGRC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除在配置数据库中的一条NRF注册结果码数据记录。

## 注意事项

命令生效条件：执行该命令立即生效。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                |
|:-------|:-------|:----------------------------------------------------------------------------------------------------|
| RC     | 结果码    | 可选必选说明：必选参数 参数含义：用于指定需要删除哪一条NRF注册结果码，操作员可以使用LST NRFREGRC命令查询获得。 取值范围：100～199，202～999 默认值：无。 配置原则：无。 |

## 使用实例

删除一条NRF注册结果码数据记录，“结果码”为“150”。

```
RMV NRFREGRC: RC=150;
```
