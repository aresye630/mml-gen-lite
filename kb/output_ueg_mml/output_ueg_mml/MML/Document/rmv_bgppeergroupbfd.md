# 删除BGP对等体组BFD检测（RMV BGPPEERGROUPBFD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除对等体组的BFD检测。

#### 注意事项

- 该命令执行后立即生效。
- 当仅指定组地址族类型和组名时，此时去使能对等体组上的BFD功能。当指定其他参数时，此时恢复对应参数为默认值。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称         | 参数说明                                                                                                                         |
|:------------|:-------------|:-----------------------------------------------------------------------------------------------------------------------------|
| VRFNAME     | VPN实例名称      | 可选必选说明：可选参数 参数含义：该参数用于指定用户的BGP VPN实例。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：_public_ 配置原则：使用LST L3VPNINST命令查看可用VPN。          |
| GROUPNAME   | 组名           | 可选必选说明：必选参数 参数含义：该参数用于指定用户所配置的对等体组。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～47。 默认值：无 配置原则：使用LST BGPPEERGROUP命令查看可用对等体组名。              |
| AFTYPE      | 组地址族类型       | 可选必选说明：必选参数 参数含义：该参数用于指定BGP VPN实例下的地址族。 数据来源：本端规划 取值范围：枚举类型。 public：公网地址族。ipv4uni：IPv4地址族。ipv6uni：IPv6地址族。noaf：不指定地址族。 默认值：无 |
| MULTIPLIER  | 检测时间倍数       | 可选必选说明：可选参数 参数含义：该参数用于指定BFD会话的检测时间倍数。 数据来源：本端规划 取值范围：整数类型，取值范围为3～50。 默认值：无                                                   |
| ISBFDENABLE | BFD是否使能      | 可选必选说明：可选参数 参数含义：该参数用于指定是否使能BFD检测。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无                                           |
| RXINTERVAL  | 最小接收间隔时间（ms） | 可选必选说明：可选参数 参数含义：该参数用于指定该BFD的最小接收时间间隔。 数据来源：本端规划 取值范围：整数类型，取值范围为30～1000，单位是毫秒。 默认值：无                                         |
| TXINTERVAL  | 最小发送间隔时间（ms） | 可选必选说明：可选参数 参数含义：该参数用于指定该BFD的最小发送时间间隔。 数据来源：本端规划 取值范围：整数类型，取值范围为30～1000，单位是毫秒。 默认值：无                                         |
| ISSINGLEHOP | 使能单跳模式       | 可选必选说明：可选参数 参数含义：该参数用于指定是否设置BFD为单跳模式。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无                                        |

#### 使用实例

删除对等体组的BFD检测：

```
RMV BGPPEERGROUPBFD:VRFNAME="vpna",AFTYPE=ipv4uni,GROUPNAME="asdf",RXINTERVAL=200,TXINTERVAL=200;
```
