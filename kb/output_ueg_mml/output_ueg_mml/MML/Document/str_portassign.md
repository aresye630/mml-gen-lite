# 启动端口分配（STR PORTASSIGN）

- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响业务处理，需联系华为技术支持确认后再执行。

本命令用于重新分配PMS和DRS服务的端口范围。

## 注意事项

HLB与NTS服务不支持通过此命令进行端口重置。

## 参数说明

| 参数标识        | 参数名称   | 参数描述                                                                      |
|:------------|:-------|:--------------------------------------------------------------------------|
| SERVICETYPE | 服务类型   | 可选必选说明：必选参数 参数含义：用于指定重新分配的服务类型。 取值范围：枚举类型 PMS(PMS)DRS(DRS) 默认值：无。 配置原则：无。 |

## 使用实例

日常维护管理，“SERVICETYPE”取值为“PMS”时，重新分配PMS服务端口范围，实例如下。

```
STR PORTASSIGN: SERVICETYPE=PMS;
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。
