# 查询媒体中继全局回源TCP控制（LST GLBRLYOTCPCTRL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明

- 输出结果说明

#### 命令功能

**适用NF：UPF、PGW-U**

该命令用于查询媒体中继全局回源TCP控制。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询媒体中继全局回源TCP控制：

```
LST GLBRLYOTCPCTRL:;
```

```
RETCODE = 0  操作成功

The result is as follows
------------------------
     IPv4最大报文段长度 = 1460
发送缓冲区大小（千字节） =  20
接收缓冲区大小（千字节） =  80
(结果个数 = 1)

---    END
```
