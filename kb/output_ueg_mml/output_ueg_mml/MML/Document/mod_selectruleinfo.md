# 修改UPF选择规则信息（MOD SELECTRULEINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C、SMF**

该命令用于修改UPF选择规则信息。

## 注意事项

- 该命令执行后只对新激活用户生效。

- 修改高通量业务规则时，其优先级需低于重点业务保障和用户体验规则的优先级。
- 当前版本不支持RULERANGE配置为“ALL”。
- 修改媒体中继业务规则时，其优先级低于高通量业务。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                                                    |
|:----------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RULENAME  | 规则名称     | 可选必选说明：必选参数  参数含义：该参数用于指定PCF下发的规则名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。区分大小写。  默认值：无  配置原则：  本参数取值与ADD UPFBINDSELRULE命令中的“规则名称”参数取值保持一致时，该规则的参数功能生效。                   |
| RULEFUNC  | 规则功能     | 可选必选说明：可选参数  参数含义：该参数用于指定PCF下发的规则绑定的功能。  数据来源：全网规划 取值范围： QOSANA（重点业务保障）QOSEXP（用户体验）QOSCCC（高通量业务）RELAY（媒体中继业务）  默认值：无  配置原则：无                                            |
| PRIORITY  | 优先级      | 可选必选说明：可选参数  参数含义：该参数用于标识规则的优先级。  数据来源：全网规划  取值范围：整数类型，取值范围是0~65535。值越小优先级越高。  默认值：无  配置原则：无                                                                            |
| DELIVERSW | 是否下发给UPF | 可选必选说明：可选参数  参数含义：该参数用于标识规则是否下发给UPF。  数据来源：全网规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无  配置原则：无                                                                             |
| RULERANGE | 下发范围     | 可选必选说明：该参数在"DELIVERSW"配置为"ENABLE"时为条件可选参数。  参数含义：该参数用于标识规则的下发范围。  数据来源：全网规划 取值范围： CENTRAL（仅对中心UPF(主锚点UPF)生效）ALL（对所有UPF均生效）  默认值：无  配置原则：  该参数仅在DELIVERSW配置为“ENABLE”时生效。 |

## 使用实例

修改UPF选择规则信息，规则名称为"rulename1"，规则功能为用户体验：

```
MOD SELECTRULEINFO: RULENAME="rulename1", RULEFUNC=QOSANA-0&QOSEXP-1&QOSCCC-0&RELAY-0;
```
