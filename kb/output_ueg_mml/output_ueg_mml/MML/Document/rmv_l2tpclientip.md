# 删除L2TP绑定的接口（RMV L2TPCLIENTIP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于删除L2TP组上已绑定的源端Gi接口。用户删除指定的源端接口场景，可以指定源端接口名称。

#### 注意事项

- 该命令执行后立即生效。
- 该命令不指定源端接口名称场景，只能删除没有用户存在的绑定关系，可以使用LST L2TPCLIENTIP命令查询删除结果。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                        |
|:--------------|:-------|:----------------------------------------------------------------------------|
| L2TPGROUPID   | L2TP组号 | 可选必选说明：必选参数 参数含义：指定L2TP组号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～1500。 默认值：无 配置原则：无    |
| INTERFACENAME | 接口名称   | 可选必选说明：可选参数 参数含义：指定源端Gi接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无 |

#### 使用实例

假设客户不再使用L2TP组1绑定的"giif1/0/0"源端接口与LNS交互，可以使用该命令删除绑定关系：

```
RMV L2TPCLIENTIP:L2TPGROUPID=1,INTERFACENAME="giif1/0/0";
```
