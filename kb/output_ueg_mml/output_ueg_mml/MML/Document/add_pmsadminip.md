# 添加策略管理服务管理员IP地址(ADD PMSADMINIP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于添加策略管理服务的管理员的IP地址。

该命令的使用场景：当需要限制登录PMS服务的IP地址时，可使用本命令添加客户端允许访问PMS服务中WEBUI/SOAP/CLI/REST接口的IP地址。

## 注意事项

系统最多可以配置256个IP地址。

## 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                       |
|:------------|:-----------|:-----------------------------------------------------------------------------------------------------------|
| IPID        | IP地址索引     | 可选必选说明：必选参数 参数含义：用于唯一标识一个IP地址信息，且新增的IP地址索引不能和已有的IP地址索引重复。 取值范围：1～256 默认值：无。 配置原则：无。                        |
| IPVER       | IP版本       | 可选必选说明：必选参数 参数含义：用于指定允许访问策略管理服务界面的IP地址的IP版本类型。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。                   |
| IP          | IP地址       | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV4(IPV4)”时该参数必须配置，用于指定允许访问策略管理服务界面的IPv4地址。 取值范围：IPv4地址 默认值：无。 配置原则：无。        |
| NETMASK     | 子网掩码       | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV4(IPV4)”时该参数支持配置，用于指定允许访问策略管理服务界面的IPv4地址对应的子网掩码。 取值范围：IPv4地址 默认值：无。 配置原则：无。 |
| IPV6        | IPV6地址     | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV6(IPV6)”时该参数必须配置，用于指定允许访问策略管理服务界面的IPv6地址。 取值范围：IPv6地址 默认值：无。 配置原则：无。        |
| IPV6MASK    | IPV6地址前缀长度 | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV6(IPV6)”时该参数支持配置，用于指定允许访问策略管理服务界面的IPv6地址对应的前缀长度。 取值范围：1~128 默认值：无。 配置原则：无。  |
| DESCRIPTION | 描述         | 可选必选说明：可选参数 参数含义：用于对新增IP地址信息进行描述说明。 取值范围：长度不超过48的字符串 默认值：无。 配置原则：无。                                        |

## 使用实例

- 添加策略管理服务管理员IPv4地址：“IP地址索引”为“12”，“IP版本”为“IPV4(IPV4)”，“IP地址”为“192.168.123.111”，“子网掩码”为“255.255.255.0”，“描述”为“IPv4”。

  ```
  ADD PMSADMINIP: IPID=12, IPVER=IPV4, IP="192.168.123.111", NETMASK="255.255.255.0", DESCRIPTION="IPv4";
  ```

- 添加策略管理服务管理员IPv6地址：“IP地址索引”为“15”，“IP版本”为“IPV6(IPV6)”，“IPV6地址”为“2001:0db8:80ff:fa01:0000:0000:0000:1515”，“IPV6地址前缀长度”为“64”，“描述”为“IPv6”。

  ```
  ADD PMSADMINIP: IPID=15, IPVER=IPV6, IPV6="2001:0db8:80ff:fa01:0000:0000:0000:1515", IPV6MASK=64, DESCRIPTION="IPv6";
  ```
