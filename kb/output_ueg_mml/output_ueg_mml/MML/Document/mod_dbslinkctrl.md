# 修改DBS链路中心(MOD DBSLINKCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于修改DBS链路中心。在该命令中，系统通过“服务模块号”参数来唯一标识一条DBS链路中心信息。

## 注意事项

- 通过“本地链路中心校验码”参数指定的本端链路中心的校验码，必须与在远端网元执行**ADD RDSGLINKCTRL**或**MOD RDSGLINKCTRL**指定的校验码一致，否则会导致本网元无法接收该远端的配置消息。
- 本命令配置的“本地链路中心校验码”参数检查在USCDB网元侧进行，禁止配置的“本地链路中心校验码”可以通过**ADD WEAKPWD**命令配置或通过**LST WEAKPWD**命令查询。

## 参数说明

| 参数标识      | 参数名称         | 参数说明                                                                                                                                                                                                                                                                 |
|:----------|:-------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICENO | 服务模块号        | 可选必选说明：必选参数 参数含义：标识一个DBS链路中心的关键字段，用于指定需要修改哪一个DBS链路中心。操作员可以使用LST DBSLINKCTRL命令查询获得。                                                                                                                                                                                   |
| IPVER     | IP类型         | 可选必选说明：可选参数 参数含义：用于指定IP地址类型。 取值范围： IPV4：当系统要求使用IPv4类型的IP地址时选择此选项。IPV6：当系统要求使用IPv6类型的IP地址时选择此选项。 默认值：无。 配置原则：无                                                                                                                                                        |
| IPV4IP    | 本地链路中心IPV4地址 | 可选必选说明：条件必选参数 参数含义：用于指定IPV4类型的本地IP地址。 该参数必须先由ADD DBSIPADDR命令定义才能在此处引用。 取值范围：IPV4格式的地址。 默认值：无。 配置原则：仅当本命令中的“IP类型”参数设置为“IPV4(IPV4)”时该参数有效。                                                                                                                             |
| IPV6IP    | 本地链路中心IPV6地址 | 可选必选说明：条件必选参数 参数含义：用于指定IPV6类型的本地IP地址。格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如：2001:DB8:8432:4098:4782:5784::。 该参数必须先由ADD DBSIPADDR命令定义才能在此处引用。 取值范围：IPV6格式的地址。 默认值：无。 配置原则：仅当本命令中的“IP类型”参数设置为“IPV6(IPV6)”时该参数有效。                                              |
| PASSWORD  | 本地链路中心校验码    | 可选必选说明：可选参数 参数含义：用于指定本端链路中心的校验码。 取值范围：符合校验码复杂度的字符串。 默认值：无。 配置原则：校验码区分大小写，其复杂度需同时满足下列条件：必须至少包含以下四个类别中的三类：英文大写字母。英文小写字母。数字：0～9。特殊字符：~ ! # % ^ * ( ) _ - + [ ] { } | < > . ?。 不允许使用三个或三个以上连续的字母或数字（例如：ABC、123）。不允许使用三个或三个以上连续的相同字符（例如：AAA）。长度最短8个字符，最长30个字符。第一个字符必须是字母。 |

## 使用实例

修改DBS链路中心的IP地址，“服务模块号”为“52”，“IP类型”为“IPV4”，“本地链路中心IPV4地址”为“192.168.39.32”。命令示例如下：

```
MOD DBSLINKCTRL: SERVICENO=52, IPVER=IPV4, IPV4IP="192.168.39.32";
```
