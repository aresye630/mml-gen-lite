# 激活一次链路迁移操作（ACT LINKMIGRATION）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C、SMF、GGSN**

该命令用于在链路分布不均的场景下激活一次链路迁移，涉及的链路接口类型为Ga/Gx/Gy/S6b。链路迁移策略可以通过调试命令OPR DBGDATA的子命令calseqmigpolicy进行查询。

## 注意事项

- 该命令执行后立即生效。

- 链路迁移时的绑定方式由集中点部署模式决定(SET CONCENPOINT)。
- 对于Ga接口链路，仅在Ga集中点部署模式为SINGLE\_CONNECT时生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                          |
|:--------------|:-------|:------------------------------------------------------------------------------------------------------------------------------|
| LINKINFTYPE   | 链路接口类型 | 可选必选说明：必选参数  参数含义：该参数用于用户指定链路迁移的接口类型。  数据来源：全网规划 取值范围： GX（Gx链路接口类型）GY（Gy链路接口类型）S6B（S6b链路接口类型）GA（Ga链路接口类型）  默认值：无  配置原则：无      |
| MIGRATIONTYPE | 迁移类型   | 可选必选说明：可选参数  参数含义：该参数用于指定链路迁移的迁移类型。  数据来源：本端规划 取值范围： “LOADBALANCE（负载均衡）”：负载均衡“ANTIAFFINITY（反亲和）”：反亲和  默认值：LOADBALANCE  配置原则：无 |

## 使用实例

激活一次Ga接口链路迁移，迁移类型为反亲和：

```
ACT LINKMIGRATION:LINKINFTYPE=GA,MIGRATIONTYPE=ANTIAFFINITY;
```
