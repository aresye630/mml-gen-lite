# 删除Diameter流控节点(RMV DMOC)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于删除Diameter流控节点，根据Diameter流控节点的索引删除节点。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                             |
|:-------|:-------|:---------------------------------------------------------------------------------|
| INDEX  | 索引     | 可选必选说明：必选参数 参数含义：该参数用于指定Diameter流控节点的索引。 数据来源：本端规划 取值范围：整数范围1~1000 默认值： 无 配置原则：无 |

#### 使用实例

删除指定索引的Diameter流控节点：

RMV DMOC: INDEX=1;
