# 查询集中点部署模式（LST UPCONCENPOINT）

- 命令功能
- 注意事项
- 操作用户权限

- 输出结果说明

#### 命令功能

**适用NF：UPF**

此命令用于查询集中点的部署模式。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询集中点部署模式：

```
LST UPCONCENPOINT:;
```

```
RETCODE = 0  操作成功。
集中点信息
----------
 Swm集中点模式  =  本端IP和Diameter对端主机名
(结果个数 = 1)
---    END
```
