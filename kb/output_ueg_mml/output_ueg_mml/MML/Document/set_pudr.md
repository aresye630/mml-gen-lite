# 设置用户数据请求（SET PUDR）

- 注意事项

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响业务处理，需联系华为技术支持确认后再执行。

该命令用于强制刷新用户数据并查询需要强制刷新的用户数据总数。

该命令的使用场景：当PES服务内BLC和NGSRV与UPM的用户数据不一致，导致用户的策略下发异常时，可以执行该命令进行用户数据强制刷新。

## 注意事项

- 当软参“UPM\_SUBCTRL”值为“2”时，不允许强制刷新用户数据。
- 该命令强制查询用户数据只针对本FE在线用户有效。每个FE的受限业务配置是独立的。
- 执行此命令前，请联系华为技术工程师进行指导。
- 对于只有语音会话在线的组成员用户，若语音会话上线时**VRM\_VOLTEQRYSPR**为0，UPCF不查询SPR，只匹配Default动态用户组业务，下发策略信息，随后修改**VRM\_VOLTEQRYSPR**为1执行**SET PUDR**命令，则组成员用户查库后会被强制下线。

## 参数说明

| 参数ID      | 参数名称   | 参数描述                                                                                                                                                                                                                                                                                                                     |
|:----------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBTYPE   | 用户类型   | 可选必选说明：必选参数 参数含义：用于指定用户数据请求命令的用户类型。 取值范围：ALL(所有用户)：表示处理所有用户数据。SINGLE(单个用户)：表示处理指定用户数据。LMTSRVSUB(受限业务用户)：表示处理所有受限业务用户数据。 默认值：无。 配置原则：无。                                                                                                                                                                                   |
| OPERATION | 操作     | 可选必选说明：该参数在“SUBTYPE”配置为“ALL”或“LMTSRVSUB”时为条件必选参数。 参数含义：用于指定用户数据请求命令的操作类型。 取值范围： DISABLE（禁止）：表示所有用户数据不用强制刷新。ENABLE（使能）：表示所有用户数据需要强制刷新。COUNT（统计）: 表示所有用户数据中需要强制刷新的用户个数。 默认值：无。 配置原则：无。  说明： 当“用户类型”为“LMTSRVSUB”时，取值范围不包括“COUNT”。                                                                                           |
| SPEED     | 速度     | 可选必选说明：该参数在“OPERATION”配置为“ENABLE”时为条件可选参数。 参数含义：用于指定用户数据请求命令的速度。 取值范围：NORMAL(正常)：表示每秒处理用户个数为软参“VRM_RARSENDSPEED”值的百分之十。FAST(快速)：表示每秒处理用户个数为软参“VRM_RARSENDSPEED”值的百分之三十。 默认值：NORMAL(正常)。 配置原则：无。  说明： 软参“VRM_RARSENDSPEED”取值为“0”时，用户数据请求命令的速度为20个用户/秒。用户数据请求命令的速度为10的倍数，且最小速度为10个用户/秒。在PES遍历完所有用户数据后，速度自动恢复为“NORMAL(正常)”。 |
| SUBID     | 用户标识   | 可选必选说明：该参数在“SUBTYPE”配置为“SINGLE”时为条件必选参数。 参数含义：用于指定用户数据请求命令的用户标识。 取值范围：长度不超过255的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                       |

## 使用实例

设置强制刷新所有用户数据。“用户类型”为“ALL”，“操作”为“ENABLE”，“速度”为“NORMAL”。

```
SET PUDR: SUBTYPE=ALL, OPERATION=ENABLE, SPEED=NORMAL;
```

操作结果如下：

```
%%SET PUDR: SUBTYPE=ALL, OPERATION=ENABLE, SPEED=NORMAL, CONFIRM=Y;%%
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项解释请参见表1。

| 参数名称   | 参数描述                                                                                                                                                                                                                                                                           |
|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 实例号    | 用于返回服务的实例号。 取值范围：长度不超过256的字符串。                                                                                                                                                                                                                                                 |
| 用户数    | 当“用户类型”为“ALL”时：“操作”为“DISABLE”，表示设置当前PES服务内不需要强制刷新的用户个数。“操作”为“ENABLE”，表示设置当前PES服务内强制刷新的用户个数。“操作”为“COUNT”，表示统计当前PES服务内强制刷新的用户个数。 当“用户类型”为“LMTSRVSUB”时：“操作”为“DISABLE”，表示设置当前PES服务内不需要强制刷新的受限业务用户个数。“操作”为“ENABLE”，表示设置当前PES服务内强制刷新的受限业务用户个数。 当“用户类型”为“SINGLE”时，表示指定用户在PES服务内的处理个数。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释    | 原因分析         | 处理建议                              |
|------:|:---------|:-------------|:----------------------------------|
| 58147 | 未配置受限业务。 | 系统未配置受限业务数据。 | 执行ADD PLMTSRV命令添加受限业务数据，再重新执行本命令。 |
