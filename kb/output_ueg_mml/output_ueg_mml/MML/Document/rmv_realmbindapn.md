# 删除APN与Diameter Realm关联关系（RMV REALMBINDAPN）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于删除APN对应的Diameter域信息，或撤销通过IMSI构造Diameter域信息的方式。

#### 注意事项

该命令执行后只对新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                                                    |
|:------------|:-----------|:----------------------------------------------------------------------------------------------------------------------------------------|
| APN         | APN名称      | 可选必选说明：必选参数 参数含义：该参数用于指定要与Diameter域绑定的APN实例名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：根据实际需要删除绑定关系的APN实例输入对应参数。      |
| APPLICATION | Diameter应用 | 可选必选说明：必选参数 参数含义：该参数用于指定APN绑定Diameter域的Diameter应用类型。 数据来源：对端协商 取值范围：枚举类型。 GY：Gy接口应用。GX：Gx接口应用。S6B：S6b接口应用。 默认值：无 配置原则：根据实际应用场景选择对应的枚举值。 |

#### 使用实例

由于业务变动，APN isp接入的用户不再支持GX应用，则删除APN ISP下Gx应用绑定的Diameter域信息：

```
RMV REALMBINDAPN: APN="isp", APPLICATION=GX;
```
