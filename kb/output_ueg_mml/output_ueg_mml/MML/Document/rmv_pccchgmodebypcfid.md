# 删除基于PCF的计费策略接口类型（RMV PCCCHGMODEBYPCFID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

配置基于PCF的计费策略接口类型不当可能导致PCC用户选择错误接口的PCRF/PCF服务器，进而影响用户使用业务，比如用户无法正常激活。

**适用NF：SMF**

删除基于PCF的计费策略接口类型。

## 注意事项

该命令执行后只对新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                |
|:---------|:--------|:------------------------------------------------------------------------------------------------------------------------------------|
| PCFINSID | PCF实例标识 | 可选必选说明：必选参数  参数含义：字符串唯一标识PCF实例。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。不支持空格，不区分大小写。  默认值：无  配置原则：  PCF实例标识在TOPO本地配置，或者由NRF返回。需要整网协商配置。 |

## 使用实例

删除PCF实例标识为pcf1的计费策略接口类型

```
RMV PCCCHGMODEBYPCFID: PCFINSID="pcf1";
```
