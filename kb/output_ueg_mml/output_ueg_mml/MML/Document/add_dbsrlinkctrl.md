## 命令功能

该命令用于增加远端DSG链路中心。

该命令的使用场景：当BE网元与FE网元使用链路中心方式对接，使用该命令增加远端网元的DSG链路中心。

用户为FE配置远端链路中心时，需要为每个远端Location配置一个远端链路中心。

配置对接通常有以下步骤：

1. 通过**ADD DBSLINKCTRL**命令增加DBS链路中心。
2. 通过**ADD DBSRLOCATION**命令增加远端Location标识。
3. 通过本组命令增加远端DSG链路中心。
4. 通过**SYN DBSRDSG**同步对端DSG信息到本端数据库。
5. 通过**SYN DBSRIPADDR**同步对端IP信息到本端数据库。

在对接双方都经过以上配置之后，通过**ACT DBSIPDISP**命令激活链路，完成对接配置。

DBS链路中心：DBS链路中心负责将自身网元的DBS和IP信息发送到对端局点，同时接收对端局点发送的配置信息。链路中心指定IP，端口号固定为1999。同时配置对端网元的DSG链路中心的IP，链路中心将使用配置的IP和固定端口建立网元间的通讯通道，发送配置信息。

远端Location：远端Location与本端Location是相对的，远端Location和远端网元一一对应。例如，对于主用局USCDB，它的远端Location指主用局FE、容灾局FE、容灾局USCDB的Location。对于容灾局USCDB，它的远端Location指容灾局FE、主用局FE、主用局USCDB的Location。

## 注意事项

- 该命令最多配置512条记录。
- 首先通过**ADD DBSRLOCATION**命令配置远端Location后，才能通过该命令配置远端DSG链路中心。
- 通过“远端链路中心校验码”参数指定的远端链路中心的校验码，必须与在远端网元执行**ADD DSGLINKCTRL**或**MOD DSGLINKCTRL**指定的校验码一致，否则会导致配置消息无法发送到该远端。
- “远端链路中心校验码”不支持查询，如无法获取，可执行**RMV DBSLINKCTRL**删除已存在的本端DBS链路中心，然后执行**ADD DBSLINKCTRL**和**ADD DBSRLINKCTRL**重新设置“本地链路中心校验码”和“远端链路中心校验码”后增加DBS的本端和远端链路中心。
- 本命令配置的“远端链路中心校验码”参数检查在USCDB网元侧进行，禁止配置的“远端链路中心校验码”可以通过**ADD WEAKPWD**命令配置或通过**LST WEAKPWD**命令查询。

## 参数说明

| 参数标识     | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                   |
|:---------|:-------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INDEX    | 配置索引         | 可选必选说明：必选参数 参数含义：用于指定一条远端DSG链路中心配置信息对应的索引。当配置同一“远端Location标识”时，需要配置不同的该索引。 取值范围：1～64 默认值：1 配置原则：无                                                                                                                                                                                      |
| RLOCID   | 远端Location标识 | 可选必选说明：必选参数 参数含义：用于指定一个远端网元标识。当配置同一“配置索引”时，需要配置不同的“远端Location标识”。 取值范围：1～512 默认值：无。 配置原则：该参数须在对接的远端网元中先定义，然后在本端网元通过ADD DBSRLOCATION命令配置后，才能在此处索引。                                                                                                                                      |
| IPVER    | IP类型         | 可选必选说明：必选参数 参数含义：用于指定IP地址类型。 取值范围： IPV4：当系统要求使用IPv4类型的IP地址时选择此选项。IPV6：当系统要求使用IPv6类型的IP地址时选择此选项。 默认值：无。 配置原则：无                                                                                                                                                                          |
| IPV4IP   | 远端链路中心IPV4地址 | 可选必选说明：条件必选参数 参数含义：用于指定远端网元的Location IPv4地址。这个地址必须在对接的远端USCDB网元或者FE网元中已经配置完毕。 取值范围：IPV4格式的地址。 默认值：无。 配置原则：仅当本命令中的“IP类型”参数取值为“IPV4”时该参数有效。  须知： 当FE使用该命令与BE对接时，对于不同业务类型的BE DSG，此参数的取值必须不同。                                                                                              |
| IPV6IP   | 远端链路中心IPV6地址 | 可选必选说明：条件必选参数 参数含义：用于指定远端网元的Location IPv6地址。这个地址必须在对接的远端USCDB网元或者FE网元中已经配置完毕。 IPv6格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如：2001:0DB8:02de:0000:0000:0000:0000:0e13。 取值范围：IPV6格式的地址。 默认值：无。 配置原则：仅当本命令中的“IP类型”参数取值为“IPV6”时该参数有效。  须知： 当FE使用该命令与BE对接时，对于不同业务类型的BE DSG，此参数的取值必须不同。 |
| PASSWORD | 远端链路中心校验码    | 可选必选说明：必选参数 参数含义：用于指定远端链路中心的校验码。 取值范围：符合校验码复杂度的字符串。 默认值：无。 配置原则： 校验码区分大小写，其复杂度需同时满足下列条件必须至少包含以下四个类别中的三类：英文大写字母。英文小写字母。数字：0～9。特殊字符：~ ! # % ^ * ( ) _ - + [ ] { } | < > . ?。 不允许使用三个或三个以上连续的字母或数字（例如：ABC、123）。不允许使用三个或三个以上连续的相同字符（例如：AAA）。长度最短8个字符，最长30个字符。第一个字符必须是字母。                   |
| RDSGST   | 远端DSG业务类型    | 可选必选说明：可选参数 参数含义：用于设置远端DSG网元的业务类型。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：该参数为联想参数列表，不能手动输入，其取值为LST DBSSRVGROUP命令查询获得的“业务类型名称”输出参数。                                                                                                                                                            |

## 使用实例

在开局场景下，增加远端DSG链路中心，“配置索引”为“3”，“远端Location标识”为“77”，“IP类型”为“IPV4”，“远端链路中心IPV4地址”为“172.21.128.24”，“远端链路中心校验码”为“\*\*\*\*\*\*\*\*\*”，“远端DSG业务类型”为“SUP-FE”。命令示例如下：

```
ADD DBSRLINKCTRL: INDEX=3, RLOCID=77, IPVER=IPV4, IPV4IP="172.21.128.24", PASSWORD="*********", RDSGST="SUP-FE";
```

**说明** 

“远端链路中心校验码”使用密码控件，每一个校验码字符在命令行输入区域均显示为“\*”。

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                         | 原因分析                                | 处理建议                                                         |
|-------:|:------------------------------|:------------------------------------|:-------------------------------------------------------------|
| 302531 | 业务分组功能开关打开，请输入正确的业务类型参数。      | 业务分组功能开关打开时，未输入对应的“远端DSG业务类型”。      | 执行LST DBSSRVGROUP命令查询“业务类型名称”，输入查询到的结果，然后重新执行本命令。            |
| 302532 | 输入的业务类型不属于业务分组内，请输入正确的业务类型参数。 | 业务分组功能开关打开时，输入的“远端DSG业务类型”不属于业务分组内。 | 执行LST DBSSRVGROUP命令查询“业务类型名称”，输入查询到的结果，然后重新执行本命令。            |
| 302533 | 分组开关未打开，不能输入与本网元类型不同的业务类型。    | 分组开关未打开，当前网元不支持DBS多应用共存的业务类型。       | 执行LST DBSSRVGROUP命令查询“业务类型名称”，输入与本网元类型相同的“业务类型名称”，然后重新执行本命令。 |
