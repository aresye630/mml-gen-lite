# 增加公共APN NI配置(ADD PUBLICAPNNI)

#### 命令功能

**适用网元：SGSN、MME**

该命令用于配置公用APN NI(Access Point Name Network Identifier)信息，公用APN NI信息在激活请求信息纠正功能时使用。

#### 注意事项

- 该命令执行后立即生效。
- 本表最大记录数为128。
- 关联配置：**ADD SMACTCTRL**用于配置激活请求信息纠正功能涉及到的相关参数。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                                                                                             |
|:-------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APNNI  | APN网络标识 | 可选必选说明：必选参数 参数含义：APN网络标识。 数据来源：整网规划 取值范围：1～62位字符串 默认值：无 配置原则：APN网络标识由一个或多个LABEL构成，各LABEL间用“.”间隔。每个LABEL的构成字符只能是字母A～Z或a～z、数字0～9和中划线“-”，不区分大小写。APN网络标识地址不能以“rac”、“lac”、“sgsn”或“rnc”开头，不能以“.gprs”结尾，不能取值为“*”。  说明： 各记录APN NI字段不能重复。 |

#### 使用实例

配置一条记录，增加APN NI为“cmwap”的APN网络标识为公用APN：

ADD PUBLICAPNNI: APNNI="cmwap";
