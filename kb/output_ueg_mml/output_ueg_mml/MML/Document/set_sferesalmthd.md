# 设置VNRS内部资源不足告警的阈值参数（SET SFERESALMTHD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来设置ALM-231612426 VNRS内部资源不足告警的阈值参数。

#### 注意事项

- 该命令执行后立即生效。

该命令存在系统初始记录，参数的初始设置值如下表：

| RESTYPE       |   TRIGGERTHD |   RESUMETHD |
|:--------------|-------------:|------------:|
| IPv4RecmpNode |           80 |          70 |
| IPv4ReasmNode |           80 |          70 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                                                                          |
|:-----------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------|
| RESTYPE    | 资源类型    | 可选必选说明：必选参数 参数含义：该参数用于指定ALM-231612426 VNRS内部资源不足告警的资源类型。 数据来源：本端规划 取值范围：枚举类型。 IPv4RecmpNode：IPv4分片重排节点。IPv4ReasmNode：IPv4分片重组节点。 默认值：无 配置原则：无 |
| TRIGGERTHD | 触发阈值（%） | 可选必选说明：必选参数 参数含义：该参数用于指定ALM-231612426 VNRS内部资源不足告警的触发阈值。 数据来源：本端规划 取值范围：整数类型，取值范围为2~100。 默认值：无 配置原则：触发阈值（%）必须大于恢复阈值（%）。                       |
| RESUMETHD  | 恢复阈值（%） | 可选必选说明：必选参数 参数含义：该参数用于指定ALM-231612426 VNRS内部资源不足告警的恢复阈值。 数据来源：本端规划 取值范围：整数类型，取值范围为1～99。 默认值：无 配置原则：恢复阈值（%）必须小于触发阈值（%）。                        |

#### 使用实例

```
设置IPv4分片重排节点资源不足导致的ALM-231612426 VNRS内部资源不足告警的阈值参数为触发阈值90%，恢复阈值80%：
SET SFERESALMTHD: RESTYPE=IPv4RecmpNode, TRIGGERTHD=90, RESUMETHD=80;
```
