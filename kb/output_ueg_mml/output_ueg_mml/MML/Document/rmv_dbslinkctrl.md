# 删除DBS链路中心(RMV DBSLINKCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除DBS链路中心。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                         |
|:----------|:-------|:-------------------------------------------------------------------------------------------------------------|
| SERVICENO | 服务模块号  | 可选必选说明：必选参数 参数含义：标识一个DBS链路中心的关键字段，用于指定需要删除哪一个DBS链路中心。操作员可以使用LST DBSLINKCTRL命令查询获得。 取值范围：1～1024 默认值：无。 配置原则：无 |

## 使用实例

删除DBS链路中心，“服务模块号”为“52”。命令示例如下：

```
RMV DBSLINKCTRL: SERVICENO=52;
```
