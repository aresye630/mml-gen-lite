# 增加日志手动控制(ADD LOGCTRL)

## 命令功能

该命令用于手动增加一条PES服务日志的抑制记录。

该命令的使用场景：当PES服务产生的冗余日志过多影响日常维护和问题定位时，可以通过设置该命令，对系统中生成的冗余日志进行抑制，即设置的抑制日志信息不会被输出到日志文件中。

## 注意事项

- 系统最多支持配置20条日志的抑制记录。
- 只对级别为ERROR的日志进行抑制。
- 在升级或服务重启后，系统添加的所有日志抑制记录会失效，需要重新设置。
- 该日志控制功能基于SET PCFLOGSUPPRES配置的自动抑制调整后，再进行冗余日志的过滤和判断。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                |
|:-----------|:-------|:--------------------------------------------------------------------|
| FILENAME   | 文件名    | 可选必选说明：必选参数 参数含义：用于指定需要抑制的日志的文件名。 取值范围：长度不超过64字节的字符串 默认值：无。 配置原则：无。 |
| LINENUMBER | 行号     | 可选必选说明：必选参数 参数含义：用于指定需要抑制的日志所在的行号。 取值范围：1～65535 默认值：无。 配置原则：无。      |

## 使用实例

当系统产生的冗余日志过多影响日常维护和问题定位时，参考日志下载操作步骤下载PES服务运行日志，从运行日志文件中获取到需要抑制的日志的文件名和行号。例如增加日志控制记录，“文件名”为“glbdataloadctrl.cpp”，“行号”为“187”：

```
ADD LOGCTRL: FILENAME="glbdataloadctrl.cpp", LINENUMBER=187;
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。
