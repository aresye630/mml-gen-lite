# 删除重定向配置信息(RMV REDIRECTCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响会话重定向功能。需联系华为技术支持确认后再执行。

该命令用于从配置数据库中删除重定向配置数据记录。

## 注意事项

无。

## 参数说明

| 参数标识             | 参数名称    | 参数说明                                                                                 |
|:-----------------|:--------|:-------------------------------------------------------------------------------------|
| REDIRECTCONFIGID | 重定向配置ID | 标识一条重定向配置记录的关键字段，用于指定需要删除哪一条重定向配置记录。操作员可以使用LST REDIRECTCFG命令查询获得。 取值范围：1～2048 默认值：无。 |

## 使用实例

删除重定向配置记录。“重定向配置ID”为“2”。

```
RMV REDIRECTCFG: REDIRECTCONFIGID=2;
```
