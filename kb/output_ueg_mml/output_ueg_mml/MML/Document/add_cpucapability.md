# 增加CPU能力基线(ADD CPUCAPABILITY)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于添加指定CPU信息所对应的能力基线值，指定CPU信息包含CPU类型、CPU代数以及CPU主频率。

#### 注意事项

CPU类型、CPU代数以及CPU主频这三者的值会确定记录的唯一性，即前后两次如果输入的CPU信息相同，即使能力基线值不一致，也会视为重复记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                            |
|:----------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CPUTYPE         | CPU类型  | 可选必选说明：必选参数。 参数含义：该参数表示CPU类型。当前只支持CPU的类型为x86_64和aarch64，其x86_64为X86机器使用的CPU类型，aarch64为ARM机器使用的CPU类型。 数据来源：本端规划。 取值范围：“x86_64(x86_64) ”“aarch64(aarch64) ” 默认值：无 |
| CPUVERSION      | CPU代数  | 可选必选说明：必选参数 参数含义：该参数表示CPU代数。 数据来源：本端规划 取值范围：字符串形式，区分大小写，字符串长度为1～63。 默认值：无                                                                                       |
| CPUFREQUENCY    | CPU主频  | 可选必选说明：必选参数 参数含义：该参数表示CPU主频率。 数据来源：本端规划 取值范围：整形数值，范围0~65536。 默认值：无                                                                                              |
| CAPABILITY      | 能力基线   | 可选必选说明：必选参数 参数含义：该参数表示CPU对应的能力基线值，能力基线值越大，代表CPU运算能力越大，可承载的业务量越多，反之越小。 数据来源：本端规划 取值范围：整形数值，范围0~65536。 默认值：无                                                      |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。该参数不能取值为VNFP、ACS、VNRS_VNFC的服务实例名称。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。                  |

#### 使用实例

增加CPU类型、主频、代数分别为x86\_64、2100MHz、E5-2690所对应的能力基线值为1000的记录，执行以下命令：

ADD CPUCAPABILITY: CPUTYPE=x86\_64, CPUVERSION="E5-2690", CPUFREQUENCY=2100, CAPABILITY=1000,SERVICEINSTANCE="vnfc";
