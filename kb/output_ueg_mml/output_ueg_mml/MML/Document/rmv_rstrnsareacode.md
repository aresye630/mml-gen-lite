# 删除TA级切片限制区域码（RMV RSTRNSAREACODE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除TA级切片限制区域码。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                        |
|:---------|:-------|:------------------------------------------------------------------------------------------------------------|
| AREACODE | 区域编码   | 可选必选说明：必选参数  参数含义：该参数用于唯一标识AMF服务的某个区域，该区域由一个或者若干个跟踪区组成。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~128。  默认值：无  配置原则：无 |

## 使用实例

删除编码为“jq001.pd006.sh.mcc123.mnc45”的TA级限制切片所属区域编码，执行如下命令：

```
RMV RSTRNSAREACODE:AREACODE="jq001.pd006.sh.mcc123.mnc45";
```
