# 查询SMF拨测用户配置（LST SMFDIALTEST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C、SMF**

该命令用于查询拨测用户配置。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                              |
|:------------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TSTUSRRANGE | 用户标识类型   | 可选必选说明：可选参数  参数含义：该参数用于配置拨测用户类型。  数据来源：本端规划 取值范围： MSISDN（MSISDN）IMSI（IMSI）  默认值：无  配置原则：无                                                                                         |
| BEGINMSISDN | 起始MSISDN | 可选必选说明：该参数在"TSTUSRRANGE"配置为"MSISDN"时为条件可选参数。  参数含义：该参数用于配置拨测用户的起始MSISDN。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~15。只允许输入十进制数字（0-9）。  默认值：无  配置原则：  该参数在“用户标识类型”参数配置为“MSISDN(MSISDN)”后生效。 |
| BEGINIMSI   | 起始IMSI   | 可选必选说明：该参数在"TSTUSRRANGE"配置为"IMSI"时为条件可选参数。  参数含义：该参数用于配置拨测用户的起始IMSI。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是14~15。只允许输入十进制数字（0-9）。  默认值：无  配置原则：  该参数在“用户标识类型”参数配置为“IMSI(IMSI)”后生效。        |

## 使用实例

查询一条拨测用户配置，起始IMSI为460001111111111。

```
%%LST SMFDIALTEST: BEGINIMSI="460001111111111";%%
RETCODE = 0  操作成功。

操作结果如下
-------------------------
      用户标识类型  =  IMSI
        起始MSISDN  =  NULL
        终止MSISDN  =  NULL
          起始IMSI  =  460001111111111
          终止IMSI  =  460001111111112
(结果个数 = 1)
---    END
```
