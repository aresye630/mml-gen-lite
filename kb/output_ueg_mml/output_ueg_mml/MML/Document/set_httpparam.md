# 设置HTTP链路流参数(SET HTTPPARAM)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置HTTP动态链路参数，可以增加和修改链路流参数。在流数目达到最大设置值时，链路会自动重建相同链路，并使用新链路通信。

## 注意事项

- 在动态链路建立后，链路一旦被使用，则链路不会被主动拆除。
- 在对链路流数目进行设置时，只可对前四条链接进行设置。
- 本命令配置只在HLB直连模式下才会生效，即需要通过**MOD UDMSOFTPARA**命令将软参**HttpLink(HTTP链路策略)**置为“0”，通过HLB管理链路，所有的HLB均和对端网元建立动态链路。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                        |
|:-----------|:-------|:----------------------------------------------------------------------------|
| LINKNUM    | 链接数目   | 可选必选说明：必选参数 参数含义：用于标识建立最大动态链路数目。 取值范围：0～255 默认值：2 配置原则：无。                   |
| STREAMNUM1 | 流数目1   | 可选必选说明：可选参数 参数含义：用于标识第一条动态链路最大流数目。 取值范围：0～2147483647 默认值：2147483647 配置原则：无。 |
| STREAMNUM2 | 流数目2   | 可选必选说明：可选参数 参数含义：用于标识第二条动态链路最大流数目。 取值范围：0～2147483647 默认值：2147483647 配置原则：无。 |
| STREAMNUM3 | 流数目3   | 可选必选说明：可选参数 参数含义：用于标识第三条动态链路最大流数目。 取值范围：0～2147483647 默认值：2147483647 配置原则：无。 |
| STREAMNUM4 | 流数目4   | 可选必选说明：可选参数 参数含义：用于标识第四条动态链路最大流数目。 取值范围：0～2147483647 默认值：2147483647 配置原则：无。 |

## 使用实例

在UDM初始配置阶段，设置动态HTTP链路参数，“链路数目”为“2”，“流数目1”为“10”，“流数目2”为“10”，“流数目3”为“10”，“流数目4”为“10”:

```
SET HTTPPARAM: LINKNUM=2, STREAMNUM1=10, STREAMNUM2=10, STREAMNUM3=10, STREAMNUM4=10;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
