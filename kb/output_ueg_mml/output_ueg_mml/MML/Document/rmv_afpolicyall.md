# 删除所有防欺诈策略配置（RMV AFPOLICYALL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，删除所有的防欺诈配置后，功能可能不正常，不要一次性删除所有的防欺诈配置。

该命令用于删除所有判断出欺诈行为后的处理策略。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

无。

#### 使用实例

如果运营商要删除所有在判断出欺诈行为后处理策略，则配置命令如下：

```
RMV AFPOLICYALL:;
```
