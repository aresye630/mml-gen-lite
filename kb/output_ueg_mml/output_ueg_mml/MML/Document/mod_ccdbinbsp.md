# 修改基础软件参数的配置信息（MOD CCDBINBSP）

## 命令功能

**须知** 

该命令属于高危命令，该操作将修改软件基础参数，配置不当，将导致业务严重错误。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对基础软件参数的值进行修改。在该命令中，系统通过参数“基础软件参数名称”和参数“基础软件参数值”的组合来唯一标识一条软件参数配置信息数据记录。

在修改软件参数前，可以通过**LST CCDBINBSP**命令查询系统参数当前值，并参考产品手册的“CCDB软件参数”对软件参数进行配置。

该命令的使用场景：

- 开局场景：开局时根据客户的业务要求及规划，调整业务参数。
- 升级场景：升级场景下按升级指导书要求修改业务参数，以便升级顺利实施。
- 扩容场景：扩容场景下按扩容指导书要求修改业务参数，以便扩容顺利实施。
- 其他维护场景：经过华为技术支持确认的其他维护场景，根据操作指导完成业务参数修改，完成特定的维护操作。

该命令仅用于开局、扩容、升级等工程操作和特殊故障恢复场景。

## 注意事项

- 软件参数值都有特定含义，此命令的修改可能严重影响系统的运行，修改时，请联系华为技术支持处理。
- 在缺省的情况下，系统在初始化时已经预置了软件参数数据表中的全部数据。
- 该命令不允许进行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                   |
|:-------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------|
| INBSPN | 基础软件参数名称 | 可选必选说明：必选参数 标识一条基础软件参数数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪一类基础软件参数名称进行修改或调整。 取值范围：请参考产品手册的“CCDB软件参数”。 默认值：无 配置原则：操作员可以通过LST CCDBINBSP命令查询获得。 |
| INBSPV | 基础软件参数值  | 可选必选说明：必选参数 用于标识需要修改的基础软件参数的参数值。 取值范围：0~4294967295 默认值：无 配置原则：无                                                                        |

## 使用实例

修改基础软件参数，“基础软件参数名称”为“DBSRV\_TVERIFYOPER”，“基础软件参数值”为“3000”。

```
MOD CCDBINBSP: INBSPN=DBSRV_TVERIFYOPER, INBSPV=3000;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
