# 修改算法优先级配置信息(MOD ALGPRIORITY)

#### 命令功能

**适用网元：SGSN**

该命令用于修改算法的优先级。SGSN在给RAN发送算法时会根据算法优先级排序。当**MOD IUAUTHCIPH**命令中加密开关打开后，选择不同的加密算法或完整性算法，系统根据该命令配置的算法优先级对算法进行重排序。如果所有算法均未设置优先级，则为随机顺序。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                |
|:--------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ALGTYPE | 算法类型   | 可选必选说明：必选参数 参数含义：该参数于指定对何种算法设置优先级。目前有加密算法和完整性算法两种类型。 数据来源：整网规划 取值范围：“CIPH(UMTS加密算法)”“INTE(UMTS完整性算法)” 默认值：无                                                                                                                                         |
| ALGCIPH | 加密算法   | 可选必选说明：条件必选参数 参数含义：该参数用于指定加密算法的类型。加密算法是用来保密用户身份，用户数据及信令通道。 前提条件：该参数在“ALGTYPE（算法类型）”设置为“CIPH（UMTS加密算法）”时生效。 数据来源：整网规划 取值范围：“NOCIPH(不加密)”：表示对RNC建立的连接不加密，也可以通过不启动加密算法实现。“UEA1(UEA1)”“UEA2(UEA2)” 默认值：无 配置原则：根据MOD IUAUTHCIPH中加密算法的配置原则，对各加密算法进行优先级配置。 |
| ALGINTE | 完整性算法  | 可选必选说明：条件必选参数 参数含义：该参数用于指定完整性算法类型，只在IU模式下使用。完整性算法是用来保证信令源鉴权数据的完整性。 前提条件：该参数在“ALGTYPE（算法类型）”设置为“INTE（UMTS完整性算法）”时生效。 数据来源：整网规划 取值范围：“UIA1(UIA1)”“UIA2(UIA2)” 默认值：无 配置原则：根据MOD IUAUTHCIPH中完整性算法的配置原则，对各完整性算法进行优先级配置。                                  |
| ALGPRI  | 算法优先级  | 可选必选说明：条件可选参数 参数含义：该参数用于设置所选择算法的优先级。 前提条件：该参数在“ALGTYPE（算法类型）”设置为“INTE（UMTS完整性算法）”或“CIPH（UMTS加密算法）”时生效。 数据来源：整网规划 取值范围：0～255 默认值：无 配置原则：数值越小，优先级越高。同一种算法类型下（加密或者完整性），算法的优先级值不能相同且算法唯一。                                                               |

#### 使用实例

场景描述：SGSN已配置的加密算法UEA1级别为2，NOCIPH级别为8。如果希望不加密，则可以通过配置NOCIPH优先级为1，高于UIA1实现。

修改算法类型为加密算法，算法为不加密的优先级为1：

MOD ALGPRIORITY: ALGTYPE=CIPH, ALGCIPH=NOCIPH, ALGPRI=1;
