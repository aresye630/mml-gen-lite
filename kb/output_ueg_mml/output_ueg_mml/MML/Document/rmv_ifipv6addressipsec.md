# 删除接口IPv6地址（RMV IFIPV6ADDRESSIPSEC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除接口的IPv6地址，包括逻辑接口及物理接口。

## 注意事项

- 该命令执行后立即生效。

- 该命令可以在VNRS\_VNFC的Ethernet接口，Ethernet子接口，Eth-Trunk接口，Eth-Trunk子接口以及Loopback口，Tunnel口上配置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                                                                       |
|:--------------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| IFNAME        | 接口名      | 可选必选说明：必选参数  参数含义：该参数用于指定需要配置IP地址的接口名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。接口名称由接口类型+接口编号组成。  默认值：无  配置原则：  请使用LST INTERFACEIPSEC命令查看可用接口。 |
| IFIP6ADDR     | IPv6地址   | 可选必选说明：必选参数  参数含义：该参数用于指定需要配置的接口IP地址。  数据来源：本端规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无                                                            |
| ADDRPREFIXLEN | IPv6地址前缀 | 可选必选说明：可选参数  参数含义：该参数用于指定需要配置的接口IPv6地址的网络掩码。  数据来源：本端规划  取值范围：整数类型，取值范围是1~128。  默认值：无  配置原则：无                                              |
| ADDRTYPE      | IPv6地址类型 | 可选必选说明：可选参数  参数含义：地址类型。  数据来源：本端规划 取值范围： Global（Global地址）LinkLocal（链路本地地址）Anycast（任播地址）  默认值：无  配置原则：无                                     |

## 使用实例

删除LoopBack4接口上配置的地址：

```
RMV IFIPV6ADDRESSIPSEC: IFNAME="LoopBack4",IFIP6ADDR="fc00:0000:0000:0000:0000:0000:0000:0000",ADDRPREFIXLEN=128;
```
