# 删除用户模板和规则的绑定关系（RMV CPRULEBINDING）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于删除用户模板与规则的绑定关系。当运营商希望删除用户模板与规则的绑定关系时，则配置该命令。如果不输入规则名称，表示删除该用户模板名称对应的用户模板下所有的规则与用户模板绑定关系。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

假如运营商需要删除名称为用户模板名称为userprofile和规则的绑定关系：

```
RMV CPRULEBINDING: USERPROFILENAME="userprofile";
```
