# 查询PEER与PREALMRT关联关系（LST PREALMPEERREL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于系统按照路由标识来查询“对端标识”与“路由标识”的关联关系；若不输入，则表示所有的“对端标识”与“路由标识”的关联关系。

- 如果需要查询全部“对端标识”与“路由标识”的关联关系，请不要输入任何参数。
- 如果需要查询某个路由标识的“对端标识”与“路由标识”关联关系，请依据参数说明输入查询条件。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                               |
|:-------|:-------|:-----------------------------------|
| RID    | 路由标识   | 用于标识域路由。 取值范围：0～29 默认值：无。          |
| PEERID | 对端标识   | 用于标识Diameter对端实体。 取值范围：0～15 默认值：无。 |

## 使用实例

1. 查询所有“对端标识”与“路由标识”关联关系。

   ```
   LST PREALMPEERREL:;
   ```

   ```
   %%LST PREALMPEERREL:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
    路由标识  对端标识  是否为Master对端

    0         1         False           
    0         0         True            
    1         0         True            
    1         1         False           
   (结果个数 = 4)

   ---    END
   ```
2. 查询指定路由标识的“对端标识”与“路由标识”关联关系。“路由标识”为“1”。

   ```
   LST PREALMPEERREL: RID=1;
   ```

   ```
   %%LST PREALMPEERREL: RID=1;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
    路由标识  对端标识  是否为Master对端

    1         0         True            
    1         1         False           
   (结果个数 = 2)

   ---    END
   ```
