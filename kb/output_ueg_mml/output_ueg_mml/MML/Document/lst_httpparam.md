# 查询HTTP链路流参数(LST HTTPPARAM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询设置的HTTP动态链路参数。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询设置的HTTP动态链路参数。

```
LST HTTPPARAM:;
```

```
%%LST HTTPPARAM:;%%
RETCODE = 0  操作成功

链接数目  =  8
 流数目1  =  2147483647
 流数目2  =  2147483647
 流数目3  =  2147483647
 流数目4  =  2147483647
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET HTTPPARAM**命令的参数说明。
