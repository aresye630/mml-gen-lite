# 增加APN粒度的智家随行会话控制（ADD APNTOHCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于增加APN粒度的智家随行会话控制。

## 注意事项

- 该命令执行后只对新激活用户生效。

- 最多可输入20000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                                                                                                                  |
|:-------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN    | APN      | 可选必选说明：必选参数  参数含义：该参数用于指定智家随行会话的APN实例名。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无  配置原则：  该参数使用ADD CPAPN命令配置生成。 |
| TOHSW  | 智家随行会话开关 | 可选必选说明：可选参数  参数含义：该参数用于控制SMF是否支持建立智家随行会话。  数据来源：本端规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无  配置原则：  如果不配置该参数，默认为不使能。  优先级高于整机配置SET SMFFUNC中的NGLANSWITCH字段。                                                                               |
| FWASW  | FWA开关    | 可选必选说明：可选参数  参数含义：该参数用于控制SMF是否支持建立智家随行场景下的FWA会话。  数据来源：本端规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无  配置原则：无                                                                                                                               |

## 使用实例

增加APN粒度的智家随行会话控制，APN名称为“toh.apn”，智家随行会话开关为“使能”，FWA开关为“使能”。

```
ADD APNTOHCTRL: APN="toh.apn",TOHSW=ENABLE,FWASW=ENABLE;
```
