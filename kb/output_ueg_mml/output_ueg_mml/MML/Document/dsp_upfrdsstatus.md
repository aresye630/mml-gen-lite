# 显示UPF中转Radius状态（DSP UPFRDSSTATUS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于查看UPF中转Radius状态。当前最多支持显示100条记录。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                         |
|:------------|:--------|:-----------------------------------------------------------------------------------------------------------------------------|
| AAATYPE     | AAA类型   | 可选必选说明：可选参数  参数含义：该参数用于指定AAA类型。  数据来源：本端规划 取值范围： “AUTHENTICATION（AAA鉴权）”：表示AAA鉴权。“ACCOUNTING（AAA计费）”：表示AAA计费。  默认值：无  配置原则：无 |
| UPFINSTANCE | UPF实例名称 | 可选必选说明：可选参数  参数含义：该参数用于指定UPF实例名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~36。  默认值：无  配置原则：无                                         |

## 使用实例

显示UPF中转Radius状态。

```
%%DSP UPFRDSSTATUS:;%%
RETCODE = 0  操作成功

结果如下
------------------------
AAA类型        UPF实例名称      UPF中转Radius状态

AAA鉴权        upf_instance_1   异常
AAA计费        upf_instance_2   异常
(结果个数 = 2)

---    END
```

## 输出结果说明

| 输出项名称         | 输出项解释                                                                            |
|:--------------|:---------------------------------------------------------------------------------|
| AAA类型         | 该参数用于指定AAA类型。 取值说明： “AUTHENTICATION（AAA鉴权）”：表示AAA鉴权。“ACCOUNTING（AAA计费）”：表示AAA计费。 |
| UPF实例名称       | 该参数用于指定UPF实例名称。                                                                  |
| UPF中转Radius状态 | 该参数用于指定UPF中转Radius状态。 取值说明： “ABNORMAL（异常）”：表示状态异常。“NORMAL（正常）”：表示状态正常。           |
