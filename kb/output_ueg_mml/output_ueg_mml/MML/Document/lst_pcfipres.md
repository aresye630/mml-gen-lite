# 查询PCF业务IP资源(LST PCFIPRES)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询业务IP资源信息。

该命令的使用场景：当北向IP资源上报异常时，可通过执行该命令查询系统当前配置的“接口类型”。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询当前系统中所有业务IP资源信息。

```
LST PCFIPRES:;
```

```
%%LST PCFIPRES:;%%
RETCODE = 0  操作成功

操作结果如下:
-------------
接口类型   

Gx_PCF          
Gx_PCRF         
Mgt             
N15             
N28             
N5              
N7              
Rx_PCF          
Rx_PCRF         
Sy
(结果个数 = 10)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义参见表1。

| 输出项名称   | 输出项解释             |
|:--------|:------------------|
| 接口类型    | 用于返回当前系统中配置的接口类型。 |
