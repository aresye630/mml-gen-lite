# 增加PCRF对端PCEF实体(ADD PPCEF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条对端PCEF实体数据记录。在该命令中，“对端域名”、“对端主机名”（必须全网唯一，由局方统一规划这个数据）、“协议类型”、“共享密钥”、“确认共享密钥”、“链路选择模式”、“业务绑定模式”和“业务保活时长”参数的配置需要与对端网元PCEF协商一致。

## 注意事项

当“链路选择模式”为“SINGLE\_LINK(独立链路)”时，“业务绑定模式”不能为“SHARE(共享)”。

## 参数说明

| 参数标识          | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                      |
|:--------------|:------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PCRFID        | PCRF标识      | 用于标识PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围： 1 默认值： 无。                                                                                                                                                                                                                                 |
| PCEFID        | 对端PCEF标识    | 用于在UPCF的配置库中定义一个对端PCEF实体。该参数的配置原则：如果配置多个对端PCEF实体，从0开始顺序配置。实际可配置的最大值受系统软参VRM_MAXPCEFNUM的限制，系统当前值可通过LST PCFINSP命令进行查询，具体软参功能及使用方法请参见《UPCF软件参数》。 取值范围： 0～1023 默认值： 无。                                                                                                                        |
| PN            | 对端名称        | 用于具体描述一个对端PCEF的名称，以便于识别。其值域类型为字符串，区分大小写。 取值范围： 长度不超过128的字符串 默认值： 无。                                                                                                                                                                                                                       |
| PT            | 协议类型        | PCRF与对端PCEF产品对接的参数之一，用于定义产品间使用的通信协议，需要PCRF与对端PCEF协商一致；若不一致，可能会导致两者之间的连接无法正常建立。 取值说明：DIAMETER(Diameter协议) 默认值： 无。                                                                                                                                                                          |
| DN            | 对端域名        | 仅当本命令中的“协议类型”参数取值为“DIAMETER”时，该参数才显示且为必选参数。 PCRF与对端PCEF产品对接的参数之一，用于指定对端PCEF域名，需要与对端PCEF协商一致。该参数在配置时区分大小写，在查询时不区分大小写。 取值范围： 长度不超过64的字符串 默认值： 无。                                                                                                                                            |
| HN            | 对端主机名       | PCRF与对端PCEF产品对接的参数之一（必须全网唯一，由局方统一规划这个数据），用于定义对端PCEF的主机名称，需要PCRF与PCEF协商一致。该参数在配置时不区分大小写，在查询时区分大小写。 取值范围： 长度不超过127的字符串 默认值： 无。                                                                                                                                                              |
| LSMODE        | 链路选择模式      | PCRF与对端PCEF产品对接的参数之一，用于定义链路选择模式，是PCRF往PCEF发送数据走哪条链路的重要依据。链路选择模式有两种类型。 独立链路：某次会话的消息只能走一个固定的链路，一旦该链路中断，会话消息就无法发送到对端； 负载均衡：循环使用所有到对端的在线链路； 取值说明： SINGLE_LINK(独立链路)LOAD_BALANCE(负载均衡) 默认值： LOAD_BALANCE(负载均衡)                                                                                 |
| SBMODE        | 业务绑定模式      | PCRF与对端PCEF产品对接的参数之一，用于定义业务绑定模式。业务绑定模式主要影响链路状态改变时链路所承载的业务的处理。业务绑定模式有以下两种： 独立模式：连接绑定业务，连接不可用时需要释放业务； 共享模式：对端绑定业务，对端的所有连接都不可用时才释放业务。 该参数需要PCRF与PCEF协商一致；若不一致，可能会导致两者之间的业务交互异常。 取值说明： SINGLE(独立)SHARE(共享) 默认值： SHARE(共享)                                                                     |
| SKA           | 业务保活时长 （s）  | 仅当本命令中的“协议类型”参数取值为“DIAMETER”时，该参数才显示且为可选参数。 PCRF与对端PCEF产品对接的参数之一，用于定义业务保活时间，当链路不可用时，在业务保活时间内，业务是不会释放的，需要PCRF与对端PCEF协商一致；若不一致，可能会导致两者之间的控制块不一致，业务异常。如果对端PCEF的业务保活时长为0，将导致该对端上的现有业务会中断。 建议修改业务保活时长为90秒。 单位：秒。 取值范围： 0～3600 默认值： 90  说明： 若软参“VRM_SESSIONBACKUPSWITCH”取值为非0，则该参数不生效。          |
| DASWITCH      | 审计开关        | PCRF与对端PCEF产品对接的参数之一，用于定义设备间的审计开关，如果需要进行设备间审计，则需要置审计开关为ON，不需要进行设备间审计，则需要置审计开关为OFF。审计开关建议关闭。 取值说明： OFF(关闭定时审计)ON(打开定时审计) 默认值：无。  说明： 当“审计开关”设置为“ON”时： 当软参“VRM_DEVAUDITSTARTTIME”取值为“5”时，表示系统对创建时间未超过5分钟的会话不发起设备间审计。当软参“VRM_DEVAUDITSTARTTIME”取值为“X（5＜X≤1440）”时，表示系统对更新时间未超过X分钟的会话不发起设备间审计。 |
| DATIME        | 设备间审计时长 （m） | PCRF与对端PCEF产品对接的参数之一，用于定义设备间的审计的时长。当设备间审计开关为ON时，需要输入设备间审计时长。 单位：分钟。 取值范围： 720～1440 默认值： 无。                                                                                                                                                                                                |
| ABILITYDICTID | 能力字典ID      | 仅当本命令中“协议类型”参数取值为“DIAMETER”时，该参数才显示且为必选参数。 该参数用于选择PCEF能力字典。 取值范围：0～127 取值说明：能力字典ID的具体取值由ADD PCEFABIDICT命令定义。 默认值： 无                                                                                                                                                                       |
| PCEFCAT       | 对端PCEF类别    | 对端PCEF实体的类别，只在多PCEF场景下使用。 取值说明：由ADD PPCEFCAT命令定义的PCRF对端PCEF类别。 默认值：无。                                                                                                                                                                                                                     |
| PPCEFGROUP    | 对端PCEF组     | 对端PCEF的组信息，可用于多PCEF场景下的PCEF分组。 取值说明：NULL(NULL)Group1(Group1)～Group64(Group64) 默认值：无。                                                                                                                                                                                                      |
| CUSTOMATTR    | 自定义属性       | 用于具体描述一个对端PCEF的自定义属性，以便于扩展。其值域类型为字符串，区分大小写。 取值范围：长度不超过32的字符串。 默认值：无。                                                                                                                                                                                                                      |

## 使用实例

1. 增加PCRF对端PCEF实体。“PCRF实体标识”为“1”，“对端PCEF实体标识”为“0”，“对端PCEF实体名称”为“PCEF0”，“协议类型”为“DIAMETER”，“对端PCEF实体域名”为“PCEF0domain”，“对端PCEF实体主机名”为“PCEF0host”，“审计开关”为“ON”，“设备间审计时长”为“720”，“能力字典ID”为“64”，其他参数均使用缺省值。

   ```
   ADD PPCEF: PCRFID=1, PCEFID=0, PN="PCEF0",PT=DIAMETER, DN="PCEF0domain", HN="PCEF0host",DASWITCH=ON, DATIME=720, ABILITYDICTID=64,PCEFCAT="GGSN", PPCEFGROUP=NULL;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释            | 原因分析                    | 处理建议                           |
|------:|:-----------------|:------------------------|:-------------------------------|
| 57321 | 无效参数：密码不满足复杂度要求。 | “共享密钥”未按参数说明中的配置原则输入取值。 | 请根据参数说明中的配置原则，重新输入参数取值后，再执行命令。 |
