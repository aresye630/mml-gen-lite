# 查询Gx UPF组（LST GXUPFGROUP）

#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

该命令用来查看指定Gx Upf组或者已配置所有Gx Upf组的配置信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                                                                                      |
|:-----------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
| UPFGRPNAME | Gx UPF组名称 | 可选必选说明：可选参数 参数含义：该参数用于指定UPF组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。不支持空格及特殊字符“#”、“$”和“&”等，由“_”、“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

查看所有GxUpfGroup配置：

```
LST GXUPFGROUP:;
```

```

```
