# 删除PCRF对端AF实体(RMV PAF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致相关业务中断，请联系华为技术支持确认后再执行。

该命令为配置类命令，用于从配置数据库中删除一条对端AF实体数据记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                      |
|:-------|:-------|:--------------------------------------------------------------------------|
| PCRFID | PCRF标识 | 用于指定一个本端PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围： 1 默认值： 无。             |
| AFID   | 对端AF标识 | 用于在UPCF的配置库中定义一个对端AF实体。该参数的配置原则：如果配置多个对端AF实体，从0开始顺序配置。 取值范围： 0-15 默认值： 无。 |

## 使用实例

删除PCRF对端AF实体。PCRF实体标识为1，对端AF实体标识为0。

```
RMV PAF: PCRFID=1, AFID=0;
```
