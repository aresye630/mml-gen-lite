# 增加PCRF对端AF能力字典(ADD AFABIDICT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条对端AF实体能力字典记录。UPCF在与AF对接时，需要在UPCF内部为AF指定一个能力字典，并将按照该能力字典对应的能力项进行相应的业务处理。

## 注意事项

系统缺省情况下仅有32条默认记录，能力字典ID为0时能力项设置当前Rx能力，能力字典ID为1时能力项设置PEF作为AF的Rx能力，2～31为预留默认值与能力字典ID为0一样。

## 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                      |
|:----------------|:-------|:--------------------------------------------------------------------------|
| ABILITYDICTID   | 能力字典ID | 用于标识AF能力字典的编号。 取值范围： 0～127，其中0～31是系统预置字典，不允许重复添加，因此建议该参数取值为32～127。 默认值： 无 |
| ABILITYDICTNAME | 能力字典名  | 用于具体描述一个AF能力字典的名称，以便于识别。其值域类型为字符串，不区分大小写。 取值范围： 长度不超过32的字符串。 默认值： 无       |

## 使用实例

增加一条AF能力字典。“能力字典ID”为“68”，“能力字典名”为“HUAWEI5”。

```
ADD AFABIDICT: ABILITYDICTID=68, ABILITYDICTNAME="HUAWEI5";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释            | 原因分析            | 处理建议                                                                             |
|------:|:-----------------|:----------------|:---------------------------------------------------------------------------------|
| 53001 | 对象已存在，不能增加相同的对象。 | 输入的“能力字典ID”已存在。 | 执行LST AFABIDICT命令查询已存在的能力字典ID，再执行本命令重新输入参数“能力字典ID”的取值，确保已输入的取值和已存在的能力字典ID的取值不相同。 |
