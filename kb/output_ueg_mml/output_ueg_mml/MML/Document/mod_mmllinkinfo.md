# 修改MML连接信息（MOD MMLLINKINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

用于修改MMLService直连通道的配置参数信息。

#### 注意事项

无。

#### 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                            |
|:------------|:----------|:----------------------------------------------------------------------------------------------------------------|
| LINKPORT    | 连接端口号     | 可选必选说明：必选参数 参数含义：MMLService直连通道的侦听端口号。 取值范围：8990～9000。 默认值：9000。 配置原则：该参数为用户指定需要配置的直连端口号。                       |
| LINKNUM     | 并发连接数     | 可选必选说明：必选参数 参数含义：MMLService直连通道的并发连接数，表示MMLService最大支持的并发直连数量。 取值范围：4～25。 默认值：16。 配置原则：配置参数值应大于等于实际需要的直连并发连接数量。 |
| LINKTIMEOUT | 连接超时时间（分） | 可选必选说明：必选参数 参数含义：MMLService直连通道的超时时间，连接建立后若在该指定超时时间内无数据交互，则连接断开。 取值范围：5～40。 默认值：5。 配置原则：无。                      |

#### 使用实例

修改MMLService连接信息，修改连接端口号为9000，修改并发连接数为16，修改连接超时时间为5分钟：

```
%%MOD MMLLINKINFO: LINKPORT=9000, LINKNUM=16, LINKTIMEOUT=5;%%
RETCODE = 0  操作成功

---    END
```

#### 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，请联系华为技术支持处理。输出结果说明如表1所示。
