# 删除APN配置（RMV APNPROFILE）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用于删除APN的APN的概要信息。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                  |
|:-------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APNNI  | APN网络标识 | 可选必选说明：必选参数 参数含义：该参数用于指定APN网络标识。 数据来源：整网规划 取值范围：1~62位字符串 默认值： 无 配置原则：APN网络标识地址由一个或多个LABEL构成，各LABEL间用“.”间隔。每个LABEL的构成字符只能是字母A～Z或a～z、数字0～9和中划线“-”。APN网络标识地址不能以“rac”、“lac”、“sgsn”或“rnc”开头，不能以“.gprs”结尾。 说明： APN网络标识不区分大小写。APNNI在APN中所处的位置，例如：example1.com.mnc123.mcc123.gprs，其中NI= example1.com， OI= mnc123.mcc123.gprs。 |

#### 使用实例

删除一条APNNI的概要配置，APNNI为INTERNET，可以用如下命令：

```
RMV APNPROFILE: APNNI="INTERNET";
```
