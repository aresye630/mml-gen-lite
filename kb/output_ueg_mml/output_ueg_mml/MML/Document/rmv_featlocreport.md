# 删除基于特性的位置上报配置（RMV FEATLOCREPORT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于删除基于特性的位置上报配置。

## 注意事项

随流程生效

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                        |
|:--------|:-------|:----------------------------------------------------------------------------|
| FEATURE | 特性名称   | 可选必选说明：必选参数  参数含义：该参数用于指定特性名称。  数据来源：本端规划 取值范围： QOSANA（质差分析）  默认值：无  配置原则：无 |

## 使用实例

删除“FEATURE”为“QOSANA”的位置上报配置：

```
RMV FEATLOCREPORT:FEATURE=QOSANA;
```
