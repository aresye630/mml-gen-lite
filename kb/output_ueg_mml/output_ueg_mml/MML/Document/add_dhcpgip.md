# 增加支持DHCP服务的GGSN IP地址（ADD DHCPGIP）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

1. 该命令用于增加支持DHCP服务的GGSN IP地址。
2. SGSN支持用户采用DHCP方式接入，在采用DHCP接入方式时，不需要对APN进行DNS解析，只需要在SGSN中配置支持DHCP服务的GGSN IP地址即可。

#### 注意事项

- 该命令执行后立即生效。
- 最多可以输入4条记录。
- 输入的IP地址不允许与已有的记录重复。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称        | 参数说明                                                                                                                                                                                                                     |
|:-------|:------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPT    | IP地址类型      | 可选必选说明：可选参数 参数含义：该参数用于指定IP地址类型。 数据来源：整网规划 取值范围： “IPV4(IPV4)”、“IPV6(IPV6)”、“IPV4V6(IPV4V6)” 默认值： “IPV4(IPV4)”                                                                                                             |
| IPV4   | GGSN IPv4地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定GGSN IPv4地址。 数据来源：整网规划 取值范围：0.0.0.0～255.255.255.255 默认值： 无。 配置原则：有效的IPv4地址不能为 0.0.0.0,255.255.255.255，或0.x.y.z。有效的IPv4地址不能为环回地址(127.x.y.z)，或组播地址(224.x.y.z)。有效的IPv4地址必须是A、B或者C类地址。             |
| IPV6   | GGSN IPv6地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定GGSN IPv6地址。 数据来源：整网规划 取值范围：::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值： 无。 配置原则：IPv6地址必须是全球单播地址，不能为::、 FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址(::1)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。 |
| DESC   | 描述          | 可选必选说明：可选参数 参数含义：该参数用于增加配置命令的描述信息。 数据来源：整网规划 取值范围：0~32位字符串 默认值：无                                                                                                                                                         |

#### 使用实例

1. 增加一个支持DHCP服务的GGSN IPv4地址“192.168.22.22”：

   **ADD DHCPGIP: IPT=IPV4, IPV4="192.168.22.22";**
