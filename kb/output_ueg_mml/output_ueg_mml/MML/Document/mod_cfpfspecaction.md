# 修改指定内容过滤策略特殊场景下的业务动作（MOD CFPFSPECACTION）

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于修改指定内容分类，指定内容分类套餐策略包括默认策略，错误策略和未知策略。

#### 注意事项

- 该命令执行后立即生效。
- 默认策略适用场景：ICAP响应消息中携带的分类信息有效，且无对应ContentCate配置。
- 错误策略适用场景：ICAP响应码数值不等于200\201\202。
- 未知策略适用场景：ICAP响应消息没有携带分类信息，或者分类值为空。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

修改一条指定内容分类配置：

```
MOD CFPFSPECACTION: CFPROFILENAME="profile1_test", DEFACTION=BLOCK;
```
