#### 命令功能

**适用网元：SGSN**

该命令用于查看各个节点上的资源使用情况。

#### 注意事项

无

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                  |
|:-------|:-------|:----------------------------------------------------------------------|
| RUNAME | RU名称   | 可选必选说明：可选参数 参数含义：该参数用于指定资源单元名称。该参数可以通过DSP RU命令查询。 取值范围：1~63位字符串 默认值：无 |
| PN     | 进程号    | 可选必选说明：可选参数 参数含义：该参数用于指定UPP进程的序号。 取值范围：0~20 默认值：无                     |

#### 使用实例

查询资源单元为USN\_SP\_RU\_0066上0号UPP进程的资源使用情况：

DSP PFRES: RUNAME="USN\_SP\_RU\_0066", PN=0;

```

RETCODE = 0  操作成功。
```

| QoS3类业务用户数            | 交互类业务用户数。                                                                                                                                                                                                                                                                                                                       |
| QoS4类业务用户数            | 背景类业务用户数。                                                                                                                                                                                                                                                                                                                       |
| PDP数状态                | PDP上下文表的使用状态。 取值说明： 正常忙过载拥塞  说明： 正常：PDP数小于忙门限时的状态。忙：PDP数大于等于忙门限，小于过载门限时的状态。过载：PDP数大于等于过载门限，小于拥塞门限时的状态。拥塞：PDP数大于等于拥塞门限时的状态。过载和拥塞门限可以通过命令LST USRPDPCAP获得。 忙门限计算方法：如果过载恢复门限>20，忙恢复门限=过载恢复门限-10。 否则，忙恢复门限=过载恢复门限/2。（如果过载恢复门限设置为1，则忙恢复门限为0，此时将无法恢复成正常状态。） 如果过载门限>20，忙门限=过载门限-10。 否则，忙门限=过载门限/2。 （忙恢复门限大于0的情况下，如果忙门限等于忙恢复门限，则把忙门限加1。） |

| 包转发速率(Packets/s)      | SPU当前的包转发速率。                                                                                                                                                                                                                                                                                                                    |
