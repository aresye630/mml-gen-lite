# 增加网元号段信息(ADD NFRANGEINFO)

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致用户路由异常，影响业务处理，需联系华为技术支持确认后再执行。

该命令用于增加本端网元配置处理的号段信息。该命令可用于指定服务注册信息NFProfile中的pcfInfo的supiRanges，当系统向NRF发起服务注册时使用此数据。

该命令的参数索引关系如图1所示。

**图1** 命令参数的索引关系图

## 注意事项

- 至少指定“开始”和“结束”参数、或“模式”参数之一。
- 相同“组名称”，“号段类型”必须相同。
- 单个PCF实例最多支持40960个号段，UPCF网元内的所有PCF实例总计支持40960个号段。
- 添加数据成功，如果指定“组名称”已在**ADD NFINFO**的“SUPI号段组”或“GPSI号段组”中引用，且**ADD NFINFO**的“网元信息标识”在**ADD NFSRV**命令的“网元信息标识”中引用，且**ADD NFSRV**命令中的“网元状态”为“REGISTERED”时，将按照**ADD NFSRV**命令中“更新方式”参数中指定的更新模式60秒内向NRF发送Nnrf\_NFManagement\_NFUpdate Request消息请求更新。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                  |
|:-----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GRPNAME    | 组名称    | 可选必选说明：必选参数 参数含义：用于标识本端网元号段信息所属组的信息，该参数由本端自定义。 取值范围：长度不超过32的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则： 若该“组名称”不存在，则创建该组名称。同一个“组名称”内，可以分多次加入不同的号段，但每次加入号段时索引不能重复。同一个“组名称”内，支持不同号段间的重叠。 |
| INDEX      | 索引     | 可选必选说明：必选参数 参数含义：用于标识本端网元号段信息数据记录的关键字段。 取值范围：1~40960。 默认值：无。 配置原则：无。                                                                                                                  |
| RANGETYPE  | 号段类型   | 可选必选说明：必选参数 参数含义：用于标识本端网元号段信息的类型。 取值范围： SUPI(用户永久标识)GPSI(通用公共用户标识) 默认值：无。 配置原则：无。                                                                                                     |
| STARTVALUE | 开始     | 可选必选说明：可选参数 参数含义：用于指定号段的开始值。 取值范围：5~15位的十进制数字组成的字符串。 默认值：无。 配置原则：该参数与“结束”参数配置后，不能与“模式”参数同时配置，如已配置“开始”、“结束”参数，则无需再配置“模式”参数。                                                            |
| ENDVALUE   | 结束     | 可选必选说明：可选参数 参数含义：用于指定号段的结束值。 取值范围：5~15位的十进制数字组成的字符串。 默认值：无。 配置原则：该参数与“开始”参数配置后，不能与“模式”参数同时配置，如已配置“开始”、“结束”参数，则无需再配置“模式”参数。                                                            |
| PATTERN    | 模式     | 可选必选说明：可选参数 参数含义：用于指定号段的正则表达式。 取值范围：长度不超过128的字符串 默认值：无。 配置原则：该参数与“开始”、“结束”参数不能同时配置，如已配置“开始”、“结束”参数，则无需再配置本参数。                                                                         |

## 使用实例

1. 增加一个网元号段信息，使用“开始”和“结束”参数。“组名称”为“supi-group-01”，“索引”为“1”，“号段类型”为“SUPI”，“开始”为“460020291210000”，“结束”为“460020291220000”：

   ```
   ADD NFRANGEINFO: GRPNAME="supi-group-01", INDEX=1, RANGETYPE=SUPI, STARTVALUE="460020291210000", ENDVALUE="460020291220000";
   ```
2. 增加一个网元号段信息，使用“模式”参数。“组名称”为“supi-group-02”，“索引”为“1”，“号段类型”为“SUPI”，“模式”为“^imsi-46002029122[0-9]{4}$”：

   ```
   ADD NFRANGEINFO: GRPNAME="supi-group-02", INDEX=1, RANGETYPE=SUPI, PATTERN="^imsi-46002029122[0-9]{4}$";
   ```
3. 在“组名称”为“supi-group-01”里再添加一个号段。“组名称”为“supi-group-01”，“索引”为“2”，“号段类型”为“SUPI”，“开始”为“460020291220000”，“结束”为“460020291225000”：

   ```
   ADD NFRANGEINFO: GRPNAME="supi-group-01", INDEX=2, RANGETYPE=SUPI, STARTVALUE="460020291220000", ENDVALUE="460020291225000";
   ```
4. 在“组名称”为“supi-group-01”里再添加一个号段，此号段信息和实例3里的号段有重叠。“组名称”为“supi-group-01”，“索引”为“3”，“号段类型”为“SUPI”，“开始”为“460020291220000”，“结束”为“460020291229999”：

   ```
   ADD NFRANGEINFO: GRPNAME="supi-group-01", INDEX=3, RANGETYPE=SUPI, STARTVALUE="460020291220000", ENDVALUE="460020291229999";
   ```
5. 增加一个“号段类型”为“GPSI”的网元号段信息，使用“开始”和“结束”参数。“组名称”为“gpsi-group-01”，“索引”为“1”，“号段类型”为“GPSI”，“开始”为“86139”，“结束”为“86199”：

   ```
   ADD NFRANGEINFO: GRPNAME="gpsi-group-01", INDEX=1, RANGETYPE=GPSI, STARTVALUE="86139", ENDVALUE="86199";
   ```
