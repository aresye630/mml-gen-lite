# 查询MEP HTTP客户端通信参数（LST MEPCLIENTCOMMPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF、MPF**

该命令用于查询MEP HTTP客户端通信参数。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称          | 参数说明                                                                                                                   |
|:---------|:--------------|:-----------------------------------------------------------------------------------------------------------------------|
| PARANAME | HTTP客户端通信参数名称 | 可选必选说明：可选参数 参数含义：该参数用于指定HTTP客户端通信参数名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“.”组成，且只能以字母或者数字开头。 默认值：无 配置原则：无 |

#### 使用实例

- 查询全部的MEPCLIENTCOMMPARA对象：

  ```
  LST MEPCLIENTCOMMPARA:;
  ```

  ```
  RETCODE = 0  操作成功

  MEP HTTP客户端通信参数
  ----------------------
  HTTP客户端通信参数名称  与服务端建立连接超时时间  发送请求超时时间  读取服务端响应超时时间  

  DefaultClientPara       60                        60                60                      
  cli-comm-para           40                        40                40                      
  (结果个数 = 2)

  ---    END
  ```
- 查询MEPCLIENTCOMMPARA对象，查询的MEPCLIENTCOMMPARA对象名称为"cli-comm-para"：

  ```
  LST MEPCLIENTCOMMPARA: PARANAME="cli-comm-para";
  ```

  ```
  RETCODE = 0  操作成功

  MEP HTTP客户端通信参数
  ----------------------
    HTTP客户端通信参数名称  =  cli-comm-para
  与服务端建立连接超时时间  =  40
          发送请求超时时间  =  40
    读取服务端响应超时时间  =  40
  (结果个数 = 1)

  ---    END
  ```
