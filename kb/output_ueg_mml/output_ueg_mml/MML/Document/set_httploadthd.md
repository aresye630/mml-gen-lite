# 设置HTTP2链路负荷过载阈值(SET HTTPLOADTHD)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成负荷过载告警上报异常，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置HLB服务实例负荷过载告警的上报阈值和恢复阈值。

该命令的使用场景：系统依据“HTTP链路遍历周期”软参设置的遍历周期定时检测HLB服务的负荷，并判断是否要上报ALM-18410 HLB服务实例负荷过载告警。

- 当连续三个周期发送负荷或者接收负荷超过HLB服务负荷过载阈值，则上报ALM-18410 HLB服务实例负荷过载告警。
- 当连续三个周期发送负荷和接收负荷都低于HLB服务过载恢复阈值，则恢复ALM-18410 HLB服务实例负荷过载告警。

## 注意事项

过载阈值与恢复阈值需满足如下要求：

- “HLB服务负荷过载阈值(%)”大于“HLB服务过载恢复阈值(%)”

## 参数说明

| 参数标识           | 参数名称           | 参数说明                                                                                                     |
|:---------------|:---------------|:---------------------------------------------------------------------------------------------------------|
| HLBOVERLOADTHD | HLB服务负荷过载阈值(%) | 可选必选说明：可选参数 参数含义：用于标识HLB服务的负荷过载阈值。 取值范围：0~100 单位：% 系统初始设置值：80 配置原则：“HLB服务负荷过载阈值(%)”大于“HLB服务过载恢复阈值(%)”。   |
| HLBRESTORETHD  | HLB服务过载恢复阈值(%) | 可选必选说明：可选参数 参数含义：用于标识HLB服务的负荷过载恢复阈值。 取值范围：0~100 单位：% 系统初始设置值：75 配置原则：“HLB服务过载恢复阈值(%)”小于“HLB服务负荷过载阈值(%)”。 |

## 使用实例

设置HTTP2链路和HLB服务的“HLB服务负荷过载阈值(%)”为“80”，“HLB服务过载恢复阈值(%)”为“75”：

```
SET HTTPLOADTHD：HLBOVERLOADTHD=80,HLBRESTORETHD=75;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表 错误码列表所示。

|    错误码 | 消息解释          | 原因分析                                                   | 处理建议                                                                                                                               |
|-------:|:--------------|:-------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------|
| 360161 | 恢复阈值必须小于过载阈值。 | 可能原因为输入参数不符合如下参数限制： “HLB服务负荷过载阈值(%)”大于“HLB服务过载恢复阈值(%)” | 执行SET HTTPLOADTHD命令，重新输入参数，确保输入参数满足如下条件： “HLB服务负荷过载阈值(%)”大于“HLB服务过载恢复阈值(%)” 可通过执行LST HTTPLOADTHD命令，查看已经配置的HLB服务实例负荷过载告警的上报阈值和恢复阈值。 |
