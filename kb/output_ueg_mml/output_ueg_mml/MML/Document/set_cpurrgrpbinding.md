# 设置用户模板的计费属性绑定关系（SET CPURRGRPBINDING）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于设置用户模板的计费属性绑定关系。

#### 注意事项

- 该命令执行后立即生效。
- 如果UserProfile下不绑定默认计费属性，用户的数据包按全局计费属性计费，否则不计费。
- 该命令设定后的数据，需要通过LST CPUSERPROFILE命令进行查看。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称     | 参数说明                                                                                                                    |
|:----------------|:---------|:------------------------------------------------------------------------------------------------------------------------|
| USERPROFILENAME | 用户模板名称   | 可选必选说明：必选参数 参数含义：该参数用于指定用户模板名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD CPUSERPROFILE命令配置生成。 |
| DFTURRGRPNAME   | 缺省URR组名称 | 可选必选说明：可选参数 参数含义：指定缺省URR组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD CPURRGROUP命令配置生成。       |

#### 使用实例

假如运营商希望为用户模板绑定默认计费属性：

```
SET CPURRGRPBINDING:USERPROFILENAME="testuserprofilename",DFTURRGRPNAME="dfturrgrp";
```
