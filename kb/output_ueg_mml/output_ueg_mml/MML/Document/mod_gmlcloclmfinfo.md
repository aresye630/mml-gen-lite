# 修改本地LMF信息配置（MOD GMLCLOCLMFINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于修改本地LMF Identification信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                      |
|:-------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCEID | NF实例标识 | 可选必选说明：必选参数 参数含义：该参数用于指定NF实例标识。 数据来源：全网规划 取值范围：字符串类型，输入长度范围是1~36。 默认值：无 配置原则：无                                                                            |
| LMFID        | LMF标识  | 可选必选说明：必选参数 参数含义：该参数用于指定GMLC在定位请求消息中携带的LMF Identification。 数据来源：全网规划 取值范围：字符串类型，输入长度范围是1~255。本参数的构成字符只能是字母A～Z或a～z、数字0～9、中划线"-"和下划线"_"组成的字符串。 默认值：无 配置原则：无 |

#### 使用实例

配置本地LMF Identification信息：

```
MOD GMLCLOCLMFINFO: NFINSTANCEID="1465150f-32dc-496f-9e51-b204b0a44275", LMFID="lmf_Identification_1";
```
