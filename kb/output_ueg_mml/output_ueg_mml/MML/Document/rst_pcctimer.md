# 复位PCC定时器（RST PCCTIMER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

此命令用于重启PCC定时器。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                   |
|:----------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
| TIMERTYPE | PCC定时器 | 可选必选说明：必选参数 参数含义：该参数用于在supported-features动态协商功能使能时，手动重启定时器，并清除UNC本地缓存的所有PCRF的实际feature支持能力。 数据来源：本端规划 取值范围：枚举类型。 SUPFEA_NEGO_TMR：动态协商定时器。 默认值：无 配置原则：无 |

#### 使用实例

如果希望重启动态协商定时器，清除UNC本地缓存的所有PCRF的实际feature支持能力，则可以进行如下设置：

```
RST PCCTIMER: TIMERTYPE=SUPFEA_NEGO_TMR;
```
