# 查询地址池组映射关系（LST CPPOOLGRPMAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于查询地址池组和UPF组的映射关系。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                |
|:------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| MAPPINGNAME | 映射名称   | 可选必选说明：可选参数  参数含义：该参数用于指定地址池组映射规则名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~79。不支持空格及特殊字符“#”、“$”和“&”等，由“-”、“_”、数字、字母和“.”组成，不能以“.”开头，不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

查询地址池组和UPF组的映射关系：

```
LST CPPOOLGRPMAP:;
RETCODE = 0  操作成功。

结果如下
------------------------
     映射名称  =  one
 地址池组名称  =  spoolgrp1
    UPF组名称  =  upfgrp1
 位置区组类型  =  无
 位置区组名称  =  NULL
      APN名称  =  NULL
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释               |
|:--------|:--------------------|
| 映射名称    | 该参数用于指定地址池组映射规则名称。  |
| 地址池组名称  | 该参数用于指定地址池组的名称。     |
| UPF组名称  | 该参数用于指定UPF组的名称。     |
| 位置区组类型  | 该参数用于指定映射地址池组的区域类型。 |
| 位置区组名称  | 该参数用于指定位置组名称。       |
| APN名称   | 该参数用于指定APN实例名。      |
