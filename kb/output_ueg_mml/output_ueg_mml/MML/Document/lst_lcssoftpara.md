# 查询LCS软参记录（LST LCSSOFTPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询软件参数信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                                                                     |
|:----------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DT        | 软参记录数据类型 | 可选必选说明：可选参数 参数含义：软件参数的数据类型。 数据来源：本端规划 取值范围：枚举类型。 BIT：比特。BYTE：字节。DWORD：双字。STRING：字符串。 默认值：无 配置原则： 配置BIT表示需要查询比特类型软件参数。配置BYTE表示需要查询字节类型软件参数。配置DWORD表示需要查询双字类型软件参数。配置STRING表示需要查询字符串类型软件参数。 |
| BITNUM    | Bit索引    | 可选必选说明：条件可选参数 前提条件：该参数在“DT”配置为“BIT”时为可选参数。 参数含义：比特类型软件参数的索引。 数据来源：本端规划 取值范围：整数类型，取值范围为1～1920。 默认值：无 配置原则：无                                                                               |
| BYTENUM   | Byte索引   | 可选必选说明：条件可选参数 前提条件：该参数在“DT”配置为“BYTE”时为可选参数。 参数含义：字节类型软件参数的索引。 数据来源：本端规划 取值范围：整数类型，取值范围为1～960。 默认值：无 配置原则：无                                                                               |
| DWORDNUM  | DWord索引  | 可选必选说明：条件可选参数 前提条件：该参数在“DT”配置为“DWORD”时为可选参数。 参数含义：双字类型软件参数的索引。 数据来源：本端规划 取值范围：整数类型，取值范围为1～120。 默认值：无 配置原则：无                                                                              |
| STRINGNUM | String索引 | 可选必选说明：条件可选参数 前提条件：该参数在“DT”配置为“STRING”时为可选参数。 参数含义：字符串类型软件参数的索引。 数据来源：本端规划 取值范围：整数类型，取值范围为1～30。 默认值：无 配置原则：无                                                                             |

#### 使用实例

查询当前参数索引为2的单字节类型软参的设置情况：

```
LST LCSSOFTPARA: DT=BYTE, BYTENUM=2;
```

```

    软参记录索引  =  2
      软参记录值  =  1
(结果个数 = 1)
---    END
```
