# 校验SUCI密钥(CHK SUCIKEY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于校验SUCI（Subscription Concealed Identifier）私钥，以检查输入的私钥值与数据库中的私钥值是否匹配。

## 注意事项

“SUCI密钥值”和“SUCI公钥值”参数必须输入其中一个且不能同时输入。

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                                                                                                                |
|:----------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| KEYNAME   | Key名称   | 可选必选说明：必选参数 参数含义：标识SUCI私钥的名称。用于指定需要校验哪个“Key名称”对应的SUCI私钥记录，操作员可以使用LST SUCIKEY命令查询获得。 取值范围：1～16个字母、数字或特殊字符组成的字符串。 默认值：无。 配置原则：该参数是SUCI私钥记录的唯一索引。该参数全局唯一，不能重复。                                                         |
| KEYVALUE  | SUCI密钥值 | 可选必选说明：可选参数 参数含义：用于标识SUCI私钥的取值。 取值范围：64位十六进制数字组成的字符串。 默认值：无。 配置原则：界面上输入该参数，以"*****"方式匿名显示。                                                                                                                          |
| PUBLICKEY | SUCI公钥值 | 可选必选说明：可选参数 参数含义：用于标识SUCI公钥的取值。 取值范围：最大支持66位十六进制数字组成的字符串。 默认值：无。 配置原则： 界面上输入该参数，以"*****"方式匿名显示。操作员可以LST SUCIKEY使用命令查询“SUCI 密钥类型”。当“SUCI 密钥类型”为“SUCI密钥类型A”时，该参数取值长度为64。当“SUCI 密钥类型”为“SUCI密钥类型B”时，仅支持压缩格式的公钥取值，长度为66。 |

## 使用实例

1. 校验“Key名称”为“key1”，“SUCI密钥值”为“77076d0a7318a57d3c16c17251b26645df4c2f87ebc0992ab177fba51db92c2a”的SUCI私钥记录。

   ```
   CHK SUCIKEY:KEYNAME="key1", KEYVALUE="*****";
   ```

   ```
   %%CHK SUCIKEY:KEYNAME="key1", KEYVALUE="*****";%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   SUCI密钥是否一致  =  是
   (结果个数 = 1)

   ---    END
   ```
2. 校验“Key名称”为“key1”，“SUCI公钥值”为“77076d0a7318a57d3c16c17251b26645df4c2f87ebc0992ab177fba51db92c03”的SUCI私钥记录。

   ```
   CHK SUCIKEY:KEYNAME="key1", PUBLICKEY="*****";
   ```

   ```
   %%CHK SUCIKEY:KEYNAME="key1", PUBLICKEY="*****";%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   SUCI公钥是否一致  =  否
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释                   | 原因分析                                                                                                                                      | 处理建议                                                                                                 |
|-------:|:-----------------------|:------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------|
| 300022 | SUCI秘钥不合法。             | 可能的原因为如下之一： 参数“SUCI密钥值”的取值不是十六进制数字组成的字符串。参数“SUCI密钥值”的长度不等于64个字符。                                                                          | 根据实际情况，重新输入“SUCI密钥值”的取值，确保其取值符合要求。                                                                   |
| 360196 | SUCI密钥值和SUCI公钥值只能存在一个。 | 同时输入了“SUCI密钥值”和“SUCI公钥值”参数。                                                                                                               | 根据实际情况，重新输入“SUCI密钥值”或“SUCI公钥值”的取值。                                                                   |
| 360197 | SUCI密钥值和SUCI公钥值必须存在一个。 | “SUCI密钥值”和“SUCI公钥值”参数都没有输入。                                                                                                               | 根据实际情况，务必输入“SUCI密钥值”和“SUCI公钥值”其中一个参数。                                                                |
| 360198 | 待校验的配置数据不存在。           | 输入的“Key名称”参数不存在。                                                                                                                          | 执行LST SUCIKEY命令查询是否存在“Key名称”。 若存在“Key名称”，请根据查询结果重新输入“Key名称”。若不存在“Key名称”，执行ADD SUCIKEY命令重新添加一条SUCI私钥。 |
| 360199 | SUCI公钥值不合法。            | 可能的原因为如下之一： “SUCI公钥值”的取值不是十六进制数字组成的字符串。“SUCI公钥值”的长度不合法。当“SUCI 密钥类型”为“SUCI密钥类型A”时，该参数取值长度为64。当“SUCI 密钥类型”为“SUCI密钥类型B”时，仅支持压缩格式的公钥取值，长度为66。 | 根据实际情况，重新输入“SUCI公钥值”的取值，确保其取值符合要求。                                                                   |
