# 增加MME和PGW IP地址(ADD EDGEMMEPGWIP)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于配置MME和PGW IP地址对应关系。

#### 注意事项

- 该命令配置后立即生效。
- 整系统最大允许配置100条记录。
- 如果配置IPv4v6双栈模式，优先使用IPv6地址。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

新增一条MME和PGW IP地址对应关系，MME IP类型为IPV4，MME IPV4地址为“10.192.57.15”，PGW IP类型为IPV4，PGW IPV4地址为“10.182.57.32”，执行如下命令：

```
ADD EDGEMMEPGWIP: MMEIPVERSION=IPV4, MMEIPV4="10.192.57.15", PGWIPVERSION=IPV4, PGWIPV4="10.182.57.32";
```
