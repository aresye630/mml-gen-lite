# 删除DNS查询控制参数(RMV DNSQ)

- 命令功能

- 本地用户权限
- 网管用户权限

- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于删除DNS查询控制参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令执行后，相应的DNS查询控制参数将失效。
- 该命令执行后，需要执行**CLR DNSC**来清除L1，L2 缓存，以保证使用最新的配置进行查询。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                   |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：必选参数 参数含义：该参数用于表示签约用户的范围。 数据来源：整网规划 取值范围：“All（所有用户）”“SPECIFY（指定用户）” 默认值：无                                                                                                                                                                                                                       |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件必选参数 参数含义：该参数用于表示IMSI前缀。 前提条件：当“用户范围”为“SPECIFY（指定用户）”时，此参数为必选参数。 数据来源：整网规划 取值范围：5~15位数字 默认值：无  说明： IMSI前缀按照IMSI最长匹配进行查询，相同IMSI前缀的DNS域名后缀不能相同。                                                                                                                                                 |
| DNSUF    | 域名后缀   | 可选必选说明：必选参数 参数含义：该参数用于表示DNS服务器域名后缀。 数据来源：整网规划 取值范围：1~255 默认值：无  说明： 按照域名后缀选择合适的DNS服务器。域名后缀在比较时从后向前进行最大匹配。域名后缀支持配置为*。任何域名和*比较，都认为匹配。域名后缀不能以“.”开始，也不能以“.”结束。相同域名后缀下的IMSI前缀不能相同，相同IMSI前缀下的域名后缀不能相同。该参数只能由字母（A-Z或者a-z）、数字（0-9）、连字符（-）、通配符（*）和点（.）组成。按照协议RFC1035规定，Hostname最大有效字符数为253，并且每个Label最大长度为63个字节。 |

#### 使用实例

删除“用户范围”为“所有用户”，“域名后缀”为“huawei.com”的DNS查询管理参数：

RMV DNSQ: SUBRANGE=All, DNSUF="huawei.com";
