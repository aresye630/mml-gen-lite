# 查询DNS Client IP与DNS实体的绑定关系(LST DNSLE)

#### 命令功能

**适用网元：SGSN、MME****、AMF**

该命令用于查看配置的DNS本端实体信息，DNS本端实现体包含了DNS本端的IP地址、端口和VPN名称。

#### 注意事项

- 该命令执行后立即生效。
- 如果不输入参数，则查询所有记录。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                                                                    |
|:--------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------|
| IPT     | IP地址类型    | 可选必选说明：可选参数 参数含义：该参数用于指定IP地址类型。 数据来源：整网规划 取值范围：“IPV4(IPV4)”“IPV6(IPV6)” 默认值：无                                                           |
| IPV4    | IPv4地址    | 可选必选说明：条件可选参数 参数含义：该参数用于指定IPv4地址。 前提条件：当“IP地址类型”设置为“IPV4(IPV4)”时，该参数有效。 数据来源：整网规划 取值范围：0.0.0.0～255.255.255.255 默认值：无                    |
| IPV6    | IPv6地址    | 可选必选说明：条件可选参数 参数含义：该参数用于指定IPv6地址。 前提条件：当“IP地址类型”设置为“IPV6(IPV6)”时，该参数有效。 数据来源：整网规划 取值范围：::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 |
| LOCPORT | 本地端口号     | 可选必选说明：可选参数 参数含义：该参数用于指定本端端口号。 数据来源：整网规划 取值范围：15000~65535 默认值：无                                                                         |
| VPNNAME | VPN名称     | 可选必选说明：可选参数 参数含义：该参数用于指定DNS本端实体到DNS服务器间的链路所用的VPN名称。 数据来源：整网规划 取值范围：0~31个字符。 默认值：无                                                       |
| LENAME  | DNS本端实体名称 | 可选必选说明：可选参数 参数含义：该参数用于指定DNS本端实体的名称。 数据来源：整网规划 取值范围：0~32个字符。 默认值：无                                                                       |

#### 使用实例

查询所有DNS本端实体：

LST DNSLE:;

```
%%LST DNSLE:;%%

```
