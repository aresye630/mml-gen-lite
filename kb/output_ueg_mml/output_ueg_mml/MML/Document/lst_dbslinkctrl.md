# 查询DBS链路中心(LST DBSLINKCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询DBS链路中心。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询所有DBS链路中心配置：

```
LST DBSLINKCTRL:;
```

```
%%LST DBSLINKCTRL:;%%
RETCODE = 0  操作成功

操作结果如下
------------
 服务模块号  IP类型  本地链路中心IPV4地址  本地链路中心IPV6地址

 53          IPV4    10.14.39.40           NULL                       
 63          IPV4    10.14.39.41           NULL                          
(结果个数 = 2)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD DBSLINKCTRL**命令的参数说明。
