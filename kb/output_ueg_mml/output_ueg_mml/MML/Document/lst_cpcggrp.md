#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

此命令用来查询指定的抄送CG组。

#### 注意事项

当前版本不支持此命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询所有的抄送CG组：

```
LST CPCGGRP:;
```

```
RETCODE = 0  操作成功

抄送CG组
--------
  抄送CG组ID  =  1
抄送CG组描述  =  test
(结果个数 = 1)

---    END
```
