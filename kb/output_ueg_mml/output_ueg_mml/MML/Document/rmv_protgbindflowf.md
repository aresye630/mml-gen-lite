# 删除流过滤器协议组绑定关系（RMV PROTGBINDFLOWF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，可能会影响业务。

该命令用于删除协议组与流过滤器绑定关系。

#### 注意事项

- 该命令执行后立即生效。
- 如果不输入ProtGroupName，则代表删除该FlowFilterName对应的流过滤器下所有的协议组与流过滤器绑定关系。
- 该命令会导致用户匹配范围发生变化，可能导致性能下降。执行命令前请评估对性能的影响，如果无法评估请联系华为技术支持。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                        |
|:---------------|:-------|:--------------------------------------------------------------------------------------------|
| FLOWFILTERNAME | 流过滤器名称 | 可选必选说明：必选参数 参数含义：该参数用于指定流过滤器名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无 |
| PROTGROUPNAME  | 协议组名称  | 可选必选说明：可选参数 参数含义：该参数用于设置协议组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无  |

#### 使用实例

删除协议组与流过滤器绑定关系：“FLOWFILTERNAME”为“testflowfiltername”，“PROTGROUPNAME”为“p2p”：

```
RMV PROTGBINDFLOWF:FLOWFILTERNAME="testflowfiltername",PROTGROUPNAME ="p2p";
```
