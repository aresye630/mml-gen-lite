# 查询BFD参数(LST BFDINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询BFD信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询BFD信息。

```
LST BFDINFO:;
```

```
%%LST BFDINFO:;%%
RETCODE = 0  操作成功

         BFD开关  =  BFD打开
        探测倍数  =  3
最小发送时间间隔  =  50
最小接收时间间隔  =  50
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET BFDINFO**命令的参数说明。
