# 配置GTP路径管理IP地址（ADD ECHOIPLIST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用来增加对端网元所属的GTP数据面IP地址段，即配置GTP路径管理黑白名单中的地址段。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为200。
- ADD ECHOIPLIST是配合SET UPGTPPATH使用的。
- 使用LST UPGTPPATH查看EchoList类型为黑名单还是白名单。
- 如果对端网元的IP地址落在ADD ECHOIPLIST配置的地址段内：

  - 配置GTP路径管理名单属性为白名单时，系统向对端网元发送GTP信令路径Echo探测或是GTP数据路径Echo探测。
  - 配置GTP路径管理名单属性为黑名单时，系统不会向对端网元发送GTP信令路径Echo探测或是GTP数据路径Echo探测。
- 如果对端网元的IP地址没有落在ADD ECHOIPLIST配置的地址段内：

  - 配置GTP路径管理名单属性为黑名单时，系统向对端网元发送GTP信令路径Echo探测或是GTP数据路径Echo探测。
  - 配置GTP路径管理名单属性为白名单时，系统不会向对端网元发送GTP信令路径Echo探测或是GTP数据路径Echo探测。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                     |
|:----------|:---------|:-------------------------------------------------------------------------------------------------------------------------|
| IPVERSION | IP地址版本类型 | 可选必选说明：必选参数 参数含义：该参数用来指定IP类型。 数据来源：全网规划 取值范围：枚举类型。 IPV4：表示地址类型为IPv4。IPV6：表示地址类型为IPv6。 默认值：IPV4 配置原则：无                    |
| IPV4ADDR  | IPv4地址   | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV4”时为必选参数。 参数含义：指定GTP路径管理黑白名单中的IPv4地址段的地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无 配置原则：无 |
| IPV4MASK  | IP掩码     | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV4”时为必选参数。 参数含义：该参数用来指定IPv4掩码长度。 数据来源：本端规划 取值范围：整数类型，取值范围为1～32。 默认值：无 配置原则：无     |
| IPV6ADDR  | IPv6地址   | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV6”时为必选参数。 参数含义：指定GTP路径管理黑白名单中的IPv6地址段的地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无 配置原则：无 |
| IPV6MASK  | IP掩码     | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV6”时为必选参数。 参数含义：该参数用来指定IPv6掩码长度。 数据来源：本端规划 取值范围：整数类型，取值范围为1～128。 默认值：无 配置原则：无    |

#### 使用实例

增加IP地址为10.36.0.2，mask为27的IP地址段为GTP路径管理的黑白名单控制的网段：

```
ADD ECHOIPLIST: IPVERSION=IPV4, IPV4ADDR="10.36.0.2", IPV4MASK=27;
```
