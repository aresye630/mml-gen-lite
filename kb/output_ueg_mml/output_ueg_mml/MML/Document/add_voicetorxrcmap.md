# 增加语音错误码映射（ADD VOICETORXRCMAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于增加一条N7/Gx接口的语音错误码映射记录。

该命令的使用场景：

UE发起语音呼叫，AF发送AAR给UPCF，当对端SMF或PCEF链路故障时，会导致UPCF发送请求消息失败或接收SMF/PCEF响应消息超时，UPCF支持通过配置语音错误码映射，将配置的映射后的错误码发送给AF，以便AF根据此错误码向UDM触发P-CSCF Restoration流程。

## 注意事项

- 整个语音恢复流程需要AF提前开启基于UDM的P-CSCF Restoration功能。
- 本命令仅支持将N7/Gx接口中携带的指定的语音错误码映射为与AF侧协商一致的错误码。

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                                                    |
|:-------|:-----------|:------------------------------------------------------------------------------------------------------------------------|
| N7RC   | N7/Gx接口结果码 | 可选必选说明：必选参数 参数含义：用于指定要进行转换的N7或Gx接口消息结果码。 取值范围： RC0(UpdateNotifyRspTimeOut-AARI)RC1(RAATimeOut-AARI) 默认值：无。 配置原则：不可重复。   |
| RXRC   | Rx接口结果码    | 可选必选说明：必选参数 参数含义：用于指定N7或Gx接口消息结果码转换Rx接口消息原因值。 取值范围： 5065(DIAMETER_REQUESTED_IPCAN_SESSION_NOT_AVAILABLE) 默认值：无。 配置原则：无。 |

## 使用实例

增加一条语音错误码映射记录。“N7/Gx接口结果码”为“RC0”，“Rx接口结果码”为“5065”。

```
ADD VOICETORXRCMAP: N7RC=RC0, RXRC=5065;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如下表1所示。

|   错误码 | 消息解释                     | 原因分析                             | 处理建议                                                                                                                                   |
|------:|:-------------------------|:---------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------|
| 58116 | VOICETORXRCMAP已经达到最大数限制。 | UPCF最多支持配置2条语音错误码映射记录，配置超过最大数限制。 | 执行LST VOICETORXRCMAP查询所有已存在映射记录，执行RMV VOICETORXRCMAP删除不需要的映射记录，再执行ADD VOICETORXRCMAP命令添加映射记录。                                          |
| 58117 | 对象已存在，不能增加相同的对象。         | UPCF不能重复配置语音错误码映射。               | 执行LST VOICETORXRCMAP查询该语音错误码是否已经存在映射记录，并检查该映射关系是否和要添加的映射记录一致。如果一致，则无需再执行ADD VOICETORXRCMAP命令；如果不一致，则执行MOD VOICETORXRCMAP命令修改为要添加的映射记录。 |
