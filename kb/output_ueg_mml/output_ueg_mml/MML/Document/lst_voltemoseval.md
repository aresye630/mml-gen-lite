# 查询VoLTE AMR编解码的语音质量采用的评估方式（LST VOLTEMOSEVAL）

#### 命令功能

**适用NF：PGW-U**

该命令用于查询VoLTE AMR编解码的语音质量采用的评估方式。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询VoLTE AMR编解码的语音质量采用的评估方式：

```
LST VOLTEMOSEVAL:;
```

```
RETCODE = 0 操作成功

显示Mos评估方式
---------------
评估方式 = POLQA_SWB_AMR
(结果个数 = 1)

--- END
```

#### 输出结果说明

参见SET VOLTEMOSEVAL的参数说明。
