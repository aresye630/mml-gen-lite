# 查询有界邮箱开关配置状态（LST LIMITMBSWITCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询有界邮箱开关配置状态。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询有界邮箱开关配置。

```
%%LST LIMITMBSWITCH:;%%
RETCODE = 0  操作成功

结果如下
--------
有界邮箱开关  =  开启
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                     |
|:--------|:------------------------------------------|
| 有界邮箱开关  | 有界邮箱开关，ON表示sdrc将使用有界邮箱功能，OFF表示sdrc使用无界邮箱。 |
