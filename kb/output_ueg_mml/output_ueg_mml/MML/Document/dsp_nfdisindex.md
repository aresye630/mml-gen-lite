# 显示服务发现响应缓存索引(DSP NFDISINDEX)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询服务发现缓存索引。

- 当“索引类型”为“NFINSTANCEID”时：
  - 如果不输入“网元实例ID”参数：用于查询所有“网元实例ID”类型的索引。
  - 如果输入“网元实例ID”参数：用于查询对应“网元实例ID”类型的索引。
  - 如果输入“对端网元类型”参数：用于查询对应“对端网元类型”的索引。

- 当“索引类型”参数为“GUAMI”时：
  - 如果不输入“PLMN ID”和“AMF标识”参数：用于查询所有GUAMI类型的索引。
  - 如果输入“PLMN ID”和“AMF标识”参数：用于查询对应GUAMI的索引。“PLMN ID”和“AMF标识”参数必须同时输入。

- 当“索引类型”参数为“FQDN”时：
  - 如果不输入“域名”参数：用于查询所有FQDN类型的索引。
  - 如果输入“域名”参数：用于查询对应FQDN的索引。

- 当“索引类型”参数为“SET”时：
  - 如果不输入“PLMN ID”、“AMF Region ID”、“AMF Set ID”参数：用于查询所有SET类型的索引。
  - 如果不输入“PLMN ID”，仅输入“AMF Region ID”、“AMF Set ID”参数：用于查询AMFREGION和AMFSET组合的索引。
  - 如果输入“PLMN ID”、“AMF Region ID”、“AMF Set ID”参数：用于查询PLMN、AMFREGION和AMFSET组合的索引。

- 当“索引类型”参数为“PNFTYPE”时，根据输入的“对端网元类型”查询对应网元类型的索引。

## 注意事项

无。

## 参数说明

| 参数标识         | 参数名称          | 参数说明                                                                                                                                                                                                                               |
|:-------------|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CACHETYPE    | 缓存类型          | 可选必选说明：必选参数 参数含义：用于指示系统按照哪个缓存类型查询服务发现缓存索引。 取值范围：NRFC(NRFC)UDM(UDM) 默认值：无。 配置原则：无。                                                                                                                                                  |
| SFINSTANCEID | SF实例号         | 可选必选说明：必选参数 参数含义：用于指示系统按照哪个SF实例号来查询服务发现缓存索引。 取值范围：长度不超过65位的字符串。 配置原则： 当“缓存类型”参数为“NRFC(NRFC)”时，在DSP UDMSERVICE命令中查询的“SF实例号”输出项对应的“服务类型”为“NRFClient”。当“缓存类型”参数为“UDM(UDM)”时，在DSP UDMSERVICE命令中查询的“SF实例号”输出项对应的“服务类型”为“UdmSubService”。 |
| INDEXTYPE    | 索引类型          | 可选必选说明：可选参数 参数含义：用于指示按哪种索引类型查询服务发现缓存索引。 取值范围： ALL：查询所有类型的服务发现缓存索引。NFINSTANCEID：查询NFINSTANCEID对应的服务发现缓存索引。GUAMI：查询GUAMI对应的服务发现缓存索引。FQDN：查询FQDN对应的服务发现缓存索引。SET：查询SET类型的服务发现缓存索引。PNFTYPE：查询对端网元类型对应的服务发现缓存索引。 默认值：无。 配置原则：无。          |
| NFINSTANCEID | 网元实例ID        | 可选必选说明：条件可选参数 参数含义：用于指示系统查询哪个网元实例ID的服务发现缓存索引。 取值范围：有效的UUIDv4格式，只允许输入0～9，a～f，A～F，“-”。 UUIDv4格式为“xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx”，例如：4947a69a-f61b-4bc1-b9da-47c9c5d14b64。 默认值：无。 配置原则：仅当本命令中的“索引类型”参数为“NFINSTANCEID”时该参数有效。    |
| PLMN         | PLMN ID       | 可选必选说明：条件可选参数 参数含义：用于指示系统查询哪个PLMN ID的服务发现缓存索引。 取值范围：5位或6位十进制数字组成的字符串。 默认值：无。 配置原则：仅当“索引类型”参数为“GUAMI”或“SET”时该参数有效。 当“索引类型”参数为“SET”时，不允许仅携带该参数。                                                                                      |
| AMFID        | AMF标识         | 可选必选说明：条件可选参数 参数含义：用于指示系统查询哪个AMF标识的服务发现缓存索引。 取值范围：6位十六进制数字组成的字符串。 默认值：无。 配置原则：仅当“索引类型”参数为“GUAMI”时该参数有效。                                                                                                                            |
| FQDN         | 域名            | 可选必选说明：条件可选参数 参数含义：用于指示系统查询哪个域名的服务发现缓存索引。 取值范围：1~255位字符串。 默认值：无。 配置原则：仅当“索引类型”参数为“FQDN”时该参数有效。                                                                                                                                     |
| AMFREGION    | AMF Region ID | 可选必选说明：条件可选参数 参数含义：用于指示系统查询哪个AMF Region ID的服务发现缓存索引。 取值范围：2位十六进制数字组成的字符串。 默认值：无。 配置原则： 仅当“索引类型”参数为“SET”时该参数有效。如果输入了本参数，则必须同时输入“AMF Set ID”参数。                                                                                      |
| AMFSET       | AMF Set ID    | 可选必选说明：条件可选参数 参数含义：用于指示系统查询哪个AMF Set ID的服务发现缓存索引。 取值范围：3位十六进制数字组成的字符串，第1位的取值范围是0～3，后两位是十六进制数字。 默认值：无。 配置原则： 仅当“索引类型”参数为“SET”时该参数有效。如果输入了本参数，则必须同时输入“AMF Region ID”参数。                                                              |
| PNFTYPE      | 对端网元类型        | 可选必选说明： 当“索引类型”参数为“NFINSTANCEID”时该参数为可选参数。 当“索引类型”参数为“PNFTYPE”时该参数为必选参数。 参数含义：用于指示系统查询哪个对端网元类型的服务发现缓存索引。 取值范围： AMF(接入和移动性管理功能)SMF(会话管理功能) 默认值：无。 配置原则：无。                                                                           |

## 使用实例

查询“缓存类型”为“NRFC(NRFC)”、“SF实例号”为“427512818427475922711034808”、“索引类型”为“ALL”的服务发现缓存索引信息。

```
DSP NFDISINDEX: CACHETYPE=NRFC, SFINSTANCEID="427512818427475922711034808", INDEXTYPE=ALL;
```
