# 修改SOAP对端(MOD SOAPPE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于修改系统中的一条SOAP对端记录。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                                   |
|:-------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
| ID     | SOAP对端标识 | 可选必选说明：必选参数 表示SOAP对端标识的关键字段，用于指定需要对哪个ID对应的SOAP对端信息进行修改。 取值范围：1～255 默认值：无。                                                                              |
| FQDN   | FQDN     | 可选必选说明：可选参数 用于指定待配置网络应用功能的全量域名（Fully Qualified Domain Name），在本命令中用于标识修改后的AP的FQDN。 取值范围：长度不超过127的字符串。 默认值：无。 说明：该参数不区分大小写，在执行LST SOAPPE命令查询出的报文中为全小写形式。 |

## 使用实例

修改“SOAP对端标识”为“1”的“FQDN”为“a”:

```
MOD SOAPPE: ID=1, FQDN="a";
```
