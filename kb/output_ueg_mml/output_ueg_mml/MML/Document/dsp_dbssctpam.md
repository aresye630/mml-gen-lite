# 查看SCTP偶联管理信息(DSP DBSSCTPAM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查看SCTP偶联管理信息。

若需要查询某条SCTP偶联管理信息，请输入“服务模块号”或“服务模块号”和其他参数的组合。

## 注意事项

无。

## 参数说明

| 参数ID      | 参数名称   | 参数描述                                                                                                   |
|:----------|:-------|:-------------------------------------------------------------------------------------------------------|
| SERVICENO | 服务模块号  | 可选必选说明：必选参数。 参数含义：用于请求系统显示哪个DBS服务的SCTP偶联管理信息。 取值范围： 1～1024 默认值： 无。 配置原则：无。                             |
| AID       | 偶联号    | 可选必选说明：可选参数。 参数含义：用于请求系统显示哪个偶联号的SCTP偶联管理信息；若不输入，则表示请求显示全部偶联号的SCTP偶联管理信息。 取值范围： 0～65534 默认值： 无。 配置原则：无。 |

## 使用实例

查看SCTP偶联管理信息，DBS服务模块号为102。

```
DSP DBSSCTPAM: SERVICENO=102;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称    | 输出项解释                                                                                                                                      |
|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| 偶联号      | SCTP偶联号码。                                                                                                                                  |
| 对端SCTP端口 | 对端SCTP端口号。                                                                                                                                 |
| 对端主用地址   | 当前SCTP偶联对端主用的IP地址。                                                                                                                         |
| 偶联心跳间隔   | 在一定的时间内SCTP偶联未向某个特定的IP地址发送数据，SCTP偶联将向该IP地址发送心跳消息（SCTP的一种消息类别，用于监视到某个目的地址的可达性），以检查远端IP地址是否处于激活状态。此参数用于定义DSG在上述情况下向远端IP地址发送心跳消息的周期，其单位为“毫秒”。 |
| 偶联状态     | 当前SCTP偶联的偶联状态。 偶联状态取值： CLOSEDCOOKIE ACKCOOKIE ECHOESTABLISHEDSHUTDOWN_PENDINGSHUTDOWN_SENTSHUTDOWN_RECEIVEDSHUTDOWN_ACK_SENTTCB已删除         |
| 入流数      | 当前SCTP偶联在接收方向上的流个数。 “流”就是一个SCTP偶联中，从一个端点到另一个端点的单向逻辑通道。                                                                                     |
| 出流数      | 当前SCTP偶联在发送方向上的流个数。                                                                                                                        |
| 偶联最大重传次数 | 在一个SCTP偶联上所允许的消息连续重传的最大次数。                                                                                                                 |
| 对端地址个数   | 当前SCTP偶联对端传送地址的数量。                                                                                                                         |
| 对端IP地址   | 当前SCTP偶联在对端的IP地址。                                                                                                                          |
| 对端IP状态   | 当前SCTP偶联对端的IP状态。 IP状态取值： 激活未激活                                                                                                             |
| 对端心跳标志   | 表示对端是否使用心跳进行链路状态检测。 心跳标志取值： 0：表示使用心跳进行链路状态检测。1：表示不使用心跳进行链路状态检测。                                                                            |
| 路径最大重传次数 | 在一个SCTP偶联上所允许的向某个特定的IP地址进行消息连续重传的最大次数。                                                                                                     |
| PMTU     | PMTU（Patch Most Transmission Unit，路径最大传输单元），表示一个SCTP偶联上所允许的向某个特定的IP地址进行消息传输的最大数据帧长度。 单位：字节                                                 |
