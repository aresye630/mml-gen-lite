# 删除区域内路由聚合配置（RMV OSPFABRSUMMARY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于取消区域边界路由器ABR对区域内路由进行路由聚合。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                   |
|:------------|:--------|:-----------------------------------------------------------------------|
| PROCID      | OSPF进程号 | 可选必选说明：必选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 |
| AREAID      | 区域ID    | 可选必选说明：必选参数 参数含义：区域ID。 数据来源：对端协商 取值范围：IPv4地址类型。点分十进制格式。 默认值：无          |
| TOPONAME    | 拓扑标识    | 可选必选说明：必选参数 参数含义：拓扑标识。 数据来源：全网规划 取值范围：枚举类型。 base：基础类型。 默认值：无           |
| IPADDRESS   | IP地址    | 可选必选说明：必选参数 参数含义：IP地址。 数据来源：本端规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无          |
| ADDRESSMASK | IP地址的掩码 | 可选必选说明：必选参数 参数含义：IP地址的掩码。 数据来源：本端规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无       |

#### 使用实例

取消OSPF进程1下10.2.0.0的区域内路由聚合配置：

```
RMV OSPFABRSUMMARY:PROCID=1,AREAID="0.0.0.1",TOPONAME=base,IPADDRESS="10.2.0.0",ADDRESSMASK="255.255.0.0";
```
