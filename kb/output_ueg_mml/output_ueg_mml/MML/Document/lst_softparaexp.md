#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询软件参数配置导出模式，软件参数导出模式是指执行导出命令后，导出的MML配置文件中**SET SOFTPARA**

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询软件参数配置导出模式：

LST SOFTPARAEXP:;

```
%%LST SOFTPARAEXP:;%%
RETCODE = 0  操作成功。

输出结果如下
------------------------
软件参数导出模式  =  非缺省默认软件参数值
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见**SET SOFTPARAEXP**命令的参数说明。
