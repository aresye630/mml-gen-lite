# 添加NTS设备地址(ADD NTSDEVADDR)

- 命令功能

- 输出结果说明

## 命令功能

该命令用于在配置数据库中增加一条NTS设备地址信息数据记录。

使用场景：

UPCF支持在特定场景（例如用户流量达到阈值、配额充值）给用户发送通知，提醒用户当前业务的使用状态；或将通知发送到第三方服务器上，由第三方服务器决定后续的处理。

- 与短消息中心对接，可以通过短消息中心发送短信通知给终端用户。
- 与邮件服务器对接，可以通过邮件服务器发送邮件通知给终端用户。
- 与SOAP服务器对接，可以发送SOAP通知到SOAP服务器上，由SOAP服务器决定后续的处理（如以短信、邮件或PUSH通知方式通知给终端用户）。

通知发送前配置UPCF与对端的对接数据为必选操作之一。需执行本命令增加UPCF负责通知任务服务（NTS）的设备地址。

## 注意事项

- IPv4类型的IP地址不能配置如下非法IP地址：“127.0.0.1”、“0.0.0.0”、“255.255.255.255”、“224.0.0.1”。
- IPv6类型的IP地址不支持混合方式表达，即xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:d.d.d.d，其中x表示一个十六进制数（0～9或A～F），而d.d.d.d表示一个IPv4地址。
- IPv6类型的IP地址不支持以下特殊地址的配置，其中x表示一个十六进制数（0～9或A～F）：

  - 0000:0000:0000:0000:0000:0000:0000:0000
  - FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF
  - 0000:0000:0000:0000:0000:0000:0000:0001
  - FFxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE8x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE9x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEAx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEBx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
- 当未配置IP地址时，NTS能够启动，但不能提供服务。此时配置IP地址后，NTS不用重启，使用该IP地址提供服务。
- PMS/NTS/DRS/HLB/DLB/NLF/LDAP设备的IP地址（包括IPv4地址和IPv6地址）需要唯一，任意两种设备的IP地址不能重复。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                         |
|:------------|:-------|:---------------------------------------------------------------------------------------------|
| DEVAID      | 设备地址标识 | 可选必选说明：必选参数 参数含义：用于标识一条NTS设备地址信息数据记录。 取值范围：0～7 默认值：无。 配置原则：无。                                |
| VPNINDEX    | VPN索引  | 可选必选说明：必选参数 参数含义：用于指定一个NTS VPN实体，该参数必须先由ADD NTSVPN命令定义，然后才能在此索引。 取值范围：0～15 默认值：无。 配置原则：无。    |
| IPVER       | IP版本   | 可选必选说明：必选参数 参数含义：用于指定NTS设备地址的IP版本类型。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。               |
| IP          | IPV4地址 | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV4(IPV4)”时该参数必须配置，用于表示NTS的设备IPv4地址。 取值范围：IPv4地址 默认值：无。 配置原则：无。 |
| IPV6        | IPV6地址 | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV6(IPV6)”时该参数必须配置，用于表示NTS的设备IPv6地址。 取值范围：IPv6地址 默认值：无。 配置原则：无。 |
| DESCRIPTION | 描述     | 可选必选说明：可选参数 参数含义：用于描述NTS设备地址的用途。 取值范围：长度不超过32的字符串 默认值：无。 配置原则：无。                             |

## 使用实例

1. 增加IPv4类型的NTS设备地址信息，“设备地址标识”为“0”，“VPN索引”为“1”，“IP版本”为“IPV4(IPV4)”，“IPV4地址”为“192.168.0.130”，“描述”为“NTS\_IPV4”。

   ```
   ADD NTSDEVADDR: DEVAID=0, VPNINDEX=1, IPVER=IPV4, IP="192.168.0.130", DESCRIPTION="NTS_IPV4";
   ```
2. 增加IPv6类型的NTS设备地址信息，“设备地址标识”为“0”，“VPN索引”为“2”，“IP版本”为“IPV6(IPV6)”，“IPV6地址”为“2001:0db8:3fff:ffff:ffff:ffff:ffff:ffff”，“描述”为“NTS\_IPV6”。

   ```
   ADD NTSDEVADDR: DEVAID=0, VPNINDEX=2, IPVER=IPV6, IPV6="2001:0db8:3fff:ffff:ffff:ffff:ffff:ffff", DESCRIPTION="NTS_IPV6";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释        | 原因分析                                                     | 处理建议                                                                                 |
|------:|:-------------|:---------------------------------------------------------|:-------------------------------------------------------------------------------------|
| 57912 | NTSVPN对象不存在。 | 输入的“VPN索引”不存在。                                           | 执行LST NTSVPN命令查询全部NTS VPN配置信息，记录已存在的“VPN索引”。 执行本命令，重新设置“VPN索引”，并确保和已存在的NTS“VPN索引”相同。 |
| 58107 | 设备地址冲突。      | PMS/NTS/DRS/HLB/DLB/NLF/LDAP设备的IP地址需要唯一，任意两种设备的IP地址不能重复。 | 修改IP地址，重新执行本命令增加设备地址。                                                                |
