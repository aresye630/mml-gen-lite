# 查询链路分配参数（LST LINKASSIGNPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询主用DLB服务分配的比例。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询主用DLB服务分配的比例。

```
LST LINKASSIGNPARA:;
```

```
%%LST LINKASSIGNPARA:;%%
RETCODE = 0  操作成功

操作结果如下:
---------------
DLB比例  =  1/2
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见SET LINKASSIGNPARA命令的参数说明。
