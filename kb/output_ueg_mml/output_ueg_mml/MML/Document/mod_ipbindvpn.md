# 修改接口绑定VPN（MOD IPBINDVPN）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改接口已绑定的VPN。

#### 注意事项

- 该命令执行后立即生效。
- 当参数IFIPADDR不指定时，会清空该接口下原来的IP地址；当参数IFIPADDR指定时，会使用被指定的地址替代原来的地址。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                                                                                                       |
|:-----------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IFNAME     | 接口名      | 可选必选说明：必选参数 参数含义：该参数用于表示绑定VPN的接口名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。接口名称由接口类型+接口编号组成。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。                                                                                                                                 |
| IFIPADDR   | IPv4地址   | 可选必选说明：可选参数 参数含义：该参数用于指定需要配置的IP地址。 数据来源：本端规划 取值范围：IPv4地址类型。0.0.0.0～255.255.255.255。 默认值：无 配置原则：本参数参与自动化配置，请在下发本MML命令前使用DSP OPSASSISTSTATE命令查询自动化配置维护助手autoscaling_autoconfig.py，确保当前设备不在自动化配置过程中。如果当前正在自动化配置过程中，不要做本业务的增删改操作，否则最终生效的配置将不可预期。               |
| SUBNETMASK | IPv4地址掩码 | 可选必选说明：可选参数 参数含义：该参数用于指定需要配置的接口IPv4地址的网络掩码。 数据来源：本端规划 取值范围：IPv4地址类型。0.0.0.0～255.255.255.255。 默认值：无 配置原则：本参数参与自动化配置，请在下发本MML命令前使用DSP OPSASSISTSTATE命令查询自动化配置维护助手autoscaling_autoconfig.py，确保当前设备不在自动化配置过程中。如果当前正在自动化配置过程中，不要做本业务的增删改操作，否则最终生效的配置将不可预期。      |
| VRFNAME    | VPN实例名称  | 可选必选说明：必选参数 参数含义：该参数用于指定接口绑定的VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：本参数参与自动化配置，请在下发本MML命令前使用DSP OPSASSISTSTATE命令查询自动化配置维护助手autoscaling_autoconfig.py，确保当前设备不在自动化配置过程中。如果当前正在自动化配置过程中，不要做本业务的增删改操作，否则最终生效的配置将不可预期。请使用LST L3VPNINST命令查看可用VPN。 |

#### 使用实例

修改接口绑定VPN：

```
MOD IPBINDVPN:IFNAME="Ethernet64/0/3",VRFNAME="vrf1";
```
