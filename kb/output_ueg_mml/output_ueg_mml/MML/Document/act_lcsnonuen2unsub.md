# 去订阅LCS UE无关的N2信息（ACT LCSNONUEN2UNSUB）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

执行该命令可以触发NON-UE去订阅。

#### 注意事项

- 该命令执行后立即生效。
- 该消息会触发LMF发送去订阅消息，且去订阅后会导致正在进行周期定位的用户无法上报定位信息。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                |
|:--------------|:--------|:------------------------------------------------------------------------------------|
| GNODEBID      | 基站ID    | 可选必选说明：可选参数 参数含义：该参数用于指定基站ID。 数据来源：全网规划 取值范围：整型数字类型，取值范围为0~4294967295。 默认值：无 配置原则：无 |
| AMFINSTANCEID | AMF实例标识 | 可选必选说明：可选参数 参数含义：该参数用于指定AMF实例标识。 数据来源：全网规划 取值范围：字符串类型，输入长度范围是1~36。 默认值：无 配置原则：无     |

#### 使用实例

- 不输入参数，则所有基站信息以及全局订阅信息均会去订阅：

  ```
  ACT LCSNONUEN2UNSUB:;
  ```
- 仅输入参数GNODEBID，则会去订阅基于指定GNODEBID进行的订阅：

  ```
  ACT LCSNONUEN2UNSUB: GNODEBID=190041;
  ```
- 仅输入参数AMFINSTANCEID，则所有基站信息以及全局订阅信息中向该AMF进行的订阅均会被去订阅：

  ```
  ACT LCSNONUEN2UNSUB: AMFINSTANCEID="AMF_Instance_0";
  ```
- GNODEBID和AMFINSTANCEID均输入，则会去订阅指定AMF和GNODEBID的订阅：

  ```
  ACT LCSNONUEN2UNSUB: GNODEBID=190041, AMFINSTANCEID="AMF_Instance_0";
  ```
