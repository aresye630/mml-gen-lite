# 查询路由管理消费者订阅信息（DSP RMCONSUMERSUBSCRIBE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询路由管理模块的消费者订阅信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称       | 参数说明                                                                                                                                                                       |
|:--------------|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VPNNAME       | VPN实例名称    | 可选必选说明：可选参数 参数含义：该参数用于表示路由所属VPN的名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                                                                                                |
| VRFINDEX      | VPN实例ID    | 可选必选说明：可选参数 参数含义：该参数用于表示VPN实例ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                                                                              |
| PARTNERID     | Partner ID | 可选必选说明：可选参数 参数含义：该参数用于表示Partner ID。 数据来源：本端规划 取值范围：十六进制整数类型，取值范围为0x0～0xFFFFFFFF。 默认值：无                                                                                     |
| VPID          | VP ID      | 可选必选说明：可选参数 参数含义：该参数用于表示VP ID。 数据来源：本端规划 取值范围：十六进制整数类型，取值范围为0x0～0xFFFFFFFF。 默认值：无                                                                                          |
| ADDRESSFAMILY | 地址族        | 可选必选说明：必选参数 参数含义：该参数用于表示路由所属VPN的地址族。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。ipv6unicast：IPv6单播。 默认值：无                                                                     |
| ALL           | 所有实例       | 可选必选说明：可选参数 参数含义：该参数用于表示是否查询所有实例。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：FALSE                                                                                      |
| PREFIX        | 路由前缀       | 可选必选说明：可选参数 参数含义：该参数用于表示路由前缀。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～41。IPv4地址格式是点分十进制格式，格式为X.X.X.X，IPv6地址格式是32位16进制数，格式为X:X:X:X:X:X:X:X。 默认值：无                                     |
| MASKLEN       | 路由掩码长度     | 可选必选说明：可选参数 参数含义：IPv4场景，该参数用于表示路由的掩码长度；IPv6场景，该参数用于表示路由的前缀长度。 数据来源：本端规划 取值范围：整数类型，取值范围为0～128。ADDRESSFAMILY为ipv4unicast时取值范围0～32，ADDRESSFAMILY为ipv6unicast时取值范围0～128。 默认值：无 |

#### 使用实例

查询路由管理模块的消费者订阅信息：

```
DSP RMCONSUMERSUBSCRIBE:ADDRESSFAMILY=ipv4unicast;
```
