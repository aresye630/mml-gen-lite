# 增加服务范围配置信息(ADD NFSERSCOPE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于PCF向NRF注册时增加网元服务范围配置信息。

通过此命令可以配置一个PCF的服务范围（由各运营商自行定义），实现用户的就近访问，而无需返回归属地的PCF接入。语音场景和“基于漫游地签约的本地分流业务策略控制”场景需要配置此命令。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                     |
|:---------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------|
| GRPNAME  | 组名称    | 可选必选说明：必选参数 参数含义：用于标识一个网元服务范围配置信息所属组的名称。 取值范围：由数字、字母、“-”或“_”组成的长度不超过32的字符串 默认值：无。 配置原则： 该参数可以重复，但和索引组合以后成为全局唯一对象关键字段，组合不能重复。该参数配置时不能取值为“NULL”，否则无法被正常索引。 |
| INDEX    | 索引     | 可选必选说明：必选参数 参数含义：用于标识一个网元服务范围配置信息在组内的唯一一条记录。 取值范围：1~1024 默认值：无。 配置原则：该参数在不同的组名称下可以重复，但和组名称组合以后成为全局唯一对象关键字段，组合不能重复。                                       |
| SERSCOPE | 服务范围   | 可选必选说明：必选参数 参数含义：用于标识一个网元所属服务范围。 取值范围：长度不超过64的字符串 默认值：无。 配置原则：无。                                                                                         |

## 使用实例

增加一条网元服务范围信息。“组名称”为“nfserscope”，“索引”为“1”，“服务范围”为“gaabbcc”：

```
ADD NFSERSCOPE: GRPNAME="nfserscope", INDEX=1, SERSCOPE="gaabbcc";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
