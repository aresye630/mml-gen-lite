# 查询HLB自动去激活（LST AUTODEAHLB）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询HLB自动去激活配置参数。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询HLB自动去激活配置参数。

```
LST AUTODEAHLB:;
```

```
%%LST AUTODEAHLB:;%%

RETCODE = 0  操作成功  
操作结果如下
------------------------     
            ID  =  1 
自动去激活开关  =  Enable 
  对端故障时长  =  800

(结果个数 = 1)
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET AUTODEAHLB**命令的参数说明。
