# 修改服务发现网元实例信息(MOD UDMDISCNFPROF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改一个服务发现SCP或SEPP网元实例信息。在该命令中，系统通过“网元实例名称”参数来唯一标识服务发现网元实例的名称。

## 注意事项

执行本命令修改SCP/SEPP链路时，如果**DSP UDMHTTPLNK**命令在客户端模式下查询的结果中已经存在相同对端IP地址和对端端口号且对端网元类型为非SCP/SEPP的链路，先确认对端是否存在IP冲突，如果存在，需要先解决IP冲突问题，再执行**RMV HTTPLINK**命令删除该非SCP/SEPP链路。删除链路后执行本命令修改SCP/SEPP链路，操作完成后修改链路1分钟左右生效。

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                              |
|:-------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSNAME    | 网元实例名称 | 可选必选说明：必选参数 参数含义：标识服务发现SCP或SEPP网元实例信息的关键字段。用于指定对哪个服务发现SCP或SEPP网元实例信息进行修改。操作员可以使用LST UDMDISCNFPROF命令查询获得。 取值范围：长度不超过32的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：该参数全局唯一，不能重复。                                     |
| NFPROFILE    | 网元实例信息 | 可选必选说明：可选参数 参数含义：用于标识服务发现SCP或SEPP网元实例的详细信息，该参数为JSON格式。 取值范围：长度不超过8000的字符串。 默认值：无。 配置原则：参考网元实例信息配置中信元“网元实例信息”的格式。 其中nfInstanceID、nfType两个参数必须和ADD UDMDISCNFPROF命令的“网元实例标识”、“网元类型”一致。当需要修改SCP网元实例信息时，scpInfo参数必须配置。 |
| LOCALNFINSID | 本端网元实例 | 可选必选说明：可选参数 参数含义：用于标识SCP或SEPP网元对应的本端网元实例标识（即网元实例在系统中的序号）。 取值范围：长度不超过1024的字符串。 默认值：无。 配置原则： 在配置该参数前，请确认该服务发现本端网元实例已通过ADD UDMNFSRV参数“网元类型”为“UDM(统一数据管理)”时添加，对应的网元实例可通过LST UDMNFSRV查询。多个实例标识用逗号分隔开。该参数至少配置一个网元实例标识。  |

## 使用实例

修改一个服务发现网元实例信息。“网元实例名称”为“scp”，“网元实例信息”为:“{"nfInstanceId" :"33333333-3333-3333-3333-333333333333","scpInfo":{"scpDomainInfoList":{"11111":{"scpFqdn":"huawei1.com","scpIpEndPoints":[{"ipv4Address":"192.168.91.105","ipv6Address":"2001:db8::11","port":8020,"transport":"TCP"}]}}},"nfStatus":"REGISTERED","fqdn" : "huawei.com","nfType":"SCP"}”，“本端网元实例”为“4947a32a-f61b-4bc1-b9da-47c9c8690001”：

```
MOD UDMDISCNFPROF: NFINSNAME="scp", NFPROFILE="{\"nfInstanceId\" :\"33333333-3333-3333-3333-333333333333\",\"scpInfo\":{\"scpDomainInfoList\":{\"11111\":{\"scpFqdn\":\"huawei1.com\",\"scpIpEndPoints\":[{\"ipv4Address\":\"192.168.91.105\",\"ipv6Address\":\"2001:db8::11\", \"port\":8020,\"transport\":\"TCP\"}]}}},\"nfStatus\":\"REGISTERED\",\"fqdn\" : \"huawei.com\",\"nfType\":\"SCP\"}", LOCALNFINSID="4947a32a-f61b-4bc1-b9da-47c9c8690001";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                             | 原因分析                                                                                             | 处理建议                                                                                                      |
|-------:|:----------------------------------|:-------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------|
| 360041 | 参数值不合法。                           | 错误码提示输入的参数不合法或直接输入的“网元实例信息”参数携带中的nfInstanceID、nfType两个参数和ADD UDMDISCNFPROF命令的“网元实例标识”、“网元类型”不一致。 | 重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                 |
| 360184 | LOCALNFINSID未在NFTYPE为UDM的NFSRV中配置 | 在配置“本端网元实例”参数前，需要确认该网元实例已通过ADD UDMNFSRV命令参数“网元类型”为“UDM(统一数据管理)”时添加。                              | 根据实际情况，重新输入参数，请确认该服务发现本端网元实例已通过ADD UDMNFSRV命令参数“网元类型”为“UDM(统一数据管理)”时添加，对应的网元实例可通过LST UDMNFSRV查询。          |
| 360187 | 静态配置不允许修改                         | 当“网元实例信息”对应的“网元类型”为“SCP(服务通信代理)”或“SEPP(安全边缘保护代理)”时，才能修改“网元实例信息”参数的值。                             | 根据实际情况，重新输入参数。请确认本命令的参数“网元实例信息”对应的“网元类型”为“SCP(服务通信代理)”或“SEPP(安全边缘保护代理)”，对应网元实例类型可通过LST UDMDISCNFPROF命令查询。 |
