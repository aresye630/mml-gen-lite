# 查询Sy/N28结果码映射（LST SYTOGXRCMAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询UPCF配置数据库中Sy/N28结果码映射的配置信息。

- 如果需要查询全部Sy/N28结果码映射记录，则不要输入任何参数。
- 如果需要查询指定的Sy/N28结果码映射记录，请输入“SYRC”或其它参数或这些参数的组合。

**说明** 

该命令的最大记录条数为301条（包括5条默认记录）。

## 注意事项

无。

## 使用实例

- 只输入SYRC参数，查询Sy/N28结果码映射记录信息。“Sy/N28接口结果码”为“RC0”。

  ```
  LST SYTOGXRCMAP: SYRC=RC0;
  ```

  ```
  %%LST SYTOGXRCMAP: SYRC=RC0;%%
  RETCODE = 0  操作成功

  操作结果如下:
  -------------
            Sy/N28接口结果码 = SLATimeOut
               CCA消息结果码 = DIAMETER_SUCCESS
  RAR/UpdateNotify消息原因码 = Keep Session Alive
        CreateResponse结果码 = Created
                PCEF主机名称 = NULL
                是否默认记录 = 1
  （结果个数 = 1）

  --- END
  ```
- 不输入任何参数，查询Sy/N28结果码映射记录信息。

  ```
  LST SYTOGXRCMAP:;
  ```

  ```
  %%LST SYTOGXRCMAP:;%%
  RETCODE = 0  操作成功
  操作结果如下:
  -------------
  Sy/N28接口结果码      CCA消息结果码       RAR/UpdateNotify消息原因码             CreateResponse结果码        PCEF主机名      是否默认记录 
  SLATimeOut            DIAMETER_SUCCESS    Keep Session Alive                     Created                     NULL            1
  CounterInfoError      DIAMETER_SUCCESS    Keep Session Alive                     Created                     NULL            1
  EmptySNR              DIAMETER_SUCCESS    Keep Session Alive                     Created                     NULL            1
  DefaultError          DIAMETER_SUCCESS    Keep Session Alive                     Created                     NULL            1
  NoAvailableSyLink     DIAMETER_SUCCESS    Keep Session Alive                     Created                     NULL            1
  （结果个数 = 6）

  --- END
  ```
