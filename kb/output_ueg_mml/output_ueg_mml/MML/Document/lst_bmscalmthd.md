# 查询接收STA响应超时次数的告警阈值（LST BMSCALMTHD）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询接收STA响应超时次数的告警阈值。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

用户要查询BM-SC无响应的应用层告警机制是否生效。

```
LST BMSCALMTHD:;
```

## 输出结果说明

| 输出项名称   | 输出项解释                                           |
|:--------|:------------------------------------------------|
| 告警阈值    | 该参数用于控制等待BM-SC回复STA消息超时次数连续累加到多少时触发BM-SC无响应的告警。 |
| 恢复告警阈值  | 该参数用于控制收到STA消息数累加到多少次恢复BM-SC无响应的告警。             |
