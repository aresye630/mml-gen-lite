# 设置S10路径参数(SET EDGECFGS10GTP)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于配置是否根据ADD EDGEMMEPGWIP配置主动发送S10口echo消息。

#### 注意事项

- 系统初次运行时，会执行系统初始设置值。
- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                  |
|:---------|:---------|:--------------------------------------------------------------------------------------|
| SENDECHO | 发送echo消息 | 可选必选说明：必选参数 参数含义：该参数指示是否发送echo消息。 数据来源：整网规划 取值范围：“OFF(关闭)”“ON(打开)” 系统初始设置值：“OFF(关闭)”。 |

#### 使用实例

设置是否根据ADD EDGEMMEPGWIP配置主动发送S10口echo消息，执行如下命令：

```
SET EDGECFGS10GTP: SENDECHO=ON;
```
