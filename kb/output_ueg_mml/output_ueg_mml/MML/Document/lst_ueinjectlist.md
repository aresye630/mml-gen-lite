# 查询UE灌包白名单（LST UEINJECTLIST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于查询白名单中的UE信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询UE下行灌包功能的白名单：

```
LST UEINJECTLIST:;
```

```
RETCODE = 0  操作成功。

UE 下行灌包白名单
-----------------
  用户标识  =  IMSI
用户ID信息  =  12345678901234
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见SET UEINJECTLIST的参数说明。
