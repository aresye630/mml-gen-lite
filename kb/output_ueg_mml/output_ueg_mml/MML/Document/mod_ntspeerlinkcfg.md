# 修改通知服务对端链路配置信息(MOD NTSPEERLINKCFG)

- 命令功能

- 参数说明

- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令用于修改在配置数据库中的一条通知任务服务对端链路配置信息数据记录。在该命令中，系统通过“链路ID”关键字段来唯一标识一条通知任务服务对端链路配置信息数据记录。

## 注意事项

- 参数“本地角色”不允许修改，如需修改这个参数，可以采用先执行**LST NTSPEERLINKCFG**命令查询“本地角色”对应的“链路ID”，再执行**RMV NTSPEERLINKCFG**命令输入“链路ID”删除链路，最后执行**ADD NTSPEERLINKCFG**命令重新添加新链路的方式处理。
- 参数“对端IP地址”（或“对端IPV6地址”）和“对端端口”必须与参数“SOAP服务器URL”及“认证服务器URL”中包含的IP地址和端口保持一致。
- 如果修改“本端IP地址”（或“本端IPV6地址”）、“对端IP地址”（或“对端IPV6地址”）、“对端端口”、“用户名”、“密码”或“是否支持加密”，重新建链的时间为5分钟。
- 设置“本端IP地址”后，NTS与对端服务器的通信只能使用该命令配置的“本端IP地址”，不能再使用**ADD NTSDEVADDR**命令定义的其他IP地址。
- IPv4类型的IP地址不能配置如下非法IP地址：“127.0.0.1”、“0.0.0.0”、“255.255.255.255”、“224.0.0.1”。
- IPv6类型的IP地址不支持混合方式表达，即xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:d.d.d.d，其中x表示一个十六进制数（0～9或A～F），而d.d.d.d表示一个IPv4地址。
- IPv6类型的IP地址不支持以下特殊地址的配置，其中x表示一个十六进制数（0～9或A～F）：

  - 0000:0000:0000:0000:0000:0000:0000:0000
  - FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF
  - 0000:0000:0000:0000:0000:0000:0000:0001
  - FFxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE8x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE9x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEAx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEBx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx

## 使用实例

修改一条通知任务服务对端链路的配置信息，“链路ID”为“1”，“本地角色”为“CMPPClient(CMPP客户端)”，“IP版本”为“IPV4(IPV4)”，“对端IP地址”修改为“10.1.111.77”，“对端端口”修改为“2089”，其他参数使用缺省值。

```
MOD NTSPEERLINKCFG: LINKID=1, LOCALROLE=CMPPClient, IPVER=IPV4, PEERIP="10.1.111.77", PEERPORT=2089;
```
