# 修改远端用户数据同步服务器（MOD RDATASYNSERVER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UDM**

该命令用于修改数据自动同步远端配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                                 |
|:-------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVERNAME   | 服务器名称  | 可选必选说明：必选参数 参数含义：远端用户数据同步服务器名称。 数据来源：本端规划 取值范围：由数字、字母和下划线组成的不超过16位的字符串。 默认值：无 配置原则： 该参数使用ADD RDATASYNSERVER命令配置生成。由数字、字母和下划线组成的不超过16位的字符串。                                                                                           |
| GROUPID      | 服务器组ID | 可选必选说明：可选参数 参数含义：服务器所属的服务器组ID。 数据来源：本端规划 取值范围：1～1。 默认值：无 配置原则：1~1。                                                                                                                                                                   |
| PRIORITY     | 服务器优先级 | 可选必选说明：可选参数 参数含义：用于指定服务器在服务器组内的优先级。 数据来源：对端协商 取值范围：1~255。 默认值：无 配置原则：无                                                                                                                                                               |
| PROTOCOL     | 传输协议类型 | 可选必选说明：可选参数 参数含义：用于指定远端服务器支持的传输协议类型。 数据来源：对端协商 取值范围： SFTP：SFTP。 默认值：无 配置原则：无                                                                                                                                                         |
| SERVERPORT   | 服务端端口  | 可选必选说明：可选参数 参数含义：用于指定远端SFTP服务器的端口号。 数据来源：对端协商 取值范围：1~65535。 默认值：无 配置原则：1~65535。                                                                                                                                                      |
| USERNAME     | 用户名称   | 可选必选说明：可选参数 参数含义：用于指定SFTP用户名。 数据来源：对端协商 取值范围：长度不超过31位的字符串。不支持空格。区分大小写。 默认值：无 配置原则： 输入单空格将删除该参数已有配置项。长度不超过31位的字符串。不支持空格。区分大小写。                                                                                                        |
| AUTHTYPE     | 认证模式   | 可选必选说明：可选参数 参数含义：用于指定SFTP登录的认证模式。 数据来源：对端协商 取值范围： PASSWORD：密码认证。PUBLICKEY：公钥认证。 默认值：无 配置原则：无                                                                                                                                         |
| PWD          | 密码     | 可选必选说明：条件必选参数 前提条件：该参数在“AUTHTYPE”配置为“PASSWORD”时为必选参数。 参数含义：用于指定登录远端SFTP服务器的密码。 数据来源：对端协商 取值范围：密码类型，输入长度范围为1～109。不加密输入时，长度范围是1～63；加密输入时，长度为108。不支持空格，区分大小写。 默认值：无 配置原则：密码类型，输入长度范围为1～109。不加密输入时，长度范围是1～63；加密输入时，长度为108。不支持空格，区分大小写。   |
| PWDCFM       | 确认密码   | 可选必选说明：条件必选参数 前提条件：该参数在“AUTHTYPE”配置为“PASSWORD”时为必选参数。 参数含义：用于指定登录远端SFTP服务器的确认密码。 数据来源：对端协商 取值范围：密码类型，输入长度范围为1～109。不加密输入时，长度范围是1～63；加密输入时，长度为108。不支持空格，区分大小写。 默认值：无 配置原则：密码类型，输入长度范围为1～109。不加密输入时，长度范围是1～63；加密输入时，长度为108。不支持空格，区分大小写。 |
| RWORKDIR     | 远端工作目录 | 可选必选说明：可选参数 参数含义：用于指定远端SFTP服务器上的工作目录。 数据来源：对端协商 取值范围：长度不超过127的字符串，字符串不能包含特殊字符：逗号，分号，等号，双引号，单引号和小数点，区分大小写。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。                                                                                               |
| DETECTSWITCH | 探测开关   | 可选必选说明：可选参数 参数含义：该参数用于指定服务器探测功能开关，仅当SET EDGEDSPOLICY命令中“开关”取值为ENABLE时，该参数生效。 数据来源：本端规划 取值范围： ENABLE：使能。DISABLE：去使能。 默认值：无 配置原则：无                                                                                                     |

#### 使用实例

将服务器名为rdata1的远端数据同步配置组id改为2：

```
MOD RDATASYNSERVER: SERVERNAME="rdata1", PRIORITY=2;
```
