# 删除NRF公钥 （RMV NRFKEY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致业务处理受损，需联系华为技术支持确认后再执行。

该命令用于删除一条已添加的NRF公钥配置信息。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                          |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------|
| NRFKEYID | 公钥ID   | 可选必选说明：必选参数。 参数含义：指定一条NRF公钥在系统内的唯一标识，用于指定需要删除哪一条NRF公钥配置数据记录，操作员可以使用LST NRFKEY命令查询获得。 取值范围：1～32 默认值：无。 配置原则：无。 |

## 使用实例

删除一个“公钥ID”为“11”的NRF公钥。

```
RMV NRFKEY: NRFKEYID=11;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
