# 查询报表服务系统软参(LST DRSSSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询DRS系统软件参数的配置信息。

- 若需要查询全部软参数据记录的概要信息，请不要输入任何参数。
- 若需要查询某条参数数据记录的详细信息，请输入“系统配置参数”和“参数名”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                                             |
|:-------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SCP    | 系统配置参数  | 可选必选说明：可选参数 参数含义：用于指示系统按照系统配置参数来查询DRS系统软参；若不输入，则表示所有的系统配置参数。 取值范围： SYSPARAMETER(系统参数) 默认值：无。 配置原则：无。                                                                             |
| SPN    | 参数名     | 可选必选说明：可选参数 参数含义：用于指示系统按照参数名来查询DRS系统软参；若不输入，则表示所有的参数名。 取值范围： VRM_DRSREDUNDANCYSWITCH(DRS容灾开关)VRM_DRSSFTPCLIENTACSWITCH(DRS SFTP客户端算法兼容开关)VRM_DRSWORKMODE(DRS工作模式) 默认值：无。 配置原则：无。 |
| SPV    | 参数值     | 可选必选说明：可选参数 参数含义：用于指示系统按照参数值来查询DRS系统软参；若不输入，则表示所有的参数值。请参考产品手册的“DRS系统软参”。 取值范围：0-2147483647。 默认值：无。 配置原则：无。                                                                       |
| DFTV   | 软件参数默认值 | 可选必选说明：可选参数 参数含义：用于指示系统按照软件参数默认值来查询DRS系统软参；若不输入，则表示所有的软件参数默认值。 默认值：无。 配置原则：无。                                                                                                    |

## 使用实例

1. 查询DRS系统全部软参配置信息。

   ```
   LST DRSSSP:;
   ```

   ```
   %%LST DRSSSP:;%%
   RETCODE = 0  操作成功
   操作结果如下: 
   ------------- 
   系统配置参数  参数名                           参数值  软件参数默认值              
   系统参数      DRS容灾开关                       0       0
   系统参数      DRS SFTP客户端算法兼容开关        0       0
   系统参数      DRS工作模式                       0       0
   (结果个数 = 3)
     
   ---    END
   ```
2. 查询“DRS容灾开关”参数。“系统配置参数”为“SYSPARAMETER(系统参数)”，“参数名”为“VRM\_DRSREDUNDANCYSWITCH(DRS容灾开关)”。

   ```
   LST DRSSSP: SCP=SYSPARAMETER, SPN=VRM_DRSREDUNDANCYSWITCH;
   ```

   ```
   %%LST DRSSSP: SCP=SYSPARAMETER, SPN=VRM_DRSREDUNDANCYSWITCH;%%
    RETCODE = 0  操作成功
    操作结果如下: 
   -------------
      系统配置参数  =  系统参数
            参数名  =  DRS容灾开关
            参数值  =  0
    软件参数默认值  =  0 
   (结果个数 = 1)  

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见参数说明。
