# 查询支持DHCP服务的GGSN IP地址（LST DHCPGIP）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用网元：SGSN**

1. 该命令用于查询支持DHCP服务的GGSN IP地址。
2. SGSN支持用户采用DHCP方式接入，在采用DHCP接入方式时，不需要对APN进行DNS解析，只需要在SGSN中配置支持DHCP服务的GGSN IP地址即可。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称        | 参数说明                                                                                                    |
|:-------|:------------|:--------------------------------------------------------------------------------------------------------|
| IPT    | IP地址类型      | 可选必选说明：可选参数 参数含义：该参数用于指定IP地址类型 数据来源：整网规划 取值范围：“IPV4(IPV4)”、“IPV6(IPV6)”、“IPV4V6(IPV4V6)” 默认值： 无         |
| IPV4   | GGSN IPv4地址 | 可选必选说明：条件可选参数 参数含义：该参数用于指定GGSN IPv4地址。 数据来源：整网规划 取值范围：0.0.0.0～255.255.255.255 默认值： 无                    |
| IPV6   | GGSN IPv6地址 | 可选必选说明：条件可选参数 参数含义：该参数用于指定GGSN IPv6地址。 数据来源：整网规划 取值范围：::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值： 无 |

#### 使用实例

查询所有支持DHCP的GGSN IP地址：

`LST DHCPGIP:;`

```
%%LST DHCPGIP:;%%
RETCODE = 0  Execution succeeded

-----------------------------

  GGSN IPv4地址  =  192.168.22.22
  GGSN IPv6地址  =  NULL
           描述  =  NULL
(结果个数  = 1)
---    END
```
