# 查询局向流控配置(LST MFLOWCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明
- 参考信息

## 命令功能

该命令为维护类命令，查询一个局向流控配置。

## 注意事项

无。

## 参数说明

| 参数ID          | 参数名称          | 参数描述                                                                                                                                                                                                     |
|:--------------|:--------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PCRFID        | PCRF实体ID      | 用于标识PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围：1 默认值：无。                                                                                                                                                  |
| PEERTYPE      | PCRF对端实体类型    | 用于标识PCRF对端实体类型。 取值说明： PCEFDRAAFTDF 默认值：无。                                                                                                                                                                |
| PEERID        | PCRF对端实体ID    | 用于标识PCRF对端实体，该参数必须先由ADD PPCEF、ADD PEER或者ADD PAF命令定义，然后才能在此处索引。 取值范围：0～1023 默认值：无。                                                                                                                        |
| INTERFACETYPE | 接口类型          | 用于标识PCRF对端接口类型。 取值说明： GxRx 默认值：无。                                                                                                                                                                        |
| FLOWCTRL      | 流量控制开关        | 用于设定是否进行局向流控。 取值说明： OFF(关闭流控)ON(打开流控) 默认值：OFF。                                                                                                                                                           |
| CCRINUM       | 每秒最大CCR_I消息数量 | 用于设定每秒该局向在每个DLB上允许通过的最大CCR_I消息数量，超过此数量的CCR_I消息将被丢弃。 取值范围：0～1000000 默认值：无。                                                                                                                                |
| CCRUNUM       | 每秒最大CCR_U消息数量 | 用于设定每秒该局向在每个DLB上允许通过的最大CCR_U消息数量，超过此数量的CCR_U消息将被丢弃。 取值范围：0～1000000 默认值：无。                                                                                                                                |
| CCRTNUM       | 每秒最大CCR_T消息数量 | 用于设定每秒该局向在每个DLB上允许通过的最大CCR_T消息数量，超过此数量的CCR_T消息将被丢弃。 取值范围：0～1000000 默认值：无。                                                                                                                                |
| AARINUM       | 每秒最大AAR-I消息数量 | 用于设定每秒该局向在每个DLB上允许通过的最大AAR_I消息数量，超过此数量的AAR_I消息将被丢弃。 取值范围：0～1000000 默认值：无。  说明： Rx接口消息流控时，Rx-Request-Type AVP取值为“PCSCF_RESTORATION (2)”的AAR消息和Rx-Request-Type AVP取值为“INITIAL_REQUEST (0)”的AAR_I消息为同样的优先级。 |

## 使用实例

1. 查询一个局向流控配置。“PCRF实体ID”为“1”，“PCRF对端实体类型”为“PCEF”，“PCRF对端实体ID”为“0”。

   ```
   LST MFLOWCTRL: PCRFID=1, PEERTYPE=PCEF, PEERID=0;
   ```

   ```
   %%LST MFLOWCTRL: PCRFID=1, PEERTYPE=PCEF, PEERID=0;%%
   RETCODE = 0  操作成功

   操作结果如下:
   ------------------------
              PCRF实体ID  =  1
        PCRF对端实体类型  =  PCEF
               接口类型   =  Gx
           PCRF对端实体ID =  0
            流量控制开关  =  打开流控
   每秒最大CCR_I消息数量  =  800
   每秒最大CCR_U消息数量  =  1600
   每秒最大CCR_T消息数量  =  1600
   每秒最大AAR-I消息数量  =  NULL
   (结果个数 = 1)

   ---    END
   ```
2. 查询所有局向流控配置。

   ```
   LST MFLOWCTRL:;
   ```

   ```
   %%LST MFLOWCTRL:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
    PCRF实体ID  PCRF对端实体类型  接口类型  PCRF对端实体ID  流量控制开关  每秒最大CCR_I消息数量  每秒最大CCR_U消息数量  每秒最大CCR_T消息数量  每秒最大AAR-I消息数量

    1           PCEF              Gx        1               打开流控      100                    200                    300                    NULL	
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
