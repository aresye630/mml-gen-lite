# 查询存储bypass模式下系统运行模式配置信息(DSP BYPASSRM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询存储bypass模式下服务整局状态的配置信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询系统的运行模式配置信息：

```
%%DSP BYPASSRM:;%%
RETCODE = 0  操作成功
 
查询结果如下
------------
Bypass模式系统运行状态  =  激活模式
(结果个数 = 1)
 
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET BYPASSRM** 命令的参数说明。
