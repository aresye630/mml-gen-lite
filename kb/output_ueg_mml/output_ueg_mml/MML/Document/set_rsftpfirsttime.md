# 首次认证使能（SET RSFTPFIRSTTIME）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UDM**

该命令用于首次认证使能。

#### 注意事项

- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | FIRSTTIMEENABLE   |
|:-------|:------------------|
| 初始值    | DISABLE           |

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                         |
|:----------------|:-------|:-----------------------------------------------------------------------------|
| FIRSTTIMEENABLE | 首次认证使能 | 可选必选说明：必选参数 参数含义：首次认证使能。 数据来源：本端规划 取值范围： DISABLE：去使能。ENABLE：使能。 默认值：无 配置原则：无 |

#### 使用实例

使能远端用户数据同步首次认证：

```
SET RSFTPFIRSTTIME:FIRSTTIMEENABLE= ENABLE;
```
