# 删除LAIVLR黑名单(RMV LAIVLRBLACKLIST)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于删除LAI与VLR的黑名单对应关系。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                            |
|:-------|:-------|:------------------------------------------------------------------------------------------------|
| VN     | VLR号   | 可选必选说明：必选参数 参数说明：该参数用于表示位置区对应的VLR号码。 数据来源：整网规划 取值范围： 1～15位十进制数字 默认值：无                           |
| BGNLAI | LAI    | 可选必选说明：必选参数 参数说明：该参数是指对应一个VLR号的LAI黑名单的起始位置区，由“MCC”、“MNC”和“LAC”组成。 数据来源：整网规划 取值范围：9~10位的数字 默认值：无 |

#### 使用实例

删除起始LAI为"308013101"的LAI区间与VLR为"12345678912"的黑名单对应关系：

RMV LAIVLRBLACKLIST: VN="12345678912", BGNLAI="308013101";
