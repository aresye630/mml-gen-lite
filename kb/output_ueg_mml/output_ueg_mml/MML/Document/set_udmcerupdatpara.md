# 设置证书更新流程参数（SET UDMCERUPDATPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于设置HLB服务的证书更新流程配置信息。

为提升证书替换效率，减小证书替换对业务影响，网元在收到证书替换通知时，除获取证书外，需同步完成使用证书的通信链路拆链再建链，同时保证处理过程中链路中断时间在业务可接受范围内。当前UDM的证书主要是在HLB建链过程中使用，证书的更新会通过CSP下发到HLB服务，HLB完成证书更新及拆链、重建链等动作。

最终更新时长 = [HLB链路数(系统中链路数最大的HLB) / 更新链路数量] \* 更新间隔 + 平面更新等待时长

**说明** 

系统最终更新时长不能超过40分钟，超时后系统会提示更新失败。

## 注意事项

- 证书更新流程配置信息设置不当，会导致业务处理异常，因此需要与华为技术支持确认后才可以操作。
- 当链路数较少的场景时，可通过此命令调整证书更新流程配置信息；当链路数较多的场景时，建议使用默认值。

## 参数说明

| 参数标识           | 参数名称        | 参数说明                                                                                                                            |
|:---------------|:------------|:--------------------------------------------------------------------------------------------------------------------------------|
| PROINTERVAL    | 更新间隔        | 可选必选说明：可选参数 参数含义：用于标识单个HLB服务每批次链路的更新间隔的能力。 取值范围：3～500，单位：秒 默认值：3 配置原则：无。                                                        |
| PROLINKNUM     | 更新链路数量      | 可选必选说明：可选参数 参数含义：用于标识单个HLB服务每批次更新的链路数的能力。 取值范围：5～500 默认值：10 配置原则：无。                                                             |
| ACTIVEOLDLINK  | 更新证书时是否拆除链路 | 可选必选说明：可选参数 参数含义：用于标识HLB服务在证书更新过程中是否拆除链路。 取值范围： YES(是)：拆除链路NO(否)：不拆除链路 默认值：YES(是) 配置原则：无。                                       |
| PLAUPGINTERVAL | 平面更新等待时长    | 可选必选说明：可选参数 参数含义：用于标识HLB服务更新链路时，两个平面分别更新时中间等待的时长。HLB服务更新链路时分两个平面，系统优先更新0平面上链路，等待一定时间后再更新1平面上的链路。 取值范围：0～500，单位：秒 默认值：30 配置原则：无。 |

## 使用实例

设置HLB服务的“更新间隔”为“3”，“更新链路数量”为“10”,“更新证书时否拆除链路”为“YES(是)”,“平面更新等待时长”为“30”：

```
SET UDMCERUPDATPARA：PROINTERVAL=3, PROLINKNUM=10, ACTIVEOLDLINK=YES, PLAUPGINTERVAL=30;
```
