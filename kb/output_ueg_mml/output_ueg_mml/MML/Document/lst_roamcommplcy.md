# 查询漫游通信策略（LST ROAMCOMMPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF、SMF、NWDAF、NEF、SCF**

该命令用于显示漫游通信策略信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

运营商需要查询漫游通信策略；

```
%%LST ROAMCOMMPLCY:;%%
RETCODE = 0  操作成功

结果如下
------------------------
漫游路由模式 = 通过SEPP通信
信令汇聚模式 = Http Proxy
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                      |
|:--------|:-------------------------------------------|
| 漫游路由模式  | 该参数用于指定漫游路由模式。                             |
| 信令汇聚模式  | 该参数用于指定漫游信令汇聚模式。仅在ROUTEMODE设置为SEPP或SCP时生效。 |
