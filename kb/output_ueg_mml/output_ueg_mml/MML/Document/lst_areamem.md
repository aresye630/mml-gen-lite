# 查询跟踪区成员（LST AREAMEM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询指定区域或者系统中配置的所有区域的跟踪区成员。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                          |
|:---------|:-------|:------------------------------------------------------------------------------------------------------------------------------|
| AREACODE | 区域编码   | 可选必选说明：可选参数  参数含义：该参数用于标识AMF服务的某区域范围。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~128。  默认值：无  配置原则：  AREACODE参数依赖于AREACODE命令的AREACODE参数。 |

## 使用实例

- 查询编码为“jq001.pd006.sh.mcc123.mnc45”的区域成员信息，执行如下命令：

  ```
  %%LST AREAMEM: AREACODE="jq001.pd006.sh.mcc123.mnc45";%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
           区域编码  =  jq001.pd006.sh.mcc123.mnc45
                MCC  =  460
                MNC  =  03
   跟踪区编码起始值  =  120101
   跟踪区编码结束值  =  120101
           描述信息  =  NULL
  (结果个数 = 1)

  ---    END
  ```
- 查询系统中当前配置的所有区域的信息，执行如下命令：

  ```
  %%LST AREAMEM:;%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
           区域编码  =  jq001.pd006.sh.mcc123.mnc45
                MCC  =  460
                MNC  =  03
   跟踪区编码起始值  =  120101
   跟踪区编码结束值  =  120101
           描述信息  =  NULL
  (结果个数 = 1)

  ---    END
  ```

## 输出结果说明

| 输出项名称    | 输出项解释                                   |
|:---------|:----------------------------------------|
| 区域编码     | 该参数用于标识AMF服务的某区域范围。                     |
| MCC      | 该参数用于表示组成通用区域的位置区成员的移动国家码，与无线接入网的MCC一致。 |
| MNC      | 该参数用于表示组成通用区域的位置区成员的移动网号，与无线接入网的MNC一致。  |
| 跟踪区编码起始值 | 该参数用于表示跟踪区编码的起始值。                       |
| 跟踪区编码结束值 | 该参数用于表示跟踪区编码的结束值。                       |
| 描述信息     | 该参数是对区域成员的描述信息，在运维中起到助记的作用。             |
