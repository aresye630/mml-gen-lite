## 命令功能

用于在配置数据库中增加一条TDF目的域名。

该命令的使用场景：当UPCF通过DRA与TDF对接的场景下，该命令用于指定目的TDF所在域的域名。用户上线时，UPCF发送TSR（TDF-Session-Request）消息与对端TDF建立Sd会话时，DRA设备根据UPCF发送TSR消息中的目的域名，将对应的TSR消息发送给对应的TDF对端。

## 注意事项

本命令支持最多添加512条域名配置记录。

## 参数说明

| 参数标识          | 参数名称     | 参数描述                                                                                                                        |
|:--------------|:---------|:----------------------------------------------------------------------------------------------------------------------------|
| PCRFID        | PCRF标识   | 用于定义PCRF实体标识，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围：1 默认值：无。                                                                   |
| REALMID       | 目的域名ID   | 用于定义TDF所在域的域名ID。 取值范围：0～511 默认值：无。                                                                                          |
| APPTYPE       | 目的域应用类型  | 用于定义TDF的应用类型。 取值范围：TDF（TDF）：当使用的TDF种类都不同时，本参数可以配置为“TDF（TDF）”，此时必须要配置“目的域名”。DefaultTDF（DefaultTDF）：TDF都是一类时，不用配置目的域名。 默认值：无。 |
| DEN           | 对端名称     | 用于定义对端的名称，以便于识别。 取值范围：长度不超过128的字符串 默认值：无。                                                                                   |
| DRN           | 目的域名     | 用于定义TDF对端的目的域名。 取值范围：长度不超过64的字符串 默认值：无。                                                                                     |
| ABILITYDICTID | 能力字典ID   | 用于定义TDF对端的能力字典ID。 取值范围：0～127 默认值：无。                                                                                         |
| PCEFCAT       | 对端PCEF类别 | 对端PCEF实体的类别，只在多PCEF场景下使用，该参数由ADD PPCEFCAT命令定义，然后才能在此处索引。 取值范围：长度不超过16字节的字符串 默认值：无。                                          |

## 使用实例

在开局场景下，当完成与DRA对接后，执行如下命令，配置UPCF与TDF目的域名，“PCRF标识”为“1”，“目的域名ID”为“50”，“目的域应用类型”为“TDF”，“目的域名”为“Huawei\_01”，“能力字典ID”为“58”。

```
ADD PDREALMCFG: PCRFID=1, REALMID=50, APPTYPE=TDF, DRN="Huawei_01", ABILITYDICTID=58;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                                         | 原因分析                                                | 处理建议                                                                                          |
|------:|:----------------------------------------------|:----------------------------------------------------|:----------------------------------------------------------------------------------------------|
| 57624 | 目的域名ID已经在使用。                                  | 历史操作中，目的域名ID已经定义。                                   | 执行LST PDREALMCFG查询该目的域名ID的配置信息并根据查询结果确认是否需要添加新的配置数据。                                          |
| 57625 | 目的域名已经在使用。                                    | 历史操作中，目的域名已经定义。                                     | 执行LST PDREALMCFG查询该目的域名的配置信息并根据查询结果确认是否需要添加新的配置数据。                                            |
| 57626 | “目的域应用类型”为“DefaultTDF（DefaultTDF）”的目的域只能添加一个。 | 历史操作中，“目的域应用类型”为“DefaultTDF（DefaultTDF）”的目的域只能添加一个。 | 执行LST PDREALMCFG查询当前“目的域应用类型”为“DefaultTDF（DefaultTDF）”的目的域配置，根据查询结果确认是否需要变更当前DefaultTDF的配置信息。 |
