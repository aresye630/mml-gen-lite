# 设置数据同步客户端支持的消息认证算法（SET RDATACLIENTHMACALGOS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于设置数据同步客户端支持的消息认证算法。在登陆远端数据同步服务器时，本地客户端和对端服务器协商消息认证算法。协商会选择服务器和客户端都支持的算法。如果服务器和客户端没有相同的算法，则协商失败。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 可选参数至少配置一个。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | HMAC_SHA2_256   | HMAC_SHA2_256_ETM_OPENSSH   |
|:-------|:----------------|:----------------------------|
| 初始值    | True            | True                        |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识                      | 参数名称                                | 参数说明                                                                                                                                                                              |
|:--------------------------|:------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HMAC_SHA2_256             | hmac-sha2-256消息认证算法                 | 可选必选说明：可选参数 参数含义：本参数用于指定hmac-sha2-256消息认证的开启或者关闭。 数据来源：本端规划 取值范围：true:开启hmac-sha2-256消息认证 false:关闭hmac-sha2-256消息认证。 默认值：无 配置原则：无                                                 |
| HMAC_SHA2_256_ETM_OPENSSH | hmac-sha2-256-etm@openssh.com消息认证算法 | 可选必选说明：可选参数 参数含义：本参数用于指定hmac-sha2-256-etm@openssh.com消息认证的开启或者关闭。 数据来源：本端规划 取值范围：true:开启hmac-sha2-256-etm@openssh.com消息认证 false:关闭hmac-sha2-256-etm@openssh.com消息认证。 默认值：无 配置原则：无 |

#### 使用实例

设置数据同步客户端支持的消息认证算法，开启HMAC\_SHA2\_256和HMAC\_SHA2\_256\_ETM\_OPENSSH密钥交换算法：

```
SET RDATACLIENTHMACALGOS: HMAC_SHA2_256=TRUE, HMAC_SHA2_256_ETM_OPENSSH= TRUE;
```
