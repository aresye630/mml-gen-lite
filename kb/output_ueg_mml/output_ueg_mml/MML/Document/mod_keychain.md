# 修改Keychain的配置（MOD KEYCHAIN）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改Keychain的全局属性。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

修改Keychain ospf的接收容错时长为无限，时间模式UTC：

```
MOD KEYCHAIN:KEYCHAINNAME="ospf",TIMEMODE=UTC,RECVTOLTYPE=INFINITE;
```
