# 设置HTTP客户端链路（SET NCSHTTPCLINK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令用于设置HTTP客户端链路信息。

该命令的使用场景：当PCF与对端对接的场景下，该命令用于修改PCF与对端的HTTP客户端链路的链路管理状态。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                            |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFTYPE | NF类型   | 可选必选说明：必选参数 参数含义：用于表示PCF对端NF类型。操作员可以使用DSP NCSHTTPCLINK命令查询获得。 取值范围： NRF(NRF)AMF(AMF)SMF(SMF)BSF(BSF)CHF(CHF)AF(AF)SCP(SCP)UDR(UDR)NWDAF(NWDAF)HPCF(HPCF) 默认值：无。 配置原则：无。                                         |
| PEERID | 对端标识   | 可选必选说明：必选参数 参数含义：用于表示PCF对端标识。操作员可以使用DSP NCSHTTPCLINK命令查询获得。 取值范围：0~1023 默认值：无。 配置原则：无。                                                                                                                          |
| LINKID | 链路标识   | 可选必选说明：必选参数 参数含义：用于表示HTTP客户端链路标识。操作员可以使用DSP NCSHTTPCLINK命令查询获得。 取值范围：0~127 默认值：无。 配置原则：无。                                                                                                                       |
| ADSTS  | 链路管理状态 | 可选必选说明：可选参数 参数含义：用于指定链路的管理状态。 取值范围： DISABLE (去使能)ENABLE (使能) 默认值：无。 配置原则：当“链路管理状态”为“去使能”时，建立的链路是无法连通的。  说明： 如果使用该命令将指定链路的“链路管理状态”设置为了“去使能”，则该链路无法根据SET HTTPCLIENTCFG命令的配置进行链路重建。主NCS重启后，链路的“链路管理状态”会被重新设置为“使能”。 |

## 使用实例

设置SMF对端HTTP客户端链路信息，“对端标识”为“21”，“链路标识”为“12”，“链路管理状态”为“ENABLE (使能)” 。

```
SET NCSHTTPCLINK: NFTYPE=SMF, PEERID=21, LINKID=12, ADSTS=ENABLE;
```
