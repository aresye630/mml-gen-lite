# 删除报表服务对端服务器(RMV DRSPEER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除在配置数据库中的一条报表服务对端服务器的数据记录。

## 注意事项

如果对端服务器已经被DRS链路引用，需要先删除关联的DRS链路，否则删除对端服务器失败。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                  |
|:-------|:--------|:----------------------------------------------------------------------------------------------------------------------|
| PEERID | 对端服务器ID | 可选必选说明：必选参数 参数含义：标识一条报表服务对端服务器的数据记录的关键字段，用于指定需要删除哪一条报表服务对端服务器的数据记录，操作员可以使用LST DRSPEER命令查询获得。 取值范围：1～32 默认值：无。 配置原则：无。 |

## 使用实例

删除一条报表服务对端服务器的数据记录，“对端服务器ID”为“1”。

1. 使用**LST DRSPEERLINKCFG**命令查询“对端服务器ID”被DRS链路引用：

   ```
   %%LST DRSPEERLINKCFG: LINKID=1;%% 
   RETCODE = 0  操作成功  
   操作结果如下:
   -------------
              链路ID  =  1
        对端服务器ID  =  1
            本地角色  =  FTP客户端
              IP版本  =  IPV4
          本端IP地址  =  10.0.0.0
        本端IPV6地址  =  NULL
          对端IP地址  =  10.255.255.211
        对端IPV6地址  =  NULL
            对端端口  =  8080
              用户名  =  root
                密码  =  *****
   FTP服务器日志路径  =  temp/
                描述  =  NULL
        链路管理状态  =  使能
   (结果个数 = 1)
   ---    END
   ```
2. 执行**RMV DRSPEERLINKCFG**命令删除关联的链路：

   ```
   %%RMV DRSPEERLINKCFG: LINKID=1, CONFIRM=Y;%%
   RETCODE = 0  操作成功
   ---    END
   ```
3. 删除DRS对端服务器，“对端服务器ID”为“1”：

   ```
   RMV DRSPEER: PEERID=1;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释            | 原因分析                                   | 处理建议                                                                                           |
|------:|:-----------------|:---------------------------------------|:-----------------------------------------------------------------------------------------------|
| 57987 | 对端服务器对象被引用，不能删除。 | 需要删除的对端服务器已经通过命令ADD DRSPEERLINKCFG被引用。 | 执行命令LST DRSPEERLINKCFG，查询引用该对端服务器对象的链路。执行命令RMV DRSPEERLINKCFG删除引用该对端服务器对象的链路。重新执行本命令删除对端服务器对象。 |
