# 查询内容过滤全局开关（LST GLBCFFUNC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

查询内容过滤全局开关。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询内容过滤全局开关：

```
LST GLBCFFUNC:;
```

```
RETCODE = 0  操作成功

内容过滤全局开关
----------------
                         内容过滤全局开关  =  使能（开启）
单POD向同一个服务器发送Reqmod消息的链路数  =  1
(结果个数 = 1)

---    END
```
