# 删除S1模式实时小区位置订阅(RMV S1LOCRPT)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

此命令用于删除S1模式实时小区位置订阅。

#### 注意事项

- 此命令执行后立即生效。但是当前正在进行的订阅流程不受影响，等到用户切换到空闲态后自动取消订阅。
- 此命令用来取消对UE的实时小区位置的订阅，若无需继续上报CHR单据给vSCEF，还需要同时通过CHR的相关命令如 **SET CHRCFG**命令来取消对Location Report流程的CHR单据订阅。否则可能有其他触发源（PCRF，HSS或LCS）发出的Location Report流程的CHR单据继续上报。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                     |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------|
| AREA   | 区域范围   | 可选必选说明：必选参数 参数含义：该参数用于指定待删除的区域范围。 数据来源：整网规划 取值范围： “TA(指定跟踪区)”：表示该区域标识类型为跟踪区。 默认值：无  说明： 区域范围表示进行实时位置订阅所适用的位置区域。区域范围目前只支持跟踪区粒度的范围。相同粒度区域范围的各记录的区域码区段不能交叠。 |
| MCC    | 移动国家码  | 可选必选说明：条件必选参数 参数含义：该参数用于指定待删除的移动国家代码。 前提条件：该参数在“AREA(区域范围)”设置为“TA(指定跟踪区)”时，才需要配置。 数据来源：整网规划 取值范围：3位的十进制数字 默认值：无                                          |
| MNC    | 移动网号   | 可选必选说明：条件必选参数 参数含义：该参数用于指定待删除的移动网号。 前提条件：该参数在“AREA(区域范围)”设置为“TA(指定跟踪区)”时，才需要配置。 数据来源：整网规划 取值范围：2～3位的十进制数字 默认值：无                                          |
| TAC    | 跟踪区域码  | 可选必选说明：条件必选参数 参数含义：该参数用于指定待删除的跟踪区域码。 前提条件：该参数在“AREA(区域范围)”设置为“TA(指定跟踪区)”时，才需要配置。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无                                      |

#### 使用实例

删除一条S1模式实时小区位置订阅记录，区域范围为TA，移动国家码为111，移动网号为222，跟踪区域码为0x3333：

RMV S1LOCRPT: AREA=TA, MCC="111", MNC="222", TAC="0x3333";
