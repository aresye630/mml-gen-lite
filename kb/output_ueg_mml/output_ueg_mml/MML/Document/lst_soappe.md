# 查询SOAP对端(LST SOAPPE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于查询系统中SOAP对端记录：

- 若需要查询所有SOAP对端配置信息，请不要输入任何参数。
- 若需要查询某条具体SOAP对端配置信息，请输入“SOAP对端标识”参数。

  **说明** 

  该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                           |
|:-------|:---------|:---------------------------------------------------------------|
| ID     | SOAP对端标识 | 可选必选说明：可选参数 用于指示系统按照哪个ID来查询SOAP对端配置信息；若不输入，则表示查询所有的SOAP对端配置信息。 |

## 使用实例

1. 查询全部SOAP对端配置记录：

   ```
   LST SOAPPE:;
   ```

   ```
   %%LST SOAPPE:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    SOAP对端标识  FQDN  

    0             NULL     
    1             adfdf 
    2             adfdf 
    3             adfdf 
    4             adfdf  
   (结果个数 = 5)

   ---    END
   ```
2. 查询“SOAP对端标识”为“1”的记录：

   ```
   LST SOAPPE: ID=1;
   ```

   返回结果如下：

   ```
   %%LST SOAPPE: ID=1;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
   SOAP对端标识  =  1
           FQDN  =  a
   (结果个数 = 1)

   ---    END
   ```
