# 启动冗余会话备份数据审计任务(STR OTSSESSADT)

- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

该命令为维护类命令，用于任意时间启动冗余会话备份数据审计任务，对USCDB中超过有效期的会话数据进行清理。

## 注意事项

- 在没有设置审计任务的情况下，执行该命令时，将使用系统的缺省配置来启动冗余会话备份数据审计任务。

  **说明** 

  冗余会话备份数据审计任务的系统缺省配置如下：

  ```
  启动时间    审计周期     会话过期时长     审计速度     任务状态     审计失败告警     告警阈值（万分之一）      PS_IPADDR表审计功能
  03:00:00      24           48               30           打开         上报告警               20                不开启审计
  ```
- 冗余会话备份数据审计任务的参数为**SET SESSADT**命令下审计类型设置为USCDB的参数。

## 参数说明

无。

## 使用实例

启动冗余会话备份数据审计任务操作，执行命令如下：

```
STR OTSSESSADT:;
```

```
%%STR OTSSESSADT:;%% 
RETCODE = 0  操作成功  

 ---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                      | 原因分析                                                                   | 处理建议                                                                                             |
|------:|:---------------------------|:-----------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------|
| 58075 | BE过载不允许执行STR OTSSESSADT命令。 | PES收到BE流控消息且BE流控状态为流控时，通知OTS停止本次正在执行的冗余会话备份数据审计任务，不允许手动启动冗余会话备份数据审计任务。 | 请在BE解除流控后再执行该命令。                                                                                 |
| 58102 | 任务已经启动。                    | 执行该命令时，已存在正在执行的任务。                                                     | 执行DSP OTSSESSADT命令查询冗余会话备份数据审计的任务状态，当状态为“运行”时，建议等待任务执行完成，等待状态变更为“空闲”时，再重新执行该命令。                  |
| 58103 | 操作失败。                      | 系统内部异常。                                                                | 等待几分钟后，再重新执行该命令。执行DSP OTSSESSADT命令查询冗余会话备份数据审计的任务状态，当状态为“空闲”时，再重新执行该命令。如果一直上报该错误码，请联系华为技术支持进行处理。 |
