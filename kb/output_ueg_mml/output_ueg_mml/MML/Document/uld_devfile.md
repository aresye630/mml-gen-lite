## 命令功能

该命令用于上传设备档案文件到网管服务器，是提供给网管的机机命令接口，仅能在网管上执行。

该命令的使用场景为：网管下发EXP DEVFILE导出设备档案文件后，执行该命令上传设备档案文件到网管服务器。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                      |
|:-------|:-------|:----------------------------------------------------------|
| IP     | IP地址   | 可选必选说明：必选参数。 参数含义：用于指定网管服务器。                              |
| USR    | 用户名    | 可选必选说明：必选参数。 参数含义：用于标识登录服务器使用的用户名。                        |
| PWD    | 密码     | 可选必选说明：必选参数。 参数含义：用于标识登录服务器使用的密码。                         |
| DSTF   | 目标文件名称 | 可选必选说明：必选参数。 参数含义：用于指定要上传到网管端的设备档案文件的完整目标路径，目标文件目录必须已经存在。 |

## 使用实例

上传设备档案文件“DevFile.xml”到网管服务器：

```
ULD DEVFILE: IP="127.0.0.1", USR="sftp", PWD="******", DSTF="/opt/devfile/0_DevFile.xml";
```
