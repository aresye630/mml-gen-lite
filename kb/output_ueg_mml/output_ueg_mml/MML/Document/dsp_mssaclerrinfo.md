# 查询软转发支撑访问控制列表模块错误信息（DSP MSSACLERRINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询访问控制列表错误信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                   |
|:--------|:-------|:-------------------------------------------------------------------------------------------------------|
| RUNAME  | RU名称   | 可选必选说明：必选参数 参数含义：该参数用于指定RU名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：使用DSP RU查看RU名称。 |
| TABLEID | 表ID    | 可选必选说明：必选参数 参数含义：该参数用于表示访问控制列表ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                         |

#### 使用实例

查询软转发支撑访问控制列表错误信息：

```
DSP MSSACLERRINFO:TABLEID=7,RUNAME="VNODE_VNRS_VNFC_IPU_0064";
```

```
RETCODE = 0  操作成功。

结果如下
--------
      操作  =  add-rule
规则优先级  =  10
    错误码  =  0x12C3346B
      时间  =  2016-10-19 10:26:28.756
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释             |
|:--------|:------------------|
| 操作      | 用于表示访问控制列表错误标识。   |
| 规则优先级   | 用于表示访问控制列表优先级。    |
| 错误码     | 用于表示访问控制列表模块错误码。  |
| 时间      | 用于表示访问控制列表模块错误时间。 |
