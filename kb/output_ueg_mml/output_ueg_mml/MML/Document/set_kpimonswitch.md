# 设置KPI异常检测功能开关（SET KPIMONSWITCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

关闭开关会清理掉持久化数据，重新打开检测开关后，需要重新累积7天KPI数据才做检测。

该命令用于设置KPI异常检测功能开关。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| SWITCH   |
|:---------|
| ON       |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                               |
|:-------|:----------|:-----------------------------------------------------------------------------------|
| SWITCH | KPI异常检测开关 | 可选必选说明：必选参数  参数含义：该参数用于指定KPI异常检测开关。  数据来源：本端规划 取值范围： ON（开启）OFF（关闭）  默认值：无。  配置原则：无 |

## 使用实例

- 开启KPI异常检测。

  ```
  SET KPIMONSWITCH: SWITCH=ON;
  ```
- 关闭KPI异常检测。

  ```
  SET KPIMONSWITCH: SWITCH=OFF;
  ```
