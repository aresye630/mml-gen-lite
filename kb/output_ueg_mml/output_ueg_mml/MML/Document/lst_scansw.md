# 查询离线业务参数(LST SCANSW)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询离线业务的参数。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称           | 参数说明                                                                                                                                                                                                                                                                             |
|:-------|:---------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SW1    | 离线配额复位         | 用于标识遍历任务中离线配额复位业务是否打开。 取值说明： ENABLE(打开)DISABLE(关闭) 默认值：无。  说明： 当该开关打开时，由于动态配额离线复位清理会删除动态配额，因此不支持发送离线动态配额复位通知。                                                                                                                                                                    |
| SW2    | 离线帐户复位         | 用于标识遍历任务中离线帐户复位业务是否打开。 取值说明： ENABLE(打开)DISABLE(关闭) 默认值：无。                                                                                                                                                                                                                        |
| SW3    | 离线业务生效发通知      | 用于标识遍历任务中离线业务生效发通知业务是否打开。 取值说明： ENABLE(打开)DISABLE(关闭) 默认值：无。                                                                                                                                                                                                                     |
| SW4    | 离线业务失效发通知      | 用于标识遍历任务中离线业务失效发通知业务是否打开。 取值说明： ENABLE(打开)DISABLE(关闭) 默认值：无。                                                                                                                                                                                                                     |
| SW5    | 默认PCC临时数据清理    | 用于标识遍历任务中默认PCC临时数据清理业务是否打开。 取值说明： ENABLE(打开)DISABLE(关闭) 默认值：无。                                                                                                                                                                                                                   |
| SW6    | 抑制短信记录超期清理     | 用于标识遍历任务中抑制短信记录超期清理业务是否打开。 取值说明： ENABLE(打开)DISABLE(关闭) 默认值：无。  说明： 当该开关打开时，离线任务中支持对用户通知记录进行抑制失败检查。通知抑制失败记录文件保存在OTES服务所在虚机（裸机Pod）上的“/opt/OTES/notifyrestrictfail”目录下                                                                                                              |
| SW7    | 业务或套餐过期前通知     | 用于标识遍历任务中业务或套餐过期前通知业务是否打开。 取值说明： ENABLE(打开)DISABLE(关闭) 默认值：无。                                                                                                                                                                                                                    |
| SW8    | 静态用户清理         | 用于设置静态用户数据的清理开关。 取值说明： ENABLE(打开)DISABLE(关闭) 默认值：无。                                                                                                                                                                                                                              |
| SW9    | 无签约用户清理        | 用于设置无签约用户数据的清理开关。 取值说明： ENABLE(打开)DISABLE(关闭) 默认值：无。  说明： 清除无签约的静态开户的用户数据，需满足如下三个条件：该开关打开，即“SW9”的取值为“ENABLE”。确认EDR的license控制项已打开。通过DSP LICENSE查询EDR功能信息值，当功能信息值列表中“EDR”的取值不为“0”时，表示支持EDR license控制项。 设置EDR上报特性列表为“ProvisioningEDR（业务发放系统EDR）”。如何设置请参见设置EDR上报特性列表(SET EDRREPORT)。 |
| SW10   | 已耗尽配额实例清理      | 用于控制已耗尽配额实例的清理开关。 取值说明： ENABLE(打开)DISABLE(关闭) 默认值：无。  说明： 在清理配额实例时，若“已耗尽配额实例清理”设置为“打开”，则清理过期配额实例和已耗尽配额实例；若“已耗尽配额实例清理”设置为“关闭”，则清理已过期配额实例但不清理已耗尽配额实例。若“已耗尽配额实例清理”设置为“打开”，当所有配额实例都已耗尽但未过期，那么会保留最后一个耗尽配额实例不清理。                                                                       |
| SW11   | 离线配额初始值刷新      | 用于控制离线遍历任务中配额初始值和剩余值的刷新开关。当该开关打开时，OTS会遍历并刷新用户配额表的配额初始值和配额剩余值。 取值说明： ENABLE(打开)DISABLE(关闭) 默认值：无。  说明： LST PSYSPARA命令中“SetTotalShareQuotaLimitation”为1时，离线配额初始值刷新即使设置为“ENABLE”也不生效。离线扫描启动后且该参数设置为打开，如果发现全局配额表中配额初始值有调整，则OTS根据最新的配额初始值刷新用户配额表的配额初始值和配额剩余值，重新计算配额状态。                |
| SW12   | 清理过期的sponsor业务 | 用于控制遍历任务中SPONSOR_SERVICE业务过期清理的开关。 取值说明： ENABLE(打开)DISABLE(关闭) 默认值：无。 初始值：DISABLE(关闭)  说明： 该开关打开时，系统会清理用户所有SPONSOR_SERVICE类型的业务中“绝对有效时间段”过期的业务。                                                                                                                                  |

## 使用实例

查询离线业务的参数。

```
LST SCANSW:;
```

```
%%LST SCANSW:;%%
RETCODE = 0  操作成功

操作结果如下:
-------------
         离线配额复位  =  关闭
         离线帐户复位  =  关闭
   离线业务生效发通知  =  关闭
   离线业务失效发通知  =  打开
  默认PCC临时数据清理  =  关闭
 抑制短信记录超期清理  =  关闭
 业务或套餐过期前通知  =  关闭
         静态用户清理  =  关闭
       无签约用户清理  =  关闭 
   已耗尽配额实例清理  =  打开
   离线配额初始值刷新  =  打开
清理过期的sponsor业务  =  关闭
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见本命令的参数说明。
