# 查询IPSQM缓存队列深度（LST IPSQMQDEPTH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-U、UPF**

该命令用于查询整形队列深度。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询整形队列深度：

```
LST IPSQMQDEPTH:;
```

```
RETCODE = 0  操作成功

IPSQM缓存队列深度
-----------------
队列深度（报文个数）  =  256
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见SET IPSQMQDEPTH的参数说明。
