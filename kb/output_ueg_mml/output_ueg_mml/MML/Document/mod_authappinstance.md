# 修改APP实例授权（MOD AUTHAPPINSTANCE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

**须知** 

本命令属于高危命令，修改APP实例授权信息会导致MEP平台为修改前本APP实例所属的APPID所签发的token失效，使用该APPID的APP需要重新申请token才能继续访问，请谨慎修改。

该命令用于修改APP实例ID和APPID的绑定关系，绑定之后，则该APP实例可访问为该APPID所添加的授权服务列表中的服务。当需要限制某些服务资源仅允许这些服务资源所属的APP实例修改时，可通过此命令配置APPID和APPINSTANCEID的绑定关系达到此目的，同时该APP实例申请token时需要同时携带APPID和APP实例ID。例如为指定APP实例所下发的分流规则仅允许该APP实例修改该分流规则的激活状态。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                                                                                      |
|:--------------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APPINSTANCEID | APP实例ID | 可选必选说明：必选参数 参数含义：该参数用于指定APP实例标识。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“_”组成。 默认值：无 配置原则：无                                                                       |
| APPID         | APP标识   | 可选必选说明：可选参数 参数含义：该参数用于指定APP实例所属的APP标识。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“_”组成。 默认值：无 配置原则： 该参数使用ADD APPAUTHINFO命令配置生成。输入单空格将删除该参数已有配置项。根据APP实例所属的APPID进行配置。 |

#### 使用实例

修改APP实例ID为"appInstance1"的APP实例授权信息，APP实例所属的APP标识为"app1"：

```
MOD AUTHAPPINSTANCE: APPINSTANCEID="appInstance1", APPID="app1";
```
