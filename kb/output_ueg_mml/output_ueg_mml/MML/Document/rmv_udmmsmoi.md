# 删除UDM微服务进程测量对象(RMV UDMMSMOI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条微服务的进程测量对象。

## 注意事项

HttpDisCtrlService服务订阅其它服务的上下线通知，从而管理微服务进程测量对象。

- 当其他服务下线时，HttpDisCtrlService服务在线，则HttpDisCtrlService服务会自动执行此命令删除UDM微服务进程的测量对象。
- 当其他服务下线时，HttpDisCtrlService服务已下线，则无法自动删除UDM微服务进程的测量对象，需手动执行此命令删除测量对象。若未手动删除测量对象，当HttpDisCtrlService服务恢复上线时，内部校验机制发现实际在线的服务与测量对象不符，HttpDisCtrlService服务会自动执行此命令删除多余的测量对象。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                          |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ST      | 服务类型   | 可选必选说明：必选参数 参数含义：用于标识待删除测量对象的服务类型。 取值范围： UdmAppCtrlService(UdmAppCtrlService)NRFClient(NRFClient)HttpDisCtrlService(HttpDisCtrlService)UdmSubService(UdmSubService)UdmAuthService(UdmAuthService)UdmTcpService(UdmTcpService)UdmHttpService(UdmHttpService)UdmAlbService(UdmAlbService)EnumService(EnumService) 默认值：无 配置原则：无。 |
| NODEID  | 节点ID   | 可选必选说明：必选参数 参数含义：用于标识待删除测量对象所属的节点ID。 取值范围：长度不超过128位的字符串。 默认值：无 配置原则：无。                                                                                                                                                                                                                                                        |
| PODNAME | POD名称  | 可选必选说明：必选参数 参数含义：用于标识POD名称。 取值范围：长度不超过128位的字符串。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                  |
| INSID   | 服务实例ID | 可选必选说明：必选参数 参数含义：用于标识待删除测量对象的服务实例ID。 取值范围：长度不超过64位的字符串。 默认值：无 配置原则：无。                                                                                                                                                                                                                                                         |

## 使用实例

删除“服务类型”为“UdmTcpService”，“节点ID”为“172.19.239.71”，“POD名称”为“hlb-a-pod439-6f95f7cbf4-k47v7”，“服务实例ID”为“11663530850187870750”的微服务进程测量对象：

```
RMV UDMMSMOI: ST=UdmTcpService, NODEID="172.19.239.71", PODNAME="hlb-a-pod439-6f95f7cbf4-k47v7", INSID="11663530850187870750";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释         | 原因分析                                     | 处理建议                                                                                                        |
|------:|:--------------|:-----------------------------------------|:------------------------------------------------------------------------------------------------------------|
|   505 | 当前操作的配置数据不存在。 | 输入的参数“服务类型”、“节点ID”、“POD名称”、或“服务实例ID”不存在。 | 执行LST UDMMSMOI命令，查询已配置的微服务进程测量对象对应的“服务类型”、“节点ID”、“POD名称”、和“服务实例ID”，重新执行RMV UDMMSMOI命令，输入已配置的微服务进程测量对象对应的数据。 |
