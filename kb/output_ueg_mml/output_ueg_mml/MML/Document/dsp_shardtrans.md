# 显示分片数据迁移状态（DSP SHARDTRANS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

数据迁移是指把一个DUS微服务的部分或所有分片数据迁移到另外的DUS微服务里。数据迁移的主要使用场景为：

- 在DUS微服务扩容场景下，需要将原DUS微服务中的分片数据迁移到新的DUS微服务中。
- 在DUS微服务缩容场景下，需要将隔离的DUS微服务中的分片数据迁移到未隔离的DUS微服务中。

该命令用于显示分片数据迁移状态。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                      |
|:--------|:-------|:------------------------------------------------------------------------------------------|
| APPTYPE | 应用类型   | 可选必选说明：必选参数。 参数含义：用于请求系统按照指定的应用类型查看分片数据迁移状态。 取值范围：需要与LST APPTYPE的“应用类型”对应。 默认值：无。 配置原则：无。 |

## 使用实例

查看分片数据迁移状态。

```
DSP SHARDTRANS: APPTYPE = "SUP-DUS";
```

```
%%DSP SHARDTRANS: APPTYPE="SUP-DUS";%%
RETCODE = 0  操作成功

操作结果如下
------------------------
数据迁移状态  =  正常状态

(结果个数 = 1)
---    END
```
