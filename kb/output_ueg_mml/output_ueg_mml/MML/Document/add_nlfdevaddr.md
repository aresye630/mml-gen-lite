# 添加NLF设备地址(ADD NLFDEVADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中增加一条NLF设备地址信息数据记录。

该命令的使用场景：NTS服务会将生成好的通知日志文件（压缩后的.tar.gz格式文件）上传到NLF服务，NLF服务支持通知日志文件的上传或下载。NLF对外提供如下服务时，需要配置此命令。

- NLF作为SFTP服务端，第三方服务器需要通过NLF提供的SFTP服务端获取通知日志文件。
- NLF作为SFTP客户端，向DRS服务上传通知日志文件。

## 注意事项

- 当未配置NLF设备IP地址时，NLF能够启动，但不能对外提供服务。配置NLF设备IP地址后，NLF可以使用该IP地址对外提供服务。
- 对于IPv4地址，不支持配置以下地址：“127.0.0.1”、“0.0.0.0”、“255.255.255.255”、“224.0.0.1”。
- PMS/NTS/DRS/HLB/DLB/NLF/LDAP设备的IP地址（包括IPv4地址和IPv6地址）需要唯一，任意两种设备的IP地址不能重复。
- NLF启动SFTP服务侦听（即NLF作服务端）时，需注意如下内容：
  - 当复用IP地址即“复用”取值为“YES(YES)”时，NLF SFTP服务端的侦听端口系统会默认使用“2223”。
  - 当不复用IP地址“复用”取值为“NO(NO)”时，NLF SFTP服务端的侦听端口系统会默认使用“2222”。

## 使用实例

1. 查询“VPN名称”，通过执行**LST L3VPNINST**命令查询到的“VPN实例名称”。

   ```
   LST L3VPNINST:;
   ```
2. 查询PMS的“设备地址标识”，通过执行**LST PMSDEVADDR**命令查询到“FTP”配置为“NO”的“设备地址标识”。

   ```
   LST PMSDEVADDR: FTP=NO;
   ```
3. 增加NLF设备地址信息。
   1. 增加IPv4类型的NLF设备地址信息，“设备地址标识”为“1”，开启“复用”开关，“PMS设备地址标识”根据2查询得为“2”，“描述”为“开启复用”。

      ```
      ADD NLFDEVADDR: DEVAID=1, REUSE=YES, PMSDEVAID=2, DESCRIPTION="开启复用";
      ```
   2. 增加IPv6类型的NLF设备地址信息，“设备地址标识”为“2”，关闭“复用”开关，“VPN名称”为“VPN02”，“IP版本”为“IPV6(IPV6)”，“IPV6地址”为“2001:0db8:3fff:ffff:ffff:ffff:ffff:ffff”，“描述”为“NLF\_IPV6”。

      ```
      ADD NLFDEVADDR: DEVAID=2, REUSE=NO, VPNNAME="VPN02", IPVER=IPV6, IPV6="2001:0db8:3fff:ffff:ffff:ffff:ffff:ffff", DESCRIPTION="NLF_IPV6";
      ```
