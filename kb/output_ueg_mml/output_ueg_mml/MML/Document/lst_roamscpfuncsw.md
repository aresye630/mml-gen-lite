# 查询漫游跨PLMN场景间接路由功能（LST ROAMSCPFUNCSW）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF、SMF、NEF、NWDAF、SCF**

该命令用于显示漫游跨PLMN场景间接路由功能配置。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                       |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LNFTYPE | 本端NF类型 | 可选必选说明：可选参数  参数含义：该参数用于指定本端NF的类型。  数据来源：全网规划 取值范围： “AMF（AMF）”：NF类型为AMF“SMF（SMF）”：NF类型是SMF  默认值：无  配置原则：无                                                                   |
| PNFTYPE | 对端NF类型 | 可选必选说明：可选参数  参数含义：该参数用于指定对端NF的类型。  数据来源：全网规划 取值范围： “UDM（UDM）”：NF类型是UDM“AUSF（AUSF）”：NF类型为AUSF“AMF（AMF）”：NF类型为AMF“SMF（SMF）”：NF类型为SMF“EIR（5G-EIR）”：NF类型为5G-EIR  默认值：无  配置原则：无 |

## 使用实例

运营商需要查询漫游跨PLMN场景间接路由功能配置。

```
%%LST ROAMSCPFUNCSW:;%%
RETCODE = 0  操作成功

结果如下
------------------------
          本端NF类型 = AMF
          对端NF类型 = UDM
服务发现代理开关 = OFF
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称    | 输出项解释                                                                                                                                                                         |
|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 本端NF类型   | 该参数用于指定本端NF的类型。                                                                                                                                                               |
| 对端NF类型   | 该参数用于指定对端NF的类型。                                                                                                                                                               |
| 服务发现代理开关 | 该参数用于设置漫游跨PLMN场景下是否使用SCP代理NF的服务发现功能，如果设置为ON，则漫游跨PLMN场景下指定的本端和对端类型之间的NF服务发现功能通过SCP间接实现。注意，不是通过直接和SCP进行服务发现交互，而是在业务消息交互的过程中，SCP解码业务消息获得用户号码等信息进行消息路由或抽取业务消息里携带的服务发现头到NRF进行服务发现。 |
