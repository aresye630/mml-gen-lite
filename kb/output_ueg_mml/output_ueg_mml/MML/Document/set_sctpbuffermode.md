#### 命令功能

**须知** 

该命令会改变SCTP通信缓存的使用方式，触发SGP进程内存占用率变化，影响S1接口和N2接口链路的接入。系统稳定运行场景下请慎用本功能。

**适用NF：SGSN、MME、AMF**

该命令用于设置系统中SCTP缓冲区的模式。当前模式支持共享模式和私有模式。私有模式表示每个偶联有自己单独的缓冲区，共享模式表示单个SGP进程内的偶联共用一块内存。共享模式相比私有模式可以减少内存开销。

#### 注意事项

- 该命令执行后需要重启SGP进程才能生效。
- 该命令会影响SCTP内存分布，配置参数不合理可能导致SGP进程异常。
- 当将此命令中接收端缓冲区模式或发送端缓冲区模式设置为私有时，单SGP进程可容纳的SCTP偶联数量会减少至1000。请先通过DSP SCTPBALANCEINFO查询每个进程上的“单进程基站总个数”，确认基站数均小于1000时方可使用私有模式。

#### 本地用户权限

manage-ug;system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                       |
|:-------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| RXMODE | 接收端缓冲区模式 | 可选必选说明：可选参数 参数含义：该参数用于设置SCTP接收端缓冲区模式。 数据来源：本端规划 取值范围：枚举类型 SHARE（共享模式）：所有偶联将使用进程共享的SCTP缓冲区。PRIVATE（私有模式）：所有偶联将使用各自私有的SCTP缓冲区。 系统初始设置值：SHARE |
| TXMODE | 发送端缓冲区模式 | 可选必选说明：可选参数 参数含义：该参数用于设置SCTP发送端缓冲区模式。 数据来源：本端规划 取值范围：枚举类型 SHARE（共享模式）：所有偶联将使用进程共享的SCTP缓冲区。PRIVATE（私有模式）：所有偶联将使用各自私有的SCTP缓冲区。 系统初始设置值：SHARE |

#### 使用实例

设置SCTP发送端缓冲区模式为私有模式、接收端缓冲区模式为共享模式：

```
SET SCTPBUFFERMODE: RXMODE=SHARE, TXMODE=PRIVATE;
```
