# 显示ServiceConfig服务调试信息（DSP MMLSCSDBG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此命令用于查询ServiceConfig服务的调试信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                    |
|:----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NODE      | 节点信息   | 可选必选说明：必选参数  参数含义：该参数用于表示发给ServiceConfig服务的主备节点信息。  数据来源：本端规划 取值范围： Active（主用节点）Standby（备用节点）  默认值：无  配置原则：无                                                                                            |
| DEBUGTYPE | 调试类型   | 可选必选说明：必选参数  参数含义：该参数用于表示发给ServiceConfig服务的调试类型。  数据来源：本端规划 取值范围： FullTaskReport（全量任务报告）LastSetupTaskReport（最近一次设置任务报告）LastRollbackTaskReport（最近一次回滚任务报告）LastQueryTaskReport（最近一次查询任务报告）  默认值：无  配置原则：无 |

## 使用实例

查询节点信息为Active，调试类型为Report：

```
%%DSP MMLSCSDBG: NODE=Active, DEBUGTYPE=FullTaskReport;%%
RETCODE = 0  操作成功

结果如下
--------
调试输出  =  
Active is running normally

(结果个数 = 1)

---    END
```
