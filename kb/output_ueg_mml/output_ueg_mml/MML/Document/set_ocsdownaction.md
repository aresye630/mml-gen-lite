# 设置DCC模板OCS状态Down动作（SET OCSDOWNACTION）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于设置DCC在线计费模板OCS状态Down动作。

#### 注意事项

- 该命令执行后只对新激活用户生效。
- 该命令最大记录数为101。
- 该命令设定后的数据，需要通过LST DCCTEMPLATE命令进行查看。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | DCCTMPLTNAME   | OCSDNACTION   | HOLDINGTMFLAG   |
|:-------|:---------------|:--------------|:----------------|
| 初始值    | global         | PERMIT        | DISABLE         |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称             | 参数说明                                                                                                                                                                                                                                                                                                 |
|:--------------|:-----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DCCTMPLTNAME  | DCC模板名称          | 可选必选说明：必选参数 参数含义：该参数用于指定操作的DCC在线计费模板的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则： 该参数使用ADD DCCTEMPLATE命令配置生成。该命令基于此参数配置DCC在线计费模板的OCS状态Down动作。                                                                                                                                                   |
| OCSDNACTION   | OCS断用户处理动作       | 可选必选说明：必选参数 参数含义：该参数用于配置在线计费模板中配置用户激活时Gy对端状态为Down时的动作。 数据来源：本端规划 取值范围：枚举类型。 PERMIT：通过。FORBIDDEN：禁止。BLOCK：阻塞业务一段时间后去活用户，阻塞时间受DCCTEMPLATE下的BLOCKTIMER控制。INHERIT：继承。 默认值：无 配置原则：OCSDnAction参数为PERMIT时，需要首先通过SET HOLDINGTIME命令配置HoldingTime参数。                                                           |
| HOLDINGTMFLAG | OCS断用户允许在线时间控制开关 | 可选必选说明：条件可选参数 前提条件：该参数在“OCSDNACTION”配置为“PERMIT”时为可选参数。 参数含义：该参数用于指定OCS状态为DOWN时允许用户激活后，是否使用HoldingTime控制允许用户访问的时间。如果使用HoldingTime控制用户访问时间，HoldingTime超时后用户将被去活。HoldingTime时间通过参数HoldingTime配置。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能OCS断用户允许在线时间控制。ENABLE：使能OCS断用户允许在线时间控制。INHERIT：继承全局DCC模板。 默认值：无 配置原则：无 |

#### 使用实例

设置名为“DccTemplate”的DCC在线计费模板的OCS断用户处理动作为通过，并打开OCS断用户允许在线时间控制开关：

```
SET OCSDOWNACTION:DCCTMPLTNAME="DccTemplate",OCSDNACTION=PERMIT,HOLDINGTMFLAG=ENABLE;
```
