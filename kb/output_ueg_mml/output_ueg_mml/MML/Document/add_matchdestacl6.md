# 增加匹配IPv6地址ACL（ADD MATCHDESTACL6）

#### 命令功能

该命令用于添加ACL匹配IPv6目的地址。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为65535。
- 配置该命令前，必须已经通过ADD ROUTEPOLICY配置了指定路由策略的名字以及通过ADD ROUTEPOLICYNODE配置了该策略下的节点。
- 配置该命令前，必须已经通过ADD ACLRULEBAS6或ADD ACLRULEADV6配置了ACL过滤器，对于命名型ACL，配置过滤规则时，只有指定的源地址范围对配置规则有效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称       | 参数说明                                                                                                                                              |
|:-------------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
| POLICYNAME   | 路由策略名字     | 可选必选说明：必选参数 参数含义：配置操作的路由策略名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无 配置原则：不支持输入空格。                                                              |
| NODESEQUENCE | 路由策略节点号    | 可选必选说明：必选参数 参数含义：该参数用于配置操作的路由策略节点。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无                                                                        |
| ACLNAMEORNUM | ACL名字或ACL号 | 可选必选说明：必选参数 参数含义：该参数用于指定ACL规则组名称或是编号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：如果输入ACL号的话，取值范围是2000～2999，若输入名字的话，需要输入以英文字母a～z或A～Z开头的1～32位字符串。 |

#### 使用实例

添加路由策略a节点10的匹配条件， ACL过滤器abc匹配IPv6目的地址：

```
ADD MATCHDESTACL6:NODESEQUENCE=10,ACLNAMEORNUM="abc", POLICYNAME="a";
```

#### 参考信息

为实现路由策略，首先定义将要实施路由策略的路由特征，即定义一组匹配规则和设置规则，然后将它们应用于路由的发布、接收和引入等过程的路由策略中。
