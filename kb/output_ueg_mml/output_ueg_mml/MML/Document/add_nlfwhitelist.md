# 添加NLF白名单(ADD NLFWHITELIST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于配置数据库中增加一条NLF白名单信息数据记录。

该命令的使用场景：当NLF作为SFTP服务端，需要支持口令防暴力破解，通过NLF提供的IP白名单控制SFTP客户端的IP连接。在白名单内的IP可以正常连接，不在白名单内的IP连接会被断开。

## 注意事项

- **命令生效条件**：该命令执行后立即生效。
- 当软参“VRM\_WHITELISTSWITCH”的取值为1时，白名单功能启用，此时对于旧的连接，不在白名单列表里的连接会被断开；对于新的连接，只有在白名单列表里的IP才允许接入。
- 当软参“VRM\_WHITELISTSWITCH”的取值为0时，白名单功能关闭，此时对所有连接不做限制。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                        |
|:------------|:-------|:------------------------------------------------------------------------------------------------------------|
| ID          | 索引     | 可选必选说明：必选参数 参数含义：用于定义一条NLF白名单的数据记录。 取值范围：0～255 默认值：无。 配置原则：无。                                               |
| IPVER       | IP版本   | 可选必选说明：必选参数 参数含义：用于指定NLF白名单的SFTP客户端的IP版本类型。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。                       |
| IP          | IPV4地址 | 可选必选说明：必选参数 参数含义：仅当“IP版本”选择“IPV4(IPV4)”时该参数需配置，NLF与对端对接的参数之一，用于表示SFTP客户端的IPv4地址。 取值范围：IPv4地址 默认值：无。 配置原则：无。 |
| IPV6        | IPV6地址 | 可选必选说明：必选参数 参数含义：仅当“IP版本”选择“IPV6(IPV6)”时该参数需配置，NLF与对端对接的参数之一，用于表示SFTP客户端的IPv6地址。 取值范围：IPv6地址 默认值：无。 配置原则：无。 |
| DESCRIPTION | 描述     | 可选必选说明：可选参数 参数含义：用于NLF白名单数据记录的描述。 取值范围：长度不超过32的字符串 默认值：无。 配置原则：无。                                           |

## 使用实例

增加一条NLF白名单数据记录。“索引”为“1”，“IP版本”为“IPV4(IPV4)”，“IPV4地址”为“10.168.0.130”，“描述”为“test”。

```
ADD NLFWHITELIST: ID=1, IPVER=IPV4, IP=10.168.0.130, DESCRIPTION="test";
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释   | 原因分析                     | 处理建议                                                                                        |
|------:|:--------|:-------------------------|:--------------------------------------------------------------------------------------------|
| 58037 | IP已经存在。 | 输入的“IPV4地址”或“IPV6地址”已存在。 | 执行LST NLFWHITELIST命令查询全部NLF白名单配置信息，记录已存在的IP地址。 执行本命令，重新设置“IPV4地址”或“IPV6地址”，并确保和已存在的IP地址不相同。 |
