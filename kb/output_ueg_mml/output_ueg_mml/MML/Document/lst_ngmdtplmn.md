# 查询最小化路测的PLMN（LST NGMDTPLMN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询最小化路测（MDT）的PLMN。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------------------|
| PLMNIDX | PLMN索引 | 可选必选说明：可选参数  参数含义：该参数表示最小化路测（MDT）的PLMN。  数据来源：本端规划  取值范围：整数类型，取值范围是0~127。PLMNIDX通过ADD NGSRVPLMN进行配置。  默认值：无  配置原则：无 |

## 使用实例

查询最小化路测的PLMN，执行如下命令：

```
%%LST NGMDTPLMN:;%%
RETCODE = 0  操作成功

结果如下
--------
PLMN索引  

1         
2         
3         
(结果个数 = 3)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                 |
|:--------|:----------------------|
| PLMN索引  | 该参数表示最小化路测（MDT）的PLMN。 |
