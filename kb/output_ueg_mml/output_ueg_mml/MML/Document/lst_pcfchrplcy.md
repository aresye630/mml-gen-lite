# 查询CHR输出策略(LST PCFCHRPLCY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

用于查询呼叫Rx会话和注册Rx会话的CHR单据输出策略，通过执行本命令，操作员可以了解到系统当前在哪些场景下会输出CHR单据。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询CHR单据输出策略。

**LST PCFCHRPLCY:;**

```
%%LST PCFCHRPLCY:;%% 
RETCODE = 0  操作成功  

操作结果如下:
 ------------------------         
注册CHR输出策略  =  成功的注册会话                         
                 =  失败的注册会话                          
                 =  注册会话主动更新                         
                 =  注册会话正常下线                          
                 =  注册会话异常终止         
呼叫CHR输出策略  =  失败的呼叫会话                          
                 =  呼叫会话异常终止
 
(结果个数 = 1)
 ---    END
```

## 输出结果说明

请参见SET PCFCHRPLCY命令的参数说明。
