# 增加IPv6 DNS Hostfile记录（ADD NGIPV6DNSH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于配置网元接口所对应的IPv6地址信息，该信息用于网元选择时DNS查询功能。

如果配置了多个IP地址，域名解析结果中将会根据“PRIORITY（优先级）”和“WEIGHT（权重）”进行先后次序排列：

- 优先级别高的排前面。
- 同一优先级别的再按照权重来选择，权重越大，则排在前面的概率越高。

## 注意事项

- 该命令执行后立即生效。

- 该表中最多能配置1024个不同主机名。每个主机名最多配置8个IP地址区间，每个区间对应一条记录。相同主机名不能配置重复的IP地址。
- 一个主机名最多能对应64个IP地址，且64个地址中至少有一个有效的单播地址。
- 同一域名对应的IP地址信息，必须全部配置在本地或者全部配置在DNS服务器上。
- 同一主机名只能有唯一主机名索引。
- 该命令执行后，可能导致HTTP的FQDN链路信息地址发生变更，建议通过执行CHK SBILINKFQDNIP，核查HTTP的链路信息。

- 最多可输入8192条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

网络升级过程中，网络新增一个网元，该网元对应的域名配置IPv6类型的地址，具体操作为：增加一个“主机名索引”值为“1028”，“主机名”为“HUAWEI1.COM.GTP.APN.EPC.MNC123.MCC456.3GPPNETWORK.ORG”，“地址区间号”为“SECTION1”，“IPv6地址1”为“2001:0db8::1”，“优先级1”为“10”，“权重1”为“100”：

```
ADD NGIPV6DNSH: HSINDEX=1028, HOSTNAME="HUAWEI1.COM.GTP.APN.EPC.MNC123.MCC456.3GPPNETWORK.ORG", ADDRSECTION=SECTION1, IPV6ADDR1="2001:0db8::1", PRIORITY1=10, WEIGHT1=100;
```
