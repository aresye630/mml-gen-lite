# 显示Fabric链路探测任务的详细结果（DSP PAEFABDETDTL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询Fabric平面链路状态探测详细结果。

## 注意事项

不支持在探测过程查询详细探测结果，如果要强制查询，请先执行**STP PAEFABDETECT**命令停止探测。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                            |
|:------------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TASK        | 查询范围    | 可选必选说明：必选参数  参数含义：该参数用于指定查询的fabric检测任务。  数据来源：本端规划 取值范围： TASK_SINGLE_LINK（单条链路）  默认值：无  配置原则：无                                                                  |
| SRCPODNAME  | 源Pod名称  | 可选必选说明：该参数在"TASK"配置为"TASK_SINGLE_LINK"时为条件必选参数。  参数含义：该参数用于指定本端Pod名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。  默认值：无  配置原则：  使用DSP POD获取Pod名称。                      |
| DSTPODNAME  | 目的Pod名称 | 可选必选说明：该参数在"TASK"配置为"TASK_SINGLE_LINK"时为条件必选参数。  参数含义：该参数用于指定远端Pod名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。  默认值：无  配置原则：  使用DSP POD获取Pod名称。                      |
| SRCPORTNAME | 源端口名称   | 可选必选说明：该参数在"TASK"配置为"TASK_SINGLE_LINK"时为条件必选参数。  参数含义：该参数用于指定本端端口名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~20。  默认值：无  配置原则：  使用DSP PAEPORTINFO获取探测端口名称（仅支持Fabric端口）。 |
| DSTPORTNAME | 目的端口名称  | 可选必选说明：该参数在"TASK"配置为"TASK_SINGLE_LINK"时为条件必选参数。  参数含义：该参数用于指定远端端口名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~20。  默认值：无  配置原则：  使用DSP PAEPORTINFO获取探测端口名称（仅支持Fabric端口）。 |

## 输出结果说明

| 输出项名称      | 输出项解释                                                                                                                                                                              |
|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 源Pod名称     | 该参数用于指定本端Pod名称。                                                                                                                                                                    |
| 目的Pod名称    | 该参数用于指定远端Pod名称。                                                                                                                                                                    |
| 源端口名称      | 该参数用于指定本端端口名称。                                                                                                                                                                     |
| 目的端口名称     | 该参数用于指定远端端口名称。                                                                                                                                                                     |
| Fabric平面ID | 该参数表示fabric链路探测的平面ID。                                                                                                                                                              |
| 探测报文长度     | 该参数表示fabric链路探测的报文长度。 取值说明： “PKTLENGTH_256（报文长度256字节）”：报文长度256字节“PKTLENGTH_512（报文长度512字节）”：报文长度512字节“PKTLENGTH_1024（报文长度1024字节）”：报文长度1024字节“PKTLENGTH_1500（报文长度1500字节）”：报文长度1500字节 |
| 探测间隔       | 该参数表示fabric链路探测时间间隔。                                                                                                                                                               |
| 源端发送包数     | 该参数表示fabric链路探测源端发送成功的包数量。                                                                                                                                                         |
| 源端接收包数     | 该参数表示fabric链路探测源端接收成功的包数量。                                                                                                                                                         |
| 丢包率（‰）     | 该参数表示fabric链路探测丢包占比。                                                                                                                                                               |
| 错包率（‰）     | 该参数表示fabric链路探测错包占比。                                                                                                                                                               |
| 最大时延时间     | 该参数表示fabric链路探测最大时延时间。                                                                                                                                                             |
| 最小时延时间     | 该参数表示fabric链路探测最小时延时间。                                                                                                                                                             |
| 平均时延时间     | 该参数表示fabric链路探测平均时延时间。                                                                                                                                                             |
| 最大抖动时间     | 该参数表示fabric链路探测最大抖动时间。                                                                                                                                                             |
| 最小抖动时间     | 该参数表示fabric链路探测最小抖动时间。                                                                                                                                                             |
| 平均抖动时间     | 该参数表示fabric链路探测平均抖动时间。                                                                                                                                                             |
| 探测状态       | 该参数表示fabric链路探测状态。 取值说明： DETECTING（正在探测）DETECTED（完成探测）SOURCE_PORT_DOWN（源端口故障）DESTINATION_PORT_DOWN（目的端口故障）                                                                         |
