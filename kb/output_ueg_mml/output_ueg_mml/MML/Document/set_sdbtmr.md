# 设置核查定时器配置（SET SDBTMR）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

此命令用于设置系统中SDB（Subscriber DataBase）模块维护相关的定时器配置。

#### 注意事项

- 该命令执行后生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称             | 参数说明                                                                                                              |
|:--------|:-----------------|:------------------------------------------------------------------------------------------------------------------|
| PURGTMR | 用户分离后签约数据保留时间（h） | 可选必选说明：必选参数 参数含义：该参数用于指定定时器在用户分离后启动，在用户附着后停止，如果超时，将删除UNC上的用户的签约数据。 数据来源：整网规划 取值范围：0～240h 系统初始设置值：24 配置原则：建议值为24h。 |

#### 使用实例

1. 设置系统用户分离后签约数据保留时间：

   SET SDBTMR: PURGTMR=24;
