# 删除Pre-R8 QoS到TOS/DSCP的映射规则（RMV PRER8REMARK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：GGSN**

该命令用于删除QoS参数映射到IP报文头中的TOS（服务类型）或者DSCP（区别服务编码点）的映射配置。

## 注意事项

该命令执行后只对新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称          | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                    |
|:---------------|:--------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| QOSPROFILENAME | QoS Profile名称 | 可选必选说明：必选参数  参数含义：该参数用于指定QosProfile的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。不区分大小写。  默认值：无  配置原则：  该参数需要先通过ADD QOSPROFILE或者SET CPQOSGLOBAL命令配置。                                                                                                                                                                                                                                                                          |
| SERVICELEVEL   | 业务级别          | 可选必选说明：必选参数  参数含义：该参数用于指定业务级别。  数据来源：本端规划 取值范围： “CONVERSATIONAL（会话业务）”：会话业务。“STM_GBR_MORE25K（下行保证带宽大于等于25kbit/s的流类业务）”：下行保证带宽大于等于25kbit/s的流类业务。“STM_GBR_LESS25K（下行保证带宽小于25kbit/s的流类业务）”：下行保证带宽小于25kbit/s的流类业务。“INT_TC_PRI1（发送控制优先级为1的交互类业务）”：发送控制优先级为1的交互类业务。“INT_TC_PRI2（发送控制优先级为2的交互类业务）”：发送控制优先级为2的交互类业务。“INT_TC_PRI3（发送控制优先级为3的交互类业务）”：发送控制优先级为3的交互类业务。“BACKGROUND（背景业务）”：背景业务。“GENERAL（通用业务）”：通用业务。  默认值：无  配置原则：无 |
| USERPRIORITY   | 用户级别          | 可选必选说明：必选参数  参数含义：该参数用于指定用户级别。  数据来源：本端规划 取值范围： “GENERAL（通用用户）”：通用用户。“HIGH（高端用户）”：高端用户。“NORMAL（普通用户）”：普通用户。“LOW（低端用户）”：低端用户。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                             |

## 使用实例

删除QoS Profile名称为profile的QoS的DSCP的映射信息：

```
RMV PRER8REMARK: QOSPROFILENAME="profile", SERVICELEVEL=GENERAL, USERPRIORITY=HIGH;
```
