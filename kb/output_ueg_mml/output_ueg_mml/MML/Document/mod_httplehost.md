# 修改HTTP域名配置（MOD HTTPLEHOST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于对配置数据库中的一条HTTP域名配置信息数据记录的某些参数进行修改或调整。在该命令中，系统通过“本端实体标识”参数来唯一标识一条HTTP域名配置信息。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                               |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LEID   | 本端实体标识 | 标识一条HTTP域名配置信息的关键字段（其取值不能被修改），用于指定需要对哪一个“本端实体标识”对应的HTTP域名配置信息数据记录的参数进行修改或调整，操作员可以使用LST HTTPLEHOST命令查询获得。 取值范围：0～255。 默认值：无。 注意：该参数为必选参数。                           |
| TYPE   | 类型     | 用于指定要修改的HTTP域名配置信息中本端HTTP实体的类型是BSF还是AP。 取值范围：BSF(BSF)：UIM实现GBA认证功能时，作为BSF功能实体。AP(AP)：UIM实现GBA认证功能时，作为AP功能实体。 默认值：无。 注意：该参数为可选参数。                                   |
| FQDN   | 全量域名   | 用于指定要修改的HTTP域名配置信息中BSF或AP实体的全量域名（Fully Qualified Domain Name）。全局唯一，不能重复。 需要指出的是，该参数不区分大小写，在执行LST HTTPLEHOST命令查询出的报文中为全小写形式。 取值范围：长度不超过127的字符串。 默认值：无。 注意：该参数为可选参数。 |
| LENAME | 本端实体名  | 用于指定要修改的HTTP域名配置信息中本端HTTP实体的名称。全局唯一，不能重复。 取值范围：长度不超过127的字符串。 默认值：无。 注意：该参数为可选参数。                                                                                   |

## 使用实例

修改一条HTTP域名配置信息，携带以下参数：

- “本端实体标识”为“1”
- “类型”为“AP(AP)”
- “全量域名”为“xcap.mnc000.mcc460.pub.3gppnetwork.org”
- “本端实体名”为“ap”

执行命令如下：

```
MOD HTTPLEHOST: LEID=1, TYPE=AP, FQDN="xcap.mnc000.mcc460.pub.3gppnetwork.org", LENAME="ap";
```
