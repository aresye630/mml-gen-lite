# 查询N3接口故障RAN组（LST FAULTRANGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、SMF**

该命令用于查询N3接口故障RAN组，当N3接口出现故障，SMF在为通过该RAN组内的RAN接入的用户选择UPF时，会自动过滤掉与该RAN组绑定的UPF组内的UPF。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                              |
|:-----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
| RANGRPNAME | RAN组名  | 可选必选说明：可选参数  参数含义：该参数用于指定RAN组名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。不支持空格及特殊字符“#”、“$”和“&”等，由“-”、“_”、数字、字母和“.”组成，不能以“.”开头或结尾，不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

查询所有N3接口故障RAN组：

```
%%LST FAULTRANGRP:;%%
RETCODE = 0  操作成功

结果如下
--------
           RAN组名 =  group1
UP链路故障处理模式 = 直接隔离
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称      | 输出项解释              |
|:-----------|:-------------------|
| RAN组名      | 该参数用于指定RAN组名。      |
| UP链路故障处理模式 | 该参数用于指定UP链路故障处理模式。 |
