# 删除HTTP本端实体组（RMV HTTPLEGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除HTTP本端实体组信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                   |
|:-------|:-------|:---------------------------------------------------------------------------------------|
| INDEX  | 索引     | 可选必选说明：必选参数  参数含义：该参数用于指定HTTP本端实体组的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~64。  默认值：无  配置原则：无 |

## 使用实例

若想删除一组索引为1的HTTP本端实体组：

```
RMV HTTPLEGRP: INDEX=1;
```
