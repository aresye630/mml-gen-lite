# 查询AP功能体本局信息(LST APTYPE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询AP功能体本局数据信息。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                               |
|:-------|:-------|:---------------------------------------------------|
| UIMID  | UIM标识  | 用于指示系统按照哪个“UIM标识”来查询AP功能体本局信息；若不输入，则表示所有AP功能体本局信息。 |

## 使用实例

查询AP功能体本局信息，“UIM标识”为“1”:

```
LST APTYPE: UIMID=1;
```

返回结果如下

```
%%LST APTYPE:;%%
RETCODE = 0  操作成功
结果如下
--------
UIM标识  =  1
 AP类型  =  转发
(结果个数 = 1)
---    END
```

请参见**SET APTYPE**命令的参数说明。
