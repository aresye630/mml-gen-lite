#### 命令功能

**适用网元：MME**

该命令用于修改S1模式接入限制参数。该命令先根据IMSI号段将用户进行分类，再对每一类用户按照用户签约的ARD信息、签约的APN信息进行区分而控制用户接入E-UTRAN网络。

#### 注意事项

- 当本表记录中存在用户的IMSI对应的IMSI前缀或者所在的IMSI范围，且用户的属性（APNNI）与S1ARD配置的属性匹配时，按照该配置的控制类型（CTRLTYPE）对用户接入进行控制。
- 当本表记录中存在用户的IMSI对应的IMSI前缀或者所在的IMSI范围，且用户的属性（APNNI）与S1ARD配置的属性均不匹配时，按照与该配置相反的控制类型（CTRLTYPE）对用户接入进行控制。
- 当本表记录中不存在用户的IMSI对应的IMSI前缀或者所在的IMSI范围时，不限制用户接入。
- 此配置涉及用户接入控制功能特性（特性编号：WSFD-106003，License部件编码：LKV2ARD02），执行命令请使用**DSP LICENSE**命令确认对应特性license是否得到授权，执行**LST LICENSESWITCH**命令确认特性开关状态为“ENABLE(打开)”。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|:---------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围    | 可选必选说明：必选参数 参数含义：该参数用于指定用户范围。 数据来源：整网规划 取值范围：“ALL_USER(所有用户)”：表示该指定用户范围为所有用户。“SPECIAL_IMSIPRE(指定IMSI前缀)”：表示该用户范围为指定IMSI前缀。“SPECIAL_IMSI_RANGE(指定IMSI范围)”：表示该用户范围为指定IMSI范围。 默认值：无                                                                                                                                                                                                                                                                                             |
| IMSIPRE  | IMSI前缀  | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI前缀。使用时按照IMSI完全匹配进行查询。 前提条件：该参数在“SUBRANGE（用户范围）”设置为“SPECIAL_IMSIPRE(指定IMSI前缀)”时生效。 数据来源：整网规划 取值范围：1～15位数字 默认值：无                                                                                                                                                                                                                                                                                                                                 |
| IMSI     | IMSI    | 可选必选说明：条件必选参数 参数含义：该参数用于配置指定用户的IMSI，对该IMSI所在号段进行修改。 前提条件：该参数在“SUBRANGE(用户范围)”设置为“SPECIAL_IMSI_RANGE(指定IMSI范围)”时生效。 数据来源：整网规划 取值范围：1～15位数字 默认值：无                                                                                                                                                                                                                                                                                                                              |
| APNNI    | APNNI   | 可选必选说明：可选参数 参数含义：该参数用于配置指定APNNI。 数据来源：整网规划 取值范围：1～62位字符串 默认值：无 配置原则：APN网络标识地址由一个或多个LABEL构成，各LABEL间用“.”间隔。每个LABEL的构成字符只能是字母A～Z或a～z、数字0～9和中划线“-”，字母不区分大小写。APN网络标识地址不能以“rac”、“lac”、“sgsn”或“rnc”开头，不能以“.gprs”结尾。  说明： 如果APNNI配置为“*”，表示该记录适用于所有的APNNI。                                                                                                                                                                                                                            |
| ARD      | 启用签约ARD | 可选必选说明：可选参数 参数含义：该参数用于指定是否启用签约ARD。 数据来源：整网规划 取值范围：“NO(否)”“YES(是)” 默认值:无 配置原则：不启用签约ARD时，该参数设置为“NO(否)”；启用签约ARD时，该参数设置为“YES(是)”。不建议同时使用签约ARD功能与签约APN NI功能。                                                                                                                                                                                                                                                                                                                      |
| CTRLTYPE | 控制类型    | 可选必选说明：可选参数 参数含义：该参数用于指定是否允许用户接入。 数据来源：整网规划 取值范围：“ALLOW(允许)”“REJECT(拒绝)” 默认值：无                                                                                                                                                                                                                                                                                                                                                                                               |
| CAUSE    | 原因值     | 可选必选说明：可选参数 参数含义：该参数用于指定拒绝用户接入时使用的原因值。 数据来源：整网规划 取值范围：“CUSTOMER_DEFINED(自定义)”“EPS_SERVICE_NOT_ALLOWED(EPS_SERVICE_NOT_ALLOWED)”“EPS_NONEPS_SRV_NOT_ALLOWED(EPS_NONEPS_SRV_NOT_ALLOWED)”“PLMN_NOT_ALLOWED(PLMN_NOT_ALLOWED)”：“TA_NOT_ALLOWED(TA_NOT_ALLOWED)”“ROAMING_NOT_ALLOWED_IN_TA(ROAMING_NOT_ALLOWED_IN_TA)”“EPS_SRV_NOT_ALLOWED_IN_PLMN(EPS_SRV_NOT_ALLOWED_IN_PLMN)”“NO_SUITABLE_CELLS_IN_TA(NO_SUITABLE_CELLS_IN_TA)” 默认值：无  说明： 附着或路由更新拒绝的原因值，请参考3GPP TS 24.301输入。 |
| SDCAUSE  | 自定义原因值  | 可选必选说明：条件必选参数 参数含义：该参数用于指定自定义原因值。 前提条件：该参数在“CAUSE(原因值)”设置为“CUSTOMER_DEFINED(自定义)”时生效。 数据来源：整网规划 取值范围：1～254 默认值：无  说明： 当原因值为自定义时，根据3GPP TS 24.301填写。                                                                                                                                                                                                                                                                                                                          |

#### 使用实例

1. 修改所有用户的Iu模式接入限制记录，将控制类型修改为“允许”：

   MOD S1ARD: SUBRANGE=ALL\_USER, CTRLTYPE=ALLOW;
2. 修改IMSI前缀为123456的Iu模式接入限制记录，将控制类型修改为“允许”：

   MOD S1ARD: SUBRANGE=SPECIAL\_IMSIPRE, IMSIPRE="123456", CTRLTYPE=ALLOW;
