# 查询HTTP端口分配信息(LST HTTPPORTINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询HTTP端口分配信息。

- 当需要查询某个HLB实列的HTTP端口分配信息时，输入参数“HLB实例ID”进行查询。
- 当需要查询所有实列的HTTP端口分配信息时，不输入参数直接进行查询。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                          |
|:-------|:--------|:--------------------------------------------------------------------------------------------------------------|
| HLBID  | HLB实例ID | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个HLB的实例ID查询HTTP端口分配信息。若不输入表示查询所有HLB实例的HTTP端口分配信息。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询“HLB实例ID”为“201909041621FECA”的HTTP端口分配信息：

   ```
   LST HTTPPORTINFO:HLBID="201909041621FECA";
   ```

   ```
   %%LST HTTPPORTINFO:HLBID="201909041621FECA";%% 
   RETCODE = 0  操作成功    
   HLB实例ID         起始端口  端口数量  其他说明    
   201909041621FECA  20000     20        NULL       
   201909041621FECA  65535     1         NULL           
   (结果个数 = 2)  
   ---    END
   ```
2. 查询所有HLB实例ID的HTTP端口分配信息：

   ```
   LST HTTPPORTINFO:;
   ```

   ```
   %%LST HTTPPORTINFO:;%% 
   RETCODE = 0  操作成功    
   HLB实例ID         起始端口  端口数量  其他说明    
   201909041621FECA  20000     20        NULL       
   201909041621FECA  65535     1         NULL       
   201909041621FECB  20020     60        NULL       
   201909041621FECB  20080     128       NULL       
   201909041621FECB  20208     1         NULL       
   (结果个数 = 5)  
   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。各参数含义如表1所示。

| 输出项名称   | 输出项解释                  |
|:--------|:-----------------------|
| 起始端口    | 用于返回系统分配的起始端口。         |
| 端口数量    | 用于返回系统分配的端口数量。         |
| 其他说明    | 用于返回HTTP端口分配记录的一些附加说明。 |
