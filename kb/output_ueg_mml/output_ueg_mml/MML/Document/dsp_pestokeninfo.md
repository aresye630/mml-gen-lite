# 查询PES业务Token信息（DSP PESTOKENINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询PES内Token的分配信息。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                             |
|:------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 服务类型   | 可选必选说明：必选参数 参数含义：用于定义不同的查询条件，以此实现不同的查询功能。 取值范围：PES(PcfPolicyEngineService) 默认值：无。 配置原则：无。                                                        |
| INSTID      | 服务实例ID | 可选必选说明：可选参数 参数含义：用于标识微服务实例ID；若不输入，则表示所有微服务实例ID。  说明： 实例ID查询方法：执行DSP SERVICEINFO命令获取返回微服务的实例ID。 取值范围：长度不超过256的字符串。 默认值：无。 配置原则：必须是PES服务类型对应的实例ID。 |

## 使用实例

查询PES内Token的分配信息。“服务类型”为“PES(PcfPolicyEngineService)”，“服务实例ID”为“538702957”。

```
DSP PESTOKENINFO: SERVICETYPE=PES, INSTID="538702957";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项解释请参见表1。

| 输出项名称   | 输出项解释                                                   |
|:--------|:--------------------------------------------------------|
| 服务实例ID  | 用于指示查询结果中的实例号。 取值范围：长度不超过256的字符串。 默认值：无。                |
| Pod名称   | 用于指示查询结果中Pod的名称，取自各个微服务对应的Pod。 取值范围：长度不超过64的字符串。 默认值：无。 |
| Token值  | 用于指示查询结果中服务实例分配到的Token值。 取值范围：0-2147483647。 默认值：无。      |
| Token数量 | 用于指示查询结果中服务实例分配的Token数量。 取值范围：0-2147483647。 默认值：无。      |
