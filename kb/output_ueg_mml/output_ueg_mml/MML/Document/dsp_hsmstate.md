# 显示HSM状态(DSP HSMSTATE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询本端指定HSM设备的实时状态信息。

## 注意事项

状态查询消息优先级高于鉴权请求消息优先级，ALB处理状态查询消息时，选择链路后优先发送状态查询消息。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                             |
|:--------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------|
| HSMNAME | HSM名称  | 可选必选说明：可选参数 用于指示系统查询哪个HSM设备名称对应的HSM设备运行状态；若不输入，则表示查询所有的HSM设备名称对应的HSM设备运行状态。 取值范围：长度不超过64的字符串。 默认值：无。 配置原则：仅支持查询已在ADD HSMRSRV命令添加的“HSM名称”对应的状态信息。 |

## 使用实例

查询HSM设备的状态信息：

```
DSP HSMSTATE:;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，参数含义请参见表1的参数说明。

| 输出项名称           | 输出项解释                                             |
|:----------------|:--------------------------------------------------|
| HSM名称           | 用于在配置数据库中定义一个HSM设备的别名，在UDM中唯一，为便于区分，建议取有意义的名称。    |
| HSM状态           | 用于返回指定HSM设备当前所处的状态： “1”：故障。“2”：出厂。“4”：初始化。“5”：运行。 |
| HSM ID标识        | 用于在配置数据库中定义一条HSM设备数据记录索引，该索引仅供内部使用，无实际含义。         |
| 固件版本号           | 用于返回指定HSM的固件版本号。                                  |
| 管理信息1           | 用于返回HSM设备商指定的管理信息1。                               |
| 管理信息2           | 用于返回HSM设备商指定的管理信息2。                               |
| 管理信息3           | 用于返回HSM设备商指定的管理信息3。                               |
| 温度状态            | 用于返回指定HSM设备当前温度状态： “0”：正常。“1”：过低。“2”：过高。          |
| 温度              | 用于返回指定HSM设备当前温度。                                  |
| 内部安全保护壳状态       | 用于返回指定hsm设备内部安全保护壳当前状态： “0”：正常。“1”：损坏。            |
| 外部安全保护壳状态       | 用于返回指定HSM设备外部安全保护壳当前状态： “0”：正常。“1”：损坏。            |
| 电源状态            | 用于返回指定HSM设备电源当前状态： “0”：正常。“1”：过低。“2”：过高。          |
| SD-RAM已使用内存     | 用于返回指定HSM设备SRAM已使用内存。                             |
| SD-RAM空闲内存      | 用于返回指定HSM设备SD-RAM未使用内存。                           |
| Secure-RAM已使用内存 | 用于返回指定HSM设备Secure-RAM已使用内存。                       |
| Secure-RAM空闲内存  | 用于返回指定HSM设备Secure-RAM未使用内存。                       |
