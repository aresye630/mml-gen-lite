# 删除DCC模板（RMV DCCTEMPLATE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于删除DCC在线计费模板。

#### 注意事项

- 该命令执行后立即生效。
- 当DCCTemplate配置在APNCharge、GlbDccTemplate、UsrProfCharge中时，不可以删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                    |
|:-------------|:--------|:----------------------------------------------------------------------------------------|
| DCCTMPLTNAME | DCC模板名称 | 可选必选说明：必选参数 参数含义：该参数用于指定操作的DCC在线计费模板的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无 |

#### 使用实例

删除名为“DccTemplate”的DCC在线计费模板：

```
RMV DCCTEMPLATE:DCCTMPLTNAME="DccTemplate";
```
