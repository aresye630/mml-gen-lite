# 设置APP配置数据检查功能（SET DATACHKPOLICY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于设置APP配置数据检查功能开关状态。

#### 注意事项

- 该命令执行后立即生效。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| AUTOSWITCH   |
|:-------------|
| on           |

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                 |
|:----------------|:-------|:---------------------------------------------------------------------------------------------------------------------|
| AUTOSWITCH      | 自动检查开关 | 可选必选说明：必选参数 参数含义：自动检查开关。 数据来源：本端规划 取值范围：枚举类型。 on：开启。off：关闭。 默认值：无                                                    |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识，0表示VNFP。 |

#### 使用实例

设置APP配置数据自动检查开关状态为on：

```
SET DATACHKPOLICY:AUTOSWITCH=on,SERVICEINSTANCE="vnfc";
```
