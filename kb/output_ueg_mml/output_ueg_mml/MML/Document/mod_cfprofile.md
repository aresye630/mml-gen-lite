# 修改内容过滤策略（MOD CFPROFILE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于修改内容过滤策略。

#### 注意事项

该命令执行后只对之后发生承载更新的用户或者新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                          |
|:--------------|:---------|:----------------------------------------------------------------------------------------------|
| CFPROFILENAME | 内容过滤策略名称 | 可选必选说明：必选参数 参数含义：该参数用于设置内容过滤策略名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无 |
| PRIORITY      | 优先级      | 可选必选说明：必选参数 参数含义：该参数用于设置优先级。 数据来源：本端规划 取值范围：整数类型，取值范围为1~65535。 默认值：无 配置原则：无                   |
| CFGDOMAINNAME | 配置域名称    | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无            |

#### 使用实例

配置CFPROFILE，优先级修改成2：

```
MOD CFPROFILE: CFPROFILENAME="cfp1", PRIORITY=2;
```
