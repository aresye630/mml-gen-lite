# 设置APN Non-IP配置（SET APNNONIPFUNC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

此命令用于开启或关闭指定APN的网关Non-IP功能。

#### 注意事项

- 该命令执行后立即生效。
- 系统最多支持配置10000条APNNonIpFunc。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | NONIPSWITCH   |   USERPORT |
|:-------|:--------------|-----------:|
| 初始值    | DISABLE       |       5683 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称           | 参数说明                                                                                                                                                                                                                    |
|:------------|:---------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN         | APN            | 可选必选说明：必选参数 参数含义：该参数用于指定APN实例名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～64。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。 默认值：无 配置原则：该参数使用ADD UPAPN命令配置生成。 |
| NONIPSWITCH | APN Non-IP功能开关 | 可选必选说明：可选参数 参数含义：该参数用于基于APN控制开启和关闭Non-IP功能。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则： ENABLE：开启基于APN控制Non-IP的功能。DISABLE：关闭基于APN控制Non-IP的功能。                                                               |
| USERPORT    | 用户端口号          | 可选必选说明：可选参数 参数含义：指定用户的端口号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～65535。 默认值：无 配置原则：无                                                                                                                                               |

#### 使用实例

使能apn apn1.com的Non-IP功能：

```
SET APNNONIPFUNC:APN="apn1.com",NONIPSWITCH=ENABLE;
```
