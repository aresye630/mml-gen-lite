# 显示去活用户会话的速率（LST DEACTIVERATE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用来查询已配置的去活用户的会话速率。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

运营商配置了去活用户会话的速率，可以使用该命令来查询已配置的去活用户会话速率：

```
LST DEACTIVERATE:;
```

```
RETCODE = 0  操作成功。

结果如下
--------
去活速率（会话/秒）  =  25
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见SET DEACTIVERATE的参数说明。
