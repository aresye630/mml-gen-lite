# 增加Fabric-Trunk成员接口（ADD FABRICTRUNKMEMBER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于增加NP卡Fabric-Trunk成员接口。在非NP卡基础上扩容NP卡的异构场景下，将NP卡中的多个物理接口作为一个逻辑接口使用。

#### 注意事项

该命令仅适用于非NP卡基础上扩容NP卡的异构场景，在纯NP场景该命令不生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                               |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRACK | 框号     | 可选必选说明：必选参数。 参数含义：该参数标识Fabric-Trunk接口内成员口所属框的编号。 数据来源：本端规划。 取值范围： “Subrack_0”：框号0。“Subrack_1”：框号1。“Subrack_2”：框号2。“Subrack_3”：框号3。 配置原则：无。 默认值：无。                                                  |
| SLOTID  | 槽位号    | 可选必选说明：必选参数。 参数含义：该参数标识Fabric-Trunk接口内成员口所属插槽的编号。 数据来源：本端规划。 取值范围： “Slot_1”：槽位号1。“Slot_2”：槽位号2。“Slot_3”：槽位号3。“Slot_4”：槽位号4。“Slot_5”：槽位号5。“Slot_6”：槽位号6。“Slot_7”：槽位号7。“Slot_8”：槽位号8。 配置原则：无。 默认值：无。 |
| PORTID  | 端口号    | 可选必选说明：必选参数。 参数含义：该参数标识Fabric-Trunk接口内成员口所对应的端口编号。 数据来源：本端规划。 取值范围： “P1”：端口号1。“P2”：端口号2。“P3”：端口号3。“P4”：端口号4。 配置原则：无。 默认值：无。                                                                        |

#### 使用实例

增加一个Fabric-Trunk成员接口，该接口是1号框，8号槽位中的3号端口：

```
%%ADD FABRICTRUNKMEMBER: SUBRACK=Subrack_1, SLOTID=Slot_8, PORTID=P3;%%
RETCODE = 0  操作成功
---    END
```
