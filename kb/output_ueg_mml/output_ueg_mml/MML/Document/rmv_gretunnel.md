# 删除GRE隧道（RMV GRETUNNEL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除GRE隧道。

当网络重新规划，之前创建的GRE隧道不再使用。此时可执行该命令删除已创建的GRE隧道。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                     |
|:--------|:-------|:-------------------------------------------------------------------------------------------------------------------------|
| TNLNAME | 隧道名称   | 可选必选说明：必选参数 参数含义：该参数用于指定GRE隧道接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：字符串形式为Tunnel+接口编号。 接口编号为一维或三维（格式为X/Y/Z）。 |
| TNLTYPE | 隧道类型   | 可选必选说明：必选参数 参数含义：该参数用于指定隧道类型。 数据来源：本端规划 取值范围：枚举类型。 gre：指定隧道类型为Gre。gre6：指定隧道类型为Gre6。 默认值：无                                |

#### 使用实例

已建立GRE隧道Tunnel1，现需要删除该隧道：

```
RMV GRETUNNEL:TNLNAME="Tunnel1",TNLTYPE=gre;
```
