# 查询MPLS LSP统计信息（DSP MPLSLSPSTC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询MPLS LSP统计信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称       | 参数说明                                                                                                                                                               |
|:--------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LSPTYPE | MPLS LSP类型 | 可选必选说明：可选参数 参数含义：该参数用于表示MPLS LSP类型。 数据来源：本端规划 取值范围：枚举类型。 LDP_LSP：LDP LSP。BGP_LSP：BGP LSP。BGP_IPV6_LSP：BGP IPv6 LSP。L3VPN_IPV6_LSP：L3VPN IPv6 LSP。LSP：所有的LSP。 默认值：无 |

#### 使用实例

查询MPLS LSP统计信息：

```
DSP MPLSLSPSTC:;
```

```
RETCODE = 0  操作成功。

结果如下
--------
MPLS LSP类型      LSP总计数量        入节点数量     中间节点数量    出节点数量

LDP LSP           13                 5              5               3
BGP LSP           0                  0              0               0
BGP IPv6 LSP      0                  0              0               0
L3VPN IPv6 LSP    0                  0              0               0
所有的LSP         13                 5              5               3
(结果个数 = 5)
---    END
```

| 入节点数量      | 用于表示入节点数量。      |
| 中间节点数量     | 用于表示中间节点数量。     |
