# 查询对端网元静态信息（LST PNFSTCINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询对端网元静态信息。

- 如果需要查询全部对端网元静态信息，请不要输入任何参数。
- 如果需要查询指定对端网元静态信息，请依据参数说明输入查询条件。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                       |
|:------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| ID          | ID     | 可选必选说明：可选参数 参数含义：用于标识对端网元ID。 取值范围：0~2000 默认值：无。 配置原则：无。                                                                                    |
| NFTYPE      | 网元类型   | 可选必选说明：可选参数 参数含义：用于标识对端网元类型。 取值范围： SMF(SMF) AMF(AMF) AF(AF)BSF(BSF) CHF(CHF) SCP(SCP) NWDAF(NWDAF)HPCF(HPCF)NRF(NRF) 默认值：无。 配置原则：无。        |
| IPVER       | IP版本   | 可选必选说明：可选参数 参数含义：用于指定对端网元的IP地址的IP版本类型。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。                                                           |
| IPV4IP      | IPv4地址 | 可选必选说明：条件必选参数 参数含义：当“IPVER”选择“IPV4(IPV4)”时该参数必须配置，用于表示对端网元的IPv4地址。 取值范围：IPv4地址 默认值：无。 配置原则：无。                                              |
| IPV6IP      | IPv6地址 | 可选必选说明：条件必选参数 参数含义：当“IPVER”选择“IPV6(IPV6)”时该参数必须配置，用于表示对端网元的IPv6地址。 取值范围：IPv6地址 默认值：无。 配置原则：无。                                              |
| NFINSTNAME  | 网元实例名称 | 可选必选说明：可选参数 参数含义：用于标识对端网元的名称。 取值范围：长度不超过64的字符串 默认值：无。 配置原则：无。  说明： 当SET HTTPCLIENTCFG中“LINKCTLMODE”参数取值为“OLD(旧模式）”时，上报的告警不支持携带本参数“网元实例名称”。 |
| DESCRIPTION | 描述     | 可选必选说明：可选参数 参数含义：用于描述对端网元的IP地址的用途。 取值范围：0~128位字符串 默认值：无。 配置原则：无。                                                                           |

## 使用实例

1. 查询所有对端网元静态信息。

   ```
   LST PNFSTCINFO:;
   ```

   ```
   %%LST PNFSTCINFO:;
   %% RETCODE = 0  操作成功 
    
   操作结果如下 
   ------------------------ 
   ID  网元类型  IP版本  IPv4地址        IPv6地址                                网元实例名称  描述
   0   SMF       IPV4    10.255.255.255  ::                                      TestSMF       NULL          
   1   AMF       IPV6    0.0.0.0         FC00:123:4567:8901:2345:6789:1234:5678  TestAMF       NULL          
   2   BSF       IPV4    10.0.0.0        ::                                      TestBSF       NULL          
   (结果个数 = 3)

   ---    END
   ```
2. 查询“ID”为“2”的对端网元静态信息。

   ```
   LST PNFSTCINFO: ID=2;
   ```

   ```
   %%LST PNFSTCINFO: ID=2;
   %% RETCODE = 0  操作成功 

   操作结果如下 
   ------------------------               
             ID  =  2          
       网元类型  =  BSF       
         IP版本  =  IPV4     
       IPv4地址  =  10.0.0.0     
       IPv6地址  =  :: 
   网元实例名称  =  TestBSF      
           描述  =  NULL 
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见ADD PNFSTCINFO命令的参数说明。
