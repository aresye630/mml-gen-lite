# 增加区域码转换策略(ADD ZCCONVERT)

#### 命令功能

**适用网元：SGSN、MME**

此命令用于增加区域码转换策略。区域码用于定义允许或者禁止用户漫游的区域，通过指定本地的区域码转换策略，运营商可以覆盖HLR/HSS中为用户签约的区域码。

#### 注意事项

- 此命令最大记录数为1024。
- 此命令执行后立即生效。
- 区域码转换策略仅在**SET MMFUNC**的参数“区域码”设置为“YES（是）”时，才能生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                      |
|:------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE    | 用户范围   | 可选必选说明：必选参数 参数含义：该参数用于指定待增加区域码转换策略的用户范围。 数据来源：全网规划 取值范围：“ALL_USER（所有用户）”“HOME_USER（本网用户）”“FOREIGN_USER（外网用户）”“IMSI_PREFIX（指定IMSI前缀）” 默认值：无  说明： 区域码转换策略优先级从高到低为：“IMSI_PREFIX（指定IMSI前缀）”，“FOREIGN_USER（外网用户）”或“HOME_USER（本网用户）”，“ALL_USER（所有用户）”。                                                                                          |
| NOID        | 运营商标识  | 可选必选说明：条件必选参数 参数含义：该参数用于指定运营商标识。 前提条件：该参数在“SUBRANGE（用户范围）”配置为“FOREIGN_USER（外网用户）”或“HOME_USER（本网用户）”后生效。 数据来源：全网规划 取值范围：0～64，128～254 默认值：无 配置原则：若该参数需要配置为0或128～254之间的值时，须先在ADD MNO中配置取值相同的“MNOID”参数。若该参数需要配置为1～64之间的值时，须先在ADD MVNO中配置取值相同的“MVNOID”参数。  说明： 对于外网用户，该参数是与其归属运营商签订可漫游协议，为其提供服务的MNO运营商标识。 对于本网用户，该参数是为该用户归属的MNO运营商标识。          |
| IMSIPRE     | IMSI前缀 | 可选必选说明：条件必选参数 参数含义：该参数用于指定区域码转换的IMSI前缀。系统根据该参数值对用户的IMSI进行匹配，从而区分不同的用户群。 前提条件：只有“SUBRANGE（用户范围）”为“IMSI_PREFIX（指定IMSI前缀）”时，该参数才有效。 数据来源：全网规划 取值范围：1～15位十进制数字字符串 默认值：无                                                                                                                                                                       |
| CONVERTPLCY | 转换策略   | 可选必选说明：必选参数 参数含义：本参数取值为“IGNORE_SUB_ZC（忽略签约ZC）”时，表示忽略用户的签约ZC，UNC不再根据签约ZC进行接入控制，直接允许用户接入。本参数取值为“OVERWRITE_DIRECTLY（采用指定ZC）”时，表示无论用户是否存在签约ZC，均使用本命令指定的ZC进行ZC接入限制。本参数取值为“OVERWRITE_IF_SUB（签约则采用指定ZC）”时，表示如果用户存在签约ZC，使用本命令指定的ZC进行ZC接入限制。 数据来源：全网规划 取值范围：“IGNORE_SUB_ZC(忽略签约ZC)”“OVERWRITE_DIRECTLY(采用指定ZC)”“OVERWRITE_IF_SUB(签约则采用指定ZC)” 默认值：无 |
| ZC          | 区域码    | 可选必选说明：条件必选参数 参数含义：该参数用于指定区域码。 前提条件: 该参数需要在ADD ZC中事先配置，可执行LST ZC进行查看。 数据来源：全网规划 取值范围：0x0000～0xFFFF 默认值：无 配置原则：输入16进制数时，可以直接输入，也可以在数字前加0X或0x。                                                                                                                                                                                              |

#### 使用实例

运营商B的用户漫游到A时，其ZC码与A定义的ZC码相同，A忽略漫游用户的ZC码:

ADD ZCCONVERT: SUBRANGE=FOREIGN\_USER, NOID=130, CONVERTPLCY=IGNORE\_SUB\_ZC;

配置IMSI前缀为1230301的用户只能在跟踪区4201~4209中接入，其它区域均拒绝接入：

ADD ZC: ZC="0x2000", IDTYPE=TA, MCC="123", MNC="03", TAC="4201", TACRANGE="4209";

ADD ZCCONVERT: SUBRANGE=IMSI\_PREFIX, IMSIPRE="1230301", CONVERTPLCY=OVERWRITE\_DIRECTLY, ZC="0x2000";
