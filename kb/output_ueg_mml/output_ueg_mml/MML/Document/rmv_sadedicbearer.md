# 删除业务感知专有承载配置（RMV SADEDICBEARER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，该命令会影响业务触发的QoS保障特性，请谨慎使用并联系华为技术支持协助操作。

该命令用于删除某一个协议或协议组触发专有承载创建的模式。

#### 注意事项

- 该命令执行后立即生效。
- 不支持批量删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                |
|:--------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROTOCOLLEVEL | 协议等级   | 可选必选说明：必选参数 参数含义：该参数用于指定协议、子协议类型。 数据来源：本端规划 取值范围：枚举类型。 PROTOCOLGROUP：协议组级别。PROTOCOL：协议级别。 默认值：无 配置原则：无                                                              |
| PROTOCOLNAME  | 协议名称   | 可选必选说明：条件必选参数 前提条件：该参数在“PROTOCOLLEVEL”配置为“PROTOCOL”时为必选参数。 参数含义：该参数用于指定协议名称。数据源为系统支持识别的所有类型的协议、子协议。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无     |
| PROTGROUPNAME | 协议组名称  | 可选必选说明：条件必选参数 前提条件：该参数在“PROTOCOLLEVEL”配置为“PROTOCOLGROUP”时为必选参数。 参数含义：该参数用于指定协议组名称。数据源为系统支持识别的所有类型的协议分类。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

删除业务感知专有承载配置：PROTOCOLEVEL为PROTOCOLGROUP，PROTGROUPNAME为p2p：

```
RMV SADEDICBEARER:PROTOCOLLEVEL=PROTOCOLGROUP,PROTGROUPNAME="p2p";
```
