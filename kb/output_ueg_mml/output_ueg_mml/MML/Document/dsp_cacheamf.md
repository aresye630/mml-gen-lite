# 查询AMF缓存信息（DSP CACHEAMF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于查询AMF缓存信息。

- 若要查询全部AMF缓存信息，请不要输入任何参数。
- 若要查询某个服务的某个实例的AMF缓存信息，请输入“服务ID”及“实例ID”参数。

## 注意事项

- “服务ID”和“实例ID”要么同时输入，要么都不输入。
- 当**MOD UDMSOFTPARA**命令中的“UDMConfig”对应的“MaxCacheAMF（UDM最大AMF缓存记录数）”参数取值为“0”时，通过**DSP CACHEAMF**命令查询AMF缓存信息返回空值。
- DCS等待每个UDM超时时间3s，超过3s认为查询失败，查询结果中：
  - 如果未输入“服务ID”和“实例ID”，则输出所有服务ID和实例ID值，其他对应的输出项为空。
  - 如果输入“服务ID”和“实例ID”，则输出该服务ID和实例ID值，其他对应的输出项为空。
- 通过该命令可以查询AMF缓存信息和服务发现数据。
  - 如果“是否服务发现结果”字段显示为“是”则UDM访问AMF的状态仅表示服务发现流程和NRF通知流程的AMF状态。
  - 如果“是否服务发现结果”字段显示为“否”且UDM查询AMF的状态为“NOK”，此时，UDM将通知消息发送给备用AMF。如果通过**RMV CACHEAMF**命令删除该条AMF缓存数据，则UDM认为AMF的状态即为正常状态，UDM将通知消息发送给主用AMF。
- 当报文大小超过1M时，请不要查询全部AMF缓存信息，根据条件输入“服务ID”及“实例ID”参数去查询某个服务的某个实例AMF缓存信息。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                           |
|:-----------|:-------|:---------------------------------------------------------------------------------------------------------------|
| SERVICEID  | 服务ID   | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个服务来查询AMF缓存信息；若不输入，则表示查询所有的服务ID。 取值范围：0~4294967295 默认值：无 配置原则：无。                     |
| INSTANCEID | 实例ID   | 可选必选说明：条件必选参数 参数含义：用于指示系统按照哪个实例ID来查询AMF缓存信息；若不输入，则表示查询所有的实例ID。 取值范围：0~4294967295 默认值：无 配置原则：当“服务ID”输入时该参数必须输入。 |

## 使用实例

1. 查询所有AMF缓存信息：

   ```
   DSP CACHEAMF: CONFIRM=Y;
   ```

   ```

   RETCODE = 0  操作成功
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义如表1所示。

| 输出项名称      | 输出项解释                                                |
|:-----------|:-----------------------------------------------------|
| 全局唯一的AMF标识 | 用于返回全局唯一的AMF标识。                                      |
| IP端口       | 用于返回AMF对应的IP和端口号。                                    |
| 全量域名       | 用于返回AMF的全量域名，仅当“是否服务发现结果”为“是”时，会输出该参数。               |
| 容量         | 用于返回AMF网元的容量，仅当“是否服务发现结果”为“是”时，会输出该参数。               |
| 优先级        | 用于返回AMF网元处理的优先级，仅当“是否服务发现结果”为“是”时，会输出该参数。 值越小，优先级越大。 |
| 是否服务发现结果   | 用于返回是否服务发现结果。 是否                                     |
| 过期时间       | 用于返回AMF缓存信息的过期时间。仅当“是否服务发现结果”为“是”时，会输出该参数。           |
| 状态         | 用于返回UDM访问AMF的状态。 OK：可以正常访问。NOK：访问异常。                 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

| 100016 | 参数(参数标识)的值(参数取值)不在指定范围内。   | 输入参数“服务ID”或“实例ID”的取值，不符合取值范围要求。        | 根据实际情况，重新输入“服务ID”或“实例ID”，确保其取值符合要求。    |
