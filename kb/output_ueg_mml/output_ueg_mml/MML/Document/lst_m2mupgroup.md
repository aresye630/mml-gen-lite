# 查询M2M关联的UPF组（LST M2MUPGROUP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于查询M2M关联的UPF组。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询M2M关联的UPF组：

```
LST M2MUPGROUP:;
RETCODE = 0  操作成功

结果如下
--------
UPF组名称 

upfgrp1
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释          |
|:--------|:---------------|
| UPF组名称  | 该参数用于指定UPF组名称。 |
