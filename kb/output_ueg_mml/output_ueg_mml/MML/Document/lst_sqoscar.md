# 查询流行为CAR配置（LST SQOSCAR）

#### 命令功能

该命令用来查询流行为CAR配置。

#### 注意事项

该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                     |
|:-------------|:-------|:-----------------------------------------------------------------------------------------|
| BEHAVIORNAME | 流行为名称  | 可选必选说明：可选参数 参数含义：该参数用于指定流行为名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：区分大小写，不支持空格。 |

查询流行为的CAR配置：

```
LST SQOSCAR:;
```
