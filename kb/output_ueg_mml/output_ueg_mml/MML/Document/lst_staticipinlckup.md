# 查询静态地址段在锁定UPF的用户处理（LST STATICIPINLCKUP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF、SGW-C、PGW-C、GGSN**

该命令用于查询静态地址段在锁定UPF的用户处理。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询静态地址段在锁定UPF的用户处理：
LST STATICIPINLCKUP:;

```
%%LST STATICIPINLCKUP:;%%
RETCODE = 0  操作成功。

结果如下
------------------------
静态用户在锁定UPF的激活处理  =  静态用户可以在锁定的UPF激活
(结果个数 = 1)
```

## 输出结果说明

| 输出项名称           | 输出项解释                                             |
|:----------------|:--------------------------------------------------|
| 静态用户在锁定UPF的激活处理 | 该参数用于指定用户的IP所属的地址段被分配到了锁定的UPF时，是否允许静态用户在锁定的UPF激活。 |
