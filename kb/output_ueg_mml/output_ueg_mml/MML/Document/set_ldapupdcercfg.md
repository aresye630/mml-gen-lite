# 设置LDAP证书更新配置(SET LDAPUPDCERCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

#### 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致业务中断，需联系华为技术支持确认后再执行。

用于设置LDAP证书更新后，LDAP链路重建的相关参数。

#### 注意事项

- LDAP证书更新期间，执行本命令调整参数取值后会实时生效。
- 该命令存在系统初始记录，参数的初始设置值如下：
  - “LDAP重建链时间间隔”为“3”
  - “TLS协商时间间隔”为“2”

#### 参数说明

| 参数标识          | 参数名称        | 参数说明                                                                   |
|:--------------|:------------|:-----------------------------------------------------------------------|
| LDAPRECONTIME | LDAP重建链时间间隔 | 可选必选说明：可选参数 参数含义：用于设置LDAP证书更新后的重建链时间间隔。 取值范围：1~300，单位秒。 默认值：无。 配置原则：无。 |
| TLSRECONTIME  | TLS协商时间间隔   | 可选必选说明：可选参数 参数含义：用于设置TLS协商的时间间隔。 取值范围：1~300，单位秒。 默认值：无。 配置原则：无。        |

#### 使用实例

设置LDAP证书更新配置。“LDAP重建链时间间隔”为“3”，“TLS协商时间间隔”为“2”。

```
SET LDAPUPDCERCFG: LDAPRECONTIME=3, TLSRECONTIME=2;
```
