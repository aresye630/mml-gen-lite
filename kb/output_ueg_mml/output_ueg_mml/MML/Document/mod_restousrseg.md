# 修改容灾用户号段参数 (MOD RESTOUSRSEG)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

此命令用于修改容灾用户号段参数置。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                      |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：必选参数 参数含义：该参数用于指定链式备份功能服务的用户范围。 取值范围： IMSI_PREFIX(指定IMSI前缀) 默认值：无 配置原则：无                                                                                                                           |
| IMSIPRE  | IMSI前缀 | 必选说明：条件必选参数 参数含义：该参数用于指定链式备份功能服务的用户范围的IMSI前缀。 前提条件：该参数在“用户范围”参数配置为“IMSI_PREFIX(指定IMSI前缀)”后生效。 数据来源：全网规划 取值范围：5～15位十进制数字字符串。 默认值：无 配置原则： 无  说明： IMSI前缀的匹配方式采取由前向后的最长匹配，即若对于用户可以匹配到多个用户群，则使用IMSI前缀最长的用户群配置。 |
| ISRESTO  | 是否备份用户 | 可选必选说明：可选参数 参数含义：该参数用于指定是否备份指定用户号段的用户信息。 取值范围： YES (是)NO (否) 默认值：YES (是) 配置原则：无                                                                                                                           |

#### 使用实例

1. 修改容灾用户号段参数配置，可以用如下命令：

   ```
   MOD RESTOUSRSEG: SUBRANGE=IMSI_PREFIX, IMSIPRE=12345, ISRESTO=YES;
   ```
