# 查询IP转发负载分担hash计算模式（LST SFELBHASH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询IP转发负载分担hash计算模式。

#### 注意事项

- 该命令执行后立即生效。
- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。
- 该命令仅支持发往Fabric口方向的报文做负载分担hash。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询负载分担hash计算模式：

```
LST SFELBHASH:;
```

```
RETCODE = 0 操作成功。

结果如下
-------------------------
  报文类型  = IP报文
  hash类型  = 三元组
(结果个数 = 1)
--- 结束
```
