# 查询SMSF号段白名单功能开关 （LST NRFSMSFSEGSW）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NRF**

该命令用于查询SMSF号段白名单开关。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询SMSF号段白名单功能开关。

```
LST NRFSMSFSEGSW:;
%%LST NRFSMSFSEGSW:;%%
RETCODE = 0  操作成功

结果如下
------------------------
SMSF号段白名单开关  =  关闭
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                |
|:--------|:---------------------------------------------------------------------------------------------------------------------|
| 号段白名单开关 | 该参数用于表示NRF是否开启SMSF号段白名单功能。当开关设置为FUNC_ON时，若发现参数中携带的号段在白名单内，NRF会使用号段参数匹配，否则将忽略该号段参数。当开关设置为FUNC_OFF时，NRF将会按照发现参数进行正常匹配。 |
