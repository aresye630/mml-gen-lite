# 删除UPF信息（RMV UPFINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于删除当前MPF对接的UPF配置信息。

#### 注意事项

- 该命令执行后立即生效。
- 删除UPF信息会导致UPF上的规则信息无法被通知修改和删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                          |
|:--------|:-------|:----------------------------------------------------------------------------------------------|
| UPFNAME | UPF名称  | 可选必选说明：必选参数 参数含义：UPF名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无                        |
| IPTYPE  | IP地址类型 | 可选必选说明：必选参数 参数含义：IP地址类型。 数据来源：对端协商 取值范围：枚举类型。 IPV4：表示地址类型为IPv4。IPV6：表示地址类型为IPv6。 默认值：无 配置原则：无 |

#### 使用实例

删除名称为isp.upf001，地址类型为IPv4的UPF配置信息：

```
RMV UPFINFO: UPFNAME="isp.upf001", IPTYPE=IPv4;
RETCODE = 0  操作成功

---    END
```
