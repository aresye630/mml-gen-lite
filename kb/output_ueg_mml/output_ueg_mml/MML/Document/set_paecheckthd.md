# 设置PAE寻呼反压流控检测阈值(SET PAECHECKTHD)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MME、AMF**

该命令用于设置LINK节点相关资源过载检测阈值参数，包括link-pod内pBuf资源使用率过载、恢复门限，PAE与虚拟交换机间消息发送队列使用率过载、恢复门限等信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称        | 参数说明                                                                                                                |
|:---------|:------------|:--------------------------------------------------------------------------------------------------------------------|
| RESTYPE  | 资源类型        | 可选必选说明：必选参数 参数含义：该参数用于表示检测的资源类型。 数据来源：本端规划 取值范围： PBUF（link-pod内使用的pBuf资源） SHAREQUEUE（PAE与软SDN间消息发送队列） 默认值：无 配置原则： 无 |
| TRIGTHD  | 触发过载阈值（%）   | 可选必选说明：可选参数 参数含义：该参数用于表示触发资源过载的阈值。 数据来源：本端规划 取值范围：整数类型，取值范围为2～99。 默认值：80 配置原则： 无                                    |
| RESUMTHD | 触发过载恢复阈值（%） | 可选必选说明：可选参数 参数含义：该参数用于表示触发资源过载恢复的阈值。 数据来源：本端规划 取值范围：整数类型，取值范围为2～99。 默认值：50 配置原则： 无                                  |

#### 使用实例

设置PAE寻呼反压流控检测阈值的资源类型为link-pod内使用的pBuf资源，触发过载阈值（%）为60，触发过载恢复阈值（%）为30：

```
SET PAECHECKTHD: RESTYPE=PBUF, TRIGTHD=60, RESUMTHD=30;
```
