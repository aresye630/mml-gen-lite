# 增加接口绑定VPN（ADD IPBINDVPNIPSEC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该配置影响该隧道下的地址信息，有业务影响。

该命令用于配置接口绑定VPN。

## 注意事项

- 该命令执行后立即生效。

- 执行该命令将清除该接口下所有的IP配置。
- 需要在执行**ADD IPSECINTFCFGIPSEC**之前执行该命令，来使绑定的VPN生效。

- 最多可输入65535条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称      | 参数说明                                                                                                                                          |
|:---------------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------|
| IFNAME         | 接口名       | 可选必选说明：必选参数  参数含义：用于设置绑定VPN的接口名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。接口名称由接口类型+接口编号组成。  默认值：无  配置原则：无                                          |
| IFIPADDR       | IPv4地址    | 可选必选说明：该参数在"IPTYPECHECK"配置为"Ipv4"时为条件可选参数。  参数含义：该参数用于指定需要配置的IPv4地址。  数据来源：本端规划  取值范围：IPv4地址类型。0.0.0.0～255.255.255.255。  默认值：无  配置原则：无        |
| SUBNETMASK     | IPv4地址掩码  | 可选必选说明：该参数在"IPTYPECHECK"配置为"Ipv4"时为条件可选参数。  参数含义：该参数用于指定需要配置的接口IPv4地址的网络掩码。  数据来源：本端规划  取值范围：IPv4地址类型。0.0.0.0～255.255.255.255。  默认值：无  配置原则：无 |
| VRFNAME        | VPN实例名称   | 可选必选说明：必选参数  参数含义：该参数用于指定接口绑定的VPN实例名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。  默认值：无  配置原则：无                                                     |
| IPTYPECHECK    | 校验为V4还是V6 | 可选必选说明：可选参数  参数含义：校验为IPv4还是IPv6。  数据来源：本端规划 取值范围： “Ipv4（IPv4）”：IPv4“Ipv6（IPv6）”：IPv6  默认值：Ipv4  配置原则：无                                        |
| IPV6ADDR       | IPv6地址    | 可选必选说明：该参数在"IPTYPECHECK"配置为"Ipv6"时为条件可选参数。  参数含义：该参数用于指定需要配置的IPv6地址。  数据来源：本端规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无                                |
| SUBNETMASKIPV6 | IPv6地址掩码  | 可选必选说明：该参数在"IPTYPECHECK"配置为"Ipv6"时为条件可选参数。  参数含义：该参数用于指定需要配置的接口IPv6地址的网络掩码。  数据来源：本端规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无                         |

## 使用实例

配置接口绑定VPN：

```
ADD IPBINDVPNIPSEC:IFNAME="Loopback1",VRFNAME="vrf1",IPTYPECHECK=Ipv4;
```
