# 显示地址缓存（DSP ADDRIP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：GGSN、PGW-C、SMF**

该命令用于显示路由地址或静态地址缓存。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                          |
|:-----------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------|
| DSPTYPE    | 查询类型   | 可选必选说明：必选参数  参数含义：该参数用于指定查询路由地址或静态地址缓存的方式。  数据来源：本端规划 取值范围： QRYALL（查询所有地址）QRYALLBYAPN（查询该APN下的所有地址）QRYCONFLICT（查询与该条地址冲突的所有地址）  默认值：无  配置原则：无 |
| ADDRIPTYPE | 本地地址类型 | 可选必选说明：必选参数  参数含义：该参数用于指定本地地址类型。  数据来源：本端规划 取值范围： ROUTEIP（路由IP地址）STATICIP（静态IP地址）  默认值：无  配置原则：无                                              |
| APN        | APN名称  | 可选必选说明：该参数在"DSPTYPE"配置为"QRYCONFLICT"、"QRYALLBYAPN"时为条件必选参数。  参数含义：该参数用于指定APN实例名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。  默认值：无  配置原则：无           |
| IPVERSION  | IP地址类型 | 可选必选说明：该参数在"DSPTYPE"配置为"QRYCONFLICT"时为条件必选参数。  参数含义：该参数用于指定IP地址类型。  数据来源：本端规划 取值范围： “IPv4（IPv4）”：IPv4“IPv6（IPv6）”：IPv6  默认值：无  配置原则：无         |
| IPV4       | IPV4地址 | 可选必选说明：该参数在"IPVERSION"配置为"IPv4"时为条件必选参数。  参数含义：该参数用于指定IPv4地址。  数据来源：本端规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无                                       |
| IPV6       | IPV6地址 | 可选必选说明：该参数在"IPVERSION"配置为"IPv6"时为条件必选参数。  参数含义：该参数用于指定IPv6地址。  数据来源：本端规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无                                       |
| IPV4MASK   | IPV4掩码 | 可选必选说明：该参数在"IPVERSION"配置为"IPv4"时为条件可选参数。  参数含义：该参数用于指定IPv4地址的网络掩码。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无                    |
| IPV6PREFIX | IPV6前缀 | 可选必选说明：该参数在"IPVERSION"配置为"IPv6"时为条件可选参数。  参数含义：该参数用于指定IPv6地址的前缀。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无                      |

## 使用实例

显示所有静态地址缓存。

```
%%DSP ADDRIP: DSPTYPE=QRYALL, ADDRIPTYPE=ROUTEIP;%%
RETCODE = 0  操作成功

结果如下
------------------------
IP Address Version  IPV4 Address  IPv6 Address  IPv4 Mask  IPv6 Prefix  

IPv4                192.168.0.1       ::            25         0
(Number of results = 1)
```
