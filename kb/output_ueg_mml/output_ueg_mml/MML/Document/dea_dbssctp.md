# 去激活SCTP链路(DEA DBSSCTP)

## 命令功能

**须知** 

- 该命令属于高危命令，该操作可能会导致业务中断。因此执行该命令前，需要与华为技术支持确认后才可以实施。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于去激活一条指定SCTP链路或一键式去激活当局和指定远端局点的所有链路，其对应的恢复命令为**ACT DBSSCTP**。

该命令的使用场景：在异常场景下，用于故障定位及修复使用。

## 注意事项

- 去激活链路可能会导致业务呼损，须谨慎操作。
- 该命令不允许执行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。

## 参数说明

| 参数ID      | 参数名称         | 参数描述                                                                 |
|:----------|:-------------|:---------------------------------------------------------------------|
| SERVICENO | 服务模块号        | 可选必选说明：可选参数 参数含义：用于指定需要去激活链路的DBS服务模块号。 取值范围：1～1024 默认值：无。 配置原则：无。    |
| RLOCID    | 远端Location标识 | 可选必选说明：必选参数 参数含义：用于指定需要去激活链路的远端Location标识。 取值范围：1～512 默认值：无。 配置原则：无。 |
| RDSGMID   | 远端DSG模块号     | 可选必选说明：可选参数 参数含义：用于指定需要去激活链路的远端DSG模块号。 取值范围：1～2047 默认值：无。 配置原则：无。    |

## 使用实例

1. 去激活一条链路，“服务模块号”为“2”,“远端Location标识”为“6”，“远端DSG模块号”为“3”。

   ```
   DEA DBSSCTP: SERVICENO=2, RLOCID=6, RDSGMID=3;
   ```
2. 去激活本局和“远端Location标识”为“6”的局点的所有链路：

   ```
   DEA DBSSCTP: RLOCID=6;
   ```
3. 去激活“服务模块号”为“2”和“远端Location标识”为“6”的局点所有链路。

   ```
   DEA DBSSCTP: SERVICENO=2, RLOCID=6;
   ```
4. 去激活本局所有DBS的链路和“远端Location标识”为“6”、“远端DSG模块号”为“3”的链路。

   ```
   DEA DBSSCTP: RLOCID=6, RDSGMID=3;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释           | 原因分析                     | 处理建议                                                                                                                   |
|-------:|:----------------|:-------------------------|:-----------------------------------------------------------------------------------------------------------------------|
| 100014 | 必选参数 RLOCID 未指定 | “远端Location标识”参数为必选参数。   | 请设置正确的“远端Location标识”参数值后重新执行本命令。                                                                                       |
| 302019 | 服务模块号不存在        | “服务模块号”对应的DBS不存在。        | 通过FE网元命令LST DBSSERVICENO查询DBS的模块号，输入查询到的DBS模块号后，重新执行该命令。                                                               |
| 331062 | SCTP链路不存在       | 指定DBS服务模块号的SCTP链路不在链路集中。 | 先在“FE MML命令”界面执行DSP DBSSCTP命令查询SCTP链路状态信息，确认查询到的SCTP链路信息与本命令指定的SCTP链路信息是否一致： 如果不一致，请修改为正确的链路信息后重新执行本命令。如果一致，请联系华为技术支持。 |
