# 查询锁定的UPF地址（LST UPFADDRLCK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、GGSN、PGW-C、SMF**

该命令用于查询锁定的UPF地址。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                                  |
|:-------------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------|
| UPINSTANCEID | UPF实例标识 | 可选必选说明：可选参数  参数含义：该参数用于指定UPF实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~36。不区分大小写。  默认值：无  配置原则：  本参数取值与ADD PNFPROFILE命令中的“NF实例标识”参数取值保持一致。 |

## 使用实例

查询所有锁定的UPF地址。

```
%%LST UPFADDRLCK:;%%
RETCODE = 0  操作成功。

结果如下
------------------------
   UPF实例标识  =  up1
   UPF的IP版本  =  IPV4
   UPF的IP地址  =  10.0.0.2  
是否开启定时器  =  使能
加锁时长(小时)  =  2
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称    | 输出项解释                    |
|:---------|:-------------------------|
| UPF实例标识  | 该参数用于指定UPF实例名称。          |
| UPF的IP版本 | 该参数用于指定UPF的IP地址类型。       |
| UPF的IP地址 | 该参数用于指定UPF的IP地址。         |
| 是否开启定时器  | 该参数用于指定是否开启定时器用于解锁UPF地址。 |
| 加锁时长(小时) | 该参数用于指定加锁定时器时长，单位为小时。    |
