# 查询基于NG-RAN的定位去使能开关（LST LCSPOSDEANRSW）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询基于NG-RAN的LMF消息控制配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识           | 参数名称    | 参数说明                                                                                          |
|:---------------|:--------|:----------------------------------------------------------------------------------------------|
| NGRANIDSEGNAME | 基站标识段名称 | 可选必选说明：可选参数 参数含义：该参数用于指定基站标识段名称。 数据来源：全网规划 取值范围：字符串类型，不区分大小写，不能包含空格，输入长度范围为1～31。 默认值：无 配置原则：无 |

#### 使用实例

查询基于NG-RAN的LMF消息控制配置：

```
LST LCSPOSDEANRSW:;
```

```
RETCODE = 0 操作成功

基于NG-RAN的LMF消息控制参数
---------------------------
                      基站标识段名称  =  1
                        基站起始标识  =  1
                        基站结束标识  =  2
发送Positioning Deactivation消息开关  =  去使能
(结果个数 = 1)

---    END
```
