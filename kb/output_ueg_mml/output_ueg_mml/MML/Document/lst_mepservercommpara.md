# 查询MEP HTTP服务端通信参数（LST MEPSERVERCOMMPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF、MPF**

该命令用于查询MEP HTTP服务端通信参数。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称          | 参数说明                                                                                                                   |
|:---------|:--------------|:-----------------------------------------------------------------------------------------------------------------------|
| PARANAME | HTTP服务端通信参数名称 | 可选必选说明：可选参数 参数含义：该参数用于指定HTTP服务端通信参数名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“.”组成，且只能以字母或者数字开头。 默认值：无 配置原则：无 |

#### 使用实例

- 查询全部的MEPSRVCOMMPARA对象：

  ```
  LST MEPSERVERCOMMPARA:;
  ```

  ```
  RETCODE = 0  操作成功

  MEP HTTP服务端通信参数
  ----------------------
  HTTP服务端通信参数名称  读取客户端请求头超时时间  读取客户端请求体超时时间  向客户端发送响应超时时间  连接保活超时时间  保活连接可处理的最大请求数  

  DefaultServerPara       60                        60                        60                        75                1000                                          
  srv-comm-para           70                        70                        70                        60                500                         
  (结果个数 = 2)

  ---    END
  ```
- 查询MEPSRVCOMMPARA对象，查询的MEPSRVCOMMPARA对象名称为"srv-comm-para"：

  ```
  LST MEPSERVERCOMMPARA: PARANAME="srv-comm-para";
  ```

  ```
  RETCODE = 0  操作成功

  MEP HTTP服务端通信参数
  ----------------------
      HTTP服务端通信参数名称  =  srv-comm-para
    读取客户端请求头超时时间  =  70
    读取客户端请求体超时时间  =  70
    向客户端发送响应超时时间  =  70
            连接保活超时时间  =  60
  保活连接可处理的最大请求数  =  500
  (结果个数 = 1)

  ---    END
  ```
