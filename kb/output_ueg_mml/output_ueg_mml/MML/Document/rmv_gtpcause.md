# 删除GTP原因值(RMV GTPCAUSE)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

此命令用于删除GTP原因值。

#### 注意事项

- 此命令执行后立即生效。
- 操作过程或操作后不会引起业务、OM的中断或指标下降。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                          |
|:-----------|:-------|:--------------------------------------------------------------------------------------------------------------|
| GTPVERSION | GTP版本  | 可选必选说明：必选参数 参数含义：待删除的GTP版本。 取值范围：“GTPV0V1（GTPv0v1）”：表示该指定GTP版本为GTPv0v1。“GTPV2（GTPv2）”：表示该指定GTP版本为GTPv2。 默认值：无 |
| REJCAUSE   | 拒绝原因值  | 可选必选说明：必选参数 参数含义：待删除的拒绝原因值。 取值范围：1~255 默认值：无                                                                  |

#### 使用实例

删除一条GTP原因值记录，GTP版本为“GTPv0v1”，拒绝原因值为194：

RMV GTPCAUSE: GTPVERSION=GTPV0V1, REJCAUSE=194;
