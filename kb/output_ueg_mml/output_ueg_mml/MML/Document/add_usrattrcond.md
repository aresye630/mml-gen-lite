# 配置用户属性过滤条件（ADD USRATTRCOND）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于增加用户属性过滤条件。

#### 注意事项

- 该命令执行后只对新激活用户生效。
- 该命令最大记录数为4800。
- 该命令中CONDNAME相同ITEMID不同的过滤项目之间为或关系。即只要有一个过滤项目匹配成功，则认为该过滤条件匹配成功。一个过滤项目中CONTENTTYPE不同的过滤内容之间为与关系。即该过滤项目中所有过滤内容需要都匹配成功，才认为该过滤项目匹配成功。
- CONDNAME、ITEMID、CONTENTTYPE唯一确定一条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                     |
|:----------------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CONDNAME        | 过滤条件名称   | 可选必选说明：必选参数 参数含义：该参数用于设置过滤条件名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：该命令最多可配置16个CONDNAME。                                                                                                                                                                                                                                                                                                           |
| ITEMID          | 过滤条件项目索引 | 可选必选说明：必选参数 参数含义：该参数用于设置用户过滤条件项目索引。 数据来源：本端规划 取值范围：整数类型 ，取值范围是1~4294967295。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                 |
| CONTENTTYPE     | 内容类型     | 可选必选说明：必选参数 参数含义：该参数用于设置过滤条件内容类型。 数据来源：本端规划 取值范围：枚举类型。 USER_PROFILE：用户模板。APN：APN。RAT：RAT类型。MSISDN：MSISDN。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                   |
| APNNAME         | APN名称    | 可选必选说明：条件必选参数 前提条件：该参数在“CONTENTTYPE”配置为“APN”时为必选参数。 参数含义：该参数用于设置APN名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。 默认值：无 配置原则： 该参数使用ADD UPAPN命令配置生成。每个CONDNAME下最多可配置100个APN作为过滤条件。                                                                                                                            |
| USERPROFILENAME | 用户模板名称   | 可选必选说明：条件必选参数 前提条件：该参数在“CONTENTTYPE”配置为“USER_PROFILE”时为必选参数。 参数含义：该参数用于设置用户模板名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数使用ADD USERPROFILE命令配置生成。每个CONDNAME下最多可配置100个USERPROFILE作为过滤条件。                                                                                                                                                                                                            |
| RATTYPE         | RAT类型    | 可选必选说明：条件必选参数 前提条件：该参数在“CONTENTTYPE”配置为“RAT”时为必选参数。 参数含义：该参数用于设置RAT类型。 数据来源：本端规划 取值范围：枚举类型。 RESERVED：预留RAT类型。UTRAN：无线接入类型为UMTS陆地无线接入网。GERAN：无线接入类型为GSM/EDGE无线接入网。WLAN：无线接入类型为无线局域网。GAN：无线接入类型为通用接入网络 。HSPAE：无线接入类型为增强型高速分组接入。EUTRAN：无线接入类型为演进UMTS陆地无线接入网。VIRTUAL：无线接入类型为Virtual。EUTRANNBIOT：无线接入类型为EUTRAN-NB-IoT。LTEM：无线接入类型为LTE-M。NR：无线接入类型为NR。REDCAPNR：无线接入类型为RedCap-NR。 默认值：无 配置原则：每个CONDNAME下最多可配置100个RATTYPE作为过滤条件。 |
| MSISDN          | MSISDN   | 可选必选说明：条件必选参数 前提条件：该参数在“CONTENTTYPE”配置为“MSISDN”时为必选参数。 参数含义：该参数用于设置MSISDN。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～15。每个字符必须为0~9的数字。 MSISDN号的组成： 1、用户注册的国家的Country Code (CC) 2、国家移动号，组成如下：National Destination Code (NDC)；Subscriber Number (SN)。 默认值：无 配置原则：每个CONDNAME下最多可配置100个MSISDN作为过滤条件。                                                                                                                                     |

#### 使用实例

运营商需要增加一个用户属性过滤条件，要求过滤用户模板是up1的用户：

```
ADD USRATTRCOND: CONDNAME="user_cond1", ITEMID=1, CONTENTTYPE=USER_PROFILE, USERPROFILENAME="up1";
```
