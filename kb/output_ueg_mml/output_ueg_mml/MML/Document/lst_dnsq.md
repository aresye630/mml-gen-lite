#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询DNS查询控制的相关参数，包括DNS查询方式，DNS服务器组ID。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                      |
|:---------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：可选参数 参数含义：该参数用于表示签约用户的范围。 数据来源：整网规划 取值范围：“All（所有用户）”“SPECIFY（指定用户）” 默认值：无                                                                                                                                                                                                          |
| IMSIPRE  | IMSI前缀 | 可选必选说明：可选参数 参数含义：该参数用于系统根据该参数对用户的IMSI进行匹配，从而区分不同的用户群。 前提条件：当“用户范围”为“SPECIFY（指定用户）”时，此参数为必选参数。 数据来源：整网规划 取值范围：5~15数字 默认值：无  说明： 没有配置IMSI前缀的记录，在IMSI前缀项上显示的结果为“EEEEEEEEEEEEEEE”。                                                                                                            |
| DNSUF    | 域名后缀   | 可选必选说明：可选参数 参数含义：该参数用于表示域名后缀。 取值范围：0~255个字符 默认值：无  说明： 按照域名后缀选择合适的DNS服务器。域名后缀在比较时从后向前进行最大匹配。域名后缀支持配置为*。任何域名和*比较，都认为匹配。域名后缀不能以“.”开始，也不能以“.”结束。相同域名后缀下的IMSI前缀不能相同，相同IMSI前缀下的域名后缀不能相同。该参数只能由字母（A-Z或者a-z）、数字（0-9）、连字符（-）、通配符（*）和点（.）组成。按照协议RFC1035规定，Hostname最大有效字符数为253，并且每个Label最大长度为63个字节。 |

#### 使用实例

查询DNS查询控制的参数，命令格式如下：

LST DNSQ: SUBRANGE=All, DNSUF="gprs";

```
%%LST DNSQ: SUBRANGE=All, DNSUF="gprs";%% 
RETCODE = 0  操作成功。  

操作结果如下 
--------------

     IMSI前缀  =  EEEEEEEEEEEEEEE           
     域名后缀  =  gprs              
   DNS解析方式 =  本地数据优先
   DNS查询方式 =  NAPTR      
DNS服务器组ID  =  1 
         描述  =  NULL
(结果个数 = 1)  

---    END
```
