# 删除S1模式用户漫游限制列表(RMV S1SUBRRLST)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

此命令用于删除S1模式区域漫游限制列表。

#### 注意事项

此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                    |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：必选参数 参数含义：该参数用于指定用户范围。 数据来源：整网规划 取值范围：“IMSI_PREFIX（指定IMSI前缀）”“IMSI_RANGE（指定IMSI范围）”“FOREIGN_USER（外网用户）”“HOME_USER（本网用户）”“ALL_USER（所有用户）” 默认值：无                                                   |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件必选参数 参数含义：该参数用于系统对用户的IMSI进行匹配，从而区分不同的用户群。 前提条件：该参数在“用户范围”参数配置为“IMSI_PREFIX（指定IMSI前缀）”后生效。 数据来源：整网规划 取值范围：5～15位十进制字符串 默认值：无  说明： IMSI前缀的匹配方式采取由前向后的最长匹配，即若对于用户可以匹配到多个用户群，则使用IMSI前缀最长的用户群配置。     |
| IMSI     | IMSI   | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI，对该IMSI所在号段进行删除。 前提条件：只有“用户范围”为“IMSI_RANGE（指定IMSI范围）”时，该参数才有效。 数据来源：整网规划 取值范围：5～15位十进制字符串 默认值：无                                                                           |
| NOID     | 运营商标识  | 可选必选说明：条件必选参数 参数含义：该参数用于指定运营商标识。 前提条件：该参数在“SUBRANGE（用户范围）”配置为“FOREIGN_USER（外网用户）”或“HOME_USER（本网用户）”后生效。 对于外网用户，该参数是外网用户对应的签订互联PLMN漫游协议的运营商标识，对于本网用户，该参数是本网用户对应的运营商标识。 数据来源：整网规划 取值范围：0～64，128～254 默认值：无 |

#### 使用实例

S1模式删除IMSI前缀为123456的区域漫游限制配置记录：

RMV S1SUBRRLST: SUBRANGE=IMSI\_PREFIX, IMSIPRE="123456";
