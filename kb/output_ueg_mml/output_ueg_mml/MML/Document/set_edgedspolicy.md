# 设置园区用户数据同步策略（SET EDGEDSPOLICY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UDM**

**须知** 

本命令属于高危命令，该命令会修改数据同步策略,两台互为主备的UEG，同步时间应当不同，并且SWITCH会控制园区UDM数据同步功能

该命令用于设置园区UDM用户数据同步策略。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 数据同步时，如果与主备SFTP服务器连接失败且连接尝试次数均超过“ALMThesTimes”阈值，连接尝试停止。
- 如果SWITCH设置为DISABLE，则不会自动同步数据，当两台UEG做主备或负荷分担时，两台设备的同步时间要错开，建议相差12小时。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | CYCLE   | STARTTIME   | ENDTIME   |   RETRYINTVL |   ALMTHESTIMES | PREFIXSEPARATOR   | PREFIXFORMAT   |   FILEEXPIRE | SWITCH   |
|:-------|:--------|:------------|:----------|-------------:|---------------:|:------------------|:---------------|-------------:|:---------|
| 初始值    | 1D      | 00:00       | 02:00     |            1 |              5 | _                 | Common         |            3 | DISABLE  |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                 |
|:----------------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CYCLE           | 获取周期       | 可选必选说明：可选参数 参数含义：用于指定UDM从远端SFTP服务器同步用户数据的周期。 数据来源：全网规划 取值范围：长度不超过15的字符串，格式为n1D。n1表示天数，取值范围是1～365，后面的D表示天。 默认值：无 配置原则：无                                                                                                                                                               |
| STARTTIME       | 开始时间       | 可选必选说明：可选参数 参数含义：用于指定园区UDM基于周期同步用户数据的开始时间。 数据来源：全网规划 取值范围：长度不超过5的字符串，格式为“HH:MM”, HH表示小时，MM为分钟。 默认值：无 配置原则：配置的数据同步起始时间要避开业务高峰期。                                                                                                                                                       |
| ENDTIME         | 结束时间       | 可选必选说明：可选参数 参数含义：用于指定园区UDM基于周期同步用户数据的结束时间。若到了配置的结束时间文件仍没有传输完，会继续传输，直到同步完成。 数据来源：全网规划 取值范围：长度不超过5的字符串，格式为“HH:MM”, HH表示小时，MM为分钟。 默认值：无 配置原则： 建议结束时间比开始时间相隔1小时，预留充足的数据同步时长。输入的“结束时间”晚于“开始时间”。允许配置的起始时间和结束时间跨天，例如23:00(start)~01:00(end)。                                                |
| RETRYINTVL      | 重试间隔       | 可选必选说明：可选参数 参数含义：用于指定尝试重新建立SFTP连接的时间间隔。在当前周期结束时间到达之前，如SFTP连接未建立成功，SFTP Client会持续按照RETRYINTVL时间间隔尝试重新建立SFTP连接。 数据来源：全网规划 取值范围：0, 1~60，单位是分钟。 默认值：无 配置原则：0表示不重试。                                                                                                                       |
| ALMTHESTIMES    | 连续连接失败告警阈值 | 可选必选说明：可选参数 参数含义：用于同一周期的开始时间和结束时间之间，触发SFTP告警告警的SFTP连接连续失败次数。 数据来源：全网规划 取值范围：1~5，单位为次数。 默认值：无 配置原则： 如果RETRYINTVL配置为0，则一旦发生SFTP连接失败/中断就会触发告警。如设置5次，则连续尝试连接SFTP服务器五次不成功，上报SFTP失败告警。如本周期结束时间到达后，告警未恢复，告警会持续到下一周期，直到SFTP连接成功时告警才会恢复。                                                      |
| FILTERPREFIX    | 文件名前缀匹配条件  | 可选必选说明：可选参数 参数含义：用于指定SFTP传输文件的前缀过滤条件。 数据来源：全网规划 取值范围：长度不超过63的字符串，不允许包含特殊字符：“，”、“’”、“-”、“.”和“；”。 默认值：无 配置原则： 前缀处理区分大小写。当前版本只支持配置一个过滤条件。例如：配置为“Campus1”，则要求下载的文件名前缀的第一个部分能够匹配”Campus1*”。需要与远端服务器协商一致。如不一致，文件同步会失败。                                                                     |
| FILTERSUFFIX    | 文件名后缀匹配条件  | 可选必选说明：可选参数 参数含义：用于指定SFTP传输文件的后缀过滤条件。 数据来源：全网规划 取值范围：长度不超过63的字符串，不支持特殊字符：“，”、“’”和“；”。 默认值：无 配置原则： 当前版本只能配置一个过滤条件，只支持设置”tar.gz”。可不配置，不配置默认按照”tar.gz”过滤。需要与远端服务器协商一致。如不一致，文件同步会失败。                                                                                                     |
| PREFIXSEPARATOR | 文件名前缀分割符   | 可选必选说明：可选参数 参数含义：用于设置用户数据文件名前缀的分隔符。 数据来源：全网规划 取值范围：字符类型，允许输入的字符为 “_”。 默认值：无 配置原则： 本参数值不能被清空。必须与远端服务器定义一致，否则数据同步文件解析会失败。当前版本只能配置下划线“_”。                                                                                                                                               |
| PREFIXFORMAT    | 文件名前缀的格式   | 可选必选说明：可选参数 参数含义：用于设置用户数据文件名前缀的格式。 数据来源：全网规划 取值范围：枚举类型。 Common：文件名格式为”园区描述”+分隔符+“自定义描述”+分隔符+“日期时间（格式YYYYMMDDHHMMSS）”+分隔符+“文件序号”。分隔符通过PREFIXSEPARATOR设置。Custom1：文件名格式为“省份标识”+分隔符+”园区描述”+分隔符+“备注”+分隔符+“导出时间戳（格式YYYYMMDDHHMMSS）”+分隔符+ “序号”。 默认值：无 配置原则：文件名格式必须与远端服务器定义一致，否则用户数据文件同步会失败。 |
| FILEEXPIRE      | 文件老化时长     | 可选必选说明：可选参数 参数含义：设置备份文件老化时长。文件备份时长超过配置的老化时长，备份文件被老化掉。 数据来源：全网规划 取值范围：2~7，单位是天。 默认值：无 配置原则：因文件备份空间有限，老化时间需要谨慎配置，建议配置为3天。                                                                                                                                                              |
| SWITCH          | 开关         | 可选必选说明：必选参数 参数含义：开关控制是否使能园区UDM数据同步任务。 数据来源：本端规划 取值范围： DISABLE：DISABLE。ENABLE：ENABLE。 默认值：无 配置原则：使能园区UDM数据自动同步时设置成ENABLE，不使能园区UDM数据自动同步任务时设置成DISABLE。                                                                                                                                 |

#### 使用实例

设置园区UDM用户数据同步策略：

```
SET EDGEDSPOLICY: SWITCH=ENABLE, CYCLE="1D", STARTTIME="10:00", ENDTIME="11:00", RETRYINTVL=5, ALMTHESTIMES=1, FILTERPREFIX="19", FILTERSUFFIX="tar.gz", PREFIXSEPARATOR="_", PREFIXFORMAT=Common, FILEEXPIRE=2;
```
