# 停止会话备份数据审计任务（STP SESSADT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为维护类命令，用于立即停止会话备份数据审计任务。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                              |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------|
| TYPE   | 审计类型   | 指定审计任务的类型。 取值范围： UPCF (UPCF与USCDB间的会话数据审计)USCDB(USCDB的会话备份冗余数据清理审计) 说明： 当需要停止USCDB的会话备份冗余数据清理审计任务时，执行STP OTSSESSADT命令停止任务。 默认值：无。 |

## 使用实例

停止“审计类型”为“UPCF”会话备份数据审计任务操作。执行命令如下：

```
STP SESSADT: TYPE=UPCF;
```
