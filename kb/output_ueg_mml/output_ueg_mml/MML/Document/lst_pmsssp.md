# 查询策略管理服务系统软参(LST PMSSSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询PMS系统软件参数的配置信息。

- 若需要查询全部软参数据记录的概要信息，请不要输入任何参数。
- 若需要查询某条参数数据记录的详细信息，请输入“系统配置参数”和“参数名”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
|:-------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SCP    | 系统配置参数  | 可选必选说明：可选参数 参数含义：系统配置参数标识。 取值范围： SYSPARAMETER(系统参数) 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| SPN    | 参数名     | 可选必选说明：可选参数 参数含义：标识软件参数名称，用于指定需要对哪一类软参数据记录的参数进行查询。 取值范围： VRM_PPMWORKMODE(PPM接口工作模式)VRM_PMWORKMODE(Pm接口工作模式)VRM_4AWORKMODE(4A接口工作模式)VRM_CLIMODIFYCTRL(CLI接口业务反约束修改开关)VRM_MAXQUOTANUMPERSERVICE (SERVICE最多可关联的配额数)VRM_PMSCRLPOLICY(PMS数字证书CRL处理策略)VRM_CHKSOAPUSERSWITCH(检查SOAP服务端用户账号开关)VRM_CLIWORKMODE(CLI接口工作模式)VRM_SETPMSDOMAIN(设置PMS WEBServer 的domain参数)VRM_PMSOPTLOGSW(PMS操作日志是否周期性记录到本地文件)VRM_VOLTEGLOBALDATA(PCF支持语音全局数据)VRM_PMSSFTPCLIENTACSWITCH(PMS SFTP客户端算法兼容开关)VRM_MAXSRVZONENUMPERAREA(小区可归属最大服务区个数)VRM_PMSCHKINVALIDCH(PMS不可见字符检查开关)VRM_SSHWORKMODE(PMS SSH服务启用开关)VRM_PMSSSHSRVACSWITCH(PMS SSH服务端安全算法开关) 默认值：无。 配置原则：无。  说明： 以下软参在当前版本已经废弃： VRM_PPMWORKMODE(PPM接口工作模式) |
| SPV    | 参数值     | 可选必选说明：可选参数 参数含义：标识软件参数的值，具体软参的取值范围请参考产品手册的“PMS系统软参”。 取值范围：0～2147483647 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| DFTV   | 软件参数默认值 | 可选必选说明：可选参数 参数含义：标识软件参数的默认取值。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |

## 使用实例

1. 查询策略管理服务系统全部软参配置信息。

   ```
   LST PMSSSP:;
   ```

   ```
   %%LST PMSSSP:;%%
   RETCODE = 0    操作成功

   操作结果如下:

   系统配置参数  参数名                                参数值  软件参数默认值  

   系统参数      PPM接口工作模式                       0       0
   系统参数      PMS操作日志是否周期性记录到本地文件   0       0    
   系统参数      Pm接口工作模式                        0       0               
   系统参数      4A接口工作模式                        0       0               
   系统参数      CLI接口业务反约束修改开关             0       0               
   系统参数      SERVICE最多可关联的配额数             3       3      
   系统参数      PMS数字证书CRL处理策略                1       1
   系统参数      检查SOAP服务端用户账号开关            0       0
   系统参数      CLI接口工作模式                       0       1
   系统参数      设置PMS WEBServer 的domain参数        32      32   
   系统参数      PCF支持语音全局数据                   0       0   
   系统参数      PMS SFTP客户端算法兼容开关            0       0

   (结果个数 = 16)

   ```
2. 查询PCF支持语音全局数据。“系统配置参数”为“SYSPARAMETER(系统参数)”，“参数名”为“VRM\_VOLTEGLOBALDATA(PCF支持语音全局数据)”。

   ```
   LST PMSSSP: SCP=SYSPARAMETER, SPN=VRM_VOLTEGLOBALDATA;
   ```

   ```
   %%LST PMSSSP: SCP=SYSPARAMETER, SPN=VRM_VOLTEGLOBALDATA;%%
   RETCODE = 0    操作成功

   操作结果如下:
   ------------
     系统配置参数 = 系统参数
           参数名 = PCF支持语音全局数据
           参数值 = 0
   软件参数默认值 = 0
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**MOD PMSSSP**命令的参数说明。
