# 删除DNAI服务区域（RMV DNAREA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、SMF、GGSN、PGW-C**

该命令用于删除DNAI服务区域。

## 注意事项

- 该命令执行后立即生效。

- 该命令用于删除DNAI服务区域，必须先使用命令RMV DNAREABINDN2TAI、RMV DNAREABINDN2CID、RMV DNAREABINDDNAI删除对应与该服务区名称相同的记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称       | 参数说明                                                                                                                                                    |
|:---------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------|
| AREANAME | DNAI服务区域名称 | 可选必选说明：必选参数  参数含义：该参数用于配置DNAI服务区域名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~255。不能为非法字符，只允许输入字母，数字、“_”、“.”，并且开头和结尾只能是数字或者字母，不能出现连续两个“.”。不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

删除区域名称为"DNAREA1"的DNAI服务区域：

```
RMV DNAREA: AREANAME="DNAREA1";
```
