# 删除共享PLMN群组成员(RMV SHAREPLMNMEM)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

在**MOCN**组网下的两网融合项目中，基于区域逐步融合，需要配置基于特定区域PLMN的使用策略。该命令用于删除共享PLMN群组成员。

#### 注意事项

- 此命令执行后60秒内生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                         |
|:---------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------|
| PLMNGPID | PLMN群组标识 | 可选必选说明：必选参数 参数含义：该参数用于指定PLMN群组标识。 数据来源：本端规划 取值范围：1～31 默认值：无                                                                                  |
| MCC      | 移动国家码    | 可选必选说明：必选参数 参数含义：该参数用于指定由ITU-T统一分配的移动网络所在国家的标识符。 数据来源：整网规划 取值范围：3位十进制数 默认值：无  说明： ADD SHAREPLMNMEM中的MCC + MNC来源于ADD MMESHAREPLMN中的MCC + MNC。 |
| MNC      | 移动网号     | 可选必选说明：必选参数 参数含义：该参数用于指定一个国家内的PLMN标识符。 数据来源：整网规划 取值范围：位数为2或3的十进制数 默认值：无  说明： ADD SHAREPLMNMEM中的MCC + MNC来源于ADD MMESHAREPLMN中的MCC + MNC。      |

#### 使用实例

删除一条：“PLMN群组标识”为“1”，“移动国家码”为“460”，“移动网号”为“05”的记录。

`RMV SHAREPLMNMEM: PLMNGPID=1, MCC="460", MNC="05";`
