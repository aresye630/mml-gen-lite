# 修改ADC参数（MOD ADCPARA）

- 命令功能
- 注意事项
- 操作用户权限

- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于修改应用的流信息上报开关。流信息的上报功能是指对于需要进行检测上报的应用，在上报应用开始/结束上报时，同时上报当前业务的流信息，便于PCRF/PCF能够获取到应用与流的对应关系，从而可以下发更精确地策略对业务进行控制。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称            | 参数说明                                                                                                                                                                                   |
|:----------------|:----------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FLOWFILTERNAME  | 流过滤器/流过滤器组名称    | 可选必选说明：必选参数 参数含义：该参数用于设置应用对应的流过滤器或流过滤器组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD FLOWFILTER或ADD FLOWFILTERGRP命令配置生成。                                      |
| FLOWINFORPT     | 流信息上报标识         | 可选必选说明：可选参数 参数含义：该参数用于设置流信息上报标识。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不上报流信息。ENABLE：上报流信息。 默认值：无 配置原则： DISABLE：在向PCRF上报应用开始/结束时，不上报流信息。ENABLE：在向PCRF上报应用开始/结束时，上报流信息。                          |
| KEYFLOWDETECTSW | 关键流检测开关         | 可选必选说明：可选参数 参数含义：该参数用于配置识别关键业务流的开关是否开启。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能（关闭）。ENABLE：使能（开启）。 默认值：无 配置原则：无                                                                               |
| KEYFLOWTIME     | 关键流时长（秒）        | 可选必选说明：条件可选参数 前提条件：该参数在“KEYFLOWDETECTSW”配置为“ENABLE”时为可选参数。 参数含义：该参数用于指定识别关键业务流的最低持续时长。 数据来源：本端规划 取值范围：整数类型，取值范围为5～60。 默认值：无 配置原则：无                                                     |
| KEYFLOWSPEED    | 关键流速率（二进制千比特每秒） | 可选必选说明：条件可选参数 前提条件：该参数在“KEYFLOWDETECTSW”配置为“ENABLE”时为可选参数。 参数含义：1、该参数用于指定关键业务流的最低传输速率。 2、参数单位是二进制千比特每秒，即Kibps，1Kibps等于1024bps。 数据来源：本端规划 取值范围：整数类型，取值范围为1～2048。 默认值：无 配置原则：无           |
| ADCHYSTIMER     | 应用级上报迟滞时间（秒）    | 可选必选说明：可选参数 参数含义：该参数用于配置ADC功能应用级上报迟滞时间。 数据来源：本端规划 取值范围：整数类型，取值范围为0～3600。 默认值：无 配置原则：当单用户一个应用的Start和Stop消息上报过于频繁时，建议调大此参数。 当希望一个应用的Start和Stop消息上报尽量精确时，建议调小此参数。 该参数配置为0时，认为应用级延迟上报功能关闭。 |
| REDIRECTNAME    | 重定向名称           | 可选必选说明：可选参数 参数含义：该参数用于设置重定向名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1~31。不支持空格，不区分大小写。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。                                                                             |

#### 使用实例

假设运营商需要指定ADC应用不上报流信息，指定应用对应的流过滤器名称为testflowfiltername：

```
MOD ADCPARA:FLOWFILTERNAME="testflowfiltername",FLOWINFORPT=DISABLE, KEYFLOWDETECTSW=ENABLE, KEYFLOWTIME=5, KEYFLOWSPEED=50, ADCHYSTIMER=0;
```
