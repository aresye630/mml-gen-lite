# PMS同步全局数据(SYN PMSGLBDATA)

## 命令功能

**须知** 

此命令是高危命令，多次连续执行可能会导致系统过载，需联系华为技术支持确认后再执行。

该命令为维护类命令，用于刷新PMS微服务的全局数据，不检查时间戳。PMS微服务每20秒进行一次全局数据校验。如果发现数据不一致，可以采用手动执行此命令，强制刷新PMS微服务的全局数据。

## 注意事项

多FE场景下，每个FE执行时需要间隔1分钟以上。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                            |
|:--------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PODNAME | POD名称  | 可选必选说明：可选参数 参数含义：用于指定POD名称中的PMS微服务进行强制全局数据刷新。不指定POD名称时，所有PMS微服务强制刷新。 取值范围：长度不超过256的字符串。 默认值： 无。 配置原则：只能选择PMS对应的POD名称，可通过DSP POD命令根据Pod类型查询Pod名称。  说明： 对于同一个POD名称中的PMS微服务重复执行SYN PMSGLBDATA，直接返回成功，不中断正在执行的刷新任务。 |

## 使用实例

同步PMS微服务的全局数据。

```
SYN PMSGLBDATA:;
```

```
%%SYN PMSGLBDATA: CONFIRM=Y;%%
RETCODE = 0  操作成功

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释               | 原因分析                                | 处理建议                         |
|------:|:--------------------|:------------------------------------|:-----------------------------|
| 58031 | 服务状态异常，请检查服务状态，再重试。 | 需要刷新的服务“可用状态”处于“未就绪”或“故障”状态，无法进行刷新。 | 请联系华为技术支持，确保服务状态无异常再重新执行本命令。 |
