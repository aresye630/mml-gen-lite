# 查询MPLS全局配置（LST MPLSSITE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询MPLS全局配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询MPLS全局配置：

```
LST MPLSSITE:;
```

```
RETCODE = 0  操作成功。

结果如下
--------
MPLS LSR ID  =  192.168.1.1
   MPLS能力  =  DISABLE
    LDP能力  =  DISABLE
 空标签类型  =  隐式空标签
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见SET MPLSSITE的参数说明。
