# 设置SMS小范围CHR存储配置（SET SMSCHRSTORCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMSF**

该命令用于设置SMS小范围CHR存储配置。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| CHRSPESUBSAVE   | CHRSAVEPATH   |
|:----------------|:--------------|
| FUNC_OFF        | SAVE_OMU      |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                             |
|:--------------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CHRSPESUBSAVE | 小范围CHR使能开关 | 可选必选说明：可选参数  参数含义：该参数用于表示小范围CHR使能开关。  数据来源：本端规划 取值范围： “FUNC_ON（打开）”：功能开关打开“FUNC_OFF（关闭）”：功能开关关闭  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST SMSCHRSTORCFG查询当前参数配置值。  配置原则：无                                                                                                                         |
| CHRSAVEPATH   | 小范围CHR存储路径 | 可选必选说明：该参数在"CHRSPESUBSAVE"配置为"FUNC_ON"时为条件可选参数。  参数含义：该参数用于表示小范围CHR存储路径。  数据来源：本端规划 取值范围： “SAVE_OMU（保存到OMU）”：表示保存到OMU。“SAVE_UCF（保存到UCF）”：表示保存到UCF。“SAVE_OMU_AND_UCF（保存到OMU和UCF）”：表示保存到OMU和UCF。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST SMSCHRSTORCFG查询当前参数配置值。  配置原则：  当前只支持“SAVE_OMU(保存到OMU)”。 |

## 使用实例

运营商希望设置“小范围CHR使能开关”为“打开”，“小范围CHR存储路径”为“保存到OMU”的SMS小范围CHR存储配置，执行如下命令：

```
SET SMSCHRSTORCFG:CHRSPESUBSAVE=FUNC_ON, CHRSAVEPATH=SAVE_OMU;
```
