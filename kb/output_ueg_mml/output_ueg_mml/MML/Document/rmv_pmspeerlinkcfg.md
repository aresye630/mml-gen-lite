# 删除策略管理服务对端链路配置信息(RMV PMSPEERLINKCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于删除策略管理服务对端链路的配置信息。

## 注意事项

如果要删除的链路被通知模板关联，不能够直接删除。需要在通知模板中取消关联后，才能通过本命令删除该链路配置信息。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                   |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------|
| LINKID | 链路ID   | 可选必选说明：必选参数 参数含义：标识一条策略管理服务对端链路ID的关键字段，用于指定需要删除哪一条链路ID的数据记录，操作员可以使用LST PMSPEERLINKCFG命令查询获得。 取值范围：1～255 默认值：无。 配置原则：无。 |

## 使用实例

删除策略管理服务对端链路的配置信息。“链路ID”为“1”。

```
RMV PMSPEERLINKCFG: LINKID=1;
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。
