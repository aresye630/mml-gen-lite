# 测试GTPU路径（TST GTPUPATHINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、SGW-C、PGW-C、GGSN**

该命令用于通过发送Echo消息的方法测试本端与对端之间的GTPU路径是否正常。如果路径正常，则返回报文显示路径地址信息；如果路径不正常，则返回报文显示20111错误码，提示无记录。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                       |
|:----------|:---------|:-----------------------------------------------------------------------------------------------------------|
| IPTYPE    | IP类型     | 可选必选说明：必选参数  参数含义：该参数用于指定GTPU的IP类型。  数据来源：全网规划 取值范围： IPV4（IPV4）IPV6（IPV6）  默认值：无  配置原则：无                   |
| LOCALIPV4 | 本端IPv4地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPV4"时为条件必选参数。  参数含义：该参数用于指定GTPU本端IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无 |
| PEERIPV4  | 对端IPv4地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPV4"时为条件必选参数。  参数含义：该参数用于指定GTPU对端IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无 |
| LOCALIPV6 | 本端IPv6地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPV6"时为条件必选参数。  参数含义：该参数用于指定GTPU本端IPv6地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无 |
| PEERIPV6  | 对端IPv6地址 | 可选必选说明：该参数在"IPTYPE"配置为"IPV6"时为条件必选参数。  参数含义：该参数用于指定GTPU对端IPv6地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无 |
| VPN       | VPN      | 可选必选说明：可选参数  参数含义：该参数用于指定本端VPN。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~31。  默认值：无  配置原则：无                         |
| PORT      | 对端端口     | 可选必选说明：可选参数  参数含义：该参数用于指定对端GTPU端口。  数据来源：全网规划  取值范围：整数类型，取值范围是0~65535。  默认值：无  配置原则：无                      |

## 使用实例

测试本端与对端之间的GTPU路径是否正常，IP地址类型为IPTypeV4，本端IP地址为10.0.0.1，对端IP地址为10.0.0.2;

```
TST GTPUPATHINFO: IPTYPE=IPV4, LOCALIPV4="10.0.0.1", PEERIPV4="10.0.0.2";
```
