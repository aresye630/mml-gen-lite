# 增加NF实例概述信息（ADD UPNFPROFILE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于添加NF实例的概述信息。当NF实例向NRF注册时，可以将实例的概述信息带给NRF，为在业务流程中其他NF发现该NF时提供选择信息。配置的本端UPNFPROFILE类型为向NRF服务订阅时携带的本端网元类型。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为2。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                                                                         |
|:---------------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCENAME | NF实例名称     | 可选必选说明：必选参数 参数含义：该参数用于指定NF实例名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围是0~64。 默认值：无 配置原则：本参数的构成字符只能是字母A～Z或a～z、数字0～9、中划线"-"和下划线"_"，例如，AMF_Instance_0。 本参数来源于ADD UPNFUUID命令中的“NF实例名称”参数。                                                                                                                                                                                                   |
| NFTYPE         | NF类型       | 可选必选说明：必选参数 参数含义：本参数用于指定NF类型。 数据来源：全网规划 取值范围： NfInvalid：NfInvalid。NfUDM：NfUDM。NfAMF：NfAMF。NfLMF：NfLMF。NfGMLC：NfGMLC。 默认值：无 配置原则：无                                                                                                                                                                                                                                            |
| NFSTATUS       | NF状态       | 可选必选说明：可选参数 参数含义：该参数用于指定NF状态。 数据来源：全网规划 取值范围： Invalid：表示当前NF实例处于无效态，如果配置成该值，NF选择时不会选择此类NF。Registered：表示当前NF实例处于注册态，如果配置成该值，NF选择时只会选择此类NF。Suspended：表示当前NF实例处于挂起态。当NF实例处于运维状态下，比如正在进行用户迁移等，不希望在NF发现流程中被选中时，可以置为此状态，迁移完毕后通过该命令对应的MOD命令修改为注册态即可。UnDiscoverable：表示当前NF实例处于不可被发现状态，如果配置成该值，NF选择时不会选择此类NF。DeRegistered：表示当前NF实例处于去注册态，如果配置成该值，NF选择时不会选择此类NF。 默认值：Registered 配置原则：无 |
| HTTPLEIDX      | http地址实例标识 | 可选必选说明：可选参数 参数含义：本参数用于指定http地址实例标识。 数据来源：全网规划 取值范围：整数类型，取值范围是0~255。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                             |
| CAPACITY       | 容量         | 可选必选说明：可选参数 参数含义：本参数用于指定NF的相对权重（与其他同类型NF实例相比）。 数据来源：全网规划 取值范围：整数类型，取值范围是0~65535。值越大表示容量越大。 默认值：100 配置原则：无                                                                                                                                                                                                                                                                    |
| PRIORITY       | 优先级        | 可选必选说明：可选参数 参数含义：本参数用于指定NF的优先级（与其他同类型NF实例相比）。 数据来源：全网规划 取值范围：整数类型，取值范围是0~65535。值越小优先级越高。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                        |
| LOAD           | 负载         | 可选必选说明：可选参数 参数含义：本参数用于指定NF的负载。 数据来源：全网规划 取值范围：整数类型，取值范围是0~100。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                  |

#### 使用实例

新增1个AMF的NF实例，将其初始状态置为注册态，该NF实例除了要满足本网内的业务外，还要考虑外网（跨PLMN）NF对该NF实例的访问。该NF支持SMF、AUSF、UDM对其进行访问，且将该NF实例优先级设置为1，容量设置为100，脚本如下：

```
ADD UPNFPROFILE: NFINSTANCENAME="AMF_Instance_0", NFTYPE=NfAMF, NFSTATUS=Registered, PRIORITY=1;
```
