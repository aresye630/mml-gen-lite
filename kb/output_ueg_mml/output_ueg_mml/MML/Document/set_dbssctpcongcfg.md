## 命令功能

该命令用于设置DBS SCTP拥塞控制参数。

该命令的使用场景：在开局或日常的操作维护活动中，当需要开启或关闭SCTP拥塞控制功能，或者不想使用系统初始设置值时，可以使用此命令进行设置。

## 注意事项

执行本命令修改参数后，需要登录“OM Portal MML命令”界面，选择FE网元执行如下命令重启DBS服务才能生效。

```
RST MSPROCESS: PROCOBJECT=PROCNAME, PROCNAME="CELL_UdrDbbroker";
```

## 参数说明

| 参数标识              | 参数名称     | 参数说明                                                                                                                                                                         |
|:------------------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SWTICH            | 开关       | 可选必选说明：必选参数 参数含义：用于设置SCTP拥塞控制的关闭/开启状态。 取值范围： OFF(关) ON(开) 默认值：无。 配置原则：该参数的系统初始设置值为“ON(开)”。                                                                                   |
| CONGESTTIONTYPE   | 拥塞控制算法类型 | 可选必选说明：条件必选参数 参数含义：用于指定SCTP使用的拥塞控制算法类型。 取值范围：BBR（BBR拥塞控制算法） 默认值：BBR（BBR拥塞控制算法）。 配置原则： 仅当本命令中的“开关”取值为“ON(开)”时该参数有效。该参数的系统初始设置值为“BBR（BBR拥塞控制算法）”。                              |
| NORMALMSGDELAY    | 正常消息积压时延 | 可选必选说明：条件可选参数 参数含义：用于指定正常消息积压时延。当SCTP消息在缓存中积压时延小于或等于该参数的取值时解除拥塞控制。 取值范围：20~2000，单位为ms（毫秒）。 默认值：无。 配置原则： 仅当本命令中的“开关”取值为“ON(开)”时该参数有效。该参数取值必须小于“过载消息积压时延”的取值。该参数的系统初始设置值为“50”。 |
| OVERLOADMSGDELAY  | 过载消息积压时延 | 可选必选说明：条件可选参数 参数含义：用于指定过载消息积压时延。当SCTP消息在缓存中积压时延大于该参数的取值时启动拥塞控制。 取值范围：100~2500，单位为ms（毫秒）。 默认值：无。 配置原则： 仅当本命令中的“开关”取值为“ON(开)”时该参数有效。该参数取值必须大于“正常消息积压时延”的取值。该参数的系统初始设置值为“500”。  |
| NORMALCACHEUSED   | 正常缓存占用率  | 可选必选说明：条件可选参数 参数含义：用于指定正常缓存占用率。当SCTP消息的缓存占用率小于或等于该参数的取值时解除拥塞控制。 取值范围：1~90，单位为%。 默认值：无。 配置原则： 仅当本命令中的“开关”取值为“ON(开)”时该参数有效。该参数取值必须小于“过载缓存占用率”的取值。该参数的系统初始设置值为“60”。             |
| OVERLOADCACHEUSED | 过载缓存占用率  | 可选必选说明：条件可选参数 参数含义：用于指定过载缓存占用率。当SCTP消息的缓存占用率大于该参数的取值时启动拥塞控制。 取值范围：20~99，单位：% 默认值：无。 配置原则： 仅当本命令中的“开关”取值为“ON(开)”时该参数有效。该参数取值必须大于“正常缓存占用率”的取值。该参数的系统初始设置值为“80”。                |

## 使用实例

设置SCTP拥塞控制参数：“开关”为“ON(开)”，“拥塞控制算法类型”为“BBR（BBR拥塞控制算法）”。

```
SET DBSSCTPCONGCFG: SWTICH=ON, CONGESTTIONTYPE=BBR;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释   | 原因分析                                                                             | 处理建议                                                                                                                    |
|-------:|:-------|:---------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------|
| 302597 | 参数不合法。 | 可能原因为输入参数不符合如下参数限制： “过载消息积压时延”的取值必须大于“正常消息积压时延”的取值。“过载缓存占用率”的取值必须大于“正常缓存占用率”的取值。 | 执行该命令，重新输入参数，确保满足如下条件： “过载消息积压时延”的取值必须大于“正常消息积压时延”的取值。“过载缓存占用率”的取值必须大于“正常缓存占用率”的取值。 可通过LST DBSSCTPCONGCFG命令，查看已配置的参数取值。 |
