# 显示UCF链路状态（DSP UCFSVRLNKSTAT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询UCF与报表服务器之间的链路状态。

## 注意事项

执行命令前请确认UCF服务处于上线状态。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                                                              |
|:-------------|:---------|:----------------------------------------------------------------------------------------------------------------------------------|
| UCFSVRNAME   | UCF服务器名称 | 可选必选说明：可选参数  参数含义：该参数用于请求系统显示到指定UCF服务器的链路状态；若不输入，则显示本端到所有对端UCF服务器的链路状态信息。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~32。  默认值：无  配置原则：无      |
| PROTOCOLTYPE | 协议类型     | 可选必选说明：可选参数  参数含义：该参数用于请求系统显示指定协议类型的链路状态；若不输入，则显示环境中所有协议类型的信息。  数据来源：本端规划 取值范围： TCP（TCP）SFTP（SFTP）FTP（FTP）UDP（UDP）  默认值：无  配置原则：无 |

## 使用实例

运营商A查询UCF本端与报表服务器的链路状态信息：

```
%%DSP UCFSVRLNKSTAT:;%%
RETCODE = 0  操作成功

结果如下
--------
UCF POD ID     UCF服务器名称  本端IP类型  本端IPv4地址  本端IPv6地址  本端端口  对端IP类型  对端IPv4地址  对端IPv6地址  对端端口  协议类型  链路状态  

ucfexec-pod-1  UCFSVR         IPv4        10.10.0.6     ::            6666      IPv4        10.10.0.66    ::            10500     TCP       正常      
ucfexec-pod-0  UCFSVR         IPv4        10.10.0.6     ::            6667      IPv4        10.10.0.66    ::            10500     TCP       正常      
(结果个数 = 2)

---    END
```

## 输出结果说明

| 输出项名称      | 输出项解释                                                                                 |
|:-----------|:--------------------------------------------------------------------------------------|
| UCF POD ID | 该参数用于返回UCF服务的pod ID。                                                                  |
| UCF服务器名称   | 该参数用于请求系统显示到指定UCF服务器的链路状态；若不输入，则显示本端到所有对端UCF服务器的链路状态信息。                               |
| 本端IP类型     | 该参数用于返回UCF本端的IP地址类型。 取值说明： IPv4（IPv4）IPv6（IPv6）                                       |
| 本端IPv4地址   | 该参数用于返回UCF本端的IPv4地址。                                                                  |
| 本端IPv6地址   | 该参数用于返回UCF本端的IPv6地址。                                                                  |
| 本端端口       | 该参数用于返回UCF本端的端口号。                                                                     |
| 对端IP类型     | 该参数用于返回UCF服务器的IP地址类型。 取值说明： IPv4（IPv4）IPv6（IPv6）                                      |
| 对端IPv4地址   | 该参数用于返回UCF服务器的IPv4地址。                                                                 |
| 对端IPv6地址   | 该参数用于返回UCF服务器的IPv6地址。                                                                 |
| 对端端口       | 该参数用于返回UCF服务器的端口号。                                                                    |
| 协议类型       | 该参数用于请求系统显示指定协议类型的链路状态；若不输入，则显示环境中所有协议类型的信息。 取值说明： TCP（TCP）SFTP（SFTP）FTP（FTP）UDP（UDP） |
| 链路状态       | 该参数用于返回链路的状态。 取值说明： UP（正常）Down（中断）                                                    |
