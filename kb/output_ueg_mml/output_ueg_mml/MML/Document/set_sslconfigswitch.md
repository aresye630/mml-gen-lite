# 设置SSL协议开关 (SET SSLCONFIGSWITCH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**须知** 

- 开关默认关闭，设置开关为打开状态会启用TLSv1.1不安全协议，**存在安全风险**，**系统会上报告警**，同时该操作执行生效过程中可能会导致**网管对接出现短暂的断链**。

- 关闭开关后，新建链接会切换到安全的对接协议。若关闭开关时存在使用TLSv1.1协议对接的活动链路，为了保证业务不中断，服务端不会主动断链，需要对接客户端主动断链再重新对接。

用于设置SSL协议开关状态。

#### 注意事项

- 设置SSL协议开关状态为开时，会开启不安全的TLSv1.1协议及弱加密算法套件。
- 当前系统的SSL协议开关状态仅支持9000端口配置。
- SSL协议开关初始状态为关闭。

#### 参数说明

| 参数标识            | 参数名称      | 参数说明                                                               |
|:----------------|:----------|:-------------------------------------------------------------------|
| SSLSWITCHSTATUS | SSL协议开关状态 | 可选必选说明：必选参数。 参数含义：SSL协议开关状态。 取值范围： ON(开)OFF(关) 默认值：OFF(关)。 配置原则：无。 |

#### 使用实例

设置SSL协议开关状态为开：

```
%%SET SSLCONFIGSWITCH: SSLSWITCHSTATUS=ON;%%
RETCODE = 0  操作成功

---    END
```
