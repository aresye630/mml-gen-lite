# 增加联合接入IMSI白名单(ADD PSCSIMSI)

#### 命令功能

**适用网元：MME**

该命令用于增加联合接入IMSI白名单。当SET PSCSPLCY中SUBPLCY参数设置为IMSI\_IDENT时需要通过本命令添加白名单中的用户。

#### 注意事项

- 本表最大记录数为100条。
- 当SET PSCSPLCY中SUBPLCY参数设置为IMSI\_IDENT时生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                     |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------|
| IMSIPRE | IMSI前缀 | 可选必选说明：必选参数 参数含义：该参数用于指定IMSI前缀以区分不同的用户群。 数据来源：整网规划 取值范围：1~15位十进制数字 默认值：无 配置原则：IMSI前缀的匹配方式采取由前向后的最长匹配，即若对于用户可以匹配到多个用户群，则使用IMSI前缀最长的用户群配置。 |

#### 使用实例

增加联合接入IMSI白名单：

```
ADD PSCSIMSI: IMSIPRE="12345";
```
