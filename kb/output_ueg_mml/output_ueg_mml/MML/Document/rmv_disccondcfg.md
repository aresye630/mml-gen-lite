# 删除服务发现条件信息（RMV DISCCONDCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致系统异常，影响业务处理，需联系华为技术支持确认后再执行。

该命令用于删除一条服务发现条件信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                         |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFTYPE | 网元类型   | 可选必选说明：必选参数 参数含义：标识一个网元类型的关键字段，用于指定需要删除哪个网元的服务发现条件信息，操作员可以使用LST DISCCONDCFG命令查询获得。 取值范围： CHF(CHF)BSF(BSF)SCP(SCP)AMF(AMF)NWDAF(NWDAF)PCF(PCF) 默认值：无。 配置原则：无。 |

## 使用实例

删除一个服务发现条件信息，“网元类型”为“BSF(BSF)”

```
RMV DISCCONDCFG: NFTYPE=BSF;
```
