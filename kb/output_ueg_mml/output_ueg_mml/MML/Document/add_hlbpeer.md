# 添加HLB对端(ADD HLBPEER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令配置有风险，HTTP协议不安全，推荐使用安全的HTTPS协议进行对接，请确认是否继续？

用于在配置数据库中增加一条与HLB对接的实体数据记录。

该命令在特定场景下才能使用，如需使用该命令增加与HLB连接的对端实体配置信息请联系华为技术支持。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                   |
|:----------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PEERID    | 对端标识    | 可选必选说明：必选参数 参数含义：用于定义HLB对端设备的标识。 取值范围：0～63 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。                                                                                                                                                                                                                                                                           |
| NAME      | 名称      | 可选必选说明：可选参数 参数含义：用于定义HLB对端设备的名称。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。                                                                                                                                                                                                                                                                  |
| TYPE      | 对端类型    | 可选必选说明：必选参数 参数含义：用于定义HLB对端设备的类型。 取值范围：NRF(NRF)AMF(AMF)SMF(SMF)BSF(BSF)CHF(CHF) 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。                                                                                                                                                                                                                                       |
| HTTPSFUNC | HTTPS功能 | 可选必选说明：可选参数 参数含义：表示是否开启HTTPS功能，启用TLS证书。 取值范围： ON(打开)：表示启用TLS证书。OFF(关闭)：表示不启用TLS证书。 默认值：ON(打开) 配置原则：无。  说明： 当该参数设置为“ON(打开)”时，HLB服务性能将会下降20%，如需开启请联系华为技术支持。                                                                                                                                                                                              |
| CERTSCENE | 证书应用场景  | 可选必选说明：条件必选参数 参数含义：表示注册HLB服务的TLS证书应用场景，仅当“HTTPS功能”配置为“ON(打开)”时该参数可配置且必须配置。 取值范围： UPCF_HLB_Lcert(UPCF_HLB_Lcert) 默认值：无。 配置原则：无。  说明： 证书应用场景下关联的证书文件，必须是设备证书文件、证书私钥文件和CA证书文件分别有且只有一个。                                                                                                                                                                    |
| TLSCFGID  | TLS配置ID | 可选必选说明：必选参数 参数含义：用于指定关联的TLS配置记录，该参数必须先由ADD HLBTLSCFG命令定义，然后才能在此处索引。仅当“HTTPS功能”配置为“ON(打开)”时该参数可配置且必须配置。 取值范围：1～128 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。                                                                                                                                                                                                    |
| SIGROUTE  | 信令路由    | 可选必选说明：可选参数 参数含义：用于设置信令路由功能。 取值范围： ON(打开)：表示打开信令路由功能。OFF(关闭)：表示关闭信令路由功能。 默认值：OFF(关闭)。 配置原则：无。                                                                                                                                                                                                                                                          |
| LINKNUM   | 链路数     | 可选必选说明：可选参数 参数含义：当“信令路由”的取值为“ON”时该参数有效，用于设置一个HLB服务对一条HLBPEERLINK配置实际建立的链路数量。 取值范围：2～4 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                   |
| STREAMNUM | 最大流数目   | 可选必选说明：可选参数 参数含义：当“信令路由”的取值为“ON”时该参数有效，用于设置对端下每条链路发送的最大流数目。 根据“链路数”设置不同链路的最大流数目，使用“-”区分不同链路，如配置2个链路的最大流数目分别为1024和2048，则输入 1024-2048 取值范围：长度不超过128的字符串。限定只能输入数字和-。 默认值：无。 配置原则：无。  说明： 单条链路的最大流数目的取值范围是0～2147483647，0表示该条链路不设置最大数目。当不输入参数值时，表示所有链路都不设置最大流数目。设置该参数时，如果HLB与对端存在已建链路会导致链路断链重建，对业务有影响。 当链路不设置最大流数目时，该链路流数目不进行统计，DSP HLBPEERL显示的“当前流数目”为“0”。 |
| LINKMODE  | 链路模式    | 可选必选说明：可选参数 参数含义：当“信令路由”的取值为“ON”时该参数有效，用于设置对端链路的选路模式。 取值范围： PRIORITY(优先级)WEIGHT(权重) 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                     |
| PRIORITY  | 优先级     | 可选必选说明：可选参数 参数含义：当“链路模式”取值为“Priority”时该参数有效，用于设置对端下每条链路的优先级。 根据“LINKNUM”设置不同链路的优先级，使用“-”区分不同链路，如配置2个链路的优先级分别为16和32，则输入 16-32。 取值范围：长度不超过64的字符串，限定只能输入数字和-。 默认值：无。 配置原则：无。  说明： 单条链路优先级的取值范围是0-32，0表示该条链路优先级最低。                                                                                                                                         |
| WEIGHT    | 权重      | 可选必选说明：可选参数 参数含义：当“链路模式”取值为“Weight”时该参数有效，用于设置对端下每条链路的权重。 根据“LINKNUM”设置不同链路的权重，使用“-”区分不同链路，如配置2个链路的权重分别为5和5，则输入 5-5，所有链路权重加起来等于10。 取值范围：长度不大于64的字符串，限定只能输入数字和-。 默认值：无。 配置原则：无。  说明： 单条链路权重的取值范围是0-10，0表示该条链路不参与消息发送。                                                                                                                                   |

## 使用实例

增加HLB对端实体信息。“对端标识”为“1”，“名称”为“smf00”，“类型”为“SMF”，“HTTPS功能”为“ON(打开)”，“证书应用场景”为“UPCF\_HLB\_Lcert(UPCF\_HLB\_Lcert)”，“TLS配置ID”为“1”。

```
ADD HLBPEER: PEERID=1, NAME="smf00", TYPE=SMF, HTTPSFUNC=ON, CERTSCENE=UPCF_HLB_Lcert, TLSCFGID=1;
```
