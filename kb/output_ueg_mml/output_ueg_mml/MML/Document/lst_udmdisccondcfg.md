# 查询服务发现条件信息(LST UDMDISCCONDCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询所有网元实例的服务发现条件信息：

- 若要查询全部网元实例的服务发现条件信息，请不要输入任何参数。
- 若要查询某一类型网元实例的服务发现条件信息，请输入“网元类型”参数。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                 |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------|
| NFTYPE | 网元类型   | 可选必选说明：可选参数 参数含义：用于指示系统按照网元实例的类型来查询服务发现条件信息；若不输入，则表示所有网元类型的服务发现条件信息。 取值范围： SCP：服务通信代理 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询所有SCP网元实例的服务发现条件信息:

   ```
   LST UDMDISCCONDCFG: NFTYPE=SCP;
   ```

   ```
   %%LST UDMDISCCONDCFG: NFTYPE=SCP;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   网元类型  =  SCP
    SCP参数  =  SCPDOMAINS
   (结果个数 = 1)

   ---    END
   ```
2. 查询全部网元实例的服务发现条件信息:

   ```
   LST UDMDISCCONDCFG:
   ```

   ```
   %%LST UDMDISCCONDCFG:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   网元类型  =  SCP
    SCP参数  =  SCPDOMAINS
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD UDMDISCCONDCFG**命令的参数说明。
