# 查询全局数据最大记录数(LST GLBMAXNUM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令是维护类命令，用于查询全局数据的最大记录数。

- 如果需要查询全部全局数据的最大记录数，请不要输入任何参数。
- 如果需要查询某个全局数据的最大记录数，请依据参数说明输入查询条件。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数描述                                                                                                                                                                                                                                                                                                 |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NAME   | 全局数据名称 | 可选必选说明：可选参数 参数含义：用于指定需要查询最大记录数的全局数据对象。 取值范围： CONDITIONGROUP(CONDITIONGROUP)：条件组ACTIONGROUP(ACTIONGROUP)：动作组NOTIFICATION(NOTIFICATION)：消息通知RULE(RULE)：规则POLICY(POLICY)：策略SERVICE(SERVICE)：业务ACTIONELEMENT(ACTIONELEMENT)：动作元素NGACTION(NGACTION)：5G动作组NGACTIONELEM(NGACTIONELEM)：5G动作元素 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询所有的全局数据的配置。

   ```
   LST GLBMAXNUM:;
   ```

   ```
   %%LST GLBMAXNUM:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
    全局数据名称    全局数据最大记录数  全局数据最大记录数默认值     

    CONDITIONGROUP   10240               10240
    ACTIONGROUP      1024                1024
    NOTIFICATION     4096                4096
    RULE             30000               20480
    POLICY           4096                4096
    SERVICE          4096                4096
    ACTIONELEMENT    30720               12288
    NGACTION         3072                3072
    NGACTIONELEM     12288               12288
   (结果个数 = 9)

   ---    END
   ```
2. 查询规则的最大记录数。“全局数据名称”为“RULE(RULE)”。

   ```
   LST GLBMAXNUM: NAME=RULE;
   ```

   ```
   %%LST GLBMAXNUM: NAME=RULE;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
               全局数据名称  =  RULE
         全局数据最大记录数  =  30000
   全局数据最大记录数默认值  =  20480
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET GLBMAXNUM**命令的参数说明。
