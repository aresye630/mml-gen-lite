# 清除用户面故障缓存（CLR UPFAULTCACHE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C、SMF、GGSN**

该命令用于清除用户面故障缓存。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                  |
|:-------------|:--------|:----------------------------------------------------------------------------------------------------------------------|
| UPINSTANCEID | UPF实例标识 | 可选必选说明：可选参数  参数含义：该参数用于指定UPF实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~50。不区分大小写。  默认值：无  配置原则：无                           |
| FAULTTYPE    | 故障类型    | 可选必选说明：可选参数  参数含义：该参数用于指定故障类型。  数据来源：本端规划 取值范围： ALL（所有）N3（N3链路故障信息）N6（N6链路故障信息）  默认值：ALL  配置原则：无                      |
| APN          | APN名称   | 可选必选说明：该参数在"FAULTTYPE"配置为"N6"时为条件可选参数。  参数含义：该参数用于指定APN实例名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

清除所有用户面故障缓存。CLR UPFAULTCACHE: FAULTTYPE=ALL;

```
CLR UPFAULTCACHE: FAULTTYPE=ALL;
```
