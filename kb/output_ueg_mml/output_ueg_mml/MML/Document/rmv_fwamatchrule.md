# 删除FWA用户匹配规则（RMV FWAMATCHRULE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除FWA用户匹配规则。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                 |
|:----------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MATCHTYPE | 匹配类型   | 可选必选说明：必选参数  参数含义：该参数用于指定匹配是否为FWA用户的类型，当前支持按照PCC Rule和APN进行匹配。  数据来源：本端规划 取值范围： MatchTypeRule（RULE匹配）MatchTypeApn（APN匹配）  默认值：无  配置原则：  大小写不敏感。                      |
| MATCHFUNC | 匹配方式   | 可选必选说明：必选参数  参数含义：该参数用于指定采用全匹配还是只需要包含配置的PCC RULE或者APN的方式判断是否是FWA用户。  数据来源：本端规划 取值范围： “MatchFuncFull（全匹配）”：全匹配“MatchFuncContain（包含匹配）”：包含该字符串即匹配为FWA用户  默认值：无  配置原则：无 |
| RULE      | PCC规则  | 可选必选说明：该参数在"MATCHTYPE"配置为"MatchTypeRule"时为条件必选参数。  参数含义：该参数用于指定用于判断是否是FWA用户的PCC规则。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~63。  默认值：无  配置原则：无                                |
| APN       | APN名称  | 可选必选说明：该参数在"MATCHTYPE"配置为"MatchTypeApn"时为条件必选参数。  参数含义：该参数用于指定用于判断是否是FWA用户的APN。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~63。  默认值：无  配置原则：无                                   |

## 使用实例

当需要删除基于指定PCC RULE进行全匹配来判断当前用户是否是FWA用户时，进行如下设置,

```
RMV FWAMATCHRULE:MATCHTYPE=MatchTypeRule,MATCHFUNC=MatchFuncFull,RULE="up_870000174";
```
