# 查询本端服务器配置(LST HTTPLSERVER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询数据库中本端服务器配置数据记录。

- 若需要查询所有的本端服务器配置，不需要输入参数。
- 若需要查询某条“本端服务器名称”对应的本端服务器配置，请输入“本端服务器名称”。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                     |
|:------------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------|
| LSERVERNANE | 本端服务器名称 | 可选必选说明：可选参数 参数含义：用于标识需要按照哪个本端HTTP服务端名称来查询本端服务器配置，若不输入，则查询所有本端服务器的配置。 取值范围：长度不超过128的由数字和字母组成的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询所有本端服务器配置信息：

   ```
   LST HTTPLSERVER:;
   ```

   ```
   %%LST HTTPLSERVER:;%%
   RETCODE = 0  操作成功

   本端服务器名称  IP名称  端口  开启HTTPS  证书应用场景      TLS配置ID  

   aaaaaa          ip411   8084  关闭HTTPS  HLB 证书应用场景  1          
   asdfafd         ip411   8888  关闭HTTPS  HLB 证书应用场景  1          
   http            ip411   1111  关闭HTTPS  NULL              NULL       
   httpsserver     ip411   8081  关闭HTTPS  HLB 证书应用场景  1          
   test            ip411   8082  关闭HTTPS  HLB 证书应用场景  1          
   (结果个数 = 5)

   ---    END
   ```
2. 查询“本端服务器名称”为“aaaaaa”的信息：

   ```
   LST HTTPLSERVER: LSERVERNANE="aaaaaa";
   ```

   ```
   %%LST HTTPLSERVER: LSERVERNANE="aaaaaa";%%
   RETCODE = 0  操作成功

   本端服务器名称  =  aaaaaa
           IP名称  =  ip411
             端口  =  8084
        开启HTTPS  =  关闭HTTPS
     证书应用场景  =  HLB 证书应用场景
        TLS配置ID  =  1
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD HTTPLSERVER**命令的参数说明。
