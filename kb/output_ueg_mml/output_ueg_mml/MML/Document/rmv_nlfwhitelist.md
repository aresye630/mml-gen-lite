# 删除NLF白名单(RMV NLFWHITELIST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中删除一条NLF白名单信息数据记录。

## 注意事项

**命令生效条件**：该命令执行后立即生效。如果有使用已删除的IP地址，则此连接会被立即断开。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                          |
|:-------|:-------|:--------------------------------------------------------------|
| ID     | 索引     | 可选必选说明：必选参数 参数含义：用于定义一条NLF白名单的数据记录。 取值范围：0～255 默认值：无。 配置原则：无。 |

## 使用实例

删除一条NLF白名单信息，“索引”为“1”。

```
RMV NLFWHITELIST: ID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
