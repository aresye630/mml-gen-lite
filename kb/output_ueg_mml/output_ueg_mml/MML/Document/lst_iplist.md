# 查询IP地址列表（LST IPLIST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于显示配置IP地址。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                        |
|:-----------|:-------|:--------------------------------------------------------------------------------------------|
| IPLISTNAME | IP列表名称 | 可选必选说明：可选参数 参数含义：该参数用于指定IP列表名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

- 查询指定IP地址列表：

  ```
  LST IPLIST:IPLISTNAME="test01";
  ```

  ```
  RETCODE = 0  操作成功。

  IP地址列表信息
  --------------
      IP列表名称  =  test01
  IP地址版本类型  =  IPV4
        地址信息  =  10.0.0.1
      IP地址掩码  =  1
      配置域名称  =  NULL
  (结果个数 = 1)
  ---    END
  ```
- 查询所有IP地址列表：

  ```
  LST IPLIST:;
  ```

  ```
  RETCODE = 0  操作成功。

  IP地址列表信息
  --------------
  IP列表名称    IP地址版本类型    地址信息    IP地址掩码    配置域名称

  iplist01      IPV4              10.0.0.1    1             NULL
  test01        IPV4              10.0.0.1    1             NULL
  test02        IPV4              10.0.0.1    1             NULL
  (结果个数 = 3)
  ---    END
  ```
