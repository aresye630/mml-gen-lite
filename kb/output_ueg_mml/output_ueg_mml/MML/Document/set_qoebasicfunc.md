# 设置QoE基本功能（SET QOEBASICFUNC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，设置不当会导致保障体验类业务功能不可用。

此命令用于设置QoE基本功能相关参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 只有开启了QOESWITCH开关和INQOESWITCH开关，QoE模型才会加载。
- 只有安装IISA服务后才可配置为融合智能感知模式。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | QOESWITCH   | INQOESWITCH   | MODE   |
|:-------|:------------|:--------------|:-------|
| 初始值    | DISABLE     | ENABLE        | SSU    |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                        |
|:------------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| QOESWITCH   | QoE分析开关   | 可选必选说明：必选参数 参数含义：该参数用于设置QoE分析开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能QoE分析。ENABLE：使能QoE分析。 默认值：无 配置原则：无                                                                         |
| INQOESWITCH | QoE智能分析开关 | 可选必选说明：条件可选参数 前提条件：该参数在“QOESWITCH”配置为“ENABLE”时为可选参数。 参数含义：该参数用于配置QoE智能分析开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能QoE智能分析。ENABLE：使能QoE智能分析。 默认值：ENABLE 配置原则：无                     |
| MODE        | 运行模式      | 可选必选说明：条件可选参数 前提条件：该参数在“INQOESWITCH”配置为“ENABLE”时为可选参数。 参数含义：该参数用来指定体验感知业务的运行模式。 数据来源：本端规划 取值范围：枚举类型。 SSU：使用智能服务单元模式。IISA：使用融合智能感知模式。 默认值：SSU 配置原则：只有安装IISA服务后才可配置为融合智能感知模式。 |

#### 使用实例

设置QoE基本功能，开启QoE分析开关，开启QoE智能分析开关，执行如下命令：

```
SET QOEBASICFUNC: QOESWITCH=ENABLE, INQOESWITCH=ENABLE,MODE=SSU;
```
