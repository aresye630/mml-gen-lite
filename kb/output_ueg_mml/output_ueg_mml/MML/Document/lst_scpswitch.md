# 查询SCP功能开关(LST SCPSWITCH)

## 命令功能

该命令用来查询SCP功能开关配置状态。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询SCP功能是否开启：

```
LST SCPSWITCH:;
```

```
%%LST SCPSWITCH:;%%
RETCODE = 0  操作成功

操作结果如下:
-------------
             开关  =  禁用
业务经SCP路由开关  =  NULL
(结果个数 = 1)
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET SCPSWITCH**命令的参数说明。
