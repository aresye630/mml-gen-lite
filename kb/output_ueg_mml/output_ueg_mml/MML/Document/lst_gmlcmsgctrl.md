# 查询GMLC消息控制参数（LST GMLCMSGCTRL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询系统当前配置的GMLC消息控制参数。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询GMLC消息控制参数：

```
LST GMLCMSGCTRL:;
```

