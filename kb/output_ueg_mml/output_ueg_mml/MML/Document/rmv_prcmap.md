# 删除PCRF结果码映射（RMV PRCMAP）

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响业务处理，需联系华为技术支持确认后再执行。

该命令用于删除一条PCRF的结果码映射记录。

## 注意事项

- 执行本命令时，请参照参数说明的取值范围要求，输入“接口类型”下对应的“源结果码”。
- 对于未配置或已删除的结果码映射记录不可执行本操作，可通过LST PRCMAP查询已有的配置记录，再根据查询结果重新执行本命令。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                |
|:-------|:-------|:------------------------------------------------------------------------------------|
| IFTYPE | 接口类型   | 可选必选说明：必选参数 参数含义：用于指定删除PCRF的结果码映射的接口类型。 取值范围：Gx(Gx)Rx(Rx) 默认值：Gx(Gx) 配置原则：无         |
| SRCRC  | 源结果码   | 可选必选说明：必选参数 参数含义：用于指定删除PCRF的结果码映射的源结果码。 取值范围：与ADD PRCMAP命令中的源结果码参数值一致。 默认值：无 配置原则：无 |

## 使用实例

删除一条PCRF结果码映射，“接口类型”为“Gx(Gx)”，“源结果码”为“RC1001(DIAMETER\_MULTI\_ROUND\_AUTH)”。

```
RMV PRCMAP: IFTYPE=Gx, SRCRC=RC1001;
```
