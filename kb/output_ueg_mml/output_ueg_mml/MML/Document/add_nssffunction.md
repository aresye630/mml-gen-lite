# 添加NSSF功能实例信息（ADD NSSFFUNCTION）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NSSF**

本命令用于添加NSSF功能实例信息。

## 注意事项

- 该命令执行后立即生效。

- 该命令当前版本仅支持配置1条记录，否则会影响北向功能。

- 最多可输入100条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称       | 参数说明                                                                                                            |
|:---------------|:-----------|:----------------------------------------------------------------------------------------------------------------|
| INSTANCEID     | NSSF功能实例号  | 可选必选说明：必选参数  参数含义：NSSF功能实例号。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~40。  默认值：无  配置原则：无                                 |
| NAME           | NSSF功能实例描述 | 可选必选说明：必选参数  参数含义：NSSF功能实例描述。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~64。  默认值：无  配置原则：无                                |
| ADMINSTATE     | 管理状态       | 可选必选说明：可选参数  参数含义：NSSF功能实例的管理状态。  数据来源：本端规划 取值范围： Locked（锁定）Unlocked（未锁定）ShuttingDown（关机）  默认值：Unlocked  配置原则：无 |
| OPERATIONSTATE | 运行状态       | 可选必选说明：可选参数  参数含义：NSSF功能实例的运行状态。  数据来源：本端规划 取值范围： Enabled（运行）Disabled（不运行）  默认值：Enabled  配置原则：无                 |
| FQDN           | FQDN       | 可选必选说明：必选参数  参数含义：NSSF功能实例的FQDN。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~255。  默认值：无  配置原则：无                            |

## 使用实例

新增NSSF功能实体号为Instanceid01，NSSF功能实体描述为nfdescription01，管理状态为Locked，运行状态为Enabled，FQDN为fqdn01，最大切片选择次数为100的NSSF功能实例信息。

```
ADD NSSFFUNCTION:INSTANCEID="Instanceid01",NAME="nfdescription01",ADMINSTATE=Locked,OPERATIONSTATE=Enabled,FQDN="fqdn01";
```
