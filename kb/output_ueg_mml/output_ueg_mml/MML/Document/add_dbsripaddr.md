# 增加远端网元IP地址(ADD DBSRIPADDR)

## 命令功能

**须知** 

该命令属于高危命令，该操作可能会导致业务中断。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于增加远端网元IP地址，使得本端网元和远端USCDB链路互通。

该命令的使用场景：当华为FE需与USCDB对接时，需要通过该命令增加远端网元IP地址。

通过以下步骤配置对接数据：

1. 通过**ADD DBSRLOCATION**命令增加远端Location标识。
2. 通过**ADD DBSRDSG**增加远端DSG模块。
3. 通过本命令增加远端IP地址。

完成以上配置之后，通过**ACT DBSIPDISP**命令激活链路，完成华为FE与USCDB的对接配置。

## 注意事项

- 远端Location IP信息是在远端网元客户端执行**ADD SRVIPADDR**命令增加后在此引用。
- IP地址与网关必须在同一网段，否则，会导致通信失败。
- IP地址不能与已使用的IP地址重复，否则，会导致通信失败。
- 执行该命令后需要通过**ACT DBSIPDISP**命令激活IP链路之后配置才能生效。
- 如果IP地址相同，“远端IP地址业务类型”必须不同。

## 参数说明

| 参数标识    | 参数名称               | 参数说明                                                                                                                             |
|:--------|:-------------------|:---------------------------------------------------------------------------------------------------------------------------------|
| RLOCID  | 远端Location标识       | 可选必选说明：必选参数。 参数含义：用于指定一个远端网元标识。 取值范围：1～512 默认值：无。 配置原则：该参数须在对接的远端USCDB网元中先定义，然后在本端网元通过ADD DBSRLOCATION命令配置后，才能在此处索引。             |
| ID      | 远端业务IP的索引          | 可选必选说明：必选参数。 参数含义：用于指定远端网元IP地址对应的远端业务IP的索引。 取值范围：1～4080 默认值：无。 配置原则：该参数必须在对接的远端网元中先定义，然后才能在此处索引。                                 |
| IPVER   | IP类型               | 可选必选说明：必选参数。 参数含义：用于指定远端IP地址类型。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无                                                         |

| IPV4IP2 | 远端Location IPV4地址2 | 可选必选说明：条件可选参数。 参数含义：用于指定远端网元的Location IP地址。这个地址必须在对接的远端网元中已经配置完毕。 取值范围：IPV4地址。 默认值：无。 配置原则：仅当本命令中的“IP类型”参数取值为“IPV4(IPV4)”时该参数有效。 |

| IPV6IP2 | 远端Location IPV6地址2 | 可选必选说明：条件可选参数。 参数含义：用于指定远端网元的Location IP地址。这个地址必须在对接的远端网元中已经配置完毕。 取值范围：IPV6地址。 默认值：无。 配置原则：仅当本命令中的“IP类型”参数取值为“IPV6(IPV6)”时该参数有效。 |
| RIPST   | 远端IP地址业务类型         | 可选必选说明：可选参数。 参数含义：用于指定远端网元IP地址的业务类型。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：该参数为联想参数列表，不能手动输入，其取值为LST DBSSRVGROUP命令查询获得的“业务类型名称”输出参数。    |

## 使用实例

在开局场景下，增加远端网元IP地址，“远端Location标识”为“3”，“远端业务IP的索引”为“1”，“IP类型”为“IPV4”，“远端Location IPV4地址1”为“172.21.128.24”，“远端Location IPV4地址2”为“172.21.128.25”，“远端IP地址业务类型”为“SUP-FE”：

```
ADD DBSRIPADDR: RLOCID=3, ID=1, IPVER=IPV4, IPV4IP1="172.21.128.24", IPV4IP2="172.21.128.25", RIPST="SUP-FE";
```
