# 设置指定消息类型固定速率流控信息（SET GTPCFIXEDFC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

存在较大操作风险，执行不当会导致业务受损或中断。

**适用NF：SGW-C、PGW-C**

设置指定消息类型的固定速率门限，超过门限的消息将会被UNC丢弃，以减少其它网元对UNC的信令冲击，以及UNC对周边网元的信令冲击。

## 注意事项

- 该命令执行后立即生效。

- 当SET AMFN26PLCY命令中N26ITFMODE取值为“COMBINE”时，当前命令无效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| MSGTYPE              | FCSWITCH   |   THRESHOLD |
|:---------------------|:-----------|------------:|
| CREATESESSIONREQUEST | ON         |        1200 |
| MODIFYBEARERREQUEST  | ON         |       15000 |
| ALLMSGTYPE           | ON         |       30000 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称        | 参数说明                                                                                                                                                                                                                                                              |
|:----------|:------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MSGTYPE   | 流控消息类型      | 可选必选说明：必选参数  参数含义：该参数用于设置GTP-C接口被流控的消息类型。  数据来源：全网规划 取值范围： “CREATESESSIONREQUEST（Create Session Request）”：表示Create Session Request消息“MODIFYBEARERREQUEST（Modify Bearer Request）”：表示Modify Bearer Request消息“ALLMSGTYPE（All Message Type）”：表示所有消息类型  默认值：无。  配置原则：无 |
| FCSWITCH  | 固定速率流控开关    | 可选必选说明：必选参数  参数含义：该参数用于设置指定消息类型流控功能开关。  数据来源：全网规划 取值范围： “ON（开启）”：开启GTP-C接口的“固定速率流控”功能。“OFF（关闭）”：关闭GTP-C接口的“固定速率流控”功能。  默认值：无。  配置原则：  当希望开启指定消息类型流控功能时，设置为"ON"；当希望关闭指定消息类型流控功能时，设置为"OFF"。                                                                         |
| THRESHOLD | 流控速率门限(个/秒) | 可选必选说明：该参数在"FCSWITCH"配置为"ON"时为条件必选参数。  参数含义：该参数用于设置单sm-pod指定消息的接收流控速率上限。  数据来源：全网规划  取值范围：整数类型，取值范围是0~1000000。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST GTPCFIXEDFC查询当前参数配置值。  配置原则：  该参数按sm-pod单POD粒度设置。                                                         |

## 使用实例

针对的Create Session Request开启固定速率流控，速率门限是单sm-pod 4000个/秒。执行如下命令：

```
SET GTPCFIXEDFC:MSGTYPE=CREATESESSIONREQUEST,FCSWITCH=ON,THRESHOLD=4000;
```
