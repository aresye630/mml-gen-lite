# 查询缺省GBR承载参数（LST DFTGBRBEARER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于查询SMF是否支持创建default-gbr承载（提供最低带宽保障的any to any GBR专有承载）、本地触发创建default-gbr承载时的承载QoS、以及删除default-gbr承载时SMF是否去活整个PDU会话。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                             |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN    | APN名称  | 可选必选说明：可选参数 参数含义：该参数用于指定APN名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”特殊字符，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

假如运营商需要查询指定APN是否支持创建default-gbr承载，则使用该实例：

```
LST DFTGBRBEARER: APN="test1";
```
