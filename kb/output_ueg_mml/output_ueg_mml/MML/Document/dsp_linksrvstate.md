# 查询链路服务状态（DSP LINKSRVSTATE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询DLB/LDAP链路的服务状态。

- 如果需要查询全部服务类型链路的服务状态信息，请不要输入任何参数。
- 如果需要查询指定服务类型链路的服务状态信息，请依据参数说明输入查询条件。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数描述                                                                                  |
|:------------|:-------|:--------------------------------------------------------------------------------------|
| SERVICETYPE | 服务类型   | 可选必选说明：可选参数 参数含义：用于指示系统按照服务类型来查询链路的服务状态；若不输入，则表示所有的服务类型。 取值范围： DLBLDAP 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询全部链路的服务状态。

   ```
   DSP LINKSRVSTATE:;
   ```

   ```
   %%DSP LINKSRVSTATE:;%% 
   RETCODE = 0  操作成功  

   操作结果如下：
   ------------------------ 
   服务类型      实例号                状态     
   DLB           13219527154257908387  Master  
   DLB           13219527154257644631  Slave   
   LDAP          13220681783200989931  Master  
   LDAP          13220681783200732780  Slave  
   (结果个数 = 4)  

   ---    END
   ```
2. 查询LDAP链路的服务状态。“服务类型”为“LDAP”。

   ```
   DSP LINKSRVSTATE: SERVICETYPE=LDAP;
   ```

   ```
   %%DSP LINKSRVSTATE: SERVICETYPE=LDAP;%% 
   RETCODE = 0  操作成功  

   操作结果如下：
   ------------------------ 
   服务类型      实例号                状态       
   LDAP          13220681783200989931  Master  
   LDAP          13220681783200732780  Slave  
   (结果个数 = 2)  

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1。

| 输出项名称   | 输出项解释                          |
|:--------|:-------------------------------|
| 服务类型    | 表示链路的服务类型。 取值范围： DLBLDAP       |
| 实例号     | 表示链路的服务实例号。 取值范围：长度不超过256的字符串。 |
| 状态      | 表示链路的服务状态。 取值范围： SlaveMaster   |
