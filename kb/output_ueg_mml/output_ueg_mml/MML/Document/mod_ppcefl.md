# 修改PCRF对端PCEF链路信息(MOD PPCEFL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于修改或调整配置数据库中的一条PCRF实体和对端PCEF实体的链路数据记录。在该命令中，系统通过“PCRF标识”、“对端PCEF标识”和“对端PCEF链路标识”参数来唯一标识一条PCRF实体和对端PCEF实体的链路数据记录。

## 注意事项

- 相同“对端PCEF标识”下，只能存在一条“对端IPV4地址”/“对端IPV6地址”、“本端IPV4地址”/“本端IPV6地址”、“本地侦听端口”和“传输协议类型”取值都相同且“对端端口”为“0”的链路。
- 不同“对端PCEF标识”下，可以各存在一条“对端IPV4地址”/“对端IPV6地址”、“本端IPV4地址”/“本端IPV6地址”、“本地侦听端口”和“传输协议类型”取值都相同且“对端端口”为“0”的链路。
- 修改对端PCEF链路的“对端IPV4地址”/“对端IPV6地址”、“对端端口”、“链路管理状态”和“本地端口模式”会导致链路状态改变，影响业务。
- IPv6类型的IP地址不支持混合方式表达，即xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:d.d.d.d，其中x表示一个十六进制数（0～9或A～F），而d.d.d.d表示一个IPv4地址。
- “对端IPV6地址”不支持以下特殊地址的配置，其中x表示一个十六进制数（0～9或A～F）：
  - FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF
  - 0000:0000:0000:0000:0000:0000:0000:0001
  - FFxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE8x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE9x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEAx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEBx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
- 如果两双归属链路的本地端口号相同，且本地对应的链路及IP地址分别为链路1的本地IP1+双归属本地IP2与链路2的本地IP3+双归属本地IP4，此时存在如下几种情况会导致本端地址端口冲突：
  - 本地IP1=本地IP3，双归属本地IP2≠双归属本地IP4
  - 本地IP1=双归属本地IP4，双归属本地IP2≠本地IP3
  - 本地IP1≠本地IP3，双归属本地IP2=双归属本地IP4
  - 本地IP1≠双归属本地IP4，双归属本地IP2=本地IP3
- 当本端作为服务端时，若满足以下任意条件，新增链路与已有链路的“对端端口”只能同时为“0”或者同时为“非0”。
  - “传输协议类型”为“TCP”，且新增链路与已有链路的“本端IPV4地址/本端IPV6地址”、“本地侦听端口”都相同。
  - “传输协议类型”为“SCTP”，“双归属开关”关闭，且新增链路与已有链路的“IPV4地址/本端IPV6地址”、“本地侦听端口”都相同。
  - “传输协议类型”为“SCTP”，“双归属开关”打开，且新增链路与已有链路的“本端IPV4地址/本端IPV6地址/双归属本端IPV4地址/双归属本端IPV6地址”、“本地侦听端口”都相同。

## 参数说明

| 参数标识      | 参数名称        | 参数说明                                                                                                                                                                                                                                                                        |
|:----------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PCRFID    | PCRF标识      | 用于标识PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围：1 默认值：无。                                                                                                                                                                                                                     |
| PCEFID    | 对端PCEF标识    | 用于指定一个PCEF实体，该参数必须先由ADD PPCEF命令定义，然后才能在此处索引。 取值范围：0～1023 默认值：无。                                                                                                                                                                                                             |
| LNKID     | 对端链路标识      | 用于在UPCF的配置库中定义一个对端PCEF实体链路。该参数的配置原则：如果配置多个对端PCEF实体链路，从0开始顺序配置。 取值范围：0～3 默认值：无。                                                                                                                                                                                              |
| DISPMODE  | 分发模式        | 用于定义网络报文的分发模式。 取值范围： SpecialQuintuple（固定五元组转发）WellKnownPort（知名端口分发） 默认值：无。  说明： 该参数不支持“WellKnownPort（知名端口分发）”                                                                                                                                                               |
| TPTYPE    | 传输协议类型      | 用于指定链路的传输协议类型，当前可以选择传输控制协议、流量控制传输协议 取值范围： SCTP（流量控制传输协议）TCP（传输控制协议） 默认值：无。                                                                                                                                                                                                  |
| DUALHOME  | 双归属开关       | 双归属开关。“传输协议类型”为“SCTP”时，才可以配置该参数。 取值说明： OFF(关闭)ON(打开) 默认值：无                                                                                                                                                                                                                  |
| CROSSPATH | 交叉路径        | 双归属时的交叉路径配置。当“双归属开关”为“ON(打开)”时，需要设置此参数。 取值说明： OFF(关闭)：表示关闭交叉路径功能。ON(打开)：表示打开交叉路径功能。 默认值：ON(打开)                                                                                                                                                                              |

| IPVER     | IP版本        | 用于指定本端和对端IP地址的IP版本类型。 取值范围： IPV4IPV6 默认值：无。                                                                                                                                                                                                                                 |
| DLIP      | 双归属本端IPV4地址 | PCRF与对端PCEF产品对接的参数之一，用于指定链路使用的双归属本端IPv4地址。需要PCRF与对端PCEF协商一致；若不一致，可能会导致两者之间的链路无法正常建立。该参数必须已经通过ADD DLBDEVADDR命令添加。 取值范围：IPv4地址 默认值：无。  说明： 当“双归属地址IP版本”选择“IPV4”时，可设置该参数。                                                                                                      |
| DLIPV6    | 双归属本端IPV6地址 | PCRF与对端PCEF产品对接的参数之一，用于指定链路使用的双归属本端IPv6地址。需要PCRF与对端PCEF协商一致；若不一致，可能会导致两者之间的链路无法正常建立。该参数必须已经通过ADD DLBDEVADDR命令添加。 取值范围：IPv6地址 默认值：无。  说明： 当“双归属地址IP版本”选择“IPV6”时，可设置该参数。当前UPCF只支持Gx和Rx两种信令接口配置该参数。                                                                            |
| LIP       | 本端IPV4地址    | PCRF与对端PCEF产品对接的参数之一，用于指定链路使用的本端IPv4地址。需要PCRF与对端PCEF协商一致；若不一致，可能会导致两者之间的链路无法正常建立。该参数必须已经通过ADD DLBDEVADDR命令添加。 取值范围：IPv4地址 默认值：无。  说明： 当“IP版本”选择“IPV4”时，可设置该参数。当“双归属开关”为“ON(打开)”，且“双归属地址IP版本”选择“IPV4”时，本参数作为PCRF侧diameter链路端点的主IP地址，与“PIP”组成主路径。                             |
| LIPV6     | 本端IPV6地址    | PCRF与对端PCEF产品对接的参数之一，用于指定链路使用的本端IPv6地址。需要PCRF与对端PCEF协商一致；若不一致，可能会导致两者之间的链路无法正常建立。该参数必须已经通过ADD DLBDEVADDR命令添加。 取值范围：IPv6地址 默认值：无。  说明： 当“IP版本”选择“IPV6”时，可设置该参数。当前UPCF只支持Gx和Rx两种信令接口配置该参数。当“双归属开关”为“ON(打开)”，且“双归属地址IP版本”选择“IPV6”时，本参数作为PCRF侧diameter链路端点的主IP地址，与“PIPV6”组成主路径。 |

| RPCRFID   | 容灾PCRF标识    | 用于指定一个容灾PCRF实体，该参数必须先由ADD RPCRF命令定义，然后才能在此处索引。 取值范围：0～255 默认值：255  说明： 该参数只在会话备份功能打开且有Rx接口时才需要配置，其他场景不需要配置。如果该参数为255则主备PCRF之间不转发Rx消息。                                                                                                                                       |

## 使用实例

1. 修改一条PCRF实体和对端PCEF实体链路的链路管理状态为去使能。“PCRF标识”为“1”，“对端PCEF标识”为“0”，“对端链路标识”为“0”，“链路管理状态”改为“去使能”。

   ```
   MOD PPCEFL: PCRFID=1, PCEFID=0,LNKID=0, ADSTS=DISABLE;
   ```
2. 修改一条PCRF实体和对端PCEF实体链路的IP地址、对端端口和链路管理状态。“PCRF标识”为“1”，“对端PCEF标识”为“0”，“对端链路标识”为“0”，“传输协议类型”为“TCP”，“IP版本”为“IPV4”，“对端IPV4地址”改为“192.168.131.11”，“对端端口”改为“1199”，“链路管理状态”改为“去使能”。

   ```
   MOD PPCEFL: PCRFID=1, PCEFID=0, LNKID=0, TPTYPE=TCP, IPVER=IPV4, PIP="192.168.131.11", PPT=1199, ADSTS=DISABLE;
   ```
3. 修改一条PCRF实体和对端PCEF实体链路的双归属IP地址。“PCRF标识”为“1”，“对端PCEF标识”为“1”，“对端链路标识”为“1”，“传输协议类型”为“SCTP”，“双归属开关”为“ON”，“双归属地址IP版本”为“IPV4”，“双归属对端IPV4地址”改为“192.168.130.20”，“对端IPV4地址”改为“192.168.131.10”。

   ```
   MOD PPCEFL: PCRFID=1, PCEFID=1, LNKID=1, TPTYPE=SCTP, DUALHOME=ON, DIPVER=IPV4, DPIP="192.168.130.20", PIP="192.168.131.10";
   ```
