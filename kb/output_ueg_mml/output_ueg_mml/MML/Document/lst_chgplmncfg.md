# 查询PLMN计费配置(LST CHGPLMNCFG)

- 本地用户权限

- 输出结果说明

#### 命令功能

**适用网元：SGSN**

该命令用于查询话单生成策略相关配置。

#### 注意事项

如果有输入参数，则显示与输入参数匹配的话单生成策略配置记录；如果没有输入参数，则显示所有话单生成策略配置记录。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                               |
|:---------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：可选参数 参数含义：该参数用于指定所包含的用户范围。 取值范围：“ALL_USER（所有用户）”“CELL_PLMNID（指定CELL_PLMNID）” 默认值：无                                                                                                          |
| MCC      | 移动国家码  | 可选必选说明：条件必选参数 参数含义：该参数用于表示PLMN的移动国家号码。 取值范围：位数为3的十进制数字 默认值：无                                                                                                                                       |
| MNC      | 移动网号   | 可选必选说明：条件必选参数 参数含义：该参数用于表示PLMN的移动网号码。 取值范围：位数为2或3的十进制数字 默认值：无                                                                                                                                      |
| APNNI    | APNNI  | 可选必选说明：可选参数 参数含义：该参数用于指定APN网络标识。 取值范围：1～62位字符串 默认值：无  说明： APN网络标识地址由一个或多个LABEL构成，各LABEL间用“.”间隔。每个LABEL的构成字符只能是字母A～Z或a～z、数字0～9和中划线“-”，字母不区分大小写。APN网络标识地址不能以“rac”、“lac”、“sgsn”或“rnc”开头，不能以“.gprs”结尾。 |

#### 使用实例

查询SUBRANGE="指定CELL\_PLMNID" ,MCC="123", MNC="001"的话单生成策略，配置格式为：

LST CHGPLMNCFG: SUBRANGE=CELL\_PLMNID,MCC="123", MNC="001";
