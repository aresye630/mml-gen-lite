# 查询SBI接口设备间审计参数（LST SBIDEVAUDIT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询SBI接口设备间设置的所有审计信息，包含设备接口类型和审计时长信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询设备间审计信息。

```
LST SBIDEVAUDIT;
```

```
%%LST SBIDEVAUDIT:;%%
RETCODE = 0  操作成功

操作结果如下:
-------------
SBI接口类型     设备间审计时长（m）    对端上报审计时长（m）  连续审计超时次数   周期性审计时长（m）
N28             0                      0                      0                  0
N7              0                      480                    0                  0
Bsf             0                      0                      0                  0
N23             0                      0                      0                  0
(结果个数 = 4)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见SET SBIDEVAUDIT命令的参数说明。
