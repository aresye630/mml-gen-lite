# 增加UE无线能力选择UNC参数(ADD UERCAPUNCSEL)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于配置根据UE无线能力选择UNC的参数，指定用户范围的用户的UE无线能力长度大于指定阈值的用户在**STR OFFLOADBYENODEB**和**STR OFFLOADBYMME**迁移用户的过程中迁移到UNC网元。

#### 注意事项

- 该命令执行后立即生效。
- 最大配置记录数是1024条。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                   |
|:----------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE  | 用户范围     | 可选必选说明：必选参数 参数含义：该参数用于指定待进行网元重选的用户范围。 数据来源：整网规划 取值范围： ALL_USER（所有用户）：表示用户范围为系统内所有用户。HOME_USER（本网用户）：表示用户范围为本网用户。FOREIGN_USER（外网用户）：表示用户范围为外网用户。IMSI_PREFIX（指定IMSI前缀）：表示用户范围通过IMSI前缀指定。SPECIFIC_IMSI（指定IMSI）：表示用户范围通过IMSI指定。 默认值：无 配置原则：UNC重选策略匹配优先级高到低为：“SPECIFIC_IMSI（指定IMSI）”，“IMSI_PREFIX（指定IMSI前缀）”，“FOREIGN_USER(外网用户)”或“HOME_USER(本网用户)”， “ALL_USER(所有用户)”。 系统优先匹配高优先级的配置记录，如果匹配不到，再匹配低优先级的配置记录。 |
| NOID      | 运营商标识    | 可选必选说明：条件必选参数 参数含义：该参数用于指定运营商标识。 前提条件：该参数在“用户范围”参数配置为“HOME_USER(本网用户)”或“FOREIGN_USER(外网用户)”后生效。 数据来源：整网规划 取值范围：0～64，128～254 默认值：无 配置原则：若该参数需要配置为0或128～254之间的值时，须先在ADD MNO中配置取值相同的“MNOID”参数。若该参数需要配置为1～64之间的值时，须先在中配置取值相同的“MVNOID”参数。                                                                                                                                                                   |
| IMSIPRE   | IMSI前缀   | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI前缀以区分不同的用户群。 前提条件：该参数在“用户范围”参数配置为“指定IMSI前缀”后生效。 数据来源：整网规划 取值范围：5~14位十进制数字字符串 默认值：无                                                                                                                                                                                                                                                                                       |
| IMSI      | IMSI     | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI以区分不同的用户群。 前提条件：该参数在“用户范围”参数配置为“指定IMSI”后生效。 数据来源：整网规划 取值范围：15位十进制数字字符串 默认值：无                                                                                                                                                                                                                                                                                             |
| UNCSELSW  | UNC重选开关  | 可选必选说明：必选参数 参数含义：该参数用于指定是否开启UNC重选功能。 数据来源：整网规划 取值范围： OFF：关闭ON：开启 默认值：无                                                                                                                                                                                                                                                                                                                                 |
| UERCLEN   | 长度阈值(KB) | 可选必选说明：条件必选参数 参数含义：该参数用于指定根据UE无线能力重选UNC的UE无线能力长度， UE无线能力长度大于“长度阈值(KB)”的用户可以迁移到UNC。 前提条件：该参数在“UNC重选开关”参数配置为“ON(开启)”后生效。 数据来源：整网规划 取值范围：1~63                                                                                                                                                                                                                                                             |
| TMMEGPIDX | 目标MME组索引 | 可选必选说明：条件必选参数 参数含义：该参数用于指定根据UE无线能力进行UNC选择时的目标MME群组的标识。 前提条件：该参数在“UNC重选开关”参数配置为“ON(开启)”后生效。 数据来源：整网规划 取值范围：0~63的整数类型。 默认值：无 配置原则：该参数必须已经在ADD MMEGP配置。                                                                                                                                                                                                                                                   |

#### 使用实例

增加一条“用户范围”为“所有用户”，“UNC重选开关”为“ON（开启）”，“长度阈值(KB)”为“3”，“目标MME组索引”为“0”的记录；

```
ADD UERCAPUNCSEL: SUBRANGE=ALL_USER, UNCSELSW=ON, UERCLEN=3, TMMEGPIDX=0;
```
