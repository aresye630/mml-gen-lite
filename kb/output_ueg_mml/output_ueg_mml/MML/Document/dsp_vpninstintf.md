# 查询VPN实例接口信息（DSP VPNINSTINTF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询VPN实例接口信息。

#### 注意事项

- 该命令执行后立即生效。
- 此命令最多查询1000个VPN实例，且每个VPN实例最多显示5个接口名，超出则显示“……”。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                             |
|:--------|:--------|:-------------------------------------------------------------------------------------------------|
| VRFNAME | VPN实例名称 | 可选必选说明：可选参数 参数含义：VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：使用LST L3VPNINST命令查看可用VPN。 |

#### 使用实例

查询VPN实例接口信息：

```
DSP VPNINSTINTF: VRFNAME="__mpp_vpn_inner__";
```

```
RETCODE = 0 操作成功。

结果如下
------------------------
VPN实例接口信息 =
VPN-Instance Name : __mpp_vpn_inner__
VPN-Instance ID : 1
Interface Number : 1
Interface list : GigabitEthernet0/0/1

(结果个数 = 1)
--- END
```

#### 输出结果说明

| 输出项名称     | 输出项解释      |
|:----------|:-----------|
| VPN实例接口信息 | VPN实例接口信息。 |
