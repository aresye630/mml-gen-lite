# 查询网元服务信息(LST UDMNFSERVICE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询网元服务信息。

- 若需要查询所有网元服务的信息，请不输入任何参数。
- 若需要查询某个网元服务的信息，请输入“组名称”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                          |
|:--------------|:-------|:------------------------------------------------------------------------------------------------------------------------------|
| GRPNAME       | 组名称    | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个组名称来查询网元服务信息；若不输入，则表示查询所有的组服务的网元服务信息。 取值范围：长度不超过32位的字符串，字符串由数字、字母、“-”或“_”组成。 默认值：无。 配置原则：无。      |
| SERVICEID     | 服务标识   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个服务标识来查询网元服务信息；若不输入，则表示查询所有服务标识的网元服务信息。 取值范围：长度不超过36位的字符串，字符串由数字、字母、“-”或“_”组成。 默认值：无。 配置原则：无。     |
| SERVICEINSTID | 服务实例标识 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个服务实例标识来查询网元服务信息；若不输入，则表示查询所有服务实例标识的网元服务信息。 取值范围：长度不超过36位的字符串，字符串由数字、字母、“-”或“_”组成。 默认值：无。 配置原则：无。 |

   ```
   LST UDMNFSERVICE:;
   ```

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD UDMNFSERVICE**命令的参数说明。
