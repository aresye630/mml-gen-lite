# 删除上传日志文件配置（RMV ULDLOGFILECFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于删除一条上传日志文件的配置信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| LINKID | 链路ID   | 可选必选说明：必选参数。 参数含义：标识一条上传日志文件配置信息的关键字段之一，用于指定需要删除哪一条上传日志文件配置信息的链路ID，操作员可以使用LST ULDLOGFILECFG命令查询获得。 取值范围：0~15。 默认值：无。 配置原则：无。                        |
| TYPE   | 日志类型   | 可选必选说明：必选参数。 参数含义：标识一条上传日志文件配置信息的关键字段之一，用于指定需要删除哪一条上传日志文件配置信息的日志类型，操作员可以使用LST ULDLOGFILECFG命令查询获得。 取值说明： PMSOPTLOG(PMS操作日志)：PMS操作日志。 默认值：无。 配置原则：无。 |

## 使用实例

删除一条上传日志文件配置。“链路ID”为“1”，“日志类型”为“PMSOPTLOG(PMS操作日志)”。

```
RMV ULDLOGFILECFG: LINKID=1, TYPE=PMSOPTLOG;
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释         | 原因分析               | 处理建议                                             |
|------:|:--------------|:-------------------|:-------------------------------------------------|
|   505 | 当前操作的配置数据不存在。 | 输入的“链路ID”对应的记录不存在。 | 重新输入“链路ID”，确保其对应的记录已存在。可通过LST ULDLOGFILECFG命令查询。 |
