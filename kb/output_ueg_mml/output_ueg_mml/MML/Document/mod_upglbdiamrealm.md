# 修改全局Diameter域（MOD UPGLBDIAMREALM）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

**须知** 

本命令属于高危命令，该操作会修改系统缺省的Diameter域，可能会影响DRA选择。

该命令用于修改系统缺省的Diameter域。

#### 注意事项

该命令执行后只对新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称               | 参数说明                                                                                                                                                                                                                                                                            |
|:--------------|:-------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APPLICATION   | Diameter应用         | 可选必选说明：必选参数 参数含义：该参数用于指定全局Diameter域所属的Diameter应用。 数据来源：全网规划 取值范围：枚举类型。 SWM：SWM接口应用。 默认值：无 配置原则：根据实际应用场景选择对应的枚举值。                                                                                                                                                                |
| CONSTBYIMSISW | 根据IMSI构造归属地Realm开关 | 可选必选说明：必选参数 参数含义：该参数用于指定是否使能根据IMSI构造Peer的归属地Diameter域名。 数据来源：全网规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：当选择ENABLE时，将通过IMSI构造Diameter域，构造格式为“epc.mnc<MNC>.mcc<MCC>.3gppnetwork.org”。                                                                                      |
| REALM         | Diameter域名         | 可选必选说明：条件必选参数 前提条件：该参数在“CONSTBYIMSISW”配置为“DISABLE”时为必选参数。 参数含义：该参数用于指定与号段绑定的Diameter域名或者缺省的Diameter域名。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～127。不支持空格，必须是可见ASCII码，由软参BIT2670控制是否区分大小写。 默认值：无 配置原则： 当根据IMSI构造归属地Realm开关设置为ENABLE时，该参数无效。当根据IMSI构造归属地Realm开关设置为DISABLE时，必须手动指定Diameter域。 |

#### 使用实例

如果需要修改全局缺省的Diameter域aaa.huawei.com到dra.huawei.com，可以按以下方式配置：

```
MOD UPGLBDIAMREALM:APPLICATION=SWM,CONSTBYIMSISW=DISABLE,REALM="dra.huawei.com";
```
