# 查询HTTP接口配置(LST HTTPCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询HTTP接口配置参数。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                              |
|:-------|:-------|:------------------------------------------------------------------|
| ID     | ID     | 可选必选说明：可选参数 参数含义：用于指定系统按照记录标识查询HTTP接口配置参数。 取值范围：1。 默认值：无。 配置原则：无。 |

## 使用实例

执行**LST HTTPCFG**命令，查询HTTP接口配置参数。

```
LST HTTPCFG:;
```

```
%%LST HTTPCFG:;%%

RETCODE = 0  操作成功  
操作结果如下
------------------------     
                              ID  =  1 
           HTTP2空闲拆链超时时间  =  1024 
           HTTP请求参数校验开关   =  0
信令消息重复键和NRF消息校验开关   =  0

(结果个数 = 1)
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET HTTPCFG**命令的参数说明。
