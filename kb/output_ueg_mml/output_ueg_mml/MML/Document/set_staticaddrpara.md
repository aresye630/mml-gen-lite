# 设置静态地址参数（SET STATICADDRPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于设置使用静态地址用户的扫描任务参数，配置静态地址用户的去激活扫描任务，去激活选择了非绑定UPF的用户。

## 注意事项

- 该命令执行后立即生效。

- 扫描开始和结束时间为UTC时间，并且持续时间必须大于10分钟。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| SCANSWT   | SCANSTARTTIME   | SCANENDTIME   |
|:----------|:----------------|:--------------|
| DISABLE   | 00:00           | 00:00         |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                        |
|:--------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SCANSWT       | 扫描任务开关 | 可选必选说明：可选参数  参数含义：该参数用于指定静态用户扫描任务的开关。  数据来源：本端规划 取值范围： DISABLE（去使能）ENABLE（使能）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST STATICADDRPARA查询当前参数配置值。  配置原则：无     |
| SCANSTARTTIME | 扫描开始时间 | 可选必选说明：该参数在"SCANSWT"配置为"ENABLE"时为条件必选参数。  参数含义：该参数用于指定静态地址用户扫描开始UTC时间。  数据来源：本端规划  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST STATICADDRPARA查询当前参数配置值。  配置原则：无 |
| SCANENDTIME   | 扫描结束时间 | 可选必选说明：该参数在"SCANSWT"配置为"ENABLE"时为条件必选参数。  参数含义：该参数用于指定静态地址用户扫描结束UTC时间。  数据来源：本端规划  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST STATICADDRPARA查询当前参数配置值。  配置原则：无 |

## 使用实例

配置静态地址参数，扫描开关关闭：

```
SET STATICADDRPARA: SCANSWT=DISABLE;
```
