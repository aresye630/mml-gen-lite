# 删除SSO链路(RMV SSOLINK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令属于高危命令，删除SSO链路会造成UPCF WebUI的SSO功能不可用。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除SSO链路的配置信息。

## 注意事项

删除SSO链路会造成UPCF WebUI的SSO功能不可用，因此必须在华为技术支持工程师指导下使用，严禁私自执行。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                               |
|:-------|:-------|:---------------------------------------------------------------------------------------------------|
| LINKID | 链路ID   | 可选必选说明：必选参数 参数含义：标识一条SSO链路的关键字段，用于指定需要删除的SSO链路数据记录，操作员可以使用LST SSOLINK命令查询获得。 取值范围：1 默认值：无。 配置原则：无。 |

## 使用实例

删除SSO链路的配置信息。“链路ID”为“1”。

```
RMV SSOLINK: LINKID=1;
```
