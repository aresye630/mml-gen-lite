## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致业务中断，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于在配置数据库中修改一条TDF对端路由记录。

## 注意事项

增加、删除和修改TDF对端路由记录，对在线Sd会话不生效。

## 参数说明

| 参数标识      | 参数名称   | 参数描述                                                                                                                                                                                                                  |
|:----------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ROUTEID   | 路由ID   | 用于在UPCF的配置库中定义一条TDF路由数据。该参数的配置原则：如果配置多个TDF对端路由，从0开始顺序配置。 取值范围：0～511 默认值：无。                                                                                                                                            |
| ROUTETYPE | 路由类型   | 用于在UPCF的配置库中定义一个路由数据的类型。 取值说明： PcefHostName(PCEF主机名)PcefRealmName(PCEF域名) 默认值：无。  说明： UPCF和TDF直连场景，该参数只能配置为“PcefHostName(PCEF主机名)”。UPCF和TDF准直连场景，该参数只能配置为“PcefRealmName(PCEF域名)”。                                     |
| ROUTEKEY  | 路由键    | 用于具体描述一个TDF路由键。其值域类型为字符串，该参数在配置时不区分大小写，在查询时区分大小写。当“路由类型”参数选择“PcefHostName(PCEF主机名)”时，此参数为PCEF对端主机名。当“路由类型”参数选择“PcefRealmName(PCEF域名)”时，此参数为PCEF对端域名。 取值范围：长度不超过127的字符串 默认值：无。  说明： 此处PCEF主机名和PCEF域名特指GGSN或UGW的主机名和域名。 |
| PEERID    | 对端标识   | 用于具体描述一个TDF路由键映射的TDF对端ID。该参数必须先由ADD PEER命令定义，并且对端类型为TDF，然后才能在此处索引。 取值范围：0～127 默认值：无。                                                                                                                                  |
| TDFRN     | TDF域名  | 用于指定一个TDF的域名，当“ROUTETYPE”取值为“PcefRealmName(PCEF域名)”时，该参数有效。 取值范围：长度不超过64的字符串 默认值：无。                                                                                                                                   |

## 使用实例

1. 修改TDF对端路由记录。TDF的“路由ID”为“1”，“路由类型”为“PcefHostName(PCEF主机名)”，“路由键”改为“PCEF02”。

   ```
   MOD TDFROUTE: ROUTEID=1, ROUTETYPE=PcefHostName, ROUTEKEY="PCEF02";
   ```
2. 修改TDF对端路由记录。TDF的“路由ID”为“1”，“路由类型”为“PcefHostName(PCEF主机名)”，“对端标识”改为“2”。

   ```
   MOD TDFROUTE: ROUTEID=1, ROUTETYPE=PcefHostName, PEERID=2;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释     | 原因分析                               | 处理建议                                                                                         |
|------:|:----------|:-----------------------------------|:---------------------------------------------------------------------------------------------|
| 57804 | 已存在相同的记录。 | 已经存在一条“路由类型”和“路由键”都相同的TDF对端路由配置记录。 | 执行LST TDFROUTE命令查询所有的配置信息。重新执行本命令配置路由信息，并保证只存在一条“路由类型”和“路由键”都相同的TDF对端路由配置记录。                 |
| 57257 | Peer不存在。  | 输入的“对端标识”不存在。                      | 执行LST PEER命令查询所有的对端配置信息。若需要配置的对端不存在，则可执行ADD PEER命令添加对端配置信息。重新执行本命令配置TDF路由信息，并保证输入的“对端标识”已存在。 |
