# 清除LCS TRP信息（CLR LCSTRPINFO）

- 命令功能
- 注意事项
- 操作用户权限

#### 命令功能

**适用NF：UPF**

**须知** 

本命令属于高危命令，此操作会清除获取的TRP信息，请确认是否继续？

该命令用于清除获取的TRP信息。

#### 注意事项

- 该命令执行后立即生效。
- 不输入gNodeB会清除所有TRP信息。
- 不输入TRPCLRPLY参数时，默认清除LMF本地内存的TRP信息。
- 当输入TRPCLRPLY参数为LOCAL\_AND\_COMPONENT时，会清除LMF本地内存和算法组件的TRP信息，该操作会影响后续定位流程，建议对后续不再使用定位功能的基站使用该参数来释放TRP资源。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                 |
|:----------|:--------|:---------------------------------------------------------------------------------------------------------------------|
| GNODEBID  | 基站ID    | 可选必选说明：可选参数 参数含义：该参数用于指定基站ID。 数据来源：全网规划 取值范围：整型数字类型，取值范围为0~4294967295。 默认值：无 配置原则：无                                  |
| TRPCLRPLY | TRP清除策略 | 可选必选说明：可选参数 参数含义：该参数用于指定TRP信息的清除策略。 数据来源：全网规划 取值范围： LMF_LOCAL：LMF本地内存。LOCAL_AND_COMPONENT：LMF本地内存和算法组件。 默认值：无 配置原则：无 |

#### 使用实例

清除获取的TRP信息：

```
CLR LCSTRPINFO: GNODEBID=1832160;
```
