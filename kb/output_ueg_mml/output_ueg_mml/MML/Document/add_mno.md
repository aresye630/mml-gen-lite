# 增加MNO配置信息(ADD MNO)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

运营商信息配置不合理将导致用户无法驻留网络，影响用户业务。

**适用网元：SGSN、MME**

此命令用于增加一个MNO的标识。MNO（Mobile Network Operator，移动网络运营商），可以包括一个或多个PLMN。

#### 注意事项

- 此命令执行后立即生效。
- 此命令最大记录数为128。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                      |
|:----------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MNOID     | MNO标识  | 可选必选说明：必选参数 参数含义：该参数用于指定MNO的标识。 数据来源：整网规划 取值范围：0，128~254 默认值：无  说明： 0为系统初始值。由于系统初始化后，已存在一条“MNOID”为0的记录，当“MNOID”参数为0时，执行ADD MNO的效果等同于执行MOD MNO命令。“MNOID”参数必须要与已配置的“MNOID”不同。                                                                                                                                                               |
| FULLNAME  | 运营商全称  | 可选必选说明：可选参数 参数含义：该参数用于指定运营商全称。 数据来源：整网规划 取值范围：0～79位字符串，数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符 默认值：无  说明： GMM information/EMM information消息中携带的“Full name for network”信元值来源于该参数。 因终端实现不同，可能部分终端优先使用SIM/USIM卡自带的网络名称，此时网络侧下发的网络名称会不生效。 运营商全称不能输入“NULL”，字母不区分大小写。 “MNOID”参数为0时，若需恢复该参数为初始配置"NULL"，请使用MOD MNO命令。  |
| SHORTNAME | 运营商简称  | 可选必选说明：可选参数 参数含义：该参数用于指定运营商简称。 数据来源：整网规划 取值范围：0～79位字符串，数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符 默认值：无  说明： GMM information/EMM information消息中携带的“Short name for network”信元值来源于该参数。 因终端实现不同，可能部分终端优先使用SIM/USIM卡自带的网络名称，此时网络侧下发的网络名称会不生效。 运营商简称不能输入“NULL”，字母不区分大小写。 “MNOID”参数为0时，若需恢复该参数为初始配置"NULL"，请使用MOD MNO命令。 |

#### 使用实例

增加一个“MNO标识”为“128”，“运营商全称”为“aaa”，“运营商简称”为“a”的MNO标识：

ADD MNO: MNOID=128, FULLNAME="aaa", SHORTNAME="a";
