# 查询远端用户数据同步服务器（LST RDATASYNSERVER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UDM**

该命令用于显示数据自动同步远端配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                       |
|:-----------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| SERVERNAME | 服务器名称  | 可选必选说明：可选参数 参数含义：远端用户数据同步服务器名称。 数据来源：本端规划 取值范围：由数字、字母和下划线组成的不超过16位的字符串。 默认值：无 配置原则： 该参数使用ADD RDATASYNSERVER命令配置生成。由数字、字母和下划线组成的不超过16位的字符串。 |

#### 使用实例

输出所有远端数据同步配置信息；若想查看指定远端数据同步配置信息，可指定服务器名称，如果输入的服务器名称在系统中不存在，则查询失败。：

```
LST RDATASYNSERVER: SERVERNAME="demo";
```
