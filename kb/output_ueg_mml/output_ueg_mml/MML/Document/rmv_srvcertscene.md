# 删除配置证书场景（RMV SRVCERTSCENE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、PGW-U**

该命令用于删除配置证书场景。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                              |
|:-------|:---------|:----------------------------------------------------------------------------------------------------------------------------------|
| SCENE  | 证书使用场景名称 | 可选必选说明：必选参数 参数含义：该参数用于指定证书使用场景的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围是1~127。区分大小写，不允许仅大小写不同的重复记录。不支持中文字符，只能由“_”、数字和大小写字母组成。 默认值：无 配置原则：无 |

#### 使用实例

删除配置证书场景：

```
RMV SRVCERTSCENE: SCENE="test01";
```
