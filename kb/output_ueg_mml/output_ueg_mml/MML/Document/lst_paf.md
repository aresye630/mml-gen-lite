# 查询PCRF对端AF实体配置信息(LST PAF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于在配置数据库中查询对端AF实体的配置信息。如果需要查询全部对端AF实体的配置信息，请不要输入任何参数；如果需要查询某个对端AF实体的配置信息，请依据参数说明输入查询条件。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称       | 参数说明                                                                                                                                                                                                       |
|:--------------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PCRFID        | PCRF标识     | 用于指定一个本端PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围： 1 默认值： 无。                                                                                                                                              |
| AFID          | 对端AF标识     | 用于在UPCF的配置库中定义一个对端AF实体。该参数的配置原则：如果配置多个对端AF实体，从0开始顺序配置。 取值范围： 0～15 默认值： 无。                                                                                                                                  |
| PN            | 对端名称       | 用于具体描述一个对端AF的名称，以便于识别。其值域类型为字符串，区分大小写。 取值范围： 长度不超过128的字符串 默认值： 无。                                                                                                                                          |
| DN            | 对端域名       | PCRF与对端AF产品对接的参数之一，用于指定对端AF域名，需要与对端AF协商一致；若不一致，可能会导致两者之间的连接无法正常建立。该参数在配置时不区分大小写，在查询时区分大小写。 取值范围： 长度不超过64的字符串 默认值： 无。                                                                                       |
| HN            | 对端主机名      | PCRF与对端AF产品对接的参数之一（必须全网唯一，由局方统一规划这个数据），用于定义对端AF主机名称，需要PCRF与对端AF协商一致；若不一致，可能会导致两者之间的链路无法正常建立。该参数在配置时不区分大小写，在查询时区分大小写。 取值范围： 长度不超过127的字符串 默认值： 无。                                                            |
| PT            | 协议类型       | PCRF与对端AF产品对接的参数之一，用于定义产品间使用的通信协议，需要PCRF与对端AF协商一致；若不一致，可能会导致两者之间的连接无法正常建立。 取值说明： DIAMETER(Diameter协议) 默认值： 无。                                                                                              |
| LSMODE        | 链路选择模式     | PCRF与对端AF产品对接的参数之一，用于定义链路选择模式，是PCRF往AF发送数据走哪条链路的重要依据。 取值说明： SINGLE_LINK(独立链路)：某次会话的消息只能走一个固定的链路，一旦该链路中断，会话消息就无法发送到对端。LOAD_BALANCE(负载均衡)：循环使用所有到对端的在线链路。 默认值： 无。                                            |
| SBMODE        | 业务绑定模式     | PCRF与对端AF产品对接的参数之一，用于定义业务绑定模式。业务绑定模式主要影响链路状态改变时链路所承载的业务的处理。业务绑定模式有以下两种： 独立模式：连接绑定业务，连接不可用时需要释放业务； 共享模式：对端绑定业务，对端的所有连接都不可用时才释放业务。 该参数需要PCRF与AF协商一致；若不一致，可能会导致两者之间的业务交互异常。 取值说明： SINGLE(独立)SHARE(共享) 默认值： 无。 |
| SKA           | 业务保活时长（s）  | PCRF与对端AF产品对接的参数之一，用于定义业务保活时间，当链路不可用时，在业务保活时间内，业务是不会释放的。需要PCRF与AF协商一致；若不一致，可能会导致两者之间的控制块不一致，业务异常。 单位：秒。 取值范围： 0～3600 默认值： 无。  说明： 若软参“VRM_SESSIONBACKUPSWITCH”取值为非0，则该参数不生效。                               |
| DASWITCH      | 审计开关       | PCRF与对端AF产品对接的参数之一，用于定义设备间的审计开关。 取值说明： OFF(关闭定时审计)ON(打开定时审计) 默认值： 无。                                                                                                                                       |
| DATIME        | 设备间审计时长（m） | PCRF与对端AF产品对接的参数之一，用于定义设备间的审计的时长。 单位：分钟。 取值范围： 720～1440 默认值： 无。                                                                                                                                            |
| ABILITYDICTID | 能力字典ID     | 用于选择AF能力字典。 取值范围：0～127 取值说明：能力字典ID的具体取值由ADD AFABIDICT命令定义。 默认值：无。                                                                                                                                          |

## 使用实例

1. 查询所有的PCRF对端AF实体配置信息。

   ```
   LST PAF:;
   ```

   ```
   %%LST PAF:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
               PCRF标识  =  1
             对端AF标识  =  0
               对端名称  =  af0
               对端域名  =  af0domain
             对端主机名  =  af0host
               协议类型  =  Diameter协议
           链路选择模式  =  负载均衡
           业务绑定模式  =  共享
     业务保活时长 （s）  =  0
               审计开关  =  打开定时审计
   设备间审计时长 （m）  =  720
             能力字典ID  =  64
   (结果个数 = 1)

   ---    END
   ```
2. 查询一条PCRF对端AF实体配置信息。PCRF实体标识为1，对端AF实体标识为0。

   ```
   LST PAF: PCRFID=1, AFID=0;
   ```

   ```
   %%LST PAF: PCRFID=1, AFID=0;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
               PCRF标识  =  1
             对端AF标识  =  0
               对端名称  =  af0
               对端域名  =  af0domain
             对端主机名  =  af0host
               协议类型  =  Diameter协议
           链路选择模式  =  负载均衡
           业务绑定模式  =  共享
     业务保活时长 （s）  =  0
               审计开关  =  打开定时审计
   设备间审计时长 （m）  =  720
             能力字典ID  =  64
   (结果个数 = 1)

   ---    END
   ```
