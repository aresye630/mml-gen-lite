# 修改SOAP对端地址段(MOD SOAPPEADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改系统中的一条SOAP对端IP地址段记录。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                  |
|:---------|:---------|:------------------------------------------------------------------------------------------------------|
| ID       | SOAP对端标识 | 可选必选说明：必选参数 标识SOAP对端地址段的关键字段之一，用于指定需要对哪个ID对应的SOAP对端地址段记录进行修改。 取值范围：1～255 默认值：无。                       |
| ADDRID   | 网段编号     | 可选必选说明：必选参数 标识SOAP对端地址段的关键字段之一，用于指定需要对哪个网段编号对应的SOAP对端地址段记录进行修改。 取值范围：0～7 默认值：无。                       |
| IPVER    | IP版本     | 可选必选说明：必选参数 用于标识修改后的SOAP对端地址段的IP地址类型。 取值范围： IPV4(IPV4) IPV6(IPV6) 默认值：无。                              |
| IPV4     | IPv4地址段  | 可选必选说明：条件必选参数 仅当本命令的“IP版本”参数取值为“IPV4(IPV4)”时，该参数必选。用于标识修改后的SOAP对端IPv4地址段。 取值范围：有效的IPv4地址。 默认值：无。      |
| MASK     | IPv4掩码   | 可选必选说明：条件必选参数 仅当本命令的“IP版本”参数取值为“IPV4(IPV4)”时，该参数必选。用于标识修改后的SOAP对端的IPv4地址的子网掩码。 取值范围：有效的IPv4地址。 默认值：无。 |
| IPV6     | IPv6地址段  | 可选必选说明：条件必选参数 仅当本命令的“IP版本”参数取值为“IPV6(IPV6)”时，该参数必选。用于标识修改后的SOAP对端IPv6地址段。 取值范围：有效的IPv6地址。 默认值：无。      |
| PRELENV6 | IPv6前缀长度 | 可选必选说明：条件必选参数 仅当本命令的“IP版本”参数取值为“IPV6(IPV6)”时，该参数必选。用于标识修改后的SOAP对端IPv6前缀长度。 取值范围：0～128 默认值：无。          |

## 使用实例

修改“SOAP对端标识”为“1”、“网段编号”为“2”的SOAP对端IP地址段记录“IP版本”为“IPV4(IPV4)”、“IPv4地址段”为“10.5.40.10”、“IPv4掩码”为“255.255.255.0”：

```
MOD SOAPPEADDR: ID=1, ADDRID=2, IPVER=IPV4, IPV4="10.5.40.10", MASK="255.255.255.0";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                 | 原因分析                                                           | 处理建议                                                                                     |
|-------:|:--------------------------------------|:---------------------------------------------------------------|:-----------------------------------------------------------------------------------------|
| 360263 | IPv4地址段与IPv4掩码(IPv6地址段与IPv6前缀长度)已经存在。 | 输入的参数“IPv4地址段”与“IPv4掩码”的组合或者“IPv6地址段”与“IPv6前缀长度”的组合与系统中已定义的重复。 | 执行LST SOAPPEADDR命令查询，重新输入“IPv4地址段”与“IPv4掩码”的组合或者“IPv6地址段”与“IPv6前缀长度”的组合，确保其取值与查询结果中的不重复。 |
| 360264 | IPv4地址段255.255.255.255是非法值。           | 参数“IPv4地址段”不能取值为“255.255.255.255”。                             | 重新输入“IPv4地址段”参数，确保其取值不为“255.255.255.255”。                                                |
| 360265 | IPv6地址段全F是非法值。                        | 参数“IPv6地址段”不能取值为“FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF”。     | 重新输入“IPv6地址段”参数，确保其取值不为“FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF”。                        |
