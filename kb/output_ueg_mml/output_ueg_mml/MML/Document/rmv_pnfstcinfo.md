# 删除对端网元静态信息（RMV PNFSTCINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除一条对端网元静态信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                              |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------|
| ID     | ID     | 可选必选说明：必选参数 参数含义：用于识别一条对端网元静态信息记录的关键字段，用于指定需要删除哪一条对端网元静态信息记录，可以使用LST PNFSTCINFO命令查询获取。 取值范围：0~2000 默认值：无。 配置原则：无。 |

## 使用实例

删除一条“ID”为“3”的对端网元静态信息。

```
RMV PNFSTCINFO: ID=3;
```
