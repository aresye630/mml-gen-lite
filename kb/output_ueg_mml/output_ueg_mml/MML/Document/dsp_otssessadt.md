# 查询冗余会话备份数据审计任务状态(DSP OTSSESSADT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询冗余会话备份数据审计任务状态。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询冗余会话备份数据审计任务状态，执行命令如下：

```
DSP OTSSESSADT:;
```

## 输出结果说明

| 参数名称     | 参数说明                                                                                                     |
|:---------|:---------------------------------------------------------------------------------------------------------|
| 处理状态     | 用于标识会话审计任务状态： 空闲运行停止结束终止（BE流控） 说明： 当FE-BE协同流控开启时，该命令状态为“终止（BE流控）”，表示结束正在执行的冗余会话备份数据审计任务，没有发起审计任务的不再进行审计。 |
| 处理启动时间   | 冗余会话备份数据审计开始的时间。                                                                                         |
| 处理结束时间   | 冗余会话备份数据审计结束的时间。                                                                                         |
| 会话类型     | 用于查询会话的类型。 取值范围： GxRx/N5Sy/N28N7N15 AMN15 UEUser InfoUser IDIpAddr                                       |
| 完成审计会话个数 | 用于统计完成会话审计的个数。                                                                                           |
| 释放会话个数   | 用于统计完成会话审计任务结束后释放的会话个数。                                                                                  |
