# 查询EDR导出日志任务状态(DSP EDRLOG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询EDR日志导出任务执行记录。

## 注意事项

UCF只保存最近一次执行记录，所以只能查询最近的一次EDR日志导出任务执行情况。

## 参数说明

无。

## 使用实例

查询EDR导出日志任务状态，执行命令如下：

```
DSP EDRLOG:;
```

```
%%DSP EDRLOG:;%%
RETCODE = 0  操作成功
结果如下
------------------------
        任务ID  =  1250884749
      任务内容  =  ^[0-9]+,[0-9:\-\s]{19},41236542001
      开始时间  =  2022-07-26 15:24:20
      结束时间  =  2022-07-29 15:24:20
(结果个数 = 1)
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1。

| 输出项名称   | 输出项解释                                   |
|:--------|:----------------------------------------|
| 任务ID    | 用于表示任务ID的唯一标识                           |
| 任务内容    | 用于表示最近一次执行EXP EDRLOG命令输入的“用户标识”或“正则表达式” |
| 开始时间    | 用于表示最近一次执行EXP EDRLOG命令输入的“开始时间”         |
| 结束时间    | 用于表示最近一次执行EXP EDRLOG命令输入的“结束时间”         |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释         | 原因分析                              | 处理建议                              |
|------:|:--------------|:----------------------------------|:----------------------------------|
| 58181 | 当前任务还在运行中，请等待 | 执行EXP EDRLOG后，EDR导出任务未完成时，这时执行本命令 | 请等待导出任务完成，重新执行。                   |
| 58156 | 未查询到相关导出任务    | UCF没有执行的EDR日志导出记录                 | 执行EXP EDRLOG命令启动日志导出任务，然后重新执行本命令。 |
| 58157 | 命令处理超时        | UCF在15s内不返回任务消息                   | 请等待几分钟后，重新执行。                     |
