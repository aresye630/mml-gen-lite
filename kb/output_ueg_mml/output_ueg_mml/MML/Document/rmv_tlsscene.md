# 删除TLS证书场景（RMV TLSSCENE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

当需要更换或删除TLS证书场景时，使用该命令删除TLS证书场景配置。

## 注意事项

- 该命令执行后立即生效。

- 删除TLS证书场景前，需要先删除对应的TLSPARA。
- 删除TLS证书场景后，该场景与证书的关联关系也会删除，如果再次添加该场景，则需要重新关联证书。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                               |
|:-------|:-------|:-----------------------------------------------------------------------------------|
| INDEX  | 索引     | 可选必选说明：必选参数  参数含义：该参数用于指定证书场景的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~254。  默认值：无  配置原则：无 |

## 使用实例

若运营商想删除索引为1的TLS证书场景配置，可以用如下命令：

```
RMV TLSSCENE:INDEX=1;
```
