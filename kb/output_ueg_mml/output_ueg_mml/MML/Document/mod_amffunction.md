# 修改AMF功能实例信息（MOD AMFFUNCTION）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于修改AMF功能实例信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称    | 参数说明                                                                                                                                                                                                                                                                         |
|:---------------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INSTANCEID     | NF实例号   | 可选必选说明：必选参数  参数含义：NF实例号。用于AMF与北向网管对接使用，通过NFInstance ID可以实现与北向网管上与网元的话统、告警信息的关联。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~40。  默认值：无  配置原则：  该参数需要根据北向网管的要求来填写，例如，填写为在MANO上创建VNF时的InstanceID。                                                                                          |
| NAME           | NF实例描述  | 可选必选说明：可选参数  参数含义：NF实例名称描述。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~64。  默认值：无  配置原则：  实例名称构成字符只能是字母A～Z或a～z、数字0～9和中划线“-”。                                                                                                                                                            |
| ADMINSTATE     | 管理状态    | 可选必选说明：可选参数  参数含义：AMF管理状态。  数据来源：本端规划 取值范围： Locked（锁定）Unlocked（未锁定）ShuttingDown（关机）  默认值：无  配置原则：无                                                                                                                                                                           |
| OPERATIONSTATE | 运行状态    | 可选必选说明：可选参数  参数含义：AMF运行状态。  数据来源：本端规划 取值范围： Enabled（运行）Disabled（不运行）  默认值：无  配置原则：无                                                                                                                                                                                          |
| FQDN           | FQDN    | 可选必选说明：可选参数  参数含义：AMF Function的FQDN。需要与ADD NFPROFILE中该NF使用的FQDN一致。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~255。  默认值：无  配置原则：  例如，amf1.cluster1.net2.amf.5gc.mnc012.mcc345.3gppnetwork.org。  FQDN由一个或多个LABEL构成，各LABEL间用“.”间隔。  每个LABEL的构成字符只能是字母A～Z或a～z、数字0～9和中划线“-”。                |
| MAXUSER        | 最大注册用户数 | 可选必选说明：可选参数  参数含义：当前软硬件配置条件下（如licence限制），AMF最大能够支持的注册用户数。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：  根据当前系统软硬件配置条件下，例如license中配置的数值进行设置。  通过DSP LICENSERES查询LKV2SASAU01项，若已激活License文件包含该项，会自动将ADD AMFFUNCTION配置中“最大注册用户数”参数取值修改为LKV2SASAU01的5G SA附着用户数的“资源总值”。 |
| RELATIVECAP    | 相对容量    | 可选必选说明：可选参数  参数含义：AMF集合内该AMF的相对容量，代表了NG-RAN选择AMF的概率。取值为整数[0..255]。  数据来源：本端规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：  与ADD AMFINFO中CAPACITY参数配置的数值保持一致。                                                                                                                        |
| MAXGNBNUM      | 最大支持基站数 | 可选必选说明：可选参数  参数含义：当前软硬件配置条件下（如licence限制），AMF最大可以支持的5G基站数。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无                                                                                                                                                            |

## 使用实例

修改InstanceID为“b7b621d82dfb4a009d492491bd9d72a4”的AMFFUNCTION的最大用户数MAXUSER为800000。

```
MOD AMFFUNCTION: INSTANCEID="b7b621d82dfb4a009d492491bd9d72a4", MAXUSER=800000;
```
