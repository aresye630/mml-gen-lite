# 查询计费星期表（LST WEEKDAY）

#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

该命令用于查询计费属性星期表配置信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                         |
|:----------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GLOBALFLG | 全局配置   | 可选必选说明：可选参数 参数含义：该参数用于指定计费类型。 数据来源：全网规划 取值范围：枚举类型。 GLOBAL：指定计费属性为缺省全局计费属性。CHARGE_CHARACT：指定计费属性为配置的特殊计费属性值。 默认值：无 配置原则： GLOBAL：当GLOBALFLG值为GLOBAL时，表示要配置全局计费星期表。CHARGE_CHARACT：当GLOBALFLG值为CHARGE_CHARACT时，表示要通过计费属性配置计费星期表。 |
| CCVALUE   | 计费属性值  | 可选必选说明：条件必选参数 前提条件：该参数在“GLOBALFLG”配置为“CHARGE_CHARACT”时为必选参数。 参数含义：该参数用于指定特殊的CC值。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～6。该参数为十六进制数据类型，仅支持输入0x/X、a-f/A-F 、0-9，允许不输入0x前缀，字母不区分大小写，取值范围0x0000~0xFFFF。 默认值：无 配置原则：无                      |

#### 使用实例

查询计费属性值为1的用户的星期表配置信息：

```
LST WEEKDAY: GLOBALFLG=CHARGE_CHARACT, CCVALUE="0x4020";
```
