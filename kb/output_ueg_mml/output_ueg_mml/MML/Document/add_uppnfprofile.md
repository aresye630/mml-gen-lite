# 增加对端NF实例概述信息（ADD UPPNFPROFILE）

- 命令功能

- 操作用户权限

- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于增加本地配置的对端NF实例的概述信息。该命令用于在网络中没有部署NRF，或对端NF没有注册到NRF，或网络中存在NRF但需基于运营商策略本地配置周边NF的场景下，配置对端NF实例相关信息。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为512。
- 当NF类型为UPF时，IP地址类型不支持IPV4V6双栈类型，且IPV4或IPV6地址只能添加一个。
- 当规划和配置对端NF的地址时，需要注意与本端NF支持的HTTPLE客户端的IP地址类型要保持一致（通过LST HTTPLE来查看），如不一致会可能导致链路建不起来（比如对端只支持IPV6，本端只支持IPV4）。
- 如果对端NF服务注册在NRF上，则本命令配置中的对端NF信息需要和其注册在NRF上的信息保持一致。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

增加对端LMF实例的概述信息，NF实例标识为LMF\_Instance\_0，NF类型为NfLMF，NF状态为Registered，IP地址类型为IPv4，PORT为80：

```
ADD UPPNFPROFILE: NFINSTANCEID="LMF_Instance_0", NFTYPE=NfLMF, NFSTATUS=Registered, IPADDRESSTYPE=IPTypeV4, IPV4ADDRESS1="0.0.0.0", PORT=80;
```
