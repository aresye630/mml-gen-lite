#### 命令功能

**适用网元：SGSN、MME**

该命令用于设置GB、GB NS接口跟踪、随机用户跟踪和用户跟踪参数。用户跟踪表示跟踪以IMSI（International Mobile Subscriber Identity）或MSISDN（Mobile Station International ISDN Number）为标识的特定用户消息；随机用户跟踪表示基于设置的条件，随机性的选择满足触发条件的任何用户并上报其用户跟踪；接口跟踪表示跟踪接口的消息。

#### 注意事项

- 系统初次运行时，会执行系统初始设置值。
- 执行该命令后，需要删除原来已经创建的用户跟踪和GB、GB NS接口跟踪，然后重新创建对应的跟踪，修改才能生效。
- 设置GB、GB NS接口跟踪为不允许时，将无法创建对应的接口跟踪。
- 设置随机用户跟踪为不允许时，将无法创建随机用户跟踪。
- 设置用户跟踪消息类型或方向为不允许时，用户跟踪任务仍然能够创建，但是不能跟踪到相应消息类型或方向的用户跟踪消息。

#### 本地用户权限

manage-ug

#### 网管用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识    | 参数名称          | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                            |
|:--------|:--------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TRCTP   | 跟踪类型          | 可选必选说明：必选参数 参数含义：该参数用来确定需要设置的跟踪类型。 数据来源：本端规划。 取值范围：“INTERFACE(接口跟踪任务)”“USER(用户跟踪任务)”“RANDOM_USER(随机用户跟踪任务)” 系统初始设置值：无                                                                                                                                                                                                                                                                                                           |
| GBFLG   | 是否允许GB接口跟踪    | 可选必选说明：条件可选参数 参数含义：该参数用来指定是否允许创建GB接口跟踪。GB接口跟踪用于查看指定NSE（Network Service Entity）号码或小区号码的GB接口的SIG（信令）管理消息或DATA（数据）消息。 前提条件：该参数在“跟踪类型”设置为“INTERFACE(接口跟踪任务)”时有效。 数据来源：本端规划。 取值范围：“YES(是)”“NO(否)” 系统初始设置值：无                                                                                                                                                                                                                          |
| GBNSFLG | 是否允许GB NS接口跟踪 | 可选必选说明：条件可选参数 参数含义：该参数用来确定是否允许创建GB NS接口跟踪。此跟踪用于查看GB接口NS层信令消息。 前提条件：该参数在“跟踪类型”设置为“INTERFACE(接口跟踪任务)”时有效。 数据来源：本端规划。 取值范围：“YES(是)”“NO(否)” 系统初始设置值：无                                                                                                                                                                                                                                                                               |
| MSGT    | 允许的用户跟踪消息类型   | 可选必选说明：条件可选参数 参数含义：该参数用来确定允许那些消息类型。 前提条件：该参数在“跟踪类型”设置为“USER(用户跟踪任务)”时有效。 数据来源：本端规划。 取值范围：“DIAMETER(DIAMETER消息)”“S1AP(S1AP消息)”“SS(Iu/Gb接口SS消息)”“MM(S1/Iu/Gb/Gn/Gp接口MM消息)”“SM(S1/Iu/Gb/Gn/Gp接口SM消息)”“SMS(Iu/Gb接口SMS消息)”“BSSAP+(Gs/Gd/Gr接口BSSAP+消息)”“MAP(Gs/Gd/Gr接口MAP消息)”“CAP(Ge接口CAP消息)”“LCS(LCS消息)”“RANAP(Iu接口RANAP消息)”“SCCP(Iu接口SCCP消息)”“LLC(Gb接口LLC消息)”“PTP(Gb接口PTP消息)”“SNDCP(Gb接口SNDCP消息)”“GTPU(Gn/Gp接口GTPU消息)” 系统初始设置值：全部选中 |

| MSGLEN  | GTPU消息长度      | 可选必选说明：条件可选参数 参数含义：用户跟踪GTPU数据净荷部分的长度由默认上报长度和可配置长度两部分组成。本参数用来约束可配置长度部分，单位为字节。默认上报长度根据净荷部分的数据协议类型，区分TCPIP报文和非TCPIP报文。TCPIP报文默认上报TCP和IP头长度。非TCPIP报文默认上报40字节。 前提条件：该参数在“跟踪类型”设置为“USER(用户跟踪任务)”时有效。 数据来源：本端规划。 取值范围： 0~300 系统初始设置值：0                                                                                                                                                                                                 |
| CTRLFLG | 是否允许随机用户跟踪    | 可选必选说明：条件可选参数 参数含义：该参数用来确定是否允许创建随机用户跟踪。此跟踪基于设置的条件，随机性的选择满足触发条件的任何用户并上报其用户跟踪。 前提条件：该参数在“跟踪类型”设置为“RANDOM_USER(随机用户跟踪任务)”时有效。 数据来源：本端规划。 取值范围：“YES(是)”“NO(否)” 系统初始设置值：“YES(是)”                                                                                                                                                                                                                                                     |

#### 使用实例

1. 设置跟踪参数，跟踪类型为INTERFACE(接口跟踪任务)，不允许创建GB接口跟踪：

   SET TRC\_CFG: TRCTP=INTERFACE, GBFLG=NO;
2. 设置跟踪参数，跟踪类型为USER(用户跟踪任务)，不允许跟踪Iu/Gb接口SS消息、S1/Iu/Gb/Gn/Gp接口MM消息，不允许跟踪GTPU出口消息：

   SET TRC\_CFG: TRCTP=USER, MSGT=SS-0&MM-0, DRCT=OUTPUT-0;
3. 设置跟踪参数，跟踪类型为RANDOM\_USER(随机用户跟踪任务)，不允许创随机用户跟踪：

   SET TRC\_CFG: TRCTP=RANDOM\_USER, CTRLFLG=NO;
