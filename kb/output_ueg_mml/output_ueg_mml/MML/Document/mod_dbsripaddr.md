# 修改远端网元IP地址(MOD DBSRIPADDR)

- 命令功能

- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，该操作可能会导致业务中断。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一个远端网元IP地址进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一个远端网元IP地址：

- “远端Location标识”
- “远端业务IP的索引”

## 注意事项

- 修改远端网元IP地址将影响dbbroker和远端DSG的网络连接，导致业务中断，请慎重执行此命令。
- 执行该命令后需要通过**ACT DBSIPDISP**命令激活IP链路之后配置才能生效。

## 参数说明

| IPV6IP2 | 远端Location IPV6地址2 | 可选必选说明：条件可选参数 参数含义：用于指定远端网元的Location IP地址。这个地址必须在对接的远端网元中已经配置完毕。 取值范围：IPV6地址。 默认值：无。 配置原则：仅当本命令中的“IP类型”参数取值为“IPV6(IPV6)”时该参数有效。 |

## 使用实例

在维护场景下，修改远端网元IP地址，“远端Location标识”为“3”，“远端业务IP的索引”为“1”，“IP类型”为“IPV4”，“远端Location IPV4地址1”为“192.168.128.12”，“远端Location IPV4地址2”为“192.168.128.13”：

```
MOD DBSRIPADDR: RLOCID=3, ID=1, IPVER=IPV4, IPV4IP1="192.168.128.12", IPV4IP2="192.168.128.13";
```
