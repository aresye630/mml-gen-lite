# 查询RU磁盘过载配置（LST RUDISKPARTITION）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询不同RU类型的磁盘分区过载阈值。

当RU磁盘分区使用率超过阈值时，会触发磁盘分区使用率超限告警。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                        |
|:----------------|:-------|:----------------------------------------------------------------------------------------------------------------------------|
| RUTYPE          | RU类型   | 可选必选说明：可选参数 参数含义：该参数用于指定RU类型。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：请使用LST RESINSTANCETYPE命令查询存在的资源单元类型。 |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识，但不能填写0，0表示VNFP。 |

#### 使用实例

查询VNODE\_CSLB\_VNFC\_OMU类型磁盘可配置数据：

```
LST RUDISKPARTITION:RUTYPE="VNODE_CSLB_VNFC_OMU",SERVICEINSTANCE="vnfc";
```
