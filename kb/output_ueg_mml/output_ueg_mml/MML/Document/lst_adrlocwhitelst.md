# 查询位置区域地址分配用户白名单（LST ADRLOCWHITELST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询位置区域分配地址用户白名单。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询位置区域分配地址用户白名单：

```
LST ADRLOCWHITELST:;
```

```
RETCODE = 0  操作成功。

位置区域地址分配白名单
----------------------
MSISDN  =  123456
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见ADD ADRLOCWHITELST的参数说明。
