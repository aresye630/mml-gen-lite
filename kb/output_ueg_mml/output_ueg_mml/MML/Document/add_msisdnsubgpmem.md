# 增加MSISDN用户群成员(ADD MSISDNSUBGPMEM)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

此命令用于增加MSISDN用户群成员记录。

#### 注意事项

- 此命令执行后立即生效。
- 此命令最大记录数为20000。
- 此命令配置的“用户群标识”参数值不能在**ADD SUBGPMEM**配置中使用。
- 此命令配置的“用户群标识”参数值不能在**ADD PEERPLMN**配置中使用。
- 此命令配置的“用户群标识”参数值如果在**ADD S1ACCAREALST**或**MOD S1ACCAREALST**配置中使用，“SPECSUB（拒绝特征用户接入）”只能配置为“NO(否)”，且“ENBIND（指示特征RFSP索引）”只能配置为“NO(不指示)”。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                                                                                                                                    |
|:----------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBID     | 用户群标识    | 可选必选说明：必选参数 参数含义：该参数用于指定用户群标识。 数据来源：本端规划 取值范围：1～100。 默认值：无 配置原则： 配置的参数值必须在ADD SUBGP中已经配置。配置的参数值不能在ADD SUBGPMEM或ADD PEERPLMN配置中使用。如果系统中存在包含了该SUBID，且参数“SPECSUB（拒绝特征用户接入）”不为“NO(否)”，或“ENBIND（指示特征RFSP索引）”不为“NO(不指示)”的ADD S1ACCAREALST记录，则该SUBID不能在本命令中使用。 |
| MSISDNPRE | MSISDN前缀 | 可选必选说明：必选参数 参数含义：该参数用于指定MSISDN前缀。 数据来源：本端规划 取值范围：1～15位十进制数字。 默认值：无                                                                                                                                                                                      |

#### 使用实例

增加一条MSISDN用户群成员记录，用户群标识为30，MSISDN前缀为12345：

ADD MSISDNSUBGPMEM: SUBID=30, MSISDNPRE="12345";
