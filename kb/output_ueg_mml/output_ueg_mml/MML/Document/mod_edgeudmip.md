# 修改园区UDM的IP地址（MOD EDGEUDMIP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UDM**

**须知** 

本命令属于高危命令，此操作会更改边缘UDM的IP地址，可能导致相关业务中断。

该命令用于修改边缘UDM本端IP地址。

#### 注意事项

- 该命令执行后立即生效。
- 如果需要输入该命令的可选参数VPN实例名称（即逻辑接口与VPN绑定），则需要提前配置ADD VPNINFO命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称         | 参数说明                                                                                                                                                                                         |
|:------------|:-------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPNAME      | IP地址名称       | 可选必选说明：必选参数 参数含义：该参数用于配置园区UDM的IP地址名称。 数据来源：全网规划 取值范围：长度不超过31的由数字和字母组成的字符串，只允许输入0～9，a～z，A～Z和下划线。 默认值：无 配置原则：无                                                                                 |
| IPTYPE      | IP地址的类型      | 可选必选说明：必选参数 参数含义：用于标识园区UDM的IP地址的类型。 数据来源：全网规划 取值范围： DSM：用于用户数据同步。 默认值：无 配置原则：无                                                                                                               |
| IPVERSION   | IP地址版本       | 可选必选说明：必选参数 参数含义：该参数用于用户指定IP类型。 数据来源：全网规划 取值范围：枚举类型。 IPV4：IPv4。IPV6：IPv6。IPVER_ALL：IPv4和IPv6。 默认值：无 配置原则：无                                                                                   |
| IPV4ADDRESS | IPv4地址       | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPV4” 或 “IPVER_ALL”时为可选参数。 参数含义：该参数用于配置IPv4地址。 数据来源：全网规划 取值范围：IPv4地址类型。采用点分十进制"X.X.X.X"格式。 默认值：无 配置原则：根据局点的网络规划进行配置，点分十进制格式。除A、B、C类地址合法外，其余都为非法地址。     |
| IPV4MTU     | IPv4 MTU（字节） | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPV4” 或 “IPVER_ALL”时为可选参数。 参数含义：该参数用于指定IPv4报文的最大传输单元。 数据来源：全网规划 取值范围：整数类型，取值范围为328～9600。 默认值：无 配置原则：根据数据包大小进行配置。                                       |
| IPV6ADDRESS | IPv6地址       | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPV6” 或 “IPVER_ALL”时为可选参数。 参数含义：该参数用于配置主IPV6地址。 数据来源：全网规划 取值范围：采用冒号分十六进制X:X:X:X:X:X:X:X格式。 默认值：无 配置原则：根据环境的网络规划进行配置，冒号分十六进制格式。除单播、任播和组播地址合法外，其余都为非法地址。 |
| IPV6MTU     | IPv6 MTU（字节） | 可选必选说明：条件可选参数 前提条件：该参数在“IPVERSION”配置为“IPV6” 或 “IPVER_ALL”时为可选参数。 参数含义：该参数用于指定逻辑接口IPv6报文的最大传输单元。 数据来源：全网规划 取值范围：整数类型，取值范围为1280～9600。 默认值：无 配置原则：根据数据包大小进行配置。                                  |
| VPNINSTANCE | VPN实例名称      | 可选必选说明：可选参数 参数含义：该参数用于IP地址使用的VPN。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，区分大小写。 默认值：无 配置原则： 输入单空格将删除该参数已有配置项。绑定VPN时需要确保该VPN已经配置。                                                             |

#### 使用实例

- 修改UDM地址，UDM名称为udm01，IP地址的类型为DSM，IPv4地址为192.168.1.1，MTU为1500：

  ```
  MOD EDGEUDMIP: IPNAME="udm01", IPTYPE=DSM, IPVERSION=IPV4, IPV4ADDRESS="192.168.1.1", IPV4MTU=1500;
  ```
- 修改UDM地址，UDM名称为udm01，IP地址的类型为DSM，IPv6地址为fc00::1，MTU为1800：

  ```
  MOD EDGEUDMIP: IPNAME="udm01", IPTYPE=DSM, IPVERSION=IPV6, IPV6ADDRESS="fc00:0000:0000:0000:0000:0000:0000:0001", IPV6MTU=1800;
  ```
