# 查询HTTP域名配置（LST HTTPLEHOST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询HTTP域名配置信息数据记录：

- 若需要查询全部HTTP域名配置信息数据记录，请不要输入任何参数。
- 若需要查询某个HTTP域名配置信息数据记录，请输入“本端实体标识”、“类型”或“全量域名”参数的组合。

  **说明** 

  该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                             |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------------|
| LEID   | 本端实体标识 | 用于指定系统需要按照哪个本端HTTP实体标识查询HTTP域名配置信息数据记录。 取值范围：0～255。 默认值：无。 注意：该参数为可选参数。                                                          |
| TYPE   | 类型     | 用于指定系统需要查询的HTTP域名配置信息中的本端实体的类型是BSF还是AP。 取值范围：BSF(BSF)：UIM实现GBA认证功能时，作为BSF功能实体。AP(AP)：UIM实现GBA认证功能时，作为AP功能实体。 默认值：无。 注意：该参数为可选参数。 |
| FQDN   | 全量域名   | 用于指定系统需要按照哪个全量域名查询本端HTTP域名配置信息数据记录。 需要指出的是，该参数不区分大小写，在执行本命令查询出的报文中为全小写形式。 取值范围：长度不超过127的字符串。 默认值：无。 注意：该参数为可选参数。                 |

## 使用实例

1. 查询所有的HTTP域名配置信息数据记录，不携带参数：

   执行命令如下：

   ```
   LST HTTPLEHOST:;
   ```

   返回结果如下：

   ```
   %%LST HTTPLEHOST:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    本端实体标识  类型    全量域名                                    本端实体名

    0             BSF     test                                        HUAWEI    
    1             AP      xcap.mnc000.mcc460.pub.3gppnetwork.org      name      
   (结果个数 = 2)

   ---    END
   ```
2. 查询某个HTTP域名配置信息数据记录，携带以下参数：

   - “本端实体标识”为“1”
   - “类型”为“AP(AP)”

   执行命令如下：

   ```
   LST HTTPLEHOST: LEID=1, TYPE=AP;
   ```

   返回结果如下：

   ```
   %%LST HTTPLEHOST: LEID=1, TYPE=AP;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
   本端实体标识  =  1
           类型  =  AP
       全量域名  =  xcap.mnc000.mcc460.pub.3gppnetwork.org
     本端实体名  =  name
   (结果个数 = 1)

   ---    END
   ```
