# 配置信标UE（ADD BEACONUE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

新增信标UE。

#### 注意事项

该命令最大记录数为1000。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称              | 参数说明                                                                                                                         |
|:------------|:------------------|:-----------------------------------------------------------------------------------------------------------------------------|
| BEACONUEID  | 信标UE标识            | 可选必选说明：必选参数 参数含义：该参数用于设置信标UE标识。 数据来源：本端规划 取值范围：整数类型，取值范围为0～18446744073709551615。 默认值：无 配置原则：无                                |
| MAPID       | 地图标识              | 可选必选说明：必选参数 参数含义：该参数用于设置地图标识。 数据来源：本端规划 取值范围：整数类型，取值范围为-9223372036854775808～9223372036854775807。 默认值：无 配置原则：无                |
| HEIGHT      | 信标UE高度（厘米）        | 可选必选说明：必选参数 参数含义：该参数用于设置信标UE高度，单位：厘米。 数据来源：本端规划 取值范围：整数类型，取值范围为-9223372036854775808～9223372036854775807。 默认值：无 配置原则：无        |
| POSITIONX   | 信标UE安装相对位置X信息（厘米） | 可选必选说明：必选参数 参数含义：该参数用于设置信标UE安装相对位置X信息，单位：厘米。 数据来源：本端规划 取值范围：整数类型，取值范围为-9223372036854775808～9223372036854775807。 默认值：无 配置原则：无 |
| POSITIONY   | 信标UE安装相对位置Y信息（厘米） | 可选必选说明：必选参数 参数含义：该参数用于设置信标UE安装相对位置Y信息，单位：厘米。 数据来源：本端规划 取值范围：整数类型，取值范围为- 2147483647 ~2147483646。 默认值：无 配置原则：无                 |
| DESCRIPTION | 描述信息              | 可选必选说明：可选参数 参数含义：该参数用于设置信标UE配置描述信息。 数据来源：全网规划 取值范围：字符串类型，长度为32位。 默认值：无 配置原则：无                                                |

#### 使用实例

新增信标UE：

```
ADD BEACONUE: BEACONUEID="460025555530002", MAPID="42691", HEIGHT="150", POSITIONX="5175091", POSITIONY="5330746";
```
