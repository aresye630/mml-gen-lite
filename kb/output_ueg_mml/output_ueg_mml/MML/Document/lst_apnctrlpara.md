#### 命令功能

**适用网元：SGSN**

该命令用于查询基于APN的信令控制参数。

#### 注意事项

不指定APN组时，输出所有APN组的信令控制参数。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                   |
|:---------|:--------|:-----------------------------------------------------------------------|
| APNGRPID | APNNI组号 | 可选必选说明：可选参数 参数含义：本参数用于指定开启APN信令控制功能的APNNI组号。 数据来源：全网规划 取值范围：0～15 默认值：无 |

#### 使用实例

1. 查询所有记录：

   `LST APNCTRLPARA:;`

   ```
   %%LST APNCTRLPARA:;%%
   RETCODE = 0  操作成功。

   操作结果如下
   --------------
    APNNI组号  附着请求控制门限（次/秒）  PDP上下文请求控制门限（次/秒）

    0          1000                       1000                          
    1          5000                       5000                          
   (结果个数 = 2)

   ---    END
   ```
2. 查询指定的记录：

   `LST APNCTRLPARA: APNGRPID=1;`

   ```
   %%LST APNCTRLPARA: APNGRPID=1;%%
   RETCODE = 0  操作成功。

   操作结果如下
   --------------
                        APNNI组号  =  1
        附着请求控制门限（次/秒）  =  5000
   PDP上下文请求控制门限（次/秒）  =  5000
   (结果个数 = 1)

   ---    END
   ```
