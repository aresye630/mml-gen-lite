# 查询设置的POD实例个数（LST PODINST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令已废弃。

该命令用于查询使用SET PODINST命令设置的POD实例个数。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                    |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------------------|
| PODTYPE | Pod类型  | 可选必选说明：必选参数 参数含义：该参数用于指定需要查询的Pod类型。 取值范围： SRV_R(路由POD总数量)SRV_L(分发POD总数量)SRV_S(业务POD总数量)SRV_LD(LDAP POD总数量) 默认值：无 配置原则：无 |

## 使用实例

1. 查询全部Pod类型的实例设置信息。

   ```
   +++    UPCF/*MEID:129 MENAME:upcf129*/        2022-11-17 09:01:15+0:00
   O&M    #8919
   %%LST PODINST:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------------------
   Pod类型                                           实例设置开关        Pod实例个数
   pcf-srvr1-pod+pcf-srvra-pod/pcf-srvrb-pod          OFF                      0                   
   pcf-srvl1-pod+pcf-srvl2-pod                        OFF                      0                        
   pcf-srvs-pod                                       OFF                      0                        
   pcf-ldap-pod                                       OFF                      0                        
   (结果个数 = 4)
   ---    END
   ```
2. 查询指定“Pod类型”为“SRV\_S”的实例设置信息。

   ```
   +++    UPCF/*MEID:129 MENAME:upcf129*/        2022-11-17 09:05:11+0:00
   O&M    #8939
   %%LST PODINST: PODTYPE=SRV_S;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------------------               
           Pod类型  =  pcf-srvs-pod
      实例设置开关  =  OFF
       Pod实例个数  =  0
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见SET PODINST命令的参数说明。
