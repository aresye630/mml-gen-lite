# 增加APN用户模板组绑定关系（ADD APNUSRPROFG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

本命令用于将USRPROFGROUP绑定到APN下。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为10000。
- 每个APN只能绑定一个USRPROFGROUP。
- 要配置此命令，需要首先配置ADD CPAPN和ADD USRPROFGROUP。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                                                                                                                                                             |
|:--------------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN           | APN     | 可选必选说明：必选参数 参数含义：该参数用于指定APN对象名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”特殊字符，不区分大小写。 默认值：无 配置原则： 该参数使用ADD CPAPN命令配置生成。配置的APN必须是系统已经存在的APN对象名称。 |
| USERPROFGNAME | 用户模板组名称 | 可选必选说明：必选参数 参数含义：该参数用于指定用户模板组名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数使用ADD USRPROFGROUP命令配置生成。配置的USERPROFGNAME必须是系统已经存在的UsrProfGroup对象名称。                                                                              |

#### 使用实例

增加ApnUsrProfG配置，APN名称为apn1，USERPROFGNAME为usrprofilegroup1：

```
ADD APNUSRPROFG:APN="apn1",USERPROFGNAME="usrprofilegroup1";
```
