# 查询基于特性的位置上报配置（LST FEATLOCREPORT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF**

该命令用于查询基于特性的位置上报配置。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                        |
|:--------|:-------|:----------------------------------------------------------------------------|
| FEATURE | 特性名称   | 可选必选说明：可选参数  参数含义：该参数用于指定特性名称。  数据来源：本端规划 取值范围： QOSANA（质差分析）  默认值：无  配置原则：无 |

## 使用实例

显示FEATURE为QOSANA的位置上报配置：

```
%%LST FEATLOCREPORT:FEATURE=QOSANA;%%
            RETCODE = 0  操作成功。

            结果如下
            --------
                 特性名称 = QOSANA
  配置NR全球小区的trigger = ENABLE
            (结果个数 = 1)
            ---    END
```

## 输出结果说明

| 输出项名称            | 输出项解释                         |
|:-----------------|:------------------------------|
| 特性名称             | 该参数用于指定特性名称。                  |
| 配置NR全球小区的trigger | 该参数用于指定5G NR全球小区的trigger是否使能。 |
