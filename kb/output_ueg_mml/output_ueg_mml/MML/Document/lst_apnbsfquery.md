# 查询APN的BSF查询功能配置（LST APNBSFQUERY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF、PGW-C**

该命令用于查询指定APN的BSF查询功能配置。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                         |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN    | APN名称  | 可选必选说明：可选参数  参数含义：该参数用于指定APN名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”特殊字符，不区分大小写。  默认值：无  配置原则：  该参数使用ADD CPAPN命令配置生成。 |

## 使用实例

假如用户需要对APN为“huawei.com”的BSF查询功能属性配置，则使用该实例：

```
%%LST APNBSFQUERY: APN="huawei.com";%%
RETCODE = 0  操作成功

结果如下
------------------------
                                       APN名称  =  huawei.com
    BSF支持基于DNN过滤查询会话绑定信息特性开关  =  继承
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称                    | 输出项解释                            |
|:-------------------------|:---------------------------------|
| APN名称                    | 该参数用于指定APN名称。                    |
| BSF支持基于DNN过滤查询会话绑定信息特性开关 | 该参数用于指定BSF支持基于DNN过滤查询会话绑定信息特性开关。 |
