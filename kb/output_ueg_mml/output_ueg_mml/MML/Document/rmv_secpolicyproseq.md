# 删除安全策略匹配顺序（RMV SECPOLICYPROSEQ）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来删除安全策略匹配顺序。

#### 注意事项

- 该命令执行后立即生效。
- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                         |
|:------------|:-------|:-------------------------------------------------------------|
| SECPOLICYID | 安全策略编号 | 可选必选说明：必选参数 参数含义：安全策略号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～30。 默认值：无 |

#### 使用实例

删除安全策略匹配顺序：

```
RMV SECPOLICYPROSEQ:SECPOLICYID=1;
```
