# 查询DNS本端实体（LST NGDNSLE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查看配置的DNS本端实体信息，DNS本端实体包含了DNS本端的IP地址。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                                         |
|:--------|:----------|:-------------------------------------------------------------------------------------------------------------|
| IPTYPE  | IP地址类型    | 可选必选说明：可选参数  参数含义：该参数用于指定DNS本端实体的IP地址类型。  数据来源：全网规划 取值范围： IPV4（IPv4）IPV6（IPv6）  默认值：无  配置原则：无                |
| IPV4    | IPv4地址    | 可选必选说明：该参数在"IPTYPE"配置为"IPV4"时为条件必选参数。  参数含义：该参数用于指定DNS本端实体的IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无 |
| IPV6    | IPv6地址    | 可选必选说明：该参数在"IPTYPE"配置为"IPV6"时为条件必选参数。  参数含义：该参数用于指定DNS本端实体的IPv6地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无 |
| VPNNAME | VPN名称     | 可选必选说明：可选参数  参数含义：该参数用于指定DNS本端实体到DNS服务器间的链路所用的VPN名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~31。  默认值：无  配置原则：无      |
| LENAME  | DNS本端实体名称 | 可选必选说明：可选参数  参数含义：该参数用于指定DNS本端实体的名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~32。  默认值：无  配置原则：无                      |

## 使用实例

- 查询IP地址类型为IPv4，IP地址为192.168.101.100的DNS本端实体。

  ```
  %%LST NGDNSLE: IPTYPE=IPV4, IPV4="192.168.101.100";%%
  RETCODE = 0  操作成功

  操作结果如下
  ------------
             IP地址类型  =  IPv4
               IPv4地址  =  192.168.101.100
               IPv6地址  =  ::
                VPN名称  =  NULL
        DNS本端实体名称  =  dnsle01
  (结果个数 = 1)

  ---    END
  ```
- 查询所有DNS本端实体。

  ```
  %%LST NGDNSLE:;%%
  RETCODE = 0  操作成功

  操作结果如下
  ------------
  IP地址类型       IPv4地址         IPv6地址   VPN名称  DNS本端实体名称  

  IPv4             192.168.101.100  ::         NULL     dnsle01          
  IPv4             192.168.101.111  ::         NULL     dnsle02          
  (结果个数 = 2)

  ---    END
  ```
