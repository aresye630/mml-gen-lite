# 修改PCRF容灾PCRF实体信息(MOD RPCRF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令为配置命令，用于修改或调整配置数据库中的一条容灾PCRF实体的数据记录。

开局场景下，当容灾PCRF实体的配置信息在添加的时候由于误操作导致错误，或者系统运行过程中容灾PCRF的配置信息发生变更时，可以通过该命令进行修改。

在该命令中，系统通过“本端PCRF标识”参数和“容灾PCRF标识”参数来唯一标识一条容灾PCRF实体数据记录。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称              | 参数说明                                                                                                                                                                                                         |
|:--------|:------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PCRFID  | 本端PCRF标识          | 用于标识PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围：1 默认值：无。                                                                                                                                                      |
| RPCRFID | 容灾PCRF标识          | 标识一条容灾PCRF实体配置信息的关键字段之一（其取值不能被修改），用于指定需要对哪一条容灾PCRF实体的配置信息进行修改或调整，操作员可以使用LST RPCRF命令查询获得。 取值范围：0～5 默认值：无。                                                                                                     |
| PN      | 对端名称              | 用于标识容灾PCRF实体的名称。其值域类型为字符串，区分大小写。 取值范围：长度不超过128的字符串 默认值：无。                                                                                                                                                    |
| DN      | 对端域名              | 用于标识容灾PCRF实体的域名。 该参数配置原则：该参数需要PCRF与容灾PCRF协商一致。该参数的取值不区分大小写，建议使用小写。若使用大写输入，系统会默认以小写的方式进行处理。 取值范围：长度不超过64的字符串 默认值：无。                                                                                           |
| HN      | 对端主机名             | 用于标识容灾PCRF实体的主机名。 该参数配置原则：该参数全网唯一，由运营商统一规划。该参数需要PCRF与容灾PCRF协商一致。该参数的取值不区分大小写，建议使用小写。若使用大写输入，系统会默认以小写的方式进行处理。 取值范围：长度不超过127的字符串 默认值：无。                                                                        |
| RTYPE   | 容灾类型              | 用于定义容灾组网类型。 各参数选项的含义是： Active_Standby(1+1主备组网)：1个容灾PCRF与一个主用PCRF连接部署。N.Active_1.Standby(N+1主备组网)：一个容灾PCRF与多个主用PCRF连接部署。 默认值：无。                                                                               |
| LSTATUS | 本地PCRF容灾状态        | 用于定义本地PCRF网元的容灾角色。 该参数配置原则：当存在多个RPCRF时，LSTATUS必须相同。 各参数选项的含义是： Active(主用)：表示本地PCRF是主用PCRF。Standby(备用)：表示本地PCRF是容灾PCRF。 默认值：无。                                                                                |
| SKA     | 业务保活时长（s）         | 用于标识PCRF与容灾PCRF实体对接的业务保活时间，当链路不可用时，在业务保活时间内，业务是不会释放的。 单位：秒。 取值范围：0～3600 默认值：无。  说明： 若软参“VRM_SESSIONBACKUPSWITCH”取值为非0，则该参数不生效。                                                                               |
| RLOCID  | 容灾PCRF Location标识 | 表示容灾PCRF的Location ID。 参数配置原则：可选参数，该参数用于PCRF容灾组网场景下，会话备份功能打开（即VRM_SESSIONBACKUPSWITCH软参值为“3”），且用户定时器持久化功能打开（即VRM_SYNTIMER软参值为“1”）时，才需要配置。 取值范围：0～65535 默认值：无。  说明： 当该参数取默认值65535时，系统认为“容灾PCRF Location标识”未定义。 |

## 使用实例

1. 修改PCRF容灾PCRF实体配置信息。“本端PCRF标识”为“1”，“容灾PCRF标识”为“0”，“对端名称”改为“RPCRF2”。

   ```
   MOD RPCRF: PCRFID=1, RPCRFID=0, PN="RPCRF2";
   ```
2. 修改PCRF容灾PCRF实体配置信息。“本端PCRF标识”为“1”，“容灾PCRF标识”为“0”，“对端名称”改为“RPCRF2”，“对端域名”改为“huawei.com”，“对端主机名”改为“rzpcrf.huawei.com”，“容灾类型”改为“Active\_Standby(1+1主备组网)”，“本地PCRF容灾状态”改为“STANDBY(备进程)”，“业务保活时长（SKA）”改为“100”。

   ```
   MOD RPCRF: PCRFID=1, RPCRFID=0, PN="RPCRF2", DN="huawei.com", HN="rzpcrf.huawei.com", RTYPE=Active_Standby, LSTATUS=STANDBY, SKA=100;
   ```
