# 删除PCRF容灾PCRF链路(RMV RPCRFL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令为配置命令，用于在UPCF网元下删除一条连接PCRF实体与容灾PCRF实体的链路。

开局场景下，由于误操作UPCF添加了错误的RPCRF链路，或者在UPCF需要删除当前的RPCRF链路时，可以使用本命令删除PCRF与容灾PCRF之间的链路。

## 注意事项

执行本命令，当PCRF与容灾PCRF的某条链路的“链路管理状态”为“去使能”时，才能成功删除该链路；否则删除失败。通过**MOD RPCRFL**命令可以将“链路管理状态”置为“DISABLE”。

## 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                         |
|:--------|:---------|:---------------------------------------------------------------------------------------------|
| PCRFID  | 本端PCRF标识 | 标识一条RPCRF链路配置信息的关键字段之一（其取值不能被修改），用于指定需要删除哪一个PCRF实体对应的RPCRF链路的配置信息，操作员可以使用LST PCRF命令查询获得。     |
| RPCRFID | 容灾PCRF标识 | 标识一条RPCRF链路配置信息的关键字段之一（其取值不能被修改），用于指定需要删除哪一个容灾PCRF实体对应的RPCRF链路的配置信息，操作员可以使用LST RPCRFL命令查询获得。 |
| LNKID   | 链路标识     | 标识一条RPCRF链路配置信息的关键字段之一（其取值不能被修改），用于指定需要删除哪一个链路标识对应的RPCRF链路的配置信息，操作员可以使用LST RPCRFL命令查询获得。     |

## 使用实例

删除一条PCRF实体和容灾PCRF实体链路。“本端PCRF标识”为“1”，“容灾PCRF标识”为“0”，“链路标识”为“0”。

```
RMV RPCRFL: PCRFID=1, RPCRFID=0, LNKID=0;
```
