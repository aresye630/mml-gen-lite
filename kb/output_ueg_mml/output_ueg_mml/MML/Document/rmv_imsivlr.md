# 删除IMSI与VLR对应关系(RMV IMSIVLR)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于删除IMSI对应的MSC/VLR。

#### 注意事项

该命令执行后，用户通过SGs接口选择MSC/VLR时生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                              |
|:-------|:-------|:------------------------------------------------------------------|
| IMSI   | IMSI   | 可选必选说明：必选参数 参数含义：该参数用于指定用户的IMSI。 数据来源：全网规划 取值范围：14~15位十进制数字 默认值：无 |

#### 使用实例

删除指定IMSI"123030000000001"的IMSI与MSC/VLR对应关系记录：

RMV IMSIVLR: IMSI="123030000000001";
