#### 命令功能

**适用NF：MME**

该命令用于查看宽带集群系统的容灾状态。当宽带集群系统启用异地容灾功能时，MME在Tm1接口与一或多个TSN进行双向的定时探测，TSN侧通过探测消息下发自身状态给MME，指示MME自身的状态发生了变更；MME侧通过TSN的通知或者自己探测的结果来变更自身保存的TSN状态。当宽带集群系统处于容灾主或者单站主状态时，允许接入业务；当系统处于容灾备或检测备状态时，不允许接入业务。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数ID           | 参数名称   | 参数说明                                                                                                                                               |
|:---------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
| SHOWDETAILINFO | 显示详细信息 | 可选必选说明：必选参数 。 参数含义：用于请求系统是否需要显示详细信息。显示详细信息指每个进程上本地表的信息，非详细信息直接取主进程DDB表信息。 数据来源：本端规划。 取值范围：枚举类型“NO(否)”“YES(是)” 默认值：“NO(否)”。                         |
| PROCTYPE       | 进程类型   | 可选必选说明：必选参数 。 参数含义：进程类型。 数据来源：本端规划。 取值范围：枚举类型“SPP(SPP)”“SGP(SGP)” 默认值：“SPP(SPP)”。                                                                  |
| SERVICETYPE    | VNFC名称 | 可选必选说明：必选参数 参数含义：指定VNFC名称，可以通过UNC MML页面执行LST VNFC命令查询得到。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格。 默认值：无 配置原则：SPP配置USN_VNFC的对应名称，SGP配置LINK_VNFC的对应名称 |

#### 使用实例

1. 获取主SPP进程DDB表上的容灾信息：

   ```
   DSP BTRUNCSTATUS: SHOWDETAILINFO=NO, PROCTYPE=SPP, SERVICETYPE="USN_VNFC";
   ```
2. 获取所有SPP进程本地表上的容灾信息：

   ```
   DSP BTRUNCSTATUS: SHOWDETAILINFO=YES, PROCTYPE=SPP, SERVICETYPE="USN_VNFC";
   ```
3. 获取主SGP进程DDB表上的容灾信息：

   ```
   DSP BTRUNCSTATUS: SHOWDETAILINFO=YES, PROCTYPE=SGP, SERVICETYPE="LINK_VNFC";
   ```

#### 输出结果说明

| 输出项名称    | 输出项解释                                       |
|:---------|:--------------------------------------------|
| tsn1容灾状态 | 结果枚举如下： 暂态主容灾主容灾备单站主检测备                     |
| tsn2容灾状态 | 结果枚举如下： 暂态主容灾主容灾备单站主检测备                     |
| 当前系统主    | 结果枚举如下： 无系统主TSN1为系统主TSN2为系统主                |
| 升主时间     | 当前系统主成为系统主时的时间。                             |
| RU名称     | RU名称。                                       |
| 进程类型     | 取值如下： “SPP(SPP)”“SGP(SGP)”                  |
| 进程号      | RU内同类进程序号（当输入参数中“显示详细信息“选”否”时，这里展示的是主进程进程号） |
| 服务类型     | VNFC名称。可以通过UNC MML页面执行LST VNFC命令查询得到。       |
