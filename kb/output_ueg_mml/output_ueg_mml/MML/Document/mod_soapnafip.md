# 修改SOAP客户端IP地址(MOD SOAPNAFIP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于对系统中SOAP客户端IP地址记录进行修改。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                            |
|:-----------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------|
| ID         | ID       | 可选必选说明：必选参数 标识SOAP客户端IP地址的关键字段之一，用于指定需要对哪个ID对应的SOAP客户端IP地址记录进行修改。 取值范围：0～255 默认值：无。                                                             |
| ADDRTYPE   | IP地址类型   | 可选必选说明：可选参数 标识SOAP客户端IP地址的关键字段之一，用于指定需要对哪种地址类型对应的SOAP客户端IP地址记录进行修改。 取值范围：IPV4(IPV4)IPV6(IPV6) 默认值：无。                                            |
| NETWORKSV4 | IPv4网段   | 可选必选说明：条件必选参数 仅当该命令的参数“IP地址类型”取值为“IPV4(IPV4)”时该参数有效。标识SOAP客户端IP地址的关键字段之一，用于指定需要对哪个IPv4网段对应的SOAP客户端IP地址记录进行修改。 取值范围：有效的IPv4地址。 默认值：无。            |
| MASKV4     | IPv4子网掩码 | 可选必选说明：条件必选参数 仅当该命令的参数“IP地址类型”取值为“IPV4(IPV4)”时该参数有效。标识SOAP客户端IP地址的关键字段之一，用于指定需要对哪个IPv4子网掩码对应的SOAP客户端IP地址记录进行修改。 取值范围：有效的IPv4地址。 默认值：无。          |
| NETWORKSV6 | IPv6网段   | 可选必选说明：条件必选参数 仅当该命令的参数“IP地址类型”取值为“IPV6(IPV6)”时该参数有效。标识SOAP客户端IP地址的关键字段之一，用于指定需要对哪个IPv6网段对应的SOAP客户端IP地址记录进行修改。 取值范围：有效的IPv6地址。 默认值：无。            |
| PRELENV6   | IPv6前缀长度 | 可选必选说明：条件必选参数 仅当该命令的参数“IP地址类型”取值为“IPV6(IPV6)”时该参数有效。标识SOAP客户端IP地址的关键字段之一，用于指定需要对哪个IPv6前缀长度对应的SOAP客户端IP地址记录进行修改。 取值范围：0-128。 默认值：无。              |
| IPDESC     | IP描述     | 可选必选说明：条件可选参数 仅当该命令的参数“IP地址类型”取值为“IPV4(IPV4)”或“IPV6(IPV6)”时该参数有效。标识SOAP客户端IP地址的关键字段之一，用于指定需要对哪个名称对应的SOAP客户端IP地址记录进行修改。 取值范围：长度不超过64的字符串。 默认值：无。 |

## 使用实例

修改“ID”为“1”的SOAP客户端IP地址记录的“IP地址类型”为“IPV6(IPV6)”，“IPv6网段”为“2001:DB8:1::”，“IPv6前缀长度”为“11”。

```
MOD SOAPNAFIP: ID=1, ADDRTYPE=IPV6, NETWORKSV6="2001:DB8:1::0", PRELENV6=11, IPDESC="soap client ip1";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                      | 原因分析                                                           | 处理建议                                                                                       |
|-------:|:---------------------------|:---------------------------------------------------------------|:-------------------------------------------------------------------------------------------|
| 360267 | 网段与子网掩码不能重复。               | 输入的参数“IPv4网段”与“IPv4子网掩码”的组合或者“IPv6网段”与“IPv6前缀长度”的组合与系统中已定义的重复。 | 执行LST SOAPNAFIP命令查询后，重新输入参数“IPv4网段”与“IPv4子网掩码”的组合或者“IPv6网段”与“IPv6前缀长度”的组合，确保其取值与查询结果中的不重复。 |
| 360268 | IPv4网段255.255.255.255是非法值。 | 参数“IPv4网段”不能取值为“255.255.255.255”。                              | 重新输入“IPv4网段”参数，确保其取值不为“255.255.255.255”。                                                   |
| 360269 | IPv6网段全F是非法值。              | 参数“IPv6网段”不能取值为“FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF”。      | 重新输入“IPv6网段”参数，确保其取值不为“FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF”。                           |
