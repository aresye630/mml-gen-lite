# 查询对端NF的外部群组信息（LST PNFEXGROUPID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF、SMF、NSSF、SMSF、NCG、NEF、NWDAF、SCF**

该命令用于查询本地配置的对端NF实例支持的外部群组标识的信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询对端NF的外部群组信息。

```
%%LST PNFEXGROUPID:;%%
RETCODE = 0  操作成功

结果如下
--------
  NF实例标识  =  udm_instance_0
外部群组标识  =  externalGroupId01
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释          |
|:--------|:---------------|
| NF实例标识  | 该参数用于指定NF实例标识。 |
| 外部群组标识  | 该参数用于指定外部组标识。  |
