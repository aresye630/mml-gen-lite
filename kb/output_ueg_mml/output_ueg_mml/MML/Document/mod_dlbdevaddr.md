# 修改DLB设备地址(MOD DLBDEVADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

- 此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令为配置类命令，用于修改配置数据库中的DLB设备地址信息。在该命令中，系统通过“设备地址标识”来唯一标识一条DLB设备地址信息数据记录。

## 注意事项

- 修改设备地址会使得所有使用该地址的在线连接中断。
- 不支持IPv4和IPv6相互修改。

- IPv6类型的IP地址不支持混合方式表达，即xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:d.d.d.d，其中x表示一个十六进制数（0～9或A～F），而d.d.d.d表示一个IPv4地址。
- “IPV6地址”不支持以下特殊地址的配置，其中x表示一个十六进制数（0～9或A～F）：

  - 0000:0000:0000:0000:0000:0000:0000:0000
  - FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF
  - 0000:0000:0000:0000:0000:0000:0000:0001
  - FFxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE8x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE9x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEAx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEBx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
- 在SCTP场景下，本端最多允许配置10个IPV4地址或10个IPV6地址。
- PMS/NTS/DRS/HLB/DLB/NLF/LDAP设备的IP地址（包括IPv4地址和IPv6地址）需要唯一，任意两种设备的IP地址不能重复。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                            |
|:------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------|
| DEVAID      | 设备地址标识  | 可选必选说明：必选参数 参数含义：标识一条本地设备地址信息的关键字段，用于指定需要对哪一条本地设备地址信息进行修改或调整，操作员可以使用LST DLBDEVADDR命令查询获得。 取值范围：0～31 默认值：无。 配置原则：无。                              |
| VPNINDEX    | VPN索引   | 可选必选说明：可选参数 参数含义：用于指定一个DLBVPN实体。该参数必须先由ADD DLBVPN命令定义，然后才能在此索引。 取值范围：0～15 默认值：无。 配置原则：无。                                                        |
| IPVER       | IP版本    | 可选必选说明：可选参数 参数含义：用于指定设备IP地址的IP版本类型。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。                                                                   |
| IP          | IPV4地址  | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV4(IPV4)”时该参数有效，用于表示DLB设备的IPv4地址。 取值范围：IPv4地址 默认值：无。                                                              |
| IPV6        | IPV6地址  | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV6(IPV6)”时该参数有效，用于表示DLB设备的IPv6地址。 取值范围：IPv6地址 默认值：无。 配置原则：无。                                                      |
| DESCRIPTION | 描述      | 可选必选说明：可选参数 参数含义：用于描述设备IP地址的用途。 取值范围：长度不超过32位的字符串 默认值：无。 配置原则：无。                                                                                |
| DSCP        | DSCP优先级 | 可选必选说明：可选参数 参数含义：用于指定修改后的DSCP优先级。 取值范围：0～63，255 默认值：255。 配置原则：无。  说明： DSCP优先级有64级，为0～63，级别为63时，优先级最高。255表示不设置DSCP。DSCP优先级更新后需要重启Diameter链路才能生效。 |

## 使用实例

1. 修改IPv4类型的DLB设备地址信息。“设备地址标识”为“1”，“IP版本”为“IPV4(IPV4)”，“IPV4地址”为“192.168.0.130”。

   ```
   MOD DLBDEVADDR: DEVAID=1, IPVER=IPV4, IP="192.168.0.130";
   ```
2. 修改IPv6类型的DLB设备地址信息。“设备地址标识”为“2”，“IP版本”为“IPV6(IPV6)”，“IPV6地址”为“2001:0db8:3267:ffff:ffff:ffff:ffff:ffff”。

   ```
   MOD DLBDEVADDR: DEVAID=2, IPVER=IPV6, IPV6="2001:0db8:3267:ffff:ffff:ffff:ffff:fff";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 消息解释    | 原因分析                                                     | 处理建议                  |
|------:|:--------|:---------------------------------------------------------|:----------------------|
| 58107 | 设备地址冲突。 | PMS/NTS/DRS/HLB/DLB/NLF/LDAP设备的IP地址需要唯一，任意两种设备的IP地址不能重复。 | 修改IP地址，重新执行本命令修改设备地址。 |
