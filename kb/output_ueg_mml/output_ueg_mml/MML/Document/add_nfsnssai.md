## 命令功能

该命令用于增加本端网元的S-Nssai（单网络切片选择支撑信息）信息。该命令用于指定服务注册的NFProfile中sNssais、allowedNssais，以及NFService中的allowedNssais。系统向NRF发起服务注册时使用配置的数据。

## 注意事项

- 添加数据成功，如果当前“组名称”已在**ADD NFSRV**的“S-NSSAI组名称”中引用，且**ADD NFSRV**命令中的“网元状态”为“REGISTERED”时，将按照**ADD NFSRV**命令中“更新方式”参数中指定的更新模式60秒内向NRF发送Nnrf\_NFManagement\_NFUpdate Request消息请求更新。
- 添加数据成功，如果当前“组名称”已在**ADD NFCOMINFO**的“允许的S-Nssai组”中引用，且**ADD NFCOMINFO**的“公共信息标识”在**ADD NFSRV**命令的“网元公共信息标识”中引用，且**ADD NFSRV**命令中的“网元状态”为“REGISTERED”时，将按照**ADD NFSRV**命令中“更新方式”参数中指定的更新模式60秒内向NRF发送Nnrf\_NFManagement\_NFUpdate Request消息请求更新。
- 添加数据成功，如果当前“组名称”已在**ADD NFCOMINFO**的“允许的S-Nssai组”中引用，且**ADD NFCOMINFO**的“公共信息标识”在**ADD NFSERVICE**命令的“网元公共信息标识”中引用，且**ADD NFSERVICE**的“组名称”在**ADD NFSRV**命令的“网元服务组”中引用，且**ADD NFSRV**命令中的“网元状态”为“REGISTERED”时，将按照**ADD NFSRV**命令中“更新方式”参数中指定的更新模式60秒内向NRF发送Nnrf\_NFManagement\_NFUpdate Request消息请求更新。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                        |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GRPNAME | 组名称    | 可选必选说明：必选参数 参数含义：用于标识本端网元S-Nssai信息所属组的信息。 取值范围：长度不超过32的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则： 该组名由本端自定义。若该“组名称”不存在，则创建该组名称。该参数配置时不能取值为“NULL”，否则无法被正常索引。 |
| INDEX   | 索引     | 可选必选说明：必选参数 参数含义：用于标识一条本端网元S-Nssai信息的关键字段。 取值范围：1~10240。 默认值：无。 配置原则：无。                                                                                     |
| SST     | 分片业务类型 | 可选必选说明：必选参数 参数含义：用于指定本端网元S-Nssai信息中的分片业务类型。 取值范围：0~255。 默认值：无。 配置原则：该“分片业务类型”由运营商统一规划，该值须与用户在UDM网元上5G开户中的切片信息保持一致。                                          |
| SD      | 切片区分器  | 可选必选说明：可选参数 参数含义：用于指定本端网元S-Nssai信息中的切片区分器。 取值范围：长度为6的16进制数字字符串 默认值：无。 配置原则：该“切片区分器”由运营商统一规划，该值须与用户在UDM网元上5G开户中的切片信息保持一致。                                    |

## 使用实例

增加一个网元切片信息。“组名称”为“snssai-group-01”，“索引”为“1”，“分片业务类型”为“12”，“切片区分器”为“2ac221”：

```
ADD NFSNSSAI: GRPNAME="snssai-group-01", INDEX=1, SST=12, SD="2ac221";
```
