# 删除LDAP链路(RMV LDAPLNK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令用于从配置数据库中删除一条LDAP服务与外置SPR数据库的链路数据记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                          |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------|
| LINKID | 链路ID   | 可选必选说明：必选参数 参数含义：标识一条LDAP链路数据记录的关键字段，用于指定需要删除哪一条LDAP链路数据记录，操作员可以使用LST LDAPLNK命令查询获得。 取值范围：0～31 默认值：无。 配置原则：无。 |

## 使用实例

删除一条LDAP与SPR数据库的链路配置信息记录，“链路ID”为“4”。

```
RMV LDAPLNK: LINKID=4;
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。
