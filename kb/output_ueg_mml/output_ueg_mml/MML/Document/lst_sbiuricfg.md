# 查询SBI接口的URI配置（LST SBIURICFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询UPCF发送请求/响应消息时，本端URI中host的取值格式。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                      |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------|
| NFTYPE | 网元类型   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个网元类型来查询本端URI中host的取值格式；若不输入，则表示查询所有网元类型本端URI中host的取值格式。 取值范围：SCP(SCP)NRF(NRF) 默认值：无。 配置原则：无。 |

## 使用实例

查询所有网元类型本端URI中host的取值格式。

```
LST SBIURICFG:;
```

```
%%LST SBIURICFG:;%%
RETCODE = 0  操作成功

结果如下
-------------------------
网元类型  =  SCP
接口类型  =  N7
 URI类型  =  Location
 URI取值  =  FQDN
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET SBIURICFG**。
