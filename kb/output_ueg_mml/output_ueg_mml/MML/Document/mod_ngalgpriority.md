# 修改5G算法优先级属性（MOD NGALGPRIORITY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

执行该命令配置的加密性算法或者完整性算法优先级不合理，可能导致终端接入异常。

**适用NF：AMF**

该命令用于修改指定加密或完整性算法的优先级属性。

AMF根据此命令配置不同加密算法或完整性算法的优先级，在UE和AMF同时支持此算法的前提下，选择优先级最高的算法发送给UE，用以对NAS消息的加密和完整性保护。如果所有算法均未设置优先级属性，系统会根据算法的默认优先级属性（从高到低分别为AES、SNOW 3G、ZUC、空加密算法）和UE进行协商，最终确定采用的加密或完整性算法。

## 注意事项

- 该命令执行后立即生效。

- 通过ADD NGUSRSECPARA命令打开加密或者完整性功能开关，本命令配置的算法优先级才会生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                 |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ALGTYPE | 算法类型   | 可选必选说明：必选参数  参数含义：该参数用于指定对何种类型的算法设置优先级属性，分加解密算法和完整性算法两种类型。  数据来源：全网规划 取值范围： “CIPH（加密算法）”：加密算法“INTE（完整性算法）”：完整性算法  默认值：无  配置原则：无                                                                      |
| ALGCIPH | 加密算法   | 可选必选说明：该参数在"ALGTYPE"配置为"CIPH"时为条件必选参数。  参数含义：该参数用于指定对何种加密算法设置优先级属性。  数据来源：全网规划 取值范围： “NEA0（空加密算法）”：空加密算法“NEA1（SNOW 3G加密算法）”：SNOW 3G加密算法“NEA2（AES加密算法）”：AES加密算法“NEA3（ZUC加密算法）”：ZUC加密算法  默认值：无  配置原则：无 |
| ALGINTE | 完整性算法  | 可选必选说明：该参数在"ALGTYPE"配置为"INTE"时为条件必选参数。  参数含义：该参数用于指定对何种完整性算法设置优先级属性。  数据来源：本端规划 取值范围： “NIA1（SNOW 3G完整性算法）”：SNOW 3G完整性算法“NIA2（AES完整性算法）”：AES完整性算法“NIA3（ZUC完整性算法）”：ZUC完整性算法  默认值：无  配置原则：无             |
| ALGPRI  | 算法优先级  | 可选必选说明：必选参数  参数含义：该参数用于设置指定算法的优先级数值。数值越小，优先级越高。  数据来源：全网规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无                                                                                                     |
| DESC    | 描述信息   | 可选必选说明：可选参数  参数含义：该参数用以描述针对指定算法配置的优先级，在运维中起助记的作用。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~32。  默认值：无  配置原则：  输入单空格将删除该参数已有配置项。                                                                               |

## 使用实例

修改算法类型为NEA1（SNOW 3G）加密算法的优先级为3，执行如下命令：

```
MOD NGALGPRIORITY: ALGTYPE=CIPH, ALGCIPH=NEA1, ALGPRI=3;
```
