# 删除拨测用户配置(RMV ISSUDIALTEST)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于删除一组拨测用户的配置。

#### 注意事项

- 配置删除后，对应的拨测用户会逐步通过先分离再重新接入的方式迁移到老侧USN\_VNFC。
- 本命令的起始IMSI/MSISDN必须和**LST ISSUDIALTEST**命令查询到的起始IMSI/MSISDN一致。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                   |
|:------------|:---------|:-----------------------------------------------------------------------------------------------------------------------|
| TSTUSRRANGE | 用户标识类型   | 可选必选说明：必选参数 参数含义：该参数用于配置拨测用户范围。 数据来源：本端规划 取值范围：枚举类型。“MSISDN(MSISDN)”“IMSI(IMSI)” 默认值：无                                 |
| BEGMSISDN   | 起始MSISDN | 可选必选说明：条件必选参数 参数含义：该参数用于配置拨测用户的起始MSISDN。 前提条件：该参数在“用户标识类型”参数配置为“MSISDN(MSISDN)”后生效。 数据来源：本端规划 取值范围：1～15位十进制数字字符串 默认值：无 |
| BEGIMSI     | 起始IMSI   | 可选必选说明：条件必选参数 参数含义：该参数用于配置拨测用户的起始IMSI。 前提条件：该参数在“用户标识类型”参数配置为“IMSI(IMSI)”后生效。 数据来源：本端规划 取值范围：6～15位十进制数字字符串 默认值：无       |

#### 使用实例

删除一条拨测用户配置，起始IMSI为123001111111111。

RMV ISSUDIALTEST: TSTUSRRANGE=IMSI, BEGIMSI="123001111111111";
