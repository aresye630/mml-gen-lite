# 删除VPN组成员（RMV SQOSVPNGROUPMEM）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来删除VPN组成员。

#### 注意事项

- 该命令执行后立即生效。

- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                              |
|:-------------|:-------|:------------------------------------------------------------------------------------------------------------------|
| VPNGROUPNAME | VPN组名称 | 可选必选说明：必选参数 参数含义：该参数用于指定VPN组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无 配置原则：区分大小写，不支持空格。 |
| VPNNAME      | VPN名称  | 可选必选说明：必选参数 参数含义：该参数用于指定VPN名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：区分大小写，不支持空格。                          |
| VPNPRIORITY  | VPN优先级 | 可选必选说明：可选参数 参数含义：该参数用于指定VPN优先级。 数据来源：本端规划 取值范围：整数类型，取值范围为1～16。 默认值：无                                              |

#### 使用实例

删除VPN组成员：

```
RMV SQOSVPNGROUPMEM:VPNGROUPNAME="vg1",VPNNAME="vpn1";
```
