# 配置CG（ADD CG）

- 命令功能

- 操作用户权限

#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

ADD CG命令用来添加一条CG配置信息。当用户进行离线计费时，需要配置CG接收离线计费生成的话单。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为32。
- 当前版本不支持此命令的REALMNAME参数。
- 配置WALVALUE值进行流控时，存在一定误差，非精准流控。建议配置WALVALUE值为10\*Ga逻辑接口数的整数倍。
- 要配置此命令的GAPORT参数，需要先配置SET CONCENPOINT命令的GaConcenMode参数配置为SINGLE\_CONNECT并且byte780 bit4置为1，否则GAPORT参数不生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

| IPV4ADDR  | CG IPv4地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV4”时为必选参数。 参数含义：CG服务器的IPv4地址。 数据来源：全网规划 取值范围：IPv4地址类型。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                    |
| IPV6ADDR  | CG IPv6地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV6”时为必选参数。 参数含义：CG服务器的IPv6地址。 数据来源：全网规划 取值范围：IPv6地址类型。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                    |
| PORT      | CG端口号     | 可选必选说明：必选参数 参数含义：CG服务器的端口号。 数据来源：全网规划 取值范围：整数类型，取值范围为1024～65535。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                                  |
| PRIORITY  | 等级        | 可选必选说明：必选参数 参数含义：CG服务器的等级。值越小优先级越高，即0的优先级最高，100的优先级最低。 数据来源：本端规划 取值范围：整数类型，取值范围为0～100。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                            |

| REALMNAME | CG域名      | 可选必选说明：可选参数 参数含义：该参数用于指定对端域名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                                   |
| GAPORT    | Ga本端端口    | 可选必选说明：可选参数 参数含义：该参数用于指定通过Ga接口与对端建链时的源端口号。 数据来源：全网规划 取值范围：整数类型，取值范围为0，10551～10600。 默认值：无 配置原则： 在SET CONCENPOINT命令的GaConcenMode参数配置为SINGLE_CONNECT并且byte780 bit4置为1时生效。不能配置相同的GaPort。配置为0表示不指定源端口号。不配置此参数时值默认为0。                                                                                                                                                                                                                                |

#### 使用实例

增加CG，CG的IP地址为192.168.0.2，CG的端口号为25009，CG的等级为1，话单的类型为R9\_PGW：

```
ADD CG:IPVERSION=IPV4, IPV4ADDR="192.168.0.2",PORT=25009,PRIORITY=1,CDRTYPE=R9_PGW;
```
