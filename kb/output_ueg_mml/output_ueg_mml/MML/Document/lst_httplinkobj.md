# 查询HTTP链路测量对象(LST HTTPLINKOBJ)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询HTTP链路测量对象。

- 如果需要查询所有的HTTP链路测量对象记录，请不要输入任何参数。
- 如果需要查询指定的HTTP链路测量对象记录，请依据参数说明输入查询的条件。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                          |
|:----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| WORKMODE  | 工作模式   | 可选必选说明：可选参数 参数含义：用于指示系统按照工作模式来查询HTTP链路测量对象记录；若不输入，则表示所有的工作模式。 取值范围： SERVER(服务端)CLIENT(客户端) 默认值：无。 配置原则：无。                                                                                                     |
| LOCALIP   | 本端IP地址 | 选必选说明：可选参数 参数含义：用于指示系统按照本端IP地址来查询HTTP链路测量对象记录；若不输入，则表示所有的本端IP地址。 取值范围：IPv4地址/IPv6地址 默认值：无。 配置原则：当IP地址类型为IPv6地址时，配置该参数时需要将IP地址当中的“:”替换为“-”，字母不支持小写，且不支持自动补0。IPv6地址配置示例：FC00-0000-0000-4007-0156-0110-0006-0123 |
| LOCALPORT | 本端端口   | 选必选说明：可选参数 参数含义：用于指示系统按照本端端口来查询HTTP链路测量对象记录；若不输入，则表示所有的本端端口。 取值范围：0~65535 默认值：无。 配置原则：无。                                                                                                                      |
| PEERIP    | 对端IP地址 | 选必选说明：可选参数 参数含义：用于指示系统按照对端IP地址来查询HTTP链路测量对象记录；若不输入，则表示所有的对端IP地址。 取值范围：IPv4地址/IPv6地址 默认值：无。 配置原则：当IP地址类型为IPv6地址时，配置该参数时需要将IP地址当中的“:”替换为“-”，字母不支持小写，且不支持自动补0。IPv6地址配置示例：FC00-0000-0000-4007-0156-0110-0006-0123 |
| PEERPORT  | 对端端口   | 选必选说明：可选参数 参数含义：用于指示系统按照对端端口来查询HTTP链路测量对象记录；若不输入，则表示所有的对端端口。 取值范围：0~65535 默认值：无。 配置原则：无。                                                                                                                      |

## 使用实例

- 查询所有的HTTP链路测量对象记录。

  ```
  LST HTTPLINKOBJ:;
  ```

  ```
  %%LST HTTPLINKOBJ:;%%
  RETCODE = 0  操作成功

  操作结果如下
  ---------------
  工作模式  本端IP地址       本端端口    对端IP地址        对端端口        

  客户端    10.194.39.220    40022       10.195.39.221     10501           
  客户端    10.194.39.220    40029       10.195.39.221     10501           
  (结果个数 = 2)

  ---    END
  ```

- 查询指定的HTTP链路测量对象记录。“本端端口”为“40022”。

  ```
  LST HTTPLINKOBJ: LOCALPORT=40022;
  ```

  ```
  %%LST HTTPLINKOBJ: LOCALPORT=40022;%%
  RETCODE = 0  操作成功

  操作结果如下
  ---------------
    工作模式  =  客户端
  本端IP地址  =  10.194.39.220    
    本端端口  =  40022    
  对端IP地址  =  10.195.39.221   
    对端端口  =  10501   
  (结果个数 = 1)  

  ---    END
  ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD HTTPLINKOBJ**命令的参数说明。
