## 命令功能

**须知** 

- 此命令是高危命令，如果执行不当会影响业务处理，需联系华为技术支持确认后再执行。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令为维护类命令，用于设置本端网元实例的网元状态信息。网元实例通过NRF注册，能被其他网元发现并进行业务交互。在存储BYPASS模式下，如果虚拟机（裸机Pod）存储故障，可以通过此命令设置主用UPCF为未注册状态，将业务切换到容灾UPCF处理。

## 注意事项

- **SET NFSRV**设置NCS中指定网元实例的网元工作状态。NCS重启或倒换后，该设置不再生效。
- 只有在虚拟机（裸机Pod）存储故障时才允许使用**SET NFSRV**命令。
- 执行**SET NFSRV**命令后，若进行手动或自动校验NCS内存数据和CSP内存数据的一致性，系统上报“ALM-34260 内存数据不一致”告警，在此情况下，请勿执行**SYN NRFDATA**命令同步内存数据以消除告警，需联系华为技术支持确认后处理。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                      |
|:----------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSNAME | 网元实例名称 | 可选必选说明：必选参数 参数含义：用于标识本端网元发起NRF注册时实例的名称。 取值范围：长度不超过32的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：该参数全局唯一，不能重复。                                                                                                                                                                                              |
| NFSTATUS  | 网元状态   | 可选必选说明：必选参数 参数含义：用于标识本端网元的工作状态。 取值范围：REGISTERED(正常工作状态)SUSPENDED(服务暂停状态)UNREGISTERED(未注册状态) 默认值：无。 配置原则：无。  说明： 当设置网元状态为REGISTERED时，本端PCF网元注册到NRF上并正常工作。当设置网元状态为SUSPENDED时，本端PCF网元注册到NRF上，但处于暂停工作状态，此时NRF上可以查询到此PCF网元实例，但是不会将此状态PCF的供其他网元服务发现。当设置网元状态为UNREGISTERED时，系统通知NRF删除此NF注册信息，即此时NRF上查询不到此PCF网元实例。 |

## 使用实例

1. 虚拟机（裸机Pod）存储故障时，设置“网元实例名称”为“pcf-application-002”的“网元状态”为“UNREGISTERED(未注册状态)”，不提供业务服务。

   ```
   SET NFSRV: NFINSNAME="pcf-application-002", NFSTATUS=UNREGISTERED;
   ```
2. 虚拟机（裸机Pod）存储故障时，设置“网元实例名称”为“pcf-application-002”的“网元状态”为“REGISTERED(正常工作状态)”，继续提供业务服务。

   ```
   SET NFSRV: NFINSNAME="pcf-application-002", NFSTATUS=REGISTERED;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释         | 原因分析            | 处理建议                          |
|------:|:--------------|:----------------|:------------------------------|
| 58046 | 当前操作的配置数据不存在。 | 输入的“网元实例名称”不存在。 | 使用LST NFSRV命令查询“网元实例名称”后重新输入。 |

## 参考信息

BYPASS模式：虚拟机（裸机Pod）在初始安装时分配有充足的磁盘，正常运行时处于有盘模式。当存储故障时，系统自动把运行文件都加载在内存中，转为无盘模式运行。
