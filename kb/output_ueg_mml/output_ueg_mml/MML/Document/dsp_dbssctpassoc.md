# 显示DBS SCTP偶联配置(DSP DBSSCTPASSOC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于请求系统显示DBS服务的SCTP偶联配置信息，并生成SCTP偶联话统统计对象。

## 注意事项

- 该命令所显示的DBS服务的SCTP偶联配置信息，是最后一次执行**ACT DBSIPDISP**命令请求系统激活IP配置后，DBS服务的偶联配置信息。
- 如果链路配置发生变化，需要在执行**ACT DBSIPDISP**命令后，执行本命令用以更新SCTP偶联话统统计对象信息。如果没有执行本命令，那么SCTP偶联话统统计对象信息不会自动更新，将停留在上次执行本命令的状态。

## 参数说明

无。

## 使用实例

显示DBS服务的SCTP偶联配置信息，执行命令如下：

```
DSP DBSSCTPASSOC:;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1的参数说明。

| 输出项名称       | 输出项解释                 |
|:------------|:----------------------|
| 测量对象ID      | 用于返回SCTP偶联测量对象标识。     |
| SCTP偶联本地IP1 | 用于返回SCTP偶联本端设备的IP地址1。 |
| SCTP偶联本地IP2 | 用于返回SCTP偶联本端设备的IP地址2。 |
| SCTP偶联本地端口号 | 用于返回SCTP偶联本端设备的端口号。   |
| SCTP偶联对端IP1 | 用于返回SCTP偶联远端设备的IP地址1。 |
| SCTP偶联对端IP2 | 用于返回SCTP偶联远端设备的IP地址2。 |
| SCTP偶联对端端口号 | 用于返回SCTP偶联远端设备的端口号。   |
| FE类型名称      | 用于返回FE类型名称。           |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释   | 原因分析                              | 处理建议                   |
|------:|:--------|:----------------------------------|:-----------------------|
|   520 | 部分成功。   | 存在部分DBS微服务故障。存在部分业务类型的DBS微服务全部故障。 | 重试当前操作，若仍不成功请联系华为技术支持。 |
