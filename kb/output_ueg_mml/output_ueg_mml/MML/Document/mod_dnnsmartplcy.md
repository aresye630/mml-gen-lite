# 修改DNN智能分流配置（MOD DNNSMARTPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于修改PDU会话创建使用的DNN智能分流配置。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称        | 参数说明                                                                                                                                                      |
|:---------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
| DNN      | DNN         | 可选必选说明：必选参数  参数含义：该参数用于指定用户会话创建使用的DNN名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。可输入的字符有字母、十进制数字、“-”和“.”，并且开头和结尾只能是数字或者字母。不能出现连续两个“.”。字母大小写不敏感。  默认值：无  配置原则：无 |
| SMFSELSW | 是否支持专用SMF选择 | 可选必选说明：可选参数  参数含义：该参数用于指定智能分流用户PDU会话创建时使用的DNN是否支持专用SMF选择。  数据来源：全网规划 取值范围： “YES（是）”：是“NO（否）”：否  默认值：无  配置原则：无                                             |

## 使用实例

关闭DNN“huawei.com”智能分流功能，请执行：

```
MOD DNNSMARTPLCY: DNN="huawei.com", SMFSELSW=NO;
```
