# 删除PCRF与Diameter对端的链路(RMV PEERL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于在配置数据库中删除一条PCRF实体与Diameter对端的链路数据记录。

## 注意事项

执行本命令，当PCRF实体与Diameter对端的某条链路的“链路管理状态”为“去使能”时，才能成功删除该链路；否则删除失败。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                 |
|:-------|:-------|:---------------------------------------------------------------------|
| PCRFID | PCRF标识 | 用于标识PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围：1 默认值：无。              |
| PT     | 对端类型   | 用于定义对端类型。 取值范围： DRA(DRA)TDF(TDF) 默认值：无。                              |
| PEERID | 对端标识   | 用于指定一个对端，该参数必须先由ADD PEER命令定义，然后才能在此处索引。 取值范围：0～127 默认值：无。            |
| LNKID  | 对端链路标识 | 用于在UPCF的配置库中定义一个对端链路。该参数的配置原则：如果配置多个对端链路，从0开始顺序配置。 取值范围：0～135 默认值：无。 |

## 使用实例

删除一条PCRF实体和Diameter对端链路。“PCRF标识”为“1”，“对端类型”为“DRA”，“对端标识”为“0”，“对端链路标识”为“0”。

1. 在OM Portal界面选择“应用管理 > MML”，在UPCF网元下执行**LST PEERL**命令查询此条链路对应“链路管理状态”是否为“去使能”。
   - 是 => 步骤 3
   - 否 => 步骤 2
2. 执行**MOD PEERL**将“链路管理状态”置为“去使能”。

   ```
   MOD PEERL: PCRFID=1, PT=DRA, PEERID=0, LNKID=0, ADSTS=DISABLE;
   ```
3. 执行**RMV PEERL**命令删除链路。例如，删除如下链路：“PCRF标识”为“1”，“对端类型”为“DRA”，“对端标识”为“0”及“对端链路标识”为“0”。

   ```
   RMV PEERL: PCRFID=1, PT=DRA, PEERID=0, LNKID=0;
   ```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                             | 原因分析                             | 处理建议                                                                          |
|------:|:----------------------------------|:---------------------------------|:------------------------------------------------------------------------------|
| 57853 | 需要删除的链路的“链路管理状态”必须是“去使能”时，才能删除链路。 | 需要删除的链路的“链路管理状态”为“使能”，导致该命令执行失败。 | 执行命令LST PEERL查询指定链路的“链路管理状态”。如果确定要删除此链路，可以通过MOD PEERL将“链路管理状态”置为“去使能”，再执行本命令。 |
