# 查询目标NF组（LST TNFGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF、SMF、NRF、NSSF、NCG、SMSF**

该命令用于查询目标NF组的配置。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                 |
|:--------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------|
| TNFTYPE | 目标NF类型 | 可选必选说明：可选参数  参数含义：本参数用于指定目标NF组内的NF类型。  数据来源：本端规划 取值范围： “CHF（CHF）”：CHF“UPF（UPF）”：UPF“PCSCF（PCSCF）”：PCSCF“PCF（PCF）”：PCF  默认值：无  配置原则：无 |

## 使用实例

运营商A需要查询TNFTYPE为CHF的目标NF组信息。

```
%%LST TNFGRP:;%%
RETCODE = 0  操作成功

结果如下
--------
  目标NF类型  =  CHF
目标NF组索引  =  1
目标NF组名称  =  CHF_GROUP_0
( 结果个数 = 1)

---    END
```
