# 增加SCTP本地实体组(ADD SCTPLEGRP)

#### 命令功能

**适用网元：MME、AMF**

本命令用于添加SCTP本端实体组。5G基站(NG RAN)支持多偶联接入，添加SCTP本端实体组用于将多个SCTP本端实体绑定，从而实现多偶联。

#### 注意事项

- 该命令执行后立即生效。
- 此命令最大记录数为256。
- 一个SCTP本端实体组只能被一个NGAP或SFGAP本端实体引用。
- 一个SCTP本端实体组可以同时包含IPV4地址的本端实体和IPV6地址的本端实体。

#### 本地用户权限

无

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称        | 参数说明                                                                        |
|:------------|:------------|:----------------------------------------------------------------------------|
| SCTPGROUPID | SCTP本地实体组标识 | 可选必选说明：必选参数 参数含义：该参数用于指定SCTP本地实体组的标识。 数据来源：本端规划 取值范围：整数类型，取值范围为0~255。 默认值：无 |

#### 使用实例

增加一个SCTP本地实体组，索引为0。

```
ADD SCTPLEGRP: SCTPGROUPID=0;
```
