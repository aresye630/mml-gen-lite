# 增加网元订阅信息(ADD UDMNFSUBSCRDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加一条订阅信息，如果NRFClient需要收到符合以下限制条件的网元发生变更时对其发送通知，可执行此命令。

- NRFClient订阅的网元实例在NRF上完成注册时。
- NRFClient订阅的网元实例在NRF上完成去注册时。
- NRFClient订阅的网元实例在NRF上更新nfProfile时。

## 注意事项

- 执行该命令，如果“订阅状态”为“SUBSCRIBED”，NRFClient向NRF发送订阅请求，以便NRF将满足订阅条件的网元实例发送通知消息给NRFClient。
- 该命令为调测命令，仅适用于开局阶段调测或者维护的操作场景。
- 该命令为静态订阅命令暂不支持持续订阅功能。

## 参数说明

| 参数标识              | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                                    |
|:------------------|:------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBSCRNAME        | 订阅名称        | 可选必选说明：必选参数 参数含义：用于标识一个订阅的名称。 取值范围：长度不超过32的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：该参数全局唯一。                                                                                                                                                                                                                           |
| NOTIFURL          | 通知URL       | 可选必选说明：必选参数 参数含义：用于标识NRFClient接收通知消息的URL。 取值范围：长度不超过512位的字符串，包含协议类型(http/https)、FQDN域名或IP、端口（可选）等信息。举例：http://192.168.48.31:8080/subscription 默认值：无。 配置原则： FQDN域名和IP地址的对应关系可通过LST UDMFQDNINFO命令查询获得，IP地址信息可通过LST HTTPIP命令查询获得，IP地址和端口的对应关系可通过LST HTTPLSERVER命令查询获得。支持配置不携带端口的通知URL，当未配置端口时，HTTP默认使用80端口，HTTPS默认使用443端口。 |

| TARGETAMFSETID    | 目标AMF集标识    | 可选必选说明：条件可选参数 参数含义：用于标识目标AMF的集标识。 取值范围：长度为3的字符串，只允许输入0～9，a～f，A～F。 默认值：无。 配置原则：仅当本命令中的参数“订阅条件”取值为“AMFCOND”时，该参数有效并且与“目标AMF区域标识”至少输入一个。                                                                                                                                                                                   |

## 使用实例

在配置NRF服务注册管理特性时，增加一个网元订阅信息。“订阅名称”为“SUBSCRIBED1”，“通知URL”为“http://192.168.48.31:8080/v1”，“订阅条件”为“NFTYPECOND”，“目标网元类型”为“AMF”,“有效时间”为“2022&04&16&19&33&24”，“通知事件类型”为“ALL”,“网元类型”为“AUSF”，“PLMN标识”为“{"mcc":"460","mnc":"08"}”,“通知条件”为“{"monitoredAttributes":["/ipv4Addresses","/allowedNfTypes"]}”,“订阅状态”为“SUBSCRIBED”, “NRF所属组信息”为“udm-nrfgroup-01”:

```
ADD UDMNFSUBSCRDATA: SUBSCRNAME="SUBSCRIBED1", NOTIFURL="http://192.168.48.31:8080/v1", SUBSCRCOND=NFTYPECOND, TARGETNFTYPE=AMF, VALIDITYTIME=2022&04&16&19&33&24, NOTIFEVENTS=ALL, NFTYPE=AUSF, PLMNID="{\"mcc\":\"460\",\"mnc\":\"08\"}", NOTIFCOND="{\"monitoredAttributes\":[\"/ipv4Addresses\",\"/allowedNfTypes\"]}", SUBSCRSTATUS=SUBSCRIBED, NRFGROUP="udm-nrfgroup-01";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                    | 原因分析                                        | 处理建议                                                                  |
|-------:|:-------------------------|:--------------------------------------------|:----------------------------------------------------------------------|
|    503 | 配置数据已存在                  | “订阅名称”已存在。                                  | 修改“订阅名称”确保与已有订阅名称不同，可通过LST UDMNFSUBSCRDATA命令查询已有订阅。                   |
| 360041 | 参数值不合法                   | 错误响应消息中携带的参数不合法。                            | 修改错误提示中携带的参数后重新运行命令，参考参数说明中对应参数的格式。                                   |
| 360043 | 参数值未配置                   | 输入的“NRF所属组信息”未定义。                           | 根据实际情况，重新输入参数，确保输入的“NRF所属组信息”已定义，可通过LST UDMNRFINFO命令查询已定义的“NRF所属组信息”。 |
| 360045 | 非法冗余参数                   | 错误提示中携带的参数为冗余参数，不应在命令中携带。                   | 删除命令中包含的错误提示中对应参数后重新运行命令。                                             |
| 360049 | 目标AMF集标识和目标AMF区域标识至少输入一个 | “目标AMF集标识”和“目标AMF区域标识”一个都没有输入。              | 根据实际情况，重新输入“目标AMF集标识”或“目标AMF区域标识”参数，至少输入一个。                           |
| 360050 | 目标网元类型不合法，只允许选择UDR       | 当“订阅条件”选择“NFGROUPCOND”时，“目标网元类型”只允许选择“UDR”。 | 根据实际情况，将“目标网元类型”选择为“UDR”。                                             |
| 360052 | AmfId和PlmnId必须同时存在       | “目标AMF唯一标识列表”中amfId和plmnId必须同时输入。           | 参考信元“目标AMF唯一标识列表”的格式，输入amfId或plmnId，确保amfId和plmnId同时出现。               |
