# 查询SSL协议开关状态 (LST SSLCONFIGSWITCH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

用于查询SSL协议开关状态。

#### 注意事项

无。

#### 参数说明

无。

#### 使用实例

查询SSL协议开关状态：

```
%%LST SSLCONFIGSWITCH:;%%
RETCODE = 0  操作成功

结果如下
------------
SSL协议开关状态  =  开 
(结果个数 = 1)
---    END
```

#### 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。输出结果说明如表1所示。

该命令执行异常，请联系华为技术支持处理。错误码说明如表2所示。

|:----------|:------------|
| SSL协议开关状态 | SSL协议的开关状态。 |

|-------:|:-----------|:-------|:-----------|
