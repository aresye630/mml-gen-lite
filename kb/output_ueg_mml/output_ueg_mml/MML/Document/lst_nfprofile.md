# 查询NF信息(LST NFPROFILE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于在配置数据库中查询网络功能的配置信息。当前只有一条记录。

## 注意事项

无。

## 参数说明

| 参数标识         | 参数名称        | 参数说明                                                                                                                                                                                                                                                                             |
|:-------------|:------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ID           | 索引          | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个NF信息索引来查询NF的配置信息；若不输入，则表示所有的NF信息。 取值范围：1 默认值：无。 配置原则：无。                                                                                                                                                                                             |
| FQDN         | FQDN        | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个FQDN来查询NF的配置信息；若不输入，则表示所有的FQDN。 取值范围：长度不超过128位的字符串 默认值：无。 配置原则：无。                                                                                                                                                                                   |
| CONFIGMODE   | 配置模式        | 可选必选说明：可选参数 参数含义：用于定义此PCF局点获取最大签约用户数的方式是手工还是自动。 取值范围： MANU（手工配置）AUTO（自动配置） 默认值：MANU（手工配置） 配置原则： 当该UPCF局点存在数据业务时，设置本参数值为“AUTO（自动配置）”，支持最大签约用户数自动获取。当该UPCF局点仅承载纯语音业务(VoLTE)，设置为“MANU（手工配置）”。                                                                                       |
| MAXSUBNBR    | 最大签约用户数     | 可选必选说明：可选参数 参数含义：用于指定用户网管北向接口查询UPCF的最大签约用户数。 取值范围：无。 默认值：无。 配置原则：系统自动计算。  说明： 当“配置模式”设置为“AUTO（自动配置）”时，该参数的取值“SPR用户和签约信息存储和管理”、“UDR用户和签约信息存储和管理(eMBB-NSA)”、“UDR用户和签约信息存储和管理(eMBB-SA)”和“基于漫游地签约的本地分流业务策略控制”四项License值之和。当“配置模式”设置为“MANU（手工配置）”时，该参数的取值为执行ADD NFPROFILE时设置的最大签约用户数。 |
| VNFINSTID    | VNF实例ID     | 可选必选说明：可选参数 参数含义：用于指定网管北向VNF实例ID。 取值范围：长度不超过64位的字符串 默认值：无。 配置原则：系统自动获取。  说明： VNF实例ID获取方式：登录U2020 VNF LCM，在“VNF总览”中点击对应的UPCF网元，进入网元管理页面，获取“VNF ID”。                                                                                                                               |
| UDRVNFINSTID | UDR VNF实例ID | 可选必选说明：可选参数 参数含义：用于指定网管北向UDR VNF实例ID。 取值范围：长度不超过128位的字符串 默认值：无。 配置原则：系统自动获取。  说明： UDR VNF实例ID获取方式：登录U2020 VNF LCM，在“VNF总览”中点击对应的USCDB网元，进入网元管理页面，获取“VNF ID”。                                                                                                                     |
| UDRVNFNAME   | UDR VNF名称   | 可选必选说明：可选参数 参数含义：用于指定网管北向UDR VNF的名称。 取值范围：长度不超过128位的字符串 默认值：无。 配置原则：无。  说明： UDR VNF名称获取方式：登录OM Portal，选择“应用管理 > MML”，进入MML命令界面。选择CSP网元执行LST ME命令，“网元类型”为“USCDB”的“网元名称”即“UDR VNF名称”。                                                                                              |
| RESERVE1     | 预留1         | 可选必选说明：可选参数 参数含义：预留参数。 取值范围：长度不超过128位的字符串 默认值：无。 配置原则：无。                                                                                                                                                                                                                         |
| RESERVE2     | 预留2         | 可选必选说明：可选参数 参数含义：预留参数。 取值范围：0~2147483647 默认值：无。 配置原则：无。                                                                                                                                                                                                                          |

## 使用实例

查询NF配置信息。

```
LST NFPROFILE:;
```
