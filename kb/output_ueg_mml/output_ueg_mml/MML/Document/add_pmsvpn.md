# 添加PMS VPN(ADD PMSVPN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条PMS接入CSLB时业务IP地址的VPN数据记录。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                        |
|:------------|:-------|:----------------------------------------------------------------------------------------------------------------------------|
| VPNINDEX    | VPN索引  | 可选必选说明：必选参数 参数含义：用于标识CSLB业务IP的VPN索引，与“VPN名称”共同标识一个VPN策略。 取值范围：0～31 默认值：无。 配置原则：无。                                           |
| VPNNAME     | VPN名称  | 可选必选说明：必选参数 参数含义：用于标识CSLB业务IP的VPN名称，与“VPN索引”共同标识一个VPN策略。 取值范围：长度不超过31位的字符串 默认值：无。 配置原则：需要与ADD L3VPNINST命令中“VPN实例名称”参数值保持一致。 |
| DESCRIPTION | 描述     | 可选必选说明：可选参数 参数含义：用于描述CSLB业务IP的VPN用途。 取值范围：长度不超过32位的字符串 默认值：无。 配置原则：无。                                                       |

## 使用实例

增加一条PMS的VPN数据记录。“VPN索引”为“0”，“VPN名称”为“VPN\_20”，“描述”为“test”。

```
ADD PMSVPN: VPNINDEX=0, VPNNAME="VPN_20", DESCRIPTION="test";
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。
