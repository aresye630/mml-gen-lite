# 查看用户检测开关（LST SESSIONDETECT）

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于查看用户检测开关状态。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询检测用户功能配置信息：

```
LST SESSIONDETECT:;
```

```
RETCODE = 0 操作成功。

检测用户开关
---------------------
用户检测开关 = ENABLE
带宽检测周期 = 2
(结果个数 = 1)
--- END
```

#### 输出结果说明

参见SET SESSIONDETECT的参数说明。
