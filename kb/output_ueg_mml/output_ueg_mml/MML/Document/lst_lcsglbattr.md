# 查询LCS全局属性（LST LCSGLBATTR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询LCS的全局属性。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询LCS的全局属性：

```
LST LCSGLBATTR:;
```

```
RETCODE = 0  操作成功

LCS全局属性
-----------
      LCS服务联动开关  =  使能
        LMF故障返回码  =  重定向
      隔离AMF功能开关  =  使能
隔离AMF定位失败返回码  =  服务不可用
    故障重试间隔（秒）  =  600
   定位请求连续失败次  =  3
         重试间隔次数  =  10
(结果个数 = 1)

---    END
```
