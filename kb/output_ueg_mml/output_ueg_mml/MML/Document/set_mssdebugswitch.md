# 设置维测信息统计开关（SET MSSDEBUGSWITCH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

本命令属于高危命令，操作不当会导致性能下降，请谨慎使用并联系华为技术支持协助操作。

该命令用于设置MSS维测统计信息开关。

#### 注意事项

- 该命令执行后立即生效。
- 本功能使能会消耗内存、降低性能且在用户指定的时间之后会自动去使能，去使能之后内存释放、性能恢复。默认时间是30分钟。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                                                                                                             |
|:------------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RUNAME      | RU名称    | 可选必选说明：必选参数 参数含义：该参数用于指定RU名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：使用DSP RU查看RU名称。                                                                                                                                                                           |
| DEBUGSWITCH | 开关标记    | 可选必选说明：必选参数 参数含义：该参数用于表示开关标记。 数据来源：本端规划 取值范围：枚举类型。 FALSE：关闭。TRUE：打开。 默认值：无                                                                                                                                                                                                       |
| DEBUGTYPE   | 开关类型    | 可选必选说明：必选参数 参数含义：该参数用于表示开关类型。 数据来源：本端规划 取值范围：枚举类型。 schedule-work：Work精度维测开关。schedule-group：调度组精度开关。schedule-queue：调度队列维测开关。energy-conservation：绿色节能维测开关。oe-check：保序校验维测开关。oe-statistics：保序精度维测开关。timer-event：定时器事件维测开关。timer-statistics：定时器精度维测开关。schedule-trace：调度轨迹维测开关。 默认值：无 |
| TIME        | 维测时间（s） | 可选必选说明：条件可选参数 前提条件：该参数在“DEBUGSWITCH”配置为“TRUE”时为可选参数。 参数含义：该参数用于表示维测状态持续时间，单位为秒。 数据来源：本端规划 取值范围：整数类型，取值范围为1～86400。 默认值：1800                                                                                                                                                       |

#### 使用实例

设置维测信息统计开关打开：

```
SET MSSDEBUGSWITCH:DEBUGSWITCH=TRUE,DEBUGTYPE=schedule-work,RUNAME = "VNODE_VNRS_VNFC_IPU_0064";
```
