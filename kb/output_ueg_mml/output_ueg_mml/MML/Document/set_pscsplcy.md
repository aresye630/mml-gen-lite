# 设置联合接入策略(SET PSCSPLCY)

- 命令功能

- 本地用户权限
- 网管用户权限

#### 命令功能

**适用网元：MME**

该命令用于设置联合接入策略。

#### 注意事项

- 此命令执行后立即生效。
- 此命令优先级高于ADD PROCLMTPLCY和BYTE\_EX\_B68 BIT8。
- 此命令与软参BYTE\_EX\_B126 BIT3存在关联关系。开启联合接入限制功能后，若满足限制条件，对已联合附着用户的SGs链路，MME本地解除并向MSC/VLR发送SGsAP IMSI Detach Indication消息以解除该用户在MSC/VLR中的SGs链路连接，消息中携带的IMSI Detach from non-EPS service type信元值由此软参控制。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

| IMSPDNCOND  | 无IMS PDN连接时是否限制联合TAU  | 可选必选说明：条件可选参数 参数含义：该参数用于控制在联合TAU流程中，如果用户未建立IMS的PDN连接，是否限制CS注册。 前提条件：该参数在“COMTAUSW”配置为“YES”时为可选参数。 数据来源：整网规划 取值范围： “YES(是)”“NO(否)” 默认值：NO(否)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |

| CSCAUSE     | 联合接入限制原因值             | 可选必选说明：条件可选参数 参数含义：该参数用于联合附着和联合TAU流程中CS注册受限后，响应UE的原因值。 前提条件：该参数在“ACCSUCC”配置为“NO”时为可选参数。 数据来源：整网规划 取值范围： MSC_TEMPORARILY_NOT_REACHABLE(#16 MSC temporarily not reachable)CS_DOMAIN_NOT_AVAILABLE(#18 CS domain not available) 默认值：CS_DOMAIN_NOT_AVAILABLE(#18 CS domain not available)  说明： EMM CAUSE中的失败原因值，请参考3GPP TS 24.301进行输入。                                                                                                                                                                                                                                                                                                    |

| NOCSIDENT   | 无CS规划识别条件             | 可选必选说明：条件可选参数 参数含义：该参数用于指定运营商针对某个用户未规划CS网络的匹配条件。 前提条件：该参数在“NOCSPLCY”配置为“YES”时为可选参数。 数据来源：整网规划 取值范围： “TAILAI（TAILAI）”：表示根据ADD TAILAI进行匹配，如果匹配失败，即为运营商针对该用户未规划CS网络。                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| NOCSUEIDENT | 用户识别条件                | 可选必选说明：条件可选参数 参数含义：针对未规划CS网络的用户，该参数用于指定实施特定策略的用户匹配条件。 前提条件：该参数在“NOCSPLCY”配置为“YES”时为可选参数。 数据来源：整网规划 取值范围： “IMSAPN(IMS APN)”：表示用户签约支持IMS APN。“IMSCAP(IMSCAP)”：表示终端能力支持IMS。 系统初始设置值：IMSAPN-1&IMSCAP-1                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| NOCSFAKEACC | 无CS规划用户是否响应联合接入假成功    | 可选必选说明：条件可选参数 参数含义：该参数用于运营商未规划CS网络场景下，用户发起联合附着和联合TAU流程中CS注册受限后，MME是否向UE返回联合接入成功的Attach/TAU Accept消息。 前提条件：该参数在“NOCSPLCY”配置为“YES”时为可选参数。 数据来源：整网规划 取值范围： “YES(是)”“NO(否)” 系统初始设置值：“NO(否)”                                                                                                                                                                                                                                                                                                                                                                                                                                               |

| FAKELAIPLCY | 联合接入响应假成功时LAI填写策略     | 可选必选说明：可选参数 参数含义：该参数用于控制联合附着/TAU流程CS注册受限后，Attach Accept/TAU Accept按联合附着成功响应UE时携带的LAI策略。 数据来源：整网规划 取值范围： “TAILAI(TAI映射)” ：通过TAI映射。“FAKELAI(固定值)”：取配置的固定值。 系统初始设置值：TAILAI(TAI映射)  说明： 当取值为“TAILAI(TAI映射)”时，如果ADD TAILAI配置中没有匹配记录，不携带。如果ADD TAILAI配置中有匹配记录，且TAI映射的LAI不为全F并且和联合附着/TAU请求消息中携带的LAI不一致，取TAI映射的LAI值，否则不携带。                                                                                                                                                                                                                                                                                                                    |
| FAKELAI     | LAI固定填充值              | 可选必选说明：条件可选参数 参数含义：该参数用于控制联合附着/TAU流程CS注册受限后，Attach Accept/TAU Accept按联合附着成功响应UE时携带的LAI。 前提条件：该参数在“FAKELAIPLCY”配置为“FAKELAI”时为可选参数。 数据来源：整网规划 取值范围：9～10位的字符串 默认值：无 配置原则： LAI由MCC，MNC，LAC组成。MCC为3个BCD码字符，MNC为2个或者3个BCD码字符，填写时请遵循实际长度。LAC编码为16进制数，固定为4位，不足补0。LAI可以重复，一个LAI可对应多个TAI区间。                                                                                                                                                                                                                                                                                                                                                     |

#### 使用实例

1、存在CS规划的配置实例。

SET PSCSPLCY: COMACCSW=YES, COMACCCOND=IMSAPN-1&IMSCAP-1&STNSR-1, PRESTNSR="123456", SUBPLCY=HSS\_IDENT, COMATTSW=YES, COMTAUSW=YES, IMSPDNCOND=YES, ACCSUCC=YES, CSSRVPROC=NO, FAKELAIPLCY=TAILAI;

2、存在CS规划，并且当HSS故障时，用户也能够进入HSS Bypass状态，保证用户不会回落2/3G。

SET PSCSPLCY: COMACCSW=YES, COMACCCOND=IMSAPN-1&IMSCAP-1&STNSR-1, PRESTNSR="123456", SUBPLCY=HSS\_IDENT, COMATTSW=YES, COMTAUSW=YES, IMSPDNCOND=YES, ACCSUCC=YES, CSSRVPROC=NO, CSSRVHSS=YES, NOCSPLCY=NO, FAKELAIPLCY=TAILAI;

3、不存在CS规划的配置实例。

SET PSCSPLCY: COMACCSW=NO, NOCSPLCY=YES, NOCSIDENT=TAILAI, NOCSUEIDENT=IMSAPN-1&IMSCAP-1, NOCSFAKEACC=YES, NOCSSRVPROC=YES, FAKELAIPLCY=FAKELAI, FAKELAI="123031234";
