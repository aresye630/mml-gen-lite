# 查询授权服务（LST AUTHSERV）

#### 命令功能

**适用NF：UPF、MPF**

该命令用于查询授权服务信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                 |
|:------------|:-------|:---------------------------------------------------------------------------------------------------------------------|
| SERVICENAME | 授权服务名称 | 可选必选说明：可选参数 参数含义：该参数用于指定授权服务名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～127。该服务名称由服务提供商提供，可通过DSP MECSERVICE命令查询到。 默认值：无 配置原则：无 |

#### 使用实例

- 查询全部授权服务信息：

  ```
  LST AUTHSERV:;
  ```

  ```
  RETCODE = 0  操作成功

  授权服务
  --------
  授权服务名称    授权服务列表名称  授权有效时间的截止时间  

  app01_service1  serviceList       NULL                    
  app01_service2  serviceList       NULL                    
  (结果个数 = 2)

  ---    END
  ```
- 查询授权服务信息"app01\_service2"：

  ```
  LST AUTHSERV: SERVICENAME="app01_service2";
  ```

  ```
  RETCODE = 0  操作成功

  授权服务
  --------
            授权服务名称  =  app01_service2
        授权服务列表名称  =  serviceList
  授权有效时间的截止时间  =  NULL
  (结果个数 = 1)

  ---    END
  ```
