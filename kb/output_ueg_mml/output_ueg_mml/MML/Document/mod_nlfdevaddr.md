# 修改NLF设备地址(MOD NLFDEVADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改在配置数据库中的一条NLF设备地址信息数据记录。在该命令中，系统通过“设备地址标识”来唯一标识一条NLF设备地址信息数据记录。

## 注意事项

- NLF使用已配置的设备IP地址对外提供服务，如果修改该IP地址（不支持IPV4地址和IPV6地址互相修改），需检查该IP地址是否被使用，如果被使用，则不允许修改。如果未使用，则修改成功，NLF会使用新的设备IP地址对外提供服务。
- PMS/NTS/DRS/HLB/DLB/NLF/LDAP设备的IP地址（包括IPv4地址和IPv6地址）需要唯一，任意两种设备的IP地址不能重复。

## 使用实例

1. 修改IPv4类型的NLF设备地址信息，“设备地址标识”为“1”，“复用”为“NO(NO)”，“IP版本”为“IPV4(IPV4)”，“IPV4地址”为“10.168.0.132”。

   ```
   MOD NLFDEVADDR: DEVAID=1, REUSE=NO, IPVER=IPV4, IP="10.168.0.132";
   ```
2. 修改IPv6类型的NLF设备地址信息，“设备地址标识”为“2”，“复用”为“NO(NO)”，“IP版本”为“IPV6(IPV6)”，“IPV6地址”为“2001:0db8:4fff:ffff:ffff:ffff:ffff:ffff”。

   ```
   MOD NLFDEVADDR: DEVAID=2, REUSE=NO, IPVER=IPV6, IPV6="2001:0db8:4fff:ffff:ffff:ffff:ffff:ffff";
   ```
