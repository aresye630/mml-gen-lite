# 修改NTS VPN(MOD NTSVPN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改配置数据库中的一条NTS接入CSLB时业务IP的VPN数据记录。在该命令中，系统通过“VPN索引”参数来唯一标识一条NTS VPN数据记录。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                           |
|:------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| VPNINDEX    | VPN索引  | 可选必选说明：必选参数 参数含义：标识一条NTS接入CSLB时业务IP地址的VPN数据记录的关键字段（其取值不能被修改），用于指定需要对哪一条NTS VPN信息记录的参数进行修改或调整，操作员可以使用LST NTSVPN命令查询获得。 取值范围：0～15 默认值：无。 配置原则：无。 |
| VPNNAME     | VPN名称  | 可选必选说明：可选参数 参数含义：用于标识CSLB业务IP的VPN名称。 取值范围：长度不超过31的字符串 默认值：无。 配置原则：该参数取值需要与ADD L3VPNINST命令中“VPN实例名称”参数值保持一致。                                    |
| DESCRIPTION | 描述     | 可选必选说明：可选参数 参数含义：用于描述CSLB业务IP的VPN用途。 取值范围：长度不超过32的字符串 默认值：无。 配置原则：无。                                                                           |

## 使用实例

修改一条NTS VPN数据记录，“VPN索引”为“0”，“VPN名称”为“VPN\_2”。

```
MOD NTSVPN: VPNINDEX=0, VPNNAME="VPN_2";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                            | 原因分析                  | 处理建议                                                                                            |
|------:|:---------------------------------|:----------------------|:------------------------------------------------------------------------------------------------|
| 57911 | NTSVPN对象被NTSDEVADDR引用，不能修改VPN名称。 | 输入的“VPN索引”被NTS设备地址关联。 | 执行LST NTSDEVADDR命令查询全部NTS设备地址配置信息，记录已被关联的“VPN索引”。 执行本命令，重新设置“VPN索引”，并确保NTS VPN索引存在且未被NTS设备地址关联。 |
