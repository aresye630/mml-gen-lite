# 查询授权模式（LST MEPAUTHMODE）

#### 命令功能

**适用NF：UPF、MPF**

该命令用于查询APP授权模式。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询MEP授权模式：

```
LST MEPAUTHMODE:;
```

```
RETCODE = 0  操作成功

授权模式
--------
授权模式  =  APP描述文件配置模式
(结果个数 = 1)

---    END
```
