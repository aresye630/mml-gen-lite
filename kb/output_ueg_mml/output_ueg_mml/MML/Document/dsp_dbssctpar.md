# 查看SCTP偶联运行信息(DSP DBSSCTPAR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查看SCTP偶联运行信息。

若需要查询某条SCTP偶联运行信息，请输入参数“服务模块号”和“偶联号”。

## 注意事项

无。

## 参数说明

| 参数ID      | 参数名称   | 参数描述                                                                       |
|:----------|:-------|:---------------------------------------------------------------------------|
| SERVICENO | 服务模块号  | 可选必选说明：必选参数。 参数含义：用于请求系统显示哪个DBS服务的SCTP偶联运行信息。 取值范围： 1～1024 默认值： 无。 配置原则：无。 |
| AID       | 偶联号    | 可选必选说明：必选参数。 参数含义：请求系统显示哪个偶联号的SCTP偶联运行信息。 取值范围： 0～65534 默认值： 无。 配置原则：无。    |

## 使用实例

查看SCTP偶联运行信息，DBS服务模块号为102，偶联号为3。

```
DSP DBSSCTPAR: SERVICENO=102, AID=3;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称            | 输出项解释                                                                                                                |
|:-----------------|:---------------------------------------------------------------------------------------------------------------------|
| 偶联号              | SCTP偶联号码。                                                                                                            |
| 本端接收窗口大小         | 当前SCTP偶联本端接收窗口大小。 单位：字节                                                                                              |
| 待应答的数据块个数        | 当前SCTP偶联已发送并等待对端证实的数据块的数量。                                                                                           |
| 发送缓冲区占用比率        | 当前SCTP偶联发送缓冲区占用比率。                                                                                                   |
| 接收缓冲区占用比率        | 当前SCTP偶联接收缓冲区占用比率。                                                                                                   |
| 接收累计TSN          | 当前SCTP偶联对端接收的DATA数据块的累积传输顺序号。                                                                                        |
| 最近发送TSN          | 当前SCTP偶联本端最近发送的DATA数据块的传输顺序号。                                                                                        |
| 对端地址个数           | 当前SCTP偶联对端传送地址的数量。                                                                                                   |
| 对端IP地址           | 当前SCTP偶联在对端的IP地址。                                                                                                    |
| 对端IP状态           | 当前SCTP偶联对端的IP状态。 取值范围： 激活未激活                                                                                         |
| 对端IP地址上待应答的数据块个数 | 当前SCTP偶联已发送并等待对端每个IP地址证实的数据块的数量。                                                                                     |
| 拥塞窗口大小           | 当前SCTP偶联在该地址为避免网络拥塞而允许传输的最大消息流量。 当发送的消息流量大于该值时，就会出现网络拥塞。                                                             |
| 缓慢启动门限           | 慢启动阈值。 慢启动：当在一个状态不明的网络或者是空闲了相当长时间的网络上开始传送数据时，则要求SCTP去向网络探询一下以确定其可用的容量。出于这个目的，在开始传送数据时或者是对重发定时器检出的丢失消息进行重发时，就使用慢启动算法。 |
| 等候应答数据           | 当前SCTP偶联到达命令显示的IP地址并等待证实的数据总量。                                                                                       |
| 重传超时时间           | 当前SCTP偶联上所允许的消息连续重传的时间。 单位：毫秒                                                                                        |
| 双向传播时间           | SCTP偶联从消息发送到接收到对端确认消息的时间，该输出项的值表示当前网络的传输质量情况。 单位：毫秒                                                                  |
| 双向传播时间变化         | 当前SCTP偶联中消息双向传播时间与历史消息双向传播时间平均值的一个变化量，该输出项的值通过系统内部算法得出，表征当前网络的抖动状况。                                                  |
