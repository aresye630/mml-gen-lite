# 设置DBS服务参数(SET DBSSRVPARA)

- 注意事项

- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致业务呼损，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于设置DBS服务参数。

该命令的使用场景：在分组开关打开的情况下，使用该命令设置DBS服务参数，实现对DBS多应用共存的配置和维护功能。

## 注意事项

该命令只在分组开关打开的情况下，用来设置DBS服务参数，如果分组开关关闭，则使用**SET DBSSCTPPARA**命令设置“自动回切开关”参数的取值，使用**SET DBSLINKNUM**命令设置“链路数”。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                             |
|:------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 业务类型   | 可选必选说明：必选参数 参数含义：本参数用于定义DBS存在多应用的场景下，本端网元的某种业务类型。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：该参数为联想参数列表，不能手动输入，其取值为LST DBSSRVGROUP命令查询获得的“业务类型名称”输出参数。                                       |
| AUTOSWITCH  | 自动回切开关 | 可选必选说明：可选参数 参数含义：此参数用于控制USCDB主用局故障后，FE业务是否切到USCDB容灾局以及如果切到容灾局，USCDB主用局恢复后，FE业务是否自动回切到主用局。 取值范围：0～2 0：不自动回切1：自动回切2：强制不切换，即USCDB主用局故障后，FE业务不切到USCDB容灾局。 默认值：无。 配置原则：该参数的系统初始设置值为0。 |
| LINKNUM     | 链路数    | 可选必选说明：可选参数 参数含义：本参数用于设置DBS与BE之间的链路条数。 取值范围： 4～512，实际配置时33～511不能配置，512代表的是全互联。 默认值：无。 配置原则：该参数的系统初始设置值为8。                                                                        |

## 使用实例

设置“业务类型”为“SUP-FE”，“自动回切开关”为“1”，“链路数”为“6”的DBS服务参数：

```
SET DBSSRVPARA: SERVICETYPE="SUP-FE", AUTOSWITCH=1, LINKNUM=6;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 302532 | 输入的“业务类型”不属于业务分组内，请输入正确的“业务类型”参数。 | 输入的“业务类型”参数不在“业务分组”内。                    | 通过LST DBSSRVGROUP命令查询分组中的业务类型信息，确保输入的“业务类型”参数在业务分组内。                                           |
| 302533 | 分组开关未打开，不能输入与本网元类型不同的业务类型。        | 业务分组功能未打开，不能使用SET DBSSRVPARA命令设置DBS服务参数。 | 通过LST DBSGRPSWITCH命令查询分组开关是否打开，若未打开，可执行SET DBSSCTPPARA命令设置“自动回切开关”值，执行SET DBSLINKNUM命令设置“链路数”。 |
