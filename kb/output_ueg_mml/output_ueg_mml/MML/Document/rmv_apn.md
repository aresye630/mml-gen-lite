# 删除APN（RMV APN）

- 命令功能
- 注意事项

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响业务处理，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于从配置数据库中删除一条APN数据记录。

## 注意事项

- APN数据记录可以按照APNID删除，也可以按照APNID+APNNAME删除。
- APNID被PPCEFCAT引用后，不能删除该APNID记录。
- **VRM\_VIRTUALSUBIDSWITCH**取值为“1”时，不建议删除VoLTE-APN类型的APN配置。如果要删除配置，则需要在配置后清理Session备份数据，启动会话备份数据审计。
- **VRM\_DATAVIRTUALSUBIDSWITCH**取值为“1”时，不建议删除VoLTE-APN类型的APN配置。如果要删除配置，则需要在配置后清理Session备份数据，启动会话备份数据审计。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                             |
|:--------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PCRFID  | PCRF标识 | 用于标识PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围：1 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                          |
| APNID   | APN标识  | 用于设置APN索引标识。 取值范围：0～319 默认值：无。  说明： “APN类型”配置为非“Statistics-APN(Statistics-APN)”时，该参数的取值范围为0～15。“APN类型”配置为“Statistics-APN(Statistics-APN)”时，该参数的取值范围为0～319。                                                                                                                                                                                                                                                                                       |
| APNNAME | APN名称  | 用于定义APN的取值。 取值范围：1～64字节的字符串。 默认值：无。  说明： 业务处理时，对APN大小写不敏感。即小写或者大写表示的APN的含义相同，例如“abc”和“ABC”，都表示APN的值为“ABC”。“APN类型”配置为非“Statistics-APN(Statistics-APN)”“Force-Sy-APN”、“Ignore-SPR-APN”或“Realm-Replace-APN”时，1个“APN标识”最多支持配置20个“APN名称”，即1个“APN标识”下最大支持配置20个APN信息，这些APN信息的“APN类型”必须一样。“APN类型”配置为“Statistics-APN(Statistics-APN)”时，1个“APN标识”只支持配置1个“APN名称”。“APN类型”配置为“Force-Sy-APN”、“Ignore-SPR-APN”或“Realm-Replace-APN”时，1个“APN标识”最多支持配置320个“APN名称”。 |

## 使用实例

删除APN数据记录。APN标识为0。

```
RMV APN: PCRFID=1, APNID=0, APNNAME="CMIMS";
```
