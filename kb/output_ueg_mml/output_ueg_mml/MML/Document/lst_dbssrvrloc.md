# 查询DBS应用类型远端Location信息（LST DBSSRVRLOC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询在FE侧配置的业务类型远端网元的优先级。

- 若需要查询全部业务类型远端网元的优先级，不需要输入参数。
- 若需要查询某个业务类型远端网元的优先级，请输入“业务类型”或其它参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称          | 参数说明                                                                                                                                                                       |
|:------------|:--------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 业务类型          | 可选必选说明：可选参数 参数含义：用于指示系统按照业务类型来查询远端网元的优先级；若不输入，则表示所有的业务类型。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                                                                                |
| RLOCID      | 远端Location标识  | 可选必选说明：必选参数 参数含义：用于指示系统按照远端Location标识来查询远端网元的优先级；若不输入，则表示所有的远端Location标识。 取值范围：1～512。 默认值：无。 配置原则：无。                                                                       |
| LP          | 远端location优先级 | 可选必选说明：必选参数 参数含义：用于指示系统按照远端Location优先级来查询远端网元的优先级；若不输入，则表示所有的远端Location优先级。 取值范围：1～512。 默认值：无。 配置原则：设置的优先级值越小，则其优先级越高。如果一个本端网元设备对应多个远端网元设备，则本端网元会按照优先级从高到低的顺序选择远端网元设备进行访问。 |

## 使用实例

查询全部业务类型远端网元的优先级：

```
LST DBSSRVRLOC:;
```

```
%%LST DBSSRVRLOC:;%%
RETCODE = 0  操作成功

操作结果如下
------------------------
业务类型      远端Location标识    远端location优先级   
SUP-FE        5                   1     
SUP-FE        6                   2     
(结果个数 = 2)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
