# 查询远端服务器组配置(LST HTTPRSRVGRP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询远端服务器组配置。

- 若需要查询所有远端服务器组配置，请不输入任何参数。
- 若需要查询某个远端服务器组配置，请输入“远端服务器组名”。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                        |
|:------------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------|
| RSRVGRPNAME | 远端服务器组名 | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个远端服务器组名来查询远端服务器组配置；若不输入，则表示查询所有的远端服务器组配置。 取值范围：长度不超过128的由数字和字母组成的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询所有的远端服务器组配置：

   ```
   LST HTTPRSRVGRP:;
   ```

   ```
   %%LST HTTPRSRVGRP:;%% 
   RETCODE = 0  操作成功

   远端服务器组名  对端类型  远端服务器选择模式  远端服务器组在联动倒换中的比例(%)
   a               NEF       优先级方式          0          
   aaa             NRF       优先级方式          0           
   b               AMF       优先级方式          0           
   bbb             AMF       优先级方式          0           
   c               SMF       优先级方式          0           
   ccc             AMF       优先级方式          0          
              
   (结果个数 = 6)  

   ---    END
   ```
2. 查询指定远端服务器组名的远端服务器组配置；

   ```
   LST HTTPRSRVGRP: RSRVGRPNAME="aaa";
   ```

   ```
   %%LST HTTPRSRVGRP: RSRVGRPNAME="aaa";%% 
   RETCODE = 0  操作成功

                      远端服务器组名  =  aaa
                            对端类型  =  NEF 
                  远端服务器选择模式  =  优先级方式 
   远端服务器组在联动倒换中的比例(%)  =  0
   (结果个数 = 1)  

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**LST HTTPRSRVGRP**命令的参数说明。
