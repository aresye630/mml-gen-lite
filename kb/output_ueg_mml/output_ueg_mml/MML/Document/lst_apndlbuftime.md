# 查询APN的下行数据缓存时长配置（LST APNDLBUFTIME）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

此命令用来查询APN下的普通用户下行报文缓存时长。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                    |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN    | APN    | 可选必选说明：可选参数 参数含义：该参数用于指定APN实例名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。 默认值：无 配置原则：该参数使用ADD UPAPN命令配置生成。 |

#### 使用实例

查询APN apn1.com下的普通用户下行报文缓存时长：

```
LST APNDLBUFTIME: APN="apn1.com";
```

```

```
