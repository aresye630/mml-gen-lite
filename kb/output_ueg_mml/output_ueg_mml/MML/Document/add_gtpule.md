# 增加GTP-U本地实体(ADD GTPULE)

#### 命令功能

**适用网元：SGSN、MME**

该命令用于增加GTPU本地实体。

本命令与**ADD GTPUINTFATTR**命令组合，满足各种GTPU接口的组网部署。

#### 注意事项

- 本命令执行后立即生效。
- 系统最多支持256个GTPU本端实体记录。
- GTPU本端实体最多支持32个不同的IPv4地址，以及32个不同的IPv6地址。
- 不同组号内的IP地址允许相同，同一个组号内的IP地址不允许相同。
- 一个组号下最多支持8个IPv4地址，以及8个IPv6地址。
- IP地址和vpn名称必须在SERVICEIP中配置，可以用**LST SERVICEIP**查询。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                   |
|:--------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GROUPID | 组号     | 可选必选说明：可选参数 参数含义：本参数用于指定GTPU本端实体对应的组号。组号用于组网规划时不同接口，或者不同用户范围使用独立的GTPU本端实体。 数据来源：全网规划 取值范围：0~32 默认值：0 配置原则：Iu接口GTPU IP的组号必须设为32。  说明： 如果添加非0组号且非32组号的GTPU本端实体，则需要同步增加ADD GTPUINTFATTR配置。组号的应用参考ADD GTPUINTFATTR命令帮助。                                                                                    |
| IPTYPE  | IP地址类型 | 可选必选说明：必选参数 参数含义：本参数用于指定GTPU本端实体的IP地址类型。 数据来源：全网规划 取值范围：“TPTADDR_TYPE_IPV4(IPV4)”“TPTADDR_TYPE_IPV6(IPV6)” 默认值：无                                                                                                                                                                                       |
| LEIPV4  | IPv4地址 | 可选必选说明：条件必选参数 参数含义：本参数用于指定GTPU本端实体的IPv4地址。 前提条件：该参数在“IP地址类型”参数配置为“TPTADDR_TYPE_IPV4(IPV4)”后生效。 数据来源：全网规划 取值范围：0.0.0.0~255.255.255.255 默认值：无 配置原则：业务地址不能配置为0.0.0.0、255.255.255.255和环回地址(127.x.y.z)。业务地址必须是A、B或者C类地址。如果添加的地址和CHGCDPIP对象的IP地址相同，且IP地址对应的CHGCDPIP对象记录中端口范围包含3386，则不允许添加，可以用LST CHGCDPIP查询。 |
| LEIPV6  | IPv6地址 | 可选必选说明：条件必选参数 参数含义：本参数用于指定GTPU本端实体的IPv6地址。 前提条件：该参数在“IP地址类型”参数配置为“TPTADDR_TYPE_IPV6(IPV6)”后生效。 数据来源：全网规划 取值范围：::~FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 配置原则：IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址(::1)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。                          |
| VPNNAME | VPN名称  | 可选必选说明：可选参数 参数含义：本参数用于指定GTPU本端实体对应的VPN名称。 数据来源：全网规划 取值范围：0~31位字符串 默认值：无                                                                                                                                                                                                                                |
| DESC    | 描述信息   | 可选必选说明：可选参数 参数含义：本参数用于指定描述信息。 数据来源：全网规划 取值范围：0~32位字符串 默认值：无                                                                                                                                                                                                                                            |

#### 使用实例

增加“组号”为“2”，“IPv4地址”为“192.168.1.24”的本地实体：

ADD GTPULE: GROUPID=2, IPTYPE=TPTADDR\_TYPE\_IPV4, LEIPV4="192.168.1.24";
