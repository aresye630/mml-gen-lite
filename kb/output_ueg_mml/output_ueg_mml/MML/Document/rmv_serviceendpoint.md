# 删除服务端点（RMV SERVICEENDPOINT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

该命令用于删除服务端点。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                            |
|:-------------|:-------|:----------------------------------------------------------------------------------------------------------------|
| ENDPOINTNAME | 服务端点名称 | 可选必选说明：必选参数 参数含义：该参数用于指定服务端点名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“_”组成，且只能以字母或者数字开头。 默认值：无 配置原则：无 |

#### 使用实例

删除SERVICEENDPOINT对象，删除的SERVICEENDPOINT对象名称为"service\_endpoint"：

```
RMV SERVICEENDPOINT: ENDPOINTNAME="service_endpoint";
```
