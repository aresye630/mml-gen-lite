# 显示CUS服务信息（DSP CUSSTAT）

## 命令功能

该命令用于查询CUS服务实例的状态。

该命令的使用场景：

- 维护场景**：**当需要定位问题时，可通过此命令查询CUS服务实例的状态信息。
- 升级场景**：**升级前可以通过此命令检查服务实例的状态，仅状态为“STARTED”时可进行升级。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                          |
|:--------|:-------|:--------------------------------------------------------------|
| PODNAME | POD名称  | 可选必选说明：可选参数。 参数含义：用于请求系统按照指定POD名称显示服务实例状态信息；若不输入，则表示所有的POD名称。 |
| INSTID  | 实例标识   | 可选必选说明：可选参数。 参数含义：用于请求系统按照指定服务实例标识显示服务实例状态信息；若不输入，则表示所有的实例标识。 |

## 使用实例

查询所有微服务实例的状态信息：

```
DSP CUSSTAT:;
```

```
%%DSP CUSSTAT:;%% 
RETCODE = 0  操作成功  

操作结果如下 
------------------------ 
POD名称                           实例标识              实例状态    
cuservice-pod23-6fccb86c54-9s4tk  12201171390267047474  主用状态       
cuservice-pod23-6fccb86c54-f88bn  12201171390266915348  备用状态        
(结果个数 = 2)  

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称   | 输出项解释                                                           |
|:--------|:----------------------------------------------------------------|
| POD名称   | 用于表示服务实例所属的POD名称。                                               |
| 实例标识    | 用于表示实例标识，实例标识在Location内唯一。                                      |
| 实例状态    | 用于表示服务实例当前的状态，当服务实例处于“主用状态”或“备用状态”时，可对外承接业务。 取值范围： 无效状态备用状态主用状态 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释   | 原因分析    | 处理建议       |
|------:|:--------|:--------|:-----------|
| 67779 | 未知错误。   | 系统内部错误。 | 请联系华为技术支持。 |
