# 查询M2M服务器组绑定关系（LST M2MSVRGRPBIND）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SMF**

命令是用来查询指定APN实例下绑定M2M服务器组。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识      | 参数名称      | 参数说明                                                                                                                                                                                                                           |
|:----------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GROUPNAME | M2M服务器组名称 | 可选必选说明：可选参数  参数含义：该参数用于指定M2M服务器组的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。不区分大小写，不支持空格。  默认值：无  配置原则：  该参数使用ADD CPM2MSERVERGRP命令配置生成。                                                                                            |
| APN       | APN名称     | 可选必选说明：可选参数  参数含义：该参数用于指定APN实例名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”特殊字符，不区分大小写。  默认值：无  配置原则：  该参数使用ADD CPAPN命令配置生成。 |

## 使用实例

查询指定的APN与M2M服务器组的绑定信息，APN为isp：

```
%%LST M2MSVRGRPBIND: APN="isp";%%
RETCODE = 0  操作成功

结果如下
--------
M2M服务器组名称  =  m2msrvgroup01
        APN名称  =  isp
      UPF组名称  =  NULL
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称     | 输出项解释              |
|:----------|:-------------------|
| M2M服务器组名称 | 该参数用于指定M2M服务器组的名称。 |
| APN名称     | 该参数用于指定APN实例名称。    |
| UPF组名称    | 该参数用于指定UPF组的名称。    |
