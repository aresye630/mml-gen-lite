# 设置SBI接口TCP配置(SET SBITCPCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于设置SBI接口TCP配置参数。

## 注意事项

在缺省的情况下，系统在初始化时已经在配置数据库中预置了该命令的参数信息，参数“SYN消息流控阈值”取值为“0”，参数“单IP连接限制数”取值为“0”。

## 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                                      |
|:-----------|:----------|:----------------------------------------------------------------------------------------------------------|
| ID         | ID        | 可选必选说明：必选参数 参数含义：用于设置SBI接口TCP参数的记录标识。 取值范围：1 默认值：无。 配置原则：无。                                               |
| SYNTHD     | SYN消息流控阈值 | 选必选说明：可选参数 参数含义：该参数用于设置单个HLB实例每秒可处理的SYN消息的阈值。 取值范围：0~100000 默认值：无。 配置原则：无。  说明： 该参数取值为“0”时表示不进行流控。        |
| LINKOFNFIP | 单IP连接限制数  | 选必选说明：可选参数 参数含义：该参数用于设置一个NF IP和单个HLB服务的最大HTTP链路数。 取值范围：0~1024 默认值：无。 配置原则：无。  说明： 该参数取值为“0”时表示不限制HTTP链路数。 |

## 使用实例

设置SBI接口TCP配置。“SYN消息流控阈值”为“1024”，“单IP连接限制数”为“1024”。

```
SET SBITCPCFG: ID=1, SYNTHD=1024, LINKOFNFIP=1024;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
