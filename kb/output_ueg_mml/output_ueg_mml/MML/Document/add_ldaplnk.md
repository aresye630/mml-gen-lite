## 命令功能

**须知** 

LDAP链路推荐使用TLS协议进行安全传输对接。

该命令用于在配置数据库中增加一条LDAP服务与外置SPR（Subscription Profile Repository）数据库的链路数据记录。在该命令中，“对端IPV4地址”、“对端端口”、“用户名”和“密码”参数的配置需要与外置SPR协商。

该命令的使用场景：

当运营商的一些数据信息（例如全部用户数据和签约数据）存储在外置SPR时，UPCF支持通过基于LDAP协议的Sp接口与外置SPR对接，从而获取用户数据。

获取用户数据前，必须配置UPCF与外置SPR的对接数据。操作员可通过执行本命令增加UPCF与外置SPR之间的链路。

## 注意事项

- IPv4类型的IP地址不能配置如下非法IP地址：“127.0.0.1”、“0.0.0.0”、“255.255.255.255”、“224.0.0.1”。
- 当TLS功能设置为“ON(打开)”时，LDAP服务性能将会下降20%，如需开启请联系华为技术支持。
- “TLS\_AES\_128\_CCM\_8\_SHA256(TLS\_AES\_128\_CCM\_8\_SHA256)”参数值属于不安全加密套件，建议使用其他安全加密套件。

| CERTSCENE | 证书应用场景   | 可选必选说明：条件必选参数 参数含义：表示注册LDAP服务的TLS证书应用场景，仅当“TLS功能”配置为“ON(打开)”时该参数可配置且必须配置。 取值范围：UPCF_LDAP_certForLDAPLNK(LDAP接口链路客户端证书) 默认值：无。 配置原则：无。  说明： 证书应用场景下关联的证书文件，必须是CA证书文件。                                                                                                                                                                                                                                                              |

| TLSCFGID  | TLS配置ID  | 可选必选说明：条件必选参数 参数含义：用于在配置库中定义一条TLS配置记录，取值不能重复。仅当“TLS功能”配置为“ON(打开)”时该参数可配置且必须配置。 取值范围：1～128 默认值：无。 配置原则：本参数可通过执行ADD COMTLSCFG命令进行配置。                                                                                                                                                                                                                                                                                                |

## 使用实例

增加一条LDAP链路配置信息的数据记录，“链路ID”为“4”，“链路名称”为“LDAPNAME”，“IP版本”为“IPV4(IPV4)”，“本端IPV4地址”为“10.168.0.130”，“本端端口”为“2020”，“对端IPV4地址”为“10.85.52.32”，“对端端口”为“2030”，“用户名”为“upcf”，“密码”为“\*\*\*\*\*\*”，“确认密码”为“\*\*\*\*\*\*”，“数据源优先级”为“1”，“链路管理状态”为“ENABLE(使能)”，“TLS功能”为“ON(打开)”，“证书应用场景”为“UPCF\_LDAP\_certForLDAPLNK(LDAP接口链路客户端证书)”，“CRL策略”为“Check(检查)”。

```
ADD LDAPLNK: LINKID=4, LNKNAME="LDAPNAME", IPVER=IPV4, LOCALIP="10.168.0.130", LOCALPORT=2020, PEERIP="10.85.52.32", PEERPORT=2030, USERNAME="upcf", PWD="*****", CFM="*****", DSPRI=1, ADSTS=ENABLE, TLSFUNC=ON, CERTSCENE=UPCF_LDAP_certForLDAPLNK, CRLPOLICY=Check;
```

**说明** 

密码在命令行输入区域显示为\*\*\*\*\*。
