#### 命令功能

**适用网元：MME**

该命令用于设置P-GW Back-off流控功能的相关参数。MME支持基于P-GW Back-off timer的APN级流控功能会使用到本命令。

#### 注意事项

- 该命令执行后立即生效。
- 此配置涉及WSFD-215201 基于延迟定时器的信令拥塞控制特性，license部件编码：LKV2LTCC01，请在设置参数前使用**DSP LICENSE**命令确认对应特性license是否得到授权，执行**LST LICENSESWITCH**命令确认特性开关状态为“ENABLE(打开)”。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                                                                                                 |
|:-----------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FCSWITCH   | 流控开关    | 可选必选说明：可选参数 参数含义：本参数用于指定是否开启P-GW Back-off流控功能。 数据来源：本端规划 取值范围：“OFF(关)”“ON(开)” 系统初始设置值：“OFF(关)”。 配置原则：基于延迟定时器的信令拥塞控制特性依赖于网关下发的P-GW Back-off Timer信元，需要MME和网关同时开启才能使用。 |
| APNNIGRPID | APNNI组号 | 可选必选说明：条件必选参数 参数含义：本参数用户设置支持P-GW Back-off APN流控的APNNI组号。 前提条件:本参数在“流控开关”参数配置为“ON(开)”后生效。 数据来源：本端规划 取值范围：0～15 系统初始设置值：无 配置原则：组号需要引用ADD APNNIGROUP命令中已配置的组号。           |
| PGWGRPID   | P-GW组号  | 可选必选说明：条件必选参数 参数含义：本参数用于表示用户设置支持P-GW Back-off APN流控的P-GW组号。 前提条件: 本参数在“流控开关”参数配置为“ON(开)”后生效。 数据来源：本端规划 取值范围：0～15 系统初始设置值：无 配置原则：组号需要引用ADD PGWGROUP命令中已配置的组号。         |

#### 使用实例

启用信令拥塞控制功能时，设置流控功能的相关参数。设置“流控开关”参数为“ON(开)”、“APNNI组号”参数为“2”，“P-GW组号”参数为“2”。运行如下命令：

SET PGWBACKOFF: FCSWITCH=ON, APNNIGRPID=2, PGWGRPID=2;
