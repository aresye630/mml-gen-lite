# 开始HTTP软件调试(STR HTTPSFTD)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致业务处理受损，需联系华为技术支持确认后再执行。

本命令用于HLB服务的软件调试。

该命令的使用场景：在日常操作维护中，操作员可根据实际需要使用该命令设置调试操作类型，以便进行问题定位。

## 注意事项

- 该命令正在执行中，未完成操作结果输出时，无法重新执行该命令。
- 在该命令中，以下关键参数需要与对端服务器协商：
  - “对端IPV4地址”
  - “对端IPV6地址”
  - “对端端口号”

## 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                                                                                                                                                                                                            |
|:-------------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INSTANCENO   | 服务实例ID   | 可选必选说明：可选参数 参数含义：用于指定HLB服务的实例号。 取值范围：长度不超过256的字符串。 默认值：无。 配置原则：无。  说明： 执行该命令时，如果输入的“服务实例ID”不存在，则仅返回操作成功，不打印统计项日志信息。                                                                                                                                                             |
| CMDTYPE      | 命令类型     | 可选必选说明：必选参数 参数含义：用于指定调试操作的命令类型。 取值范围： STAT_TYPE(统计类型)：用于指定调试操作的统计类型。 默认值：无。 配置原则：无。                                                                                                                                                                                             |
| STATTYPE     | 统计类型     | 可选必选说明：条件必选参数 参数含义：用于指定调试操作的统计类型。仅当“命令类型”选择“STAT_TYPE(统计类型)”时，该参数必选。 取值范围： ALL_STAT(打印所有统计信息)REQ_STAT(打印请求统计信息)ABNL_REQ_STAT(打印异常请求统计信息)CONN_STAT(打印链路统计信息)CONN_INTERNAL_STAT(打印链路内部统计信息)EXCEPTION_STAT(打印异常统计信息)RESOURCE_STAT(打印资源统计信息)MEM_POOL_STAT(打印内存池统计信息) 默认值：无。 配置原则：无。 |
| RESOURCETYPE | 资源类型     | 可选必选说明：条件可选参数 参数含义：用于指定调试操作的资源类型。仅当“统计类型”选择“RESOURCE_STAT(打印资源统计信息)”时，该参数可选。如果不设置该参数取值，则打印所有资源类型的统计信息；如果设置该参数取值，则打印指定资源类型的统计信息。 取值范围： REQCB(打印请求控制块统计信息)CONNCB(打印链路控制块统计信息)TLS_CTX(打印TLS统计信息)USR_TIMER(打印用户定时器统计信息)RES_ALL(打印所有资源统计信息) 默认值：无。 配置原则：无。                           |
| IPVER        | IP版本     | 可选必选说明：条件可选参数 参数含义：用于指定本端和对端的IP地址版本。仅当“统计类型”选择“CONN_INTERNAL_STAT(打印链路内部统计信息)”时，该参数可选。 取值范围： IPV4(IPV4) IPV6(IPV6) 默认值：无。 配置原则：无。                                                                                                                                               |
| LOCALIP      | 本端IPV4地址 | 可选必选说明：条件可选参数 参数含义：表示本端与对端设备对接的参数之一，用于指定链路使用的本端IPV4地址。仅当“IP版本”选择“IPV4(IPV4)”时，该参数可选。 取值范围：IPV4格式的地址。 默认值：无。 配置原则：此IP地址必须是本地实际的IP地址且必须先由ADD HLBDEVADDR命令定义，然后才能在此处引用。                                                                                                            |
| LOCALIPV6    | 本端IPV6地址 | 可选必选说明：条件可选参数 参数含义：表示本端与对端设备对接的参数之一，用于指定链路使用的本端IPV6地址。仅当“IP版本”选择“IPV6(IPV6)”时，该参数可选。 取值范围：IPV6格式的地址。 默认值：无。 配置原则：此IP地址必须是本地实际的IP地址且必须先由ADD HLBDEVADDR命令定义，然后才能在此处引用。                                                                                                            |
| LOCALPORT    | 本端端口号    | 可选必选说明：条件可选参数 参数含义：表示本端与对端设备对接的参数之一，用于指定链路使用的本端端口号。仅当“统计类型”选择“CONN_INTERNAL_STAT(打印链路内部统计信息)”时，该参数可选。 取值范围：1～65535 默认值：无。 配置原则：无。                                                                                                                                               |
| PEERIP       | 对端IPV4地址 | 可选必选说明：条件可选参数 参数含义：表示本端与对端设备对接的参数之一，用于指定链路使用的对端IPV4地址。仅当“IP版本”选择“IPV4(IPV4)”时，该参数可选。 取值范围：IPV4格式的地址。 默认值：无。 配置原则：此IP地址需要与对端协商一致。                                                                                                                                                |
| PEERIPV6     | 对端IPV6地址 | 可选必选说明：条件可选参数 参数含义：表示本端与对端设备对接的参数之一，用于指定链路使用的对端IPV6地址。仅当“IP版本”选择“IPV6(IPV6)”时，该参数可选。 取值范围：IPV6格式的地址。 默认值：无。 配置原则：此IP地址需要与对端协商一致。                                                                                                                                                |
| PEERPORT     | 对端端口号    | 可选必选说明：条件可选参数 参数含义：表示本端与对端设备对接的参数之一，用于指定链路使用的对端端口号。 仅当“统计类型”选择 “CONN_INTERNAL_STAT(打印链路内部统计信息)”时，该参数可选。 取值范围：1～65535 默认值：无。 配置原则：此IP端口号需要与对端协商一致。                                                                                                                               |

## 使用实例

1. 打印一条链路内部统计信息。

   ```
   STR HTTPSFTD: INSTANCENO="1", CMDTYPE=STAT_TYPE, STATTYPE=CONN_INTERNAL_STAT, IPVER=IPV4, LOCALIP="192.168.0.130", LOCALPORT=1, PEERIP="10.173.7.128", PEERPORT=2;
   ```
2. 打印一条资源统计信息。

   ```
   STR HTTPSFTD: INSTANCENO="2", CMDTYPE=STAT_TYPE, STATTYPE=RESOURCE_STAT, RESOURCETYPE=REQCB;
   ```
