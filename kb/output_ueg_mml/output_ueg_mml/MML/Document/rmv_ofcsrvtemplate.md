# 删除离线业务模板（RMV OFCSRVTEMPLATE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用来删除离线业务模板的配置。

#### 注意事项

- 该命令执行后立即生效。
- 该命令只对新业务生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                     |
|:-------------|:--------|:-----------------------------------------------------------------------------------------|
| TEMPLATENAME | 离线业务模板名 | 可选必选说明：必选参数 参数含义：该参数用于指定离线业务模板名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不允许输入空格。 默认值：无 配置原则：无 |

#### 使用实例

删除名为“offlinetmp”的离线业务模板：

```
RMV OFCSRVTEMPLATE:TEMPLATENAME="offlinetmp";
```
