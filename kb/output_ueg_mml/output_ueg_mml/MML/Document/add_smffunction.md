# 添加SMF功能实例信息（ADD SMFFUNCTION）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于添加SMF功能实例信息。

## 注意事项

- 该命令执行后立即生效。

- 该命令当前版本仅支持配置1条记录，否则会影响北向功能。

- 最多可输入100条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                                                                                |
|:---------------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INSTANCEID     | NF实例号    | 可选必选说明：必选参数  参数含义：NF实例号。用于SMF与北向网管对接使用，通过NFInstance ID可以实现与北向网管上与网元的话统、告警信息的关联。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~40。  默认值：无  配置原则：  该参数需要根据北向网管的要求来填写，例如，填写为在MANO上创建VNF时的InstanceID。 |
| NAME           | NF功能实例描述 | 可选必选说明：可选参数  参数含义：NF功能实例描述。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~64。  默认值：无  配置原则：无                                                                                                      |
| ADMINSTATE     | 管理状态     | 可选必选说明：可选参数  参数含义：管理状态。  数据来源：本端规划 取值范围： Locked（锁定）Unlocked（未锁定）ShuttingDown（关机）  默认值：Unlocked  配置原则：无                                                                              |
| OPERATIONSTATE | 运行状态     | 可选必选说明：可选参数  参数含义：运行状态。  数据来源：本端规划 取值范围： Enabled（运行）Disabled（不运行）  默认值：Enabled  配置原则：无                                                                                              |
| FQDN           | FQDN     | 可选必选说明：可选参数  参数含义：FQDN。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~255。该参数只能由字母（A-Z或者a-z）、数字（0-9）、连字符（-）和点（.）组成，大小写不敏感，FQDN不能以“.”开始，也不能以“.”结束。  默认值：无  配置原则：无                                  |
| MAXPDUSESSIONS | 最大PDU会话数 | 可选必选说明：可选参数  参数含义：最大PDU Session数。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无                                                                                           |
| MAXQFI         | 最大QFI数   | 可选必选说明：可选参数  参数含义：最大QFI数。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无                                                                                                   |

## 使用实例

新增SMF功能实体号为Instanceid01,SMF功能实体描述为nfdescription01,管理状态为Locked,运行状态为Enabled,FQDN为fqdn01的SMF功能实例信息：

```
ADD SMFFUNCTION: INSTANCEID="Instanceid01", NAME="nfdescription01", ADMINSTATE=Locked, OPERATIONSTATE=Enabled, FQDN="fqdn01";
```
