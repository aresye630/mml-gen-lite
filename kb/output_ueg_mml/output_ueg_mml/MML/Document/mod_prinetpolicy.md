# 修改专网控制策略（MOD PRINETPOLICY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用来修改UAC功能开关。

#### 注意事项

该命令执行后只对新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                                                                                                |
|:---------------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN            | APN名称    | 可选必选说明：必选参数 参数含义：该参数用于指定APN实例名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。 默认值：无 配置原则：无 |
| DNAI           | 数据网络接入标识 | 可选必选说明：可选参数 参数含义：该参数用于指定数据网络接入标识。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。名称中不能包含空格，不区分大小写。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。                                                                                   |
| SINGLENETACCSW | 单网通功能开关  | 可选必选说明：必选参数 参数含义：该参数用于配置是否使能单网通功能。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无                                                                                                         |

#### 使用实例

修改专网控制策略开关：

```
MOD PRINETPOLICY: APN="test1", DNAI="123456", SINGLENETACCSW=ENABLE;
```
