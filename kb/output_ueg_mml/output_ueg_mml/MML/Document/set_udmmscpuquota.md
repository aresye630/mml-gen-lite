## 命令功能

**须知** 

- 本命令属于高危命令，执行不当会造成系统流控、上报CPU过载告警等异常，需要与华为技术支持确认后才可以实施。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于设置UDM微服务的进程CPU配额。

通过该命令设置的CPU配额可以计算出CPU利用率，CPU利用率=（绝对CPU/CPU配额）\*100%，当CPU利用率超过由****SET UDMMSCPUTHD****设置的阈值时，则产生**微服务进程CPU过载**告警。

## 注意事项

- 在缺省的情况下，系统初始化的时候已经在配置数据库中预置了各服务的CPU配额，可以通过**LST UDMMSCPUQUOTA**命令查询。
- 一般情况下不需要对微服务CPU配额进行配置，如果根据实际情况确实需要对CPU配额进行修改，配置不当会造成CPU过载告警上报和恢复异常，请谨慎配置。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ST       | 服务类型   | 可选必选说明：必选参数 参数含义：用于标识需要设置CPU配额的服务类型。 取值范围：UdmAppCtrlService(UdmAppCtrlService)NRFClient(NRFClient)HttpDisCtrlService(HttpDisCtrlService)UdmSubService(UdmSubService)UdmAuthService(UdmAuthService)EnumService(EnumService) 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                        |
| CPUQUOTA | CPU配额  | 可选必选说明：必选参数 参数含义：用于标识服务CPU配额。 取值范围：100～1600 默认值：各个服务的CPU配额的默认值如下所示。 当“服务类型”参数为“UdmAppCtrlService(UdmAppCtrlService)”时: 100当“服务类型”参数为“NRFClient(NRFClient)”时: 100当“服务类型”参数为“HttpDisCtrlService(HttpDisCtrlService)”时: 100当“服务类型”参数为“UdmSubService(UdmSubService)”时: 600当“服务类型”参数为“UdmAuthService(UdmAuthService)”时: 600当“服务类型”参数为“EnumService(EnumService)”时: 100 说明： 在x86_7285场景下参数调整为： 当“服务类型”参数为“UdmSubService(UdmSubService)”时: 1200当“服务类型”参数为“UdmAuthService(UdmAuthService)”时: 1200 配置原则：无。 |

## 使用实例

在维护场景中，修改UDM微服务的进程CPU配额，“服务类型”为“NRFClient(NRFClient)”，“CPU配额”为“150”：

```
SET UDMMSCPUQUOTA: ST=NRFClient, CPUQUOTA=150;
```
