# 删除SOAP对端(RMV SOAPPE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除系统中的一条SOAP对端记录。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                        |
|:-------|:---------|:------------------------------------------------------------|
| ID     | SOAP对端标识 | 可选必选说明：必选参数 标识SOAP对端标识的关键字段，用于指定删除哪一条SOAP对端标识记录。 取值范围：1～255 |

## 使用实例

删除一条“SOAP对端标识”为“1”的记录：

```
RMV SOAPPE: ID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释               | 原因分析                                                   | 处理建议                                                                                                                 |
|-------:|:--------------------|:-------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------|
| 360260 | 当前SOAP对端标识被引用，不能删除。 | 待删除的“SOAP对端标识”在ADD SOAPPEADDR或LST HDFCPOL命令中被引用，不可以删除。 | 执行LST SOAPPEADDR命令和LST HDFCPOL查询被引用的“SOAP对端标识”，然后执行LST SOAPPE命令查询已配置的“SOAP对端标识”，输入已配置且未被引用的“SOAP对端标识”ID，重新执行本命令进行删除。 |
