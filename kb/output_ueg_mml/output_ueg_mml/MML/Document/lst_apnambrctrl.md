# 查询APN-AMBR控制的配置（LST APNAMBRCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：GGSN、SMF、PGW-C**

该命令用来查询APN-AMBR控制的配置。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称              | 参数说明                                                                                                                                              |
|:---------|:------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
| CTRLTYPE | 控制类型              | 可选必选说明：可选参数  参数含义：该参数用于指定QoS控制的类型。  数据来源：全网规划 取值范围： APN_LEVEL（APN级别）GLOBAL_LEVEL（整系统级别）  默认值：无  配置原则：无                                            |
| APN      | APN               | 可选必选说明：该参数在"CTRLTYPE"配置为"APN_LEVEL"时为条件可选参数。  参数含义：该参数用于指定APN实例名。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~63。不区分大小写。  默认值：无  配置原则：  该参数使用ADD CPAPN命令配置生成。 |
| AMBRUL   | 上行APN-AMBR(千比特/秒) | 可选必选说明：可选参数  参数含义：该参数用于指定组成QoS控制的上行APN-AMBR。  数据来源：全网规划  取值范围：整数类型，取值范围是0~20000000。  默认值：无  配置原则：无                                                |
| AMBRDL   | 下行APN-AMBR(千比特/秒) | 可选必选说明：可选参数  参数含义：该参数用于指定组成QoS控制的下行APN-AMBR。  数据来源：全网规划  取值范围：整数类型，取值范围是0~20000000。  默认值：无  配置原则：无                                                |

## 使用实例

查询所有APNAMBRCTRL配置：

```
LST APNAMBRCTRL:;
```

## 输出结果说明

| 输出项名称             | 输出项解释                      |
|:------------------|:---------------------------|
| 控制类型              | 该参数用于指定QoS控制的类型。           |
| APN               | 该参数用于指定APN实例名。             |
| 上行APN-AMBR(千比特/秒) | 该参数用于指定组成QoS控制的上行APN-AMBR。 |
| 下行APN-AMBR(千比特/秒) | 该参数用于指定组成QoS控制的下行APN-AMBR。 |
