# 添加UDM IP资源 (ADD UDMIPRES)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于添加UDM IP资源信息，此IP资源信息用于北向对接。

## 注意事项

- UDM IP资源信息配置的最大记录数为64条，添加时勿超过此上限值。
- 系统默认预置了以下接口类型的记录：Cx、Mgt、N10、N12、N21、N8、S6a、Sh。默认预置记录不允许删除。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                               |
|:--------------|:-------|:-----------------------------------------------------------------------------------|
| INTERFACETYPE | 接口类型   | 可选必选说明：必选参数 参数含义：用于指定UDM IP资源信息的接口类型。 取值范围：字符串类型，输入长度范围为1～64。大小写敏感。 默认值：无。 配置原则：无。 |

## 使用实例

添加UDM IP资源信息，其中“接口类型”为“test”：

```
ADD UDMIPRES: INTERFACETYPE="test";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如下表1所示。

|   错误码 | 错误码解释          | 原因分析                      | 处理建议                                                     |
|------:|:---------------|:--------------------------|:---------------------------------------------------------|
|   503 | 配置数据已存在        | 待增加的UDM IP资源记录已存在，无法重复添加。 | 使用LST UDMIPRES查询已存在的UDM IP资源信息，重新添加一条不在记录中的UDM IP资源配置数据。 |
|   504 | 当前已配置的记录数已达到上限 | UDM IP资源配置数据已达上限，无法新增。    | 使用LST UDMIPRES查询已存在的UDM IP资源配置信息，删除无效数据并重新添加。            |
