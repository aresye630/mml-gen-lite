# 查询NGAP本端实体（LST NGAPLE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询NGAP本端实体配置信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识      | 参数名称       | 参数说明                                                                                                       |
|:----------|:-----------|:-----------------------------------------------------------------------------------------------------------|
| NGAPLEIDX | NGAP本端实体索引 | 可选必选说明：可选参数  参数含义：该参数用于指定NGAP本端实体的索引，该索引作为NGAP本端实体的唯一标识。  数据来源：本端规划  取值范围：整数类型，取值范围是0~1023。  默认值：无  配置原则：无 |

## 使用实例

- 查询已经配置的所有NGAP本端实体，执行如下命令：

  ```
  %%LST NGAPLE:;%%
  RETCODE = 0  操作成功

  结果如下
  --------
  NGAP本端实体索引  SCTP本端实体组索引  NGAP参数索引

  1                 1                   0             
  2                 2                   0             
  (结果个数 = 2)

  ---    END
  ```
- 输入NGAP本端实体标识，查询指定的NGAP本端实体，执行如下命令：

  ```
  %%LST NGAPLE: NGAPLEIDX=1;%%
  RETCODE = 0  操作成功

  结果如下
  --------
    NGAP本端实体索引  =  1
  SCTP本端实体组索引  =  1
        NGAP参数索引  =  0
  (结果个数 = 1)

  ---    END
  ```

## 输出结果说明

| 输出项名称       | 输出项解释                                                                                                               |
|:------------|:--------------------------------------------------------------------------------------------------------------------|
| NGAP本端实体索引  | 该参数用于指定NGAP本端实体的索引，该索引作为NGAP本端实体的唯一标识。                                                                              |
| SCTP本端实体组索引 | 该参数用于指定NGAP本端实体引用的SCTP本端实体组索引，一个NGAP本端实体最多可引用32个SCTP本端实体。该本端实体组索引下最多配置32个本端实体。                                      |
| NGAP参数索引    | 该参数用于指定NGAP本端实体的NGAP协议参数配置索引。NGAP协议参数存在系统默认配置，如果NGAP本端实体默认使用系统默认参数可不指定该参数。如果NGAP本端实体需要使用其他配置值，则可以引用对应配置的NGAP协议参数索引。 |
