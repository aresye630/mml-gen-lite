# 添加网元服务版本信息(ADD NFSRVVER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加本端PCF网元服务的版本信息，通过**ADD NFSRV**关联索引后，向NRF注册。

该命令的参数索引关系如图1所示。

**图1** 命令参数索引关系图

## 注意事项

无。

## 参数说明

| 参数标识            | 参数名称      | 参数说明                                                                                                                       |
|:----------------|:----------|:---------------------------------------------------------------------------------------------------------------------------|
| GRPNAME         | 组名称       | 可选必选说明：必选参数 参数含义：用于标识本端网元服务版本信息所属组的信息。 取值范围：由数字、字母、“-”或“_”组成的长度不超过32的字符串 默认值：无。 配置原则：该参数由本端网元自定义。                          |
| INDEX           | 索引        | 可选必选说明：必选参数 参数含义：用于标识本端网元服务版本信息在组内的唯一一条记录。 取值范围：1~1024 默认值：无。 配置原则：该参数全局唯一，不能重复。                                           |
| APIVERSIONINURI | URI中的接口版本 | 可选必选说明：必选参数 参数含义：用于标识本端网元服务版本信息中URI接口版本。 取值范围：由字母、数字组成的长度不超过32的字符串举例："v1","v2"。 默认值：无。 配置原则：当前版本对应的“URI中的接口版本”为定值“v1”。     |
| APIFULLVERSION  | 接口全部版本号   | 可选必选说明：必选参数 参数含义：用于标识本端网元服务版本信息中接口全部版本号。 取值范围：由字母、数字、“.”或“-”组成的长度不超过32的字符串，字符串必须使用“.”分隔 举例："1.0.0",“2.0.0-alpha-1”。 默认值：无。 |
| EXPIRY          | 到期时间      | 可选必选说明：可选参数 参数含义：用于标识一个网元服务版本信息的到期时间。 取值范围：晚于当前命令提交执行的时间，格式为“YYYY&MM&DD&HH&NN&SS” 默认值：无。 配置原则：无。                           |

## 使用实例

增加一个网元服务版本信息。“组名称”为“srvver-group-01”，“索引”为“1020”，“URI中的接口版本”为“v1”，“接口全部版本号”为“1.0.0”：

```
ADD NFSRVVER:GRPNAME="srvver-group-01", INDEX=1020, APIVERSIONINURI="v1", APIFULLVERSION="1.0.0";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如下表1所示。

|    错误码 | 错误码解释   | 原因分析        | 处理建议                                 |
|-------:|:--------|:------------|:-------------------------------------|
|    503 | 配置数据已存在 | 已有相同“索引”配置。 | 使用命令LST NFSRVVER查询并重新输入“索引”，确保其值不存在。 |
| 360041 | 参数值不合法  | 指定参数值不合法。   | 参考参数的定义或举例内容，并重新输入，确保格式正确。           |
