## 命令功能

该命令为配置类命令，用于配置EDR文件名的前缀、不同格式的校验文件以及EDR匿名化开关，以满足不同局点对EDR文件的定制需求。

该命令的使用场景：

- SF提供Restful接口，PCF通过该接口告知SF生成EDR文件名的格式和校验文件的格式，然后SF通过UCF服务上传EDR文件至第三方服务器。当不同局点对EDR文件名及校验文件有不同要求时，操作员可以使用该命令配置EDR文件名前缀及配置不同格式的校验文件。
- 通过打开EDR匿名化开关，会对相关EDR字段（包括SubscriberIdentifier、IMSI、MSISDN、Trans-in Subscriber ID、GroupSubID和OldGroupSubID）进行匿名化处理，保护用户的个人数据。

## 注意事项

- 数据库中最多有一条配置记录，当数据库中已经存在配置记录时，此命令的执行会修改原来的配置信息。
- 该命令存在系统初始记录，参数的初始设置值如下：
  - “ID”为“1”
  - “EDR文件名前缀”为“NULL”
  - “EDR文件校验”为“DISABLE(去使能)”
  - “天控制文件上传时间”为“0”
  - “匿名化开关”为“ON”

| ANONYMOUSSW    | 匿名化开关     | 可选必选说明：可选参数 参数含义：用于设置EDR文件是否开启匿名化。匿名化的EDR字段包括SubscriberIdentifier、IMSI、MSISDN、Trans-in Subscriber ID、GroupSubID和OldGroupSubID。 取值范围： ON(ON)OFF(OFF) 默认值：无 配置原则：无  说明： 如果“匿名化开关”设置为“OFF”，同时通过SET EDRREPORT命令的设置打开了EDR上报开关，系统会上报告警“ALM-34270 EDR文件未做匿名化处理”。如果“匿名化开关”设置为“ON”，因用户标识被匿名化，EDR记录将无法对应到具体的用户。假设字段长度为N，脱敏匿名化参考如下：N <= 4，全部采用 * 号替换。4 < N ，保留字段前(N / 3)的长度，其他使用*号替换。举例参考：460971997122511、1996、550 -> 46097**********、****、***。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |

## 使用实例

设置EDR文件名前缀，“ID”为“1”，“EDR文件名前缀”为“TestFileName”，“EDR文件校验”为“DISABLE(去使能)”。

```
SET EDRCONFIG: ID=1, PREFIX="TestFileName", CHKFILE=DISABLE;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释         | 原因分析                                     | 处理建议                                          |
|------:|:--------------|:-----------------------------------------|:----------------------------------------------|
| 58170 | PREFIX参数取值非法。 | “PREFIX”取值只能由数字、大小写英文字母、下划线“_”和小数点“.”组成。 | 重新输入“PREFIX”取值，确保只包含数字、大小写英文字母、下划线“_”和小数点“.”。 |

## 参考信息

| 参数                    | 说明                    |
|:----------------------|:----------------------|
| File Name             | 压缩前的EDR文件名。           |
| #size of file         | 压缩前的EDR文件大小。 单位：Bytes |
| #number of the record | EDR文件的记录数。            |

| 参数名称                  | 参数说明                                 |
|:----------------------|:-------------------------------------|
| DataFileName          | 完整文件名，为EDR文件压缩后的名字。                  |
| FileCreationTimestamp | EDR文件创建时间。 格式：YYYYMMDDHHMMSS         |
| FileClosureTimestamp  | EDR文件最后修改时间。 格式：YYYYMMDDHHMMSS       |
| OpeningSequenceNumber | 首行EDR记录序列号，固定填充00000001。             |
| ClosingSequenceNumber | 尾行EDR记录序列号，通过EDR文件行数获取，不足8位在序列号前面补0。 |
| ControlTotal          | EDR记录数，记录EDR文件总行数。                   |
| FileSize              | EDR文件压缩前大小。 单位：Bytes                 |
| FileChecksum          | EDR文件校验值。                            |

**说明** 

定制格式审计文件第一行固定填充“**DataFileName|FileCreationTimestamp|FileClosureTimestamp|OpeningSequenceNumber|ClosingSequenceNumber|ControlTotal|FileSize|FileChecksum**”，第二行是具体的取值，每个值之间使用“|”分割。
