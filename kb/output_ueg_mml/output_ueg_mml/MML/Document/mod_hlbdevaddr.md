# 修改HLB设备地址(MOD HLBDEVADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

- 此命令是高危命令，如果执行不当会导致业务异常，同时推荐使用HTTPS协议对接，需联系华为技术支持确认后再执行。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令为配置类命令，用于修改配置数据库中的HLB设备地址信息。在该命令中，系统通过“设备地址标识”来唯一标识一条HLB设备地址信息数据记录。

**说明** 

使用该命令修改HLB服务的IP地址，新的IPV4地址或IPV6地址将会在命令执行5秒钟后才会生效。

## 注意事项

- 修改设备地址会使得所有使用该地址的在线连接中断。
- 不支持IPv4和IPv6相互修改。

- IPv6类型的IP地址不支持混合方式表达，即xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:d.d.d.d，其中x表示一个十六进制数（0～9或A～F），而d.d.d.d表示一个IPv4地址。
- “IPV6地址”不支持以下特殊地址的配置，其中x表示一个十六进制数（0～9或A～F）：

  - 0000:0000:0000:0000:0000:0000:0000:0000
  - FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF
  - 0000:0000:0000:0000:0000:0000:0000:0001
  - FFxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE8x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE9x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEAx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEBx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
- PMS/NTS/DRS/HLB/DLB/NLF/LDAP设备的IP地址（包括IPv4地址和IPv6地址）需要唯一，任意两种设备的IP地址不能重复。
- VRM\_PCFLIPSELECTMODE的取值为“1”时不允许修改“VPNNAME”，“IPVER”，“HTTPSFUNC”三个参数值。
- “VPNNAME”参数值相同的HLBDEVADDR记录的“TOEDGE”参数值需要保持一致。
- UPCF作为客户端与服务端同一个IP+端口建链时，仅支持HTTP或HTTPS中的一种。

## 使用实例

1. 修改IPv4类型的HLB设备地址信息。“设备地址标识”为“1”，“IP版本”为“IPV4(IPV4)”，“IPV4地址”为“192.168.0.130”。

   ```
   MOD HLBDEVADDR: DEVAID=1, IPVER=IPV4, IP="192.168.0.130";
   ```
2. 修改IPv6类型的HLB设备地址信息。“设备地址标识”为“2”，“IP版本”为“IPV6(IPV6)”，“IPV6地址”为“fc00:ffff:7834:ffff:ffff:ffff:ffff:ffff”。

   ```
   MOD HLBDEVADDR: DEVAID=2, IPVER=IPV6, IPV6="fc00:ffff:7834:ffff:ffff:ffff:ffff:ffff";
   ```
