# 查询UPCF归属地信息(LST HOMEAREA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询UPCF归属地信息。

- 若要查询全部UPCF归属地信息，请不要输入任何参数。
- 若要查询某个UPCF归属地信息，请输入“省份代号”或其他参数，或者“省份代号”和其他参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                           |
|:-------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROVINCECODE | 省份代号   | 可选必选说明：可选参数 参数含义：用于标识PCF策略统计数据来源的省份代号，为各省份缩写；若不输入，则表示查询所有省份代码的UPCF归属地信息。 取值范围：2位英文大写字母。 默认值：无。 配置原则：各省份缩写，如ZB（总部），AH(安徽)。当出现重复的省份缩写或者省份缩写超出2位等特殊情况时，可参考表2进行配置。 |
| PCFID        | PCF编号  | 可选必选说明：可选参数 参数含义：用于标识PCF策略统计数据来源的PCF编号；若不输入，则表示查询所有PCF编号的UPCF归属地信息。 取值范围：长度不超过32的字符串。字符串只能由数字、字母和“_”组成。 默认值：无。 配置原则：一般由地理标识、网元标识、网元序号、网元属性、厂家标识五部分组成。          |

## 使用实例

查询UPCF归属地信息。

```
%%LST HOMEAREA:;%% 
RETCODE = 0  操作成功  
操作结果如下: 
-------------
省份代号  =  JX 
 PCF编号  =  JNPCRFPLS01BHW
(结果个数 = 1)
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET HOMEAREA**命令的参数说明。
