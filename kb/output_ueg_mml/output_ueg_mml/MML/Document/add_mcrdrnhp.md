# 增加组播报文重定向策略（ADD MCRDRNHP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来创建组播报文重定向策略。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为4093。
- 当前仅支持地址类型为IPv4的下一跳，且下一跳地址不能为空。
- “\_public\_”、“\_mpp\_vpn\_inner\_\_”和“\_\_mpp\_vpn\_inner\_server\_\_”不支持配置组播报文重定向策略。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称      | 参数说明                                                                                                          |
|:--------------|:----------|:--------------------------------------------------------------------------------------------------------------|
| VPNNAME       | VPN名称     | 可选必选说明：必选参数 参数含义：该参数用来表示VPN实例名称。 数据来源：本端规划。 取值范围：字符串类型，输入长度范围为1～31。 默认值：无。 配置原则：通过LST L3VPNINST查看当前已存在的VPN实例。 |
| IPVERSION     | 地址类型      | 可选必选说明：可选参数 参数含义：该参数用于指定下一跳地址为IPv4类型或IPv6类型。 数据来源：本端规划 取值范围：枚举类型。 IPv4：IPv4类型。IPv6：IPv6类型。 默认值：IPv4 配置原则：无    |
| NEXTHOPADDRV4 | IPv4下一跳地址 | 可选必选说明：条件必选 参数含义：该参数用于指定下一跳IPv4地址，表示重定向到的网关IP。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无 配置原则：无                          |
| NEXTHOPADDRV6 | IPv6下一跳地址 | 可选必选说明：条件必选 参数含义：该参数用于指定下一跳IPv6地址，表示重定向到的网关IP。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无 配置原则：无                          |

#### 使用实例

增加组播报文重定向策略：

```
ADD MCRDRNHP: VPNNAME="vrf1", IPVERSION=IPv4, NEXTHOPADDRV4="192.168.0.1";
```
