# 增加网元路由模式（ADD NFROUTEMODEL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会导致业务通信路由方式变更，造成业务呼损或系统崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于增加UDM和NRF之间SCP对接的网元路由模式。

增加网元路由模式不管选择直连路由模式还是间接路由模式，都支持以下配置方式：

- 当请求消息为NF Type时，NF可以配置所有的Model通信模式。
- 当请求消息为NF Instance ID时，NF配置可根据目标NF Instance Id划分不同区域进行配置：
  - 本区域使用直接路由MODEL-B模式。
  - 跨区域使用间接路由MODEL-C或MODEL-D模式。

## 注意事项

- UDM在系统初始化的时候已经预置如下几条默认数据记录，操作员可以通过**LST NFROUTEMODEL**命令查询得出。

  ```
  ADD NFROUTEMODEL: RTNAME="Default_Global", NFTYPE=DEFAULT, MODEL=MODEL-B, SWITCH=ENABLE;
  ADD NFROUTEMODEL: RTNAME="Default_AMF_PLMN", NFTYPE=AMF, DESTTYPE=PLMN, PLMN="Default", MODEL=MODEL-B, SWITCH=DISABLE;
  ADD NFROUTEMODEL: RTNAME="Default_SMF_PLMN", NFTYPE=SMF, DESTTYPE=PLMN, PLMN="Default", MODEL=MODEL-B, SWITCH=DISABLE;
  ```
- 系统中增加的网元路由模式的最大记录数不能超过1024条。
- 系统中只允许配置1条“网元类型”为“DEFAULT(DEFAULT)”的数据记录。
- 路由模式匹配的优先级如下：
  1. 匹配“网元类型”为对应网元、“目标类型”为“NFINSTANCE(NFINSTANCE)”且设置了“网元实例”参数的数据。
  2. 匹配“网元类型”为对应网元、“目标类型”为“IPADDR(IPADDR)”且设置了“IP地址”参数的数据，或匹配“网元类型”为对应网元、“目标类型”为“FQDN(FQDN)”且设置了“域名”参数的数据，两者二选一，优先级相同。
  3. 匹配“网元类型”为对应网元、“目标类型”为“IPRANGE(IPRANGE)”且设置了“IP地址段起始地址”和“IP地址段结束地址”参数的数据，或匹配“网元类型”为对应网元、“目标类型”为“FQDNSUFFIX(FQDNSUFFIX)”且设置了“域名后缀”参数的数据，两者二选一，优先级相同。
  4. 匹配“网元类型”为对应网元、“目标类型”为“PLMN(PLMN)”且设置了“PLMN ID”参数的数据。
  5. 匹配“网元类型”为对应网元、“目标类型”为“PLMN(PLMN)”且“PLMN ID”取值为“Default”的数据。
  6. 匹配“网元类型”为对应网元的数据。
  7. 匹配“网元类型”为“DEFAULT(DEFAULT)”的数据。
- 对于UDM做Consumer场景（域选、查位置、查状态、UE可达性订阅、NEF能力开放事件订阅），UDM需要服务发现才能获取到对应网元的IP或FQDN，当UDM配置了对应网元“目标类型”为“IPADDR(IPADDR)”、“FQDN(FQDN)”、“IPRANGE(IPRANGE)”或“FQDNSUFFIX(FQDNSUFFIX)”且“发现模式”为“MODEL-D(模式D)”时，如果UDM在服务发现前根据其他配置判断发现模式为非MODEL-D模式时，UDM需要做一次服务发现，再根据IP或FQDN匹配上该MODEL-D模式的配置，然后SCP还会再进行一次服务发现。该场景可能会导致UDM和SCP重复进行服务发现，因此不建议AMF网元配置“目标类型”为“IPADDR(IPADDR)”、“FQDN(FQDN)”、“IPRANGE(IPRANGE)”或“FQDNSUFFIX(FQDNSUFFIX)”时，“发现模式”配置为“MODEL-D(模式D)”。
- 当“SCPRouteMode(SCP路由模式)”软参配置为“0”时，通过本命令的“发现模式”参数配置决定UDM发送3gpp-Sbi-Callback消息（如PCSCF故障容灾的消息、AMF去注册通知的消息、签约数据变更通知的消息、通知NEF的消息等）时是否经过SCP路由。

## 使用实例

1. 增加网元路由模式，“路由名称”为“4604567890003”，“网元类型”为“AMF(AMF)”，“目标类型”为“NFINSTANCE(NFINSTANCE)”，“网元实例”为“4947a69a-f61b-4bc1-b9da-47c9c5d14b64”，“发现模式”为“MODEL-D(模式D)”，“开关”为“DISABLE(非使能)”：

   ```
   ADD NFROUTEMODEL: RTNAME="4604567890003", NFTYPE=AMF, DESTTYPE=NFINSTANCE, NFINSTANCE="4947a69a-f61b-4bc1-b9da-47c9c5d14b64", MODEL=MODEL-D, SWITCH=DISABLE, CONFIRM=Y;
   ```
2. 增加网元路由模式，“路由名称”为“4604567890001”，“网元类型”为“AMF(AMF)”，“发现模式”为“MODEL-B(模式B)”，“开关”为“DISABLE(非使能)”：

   ```
   ADD NFROUTEMODEL: RTNAME="4604567890001", NFTYPE=AMF, MODEL=MODEL-B, SWITCH=DISABLE, CONFIRM=Y;
   ```
3. 增加网元路由模式，“路由名称”为“4604567890005”，“网元类型”为“DEFAULT(DEFAULT)”，“发现模式”为“MODEL-B(模式B)”，“开关”为“ENABLE(使能)”：

   ```
   ADD NFROUTEMODEL: RTNAME="4604567890005", NFTYPE=DEFAULT, MODEL=MODEL-B, SWITCH=ENABLE;
   ```
4. 增加网元路由模式，“路由名称”为“4604567890006”，“网元类型”为“AMF(AMF)”，“目标类型”为“PLMN(PLMN)”，“PLMN”为“23256”，“发现模式”为“MODEL-B(模式B)”，“开关”为“ENABLE(使能)”：

   ```
   ADD NFROUTEMODEL: RTNAME="4604567890006", NFTYPE=AMF, DESTTYPE=PLMN, PLMN="23256", MODEL=MODEL-B, SWITCH=ENABLE;
   ```
5. 增加网元路由模式，“路由名称”为“4604567890007”，“网元类型”为“AMF(AMF)”，“目标类型”为“IPRANGE(IPRANGE)”，“IP地址段起始地址”为“192.168.100.0”，“IP地址段结束地址”为“192.168.100.100”，“发现模式”为“MODEL-B(模式B)”，“开关”为“ENABLE(使能)”：

   ```
   ADD NFROUTEMODEL: RTNAME="4604567890007", NFTYPE=AMF, DESTTYPE=IPRANGE, IPSTART="192.168.100.0", IPEND="192.168.100.100", MODEL=MODEL-B, SWITCH=ENABLE;
   ```

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。
