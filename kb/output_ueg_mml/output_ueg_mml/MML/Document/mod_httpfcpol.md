# 修改手工流控策略（MOD HTTPFCPOL）

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一条HTTP手工流控策略的某些参数进行修改或调整。 在该命令中，系统通过“策略名称”参数来唯一标识一条手工流控策略。

## 注意事项

该命令不支持GBA（Generic Bootstrapping Architecture）场景。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                   |
|:------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| POFCNM      | 策略名称   | 可选必选说明：必选参数。 参数含义：标识手工流控策略数据的关键字段（其取值不能被修改），用于指定需要对哪个策略名称对应的手工流控策略数据记录的参数进行修改或调整，操作员可以使用LST HTTPFCPOL命令查询获得。 取值范围：长度不超过32位的字符串，只允许输入：0～9，a～z，A～Z，“-”和“_”。 默认值：无 配置原则：无 |
| FCMODE      | 流控开关   | 可选必选说明：可选参数 参数含义：用于标识是否激活本条手工流控策略。 取值范围： ACTIVE(激活)DEACTIVE(去激活) 默认值：无 配置原则：无                                                                                          |
| FCREQRATE   | 流控速率   | 可选必选说明：可选参数 参数含义：用于标识修改后单个模块每秒的最大消息量，当UDM接收到的请求消息速率超过该值时，启动手工流控功能。 取值范围：0～65535 默认值：无 配置原则： 该参数取值为“0”时，表示不启动手工流控。                                                      |
| BURSTREQNUM | 突发请求数  | 可选必选说明：可选参数 参数含义：用于标识修改后的突发请求数。UDM接收到的HTTP请求消息速率超过“流控速率”参数值后，不会立即丢弃消息，当继续处理的消息数量达到该参数配置的值时，开始丢弃消息并上报流控告警。 取值范围：0～2000 默认值：无 配置原则：无                                     |
| FCTPLID     | 流控模板标识 | 可选必选说明：可选参数 参数含义：用于标识需要修改哪一个流控模板号。该参数在ADD HTTPFCTPL命令定义后在才能在此处引用。 默认值：无 配置原则：无                                                                                         |

## 使用实例

在配置HTTP手工流控时，修改一条“策略名称”为“AAA\_02”的手工流控参数信息，其中，“流控速率”为“6000”，“突发请求数”为“600”：

```
MOD HTTPFCPOL: POFCNM="AAA_02", FCREQRATE=6000, BURSTREQNUM=600;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释     | 原因分析          | 处理建议                                                      |
|-------:|:----------|:--------------|:----------------------------------------------------------|
|    505 | 目标配置数据不存在 | 待修改的策略名称不存在。  | 执行LST HTTPFCPOL命令查询已配置的“策略名称”，输入正确的“策略名称”后重新执行本命令修改。      |
| 360135 | 无效策略模板ID  | 引用的策略模板ID不存在。 | 执行LST HTTPFCTPL命令查询已配置的 “流控模板标识”参数，输入正确的策略模板ID后重新执行本命令修改。 |
