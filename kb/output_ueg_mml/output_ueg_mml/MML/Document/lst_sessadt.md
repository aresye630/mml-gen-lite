# 查询会话备份数据审计任务参数（LST SESSADT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护命令，用于查询会话备份数据审计任务的配置信息。

- 如果需要查询全部会话备份数据审计任务参数信息，请不要输入任何参数。
- 如果需要查询UPCF与USCDB间的会话数据审计任务参数信息，“审计类型”请选择“UPCF”。
- 如果需要查询USCDB中冗余会话数据清理任务参数信息，“审计类型”请选择“USCDB”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                           |
|:-------|:-------|:-----------------------------------------------------------------------------------------------|
| TYPE   | 审计类型   | 用于查询指定类型的审计任务，若不输入，则表示查询所有的会话备份数据审计任务。 取值范围： UPCF(UPCF与USCDB间的会话数据审计)USCDB(USCDB的会话备份冗余数据清理审计) |

## 使用实例

查询全部会话数据审计配置信息。执行命令如下：

```
LST SESSADT:;
```
