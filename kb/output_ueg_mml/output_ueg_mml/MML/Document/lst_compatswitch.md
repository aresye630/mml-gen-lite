# 查询兼容性参数（LST COMPATSWITCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询兼容性软件参数信息。

## 注意事项

- 若需要查询全部软参数据记录的概要信息，请不要输入任何参数。
- 若需要查询某条参数数据记录的详细信息，请输入“参数名”。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                          |
|:--------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------|
| SWNAME  | 参数名    | 可选必选说明：可选参数 参数含义：标识一条软参数据记录的关键字段之一（其取值在枚举值内取得），用于指定需要对哪一类软参数据记录的参数进行查询；若不输入，则表示所有的参数名。 取值说明：详细信息请参考产品手册的“UPCF软件参数 > PES兼容性软参”。 默认值：无。 配置原则：无。 |
| SWVALUE | 参数值    | 可选必选说明：可选参数 参数含义：标识一条软参数据记录的关键字段之一，此处取值应在取值范围内取值。其中，类型的编号规则是从上到下，从0开始顺序编号。 取值范围：0～2147483647 默认值：无。 配置原则：无。                                   |

## 使用实例

查询兼容性软参。参数名为N7ReleaseCause。

```
LST COMPATSWITCH: SWNAME=N7ReleaseCause;
```

```
%%LST COMPATSWITCH: SWNAME=N7ReleaseCause;%%
RETCODE = 0  操作成功

操作结果如下:
-------------
        参数名  =  N7释放会话原因
        参数值  =  1
软件参数默认值  =  0
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见本命令的参数说明。
