# 删除ADC参数（RMV ADCPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，删除AdcPara可能会导致用户策略获取发生变化，影响策略获取，导致用户业务受损，请谨慎使用并联系华为支持协助操作。

该命令用于删除ADC参数。当运营商希望删除指定ADC应用的流信息上报开关时，则执行该命令。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称         | 参数说明                                                                                                   |
|:---------------|:-------------|:-------------------------------------------------------------------------------------------------------|
| FLOWFILTERNAME | 流过滤器/流过滤器组名称 | 可选必选说明：必选参数 参数含义：该参数用于设置应用对应的流过滤器或流过滤器组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

假设运营商需要删除指定ADC应用下的参数时，指定流过滤器名称为testflowfiltername，可以执行该命令：

```
RMV ADCPARA:FLOWFILTERNAME="testflowfiltername";
```
