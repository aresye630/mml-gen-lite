# 查询CCDB公共配置数据（LST CCDBPUBLICDATA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示CCDB公共配置表数据值。

## 注意事项

只有系统管理员权限级别用户可执行该命令。

## 参数说明

无。

## 使用实例

显示CCDB的所有公共配置数据。

```
LST CCDBPUBLICDATA:;
```

```
%%LST CCDBPUBLICDATA:;%%
RETCODE = 0  操作成功  

操作结果如下: 
-------------  
配置项ID    配置项取值  配置项名称  
0           8           DUS的POD数量
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。各输出项含义请参见表1 输出项解释的参数说明。

| 输出项名称   | 输出项解释                         |
|:--------|:------------------------------|
| 配置项ID   | 用于标识公共配置项的ID，区分CCDB中不同的公共配置项。 |
| 配置项取值   | 用于标识配置项ID对应的配置项取值。            |
| 配置项名称   | 用于标识该配置项的名称。                  |
