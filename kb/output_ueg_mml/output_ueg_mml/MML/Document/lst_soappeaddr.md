# 查询SOAP对端地址段(LST SOAPPEADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询系统中SOAP对端IP地址段记录：

- 若需要查询所有SOAP对端地址段配置信息，请不要输入任何参数。
- 若需要查询某个SOAP对端标识对应的对端地址段配置信息，请输入“SOAP对端标识”参数。
- 若需要查询某个SOAP对端标识下具体网段编号对应的SOAP对端地址段配置信息，请同时输入“SOAP对端标识”参数和“网段编号”参数。

  **说明** 

  该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                    |
|:-------|:---------|:------------------------------------------------------------------------|
| ID     | SOAP对端标识 | 可选必选说明：可选参数 用于指示系统按照哪个ID来查询SOAP对端地址段配置信息；若不输入，则表示查询全部的SOAP对端地址段配置信息。    |
| ADDRID | 网段编号     | 可选必选说明：条件可选参数 当“SOAP对端标识”参数取值不为空时，该参数可选。用于指示系统按照哪个网段编号来查询SOAP对端地址段配置信息。 |

## 使用实例

1. 查询所有SOAP对端地址段记录。

   ```
   LST SOAPPEADDR:;
   ```

   ```
   +++    UIM/*MEID:100 MENAME:WJ_TEST*/        2021-04-23 15:07:48+00:00
   O&M    #1071
   %%LST SOAPPEADDR:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    SOAP对端标识  网段编号  IP版本  IPv4地址段   IPv4掩码       IPv6地址段                               IPv6前缀长度

    1             0         IPV6    NULL         NULL           FFFF:FFFF:FFFF:FFFF:FEEE:EEEE:EEEE:EEEE  6           
    2             3         IPV4    10.5.48.71   255.255.255.0  NULL                                     0           
    2             2         IPV6    NULL         NULL           2001:DB8:2DE:0:0:0:0:1E13                2           
    2             0         IPV4    10.5.40.12   255.255.255.0  NULL                                     0           
    3             1         IPV4    10.5.40.10   255.255.255.0  NULL                                     0           
   (结果个数 = 5)

   ---    END
   ```
2. 查询“SOAP对端标识”为“1”的SOAP对端地址段配置信息：

   ```
   LST SOAPPEADDR: ID=1;
   ```

   ```
   +++    UIM/*MEID:100 MENAME:WJ_TEST*/        2021-04-23 15:10:19+00:00
   O&M    #1094
   %%LST SOAPPEADDR: ID=1;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    SOAP对端标识  网段编号  IP版本  IPv4地址段   IPv4掩码       IPv6地址段  IPv6前缀长度

    1             7         IPV4    10.5.40.20   255.255.255.0  NULL        0           
    1             1         IPV4    10.5.40.10   255.255.255.0  NULL        0           
   (结果个数 = 2)

   ---    END
   ```
3. 查询“SOAP对端标识”为“1”、“网段编号”为“2”的SOAP对端地址段配置信息：

   ```
   LST SOAPPEADDR: ID=2, ADDRID=2;
   ```

   ```
   +++    UIM/*MEID:100 MENAME:WJ_TEST*/        2021-04-23 15:11:53+00:00
   O&M    #1107
   %%LST SOAPPEADDR: ID=2, ADDRID=2;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
   SOAP对端标识  =  2
       网段编号  =  2
         IP版本  =  IPV6
     IPv4地址段  =  NULL
       IPv4掩码  =  NULL
     IPv6地址段  =  2001:DB8:2DE:0:0:0:0:1E13
   IPv6前缀长度  =  2
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD SOAPPEADDR**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                    | 原因分析                          | 处理建议                                                      |
|-------:|:-------------------------|:------------------------------|:----------------------------------------------------------|
| 360285 | 不允许输入SOAP对端标识为空，网段编号不为空。 | 输入了“网段编号”参数但是未输入“SOAP对端标识”参数。 | “网段编号”参数为条件可选参数，如需使用该参数，请先输入有效的“SOAP对端标识”参数后再输入本参数执行查询命令。 |
