# 查询5G LAN实例绑定VXLAN组（LST NGVNBINDVXLAN）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询5G LAN会话实例使用的VXLAN链路信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                               |
|:-----------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VNINSTANCE | 5G LAN实例名称 | 可选必选说明：可选参数 参数含义：该参数用于指定5G LAN会话实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为18～37。VNINSTANCE以连字号分为4段，形式为GroupServiceID-MCC-MNC-LocalGroupID。其中，GroupServiceID长度为8，只能输入数字或者范围为A到F或a-f的字母；MCC长度为3，只能输入数字；MNC长度为2~3，只能输入数字；LocalGroupID长度为2~20的偶数，只能输入数字或者范围为A到F或a-f的字母。例如，A0000001-460-003-01，A0000001-460-003-A000000001。不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

查询5G LAN会话实例"A0000001-460-003-01"的VXLAN隧道信息：

```
LST NGVNBINDVXLAN: VNINSTANCE="A0000001-460-003-01":;
```

```

```
