# 配置理想到达报文的最小时延偏差、固定传输时延（SET VONRPERFTDELAY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于设置理想到达报文的最小时延偏差、固定传输时延。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   |   MINDELAYERROR |   FIXTRANSTIME |
|:-------|----------------:|---------------:|
| 初始值    |              10 |            180 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称          | 参数说明                                                                                       |
|:--------------|:--------------|:-------------------------------------------------------------------------------------------|
| MINDELAYERROR | 理想到达报文的最小时延偏差 | 可选必选说明：可选参数 参数含义：该参数用于指定理想到达报文的最小时延偏差。 数据来源：本端规划 取值范围：整数类型，取值范围为0～200，粒度为100。 默认值：无 配置原则：无 |
| FIXTRANSTIME  | 理想时延报文的固定传输时延 | 可选必选说明：可选参数 参数含义：该参数用于指定理想时延报文的固定传输时延。 数据来源：本端规划 取值范围：整数类型，取值范围为0～1000，单位是毫秒。 默认值：无 配置原则：无 |

#### 使用实例

设置理想报文的最小时延误差、固定传输时延：

```
SET VONRPERFTDELAY: MINDELAYERROR=20, FIXTRANSTIME=20;
```
