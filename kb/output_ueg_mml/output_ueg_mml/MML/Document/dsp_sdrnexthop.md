# 查询SDRC中缓存的下一跳信息（DSP SDRNEXTHOP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询SDRC中缓存的下一跳信息，需要用户指定APPTYPE以及相应的下一跳组ID。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                     |
|:---------------|:-------|:-----------------------------------------------------------------------------------------|
| APPTYPE        | App类型  | 可选必选说明：必选参数  参数含义：该参数用于表示业务类型。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无   |
| NEXTHOPGROUPID | 下一跳组ID | 可选必选说明：必选参数  参数含义：该参数用于表示下一跳组ID。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无 |

## 使用实例

使用如下命令查询指定APPTYPE和下一跳组中的下一跳信息：

```
%%DSP SDRNEXTHOP: APPTYPE=140, NEXTHOPGROUPID=65;%%
RETCODE = 0  操作成功

结果如下
--------
App 类型  下一跳组ID  下一跳索引  FABRIC TB  FABRIC TP    

140      65          1           1119      2217811712  
140      65          0           1107      2217811712  
(结果个数 = 2)
```

## 输出结果说明

| 输出项名称     | 输出项解释                          |
|:----------|:-------------------------------|
| App类型     | 该参数用于表示业务类型。                   |
| 下一跳组ID    | 该参数用于表示下一跳组ID。                 |
| 下一跳索引     | 该参数用于表示下一跳索引，和Root Token Id相同。 |
| FABRIC TB | 该参数用于标识进程所在虚拟机（裸机）的ID。         |
| FABRIC TP | 该参数用于标识虚拟机（裸机）中的虚拟端口ID。        |
