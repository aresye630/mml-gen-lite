#### 命令功能

**适用网元：MME**

该命令用于查询MDT控制参数。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询MDT控制参数：

LST MDTCTRL:;

```
%%LST MDTCTRL:;%%
RETCODE = 0  操作成功

操作结果如下
--------------
                           MDT开关  =  ON
是否向新侧MME携带MDT-Configuration  =  ON
(结果个数 = 1)

---    END
```

#### 输出结果说明
