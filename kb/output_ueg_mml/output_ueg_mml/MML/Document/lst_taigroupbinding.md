# 查看TAI组绑定的TAC号段（LST TAIGROUPBINDING）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于查看TAI组绑定的TAC号段。

#### 注意事项

该命令执行后只对新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                              |
|:-------------|:--------|:------------------------------------------------------------------------------------------------------------------|
| TAIGROUPNAME | 指定TAI组名 | 可选必选说明：可选参数 参数含义：该参数用于指定TAI组名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD TAIGROUP命令配置生成。 |

#### 使用实例

假设运营商需要查看指定TAC号段与TAI组的绑定关系：TAI组为beijing，TAC号段为0：

```
LST TAIGROUPBINDING:;
```

```
RETCODE = 0  操作成功

TAI组与TAI号段绑定关系
-------------------------------
    指定TAI组名  =  beijing
      TAC起始ID  =  0x000000
      TAC截止ID  =  0x000010
    TAC 段编号  =  0
(返回个数 = 1)

---    END
```
