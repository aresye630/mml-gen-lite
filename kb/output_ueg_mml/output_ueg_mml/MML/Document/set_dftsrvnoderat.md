# 设置默认RAT类型（SET DFTSRVNODERAT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：GGSN**

该命令用来设置默认的RAT类型。获取RAT类型用于从虚拟APN映射到真实APN、匹配user-profile进行业务、计费控制。当SGSN IP在表中没有匹配项并且消息中没有携带RAT Type信元时，会用这个默认的RAT类型作为它对应的RAT类型。当要配置该表的默认表项时，使用这条命令。

## 注意事项

- 该命令执行后立即生效。

- 若系统中尚未配置默认RAT类型，执行命令增加默认RAT类型；若系统中已配置默认RAT类型，执行本命令则修改已配置的默认RAT类型。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| NODETYPE   | RATTYPE   |
|:-----------|:----------|
| GGSN       | NONE      |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NODETYPE | 网元类型   | 可选必选说明：必选参数  参数含义：该参数表示当前配置的网元类型。  数据来源：本端规划 取值范围： GGSN（GGSN）  默认值：无。  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| RATTYPE  | RAT类型  | 可选必选说明：可选参数  参数含义：该参数用于指定默认的RAT类型。  数据来源：全网规划 取值范围： “NONE（NONE）”：表示尚未配置默认的RAT类型。即没有RAT类型。“UTRAN（UTRAN）”：表示默认RAT类型为UTRAN。“GERAN（GERAN）”：表示默认RAT类型为GERAN。“WLAN（WLAN）”：表示默认RAT类型为WLAN。“GAN（GAN）”：表示默认RAT类型为GAN。“EUTRAN（EUTRAN）”：表示默认RAT类型为EUTRAN。“UNSPECIFIED（UNSPECIFIED）”：表示默认RAT类型未知。即没有RAT类型。“EUTRAN_NB_IOT（EUTRAN_NB_IOT）”：表示默认RAT类型为EUTRAN-NB-IoT。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST DFTSRVNODERAT查询当前参数配置值。  配置原则：  当RATTYPE配置成“UNSPECIFIED”时，DWORD1021 BIT29 控制GGSN-C从读取配置后返回SMFCOMMONDEFAULTRAT_TYPEUNSPECIFIED还是nil。 |

## 使用实例

当设置SGSN默认的RAT类型为WLAN时，可按如下配置：

```
SET DFTSRVNODERAT:NODETYPE=GGSN, RATTYPE=WLAN;
```
