# 添加DLB设备地址(ADD DLBDEVADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条DLB设备地址信息数据记录。当需要使用DLB服务时，需要为DLB服务配置IP地址，以便UPCF能够识别该服务。

- 双栈场景下，配置2个本端DLBDEVADDR记录，1个本端IPV4地址，1个本端IPV6地址。
- SCTP双归属场景下，配置4个本端DLBDEVADDR记录，2个本端IPV4地址，2个本端IPV6地址。

## 注意事项

- IPv6类型的IP地址不支持混合方式表达，即xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:d.d.d.d，其中x表示一个十六进制数（0～9或A～F），而d.d.d.d表示一个IPv4地址。
- “IPV6地址”不支持以下特殊地址的配置，其中x表示一个十六进制数（0～9或A～F）：

  - 0000:0000:0000:0000:0000:0000:0000:0000
  - FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF
  - 0000:0000:0000:0000:0000:0000:0000:0001
  - FFxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE8x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE9x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEAx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEBx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
- 在SCTP场景下，本端最多允许配置10个IPV4地址或10个IPV6地址。
- 对于IPv4地址，不支持配置以下地址：“127.0.0.1”、“0.0.0.0”、“255.255.255.255”、“224.0.0.1”。
- PMS/NTS/DRS/HLB/DLB/NLF/LDAP设备的IP地址（包括IPv4地址和IPv6地址）需要唯一，任意两种设备的IP地址不能重复。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                               |
|:------------|:--------|:-------------------------------------------------------------------------------------------------------------------|
| DEVAID      | 设备地址标识  | 可选必选说明：必选参数 参数含义：用于在UPCF配置库中定义一条本地设备地址信息。 取值范围：0～31 默认值：无。 配置原则：无。                                                 |
| VPNINDEX    | VPN索引   | 可选必选说明：必选参数 参数含义：用于指定一个DLB VPN实体。该参数必须先由ADD DLBVPN命令定义，然后才能在此索引。 取值范围：0～15 默认值：无。 配置原则：无。                          |
| IPVER       | IP版本    | 可选必选说明：必选参数 参数含义：用于指定设备IP地址的IP版本类型。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。                                      |
| IP          | IPV4地址  | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV4(IPV4)”时该参数有效，用于表示DLB设备的IPv4地址。 取值范围：IPv4地址 默认值：无。 配置原则：无。                         |
| IPV6        | IPV6地址  | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV6(IPV6)”时该参数有效，用于表示DLB设备的IPV6地址。 取值范围：IPV6地址 默认值：无。 配置原则：无。                         |
| DESCRIPTION | 描述      | 可选必选说明：可选参数 参数含义：用于描述设备IP地址的用途。 取值范围：长度不超过32位的字符串 默认值：无。 配置原则：无。                                                   |
| DSCP        | DSCP优先级 | 可选必选说明：可选参数 参数含义：用于指定修改后的DSCP优先级。 取值范围：0～63，255 默认值：255。 配置原则：无。  说明： DSCP优先级有64级，为0～63，级别为63时，优先级最高。255表示不设置DSCP。 |

## 使用实例

1. 增加IPv4类型的DLB设备地址信息。“设备地址标识”为“1”，“VPN索引”为“1”，“IP版本”为“IPV4(IPV4)”，“IPV4地址”为“192.168.0.130”，“描述”为“DLB\_IPV4”，“DSCP优先级”为“255”。

   ```
   ADD DLBDEVADDR: DEVAID=1, VPNINDEX=1, IPVER=IPV4, IP="192.168.0.130", DESCRIPTION="DLB_IPV4", DSCP=255;
   ```
2. 增加IPv6类型的DLB设备地址信息。“设备地址标识”为“2”，“VPN索引”为“2”，“IP版本”为“IPV6(IPV6)”，“IPV6地址”为“2001:0db8:2fff:ffff:ffff:ffff:ffff:ffff”，“描述”为“DLB\_IPV6”。

   ```
   ADD DLBDEVADDR: DEVAID=2, VPNINDEX=2, IPVER=IPV6, IPV6="2001:0db8:2fff:ffff:ffff:ffff:ffff:ffff", DESCRIPTION="DLB_IPV6";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 消息解释      | 原因分析                                                     | 处理建议                                                                 |
|------:|:----------|:---------------------------------------------------------|:---------------------------------------------------------------------|
| 58107 | 设备地址冲突。   | PMS/NTS/DRS/HLB/DLB/NLF/LDAP设备的IP地址需要唯一，任意两种设备的IP地址不能重复。 | 修改IP地址，重新执行本命令增加设备地址。                                                |
| 53372 | IP地址已经存在。 | 输入的“IP”或“IPV6”已存在。                                       | 执行LST DLBDEVADDR命令查询全部DLB设备地址。执行本命令，重新设置“IP”或“IPV6”，并确保和已存在的IP地址不相同。 |
