# 设置服务化接口链路集属性（SET SBILINKSETCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置服务化接口链路集的属性配置信息，该属性设置后整系统生效。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

|   SETAGINGTIME | FQDNCHECKSWITCH   |   FAULTLINKPCT |   FAULTPROCESSPCT |
|---------------:|:------------------|---------------:|------------------:|
|             10 | ON                |             50 |                20 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                                              |
|:----------------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SETAGINGTIME    | 链路集老化时间(小时) | 可选必选说明：可选参数  参数含义：该参数用于指定链路集老化时间。  数据来源：本端规划  取值范围：整数类型，取值范围是5~72，单位是小时。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST SBILINKSETCFG查询当前参数配置值。  配置原则：无                                                                                                                                                                                 |
| FQDNCHECKSWITCH | FQDN周期性检查开关 | 可选必选说明：可选参数  参数含义：该参数用于控制是否开启周期性检查链路集FQDN对应的IP地址的功能。  数据来源：本端规划 取值范围： OFF（关闭）ON（打开）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST SBILINKSETCFG查询当前参数配置值。  配置原则：无                                                                                                                                                                      |
| FAULTLINKPCT    | 进程内链路集故障阈值  | 可选必选说明：可选参数  参数含义：该参数用于判定链路集在单个HTTP进程中是否为故障，当故障链路数占比大于等于此参数，则认为进程内到对端的链路集故障。  数据来源：本端规划  取值范围：整数类型，取值范围是0~100，单位是百分比。当该参数设置为0时，则按照默认值生效。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST SBILINKSETCFG查询当前参数配置值。  配置原则：  如果针对所有链路集均生效，则配置该参数。如果针对某个对端NF的链路集生效，则使用ADD SBILINKSETPROP命令配置。如果都配置，则优先使用ADD SBILINKSETPROP的命令配置生效。            |
| FAULTPROCESSPCT | 系统内链路集故障阈值  | 可选必选说明：可选参数  参数含义：该参数用于判定链路集在系统内是否为故障，当存在链路集故障的进程数占比大于等于此参数，则认为系统内链路集故障，该链路集对应的NF服务不可达。  数据来源：本端规划  取值范围：整数类型，取值范围是0~100，单位是百分比。当该参数设置为0时，则按照默认值生效。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST SBILINKSETCFG查询当前参数配置值。  配置原则：  如果针对所有链路集均生效，则配置该参数。如果针对某个对端NF的链路集生效，则使用ADD SBILINKSETPROP命令配置。如果都配置，则优先使用ADD SBILINKSETPROP的命令配置生效。 |

## 使用实例

设置链路集老化时间为10，可以执行如下命令：

```
SET SBILINKSETCFG:SETAGINGTIME=10;
```
