# 查询UCF报表本地IP资源池（LST UCFIP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询UCF的本地报表IP地址池。

## 注意事项

执行命令前请确认UCF服务处于上线状态。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

运营商A查询UCF配置单据上报的本地IP资源池配置信息：

```
%%LST UCFIP:;%%
RETCODE = 0  操作成功

结果如下
--------
    索引号  =  1
  协议类型  =  SFTP
    IP类型  =  IPv4
  IPv4地址  =  10.181.23.253
  IPv6地址  =  ::
起始端口号  =  2000
结束端口号  =  2001
   VPN名称  =  _public_
      描述  =  NULL

(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                 |
|:--------|:----------------------|
| 索引号     | 该参数用于标识记录索引号。         |
| 协议类型    | 该参数用于指定UCF报表使用的协议类型。  |
| IP类型    | 该参数用于指定IP地址的类型。       |
| IPv4地址  | 该参数用于指定UCF本端的IPv4地址。  |
| IPv6地址  | 该参数用于指定UCF本端的IPv6地址。  |
| 起始端口号   | 该参数用于指定UCF报表地址的起始端口号。 |
| 结束端口号   | 该参数用于指定UCF报表地址的结束端口号。 |
| VPN名称   | 该参数用于指定报表传输使用的VPN名称。  |
| 描述      | 该参数用于标识报表IP资源池的描述信息。  |
