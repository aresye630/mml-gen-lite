# 查询VLR局向Sgs固定速率流控 (LST MMESGSFIXEDFC)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SMSF**

此命令用于查询VLR局向Sgs固定速率流控参数。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                   |
|:-------|:-------|:---------------------------------------------------------------------------------------|
| MMEIDX | MME索引  | 可选必选说明：可选参数 参数含义：该参数用于指定一个MME实体，在全局范围内唯一。 数据来源：本端规划 取值范围：整数类型，取值范围为0~1999 默认值：无 配置原则：无 |

#### 使用实例

查询已经配置的所有的VLR局向Sgs固定速率流控参数。

```
%%LST MMESGSFIXEDFC:;%%
RETCODE = 0  操作成功  
操作结果如下 ------------              
                                            MME索引   =  1 
              Location Update Request速率门限(个/秒)  =  2000       
                    Detach Indication速率门限(个/秒)  =  2000                  
                               Paging速率门限(个/秒)  =  2000

(结果个数 = 1)  
---    结束
```
