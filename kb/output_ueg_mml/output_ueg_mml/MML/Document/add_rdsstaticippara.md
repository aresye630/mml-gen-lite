# 增加园区用户IP地址信息（ADD RDSSTATICIPPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于增加Radius静态IP地址信息、UDM静态IP地址信息或5G LAN组信息。

## 注意事项

- 该命令执行后只对新激活用户生效。

- 该命令配置仅在下面两种情况下生效。第一种情况：SET CPAPNADDRESSATTR命令的“IPV4ALLOCTYPE”或者“IPV6ALLOCTYPE”参数配置为RADIUS（RADIUS），且SET EDGESMCOMMFUNC命令开启“RDSSTATICIPSW”开关。第二种情况：SET EDGESMCOMMFUNC命令开启“UDMSTATICIPSW”开关，开启UDM全故障Bypass功能（SET SMFUDMBYPASS命令开启“UDMBYPASS”开关）并且用户进入UDM Bypass状态。
- Radius服务器下发的静态IP地址优先级高于该命令配置。
- UDM下发的静态IP地址和GROUPID优先级高于该命令配置。

- 最多可输入50000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

|:------------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

| APN         | APN名称     | 可选必选说明：必选参数  参数含义：该参数用于指定APN实例名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“ ” ”、“ ` ”特殊字符，不区分大小写。  默认值：无  配置原则：无                                                                                                                                                                                               |

| IPV4ADDRESS | IPv4地址    | 可选必选说明：该参数在"ADDRTYPE"配置为"IPV4"、"IPV4V6"时为条件可选参数。  参数含义：IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。1.取值范围：1.0.0.0~255.255.255.254。2.IPv4地址不能为组播地址（224.x.y.z）和环回地址(127.x.y.z)。3.IPv4地址必须是A、B或者C类地址。  默认值：无  配置原则：无                                                                                                                                                                                                                     |
| IPV6ADDRESS | IPv6地址    | 可选必选说明：该参数在"ADDRTYPE"配置为"IPV6"、"IPV4V6"时为条件可选参数。  参数含义：该参数用于指定IPV6类型地址。  数据来源：全网规划  取值范围：IPv6地址类型。1.取值范围：::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。2.IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址（::1）、链路本地地址（FE80::/10）、组播地址（FF00::/8）和IPv4映射地址（::FFFF:XXXX:XXXX），若为IPv4兼容地址时，需判断是否符合IPv4地址要求。  默认值：无  配置原则：无                                                                                       |
| GROUPID     | 5G LAN组ID | 可选必选说明：该参数在"ADDRTYPE"配置为"Ethernet"时为条件必选参数。该参数在"ADDRTYPE"配置为"IPV4"、"IPV6"、"IPV4V6"时为条件可选参数。  参数含义：该参数用于指定5G LAN群组的ID。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是18~37。字母大小写不敏感且全局唯一。  默认值：无  配置原则：  GROUPID以连字号分为4段，形式为GroupServiceID-MCC-MNC-LocalGroupID。其中，GroupServiceID长度为8，只能输入数字或者范围为A到F或a-f的字母；MCC长度为3，只能输入数字；MNC长度为2~3，只能输入数字；LocalGroupID长度为2~20的偶数，只能输入数字或者范围为A到F或a-f的字母。例如，A0000001-460-003-01，A0000001-460-003-A000000001。 |

## 使用实例

增加基于IMSI值123456789012345，APN值huawei.com的Radius静态IPv4地址：

```
ADD RDSSTATICIPPARA: IMSI="123456789012345", APN="huawei.com", ADDRTYPE=IPV4, IPV4ADDRESS="192.168.10.10";
```
