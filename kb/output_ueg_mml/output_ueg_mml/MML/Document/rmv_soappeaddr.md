# 删除SOAP对端地址段(RMV SOAPPEADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在系统中删除配置的SOAP对端地址段记录。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

需要删除SOAP对端标识下具体网段的SOAP对端地址段记录时，请同时输入“SOAP对端标识”参数和“网段编号”参数。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                               |
|:-------|:---------|:-----------------------------------------------------------------------------------|
| ID     | SOAP对端标识 | 可选必选说明：必选参数 标识SOAP对端地址段的关键字段之一，用于指定需要删除哪个ID对应SOAP对端地址段记录。 取值范围：1～255               |
| ADDRID | 网段编号     | 可选必选说明：必选参数 标识SOAP对端地址段的关键字段之一，用于指定需要删除当前“SOAP对端标识”下哪个网段ID对应的SOAP对端地址段记录。 取值范围：0～7 |

## 使用实例

1. 删除“SOAP对端标识”为“1”、“网段编号”为“2”的SOAP对端地址段记录：

   ```
   RMV SOAPPEADDR: ID=1, ADDRID=2;
   ```
