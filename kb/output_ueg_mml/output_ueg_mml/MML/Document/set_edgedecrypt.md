# 解密配置（SET EDGEDECRYPT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UDM**

该命令用于设置园区UDM数据同步文件解密配置。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | DECRYALGO   | OPTIONALPARA   | KEYGENALGO   |   ITERATION | MD     |   ENCODEMODE |
|:-------|:------------|:---------------|:-------------|------------:|:-------|-------------:|
| 初始值    | AES256CBC   | Disable        | Default      |           0 | sha256 |          nan |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                                                       |
|:-------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DECRYALGO    | 解密算法   | 可选必选说明：可选参数 参数含义：该参数用于指定用户数据文件的解密算法。 数据来源：全网规划 取值范围：当前版本只支持AES256-CBC。 AES256CBC：表示加密算法为AES256-CBC。 默认值：无 配置原则：该参数已弃用。                                                                                                                                     |
| PASSWORD     | 密码     | 可选必选说明：可选参数 参数含义：该参数用于设置生成密钥的密码。 数据来源：全网规划 取值范围：密码类型，允许输入的密码明文长度为6~64，允许输入字符包括：英文大写字母、英文小写字母、数字：0～9、特殊字符：~ ! # % ^ * ( ) _ - + [ ] { } < > . ?。 默认值：无 配置原则：无                                                                                               |
| PWDCFM       | 密码确认   | 可选必选说明：可选参数 参数含义：该参数用于二次确认生成密钥的密码。 数据来源：全网规划 取值范围：密码类型，允许输入的密码明文长度为6~64，允许输入字符包括：英文大写字母、英文小写字母、数字：0～9、特殊字符：~ ! # % ^ * ( ) _ - + [ ] { } < > . ?。 默认值：无 配置原则：无                                                                                             |
| OPTIONALPARA | 可选参数   | 可选必选说明：可选参数 参数含义：该参数用于打开可选参数配置开关。 数据来源：全网规划 取值范围： Disable：关闭可选参数开关。Enable：打开可选参数开关。 默认值：无 配置原则： 建议采用可选参数保持缺省值，以提升解密算法的性能。可选参数的修改在下一次执行用户数据文件导入时生效。OPTIONALPARA配置为Disable时，对应大网UDM设置-salt随机生成盐值，md为sha256，其他参数为默认值；OPTIONALPARA配置为Enable时，需要配置各参数与大网加密参数一致。 |
| KEYGENALGO   | 密钥生成算法 | 可选必选说明：条件可选参数 前提条件：该参数在“OPTIONALPARA”配置为“Enable”时为可选参数。 参数含义：该参数设置密钥生成算法。 数据来源：全网规划 取值范围： Default：缺省算法。PBKDF2：PBKDF2算法。 默认值：无 配置原则：配置值需要与大网UDM一致，否则用户数据文件无法解密。                                                                                             |
| ITERATION    | 迭代次数   | 可选必选说明：条件可选参数 前提条件：该参数在“OPTIONALPARA”配置为“Enable”时为可选参数。 参数含义：该参数设置PBKDF2的迭代次数。 数据来源：全网规划 取值范围：整数类型，取值范围为0～10000。 默认值：无 配置原则： 缺省值为0，表示PBKDF2算法按照默认次数迭代计算Key。配置值要与大网UDM一致，否则用户数据文件无法解密。                                                                      |
| MD           | 消息摘要算法 | 可选必选说明：条件可选参数 前提条件：该参数在“OPTIONALPARA”配置为“Enable”时为可选参数。 参数含义：该参数用于设置生成密钥使用的消息摘要算法。 数据来源：全网规划 取值范围： md5：md5算法。sha256：sha256算法。 默认值：无 配置原则： 配置值要与大网UDM一致，否则用户数据文件无法解密。md5算法有安全风险，不推荐使用。                                                                      |
| ENCODEMODE   | 密文编码模式 | 可选必选说明：条件可选参数 前提条件：该参数在“OPTIONALPARA”配置为“Enable”时为可选参数。 参数含义：该参数用于设置密文编码方式。 数据来源：全网规划 取值范围： None：无。Base64：密文使用Base64编码；解密前需要先用Base64解码。 默认值：无 配置原则：配置值要与大网UDM一致，否则用户数据文件无法解密。                                                                              |

#### 使用实例

设置园区UDM数据同步文件解密配置：

```
SET EDGEDECRYPT: DECRYALGO=AES256-CBC;
```
