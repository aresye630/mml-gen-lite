# 查询GUTI选网功能区域成员（LST GUTISELAREAMEM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询指定GUTI选网功能的区域或者系统中配置的所有GUTI选网功能的区域的跟踪区成员。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识            | 参数名称         | 参数说明                                                                                                                                                   |
|:----------------|:-------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
| GUTISELAREACODE | GUTI选网功能区域编码 | 可选必选说明：可选参数  参数含义：该参数用于标识AMF服务的某区域范围。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~128。  默认值：无  配置原则：  GUTISELAREACODE参数依赖于ADD GUTISELAREACODE命令的GUTISELAREACODE参数。 |

## 使用实例

- 查询编码为“GUTISelZone”的区域成员信息，执行如下命令：

  ```
  %%LST GUTISELAREAMEM:;%%
  RETCODE = 0  操作成功

  The result is as follows
  ------------------------
  GUTI选网功能区域编码  =  GUTISelZone
                   MCC  =  123
                   MNC  =  45
      跟踪区编码起始值  =  120101
      跟踪区编码结束值  =  120101
              描述信息  =  NULL
  (结果个数 = 2)

  ---    END
  ```
- 查询系统中当前配置的所有区域的信息，执行如下命令：

  ```
  %%LST GUTISELAREAMEM:;%%
  RETCODE = 0  操作成功

  The result is as follows
  ------------------------
  GUTI选网功能区域编码  MCC  MNC  跟踪区编码起始值  跟踪区编码结束值  描述信息  

  GUTISelZone            123  45   120101            120101            NULL         
  GUTISelZone2           123  001  123456            123456            NULL         
  (结果个数 = 2)

  ---    END
  ```

## 输出结果说明

| 输出项名称        | 输出项解释                                   |
|:-------------|:----------------------------------------|
| GUTI选网功能区域编码 | 该参数用于标识AMF服务的某区域范围。                     |
| MCC          | 该参数用于表示组成通用区域的位置区成员的移动国家码，与无线接入网的MCC一致。 |
| MNC          | 该参数用于表示组成通用区域的位置区成员的移动网号，与无线接入网的MNC一致。  |
| 跟踪区编码起始值     | 该参数用于表示跟踪区编码的起始值。                       |
| 跟踪区编码结束值     | 该参数用于表示跟踪区编码的结束值。                       |
| 描述信息         | 该参数是对区域成员的描述信息，在运维中起到助记的作用。             |
