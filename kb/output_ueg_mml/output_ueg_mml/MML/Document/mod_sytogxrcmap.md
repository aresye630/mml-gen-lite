# 修改Sy/N28结果码映射（MOD SYTOGXRCMAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在UPCF配置数据库中修改一条Sy/N28结果码映射记录。

在该命令中，系统通过“Sy/N28接口结果码”和“PCEF主机名”参数来标识一条Sy/N28结果码映射记录。

## 注意事项

无。

## 使用实例

- 修改一条Sy结果码映射，“Sy/N28接口结果码”为“RC3004”，“CCA消息结果码”为“RC2001”,“RAR/UpdateNotify消息原因码”为“RC9999”，“PCEF主机名”为“PCEF01”。

  ```
  MOD SYTOGXRCMAP: SYRC=RC3004, CCARC=RC2001, RARRC=RC9999, HOSTNAME="PCEF01";
  ```

  ```
  %%MOD SYTOGXRCMAP: SYRC=RC3004, CCARC=RC2001, RARRC=RC9999, HOSTNAME="PCEF01";%%
  RETCODE = 0  操作成功

  ---    END
  ```
- 修改一条N28结果码映射，“Sy/N28接口结果码”为“RC400\_5”，“CCA消息结果码”为“RC2001”,“RAR/UpdateNotify消息原因码”为“RC9999”，“CreateResponse结果码”为“RC201”，“PCEF主机名”为“NULL”。

  ```
  MOD SYTOGXRCMAP: SYRC=RC400_5, CCARC=RC2001, RARRC=RC9999, N7RC=RC201, HOSTNAME="NULL";
  ```

  ```
  %%MOD SYTOGXRCMAP: SYRC=RC400_5, CCARC=RC2001, RARRC=RC9999, N7RC=RC201, HOSTNAME="NULL";%%
  RETCODE = 0  操作成功

  ---    END
  ```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                   | 原因分析               | 处理建议   |
|------:|:------------------------|:-------------------|:-------|
| 58273 | 参数ISDEFAULTRECORD不允许修改。 | 不允许修改参数“是否默认记录”的值。 | 无须处理。  |
