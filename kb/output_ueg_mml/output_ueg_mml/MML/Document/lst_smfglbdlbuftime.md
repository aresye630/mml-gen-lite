# 查询全局下行报文缓存时长（LST SMFGLBDLBUFTIME）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C**

该命令用来查询全局下行报文缓存时长。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询全局下行报文缓存时长：

```
%%LST SMFGLBDLBUFTIME:;%%
RETCODE = 0 操作成功

结果如下
----------------------------
普通用户下行报文缓存时长(秒)    =  9
NB-IoT用户下行报文缓存时长(秒)  =  6
(结果个数 = 1)
--- END
```

## 输出结果说明

| 输出项名称               | 输出项解释                       |
|:--------------------|:----------------------------|
| 普通用户下行报文缓存时长(秒)     | 该参数用于指定全局的普通用户下行报文缓存时长。     |
| NB-IoT用户下行报文缓存时长(秒) | 该参数用于指定全局的NB-IoT用户下行报文缓存时长。 |
