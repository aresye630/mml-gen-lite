# 查询CSLB插件侧VPN对应的转发拓扑（DSP LBPLUGINVPNTOPO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

查询CSLB插件侧VPN对应的转发拓扑。用于检查插件侧拓扑信息和服务侧拓扑信息一致性。转发拓扑由高字节TB、低字节TB以及TP信息表示，分为VPN对应的VNRS转发拓扑与VPN对应的CSLB转发拓扑

#### 注意事项

- 该命令仅限于开发和测试使用。
- 该命令批量下发可能导致执行超时。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                          |
|:----------|:---------|:------------------------------------------------------------------------------------------------------------------------------|
| SRVVNFCID | 业务VNFCID | 可选必选说明：必选参数 参数含义：该参数用于指定业务VNFC的唯一标识，通过在窗口下执行LST NODE获得，所得NODE ID（节点ID）即为业务VNFC ID 数据来源：本端规划 取值范围：整数类型，取值范围为0~4294967295 默认值：无 |
| PLUGINID  | 插件ID     | 可选必选说明：必选参数 参数含义：业务VNFC注册CSLB插件的ID号，通过在窗口下执行DSP LBPLUGIN获得，所得Plugin ID即为插件ID 数据来源：本端规划 取值范围：整数类型，取值范围为0~4294967295 默认值：无      |
| VPNNAME   | VPN名称    | 可选必选说明：必选参数 参数含义：VPN名称 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0~63 配置原则：公网填“_public_” 默认值：无                                              |
| TOPOTYPE  | 拓扑类型     | 可选必选说明：必选参数 参数含义：改参数用于指定是查询VNRS的拓扑还是查询CSLB的拓扑 数据来源：本端规划 取值范围：“MPE(CSLB的转发面拓扑)”“SFE(VNRS的转发面拓扑)” 默认值：无                         |
| HTB       | 高字节TB    | 可选必选说明：可选参数 参数含义：表示TB的高16位。TB全称是Target Blade，即目标板 数据来源：本端规划 取值范围：整数类型，取值范围为0~65535 默认值：无                                      |
| LTB       | 低字节TB    | 可选必选说明：可选参数 参数含义：表示TB的低32位。TB全称是Target Blade，即目标板 数据来源：本端规划 取值范围：整数类型，取值范围为0~4294967295 默认值：无                                 |
| TP        | TP       | 可选必选说明：可选参数 参数含义：表示目标端口。TP全称是Target Port 数据来源：本端规划 取值范围：整数类型，取值范围为0~4294967295 默认值：无                                          |

#### 使用实例

- 查询CSLB插件侧VPN对应的转发地址信息

  `DSP LBPLUGINVPNTOPO: SRVVNFCID=4, PLUGINID=1, VPNNAME="_public_", TOPOTYPE=SFE, LTB=70;`

  ```
  RETCODE = 0  操作成功

  操作结果如下:
  -------------
  业务VNFCID  =  4
      插件ID  =  1
     VPN名称  =  _public_
    拓扑类型  =  VNRS的转发面拓扑
    高字节TB  =  0
    低字节TB  =  70
         TP  =  4098
  (结果个数 = 1)
  ---    END
  ```

#### 输出结果说明

| 输出项名称    | 输出项解释                                 |
|:---------|:--------------------------------------|
| 业务VNFCID | 参数含义：表示业务VNFC的唯一标识                    |
| 插件ID     | 参数含义：表示业务VNFC注册CSLB插件的ID号             |
| VPN名称    | 参数含义：表示VPN名称                          |
| 拓扑类型     | 参数含义：表示VNRS的拓扑或者是CSLB的拓扑              |
| 高字节TB    | 参数含义：表示TB的高16位。TB全称是Target Blade，即目标板 |
| 低字节TB    | 参数含义：表示TB的低32位。TB全称是Target Blade，即目标板 |
| TP       | 参数含义：表示目标端口。TP全称是Target Port          |
