# 删除ULCL属性（RMV ULCLPROP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SMF**

该命令用于删除ULCL属性。

#### 注意事项

- 该命令执行后立即生效。
- 如果只输入“ULCL属性名称”，删除所有该“ULCL属性名称”的DNAI配置。如果不输入参数，表示删除系统中所有的ULCL属性。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称      | 参数说明                                                                                                                                                        |
|:-------------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ULCLPROPNAME | ULCL属性名称  | 可选必选说明：可选参数 参数含义：该参数用于设置ULCL的属性名称。该参数可供RULE命令中的“策略名称”参数引用。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无                                      |
| DNAI         | 数据网络访问标识符 | 可选必选说明：可选参数 参数含义：该参数用于设置ULCL属性名称相关联的数据网络访问标识符。该参数的数据规划上需要和PNFDNAI命令中的“数据网络访问标识”参数保持一致。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数不可单独设置。 |

#### 使用实例

假如运营商需要删除一个ULCL属性名称与DNAI对应关系，ULCL属性名称为“testulclpropname”，DNAI为“testdnai”：

```
RMV ULCLPROP: ULCLPROPNAME="testulclpropname", DNAI="testdnai";
```
