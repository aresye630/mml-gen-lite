# 查询PCRF对端OCS接入点链路状态信息(DSP POCSL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在UPCF网元下查询PCRF实体和对端OCS接入点实体间链路的状态信息，以便管理人员了解链路的状态。

该命令的使用场景：开局场景下或系统运行中，当前的PCRF与对端OCS接入点间的链路通讯出现异常的时候，管理人员可以通过该命令来了解链路的状态。

## 注意事项

无。

## 参数说明

| 参数ID   | 参数名称   | 参数描述                                                                                                                                                                                                                                                                                                                                                                                |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PCRFID | PCRF标识 | 用于请求系统显示指定PCRF标识的链路状态信息；若不输入，则显示所有PCRF标识下的链路状态信息。 取值范围：1 默认值：无。                                                                                                                                                                                                                                                                                                                     |
| CPID   | 接入点标识  | 用于请求系统显示指定接入点标识的链路状态信息；若不输入，则显示所有接入点标识下的链路状态信息。 取值范围：0～15 默认值：无。                                                                                                                                                                                                                                                                                                                    |
| LNKID  | 链路ID   | 用于请求系统显示指定对端链路ID的链路状态信息；若不输入，则显示所有对端链路ID的链路状态信息。 取值范围：0～67 默认值：无。                                                                                                                                                                                                                                                                                                                   |
| STATE  | 链路状态   | 用于请求系统显示指定链路状态的链路状态信息；若不输入，则显示所有状态的链路状态信息。当链路状态为LINKDOWN(离线)时，PCRF对端OCS接入点链路是不连通的，无法和对端OCS接入点交互。当对应链路的管理状态为“DISABLE”（通过LST POCSL查看）或者其他原因导致链路故障时，链路状态是LINKDOWN(离线)。同时会产生ALM-34078 PCRF与OCS链路故障的告警。当链路状态为LINKUP(在线)时，PCRF对端OCS接入点链路是连通的，此时可以和对端OCS接入点交互。当链路状态为UNKNOWN(未知)时，无法获取链路状态。 取值说明： LINKDOWN(离线)LINKUP(在线)UNKNOWN(未知)  说明： 当链路未关联上DLB实例时，无法获取链路状态，链路状态的查询返回结果为UNKNOWN。 默认值：无。 |

## 使用实例

1. 查询所有的PCRF实体和对端OCS接入点实体链路的状态信息。

   ```
   DSP POCSL:;
   ```

   ```
   %%DSP POCSL:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
     PCRF标识  =  1
   接入点标识  =  0
       链路ID  =  0
    DLB实例号  =  11670318715285290961
     链路状态  =  离线
   (结果个数 = 1)

   ---    END
   ```
2. 查询链路状态为离线的所有PCRF和对端OCS接入点之间链路的状态信息。

   ```
   DSP POCSL:STATE=LINKDOWN;
   ```

   ```
   %%DSP POCSL: STATE=LINKDOWN;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
     PCRF标识  =  1
   接入点标识  =  0
       链路ID  =  0
    DLB实例号  =  11670318715285290961
     链路状态  =  离线
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                                                     |
|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
| PCRF标识  | 用于返回OCS接入点链路的PCRF标识信息。                                                                                                                                    |
| 接入点标识   | 用于返回OCS接入点标识信息。                                                                                                                                           |
| 链路ID    | 用于返回OCS接入点链路ID信息。                                                                                                                                         |
| DLB实例号  | 用于描述DLB服务的实例号。                                                                                                                                            |
| 链路状态    | 用于返回OCS接入点链路状态信息： 链路状态为LINKDOWN(离线)，说明PCRF实体和对端OCS接入点实体之间未建立链路，或者链路故障。链路状态为LINKUP(在线)，说明PCRF实体和对端OCS接入点实体之间已经建立链路。链路状态UNKNOWN(未知)，说明链路未关联上DLB实例，无法获取链路状态。 |
