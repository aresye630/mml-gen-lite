# 显示删除NSE列表下的用户任务运行状态(DSP NSEUSR)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用网元：SGSN**

该命令用于查询**RMV NSEUSR**任务运行状态。当**RMV NSEUSR**任务正在运行时，该命令可以查询任务的剩余时间。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询删除NSE列表下的用户的任务状态：

DSP NSEUSR:;

```
%%DSP NSEUSR:;%%
RETCODE = 0  执行成功。

结果如下
-------------------------------
           任务状态 = 正在运行
    任务剩余时间(s) = 1200

(结果个数 = 1)

---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                                 |
|:--------|:--------------------------------------|
| 任务的运行状态 | 删除NSE列表下的用户的任务的运行状态。 取值说明： “停止”“正在运行” |
| 任务的剩余时间 | 删除NSE列表下的用户的任务的剩余时间。                  |
