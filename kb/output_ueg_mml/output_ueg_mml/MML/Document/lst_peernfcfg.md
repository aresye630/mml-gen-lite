# 查询NF对端参数（LST PEERNFCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

用于在配置数据库中查询对端参数配置信息。

- 如果需要查询全部对端参数配置信息，请不要输入任何参数。
- 如果需要查询某个对端参数配置信息，请依据参数说明输入查询条件。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                     |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFTYPE | NF类型   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个NF类型来查询NF对端参数配置信息；若不输入，则表示所有的NF类型。 取值范围：NRF(NRF)AMF(AMF)SMF(SMF)BSF(BSF)CHF(CHF)AF(AF)SCP(SCP)UDR(UDR)NWDAF(NWDAF)HPCF(HPCF) 默认值：无。 配置原则：无。 |

## 使用实例

- 查询所有的对端参数配置信息。

  ```
  LST PEERNFCFG:;
  ```

  ```
  %%LST PEERNFCFG:;%%
  RETCODE = 0  操作成功

  操作结果如下
  ------------
  NF类型  最大NF数    最大链路数    NF老化时长  

  SMF     300         50            24          
  BSF     32          32            24          
  (结果个数 = 2)

  ---    END
  ```
- 查询SMF对端参数配置信息。

  ```
  LST PEERNFCFG: NFTYPE=SMF;
  ```

  ```
  %%LST PEERNFCFG: NFTYPE=SMF;%%
  RETCODE = 0  操作成功

  操作结果如下
  ------------
       NF类型  =  SMF
     最大NF数  =  300
   最大链路数  =  50
   NF老化时长  =  24
  (结果个数 = 1)

  ---    END
  ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD PEERNFCFG**命令的参数说明。
