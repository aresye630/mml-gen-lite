# 增加VPN信息配置(ADD VPNINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在数据库增加一条VPN信息相关记录。

该命令在配置CSLB基础数据时使用，用于配置VPN名称。

## 注意事项

系统中增加的VPNINFO配置的最大记录数不能超过16。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                     |
|:------------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VPNINFONAME | VPNINFO名称 | 可选必选说明：必选参数。 参数含义：用于标识对外IP使用的VPN配置的名称。 取值范围：长度不超过128的由数字和字母组成的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。                                                               |
| VPNNAME     | VPN名称     | 可选必选说明：必选参数。 参数含义：用于标识VPNName配置信息。该参数必须先由ADD L3VPNINST命令定义后才能在此处引用。 取值范围：长度不超过31的由数字和字母组成的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。                                   |
| VPNID       | VPN ID    | 可选必选说明：必选参数。 参数含义：用于标识VPN ID配置信息。 取值范围：0～255 默认值：无。 配置原则：无。                                                                                                              |
| ATTR        | VPN属性     | 可选必选说明：可选参数。 参数含义：用于标识对外IP的VPN属性，表明该IP用于对接移动网络还是园区网络。 取值范围： MobileNetwork(对接移动网络) Campus(对接园区网络) 默认值：MobileNetwork(对接移动网络) 配置原则：如果该参数配置错误，在移动网络和园区网络使用不同的VPN时，会导致信令消息全损。 |

## 使用实例

在UDM初始配置阶段，增加一条VPN信息配置数据。“VPNINFO名称”为“vpn1”，“VPN名称”为“VRF\_T\_DATA”，“VPN ID”为“1”。

```
ADD VPNINFO: VPNINFONAME="vpn1", VPNNAME="VRF_T_DATA", VPNID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                 | 原因分析                          | 处理建议                                         |
|-------:|:----------------------|:------------------------------|:---------------------------------------------|
| 360061 | 无效的VPNINFO名称。         | 增加VPN信息时使用的“VPNINFO 名称”参数不合法。 | 请确保输入的“VPNINFO 名称”参数的取值符合取值范围。               |
| 360062 | 无效的VPN名称。             | 增加VPN信息时使用的“VPN 名称”参数不合法。     | 请确保输入的“VPN 名称”参数的取值符合取值范围。                   |
| 360022 | 参数取值无效:相同的VPNID已经被添加。 | 增加VPN信息时使用的“VPN ID”已经被添加。     | “VPN ID”不可重复，新添加的“VPN ID”不能和已经添加的“VPN ID”相同。 |
|    504 | 当前配置记录数达到上限。          | VPN配置数据已达上限，无法新增。             | 使用LST VPNINFO查询VPN配置信息，删除无效的VPN数据并重新添加。      |
