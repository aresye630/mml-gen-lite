# 设置IP FRR（SET IPFRR）

- 命令功能

- 操作用户权限

#### 命令功能

该命令用来使能IP FRR功能。

在设备上存在多种路由协议生成的路由时，如果想在部分路由故障后能够快速切换以使报文转发顺畅，可以通过配置此命令使能协议路由间的IP FRR功能。

例如，在设备上存在OSPF协议生成的一条目的地址为10.1.1.1的OSPF路由，优先级为15。同时再配置一条到目的地址10.1.1.1的静态路由，优先级为60。在未使能IP FRR的情况下，优选OSPF路由。在使能IP FRR后，会生成一条新的路由，OSPF路由作为主路由，静态路由作为备份路由。这样，在OSPF路由故障时，系统可以快速切换到静态路由，保证转发畅通。

#### 注意事项

- 该命令执行后立即生效。
- 该命令存在系统初始记录，参数的初始设置值如下表：

|   FRRENABLE |
|------------:|
|           0 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                                                    |
|:----------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------|
| AFTYPE    | 地址族     | 可选必选说明：必选参数 参数含义：该参数用于指定地址族类型。支持IPv4和IPv6单播地址族。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。ipv6unicast：IPv6单播。 默认值：无                                       |
| VRFNAME   | VPN实例名称 | 可选必选说明：必选参数 参数含义：该参数用于指定VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则： 需要确保指定的VPN实例在设备上已经通过ADD L3VPNINST创建，公网除外。必须已经通过ADD VPNINSTAF使能了该VPN的地址族。 |
| FRRENABLE | 是否使能FRR | 可选必选说明：必选参数 参数含义：该参数用于指定是否使能IP FRR功能。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无 配置原则：初始值为FALSE。                                                   |

#### 使用实例

配置IPv4公网FRR：

```
SET IPFRR:AFTYPE=ipv4unicast,VRFNAME="_public_",FRRENABLE=TRUE;
```
