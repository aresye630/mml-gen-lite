# 查询IdP元数据(LST IDPMETADATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询已加载的IdP端（即网管）元数据信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询全部IdP元数据的配置信息。

```
LST IDPMETADATA:;
```

```
%%LST IDPMETADATA:;%%
RETCODE = 0  操作成功

操作结果如下
------------------------
元数据名称  =  metadata.xml

(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见LOD IDPMETADATA命令的参数说明。
