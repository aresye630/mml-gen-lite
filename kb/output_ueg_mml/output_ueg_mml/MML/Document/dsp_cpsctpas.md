# 显示SCTP统计信息(DSP CPSCTPAS)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

此命令用于查询SCTP偶联统计信息。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                   |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------|
| DSPAST | 统计类型   | 可选必选说明：必选参数 参数含义：该参数用于指定SCTP偶联统计类型。 取值范围：“PROINT(协议内部实体)”“GLBTR(全局实体)”“ERROR(错误实体)”“ASSOC(偶联实体)” 默认值：无 |
| RUNAME | RU名称   | 可选必选说明：必选参数 参数含义：该参数用于指定SPU资源单元名。该参数可以通过DSP RU命令查询。 数据来源：整网规划。 取值范围：1~63 位字符串 默认值：无                    |
| PN     | 进程号    | 可选必选说明：必选参数 参数含义：该参数用于设置需要查询的SGP进程的进程号。 取值范围：0～11 默认值：无                                                |
| ASSID  | 偶联ID   | 可选必选说明：条件必选参数 参数含义：该参数用于指定偶联ID。 前提条件：此参数在“统计类型”参数配置为“ASSOC(偶联实体)”值后生效。 取值范围：0～4294967295 默认值：无         |
