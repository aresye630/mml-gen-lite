# 清除GTSM统计（RTR GTSMSTATISTICS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于清除GTSM统计计数。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| RUNAME | RU名称   | 可选必选说明：可选参数 参数含义：该参数用于清除指定资源单元的GTSM统计。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。通过DSP RU命令可以查询资源单元信息。 默认值：无 配置原则： 当该参数为空时会清除所有资源单元的GTSM统计。可以指定某一资源单元进行清除统计。 |

#### 使用实例

- 清除某一资源单元的统计信息：

  ```
  RTR GTSMSTATISTICS:RUNAME="VNODE_VNRS_VNFC_IPU_0064";
  ```
- 清除所有资源单元的统计信息：

  ```
  RTR GTSMSTATISTICS:;
  ```
