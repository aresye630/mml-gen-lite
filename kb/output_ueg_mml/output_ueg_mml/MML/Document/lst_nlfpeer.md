# 查询NLF对端(LST NLFPEER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询NLF对端服务器的配置信息。

- 如果需要查询全部NLF对端服务器信息，请不要输入任何参数。
- 如果需要查询指定NLF对端服务器信息，请依据参数说明输入查询的条件。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                            |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------|
| PEERID   | 对端ID   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个对端ID来查询NLF对端服务器信息；若不输入，则表示所有的对端ID。 取值范围：0～31 默认值：无。 配置原则：无。                        |
| PEERNAME | 对端名称   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个对端名称来查询NLF对端服务器信息，值域类型为字符串，区分大小写；若不输入，则表示所有的对端名称。 取值范围：长度不超过128的字符串 默认值：无。 配置原则：无。 |
| PEERTYPE | 对端类型   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个对端类型来查询NLF对端服务器信息；若不输入，则表示所有的对端类型。 取值范围： SFTP(SFTP) 默认值：无。 配置原则：无。                 |

## 使用实例

1. 查询所有的NLF对端服务器配置信息。

   ```
   LST NLFPEER:;
   ```

   ```
   %%LST NLFPEER:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   对端ID  对端名称  对端类型  

   1       NLF_sftp  SFTP      
   2       SFTP_SER  SFTP      
   (结果个数 = 2)

   ---    END
   ```
2. 查询一条NLF对端服务器配置信息，“对端ID”为“1”。

   ```
   LST NLFPEER: PEERID=1;
   ```

   ```
   %%LST NLFPEER: PEERID=1;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
     对端ID  =  1
   对端名称  =  NLF_sftp
   对端类型  =  SFTP
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见ADD NLFPEER命令的参数说明。
