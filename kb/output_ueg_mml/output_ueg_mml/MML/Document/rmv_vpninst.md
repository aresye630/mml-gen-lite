# 删除VPN实例（RMV VPNINST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于删除指定的VPN实例。

#### 注意事项

- 该命令执行后立即生效。
- 已被其他对象绑定的VPN实例不允许被删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                            |
|:------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------|
| VPNINSTANCE | VPN实例名 | 可选必选说明：必选参数 参数含义：该参数用于指定VPN实例，该参数一般由运营商规划给出。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～31。区分大小写。 默认值：无 配置原则：“_public_”是公网缺省VPN的实例名，不允许用户删除。 |

#### 使用实例

删除VPNInst业务配置，VPN实例名称为vpn1：

```
RMV VPNINST:VPNINSTANCE="vpn1";
```
