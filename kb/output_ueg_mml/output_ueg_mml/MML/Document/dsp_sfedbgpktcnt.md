# SFE报文统计（DSP SFEDBGPKTCNT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询SFE报文统计信息。

#### 注意事项

该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                      |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------|
| RUNAME | 资源单元名称 | 可选必选说明：必选参数 参数含义：该参数用于指定资源单元名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则： 区分大小写，不支持空格。使用DSP RU查看RU名称。 |

#### 使用实例

查询指定可用RU的debug的SFE报文统计信息：

```
DSP SFEDBGPKTCNT:RUNAME="VNODE_VNRS_VNFC_IPU_0066";
```

```
RETCODE = 0  操作成功。

结果如下
------------------------
匹配计数 = 0
(结果个数 = 1)
---    END
```
