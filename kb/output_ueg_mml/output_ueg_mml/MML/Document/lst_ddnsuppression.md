# 查询DDN抑制功能配置（LST DDNSUPPRESSION）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C**

该命令用来查询DDN抑制功能配置信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询DDN抑制功能配置：

```
%%LST DDNSUPPRESSION:;%%
RETCODE = 0  操作成功

输出结果如下
------------------------
DDN抑制功能开关  =  不使能
   监控时长(分)  =  5
    DDN失败次数  =  10
   抑制时长(分)  =  5
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称     | 输出项解释               |
|:----------|:--------------------|
| DDN抑制功能开关 | 该参数用于控制DDN抑制功能是否开启。 |
| 监控时长(分)   | 该参数用于配置DDN抑制的监控时长。  |
| DDN失败次数   | 该参数用于配置DDN失败次数。     |
| 抑制时长(分)   | 该参数用于配置DDN抑制的时长。    |
