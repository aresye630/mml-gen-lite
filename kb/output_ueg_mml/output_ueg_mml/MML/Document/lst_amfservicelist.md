# 查询AMF服务列表（LST AMFSERVICELIST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

本命令用于查询特定AMF功能实体的服务列表。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询AMF功能实体服务列表：

```
LST AMFSERVICELIST:;
%%LST AMFSERVICELIST:;%%
RETCODE = 0  操作成功

结果如下
------------------------
AMF服务名称  =  namfComm
(结果个数 = 1)
```

## 输出结果说明

| 输出项名称   | 输出项解释           |
|:--------|:----------------|
| AMF服务名称 | 特定AMF功能实例的服务名称。 |
