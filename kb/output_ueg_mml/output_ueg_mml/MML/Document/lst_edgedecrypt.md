# 查询解密配置（LST EDGEDECRYPT）

- 命令功能
- 注意事项
- 操作用户权限

#### 命令功能

**适用NF：UDM**

该命令用于查询园区UDM数据同步文件解密配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询园区UDM数据同步文件解密配置：

```
LST EDGEDECRYPT:;
```

