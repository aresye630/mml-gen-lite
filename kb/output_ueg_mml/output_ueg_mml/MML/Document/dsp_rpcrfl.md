# 查询PCRF容灾PCRF链路状态信息(DSP RPCRFL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为维护命令，用于在UPCF网元下查询PCRF实体和容灾PCRF实体的链路状态信息，以便管理人员了解链路的状态。

- 如果需要查询全部容灾PCRF实体的链路状态信息，请不要输入任何参数。
- 如果需要查询某个容灾PCRF实体的链路状态信息，请依据参数说明输入相应的参数作为查询的限制条件。

开局场景下或系统运行中，当前的PCRF实体与容灾PCRF实体之间的链路通讯出现异常的时候，管理人员可以通过该命令来了解链路的状态。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                              |
|:--------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PCRFID  | 本端PCRF标识 | 用于请求系统显示指定本端PCRF标识的链路状态信息；若不输入，则显示所有本端PCRF标识下的链路状态信息。 取值范围： 1 默认值： 无。                                                                                                                                                                                                                                                                             |
| RPCRFID | 容灾PCRF标识 | 用于请求系统显示指定容灾PCRF标识的链路状态信息；若不输入，则显示所有容灾PCRF标识下的链路状态信息。 取值范围： 0～5 默认值： 无。                                                                                                                                                                                                                                                                           |
| LNKID   | 链路标识     | 用于请求系统显示指定对端链路标识的链路状态信息；若不输入，则显示所有对端链路标识的链路状态信息。 取值范围： 0～65 默认值： 无。  说明： 当本地PCRF的工作模式为 “服务端”时，执行本命令时“链路标识”支持配置的最大链路数不能超过DLB实例总个数。当本地PCRF的工作模式为 “客户端”时，执行本命令时“链路标识”支持配置的最大链路数不能超过DLB实例总个数*6。                                                                                                                                                       |
| STATE   | 链路状态     | 用于请求系统显示指定链路状态的链路状态信息；若不输入，则显示所有状态的链路状态信息。 各参数选项的含义是： LINKDOWN(离线)：当链路状态为LINKDOWN(离线)时，本地PCRF与容灾PCRF实体链路是不连通的，无法和容灾PCRF实体交互。当对应链路的管理状态为“DISABLE”（通过LST RPCRFL查看）或者其他原因导致链路故障时，链路状态是LINKDOWN(离线)。同时会产生ALM-34089 PCRF与容灾PCRF链路故障的告警。LINKUP(在线)：当链路状态为LINKUP(在线)时，本地PCRF与容灾PCRF实体链路是连通的，此时可以和容灾PCRF实体交互。UNKNOWN(未知) ：当链路未关联上DLB实例时，无法获取链路状态。 默认值： 无。 |

## 使用实例

1. 查询所有的PCRF实体和容灾PCRF实体链路的状态信息。

   ```
   DSP RPCRFL:;
   ```

   ```
   %%DSP RPCRFL:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   本端PCRF标识  =  1
   容灾PCRF标识  =  1
       链路标识  =  0
      DLB实例号  =  13515101374729810040
       链路状态  =  在线
   (结果个数 = 1)

   ---    END
   ```
2. 查询链路状态为离线的所有PCRF和容灾PCRF实体之间链路的状态信息。

   ```
   DSP RPCRFL: STATE=LINKDOWN;
   ```

   ```
   %%DSP RPCRFL: STATE=LINKDOWN;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   本端PCRF标识  =  1
   容灾PCRF标识  =  1
       链路标识  =  1
      DLB实例号  =  13515101374729810040
       链路状态  =  离线
   (结果个数 = 1)

   ---    END
   ```
