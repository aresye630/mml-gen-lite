# 查询HTTP链路信息(DSP HTTPLNKINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询SDK和DCS服务中的缓存对应的HLB服务实例的HTTP链路信息。

- 若要查询全部HLB服务实例的HTTP链路信息，请输入对应的“服务类型”和“实例ID”组合。
- 若要查询某一HLB服务实例的HTTP链路信息。请输入“服务类型”、“实例ID”和“HLB实例ID”的组合。

## 注意事项

- 本命令的配置数据文件不支持使用**EXP MML**命令导出。
- 在链路均衡过程中会出现链路变更，若在均衡过程中执行本命令，查询的结果会与链路均衡前后查询的结果不一致。

## 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                                                                                          |
|:--------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE   | 服务类型    | 可选必选说明：必选参数 参数含义：用于指示系统按照哪个服务类型来查询链路信息。 取值范围：APP(APP)：指SDK服务，服务类型为UdmSubService、NRFClient或UdmAuthService。DCS(DCS)：指DCS服务，服务类型为HttpDisCtrlService。 默认值：无。 配置原则：无。              |
| INSTANCEID    | 实例ID    | 可选必选说明：必选参数 参数含义：用于指示系统按照哪个服务实例ID来查询链路信息。 取值范围：长度不超过32位的字符串。 默认值：无。 配置原则：该参数须通过DSP UDMSERVICE命令查询，才能在此处引用。                                                                    |
| HLBINSTANCEID | HLB实例ID | 可选必选说明：可选参数 参数含义：用于指示系统按照链路所在的哪个HLB服务的实例ID查询链路信息，不输入则查询所有HLB服务实例ID的链路信息。 取值范围：长度不超过32位的字符串。 默认值：无。 配置原则：该参数须通过DSP UDMSERVICE命令查询，才能在此处引用。  说明： “HLB实例ID”的服务类型为UdmHttpService。 |
| PEERNFTYPE    | 对端网元类型  | 可选必选说明：可选参数 参数含义：用于指示系统按照对端网元类型来查询HTTP链路信息。 取值范围： OTHER(OTHER)SCP(SCP)SEPP(SEPP)AUC(AUC) 默认值：无。 配置原则：无。                                                                       |
| WMODE         | 工作模式    | 可选必选说明：条件可选参数 参数含义：用于指示系统按照哪个工作模式来查询HTTP链路信息。 取值范围： SERVER(服务端)CLIENT(客户端) 默认值：CLIENT(客户端)。 配置原则：当“服务类型”参数为“DCS(DCS)”时该参数为可选参数。                                               |

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息，输出项说明如表1所示。

该命令执行异常，会返回对应的错误码及错误码解释信息。常见错误码列表如表2所示。

| 输出项名称   | 输出结果解释                                                                                                                                                                                                                                         |
|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLB实例ID | 用于返回链路所在的HLB服务的实例ID。                                                                                                                                                                                                                           |
| 链路ID    | 用于返回链路ID。                                                                                                                                                                                                                                      |
| 链路类型    | 用于返回链路的类型。 动态静态                                                                                                                                                                                                                                |
| 协议类型    | 用于返回链路的网络协议类型。 取值范围：HTTPHTTPS                                                                                                                                                                                                                  |
| 本端IP地址  | 用于返回链路的本端IP地址。 当“服务类型”为“APP”时，“本端IP地址”不返回参数值。                                                                                                                                                                                                  |
| 本端端口    | 用于返回链路的本端端口。 当“服务类型”为“APP”时，“本端端口”不返回参数值。                                                                                                                                                                                                      |
| 对端IP地址  | 用于返回链路的对端IP地址。                                                                                                                                                                                                                                 |
| 对端端口    | 用于返回链路的对端端口。                                                                                                                                                                                                                                   |
| 链路选择模式  | 用于返回链路集的工作模式，该输出项为通过ADD HTTPLKSPARA命令配置的“链路选择模式”参数值。 当通过MOD UDMSOFTPARA命令设置的“HttpLink(HTTP链路策略)”软参值为“1”时，该输出项的取值范围：优先级：按照优先级进行选链。轮询：对路由组下的所有对端实体轮流选择，即在可用对端之间循环选择。权重：按照权重进行选择。 当通过MOD UDMSOFTPARA命令设置的“HttpLink(HTTP链路策略)”软参值为“0”时，该输出项返回NULL。 |
| 链路权重    | 用于返回链路设置的权重信息。 当“链路选择模式”取值为“优先级”时，“链路权重”返回NULL。                                                                                                                                                                                                |
| 链路优先级   | 用于返回链路设置的优先级信息。 当“链路选择模式”取值为“权重”时，“链路优先级”返回NULL。                                                                                                                                                                                               |
| 链路状态    | 用于返回链路连接状态信息。 取值范围：Create：链路处于正在激活状态。Up：链路处于已激活状态。Down：链路处于未激活状态。                                                                                                                                                                              |
| 对端网元类型  | 用于返回对端网元类型。 取值范围： OTHER(OTHER)SCP(SCP)SEPP(SEPP)AUC(AUC) 该输出项仅在“工作模式”取值为“CLIENT(客户端)”且对端网元类型为“SCP(SCP)”、“SEPP(SEPP)”或“AUC(AUC”)时，返回对端网元类型，其他情况返回“OTHER”。                                                                                       |

| 360162 | 实例不存在    | 输入的“实例ID”或“HLB实例ID”不存在。                                                                | 执行DSP UDMSERVICE命令，查询“SF实例”，然后重新执行本命令，输入查询到的“SF实例”。 |
