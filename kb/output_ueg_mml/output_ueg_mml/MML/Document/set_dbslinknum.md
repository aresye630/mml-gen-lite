# 设置DBS链路条数(SET DBSLINKNUM)

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致业务呼损，需联系华为技术支持确认后再执行。

用于设置FE与BE之间的链路条数。搭建网元时，为避免大容量场景下FE与BE之间链路数过多（会导致CPU资源占用过大，虚拟机（裸机Pod）内存不足）的问题，可以使用**SET DBSLINKNUM**来设定FE与BE之间的链路条数，以达到减少链路条数的目的。最小链路条数为4。

该命令的使用场景：在开局及扩容场景下，由于局点大小存在不均衡，经过评估链路数需要修改时，按指导书步骤进行配置。

## 注意事项

- 该命令不允许进行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。
- 该命令只在分组开关关闭的情况下，用来设置“链路数”。如果分组开关打开，则使用**SET DBSSRVPARA**命令设置“链路数”。
- FE与BE互联时，假设FE的DBS服务个数为m，BE的DSG个数为n，分为以下几种场景：
  - 当n小于LINKNUM时，采用全互联的方式。
  - 当n大于等于LINKNUM时，BE侧DSG个数除以FE侧DBS服务个数大于4时，即x=n/m，当x＞4时，FE侧DBS服务只向BE侧发起x个建链请求。

    例如，当系统的链路数LINKNUM为8时：设n=10，m=2，则n＞LINKNUM，x=n/m，x=5，FE的DBS服务只向BE发起5个建链请求。
  - 当n大于等于LINKNUM时，BE的DSG个数除以FE的DBS服务个数小于等于4时，即x=n/m， 当x<=4时，FE的DBS服务向BE的DSG按照配置的链路条数进行发起建链请求，但是实际链路数不超过全互连的链路数。

    例如，当系统的链路数LINKNUM为8时：
    - 设n=9，m=2，则n＞LINKNUM，x=n/m，x=4（向下取整），FE的DBS服务向BE的DSG按照配置的链路数LINKNUM进行发起建链请求；
    - 设n=8，m=2，则n=LINKNUM，x=n/m，x=4，FE的DBS服务向BE的DSG按照配置的链路数LINKNUM进行发起建链请求。
  - FE和BE的链路数LINKNUM设置需一致。系统中LINKNUM默认为8，不修改默认值的情况下，不需要设置LINKNUM，也无法使用**LST DBSLINKNUM**查询系统默认值。 需要修改LINKNUM默认值的时候，需要用**SET DBSLINKNUM**命令。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                  |
|:--------|:-------|:------------------------------------------------------------------------------------------------------|
| LINKNUM | 链路数    | 可选必选说明：必选参数 参数含义：用于设置FE与BE之间的链路条数。 取值范围： 4～512，实际配置时33～511不能配置，512代表的是全互联。 默认值：无。 配置原则：该参数的系统初始设置值为8。 |

## 使用实例

设置DBS链路数为16，执行如下命令：

```
SET DBSLINKNUM: LINKNUM=16;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释             | 原因分析                                     | 处理建议                                                              |
|-------:|:------------------|:-----------------------------------------|:------------------------------------------------------------------|
| 400010 | 分组开关已打开，该命令不允许执行。 | 业务分组功能已打开，不能使用SET DBSLINKNUM命令设置“链路数”的值。 | 通过LST DBSGRPSWITCH命令查询分组开关是否打开，若已打开，可执行SET DBSSRVPARA命令设置“链路数”的值。 |
