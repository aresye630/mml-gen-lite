# 查询全局数据一致性校验配置(LST GLBDATACFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明
- 参考信息

## 命令功能

该命令用于查询PES全局数据一致性校验信息。

## 注意事项

无。

## 参数说明

| 参数ID        | 参数名称   | 参数描述                                                                |
|:------------|:-------|:--------------------------------------------------------------------|
| SERVICENAME | 服务名称   | 可选必选说明：必选参数 参数含义：用于指定全局数据一致性校验的微服务名称。 取值范围： PES(PES) 默认值：无。 配置原则：无。 |

## 使用实例

查询PES全局数据一致性校验信息。

```
LST GLBDATACFG: SERVICENAME=PES;
```

```
%%LST GLBDATACFG: SERVICENAME=PES;%% 
RETCODE = 0  操作成功  
结果如下: 
-------------     
         服务名称 =  PES
        校验开关  =  进行校验并上报告警
(结果个数 = 1)  

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见SET GLBDATACFG命令的参数说明。
