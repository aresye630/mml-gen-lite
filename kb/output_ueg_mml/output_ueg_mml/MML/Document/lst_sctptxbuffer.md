# 查询SCTP发送缓冲区参数(LST SCTPTXBUFFER)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGSN、MME、AMF**

该命令用于查询系统中SCTP发送缓冲区参数。

#### 注意事项

无。

#### 本地用户权限

manage-ug;system-ug;monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                        |
|:-------|:-------|:--------------------------------------------------------------------------------------------|
| MODE   | 模式选项   | 可选必选说明：可选参数 参数含义：该参数用于区分共享模式、私有模式下的参数配置。 数据来源：本端规划 取值范围：枚举类型 SHARE（共享模式）PRIVATE（私有模式） 默认值：无 |

#### 使用实例

查询发送端缓冲区共享模式下的参数信息：

```
LST SCTPTXBUFFER: MODE=SHARE;
```

```
查询结果如下
-------------------------
                    模式选项  =  共享模式
        迷你端私有缓冲区大小  =  20000
        迷你端共享缓冲区大小  =  50000
        迷你端共享缓冲区个数  =  600
(结果个数 = 1)

---    END
```
