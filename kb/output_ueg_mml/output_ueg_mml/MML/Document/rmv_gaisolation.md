# 删除Ga业务隔离配置（RMV GAISOLATION）

#### 命令功能

**须知** 

此命令不能动态生效，需要执行RST RU生效。删除隔离配置会导致隔离AP恢复接收话单，允许链路迁入。

**适用NF：NCG**

该命令用于删除已添加的Ga隔离配置。

#### 注意事项

- 命令操作后，需要执行**RST RU**命令重启生效，恢复Ga口业务，生效后才允许Ga链路迁入。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                |
|:--------------|:-------|:----------------------------------------------------------------------------------------------------|
| GAISOLATIONID | Ga隔离标识 | 可选必选说明：必选参数 参数含义：话单存储对象标识，全局唯一。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：该参数只能由字母、数字、下划线、中划线组成。 |

#### 使用实例

删除Ga隔离标识为“iso1”的Ga隔离配置，示例如下：

```
RMV GAISOLATION:GAISOLATIONID="iso1";
```
