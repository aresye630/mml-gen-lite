# 设置 IP 访问控制策略参数（SET IPCTRLPLCYPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

该命令用于设置IP访问控制策略相关参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 关闭IP访问控制策略开关后，API GW将不按照已配置的IP访问控制策略对源IP进行访问控制，请按需关闭。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | IPCTRLSWITCH   |
|:-------|:---------------|
| 初始值    | ENABLE         |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称              | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                       |
|:-------------|:------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPCTRLSWITCH | IP访问控制策略开关        | 可选必选说明：必选参数 参数含义：是否使能IP访问控制策略。 数据来源：本端规划 取值范围：枚举类型。 ENABLE：打开IP访问策略控制。DISABLE：关闭IP访问控制策略。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                     |
| ORIGIPHEADER | 携带原始IP的HTTP请求头域名称 | 可选必选说明：可选参数 参数含义：在API GW前端部署反向代理设备时，如果反向代理隐藏了访问者的原始IP，可以将原始IP在反向代理设备上通过指定HTTP请求头域的方式携带给API GW，该参数用于设置API GW从该指定的HTTP请求头域获取访问者的原始IP。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～320。每个请求头域名称为字符串类型，输入长度范围为1～31。不支持空格，由“-”、“_”、数字、字母和“.”组成，不区分大小写；本参数可支持多个请求头域名称，以‘;’隔开,最多支持设置10个。 默认值：无 配置原则： 输入单空格将删除该参数已有配置项。在API GW前端部署反向代理设备时，如果反向代理隐藏了访问者的原始IP，可以在反向代理设备上通过指定HTTP请求头域携带给API GW，该参数用于设置API GW从指定的HTTP请求头域获取访问者的原始IP。 |

#### 使用实例

打开IP访问控制策略开关：

```
SET IPCTRLPLCYPARA: IPCTRLSWITCH=ENABLE;
```
