# 设置License开关（SET DFTLICSWITCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于设置License开关。

#### 注意事项

该命令执行后立即生效。

#### 参数说明

| 参数标识    | 参数名称       | 参数说明                                                                                                                             |
|:--------|:-----------|:---------------------------------------------------------------------------------------------------------------------------------|
| LICITEM | License项名称 | 可选必选说明：必选参数 参数含义：该参数用于指定License项名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围是0~255。 默认值：无 配置原则：无                                              |
| SWITCH  | License开关  | 可选必选说明：必选参数 参数含义：该参数用于配置License项开关。 数据来源：本端规划 取值范围： ENABLE：使能。DISABLE：不使能。 默认值：无 配置原则： ENABLE为开启License项开关。DISABLE为关闭License项开关。 |

#### 使用实例

开启“License项名称”为“LKV3WMTPRC11”的License开关：

```
SET DFLICSWITCH: LICITEM="LKV3WMTPRC11", SWITCH=ENABLE;
```
