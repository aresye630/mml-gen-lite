# 设置pbuf重用检测开关（SET PBUFREUSE5GC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令用于使能PBUF重用检测，开启后会降低性能，关闭后性能恢复。请谨慎使用并联系华为技术支持协助操作。

此命令用于设置MSS的PBUF重用检测开关，重用检测功能用来检测多个进程是否同时在使用同一片PBUF。用户打开开关后，系统收集运行信息，导致转发面性能下降，开关关闭后性能恢复。

## 注意事项

- 该命令执行后立即生效。

- 本命令用于使能PBUF重用检测，开启后会降低性能，关闭后会恢复性能。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                  |
|:------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------|
| PODTYPE     | pod类型  | 可选必选说明：必选参数  参数含义：该参数用于指定pod类型。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~127。  默认值：无。  配置原则：无                                                                  |
| POOLNAME    | 内存池名称  | 可选必选说明：必选参数  参数含义：该参数用于指定内存池名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~31。  默认值：无。  配置原则：无                                                                   |
| REUSESWITCH | 开关标记   | 可选必选说明：必选参数  参数含义：该参数用于指定pbuf重用检测开关的状态。 如果开关取值是Enable，则表示检测开关打开； 如果开关取值是Disable，则表示检测开关关闭。  数据来源：本端规划 取值范围： Enable（开关打开）Disable（开关关闭）  默认值：无。  配置原则：无 |

## 使用实例

通过如下命令打开podtype为aa的pod内PAE内存池pbuf重用检测开关：

```
SET PBUFREUSE5GC:PODTYPE="aa",POOLNAME="PAE",REUSESWITCH=Enable;
```
