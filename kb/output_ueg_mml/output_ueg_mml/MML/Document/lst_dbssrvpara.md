# 查询DBS服务参数(LST DBSSRVPARA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于在分组开关打开的情况下，查询DBS服务参数：

- 若要查询全部业务类型的DBS服务参数，请不要输入任何参数。
- 若要查询某个业务类型的DBS服务参数，请输入“业务类型”参数。

## 注意事项

该命令只在分组开关打开的情况下，用来查询DBS服务参数，如果分组开关关闭，则使用**LST DBSSCTPPARA**命令查询“自动回切开关”值，使用****LST DBSLINKNUM****命令查询“链路数”。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                 |
|:------------|:-------|:-----------------------------------------------------------------------------------------------------|
| SERVICETYPE | 业务类型   | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照业务类型来查询DBS服务参数；若不输入，则表示查询所有业务类型的DBS服务参数。 取值范围：长度不超过128的字符串。 默认值：无 配置原则：无 |

## 使用实例

1. 查询当前网元各“业务类型”的DBS服务参数：

   ```
   LST DBSSRVPARA:;
   ```

   ```
   %%LST DBSSRVPARA:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   业务类型      自动回切开关  链路数  

   SUP-FE        0             8       
   GU-HLR        0             6       
   (结果个数 = 2)

   ---    END
   ```
2. 查询“业务类型”为“SUP-FE”的DBS服务参数：

   ```
   LST DBSSRVPARA:SERVICETYPE="SUP-FE";
   ```

   ```
   %%LST DBSSRVPARA: SERVICETYPE="SUP-FE";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
       业务类型  =  SUP-FE
   自动回切开关  =  0
         链路数  =  8
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET DBSSRVPARA**命令的参数说明。
