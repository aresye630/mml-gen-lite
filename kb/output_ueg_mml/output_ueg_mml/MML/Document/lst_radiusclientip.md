#### 命令功能

**适用NF：PGW-C、SMF**

LST RADIUSCLIENTIP命令用来查询Radius Group Client IP接口。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称                  | 参数说明                                                                                                                                                                                                                                                                                               |
|:--------------|:----------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RDSSVRGRPNAME | Radius Server Group名称 | 可选必选说明：可选参数 参数含义：指定Radius Server Group名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无                                                                                                                                                                                                           |
| AUTHORACCT    | 鉴权或计费                 | 可选必选说明：可选参数 参数含义：指定鉴权或计费。 数据来源：本端规划 取值范围：枚举类型。 ACCOUNTING：表示指定的Gi接口的IP地址是计费时的radius client ip。AUTHENTICATION：表示指定的Gi接口的IP地址是鉴权时的radius client ip。ACCT_AND_AUTH：表示指定的Gi接口的IP地址既是鉴权时的radius client ip，也是计费时的radius client ip。 默认值：无 配置原则： ACCOUNTING：表示计费。AUTHENTICATION：表示鉴权。ACCT_AND_AUTH：表示计费和鉴权。 |
| INTFNAME      | 接口名称                  | 可选必选说明：可选参数 参数含义：指定接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～13。用户输入形式例如：giif1/0/0。其中giif为逻辑接口类型；1/0/0中第一个数字为组号，第二个数字为实例类型；第三个数字为逻辑接口号，各逻辑接口类型有各自的配置范围。 默认值：无 配置原则：无                                                                                                                                     |

#### 使用实例

如果想要查询Radius Group Client IP接口，应该输入合法的数据，例如：

```
LST RADIUSCLIENTIP:RDSSVRGRPNAME="aaa";
```

```

```
