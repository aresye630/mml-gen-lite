# 添加SFTP服务器(ADD SFTPSERVER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中增加一条NLF作为SFTP服务器的数据记录。

该命令的使用场景：NLF服务支持通知日志文件下载，当NLF作为SFTP服务端，第三方服务器需要通过NLF提供的SFTP服务端获取通知日志文件。

## 注意事项

- NLF作为SFTP服务器时，通过软参“VRM\_WHITELISTSWITCH”控制客户端IP的连接：
  - 如果软参“VRM\_WHITELISTSWITCH”设置为“0”，所有连接不做限制。
  - 如果软参“VRM\_WHITELISTSWITCH”设置为“1”，只有通过ADD NLFWHITELIST命令配置在白名单列表里的IP才允许接入。
- NLF作为SFTP服务器时，基于是否使用兼容密钥算法，需要考虑软参“VRM\_NLFSFTPSERVERACSWITCH”的设置值。
- SFTP服务器登录的用户名和密码需在UPCF WebUI界面“安全管理 > 权限 > 系统用户”上进行配置，“用户类别”需配置为“NLF SFTP用户”，端口号固定为2222或2223。

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                                                                                                                                                    |
|:-------|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ID     | SFTP服务器的索引 | 可选必选说明：必选参数 参数含义：用于定义一条NLF作为SFTP服务器的信息。 取值范围：0 默认值：无。 配置原则：无。                                                                                                                                                           |
| IPVER  | IP版本       | 可选必选说明：必选参数 参数含义：用于指定NLF作为SFTP服务器的IP版本类型。SFTP服务器指定IP版本后不支持修改。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。                                                                                                                 |
| IP     | IPV4地址     | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV4(IPV4)”时该参数需配置，NLF与对端对接的参数之一，用于表示NLF作为SFTP服务器的IPv4地址。 取值范围：IPv4地址 默认值：无。 配置原则：此IP地址必须是本地实际的IP地址且必须先由ADD NLFDEVADDR或ADD PMSDEVADDR（通过ADD NLFDEVADDR中配置的“PMS设备地址标识”进行索引关联）命令定义，然后才能在此处引用。 |
| IPV6   | IPV6地址     | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV6(IPV6)”时该参数需配置，NLF与对端对接的参数之一，用于表示NLF作为SFTP服务器的IPv6地址。 取值范围：IPv6地址 默认值：无。 配置原则：此IP地址必须是本地实际的IP地址且必须先由ADD NLFDEVADDR或ADD PMSDEVADDR（通过ADD NLFDEVADDR中配置的“PMS设备地址标识”进行索引关联）命令定义，然后才能在此处引用。 |
| ADMST  | 管理状态       | 可选必选说明：必选参数 参数含义：用于标识NLF作为SFTP服务器的管理状态。 取值说明： ENABLE(启用)：表示启用SFTP服务。DISABLE(禁用)：表示停止SFTP服务。 默认值：无。 配置原则：无。                                                                                                              |

## 使用实例

增加一条NLF作为SFTP服务器的数据记录。“SFTP服务器的索引”为“0”，“IP版本”为“IPV4(IPV4)”，“IPV4地址”为“10.168.0.130”，“管理状态”为“ENABLE(启用)”。

```
ADD SFTPSERVER: ID=0, IPVER=IPV4, IP="10.168.0.130", ADMST=ENABLE;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释      | 原因分析                       | 处理建议                                                                                                                                                                               |
|------:|:-----------|:---------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 58026 | 本地IP地址不存在。 | 输入的“本地IP地址”或“本地IPV6地址”不存在。 | 若输入的“本地IP地址”或“本地IPV6地址”不存在：执行LST NLFDEVADDR命令，查询已存在的所有NLF设备地址记录。 查询可以复用的IP地址，通过1获取到NLF关联配置的“PMS设备地址标识”，执行LST PMSDEVADDR命令，查询PMS设备地址标识对应的IP地址。重新执行本命令，使用系统已添加的NLF设备地址或可以复用的PMS设备地址。 |
