# 删除Diameter对端地址（RMV UPDIAMPEERADDR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

**须知** 

本命令属于高危命令，删除DiamPeerAddr会导致正在使用的Diameter链路异常，中断Diameter应用相关的业务。

该命令用于删除Diameter链路的对端地址信息。

当某应用Diameter协议的服务器需要减少Diameter链路的对端地址时，执行此命令。

#### 注意事项

- 该命令执行后立即生效。
- 删除Diameter链路的对端地址信息时，必须输入地址所属的主机名称，并且该主机在UPF上已经配置。
- 删除Diameter链路的对端地址时，对应的Diameter链路也会同时删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                                                                   |
|:-------------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------|
| HOSTNAME     | 主机名称     | 可选必选说明：必选参数 参数含义：该参数用于指定地址信息所属的Diameter主机名称。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～127。不支持空格，由软参BIT 2670控制是否区分大小写。 默认值：无 配置原则：无                |
| ADDRTYPE     | 地址类型     | 可选必选说明：可选参数 参数含义：该参数用于指定Diameter地址的地址类型。 数据来源：对端协商 取值范围：枚举类型。 IPv4：地址类型为IPv4。IPv6：地址类型为IPv6。SCTP：地址类型为SCTP端点。 默认值：无 配置原则：无             |
| IPV4ADDRESS  | IPv4地址   | 可选必选说明：条件必选参数 前提条件：该参数在“ADDRTYPE”配置为“IPv4”时为必选参数。 参数含义：该参数用于指定IPv4地址。 数据来源：对端协商 取值范围：IPv4地址类型。不支持0.0.0.0和255.255.255.255。 默认值：无 配置原则：无 |
| IPV6ADDRESS  | IPv6地址   | 可选必选说明：条件必选参数 前提条件：该参数在“ADDRTYPE”配置为“IPv6”时为必选参数。 参数含义：该参数用于指定IPv6地址。 数据来源：对端协商 取值范围：IPv6地址类型。不支持全F。 默认值：无 配置原则：无                      |
| PORT         | 端口号      | 可选必选说明：条件可选参数 前提条件：该参数在“ADDRTYPE”配置为“IPv4” 或 “IPv6”时为可选参数。 参数含义：该参数用于指定IP地址的端口号。 数据来源：对端协商 取值范围：整数类型，取值范围为1～65534。 默认值：无 配置原则：无        |
| SCTPENDPOINT | SCTP端点名称 | 可选必选说明：条件必选参数 前提条件：该参数在“ADDRTYPE”配置为“SCTP”时为必选参数。 参数含义：该参数用于指定SCTP端点名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无    |

#### 使用实例

- 当用户需要重新配置Diameter主机“dra1”的所有对端地址信息，则需要先删除该DRA主机的所有地址：

  ```
  RMV UPDIAMPEERADDR:HOSTNAME="dra1";
  ```
- 当用户识别出对端Diameter主机不支持SCTP传输协议，需要删除Diameter主机“dra1”的SCTP对端地址“end1”信息：

  ```
  RMV UPDIAMPEERADDR:HOSTNAME="dra1",ADDRTYPE=SCTP,SCTPENDPOINT="end1";
  ```
