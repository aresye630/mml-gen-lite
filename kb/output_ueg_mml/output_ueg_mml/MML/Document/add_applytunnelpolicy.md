# 增加应用隧道策略（ADD APPLYTUNNELPOLICY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来增加应用隧道策略。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 先通过ADD TUNNELSELECTOR配置隧道选择器和通过ADD TUNNELSELECTORNODE配置隧道选择器节点，才能使用该命令。
- 配置应用隧道策略前，需要先通过ADD TUNNELPOLICY配置相应的隧道策略。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称     | 参数说明                                                                      |
|:----------------|:---------|:--------------------------------------------------------------------------|
| TNLSELECTORNAME | 隧道选择器名字  | 可选必选说明：必选参数 参数含义：该参数用于指定隧道选择器名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～40。 默认值：无  |
| NODESEQUENCE    | 隧道选择器节点号 | 可选必选说明：必选参数 参数含义：该参数用于指定隧道选择器节点号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无 |
| TNLPOLICYNAME   | 隧道策略名    | 可选必选说明：必选参数 参数含义：该参数用于表示隧道策略名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～39。 默认值：无    |

#### 使用实例

增加应用隧道策略的操作：

```
ADD APPLYTUNNELPOLICY:TNLSELECTORNAME="a",NODESEQUENCE=10,TNLPOLICYNAME="a";
```
