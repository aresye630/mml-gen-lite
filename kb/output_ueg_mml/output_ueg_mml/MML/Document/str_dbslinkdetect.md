# 启动DBS链路探测(STR DBSLINKDETECT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在DBS上进行FE与远端BE的链路探测，并输出探测结果。

该命令的使用场景为：在开局或扩容场景对接链路前，可执行该命令进行链路探测，判断网络连接是否正常，以便判断是否可以继续下一步操作。

## 注意事项

- 该命令执行成功，说明网络连接正常，可以继续下一步操作。如有探测失败，请记录使用的“本端IPv4地址”/“本端IPv6地址”、“本端端口号”、“对端IPv4地址”/“对端IPv6地址”、“对端端口号”，联系运营商通知承载网相关维护人员确认并修复网络。
- “协议类型”为“SCTP”时，开局场景执行该命令参数填写说明如下：
  - “本端IPv4地址”/“本端IPv6地址”和“IP地址的VPN名称”填写为运营商规划的IP地址和VPN名称。
  - “本端端口号”填写为：本端“业务基值端口”的取值+本端DBS服务模块号。
    - “业务基值端口”可通过在本端执行**LST DBSSCTPPARA**令查询输出项“业务基值端口”对应的取值。
    - 本端DBS服务模块号，可通过在本端执行**LST DBSSERVICENO**命令获取。

    例如，本端“业务基值端口”为“2000”，本端DBS服务模块号为“2”、“3”、“4”、“5”，则执行该命令时，“本端端口号”分别填写为2002、2003、2004、2005端口。
  - “对端IPv4地址”/“对端IPv6地址”需确认在对端已通过**ADD SRVIPADDR**命令添加且“业务IP类型”为“DSG”。可在对端执行**LST SRVIPADDR**命令查询。
  - “对端端口号”填写为：对端“业务基值端口”的取值+对端DSG模块号。
    - “业务基值端口”，可通过在对端执行**LST DSGSCTPPARA**命令查询输出项“业务基值端口”对应的取值。
    - 对端DSG模块号可通过在对端执行**LST MODULE**命令获取。

    例如，对端“业务基值端口”为“2000”，对端DSG模块号为“1”、“2”、“5”、“6”，则执行该命令时，“对端端口号”分别填写为2001、2002、2005、2006端口。
  - 其他参数按照需要填写。

  **说明** 

  “本端IPv4地址”/“本端IPv6地址”、“本端端口号”、“对端IPv4地址”/“对端IPv6地址”、“对端端口号”有多个取值时，需要多次执行该命令，确保“本端IPv4地址”/“本端IPv6地址”、“本端端口号”、“对端IPv4地址”/“对端IPv6地址”、“对端端口号”的所有取值均输入了至少一次。
- “协议类型”为“SCTP”时，扩容场景执行该命令参数填写说明如下：
  - “本端IPv4地址”/“本端IPv6地址”、“IP地址的VPN名称”填写说明：
    - 如果为本端扩IP场景，“本端IPv4地址”/“本端IPv6地址”、“IP地址的VPN名称”需使用运营商规划待扩容出的IP和VPN名称。
    - 如果本端不扩IP场景，“本端IPv4地址”/“本端IPv6地址”、“IP地址的VPN名称”填写为已通过**ADD DBSIPADDR**命令添加的IP地址和VPN名称，可在本端执行**LST DBSIPADDR**命令查询。
  - “本端端口号”填写为：本端“业务基值端口”的取值+本端待扩容出的DBS模块号。
    - “业务基值端口”，可通过在本端执行**LST DBSSCTPPARA**命令查询输出项“业务基值端口”对应的取值。
    - 当“AUTOSERVICENO（模块号自动化开关）”取值为“0”或“2”时，扩容出的DBS服务模块号为人工规划。
    - 当“AUTOSERVICENO（模块号自动化开关）”取值为“1”时，扩容后DBS服务模块号为自动添加，扩容后新增的DBS服务模块号可通过如下方法计算：
      1. 执行**LST DBSSERVICENO**命令查看当前所有DBS的服务模块号。
      2. 判断当前DBS服务模块号的分段，比如查出DBS服务模块号分别为1、2、3、4、301、302、303、304，可判断DBS的服务模块号分两段，即1~300， 301~。
      3. 每次扩容模块会在每个段内都扩容出一个新的模块，为其分配的模块号为在段内选取的最小可用的模块号，如上述场景，新增一对DBS的服务后，其服务模块号分别为5、305。

         **说明** 

         每次扩容的DBS服务在每个段内扩容的个数与Pod类型有关。如Pod类型为udm-uens-a-pod和udm-uens-b-pod时，会在每个段内扩容两个DBS服务，如上述举例，对应的模块号为5、6，305、306。

    例如，本端“业务基值端口”为“2000”，待扩容出的DBS服务模块号如上举例为5、305，执行该命令时，“本端端口号”分别填写为2005、2305。
  - “对端IPv4地址”/“对端IPv6地址”需确认在对端已通过**ADD SRVIPADDR**命令添加且“业务IP类型”为“DSG”。可在对端执行**LST SRVIPADDR**命令查询。
  - “对端端口号”填写为：对端“业务基值端口”的取值+对端DSG模块号。
    - “业务基值端口”，可通过在对端执行**LST DSGSCTPPARA**命令查询输出项“业务基值端口”对应的取值。
    - 对端DSG模块号可通过在对端执行**LST MODULE**命令获取。

    例如，对端“业务基值端口”为“2000”，对端DSG模块号为“1”、“2”、“5”、“6”，则执行该命令时，“对端端口号”分别填写为2001、2002、2005、2006端口。
  - 其他参数按照需要填写。

  **说明** 

  - 如为本端扩IP和本端扩DBS服务模块场景，“本端IPv4地址”/“本端IPv6地址”、“本端端口号”有多个取值时，需多次执行该命令，确保待扩容的“本端IPv4地址”/“本端IPv6地址”、“本端端口号”的所有取值均输入了至少一次。
  - 如为本端不扩IP，仅扩DBS服务模块场景，“本端端口号”有多个取值时，需多次执行该命令，确保待扩容的“本端端口号”的所有取值均输入了至少一次。
- “协议类型”为“UDP”时，必须先在本端配置DBS链路中心，可执行**LST DBSLINKCTRL**命令查询，如果未配置，请参考**ADD DBSLINKCTRL**进行配置。配置后，执行该命令参数填写说明如下：
  - “本端IPv4地址”/“本端IPv6地址”填写为**ADD DBSLINKCTRL**命令中配置的IP地址，可通过**LST DBSLINKCTRL**命令查询。
  - “IP地址的VPN名称”填写为“本端IPv4地址”/“本端IPv6地址”的VPN名称，可通过**LST DBSIPADDR**命令查询。
  - “对端IPv4地址”/“对端IPv6地址”需确认在对端已通过**ADD SRVIPADDR**命令添加且“业务IP类型”为“DSG”。可在对端执行**LST SRVIPADDR**命令查询。
  - 其他参数按照需要填写。

## 使用实例

执行该命令进行探测，“协议类型”为“SCTP(SCTP)”，“IP类型”为“IPV4(IPV4)”，“本端IPv4地址”为“192.168.100.1”，“本端端口号”为“2001”，“IP地址的VPN名称”为“public”，“对端IPv4地址”为“192.168.200.1”“，对端端口号”为“2500”，“探测包长度”为“60”。

```
STR DBSLINKDETECT: PROTOCOL=SCTP, IPVER=IPV4, LOCALIPV4IP="192.168.100.1", LOCALPORT=2001, VPNNAME="public", PEERIPV4IP="192.168.200.1", PEERPORT=2500, PKTLENGTH=60;
```
