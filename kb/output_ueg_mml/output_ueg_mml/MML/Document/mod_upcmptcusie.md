# 修改UP节点定制信元兼容性配置（MOD UPCMPTCUSIE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、SGW-C、PGW-C、GGSN**

该命令用于修改UP节点定制信元兼容性配置。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                          |
|:------------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------|
| UPFINSTANCE | UPF实例名称  | 可选必选说明：必选参数  参数含义：该参数用于指定UPF实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~36。不区分大小写。  默认值：无  配置原则：  本参数取值与ADD PNFPROFILE命令中的“NF实例标识”参数取值保持一致时，关联关系生效。 |
| IENAME      | 定制信元名称   | 可选必选说明：必选参数  参数含义：该参数用于指定需要定制的信元名称。  数据来源：全网规划 取值范围： EFSEID（扩展F-SEID）PUSERID（私有UserID）  默认值：无  配置原则：无                                         |
| CUSTOMTYPE  | 定制信元类型值  | 可选必选说明：必选参数  参数含义：该参数用于设置定制信元的类型值。  数据来源：全网规划  取值范围：整数类型，取值范围是32768~65535。  默认值：无  配置原则：无                                                     |
| CUSTOMEPID  | 定制信元企业ID | 可选必选说明：必选参数  参数含义：该参数用于设置定制信元的企业ID。  数据来源：全网规划  取值范围：整数类型，取值范围是0~65535。  默认值：无  配置原则：无                                                        |

## 使用实例

修改UP节点定制信元配置，UPF实例标识为upf\_instance\_1，设置Extend FSEID 企业ID为2011，类型值为37101，执行如下命令：

```
MOD UPCMPTCUSIE: UPFINSTANCE="upf_instance_1", IENAME=EFSEID, CUSTOMTYPE=37101, CUSTOMEPID=2011
```
