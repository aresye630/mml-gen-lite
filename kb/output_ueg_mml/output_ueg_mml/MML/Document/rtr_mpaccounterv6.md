# 清除IPv6 MPAC策略匹配统计计数（RTR MPACCOUNTERV6）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于清除当前策略匹配统计计数。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                      |
|:-----------|:-------|:--------------------------------------------------------------------------------------------------------------------------|
| POLICYNAME | 策略名称   | 可选必选说明：可选参数 参数含义：该参数用于指定策略名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。大小写敏感，英文字母开头，不支持空格。 默认值：无 配置原则：不指定策略名字，默认清除IPv6所有策略匹配统计计数。 |

#### 使用实例

清除IPv6 MPAC策略匹配统计计数：

```
RTR MPACCOUNTERV6:POLICYNAME="policyV6";
```
