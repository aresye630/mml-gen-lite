# 设置APN Radius服务器组（ADD APNRDSSVRGRP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用来添加指定APN实例下绑定的RADIUS服务器组。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为10000。
- 一个APN只能绑定一个RADIUS服务器组。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称                     | 参数说明                                                                                                                                                                                                               |
|:---------------|:-------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN            | APN名称                    | 可选必选说明：必选参数 参数含义：指定APN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”特殊字符，不区分大小写。 默认值：无 配置原则：该参数使用ADD CPAPN命令配置生成。 |
| RDSSVRGRPNAME  | RADIUS Server Group名称    | 可选必选说明：必选参数 参数含义：RADIUS服务器组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：该参数使用ADD RDSSVRGRP命令配置生成。                                                                                                              |
| COPYINTERIMUPD | 抄送Interim-Update Request | 可选必选说明：可选参数 参数含义：配置是否抄送中间话单。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：否。ENABLE：是。 默认值：DISABLE 配置原则：无                                                                                                                           |

#### 使用实例

添加APN Radius服务器组，APN为apntest，Radius服务器组名为rgtest，命令为：

```
ADD APNRDSSVRGRP:APN="apntest",RDSSVRGRPNAME="rgtest";
```
