# 查询DBS Location信息(LST DBSLOCATION)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询Location信息：

- 若需要查询全部Location信息记录的概要信息，请不要输入任何参数。
- 若需要查询某条Location信息记录的详细信息，请输入“Location标识”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                                 |
|:-------|:-----------|:-----------------------------------------------------------------------------------------------------|
| LOCID  | Location标识 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个Location标识来查询Location信息；若不输入，则表示所有的Location标识。 取值范围：1～512 默认值：无。 配置原则：无 |

## 使用实例

在维护场景下，查询Location配置信息:

```
LST DBSLOCATION:;
```

返回结果如下：

```
%%LST DBSLOCATION:;%%
RETCODE = 0  操作成功

操作结果如下
------------
Location标识  =  6
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，参数含义请参见**SET DBSLOCATION**命令的参数说明。
