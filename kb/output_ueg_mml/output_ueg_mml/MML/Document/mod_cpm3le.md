# 修改M3UA本地实体(MOD CPM3LE)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME、SMSF**

该命令用于修改M3UA本地实体配置数据。

#### 注意事项

- 该命令执行后立即生效。
- 只能修改本地实体名。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                        |
|:-------|:-------|:----------------------------------------------------------------------------|
| LEX    | 本地实体索引 | 可选必选说明：必选参数 参数含义：该参数用于表示准备修改的本地实体的索引。 数据来源：本端规划 取值范围：0~63 默认值：无 配置原则：无      |
| LEN    | 本地实体名  | 可选必选说明：可选参数 参数含义：该参数用于表示本地实体名称，标识本地实体。 数据来源：本端规划 取值范围：0~32位字符串 默认值：无 配置原则：无 |

#### 使用实例

将索引为1的M3UA本地实体名改为“Test\_M3le1”：

```
MOD CPM3LE: LEX=1, LEN="Test_M3le1";
```
