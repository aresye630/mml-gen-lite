# 查询报表服务对端链路配置信息(LST DRSPEERLINKCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令是维护类命令，用于报表服务对端链路的配置信息。

- 若需要查询全部报表服务对端链路的配置信息，请不要输入任何参数。
- 若需要查询某个报表服务对端链路的配置信息，请依据参数说明输入查询条件。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                                |
|:------------|:-----------|:--------------------------------------------------------------------------------------------------------------------|
| LINKID      | 链路ID       | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个链路ID来查询报表服务对端链路配置信息。若不输入，则表示所有的链路ID。 取值范围：1～32 默认值：无。 配置原则：无。                          |
| PEERID      | 对端服务器ID    | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个对端服务器ID来查询报表服务对端链路配置信息。若不输入，则表示所有的对端服务器ID。 取值范围：1～32 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。 |
| LOCALROLE   | 本地角色       | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个本地角色来查询报表服务对端链路配置信息。若不输入，则表示所有的本地角色。 取值说明：FTPClient(FTP客户端) 默认值：无。 配置原则：无。             |
| IPVER       | IP版本       | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个IP版本来查询报表服务对端链路配置信息。若不输入，则表示所有的IP版本。 取值范围： IPV4（IPV4）IPV6（IPV6） 默认值：无。 配置原则：无。         |
| LOCALIP     | 本端IP地址     | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个本段IP地址来查询报表服务对端链路配置信息。若不输入，则表示所有的本端IP地址。 取值范围：IPv4地址 默认值：无。 配置原则：无。                    |
| LOCALIPV6   | 本端IPV6地址   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个本端IPV6地址来查询报表服务对端链路配置信息。若不输入，则表示所有的本端IPV6地址。 取值范围：IPv6地址 默认值：无。 配置原则：无。                |
| PEERIP      | 对端IP地址     | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个对端IP地址来查询报表服务对端链路配置信息。若不输入，则表示所有的对端IP地址。 取值范围：IPv4地址 默认值：无。 配置原则：无。                    |
| PEERIPV6    | 对端IPV6地址   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个对端IPV6地址来查询报表服务对端链路配置信息。若不输入，则表示所有的对端IPV6地址。 取值范围：IPv6地址 默认值：无。 配置原则：无。                |
| PEERPORT    | 对端端口       | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个对端端口来查询报表服务对端链路配置信息。若不输入，则表示所有的对端端口。 取值范围：1～65534 默认值：无。 配置原则：无。                       |
| USRNAME     | 用户名        | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个用户名来查询报表服务对端链路配置信息。若不输入，则表示所有的用户名。 取值范围：长度不超过96的字符串。 默认值：无。 配置原则：无。                    |
| FTPPATH     | FTP服务器日志路径 | 可选必选说明：可选参数 参数含义：用于指定上传报表文件到pop-d的服务器的FTP路径。若不输入，则表示所有的FTP服务器日志路径。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                |
| DESCRIPTION | 描述         | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个描述来查询报表服务对端链路配置信息。若不输入，则表示所有的描述。 取值范围：长度不超过32的字符串。 默认值：无。 配置原则：无。                      |
| ADSTS       | 链路管理状态     | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个链路管理状态来查询报表服务对端链路配置信息。若不输入，则表示所有的链路管理状态。 取值范围： DISABLE(去使能)ENABLE(使能) 默认值：无。 配置原则：无。   |

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD DRSPEERLINKCFG**命令的参数说明。
