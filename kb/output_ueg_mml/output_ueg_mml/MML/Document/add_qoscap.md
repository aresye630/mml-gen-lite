# 增加Non-GBR承载QoS限制配置(ADD QOSCAP)

#### 命令功能

**适用网元：MME**

该命令用于增加一条QoS限制配置记录，限制特定用户群的QoS。

在网络资源比较紧张时，为了保证大部分用户的正常业务，可以使用此命令对部分用户的QoS进行限制。

#### 注意事项

- 该命令执行后立即生效。
- 本表最大记录数为1024。
- 同一网络内，所有MME/SGSN中的QoS限制配置数据应保持一致。
- 当UNC作为MME/SGSN网元时，对应用户群的QoS信息将会被配置中的QoS信息进行限制。
- 如果想取消对某一参数的限制，请参考**MOD QOSCAP**命令的说明。
- 配置记录添加后，如果当前用户正在进行业务流程，配置限制不会实时生效，在下一个流程中生效。
- QoS各参数的取值及含义具体请参见3GPP TS 23.107（QoS协议）。
- 此配置涉及基于IMSI号段的QoS控制特性（特性编号：WSFD-105104，License部件编码：LKV2IMSIQOS02），执行命令请使用**DSP LICENSE**命令确认对应特性License是否得到授权，执行**LST LICENSESWITCH**命令确认特性开关状态为“ENABLE(打开)”。
- 集群用户遥晕场景下发送Modify Bearer Command时，不受该配置控制。

#### 本地用户权限

manage-ug；system-ug。

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组。

#### 使用实例

增加一条QoS限制配置，对于“RAT”类型为“ALL”，“用户范围”为“IMSI\_PREFIX”，“IMSI”前缀为“3080107000”（即IMSI号范围在308010700000000～308010700099999内）的用户，将上行“UE AMBR”限制为“10000kbps”，下行“UE AMBR”限制为“20000kbps”，上行“APN AMBR”限制为“5000kbps”，下行“APN AMBR”限制为“10000kbps”，“QCI”限制为“8”，“ARP”的优先级别限制为“10”，“ARP”的抢占能力限制为“DISABLE”，“ARP”的被抢占能力限制为“ENABLE”，覆盖“QoS”设置为“YES”，网络提升QoS的控制方法设置为“接受QoS”，移动网络名称设置为“MobileNet1”。

`ADD QOSCAP:RATTYPE=ALL,SUBRANGE=IMSI_PREFIX,IMSIPRE="3080107000",UEAMBRULK=10000, UEAMBRDLK=20000,APNAMBRULK=5000,APNAMBRDLK=10000, QCI=8,ARPPRL=10,ARPPCI=DISABLE,ARPPVI=ENABLE,SUBQOS=YES,CTRLNWQOS=ACCEPT,MNNAME="MobileNet1";`
