# 锁定存储ByPass场景下的APN（LCK APNFORBYPASS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令仅用于在存储ByPass时锁定APN，禁止在正常情况下使用该命令。

**适用NF：SGW-C、PGW-C、SMF、GGSN**

该命令用来对指定APN进行临时锁定操作，系统重启后自动解锁。当APN锁定后，后续使用该APN激活的用户激活失败，已经在线的用户无影响。缺省情况下APN未锁定。

## 注意事项

- 该命令执行后立即生效。

- 如果APN被锁定，会导致使用该APN激活的用户接入失败。
- 该命令执行后只对新用户生效。
- 目前最多锁定3000个APN，当超过上限时，APN锁定失效。
- 由于该命令是在存储Bypass期间执行，因此无法做配置关联检查。
- LCK CPAPN和LCK APNFORBYPASS两个命令任一个对APN进行了锁定，则APN被锁定。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                          |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN    | APN    | 可选必选说明：必选参数  参数含义：该参数用于指定APN实例名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无  配置原则：  输入的APN名称需要符合APN命名规则。 |
| LOCKED | 锁定     | 可选必选说明：必选参数  参数含义：该参数用于在存储ByPass场景下对APN进行临时锁定操作。  数据来源：本端规划 取值范围： ENABLE（使能）DISABLE（不使能）  默认值：无  配置原则：  该参数为ENABLE时，指定为锁定该APN。该参数为DISABLE时，指定为解锁该APN。                                                                         |

## 使用实例

锁定APN，APN为test：

```
LCK APNFORBYPASS: APN="test", LOCKED=ENABLE, CONFIRM=Y;
```
