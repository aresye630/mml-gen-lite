# 删除策略管理服务管理员IP地址(RMV PMSADMINIP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于删除策略管理服务管理员的IP地址信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                               |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------|
| IPID   | IP地址索引 | 可选必选说明：必选参数 参数含义：唯一标识一个IP地址信息，用于指定需要删除哪一条策略管理服务管理员的IP地址信息记录，操作员可以使用LST PMSADMINIP命令查询获得。 取值范围：1～256 默认值：无。 配置原则：无。 |

## 使用实例

删除一个策略管理服务管理员IP地址信息：“IP地址索引”为“12”。

```
RMV PMSADMINIP: IPID=12;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
