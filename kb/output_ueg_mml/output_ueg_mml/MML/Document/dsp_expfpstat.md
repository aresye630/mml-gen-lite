# 显示LCS指纹数据导出状态（DSP EXPFPSTAT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于显示LCS指纹数据导出状态。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

显示LCS指纹数据导出状态：

```
DSP EXPFPSTAT:;
```

```
RETCODE = 0  操作成功

LCS指纹数据导出信息
----------------------------------------
         导出状态  =  成功
         导出时间  =  2021/12/01 18:16:30
         失败原因  =  NA
(结果个数 = 1)

---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释     |
|:--------|:----------|
| 导出状态    | 用于显示导出状态。 |
| 导出时间    | 用于显示导出时间。 |
| 失败原因    | 用于显示失败原因。 |
