# 查询锁定的POD（LST LCKPOD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

显示已经锁定的POD。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                               |
|:--------|:-------|:-----------------------------------------------------------------------------------|
| PODNAME | POD名称  | 可选必选说明：可选参数 参数含义：POD名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

显示已经锁定的POD：

```
LST LCKPOD:;
```

```
RETCODE = 0  操作成功

锁定POD信息
-------------
        POD名称  =  ssgpod-0
    锁定POD开关  =  使能
  多PDN接入开关  =  不使能
FullMesh 5G LAN组会话接入开关 = 不使能
(结果个数 = 1)

---    结束
```

#### 输出结果说明

| 输出项名称                  | 输出项解释                           |
|:-----------------------|:--------------------------------|
| POD名称                  | POD名称。                          |
| 锁定POD开关                | 使能时，POD为锁定状态，该参数为不使能时，POD为解锁状态。 |
| 多PDN接入开关               | 不使能时，允许多PDN接入，使能时，不允许多PDN接入。    |
| FullMesh 5G LAN组会话接入开关 | FullMesh 5G LAN组会话接入开关。         |
