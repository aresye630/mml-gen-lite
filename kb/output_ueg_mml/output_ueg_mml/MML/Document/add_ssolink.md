# 增加SSO链路(ADD SSOLINK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加一条SSO链路。

当UPCF WebUI使用SSO（Single Sign On）功能时，需要使用该命令增加一条SSO链路信息。

## 注意事项

系统只允许添加一条SSO链路。

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                                                        |
|:------------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LINKID      | 链路ID     | 可选必选说明：必选参数 参数含义：用于在配置库中定义一个PMS SSO链路。 取值范围：1 默认值：无。 配置原则：无。                                                                                                                                                |
| IPVER       | IP类型     | 可选必选说明：必选参数 参数含义：用于指定IP地址的IP版本类型。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。                                                                                                                                 |
| LOCALIP     | 本地IP地址   | 可选必选说明：条件必选参数 参数含义：用于指定链路使用的本地PMS设备的IPv4地址。 取值范围：IPv4地址 默认值：无。 配置原则：仅当“IP类型”配置为“IPV4(IPV4)”时该参数需要配置，此IP地址必须是本地实际的IP地址且必须先由ADD PMSDEVADDR命令（参数“FTP”需配置为“NO”）中“IPV4地址”参数定义，然后才能在此处引用。可通过LST PMSDEVADDR命令进行查询。 |
| LOCALIPV6   | 本地IPV6地址 | 可选必选说明：条件必选参数 参数含义：用于指定链路使用的本地PMS设备的IPv6地址。 取值范围：IPv6地址 默认值：无。 配置原则：仅当“IP类型”配置为“IPV6(IPV6)”时该参数需要配置，此IP地址必须是本地实际的IP地址且必须先由ADD PMSDEVADDR命令（参数“FTP”需配置为“NO”）中“IPV6地址”参数定义，然后才能在此处引用。可通过LST PMSDEVADDR命令进行查询。 |
| CISSUER     | 客户端授权人ID | 可选必选说明：可选参数 参数含义：用于标识客户端授权人ID，拼接SP元数据中entityID值。该参数为预留参数，设置不生效。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                                                                                                           |
| DESCRIPTION | 链路描述     | 可选必选说明：可选参数 参数含义：用于描述链路配置的用途。 取值范围：长度不超过32的字符串。 默认值：无。 配置原则：无。                                                                                                                                              |

## 使用实例

增加一条SSO链路配置数据记录。“链路ID”为“1”，“IP类型”为“IPV4”，“本地IP地址”为“192.168.0.130”。

```
ADD SSOLINK: LINKID=1, IPVER=IPV4, LOCALIP="192.168.0.130";
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                        | 原因分析                                                            | 处理建议                                                                                                   |
|------:|:-----------------------------|:----------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------|
| 58193 | 该IP地址不是PMS设备地址或PMS设备地址为FTP地址 | 输入的“本地IP地址”或“本地IPV6地址”不存在。输入的“本地IP地址”或“本地IPV6地址”对应的“FTP”为“YES”。 | 执行LST PMSDEVADDR命令，查询所有“FTP”为“NO”的PMS设备地址记录。 重新执行本命令，输入的“本地IP地址”或“本地IPV6地址”使用系统已添加的“FTP”为“NO”的PMS设备地址。 |
