# 查询全局初始请求计费绑定关系（LST CPGLBCTXREQRATE）

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用来查询全局的所有初始请求URR组的计费属性。

#### 注意事项

当前版本不支持此命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询全局的所有初始请求URR组的计费属性：

```
LST CPGLBCTXREQRATE:;
```

```
RETCODE = 0  操作成功。

全局初始请求计费绑定关系信息
----------------------------
初始请求URR组名称  =  urrgrp1
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见ADD CPGLBCTXREQRATE的参数说明。
