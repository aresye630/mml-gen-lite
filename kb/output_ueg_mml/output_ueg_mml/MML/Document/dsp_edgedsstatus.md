# 查询数据导入的文件名列表（DSP EDGEDSSTATUS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UDM**

该命令用于查询数据导入的文件名列表，可一次显示最多10次的数据导入信息。

#### 注意事项

只修改VNGROUP配置，不修改用户绑定的GROUPID配置，该场景不统计“修改用户数”。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

显示查询数据导入的文件名列表：

```
DSP EDGEDSSTATUS:;
```
