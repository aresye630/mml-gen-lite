# 查询MME复位标志(DSP MMERESETFLG)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明

#### 命令功能

**适用网元：MME**

此命令用于查看MME复位标志。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询MME复位标志：

DSP MMERESETFLG:;

```
%%DSP MMERESETFLG:;%%
RETCODE = 0  操作成功

输出结果如下：
-------------------------
MME复位标志  =  否
(结果个数 = 1)

---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                                                                                   |
|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MME复位标志 | 参数含义：MME复位标志。MME复位重启后，会启动TS12_1定时器，并设置MME复位标志为“是”。TS12_1定时器超时后，MME设置复位标志为“否”。请参考3GPP 29.118。 取值范围：“NO(否)”“YES(是)”  说明： TS12_1的值等于SET SGSPARA中“MME复位标志定时器增量(s)”设定值与SET EMM中“T3412”设定值之和。 |
