# 查询基于IMSI优选指定SMF配置（LST SMFPRESELBYIMSI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询基于IMSI优选指定SMF配置。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                           |
|:-------|:-------|:-----------------------------------------------------------------------------------------------|
| IMSI   | IMSI   | 可选必选说明：可选参数  参数含义：该参数用于指定进行优选指定SMF的用户IMSI。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是14~15。  默认值：无  配置原则：无 |

## 使用实例

查询IMSI为“123456789012345”的用户优选指定SMF配置，执行如下命令：

```
%%LST SMFPRESELBYIMSI:IMSI="123456789012345";%%
RETCODE = 0  操作成功

结果如下
--------
     IMSI  =  123456789012345
SMF实例ID  =  a6a61c6f-0d3a-4221-b1da-424eda3ccf67
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                    |
|:--------|:-------------------------|
| IMSI    | 该参数用于指定进行优选指定SMF的用户IMSI。 |
| SMF实例ID | 该参数用于指定优选SMF的实例标识。       |
