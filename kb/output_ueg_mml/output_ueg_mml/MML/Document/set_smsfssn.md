# 设置SMSF本局SSN号（SET SMSFSSN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMSF**

该命令用于设置SMSF对接SMSC网元时，SCCP层主叫地址中携带的SSN号。

## 注意事项

- 该命令执行后立即生效。
- 该命令目前适用于SMSF和SMSC短信中心对接时使用。在修改该命令前请通过**ADD CPSCCPSSN**命令配置本局信令点需要配置的子系统号。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                   |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------|
| SSN    | 子系统号   | 可选必选说明：可选参数 参数含义：该参数用于指定子系统号。 数据来源：本端规划 取值范围： “VLR(7)” “MSC(8)” “SGSN(149)” 默认值：无 初始系统默认值为“SGSN(149)”。 |

## 使用实例

设置SMSFSSN号为“MSC”。

```
SET SMSFSSN: SSN=MSC;
```
