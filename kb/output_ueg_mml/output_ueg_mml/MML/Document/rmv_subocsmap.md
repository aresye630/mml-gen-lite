# 删除OCS映射（RMV SUBOCSMAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响业务处理，需联系华为技术支持确认后再执行。

该命令用于在UPCF配置数据库中删除一条OCS映射记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                               |
|:-------|:-------|:-----------------------------------------------------------------------------------|
| MAPID  | 映射ID   | 标识一条OCS映射记录的关键字段，用于指定需要删除哪一条OCS映射记录。操作员可以使用LST SUBOCSMAP命令查询获得。 取值范围：0～1023 默认值：无。 |

## 使用实例

删除一条用户属性OCS映射记录，“映射ID”为“2”。

```
RMV SUBOCSMAP: MAPID=2;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
