# 删除IPv6群组成员(RMV IPV6GPMEM)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于删除IP群组成员配置。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称       | 参数说明                                                                                                                                                                                                             |
|:--------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPGPID  | IP群组标识     | 可选必选说明：必选参数 参数含义：该参数用于指定IP群组标识。 前提条件：“IP群组标识”已经通过ADD IPGP配置。 数据来源：本端规划 取值范围：1-255 默认值：无                                                                                                                          |
| IPV6    | IPv6地址     | 可选必选说明：条件必选参数 参数含义：该参数用于指定IPv6地址。 数据来源：本端规划 取值范围：::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 配置原则：IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址（::1）、链路本地地址（FE80::/10）和组播地址（FF00::/8）。 |
| IPV6MSK | IPV6地址前缀长度 | 可选必选说明：条件必选参数 参数含义：该参数用于指定IPv6地址的前缀的长度。 数据来源：本端规划 取值范围：0~128 默认值：无 配置原则：0是无效掩码。                                                                                                                                  |

#### 使用实例

删除IPv6群组成员，IP群组标识为1，IP地址为2001:db8::，IPV6地址前缀长度为61：

RMV IPV6GPMEM: IPGPID=1, IPV6="2001:db8::", IPV6MSK=64;
