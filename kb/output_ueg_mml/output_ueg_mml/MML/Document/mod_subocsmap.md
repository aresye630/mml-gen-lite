# 修改OCS映射（MOD SUBOCSMAP）

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响业务处理，需联系华为技术支持确认后再执行。

该命令用于在UPCF配置数据库中修改一条用户扩展属性或消息属性OCS映射记录。

## 注意事项

- 在线修改OCS映射记录时，SLR-Intermediate/STR消息还是发到修改前的OCS。如果此时OCS业务已切到新的OCS，则可能导致查询配额失败。
- Sy消息在主用局与容灾局之间转发处理时，如果支持OCS映射功能，则主用局和容灾局的OCS映射配置保持一致。
- OCS路由类型选择消息属性时，系统支持同一个消息属性取不同值，映射不同的OCS域名。
- OCS路由类型选择用户扩展属性时，系统不支持多个用户属性都配置OCS映射，但支持同一个用户属性取不同值时，映射不同的OCS域名。
- 执行本命令时，系统参数“ExtendAttriStrProcessModeEx”不允许设置为非0。

## 使用实例

修改一条用户扩展属性OCS映射记录。“映射ID”为“1”，“OCS路由类型”为“SubscriberAttribute（Subscriber Attribute）”，“用户属性”为“usrExAttr1（用户扩展属性1）”，“用户属性值”修改为“7”。

```
MOD SUBOCSMAP: MAPID=1, OCSRT=SubscriberAttribute, SUBATTR=usrExAttr1, ATTRVALUE=7;
```
