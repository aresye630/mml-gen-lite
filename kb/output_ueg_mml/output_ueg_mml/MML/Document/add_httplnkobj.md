# 新增HTTP链路测量对象(ADD HTTPLNKOBJ)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加一条HTTP2/HTTP1.1链路测量对象。

该命令的使用场景：

当系统需要基于HTTP2/HTTP1.1链路进行链路性能指标统计时，需要增加对应HTTP2/HTTP1.1链路测量对象。

## 注意事项

系统中增加的HTTP2/HTTP1.1测量对象记录数不能超过100条，超过规格后新增链路测量对象会添加失败。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                  |
|:----------|:-------|:------------------------------------------------------------------------------------------------------|
| WORKMODE  | 工作模式   | 可选必选说明：必选参数 参数含义：用于标识待增加的HTTP2/HTTP1.1链路测量对象的工作模式。 取值范围： SERVER(SERVER) CLIENT(CLIENT) 默认值：无。 配置原则：无。 |
| LOCALIP   | 本端IP地址 | 可选必选说明：必选参数 参数含义：用于标识待新增的HTTP2/HTTP1.1链路测量对象的本端IP地址。 取值范围：IPV4/IPV6地址格式的字符串，最大长度为40位。 默认值：无。 配置原则：无。  |
| LOCALPORT | 本端端口   | 可选必选说明：必选参数 参数含义：用于标识待增加的HTTP2/HTTP1.1链路测量对象的本端端口。 取值范围：0~65535。 默认值：无。 配置原则：无。                       |
| PEERIP    | 对端IP地址 | 可选必选说明：必选参数 参数含义：用于标识待新增的HTTP2/HTTP1.1链路测量对象的对端IP地址。 取值范围：IPV4/IPV6地址格式的字符串，最大长度为40位。 默认值：无。 配置原则：无。  |
| PEERPORT  | 对端端口   | 可选必选说明：必选参数 参数含义：用于标识待增加的HTTP2/HTTP1.1链路测量对象的对端端口。 取值范围：0~65535。 默认值：无。 配置原则：无。                       |

## 使用实例

当系统需要针对“工作模式”为“CLIENT”，“本端IP地址”为“192.168.121.183”，“本端端口”为“31”，“对端IP地址”为“192.168.121.184”, “对端端口”为“32”的链路进行链路性能指标统计时，增加如下链路测量对象：

```
ADD HTTPLNKOBJ: WORKMODE=CLIENT, LOCALIP="192.168.121.183", LOCALPORT=31, PEERIP="192.168.121.184", PEERPORT=32;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释        | 原因分析                                    | 处理建议                                                                    |
|-------:|:-------------|:----------------------------------------|:------------------------------------------------------------------------|
|    504 | 当前配置记录数达到上限。 | HTTP2/HTTP1.1链路测量对象数据记录数已达到上限100条，无法添加。 | 使用命令LST HTTPLNKOBJ查询HTTP2/HTTP1.1链路测量对象，删除无效数据并重新添加。                    |
| 360164 | 当前操作的链路不存在。  | 输入信息错误，需要输入正确的链路信息。                     | 使用DSP UDMHTTPLNK查询链路信息，找到需要进行链路性能指标统计的HTTP2/HTTP1.1链路数据状态信息，重新添加链路测量对象。 |
| 360165 | 当前添加的对象已存在。  | 链路测量对象里已经存在对应设置的链路。                     | 无需处理，使用LST HTTPLNKOBJ可以查询到对应的链路测量对象。                                    |
