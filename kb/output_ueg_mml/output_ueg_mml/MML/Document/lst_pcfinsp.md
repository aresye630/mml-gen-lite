## 命令功能

该命令为维护类命令，查询内部软件参数的配置信息。

## 注意事项

- 若需要查询全部软参数据记录的概要信息，请不要输入任何参数。
- 若需要查询某条参数数据记录的详细信息，请输入“参数名”。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                  |
|:-------|:--------|:------------------------------------------------------------------------------------------------------|
| INSPN  | 参数名     | 标识一条软参数据记录的关键字段之一（其取值在枚举值内取得），用于指定需要对哪一类软参数据记录的参数进行查询。 取值说明：详细信息请参考产品手册的“操作维护>软件参数>UPCF软件参数”。 默认值： 无。 |
| INSPV  | 参数值     | 标识一条软参数据记录的关键字段之一，此处取值应在取值范围内取值。其中，类型的编号规则是从上到下，从0开始顺序编号。 取值范围： 0～2147483647 默认值： 无。                  |
| DFTV   | 软件参数默认值 | 标识一条软参数据记录的关键字段之一，此处取值应在取值范围内取值。标识该参数的默认取值。 取值范围： 0～2147483647 默认值： 无。                                |

## 使用实例

查询内部软参。参数名为VRM\_GLBREFLASHINTERVAL。

```
LST PCFINSP: INSPN=VRM_GLBREFLASHINTERVAL;
```

```
%%LST PCFINSP: INSPN=VRM_GLBREFLASHINTERVAL;%%
RETCODE = 0  操作成功

操作结果如下:
-------------
        参数名  =  全局数据刷新时间间隔
        参数值  =  20
软件参数默认值  =  20
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见本命令的参数说明。
