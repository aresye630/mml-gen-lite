# 修改LCS算法参数（MOD LCSALGOPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于修改用户位置解算的算法开关以及参数配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称                | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|:---------------|:--------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GNODEBID       | 基站标识                | 可选必选说明：必选参数 参数含义：该参数用于设置基站标识。 数据来源：本端规划 取值范围：0~4294967295。 默认值：无 配置原则：该参数使用LST LCSALGOPARA命令配置生成。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| NRCELLID       | 小区标识                | 可选必选说明：必选参数 参数含义：该参数用于配置NR小区标识。 数据来源：本端规划 取值范围：0~65534。 默认值：无 配置原则：该参数使用LST LCSALGOPARA命令配置生成。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| LCSCALCSWITCH  | LCS算法开关             | 可选必选说明：可选参数 参数含义：该参数用于配置使能LCS算法的类型。 数据来源：本端规划 取值范围： UTDOA_C43_FANG：UTDOA_C43 FANG 算法。MBGD：小批量梯度下降算法。TOA_FINGERPRINT：TOA指纹定位解算算法。RSRP_FINGERPRINT：RSRP指纹定位解算算法。RSRP_TRIANGLE：RSRP三角定位解算算法。UTDOA_ONE_DIM：TOA一维定位解算算法。KALMAN_FILTER：卡尔曼滤波算法。RSRP_RADIOSLAM：基于RSRP RadioSLAM指纹自动采集算法。TOA_RADIOSLAM：基于TOA RadioSLAM指纹自动采集算法。MULTI_TOA_MEAS：多径TOA算法。UTDOA_AUTO_TAE：免信标部署。UTDOA_CLUSTER_FANG：UTDOA全聚类FANG算法开关。 默认值：无 配置原则：联系华为工程师进行配置。缺省不配置该命令时，取值范围为UTDOA_C43_FANG、MBGD、RSRP_FINGERPRINT、RSRP_TRIANGLE、KALMAN_FILTER、RSRP_RADIOSLAM、TOA_RADIOSLAM的值为1，其他值为0。当单独配置UTDOA_CLUSTER_FANG或MULTI_TOA_MEAS算法时，联系华为工程师审核。 |
| UTDOACALCTHD   | UTDOA定位解算阈值（厘米）     | 可选必选说明：可选参数 参数含义：该参数用于配置UTDOA经过双曲线解算之后多个解算坐标的质心与各个解算坐标的最大偏离值。 数据来源：本端规划 取值范围：50~1000。 默认值：无 配置原则：联系华为无线工程师进行配置。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| RSRPFPTHD      | 场强指纹定位解算阈值（0.1分贝毫瓦） | 可选必选说明：可选参数 参数含义：该参数用于配置场强指纹匹配过程中pRRU间的平均门限阈值。 数据来源：本端规划 取值范围：100~500。 默认值：无 配置原则：联系华为无线工程师进行配置。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| TOAFPTHD       | TOA指纹定位解算阈值（0.1纳秒）  | 可选必选说明：可选参数 参数含义：该参数用于配置TOA指纹匹配过程中pRRU间的平均门限阈值。 数据来源：本端规划 取值范围：10~50。 默认值：无 配置原则：联系华为无线工程师进行配置。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| RSRPTRANGLETHD | 场强三角定位解算阈值          | 可选必选说明：可选参数 参数含义：该参数用于配置场强三角定位平均门限阈值。 数据来源：本端规划 取值范围：50~3000。 默认值：无 配置原则：联系华为无线工程师进行配置。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| MBGDITRTTHD    | MBGD定位解算迭代步长        | 可选必选说明：可选参数 参数含义：MBGD算法使用梯度下降的方式进行求解，该参数用于配置每次迭代变化的距离。 数据来源：本端规划 取值范围：10~100。 默认值：无 配置原则：联系华为无线工程师进行配置。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| MBGDITRTENDTHD | MBGD定位解算迭代结束误差变化量   | 可选必选说明：可选参数 参数含义：该参数用于配置MBGD算法迭代过程两次迭代结果的误差的差值，即两次迭代结果误差变化量小于该值则迭代结束。 数据来源：本端规划 取值范围：1~10。 默认值：无 配置原则：联系华为无线工程师进行配置。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| MBGDITRTERRTHD | MBGD定位解算误差判决门限      | 可选必选说明：可选参数 参数含义：该参数用于配置MBGD算法迭代结束后的两个prru之间的平均误差门限，小于该门限则表示结果有效。 数据来源：本端规划 取值范围：10~160。 默认值：无 配置原则：联系华为无线工程师进行配置。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

#### 使用实例

修改GNODEBID为123，NRCELLID为123的用户位置解算的算法开关以及参数配置，将UTDOACALCTHD改为123：

```
MOD LCSALGOPARA: GNODEBID=123, NRCELLID=123, UTDOACALCTHD=123;
```
