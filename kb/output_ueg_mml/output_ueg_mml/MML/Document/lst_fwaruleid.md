# 查询FWA用户规则ID配置（LST FWARULEID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询FWA用户规则ID的配置信息。

- 如果需要查询全部FWA用户规则ID配置信息，请不要输入任何参数。
- 如果需要查询某条FWA用户规则ID配置信息，请输入参数“ID”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                           |
|:-------|:-------|:---------------------------------------------------------------|
| ID     | ID     | 可选必选说明：可选参数。 参数含义：表示FWA用户规则ID配置的记录标识。 取值范围：0～19 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询所有的FWA用户规则ID配置。

   ```
   LST FWARULEID:;
   ```

   ```
   %%LST FWARULEID:;%%
   RETCODE = 0  操作成功

   结果如下
   ------------
   ID  关键字        匹配类型       描述  

   0   fwa123        子字符串匹配   NULL         
   1   up_870000174  全匹配         NULL         
   (结果个数 = 2)

   ---    END
   ```
2. 查询一条FWA用户规则ID配置。“ID”为“0”。

   ```
   LST FWARULEID: ID=0;
   ```

   ```
   %%LST FWARULEID: ID=0;%%
   RETCODE = 0  操作成功

   结果如下
   ------------
            ID  =  0
        关键字  =  fwa123
      匹配类型  =  子字符串匹配
          描述  =  NULL
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见ADD FWARULEID命令的参数说明。
