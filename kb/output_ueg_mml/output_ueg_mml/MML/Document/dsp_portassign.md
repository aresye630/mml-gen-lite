# 查询端口分配结果（DSP PORTASSIGN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询已经重新分配后的各服务端口范围。

## 注意事项

无。

## 参数说明

无。

## 使用实例

直接执行**DSP PORTASSIGN**命令，可查询到当前所有PMS、NTS、HLB、DRS服务的实例ID及重新分配后的起始、结束端口号信息，实例如下。

```
DSP PORTASSIGN:;
```

```
%%DSP PORTASSIGN:;%%
RETCODE = 0  操作成功

操作结果如下:
-------------
服务类型      实例号                开始端口    结束端口  

PMS           12701247132752783149  47000       47199     
PMS           12701247132752939736  47200       47399     
NTS           12406387234061688495  40000       40199     
NTS           12406387234061530270  40200       40399     
HLB           12402564472649920684  40000       40007     
HLB           12402564472650076549  40008       40015     
(结果个数 = 6)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项解释请参见如下表1。

| 输出项名称   | 输出项解释                                           |
|:--------|:------------------------------------------------|
| 服务类型    | 参数含义：表示返回查询到的服务类型。 取值范围：枚举类型，取值如下。 PMSDRSNTSHLB |
| 实例号     | 参数含义：用于指定微服务对应的实例号。 取值范围：长度不超过256的字符串。          |
| 开始端口    | 参数含义：表示查询到的服务对应的起始端口号。 取值范围：长度不超过65536的整数。      |
| 结束端口    | 参数含义：表示查询到的服务对应的结束端口号。 取值范围：长度不超过65536的整数。      |
