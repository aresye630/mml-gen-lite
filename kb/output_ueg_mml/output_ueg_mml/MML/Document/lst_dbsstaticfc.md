# 查询DBS静态流控配置(LST DBSSTATICFC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询DBS静态流控参数：

- 若需要查询全部DBS静态流控信息，请不要输入任何参数。
- 若需要查询某条DBS静态流控信息，请输入“限制请求速率”或“突发请求数”或这两个参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                          |
|:-------------|:-------|:------------------------------------------------------------------------------------------------------------------------------|
| LIMITREQRATE | 限制请求速率 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照“限制请求速率”的值来查询单个DBS静态流控软参配置信息；若不输入，则表示所有“限制请求速率”的值。 取值范围：1000～100000 默认值：无。 配置原则：该参数的系统初始设置值为30000。 |
| BURSTREQNUM  | 突发请求数  | 可选必选说明：可选参数 参数含义：用于指示系统需要按照“突发请求数”的值来查询单个DBS静态流控软参配置信息；若不输入，则表示所有“突发请求数”的值。 取值范围：100～1000 默认值：无。 配置原则：该参数的系统初始设置值为500。        |

## 使用实例

查询DBS静态流控参数：

```
LST DBSSTATICFC:;
```

```
%%LST DBSSTATICFC:;%%

RETCODE = 0 操作成功 
操作结果如下
------------------------
限制请求速率 = 1000
  突发请求数 = 100
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。
