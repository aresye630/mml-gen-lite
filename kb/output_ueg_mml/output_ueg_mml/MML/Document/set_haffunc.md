# 设置HAF服务内部功能的相关参数（SET HAFFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

当前版本配置此命令不生效。

该命令用于设置HAF服务内部功能的相关参数。

## 注意事项

- 该命令执行后立即生效。

- 当前版本参数MCENHANCED的配置不生效。
- 为避免频繁执行对系统性能产生冲击，该命令在三分钟之内只能执行一次。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| DOMAINFAULT   | MCENHANCED   |
|:--------------|:-------------|
| ON            | ON           |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                                                                               |
|:------------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DOMAINFAULT | 域故障开关   | 可选必选说明：可选参数  参数含义：该参数用于指定域故障功能的开关。  数据来源：本端规划 取值范围： “ON（打开）”：域故障功能打开“OFF（关闭）”：域故障功能关闭  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST HAFFUNC查询当前参数配置值。  配置原则：  FusionSphere分批升级活动中，如果某批次升级出现调整失败提示时，需要通过该命令配置为OFF。其他场景为ON。升级完成后，如果参数的取值为OFF，需要将其手动设置为ON。 |
| MCENHANCED  | 多连接增强开关 | 可选必选说明：可选参数  参数含义：该参数用于指定是否开启多连接增强功能。  数据来源：本端规划 取值范围： “ON（打开）”：多连接增强功能打开“OFF（关闭）”：多连接增强功能关闭  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST HAFFUNC查询当前参数配置值。  配置原则：  该参数配置不生效。                                                                          |

## 使用实例

- 打开域故障功能开关。

  ```
  SET HAFFUNC:DOMAINFAULT=ON;
  ```
- 打开多连接增强开关。

  ```
  SET HAFFUNC:MCENHANCED=ON;
  ```
