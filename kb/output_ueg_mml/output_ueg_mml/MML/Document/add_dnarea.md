# 增加DNAI服务区域（ADD DNAREA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、SMF、GGSN、PGW-C**

该命令用于增加DNAI服务区域。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入16000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称       | 参数说明                                                                                                                                                    |
|:---------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------|
| AREANAME | DNAI服务区域名称 | 可选必选说明：必选参数  参数含义：该参数用于配置DNAI服务区域名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~255。不能为非法字符，只允许输入字母，数字、“_”、“.”，并且开头和结尾只能是数字或者字母，不能出现连续两个“.”。不区分大小写。  默认值：无  配置原则：无 |
| AREATYPE | DNAI服务区域类型 | 可选必选说明：必选参数  参数含义：该参数用于配置DNAI服务区域类型。  数据来源：全网规划 取值范围： N2TAI（5G类型的TAI）N2CID（5G类型的Cell Id）S1TAI（4G类型的TAI）S1CID（4G类型的Cell Id）  默认值：无  配置原则：无               |

## 使用实例

增加5G类型的TAI服务区域

```
ADD DNAREA: AREANAME="DNAREA1", AREATYPE=N2TAI;
```
