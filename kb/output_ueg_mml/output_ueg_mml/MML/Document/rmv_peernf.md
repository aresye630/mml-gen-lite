# 删除对端NF（RMV PEERNF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响业务处理，需联系华为技术支持确认后再执行。

该命令用于删除指定的对端NF信息。

## 注意事项

若“NF类型”为“SCP”，则在执行该命令后需要立即执行**CLR NFCACHE**命令，重新同步NF Profile信息。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                           |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTID | NF标识   | 可选必选说明：必选参数 参数含义：表示NF标识，用于指定需要删除哪一条对端NF配置信息数据记录的关键参数之一；操作员可以使用LST PEERNF命令查询获得。 取值范围：长度不超过36位的字符串 默认值：无。 配置原则：无。                                                                               |
| NFTYPE   | NF类型   | 可选必选说明：必选参数 参数含义：表示PCF对端NF类型，用于指定需要删除哪一条对端NF配置信息数据记录的关键参数之一；操作员可以使用LST PEERNF命令查询获得。 取值范围： NRF(NRF)AMF(AMF)SMF(SMF)BSF(BSF)CHF(CHF)AF(AF)SCP(SCP)UDR(UDR)NWDAF(NWDAF)HPCF(HPCF) 默认值：无。 配置原则：无。 |
| PEERID   | 对端标识   | 可选必选说明：必选参数 参数含义：表示PCF对端标识，用于指定需要删除哪一条对端NF配置信息数据记录的关键参数之一；操作员可以使用LST PEERNF命令查询获得。 取值范围：0~1023 默认值：无。 配置原则：无。                                                                                  |

## 使用实例

- 删除“NF标识”为“5947a69a-f61b-4bc1-b9da-47c9c5d14b64”，“对端标识”为“1”的CHF对端NF信息。

  ```
  RMV PEERNF: NFINSTID="5947a69a-f61b-4bc1-b9da-47c9c5d14b64", NFTYPE=CHF, PEERID=1;
  ```
- 删除“NF标识”为“4947a69a-f61b-4bc1-b9da-47c9c5d14b64”，“对端标识”为“2”的BSF对端NF信息。

  ```
  RMV PEERNF: NFINSTID="4947a69a-f61b-4bc1-b9da-47c9c5d14b64", NFTYPE=BSF, PEERID=2;
  ```
