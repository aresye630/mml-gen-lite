# 查询组网拓扑采集功能开关(LST NWTOPO)

#### 命令功能

**适用网元：SGSN、MME**

该命令用于显示组网拓扑信息采集功能是否打开。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询组网拓扑采集功能开关状态，运行命令如下：

`LST NWTOPO:;`

```
%%LST NWTOPO:;%%
RETCODE = 0  执行成功。

操作结果如下
-------------------------
拓扑采集功能  =  去使能
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见**SET NWTOPO**的参数说明。
