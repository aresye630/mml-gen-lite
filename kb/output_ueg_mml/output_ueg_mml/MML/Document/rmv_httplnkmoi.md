# 删除HTTP链路测量对象实例(RMV HTTPLNKMOI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于删除一条HTTP链路测量对象实例。

当DCS服务感知到HLB服务下线时，DCS服务将此HLB服务的实例ID从HTTPLNKMOI配置中删除。后续DCS服务每分钟校验HLB服务实例ID，校验时同时刷新HTTPLNKMOI配置，对于删除的HLB服务实例ID，则需要从HTTPLNKMOI配置中也删除。

本命令主要用于在系统异常情况下进行维护，通过执行本命令可以删除不存在的HLB服务实例ID。

## 注意事项

执行本命令删除HTTP链路测量对象实例时，若删除的对象实例为当前存在的有效实例，删除后系统会自动恢复该实例。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                      |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------|
| INSID  | 服务实例ID | 可选必选说明：必选参数 参数含义：标识一条HTTP链路测量对象实例记录的关键字段，用于指定需要删除哪一条服务实例号对应的HTTP链路测量对象实例记录，操作员可以使用LST HTTPLNKMOI命令查询获得。 取值范围：长度不超过255的字符串。 默认值：无。 配置原则：无。 |

## 使用实例

1. 执行**LST HTTPLNKMOI**命令，查询系统中已存在的“服务实例ID”。

   ```
   LST HTTPLNKMOI:;
   ```
2. 删除1中查询出来的一条“服务实例ID”。下面以“服务实例ID”为“13564655801154191991”的HTTP链路测量对象实例为例。

   ```
   RMV HTTPLNKMOI: INSID="13564655801154191991";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如下表1所示。

|   错误码 | 消息解释         | 原因分析                    | 处理建议                                        |
|------:|:-------------|:------------------------|:--------------------------------------------|
|   505 | 当前操作的配置数据不存在 | 输入的“服务实例ID”参数值不存在或已被删除。 | 执行LST HTTPLNKMOI命令查询已存在的“服务实例ID”，重新执行本命令删除。 |
