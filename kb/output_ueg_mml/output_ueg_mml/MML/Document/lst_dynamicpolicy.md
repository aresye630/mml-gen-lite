# 查询服务类型分配动态权重的管理策略（LST DYNAMICPOLICY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C、SMF、GGSN**

该命令用于查询指定服务类型的动态权重调整的动态负载均衡参数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                  |
|:------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 服务类型   | 可选必选说明：可选参数  参数含义：该参数用于指定服务类型。  数据来源：本端规划 取值范围： “UAM_0（UAM_0）”：涉及如下类型POD：接入/移动性管理POD。“USM_0（USM_0）”：涉及如下类型POD：会话管理POD。  默认值：无  配置原则：无 |

## 使用实例

查询服务类型为UAM\_0和USM\_0的调整阈值、差值门限、基础消耗、忙时差值门限：

```
%%LST DYNAMICPOLICY:;%%
            RETCODE = 0  操作成功

            结果如下
            --------
            服务类型  调整阈值  差值门限  基础消耗  忙时差值门限

            UAM_0     70         6         5         10
            USM_0     75         7         6         10
            (结果个数 = 2)

            ---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                              |
|:--------|:---------------------------------------------------|
| 服务类型    | 该参数用于指定服务类型。                                       |
| 调整阈值    | 该参数用于指定动态负载的调整阈值，同类型业务POD CPU使用率小于此数值时不进行动态负载调整。   |
| 差值门限    | 该参数用于指定动态负载的差值门限，同类型业务POD间CPU使用率差值小于此数值时不进行动态负载调整。 |
| 基础消耗    | 该参数用于指定基础消耗，表示POD空载时的CPU使用率。                       |
| 忙时差值门限  | 该参数用于指定忙时差值门限。                                     |
