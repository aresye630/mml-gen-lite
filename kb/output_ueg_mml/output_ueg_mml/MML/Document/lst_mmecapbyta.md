# 查询基于跟踪区的MME相对权重配置(LST MMECAPBYTA)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用网元：MME**

此命令用于查询指定跟踪区下，本MME在MME Pool区内的相对权重值。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                             |
|:-------|:-------|:-----------------------------------------------------------------|
| MCC    | 移动国家码  | 可选必选说明：可选参数 参数含义：该参数用于指定移动国家代码。 数据来源：整网规划 取值范围：3位的十进制数字 默认值：无    |
| MNC    | 移动网号   | 可选必选说明：可选参数 参数含义：该参数用于指定移动网号。 数据来源：整网规划 取值范围：2～3位的十进制数字 默认值：无    |
| TAC    | 跟踪区域码  | 可选必选说明：可选参数 参数含义：该参数用于指定跟踪区域码 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无 |

#### 使用实例

查看当前配置的全部跟踪区相对权重记录：

LST MMECAPBYTA:;

```
%%LST MMECAPBYTA:;%%
RETCODE = 0  操作成功。

输出结果如下
------------------------
移动国家码    移动网号    跟踪区域码    相对权重

123           03          0x201         100                  
123           03          0x202         255                  
(结果个数 = 2)
---    END
```

查看跟踪区123030200为对应的相对权重记录:

%%LST MMECAPBYTA: MCC="123", MNC="03", TAC="200";%%

```
%%LST MMECAPBYTA: MCC="123", MNC="03", TAC="200";%%
RETCODE = 0  操作成功。

输出结果如下
------------------------
移动国家码  =  123
  移动网号  =  03
跟踪区域码  =  0x200
  相对权重  =  255
(结果个数 = 1)
---    END
```
