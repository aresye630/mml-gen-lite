# 查询LCS NR Map ID配置（LST LCSNRMAPID）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该配置用于查询GnodeBId与MapId的映射关系。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                |
|:---------|:-------|:------------------------------------------------------------------------------------|
| GNODEBID | 基站标识   | 可选必选说明：可选参数 参数含义：该参数用于设置基站标识。 数据来源：全网规划 取值范围：整型数字类型，取值范围为0~4294967295。 默认值：无 配置原则：无 |
| MAPID    | 地图索引   | 可选必选说明：可选参数 参数含义：该参数用于指定地图索引。 数据来源：本端规划 取值范围：整数类型，取值范围是0~511。 默认值：无 配置原则：无          |

#### 使用实例

该命令用于查询GnodeBId和MapId的映射关系：

```
LST LCSNRMAPID:;
```

```

```
