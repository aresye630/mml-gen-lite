# 查询绑定配置(LST BINDCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于在配置数据库中查询Rx会话与Gx会话、Rx会话与N7会话和N5会话与N7会话的绑定配置信息。

- 若要查询全部绑定的配置信息，请不要输入任何参数。
- 若要查询某个绑定的配置信息，请输入“类型”或其他参数，或者“类型”和其他参数的组合。

## 注意事项

无。

## 使用实例

查询绑定配置信息。

```
LST BINDCFG:;
```
