# 增加APN激活数目限制(ADD APNACTNUM)

#### 命令功能

**适用网元：MME**

该命令用于增加APN激活数目限制配置。配置同一个用户相同APN可以建立的PDN连接最大数目和IP地址最大数目，当终端建立的PDN连接个数或分配的IP地址个数到达设置的阈值时，系统给终端回复PDN连接拒绝消息，携带配置的原因值。

#### 注意事项

- 该命令执行后立即生效。
- 本表最大记录数为256。
- 该命令执行后，对于用户已建立的PDN连接数不做限制，仅当用户建立新的PDN连接时生效。
- 该命令执行后，对于Handover和TAU流程中的PDN连接数不做限制。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:----------------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APNNI           | APN网络标识   | 可选必选说明：必选参数 参数含义：该参数用于指定PDN连接建立流程中使用的APN网络标识。 数据来源：全网规划 取值范围：1~62位字符串 默认值：无 配置原则：APN网络标识由一个或多个LABEL构成，各LABEL间用“.”间隔。每个LABEL的构成字符只能是字母A～Z或a～z、数字0～9和中划线“-”，字母不区分大小写。APN网络标识地址不能以“rac”、“lac”、“sgsn”或“rnc”开头，不能以“.gprs”结尾。  说明： “*”为通配符，表示对所有的APNNI生效。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| PDNNUM          | PDN连接数目   | 可选必选说明：可选参数 参数含义：该参数用于指定同一个用户相同APN可以建立的最大PDN连接数目。 数据来源：全网规划 取值范围：1~11 默认值：2  说明： 根据协议规定，同一个用户最多可建立11个PDN连接。本参数取值建议不小于“IPv4地址数目”和“IPv6地址数目”。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| IPV4ADDRNUM     | IPv4地址数目  | 可选必选说明：可选参数 参数含义：该参数用于指定同一个用户相同APN可以分配的最大IPv4地址数目。 数据来源：全网规划 取值范围：1~11 默认值：2  说明： IPv4v6双栈的PDN连接会分配1个IPv4地址，1个IPv6地址。本参数取值建议不大于“PDN连接数目”。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| IPV6ADDRNUM     | IPv6地址数目  | 可选必选说明：可选参数 参数含义：该参数用于指定同一个用户相同APN可以分配的最大IPv6地址数目。 数据来源：全网规划 取值范围：1~11 默认值：2  说明： IPv4v6双栈的PDN连接会分配1个IPv4地址，1个IPv6地址。本参数取值建议不大于“PDN连接数目”。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| PDNCONNREJCAUSE | PDN连接拒绝原因 | 可选必选说明：可选参数 参数含义：该参数用于设置PDN连接拒绝原因值。当终端建立的PDN连接个数或分配的IP地址个数到达设置的阈值时，系统给终端回复PDN连接拒绝消息，携带此原因值。 数据来源：全网规划 取值范围：“OPERATOR_DETERMINED_BARRING_8(Operator Determined Barring 8)”“INSUFFICIENT_RESOURCES_26(Insufficient resources 26)”“UNKNOWN_OR_MISSING_APN_27(Unknown or missing APN 27)”“USER_AUTH_FAILED_29(User authentication failed 29)”“REQUEST_REJECT_BY_SGW_OR_PGW_30(Request rejected by S-GW or P-GW 30)”“SERVICE_OPTION_NOT_SUPPORTED_32(Service option not supported 32)”“REQUEST_SERVICE_OPT_NOT_SUB_33(Requested service option not subscribed 33)”“NETWORK_FAILURE_38(Network failure 38)”“MULTI_PDN_FOR_APN_NOT_ALW_55(Multiple PDN for APN not allowed 55)”“PROTOCOL_ERROR_UNSPECIFED_111(Protocol error, unspecified 111)” 默认值：MULTI_PDN_FOR_APN_NOT_ALW_55(Multiple PDN for APN not allowed 55)  说明： 该参数建议使用默认值，原因值描述请参见协议24301-6.5.1.6章节。 |

#### 使用实例

增加一条“APN网络标识”为HUAWEI、“PDN连接数目”为3、“IPv4地址数目”为2、“IPv6地址数目”为2、“PDN连接拒绝原因”为Multiple PDN for APN not allowed 55 的APN激活数目限制配置记录

ADD APNACTNUM: APNNI="HUAWEI", PDNNUM=3, IPV4ADDRNUM=2, IPV6ADDRNUM=2, PDNCONNREJCAUSE=MULTI\_PDN\_FOR\_APN\_NOT\_ALW\_55;
