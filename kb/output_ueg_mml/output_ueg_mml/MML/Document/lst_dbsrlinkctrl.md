# 查询远端DSG链路中心(LST DBSRLINKCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询远端DSG链路中心的配置信息：

- 若需要查询所有远端DSG链路中心的配置信息，请不要输入任何参数。
- 若需要查询某条远端DSG链路中心配置信息，请输入“远端Location标识”或者其他参数或者这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称         | 参数说明                                                                                                                          |
|:-------|:-------------|:------------------------------------------------------------------------------------------------------------------------------|
| INDEX  | 配置索引         | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个配置索引来查询远端DSG链路中心的配置信息；若不输入，则表示查询所有远端DSG链路中心的配置信息。 取值范围：1～64 默认值：1 配置原则：无                         |
| RLOCID | 远端Location标识 | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个远端Location标识来查询远端DSG链路中心的配置信息；若不输入，则表示查询所有远端DSG链路中心的配置信息。 取值范围：1～512 默认值：无。 配置原则：               |
| RDSGST | 远端DSG业务类型    | 可选必选说明：可选参数。 参数含义：用于指示系统需要哪个远端DSG业务类型来查询DSG链路中心的配置信息；若不输入，则表示查询所有远端DSG业务类型对应的远端DSG链路中心的配置信息。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无 |

## 使用实例

查询所有远端DSG链路中心配置：

```
LST DBSRLINKCTRL:;
```

