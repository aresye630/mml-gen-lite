# 删除PMS VPN(RMV PMSVPN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在配置数据库中删除一条PMS接入CSLB时业务IP地址的VPN数据记录。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                   |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------|
| VPNINDEX | VPN索引  | 可选必选说明：必选参数 参数含义：标识一条VPN数据记录的关键字段，用于指定需要删除哪一条VPN数据记录，操作员可以使用LST PMSVPN命令查询获得。 取值范围：0～31 默认值：无。 配置原则：无。 |

## 使用实例

删除一条VPN数据记录。“VPN索引”为“0”。

```
RMV PMSDEVADDR: DEVAID=0;
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。
