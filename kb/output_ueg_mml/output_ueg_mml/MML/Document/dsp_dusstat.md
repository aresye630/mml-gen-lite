## 命令功能

该命令用于查询DUS服务实例的运行状态，如服务实例状态、内存占用率等。

该命令的使用场景：

- 维护场景**：**当需要定位问题时，可通过此命令查询DUS服务实例的状态信息。
- 升级场景**：**升级前可以通过此命令检查服务实例的状态，仅状态为“初始化完成”时可进行升级。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                          |
|:--------|:-------|:--------------------------------------------------------------|
| APPTYPE | 应用类型   | 可选必选说明：可选参数。 参数含义：用于请求系统按照指定应用类型显示服务实例状态信息；若不输入，则表示所有的应用类型。   |
| PODNAME | POD名称  | 可选必选说明：可选参数。 参数含义：用于请求系统按照指定POD名称显示服务实例状态信息；若不输入，则表示所有的POD名称。 |
| INSTID  | 实例标识   | 可选必选说明：可选参数。 参数含义：用于请求系统按照指定实例标识显示服务实例状态信息；若不输入，则表示所有的实例标识。   |

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称        | 输出项解释                                                                                                                                                                                                        |
|:-------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 应用类型         | 用于表示服务实例的应用类型。                                                                                                                                                                                               |
| POD名称        | 用于表示服务实例所属的POD名称。                                                                                                                                                                                            |
| Cluster标识    | 用于表示服务实例所属的集群ID。                                                                                                                                                                                             |
| 实例标识         | 用于表示实例标识，实例标识在Location内唯一。                                                                                                                                                                                   |
| 实例状态         | 用于表示服务实例当前的状态，当服务实例处于“初始化完成”状态时可对外承接业务。 取值范围： 非法的状态去激活异常初始化注册完成订阅完成基线化完成加载中加载完毕预启动初始化完成备份状态升级状态回滚状态迁移状态限制状态范围                                                                                                |
| 流控状态         | 用于表示服务实例当前是否处于流量控制状态。 取值范围： 关开仅消息阻塞流控 说明： 此输出项在该版本暂不支持。                                                                                                                                                      |
| 共享内存容量（MB）   | 用于表示服务实例当前的数据共享内存预分配大小，单位为兆字节。                                                                                                                                                                               |
| 共享内存占用率（%）   | 用于表示服务实例当前的共享内存实际使用大小相对于共享内存容量的占比。 取值说明： 0%～85%: 处于此范围属于正常的内存占用率。85%～95%: 如果服务实例内存占用率处于此范围，服务实例会上报“ALM-15503 微服务实例内存使用率过高”告警，需要关注是否需要扩容处理。>95%：如果服务实例内存占用率大于95%，服务实例会上报“ALM-15505 微服务实例内存不足”告警，需要关注是否需要扩容处理。 |
| 服务启动时间       | 用于表示服务实例的启动时间。                                                                                                                                                                                               |
| 主分片对象数量      | 用于表示服务实例中所有主分片的对象数量。                                                                                                                                                                                         |
| 备分片对象数量      | 用于表示服务实例中所有备分片的对象数量。                                                                                                                                                                                         |
| 复制消息堆积个数     | 用于表示待发送的复制消息个数。                                                                                                                                                                                              |
| 校验消息队列大小     | 用于表示该服务实例中校验消息队列中堆积的校验消息的个数。                                                                                                                                                                                 |
| 校验消息队列使用率（%） | 用于表示该服务实例中的校验消息队列使用率。                                                                                                                                                                                        |
| 垃圾对象数量       | 用于表示该服务实例中存在但不属于该服务实例的对象数量。                                                                                                                                                                                  |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释        | 原因分析                                                                    | 处理建议                                                                                                         |
|------:|:-------------|:------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------|
| 67820 | 指定的实例不存在。    | 输入的“实例标识”在系统中不存在。                                                       | 不输入“实例标识”参数，执行本命令，查询所有DUS服务实例的“实例标识”；正确配置“实例标识”参数后，重新执行本命令。                                                  |
| 67821 | 指定的POD名称不存在。 | 输入的“POD名称”在系统中不存在。                                                      | 通过执行DSP POD命令，查看当前所有的“Pod名称”，正确配置本命令的“POD名称”参数后，重新执行本命令。                                                     |
| 67822 | 指定的应用类型不存在。  | 输入的“应用类型”在系统中不存在。同时输入“应用类型”参数和“实例标识”参数时，输入的“应用类型”在系统中存在，但是在指定的服务实例中不存在。 | 通过执行LST APPTYPE命令查询当前已添加的业务类型，正确设置“应用类型”参数后，重新执行本命令。不输入“实例标识”参数，执行本命令，查询各服务实例所包含的应用类型，正确设置“应用类型”参数后，重新执行本命令。 |
