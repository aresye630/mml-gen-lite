# 删除话单统计（RMV CDRSTAT）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：NCG**

该命令用于删除话单统计任务。

#### 注意事项

- 执行删除操作后，会删除话单统计任务生成的结果文件，在执行删除操作之前，需确保结果文件已取走。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                          |
|:----------|:---------|:--------------------------------------------------------------------------------------------------------------|
| CDRSTATID | 话单统计任务标识 | 可选必选说明：必选参数 参数含义：话单统计任务标识，全局唯一。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则： 该参数不能包含“\”。不能输入的特殊字符请参考“特殊字符表”。 |

#### 使用实例

删除话单统计任务，配置举例如下：

```
RMV CDRSTAT: CDRSTATID="cdrstat1";
```
