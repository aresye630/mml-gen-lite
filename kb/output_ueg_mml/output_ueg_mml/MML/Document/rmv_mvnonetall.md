# 删除所有MVNO网络配置信息（RMV MVNONETALL）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

本命令用于删除所有MVNO网络配置信息。

#### 注意事项

- 该命令执行后立即生效。
- RMV MVNONETALL命令无法删除带IMSI参数的配置

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                    |
|:------------|:-------|:--------------------------------------------------------|
| OPTION_TYPE | 操作类型   | 可选必选说明：必选参数 参数含义：操作类型 数据来源：整网规划 取值范围：ALL 默认值：ALL 配置原则：无 |

#### 使用实例

删除所有MVNO网络配置信息。

```
%%RMV MVNONETALL: OPTION_TYPE=ALL;%%
```
