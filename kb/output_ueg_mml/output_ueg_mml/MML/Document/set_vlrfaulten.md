# 设置VLR故障增强功能(SET VLRFAULTEN)

#### 命令功能

**须知** 

该命令只有未部署IMS语音，并且VLR全部故障的场景下使用，否则可能造成整网语音不可用。在VLR恢复后请及时关闭该故障增强功能。

**适用网元：MME**

该命令用于设置VLR全故障场景增强功能开关。此配置仅在已明确VLR全故障的场景下应急使用，功能默认关闭。开启VLR故障增强开关后，在VLR全故障的场景下，通过模拟用户联合附着/TAU成功响应，使用户可以驻留4G使用数据业务。

#### 注意事项

- 该命令执行后立即生效。

- 此命令的最大记录数为1。

#### 本地用户权限

manage-ug;system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                                                                                                          |
|:----------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FAULTENSW | VLR故障增强功能开关 | 可选必选说明：可选参数 参数含义：该参数用于控制开启和关闭VLR全故障应急增强功能开关。功能开启后，当联合附着和联合TAU流程中CS注册失败后，MME按照联合接入成功响应UE，并且后续UE发起Extended Service Request流程时，MME可以让UE驻留4G，不回落CS域。 数据来源：全网规划 取值范围： OFF（关闭） ON（开启） 系统初始设置值：OFF（关闭） 配置原则：当VLR全部故障时，语音业务存在CS语音，但未部署IMS语音，为避免用户大批量脱网，可以开启本功能。  说明： 用户驻留4G主要通过如下方式实现：MME收到Extended Service Request消息后返回携带#39 CS service temporarily not available原因值和T3442 value信元的Service reject消息。 |

#### 使用实例

设置VLR全故障场景增强功能开启：

```
SET VLRFAULTEN: FAULTENSW=ON;
```
