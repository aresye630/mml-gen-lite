# 删除N26融合网关选择策略(RMV N26GWSELPLCY)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于LTE和5G互通组网部署时，删除5G用户的融合PGW-C/SMF选择策略。

#### 注意事项

- 该命令执行后不会对正在进行信令流程的用户立即生效，该命令中的限制会在用户的下一次信令流程中生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                              |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：必选参数 参数含义：该参数用于指定配置融合PGW-C/SMF选择策略的用户范围。 数据来源：全网规划 取值范围：“ALL_USER（所有用户）”“HOME_USER（本网用户）”“FOREIGN_USER（外网用户）”“IMSI_PREFIX（指定IMSI前缀）” 默认值：无                                                                                                                                 |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件必选参数 参数含义：该参数用以指定待配置融合PGW-C/SMF选择策略用户的IMSI前缀。 前提条件：只有“用户范围”为“IMSI_PREFIX（指定IMSI前缀）”时，该参数才有效。 数据来源：全网规划 取值范围：1～15位十进制数字字符串 默认值：无                                                                                                                                          |
| NOID     | 运营商标识  | 可选必选说明：条件必选参数 参数含义：该参数用于指定运营商标识。 前提条件：该参数在“SUBRANGE（用户范围）”配置为“FOREIGN_USER（外网用户）”或“HOME_USER（本网用户）”后生效。 数据来源：全网规划 取值范围：0～64，128～254 默认值：无                                                                                                                                         |
| APNNI    | APNNI  | 可选必选说明：必选参数 参数含义：该参数用于指定APNNI。 数据来源：全网规划 取值范围：1～62位字符串 默认值：无  说明： APN网络标识地址由一个或多个LABEL构成，各LABEL间用“.”间隔。每个LABEL的构成字符只能是字母A～Z或a～z、数字0～9和中划线“-”，字母不区分大小写。APN网络标识地址不能以“rac”、“lac”、“sgsn”或“rnc”开头，不能以“.gprs”结尾。符号“*”表示通配符，即不限制APNNI。如果“APNNI”为“*”，表示该记录适用于所有的APNNI，否则该记录适用于指定的APNNI记录。 |

#### 使用实例

删除“用户范围”为“ALL\_USER（所有用户）”，“APNNI”为“HUAWEI1.com”的配置：

```
RMV N26GWSELPLCY: SUBRANGE=ALL_USER, APNNI="HUAWEI1.com";
```
