# 查询升级服务申请状态（DSP UPGSRVREQSTATUS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于查询升级服务申请状态。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                  |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------|
| PHASE  | 升级阶段   | 可选必选说明：必选参数 参数含义：升级阶段。 数据来源：本端规划 取值范围： CTRL_UPG_END：ctrl升级完成。ALL_UPG_END：全部升级完成。 默认值：无 配置原则：该参数使用ACT UPGSRVREQ命令配置生成。 |

#### 使用实例

查询升级服务申请状态：

```
DSP UPGSRVREQSTATUS: PHASE=CTRL_UPG_END;
```

```
RETCODE = 0 操作成功
 
服务申请状态
-------------
状态 = 结束
(结果个数 = 1)
 
--- 结束
```

#### 输出结果说明

| 输出项名称   | 输出项解释   |
|:--------|:--------|
| 状态      | 升级服务状态。 |
