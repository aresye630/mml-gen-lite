# 删除服务支持的切片实例（RMV CPSLICEINSTINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、AMF、NRF、NSSF、NCG、NEF**

该命令用于删除服务支持的切片实例。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称       | 参数说明                                                                                                                                      |
|:--------|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------|
| NSIINFO | 网络分片实例信息   | 可选必选说明：必选参数  参数含义：该参数用于指定网络分片实例信息。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~40。本参数的构成字符只能是字母A～Z或a～z、数字0～9和中划线"-"，且不能以中划线“-”开头或结尾。  默认值：无  配置原则：无   |
| NSSIID  | 网络分片子网实例标识 | 可选必选说明：必选参数  参数含义：该参数用于指定网络分片子网实例标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~40。本参数的构成字符只能是字母A～Z或a～z、数字0～9和中划线"-"，且不能以中划线“-”开头或结尾。  默认值：无  配置原则：无 |

## 使用实例

删除一个网络分片实例信息为“NSSI-C-001-HDBNJ-NSSMF-01-A-HW”，网络分片子网实例标识为“NSSI-C-001-HDBNJ-NSSMF-01-A-HW01”的服务支持的切片实例：

```
RMV CPSLICEINSTINFO：NSIINFO="NSSI-C-001-HDBNJ-NSSMF-01-A-HW"； NSSIID="NSSI-C-001-HDBNJ-NSSMF-01-A-HW01"；
```
