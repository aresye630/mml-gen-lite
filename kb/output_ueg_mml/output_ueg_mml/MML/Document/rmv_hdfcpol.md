# 删除手动流控策略(RMV HDFCPOL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在配置数据库中删除一条手动流控策略数据记录。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                |
|:-------|:---------|:--------------------------------------------------------------------|
| ID     | 手动流控策略ID | 标识一条手动流控策略数据记录的关键字段，用于指定需要删除哪一条手动流控策略数据记录，操作员可以使用LST HDFCPOL命令查询获得。 |

## 使用实例

删除手动流控策略ID为1的记录。

```
RMV HDFCPOL: ID=1;
```
