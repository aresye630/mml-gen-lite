# 删除协议扩展端口号(RMV EXTPORT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成UIM无法与其他实体通信，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除一个UIM应用协议的扩展端口。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

删除UIM的扩展端口，必须要通知对端设备及时修改链路配置。否则，UIM与对端的通信会中断，请谨慎操作。

## 参数说明

| 参数标识     | 参数名称   | 参数描述                                                                   |
|:---------|:-------|:-----------------------------------------------------------------------|
| PORTTYPE | 端口类型   | 标识一条扩展端口信息数据记录的关键字段之一，用于指定需要删除哪一个应用协议类型的扩展端口，操作员可以使用LST EXTPORT命令查询获得。 |
| EXTPORT  | 扩展端口号  | 标识一条扩展端口信息数据记录的关键字段之一，用于指定需要删除哪一个扩展端口号，操作员可以使用LST EXTPORT命令查询获得。       |

## 使用实例

删除“端口类型”为“SOAP(SOAP)”，“扩展端口号”为“8081”的记录。

```
RMV EXTPORT: PORTTYPE=SOAP, EXTPORT=8081;
```
