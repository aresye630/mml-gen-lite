# 显示智能流控开启时长（DSP SMARTFCDURA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C**

该命令用于查询智能流控功能的定时开启时长。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询智能流控定时时长。

```
DSP SMARTFCDURA:;
```

| 输出项名称   | 输出项解释        |
|:--------|:-------------|
| Result  | 该参数用于显示查询结果。 |
