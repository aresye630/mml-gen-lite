# 查询ADC参数（LST CPADCPARA）

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于查询ADC参数。当运营商希望查询ADC下的流过滤器信息和重定向信息以及ADC的信息上报功能是否开启时，则执行该命令。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                             |
|:---------------|:-------|:-------------------------------------------------------------------------------------------------|
| FLOWFILTERNAME | 流过滤器名称 | 可选必选说明：可选参数 参数含义：该参数用于设置应用对应的流过滤器名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

假设运营商要查询指定ADC应用下的流信息上报开关信息，指定流过滤器名称为testflowfiltername：

```
LST CPADCPARA:FLOWFILTERNAME="testflowfiltername";
```

```
RETCODE = 0  操作成功。

ADC参数信息
-----------
  流过滤器名称  =  testflowfiltername
流信息上报标识  =  不使能
(结果个数 = 1)
---    END
```
