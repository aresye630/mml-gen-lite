# 查询CP和UP IP合一控制功能（LST CUSINGLEIPATTR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：MME、AMF、UPF、SGW-U**

此命令查询是否支持控制面N2/S1-MME和用户面N3/S1-U接口共IP地址。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询CP和UP IP合一控制功能的开关状态：

```
LST CUSINGLEIPATTR:;
```

```
RETCODE = 0  操作成功。

结果如下
-------------------
功能开关  =  使能
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见SET CUSINGLEIPATTR的参数说明。
