# 查询NF服务版本信息（LST NFSERVICEVER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF、SMF、NSSF、NRF、SMSF、NCG、NEF、NWDAF、SCF**

该命令用于查询NF服务实例的版本信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                                                                  |
|:---------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCENAME | NF实例名称 | 可选必选说明：可选参数  参数含义：该参数用于指定NFS实例所归属的NF实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~50。  默认值：无  配置原则：  本参数需要与ADD NFUUID命令中的NFINSTANCENAME值保持一致。 |
| SRVINSTANCEID  | 服务实例标识 | 可选必选说明：可选参数  参数含义：本参数用于指定NFS实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~50。  默认值：无  配置原则：  本参数与ADD CPNFSERVICE命令中的SRVINSTANCEID值一致时生效。      |

## 使用实例

运营商A需要查询所有服务实例的版本信息。

```
%%LST NFSERVICEVER:;%%
RETCODE = 0  操作成功

结果如下
--------
  NF实例名称  =  AMF_Instance_0
服务实例标识  =  Service_Instance_0
 API版本信息  =  1.0.0
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                   |
|:--------|:------------------------|
| NF实例名称  | 该参数用于指定NFS实例所归属的NF实例名称。 |
| 服务实例标识  | 本参数用于指定NFS实例标识。         |
| API版本信息 | 本参数用于指定NFS的全量版本信息。      |
