# 查询HTTP客户端配置（LST HTTPCLIENTCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询HTTP客户端配置信息。

## 注意事项

当输出结果当中的**链路管理模式**为“旧模式”，则“链路状态同步时长”、“NRF链路探测”、和“链路告警过滤方式”取值实际不生效。

## 参数说明

无。

## 使用实例

查询HTTP客户端配置信息。

```
LST HTTPCLIENTCFG:;
```

```
%%LST HTTPCLIENTCFG:;%%
RETCODE = 0  操作成功

操作结果如下
------------
    链路管理模式  =  新模式   
    心跳发送间隔  =  60
    心跳发送次数  =  3
    链路重建时长  =  60
链路状态同步时长  =  300
    链路拆除模式  =  复位拆除
    链路重建模式  =  不更换端口
     NRF链路探测  =  是
链路告警过滤方式  =  不生效
(结果个数= 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET HTTPCLIENTCFG**命令的参数说明。
