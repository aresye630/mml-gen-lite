# 删除HTTP状态码判定配置（RMV HTTPSTATUS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

执行该命令会改变HTTP特定场景下的行为，可能导致业务受损。

该命令用于删除已有的HTTP状态码判定配置。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                          |
|:-------|:-------|:----------------------------------------------------------------------------------------------|
| INDEX  | 索引     | 可选必选说明：必选参数  参数含义：该参数用于指定HTTPSTATUS配置的索引信息。  数据来源：本端规划  取值范围：整数类型，取值范围是1~1024。  默认值：无  配置原则：无 |

## 使用实例

删除已有的HTTP状态码判定配置，可以用如下命令：

```
RMV HTTPSTATUS: INDEX=1;
```
