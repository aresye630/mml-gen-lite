# 设置QoS监测配置（SET QOSMONT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于设置QoS监测配置。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| MONTSWITCH   |
|:-------------|
| DISABLE      |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                      |
|:-----------|:--------|:------------------------------------------------------------------------------------------|
| MONTSWITCH | QoS监测开关 | 可选必选说明：必选参数  参数含义：该参数用于配置QoS监测开关。  数据来源：本端规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无。  配置原则：无 |

## 使用实例

QoS监测开关配置为ENABLE:

```
SET QOSMONT: MONTSWITCH=ENABLE;
```
