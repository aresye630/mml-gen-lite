# 设置License告警阈值(SET LICALM)

- 命令功能
- 注意事项

- 使用实例
- 输出结果说明

## 命令功能

本命令用于设置License的告警阈值。系统根据当前使用的License控制项使用值和授权的License控制项授权值的比例和配置的告警阈值进行比较，超出相应的阈值时，上报License预警告警或过载告警，以免造成负荷过载引起业务受损。

## 注意事项

- 通过本命令配置TPS License控制项的告警阈值时需要按照现网多FE负荷分担比例原则设置，例如：TPS过载告警阈值为100%，2\*FE按照1：1负荷分担，单FE需要具备承载另一个FE网元故障能力，本命令需要设置过载告警阈值为50%，以保证本FE承载另一故障FE网元全部业务时不会产生License过载告警而导致鉴权业务受限。
- 通过本命令配置License告警阈值时，参数取值需要符合以下条件：“过载告警门限” > “过载告警恢复门限” > “预警告警门限” >“ 预警告警恢复门限” 。

## 参数说明

| 参数标识            | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                         |
|:----------------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LICITEM         | License控制项 | 可选必选说明：必选参数 参数含义：该参数标识需要设置告警阈值的License控制项。 数据来源：本端规划 取值范围：AUSF_Basic_TPS(AUSF Basic TPS)AAA_Basic_TPS(AAA_Basic_TPS)BSF_Basic_TPS(BSF_Basic_TPS)AP_Basic_TPS(AP_Basic_TPS)  说明： “AAA_Basic_TPS(AAA_Basic_TPS)”，“BSF_Basic_TPS(BSF_Basic_TPS)”和“AP_Basic_TPS(AP_Basic_TPS)”仅在Full-stack虚机场景下支持。 默认值：无。 配置原则：无。                |
| INFOALMTH       | 预警告警门限     | 可选必选说明：必选参数 参数含义：该参数标识License预警告警门限值。当前使用的License控制项使用值和授权的License控制项授权值比例大于该参数设置值时，产生ALM-18801 TPS License超过预警阈值告警。 数据来源：本端规划 取值范围：1~90 系统初始设置值：45 配置原则： 该参数取值大于“预警告警恢复门限”参数取值，并且小于“过载告警恢复门限”参数取值。产生告警时，当前使用的License控制项使用值和授权的License控制项授权值的实际比值和本参数设置的值存在1%偏差。例如，本参数设置为45时，当前使用的License控制项使用值和授权的License控制项授权值的比值为46时上报告警。 |
| INFORSALMTH     | 预警告警恢复门限   | 可选必选说明：必选参数 参数含义：该参数标识 License预警告警恢复门限值。当前使用的License控制项使用值和授权的License控制项授权值比例小于该参数设置值时，预警告警恢复。例如，本参数设置为44时，当前使用的License控制项使用值和授权的License控制项授权值的比值为43时告警恢复。 数据来源：本端规划 取值范围：1~88 系统初始设置值：44 配置原则：该参数取值小于“预警告警门限”参数取值。                                                                                                          |
| OVERLOADALMTH   | 过载告警门限     | 可选必选说明：必选参数 参数含义：该参数标识License过载告警门限值。当前使用的License控制项使用值和授权的License控制项授权值比例大于该参数设置值时表示过载，并上报ALM-18802 TPS License超过过载阈值告警。 数据来源：本端规划 取值范围：1~100 系统初始设置值：50 配置原则： 该参数取值大于“过载告警恢复门限”参数取值。产生告警时，当前使用的License控制项使用值和授权的License控制项授权值的实际比值和本参数设置的值存在1%偏差。例如，本参数设置为50时，当前使用的License控制项使用值和授权的License控制项授权值的比值为51时上报告警。              |
| OVERLOADRSALMTH | 过载告警恢复门限   | 可选必选说明：必选参数 参数含义：该参数用于设置License过载告警恢复门限值。当前使用的License控制项使用值和授权的License控制项授权值比例小于该参数设置值时，过载告警恢复。例如，本参数设置为49时，当前使用的License控制项使用值和授权的License控制项授权值的比值为48时告警恢复。 数据来源：本端规划 取值范围：1~98 系统初始设置值：49 配置原则：该参数取值大于“预警告警门限”参数取值，并且小于“过载告警门限”参数取值。                                                                                        |

## 使用实例

设置AUSF TPS License的容量告警数据，其中“预警告警门限”为“44”、“预警告警恢复门限”为“43”、“过载告警门限”为“49”、“过载告警恢复门限”为“48”：

```
SET LICALM: LICITEM=AUSF_Basic_TPS, INFOALMTH=44, INFORSALMTH=43, OVERLOADALMTH=49, OVERLOADRSALMTH=48;
```
