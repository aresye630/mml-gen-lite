# 删除LCS客户端信息（RMV LCSCLIENTINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

**须知** 

本命令属于高危命令，如果LCS Client没有绑定白名单MSISDN号段组，业务无法接入

该命令用于删除LCS Client与黑白名单MSISDN号段组的绑定关系。

#### 注意事项

- 该命令执行后立即生效。
- 该命令执行后，LCS CLient绑定的黑白名单MSISDN号段组均被删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称           | 参数说明                                                                                                |
|:-------------|:---------------|:----------------------------------------------------------------------------------------------------|
| LCSCLIENTID  | LCS客户端标识       | 可选必选说明：可选参数 参数含义：该字段用于指定LCS客户端标识。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无                    |
| SEGGROUPNAME | 白名单MSISDN号段组名称 | 可选必选说明：可选参数 参数含义：该参数用于指定白名单MSISDN号段组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

删除LCS客户端标识为"app1"，白名单号段组名为"group1"的CLIENTINFO：

```
RMV LCSCLIENTINFO: LCSCLIENTID="app1", SEGGROUPNAME="group1", CONFIRM=Y;
```
