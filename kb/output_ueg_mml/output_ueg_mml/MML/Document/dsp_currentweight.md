# 显示服务类型当前时间的非动态权重（DSP CURRENTWEIGHT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C、SMF、GGSN**

该命令用于查询当前的权重配置。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                  |
|:------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 服务类型   | 可选必选说明：必选参数  参数含义：该参数用于指定服务类型。  数据来源：本端规划 取值范围： “UAM_0（UAM_0）”：涉及如下类型POD：接入/移动性管理POD。“USM_0（USM_0）”：涉及如下类型POD：会话管理POD。  默认值：无  配置原则：无 |

## 使用实例

查询“服务类型”为“USM\_0”的pod的当前权重信息，执行如下命令：

```
%%DSP CURRENTWEIGHT: SERVICETYPE=USM_0;%%
RETCODE = 20111 操作成功

结果如下
--------
服务类型  POD名称  Host ID  Node ID  权重  当前权重策略类型
USM_0  sm2-pod-0 192.168.1.4  192.168.1.5  1.000   STATIC
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称    | 输出项解释                                                                                                                                                                                               |
|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 服务类型     | 该参数用于指定服务类型。 取值说明： “UAM_0（UAM_0）”：涉及如下类型POD：接入/移动性管理POD。“USM_0（USM_0）”：涉及如下类型POD：会话管理POD。                                                                                                           |
| POD名称    | 该参数用于指定POD名称。                                                                                                                                                                                       |
| Host ID  | 该参数用于指定Host ID。                                                                                                                                                                                     |
| Node ID  | 该参数用于指定Node ID。                                                                                                                                                                                     |
| 当前权重值    | 该参数用于指定权重值。                                                                                                                                                                                         |
| 当前权重策略类型 | 该参数用于指定权重类型。 取值说明： “DEFAULT（默认策略）”：同类型POD按照同等比例进行业务分配。“STATIC（静态策略）”：支持人工指定POD NAME实例配置差异化的静态权重，开启后动态权重不生效。“DYNAMIC（动态策略）”：开启之后系统可以根据CPU利用率进行均衡调整，适用于SMF。“DEFAULTHET（默认异构策略）”：开启之后可根据CPU硬件能力进行业务分配。 |
