# 查询I-UPF在特定园区专用APN下的部署模式配置（LST IUPFAPNDPMODE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF**

该命令用于查询I-UPF在特定园区专用APN下的部署模式配置，对非ULCL场景生效。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                      |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN    | APN名称  | 可选必选说明：可选参数  参数含义：该参数用于表示APN名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无  配置原则：  该参数取值应与ADD CPAPN命令中参数“APN”保持一致。 |

## 使用实例

查询APN为huawei.com的IUPF部署模式配置：

```
%%LST IUPFAPNDPMODE: APN="huawei.com";%%
            RETCODE = 0  操作成功

            结果如下
            --------
            APN  =  huawei.com
            5G下的IUPF部署模式  =  禁止插入IUPF
            5G禁止IUPF插入时返回的失败NAS原因值 = INSUFFICIENT_RESOURCES_FOR_SPECIFIC_SLICE_AND_DNN
            (结果个数 = 1)

            ---    END
```

## 输出结果说明

| 输出项名称                   | 输出项解释                                                       |
|:------------------------|:------------------------------------------------------------|
| APN名称                   | 该参数用于表示APN名称。                                               |
| 5G下的I-UPF部署模式           | 该参数用于指定5G组网形态下的I-UPF部署模式。                                   |
| 5G禁止I-UPF插入时返回的失败NAS原因值 | 该参数用于指定5G禁止I-UPF插入时，由于该配置导致的会话创建失败或修改失败，SMF给AMF返回的NAS拒绝原因值。 |
