# 设置N15策略优先级（SET N15SRVPRIO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于设置N15策略优先级。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                                                                                                    |
|:-----------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| POLICYTYPE | 策略类型      | 可选必选说明：必选参数。 参数含义：用于设置策略类型。 取值范围：AM(AM策略) 默认值：无。 配置原则：无。                                                                                                                |
| AMSRVPRIO  | 归属地AM策略优先 | 可选必选说明：条件必选参数。 前提条件：该参数在“策略类型”配置为“AM(AM策略)”时为必选参数。 参数含义：用于设置归属地AM策略优先。 取值范围： 全部选中：表示全部选中当前支持的所有取值。全部清空：表示全部清除当前支持的所有取值。全部灰化：表示当前所有选择值均不生效。UELOGO(UELOGO) 默认值：无。 配置原则：无。 |

## 使用实例

设置“归属地AM策略优先”为“UELOGO”的N15策略优先级。

```
SET N15SRVPRIO: POLICYTYPE=AM, AMSRVPRIO=UELOGO-1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
