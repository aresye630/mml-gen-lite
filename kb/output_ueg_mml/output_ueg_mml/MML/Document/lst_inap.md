# 查询内部审计参数配置信息(LST INAP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于在配置数据库中查询内部审计参数的配置信息。当前只有一条记录。

## 注意事项

无。

## 参数说明

| 参数标识            | 参数名称     | 参数说明                                 |
|:----------------|:---------|:-------------------------------------|
| APID            | 内部审计参数标识 | 用于指定一条内部审计参数配置记录，因为只有一条记录，此属性的值只能为0。 |
| AUDITTIME       | 审计时间     | 其值域类型为时间类型，用于指示每天定时发起内部审计的时间点。       |
| AUTOAUDITSWITCH | 自动增强审计开关 | 用于查询是否启动自动增强审计。                      |

## 使用实例

查询内部审计参数信息。

```
LST INAP:;
```

```
%%LST INAP:;%%
RETCODE = 0  操作成功

操作结果如下:
-------------
内部审计参数标识  =  0
        审计时间  =  03:00:00
自动增强审计开关  =  开启自动增强审计
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见本命令的参数说明。
