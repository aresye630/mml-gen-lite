# 删除NF TAC区域信息（RMV TACRANGE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、NRF、NSSF、NCG、SMSF、NWDAF、NEF、SCF**

该命令用于删除TAC区域信息。

## 注意事项

- 该命令执行后立即生效。

- 当该命令记录的INDEX被TAIRANGELIST引用时，无法进行删除操作。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                       |
|:-------|:-------|:-------------------------------------------------------------------------------------------|
| INDEX  | 索引标识   | 可选必选说明：必选参数  参数含义：本参数用于指定索引标识，用于标识TAC区域。  数据来源：全网规划  取值范围：整数类型，取值范围是0~2047。  默认值：无  配置原则：无 |

## 使用实例

运营商A需要删除索引标识为1的TAC区域信息。

```
RMV TACRANGE: INDEX=1;
```
