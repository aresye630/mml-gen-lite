# 修改策略管理服务对端链路配置信息(MOD PMSPEERLINKCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于修改或调整策略管理服务对端链路的配置信息。在该命令中，系统通过“链路ID”关键参数来唯一标识一条策略管理服务对端链路的配置信息。

## 注意事项

- 参数“本地角色”不允许修改，如需修改这个参数，可以采用先执行**LST PMSPEERLINKCFG**命令查询“本地角色”对应的“链路ID”，再执行

  **RMV PMSPEERLINKCFG**命令输入“链路ID”删除链路，最后执行**ADD PMSPEERLINKCFG**命令重新添加新链路的方式处理。
- 参数“对端IP地址”不能与访问FTP服务器或SFTP服务器的客户端的IP地址相同。
- 如果修改IP重新建链的时间为5分钟。
- 设置“本地IP地址”后，PMS与该命令配置的对端服务器通信时，只能使用设置的“本地IP地址”，不能再使用**ADD PMSDEVADDR**命令定义的其他IP地址。
- IPv4类型的IP地址不能配置如下非法IP地址：“127.0.0.1”、“0.0.0.0”、“255.255.255.255”、“224.0.0.1”。
- IPv6类型的IP地址不支持混合方式表达，即xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:d.d.d.d，其中x表示一个十六进制数（0～9或A～F），而d.d.d.d表示一个IPv4地址。
- IPv6类型的IP地址不支持以下特殊地址的配置，其中x表示一个十六进制数（0～9或A～F）：

  - 0000:0000:0000:0000:0000:0000:0000:0000
  - FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF
  - 0000:0000:0000:0000:0000:0000:0000:0001
  - FFxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE8x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE9x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEAx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEBx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx

## 使用实例

修改一条策略管理服务对端链路的对端IP和对端端口配置信息。“链路ID”为“1”，“本地角色”为“FTPClient(FTP客户端)”，“本地IP地址”为“192.168.0.130”，“对端IP地址”修改为“10.1.111.77”，“对端端口”修改为“2030”，其他参数使用缺省值。

```
MOD PMSPEERLINKCFG: LINKID=1, LOCALROLE=FTPClient, IPVER=IPV4, LOCALIP="192.168.0.130", PEERIP="10.1.111.77", PEERPORT=2030, CONFIRM=Y;
```
