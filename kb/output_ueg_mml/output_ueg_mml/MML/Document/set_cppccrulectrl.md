# 设置PCC规则相关控制（SET CPPCCRULECTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于设置PCC规则相关控制。使能或关闭QosRule是否使用PccRule优先级。

## 注意事项

- 该命令执行后只对新激活用户生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| QOSRULEPRIO         |
|:--------------------|
| INTERNAL_ALLOCATION |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|:------------|:-------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| QOSRULEPRIO | QoS Rule设置原则 | 可选必选说明：可选参数  参数含义：QOSRULEPRIO_SWITCH的值设置为INTERNAL_ALLOCATION，QosRule的优先级内部分配。QOSRULEPRIO_SWITCH的值设置为INHERIT_PCCRULE_PRECEDENCE，QosRule的优先级继承PCF下发PccRule优先级，并且SMF会限制PCF下发PccRule优先级范围是0~255。  数据来源：本端规划 取值范围： “INTERNAL_ALLOCATION（内部分配）”：QosRule不继承PccRule的优先级，QosRule的优先级内部分配。“INHERIT_PCCRULE_PRECEDENCE（继承PCC Rule优先级）”：QosRule的优先级继承PCF下发PccRule优先级，并且SMF会限制PCF下发PccRule优先级范围是0~255。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CPPCCRULECTRL查询当前参数配置值。  配置原则：无 |

## 使用实例

使能QosRule使用PccRule优先级。

```
SET CPPCCRULECTRL: QOSRULEPRIO= INHERIT_PCCRULE_PRECEDENCE;
```
