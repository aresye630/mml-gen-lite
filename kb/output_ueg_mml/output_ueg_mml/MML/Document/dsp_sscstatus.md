# 查询用户下线状态信息(DSP SSCSTATUS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

在执行了**SND SSCR**命令后，可以通过该命令查询用户下线的实际情况。

## 注意事项

无。

## 参数说明

无。

## 使用实例

UPCF主动发起用户下线请求后，查询用户下线状态信息

```
DSP SSCSTATUS:;
```

```
%%DSP SSCSTATUS:;%%
RETCODE = 0  操作成功

操作结果如下:
-------------
PES实例号  状态  完成率  目的主机名  需要处理的总个数  已经处理的个数  

538422018  空闲  NULL    NULL        0                 0               
538735686  空闲  NULL    NULL        0                 0               
(结果个数 = 2)

---    END
```

## 输出结果说明

| 参数名称     | 参数说明                                                                                                                         |
|:---------|:-----------------------------------------------------------------------------------------------------------------------------|
| PES实例号   | 用于返回当前的PES服务实例号。 取值范围：长度不超过256的字符串。                                                                                          |
| 状态       | 用于返回当前PES服务中执行用户下线的状态。 取值范围： 空闲：表示当前没有用户下线任务在执行。处理中：表示用户下线任务正在执行。异常终止：表示用户下线任务未执行完成。可再次执行SND SSCR命令。超时：表示系统接收PES服务的查询响应消息超时。 |
| 完成率      | 用于返回当前PES服务中执行用户下线的完成比率。 取值范围：NULL：表示当前没有用户下线任务在执行。1%～99%：表示用户下线任务执行的进度。                                                     |
| 目的主机名    | 用于返回当前用户下线任务的目的主机名。                                                                                                          |
| 需要处理的总个数 | 用于返回当前PES服务中需要处理的用户的总个数。                                                                                                     |
| 已经处理的个数  | 用于返回当前PES服务中已经处理的用户的个数。                                                                                                      |
