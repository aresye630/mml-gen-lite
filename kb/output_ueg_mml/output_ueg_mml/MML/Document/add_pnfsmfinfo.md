# 增加对端SMF的信息（ADD PNFSMFINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、NCG、NWDAF、NEF、SMF、SCF**

该命令用于增加本地配置的对端SMF支持的PGW域名信息和接入方式等信息。该命令用于在网络中没有部署NRF，或对端NF没有注册到NRF，或网络中存在NRF但需基于运营商策略本地配置周边NF的场景下，配置对端NF实例相关的信息。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入64条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                               |
|:-------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCEID | NF实例标识 | 可选必选说明：必选参数  参数含义：该参数用于指定NF实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~64。NFINSTANCEID参数建议满足以下约束规则：1.如果输入为uuid格式（格式例如：a6a61c6f-0d3a-4221-b1da-424eda3ccf67）只能为A-F、a-f、0-9和“-”的字符。2.如果输入不为uuid格式，长度不能超过18且不允许输入只包含0-9和“.”的字符串，例如：1.2.3.4、不允许输入只包含十六进制数（A-F、a-f、0-9）和“:”的字符串，例如：1::2、FBFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。3.该参数大小写不敏感。  默认值：无  配置原则：  本参数取值与ADD PNFPROFILE命令中的“NF实例标识”参数取值保持一致时，关联关系生效。 |
| PGWFQDN      | PGW域名  | 可选必选说明：必选参数  参数含义：当SMF与PGW-C合一部署时，该参数表示PGW-C的FQDN名称，用于用户从EPC到5G互操作流程中，帮助AMF找到EPC承载所在的融合网关。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~255。不区分大小写。  默认值：无  配置原则：无                                                                                                                                                                                                                                              |
| ACCESSTYPE   | 接入类型   | 可选必选说明：可选参数  参数含义：该参数用于指定SMF允许的接入方式。  数据来源：全网规划 取值范围： “AccessTypeINVALID（无效接入类型）”：无效接入类型“AccessType3GPP_ACCESS（3GPP接入类型）”：3GPP接入类型“AccessTypeNON_3GPP_ACCESS（NON 3GPP接入类型）”：NON 3GPP接入类型“AccessTypeMAX（MAX接入类型）”：MAX接入类型  默认值：无  配置原则：  当没有选择任何一种接入方式时，默认表示支持所有的接入方式。                                                                                                                              |

## 使用实例

增加对端SMF的信息，NF标识为SMF\_Instance\_0，PGWFQDN为huawei.com。

```
ADD PNFSMFINFO: NFINSTANCEID="SMF_Instance_0", PGWFQDN="huawei.com";
```
