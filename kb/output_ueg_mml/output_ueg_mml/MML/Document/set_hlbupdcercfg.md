# 设置HLB证书更新配置（SET HLBUPDCERCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

#### 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致业务中断，需联系华为技术支持确认后再执行。

用于设置HLB实例更新证书后，HLB链路分批拆除和重建的时间间隔。

#### 注意事项

- HLB证书更新期间，执行本命令调整参数取值后不会实时生效，等待下一次证书更新时才会使用新设置的参数值。
- HLB重建链的时间间隔需要小于所有HLB实例完成拆链的时间，保证不会出现所有HLB链路全部拆除链路又还未重建的情况。

  即HLBRECONTIME<（HLB实例数-1）\*HLBRESETCONTIME。
- 如果通过本命令设置的“HLB重建链时间间隔”大于通过SET HTTPCLIENTCFG命令设置的HLB故障链路重建时长，HLB会以故障链路重建时长为准进行链路重建。
- 该命令存在系统初始记录，参数的初始设置值如下：
  - “HLB拆链时间间隔”为“20”
  - “HLB重建链时间间隔”为“5”

#### 参数说明

| 参数标识            | 参数名称       | 参数说明                                                                  |
|:----------------|:-----------|:----------------------------------------------------------------------|
| HLBRESETCONTIME | HLB拆链时间间隔  | 可选必选说明：可选参数 参数含义：用于设置HLB证书更新后的拆链时间间隔。 取值范围：1~300，单位秒。 默认值：无。 配置原则：无。  |
| HLBRECONTIME    | HLB重建链时间间隔 | 可选必选说明：可选参数 参数含义：用于设置HLB证书更新后的重建链时间间隔。 取值范围：1~300，单位秒。 默认值：无。 配置原则：无。 |

#### 使用实例

设置HLB证书更新配置。“HLB拆链时间间隔”为“20”，“HLB重建链时间间隔”为“5”。

```
SET HLBUPDCERCFG: HLBRESETCONTIME=20, HLBRECONTIME=5;
```
