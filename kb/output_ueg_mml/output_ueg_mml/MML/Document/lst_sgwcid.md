# 查询SGW-C网络标识符（LST SGWCID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C**

该命令用于查询SGW-C的全球唯一标识。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询SGW-C的全球唯一标识，执行命令如下：

```
%%LST SGWCID:;%%
            RETCODE = 0  操作成功

            结果如下
            ------------------------
            移动国家码  =  460
            移动网号  =  01
            SGW-C标识  =  0
            (结果个数 = 1)

            ---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                            |
|:--------|:---------------------------------|
| 移动国家码   | 该参数用于指定组成SGW-C的全球唯一标识的移动国家码信息。   |
| 移动网号    | 该参数用于指定组成SGW-C的全球唯一标识的移动网号信息。    |
| SGW-C标识 | 该参数用于指定组成SGW-C的全球唯一标识的SGW-C标识信息。 |
