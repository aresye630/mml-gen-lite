# 删除UPF组的DNS属性（RMV UEDNSBINDUPGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：GGSN、PGW-C、SMF**

该命令用于删除指定UPF组的DNS属性和DNS64属性。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                 |
|:-----------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UPFGRPNAME | UPF组名称 | 可选必选说明：必选参数  参数含义：该参数用于指定UPF组的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。不区分大小写。  默认值：无  配置原则：  该参数使用ADD UEDNSUPGROUP命令生成。                                                                                                                                                                               |
| APNTYPE    | APN类型  | 可选必选说明：必选参数  参数含义：该参数用于指定APN类型。  数据来源：本端规划 取值范围： ALL_APN（所有APN）APN_GROUP（APN组）SPECIAL_APN（指定APN）  默认值：无  配置原则：  优先级从高到低：“SPECIAL_APN”、“APN_GROUP”、“ALL_APN”。                                                                                                                                         |
| APNGRPNAME | APN组名  | 可选必选说明：该参数在"APNTYPE"配置为"APN_GROUP"时为条件必选参数。  参数含义：该参数用于指定APN组名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~31。  默认值：无  配置原则：  该参数使用ADD SMFAPNGRP命令配置生成。  该参数在“APNTYPE”参数配置为“APN_GROUP”后生效。                                                                                                                      |
| APN        | APN名称  | 可选必选说明：该参数在"APNTYPE"配置为"SPECIAL_APN"时为条件必选参数。  参数含义：该参数用于指定APN实例名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”特殊字符，不区分大小写。  默认值：无  配置原则：  该参数使用ADD CPAPN命令配置生成。  该参数在“APNTYPE”参数配置为“SPECIAL_APN”后生效。 |

## 使用实例

当APNTYPE为ALL\_APN时，删除UPF组upfgrp1的DNS属性和DNS64属性：

```
RMV UEDNSBINDUPGRP: UPFGRPNAME="upfgrp1",APNTYPE=ALL_APN;
```
