# 设置冲突配置（SET SESCOLLISIONCFG）

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响N7会话上线，修改会话冲突配置需联系华为技术支持确认后再执行。

该命令为配置类命令，针对同一个用户下的N7会话场景，用于设置对PduSessionId相同的会话是否进行冲突检测。若UPCF检测到同一用户下PduSessionId相同的冲突会话，会释放老的N7会话，并发送terminateNotify消息给对端SMF。

## 注意事项

- 该命令执行成功后， 对新上线的N7会话立即生效。
- 在缺省的情况下，系统在初始化时已经在配置数据库中预置了冲突配置信息，参数“PduSessionId”取值为“Support（支持）”。

## 参数说明

| 参数标识         | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
|:-------------|:-------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ID           | ID           | 可选必选说明：必选参数 参数含义：用于设置参与同用户下N7会话冲突检测参数的记录标识。 取值范围：1。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| PDUSESSIONID | PduSessionId | 可选必选说明：可选参数 参数含义：用于表示是否支持通过PduSessionId进行同用户下N7会话冲突检测，进而释放掉冲突的N7会话。 取值范围： Support（支持）：UPCF对同一用户相同PduSessionId的N7会话进行检测，并释放掉PduSessionId冲突的老的N7会话，保留较新的N7会话，并发送terminateNotify消息给对端SMF。 说明： 当PduSessionId取值为Support（支持）时，释放掉PduSessionId冲突的老的N7会话后，除下列一种特殊场景外，UPCF都将会发送terminateNotify消息给对端SMF。 当一个N7会话（后文称为N7-1会话）在恢复的过程中，与内存中的另一个N7会话（后文称为N7-2会话）发生PduSessionId冲突，UPCF将会对两个会话的建立时间进行比较，若N7-1会话的时间戳小于等于另一个N7-2会话（N7-1会话时间较旧），则N7-1会话将会恢复失败，此时UPCF将不会发送terminateNotify消息给对端SMF。 Unsupport（不支持）：UPCF不开启同一用户相同PduSessionId的N7会话冲突检测。 默认值：无。 配置原则：无。 |

## 使用实例

设置PduSessionId为“Unsupport”，不支持通过PduSessionId进行同用户下N7会话冲突检测。

```
SET SESCOLLISIONCFG: ID=1, PDUSESSIONID=Unsupport;
```

