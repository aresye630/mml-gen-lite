# 设置发送通知的NTS实例个数(SET NTSNFNUM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，执行不当会影响通知发送，需联系华为技术支持确认后再执行。

该命令用于修改NTS通知配置信息。

操作员可以通过执行**SET NTSNFNUM**命令修改可以发送短消息通知、Email通知或SOAP通知的最大NTS个数。

短消息通知、Email通知和SOAP通知的主NTS数的初始值为0。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称         | 参数说明                                                                                     |
|:-------|:-------------|:-----------------------------------------------------------------------------------------|
| TYPE   | 通知类型         | 可选必选说明：必选参数 参数含义：用于设置NTS的通知类型。 取值范围： SMS（短消息通知）EMAIL（Email通知）SOAP（SOAP通知） 默认值：无。 配置原则：无。 |
| ACTNUM | 发送通知的NTS实例个数 | 可选必选说明：必选参数 参数含义：用于设置可以发送SMS通知、Email通知或SOAP通知的最大NTS实例个数。 取值范围：0~64 默认值：0。 配置原则：无。        |

## 使用实例

修改“短消息通知”的“主NTS数”为“7”。

```
SET NTSNFNUM: TYPE=SMS, ACTNUM=7;
```

返回结果如下:

```
%%SET NTSNFNUM: TYPE=SMS, ACTNUM=7, CONFIRM=Y;%%
RETCODE = 0  
Operation succeeded

---    END
```
