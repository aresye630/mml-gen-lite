# 删除网元服务信息(RMV UDMNFSERVICE)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成UDM在NRF上的注册信息中的服务信息发生错误，从而导致周边网元无法访问UDM提供的服务，造成业务失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除一条网元服务信息。

## 注意事项

- 删除网元服务信息数据时，如果指定“服务标识”所在的“组名称”被**ADD UDMNFSRV**引用，且是该服务组下最后一条记录，则不允许删除。

- 删除网元服务信息数据时，如果指定“服务标识”所在的“组名称”被**ADD UDMNFSRV**引用且NFSRV已注册成功，则按NFSRV中指定的更新方法立即向NRF发送更新请求。
- 当凌晨自动校验或执行**VRY NRFDATA**命令手动校验NRFClient内存数据时，在校验该MML命令的过程中，无法执行该命令，若运行该命令，则提示“360155 该MML数据正在校验中，请稍后再试”。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                          |
|:----------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICEID | 服务标识   | 可选必选说明：必选参数 参数含义：标识一条网元服务信息数据的关键字段，用于指定需要删除哪一条网元服务信息数据记录，操作员可以使用LST UDMNFSERVICE命令查询获得。 取值范围：长度不超过36位的字符串，字符串由数字、字母、“-”或“_”组成。 默认值：无。 配置原则：无。 |

## 使用实例

删除“服务标识”为“srvgrp1”的网元服务信息：

```
RMV UDMNFSERVICE: SERVICEID="srvgrp1";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释             | 原因分析                                    | 处理建议                                               |
|-------:|:------------------|:----------------------------------------|:---------------------------------------------------|
|    505 | 当前操作的配置数据不存在      | 输入的“服务标识”不存在。                           | 执行LST UDMNFSERVICE命令查询“服务标识”后重新输入。                 |
| 360044 | 当前记录在其他命令中引用，无法删除 | 该网元服务的“服务标识”被某一NFSRV引用。                 | 先删除NFSRV对该网元服务所属组的引用，再执行RMV UDMNFSERVICE命令删除该网元服务。 |
| 360155 | 该MML数据正在校验中，请稍后再试 | NRFClient内存数据校验正在进行中，对该命令的校验结束后才可执行该命令。 | 请稍后重试。                                             |
