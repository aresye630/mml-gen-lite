# 显示隧道策略信息（DSP TUNNELPOLICY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示隧道策略信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称      | 参数说明                                                                                                                |
|:--------------|:----------|:--------------------------------------------------------------------------------------------------------------------|
| ISPOLICYCOUNT | 是否仅查询策略个数 | 可选必选说明：必选参数 参数含义：该参数用于表示是否仅查询策略个数。 数据来源：本端规划 取值范围：枚举类型。 FALSE：否。TRUE：是。 默认值：无                                       |
| TNLPOLICYNAME | 隧道策略名字    | 可选必选说明：条件可选参数 前提条件：该参数在“ISPOLICYCOUNT”配置为“FALSE”时为可选参数。 参数含义：该参数用于表示隧道策略名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～39。 默认值：无 |

#### 使用实例

- 显示隧道策略信息：

  ```
  DSP TUNNELPOLICY:ISPOLICYCOUNT=FALSE;
  ```

  ```
  RETCODE = 0  操作成功。

  结果如下
  --------
    隧道策略名字  =  tp
  隧道类型序列号  =  GRE LSP
      负载分担数  =  50
  (结果个数 = 1)
  ---    END
  ```
- 显示隧道策略信息，仅查询策略个数：

  ```
  DSP TUNNELPOLICY:ISPOLICYCOUNT=TRUE;
  ```

  ```
  RETCODE = 0  操作成功。

  结果如下
  --------
    策略总数  =  1
  选择策略数  =  1
  无效策略数  =  0
  (结果个数 = 1)
  ---    END
  ```

#### 输出结果说明

| 输出项名称   | 输出项解释        |
|:--------|:-------------|
| 策略总数    | 用于表示策略总数。    |
| 选择策略数   | 用于表示选择策略数。   |
| 无效策略数   | 用于表示无效策略数。   |
| 隧道策略名字  | 用于表示隧道策略名字。  |
| 隧道类型序列号 | 用于表示隧道类型序列号。 |
| 负载分担数   | 用于表示负载分担数。   |
