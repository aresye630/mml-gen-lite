# 查询全局计费属性（LST GLBURRGROUP）

- 命令功能
- 注意事项

#### 命令功能

**适用NF：PGW-U、UPF**

本条命令用于查询全局计费属性。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询显示全局计费属性：

```
LST GLBURRGROUP:;
```

