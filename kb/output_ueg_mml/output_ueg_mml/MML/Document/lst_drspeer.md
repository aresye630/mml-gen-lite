# 查询报表服务对端服务器配置信息(LST DRSPEER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询报表服务对端服务器的配置信息。

- 如果需要查询全部DRS对端服务器数据，请不要输入任何参数。
- 如果需要查询特定的DRS对端服务器数据，请依据参数说明输入查询的条件。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                  |
|:---------|:--------|:----------------------------------------------------------------------------------------------------------------------|
| PEERID   | 对端服务器ID | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个对端服务器ID来查询DRS对端服务器信息；若不输入，则表示所有的对端服务器ID。 取值范围：1～32 默认值：无。 配置原则：无。                        |
| PEERNAME | 对端服务器名称 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个对端服务器名称来查询DRS对端服务器信息，值域类型为字符串，区分大小写；若不输入，则表示所有的对端服务器名称。 取值范围：长度不超过128的字符串 默认值：无。 配置原则：无。 |
| PEERTYPE | 对端服务器类型 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个对端服务器类型来查询DRS对端服务器信息；若不输入，则表示所有的对端服务器类型。 取值范围： SFTP(SFTP协议)FTP(FTP协议) 默认值：无。 配置原则：无。     |

## 使用实例

1. 查询DRS对端服务器的配置信息。

   ```
   LST DRSPEER:;
   ```

   ```
   %%LST DRSPEER:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
     对端服务器ID  =  1 
   对端服务器名称  =  DRSSFTP1
   对端服务器类型  =  SFTP协议
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD DRSPEER**命令的参数说明。
