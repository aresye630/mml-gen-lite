# 显示NRF状态(DSP NRFSTATUS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询NRF的状态。

- 若需要查询某个NRF的状态，请输入“NRF名称”参数。
- 若需要查询某个组中NRF的状态，请输入“NRF所属组信息”参数。
- 若需要查询所有NRF的状态，不输入任何参数。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                                    |
|:---------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------|
| NRFGROUP | NRF所属组信息 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个“NRF所属组信息”来查询NRF状态；若不输入，则表示所有的NRF所属组信息。 取值范围：长度不超过32位的字符串。 默认值：无。 配置原则：该参数全局唯一且需UDM与NRF端协商获取此参数名，通过ADD UDMNRFINFO命令配置初始添加。 |
| NRFNAME  | NRF名称    | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个“NRF名称”来查询NRF状态；若不输入，则表示所有的NRF名称。 取值范围：长度不超过32位的字符串。 默认值：无。 配置原则：该参数全局唯一且需UDM与NRF端协商获取此参数名，通过ADD UDMNRFINFO命令配置初始添加。       |

## 使用实例

1. 查询所有NRF状态：

   ```
   DSP NRFSTATUS:;
   ```

   ```
   %%DSP NRFSTATUS:;%%
   RETCODE = 0  操作成功

   结果如下
   -----------
   NRF所属组信息  NRF名称   NRF URI                  NRF URI2 优先级       NRF状态               网元实例名称

   nrfgroup-01    nrf-01    http://192.168.1.1:8080  NULL      1           激活                  udmnfsrv1
   nrfgroup-01    nrf-01    http://192.168.1.1:8080  NULL      1           激活                  udmnfsrv3
   nrfgroup-01    nrf-01    http://192.168.1.1:8080  NULL      1           激活                  udmnfsrv6
   nrfgroup-02    nrftest00 http://192.168.1.2:8080  NULL      1           空闲                  NULL  
   nrfgroup-03    nrftest01 http://192.168.1.2:8080  NULL      2           故障                  udmnfsrv1
   (结果个数 = 5) 

   ---    END
   ```
2. 查询特定NRF的状态，“NRF名称”为“nrf-02”：

   ```
   DSP NRFSTATUS: NRFNAME="nrf-02";
   ```

   ```
   %%DSP NRFSTATUS: NRFNAME="nrf-02";%%
   RETCODE = 0  操作成功

   结果如下
   ------------
                NRF所属组信息  =  nrfgroup-02
                      NRF名称  =  nrf-02
                      NRF URI  =  https://192.168.1.2:8080
                     NRF URI2  =  NULL
                       优先级  =  1
                      NRF状态  =  空闲
                 网元实例名称  =  NULL
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见

**ADD UDMNRFINFO**

命令的参数说明。表1列出的是未包含在

**ADD UDMNRFINFO**

命令参数说明中的输出项。

| 输出项名称   | 输出项解释                                                                                      |
|:--------|:-------------------------------------------------------------------------------------------|
| NRF状态   | 用于表示当前查询的NRF状态。 空闲：NRF处于没有被使用的状态。激活：NRF处于被使用的状态，并且和UDM之间通信正常。 故障：NRF处于被使用的状态，并且和UDM之间通信异常。 |
| 网元实例名称  | 用于表示UDM向当前查询的NRF上注册的网元实例名称。                                                                |
