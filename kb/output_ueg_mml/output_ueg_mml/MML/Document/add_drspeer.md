# 增加报表服务对端服务器(ADD DRSPEER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在配置数据库中添加一条报表服务对端服务器的数据记录。

当UPCF与POP-D对接的场景下，需要配置该命令增加与UPCF连接的对端网元实体信息。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                   |
|:---------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------|
| PEERID   | 对端服务器ID | 可选必选说明：必选参数 参数含义：用于标识一条报表服务对端服务器的数据记录。 取值范围：1～32 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。                                                     |
| PEERNAME | 对端服务器名称 | 可选必选说明：必选参数 参数含义：用于具体描述一个报表服务对端服务器的名称，以便于识别。值域类型为字符串，区分大小写。 取值范围：长度不超过128的字符串 默认值：无。 配置原则： 运营商统一规划，本端须与对端服务协商配置。对端服务器名称不能重复。           |
| PEERTYPE | 对端服务器类型 | 可选必选说明：必选参数 参数含义：用于标识报表服务对端服务器的应用类型。 取值范围： SFTP(SFTP协议)FTP(FTP协议) 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。  说明： 使用“FTP”协议存在安全风险，建议使用“SFTP”协议。 |

## 使用实例

增加一个SFTP类型的报表服务对端服务器。“对端服务器ID”为“1”，“对端服务器名称”为“DRSSFTP1”，“对端服务器类型”为“SFTP(SFTP协议)”。

```
ADD DRSPEER: PEERID=1, PEERNAME="DRSSFTP1", PEERTYPE=SFTP;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释         | 原因分析           | 处理建议                                                                                      |
|------:|:--------------|:---------------|:------------------------------------------------------------------------------------------|
| 57986 | 对端服务器名称已经被使用。 | “对端服务器名称”不能重复。 | 执行LST DRSPEER命令查询全部报表服务对端服务器配置信息，记录已存在的对端服务器名称。 执行本命令，重新设置“对端服务器名称”，并确保和已存在的“对端服务器名称”不相同。 |
