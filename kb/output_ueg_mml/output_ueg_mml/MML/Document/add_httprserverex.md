# 增加远端服务器扩展配置(ADD HTTPRSERVEREX)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在数据库增加一条远端服务器扩展记录。

## 注意事项

- 本命令最多可以配置1024条远端服务器扩展记录。
- 执行本命令时，如果同时配置了“全量域名”和“对端IP地址类型”参数，使用配置的IP地址建链，不再使用“全量域名”中配置的IP地址。
- 执行本命令配置SSG链路时，如果**DSP HTTPLNK**命令在客户端模式下查询的结果中已经存在相同对端IP地址和对端端口号且对端网元类型为非SSG的链路，执行本命令后需要执行**RMV HTTPLINK**命令删除该非SSG链路，操作完成后新建链路10分钟左右生效。
- 相同“网元实例标识”对应的“网元优先级”、“网元组名称”、“网元类型”必须相**同**。
- 同一个“网元组名称”对应多个“网元实例标识”时，对接时使用其中优先级最高的网元。

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                          |
|:------------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RSERVERNAME | 远端服务器名称  | 可选必选说明：必选参数 参数含义：用于指定远端SSG服务器组中的服务器名称。 取值范围：长度不超过128的由数字和字母组成的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。                                                                    |
| NFINSID     | 网元实例标识   | 可选必选说明：必选参数 参数含义：用于指定网元实例在系统中的序号。 取值范围：有效的UUIDv4格式，只允许输入0～9，a～f，A～F，“-”。 默认值：无。 配置原则：UUIDv4格式为“xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx”，例如：4947a69a-f61b-4bc1-b9da-47c9c5d14b64。 |
| NFPRIORITY  | 网元优先级    | 可选必选说明：必选参数 参数含义：用于指定网元的优先级。 取值范围：0～65535 默认值：无。 配置原则： 该参数取值越小，网元优先级越高。相同网元实例的网元优先级配置必须相同。                                                                                    |
| NFGRPNAME   | 网元组名称    | 可选必选说明：必选参数 参数含义：用于指定网元所在组的组名称。 取值范围：长度不超过128的由数字和字母组成的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：相同网元实例的网元组名称配置必须相同。                                                          |
| NFTYPE      | 网元类型     | 可选必选说明：必选参数 参数含义：用于指定网元实例的类型。 取值范围：SSG(信令安全网关) 默认值：无。 配置原则：无。                                                                                                                 |
| FQDN        | 全量域名     | 可选必选说明：可选参数 参数含义：用于指定信令安全网关的全量域名。 取值范围：长度不超过255位的字符串，字符串由数字、字母、“-”、“_”或“.”组成。 默认值：无。 配置原则：本参数和“对端IP地址类型”参数至少需要输入一个。                                                           |
| PIPVER      | 对端IP地址类型 | 可选必选说明：可选参数 参数含义：用于指定对端IP地址类型。 取值范围： IPV4(IPV4) IPV6(IPV6) 默认值：无。 配置原则：本参数和“全量域名”参数至少需要输入一个。                                                                                  |
| PIPV4IP     | 对端IPv4地址 | 可选必选说明：条件必选参数 参数含义：用于指定对端IPv4地址。 取值范围：有效的IPv4地址 默认值：无。 配置原则：当“对端IP地址类型”参数取值为“IPV4(IPV4)”时，必须输入本参数。                                                                            |
| PIPV6IP     | 对端IPv6地址 | 可选必选说明：条件必选参数 参数含义：用于指定对端IPv6地址。 取值范围：有效的IPv6地址 默认值：无。 配置原则：当“对端IP地址类型”参数取值为“IPV6(IPV6)”时，必须输入本参数。                                                                            |
| PPORT       | 对端端口号    | 可选必选说明：必选参数 参数含义：用于指定一个对端端口号。 取值范围：1~65535 默认值：无。 配置原则：无。                                                                                                                     |

## 使用实例

1. 增加一条远端服务器扩展配置，其中“远端服务器名称”为“ssg\_1”、“网元实例标识”为“11111111-1111-1111-1111-111111111111”、“网元优先级”为“1”、“网元组名称”为“001”、“网元类型”为“SSG(信令安全网关)”、“对端IP地址类型”为“IPV4(IPV4)”、“对端IPv4地址”为“192.168.91.105”、“对端端口号”为“8800”：

   ```
   ADD HTTPRSERVEREX: RSERVERNAME="ssg_1", NFINSID="11111111-1111-1111-1111-111111111111", NFPRIORITY=1, NFGRPNAME="001", NFTYPE=SSG, PIPVER=IPV4, PIPV4IP="192.168.91.105", PPORT=8800;
   ```
2. 增加一条远端服务器扩展配置，其中“远端服务器名称”为“ssg\_2”、“网元实例标识”为“11111111-1111-1111-1111-111111111112”、“网元优先级”为“2”、“网元组名称”为“002”、“网元类型”为“SSG(信令安全网关)”、“全量域名”为“udm1.huawei.com”、“对端端口号”为“8808”：

   ```
   ADD HTTPRSERVEREX: RSERVERNAME="ssg_2", NFINSID="11111111-1111-1111-1111-111111111112", NFPRIORITY=2, NFGRPNAME="002", NFTYPE=SSG, FQDN="udm1.huawei.com", PPORT=8808;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    504 | 当前配置记录数达到上限                              | 系统中配置的远端服务器扩展记录达到1024条上限，无法继续配置。                | 使用LST HTTPRSERVEREX命令查询已配置的远端服务器扩展记录，删除不需要的数据后重新执行本命令添加。                                          |
