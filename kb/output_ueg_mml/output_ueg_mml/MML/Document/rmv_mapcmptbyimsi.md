# 删除MAP协议接口兼容性IMSI号段配置(RMV MAPCMPTBYIMSI)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用于删除MAP协议接口兼容性IMSI号段配置。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                              |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：必选参数 参数含义：该参数用于指定MAP兼容性参数策略的用户范围。 数据来源：全网规划 取值范围：“FOREIGN_USER(外网用户)”“HOME_USER(本网用户)”“IMSI_PREFIX(指定IMSI前缀)” 默认值：无        |
| NOID     | 运营商标识  | 可选必选说明：条件必选参数 参数含义：该参数用于指定运营商标识。 前提条件：该参数在“用户范围”参数配置为“FOREIGN_USER(外网用户)”或“HOME_USER(本网用户)”后生效。 数据来源：全网规划 取值范围：0～64，128～254 默认值：无 |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI前缀。 前提条件：该参数在“用户范围”参数配置为“IMSI_PREFIX(指定IMSI前缀)”后生效。 数据来源：全网规划 取值范围：1～15位十进制数字字符串。 默认值：无             |

#### 使用实例

配置方式：删除“用户范围”为“IMSI\_PREFIX(指定IMSI前缀)”，“IMSI前缀”为“123456789”的配置记录

RMV MAPCMPTBYIMSI: SUBRANGE=IMSI\_PREFIX, IMSIPRE="123456789";
