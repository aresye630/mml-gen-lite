# 启动一键式网络拓扑采集任务(STR TOPOTASK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

#### 命令功能

适用网元：SGSN、MME

- 本命令用于启动一键式网络拓扑采集任务。

#### 注意事项

- 本命令会采集网元接口(Gn/Gp、Gr、Ga、Iu、S1-MME、S10、S11、S6a/S6d、S13、Sv、SGs、DNS)的静态信息（本端IP、功能实体名称、VPN名称等），IP地址对信息（IP地址对、对端网元名称、接口类型等）及IP地址对的TraceRoute信息
- 导出信息会同步到主备OMU，导出信息存储在：/opt/USN\_VNFC/x/x/vrpv8/product/cce。其中第一个x为网元ID，第二个x为RU ID。
- 该命令仅提供给U2020/MAE下发获取网元拓扑信息，OM Portal和U2020/MAE上无法执行。

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                             |
|:---------|:-------|:---------------------------------------------------------------------------------------------------------------------------------|
| TASKID   | 任务ID   | 可选必选说明：必选参数 参数含义：该参数用于指定采集任务ID。 取值范围：1-64位字符串。 默认值：无                                                                             |
| TASKTYPE | 任务类型   | 可选必选说明：必选参数 参数含义：该参数用于指定采集任务类型。 取值范围： “1”：采集4G接口静态、IP地址对、TraceRoute信息“2”：采集指定IP地址对TraceRoute信息 默认值：无                             |
| CONTENT  | 采集内容   | 可选必选说明：条件必选参数 参数含义：该参数用于指定采集任务内容。 前提条件：该参数在“任务类型”配置为“1”时生效。 取值范围： “1”：采集静态信息“2”：采集IP地址对信息“8”：采集TraceRoute信息“11”：采集全部上述三种信息 默认值：无 |
| IPVER    | IP地址类型 | 可选必选说明：可选参数 参数含义：该参数用于指定TraceRoute的IP地址类型。 数据来源：本端规划 取值范围： 4 ：IPv46 ：IPv6 默认值：无                                                  |
| SRCIP    | 源IP地址  | 可选必选说明：条件必选参数 参数含义：该参数用于指定源IP地址。 前提条件：该参数在“任务类型”配置为“2”时生效。 取值范围：1-39位字符串。 默认值：无                                                  |
| DSTIP    | 目的IP地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定目的IP地址。 前提条件：该参数在“任务类型”配置为“2”时生效。 取值范围：1-39位字符串。 默认值：无                                                 |

#### 使用实例

1. 指定任务ID为"U2020/MAE"，开始采集网元静态、IP地址对、TRACEROUTE信息：STR TOPOTASK: TASKID="U2020/MAE", TASKTYPE=1, CONTENT=11;
2. 开始采集10.137.144.1到10.137.154.2：STR TOPOTASK: TASKID="U2020/MAE", TASKTYPE=2, IPVER=4, SRCIP="10.137.144.1", DSTIP="10.137.154.2";
3. 开始采集2001:db8::2到2001:db8::/32：STR TOPOTASK: TASKID="U2020/MAE", TASKTYPE=2, IPVER=6, SRCIP="2001:db8::2", DSTIP="2001:db8::/32";
