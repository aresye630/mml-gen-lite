## 命令功能

该命令用于在UDM网元下增加外置AUC（Authentication Center）设备的配置记录，用于UDM和外置AUC之间的HTTP/HTTPS链路配置，以及UDM和外置AUC交互完成相关鉴权功能。

**图1** UDM与外置AUC交互

## 注意事项

- 系统中最多支持增加32个外置AUC设备配置记录。
- 通过该命令配置的两条记录中，IP地址和端口号不能完全相同。
- 执行本命令新增AUC链路时，如果**DSP UDMHTTPLNK**命令在客户端模式下查询的结果中已经存在相同对端IP地址和对端端口号且对端网元类型为非AUC的链路，先确认对端是否存在IP冲突，如果存在，需要先解决IP冲突问题，再执行**RMV HTTPLINK**命令删除该非AUC链路。删除链路后执行本命令新增AUC链路，操作完成后新建链路10分钟左右生效。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                       |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------|
| AUCNAME  | AUC名称  | 可选必选说明：必选参数 参数含义：用于标识一个外置AUC设备的名称。 取值范围：长度不超过64位的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：该参数全局唯一。        |
| IPVER    | IP地址类型 | 可选必选说明：必选参数 参数含义：用于标识外置AUC对外提供的信令IP地址类型。 取值范围：IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。                          |
| IPV4IP   | IPv4地址 | 可选必选说明：条件必选参数 参数含义：用于标识外置AUC设备对外提供的IPv4地址。 取值范围：有效的IPv4地址。 默认值：无。 配置原则：仅当参数“IP地址类型”取值为“IPV4(IPV4)”时，该参数必选。 |
| IPV6IP   | IPv6地址 | 可选必选说明：条件必选参数 参数含义：用于标识外置AUC设备对外提供的IPv6地址。 取值范围：有效的IPv6地址。 默认值：无。 配置原则：仅当参数“IP地址类型”取值为“IPV6(IPV6)”时，该参数必选。 |
| PORT     | 端口号    | 可选必选说明：必选参数 参数含义：用于标识外置AUC设备对外提供的端口号。 取值范围：1～65535。 默认值：无。 配置原则：无。                                         |
| PRIORITY | 优先级    | 可选必选说明：可选参数 参数含义：用于标识一个外置AUC设备的优先级。 取值范围：0～31。 默认值：0。 配置原则：数字越小优先级越高，0为最高优先级。                              |

## 使用实例

增加一个外置AUC设备信息。

```
ADD AUC: AUCNAME="auc", IPVER=IPV6, IPV6IP="FC00:12:12:1926:135:158:55:10", PORT=80, PRIORITY=0;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释          | 原因分析                                                                  | 处理建议                                                      |
|-------:|:--------------|:----------------------------------------------------------------------|:----------------------------------------------------------|
|    503 | 配置数据已存在       | 输入的“AUC名称”下已配置了外置AUC设备信息。                                             | 执行LST AUC命令查询当前已存在的“AUC名称”，重新输入未配置的“AUC名称”后重新执行本命令。       |
|    504 | 当前配置记录数达到上限   | 系统中配置的外置AUC设备配置信息达到上限，无法继续配置。                                         | 执行LST AUC命令查询当前已配置的外置AUC设备信息，删除无效数据后重新执行本命令添加。            |
| 360041 | 参数值不合法        | 界面提示的参数不合法。                                                           | 重新输入提示错误的参数的取值，确保其取值符合要求。                                 |
| 360096 | 已经存在相同的IP和端口号 | 输入的IP和端口号与已存在的记录中的IP和端口号都相同，当前支持配置与已存在记录中仅IP相同或仅端口号相同，或IP和端口号都不相同的数据。 | 使用LST AUC命令查询已配置的外置AUC设备信息，重新输入参数后添加，确保添加的IP地址和端口号没有重复配置。 |
