## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致业务异常，需联系华为技术支持确认后再执行。

该命令用于修改PES流量控制开关、启控条件等。流控功能会根据当前PES服务接收N7、N15、Gx、Rx和N24接口消息的负荷状态和配置的流控参数信息，自动开启流控和解除流控。

跟踪任务流控也使用本命令进行配置，具体配置规则请参见“UPCF产品文档 > 网络运维 > 故障处理 > UPCF故障定位手段 > 常用故障定位手段 > 消息跟踪 > 基于CPU负载控制消息跟踪任务流控”章节。

该命令的使用场景：当出现系统不稳定，如频繁启控解控，操作员可以使用本命令修改PES流控参数以使系统保持健康的运行状态，始终提供最大能力的消息响应服务。

## 注意事项

- **启动流控的条件：**
  - CPU占用率大于等于CPU流量控制启控阈值，并且当前时间PES接收的消息量达到启动流量控制的最小消息量时，会启动PES流控。
  - 消息时延大于等于时延启控阈值时，会启动PES流控。
- **解除流控的条件：**

  CPU占用率低于CPU流量控制解控阈值，消息量低于启动流量控制的最小消息量，并且消息时延小于时延解控阈值时，会解除PES流控。
- 该命令存在系统初始记录，参数的初始设置值如下：
  - “ID”为“1”。
  - “流量控制开关”为“ON”。
  - “CPU启控阈值”为“80”。
  - “CPU解控阈值”为“70”。
  - “启动流量控制的最小消息量”为“600”。
  - “AAR消息折算比例”为“3”。
  - “初始化消息折算比例”为“6”。
  - “更新消息折算比例”为“3”。
  - “终止消息折算比例”为“1”。
  - “USCDB协控开关”为“ON”。
  - “USCDB协控起控比率”为“10”。
  - “USCDB协控解控比率”为“5”。
  - “FE DSG协控起控比率”为“10”。
  - “FE DSG协控解控比率”为“0”。
  - “时延启控阈值”为“50”。
  - “时延解控阈值”为“30”。
  - “VoLTE-APN 初始化消息折算比例”为“6”。
  - “N15接口AM会话初始化消息折算比例”为“4”。
  - “N15接口AM会话更新消息折算比例”为“2”。
  - “N15接口AM会话终止消息折算比例”为“1”。
- 参数“时延解控阈值”取值为“0”表示关闭时延流控功能。
- 该命令的“SMCRAT”/“SMURAT”/“SMDRAT”参数实际表示N7消息及N15的UE消息请求之和的折算比例（具体请参见参数描述），配置错误可能导致实际配置值小于预期值，触发业务流控。执行该命令前，需要与华为技术支持确认后才可以实施。
- 该命令的“AMCRAT”/“AMURAT”/“AMDRAT”参数实际表示N15和N24的AM消息请求之和的折算比例（具体请参见参数描述），配置错误可能导致实际配置值小于预期值，触发业务流控。执行该命令前，需要与华为技术支持确认后才可以实施。
- PES流控丢包的顺序受VRM\_ENABLEVOLTEAPNGXFLOWCTRL软参取值的影响：
  - 当软参“VRM\_ENABLEVOLTEAPNGXFLOWCTRL”设置为“0”时，PES流控丢包的顺序依次为：CCR-I>Npcf\_SMPolicyControl\_Create Request（N7 Create Request消息）>CCR-U>Npcf\_SMPolicyControl\_Update Request（N7 Update Request消息）>AAR-I>CCR-T>Npcf\_SMPolicyControl\_Delete Request（N7 Delete Request消息）。
  - 当软参“VRM\_ENABLEVOLTEAPNGXFLOWCTRL”设置为“1”时，PES流控丢包的顺序依次为：CCR-I（非VoLTE-APN）>Npcf\_SMPolicyControl\_Create Request（非VoLTE-APN的N7 Create Request消息）>CCR-U>Npcf\_SMPolicyControl\_Update Request（N7 Update Request消息）>VoLTE-APN CCR-I>VoLTE-APN Npcf\_SMPolicyControl\_Create Request（VoLTE-APN的N7 Create Request消息）>AAR-I>CCR-T>Npcf\_SMPolicyControl\_Delete Request（N7 Delete Request消息）。

  UPCF按如上顺序通过动态算法进行流控，实际流控过程中可能出现极少量高优先级消息被流控。

## 使用实例

修改PES流控配置。“ID”为“1”，“流量控制开关”为“ON”，“CPU启控阈值”为“80”，“CPU解控阈值”为“70”，“启动流量控制的最小消息量”为“600”，“AAR消息折算比例”为“3”，“初始化消息折算比例”为“6”，“更新消息折算比例”为“3”，“终止消息折算比例”为“1”，“USCDB协控开关”为“ON”，“USCDB协控起控比率”为“10”，“USCDB协控解控比率”为“5”，“FE DSG协控起控比率”为“10”，“FE DSG协控解控比率”为“0”，“VoLTE-APN 初始化消息折算比例”为“6”，“N15接口AM会话初始化消息折算比例”为“4”，“N15接口AM会话更新消息折算比例”为“2”，“N15接口AM会话终止消息折算比例”为“1”。

```
MOD PESFLOWCTRL: ID=1, FLWCTRFLG=ON, CPUFLWSTR=80, CPUFLWEND=70, MINMSGNUM=600, AARRAT=3, SMCRAT=6, SMURAT=3, SMDRAT=1, ASSBECF=ON, RSUFCSTR=10, RSUFCSTP=5, FEDSGFCSTR=10, FEDSGFCSTP=0, VOLTEAPNSMCRAT=6, AMCRAT=4, AMURAT=2, AMDRAT=1;
```
