# 设置升级启动阶段（SET UPGSTAGE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于设置无损升级阶段。在升级开始时设置为START，升级结束后设置为END。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                   |
|:-------|:-------|:---------------------------------------------------------------------------------------|
| STAGE  | 升级阶段   | 可选必选说明：必选参数 参数含义：该参数指定无损升级所处的阶段。 数据来源：本端规划 取值范围： START：无损升级启动。END：无损升级结束。 默认值：无 配置原则：无 |

#### 使用实例

设置升级启动：

```
SET UPGSTAGE: STAGE=START;
```
