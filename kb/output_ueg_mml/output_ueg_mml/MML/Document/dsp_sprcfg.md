# 查询外置SPR配置信息加载状态（DSP SPRCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询外置SPR配置信息加载状态。

- 如果需要查询全部的配置数据加载状态，请不要输入任何参数。
- 如果需要查询指定的配置数据加载状态，请依据参数说明输入查询条件。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                                                                                                                   |
|:-------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| STATUS | 配置数据加载状态 | 可选必选说明：可选参数 参数含义：用于指示系统按照配置数据加载状态来查询；若不输入，则表示所有的配置数据加载状态。 取值范围： 加载成功：表示外置SPR配置文件加载成功。模板格式错误：表示外置SPR配置文件解码失败，请联系华为技术支持。加载中：表示外置SPR配置文件未加载完成，请等待全局数据刷新周期（通过执行LST PCFINSP命令可查询“GLOBALDATAREFRESHCYCLE（全局数据刷新周期）”）后重新执行该命令。 默认值：无。 配置原则：无。 |

## 使用实例

查询外置SPR配置文件。“配置数据加载状态”为“加载成功”。

```
DSP SPRCFG: STATUS=LoadSuccess;
```

```
%%DSP SPRCFG: STATUS=LoadSuccess;%%
RETCODE = 0  操作成功  
操作结果如下: 
-------------     
           实例号 =  123756
    配置文件名称  =  sprviewcfg_TLF.xml         
        局点名称  =  TLF   
            版本  =  21.2.0.20210101  
 外置SPR接口类型  =  LDAP 
配置数据加载状态  =  加载成功 
(结果个数 = 1)  

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1。

| 输出项名称     | 输出项解释                                                                                                                                                                           |
|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 实例号       | 表示PES实例号。 取值范围：长度不超过256的字符串。                                                                                                                                                    |
| 配置文件名称    | 表示加载的外置SPR配置文件名称。 取值范围：长度不超过128的字符串。                                                                                                                                            |
| 局点名称      | 表示加载的外置SPR配置文件的局点名称。 取值范围：长度不超过32的字符串。                                                                                                                                          |
| 版本        | 表示加载的外置SPR配置文件的版本。 取值范围：长度不超过32的字符串。                                                                                                                                            |
| 外置SPR接口类型 | 表示UPCF与外置SPR对接的接口类型。 取值范围：LDAP                                                                                                                                                  |
| 配置数据加载状态  | 表示外置SPR配置文件的加载状态。 取值范围： 加载成功：表示外置SPR配置文件加载成功。模板格式错误：表示外置SPR配置文件解码失败，请联系华为技术支持。加载中：表示外置SPR配置文件未加载完成，请等待全局数据刷新周期（通过执行LST PCFINSP命令可查询“GLOBALDATAREFRESHCYCLE（全局数据刷新周期）”）后重新执行该命令。 |
