# 查询服务接口过滤列表(LST UDMSBIFILTERLST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询服务接口过滤列表：

- 若需要查询所有的服务接口过滤列表，不输入任何参数。

- 若需要查询某个过滤器名称的详细接口过滤列表，请输入“过滤器名称”参数。
- 若需要查询某个服务的详细接口过滤列表，请输入“服务名称”参数。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                                                                                        |
|:-----------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FILTERNAME | 过滤器名称  | 可选必选说明：可选参数 参数含义：用于指示系统按照过滤器名称来查询服务接口过滤列表数据；若不输入，则表示所有的过滤器名称。 取值范围：长度不超过128位的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。                                                                                                                                   |
| SERVERNAME | 服务名称   | 可选必选说明：可选参数 参数含义：用于指示系统按照服务名称来查询服务接口过滤列表数据；若不输入，则表示所有的服务名称。 取值范围： nausf(鉴权服务功能) nausf-auth(AUSF UE鉴权)nausf-sorprotection(AUSF SoR保护)nudm(统一数据管理)nudm-sdm(UDM订阅数据管理)nudm-uecm(UDM UE上下文管理)nudm-ueau(UDM UE鉴权)nudm-ee(UDM事件发布)nudm-pp(UDM参数提供) 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询所有服务接口过滤列表：

   ```
   LST UDMSBIFILTERLST:;
   ```

   ```
   %%LST UDMSBIFILTERLST:;%% 
   RETCODE = 0  操作成功  

   过滤器名称  服务名称      IP版本  IPv4地址        IPv6地址  IPv4掩码位数  IPV6前缀长度  操作类型   

   auth2       鉴权服务功能  IPV4    10.5.26.10      NULL      24            NULL         黑名单
   auth4       鉴权服务功能  IPV4    10.5.26.8       NULL      24            NULL         白名单         
   (结果个数 = 3) 

   ---    END
   ```
2. 查询服务接口过滤列表，“过滤器名称”为“auth4”。

   ```
   LST UDMSBIFILTERLST: FILTERNAME="auth4";
   ```

   ```
   %%LST UDMSBIFILTERLST: FILTERNAME="auth4";%% 
   RETCODE = 0  操作成功

      过滤器名称  =  auth4
        服务名称  =  鉴权服务功能
          IP版本  =  IPV4
        IPv4地址  =  10.5.26.8
        IPv6地址  =  NULL
    IPv4掩码位数  =  24
    IPV6前缀长度  =  NULL
        操作类型  =  白名单
   (结果个数 = 1)

   ---    END
   ```
3. 查询服务接口过滤列表，“服务名称”为“nausf(鉴权服务功能)”。

   ```
   LST UDMSBIFILTERLST: SERVERNAME=nausf;
   ```

   ```
   %%LST UDMSBIFILTERLST: SERVERNAME=nausf;%% 
   RETCODE = 0  操作成功    

      过滤器名称  =  auth4
        服务名称  =  鉴权服务功能
          IP版本  =  IPV4
        IPv4地址  =  10.5.26.8
        IPv6地址  =  NULL
    IPv4掩码位数  =  24
    IPV6前缀长度  =  NULL
        操作类型  =  白名单
   (结果个数 = 1) 

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD UDMSBIFILTERLST**命令的参数说明。
