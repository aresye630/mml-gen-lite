# 修改归属网络Serving PLMN信息(MOD HNOSRVPLMN)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

此命令用于修改Serving PLMN的“运营商名称”描述。

#### 注意事项

- 此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                               |
|:-------|:-------|:-----------------------------------------------------------------------------------|
| NOID   | 运营商标识  | 可选必选说明：必选参数 参数含义：该参数用于指定运营商标识。 数据来源：整网规划 取值范围：0～64，128～254 默认值：无                   |
| MCC    | 移动国家码  | 可选必选说明：必选参数 参数含义：该参数用于指定该运营商的Serving PLMN的移动国家号码。 数据来源：整网规划 取值范围：3位十进制数字 默认值：无     |
| MNC    | 移动网号   | 可选必选说明：必选参数 参数含义：该参数用于指定该运营商的Serving PLMN的移动网号码。 数据来源：整网规划 取值范围：位数为2或3的十进制数字 默认值：无 |
| PLMNN  | 运营商名称  | 可选必选说明：可选参数 参数含义：该参数用于指定运营商名称。 数据来源：整网规划 取值范围：0~50位字符串 默认值：无                       |

#### 使用实例

将Serving PLMN的运营商名称修改为BBB

MOD HNOSRVPLMN: NOID=0, MCC="123", MNC="03", PLMNN="BBB";
