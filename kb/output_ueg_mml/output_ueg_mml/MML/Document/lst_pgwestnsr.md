#### 命令功能

**适用网元：MME**

该命令用于查询SRVCC的紧急会话转移号码和P-GW关系配置表。UNC通过本命令查询出来的PGW IP来找到P-GW对应的“SRVCC的紧急会话转移号码”。与华为MSC设备对接需要配置本命令。

#### 注意事项

1. 如果不输入任何参数，输出所有的记录。
2. 如果输入IPT参数，则输出指定IP地址类型的记录。
3. 如果输入了指定的IP地址和IP地址掩码，输出指定的记录。
4. IP地址和IP地址掩码必须成对输入，不允许只输入IP地址而不输入掩码。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称         | 参数说明                                                                                                                                           |
|:--------|:-------------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| IPT     | PGW的IP地址类型   | 可选必选说明：可选参数 参数含义：该参数用于指定P-GW的IP地址类型。 数据来源：运营商规划 取值范围：IPV4(IPV4)IPV6(IPV6) 默认值：无                                                                |
| PGWIPV4 | PGW的IPV4地址   | 可选必选说明：可选参数 参数含义：该参数用于设置P-GW的IPv4地址。 前提条件：该参数在“PGW的IP地址类型”配置为“IPV4(IPV4)”后生效。 数据来源：运营商规划 取值范围：0.0.0.0～255.255.255.255 默认值：无                    |
| IPV4MSK | PGW的IPV4地址掩码 | 可选必选说明：可选参数 参数含义：该参数用于设置P-GW的IPv4类型的GTPC地址掩码。 前提条件：该参数在“PGW的IP地址类型”配置为“IPV4(IPV4)”后生效。 数据来源：运营商规划 取值范围： 0.0.0.0～255.255.255.255 默认值：无          |
| PGWIPV6 | PGW的IPV6地址   | 可选必选说明：可选参数 参数含义：该参数用于设置P-GW的IPv6地址。 前提条件：该参数在“PGW的IP地址类型”配置为“IPV6(IPV6)”后生效。 数据来源：运营商规划 取值范围：::~FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 |
| IPV6MSK | IPV6地址前缀长度   | 可选必选说明：可选参数 参数含义：该参数用于设置P-GW的IPv6地址的前缀的长度。 前提条件：该参数在“PGW的IP地址类型”配置为“IPV6(IPV6)”后生效。 数据来源：运营商规划 取值范围：1～128 默认值：无                                |

#### 使用实例

1. 不输入查询条件，查询全部SRVCC的紧急会话转移号码和P-GW关系配置表：

   LST PGWESTNSR:;

   ```
   %%LST PGWESTNSR:;%%
   RETCODE = 0  操作成功。

   输出结果如下
   ------------
   PGW的IP地址类型    PGW的IPV4地址    PGW的IPV4地址掩码    PGW的IPV6地址                  IPV6地址前缀长度    SRVCC的紧急会话转移号码

   IPV4               192.168.111.0    255.255.255.255      2001:db8:10:19:44:55:10:12     0                   12345678               
   IPV4               192.168.111.1    255.255.255.255      2001:db8:10:19:44:55:10:13     0                   12345678               
   (结果个数 = 2)
   ---    END
   ```
2. 查询“PGW的IP地址类型”为“IPV4”，“PGWIPV4”为“192.168.111.111”，“IPV4MSK”为“255.255.0.0”的E-STN-SR和P-GW关系配置表。

   LST PGWESTNSR: IPT=IPV4, PGWIPV4="192.168.111.0", IPV4MSK="255.255.255.255";

   ```
   %%LST PGWESTNSR: IPT=IPV4, PGWIPV4="192.168.111.0", IPV4MSK="255.255.255.255";%%
   RETCODE = 0  操作成功。

   输出结果如下
   ------------
           PGW的IP地址类型  =  IPV4
             PGW的IPV4地址  =  192.168.111.0
         PGW的IPV4地址掩码  =  255.255.255.255
             PGW的IPV6地址  =  2001:db8:10:19:44:55:10:12
          IPV6地址前缀长度  =  0
   SRVCC的紧急会话转移号码  =  12345678
   (结果个数 = 1)
   ---    END
   ```
