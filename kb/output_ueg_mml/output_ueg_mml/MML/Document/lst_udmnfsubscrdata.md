# 查询网元订阅信息(LST UDMNFSUBSCRDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询订阅数据。

- 若需要查询某条订阅数据的详细信息，请输入“订阅名称”或其他参数或这些参数的组合；

- 若需要查询所有订阅数据的信息，不输入任何参数。

## 注意事项

无。

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                  |
|:-------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBSCRNAME   | 订阅名称   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个“订阅名称”来查询订阅数据；若不输入，则表示所有的“订阅名称”。 取值范围：长度不超过32的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。                                                                                                                                                                                               |
| SUBSCRID     | 订阅标识   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个“订阅标识”来查询订阅数据；若不输入，则表示所有的“订阅标识”。 取值范围：长度不超过32的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                        |
| SUBSCRCOND   | 订阅条件   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个“订阅条件”来查询订阅数据；若不输入，则表示所有的“订阅条件”。 取值范围：NFINSTANCEIDCOND(网元标识)：订阅目标网元的实例标识。NFTYPECOND(网元类型)：订阅目标网元的网元类型。SERVICENAMECOND(服务名称)：订阅目标网元的服务名称。AMFCOND(AMF标识)：订阅目标AMF的标识。GUAMILISTCOND(AMF唯一标识集)：订阅目标AMF的唯一标识集。NETWORKSLICECOND(网络集合)：订阅目标网元的网络切片集合。NFGROUPCOND(网元组)：订阅目标网元的组标识。 默认值：无。 配置原则：无。 |
| NOTIFEVENTS  | 通知事件类型 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个“通知事件类型”来查询订阅数据；若不输入，则表示所有的“通知事件类型”。 取值范围：NF_REGISTERED(网元注册通知)NF_DEREGISTERED(网元去注册通知)NF_PROFILE_CHANGED(网元更新通知)NF_REGED_DEREGED(网元注册和去注册通知)NF_REGED_CHANGED(网元注册和更新通知)NF_DEREGED_CHANGED(网元去注册和更新通知)ALL(全部通知) 默认值：无。 配置原则：无。                                                           |
| NFTYPE       | 网元类型   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个“网元类型”来查询订阅数据；若不输入，则表示所有的“网元类型”。 取值范围：UDM(统一数据管理)AUSF(鉴权服务功能) 默认值：无。 配置原则：无。                                                                                                                                                                                                             |
| NFFQDN       | 网元全量域名 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个“网元全量域名”来查询订阅数据；若不输入，则表示所有的“网元全量域名”。 取值范围：长度不超过255的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                   |
| PLMNID       | PLMN标识 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个“PLMN标识”来查询订阅数据；若不输入，则表示所有的“PLMN标识”。 取值范围：格式：JSON。举例：{"mcc":"460","mnc":"08"} 默认值：无。 配置原则：无。                                                                                                                                                                                             |
| SUBSCRSTATUS | 订阅状态   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个“订阅状态”来查询订阅数据；若不输入，则表示所有的“订阅状态”。 取值范围：SUBSCRIBED(订阅)UNSUBSCRIBED(去订阅) 默认值：无。 配置原则：无。                                                                                                                                                                                                     |
