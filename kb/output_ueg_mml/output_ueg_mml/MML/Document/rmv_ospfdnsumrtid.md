# 删除特定路由器禁止检查Summary-LSA的DN比特位配置（RMV OSPFDNSUMRTID）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于恢复特定路由器对Summary LSA的DN位检查的默认配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                   |
|:---------|:--------|:-----------------------------------------------------------------------|
| PROCID   | OSPF进程号 | 可选必选说明：必选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 |
| ROUTERID | 路由器标识   | 可选必选说明：必选参数 参数含义：路由器标识。 数据来源：全网规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无         |

#### 使用实例

恢复10.2.2.2路由器对Summary LSA的DN位检查的默认配置：

```
RMV OSPFDNSUMRTID:PROCID=1,ROUTERID="10.2.2.2";
```
