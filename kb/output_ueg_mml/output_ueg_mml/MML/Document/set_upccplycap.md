# 设置UPCC全局数据容量（SET UPCCPLYCAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响混合组网下UPCC网元的业务处理，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于设置UPCF支持配置的UPCC全局数据对象的最大记录数，修改后立即生效。

该命令的使用场景：支持对UPCF中允许配置UPCC全局数据的容量做限制。

## 注意事项

- 混合组网时，即PGW软参“MixedNetworkSwitch”设置为“1”时，系统会先比较**LST GLBMAXNUM**命令和**LST UPCCPLYCAP**命令的查询返回结果的相同配置项的值，使用较小值作为UPCF允许配置的全局数据对象的最大记录数。
- 混合组网时，UPCF通过**SET UPCCPLYCAP**设置的全局数据的最大记录数不能超过UPCC的版本能力，否则会导致UPCC全局数据加载异常，影响业务。
- 混合组网时，若软参“VRM\_UPCCPLYCAPSWITCH”取值为“1”，则本命令配置不生效。

## 使用实例

设置规则的容量，“全局数据名称”为“RULE”，“全局数据容量”为“30000”。

```
SET UPCCPLYCAP: NAME=RULE, CAPACITY=30000;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释           | 原因分析                                        | 处理建议                               |
|------:|:----------------|:--------------------------------------------|:-----------------------------------|
| 58199 | CAPACITY参数取值非法。 | “全局数据名称”为UPCC全局数据对象时，其对应的“全局数据容量”参数取值不符合要求。 | 保证UPCC全局数据对象的对应“全局数据容量”参数取值在要求范围内。 |
