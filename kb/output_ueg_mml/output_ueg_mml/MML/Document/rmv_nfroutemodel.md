# 删除网元路由模式（RMV NFROUTEMODEL）

## 命令功能

**须知** 

本命令属于高危命令，执行不当会导致业务通信路由方式变更，造成业务呼损或系统崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除UDM和NRF之间SCP对接的网元路由模式。

## 注意事项

- 如果操作员删除某条网元路由模式，会导致整体业务通信方式变更，请操作员在执行该操作之前仔细确认任务的可行性。
- UDM在系统初始化的时候已经预置如下几条默认数据记录，操作员可以通过**LST NFROUTEMODEL**命令查询得出。预置的默认数据记录不允许删除。

  ```
  ADD NFROUTEMODEL: RTNAME="Default_Global", NFTYPE=DEFAULT, MODEL=MODEL-B, SWITCH=ENABLE;
  ADD NFROUTEMODEL: RTNAME="Default_AMF_PLMN", NFTYPE=AMF, DESTTYPE=PLMN, PLMN="Default", MODEL=MODEL-B, SWITCH=DISABLE;
  ADD NFROUTEMODEL: RTNAME="Default_SMF_PLMN", NFTYPE=SMF, DESTTYPE=PLMN, PLMN="Default", MODEL=MODEL-B, SWITCH=DISABLE;
  ```

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                            |
|:-------|:-------|:------------------------------------------------------------------------------------------------|
| RTNAME | 路由名称   | 可选必选说明：必选参数 参数含义：用于指定需要删除哪一条网元路由模式，操作员可使用LST NFROUTEMODEL查询获得。 取值范围：长度为1~128的字符串。 默认值：无 配置原则：无。 |

## 使用实例

删除网元路由模式，“路由名称”为“4604567890001”：

```
RMV NFROUTEMODEL: RTNAME="4604567890001", CONFIRM=Y
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释               | 原因分析            | 处理建议            |
|-------:|:-------------------|:----------------|:----------------|
| 360093 | 默认配置数据的添加、删除、修改受限。 | 预置的默认数据记录不允许删除。 | 不可以删除预置的默认数据记录。 |
