# 查询电子保单信息（LST DIGIW）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明
- 参考信息

## 命令功能

本命令用于查询指定网元的电子保单信息，包含首次上电时间、服务起始时间以及服务年限。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                     |
|:-------|:-------|:-----------------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：用于指示系统需要按照哪个网元ID来查询电子保单信息。 取值范围：0~65535。 默认值：无。 配置原则：可以使用LST ME命令查询获得。 |

## 使用实例

查询电子保单信息：

```
%%LST DIGIW: MEID=55;%%
RETCODE = 0  操作成功
 
操作结果如下
------------
  首次上电时间  =  2012-01-17
  服务起始时间  =  2021-06-10
服务年限（月）  =  120
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息，输出项如表1所示。

该命令执行异常，会返回对应的错误码。常见错误码列表如

表2 错误码列表

所示。

| 输出项名称   | 输出项解释                                                   |
|:--------|:--------------------------------------------------------|
| 首次上电时间  | 产品首次激活的license文件中的文件创建时间。                               |
| 服务起始时间  | 客户界面合同约定的服务起始时间，根据合同不同可能是 “某台设备、单板/部件”的POD /PAC /FAC时间。 |
| 服务年限（月） | 客户界面合同约定的服务时长。                                          |

|   错误码 | 错误码解释         | 原因分析                       | 处理建议      |
|------:|:--------------|:---------------------------|:----------|
|   500 | 系统内部错误，请联系管理员 | 执行过程中可能存在网络故障或者服务不可用等异常因素。 | 等待几分钟后重试。 |
