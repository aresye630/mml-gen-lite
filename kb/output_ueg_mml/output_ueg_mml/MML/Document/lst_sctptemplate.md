# 查询SCTP模板（LST SCTPTEMPLATE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-C、SMF**

此命令用于查询SCTP模板。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                              |
|:--------------|:---------|:----------------------------------------------------------------------------------|
| SCTPTEMPLNAME | SCTP模板名称 | 可选必选说明：可选参数 参数含义：该参数用于指定SCTP模板的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无 |

#### 使用实例

查询SCTP模板信息：

```
LST SCTPTEMPLATE: SCTPTEMPLNAME="sctp_tp1";
```

