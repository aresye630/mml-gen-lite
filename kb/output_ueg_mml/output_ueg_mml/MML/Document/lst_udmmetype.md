# 查询配置库中的UDM网元类型（LST UDMMETYPE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询配置库中的UDM网元类型。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询当前配置库中的UDM网元类型：

```
LST UDMMETYPE:;
```

```
%%LST UDMMETYPE:;%%
RETCODE = 0  操作成功

操作结果如下:
-------------
网元类型  =  UDM
(结果个数 = 1)

---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息和相关参数，“网元类型”参数含义请参见**SET UDMMETYPE**命令的参数说明。

命令执行异常，会返回提示没有对应的查询结果。
