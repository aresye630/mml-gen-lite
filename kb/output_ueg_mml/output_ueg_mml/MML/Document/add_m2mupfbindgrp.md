# 增加UPF和M2M关联的UPF组的绑定关系（ADD M2MUPFBINDGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于添加UPF和M2M关联的UPF组的绑定关系。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入3000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                                                   |
|:-----------|:--------|:-----------------------------------------------------------------------------------------------------------------------|
| UPFGRPNAME | UPF组名称  | 可选必选说明：必选参数  参数含义：该参数用于指定UPF组的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。不区分大小写。  默认值：无  配置原则：  该参数使用ADD M2MUPGROUP命令配置生成。 |
| UPFID      | UPF实例标识 | 可选必选说明：必选参数  参数含义：该参数用于指定UPF实例名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。不区分大小写。  默认值：无  配置原则：  该参数使用ADD UPNODE命令配置生成。    |

## 使用实例

添加UPF和UPF组的绑定关系，UPF组为upfgrp1，UPF为upf\_instance\_1：

```
ADD M2MUPFBINDGRP: UPFGRPNAME="upfgrp1", UPFID="upf_instance_1";
```
