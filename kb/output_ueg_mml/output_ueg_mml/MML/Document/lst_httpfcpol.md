# 查询手工流控策略（LST HTTPFCPOL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询已配置的手工流控策略：

- 若需要查询所有手工流控策略，请不要输入任何参数。
- 若需要查询某一个手工流控策略，请输入“策略名称”参数或其他参数组合。

## 注意事项

该命令不支持GBA（Generic Bootstrapping Architecture）场景。

## 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                |
|:--------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| POFCNM  | 策略名称     | 可选必选说明：可选参数。 参数含义：用于指示系统按照哪个策略名称来查询手工流控策略；若不输入，则表示查询所有的策略名称。 取值范围：长度不超过32位的字符串，只允许输入：0～9，a～z，A～Z，“-”和“_”。 默认值：无 配置原则：无                                                                                                                                                                                                                              |
| FCMODE  | 流控开关     | 可选必选说明：可选参数。 参数含义：用于指示系统按照手工流控开关是否激活查询流控信息。 取值范围： ACTIVE(激活)DEACTIVE(去激活) 默认值：无 配置原则：无                                                                                                                                                                                                                                                              |
| FCTYPE  | 流控类型     | 可选必选说明：可选参数。 参数含义：用于指示系统按照哪种流控类型查询手工流控信息。 取值范围： IPFC(IP手工流控)：表示按照对端IP对HLB模块上的消息进行手工流控。GLFC(全局手工流控)：表示对HLB模块上的所有请求消息进行手工流控。UDMFC(UDM业务手工流控)：表示当SET UDMMETYPE命令“网元类型”参数为“UDM(UDM)”时，对UdmSubService和AuthService服务上所有请求消息进行手工流控。IWFFC(IWF业务手工流控)：表示当SET UDMMETYPE命令“网元类型”参数为“UDM-IWF(UDM-IWF)”时，对UdmSubService和AuthService服务上所有请求消息进行手工流控。 默认值：无 配置原则：无 |
| IPVER   | IP地址类型   | 可选必选说明：条件必选参数 参数含义：用于指示系统按照哪种对端IP地址类型查询手工流控信息。 取值范围： IPV4(IPV4地址)：IPv4地址IPV6(IPV6地址)：IPv6地址 默认值：无 配置原则：当“流控类型”参数取值为“IPFC(IP手工流控)”时该参数生效。                                                                                                                                                                                                            |
| PEIPV4  | 对端IPV4地址 | 可选必选说明：条件必选参数 参数含义：用于指示系统按照哪个对端IPv4地址查询手工流控信息。 取值范围：有效的IPv4地址 默认值：无 配置原则：当“IP地址类型”参数取值为“IPV4(IPV4地址)”时该参数生效。                                                                                                                                                                                                                                        |
| PEIPV6  | 对端IPV6地址 | 可选必选说明：条件必选参数 参数含义：用于指示系统按照哪个对端IPv6地址查询手工流控信息。 取值范围：有效的IPv6地址 默认值：无 配置原则：当“IP地址类型”参数取值为“IPV6(IPV6地址)”时该参数生效。                                                                                                                                                                                                                                        |
| FCTPLID | 流控模板标识   | 可选必选说明：可选参数。 参数含义：用于指示系统按照哪个流控模板号查询手工流控信息。 取值范围：长度不超过32位的字符串，只允许输入：0～9，a～z，A～Z，“-”和“_”。 默认值：无 配置原则：无                                                                                                                                                                                                                                                |

## 使用实例

1. 查询所有手工流控功能参数信息：

   ```
   LST HTTPFCPOL:;
   ```

   ```
   %%LST HTTPFCPOL:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   策略名称        流控开关  流控类型         IP地址类型  对端IPV4地址  对端IPV6地址  流控速率  突发请求数  流控模板标识  

   DefaultPol-IWF  激活      IWF业务手工流控  NULL        NULL          NULL          7800      1000        DefaultFCTPL  
   DefaultPol-UDM  激活      UDM业务手工流控  NULL        NULL          NULL          6500      1000        DefaultFCTPL  
   (结果个数 = 2)

   ---    END
   ```
2. 查询“策略名称”为“DefaultPol-UDM”的手工流控功能参数信息：

   ```
   LST HTTPFCPOL: POFCNM="DefaultPol-UDM";
   ```

   ```
   %%LST HTTPFCPOL: POFCNM="DefaultPol-UDM";%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
       策略名称  =  DefaultPol-UDM
       流控开关  =  激活
       流控类型  =  UDM业务手工流控
     IP地址类型  =  NULL
   对端IPV4地址  =  NULL
   对端IPV6地址  =  NULL
       流控速率  =  6500
     突发请求数  =  1000
   流控模板标识  =  DefaultFCTPL
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD HTTPFCPOL**命令的参数说明。
