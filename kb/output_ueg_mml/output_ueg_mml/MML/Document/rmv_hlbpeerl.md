# 删除HLB对端链路(RMV HLBPEERL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于在配置数据库中删除一条HLB与对端实体的链路数据记录。

该命令在特定场景下才能使用，如需使用该命令删除HLB对端链路请联系华为技术支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                               |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------|
| PEERID | 对端标识   | 可选必选说明：必选参数 参数含义：标识一条HLB对端链路数据记录的关键字段之一，用于指定需要删除哪一条HLB对端链路数据记录，操作员可以使用LST HLBPEERL命令查询获得。 取值范围：0～63 默认值：无。 配置原则：无。 |
| LINKID | 链路标识   | 可选必选说明：必选参数 参数含义：标识一条HLB对端链路数据记录的关键字段之一，用于指定需要删除哪一条HLB对端链路数据记录，操作员可以使用LST HLBPEERL命令查询获得。 取值范围：0 默认值：无。 配置原则：无。    |

## 使用实例

删除一条HLB和对端设备的链路。“对端标识”为“2”，“链路标识”为“0”。

```
RMV HLBPEERL: PEERID=2, LINKID=0;
```
