# 查询License资源数目和使用率(DSP UDMLICRATE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询当前系统中5G FE License使用率相关信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

**说明** 

不同网元形态下的License资源查询结果显示不同，此处仅供示例。各个License资源项具体功能请参考“**License控制项说明**”页面。

- UDM网元形态的裸机场景下，查询当前系统中5G FE License使用率相关信息，执行命令如下：

  ```
  DSP UDMLICRATE:;
  ```

  如执行成功，显示如下信息：

  ```
  %%DSP UDMLICRATE:;%%
  RETCODE = 0  操作成功

  操作结果如下:
  -------------
  License ID   License控制项                     类型    授权值      实际使用值  使用百分比(%)  剩余百分比(%)  
  LKQ7UDMFE02  5G AUSF鉴权                       资源项  1800000     0           0              100            
  LKQ7UDMFE03  单次AUSF TPS高峰最少连续过载天数  资源项  1           0           0              100            
  LKQ7UDMFE04  每年内最大AUSF TPS高峰次数        资源项  10          0           0              100                       

  (结果个数 = 3)

  ---    END
  ```

- UDM网元形态虚机场景下，查询当前系统中5G FE License使用率相关信息，执行命令如下：

## 输出结果说明

| 输出项名称      | 输出项解释                                                                                  |
|:-----------|:---------------------------------------------------------------------------------------|
| License ID | 用于返回License控制项的名称。                                                                     |
| License控制项 | 用于返回License控制项的描述信息。                                                                   |
| 类型         | 用于返回License控制项类型。 “资源型”：按照用户数进行控制。 “功能型”：按照业务功能进行控制。 UDM所有的License控制项都为“资源型”。          |
| 授权值        | 用于返回当前License控制项支持的最大资源信息数。                                                            |
| 实际使用值      | 用于返回当前License控制项实际使用值。                                                                 |
| 使用百分比(%)   | 用于返回当前License控制项已使用率，其取值为“实际使用值”和“授权值”的比值。                                             |
| 剩余百分比(%)   | 用于返回当前License控制项可使用率。 如果“实际使用值”小于或等于“授权值”，取值为“100”与“使用百分比”之差。 如果“实际使用值”大于“授权值”，取值为“0”。 |
