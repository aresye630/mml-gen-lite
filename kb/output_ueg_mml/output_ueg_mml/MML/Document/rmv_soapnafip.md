# 删除SOAP客户端IP地址(RMV SOAPNAFIP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在系统中删除一条SOAP客户端IP地址记录。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

除了在开局初始配置时，其他情况下删除SOAP客户端的IP地址信息可能会导致系统产生致命错误，请慎重操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                          |
|:-------|:-------|:------------------------------------------------------------------------------|
| ID     | ID     | 标识SOAP客户端IP地址的关键字段，用于指定需要删除的一条具体IP地址信息，该参数可以使用LST SOAPNAFIP命令查询获得。 取值范围：0-255 |

## 使用实例

删除额外增加的一个SOAP客户端IP地址。

```
RMV SOAPNAFIP: ID=1;
```
