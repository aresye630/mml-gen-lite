# 查询对端HTTP实体(LST HTTPPE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询对端HTTP实体信息：

- 若需要查询全部对端HTTP实体信息，请不要输入任何参数。
- 若需要查询某个对端HTTP实体信息，请输入“对端HTTP实体标识”和“对端域名”参数的组合。

  **说明** 

  该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                                                                       |
|:-------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| PEID   | 对端HTTP实体标识 | 用于指示系统需要按照哪个对端HTTP实体标识来查询对端HTTP实体信息数据记录；若不输入，表示查询所有的对端HTTP实体信息。 取值范围：0～255。 默认值：无。 注意：该参数为可选参数。                                            |
| HOST   | 对端域名       | 用于指示系统需要按照哪个HTTP对端实体的FQDN来查询对端HTTP实体信息数据记录。对端域名与对端HTTP实体一一对应。 需要指出的是，该参数不区分大小写，在执行本命令查询出的报文中为全小写形式。 取值范围：长度不超过127的字符串。 默认值：无。 注意：该参数为可选参数。 |

## 使用实例

1. 查询对端HTTP实体信息，不携带参数：

   执行命令如下：

   ```
   LST HTTPPE:;
   ```

   返回结果如下：

   ```
   %%LST HTTPPE:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
     对端HTTP实体标识  对端域名  对端HTTP实体名  链路集选择模式

    1                 !@#!      12               轮询法
    2                 HUAWEI    SJDFIS           主备方式       
   (结果个数 = 2)

   ---    END
   ```
2. 查询对端HTTP实体信息，携带以下参数：

   - “对端HTTP实体标识”为“2”
   - “对端域名”为“HUAWEI”

   执行命令如下：

   ```
   LST HTTPPE: PEID=2, HOST="HUAWEI";
   ```

   返回结果如下：

   ```
   %%LST HTTPPE: PEID=2, HOST="HUAWEI";%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
   对端HTTP实体标识  =  2
           对端域名  =  HUAWEI
     对端HTTP实体名  =  SJDFIS
     链路集选择模式  =  主备方式
   (结果个数 = 1)

   ---    END
   ```
