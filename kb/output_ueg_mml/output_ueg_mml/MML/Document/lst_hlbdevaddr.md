# 查询HLB设备地址(LST HLBDEVADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于在配置数据库中查询HLB设备地址信息。

- 如果需要查询全部设备地址信息，请不要输入任何参数。
- 如果需要查询某条设备地址信息，请依据参数说明输入查询条件。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                |
|:------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DEVAID      | 设备地址标识  | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个设备地址标识来查询HLB设备地址信息；若不输入，则表示所有的设备地址标识。 取值范围：0～31 默认值：无。 配置原则：无。                                                                                         |
| VPNNAME     | VPN名称   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个VPN名称来查询HLB设备地址信息；若不输入，则表示所有的VPN名称。 取值范围：长度不超过32位的字符串 默认值：无。 配置原则：无。                                                                                   |
| IPVER       | IP版本    | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个IP版本来查询HLB设备地址信息；若不输入，则表示所有的IP版本。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。                                                                            |
| IP          | IPV4地址  | 可选必选说明：可选参数 参数含义：当“IP版本”选择“IPV4(IPV4)”时，可设置该参数。用于指示系统需要按照哪个IPV4地址来查询HLB设备地址信息；若不输入，则表示所有的IPV4地址。 取值范围：IPv4地址 默认值：无。 配置原则：无。                                                         |
| IPV6        | IPV6地址  | 可选必选说明：可选参数 参数含义：当“IP版本”选择“IPV6(IPV6)”时，可设置该参数。用于指示系统需要按照哪个IPV6地址来查询HLB设备地址信息；若不输入，则表示所有的IPV6地址。 取值范围：IPv6地址 默认值：无。 配置原则：无。                                                         |
| HTTPSFUNC   | HTTPS功能 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个HTTPS功能来查询HLB设备地址信息；若不输入，则表示所有的HTTPS功能。 取值范围： ON(打开)：表示启用TLS证书。OFF(关闭)：表示不启用TLS证书。 默认值：无。 配置原则：无。                                                      |
| CERTSCENE   | 证书应用场景  | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个证书应用场景来查询HLB设备地址信息；若不输入，则表示所有的证书应用场景。 取值范围： UPCF_HLB_Lcert(UPCF_HLB_Lcert) 默认值：无。 配置原则：无。                                                              |
| TLSCFGID    | TLS配置ID | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个TLS配置ID来查询HLB设备地址信息；若不输入，则表示所有的TLS配置ID。 取值范围：1～128 默认值：无。 配置原则：无。                                                                                      |
| DESCRIPTION | 描述      | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个描述来查询HLB设备地址信息；若不输入，则表示所有的描述。 取值范围：长度不超过32位的字符串 默认值：无。 配置原则：无。                                                                                         |
| DSCP        | DSCP优先级 | 可选必选说明：可选参数 参数含义：用于指定修改后的DSCP优先级。 取值范围：0～63，255 默认值：255。 配置原则：无。  说明： DSCP优先级有64级，为0～63，级别为63时，优先级最高。255表示不设置DSCP。                                                                  |
| TOEDGE      | 对接边缘    | 可选必选说明：可选参数 参数含义：用于标识是否对接边缘网元。 取值范围： YES(是)：表示该HLBDEVADDR用于对接边缘网元。NO(否)：表示该HLBDEVADDR用于对接大网网元。 默认值：无。 配置原则：无。  说明： 参数取值为“YES”的记录仅应用于SMF/AMF/NEF对端。若多条记录的“VPNNAME”值相同，则本参数的取值需要保持一致。 |

## 使用实例

1. 查询所有的HLB设备地址的配置信息。

   ```
   LST HLBDEVADDR:;
   ```

   ```
   %%LST HLBDEVADDR:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   设备地址标识   VPN名称  IP版本  IPV4地址       IPV6地址  HTTPS功能  证书应用场景    TLS配置ID  描述      DSCP优先级  对接边缘          
   1              HLB_VPN  IPV4    10.194.4.130   NULL      OFF        NULL            NULL       NULL      255         NO
   2              VPN1     IPV4    10.168.0.130   NULL      ON         UPCF_HLB_Lcert  1          HLB_IPV4  255         NO
   (结果个数 = 2)

   ---    END
   ```
2. 查询一条HLB设备地址的配置信息。“设备地址标识”为“2”。

   ```
   LST HLBDEVADDR: DEVAID=2;
   ```

   ```
   %%LST HLBDEVADDR: DEVAID=2;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   设备地址标识  =  2
        VPN名称  =  VPN1
         IP版本  =  IPV4
       IPV4地址  =  10.168.0.130
       IPV6地址  =  NULL
      HTTPS功能  =  ON
   证书应用场景  =  UPCF_HLB_Lcert
      TLS配置ID  =  1
           描述  =  HLB_IPV4
     DSCP优先级  =  255
       对接边缘  =  NO
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD HLBDEVADDR**命令的参数说明。
