## 命令功能

**须知** 

该命令属于高危命令，该操作可能产生短时间内进程CPU使用率较高，导致业务受损。建议避免在高峰业务场景下执行该命令。

该命令主要用于维护和故障场景下获取CCDB的关键资源信息与内部辅助定位信息等，便于故障定位。

不同类型的服务支持获取不同类型的服务实例信息，具体可获取的信息包含如下：

- 支持获取CUS的Channel备份文件信息。
- 支持获取CUS当前所有服务的心跳内存信息。
- 支持获取CUS当前FE加载的应用插件配置信息。
- 支持获取CUS/DUS本地日志信息（包含运行日志，初始化日志，内核日志）。
- 支持获取DUS的GMDB内核关键资源信息。

## 注意事项

- 该命令在执行过程中可能会导致系统短时间内的CPU升高，引起业务呼损。建议避免在高峰业务场景下执行该命令。
- 该命令暂不支持一键式用户信息收集能力。
- 执行命令后，经过收集系统信息、写到本地磁盘、上传到指定路径。路径为“/opt/csp/UDRDxs/ccdb\_srv\_info\_workdir”,其中UDRDxs为对应的服务名，文件名统一为“NID\_LID\_MID\_TYPE\_TIMESTAMP.tar.gz”。
- 文件上传后，可在OM Portal界面的“系统 > 文件传输 > 应用文件 > CCDBNODEINFO/APP<APPID名称>/NID\_LID\_MID\_TYPE\_TIMESTAMP”路径下载获取。
- 系统信息文件上传后，本地生成的文件需要删除。
- 因为涉及收集文件，命令执行时间可能较长（10~60秒），影响该命令的后续再执行，维护人员需谨慎操作。
- 日志数据在传出运营商网络前，需要采用匿名化工具对日志数据进行匿名化处理。日志匿名化处理工具可以在https://support.huawei.com/上获取。在“产品软件”页签中浏览或搜索“Log Anonymity Tool”，获取最新版本的工具。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                      |
|:-------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TYPE   | 服务实例信息类型 | 可选必选说明：必选参数。 参数含义：用于标识获取的服务实例信息的类型。 取值范围： HEARTBEAT（心跳信息） LOCALLOG（本地日志信息）GMDB（内核资源信息）CHANNEL（CHANNEL信息）FEPLUG（FE插件信息）  说明： “FEPLUG（FE插件信息）”选项在当前版本暂不支持。 默认值：无。 配置原则：无。                                                                                                                                                                   |
| INSTID | 实例标识     | 可选必选说明：该参数为条件必选参数。 对于本地日志信息和内核资源信息，“实例标识”为必选参数。对于心跳信息、Channel信息和FE插件信息，“实例标识”为可选参数。 参数含义：用于标识需要导出的资源信息的服务实例标识。服务实例信息可以通过DSP DUSSTAT和DSP CUSSTAT命令获取。 取值范围：长度不超过20的字符串，用10进制或者16进制的字符串（16进制字符串必须以0x或者0X开头）表示。 默认值：无。 配置原则：无。  说明： 对于心跳信息、Channel信息和FE插件信息，如果指定“实例标识”则需要指定CUS的实例标识。对于内核资源信息需要指定DUS的实例标识。对于本地日志信息既可以指定CUS的实例标识也可以指定DUS的实例标识。 |

## 使用实例

1. 获取心跳信息。

   ```
   GET CCDBSRVINFO: TYPE=HEARTBEAT;
   ```
2. 获取“实例标识”为“0x1000000012000002”的本地日志信息。

   ```
   GET CCDBSRVINFO: TYPE=LOCALLOG, INSTID="0x1000000012000002";
   ```
3. 获取“实例标识”为“0x1000000012000002”的内核资源信息。

   ```
   GET CCDBSRVINFO: TYPE=GMDB, INSTID="0x1000000012000002";
   ```

| 67952 | 指定的实例ID错误  | 当前输入的“实例标识”不支持收集此内容。 | 修改实例标识后重新执行该命令。实例标识可以通过DSP DUSSTAT和DSP CUSSTAT命令获取。                                                                                                                                                                                       |
