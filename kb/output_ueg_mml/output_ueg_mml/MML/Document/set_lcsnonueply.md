# LCS UE无关的策略参数（SET LCSNONUEPLY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于设置LCS UE无关的策略参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 执行SET LCSNONUEPLY命令时，需要至少输入一个参数；否则，命令执行失败。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | N2SUBINCLGNBSW   |   N2SUBINTTIMES |   N2SUBINTERVAL |   N2SUBALARMTHD |   TRPUPDINTERVAL |   TRPALARMTHD |   NOUEDELGNBTIME |
|:-------|:-----------------|----------------:|----------------:|----------------:|-----------------:|--------------:|-----------------:|
| 初始值    | ENABLE           |             100 |               5 |               3 |               24 |             3 |                0 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称                | 参数说明                                                                                                                                           |
|:---------------|:--------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| N2SUBINCLGNBSW | N2信息订阅携带gNB参数开关     | 可选必选说明：可选参数 参数含义：该参数用于配置UE无关的N2信息订阅消息中是否携带gNodeB参数。 数据来源：全网规划 取值范围： DISABLE：开关去使能。ENABLE：开关使能。 默认值：无 配置原则：无                                    |
| N2SUBINTTIMES  | 非UE N2信息订阅间隔次数      | 可选必选说明：可选参数 参数含义：该参数用于设置多少次定位触发一次UE无关的N2消息订阅流程，配置为0时不需要基于定位次数触发UE无关的N2消息订阅流程。 数据来源：本端规划 取值范围：整数类型，取值范围为0～1000，单位是次。 默认值：无 配置原则：无               |
| N2SUBINTERVAL  | UE无关的N2信息订阅时间间隔（分钟） | 可选必选说明：可选参数 参数含义：该参数用于设置定时发送UE无关的N2订阅消息的时间间隔。配置为0时每次定位都会发送UE无关的N2订阅消息。 数据来源：本端规划 取值范围：整数类型，取值范围为0～1440，单位是分钟。 默认值：无 配置原则：无                     |
| N2SUBALARMTHD  | UE无关的N2信息订阅失败告警阈值   | 可选必选说明：可选参数 参数含义：尝试订阅UE无关的N2信息失败次数达到该配置值时需要上报“LCS UE无关的N2信息订阅失败”告警。 数据来源：本端规划 取值范围：整数类型，取值范围为1～10，单位是次数。 默认值：无 配置原则：无                          |
| TRPUPDINTERVAL | TRP更新时间间隔（小时）       | 可选必选说明：可选参数 参数含义：该参数用于设置定时更新TRP的时间间隔。配置为0时每次定位都会更新TRP。 数据来源：本端规划 取值范围：整数类型，取值范围为0～48，单位是小时。 默认值：无 配置原则：无                                       |
| TRPALARMTHD    | TRP告警上报阈值           | 可选必选说明：可选参数 参数含义：尝试获取TRP信息失败次数达到该配置值时需要上报TRP信息获取失败告警。 数据来源：本端规划 取值范围：整数类型，取值范围为1～10，单位是次数。 默认值：无 配置原则：无                                        |
| NOUEDELGNBTIME | 无用户删除基站信息时长（分钟）     | 可选必选说明：可选参数 参数含义：当对应的基站无定位用户上下文后，达到无用户删除基站信息时长时删除本地保存的基站信息。配置为0时表示基站下无定位用户时不需要删除本地保存的基站信息。 数据来源：本端规划 取值范围：整数类型，取值范围为0～1440，单位是分钟。 默认值：无 配置原则：无 |

#### 使用实例

设置LCS UE无关的策略参数：

```
SET LCSNONUEPLY: N2SUBINCLGNBSW=ENABLE, N2SUBINTTIMES=100, N2SUBINTERVAL=5, N2SUBALARMTHD=3, TRPUPDINTERVAL=24, TRPALARMTHD=3, NOUEDELGNBTIME=0;
```
