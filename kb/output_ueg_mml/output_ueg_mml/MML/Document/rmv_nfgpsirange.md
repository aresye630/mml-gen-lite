# 删除NF GPSIRANGE信息（RMV NFGPSIRANGE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMSF、NWDAF、NEF、SCF**

该命令用于删除NF实例支持的GPSIRANGE信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                                                                                                                                      |
|:---------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCENAME | NF实例名称 | 可选必选说明：必选参数  参数含义：该参数用于指定GPSIRANGE对应的NF实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~50。本参数的构成字符只能是字母A～Z或a～z、数字0～9、中划线"-"和下划线"_"，例如，SMSF_Instance_0。  默认值：无  配置原则：  本参数取值与ADD NFUUID命令中的“NF实例名称”参数取值保持一致时，关联关系生效。 |
| RANGESTART     | 起始号段   | 可选必选说明：必选参数  参数含义：该参数用于指定GPSI的起始号段。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是5~15。  默认值：无  配置原则：  GPSI的终止号段需要不小于GPSI的起始号段，且终止号段和起始号段长度需相等。                                                                           |

## 使用实例

删除NF GPSIRANGE信息，NF实例名称为SMSF\_Instance\_0，起始号段为138100000000000。

```
RMV NFGPSIRANGE: NFINSTANCENAME="SMSF_Instance_0", RANGESTART="138100000000000";
```
