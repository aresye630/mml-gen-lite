# 删除基于应用的质差上报策略（RMV APPPOLICYCTRL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于删除基于应用的质差上报策略。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                    |
|:-------------|:-------|:----------------------------------------------------------------------------------------|
| APPIDNAME    | 应用ID   | 可选必选说明：必选参数 参数含义：该参数用于指定重点业务保障的应用组名称。 数据来源：全网规划 取值范围：字符串类型，区分大小写，长度为1-63位。 默认值：无 配置原则：无 |
| SUBAPPIDNAME | 子应用ID  | 可选必选说明：必选参数 参数含义：该参数用于指定重点业务保障的应用名称。 数据来源：全网规划 取值范围：字符串类型，区分大小写，长度为1-63位。 默认值：无 配置原则：无  |

#### 使用实例

删除应用ID为zhibo，子应用ID为huya的基于应用的质差策略，执行如下命令：

```
RMV APPPOLICYCTRL: APPIDNAME="zhibo", SUBAPPIDNAME="huya";
```
