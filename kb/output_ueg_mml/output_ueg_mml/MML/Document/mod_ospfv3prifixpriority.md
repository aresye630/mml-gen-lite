# 修改OSPFv3路由收敛优先级配置（MOD OSPFV3PRIFIXPRIORITY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改OSPFv3路由的收敛优先级。

#### 注意事项

- 该命令执行后立即生效。
- 只有配置了OSPFv3进程后才能使用该命令。
- 缺省情况下，公网OSPFv3主机路由的收敛优先级为medium，直连路由的收敛优先级为high，静态路由的收敛优先级为medium，其他协议（如BGP等）路由的收敛优先级为low。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称       | 参数说明                                                                                                                               |
|:-------------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------|
| PROCID       | OSPFv3进程号  | 可选必选说明：必选参数 参数含义：OSPFv3进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 配置原则：OSPFv3进程必须已经存在。请使用LST OSPFV3命令查看可用的OSPFv3进程。         |
| TOPOID       | 拓扑标识       | 可选必选说明：必选参数 参数含义：拓扑标识。 数据来源：全网规划 取值范围：整数类型，取值范围为0。 默认值：无 配置原则：目前只支持默认拓扑0。                                                          |
| PRIORITY     | 路由优先级      | 可选必选说明：必选参数 参数含义：路由优先级。 数据来源：本端规划 取值范围：枚举类型。 critical：配置OSPFv3路由的收敛优先级为关键。high：配置OSPFv3路由的收敛优先级为高。medium：配置OSPFv3路由的收敛优先级为中。 默认值：无 |
| IPPREFIXNAME | IPv6前缀列表名称 | 可选必选说明：必选参数 参数含义：IPv6前缀列表名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～169。 默认值：无 配置原则：不支持空格，区分大小写。                                            |

#### 使用实例

修改路由收敛优先级为critical的ipv6-prefix名为prefix-name1：

```
MOD OSPFV3PRIFIXPRIORITY:PROCID=1,TOPOID=0,PRIORITY=critical,IPPREFIXNAME="prefix-name1";
```
