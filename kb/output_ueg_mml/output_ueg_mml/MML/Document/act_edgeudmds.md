# 手动触发园区用户数据同步（ACT EDGEUDMDS）

- 命令功能

- 操作用户权限

#### 命令功能

**适用NF：UDM**

**须知** 

本命令属于高危命令，仅适用于运维人员可能期望能够立刻从SFTP Server同步数据。例如调测阶段修改配置后可立刻执行命令，验证修改的配置是否正确生效，或者故障场景数据丢失时，需要手动立刻恢复数据。

该命令用于手动发起SFTP连接同步数据流程，支持指定服务器和不指定服务器两种方式。不指定服务器时，流程同单/主备数据同步。

#### 注意事项

- 该命令执行后立即生效。
- 如果需要输入该命令的远端数据同步服务器名，则需要提前配置ADD RDATASYNSERVER命令。如果用户没有对远端数据同步服务器名进行配置，系统将会下发缺省命令。
- 当启动手动数据同步时，如果与主备SFTP服务器连接失败时且连接尝试次数均超过“ALMThesTimes”阈值，连接尝试停止。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称       | 参数说明                                                                                             |
|:-----------|:-----------|:-------------------------------------------------------------------------------------------------|
| SERVERNAME | 远端数据同步服务器名 | 可选必选说明：可选参数 参数含义：用于设置服务器名。 数据来源：本端规划 取值范围：长度为1~16的字符串。 默认值：无 配置原则：必须是ADD RDATASYNSERVER配置的服务器之一。 |

#### 使用实例

- 手动发起SFTP连接同步数据流程，不指定服务器：

  ```
  ACT EDGEUDMDS:;
  ```
- 手动发起SFTP连接同步数据流程，指定服务器，SERVERNAME实例为server1：

  ```
  ACT EDGEUDMDS: SERVERNAME="server1";
  ```
