# 查询Proxy SGW-C接入控制列表（LST PROXYSGWACCLIST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C**

该命令用于Proxy S-GW特性中查询接入控制列表记录。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                                                      |
|:------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGEALL | 用户范围   | 可选必选说明：可选参数  参数含义：该参数用于指定接入控制的范围。  数据来源：本端规划 取值范围： ALL_USER（所有用户）IMSI_PRE（IMSI前缀）MSISDN_PRE（MSISDN前缀）  默认值：无  配置原则：  当存在多种用户范围的记录时，匹配的优先级由高到低为： IMSI_PRE/MSISDN_PRE，ALL_USER，如果某一用户同时匹配IMSI_PRE以及MSISDN_PRE记录时，最终是否允许接入受SET PROXYSGWFUNC命令中的LISTTYPE参数控制。 |
| PREFIX      | 前缀     | 可选必选说明：该参数在"SUBRANGEALL"配置为"IMSI_PRE"、"MSISDN_PRE"时为条件可选参数。  参数含义：该参数用于指定接入控制的号码前缀，当SUBRANGE为IMSI_PRE时表示IMSI号码前缀，当SUBRANGE为MSISDN_PRE时表示MSISDN号码前缀。使用时按照最长匹配进行查询。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~15。  默认值：无  配置原则：  取值范围为1~15位数字。                        |
| CTRLTYPE    | 控制类型   | 可选必选说明：可选参数  参数含义：该参数用于控制是否允许用户接入。  数据来源：本端规划 取值范围： ALLOW（允许）REJECT（拒绝）  默认值：无  配置原则：无                                                                                                                                                                    |

## 使用实例

查询所有Proxy SGW-C接入列表记录，执行如下命令：

```
%%LST PROXYSGWACCLIST:;%%
RETCODE = 0  操作成功

结果如下
--------
用户范围  =  所有用户
    前缀  =  *
控制类型  =  允许
描述信息  =  All User
(结果个数 = 1)

---    END
```
