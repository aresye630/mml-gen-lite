## 命令功能

**须知** 

本命令属于高危命令，执行不当会导致业务通信路由方式变更，造成业务呼损或系统崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置是否启用SCP（Service Communication Proxy）功能开关。

该命令的使用场景：在SCP链路故障或SCP功能异常等场景下，关闭SCP功能开关。

## 注意事项

- 该命令中所描述的初始设置值，是指操作员通过**LST SCPSWITCH**命令查询得出的系统在初始化时的预置参数值。“开关”参数的初始设置值为：“DISABLE（禁用）”。
- 该命令“开关”参数设置为“ENABLE（启用）”时，需要通过**DSP UDMLICRATE**查看是否加载NF间接路由功能License。对应的License控制项为：“81203687 LKQ7UDMFE16 NF间接路由功能”。
- 如果未加载NF间接路由功能License则不允许通过该命令的“开关”参数开启SCP路由的通信方式，否则会上报“360207 NF间接路由功能 License未加载”的错误码。
- 业务流程是否经SCP路由根据“开关”与“业务经SCP路由开关”参数决定：
  - 当“业务经SCP路由开关”配置时，以“业务经SCP路由开关”参数为准，“业务经SCP路由开关”配置为“ENABLE(启用)”时表示业务经过SCP路由。
  - 当“业务经SCP路由开关”不配置时，以“开关”参数配置值为准，“开关”配置为“ENABLE(启用)”时表示业务经过SCP路由。

## 参数说明

| 参数ID           | 参数名称       | 参数描述                                                                                                                                          |
|:---------------|:-----------|:----------------------------------------------------------------------------------------------------------------------------------------------|
| SWITCH         | 开关         | 可选必选说明：必选参数 参数含义：用于设置SCP功能为禁用/启用状态。SCP服务发现、链路建立、业务消息发送均受该参数控制。 取值范围： DISABLE(禁用)：不采用SCP通信方式ENABLE(启用)：采用SCP通信方式 默认值：无。 配置原则：无。                |
| SERVICE_SWITCH | 业务经SCP路由开关 | 可选必选说明：可选参数 参数含义：该参数用于配置业务消息发送是否经过SCP路由。 取值范围： DISABLE(禁用)：不经过SCP路由ENABLE(启用)：经过SCP路由 默认值：无。 配置原则：“开关”取值为“DISABLE(禁用)”时不允许配置该参数为“ENABLE(启用)”。 |

## 使用实例

在SCP链路故障或SCP功能异常等场景下，关闭SCP功能开关：

```
SET SCPSWITCH: SWITCH=DISABLE;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释               | 原因分析                                                   | 处理建议                                                      |
|-------:|:--------------------|:-------------------------------------------------------|:----------------------------------------------------------|
| 360207 | NF间接路由功能License未加载。 | 未加载NF间接路由功能License。                                    | 通过DSP UDMLICRATE查看是否加载了NF间接路由功能License，如果未加载，请联系华为技术支持处理。 |
| 360204 | 参数冲突。               | “开关”取值为“DISABLE(禁用)”时不允许配置“业务经SCP路由开关”参数为“ENABLE(启用)”。 | “开关”取值为“DISABLE(禁用)”时不允许配置“业务经SCP路由开关”参数为“ENABLE(启用)”。    |
