# 设置丢包和并发流告警配置信息（SET DROPPKGALMINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于设置丢包和并发流告警的配置信息。

该命令的使用场景为：

1. HLB服务每5秒对nStack协议栈的丢包率进行统计，根据丢包率是否达到“TCP协议栈丢包告警阈值(‰)”，判断是否要上报ALM-18412 TCP协议栈连续丢包告警。
2. HLB服务在“HTTP链路遍历周期”软参设置的遍历周期内，根据HTTP链路消息的丢包数是否达到“HTTP协议栈丢包告警阈值”，判断是否要上报ALM-18413 HTTP协议栈连续丢包告警。
3. HLB服务在“HTTP链路遍历周期”软参设置的遍历周期内，根据单个周期内HTTP链路的并发流数量是否达到“并发流超限告警阈值”，判断是否要上报ALM-18414 HTTP连接即将达到最大并发流限制告警。

## 注意事项

告警恢复阈值需要满足以下要求：

- “TCP协议栈丢包告警恢复阈值(‰)”小于“TCP协议栈丢包告警阈值(‰)”。
- “HTTP协议栈丢包告警恢复阈值”小于“HTTP协议栈丢包告警阈值”。
- “并发流超限告警恢复阈值”小于“并发流超限告警阈值”。

## 使用实例

1、设置丢包和并发流告警配置信息，当“告警类型”选择为“TCP\_PKT\_LOSS”、“告警产生抑制周期数”为“3”、“告警恢复抑制周期数”为“3”、“TCP协议栈丢包告警阈值(‰)”为“5”、“TCP协议栈丢包告警恢复阈值(‰)”为“2”时，执行如下命令：

```
SET DROPPKGALMINFO: ALMTYPE=TCP_PKT_LOSS, RPTPERIODNUM=3, CLRPERIODNUM=3, TCPPKTLOSRPTRATE=5, TCPPKTLOSCLRRATE=2;
```

2、设置丢包和并发流告警配置信息，当“告警类型”选择为“HTTP\_PKT\_LOSS”、“告警产生抑制周期数”为“3”、“告警恢复抑制周期数”为“3”、“HTTP协议栈丢包告警阈值”为“1”、“HTTP协议栈丢包告警恢复阈值”为“0”时，执行如下命令：

```
SET DROPPKGALMINFO: ALMTYPE=HTTP_PKT_LOSS, RPTPERIODNUM=3, CLRPERIODNUM=3, HTTPPKTLOSRPTNUM=1, HTTPPKTLOSCLRNUM=0;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释                    | 原因分析                 | 处理建议              |
|-------:|:------------------------|:---------------------|:------------------|
| 100016 | 参数值不在有效取值范围内。           | 设置告警的配置参数不在这个取值范围之内。 | 检查参数取值范围是否有误。     |
| 360169 | 参数值不合理：告警恢复阈值要小于告警上报阈值。 | 设置的告警恢复阈值没有小于告警上报阈值。 | 设置告警恢复阈值小于告警上报阈值。 |
