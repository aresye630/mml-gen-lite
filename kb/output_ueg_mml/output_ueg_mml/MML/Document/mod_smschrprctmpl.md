# 修改SMS CHR流程控制模板（MOD SMSCHRPRCTMPL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMSF**

该命令用于修改SMS CHR流程控制模板，用以控制CHR的采集流程。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称            | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|:--------------|:----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TMPLIDX       | 流程控制模板索引        | 可选必选说明：必选参数  参数含义：该参数用于表示流程控制模板索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~127。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| SMSCHRFAILPRC | SMS CHR失败流程上报选项 | 可选必选说明：可选参数  参数含义：该参数用于表示SMS CHR失败流程上报选项。  数据来源：本端规划 取值范围： “OTHER（其他流程需要上报CHR单据）”：表示其他流程需要上报CHR单据。“SMSFREG（5G注册流程需要上报CHR单据）”：表示5G注册流程需要上报CHR单据。“SMSFDEREG（5G去注册流程需要上报CHR单据）”：表示5G去注册流程需要上报CHR单据。“SMSFMO（5G MO流程需要上报CHR单据）”：表示5G MO流程需要上报CHR单据。“SMSFMT（5G MT流程需要上报CHR单据）”：表示5G MT流程需要上报CHR单据。“VLRLUR（4G位置更新流程需要上报CHR单据）”：表示4G位置更新流程需要上报CHR单据。“VLRDETACH（4G去注册流程需要上报CHR单据）”：表示4G去注册流程需要上报CHR单据。“VLRMO（4G MO流程需要上报CHR单据）”：表示4G MO流程需要上报CHR单据。“VLRMT（4G MT流程需要上报CHR单据）”：表示4G MT流程需要上报CHR单据。“VLRALERT（4G用户可达通知流程需要上报CHR单据）”：表示4G用户可达通知流程需要上报CHR单据。  默认值：OTHER-1&SMSFREG-1&SMSFDEREG-1&SMSFMO-1&SMSFMT-1&VLRLUR-1&VLRDETACH-1&VLRMO-1&VLRMT-1&VLRALERT-1  配置原则：无 |

## 使用实例

运营商希望修改“流程控制模板索引”为“1”的SMS CHR流程控制模板的“短信CHR失败流程上报选项”为“其他流程需要上报CHR单据”，执行如下命令：

```
MOD SMSCHRPRCTMPL: TMPLIDX=1, SMSCHRFAILPRC=OTHER-1&SMSFREG-0&SMSFDEREG-0&SMSFMO-0&SMSFMT-0&VLRLUR-0&VLRDETACH-0&VLRMO-0&VLRMT-0&VLRALERT-0;
```
