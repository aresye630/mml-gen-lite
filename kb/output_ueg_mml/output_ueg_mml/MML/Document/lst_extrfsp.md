# 查询扩展RFSP策略组成员(LST EXTRFSP)

#### 命令功能

**适用网元：SGSN、MME**

该命令用于查看扩展RFSP策略组中的策略。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称       | 参数说明                                                                                                                                                 |
|:--------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
| TYPE    | 类型         | 可选必选说明：可选参数 参数含义：该参数用于指定该扩展RFSP策略的类型。 数据来源：整网规划 取值范围：“SPEC_MOVE_SUB(指定的移动用户)” 默认值：无                                                                  |
| ARETYPE | 区域类型       | 可选必选说明：条件可选参数 参数含义：该参数用于指定扩展RFSP策略控制区域范围类型。 前提条件：该参数在“TYPE（类型）”参数配置为“SPEC_MOVE_SUB(指定的移动用户)”后生效。 数据来源：整网规划 取值范围：“TAGP(跟踪区群组)”“ENBGP(eNodeB群组)” 默认值：无 |
| TAGPID  | 跟踪区群组标识    | 可选必选说明：条件可选参数 参数含义：该参数用于指定跟踪区群组标识。 前提条件：该参数在“ARETYPE（区域类型）”参数配置为“TAGP(跟踪区群组)”后生效。 数据来源：整网规划 取值范围：1~2048 默认值：无                                        |
| ENBGPID | eNodeB群组标识 | 可选必选说明：条件可选参数 参数含义：该参数用于指定eNodeB群组标识。 前提条件：该参数在“ARETYPE（区域类型）”参数配置为“ENBGP(eNodeB群组)”后生效。 数据来源：整网规划 取值范围：1~2048 默认值：无                                 |

#### 使用实例

查询扩展RFSP策略组中的策略：

LST EXTRFSP:;
