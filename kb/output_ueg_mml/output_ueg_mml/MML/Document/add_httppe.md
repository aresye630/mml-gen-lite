# 增加对端HTTP实体(ADD HTTPPE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在配置数据库中增加一条对端HTTP实体的数据记录，为下一步配置HTTP链路做准备。当UIM采用GBA架构对用户进行认证时，Ua、Ub和AP-AS接口使用HTTP/HTTPS协议消息交互并进行消息转发，完成用户业务访问交互操作信息的传递。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

- HTTP链路的处理性能远高于HTTPS链路，但HTTPS链路在信息传输方面具有更高的安全性。如果无法确认当前应用场景是否需要使用HTTPS链路，建议联系华为技术工程师。
- 当UIM与用户终端在Ua和Ub接口进行信息交互时，UIM作为HTTP服务器，不需要配置HTTP对端实体。
- 当UIM与AS在AP-AS接口进行信息交互时，UIM的功能实体AP作为HTTP客户端，AS作为HTTP服务器，需要配置HTTP对端实体。
- 执行该命令配置“对端域名”取值需要与命令**ADD HTTPPEHOST**中配置的对端域名保持一致。

## 参数说明

| 参数标识    | 参数名称       | 参数说明                                                                                                                                                                                                                                                  |
|:--------|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PEID    | 对端HTTP实体标识 | 用于指定对端HTTP实体。 取值范围：0～255 默认值：无。 注意：该参数为必选参数。                                                                                                                                                                                                          |
| HOST    | 对端域名       | 用于指定标识HTTP对端实体的FQDN。一个“对端域名”参数只能加一个HTTPPE，即对端域名与对端HTTP实体一一对应。 需要指出的是，该参数不区分大小写，在执行LST HTTPPE命令查询出的报文中为全小写形式。 取值范围：长度不超过127的字符串。 默认值：无。 注意：该参数为必选参数。                                                                                                   |
| PENAME  | 对端HTTP实体名  | 用于指定对端HTTP实体的名称。 取值范围：长度不超过127的字符串。 默认值：无。 注意：该参数为可选参数。                                                                                                                                                                                               |
| LNKSMOD | 链路集选择模式    | 用于在配置数据库中指定当前对端实体与AS之间的链路集选择模式。 取值范围：POLLING(轮询法)：对HTTP实体下的所有链路集轮流选择，即在可用对端的链路集之间循环选择链路集。AORS(主备方式)：当前只有一条链路集主用，其余链路集都是备用。只有当主用链路集下的链路全部失效时，次优先级链路集启用为主用链路集。 说明： 链路集优先级由本命令定义的对端实体关联的ADD HTTPRSRV命令中定义的“链路集参数ID”参数取值控制，取值越小优先级越高。 默认值：无。 注意：该参数为必选参数。 |

## 使用实例

增加一个对端HTTP实体，携带以下参数：

- “对端HTTP实体标识”为“1”
- “对端域名”为“ap.huawei.com”
- “对端HTTP实体名”为“ap”
- “链路集选择模式”为“POLLING”

执行命令如下：

```
ADD HTTPPE: PEID=1, HOST="ap.huawei.com", PENAME="ap", LNKSMOD=POLLING;
```
