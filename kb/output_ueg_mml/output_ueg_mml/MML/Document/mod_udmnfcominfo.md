# 修改网元公共信息（MOD UDMNFCOMINFO）

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成UDM在NRF上的注册信息发生错误，从而导致周边网元无法访问UDM提供的服务，造成业务失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一条网元公共数据记录的某些参数进行修改或调整。在该命令中，系统通过“公共信息标识”参数来唯一标识一条网元公共信息。

## 注意事项

- 任意参数被修改后，当**ADD UDMNFSRV**命令中的“网元状态”为“REGISTERED”且满足如下条件时，将按照**ADD UDMNFSRV**命令中“更新方式”参数中指定的更新模式立即向NRF发送更新请求。
  - “公共信息标识”在**ADD UDMNFSRV**中引用。
  - “公共信息标识”在**ADD UDMNFSERVICE**中引用，且**ADD UDMNFSERVICE**命令定义的“组名称”已被**ADD UDMNFSRV**引用。
- 当凌晨自动校验或执行**VRY NRFDATA**命令手动校验NRFClient内存数据时，在校验该MML命令的过程中，无法执行该命令，若运行该命令，则提示“360155 该MML数据正在校验中，请稍后再试”。

## 使用实例

在开局场景下配置信令数据时，修改“公共信息标识”为“cominfo\_02”的网元公共信息，将“全量域名”修改为“huawei1.com”：

```
MOD UDMNFCOMINFO: NFCOMINFOID="cominfo_02", FQDN="huawei1.com";
```
