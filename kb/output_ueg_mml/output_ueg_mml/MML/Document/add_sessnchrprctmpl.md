# 增加会话CHR流程控制模板（ADD SESSNCHRPRCTMPL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SGW-C、SMF、GGSN**

该命令用于新增会话CHR流程控制模板，用以控制CHR的采集流程。

## 注意事项

- 该命令执行后立即生效。

- 系统初始运行，会默认创建索引为0和1的SESSNCHRPRCTMPL配置，分别用于高性能CHR服务器和低性能CHR服务器的采集流控控制。这两条默认配置无法被删除，只能修改。

- 最多可输入128条记录。
