# 增加当前UPF绑定的IP域（ADD UPIPDOMAIN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于将指定UPF绑定到特定的IPDomain，当该UPF作为会话主锚点UPF时，SMF内部会在UE IP前加上该IPDomain前缀，并带给PCF，用于扩展地址池。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入32768条记录。
- IPDOMAIN参数为大小写敏感，需要确保本端IPDOMAIN配置大小写与对端网元请求的IPDOMAIN保持一致。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称      | 参数说明                                                                                                                                                                                                                                         |
|:----------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UPNODE    | UPF节点标识   | 可选必选说明：必选参数  参数含义：该参数用于表示UPF节点标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~36。  默认值：无  配置原则：  本参数取值与ADD PNFPROFILE命令中的“NF实例标识”参数取值保持一致时，关联关系生效。                                                                                                       |
| IPDOMAIN  | IP地址段归属的域 | 可选必选说明：必选参数  参数含义：该参数用于表示IP地址段归属的域。例如当两个UPF上的IP地址段中存在重叠的地址时，可以配置地址段1归属IPDOAMAIN1，地址段2归属IPDOMAIN2，随UE IP将IPDOMAIN携带给PCF，PCF检测到IP地址冲突，不影响用户正常使用业务。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：  SMF为每个IP地址段归属的域提供不同的标识符（如SMF NF实例标识符）。  |
| DNNSWITCH | DNN开关     | 可选必选说明：必选参数  参数含义：该参数用于表示是否打开指定DNN绑定UPNODE和IPDOMAIN的开关。  数据来源：全网规划 取值范围： “ENABLE（使能）”：Dnn配置使能“DISABLE（不使能）”：DNN配置不使能  默认值：无  配置原则：  若配置UPNODE和IPDomain之间的绑定关系，对所有DNN都生效，此参数应配置为DISABLE。  若配置UPNODE和IPDomain之间的绑定关系，只对某些DNN都生效，此参数应配置为ENABLE。 |
| DNN       | 数据网络名称    | 可选必选说明：该参数在"DNNSWITCH"配置为"ENABLE"时为条件必选参数。  参数含义：该参数用于表示数据网络名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~63。可输入的字符有字母、十进制数字、“-”和“.”，并且开头和结尾只能是数字或者字母。不能出现连续两个“.”。字母大小写不敏感。  默认值：无  配置原则：无                                                             |

## 使用实例

- 增加UPNODE为"upf\_instance\_1"的UPF与IPDomain的绑定关系：

  ```
  ADD UPIPDOMAIN: UPNODE="upf_instance_1", IPDOMAIN="Domain_0", DNNSWITCH=DISABLE;
  ```
- 增加UPNODE为"upf\_instance\_1"的UPF在DNN为"huawei.com"上与IPDomain的绑定关系：

  ```
  ADD UPIPDOMAIN: UPNODE="upf_instance_1", IPDOMAIN="Domain_0", DNNSWITCH=ENABLE, DNN="huawei.com";
  ```
