# 查询UPF组（LST ADDRUPGROUP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于查询UPF组的信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                               |
|:-----------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
| UPFGRPNAME | UPF组名称 | 可选必选说明：可选参数  参数含义：该参数用于指定UPF组名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。不支持空格及特殊字符“#”、“$”和“&”等，由“-”、“_”、数字、字母和“.”组成，不能以“.”开头或结尾，不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

查询所有UPF组的信息：

```
LST ADDRUPGROUP:;
RETCODE = 0  操作成功。

结果如下
------------------------
UPF组名称  =  upfgrp1
UPF组类型  =  本地
(结果个数 = 1)
```

## 输出结果说明

| 输出项名称   | 输出项解释                 |
|:--------|:----------------------|
| UPF组名称  | 该参数用于指定UPF组名称。        |
| UPF组类型  | 该参数用于指定UPF组的UE地址规划类型。 |
