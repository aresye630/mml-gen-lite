# 增加DC间通信通道信息（ADD DRDCI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令为增加容灾控制通道信息，可能导致业务中断，需要按照激活主备容灾指导书进行操作，请勿自行执行该命令。

该命令用于增加DC间通信通道信息。

## 注意事项

- 该命令执行后立即生效。

- 该命令只用于在UEG-L/UEN网元采用主备（冷备）容灾模式下执行。
- 该命令只用于在UEG-M/UEG网元采用主备（热备）容灾模式下执行。
- UEG/UEN网元最多配置一条记录。

- 最多可输入16条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称          | 参数说明                                                                                                                                                                                           |
|:------------|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DRGROUPID   | 容灾组标识         | 可选必选说明：必选参数  参数含义：该参数用于指定容灾组标识。  数据来源：全网规划  取值范围：整数类型，取值范围是1~8。  默认值：无  配置原则：  可通过LST DRGROUPINFO命令获取返回结果中的容灾组标识作为参数输入。                                                                        |
| IPVERSION   | IP版本号         | 可选必选说明：必选参数  参数含义：该参数用于配置容灾控制通道IP地址类型。  数据来源：全网规划 取值范围： IPV4（IPv4类型地址）IPV6（IPv6类型地址）  默认值：无  配置原则：无                                                                                            |
| LDCIP       | 本端DC通信IPv4地址  | 可选必选说明：该参数在"IPVERSION"配置为"IPV4"时为条件必选参数。  参数含义：该参数用于配置本端容灾控制通道IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无                                                                                |
| PDCIP       | 对端DC通信IPv4地址  | 可选必选说明：该参数在"IPVERSION"配置为"IPV4"时为条件必选参数。  参数含义：该参数用于配置对端容灾控制通道IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。  默认值：无  配置原则：无                                                                                |
| LDCIPV6     | 本端DC通信IPv6地址  | 可选必选说明：该参数在"IPVERSION"配置为"IPV6"时为条件必选参数。  参数含义：该参数用于配置本端容灾控制通道IPv6地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无                                                                                |
| PDCIPV6     | 对端DC通信IPv6地址  | 可选必选说明：该参数在"IPVERSION"配置为"IPV6"时为条件必选参数。  参数含义：该参数用于配置对端容灾控制通道IPv6地址。  数据来源：全网规划  取值范围：IPv6地址类型。  默认值：无  配置原则：无                                                                                |
| VPNINSTANCE | VPN实例名称       | 可选必选说明：必选参数  参数含义：该参数用于配置VPN实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~31。  默认值：无  配置原则：  输入的参数VPN实例名称，需要提前通过ADD VPNINST命令进行配置，或者使用默认的VPN实例“_public_”。“_public_”是公网缺省的VPN实例名，不能通过LST VPNINST命令查询出来。 |
| DATABKMODE  | 数据备份模式        | 可选必选说明：可选参数  参数含义：该参数用于配置数据备份模式。  数据来源：全网规划 取值范围： Active-Standby（主备（冷备）容灾模式，无数据备份）Active-Standby_Hot_Backup（主备（热备）容灾模式，有数据备份）  默认值：Active-Standby  配置原则：  参数为预留参数，当前无实际作用。                     |
| HBINTERVAL  | 心跳探测时长(100ms) | 可选必选说明：可选参数  参数含义：该参数用于配置容灾控制通道的心跳探测时长，单位为100ms。  数据来源：全网规划  取值范围：整数类型，取值范围是1~100。  默认值：10  配置原则：无                                                                                             |
| HBTIMES     | 心跳重传次数        | 可选必选说明：可选参数  参数含义：该参数用于配置容灾控制通道的心跳重传次数。  数据来源：全网规划  取值范围：整数类型，取值范围是1~30。  默认值：6  配置原则：无                                                                                                        |

## 使用实例

增加DC间通信通道信息：

```
%%ADD DRDCI: DRGROUPID=1, IPVERSION=IPV4, LDCIP="172.16.3.4", PDCIP="172.16.5.6", VPNINSTANCE="12345", DATABKMODE=Active-Standby;%%
RETCODE = 0  操作成功

---    END
```
