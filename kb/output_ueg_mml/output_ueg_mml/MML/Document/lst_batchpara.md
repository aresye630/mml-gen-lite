# 查询批量调度参数（LST BATCHPARA）

#### 命令功能

**适用NF：UPF**

该命令用于查询设置的批量调度参数。

#### 注意事项

如果没有记录，则当前的批量调度参数为系统初始默认的参数。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                      |
|:----------|:---------|:--------------------------------------------------------------------------------------------------------------------------|
| STAGENAME | 数据转发阶段名称 | 可选必选说明：必选参数 参数含义：该参数用于指定数据转发阶段。 数据来源：本端规划 取值范围：枚举类型。 FASTSTAGE：包保序转发阶段。CPLXSTAGE：流保序转发阶段。SQTLSTAGE：用户保序转发阶段。 默认值：无 配置原则：无 |

#### 使用实例

查询包保序转发阶段的批量调度参数：

```
LST BATCHPARA: STAGENAME=FASTSTAGE;
```
