# 查询SGS MME实体(LST SGSMME)

- 命令功能
- 注意事项
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SMSF**

该命令用于查询配置的SGS MME实体。

#### 注意事项

无。

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                   |
|:-------|:-------|:-----------------------------------------------------------------------|
| MMEX   | MME索引  | 可选必选说明：必选参数 参数含义：该参数用于指定一个MME实体，在全局范围内唯一。 数据来源：本端规划 取值范围：0～1999。 默认值：无 |

#### 使用实例

查询已经配置的所有的SGS MME实体记录。

```
%%LST SGSMME:;%%
RETCODE = 0  操作成功 
The result is as follows 
------------------------ 
MME索引     MME名          MME POOL标识     MME容量权重     
1           46000800101     126              23
2           46000800102     125              25
(结果个数 = 2)
```
