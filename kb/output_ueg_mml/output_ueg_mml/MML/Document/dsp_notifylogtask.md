# 显示通知日志导出任务状态（DSP NOTIFYLOGTASK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询最近一次用户失败通知日志导出任务的执行情况

## 注意事项

- 由于失败通知日志历史记录只记录在内存中，NLF服务重启后记录会清除。
- 导出的日志包含用户的个人数据，如：IMSI、MSISDN等。因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护。例如：
  1. 采用安全的文件传输协议（如SFTP）传输文件。
  2. 并严格控制文件的访问权限。
  3. 及时清理数据文件。

  在从运营商网络获取数据前，必须要获得运营商的授权。

  若需从运营商网络中获取必要的数据，需要运营商维护人员对其中的个人数据进行匿名化处理，匿名化后的数据由运营商维护人员审核后提供，以防止个人数据泄露。匿名化处理工具可以在https://support.huawei.com/获取，获取方法请参见产品手册“匿名化工具安全策略”页面。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                             |
|:-------|:-------|:-------------------------------------------------------------------------------------------------|
| SUBID  | 用户标识   | 可选必选说明：可选参数。 参数含义：可以通过MSISDN或IMSI指定用户的唯一标识，系统可根据此唯一标识筛选导出该用户的失败通知日志文件。 取值范围：长度不超过255的字符串。 默认值：无。 |

## 使用实例

查询某用户的失败通知导出日志任务状态，执行命令如下：

```
DSP NOTIFYLOGTASK:SUBID="41236542001";
```

```
%%DSP NOTIFYLOGTASK:;%%
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1。

| 输出项名称   | 输出项解释                                                    |
|:--------|:---------------------------------------------------------|
| 任务ID    | 用于表示任务ID的唯一标识。                                           |
| 用户标识    | 用于表示最近一次执行EXP NOTIFYLOG命令输入的“用户标识”。                      |
| 开始时间    | 用于表示最近一次执行EXP NOTIFYLOG命令输入的“开始时间”。                      |
| 结束时间    | 用于表示最近一次执行EXP NOTIFYLOG命令输入的“结束时间”。                      |
| 状态      | 用于表示最近一次执行EXP NOTIFYLOG命令导出失败通知日志的任务状态。 取值范围： 执行中成功失败上传中 |
| 文件名     | 用于表示最近一次执行EXP NOTIFYLOG命令导出失败通知日志的文件名称。                  |
