# 修改远端服务器链路集参数配置（MOD HTTPLKSPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改一条远端服务器链路集参数配置项，修改参数包括链路集参数ID、链路数目、流数目数组和链路选择模式。在该命令中，系统通过“链路集参数ID”参数来唯一标识一条链路集参数配置信息。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                                       |
|:----------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PARAID    | 链路集参数ID   | 可选必选说明：必选参数。 参数含义：标识一条链路集参数的关键字段（其取值不能被修改），用于指定需要修改哪一条链路集参数，操作员可以使用LST HTTPLKSPARA命令查询获得。 取值范围：1~255。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                       |
| LINKNUM   | 链接数目      | 可选必选说明：可选参数。 参数含义：用于标识建立动态和静态链路的最大数目。若取值为6，则表示这条链路集ID下，需要配置6条HTTP链路。 取值范围：0(全互联)或2～512。 默认值：无。  说明： GBA场景下，该参数的推荐默认值为：16*HLB数量。 配置原则：全互联是指UDM中每个HLB实例都可以处理对端NF发起的HTTP请求链接；这种方式HLB实例实现简单，但是无法做到对端NF请求进行资源隔离。非SCP、SEPP和AUC对端类型，该参数取值为0或者16时，会增加对端链路负荷。仅SCP、SEPP和AUC对端类型，该参数允许配置超过16条链路。当配置超过16条链路时，实际创建的链路数取LINKNUM与系统HLB可创建的链路数取两者之间的最小值。对于同一个远端IP加PORT，每个HLB实例最多可创建16条链路。 静态链路允许配置超过16条链路。 |
| STREAMNUM | 流数目数组     | 可选必选说明：可选参数。 参数含义：用于标识动态和静态链路最大流数目。 取值范围：长度范围为0~255的字符串。 默认值：无。 配置原则： 与链接数目相对应，使用“，”区分不同链接的最大流数目，如配置2个链路的最大流数目分别为1024和2048，则输入1024,2048，如果只输出一个，则全部使用。当配置的“流数目数组”少于“链接数目”时，则系统取最后一个流数目作为剩下链路的流数目数组；当配置的“流数目数组”多于“链接数目”时，则系统会舍弃多余的流数目数组。当“链接数目”配置超过16条链路时，不支持配置该参数为数组方式。                                                                                                                    |
| LNKMOD    | 链路选择模式    | 可选必选说明：可选参数。 参数含义：用于标识待修改的链路集的工作模式。 取值范围： ACTIVEWITHPRI(基于优先级)：按照优先级进行选链。根据流数量进行断链后建链，如果流数量耗尽，则断链并且HLB通知DCS，DCS选择次优先级链路进行发送消息，直至流数量耗尽后重新按照优先级选链。POLLING(轮询方式)：对路由组下的所有对端实体轮流选择，即在可用对端之间循环选择。POLLINGWITHWGT(基于权重的轮询方式)：按照权重进行选择，需要根据设置的权重比例发送。例如：A和B都是链路，A的权重设置为20，B的权重设置为80，则A与B按照1:4消息流量进行发送。 默认值：无。 配置原则：该参数仅针对同一个对端，即对端IP和端口号相同。                                                        |
| POR       | 初始链路优先级数组 | 可选必选说明：条件必选参数。 参数含义：用于标识各条链路的优先级顺序。 取值范围：长度范围为0~1024的字符串。使用“，”区分不同链接的优先级，如配置2个链路的最大优先级数组1和2，则输入1,2，优先级取值范围为1～32 默认值：无。 配置原则： 仅当本命令的参数“链路选择模式”取值为“ACTIVEWITHPRI”时，该参数有效。当“链接数目”配置超过16条链路时，不支持配置该参数为数组方式。                                                                                                                                                                                    |
| LNKWGHT   | 初始链路权重数组  | 可选必选说明：条件必选参数。 参数含义：用于标识每条链路的权重。 取值范围：长度范围为0~255的字符串。使用“，”区分不同链接的权重，如配置2个链路的权重分别为60和40，则输入60,40，如果不输入，默认值相同，均为50，权重取值范围为1～100 默认值：无。 配置原则： 仅当本命令的参数“链路选择模式”取值为“POLLINGWITHWGT”时，该参数有效。当“链接数目”配置超过16条链路时，不支持配置该参数为数组方式。                                                                                                                                                                     |

## 使用实例

修改“链路集参数ID”为“1”的链路集参数配置，“链接数目”改为“9”，“流数目数组”改为“2147483646”，“链路选择模式”改为“ACTIVEWITHPRI(基于优先级)”，“初始链路优先级数组”为“3,4,5”:

```
MOD HTTPLKSPARA: PARAID=1, LINKNUM=9, STREAMNUM="2147483646",LNKMOD=ACTIVEWITHPRI,POR="3,4,5";
```
