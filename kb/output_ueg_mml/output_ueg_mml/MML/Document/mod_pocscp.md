# 修改PCRF对端OCS接入点实体信息(MOD POCSCP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致业务中断，需联系华为技术支持确认后再执行。

该命令用于修改或调整UPCF网元下的对端OCS接入点的配置信息。

该命令的使用场景：开局场景下，当对端OCS接入点的配置信息在添加的时候由于误操作导致错误，或者系统运行过程中OCS接入点的配置信息发生变更时，可以通过该命令进行修改。

在该命令中，“对端域名”和“对端主机名”参数的配置需要与对端OCS接入点协商一致。

## 注意事项

无。

## 参数说明

| 参数ID          | 参数名称        | 参数描述                                                                                                                                                                                                                    |
|:--------------|:------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PCRFID        | PCRF标识      | 标识一个OCS接入点配置信息的关键字段（其取值不能被修改），用于标识PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围：1 默认值：无。                                                                                                                                   |
| CPID          | 接入点标识       | 标识一个OCS接入点配置信息的关键字段（其取值不能被修改），用于标识对端OCS接入点的接入点标识。该参数必须先由ADD POCSCP命令定义，然后才能在此处索引。 取值范围：0～15 默认值：无。                                                                                                                      |
| CPN           | 接入点名称       | 用于标识一个对端OCS接入点的名称。 取值范围：长度不超过128的字符串。 默认值：无。                                                                                                                                                                            |
| DN            | 对端域名        | 用于标识对端OCS接入点的域名。 该参数的配置原则：该参数需要PCRF与OCS接入点协商一致。该参数的取值不区分大小写，建议使用小写。若使用大写输入，系统会默认以小写的方式进行处理。 取值范围：长度不超过64的字符串。 默认值：无。                                                                                                    |
| HN            | 对端主机名       | 用于标识对端OCS接入点的主机名。 该参数的配置原则：该参数全网唯一，由运营商统一规划。该参数需要PCRF与OCS接入点协商一致。该参数的取值不区分大小写，建议使用小写。若使用大写输入，系统会默认以小写的方式进行处理。 取值范围：长度不超过127的字符串。 默认值：无。                                                                                 |
| DASWITCH      | 审计开关        | 用于标识PCRF与对端OCS接入点对接设备间的审计开关。 取值说明： OFF(关闭定时审计)ON(打开定时审计) 默认值：无。                                                                                                                                                         |
| DATIME        | 设备间审计时长 （m） | 用于标识PCRF与对端OCS接入点对接设备间的审计的时长，当设备间“审计开关”为“ON”时，需要输入“设备间审计时长”。 单位：分钟。 取值范围： 15～1440 默认值： 无。                                                                                                                               |
| CPP           | 接入点优先级      | 用于标识OCS接入点的优先级，优先级值越小，优先级越高。 取值范围：0～255 默认值：无。  说明： 在多个OCS对端上配置优先级，若优先级相同则是轮询关系，优先级不同则是主备关系，UPCF优先将消息发往优先级高的OCS。当OCS上已经存在会话，此时修改OCS对端优先级，导致多个OCS对端的优先级排序与修改前不一样，原OCS上已经存在的会话将保持现有处理，不会迁移到优先级较高的对端。同时，后续新会话按照新优先级排序选择对端。 |
| ABILITYDICTID | 能力字典ID      | 用于配置OCS能力字典。 取值范围：0~15 默认值：无。  说明： 该参数仅支持与UPCF直连的OCS配置，不支持通过DRA与UPCF连接OCS的配置。                                                                                                                                           |

## 使用实例

开局场景下，添加OCS接入点对端的时候，由于误操作导致添加的接入点名称不是拟定的名称，需要通过以下命令修改PCRF对端OCS接入点名称。例如，将“PCRF实体标识”为“1”，“接入点标识”为“0”的OCS接入点的“接入点名称”修改为“ocs”。

```
MOD POCSCP: PCRFID=1, CPID=0, CPN="ocs";
```
