# 查询HLB系统运行模式配置(LST HLBSYSRM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询HLB服务的系统运行模式配置信息。

- 若要查询全部HLB系统运行模式配置信息，请不要输入任何参数。
- 若要查询某个HLB系统运行模式配置信息，请输入“系统运行状态”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                      |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------|
| FS     | 系统运行状态 | 可选必选说明：可选参数 参数含义：用于指定系统的运行模式。 取值范围：ACTIVE(激活模式)：表示可提供业务服务。 DEACTIVE(去激活模式)：即退服，表示不可提供业务服务。 默认值：无。 配置原则：无。 |

## 使用实例

查询系统的运行模式配置信息。

```
LST HLBSYSRM:;
```

```
%%LST HLBSYSRM:;%% 
RETCODE = 0  操作成功  
操作结果如下
------------------------ 
系统运行状态  =  激活模式 
(结果个数 = 1) 
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，参数含义请参见参数说明。
