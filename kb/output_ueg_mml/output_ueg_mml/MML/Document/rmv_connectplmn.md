# 删除互联PLMN(RMV CONNECTPLMN)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

此命令用于删除互联PLMN控制表中某个PLMN。

#### 注意事项

- 此命令执行后立即生效。
- 删除后该PLMN的用户将不能在本USN网元接入，已接入用户不受影响。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                  |
|:----------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MCC       | 移动国家码  | 可选必选说明：必选参数 参数含义：该参数用于指定待删除的互联PLMN的移动国家号码。 取值范围：3位十进制数字 默认值：无                                                                                                         |
| MNC       | 移动网号   | 可选必选说明：必选参数 参数含义：该参数用于指定待删除的互联PLMN的移动网号码。 取值范围：位数为2或3的十进制数字 默认值：无                                                                                                     |
| MATCHIMSI | 匹配IMSI | 可选必选说明：可选参数 参数含义：该参数用于指定除了MCC和MNC外的IMSI的字段。 取值范围：长度不超过10的十进制数字 默认值：无                                                                                                  |
| NOID      | 运营商标识  | 可选必选说明：可选参数 参数含义：该参数用于指定待删除的运营商标识。 取值范围：0~64，128~254 默认值：无 配置原则：若该参数需要配置为0或128～254之间的值时，请先在ADD MNO中配置取值相同的“MNOID”参数。若该参数需要配置为1～64之间的值时，须先在ADD MVNO中配置取值相同的“MVNOID”参数。 |

#### 使用实例

删除互联PLMN，其中，移动国家码为123，移动网号为00：

RMV CONNECTPLMN: MCC="123", MNC="00";
