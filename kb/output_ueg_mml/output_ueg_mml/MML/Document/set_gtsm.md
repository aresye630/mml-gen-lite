# 设置GTSM全局配置属性（SET GTSM）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于设置GTSM全局属性。

GTSM（Generalized TTL Security Mechanism），即通用TTL安全保护机制。GTSM通过检查IP报文头中的TTL值是否在一个预先定义好的范围内，对IP层以上业务进行保护。在实际应用中，用于保护建立在TCP/IP基础上的控制层面（路由协议等）免受CPU利用（CPU-utilization）类型的攻击，如CPU过载（CPU overload）。

#### 注意事项

- 该命令执行后立即生效。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| ACTION   |
|:---------|
| PASS     |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                          |
|:-------|:-------|:------------------------------------------------------------------------------|
| ACTION | 动作行为   | 可选必选说明：必选参数 参数含义：该参数用于指定GTSM动作行为。 数据来源：本端规划 取值范围：枚举类型。 DROP：丢弃。PASS：通过。 默认值：无 |

#### 使用实例

设置GTSM全局属性：

```
SET GTSM:ACTION=DROP;
```
