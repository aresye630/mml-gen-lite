# 添加NRF注册结果码（ADD NRFREGRC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在配置数据库中增加一条NRF注册结果码信息数据记录。

该命令的使用场景：

当软参“VRM\_NRFREGISTERSWITCH”取值为“1”时，需通过该命令增加注册结果码，此场景下，UPCF向NRF发起服务注册请求后，UPCF收到NRF返回的注册结果码为X，该命令配置的NRF注册结果码列表为Y：

- 若X在列表Y中，则表示UPCF不再向该NRF发起服务注册请求。
- 若列表Y为空或者X不在列表Y中，则表示UPCF继续向该NRF发起服务注册请求，发起服务注册请求的时间间隔通过软参“VRM\_NRFREGISTERINTERVAL”设置。

## 注意事项

- 当软参“VRM\_NRFREGISTERSWITCH”取值为“0”时，通过该命令增加的注册结果码无效。
- 命令生效条件：执行该命令立即生效。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                               |
|:-------|:-------|:-------------------------------------------------------------------|
| RC     | 结果码    | 可选必选说明：必选参数 参数含义：用于标识NRF注册结果码。 取值范围：100～199，202～999 默认值：无。 配置原则：无。 |

## 使用实例

增加一条NRF注册结果码信息数据记录，“结果码”为“150”。

```
ADD NRFREGRC: RC=150;
```
