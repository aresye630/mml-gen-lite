# 设置Voice Centric终端接入参数配置（SET VCFUNCPARA）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME****、AMF**

该命令用于设置Voice Centric终端接入参数配置。

#### 注意事项

- 此命令执行后立即生效。
- 当所有必选且不是枚举类型的参数设置为单空格时，本命令恢复系统初始记录。

该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   |   MCC |   MNC |   AUTRLM | EALGPL   |   EXPIRES |   IMPUSIP |   IMPUTEL |
|:-------|------:|------:|---------:|:---------|----------:|----------:|----------:|
| 初始值    |     0 |     0 |      nan | OFF      |         0 |       nan |       nan |

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数ID    | 参数名称       | 参数描述                                                                                                                                                          |
|:--------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MCC     | 移动国家码      | 可选必选说明：必选参数 参数含义：该参数用于指定移动国家号码。 数据来源：整网规划 取值范围：3位十进制数 默认值：无 配置原则：用于AIR（Authentication Information Request）消息中，Visited-PLMN-Id信元携带的参数，该信元由MCC和MNC组成。           |
| MNC     | 移动网号       | 可选必选说明：必选参数 参数含义：该参数用于指定移动网号码。 数据来源：整网规划 取值范围：位数为2或3的十进制数字 默认值：无 配置原则：用于AIR消息中，Visited-PLMN-Id信元携带的参数，该信元由MCC和MNC组成。                                          |
| AUTRLM  | 鉴权域        | 可选必选说明：必选参数 参数含义：该参数用于填写WWW-Authenticate头域realm参数，一般为本设备的本地域名，也就是UE的归属域。 数据来源：本端规划 取值范围：字符串类型，输入长度范围是1~127。 例如：ims.mnc000.mcc123.3gppnetwork.org 默认值：无 配置原则：无 |
| EALGPL  | 加密策略       | 可选必选说明：必选参数 参数含义：该参数用于配置加密策略。 数据来源：本端规划 取值范围： “OFF(关闭)”：表示优选NULL加密算法。 “ON(打开)”：表示优选非NULL加密算法。 默认值：无 配置原则： 当使能IMS-AKA加密策略时，配置ON。当去使能IMS-AKA加密策略时，配置OFF。        |
| EXPIRES | 注册时长       | 可选必选说明：可选参数 参数含义：该参数用于指定注册时长值，单位为秒。 数据来源：本端规划 取值范围：0-864000，设置为0时表示注册时长为3600秒 默认值：无 配置原则：无                                                                    |
| IMPUSIP | IMPU SIP格式 | 可选必选说明：必选参数 参数含义：该参数用于指定要添加的IMPU的值，SIP URI格式。 数据来源：本端规划 取值范围：字符串类型，输入长度范围是1~127 以”sip:”开头，格式：sip:+<MSISDN>@ims.mnc<mnc>.mcc<mcc>.3gppnetwork.org 默认值：无 配置原则：无 |
| IMPUTEL | IMPU TEL格式 | 可选必选说明：必选参数 参数含义：该参数用于指定要添加的IMPU的值，TEL URI格式 数据来源：本端规划 取值范围：字符串类型，输入长度范围是1~127 以”tel:”开头，格式：tel:+<MSISDN> 默认值：无 配置原则：无                                        |

#### 使用实例

设置VC功能参数，设置“移动国家码”为“123”，“移动网号”为“00”，“鉴权域”为“ims.mnc000.mcc123.3gppnetwork.org”，“加密策略”为“OFF(关闭)”，“注册时长”为“3600”，“IMPU SIP格式”为“sip:+1234567890123@ims.mnc000.mcc123.3gppnetwork.org”，“IMPU TEL格式”为“tel:+1234567890123”：

```
SET VCFUNCPARA: MCC="123", MNC="00", AUTRLM="ims.mnc000.mcc123.3gppnetwork.org", EALGPL=OFF, EXPIRES=3600, IMPUSIP="sip:+1234567890123@ims.mnc000.mcc123.3gppnetwork.org", IMPUTEL="tel:+1234567890123";
```
