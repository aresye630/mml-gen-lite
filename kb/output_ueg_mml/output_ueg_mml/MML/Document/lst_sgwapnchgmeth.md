# 查询SGW APN计费方式（LST SGWAPNCHGMETH）

#### 命令功能

**适用NF：SGW-C**

LST SGWAPNCHGMETH命令查询APN下的用户是否产生S-GW话单。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                        |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------|
| APN    | APN名称  | 可选必选说明：可选参数 参数含义：该参数用于指定APN实例名。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格以及特殊字符：“_”、“#”、“$”、“&”等。 默认值：无 配置原则：无 |

#### 使用实例

查询APN实例aa的用户是否打开SGW的离线计费开关，是否生成SGW话单：

```
LST SGWAPNCHGMETH:APN="aa";
```

```
RETCODE = 0  操作成功。

SGW计费方式
-----------
        APN名称  =  aa
APN离线计费开关  =  禁止
(结果个数 = 1)
---    END
```
