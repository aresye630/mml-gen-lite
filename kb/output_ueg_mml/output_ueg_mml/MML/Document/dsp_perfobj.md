#### 命令功能

**适用网元：SGSN、MME**

本命令用于显示特定的TAI组下包含的TAI详细列表。

#### 注意事项

无。

#### 本地用户权限

manage-ug

#### 网管用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                          |
|:------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MOC         | 测量对象类型 | 可选必选说明：必选参数 参数含义：待查询的测量对象类型。 取值范围：“TAIGP(TAI组)” 默认值：无                                                                                                         |
| TAIGPN      | TAI组名  | 可选必选说明：条件必选参数 参数含义：待查询的TAI组测量对象的名称。 前提条件：该参数在“MOC(测量对象类型)”参数设置为“TAIGP(TAI组)”后生效。 取值范围：1~32位字符串 默认值：无                                                          |
| SERVICETYPE | 服务名称   | 可选必选说明：必选参数 参数含义：本参数用于指定服务名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。数字“0~9”，大写字母“A~Z”，小写字母“a~z”，特殊字符“-”，“_”，其他均为非法字符，并且首字符必须为字母。 默认值：无  说明： 该参数可以通过LST VNFC命令查询得到。 |

#### 使用实例

查询系统配置的TAI组“huawei”所包含的TAI详细列表：

DSP PERFOBJ: MOC=TAIGP, TAIGPN="huawei", SERVICETYPE="USN\_VNFC";

```
%%DSP PERFOBJ: MOC=TAIGP, TAIGPN="huawei", SERVICETYPE="USN_VNFC";%%
RETCODE = 0  操作成功。

操作结果如下:
-------------------------
TAI组规则索引	TAI       	

1             308014101	
2             308014111	

(结果个数 = 2)

---    END
```

#### 输出结果说明

| 输出项名称    | 输出项解释                           |
|:---------|:--------------------------------|
| TAI组规则索引 | TAI组下配置的TAI组规则索引。 取值范围：1~1500   |
| TAI      | 该TAI组下包含的所有TAI列表。 取值范围：9~10位字符串 |
