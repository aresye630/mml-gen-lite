# 查询NLF服务系统软参(LST NLFSSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询NLF系统软件参数的配置信息。

- 若需要查询全部软参数据记录的概要信息，请不要输入任何参数。
- 若需要查询某条参数数据记录的详细信息，请输入“系统配置参数”和“参数名”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                               |
|:-------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SCP    | 系统配置参数  | 可选必选说明：可选参数 参数含义：用于指示系统按照系统配置参数来查询NLF系统软参；若不输入，则表示所有的系统配置参数。 取值范围： SYSPARAMETER(系统参数) 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                               |
| SPN    | 参数名     | 可选必选说明：可选参数 参数含义：用于指示系统按照参数名来查询NLF系统软参；若不输入，则表示所有的参数名。 取值范围： VRM_RETENTIONNOTIFYLOG(通知历史文件存留期)VRM_WHITELISTSWITCH(白名单功能开关)VRM_MAXSESSIONNUMPERUSER(单个用户最大SFTP会话个数)VRM_KEEPALIVESWITCH(SFTP保活开关)VRM_EDRSTATSWITCH(EDR统计开关)VRM_NLFSFTPCLIENTACSWITCH(NLF SFTP客户端算法兼容开关)VRM_NLFSFTPSERVERACSWITCH(NLF SFTP服务端算法兼容开关) 详细信息请参考产品手册的“UPCF软件参数 > NLF系统软参”。 默认值：无。 配置原则：无。 |
| SPV    | 参数值     | 可选必选说明：可选参数 参数含义：用于指示系统按照参数值来查询NLF系统软参；若不输入，则表示所有的参数值。 取值范围：0～2147483647 详细信息请参考产品手册的“UPCF软件参数 > NLF系统参数”。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                          |
| DFTV   | 软件参数默认值 | 可选必选说明：可选参数 参数含义：用于指示系统按照软件参数默认值来查询NLF系统软参；若不输入，则表示所有的软件参数默认值。 取值范围：0～2147483647 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                    |

## 使用实例

查询NLF服务软参配置信息。

```
LST NLFSSP:;
```

```

RETCODE = 0  操作成功
```
