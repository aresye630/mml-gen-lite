# 增加UPF位置信息与UPF优先支持的5G TAI范围的绑定关系（ADD LOCBINDN2TAI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于增加UPF位置信息与UPF优先支持的TAI范围的绑定关系。

在用户激活时，SMF从激活请求中获取用户位置信息，在为用户选择UPF时，会优先选择包含用户位置信息的已绑定TAI域的UPF，以获得更好的服务。

## 注意事项

- 使用命令SET UPSELECTFLAG将LOCALITY开关置为ENABLE时生效。

- 同一LOCALITY下，MCC相同且MNC长度不同时，MNC的前两位不允许相同。
- 相同LOCALITY，MCC，MNC的记录，绑定的N2TAC范围不允许重叠。

- 最多可输入16384条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称       | 参数说明                                                                                                                                         |
|:-----------|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------------|
| LOCALITY   | UPF位置区     | 可选必选说明：必选参数  参数含义：该参数用于标识UPF位置区。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~255。  默认值：无  配置原则：  该参数需要与ADD PNFPROFILE命令中 “LOCALITY”的取值保持一致，参数匹配时大小写不敏感。  |
| MCC        | 移动国家码      | 可选必选说明：必选参数  参数含义：该参数用于指定对端NF的移动国家码。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。  默认值：无  配置原则：  本参数由3个十进制数字组成。                                            |
| MNC        | 移动网号       | 可选必选说明：必选参数  参数含义：该参数用于指定对端NF的移动网号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。  默认值：无  配置原则：  本参数由2~3个十进制数字组成。                                       |
| N2TACSTART | N2 TAC起始号段 | 可选必选说明：必选参数  参数含义：该参数用于指定TAC的起始号段。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。不区分大小写。  默认值：无  配置原则：  字符串类型，6位16进制数。  TAC的终止号段需要不小于TAC的起始号段，且结束值和开始值长度需相等。 |
| N2TACEND   | N2 TAC终止号段 | 可选必选说明：必选参数  参数含义：该参数用于指定TAC的终止号段。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。不区分大小写。  默认值：无  配置原则：  字符串类型，6位16进制数。  TAC的终止号段需要不小于TAC的起始号段，且结束值和开始值长度需相等。 |

## 使用实例

新增UPF位置信息与UPF优先支持的TAI范围的绑定关系，其中UPF位置区为“locality1”，MCC为460, MNC为03，N2 TAC起始号段为130101，N2 TAC终止号段为130102。

```
ADD LOCBINDN2TAI: LOCALITY="locality1",MCC="460",MNC="03",N2TACSTART="130101",N2TACEND="130102";
```
