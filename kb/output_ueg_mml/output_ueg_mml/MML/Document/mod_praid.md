# 修改PRA标识(MOD PRAID)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限

- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于修改指定PRA区域的基本信息，例如该PRA区域内本网异地用户的可用属性、PRA区域的描述信息。

#### 注意事项

无

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称       | 参数说明                                                                                                                                                                                                  |
|:---------|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PRAID    | PRA标识      | 可选必选说明：必选参数 参数含义：该参数表示PRA区域的标识。 数据来源：整网规划 取值范围：0x800000～0xFFFFFF 默认值：无                                                                                                                                |
| NONLOCAL | 本网异地用户可用开关 | 可选必选说明：可选参数 参数含义：该参数用以表示本网异地用户是否可用PRA功能。 数据来源：整网规划 取值范围：“OFF(关闭)”“ON(打开)” 默认值:无 配置原则：“ON(打开)”：表示本网异地用户可用PRA功能。“OFF(关闭)”：表示本网异地用户不可用PRA功能。  说明： 当本参数设置为“ON”时，本网异地用户能否使用PRA功能还依赖于PCRF等网元是否启动对该用户的PRA订阅。 |
| PRANAME  | PRA名称      | 可选必选说明：可选参数 参数含义：该参数用于指定PRA名称。 数据来源：整网规划 取值范围：0～32位字符串 默认值：无                                                                                                                                          |

#### 使用实例

配置以“0x800001”为PRA标识的PRA区域基本信息。

MOD PRAID: PRAID="0x800001", NONLOCAL=OFF, PRANAME="praname2";
