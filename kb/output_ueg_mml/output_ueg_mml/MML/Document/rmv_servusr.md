# 模拟设备故障删除用户信息(RMV SERVUSR)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

本命令通过本地删除指定用户的所有数据，删除用户的操作不会通知周边网元以及终端。用于调测"MME链式备份特性"，模拟设备故障场景后该指定用户的业务恢复测试。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                      |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------|
| RMVTP  | 删除方式   | 可选必选说明：可选参数 参数含义：该参数用于指定被删除用户的识别码类型。 数据来源：本端规划 取值范围：“IMSI(指定IMSI)”“IMEI(指定IMEI)” 默认值：无 配置原则：指定IMEI删除仅适用于无USIM卡的紧急呼叫用户。                    |
| IMSI   | IMSI   | 可选必选说明：条件必选参数 参数含义：该参数用于指定被删除用户的国际移动用户识别码，由MCC，MNC，MSIN组成，在PLMN中唯一标识用户。 前提条件：该参数在“删除方式”设置为“IMSI(指定IMSI)”时有效。 数据来源：本端规划 取值范围：0~15位数字 默认值：无 |
| IMEI   | IMEI   | 可选必选说明：条件必选参数 参数含义：该参数用于指定用户设备的国际移动设备标识。 前提条件：该参数在“删除方式”设置为“IMEI(指定IMEI)”时有效。 数据来源：本端规划 取值范围：0~15位数字 默认值：无                                |

#### 使用实例

删除IMSI为123071104000955的用户数据：

RMV SERVUSR: RMVTP=IMSI, IMSI="123071104000955";
