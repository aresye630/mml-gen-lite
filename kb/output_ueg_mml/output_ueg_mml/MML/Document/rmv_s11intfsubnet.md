# 删除S11接口子网配置 (RMV S11INTFSUBNET)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

此命令用于删除S11或S11-U接口的子网配置。

#### 注意事项

- 该命令执行后立即生效。
- 该命令在版本升级过程中禁止执行。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                           |
|:-------|:-------|:---------------------------------------------------------------|
| LNKIDX | 链路关联索引 | 可选必选说明：必选参数 参数含义：该参数用于指定本对端IP地址关联索引。 取值范围：0~65534 默认值：无 配置原则：无 |

#### 使用实例

1. 删除关联索引为0的S11接口子网配置，可以用如下命令：

   ```
   RMV S11INTFSUBNET: LNKIDX=0;
   ```
