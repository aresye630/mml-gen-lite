#### 命令功能

**适用网元：SGSN、MME**

该命令用于显示运营商网络名称。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                                                                             |
|:---------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围     | 可选必选说明：可选参数 参数含义：该参数用于指定用户范围。 数据来源：整网规划 取值范围：“ALL_USER(所有用户)”“IMSI_PREFIX(指定IMSI前缀)”“IMSI_RANGE(指定IMSI范围)” 默认值：无                                                                                 |
| IMSIPRE  | IMSI前缀   | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI前缀。 前提条件：只有“用户范围”参数配置为“IMSI_PREFIX(指定IMSI前缀)”时，该参数才有效。 数据来源：整网规划 取值范围：1～15位十进制数字 默认值：无                                                                             |
| IMSI     | IMSI     | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI，通过该IMSI确定需显示的“IMSI_RANGE(指定IMSI范围)”记录。该IMSI可为待显示“IMSI_RANGE(指定IMSI范围)”内的任意IMSI。 前提条件：只有“用户范围”参数设置为“IMSI_RANGE(指定IMSI范围)”时，该参数才有效。 数据来源：整网规划 取值范围：1～15位十进制数字 默认值：无 |
| PLMNPLCY | PLMN匹配策略 | 可选必选说明：可选参数 参数含义：该参数用于指定在给UE下发网络名称时，是否匹配无线侧PLMN，无线侧是多个运营商等场景下，一般需要根据无线侧PLMN给UE下发不同的网络名称，此时配置该参数为YES。 数据来源：整网规划 取值范围：“NO(否)”“YES(是)” 默认值：无                                                        |
| MCC      | 移动国家码    | 可选必选说明：条件可选参数 参数含义：该参数用于指定无线侧PLMN的移动国家号码。 前提条件：该参数在“PLMN匹配策略”参数配置为“YES(是)”后生效。 数据来源：整网规划 取值范围：3位十进制数字 默认值：无  说明： 该参数仅对WB-E-UTRAN、NB-IoT用户生效。                                                     |
| MNC      | 移动网号     | 可选必选说明：条件可选参数 参数含义：该参数用于指定无线侧PLMN的移动网号码。 前提条件：该参数在“PLMN匹配策略”参数配置为“YES(是)”后生效。 数据来源：整网规划 取值范围：位数为2或3的十进制数字 默认值：无  说明： 该参数仅对WB-E-UTRAN、NB-IoT用户生效。                                                 |

#### 使用实例

查询用户的网络名称配置：

`LST USRMMINFO:;`

```
%%LST USRMMINFO:;%%
RETCODE = 0  操作成功。

输出结果如下
--------------
      用户范围  =  指定IMSI前缀
      IMSI前缀  =  123456
      起始IMSI  =  NULL
      终止IMSI  =  NULL
  PLMN匹配策略  =  否
    移动国家码  =  NULL
      移动网号  =  NULL
    运营商全称  =  bbb
    运营商简称  =  b
(结果个数 = 1)

---    END
```
