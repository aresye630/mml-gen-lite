# 设置SMS配置信息(SET SMS)

#### 命令功能

**适用网元：SGSN**

该命令用于设置SMS相关的参数配置。

#### 注意事项

- 系统初次运行时，会执行系统初始设置值。
- 该命令执行后立即生效。
- 由于受Gd接口中底层定时器时长的限制(28秒)，参数“短消息最大重发次数(SMSMRT)”和“SMMT等待CP\_ACK定时器(TR3)”之间应该满足以下的制约关系：(SMSMRT+1) TR3 < 28000。
- QoS参数取系统初始设置值即可，不需要改动。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

| PT           | QoS最大吞吐量             | 可选必选说明：可选参数 参数含义：该参数用于指定2G SMS QoS最大吞吐量指标。 数据来源：整网规划 取值范围：1~9 系统初始设置值：9                                                                                 |
| MT           | QoS平均吞吐量             | 可选必选说明：可选参数 参数含义：该参数用于指定2G SMS QoS平均吞吐量指标。 数据来源：整网规划 取值范围：1~18 系统初始设置值：18                                                                               |
| SMSMRT       | 短消息最大试发次数            | 可选必选说明：可选参数 参数含义：该参数用于指定短消息最大重发次数。 数据来源：整网规划 取值范围：1~3 系统初始设置值：3                                                                                         |

| TR2          | SMMO等待CP_ACK定时器（ms）  | 可选必选说明：可选参数 参数含义：该参数用于指定SMMO流程中等待手机返回响应消息CP_ACK的时间。 数据来源：整网规划 取值范围：1000~65535 系统初始设置值：6500                                                              |
| TR3          | SMMT等待CP_ACK定时器（ms）  | 可选必选说明：可选参数 参数含义：该参数用于指定SMMT流程中等待手机返回响应消息CP_ACK的时间。 数据来源：整网规划 取值范围：1000~65535 系统初始设置值：6500                                                              |
| TR4          | SMMT等待CP_DATA定时器（ms） | 可选必选说明：可选参数 参数含义：该参数用于指定SMMT流程中等待手机返回响应消息CP_DATA的时间。 数据来源：整网规划 取值范围：1000~65535 系统初始设置值：10000                                                            |
| RSMSCT       | S-SMO-CDR中记录的短消息中心   | 可选必选说明：可选参数 参数含义：该参数用于指定S-SMO-CDR中记录短消息中心号码的方式。 数据来源：整网规划 取值范围：“BEFORECORRECT(请求的短消息中心)”“AFTERCORRECT(纠正的短消息中心)” 系统初始设置值：“BEFORECORRECT(请求的短消息中心)”      |
| SMSODBSCHEME | SMS ODB 限制方案         | 可选必选说明：可选参数 参数含义：该参数用于指定SMS ODB（Operator-Determined-Barring） 限制方案 。 数据来源：整网规划 取值范围：“DESTNUM(根据目的号码限制)”“SMSCNUM(根据短信中心号码限制)” 系统初始设置值：“DESTNUM(根据目的号码限制)” |

#### 使用实例

设置SMS表里的数据：

SET SMS: RC=1, PRI=1, DC=1, PT=9, MT=18, SMSMRT=3, TR1=20000, TR2=6500, TR3=6500, TR4=20000, RSMSCT=BEFORECORRECT, SMSODBSCHEME=DESTNUM;
