# 显示跟踪代理侧跟踪任务信息（DSP TRCAGENTTASK）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示跟踪代理侧跟踪任务信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| PROCESSID       | 进程ID   | 可选必选说明：必选参数 参数含义：进程ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                          |
| TRACETASKID     | 跟踪任务号  | 可选必选说明：可选参数 参数含义：跟踪任务号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967294。 默认值：无                                         |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

显示跟踪代理侧跟踪任务信息：

```
DSP TRCAGENTTASK:PROCESSID=1003,SERVICEINSTANCE="vnfc";
```

```
RETCODE = 0  操作成功

结果如下:
--------
跟踪任务号    跟踪业务类型    组合条件

1             512             1       
2             512             1       
(结果个数 = 2)
---    END
```

|:--------|:--------|

| 跟踪业务类型  | 跟踪业务类型。 |
| 组合条件    | 组合条件。   |
