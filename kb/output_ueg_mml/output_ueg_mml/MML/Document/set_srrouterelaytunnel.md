# 设置静态路由迭代隧道功能开关（SET SRROUTERELAYTUNNEL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于设置静态路由迭代隧道功能开关。

缺省情况下，静态路由只能迭代到出接口和下一跳，不会迭代到隧道。配置了该命令后，静态路由将优先迭代到LSP隧道，如果没有LSP隧道，静态路由也可以迭代到出接口和下一跳。

该命令和SET ROUTERELAYTUNNEL命令迭代隧道使能开关不能同时配置为TRUE。

#### 注意事项

- 该命令执行后立即生效。
- 该命令存在系统初始记录，参数的初始设置值如下表：

|   RELAYENABLE |
|--------------:|
|             0 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                                                               |
|:--------------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------|
| RELAYENABLE   | 迭代隧道使能开关 | 可选必选说明：必选参数 参数含义：该参数用于迭代隧道使能开关。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无                                                    |
| PREFIXNAME    | 前缀列表名    | 可选必选说明：可选参数 参数含义：该参数用于指定前缀列表名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～169。 默认值：无 配置原则： 输入单空格将删除该参数已有配置项。前缀列表需要通过ADD PREFIXFILTERNODE命令提前配置。 |
| TNLPOLICYNAME | 隧道策略名    | 可选必选说明：可选参数 参数含义：该参数用于表示隧道策略名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～39。 默认值：无 配置原则： 输入单空格将删除该参数已有配置项。隧道策略需要通过ADD TUNNELPOLICY命令提前配置。      |

#### 使用实例

设置静态路由迭代隧道功能开关：

```
SET SRROUTERELAYTUNNEL:RELAYENABLE=TRUE,TNLPOLICYNAME="tp";
```
