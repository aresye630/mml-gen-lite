# 查询SRVCC流程限制策略(LST SRVCCLMTPLCY)

- 命令功能

- 本地用户权限

#### 命令功能

**适用网元：MME**

该命令用于查询SRVCC流程限制策略。

#### 注意事项

此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：可选参数 参数含义：该参数用于指定用户范围。 数据来源：整网规划 取值范围： ALL_USER（所有用户）：表示用户范围为系统内所有用户。HOME_USER（本网用户）：表示用户范围为本网用户。FOREIGN_USER（外网用户）：表示用户范围为外网用户。IMSI_PREFIX（指定IMSI前缀）：表示用户范围通过IMSI前缀指定。SPECIFIC_IMSI（指定IMSI）：表示用户范围通过IMSI指定。 默认值：无 配置原则：SRVCC流程限制策略匹配优先级从高到低为：“SPECIFIC_IMSI（指定IMSI）”，“IMSI_PREFIX（指定IMSI前缀）”，“FOREIGN_USER(外网用户)”或“HOME_USER(本网用户)”， “ALL_USER(所有用户)”。 系统优先匹配高优先级的配置记录，如果匹配不到，再匹配低优先级的配置记录。 |
| NOID     | 运营商标识  | 可选必选说明：条件可选参数 参数含义：该参数用于指定运营商标识。 前提条件：该参数在“用户范围”参数配置为“HOME_USER(本网用户)”或“FOREIGN_USER(外网用户)”后生效。 数据来源：整网规划 取值范围：0～64，128～254 默认值：无 配置原则：若该参数需要配置为0或128～254之间的值时，须先在ADD MNO中配置取值相同的“MNOID”参数。若该参数需要配置为1～64之间的值时，须先在ADD MVNO中配置取值相同的“MVNOID”参数。                                                                                                                                                        |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件可选参数 参数含义：该参数用于指定IMSI前缀以区分不同的用户群。 前提条件：该参数在“用户范围”参数配置为“IMSI_PREFIX（指定IMSI前缀）”后生效。 数据来源：整网规划 取值范围：5～14位十进制字符串 默认值：无                                                                                                                                                                                                                                                                         |
| IMSI     | IMSI   | 可选必选说明：条件可选参数。 参数含义：该参数用于指定用户的IMSI（完整IMSI）。 前提条件：该参数在“用户范围”配置为“SPECIFIC_IMSI（指定IMSI）”后生效。 数据来源：全网规划 取值范围：15位十进制字符串 默认值：无 配置原则：无                                                                                                                                                                                                                                                                     |

#### 使用实例

1.查询一条“用户范围”为“ALL\_USER”的流程限制策略配置：

LST SRVCCLMTPLCY: SUBRANGE=ALL\_USER;

```
%%LST SRVCCLMTPLCY: SUBRANGE=ALL_USER;%%
RETCODE = 0  操作成功。

查询结果如下
------------
                 用户范围  =  所有用户
               运营商标识  =  NULL
                 IMSI前缀  =  NULL
                 指定IMSI  =  NULL
    是否限制携带SRVCC能力  =  是
紧急呼叫是否限制SRVCC能力  =  是
(结果个数 = 1)

---    END
```

2.查询全部的流程限制策略配置：

LST SRVCCLMTPLCY:;

```
%%LST SRVCCLMTPLCY:;%%
RETCODE = 0  操作成功。

查询结果如下
------------
用户范围      运营商标识  IMSI前缀         指定IMSI  是否限制携带SRVCC能力  紧急呼叫是否限制SRVCC能力  

所有用户      NULL        NULL             NULL      是                     是
本网用户      0           NULL             NULL      是                     否
指定IMSI前缀  NULL        12345678901234   NULL      是                     是
(结果个数 = 3)

---    END
```
