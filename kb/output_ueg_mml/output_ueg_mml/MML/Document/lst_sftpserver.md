# 查询SFTP服务器(LST SFTPSERVER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询NLF作为SFTP服务器的配置信息。

- 如果需要查询全部NLF作为SFTP服务器的配置信息，请不要输入任何参数。
- 如果需要查询指定NLF作为SFTP服务器的配置信息，请依据参数说明输入查询的条件。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                                                                      |
|:-------|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------|
| ID     | SFTP服务器的索引 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个SFTP服务器的索引来查询NLF作为SFTP服务器的配置信息；若不输入，则表示所有的SFTP服务器的索引。 取值范围：0 默认值：无。 配置原则：无。                                  |
| IPVER  | IP版本       | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个IP版本类型来查询NLF作为SFTP服务器的配置信息；若不输入，则表示所有的IP版本类型。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。                      |
| IP     | IPV4地址     | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV4(IPV4)”时该参数可配置，用于指示系统需要按照哪个IPv4地址来查询NLF作为SFTP服务器的配置信息；若不输入，则表示所有的IPv4地址。 取值范围：IPv4地址 默认值：无。 配置原则：无。       |
| IPV6   | IPV6地址     | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV6(IPV6)”时该参数可配置，用于指示系统需要按照哪个IPv6地址来查询NLF作为SFTP服务器的配置信息；若不输入，则表示所有的IPv6地址。 取值范围：IPv6地址 默认值：无。 配置原则：无。       |
| ADMST  | 管理状态       | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个管理状态来查询NLF作为SFTP服务器的配置信息；若不输入，则表示所有的管理状态。 取值说明： ENABLE(启用)：表示启用SFTP服务。DISABLE(禁用)：表示停止SFTP服务。 默认值：无。 配置原则：无。 |

## 使用实例

查询NLF作为SFTP服务器的配置信息。

```
LST SFTPSERVER:;
```

```
%%LST SFTPSERVER:;%%
RETCODE = 0  操作成功

操作结果如下:
-------------

          IP版本  =  IPV4
        IPV4地址  =  10.168.0.130
        IPV6地址  =  NULL
        管理状态  =  启动
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见ADD SFTPSERVER命令的参数说明。
