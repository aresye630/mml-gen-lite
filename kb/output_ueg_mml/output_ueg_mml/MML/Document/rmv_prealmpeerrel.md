# 删除PEER与PREALMRT关联关系（RMV PREALMPEERREL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响业务处理，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于在配置数据库中删除一条PEER与PREALMRT关联关系的记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                               |
|:-------|:-------|:-----------------------------------|
| RID    | 路由标识   | 用于标识域路由。 取值范围：0～29 默认值：无。          |
| PEERID | 对端标识   | 用于标识Diameter对端实体。 取值范围：0～15 默认值：无。 |

## 使用实例

删除一条PEER与PREALMRT关联关系。“路由标识”为“1”，“对端标识”为“1”。

```
RMV PREALMPEERREL: RID=1, PEERID=1;
```
