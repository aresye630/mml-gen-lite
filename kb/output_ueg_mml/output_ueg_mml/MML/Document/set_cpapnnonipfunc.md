# 设置APN Non-IP功能配置（SET CPAPNNONIPFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C**

此命令用于开启或关闭指定APN的网关Non-IP功能。

## 注意事项

- 该命令执行后立即生效。

- 在每次执行ADD CPAPN命令时会自动为本命令增加一条记录，记录中参数的初始设置值如下：NONIPSWITCH：INHERIT。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称           | 参数说明                                                                                                                                                                                                                            |
|:------------|:---------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN         | APN            | 可选必选说明：必选参数  参数含义：该参数用于指定APN实例名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无。  配置原则：  该参数使用ADD CPAPN命令配置生成。 |
| NONIPSWITCH | APN Non-IP功能开关 | 可选必选说明：可选参数  参数含义：该参数用于基于APN控制开启和关闭Non-IP功能。  数据来源：本端规划 取值范围： INHERIT（继承全局）DISABLE（不使能）ENABLE（使能）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST CPAPNNONIPFUNC查询当前参数配置值。  配置原则：无                                                     |

## 使用实例

使能apn isp的Non-IP功能：

```
SET CPAPNNONIPFUNC:APN="isp",NONIPSWITCH=ENABLE;
```
