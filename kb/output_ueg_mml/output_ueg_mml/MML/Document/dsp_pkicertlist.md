# 显示证书列表（DSP PKICERTLIST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示证书列表。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                      |
|:---------|:-------|:------------------------------------------------------------------------------------------|
| FILETYPE | 文件类型   | 可选必选说明：可选参数  参数含义：文件类型。  数据来源：本端规划 取值范围： “CA（CA证书）”：CA证书“LOCAL（本地证书）”：本地证书  默认值：无  配置原则：无 |
| FILENAME | 文件名称   | 可选必选说明：可选参数  参数含义：文件名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~63。  默认值：无  配置原则：无                |
| PODNAME  | Pod名称  | 可选必选说明：可选参数  参数含义：Pod名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~63。  默认值：无  配置原则：无               |

## 使用实例

显示证书列表：

```
DSP PKICERTLIST:;
RETCODE = 0  操作成功

结果如下
-------------------------
    文件类型  =  本地证书
    文件名称  =  ee1.cer
    Pod名称  =  ipsecexec-pod-0192-168-1-1
(结果个数 = 1)
---    END
```

| 文件名称    | 文件名称。                                         |
| Pod名称   | Pod名称。                                        |
