# 增加全局初始请求计费绑定关系（ADD CPGLBCTXREQRATE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用来配置全局的初始请求URR组名称的计费属性。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为10。
- 配置全局的初始请求URR组名称的计费属性前需要先配置URRGroup。
- 全局下最多可以配置10个计费属性。
- 当前版本不支持此命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称       | 参数说明                                                                                        |
|:---------------|:-----------|:--------------------------------------------------------------------------------------------|
| CTXRURRGRPNAME | 初始请求URR组名称 | 可选必选说明：必选参数 参数含义：该参数用于设置计费属性名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

配置全局的初始请求URR组名称的计费属性，对应的URRGroup为“urrgrp1”：

```
ADD CPGLBCTXREQRATE: CTXRURRGRPNAME="urrgrp1";
```
