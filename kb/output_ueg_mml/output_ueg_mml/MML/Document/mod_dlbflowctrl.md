## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致业务异常，需联系华为技术支持确认后再执行。

该命令用于修改DLB流量控制开关、启控条件等。流控功能会根据当前DLB服务接收Gx接口和Rx接口消息的负荷状态和配置的流控参数信息，自动开启流控和解除流控。

跟踪任务流控也使用本命令进行配置，具体配置规则请参见“UPCF产品文档 > 网络运维 > 故障处理 > UPCF故障定位手段 > 常用故障定位手段 > 消息跟踪 > 基于CPU负载控制消息跟踪任务流控”章节。

该命令的使用场景：当出现系统不稳定，如频繁启控解控，操作员可以使用本命令修改DLB流控参数以使系统保持健康的运行状态，始终提供最大能力的消息响应服务。

## 注意事项

- **启动流控的条件：**
  - CPU占用率大于等于CPU流量控制启控阈值，并且当前时间的DLB接收消息量达到启动流量控制的最小消息量时，会启动DLB流控。
  - 消息时延大于等于时延启控阈值时，会启动DLB流控。
- **解除流控的条件：**

  CPU占用率低于CPU流量控制解控阈值，消息量低于启动流量控制的最小消息量，并且消息时延小于时延解控阈值时，会解除DLB流控。
- 该命令存在系统初始记录，参数的初始设置值如下：
  - “流量控制开关”为“ON”。
  - “CPU启控阈值”为“90”。
  - “CPU解控阈值”为“80”。
  - “启动流量控制的最小消息量”为“1350”。
  - “时延启控阈值”为“50”。
  - “时延解控阈值”为“30”。
- 参数“时延解控阈值”取值为“0”表示关闭时延流控功能。

## 参数说明

| 参数标识      | 参数名称         | 参数说明                                                                                                                                                                  |
|:----------|:-------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FLWCTRFLG | 流量控制开关       | 可选必选说明：必选参数 参数含义：该参数用于设置是否启动DLB流量控制。 取值范围：ON(打开流控)OFF(关闭流控) 默认值：无。 系统初始设置值：ON(打开流控) 配置原则：无。                                                                           |
| CPUFLWSTR | CPU启控阈值      | 可选必选说明：可选参数 参数含义：该参数用于设置需要启动流控时的CPU占用率，仅当本命令中的“流量控制开关”参数为“ON(打开流控)”时该参数有效。 取值范围：10-100 单位：％ 默认值：无。 系统初始设置值：90 配置原则：CPU解控阈值不能比CPU启控阈值大，否则系统产生错误码，配置失效。                 |
| CPUFLWEND | CPU解控阈值      | 可选必选说明：可选参数 参数含义：该参数用于设置需要解除流量控制时的CPU占用率，仅当本命令中的“流量控制开关”参数为“ON(打开流控)”时该参数有效。 取值范围：0-90 单位：％ 默认值：无。 系统初始设置值：80 配置原则：CPU解控阈值不能比CPU启控阈值大，否则系统产生错误码，配置失效。                 |
| MINMSGNUM | 启动流量控制的最小消息量 | 可选必选说明：可选参数 参数含义：该参数用于设置DLB流控达到启控点时的最小消息量，仅当本命令中的“流量控制开关”参数为“ON(打开流控)”时该参数有效。 取值范围：100-65535 单位：TPS 默认值：无。 系统初始设置值：1350 配置原则：该参数设置时不允许高于“系统初始设置值”“1350”。              |
| TSSTR     | 时延启控阈值       | 可选必选说明：可选参数 参数含义：该参数用于设置需要启动流控时的消息延时量，仅当本命令中的“流量控制开关”参数为“ON(打开流控)”时该参数有效。 取值范围：1-2500 单位：毫秒 默认值：无。 系统初始设置值：50 配置原则：时延解控阈值不能比时延启控阈值大，否则系统产生错误码，配置失效。                   |
| TSEND     | 时延解控阈值       | 可选必选说明：可选参数 参数含义：该参数用于设置需要解除流控时的消息延时量，仅当本命令中的“流量控制开关”参数为“ON(打开流控)”时该参数有效。 取值范围：0-1000，取值为“0”表示关闭时延流控功能。 单位：毫秒 默认值：无。 系统初始设置值：30 配置原则：时延解控阈值不能比时延启控阈值大，否则系统产生错误码，配置失效。 |

## 使用实例

修改DLB流控配置。“流量控制开关”为“ON”，“CPU启控阈值”为“90”，“CPU解控阈值”为“85”，“启动流量控制的最小消息量”为“1350”。

```
MOD DLBFLOWCTRL: FLWCTRFLG=ON, CPUFLWSTR=90, CPUFLWEND=85, MINMSGNUM=1350;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|------:|:--------------------|:------------------------------|:----------------------------------|
| 57902 | CPU解控阈值不能比CPU启控阈值大。 | “CPU启控阈值”必须大于或等于“CPU解控阈值”。    | 请将“CPU启控阈值”的值设置为大于或等于“CPU解控阈值”的值。 |
| 58123 | 时延解控阈值不能比时延启控阈值大。   | “时延启控阈值”必须大于或等于“时延解控阈值”。      | 请将“时延启控阈值”的值设置为大于或等于“时延解控阈值”的值。   |
| 58251 | MINMSGNUM参数取值超出范围。  | “MINMSGNUM”参数的值应当在100-1350之间。 | 请将“MINMSGNUM”参数的值设置为100-1350之间。   |
