# 增加目标NF发现和选择的位置匹配信息（ADD NFLOC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

执行该命令，如果参数设置不合理，可能影响AMF优选本DC SMF。

**适用NF：AMF、SMF**

该命令用于为目标NF的发现和选择增加位置匹配相关的信息，即在目标NF的发现和选择过程中，可以基于NF部署的位置做精确或者优先匹配。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入16条记录。
- SMF仅支持通过该指令实现Preferred-Locality发现目标UDM；暂不支持通过该指令实现Preferred-Locality优选PCF等其它目标NF。
- 对于同一个NF，在发现同一种目标NF的时候，只能使用Locality或Preferred Locality其中一种；在同时配置的情况下，以Locality的优先级为高。
- 对于同一个NF的一种位置类型，如果指定了“NF\_ALL”类型的目标NF，则不允许再指定具体的目标NF类型；反之，如果已经指定了具体的目标NF类型，则不允许再配置“NF\_ALL”类型的目标NF。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|:----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFTYPE    | NF类型   | 可选必选说明：必选参数  参数含义：该参数用于表示服务发现的目标NF的请求者的NF类型。  数据来源：全网规划 取值范围： “NfAMF（NfAMF）”：AMF“NfSMF（NfSMF）”：SMF  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| TGTNFTYPE | 目标NF类型 | 可选必选说明：可选参数  参数含义：该参数用于表示目标NF的类型。  数据来源：全网规划 取值范围： “NF_ALL（所有NF）”：所有NF“UDM（UDM）”：UDM“AMF（AMF）”：AMF“SMF（SMF）”：SMF“AUSF（AUSF）”：AUSF“PCF（PCF）”：PCF“SMSF（SMSF）”：SMSF“NSSF（NSSF）”：NSSF“LMF（LMF）”：LMF“GMLC（GMLC）”：GMLC“FIFTHG_EIR（5G_EIR）”：5G_EIR  默认值：NF_ALL  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| LOCTYPE   | 位置类型   | 可选必选说明：可选参数  参数含义：该参数用于表示目标NF发现和选择流程中用作匹配条件的位置类型。  数据来源：全网规划 取值范围： “LOCALITY（位置）”：将位置信息作为仅次于目标NF优先级的策略选择目标NF。“PREFERRED_LOCALITY（优选位置）”：将位置信息作为最高优先级选择目标NF。  默认值：PREFERRED_LOCALITY  配置原则：  在基于位置的NF发现和选择过程中，如果运营商期望以目标NF的位置信息作为第一优选条件，则使用PREFERRED_LOCALITY类型；如果期望以目标NF的优先级作为第一优选条件，位置信息次之，则使用LOCALITY类型。如果运营商期望用点分格式，应使用LOCALITY类型。LOCALITY的点分格式为“大区标识.数据中心标识.资源池标识”。  LOCALITY和PREFERRED_LOCALITY两种目标NF的位置匹配条件都依赖于目标NF配置了位置信息，并注册给了NRF。两者的区别在于：  执行位置匹配的地点不同。LOCALITY是在请求者NF从NRF获取目标NF列表后执行的，而PREFERRED_LOCALITY是在NRF上执行的。说明：基于PREFERRED_LOCALITY选择时，NRF可能仅返回与优选位置匹配的目标NF列表，也可能返回非优选位置匹配的目标NF。华为的NRF支持开关控制（在NRF上通过SET NRFFUNCSW命令中“DISCLOCPREFERSW”和“DISCLOCMATEHSW”控制）。为了防止NRF返回非PREFERRED_LOCALITY匹配的目标NF列表，UNC支持从NRF获取目标NF列表后，本地再按照优选区域匹配目标NF列表。  执行位置匹配的优先级不同。LOCALITY是首先使用优先级筛选后再根据位置进行匹配；而PREFERRED_LOCALITY是首先根据优选位置匹配，随后再针对匹配优选位置的目标NF根据优先级、权重进行选择。 执行位置匹配的算法不同。LOCALITY支持点分格式的字符串，支持指定长度的匹配；而PREFERRED_LOCALITY目标仅支持全字段匹配。 执行位置匹配的依赖条件不同。LOCALITY需要在UNC上打开匹配开关（详见SET NFDISCPLCY的LOCSELECT参数）；而PREFERRED_LOCALITY与NRF上的优选位置功能有关。 |
| PREFERLOC | 优选位置   | 可选必选说明：该参数在"LOCTYPE"配置为"PREFERRED_LOCALITY"时为条件可选参数。  参数含义：该参数用于表示目标NF的优选位置，即在该指定位置中的目标NF将被优先选择。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~128。  默认值：无  配置原则：  如果期望选择的目标NF与请求者NF的位置（Locality）不同，则通过本参数指定目标NF的优选位置（Preferred Locality）；否则无须输入，默认使用与请求者NF相同的Locality（详见ADD CPNFPROFILE）。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| DESC      | 描述信息   | 可选必选说明：可选参数  参数含义：该参数是对本NF配置优选区域的描述信息，在运维中起助记的作用。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~32。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |

## 使用实例

由于网络调整，运营商期望数据中心“DC1”内的AMF为新建的PDU Session选择位于“DC2”数据中心内的SMF，执行如下命令：

```
ADD NFLOC: NFTYPE=NfAMF, TGTNFTYPE=SMF, LOCTYPE=PREFERRED_LOCALITY, PREFERLOC="DC2", DESC="prefer the SMFs of DC2";
```
