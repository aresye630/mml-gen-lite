# 查询时间字符串格式(LST TIMESTRFMT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询时间字符串格式的配置信息，这里的时间格式是指发给用户短消息中显示的时间格式，当前只有一条记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                         |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FMTID  | FMT标识  | 可选必选说明：可选参数 参数含义：用于指定一条时间字符串格式配置记录，因为只有一条记录，此属性的值只能为0。 取值范围：0 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                   |
| FORMAT | 时间日期格式 | 可选必选说明：可选参数 参数含义：用于标识时间字符串格式的编号。 取值范围： FMT1 (MM-DD-YYYY hh:mm:ss)FMT2 (YYYY-MM-DD hh:mm:ss)FMT3 (DD-MM-YYYY hh:mm:ss)FMT4 (MM.DD-YYYY hh:mm:ss)FMT5 (YYYY.MM.DD hh:mm:ss)FMT6 (DD.MM.YYYY hh:mm:ss)FMT7 (MM-DD-YYYY)FMT8 (YYYY-MM-DD)FMT9 (DD-MM-YYYY)FMT10 (MM.DD.YYYY)FMT11 (YYYY.MM.DD)FMT12 (DD.MM.YYYY)FMT13 (YYYYMMDDhhmmss)FMT14 (DD.MM) 默认值：无 配置原则：无 |

## 使用实例

查看时间字符串格式。

```
LST TIMESTRFMT:;
```

```
%%LST TIMESTRFMT:;%%
RETCODE = 0  操作成功

操作结果如下:
------------------------
      FMT标识  =  0
 时间日期格式  =  MM-DD-YYYY hh:mm:ss
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见本命令的参数说明。
