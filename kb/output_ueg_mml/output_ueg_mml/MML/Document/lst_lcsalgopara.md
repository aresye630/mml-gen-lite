# 查询LCS算法参数（LST LCSALGOPARA）

#### 命令功能

**适用NF：UPF**

该命令用于查询用户位置解算的算法开关以及参数配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询所有用户位置解算的算法开关以及参数配置：

```
LST LCSALGOPARA:;
```
