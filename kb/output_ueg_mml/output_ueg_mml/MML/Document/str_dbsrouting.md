# 设置DBS路由目的Location(STR DBSROUTING)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

DBS服务增加一个消息选择路由的命令，下发此命令后，DBS服务消息自动选择到正常的最高优先的BE局点。

## 注意事项

- 对于UDM产品：当FE DSG与DBS配置同一本端Location标识时，需同时执行STR DSGROUTING和STR DBSROUTING命令，且两条命令间隔不超过20s，如果超过，则FE的数据访问无法选择到正常高优先级BE局点。
- 对于UPCF产品：无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                 |
|:------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 业务类型   | 可选必选说明：可选参数。 参数含义：用于设置DBS路由目的Location的业务类型。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：该参数为联想参数列表，不能手动输入，其取值为LST DBSSRVGROUP命令查询获得的“业务类型名称”输出参数。 |

## 使用实例

启动DBS消息选择路由操作。执行命令如下：

```
STR DBSROUTING:;
```

```
%%STR DBSROUTING:;%%
RETCODE = 0  操作成功

操作结果如下
------------------------
 服务模块号         目的Location标识         业务类型         操作结果             

 40                 88                        SUP-FE          操作成功
 41                 88                        SUP-FE          操作成功
(结果个数 = 2)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1的参数说明。

| 输出项名称        | 输出项解释                                                                                                                                                                                                                                         |
|:-------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 服务模块号        | 服务模块号。                                                                                                                                                                                                                                        |
| 目的Location标识 | 目的Location标识。                                                                                                                                                                                                                                 |
| 业务类型         | 用于设置路由目的Location的业务类型。                                                                                                                                                                                                                        |
| 操作结果         | 操作结果。 操作成功操作失败操作超时对端局点为正常的最高优先级局点：表示当前DBS路由目的Location已经是状态正常的最高优先级Location。当前DBS路由目的Location可以通过DSP DBSROUTING命令查询。接管状态不能操作：表示当前USCDB局点处于容灾接管状态，执行该命令失败。 说明： 如果“操作结果”参数显示为“接管状态不能操作”时，需要在接管USCDB上执行STP TAKEOVER停止接管后，再执行本命令设置DBS路由目的Location。 |
