#### 命令功能

**适用网元：MME**

该命令用于查询eNodeB群组成员记录。

#### 注意事项

此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称       | 参数说明                                                                                                                                                                                                                                  |
|:--------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ENBGPID | eNodeB群组标识 | 可选必选说明：可选参数 参数含义：该参数用于指定eNodeB群组标识。 数据来源：本端规划 取值范围：1～2048 默认值：无                                                                                                                                                                       |
| ENBTYPE | eNodeB类型   | 可选必选说明：可选参数 参数含义：该参数用于指定eNodeB类型。 数据来源：整网规划 取值范围：“HOME_ENODEB(Home_eNodeB)”“MACRO_ENODEB(Macro_eNodeB)” 默认值：无                                                                                                                         |
| MCC     | 移动国家码      | 可选必选说明：可选参数 参数含义：该参数用于指定移动国家码 数据来源：整网规划 取值范围：3位的十进制数字 默认值：无                                                                                                                                                                           |
| MNC     | 移动网号       | 可选必选说明：可选参数 参数含义：该参数用于指定移动网号。 数据来源：整网规划 取值范围：2～3位的十进制数字 默认值：无                                                                                                                                                                         |
| ENBID   | eNodeB标识   | 可选必选说明：可选参数 参数含义：该参数用于指定eNodeB标识。 数据来源：整网规划 取值范围：0～268435455 默认值：无  说明： 若参数“eNodeB类型”取值为“HOME_ENB(HOME_ENB)”，则该参数最大取值268435455。若参数“eNodeB类型”取值为“MACRO_ENB(MACRO_ENB)”，则该参数最大取值1048575。查询支持“ENBID”范围匹配，即如果用户输入范围内的某个值，则将该值对应的范围记录显示出来。 |

#### 使用实例

查询所有eNodeB群组成员记录：

LST ENBGPMEM:;

```
%%LST ENBGPMEM:;%%
RETCODE = 0  操作成功。

操作结果如下
--------------
eNodeB群组标识  =  1
    eNodeB类型  =  Macro_eNodeB
    移动国家码  =  456
      移动网号  =  12
起始eNodeB标识  =  1234
终止eNodeB标识  =  1234
(结果个数 = 1)

---    END
```
