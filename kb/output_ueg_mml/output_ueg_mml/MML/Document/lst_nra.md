#### 命令功能

**适用网元：SGSN**

查询空路由区配置表。

#### 注意事项

查询的索引方式为LAI，若查询全部记录，无需输入参数。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                               |
|:-------|:-------|:-------------------------------------------------------------------|
| LAI    | LAI    | 可选必选说明：可选参数 参数含义：该参数用于指定空路由区所在的位置区。 数据来源：整网规划 取值范围：9～10位字符串 默认值：无。 |

#### 使用实例

查询条位置区所有的空路由区配置表记录：

**LST NRA:;**

```
%%LST NRA:;%%
RETCODE = 0  操作成功。

空路由区小区对照表
------------------
 LAI        RAC   

 100000000  0x10  
 100000001  0x10  
 100000002  0x10  
 100000003  0x10  
(结果个数 = 4)

---    END
```
