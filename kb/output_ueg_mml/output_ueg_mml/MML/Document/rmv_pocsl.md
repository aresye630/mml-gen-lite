# 删除PCRF对端OCS接入点链路(RMV POCSL)

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令用于在UPCF网元下删除一条连接PCRF实体与对端OCS接入点实体的链路。

该命令的使用场景：开局场景下，由于误操作UPCF添加了错误的OCS链路，或者在UPCF需要删除当前的OCS接入点对端时，可以使用本命令删除PCRF与OCS接入点之间的链路。

## 注意事项

- 删除PCRF与对端OCS接入点之间的链路，则该链路上的所有的Sy会话会中断，PCRF无法通过Sy接口获取用户的配额状态（Sy类型的配额），对端OCS接入点也无法通过Sy接口通知PCRF配额状态（Sy类型的配额）更改，PCRF将按用户的默认配额状态来计算和下发规则，可能导致用户的计费和策略控制出现偏差。
- 执行该命令，当PCEF与对端OCS的某条链路的“链路管理状态”为“去使能”时，才能成功删除该链路；否则删除失败。

## 参数说明

| 参数ID   | 参数名称   | 参数描述                                                                             |
|:-------|:-------|:---------------------------------------------------------------------------------|
| PCRFID | PCRF标识 | 标识一条链路配置信息的关键字段，用于标识PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围：1 默认值：无。          |
| CPID   | 接入点标识  | 标识一条链路配置信息的关键字段，用于标识对端OCS接入点实体。该参数必须先由ADD POCSCP命令定义，然后才能在此处索引。 取值范围：0～15 默认值：无。 |
| LNKID  | 链路ID   | 标识一条链路配置信息的关键字段，用于标识一条PCRF实体与对端OCS接入点实体间的链路。 取值范围：0～67 默认值：无。                    |

## 使用实例

开局场景下，由于添加了错误的链路信息，UPCF需要删除链路时，需要进行如下配置。当前链路的“PCRF标识”为“1”，“接入点标识”为“0”，“链路ID”为“0”。

1. 执行**LST POCSL**命令查询PCRF与对端OCS接入点之间的链路配置信息。若PCRF与对端OCS接入点间不存在链路，则不需要执行以下操作。否则，查询当前链路对应的“链路管理状态”是否为“去使能”。
   - 是 => 步骤 3
   - 否 => 步骤 2
2. 执行**MOD POCSL**将“链路管理状态”置为“去使能”。

   ```
   MOD POCSL: PCRFID=1, CPID=0, LNKID=0, ADSTS=DISABLE;
   ```
3. 执行**RMV POCSL**删除当前的PCRF与对端OCS接入点间链路。

   ```
   RMV POCSL: PCRFID=1, CPID=0, LNKID=0;
   ```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                             | 原因分析                             | 处理建议                                                                          |
|------:|:----------------------------------|:---------------------------------|:------------------------------------------------------------------------------|
| 57853 | 需要删除的链路的“链路管理状态”必须是“去使能”时，才能删除链路。 | 需要删除的链路的“链路管理状态”为“使能”，导致该命令执行失败。 | 执行命令LST POCSL查询指定链路的“链路管理状态”。如果确定要删除此链路，可以通过MOD POCSL将“链路管理状态”置为“去使能”，再执行本命令。 |
