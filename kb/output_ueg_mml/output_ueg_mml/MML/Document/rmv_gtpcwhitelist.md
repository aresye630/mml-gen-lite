# 删除GTP-C路径白名单(RMV GTPCWHITELIST)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

本命令用于删除GTP-C路径白名单。

#### 注意事项

本命令执行后对新的SRVCC流程生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                       |
|:-------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| INTFTP | 接口类型     | 可选必选说明：必选参数 参数含义：本参数用于指定对端IP地址所属的接口类型。 数据来源：全网规划 取值范围：“Sv(Sv)” 默认值：无                                                                       |
| IPT    | IP地址类型   | 可选必选说明：必选参数 参数含义：本参数用于指定IP地址类型。 数据来源：全网规划 取值范围：“IPV4(IPV4)”“IPV6(IPV6)” 默认值：无                                                              |
| LIPV4  | 本端IPv4地址 | 可选必选说明：条件必选参数 参数含义：本参数用于指定本端IPv4地址。 前提条件：本参数在"IP地址类型"参数配置为"IPV4(IPV4)"后生效。 数据来源：全网规划 取值范围：0.0.0.0~255.255.255.255 默认值：无                    |
| PIPV4  | 对端IPv4地址 | 可选必选说明：条件必选参数 参数含义：本参数用于指定对端IPv4地址。 前提条件：本参数在"IP地址类型"参数配置为"IPV4(IPV4)"后生效。 数据来源：全网规划 取值范围：0.0.0.0~255.255.255.255 默认值：无                    |
| LIPV6  | 本端IPv6地址 | 可选必选说明：条件必选参数 参数含义：本参数用于指定本端IPv6地址。 前提条件：本参数在"IP地址类型"参数配置为"IPV6(IPV6)"后生效。 数据来源：全网规划 取值范围：::~FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 |
| PIPV6  | 对端IPv6地址 | 可选必选说明：条件必选参数 参数含义：本参数用于指定对端IPv6地址。 前提条件：本参数在"IP地址类型"参数配置为"IPV6(IPV6)"后生效。 数据来源：全网规划 取值范围：::~FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 |

#### 使用实例

删除GTP-C路径白名单的一条配置。

RMV GTPCWHITELIST: INTFTP=Sv, IPT=IPV4, LIPV4="192.168.23.67", PIPV4="192.168.123.4";
