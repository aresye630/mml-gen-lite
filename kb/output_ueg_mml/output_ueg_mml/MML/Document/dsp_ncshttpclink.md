# 查询NCS缓存中的HTTP客户端链路（DSP NCSHTTPCLINK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询NCS缓存中的HTTP客户端链路信息。

请依据参数说明输入查询条件，查询NCS缓存中的HTTP客户端链路信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                              |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFTYPE | NF类型   | 可选必选说明：必选参数 参数含义：用于指示系统需要按照哪个NF类型来查询NCS缓存中的HTTP客户端链路信息。 取值范围： NRF(NRF)AMF(AMF)SMF(SMF)BSF(BSF)CHF(CHF)AF(AF)SCP(SCP)UDR(UDR)NWDAF(NWDAF)HPCF(HPCF) 默认值：无。 配置原则：无。 |
| PEERID | 对端标识   | 可选必选说明：必选参数 参数含义：用于指示系统需要按照哪个对端标识来查询NCS缓存中的HTTP客户端链路信息。操作员可以使用LST PEERNF命令查询“对端标识”获得。 取值范围：0~1023 默认值：无。 配置原则：无。                                                  |
| INSTID | 实例ID   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个NCS实例ID来查询NCS缓存中的HTTP客户端链路信息；若不输入，则表示所有的NCS实例ID。操作员可以使用DSP SDRSERVICE命令查询获得，“APPTYPE”参数取值为“3504”。 取值范围：长度不超过32位的字符串 默认值：无。 配置原则：无。   |
| STATE  | 状态     | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个状态来查询NCS缓存中的HTTP客户端链路信息；若不输入，则表示所有的状态。 取值范围： ONLINE(在线)OFFLINE(离线) 默认值：无。 配置原则：无。                                                    |

## 使用实例

- 查询“NF类型”为“SMF”，“对端标识”为“0”的NCS缓存中的HTTP客户端链路信息。

  ```
  DSP NCSHTTPCLINK: NFTYPE=SMF, PEERID=0;
  ```

  ```
  %%DSP NCSHTTPCLINK: NFTYPE=SMF, PEERID=0;%%
  RETCODE = 0  操作成功

  操作结果如下
  ------------
  NF类型  对端标识  链路标识  HLB实例ID                协议类型  本端IP地址      本端端口号  对端IP地址      对端端口号  状态    链路管理状态  

  SMF     0         0         11944584739713132856     HTTP      10.194.39.220   40022       10.195.39.221   10501       在线    使能          
  SMF     0         1         11944584739713132855     HTTP      10.194.39.220   40029       10.195.39.221   10501       在线    使能            
  (结果个数 = 2)

  ---    END
  ```

- 查询“NF类型”为“SMF”，“对端标识”为“0”，“实例ID”为“12444584739713132856”的NCS缓存中的HTTP客户端链路信息。

  ```
  DSP NCSHTTPCLINK: NFTYPE=SMF, PEERID=0, INSTID="12444584739713132856";
  ```

  ```
  %%DSP NCSHTTPCLINK: NFTYPE=SMF, PEERID=0, INSTID="12444584739713132856";%%
  RETCODE = 0  操作成功

  操作结果如下
  ------------
        NF类型  =  SMF
      对端标识  =  0

     HLB实例ID  =  11944584739713132856
      协议类型  =  HTTP
    本端IP地址  =  10.194.39.220
    本端端口号  =  40022
    对端IP地址  =  10.195.39.221
    对端端口号  =  10501
          状态  =  在线
  链路管理状态  =  使能
  (结果个数 = 1)

  ---    END
  ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义如表1。

| 输出项名称   | 输出项解释                                                                                                                        |
|:--------|:-----------------------------------------------------------------------------------------------------------------------------|
| NF类型    | 用于表示NF类型。 取值范围： NRFAMFSMFBSFCHFAFSCPUDRNWDAFHPCF                                                                             |
| 对端标识    | 用于表示对端标识。 取值范围：0~1023                                                                                                        |
| 链路标识    | 用于表示链路标识。 取值范围：0~127                                                                                                         |
| HLB实例ID | 用于表示HLB的实例ID。 取值范围：长度不超过32位的字符串                                                                                              |
| 协议类型    | 用于表示NF使用的协议。 取值范围： HTTPHTTPS                                                                                                 |
| 本端IP地址  | 用于表示本端的IP地址。 取值范围：IPv4地址/IPv6地址                                                                                              |
| 本端端口号   | 用于表示本端的端口号。  说明： 如果SET HTTPCLIENTCFG命令设置了“链路重建模式”为“CHANGEPORT(更换端口)”，则不同时间使用DSP NCSHTTPCLINK命令查询NCS缓存中的HTTP客户端链路时本端端口号可能会不同。 |
| 对端IP地址  | 用于表示对端的IP地址。 取值范围：IPv4地址/IPv6地址                                                                                              |
| 对端端口号   | 用于表示对端的端口号。                                                                                                                  |
| 状态      | 用于表示链路的状态。 取值范围： 在线离线                                                                                                        |
| 链路管理状态  | 用于表示链路管理状态。 取值范围： 使能去使能                                                                                                      |
