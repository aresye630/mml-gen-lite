# 增加UE USAGE TYPE群组(ADD UEUSGTYPEGP)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令增加一条UE USAGE TYPE群组记录，用于在**ADD DNSN**中辅助进行DNS查询。需要结合**ADD UEUSGTYPEGPMEM**命令为UE USAGE TYPE群组添加成员。

#### 注意事项

- 该命令执行后立即生效。
- 此命令最大记录数为1024。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称              | 参数说明                                                                                                     |
|:--------------|:------------------|:---------------------------------------------------------------------------------------------------------|
| UEUSGTYPEGPID | UE USAGE TYPE群组标识 | 可选必选说明：必选参数 参数含义：该参数用于指定UE USAGE TYPE群组标识。 数据来源：本端规划 取值范围：0~1023 默认值：无 配置原则：“UE USAGE TYPE群组标识”在本MME内唯一。 |
| DESC          | 描述                | 可选必选说明：可选参数 参数含义：该参数用于指定UE USAGE TYPE群组的描述信息。 数据来源：本端规划 取值范围：1~32位字符串 默认值：noname                         |

#### 使用实例

运营商规划网络，增加一个“UE USAGE TYPE群组标识”为“1”，群组名称为“eMtc”的UE USAGE TYPE群组：

ADD UEUSGTYPEGP: UEUSGTYPEGPID=1, DESC="eMtc";
