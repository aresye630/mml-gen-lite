# 增加APNNI组(ADD APNNIGROUP)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于增加APNNI组信息。关联了该组的APNNI可以被基于延迟定时器的信令拥塞控制特性和Non-IP数据传输特性使用。

#### 注意事项

- 此命令执行后立即生效。
- 该命令最大记录数为16。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称    | 参数说明                                                            |
|:-------|:--------|:----------------------------------------------------------------|
| GRPID  | APNNI组号 | 可选必选说明：必选参数 参数含义：该参数用于指定APNNI组号。 数据来源：本端规划 取值范围：0～15 默认值：无      |
| DESC   | 描述      | 可选必选说明：可选参数 参数含义：APNNI描述信息。 数据来源：本端规划 取值范围：0～256位字符串 默认值：noname |

#### 使用实例

运营商希望增加新的组号为2的APNNI组来管理APNNI成员信息，描述为“M2M APNNI Group”，则设置“APNNI组号”参数为“2”、“描述”参数为“M2M APNNI Group”。运行如下命令：

ADD APNNIGROUP: GRPID=2, DESC="M2M APNNI Group";
