# 修改PCF的业务服务区（MOD PCFSSCOPE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、PGW-C、GGSN**

该命令用于修改PCF的业务服务区。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                             |
|:-----------|:-------|:-------------------------------------------------------------------------------------------------|
| SSCOPEID   | 服务区标识  | 可选必选说明：必选参数  参数含义：该参数用于指定服务区标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。不区分大小写，转为小写存储。  默认值：无  配置原则：无 |
| SSCOPENAME | 服务区名称  | 可选必选说明：可选参数  参数含义：该参数用于指定服务区名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~50。 区分大小写。  默认值：无  配置原则：无        |

## 使用实例

修改服务区标识为citya的PCF业务服务区，把服务区名称修改为CityA。

```
MOD PCFSSCOPE: SSCOPEID="citya", SSCOPENAME="CityA";
```
