# 查询HTTP统计参数（LST HTTPSTATPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询进行统计的HTTP对端地址。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                      |
|:-----------|:---------|:----------------------------------------------------------------------------------------------------------|
| PEERIPTYPE | 对端IP地址类型 | 可选必选说明：可选参数  参数含义：该参数用于指定对端IP地址类型。  数据来源：全网规划 取值范围： “IPv4（IPv4）”：IPv4地址“IPv6（IPv6）”：IPv6地址  默认值：无  配置原则：无 |

## 使用实例

查询HTTP统计的对端IP地址，执行命令如下：

```
%%LST HTTPSTATPARA:;%%
RETCODE = 0  操作成功

结果如下
--------

```
