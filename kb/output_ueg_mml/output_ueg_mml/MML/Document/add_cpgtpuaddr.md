# 增加CP GTP-U地址（ADD CPGTPUADDR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C、SMF、GGSN**

该命令用于增加与UPF对接的本端用户面地址。

## 注意事项

- 该命令执行后立即生效。

- IPv4和IPv6最多可以分别输入1条记录。
- 当UPLOGICINTF的IPVERSION为V4V6时，IPVERSION需配置为IPv6。
- IP地址和VPN名称必须在LOGICIP表中已经配置，可以用LST LOGICIP查询。

- 最多可输入2条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                                     |
|:----------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPVERSION | IP地址类型 | 可选必选说明：必选参数  参数含义：该参数用于指定与UPF对接的本端GTP-U IP地址类型。  数据来源：全网规划 取值范围： IPV4（IPv4）IPV6（IPv6）  默认值：无  配置原则：无                                                                                                                                     |
| IPV4ADDR  | IPv4地址 | 可选必选说明：该参数在"IPVERSION"配置为"IPV4"时为条件必选参数。  参数含义：该参数用于指定与UPF对接的本端GTP-U IPv4地址。  数据来源：全网规划  取值范围：IPv4地址类型。IPv4地址类型。业务地址不能配置为0.0.0.0、255.255.255.255和环回地址(127.x.y.z)。业务地址必须是A、B或者C类地址。  默认值：无  配置原则：无                                        |
| IPV6ADDR  | IPv6地址 | 可选必选说明：该参数在"IPVERSION"配置为"IPV6"时为条件必选参数。  参数含义：该参数用于指定与UPF对接的本端GTP-U IPv6地址。  数据来源：全网规划  取值范围：IPv6地址类型。IPv6地址类型。IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址(::1)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。  默认值：无  配置原则：无 |
| VPN       | VPN名称  | 可选必选说明：可选参数  参数含义：该参数用于指定与UPF对接的本端GTP-U使用的VPN名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~31。  默认值：_public_  配置原则：无                                                                                                                               |

## 使用实例

添加一个与UPF对接的本端GTP-U地址，IPv4地址为192.168.0.20：

```
ADD CPGTPUADDR:IPVERSION=IPV4,IPV4ADDR="192.168.0.20";
```
