# 查询 UP 参数信息（LST UPINFO）

- 命令功能

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用来查看UPF相关配置属性。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查看UPF相关配置属性：

```
LST UPINFO:;
```

```
RETCODE = 0  操作成功

UP  参数配置
------------
                 名称 = upf27
IPv6地址类型的Node Id = ::
IPv4地址类型的Node Id = 0.0.0.0
(结果个数 = 1)
---    END
```
