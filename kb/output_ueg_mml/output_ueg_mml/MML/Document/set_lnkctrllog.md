# 设置链路控制消息日志开关(SET LNKCTRLLOG)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：AMF**

该命令用于设置链路控制消息日志开关。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                          |
|:-------|:-------|:----------------------------------------------------------------------------------------------|
| SCTP   | SCTP   | 可选必选说明：可选参数 参数含义：该参数用于控制链路控制消息日志开关是否开启。 数据来源：全网规划 取值范围： ON（开启） OFF（关闭） 系统初始设置值：ON（开启） 配置原则： 无 |

#### 使用实例

若要关闭链路控制消息日志开关，可以用如下命令：

```
SET LNKCTRLLOG: SCTP=OFF;
```
