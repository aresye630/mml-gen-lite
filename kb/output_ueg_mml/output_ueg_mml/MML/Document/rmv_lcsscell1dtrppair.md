# 删除LCS小站一维算法TRP（RMV LCSSCELL1DTRPPAIR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于删除LCS小站一维算法的TRP配置。

#### 注意事项

- 该命令执行后立即生效。
- 执行该命令时，不会校验TRPID1和TRPID2两个参数的顺序，若输入的两个参数和添加时的两个参数只是顺序不一致，该记录会被成功删除。
- 执行该命令后，重新发起定位请求时修改生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                |
|:---------|:-------|:------------------------------------------------------------------------------------|
| GNODEBID | 基站标识   | 可选必选说明：必选参数 参数含义：该参数用于设置基站标识。 数据来源：全网规划 取值范围：整型数字类型，取值范围为0~4294967295。 默认值：无 配置原则：无 |
| TRPID1   | TRP标识1 | 可选必选说明：必选参数 参数含义：该参数用于设置TRP标识。 数据来源：全网规划 取值范围：整型数字类型，取值范围为1~65535。 默认值：无 配置原则：无     |
| TRPID2   | TRP标识2 | 可选必选说明：必选参数 参数含义：该参数用于设置TRP标识。 数据来源：全网规划 取值范围：整型数字类型，取值范围为1~65535。 默认值：无 配置原则：无     |

#### 使用实例

删除LCS小站一维算法的TRP配置：

```
RMV LCSSCELL1DTRPPAIR: GNODEBID=190041, TRPID1=1, TRPID2=2;
```
