# 查询网元S-Nssai信息(LST UDMNFSNSSAI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询网元S-Nssai信息。

- 若需要查询某个S-Nssai的详细信息，请输入“索引”参数。
- 若需要查询某个组的S-Nssai信息，请输入“组名称”参数。
- 若需要查询所有S-Nssai的信息，不输入任何参数。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GRPNAME | 组名称    | 可选必选说明：可选参数 参数含义：用于指定需要根据哪一个组名称标识来查询网元S-Nssai信息；若不输入，则表示查询所有组名称。 取值范围：长度不超过32的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 参数来源：该参数由本端UDM自行定义。 默认值：无。 配置原则：该参数和“索引”参数组成全局唯一对象关键字段。 |
| INDEX   | 索引     | 可选必选说明：可选参数 参数含义：用于指定需要根据哪一个索引标识来查询网元S-Nssai信息；若不输入，则表示查询所有索引。 取值范围：1~1024。 参数来源：该参数由本端UDM自行定义。 默认值：无。 配置原则：该参数和“组名称”参数组成全局唯一对象关键字段。                                |

## 使用实例

1. 查询所有S-Nssai信息：

   ```
   LST UDMNFSNSSAI:;
   ```

   ```
   %%LST UDMNFSNSSAI:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   组名称       索引  分片业务类型  切片区分器  

   nfsnssai_01  200   200           a00200      
   nfsnssai_01  201   201           a00201      
   nfsnssai_01  202   202           a00202      
   nfsnssai_01  203   203           a00203      
   nfsnssai_01  205   205           a00205      
   nfsnssai_02  206   206           a00206      
   (结果个数 = 6)

   ---    END
   ```
2. 查询特定S-Nssai信息，“索引”为“200”：

   ```
   LST UDMNFSNSSAI: INDEX=200;
   ```

   ```
   %%LST UDMNFSNSSAI: INDEX=200;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
         组名称  =  nfsnssai_01
           索引  =  200
   分片业务类型  =  200
     切片区分器  =  a00200
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD UDMNFSNSSAI**命令的参数说明。
