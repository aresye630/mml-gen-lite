## 命令功能

**须知** 

此命令是高危命令，多次连续执行可能会导致系统过载，需联系华为技术支持确认后再执行。

该命令用于刷新NTS服务的全局数据。NTS服务每隔一段时间（通过软参“VRM\_GLBREFLASHINTERVAL”设置）会自动进行一次全局数据校验，当发现NTS缓存的数据和数据库中全局数据不一致时，操作员可以通过手动执行该命令，强制刷新NTS服务的全局数据。

## 注意事项

多FE场景下，每个FE执行时需要间隔1分钟以上。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PODNAME | POD名称  | 可选必选说明：可选参数 参数含义：用于指定POD名称中的NTS服务进行强制全局数据刷新，如果不指定POD名称，所有的NTS服务均进行强制全局数据刷新。 取值范围：长度不超过256的字符串。 默认值：无。 配置原则：无。 NTS服务对应的POD名称可以通过执行DSP POD命令获取，具体查询方式举例如下：DSP POD: TYPE=byType, PODTYPE="pcf-addn", MEID="235"; %%DSP POD: TYPE=byType, PODTYPE="pcf-addn-pod", MEID="235";%% RETCODE = 0 操作成功 操作结果如下 ------------ Pod名称 Pod类型 Pod状态 节点名称 pcf-addn-pod235-8f7674cf-fzbfd pcf-addn-pod Running fd0e:135:164:123::112 pcf-addn-pod235-8f7674cf-m9zvj pcf-addn-pod Running fd0e:135:164:123::117 (结果个数 = 2) --- END  说明： 对于同一个POD名称中的NTS服务重复执行该命令，系统会直接返回成功，不中断正在执行的刷新任务。 |

## 使用实例

同步NTS微服务的全局数据。

```
SYN NTSGLBDATA:;
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。
