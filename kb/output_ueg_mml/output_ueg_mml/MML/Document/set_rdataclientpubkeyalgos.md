# 设置数据同步客户端公钥算法（SET RDATACLIENTPUBKEYALGOS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于设置数据同步客户端支持的公钥算法和主机密钥算法。在登陆远端数据同步服务器时，本地客户端和对端服务器协商公钥和主机密钥算法。协商会选择服务器和客户端都支持的算法。如果服务器和客户端没有相同的算法，则协商失败。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 可选参数至少配置一个。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | SSH_ED25519   | SSH_ED25519_OPENSSH   | RSA_SHA2_256   | RSA_SHA2_512   |
|:-------|:--------------|:----------------------|:---------------|:---------------|
| 初始值    | True          | True                  | True           | True           |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

设置数据同步客户端支持的公钥算法，开启SSH\_ED25519、SSH\_ED25519\_OPENSSH、RSA\_SHA2\_256、RSA\_SHA2\_512公钥算法：

```
SET RDATACLIENTPUBKEYALGOS: SSH_ED25519=TRUE, SSH_ED25519_OPENSSH = TRUE, RSA_SHA2_256=TRUE, RSA_SHA2_512=TRUE;
```
