# 查看园区用户数据同步策略（LST EDGEDSPOLICY）

- 命令功能
- 注意事项
- 操作用户权限

- 输出结果说明

#### 命令功能

**适用NF：UDM**

显示园区用户数据同步策略。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

显示园区UDM用户数据同步策略：

```
LST EDGEDSPOLICY:;
```
