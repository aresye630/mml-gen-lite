# 查询Home Group和APN的绑定关系（LST HOMEGRPBINDAPN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、GGSN**

该命令用来查询APN实例与Home Group的绑定关系。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识          | 参数名称         | 参数说明                                                                                                                                                                                                                                                |
|:--------------|:-------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN           | APN          | 可选必选说明：必选参数  参数含义：该参数用于指定APN实例名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“ ” ”、“ ` ”特殊字符，不区分大小写。  默认值：无  配置原则：  该参数使用ADD CPAPN命令配置生成。 |
| HOMEGROUPINDX | Home Group编号 | 可选必选说明：可选参数  参数含义：该参数用来设置Home Group的编号。  数据来源：本端规划  取值范围：整数类型，取值范围是1~128。  默认值：无  配置原则：  该参数使用ADD HOMEGROUP命令配置生成。                                                                                                                                  |

## 使用实例

- 查询“APN”为“huawei.com”，“Home Group编号”为“1”的Home Group和APN的绑定关系配置：

  ```
  %%LST HOMEGRPBINDAPN: APN="huawei.com", HOMEGROUPINDX=1;%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
             APN  =  huawei.com
  Home Group编号  =  1
  (结果个数 = 1)

  ---    END
  ```
- 查询“APN”为“huawei.com”的全部Home Group和APN的绑定关系配置：

  ```
  %%LST HOMEGRPBINDAPN: APN="huawei.com";%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
  APN         Home Group编号  

  huawei.com  1                 
  huawei.com  2                 
  huawei.com  3                 
  (结果个数 = 3)

  ---    END
  ```
