# 刷新BGP对等体（SYN BGPPEER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于刷新指定BGP对等体信息。

当BGP配置发生变化后，如果需要使新的配置立即生效，可以执行SYN BGPPEER命令。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                                            |
|:--------------|:---------|:----------------------------------------------------------------------------------------------------------------|
| VRFNAME       | VPN实例名称  | 可选必选说明：可选参数 参数含义：该参数用于指定VPN名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：_public_ 配置原则：使用LST L3VPNINST命令查看可用VPN。    |
| AFTYPE        | BGP地址族类型 | 可选必选说明：必选参数 参数含义：该参数用于指定BGP地址族类型。 数据来源：本端规划 取值范围：枚举类型。 ipv4uni：IPv4地址族。ipv4vpn：VPNv4地址族。ipv6vpn：VPNv6地址族。 默认值：无 |
| DIRECTION     | 方向       | 可选必选说明：必选参数 参数含义：该参数用于指定刷新BGP路由信息的方向。 数据来源：本端规划 取值范围：枚举类型。 export：出口。import：入口。 默认值：无                           |
| REMOTEADDRESS | 对等体地址    | 可选必选说明：可选参数 参数含义：该参数用于指定对等体地址。 数据来源：对端协商 取值范围：IPv4地址类型。 默认值：无                                                   |

#### 使用实例

刷新BGP对等体：

```
SYN BGPPEER:VRFNAME="_public_",AFTYPE=ipv4uni,DIRECTION=export,REMOTEADDRESS="10.1.1.1";
```
