# 查询设备间的快速审计状态(DSP AUDITSTATUS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

在执行了**SND AUDIT**命令后，可以通过该命令查询设备间的快速审计的实际情况。

## 注意事项

如果在审计过程中同时有用户上下线的情况，可能会导致查询结果显示不准确。

## 参数说明

无。

## 使用实例

查询设备间的快速审计状态。

```
DSP AUDITSTATUS:;
```

```
%%DSP AUDITSTATUS:;%%
RETCODE = 0  操作成功

操作结果如下：
--------------
实例号     状态  完成率  需要处理的总个数  已经处理的个数  

538885690  空闲  NULL    0                 0               
538893643  空闲  NULL    0                 0                           
(结果个数 = 2)

共有2个结果
共有3个报告
---    END
```

## 输出结果说明

| 参数名称     | 参数说明                                                                                                             |
|:---------|:-----------------------------------------------------------------------------------------------------------------|
| 实例号      | 用于描述当前查询结果中的实例号。                                                                                                 |
| 状态       | 用于描述当前PES服务中执行快速审计的状态。状态包括：空闲、处理中、异常终止。 空闲：表示当前没有快速审计任务在执行。处理中：表示快速审计任务正在执行。异常终止：表示快速审计任务未执行完成。可再次执行SND AUDIT命令。 |
| 完成率      | 用于描述当前PES服务中执行快速审计的完成比率。 取值范围包括：NULL：表示当前没有快速审计任务在执行。0%～99%：表示快速审计任务执行的进度。                                       |
| 需要处理的总个数 | 用于描述当前PES服务中需要处理的总在线会话个数。                                                                                        |
| 已经处理的个数  | 用于描述当前PES服务中已经处理的在线会话个数。                                                                                         |
