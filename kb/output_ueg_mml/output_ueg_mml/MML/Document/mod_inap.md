# 修改内部审计参数(MOD INAP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于修改或调整配置数据库中内部审计参数的配置数据记录。

## 注意事项

无。

## 参数说明

| 参数标识            | 参数名称     | 参数说明                                                                                                                                                                                                                |
|:----------------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APID            | 内部审计参数标识 | 用于指定一条内部审计参数配置记录，因为只有一条记录，此属性的值只能为0。 取值范围：0 默认值：无。                                                                                                                                                                  |
| AUDITTIME       | 审计时间     | 其值域类型为时间类型，用于指示每天定时发起内部审计的时间点。 取值范围：长度不超过8的字符串 默认值：无。 初始值：03:00:00。  说明： 修改“审计时间”只对PES服务生效。假设“审计时间”为T1，则PES服务的各模块分别启动审计的时间点为：BLC：T1+10分钟+30秒ALC：T1+30秒NGSRV：T1+10分钟+30秒UPM：T1+10分钟+0.15秒                            |
| AUTOAUDITSWITCH | 自动增强审计开关 | 用于设置是否启动自动增强审计。 取值范围： YES(开启自动增强审计)NO(不开启自动增强审计) 默认值：YES  说明： 自动增强审计功能支持LICENSE审计和哈希审计两种类型的审计。哈希审计的自动增强审计功能受到本参数和“VRM_HASHAUDITSWITCH”软参控制，即本参数取值为“YES(开启自动增强审计)”时，若“VRM_HASHAUDITSWITCH”取值为“0”，则哈希审计的自动增强审计功能不会触发。 |

## 使用实例

修改内部审计参数配置。内部审计参数标识为“0”，审计时间为“03:30:00”，自动增强审计开关为“YES(开启自动增强审计)”。

```
MOD INAP: APID=0, AUDITTIME=03&30&00, AUTOAUDITSWITCH=YES;
```
