# 增加防欺诈可信DNS服务器（ADD AFDNSSERVER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于配置可信的DNS服务器IP，用于从DNS响应中学习应用服务器IP地址。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为20。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称         | 参数说明                                                                                                                                    |
|:----------|:-------------|:----------------------------------------------------------------------------------------------------------------------------------------|
| IPVERSION | IP地址版本类型     | 可选必选说明：必选参数 参数含义：该参数用于指定IP地址版本类型。 数据来源：本端规划 取值范围：枚举类型。 IPV4：IPv4地址类型。IPV6：IPv6地址类型。 默认值：无 配置原则：无                                        |
| IPV4ADDR  | DNS服务器IPv4地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV4”时为必选参数。 参数含义：该参数用于指定IPv4地址。 数据来源：本端规划 取值范围：IPv4地址类型。采用点分十进制"X.X.X.X"格式。 默认值：无 配置原则：无         |
| IPV6ADDR  | DNS服务器IPv6地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV6”时为必选参数。 参数含义：该参数用于指定IPv6地址。 数据来源：本端规划 取值范围：IPv6地址类型。采用冒号分十六进制X:X:X:X:X:X:X:X格式。 默认值：无 配置原则：无 |

#### 使用实例

设置防欺诈功能可信的DNS server地址：

```
ADD AFDNSSERVER:IPVERSION=IPV4,IPV4ADDR="192.168.0.1";
```
