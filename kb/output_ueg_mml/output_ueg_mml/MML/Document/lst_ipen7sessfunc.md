# 查询智能双N7会话特性是否使能（LST IPEN7SESSFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF、PGW-C**

该命令用于查询智能双N7会话特性是否使能。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询智能双N7会话特性是否使能：

```
%%LST IPEN7SESSFUNC:;%%
RETCODE = 0  操作成功

结果如下
--------
智能N7会话特性开关  =  使能
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称       | 输出项解释        |
|:------------|:-------------|
| 智能双N7会话特性开关 | 智能双N7会话特性开关。 |
