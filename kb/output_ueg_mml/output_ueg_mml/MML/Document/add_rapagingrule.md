# 增加基于路由区的寻呼参数设置(ADD RAPAGINGRULE)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

本命令用于增加基于路由区的2/3G寻呼参数，优先级高于整系统设置的2G(**SET GMM**)和3G(**SET PMM**)寻呼策略。

#### 注意事项

- 对某些路由区大量终端用户聚集的情况下，针对这些路由区执行本命令设置较小的“N3313”和“T3313”，可以降低大量的寻呼对无线侧设备造成的压力。
- 同一RAI(MCC+MNC+LAC+RAC)可以配置多条记录，但同一RAI(MCC+MNC+LAC+RAC)的多条记录的WKDAY＋STARTTIME+ENDTIME指定的时间区域不能重叠。
- 本表最大记录数为100。
- 如果启用特殊寻呼参数的区域与系统不在同一时区，则需要先将该区域时间转换成系统本地时间后再配置。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称         | 参数说明                                                                                                                                                                                                                                                                         |
|:------------|:-------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MCC         | 移动国家代码       | 可选必选说明：必选参数 参数含义：该参数用于指定移动国家代码。 数据来源：整网规划 取值范围：位数为3的十进制数字 默认值：无                                                                                                                                                                                                              |
| MNC         | 移动网号         | 可选必选说明：必选参数 参数含义：该参数用于指定移动网号。 数据来源：整网规划 取值范围：位数为2或3的十进制数字 默认值：无                                                                                                                                                                                                              |
| LAC         | 位置区域码        | 可选必选说明：必选参数 参数含义：该参数用于指定位置区域码。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无                                                                                                                                                                                                            |
| RAC         | 路由区域码        | 可选必选说明：必选参数 参数含义：该参数用于指定路由区域码。 数据来源：整网规划 取值范围：0x00～0xFF 默认值：无                                                                                                                                                                                                                |
| WKDAY       | 星期序号         | 可选必选说明：必选参数 参数含义：该参数用于指定寻呼策略生效的一星期中的某一天。 数据来源：整网规划 取值范围：“MON(星期一)”“TUES(星期二)”“WED(星期三)”“THURS(星期四)”“FRI(星期五)”“SAT(星期六)”“SUN(星期日)” 默认值：无                                                                                                                                      |
| STARTTIME   | 起始时间         | 可选必选说明：必选参数 参数含义：该参数用于指定寻呼策略生效的起始时间。 数据来源：整网规划 取值范围：00&00～23&59 默认值：无  说明： “起始时间”必须在“终止时间”之前，而且不能相等。                                                                                                                                                                         |
| ENDTIME     | 终止时间         | 可选必选说明：必选参数 参数含义：该参数用于指定寻呼策略生效的终止时间。 数据来源：整网规划 取值范围：00&00～23&59 默认值：无  说明： “起始时间”必须在“终止时间”之前，而且不能相等。                                                                                                                                                                         |
| T3313       | T3313（s）     | 可选必选说明：可选参数 参数含义：此定时器用于控制SGSN发起寻呼与MS响应的时间间隔。 数据来源：整网规划 取值范围：4～20 默认值：“6”  说明： 对于3G，在SGSN发送PAGING REQUEST消息后启动，在收到SERVICE REQUEST(PAGING RESPONSE)消息后停止，超时后，SGSN重发PAGING REQUEST消息；对于2G，在SGSN发送PAGING REQUEST消息后启动，在收到MS的任意的LLC消息(非NULL FRAME)后停止，超时后，SGSN重发PAGING REQUEST消息。 |
| N3313       | N3313（times） | 可选必选说明：可选参数 参数含义：该参数用于指定在寻呼流程中，没有收到MS的响应消息，SGSN重复发送PAGING REQUEST消息的次数。 数据来源：整网规划 取值范围：0～5 默认值：“2”  说明： 若将N3313调整为低于SET GMM和SET PMM原配置值，可能会导致这些路由区内的寻呼成功率降低。                                                                                                                 |
| PAGINGDELTA | 重寻呼间隔递增值（s）  | 可选必选说明：可选参数 参数含义：该参数用于指定在寻呼流程中，没有收到MS的响应消息，SGSN重复发送PAGING REQUEST消息的间隔递增时间值。 数据来源：整网规划 取值范围：0～20 默认值：“0”                                                                                                                                                                     |
| RADESC      | 描述           | 可选必选说明：可选参数 参数含义：本参数指定本路由区的简要描述，用于帮助解释本记录指定的物理位置。 数据来源：整网规划 取值范围：长度不超过32的字符串 默认值：“noname”                                                                                                                                                                                    |

#### 使用实例

对于“移动国家代码”为“123”，“移动网号”为“03”，“位置区域码”为“0x113”，“路由区域码”为“0x3E”的路由区设置“星期序号”为“SAT(星期六)”，“起始时间”为“18&00”，“终止时间”为“20&00”，寻呼策略参数配置为“T3313(s)”为“6”、“N3313(times)”为“2”、“重寻呼间隔递增值(s)”为“4”，“描述”为“stadium”：

ADD RAPAGINGRULE: MCC="123", MNC="03", LAC="0x113", RAC="0x3E", WKDAY=SAT, STARTTIME=18&00, ENDTIME=20&00, T3313=6, N3313=2, PAGINGDELTA=4, RADESC="stadium";
