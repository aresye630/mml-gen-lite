# 增加服务模块号(ADD DBSSERVICENO)

## 命令功能

**须知** 

该命令属于高危命令，该操作可能会导致业务中断。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于增加服务模块号信息。

该命令的使用场景：服务模块号唯一标识网元所属的dbbroker，用于和远端DSG建立链路。

## 注意事项

在删除某个服务模块号对应的配置信息后，如果需要再次使用相同模块号增加配置信息，请在5分钟后执行本命令增加配置信息，否则将会上报错误码“48033 SDK响应错误，请联系华为技术支持。”。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                                        |
|:--------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICENO     | 服务模块号  | 可选必选说明：必选参数 参数含义：用于指定网元对应dbbroker微服务的模块号，该服务模块号在系统中唯一。 取值范围：1～1024 默认值：无。 配置原则：当HLR/HSS服务和dbbroker共Location时，dbbroker上ADD DBSSERVICENO添加的服务模块号不能和HLR/HSS服务上ADD MODULE添加的DSG模块号重复。                           |
| PODNAME       | POD名称  | 可选必选说明：必选参数 参数含义：用于指定网元所属的POD名称，该POD名称在系统中唯一。该参数可以通过执行DSP PODINFO命令输出的DBS相关“容器类型”对应的“Pod标识”获取。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：当同一个POD下同时配置多个“服务模块号”时，可能会导致建链异常。因此，建议同一个POD下只配置一个“服务模块号”。                    |
| CONTAINERFLAG | 容器标志   | 可选必选说明：可选参数 参数含义：当一个POD中存在4个容器时，该参数用于指定网元所属的容器标志。 取值范围：长度不超过32的字符串。该参数的取值在UDM产品的VNFD文件中定义，不支持通过命令修改，具体为“P1”“P2”、“P3”、“P4”。 默认值：无。 配置原则：当一个POD和容器的组合下同时配置多个“服务模块号”时，可能会导致链路异常。因此，建议一个POD和容器的组合下只配置一个“服务模块号”。 |
| PROCESSID     | 进程号    | 可选必选说明：可选参数 参数含义：用于指定网元所属的dbbroker微服务进程号。 取值范围：0～1 默认值：0 配置原则：虚拟机场景下，“进程号”的取值范围为“0”。裸机场景下“进程号”的取值范围为“0～1”。                                                                                                  |

## 使用实例

在开局场景下，增加服务模块号，“服务模块号”为“321”，“POD名称”为“dbs-a-pod217-0”:

```
ADD DBSSERVICENO: SERVICENO=321, PODNAME="dbs-a-pod217-0";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                    | 原因分析                            | 处理建议                                                                                           |
|-------:|:-----------------------------------------|:--------------------------------|:-----------------------------------------------------------------------------------------------|
|  48033 | SDK响应错误，请联系华为技术支持。                       | 删除某个服务模块号对应的配置信息后未等待5分钟再增加配置信息。 | 请5分钟后再重新执行ADD DBSSERVICENO添加配置信息。                                                              |
|    503 | 配置数据已存在。                                 | 输入的“服务模块号”已存在。                  | 执行LST DBSSERVICENO命令查询已存在的“服务模块号”。重新输入“服务模块号”，确保取值与查询结果中不重复。                                   |
| 302594 | 该PODNAME、CONTAINERFLAG与PROCESSID的组合已被配置。 | 输入的“POD名称”、“容器标识”和“进程号”的组合已被配置。 | 执行LST DBSSERVICENO命令查询当前已存在的“POD名称”、“容器标识”和“进程号”的组合。重新输入“POD名称”、“容器标识”和“进程号”组合，确保与查询结果中的组合不重复。 |
