# 删除HTTP域名配置（RMV HTTPLEHOST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于从配置数据库中删除一条HTTP实体域名配置信息数据记录。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

删除HTTP实体域名配置信息可能会造成GBA功能无法正常使用，用户业务访问交互操作信息无法正常转发，请谨慎操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                           |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------|
| LEID   | 本端实体标识 | 用于标识一条HTTP域名配置信息数据记录的关键字段，用于指定需要删除哪一条本端HTTP实体数据记录，操作员可以使用LST HTTPLEHOST命令查询获得。 取值范围：0～255。 默认值：无。 注意：该参数为必选参数。 |

## 使用实例

删除一条HTTP域名配置信息数据记录，“本端实体标识”为“1”：

执行命令如下：

```
RMV HTTPLEHOST: LEID=1;
```
