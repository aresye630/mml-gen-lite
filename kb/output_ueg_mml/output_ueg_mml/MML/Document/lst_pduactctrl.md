# 查询PDU会话激活控制参数（LST PDUACTCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询基于DNN配置PDU会话激活处理策略。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                       |
|:---------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围     | 可选必选说明：可选参数  参数含义：该参数用于指定用户范围。  数据来源：全网规划 取值范围： “ALL_USER（所有用户）”：所有用户。“HOME_USER（本网用户）”：本网用户。“FOREIGN_USER（外网用户）”：外网用户。“IMSI_PREFIX（IMSI前缀）”：IMSI前缀。“SPECIFIC_IMSI（指定IMSI）”：指定IMSI。  默认值：无  配置原则：无                                                                                                                         |
| IMSIPRE  | IMSI前缀   | 可选必选说明：该参数在"SUBRANGE"配置为"IMSI_PREFIX"时为条件可选参数。  参数含义：该参数用于指定IMSI前缀。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是5~14。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                                                                                                                                                                     |
| IMSI     | IMSI     | 可选必选说明：该参数在"SUBRANGE"配置为"SPECIFIC_IMSI"时为条件可选参数。  参数含义：该参数用于指定IMSI。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是14~15。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                                                                                                                                                                    |
| DNNTYPE  | DNN类型    | 可选必选说明：可选参数  参数含义：该参数用于指定请求DNN类型。  数据来源：全网规划 取值范围： “ALL_DNN（所有DNN）”：表示请求DNN为任意DNN。“NOT_NULL_DNN（非空DNN）”：表示请求DNN为非空DNN。“NULL_DNN（空DNN）”：表示请求DNN为空DNN。“SPECIAL_DNN（指定DNN）”：表示请求DNN为指定DNN。  默认值：无  配置原则：  请求DNN为空时，选择“NULL_DNN”。  请求DNN为非空时，选择“NOT_NULL_DNN”。  请求DNN为指定DNN时，选择“SPECIAL_DNN”。  请求DNN包括空DNN和非空DNN时，选择“ALL_DNN”。 |
| DNN      | 用户请求的DNN | 可选必选说明：该参数在"DNNTYPE"配置为"SPECIAL_DNN"时为条件可选参数。  参数含义：该参数用于指定用户请求的DNN。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。可输入的字符有字母、十进制数字、“-”和“.”，并且开头和结尾只能是数字或者字母。不能出现连续两个“.”。字母大小写不敏感。  默认值：无  配置原则：无                                                                                                                                      |

## 使用实例

查询基于DNN配置PDU会话激活处理策略，执行如下命令：

```
%%LST PDUACTCTRL:;%%
RETCODE = 0  操作成功

结果如下
------------------------
用户范围     IMSI前缀     IMSI             DNN类型     用户请求的DNN    处理策略  拒绝原因值  

本网用户     NULL         NULL             空DNN       NULL             直接拒绝  0             
指定IMSI     NULL         123456789012345  指定DNN     HUAWEI.COM       直接拒绝  0             
(结果个数 = 2)

---    END
```

## 输出结果说明

| 输出项名称    | 输出项解释                                   |
|:---------|:----------------------------------------|
| 用户范围     | 该参数用于指定用户范围。                            |
| IMSI前缀   | 该参数用于指定IMSI前缀。                          |
| IMSI     | 该参数用于指定IMSI。                            |
| DNN类型    | 该参数用于指定请求DNN类型。                         |
| 用户请求的DNN | 该参数用于指定用户请求的DNN。                        |
| 处理策略     | 该参数用于控制整体策略，是直接拒绝激活，还是在签约数据匹配失败后进行纠正处理。 |
| 拒绝原因值    | 该参数用于控制拒绝PDU会话激活时下发给UE的原因值。             |
