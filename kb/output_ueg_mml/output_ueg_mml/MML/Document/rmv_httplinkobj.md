# 删除HTTP链路测量对象(RMV HTTPLINKOBJ)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于删除一条HTTP链路测量对象记录。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                |
|:----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| WORKMODE  | 工作模式   | 可选必选说明：必选参数 参数含义：用于指定需要删除记录的HTTP链路的工作模式，操作员可以使用LST HTTPLINKOBJ命令查询获得。 取值范围： SERVER(服务端)CLIENT(客户端) 默认值：无。 配置原则：无。                                                                                                   |
| LOCALIP   | 本端IP地址 | 选必选说明：必选参数 参数含义：用于指定需要删除记录的HTTP链路的本端IP地址，操作员可以使用LST HTTPLINKOBJ命令查询获得。 取值范围：IPv4地址/IPv6地址 默认值：无。 配置原则：当IP地址类型为IPv6地址时，配置该参数时需要将IP地址当中的“:”替换为“-”，字母不支持小写，且不支持自动补0。IPv6地址配置示例：FC00-0000-0000-4007-0156-0110-0006-0123 |
| LOCALPORT | 本端端口   | 选必选说明：必选参数 参数含义：用于指定需要删除记录的HTTP链路的本端端口，操作员可以使用LST HTTPLINKOBJ命令查询获得。 取值范围：0~65535 默认值：无。 配置原则：无。                                                                                                                    |
| PEERIP    | 对端IP地址 | 选必选说明：必选参数 参数含义：用于指定需要删除记录的HTTP链路的对端IP地址，操作员可以使用LST HTTPLINKOBJ命令查询获得。 取值范围：IPv4地址/IPv6地址 默认值：无。 配置原则：当IP地址类型为IPv6地址时，配置该参数时需要将IP地址当中的“:”替换为“-”，字母不支持小写，且不支持自动补0。IPv6地址配置示例：FC00-0000-0000-4007-0156-0110-0006-0123 |
| PEERPORT  | 对端端口   | 选必选说明：必选参数 参数含义：用于指定需要删除记录的HTTP链路的对端端口，操作员可以使用LST HTTPLINKOBJ命令查询获得。 取值范围：0~65535 默认值：无。 配置原则：无。                                                                                                                    |

## 使用实例

1. 执行**LST HTTPLINKOBJ**命令，查询系统中已存在的HTTP链路测量对象记录。

   ```
   LST HTTPLINKOBJ:;
   ```
2. 删除1中查询出来的一条HTTP链路测量对象记录。下面以“工作模式”为“CLIENT(客户端)”，“本端IP地址”为“10.194.39.220”，“本端端口”为“40022”，“对端IP地址”为“10.195.39.221”，对端端口为“10501”的HTTP链路测量对象为例。

   ```
   RMV HTTPLINKOBJ: WORKMODE=CLIENT, LOCALIP="10.194.39.220", LOCALPORT=40022, PEERIP="10.195.39.221", PEERPORT=10501;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如下表1所示。

|   错误码 | 消息解释          | 原因分析                     | 处理建议                                                  |
|------:|:--------------|:-------------------------|:------------------------------------------------------|
|   505 | 当前操作的配置数据不存在。 | 要删除的HTTP链路测量对象记录在系统中不存在。 | 执行LST HTTPLINKOBJ命令查询系统中已存在的HTTP链路测量对象记录，重新执行本命令删除记录。 |
