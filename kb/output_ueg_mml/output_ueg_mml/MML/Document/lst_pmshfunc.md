# 查询策略管理服务高级功能配置信息(LST PMSHFUNC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询系统是否已支持系统的Pm接口或Rest接口功能。

## 注意事项

无。

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                               |
|:-------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FUNCID       | 功能ID   | 可选必选说明：可选参数 参数含义：用于表示系统支持的功能项标识。 取值范围： PmCLIPolicyRestPolicy 默认值：无。 配置原则：无。                                                                                                        |
| VALUE        | 值      | 可选必选说明：可选参数 参数含义：用于表示系统支持的功能项值。 取值范围：0～1 当“功能ID”为“PmCLIPolicy”时，取值范围如下：0：表示不支持Pm接口获取策略脚本。1：表示支持Pm接口获取策略脚本。 当“功能ID”为“RestPolicy”时，取值范围如下：0：表示不启用Rest接口。1：表示启用Rest接口。 默认值：无。 配置原则：无。 |
| DEFAULEVALUE | 缺省值    | 可选必选说明：可选参数 参数含义：用于表示系统支持的缺省值。 取值范围：0～1 默认值：无。 配置原则：无。                                                                                                                             |

## 使用实例

查询策略管理服务高级功能配置信息。

```
LST PMSHFUNC:;
```

```
%%LST PMSHFUNC:;%%
RETCODE = 0  操作成功

操作结果如下:
------------
功能ID        值     缺省值
PmCLIPolicy   1      0
RestPolicy    0      0
(结果个数 = 2)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见参数说明。
