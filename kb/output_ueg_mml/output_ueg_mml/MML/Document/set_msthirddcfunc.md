## 命令功能

**须知** 

- 本命令属于高危命令，执行不当会造成全部业务呼损。执行之前请确认当前局点是否作为冷备局点。如有疑问请与华为技术支持确认后才可以实施。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。
- 执行之前请确认是否为冷备局点，请确认是否需要设置为接管状态或冷备状态。

该命令用于设置5G局点容灾类型和容灾状态，与**SET THIRDDCFUNC**命令共同使用。在主用大区双DC（Data Center）故障或省际链路全阻场景下，考虑使用5GC网和IMS网络单独部署的第三容灾DC接管大区业务。

## 注意事项

- UDM最多同时接管一个大区的业务。
- 新建FE的容量选择待接管大区中容量最大的一套。

- 该命令与**SET THIRDDCFUNC**命令共同使用才能生效，配置时两个命令的“局点类型”参数、“容灾状态”参数必须配置为相同取值。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                |
|:--------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LOCALFUNC     | 局点类型   | 可选必选说明：必选参数 参数含义：用于指定5G局点的容灾类型。 取值范围： NORMAL(普通)DC(冷备) 默认值：无。 配置原则：无。                                                                                                                                                                                                                               |
| THIRDDCSTATUS | 容灾状态   | 可选必选说明：条件必选参数 参数含义：用于指定5G局点的容灾状态。 取值范围： NULL(NULL)DCSTATUS(冷备状态)：备份其他局点业务。TAKEOVERSTATUS(接管状态)：接管备份局点业务。 默认值：无。 配置原则： 当本命令中的“局点类型”参数为“NORMAL(普通)”时，该参数取值为“NULL(NULL)”。当本命令中的“局点类型”参数为“DC(冷备)”时，该参数取值为“DCSTATUS(冷备状态)”或“TAKEOVERSTATUS(接管状态)”其中之一。当该参数取值为“DCSTATUS(冷备状态)”时，不再处理业务。修改之前请确认当前是否还有业务消息。 |

## 使用实例

设置局点的冷备5G功能参数，将“局点类型”取值为“DC(冷备)”，“容灾状态”取值为“DCSTATUS(冷备状态)”。

```
SET MSTHIRDDCFUNC: LOCALFUNC=DC, THIRDDCSTATUS=DCSTATUS;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
