# 停止时延统计任务（STP DELAYSTAT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响系统性能，需联系华为技术支持确认后再执行。

该命令用于停止统计各消息流程的时延信息。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                     |
|:------------|:-------|:-------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 服务类型   | 可选必选说明：必选参数 参数含义：该参数用于指定微服务实例的服务类型。 取值范围：PcfPolicyEngineService(PcfPolicyEngineService) 默认值：无。 配置原则：无                    |
| INSTANCEID  | 实例号    | 可选必选说明：可选参数 参数含义：用于指定停止时延统计任务时微服务的实例号。 取值范围：0~256长度字符串 默认值：无。  说明： 本参数如果为空则对所有实例都生效，参数可以通过查询服务信息（DSP SERVICEINFO）命令查询获取。 |

## 使用实例

停止正在执行时延任务统计操作，“实例号”为“4218287”

```
STP DELAYSTAT: SERVICETYPE=PcfPolicyEngineService, INSTANCEID="4218287";
```

```
%%STP DELAYSTAT: SERVICETYPE=PcfPolicyEngineService, INSTANCEID="4218287";%%

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
