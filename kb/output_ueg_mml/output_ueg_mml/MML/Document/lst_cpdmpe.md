#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询Diameter对端实体配置。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                            |
|:--------|:-------|:--------------------------------------------------------------------------------|
| PEERIDX | 对端实体索引 | 可选必选说明：可选参数 参数含义：该参数用于指定Diameter对端实体索引。 取值范围：0～639 默认值：无  说明： 如果不输入，表示查询所有配置记录。 |

#### 使用实例

查询所有Diameter对等端实体配置：

LST CPDMPE:;

```
%%LST CPDMPE:;%%
RETCODE = 0  操作成功。

操作结果如下
------------

1               example01.com                 NULL          S6a/S6d           关闭

```
