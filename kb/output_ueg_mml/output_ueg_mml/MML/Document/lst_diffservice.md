# 查询差异化服务接入门限(LST DIFFSERVICE)

- 命令功能
- 注意事项
- 本地用户权限

#### 命令功能

**适用网元：SGSN**

该命令用于查询差异化服务配置信息。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AT     | 接入类型   | 可选必选说明：必选参数 参数含义：该参数用于设置待查询的用户接入门限或者PDP接入门限。 取值范围： “USER(用户接入)”：差异化服务触发类型为用户类型“PDP(PDP接入)”：差异化服务触发类型为PDP类型 默认值： 无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| USRPRI | 用户级别   | 可选必选说明：条件可选参数 参数含义：该参数用于指定待查询的用户签约QoS属性中的分配保留优先级（Allocation/Retention Priority）。 前提条件：此参数在“AT”设置为“USER(用户接入)”或“PDP(PDP接入)”时生效。 取值范围： “HIGHLEVELUSER(高端用户)”：分配保留优先级为1。“NORMALUSER(普通用户)”：分配保留优先级为2。“LOWLEVELUSER(低端用户)”：分配保留优先级为3。 默认值：无  说明： 不输入该参数时，查询所有用户级别的接入门限。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| SRVLVL | 业务级别   | 可选必选说明：条件可选参数 参数含义：待查询的业务级别，由用户PDP上下文QoS中的流量等级（Traffic class）、下行保证速率（Guaranteed bit rate for downlink）和发送控制优先级（Traffic handling priority）确定。 前提条件：此参数在“接入类型”选取为“PDP(PDP接入)”时生效。 取值范围：“CONVERSATION(Conversation)”：流量等级为Conversational class。“STREAMINGGBRMORE25KBPS(StreamGBRMore25kbps)”：流量等级为Streaming class，下行保证速率大于等于25kbit/s。“STREAMINGGBRLESS24KBPS(StreamGBRLess24kbps)”：流量等级为Streaming class，下行保证速率小于等于24kbit/s。“INTERACTIVETRAFFICPRI1(InteractiveTrafficPri1)”：流量等级为Interactive class，发送控制优先级为1。“INTERACTIVETRAFFICPRI2(InteractiveTrafficPri2)”：流量等级为Interactive class，发送控制优先级为2。“INTERACTIVETRAFFICPRI3(InteractiveTrafficPri3)”：流量等级为Interactive class，发送控制优先级为3。“BACKGROUND(Background)”：流量等级为Background class。“NONE(None)”：通用业务级别，表示该用户没有业务级别，设置的门限就是该用户级别所有业务级别的门限。 默认值：无  说明： 不输入该参数时，查询所有业务级别的接入门限。 |

#### 使用实例

查询以“PDP方式”接入，用户级别为“高端用户”，业务级别为“Background”的差异化服务配置信息：

LST DIFFSERVICE: AT=PDP, USRPRI=HIGHLEVELUSER, SRVLVL=BACKGROUND;

```
%%LST DIFFSERVICE: AT=PDP, USRPRI=HIGHLEVELUSER, SRVLVL=BACKGROUND;%%
RETCODE = 0  操作成功。

-------------------------------------

            业务级别  =  Background

PDP数负荷恢复门限(%)  =  10
(结果个数 = 1)

---    END
```
