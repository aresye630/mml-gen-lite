# 增加计费消息属性模板（ADD RDSACCTATTTEMP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用来新增计费消息属性模板。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为3。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称                        | 参数说明                                                                                                                                                               |
|:-------------|:----------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ATTRTEMPNAME | 计费消息属性模板名字                  | 可选必选说明：必选参数 参数含义：该参数用于指定计费消息属性模板名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无                                                                                 |
| RULEBASENAME | 支持携带属性Charge-Rule-Base-Name | 可选必选说明：可选参数 参数含义：指定是否支持携带信元Charge-Rule-Base-Name。 数据来源：本端规划 取值范围：枚举类型。 CRBN：携带该信元且取值为CRBN。CFCATE：URL过滤分类组名。DISABLE：不支持携带该信元。MULTI_CRBN：携带多个CRBN信元。 默认值：CRBN 配置原则：无 |

#### 使用实例

新增名为“RDSACCTATTTEMP”的计费消息属性模板，支持携带属性Charge-Rule-Base-Name为DISABLE：

```
ADD RDSACCTATTTEMP: ATTRTEMPNAME="RDSACCTATTTEMP", RULEBASENAME=DISABLE;
```
