# 增加APN智能分流关键词（ADD APNINTELSHUNT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C**

该命令用于增加APN智能分流关键词。

## 注意事项

- 该命令执行后立即生效。

- 每个APN下最多配置1个智能分流关键词，一个智能分流关键词可以被多个APN绑定。

- 最多可输入20000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                                                                                                                                                                                 |
|:-----------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN        | APN     | 可选必选说明：必选参数  参数含义：该参数用于指定2B2C双DNN特性中通用DNN会话的APN实例名。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“ ” ”、“ ` ”特殊字符，不区分大小写。  默认值：无  配置原则：  该参数使用ADD CPAPN命令配置生成。 |
| INTELSHUNT | 智能分流关键词 | 可选必选说明：必选参数  参数含义：该参数用于指定智能分流关键词。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“ ” ”、“ ` ”特殊字符，不区分大小写。  默认值：无  配置原则：无                                         |

## 使用实例

增加“APN”为“huawei.com”，智能分流关键词为“huawei1”的配置：

```
ADD APNINTELSHUNT: APN="huawei.com", INTELSHUNT="huawei1";
```
