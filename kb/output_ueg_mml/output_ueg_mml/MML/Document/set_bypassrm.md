# 设置存储bypass模式下系统运行模式配置信息(SET BYPASSRM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

- 本命令属于高危命令，仅在支持存储bypass模式下且存储故障判断需要切换容灾局时操作。执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于在存储Bypass模式下且存储故障判断需要切换容灾局时设置整局状态。

## 注意事项

- 该命令需要DCS服务正常才能执行。
- 该命令仅能在支持存储Bypass模式下且存储故障判断需要切换容灾局时才能进行操作。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称           | 参数说明                                                                                                                                                 |
|:-------|:---------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
| FS     | Bypass模式系统运行状态 | 可选必选说明：必选参数 参数含义：本参数用于指定系统的运行状态。 取值范围： ACTIVE(激活模式)：表示网元处于正常工作状态，在此状态下，该网元可以处理业务。DEACTIVE(去激活模式)：表示网元处于去激活状态，在此状态下，该网元不能处理任何业务，请谨慎使用。 默认值：无。 配置原则：无。 |

## 使用实例

存储Bypass模式下，存储故障判断需要切换容灾局时，主用网元需要退出服务进行维护：

1. 将“Bypass模式系统运行状态”设置为“DEACTIVE(去激活模式)”状态使存储Bypass模式下的网元暂时退出服务。此时根据容灾机制，业务处理将转移到容灾网元进行处理。

   ```
   SET BYPASSRM: FS=DEACTIVE;
   ```
2. 在确认主用网元恢复正常后，再将“Bypass模式系统运行状态”设置为“ACTIVE(激活模式)”状态使该网元重新处理业务，此时可以通过手工倒回的方式将业务从容灾网元重新倒回到主用网元。

   ```
   SET BYPASSRM: FS=ACTIVE;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释           | 原因分析                         | 处理建议                            |
|-------:|:----------------|:-----------------------------|:--------------------------------|
| 100016 | 参数“FS”值不在取值范围内。 | 参数“Bypass模式系统运行状态”取值不在取值范围内。 | 根据参数取值范围和配置原则，输入正确的参数值后执行本命令添加。 |
