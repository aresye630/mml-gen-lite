# 查询用户数据请求状态（DSP PUDRSTATUS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询用户数据请求状态。

执行**SET PUDR**命令触发在线用户重新查询库后，可执行本命令查询用户数据请求状态。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询用户数据请求状态。

```
DSP PUDRSTATUS:;
```


## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项解释请参见表1。

| 参数名称   | 参数描述                               |
|:-------|:-----------------------------------|
| 实例号    | 用于返回服务的实例号。 取值范围：长度不超过256的字符串。     |
| 启动时间   | 表示执行SET PUDR命令，开始触发用户数据请求的开始时间。    |
| 完成时间   | 表示完成用户数据请求时间。如果任务正在进行中，则完成时间为NULL。 |
| 用户数    | 表示触发用户数据请求的用户数。                    |
