# 加载远端用户数据同步用户密钥文件（LOD RDATASYNUSERKEY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于为远端用户数据同步服务器用户加载身份认证密钥文件。当用户开启公钥认证方式时，需要使用本命令加载此用户使用的密钥文件。

#### 注意事项

- 该命令最大记录数为10。
- 执行本命令之前需要通过OM Portal的文件传输服务上传用户公私钥文件到 “数据同步客户端用户密钥”文件夹内。上传方法可参考产品文档中“GUI参考 > 文件传输”。
- 上传服务规格：单文件大小不能超过16K字节，文件总数不超过50个。
- 密钥文件为OPENSSH格式或PEM格式。
- 本命令执行成功后，必须通过LST RDATASYNUSERKEY命令检查密钥加载状态，当“密钥状态”为“正常”时，说明密钥文件加载成功。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                          |
|:---------------|:---------|:------------------------------------------------------------------------------------------------------------------------------|
| SERVERNAME     | 服务器名称    | 可选必选说明：必选参数 参数含义：远端用户数据同步服务器名称。 数据来源：本端规划 取值范围：与LST RdataSynServer中的servername保持一致。 默认值：无 配置原则：该参数使用ADD RDATASYNSERVER命令配置生成。 |
| USERNAME       | 用户名称     | 可选必选说明：必选参数 参数含义：用于指定SFTP用户名。 数据来源：对端协商 取值范围：与远端SFTP服务器的用户名保持一致。 默认值：无 配置原则：无                                                 |
| KEYNAME        | 密钥名称     | 可选必选说明：必选参数 参数含义：用于创建用户加载密钥的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～128。 默认值：无 配置原则：无                                               |
| PUBKEYFILE     | 公钥文件名    | 可选必选说明：必选参数 参数含义：用于指定待加载公钥文件名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～128。 默认值：无 配置原则：无                                                |
| PRIVATEKEYFILE | 私钥文件名    | 可选必选说明：必选参数 参数含义：用于指定待加载私钥文件名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～128。 默认值：无 配置原则：无                                                |
| PRIVATEKEYPWD  | 私钥文件解密密钥 | 可选必选说明：必选参数 参数含义：用于指定待加载私钥文件解密密码。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～433。 默认值：无 配置原则：无                                             |

#### 使用实例

加载远端用户数据同步用户密钥文件，服务器名称为rdata1，用户名为abc，密钥名称key1，公钥文件名rsa\_key.pub，私钥文件名rsa\_key，私钥文件解密密码为"\*\*\*\*\*"：

```
LOD RDATASYNUSERKEY: SERVERNAME="rdata1", USERNAME="abc", KEYNAME = "key1", PUBKEYFILE = "rsa_key.pub", PRIVATEKEYFILE = "rsa_key", PRIVATEKEYPWD = "rsa_key";
```
