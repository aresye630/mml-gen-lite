## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于增加一条远端服务器配置信息。

在UDM初始配置阶段，该命令用于设置与对端网元对接时的远端服务器配置。

该命令的索引关系如图1所示。

**图1** 命令参数的索引关系图

## 注意事项

- 执行该命令增加SCP/SEPP/AUC类型的远端服务器配置信息，且“链路类型”为“Dynamic(动态)”时，“本端IP名称”对应的“对端IP地址类型”只允许配置一条数据记录。
- 最大支持1024条远端服务器配置。

## 参数说明

| RSRVGRPNAME  | 远端服务器组名       | 可选必选说明：可选参数 参数含义：用于标识一个远端HTTP服务端组的名称。该参数必须先由ADD HTTPRSRVGRP命令定义以后才能在此处引用。 取值范围：长度不超过128的由数字和字母组成的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。                                                                                                                                                                                                     |

| PPORT        | 对端端口号         | 可选必选说明：条件必选参数 参数含义：用于标识一个对端端口号。 取值范围：1~65535 默认值：80。 配置原则：该参数在“链路类型”为“Static（静态）”时为必选参数。                                                                                                                                                                                                                                                          |

| PING_PERIOD  | PING帧发送周期     | 可选必选说明：条件可选参数 参数含义：用于标识对端的PING帧心跳周期，按照该参数的配置HLB周期性向对端发送PING帧维持和检测链路。  说明： 对于HTTP1.1链路，用于标识Keepalive报文的发送周期，按照该参数的配置HLB周期性向对端发送Keepalive探测报文维持和检测链路。 取值范围：0~600，单位为秒。 默认值：0 配置原则： 当该参数取值为“0”时，表示HLB作为客户端每60秒向对端发送PING帧。 说明： 对于HTTP1.1链路，当该参数取值为“0”时，表示HLB作为客户端每60秒向对端发送Keepalive探测报文。 该参数在“链路类型”为“Static(静态)”时为可选参数。                               |
| HTTPHOST     | 远端服务器域名       | 可选必选说明：可选参数 参数含义：用于指定标识HTTP对端实体的FQDN。该参数需要ADD HTTPPE命令定义后才能使用。 取值范围：长度不超过127的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                  |

## 使用实例

1. 在UDM初始配置阶段，增加一条远端服务器配置。“远端服务器名称”为“smf\_1”，“链路类型”为“Dynamic(动态)”，“远端服务器组名”为“aaa”，“本端IP名称”为“IP2”，“链路集参数ID”为“3”。

   ```
   ADD HTTPRSRV: RSERVERNAME="smf_1", LNKTYPE=Dynamic, RSRVGRPNAME="aaa", LIPNAME="IP2", PARAID=3;
   ```
2. 执行该命令配置HLB客户端数字证书，以确保UDM通过HTTPS接口与对端设备进行通信时的安全性。“远端服务器名称”为“smf\_2”，“链路类型”为“Static(静态)”，“本端IP名称”为“IP2”，“对端IP地址类型”为“IPV4”，“对端IPv4地址”为“10.0.0.2”，“对端端口号”为“80”，“开启HTTPS”为“TRUE(TRUE)”，“证书应用场景”为“UDM\_HLB\_Cert(HLB证书应用场景)”，“TLS配置ID”为“1”，“链路集参数ID”为“2”。

   ```
   ADD HTTPRSRV: RSERVERNAME="smf_2", LNKTYPE=Static, LIPNAME="IP2", PIPVER=IPV4, PIPV4IP="10.0.0.2", PPORT=80, HTTPSFUNC=TRUE, CERTID=UDM_HLB_Cert, TLSCFGID=1, PARAID=2;
   ```
