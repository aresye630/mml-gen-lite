# 查询SMF的UDM全故障Bypass相关功能（LST SMFUDMBYPASS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF**

该命令用于查询SMF的UDM全故障Bypass相关功能。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询SMF的UDM全故障Bypass功能。

```
%%LST SMFUDMBYPASS;%%
RETCODE = 0  操作成功

结果如下
--------
SMF的UDM全故障BYPASS开关  =  打开
     故障探测速率(个/秒)  =  1
        扫描时间间隔(秒)  =  600
         上报异常CHR开关  =  打开
  自动退出BYPASS功能开关  =  打开
(结果个数 = 1)

 ---    END
```

## 输出结果说明

| 输出项名称          | 输出项解释                                                                                                                                                                         |
|:---------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UDM全故障Bypass开关 | 该参数用于指定SMF是否支持基于用户的UDM全故障Bypass功能。                                                                                                                                            |
| 故障探测速率(个/秒)    | 该参数用于指定故障探测速率，即每个DS每秒扫描多少个用户，扫描到后对符合重选UDM条件的用户立即重选。                                                                                                                           |
| 扫描时间间隔(秒)      | 该参数用于表示UDM Bypass后SMF对用户扫描的时间间隔。                                                                                                                                              |
| 上报异常CHR开关      | 该参数用于设置当由于UDM Bypass会话接入成功时，是否上报异常CHR单据。 参数意义如下： 当设置为ON时，将接入5G成功且进入UDM Bypass的流程（涉及首次PDU会话激活、4到5切换）上报到异常CHR单据。 当设置为OFF时，将接入5G成功且进入UDM Bypass的流程（涉及首次PDU会话激活、4到5切换）上报到正常CHR单据。 |
| 自动退出Bypass功能开关 | 该参数是用于控制是否开启用户会话自动退出UDM Bypass状态的开关。 值为“ON”时，会话会在UDM恢复后自动退出Bypass。 值为“OFF”时，会话会在UDM恢复后，不自动退出。                                                                                 |
