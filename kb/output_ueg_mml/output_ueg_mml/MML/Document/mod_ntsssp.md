# 修改通知服务系统软参(MOD NTSSSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致系统异常，影响业务处理，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于修改NTS系统软件参数的配置信息。

## 注意事项

- 在缺省的情况下，系统在初始化的时候已经预置了软参数据表中的全部数据。
- 操作员应使用默认值。如果操作员确实需要修改软件参数，请联系华为技术服务工程师处理，禁止随意修改。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SCP    | 系统配置参数 | 可选必选说明：必选参数 参数含义：系统配置参数标识。 取值范围： SYSPARAMETER(系统参数) 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| SPN    | 参数名    | 可选必选说明：必选参数 参数含义：标识软件参数名称，用于指定需要对哪一类软参数据记录的参数进行修改。 取值范围： VRM_NTSCRLPOLICY(NTS数字证书CRL处理策略)VRM_NOTIFYRESENDINTERVAL(用户通知重发时间间隔)VRM_NOTIFYRESENDTIMES(用户通知重发次数)VRM_NOTIFYSENDSPEED(消息通知发送速度)VRM_NTFSENDCONTROL(通知重发控制)VRM_NTFRESENDTIMERANGE(重发通知有效期)VRM_NOTIFYSENDVALTIME(待发通知有效期)VRM_NOTIFYEXPORTTYPE(历史通知导出类型)VRM_NOTIFYRECOVERYVALUE(用户通知链路告警恢复阈值)VRM_NOTIFYALARMVALUE(用户通知链路告警上报阈值)VRM_NOTIFYWAITTEDALMTH(通知待发文件堆积告警阈值)VRM_NOTIFYRESENDALMTH(通知重发文件堆积告警阈值)VRM_NOTIFYALMTIME(通知文件堆积告警时长)VRM_NTSLINKPASSWDENCRYALGORITHM(NTS通知链路密码加密算法)VRM_SMTPHEARTBEATSWITCH（SMTP心跳开关） 详细信息请参考产品手册的“UPCF软件参数 > NTS系统软参”。 默认值：无。 配置原则：无。 |
| SPV    | 参数值    | 可选必选说明：必选参数 参数含义：标识软件参数的值。 取值范围：0～2147483647 详细信息请参考产品手册的“UPCF软件参数 > NTS系统软参”。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |

## 使用实例

为保证对接设备间数字证书使用的安全性，系统检查到对端数字证书CRL时，会中断对端链路，设置“系统配置参数”为“SYSPARAMETER(系统参数)”，“参数名”为“VRM\_NTSCRLPOLICY(NTS数字证书CRL处理策略)”，“参数值”软参设置为“1”。

```
MOD NTSSSP: SCP=SYSPARAMETER, SPN=VRM_NTSCRLPOLICY, SPV=1;
```
