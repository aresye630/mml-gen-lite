# 查询LCS NF锁定开关（LST LCSNFLOCK）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询LCS NF的锁定开关。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询LCS NF的锁定开关：

```
LST LCSNFLOCK:;
```

```
RETCODE = 0  操作成功

LCS NF锁定开关
------------------
 LMF锁定开关  =  DISABLE
GMLC锁定开关  =  DISABLE
(结果个数 = 1)

---    END
```
