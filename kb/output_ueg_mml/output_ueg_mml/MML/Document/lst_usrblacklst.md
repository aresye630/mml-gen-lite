# 查询用户黑名单限制列表（LST USRBLACKLST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

如果黑名单限制列表记录过多时，执行该命令会占用维护终端较长时间，进而导致用户无法继续使用该维护终端。

**适用NF：SGSN、MME、AMF**

该命令用于查询黑名单限制的用户列表。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                    |
|:-------|:-------|:----------------------------------------------------------------------------------------|
| IMSI   | IMSI   | 可选必选说明：可选参数  参数含义：该参数用于指定限制用户黑名单接入的IMSI。  数据来源：全网规划  取值范围：字符串类型，输入长度是15。  默认值：无  配置原则：无 |

## 使用实例

查询系统中黑名单限制的用户列表，执行如下命令：

```
%%LST USRBLACKLST:;%%
RETCODE = 0  操作成功

结果如下
--------
            IMSI  =  123456789012345
        限制模式  =  N2模式&S1模式&Iu模式&Gb模式
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                  |
|:--------|:-----------------------|
| IMSI    | 该参数用于指定限制用户黑名单接入的IMSI。 |
| 限制模式    | 该参数用于控制限制用户黑名单接入的系统模式。 |
