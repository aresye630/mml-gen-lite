# 修改时间字符串格式(MOD TIMESTRFMT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于修改或调整配置数据库中的时间字符串格式配置，这里的时间格式是指发给用户短消息中显示的时间格式，当前只有一条记录。

该命令的使用场景：在填充通知内容时，可以添加时间相关属性，时间的格式由该命令设置。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                            |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FMTID  | FMT标识  | 可选必选说明：必选参数 参数含义：用于指定一条时间字符串格式配置记录，因为只有一条记录，此属性的值只能为0。 取值范围：0 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                      |
| FORMAT | 时间日期格式 | 可选必选说明：必选参数 参数含义：用于标识时间字符串格式的编号。 取值范围： FMT1 (MM-DD-YYYY hh:mm:ss)FMT2 (YYYY-MM-DD hh:mm:ss)FMT3 (DD-MM-YYYY hh:mm:ss)FMT4 (MM.DD-YYYY hh:mm:ss)FMT5 (YYYY.MM.DD hh:mm:ss)FMT6 (DD.MM.YYYY hh:mm:ss)FMT7 (MM-DD-YYYY)FMT8 (YYYY-MM-DD)FMT9 (DD-MM-YYYY)FMT10 (MM.DD.YYYY)FMT11 (YYYY.MM.DD)FMT12 (DD.MM.YYYY)FMT13 (YYYYMMDDhhmmss)FMT14 (DD.MM) 默认值：无 系统初始设置值：FMT1 (MM-DD-YYYY hh:mm:ss) 配置原则：无 |

## 使用实例

修改时间字符串格式。

```
MOD TIMESTRFMT: FMTID=0, FORMAT=FMT1;
```
