# 设置日志自动抑制(SET PCFLOGSUPPRES)

## 命令功能

该命令用于设置UPCF各服务（包含PMS/HLB/PES/DLB/NCS/APPCTRL/NTS/LCS/DCS/DRS/NLFS/OTS等）ERROR级别的运行文本日志的自动抑制配置参数。在抑制周期内，相同内容的运行文本日志只会输出一条记录，但系统会记录具体的输出条数，方便维护人员进行统计。

该命令的使用场景：当系统产生的冗余日志过多影响日常维护和问题定位时，可以通过设置该命令，对系统中生成的冗余日志实现自动抑制调整，减少重复日志，延长有效日志的保存周期。

## 注意事项

- 当软参“VRM\_LOGPRINTPERIOD”的取值为0时，日志自动抑制功能将关闭。
- 该命令支持联机设定到各服务，每个服务有1条日志自动抑制参数记录，且各服务只加载自己的参数记录进行处理。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                        |
|:------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 服务类型   | 可选必选说明：必选参数 参数含义：标识日志自动抑制的服务类型。 取值范围： PMSRedisHLBPESDLBNCSAPPCTRLNTSLCSDCSDRSNLFSOTS 默认值：无 配置原则：无。  说明： “服务类型”下的“Redis”参数功能已废弃。                                                                             |
| SWITCH      | 自动调节开关 | 可选必选说明：必选参数 参数含义： 用于设置日志自动抑制的自动调节开关。 当该参数设置为“ON(打开)”，且为首次输出日志时，则取最小周期为初始日志自动抑制周期值。当该参数关闭后再打开时，则取关闭时抑制周期的值为日志自动抑制周期值。当该参数设置为“OFF(关闭)”时，则取软参“VRM_LOGPRINTPERIOD”的值为日志抑制周期值。 取值范围： ON(打开)OFF(关闭) 默认值：无 配置原则：无。 |
| ACCRATE     | 加速速率   | 可选必选说明：可选参数 参数含义： 用于设置日志自动抑制的加速速率，仅当本命令中的“自动调节开关”参数为“ON(打开)”时该参数有效。 当每5分钟输出日志的数量达到“加速速率”设置的值时，则需要在抑制周期的基础上增加一个“步长”，但不可大于“最大周期”的值。例如原抑制周期为200毫秒，“步长”为100毫秒，则现抑制周期变为300毫秒。 取值范围：3000～30000 默认值：3000 配置原则：无。   |
| DECRATE     | 减速速率   | 可选必选说明：可选参数 参数含义： 用于设置日志自动抑制的减速速率，仅当本命令中的“自动调节开关”参数为“ON(打开)”时该参数有效。 当每5分钟输出日志的数量达到“减速速率”设置的值时，则需要在抑制周期的基础上减少一个“步长”，但不可小于“最小周期”的值。例如原抑制周期为200毫秒，“步长”为100毫秒，则现抑制周期变为100毫秒。 取值范围：30～2700 默认值：30 配置原则：无。        |
| RSTRATE     | 复位速率   | 可选必选说明：可选参数 参数含义： 用于设置日志自动抑制的复位速率，仅当本命令中的“自动调节开关”参数为“ON(打开)”时该参数有效。 当每5分钟输出日志的数量达到“复位速率”设置的值时，则需要将抑制周期重置为初始日志自动抑制周期值。 取值范围：1～27 默认值：3 配置原则：无。                                                               |
| MINPERIOD   | 最小周期   | 可选必选说明：可选参数 参数含义：用于设置日志自动抑制的最小周期，仅当本命令中的“自动调节开关”参数为“ON(打开)”时该参数有效。 取值范围：10～1000 单位：毫秒 默认值：100 配置原则：无。                                                                                                       |
| MAXPERIOD   | 最大周期   | 可选必选说明：可选参数 参数含义： 用于设置日志自动抑制的最大周期，仅当本命令中的“自动调节开关”参数为“ON(打开)”时该参数有效。 该参数的配置原则：“最大周期”须大于初始日志自动抑制周期值。 取值范围：30000～300000 单位：毫秒 默认值：30000 配置原则：无。                                                                |
| STEP        | 步长     | 可选必选说明：可选参数 参数含义： 用于设置日志自动抑制周期的步长，仅当本命令中的“自动调节开关”参数为“ON(打开)”时该参数有效。 取值范围：10～1000 单位：毫秒 默认值：100 配置原则：无。 配置原则：“步长”须小于等于初始日志自动抑制周期值。                                                                           |

## 使用实例

设置“服务类型”为“PES”的日志自动抑制，“自动调节开关”为“ON(打开)”，“加速速率”为“10000”，“减速速率”为“100”，“复位速率”为“10”，“最小周期”为“200”，“最大周期”为“200000”，“步长”为“100”：

```
SET PCFLOGSUPPRES: SERVICETYPE=PES, SWITCH=ON, ACCRATE=10000, DECRATE=100, RSTRATE=10, MINPERIOD=200, MAXPERIOD=200000, STEP=100;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
