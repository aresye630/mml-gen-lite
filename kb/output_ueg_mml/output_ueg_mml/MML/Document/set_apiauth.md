# 设置API token鉴权（SET APIAUTH）

- 命令功能
- 注意事项
- 操作用户权限

- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

**须知** 

本命令属于高危命令，关闭token鉴权后，API GW不对接口调用进行token鉴权，可能存在安全风险，请谨慎关闭。

该命令用于设置API token鉴权开关。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- MPF独立运维场景下，在独立UPF上需要关闭token鉴权功能，在独立MPF上需要打开token鉴权功能。请联系华为工程师。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | ISAUTH   |
|:-------|:---------|
| 初始值    | ENABLE   |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                               |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------|
| ISAUTH | 鉴权开关   | 可选必选说明：必选参数 参数含义：是否使能API GW对APP接口调用的token鉴权。 数据来源：本端规划 取值范围：枚举类型。 ENABLE：打开token鉴权。DISABLE：关闭token鉴权。 默认值：无 配置原则：无 |

#### 使用实例

打开token鉴权：

```
SET APIAUTH:ISAUTH=ENABLE;
```
