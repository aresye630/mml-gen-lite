# 删除IP地址选择策略(RMV IPSELPLCY)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于删除S10、S11、Gn/Gp、S5/S8、S3、S4、Sv接口IP地址选择策略。

#### 注意事项

- 该命令执行后立即生效。
- 删除“DEFAULT(缺省策略)”，则S10、S11、Gn/Gp、S5/S8、S3、S4、Sv接口按IPv4策略来选。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                 |
|:----------|:-------|:---------------------------------------------------------------------------------------------------------------------|
| CTRLRANGE | 控制范围   | 可选必选说明：必选参数 参数含义：该参数用于指定命令生效的范围。 数据来源：整网规划 取值范围：“DEFAULT(缺省策略)”“SPECIFY(指定IMSI)” 默认值：无                               |
| IMSI      | IMSI   | 可选必选说明：条件必选参数 参数含义：该参数用于指定用户的IMSI。 前提条件：该参数在“CTRLRANGE(控制范围)”设置为“SPECIFY(指定IMSI)”有效。 数据来源：整网规划 取值范围：1~15位十进制数字 默认值：无 |

#### 使用实例

删除其中一个测试用户：

RMV IPSELPLCY: CTRLRANGE=SPECIFY, IMSI="123031501000001";
