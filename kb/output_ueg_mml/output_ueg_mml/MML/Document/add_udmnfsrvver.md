## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成UDM在NRF上的注册信息中的服务版本信息发生错误，从而导致周边网元无法访问UDM提供的服务，造成业务失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于增加网元服务版本信息。

- **命令作用**：通过本命令可以配置网元UDM向NRF发起服务注册时使用配置的数据。
- **该命令的使用场景**：该命令主要用于网元新开局场景下，配置本网元设备的服务版本信息，可以使周边网元正常访问UDM提供的服务。
- **命令可选/必选说明**：该命令在NRF注册场景是必选配置命令。

## 注意事项

当待增加数据中“组名称”与已有数据相同，“索引”与已有数据不同时，需同时满足如下条件，否则返回错误码“360042 参数值已存在”。

- “URI中的接口版本”参数取值与已有数据不能相同。
- “接口全部版本号”参数首字段（以点号进行分隔，第一个字段即为首字段）与已有数据不能相同。

## 参数说明

| 参数标识            | 参数名称      | 参数说明                                                                                                                                                                                                                           |
|:----------------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GRPNAME         | 组名称       | 可选必选说明：必选参数 参数含义：用于标识一个网元服务版本信息所属组的信息。该参数在执行ADD UDMNFSRV命令进行NRF注册信息实例化时，用于关联本网元服务版本组信息，以及在执行ADD UDMNFSERVICE命令时，用于配置网元允许接入的服务版本组信息。 取值范围：由数字、字母、“-”或“_”组成的长度不超过32的字符串。 参数来源：该参数由本端UDM自行定义。 默认值：无。 配置原则：该参数和“索引”参数组成全局唯一对象关键字段。 |
| INDEX           | 索引        | 可选必选说明：必选参数 参数含义：用于标识一个网元服务版本信息的索引。 取值范围：1~1024 参数来源：该参数由本端UDM自行定义。 默认值：无。 配置原则：该参数和“组名称”参数组成全局唯一对象关键字段。                                                                                                                       |
| APIVERSIONINURI | URI中的接口版本 | 可选必选说明：必选参数 参数含义：用于标识一个网元服务版本信息中URI接口版本。 取值范围：由字母、数字组成的长度不超过32的字符串，例如："v1","v2"。 参数来源：该参数由运营商根据实际情况进行规划。 默认值：无。 配置原则：仅当网元服务名称为“nudm-sdm”时，该参数取值为v2，其他场景该参数取值为v1。                                                               |
| APIFULLVERSION  | 接口全部版本号   | 可选必选说明：必选参数 参数含义：用于标识一个网元服务版本信息中接口全部版本号。 取值范围：由字母、数字、“.”或“-”组成的长度不超过32的字符串，字符串必须使用“.”分隔，首字段必须唯一。例如："1.0.0",“2.1.0”。 参数来源：该参数由运营商根据实际情况进行规划。 默认值：无。 配置原则：该参数首字符的取值与“URI中的接口版本”参数存在对应关系。若“URI中的接口版本”为“v1”，则该参数的首字符为“1”。          |
| EXPIRY          | 到期时间      | 可选必选说明：可选参数 参数含义：用于标识一个网元服务版本信息的到期时间。 取值范围：格式为“YYYY/MM/DD HH:NN:SS” 参数来源：该参数由运营商根据实际情况进行规划。 默认值：无。 配置原则：该参数要晚于当前命令提交执行的时间。                                                                                                     |

## 使用实例

对于5G场景下的新建局，增加一条UDM网元的服务版本信息是网元向NRF发起注册且能正常实现业务功能的必配信息之一。详细操作步骤如下：

1. 执行**LST UDMNFSRVVER**，确认当前系统未配置任何网元服务版本信息。
2. 规划增加一条UDM网元服务版本信息所需参数取值，详细参数规划示例如下，
   - “组名称”：本端自行规划名字为“srvver-group-01”。
   - “索引”：本端自行规划记录索引为“1”。
   - “URI中的接口版本”：根据运营商规划确定为“v2”。
   - “接口全部版本号”：根据运营商规划确定为“2.1.0”。

   **脚本示例如下**：

   ```
   ADD UDMNFSRVVER: GRPNAME="srvver-group-01", INDEX=1, APIVERSIONINURI="v2", APIFULLVERSION="2.1.0";
   ```
3. 继续执行**LST UDMNFSRVVER**查看配置信息与规划内容是否一致，若不一致可执行 **RMV UDMNFSRVVER**命令删除配置错误的记录，再重新执行步骤2中的**ADD UDMNFSRVVER**命令添加UDM网元的服务版本信息。
