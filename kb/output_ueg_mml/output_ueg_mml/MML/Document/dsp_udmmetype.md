# 查询UDM网元类型（DSP UDMMETYPE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询网元在网管上的形态类型。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询当前已配置网元在网管上的形态类型：

```
DSP UDMMETYPE:;
```

```
%%DSP UDMMETYPE:;%%
RETCODE = 0  操作成功

操作结果如下:
-------------
  网元ID  =  498
网元类型  =  UDM-IWF
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET UDMMETYPE**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如下表所示。

|    错误码 | 错误码解释           | 原因分析       | 处理建议           |
|-------:|:----------------|:-----------|:---------------|
| 360125 | 查询网元METYPE信息失败。 | CSP组件返回失败。 | 请联系华为技术支持进行处理。 |
