# 查询网元默认通知订阅信息(LST UDMNFNOTIFSUB)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询网元默认通知订阅信息。

- 若需要查询所有通知订阅信息，不输入任何参数。
- 若需要查询某个通知订阅的详细信息，请输入“索引”参数。
- 若需要查询某个组的通知订阅信息，请输入“组名称”参数。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------------------------------|
| GRPNAME | 组名称    | 可选必选说明：必选参数 参数含义：用于指示系统按照哪个组名称来查询网元默认通知订阅信息；若不输入，则表示查询所有的组名称。 取值范围：由数字、字母、“-”或“_”组成的长度不超过32的字符串 默认值：无。 配置原则：该参数和“索引”参数组成全局唯一对象关键字段。 |
| INDEX   | 索引     | 可选必选说明：必选参数 参数含义：用于指示系统按照哪个索引来查询网元默认通知订阅信息；若不输入，则表示查询所有的索引。 取值范围：1~1024 默认值：无。 配置原则：该参数和“组名称”参数组成全局唯一对象关键字段。                        |

## 使用实例

1. 查询所有的网元默认通知订阅信息：

```
LST UDMNFNOTIFSUB:;
```

```
%%LST UDMNFNOTIFSUB:;%% 
RETCODE = 0  操作成功
    
组名称             索引  通知类型  回调URI                N1消息类型  N2信息类型    
notifsub-group-01  3     N1消息    https://127.3.105.76/  NULL        NULL         
nfnotifsub_01      101   N1消息    http://127.3.105.76/  NULL        NULL         

(结果个数 = 2)  
---    END
```

2. 查询“索引”为“101”的网元默认通知订阅信息：

```
LST UDMNFNOTIFSUB: INDEX=101;
```

```
%%LST UDMNFNOTIFSUB: INDEX=101;%% 
RETCODE = 0  操作成功   
     
    组名称  =  nfnotifsub_01       
      索引  =  101   
  通知类型  =  N1消息    
   回调URI  =  http://127.3.105.76/ 
N1消息类型  =  NULL 
N2信息类型  =  NULL 
(结果个数 = 1)  

---    END
```

3. 查询“组名称”为“101”的网元默认通知订阅信息：

```
LST UDMNFNOTIFSUB: GRPNAME="nfnotifsub_01";
```

```
%%LST UDMNFNOTIFSUB: GRPNAME="nfnotifsub_01";
%% RETCODE = 0  操作成功

    组名称  =  nfnotifsub_01
      索引  =  101   
  通知类型  =  N1消息
   回调URI  =  http://127.3.105.76/ 
N1消息类型  =  NULL 
N2信息类型  =  NULL 
(结果个数 = 1)  

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD UDMNFNOTIFSUB**命令的参数说明。
