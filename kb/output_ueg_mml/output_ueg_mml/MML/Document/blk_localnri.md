# 闭塞本局NRI配置信息(BLK LOCALNRI)

#### 命令功能

**适用网元：SGSN**

该命令用于闭塞本局NRI配置信息。本局NRI被闭塞之后，从“NRI起始值”开始的N个NRI都将处于BLOCKED状态（其中N为**ADD LOCALNRI**命令中输入的“NRI个数”），SGSN在新分配PTMSI时，将不使用BLOCKED状态的NRI值，但是可以正确识别该NRI值为本局NRI。

#### 注意事项

- 该命令执行立即生效。
- 该命令输入的“NRI起始值”必须为**ADD LOCALNRI**命令中输入的“NRI起始值”。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                                                                                                                                                         |
|:--------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| POOLID  | POOL区标识 | 可选必选说明：必选参数 参数含义：该参数用于POOL区标识。 数据来源：整网规划 取值范围：0～4095 默认值：无                                                                                                                                                                                                   |
| NRIVBGN | NRI起始值  | 可选必选说明：必选参数 参数含义：该参数用于NRI起始值，参数值需与ADD LOCALNRI中的“NRI起始值”相同，NRI（Net Resource Identify），网络资源标识，用于标识一个CN节点。RAN根据NRI将MS的消息路由到对应的SGSN。 数据来源：整网规划 取值范围：0～1023 默认值： 无  说明： NRI的取值范围在0～(2n-1)，n为本Pool的NRI长度。若POOL表的NRI长度为10，则LOCALNRI表的NRI个数必须大于等于4， NRI起始值小于等于1020。 |

#### 使用实例

闭塞一条POOLID为1，NRI的起始值为10的本局NRI配置信息：

BLK LOCALNRI: POOLID=1， NRIVBGN=10；
