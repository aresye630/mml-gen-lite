# 修改服务发现自适应流控NF级配置（MOD DISCADAPTFC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、NSSF、SMSF、NCG、NEF、NWDAF、SCF**

该命令用于修改服务发现自适应流控NF级配置。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

修改用于发现AMF的配置，把起控成功率改为79%

```
%%MOD DISCADAPTFC: NFTYPE=NfAMF, STARTSUCCRATE=79;%%
RETCODE = 0   操作成功
```
