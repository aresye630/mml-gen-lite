## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致系统异常，影响业务处理，需联系华为技术支持确认后再执行。

该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于删除一个NRF网元的数据信息。

- **命令作用**：该命令用于配置PCF需要注册到的NRF信息时，当组网中部署了多个NRF网元，支持删除配置目标NRF的所属组及优先级等信息。

  **图1** 命令参数的索引关系图

## 注意事项

- **对系统的影响**：无。
- **命令生效条件**：执行该命令立即生效。
- **其他注意事项**：如果NRF所属的组被某个网元实例引用，则应该保证数据删除后此组内至少还剩下一个NRF，否则不能执行此操作。操作员可以先使用**LST NFSRV**命令查询NRF所属组是否被某个网元实例引用，若被引用，则执行**RMV NFSRV**删除该网元实例，然后执行**RMV NRFINFO**删除该NRF。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NRFNAME | NRF名称  | 可选必选说明：必选参数 参数含义：标识一条NRF数据记录的关键字段，用于指定需要删除哪一条NRF数据记录。 取值范围：长度不超过32的字符串，只允许输入：0～9，a～z，A～Z，“-”和“_”。 参数来源：该参数全局唯一且需PCF与NRF端协商获取此参数名，可通过执行LST NRFINFO命令查询获得。 取值范围：长度不超过32的字符串，只允许输入：0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。 |

## 使用实例

该命令的使用场景主要为通过“ADD NRFINFO”命令添加NRF注册信息时，错误配置了PCF需要发起注册的“NRF名称”参数，此时须执行如下步骤进行操作：

1. 执行**RMV NRFINFO**命令删除错误配置记录之前，须先使用**LST NFSRV**命令查询NRF所属组被网元实例引用：

   ```
   %%LST NFSRV: NFTYPE=PCF;%% 
   RETCODE = 0  操作成功          
          网元实例名称  =  pcf-application-02
          网元实例标识  =  4947a69a-f61b-4bc1-b9da-47c9c5d14b66
         NRF所属组信息  =  nrfgroup-01
              网元类型  =  策略控制功能
              网元状态  =  正常工作状态
              配置方式  =  命令模式
            PLMN组名称  =  NULL
         S-NSSAI组名称  =  NULL
               NSI列表  =  NULL
                  位置  =  NULL
      网元公共信息标识  =  cominfo_01
          网元信息标识  =  NULL
        网元服务持续性  =  NULL
            网元服务组  =  NULL
    网元服务范围组名称  =  NULL
          上报网管标志  =  不上报网管
              更新方法  =  PUT更新
              心跳周期  =  0
          网元实例信息  =  NULL
    (结果个数 = 1)
     ---    END
   ```
2. 继续执行**LST NRFINFO**命令查询待删除NRF注册信息中“NRF所属组信息”参数的取值。

   ```
   %%LST NRFINFO:;%% 
   RETCODE = 0  操作成功  
   操作结果如下 
   ------------ 
   NRF所属组信息  =  nrfgroup-01       
   NRF名称  =  nrf-01       
   NRF URI  =  https://192.168.1.1:8080        
   优先级  =  2      
   超时时长  =  5      
   失败次数  =  3 
   编码方式 = NULL
   (结果个数 = 1)  
   ---    END
   ```
3. 根据1，2步执行结果判断第1步的查询结果中的“NRF所属组信息”参数的取值是否与步骤2中查询“NRF所属组信息”参数的取值一致：
   - 若一致，请执行a，b两步完成NRF注册信息删除操作。
     1. 执行**RMV NFSRV**删除网元实例：

        ```
        RMV NFSRV: NFINSNAME="pcf-application-02";
        ```
     2. 执行**RMV NRFINFO**删除NRF网元，“NRF名称”为“nrf-01”：

        ```
        RMV NRFINFO: NRFNAME="nrf-01";
        ```
   - 若不一致，请直接执行**RMV NRFINFO**删除NRF网元，“NRF名称”为“nrf-01”：

     ```
     RMV NRFINFO: NRFNAME="nrf-01";
     ```
4. 删除配置错误的NRF注册信息后，重新根据正确规划的NRF注册信息完成NRF注册信息添加。

   ```
   ADD NRFINFO: NRFGROUP="nrfgroup-01", NRFNAME="nrf-02", NRFURI="https://192.168.1.2:8080", PRI=2, DURATION=5, TIMES=3;
   ```
5. 再次执行**LST NRFINFO**命令查询当前配置与其规划是否一致。

   ```
   %%LST NRFINFO:;%%
   RETCODE = 0  操作成功  
   操作结果如下 
   ------------
   NRF所属组信息  =  nrfgroup-01       
   NRF名称  =  nrf-02       
   NRF URI  =  https://192.168.1.2:8080        
   优先级  =  2      
   超时时长  =  5      
   失败次数  =  3 
   编码方式 = NULL
   (结果个数 = 1)  
   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释        | 原因分析        | 处理建议                                |
|------:|:-------------|:------------|:------------------------------------|
|   505 | 当前操作的配置数据不存在 | “NRF名称”不存在。 | 使用LST NRFINFO命令查询获得“NRF名称”，确保其值已存在。 |
