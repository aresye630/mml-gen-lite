# 删除区域码转换策略(RMV ZCCONVERT)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

此命令用于删除区域码转换策略。

#### 注意事项

- 此命令执行后立即生效

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                             |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：必选参数 参数含义：该参数用于指定待删除区域码转换策略的用户范围。 数据来源：全网规划 取值范围：“ALL_USER（所有用户）”“HOME_USER（本网用户）”“FOREIGN_USER（外网用户）”“IMSI_PREFIX（指定IMSI前缀）” 默认值：无  说明： 区域码转换策略优先级从高到低为：“IMSI_PREFIX（指定IMSI前缀）”，“FOREIGN_USER（外网用户）”或“HOME_USER（本网用户）”，“ALL_USER（所有用户）”。 |
| NOID     | 运营商标识  | 可选必选说明：条件必选参数 参数含义：该参数用于指定运营商标识。 前提条件：该参数在“SUBRANGE（用户范围）”配置为“FOREIGN_USER（外网用户）”或“HOME_USER（本网用户）”后生效。 数据来源：全网规划 取值范围：0～64，128～254 默认值：无  说明： 对于外网用户，该参数是与其归属运营商签订可漫游协议，为其提供服务的MNO运营商标识。 对于本网用户，该参数是为该用户归属的MNO运营商标识。                            |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件必选参数 参数含义：该参数用于指定区域码转换的IMSI前缀。系统根据该参数值对用户的IMSI进行匹配，从而区分不同的用户群。 前提条件：只有“SUBRANGE（用户范围）”为“IMSI_PREFIX（指定IMSI前缀）”时，该参数才有效。 数据来源：全网规划 取值范围：1～15位十进制数字字符串 默认值：无                                                                              |

#### 使用实例

场景参见**ADD ZCCONVERT**的命令使用实例。

删除运营商标识为1的本网用户：

RMV ZCCONVERT: SUBRANGE=HOME\_USER, NOID=1;
