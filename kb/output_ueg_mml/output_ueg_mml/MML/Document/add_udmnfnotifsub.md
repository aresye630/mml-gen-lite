# 添加网元默认通知订阅信息(ADD UDMNFNOTIFSUB)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加网元默认通知订阅信息。为服务实例指定缺省订阅通知信息，并用**MOD UDMNFSERVICE**命令关联到对应服务实例，可以关联多个不同服务实例。

该命令的参数索引关系如图1所示。

**图1** 命令参数索引关系图

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                                     |
|:------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GRPNAME     | 组名称    | 可选必选说明：必选参数 参数含义：用于标识一个网元默认通知订阅信息所属组的名称。 取值范围：由数字、字母、“-”或“_”组成的长度不超过32的字符串 默认值：无。 配置原则：该参数和“索引”参数组成全局唯一对象关键字段。                                                                                                                           |
| INDEX       | 索引     | 可选必选说明：必选参数 参数含义：用于标识一个网元默认通知订阅信息的索引。 取值范围：1~1024 默认值：无。 配置原则：该参数和“组名称”参数组成全局唯一对象关键字段。                                                                                                                                                   |
| NOTIFTYPE   | 通知类型   | 可选必选说明：必选参数 参数含义：用于标识一个网元默认通知订阅信息的通知类型。 取值范围： N1_MESSAGES（N1消息）N2_INFORMATION（N2消息）LOCATION_NOTIFICATION（位置添加通知）DATA_REMOVAL_NOTIFICATION（位置删除通知）DATA_CHANGE_NOTIFICATION（位置变更通知） 默认值：无。 配置原则：同一网元默认通知订阅信息所属组内“通知类型”不能重复。                |
| CALLBACKURI | 回调URI  | 可选必选说明：必选参数 参数含义：用于标识一个网元默认通知订阅信息的回调URI。 取值范围：长度不超过512字符串，包含协议类型(http/https)、FQDN域名或IP、端口（可选）等信息。举例：http://192.168.48.31:8080/subscription 默认值：无。 配置原则： 同一网元默认通知订阅信息所属组内“回调URI”不能重复。支持配置不携带端口的回调URL，当未配置端口时，HTTP默认使用80端口，HTTPS默认使用443端口。 |
| N1MSGCLASS  | N1消息类型 | 可选必选说明：条件必选参数 参数含义：用于标识一个网元默认通知订阅信息的N1消息类型。 取值范围： 5GMM（接收到的整个NAS消息）SM（短消息类型的N1消息）LP（eMLPP类型的N1消息）SMS（SMS类型的N1消息）UPD（UE策略下发的N1消息） 默认值：无。 配置原则：仅当本命令中的参数“通知类型”为“N1_MESSAGES（N1消息）”时，该参数有效。                                                 |
| N2INFOCLASS | N2信息类型 | 可选必选说明：条件必选参数 参数含义：用于标识一个网元默认通知订阅信息的N2消息类型。 取值范围： SM（N2短信消息）NRPPa（N2的NRPPa消息）PWS（PWS类型的N2的PWS信息）PWS-BCAL（N2广播完成区域列表或广播取消区域列表）PWS-RF（N2重启指示或失败指示）RAN（N2运行相关信息） 默认值：无。 配置原则：仅当本命令中的参数“通知类型”为“N2_INFORMATION（N2消息）”时，该参数有效。                 |

## 使用实例

在开局场景下配置本局数据时，增加一个网元订阅通知信息。“组名称”为“notifsub-group-01”，“索引”为“1010”，“通知类型”为“N1\_MESSAGES”，“回调URI”为“http://127.3.105.76:8080”,“N1消息类型”为“5GMM（接收到的整个NAS消息）”：

```
ADD UDMNFNOTIFSUB: GRPNAME="notifsub-group-01", INDEX=1010, NOTIFTYPE=N1_MESSAGES, CALLBACKURI="http://127.3.105.76:8080",N1MSGCLASS=5GMM;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如下表1所示。

|    错误码 | 错误码解释   | 原因分析        | 处理建议                                      |
|-------:|:--------|:------------|:------------------------------------------|
|    503 | 配置数据已存在 | 已有相同“索引”配置。 | 使用命令LST UDMNFNOTIFSUB查询并重新输入“索引”，确保其值不存在。 |
| 360041 | 参数值不合法  | 指定参数值不合法。   | 参考参数的定义或举例内容，并重新输入，确保格式正确。                |
