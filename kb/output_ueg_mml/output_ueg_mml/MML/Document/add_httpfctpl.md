# 增加手工流控模板（ADD HTTPFCTPL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在系统中增加一条HTTP手工流控模板策略，表示UDM接收到HTTP请求消息时对各类型的请求消息按照模板设置的比例进行放行。

## 注意事项

- 执行该命令配置手工流控模板，最多可配置128条记录。
- 执行该命令配置的单个模板所有比例参数之和不能超过100%。
- 系统初始化时会在数据库中增加一条手工流控模板数据记录，可以通过执行**LST HTTPFCTPL**命令查询。

  ```
  ADD HTTPFCTPL: FCTPLID="DefaultFCTPL", AUTHMRAT=12, AMFREGRAT=0, AMFPATCHMRAT=0, AMFNREGMRAT=0, AMFNPATCHRAT=0, AMFGETMRAT=0, AMFNGETMRAT=0, SMFRMRAT=20, SMFDRMRAT=0, SMSFRMRAT=0, SMSFDRMRAT=0, SMSFNDRMRAT=0, SMSFGMRAT=0, SMSFNGMRAT=0, SDMSUBDELMRAT=0, SDMSUBPATCHMRAT=0, SDMSUBMRAT=0, NSSAIGETMRAT=12, SMSGETMRAT=0, IDTRANSGETMRAT=0, DSETGETMRAT=0, SMDATAGETMRAT=0, SMFSELMRAT=0, UECXSMFMRAT=0, AMDATAMRAT=0, SMSMNGDATARAT=0, UECXTSMSFDATARAT=0, EESUBMRAT=0, EEUNSUBMRAT=0, N5GEQUIPMENTSTATUS=0, OTHERMRAT=0, AMFLOCMRAT=0, EEMODSUBMRAT=0;
  ```

## 使用实例

在配置HTTP手工流控时，在系统中增加一条手工流控模板数据记录，其中“流控模板标识”为“AAA\_007”，“AMF注册消息比例”为“5”，“AMF更新(去注册)消息比例”为“7”：

```
ADD HTTPFCTPL: FCTPLID="AAA_007", AMFREGRAT=5, AMFPATCHMRAT=7;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如下表所示。

|    错误码 | 错误码解释         | 原因分析                       | 处理建议                                                |
|-------:|:--------------|:---------------------------|:----------------------------------------------------|
|    503 | 配置数据已存在       | 相同“流控模板标识”的配置数据已存在，无法重复添加。 | 使用LST HTTPFCTPL查询已存在的手工流控模板参数信息，配置时填入未使用过的“流控模板标识”。 |
| 360140 | 消息配置比例之和大于100 | 输入的所有比例参数百分比之和超过100%。      | 重新输入比例参数，确保参数百分比之和不超过100%，然后执行该命令进行配置。              |
