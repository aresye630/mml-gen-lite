# 查询策略数据管理端口配置(LST PMSPMGRPORT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询策略数据管理端口的配置信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询策略数据管理端口的配置信息。

```
LST PMSPMGRPORT:;
```

```
%%LST PMSPMGRPORT:;%%
RETCODE = 0  操作成功

操作结果如下:
-------------
      端口号  =  7780
    端口类型  =  CLI
端口激活状态  =  INACTIVE
    保活时长  =  30
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见MOD PMSPMGRPORT命令的参数说明。
