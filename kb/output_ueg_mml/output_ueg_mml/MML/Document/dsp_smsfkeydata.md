# 显示SMSF用户关键信息（DSP SMSFKEYDATA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMSF**

该命令用于查询5G SMSF注册用户的关键信息，包括用户信息、用户短消息签约信息等。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                  |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------|
| QUERYOPT | 查询方式   | 可选必选说明：必选参数  参数含义：该参数用于表示SMSF用户查询方式。  数据来源：本端规划 取值范围： “SUPI（SUPI）”：填写用户的IMSI“GPSI（GPSI）”：填写用户的MSISDN  默认值：无  配置原则：无   |
| SUPI     | SUPI   | 可选必选说明：该参数在"QUERYOPT"配置为"SUPI"时为条件必选参数。  参数含义：该参数用于表示SMSF用户SUPI信息。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是5~15。  默认值：无  配置原则：无 |
| GPSI     | GPSI   | 可选必选说明：该参数在"QUERYOPT"配置为"GPSI"时为条件必选参数。  参数含义：该参数用于表示SMSF用户GPSI信息。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~15。  默认值：无  配置原则：无 |

## 使用实例

当运营商希望查询SUPI为"123033500100001"的SMSF用户的关键信息时，执行如下命令：

```
DSP SMSFKEYDATA: QUERYOPT=SUPI, SUPI="123033500100001";
```
