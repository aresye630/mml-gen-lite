# 查询UPF位置信息与UPF优先支持的4G TAI范围的绑定关系（LST LOCBINDS1TAI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C**

该命令用于查询UPF位置信息与UPF优先支持的TAI范围的绑定关系。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                        |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------|
| LOCALITY | UPF位置区 | 可选必选说明：可选参数  参数含义：该参数用于标识UPF位置区。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~255。  默认值：无  配置原则：  该参数需要与ADD PNFPROFILE命令中 “LOCALITY”的取值保持一致，参数匹配时大小写不敏感。 |
| TAI      | TAI    | 可选必选说明：可选参数  参数含义：该参数用于查询单个TAI绑定的LOCALITY。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是9~10。不区分大小写。  默认值：无  配置原则：  字符串类型，输入长度范围是9~10。后4位为16进制数，其余为10进制数。  |

## 使用实例

- 查询所有的UPF位置信息与UPF优先支持的TAI范围的绑定关系
  LST LOCBINDS1TAI:;

  ```
  %%LST LOCBINDS1TAI:;%%
  RETCODE = 0  操作成功

  结果如下
  --------
  UPF位置区  移动国家码  移动网号  S1 TAC起始号段  S1 TAC终止号段  

  locality1  460         03        1301            1302            
  locality1  460         03        1303            1304            
  locality2  460         03        1305            1306            
  (结果个数 = 3)

  ---    END
  ```
- 查询特定的UPF位置信息与UPF优先支持的TAI范围的绑定关系，其中UPF位置区为“locality1”
  LST LOCBINDS1TAI: TAI="123031301";

  ```
  %%LST LOCBINDS1TAI: TAI="123031301";%%
  RETCODE = 0  操作成功

  结果如下
  --------
       UPF位置区  =  locality1
      移动国家码  =  460
        移动网号  =  03
  S1 TAC起始号段  =  1301
  S1 TAC终止号段  =  1302
  (结果个数 = 1)

  ---    END
  ```

## 输出结果说明

| 输出项名称      | 输出项解释              |
|:-----------|:-------------------|
| UPF位置区     | 该参数用于标识UPF位置区。     |
| 移动国家码      | 该参数用于指定对端NF的移动国家码。 |
| 移动网号       | 该参数用于指定对端NF的移动网号。  |
| S1 TAC起始号段 | 该参数用于指定TAC的起始号段。   |
| S1 TAC终止号段 | 该参数用于指定TAC的终止号段。   |
