# 查询本端NF和对端NRF实例的注册关系（LST NFREGNRF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF、SMF、NRF、NSSF、NCG、NEF、NWDAF、SCF、CBCF**

该命令用于查询本端NF和NRF实例的注册关系。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识            | 参数名称    | 参数说明                                                                                                                                               |
|:----------------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
| NFTYPE          | 本端NF类型  | 可选必选说明：可选参数  参数含义：该参数用于指定网元所部署的NF类型。  数据来源：本端规划 取值范围： “NRF（NRF）”：NRF类型“NON_NRF（non-NRF）”：非NRF类型  默认值：无  配置原则：  该参数需要与ADD CPNFPROFILE命令配置的本端NF类型一致。 |
| NRFINSTANCENAME | NRF实例名称 | 可选必选说明：可选参数  参数含义：该参数用于指定本端NF所注册的对端NRF实例名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~38。  默认值：无  配置原则：  该参数取自ADD NRF命令配置的NRF实例名称。                           |

## 使用实例

假设要查询本端NF与对端NRF实例的注册关系，执行如下命令：

```
%%LST NFREGNRF:;%%
RETCODE = 0 操作成功

结果如下
------------------------
 本端NF类型 = NRF
NRF实例名称 = NRF_Instance_0
     优先级 = 10
       权重 = 100
（结果个数 = 1）

---- END
```

## 输出结果说明

| 输出项名称   | 输出项解释                          |
|:--------|:-------------------------------|
| 本端NF类型  | 该参数用于指定网元所部署的NF类型。             |
| NRF实例名称 | 该参数用于指定本端NF所注册的对端NRF实例名称。      |
| 优先级     | 该参数用于配置本端NF选择指定的NRF实例进行注册的优先级。 |
| 权重      | 该参数用于配置本端NF选择指定的NRF实例进行注册的权重。  |
