# 修改融合计费模板（MOD CCT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于修改融合计费模板（Converged Charging Template），用于配置融合计费相关参数。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

修改名为“Cct”的CCT融合计费模板，业务级流量阈值为1800MB：

```
MOD CCT: CCTMPLTNAME="Cct", RGVOLUMELIMIT=1800;
```
