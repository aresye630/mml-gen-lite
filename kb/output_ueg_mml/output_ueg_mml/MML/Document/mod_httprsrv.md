# 修改远端服务器配置(MOD HTTPRSRV)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于对远端服务器中的一条记录的某些参数进行修改或调整。在该命令中，系统通过“远端服务器名称”参数来唯一标识一条远端服务器配置记录。

## 注意事项

执行本命令当“远端服务器域名”和“URI前缀”参数配置为空或者空格时，系统会将参数置为NULL。

## 参数说明

| 参数标识         | 参数名称          | 参数说明                                                                                                                                                                                                                                                                                                                                   |
|:-------------|:--------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RSERVERNAME  | 远端服务器名称       | 可选必选说明：必选参数 参数含义：标识一个远端服务器配置的关键字段（其取值不能被修改），用于指定需要修改哪一个远端服务器配置记录。操作员可以使用命令LST HTTPRSRV查询获得。 取值范围：长度不超过128的由数字和字母组成的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。                                                                                                                                                                        |
| LNKTYPE      | 链路类型          | 可选必选说明：必选参数 参数含义：用于描述HTTP链路类型。 取值范围： Dynamic(动态)Static(静态) 默认值：无。 配置原则：当部署为GBA认证的AP功能实体时，仅支持配置静态HTTP链路。                                                                                                                                                                                                                                |
| HTTPSFUNC    | 开启HTTPS       | 可选必选说明：条件必选参数 参数含义：用于标识静态链路是否开启HTTPS。 取值范围： TRUE(TRUE)FALSE(FALSE) 默认值：无。 配置原则：仅当本命令中“链路类型”参数为“Static（静态）”时该参数有效。                                                                                                                                                                                                                      |
| CERTID       | 证书应用场景        | 可选必选说明：条件可选参数 参数含义：用于标识证书应用场景。该参数必须先由证书组管理命令定义，然后才能在此处引用。操作员可以使用命令LST HTTPRSRV查询获得。 取值范围：UDM_HLB_Cert(HLB证书应用场景) 默认值：无。 配置原则：当本命令中“开启HTTPS”参数取值为“TRUE(TRUE)”时该参数有效。该参数在“动态链路开启HTTPS”参数取值为“TRUE(TRUE)”或“BYURI(BYURI)”时为可选参数，如果不选择，则主机侧默认使用系统预置值“UDM_HLB_Cert(HLB证书应用场景)”，执行LST HTTPRSRV命令显示查询结果为“NULL”。                                 |
| TLSCFGID     | TLS配置ID       | 可选必选说明：条件可选参数 参数含义：用于标识一条TLS协议配置记录ID。该参数必须先由ADD UDMHLBTLSCFG命令定义，然后才能在此处引用。 取值范围：1~128 默认值：无。 配置原则：当本命令中“开启HTTPS”参数为“TRUE(TRUE)”时该参数有效。                                                                                                                                                                                                |
| PARAID       | 链路集参数ID       | 可选必选说明：可选参数 参数含义：用于标识一个链路集参数的ID。需要修改时操作员可以使用命令LST HTTPRSRV查询获得。该参数需要ADD HTTPLKSPARA命令定义后才能使用。 取值范围：1~255 默认值：无。 配置原则：无。                                                                                                                                                                                                                |
| DYNHTTPSFUNC | 动态链路开启HTTPS   | 可选必选说明：条件可选参数 参数含义：用于标识动态链路是否开启HTTPS。 取值范围：FALSE(FALSE)TRUE(TRUE)BYURI(BYURI) 默认值：无。 配置原则：该参数在“链路类型”为“Dynamic(动态)”时为可选参数。配置SCP/SEPP/AUC类型的远端服务器信息时，该参数必选且只允许选择“TRUE(TRUE)”或“FALSE(FALSE)”取值。配置非SCP/SEPP/AUC类型的远端服务器信息时，该参数只允许选择“BYURI(BYURI)”取值。 HTTP链路的处理性能远高于HTTPS链路，但是HTTPS链路在信息传输方面具有更高的安全性。如果无法确认当前应用场景是否需要使用HTTPS链路，建议联系华为技术工程师。 |
| USEFQDNINURI | 是否在URI中使用FQDN | 可选必选说明：条件可选参数 参数含义：用于标识SCP/SEPP/AUC消息中的URI是否携带FQDN。 取值范围：FALSE(FALSE)TRUE(TRUE) 默认值：无。 配置原则：该参数在“动态链路开启HTTPS”为“TRUE(TRUE)”或“FALSE(FALSE)”时为可选参数。该参数仅对SCP/SEPP/AUC类型的“远端服务器组名”生效。                                                                                                                                                       |
| PING_PERIOD  | PING帧发送周期     | 可选必选说明：条件可选参数 参数含义：用于标识对端的PING帧心跳周期，按照该参数的配置HLB周期性向对端发送PING帧维持和检测链路。  说明： 对于HTTP1.1链路，用于标识Keepalive报文的发送周期，按照该参数的配置HLB周期性向对端发送Keepalive探测报文维持和检测链路。 取值范围：0~600，单位为秒。 默认值：无。 配置原则： 当该参数取值为“0”时，表示HLB作为客户端每60秒向对端发送PING帧。 说明： 对于HTTP1.1链路，当该参数取值为“0”时，表示HLB作为客户端每60秒向对端发送Keepalive探测报文。 仅当本命令中“链路类型”参数为“Static（静态）”时该参数有效。               |
| HTTPHOST     | 远端服务器域名       | 可选必选说明：可选参数 参数含义：用于指定标识HTTP对端实体的FQDN。该参数需要ADD HTTPPE命令定义后才能使用。 取值范围：长度不超过127的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                       |
| URIPREFIX    | URI前缀         | 可选必选说明：可选参数 参数含义：用于指定标识URI前缀。当UIM实现GBA功能作为AP实体时，通过AP将UE的HTTP请求消息转发给AS，该参数配置的URI前缀将被添加到HTTP消息中。 取值范围：长度不超过31的字符串。 默认值：无。                                                                                                                                                                                                                |

## 使用实例

修改“远端服务器名称”为“smf\_3”，“链路类型”为“Static(静态)”，“开启HTTPS”为“TRUE(TRUE)”，“证书应用场景”为“UDM\_HLB\_Cert(HLB证书应用场景)”，“TLS配置ID”为“5”，“链路集参数ID”为“13”的远端服务器配置：

```
MOD HTTPRSRV: RSERVERNAME="smf_3", LNKTYPE=Static, HTTPSFUNC=TRUE, CERTID=UDM_HLB_Cert, TLSCFGID=5, PARAID=13;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                      | 原因分析                                                                                                             | 处理建议                                                          |
|-------:|:---------------------------|:-----------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------|
|    505 | 当前操作的配置数据不存在               | 输入的“远端服务器名称”不存在。                                                                                                 | 执行LST HTTPRSRV命令查询“远端服务器名称”后重新输入。                             |
| 360106 | 动态链路不可修改HTTPS属性。           | 该远端服务器的“链路类型”取值为“动态”。                                                                                            | 执行LST HTTPRSRV命令，从查询结果中查找“链路类型”为“静态”的远端服务器，对该服务器进行HTTPS属性的修改。 |
| 360185 | PARAID参数关联的LINKNUM不能超过16条。 | 仅如下两种场景系统允许配置超过16条链路数，否则不允许超过16条链路数。仅SCP、SEPP、AUC对端类型，远端HTTPRSRVGRP对应的HTTPRSRV配置的LINKNUM允许超过16条。静态链路允许配置超过16条链路。 | 根据实际情况设置LINKNUM链路条数不超过16条配置记录。                                |
| 360201 | 链路类型不可修改。                  | 正在修改远端服务器的“链路类型”取值。                                                                                              | 动态链路不允许修改为静态链路，静态链路不允许修改为动态链路。                                |
| 360275 | 对端域名不存在，请执行LST HTTPPE查询。   | 输入的“远端服务器域名”未定义。                                                                                                 | 使用命令LST HTTPPE查询对端HTTP实体信息，并重新执行本命令配置，输入已存在的“远端服务器域名”。        |
