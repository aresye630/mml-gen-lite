# 查询证书更新流程参数（LST UDMCERUPDATPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询HLB服务的证书更新流程配置信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询HLB服务的证书更新流程配置信息：

```
LST UDMCERUPDATPARA:;
```

```
%%LST UDMCERUPDATPARA:;%%
RETCODE = 0  操作成功
结果如下
--------
              更新间隔  =  3
          更新链路数量  =  10
更新证书时是否拆除链路  =  是
      平面更新等待时长  =  30
(结果个数 = 1)
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET UDMCERUPDATPARA**命令的参数说明。
