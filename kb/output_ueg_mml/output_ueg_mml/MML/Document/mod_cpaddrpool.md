# 修改地址池（MOD CPADDRPOOL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：GGSN、SMF、PGW-C**

该命令用于修改地址池属性，包括：地址租约使能标志、地址租期(秒)、子池类型、绑定VPN、VPN实例名、白名单检查开关、IMS开关、是否允许地址重叠。

## 注意事项

- 该命令执行后立即生效。

- 一个地址池只能绑定到一个VPN实例下。地址池下若不执行该命令，则默认配置为公网下的地址池，查询命令显示的地址池VPN实例名称为NULL。
- 如果一个地址池下配置有地址段（通过LST CPSECTION查询）或Agent IP（通过LST AGENTIP查询），或者该地址池所在的地址池组（通过LST POOLBINDGRP查询）映射关系中有APN（通过LST CPPOOLGRPMAP查询），或者该地址池所在的地址池组和DHCP服务器组有关联（通过LST DHCPBINDPOOLGRP），则禁止修改该地址池的VPN实例。
- 配置RELAESETIME为0且配置IPLEASE为Enable，则本次配置将执行失败。
- 修改后的CHECKIPVALID参数只对新激活的用户生效。
- 不允许修改地址池类型。
- 当前版本不支持此命令的SINGLEIPFLAG、OVERLAP参数。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称           | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
|:--------------|:---------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| POOLNAME      | 地址池名称          | 可选必选说明：必选参数  参数含义：该参数用于指定地址池的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~79。不支持空格及特殊字符“#”、“$”和“&”等，由“-”、“_”、数字、字母和“.”组成，不能以“.”开头，不区分大小写。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                   |
| POOLTYPE      | 地址池类型          | 可选必选说明：可选参数  参数含义：该参数用于指定地址池类型。  数据来源：本端规划 取值范围： “Local（本地）”：通过5GC（SMF或UPF）或AAA服务器分配动态地址。“UDM（UDM）”：通过UDM签约分配静态地址。“Radius（RADIUS）”：通过外部AAA服务器分配静态地址。“DHCP（DHCP）”：通过外部DHCP服务器分配静态地址。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                |
| IPLEASE       | 地址租约使能标志       | 可选必选说明：该参数在"POOLTYPE"配置为"Local"时为条件可选参数。  参数含义：该参数指定是否使能IP地址租约功能。  数据来源：本端规划 取值范围： Disable（去使能）Enable（使能）  默认值：无  配置原则： 对于本地地址池下的静态地址段，IPLEASE参数不生效。在配置IPLEASE参数值为ENABLE后上线的在线用户，配置IPLEASE参数值为DISABLE后，去活用户，该用户再次上线时，将不再具有地址租约功能。在配置IPLEASE参数值为ENABLE后上线的在线用户，去活用户，该用户再次上线时，需要选择到上一次激活使用的主锚点UPF后，才能生效租约功能。                                                                                                                                                                                                                        |
| RELEASETIME   | 地址租期(秒)        | 可选必选说明：该参数在"POOLTYPE"配置为"Local"时为条件可选参数。  参数含义：该参数指定用户释放之后，对应用户IP地址的等待释放时间。取值为0时，表示用户去激活后，其使用的本地地址将被立即释放，且可重新分配给其他用户使用。取值非0时，表示用户去激活后，其使用的地址不会立即释放，而是等待配置的时间之后才能被使用。  数据来源：本端规划  取值范围：整数类型，取值范围是0~86400，单位是秒。  默认值：无  配置原则： 建议配置RELEASTIME的值大于0，并根据实际需要进行调整。配置RELEASTIME为0且配置IPLEASE为Enable，则本次配置将执行失败。已经配置IPLEASE为Enable，本次配置时只配置RELEASTIME为0而未配置IPLEASE，则本次配置将执行失败。在配置RELEASTIME参数大于0后上线的在线用户，配置RELEASTIME参数为0后，去活用户，该用户使用的地址将被立即释放。配置RELEASTIME不为0，如果集中去活（例如锁APN去活）大量用户后，马上激活，大量新用户接入，这时大量地址处于等待释放状态，可能会出现因无空闲地址而导致的用户入网失败的情况。 |
| SINGLEIPFLAG  | 子池类型           | 可选必选说明：该参数在"POOLTYPE"配置为"Local"时为条件可选参数。  参数含义：该参数用于指定地址池子池类型。  数据来源：本端规划 取值范围： Enable（使能）Disable（去使能）  默认值：无  配置原则： 配置小地址池对性能影响较大，正常情况下不建议配置。当现网中经常出现的多个SPU同用一个地址池时，配置小容量地址池主要解决由于地址分配不均导致在用户激活过程中无可用的地址而激活失败的问题。由于原有的地址池分配处理中每个地址段最多可以划分为1024个子段，对于小地址池来说，每个子段只有一个地址，则小地址池中每个地址段的地址个数不能超过1024个。对于小地址池中总的地址个数不做限制，理论上每个小地址池最多可以配置1024*64=65536个地址。                                                                                                                                                                               |
| CHECKIPVALID  | 白名单检查开关        | 可选必选说明：该参数在"POOLTYPE"配置为"UDM"、"Radius"时为条件可选参数。  参数含义：该参数用于指定静态地址用户的白名单检查开关。  数据来源：本端规划 取值范围： Disable（去使能）Enable（使能）  默认值：无  配置原则： 地址池中“白名单检查开关”参数使能时，则表示该地址池关联的APN开启白名单。开启白名单开关后，接入该APN的静态地址用户激活时，根据地址查找对应的地址池，然后根据地址池查找关联的UPF实例，如果查找失败，则拒绝激活该用户。                                                                                                                                                                                                                                                                                |
| HASVPN        | 绑定VPN          | 可选必选说明：可选参数  参数含义：该参数用于指定是否绑定VPN。  数据来源：本端规划 取值范围： Disable（去使能）Enable（使能）  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| VPNINSTANCE   | VPN实例名         | 可选必选说明：该参数在"HASVPN"配置为"Enable"时为条件必选参数。  参数含义：该参数用于指定VPN实例名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~31。字母区分大小写，不支持空格。  默认值：无  配置原则：  该参数使用ADD CPVPNINST命令配置生成。                                                                                                                                                                                                                                                                                                                                                                          |
| IMSSW         | IMS开关          | 可选必选说明：该参数在"POOLTYPE"配置为"Local"时为条件可选参数。  参数含义：指定使能IP地址租约功能是否对IMS用户有效。  数据来源：本端规划 取值范围： Disable（去使能）Enable（使能）  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                     |
| OVERLAP       | 是否允许地址重叠       | 可选必选说明：该参数在"POOLTYPE"配置为"Local"时为条件可选参数。  参数含义：指定该地址池是全局地址池，还是局部地址池，局部地址池允许地址重叠。  数据来源：本端规划 取值范围： Disable（去使能）Enable（使能）  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                           |
| SPECIPALLOCSW | 是否分配特殊IP地址     | 可选必选说明：可选参数  参数含义：该参数用于指定是否分配特殊IP地址。IP地址中主机号全0或全1的IP地址是特殊IP地址。  数据来源：本端规划 取值范围： Disable（去使能）Enable（使能）  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                             |
| ALARMSW       | 是否开启地址使用率的告警功能 | 可选必选说明：可选参数  参数含义：该参数用于指定告警“ALM-100297 地址池组使用率超阈值”是否对本地址池内IP地址使用率生效。  数据来源：本端规划 取值范围： DISABLE（去使能）ENABLE（使能）INHERIT（继承）  默认值：无  配置原则：  如果该字段取值为“INHERIT”，则使用SET POOLALMPARA命令中地址池资源过载告警开关字段取值。                                                                                                                                                                                                                                                                                                                                    |

## 使用实例

修改一个本地IPv4地址池“pool1”的地址租约使能：

```
MOD CPADDRPOOL:POOLNAME="pool1",POOLTYPE=Local,IPLEASE=Enable,RELEASETIME=1;
```
