# 删除FQDN信息（RMV UDMFQDNINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除FQDN信息。

## 注意事项

FQDN对应的IP地址被删除后，后续业务将不再向此IP对应的客户端链路发送消息，HLB已经建立的链路将通过老化机制自动释放，即链路超过某段时间连续没有消息时，链路自动关闭。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                              |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------|
| NAME   | FQDN名称 | 可选必选说明：必选参数 参数含义：用于标识FQDN名称。该参数必须由ADD UDMFQDNINFO命令配置后才能在此处引用。 取值范围：长度不超过255位的字符串。 默认值：无。 配置原则：无。                                 |
| IPADDR | IP地址   | 可选必选说明：必选参数 参数含义：用于标识FQDN域名对应的IP地址。与“FQDN名称”配合使用，标识某一条FQDN信息。该参数必须由ADD UDMFQDNINFO命令配置后才能在此处引用。 取值范围：长度不超过40位的字符串。 默认值：无。 配置原则：无。 |

## 使用实例

删除“FQDN名称”为“udm1.huawei.com”对应的“IP地址”为“192.168.13.67”的FQDN信息。

```
RMV UDMFQDNINFO: NAME="udm1.huawei.com", IPADDR="192.168.13.67";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                    | 原因分析                                                 | 处理建议                                                                        |
|-------:|:-------------------------|:-----------------------------------------------------|:----------------------------------------------------------------------------|
|    505 | 当前操作的配置数据不存在             | 输入的FQDN名称与IP地址的组合未通过ADD UDMFQDNINFO添加，删除时无法找到FQDN信息。 | 根据实际情况，进行如下操作： FQDN信息不存在，不需要删除。使用LST UDMFQDNINFO命令查询已存在的FQDN信息，然后重新使用此命令删除。 |
| 360121 | IPADDR参数必须是IPv4地址或IPv6地址 | 输入的“IP地址”不是IPv4或IPv6地址。                              | 根据实际情况重新输入符合IP地址要求的参数。                                                      |
