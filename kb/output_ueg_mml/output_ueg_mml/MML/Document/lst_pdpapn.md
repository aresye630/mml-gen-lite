#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询指定用户PDP类型与APN NI地址的映射关系。

UNC中一次激活场景和MME中PDN连接建立场景，用户匹配到野卡或者匹配到多组签约数据时，需要根据IMSI和PDP/PDN类型查询本地的APN NI。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称      | 参数说明                                                                                                                                                                                                                                                            |
|:---------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围      | 可选必选说明：可选参数 参数含义：该参数用于指定签约用户的范围。 取值范围：“ALL_USER(所有用户)”“IMSI_PREFIX(指定IMSI前缀)”“IMSI_RANGE(指定IMSI范围)” 默认值：无                                                                                                                                                       |
| IMSIPRE  | IMSI前缀    | 可选必选说明：条件可选参数 参数含义：系统根据该参数值对用户的IMSI进行匹配，从而区分不同的用户群 前提条件：该参数在“用户范围”参数设置为“IMSI_PREFIX(指定IMSI前缀)”时，才需要配置。 取值范围：1～15位数字 默认值：无  说明： 根据“IMSI前缀 ”、“PDP/PDN类型”映射唯一的“APN NI”。                                                                                            |
| IMSI     | IMSI      | 可选必选说明：条件可选参数 参数含义：该参数用于指定所要查询的IMSI。 前提条件：该参数在“用户范围”参数设置为“IMSI_RANGE(指定IMSI范围)”时，才需要配置。 取值范围：1～15位数字 默认值：无  说明： 根据“IMSI ”、“PDP/PDN类型”映射唯一的“APN NI”。                                                                                                             |
| PDPTYPE  | PDP/PDN类型 | 可选必选说明：可选参数 参数含义：该参数用于指定PDP类型。 取值范围：“PT_IPV4(IPV4协议)”：表示用户激活的PDP类型为IPV4协议。“PT_IPV6(IPV6协议)”：表示用户激活的PDP类型为IPV6协议。“PT_PPP(点对点通信协议)”：表示用户激活的PDP类型为点对点通信协议。“PT_IPV4_IPV6(IPV4和IPV6协议)”：表示用户激活的PDP类型为IPV4和IPV6协议。“PT_ALL(所有类型)”：表示用户激活的PDP类型为所有类型，不包含Non-IP类型。 默认值：无 |

#### 使用实例

查询所有记录

LST PDPAPN:;

```
%%LST PDPAPN:;%%
RETCODE = 0  操作成功。

查询结果如下
--------------
   用户范围  =  指定IMSI前缀
   IMSI前缀  =  11111111
PDP/PDN类型  =  IPV4协议
     APN NI  =  2222
(结果个数 = 1)

---    END
```
