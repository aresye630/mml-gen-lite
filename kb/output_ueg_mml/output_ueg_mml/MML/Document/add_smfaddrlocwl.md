# 增加位置区域地址分配用户白名单（ADD SMFADDRLOCWL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于增加位置区域地址分配用户白名单，加入白名单的用户不受基于位置地址分配开关控制，不基于位置区域分配地址，即针对该用户，SET CPIPALLOCBYLOCSW命令中的SWITCH参数相当于DISABLE。

## 注意事项

- 该命令执行后只对新激活用户生效。

- 如果白名单中存在用户，那么至少有一条ADD CPPOOLGRPMAP命令中不包含LOCATIONGRPNAME参数，且SET CPAPNIPALLOCRULE或者SET CPIPALLOCRULE命令中IPv4/v6的三级规则中不能都有LOCATION（位置区）。

- 最多可输入20条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                     |
|:-------|:-------|:-----------------------------------------------------------------------------------------|
| MSISDN | MSISDN | 可选必选说明：必选参数  参数含义：该参数用于指定用户的MSISDN信息。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~15。  默认值：无  配置原则：无 |

## 使用实例

增加MSISDN为123456用户到位置区域地址分配白名单中：

```
ADD SMFADDRLOCWL: MSISDN="123456";
```
