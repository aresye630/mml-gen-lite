# 修改UE USAGE TYPE群组(MOD UEUSGTYPEGP)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于修改UE USAGE
TYPE群组的描述信息。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称              | 参数说明                                                                        |
|:--------------|:------------------|:----------------------------------------------------------------------------|
| UEUSGTYPEGPID | UE USAGE TYPE群组标识 | 可选必选说明：必选参数 参数含义：该参数用于指定UE USAGE TYPE群组标识。 数据来源：本端规划 取值范围：0～1023 默认值：无      |
| DESC          | 描述                | 可选必选说明：可选参数 参数含义：该参数用于指定UE USAGE TYPE群组的描述信息。 数据来源：本端规划 取值范围：1～32位字符串 默认值：无 |

#### 使用实例

修改“UE USAGE TYPE群组标识”为“0”的UE USAGE TYPE群组描述信息：

`MOD UEUSGTYPEGP: UEUSGTYPEGPID=0,
DESC="NB-IoT";`
