# 显示UDM用户缓存信息(DSP UDMUSERCACHE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询UDM用户缓存信息。

- 若要查询当前全部服务的缓存信息，请不要输入任何参数。
- 若要查询某个服务的缓存信息，请输入所要查询的服务实例号。

## 注意事项

无

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                 |
|:-------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
| SFINSTANCEID | SF实例号  | 可选必选说明：可选参数 参数含义：用于指示CSP服务管理中UDM的SF实例号。 取值范围：长度不超过65位的字符串。 默认值：无。 配置原则：执行DSP UDMSERVICE命令，在参数“服务类型”中选择“UdmSubService(UdmSubService)”，查询获得对应的“SF实例号”。 |

## 使用实例

1. 查询所有服务的缓存信息：

   `DSP UDMUSERCACHE:;`

   ```
   %%DSP UDMUSERCACHE:;%% 
   RETCODE = 0  操作成功  

   操作结果如下: 
   ------------- 
   SF实例号              缓存队列大小  每秒缓存查询次数  每秒缓存命中次数  二次查询次数  瞬时缓存命中率  平均缓存命中率  最小缓存命中率  最大缓存命中率    
   12512196205824747599  5             172               41                131           23              26              24              28 
   12512196205825148664  6             205               55                150           26              29              26              32 
   (结果个数 = 2)  

   ---    END
   ```
2. 查询服务实例号为“12512196205824747599”的缓存信息：

   `DSP UDMUSERCACHE: SFINSTANCEID="12512196205824747599";`

   ```
   %%DSP UDMUSERCACHE: SFINSTANCEID="12512196205824747599";%%
   RETCODE = 0  操作成功  

   操作结果如下:
   -------------         
           SF实例号  =  12512196205824747599     
       缓存队列大小  =  5 
   每秒缓存查询次数  =  172
   每秒缓存命中次数  =  41     
       二次查询次数  =  131   
     瞬时缓存命中率  =  23   
     平均缓存命中率  =  26   
     最小缓存命中率  =  24   
     最大缓存命中率  =  28
   (结果个数 = 1)  

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1。

| 输出项名称    | 输出项解释                                                |
|:---------|:-----------------------------------------------------|
| SF实例号    | 用于返回CSP服务管理中UDM的SF实例号。                               |
| 缓存队列大小   | 用于返回FE Cache实际缓存队列长度。                                |
| 每秒缓存查询次数 | 用于返回FE Cache每秒缓存访问次数。 该参数为0时，表示当前服务中无消息。             |
| 每秒缓存命中次数 | 用于返回FE Cache每秒缓存命中次数。                                |
| 二次查询次数   | 用于返回FE Cache缓存数据不一致场景下导致的二次查询次数。 以秒为单位统计单个周期内二次查询次数。 |
| 瞬时缓存命中率  | 用于返回FE Cache瞬时缓存命中率。 以秒为单位统计单个周期内缓冲命中率。              |
| 平均缓存命中率  | 用于返回FE Cache平均缓存命中率。 以60秒为单位统计单个周期内平均缓存命中率。          |
| 最小缓存命中率  | 用于返回FE Cache最小缓存命中率。 以60秒为单位统计单个周期内最小缓存命中率。          |
| 最大缓存命中率  | 用于返回FE Cache最大缓存命中率。 以60秒为单位统计单个周期内最大缓存命中率。          |
