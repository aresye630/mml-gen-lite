# 删除智能分流ULCL部署模式（RMV MULDNNULCLMODE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于删除指定智能分流专网DNN的ULCL部署模式。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                                                                                                                                                        |
|:-------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DEDDNN | 智能分流专网DNN | 可选必选说明：必选参数  参数含义：该参数指定智能分流专网DNN名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

删除指定智能分流专网DNN的ULCL部署模式，智能分流专网DNN为“special.dnn”。

```
RMV MULDNNULCLMODE: DEDDNN="special.dnn";
```
