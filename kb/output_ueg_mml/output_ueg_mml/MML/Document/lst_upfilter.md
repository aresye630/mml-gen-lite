# 查询UPF过滤组（LST UPFILTER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF**

该命令用于查询UPF过滤组信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识           | 参数名称    | 参数说明                                                                                                                                                 |
|:---------------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCENAME | UPF实例名称 | 可选必选说明：可选参数  参数含义：该参数用于标识UPF实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~255。不区分大小写。  默认值：无  配置原则：无                                                         |
| DNN            | DNN名称   | 可选必选说明：可选参数  参数含义：该参数用于指定DNN名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~66。不区分大小写，转成小写存储，可输入的字符有字母、十进制数字、“-”和“.”，并且开头和结尾只能是数字和字母，不能出现连续两个“.”。  默认值：无  配置原则：无 |

## 使用实例

- 查询所有UPF过滤组信息：

  ```
  %%LST UPFILTER:;%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
  UPF实例名称  =  upf1
      DNN名称  =  huawei.com
     过滤组ID  =  1
  (结果个数 = 1)

  ---    END
  ```
- 查询指定UPF实例名为“UP1”的信息：

  ```
  %%LST UPFILTER: NFINSTANCENAME="UP1";%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
  UPF实例名称  =  up1
      DNN名称  =  huawei.com
     过滤组ID  =  1
  (结果个数 = 1)

  ---    END
  ```

## 输出结果说明

| 输出项名称   | 输出项解释                                |
|:--------|:-------------------------------------|
| UPF实例名称 | 该参数用于标识UPF实例名称。                      |
| DNN名称   | 该参数用于指定DNN名称。                        |
| 过滤组ID   | 该参数用于指定过滤组ID，可以通过LST FILTERGP命令进行查询。 |
