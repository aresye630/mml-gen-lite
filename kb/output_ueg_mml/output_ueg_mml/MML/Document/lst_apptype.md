# 查询应用类型（LST APPTYPE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示当前添加的应用类型、分片数量和对应数据类型的分片数等信息。此信息可以从CUS的分片配置缓存中进行获取。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询当前的应用列表：

```
LST APPTYPE:;
```

```
%%LST APPTYPE:;%% 
RETCODE = 0  操作成功  

操作结果如下: 
-------------  
        应用类型 = SUP-DUS
    应用分片数量 = 1607
数据类型分片数量 = UserData：1607 RouteData: 1607
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。各输出项含义请参见表1输出项解释的参数说明。

| 输出项名称    | 输出项解释                                                  |
|:---------|:-------------------------------------------------------|
| 应用类型     | 用于返回查询的业务应用类型。                                         |
| 应用分片数量   | 用于返回对应应用类型的应用分片数量。                                     |
| 数据类型分片数量 | 用于返回对应应用类型的数据类型分片数量性。应用包含了几种数据类型，就会对应显示包含的几种数据类型的分片数量。 |
