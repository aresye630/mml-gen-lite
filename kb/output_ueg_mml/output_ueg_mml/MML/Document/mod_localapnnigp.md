# 修改本地APNNI组(MOD LOCALAPNNIGP)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用于修改本地APNNI组信息。定制APN纠正功能会引用该配置参数APNNIGRPID，可参考**ADD SMACTCTRL**命令的APNNIGRPID参数说明。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                                                                                                                                                            |
|:-----------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APNNIGRPID | 本地APNNI组号 | 可选必选说明：必选参数 参数含义：该参数用于指定本地APNNI组号。 数据来源：本端规划取值范围：0～127 默认值：无                                                                                                                                                                    |
| APNNI      | APNNI     | 可选必选说明：必选参数 参数含义：该参数用来指定APNNI信息。 数据来源：本端规划 取值范围：1～62位字符串 默认值：无 配置原则：APN网络标识由一个或多个LABEL构成，各LABEL间用“.”间隔。每个LABEL的构成字符只能是字母A～Z或a～z、数字0～9和中划线“-”，不区分大小写。APN网络标识地址不能以“rac”、“lac”、“sgsn”或“rnc”开头，不能以“.gprs”结尾，不能取值为“*”。同一组内APNNI不能相同。 |
| PRI        | APNNI优先级  | 可选必选说明：必选参数 参数含义：该参数用于设置用一个组内APNNI的优先级。 数据来源：本端规划 取值范围：0～127 默认值：无 配置原则： 数值越小，优先级越高。同一组内APNNI的优先级值不能相同。                                                                                                                         |

#### 使用实例

修改"本地APNNI组号"为1，"APNNI"为"HUAWEI1.COM"的"APNNI优先级"为1：

MOD LOCALAPNNIGP: APNNIGRPID=1, APNNI="HUAWEI1.COM", PRI=1;
