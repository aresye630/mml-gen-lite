# 删除PCRF对端PCEF能力字典(RMV PCEFABIDICT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于在配置数据库中删除一条对端PCEF实体能力字典记录。

## 注意事项

系统预置的能力字典无法删除。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                |
|:--------------|:-------|:------------------------------------|
| ABILITYDICTID | 能力字典ID | 用于标识PCEF能力字典的编号。 取值范围： 0~127 默认值： 无 |

## 使用实例

1. 删除一条PCEF能力字典。“能力字典ID”为“63”。

   ```
   RMV PCEFABIDICT: ABILITYDICTID=63;
   ```

   ```
   %%RMV PCEFABIDICT: ABILITYDICTID=63;%%
   RETCODE = 0  操作成功

   ---    END
   ```
