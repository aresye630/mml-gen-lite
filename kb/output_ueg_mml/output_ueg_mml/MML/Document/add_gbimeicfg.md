#### 命令功能

**适用网元：SGSN**

该命令用于增加GERAN指定号段用户获取和检查IMEI的策略。

#### 注意事项

- 该命令执行后立即生效。

- 指定号段的用户群采用对应的IMEI配置策略，未配置的用户群采用默认的IMEI配置策略。

- 该表最多包含128条记录。

输入的起始IMSI必须小于或者等于终止IMSI。判断起始IMSI和终止IMSI大小的原则是：对于输入IMSI的长度小于系统规定IMSI长度时，将该IMSI补足0到规定长度后进行大小比较，且起始IMSI必须小于终止IMSI。只有输入IMSI长度等于系统规定长度时，起始IMSI才能等于终止IMSI。 对于系统规定IMSI长度为15的情况，如表1所示：

|          起始IMSI |          终止IMSI | 实际限定IMSI范围                        |
|----------------:|----------------:|:----------------------------------|
|       123002666 |          123002 | 增加记录失败，起始IMSI大于终止IMSI             |
|          123002 |       123002666 | 123002000000000～123002666000000   |
|          123002 |          123002 | 增加记录失败，起始IMSI不能等于终止IMSI           |
| 123002000000000 | 123002000000000 | 仅限定IMSI号码123002000000000          |
| 123003000000000 | 123004000000000 | 123003000000000 ～ 123004000000000 |

- 输入的起始IMSI和终止IMSI定义的IMSI号段范围不允许与其它记录定义的IMSI号段范围相互交叉、包含或重合。

- 该命令部分参数与相关特性license共同完成该特性的开启，请在设置参数前使用**DSP LICENSE**命令确认对应特性license是否得到授权，执行**LST LICENSESWITCH**命令确认特性开关状态为“ENABLE(打开)”，具体相关特性请参考参数的说明。

系统部署完成后，已经存在一条默认的IMEI配置记录，参数的设置值如下表：

manage-ug；system-ug

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

增加IMSI前缀为“123456”的GERAN用户的IMEI配置，获取IMEISV，检查IMEI，EIR接口类型为Gf，IMEI获取失败允许接入，IMEI检查超时允许接入，允许灰名单用户接入，不允许黑名单用户接入，不允许EIR返回用户原因失败时接入，允许EIR返回设备原因失败时接入，EIR响应超时时长为5，IMEI未改变时Attach流程不需要检查IMEI，对应USRGRP1：

ADD GBIMEICFG: SUBRANGE=IMSI\_PREFIX, IMSIPRE="123456", GETIMEIPLC=IMEISV, CHKIMEIPLC=IMEI, ITTYPE=Gf, IMEIACCESS=YES, CTFLAG=YES, GRALLOW=YES, BLALLOW=NO, USERERR=NO, PROVIDERR=YES, EIROUTTIMER=5, CHKIMEITHRESHOLD=0, DESC="FOR USRGRP1";
