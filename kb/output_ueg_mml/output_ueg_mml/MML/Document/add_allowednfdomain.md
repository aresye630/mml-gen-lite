# 增加NF或NF服务支持的域名（ADD ALLOWEDNFDOMAIN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、NRF、NSSF、NCG、NEF、NWDAF、SCF**

该命令用于添加NF实例或NF服务实例所支持的域名。当NF实例或NF服务实例只支持为某些域名服务时，需要对支持的域名进行配置。配置后，其他NF只能通过本NF支持的域名来访问本NF的服务实例。

如果仅配置某个NF实例支持的域名，表示该NF实例下的所有服务实例支持的域名相同。

## 注意事项

- 该命令执行后立即生效。

- 实际命令配置记录数需要全网规划，超过NRF等NF的限制时，可能导致注册失败，出现"ALM-100225 NF注册失败"告警等问题。
- 如果某个NF服务实例下没有配置支持的域名，表示该NF服务实例支持所有的域名。
- 如果NF实例或该NF下的所有服务实例均未配置支持的域名，则表示该NF支持所有的域名。

- 最多可输入4096条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                |
|:---------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INDEX          | 索引标识   | 可选必选说明：必选参数  参数含义：本参数用于指定索引标识。  数据来源：全网规划  取值范围：整数类型，取值范围是0~4095。  默认值：无  配置原则：无                                                                                                                                                                                                                                                    |
| REGTYPE        | 注册类型   | 可选必选说明：必选参数  参数含义：本参数用于指定注册类型。  数据来源：全网规划 取值范围： RegInvalid（RegInvalid）RegNfProfile（RegNfProfile）RegService（RegService）RegMAX（RegMAX）  默认值：无  配置原则： 如果注册类型为REGINVALID(RegInvalid)，则配置无效。通常不需要配置。如果注册类型为REGNFPROFILE(RegNfProfile)，表示配置NF实例支持的域名。如果注册类型为REGSERVICE(RegService) ，表示配置NF服务实例支持的域名。如果注册类型为REGMAX(RegMAX) ，则配置无效。通常不需要配置。 |
| NFINSTANCENAME | NF实例名称 | 可选必选说明：必选参数  参数含义：本参数用于指定NF实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~50。  默认值：无  配置原则：  本参数需要与ADD NFUUID命令中的NFINSTANCENAME值保持一致。                                                                                                                                                                                                        |
| SRVINSTANCEID  | 服务实例标识 | 可选必选说明：可选参数  参数含义：本参数用于指定服务实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~50。  默认值：无  配置原则： 本参数与ADD CPNFSERVICE命令中的SRVINSTANCEID值一致时生效。本参数构成字符只能是字母A～Z或a～z、数字0～9、中划线"-"和下划线"_"，且不能以中划线"-"或下划线"_"开头和结尾，例如，Service_Instance_0。                                                                                                                 |
| NFDOMAIN       | 域名     | 可选必选说明：可选参数  参数含义：本参数用于指定允许访问的域名。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则： NF域名由一个或多个LABEL构成，各LABEL间用“.”间隔。每个LABEL的构成字符只能是字母A～Z或a～z、数字0～9和中划线“-”。不能用“-”或者“.”开头和结尾，中间不能出现连续的两个“.”。例：huawei.com                                                                                                                             |

## 使用实例

运营商A需要配置SMF\_Instance\_0的Service\_Instance\_0支持NFDOMAIN为huawei.com，INDEX为0，REGTYPE为RegService的域名。

```
ADD ALLOWEDNFDOMAIN: INDEX=0, REGTYPE= RegService, NFINSTANCENAME="SMF_Instance_0",SRVINSTANCEID="Service_Instance_0", NFDOMAIN="huawei.com";
```
