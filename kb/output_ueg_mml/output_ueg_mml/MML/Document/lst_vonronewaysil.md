# 查询单通检测信息（LST VONRONEWAYSIL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询单通检测信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询单通检测信息：

```
LST VONRONEWAYSIL:;
```

```
RETCODE = 0  操作成功

单通检测信息
------------
               单通检测开关  =  使能（开启）
       单通检测的丢包率门限  =  25
单通检测的连续MOS计算周期数  =  3
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见SET VONRONEWAYSIL的参数说明。
