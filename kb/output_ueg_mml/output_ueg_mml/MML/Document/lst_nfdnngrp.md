# 查询网元DNN组信息(LST NFDNNGRP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询网元DNN组信息。

- 若需要查询所有网元DNN组信息，不输入任何参数。
- 若需要查询某个组的网元DNN组信息，请输入“组名称”参数。
- 若需要查询某个网元DNN组信息，请输入“索引”参数。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                              |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------------|
| GRPNAME | 组名称    | 可选必选说明：可选参数 参数含义：用于指示系统按照组名称来查询网元DNN组信息；若不输入，则表示所有的组名称。 取值范围：长度不超过32的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。 |
| INDEX   | 索引     | 可选必选说明：可选参数 参数含义：用于指示系统按照索引来查询网元DNN组信息；若不输入，则表示所有的索引。 取值范围：1~10240 默认值：无。 配置原则：无。                                 |
| DNN     | DNN    | 可选必选说明：可选参数 参数含义：用于指示系统按照DNN来查询网元DNN组信息；若不输入，则表示所有的DNN。 取值范围：长度不超过64的字符串 默认值：无。 配置原则：无。                           |

## 使用实例

1. 查询所有的网元DNN组信息：

   ```
   LST NFDNNGRP:;
   ```

   ```
   %%LST NFDNNGRP:;%%
   RETCODE = 0  操作成功

   操作结果如下 
   ---------------------
   组名称      索引  DNN   
       
   nfdnngrp    1     dnn01        
   nfdnngrp2   2     dnn02    
   (结果个数 = 2) 
     
   ---    END
   ```
2. 查询“组名称”为“nfdnngrp”的网元DNN组信息：

   ```
   LST NFDNNGRP: GRPNAME="nfdnngrp";
   ```

   ```
   %%LST NFDNNGRP: GRPNAME="nfdnngrp";%%
   RETCODE = 0  操作成功 

   操作结果如下 
   ---------------------
   组名称  =  nfdnngrp
     索引  =  1   
      DNN  =  dnn01 
   (结果个数 = 1)  

   ---    END
   ```
3. 查询“索引”为“1”的网元DNN组信息：

   ```
   LST NFDNNGRP: INDEX=1;
   ```

   ```
   %%LST NFDNNGRP: INDEX=1;%%
   RETCODE = 0  操作成功

   操作结果如下 
   ---------------------
   组名称  =  nfdnngrp
     索引  =  1   
      DNN  =  dnn01
    (结果个数 = 1)  

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD NFSERSCOPE**命令的参数说明。
