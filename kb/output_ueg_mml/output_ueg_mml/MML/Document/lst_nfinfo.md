# 查询网元信息（LST NFINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询数据配置库中网元的特定配置信息：

- 若要查询全部网元的特定配置信息，请不要输入任何参数。
- 若要查询某个网元的特定配置信息，请输入“网元信息标识”或其他参数，或者“网元信息标识”和其他参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                 |
|:---------|:-------|:---------------------------------------------------------------------------------------------------------------------|
| NFINFOID | 网元信息标识 | 可选必选说明：可选参数 参数含义：用于指示系统按照网元信息标识来查询网元信息；若不输入，则表示查询所有网元信息标识的网元信息。 取值范围：长度不超过32位的字符串，字符串由数字、字母、“-”或“_”组成 默认值：无。 配置原则：无。 |
| NFTYPE   | 网元类型   | 可选必选说明：可选参数 参数含义：用于指示系统按照网元类型来查询某个网元信息；若不输入，则表示查询所有网元类型的网元信息。 取值范围：PCF(策略控制功能) 默认值：PCF(策略控制功能) 配置原则：无。               |

## 使用实例

1. 查询所有网元信息：

   ```
   LST NFINFO:;
   ```

   ```
   %%LST NFINFO:;%% 
   RETCODE = 0  操作成功    

   操作结果如下 
   ---------------------
   网元信息标识  网元类型          网元组ID  SUPI号段组  GPSI号段组  DNN列表  Rx Diameter 主机  Rx Diameter 域  DNN组 
     
   GPSI_01         策略控制功能      2         NULL        GPSI_01     NULL     NULL              NULL            NULL           
   pcfinfo_01      策略控制功能      1         SUPI_01     NULL        NULL     NULL              NULL            NULL   
   (结果个数 = 2)  

   ---    END
   ```
2. 查询一条网元信息，“网元信息标识”为“pcfinfo\_01”：

   ```
   LST NFINFO: NFINFOID="pcfinfo_01";
   ```

   ```
   %%LST NFINFO: NFINFOID="pcfinfo_01";%% 
   RETCODE = 0  操作成功
         
   操作结果如下 
   ---------------------
       网元信息标识  =  pcfinfo_01
           网元类型  =  策略控制功能        
           网元组ID  =  1
         SUPI号段组  =  SUPI_01
         GPSI号段组  =  NULL
            DNN列表  =  NULL
   Rx Diameter 主机  =  NULL
     Rx Diameter 域  =  NULL 
              DNN组  =  NULL 
   (结果个数 = 1)

     ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD NFINFO**命令的参数说明。
