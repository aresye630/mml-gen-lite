# 查询HLB对端(LST HLBPEER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

用于在配置数据库中查询与HLB对端实体的配置信息。

- 如果需要查询全部HLB对端实体的配置信息，请不要输入任何参数。
- 如果需要查询某个HLB对端实体的配置信息，请依据参数说明输入查询条件。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                                                                                                              |
|:----------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PEERID    | 对端标识    | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个设备标识查询HLB对端信息；若不输入，则表示所有的对端标识。 取值范围：0～63 默认值：无。 配置原则：无。                                                                                                                              |
| NAME      | 名称      | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个设备名称查询HLB对端信息；若不输入，则表示所有的设备名称。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                                                                                                                     |
| TYPE      | 对端类型    | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个设备类型查询HLB对端信息；若不输入，则表示所有的对端类型。 取值范围：NRF(NRF)AMF(AMF)SMF(SMF)BSF(BSF)CHF(CHF) 默认值：无。 配置原则：无。                                                                                          |
| HTTPSFUNC | HTTPS功能 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个HTTPS功能来查询HLB对端信息；若不输入，则表示所有的HTTPS功能。 取值范围： ON(打开)：表示启用TLS证书。OFF(关闭)：表示不启用TLS证书。 默认值：无。 配置原则：无。                                                                                      |
| CERTSCENE | 证书应用场景  | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个证书应用场景来查询HLB对端信息；若不输入，则表示所有的证书应用场景。 取值范围： UPCF_HLB_Lcert(UPCF_HLB_Lcert) 默认值：无。 配置原则：无。                                                                                              |
| TLSCFGID  | TLS配置ID | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个TLS配置ID来查询HLB对端信息；若不输入，则表示所有的TLS配置ID。 取值范围：1～128 默认值：无。 配置原则：无。                                                                                                                      |
| SIGROUTE  | 信令路由    | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个信令路由功能查询HLB对端信息；若不输入，则表示所有的信令路由。 取值范围哪： ON(打开)：表示打开信令路由功能。OFF(关闭)：表示关闭信令路由功能。 默认值：OFF。 配置原则：无。                                                                                       |
| LINKNUM   | 链路数     | 可选必选说明：可选参数 参数含义：当“信令路由”的取值为“ON”时该参数有效，用于指示系统按照链路数量查询HLB对端信息；若不输入，则表示所有的链路数。 取值范围：2～4 默认值：无。 配置原则：无。                                                                                                              |
| STREAMNUM | 最大流数目   | 可选必选说明：可选参数 参数含义：当“信令路由”的取值为“ON”时该参数有效，用于指示系统需要按照对端下每条链路发送的最大流数目查询HLB对端信息；若不输入，则表示所有的最大流数目。 根据“链路数”设置不同链路的最大流数目，使用“-”区分不同链路，如配置2个链路的最大流数目分别为1024和2048，则输入 1024-2048。 取值范围：长度不大于128的字符串。限定只能输入数字和-。 默认值：无。 配置原则：无。 |
| LINKMODE  | 链路模式    | 可选必选说明：可选参数 参数含义：当“信令路由”的取值为“ON”时该参数有效，用于指示系统需要按照对端链路的哪个链路模式查询HLB对端信息；若不输入，则表示所有的链路模式。 取值范围： PRIORITY(优先级)WEIGHT(权重) 默认值：无。 配置原则：无。                                                                               |
| PRIORITY  | 优先级     | 可选必选说明：可选参数 参数含义：当“链路模式”取值为“Priority”时该参数有效，用于指示系统需要按照哪个优先级来查询HLB对端信息；若不输入，则表示所有的优先级。 根据“LINKNUM”设置不同链路的优先级，使用“-”区分不同链路，如配置2个链路的优先级分别为16和32，则输入 16-32。 取值范围：长度不超过64的字符串，限定只能输入数字和-。 默认值：无。 配置原则：无。                |
| WEIGHT    | 权重      | 可选必选说明：可选参数 参数含义：当“链路模式”取值为“Weight”时该参数有效，用于指示系统需要按照哪个权重数来查询HLB对端信息；若不输入，则表示所有的优先级。 根据“LINKNUM”设置不同链路的权重，使用“-”区分不同链路，如配置2个链路的权重分别为5和5，则输入 5-5，所有链路权重加起来等于10。 取值范围：长度不大于64的字符串，限定只能输入数字和-。 默认值：无。 配置原则：无。          |

## 使用实例

```

```
