# 启动时延统计任务（STR DELAYSTAT）

## 命令功能

**须知** 

- 此命令是高危命令，如果执行不当会影响系统性能，需联系华为技术支持确认后再执行。
- 本功能启用后，所启用服务的cpu可能上涨5%。

该命令主要用于统计各内部消息流程的时延信息，并将相关信息输出到文件中。

## 注意事项

- 命令执行结束后，统计到的消息流程时延信息将存储在PES服务所在容器的“/opt/csplog/{APPID}/PcfPolicyEngineService/export/log”目录下，文件名格式为“pes\_delay\_x\_yyyymmddhhmmss.csv.gz”。其中：
  - *x*指PES的进程Id。
  - *yyy**ymmddhhmmss*表示生成文件时的时间戳。
- 统计到的消息流程时延信息也可以通过OM Portal上“监控分析 > 运行日志”下载，具体下载步骤如下：
  1. 登录CSP Portal，选择“监控分析 > 运行日志”，在左侧导航栏中选择“服务日志收集”。
  2. 设置“应用名称”，然后从“服务类型”导航树中选中“PcfPolicyEngineService”节点下选择需要导出PES消息流程时延信息的节点。

     **说明** 

     导航树中选择的PES节点名称和执行该命令输入的“实例号”所属的“虚拟机IP”（裸机场景下为“容器IP”）保持一致，“虚拟机IP”（裸机场景下为“容器IP”）可以通过查询服务信息（DSP SERVICEINFO）命令查询获取。
  3. 设置参数“时间区间”，单击“开始收集”。
  4. 收集完成后，单击“日志下载地址”右侧的压缩包名称，可以将统计到的消息流程时延信息保存至本地。

## 参数说明

| 参数标识         | 参数名称      | 参数说明                                                                                                                     |
|:-------------|:----------|:-------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE  | 服务类型      | 可选必选说明：必选参数 参数含义：该参数用于指定微服务实例的服务类型。 取值范围：PcfPolicyEngineService(PcfPolicyEngineService) 默认值：无。 配置原则：无。                   |
| DURATION     | 时延统计任务时长  | 可选必选说明：必选参数 参数含义：用于设置时延统计任务的时间长度。 取值范围：10~604800 单位：秒 默认值：60                                                             |
| NEEDFLOWCTRL | 流控时是否自动停止 | 可选必选说明：必选参数 参数含义：用于控制流控任务启动时，是否自动停止时延统计任务。 取值范围：枚举类型。 TRUE（是）：流控任务启动时停止时延统计任务。FALSE（否）：流控任务启动时继续执行时延统计任务。 默认值：TRUE（是）    |
| INSTANCEID   | 实例号       | 可选必选说明：可选参数 参数含义：用于指定启动时延统计任务时微服务的实例号。 取值范围：0~256长度字符串 默认值：无。  说明： 本参数如果为空则对所有实例都生效，参数可以通过查询服务信息（DSP SERVICEINFO）命令查询获取。 |

## 使用实例

统计60秒时间内的PES微服务时延统计任务，“实例号”为“4218287”，“流控时是否自动停止”为“TRUE（是）”。

```
STR DELAYSTAT: SERVICETYPE=PcfPolicyEngineService, DURATION=60, NEEDFLOWCTRL=TRUE, INSTANCEID="4218287";
```
