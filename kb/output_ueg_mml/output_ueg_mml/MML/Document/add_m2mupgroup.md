# 增加M2M关联的UPF组（ADD M2MUPGROUP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于增加M2M关联的UPF组。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入3000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                       |
|:-----------|:-------|:-------------------------------------------------------------------------------------------|
| UPFGRPNAME | UPF组名称 | 可选必选说明：必选参数  参数含义：该参数用于指定UPF组名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

增加M2M关联的UPF组，组名为upfgrp1：

```
ADD M2MUPGROUP: UPFGRPNAME="upfgrp1";
```
