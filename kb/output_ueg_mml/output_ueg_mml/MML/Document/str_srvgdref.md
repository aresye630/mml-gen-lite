# 启动强制刷新微服务全局数据（STR SRVGDREF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令对性能有影响，建议在话务量低时执行。执行该命令前，需要与华为技术支持确认后才可以实施。

该命令是用于强制刷新UdmSubService/UdmAuthService中的全局数据。

## 注意事项

- 该命令支持在存储bypass时使用。
- 当多个UDM对接同一个USCDB时，不建议在多个UDM上同时执行本命令。

## 使用实例

设置数据刷新，“服务类型”为“UdmSubService”，“服务实例ID”为“13564655801154191991”,“加载表名”为“N\_G\_GLOBAL\_DATA(N\_G\_GLOBAL\_DATA)”，。

```
STR SRVGDREF: ST=UdmSubService, MSINSID="13564655801154191991", TABLE=N_G_GLOBAL_DATA;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表 错误码列表所示。

|    错误码 | 消息解释              | 原因分析                 | 处理建议                                 |
|-------:|:------------------|:---------------------|:-------------------------------------|
| 360145 | 调试任务服务类型实例不存在。    | “服务实例ID”输入错误或者不存在。   | 请通过DSP UDMSERVICE查询“服务实例ID”，重新执行该命令。 |
| 360239 | 所选服务类型不支持对所选表强制刷新 | 选择的“服务类型”和“加载表名”不匹配。 | 请重新选择强制刷新的表，确保输入的是所选“服务类型”对应的“加载表名”。 |
| 360240 | 不支持强制刷新该表         | 输入的“加载表名”不支持刷新。      | 请重输入“加载表名”，确保输入的“加载表名”在该命令的取值范围中。    |
