# 查询NSSF功能实例信息（LST NSSFFUNCTION）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：NSSF**

本命令用于查询NSSF功能实例的信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询所有NSSF功能实例的配置信息。

```
LST NSSFFUNCTION;
```

## 输出结果说明

| 输出项名称      | 输出项解释                                                      |
|:-----------|:-----------------------------------------------------------|
| NSSF功能实例号  | NSSF功能实例号。                                                 |
| NSSF功能实例描述 | NSSF功能实例描述。                                                |
| 管理状态       | NSSF功能实例的管理状态。                                             |
| 运行状态       | NSSF功能实例的运行状态。                                             |
| FQDN       | NSSF功能实例的FQDN。                                             |
| 最大切片选择次数   | 该参数用于指定NSSF支持的每秒最大切片选择次数，系统会根据“NSSF每秒事务数”License项值自动刷新该参数。 |
