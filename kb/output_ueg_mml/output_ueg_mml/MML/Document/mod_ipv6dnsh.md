# 修改IPV6 DNS Hostfile记录(MOD IPV6DNSH)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于修改网元接口所对应的IPv6地址信息。

#### 注意事项

- 该命令执行后立即生效。
- 一个主机名最多能对应64个IP地址，且64个地址中至少有一个有效的单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址（::1）、链路本地地址（FE80::/10）和组播地址（FF00::/8）。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识                | 参数名称            | 参数说明                                                                                                                                                                                                                                                                                                                                            |
|:--------------------|:----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HOSTNAME            | 主机名             | 可选必选说明：必选参数 参数含义：该参数用于配置主机名。 数据来源：整网规划 取值范围：1～255位字符串 默认值：无 配置原则：参见命令ADD IPV6DNSH。  说明： “HOSTNAME”和“ADDRSECTION”作为组件查找记录，不能修改。主机信息表中配置的IPV6 DNS主机名称不能重复。                                                                                                                                                                                        |
| ADDRSECTION         | 地址区间号           | 可选必选说明：必选参数 参数含义：该参数用来划分IP地址区间。对同一个域名最多可以配置64个IP地址，使用此参数可以将64个IP地址划分为8个IP地址区间，每个区间最多8个IP地址，这样可以分8次来配置64个IP地址。 数据来源：整网规划 取值范围：“SECTION1(SECTION1)”“SECTION2(SECTION2)”“SECTION3(SECTION3)”“SECTION4(SECTION4)”“SECTION5(SECTION5)”“SECTION6(SECTION6)”“SECTION7(SECTION7)”“SECTION8(SECTION8)” 默认值：无  说明： “ADDRSECTION”和“HOSTNAME”作为组件查找记录，不能修改。 |
| IPV6ADDR1_IPV6ADDR8 | IPv6地址1～IPv6地址8 | 可选必选说明：可选参数 参数含义：该参数用于指定主机对应的IPV6地址。 数据来源：整网规划 取值范围：::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 配置原则：IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址（::1）、链路本地地址（FE80::/10）、组播地址（FF00::/8）和IPv4映射地址（::FFFF:XXXX:XXXX），若为IPv4兼容地址时，需判断是否符合IPv4地址要求。                                                                      |
| PRIORITY1_PRIORITY8 | 优先级1～优先级8       | 可选必选说明：可选参数 参数含义：该参数用于配置IP地址的优先级。 数据来源：整网规划 取值范围：0～255 默认值：无 配置原则：优先级数值配置越小，代表优先级越高。IP地址的优先级越高，越排在前面。                                                                                                                                                                                                                                           |
| WEIGHT1_WEIGHT8     | 权重1～权重8         | 可选必选说明：可选参数 参数含义：该参数用于配置IP地址的权重。 数据来源：整网规划 取值范围：1～255 默认值：无 配置原则：权重数值配置越大，代表权重越大。对于同优先级的IP地址，进行随机选择，IP地址的权重越大，被选中的概率就越大。  说明： 权重高的排在前面的机率越高（所配的数越小，权重越小）。                                                                                                                                                                                       |

#### 使用实例

网络改造过程中，将网络中某网元的“主机名”为“HUAWEI1.COM.GTP.APN.EPC.MNC001.MCC308.3GPPNETWORK.ORG”的一条记录，ADDRSECTION1下的“IPv6地址1”修改为“2001:db8:10:19:44:55:10:12”、“优先级1”修改为“10”、“权重1”修改为“100”：

`MOD IPV6DNSH: HOSTNAME="HUAWEI1.COM.GTP.APN.EPC.MNC001.MCC308.3GPPNETWORK.ORG", ADDRSECTION=SECTION1, IPV6ADDR1="2001:db8:10:19:44:55:10:12", PRIORITY1=10, WEIGHT1=100;`
