# 删除联合接入HSS白名单(RMV PSCSHSS)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于删除联合接入HSS白名单。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                              |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------------|
| HSSHOST | HSS主机名 | 可选必选说明：必选参数 参数含义：该参数用于标识HSS的主机名。 数据来源：全网规划 取值范围：1~127位字符串。数字“0~9”，大写字母“A~Z”，小写字母“a~z”，特殊字符“-”，“.”，其他均为非法字符。 默认值：无 |

#### 使用实例

删除主机名为HUAWEI的联合接入HSS白名单:

```
RMV PSCSHSS: HSSHOST="HUAWEI";
```
