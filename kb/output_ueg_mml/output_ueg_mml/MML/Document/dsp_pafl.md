# 查询PCRF对端AF链路状态信息(DSP PAFL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为维护类命令，用于查询PCRF实体和对端AF实体的链路状态信息。如果需要查询所有链路的状态信息，请不要输入任何参数；如果需要查询某条链路的状态信息，请依据参数说明输入查询条件。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                       |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------|
| PCRFID | PCRF标识 | 用于标识PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围： 1 默认值： 无。                                                                  |
| AFID   | 对端AF标识 | 用于标识对端AF实体，该参数必须先由ADD PAF命令定义，然后才能在此处索引。 取值范围： 0～15 默认值： 无。                                                                |
| LNKID  | 对端链路标识 | 用于在UPCF的配置库中定义一个对端AF实体链路。该参数的配置原则：如果配置多个对端AF实体链路，从0开始顺序配置。 取值范围： 0～31 默认值： 无。                                              |
| STATE  | 链路状态   | 用于指定链路状态，包括：在线、离线、未知三种状态。 取值说明： LINKDOWN(离线)LINKUP(在线)UNKNOWN(未知)  说明： 当链路未关联上DLB实例时，无法获取链路状态，链路状态的查询返回结果为UNKNOWN。 默认值： 无。 |

## 使用实例

1. 查询所有的PCRF实体和对端AF实体链路的状态信息。

   ```
   DSP PAFL:;
   ```

   ```
   %%DSP PAFL:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
    PCRF标识  对端AF标识  对端链路标识  DLB实例号                链路状态

    1         0           0             12851153534470311709     离线    
    1         0           1             12851153534470311709     离线    
   (结果个数 = 2)

   ---    END
   ```
2. 查询一条PCRF实体和对端AF实体链路的状态信息。“PCRF标识”为“1”，“对端AF标识”为“0”，“对端链路标识”为“0”，其他参数使用缺省值。

   ```
   DSP PAFL: PCRFID=1, AFID=0, LNKID=0;
   ```

   ```
   %%DSP PAFL: PCRFID=1, AFID=0, LNKID=0;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
       PCRF标识  =  1
     对端AF标识  =  0
   对端链路标识  =  0
      DLB实例号  =  12851153534470311709
       链路状态  =  离线
   (结果个数 = 1)

   ---    END
   ```
