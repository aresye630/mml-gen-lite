# 增加IMEI群组成员(ADD IMEIGPMEM)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

此命令用于为**ADD IMEIGP**增加的IMEI群组增加IMEI成员，完成以群粒度进行业务策略控制。

#### 注意事项

- 此命令执行后立即生效。
- 此命令最大记录数为10000。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称         | 参数说明                                                                                                           |
|:---------|:-------------|:---------------------------------------------------------------------------------------------------------------|
| IMEIGPID | IMEI群组标识     | 可选必选说明：必选参数 参数含义：该参数用于指示IMEI群组标识。 前提条件：“IMEI群组标识”已经通过ADD IMEIGP配置。 数据来源：本端规划 取值范围：1~50 默认值：无                   |
| IMEITAC  | IMEI设备型号核准号码 | 可选必选说明：必选参数 参数含义：该参数用于设置用户的设备型号核准号码（TAC）。TAC由IMEI的前8位数字组成，由欧洲型号认证中心分配，用来标识某一型号的手机。 数据来源：本端规划 取值范围：8位十进制数 默认值：无 |
| UEDESC   | 终端详细信息       | 可选必选说明：可选参数 参数含义：该参数用于指定终端详细信息。 数据来源：本端规划 取值范围：0~255位字符串 默认值：无                                                 |

#### 使用实例

增加一个IMEI群组，其群组名称为“iphone”，群组成员设备型号核准号码为35437906：

ADD IMEIGP: IMEIGPID=1, IMEIGPN="iphone";

ADD IMEIGPMEM: IMEIGPID=1, IMEITAC="35437906";
