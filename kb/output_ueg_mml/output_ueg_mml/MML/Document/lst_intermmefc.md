# 查询Inter-MME流控参数(LST INTERMMEFC)

#### 命令功能

**适用网元：MME**

该命令用于查询Inter-MME接入流控功能的相关参数。

#### 注意事项

此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询Inter-MME流控参数：

LST INTERMMEFC:;

```
%%LST INTERMMEFC:;%%
RETCODE = 0  操作成功。

输出结果如下
--------------
Inter-MME接入流控功能开关  =  开启
           流控速率最小值  =  10
           流控速率最大值  =  200
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见**SET INTERMMEFC**的参数说明。
