# 设置会话备份数据审计任务参数（SET SESSADT）

## 命令功能

该命令用于设置会话备份数据审计任务参数。

操作员可以通过执行**SET SESSADT**命令设置周期运行会话备份数据审计任务，使会话备份数据审计任务从设置的“启动时间”开始，以“审计周期”为周期自动运行任务。

## 注意事项

该命令存在系统初始记录，参数的初始设置值如下表：

| 审计类型   | 启动时间     |   审计周期 |   会话过期时长 |   审计速度 | 任务状态   | 审计失败告警   |   告警阈值（万分之一） | PS_IPADDR表审计功能   |
|:-------|:---------|-------:|---------:|-------:|:-------|:---------|-------------:|:-----------------|
| UPCF   | 03:00:00 |     12 |      nan |     10 | 打开     | 上报告警     |           20 | 不开启审计            |
| USCDB  | 03:00:00 |     24 |       48 |     30 | 打开     | 不上报告警    |           20 | 不开启审计            |

## 参数说明

| 参数标识        | 参数名称           | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:------------|:---------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TYPE        | 审计类型           | 用于设置审计任务的类型。 取值范围： UPCF(UPCF与USCDB间的会话数据审计)USCDB(USCDB的会话备份冗余数据清理审计) 说明： USCDB类型的参数设置记录用于冗余会话备份数据审计任务的参数。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| STRTIME     | 启动时间           | 用于设置审计任务启动时间点。 取值范围：00:00:00～23:59:59 默认值：无。  说明： 系统启动后，若不设置该参数，系统将该参数的值设置为“03:00:00”。                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| INTERVAL    | 审计周期           | 用于设置一轮审计任务的间隔时长。 取值范围：1～24 单位：小时  说明： 系统启动后，若不设置该参数： 当“审计类型”为“UPCF”时，系统将该参数的值设置为“12”。 当“审计类型”为“USCDB”时，系统将该参数的值设置为“24”。                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| EXPIRED     | 会话过期时长         | 用于设置USCDB中的会话数据多长时间过期。在“审计类型”为“USCDB”时有效，此时长不能小于“审计类型”为“UPCF”的审计任务的“审计周期”值，因为需要通过UPCF类型的审计任务来更新时间戳。 取值范围：1～72 单位：小时 默认值：无。  说明： 系统启动后，若不设置该参数，系统将该参数的值设置为“48”。                                                                                                                                                                                                                                                                                                                                                                                            |
| SPEED       | 审计速度           | 用于设置审计任务处理速度，系统将按照此速度处理审计任务。 取值范围：1～250 单位：个/秒 默认值：无。  说明： 系统启动后，若不设置该参数，系统将该参数的值设置为“10”。由于系统性能限制，该参数不建议设置超过50。当该参数取值大于50时，系统会根据性能优化自动调整每秒处理的任务数，不一定会达到设置的处理速度。                                                                                                                                                                                                                                                                                                                                                                                           |
| STATUS      | 任务状态           | 用于设置审计任务状态。 取值范围： ENABLE(打开)：打开审计任务DISABLE(关闭)：关闭审计任务 默认值：无。  说明： 系统启动后，若不设置该参数，系统将该参数的值设置为“ENABLE(打开)”。多FE场景下，只在一个FE开启“审计类型”为“USCDB”的审计任务，该参数设置为“ENABLE(打开)”；其他FE关闭审计功能，参数设置为“DISABLE(关闭)”。                                                                                                                                                                                                                                                                                                                                                              |
| FAILEDALARM | 审计失败告警         | 用于设置UPCF审计失败时，是否上报“ALM-34137 会话备份审计失败比例超过阈值”告警。 取值范围： YES(上报告警)NO(不上报告警) 默认值：无。  说明： 当“审计类型”为“USCDB”时，本参数不支持设置，固定取值为“NO”。系统启动后，当“审计类型”为“UPCF”时，若不设置该参数，系统将该参数的值设置为“YES(上报告警)”。                                                                                                                                                                                                                                                                                                                                                                            |
| ALARMTH     | 告警阈值（万分之一）     | 用于设置UPCF审计失败会话数与审计的会话总数比例告警阈值。 取值范围：1～10000 默认值：无。  说明： 当“审计类型”为“USCDB”时，本参数不生效。系统启动后，当“审计类型”为“UPCF”时，若不设置该参数，系统将该参数的值设置为“20”。当“审计失败告警”为“YES(上报告警)”时，需要设置此参数。                                                                                                                                                                                                                                                                                                                                                                                             |
| IPADDRADT   | PS_IPADDR表审计功能 | 用于设置UPCF进行“USCDB”类型的审计时，是否对PS_IPADDR表进行审计。 取值范围： YES(开启审计) NO(不开启审计) YES_ENHANCED(开启增强审计) 默认值：无。  说明： 当“审计类型”为“UPCF”时，本参数不支持设置，固定取值为“NO(不开启审计)”。 “IPADDRADT”从其他值修改为“YES_ENHANCED（开启增强审计）”时，修改动作必须在升级操作的X小时后才能执行，X为LST SESSADT查到的“会话过期时长”的参数值。系统启动后，当“审计类型”为“USCDB”时：若不设置该参数，系统将该参数的值设置为“NO(不开启审计)”。若本参数取值为“YES(开启审计)”，则离线审计支持删除IP路由表中记录的时间戳距离当前系统时间超过48小时且时间戳不为0的记录。若本参数取值为“YES_ENHANCED(开启增强审计)”，则离线审计支持删除IP路由表中记录的时间戳距离当前系统时间超过48小时和时间戳为0的记录。 IP路由表记录的时间戳在20.10.2及以后版本默认不为0，从低版本升级到20.10.2及更高版本的所有记录默认为0，低版本的有效记录在升级后的24小时内会刷新为系统时间，低版本的无效记录在升级后一直保持为0。 |

## 使用实例

周期进行会话备份数据审计任务：设置“审计类型”取值为“UPCF”“启动时间”取值为“15:27:03”，“审计周期”取值为“24小时”，“审计速度”取值为“30个/秒”，“任务状态”取值为“ENABLE(打开)”，“审计失败告警”取值为“YES(上报告警)”，“告警阈值（万分之一）”取值为“30”。

启动会话备份数据审计任务操作。执行命令如下：

```
SET SESSADT: TYPE=UPCF, STRTIME=15&27&03, INTERVAL=24, SPEED=30, STATUS=ENABLE, FAILEDALARM=YES, ALARMTH=30;
```


## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释                                  | 原因分析                                                | 处理建议                                                      |
|------:|:---------------------------------------|:----------------------------------------------------|:----------------------------------------------------------|
| 58184 | 当参数TYPE取值为USCDB时，参数FAILEDALARM取值只能是NO。 | 当参数“TYPE”取值为“USCDB”时，参数“FAILEDALARM”取值为“YES(上报告警)”。 | 当参数“TYPE”取值为“USCDB”时，请务必将参数“FAILEDALARM”取值设置为“NO(不上报告警)”。 |
