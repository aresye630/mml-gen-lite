# 显示LDP LSP管理组件Outsegment转发表项（DSP LDPLSPMGOUTSEG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示LDP LSP管理组件的Outsegment转发表项。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称       | 参数说明                                                                                                      |
|:-------------|:-----------|:----------------------------------------------------------------------------------------------------------|
| VRFNAME      | VPN实例名称    | 可选必选说明：可选参数 参数含义：该参数用于表示VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                                  |
| FECADDR      | 目的地址       | 可选必选说明：可选参数 参数含义：该参数用于表示目的地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无 配置原则：当“PREFIXLENGTH”参数被输入的时候，该参数也必须输入。       |
| PREFIXLENGTH | 前缀长度       | 可选必选说明：可选参数 参数含义：该参数用于表示目的地址的前缀长度。 数据来源：本端规划 取值范围：整数类型，取值范围为0～32。 默认值：无 配置原则：当“FECADDR”参数被输入的时候，该参数也必须输入。 |
| PEERID       | 对等体的LSR ID | 可选必选说明：可选参数 参数含义：该参数用于表示对等体的LSR ID。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无                                        |

#### 使用实例

显示LDP LSP管理组件Outsegment转发表项：

```
DSP LDPLSPMGOUTSEG:VRFNAME="_public_",FECADDR="192.168.1.1",PREFIXLENGTH=32;
```
