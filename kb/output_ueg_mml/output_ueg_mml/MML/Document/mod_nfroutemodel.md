# 修改网元路由模式（MOD NFROUTEMODEL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会导致业务通信路由方式变更，造成业务呼损或系统崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改UDM和NRF之间SCP对接的网元路由模式。在该命令中，系统通过“路由名称”参数来唯一标识一条网元路由模式记录。

## 注意事项

UDM在系统初始化的时候已经预置如下几条默认数据记录，操作员可以通过**LST NFROUTEMODEL**命令查询得出。预置的数据记录仅允许修改“发现模式”和“开关”；且仅预置记录中“路由名称”为“Default\_AMF\_PLMN”和“Default\_SMF\_PLMN”的两条记录支持设置“PLMN ID”参数值为“Default”。

```
ADD NFROUTEMODEL: RTNAME="Default_Global", NFTYPE=DEFAULT, MODEL=MODEL-B, SWITCH=ENABLE;
ADD NFROUTEMODEL: RTNAME="Default_AMF_PLMN", NFTYPE=AMF, DESTTYPE=PLMN, PLMN="Default", MODEL=MODEL-B, SWITCH=DISABLE;
ADD NFROUTEMODEL: RTNAME="Default_SMF_PLMN", NFTYPE=SMF, DESTTYPE=PLMN, PLMN="Default", MODEL=MODEL-B, SWITCH=DISABLE;
```

## 参数说明

| NFTYPE     | 网元类型      | 可选必选说明：必选参数 参数含义：用于标识网元实例的类型。 取值范围： AMF(AMF)SMF(SMF)SMSF(SMSF)NEF(NEF)DEFAULT(DEFAULT)SCP(SCP)SEPP(SEPP) 默认值：无 配置原则：无。                                                                                                                                                                                                                                                                                                                                       |

| IPSTART    | IP地址段起始地址 | 可选必选说明：条件必选参数 参数含义：用于标识IP地址段起始地址。 取值范围：IPV4地址/IPV6地址。 默认值：无 配置原则：当“目标类型”为“IPRANGE(IPRANGE)”时，该参数有效且必选。                                                                                                                                                                                                                                                                                                                                                       |
| IPEND      | IP地址段结束地址 | 可选必选说明：条件必选参数 参数含义：用于标识IP地址段结束地址。 取值范围：IPV4地址/IPV6地址。 默认值：无 配置原则：当“目标类型”为“IPRANGE(IPRANGE)”时，该参数有效且必选。                                                                                                                                                                                                                                                                                                                                                       |
| FQDNSUFFIX | 域名后缀      | 可选必选说明：条件必选参数 参数含义：用于标识域名后缀。 取值范围：由1~255位字节组成的字符串。 默认值：无 配置原则： 当“目标类型”为“FQDNSUFFIX(FQDNSUFFIX)”时，该参数有效且必选。需要符合域名格式，由“.”分隔的多个Label组成，其中Label由字母、数字、-和_组成。                                                                                                                                                                                                                                                                                                     |

## 使用实例

修改网元路由模式，“路由名称”为“4604567890001”，“网元类型”为“AMF(AMF)”，“发现模式”为“MODEL-B(模式B)”，“开关”为“ENABLE(使能)”：

```
MOD NFROUTEMODEL: RTNAME="4604567890001", NFTYPE=AMF, MODEL=MODEL-B, SWITCH=ENABLE, CONFIRM=Y
```
