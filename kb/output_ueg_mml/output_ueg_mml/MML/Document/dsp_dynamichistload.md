# 显示各业务pod历史的忙时负载、权重和部署位置信息（DSP DYNAMICHISTLOAD）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C、SMF、GGSN**

该命令用于查询指定的服务类型的业务pod近七天的忙时负载、权重和部署位置信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                           |
|:------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 服务类型   | 可选必选说明：必选参数  参数含义：该参数用于指定服务类型，查看对应的Token、权重和负载信息。  数据来源：本端规划  取值范围：1.UAM会话管理组（UEAM与UEM） 2. USM会话管理服务（UESM、SMC、UPC、SM5GCM、STG、SM5GPOLICY） “UAM_0（UAM_0）”：涉及如下类型POD：接入/移动性管理POD。“USM_0（USM_0）”：涉及如下类型POD：会话管理POD。  默认值：无  配置原则：无 |

## 使用实例

查询“服务类型”为“UAM\_0”的pod的动态权重信息，执行如下命令：

```
%%DSP DYNAMICHISTLOAD
: SERVICETYPE=UAM_0;%%
RETCODE = 0  操作成功

结果如下
--------
服务类型  日期  POD名称  Node ID  Host ID  忙时时间段  忙时负载  权重  TOKEN数量
UAM_0  2022-04-24  usn-pod-0  192.168.1.4  192.168.1.5  19:30:22  65  1.000  1500
(结果个数 = 1)

---    END
```
