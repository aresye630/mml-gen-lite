# 增加VLR信令点(ADD VLROPC)

- 命令功能
- 注意事项
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SMSF**

该命令用于增加VLR信令点配置。该信令点用于对接HLR。

#### 注意事项

- 此命令的最大记录数为1。
- 该命令中的NI+OPC+VLRN需要先通过ADD SCCPOPC创建。

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                                                                                                                                                                                          |
|:--------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OPX     | VLR信令点索引 | 可选必选说明：必选参数 参数含义：该参数用于指定VLR本局信令点索引。 数据来源：本端规划 取值范围：0~1。 默认值：无 配置原则：无                                                                                                                                                                                          |
| NI      | 网络指示语    | 可选必选说明：必选参数 参数含义：该参数用于指定网络指示语，区分不同的网络。 数据来源：整网规划 取值范围：“INT（国际网）”“INTB（国际备用网）”“NAT（国内网）”“NATB（国内备用网）” 默认值：无 配置原则：NI+OPC+VLRN需要在SCCPOPC记录中存在。  说明： 配置的网络指示语在信令属性表中应该配置为有效（SET SIGATTR）。                                                                         |
| OPC     | 本局信令点编码  | 可选必选说明：必选参数 参数含义：该参数用于指定本局信令点编码，可以采用24位信令点编码或14位信令编码。本局信令点编码在同一网络中唯一。 数据来源：整网规划 取值范围：字符串类型，输入长度范围为1~8 默认值：无 配置原则：配置的信令点编码结构需要和信令属性表中对应的信令网络的网络结构保持一致。取值为0x1~0x3FFF（对应14位编码）或0x1~0xFFFFFF（对应24位编码），不输入0x也取输入为十六进制值，即输入123等价于0x123。NI+OPC+SMSFN需要在SCCPOPC记录中存在。 |
| VLRN    | 本局VLR号   | 可选必选说明：必选参数 参数含义：该参数用于指定本局VLR号。需要和MME、SMSC协商。 数据来源：整网规划 取值范围：长度不超过16的十进制数字 默认值：无 配置原则：NI+OPC+VLRN需要在SCCPOPC记录中存在。                                                                                                                                             |
| VLRNAME | 本局VLR名称  | 可选必选说明：必选参数 参数含义：该参数用于指定本局信令点名。该字段需要和MME协商。 数据来源：本端规划 取值范围：长度不超过32的字符串 默认值：noname 配置原则：无                                                                                                                                                                      |
| SSN     | 子系统号     | 可选必选说明：可选参数 参数含义：该参数用于指定SMSF本局信令点的主用信令点。 数据来源：本端规划 取值范围： “VLR(7)” “MSC(8)” 默认值：VLR(7) 配置原则：无                                                                                                                                                                  |

#### 使用实例

增加VLR本局主用信令点，本局信令点索引为1，网络指示语为INT，本局信令点编码为“0x55”，本局信令点名为“Peking”：

```
ADD VLROPC: OPX=1, NI=INT, OPC="0x55", VLRN="8615654029", VLRNAME="Peking";
```
