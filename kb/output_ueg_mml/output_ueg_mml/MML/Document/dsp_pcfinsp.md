# 查询未生效软参(DSP PCFINSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询PES系统中未生效软参的信息，包括未生效软参名、未生效软参所属服务类型、实例号、软参的修改值、生效值和默认值等信息。

## 注意事项

通过命令结果只能判断PES是否完成重启，无法确认其他非PES服务是否已经重启。

## 参数说明

无。

## 使用实例

查询当前系统中所有未生效的软参。

```
DSP PCFINSP:;
```

```
%%DSP PCFINSP:;%%
RETCODE = 0  操作成功

操作结果
--------
实例号  =  65561
软参名字  =  VRM_SUBSRCIPTIONIDTYPE
  修改值  =  1
  生效值  =  0
  默认值  =  1
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释               |
|:--------|:--------------------|
| 实例号     | 用于描述未生效软参所属微服务的实例号。 |
| 软参名字    | 用于描述未生效软参的软参名。      |
| 修改值     | 用于描述软参修改后的值。        |
| 生效值     | 用于描述软参在UPCF系统中生效的值。 |
| 默认值     | 用于描述软参初始设定的值。       |
