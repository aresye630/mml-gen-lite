#### 命令功能

**适用网元：SGSN、MME、SMSF**

此命令用于增加SCCP新全局码表指定记录的信息。此项配置命令关联SCCPGT中的翻译结果类型一项。当“翻译结果类型”为“DPCNEWGT（DPC + 新GT）”，这里的新GT是用于远端GT翻译的，如果本端发出的消息到达远端例如HLR、VLR后，希望将消息中的GT进行替换为更为合理的新GT，则需要先配置此项，然后在SCCPGT的GT翻译表中对新GT的索引进行关联即可。

#### 注意事项

- 此命令执行后立即生效。
- 此命令最大记录数为4096。
- GT码不能重复。
- 参数的枚举值描述和配置原则可以参考**ADD CPSCCPGT**中的配置。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                                                                                                                        |
|:--------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NGTX    | 新GT码索引  | 可选必选说明：必选参数 参数含义：该参数用于指定GT码对应的索引值。 数据来源：本端规划 取值范围：0~4095 默认值：无                                                                                                                                                              |
| GTEXP   | GT码表示语  | 可选必选说明：可选参数 参数含义：该参数用于指定GT码表示语。 数据来源：整网规划 取值范围： “FOUR(ITU四类)”“SIX(ANSI二类)” 默认值：“FOUR(ITU四类)”                                                                                                                                |
| ITUTT   | ITU翻译类型 | 可选必选说明：条件可选参数 参数含义：该参数用于指定ITU模式的GT码翻译类型。 前提条件：该参数在“GT码表示语”参数设置为“FOUR(ITU四类)”时，才需要配置。 数据来源：整网规划 取值范围：0~255 默认值：0 配置原则：当运营商需要使用STP基于GT码的Translation Type再次进行分类路由转发时，配置此参数。                                                    |
| TT      | 翻译类型    | 可选必选说明：条件可选参数 参数含义：该参数用于指定翻译类型。 前提条件：该参数在“GT码表示语”参数设置为“SIX(ANSI二类)”时，才需要配置。 数据来源：整网规划 取值范围：“ANSI9(ANSI 9类)”“ANSI10(ANSI 10类)” 默认值：“ANSI9(ANSI 9类)”                                                                          |
| NP      | 编号计划    | 可选必选说明：条件可选参数 参数含义：该参数用于指定编号计划。 前提条件：该参数在“GT码表示语”参数设置为“FOUR(ITU四类)”时，才需要配置。 数据来源：整网规划 取值范围：“ISDNP(ISDN/电话编号计划)”“DATA(数据编号计划)”“TELEX(Telex编号计划)”“SMS(海事移动编号计划)”“PMS(陆地移动编号计划)”“ISDNMS(ISDN/移动编号计划)” 默认值：“ISDNP(ISDN/电话编号计划)” |
| ADDREXP | 地址性质表示语 | 可选必选说明：条件可选参数 参数含义：该参数用于指定地址性质表示语。 前提条件：该参数在“GT码表示语”参数设置为“FOUR(ITU四类)”时，才需要配置。 数据来源：整网规划 取值范围：“FREE(空闲)”“SUBDN(用户号码)”“NSU(国内备用号码)”“NVU(国内有效号码)”“INTDN(国际号码)” 默认值：“INTDN(国际号码)”                                              |
| ADDR    | 地址信息    | 可选必选说明：必选参数 参数含义：该参数用于指定地址信息。 数据来源：整网规划 取值范围：长度不超过20的十进制数字字符串 默认值：无                                                                                                                                                         |
| DESC    | 描述      | 可选必选说明：可选参数 参数含义：该参数用于指定SCCP新全局码表的记录名称。 数据来源：本端规划 取值范围：长度不超过32的字符串 默认值：NULL                                                                                                                                                 |

#### 使用实例

场景1：

当运营商需要使用信令转接点基于GT码的Translation Type再次进行分类路由转发时，通过SCCP新全局码表配置所有到该目的信令点的全局码的Translation Type，SCCP新全局码的参数“GT码表示语”，“编号计划”，“地址性质表示语”，“地址信息”与对应的SCCP全局码保持一致。例如将到HLR101的SCCP全局码的Translation Type配置为9，配置命令如下：

ADD CPSCCPNGT: NGTX=2, GTEXP=FOUR, ITUTT=9, NP=ISDNP, ADDR="8613915101", DESC="FOR HLR101";

ADD CPSCCPNGT: NGTX=3, GTEXP=FOUR, ITUTT=9, NP=ISDNMS, ADDR="8613915", DESC="FOR HLR101";

ADD CPSCCPGT: GTX=151, NI=NAT, RT=DPCNEWGT, GTEXP=FOUR, NP=ISDNP, ADDREXP=INTDN, ADDR="8613915101", DPC="0x15101", NGTX=2, NAME="FOR HLR101";

ADD CPSCCPGT: GTX=251, NI=NAT, RT=DPCNEWGT, GTEXP=FOUR, NP=ISDNMS, ADDREXP=INTDN, ADDR="8613915", DPC="0x15101", NGTX=3, NAME="FOR HLR101";

场景2：

增加SCCP新全局码表指定记录的信息：

ADD CPSCCPNGT: NGTX=1, GTEXP=FOUR, ADDR="123", DESC="FOR HLR1";
