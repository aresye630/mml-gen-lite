# 查询服务发现网元类型信息（LST DISCNFTYPECFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询一条服务发现网元类型信息。

- 若需要查询所有服务发现网元类型信息，请不输入任何参数。
- 若需要查询某个服务发现网元类型信息，请依据参数说明输入查询的条件。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                  |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------|
| NFTYPE | 网元类型   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个网元类型来查询服务发现网元类型信息；若不输入，则表示查询所有网元类型的服务发现网元类型信息。 取值范围： CHF(CHF)BSF(BSF)UDR(UDR)NWDAF(NWDAF) 默认值：无。 配置原则：无。 |
| SWITCH | 开关     | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个开关来查询服务发现网元类型信息；若不输入，则表示查询所有开关的服务发现网元类型信息。 取值范围： ON(打开)OFF(关闭) 默认值：无。 配置原则：无。                            |

## 使用实例

1. 查询所有服务发现网元类型信息：

   ```
   LST DISCNFTYPECFG:;
   ```

   ```
   %%LST DISCNFTYPECFG:;%% 
   RETCODE = 0  操作成功 
    
   操作结果如下
   ------------------------ 
   网元类型     开关      
              
   CHF          ON                  
   BSF          ON 
   UDR          ON
   NWDAF        OFF 
   (结果个数 = 4) 
    
   ---    END
   ```
2. 查询一个服务发现网元类型信息，“网元类型”为“BSF(BSF)”：

   ```
   LST DISCNFTYPECFG: NFTYPE=BSF;
   ```

   ```
   %%LST DISCNFTYPECFG: NFTYPE=BSF;%% 
   RETCODE = 0  操作成功
    
   操作结果如下 
   ------------------------       
     网元类型  =  BSF 
         开关  =  ON 
   (结果个数 = 1) 

    ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见SET DISCNFTYPECFG。
