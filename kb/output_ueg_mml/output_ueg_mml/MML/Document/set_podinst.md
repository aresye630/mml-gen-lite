# 设置POD实例个数（SET PODINST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令已废弃。

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于设置POD实例个数。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                                                    |
|:-----------|:--------|:------------------------------------------------------------------------------------------------------------------------|
| PODTYPE    | Pod类型   | 可选必选说明：必选参数 参数含义：该参数用于指定需要设置的Pod类型。 取值范围： SRV_R(路由POD总数量)SRV_L(分发POD总数量)SRV_S(业务POD总数量)SRV_LD(LDAP POD总数量) 默认值：无 配置原则：无 |
| MODE       | 实例设置开关  | 可选必选说明：必选参数 参数含义：该参数用于对指定的Pod类型设置实例开关。 取值范围： OFF(实例设置开关关闭)ON(实例设置开关打开) 默认值：OFF 配置原则：无                                   |
| INSTNUMBER | Pod实例个数 | 可选必选说明：可选参数 参数含义：该参数用于对指定的Pod类型设置实例个数。 取值范围：0~255 默认值：0 配置原则：无                                                          |

## 使用实例

设置“SRV\_R”Pod类型的实例个数为“2”。

```
SET PODINST: PODTYPE=SRV_R, MODE=ON, INSTNUMBER=2;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
