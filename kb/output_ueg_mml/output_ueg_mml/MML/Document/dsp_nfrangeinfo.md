# 显示网元号段信息(DSP NFRANGEINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询网元号段信息。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                                                                               |
|:-----------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GRPNAME    | 组名称    | 可选必选说明：可选参数 参数含义：用于标识本端网元号段信息所属组的信息，该参数由本端网元自定义；若不输入，则表示所有的组名称。 取值范围：长度不超过32的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。                                                                                                                          |
| RANGETYPE  | 号段类型   | 可选必选说明：可选参数 参数含义：用于标识本端网元号段信息的号段类型；若不输入，则表示所有的号段类型。 取值范围： SUPI(用户永久标识)GPSI(通用公共用户标识) 默认值：无。 配置原则：无。                                                                                                                                                |
| MERGERANGE | 号段合并   | 可选必选说明：可选参数 参数含义：用于标识本端网元号段信息是否进行号段合并；若不输入，则表示进行号段合并。 取值范围： FALSE(FALSE)TRUE(TRUE) 默认值：TRUE(TRUE)。 配置原则：当该参数设置为“TRUE(TRUE)”时，只对同时满足如下2个条件的网元号段生效： “号段类型”设置为“SUPI”或“GPSI”的网元号段。设置了“开始”值和“结束”值的网元号段。  说明： 当几个网元号段合并成为一个网元号段，合并后的网元号段索引为这几个号段索引中的最小值。 |

## 使用实例

1. 查询特定号段信息，“号段合并”为“TRUE”：

   ```
   DSP NFRANGEINFO: MERGERANGE=TRUE;
   ```

   ```
   %%DSP NFRANGEINFO: MERGERANGE=TRUE;%%
   RETCODE = 0  操作成功

   操作结果如下 
   ------------
   组名称         索引  号段类型          开始             结束             模式  

   gpsi-group-01  1     通用公共用户标识  86139            86199            NULL                     
   rangeSupi_01   1     用户永久标识      123456789040000  123456789059999  NULL    
   rangeSupi_02   2     用户永久标识      NULL             NULL             ^imsi-12345678904[0-9]{4}$  
   (结果个数 = 3)

   ---    END
   ```
2. 查询特定号段信息，“号段类型”为“用户永久标识”，“号段合并”为“TRUE”：

   ```
   DSP NFRANGEINFO: RANGETYPE=SUPI, MERGERANGE=TRUE;
   ```

   ```
   %%DSP NFRANGEINFO: RANGETYPE=SUPI, MERGERANGE=TRUE;%%
   RETCODE = 0  操作成功

   操作结果如下 
   ------------
   组名称         索引  号段类型          开始             结束             模式  
                       
   rangeSupi_01   1     用户永久标识      123456789040000  123456789059999  NULL    
   rangeSupi_02   2     用户永久标识      NULL             NULL             ^imsi-12345678904[0-9]{4}$  
   (结果个数 = 2)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD NFRANGEINFO**命令的参数说明。
