## 命令功能

该命令用于增加网元订阅通知信息。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                           |
|:------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GRPNAME     | 组名称    | 可选必选说明：必选参数 参数含义：用于标识一个网元订阅通知信息所属组的名称。 取值范围：由数字、字母、“-”或“_”组成的长度不超过32的字符串 默认值：无。 配置原则：无。                                                                                                        |
| INDEX       | 索引     | 可选必选说明：必选参数 参数含义：用于标识一个网元订阅通知信息在组内的唯一一条记录。 取值范围：1~1024 默认值：无。 配置原则：该参数全局唯一，不能重复。                                                                                                               |
| NOTIFTYPE   | 通知类型   | 可选必选说明：必选参数 参数含义：用于标识一个网元订阅通知信息的通知类型。 取值范围： N1_MESSAGES（N1消息）N2_INFORMATION（N2消息）LOCATION_NOTIFICATION（位置添加通知）DATA_REMOVAL_NOTIFICATION（位置删除通知）DATA_CHANGE_NOTIFICATION（位置变更通知） 默认值：无。 配置原则：无。 |
| CALLBACKURI | 回调URI  | 可选必选说明：必选参数 参数含义：用于标识一个网元订阅通知信息的回调URI。 取值范围：由IP+端口组成，格式要求为https://IP:端口。 举例："https://192.168.16.5:31943" 默认值：无。 配置原则：无。                                                                        |
| N1MSGCLASS  | N1消息类型 | 可选必选说明：可选参数 参数含义：用于标识一个网元订阅通知信息的N1消息类型。 取值范围： 5GMM（接收到的整个NAS消息）SM（短消息类型的N1消息）LP（eMLPP类型的N1消息）SMS（SMS类型的N1消息）UPD（UE策略下发的N1消息） 默认值：无。 配置原则：无。                                                    |
| N2INFOCLASS | N2信息类型 | 可选必选说明：可选参数 参数含义：用于标识一个网元订阅通知信息的N2消息类型。 取值范围： SM（N2短信消息）NRPPa（N2的NRPPa消息）PWS（PWS类型的N2的PWS信息）PWS-BCAL（N2广播完成区域列表或广播取消区域列表）PWS-RF（N2重启指示或失败指示）RAN（N2运行相关信息） 默认值：无。 配置原则：无。                       |

## 使用实例

增加一个网元订阅通知信息。“组名称”为“notifsub-group-01”，“索引”为“1010”，“通知类型”为“N1\_MESSAGES”，“回调URI”为“https://192.168.16.5:31943”：

```
ADD NFNOTIFSUB: GRPNAME="notifsub-group-01", INDEX=1010, NOTIFTYPE=N1_MESSAGES, CALLBACKURI="https://192.168.16.5:31943";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如下表1所示。

|    错误码 | 错误码解释   | 原因分析        | 处理建议                                   |
|-------:|:--------|:------------|:---------------------------------------|
|    503 | 配置数据已存在 | 已有相同“索引”配置。 | 使用命令LST NFNOTIFSUB查询并重新输入“索引”，确保其值不存在。 |
| 360041 | 参数值不合法  | 指定参数值不合法。   | 参考参数的定义或举例内容，并重新输入，确保格式正确。             |
