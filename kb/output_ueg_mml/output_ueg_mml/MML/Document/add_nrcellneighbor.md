# 增加定位NR邻区（ADD NRCELLNEIGHBOR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于增加定位NR邻区。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为30000。其中主小区最多配置10000个，单个主小区最多支持配置3个邻区。
- 只有在执行该命令后发起的定位请求才会携带新增的邻区信息。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称          | 参数说明                                                                                                                                                                                                                         |
|:------------|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GNODEBID    | 基站标识          | 可选必选说明：必选参数 参数含义：该参数用于设置基站标识。 数据来源：全网规划 取值范围：0~4294967295。 默认值：无 配置原则：1. 该参数最大有效值要参考gNB ID Length (LST UPLCSPARA)的值， 否则多小区场景的定位业务中邻区配置可能不生效。例如，gNB ID Length值为22，则该参数最大有效值为4194303（1<<22 -1） 2. 该参数取值需要与NeigbGNBId保持一致。      |
| NRCELLID    | NR小区标识        | 可选必选说明：必选参数 参数含义：该参数表示小区的标识。 数据来源：全网规划 取值范围：0~65534。 默认值：无 配置原则：该参数最大有效值要参考gNB ID Length (LST UPLCSPARA)的值， 否则多小区场景的定位业务中邻区配置可能不生效。例如，gNB ID Length 值为22，则该参数最大值为16383（1<<14 -1）。其中14=36-22，36为固定值。                          |
| NEIGBGNBID  | 邻区所在的gNodeB标识 | 可选必选说明：必选参数 参数含义：该参数表示定位邻区所在的gNodeB标识。 数据来源：全网规划 取值范围：0~4294967295。 默认值：无 配置原则：1. 该参数最大有效值要参考gNB ID Length (LST UPLCSPARA)的值， 否则多小区场景的定位业务中邻区配置可能不生效。例如，gNB ID Length值为22，则该参数最大值为4194303（1<<22 -1） 2. 该参数取值需要与GNodeBId保持一致。 |
| NEIGBCELLID | 邻区的NR Cell标识  | 可选必选说明：必选参数 参数含义：该参数表示定位邻区的小区标识。 数据来源：全网规划 取值范围：0~65534。 默认值：无 配置原则：该参数最大有效值要参考gNB ID Length (LST UPLCSPARA)的值， 否则多小区场景的定位业务中邻区配置可能不生效。例如，gNB ID Length值为22，则该参数最大值为16383（1<<14 -1）。其中14=36-22，36为固定值。                       |

#### 使用实例

增加定位NR邻区：

```
ADD NRCELLNEIGHBOR: GNODEBID=1, NRCELLID=3, NEIGBGNBID=1, NEIGBCELLID=4;
```
