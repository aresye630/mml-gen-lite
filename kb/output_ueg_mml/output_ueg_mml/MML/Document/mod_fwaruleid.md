# 修改FWA用户规则ID配置（MOD FWARULEID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响FWA用户识别。

该命令用于修改一条FWA用户规则ID配置记录。

## 注意事项

修改FWA用户规则ID配置，不会立即对已在线的用户进行FWA用户识别判断，当已在线用户因营帐或信令消息触发策略重新计算时，系统会根据最新的配置识别是否为FWA用户，同时基于最新识别结果进行FWA license和话统变更。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                      |
|:------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ID          | ID     | 可选必选说明：必选参数。 参数含义：表示FWA用户规则ID配置的记录标识。 取值范围：0～19 默认值：无。 配置原则：无。                                                                                                                                                            |
| KEYWORD     | 关键字    | 可选必选说明：可选参数。 参数含义：表示识别FWA用户的匹配字段。 取值范围：长度不超过255的字符串 默认值：无。 配置原则：无。                                                                                                                                                        |
| MATCHTYPE   | 匹配类型   | 可选必选说明：可选参数。 参数含义：表示识别FWA用户的匹配类型。 取值范围： FULL(全匹配)：UPCF会将用户签约业务中生效规则的pccRuleId与“关键字”进行全匹配（忽略大小写），如果完全一致，则全匹配成功。SUBSTRING(子字符串匹配)：UPCF会将用户签约业务中生效规则的pccRuleId与“关键字”进行子字符串匹配（忽略大小写），如果pccRuleId包含“关键字”，则匹配成功。 默认值：无。 配置原则：无。 |
| DESCRIPTION | 描述     | 可选必选说明：可选参数。 参数含义：用于对FWA用户规则ID配置记录的描述。 取值范围：长度不超过128的字符串 默认值：无。 配置原则：无。                                                                                                                                                   |

## 使用实例

修改FWA用户规则ID配置。“ID”为“0”，“关键字”为“fwa456”，“匹配类型”为“FULL(全匹配)”。

```
MOD FWARULEID: ID=0, KEYWORD="fwa456", MATCHTYPE=FULL;
```
