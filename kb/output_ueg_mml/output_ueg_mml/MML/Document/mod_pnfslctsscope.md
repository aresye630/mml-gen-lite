# 修改选择对端NF时使用的业务服务区（MOD PNFSLCTSSCOPE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于修改选择对端NF时使用的业务服务区。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                             |
|:-------------|:-------|:-------------------------------------------------------------------------------------------------|
| PEERNFTYPE   | 对端NF类型 | 可选必选说明：必选参数  参数含义：该参数用于指定对端NF类型。  数据来源：本端规划 取值范围： “DEFAULT（默认的对端NF类型）”：默认的对端NF类型。  默认值：无  配置原则：无 |
| SRVSCOPENAME | 服务区名称  | 可选必选说明：可选参数  参数含义：本参数用于指定服务区名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~50。区分大小写。  默认值：无  配置原则：无         |

## 使用实例

修改选择对端NF时使用的业务服务区为CityB。

```
MOD PNFSLCTSSCOPE: PEERNFTYPE=DEFAULT, SRVSCOPENAME="CityB";
```
