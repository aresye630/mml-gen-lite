# 删除OSPFv3引入路由聚合配置（RMV OSPFV3ASBRSUMMARY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于取消ASBR对OSPFv3引入的路由进行路由聚合。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                          |
|:------------|:----------|:----------------------------------------------------------------------------------------------|
| PROCID      | OSPFv3进程号 | 可选必选说明：必选参数 参数含义：OSPFv3进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 配置原则：OSPFv3进程必须已经存在。 |
| TOPOID      | 拓扑标识      | 可选必选说明：必选参数 参数含义：拓扑标识。 数据来源：全网规划 取值范围：整数类型，取值范围为0。 默认值：无 配置原则：目前只支持默认拓扑0。                     |
| IPADDRESS   | IPv6地址    | 可选必选说明：必选参数 参数含义：IPv6地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无                                       |
| IPV6MASKLEN | IPv6前缀长度  | 可选必选说明：必选参数 参数含义：IPv6前缀长度。 数据来源：本端规划 取值范围：整数类型，取值范围为1～128。 默认值：无                              |

#### 使用实例

取消OSPFv3进程1下引入2001:db8::的路由聚合：

```
RMV OSPFV3ASBRSUMMARY:PROCID=1,TOPOID=0,IPADDRESS="2001:db8::",IPV6MASKLEN=64;
```
