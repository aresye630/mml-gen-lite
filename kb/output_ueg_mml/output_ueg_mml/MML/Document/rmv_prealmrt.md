# 删除PCRF的域路由记录（RMV PREALMRT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于在配置数据库中删除一条PCRF的域路由记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                |
|:-------|:-------|:--------------------------------------------------------------------|
| PCRFID | PCRF标识 | 用于标识PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围：1 默认值：无。             |
| RID    | 路由标识   | 用于在UPCF的配置库中定义一个域路由。该参数的配置原则：如果配置多个对端域路由，从0开始顺序配置。 取值范围：0～29 默认值：无。 |

## 使用实例

删除PCRF的域路由记录。“PCRF标识”为“1”，“路由标识”为“0”。

```
RMV PREALMRT: PCRFID=1, RID=0;
```
