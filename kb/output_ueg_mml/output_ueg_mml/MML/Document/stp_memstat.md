# 停止内存申请统计任务（STP MEMSTAT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响系统性能，需联系华为技术支持确认后再执行。

该命令用于停止正在进行的内存申请统计任务。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                  |
|:------------|:-------|:----------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 服务类型   | 可选必选说明：必选参数 参数含义：用于指定需要停止内存申请统计的微服务类型。 取值范围：PcfPolicyEngineService 默认值：无。  说明： 目前仅支持对PES服务进行该操作。                      |
| INSTANCEID  | 实例号    | 可选必选说明：必选参数 参数含义：用于指定需要停止内存申请统计微服务的实例号。 取值范围：0~256长度字符串 默认值：无。  说明： 该实例号需要设置为通过启动内存申请统计任务（STR MEMSTAT）执行内存申请统计任务的实例号。 |

## 使用实例

停止正在执行内存申请统计操作，“实例号”为“4201903”

```
STP MEMSTAT: SERVICETYPE=PcfPolicyEngineService, INSTANCEID="4201903";
```

```
%%%STP MEMSTAT: SERVICETYPE=PcfPolicyEngineService, INSTANCEID="4201903";%%
RETCODE = 0  操作成功  

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
