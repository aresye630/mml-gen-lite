# 增加PCRF对端OCS接入点链路(ADD POCSL)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

该命令用于在UPCF网元下增加一条连接PCRF实体与对端OCS接入点实体的链路。

该命令的使用场景：开局或其他场景下，UPCF需要增加OCS对端的时候，用此命令添加PCRF实体与对端OCS接入点实体间的链路。

在该命令中，“对端IPV4地址”/“对端IPV6地址”、“对端端口”和“传输协议类型”参数的配置需要与对端OCS接入点协商一致。

## 注意事项

- UPCF通过Sy接口和OCS对接时，支持添加一个或多个对端OCS接入点（实际可配置的最大值受系统软参“VRM\_MAXPOCSCPNUM”的限制）。
- 在执行本命令配置链路时，每个POCSCP对端的可配置的POCSL链路数的最大值由DLB实例个数决定。
- IPv6类型的IP地址不支持混合方式表达，即xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:d.d.d.d，其中x表示一个十六进制数（0～9或A～F），而d.d.d.d表示一个IPv4地址。
- “对端IPV6地址”不支持以下特殊地址的配置，其中x表示一个十六进制数（0～9或A～F）：
  - FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF
  - 0000:0000:0000:0000:0000:0000:0000:0001
  - FFxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE8x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE9x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEAx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEBx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx

## 参数说明

| 参数ID      | 参数名称        | 参数描述                                                                                                                                                                                                                                                            |
|:----------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PCRFID    | PCRF标识      | 用于标识PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围：1 默认值：无。                                                                                                                                                                                                         |
| CPID      | 接入点标识       | 用于标识对端OCS的接入点标识。该参数必须先由ADD POCSCP命令定义，然后才能在此处索引。 取值范围：0～15 默认值：无。                                                                                                                                                                                               |
| LNKID     | 链路ID        | 用于标识一条PCRF实体与对端OCS接入点实体间的链路。 取值范围：0～67 默认值：无。                                                                                                                                                                                                                   |
| TPTYPE    | 传输协议类型      | 用于标识链路的传输协议类型。 该参数的配置原则：该参数必须由PCRF和OCS接入点协商一致。 取值范围： SCTP（流量控制传输协议）TCP（传输控制协议） 默认值：无                                                                                                                                                                            |
| DUALHOME  | 双归属开关       | 双归属开关。“传输协议类型”为“SCTP”时，才可以配置该参数。 取值说明： OFF(关闭)ON(打开) 默认值：无                                                                                                                                                                                                      |
| CROSSPATH | 交叉路径        | 双归属时的交叉路径配置。当“双归属开关”为“ON(打开)”时，需要设置此参数。 取值说明： OFF(关闭)：表示关闭交叉路径功能。ON(打开)：表示打开交叉路径功能。 默认值：ON(打开)                                                                                                                                                                  |
| DIPVER    | 双归属地址IP版本   | 当双归属开关打开时，需要设置此参数。用于指定本端和对端IP地址、双归属本端和对端IP地址的IP版本类型。 取值范围： IPV4IPV6 默认值：无。                                                                                                                                                                                      |
| IPVER     | IP版本        | 用于指定本端和对端IP地址的IP版本类型。 取值范围： IPV4IPV6 默认值：无。                                                                                                                                                                                                                     |
| DLIP      | 双归属本端IPV4地址 | PCRF与对端OCS接入点产品对接的参数之一，用于标识PCRF与对端OCS接入点连接时使用的双归属本端IPv4地址。该参数必须已经通过ADD DLBDEVADDR命令添加。 取值范围：IPv4地址 默认值：无。  说明： 当“双归属地址IP版本”选择“IPV4”时，可设置该参数。                                                                                                                    |
| DLIPV6    | 双归属本端IPV6地址 | PCRF与对端OCS接入点产品对接的参数之一，用于标识PCRF与对端OCS接入点连接时使用的双归属本端IPv6地址。该参数必须已经通过ADD DLBDEVADDR命令添加。 取值范围：IPv6地址 默认值：无。  说明： 当“双归属地址IP版本”选择“IPV6”时，可设置该参数。当前UPCF只支持Gx、Rx、Hb和Sy四种信令接口配置该参数。                                                                                    |
| LIP       | 本端IPV4地址    | PCRF与对端OCS接入点产品对接的参数之一，用于标识PCRF与对端OCS接入点连接时使用的本端IPv4地址。该参数必须已经通过ADD DLBDEVADDR命令添加。 取值范围：IPv4地址 默认值：无。  说明： 当“IP版本”选择“IPV4”时，可设置该参数。当“双归属开关”为“ON(打开)”，且“双归属地址IP版本”选择“IPV4”时，本参数作为PCRF侧diameter链路端点的主IP地址，与“PIP”组成主路径。                                           |
| LIPV6     | 本端IPV6地址    | PCRF与对端OCS接入点产品对接的参数之一，用于标识PCRF与对端OCS接入点连接时使用的本端IPv6地址。该参数必须已经通过ADD DLBDEVADDR命令添加。 取值范围：IPv6地址 默认值：无。  说明： 当“IP版本”选择“IPV6”时，可设置该参数。当前UPCF只支持Gx、Rx、Hb和Sy四种信令接口配置该参数。当“双归属开关”为“ON(打开)”，且“双归属地址IP版本”选择“IPV6”时，本参数作为PCRF侧diameter链路端点的主IP地址，与“PIPV6”组成主路径。         |
| LPT       | 本地端口        | 用于标识PCRF与对端OCS接入点连接时使用的本地端口。 该参数的配置原则：该参数需要由运营商统一规划。如果没有规划，本地端口可以在取值范围内任选一个没有被占用的端口。 取值范围：0～65534 默认值：无。  说明： 当参数“传输协议类型”为“TCP（传输控制协议）”时，参数“本地端口”配置的端口必须大于或者等于1024，否则可能会导致建链失败。                                                                                 |
| DPIP      | 双归属对端IPV4地址 | PCRF与对端OCS接入点产品对接的参数之一，用于标识PCRF与对端OCS接入点连接时使用的双归属对端IPv4地址。 该参数的配置原则：该参数必须由PCRF和OCS接入点协商一致。 取值范围：IPv4地址 默认值：无。  说明： 当“双归属地址IP版本”选择“IPV4”时，可设置该参数。                                                                                                                |
| DPIPV6    | 双归属对端IPV6地址 | PCRF与对端OCS接入点产品对接的参数之一，用于标识PCRF与对端OCS接入点连接时使用的双归属对端IPv6地址。 该参数的配置原则：该参数必须由PCRF和OCS接入点协商一致。 取值范围：IPv6地址 默认值：无。  说明： 当“双归属地址IP版本”选择“IPV6”时，可设置该参数。当前UPCF只支持Gx、Rx、Hb和Sy四种信令接口配置该参数。                                                                                |
| PIP       | 对端IPV4地址    | PCRF与对端OCS接入点产品对接的参数之一，用于标识PCRF与对端OCS接入点连接时使用的对端IPv4地址。 该参数的配置原则：该参数必须由PCRF和OCS接入点协商一致。 取值范围：IPv4地址 默认值：无。  说明： 当“IP版本”选择“IPV4”时，可设置该参数。当“双归属开关”为“ON(打开)”，且“双归属地址IP版本”选择“IPV4”时，系统把本参数作为对端OCS侧diameter链路端点的主IP地址，与“LIP”组成主路径。                                   |
| PIPV6     | 对端IPV6地址    | PCRF与对端OCS接入点产品对接的参数之一，用于标识PCRF与对端OCS接入点连接时使用的对端IPv6地址。 该参数的配置原则：该参数必须由PCRF和OCS接入点协商一致。 取值范围：IPv6地址 默认值：无。  说明： 当“IP版本”选择“IPV6”时，可设置该参数。当前UPCF只支持Gx、Rx、Hb和Sy四种信令接口配置该参数。当“双归属开关”为“ON(打开)”，且“双归属地址IP版本”选择“IPV6”时，系统把本参数作为对端OCS侧diameter链路端点的主IP地址，与“LIPV6”组成主路径。 |
| PPT       | 对端端口        | PCRF与对端OCS接入点产品对接的参数之一，用于标识PCRF与对端OCS接入点连接时使用的对端端口。 该参数的配置原则：该参数必须由PCRF和OCS接入点协商一致。 取值范围：1～65534 默认值：无。                                                                                                                                                         |
| ADSTS     | 链路管理状态      | 用于管理链路的状态。 当“链路管理状态”为“去使能”时，建立的链路是无法连通的，通过DSP POCSL命令查询出来的该链路状态为“LINKDOWN（离线）”。同时会产生ALM-34078 PCRF与OCS链路故障的告警。 建议添加链路的时候该参数使用默认值。 取值范围： DISABLE（去使能）ENABLE（使能） 默认值：ENABLE（使能）                                                                                   |

## 使用实例

1. 增加PCRF实体和对端OCS接入点链路（传输协议类型为TCP）。“PCRF标识”为“1”，“接入点标识”为“0”，“链路标识”为“0”,“传输协议类型”为“TCP”，“IP版本”为“IPV4”，“本端IPV4地址”为“192.168.131.33”，“本地端口”为“1200”，“对端IPV4地址”为“192.168.130.20”，“对端端口”为“1233”，其他参数使用缺省值。

   ```
   ADD POCSL: PCRFID=1, CPID=0, LNKID=0, TPTYPE=TCP, IPVER=IPV4, LIP="192.168.131.33", LPT=1200, PIP="192.168.130.20", PPT=1233;
   ```
2. 增加PCRF实体和对端OCS接入点链路（传输协议类型为SCTP）。“PCRF标识”为“1”，“接入点标识”为“1”，“链路标识”为“1”,“传输协议类型”为“SCTP”，“双归属开关”为“ON”，“交叉路径”为“ON”，“双归属地址IP版本”为“IPV4”，“双归属本端IPV4地址”为“192.168.131.34”，“本端IPV4地址”为“192.168.130.33”，“本地端口”为“2100”，“双归属对端IPV4地址”为“192.168.131.21”，“对端IPV4地址”为“192.168.130.20”，“对端端口”为“2134”，其他参数使用缺省值。

   ```
   ADD POCSL: PCRFID=1, CPID=1, LNKID=1, TPTYPE=SCTP, DUALHOME=ON, CROSSPATH=ON, DIPVER=IPV4, DLIP="192.168.131.34", LIP="192.168.130.33", LPT=2100, DPIP="192.168.131.21", PIP="192.168.130.20", PPT=2134;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释            | 原因分析                                                                                                        | 处理建议                                                                                                            |
|------:|:-----------------|:------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------|
| 57442 | 本端IP和端口已经被使用。    | 当本端作为TCP客户端时，新增链路与已有链路配置了相同的本地IP和本地端口的Diameter链路。当本端作为SCTP客户端时，新增链路与已有链路配置了相同的本地IP、双归属本地IP和本地端口的Diameter链路。 | 当本端作为TCP客户端时，确保新增链路与已有链路配置了不同的本地IP和本地端口的Diameter链路。当本端作为SCTP客户端时，确保新增链路与已有链路配置了不同的本地IP、双归属本地IP和本地端口的Diameter链路。 |
| 58245 | 本地端口号必须大于等于1024。 | “传输协议类型”为“TCP（传输控制协议）”，“本地端口”配置小于1024。                                                                      | 重新执行本命令，当“传输协议类型”为“TCP（传输控制协议）”时，“本地端口”配置必须大于或等于1024。                                                           |
