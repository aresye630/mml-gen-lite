# 查询数据同步连接状态（DSP RDATASYNCONN）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UDM**

查询数据同步连接状态。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                       |
|:-----------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| SERVERNAME | 服务器名称  | 可选必选说明：必选参数 参数含义：远端用户数据同步服务器名称。 数据来源：本端规划 取值范围：由数字、字母和下划线组成的不超过16位的字符串。 默认值：无 配置原则： 该参数使用ADD RDATASYNSERVER命令配置生成。由数字、字母和下划线组成的不超过16位的字符串。 |

#### 使用实例

查询数据同步连接状态：

```
DSP RDATASYNCONN: SERVERNAME="sftpserver_ipv41";
```

```
RETCODE = 0  操作成功

数据同步连接状态
----------------
      服务器名称  =  sftpserver_ipv41
        连接状态  =  Connected
SFTP连接失败原因  =  NULL
(结果个数 = 1)

---    END
```

#### 输出结果说明

| 输出项名称      | 输出项解释            |
|:-----------|:-----------------|
| 服务器名称      | 远端用户数据同步服务器名称。   |
| 连接状态       | 当前与SFTP服务器的连接状态。 |
| SFTP连接失败原因 | SFTP连接失败原因。      |
