# 删除紧急号码配置信息（RMV NGEMGCNUM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

此命令用于删除配置的紧急呼叫号码信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                         |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MCC    | 移动国家码  | 可选必选说明：必选参数  参数含义：该参数用于指定需要配置紧急呼叫号码的移动国家码。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                                                                     |
| NUM    | 紧急呼叫号码 | 可选必选说明：必选参数  参数含义：该参数用于指明紧急业务对应的号码。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~80。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                                                                       |
| ESC    | 紧急服务分类 | 可选必选说明：可选参数  参数含义：该参数用于指定紧急呼叫号码的服务类型。  数据来源：全网规划 取值范围： “POLICE（报警）”：报警“AMBULANCE（医疗救护）”：医疗救护“FIREBRIGADE（火警）”：火警“MARINEGUARD（海上救援）”：海上救援“MOUNTAIN（高山救援）”：高山救援“ALL（通用类型）”：通用类型  默认值：无  配置原则：无 |

## 使用实例

删除MCC为“460”，紧急服务分类为火警，紧急号码为“119”的紧急呼叫配置信息，执行如下命令：

```
RMV NGEMGCNUM: MCC="460", ESC=FIREBRIGADE, NUM="119";
```
