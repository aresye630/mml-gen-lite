# 设置限流（SET RATELIMIT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

**须知** 

本命令属于高危命令，设置限流需要重启API GW业务进程，可能导致业务中断。限流值过小可能导致部分业务请求被拒绝。

配置API GW的限流策略，RATELIMIT\_TYPE为GLOBAL时控制APP单位时间内对API GW的访问频率,RATELIMIT\_TYPE为SINGLE时给所有路由设置一个统一的限流。如果短时间内访问API GW的流量过大，需要防止流量超过API GW负载能力，则应进行限流配置。当设置每秒限流配置为0时，API GW不进行限流。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   |   SECOND | RATELIMIT_TYPE   |
|:-------|---------:|:-----------------|
| 初始值    |        0 | GLOBAL           |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                                                                    |
|:---------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------|
| SECOND         | 每秒请求限制 | 可选必选说明：条件必选参数 前提条件：该参数在“RATELIMIT_TYPE”配置为“SINGLE” 或 “GLOBAL”时为必选参数。 参数含义：每秒请求次数限制。 数据来源：本端规划 取值范围：整数类型，取值范围为0～2147483647。 默认值：无 配置原则：无 |
| RATELIMIT_TYPE | 流控类型   | 可选必选说明：必选参数 参数含义：限流的类型。 数据来源：本端规划 取值范围：枚举类型。 GLOBAL：全局流量控制。SINGLE：给每个路由设置相同限流。 默认值：无 配置原则：无                                             |

#### 使用实例

短时间内访问API GW的流量过大，需要防止过大流量超过API GW负载，则需要配置限流：

```
SET RATELIMIT: RATELIMIT_TYPE=GLOBAL, SECOND=5000;
```
