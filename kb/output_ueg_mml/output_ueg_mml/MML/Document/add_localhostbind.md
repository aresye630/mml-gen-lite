# 增加Diameter本端主机与Diameter本端主机组的关联关系（ADD LOCALHOSTBIND）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

此命令用于添加指定的Diameter本端主机到本端主机分组中。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1000。
- 单个Diameter本端主机分组内最多可以有64个本端主机。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称           | 参数说明                                                                                                                                               |
|:------------|:---------------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
| LOCGRPNAME  | Diameter本端信息组名 | 可选必选说明：必选参数 参数含义：该参数用于指定Diameter本端主机组名。要求在系统内唯一，数据来源为运营商规划。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD LOCALHOSTGRP命令配置生成。 |
| LOCHOSTNAME | Diameter本端主机名  | 可选必选说明：必选参数 参数含义：本参数指定Diameter本端主机名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～127。不支持空格。 默认值：无 配置原则：该参数使用ADD DIAMLOCINFO命令配置生成。                               |

#### 使用实例

增加Diameter本端主机名与Diameter本端主机组的关联关系，组名为“abc”，主机名为“aaa”：

```
ADD LOCALHOSTBIND: LOCGRPNAME="abc", LOCHOSTNAME="aaa";
```
