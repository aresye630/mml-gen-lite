# 删除IP区域群成员(RMV IPAREAGPMEM)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于删除区域群成员记录。

#### 注意事项

- 此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                      |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------|
| AREAID | 区域群标识  | 可选必选说明：必选参数 参数含义：待删除的区域群标识。 数据来源：整网规划 取值范围：1~256 默认值：无                                                    |
| IDTYPE | 标识类型   | 可选必选说明：必选参数 参数含义：待删除的区域标识类型。 数据来源：整网规划 取值范围：“LAC(位置区域码)”“TAC(跟踪区域码)” 默认值：无                                |
| LAC    | 位置区域码  | 可选必选说明：条件必选参数 参数含义：待删除的位置区域码。 前提条件：该参数在“IDTYPE(标识类型)”设置为“LAC(位置区)”时生效。 数据来源：整网规划 取值范围：0x0000~0xFFFF 默认值：无 |
| TAC    | 跟踪区域码  | 可选必选说明：条件必选参数 参数含义：待删除的跟踪区域码。 前提条件：该参数在“IDTYPE(标识类型)”设置为“TAC(跟踪区)”时生效。 数据来源：整网规划 取值范围：0x0000~0xFFFF 默认值：无 |

#### 使用实例

删除一条IP区域群成员记录，区域群标识为1，标识类型为LAC，位置区域码为0x1234：

RMV IPAREAGPMEM: AREAID=1, IDTYPE=LAC, LAC="0x1234";
