# 增加PCRF目的主机配置（ADD PDHOSTCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于增加业务处理中需要与目的主机相关的配置。

## 注意事项

当PCRF目的主机配置记录数超过512\***VRM\_CBOVERRUNALMTH**时，系统会上报“ALM-34120 控制块资源使用率达到阈值”。

## 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|:--------------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PCRFID        | PCRF标识   | 用于标识PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围：1 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| HOSTID        | 目的主机ID   | 用于标识目的主机。 取值范围：0～511 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| APPTYPE       | 应用类型     | 目的主机的应用类型，配置该参数后，都需要继续配置参数ABILITYDICTID，标识对端PCEF或AF的能力。 取值说明： PCEF：当运营商使用的PCEF种类都不同时，应用类型可以配置为“PCEF”，此时必须要输入目的主机名。DefaultPCEF：当运营商使用的PCEF都是一类的，且具有相同的能力时，应用类型可以配置为“DefaultPCEF”，此时不需要配置目的主机名。DynamicPCEF：当运营商使用的PCEF是不同类别的，并且主机个数又超过了512个时，应用类型可以配置为“DynamicPCEF”，此时目的主机名只需要输入实际主机名的字符子串，进行模糊匹配。AF：当运营商使用的AF种类都不同时，应用类型可以配置为“AF”，此时必须要输入目的主机名。DefaultAF：当运营商使用的AF都是一类的，且具有相同的能力时，应用类型可以配置为“DefaultAF”，此时不需要配置目的主机名。DynamicAF：当运营商使用的AF是不同类别的，并且主机个数又超过了512个时，应用类型可以配置为“DynamicAF”，此时目的主机名只需要输入实际主机名的字符子串，进行模糊匹配。 默认值：无。                                                                                                                                                                                                                                                                                                     |
| DEN           | 目的实体名称   | 目的实体名称。 取值范围：长度不超过128的字符串 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| DHN           | 目的主机名    | 目的主机名称。当APPTYPE为DefaultPCEF或DefaultAF时，不能配置。当APPTYPE为DynamicPCEF或DynamicAF时，可以配置为实际主机名的子串，支持上线过程中对主机名的模糊匹配。最多只允许配置8个APPTYPE为DynamicPCEF和8个APPTYPE为DynamicAF的目的主机。主机名按规则匹配。对于Gx接口的请求消息，用户上线过程中使用上行消息中的原Host name优先匹配APPTYPE为PCEF的配置记录。如果匹配PCEF类型失败，就匹配APPTYPE为DynamicPCEF的配置记录，根据上行原Host Name字符串包含配置DHN判断是否匹配，多条记录时按DHN的长度由大到小排序，如果长度相同，优先匹配ID小的。如果上述两种方式都没有匹配成功则使用DefaultPCEF配置，如果没有配置DefaultPCEF，则回应失败CCA，携带错误码DIAMETER_UNKNOWN_PEER 3010。用户在线过程中目的主机配置中DynamicPCEF类型的配置发生变更不影响当前已经在线的用户，新上线的用户按新记录进行匹配。 对于Rx接口的请求消息，用户上线过程中使用上行消息中的原Host name优先匹配APPTYPE为AF的配置记录。如果匹配AF类型失败，就匹配APPTYPE为DynamicAF的配置记录，根据上行原Host Name字符串包含配置DHN判断是否匹配，多条记录时按DHN的长度由大到小排序，如果长度相同，优先匹配ID小的。如果上述两种方式都没有匹配成功则使用DefaultAF配置，如果没有配置DefaultAF，则默认AF能力字典ID为0。用户在线过程中目的主机配置中DynamicAF类型的配置发生变更不影响当前已经在线的用户，新上线的用户按新记录进行匹配。 取值范围：长度不超过127的字符串 默认值：无。 |
| ABILITYDICTID | 能力字典ID   | 用于选择PCEF或AF的能力字典。 取值范围：0～127 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| PCEFCAT       | 对端PCEF类别 | 对端PCEF实体的类别，只在多PCEF场景下使用。 取值范围：由ADD PPCEFCAT命令定义的PCRF对端PCEF类别。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| PPCEFGROUP    | 对端PCEF组  | 对端PCEF的组信息，可用于多PCEF场景下的PCEF分组。当APPTYPE为DefaultPCEF时，不能配置。 取值说明： NULL(NULL)Group1(Group1)～Group64(Group64) 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| CUSTOMATTR    | 自定义属性    | 用于具体描述一个对端PCEF的自定义属性，以便于扩展。其值域类型为字符串，区分大小写，当APPTYPE取值为PCEF时，可以设置该参数。 取值范围：长度不超过32的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| IPDOMAIN      | IP地址域    | 用于标识对端关联的IP地址域。当APPTYPE为PCEF/DefaultPCEF/DynamicPCEF时，该参数才显示且为可选参数。 取值范围：长度为0~255的字符串。 取值说明：如果配置为字符串“NULL”则PCF按未配置处理。 默认值：无。  说明： 本参数不能设置为“NULL”，否则不生效。本参数参与会话绑定时，按“VRM_IPDOMAINSENSITIVE”的取值决定是否大小写敏感。“VRM_IPDOMAINSENSITIVE”取值为“1”时，修改本参数对已在线的Gx会话不生效，对新上线的Gx会话生效。本参数只在“VRM_IPDOMAINSRCFORGX”取值为“1”且SET BINDCFG中“IPV4IPDOMAIN”设置为“Support”时生效。修改“VRM_IPDOMAINSRCFORGX”取值为“1”前，建议先调整“IPDOMAIN”参数为目标值。                                                                                                                                                                                                                                                                                                                                                                                                                      |

## 使用实例

1. 增加PCRF的目的主机配置。“PCRF标识”为“1”，“目的主机ID”为“0”，“应用类型”为“DefaultPCEF”，“目的实体名称”为“PCEF”, “能力字典ID”为“67”，“对端PCEF类别”为“ggsn”。

   ```
   ADD PDHOSTCFG: PCRFID=1, HOSTID=0, APPTYPE=DefaultPCEF, DEN="PCEF", ABILITYDICTID=67, PCEFCAT="ggsn";
   ```
2. 增加PCRF的目的主机配置。“PCRF标识”为“1”，“目的主机ID”为“1”，“应用类型”为“PCEF”，“目的实体名称”为“GGSN”，“目的主机名”为“GGSN”，“能力字典ID”为“67”，“对端PCEF类别”为“ggsn”，“对端PCEF组”为“Group1”。

   ```
   ADD PDHOSTCFG: PCRFID=1, HOSTID=1, APPTYPE=PCEF, DEN="GGSN", DHN="GGSN", ABILITYDICTID=67, PCEFCAT="ggsn", PPCEFGROUP=Group1;
   ```
3. 增加PCRF的目的主机配置。“PCRF标识”为“1”，“目的主机ID”为“6”，“应用类型”为“PCEF”，“目的实体名称”为“GGSN”，“目的主机名”为“GGSN1”，“能力字典ID”为“67”，“对端PCEF类别”为“ggsn”，“对端PCEF组”为“Group1”，“自定义属性”为“2a02:3018:0:300:0:20”。

   ```
   ADD PDHOSTCFG: PCRFID=1, HOSTID=6, APPTYPE=PCEF, DEN="GGSN", DHN="GGSN1", ABILITYDICTID=67, PCEFCAT="ggsn", PPCEFGROUP=Group1, CUSTOMATTR="2a02:3018:0:300:0:20";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                      | 原因分析                                             | 处理建议                                                                                                                                        |
|------:|:---------------------------|:-------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------|
| 58243 | 参数IPDOMAIN对应用类型为AF的目的主机无效。 | 执行本命令时，“应用类型”参数的取值为“AF”、“DefaultAF”或“DynamicAF”。 | 重新执行本命令，将“应用类型”参数的取值取为“PCEF”、“DefaultPCEF”或“DynamicPCEF”，再添加参数“IP地址域”的值。重新执行本命令，若“应用类型”参数的取值取为“AF”、“DefaultAF”或“DynamicAF”，则不添加参数“IP地址域”的值。 |
