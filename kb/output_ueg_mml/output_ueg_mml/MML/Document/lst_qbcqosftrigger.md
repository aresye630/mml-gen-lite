# 查询QBC计费QoS Flow级的trigger参数（LST QBCQOSFTRIGGER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于查询QBC计费QoS Flow级的trigger参数。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                             |
|:------------|:---------|:-----------------------------------------------------------------------------------------------------------------|
| CCTMPLTNAME | 融合计费模板名称 | 可选必选说明：可选参数  参数含义：该参数用于指定融合计费模板名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。不区分大小写。  默认值：无  配置原则：  该参数使用ADD CCT命令配置生成。 |

## 使用实例

查询绑定名称为“test”的CCT融合计费模板的QBC计费QoS Flow级的trigger参数：

```
%%LST QBCQOSFTRIGGER: CCTMPLTNAME="test";%%
RETCODE = 0  操作成功

结果如下
--------
融合计费模板名称  =  test
         QoS更新  =  延迟上报
   QoS流时间阈值  =  延迟上报
   QoS流流量阈值  =  延迟上报
       QoS流结束  =  延迟上报
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称    | 输出项解释                        |
|:---------|:-----------------------------|
| 融合计费模板名称 | 该参数用于指定融合计费模板名称。             |
| QoS更新    | 该参数用于设置QoS更新的trigger上报方式。    |
| QoS流时间阈值 | 该参数用于设置QoS流时间阈值的trigger上报方式。 |
| QoS流流量阈值 | 该参数用于设置QoS流流量阈值的trigger上报方式。 |
| QoS流结束   | 该参数用于设置QoS流结束的trigger上报方式。   |
