# 查询RRC Inactive生效的TAI范围（LST RRCINACTTAI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

本命令用于查询RRC Inactive生效的TAI范围。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                            |
|:-------|:--------|:--------------------------------------------------------------------------------------------------------------------------------|
| MCC    | MCC     | 可选必选说明：可选参数  参数含义：该参数用于指定移动国家代码。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                  |
| MNC    | MNC     | 可选必选说明：可选参数  参数含义：该参数用于指定移动网号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                |
| BGNTAC | 跟踪区起始编码 | 可选必选说明：可选参数  参数含义：该参数用于表示跟踪区编码的起始值。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。TAC编码为16进制数，只能由数字（0-9），字母（A-F、a-f）组成。字母大小写不敏感。  默认值：无  配置原则：无 |

## 使用实例

- 查询RRC Inactive生效的TAI范围，执行如下命令：

  ```
  %%LST RRCINACTTAI:;%%
  RETCODE = 0  操作成功

  输出结果如下
  --------------
             MCC  =  123
             MNC  =  00
  跟踪区起始编码  =  000112
  跟踪区结束编码  =  000350
        描述信息  =  2
  (结果个数 = 1)

  ---    END
  ```
- 查询MCC为“123”，MNC为“00”条件下，RRC Inactive生效的TAI范围，执行如下命令：

  ```
  %%LST RRCINACTTAI: MCC="123", MNC="00";%%
  RETCODE = 0  操作成功

  输出结果如下
  --------------
             MCC  =  123
             MNC  =  00
  跟踪区起始编码  =  000112
  跟踪区结束编码  =  000350
        描述信息  =  2
  (结果个数 = 1)

  ---    END
  ```

## 输出结果说明

| 输出项名称   | 输出项解释                                |
|:--------|:-------------------------------------|
| MCC     | 该参数用于指定移动国家代码。                       |
| MNC     | 该参数用于指定移动网号。                         |
| 跟踪区起始编码 | 该参数用于表示跟踪区编码的起始值。                    |
| 跟踪区结束编码 | 该参数用于表示跟踪区编码结束值。                     |
| 描述信息    | 该参数用于描述使用RRC Inactive的TAI，在运维中起助记作用。 |
