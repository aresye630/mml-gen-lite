#### 命令功能

**适用网元：MME、AMF**

此命令用于查询当前配置的H-SFN=0的参考时间。

#### 注意事项

此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                                                                          |
|:-----------|:-------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TIMETYPE   | 时间类型         | 可选必选说明：可选参数 参数含义：该参数用于设置MME/AMF使用何种计时方式与eNodeB/NG-RAN对齐H-SFN=0的参考时间。 数据来源：对端协商 取值范围：枚举类型。 GPS(GPS)UTC(UTC) 系统初始设置值：UTC(UTC)。 配置原则：MME/AMF支持UTC，GPS两种时间作为参考时间，使用时只能使用其中一种，使用何种方式需与eNodeB/NG-RAN侧协商一致                                                                                                                                           |
| GPSBEGIN   | 使用GPS起始时间    | 可选必选说明：条件可选参数 参数含义：该参数用于设置MME/AMF是否使用GPS起始时间（1980年1月6日00:00:00）作为与eNodeB/NG-RAN对齐H-SFN=0的参考时间。 前提条件：该参数在“时间类型”参数配置为“GPS”后生效。 数据来源：全网规划 取值范围：枚举类型。 NO（否）。YES（是）。 系统初始设置值：NO（否）。                                                                                                                                                                |
| DATE       | H-SFN参考日期    | 可选必选说明：条件可选参数 参数含义：该参数用于设置H-SFN=0的具体日期，参数格式为“YYYY&MM&DD”，其中，“YYYY”代表年，“MM”代表月，“DD”代表日。 前提条件： 该参数在“使用GPS起始时间”参数配置为“否”后生效。该参数在“时间类型”参数配置为“UTC”后生效。 数据来源：全网规划 取值范围：日期类型，输入格式是YYYY/MM/DD。（日期限定只允许配置1990年1月1日至2037年12月31日） 系统初始设置值：2010/01/01 配置原则：设置的日期为已经过去的某一日期，不能配置未来的日期。                                                                      |
| TIME       | H-SFN参考时间    | 可选必选说明：条件可选参数 参数含义：该参数用于设置H-SFN=0的具体时间，输入格式为“HH:MM:SS”，“HH”代表时，“MM”代表分，“SS”代表秒。 前提条件： 该参数在“使用GPS起始时间”参数配置为“否”后生效。该参数在“时间类型”参数配置为“UTC”后生效。 数据来源：全网规划 取值范围：时间类型，输入格式是HH:MM:SS。 系统初始设置值：00：00：00                                                                                                                                                 |
| GPSLEAPSEC | 当前时间与参考时间闰秒差 | 可选必选说明：条件可选参数 参数含义：该参数用于设置当前时间与参考时间闰秒差。 前提条件：该参数在“使用GPS起始时间”参数设置后生效。 数据来源：全网规划 取值范围：整数类型，取值范围为0～255。 系统初始设置值：0。 配置原则：如果选择使用GPS起始时间（1980年1月6日00:00:00）作为H-SFN=0的参考时间，本参数设置值=最新公布的闰秒数-19（19为1980年1月1日公布的闰秒数）。如果设置了其他时间作为H-SFN=0的参考时间，本参数设置值=最新公布的闰秒数-设置的参考时间之前最近一次公布的闰秒数。闰秒数请到IERS官方网站查询：http://hpiers.obspm.fr/eoppc/bul/bulc/UTC-TAI.history。 |

#### 使用实例

查询H-SFN参考时间配置。

LST HSFNTIME:;

```
%%LST HSFNTIME:;%%
RETCODE = 0  操作成功。

查询结果如下
-------------------------
                 时间类型  =  使用GPS时间作为H-SFN=0的参考时间
          使用GPS起始时间  =  否
            H-SFN参考日期  =  2000-01-01
            H-SFN参考时间  =  00:00:00
 当前时间与参考时间闰秒差  =  4
(结果个数 = 1)

---    END
```
