# 查询HTTP链路告警过滤黑白名单(LST LNKALMBWADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询已配置的客户端动态链路告警过滤黑白名单记录。

## 注意事项

- 若需要查询所有的链路告警过滤黑白名单记录，不输入任何参数。

- 若需要查询某一个具体链路告警过滤黑白名单记录，请输入“过滤器名称”；若需要查询某一类链路告警过滤黑白名单记录，请输入“IP版本”、“操作类型”参数中的一个或多个。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                  |
|:-----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------|
| FILTERNAME | 过滤器名称  | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个过滤器名称来查询动态链路告警过滤黑白名单记录；若不输入，则表示查询所有过滤器名称下的记录。 取值范围：长度不超过128位的字符串，只允许输入：0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。 |
| IPVER      | IP版本   | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个IP地址类型来查询链路告警过滤黑白名单记录；若不输入，则表示查询所有IP地址类型下的记录。 取值范围：IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。                     |
| OPTYPE     | 操作类型   | 可选必选说明：可选参数 参数含义：用于指示系统查询哪个操作类型的链路告警过滤黑白名单记录；若不输入，则表示查询所有的操作类型下的记录。 取值范围：WHITELIST(白名单)BLACKLIST(黑名单) 默认值：无。 配置原则：无。                  |

## 使用实例

1. 查询所有已配置的客户端动态链路告警过滤黑白名单记录：

   ```
   LST LNKALMBWADDR:;
   ```

   ```
   %%LST LNKALMBWADDR:;%%
   RETCODE = 0  操作成功

   操作结果如下: 
   --------
   过滤器名称  IP版本      IPV4地址      IPV4掩码  IPV6地址                  IPV6前缀长度  操作类型  

   file01      IPV4        10.144.118.1  24        NULL                      NULL          白名单    
   (结果个数 = 1)

   ---    END
   ```
2. 查询“过滤器名称”为“file01”的客户端动态链路告警过滤黑白名单记录：

   ```
   LST LNKALMBWADDR: FILTERNAME="file01";
   ```

   ```
   %%LST LNKALMBWADDR: FILTERNAME="file01";%%
   RETCODE = 0  操作成功

   操作结果如下: 
   --------
     过滤器名称  =  file01
         IP版本  =  IPV4
       IPV4地址  =  10.144.118.1
       IPV4掩码  =  24
       IPV6地址  =  NULL
   IPV6前缀长度  =  NULL
       操作类型  =  白名单
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见增加HTTP链路告警过滤黑白名单(ADD LNKALMBWADDR)命令的参数说明。
