# 查询HLB TLS配置(LST HLBTLSCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询配置数据库中HLB的TLS配置信息：

- 如果需要查询HLB的全部TLS配置信息，请不要输入任何参数。
- 如果需要查询HLB的某个TLS配置信息，请依据参数说明输入查询条件。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                |
|:------------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| TLSCFGID    | TLS配置ID | 可选必选说明：可选参数 参数含义：用于指示系统按照TLS配置ID来查询HLB的TLS配置信息；若不输入，则表示所有的TLS配置ID。 取值范围：1～128 默认值：无。 配置原则：无。                                                        |
| TLSCFGNAME  | TLS配置名称 | 可选必选说明：可选参数 参数含义：用于指示系统按照TLS配置名称来查询HLB的TLS配置信息；若不输入，则表示所有的TLS配置名称。 取值范围：长度不超过32的字符串。 默认值：无。 配置原则：无。                                                 |
| PROTOCOLVER | 协议版本    | 可选必选说明：可选参数 参数含义：用于指示系统按照协议版本来查询HLB的TLS配置信息；若不输入，则表示所有的协议版本。 取值范围： TLS1_2(TLS1.2协议) TLS1_3(TLS1.3协议)TLS1_2+TLS1_3(TLS1.2协议+TLS1.3协议) 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询所有的HLB TLS配置信息。

   ```
   LST HLBTLSCFG:;
   ```

   ```
   %%LST HLBTLSCFG:;%%
   RETCODE = 0  操作成功

   操作结果如下;
   -------------------------
   TLS配置ID  TLS配置名称  协议版本    TLS加密套件                              TLS1.3加密套件  描述      
   1          TLScfg       TLS1.2协议  TLS_ECDHE_ECDSA_WITH_AES_256_GCM_SHA384  NULL            NULL      
   2          TLScfg01     TLS1.2协议  TLS_DHE_RSA_WITH_AES_256_GCM_SHA384      NULL            TLS link  
   (结果个数 = 2)

   ---    END
   ```
2. 查询特定HLB TLS的配置信息。“TLS配置ID”为“1”。

   ```
   LST HLBTLSCFG: TLSCFGID=1;
   ```

   ```
   %%LST HLBTLSCFG:;%%
   RETCODE = 0  操作成功

   操作结果如下;
   -------------------------
        TLS配置ID  =  1
      TLS配置名称  =  tls1
         协议版本  =  TLS1.2协议
      TLS加密套件  =  TLS_DHE_RSA_WITH_AES_256_GCM_SHA384
   TLS1.3加密套件  =  NULL
             描述  =  tls1
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD HLBTLSCFG**命令的参数说明。
