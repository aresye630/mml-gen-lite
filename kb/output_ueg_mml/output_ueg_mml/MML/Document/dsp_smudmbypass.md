# 显示会话UDM Bypass信息（DSP SMUDMBYPASS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF**

该命令用于查询5G会话上下文UDM Bypass信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识         | 参数名称          | 参数说明                                                                                                                               |
|:-------------|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------|
| QUERYTYPE    | 查询方式          | 可选必选说明：必选参数  参数含义：该参数用于指定查询方式。  数据来源：本端规划 取值范围： IMSI（用户IMSI号）MSISDN（用户MSISDN号）MEI（用户MEI号）  默认值：无  配置原则：无                           |
| IMSI         | 国际移动用户标识      | 可选必选说明：该参数在"QUERYTYPE"配置为"IMSI"时为条件必选参数。  参数含义：该参数用于指定用户永久标识或者国际移动用户标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是5~15。  默认值：无  配置原则：无         |
| MSISDN       | 移动台国际 ISDN 号码 | 可选必选说明：该参数在"QUERYTYPE"配置为"MSISDN"时为条件必选参数。  参数含义：该参数用于指定一般公共订阅标识或移动台国际 ISDN 号码。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~15。  默认值：无  配置原则：无 |
| MEI          | 国际移动设备标识      | 可选必选说明：该参数在"QUERYTYPE"配置为"MEI"时为条件必选参数。  参数含义：该参数用于指定永久设备标识或国际移动设备标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~16。  默认值：无  配置原则：无           |
| PDUSESSIONID | PDU会话标识       | 可选必选说明：必选参数  参数含义：该参数用于指定 PDU 会话 ID。  数据来源：本端规划  取值范围：整数类型，取值范围是1~15。  默认值：无  配置原则：无                                               |

## 使用实例

查询类型为IMSI，IMSI为123031100100001，PDUSESIONID为5的会话UDM Bypass信息：

```
%%DSP SMUDMBYPASS: QUERYTYPE=IMSI, IMSI="123038700100001", PDUSESSIONID=5;%%
RETCODE = 0  操作成功

Session UDM Bypass Info
----------------
               国际移动用户标识  =  123038700100001
                           IMEI  =  NULL
           移动台国际 ISDN 号码  =  8613587000001
                   PDU 会话标识  =  5
             会话UDM Bypass状态  =  是
         进入UDM Bypass状态时间  =  2021-11-11 01:57:36+00:00
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称            | 输出项解释                                                                              |
|:-----------------|:-----------------------------------------------------------------------------------|
| 国际移动用户标识         | 该参数用于指定用户永久标识或者国际移动用户标识。                                                           |
| 移动台国际 ISDN 号码    | 该参数用于指定一般公共订阅标识或移动台国际 ISDN 号码。                                                     |
| 国际移动设备标识         | 该参数用于指定永久设备标识或国际移动设备标识。                                                            |
| PDU会话标识          | 该参数用于指定 PDU 会话 ID。                                                                 |
| 会话UDM Bypass状态   | 该参数用于显示会话的UDM Bypass状态。 取值说明： TRUE(TRUE)FALSE(FALSE)                               |
| 进入UDM Bypass状态时间 | 该参数用于显示会话进入UDM Bypass状态的时间，UDMBYPASS为False时不显示，UDMBYPASS为True时显示进入UDM Bypass状态的时间。 |
