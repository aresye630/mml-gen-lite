# 修改NF对端参数（MOD PEERNFCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致系统异常，影响业务处理，需联系华为技术支持确认后再执行。

该命令用于在配置数据库中修改一条NF对端参数配置信息的数据记录。

在该命令中，系统通过“NF类型”参数来唯一标识一条NF对端参数配置信息的数据记录。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                     |
|:------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFTYPE      | NF类型   | 可选必选说明：必选参数 参数含义：用于标识PCF对端NF类型。标识一条NF对端参数配置信息的数据记录的关键字段，用于指定需要修改哪一条NF对端参数配置信息的数据记录，操作员可以使用LST PEERNFCFG命令查询获得。 取值范围：NRF(NRF)AMF(AMF)SMF(SMF)BSF(BSF)CHF(CHF)AF(AF)SCP(SCP)UDR(UDR)NWDAF(NWDAF)HPCF(HPCF) 默认值：无。 配置原则：无。                                                                                                  |
| MAXNFNUM    | 最大NF数  | 可选必选说明：可选参数 参数含义：用于设置某个NF可配置的最大NF的数量。 取值范围：1～1024 单位：个 默认值：无。 配置原则： 对于SMF，该参数可设置的最大值为1024。对于AMF，该参数可设置的最大值为512。对于SCP/HPCF，该参数可设置的最大值为256。对于CHF/NRF，该参数可设置的最大值为64。对于AF/BSF，该参数可设置的最大值为32。对于UDR，该参数可设置的最大值为16。对于NWDAF，该参数可设置的最大值为128。如果该参数未设置，则AMF/SMF/SCP默认按照256处理，NRF/NWDAF/HPCF默认按照64处理，AF/BSF/CHF默认按照32处理,UDR默认按照16处理。 |
| MAXLINKNUM  | 最大链路数  | 可选必选说明：可选参数 参数含义：用于设置PCF和某个NF建立的最大链路数。 取值范围：0，2～128，0表示最大建链路数和部署的HLB服务实例数相同 单位：条 默认值：无。 配置原则： 当该参数设置的最大链路数超过HLB服务实例的数量时，实际建链的数量为HLB服务实例数。该参数如果由小改大，NCS则轮选HLB，增加建立链路。该参数如果由大改小，NCS则轮选HLB，拆除多余链路。                                                                                                                          |
| NFCLEARTIME | NF老化时长 | 可选必选说明：可选参数 参数含义：用于设置PCF清理故障NF对端的时长。 取值范围：0～72，0表示不老化 单位：小时 默认值：24。 配置原则：无。                                                                                                                                                                                                                                              |

## 使用实例

修改NF对端参数。“NF类型”为“SMF”，“最大链路数”为“25”，“NF老化时长”为“28”。

```
MOD PEERNFCFG: NFTYPE=SMF, MAXLINKNUM=25, NFCLEARTIME=28;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                                                                                                                                                                                | 原因分析        | 处理建议                      |
|------:|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:------------|:--------------------------|
| 58084 | 参数取值无效：SMF的MAXNFNUM取值范围是1-1024，AMF的MAXNFNUM取值范围是1-512，CHF/NRF的MAXNFNUM取值范围是1-64，AF/BSF的MAXNFNUM取值范围是1-32，SCP/HPCF的MAXNFNUM取值范围是1-256，UDR的MAXNFNUM取值范围是1-16，NWDAF的MAXNFNUM取值范围是1-128。 | 输入的提示参数不合法。 | 重新输入提示错误的参数的取值，确保其取值符合要求。 |
