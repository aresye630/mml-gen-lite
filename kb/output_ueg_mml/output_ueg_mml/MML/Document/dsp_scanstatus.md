# 查询当前遍历任务状态(DSP SCANSTATUS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询遍历任务状态。

**说明** 

与业务、配额、套餐、账户相关的通知，即使通知被抑制导致没有发送，统计通知发送次数时该值也会被增加。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                             |
|:-----------|:-------|:---------------------------------------------------------------------------------|
| TYPE       | 类型     | 用于表示要查询的遍历任务类型。 取值范围：CURRENT(当前离线遍历任务)HISTORY(历史离线遍历任务) 默认值： CURRENT。            |
| REPORTTYPE | 查询报告类型 | 用于表示要查询的遍历任务结果显示的类型。 REPORT_TASK(离线任务状态报告)REPORT_STAT(离线业务统计报告) 默认值：REPORT_TASK。 |

## 使用实例

- 查询遍历任务状态报告。“查询报告类型”为“REPORT\_TASK”。

  DSP SCANSTATUS: TYPE=CURRENT,REPORTTYPE=REPORT_TASK;
