# 增加PCRF结果码映射（ADD PRCMAP）

- 命令功能

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响业务处理，需联系华为技术支持确认后再执行。

该命令用于在配置数据库中增加一条PCRF的结果码映射记录。当UPCF向对端发送CCA-I、CCA-U或AAA消息时，如果配置了PCRF的结果码映射，则UPCF向对端返回上述消息类型的Result-Code AVP中会携带了映射后的目的结果码。

## 注意事项

- 执行本命令时，请参照参数说明的取值范围要求，输入“接口类型”下对应的“源结果码”和“目的结果码”。
- 配置结果码映射记录时不能和已有结果码映射记录的参数值重复，可通过LST PRCMAP查询已有的配置记录，再根据查询结果重新执行本命令。
- 执行本命令后，建议操作员将转换后的结果码进行记录，在处理对应的错误码之前，需要先了解该错误码是否存在转换记录。

## 使用实例

添加一条PCRF的结果码映射，“接口类型”为“Gx(Gx)”，“源结果码”为“RC5147(DIAMETER\_ERROR\_CONFLICTING\_REQUEST)”，“目的结果码”为“RC5017(DIAMETER\_NO\_COMMON\_SECURITY)”。

```
ADD PRCMAP: IFTYPE=Gx, SRCRC=RC5147, DSTRC=RC5017;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释       | 原因分析                    | 处理建议                                 |
|------:|:------------|:------------------------|:-------------------------------------|
| 57753 | 接口类型和错误码不匹配 | 输入的源结果码或目的结果码不在该接口要求范围。 | 请参照参数说明的取值范围要求，重新输入该接口对应的源结果码、目的结果码。 |
