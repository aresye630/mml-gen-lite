# 设置全局缺省PCRF组（SET DFTGLBPCRFGRP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

此命令用来修改缺省全局PCRF分组。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                |
|:------------|:--------|:----------------------------------------------------------------------------------------------------|
| PCRFGRPNAME | PCRF组名称 | 可选必选说明：可选参数 参数含义：该参数用于设置绑定的PCRF组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～128。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。 |

#### 使用实例

修改DFTGLBPCRFGRP：PCRFGRPNAME为pcr：

```
SET DFTGLBPCRFGRP:PCRFGRPNAME="pcr";
```
