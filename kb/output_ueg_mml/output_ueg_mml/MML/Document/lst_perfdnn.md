# 查询DNN性能统计对象（LST PERFDNN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF**

该命令用于查询DNN性能统计对象。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                 |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DNN    | 数据网络名称 | 可选必选说明：可选参数  参数含义：该参数用于表示指定的网络切片支持的数据网络名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无  配置原则：  确保DNN性能统计对象支持的DNN在LST APN中能够查询到。  |
| MCC    | 移动国家码  | 可选必选说明：可选参数  参数含义：该参数表示组成Serving PLMN的移动国家码信息。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：  本参数需要在ADD NGSRVPLMN中已配置。                                                                                                                |
| MNC    | 移动网号   | 可选必选说明：可选参数  参数含义：该参数表示组成Serving PLMN的移动网号信息。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：  本参数需要在ADD NGSRVPLMN中已配置。                                                                                                             |
| SNSSAI | 网络切片   | 可选必选说明：可选参数  参数含义：该参数标识切片信息，由切片业务类型和切片细分标识组成。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是8~10。网络切片输入格式为SST-SD。SST输入长度范围是1~3，只允许输入十进制数字（0-9），除0之外不能以0开头，对应十进制数取值范围是0~255；SD输入长度为6，采用十六进制表示，只能由数字（0-9），字母（A-F、a-f）组成，字母大小写不敏感。  默认值：无  配置原则：  本参数需要在ADD PLMNNS中已配置。 |

## 使用实例

当运营商希望查询一个在PERFDNN配置的DNN性能统计对象时,执行如下命令：

```
%%LST PERFDNN:;%%
RETCODE = 0  操作成功

结果如下
------------------------------
              DNN = "huawei.com"
              MCC = "123"
              MNC = "03"
           SNSSAI = "1-010101"
(结果个数 = 1)

---    END
```

| 移动国家码   | 该参数表示组成Serving PLMN的移动国家码信息。 |
| 移动网号    | 该参数表示组成Serving PLMN的移动网号信息。  |
