# 修改报表服务对端链路配置信息(MOD DRSPEERLINKCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于修改或调整数据报表服务对端链路的配置信息。在该命令中，系统通过链路ID关键字段来唯一标识一条数据报表服务对端链路的配置信息。

## 注意事项

- 对于IPv4地址，不支持配置以下地址：127.0.0.1、0.0.0.0、255.255.255.255、224.0.0.1。
- IPv6类型的IP地址仅支持格式xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx，其中x表示一个十六进制数（0～9、A～F或者a~f）。
- IPV6地址不支持以下特殊地址的配置，其中x表示一个十六进制数（0～9、A～F或者a~f），A-F与a-f实际意义一样，大小写不区分：

  - 0000:0000:0000:0000:0000:0000:0000:0000
  - FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF
  - 0000:0000:0000:0000:0000:0000:0000:0001
  - FFxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE8x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE9x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEAx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEBx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx

## 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                                                                                                         |
|:------------|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LINKID      | 链路ID       | 可选必选说明：必选参数 参数含义：用于标识一条报表服务对端链路配置信息的数据记录。标识一条报表服务对端链路数据记录的关键字段，用于指定需要对哪一条对端链路数据记录进行修改或调整，操作员可以使用LST DRSPEERLINKCFG命令查询获得。 取值范围：1～32 默认值：无。 配置原则：无。                                           |
| LOCALROLE   | 本地角色       | 可选必选说明：必选参数 参数含义：用于标识本地角色。 取值说明：FTPClient(FTP客户端) 默认值：无。 配置原则：无。                                                                                                                             |
| IPVER       | IP版本       | 可选必选说明：必选参数 参数含义：用于指定IP地址的IP版本类型。 取值范围： IPV4（IPV4）IPV6（IPV6） 默认值：无。 配置原则：无。                                                                                                                  |

| LOCALIPV6   | 本端IPV6地址   | 可选必选说明：可选参数 参数含义：报表服务与对端对接的参数之一，仅当“IP版本”选择“IPV6(IPV6)”时该参数需要配置，用于指定链路使用的本端DRS设备的IPv6地址。 取值范围：IPv6地址 默认值：无。 配置原则：此IP地址必须是本地实际的IP地址且必须先由ADD DRSDEVADDR命令定义，然后才能在此处引用。                          |
| PEERIP      | 对端IP地址     | 可选必选说明：可选参数 参数含义：报表服务与对端对接的参数之一，仅当“IP版本”选择“IPV4”时该参数有效，用于指定链路使用的对端IPv4地址。 取值范围：IPv4地址 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。                                                                      |
| PEERIPV6    | 对端IPV6地址   | 可选必选说明：可选参数 参数含义：报表服务与对端对接的参数之一，仅当“IP版本”选择“IPV6”时该参数有效，用于指定对端IPv6地址。 取值范围：IPv6地址 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。                                                                           |
| PEERPORT    | 对端端口       | 可选必选说明：可选参数 参数含义：报表服务与对端对接的参数之一，用于指定链路使用的对端端口。 取值范围：1～65534 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。                                                                                                |

| PASSWD      | 密码         | 可选必选说明：可选参数 参数含义：用于标识FTP客户端的登录密码。 取值范围：长度为不超过255的字符串。 默认值：无。 配置原则：密码中不能包含空格。                                                                                                                 |
| CFM         | 确认密码       | 可选必选说明：可选参数 参数含义：用于标识FTP客户端的登录确认密码。 取值范围：长度为不超过255的字符串。 默认值：无。 配置原则：无。                                                                                                                       |

| DESCRIPTION | 描述         | 可选必选说明：可选参数 参数含义：用于描述链路配置的用途。 取值范围：长度不超过32的字符串。 默认值：无。 配置原则：无。                                                                                                                               |
| ADSTS       | 链路管理状态     | 可选必选说明：可选参数 参数含义：该参数仅在“对端服务器类型”配置为“FTP(FTP协议)”或“SFTP(SFTP协议)”且“本地角色”配置为“FTPClient(FTP客户端)”的情况下起作用。用于指定链路的管理状态，包括：使能、去使能。“链路管理状态”为“去使能”的链路是无法建立的。 取值范围： DISABLE(去使能)ENABLE(使能) 默认值：无。 配置原则：无。 |

## 使用实例

修改一条报表服务对端链路的对端IP和对端端口配置信息。“链路ID”为“1”，“本地角色”为“FTPClient(FTP客户端)”，“对端IPV6地址”修改为“fc00:0:0:666:59:123:189:121”，“对端端口”修改为“22”，其他参数使用缺省值。

```
MOD DRSPEERLINKCFG: LINKID=1, LOCALROLE=FTPClient, IPVER=IPV6, LOCALIPV6="fe80:0:11:21:211:110:35:906", PEERIPV6="fc00:0:0:666:59:123:189:121", PEERPORT=22, USRNAME="user", PASSWD="*****", CFM="*****", FTPPATH="/FTP", DESCRIPTION="popd";
```

**说明** 

密码和确认密码复杂度要求如下：

- 密码长度为8-255位。
- 至少包含4个种类，分别为：大写字母、小写字母、数字和特殊字符`!@#$%^&\*()\_-=+\|[]{};:'",<.>/。
- 密码不能和用户名或其倒序相同。
- 如果密码不满足复杂度要求，存在安全风险。
- 密码中不能存在空格。

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 57998 | IP地址非法。                  | 对端IP不合法，不允许输入的IP地址请参见注意事项。                        | 请重新输入符合配置要求的合法IP地址。                                                                                                                                                                                                                                                                                                                                             |
| 57999 | IP/PORT 已经存在。            | 同种“本地角色”下，输入的“对端IP地址”，“对端端口”存在同样的记录。              | 执行LST DRSPEERLINKCFG查询所有已存在“对端IP地址”及其对应的“对端端口”记录。执行本命令，重新输入“对端IP地址”和“对端端口”，且不能和已存在的记录一样。                                                                                                                                                                                                                                                                        |
| 58000 | DRSPEERLINKCFG不存在。       | 链路ID存在，但是本地角色不存在。                                 | 重新输入本地角色，取值为： FTPClient(FTP客户端)                                                                                                                                                                                                                                                                                                                                 |
