# 添加网元公共信息（ADD NFCOMINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加网元的公共信息，用于指定3GPP TS 29.510协议中服务注册时NFProfile、NFService中相同字段的值，通过**ADD NFSRV**关联索引后，向NRF注册。

该命令的参数索引关系如图1所示。

**图1** 命令参数的索引关系图

## 注意事项

系统支持最多添加128条网元的公共信息记录。

|:-----------------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

| FQDN             | 全量域名        | 可选必选说明：可选参数 参数含义：用于指定PCF网元的全量域名。5G场景下，NF实例向NRF发起PCF服务发现查询请求，支持NF Client端通过域名的方式获取PCF地址。 取值范围：长度不超过128位的字符串，字符串由数字、字母、“-”、“_”或“.”组成 说明： 自UPCF 20.3.0版本及后续版本，FQDN取值范围新增支持设置下划线。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| INTERPLMNFQDN    | PLMN间全量域名   | 可选必选说明：可选参数 参数含义：用于指定PCF网元和其它网络交互时体现的全量域名。 取值范围：长度不超过128位的字符串，字符串由数字、字母、“-”、“_”或“.”组成 说明： 自UPCF 20.3.0版本及后续版本，INTERPLMNFQDN取值范围新增支持设置下划线。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

| PRIORITY         | 优先级         | 可选必选说明：可选参数 参数含义：用于指定PCF网元的优先级。值越小，优先级越大。 取值范围：0～65535 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| CAPACITY         | 容量          | 可选必选说明：可选参数 参数含义：表示容量信息，即相对于同种业务类型的其他NF实例权重。如果nfServiceList参数也包含容量值，则对端优先选择nfServiceList中的容量值。 取值范围：0～65535 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| LOAD             | 负载          | 可选必选说明：可选参数 参数含义：用于指定PCF网元的当前负载百分比。 取值范围：0～100 默认值：0。 配置原则：当前预留配置，暂不支持获取业务微服务动态负载信息。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| CHECKIPADDR      | IP地址校验开关    | 可选必选说明：可选参数 参数含义：用于表示是否对“IP地址和端口”参数中的IP地址与HLB业务IP地址做校验。 取值范围： YES(YES)：表示需要检查参数“IP地址和端口”中的IP地址是否已通过ADD HLBDEVADDR命令添加配置。如果检查的结果存在，则该条命令执行的添加配置成功。如果检查的结果不存在，则该条命令执行的添加配置失败。NO(NO)：表示不需要检查参数“IP地址和端口”中的IP地址是否已通过ADD HLBDEVADDR命令添加配置。 默认值：YES(YES)。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |

## 使用实例

增加一条网元公共信息，“公共信息标识”为“cominfo\_01”，“网元类型”为“PCF”，“全量域名”为“huawei.com”，“优先级”为“5”：

```
ADD NFCOMINFO: NFCOMINFOID="cominfo_01", NFTYPE=PCF, FQDN="huawei.com", PRIORITY=5;
```
