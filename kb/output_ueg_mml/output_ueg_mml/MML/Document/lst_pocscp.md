# 查询PCRF对端OCS接入点实体配置信息(LST POCSCP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询对端OCS接入点的配置信息:

- 如果需要查询全部对端OCS接入点实体的配置信息，请不要输入任何参数；
- 如果需要查询某个对端OCS接入点实体的配置信息，请依据参数说明输入相应的参数作为查询的限制条件。

该命令的使用场景：当需要进行增加、删除、修改或者其他与对端OCS接入点实体相关的操作时，可以先通过此命令来查询对端OCS接入点实体的配置信息。

## 注意事项

无。

## 参数说明

| 参数ID          | 参数名称        | 参数描述                                                                                                                                                                                                                           |
|:--------------|:------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PCRFID        | PCRF标识      | 用于指示UPCF需要按照哪个PCRF标识来查询OCS接入点的配置信息。 取值范围：1 默认值：无。                                                                                                                                                                              |
| CPID          | 接入点标识       | 用于指示UPCF需要按照哪个接入点标识来查询OCS接入点的配置信息。 取值范围：0～15 默认值：无。                                                                                                                                                                            |
| CPN           | 接入点名称       | 用于指示UPCF需要按照哪个接入点名称来查询OCS接入点的配置信息。 取值范围：长度不超过128的字符串。 默认值：无。                                                                                                                                                                   |
| DN            | 对端域名        | 用于指示UPCF需要按照哪个对端域名来查询OCS接入点的配置信息。 取值范围：长度不超过64的字符串。 默认值：无。                                                                                                                                                                     |
| HN            | 对端主机名       | 用于指示UPCF需要按照哪个对端主机名来查询OCS接入点的配置信息。 取值范围：长度不超过127的字符串。 默认值：无。                                                                                                                                                                   |
| DASWITCH      | 审计开关        | 用于指示UPCF需要按照哪种审计开关来查询OCS接入点的配置信息。 取值说明： OFF(关闭定时审计)ON(打开定时审计) 默认值： 无。                                                                                                                                                          |
| DATIME        | 设备间审计时长 （m） | 用于指示UPCF需要按照哪个设备审计时长来查询OCS接入点的配置信息。 单位：分钟。 取值范围： 15～1440 默认值： 无。                                                                                                                                                               |
| CPP           | 接入点优先级      | 用于指示UPCF需要按照哪个接入点优先级来查询OCS接入点的配置信息。 取值范围：0～255 默认值：无。  说明： 在多个OCS对端上配置优先级，若优先级相同则是轮询关系，优先级不同则是主备关系，UPCF优先将消息发往优先级高的OCS。当OCS上已经存在会话，此时修改OCS对端优先级，导致多个OCS对端的优先级排序与修改前不一样，原OCS上已经存在的会话将保持现有处理，不会迁移到优先级较高的对端。同时，后续新会话按照新优先级排序选择对端。 |
| ABILITYDICTID | 能力字典ID      | 用于标识OCS能力字典。 取值范围：0~15 默认值：无。                                                                                                                                                                                                  |

## 使用实例

1. 查询所有的PCRF对端OCS接入点实体配置信息。

   ```
   LST POCSCP:;
   ```

   ```
   %%LST POCSCP:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
               PCRF标识  =  1
             接入点标识  =  0
             接入点名称  =  UPCF_OCS
               对端域名  =  huawei.com
             对端主机名  =  ocs.huawei.com
               审计开关  =  打开定时审计
   设备间审计时长 （m）  =  720
   (结果个数 = 1)

   ---    END
   ```
2. 查询特定接入点名称的PCRF对端OCS接入点实体配置信息。其中，“接入点名称”为“UPCF\_OCS”。

   ```
   LST POCSCP: CPN="UPCF_OCS";
   ```

   ```
   %%LST POCSCP: CPN="UPCF_OCS ";%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
               PCRF标识  =  1
             接入点标识  =  0
             接入点名称  =  UPCF_OCS
               对端域名  =  huawei.com
             对端主机名  =  ocs.huawei.com
               审计开关  =  打开定时审计
   设备间审计时长 （m）  =  720
   (结果个数 = 1)

   ---    END
   ```
