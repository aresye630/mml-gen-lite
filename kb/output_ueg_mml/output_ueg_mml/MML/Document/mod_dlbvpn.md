# 修改DLB VPN(MOD DLBVPN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于修改DLB接入CSLB时业务IP的VPN配置信息。在该命令中，系统通过“VPN索引”参数来唯一标识一条VPN数据记录。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                            |
|:------------|:-------|:----------------------------------------------------------------------------------------------------------------|
| VPNINDEX    | VPN索引  | 可选必选说明：必选参数 参数含义：标识一条VPN数据记录的关键字段，用于指定需要对哪一条VPN数据记录的参数进行修改或调整，操作员可以使用LST DLBVPN命令查询获得。 取值范围：0~15 默认值：无。 配置原则：无。 |
| VPNNAME     | VPN名称  | 可选必选说明：可选参数 参数含义：本参数用于标识CSLB业务IP的VPN名称。 取值范围：长度不超过31的字符串 默认值：无。 配置原则：需要与ADD L3VPNINST命令中“VPN实例名称”参数值保持一致。       |
| DESCRIPTION | 描述     | 可选必选说明：可选参数 参数含义：本参数用于标识CSLB业务IP的VPN名称。 取值范围：长度不超过32的字符串 默认值：无。 配置原则：无。                                         |

## 使用实例

修改一个VPN的名称。“VPN索引”为“0”，“VPN名称”为“VPN\_2”。

```
MOD DLBVPN: VPNINDEX=0, VPNNAME="VPN_2";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
