# 增加区域群(ADD AREAGP)

#### 命令功能

**适用网元：SGSN、MME**

此命令用于增加区域群记录，为区域群成员提供区域群标识，同一个区域群中的成员具有相同的接入控制策略。

如果需要对多个区域采用相同的接入控制策略时，需要执行此命令。

#### 注意事项

- 此命令最大记录数为50。
- 此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                |
|:-------|:-------|:--------------------------------------------------------------------|
| AREAID | 区域群标识  | 可选必选说明：必选参数 参数含义：该参数用于指定区域群标识。 数据来源：整网规划 取值范围：1~50 默认值：无            |
| AREAN  | 区域群名称  | 可选必选说明：可选参数 参数含义：该参数用于指定区域群名称。 数据来源：整网规划 取值范围：1~32位字符串 默认值：“noname” |

#### 使用实例

增加一条区域群标识为1的区域群记录：

ADD AREAGP: AREAID = 1;
