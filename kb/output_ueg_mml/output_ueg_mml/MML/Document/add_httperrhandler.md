# 增加间接路由代理故障重选配置（ADD HTTPERRHANDLER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于增加间接路由代理故障重选配置。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入1000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称         | 参数说明                                                                                                                                |
|:-------------|:-------------|:------------------------------------------------------------------------------------------------------------------------------------|
| NFTYPE       | 对端网络功能类型     | 可选必选说明：必选参数  参数含义：该参数用于指定对端网元类型。  数据来源：本端规划 取值范围： “SMF（SMF）”：表示对端网元为SMF。“UDM（UDM）”：表示对端网元是UDM。“AMF（AMF）”：表示对端网元是AMF。  默认值：无  配置原则：无 |
| STATUSCODE   | 状态码          | 可选必选说明：必选参数  参数含义：该参数用于指定状态码。  数据来源：本端规划  取值范围：整数类型，取值范围是0~1000。  默认值：无  配置原则：无                                                     |
| RESENDSWITCH | 间接路由代理故障处理开关 | 可选必选说明：可选参数  参数含义：该参数用于控制开启和关闭间接路由代理故障处理功能。  数据来源：本端规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：ENABLE  配置原则：无                             |

## 使用实例

增加对端为UDM网络功能，状态码504的间接路由代理故障重选功能。

```
ADD HTTPERRHANDLER:NFTYPE=UDM,STATUSCODE=504,RESENDSWITCH=ENABLE;
```
