# 查询手动流控策略(LST HDFCPOL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询手动流控策略信息。

- 若需要查询所有流控策略数据记录，请不要输入任何参数。
- 若需要查询某一条流控策略数据记录，请输入“手动流控策略ID”参数。

  **说明** 

  该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                 |
|:-------|:---------|:-----------------------------------------------------|
| ID     | 手动流控策略ID | 用于指示系统需要按照哪个流控策略索引来查询流控策略数据记录；若不输入，则表示查询所有的流控策略数据记录。 |

## 使用实例

1. 查询全部流控策略数据记录。

   ```
   LST HDFCPOL:;
   ```

   ```
   %%LST HDFCPOL:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    手动流控策略ID  流控开关  流控消息类型  手动流控模式  本端服务器名称    SOAP对端ID  最大处理能力  

    1               开启      HTTP          HLB_SRV       HLB_SRV           0           22             
    4               开启      SOAP-TLS      SOAP对端ID    NULL              6           1000          
   (结果个数 = 2)

   ---    END
   ```
2. 查询流控策略索引值为1的数据记录。

   ```
   LST HDFCPOL: ID=1;
   ```

   ```
   %%LST HDFCPOL:;%%
   RETCODE = 0  操作成功

   结果如下
   --------
   手动流控策略ID  =  1
         流控开关  =  开启
     流控消息类型  =  HTTP
     手动流控模式  =  HTTP链路名称
   本端服务器名称  =  HLB_SRV
       SOAP对端ID  =  0
     最大处理能力  =  22
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD HDFCPOL**命令的参数说明。
