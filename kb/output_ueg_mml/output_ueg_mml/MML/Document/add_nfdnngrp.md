## 命令功能

该命令用于PCF向NRF注册时增加网元DNN组信息。

通过此命令可以配置一个PCF的DNN组信息（由各运营商自行定义），实现同一网元DNN组访问。

**图1** 命令参数索引关系图

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                      |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GRPNAME | 组名称    | 可选必选说明：必选参数 参数含义：用于标识一个网元DNN组信息所属组的信息。 取值范围：长度不超过32的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则： 该参数由本端自定义。该参数可以重复，但和索引组合以后成为全局唯一对象关键字段，组合不能重复。该参数配置时不能取值为“NULL”，否则无法被正常索引。 |
| INDEX   | 索引     | 可选必选说明：必选参数 参数含义：用于标识一个网元DNN组信息在组内的唯一一条记录。 取值范围：1~10240 默认值：无。 配置原则：该参数在不同的组名称下可以重复，但和组名称组合以后成为全局唯一对象关键字段，组合不能重复。                                                         |
| DNN     | DNN    | 可选必选说明：必选参数 参数含义：用于标识DNN。 取值范围：长度不超过64的字符串 默认值：无。 配置原则：该参数在同一个组名称下可以重复，即不同记录的组名称、DNN可以相同，但索引不相同。                                                                          |

## 使用实例

增加一条网元DNN组信息。“组名称”为“nfdnngrp”，“索引”为“1”，“DNN”为“dnn01”：

```
ADD NFDNNGRP: GRPNAME="nfdnngrp", INDEX=1, DNN="dnn01";
```
