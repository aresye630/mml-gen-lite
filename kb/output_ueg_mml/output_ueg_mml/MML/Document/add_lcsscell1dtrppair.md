# 增加LCS小站一维定位TRP（ADD LCSSCELL1DTRPPAIR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于增加LCS小站一维定位的TRP配置。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为20000。
- 如果需要开启小站一维定位功能，需要执行ADD LCSALGOPARA命令增加LCSCALCSWITCH属性的UTDOA\_ONE\_DIM一维算法开关。
- TRPID1和TRPID2两个参数没有顺序限制，若两个参数只是顺序不一致会被认为是同一条记录，不能重复添加。
- TRPID1和TRPID2两个参数值不能相同。
- 执行该命令配置成1维TRP，不能再执行ADD LCSSCELLALONETRP将其配置为0维TRP，反之相同。
- 执行该命令配置成1维TRP，如果同时需要其参与2维定位，需要执行ADD LCSSCELL2DTRP命令将其配置为2维TRP，否则不参与2维定位。
- 配置小站一维定位的TRP时，按照实际规划配置相邻关系。
- 执行该命令后，重新发起定位请求时修改生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                |
|:---------|:-------|:------------------------------------------------------------------------------------|
| GNODEBID | 基站标识   | 可选必选说明：必选参数 参数含义：该参数用于设置基站标识。 数据来源：全网规划 取值范围：整型数字类型，取值范围为0~4294967295。 默认值：无 配置原则：无 |
| TRPID1   | TRP标识1 | 可选必选说明：必选参数 参数含义：该参数用于设置TRP标识。 数据来源：全网规划 取值范围：整型数字类型，取值范围为1~65535。 默认值：无 配置原则：无     |
| TRPID2   | TRP标识2 | 可选必选说明：必选参数 参数含义：该参数用于设置TRP标识。 数据来源：全网规划 取值范围：整型数字类型，取值范围为1~65535。 默认值：无 配置原则：无     |

#### 使用实例

增加LCS小站一维定位的TRP配置：

```
ADD LCSSCELL1DTRPPAIR: GNODEBID=190041, TRPID1=1, TRPID2=2;
```
