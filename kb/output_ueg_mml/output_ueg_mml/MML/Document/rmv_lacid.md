# 从LAC组内删除一个LAC（RMV LACID）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用来删除LAC组内绑定的LAC号段。

#### 注意事项

该命令执行后只对新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                       |
|:-------------|:--------|:-------------------------------------------------------------------------------------------|
| LACGROUPNAME | 指定LAC组名 | 可选必选说明：必选参数 参数含义：该参数用于指定LAC组名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。不支持空格，不区分大小写。 默认值：无 配置原则：无 |
| LACSECNUM    | Lac 段编号 | 可选必选说明：可选参数 参数含义：该参数用于指定LAC段编号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～23999。 默认值：无 配置原则：无             |

#### 使用实例

假设运营商需要删除指定LAC组绑定的某个LAC号段，LAC组为beijing，LAC号段为2时，执行该命令：

```
RMV LACID:LACGROUPNAME="beijing",LACSECNUM=2;
```
