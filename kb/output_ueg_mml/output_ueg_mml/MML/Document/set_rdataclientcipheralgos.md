# 设置数据同步客户端支持的加密算法（SET RDATACLIENTCIPHERALGOS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于设置数据同步客户端支持的加密算法。在登陆远端数据同步服务器时，本地客户端和对端服务器协商加密算法。如果服务器和客户端没有相同的算法，则协商失败。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 可选参数至少配置一个。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | CHACHA20_POLY1305_OPENSSH   | AES128GCM_OPENSSH   | AES128CTR   | AES192CTR   | AES256CTR   |
|:-------|:----------------------------|:--------------------|:------------|:------------|:------------|
| 初始值    | True                        | True                | True        | True        | True        |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

设置数据同步客户端支持的加密算法，开启CHACHA20POLY1305\_OPENSSH、AES128GCM\_OPENSSH、AES128CTR、AES192CTR、AES256CTR加密算法：

```
SET RDATACLIENTCIPHERALGOS: CHACHA20_POLY1305_OPENSSH=TRUE, AES128GCM_OPENSSH= TRUE, AES128CTR=TRUE, AES192CTR=TRUE, AES256CTR= TRUE;
```
