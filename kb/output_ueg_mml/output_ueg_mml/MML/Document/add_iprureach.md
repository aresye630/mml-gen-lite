# 增加RU到网关的可达性检测配置（ADD IPRUREACH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于添加RU到网关可达性检测的配置。该命令用于入不转板场景，用于通告CSLB RU到网关的故障状态。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为4096。
- 执行该命令前要保证通过ADD L3VPNINST已配置指定的VPN实例，通过ADD BFDSESSION已配置指定的BFD会话。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称    | 参数说明                                                                                                            |
|:---------------|:--------|:----------------------------------------------------------------------------------------------------------------|
| VPNNAME        | VPN实例名称 | 可选必选说明：必选参数 参数含义：该参数用于表示VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                                        |
| IPVERSION      | IP版本    | 可选必选说明：必选参数 参数含义：该参数用来表示网关地址的IP版本。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。ipv6unicast：IPv6单播。 默认值：无            |
| DESTADDR4      | 目的地址    | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“ipv4unicast”时为必选参数。 参数含义：该命令用来表示网关的IP地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无   |
| DESTADDR6      | 目的地址    | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“ipv6unicast”时为必选参数。 参数含义：该命令用来表示网关的IPv6地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无 |
| SOURCERU       | RU名称    | 可选必选说明：必选参数 参数含义：该参数用来表示资源单元名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～49。 默认值：无                                         |
| BFDSESSIONNAME | BFD会话名称 | 可选必选说明：必选参数 参数含义：该参数用来表示联动的BFD会话名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～64。 默认值：无                                     |

#### 使用实例

增加一条RU到网关可达性检测的配置：

```
ADD IPRUREACH:VPNNAME="vrf",IPVERSION=ipv4unicast,DESTADDR4="10.1.1.1",SOURCERU="VNODE_VNRS_VNFC_IPU_0066",BFDSESSIONNAME="test";
```
