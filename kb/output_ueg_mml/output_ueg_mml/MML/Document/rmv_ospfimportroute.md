# 删除OSPF引入路由配置（RMV OSPFIMPORTROUTE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来删除引入到OSPF域中的外部路由。

#### 注意事项

- 该命令执行后立即生效。
- 只有配置了OSPF进程和引入外部路由后才能使用该命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称    | 参数说明                                                                                                                     |
|:---------------|:--------|:-------------------------------------------------------------------------------------------------------------------------|
| PROCID         | OSPF进程号 | 可选必选说明：必选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无                                                   |
| TOPOID         | 拓扑标识    | 可选必选说明：可选参数 参数含义：拓扑标识。 数据来源：全网规划 取值范围：整数类型，取值范围为0。 默认值：无 配置原则：目前只支持默认拓扑0。                                                |
| PROTOCOL       | 协议分类    | 可选必选说明：必选参数 参数含义：用于指定OSPF引入外部路由的路由类型。 数据来源：本端规划 取值范围：枚举类型。 Direct：直连路由。OSPF：OSPF路由。Static：静态路由。BGP：BGP路由。wlr：无线路由。 默认值：无 |
| PROTOCOLPROCID | 协议进程号   | 可选必选说明：条件可选参数 前提条件：该参数在“PROTOCOL”配置为“OSPF”时为可选参数。 参数含义：引入路由协议的进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无          |

#### 使用实例

将OSPF进程下1下引入的OSPF进程2的路由删除：

```
RMV OSPFIMPORTROUTE: PROCID=1, TOPOID=0, PROTOCOL=OSPF, PROTOCOLPROCID=2;
```
