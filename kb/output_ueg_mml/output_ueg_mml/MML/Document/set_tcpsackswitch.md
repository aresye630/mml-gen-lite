# 设置TCP SACK开关配置（SET TCPSACKSWITCH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

SET TcpSackSwitch命令用来修改Gx，Gy接口TCP协议是否支持SACK选项。

#### 注意事项

- 该命令需要重新建链后才能生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | GX      | GY      |
|:-------|:--------|:--------|
| 初始值    | DISABLE | DISABLE |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称                | 参数说明                                                                                                                                        |
|:-------|:--------------------|:--------------------------------------------------------------------------------------------------------------------------------------------|
| GX     | Gx接口TCP协议支持SACK选项开关 | 可选必选说明：可选参数 参数含义：Gx接口TCP是否支持SACK选项。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：否。ENABLE：是。 默认值：无 配置原则： ENABLE：Gx接口支持TCP SACK选项。DISABLE：Gx接口不支持TCP SACK选项。 |
| GY     | Gy接口TCP协议支持SACK选项开关 | 可选必选说明：可选参数 参数含义：Gy接口TCP是否支持SACK选项。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：否。ENABLE：是。 默认值：无 配置原则： ENABLE：Gy接口支持TCP SACK选项。DISABLE：Gy接口不支持TCP SACK选项。 |

#### 使用实例

GX接口使能TCP的SACK选项，GY接口使能TCP的SACK选项：

```
SET TCPSACKSWITCH:GX=ENABLE,GY=ENABLE;
```
