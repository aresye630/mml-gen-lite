# 查询通用接入和移动扩展功能（LST EDGEAMCOMMFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询通用接入和移动扩展功能。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询通用接入和移动扩展功能，执行如下命令：

```
%%LST EDGEAMCOMMFUNC:;%%
RETCODE = 0  操作成功

结果如下
--------
  二次重选UDM开关  =  使能
      UDM部署模式  =  合设
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称     | 输出项解释                                                                                                   |
|:----------|:--------------------------------------------------------------------------------------------------------|
| 二次重选UDM开关 | 该参数用于设置AMF是否开启二次重选UDM功能。                                                                                |
| UDM部署模式   | 当SECSELECTUDMSW为ENABLE时，该参数用于表示AUSF和UDM的部署模式。该参数仅用于配置当大网主备AUSF均故障后是否仍需要与大网UDM进行交互，与现网UDM和AUSF的实际部署模式无关。 |
