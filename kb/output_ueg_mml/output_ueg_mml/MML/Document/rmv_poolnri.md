# 删除POOL区NRI配置信息(RMV POOLNRI)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

此命令用于删除本POOL区内非本SGSN的NRI属性配置信息。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                   |
|:-------|:--------|:-----------------------------------------------------------------------------------------------------------------------|
| POOLID | POOL区标识 | 可选必选说明：必选参数 参数含义：该参数用于指定POOL区标识。 取值范围：0～4095 默认值：无                                                                     |
| NRIV   | NRI值    | 可选必选说明：必选参数 参数含义：该参数用于指定NRI的值，NRI（Net Resource Identify），网络资源标识，用于标识一个CN节点。RAN根据NRI将MS的消息路由到对应的SGSN。 取值范围：0～1023 默认值：无 |

#### 使用实例

删除POOLID为1，NRI值为10的NRI记录：

RMV POOLNRI: POOLID=1, NRIV=10;
