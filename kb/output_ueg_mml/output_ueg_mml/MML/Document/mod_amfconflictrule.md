# 修改AMF冲突规则（MOD AMFCONFLICTRULE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，增加冲突规则可能影响现有业务对冲突场景的判断和解决策略，如果需要使用该命令，请联系华为技术支持。

**适用NF：AMF**

该命令用于修改AMF冲突规则。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                               |
|:------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CSTYPE      | CS类型   | 可选必选说明：必选参数  参数含义：该参数用于指定CS的类型。  数据来源：本端规划 取值范围： UEAM（UEAM模块）LOCM（LOCM模块）UEM（UEM模块）AMPOLICY（AMPOLICY模块）  默认值：无  配置原则：无                                                             |
| PROCTYPE    | 流程内部标识 | 可选必选说明：必选参数  参数含义：该参数用于指定流程内部标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~64。不能为非法字符，只允许输入字母，数字，区分大小写。例如：ProcTypeIntraAmfInitialReg。  默认值：无  配置原则：无                                         |
| INITEVENTID | 初始事件类型 | 可选必选说明：必选参数  参数含义：该参数用于指定触发新流程的初始事件类型。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~64。不能为非法字符，只允许输入字母，数字，区分大小写。例如：InitIntraRegistration。  默认值：无  配置原则：无                                        |
| RULE        | 冲突流程规则 | 可选必选说明：必选参数  参数含义：该参数用于指定冲突流程规则。  数据来源：本端规划  取值范围：任意类型，取值范围是0~4096。不能为非法字符，只允许输入JSON格式范围内的合法字符，区分大小写。例如：{"Name": "When","Children": [{ "Name": "ResultPreempt" }]}。  默认值：无  配置原则：无 |

## 使用实例

在IntraAmfHandover流程中，收到了NG-RAN的“RRC Inactive Transition Report”消息，如果希望将当前的处理策略修改为抢占策略，则执行如下命令。

```
MOD AMFCONFLICTRULE: CSTYPE=UEAM, PROCTYPE="IntraAmfHandover", INITEVENTID="InitN2NotifyEvent", RULE="{\"Name\":\"When\",\"Children\":[{\"Name\":\"ResultPreempt\"}]}";
```
