#### 命令功能

**适用网元：SGSN**

当使用Iu-flex功能时，需要配置SGSN的NRI，该命令用于配置本SGSN的NRI属性。Iu-flex指一个RAN连接同一个功能域（CS或者PS）的多个CN节点的功能。Iu-flex新增的功能包括：RAN节点的消息路由功能；各个CN节点的负载平衡功能；缺省SGSN功能；后向兼容的功能等。系统开启Iu-flex功能，当发生附着或者路由区更新流程时，本SGSN可以根据P-TMSI中的NRI是否在本表中来确定是否为Inter流程。关于Iu-flex功能描述，请参考3GPP协议23.236。

#### 注意事项

- 本命令执行后立即生效。
- 在本UNC执行SGSN Pool用户迁移的过程中，请不要执行本命令，否则会导致用户无法平滑地迁移到其它SGSN中。
- NRI值，或NRI起始值与长度构成的取值范围不能超过或者等于2NRI长度。
- POOLID、NRI起始值唯一确定一条记录。
- 该表最大记录数为32。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                                                                                                                                                            |
|:--------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| POOLID  | POOL区标识 | 可选必选说明：必选参数 参数含义：该参数用于POOL区标识。 数据来源：整网规划 取值范围：0～4095 默认值：无                                                                                                                                                                                                      |
| NRIVBGN | NRI起始值  | 可选必选说明：必选参数 参数含义：该参数用于设置NRI起始值，NRI（Net Resource Identify），网络资源标识，用于标识一个CN节点。RAN根据NRI将MS的消息路由到对应的SGSN。 数据来源：整网规划 取值范围：0～1023 默认值：无  说明： NRI的取值范围在0～(2n-1)，n为本Pool的NRI长度。若POOL表的NRI长度为10，则LOCALNRI表的NRI个数必须大于等于4， NRI起始值小于等于1020。                                 |
| NRINUM  | NRI个数   | 可选必选说明：必选参数 参数含义：该参数用于SGSN最少需要配置的NRI的个数。 数据来源：整网规划 取值范围：1～64 默认值：无  说明： “NRI个数”的取值只与ADD POOL命令的“NRI长度”参数有关。详情请见表1。NRI的取值范围在0～(2n-1)，n为本Pool的NRI长度。                                                                                                              |
| STATE   | NRI状态   | 可选必选说明：可选参数 参数含义：该参数用于指定NRI的状态。 数据来源：整网规划 取值范围：“UNBLOCKED(UNBLOCKED)”“BLOCKED(BLOCKED)” 默认值：“UNBLOCKED(UNBLOCKED)”  说明： 当NRI处于“UNBLOCKED(UNBLOCKED)”状态时，SGSN在新分配PTMSI时将使用NRI值；当NRI处于“BLOCKED(BLOCKED)”状态时，SGSN在新分配PTMSI时将不使用BLOCKED状态的NRI值，但是可以正确识别该NRI值为本局NRI。 |

#### 使用实例

增加一条POOLID为1，NRI的值为10，NRI个数为1，NRI状态为UNBLOCKED的本局NRI配置信息：

ADD LOCALNRI: POOLID=1, NRIVBGN=10, NRINUM=1, STATE=UNBLOCKED;
