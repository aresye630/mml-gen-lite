# 设置Tethering用户终端数量检测全局开关（SET TETHERDETGLBSW）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，该命令生效范围为整机，开启后可能导致性能下降明显。

该命令用来设置Tethering用户终端数量检测全局开关。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 此命令的生效范围为整机。
- 此命令开启后可能导致性能下降明显。执行命令前请评估对性能的影响，如果无法评估请联系华为技术支持。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | SWITCH   |
|:-------|:---------|
| 初始值    | DISABLE  |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                     |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------|
| SWITCH | 开关标识   | 可选必选说明：可选参数 参数含义：该参数用来配置Tethering用户终端数量检测功能开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：Tethering终端数量检测功能关闭。ENABLE：Tethering终端数量检测功能打开。 默认值：无 配置原则：无 |

#### 使用实例

假如运营商需使能Tethering用户终端数量检测全局功能：

```
SET TETHERDETGLBSW: SWITCH=ENABLE;
```
