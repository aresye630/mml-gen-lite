# 修改5G Connect PLMN（MOD NGCONNECTPLMN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于修改可接入到本运营商的Connect PLMN的相关信息。

## 注意事项

- 该命令执行后立即生效。

- 紧急呼叫EMG参数同时受SET NGMMFUNC命令EMG参数控制，且同时开启才生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称       | 参数说明                                                                                                                                                                                                                                                                |
|:----------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NOID      | 运营商标识      | 可选必选说明：必选参数  参数含义：该参数用于指定在UNC系统中唯一标识某个运营商。  数据来源：本端规划  取值范围：整数类型，取值范围为0。  默认值：无  配置原则：无                                                                                                                                                                             |
| MCC       | 移动国家码      | 可选必选说明：必选参数  参数含义：该参数用于表示组成Connect PLMN的移动国家码信息。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                                                                                                                                      |
| MNC       | 移动网号       | 可选必选说明：必选参数  参数含义：该参数用于表示组成Connect PLMN的移动网号信息。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                                                                                                                                   |
| SUBRANGE  | 用户范围       | 可选必选说明：可选参数  参数含义：该参数用于指定应用5G Connect PLMN的用户范围。  数据来源：全网规划 取值范围： “ALL_USER（所有用户）”：所有用户“SPECIFIED_IMSI_RANGE（指定IMSI范围）”：指定IMSI范围  默认值：无  配置原则：无                                                                                                                     |
| IMSIPRE   | IMSI前缀     | 可选必选说明：该参数在"SUBRANGE"配置为"SPECIFIED_IMSI_RANGE"时为条件必选参数。  参数含义：该参数用于指定应用5G Connect PLMN的IMSI前缀。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~15。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                                                                                   |
| EMG       | 是否允许紧急呼叫业务 | 可选必选说明：可选参数  参数含义：该参数用于指定是否允许使用紧急呼叫业务。  数据来源：全网规划 取值范围： “EMFNR（NR接入的紧急呼叫回落）”：支持从NR接入5GC的紧急呼叫业务回落到EPS。“EMCNR（NR接入的紧急呼叫）”：支持NR接入5GC的紧急呼叫业务。  默认值：无  配置原则：  如果运营商期望通过EPS Fallback的方式回落到LTE网络进行紧急呼叫时，建议配置为EMFNR；如果运营商期望直接使用5G网络进行紧急呼叫时，建议配置为EMCNR。                      |
| EMGCNUMSW | 紧急号码下发开关   | 可选必选说明：可选参数  参数含义：该参数用于控制AMF在给漫游用户发送Registration Accept消息时，是否将配置的MCC的紧急呼叫号码携带在消息中发送给UE。  数据来源：全网规划 取值范围： “YES（是）”：是“NO（否）”：否  默认值：无  配置原则：  当本参数设置为“YES(是)”时，AMF将在Registration Accept消息中给漫游用户发送紧急号码列表。其中，紧急号码列表来源于ADD NGEMGCNUM中的配置，如果ADD NGEMGCNUM没有配置，则不下发紧急号码列表。 |
| ROAMTYPE  | 漫游模式       | 可选必选说明：可选参数  参数含义：该参数用于指定漫游用户的漫游模式。  数据来源：全网规划 取值范围： “INTERNATIONALROAM（国际漫游）”：国际漫游模式。“NATIONALROAM（异网漫游）”：异网漫游模式。  默认值：无  配置原则：无                                                                                                                                   |
| HIDEULISW | 隐藏用户位置信息开关 | 可选必选说明：可选参数  参数含义：该参数用于控制AMF在发给周边网元的消息中携带的UserLocation是否为固定值。  数据来源：全网规划 取值范围： “YES（是）”：是“NO（否）”：否  默认值：无  配置原则：  不建议本功能与用户事件订阅与上报、指定区域用户位置上报(PRA)和5G网络基于实时位置的策略控制功能同时开启。                                                                                           |
| TAC       | 跟踪区域       | 可选必选说明：该参数在"HIDEULISW"配置为"YES"时为条件可选参数。  参数含义：该参数用于指定跟踪区域。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。TAC编码为16进制数，按照字符串格式输入，字符串长度为6，只能由数字（0-9），字母（A-F、a-f）组成。字母大小写不敏感。  默认值：无  配置原则：无                                                                                            |
| NRCELLID  | 小区标识       | 可选必选说明：该参数在"HIDEULISW"配置为"YES"时为条件可选参数。  参数含义：该参数用于指定小区标识。  数据来源：全网规划  取值范围：字符串类型，输入长度是9。采用十六进制表示（无须输入“0x”前缀），只能由数字（0-9），字母（A-F、a-f）组成。字母大小写不敏感。  默认值：无  配置原则：无                                                                                                     |
| GNBIDLEN  | gNodeB标识长度 | 可选必选说明：该参数在"HIDEULISW"配置为"YES"时为条件可选参数。  参数含义：该参数用于指定gNodeB标识的长度（比特位数）。  数据来源：全网规划  取值范围：整数类型，取值范围是22~32。  默认值：无  配置原则：无                                                                                                                                            |
| GNBID     | gNodeB标识   | 可选必选说明：该参数在"HIDEULISW"配置为"YES"时为条件可选参数。  参数含义：该参数用于指定gNodeB标识。  数据来源：全网规划  取值范围：整数类型，取值范围是1~4294967295。  默认值：无  配置原则：无                                                                                                                                              |
| DESC      | 描述信息       | 可选必选说明：可选参数  参数含义：该参数是对配置的Connect PLMN的描述信息，在运维过程中起助记作用。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~32。  默认值：无  配置原则：  输入单空格将删除该参数已有配置项。                                                                                                                                       |

## 使用实例

为PLMN为12345的所有漫游用户修改描述信息，执行如下命令：

```
MOD NGCONNECTPLMN: NOID=0, MCC="123", MNC="45", DESC="for MNO B";
```
