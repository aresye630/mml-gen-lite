# 清除网元实例缓存信息(CLR NFPROFILE)

- 命令功能

- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损，因此执行该命令前，需要与华为技术支持确认后才可以实施。

本命令用于清除服务发现AMF、SMF、SCP网元实例信息缓存数据，或清除SEPP网元链路数据。例如当服务发现AMF、SMF、SCP网元实例信息的缓存数量达到软参“NFProfileCacheLimit(NFProfile缓存大小)”配置的最大值时，可以执行该命令清除缓存信息。

## 注意事项

- 本命令建议在夜间话务量低时操作。
- 执行本命令清除当前服务发现缓存数据前，请确认UDM和NRF链路正常：执行**DSP UDMNFSRV**命令，若“查询位置”参数选择“REMOTE（远端）”时**DSP UDMNFSRV**命令能正常返回网元实例动态信息，则当前系统中有正常的NRF，能保证服务发现可返回正常数据。
- 本命令仅可清除SEPP网元链路数据，由于SEPP网元服务发现数据是通过**ADD UDMDISCNFPROF**命令增加的静态服务发现配置数据，不可通过输入SEPP网元的“网元实例标识”清除，否则会报错误码360143。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                     |
|:------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CLRMETHOD   | 清除方式   | 可选必选说明：必选参数 参数含义：用于标识按照哪种类型清除AMF、SMF、SCP网元实例信息缓存数据或SEPP网元链路数据。 取值范围：ALL(所有)：清除所有AMF、SMF、SCP网元实例信息缓存数据，或SEPP网元链路数据。Single(单条)：清除某一条AMF、SMF或SCP网元实例信息缓存数据。CrossPLMN(所有跨PLMN)：清除所有跨PLMN网络的AMF或SMF网元实例信息缓存数据。 默认值：无。 配置原则：无。 |
| NFTYPE      | 网元类型   | 可选必选说明：条件必选参数 参数含义：用于标识清除系统中哪个网元类型的网元实例信息或链路数据。 取值范围： AMF(AMF)：接入和移动性管理功能SCP(SCP)：服务通信代理SEPP(SEPP)：安全边缘保护代理SMF(SMF)：会话管理功能 默认值：无。 配置原则：仅当本命令中的“清除方式”参数取值为“ALL(所有)”时该参数有效。                                                |
| NFINSID     | 网元实例标识 | 可选必选说明：条件必选参数 参数含义：用于标识清除系统中缓存的哪个网元实例号的AMF、SMF或SCP网元实例缓存信息。该参数可以通过执行DSP NFINSTANCE命令获取。 取值范围：长度不超过36位的字符串。 默认值：无。 配置原则：仅当本命令中的“清除方式”参数取值为“Single(单条)”时该参数有效。                                                             |
| FORCIBLECLR | 是否强制清除 | 可选必选说明：必选参数 参数含义：用于标识是否强制清除AMF、SMF、SCP网元实例缓存信息或SEPP网元链路数据。 取值范围：TRUE(是)：强制清除AMF、SMF、SCP网元实例缓存信息或SEPP网元链路数据。FALSE(否)：不强制清除AMF、SMF、SCP网元实例缓存信息或SEPP网元链路数据。 默认值：无。 配置原则：无。                                                  |

## 使用实例

1. 当出现NRF故障、业务失败时，强制清除“网元实例标识”为“10406029-ffff-ffff-ffff-6197a1d09d55”的网元实例缓存信息：

   ```
   CLR NFPROFILE: CLRMETHOD=Single, NFINSID="10406029-ffff-ffff-ffff-6197a1d09d55", FORCIBLECLR=TRUE;
   ```
2. 当需要清除SEPP网元链路数据时，设置“清除方式”为“ALL”，“网元类型”为“SEPP”，“是否强制清除”为“TRUE(是)”：

   ```
   CLR NFPROFILE: CLRMETHOD=All, NFTYPE=SEPP, FORCIBLECLR=TRUE;
   ```

## 输出结果说明

该命令执行异常，会返回对应的错误码。常见错误码如下表1所示。

|    错误码 | 消息解释                                                            | 原因分析                                                | 处理建议                                                         |
|-------:|:----------------------------------------------------------------|:----------------------------------------------------|:-------------------------------------------------------------|
| 360041 | 参数值不合法                                                          | 输入的“网元实例标识”参数取值不存在。                                 | 执行DSP NFINSTANCE命令查询“网元实例标识”参数，确保参数输入正确。                     |
| 360143 | 指定的NFINSID是静态服务发现配置数据，请使用RMV UDMDISCNFPROF命令删除, 不合法参数包含NFINSID。 | 输入的“网元实例标识”参数取值是通过ADD UDMDISCNFPROF命令增加的静态服务发现配置数据。 | 执行RMV UDMDISCNFPROF命令删除“网元实例标识”参数对应的“网元实例名称”的配置数据。           |
| 360148 | NRF全部故障，禁止清除缓存数据。                                               | NRF全部故障，导致无法使用本命令清除缓存信息。                            | 使用命令DSP UDMNFSRV查询实例注册状态信息，若“当前注册状态”参数为“服务暂停状态”，请联系华为技术支持处理。 |
