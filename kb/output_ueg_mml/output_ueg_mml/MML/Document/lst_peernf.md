# 查询对端NF（LST PEERNF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询对端NF信息。

- 如果需要查询全部对端NF信息，请不要输入任何参数。
- 如果需要查询指定对端NF信息，请依据参数说明输入查询条件。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                  |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTID | NF标识   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个NF标识来查询对端NF信息；若不输入，则表示所有的NF标识。 取值范围：长度不超过36位的字符串 默认值：无。 配置原则：无。                                                                          |
| NFTYPE   | NF类型   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个NF类型来查询对端NF信息；若不输入，则表示所有的NF类型。 取值范围： NRF(NRF)AMF(AMF)SMF(SMF)BSF(BSF)CHF(CHF)AF(AF)SCP(SCP)UDR(UDR)NWDAF(NWDAF)HPCF(HPCF) 默认值：无。 配置原则：无。 |
| PEERID   | 对端标识   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个对端标识来查询对端NF信息；若不输入，则表示所有的对端标识。 取值范围：0~1023 默认值：无。 配置原则：无。                                                                                |
| STATE    | 状态     | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个状态来查询对端NF信息；若不输入，则表示所有的状态。 取值范围： ONLINE(在线)OFFLINE(离线) 默认值：无。 配置原则：无。                                                                    |

## 使用实例

- 查询所有的对端NF信息。

  ```
  LST PEERNF:;
  ```

  ```
  %%LST PEERNF:;%%
  RETCODE = 0  操作成功

  操作结果如下
  ------------
  NF标识     NF类型  对端标识  NF优先级  协议类型  IP地址      端口号  状态  故障时间  

  NA         SMF     0         1         HTTP      10.0.5.36   10501   在线  0         
  NA         AMF     1         2         HTTP      10.5.5.36   10502   在线  0         
  (结果个数 = 2)

  ---    END
  ```
- 查询SMF对端信息。

  ```
  LST PEERNF: NFTYPE=SMF;
  ```

  ```
  %%LST PEERNF: NFTYPE=SMF;%%
  RETCODE = 0  操作成功

  操作结果如下
  ------------
        NF标识  =  NA
        NF类型  =  SMF
      对端标识  =  0
      NF优先级  =  1
      协议类型  =  HTTP
        IP地址  =  10.0.5.36
        端口号  =  10501
          状态  =  在线
      故障时间  =  0
  (结果个数 = 1)

  ---    END
  ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义如表1。

| 输出项名称   | 输出项解释                                                          |
|:--------|:---------------------------------------------------------------|
| NF标识    | 用于表示查询的NF标识。 取值范围：长度不超过36位的字符串 当NF类型为NRF、SMF、AMF、AF时，此参数取值为NA。 |
| NF类型    | 用于表示NF类型。 取值范围： NRFAMFSMFBSFCHFAFSCPUDRNWDAFHPCF               |
| 对端标识    | 用于表示对端标识。 取值范围：0~1023                                          |
| NF优先级   | 用于表示NF的优先级，数字越小优先级越高。 取值范围：0~65535                             |
| 协议类型    | 用于表示NF使用的协议。 取值范围： HTTPHTTPS                                   |
| IP地址    | 用于表示NF的IP地址。 取值范围：IPv4地址/IPv6地址                                |
| 端口号     | 用于表示NF的端口号。                                                    |
| 状态      | 用于表示NF的状态。 取值范围： 在线离线                                          |
| 故障时间    | 用于表示NF故障的时间。 取值范围：UTC时间                                        |
