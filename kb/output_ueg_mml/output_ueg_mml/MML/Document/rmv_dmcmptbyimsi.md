# 删除IMSI对应的Diameter兼容性(RMV DMCMPTBYIMSI)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于删除Diameter兼容性参数策略。

#### 注意事项

- 该命令执行后对已经附着的用户不立即生效，对新接入的用户立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                           |
|:---------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：必选参数 参数含义：该参数用于指定Diameter兼容性参数策略的用户范围。 数据来源：全网规划 取值范围：“FOREIGN_USER(外网用户)”“HOME_USER(本网用户)”“IMSI_PREFIX(指定IMSI前缀)” 默认值：无 配置原则： Diameter参数策略优先级从高到低为：“IMSI_PREFIX(指定IMSI前缀)”，“FOREIGN_USER(外网用户)”或“HOME_USER(本网用户)”。系统优先查找高优先级的配置记录，如果查找不到，再查找低优先级的配置记录。 |
| NOID     | 运营商标识  | 可选必选说明：条件必选参数 参数含义：该参数用于指定运营商标识。 前提条件：该参数在“用户范围”参数配置为“FOREIGN_USER(外网用户)”或“HOME_USER(本网用户)”后生效。 数据来源：全网规划 取值范围：0～64，128～254 默认值：无  说明： 对于外网用户，该参数是与其归属运营商签订可漫游协议，为其提供服务的MNO/MVNO运营商标识。对于本网用户，该参数是为该用户归属的MNO/MVNO运营商标识。                                         |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI前缀。 前提条件: 该参数在用户范围设定为“IMSI_PREFIX(指定IMSI前缀)”时，才需要配置。 数据来源：全网规划 取值范围：0～15位十进制数字字符串。 默认值：无  说明： IMSI前缀的匹配方式采取由前向后的最长匹配，即若对于用户可以匹配到多个用户群，则使用IMSI前缀最长的用户群配置。                                                                         |

#### 使用实例

场景参见**ADD DMCMPTBYIMSI**的命令使用实例。

删除以12303为IMSI前缀的用户的配置策略：

RMV DMCMPTBYIMSI: SUBRANGE=IMSI\_PREFIX, IMSIPRE="12303";
