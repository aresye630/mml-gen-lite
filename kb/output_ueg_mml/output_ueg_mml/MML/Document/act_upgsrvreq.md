# 下发升级服务申请（ACT UPGSRVREQ）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于下发升级服务申请。下发CTRL升级完成后的请求时设置为CTRL\_UPG\_END，下发ALL升级完成后的请求时设置为ALL\_UPG\_END。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                          |
|:-------|:-------|:----------------------------------------------------------------------------------------------|
| PHASE  | 升级阶段   | 可选必选说明：必选参数 参数含义：升级阶段。 数据来源：本端规划 取值范围： CTRL_UPG_END：ctrl升级完成。ALL_UPG_END：全部升级完成。 默认值：无 配置原则：无 |

#### 使用实例

下发CTRL升级完成后的下表请求：

```
ACT UPGSRVREQ: PHASE=CTRL_UPG_END;
```
