# 回退分片数据迁移（RBK SHARDTRANS）

## 命令功能

**须知** 

该命令属于高危命令。该操作执行后回退数据迁移任务，操作不当将导致扩缩容失败、业务严重呼损。因此执行该命令前需要与华为技术支持进行确认。

数据迁移是指把一个DUS微服务的部分或所有分片数据迁移到另外的DUS微服务里。数据迁移的主要使用场景为：

- 在DUS微服务扩容场景下，需要将原DUS微服务中的分片数据迁移到新的DUS微服务中。
- 在DUS微服务缩容场景下，需要将隔离的DUS微服务中的分片数据迁移到未隔离的DUS微服务中。

该命令支持回退分片数据迁移任务。数据迁移过程中出现错误，此时可通过执行该命令回退分片数据迁移任务。

## 注意事项

- 该命令不允许进行批操作。
- 该命令必须在华为技术工程师指导下执行。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                        |
|:--------|:-------|:--------------------------------------------------------------------------------------------|
| APPTYPE | 应用类型   | 可选必选说明：必选参数。 参数含义：用于请求系统按照指定的应用类型进行回退分片数据迁移操作。 取值范围：需要与LST APPTYPE的“应用类型”对应。 默认值：无。 配置原则：无。 |

## 使用实例

回退分片数据迁移任务。

```
RBK SHARDTRANS: APPTYPE = "SUP-DUS";
```
