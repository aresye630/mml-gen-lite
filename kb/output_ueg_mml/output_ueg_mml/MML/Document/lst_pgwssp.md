# 查询PGW系统软参(LST PGWSSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询PGW系统软参信息。

- 若需要查询所有PGW系统软参信息，请不要输入任何参数。
- 若需要查询指定的PGW系统软参信息，请输入“参数名”。

## 注意事项

无。

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                       |
|:-------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| SYSPARAMETER | 参数名    | 用于指定需要对哪一类PGW软参数据记录的参数进行查询。 取值说明：详细信息请参考产品手册的“参考 > PGW Web LMT用户数据和全局数据管理 > PGW Web LMT命令 > 全局数据命令组 > 系统参数管理 > 查询系统参数（LST PSYSPARA）”中“参数标识”列描述的枚举值。 默认值：无。 |

## 使用实例

1. 查询全部的PGW系统软参配置信息。

   ```
   LST PGWSSP:;
   ```
2. 查询指定“参数名”为“AddSubSwitch”的PGW软参信息。

   ```
   LST PGWSSP: SYSPARAMETER=AddSubSwitch;
   ```

   ```
   %%LST PGWSSP: SYSPARAMETER=AddSubSwitch;%%
   RETCODE = 0  操作成功  

   操作结果如下:
   -------------          
           参数名  =  AddSubSwitch         
           参数值  =  1 
   软件参数默认值  =  1 
   (结果个数 = 1)  

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义参见表1。

| 输出项名称   | 输出项解释                                                                                                                                           |
|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------|
| 参数名     | 用于返回查询出的PGW软参名。                                                                                                                                 |
| 参数值     | 用于返回查询出的PGW软参值。  说明： 详细信息请参考产品手册的“参考 > PGW Web LMT用户数据和全局数据管理 > PGW Web LMT命令 > 全局数据命令组 > 系统参数管理 > 设置系统参数（LST PSYSPARA）”中“参数说明”列描述的取值范围、取值功能。   |
| 软件参数默认值 | 用于返回查询出的PGW软参默认值。  说明： 详细信息请参考产品手册的“参考 > PGW Web LMT用户数据和全局数据管理 > PGW Web LMT命令 > 全局数据命令组 > 系统参数管理 > 设置系统参数（LST PSYSPARA）”中“参数说明”列描述的取值范围、取值功能。 |
