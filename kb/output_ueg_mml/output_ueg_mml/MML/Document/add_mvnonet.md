# 增加MVNO网络配置信息(ADD MVNONET)

#### 命令功能

**适用网元：SGSN、MME**

此命令用于增加MVNO的网络配置。UNC根据MVNOMCC、MVNOMNC、MATCHIMSI这三个参数及用户的IMSI，判断用户的归属MVNO，为用户提供所属MVNO的服务。

#### 注意事项

- 此命令最大记录数为2048条。
- 此命令执行后立即生效。
- 若MCC相同，MNC有效长度为2和3位的MNC前两位不允许相同。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                             |
|:----------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MVNOMCC   | MVNO移动国家码  | 可选必选说明：必选参数 参数含义：该参数用于指定MVNO用户的IMSI的移动国家代码。 数据来源：整网规划 取值范围：3位十进制数字 默认值：无 配置原则： “MVNO移动国家码”　+ “MVNO移动网号”　+ “ 匹配IMSI”在CONNECTPLMN和本表唯一，“匹配IMSI”为空时，“MVNO移动国家码”　+ “MVNO移动网号”在HPLMN、CONNECTPLMN和本表唯一，参见ADD HPLMN和ADD CONNECTPLMN。                                                                                                                                                                                    |
| MVNOMNC   | MVNO移动网号   | 可选必选说明：必选参数 参数含义：该参数用于指定MVNO用户的IMSI的移动网号。 数据来源：整网规划 取值范围：位数为2或3的十进制数字 默认值：无 配置原则： “MVNO移动国家码”　+ “MVNO移动网号”　+ “ 匹配IMSI”在CONNECTPLMN和本表唯一，“匹配IMSI”为空时，“MVNO移动国家码”　+ “MVNO移动网号”在HPLMN、CONNECTPLMN和本表唯一，参见ADD HPLMN和ADD CONNECTPLMN。                                                                                                                                                                                 |
| MATCHIMSI | 匹配IMSI     | 可选必选说明：可选参数 参数含义：该参数用于指定MVNO用户除了MCC和MNC外的IMSI的字段。 数据来源：整网规划 取值范围：长度不超过10的十进制数字 默认值：无 配置原则： “MVNO移动国家码”　+ “MVNO移动网号”　+ “ 匹配IMSI”在HPLMN、CONNECTPLMN和本表唯一，参见ADD HPLMN和ADD CONNECTPLMN。由于MCC　+　MNC　+　MATCHIMSI组成IMSI号段，因此，它们的长度之和不能大于IMSI的编码长度（15）。                                                                                                                                                                  |
| MVNOCC    | MVNO 国家码   | 可选必选说明：必选参数 参数含义：该参数用于指定MVNO的国家码。 数据来源：整网规划 取值范围：长度不超过6的十进制数字 默认值：无  说明： 当MVNO用户发起短消息流程时使用。                                                                                                                                                                                                                                                                                                                      |
| MVNOID    | MVNO标识     | 可选必选说明：必选参数 参数含义：该参数用于根据MVNO标识增加这个MVNO的网络配置。 前提条件：“MVNO标识”已经增加，参见ADD MVNO。 数据来源：整网规划 取值范围：1～64 默认值：无                                                                                                                                                                                                                                                                                                             |
| EMCBS     | 是否允许紧急呼叫业务 | 可选必选说明：可选参数 参数含义：该参数用于指定是否允许使用紧急呼叫业务。 数据来源：整网规划 取值范围：“NO(不允许)”“YES(允许)” 默认值：“YES(允许)” 配置原则：如果不支持VOLTE紧急呼叫业务，期望在CS域做紧急呼叫时，建议配置为“NO（不允许）”                                                                                                                                                                                                                                                                          |
| EMGCNUMSW | 紧急号码下发开关   | 可选必选说明：可选参数 参数含义：该参数用来控制系统在给指定MVNO用户发送Attach Accept、TAU Accept、RAU Accept消息时，是否将紧急号码携带在消息中发送给UE。 数据来源：整网规划 取值范围：“ON(开启)”“OFF(关闭)” 默认值：“ON(开启)” 配置原则：当本参数设置为“ON(开启)”时，系统将在Attach Accept、TAU Accept、RAU Accept消息中给指定MVNO用户发送紧急号码列表。其中，紧急号码列表来源于ADD EMGCNUM中的配置，如果ADD EMGCNUM没有配置，则不下发紧急号码。  说明： 紧急号码下发还受其它配置（SET MMFUNC中EMNUM参数、DWORD_EX6 BIT10、DWORD_EX6 BIT11、DWORD_EX33 BIT13、DWORD_EX33 BIT12）控制，共同决策是否下发紧急号码。 |

#### 使用实例

增加MVNO标识为1的MVNO的网络资源：

ADD MVNONET: MVNOMCC="460", MVNOMNC="00", MATCHIMSI="111", MVNOCC="860", MVNOID=1, EMCBS=YES;
