# 删除NGAP本端实体（RMV NGAPLE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

执行此命令，会导致NG-RAN链路异常，影响用户业务。

**适用NF：AMF**

该命令用于删除NGAP本端实体和SCTP本端实体的关联关系。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称       | 参数说明                                                                                                       |
|:----------|:-----------|:-----------------------------------------------------------------------------------------------------------|
| NGAPLEIDX | NGAP本端实体索引 | 可选必选说明：必选参数  参数含义：该参数用于指定NGAP本端实体的索引，该索引作为NGAP本端实体的唯一标识。  数据来源：本端规划  取值范围：整数类型，取值范围是0~1023。  默认值：无  配置原则：无 |

## 使用实例

删除本端实体标识为0的NGAP本端实体，执行如下命令：

```
RMV NGAPLE: NGAPLEIDX=0;
```
