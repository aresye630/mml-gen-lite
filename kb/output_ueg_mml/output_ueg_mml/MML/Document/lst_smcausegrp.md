# 查询SM原因值映射组配置（LST SMCAUSEGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF、PGW-C、SGW-C、GGSN**

该命令用于查询原因值映射组配置记录。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                            |
|:-----------|:-------|:------------------------------------------------------------------------------------------------|
| CAUSEGRPID | 原因值组标识 | 可选必选说明：可选参数  参数含义：该参数用于指定表示一个原因值映射规则集合的唯一数字ID。  数据来源：全网规划  取值范围：整数类型，取值范围是1~127。  默认值：无  配置原则：无 |

## 使用实例

查询原因值映射组配置：参数原因值组标识设置为126。
LST SMCAUSEGRP: CAUSEGRPID=126;

```
%%LST SMCAUSEGRP: CAUSEGRPID=126;%%
RETCODE = 0  操作成功。

输出结果如下
--------------
原因值组标识  =  126
原因值组名称  =  aaa
（结果个数 = 1）

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                        |
|:--------|:-----------------------------|
| 原因值组标识  | 该参数用于指定表示一个原因值映射规则集合的唯一数字ID。 |
| 原因值组名称  | 该参数用于指定当前CAUSEGRPID对应的字符名称。  |
