# 删除UPF地址属性（RMV UPFADDRATTR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

删除该配置可能会导致UPG热备特性和双UPG故障bypass功能失效。

**适用NF：SMF**

该命令用于删除UPF地址属性。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                              |
|:-------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCEID | NF实例标识 | 可选必选说明：必选参数  参数含义：该参数用于指定NF实例标识。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~36。  默认值：无  配置原则：  该取值必须和ADD PNFPROFILE中配置的“NFINSTANCEID”参数取值相同。 |

## 使用实例

以下命令用于删除实例名称为upf1的UPF地址属性。

```
RMV UPFADDRATTR: NFINSTANCEID="upf1";
```
