# 增加PCRF容灾PCRF实体(ADD RPCRF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条容灾PCRF实体数据记录。

对于主用PCRF来说，备用PCRF为其RPCRF，对于备用PCRF来说，主用PCRF为其RPCRF。

在主用PCRF和备用PCRF都需要配置ADD RPCRF，用于标识对应的备用PCRF。

## 注意事项

在会话备份和恢复功能启用时需要配置。

## 参数说明

| 参数标识    | 参数名称              | 参数说明                                                                                                                                                                                                            |
|:--------|:------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PCRFID  | 本端PCRF标识          | 用于标识PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围：1 默认值：无。                                                                                                                                                         |
| RPCRFID | 容灾PCRF标识          | 用于标识容灾PCRF实体。 取值范围：0～5  说明： 在（N+1）*FE容灾主备组网时，备用PCRF最大支持6个远端主用PCRF配置，其他组网情况只配置一个容灾PCRF。 默认值：无。                                                                                                                   |
| PN      | 对端名称              | 用于标识容灾PCRF实体的名称。其值域类型为字符串，区分大小写。 取值范围：长度不超过128的字符串 获取源：在备用PCRF上执行LST PCRF命令可以获取该值。 默认值：无。                                                                                                                       |
| DN      | 对端域名              | 用于标识容灾PCRF实体的域名。 该参数配置原则：该参数需要PCRF与容灾PCRF协商一致。该参数的取值不区分大小写，建议使用小写。若使用大写输入，系统会默认以小写的方式进行处理。 取值范围：长度不超过64的字符串 获取源：在备用PCRF上执行LST PCRF命令可以获取该值。 默认值：无。                                                              |
| HN      | 对端主机名             | 用于标识容灾PCRF实体的主机名。 该参数配置原则：该参数全网唯一，由运营商统一规划。该参数需要PCRF与容灾PCRF协商一致。该参数的取值不区分大小写，建议使用小写。若使用大写输入，系统会默认以小写的方式进行处理。 取值范围：长度不超过127的字符串 获取源：在备用PCRF上执行LST PCRF命令可以获取该值。 默认值：无。                                           |
| WMODE   | 工作模式              | 用于定义本地PCRF实体在传输层是作为客户端还是服务端。 取值范围： CLIENT(客户端)SERVER(服务端)  说明： 在Active局点，建议“工作模式”配置为“SERVER”；在Standby局点，建议“工作模式”配置为“CLIENT”。 默认值：CLIENT(客户端)                                                                    |
| RTYPE   | 容灾类型              | 用于定义容灾组网类型。 各参数选项的含义是： Active_Standby(1+1主备组网)：一个容灾PCRF与一个主用PCRF连接部署。N.Active_1.Standby(N+1主备组网)：一个容灾PCRF与多个主用PCRF连接部署。 默认值：Active_Standby(1+1主备组网)                                                             |
| LSTATUS | 本地PCRF容灾状态        | 用于定义本地PCRF网元的容灾角色。 该参数配置原则：当存在多个RPCRF时，LSTATUS必须相同。 各参数选项的含义是： Active(主用)：表示本地PCRF是主用PCRF。Standby(备用)：表示本地PCRF是容灾PCRF。 默认值：无。                                                                                   |
| SKA     | 业务保活时长（s）         | PCRF与RPCRF对接的参数之一，用于定义业务保活时间，当链路不可用时，在业务保活时间内，业务是不会释放的。 单位：秒。 取值范围：0～3600 默认值：90  说明： 若软参“VRM_SESSIONBACKUPSWITCH”取值为非0，则该参数不生效。                                                                                |
| RLOCID  | 容灾PCRF Location标识 | 表示容灾PCRF的Location ID。 参数配置原则：可选参数，该参数用于PCRF容灾组网场景下，会话备份功能打开（即VRM_SESSIONBACKUPSWITCH软参值为“3”），且用户定时器持久化功能打开（即VRM_SYNTIMER软参值为“1”）时，才需要配置。 取值范围：0～65535 默认值：65535  说明： 当该参数取默认值65535时，系统认为“容灾PCRF Location标识”未定义。 |

## 使用实例

增加PCRF容灾PCRF实体。“本端PCRF标识”为“1”，“容灾PCRF标识”为“0”，“对端名称”为“RPCRF”，“对端域名”为“huawei.com”，“对端主机名”为“pcrf\_rz.huawei.com”，“工作模式”为“SERVER”，“本地PCRF容灾状态”为“ACTIVE”，其他参数均使用默认值。

```
ADD RPCRF: PCRFID=1, RPCRFID=0, PN="RPCRF", DN="huawei.com", HN="pcrf_rz.huawei.com", WMODE=SERVER, LSTATUS=ACTIVE;
```
