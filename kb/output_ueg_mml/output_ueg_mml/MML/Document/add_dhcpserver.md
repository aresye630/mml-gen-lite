# 增加DHCP服务器（ADD DHCPSERVER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于配置DHCP服务器的IP地址。

## 注意事项

- 该命令执行后立即生效。

- 执行该命令之前，需要先执行ADD DHCPSERVERGRP创建DHCP服务器组。
- 一个DHCP服务器组包含两个DHCP服务器，一主一备。配置的时候必须先配主DHCP服务器，后配备DHCP服务器。

- 最多可输入2000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称          | 参数说明                                                                                                                                                                                |
|:------------|:--------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GROUPNAME   | DHCP服务器组名称    | 可选必选说明：必选参数  参数含义：该参数指定DHCP服务器组名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。不支持空格，不区分大小写。  默认值：无  配置原则：  该参数使用ADD DHCPSERVERGRP命令配置生成。                                                    |
| ISPRIMARY   | 是否是主DHCP服务器   | 可选必选说明：必选参数  参数含义：该参数指定是否为主DHCP服务器。  数据来源：本端规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无  配置原则：无                                                                                          |
| IPVERSION   | IP地址类型        | 可选必选说明：必选参数  参数含义：该参数指定DHCP服务器的IP地址类型。  数据来源：本端规划 取值范围： IPV4（IPv4地址类型）IPV6（IPv6地址类型）  默认值：无  配置原则：无                                                                                 |
| V4IPADDRESS | DHCPv4服务器IP地址 | 可选必选说明：该参数在"IPVERSION"配置为"IPV4"时为条件必选参数。  参数含义：该参数指定DHCP服务器的IPv4地址。  数据来源：本端规划  取值范围：IPv4地址类型。  默认值：无  配置原则：  同一个服务器组下的主、备服务器IPv4地址不能相同。                                            |
| V6IPADDRESS | DHCPv6服务器IP地址 | 可选必选说明：该参数在"IPVERSION"配置为"IPV6"时为条件必选参数。  参数含义：该参数指定DHCP服务器的IPv6地址。  数据来源：本端规划  取值范围：IPv6地址类型。除了组播地址、链路本地地址、环回地址或未指定的地址为非法地址外，其他都为合法地址。  默认值：无  配置原则：  同一个服务器组下的主、备服务器IPv6子网前缀不能相同。 |
| WALVALUE    | WAL值          | 可选必选说明：可选参数  参数含义：该参数表示整机（UNC）每秒发送给该DHCP服务器的最大消息数。  数据来源：本端规划  取值范围：整数类型，取值范围是0~65535。  默认值：无  配置原则：  缺省为0，表示不控制消息数。                                                                |

## 使用实例

当需要为DHCP服务器组group1添加主DHCP服务器，配置其IP地址为10.1.1.1时，使用该命令：

```
ADD DHCPSERVER:GROUPNAME="group1",ISPRIMARY=ENABLE,IPVERSION=IPV4,V4IPADDRESS="10.1.1.1";
```
