# 查询NLF设备地址(LST NLFDEVADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询NLF设备地址信息。

- 如果需要查询全部NLF设备地址信息，请不要输入任何参数。
- 如果需要查询指定NLF设备地址信息，请输入“设备地址标识”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                     |
|:------------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------|
| DEVAID      | 设备地址标识    | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个设备地址标识来查询NLF设备地址信息；若不输入，则表示所有的设备地址标识。 取值范围：0～7 默认值：无。 配置原则：无。                                               |
| REUSE       | 复用        | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪种复用来查询NLF设备地址信息；若不输入，则表示所有的复用方式。 取值范围： YES(YES)NO(NO) 默认值：无。 配置原则：无。                                         |
| VPNNAME     | VPN名称     | 可选必选说明：当参数“REUSE”取值为“NO(NO)”时，该参数可见，且参数为可选。 参数含义：用于指示系统需要按照哪个VPN名称来查询NLF设备地址信息；若不输入，则表示所有的VPN名称。 取值范围：长度不超过31的字符串 默认值：无。 配置原则：无。         |
| IPVER       | IP版本      | 可选必选说明：当参数“REUSE”取值为“NO(NO)”时，该参数可见，且参数为可选。 参数含义：用于指示系统需要按照哪个IP版本来查询NLF设备地址信息；若不输入，则表示所有的IP版本。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。 |
| IP          | IPV4地址    | 可选必选说明：可选参数 参数含义：当“IP版本”选择“IPV4(IPV4)”时该参数可配置。用于指示系统需要按照哪个IPV4地址来查询NLF设备地址信息；若不输入，则表示所有的IPV4地址。 取值范围：IPv4地址 默认值：无。 配置原则：无。               |
| IPV6        | IPV6地址    | 可选必选说明：可选参数 参数含义：当“IP版本”选择“IPV6(IPV6)”时该参数可配置。用于指示系统需要按照哪个IPV6地址来查询NLF设备地址信息；若不输入，则表示所有的IPV6地址。 取值范围：IPv6地址 默认值：无。 配置原则：无。               |
| PMSDEVAID   | PMS设备地址标识 | 可选必选说明：当参数“REUSE”取值为“YES(YES)”时，该参数可见，且参数为可选。 参数含义：用于指示系统需要按照哪个PMS设备地址标识来查询NLF设备地址信息；若不输入，则表示所有的PMS设备地址标识。 取值范围：0~31 默认值：无。 配置原则：无。      |
| DESCRIPTION | 描述        | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个描述来查询NLF设备地址信息；若不输入，则表示所有的描述。 取值范围：长度不超过32的字符串 默认值：无。 配置原则：无。                                               |

## 使用实例

1. 查询所有的NLF设备地址的配置信息。

   ```
   LST NLFDEVADDR:;
   ```

   ```
   %%LST NLFDEVADDR:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   设备地址标识  复用    PMS设备地址标识   VPN名称  IP版本  IPV4地址      IPV6地址                                 描述      

   1             YES     2                 NULL     NULL    NULL          NULL                                     开启复用  
   2             NO      NULL              VPN02    IPV6    NULL          2001:0db8:3fff:ffff:ffff:ffff:ffff:ffff  NLF_IPV6  
   (结果个数 = 2)

   ---    END
   ```
2. 查询非复用的NLF设备地址的配置信息，“复用”为“NO(NO)”。

   ```
   LST NLFDEVADDR: REUSE=NO;
   ```

   ```
   %%LST NLFDEVADDR: REUSE=NO;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
      设备地址标识  =  2
              复用  =  NO
   PMS设备地址标识  =  NULL
           VPN名称  =  VPN01
            IP版本  =  IPV4
          IPV4地址  =  10.168.0.130
          IPV6地址  =  NULL
              描述  =  NLF_IPV4
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见ADD NLFDEVADDR命令的参数说明。
