# 删除位置区列表(RMV VLROFFLOADLAILST)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

本命令用于删除指定的LAI。

#### 注意事项

- 该命令执行后立即生效。
- 若未输入参数，表示删除所有记录。
- 如果在对4G用户执行IMSI分离操作任务期间（可通过**DSP VLROFFLOADBYLAI**查询）执行本命令，系统仍然会对已删除的LAI对应TAI下联合附着的4G用户执行IMSI分离操作，直到当前任务结束。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                  |
|:-------|:-------|:----------------------------------------------------------------------|
| LAI    | LAI    | 可选必选说明：可选参数 参数含义：该参数用于指定位置区标识，标识一个位置区。 数据来源：整网规划 取值范围：9～10位的字符串 默认值：无 |

#### 使用实例

1. 从LAI列表中删除一个LAI，LAI的值为“308010001”：

   `RMV VLROFFLOADLAILST: LAI="308010001";`
2. 从LAI列表中删除所有LAI：

   `RMV VLROFFLOADLAILST:;`
