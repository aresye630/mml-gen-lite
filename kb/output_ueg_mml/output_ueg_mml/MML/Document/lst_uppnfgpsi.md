# 查询对端NF的GPSI信息（LST UPPNFGPSI）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询本地配置的对端NF实例支持的GPSI信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                 |
|:-------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INDEX        | 索引     | 可选必选说明：可选参数 参数含义：该参数用于指定GPSI的索引。 数据来源：本端规划 取值范围：整数类型，取值范围是0~65535。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                      |
| NFINSTANCEID | NF实例标识 | 可选必选说明：可选参数 参数含义：该参数用于指定GPSI对应的NF实例标识。 数据来源：全网规划 取值范围：NfInstanceId参数建议满足以下约束规则： 1.如果输入为uuid格式（格式例如：a6a61c6f-0d3a-4221-b1da-424eda3ccf67）只能为A-F、a-f、0-9的字符。 2.如果输入不为uuid格式，长度不能超过18且不允许输入只包含0-9和“.”的字符串，例如：1.2.3.4、不允许输入只包含十六进制数（A-F、a-f、0-9）和“:”的字符串，例如：1::2、FBFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF。 默认值：无 配置原则：本参数取值与ADD UPPNFPROFILE命令中的“NF实例标识”参数取值保持一致时，关联关系生效。 |

#### 使用实例

查询对端NF实例标识为udm\_instance\_0所支持的GPSI信息：

```
LST UPPNFGPSI: NFINSTANCEID="udm_instance_0";
```
