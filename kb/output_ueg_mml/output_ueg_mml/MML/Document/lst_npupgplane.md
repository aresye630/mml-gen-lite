# 查询NP升级平面（LST NPUPGPLANE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询NP升级平面。

#### 注意事项

- 该命令执行后立即生效。
- 该命令仅适用于NP卡省交换组网模式。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无

#### 使用实例

查询NP升级平面：

```
%%LST NPUPGPLANE:;%%
RETCODE = 0  操作成功

结果如下
--------
RU编号  平面编号  

66      plane_1   
87      plane_2   
(结果个数 = 2)

---    END
```

#### 输出结果说明

参见**ADD NPUPGPLANE**的参数说明。
