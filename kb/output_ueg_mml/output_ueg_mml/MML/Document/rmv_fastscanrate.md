# 删除快速扫描任务（RMV FASTSCANRATE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、SGW-C、PGW-C、GGSN**

该命令用于删除快速扫描任务。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                          |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------|
| TASKTYPE | 扫描任务类型 | 可选必选说明：必选参数  参数含义：该参数用于指定扫描任务的类型。  数据来源：本端规划 取值范围： UPF_DEACTIVE（UPF去活扫描任务）SBC_FAULT（SBC故障扫描任务）  默认值：无  配置原则：无 |

## 使用实例

删除扫描任务类型为UPF\_DEACTIVE的快速扫描任务：

```
RMV FASTSCANRATE: TASKTYPE=UPF_DEACTIVE;
```
