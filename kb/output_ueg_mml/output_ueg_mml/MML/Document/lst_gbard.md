#### 命令功能

**适用网元：SGSN**

该命令用于查询Gb模式接入限制记录。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                  |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：可选参数 参数含义：待查询记录的用户范围。 取值范围：“ALL_USER(所有用户)”：表示该指定用户范围为所有用户。“SPECIAL_IMSIPRE(指定IMSI前缀)”：表示该用户范围为指定IMSI前缀。“SPECIAL_IMSI_RANGE(指定IMSI范围)”：表示该用户范围为指定IMSI范围。 默认值：无 |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件可选参数 参数含义：该参数用于指定用户的IMSI前缀的信息。使用时按照IMSI完全匹配进行查询。 前提条件：该参数在“SUBRANGE(用户范围)”设置为“SPECIAL_IMSIPRE(指定IMSI前缀)”时生效。 取值范围：1～15位数字 默认值：无                              |
| IMSI     | IMSI   | 可选必选说明：条件可选参数 参数含义：该参数用于查询指定用户的IMSI。 前提条件：该参数在“SUBRANGE(用户范围)”设置为“SPECIAL_IMSI_RANGE(指定IMSI范围)”时生效。 取值范围：1～15位数字 默认值：无                                                |

#### 使用实例

1. 查询所有Gb模式接入限制参数记录：

   LST GBARD:;

   ```
   %%LST GBARD:;%%
   RETCODE = 0  操作成功。

   查询结果如下
   --------------
    用户范围      起始IMSI  终止IMSI  APNNI        卡类型            启用签约ARD  控制类型  原因值           自定义原因值

    指定IMSI范围  12301     12305     HUAWEI1.COM  SIM & USIM          是           拒绝      自定义            1
    所有用户      NULL      NULL      *            NULL                否           拒绝      自定义            2
    指定IMSI范围  111       222       *            NULL                否           允许      本地无合适小区    NULL
   (结果个数 = 3)

   ---    END
   ```
2. 查询用户范围为ALL\_USER的Gb模式接入限制参数记录：

   LST GBARD: SUBRANGE=ALL\_USER;

   ```
   %%LST GBARD: SUBRANGE=ALL_USER;%%
   RETCODE = 0  操作成功。

   查询结果如下
   --------------
       用户范围  =  所有用户
          APNNI  =  *
         卡类型  =  NULL
    启用签约ARD  =  否
       控制类型  =  拒绝
         原因值  =  自定义
   自定义原因值  =  2
   (结果个数 = 1)

   ---    END
   ```
