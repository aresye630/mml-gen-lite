# 增加手工流控策略（ADD HTTPFCPOL）

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在UDM上配置HTTP手工流控策略。操作员可以根据消息来源（对端IP）和消息类型使用本命令设置手工流控策略，控制UDM在单位时间内处理的最大消息量，保证模块的稳定运行。

## 注意事项

- 执行该命令配置手工流控策略，最多可配置128条记录。
- HTTP手工流控优先于自动流控，当手工流控放行的消息达到自动流控起控阈值时，启动微服务自动流控功能。
- 系统初始化时会在数据库中增加如下两条手工流控策略数据记录，可以通过执行**LST HTTPFCPOL**命令查询。不允许重复增加默认的流控策略数据记录，否则系统会报错。

  ```
  ADD HTTPFCPOL: POFCNM="DefaultPol-IWF", FCMODE=ACTIVE, FCTYPE=IWFFC, FCREQRATE=13000, BURSTREQNUM=1000, FCTPLID="DefaultFCTPL";
  ADD HTTPFCPOL: POFCNM="DefaultPol-UDM", FCMODE=ACTIVE, FCTYPE=UDMFC, FCREQRATE=17000, BURSTREQNUM=1000, FCTPLID="DefaultFCTPL";
  ```
- 该命令不支持GBA（Generic Bootstrapping Architecture）场景。

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                      |
|:------------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| POFCNM      | 策略名称     | 可选必选说明：必选参数 参数含义：该参数标识手工流控策略名称。 取值范围：长度不超过32位的字符串，只允许输入：0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                               |
| FCMODE      | 流控开关     | 可选必选说明：必选参数 参数含义：该参数标识是否激活本条手工流控功能。 取值范围： ACTIVE(激活)DEACTIVE(去激活) 默认值：DEACTIVE(去激活) 配置原则：无。                                                                                                                                                                                                                                               |
| FCTYPE      | 流控类型     | 可选必选说明：必选参数 参数含义：该参数标识流控类型。 取值范围： IPFC(IP手工流控)：表示按照对端IP对HLB模块上的消息进行手工流控。GLFC(全局手工流控)：表示对HLB模块上的所有请求消息进行手工流控。UDMFC(UDM业务手工流控)：表示当SET UDMMETYPE命令“网元类型”参数为“UDM(UDM)”时，对UdmSubService和AuthService服务上的所有请求消息进行手工流控。IWFFC(IWF业务手工流控)：表示当SET UDMMETYPE命令“网元类型”参数为“UDM-IWF(UDM-IWF)”时，对UdmSubService和AuthService服务上的所有请求消息进行手工流控。 默认值：无。 配置原则：无。 |
| IPVER       | IP地址类型   | 可选必选说明：可选参数 参数含义：该参数标识需要流控的对端IP地址类型。 取值范围： IPV4(IPV4地址)：IPv4地址IPV6(IPV6地址)：IPv6地址 默认值：无。 配置原则：当“流控类型”参数取值为“IPFC(IP手工流控)”时该参数生效。                                                                                                                                                                                                           |
| PEIPV4      | 对端IPV4地址 | 可选必选说明：可选参数 参数含义：该参数标识对端IPv4地址。 取值范围：IPv4地址 默认值：无。 配置原则：当“IP地址类型”参数取值为“IPV4(IPV4地址)”时该参数生效。                                                                                                                                                                                                                                               |
| PEIPV6      | 对端IPV6地址 | 可选必选说明：可选参数 参数含义：该参数标识对端IPv6地址。 取值范围：IPv6地址 默认值：无。 配置原则：当“IP地址类型”参数取值为“IPV6(IPV6地址)”时该参数生效。                                                                                                                                                                                                                                               |
| FCREQRATE   | 流控速率     | 可选必选说明：必选参数 参数含义：该参数标识单个模块单位时间内的最大消息量，当UDM接收到的请求消息速率超过该值时，启动手工流控功能。 取值范围：0~65535，单位：条/s 默认值：无。 配置原则：该参数取值为“0”时，表示不启动手工流控。                                                                                                                                                                                                                 |
| BURSTREQNUM | 突发请求数    | 可选必选说明：可选参数 参数含义：该参数标识突发请求消息数。UDM接收到的HTTP请求消息速率超过“流控速率”参数值后，不会立即丢弃消息，当继续处理的消息数量达到该参数配置的值时，开始丢弃消息。 取值范围：0~2000 默认值：500 配置原则：无。                                                                                                                                                                                                             |
| FCTPLID     | 流控模板标识   | 可选必选说明：可选参数 参数含义：该参数标识手工流控模板号，当存在手工流控模板时，UDM按照配置的单个手工流控模板策略流控消息。该参数仅在ADD HTTPFCTPL命令定义后在才能在此处引用。 取值范围：长度不超过32位的字符串，只允许输入：0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。                                                                                                                                                                              |

## 使用实例

1. 在配置HTTP手工流控时，增加“流控类型”为“IPFC(IP手工流控)”的HTTP手工流控策略，其中“策略名称”为“AAA\_01”，“流控开关”为“ACTIVE(激活)”，“IP地址类型”为“IPV4(IPV4地址)”，“对端IPV4地址”为“172.16.0.1”，“流控速率”为“30000”:

   ```
   ADD HTTPFCPOL: POFCNM="AAA_01", FCMODE=ACTIVE, FCTYPE=IPFC, IPVER=IPV4, PEIPV4="172.16.0.1", FCREQRATE=30000;
   ```
2. 在配置HTTP手工流控时，增加“流控类型”为“GLFC(全局手工流控)”的HTTP手工流控策略，其中“策略名称”为“AAA\_03”，“流控开关”为“ACTIVE(激活)”，“流控速率”为“6000”，“突发请求数”为“600”：

   ```
   ADD HTTPFCPOL: POFCNM="AAA_03", FCMODE=ACTIVE, FCTYPE=GLFC, FCREQRATE=6000, BURSTREQNUM=600;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如下表所示。

|    错误码 | 错误码解释            | 原因分析                | 处理建议                                                                       |
|-------:|:-----------------|:--------------------|:---------------------------------------------------------------------------|
| 360135 | 无效策略模板ID         | 引用的流控模板标识ID不存在。     | 执行LST HTTPFCTPL命令查询已配置的“流控模板标识”参数，输入正确的策略模板ID后重新执行本命令进行配置。                 |
| 360136 | 相同IP的策略已经设置，无需重复 | 对端IP已经配置。           | 执行LST HTTPFCPOL命令查询已配置的对端IP地址，输入新的IP地址后执行本命令进行配置。                          |
| 360137 | 全局策略已经配置，无需重复    | 已配置一条全局手工流控策略。      | 如需重新配置，请执行LST HTTPFCPOL命令查询已配置的全局手工流控“策略名称”，然后执行MOD HTTPFCPOL命令修改全局手工流控策略。 |
| 360171 | 默认的流控策略不允许重复添加   | 不允许重复增加默认的流控策略数据记录。 | 系统初始化时会在数据库中增加两条手工流控策略数据记录，详细请参见本命令的注意事项。                                  |
