## 命令功能

**须知** 

该命令属于高危命令，如果访问模式设置不合理，将导致FE访问BE业务失败。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置DBS访问BE的模式。

该命令的使用场景：

- 在非冷备FE局点下，DBS需要按照远端location的优先级访问非冷备的BE局点。
- 在第三DC的冷备UDM局点下，在接管状态下DBS需要访问指定远端location的冷备BE局点。在非接管状态下，DBS不需要访问冷备的BE局点，DBS收到DCI请求需要返回BE全故障错误给FE。FE能够根据错误进行区分处理，避免FE微服务因一直加载不到数据而不停自愈重启。

## 注意事项

通过**ADD DBSRLOCATION**命令配置远端Location后，才能通过该命令设置DBS访问指定Location的BE的模式。

## 参数说明

| 参数标识   | 参数名称         | 参数说明                                                                                                                                                                                                                                  |
|:-------|:-------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MODE   | 访问模式         | 可选必选说明：必选参数 参数含义：用于指定DBS访问BE的模式。 取值范围： PRIORITY(按DBSRLOCATION的优先级访问BE)：DBS按照远端Location的优先级访问非冷备的BE。ASSIGN(指定访问Location的BE)：DBS访问指定远端Location的冷备的BE。NONE(不访问BE)：非接管状态，DBS不访问冷备的BE。 默认值：PRIORITY(按DBSRLOCATION的优先级访问BE)。 配置原则：无。        |
| RLOCID | 远端Location标识 | 可选必选说明：必选参数 参数含义：用于指定DBS访问的目标远端LocationID。 取值范围：0～512。 默认值：0 配置原则： 当参数“访问模式”需要设置为“PRIORITY(按DBSRLOCATION的优先级访问BE)”或“NONE(不访问BE)”时，该参数需要取值为“0”。当参数“访问模式”需要设置为“ASSIGN(指定访问Location的BE)”时，可以通过LST DBSRLOCATION命令查看要访问的BE的“远端Location标识”。 |

## 使用实例

- 设置DBS按照远端Location的优先级访问非冷备的BE。

  ```
  SET DBSACCESSMODE: MODE=PRIORITY, RLOCID=0;
  ```
- 设置DBS强制访问81号远端Location的冷备BE。

  ```
  SET DBSACCESSMODE: MODE=ASSIGN, RLOCID=81;
  ```
- 设置非接管状态时，DBS不访问冷备的BE。

  ```
  SET DBSACCESSMODE: MODE=NONE, RLOCID=0;
  ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                 | 原因分析                                                                               | 处理建议                                                                                           |
|-------:|:--------------------------------------|:-----------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------|
| 302003 | 远端location不存在。                        | 输入的“远端Location标识”不存在。                                                              | 执行ADD DBSRLOCATION命令，添加远端USCDB网元定义的“远端Location标识”后，重新执行本命令。                                    |
| 385009 | 参数MODE取值为PRIORITY或NONE时，RLOCID必须设置为0。 | 参数“访问模式”取值为“为PRIORITY(按DBSRLOCATION的优先级访问BE)”或“NONE(不访问BE)”时，“远端Location标识”取值非“0”。 | 参数“访问模式”需要设置为“PRIORITY(按DBSRLOCATION的优先级访问BE)”或“NONE(不访问BE)”时，“远端Location标识”需要取值为“0”，再重新执行本命令。 |
