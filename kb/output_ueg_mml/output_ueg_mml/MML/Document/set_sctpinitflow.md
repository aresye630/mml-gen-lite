# 设置SCTP接入流控(SET SCTPINITFLOW)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MME、AMF**

该命令用于设置系统中SCTP接入流控参数。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug;system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                 |
|:-------|:---------|:---------------------------------------------------------------------------------------------------------------------|
| SWITCH | 流控开关     | 可选必选说明：可选参数 参数含义：该参数用于指定是否开启S1和N2接口SCTP接入流控“固定速率流控”功能。 数据来源：整网规划 取值范围： ON（开启）OFF（关闭） 系统初始设置值：ON（开启）                  |
| CTHD   | S1固定流控速率 | 可选必选说明：可选参数 参数含义：该参数用于指定在开启S1和N2接口SCTP接入流控功能后，接入4G基站时整系统每秒SCTP建链数量。 数据来源：整网规划 取值范围：整数类型，取值范围为1~1000000。 系统初始设置值：2000 |
| CTHDN2 | N2固定流控速率 | 可选必选说明：可选参数 参数含义：该参数用于指定在开启S1和N2接口SCTP接入流控功能后，接入5G基站时整系统每秒SCTP建链数量。 数据来源：整网规划 取值范围：整数类型，取值范围为1~1000000。 系统初始设置值：2000 |

#### 使用实例

设置SCTP接入流控参数，指定流控开关为开启，S1固定流控速率为2000，N2固定流控速率为2000：

```
SET SCTPINITFLOW: SWITCH=ON, CTHD=2000, CTHDN2=2000;
```
