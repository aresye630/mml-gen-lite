# 设置DLB服务SCTP参数配置信息(SET DLBSCTPPARA)

- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致业务异常，需联系华为技术支持确认后再执行。

此命令参数修改后对于已经激活的SCTP链路需要断链重新连接。通过**MOD PPCEFL/MOD PAFL/MOD POCSL/MOD RPCRFL/MOD PEERL**将参数ADSTS去使能断链，然后再使能重新建链。该命令用于设置SCTP协议报文重发间隔初始值、报文重发间隔最小值等。

**说明** 

本命令执行时不允许设置参数“CONGESTIONFLAG”=“TRUE”，如若为“TRUE”时，对系统性能影响较大。

## 注意事项

“SET DLBSCTPPARA”中的参数修改后对于已经激活的SCTP链路需要断链重新连接。

## 参数说明

| 参数标识           | 参数名称       | 参数说明                                                                                                                                                                          |
|:---------------|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ID             | ID         | 可选必选说明：必选参数 参数含义：唯一标识。 取值范围：1 默认值：无。 配置原则：无。                                                                                                                                  |
| RTOINIT        | 报文重发间隔初始值  | 可选必选说明：可选参数 参数含义：该参数用于指定RTO（Retransmission Time-Out，重传超时时间）初始时长。 取值范围：100~10000 单位：毫秒 默认值：无。 系统初始设置值：200 配置原则：RTO最小值应小于RTO最大值。RTO初始值应大于或等于RTO最小值，且小于或等于RTO最大值。                |
| RTOMIN         | 报文重发间隔最小值  | 可选必选说明：可选参数 参数含义：该参数用于指定RTO最小时长。 取值范围：100~10000 单位：毫秒 默认值：无。 系统初始设置值：200 配置原则：RTO最小值应小于RTO最大值。RTO初始值应大于或等于RTO最小值，且小于或等于RTO最大值。                                                |
| RTOMAX         | 报文重发间隔最大值  | 可选必选说明：可选参数 参数含义：该参数用于指定RTO最大时长。 取值范围：100~10000 单位：毫秒 默认值：无。 系统初始设置值：1000 配置原则：RTO最小值应小于RTO最大值。RTO初始值应大于或等于RTO最小值，且小于或等于RTO最大值。                                               |
| MAXARETR       | 偶联最大重传次数   | 可选必选说明：可选参数 参数含义：该参数用于指定偶联可承受的最大重传次数。对于一个指定的偶联，如果重传的次数超过这个值，则删除偶联，并发送ABORT到对端，并向上层报告状态变为DOWN。 取值范围：3~10 单位：次 默认值：无。 系统初始设置值：10 配置原则：该值必须大于或等于路径最大重传次数。                        |
| MAXPRETR       | 路径最大重传次数   | 可选必选说明：可选参数 参数含义：该参数用于指定偶联的一条路径可承受的最大重传次数。如果偶联的一条路径，重传的次数超过这个值，该路径被自动设置为INACTIVE。向上层上报状态变为DOWN。 取值范围：2~5 单位：次 默认值：无。 系统初始设置值：2 配置原则：该值必须小于或等于偶联最大重传次数。                        |
| INITMAXRETR    | 初始化最大重传次数  | 可选必选说明：可选参数 参数含义：该参数用于指定偶联中INIT块最大重传次数。如果对于一个给定的偶联，重传INIT块的次数超过这个值，删除偶联，并发送ABORT到对端，向上层报告状态变为DOWN。空值不被接收。 单位：次 取值范围：3～10 默认值：无。 配置原则：该参数的系统初始设置值为8。                           |
| HBINTER        | 心跳消息间隔     | 可选必选说明：可选参数 参数含义：该参数用于指定心跳间隔时间。用于计算在空闲时间时，来自SCTP主机的2条心跳消息的间隔。心跳传送不仅依赖于此参数，也依赖于偶联的当前RTO。但是2条心跳消息的时间间隔一直要大于心跳消息间隔的值。空值不被接收。 单位：毫秒 取值范围：1000～30000 默认值：无。 配置原则：该参数的系统初始设置值为2000。 |
| RTOALPHA       | Rto Alpha值 | 可选必选说明：可选参数 参数含义：该参数用于指定在协议栈运行期间计算双向时延和RTO值的常量。 单位：% 取值范围：1～100 默认值：无。 配置原则： 该值必须小于或等于100和Rto Beta值。该参数的系统初始设置值为12。                                                           |
| RTOBETA        | Rto Beta值  | 可选必选说明：可选参数 参数含义：该参数用于定义在协议栈运行期间计算双向传播时间和RTO值的常量。 单位：% 取值范围：1～100 默认值：无。 配置原则： 该值必须小于或等于100和大于或等于Rto Alpha值。该参数的系统初始设置值为25。                                                   |
| CNGLEVELNO     | 无拥塞级阈值     | 用于定义无拥塞的发送缓存中数据占用率。该值必须小于低拥塞级阈值。 单位：% 取值范围：1～100 默认值：无。 配置原则： 该参数的系统初始设置值为40。                                                                                                 |
| CNGLEVELL      | 低拥塞级阈值     | 用于定义低拥塞的发送缓存中数据占用率。该值必须大于无拥塞级阈值并且小于高拥塞级阈值。 单位：% 取值范围：1～100 默认值：无。 配置原则： 该参数的系统初始设置值为60。                                                                                       |
| CNGLEVELH      | 高拥塞级阈值     | 用于定义高拥塞的发送缓存中数据占用率。该值必须大于低拥塞级阈值。 单位：% 取值范围：1～100 默认值：无。 配置原则： 该参数的系统初始设置值为80。                                                                                                 |
| CONGESTIONFLAG | 拥塞控制开关     | 设置发送数据时是否使用拥塞控制开关。FALSE表示不使用、TRUE表示使用。 取值范围： TRUE（是）FALSE（否） 默认值：无。 配置原则： 该参数的系统初始设置值为FALSE。                                                                                  |

## 使用实例

修改DLBSCTPPARA配置。“报文重发间隔初始值”为“200”，“报文重发间隔最小值”为“200”，“报文重发间隔最大值”为“1000”，“偶联最大重传次数”为“10”，“路径最大重传次数”为“2”,“初始化最大重传次数”为4，“心跳消息间隔”为2000，“Rto Alpha值”为2，“Rto Beta值”为25，“无拥塞级阈值”为40，“低拥塞级阈值”为60，“高拥塞级阈值”为80，“拥塞控制开关”为FALSE。

```
SET DLBSCTPPARA: ID=1,RTOINIT=200, RTOMIN=200, RTOMAX=1000, MAXARETR=10, MAXPRETR=2,INITMAXRETR=4,HBINTER=2000,RTOALPHA=2,RTOBETA=25,CNGLEVELNO=40,CNGLEVELL=60,CNGLEVELH=80,CONGESTIONFLAG=FALSE;
```
