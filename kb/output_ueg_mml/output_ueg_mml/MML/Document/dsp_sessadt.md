# 查询会话备份数据审计任务状态（DSP SESSADT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护命令，用于查询UPCF与USCDB间的会话数据审计和USCDB中冗余会话数据清理的状态，以便管理人员了解会话备份数据审计任务状态。

- 如果需要查询UPCF与USCDB间的会话数据审计状态信息，“审计类型”请选择“UPCF”，“实例号”请输入查询到的实例号。其中，在Gx、Sd、Rx、N7、N15、N5会话数据审计结束后，系统会统计出UPCF与USCDB间的会话审计总数和会话内容不一致总数。
- 如果需要查询USCDB中冗余会话数据清理状态信息，“审计类型”请选择“USCDB”。

系统运行的过程中，UPCF周期与USCDB进行Gx、Sd、Rx、N7、N15、N5会话数据审计，对超过有效期的会话数据进行清除，管理人员可以通过该命令来了解审计任务的状态。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                 |
|:-----------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------|
| TYPE       | 审计类型   | 指定审计任务的类型。 取值范围： UPCF(UPCF与USCDB间的会话数据审计)USCDB(USCDB的会话备份冗余数据清理审计) 说明： 当需要查询USCDB的会话备份冗余数据清理审计任务状态时，执行DSP OTSSESSADT命令进行状态查询。 默认值：无。 |
| INSTANCENO | 实例号    | 用于指定PES的实例号。该参数在“审计类型”取值为“UPCF”时生效。 参数范围：长度为1～256字节的字符串。 默认值：无。  说明： 实例号查询方法：执行DSP SERVICEINFO命令获取返回服务的实例号。                          |

## 使用实例

查询UPCF与USCDB间的会话数据审计状态信息，需要进行如下操作：

1. 执行**DSP SERVICEINFO**命令获取返回PES服务类型的实例号（假设查询到的实例号为“539079913”）。
2. 执行**DSP SESSADT**命令，“审计类型”取值为“UPCF”，“实例号”取值为“539079913”，执行命令如下：

```
DSP SESSADT: TYPE=UPCF, INSTANCENO="539079913";
```
