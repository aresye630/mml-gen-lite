# 修改SRVCC流程限制策略(MOD SRVCCLMTPLCY)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于修改SRVCC流程限制策略。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称            | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                |
|:------------|:----------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE    | 用户范围            | 可选必选说明：必选参数 参数含义：该参数用于指定用户范围。 数据来源：整网规划 取值范围： ALL_USER（所有用户）：表示用户范围为系统内所有用户。HOME_USER（本网用户）：表示用户范围为本网用户。FOREIGN_USER（外网用户）：表示用户范围为外网用户。IMSI_PREFIX（指定IMSI前缀）：表示用户范围通过IMSI前缀指定。SPECIFIC_IMSI（指定IMSI）：表示用户范围通过IMSI指定。 默认值：无 配置原则：SRVCC流程限制策略匹配优先级从高到低为：“SPECIFIC_IMSI（指定IMSI）”，“IMSI_PREFIX（指定IMSI前缀）”，“FOREIGN_USER(外网用户)”或“HOME_USER(本网用户)”， “ALL_USER(所有用户)”。 系统优先匹配高优先级的配置记录，如果匹配不到，再匹配低优先级的配置记录。 |
| NOID        | 运营商标识           | 可选必选说明：条件必选参数 参数含义：该参数用于指定运营商标识。 前提条件：该参数在“用户范围”参数配置为“HOME_USER(本网用户)”或“FOREIGN_USER(外网用户)”后生效。 数据来源：整网规划 取值范围：0～64，128～254 默认值：无 配置原则：若该参数需要配置为0或128～254之间的值时，须先在ADD MNO中配置取值相同的“MNOID”参数。若该参数需要配置为1～64之间的值时，须先在ADD MVNO中配置取值相同的“MVNOID”参数。                                                                                                                                                        |
| IMSIPRE     | IMSI前缀          | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI前缀以区分不同的用户群。 前提条件：该参数在“用户范围”参数配置为“IMSI_PREFIX（指定IMSI前缀）”后生效。 数据来源：整网规划 取值范围：5～14位十进制字符串 默认值：无                                                                                                                                                                                                                                                                         |
| IMSI        | IMSI            | 可选必选说明：条件必选参数。 参数含义：该参数用于指定用户的IMSI（完整IMSI）。 前提条件：该参数在“用户范围”配置为“SPECIFIC_IMSI（指定IMSI）”后生效。 数据来源：全网规划 取值范围：15位十进制字符串 默认值：无 配置原则：无                                                                                                                                                                                                                                                                     |
| SRVCCCAPCFG | 是否限制携带SRVCC能力   | 可选必选说明：可选参数 参数含义：该参数用于指定是否限制SRVCC流程，如果限制则不携带SRVCC Operation Possible信元给eNodeB。 数据来源：整网规划 取值范围： NO(否)YES(是) 默认值：无 配置原则：当SRVCC功能支持，但不期望用户发起SRVCC流程，限制在DOWNLINK NAS TRANSPORT、INITIAL CONTEXT SETUP REQUEST、HANDOVER REQUEST消息中携带SRVCC Operation Possible信元给eNodeB，将该参数设置为“YES(是)”。否则配置为“NO(否)”，保持原有实现。                                                                                                |
| EMGCAPCFG   | 紧急呼叫是否限制SRVCC能力 | 可选必选说明：条件可选参数 参数含义：该参数用于指定是否限制紧急呼叫SRVCC流程。如果限制则不携带SRVCC Operation Possible信元给eNodeB。 前提条件：该参数在“是否限制携带SRVCC能力”参数配置为“YES(是)”后生效。 数据来源：整网规划 取值范围： NO(否)YES(是) 默认值：无 配置原则：当SRVCC功能支持时，但不期望用户发起紧急呼叫SRVCC流程，限制在DOWNLINK NAS TRANSPORT、INITIAL CONTEXT SETUP REQUEST、HANDOVER REQUEST消息中携带SRVCC Operation Possible信元给eNodeB，将该参数设置为“YES(是)”。否则配置为“NO(否)”，保持原有实现。                                           |

#### 使用实例

修改一条SRVCC流程限制策略配置，“用户范围”为“ALL\_USER”，“是否限制携带SRVCC能力”为“YES(是)”，“紧急呼叫是否限制SRVCC能力”为“NO(否)”：

```
MOD SRVCCLMTPLCY: SUBRANGE=ALL_USER, SRVCCCAPCFG=YES, EMGCAPCFG=NO;
```
