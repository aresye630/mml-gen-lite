# 查看SCTP负荷信息(DSP DBSSCTPLOD)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，查看SCTP负荷信息。

若需要查询某个DBS服务模块的SCTP负荷信息，请输入“服务模块号”参数。

## 注意事项

无。

## 参数说明

| 参数ID      | 参数名称   | 参数描述                                                                     |
|:----------|:-------|:-------------------------------------------------------------------------|
| SERVICENO | 服务模块号  | 可选必选说明：必选参数。 参数含义：用于请求系统显示哪个DBS服务的SCTP负荷信息。 取值范围： 1～1024 默认值： 无。 配置原则：无。 |

## 使用实例

查看SCTP负荷信息，DBS服务模块号为102。

```
DSP DBSSCTPLOD: SERVICENO=102;
```

```
%%DSP DBSSCTPLOD: SERVICENO=102;%%
RETCODE = 0  操作成功

操作结果如下
------------
 偶联号  发送负荷(%)  接收负荷(%)

 3       0            0          
 5       0            0          
(结果个数 = 2)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称   | 输出项解释                                 |
|:--------|:--------------------------------------|
| 偶联号     | SCTP偶联号码。                             |
| 发送负荷(%) | SCTP链路发送信息的负荷。 通过此参数可以查看当前偶联的发送负荷的高低。 |
| 接收负荷(%) | SCTP链路接收信息的负荷。 通过此参数可以查看当前偶联的接收负荷的高低。 |
