# 设置S1-U黑名单参数(SET S1UBLACKLSTPARA)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

暂不支持本命令。该命令用于设置S1-U黑名单参数。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                                                                                                                                  |
|:--------------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SNDBLKLSTPLCY | 发送黑名单策略 | 可选必选说明：可选参数 参数含义：该参数控制系统在流程中接收到S-GW发送的消息中携带的S1-U IP地址为ADD S1UBLACKLST命令中配置的IP地址时，系统是否向eNodeB发送携带该IP地址的消息。 数据来源：整网规划 取值范围：“YES(发送)”“NO(不发送)” 默认值：无 系统初始设置值：YES(发送) 配置原则：当需要确保系统不向eNodeB发送携带S1-U黑名单IP地址的消息时，设置为NO（不发送）。 |

#### 使用实例

配置系统不向eNodeB发送携带S1-U黑名单IP地址的消息：

SET S1UBLACKLSTPARA: SNDBLKLSTPLCY=NO;
