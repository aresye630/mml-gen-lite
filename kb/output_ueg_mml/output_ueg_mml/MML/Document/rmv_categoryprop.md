# 删除分类属性（RMV CATEGORYPROP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用来删除所有或者根据分类属性名字删除配置信息。

#### 注意事项

- 该命令执行后立即生效。
- 若CATEGORYPROP配置信息被BWMSERVICE绑定，则不允许删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                        |
|:-------------|:-------|:--------------------------------------------------------------------------------------------|
| CATEPROPNAME | 分类属性名称 | 可选必选说明：可选参数 参数含义：该参数用于设置分类属性名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

删除名称为“test”的分类属性配置信息：

```
RMV CATEGORYPROP:CATEPROPNAME="test";
```
