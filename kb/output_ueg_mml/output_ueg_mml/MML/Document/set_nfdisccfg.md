# 设置NF发现配置（SET NFDISCCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于配置NF发现。

## 注意事项

无。

## 参数说明

| 参数标识           | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                         |
|:---------------|:-------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE    | 服务类型         | 可选必选说明：必选参数。 参数含义：用于设置NF所属服务类型。 取值范围： PES(PES)PES-NCS(PES-NCS) 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                |
| LNKFAULTDISCSW | 链路故障场景NF发现开关 | 可选必选说明：可选参数。 参数含义：用于设置链路故障场景NF发现开关类型。 取值范围： 全部选中：用于同时选中CHF发现、BSF发现、NWDAF发现。全部清空：用于同时不选中CHF发现、BSF发现、NWDAF发现。全部灰化：用于同时灰化CHF发现、BSF发现、NWDAF发现。CHFDISC(CHF发现)BSFDISC(BSF发现)NWDAFDISC(NWDAF发现) 默认值：无。 配置原则：无。  说明： PES在N7会话流程需要给BSF发起请求消息时，如果匹配到了链路故障的BSF，根据设置的链路故障场景NF发现开关决定是否进行服务发现。PES在N28会话流程需要给CHF发起请求消息时，如果匹配到了链路故障的CHF，根据设置的链路故障场景NF发现开关决定是否进行服务发现。PES在N23会话流程需要给NWDAF发起请求消息时，如果匹配到了链路故障的NWDAF，根据设置的链路故障场景NF发现开关决定是否进行服务发现。 |
| NRFDISCSW      | 向NRF发起服务发现开关 | 可选必选说明：可选参数。 参数含义：用于控制当本地缓存匹配NWDAF失败后是否向NRF发起服务发现。 取值范围： 全部选中：表示全部选中当前支持的所有取值。全部清除：表示全部清除当前支持的所有取值。全部灰化：表示当前所有选择值均不生效。NWDAFDISC(NWDAF发现) 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                      |

## 使用实例

设置一个“服务类型”为“PES(PES)”，“链路故障场景NF发现开关”为“CHF发现”的NF发现配置。

```
SET NFDISCCFG: SERVICETYPE=PES, LNKFAULTDISCSW=CHFDISC-1&BSFDISC-0&NWDAFDISC-0;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
