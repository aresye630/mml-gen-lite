# 修改业务质差检测策略（MOD POLICYCONDITION）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于修改业务质差检测策略。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

将质差策略名为policyname的上行平均速率基线修改为50Kbps：

```
MOD POLICYCONDITION: POLICYCNDNAME="policyname", UPLINKAVGRATE=50;
```
