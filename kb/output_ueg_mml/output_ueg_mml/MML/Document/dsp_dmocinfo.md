# 显示Diameter流控信息(DSP DMOCINFO)

- 命令功能

- 本地用户权限

#### 命令功能

**适用网元：SGSN、MME**

此命令用于查询Diameter Overload Indication Conveyance（DOIC）流控信息 。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称         | 参数说明                                                                                                                                                  |
|:----------|:-------------|:------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROCTYPE  | 进程类型         | 可选必选说明：可选参数 参数含义：该参数用于指定进程的进程类型。 数据来源：整网规划 取值范围：“LCP（LCP进程）”“SGP（SGP进程）” 默认值：“LCP（LCP进程）” 配置原则：无                                                      |
| RUNAME    | RU名称         | 可选必选说明：条件必选参数 参数含义：该参数用于指定SPU资源单元名。该参数可以通过DSP RU命令查询。 前提条件：此参数在“进程类型”设置为“SGP（SGP进程）”后生效。 数据来源：整网规划 取值范围：0~63 位字符串 默认值：无 配置原则：无                        |
| PROCID    | 进程号          | 可选必选说明：条件必选参数 参数含义：该参数用于指示查询的目的进程号。 前提条件：此参数在“进程类型”设置为“SGP（SGP进程）”后生效。 数据来源：整网规划 取值范围：0~255 默认值：无 配置原则：无                                              |
| QRYTYPE   | 查询类型         | 可选必选说明：可选参数 参数含义：该参数用于指定查询类型。 数据来源：整网规划 取值范围：“MEMORY（内存）”“DDB（数据库）” 默认值：“MEMORY（内存）” 配置原则：无                                                           |
| DMOCTYPE  | Diameter流控类型 | 可选必选说明：可选参数 参数含义：该参数用于指定Diameter流控信息类型。 数据来源：整网规划 取值范围：“ALL（所有类型）”“BYHOSTNAME（基于HOSTNAME）”“BYREALMNAME（基于REALMNAME）” 默认值：“ALL（所有类型）” 配置原则：无           |
| HOSTNAME  | 主机名          | 可选必选说明：条件可选参数 参数含义：该参数用于指定Diameter流控信息的主机名。 数据来源：整网规划 前提条件：此参数在“Diameter流控类型”设置为“BYHOSTNAME（基于HOSTNAME）”后生效。 取值范围：字符串类型，输入长度范围为0～127。 默认值：无 配置原则：无    |
| REALMNAME | 域名           | 可选必选说明：条件可选参数 参数含义：该参数用于指定Diameter流控信息的主机域名。 数据来源：整网规划 前提条件：此参数在“Diameter流控类型”设置为“BYREALMNAME（基于REALMNAME）”后生效。 取值范围：字符串类型，输入长度范围为0～127。 默认值：无 配置原则：无 |

#### 使用实例

查询LCP进程流控记录信息：

DSP DMOCINFO: PROCTYPE=LCP, DMOCTYPE=ALL;

```

RETCODE = 0  操作成功。
```

#### 输出结果说明

| 输出项名称                | 输出项解释                                                                                                         |
|:---------------------|:--------------------------------------------------------------------------------------------------------------|
| 进程类型                 | 查询出的流控信息的进程类型。                                                                                                |
| RU名称                 | 查询出的SPU资源单元名。                                                                                                 |
| 进程号                  | 查询出的流控信息的进程序号。                                                                                                |
| 查询类型                 | 查询出的流控信息的查询类型。                                                                                                |
| Diameter流控信息类型       | Diameter流控信息类型。                                                                                               |
| 主机名                  | Diameter流控信息的主机名。                                                                                             |
| 域名                   | Diameter流控信息的域名。                                                                                              |
| 索引                   | 对应ADD DMOC命令中的“索引”参数。                                                                                         |
| OC-Feature           | Diameter流控算法。                                                                                                 |
| Sequence Number      | Diameter流控序列号。                                                                                                |
| Validity Duration    | Diameter流控有效时长。                                                                                               |
| Reduction Percentage | Diameter流控消息减少概率。                                                                                             |
| Overload State       | Diameter流控状态。                                                                                                 |
| 最近的Diameter流控启动时间    | 最近的Diameter流控启动时间。  说明： 如果时间是无效值，默认赋值为2000-01-01 00:00:00加上当地对应时区时间，比如中国时区是加8小时，时间为2000-01-01 00:00:00+08:00。 |
| 最近的Diameter流控结束时间    | 最近的Diameter流控结束时间。  说明： 如果时间是无效值，默认赋值为2000-01-01 00:00:00加上当地对应时区时间，比如中国时区是加8小时，时间为2000-01-01 00:00:00+08:00。 |
