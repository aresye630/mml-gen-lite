# 显示链路信息(DSP LINKINFO)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用网元：MME**

此命令用于查询链路历史状态信息。

#### 注意事项

此命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                        |
|:------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RUNAME      | RU名称   | 可选必选说明：必选参数 参数含义：该参数用于指定待查询链路所在的RU名称。该参数可以通过DSP RU命令查询。 取值范围：1~63位字符串 默认值 ：无                                                                                                                                                |
| PROCTYPE    | 进程类型   | 可选必选说明：必选参数 参数含义：该参数用于指定链路的进程类型。 取值范围：“SGP(SGP)” “UPP(UPP)” 默认值：无 配置原则：当前只支持SGP进程查询。                                                                                                                                        |
| PROCID      | 进程号    | 可选必选说明：必选参数 参数含义：待查询链路所在的进程号。 取值范围： 0~4294967295 默认值 ：无                                                                                                                                                                     |
| LINKTYPE    | 链路类型   | 可选必选说明：必选参数 参数含义：待查询链路的链路类型 取值范围：DNSLNK(DNSLNK) DMLNK(DMLNK) GTPCLNK(GTPCLNK)GTPULNK(GTPULNK)LCSLNK(LCSLNK)M3UALNK(M3UALNK)NSVCLNK(NSVCLNK)S1APLNK(S1APLNK)SBCLNK(SBCLNK)SGSLNK(SGSLNK) 默认值 ：无 配置原则：当前只支持查询S1AP链路（S1APLNK）。 |
| SERVICETYPE | 服务名称   | 可选必选说明：必选参数 参数含义：此参数用于指定待查询的服务名称，可以通过LST VNFC命令查询得到。 取值范围：字符串类型，输入长度范围为1～31。数字“0~9”，大写字母“A~Z”，小写字母“a~z”，特殊字符“-”，“_”，其他均为非法字符，并且首字符必须为字母。 默认值：无 配置原则： 如果要查询GTPU的链路历史状态，则SERVICETYPE需要填写USN的名称，否则，SERVICETYPE需要填写LINK的名称。     |

#### 使用实例

查询S1AP链路信息，RU名称为LINK\_SP\_RU\_0064，进程类型为SGP，进程号为1，可以用如下命令：

```
DSP LINKINFO: RUNAME="LINK_SP_RU_0064", PROCTYPE=SGP, PROCID=1,LINKTYPE=S1APLNK, SERVICETYPE="LINK_VNFC";
```

%%DSP LINKINFO: RUNAME="LINK_SP_RU_0064", PROCTYPE=SGP, PROCID=1, LINKTYPE=S1APLNK, SERVICETYPE="LINK_VNFC";%%
