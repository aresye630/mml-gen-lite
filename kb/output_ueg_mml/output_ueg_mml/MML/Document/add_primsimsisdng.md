# 增加代理IMSI/MSISDN号段组（ADD PRIMSIMSISDNG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、GGSN、SGW-C、SMF**

该命令用于增加代理IMSI/MSISDN号段组。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入25000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称             | 参数说明                                                                                                                                                                              |
|:-------------|:-----------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SEGGROUPNAME | IMSI/MSISDN号段组名称 | 可选必选说明：必选参数  参数含义：该参数用于指定信令代理特性所使用的IMSI/MSISDN号码段组名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。只允许输入字母、数字、“.”、“_”和“-”。字母会被转换为小写字母进行存储和处理。  默认值：无  配置原则：无                                |
| SEGMENTNAME  | IMSI/MSISDN号段名称  | 可选必选说明：必选参数  参数含义：该参数用于指定信令代理特性所使用的IMSI/MSISDN号码段名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。只允许输入字母、数字、“.”、“_”和“-”。字母会被转换为小写字母进行存储和处理。  默认值：无  配置原则：  该参数使用ADD PRIMSIMSISDNSEG命令配置生成。 |

## 使用实例

增加“IMSI/MSISDN号段组名称”为“grp1”，“IMSI/MSISDN号段名称”为“imsi1”的代理IMSI/MSISDN号段组配置：

```
ADD PRIMSIMSISDNG: SEGGROUPNAME="grp1", SEGMENTNAME="imsi1";
```
