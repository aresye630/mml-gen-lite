## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响业务处理，修改配置需要重启UPCF后才能生效，混合组网下修改时需要确认UPCC版本的能力，请联系华为技术支持确认后再执行。

本命令用于设置UPCF支持配置的条件组、动作组、消息通知、规则、策略、业务、动作元素和5G动作组数量的最大个数。

该命令的使用场景：支持对UPCF中允许配置全局数据的条件组、动作组、消息通知、规则、策略、业务、动作元素和5G动作组个数的最大值做限制，防止因配置过多引起占用过多系统资源。

## 注意事项

- 一般情况下，操作员使用系统初始值。如果操作员确实需要修改参数配置，请咨询华为公司技术服务工程师，禁止随意修改。
- 参数修改后需要执行**RST POD**重启UPCF网元下所有POD才生效，否则上报告警ALM-34258 SET GLBMAXNUM配置修改未生效。
- 当“全局数据最大记录数”由大改小时，且系统已经配置了较多数据记录时，会导致配置数据加载异常。
- 混合组网时，即PGW软参“MixedNetworkSwitch”设置为“1”时，系统会先比较**LST GLBMAXNUM**命令和**LST UPCCPLYCAP**命令的查询返回结果的相同配置项的值，使用较小值作为UPCF允许配置的全局数据对象的最大记录数。
- 混合组网时，UPCF通过**SET UPCCPLYCAP**设置的全局数据的最大记录数不能超过UPCC的版本能力，否则会导致UPCC全局数据加载异常，影响业务。

## 使用实例

设置规则的最大记录数，“全局数据名称”为“RULE(RULE)”，“全局数据最大记录数”为“30000”。

```
SET GLBMAXNUM: NAME=RULE, MAXNUMBER=30000;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释            | 原因分析                 | 处理建议                                          |
|------:|:-----------------|:---------------------|:----------------------------------------------|
| 58148 | 参数MAXNUMBER取值非法。 | 输入的“MAXNUMBER”参数不合法。 | 根据选择的“全局数据名称”，参考不同全局数据的取值范围，输入合法的“全局数据最大记录数”。 |
