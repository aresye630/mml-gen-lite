# 重启LDP会话（RBL LDPSESSION）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于重启一个LDP会话。

#### 注意事项

- 该命令执行后立即生效。
- 执行该命令会导致邻居断连。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称       | 参数说明                                                                                                                        |
|:-----------|:-----------|:----------------------------------------------------------------------------------------------------------------------------|
| PEERID     | 对等体的LSR ID | 可选必选说明：必选参数 参数含义：该参数用于指定对等体的LSR ID。 数据来源：对端协商 取值范围：IPv4地址类型。 默认值：无                                                          |
| ISGRACEFUL | 是否优雅重启     | 可选必选说明：可选参数 参数含义：该参数用于指定是否优雅重启。设置ISGRACEFUL为TRUE，可以实现对于指定的对等体在重启时业务不中断。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：FALSE |

#### 使用实例

重启一个LDP会话：

```
RBL LDPSESSION:PEERID="192.168.1.1";
```
