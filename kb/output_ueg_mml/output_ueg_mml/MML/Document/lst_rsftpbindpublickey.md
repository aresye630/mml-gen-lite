# 查询远端用户数据同步服务器与公钥的绑定关系（LST RSFTPBINDPUBLICKEY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UDM**

该命令用于查询已经创建的远端用户数据同步服务器与公钥的绑定关系。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                              |
|:-----------|:-------|:------------------------------------------------------------------------------------------------------------------|
| SERVERNAME | 服务器名称  | 可选必选说明：可选参数 参数含义：远端用户数据同步服务器名称。 数据来源：本端规划 取值范围：由数字、字母和下划线组成的不超过16位的字符串。 默认值：无 配置原则：该参数使用ADD RDATASYNSERVER命令配置生成。 |

#### 使用实例

查询远端数据同步服务器rdata1与公钥的绑定关系：

```
LST RSFTPBINDPUBLICKEY: SERVERNAME = rdata1;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
服务器名称    密钥名称    
rdata1         rsa1
rdata1         rsa2
 (结果个数 = 1) 
---   END
```
