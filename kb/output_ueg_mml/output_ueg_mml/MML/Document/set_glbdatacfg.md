## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致系统异常，影响业务处理，需联系华为技术支持确认后再执行。

该命令用于设置PES全局数据一致性校验配置。

该命令的使用场景：开启该功能后，系统会周期性校验（检验周期可通过查看“VRM\_GLBREFLASHINTERVAL”软参取值）PES全局数据一致性，当PES全局数据不一致时会强制刷新全局数据。

## 注意事项

开启PES全局数据一致性校验功能后cpu上涨不超过5%。

## 参数说明

| 参数ID        | 参数名称   | 参数描述                                                                                                                                                                                                                                                               |
|:------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICENAME | 服务名称   | 可选必选说明：必选参数 参数含义：用于指定全局数据一致性校验的微服务名称。 取值范围： PES(PES) 默认值：无。 配置原则：无。                                                                                                                                                                                                |
| CHECKSWITCH | 校验开关   | 可选必选说明：必选参数 参数含义：用于设置是否开启PES全局数据一致性校验功能。 取值范围：NoCheck(不进行校验)：表示不进行PES全局数据一致性校验。CheckWithoutAlarm(进行校验但不上报告警)：表示进行PES全局数据一致性校验但不上报告警“ALM-34276 与主PES的全局数据不一致”。CheckWithAlarm(进行校验并上报告警)：表示进行PES全局数据一致性校验并上报告警“ALM-34276 与主PES的全局数据不一致”， 默认值：CheckWithAlarm。 配置原则：无。 |

## 使用实例

开启PES全局数据一致性校验。“服务名称”为“PES”，“校验开关”为“CheckWithAlarm”。

```
SET GLBDATACFG: SERVICENAME=PES, CHECKSWITCH=CheckWithAlarm;
```

```
%%SET GLBDATACFG: SERVICENAME=PES, CHECKSWITCH=CheckWithAlarm;%%
RETCODE = 0  操作成功
---    END
```
