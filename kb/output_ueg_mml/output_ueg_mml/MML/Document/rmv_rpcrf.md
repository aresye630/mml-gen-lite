# 删除PCRF容灾PCRF实体(RMV RPCRF)

- 命令功能

- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令为配置命令，用于从配置数据库中删除一条容灾PCRF实体数据记录。

该命令的使用场景：当需要删除容灾PCRF实体，或需要更换容灾PCRF实体时，可以使用本命令。

## 注意事项

删除一条容灾PCRF实体时需判断RPCRF对象是否被PEERL、RPCRFL和PAFL对象引用，如果被引用则不能删除。

## 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                               |
|:--------|:---------|:-----------------------------------------------------------------------------------|
| PCRFID  | 本端PCRF标识 | 标识一条容灾PCRF实体配置信息的关键字段之一（其取值不能被修改），用于指定需要删除哪一条容灾PCRF实体的配置信息，操作员可以使用LST PCRF命令查询获得。  |
| RPCRFID | 容灾PCRF标识 | 标识一条容灾PCRF实体配置信息的关键字段之一（其取值不能被修改），用于指定需要删除哪一条容灾PCRF实体的配置信息，操作员可以使用LST RPCRF命令查询获得。 |

## 使用实例

删除PCRF容灾PCRF实体配置信息。“本端PCRF标识”为“1”，“容灾PCRF标识”为“0”。

```
RMV RPCRF: PCRFID=1, RPCRFID=0;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                    | 原因分析                              | 处理建议                                                                                                                       |
|------:|:-------------------------|:----------------------------------|:---------------------------------------------------------------------------------------------------------------------------|
| 57348 | RPCRF对象被RPCRFL引用，不能删除记录。 | 一条容灾PCRF实体被容灾PCRF链路引用时，无法被删除。     | 执行LST RPCRFL命令，输入参数“容灾PCRF标识”，查询待删除容灾PCRF实体对应的链路信息。如果确认需要删除步骤1中的所有链路，执行RMV RPCRFL命令删除引用该“容灾PCRF标识”的RPCRFL链路信息。执行本命令，删除该记录。 |
| 57856 | RPCRF对象被PEERL引用，不能删除记录。  | 一条容灾PCRF实体被Diameter对端链路引用时，无法被删除。 | 执行LST PEERL命令，输入参数“容灾PCRF标识”，查询待删除容灾PCRF实体对应的链路信息。如果确认需要删除步骤1中的所有链路，执行RMV PEERL命令删除引用该“容灾PCRF标识”的PEERL链路信息。执行本命令，删除该记录。    |
