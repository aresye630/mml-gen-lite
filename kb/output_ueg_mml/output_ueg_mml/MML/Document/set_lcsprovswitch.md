# LCS 预备开关（SET LCSPROVSWITCH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于LCS控制API开放的开关。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | SWITCH   |
|:-------|:---------|
| 初始值    | OFF      |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                  |
|:-------|:---------|:--------------------------------------------------------------------------------------|
| SWITCH | LCS 预备开关 | 可选必选说明：必选参数 参数含义：该参数用于配置LCS 预备开关。 数据来源：本端规划 取值范围：枚举类型。 OFF：开关关闭。ON：开关打开。 默认值：无 配置原则：无 |

#### 使用实例

假如需要使用开放API下发配置的功能：

```
SET LCSPROVSWITCH: SWITCH=ON;
```
