# 删除NF实例概述信息（RMV CPNFPROFILE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

当执行此命令时，会触发NF到NRF的去注册。去注册会导致其他NF无法发现该NF，可能导致业务异常，请谨慎操作。

**适用NF：AMF、SMF、NSSF、NRF、NCG、SMSF、NEF、NWDAF、SCF**

该命令用于删除NF实例的概述信息。

## 注意事项

- 该命令执行后立即生效。

- 当NF在注册态时，执行此命令后，会触发NF到NRF的去注册。如后续重新加回此配置时，需要重新执行ACT NFONLINE命令进行NF的注册。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                                                                                                          |
|:---------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSTANCENAME | NF实例名称 | 可选必选说明：必选参数  参数含义：本参数用于指定NF实例名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~50。  默认值：无  配置原则： 本参数的构成字符只能是字母A～Z或a～z、数字0～9、中划线"-"和下划线"_"，例如，AMF_Instance_0。本参数来源于ADD NFUUID命令中的“NF实例名称”参数。 |

## 使用实例

运营商A需要删除NFINSTANCENAME为AMF\_Instance\_0的NF实例概述信息。

```
RMV CPNFPROFILE: NFINSTANCENAME="AMF_Instance_0";
```
