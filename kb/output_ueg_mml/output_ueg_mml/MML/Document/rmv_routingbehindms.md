# 删除手机后路由配置（RMV ROUTINGBEHINDMS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于删除本地配置的手机后路由信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称      | 参数说明                                                                                                                                                                                                                                |
|:----------------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI            | 用户IMSI号   | 可选必选说明：必选参数  参数含义：用户的IMSI信息。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是5~15。  默认值：无  配置原则：无                                                                                                                                                     |
| APN             | APN名称     | 可选必选说明：必选参数  参数含义：该参数用于指定APN实例名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“ ” ”、“ ` ”特殊字符，不区分大小写。  默认值：无  配置原则：  该参数必须已经通过命令ADD CPAPN配置。 |
| FRAMEDROUTEIP   | 后路由IPv4地址 | 可选必选说明：可选参数  参数含义：该参数用于指定后路由的网段地址。  数据来源：本端规划  取值范围：IPv4地址类型。采用点分十进制"X.X.X.X"格式。  默认值：无  配置原则：  IPv4地址不能配置为0.0.0.0、255.255.255.255和环回地址(127.x.y.z)。业务地址必须是A、B或者C类地址。                                                                |
| FRAMEDROUTEMASK | 后路由掩码     | 可选必选说明：可选参数  参数含义：该参数用于指定后路由的网段掩码。  数据来源：本端规划  取值范围：IPv4地址类型。采用点分十进制"X.X.X.X"格式。  默认值：无  配置原则：  输入的掩码要求对应的二进制值1和1之间不允许存在0。例如：“255.255.0.0”是有效掩码；“123.123.123.123”是无效掩码。因为123对应的二进制为“1111011”，1之间存在0。                                |

## 使用实例

删除一条本地配置的手机后路由信息：

```
RMV ROUTINGBEHINDMS: IMSI="123456789125001", APN="demo.com", FRAMEDROUTEIP="192.168.1.0", FRAMEDROUTEMASK="255.255.255.0";
---    END
```
