# 设置全局异地容灾配置（SET TMREDUNDFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C**

该命令用来设置全局异地容灾配置。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

|   STATUSINTERVAL |
|-----------------:|
|               20 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                               |
|:---------------|:---------|:-----------------------------------------------------------------------------------|
| STATUSINTERVAL | 状态通知时间间隔 | 可选必选说明：必选参数  参数含义：状态通知时间间隔。  数据来源：全网规划  取值范围：整数类型，取值范围是10~60，单位是秒。  默认值：无。  配置原则：无 |

## 使用实例

设置状态通知时间间隔为20秒：

```
SET TMREDUNDFUNC: STATUSINTERVAL=20;
```
