# 删除5G多时区参数（RMV NGTZLST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除位置区对应的时区和夏令时信息。

## 注意事项

- 该命令执行后立即生效。

- 删除前请确保当前时区标识在ADD NGAREATZ中没有被引用。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                 |
|:-------|:-------|:-------------------------------------------------------------------------------------|
| TZID   | 时区标识   | 可选必选说明：必选参数  参数含义：该参数用于指定待增加时区的索引信息。  数据来源：本端规划  取值范围：整数类型，取值范围是1~24。  默认值：无  配置原则：无 |

## 使用实例

删除“时区标识”为“1”的时区和夏令时配置信息，执行如下命令：

```
RMV NGTZLST: TZID=1;
```
