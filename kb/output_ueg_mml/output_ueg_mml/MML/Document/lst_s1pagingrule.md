#### 命令功能

**适用网元：MME**

此命令用于查询系统中全部或者指定条件的S1寻呼规则。查询结果按“匹配优先级”排序后显示。

#### 注意事项

- 此命令执行后立即生效。
- 当不指定任何条件时，表示查询系统中所有的S1寻呼规则；否则按照输入的条件查询指定的S1寻呼规则。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                |
|:----------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RECID     | 规则索引     | 可选必选说明：可选参数 参数含义：该参数用于指定待查询的S1寻呼规则的索引。 取值范围：1～1001 默认值：无  说明： 当执行ADD S1PAGINGRULE命令增加S1寻呼规则时，系统会自动为该规则分配一个1～1001之间未使用的最小的索引，以唯一的标识该S1寻呼规则。可以在不输入“规则索引”时，执行本命令查询系统分配的索引值。因为“规则索引”唯一的标识一条S1寻呼规则，故执行本命令时，如果指定了“规则索引”，建议不用再指定其它的查询条件。                                                                                   |
| GRPTYPE   | 用户群类型    | 可选必选说明：可选参数 参数含义：该参数用于指定待查询的S1寻呼规则的用户群类型。 取值范围：“ALL_USER(所有用户)”“IMSI_PREFIX(指定IMSI前缀)”“MSISDN_PREFIX(指定MSISDN前缀)”“IMEI_TAC(指定IMEI TAC)” 默认值：无                                                                                                                                                                       |
| IMSIPRE   | IMSI前缀   | 可选必选说明：条件可选参数 参数含义：该参数用于指定待查询的S1寻呼规则的IMSI前缀。 前提条件：该参数在“用户群类型”参数设置为“IMSI_PREFIX(指定IMSI前缀)”时，才生效。 取值范围：1～15位十进制数字串 默认值：无                                                                                                                                                                                              |
| MSISDNPRE | MSISDN前缀 | 可选必选说明：条件可选参数 参数含义：该参数用于指定待查询的S1寻呼规则的MSISDN前缀。 前提条件：该参数在“用户群类型”参数设置为“MSISDN_PREFIX(指定MSISDN前缀)”时，才生效。 取值范围：1～15位十进制数字串 默认值：无                                                                                                                                                                                        |
| IMEITAC   | IMEI TAC | 可选必选说明：条件可选参数 参数含义：该参数用于指定待查询的S1寻呼规则的IMEI TAC。 前提条件：该参数在“用户群类型”参数设置为“IMEI_TAC(指定IMEI TAC)”时，才生效。 取值范围：位数为8的十进制数字 默认值：无                                                                                                                                                                                              |
| SVRTYPE   | 业务类型     | 可选必选说明：可选参数 参数含义：该参数用于指定待查询的S1寻呼规则的业务类型。 取值范围：“S11_DOWNLINK(下行数据触发)”：表示由S11接口的下行业务（包含DDN或者CBR/UBR消息）触发的寻呼。“SGS_PAGING(SGs寻呼触发)”：表示由SGs接口的CS Call、SMS等业务触发的寻呼。“S102_PAGING(S102寻呼触发)”：表示由S102接口的CS Call、SMS等业务触发的寻呼。“S6A_IDR_PAGING(S6a接口IDR寻呼触发)”：表示由S6a接口的实时位置查询或状态查询业务触发的寻呼。“OTHER(其它)”：表示由其它业务触发的寻呼，如LCS等。 默认值：无 |
| PRIORITY  | 匹配优先级    | 可选必选说明：可选参数 参数含义：该参数用于指定待查询的S1寻呼规则的匹配优先级。 取值范围：0～255 默认值：无                                                                                                                                                                                                                                                          |
| ACTGRP    | 寻呼动作组合   | 可选必选说明：可选参数 参数含义：该参数用于指定寻呼规则使用的寻呼动作组合。 取值范围：LAST_ENODEB(最近访问eNodeB)NEIGH_ENODEB(邻接eNodeB)LAST_TAI(最近访问TA) 默认值：无                                                                                                                                                                                                     |
