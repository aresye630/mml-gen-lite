# 删除LCS算法参数（RMV LCSALGOPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于删除用户位置解算的算法开关以及参数配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                              |
|:---------|:-------|:--------------------------------------------------------------------------------------------------|
| GNODEBID | 基站标识   | 可选必选说明：必选参数 参数含义：该参数用于设置基站标识。 数据来源：本端规划 取值范围：0~4294967295。 默认值：无 配置原则：该参数使用LST LCSALGOPARA命令配置生成。 |
| NRCELLID | 小区标识   | 可选必选说明：必选参数 参数含义：该参数用于配置NR小区标识。 数据来源：本端规划 取值范围：0~65534。 默认值：无 配置原则：该参数使用LST LCSALGOPARA命令配置生成。    |

#### 使用实例

删除GNODEBID为123，NRCELLID为123的用户位置解算的算法开关以及参数配置：

```
RMV LCSALGOPARA: GNODEBID=123, NRCELLID=123;
```
