# 增加远端服务器组配置(ADD HTTPRSRVGRP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于增加一条远端服务器组配置信息，设置与对端网元对接时的远端服务器配置。

## 注意事项

最大支持255条远端服务器组配置。

## 参数说明

| 参数标识        | 参数名称               | 参数说明                                                                                                                                                                                     |
|:------------|:-------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RSRVGRPNAME | 远端服务器组名            | 可选必选说明：必选参数。 参数含义：用于标识一个远端HTTP服务端组的名称。 取值范围：长度不超过128的由数字和字母组成的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。                                                                               |
| RNFTYPE     | 对端类型               | 可选必选说明：必选参数。 参数含义：用于标识对端类型，建链时根据对端类型选择对应的链路集参数类型。 取值范围： NRF(NRF)AMF(AMF)SMF(SMF)NEF(NEF)SCP(SCP)SEPP(SEPP)AUC(AUC)SSG(SSG) 默认值：无 配置原则：当对端类型为NRF、SCP、SEPP、AUC或SSG时，只能配置一个远端服务器组，其他类型没有限制。 |
| MODE        | 远端服务器选择模式          | 可选必选说明：必选参数。 参数含义：用于标识远端服务器选择模式。 取值范围：PRI（优先级方式） 默认值：无。 配置原则：无。                                                                                                                          |
| WEIGHT_RATE | 远端服务器组在联动倒换中的比例(%) | 可选必选说明：可选参数。 参数含义：用于标识HTTP远端服务器组在联动倒换中的权重比例。系统根据该参数配置的权重比例，作为该组下所有对端的故障率。当故障率发生变化时，DCS向控制CCU发送该值。 取值范围：0～100 单位：%。 默认值：0。 配置原则：该参数仅在组中的远端服务器配置都是静态链路时配置，此参数配置才会生效，不适用于动态链路。              |

## 使用实例

1. 在UDM初始配置阶段，增加一条远端服务器组配置。“远端服务器组名”为“smf\_1”，“对端类型”为“SMF”，“远端服务器选择模式”为“PRI”。

   ```
   ADD HTTPRSRVGRP: RSRVGRPNAME="smf_1", RNFTYPE=SMF, MODE=PRI;
   ```
2. 在配置容灾自动倒换增强功能（FE关键对端故障场景）时，执行该命令增加HTTP远端服务器组在联动倒换中的比例。关键对端组中“远端服务器组在联动倒换中的比例(%)”参数的取值需要根据该对端组的重要程度进行设置。例如，某关键对端组中的对端非常重要，一旦故障必须进行信令倒换时，需要将参数“WEIGHT\_RATE”设置为“100”。

   ```
   ADD HTTPRSRVGRP: RSRVGRPNAME="nrf_1", RNFTYPE=NRF, MODE=PRI, WEIGHT_RATE=100;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                   | 原因分析                              | 处理建议                                                                |
|-------:|:------------------------|:----------------------------------|:--------------------------------------------------------------------|
| 360064 | 只能配置一个NRF远端服务器组。        | NRF类型的远端服务器组只能配置一个。               | 停止新增NRF类型远端服务器组配置操作。请重新评估是否需要添加NRF远端服务器组。                           |
| 360178 | 只能配置一个该类型远端服务器组。        | SCP、SEPP、AUC、SSG类型的远端服务器组均只能配置一个。 | 停止新增SCP、SEPP、AUC、SSG类型远端服务器组配置操作。请重新评估是否需要添加SCP、SEPP、AUC、SSG远端服务器组。 |
| 100016 | 参数WEIGHT_RATE取值必须为0～100 | 该参数配置不符合取值范围要求。                   | 根据实际情况，请重新输入，确保输入的参数符合取值范围要求。                                       |
