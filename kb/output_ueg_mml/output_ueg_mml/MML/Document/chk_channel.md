# 检查Channel数据（CHK CHANNEL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于校验主CUS的Channel缓存数据与其他微服务的Channel缓存数据的一致性。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                              |
|:--------|:-------|:--------------------------------------------------------------------------------------------------|
| APPTYPE | 应用类型   | 可选必选说明：必选参数。 参数含义：用于请求系统按照指定的应用类型进行Channel缓存数据一致性校验。 取值范围：需要与LST APPTYPE的“应用类型”对应。 默认值：无。 配置原则：无。 |

## 使用实例

校验“应用类型”为“SUP-DUS”的主CUS的Channel缓存数据与其他微服务的Channel缓存数据的一致性。

```
CHK CHANNEL: APPTYPE="SUP-DUS";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。各输出项含义请参见表1 输出项解释的参数说明。

| 输出项名称      | 输出项解释                                                 |
|:-----------|:------------------------------------------------------|
| 应用类型       | 用于标识当前Channel所属的应用类型。                                 |
| POD名称      | 用于标识当前Channel所属的POD名称。                                |
| 服务名称       | 用于标识当前Channel所属的微服务名称。                                |
| 进程编号       | 用于标识当前Channel所属的POD中的进程编号。                            |
| 实例标识       | 用于标识当前Channel所属的微服务实例标识。                              |
| Channel一致性 | 用于标识当前CUS的Channel缓存数据是否与其他微服务的Channel缓存数据一致。 取值范围： 是否 |

该命令执行异常，会返回对应的错误码。常见错误码如表2 错误码列表所示。

|   错误码 | 错误码解释      | 原因分析               | 处理建议                                 |
|------:|:-----------|:-------------------|:-------------------------------------|
| 67822 | 指定的应用类型不存在 | 系统中没有该“应用类型”的数据信息。 | 执行LST APPTYPE命令查询到正确的“应用类型”后重新执行该命令。 |
| 67779 | 未知错误       | 系统内部处理错误。          | 联系华为技术工程师处理。                         |
