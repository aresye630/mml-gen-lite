# 查询例外对端NF（LST EXCPEERNF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询例外对端NF信息。

- 若需要查询所有例外对端NF的信息，不输入任何参数。
- 若需要查询某个例外对端NF的详细信息，请输入“IP地址”。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                |
|:------------|:-------|:--------------------------------------------------------------------------------------------------------------------|
| IPADDR      | IP地址   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个IP地址来查询例外对端NF信息；若不输入，则表示查询所有例外对端NF的信息。 取值范围：IPv4/IPv6地址类型，长度不超过40位的字符串。 默认值：无。 配置原则：无。 |
| DESCRIPTION | 描述     | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个描述来查询例外对端NF信息；若不输入，则表示查询所有的描述。 取值范围：长度不超过255位的字符串。 默认值：无。 配置原则：无。                      |

## 使用实例

查询所有例外对端NF信息。

```
LST EXCPEERNF:;
```

```
%%LST EXCPEERNF:;%%
RETCODE = 0  操作成功

操作结果如下
------------
IP地址          描述    
192.168.21.71   NULL          
192.168.43.248  NULL  
                            
(结果个数 = 2)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD EXCPEERNF**命令的参数说明。
