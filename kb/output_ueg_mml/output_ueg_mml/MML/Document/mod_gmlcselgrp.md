# 修改GMLC选择策略组(MOD GMLCSELGRP)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于修改GMLC选择策略组。

#### 注意事项

- 该命令执行后立即生效。
- 此配置涉及位置定位服务（LCS）特性（特性编号：WSFD-106401，license部件编码：LKV2LCS02），请在设置参数前使用**DSP LICENSE**命令确认对应特性license是否得到授权，执行**LST LICENSESWITCH**命令确认特性开关状态为“ENABLE(打开)”。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称        | 参数说明                                                                  |
|:----------|:------------|:----------------------------------------------------------------------|
| GMLCGRPID | GMLC选择策略组索引 | 可选必选说明：必选参数 参数含义：该参数在系统内唯一标识一个GMLC选择策略组。 数据来源：本端规划 取值范围：0~191 默认值：无   |
| DESC      | 描述          | 可选必选说明：可选参数 参数含义：该参数用于指定GMLC选择策略组的描述信息。 数据来源：本端规划 取值范围：0~32位字符串 默认值：无 |

#### 使用实例

修改索引为0的GMLC选择策略组的描述为“proviceA”。

MOD GMLCSELGRP: GMLCGRPID=0, DESC="proviceA";
