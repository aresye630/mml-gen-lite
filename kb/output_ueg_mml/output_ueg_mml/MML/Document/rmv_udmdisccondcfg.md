# 删除服务发现条件信息(RMV UDMDISCCONDCFG)

- 注意事项

- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会导致业务通信链路发生变更，造成业务呼损或系统崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除某一类型网元实例的服务发现条件信息。

## 注意事项

执行此删除命令会导致UDM和对端实体间的通信链路发生改变，导致大量链路突发重建等，从而影响业务。请操作员在执行该操作之前与华为技术支持确认。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                            |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------|
| NFTYPE | 网元类型   | 可选必选说明：必选参数 参数含义：标识服务发现条件信息数据的关键字段。用于指定对哪个类型的网元实例的服务发现条件信息进行删除。操作员可以使用LST UDMDISCCONDCFG命令查询获得。 取值范围： SCP：服务通信代理 默认值：无。 配置原则：无。 |

## 使用实例

删除所有SCP网元实例的服务发现条件信息:

```
RMV UDMDISCCONDCFG: NFTYPE=SCP;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
