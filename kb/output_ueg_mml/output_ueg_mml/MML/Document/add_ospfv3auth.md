# 创建OSPFv3认证配置（ADD OSPFV3AUTH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于在OSPFv3进程下创建认证。

**须知** 

本命令属于高危命令，如果OSPFv3进程认证与邻居配置不同，可能会使此进程的OSPFv3邻接关系中断，造成业务影响。推荐配置满足复杂度的密码，否则有安全隐患。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为8016。
- 创建OSPFv3进程认证，请确保和邻居认证配置相同，否则会导致邻接关系中断，影响业务。
- 只有执行ADD OSPFV3配置了OSPFV3进程后才能使用此命令。
- 当前支持配置的认证算法及密码长度均符合IETF标准规定。
- 配置的密码至少包含大写、小写、数字、特殊字符中的2种，并且长度不能小于8。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称           | 参数说明                                                                                                                                                          |
|:----------|:---------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROCID    | OSPFv3进程号      | 可选必选说明：必选参数 参数含义：OSPFv3进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 配置原则：OSPFv3进程必须已经存在。请使用LST OSPFV3命令查看可用的OSPFv3进程。                                    |
| AUTHKEYID | 验证字标识符         | 可选必选说明：必选参数 参数含义：验证字标识符。 数据来源：本端规划 取值范围：整数类型，取值范围为1～65535。 默认值：无                                                                                              |
| AUTHMODE  | 认证类型           | 可选必选说明：必选参数 参数含义：认证类型。 数据来源：本端规划 取值范围：枚举类型。 hmac-sha256：HMAC-SHA256密文验证模式。 默认值：无                                                                              |
| AUTHTEXT  | HMAC-SHA256 密码 | 可选必选说明：必选参数 参数含义：HMAC-SHA256 密码 。 数据来源：本端规划 取值范围：密码类型，输入长度范围为1～255。 默认值：无 配置原则： 字符不允许包括“？”和空格。配置密码时，使用明文格式，长度范围为1~255。配置的密码建议至少包含大写、小写、数字、特殊字符中的2种，并且长度不能小于8。 |

#### 使用实例

OSPFv3进程1下配置认证：

```
ADD OSPFV3AUTH:PROCID=1, AUTHKEYID=1, AUTHMODE=hmac-sha256,AUTHTEXT="*****";
```
