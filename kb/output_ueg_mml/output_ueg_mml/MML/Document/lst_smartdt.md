# 查询基于终端类型的DT限制（LST SMARTDT）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用网元：SGSN**

此命令用于查询基于终端类型的Direct Tunnel限制的配置。

#### 注意事项

- 无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                        |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UETYPE | 终端类型   | 可选必选说明：可选参数 参数含义：待查询的终端类型。 取值范围:“ANDROID(Android)”“BLACKBERRY(Black Berry)”“IOS(iOS)”“WINDOWS(Windows)”“CUSTOM_TYPE_1(自定义类型1)”“CUSTOM_TYPE_2(自定义类型2)”“CUSTOM_TYPE_3(自定义类型3)”“CUSTOM_TYPE_4(自定义类型4)”“CUSTOM_TYPE_5(自定义类型5)”“CUSTOM_TYPE_6(自定义类型6)”“CUSTOM_TYPE_7(自定义类型7)”“CUSTOM_TYPE_8(自定义类型8)”“CUSTOM_TYPE_9(自定义类型9)”“CUSTOM_TYPE_10(自定义类型10)”“CUSTOM_TYPE_11(自定义类型11)”“CUSTOM_TYPE_12(自定义类型12)”“UNKNOWN_TYPE(未知类型)” 默认值：无 |

#### 使用实例

查询基于终端类型的DT限制:

LST SMARTDT: UETYPE=WINDOWS;

```
%%LST SMARTDT: UETYPE=WINDOWS;%%
RETCODE = 0  操作成功。

输出结果如下
--------------
  终端类型  =  Windows
DT限制开关  =  开启
      描述  =  NULL
(结果个数 = 1)
---    END
```
