# 修改重定向配置信息(MOD REDIRECTCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改或调整配置数据库中的重定向配置信息。在该命令中，系统通过“重定向配置ID”参数来标识唯一一条重定向配置数据记录。

在该命令中，“重定向端口号”和“重定向协议类型”参数的配置需要与对端网元协商一致。

## 注意事项

无。

## 参数说明

| 参数标识                | 参数名称      | 参数说明                                                                                                    |
|:--------------------|:----------|:--------------------------------------------------------------------------------------------------------|
| REDIRECTCONFIGID    | 重定向配置ID   | 标识一条重定向配置记录的关键字段（其取值不能被修改），用于指定需要对哪一条重定向配置记录的参数进行修改或调整，操作员可以使用LST REDIRECTCFG命令查询获得。 取值范围：1～2048 默认值：无。 |
| REDIRECTDSTHOSTNAME | 重定向目的主机名  | 用于具体描述一个目的PCRF/PCF主机名。 取值范围：长度不超过128字节的字符串。 默认值：无。                                                      |
| REDIRECTORIHOSTNAME | 重定向发起方主机名 | 用于具体描述一个重定向发起方主机名，如： Gx会话发起端：PCEF/DRA。 Rx会话发起端：AF/DRA。 取值范围：长度不超过128字节的字符串。 默认值：无。                      |
| REDIRECTPORT        | 重定向端口号    | 用于指定当前重定向的端口号，需要与对端协商一致。 取值范围：0～65534 默认值：无。                                                            |
| REDIRECTPROTOCOL    | 重定向协议类型   | 指定当前重定向配置信息是SCTP或TCP协议类型的服务端配置，需要与对端协商一致。 SCTP(SCTP)TCP(TCP) 默认值：无。                                     |
| DESCRIPTION         | 描述        | 用于对重定向配置信息进行描述。 取值范围：长度不超过64字节的字符串。 默认值：无。                                                              |

## 使用实例

修改一条重定向配置信息。“重定向配置ID”为“2”，“重定向目的主机名”为“PCRF02”，“重定向发起方主机名”为“PCEF02”，“重定向端口号”为“8001”，“重定向协议类型”为“TCP”，“描述”为“1”。

```
MOD REDIRECTCFG: REDIRECTCONFIGID=2, REDIRECTDSTHOSTNAME="PCRF02", REDIRECTORIHOSTNAME="PCEF02", REDIRECTPORT=8001, REDIRECTPROTOCOL=TCP, DESCRIPTION="1";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释        | 原因分析                                       | 处理建议                                                                                           |
|------:|:-------------|:-------------------------------------------|:-----------------------------------------------------------------------------------------------|
| 57735 | 重定向配置信息已经存在。 | 输入的“重定向配置ID”在系统中已经存在。                      | 执行LST REDIRECTCFG命令查询已经存在的“重定向配置ID”，然后重新执行本命令确保要添加的“重定向配置ID”和已存在的“重定向配置ID”不相同。                 |
| 57736 | 重定向配置信息不存在。  | 输入的“重定向配置ID”在系统中不存在。                       | 执行LST REDIRECTCFG命令查询“重定向配置ID”是否存在，确认不存在后，执行本命令重新添加“重定向配置ID”。                                  |
| 57737 | 相同的配置数据已经存在。 | 输入的“重定向目的主机名”和“重定向发起方主机名”的相同的配置数据在系统中已经存在。 | 执行LST REDIRECTCFG命令查询已存在的重定向配置记录。再执行本命令重新输入参数“重定向目的主机名”和“重定向发起方主机名”的取值，确保这两个参数取值与系统中存在的记录不都相同。 |
