#### 命令功能

**适用网元：MME**

该命令用于查询Diameter虚拟本地实体信息。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                           |
|:--------|:-------|:---------------------------------------------------------------|
| LOINDEX | 本地实体索引 | 可选必选说明：可选参数 参数含义：该参数用于指定虚拟本地实体的索引，唯一标识一个本地实体。 取值范围：32~63 默认值：无 |

#### 使用实例

查询单个Diameter虚拟本地实体信息：

LST DMVLE: LOINDEX=32;

```
%%LST DMVLE: LOINDEX=32;%%
RETCODE = 0  操作成功。

操作结果如下
--------------
  本地实体索引  =  32
本地实体主机名  =  example.com
  本地实体域名  =  exaple.com
        产品名  =  MME
    本地实体名  =  DMVLE
(结果个数 = 1)
---    END
```
