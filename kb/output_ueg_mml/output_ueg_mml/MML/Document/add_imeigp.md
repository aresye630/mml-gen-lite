# 增加IMEI群组(ADD IMEIGP)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

此命令用于增加IMEI群组记录，为IMEI群组成员提供群组标识等信息，以群粒度进行业务策略控制。需要结合**ADD IMEIGPMEM**命令配置成员信息。

#### 注意事项

- 此命令最大记录数为50。
- 此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                  |
|:---------|:---------|:----------------------------------------------------------------------|
| IMEIGPID | IMEI群组标识 | 可选必选说明：必选参数 参数含义：该参数用于指定IMEI群组标识。 数据来源：本端规划 取值范围：1~50 默认值：无           |
| IMEIGPN  | IMEI群组名称 | 可选必选说明：可选参数 参数含义：该参数用于指定IMEI群组名称。 数据来源：本端规划 取值范围：0~255位字符串 默认值：noname |

#### 使用实例

增加一个IMEI群组，其群组名称为“iphone”，群组成员设备型号核准号码为35437906：

ADD IMEIGP: IMEIGPID=1, IMEIGPN="iphone";

ADD IMEIGPMEM: IMEIGPID=1, IMEITAC="35437906";
