# 增加本地PLMN(ADD HPLMN)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限

- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

此命令用于增加归属PLMN配置信息。

#### 注意事项

- 此命令执行后立即生效。
- 此命令最大记录数为128。
- 若MCC相同，MNC有效长度为2位和MNC有效长度为3位的记录，前两位不允许相同。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                     |
|:----------|:------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MCC       | 移动国家码       | 可选必选说明：必选参数 参数含义：该参数用于指定HPLMN的移动国家号码。 数据来源：整网规划 取值范围：3位十进制数 默认值：无 配置原则： “移动国家码”　+ “移动网号”在MVNONET、CONNECTPLMN和本表中唯一，参见ADD MVNONET和ADD CONNECTPLMN。                                                                                                                                                                                                                                                        |
| MNC       | 移动网号        | 可选必选说明：必选参数 参数含义：该参数用于指定HPLMN的移动网号码。 数据来源：整网规划 取值范围：位数为2或3的十进制数字 默认值：无 配置原则： “移动国家码”　+ “移动网号”在MVNONET、CONNECTPLMN和本表中唯一，参见ADD MVNONET和ADD CONNECTPLMN。                                                                                                                                                                                                                                                   |
| CC        | 国家码         | 可选必选说明：可选参数 参数含义：该参数用于指定HPLMN的国家码。 数据来源：整网规划 取值范围：位数为1～6的十进制数字 默认值：无                                                                                                                                                                                                                                                                                                                                     |
| MNOID     | MNO标识       | 可选必选说明：可选参数 参数含义：该参数用于指定MNO的标识。 前提条件：“MNOID”已增加，参见ADD MNO。 数据来源：整网规划 取值范围：0，128～254 默认值：0                                                                                                                                                                                                                                                                                                                |
| SM        | 是否允许SM业务    | 可选必选说明：可选参数 参数含义：该参数用于指定是否允许这个PLMN用户使用会话管理业务。 数据来源：整网规划 取值范围：“YES(允许)”“NO(不允许)” 默认值：“YES(允许)”                                                                                                                                                                                                                                                                                                            |
| MAXSMNUM  | 最大承载数       | 可选必选说明：条件可选参数 参数含义：该参数用于指定根据运营商业务规划对应的每个用户最多建立的承载个数。用户请求建立的承载个数不能超过该值，超过则会建立失败。 前提条件：该参数在“SM”参数设置为“YES(允许)”时生效。 数据来源：整网规划 取值范围：1～11 默认值：11                                                                                                                                                                                                                                                               |
| SMS       | 是否允许SMS业务   | 可选必选说明：可选参数 参数含义：该参数用于指定是否允许这个PLMN用户使用短消息业务。 数据来源：整网规划 取值范围：“YES(允许)”“NO(不允许)” 默认值：“YES(允许)”                                                                                                                                                                                                                                                                                                             |
| SMSCR     | 是否允许纠正短消息中心 | 可选必选说明：条件可选参数 参数含义：该参数用于指定是否允许这个HPLMN用户使用纠正短消息中心业务。 前提条件：该参数在“SMS”参数设置为“YES(允许)”时生效。 数据来源：整网规划 取值范围：“NO(不允许)”“YES(允许)” 默认值：“NO(不允许)”                                                                                                                                                                                                                                                                     |
| SMSCT     | 纠正后的短消息中心   | 可选必选说明：条件必选参数 参数含义：该参数用于指定纠正后的短消息中心。 前提条件：该参数在“SMSCR”参数设置为“YES(允许)”时生效。 数据来源：整网规划 取值范围：1～15位十进制数字 默认值：无                                                                                                                                                                                                                                                                                                  |
| LCS       | 是否允许LCS业务   | 可选必选说明：可选参数 参数含义：该参数用于指定是否允许这个PLMN用户使用2G/3G的LCS业务。 数据来源：整网规划 取值范围：“YES(允许)”“NO(不允许)” 默认值：“YES(允许)”                                                                                                                                                                                                                                                                                                       |
| S5S8TYPE  | 协议类型        | 可选必选说明：可选参数 参数含义：该参数用于指定运营商在S5/S8口使用的协议类型。 数据来源：整网规划 取值范围：“GTP(GTP)”：表示S5/S8口使用GTP协议。“PMIP(PMIP)”：表示S5/S8口使用PMIP协议。 默认值：“GTP(GTP)”                                                                                                                                                                                                                                                                       |
| PLMNN     | 运营商名称       | 可选必选说明：可选参数 参数含义：该参数用于指定标识运营商名称。 数据来源：整网规划 取值范围：1～50位字符串 默认值：“noname”                                                                                                                                                                                                                                                                                                                                    |
| EMCBS     | 是否允许紧急呼叫业务  | 可选必选说明：可选参数 参数含义：该参数用于指定是否允许使用紧急呼叫业务。 数据来源：整网规划 取值范围：“NO(不允许)”“YES(允许)” 默认值：“YES(允许)” 配置原则：如果不支持VOLTE紧急呼叫业务，期望在CS域做紧急呼叫时，建议配置为“NO（不允许）”。                                                                                                                                                                                                                                                                 |
| EMGCNUMSW | 紧急号码下发开关    | 可选必选说明：可选参数 参数含义：该参数用来控制系统在给本网用户发送Attach Accept、TAU Accept、RAU Accept消息时，是否将紧急号码携带在消息中发送给UE。 数据来源：整网规划 取值范围：“ON(开启)”“OFF(关闭)” 默认值：“ON(开启)” 配置原则：当本参数设置为“ON(开启)”时，系统将在Attach Accept、TAU Accept、RAU Accept消息中给本网用户发送紧急号码列表。其中，紧急号码列表来源于ADD EMGCNUM中的配置，如果ADD EMGCNUM没有配置，则不下发紧急号码。  说明： 紧急号码下发还受其它配置（SET MMFUNC中EMNUM参数、DWORD_EX6 BIT10、DWORD_EX6 BIT11、DWORD_EX33 BIT13、DWORD_EX33 BIT12）控制，共同决策是否下发紧急号码。 |

#### 使用实例

增加一条移动国家号为460、移动网号为00的HPLMN，国家码为86的记录，MNO标识为128，是否允许紧急呼叫业务为YES：

ADD HPLMN: MCC="460", MNC="00", CC="86", MNOID=128, SM=YES, SMS=YES, PLMNN="noname", EMCBS=YES;
