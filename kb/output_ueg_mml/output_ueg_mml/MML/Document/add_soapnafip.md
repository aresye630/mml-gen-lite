# 增加SOAP客户端IP地址(ADD SOAPNAFIP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在系统中增加一条SOAP客户端的IP地址的配置信息。

该命令的使用场景：BSF与认证&转发AP间通过Zn接口交互时，如果使用SOAP协议，需要添加SOAP客户端的IP地址的配置信息。如果不添加SOAP客户端的IP的配置信息，则系统默认不认证客户端的IP接入信息；如果添加了SOAP客户端的IP配置信息，则系统中只有配置信息被添加进去的IP才可以接入，以达到安全接入控制功能。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

如果系统中本来没有配置任何客户端IP信息，新添加一条客户端IP配置信息，会导致其他未配置的SOAP客户端IP无法接入系统。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                         |
|:-----------|:---------|:-----------------------------------------------------------------------------------------------------------------------------|
| ID         | ID       | 可选必选说明：必选参数 用于标识待添加的SOAP客户端的IP地址标识，建议采用升序添加。 取值范围：0～255 默认值：无.                                                               |
| ADDRTYPE   | IP地址类型   | 可选必选说明：必选参数 用于标识待添加的SOAP客户端的IP地址类型。 取值范围：IPV4(IPV4)IPV6(IPV6) 默认值：无。                                                         |
| NETWORKSV4 | IPv4网段   | 可选必选说明：条件必选参数 仅当该命令的参数“IP地址类型”取值为“IPV4(IPV4)”时该参数有效。用于标识SOAP客户端的IPv4地址网段。 取值范围：有效的IPv4地址。 默认值：无。                             |
| MASKV4     | IPv4子网掩码 | 可选必选说明：条件必选参数 仅当该命令的参数“IP地址类型”取值为“IPV4(IPV4)”时该参数有效。用于标识SOAP客户端的IPv4地址的子网掩码。 取值范围：有效的IPv4地址。 默认值：无。                          |
| NETWORKSV6 | IPv6网段   | 可选必选说明：条件必选参数 仅当该命令的参数“IP地址类型”取值为“IPV6(IPV6)”时该参数有效。用于标识SOAP客户端的IPv6地址网段。 取值范围：有效的IPv6地址。 默认值：无。                             |
| PRELENV6   | IPv6前缀长度 | 可选必选说明：条件必选参数 仅当该命令的参数“IP地址类型”取值为“IPV6(IPV6)”时该参数有效。用于标识SOAP客户端的IPv6地址网段的前缀长度。 取值范围：0~128 默认值：无。                             |
| IPDESC     | IP描述     | 可选必选说明：条件可选参数 仅当该命令的参数“IP地址类型”取值为“IPV4(IPV4)”或“IPV6(IPV6)”时该参数有效。用于描述该IP地址用途的一些说明性文字，建议取有实际意义的对应描述。 取值范围：长度不超过64的字符串。 默认值：无。 |

## 使用实例

1. 为系统添加一个SOAP客户端IPv4地址。

   ```
   ADD SOAPNAFIP: ID=1, ADDRTYPE=IPV4, NETWORKSV4="192.168.10.0", MASKV4="255.255.255.255", IPDESC="soap client ip1";
   ```
2. 为系统添加一个SOAP客户端IPv6地址。

   ```
   ADD SOAPNAFIP: ID=2, ADDRTYPE=IPV6, NETWORKSV6="2001:DB8:1::0", PRELENV6=12, IPDESC="soap client ip2";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                      | 原因分析                                                           | 处理建议                                                                                       |
|-------:|:---------------------------|:---------------------------------------------------------------|:-------------------------------------------------------------------------------------------|
| 360267 | 网段与子网掩码不能重复。               | 输入的参数“IPv4网段”与“IPv4子网掩码”的组合或者“IPv6网段”与“IPv6前缀长度”的组合与系统中已定义的重复。 | 执行LST SOAPNAFIP命令查询后，重新输入参数“IPv4网段”与“IPv4子网掩码”的组合或者“IPv6网段”与“IPv6前缀长度”的组合，确保其取值与查询结果中的不重复。 |
| 360268 | IPv4网段255.255.255.255是非法值。 | 参数“IPv4网段”不能取值为“255.255.255.255”。                              | 重新输入“IPv4网段”参数，确保其取值不为“255.255.255.255”。                                                   |
| 360258 | 当前ID记录已存在。                 | 参数“ID”的取值必须唯一。                                                 | 执行LST SOAPNAFIP命令查询后，重新输入“ID”参数，确保其取值唯一。                                                   |
| 360269 | IPv6网段全F是非法值。              | 参数“IPv6网段”不能取值为“FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF”。      | 重新输入“IPv6网段”参数，确保其取值不为“FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF”。                           |
