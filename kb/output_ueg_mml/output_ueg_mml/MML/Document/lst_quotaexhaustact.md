# 查询配额耗尽后的动作（LST QUOTAEXHAUSTACT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SMF**

该命令用于查询配额耗尽后的动作。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                              |
|:------------|:---------|:------------------------------------------------------------------------------------------------------------------|
| CCTMPLTNAME | 融合计费模板名称 | 可选必选说明：可选参数  参数含义：该参数用于指定融合计费模板的名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。不区分大小写。  默认值：无  配置原则：  该参数使用ADD CCT命令配置生成。 |

## 使用实例

查询融合计费模板名为global的在线RG配额耗尽后动作为阻塞业务：

```
%%LST QUOTAEXHAUSTACT: CCTMPLTNAME="global";%%
RETCODE = 0  操作成功

结果如下
--------
    融合计费模板名称  =  global
在线RG配额耗尽后动作  =  阻塞业务，使业务不能继续进行
      重定向IPv4地址  =  0.0.0.0
      重定向IPv6地址  =  ::
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称       | 输出项解释                         |
|:------------|:------------------------------|
| 融合计费模板名称    | 该参数用于指定融合计费模板的名称。             |
| 在线RG配额耗尽后动作 | 该参数用于指定在线RG配置耗尽后动作。           |
| 重定向IPv4地址   | 该参数用于指定在线RG配额耗尽后重定向动作的IPv4地址。 |
| 重定向IPv6地址   | 该参数用于指定在线RG配额耗尽后重定向动作的IPv6地址。 |
