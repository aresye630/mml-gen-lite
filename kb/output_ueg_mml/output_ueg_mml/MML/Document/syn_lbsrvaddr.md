# CSLB向VNRS同步服务实例地址（SYN LBSRVADDR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

全量模式可能会影响正常服务实例地址下发，请谨慎使用并联系华为技术支持协助操作。

当CSLB和VNRS之间服务实例地址数量不一致的时候，通过这个命令可以将CSLB上的服务实例地址同步到VNRS上。

#### 注意事项

- 采用“全量同步”模式同步服务实例地址，可能会造成服务实例地址下发拥塞，导致业务流程失败，建议在VNF的业务低峰期执行，例如凌晨2点。
- 采用“全量同步”模式同步服务实例地址后，最多需要等待10分钟，同步才能完成，之后才能通过**DSP SRVADDRNUM**核查。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称       | 参数说明                                                                                                                                                                               |
|:----------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SRVVNFCID | 业务VNFCID   | 可选必选说明：必选参数 参数含义：该参数用于指定业务VNFC的唯一标识，通过在窗口下执行LST NODE获得，所得NODEID即为服务VNFC ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0~4294967295。 默认值：无                                                           |
| SYNCMODE  | 服务实例地址同步模式 | 可选必选说明：必选参数 参数含义：该参数用于指定CSLB向VNRS同步服务实例地址的模式。 数据来源：本端规划 取值范围：枚举类型“SINGLEROUTE（单服务实例地址同步）”“ALLROUTE（全量同步）” 默认值：无 配置原则：只有当服务实例地址实际存在时，才能使用单点同步服务实例地址功能，服务实例地址可通过DSP SRVIP查询获取。       |
| SRVINSTID | 服务实例ID     | 可选必选说明：条件必选参数 参数含义：该参数用于指定服务实例地址归属的服务实例ID。服务实例ID可以通过DSP LBSRVINST查询获取。 配置原则：该参数在“SYNCMODE（服务实例地址同步模式）”参数配置为“单服务实例地址同步”后生效。 数据来源：本端规划 取值范围：整数类型，取值范围为0~4294967295。 默认值：无            |
| IPTYPE    | IP地址类型     | 可选必选说明：条件必选参数 参数含义：该参数用于指定同步服务实例地址的IP地址类型。IP地址类型可以通过DSP SRVIP查询IPTYPE字段获取。 配置原则：该参数在“SYNCMODE（服务实例地址同步模式）”参数配置为“单服务实例地址同步”后生效。 数据来源：本端规划 取值范围：枚举类型“IPV4”“IPV6” 默认值：无               |
| DSTIPV4   | 目的IPv4地址   | 可选必选说明：条件必选参数 参数含义：该参数用于指定同步的IPv4地址。目的IPv4地址可以通过DSP SRVIP查询DSTIPV4字段获取。 配置原则：该参数在“IPTYPE（IP地址类型）”参数配置为“IPV4”后生效。 数据来源：本端规划 取值范围：0.0.0.0-255.255.255.255 默认值：无                      |
| DSTIPV6   | 目的IPv6地址   | 可选必选说明：条件必选参数 参数含义：该参数用于指定同步的IPv6地址。目的IPv6地址可以通过DSP SRVIP查询DSTIPV6字段获取。 配置原则：该参数在“IPTYPE（IP地址类型）”参数配置为“IPV6”后生效。 数据来源：本端规划 取值范围：::-FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无   |
| IPV4MASK  | IPv4掩码     | 可选必选说明：条件必选参数 参数含义：该参数用于指定服务实例地址IPv4掩码。IPv4掩码可以通过DSP SRVIP查询IPV4MASK字段获取。 配置原则：该参数在“IPTYPE（IP地址类型）”参数配置为“IPV4”后生效。 数据来源：本端规划 取值范围：0.0.0.0-255.255.255.255 默认值：无                    |
| IPV6MASK  | IPv6掩码     | 可选必选说明：条件必选参数 参数含义：该参数用于指定服务实例地址IPv6掩码。IPv6掩码可以通过DSP SRVIP查询IPV6MASK字段获取。 配置原则：该参数在“IPTYPE（IP地址类型）”参数配置为“IPV6”后生效。 数据来源：本端规划 取值范围：::-FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 |
| VPNNAME   | VPN名称      | 可选必选说明：条件必选参数 参数含义：该参数用于同步服务实例地址的VPN名称。VPN名称可以通过DSP SRVIP查询VPNNAME字段获取 配置原则：该参数在“SYNCMODE（服务实例地址同步模式）”参数配置为“单服务实例地址同步”后生效。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0~31。 默认值：无                 |

#### 使用实例

采用单服务实例地址同步模式，业务服务ID为4，服务实例同步模式选“单服务实例地址同步”模式，服务实例ID为1，IP类型选IPV4，服务实例地址通过DSP SRVIP命令查询获取，执行同步服务实例地址命令结果如下：

`SYN LBSRVADDR: SRVVNFCID=4, SYNCMODE=SINGLEROUTE, SRVINSTID=1, IPTYPE=IPV4, DSTIPV4="192.168.100.1", IPV4MASK="255.255.255.0", VPNNAME="_public_";`
