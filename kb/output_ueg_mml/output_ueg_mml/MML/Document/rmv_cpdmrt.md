# 删除Diameter域路由配置(RMV CPDMRT)

#### 命令功能

**须知** 

删除Diameter域路由配置将导致通过该域路由连接的对端的Diameter链路发生中断。

**适用网元：SGSN、MME**

该命令用于删除一条Diameter域路由。

#### 注意事项

- 该命令执行后立即生效。
- 删除该域路由，将导致通过该域路由连接的对端的Diameter链路发生中断。
- 如果Diameter域路由满足以下两个条件：
  1. Diameter路由组引用该域路由索引；
  2. 相同域路由索引的记录只有1条；

  则该记录不能删除。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                          |
|:---------|:-------|:------------------------------------------------------------------------------------------------------------------------------|
| ROUTEIDX | 路由索引   | 可选必选说明：必选参数 参数含义：该参数用于指定Diameter域路由索引。 取值范围：0~2047 默认值：无  说明： 可以通过LST CPDMRT命令查看已有配置，确认所要删除的Diameter域路由的索引。                   |
| PEERIDX  | 对端实体索引 | 可选必选说明：可选参数 参数含义：该参数用于指定对等端索引，用于标识目的对等端。 前提条件：在“MML命令行-UEG”窗口上执行命令ADD CPDMPE设置此参数。 取值范围：0~639 默认值：无  说明： 一个路由索引最多可配置10个对等端索引。 |

#### 使用实例

删除索引号为0的Diameter域路由：

RMV CPDMRT: ROUTEIDX=0;
