# 恢复FUI增强参数（RTR FUIENRICHMENT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于恢复FUI增强参数。控制处理重定向动作，当URL是由OCS下发的FUI URL时，可根据配置判断是否绑定重定向携带信息名称。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

无。

#### 使用实例

假如运营商想要恢复默认配置，即报文中不携带URL等信息，使用此命令：

```
RTR FUIENRICHMENT:;
```
