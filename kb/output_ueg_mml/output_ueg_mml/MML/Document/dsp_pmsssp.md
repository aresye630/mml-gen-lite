# 查询策略管理服务未生效软参(DSP PMSSSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询PMS系统中未生效软参的信息，包括未生效软参名、未生效软参所属实例号、软参的修改值、生效值和默认值等信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询当前系统中所有未生效的软参。

```
DSP PMSSSP:;
```

```
%%DSP PMSSSP:;%%
RETCODE = 0    操作成功

操作结果如下:
-------------
实例名称                                   参数名               是否生效  参数值  生效值  软件参数默认值  
 
pms-ec8fa04b-2f15-11e8-9-1923066622-lfkn0  PCF支持语音全局数据  否        1       0       0               
pms-ec8fa04b-2f15-11e8-9-1923066622-s9t71  PCF支持语音全局数据  否        1       0       0               
(结果个数 = 2)
 
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义如表1。

| 参数名     | 用于描述未生效软参的软参名。 取值范围： VRM_PPMWORKMODE(PPM接口工作模式) VRM_PMWORKMODE(Pm接口工作模式) VRM_4AWORKMODE(4A接口工作模式) VRM_CLIMODIFYCTRL(CLI接口业务反约束修改开关) VRM_MAXQUOTANUMPERSERVICE(SERVICE最多可关联的配额数) VRM_PMSCRLPOLICY(PMS数字证书CRL处理策略)VRM_CHKSOAPUSERSWITCH(检查SOAP服务端用户账号开关)VRM_CLIWORKMODE(CLI接口工作模式)VRM_SETPMSDOMAIN(设置PMS WEBServer的domain参数)VRM_PMSOPTLOGSW(PMS操作日志是否周期性记录到本地文件)VRM_VOLTEGLOBALDATA(PCF支持语音全局数据)VRM_PMSSFTPCLIENTACSWITCH(PMS SFTP客户端算法兼容开关)VRM_PMSCHKINVALIDCH（PMS不可见字符检查开关）VRM_MAXSRVZONENUMPERAREA(小区可归属最大服务区个数) 详细信息请参考产品手册的“软件参数 > UPCF软件参数 > PMS系统软参”。  说明： 以下软参在当前版本已经废弃： VRM_PPMWORKMODE(PPM接口工作模式) |
| 是否生效    | 用于描述该软参是否生效。若软参未生效，请参考产品手册的“PMS系统软参”，查看软参的生效方式。 取值范围： 是 否                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
