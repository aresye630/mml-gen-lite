# 添加HTTP链路测量对象(ADD HTTPLINKOBJ)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于增加一条HTTP链路测量对象记录。

该命令的使用场景：当需要统计某条HTTP链路接收、发送消息数的性能指标时，可使用本命令增加对应HTTP链路的测量对象，系统会创建性能测量“基于链路的HTTP链路性能测量”。

- 对于HTTP服务端链路：先执行**DSP HLBPEERL**命令查询服务端链路信息，然后执行本命令增加对应HTTP服务端链路的测量对象。
- 对于HTTP客户端链路：先执行**LST PEERNF**命令查询对端信息，然后执行**DSP HLBHTTPCLINK**命令查询对应对端的HTTP客户端链路信息，再执行本命令增加对应HTTP客户端链路的测量对象。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                            |
|:----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| WORKMODE  | 工作模式   | 可选必选说明：必选参数 参数含义：用于指定HTTP链路的工作模式。 取值范围： SERVER(服务端)CLIENT(客户端) 默认值：无。 配置原则：无。                                                                                                   |
| LOCALIP   | 本端IP地址 | 选必选说明：必选参数 参数含义：用于指定HTTP链路的本端IP地址。 取值范围：IPv4地址/IPv6地址 默认值：无。 配置原则：当IP地址类型为IPv6地址时，配置该参数时需要将IP地址当中的“:”替换为“-”，字母不支持小写，且不支持自动补0。IPv6地址配置示例：FC00-0000-0000-4007-0156-0110-0006-0123 |
| LOCALPORT | 本端端口   | 选必选说明：必选参数 参数含义：用于指定HTTP链路的本端端口。 取值范围：0~65535 默认值：无。 配置原则：无。                                                                                                                    |
| PEERIP    | 对端IP地址 | 选必选说明：必选参数 参数含义：用于指定HTTP链路的对端IP地址。 取值范围：IPv4地址/IPv6地址 默认值：无。 配置原则：当IP地址类型为IPv6地址时，配置该参数时需要将IP地址当中的“:”替换为“-”，字母不支持小写，且不支持自动补0。IPv6地址配置示例：FC00-0000-0000-4007-0156-0110-0006-0123 |
| PEERPORT  | 对端端口   | 选必选说明：必选参数 参数含义：用于指定HTTP链路的对端端口。 取值范围：0~65535 默认值：无。 配置原则：无。                                                                                                                    |

## 使用实例

增加一条HTTP链路测量对象记录。“工作模式”为“CLIENT(客户端)”，“本端IP地址”为“10.194.39.220”，“本端端口”为“40022”，“对端IP地址”为“10.195.39.221”，对端端口为“10501”。

```
ADD HTTPLINKOBJ: WORKMODE=CLIENT, LOCALIP="10.194.39.220", LOCALPORT=40022, PEERIP="10.195.39.221", PEERPORT=10501;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如下表1所示。

|   错误码 | 消息解释     | 原因分析                        | 处理建议                                    |
|------:|:---------|:----------------------------|:----------------------------------------|
| 58143 | IP地址非法。  | 输入的“本端IP地址”、“对端IP地址”参数值不合法。 | 重新执行本命令，确保输入的IP地址合法。                    |
| 58144 | 已存在相同记录。 | 增加的HTTP链路测量对象在系统中已存在记录。     | 重新执行本命令，确保要增加的记录和系统中已存在的记录的所有参数取值不完全相同。 |
