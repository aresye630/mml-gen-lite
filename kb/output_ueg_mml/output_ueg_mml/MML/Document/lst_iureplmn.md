#### 命令功能

**适用网元：SGSN**

该命令用于查询3G重定向PLMN。

#### 注意事项

- 此命令执行后立即生效。
- 此命令不对移动虚拟网络运营商生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询3G重定向PLMN。

LST IUREPLMN:;

```
%%LST IUREPLMN:;%%
RETCODE = 0  操作成功。

输出结果如下
--------------
  移动国家码 =  460
  移动国家码 =  05
(结果个数 = 1)

---    END
```
