# 显示指定的ARP-REPLY表项（DSP SFEARPREPLY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示指定资源单元的ARP-REPLY表项。

#### 注意事项

该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                            |
|:------------|:-------|:----------------------------------------------------------------------------------------------------------------|
| DESTINATION | 目的IP地址 | 可选必选说明：必选参数 参数含义：该参数用于指定目的IP地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无                                                  |
| PORTNUM     | 目的端口号  | 可选必选说明：必选参数 参数含义：该参数用于指定目的端口号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无                                          |
| VLAN        | VLAN编号 | 可选必选说明：必选参数 参数含义：该参数用于指定VLAN编号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无                                         |
| RUNAME      | RU名称   | 可选必选说明：必选参数 参数含义：该参数用于指定资源单元名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。区分大小写。 默认值：无 配置原则： 区分大小写，不支持空格。使用DSP RU查看RU名称。 |

#### 使用实例

显示指定资源单元的ARP-REPLY报文转发情况：

```
DSP SFEARPREPLY: DESTINATION="192.168.1.1", PORTNUM=4, VLAN=98, RUNAME="VNODE_VNRS_VNFC_IPU_0064";
```
