# NFVI分批升级恢复（OPR NFVIUPDRECV）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于NFVI分批升级过程失败恢复。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                       |
|:----------|:-------|:-----------------------------------------------------------------------------------------------------------|
| OPER_MODE | 操作模式   | 可选必选说明：可选参数  参数含义：操作模式类型。  数据来源：本端规划 取值范围： Recovery（升级正常结束恢复）ForceRecovery（系统异常强制恢复）  默认值：Recovery  配置原则：无 |
| POD_NAME  | Pod名称  | 可选必选说明：可选参数  参数含义：Pod名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~1024。  默认值：无  配置原则：无                              |

## 使用实例

- NFVI分批升级恢复。

  ```
  %%OPR NFVIUPDRECV: OPER_MODE=Recovery;%%
  ```
- NFVI分批升级强制恢复。

  ```
  %%OPR NFVIUPDRECV: OPER_MODE=ForceRecovery;%%
  ```
