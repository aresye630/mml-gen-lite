# 查询无线路由的路由统计信息（DSP WLRROUTESTAT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询无线路由的路由统计信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                             |
|:--------|:--------|:-------------------------------------------------------------------------------------------------|
| AFTYPE  | 地址族类型   | 可选必选说明：必选参数 参数含义：该参数用于指定地址族类型。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。ipv6unicast：IPv6单播。 默认值：无 |
| VRFNAME | VPN实例名称 | 可选必选说明：可选参数 参数含义：该参数用于表示VPN名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。区分大小写。 默认值：无                     |

#### 使用实例

查询无线路由的路由统计信息：

```
DSP WLRROUTESTAT: AFTYPE=ipv4unicast;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
VPN实例名称          路由类型    路由总数    活跃路由数

_public_             WLR_UD       4           4
_public_             WLR_BH       4           4
_public_             WLR_SP       1           1
(结果个数 = 3)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                                                                              |
|:--------|:-----------------------------------------------------------------------------------|
| VPN实例名称 | 用于表示VPN名字。                                                                         |
| 路由类型    | 该参数用于表示路由类型，包括： WLR_BH：无线黑洞路由。WLR_UD：无线用户下行路由。WLR_SP：无线信令路由。wlr_gbh：带Gif接口的无线黑洞路由。 |
| 路由总数    | 用于表示路由总数。                                                                          |
| 活跃路由数   | 用于表示路由活跃数。                                                                         |
