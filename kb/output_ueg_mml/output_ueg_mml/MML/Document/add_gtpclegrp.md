# 增加GTP-C本地实体组（ADD GTPCLEGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C、AMF、GGSN**

该命令用于增加一个GTP-C本地实体组，一个实体组内可以包含多个实体，便于管理。实体组配合ADD GTPCLEGRPMEM使用生成WLR路由。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入32条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                         |
|:--------|:-------|:---------------------------------------------------------------------------------------------|
| GROUPID | 组号     | 可选必选说明：必选参数  参数含义：该参数用于指定GTP-C本地实体所属的组。  数据来源：本端规划  取值范围：整数类型，取值范围是0~31。  默认值：无  配置原则：无      |
| DESC    | 描述信息   | 可选必选说明：可选参数  参数含义：该参数用于指定GTP-C本地实体组的描述信息。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~32。  默认值：无  配置原则：无 |

## 使用实例

增加一个组号为0的GTP-C本地实体组：

```
ADD GTPCLEGRP:GROUPID=0,DESC="for s11";
```
