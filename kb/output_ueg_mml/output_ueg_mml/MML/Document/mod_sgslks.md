# 修改SGs链路集(MOD SGSLKS)

- 命令功能
- 注意事项
- 本地用户权限

#### 命令功能

**适用网元：MME**

此命令用于修改SGs链路集名称。

#### 注意事项

- 此命令执行后立即生效。
- 此配置涉及“基于CSFB的语音业务”特性（特性编号：WSFD-102301，License部件编码：LKV2CSFBGU02），执行命令请使用**DSP LICENSE**命令确认对应特性license是否得到授权，执行**LST LICENSESWITCH**命令确认特性开关状态为“ENABLE(打开)”。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                        |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------|
| LSX    | 链路集索引  | 可选必选说明：必选参数 参数含义：待修改链路集的索引。 数据来源：本端规划 取值范围：0~255 默认值：无                                                                      |
| LSN    | 链路集名   | 可选必选说明：可选参数 参数含义：该参数用于指定链路集的名称。 数据来源：整网规划 取值范围：1~50位字符串 默认值：无  说明： 该参数用于区分不同的链路集，也可以直接使用MSC/VLR名来标识。如果不输入该参数，则表示不修改该链路集的名称。 |

#### 使用实例

修改一个链路集的“链路集名”为“VLR808”，该链路集的“链路集索引”为“0”：

MOD SGSLKS: LSX=0, LSN="VLR808";
