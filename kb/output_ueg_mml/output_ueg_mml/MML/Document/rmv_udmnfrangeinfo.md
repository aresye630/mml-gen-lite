# 删除网元号段信息(RMV UDMNFRANGEINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成号段信息不一致，从而导致业务失败，MML批处理时会造成CPU波动，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除一个网元的号段信息。

## 注意事项

- 删除数据时，如果指定“索引”所在组的“组名称”已在**ADD UDMNFINFO**的“SUPI号段组”、“GPSI号段组”或“外部组标识范围组”中引用，且是所在组下最后一条记录，是则不允许删除。
- 删除数据成功，如果指定“索引”所在组的“组名称”已在**ADD UDMNFINFO**的“SUPI号段组”、“GPSI号段组”或“外部组标识范围组”中引用，且**ADD UDMNFINFO**的“网元信息标识”在**ADD UDMNFSRV**命令的“网元信息标识”中引用，且**ADD UDMNFSRV**命令中的“网元状态”为“REGISTERED”时，将按照**ADD UDMNFSRV**命令中“更新方式”参数中指定的更新模式立即向NRF发送更新请求。
- 当凌晨自动校验或执行**VRY NRFDATA**命令手动校验NRFClient内存数据时，在校验该MML命令的过程中，无法执行该命令，若运行该命令，则提示“360155 该MML数据正在校验中，请稍后再试”。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                         |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GRPNAME | 组名称    | 可选必选说明：必选参数 参数含义：用于标识一条网元号段信息数据记录的关键字段之一。用于指定根据哪个组名称来删除网元号段信息，操作员可通过LST UDMNFRANGEINFO命令查询获得。 取值范围：长度不超过32的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：该参数和“索引”参数组成全局唯一对象关键字段。 |
| INDEX   | 索引     | 可选必选说明：必选参数 参数含义：用于标识一条网元号段信息数据记录的关键字段之一。用于指定根据哪个索引来删除网元号段信息，操作员可通过LST UDMNFRANGEINFO命令查询获得。 取值范围：1~100000。 默认值：无。 配置原则：该参数和“组名称”参数组成全局唯一对象关键字段。                             |

## 使用实例

删除号段信息，“组名称”为“supi-group-01”，“索引”为“1”：

```
RMV UDMNFRANGEINFO: GRPNAME="supi-group-01", INDEX=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释             | 原因分析                                                      | 处理建议                                    |
|-------:|:------------------|:----------------------------------------------------------|:----------------------------------------|
|    505 | 当前操作的配置数据不存在      | “索引”不存在。                                                  | 使用LST UDMNFRANGEINFO命令查询获得“索引”，确保其值已存在。 |
| 360044 | 当前记录在其他命令中引用，无法删除 | 该号段的“组名称”被ADD UDMNFINFO的“SUPI号段组”、“GPSI号段组”或“外部组标识范围组”引用。 | 先删除网元信息对该号段所属组的引用，再删除该号段组。              |
| 360155 | 该MML数据正在校验中，请稍后再试 | NRFClient内存数据校验正在进行中，对该命令的校验结束后才可执行该命令。                   | 请稍后重试。                                  |
