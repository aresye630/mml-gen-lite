# 删除AMF缓存信息（RMV CACHEAMF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除一条或者全部AMF缓存信息。

- 若要删除全部AMF缓存信息，请不要输入任何参数。
- 若要删除某条AMF缓存信息，请输入“服务ID”及“实例ID”参数，或者“服务ID”及“实例ID”与其他参数的组合。

## 注意事项

- “服务ID”和“实例ID”要么同时输入，要么都不输入。
- 当**MOD UDMSOFTPARA**命令中的“UDMConfig”对应的“MaxCacheAMF（UDM最大AMF缓存记录数）”参数取值为“0”时，通过**RMV CACHEAMF**命令删除AMF缓存信息返回空值。
- DCS等待每个UDM超时时间3s，超过3s认为删除失败。
- 通过该命令仅能删除AMF缓存信息，不能删除服务发现数据。
- 如果通过**DSP CACHEAMF**命令查询出来的“服务发现结果”为“是”且UDM访问AMF的状态为NOK，当通过本命令删除AMF缓存数据后，再次通过**DSP CACHEAMF**命令查询，UDM访问AMF的状态将更新为OK。

## 参数说明

| 参数标识       | 参数名称       | 参数说明                                                                                                                                             |
|:-----------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICEID  | 服务ID       | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个服务来删除AMF缓存信息；若不输入，则表示删除所有服务的AMF缓存信息。 取值范围：0~4294967295 默认值：无 配置原则：无。                                                  |
| INSTANCEID | 实例ID       | 可选必选说明：条件必选参数 参数含义：用于指示系统按照哪个实例来删除AMF缓存信息；若不输入，则表示删除所有实例的AMF缓存信息。 取值范围：0~4294967295。 默认值：无 配置原则：当“服务ID”输入时该参数必须输入。                               |
| GUAMI      | 全局唯一的AMF标识 | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个AMF标识来删除AMF缓存信息；若不输入，则表示删除所有AMF标识的AMF缓存信息。 取值范围：长度不超过14位的字符串。仅可输入0~9、A~F、a~f、中划线（-）和NA，NA表示GUAMI为空的记录。 默认值：无。 配置原则：无。 |
| FQDN       | 全量域名       | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个域名来删除AMF缓存信息；若不输入，则表示删除所有域名的AMF缓存信息。 取值范围：长度不超过255位的字符串。仅可输入数字、字母、中划线（-）、下划线（_）和英文点（.）。 默认值：无。 配置原则：无。                |

## 使用实例

1. 删除所有AMF缓存信息。

   ```
   RMV CACHEAMF: CONFIRM=Y;
   ```

   ```
   %%RMV CACHEAMF: CONFIRM=Y;%%
   RETCODE = 0  操作成功

   操作结果如下
    服务ID        实例ID       是否已删除
    3005664884    538653835    是 
   (结果个数 = 1)
   ---    END
   ```
2. 删除“服务ID”为“3005664884”，“实例ID”为“538653835”的AMF缓存信息。

   ```
   RMV CACHEAMF: SERVICEID=3005664884, INSTANCEID=538653835, CONFIRM=Y;
   ```

   ```
   %%RMV CACHEAMF: SERVICEID=3005664884, INSTANCEID=538653835, CONFIRM=Y;%%
   RETCODE = 0  操作成功

   操作结果如下
                   服务ID = 3005664884
                   实例ID = 538653835
               是否已删除 = 是

   (结果个数 = 1)
   ---    END
   ```
