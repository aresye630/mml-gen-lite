# 查询UPCC全局数据容量（LST UPCCPLYCAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令是维护类命令，用于查询UPCC全局数据的最大记录数。

- 如果需要查询全部UPCC全局数据的最大记录数，请不要输入任何参数。
- 如果需要查询某个UPCC全局数据的最大记录数，请依据参数说明输入查询条件。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NAME   | 全局数据名称 | 可选必选说明：可选参数 参数含义：用于指定需要查询最大记录数的UPCC全局数据对象。 取值范围： CONDITIONGROUP(CONDITIONGROUP)：条件组CONDITION(CONDITION)：条件ACTIONGROUP(ACTIONGROUP)：动作组NOTIFICATION(NOTIFICATION)：消息通知RULE(RULE)：规则RULECONDGRP(RULECONDGRP)：规则和条件组的绑定关系POLICY(POLICY)：策略POLICYTRIGGER(POLICYTRIGGER)：策略和触发器的绑定关系POLICYRULE(POLICYRULE)：策略和规则的绑定关系QUOTA(QUOTA)：配额SERVICE(SERVICE)：业务SERVICEQUOTA(SERVICEQUOTA)：业务和配额的绑定关系AREA(AREA)：区域SRVZONEAUXAREA(SRVZONEAUXAREA)：服务区和辅区域的绑定关系MESSAGETPL(MESSAGETPL)：消息模板ACTIONELEMENT(ACTIONELEMENT)：动作元素 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询所有的UPCC全局数据容量的配置。

   ```
   LST UPCCPLYCAP:;
   ```

   ```
   %%LST UPCCPLYCAP:;%%
   RETCODE = 0  操作成功

   结果如下:
   -------------
    全局数据名称              全局数据容量        默认值     

    条件组                    20480               20480
    条件                      30720               30720
    动作组                    1024                1024
    消息通知                  4096                4096
    规则                      20480               20480
    规则和条件组的绑定关系    65536               65536
    策略                      4096                4096
    策略和触发器的绑定关系    47104               47104
    策略和规则的绑定关系      65536               65536
    配额                      4096                4096
    业务                      4096                4096
    业务和配额的绑定关系      8192                8192
    区域                      130000              130000
    服务区和辅区域的绑定关系  1000                1000
    消息模板                  1024                1024
    动作元素                  12288               12288
    (结果个数 = 16)

   ---    END
   ```
2. 查询规则的最大记录数。“全局数据名称”为“RULE(RULE)”。

   ```
   LST UPCCPLYCAP: NAME=RULE;
   ```

   ```
   %%LST UPCCPLYCAP: NAME=RULE;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
       全局数据名称  =  RULE
       全局数据容量  =  30000
             默认值  =  20480
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1。

| 输出项名称   | 输出项解释                   |
|:--------|:------------------------|
| 全局数据名称  | 用于返回查询UPCC数据全局数据对象的名称。  |
| 全局数据容量  | 用于返回查询UPCC数据全局数据容量信息。   |
| 默认值     | 用于返回查询UPCC数据全局数据对象的默认值。 |
