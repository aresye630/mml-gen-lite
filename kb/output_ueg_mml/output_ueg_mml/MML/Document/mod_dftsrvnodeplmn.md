# 修改默认PLMN（MOD DFTSRVNODEPLMN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C、GGSN**

该命令用于修改UNC设备默认的PLMN。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                        |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------|
| NODETYPE | 结点类型   | 可选必选说明：必选参数  参数含义：该参数用于指定网元类型。  数据来源：本端规划 取值范围： SGSN（SGSN）SGW（SGW）PGW（PGW）  默认值：无  配置原则：无                                                   |
| PLMNCODE | PLMN标识 | 可选必选说明：可选参数  参数含义：该参数用于指定PLMN标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是5~6。PLMN字符串的格式为长度5-6的MCC+MNC，MCC长度为3个字符，MNC长度为2或者3个字符。字符：0~9。  默认值：无  配置原则：无 |

## 使用实例

修改PGW默认所属的PLMN为46002（MCC=460, MNC=02）：

```
MOD DFTSRVNODEPLMN:NODETYPE=PGW,PLMNCODE="46002";
```
