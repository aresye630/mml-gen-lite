# 删除SBCAP本地实体(RMV SBCAPLE)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于删除SBc链路本地实体。

#### 注意事项

- 该命令执行后立即生效。
- 该命令执行后，会导致和此本地实体相连的CBC网元链路中断。

#### 本地用户权限

manage-ug;system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                            |
|:---------|:-------|:------------------------------------------------------------------------------------------------|
| LLEINDEX | 本端实体号  | 可选必选说明：必选参数 参数含义：待删除的SBc链路本地实体号。 取值范围：0～127 默认值：无  说明： 可以通过LST SBCAPLE命令查看已有配置，确认所要删除的SBc链路的索引。 |

#### 使用实例

删除一个SBc链路本地实体：

RMV SBCAPLE: LLEINDEX=0;
