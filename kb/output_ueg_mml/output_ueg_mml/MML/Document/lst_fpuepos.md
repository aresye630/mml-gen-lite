# 查询指纹采集终端信息（LST FPUEPOS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

查询显示FPUEPOS的对象信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询显示FPUEPOS的对象信息：

```
LST FPUEPOS:;
```
