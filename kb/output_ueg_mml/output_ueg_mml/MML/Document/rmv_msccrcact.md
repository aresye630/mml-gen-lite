# 删除MSCC层异常返回码处理动作（RMV MSCCRCACT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于删除MSCC层异常返回码的处理动作配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称       | 参数说明                                                                              |
|:-------------|:-----------|:----------------------------------------------------------------------------------|
| DCCTMPLTNAME | 在线计费模板名称   | 可选必选说明：必选参数 参数含义：该参数用于指定在线计费模板名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无  |
| MSCCRC       | MSCC层异常返回码 | 可选必选说明：必选参数 参数含义：该参数用于指定MSCC层异常返回码。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～4。 默认值：无 配置原则：无 |

#### 使用实例

删除全局在线计费模板中MSCC异常返回码5012的处理动作：

```
RMV MSCCRCACT:DCCTMPLTNAME="global",MSCCRC="5012";
```
