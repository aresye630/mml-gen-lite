# 增加对端设备组配置(ADD PAPPIPGRP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于添加对端设备组以接入对端设备。UDM局点根据运营商业务要求，需要对某个IP进行话统统计，则使用ADD PAPPIPGRP和ADD PAPPIP命令完成配置，系统将按照此IP进行HTTP2消息统计。

## 注意事项

对端设备组配置的最大记录数为100，添加时勿超过此上限值。

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                        |
|:----------|:--------|:--------------------------------------------------------------------------------------------|
| PAPPGRPNM | 对端设备组名称 | 可选必选说明：必选参数 参数含义：用于标识待增加的对端设备组名称。 取值范围：长度不超过63的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。 |
| GRPREMARK | 对端设备组备注 | 可选必选说明：可选参数 参数含义：用于标识对端设备组的备注。 取值范围：长度不超过63的字符串式。 默认值：无。 配置原则：无。                            |

## 使用实例

运营商根据业务需求，统计对端设备组HTTP2消息时，需要通过本命令增加对端设备组。“对端设备组名称”为“PeerIpGroup”，“对端设备组备注”为“TestRemark”：

```
ADD PAPPIPGRP: PAPPGRPNM="PeerIpGroup", GRPREMARK="TestRemark";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释       | 原因分析                                      | 处理建议                                                                                                |
|-------:|:------------|:------------------------------------------|:----------------------------------------------------------------------------------------------------|
|    503 | 配置数据已存在     | “对端设备组名称”和“对端设备组备注”参数对应的一条对端设备组配置数据记录已存在。 | 根据实际情况，重新输入参数，确保输入的“对端设备组名称”和“对端设备组备注”参数对应的一条对端设备组配置数据记录不存在。可执行LST PAPPIPGRP命令查询系统中已存在的对端设备组配置数据记录。 |
|    504 | 当前配置记录数达到上限 | 对端设备组配置数据已达上限，无法新增                        | 使用LST PAPPIPGRP查询对端设备组配置信息，删除无效的对端设备组数据并重新添加。                                                       |
| 360033 | 对端设备组已配置    | “对端设备组名称”参数对应的对端设备组配置数据记录已存在。             | 根据实际情况，重新输入参数，确保输入的“对端设备组名称”参数和系统中已存在的不重复。可执行LST PAPPIPGRP命令查询系统中已存在的对端设备组配置数据记录。                   |
