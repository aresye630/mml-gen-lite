# 查询网元号段信息(LST NFRANGEINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询网元配置的处理用户号段信息。

- 若需要查询某个号段的详细信息，请输入“索引”参数；
- 若需要查询某个组的号段信息，请输入“组名称”参数；
- 若需要查询所有号段信息，不输入任何参数。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                      |
|:----------|:-------|:--------------------------------------------------------------------------------------------------------------------------|
| GRPNAME   | 组名称    | 可选必选说明：可选参数 参数含义：用于标识本端网元号段信息所属组的信息，该参数由本端网元自定义；若不输入，则表示所有的组名称。 取值范围：长度不超过32的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。 |
| INDEX     | 索引     | 可选必选说明：可选参数 参数含义：用于标识本端网元号段信息数据记录的关键字段；若不输入，则表示所有的索引。 取值范围：1~40960。 默认值：无。 配置原则：无。                                        |
| RANGETYPE | 号段类型   | 可选必选说明：可选参数 参数含义：用于标识本端网元号段信息的号段类型；若不输入，则表示所有的号段类型。 取值范围： SUPI(用户永久标识)GPSI(通用公共用户标识) 默认值：无。 配置原则：无。                       |

## 使用实例

1. 查询所有号段信息：

   ```
   LST NFRANGEINFO:;
   ```

   ```
   %%LST NFRANGEINFO:;%%
   RETCODE = 0  操作成功

   操作结果如下 
   ------------
   组名称         索引  号段类型          开始             结束             模式  

   rangeSupi_01   1     用户永久标识      123456789040000  123456789059999  NULL    
   rangeSupi_02   2     用户永久标识      NULL             NULL             ^imsi-12345678904[0-9]{4}$  
   (结果个数 = 2)

   ---    END
   ```
2. 查询特定号段信息，“索引”为“1”：

   ```
   LST NFRANGEINFO: INDEX=1;
   ```

   ```
   %%LST NFRANGEINFO: INDEX=1;%%
   RETCODE = 0  操作成功

   操作结果如下 
   ------------
     组名称  =  rangeSupi_01
       索引  =  1
   号段类型  =  用户永久标识
       开始  =  123456789040000
       结束  =  123456789059999
       模式  =  NULL
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD NFRANGEINFO**命令的参数说明。
