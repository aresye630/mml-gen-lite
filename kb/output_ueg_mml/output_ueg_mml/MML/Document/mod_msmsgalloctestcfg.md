# 修改微服务消息包申请测试配置信息(MOD MSMSGALLOCTESTCFG)

## 命令功能

该命令用于修改UDM微服务Dopra消息包申请测试配置信息。“大小消息包检测功能开关”开启后，微服务Dopra消息包探测失败场景下，按照配置重新探测或进行自愈。

UDM在所有服务初始化时，调用平台接口将对应服务类型的大小消息包申请测试配置信息设置给平台。

## 注意事项

- 系统只能增加一条微服务消息包申请测试配置信息，再次执行该命令时，会覆盖系统中保存的消息包申请测试配置信息取值。
- 该命令中“小消息包复位策略”或“大消息包复位策略”参数取值“NOT\_RST(不复位)”时，“SrvMemAbnormalCheckSwitch（是否启用内存异常检测开关）”软参设置为“1”，消息包申请重试失败才会上报“ALM-138030 DOPRA资源异常”告警。

## 使用实例

修改消息包申请测试配置信息。参数设置如下：

- “服务类型”为“ENS(EnumService)”
- “大小消息包检测功能开关”为“ON(打开)”
- “消息包大小阈值”为“1000”
- “大消息包测试周期”为“1000”
- “大消息包测试次数”为“60”
- “大消息包重试失败比例”为“100”
- “大消息包复位策略”为“RST(复位)”
- “小消息包测试周期”为1000
- “小消息包测试次数”为“60”
- “小消息包重试失败比例”为“100”
- “小消息包复位策略”为“RST(复位)”

命令执行如下：

```
MOD MSMSGALLOCTESTCFG: ST=ENS, MSGSIZESWITCH=ON, MSGTHRESHOLDSIZE=1000, BIGMSGTIME=1000, BIGMSGCOUNT=60, BIGMSGFAILURERATE=100, BIGMSGRSTFLAG=RST, SMALLMSGTIME=1000, SMALLMSGCOUNT=60, SMALLMSGFAILURERATE=100, SMALLMSGRSTFLAG=RST;
```

该命令执行正常，会返回命令执行成功的提示信息。
