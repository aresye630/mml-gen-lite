# 查询远端DSG(LST DBSRDSG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询远端DSG模块配置信息。

- 若需要查询全部的远端DSG概要信息，请不要输入任何参数。
- 若需要查询某条远端DSG详细信息，请输入“远端Location标识”或者其他参数或者这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称         | 参数说明                                                                                                     |
|:--------|:-------------|:---------------------------------------------------------------------------------------------------------|
| RLOCID  | 远端Location标识 | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照远端Location的标识来查询远端DSG配置信息；若不输入，则表示所有的远端Location的标识。 取值范围：1～512 默认值：无。 配置原则：无 |
| RDSGMID | 远端DSG模块号     | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照远端DSG模块号来查询远端DSG配置信息；若不输入，则表示所有的远端DSG模块号。 取值范围：1～2047 默认值：无。 配置原则：无          |
| RDSGST  | 远端DSG业务类型    | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照远端DSG业务类型来查询远端DSG配置信息；若不输入，则表示所有的远端DSG业务类型。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无 |

## 使用实例

1. 查询所有远端DSG的信息。

   ```
   LST DBSRDSG:;
   ```

   ```
   %%LST DBSRDSG:;%% 
   RETCODE = 0  操作成功  

   操作结果如下 
   ------------ 
   远端Location标识  远端DSG模块号  远端DSG业务类型    
   10                5              SUP-FE              
   10                6              SUP-FE              
   (结果个数 = 2)  

   ---    END
   ```
2. 查询“远端Location标识”为“10”，“远端DSG模块号”为“5”，“远端DSG业务类型”为“SUP-FE”的远端DSG信息。

   ```
   LST DBSRDSG: RLOCID=10, RDSGMID=5, RDSGST="SUP-FE";
   ```

   ```
   %%LST DBSRDSG: RLOCID=10, RDSGMID=5, RDSGST="SUP-FE";%% 
   RETCODE = 0  操作成功  

   操作结果如下 
   ------------ 
   远端Location标识  =  10    
      远端DSG模块号  =  5  
    远端DSG业务类型  =  SUP-FE 
   (结果个数 = 1) 

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD DBSRDSG**命令的参数说明。
