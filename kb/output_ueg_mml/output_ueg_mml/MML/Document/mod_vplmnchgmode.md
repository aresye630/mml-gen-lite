# 修改基于VPLMN配置的漫游用户归属地计费模式（MOD VPLMNCHGMODE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于修改基于VPLMN配置的漫游用户归属地计费模式。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                                                           |
|:--------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VPLMN   | VPLMN信息 | 可选必选说明：必选参数  参数含义：该参数用表示漫游场景拜访地的PLMN信息。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是5~6。PLMN字符串的格式为MCCMNC，MCC长度为3个字符，MNC长度为2或者3个字符。  默认值：无  配置原则：无                           |
| CHGMODE | 计费模式    | 可选必选说明：可选参数  参数含义：该参数用于设置漫游用户在归属地的计费模式。  数据来源：全网规划 取值范围： “FBC（FBC计费）”：漫游用户在归属地使用FBC计费。“QBC（QBC计费）”：漫游用户在归属地使用QBC计费。“NOCHG（不计费）”：漫游用户在归属地不做计费功能。  默认值：无  配置原则：无 |

## 使用实例

修改VPLMN为“08600”的漫游用户归属地计费模式为QBC计费：

```
MOD VPLMNCHGMODE: VPLMN="08600", CHGMODE=QBC;
```
