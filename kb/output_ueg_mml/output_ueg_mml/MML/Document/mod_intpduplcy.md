# 修改异网漫游PDU会话重建策略（MOD INTPDUPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于修改异网漫游用户的PDU会话重建策略。

## 注意事项

下一次移动性流程生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                            |
|:--------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE      | 用户范围      | 可选必选说明：必选参数  参数含义：该参数用于指定PDU会话重建策略生效的用户范围。  数据来源：全网规划 取值范围： “INTERNAT_ROAM_USER（所有异网漫游用户）”：所有异网漫游用户。“IMSI_PREFIX（IMSI前缀）”：指定IMSI前缀的异网漫游用户。“SPECIFIC_IMSI（指定IMSI）”：指定IMSI的异网漫游用户。  默认值：无  配置原则：无                                                                                                                                 |
| IMSIPRE       | IMSI前缀    | 可选必选说明：该参数在"SUBRANGE"配置为"IMSI_PREFIX"时为条件必选参数。  参数含义：该参数用于指定PDU会话重建策略的用户IMSI前缀。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是5~14。  默认值：无  配置原则：无                                                                                                                                                                                              |
| IMSI          | IMSI      | 可选必选说明：该参数在"SUBRANGE"配置为"SPECIFIC_IMSI"时为条件必选参数。  参数含义：该参数用于指定PDU会话重建策略的用户IMSI（完整IMSI）。  数据来源：全网规划  取值范围：字符串类型，输入长度是15。  默认值：无  配置原则：无                                                                                                                                                                                          |
| IMSPDUPLCY    | 语音会话重建策略  | 可选必选说明：可选参数  参数含义：该参数用于指定异网漫游用户发生Inter类注册和切换流程时，语音会话的重建策略。 优先使用ADD NGVOICEDEPLOY中配置的VOICEDNN来识别语音会话，如果ADD NGVOICEDEPLOY未配置，则系统默认以“IMS”作为语音DNN来识别语音会话。  数据来源：全网规划 取值范围： “NO_REACT（不重建）”：Inter注册和Inter切换流程中不重建PDU会话。“REACT_ENTER_CMIDLE（进入空闲态后重建）”：等用户进入空闲态后重建会话。“IMMEDIATE_REACT（立即重建）”：Inter注册和Inter切换流程中立即重建会话。  默认值：无  配置原则：无 |
| NONIMSPDUPLCY | 非语音会话重建策略 | 可选必选说明：可选参数  参数含义：该参数用于指定异网漫游用户发生Inter类注册和切换流程时，非语音会话的重建策略。  数据来源：全网规划 取值范围： “NO_REACT（不重建）”：Inter注册和Inter切换流程中不重建PDU会话。“REACT_ENTER_CMIDLE（进入空闲态后重建）”：等用户进入空闲态后重建会话。“IMMEDIATE_REACT（立即重建）”：Inter注册和Inter切换流程中立即重建会话。  默认值：无  配置原则：无                                                                                           |

## 使用实例

修改对所有异网漫游用户生效的PDU会话重建策略，数据会话立即重建，语音会话等进入空闲态后再重建，执行如下命令：

```
MOD INTPDUPLCY:SUBRANGE=INTERNAT_ROAM_USER,IMSPDUPLCY=REACT_ENTER_CMIDLE,NONIMSPDUPLCY=IMMEDIATE_REACT;
```
