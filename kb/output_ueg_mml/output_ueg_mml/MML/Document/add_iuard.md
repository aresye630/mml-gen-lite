#### 命令功能

**适用网元：SGSN**

该命令用于增加Iu模式接入限制参数。该命令先根据IMSI号段将用户进行分类，再对每一类用户按照用户使用的卡类型（SIM/USIM）、签约的ARD信息、签约的APN信息进行区分而控制用户接入UTRAN网络。

该命令适用于以下场景。若运营商希望拒绝某个号段接入UTRAN系统，则可以启用根据签约ARD控制用户接入特性。若运营商希望控制某类用户是否允许接入UTRAN，但HLR/HSS不支持ARD时，则可以启用根据签约APN控制用户接入特性。若运营商已经强制要求对GERAN用户使用SIM卡，UTRAN用户使用USIM卡，并希望对不同卡进行灵活的接入控制，就需要启用按SIM卡/USIM卡控制用户接入特性。

#### 注意事项

- 本表的最大记录数为2048。
- 当本表记录中存在用户的IMSI对应的IMSI前缀或者所在的IMSI范围，且用户的属性（APNNI/CSI/卡类型）至少有一项与IUARD配置的属性匹配时，按照该配置的控制类型（CTRLTYPE）对用户接入进行控制。
- 当本表记录中存在用户的IMSI对应的IMSI前缀或者所在的IMSI范围，且用户的属性（APNNI/CSI/卡类型）与IUARD配置的属性均不匹配时，按照与该配置相反的控制类型（CTRLTYPE）对用户接入进行控制。
- 当本表记录中不存在用户的IMSI对应的IMSI前缀或者所在的IMSI范围时，不限制用户接入。
- 此配置涉及用户接入控制功能特性（特性编号：WSFD-106003，License部件编码：LKV2ARD02），执行命令请使用**DSP LICENSE**命令确认对应特性license是否得到授权，执行**LST LICENSESWITCH**命令确认特性开关状态为“ENABLE(打开)”。
- 当该配置增加上百条记录时，对系统性能影响较大。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|:---------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围    | 可选必选说明：必选参数 参数含义：该参数用于指定用户范围。 数据来源：整网规划 取值范围：“ALL_USER(所有用户)”：表示该指定用户范围为所有用户。“SPECIAL_IMSIPRE(指定IMSI前缀)”：表示该用户范围为指定IMSI前缀。“SPECIAL_IMSI_RANGE(指定IMSI范围)”：表示该用户范围为指定IMSI范围。 默认值：无 配置原则：当存在“用户范围”为“SPECIAL_IMSIPRE(指定IMSI前缀)”的记录时，不允许再添加“用户范围”为“SPECIAL_IMSI_RANGE(指定IMSI范围)”的记录。同理，当存在“用户范围”为“SPECIAL_IMSI_RANGE(指定IMSI范围)”的记录时，不允许再添加“用户范围”为“SPECIAL_IMSIPRE(指定IMSI前缀)”的记录。  说明： 匹配本表记录中的用户范围时，系统首先会匹配“SPECIAL_IMSIPRE(指定IMSI前缀)”或“SPECIAL_IMSI_RANGE(指定IMSI范围)”的记录，如果没有符合的记录，才会匹配“ALL_USER(所有用户)”的用户范围。                                                                |
| IMSIPRE  | IMSI前缀  | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI前缀。使用时按照IMSI最长匹配进行查询。 前提条件：该参数在“SUBRANGE(用户范围)”设置为“SPECIAL_IMSIPRE(指定IMSI前缀)”时生效。 数据来源：整网规划 取值范围：1~15位数字 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                            |
| BEGIMSI  | 起始IMSI  | 可选必选说明：条件必选参数 参数含义：该参数用于指定用户的起始IMSI。 前提条件：该参数在“SUBRANGE(用户范围)”设置为“SPECIAL_IMSI_RANGE(指定IMSI范围)”时生效。 数据来源：整网规划 取值范围：1~15位数字 默认值：无 配置原则：当“起始IMSI”与“终止IMSI”长度全为15位时，“起始IMSI”要小于等于“终止IMSI”，否则“起始IMSI”要小于“终止IMSI”。                                                                                                                                                                                                                                                                                                                                                           |
| ENDIMSI  | 终止IMSI  | 可选必选说明：条件必选参数 参数含义：该参数用于指定用户的终止IMSI。 前提条件：该参数在“SUBRANGE(用户范围)”设置为“SPECIAL_IMSI_RANGE(指定IMSI范围)”时生效。 数据来源：整网规划 取值范围：1~15位数字 默认值：无 配置原则：参见参考信息。                                                                                                                                                                                                                                                                                                                                                                                                                           |
| APNNI    | APNNI   | 可选必选说明：可选参数 参数含义：该参数用于配置指定APNNI。 数据来源：整网规划 取值范围：1~62位字符串 默认值：“*” 配置原则：APN网络标识地址由一个或多个LABEL构成，各LABEL间用“.”间隔。每个LABEL的构成字符只能是字母A~Z或a~z、数字0~9和中划线“-”，字母不区分大小写。APN网络标识地址不能以“rac”、“lac”、“sgsn”或“rnc”开头，不能以“.gprs”结尾。  说明： 如果APNNI配置为“*”，表示该记录适用于所有的APNNI。                                                                                                                                                                                                                                                                                                                     |
| CARDTYPE | 卡类型     | 可选必选说明：可选参数 参数含义：该参数用于指定用户的卡类型。 数据来源：整网规划 取值范围：“SIM(SIM)”“USIM(USIM)” 默认值：无 配置原则： 如果选中全部清空，表示不根据用户签约的SIM卡或USIM卡作为用户的附加属性进行接入限制判断条件。如果选中其中之一或全选，表示SIM卡和/或USIM卡将作为用户的附加属性作为接入限制的判断条件，不符合条件的用户将采取与“控制类型”相反的控制策略。如果选中“SIM”卡，控制类型为“REJECT(拒绝)”，表示非SIM卡的用户都将被允许接入。如果选中“USIM”卡，控制类型为“ALLOW(允许)”，表示非“USIM”卡的用户都将被拒绝接入。如果选中“SIM”卡和“USIM”卡，控制类型为“ALLOW(允许)”，表示不根据用户卡类型控制用户接入。如果选中“SIM”卡和“USIM”卡，控制类型为“REJECT(拒绝)”，表示该记录中指定的用户范围内的用户都不能接入。如果用户不配置鉴权(可执行LST IUAUTHCIPH命令查看)，本命令中关于卡类型限制的判断不生效，此时不会对不鉴权的用户做卡类型的接入限制。                                                                 |
| ARD      | 启用签约ARD | 可选必选说明：可选参数 参数含义：该参数用于指定是否启用签约ARD。 数据来源：整网规划 取值范围：“NO(否)”“YES(是)” 默认值：“NO(否)” 配置原则：不启用签约ARD时，该参数设置为“NO(否)”；启用签约ARD时，该参数设置为“YES(是)”。不建议同时使用签约ARD功能与签约APN NI功能。                                                                                                                                                                                                                                                                                                                                                                                                           |
| CTRLTYPE | 控制类型    | 可选必选说明：必选参数 参数含义：该参数用于指定是否允许用户接入。 数据来源：整网规划 取值范围：“ALLOW(允许)”：表示符合该规则的用户是允许接入。“REJECT(拒绝)”：表示符合该规则的用户是拒绝接入。 默认值：无 配置原则：当只使用ARD的功能时，该参数建议设置为“ALLOW(允许)”，以防止收到APNNI默认值的影响。                                                                                                                                                                                                                                                                                                                                                                                                 |
| CAUSE    | 原因值     | 可选必选说明：可选参数 参数含义：该参数用于指定原因值。 数据来源：整网规划 取值范围：“CUSTOMER_DEFINED(自定义)”：表示指定原因值为自定义。“GPRS_SERVICE_NOT_ALLOWED(GPRS服务被禁止)”：表示指定原因值为GPRS服务被禁止。“GPRS_NONGPRS_SRV_NOT_ALLOWED(GPRS和非GPRS服务都被禁止)”：表示指定原因值为GPRS和非GPRS服务都被禁止。“PLMN_NOT_ALLOWED(PLMN被禁止)”：表示指定原因值为PLMN被禁止。“LA_NOT_ALLOWED(本地区域被禁止)”：表示指定原因值为本地区域被禁止。“ROAMING_NOT_ALLOWED_IN_LA(本地漫游被禁止)”：表示指定原因值为本地漫游被禁止。“GPRS_SRV_NOT_ALLOWED_IN_PLMN(本PLMN内GPRS服务被禁止)”：表示指定原因值为本PLMN内GPRS服务被禁止。“NO_SUITABLE_CELLS_IN_LA(本地无合适小区)”：表示指定原因值为本地无合适单元。 默认值：“NO_SUITABLE_CELLS_IN_LA(本地无合适小区)”  说明： 附着或路由更新拒绝的原因值，请参考3GPP TS 24.008输入。 |
| SDCAUSE  | 自定义原因值  | 可选必选说明：条件必选参数 参数含义：该参数用于指定自定义原因值。 前提条件：该参数在“CAUSE(原因值)”设置为“CUSTOMER_DEFINED(自定义)”时生效。 数据来源：整网规划 取值范围：1~254 默认值：无  说明： 当原因值为自定义时，根据3GPP TS 24.008填写。                                                                                                                                                                                                                                                                                                                                                                                                                     |

#### 使用实例

1. 增加一条Iu模式接入限制参数记录，用户范围为ALL\_USER，卡类型为SIM-1，控制类型为拒绝，原因值为GPRS\_SERVICE\_NOT\_ALLOWED：

   ADD IUARD: SUBRANGE=ALL\_USER, CARDTYPE=SIM-1, CTRLTYPE=REJECT, CAUSE=GPRS\_SERVICE\_NOT\_ALLOWED;
2. 增加一条Iu模式接入限制参数记录，用户范围为SPECIAL\_IMSIPRE，IMSIPRE为123456，卡类型为SIM-1，控制类型为拒绝，原因值为GPRS\_SERVICE\_NOT\_ALLOWED：

   ADD IUARD: SUBRANGE=SPECIAL\_IMSIPRE, IMSIPRE="123456", CARDTYPE=SIM-1, CTRLTYPE=REJECT, CAUSE=GPRS\_SERVICE\_NOT\_ALLOWED;

#### 参考信息

输入的起始IMSI必须小于或者等于终止IMSI。判断起始IMSI和终止IMSI大小的原则是：对于输入IMSI的长度小于系统规定IMSI长度时，将该IMSI补足0到规定长度后进行大小比较，且起始IMSI必须小于终止IMSI。只有输入IMSI长度等于系统规定长度时，起始IMSI才能等于终止IMSI。对于系统规定IMSI长度为15的情况，如表1所示：

|          起始IMSI |          终止IMSI | 实际限定IMSI范围                                                             |
|----------------:|----------------:|:-----------------------------------------------------------------------|
|       123002666 |          123002 | 增加记录失败，起始IMSI大于终止IMSI                                                  |
|          123002 |       123002666 | 123002000000000 ~ 123002666000000，即区间[123002000000000，123002666000000] |
|          123002 |          123002 | 增加记录失败，起始IMSI不能等于终止IMSI                                                |
| 123002000000000 | 123002000000000 | 仅限定IMSI号码123002000000000                                               |
| 123003000000000 | 123004000000000 | 123003000000000 ~ 123004000000000，即区间[123003000000000，123004000000000] |

- 输入的起始IMSI和终止IMSI定义的IMSI号段范围不允许与其它记录定义的IMSI号段范围相互交叉、包含或重合。
