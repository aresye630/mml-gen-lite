# 查询DSCP值到VLAN优先级的映射（LST DSCPMAP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询DSCP值到VLAN优先级的映射。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                 |
|:-------|:-------|:-------------------------------------------------------------------------------------|
| DSCP   | DSCP值  | 可选必选说明：可选参数 参数含义：该参数用来表示DSCP值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～63。 默认值：无                  |
| TYPE   | 优先级类型  | 可选必选说明：可选参数 参数含义：该参数用来表示优先级类型。 数据来源：本端规划 取值范围：枚举类型。 8021p：8021p优先级。exp：EXP优先级。 默认值：无 |

#### 使用实例

查询DSCP值到VLAN优先级的映射：

```
LST DSCPMAP:;
```

```
RETCODE = 0  操作成功
结果如下
-------------------------
DSCP值     优先级类型   优先级数值 
62         exp          5 
63         8021p        7 
(结果个数 = 2)
---    END
```
