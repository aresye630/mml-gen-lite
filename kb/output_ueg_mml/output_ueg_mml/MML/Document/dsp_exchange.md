# 查询负载均衡交换表（DSP EXCHANGE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

查询负载均衡交换表的详细信息

#### 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识           | 参数名称      | 参数说明                                                                                                    |
|:---------------|:----------|:--------------------------------------------------------------------------------------------------------|
| CONSUMERVNFCID | 服务VNFC ID | 可选必选说明：必选参数 参数含义：该参数用于指定业务VNFC的唯一标识，通过在业务VNFC下执行LST NODE获得，所得NODEID即为服务VNFC ID。 默认值：无 取值范围：0~4294967294 |
| EXCHANGEID     | 交换ID      | 可选必选说明：必选参数 参数含义：交换ID 数据来源：可通过执行DSP POLICYNUM查询到。 默认值：无 取值范围：0~4294967294                               |

#### 使用实例

查询服务VNFC ID为4，交换ID为18的负载均衡交换表信息的命令如下：

`DSP EXCHANGE: CONSUMERVNFCID=4, EXCHANGEID=18;`

```
%%DSP EXCHANGE: CONSUMERVNFCID=4, EXCHANGEID=18;%%
RETCODE = 0  操作成功

结果如下:
-------------------------
服务VNFC ID    交换ID    交换前数据    交换后数据 
4              18        1             71         
4              18        2             72         
4              18        3             73         
(结果个数 = 3)
---    END
```

#### 输出结果说明

|:----------|:----------|
| 服务VNFC ID | 服务VNFC ID |
| 交换ID      | 交换ID      |
| 交换前数据     | 交换前数据     |
| 交换后数据     | 交换后数据     |
