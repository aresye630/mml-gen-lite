# 查询离线业务模板（LST OFCSRVTEMPLATE）

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用来查询离线业务模板的配置信息。

#### 注意事项

如果输入离线业务模板名称，则查询指定离线业务模板信息；如果不输入离线业务模板名称，则查询全部的离线业务模板信息。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                     |
|:-------------|:--------|:-----------------------------------------------------------------------------------------|
| TEMPLATENAME | 离线业务模板名 | 可选必选说明：可选参数 参数含义：该参数用于指定离线业务模板名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不允许输入空格。 默认值：无 配置原则：无 |

#### 使用实例

查询名为“offlinetmp”的离线业务模板信息：

```
LST OFCSRVTEMPLATE: TEMPLATENAME="offlinetmp";
```
