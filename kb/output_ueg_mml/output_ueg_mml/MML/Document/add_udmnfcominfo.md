## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成UDM在NRF上的注册信息发生错误，从而导致周边网元无法访问UDM提供的服务，造成业务失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于增加网元的公共信息，用于指定3GPP TS 29.510协议中服务注册时NFProfile、NFService中相同字段的值。

该命令的参数索引关系如图1所示。

**图1** 命令参数的索引关系图

## 注意事项

当凌晨自动校验或执行**VRY NRFDATA**命令手动校验NRFClient内存数据时，在校验该MML命令的过程中，无法执行该命令，若运行该命令，则提示“360155 该MML数据正在校验中，请稍后再试”。

## 使用实例

在开局场景下配置信令数据时，增加一条网元公共信息，“公共信息标识”为“cominfo”，“网元类型”为“UDM”，“全量域名”为“huawei.com”，“优先级”为“5”：

```
ADD UDMNFCOMINFO: NFCOMINFOID="cominfo_01", NFTYPE=UDM, FQDN="huawei.com", PRIORITY=5;
```
