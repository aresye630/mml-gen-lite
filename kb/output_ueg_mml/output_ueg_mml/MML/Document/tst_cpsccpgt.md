#### 命令功能

**适用网元：SGSN、MME**

此命令用于测试SCCP GT码是否能被正确解析，对匹配的GT码输出翻译结果。

#### 注意事项

- 系统会自行选取可用的信令进程（SPP/SGP），因此，执行该操作的时候要确保系统中有可用的信令进程。否则，操作将不能正常执行。
- 系统对输入的GT码进行最大匹配，匹配成功的输出翻译结果。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                                                                                                       |
|:--------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RUNAME  | RU名称    | 可选必选说明：可选参数 参数含义：该参数用于指定SPU资源单元名。该参数可以通过DSP RU命令查询。 取值范围：0~63 位字符串 默认值：无                                                                                                                                   |
| PT      | 进程类型    | 可选必选说明：可选参数 参数含义：该参数用于指定进程的进程类型。 取值范围： “SPP(SPP)”“SGP(SGP)” 默认值：无                                                                                                                                          |
| PN      | 进程号     | 可选必选说明：可选参数 参数含义：该参数用于指定进程号。 取值范围：0~20 默认值：无                                                                                                                                                               |
| GTEXP   | GT码表示语  | 可选必选说明：可选参数 参数含义：该参数用于指定GT码的类型。 取值范围：“FOUR（ITU四类）”“SIX（ANSI二类）” 默认值：“FOUR（ITU四类）”                                                                                                                          |
| TT      | 翻译类型    | 可选必选说明：可选参数 参数含义：该参数用于指定翻译类型。 前提条件：只有当“GT码表示语”为“SIX（ANSI二类）”时，该参数才有效。 取值范围：“ANSI9（ANSI 9类）”“ANSI10（ANSI 10类）” 默认值：“ANSI9（ANSI 9类）”                                                                         |
| NP      | 编号计划    | 可选必选说明：可选参数 参数含义：该参数用于指编号计划。 前提条件：只有当“GT码表示语”为“FOUR（ITU四类）”时，该参数才有效。 取值范围：“ISDNP（ISDN/电话编号计划）”“DATA（数据编号计划）”“TELEX（Telex编号计划）”“SMS（海事移动编号计划）”“PMS（陆地移动编号计划）”“ISDNMS（ISDN/移动编号计划）” 默认值：“ISDNP（ISDN/电话编号计划）” |
| ADDREXP | 地址性质表示语 | 可选必选说明：可选参数 参数含义：该参数用于指地址性质表示语。 前提条件：只有当“GT码表示语”为“FOUR（ITU四类）”时，该参数才有效。 取值范围：“FREE（空闲）”“SUBDN（用户号码）”“NSU（国内备用号码）”“NVU（国内有效号码）”“INTDN（国际号码）” 默认值：“INTDN（国际号码）”                                              |
| ADDR    | 地址信息    | 可选必选说明：必选参数 参数含义：该参数用于指地址信息。 取值范围：长度不超过20的字符串 默认值：无                                                                                                                                                        |
