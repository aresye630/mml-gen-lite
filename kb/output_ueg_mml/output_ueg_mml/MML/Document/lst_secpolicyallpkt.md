# 查询上送报文总体速率（LST SECPOLICYALLPKT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询上送报文总体速率设置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                        |
|:------------|:-------|:------------------------------------------------------------|
| SECPOLICYID | 安全策略编号 | 可选必选说明：可选参数 参数含义：策略编号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～30。 默认值：无 |

#### 使用实例

查询上送报文总体速率设置：

```
LST SECPOLICYALLPKT:SECPOLICYID=1;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
  安全策略编号    =  1
上报速率值（pps） =  6000
  上报速率等级    =  高
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称      | 输出项解释            |
|:-----------|:-----------------|
| 安全策略编号     | 该参数表示策略号。        |
| 上报速率值（pps） | 该参数表示速度值，单位为pps。 |
| 上报速率等级     | 该参数表示速度等级。       |
