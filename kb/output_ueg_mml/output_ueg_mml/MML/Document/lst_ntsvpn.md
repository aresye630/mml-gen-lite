# 查询NTS VPN(LST NTSVPN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询NTS接入CSLB时业务IP地址的VPN信息。

- 若需要查询全部NTS VPN信息，请不要输入任何参数。
- 如果需要查询指定NTS VPN信息，请输入“VPN索引”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                             |
|:------------|:-------|:-------------------------------------------------------------------------------------------------|
| VPNINDEX    | VPN索引  | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个VPN索引来查询NTS VPN信息；若不输入，则表示所有的VPN索引。 取值范围：0～15 默认值：无。 配置原则：无。        |
| VPNNAME     | VPN名称  | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个VPN名称来查询NTS VPN信息；若不输入，则表示所有的VPN名称。 取值范围：长度不超过31的字符串 默认值：无。 配置原则：无。 |
| DESCRIPTION | 描述     | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个描述来查询NTS VPN信息；若不输入，则表示所有的描述。 取值范围：长度不超过32的字符串 默认值：无。 配置原则：无。       |

## 使用实例

1. 查询全部NTS VPN信息。

   ```
   LST NTSVPN:;
   ```

   ```
   %%LST NTSVPN:;%% 
   RETCODE = 0  操作成功
     
   操作结果如下: 
   ------------- 
   VPN索引  VPN名称  描述     
   0        VPN_20   NTS_VPN1   
   1        VPN_10   NTS_VPN2   
   (结果个数 = 2) 
    
   ---    END
   ```
2. 查询一条NTS VPN信息，“VPN索引”为“0”。

   ```
   LST NTSVPN: VPNINDEX=0;
   ```

   ```
   %%LST NTSVPN: VPNINDEX=0;%% 
   RETCODE = 0  操作成功 
    
   操作结果如下: 
   ------------- 
    VPN索引  =  0 
    VPN名称  =  VPN_20
       描述  =  NTS_VPN1 
   (结果个数 = 1)  

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD NTSVPN**命令的参数说明。
