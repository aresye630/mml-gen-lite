#### 命令功能

**适用网元：MME**

该命令用于查询配置的HSS BYPASS故障状态码信息。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                |
|:----------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RANGE     | 生效范围     | 可选必选说明：可选参数 参数含义：该参数用于指定特定故障码的生效范围。 数据来源：全网规划 取值范围： ALL（整系统）：整系统 OFFICE（局向）：特定HSS局向KEYWORD（对端主机名关键字）：包含关键字的特定HSS局向 默认值：无 配置原则：无                                                                                                                                                                                                                                                     |
| HOSTNAME  | 对端主机名    | 可选必选说明：分支可选参数 参数含义：该参数用于指定进入故障状态的HSS主机名。 前提条件：该参数在“生效范围”配置为“OFFICE（局向）”时生效。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1~127 默认值：无 配置原则：该参数不区分大小写。                                                                                                                                                                                                                                                 |
| KEYWORD   | 对端主机名关键字 | 可选必选说明：分支可选参数 参数含义：该参数用于指定进入故障状态的HSS主机名关键字。 前提条件：该参数在“生效范围”参数配置为“KEYWORD（对端主机名关键字）”时生效。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1~31 默认值：无 配置原则：该参数不区分大小写。                                                                                                                                                                                                                                      |
| FAULTCODE | 故障码      | 可选必选说明：可选参数 参数含义：该参数用于指定进入HSS BYPASS状态的原因值。 数据来源：全网规划 取值范围：0-4294967295“3002(DIAMETER_UNABLE_TO_DELIVER)”：对端不能把消息发送到目的地“3004(DIAMETER_TOO_BUSY)”：对端不能提供请求的服务“3005(DIAMETER_LOOP_DETECTED)”：系统向对端发消息时检测到有环路“1001、2002、3001、3003、3007～3010、4001～4003、5001～5017”：当配置此区间的错误码后，UNC也可触发重选路由功能，但同时可能会影响UNC下发给用户的Attach Reject等消息的拒绝原因值“10001”：HSS响应超时/未响应原因值“其他值”：当前不支持重选路由功能 默认值：无 配置原则：无 |

#### 使用实例

查询已经配置的所有HSS BYPASS故障状态码数据。

```
%%LST HSSBPFAULTCODE:;%% 
RETCODE = 0  操作成功
 
操作结果如下 
------------------------ 
        生效范围  =  局向
      对端主机名  =  hostname
对端主机名关键字  =  NULL
          故障码  =  3002
(结果个数 = 1) 
 
---    END
```
