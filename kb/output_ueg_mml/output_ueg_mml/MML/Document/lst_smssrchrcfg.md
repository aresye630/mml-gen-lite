# 查询SMS小范围CHR上报规则配置（LST SMSSRCHRCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMSF**

该命令用于查询SMS小范围CHR上报规则配置。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                     |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：可选参数  参数含义：该参数用于指定配置小范围CHR的用户范围。  数据来源：本端规划 取值范围： “SPECIFIC_IMSI（指定用户IMSI）”：表示指定用户IMSI。  默认值：无  配置原则：无                            |
| IMSIPRE  | IMSI前缀 | 可选必选说明：该参数在"SUBRANGE"配置为"SPECIFIC_IMSI"时为条件可选参数。  参数含义：该参数用于指定IMSI前缀。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是5~15。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无 |

## 使用实例

运营商希望查询SMS小范围CHR上报规则配置，执行如下命令 ：

```
LST SMSSRCHRCFG:;
%%LST SMSSRCHRCFG:;%%
RETCODE = 0  操作成功

结果如下：
------------------------
用户范围 =  指定用户IMSI
IMSI前缀  =  12303120010
流程控制模板索引 = 2
       
(结果个数 = 1)
```

## 输出结果说明

| 输出项名称    | 输出项解释                 |
|:---------|:----------------------|
| 用户范围     | 该参数用于指定配置小范围CHR的用户范围。 |
| IMSI前缀   | 该参数用于指定IMSI前缀。        |
| 流程控制模板索引 | 该参数用于指定CHR上报流程控制模板索引。 |
