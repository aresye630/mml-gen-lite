# 查询VNRS内部资源不足告警的阈值参数（LST SFERESALMTHD）

- 命令功能
- 注意事项
- 操作用户权限

- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询ALM-231612426 VNRS内部资源不足告警的阈值参数。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                          |
|:--------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------|
| RESTYPE | 资源类型   | 可选必选说明：必选参数 参数含义：该参数用于指定ALM-231612426 VNRS内部资源不足告警的资源类型。 数据来源：本端规划 取值范围：枚举类型。 IPv4RecmpNode：IPv4分片重排节点。IPv4ReasmNode：IPv4分片重组节点。 默认值：无 配置原则：无 |

#### 使用实例

查询IPv4分片重排节点资源不足导致的ALM-231612426 VNRS内部资源不足告警的阈值参数：

```
LST SFERESALMTHD: RESTYPE=IPv4RecmpNode:;
```

```
RETCODE = 0  操作成功

结果如下
------------------------
触发阈值（%）  =  90
恢复阈值（%）  =  80
(结果个数 = 1) 
---    END
```
