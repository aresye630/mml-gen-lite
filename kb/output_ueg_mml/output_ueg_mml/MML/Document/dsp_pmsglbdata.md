# 查询PMS迁移全局数据结果(DSP PMSGLBDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询PMS迁移全局数据的结果。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询PMS迁移全局数据结果。

```
DSP PMSGLBDATA:;
```

```
%%DSP PMSGLBDATA:;%%
RETCODE = 0  操作成功

操作结果如下:
-------------
  POD名称  =  pcf-all-pod20-0
 开始时间  =  2021-09-15 11:17:53
 结束时间  =  2021-09-15 11:18:04
     状态  =  成功
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明

| 输出项名称   | 输出项解释                                                                |
|:--------|:---------------------------------------------------------------------|
| POD名称   | 表示PMS微服务所在的POD名称。                                                    |
| 开始时间    | 表示PMS开始迁移全局数据的时间。 时间格式为YYYY-MM-DD HH:MM:SS。                          |
| 结束时间    | 表示PMS结束迁移全局数据的时间。 时间格式为YYYY-MM-DD HH:MM:SS，当迁移任务尚未结束时，结束时间显示为“NULL”。 |
| 状态      | 用于表示数据迁移的状态。 取值范围： 运行中：表示迁移过程中成功：表示迁移成功失败：表示迁移失败                     |
