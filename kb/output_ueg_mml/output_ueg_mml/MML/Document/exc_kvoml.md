## 命令功能

**须知** 

该命令属于高危命令，操作内存数据库可能导致数据被损坏且无法回退，务必联系华为技术支持确认后方可操作。

该命令用于对CCDB内存数据库中的指定表进行数据操作。

## 注意事项

日志数据在传出运营商网络前，需要采用匿名化工具对日志数据进行匿名化处理。日志匿名化处理工具可以在https://support.huawei.com/上获取。在“产品软件”页签中浏览或搜索“Log Anonymity Tool”，获取最新版本的工具。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|:---------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APPTYPE  | 应用类型   | 可选必选说明：必选参数 参数含义：用于标识指定的应用类型，并请求按照指定应用类型进行执行，应用类型可通过命令LST APPTYPE查询。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无.                                                                                                                                                                                                                                                                                                                                 |
| TREENAME | 树名称    | 可选必选说明：必选参数 参数含义：用于标识对象树的名称。 取值范围：长度不超过30的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                          |
| DATAKEY  | 数据键值   | 可选必选说明：必选参数 参数含义：用于标识用户数据对应的主键。 取值范围：长度不超过2000的字符串。  说明： 键值给定的字符类型需要与对应的实际类型匹配。实际类型可以通过查询Schema配置获得。对于Schema配置中数据键值字符类型为Raw类型或VarRaw类型需要在数据键值前添加hextoraw进行转换。如数据键值为“123456FF”需要转换为“hextoraw(/q123456FF/q)”。 默认值：无。 配置原则： 如果DATAKEY语句中存在“'”字符，则需要输入转义字符“/q”。如果DATAKEY语句中存在“=”字符，则需要输入转义字符“/e”。如果DATAKEY语句中存在“,”字符，则需要输入转义字符“/c”。如果DATAKEY语句中存在“;”字符，则需要输入转义字符“/s”。如果DATAKEY语句中存在“\"”字符，则需要输入转义字符“/Q”。如果DATAKEY语句中存在“/”字符，则需要输入转义字符“//”。 |
| KEYTYPE  | 键值类型   | 可选必选说明：可选参数 参数含义：用于标识用户数据对应的主键。其给定值需要与dbschema中配置的键值类型对应；当指定辅键的键值类型时，系统将进行辅键查询，否则系统默认为主键查询。 取值范围：0~4294967295。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                          |
| OML      | 对象操作语言 | 用于指定完成某项CCDB内存数据库操作的OML语句。 OML语句中操作的节点，必须是“树名称”参数下的根节点或者子节点。 取值范围：长度不超过2048的英文字符串。 配置原则： 如果OML语句中存在“'”字符，则需要输入转义字符“/q”。如果OML语句中存在“=”字符，则需要输入转义字符“/e”。如果OML语句中存在“,”字符，则需要输入转义字符“/c”。如果OML语句中存在“;”字符，则需要输入转义字符“/s”。如果OML语句中存在“\"”字符，则需要输入转义字符“/Q”。如果OML语句中存在“/”字符，则需要输入转义字符“//”。 默认值：无。  说明： 如果字段值超大，无法构造大字段值条件等，则无法进行查询，此处不做无限制长度扩展。 查询不支持带FILTER的查询，仅支持整对象查询。                                                                          |
| INSTID   | 实例标识   | 可选必选说明：可选参数 参数含义：用于标识服务实例的ID。 取值范围：长度不超过20的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                         |

## 使用实例

查询数据键值为“10101010ABCDFFFF”的对应数据信息。

```
EXC KVOML: APPTYPE="SUP-DUS", TREENAME="SDU_SUBSCRIBER", DATAKEY="10101010ABCDFFFF", OML="SELECT * FROM SDU_SUBSCRIBER WHERE PESID /e /q1000000022001101/q";
```

```

RETCODE = 0  操作成功
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。各输出项含义请参见表1输出项解释的参数说明。

| 输出项名称   | 输出项解释                           |
|:--------|:--------------------------------|
| 数据键值    | 用于返回查询的数据键值内容，与输入一致。            |
| 实例标识    | 用于返回该数据键值所在实例的实例标识。             |
| 分片属性    | 用于返回当前实例的分片主备属性。                |
| 数据信息    | 用于返回查询得到的数据文本内容，返回的文本内容为JSON格式。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2错误码列表所示。

|   错误码 | 错误码解释      | 原因分析                              | 处理建议                                      |
|------:|:-----------|:----------------------------------|:------------------------------------------|
| 67778 | 指定的表不存在。   | 输入的“树名称”不存在。                      | 修改“树名称”后重新执行。“树名称”可以通过检查Schema配置获取。       |
| 67888 | 键值非法。      | 输入的“数据键值”不合法或者不满足类型要求等，导致转换键值失败。  | 检查输入键值是否满足要求，修改后重新执行。                     |
| 67889 | OML语句不合法。  | 输入的不是SELECT查询语句，或输入的OML语句不符合语法要求。 | 修改OML语句，修改正确后重新执行。                        |
| 67890 | 数据库执行失败。   | 内部执行OML失败。                        | 请联系华为技术支持处理。                              |
| 67981 | 当前不支持查看辅键。 | 指定了辅键的“键值类型”。                     | 删除指定的“键值类型”后重新执行。对应的“键值类型”可以通过检查Schema配置。 |
