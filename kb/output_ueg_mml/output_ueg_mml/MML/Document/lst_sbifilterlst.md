# 查询服务接口过滤列表(LST SBIFILTERLST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询某个服务接口过滤列表：

- 若需要查询所有的服务接口过滤列表，不输入任何参数。
- 若需要查询某个过滤器名称的详细接口过滤列表，请输入“过滤器名称”参数。
- 若需要查询某个服务的详细接口过滤列表，请输入“对端类型”参数。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                           |
|:-----------|:-------|:-------------------------------------------------------------------------------------------------------------------------------|
| FILTERNAME | 过滤器名称  | 可选必选说明：可选参数 参数含义：定义某服务化客户端过滤名单的过滤器名称，它唯一标识一条过滤记录。用于根据某一过滤名称来查询某个接口过滤列表；若不输入，则表示所有过滤器名称的过滤列表。 取值范围：长度不超过127位的字符串 默认值：无。 配置原则：无。 |
| TYPE       | 对端类型   | 可选必选说明：可选参数 参数含义：标识需要进行过滤的对端服务类型。用于查询某个指定对端类型的过滤列表；若不输入，则表示所有对端类型的过滤列表。 取值范围： AMF(AMF)SMF(SMF)AF(AF)VPCF(VPCF) 默认值：无。 配置原则：无。  |

## 使用实例

1. 查询所有的服务接口过滤列表。

   ```
   %%LST SBIFILTERLST:;%% 
   RETCODE = 0  操作成功  
   操作结果如下 
   ------------ 
   过滤器名称  对端类型  IP版本  IPV4地址       IPV6地址  IPV4掩码       IPV6前缀长度  操作类型    
   aaa         SMF       IPV4    10.168.0.130   NULL      255.255.255.0  NULL          白名单     
   bbb         AMF       IPV4    10.168.0.131   NULL      255.255.255.0  NULL          黑名单     
   (结果个数 = 2)  
   ---    END
   ```
2. 查询“过滤器名称”为“aaa”的服务接口过滤列表。

   ```
   %%LST SBIFILTERLST: FILTERNAME="aaa";%% RETCODE = 0  操作成功  
   操作结果如下 
   ------------   
     过滤器名称  =  aaa     
       对端类型  =  SMF       
         IP版本  =  IPV4     
       IPV4地址  =  10.168.0.130     
       IPV6地址  =  NULL     
       IPV4掩码  =  255.255.255.0 
   IPV6前缀长度  =  NULL     
       操作类型  =  白名单 
   (结果个数 = 1)  
   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD SBIFILTERLST**命令的参数说明。
