# 修改SFTP服务器(MOD SFTPSERVER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令用于修改在配置数据库中的一条NLF作为SFTP服务器的数据记录。在该命令中，系统通过“链路ID”参数来唯一标识一条NLF作为SFTP服务器的数据记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                                                                                                                                                    |
|:-------|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ID     | SFTP服务器的索引 | 可选必选说明：必选参数 参数含义：标识一条NLF作为SFTP服务器的数据记录的关键字段（其取值不能被修改），用于指定需要对哪一条NLF作为SFTP服务器数据记录的参数进行修改或调整，操作员可以使用LST SFTPSERVER命令查询获得。 取值范围：0 默认值：无。 配置原则：无。                                                                           |
| IPVER  | IP版本       | 可选必选说明：可选参数 参数含义：用于指定NLF作为SFTP服务器的IP版本类型。SFTP服务器指定IP版本后不支持修改。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。                                                                                                                 |
| IP     | IPV4地址     | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV4(IPV4)”时该参数需配置，NLF与对端对接的参数之一，用于表示NLF作为SFTP服务器的IPv4地址。 取值范围：IPv4地址 默认值：无。 配置原则：此IP地址必须是本地实际的IP地址且必须先由ADD NLFDEVADDR或ADD PMSDEVADDR（通过ADD NLFDEVADDR中配置的“PMS设备地址标识”进行索引关联）命令定义，然后才能在此处引用。 |
| IPV6   | IPV6地址     | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV6(IPV6)”时该参数需配置，NLF与对端对接的参数之一，用于表示NLF作为SFTP服务器的IPv6地址。 取值范围：IPv6地址 默认值：无。 配置原则：此IP地址必须是本地实际的IP地址且必须先由ADD NLFDEVADDR或ADD PMSDEVADDR（通过ADD NLFDEVADDR中配置的“PMS设备地址标识”进行索引关联）命令定义，然后才能在此处引用。 |
| ADMST  | 管理状态       | 可选必选说明：可选参数 参数含义：用于标识NLF作为SFTP服务器的管理状态。 取值说明： ENABLE(启用)：表示启用SFTP服务。DISABLE(禁用)：表示停止SFTP服务。 默认值：无。 配置原则：无。                                                                                                              |

## 使用实例

修改一条NLF作为SFTP服务器的配置信息记录，“SFTP服务器的索引”为“0”，“IP版本”为“IPV4(IPV4)”，“IPV4地址”为“10.168.0.133”。

```
MOD SFTPSERVER: ID=0, IPVER=IPV4, IP="10.168.0.133";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释            | 原因分析                       | 处理建议                                                                                                                                                                               |
|------:|:-----------------|:---------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 58026 | 本地IP地址不存在。       | 输入的“本地IP地址”或“本地IPV6地址”不存在。 | 若输入的“本地IP地址”或“本地IPV6地址”不存在：执行LST NLFDEVADDR命令，查询已存在的所有NLF设备地址记录。 查询可以复用的IP地址，通过1获取到NLF关联配置的“PMS设备地址标识”，执行LST PMSDEVADDR命令，查询PMS设备地址标识对应的IP地址。重新执行本命令，使用系统已添加的NLF设备地址或可以复用的PMS设备地址。 |
| 58022 | 不能修改SFTP服务的IP版本。 | 输入的“IP版本”不支持修改。            | 参数“IP版本”不允许修改，如需修改这个参数，可以采用如下方式进行修改：执行RMV SFTPSERVER命令，输入查询的“SFTP服务器的索引”删除SFTP服务。执行ADD SFTPSERVER命令，重新添加正确“IP版本”的新SFTP服务器。                                                         |
