# 显示MPF属性配置（LST MPFATTR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：MPF**

该命令用于显示MPF上Mm5接口可以处理的消息类型和MepId标识配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

显示MPF属性配置：

```
LST MPFATTR:;
```

```
RETCODE = 0  操作成功

MPF属性信息
-----------
Mm5接口消息类型  =  应用描述
         MEP ID  =  mepid
(结果个数 = 1)

---    END
```

参见SET MPFATTR的参数说明。
