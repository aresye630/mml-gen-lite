# 删除HTTP链路测量对象(RMV HTTPLNKOBJ)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条HTTP2/HTTP1.1链路测量对象。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                  |
|:----------|:-------|:------------------------------------------------------------------------------------------------------|
| WORKMODE  | 工作模式   | 可选必选说明：必选参数 参数含义：用于标识待删除的HTTP2/HTTP1.1链路测量对象的工作模式。 取值范围： SERVER(SERVER) CLIENT(CLIENT) 默认值：无。 配置原则：无。 |
| LOCALIP   | 本端IP地址 | 可选必选说明：必选参数 参数含义：用于标识待删除的HTTP2/HTTP1.1链路测量对象的本端IP地址。 取值范围：IPV4/IPV6地址格式的字符串，最大长度为40位。 默认值：无。 配置原则：无。  |
| LOCALPORT | 本端端口   | 可选必选说明：必选参数 参数含义：用于标识待删除的HTTP2/HTTP1.1链路测量对象的本端端口。 取值范围：0~65535。 默认值：无。 配置原则：无。                       |
| PEERIP    | 对端IP地址 | 可选必选说明：必选参数 参数含义：用于标识待删除的HTTP2/HTTP1.1链路测量对象的对端IP地址。 取值范围：IPV4/IPV6地址格式的字符串，最大长度为40位。 默认值：无。 配置原则：无。  |
| PEERPORT  | 对端端口   | 可选必选说明：必选参数 参数含义：用于标识待删除的HTTP2/HTTP1.1链路测量对象的对端端口。 取值范围：0~65535。 默认值：无。 配置原则：无。                       |

## 使用实例

删除一条“工作模式”为“SERVER”，“本端IP地址”为“192.168.121.183”， “本端端口”为“31”，“对端IP地址”为“192.168.121.184”, “对端端口”为“32”的链路测量对象：

```
RMV HTTPLNKOBJ: WORKMODE=SERVER, LOCALIP="192.168.121.183", LOCALPORT=31, PEERIP="192.168.121.184", PEERPORT=32;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
