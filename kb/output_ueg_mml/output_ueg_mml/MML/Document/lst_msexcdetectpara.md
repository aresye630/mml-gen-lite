# 查询微服务单用户异常流程冲击防护检测参数(LST MSEXCDETECTPARA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询单用户异常流程冲击防护检测功能配置信息。

## 注意事项

存储Bypass场景不支持配置异常流程防护策略。

## 参数说明

无。

## 使用实例

查询单用户异常流程冲击防护检测功能配置信息。

```
LST MSEXCDETECTPARA:;
```

```
%%LST MSEXCDETECTPARA:;%%
RETCODE = 0  操作成功 

操作结果如下
------------------------
              检测周期  =  1
AUSF服务允许最大消息数  =  8
 UDM服务允许最大消息数  =  20
  支持同时检测的用户数  =  3000
(结果个数 = 1)

---    END
```
