# 修改内部软参(MOD PCFINSP)

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致系统异常，影响业务处理，需联系华为技术支持确认后再执行。

修改内部软参的值，包括定时器时长、系统配置参数、QoS模式等。

## 注意事项

- 该命令用于在配置软参数据时，只需要对软参作适当修改以得到所需要的配置数据，而不需要添加或删除软参的操作。
- 在缺省的情况下，系统在初始化的时候已经预置了软参数据表中的全部数据。
- 本命令中所描述的初始设置值，是指在没有改变初始设置的情况下，操作员通过**LST PCFINSP**命令查询得出的系统初始化的参数值。
- 操作员应使用默认值。如果操作员确实需要修改软件参数，请联系华为公司技术服务工程师处理，禁止随意修改。
- 修改软件参数后，执行**DSP PCFINSP**命令检查软件参数值是否生效。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                 |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------|
| INSPN  | 参数名    | 标识一条软参数据记录的关键字段之一（其取值在枚举值内取得），用于指定需要对哪一类软参数据记录的参数进行查询。 取值说明：详细信息请参考产品手册的“操作维护>软件参数>UPCF软件参数”。 默认值：无。 |
| INSPV  | 参数值    | 标识一条软参数据记录的关键字段之一，此处取值应在取值范围内取值。其中，类型的编号规则是从上到下，从0开始顺序编号。 取值范围：0～2147483647 默认值：无。                   |

## 使用实例

修改内部软参。参数名为VRM\_GLBREFLASHINTERVAL，参数值为22。

```
MOD PCFINSP: INSPN=VRM_GLBREFLASHINTERVAL, INSPV=22;
```
