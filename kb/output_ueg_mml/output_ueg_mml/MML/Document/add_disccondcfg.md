## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致系统异常，影响业务处理，需联系华为技术支持确认后再执行。

该命令用于添加一条PCF到BSF/CHF/SCP/AMF/NWDAF/PCF的服务发现条件信息。当PCF通过指定条件发现远端服务时，需要配置此命令。

- 直接通信场景下，支持配置BSF/CHF/NWDAF的服务发现条件信息。
  - 当对端为CHF时，PCF会根据配置的GPSI或PREFERLOC进行匹配，发现对应的CHF。
  - 当对端为BSF时，PCF会根据配置的IPV4ADDR、IPV4DNN等信息进行匹配，发现对应的BSF。
  - 当对端为NWDAF时，PCF会根据配置的TAI等信息进行匹配，发现对应的NWDAF。
- 间接通信（SCP代理）场景下，支持配置BSF/CHF/AMF/SCP/PCF/NWDAF的服务发现条件信息。
  - 当对端为SCP时，PCF会根据配置的SCPDOMAIN或SERSCOPE进行匹配，发现对应的SCP。
  - 当对端为BSF/CHF/AMF/PCF/NWDAF时，PCF会将本命令配置的信息下发给SCP，由SCP向NRF进行服务发现。

## 注意事项

不支持通过本命令配置的服务发现条件信息对容灾AMF进行服务发现条件。

## 使用实例

增加一个服务发现条件信息。“网元类型”为“BSF”，“BSF参数”为“IPV4ADDR&IPV4IPDOMAIN”：

```
ADD DISCCONDCFG: NFTYPE=BSF, BSFPARA=IPV4ADDR-1&IPV4DNN-0&IPV4IPDOMAIN-1&IPV6PREFIX-0;
```
