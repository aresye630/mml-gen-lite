# 增加对应PODTYPE下CPU的阈值配置（ADD PODHEALCPUTHR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

当前版本此命令可正常下发，但配置不生效。

该命令用于增加对应PODTYPE下CPU的阈值配置。

## 注意事项

- 该命令执行后立即生效。

- 不允许配置hafetcd-pod。可通过LST PODHEALCPUTHR查询已配置的Pod类型，避免配置冲突，只要输入的以“#”分隔的Pod类型在已有记录中就不允许配置。

- 最多可输入1024条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                              |
|:------------|:--------|:--------------------------------------------------------------------------------------------------|
| PODTYPE     | POD类型   | 可选必选说明：必选参数  参数含义：用于设置POD类型。可通过DSP PODINFO查询。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无 |
| NOLOADTHR   | 空载阈值（%） | 可选必选说明：可选参数  参数含义：用于配置某种类型的POD实例的CPU使用率在空载时的阈值。  数据来源：本端规划  取值范围：整数类型，取值范围是1~100。  默认值：无  配置原则：无  |
| OVERLOADTHR | 过载阈值（%） | 可选必选说明：可选参数  参数含义：用于配置某种类型的POD实例的CPU使用率过载的阈值。  数据来源：本端规划  取值范围：整数类型，取值范围是1~100。  默认值：无  配置原则：无    |

## 使用实例

增加对应PODTYPE下CPU的阈值配置。

```
%%ADD PODHEALCPUTHR: PODTYPE="haf-pod", NOLOADTHR=10, OVERLOADTHR=20;%%
RETCODE = 0  操作成功

---    END
```
