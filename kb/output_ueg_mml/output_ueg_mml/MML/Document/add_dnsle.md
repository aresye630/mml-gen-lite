#### 命令功能

**适用NF：SGSN、MME、AMF**

该命令用于增加DNS本端实体，包括：IP地址、端口、VPN名称，以便和DNS服务器进行通信。

#### 注意事项

- 该命令执行后立即生效。
- 本表最大记录数为32条。
- DNSLE配置不包含传输层协议类型，对应的传输层类型由**ADD DNSS**的参数“DNS服务器承载协议”配置。只有通过**ADD DNSS**添加了至少一个DNS服务器后，用**ADD DNSLE**增加的DNS本端实体才能起作用。
- **ADD DNSLE**增加的DNS本端实体只会分布在含两个或两个以上SGP进程的SPU上。
- IP地址和vpn名称必须在SERVICEIP表中已经配置，可以用**LST SERVICEIP**查询。
- 当同时配置了IPv4地址和IPv6地址时，需要保证配置的IPv4地址和IPv6地址数量相同。

#### 本地用户权限

manage-ug；system-ug

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                                                                                                                                                                                   |
|:--------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPT     | IP地址类型    | 可选必选说明：必选参数 参数含义：该参数用于指定IP地址类型。 数据来源：整网规划 取值范围：“IPV4(IPV4)”“IPV6(IPV6)” 默认值：无                                                                                                                                                                          |
| IPV4    | IPv4地址    | 可选必选说明：条件必选参数 参数含义：该参数用于指定IPv4地址。 前提条件：当“IP地址类型”设置为“IPV4(IPV4)”时，该参数有效。 数据来源：整网规划 取值范围：0.0.0.0～255.255.255.255 默认值：无 配置原则：IPv4地址不能为组播地址（224.x.y.z）和环回地址(127.x.y.z)。IPv4地址必须是A、B或者C类地址。该参数不能配置为如下IP地址：xxx.xxx.xxx.0xxx.xxx.xxx.255                      |
| IPV6    | IPv6地址    | 可选必选说明：条件必选参数 参数含义：该参数用于指定IPv6地址。 前提条件：当“IP地址类型”设置为“IPV6(IPV6)”时，该参数有效。 数据来源：整网规划 取值范围：::～FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无 配置原则：IPv6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址(::1)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。 |
| LOCPORT | 本地端口号     | 可选必选说明：必选参数 参数含义：该参数用于指定本端端口号。 数据来源：整网规划 取值范围：15000~65535 默认值：无                                                                                                                                                                                        |
| VPNNAME | VPN名称     | 可选必选说明：可选参数 参数含义：该参数用于指定DNS本端实体到DNS服务器间的链路所用的VPN名称。 数据来源：整网规划 取值范围：0~31个字符。 默认值：无                                                                                                                                                                      |
| LENAME  | DNS本端实体名称 | 可选必选说明：可选参数 参数含义：该参数用于指定DNS本端实体的名称。 数据来源：整网规划 取值范围：0~32个字符。 默认值：无                                                                                                                                                                                      |

#### 使用实例

添加DNS本端实体：IP地址 192.168.97.26；端口15001；VPN名称 \_abc\_；DNS本端实体名称Dnsle26。

ADD DNSLE:IPT=IPV4,IPV4="192.168.97.26",LOCPORT=15001,VPNNAME="\_abc\_",LENAME="Dnsle26";
