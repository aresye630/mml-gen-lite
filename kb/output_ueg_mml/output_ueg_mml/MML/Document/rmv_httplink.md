# 删除链路(RMV HTTPLINK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除HTTP链路。

## 注意事项

删除HTTP链路将可能影响UDM与对端无法正常通信，导致业务中断，请谨慎使用。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                         |
|:-----------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TYPE       | 删除类型     | 可选必选说明：必选参数 参数含义：用于指定按照哪种条件删除HTTP链路。 取值范围： LINKID(链路ID)INSTANCEID(实例ID)PEERIP(对端IP) 默认值：无 配置原则：无                                                                             |
| LINKID     | 链路ID     | 可选必选说明：条件必选参数 参数含义：标识一条链路的关键字段之一，用于指定需要删除哪一条HTTP链路，操作员可以使用DSP UDMHTTPLNK命令查询获得。 取值范围：0~4294967295 默认值：无 配置原则：仅当本命令中的“删除类型”参数为“LINKID(链路ID)”时该参数有效。                           |
| LINKTYPE   | 链路类型     | 可选必选说明：必选参数 参数含义：用于指定需要删除的HTTP链路所对应的链路类型。 取值范围： SERVER(服务端)CLIENT(客户端) 默认值：无 配置原则：无。                                                                                         |
| INSTANCEID | 实例ID     | 可选必选说明：条件必选参数 参数含义：标识链路的关键字段之一，用于指定需要删除哪个实例上的HTTP链路，操作员可以使用DSP UDMHTTPLNK命令查询获得。 取值范围：长度不超过32位的字符串。 默认值：无 配置原则：仅当本命令中的“删除类型”参数为“INSTANCEID(实例ID)”或“LINKID(链路ID)”时该参数有效且不能为空。 |
| PEERIPVER  | IP地址类型   | 可选必选说明：条件必选参数 参数含义：用于指定需要删除HTTP链路所在对端的IP地址类型。 取值范围： IPV4(IPV4开关)IPV6(IPV6开关) 默认值：无 配置原则：仅当本命令中的“删除类型”参数为“PEERIP(对端IP)”时该参数有效且不能为空。                                           |
| PEERIPV4   | 对端IPV4地址 | 可选必选说明：条件必选参数 参数含义：标识链路的关键字段之一，用于指定需要删除HTTP链路所在对端的IPV4地址。 取值范围：标准IPV4地址。 默认值：无 配置原则：仅当本命令中的“IP地址类型”参数为“IPV4(IPV4开关)”时该参数有效。                                                  |
| PEERIPV6   | 对端IPV6地址 | 可选必选说明：条件必选参数 参数含义：标识链路的关键字段之一，用于指定需要删除HTTP链路所在对端的IPV6地址。 取值范围：标准IPV6地址。 默认值：无 配置原则：仅当本命令中的“IP地址类型”参数为“IPV6(IPV6开关)”时该参数有效。                                                  |

## 使用实例

1. 删除一条链路数据，“删除类型”为“INSTANCEID(实例ID)”，“链路类型”为“CLIENT(客户端)”，“实例ID”为“13110641869221825038”：

   ```
   RMV HTTPLINK: TYPE=INSTANCEID, LINKTYPE=CLIENT, INSTANCEID="13110641869221825038", CONFIRM=Y;
   ```

   ```
   %%RMV HTTPLINK: TYPE=INSTANCEID, LINKTYPE=CLIENT, INSTANCEID="13110641869221825038", CONFIRM=Y;%%
   RETCODE = 0  操作成功

   操作结果如下:
   ------------

   服务类型  =  UdmHttpService
     实例ID  =  13110641869221825038
   执行结果  =  OK
   (结果个数 = 1)

   ---    END
   ```
2. 删除一条链路数据，“删除类型”为“PEERIP(对端IP)”，“链路类型”为“CLIENT(客户端)”，“IP地址类型”为“IPV4(IPV4开关)”，“对端IPV4地址”为“192.168.121.183”：

   ```
   RMV HTTPLINK: TYPE=PEERIP, LINKTYPE=CLIENT, PEERIPVER=IPV4, PEERIPV4="192.168.121.183", CONFIRM=Y;
   ```

   ```
   %%RMV HTTPLINK: TYPE=PEERIP, LINKTYPE=CLIENT, PEERIPVER=IPV4, PEERIPV4="192.168.121.183", CONFIRM=Y;%%
   RETCODE = 0  操作成功

   操作结果如下:
   ------------
   服务类型        实例ID                执行结果  

   UdmHttpService  13110641869221842985  OK        
   UdmHttpService  13110641869221700911  OK        
   (结果个数 = 2)

   ---    END
   ```
3. 删除一条链路数据，“删除类型”为“LINKID(链路ID)”，“链路ID”为“1865622853”，“链路类型”为“CLIENT(客户端)”，“实例ID”为“13110641869221825038”：

   ```
   RMV HTTPLINK: TYPE=LINKID, LINKID=1865622853, LINKTYPE=CLIENT, INSTANCEID="13110641869221825038", CONFIRM=Y;
   ```

   ```
   %%RMV HTTPLINK: TYPE=LINKID, LINKID=1865622853, LINKTYPE=CLIENT, INSTANCEID="13110641869221825038", CONFIRM=Y;%%
   RETCODE = 0  操作成功

   操作结果如下:
   ------------

   服务类型  =  UdmHttpService
     实例ID  =  13110641869221825038
   执行结果  =  OK
   (结果个数 = 1)

   共有1个结果

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息，表1列出的是各输出项的解释说明。

| 输出项名称   | 输出结果解释                          |
|:--------|:--------------------------------|
| 服务类型    | 用于返回链路所在服务的服务类型。                |
| 实例ID    | 用于返回链路所在HLB服务的实例ID。             |
| 执行结果    | 用于返回对应HLB服务实例的处理结果。 取值范围： OKNOK |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 消息解释     | 原因分析                                                                                                                                                                                                                                                | 处理建议                                                 |
|-------:|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------|
| 360159 | 未匹配到链路   | 可能原因为如下之一： 当“删除类型”参数取值为“LINKID(链路ID)”时，“实例ID”参数指定的链路不存在。当“删除类型”参数取值为“INSTANCEID(实例ID)”时，“实例ID”参数指定的链路不存在。（当参数“链路类型”取值为“SERVER(服务端)”时，系统不会上报该错误码）当“删除类型”参数取值为“PEERIP(对端IP)”时，“对端IPV4地址”或“对端IPV6地址”参数指定的链路不存在。（当参数“链路类型”取值为“SERVER(服务端)”时，系统不会上报该错误码） | 使用DSP UDMHTTPLNK查询链路信息，找到需要删除链路对应的信息，并重新输入。          |
| 360160 | 对端服务响应失败 | HttpDisCtrlService、NRFClient、UdmAuthService或者UdmSubService服务未回复响应，“可用状态”为“NULL”或“未就绪”。                                                                                                                                                              | 使用DSP UDMSERVICE查看服务的可用状态，联系华为技术支持修复不正常的服务后，重新执行此命令。 |
