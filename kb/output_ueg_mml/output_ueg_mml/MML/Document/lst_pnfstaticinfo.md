# 查询对端网元静态信息(LST PNFSTATICINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询对端网元静态信息。

- 若需要查询某条对端网元静态信息，请输入“静态配置名称”。

- 若需要查询所有对端网元静态信息，不输入任何参数。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                    |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------|
| STNAME | 静态配置名称 | 可选必选说明：必选参数。 参数含义：用于指定需要查询哪一条对端网元静态信息数据记录。 取值范围：长度不超过32字节的字符串，只允许输入：0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。 |

## 使用实例

1.查询特定订阅信息，“静态配置名称”为“udm01”：

```
LST PNFSTATICINFO: STNAME="udm01";
```

