# 查询通用会话拓展功能（LST EDGESMCOMMFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF、PGW-C**

该命令用于查询通用会话管理扩展功能。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询通用会话管理扩展功能，执行如下命令：

```
%%LST EDGESMCOMMFUNC:;%%
RETCODE = 0  操作成功

结果如下
--------
  Radius静态IP功能开关  =  不使能
       二次重选UDM开关  =  不使能
     UDM静态IP功能开关  =  不使能
         UDM静态IP类型  =  单栈
5G LAN本地签约功能开关  =  不使能
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称          | 输出项解释                                                                                                    |
|:---------------|:---------------------------------------------------------------------------------------------------------|
| Radius静态IP功能开关 | 该参数用于设置是否开启Radius静态IP功能。此开关开启后，才能使用ADD RDSSTATICIPPARA配置的静态IP。                                           |
| 二次重选UDM开关      | 该参数用于设置SMF是否开启二次重选UDM功能。                                                                                 |
| UDM静态IP功能开关    | 该参数用于设置是否开启UDM静态IP功能。此开关开启后，才能使用ADD RDSSTATICIPPARA配置的静态IP。                                              |
| UDM静态IP类型      | 该参数用于设置UDM静态IP类型。用于指示在UDM Bypass场景本地配置静态IP时，如果本地配置静态IP只有一个IPV4或者IPV6而会话请求地址类型是IPV4V6双栈时，是按照单栈处理还是按照双栈处理。 |
| 5G LAN本地签约功能开关 | 该参数用于控制开启和关闭5G LAN本地签约功能。该参数仅对层二5G LAN生效。配置为ENABLE时，优先使用本地签约的5G LAN组ID激活层二5G LAN会话。                      |
