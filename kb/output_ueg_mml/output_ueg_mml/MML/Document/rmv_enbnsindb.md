# 删除配置的eNodeB邻接关系(RMV ENBNSINDB)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

此命令用于删除手动添加的eNodeB邻接关系。

#### 注意事项

此命令执行后立即生效，并将导致整网所有eNodeB邻接关系的学习时间变长。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                                                                                             |
|:--------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ENBTYPE | eNodeB类型 | 可选必选说明：必选参数 参数含义：待删除邻接关系的中心eNodeB的类型。 取值范围：“HOME_ENODEB(Home_eNodeB)”：表示中心eNodeB类型为家庭基站，其标志长度为28位。“MACRO_ENODEB(Macro_eNodeB)”：表示中心eNodeB类型为宏基站，其标识长度为20位。 默认值：无 |
| MCC     | 移动国家码    | 可选必选说明：必选参数 参数含义：待删除邻接关系的中心eNodeB和邻接eNodeB共用的移动国家码。 取值范围：3位十进制数字 默认值：无                                                                                           |
| MNC     | 移动网号     | 可选必选说明：必选参数 参数含义：待删除邻接关系的中心eNodeB和邻接eNodeB共用的移动网号。 取值范围：2～3位十进制数字 默认值：无                                                                                          |
| ENBID   | eNodeB标识 | 可选必选说明：必选参数 参数含义：待删除邻接关系的中心eNodeB的ID。 取值范围：0～268435455 默认值：无                                                                                                     |

#### 使用实例

删除一条手动添加的eNodeB邻接关系，其中心eNodeB的“eNodeB类型”为“HOME\_ENODEB(Home\_eNodeB)”，“移动国家码”为“123”，“移动网号”为“01”，“eNodeB标识”为“327697”：

RMV ENBNSINDB: ENBTYPE=HOME\_ENODEB, MCC="123", MNC="01", ENBID=327697;
