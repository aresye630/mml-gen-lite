# 增加HTTP均衡控制IP(ADD HTTPBCIP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于添加一条均衡控制HTTP链路的IP记录。

## 注意事项

- 该命令最大记录数为2048。
- 当前系统支持的HTTP负载均衡策略数量上限为20480条，HTTP负载均衡策略数量等于通过本命令添加的HTTP均衡控制IP记录数和通过**ADD HTTPLSERVER**添加的本端服务器配置记录数的乘积。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                 |
|:---------|:---------|:---------------------------------------------------------------------------------------------------------------------|
| BCIPNAME | 均衡控制IP名称 | 可选必选说明：必选参数 参数含义：用于标识均衡控制IP地址名称。 取值范围：长度不超过128的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。                          |
| IPVER    | IP地址类型   | 可选必选说明：必选参数 参数含义：用于标识均衡控制IP地址类型。 取值范围： IPV4(IPV4)：配置IPV4类型IP地址时使用。IPV6(IPV6)：配置IPV6类型IP地址时使用。 默认值：无。 配置原则：无。         |
| IPV4ADDR | IPV4地址   | 可选必选说明：条件必选参数 参数含义：用于标识均衡控制IPV4地址。 取值范围：IPV4地址 默认值：无。 配置原则： 当“IP地址类型”参数为“IPV4”时，该参数为必选参数。该参数需要配置为HTTP链路对应的对端网元的IP地址。 |
| IPV6ADDR | IPV6地址   | 可选必选说明：条件必选参数 参数含义：用于标识均衡控制IPV6地址。 取值范围：IPV6地址 默认值：无。 配置原则： 当“IP地址类型”参数为“IPV6”时，该参数为必选参数。该参数需要配置为HTTP链路对应的对端网元的IP地址。 |

## 使用实例

增加一条均衡控制HTTP链路的IP记录。“均衡控制IP名称”为“bcipname\_1”,“IP地址类型”为“IPV4(IPV4)”，“IPV4地址”为“192.168.0.3”。

```
ADD HTTPBCIP: BCIPNAME="bcipname_1", IPVER=IPV4, IPV4ADDR="192.168.0.3",CONFIRM=Y;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释                          | 原因分析                    | 处理建议                                                                                                      |
|-------:|:------------------------------|:------------------------|:----------------------------------------------------------------------------------------------------------|
| 360203 | 添加失败，相同的IP地址已存在，冲突的IP名称为：XXX。 | 输入的IP地址已经存在。            | 请重新输入正确的IP地址，确保IP地址不重叠。                                                                                   |
| 360206 | IP名称不合法。                      | 输入的“均衡控制IP名称”不在参数取值范围内。 | 该参数取值仅支持数字，字母，下划线和连字符，根据参数取值范围和配置原则重新输入“均衡控制IP名称”参数值，然后重新执行本命令。                                           |
| 360209 | HTTP负载均衡策略数量超过最大限制。           | HTTP负载均衡策略数量已经超过20480条。 | 通过LST HTTPBCIP查询HTTP均衡控制IP记录数，通过LST HTTPLSERVER查询本端服务器配置记录数，删除无效的数据，确保HTTP均衡控制IP记录数和本端服务器配置记录数乘积不超过20480。 |
