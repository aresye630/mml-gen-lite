# 删除GTP-C V2协议兼容性(RMV GTPCV2CMPT)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于删除GTP-C V2协议兼容性配置。

#### 注意事项

此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                     |
|:-------|:-------|:---------------------------------------------------------|
| IDX    | 索引     | 可选必选说明：必选参数 参数含义：该参数用于指定唯一标识特定的可选信元的索引。 取值范围：0～511 默认值：无 |

#### 使用实例

删除一条GTP-C V2协议兼容性的配置，索引为0的记录：

RMV GTPCV2CMPT: IDX=0;
