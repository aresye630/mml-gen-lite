# 修改跟踪区列表(MOD TALST)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用来修改跟踪区列表配置数据。

#### 注意事项

- 该命令执行后立即生效。
- 该命令只能修改“描述”。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称       | 参数说明                                                                                     |
|:---------|:-----------|:-----------------------------------------------------------------------------------------|
| TALISTID | TA List 标号 | 可选必选说明：必选参数 参数含义：该参数用于在MME内唯一标识一个跟踪区列表。一个跟踪区列表由若干跟踪区TA组合而成。 数据来源：本端规划 取值范围：0~65534 默认值：无 |
| TAI      | TAI        | 可选必选说明：必选参数 参数含义：该参数用于在一个MME内唯一标识一个跟踪区。 数据来源：整网规划。 取值范围：9~10位字符串 默认值：无                   |
| DESC     | 描述         | 可选必选说明：可选参数 参数含义：该参数用于指定跟踪区列表名称。 数据来源：整网规划 取值范围：长度不超过32的字符串 默认值：无                        |

#### 使用实例

将包含跟踪区1230100010的跟踪列表1的描述改为“AREA3”：

MOD TALST: TALISTID=1, TAI="1230100010", DESC="AREA3";
