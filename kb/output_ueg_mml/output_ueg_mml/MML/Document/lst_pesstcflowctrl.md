# 查询PES静态流控配置(LST PESSTCFLOWCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询PES静态流控参数信息。

- 如果需要查询所有PES静态流控参数信息，请不要输入任何参数。
- 如果需要查询指定PES静态流控参数信息，请依据参数说明输入查询的条件。

## 注意事项

无。

## 参数说明

| 参数标识            | 参数名称                | 参数说明                                                                                                                                                                                                                          |
|:----------------|:--------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PESSTCFLWCTRFLG | PES静态流控开关           | 可选必选说明：可选参数 参数含义：用于指示系统按照是否开启“PES静态流控开关”来查询PES静态流控参数信息；若不输入，则表示当前配置的PES静态流控开关值。 取值范围： ON(打开PES静态流控) OFF(关闭PES静态流控) 默认值：无。 配置原则：无。                                                                                             |

| UPDATEMSGNUM    | 单个PES Update消息流控阈值  | 可选必选说明：可选参数 参数含义：用于指示系统按照“单个PES Update消息流控阈值”的值来查询PES静态流控参数信息；若不输入，则表示当前配置的单个PES Update消息流控阈值。 取值范围：0-65535，并且能被10整除。 单位：TPS 默认值：无。 配置原则：无。  说明： 此处的Update消息，包括N7/N15/N24/Gx的Update消息以及N24的UpdateNotify Update（/Terminate)消息。 |

| AARMSGNUM       | 单个PES AAR消息流控阈值     | 可选必选说明：可选参数 参数含义：用于指示系统按照“单个PES AAR消息流控阈值”的值来查询PES静态流控参数信息；若不输入，则表示当前配置的单个PES AAR消息流控阈值。 取值范围：0-65535，并且能被10整除。 单位：TPS 默认值：无。 配置原则：无。                                                                                         |

## 使用实例

假如运营商需要修改PES静态流量控制开关、启控条件等参数，需要先查询PES静态流控配置。

```
LST PESSTCFLOWCTRL:;
```

```
%%LST PESSTCFLOWCTRL:;%%
RETCODE = 0  操作成功

操作结果如下 
------------
            PES静态流控开关  =  打开PES静态流控
    单个PES总消息数流控阈值  =  1800
单个PES Initial消息流控阈值  =  360
 单个PES Update消息流控阈值  =  720
 单个PES Delete消息流控阈值  =  360
    单个PES AAR消息流控阈值  =  240
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。
