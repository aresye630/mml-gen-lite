# 查询APN（LST APN）

- 注意事项

- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询APN数据记录。

- 若需要查询全部APN信息，请不要输入任何参数值。
- 若需要查询全部APN信息中符合某一参数条件的APN时，请在对应参数中输入对应的参数值。

## 注意事项

无。

| APNTYPE      | APN类型   | 用于指示系统需要按照哪个APN类型来查询APN数据记录；若不输入，则表示所有的APN类型。 取值范围：Revalidation-APN(Revalidation-APN)：表示该APN是用在RevalidationTimeout/RE_TIMEOUT事件触发器用作会话审计的场景，即该APN用来做Revalation的判断。Multi-PCEF-APN(Multi-PCEF-APN)：表示该APN是用来处理Multi-PCEF场景的。当系统开启了APN识别会话功能，但某对端不携带APN时，可以添加此类型虚拟APN。Emergency-APN(Emergency-APN)：表示紧急呼叫APN。如果CCR_I携带的APN能够匹配到系统配置的Emergency-APN的APN，则表示该CCR_I是紧急呼叫消息。当流控发生时，对紧急呼叫的Gx Rx会话放通。配置了Emergency-APN并不等于是Volte，如果需要将紧急呼叫APN识别为语音会话，还需要再配置一个同名的Volte-APN。 VoLTE-APN(VoLTE-APN)：表示该APN是用来处理VoLTE场景的。若VoLTE业务配置该类型的APN，则对VoLTE会话生效，若VoLTE业务没有配置该类型的APN，则对VoLTE会话不生效。例如：当用户签约了VoLTE业务，并且VOLTE会话备份功能开关（软参VRM_GXSESSIONONLYVOLTE控制）以及会话备份功能开关（软参VRM_SESSIONBACKUPSWITCH控制）均打开了，只有当该用户配置了VoLTE-APN，UPCF才只会备份此VoLTE业务场景下的Gx会话。该类型的APN包含正常VoLTE数据业务APN和紧急呼叫APN。如果在流控场景下需要保证紧急呼叫，则需要将该紧急呼叫APN再通过该命令配置成“Emergency-APN(Emergency-APN)”类型增加到系统中。 如果Gx会话的APN为“VoLTE-APN(VoLTE-APN)”，当对端保活释放时该会话不会释放。 Force-Sy-APN(Force-Sy-APN)：用户在携带该类型APN上线时，如果软参VRM_SYSWITCH配置为“3”，则UPCF开启Sy/N28接口功能，与对端OCS/CHF建立Sy/N28会话。Ignore-SPR-APN(Ignore-SPR-APN)：用户在携带该类型APN上线时，UPCF直接发起Sy/N28会话请求，不再到BE或外置SPR中查询用户及其签约信息。此APN支持与“Force-Sy-APN(Force-Sy-APN)”共存，且只有在软参VRM_SYSWITCH配置为“3”时才生效。会话加入该类型APN后，不再支持短信抑制功能。 不支持将企业组用户、主从用户加入到“Ignore_SPR_APN(Ignore-SPR-APN)”，否则用户将无法正常使用共享业务。  说明： “APN类型”配置为“Ignore-SPR-APN(Ignore-SPR-APN)”时，UPCF不再查询BE或外置SPR： UPCF无法到BE或外置SPR中获取用户Email地址，因此不支持以邮件形式发送消息通知。UPCF无法到BE或外置SPR中获取用户MSISDN，因此不支持发送SOAP通知。UPCF无法到BE或外置SPR中获取用户MSISDN。此时，若软参“VRM_DYNSMSMSISDN”配置为“1”，UPCF支持通过Gx接口获取MSISDN以短信形式发送用户通知。 Statistics-APN(Statistics-APN)：表示该APN是用来进行性能指标统计的。如果Gx接口CCR-I消息携带或Gx会话保存的APN能够匹配到系统配置的Statistics-APN的APN，则CCR-I和RAR消息将用于基于APN的性能指标统计。Realm-Replace-APN(Realm-Replace-APN)：表示该APN是用来替换PCF/PCRF域名的。如果Gx接口CCR-I消息携带的或者Gx会话保存的APN能够匹配到系统配置的“Realm-Replace-APN”的APN，则CCA/RAR/ASR消息中的源PCF/PCRF域名将替换为记录中配置的指定本地域名。指定PCRF域名以CCR-I消息携带的APN为准，会话在线期间APN发生变化时指定PCRF域名保持不变。 Bypass-IP-APN (Bypass-IP-APN)：该APN仅允许在局点测试时，需要对GX/N7会话在IP冲突场景下进行紧急放通时临时使用，局点商用后禁止使用。会话在携带该类型APN/DNN上线后，UPCF不存储该会话携带的IP信息，不支持该会话使用与IP相关的功能。 注意： 配置Bypass-IP-APN类型APN，将导致与IP相关功能失效。如IP冲突检查、IP会话绑定、会话备份，与BSF交互，基于IP的维护等，配置前请联系华为技术支持确认后再执行。对已在线的会话配置为该类APN时，需要先踢会话下线后再配置。 默认值：无。 |

## 使用实例

1. 查询APN数据记录。

   ```
   LST APN:;
   ```

   ```
   %%LST APN:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
      PCRF标识  =  1
       APN标识  =  0
       APN名称  =  CMIMS
       APN类型  =  Revalidation-APN
   APN匹配类型  =  FullMatching
      接口类型  =  N7
   (结果个数 = 1)

   ---    END
   ```
