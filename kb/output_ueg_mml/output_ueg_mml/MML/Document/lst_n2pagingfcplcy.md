# 查询N2模式寻呼消息反压流控策略（LST N2PAGINGFCPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询N2模式寻呼反压流控功能的相关策略。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询当前系统的N2模式寻呼消息反压流控策略，执行如下命令：

```
%%LST N2PAGINGFCPLCY:;%%
RETCODE = 0  操作成功

结果如下
----------------------
N2寻呼反压流控功能开关 = 开启
      精准寻呼控制开关 = 开启
      寻呼重发控制开关 = 开启
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称          | 输出项解释                                                                 |
|:---------------|:----------------------------------------------------------------------|
| N2模式寻呼反压流控功能开关 | 该参数用于指定是否开启N2模式寻呼反压流控功能。                                              |
| 精准寻呼控制开关       | 该参数用于控制N2模式寻呼反压流控功能开启时，是否按照Last gNodeB+TA List策略对N2模式数据和语音寻呼请求进行精准寻呼。 |
| 寻呼重发控制开关       | 该参数用于控制寻呼反压流控功能开启时，是否不重复发送N2寻呼请求。                                     |
