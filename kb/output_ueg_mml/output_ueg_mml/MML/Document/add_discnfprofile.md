# 增加服务发现网元实例信息(ADD DISCNFPROFILE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加一个服务发现网元实例信息。当PCF采取静态方式发现远端服务时，需要配置此命令。

**说明** 

使用本命令配置的对端最大总数包含如下：

- 对端AMF支持的最大数量为512。
- 对端SCP支持的最大数量为256。
- 对端CHF支持的最大数量为64。
- 对端BSF支持的最大数量为257。
- 对端UDR支持的最大数量为16。
- 对端NWDAF支持的最大数量为128。
- 对端PCF支持的最大数量为256。

## 注意事项

配置的网元实例信息中的IP+端口的组合要求唯一。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                       |
|:----------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSNAME | 网元实例名称 | 可选必选说明：必选参数 参数含义：用于标识一个服务发现网元实例的名称。 取值范围：长度不超过64的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：该参数全局唯一，不能重复。                                                                                                                                                                                                                                                                                                                   |
| NFINSID   | 网元实例标识 | 可选必选说明：必选参数 参数含义：用于标识服务发现网元实例在系统中的序号，该参数为UUIDv4格式。 UUIDv4格式为“xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx”，例如：4947a69a-f61b-4bc1-b9da-47c9c5d14b64。 取值范围：长度固定为36位的字符串，只允许输入0～9，a～f，A～F，“-”。 默认值：无。 配置原则：无。                                                                                                                                                                                                                         |
| NFTYPE    | 网元类型   | 可选必选说明：必选参数 参数含义：用于标识该服务发现网元实例的类型。 取值范围：UDM(统一数据管理)AUSF(鉴权服务功能)PCF(策略控制功能)UDR(统一数据存储库)AMF(接入和移动性管理功能)SMF(会话管理功能)NEF(网络能力开放功能实体)AF(应用功能)SMSF(短消息业务功能)BSF(绑定支持功能)CHF(计费功能)SCP(服务通信代理)NWDAF(网络数据分析功能） 默认值：无。 配置原则：无。                                                                                                                                                                                                          |
| NFPROFILE | 网元实例信息 | 可选必选说明：必选参数 参数含义：用于标识服务发现网元实例的详细信息，该参数为JSON格式。 取值范围：长度不超过8000的字符串。 默认值：无。 配置原则：无。  说明： 参考网元实例信息配置中信元“网元实例信息”的格式，其中nfInstanceID、nfType两个参数必须和ADD DISCNFPROFILE命令的“网元实例标识”、“网元类型”一致。配置该参数时，必须使用nfServices数组结构和nfServiceList MAP结构当中的一种结构，且不能同时使用两种结构。该参数必须配置ipv4Addresses或ipv6Addresses。配置该参数时，如果nfServiceList以serviceInstanceId作为KEY值，则serviceInstanceId不能重复（两个serviceInstanceId仅是字母大小写不一样，也认为重复）。其中包含的信元名称详情可参考Nnrf接口信令分析。 |

## 使用实例

增加一个服务发现网元实例信息。“网元实例名称”为“bsf”，“网元实例标识”为“6947a69a-f61b-4bc1-b9da-47c9c5d14b64”，“网元类型”为“BSF(会话绑定功能实体)”，“网元实例信息”为“{"nfInstanceId":"6947a69a-f61b-4bc1-b9da-47c9c5d14b64","nfType":"BSF","nfStatus":"REGISTERED","ipv4Addresses":["10.199.43.237"]}”:

```
ADD DISCNFPROFILE: NFINSNAME="bsf", NFINSID="“6947a69a-f61b-4bc1-b9da-47c9c5d14b64”", NFTYPE=BSF, NFPROFILE="{\"nfInstanceId\":\"6947a69a-f61b-4bc1-b9da-47c9c5d14b64\",\"nfType\":\"BSF\",\"nfStatus\":\"REGISTERED\",\"ipv4Addresses\":[\"10.199.43.237\"]}";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|  58119 | 服务实例标识冲突。                               | “网元实例信息”携带有多个“serviceInstanceId”参数值重复。                                                                                                                                                                                                                                                                                                                   | 重新输入“网元实例信息”携带的参数值“serviceInstanceId”，保证其值的唯一性。                                          |
|  58265 | NFPROFILE下的nwdafInfo或nwdafInfoList配置非法。 | “网元实例信息”下的nwdafInfo或nwdafInfoList下的nwdafInfo存在非法的通配：nwdafInfo下的nwdafEvents，taiList，taiRangeList同时为空。例如nwdafInfo:{}，nwdafInfo:{nwdafEvents:[],taiList:[],taiRangeList:[]}。nwdafInfoList下的nwdafInfo配置非法：nwdafInfoList中存在超过32字节长度的主键（map key）。nwdafInfoList下的nwdafInfo超过8个。nwdafInfoList下的nwdafInfo中的nwdafEvents集合元素超过8个。nwdafInfo中单个nwdafEvent字符串长度超过32字节。 | 重新输入“网元实例信息”携带的参数值“nwdafInfo”或“nwdafInfoList”，保证其值符合格式要求。                                |
