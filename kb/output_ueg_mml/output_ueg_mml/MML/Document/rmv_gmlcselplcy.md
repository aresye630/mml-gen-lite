# 删除GMLC选择策略(RMV GMLCSELPLCY)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于删除指定条件下的GMLC选择策略。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称        | 参数说明                                                                                                                                                                          |
|:--------------|:------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GMLCGRPID     | GMLC选择策略组索引 | 可选必选说明：必选参数 参数含义：该参数在系统内唯一标识一个GMLC组。 数据来源：本端规划 取值范围：0~191 默认值：无 配置原则：该参数需要在ADD GMLCSELGRP中事先配置，可执行LST GMLCSELGRP进行查看。                                                         |
| LCSCLIENTTYPE | LCS客户端类型    | 可选必选说明：必选参数 参数含义：该参数用于标识LCS客户端类型。 数据来源：整网规划 取值范围：“EMERGENCY_SERVICES(紧急业务)”“VALUE_ADDED_SERVICES(增值业务)”“PLMN_OPERATOR_SERVICES(运营商业务)”“LAWFUL_INTERCEPT_SERVICES(合法定位)” 默认值：无 |
| LOCATIONTYPE  | 位置区标识类型     | 可选必选说明：必选参数 参数含义：该参数标识位置标识类型。 数据来源：整网规划 取值范围：“ECI(小区标识)”“TAC(跟踪区编码)” 默认值：无                                                                                                    |
| TACBEGIN      | 跟踪区起始编码     | 可选必选说明：条件必选参数 参数含义：该参数表示跟踪区起始编码。 前提条件：该参数在"位置区标识类型"参数配置为"跟踪区编码"后生效。 数据来源：整网规划 取值范围：0x0000~0xFFFF 默认值：无                                                                        |
| ECIBEGIN      | 小区起始标识      | 可选必选说明：条件必选参数 参数含义：该参数表示E-UTRAN小区起始标识。 前提条件：该参数在"位置区标识类型"参数配置为"小区标识"后生效。 数据来源：整网规划 取值范围：0~268435455 默认值：无                                                                     |

#### 使用实例

删除索引为0的GMLC选择策略组内一条选择策略。该记录的LCS客户端类型为EMERGENCY\_SERVICES（紧急业务）、小区起始标识为1。

RMV GMLCSELPLCY: GMLCGRPID=0, LCSCLIENTTYPE=EMERGENCY\_SERVICES, LOCATIONTYPE=ECI, ECIBEGIN=1;
