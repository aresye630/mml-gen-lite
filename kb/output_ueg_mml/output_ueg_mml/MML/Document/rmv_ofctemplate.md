# 删除离线计费模板或者属性（RMV OFCTEMPLATE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

此命令用于删除离线计费模板或恢复参数的默认值。当指定ATTRIBUTE参数时，则恢复对应参数的默认值，当不指定ATTRIBUTE时，则删除离线计费模板。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称     | 参数说明                                                                                                                                                                                                         |
|:----------------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OFCTEMPLATENAME | 离线计费模板名  | 可选必选说明：必选参数 参数含义：配置离线模板名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格。 默认值：无 配置原则：无                                                                                                                              |
| ATTRIBUTE       | 离线计费模板属性 | 可选必选说明：可选参数 参数含义：离线计费模板属性。 数据来源：对端协商 取值范围：枚举类型。 THRESHOLD：表示恢复模板阈值的默认值。CDR_TRIGGER：表示恢复模板中的话单产生开关的默认值。CONTAINER_TRIGGER：表示恢复模板中的容器产生开关的默认值。TQM：表示恢复模板中的时长配额机制的默认值。CDR_VERSION：表示恢复模板中的话单版本的默认值。 默认值：无 配置原则：无 |

#### 使用实例

删除一个名称为“ofc\_test”的离线计费模板：

```
RMV OFCTEMPLATE:OFCTEMPLATENAME="ofc_test";
```
