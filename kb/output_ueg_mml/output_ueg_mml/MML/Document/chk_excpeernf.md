# 检查例外对端NF（CHK EXCPEERNF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响业务处理，需联系华为技术支持确认后再执行。

该命令用于检查配置例外对端NF的无效配置记录，即配置非SMF/AMF/AF对端网元的相关信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

检查非SMF/AMF/AF对端网元信息。

```
CHK EXCPEERNF:;
```

```
%%CHK EXCPEERNF:;%%
RETCODE = 0  操作成功

操作结果如下
------------
IP地址                 NF类型

192.168.57.51          CHF
192.168.57.41          NRF                           
(结果个数 = 2)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1。

| 输出项名称   | 输出项解释                                                                                        |
|:--------|:---------------------------------------------------------------------------------------------|
| IP地址    | 用于表示错误配置的IP地址，即配置非SMF/AMF/AF对端网元的IP地址。                                                       |
| NF类型    | 用于表示错误配置的NF类型，即配置除了SMF/AMF/AF对端网元以外的例外对端NF类型。  说明： 显示的NF类型为PCF类型时，当前版本表示为N24接口服务发现的HPCF对端类型。 |
