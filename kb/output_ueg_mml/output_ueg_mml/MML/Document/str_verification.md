# 启动一次FEI与FES之间的对账操作（STR VERIFICATION）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

通过手动启动对账命令行操作，可以实现表项的平滑与老化操作，使FEI与FES之前表项保持一致。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                               |
|:-------|:-------|:---------------------------------------------------------------------------------------------------|
| RUNAME | RU名称   | 可选必选说明：可选参数 参数含义：资源单元名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则： 区分大小写，不支持空格。使用DSP RU查看RU名称。 |

#### 使用实例

对所有转发表进行对账操作：

```
STR VERIFICATION:RUNAME="VNODE_VNRS_VNFC_IPU_0064";
```
