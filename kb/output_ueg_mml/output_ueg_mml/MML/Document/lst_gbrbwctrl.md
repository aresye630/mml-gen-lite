# 查询GBR承载带宽速率控制配置（LST GBRBWCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：GGSN、PGW-C、SMF**

该命令用来查询GBR承载带宽速率控制配置信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称          | 参数说明                                                                                                                                       |
|:---------|:--------------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| CTRLTYPE | 控制类型          | 可选必选说明：可选参数  参数含义：该参数用于指定QoS控制的类型。  数据来源：全网规划 取值范围： APN_LEVEL（APN级别）GLOBAL_LEVEL（整系统级别）  默认值：无  配置原则：无                                     |
| APN      | APN名称         | 可选必选说明：该参数在"CTRLTYPE"配置为"APN_LEVEL"时为条件可选参数。  参数含义：该参数用于指定APN实例名。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是0~63。  默认值：无  配置原则：  该参数使用ADD CPAPN命令配置生成。 |
| MBRUL    | 上行最大速率(千比特/秒) | 可选必选说明：可选参数  参数含义：该参数用于指定组成GBR承载带宽控制的上行最大速率(千比特/秒)。  数据来源：全网规划  取值范围：整数类型，取值范围是1~20000000。  默认值：无  配置原则：无                                  |
| MBRDL    | 下行最大速率(千比特/秒) | 可选必选说明：可选参数  参数含义：该参数用于指定组成GBR承载带宽控制的下行最大速率(千比特/秒)。  数据来源：全网规划  取值范围：整数类型，取值范围是1~20000000。  默认值：无  配置原则：无                                  |
| GBRUL    | 上行保证速率(千比特/秒) | 可选必选说明：可选参数  参数含义：该参数用于指定组成GBR承载带宽控制的上行保证大速率(千比特/秒)。  数据来源：全网规划  取值范围：整数类型，取值范围是1~20000000。  默认值：无  配置原则：无                                 |
| GBRDL    | 下行保证速率(千比特/秒) | 可选必选说明：可选参数  参数含义：该参数用于指定组成GBR承载带宽控制的下行保证大速率(千比特/秒)。  数据来源：全网规划  取值范围：整数类型，取值范围是1~20000000。  默认值：无  配置原则：无                                 |

## 使用实例

查询所有GBRBWCTRL配置：

```
LST GBRBWCTRL:;
```
