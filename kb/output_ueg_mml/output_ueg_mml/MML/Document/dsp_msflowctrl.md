# 查询微服务流控状态(DSP MSFLOWCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询微服务的流控策略状态，执行该命令可以查询服务实例是否处于流控状态，以及最近周期收到的消息总数、流控时的消息丢弃率和微服务流控资源实时状态等信息。

- 若需要查询全部流控策略状态，请不要输入任何参数。
- 若需要查询具体某一条流控策略状态，请输入需要查询的参数或参数的组合。

## 注意事项

GBA场景下（仅虚机场景涉及），不支持查询微服务的流控策略状态。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FCTYPE   | 流控类型   | 可选必选说明：可选参数 参数含义：用于标识系统按照哪个流控类型查询流控策略状态。若不输入，表示查询所有流控策略状态。 取值范围：CPUFC(CPUFC)：表示HLB/AUSF/UDM/ENS的CPU流控。ASSUDRFC(ASSUDRFC)：表示UDM对USCDB的起控协控。ASSUDMFC(ASSUDMFC)：表示HLB对UDM/AUSF的起控协控。SCHEDULEFC(SCHEDULEFC)：表示基于调度的时延流控。 默认值：无。 配置原则：该参数仅在取值为“CPUFC(CPUFC)”时，支持查询GBA场景下（仅虚机场景涉及）的“微服务实例ID”、“微服务类型”、 “最近周期收到的消息总数”和“微服务流控资源实时状态”，其他取值时，查询结果无效。                                                                                                                                                                                                                                                                                                      |
| FCMSTYPE | 微服务类型  | 可选必选说明：可选参数 参数含义：用于标识系统按照哪个微服务类型查询流控策略状态。 取值范围：HLB(HLB)UDM(UDM)AUSF(AUSF)ENS(ENS) 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| FCITEM   | 流控资源项  | 可选必选说明：可选参数 参数含义：用于标识系统按照哪个流控资源项查询流控策略状态。 当“流控类型”取值为“CPUFC(CPUFC)”，“微服务类型”为“HLB(HLB)”、“UDM(UDM)”、“AUSF(AUSF)”或“ENS(ENS)”时，取值范围如下：NODECPU(NODECPU)：表示虚机CPU（裸机POD CPU）。CONTCPU(CONTCPU)：表示容器CPU。PROCCPU(PROCCPU)：表示进程CPU。 默认值：无。 当“流控类型”取值为“ASSUDRFC(ASSUDRFC)”，“微服务类型”为“UDM(UDM)”或“AUSF(AUSF)”时，取值范围如下：GDRUFCR(GDRUFCR)：表示全局DRU流控。DRUFCR(DRUFCR)：表示DRU流控。DSUFCR(DSUFCR)：表示DSU流控。DSGFCR(DSGFCR)：表示DSG流控。DBSFCR(DBSFCR)：表示DBS流控。 默认值：无。 当“流控类型”取值为“ASSUDMFC(ASSUDMFC)”，“微服务类型”为“HLB(HLB)”时，取值范围如下：UDMFCR(UDMFCR)：表示UDM流控。AUSFFCR(AUSFFCR)：表示AUSF流控。 默认值：无。 当“流控类型”取值为“SCHEDULEFC(SCHEDULEFC)”时，取值范围如下：LATENCY(LATENCY)：表示基于调度时延的流控。 默认值：无 配置原则：无。 |

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，其中微服务实例流控率（%）仅在处于流控状态时显示。各参数含义请参见

**MOD MSFLOWCTRL**

命令的参数说明，其他输出项参数解释如表1所示。

| 参数标识           | 参数名称        | 参数说明                                                                  |
|:---------------|:------------|:----------------------------------------------------------------------|
| MSINSID        | 微服务实例ID     | 用于标识查询的HLB服务实例ID。                                                     |
| FLOWCTRLSTATE  | 微服务流控状态     | 用于标识当前服务是否处于流控状态。                                                     |
| DISCARDRATE    | 微服务实例流控率(%) | 用于标识流控状态下微服务收到消息的丢弃率（该参数仅在流控时呈现）。 消息丢弃率=（手工流控的消息数+自适应流控的消息数）/接收到的总消息数 |
| MANUALDROP     | 手工流控丢弃的消息数  | 用于标识手工流控丢弃的消息数。                                                       |
| AUTODROP       | 自适应流控丢弃的消息数 | 用于标识自适应流控丢弃的消息数。                                                      |
| TOTALMSG       | 最近周期收到的消息总数 | 用于标识微服务处理业务时每秒收到的消息总量（包含被手工流控丢弃的消息数和自适应流控的消息数）。                       |
| REALTIMESTATUS | 微服务流控资源实时状态 | 用于标识流控状态下的CPU使用率或协控起控比。                                               |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

| 360132 | 查询任务已经下发，无需重复下发 | 存在正在进行的查询任务。      | 请在上一个查询指令完成后，重新执行该命令进行查询。                                                                               |
