# 设备间的快速审计(SND AUDIT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响业务处理，需联系华为技术支持确认后再执行。

该命令用于UPCF手工触发快速审计。

- 该命令执行后，会导致短时间内存在大量RAR(ASR)/SLR/Nchf\_SpendingLimitControl\_Subscribe/Npcf\_SMPolicyControl\_UpdateNotify请求消息。
- 该命令执行后，可以通过**DSP AUDITSTATUS**命令查询设备间的快速审计信息。

**说明** 

- UPCF不支持同时处理多个设备间的快速审计的任务。执行该命令前请先执行查询命令**DSP AUDITSTATUS**，如果已经有任务正在执行中，请等正在执行的任务完成后再执行，否则正在执行任务的PES服务会忽略对新任务的处理。
- 当处理Gx/N7接口会话设备间审计时：

  - 当软参“VRM\_DEVAUDITSTARTTIME”取值为“5”时，系统对创建时间未超过5分钟的会话不发起设备间审计。
  - 当软参“VRM\_DEVAUDITSTARTTIME”取值为“X（5＜X≤1440）”时，系统对最近一次交互未超过X分钟的会话不发起设备间审计。
- 可通过**VRM\_DEVAUDITACCELERATION**软参控制是否快速的完成设备间会话审计。当前版本不支持Gx接口通过该软参进行设备间审计提速。

## 注意事项

同一时间只能处理一个此命令发起的任务，在执行命令前请先执行命令**DSP AUDITSTATUS**，确保其他快速审计任务已完成。若上次快速审计任务未结束时就执行本命令，命令并发执行可能会导致返回13005或520错误码，此时等待最后一次快速审计任务完成即可。

**须知** 

此命令执行时会触发大量RAR(ASR)/SLR/Nchf\_SpendingLimitControl\_Subscribe/Npcf\_SMPolicyControl\_UpdateNotify请求消息，对系统性能有影响，请谨慎使用。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                     |
|:--------------|:-------|:-------------------------------------------------------------------------------------------------------------------------|
| INTERFACETYPE | 接口类型   | 用于标识审计接口类型。 取值范围： Gx(Gx)Rx(Rx)Sy(Sy)Sd(Sd)N28(N28)N7(N7)Bsf(Bsf) 默认值：Gx(Gx)。  说明： 如果SND AUDIT执行时不携带该参数，则按照默认值Gx处理。       |
| RARSENDSPEED  | 审计发送速度 | 用于设置PES服务每秒发送快速审计消息的条数。 取值范围：10～200，并且能被10整除。 默认值：50。  说明： 如果SND AUDIT执行时不携带该参数，则按照默认值50处理。当前版本暂不支持对Sy/N28接口审计发送速度的变更控制。 |

## 使用实例

1. 发送设备间的快速审计，“接口类型”为“Rx(Rx)”，“审计发送速度”为“100”。

   ```
   SND AUDIT: INTERFACETYPE=Rx, RARSENDSPEED=100;
   ```
2. 发送设备间的快速审计，“接口类型”为“Gx(Gx)”，“审计发送速度”为“200”。

   ```
   SND AUDIT: INTERFACETYPE=Gx, RARSENDSPEED=200;
   ```
