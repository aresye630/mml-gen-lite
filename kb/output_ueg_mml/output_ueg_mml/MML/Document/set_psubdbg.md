# 设置用户日志跟踪（SET PSUBDBG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响系统性能，需联系华为技术支持确认后再执行。

该命令用于问题定位时，对UPCF用户进行日志跟踪，包含Gx、Sd、Rx、N7、N15、N5、N23、N24和N28接口消息触发的日志。

用户的日志文件输出到服务所在容器的“opt/csplog/{appid}/PcfPolicyEngineService/export/log/”目录下，例如“/opt/csplog/20/PcfPolicyEngineService/export/log/”。

日志下载步骤参考服务日志收集，勾选“PcfPolicyEngineService”服务创建日志收集任务后进行下载。

## 注意事项

- 跟踪会影响系统性能，仅限于华为工程师使用，并且在问题定位完成后及时关闭日志跟踪开关。
- 当执行SET SERDBG命令开启错误码跟踪任务后，才能执行本命令跟踪到用户会话日志。即执行本命令跟踪用户会话日志前，需要先执行如下命令行：

  ```
  SET SERDBG: CMDTYPE=STR_ERR_TRACE, IFTYPE=接口, ERRCODE=错误码;
  ```

  **说明** 

  - 当参数“IFTYPE”取值为“Gx(Gx)”时，可以跟踪Gx、Sd、N7、N15、N23和N24接口消息触发的用户会话日志。
  - 当参数“IFTYPE”取值为“Rx(Rx)”时，可以跟踪Rx和N5接口消息触发的用户会话日志。
- 当用户会话跟踪任务完成后，需要执行如下命令行关闭错误码跟踪任务功能：

  ```
  SET SERDBG: CMDTYPE=STP_ERR_TRACE;
  ```

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
|:----------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CMDTYPE   | 命令类型   | 用于设置用户日志跟踪的开关。 取值范围：ON（开启）：启动指定用户的日志跟踪OFF（关闭）：关闭指定用户的日志跟踪或者关闭所有用户的日志跟踪 默认值： 无。                                                                                                                                                                                                                                                                                                                                                                                  |
| SUBID     | 用户标识   | 用于设置用户日志跟踪的用户标识。该参数必须先由PGW Web LMT上的开户命令ADD PSUB中的参数“用户标识”定义，然后才能在此处索引。 取值范围：长度不超过255的字符串。 默认值： 无。                                                                                                                                                                                                                                                                                                                                                              |
| LOGTYPE   | 日志类型   | 用于控制输出单用户的日志类型。当命令类型取值“ON”时该参数有效。 取值范围：All（全部日志）：同时输出单用户的调试日志和策略日志；或者同时输出单用户的调试日志、策略日志和会话日志 Debug（调试日志）：只输出单用户的调试日志；或者只输出单用户的调试日志和会话日志Policy（策略日志）：只输出单用户的策略日志；或者只输出单用户的策略日志和会话日志 默认值： All。  说明： 本命令中跟踪用户会话日志的功能依赖于SET SERDBG命令开启错误码跟踪任务的能力。如果SET SERDBG命令没有开启错误码跟踪任务的能力，则不会输出用户会话日志。比如：当SET SERDBG命令开启错误码跟踪任务的功能后，如果本命令的参数“日志类型”取值为“All（全部日志）”，则会同时输出单用户的调试日志、策略日志和会话日志。当SET SERDBG命令关闭错误码跟踪任务的功能后，如果本命令的参数“日志类型”取值为“All（全部日志）”，则只会同时输出单用户的调试日志和策略日志，不会输出会话日志。 |
| VALIDTIME | 有效时长   | 用于设置用户日志跟踪的有效时间。当“命令类型”取值“ON”时该参数有效。 取值范围：1～40 单位：天。 默认值： 1。                                                                                                                                                                                                                                                                                                                                                                                                    |

## 使用实例

1. 启动对用户86136\*\*\*\*的日志跟踪，有效时长为1天。

   “命令类型”为“ON”，“用户标识”为“86136\*\*\*\*”，“有效时长”为“1”。

   ```
   SET PSUBDBG: CMDTYPE=ON, SUBID="86136****", VALIDTIME=1;
   ```

   ```
   %%SET PSUBDBG: CMDTYPE=ON, SUBID="86136****", LOGTYPE=All, VALIDTIME=1, CONFIRM=Y;%%
   RETCODE = 0  操作成功

   ---    END
   ```
2. 关闭所有用户的日志跟踪。

   “命令类型”为“OFF”。

   ```
   SET PSUBDBG: CMDTYPE=OFF;
   ```

   ```
   %%SET PSUBDBG: CMDTYPE=OFF, CONFIRM=Y;%%
   RETCODE = 0  操作成功

   ---    END
   ```
