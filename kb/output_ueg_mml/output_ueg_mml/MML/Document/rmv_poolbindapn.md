# 删除APN实例与地址池绑定关系（RMV POOLBINDAPN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于解除APN与地址池的绑定关系。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                          |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------|
| POOLNAME | 地址池名称  | 可选必选说明：必选参数  参数含义：该参数用于指定地址池名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~79。  默认值：无  配置原则：  该参数使用ADD CPADDRPOOL命令配置生成。 |
| APN      | APN名称  | 可选必选说明：必选参数  参数含义：该参数用于指定APN/DNN名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。  默认值：无  配置原则：  该参数使用ADD CPAPN命令配置生成。  |

## 使用实例

解除指定APN与地址池的绑定，“APN”为“huawei.com” ，“POOLNAME”为“lap”：

```
RMV POOLBINDAPN:APN="huawei.com",POOLNAME="lap";
```
