#### 命令功能

**适用网元：SGSN、MME**

此命令用于增加MVNO的配置。MVNO（Mobile Virtual Network Operator，移动虚拟网络运营商）利用MNO（Mobile Network Operator，移动网络运营商）授权的网络资源，提供业务（包括MNO提供的业务以及MVNO自己定制的业务），并能对授权的资源进行维护。

#### 注意事项

- 此命令执行后立即生效。
- 此命令最大记录数为64。
- 此配置涉及MVNO特性（特性编号：WSFD-207005，license部件编码：LKV2MVNO02），执行命令请使用**DSP LICENSE**命令确认对应特性license是否得到授权，执行**LST LICENSESWITCH**命令确认特性开关状态为“ENABLE(打开)”。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                      |
|:----------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MVNOID    | MVNO标识 | 可选必选说明：必选参数 参数含义：该参数用于指定MVNO的标识。 数据来源：整网规划 取值范围：1～64 默认值：无  说明： MVNOID参数必须要与已配置的MVNOID不同。                                                                                                                                                                                                 |
| MVNON     | 运营商全称  | 可选必选说明：可选参数 参数含义：该参数用于指定运营商全称。 数据来源：整网规划 取值范围：0～79位字符串，数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符 默认值：无  说明： GMM information/EMM information消息中携带的“Full name for network”信元值来源于该参数。因终端实现不同，可能部分终端优先使用SIM/USIM卡自带的网络名称，此时网络侧下发的网络名称会不生效。运营商全称不能输入“NULL”，字母不区分大小写。  |
| SHORTNAME | 运营商简称  | 可选必选说明：可选参数 参数含义：该参数用于指定运营商简称。 数据来源：整网规划 取值范围：0～79位字符串，数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、“+”、空格符以及中文字符，其他均为非法字符 默认值：无  说明： GMM information/EMM information消息中携带的“Short name for network”信元值来源于该参数。因终端实现不同，可能部分终端优先使用SIM/USIM卡自带的网络名称，此时网络侧下发的网络名称会不生效。运营商简称不能输入“NULL”，字母不区分大小写。 |
| S5S8TYPE  | 协议类型   | 可选必选说明：可选参数 参数含义：该参数用于指定虚拟运营商在S5/S8口使用的协议类型。 数据来源：整网规划 取值范围：“GTP(GTP)”“PMIP(PMIP)” 默认值：GTP(GTP)                                                                                                                                                                                           |

#### 使用实例

增加一个MVNO标识为1，运营商全称为aaa，运营商简称为a，协议类型为GTP的MVNO配置信息：

ADD MVNO: MVNOID=1, MVNON="aaa", SHORTNAME="a", S5S8TYPE=GTP;
