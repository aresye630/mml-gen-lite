# 查询IPsec隧道接口（LST IPSECINTFCFG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询IPsec隧道。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                            |
|:--------------|:-------|:----------------------------------------------------------------|
| INTERFACENAME | 接口名称   | 可选必选说明：可选参数 参数含义：配置接口名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 |

#### 使用实例

查询接口名为“Tunnel1/1/1”的安全隧道：

```
LST IPSECINTFCFG:INTERFACENAME="Tunnel1/1/1";
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
        接口名称  =  Tunnel1/1/1
Tunnel口协议类型  =  IP安全
(结果个数 = 1)
---    END
```
