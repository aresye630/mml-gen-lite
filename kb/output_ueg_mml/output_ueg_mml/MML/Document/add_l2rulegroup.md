# 增加层二规则组（ADD L2RULEGROUP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于添加层二规则组。可使用该层二规则组绑定多个层二规则。

## 注意事项

- 该命令执行后只对新接入的会话生效。

- 最多可输入10000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识            | 参数名称    | 参数说明                                                                                              |
|:----------------|:--------|:--------------------------------------------------------------------------------------------------|
| L2RULEGROUPNAME | 层二规则组名称 | 可选必选说明：必选参数  参数含义：该参数用于指定层二规则组名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。不支持空格，不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

增加一个层二规则组名称为“rulegrp1”：

```
ADD L2RULEGROUP: L2RULEGROUPNAME="rulegrp1";
```
