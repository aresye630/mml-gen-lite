# 查询客户端首次认证（LST RSFTPFIRSTTIME）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UDM**

该命令用于查询客户端首次认证。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

无。

#### 使用实例

查询SSH客户端首次认证是否使能：

```
LST RSFTPFIRSTTIME:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
首次认证使能  =  使能
(结果个数 = 1) 
---    END
```
