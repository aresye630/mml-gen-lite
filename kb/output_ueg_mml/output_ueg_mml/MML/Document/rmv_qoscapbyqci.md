# 删除基于QCI的Non-GBR承载QoS限制配置(RMV QOSCAPBYQCI)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于根据用户范围及承载的QCI删除Non-GBR承载QoS限制配置记录。

#### 注意事项

- 该命令执行后对于新接入的EPS承载立即生效。如果当前用户已经激活了EPS承载，该命令的限制会在用户下一次会话管理业务流程中生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                          |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：必选参数 参数含义：该参数表示使用QoS限制的用户范围。 数据来源：整网规划 取值范围：“ALL_USER(所有用户)”：指网络中的所有用户。“IMSI_PREFIX(指定IMSI前缀)：指网络中与指定的IMSI前缀匹配的用户。”“HOME_USER(本网用户)：指网络中的本网签约用户。”“FOREIGN_USER(外网用户)：指网络中的漫游用户。” 默认值：无 |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI前缀。 前提条件：该参数在“用户范围”参数配置为“IMSI_PREFIX(指定IMSI前缀)”后生效。 数据来源：整网规划 取值范围：5~15位数字。 默认值：无                                                                               |
| QCI      | QCI    | 可选必选说明：必选参数 参数含义：该参数表示使用QoS限制的用户签约的承载的QCI。 数据来源：整网规划 取值范围：1~9 默认值：无                                                                                                                           |

#### 使用实例

运营商规划网络，删除IMSI前缀为3080107000，QCI为5的用户QoS限制配置：

RMV QOSCAPBYQCI: SUBRANGE=IMSI\_PREFIX, IMSIPRE="3080107000", QCI=5;
