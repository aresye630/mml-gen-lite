# 删除CP白名单（RMV CPACCESSLIST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于删除CP的白名单列表。

#### 注意事项

该命令执行后只对新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称               | 参数说明                                                                                                                                                                                     |
|:--------------|:-------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| WHITELISTTYPE | 白名单参数类型            | 可选必选说明：必选参数 参数含义：该参数用于指定CP白名单的参数类型。 数据来源：全网规划 取值范围：枚举类型。 NODEID：白名单参数类型为Node ID。IP：白名单参数类型为IP地址。 默认值：无 配置原则：无                                                                            |
| IPVERSION     | IP地址版本类型           | 可选必选说明：条件必选参数 前提条件：该参数在“WHITELISTTYPE”配置为“IP”时为必选参数。 参数含义：该参数用例指定IP类型。 数据来源：全网规划 取值范围：枚举类型。 IPV4：表示地址类型为IPv4。IPV6：表示地址类型为IPv6。 默认值：无 配置原则：无                                              |
| CPNODEIDTYPE  | CP Node ID类型       | 可选必选说明：条件必选参数 前提条件：该参数在“WHITELISTTYPE”配置为“NODEID”时为必选参数。 参数含义：该参数用来指定Node ID类型。 数据来源：全网规划 取值范围：枚举类型。 IPv4：表示Node ID类型为IPv4地址。IPv6：表示Node ID类型为IPv6地址。FQDN：表示Node ID类型为FQDN。 默认值：无 配置原则：无 |

| CPIPV6        | CP IPv6地址          | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV6”时为必选参数。 参数含义：指定要进行白名单控制的CP的IPv6地址段的地址，该配置需要和网络规划一致。 数据来源：全网规划 取值范围：IPv6地址类型。 默认值：无 配置原则：无                                                     |
| CPIPV4MASK    | CP IPv4掩码长度        | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV4”时为必选参数。 参数含义：该参数指定白名单控制的CP的IPv4地址段的掩码长度。 数据来源：全网规划 取值范围：整数类型，取值范围为1～32。 默认值：无 配置原则：无                                                          |
| CPIPV6MASK    | CP IPv6掩码长度        | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV6”时为必选参数。 参数含义：该参数用来指定白名单控制的CP的IPv6地址段的掩码长度。 数据来源：全网规划 取值范围：整数类型，取值范围为1～128。 默认值：无 配置原则：无                                                       |
| CPNODEIDIPV4  | CP Node ID中的IPv4地址 | 可选必选说明：条件必选参数 前提条件：该参数在“CPNODEIDTYPE”配置为“IPv4”时为必选参数。 参数含义：该参数用于指定允许建立偶联的CP的Node ID中的IPv4地址。 数据来源：全网规划 取值范围：IPv4地址类型。 默认值：无 配置原则：无                                                       |
| CPNODEIDIPV6  | CP Node ID中的IPv6地址 | 可选必选说明：条件必选参数 前提条件：该参数在“CPNODEIDTYPE”配置为“IPv6”时为必选参数。 参数含义：该参数用户设定允许建立偶联的CP的Node ID中的IPv6地址。 数据来源：全网规划 取值范围：IPv6地址类型。 默认值：无 配置原则：无                                                       |
| CPNODEIDFQDN  | CP Node ID的FQDN    | 可选必选说明：条件必选参数 前提条件：该参数在“CPNODEIDTYPE”配置为“FQDN”时为必选参数。 参数含义：该参数用户设定允许建立偶联的CP的Node ID中的FQDN。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～255。不支持空格，必须是可见ASCII码，不区分大小写。 默认值：无 配置原则：无                      |

#### 使用实例

用户要删除对CP的IP地址的白名单功能的控制，需要删除已配置的IP地址的记录，CPIPV4为10.36.0.2，CPIPV4MASK为27：

```
RMV CPACCESSLIST: WHITELISTTYPE=IP, IPVERSION=IPV4, CPIPV4="10.36.0.2", CPIPV4MASK=27;
```
