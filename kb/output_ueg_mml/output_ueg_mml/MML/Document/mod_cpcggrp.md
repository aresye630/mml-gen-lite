# 修改抄送CG组（MOD CPCGGRP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

此命令用来修改抄送CG组的描述。

#### 注意事项

- 该命令执行后立即生效。
- 输入空格则清除抄送CG组描述。
- 当前版本不支持此命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                      |
|:------------|:--------|:------------------------------------------------------------------------------------------|
| CPCGGRPID   | 抄送CG组ID | 可选必选说明：必选参数 参数含义：抄送CG组的ID。 数据来源：本端规划 取值范围：整数类型，取值范围为1。整数1。 默认值：无 配置原则：无                   |
| DESCRIPTION | 抄送CG组描述 | 可选必选说明：可选参数 参数含义：抄送CG组的描述。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。 |

#### 使用实例

修改抄送CG组ID为1的抄送CG组的描述为"test"：

```
MOD CPCGGRP: CPCGGRPID=1, DESCRIPTION="test";
```
