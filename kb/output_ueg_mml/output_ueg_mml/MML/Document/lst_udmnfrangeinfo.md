# 查询网元号段信息(LST UDMNFRANGEINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询网元号段信息。

- 若需要查询某个号段的详细信息，请输入“索引”参数；
- 若需要查询某个组的号段信息，请输入“组名称”参数；
- 若需要查询所有号段信息，不输入任何参数。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                     |
|:----------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------|
| GRPNAME   | 组名称    | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个组名称来查询网元号段信息；若不输入，则表示查询所有的组名称。 取值范围：长度不超过32的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：该参数和“索引”参数组成全局唯一对象关键字段。 |
| INDEX     | 索引     | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个索引来查询网元号段信息；若不输入，则表示查询所有的索引。 取值范围：1~100000。 默认值：无。 配置原则：该参数和“组名称”参数组成全局唯一对象关键字段。                              |
| RANGETYPE | 号段类型   | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个号段类型来查询网元号段信息；若不输入，则表示查询所有的号段类型。 取值范围： SUPI(用户永久标识)GPSI(通用公共用户标识)EXGROUP(外部组) 默认值：无。 配置原则：无。                  |

## 使用实例

1. 查询所有号段信息：

   ```
   LST UDMNFRANGEINFO:;
   ```

   ```
   %%LST UDMNFRANGEINFO:;%%
   RETCODE = 0  操作成功

   组名称         索引  号段类型          开始             结束             模式  

   rangeSupi_01   1     用户永久标识      123456789040000  123456789059999  NULL    
   rangeSupi_02   2     用户永久标识      NULL             NULL             ^imsi-12345678904[0-9]{4}$  
   (结果个数 = 2)

   ---    END
   ```
2. 查询特定号段信息，“索引”为“1”：

   ```
   LST UDMNFRANGEINFO: INDEX=1;
   ```

   ```
   %%LST UDMNFRANGEINFO: INDEX=1;%%
   RETCODE = 0  操作成功

     组名称  =  rangeSupi_01
       索引  =  1
   号段类型  =  用户永久标识
       开始  =  123456789040000
       结束  =  123456789059999
       模式  =  NULL
   (结果个数 = 1)

   ---    END
   ```
3. 查询特定号段信息，“组名称”为“supi-group-01”

   ```
   LST UDMNFRANGEINFO: GRPNAME="supi-group-01";
   ```

   ```
   %%LST UDMNFRANGEINFO: GRPNAME="supi-group-01";%%
   RETCODE = 0  操作成功

     组名称  =  supi-group-01
       索引  =  1
   号段类型  =  用户永久标识
       开始  =  123456789040000
       结束  =  123456789059999
       模式  =  NULL
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD UDMNFRANGEINFO**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                                      | 原因分析                   | 处理建议                                 |
|------:|:-------------------------------------------|:-----------------------|:-------------------------------------|
|   579 | 配置记录数超过上限40960，如需查看完整信息请缩小查询范围或执行EXP MML命令 | 配置的网元号段信息记录数超过上限40960。 | 请分批查询网元号段信息，如输入参数“组名称”、“索引”、“号段类型”等。 |
