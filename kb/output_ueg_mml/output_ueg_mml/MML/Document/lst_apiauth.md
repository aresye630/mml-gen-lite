# 查询API token鉴权配置（LST APIAUTH）

#### 命令功能

**适用NF：UPF、MPF**

该命令用于查询API token鉴权配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询token鉴权配置：

```
LST APIAUTH:;
```

```
RETCODE = 0  操作成功

API鉴权开关
-----------
鉴权开关  =  不使能
(结果个数 = 1)

---    END
```
