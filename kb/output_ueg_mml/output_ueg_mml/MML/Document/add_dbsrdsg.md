# 增加远端DSG(ADD DBSRDSG)

## 命令功能

该命令为配置类命令，用于增加远端DSG。远端DSG用于和dbbroker进行通信。

该命令的使用场景：当华为DBS需与USCDB对接时，需要通过该命令增加远端DSG模块。

通过以下步骤配置对接数据：

1. 通过**ADD DBSRLOCATION**命令增加远端Location标识。
2. 通过本命令增加远端DSG模块。
3. 通过**ADD DBSRIPADDR**命令增加远端IP地址。

完成以上配置之后，通过**ACT DBSIPDISP**命令激活链路，完成华为DBS与USCDB的对接配置。

## 注意事项

- 首先通过**ADD DBSRLOCATION**命令配置远端Location后，才能通过该命令配置远端DSG。
- 远端Location中需要存在DSG模块。

## 参数说明

| 参数标识    | 参数名称         | 参数说明                                                                                                                     |
|:--------|:-------------|:-------------------------------------------------------------------------------------------------------------------------|
| RLOCID  | 远端Location标识 | 可选必选说明：必选参数 参数含义：用于指定一个远端网元标识。 取值范围：1～512 默认值：无。 配置原则：该参数须在对接的远端USCDB网元中先定义，然后在本端网元通过ADD DBSRLOCATION命令配置后，才能在此处索引。      |
| RDSGMID | 远端DSG模块号     | 可选必选说明：必选参数 参数含义：用于标识远端DSG模块号。 取值范围：1～2047 默认值：无。 配置原则：该参数必须在对接的远端网元中先定义，然后才能在此处索引。                                      |
| RDSGST  | 远端DSG业务类型    | 可选必选说明：可选参数 参数含义：用于标识远端DSG业务类型。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：该参数为联想参数列表，不能手动输入，其取值为LST DBSSRVGROUP命令查询获得的“业务类型名称”输出参数。 |

## 使用实例

在配置对接时，增加远端Location标识后，增加一条远端DSG配置：“远端Location标识”为“10”，“远端DSG模块号”为“5”，“远端DSG业务类型”为“SUP-FE”。

```
ADD DBSRDSG: RLOCID=10, RDSGMID=5, RDSGST="SUP-FE";
```
