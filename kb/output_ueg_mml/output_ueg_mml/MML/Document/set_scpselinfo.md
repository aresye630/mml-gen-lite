# 设置选择SCP的方式(SET SCPSELINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令用于设置选择SCP的方式。

该命令的使用场景：当PCF与SCP对接的场景下，可使用本命令设置选择SCP网元的方式，选择本地配置优先或NRF发现优先。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
|:-------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MODE   | SCP选择模式 | 可选必选说明：必选参数 参数含义：用于设置使用SCP的优先级。 取值范围： LOCALFIRST(LOCALFIRST)：表示优先使用本地配置的SCP网元。REMOTEFIRST(REMOTEFIRST)：表示优先使用NRF发现的SCP网元。 默认值：LOCALFIRST(LOCALFIRST)。 配置原则：无。  说明： 为了保证通信代理功能的连续性和可靠性，在优先选择的SCP网元不可用时，系统可直接使用另外一种模式下的获得的SCP网元。 比如，“SCP选择模式”取值为“LOCALFIRST(LOCALFIRST)”，但本地配置的SCP网元不可用，系统会选择使用NRF发现的SCP网元对接发送消息。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| SCHEME | 方案      | 可选必选说明：必选参数 参数含义：用于选择采用http或https通信的SCP。 取值范围： http(http)https(https) 默认值：http(http) 配置原则： 参数取值需要与SCP协商一致。采用http或https通信方案需要跟ADD HLBDEVADDR命令添加的“TOEDGE”参数取值为“NO”的记录的“HTTPS功能”参数配置保持一致。如果执行MOD HLBDEVADDR命令修改了“HTTPS功能”参数，此参数也需同步修改。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| METHOD | SCP选择方法 | 可选必选说明：可选参数 参数含义：用于选择可用SCP的方法与顺序。 取值范围： PRIORITY(PRIORITY)：表示选择SCP网元时按照SCP网元的优先级高低进行选择，优先选择优先级高的SCP网元。CAPACITY(CAPACITY)：表示选择SCP网元时按照SCP网元的容量大小进行选择，优先选择容量大的SCP网元。LOCALITY(LOCALITY)：表示选择SCP网元时按照SCP网元的所在区域进行选择，优先选择与NF客户端（即PCF）同区域的SCP网元。 默认值：PRIORITY(PRIORITY)。 配置原则：无。  说明： 系统按照如下原则选择可用的SCP： 当“SCP选择方法”取值为“PRIORITY(PRIORITY)”时：优先选择优先级高的SCP网元。如果通过优先级筛选出了多个SCP网元，则再按照SCP网元容量大小进行选择。如果通过网元容量筛选出了多个SCP网元，则随机选择一个。 当“SCP选择方法”取值为“CAPACITY(CAPACITY)”时：优先选择容量大的SCP网元。如果通过网元容量筛选出了多个SCP网元，则再按照SCP网元优先级高低进行选择。如果通过优先级筛选出了多个SCP网元，则随机选择一个。 当“SCP选择方法”取值为“LOCALITY(LOCALITY)”时：优先选择优先级高的SCP网元。如果通过优先级筛选出了多个SCP网元，则再基于locality属性进行选择：如果PCF未向NRF注册locality属性，则：优先选择容量大的SCP网元。如果通过网元容量筛选出了多个SCP网元，则随机选择一个。 如果PCF已向NRF注册locality属性，则：优先选择与PCF同区域的SCP网元。如果没有SCP网元与PCF位于同区域或者有多个SCP网元与PCF位于同区域，则再按照SCP网元容量大小进行选择。如果通过网元容量筛选出了多个SCP网元，则随机选择一个。 |

## 使用实例

设置选择SCP的方式，其中，“SCP选择模式”为“LOCALFIRST(LOCALFIRST)”，“方案”为“http(http)”，“SCP选择方法”为“CAPACITY(CAPACITY)”。

```
SET SCPSELINFO: MODE=LOCALFIRST, SCHEME=http, METHOD=CAPACITY;
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                                     | 原因分析                                                                                                                                  | 处理建议                                                                                                                                                 |
|------:|:------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
| 58135 | SCHEME参数值与HLB设备地址信息不一致。                   | 输入参数“方案”的取值跟ADD HLBDEVADDR命令的“HTTPS功能”参数配置不一致。                                                                                        | 使用命令LST HLBDEVADDR查询并重新输入“方案”，确保其取值跟“HTTPS功能”参数配置保持一致。                                                                                               |
| 58208 | IP地址不允许引用自HLBDEVADDR对象中“TOEDGE”为“Yes”的记录。 | 可能出现以下场景： 执行命令SET SCPSELINFO时，IP地址引用自“TOEDGE”为“YES”的记录。执行命令SET SCPSELINFO时，SCPSELINFO对象中的参数“SCHEME”和HLBDEVADDR对象中的参数“HTTPSFUNC”配置不一致。 | 执行LST HLBDEVADDR查询，确保IP地址引用自“TOEDGE”为“NO”的记录。若IP地址引用自“TOEDGE”为“NO”的记录，则在执行SET SCPSELINFO命令时确保SCPSELINFO对象的参数“SCHEME”和HLBDEVADDR对象的参数“HTTPSFUNC”配置一致。 |
