# 增加UDM Bypass最小签约数据配置（ADD UDMBYPASSSUB）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于对指定的用户（群）增加UDM Bypass最小签约数据配置。用户处于UDM BYPASS状态之后，AMF无法从UDM获取用户签约数据，如果系统内无用户历史签约数据，使用该命令手动配置用户最小签约数据，保证业务惯性运行。

## 注意事项

- 执行本命令后，仅针对用户新流程生效。

- 最多可输入1024条记录。
- 参数UEUSAGETYPE若不设置，默认值为65535。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

对全网用户，新增UDM Bypass最小签约数据配置，执行如下命令：

```
ADD UDMBYPASSSUB: SUBRANGE=ALL_USER, UEUSAGETYPE=1, MICOALLOWED=TRUE, ODBPACKETSR=ALL_PACKET_SERVICES, NSINALLOWED=TRUE, SNSSAIINFOSSW=ON, SNSSAIINFOS="1-D143A5:cmnet|cmwap&1-D143A7:cmnet", LBOROAMALLOWED=TRUE, IWKEPSLND=TRUE;
```
