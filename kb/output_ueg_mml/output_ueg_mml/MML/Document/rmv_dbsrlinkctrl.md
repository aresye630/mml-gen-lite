# 删除远端DSG链路中心(RMV DBSRLINKCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除远端DSG链路中心。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称         | 参数说明                                                                                                                              |
|:-------|:-------------|:----------------------------------------------------------------------------------------------------------------------------------|
| INDEX  | 配置索引         | 可选必选说明：必选参数 参数含义：标识一条远端DSG链路中心配置信息的关键字段，用于指定需要删除哪一条远端DSG链路中心配置记录，该索引在系统中唯一，操作员可以使用LST DBSRLINKCTRL命令查询获得。 取值范围：1～64 默认值：1 配置原则：无  |
| RLOCID | 远端Location标识 | 可选必选说明：必选参数 参数含义：标识一个远端网元DSG链路中心的关键字段，用于指定需要删除哪一个远端Location标识的远端网元DSG链路中心。操作员可以使用LST DBSRLINKCTRL命令查询获得。 取值范围：1～512 默认值：无。 配置原则：无 |

## 使用实例

删除远端DSG链路中心，“配置索引”为“3”，“远端Location标识”为“77”。命令示例如下：

```
RMV DBSRLINKCTRL: INDEX=3, RLOCID=77;
```
