# 修改GTPP本端信息（MOD GTPPLOCINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

该命令用来修改GTPP本端信息。

#### 注意事项

- 该命令执行后立即生效。
- 当前版本不支持此命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称    | 参数说明                                                                                                                    |
|:---------------|:--------|:------------------------------------------------------------------------------------------------------------------------|
| HOSTNAME       | 本端主机名   | 可选必选说明：必选参数 参数含义：该参数用于指定本端主机名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格。 默认值：无 配置原则：无                                     |
| REALMNAME      | 本端域名    | 可选必选说明：可选参数 参数含义：该参数用于指定本端域名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格。 默认值：无 配置原则：无                                      |
| SERVICECONTEXT | 业务上下文标识 | 可选必选说明：可选参数 参数含义：该参数用于标识业务上下文ID，业务上下文Id是业务定位文档的标识。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格。 默认值：无 配置原则：无                 |
| LOCINTERFACE   | 本端接口名   | 可选必选说明：必选参数 参数含义：该参数用于指定GTPP本端接口名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD CPLOGICINF命令配置生成。 |

#### 使用实例

修改GTPP本端信息，本端主机名为“test”，本端域名为“test”， 业务上下文标识为“abc”， 逻辑接口名称为“gaif1/0/1”：

```
MOD GTPPLOCINFO: HOSTNAME="test", REALMNAME="test", SERVICECONTEXT="abc", LOCINTERFACE="gaif1/0/1";
```
