# 删除重定义协议（RMV PROTREDEFINE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令,执行本命令后将删除指定或所有重定义协议配置，可能影响业务识别结果，导致计费或控制策略发生变化，请谨慎使用。

该命令用来删除所有PROTOREDEFINE配置信息，或者根据SRCPROTNAME，FILTERNAME和DSTPROTNAME条件删除指定的PROTREDEFINE配置信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                   |
|:------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------|
| SRCPROTNAME | 源协议名称  | 可选必选说明：可选参数 参数含义：该参数用于设置源协议名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：该协议只能为默认协议，不支持自定义协议。                          |
| FILTERNAME  | 过滤器名称  | 可选必选说明：可选参数 参数含义：该参数用于设置过滤器名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD FILTER命令配置生成。                        |
| DSTPROTNAME | 目的协议名称 | 可选必选说明：可选参数 参数含义：该参数用于设置目的协议名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。必须为缺省协议列表中的协议名称，不能自定义。 默认值：无 配置原则：该协议只能为默认三级协议，不支持自定义协议。 |

#### 使用实例

删除重定义协议protredefine：

```
RMV PROTREDEFINE:SRCPROTNAME="tls";
```
