# 去活LCS会话（DEA LCSSESSION）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

**须知** 

本命令属于高危命令，确认要去活LCS会话？

该参数用于去激活LCS会话。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                     |
|:--------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DEATYPE | 去活方式   | 可选必选说明：必选参数 参数含义：该参数用于指定去激活会话的方式。 数据来源：全网规划 取值范围： MSISDN：按MSISDN去激活会话。IMSI：按IMSI去激活会话。NF：按NF去激活会话。 默认值：无 配置原则：该参数配置为MSISDN时，指定按照MSISDN方式去激活会话；该参数配置为IMSI时，指定按照IMSI去激活会话。 |
| NFTYPE  | NF类型   | 可选必选说明：必选参数 参数含义：该参数用于指定NF类型。 数据来源：全网规划 取值范围： NfLMF：NfLMF。NfGMLC：NfGMLC。 默认值：无 配置原则：该参数配置为NfGMLC时，指定去激活GMLC上的会话；该参数配置为NfLMF时，指定去激活LMF上的会话。                               |
| MSISDN  | MSISDN | 可选必选说明：条件必选参数 前提条件：该参数在“DEATYPE”配置为“MSISDN”时为必选参数。 参数含义：该参数用于指定用户的MSISDN信息。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～15。 默认值：无 配置原则：无                                               |
| IMSI    | IMSI   | 可选必选说明：条件必选参数 前提条件：该参数在“DEATYPE”配置为“IMSI”时为必选参数。 参数含义：该参数用于指定用户的IMSI信息。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～15。 默认值：无 配置原则：无                                                   |

#### 使用实例

- 通过用户的IMSI信息去激活GMLC的LCS会话：

  ```
  DEA LCSSESSION: DEATYPE=IMSI, NFTYPE=NfGMLC, IMSI="861234567890";
  ```
- 通过用户的MSISDN信息去激活GMLC的LCS会话：

  ```
  DEA LCSSESSION: DEATYPE=MSISDN, NFTYPE=NfGMLC, MSISDN="8613601361234";
  ```
- 通过指定NFTYPE去激活GMLC的所有周期定位会话：

  ```
  DEA LCSSESSION: DEATYPE=NF, NFTYPE=NfGMLC;
  ```
- 通过指定NFTYPE去激活LMF的所有周期定位会话：

  ```
  DEA LCSSESSION: DEATYPE=NF, NFTYPE=NfLMF;
  ```
