#### 命令功能

**适用NF：NCG**

该命令用于显示话单统计任务的状态。该命令执行后，系统返回相应的话单统计任务状态值。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无

#### 使用实例

显示所有话单统计任务状态：

```
DSP CDRSTAT:;
```

```
RETCODE = 0  操作成功
  
结果如下: 
---------
     话单统计标识  =  cdrstat1
 接入网元分组标识  =  PS2
           RU的ID  =  65
   当前统计文件名  =  ./frontsave/AP65_1/20240611/AP65_10000000004.bil
     文件修改时间  =  2024-06-11 20:42:35
     话单统计状态  =  进行中
 (结果个数 = 1)
  
---    END
```

#### 输出结果说明

| 输出项名称    | 输出项解释                  |
|:---------|:-----------------------|
| 接入网元分组标识 | 表示当前统计任务的接入分组标识。       |
| RU的ID    | 表示当前统计任务的RU ID。        |
| 当前统计文件名  | 表示当前统计任务正在处理的文件名。      |
| 文件修改时间   | 表示当前统计任务正在处理文件的修改时间。   |
| 话单统计状态   | 表示当前统计任务的状态。 待启动进行中已完成 |

其余输出项请参见**ADD CDRSTAT**的参数说明。
