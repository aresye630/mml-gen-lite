# 删除M3UA本地实体(RMV CPM3LE)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME、SMSF**

该命令用于删除M3UA本地实体。

#### 注意事项

- 该命令执行后立即生效。
- 执行该命令将中断该本地实体上的所有业务。
- 如果M3UA目的实体表中有该本地实体的相关记录，或者该本地实体的相关记录在SCCP本局信令点存在，则不能删除。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                         |
|:-------|:-------|:-------------------------------------------------------------|
| LEX    | 本地实体索引 | 可选必选说明：必选参数 参数含义：该参数用于指定准备删除的本地实体的索引。 取值范围：0~63 默认值：无 配置原则：无 |

#### 使用实例

删除索引为1的本地实体：

```
RMV CPM3LE: LEX=1;
```
