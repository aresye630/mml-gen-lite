# 查询中转UPF与Radius服务器的绑定关系（LST UPFRDSSVR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SMF**

查询中转UPF与Radius服务器的绑定关系。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                          |
|:-----------|:-------|:------------------------------------------------------------------------------------------------------------------------------|
| SERVERTYPE | 服务器类型  | 可选必选说明：可选参数  参数含义：指定RADIUS服务器类型。  数据来源：本端规划 取值范围： “AUTHENTICATION（鉴权服务器）”：表示鉴权服务器。“ACCOUNTING（计费服务器）”：表示计费服务器。  默认值：无  配置原则：无 |

## 使用实例

显示计费服务器的配置信息：

```
LST UPFRDSSVR:;
RETCODE = 0  操作成功

结果如下
--------
服务器类型  服务器IP版本  IPv4地址      UP列表名称

计费服务器  IPv4          192.168.10.1  uplist2
计费服务器  IPv4          192.168.0.47  up1
(结果个数 = 2)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                   |
|:--------|:------------------------|
| 服务器类型   | 指定RADIUS服务器类型。          |
| 服务器IP版本 | 该参数用于指定RADIUS服务器IP地址类型。 |
| IP地址    | RADIUS服务器IP地址。          |
| UP列表名称  | 指定UP列表名称。               |
