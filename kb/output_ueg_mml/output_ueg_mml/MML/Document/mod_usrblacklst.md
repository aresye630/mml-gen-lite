# 修改用户黑名单限制列表（MOD USRBLACKLST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGSN、MME、AMF**

该命令用于修改用户黑名单限制的限制模式。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                          |
|:-------------|:-------|:------------------------------------------------------------------------------------------------------------------------------|
| IMSI         | IMSI   | 可选必选说明：必选参数  参数含义：该参数用于指定限制用户黑名单接入的IMSI。  数据来源：全网规划  取值范围：字符串类型，输入长度是15。  默认值：无  配置原则：无                                       |
| RESTRICTMODE | 限制模式   | 可选必选说明：可选参数  参数含义：该参数用于控制限制用户黑名单接入的系统模式。  数据来源：全网规划 取值范围： N2_MODE（N2模式）S1_MODE（S1模式）Iu_MODE（Iu模式）Gb_MODE（Gb模式）  默认值：无  配置原则：无 |

## 使用实例

修改一条黑名单限制列表记录，用户为123456789012345，限制用户通过N2模式接入，执行如下命令：

```
MOD USRBLACKLST: IMSI="123456789012345", RESTRICTMODE=N2_MODE-1&S1_MODE-0&Iu_MODE-0&Gb_MODE-0;
```
