# 修改LDAP设备地址（MOD LDAPDEVADDR）

- 命令功能
- 注意事项

- 使用实例
- 输出结果说明

## 命令功能

**须知** 

- 此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于对配置数据库中的一条LDAP（Lightweight Directory Access Protocol）设备地址数据记录的某些参数进行修改或调整。在该命令中，系统通过“链路ID”来唯一标识一条LDAP设备地址数据记录。

## 注意事项

PMS/NTS/DRS/HLB/DLB/NLF/LDAP设备的IP地址（包括IPv4地址和IPv6地址）需要唯一，任意两种设备的IP地址不能重复。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                    |
|:------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DEVAID      | 设备地址标识 | 可选必选说明：必选参数 参数含义：标识一条LDAP设备地址数据记录的关键字段，用于指定需要对哪一条LDAP设备地址数据记录的参数进行修改或调整，操作员可以使用LST LDAPDEVADDR命令查询获得。 取值范围：0～7 默认值：无。 配置原则：无。                                           |
| VPNNAME     | VPN名称  | 可选必选说明：可选参数 参数含义：用于标识CSLB的业务IP的VPN名称。 取值范围：长度不超过31位的字符串。 默认值：无。 配置原则：需要与ADD L3VPNINST命令中“VPN实例名称”参数值保持一致，通过LST L3VPNINST命令查询得到。                                         |
| IPVER       | IP版本   | 可选必选说明：可选参数 参数含义：用于指定LDAP设备地址的IP版本类型。 取值范围：IPV4(IPV4) 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。                                                                                 |
| IP          | IPV4地址 | 可选必选说明：可选参数 参数含义：用于表示LDAP的设备IPv4地址，仅当“IP版本”选择“IPV4(IPV4)”时该参数必须配置。 取值范围：IPv4地址 默认值：无。 配置原则：IPv4类型的IP地址不能配置如下非法IP地址：“127.0.0.1”、“0.0.0.0”、“255.255.255.255”、“224.0.0.1”。 |
| DESCRIPTION | 描述     | 可选必选说明：可选参数 参数含义：用于描述LDAP设备地址的用途。 取值范围：长度不超过32的字符串 默认值：无。 配置原则：无。                                                                                                       |

## 使用实例

修改IPv4类型的LDAP设备地址信息。“设备地址标识”为“1”，“VPN名称”为“VPN1”，“IP版本”为“IPV4(IPV4)”，“IPV4地址”为“192.168.0.131”，“描述”为“LDAP\_IPV4”。

```
MOD LDAPDEVADDR: DEVAID=1, VPNNAME="VPN1", IPVER=IPV4, IP="192.168.0.131", DESCRIPTION="LDAP_IPV4";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如下表1所示。

|   错误码 | 消息解释                        | 原因分析                                                     | 处理建议                                                                                                   |
|------:|:----------------------------|:---------------------------------------------------------|:-------------------------------------------------------------------------------------------------------|
| 56015 | IP地址非法。                     | 输入的“IPV4地址”参数值非法。                                        | 遵循“IPV4地址”参数配置原则，重新输入“IPV4地址”参数值 。                                                                     |
| 58079 | 该记录被LDAPLNK对象引用，不能删除或者修改记录。 | 当前的“IPV4地址”参数值已经被其他LDAPLNK对象关联。                          | 执行命令LST LDAPLNK，查询当前IP地址对应的链路ID。执行命令RMV LDAPLNK，删除1中查询出来的链路ID的数据记录。重新执行该命令修改IP地址。                      |
| 53358 | IP已经存在。                     | 输入的“IPV4地址”参数值已经存在。                                      | 执行命令LST LDAPDEVADDR，查询LDAP设备地址信息，获取已经存在的“IPV4地址”信息。重新执行该命令，输入“IPV4地址”参数值 ，确保输入的“IPV4地址”参数值 与1中查询结果不相同。 |
| 58107 | 设备地址冲突。                     | PMS/NTS/DRS/HLB/DLB/NLF/LDAP设备的IP地址需要唯一，任意两种设备的IP地址不能重复。 | 修改IP地址，重新执行本命令修改设备地址。                                                                                  |
