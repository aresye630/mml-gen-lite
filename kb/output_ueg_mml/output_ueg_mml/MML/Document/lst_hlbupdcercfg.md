# 查询HLB证书更新配置（LST HLBUPDCERCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

用于查询HLB实例更新证书后，HLB分批拆链和重建链路的相关配置。

#### 注意事项

无。

#### 参数说明

无。

#### 使用实例

查询HLB证书更新配置。

```
LST HLBUPDCERCFG:;
```

```
%%LST HLBUPDCERCFG:;%%
RETCODE = 0  操作成功

操作结果如下
------------------------
    HLB拆链时间间隔  =  20
  HLB重建链时间间隔  =  5
(结果个数 = 1)

---    END
```

#### 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见SET HLBUPDCERCFG命令的参数说明。
