# 设置SBI接口的URI配置（SET SBIURICFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致系统异常，影响业务处理，需联系华为技术支持确认后再执行。

该命令用于配置UPCF发送请求/响应消息时，本端URI中host的取值格式。

## 注意事项

- 该命令最大记录数为256。
- 该配置只对HTTPS协议消息生效，对HTTP协议消息不生效。
- 首次执行该命令若不输入“URI取值”，则按照“IP(IP)”进行设置；再次执行该命令时，若不输入“URI取值”，则不会修改原有取值，原有取值可通过**LST SBIURICFG**命令进行查询。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                               |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFTYPE   | 网元类型   | 可选必选说明：必选参数 参数含义：用于标识UPCF发送消息的对端网元类型。 取值范围：SCP(SCP)NRF(NRF) 默认值：无。 配置原则：无。                                                                                                                                                                                                         |
| IFTYPE   | 接口类型   | 可选必选说明：必选参数 参数含义：用于设置SBI接口类型。 取值范围：N7(N7)N15_AM(N15 AM)Nnrf(Nnrf) 默认值：无。 配置原则：当“网元类型”配置为“SCP(SCP)”时，“接口类型”可以配置为“N7(N7)”或者“N15_AM(N15 AM)”。当“网元类型”配置为“NRF(NRF)”时，“接口类型”仅可以配置为“Nnrf(Nnrf)”。                                                                                          |
| URITYPE  | URI类型  | 可选必选说明：必选参数 参数含义：用于设置SBI接口的URI类型。 取值范围：Location(Location) Resource(Resource) Notification(Notification) 默认值：无。 配置原则：当“接口类型”配置为“N7(N7)”或者“N15_AM(N15 AM)”时，“URI类型”可以配置为“Location(Location)”或者“Resource(Resource)”。当“接口类型”配置为“Nnrf(Nnrf)”时，“URI类型”可以配置为“Notification(Notification)”。 |
| URIVALUE | URI取值  | 可选必选说明：可选参数 参数含义：用于设置本端URI中host的取值格式。 取值范围：IP(IP) FQDN(FQDN) 默认值：无。 配置原则：无。                                                                                                                                                                                                        |

## 使用实例

配置“网元类型”为“SCP(SCP)”，“接口类型”为“N7(N7)”，“URI类型”为“Location(Location)”，“URI取值”为“FQDN(FQDN)”。

```
SET SBIURICFG: NFTYPE=SCP, IFTYPE=N7, URITYPE=Location, URIVALUE=FQDN;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释          | 原因分析                  | 处理建议                               |
|------:|:---------------|:----------------------|:-----------------------------------|
| 58257 | 参数IFTYPE取值非法。  | “接口类型”与选取的“网元类型”不匹配。  | 请按照“接口类型”参数的配置原则描述重新配置，然后重新执行本命令。  |
| 58258 | 参数URITYPE取值非法。 | “URI类型”与选取的“接口类型”不匹配。 | 请按照“URI类型”参数的配置原则描述重新配置，然后重新执行本命令。 |
