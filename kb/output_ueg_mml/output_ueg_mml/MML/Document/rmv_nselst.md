# 删除NSE列表(RMV NSELST)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用于从NSE列表中删除指定的NSEI。

#### 注意事项

- 该命令执行后立即生效。
- 若未输入参数，表示删除所有记录。
- 如果执行该命令时**RMV NSEUSR**任务正在运行，则删除的NSEI仍然会被**RMV NSEUSR**处理，即属于这个NSE的用户仍然会被删除。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                               |
|:-------|:-------|:-----------------------------------------------------------------------------------|
| NSEI   | NSE标识  | 可选必选说明：可选参数 参数含义：该参数用于指定网络服务实体标识。 取值范围：0～65535 默认值：无  说明： 输入的NSEI必须能够通过LST NSE查询到。 |

#### 使用实例

1. 删除NSE列表下所有记录：

   RMV NSELST:;
2. 从NSE列表中删除NSEI为10的NSE：

   RMV NSELST: NSEI=10;
