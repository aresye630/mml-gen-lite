# 设置策略管理服务软件参数（SET PMSINSP）

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致系统异常，影响业务处理，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于支持升级过程中修改PMS系统软件参数的配置信息。

## 注意事项

- 在缺省的情况下，系统在初始化的时候已经预置了软参数据表中的全部数据。
- 操作员应使用默认值。如果操作员确实需要修改软件参数，请联系华为公司技术服务工程师处理，禁止随意修改。
- 修改软件参数后，执行**LST PMSINSP**命令检查软件参数值是否生效。若修改软参值未生效，请参考产品手册的“UPCF软件参数”，查看修改软参值的生效方式。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                           |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INSPN  | 参数名    | 可选必选说明：必选参数 参数含义：标识软件参数名称，用于指定需要对哪一类软参数据记录的参数进行修改。 取值范围： VRM_FIRSTLOGINSWITCH(机机账户初始口令检查开关)VRM_CHKPRIVATEKEYPASSWDSWITCH(检查证书私钥口令开关)VRM_CHKWEBHOSTSWITCH(UPCF WebUI Host头校验开关)VRM_UPCCPLYCAPSWITCH(UPCC全局数据容量开关) 详细信息请参考产品手册的“UPCF软件参数 > PMS系统软参 > 策略管理服务软件参数”。 默认值：无。 配置原则：无。 |
| INSPV  | 参数值    | 可选必选说明：必选参数 参数含义：标识软件参数的值，此处取值应在软件参数的取值范围内取值。 取值范围：0～2147483647 默认值：无。 配置原则：无。                                                                                                                                                                                                 |

## 使用实例

将PMS系统软参“VRM\_FIRSTLOGINSWITCH”的取值设置为“1”。

`SET PMSINSP: INSPN=VRM_FIRSTLOGINSWITCH, INSPV=1;`
