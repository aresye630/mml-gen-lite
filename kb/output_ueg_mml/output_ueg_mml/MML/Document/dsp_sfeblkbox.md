# 显示SFE黑匣子（DSP SFEBLKBOX）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示指定资源单元上的SFE黑匣子信息。

#### 注意事项

该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 使用实例

显示指定资源单元的SFE黑匣子信息：

```
DSP SFEBLKBOX:BOXID=frame,RUNAME="VNODE_VNRS_VNFC_IPU_0066";
```
