# 修改报表服务系统软参(MOD DRSSSP)

- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致系统异常，影响业务处理，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于修改DRS系统软件参数的配置信息。

## 注意事项

- 在缺省的情况下，系统在初始化的时候已经预置了软参数据表中的全部数据。
- 操作员应使用默认值。如果操作员确实需要修改软件参数，请联系华为技术服务工程师处理，禁止随意修改。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                         |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SCP    | 系统配置参数 | 可选必选说明：必选参数 参数含义：系统配置参数标识。 取值范围： SYSPARAMETER(系统参数) 默认值：无。 配置原则：无。                                                                                                           |
| SPN    | 参数名    | 可选必选说明：必选参数 参数含义：标识软件参数名称，用于指定需要对哪一类软参数据记录的参数进行修改。 取值范围： VRM_DRSREDUNDANCYSWITCH(DRS容灾开关)VRM_DRSSFTPCLIENTACSWITCH(DRS SFTP客户端算法兼容开关)VRM_DRSWORKMODE(DRS工作模式) 默认值：无。 配置原则：无。 |
| SPV    | 参数值    | 可选必选说明：必选参数 参数含义：标识软件参数的值，此处取值应在软件参数的取值范围内取值。详细信息请参考产品手册的DRS系统软参。 取值范围：0-2147483647。 默认值：无。 配置原则：无。                                                                          |

## 使用实例

设置“系统配置参数”为“SYSPARAMETER(系统参数)”，“参数名”为“VRM\_DRSREDUNDANCYSWITCH(DRS容灾开关)”，“参数值”软参设置为“0”。

```
MOD DRSSSP: SCP=SYSPARAMETER, SPN=VRM_DRSREDUNDANCYSWITCH, SPV=0;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                                        | 原因分析                                     | 处理建议                                       |
|------:|:---------------------------------------------|:-----------------------------------------|:-------------------------------------------|
| 53598 | 参数取值无效：参数VRM_ DRSREDUNDANCYSWITCH的取值范围是0-1。  | 输入参数VRM_ DRSREDUNDANCYSWITCH的取值不在取值范围内。  | 重新输入VRM_ DRSREDUNDANCYSWITCH取值，并保证取值为0-1。  |
| 53788 | 参数取值无效：参数VRM_DRSSFTPCLIENTACSWITCH的取值范围是0-1。 | 输入参数VRM_DRSSFTPCLIENTACSWITCH的取值不在取值范围内。 | 重新输入VRM_DRSSFTPCLIENTACSWITCH取值，并保证取值为0-1。 |
| 53831 | 参数取值无效：参数VRM_DRSWORKMODE的取值范围是0或1            | 输入参数VRM_DRSWORKMODE的取值不在取值范围内。           | 重新输入VRM_DRSWORKMODE取值，并保证取值为0或1。           |
