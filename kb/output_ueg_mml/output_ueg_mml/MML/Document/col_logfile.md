#### 命令功能

适用网元：SGSN、MME

该命令用于将VNFC上指定时间段的日志信息以zip压缩包方式导出到特定路径，文件存放路径：主OMU的“/opt/container/5gcore/LINK/linkom/linkom/home”。存在U2000网管的场景下，可以使用U2000“网络信息收集”功能导出指定时间段的日志文件。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                |
|:------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LOGTYPE     | 日志类型   | 可选必选说明：必选参数 参数含义：该参数用于指定日志类型。 数据来源：本端规划 取值范围： “ALMLOG(告警日志)” 默认值：无                                                                                                                  |
| STARTTIME   | 开始时间   | 可选必选说明：可选参数 参数含义：该参数用于指定导出日志文件的起始时间。 数据来源：本端规划 取值范围：1970-01-01～2099-12-31 默认值：无                                                                                                     |
| ENDTIME     | 结束时间   | 可选必选说明：可选参数 参数含义：该参数用于指定导出日志文件的结束时间。 数据来源：本端规划 取值范围：1970-01-01～2099-12-31 默认值：无                                                                                                     |
| MAXSIZE     | 文件最大限制 | 可选必选说明：可选参数 参数含义：该参数用于指定导出日志文件大小的上限。 数据来源：本端规划 取值范围：0～4294967295 默认值：无                                                                                                              |
| SERVICETYPE | 服务类型   | 可选必选说明：必选参数 参数含义：此参数用于指定待查询的服务类型，可以通过LST VNFC命令查询得到。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。数字“0~9”，大写字母“A~Z”，小写字母“a~z”，特殊字符“-”，“_”，其他均为非法字符，并且首字符必须为字母。 默认值：无 配置原则：需要填写USN或LINK或GB对应的名称。 |

#### 使用实例

- 导出LINK\_VNFC下的海量告警详细信息文件：

  COL LOGFILE: LOGTYPE=ALMLOG`, SERVICETYPE=LINK`;

  ```
  %%COL LOGFILE: LogType=ALMLOG, SERVICETYPE=LINK;%% 
  RETCODE = 0  操作成功。 

  操作结果如下
  ----------------  
  文件名称  =  /opt/container/5gcore/LINK/linkom/linkom/home/batch_alm/20180506_035103_almlog.zip 
  (结果个数 = 1) 
  ---    END
  ```
