# 删除TA群组成员(RMV TAGPMEM)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于删除跟踪区群组成员记录。

#### 注意事项

- 此命令执行后立即生效。
- 删除TA群组成员时必须保证相关表中不存在该TA群组成员对应跟踪区群组的相关记录。可执行**LST S1SUBRRLST**查看相关表的记录。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称    | 参数说明                                                              |
|:-------|:--------|:------------------------------------------------------------------|
| TAGPID | 跟踪区群组标识 | 可选必选说明：必选参数 参数含义：该参数用于指定跟踪区群组标识。 数据来源：本端规划 取值范围：1~2048 默认值：无      |
| MCC    | 移动国家码   | 可选必选说明：必选参数 参数含义：该参数用于指定移动国家码。 数据来源：整网规划 取值范围：3位的十进制数字 默认值：无      |
| MNC    | 移动网号    | 可选必选说明：必选参数 参数含义：该参数用于指定移动网号。 数据来源：整网规划 取值范围：2～3位的十进制数字 默认值：无     |
| TAC    | 跟踪区域码   | 可选必选说明：必选参数 参数含义：该参数用于指定跟踪区域码。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无 |

#### 使用实例

删除一个TA群组，跟踪区群组标识为1，群组成员的移动国家码为456，移动网号为12，跟踪区域码为0x1234：

RMV TAGPMEM: TAGPID=1, MCC="456", MNC="12", TAC="0x1234";

RMV TAGP: TAGPID=1;
