# 激活软件包（ACT ACSPACKAGE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

本命令属于高危命令，操作不当会影响系统的正常启动和升级，请谨慎使用并联系华为支持协助操作。

该命令用于激活升级软件包。

本命令只适用于ACS服务，其他微服务请使用ACT PACKAGE命令。

#### 注意事项

- 该命令执行后立即生效。
- 只有执行过**LOD ACSPACKAGE**，才能执行该命令。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识              | 参数名称         | 参数说明                                                                                                                                           |
|:------------------|:-------------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| UPDOBJECT         | 升级对象         | 可选必选说明：必选参数 参数含义：该参数用于指定升级对象。 数据来源：本端规划 取值范围：枚举类型。 BaseSoftware：只升级基础版本。Patch：只升级补丁。All：升级基础版本和补丁。 默认值：无                                       |
| BASICPKGVERSIONID | 基础软件包版本号     | 可选必选说明：条件必选参数，该参数在“UPDOBJECT”配置为“BaseSoftware” 或 “All”时为必选参数。 参数含义：该参数用于指定要加载的基础软件包版本号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                |
| PATCHPKGVERSIONID | 补丁版本号        | 可选必选说明：条件必选参数，该参数在“UPDOBJECT”配置为“Patch” 或 “All”时为必选参数。 参数含义：该参数用于指定要加载的补丁版本。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                           |
| RBKTIMER          | 回退定时器时长（min） | 可选必选说明：可选参数 参数含义：该参数用于指定回退定时器时长，升级后超过该时间不登录客户端，系统将自动回退到升级前版本。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535，单位是分钟。 默认值：无  说明： 在容器场景下，该参数只能配置为“0”，表示不支持自动回退。 |
| RBTMODE           | 重启模式         | 可选必选说明：可选参数 参数含义：该参数用于指定允许的重启模式。 数据来源：本端规划 取值范围：枚举类型。 NO：不重启。SOFT：软重启，不需要重启虚拟机。 默认值：NO  说明： 在容器场景下，该参数只能配置为NO。                                 |
| OPERMODE          | 操作模式         | 可选必选说明：可选参数 参数含义：该参数用于指定允许的操作模式。 数据来源：本端规划 取值范围：枚举类型。 OnlyDBTrans：仅针对高版本配置进行翻译，不备份低版本配置。 默认值：无 配置原则：无                                          |

#### 使用实例

激活升级软件包：

```
ACT ACSPACKAGE:UPDOBJECT=All,BASICPKGVERSIONID="V100R005C00B021",PATCHPKGVERSIONID="SPH0020",RBKTIMER=10,OPERMODE=OnlyDBTrans,RBTMODE=SOFT;
```
