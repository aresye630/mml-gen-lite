# 删除GnGp SGSN属性配置信息(RMV SGSNCHARACT)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

该命令用于删除对端SGSN的QoS属性信息记录。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称           | 参数说明                                                                                                                                                                                                                                                     |
|:-------|:---------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPT    | IP地址类型         | 可选必选说明：必选参数 参数含义：该参数用于指定对端SGSN的信令面IP地址类型。 数据来源：整网规划 取值范围：“IPV4”、“IPV6” 默认值：无 配置原则：IPV4，表示对端SGSN的信令面IP地址为IPV4类型。IPV6，表示对端SGSN的信令面IP地址为IPV6类型。                                                                                                             |
| IPV4   | SGSN IPv4信令面地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定对端SGSN的信令面IPV4地址。 前提条件：当“IPT（IP地址类型）”为IPv4时显示。 数据来源：整网规划 取值范围：0.0.0.1~255.255.255.254 默认值： 无 配置原则：有效的IPV4地址不能为环回地址(127.x.y.z)。有效的IPV4地址必须是A、B或者C类地址。                                                                           |
| MASKV4 | 掩码             | 可选必选说明：条件必选参数 参数含义：该参数用于指定对端SGSN的信令面IPV4地址的掩码。 前提条件：当“IPT（IP地址类型）”为IPv4时显示。 数据来源：整网规划 取值范围：0.0.0.1~255.255.255.255 默认值： 无  说明： 输入的掩码要求对应的二进制值1和1之间不允许存在0。例如：“255.255.0.0”是有效掩码；“123.123.123.123”是无效掩码。因为123对应的二进制为“1111011”，1之间存在0。                      |
| IPV6   | SGSN IPv6信令面地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定SGSN配置的信令面IPV6地址。 前提条件：当“IPT（IP地址类型）”为IPv6时显示。 数据来源：整网规划 取值范围：::~FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值： 无 配置原则：IPV6地址必须是全球单播地址，不能为::、FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址(::1)、链路本地地址(FE80::/10)和组播地址(FF00::/8)。 |
| MASKV6 | 子网前缀长度         | 可选必选说明：条件必选参数 参数含义：该参数用于指定子网前缀的长度。 前提条件：当“IPT（IP地址类型）”为IPv6时显示。 数据来源：整网规划 取值范围：1~128（数值型） 默认值： 无                                                                                                                                                         |

#### 使用实例

删除信令面IP地址为"192.168.168.12"，掩码为"255.255.255.0"的SGSN的属性信息：

RMV SGSNCHARACT:IPT=IPV4, IPV4="192.168.168.12", MASKV4="255.255.255.0";
