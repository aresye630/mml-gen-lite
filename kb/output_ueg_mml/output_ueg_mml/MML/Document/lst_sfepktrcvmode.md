# 查询SFE当前收包模式（LST SFEPKTRCVMODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询SFE当前收包模式。

#### 注意事项

- 该命令执行后立即生效。
- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询SFE当前收包模式：

```
LST SFEPKTRCVMODE:;
```

```
RETCODE = 0 操作成功

结果如下
------------------------
SFE收包模式  =  相对优先级
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见SET SFEPKTRCVMODE的参数说明。
