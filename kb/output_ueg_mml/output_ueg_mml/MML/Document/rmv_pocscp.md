# 删除PCRF对端OCS接入点实体(RMV POCSCP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致业务中断，需联系华为技术支持确认后再执行。

该命令用于在UPCF网元下删除对端OCS接入点。

该命令的使用场景：当需要删除对端OCS接入点，或需要更换对端OCS接入点时，可以使用本命令。

## 注意事项

在删除对端OCS接入点实体之前，需要先执行**RMV POCSL**命令，删除与其关联的OCS链路，否则会出现操作失败。

## 参数说明

| 参数ID   | 参数名称   | 参数描述                                                                                     |
|:-------|:-------|:-----------------------------------------------------------------------------------------|
| PCRFID | PCRF标识 | 标识一个OCS接入点配置信息的关键字段，用于标识PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围：1 默认值：无。              |
| CPID   | 接入点标识  | 标识一个OCS接入点配置信息的关键字段，用于标识对端OCS接入点的接入点标识。该参数必须先由ADD POCSCP命令定义，然后才能在此处索引。 取值范围：0～15 默认值：无。 |

## 使用实例

在开局情况的时候由于误操作添加了错误的OCS接入点信息，或者其他场景下UPCF需要删除对接的OCS接入点时，需要进行如下配置。

1. 执行**LST POCSCP**命令查询OCS接入点标识；若不存在OCS接入点，则不需要执行以下操作。
2. 执行**LST POCSL**命令查询PCRF与对端OCS接入点之间的链路是否已删除。若未删除，通过**RMV POCSL**命令先删除链路。
3. 执行**LST PCRF**命令查询PCRF实体的PCRF标识。
4. 执行**RMV POCSCP**删除PCRF对端OCS接入点实体配置信息。例如，删除“PCRF标识”为“1”，“接入点标识”为“0”的OCS接入点。

   ```
   RMV POCSCP: PCRFID=1, CPID=0;
   ```
