# 激活IP链路(ACT DBSIPDISP)

## 命令功能

**须知** 

该命令属于高危命令，该操作将激活IP配置信息。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于请求系统激活IP配置，使dbbroker和远端DSG模块进行网络连接。

## 注意事项

- 只能在开局初始配置或者扩缩容时执行，其他情况下可能会导致FE访问BE的业务失败。
- 执行本命令并且“模式”选择为“LOCAL(本地)”或者不填时，远端的DSG可能会重新分配本端IP与对端的IP，造成FE与BE之间的链路中断。故在本端执行此命令后需要立刻在远端执行**ACT IPDISP**命令，否则会造成业务呼损甚至中断。
- 如果本端和远端的链路配置未发生变化，则不会触发链路重建，不会造成业务呼损。
- 该命令不允许进行批操作。
- 当本端同时配置了远端的DSG配置和IP配置，并且入参“模式”为“ALL(所有)”时，报文才会返回对端的操作结果。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                          |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MODE   | 模式     | 可选必选说明：可选参数 参数含义：本参数用于设置远端局点激活链路的模式。 取值范围： LOCAL(本地)：手工执行命令激活链路。ALL(所有)：将选择链路正常且服务号最小的DBS微服务通知远端局点激活链路配置。 说明： 参数“ALL(所有)”只能在扩缩容场景下进行选择。 默认值：LOCAL(本地) 配置原则：无。 |

## 使用实例

1. 某局点需要激活IP链路，其配置方式如下：
   1. 执行**ADD DBSRLOCATION**命令增加远端Location标识。
   2. 执行**ADD DBSRDSG**命令增加远端DSG模块。
   3. 执行**ADD DBSRIPADDR**命令增加远端IP地址。
   4. 执行本命令激活IP配置。

      ```
      ACT DBSIPDISP:;
      ```
2. 某局点需要激活IP链路，并且配置“模式”为“ALL(所有)”：
   1. 执行**SND DBSLINKCFG**命令发送本端DBS配置和IP配置。
   2. 执行本命令激活IP配置，并且配置“模式”为“ALL(所有)”。

      ```
      ACT DBSIPDISP: MODE=ALL;
      ```

      ```
      %%ACT DBSIPDISP: MODE=ALL;%%
      RETCODE = 0 操作成功

      操作结果如下
      ----------------------
      远端LocationID 业务类型 操作结果
      5              SUP-FE   操作成功
      (结果个数 = 1)

       --- END
      ```
