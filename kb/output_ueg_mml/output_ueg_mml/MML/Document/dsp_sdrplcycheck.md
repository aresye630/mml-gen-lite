# 显示策略核查任务进度（DSP SDRPLCYCHECK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示全部或者某一条策略核查任务的完成进度。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                    |
|:-------|:---------|:--------------------------------------------------------------------------------------------------------|
| TASKID | 策略核查任务ID | 可选必选说明：可选参数  参数含义：策略核查任务ID，若不输入该参数，则表示查询所有的策略核查任务。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~1024。  默认值：无  配置原则：无 |

## 使用实例

查询系统中存在的所有策略核查任务的完成进度。

```
%%DSP SDRPLCYCHECK:;%%
            RETCODE = 0  操作成功

            结果如下
            --------
            策略核查任务ID  任务进度  任务优先级  策略类型

            e-1             -         1           内部策略
            e-14            -         1           外部通信策略
            e-15            -         1           外部通信策略
            t-6584          -         2           内部策略
            t-6585          -         2           外部通信策略
            t-6586          -         2           内部策略
            t-6587          -         2           外部通信策略
            t-6588          -         2           内部策略
            (结果个数 = 8)

            ---    END
```

## 输出结果说明

| 输出项名称    | 输出项解释                                                                        |
|:---------|:-----------------------------------------------------------------------------|
| 策略核查任务ID | 策略核查任务ID，若不输入该参数，则表示查询所有的策略核查任务。                                             |
| 任务进度     | 核查任务对应的进度。                                                                   |
| 任务优先级    | 任务优先级。                                                                       |
| 策略类型     | 策略类型，内部策略如Topic，RootToken等， 外部通信策略如VPN，LB策略等。 取值说明： Inner（内部策略）Outer（外部通信策略） |
