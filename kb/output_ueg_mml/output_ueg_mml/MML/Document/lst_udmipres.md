# 查询UDM IP资源 (LST UDMIPRES)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询已配置的UDM IP资源信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询所有的UDM IP资源信息：

```
LST UDMIPRES:;
```

```
%%LST UDMIPRES:;%%
RETCODE = 0  操作成功 
 

接口类型
   
Cx
Mgt
N10
N12
N21
N8
S6a
Sh     
(结果个数 = 8)  

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD UDMIPRES**命令的参数说明。
