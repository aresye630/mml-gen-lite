# 查询对本地用户、漫游用户、拜访用户所采用的计费属性（LST CHARGECHAR）

- 输出结果说明

#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

LST CHARGECHAR命令用来查询计费属性。

如果不指定可选参数，该命令将显示所有配置的计费属性名的属性信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                    |
|:-------|:-------|:------------------------------------------------------------------------|
| CCNAME | 计费属性名称 | 可选必选说明：可选参数 参数含义：计费属性名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无 |

#### 使用实例

CCName名称为“cc”的计费属性的显示配信息：

```
LST CHARGECHAR:;
```
