# 增加园区策略（ADD NGPARKPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于增加园区策略。通过本配置，AMF可以针对园区和DNN使用不同的策略管理。

## 注意事项

- 该命令执行后立即生效。

- 不同园区策略中的区域编码不能重复，且不能包含重叠的跟踪区。

- 最多可输入1024条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                    |
|:---------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PARKID   | 园区标识    | 可选必选说明：必选参数  参数含义：该参数用于标识一个园区。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~32。  默认值：无  配置原则：无                                                                                       |
| AREACODE | 区域编码    | 可选必选说明：必选参数  参数含义：该参数用于指定应用园区策略的区域。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~128。该区域编码必须先通过ADD AREACODE进行添加，而区域内的跟踪区列表则通过ADD AREAMEM进行添加。  默认值：无  配置原则：无                         |
| DNNGRPID | DNN群组标识 | 可选必选说明：必选参数  参数含义：该参数用于指定应用园区策略的DNN群组。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~32。DNN群组标识通过ADD DNNGRP进行配置。  默认值：无  配置原则：无                                                       |
| INERTIA  | 惯性运行开关  | 可选必选说明：可选参数  参数含义：该参数用于控制指定园区是否支持惯性运行功能。默认值为关闭。  数据来源：全网规划 取值范围： “OFF（关闭）”：关闭“ON（开启）”：开启  默认值：OFF  配置原则：  当运营商希望通AMF与NG-RAN之间的N2接口故障后，保持终端的连接状态，保证数据传输正常，需要将本参数设置为“ON”。 |

## 使用实例

将园区标识为“park”，区域编码为“huawei”，且DNN群组标识为“BIG\_GROUP”的惯性运行功能打开，执行如下命令：

```
ADD NGPARKPLCY: PARKID="park", AREACODE="huawei", DNNGRPID="BIG_GROUP", INERTIA=ON;
```
