# 设置HLB自动去激活（SET AUTODEAHLB）

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于设置HLB自动去激活功能配置参数。

## 注意事项

- 当复位DLB时需要将参数“自动去激活开关”提前设置为“Disable(关闭)”，否则可能会导致信令切换到其他局点。
- 在缺省的情况下，系统在初始化时已经在配置数据库中预置了HLB自动去激活功能配置参数信息，参数“自动去激活开关”取值为“Disable(关闭)”，参数“对端故障时长”取值为“900”。

## 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                            |
|:--------------|:--------|:--------------------------------------------------------------------------------|
| ID            | ID      | 可选必选说明：必选参数 参数含义：用于设置HLB自动去激活功能配置参数的记录标识。 取值范围：1 默认值：1。 配置原则：无。                 |
| AUTODEASW     | 自动去激活开关 | 可选必选说明：可选参数 参数含义：用于设置是否打开HLB自动去激活开关。 取值范围： Disable(关闭)Enable(打开) 默认值：无。 配置原则：无。 |
| PEERFAULTTIME | 对端故障时长  | 可选必选说明：可选参数 参数含义：用于设置所有AF/DRA对端的故障时长。 取值范围：90~3600 单位：秒 默认值：无。 配置原则：无。          |

## 使用实例

当需要打开HLB自动去激活开关时，设置“自动去激活开关”为“Enable(打开)”。

```
SET AUTODEAHLB: ID=1, AUTODEASW=Enable, PEERFAULTTIME=800;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
