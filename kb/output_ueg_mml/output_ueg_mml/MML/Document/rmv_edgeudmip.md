# 删除园区UDM的IP地址（RMV EDGEUDMIP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UDM**

**须知** 

本命令属于高危命令，此操作会删除边缘udm本端ip地址，可能导致相关业务中断。

该命令用于删除边缘UDM的IP地址。

#### 注意事项

- 该命令执行后立即生效。
- 删除的边缘udm本端ip地址需在系统中存在，否则命令执行失败。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                         |
|:-------|:--------|:-------------------------------------------------------------------------------------------------------------|
| IPNAME | IP地址名称  | 可选必选说明：必选参数 参数含义：该参数用于配置园区UDM的IP地址名称。 数据来源：全网规划 取值范围：长度不超过31的由数字和字母组成的字符串，只允许输入0～9，a～z，A～Z和下划线。 默认值：无 配置原则：无 |
| IPTYPE | IP地址的类型 | 可选必选说明：必选参数 参数含义：用于标识园区UDM的IP地址的类型。 数据来源：全网规划 取值范围： DSM：用于用户数据同步。 默认值：无 配置原则：无                               |

#### 使用实例

删除UDM地址，UDM名称为udm01，IP地址的类型为DSM：

```
RMV EDGEUDMIP: IPNAME="udm01", IPTYPE=DSM;
```
