# 设置SGmb心跳配置（SET SGMBHEARTBEATFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C**

该命令用来设置SGmb心跳配置。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| SWITCH   |   INTERVAL |   TIMES | DEACTIVEFLAG   |
|:---------|-----------:|--------:|:---------------|
| DISABLE  |         15 |       8 | ENABLE         |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称      | 参数说明                                                                                                                                                                                                                           |
|:-------------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SWITCH       | 心跳配置开关    | 可选必选说明：必选参数  参数含义：该参数用于设置SGmb心跳配置开关。  数据来源：全网规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无。  配置原则：  当开启容灾功能时，需要设置SGmb心跳开关使能。                                                                                                          |
| INTERVAL     | 心跳重发间隔    | 可选必选说明：该参数在"SWITCH"配置为"ENABLE"时为条件可选参数。  参数含义：该参数用于设置心跳重发间隔。  数据来源：全网规划  取值范围：整数类型，取值范围是10~60，单位是秒。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST SGMBHEARTBEATFUNC查询当前参数配置值。  配置原则：  该参数在“SWITCH”配置为“ENABLE”时为可选参数。                |
| TIMES        | 发送心跳消息的次数 | 可选必选说明：该参数在"SWITCH"配置为"ENABLE"时为条件可选参数。  参数含义：该参数用于设置需要去活用户时所需的超时心跳次数。  数据来源：全网规划  取值范围：整数类型，取值范围是1~60。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST SGMBHEARTBEATFUNC查询当前参数配置值。  配置原则：  该参数在“HEARTBEATSWITCH”配置为“ENABLE”时为可选参数。   |
| DEACTIVEFLAG | 去激活标志     | 可选必选说明：该参数在"SWITCH"配置为"ENABLE"时为条件可选参数。  参数含义：该参数用于设置是否去活已激活的上下文。  数据来源：全网规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST SGMBHEARTBEATFUNC查询当前参数配置值。  配置原则：  该参数在“HEARTBEATSWITCH”配置为“ENABLE”时为可选参数。 |

## 使用实例

设置心跳开关为关闭：

```
SET SGMBHEARTBEATFUNC: SWITCH=DISABLE;
```
