# 查询网元实例缓存信息(DSP NFPROFILE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询服务发现AMF、SMF或SCP网元实例信息缓存数据的详细信息。

## 注意事项

- 执行本命令查询网元实例信息缓存数据时，若“缓存类型”为“UDM(UDM)”且“网元类型”为“SCP(SCP)”，则“NRF返回有效时长”、“UDM调整有效时长”和“有效时间”显示为“NULL”。
- 执行本命令查询服务发现AMF或SMF网元实例信息缓存数据时，“本端网元实例标识”显示为“NULL”。

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                   |
|:-------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CACHETYPE    | 缓存类型   | 可选必选说明：必选参数 参数含义：用于指示系统按照哪个缓存类型来查询服务发现AMF、SMF或SCP网元实例信息。 取值范围：NRF(NRF)UDM(UDM) 默认值：无。 配置原则：无。                                                                                                                                                                                                          |
| SFINSTANCEID | SF实例号  | 可选必选说明：必选参数 参数含义：用于指示系统按照哪个实例ID来查询服务发现AMF、SMF或SCP网元实例缓存信息。该参数取值可以通过执行DSP UDMSERVICE命令获取。 取值范围：长度不超过65位的字符串。 默认值：无。 配置原则：当“缓存类型”选择“NRF(NRF)”时，在DSP UDMSERVICE中查询的“SF实例号”参数值对应的“服务类型”为“NRFClient(NRFClient)”；当“缓存类型”选择“UDM(UDM)”时，在DSP UDMSERVICE中查询的“SF实例号”参数值对应的“服务类型”为“UdmSubService(UdmSubService)”。 |
| NFINSID      | 网元实例标识 | 可选必选说明：必选参数 参数含义：当用于指示系统按照哪个缓存的网元实例号来查询服务发现AMF、SMF或SCP网元实例缓存信息，该参数可以通过执行DSP NFINSTANCE命令获取。 取值范围：长度不超过36位的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                          |

## 使用实例

查询“缓存类型”为“NRF(NRF)”,“SF实例号”为“11802013463530936371”，“网元实例标识”为“11112222-1111-2222-3333-111122223333”的服务发现网元实例缓存详细信息：

```
DSP NFPROFILE: CACHETYPE=NRF, SFINSTANCEID="11802013463530936371", NFINSID="11112222-1111-2222-3333-111122223333";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，参数说明如表1所示：

| 输出项名称     | 输出项解释                                                                                                                                                                                                                                                                                                              |
|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 网元实例信息    | 表示JSON格式的网元实例信息。                                                                                                                                                                                                                                                                                                   |
| 有效时间      | 表示该条缓存信息在此时间前有效。                                                                                                                                                                                                                                                                                                   |
| 本端网元实例标识  | 表示SCP网元对应的本端网元实例标识。                                                                                                                                                                                                                                                                                                |
| NRF返回有效时长 | 表示NRF返回的服务发现缓存数据有效期。“缓存类型”为“UDM(UDM)”时，返回值如果超过30分钟，则取30分钟。                                                                                                                                                                                                                                                         |
| UDM调整有效时长 | 表示UDM调整后实际使用的缓存数据有效期。在使用guami服务发现场景下，当同时满足服务发现携带guami、服务发现guami与响应guamilist中guami不同且“GuamiNFDiscCacheSaveMode(使用GUAMI服务发现时UDM本地缓存保存模式)”取值为“1”时，调整后实际使用的缓存数据有效期取“NRF返回有效时长”、“CrossNFProfileCacheValidPeriod(跨网服务发现缓存有效期)”软参值和30分钟的最小值；其余场景下取“NRF返回有效时长”参数查询结果和“CrossNFProfileCacheValidPeriod(跨网服务发现缓存有效期)”软参调整后的值。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 消息解释   | 原因分析                                                                               | 处理建议                                                                                                                                                                                                |
|-------:|:-------|:-----------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 360041 | 参数值不合法 | 输入的“SF实例号”参数值不合法：输入的“SF实例号”参数值和“缓存类型”不一致。输入的“SF实例号”参数值可用状态为未就绪。 输入的“网元实例标识”参数值不存在。 | 输入的“SF实例号”参数值不合法时：执行DSP UDMSERVICE命令查询输入的“SF实例号”参数值对应的服务类型，根据服务类型下拉选择正确的“缓存类型”参数值，然后重新执行本命令。执行DSP UDMSERVICE命令查询“SF实例号”参数取值，确保输入的参数值对应的可用状态为正常。 执行DSP NFINSTANCE命令，查询“网元实例标识”参数取值，输入正确的参数值后重新执行本命令。 |
