# 增加Gb模式用户漫游限制列表(ADD GBSUBRRLST)

#### 命令功能

**适用网元：SGSN**

该命令用于增加Gb模式用户漫游限制列表，此命令可基于“用户范围”配置禁止或允许某用户范围接入的“黑名单”、“白名单”区域，控制用户是否允许接入当前所在的区域。

#### 注意事项

- 该命令执行后立即生效。

- 最多可以输入2048条记录。

- 如果**ADD GBACCAREALST**配置或当前配置中存在禁止用户接入的记录，那么用户会被禁止接入。

输入的起始IMSI必须小于或者等于终止IMSI。判断起始IMSI和终止IMSI大小的原则是：对于输入IMSI的长度小于系统规定IMSI长度时，将该IMSI补足0到规定长度后进行大小比较，且起始IMSI必须小于终止IMSI。只有输入IMSI长度等于系统规定长度时，起始IMSI才能等于终止IMSI。 对于系统规定IMSI长度为15的情况，如表1所示：

|          起始IMSI |          终止IMSI | 实际限定IMSI范围                                                             |
|----------------:|----------------:|:-----------------------------------------------------------------------|
|       123002666 |          123002 | 增加记录失败，起始IMSI大于终止IMSI                                                  |
|          123002 |       123002666 | 123002000000000 ～ 123002666000000，即区间[123002000000000，123002666000000] |
|          123002 |          123002 | 增加记录失败，起始IMSI不能等于终止IMSI                                                |
| 123002000000000 | 123002000000000 | 仅限定IMSI号码123002000000000                                               |
| 123003000000000 | 123004000000000 | 123003000000000 ～ 123004000000000，即区间[123003000000000，123004000000000] |

- 输入的起始IMSI和终止IMSI定义的IMSI号段范围不允许与其它记录定义的IMSI号段范围相互交叉、包含或重合。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：必选参数 参数含义：该参数用于指定用户范围。 数据来源：整网规划 取值范围：“IMSI_PREFIX（指定IMSI前缀）”“IMSI_RANGE（指定IMSI范围）”“FOREIGN_USER（外网用户）”“HOME_USER（本网用户）”“ALL_USER（所有用户）” 默认值：无 配置原则：“IMSI_PREFIX（指定IMSI前缀）”和“IMSI_RANGE（指定IMSI范围）”取值对应的记录不能同时存在。“用户范围”的优先级从高到低为：“IMSI_PREFIX（指定IMSI前缀）”或“IMSI_RANGE（指定IMSI范围）”，“FOREIGN_USER（外网用户）”或“HOME_USER（本网用户）”，“ALL_USER（所有用户）”                                                                                                                                                                                                                                                                                                                             |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件必选参数 参数含义：该参数用于系统对用户的IMSI进行匹配，从而区分不同的用户群。 前提条件：该参数在“用户范围”参数配置为“IMSI_PREFIX（指定IMSI前缀）”后生效。 数据来源：整网规划 取值范围：5～15位十进制字符串 默认值：无  说明： 按照IMSI最长匹配进行查询，相同IMSI前缀只能配置一条记录。IMSI前缀的匹配方式采取由前向后的最长匹配，即若对于用户可以匹配到多个用户群，则使用IMSI前缀最长的用户群配置。                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| BEGIMSI  | 起始IMSI | 可选必选说明：条件必选参数 参数含义：该参数用于指定起始IMSI。 前提条件：该参数在“用户范围”参数配置为“IMSI_RANGE（指定IMSI范围）”后生效。 数据来源：整网规划 取值范围：5～15位十进制字符串 默认值：无 配置原则：当“起始IMSI”与“终止IMSI”长度全为15位时，“起始IMSI”要小于等于“终止IMSI”，否则“起始IMSI”要小于“终止IMSI”                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ENDIMSI  | 终止IMSI | 可选必选说明：条件必选参数 参数含义：该参数用于指定终止IMSI。 前提条件：该参数在“用户范围”参数配置为“IMSI_RANGE（指定IMSI范围）”后生效。 数据来源：整网规划 取值范围：5～15位十进制字符串 默认值：无 配置原则：当“终止IMSI”与“起始IMSI”长度全为15位时，“终止IMSI”要大于等于“起始IMSI”，否则“终止IMSI”要大于“起始IMSI”。                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| NOID     | 运营商标识  | 可选必选说明：条件必选参数 参数含义：该参数用于指定运营商标识。 前提条件：该参数在“用户范围”配置为“FOREIGN_USER(外网用户)”或“HOME_USER（本网用户）”后生效。对于外网用户，该参数是外网用户对应的签订互联PLMN漫游协议的运营商标识， 对于本网用户，该参数是本网用户对应的运营商标识。 数据来源：整网规划 取值范围：0～64，128～254 默认值：无  说明： 若该参数需要配置为0或128～254之间的值时，须先在ADD MNO中配置取值相同的“MNOID”参数。若该参数需要配置为1～64之间的值时，须先在ADD MVNO中配置取值相同的“MVNOID”参数。                                                                                                                                                                                                                                                                                                                                                                  |
| LARAGPID | 区域群标识  | 可选必选说明：必选参数 参数含义：该参数用于指定用户的区域群标识。 数据来源：整网规划 取值范围：1～2048 默认值：无 配置原则：该参数需要在ADD LARAGPMEM中事先配置，可执行LST LARAGPMEM进行查看。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ARMODE   | 区域限制模式 | 可选必选说明：必选参数 参数含义：该参数用于指定用户的区域限制模式。 数据来源：整网规划 取值范围：“BLACKLST(黑名单)”：“区域群标识”指定的区域为禁止用户接入区域，“区域群标识”未指定的区域为允许用户接入区域；“WHITELST(白名单)”：“区域群标识”指定的区域为允许用户接入区域，“区域群标识”未指定的区域为禁止用户接入区域。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| CAUSE    | 拒绝原因值  | 可选必选说明：可选参数 参数含义：该参数用于指定在“黑名单”或“白名单”模式中拒绝用户接入时使用的原因值。 数据来源：整网规划 取值范围：“CUSTOMER_DEFINED(自定义)”：表示拒绝用户接入时使用的原因值为自定义。“GPRS_SERVICE_NOT_ALLOWED(GPRS服务被禁止)”：表示拒绝用户接入时使用的指定原因值为GPRS服务被禁止。“GPRS_NONGPRS_SRV_NOT_ALLOWED(GPRS和非GPRS服务都被禁止)”：表示拒绝用户接入时使用的原因值为GPRS和非GPRS服务都被禁止。“PLMN_NOT_ALLOWED(PLMN被禁止)”：表示拒绝用户接入时使用的原因值为PLMN被禁止。“LA_NOT_ALLOWED(本地区域被禁止)”：表示拒绝用户接入时使用的原因值为本地区域被禁止。“ROAMING_NOT_ALLOWED_IN_LA(本地漫游被禁止)”：表示拒绝用户接入时使用的原因值为本地漫游被禁止。“GPRS_SRV_NOT_ALLOWED_IN_PLMN (本PLMN内GPRS服务被禁止)”：表示拒绝用户接入时使用的原因值为PLMN内GPRS服务被禁止。“NO_SUITABLE_CELLS_IN_LA(本地无合适小区)”：表示拒绝用户接入时使用的原因值为本地无合适单元。 默认值：“NO_SUITABLE_CELLS_IN_LA(本地无合适小区)” 配置原则：无  说明： 附着或路由更新拒绝的原因值，请参考3GPP TS 24.008输入。 |
| SDCAUSE  | 自定义原因值 | 可选必选说明：条件必选参数 参数含义：该参数用于指定自定义原因值。 前提条件：该参数在“CAUSE(原因值)”设置为“CUSTOMER_DEFINED(自定义)”时生效。 数据来源：整网规划 取值范围：1～254 默认值：无  说明： 当原因值为自定义时显示，根据3GPP TS 24.008填写。原因值为NAS消息里携带的拒绝原因值。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |

#### 使用实例

增加一条Gb模式用户漫游限制列表记录，用于控制IMSI前缀为123456的用户群，不允许在位置区为0x1000，路由区为0x20的区域接入，拒绝原因值为“NO\_SUITABLE\_CELLS\_IN\_LA(本地无合适小区)”：

ADD LARAGP: LARAGPID=55;

ADD LARAGPMEM: LARAGPID=55, IDTYPE=RA, MCC="123", MNC="05", LAC="0x1000", RAC="0x20";

ADD GBSUBRRLST: SUBRANGE=IMSI\_PREFIX, IMSIPRE="123456", LARAGPID=55, ARMODE=BLACKLST, CAUSE=NO\_SUITABLE\_CELLS\_IN\_LA;
