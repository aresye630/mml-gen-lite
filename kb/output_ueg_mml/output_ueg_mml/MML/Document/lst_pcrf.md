# 查询PCRF实体配置信息(LST PCRF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令是维护类命令，用于在配置数据库中查询本端PCRF实体的配置信息。查询时可以不用输入任何参数，也可以依据参数说明输入查询条件，所得查询结果相同。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                      |
|:-------|:-------|:--------------------------------------------------------------------------|
| PCRFID | PCRF标识 | 用于在UPCF配置库中定义一个PCRF功能实体。 取值范围： 1 默认值： 无。                                  |
| EN     | 实体名称   | 用于具体描述本端PCRF实体的名称，以便于识别。其值域类型为字符串，区分大小写。 取值范围： 长度不超过128的字符串 默认值： 无。       |
| DN     | 本地域名   | 用于标识本端实体域名。该参数在配置和查询时都不区分大小写。 取值范围： 长度不超过64的字符串 默认值： 无。                   |
| HN     | 本地主机名  | 用于在UPCF配置库中定义本端实体主机名，必须全网唯一。该参数在配置和查询时都不区分大小写。 取值范围： 长度不超过127的字符串 默认值： 无。 |

## 使用实例

1. 查询所有的本端PCRF实体配置信息。

   ```
   LST PCRF:;
   ```

   ```
   %%LST PCRF:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
      PCRF标识  =  1
      实体名称  =  PCRF
      本地域名  =  huawei.com
    本地主机名  =  pcrf.huawei.com
   Gx 接口能力  =  2400
   (结果个数 = 1)

   ---    END
   ```
2. 查询一个本端PCRF实体配置信息。PCRF实体标识为1。

   ```
   LST PCRF: PCRFID=1;
   ```

   ```
   %%LST PCRF: PCRFID=1;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
      PCRF标识  =  1
      实体名称  =  PCRF
      本地域名  =  huawei.com
    本地主机名  =  pcrf.huawei.com
   Gx 接口能力  =  2400
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                                           |
|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------|
| Gx接口能力  | 表示查询到的最大Gx消息处理能力，即PCRF最大每秒可处理的Gx接口消息（包括CCR、CCA、RAR、RAA）数。 单位：个/秒  说明： Gx接口能力=PCRF对象可用的PES服务个数*每个PES的Gx接口处理能力（400个/秒）。PCRF对象可用的PES服务个数每隔60秒刷新一次。 |
