# 显示DNS服务器状态(DSP DNSS)

- 命令功能
- 注意事项
- 本地用户权限

- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用网元：SGSN、MME****、AMF**

该命令用于查看DNS服务器的状态。

#### 注意事项

- 该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询DNS服务器信息：

DSP DNSS:;

```
%%DSP DNSS:;%%
RETCODE = 0  操作成功。

操作结果如下
-------------------------
 服务器组ID    IP地址类型     IP地址           域名服务器优先级   DNS服务器名称     服务器状态   是否支持递归
 0            IPV4           192.168.179.1   优先级1           NULL              正常        不支持
 1            IPV4           192.168.179.2   优先级1           NULL              故障        不支持
(结果个数 = 2)

---    END
```

#### 输出结果说明

| 输出项名称    | 输出项解释                                                                               |
|:---------|:------------------------------------------------------------------------------------|
| 服务器组ID   | DNS服务器组ID。 取值说明：0~37                                                                |
| IP地址类型   | DNS服务器IP地址类型。                                                                       |
| IP地址     | DNS服务器IPv4地址。                                                                       |
| IPv6地址   | DNS服务器IPv6地址。                                                                       |
| 域名服务器优先级 | DNS服务器的优先级。 取值说明： “PRI1”“PRI2”“PRI3”“PRI4”“PRI5”“PRI6”  说明： 优先级从PRI1到PRI6依次递减。      |
| DNS服务器名称 | DNS服务器名称。                                                                           |
| 服务器状态    | DNS服务器状态。 取值说明： 正常故障未知  说明： DNS服务器的状态可以是“正常”、“故障”、“未知”，当没有配置DNS本端实体时，DNS服务器状态为“未知”。 |
| 是否支持递归   | 是否支持递归。 取值说明： 不支持支持未知                                                               |
