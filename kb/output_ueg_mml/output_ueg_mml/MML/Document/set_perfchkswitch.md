# 设置性能统计核查开关(SET PERFCHKSWITCH)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于设置性能统计核查开关。

#### 注意事项

- 系统初次运行时，会执行系统初始设置值。
- 如果修改核查周期，新的核查周期会等到当前周期结束后生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                   |
|:------------|:-------|:-----------------------------------------------------------------------------------------------------------------------|
| CHECKSWITCH | 核查开关   | 可选必选说明：可选参数 参数含义：该参数打开/关闭性能核查开关。 数据来源：本端规划。 取值范围： “ON(打开)”“OFF(关闭)” 系统初始设置值：“ON(打开)”                                   |
| CHECKPERIOD | 核查周期   | 可选必选说明：条件可选参数 参数含义：该参数设置性能核查周期。 前提条件：只有“CHECKSWITCH（核查开关）”为“ON(打开)”时，该参数才有效。 数据来源：本端规划。 取值范围：30-1440(单位：分钟) 系统初始设置值：30 |

#### 使用实例

打开性能核查开关，设置核查周期为30分钟。

SET PERFCHKSWITCH:CHECKSWITCH=ON,CHECKPERIOD=30;
