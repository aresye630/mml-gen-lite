# 查询网元服务版本信息(LST UDMNFSRVVER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询网元服务版本信息。

- 若需要查询所有服务版本信息，不输入任何参数。
- 若需要查询某个服务版本的详细信息，请输入“索引”参数。
- 若需要查询某个组的服务版本信息，请输入“组名称”参数。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                   |
|:--------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
| GRPNAME | 组名称    | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个组名称来查询网元服务版本信息；若不输入，则表示查询所有的组名称。 取值范围：由数字、字母、“-”或“_”组成的长度不超过32的字符串。 参数来源：该参数由本端UDM自行定义。 默认值：无。 配置原则：该参数和“索引”参数组成全局唯一对象关键字段。 |
| INDEX   | 索引     | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个索引来查询网元服务版本信息；若不输入，则表示查询所有的索引。 取值范围：1~1024 参数来源：该参数由本端UDM自行定义。 默认值：无。 配置原则：该参数和“组名称”参数组成全局唯一对象关键字段。                         |

## 使用实例

1. 查询所有的网元服务版本信息：

   ```
   LST UDMNFSRVVER:;
   ```

   ```
   %%LST UDMNFSRVVER:;%% 
   RETCODE = 0  操作成功
       
   组名称           索引  URI中的接口版本  接口全部版本号  到期时间    
   grp1             1     v1               1.0.0           NULL       
   srvver-group-01  1020  v2               2.1.0           NULL       
   (结果个数 = 2)  

   ---    END
   ```
2. 查询“索引”为“1”的网元服务版本信息：

   ```
   LST UDMNFSRVVER: INDEX=1;
   ```

   ```
   %%LST UDMNFSRVVER: INDEX=1;%% 
   RETCODE = 0  操作成功             
            
            组名称  =  grp1            
              索引  =  1 
   URI中的接口版本  =  v1  
    接口全部版本号  =  1.0.0        
          到期时间  =  NULL 
   (结果个数 = 1)  

   ---    END
   ```
3. 查询“组名称”为“grp1”的网元服务版本信息：

   ```
   LST UDMNFSRVVER: GRPNAME="grp1";
   ```

   ```
   %%LST UDMNFSRVVER: GRPNAME="grp1";%%
   %% RETCODE = 0  操作成功 
               
            组名称  =  grp1            
              索引  =  1 
   URI中的接口版本  =  v1  
    接口全部版本号  =  1.0.0        
          到期时间  =  NULL 
   (结果个数 = 1)  

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD UDMNFSRVVER**命令的参数说明。
