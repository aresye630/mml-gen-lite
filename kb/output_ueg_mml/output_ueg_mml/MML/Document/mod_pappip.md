# 修改对端设备配置(MOD PAPPIP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改一条对端设备配置数据，在该命令中，系统通过“对端设备名称”来唯一标识一条对端设备配置数据。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                                   |
|:----------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------|
| PAPPIPNM  | 对端设备名称  | 可选必选说明：必选参数 参数含义：标识对端设备配置数据的关键字段（其取值不能被修改），用于指定需要对哪个对端设备名称对应的设备配置数据记录的参数进行修改，操作员可以使用LST PAPPIP命令查询获得。 取值范围：长度不超过63的字符串。 默认值：无。 配置原则：无。 |
| PAPPGRPNM | 对端设备组名称 | 可选必选说明：可选参数 参数含义：用于标识待修改的对端设备配置所属设备组名称。 取值范围：长度不超过63的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 配置原则：该参数必须先由ADD PAPPIPGRP命令定义，然后才能在此处引用。      |
| IPVER     | IP地址类型  | 可选必选说明：可选参数 参数含义：用于标识待修改的对端设备IP地址类型。 取值范围：IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。                                                          |
| IPV4IP    | IPV4地址  | 可选必选说明：条件必选参数 参数含义：用于标识待修改的对端设备IPV4地址。 取值范围：标准IPV4地址。 默认值：无。 配置原则：仅当本命令中的“IP地址类型”参数为“IPV4(IPV4开关)”时该参数有效。                              |
| IPV6IP    | IPV6地址  | 可选必选说明：条件必选参数 参数含义：用于标识待修改的对端设备IPV6地址。 取值范围：标准IPV6地址。 默认值：无。 配置原则：仅当本命令中的I“P地址类型”参数为“IPV6(IPV6开关)”时该参数有效。                              |
| REMARK    | 备注      | 可选必选说明：可选参数 参数含义：用于标识对端设备配置的备注。 取值范围：长度不超过63的字符串。 默认值：无。 配置原则：无。                                                                       |

## 使用实例

修改一条对端设备配置数据。“对端设备名称”为“PeerIp”，“对端设备组名称”为“PeerIpGroup”，“IP地址类型”为“IPV4”，“IPV4地址”为“10.99.99.99”，“备注”为“remark”

```
MOD PAPPIP: PAPPIPNM="PeerIp", PAPPGRPNM="PeerIPGroup", IPVER=IPV4, IPV4IP="10.99.99.99", REMARK="remark";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                 | 原因分析                               | 处理建议                                                                                                                                 |
|-------:|:----------------------|:-----------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------|
|    505 | 当前操作的配置数据不存在          | 输入修改信息错误，需要输入已存在的“对端设备名称”。         | 通过LST PAPPIP查询对端设备配置信息，找到所修改对端设备配置对应的“对端设备名称”，并重新填入。                                                                                 |
| 360036 | 对端设备配置IP已存在           | 修改的对端设备IP地址已存在。                    | 重新填入对端设备IP地址，不要与已存在的IP地址重复。 可通过LST PAPPIP查询已添加的对端IP地址，若已存在则勿重复填入。                                                                    |
| 360038 | 对端设备组名称不存在，需要先添加对端设备组 | 修改对端设备时使用的“对端设备组名称”不存在。            | 可通过以下两种方式处理： 需要监控指定的设备或者IP时通过ADD PAPPIPGRP增加相应的对端设备组，然后执行该命令修改对端设备配置数据到新添加的设备组。修改到已存在的“对端设备组名称”的设备组内，填写错误时设备组名称可通过LST PAPPIPGRP查询获得。 |
| 360039 | IP地址类型不可更改            | 不可将对端设备配置由IPV4改为IPV6，或由IPV6改为IPV4。 | 若想修改当前对端设备配置的IP地址类型，可新增一条要修改“IP地址类型”I的对端设备配置。                                                                                        |
| 360093 | 默认配置数据的添加、删除、修改受限。    | 默认对端设备配置统计默认IP话统数据，不可修改。           | 不允许修改默认对端设备配置数据。                                                                                                                     |
