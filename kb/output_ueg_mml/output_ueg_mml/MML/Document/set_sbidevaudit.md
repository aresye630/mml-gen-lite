# 设置SBI接口设备间审计参数（SET SBIDEVAUDIT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响系统性能，需联系华为技术支持确认后再执行。

该命令用于启动N7/N28/Bsf/N23设备间会话审计和N7单会话审计。通过设置该命令，可以周期性的检查会话数据的一致性，及时修复不一致的数据，降低对业务的影响。

本命令的使用场景为：支持N7/N28/Bsf/N23设备间会话审计和N7单会话审计。

## 注意事项

- **生效方式**：执行该命令将“DATIME”的取值由“A”修改为“B”，且“A”和“B”均不为“0”时，执行结果将在当前时长为“A”的审计周期结束后生效。若需要执行结果立即生效，请先执行该命令将“DATIME”的取值修改为“0”，再执行该命令将“DATIME”的取值修改为“B”。

- 执行该命令将“DATIME”的取值若从“0”改为“非0”时，若当前还有正在执行的审计任务，等本轮审计结束后再以“非0”为周期审计。

- 设备间审计是为了UPCF与对端会话数据保持一致，N7接口设备间审计分为两类，一类是N7上线后下发revalidationTime由对端通过Npcf\_SMPolicyControl\_Update Request消息上报进行审计，第二类是UPCF通过Npcf\_SMPolicyControl\_UpdateNotify Request消息进行审计。

该命令存在系统初始记录，参数的初始设置值如表1。

| SBI接口类型   |   设备间审计时长（m） |   对端上报审计时长（m） |   连续审计超时次数 |   周期性审计时长（m） |
|:----------|-------------:|--------------:|-----------:|-------------:|
| N28       |            0 |             0 |          0 |            0 |
| N7        |            0 |           480 |          0 |            0 |
| Bsf       |            0 |             0 |          0 |            0 |
| N23       |            0 |             0 |          0 |            0 |

## 参数说明

| 参数标识           | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                  |
|:---------------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SBITYPE        | SBI接口类型     | 可选必选说明：必选参数 参数含义：用于选择SBI接口类型。 取值范围： N28(N28)N7(N7)Bsf(Bsf)N23(N23) 默认值：无。 配置原则：运营商根据实际场景规划。                                                                                                                                                                                                                                                                                                                           |
| DATIME         | 设备间审计时长（m）  | 可选必选说明：可选参数 参数含义：用于设置SBI接口设备间会话审计的时长。 取值范围： 0，表示不审计15～1440 单位：分钟 默认值：无。如果不输入该参数，则保持系统初始值，具体参见表1。 配置原则：运营商根据实际场景规划。  说明： 可通过VRM_DEVAUDITACCELERATION软参控制是否快速的完成设备间会话审计。当“SBITYPE”为“N7”时，PCF只对链路状态正常的N7会话进行设备间审计，链路状态异常则不审计。当“SBITYPE”为“Bsf”时，PCF只对链路状态正常的Bsf会话进行设备间审计，链路状态异常则不审计。                                                                                                                                      |
| PRATIME        | 对端上报审计时长（m） | 可选必选说明：可选参数 参数含义：用于设置5G接入的N7接口的会话审计的时长，使对端SMF在一定时间间隔内通过Npcf_SMPolicyControl_Update消息上报RE_TIMEOUT事件，以便UPCF能及时恢复会话。 取值范围：0～2880 0：不启用审计。1～29：测试用值，不建议使用。30～2880：会话审计的时间间隔。 单位：分钟 默认值：无。如果不输入该参数，则保持系统初始值，具体参见表1。 配置原则：运营商根据实际场景规划。  说明： 先执行ADD APN命令设置APN与N7会话的APN相同，该参数设置的会话审计时间才能被下发。该参数与时间段业务、5G动作revalidationTime交互时，会取三者中计算得到的最近的一个时间作为“revalidationTime”下发的时间。N28不支持单会话审计，该参数对N28接口不生效。Bsf不涉及上报审计时长，该参数对Bsf接口不生效。 |
| TIMEOUTNUM     | 连续审计超时次数    | 可选必选说明：可选参数 参数含义：用于设置连续审计超时次数。 取值范围：0、3～32 0：表示不记录审计超时次数3～32 默认值：无。 配置原则：当参数“SBITYPE”设置为“N7”时，才可以配置该参数。  说明： 当参数“SBITYPE”设置为“N7”，且参数“DATIME”设置为“0”时，该参数不生效。                                                                                                                                                                                                                                                           |
| PERIODICDATIME | 周期性审计时长（m）  | 可选必选说明：可选参数 参数含义：用于设置N23接口的会话审计时长，使得UPCF在一定周期内通过N23的订阅更新消息探测NWDAF对应会话是否存在。 取值范围： 0，表示不审计1～9：测试用值，不建议使用。10～1440:商用时可配。 单位：分钟 默认值：无。如果不输入该参数，则保持系统初始值，具体参见表1。 配置原则：运营商根据实际场景规划。  说明： 如果配置NWDAF在线会话审计时长，建议将软参“VRM_SYNTIMER”的取值取为“1”。                                                                                                                                                                                     |

## 使用实例

设置设备间N28会话审计，“SBI接口类型”为“N28(N28)”，“设备间审计时长（m）”为“720”。

```
SET SBIDEVAUDIT: SBITYPE=N28, DATIME=720;
```

设置设备间N23会话审计，“SBI接口类型”为“N23(N23)”，“周期性审计时长（m）”为“500”。

```
SET SBIDEVAUDIT: SBITYPE=N23, PERIODICDATIME=500;
```
