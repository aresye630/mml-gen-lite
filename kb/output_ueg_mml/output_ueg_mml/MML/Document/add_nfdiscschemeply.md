# 增加服务发现Scheme优选策略（ADD NFDISCSCHEMEPLY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF、SMF、NSSF、SMSF、NCG、NEF、NWDAF、SCF**

该命令用于增加服务发现时的Scheme优选策略。当服务发现对端NF后，配置的Scheme优选策略用于选择同一NF相同服务名称的不同NF Service，无法用于选择不同的NF。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入2048条记录。
- 当策略配置为"NO\_DIFF"时，无差别选择HTTP或HTTPS的NF Service，如果需要进行NF Service负载均衡，再根据优先级和权重选出一个NF Service。
- 当策略配置为"HTTP\_ONLY"或"HTTPS\_ONLY"时，先根据策略选出符合要求的NF Service，如果需要进行NF Service负载均衡，再根据优先级和权重选出一个NF Service。
- 当策略配置为"HTTP\_FIRST"或"HTTPS\_FIRST"时，如果不需要进行NF Service负载均衡，则根据策略选出符合要求的NF Service；如果需要进行NF Service负载均衡，则先选出优先级最高的NF Service，再根据策略选出符合要求的NF Service，最后根据权重选出一个NF Service。
- 按NFInstanceId配置的策略优先于按NFType配置的策略生效。
- 按NFType配置优选策略时，SERVICENAME只能设置为"SrvNameALL"或该NFType支持的服务名称。
- 对于同一种NFType或同一个NFInstanceId，不允许同时存在SERVICENAME设置为"SrvNameALL"与设置为其它值的记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

- 增加NF类型为UDM，服务名称为NudmSdm的Scheme优选策略记录，将策略设置为HTTP\_ONLY。

  ```
  %%ADD NFDISCSCHEMEPLY: INFOTYPE=BYNFTYPE, NFTYPE=NfUDM, SERVICENAME=NudmSdm, POLICY=HTTP_ONLY;%%
  RETCODE = 0  操作成功

  ---    END
  ```
- 增加NF实例标识为smf\_Instance\_0，服务名称为NsmfPduSes的Scheme优选策略记录，将策略设置为HTTPS\_ONLY。

  ```
  %%ADD NFDISCSCHEMEPLY: INFOTYPE=BYNFID, NFINSTANCEID="smf_instance_0", SERVICENAME=NsmfPduSes, POLICY=HTTPS_ONLY;%%
  RETCODE = 0  操作成功

  ---    END
  ```
