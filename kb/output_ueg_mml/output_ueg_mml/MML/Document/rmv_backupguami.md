# 删除供备GUAMI信息（RMV BACKUPGUAMI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除将本AMF用作备用AMF的某个GUAMI信息。

## 注意事项

- 该命令执行后立即生效。

- 增加、删除或者修改本AMF提供备用功能的GUAMI信息，都会引起本AMF到NRF的注册更新。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                |
|:-------|:--------|:----------------------------------------------------------------------------------------------------|
| INDEX  | GUAMI索引 | 可选必选说明：必选参数  参数含义：该参数是将本AMF作为备用AMF的GUAMI的配置记录索引信息。  数据来源：本端规划  取值范围：整数类型，取值范围是0~255。  默认值：无  配置原则：无 |

## 使用实例

Pool内其它AMF的某个GUAMI将本AMF用作备用节点，当该AMF从Pool内迁出时，本AMF的供备GUAMI列表需要同步刷新，执行如下命令：

```
RMV BACKUPGUAMI: INDEX=11;
```
