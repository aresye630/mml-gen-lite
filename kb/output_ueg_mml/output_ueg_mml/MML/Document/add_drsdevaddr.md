# 添加DRS设备地址(ADD DRSDEVADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条DRS设备地址信息数据记录。

DRS支持与UPCF内部服务对接实现报表汇聚，并支持与POP-D网元对接进行报表上传。此命令用于配置DRS本端业务地址，从而完成与内部服务和远端网元对接建链。

## 注意事项

- 对于IPv4地址，不支持配置以下地址：127.0.0.1、0.0.0.0、255.255.255.255、224.0.0.1。
- IPv6类型的IP地址仅支持格式xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx，其中x表示一个十六进制数（0～9、A～F或者a~f）。
- “IPV6地址”不支持以下特殊地址的配置，其中x表示一个十六进制数（0～9、A～F或者a~f），A-F与a-f实际意义一样，大小写不区分：

  - 0000:0000:0000:0000:0000:0000:0000:0000
  - FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF
  - 0000:0000:0000:0000:0000:0000:0000:0001
  - FFxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE8x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE9x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEAx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEBx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
- 当未配置IP地址时，DRS能够启动，但不能提供服务。
- 当执行ADD DRSDEVADDR/MOD DRSDEVADDR/RMV DRSDEVADDR增加、修改、删除IP地址时，都必须重启DRS服务，具体操作为：
  1. 登录“UPCF MML命令”界面；
  2. 执行**RST MSPROCESS**命令重启DRS服务：

     ```
     RST MSPROCESS: PROCOBJECT=PROCNAME, PROCNAME="CELL_PcfDrs";
     ```
- PMS/NTS/DRS/HLB/DLB/NLF/LDAP设备的IP地址（包括IPv4地址和IPv6地址）需要唯一，任意两种设备的IP地址不能重复。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                              |
|:------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DEVAID      | 设备地址标识 | 可选必选说明：必选参数 参数含义：用于在UPCF配置库中定义一条本地设备地址信息。 取值范围：0~7 默认值：无。 配置原则：标识为0的地址用于与NLF/DMA/UCF服务对接建链，故需要与NLFDEVADDR/RSFTPSERVER/UCFIP的IP类型保持一致。如果通过“LST UCFIP:;”命令查询UCF地址的IP类型是IPV6，那么DEVAID为0的IP类型必须是IPV6。 |
| VPNNAME     | VPN名称  | 可选必选说明：必选参数 参数含义：用于标识CSLB业务IP的VPN名称。 取值范围：长度不超过31的字符串 默认值：无。 配置原则：需要与ADD L3VPNINST命令中“VPN实例名称”参数值保持一致。                                                                                            |
| IPVER       | IP版本   | 可选必选说明：必选参数 参数含义：用于指定本端IP地址的IP版本类型。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。                                                                                                                     |
| IP          | IPV4地址 | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV4(IPV4)”时该参数有效，用于表示本设备的IPv4地址。 取值范围：IPv4地址 默认值：无。 配置原则：无。                                                                                                          |
| IPV6        | IPV6地址 | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV6(IPV6)”时该参数可配置，用于表示本设备的IPv6地址。 取值范围：IPv6地址 默认值：无。 配置原则：无。                                                                                                         |
| FTP         | FTP    | 可选必选说明：可选参数 参数含义：用于标识是否作为与POP-D对接的FTP客户端。 取值范围： YES(是)NO(否) 默认值：NO(否)。 配置原则：只有采用FTP协议场景时，本参数的取值才能为“YES(是)”。                                                                                       |
| DESCRIPTION | 描述     | 可选必选说明：可选参数 参数含义：用于描述设备IP地址的用途。 取值范围：长度不超过32位的字符串 默认值：无。 配置原则：无。                                                                                                                                  |

## 使用实例

**注意** 

标识为0的地址用于与NLF/DMA/UCF服务对接建链，故需要与NLFDEVADDR/RSFTPSERVER/UCFIP的IP类型保持一致。如果通过“LST UCFIP:;”命令查询UCF地址的IP类型是IPV6，那么DEVAID为0的IP类型必须是IPV6。

1. 增加IPv6类型的DRS设备地址信息。“设备地址标识”为“0”，“VPN名称”为“VPN2”，“IP版本”为“IPV6(IPV6)”，“IPV6地址”为“2001:0db8:3586:1000:1000:1111:1010:ffff”，“FTP”为“NO(No)”，“描述”为“DRS\_IPV6”。

   ```
   ADD DRSDEVADDR: DEVAID=0, VPNNAME="VPN2", IPVER=IPV6, IPV6="2001:0db8:3586:1000:1000:1111:1010:ffff", FTP=NO, DESCRIPTION="DRS_IPV6";
   ```
2. 增加IPv4类型的DRS设备地址信息。“设备地址标识”为“1”，“VPN名称”为“VPN1”，“IP版本”为“IPV4(IPV4)”，“IPV4地址”为“192.168.1.130”，“FTP”为“YES(Yes)”，“描述”为“DRS\_IPV4”。

   ```
   ADD DRSDEVADDR: DEVAID=1, VPNNAME="VPN1", IPVER=IPV4, IP="192.168.1.130", FTP=YES, DESCRIPTION="DRS_IPV4";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                                  | 原因分析                                                     | 处理建议                                                                                         |
|------:|:---------------------------------------|:---------------------------------------------------------|:---------------------------------------------------------------------------------------------|
| 58025 | 当前已经有IPV4/IPV6类型的本地地址存在，不能重复同一类型的IP地址。 | 同一类型的IP地址只允许添加一条。                                        | 执行LST DRSDEVADDR命令，查询所有的DRS设备地址记录。执行RMV DRSDEVADDR命令，删除同一类型的设备地址。重新执行本命令添加设备地址。              |
| 58107 | 设备地址冲突。                                | PMS/NTS/DRS/HLB/DLB/NLF/LDAP设备的IP地址需要唯一，任意两种设备的IP地址不能重复。 | 修改IP地址，重新执行本命令增加设备地址。                                                                        |
| 58246 | 当DEVAID取值为0时，FTP取值不能为YES。              | 在添加新的一条记录中，当“设备地址标识”参数取值为“0”时，“FTP”参数取值不能为“YES”。         | 重新执行本命令添加设备地址，使“设备地址标识”取值为“0”时“FTP”参数取值为“NO”。重新执行本命令添加设备地址，使“设备地址标识”取值不为“0”时“FTP”参数取值为“YES”。 |
