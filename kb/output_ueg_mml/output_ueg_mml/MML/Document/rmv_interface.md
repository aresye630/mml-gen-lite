# 删除接口（RMV INTERFACE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来删除已创建的逻辑接口并清除该接口的相关配置。逻辑接口是指能够实现数据交换功能但物理上不存在、需要通过配置建立的接口，包括Loopback接口、NULL0接口等。

#### 注意事项

- 该命令执行后立即生效。
- 为了保证该接口能够删除，必须确保该接口在设备上已经存在。
- 该命令在版本升级过程中禁止执行。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                         |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------|
| IFNAME | 接口名    | 可选必选说明：必选参数 参数含义：该参数用于指定接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。接口名称由接口类型+接口编号组成。接口编号是十进制自然数，当编号为0时填写为“0”，其他情况不得以“0”开头。 默认值：无 |

#### 使用实例

删除逻辑接口LoopBack4：

```
RMV INTERFACE: IFNAME="LoopBack4";
```
