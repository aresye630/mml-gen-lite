# 删除NSSF功能实例信息（RMV NSSFFUNCTION）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NSSF**

该命令用于删除NSSF功能实例信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                            |
|:-----------|:----------|:--------------------------------------------------------------------------------|
| INSTANCEID | NSSF功能实例号 | 可选必选说明：必选参数  参数含义：NSSF功能实例号。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~40。  默认值：无  配置原则：无 |

## 使用实例

删除NSSF功能实体号为Instanceid01的NSSF功能实例信息。

```
RMV NSSFFUNCTION:INSTANCEID="Instanceid01";
```
