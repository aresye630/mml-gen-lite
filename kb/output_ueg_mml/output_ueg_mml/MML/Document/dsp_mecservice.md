# 查询MEC服务（DSP MECSERVICE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF、MPF**

该命令用于查询已注册的MEC服务列表。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                            |
|:-----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETAG | 服务标签   | 可选必选说明：可选参数 参数含义：该参数用于指定服务标签。 数据来源：本端规划 取值范围： MP1SERVICE：通过Mp1接口注册的服务。MEPSERVICE：MEP平台提供的服务。MM5SERVICE：通过MM5接口注册的服务。LESERVICE：通过Le接口开放的服务。MP2SERVICE：通过Mp2接口开放的服务。 默认值：无 配置原则：无 |

#### 使用实例

- 查询注册的MEC服务列表：

  ```
  DSP MECSERVICE:;
  ```

  ```
  RETCODE = 0  操作成功

  MEC服务列表
  -----------
  服务名          服务标签     

  apigw           MEP服务      
  app01_service1  MM5接口服务  
  app01_service2  Mp1接口服务  
  AseMaster       MEP服务      
  asr             MEP服务      
  (结果个数 = 5)

  ---    END
  ```
- 查询注册的Mp1接口服务：

  ```
  DSP MECSERVICE: SERVICETAG=MP1SERVICE;
  ```

  ```
  RETCODE = 0  操作成功

  MEC服务列表
  -----------
  服务名  =  app01_service2
  服务标签  =  Mp1接口服务
  (结果个数 = 1)

  ---    END
  ```

#### 输出结果说明

| 输出项名称   | 输出项解释     |
|:--------|:----------|
| 服务名     | 服务名。      |
| 服务标签    | 用于指定服务标签。 |
