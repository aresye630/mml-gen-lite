# 设置基于APN的下行数据长时间缓存配置（SET APNDLLTBUFFER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

此命令用来配置基于APN的用户下行数据长时间缓存时的最大缓存个数及存储方式。

#### 注意事项

- 该命令执行后对新数据流生效。
- 系统最多支持配置10000条。
- 该命令在下行缓存时长超过15秒时生效，下行缓存时长小于15秒时，默认下行缓存报文数量为128个。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   |   MAXBUFFERNUM | BUFFERMODE     |
|:-------|---------------:|:---------------|
| 初始值    |              1 | BUFF_MODE_RING |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                   |
|:-------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN          | APN    | 可选必选说明：必选参数 参数含义：该参数用于指定APN实例名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。 默认值：无 配置原则：该参数使用ADD UPAPN命令配置生成。                                                                                                |
| MAXBUFFERNUM | 最大缓存个数 | 可选必选说明：必选参数 参数含义：该参数用于设置基于APN的下行数据长时间缓存时的最大缓存个数。当获取了License控制项为“82200CKC LKV3G5NDRX01 NB-IoT eDRX模式”的license或者“82200FYD LKV3G5EDRX01 5G eDRX模式”的license时，该参数与session modification request/session report response消息携带的缓存个数取最小值作为系统实际缓存的最大个数; 否则，使用参数配置作为系统实际缓存的最大个数。 数据来源：本端规划 取值范围：整数类型，取值范围为1～64，单位是包数。 默认值：无 配置原则：无 |
| BUFFERMODE   | 存储方式   | 可选必选说明：必选参数 参数含义：该参数用于设置缓存报文达到规格时，报文的存储方式。环形存储是指丢弃最先存储的报文，缓存当前报文；链式存储是指丢弃当前收到的报文。 数据来源：本端规划 取值范围：枚举类型。 BUFF_MODE_RING：环形存储。BUFF_MODE_CHAIN：链式存储。 默认值：无 配置原则：无                                                                                                                                                          |

#### 使用实例

配置APN为apn1.com的APN下行报文长时间缓存最大个数为64个，存储方式为环形存储：

```
SET APNDLLTBUFFER: APN="apn1.com", MAXBUFFERNUM=64, BUFFERMODE=BUFF_MODE_RING;
```
