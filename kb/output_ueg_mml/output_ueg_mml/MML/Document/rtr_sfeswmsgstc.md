# 清除FEISW消息统计（RTR SFESWMSGSTC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来清除FEISW消息统计。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                     |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------|
| RUNAME | 资源单元名称 | 可选必选说明：必选参数 参数含义：指定系统中有效的资源单元。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则： 区分大小写，不支持空格。使用DSP RU查看RU名称。 |

#### 使用实例

清除FEISW消息统计：

```
RTR SFESWMSGSTC: RUNAME="VNRS_IPCTRL_EX_RU_0201";
RETCODE = 0  操作成功。

---    END
```
