# 配置pRRU节点坐标信息（ADD PRRUNODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

配置PRRU节点坐标信息。

#### 注意事项

该命令最大记录数为20000。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称            | 参数说明                                                                                                                         |
|:------------|:----------------|:-----------------------------------------------------------------------------------------------------------------------------|
| GNODEBID    | 基站标识            | 可选必选说明：必选参数 参数含义：该参数用于设置基站标识。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无 配置原则：无                                            |
| MAPID       | 地图标识            | 可选必选说明：必选参数 参数含义：该参数用于设置地图标识。 数据来源：本端规划 取值范围：整数类型，取值范围为-9223372036854775808～9223372036854775807。 默认值：无 配置原则：无                |
| CN          | pRRU柜号          | 可选必选说明：必选参数 参数含义：该参数用于设置pRRU柜号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～255。 默认值：无 配置原则：无                                                 |
| SRN         | pRRU框号          | 可选必选说明：必选参数 参数含义：该参数用于设置pRRU框号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～255。 默认值：无 配置原则：无                                                 |
| SN          | pRRU槽号          | 可选必选说明：必选参数 参数含义：该参数用于设置pRRU槽号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～255。 默认值：无 配置原则：无                                                 |
| HEIGHT      | pRRU高度（厘米）      | 可选必选说明：必选参数 参数含义：该参数用于设置pRRU高度，单位：厘米。 数据来源：本端规划 取值范围：整数类型，取值范围为-9223372036854775808～9223372036854775807。 默认值：无 配置原则：无        |
| POSITIONX   | pRRU相对位置X信息（厘米） | 可选必选说明：必选参数 参数含义：该参数用于设置pRRU安装相对位置X信息，单位：厘米。 数据来源：本端规划 取值范围：整数类型，取值范围为-9223372036854775808～9223372036854775807。 默认值：无 配置原则：无 |
| POSITIONY   | pRRU相对位置Y信息（厘米） | 可选必选说明：必选参数 参数含义：该参数用于设置pRRU安装相对位置Y信息，单位：厘米。 数据来源：本端规划 取值范围：整数类型，取值范围为-9223372036854775808～9223372036854775807。 默认值：无 配置原则：无 |
| DESCRIPTION | 描述信息            | 可选必选说明：可选参数 参数含义：该参数用于设置pRRU配置描述信息。 数据来源：全网规划 取值范围：字符串类型，长度为32位。 默认值：无 配置原则：无                                                |

#### 使用实例

新增PRRU节点坐标信息：

```
ADD PRRUNODE: GNODEBID=460652, MAPID="42691", CN=21, SRN=34, SN=67, HEIGHT="150", POSITIONX="5175091", POSITIONY="5330746";
```
