# 清除SCTP所有偶联的统计信息(CLR DBSSCTPBS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，该操作将清除所有SCTP偶联统计信息，影响故障场景定位信息收集。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为维护类命令，用于清除指定DBS服务模块号的SCTP所有偶联的统计信息。执行命令后，SCTP偶联统计信息会清零，重新开始统计。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                    |
|:----------|:-------|:------------------------------------------------------------------------|
| SERVICENO | 服务模块号  | 可选必选说明：必选参数 参数含义：清除SCTP所有偶联的统计信息所在的DBS服务模块号。 取值范围： 1～1024 默认值： 无 配置原则：无 |

## 使用实例

清除DBS服务模块号为88的SCTP所有偶联的统计信息。执行如下命令：

```
CLR DBSSCTPBS: SERVICENO=88;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
