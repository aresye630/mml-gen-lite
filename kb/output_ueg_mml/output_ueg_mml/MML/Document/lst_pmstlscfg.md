# 查询PMS TLS配置(LST PMSTLSCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询配置数据库中PMS TLS配置信息：

- 如果需要查询全部的PMS TLS配置信息，请不要输入任何参数。
- 如果需要查询某个PMS TLS配置信息，请依据参数说明输入查询条件。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                                |
|:-----------|:--------|:----------------------------------------------------------------------------------------------------|
| TLSCFGID   | TLS配置ID | 可选必选说明：可选参数 参数含义：用于指示系统按照TLS配置ID来查询PMS的TLS配置信息；若不输入，则表示所有的TLS配置ID。 取值范围：1～128 默认值：无。 配置原则：无。        |
| TLSCFGNAME | TLS配置名称 | 可选必选说明：可选参数 参数含义：用于指示系统按照TLS配置名称来查询PMS的TLS配置信息；若不输入，则表示所有的TLS配置名称。 取值范围：长度不超过32的字符串。 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询所有的PMS TLS配置信息。

   ```
   LST PMSTLSCFG:;
   ```

   ```
   %%LST PMSTLSCFG:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   TLS配置ID  TLS配置名称  协议版本    强加密套件                   兼容加密套件    描述
         
   1          TLScfg01     TLS1.3      TLS1_3_AES_256_GCM_SHA384    NULL            PMS TLS          
   2          TLScfg02     TLS1.3      TLS1_3_AES_128_GCM_SHA256    NULL            PMS TLS 02   
   (结果个数 = 2)

   ---    END
   ```
2. 查询指定PMS TLS的配置信息。“TLS配置ID”为“1”。

   ```
   LST PMSTLSCFG: TLSCFGID=1;
   ```

   ```
   %%LST PMSTLSCFG: TLSCFGID=1;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
       TLS配置ID  =  1
     TLS配置名称  =  TLScfg01
        协议版本  =  TLS1.3
      强加密套件  =  TLS1_3_AES_256_GCM_SHA384
    兼容加密套件  =  NULL
            描述  =  PMS TLS
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD PMSTLSCFG**命令的参数说明。
