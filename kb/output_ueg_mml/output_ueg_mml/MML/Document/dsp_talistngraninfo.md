# 显示TALIST下5G基站接入数量信息（DSP TALISTNGRANINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询TALIST下5G基站接入数量信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                    |
|:----------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| QUERYTYPE | 查询类型   | 可选必选说明：可选参数  参数含义：该参数用于指定TALIST下基站信息查询的范围。  数据来源：本端规划 取值范围： “QUERYALL（全量查询）”：查询所有TALIST下接入的基站数量“OVERLOAD（过载查询）”：查询所有过载TALIST下接入的基站数量“SPECIFIEDTAI（指定TAI）”：查询指定TAI的基站接入数量  默认值：无  配置原则：无 |
| TAI       | 跟踪区标识  | 可选必选说明：该参数在"QUERYTYPE"配置为"SPECIFIEDTAI"时为条件必选参数。  参数含义：该参数表示NG-RAN基站支持的跟踪区信息。跟踪区标识由PLMN ID和TAC组成。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是11~12。  默认值：无  配置原则：无                                   |

## 使用实例

查询所有TALIST下5G基站接入数量信息，执行如下命令：

```
%%DSP TALISTNGRANINFO:;%%
RETCODE = 0  操作成功

操作结果如下
--------------
跟踪区列表标识 跟踪区标识       基站数目
1              total            200
1              46001000101      150
1              46001000102      50
(结果个数 = 1)
---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                     |
|:--------|:--------------------------------------------------------------------------|
| 跟踪区列表标识 | 该参数用于标识一个跟踪区列表，一个跟踪区列表由一个或若干个跟踪区组成。一个跟踪区列表最多可包含16个跟踪区。其通过ADD NGTALST进行配置。 |
| 跟踪区标识   | 该参数表示NG-RAN基站支持的跟踪区信息。跟踪区标识由PLMN ID和TAC组成。                                |
| 基站数目    | 该参数表示TALIST下接入的基站数目。                                                      |
