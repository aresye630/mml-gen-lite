# 查询DLB设备地址(LST DLBDEVADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于在配置数据库中查询DLB设备地址信息。

- 如果需要查询全部设备地址信息，请不要输入任何参数。
- 如果需要查询某条设备地址信息，请依据参数说明输入查询条件

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                        |
|:------------|:--------|:----------------------------------------------------------------------------------------------------------------------------|
| DEVAID      | 设备地址标识  | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个设备地址标识来查询DLB设备地址信息；若不输入，则表示所有的设备地址标识。 取值范围：0～31 默认值：无。 配置原则：无。                                 |
| VPNINDEX    | VPN索引   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个VPN索引来查询DLB设备地址信息；若不输入，则表示所有的VPN索引。 取值范围：0～15 默认值：无。 配置原则：无。                                   |
| IPVER       | IP版本    | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个IP版本来查询DLB设备地址信息；若不输入，则表示所有的IP版本。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。                    |
| IP          | IPV4地址  | 可选必选说明：可选参数 参数含义：当“IP版本”选择“IPV4(IPV4)”时，可设置该参数。用于指示系统需要按照哪个IPV4地址来查询DLB设备地址信息；若不输入，则表示所有的IPV4地址。 取值范围：IPv4地址 默认值：无。 配置原则：无。 |
| IPV6        | IPV6地址  | 可选必选说明：可选参数 参数含义：当“IP版本”选择“IPV6(IPV6)”时，可设置该参数。用于指示系统需要按照哪个IPV6地址来查询DLB设备地址信息；若不输入，则表示所有的IPV6地址。 取值范围：IPv6地址 默认值：无。 配置原则：无。 |
| DESCRIPTION | 描述      | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个描述来查询DLB设备地址信息；若不输入，则表示所有的描述。 取值范围：长度不超过32位的字符串 默认值：无。 配置原则：无。                                 |
| DSCP        | DSCP优先级 | 可选必选说明：可选参数 参数含义：用于指定修改后的DSCP优先级。 取值范围：0～63，255 默认值：255。 配置原则：无。  说明： DSCP优先级有64级，为0～63，级别为63时，优先级最高。255表示不设置DSCP。          |

## 使用实例

1. 查询所有的DLB设备地址的配置信息。

   ```
   LST DLBDEVADDR:;
   ```

   ```
   %%LST DLBDEVADDR:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   设备地址标识  VPN索引  IP版本  IPV4地址       IPV6地址  描述  DSCP优先级      

   1             1        IPV4    172.16.27.94   NULL      NULL  255  
   2             2        IPV4    192.168.0.130  NULL      TEST  255
   (结果个数 = 2)

   ---    END
   ```
2. 查询一条DLB设备地址的配置信息。“设备地址标识”为“2”。

   ```
   LST DLBDEVADDR: DEVAID=2;
   ```

   ```
   %%LST DLBDEVADDR: DEVAID=2;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   设备地址标识  =  2
        VPN索引  =  21 
         IP版本  =  IPV4
       IPV4地址  =  192.168.0.131
       IPV6地址  =  NULL
           描述  =  test2
     DSCP优先级  =  255
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD DLBDEVADDR**命令的参数说明。
