# 配置软参记录（SET UPSOFTPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于设置软件参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为5250。
- 该命令存在系统初始记录，参数的初始设置值如下表：

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                                     |
|:------------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DT          | 软参记录数据类型 | 可选必选说明：必选参数 参数含义：软件参数的数据类型。 数据来源：本端规划 取值范围：枚举类型。 BIT：比特。BYTE：字节。DWORD：双字。STRING：字符串。 默认值：无 配置原则： 配置BIT表示需要设置比特类型软件参数。配置BYTE表示需要设置字节类型软件参数。配置DWORD表示需要设置双字类型软件参数。配置STRING表示需要设置字符串类型软件参数。 |
| BITNUM      | Bit索引    | 可选必选说明：条件必选参数 前提条件：该参数在“DT”配置为“BIT”时为必选参数。 参数含义：比特类型软件参数的索引。 数据来源：本端规划 取值范围：整数类型，取值范围为1～3840。 默认值：无 配置原则：该参数在“DT”配置为“BIT”后生效。                                                            |
| BYTENUM     | Byte索引   | 可选必选说明：条件必选参数 前提条件：该参数在“DT”配置为“BYTE”时为必选参数。 参数含义：字节类型软件参数的索引。 数据来源：本端规划 取值范围：整数类型，取值范围为1～1200。 默认值：无 配置原则：该参数在“DT”配置为“BYTE”后生效。                                                          |
| DWORDNUM    | DWord索引  | 可选必选说明：条件必选参数 前提条件：该参数在“DT”配置为“DWORD”时为必选参数。 参数含义：双字类型软件参数的索引。 数据来源：本端规划 取值范围：整数类型，取值范围为1～180。 默认值：无 配置原则：该参数在“DT”配置为“DWORD”后生效。                                                         |
| STRINGNUM   | String索引 | 可选必选说明：条件必选参数 前提条件：该参数在“DT”配置为“STRING”时为必选参数。 参数含义：字符串类型软件参数的索引。 数据来源：本端规划 取值范围：整数类型，取值范围为1～30。 默认值：无 配置原则：该参数在“DT”配置为“STRING”后生效。                                                       |
| BITVALUE    | Bit值     | 可选必选说明：条件必选参数 前提条件：该参数在“DT”配置为“BIT”时为必选参数。 参数含义：比特类型参数的值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～1。 默认值：无 配置原则：该参数在“DT”配置为“BIT”后生效。                                                                  |
| BYTEVALUE   | Byte值    | 可选必选说明：条件必选参数 前提条件：该参数在“DT”配置为“BYTE”时为必选参数。 参数含义：字节类型参数的值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～255。 默认值：无 配置原则：该参数在“DT”配置为“BYTE”后生效。                                                              |
| DWORDVALUE  | Dword值   | 可选必选说明：条件必选参数 前提条件：该参数在“DT”配置为“DWORD”时为必选参数。 参数含义：双字类型参数的值。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无 配置原则：该参数在“DT”配置为“DWORD”后生效。                                                     |
| STRINGVALUE | String值  | 可选必选说明：条件可选参数 前提条件：该参数在“DT”配置为“STRING”时为可选参数。 参数含义：字符串类型参数的值。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～64。 默认值：无 配置原则： 输入单空格将删除该参数已有配置项。该参数在“DT”配置为“STRING”后生效。                                     |

#### 使用实例

设置软参，参数类型是字节类型，参数索引为181，参数取值为3：

```
SET UPSOFTPARA: DT=BYTE, BYTENUM=181, BYTEVALUE=3;
```
