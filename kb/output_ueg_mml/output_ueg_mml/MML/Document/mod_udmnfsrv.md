# 修改网元实例信息(MOD UDMNFSRV)

## 命令功能

**须知** 

对于非NRF上配置UDM的号段的场景或者网元类型非5G-EIR，则请确认UDM上的号段信息已经配置，未配置号段或者号段配置错误，将导致用户业务全损。本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改网元实例信息。在该命令中，系统通过“网元实例名称”关键参数来唯一标识一条网元实例信息。

## 注意事项

- 网元实例信息被修改后，立刻按指定的更新模式向NRF发起注册更新请求，仍旧需要维持周期心跳注册。心跳周期以更新响应中的“心跳周期”为准；“上报网管标志”、“更新方法”修改后，不需要发送注册更新请求。
- “网元公共信息标识”、“网元信息标识”和“网元服务组”这三个参数所定义的“网元类型”与修改的网元实例信息的“网元类型”必须相同。
- 当凌晨自动校验或执行**VRY NRFDATA**命令手动校验NRFClient内存数据时，在校验该MML命令的过程中，无法执行该命令，若运行该命令，则提示“360155 该MML数据正在校验中，请稍后再试”。
- 如果号段信息未配置，将可能导致全网号段指向此UDM，如果配置错误，可能将用户指向错误的UDM，导致用户接入鉴权失败，业务全损。

## 使用实例

1. 在开局场景下配置本局数据时，修改“网元实例名称”为“udm-application-002”网元实例信息，将“PLMN组名称”修改为“nfplmn02”：

   ```
   MOD UDMNFSRV: NFINSNAME="udm-application-002", CONFMODE=COMMOND, NFPLMNGRP="nfplmn02";
   ```
2. 修改“网元实例名称”为“udm-application-002”的网元实例信息，删掉“位置”参数已配置的取值，“位置”参数输入空格后执行该命令：

   ```
   MOD UDMNFSRV: NFINSNAME="udm-application-002", CONFMODE=COMMOND, LOCALITY=" ";
   ```
