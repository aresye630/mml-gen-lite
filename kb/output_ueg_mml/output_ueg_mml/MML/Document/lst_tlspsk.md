# 查询预共享密钥信息（LST TLSPSK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询预共享密钥信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                    |
|:----------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------|
| PSKIDX    | 索引       | 可选必选说明：可选参数  参数含义：该参数用于指定TLS预共享密钥的记录索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~128。  默认值：无  配置原则：无                                                |
| PSKGRPIDX | 预共享密钥组索引 | 可选必选说明：可选参数  参数含义：该参数用于指定TLS预共享密钥组的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~128。  默认值：无  配置原则：  与ADD TLSPSKGRP中配置的预共享密钥组索引保持一致。                 |
| PSKID     | 预共享密钥标识  | 可选必选说明：可选参数  参数含义：该参数用于指定预共享密钥的密钥ID。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~128。  默认值：无  配置原则：  该参数与“HTTP模式”参数组合，唯一标识一个预共享密钥记录，不能重复配置，而且大小写敏感。 |

## 使用实例

- 查询所有预共享密钥信息执行如下命令：

  ```
  %%LST TLSPSK:;%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
                                 索引  =  1
                     预共享密钥组索引  =  1
                                 模式  =  服务端模式
                       预共享密钥标识  =  psktest
                   预共享密钥内容类型  =  16进制ASCII码
                                 描述  =  NULL
  (结果数量 = 1)

  ---    END
  ```
- 查询索引为1的预共享密钥信息执行如下命令：

  ```
  %%LST TLSPSK: PSKIDX=1;%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
                                 索引  =  1
                     预共享密钥组索引  =  1
                                 模式  =  服务端模式
                       预共享密钥标识  =  psktest
                   预共享密钥内容类型  =  16进制ASCII码
                                 描述  =  NULL
  (结果数量 = 1)

  ---    END
  ```

## 输出结果说明

| 输出项名称     | 输出项解释                       |
|:----------|:----------------------------|
| 索引        | 该参数用于指定TLS预共享密钥的记录索引。       |
| 预共享密钥组索引  | 该参数用于指定TLS预共享密钥组的索引。        |
| 模式        | 该参数用于指定PSK信息在TLS的客户端或服务端使用。 |
| 预共享密钥标识   | 该参数用于指定预共享密钥的密钥ID。          |
| 预共享密钥内容类型 | 该参数用于控制预共享密钥值类型。            |
| 描述        | 该参数用于对TLS预共享密钥进行描述。         |
