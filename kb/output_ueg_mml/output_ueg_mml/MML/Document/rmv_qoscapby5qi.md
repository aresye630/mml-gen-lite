# 删除基于5QI的QosFlow QoS限制配置（RMV QOSCAPBY5QI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于删除基于5QI的QosFlow QoS限制的相关配置参数。

## 注意事项

命令执行后只对新接入用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                  |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：必选参数  参数含义：该参数表示用于QosFlow QoS限制配置的用户范围。  数据来源：全网规划 取值范围： INVALIDSUBRANGE（无效的用户范围）IMSI_PREFIX（指定IMSI前缀的用户）VISITING（拜访用户）ROAMING（漫游用户）HOME_USER（本网用户）ALL_USER（所有用户）HOME_NOLOCAL_USER（本网非本省用户）  默认值：无  配置原则：  “SUBRANGE（用户范围）”的优先级从高到低为：“IMSI_PREFIX（指定IMSI前缀）”，"HOME_NOLOCAL_USER"（本网非本省用户），“HOME_USER（本网用户）”或“ROAMING（漫游用户）”或“VISITING（拜访用户）”，“ALL_USER（所有用户）”。 |
| IMSIPRE  | IMSI前缀 | 可选必选说明：该参数在"SUBRANGE"配置为"IMSI_PREFIX"时为条件必选参数。  参数含义：该参数用于系统根据对用户的IMSI前缀进行匹配，从而区分不同的用户群。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是5~15。  默认值：无  配置原则：无                                                                                                                                                                                                                           |
| QOS5QI   | 标准5QI  | 可选必选说明：必选参数  参数含义：该参数用于指定系统对用户QosFlow的5QI限制。  数据来源：全网规划  取值范围：整数类型，取值范围是1~255。  默认值：无  配置原则：无                                                                                                                                                                                                                                                                         |

## 使用实例

删除“用户范围”为“IMSI\_PREFIX”，“IMSI前缀”为“308010700”，“QOS5QI”为“9”的基于5QI的QosFlow QoS限制配置：

```
RMV QOSCAPBY5QI:SUBRANGE=IMSI_PREFIX,IMSIPRE="308010700",QOS5QI=9;
```
