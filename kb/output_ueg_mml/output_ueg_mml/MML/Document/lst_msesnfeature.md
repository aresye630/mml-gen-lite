# 查询ESN特征信息(LST MSESNFEATURE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询ESN特征信息数据记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                 |
|:-------|:-------|:---------------------------------------------------------------------|
| INDEX  | INDEX  | 可选必选说明：可选参数 参数含义：用于标识待查询的ESN特征信息索引。 取值范围：0～4294967295 默认值：无。 配置原则：无。 |

## 使用实例

查询ESN特征信息，“INDEX”为“0”。

```
LST MSESNFEATURE: INDEX=0;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义如表1所示。

| 输出项名称        | 输出项解释                               |
|:-------------|:------------------------------------|
| IPINFO       | 用于返回生成ESN的IP地址材料。                   |
| HOSTNAMEINFO | 用于返回生成ESN的主机名材料。                    |
| GTINFO       | 用于返回生成ESN的GT材料。                     |
| FLAG         | 用于返回ESN特征信息标识符。 “0”：即将失效。 “1”：正在生效。 |
| DATE         | 用于返回数据记录的创建时间。                      |
