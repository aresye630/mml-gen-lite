# 删除GTP路径断告警屏蔽记录(RMV GTPALMMSK)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于删除一条屏蔽GTP路径告警的配置。

#### 注意事项

- 执行该命令前，需要提前配置**ADD GTPALMMSK**命令添加IP地址/网段/IP地址范围的GTP路径告警屏蔽记录。
- 该命令执行后立即生效。
- 该命令可以多次执行。
- 该命令执行后，仅对配置的IP地址网段新产生的GTP路径告警有效，不会恢复其之前产生的GTP路径告警。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称         | 参数说明                                                                                                                                                                                     |
|:----------|:-------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CFGTP     | 配置类型         | 可选必选说明：必选参数 参数含义：该参数用于指示配置屏蔽GTP路径告警的类型。 取值范围：“IPMASK(IP+掩码)”“SENDIP(起始IP+终止IP)”“IPV6MASK(IPv6+前缀)”“SENDIPV6(起始IPv6+终止IPv6)” 默认值：无                                                        |
| IPV4ADDR  | 起始对端设备IP地址   | 可选必选说明：条件必选参数 参数含义：该参数用于指示对端设备起始IPv4地址。 前提条件：在“MML命令行-UEG”窗口上执行命令ADD GTPALMMSK。 取值范围：0.0.0.0~255.255.255.255 默认值：无                                                                       |
| EIPV4ADDR | 终止对端设备IP地址   | 可选必选说明：条件必选参数 参数含义：该参数用于指示对端设备终止IPv4地址。 前提条件：在“MML命令行-UEG”窗口上执行命令ADD GTPALMMSK。 取值范围：0.0.0.0~255.255.255.255 默认值：无  说明： 本参数的取值应该大于等于“起始对端设备IP地址”的取值。                                     |
| MASKV4    | 掩码           | 可选必选说明：条件必选参数 参数含义：该参数用于指示对端设备的IPv4地址的掩码。 前提条件：在“MML命令行-UEG”窗口上执行命令ADD GTPALMMSK。 取值范围：0.0.0.0~255.255.255.255 默认值：无                                                                     |
| IPV6ADDR  | 起始对端设备IPv6地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指示对端设备起始IPv6地址。 前提条件：在“MML命令行-UEG”窗口上执行命令ADD GTPALMMSK。 取值范围：0:0:0:0:0:0:0:0 ~ FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无                                     |
| EIPV6ADDR | 终止对端设备IPv6地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指示对端设备终止IPv6地址。 前提条件：在“MML命令行-UEG”窗口上执行命令ADD GTPALMMSK。 取值范围：0:0:0:0:0:0:0:0 ~ FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF 默认值：无  说明： 本参数的取值应该大于等于“起始对端设备IPv6地址”的取值。 |
| PRELEN    | 前缀长度         | 可选必选说明：条件必选参数 参数含义：该参数用于指示对端设备的IPv6地址的前缀长度。 前提条件：在“MML命令行-UEG”窗口上执行命令ADD GTPALMMSK。 取值范围：0~128 默认值：无                                                                                     |

#### 使用实例

1.数据配置错误或者指定的对端设备已经不存在，对应的IP地址为：192.168.168.12，掩码为：255.255.255.255，需要删除此设备的数据：

RMV GTPALMMSK: CFGTP=IPMASK, IPV4ADDR="192.168.168.12", MASKV4="255.255.255.255";
