# 添加网元信息（ADD UDMNFINFO）

## 命令功能

**须知** 

本命令属于高危命令，号段组信息和路由指示信息配置不当会导致UDM在NRF上注册的号段、路由指示信息和UDM的实际的号段、路由指示信息不一致，造成业务失败。对于非NRF上配置UDM的号段的场景或者网元类型非5G-EIR，则请确认UDM上的号段信息已经配置，未配置号段或者号段配置错误，将导致用户业务全损。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于为UDM、AUSF等网元增加其特定信息，包含3GPP TS 29.510协议中服务注册时需要使用的UdmInfo、AusfInfo等信息。

该命令的参数索引关系如图1所示。

**图1** 命令参数的索引关系图

**说明** 

当前版本不支持为5G-EIR网元增加“外部组标识范围组”配置信息。

## 注意事项

- 同一个“网元组ID”下“SUPI号段组”、“GPSI号段组”和“外部组标识范围组”总号段量建议不超过15000，如果超过15000，可能引起**DSP UDMNFSRV**查询网元实例动态信息超时。
- 当凌晨自动校验或执行**VRY NRFDATA**命令手动校验NRFClient内存数据时，在校验该MML命令的过程中，无法执行该命令，若运行该命令，则提示“360155 该MML数据正在校验中，请稍后再试”。
- 执行该命令时，如果参数“SUPI号段组”、“GPSI号段组”、“外部组标识范围组”未由**ADD UDMNFRANGEINFO**命令定义，将导致UDM向NRF注册空号段，引起网络中AMF/SMF等设备错误的识别本UDM承载全部用户，将消息误送至本UDM，报错用户不存在。请严格按照参数配置原则进行配置，参数取值保持完全一致。

## 参数说明

| 参数标识              | 参数名称           | 参数说明                                                                                                                                                                                                                                               |
|:------------------|:---------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINFOID          | 网元信息标识         | 可选必选说明：必选参数 参数含义：用于指定网元的信息标识。 取值范围：长度不超过32位的字符串，字符串由数字、字母、“-”或“_”组成 默认值：无。 配置原则：该参数在全局唯一，不能重复。                                                                                                                                                     |
| NFTYPE            | 网元类型           | 可选必选说明：必选参数 参数含义：用于指定网元的类型。 取值范围： UDM(统一数据管理)AUSF(鉴权服务功能)5G-EIR(设备身份校验) 默认值：无。 配置原则：当“网元类型”参数取值设置为“5G-EIR(设备身份校验)”时，UDM向NRF发起注册的消息中携带的nfType信元取值为5G_EIR。                                                                                           |
| NFGRPID           | 网元组ID          | 可选必选说明：可选参数 参数含义：用于指定网元的组ID。 取值范围：长度不超过128位的字符串 默认值：无。 配置原则：无。                                                                                                                                                                                     |
| NFSUPIRANGEGRP    | SUPI号段组        | 可选必选说明：条件可选参数 参数含义：用于指定网元的SUPI号段。 取值范围：长度不超过32的字符串。 配置原则： 仅当“网元类型”参数取值为“UDM”或“AUSF”时该参数有效。该参数通过ADD UDMNFRANGEINFO命令指定，取值为当“RANGETYPE”参数取值为“SUPI（用户永久标识）”时对应的“组名称”参数取值。一个网元组配置总号段量不能超过40960，建议“SUPI号段组”和“GPSI号段组”配置到不同的网元组中。                        |
| NFGPSIRANGEGRP    | GPSI号段组        | 可选必选说明：条件可选参数 参数含义：用于指定网元的GPSI号段。 取值范围：长度不超过32的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：仅当“网元类型”参数取值为“UDM”时该参数有效。该参数通过ADD UDMNFRANGEINFO命令指定，当“RANGETYPE”参数取值为“GPSI（通用公共用户标识）”时对应的“组名称”参数取值。一个网元组配置总号段量不能超过40960，建议“SUPI号段组”和“GPSI号段组”配置到不同的网元组中。 |
| NFEXGRPIDRANGEGRP | 外部组标识范围组       | 可选必选说明：条件可选参数 参数含义：用于指定网元的外部组标识范围。 取值范围：长度不超过32的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：仅当“网元类型”参数取值为“UDM”或“5G-EIR”时该参数有效。该参数通过ADD UDMNFRANGEINFO命令指定，当“RANGETYPE”参数取值为“EXGROUP（外部组）”时对应的“组名称”参数取值。                                              |
| ROUTINGINDICATORS | 路由指示           | 可选必选说明：条件可选参数 参数含义：用于指定网元的SUCI（Subscription Concealed Identifier）对应的路由指示。 取值范围： 多值：长度不超过512位的字符串，字符串由数字、字母、“-”或“.”组成，多值之间用“,”分隔单值：长度不超过4位的字符串，字符串由数字、字母、“-”或“.”组成 默认值：无。 配置原则：仅当“网元类型”参数取值为“UDM”或“AUSF”时该参数有效。                                     |
| REGRANGE          | NRF注册时是否携带号段信息 | 可选必选说明：条件可选参数 参数含义：用于指定当通过ADD UDMNFRANGEINFO命令配置了网元的号段信息后，当网元NRF注册时，是否携带配置的该号段信息。 取值范围：TRUE(上报)，携带号段信息。 默认值：TRUE(上报)。 配置原则：仅当“网元类型”参数取值为“UDM”或“AUSF”时该参数有效。                                                                                        |
| RANGECHECK        | 号段配置检查         | 可选必选说明：条件可选参数 参数含义：用于标识是否进行号段配置检查。 取值范围： TRUEFALSE 默认值：TRUE。 配置原则： 当本命令中的“网元类型”参数为“UDM”或“AUSF”时该参数生效。从无该参数的版本升级，升级后有该软参，该参数取值为“NULL”。执行该命令并且不输入该参数时，系统会设置初始值TRUE。                                                                                  |

## 使用实例

在开局场景下配置本局数据时，增加UDM网元的特定信息，其中，“网元信息标识”为“udminfo\_01”，“网元类型”为“UDM”，“网元组ID”为“1”，“SUPI号段组”为“SUPI\_01”。

```
ADD UDMNFINFO: NFINFOID="udminfo_01", NFTYPE=UDM, NFGRPID="1", NFSUPIRANGEGRP="SUPI_01", REGRANGE=TRUE;
```
