# 激活DNS规则（ACT DNSRULE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

该命令用于激活DNS Rule，包括动态DNS Rule和静态DNS Rule。

#### 注意事项

该命令执行后60s生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                                                                  |
|:--------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------|
| RULETYPE      | 规则类型    | 可选必选说明：必选参数 参数含义：指定DNS规则类型。 数据来源：本端规划 取值范围：枚举类型。 DYNAMIC：查询动态DNS规则配置信息。STATIC：查询静态DNS规则配置信息。 默认值：无 配置原则：无                                             |
| APPNAME       | 应用名称    | 可选必选说明：必选参数 参数含义：指定应用名称，可以通过DSP APPLICATIONINFO查出所有的应用名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无                                              |
| APPINSTANCEID | APP实例号  | 可选必选说明：条件可选参数 前提条件：该参数在“RULETYPE”配置为“DYNAMIC”时为可选参数。 参数含义：指定app实例号，可以通过DSP APPLICATIONINFO查出所有的app实例号。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：无 |
| DNSRULEID     | DNS规则ID | 可选必选说明：可选参数 参数含义：指定DNS规则ID，其中静态DNS规则ID是通过ADD DNSRULE命令配置的，可以通过LST DNSRULE命令查询。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～95。 默认值：无 配置原则：无                         |

#### 使用实例

激活指定app名称，app实例和DNS规则ID的动态DNS Rule，app名称为"app1"、app实例为"1234"、DNS规则ID为"rule1"。命令执行后，该规则的state将置为ACTIVE：

```
ACT DNSRULE: RULETYPE=DYNAMIC, APPNAME="app1", APPINSTANCEID="1234", DNSRULEID="rule1";
```
