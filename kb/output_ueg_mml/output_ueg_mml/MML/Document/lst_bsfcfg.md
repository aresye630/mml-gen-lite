# 查询BSF配置(LST BSFCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询BSF配置信息。

- 如果需要查询全部的BSF配置信息，请不要输入任何参数。
- 如果需要查询特定的BSF配置信息，请依据参数说明输入查询的条件。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称          | 参数说明                                                                                                                                                                                                                                  |
|:--------------|:--------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ID            | ID            | 可选必选说明：可选参数 参数含义：用于指示系统按照配置标识查询BSF配置信息；若不输入，则表示所有ID的BSF配置信息。 取值范围：1。 默认值：无。 配置原则：无。                                                                                                                                                   |
| SWITCH        | Switch        | 可选必选说明：可选参数 参数含义：用于指示系统按照BSF开关状态查询BSF配置信息；若不输入，则表示所有BSF开关状态的BSF配置信息。 取值范围： Support(支持)Unsupport(不支持) 默认值：无。 配置原则：无。                                                                                                                   |
| SUPI          | Supi          | 可选必选说明：可选参数 参数含义：用于指示系统按照5G终端用户标识查询BSF配置信息；若不输入，则表示所有5G终端用户标识的BSF配置信息。 取值范围：Support(支持)Unsupport(不支持) 默认值：无。 配置原则：无。                                                                                                                  |
| GPSI          | Gpsi          | 可选必选说明：可选参数 参数含义：用于指示系统按照终端的移动台国际ISDN号码查询BSF配置信息；若不输入，则表示所有移动台国际ISDN号码的BSF配置信息。 取值范围：Support(支持)Unsupport(不支持) 默认值：无。 配置原则：无。                                                                                                         |
| IPV4ADDR      | Ipv4Addr      | 可选必选说明：可选参数 参数含义：用于指示系统按照终端Ipv4地址查询BSF配置信息；若不输入，则表示所有Ipv4地址的BSF配置信息。 取值范围：Support(支持)Unsupport(不支持) 默认值：无。 配置原则：无。                                                                                                                    |
| IPV6PREFIX    | Ipv6Prefix    | 可选必选说明：可选参数 参数含义：用于指示系统按照终端IPv6地址前缀查询BSF配置信息；若不输入，则表示所有IPv6地址前缀的BSF配置信息。 取值范围：Support(支持)Unsupport(不支持) 默认值：无。 配置原则：无。                                                                                                                |
| IPDOMAIN      | IpDomain      | 可选必选说明：可选参数 参数含义：用于指示系统按照终端IPv4地址域标识符查询BSF配置信息；若不输入，则表示所有IPv4地址域标识符的BSF配置信息。 取值范围：Support(支持)Unsupport(不支持) 默认值：无。 配置原则：无。                                                                                                            |
| MACADDR48     | MacAddr48     | 可选必选说明：可选参数 参数含义：用于指示系统按照终端Mac地址查询BSF配置信息；若不输入，则表示所有Mac地址的BSF配置信息。 取值范围：Support(支持)Unsupport(不支持) 默认值：无。 配置原则：无。                                                                                                                      |
| FQDN          | Fqdn          | 可选必选说明：可选参数 参数含义：用于指示系统按照PCF全量域名查询BSF配置信息；若不输入，则表示所有PCF全量域名的BSF配置信息。 取值范围：Support(支持)Unsupport(不支持) 默认值：无。 配置原则：无。                                                                                                                    |
| IPENDPOINT    | IpEndPoint    | 可选必选说明：可选参数 参数含义：用于指示系统按照PCF的IP端口查询BSF配置信息；若不输入，则表示所有IP端口的BSF配置信息。 取值范围：Support(支持)Unsupport(不支持) 默认值：无。 配置原则：无。                                                                                                                      |
| PCFDIAMHOST   | PcfDiamHost   | 可选必选说明：可选参数 参数含义：用于指示系统按照由ADD PCRF命令配置的“本地主机名”查询BSF配置信息；若不输入，则表示所有本地主机名的BSF配置信息。 取值范围：Support(支持) Unsupport(不支持) 默认值：无。 配置原则：无。                                                                                                       |
| PCFDIAMREALM  | PcfDiamRealm  | 可选必选说明：可选参数 参数含义：用于指示系统按照由ADD PCRF命令配置的“本地域名”查询BSF配置信息；若不输入，则表示所有本地域名的BSF配置信息。 取值范围：Support(支持)Unsupport(不支持) 默认值：无。 配置原则：无。                                                                                                          |
| FAILEDRELEASE | FailedRelease | 可选必选说明：可选参数 参数含义：当且仅当选择参数“Switch”选择“Support(支持)”时，此参数有效。用于表示UPCF发送到BSF的会话绑定失败场景下是否支持释放N7会话能力。 取值范围： Support(支持)Unsupport(不支持) 默认值：无。 配置原则：无。  说明： 只有在“FAILEDRELEASE”取值为“Support(支持)”，且N7会话携带“VoLTE-APN”或者“Emergency-APN”的场景下才会释放N7会话。 |

## 使用实例

查询BSF配置信息。

```
LST BSFCFG:;
```

```
%%LST BSFCFG:;%% 
RETCODE = 0  操作成功

操作结果如下
------------- 
           ID  =  1
       Switch  =  支持
         Supi  =  支持
         Gpsi  =  不支持
     Ipv4Addr  =  不支持
    Ipv6Prefix  =  支持
     IpDomain  =  不支持
    MacAddr48  =  不支持
         Fqdn  =  支持
   IpEndPoint  =  不支持
  PcfDiamHost  =  不支持
 PcfDiamRealm  =  不支持
FailedRelease  =  不支持

(结果个数 = 1)  

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET BSFCFG**命令的参数说明。
