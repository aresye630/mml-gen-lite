# 启动内部审计任务（STR INAT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于启动设备内审计或哈希审计。当系统内的数据不一致导致业务受影响时，可以执行本命令立即启动内部审计，及时修复不一致的数据，降低对业务的影响。

本命令的使用场景为：

- 设备内审计：用于PES和DUS之间路由校验、PES内部PID之间相同接口类型会话的审计、HASH审计。
- 哈希审计：用于PES服务内哈希表的审计。
- LICENSE审计：可以用于内部控制块资源（包括ALC、BLC、UPM、NGSRV）和License数据之间的审计，支持N7/Gx/Sd/Rx/Sy/N28/N5/N15/N23接口的License审计和FWA用户的License审计。

## 注意事项

无。

## 使用实例

启动设备内审计，“审计类型”为“OTMODULE(设备内审计)”，“快速审计”为“YES(是)”。

```
STR INAT: ATTYPE=OTMODULE, FLAG=YES;
```
