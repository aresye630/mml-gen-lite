# 查询区域性能统计对象和TAC段的绑定关系（LST PERFREGTAC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C**

该命令用来查询区域性能统计对象和TAC段的绑定关系。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                   |
|:-----------|:-------|:-------------------------------------------------------------------------------------------------------|
| REGNAME    | 区域名称   | 可选必选说明：可选参数  参数含义：该参数用于指定与TAC段绑定的区域名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。不区分大小写。  默认值：无  配置原则：无       |
| TACSEGNAME | TAC段名称 | 可选必选说明：可选参数  参数含义：该参数用于指定与区域绑定的TAC段名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。不支持空格，不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

当运营商需要查询一个区域性能统计对象关联的TAC号段时，执行如下命令：

```
LST PERFREGTAC: REGNAME="beijing", TACSEGNAME="changping";
%%LST PERFREGTAC: REGNAME="beijing", TACSEGNAME="changping";%%
RETCODE = 0  操作成功

结果如下
--------
 区域名称  =  beijing
TAC段名称  =  changping
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                |
|:--------|:---------------------|
| 区域名称    | 该参数用于指定与TAC段绑定的区域名称。 |
| TAC段名称  | 该参数用于指定与区域绑定的TAC段名称。 |
