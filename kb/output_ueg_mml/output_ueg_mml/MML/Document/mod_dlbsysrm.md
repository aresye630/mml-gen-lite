## 命令功能

**须知** 

- 此命令是高危命令，如果执行不当会影响业务处理，需联系华为技术支持确认后再执行。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令为配置类命令，用于修改DLB服务的系统运行模式，系统运行模式用于指示DLB服务是否可以提供业务服务。

由于DLB服务故障或者其他异常情况导致系统的业务处理异常，UPCF网元无法对外提供正常业务服务时，通过该命令修改DLB为去激活模式停止业务服务，停止业务服务后，业务切换到容灾UPCF网元处理；UPCF网元故障修复后，通过该命令修改DLB为激活模式恢复其业务服务。

## 注意事项

- 执行该命令和**MOD HLBSYSRM**命令，用于倒换前修改主用UPCF网元和容灾UPCF网元的运行模式。
- 执行此命令将主用UPCF退服时，需要信令对端（比如PCEF、AF等）支持将链路自动切换到容灾UPCF，否则需要通知各对端及时将链路切换到容灾UPCF。
- 该命令不允许进行批处理操作。

**说明** 

执行本命令，将参数“FS”修改为“DEACTIVE(去激活模式)”后，可以通过执行命令“DSP MSPROCESS”查询此时的服务状态为“Unknown（未知状态）”。如果服务状态长时间不恢复，会上报“ALM-100595 进程状态未就绪”告警。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                           |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------|
| FS     | 系统运行状态 | 可选必选说明：必选参数 参数含义：用于指定系统的运行模式。 取值范围：ACTIVE(激活模式)：表示可提供业务服务。 DEACTIVE(去激活模式)：即退服，表示不可提供业务服务。 默认值：无。 系统初始设置值：ACTIVE(激活模式) 配置原则：无。 |

## 使用实例

1. DLB服务故障，设置“系统运行状态”为“DEACTIVE(去激活模式)”，不提供业务服务。

   ```
   MOD DLBSYSRM: FS=DEACTIVE;
   ```
2. DLB服务故障修复后，设置“系统运行状态”为“ACTIVE(激活模式)”，恢复业务服务。

   ```
   MOD DLBSYSRM: FS=ACTIVE;
   ```

该命令执行正常，会返回命令执行成功的提示信息。
