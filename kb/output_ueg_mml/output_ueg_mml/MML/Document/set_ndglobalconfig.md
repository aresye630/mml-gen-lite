# 设置IPv6 ND系统配置（SET NDGLOBALCONFIG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于设置IPv6 ND全局配置。

#### 注意事项

- 该命令执行后立即生效。
- 可选参数至少下发一个。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| PREDETECTFLAG   | AUTODETECTFLAG   |   SYSHOPLIMIT |   RSACALCRATELMT |   SYSSTALETIME |
|:----------------|:-----------------|--------------:|-----------------:|---------------:|
| False           | True             |            64 |                0 |           1200 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称    | 参数说明                                                                                      |
|:---------------|:--------|:------------------------------------------------------------------------------------------|
| PREDETECTFLAG  | 使能预探测   | 可选必选说明：可选参数 参数含义：该参数用于指定是否使能提前探测ND表项功能。 数据来源：本端规划 取值范围：枚举类型。 TRUE：开启状态。FALSE：关闭状态。 默认值：无  |
| AUTODETECTFLAG | 使能自动探测  | 可选必选说明：可选参数 参数含义：该参数用于指定使能自动探测。 数据来源：本端规划 取值范围：枚举类型。 TRUE：开启状态。FALSE：关闭状态。 默认值：无          |
| SYSHOPLIMIT    | 跳限      | 可选必选说明：可选参数 参数含义：该参数用于指定跳限。 数据来源：本端规划 取值范围：整数类型，取值范围为1～255。 默认值：无                         |
| RSACALCRATELMT | 速率限制    | 可选必选说明：可选参数 参数含义：该参数用于指定速率限制。 数据来源：本端规划 取值范围：整数类型，取值范围为0～100。0表示去使能该配置。 默认值：无             |
| SYSSTALETIME   | 失效时间（s） | 可选必选说明：可选参数 参数含义：该参数用来配置邻居表项在STALE状态的老化时间。 数据来源：本端规划 取值范围：整数类型，取值范围为60～172800，单位是秒。 默认值：无 |

#### 使用实例

设置IPv6 ND全局配置：使能提前探测ND表项功能：

```
SET NDGLOBALCONFIG:PREDETECTFLAG=TRUE;
```
