# 修改SCTP本地实体(MOD SCTPLE)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限

- 使用实例

#### 命令功能

**适用网元：MME、AMF**

此命令用于修改SCTP本端实体的配置参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令可修改该SCTP本端实体的用途、权重、SCTP参数索引、是否开启交叉路径和描述。

#### 本地用户权限

manage-ug; system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                                                                                                    |
|:------------|:-----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SCTPLEIDX   | SCTP本端实体索引 | 可选必选说明：必选参数 参数含义：该参数用于指定SCTP本端实体索引用于唯一标识一个SCTP本端实体。 数据来源：本端规划 取值范围：整数类型，取值范围为0~1023。 默认值：无                                                                                              |
| CROSSIPFLG  | 交叉路径是否可用   | 可选必选说明：可选参数 参数含义：该参数用于指定SCTP本端实体的交叉路径是否可用选择为否时表示交叉路径不开启，选择为是时表示开启交叉路径。 数据来源：全网规划 取值范围：枚举类型。 E_SCTP_CROSS_NO：交叉路径不可用 E_SCTP_CROSS_YES：交叉路径可用 默认值：无                                       |
| SCTPPARAIDX | SCTP协议参数索引 | 可选必选说明：可选参数 参数含义：该参数用于指定SCTP本端实体的参数配置索引，用于根据该索引获取到SCTP协议的参数配置信息该参数通过ADD CPSCTPPARA命令配置。 数据来源：全网规划 取值范围：整数类型，取值范围为0~65534。 默认值：无                                                         |
| USAGE       | 用途         | 可选必选说明：可选参数 参数含义：该参数用于指定SCTP本端实体的使用者信息，协议中定义了不同偶联可指定给不同类型的用户使用，如可指定使用者为UE、NON-UE或BOTH。 数据来源：全网规划 取值范围：枚举类型。 E_SCTP_USAGE_UE：用于指定SCTP本端实体的使用者 E_SCTP_USAGE_NONUE E_SCTP_USAGE_BOTH 默认值：无 |
| WEIGHT      | 权重         | 可选必选说明：可选参数 参数含义：该参数用于指定SCTP本端实体的权重如果该值设置为0，则标识NGAP初始化消息不允许使用该SCTP本端实体，如果该值多个SCTP本端实体设置一样，则标识在多个SCTP本端实体间负载均衡。 数据来源：全网规划 取值范围：整数类型，取值范围为0~255。 默认值：无  说明： 该参数对SFGAP不生效。                 |
| DESC        | 描述         | 可选必选说明：可选参数 参数含义：该参数用于指定SCTP本端实体的描述信息。 数据来源： 取值范围：字符串类型，输入长度范围为0~31。 默认值：无                                                                                                              |

#### 使用实例

将链路本地实体索引为1的SCTP链路的用户类型改为UE:

```
%%MOD SCTPLE: SCTPLEIDX=1, USAGE=E_SCTP_USAGE_UE;%% 
RETCODE = 0  操作成功  

---    END
```
