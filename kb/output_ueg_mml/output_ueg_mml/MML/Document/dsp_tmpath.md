#### 命令功能

**适用NF：MME**

该命令用于查询TM路径状态，如果输入路径在系统中已经存在则输出这条路径的状态。

#### 注意事项

- 该命令执行后立即生效。
- 该命令可用于SPP进程/UPP进程。
- 当“进程类型”未输入时，默认查询UPP进程上的路径状态信息。
- 当本命令QRYTP参数取值DDB（数据库）时，SET TMAPINTF命令ECHOSIG参数开关必须是ON，否则查询不出结果。

#### 本地用户权限

manage-ug;system-ug;monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                        |
|:-------|:-------|:--------------------------------------------------------------------------------------------|
| RUNAME | RU名称   | 可选必选说明：必须参数 参数含义：该参数用于指定资源单元名称。该参数可以通过DSP RU命令查询。 取值范围：1~63位字符串 默认值：无                       |
| PROCTP | 进程类型   | 可选必选说明：可选参数 参数含义：该参数用于指定进程的进程类型。 取值范围：“SPP”“UPP” 默认值：无                                      |
| PROCNO | 进程号    | 可选必选说明：可选参数 参数含义：该参数用于指定进程的序号。该参数可以通过DSP PROCESSUSN命令查询，选取结果中的“相同进程类型的索引”列。 取值范围：0~20 默认值：0 |
| QRYTP  | 查询类型   | 可选必选说明：可选参数 参数含义：该参数用于指定查询类型。 取值范围：“MEMORY（内存）”“DDB（数据库）” 默认值：无                             |

#### 使用实例

查询资源单元为USN\_SP\_RU\_0064上的TM PATH信息：

DSP TMPATH: RUNAME="USN\_SP\_RU\_0064", PROCNO=0, QRYTP=MEMORY;

```
%%DSP TMPATH: RUNAME="USN_SP_RU_0064", PROCNO=0, QRYTP=MEMORY;%%
RETCODE = 0  操作成功

操作结果如下:
-------------------------
本端IP地址       对端IP地址      TM路径接口类型      TM路径状态     对端Recovery值      端口号 

10.10.10.1       10.10.10.1      Tm1 path            正常            0                 29527
10.10.10.1       10.10.10.1      Tm1 path            正常            NULL              29527
(结果数目 = 2)
---    END
```

#### 输出结果说明

| 输出项名称       | 输出项解释                                                                             |
|:------------|:----------------------------------------------------------------------------------|
| 本端IP地址      | 无。                                                                                |
| 对端IP地址      | 无。                                                                                |
| TM路径接口类型    | 描述TM路径接口类型。 取值说明：Tm1 path                                                         |
| TM路径状态      | 描述该路径的状态。 取值说明：“正常”“故障”                                                           |
| 对端Recovery值 | 描述该路径对应的对端网元的Recovery值。                                                           |
| 端口号         | 描述Tm接口的侦听端口号。 数据来源：全网规划 取值范围：20001~65534 系统初始设置值：29527 配置原则：该参数需要和对端协商，避免两端设置不一致。 |
