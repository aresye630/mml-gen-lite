# 删除数据同步服务器公钥（RMV RSFTPPUBLICKEY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UDM**

该命令用于删除数据同步服务器公钥。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                        |
|:--------|:-------|:----------------------------------------------------------------------------|
| KEYNAME | 密钥名称   | 可选必选说明：必选参数 参数含义：密钥名称。 数据来源：本端规划 取值范围：由数字、字母和下划线组成的不超过63位的字符串。 默认值：无 配置原则：无 |

#### 使用实例

删除名称为rsa1的对端公钥：

```
RMV RSFTPPUBLICKEY:KEYNAME="rsa1";
```
