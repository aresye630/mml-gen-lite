# 设置接收STA响应超时次数的告警阈值（SET BMSCALMTHD）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置接收STA响应超时次数的告警阈值。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

|   ALARMTHRES |   RESALARMTHRES |
|-------------:|----------------:|
|            0 |               0 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                                    |
|:--------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ALARMTHRES    | 告警阈值   | 可选必选说明：可选参数  参数含义：该参数用于控制等待BM-SC回复STA消息超时次数连续累加到多少时触发BM-SC无响应的告警。  数据来源：本端规划  取值范围：整数类型，取值范围是0~63000。  默认值：0。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST BMSCALMTHD查询当前参数配置值。  配置原则：  0为无效值，即BM-SC无响应的应用层告警机制不生效。 |
| RESALARMTHRES | 恢复告警阈值 | 可选必选说明：可选参数  参数含义：该参数用于控制收到STA消息数累加到多少次恢复BM-SC无响应的告警。  数据来源：本端规划  取值范围：整数类型，取值范围是0~63000。  默认值：0。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST BMSCALMTHD查询当前参数配置值。  配置原则：  0表示收到一条STA消息就立即恢复BM-SC无响应的告警。           |

## 使用实例

用户要使BM-SC无响应的应用层告警机制生效且累积超时10次后告警，并且在收到一条STA消息后就立即恢复。

```
SET BMSCALMTHD: ALARMTHRES=10, RESALARMTHRES=0;
```
