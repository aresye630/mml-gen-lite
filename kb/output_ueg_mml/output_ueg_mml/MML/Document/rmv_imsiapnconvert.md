# 删除APNNI转换配置(RMV IMSIAPNCONVERT)

#### 命令功能

**适用网元：SGSN、MME**

该命令用于删除APN（Access Point Name）转换配置。如果用户激活请求消息中携带的APN和本配置命令“OLDAPN（请求APNNI）”匹配，则用户激活请求消息中携带的APN将被替换为“NEWAPN（转换APNNI）”后再进行签约数据匹配。

#### 注意事项

- 该命令执行后立即生效。
- 删除后影响签约数据匹配纠正功能。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                                                                      |
|:---------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围    | 可选必选说明：必选参数 参数含义：该参数用于指定签约用户的范围。 取值范围：“ALL_USER(所有用户)”“IMSI_PREFIX(指定IMSI前缀)”“IMSI_RANGE(指定IMSI范围)” 默认值：无                                                                                                                 |
| IMSIPRE  | IMSI前缀  | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI前缀。 前提条件：该参数在“用户范围”参数设置为“IMSI_PREFIX(指定IMSI前缀)”时，才需要配置。 取值范围：1~15位数字 默认值：无  说明： 根据IMSI、“请求APNNI”映射唯一的“转换APNNI”。                                                                             |
| IMSI     | IMSI    | 可选必选说明：条件必选参数 参数含义：该参数用于指定IMSI，对该IMSI所在号段进行删除。 前提条件：该参数在“用户范围”参数设置为“IMSI_RANGE(指定IMSI范围)”时，才需要配置。 取值范围：1~15位数字 默认值：无  说明： 根据IMSI、“请求APNNI”映射唯一的“转换APNNI”。                                                                 |
| OLDAPN   | 请求APNNI | 可选必选说明：必选参数 参数含义：该参数用于指定匹配的激活请求消息中携带的APN NI。 取值范围：1~62 默认值：无  说明： “请求APNNI”由一个或多个LABEL构成，各LABEL间用“.”间隔。每个LABEL的构成字符只能是字母A~Z或a~z、数字0~9和中划线“-”。例如“HUAWEI.COM”。APN网络标识地址不能以“rac”、“lac”、“sgsn”或“rnc”开头，不能以“.gprs”结尾，不能取值为“*”。 |

#### 使用实例

删除“用户范围”为“指定IMSI前缀”，“IMSI前缀”为“123007551111111”，且“请求APNNI”为“WCDMA”的APNNI转换记录：

RMV IMSIAPNCONVERT: SUBRANGE=IMSI\_PREFIX, IMSIPRE="123007551111111", OLDAPN="WCDMA";
