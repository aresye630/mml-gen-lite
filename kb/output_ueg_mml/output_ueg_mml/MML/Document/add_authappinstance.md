# 添加APP实例授权（ADD AUTHAPPINSTANCE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

该命令用于添加APP实例ID和APPID的绑定关系，绑定之后，则该APP实例可访问为该APPID所添加的授权服务列表中的服务。当需要限制某些服务资源仅允许这些服务资源所属的APP实例修改时，可通过此命令配置APPID和APPINSTANCEID的绑定关系达到此目的，同时该APP实例申请token时需要同时携带APPID和APP实例ID。例如需要限制为指定APP实例所下发的分流规则仅允许该APP实例修改该分流规则的激活状态时可使用本命令。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为2000。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                                                                     |
|:--------------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------|
| APPINSTANCEID | APP实例ID | 可选必选说明：必选参数 参数含义：该参数用于指定APP实例标识。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“_”组成。 默认值：无 配置原则：无                                                      |
| APPID         | APP标识   | 可选必选说明：必选参数 参数含义：该参数用于指定APP实例所属的APP标识。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“_”组成。 默认值：无 配置原则： 该参数使用ADD APPAUTHINFO命令配置生成。根据APP实例所属的APPID进行配置。 |

#### 使用实例

添加APP实例授权信息，APP实例ID为"appInstance1"，APP实例所属的APP标识为"app1"：

```
ADD AUTHAPPINSTANCE: APPINSTANCEID="appInstance1", APPID="app1";
```
