# 查询异网漫游PDU会话重建策略（LST INTPDUPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用户查询异网漫游用户的PDU会话重建策略。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                            |
|:---------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRANGE | 用户范围   | 可选必选说明：可选参数  参数含义：该参数用于指定PDU会话重建策略生效的用户范围。  数据来源：全网规划 取值范围： “INTERNAT_ROAM_USER（所有异网漫游用户）”：所有异网漫游用户。“IMSI_PREFIX（IMSI前缀）”：指定IMSI前缀的异网漫游用户。“SPECIFIC_IMSI（指定IMSI）”：指定IMSI的异网漫游用户。  默认值：无  配置原则：无 |
| IMSIPRE  | IMSI前缀 | 可选必选说明：该参数在"SUBRANGE"配置为"IMSI_PREFIX"时为条件可选参数。  参数含义：该参数用于指定PDU会话重建策略的用户IMSI前缀。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是5~14。  默认值：无  配置原则：无                                                              |
| IMSI     | IMSI   | 可选必选说明：该参数在"SUBRANGE"配置为"SPECIFIC_IMSI"时为条件可选参数。  参数含义：该参数用于指定PDU会话重建策略的用户IMSI（完整IMSI）。  数据来源：全网规划  取值范围：字符串类型，输入长度是15。  默认值：无  配置原则：无                                                          |

## 使用实例

- 查询系统中生效范围为“所有异网漫游用户”的PDU会话重建策略，执行如下命令：

  ```
  %%LST INTPDUPLCY:;%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
            用户范围  =  所有异网漫游用户
            IMSI前缀  =  NULL
                IMSI  =  NULL
    语音会话重建策略  =  进入空闲态后重建
  非语音会话重建策略  =  进入空闲态后重建
  (结果个数 = 1)

  ---    END
  ```
- 查询系统中当前配置的PDU回哈重建策略，执行如下命令：

  ```
  %%LST INTPDUPLCY:;%%
  RETCODE = 0  操作成功

  结果如下
  ------------------------
            用户范围  =  所有异网漫游用户
            IMSI前缀  =  NULL
                IMSI  =  NULL
    语音会话重建策略  =  进入空闲态后重建
  非语音会话重建策略  =  进入空闲态后重建
  (结果个数 = 1)

  ---    END
  ```

## 输出结果说明

| 输出项名称     | 输出项解释                                                                                                                               |
|:----------|:------------------------------------------------------------------------------------------------------------------------------------|
| 用户范围      | 该参数用于指定PDU会话重建策略生效的用户范围。                                                                                                            |
| IMSI前缀    | 该参数用于指定PDU会话重建策略的用户IMSI前缀。                                                                                                          |
| IMSI      | 该参数用于指定PDU会话重建策略的用户IMSI（完整IMSI）。                                                                                                    |
| 语音会话重建策略  | 该参数用于指定异网漫游用户发生Inter类注册和切换流程时，语音会话的重建策略。 优先使用ADD NGVOICEDEPLOY中配置的VOICEDNN来识别语音会话，如果ADD NGVOICEDEPLOY未配置，则系统默认以“IMS”作为语音DNN来识别语音会话。 |
| 非语音会话重建策略 | 该参数用于指定异网漫游用户发生Inter类注册和切换流程时，非语音会话的重建策略。                                                                                           |
