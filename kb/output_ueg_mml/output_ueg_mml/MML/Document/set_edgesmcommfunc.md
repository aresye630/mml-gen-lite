# 设置通用会话拓展功能（SET EDGESMCOMMFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、PGW-C**

此命令用于设置通用会话管理扩展功能。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| RDSSTATICIPSW   | SECSELECTUDMSW   | UDMSTATICIPSW   | UDMIPTYPE    | LOCVNSUBSW   |
|:----------------|:-----------------|:----------------|:-------------|:-------------|
| DISABLE         | DISABLE          | DISABLE         | SINGLE_STACK | DISABLE      |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称           | 参数说明                                                                                                                                                                                                                                                                                    |
|:---------------|:---------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RDSSTATICIPSW  | Radius静态IP功能开关 | 可选必选说明：可选参数  参数含义：该参数用于设置是否开启Radius静态IP功能。此开关开启后，才能使用ADD RDSSTATICIPPARA配置的静态IP。  数据来源：全网规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST EDGESMCOMMFUNC查询当前参数配置值。  配置原则：无                                                                                      |
| SECSELECTUDMSW | 二次重选UDM开关      | 可选必选说明：可选参数  参数含义：该参数用于设置SMF是否开启二次重选UDM功能。  数据来源：全网规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST EDGESMCOMMFUNC查询当前参数配置值。  配置原则：无                                                                                                                            |
| UDMSTATICIPSW  | UDM静态IP功能开关    | 可选必选说明：可选参数  参数含义：该参数用于设置是否开启UDM静态IP功能。此开关开启后，才能使用ADD RDSSTATICIPPARA配置的静态IP。  数据来源：全网规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST EDGESMCOMMFUNC查询当前参数配置值。  配置原则：无                                                                                         |
| UDMIPTYPE      | UDM静态IP类型      | 可选必选说明：该参数在"UDMSTATICIPSW"配置为"ENABLE"时为条件可选参数。  参数含义：该参数用于设置UDM静态IP类型。用于指示在UDM Bypass场景本地配置静态IP时，如果本地配置静态IP只有一个IPV4或者IPV6而会话请求地址类型是IPV4V6双栈时，是按照单栈处理还是按照双栈处理。  数据来源：全网规划 取值范围： SINGLE_STACK（单栈）DUAL_STACK（双栈）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST EDGESMCOMMFUNC查询当前参数配置值。  配置原则：无 |
| LOCVNSUBSW     | 5G LAN本地签约功能开关 | 可选必选说明：可选参数  参数含义：该参数用于控制开启和关闭5G LAN本地签约功能。该参数仅对层二5G LAN生效。配置为ENABLE时，优先使用本地签约的5G LAN组ID激活层二5G LAN会话。  数据来源：全网规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST EDGESMCOMMFUNC查询当前参数配置值。  配置原则：无                                                                 |

## 使用实例

设置关闭Radius静态IP功能，执行如下命令：

```
SET EDGESMCOMMFUNC: RDSSTATICIPSW=DISABLE;
```
