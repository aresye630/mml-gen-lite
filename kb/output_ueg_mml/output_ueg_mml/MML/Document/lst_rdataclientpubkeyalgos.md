# 查询数据同步客户端支持的公钥算法（LST RDATACLIENTPUBKEYALGOS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询数据同步客户端支持的公钥算法。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询数据同步客户端支持的公钥算法：

```
LST RDATACLIENTPUBKEYALGOS:;
```

```
RETCODE = 0 操作成功

数据同步客户端支持的公钥算法
------------------------------------------------
ssh-ed25519 公钥算法 = TRUE
ssh-ed25519-cert-v01@openssh.com 公钥算法 = TRUE
rsa-sha2-256 公钥算法 = TRUE
rsa-sha2-512 公钥算法 = TRUE
(结果个数 = 1)

--- END
```

#### 输出结果说明

参见SET RDATACLIENTPUBKEYALGOS的参数说明。
