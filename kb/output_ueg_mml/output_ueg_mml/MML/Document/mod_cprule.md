# 修改规则（MOD CPRULE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于修改规则，其中包含策略信息以及优先级。只有已经添加成功的规则才能够修改。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
|:---------------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RULENAME       | 规则名称        | 可选必选说明：必选参数 参数含义：该参数用于设置规则名称。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| POLICYTYPE     | 策略类型        | 可选必选说明：必选参数 参数含义：该参数用于设置策略类型。 数据来源：对端协商 取值范围：枚举类型。 PCC：计费与策略控制，代表该规则可以配置PCC策略，用于实现计费和策略控制功能。BWM：带宽管理，代表该规则可以配置带宽管理分类策略，其分类结果可以用于带宽管理的策略匹配功能。HEADEN：头增强，代表该规则可以配置头增强策略，可以基于配置的头增强策略向HTTP/RTSP请求报文头域中插入字段。WEBPROXY：Web Proxy，代表该规则可以配置WebProxy的IPFarm对象名称，用于设置WebProxy选择的服务器地址池。IPREDIR：IP重定向，代表该规则可以配置IP重定向的目标IP地址，支持IPv4和IPv6两种类型的IP地址。SMARTREDIRECT：Captive Portal智能重定向，代表该规则可以配置Captive Portal的IPFarm对象名称，用于设置Captive Portal选择的服务器地址池。REMARK_FPI：Remark或者FPI，代表该规则可以配置IP报文的DSCP重标记值或FPI策略。SRV_TRIGGER：Service Trigger Radius，代表该规则可以配置业务触发Radius消息交互功能标识，并配置Radius交互过程中报文处理方式。TRAFFICCLASS：Traffic Classifier，代表该规则可以配置Service Chain对象名称，用于实现业务链功能。LBO：Local Break Out，代表该规则可以用于本地业务分流。FIREWALL：防火墙，代表该规则可以配置防火墙策略。ULCL：ULCL，代表该规则可以配置ULCL策略。ADC：代表该规则用于应用检测与控制功能。QOS：代表该规则可以配置QoS策略，可以基于配置的QoS策略进行业务级QoS处理。FUP：公平使用策略，代表该规则可以配置公平使用策略。NON_SPECIFIC_TYPE：不指定具体的类型。 默认值：无 配置原则：根据部署的业务策略选择相应的策略类型。 |
| PRIORITY       | 全局优先级       | 可选必选说明：可选参数 参数含义：该参数用于设置全局优先级，仅对PCC用户生效。 数据来源：对端协商 取值范围：整数类型，取值范围为1～4294967295。值越小优先级越高。 默认值：无 配置原则：设置的PRIORITY仅对PCC用户生效。为了避免后续规划的规则与已配置规则的优先级冲突，建议规划优先级时按照10的倍数来定义，以便于后续插入任意优先级的新规则。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| POLICYNAME     | 策略名称        | 可选必选说明：条件可选参数 前提条件：该参数在“POLICYTYPE”配置为“PCC”、“ULCL” 或 “QOS”时为可选参数。 参数含义：该参数用于设置策略名称。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则： 设置的POLICYNAME必须是本策略类型所属的系统已经存在的策略名称。根据策略类型的取值不同，所对应的策略定义对象不同，其代表的对象名也做相应的调整。 PCC：计费与策略控制，代表该策略名称为PCC策略组的名称。ULCL: 过滤器规则，代表策略名称为ULCL过滤器规则的名称。QOS：QOS动作策略，代表该策略名称为QOS业务的名称，使用ADD CPQOSPROP配置命令生成。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| FLOWFILTERNAME | 流过滤器名称      | 可选必选说明：条件可选参数 前提条件：该参数在“POLICYTYPE”配置为“ULCL”时为可选参数。 参数含义：该参数用于设置rule的流过滤器名称。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| RULERANGE      | 规则生效范围      | 可选必选说明：条件可选参数 前提条件：该参数在“POLICYTYPE”配置为“PCC” 或 “QOS”时为可选参数。 参数含义：该参数用于设置规则生效范围。 数据来源：全网规划 取值范围：枚举类型。 ALL：表示对中心和边缘UPF（主锚点UPF和辅锚点UPF）均生效。CENTRAL：表示对中心UPF（主锚点）生效。LOCAL：表示对边缘UPF（辅锚点）生效。 默认值：无 配置原则：对于已添加的规则，修改生效范围时，需检查Rule的生效范围与其绑定的UserProfile生效范围是否冲突；只对新用户生效业务生效。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| NWDAFEVENTS    | NWDAF数据分析事件 | 可选必选说明：可选参数 参数含义：该参数用于指定规则对应的分析事件类型。 数据来源：全网规划 取值范围：枚举类型。 NULL：表示该规则非NWDAF智能规则。QOS_ANALYSIS：表示该规则对应的NWDAF事件分析类型为QOS分析。QOS_EXP_ANALYSIS：表示该规则对应的NWDAF事件分析类型为体验感知信息分析。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| IPERULEDELYSW  | 智能规则传递开关    | 可选必选说明：条件可选参数 前提条件：该参数在“NWDAFEVENTS”配置为“QOS_ANALYSIS” 或 “QOS_EXP_ANALYSIS”时为可选参数。 参数含义：该参数用于设置是否传递智能规则。 数据来源：全网规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：当希望该规则仅用于智能双N7会话特性时，将该开关设置为DISABLE；否则，将该开关设置为ENABLE。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |

#### 使用实例

假如运营商需要定义一个规则，要求规则类型为PCC，基于名称为TESTPCCPOLICYGRPNM的PCC策略组进行计费和策略控制，优先级为50。修改优先级为60：

```
MOD CPRULE:RULENAME="TESTRULE",POLICYTYPE=PCC,PRIORITY=60,POLICYNAME="TESTPCCPOLICYGRPNM";
```
