# 删除目标NF发现和选择的位置匹配信息（RMV NFLOC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

执行该命令，如果参数设置不合理，可能影响AMF优选本DC SMF。

**适用NF：AMF、SMF**

该命令用于删除为目标NF的发现和选择配置的位置匹配相关的信息。

位置类型为LOCALITY时，执行该命令基于目标网元位置的精确选择功能将失效。

位置类型为Preferred-Locality时，执行该命令基于目标网元位置的优先选择功能将失效。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|:----------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFTYPE    | NF类型   | 可选必选说明：必选参数  参数含义：该参数用于表示服务发现的目标NF的请求者的NF类型。  数据来源：全网规划 取值范围： “NfAMF（NfAMF）”：AMF“NfSMF（NfSMF）”：SMF  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| TGTNFTYPE | 目标NF类型 | 可选必选说明：可选参数  参数含义：该参数用于表示目标NF的类型。  数据来源：全网规划 取值范围： “NF_ALL（所有NF）”：所有NF“UDM（UDM）”：UDM“AMF（AMF）”：AMF“SMF（SMF）”：SMF“AUSF（AUSF）”：AUSF“PCF（PCF）”：PCF“SMSF（SMSF）”：SMSF“NSSF（NSSF）”：NSSF“LMF（LMF）”：LMF“GMLC（GMLC）”：GMLC“FIFTHG_EIR（5G_EIR）”：5G_EIR  默认值：无  配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| LOCTYPE   | 位置类型   | 可选必选说明：可选参数  参数含义：该参数用于表示目标NF发现和选择流程中用作匹配条件的位置类型。  数据来源：全网规划 取值范围： “LOCALITY（位置）”：将位置信息作为仅次于目标NF优先级的策略选择目标NF。“PREFERRED_LOCALITY（优选位置）”：将位置信息作为最高优先级选择目标NF。  默认值：无  配置原则：  在基于位置的NF发现和选择过程中，如果运营商期望以目标NF的位置信息作为第一优选条件，则使用PREFERRED_LOCALITY类型；如果期望以目标NF的优先级作为第一优选条件，位置信息次之，则使用LOCALITY类型。如果运营商期望用点分格式，应使用LOCALITY类型。LOCALITY的点分格式为“大区标识.数据中心标识.资源池标识”。  LOCALITY和PREFERRED_LOCALITY两种目标NF的位置匹配条件都依赖于目标NF配置了位置信息，并注册给了NRF。两者的区别在于：  执行位置匹配的地点不同。LOCALITY是在请求者NF从NRF获取目标NF列表后执行的，而PREFERRED_LOCALITY是在NRF上执行的。说明：基于PREFERRED_LOCALITY选择时，NRF可能仅返回与优选位置匹配的目标NF列表，也可能返回非优选位置匹配的目标NF。华为的NRF支持开关控制（在NRF上通过SET NRFFUNCSW命令中“DISCLOCPREFERSW”和“DISCLOCMATEHSW”控制）。为了防止NRF返回非PREFERRED_LOCALITY匹配的目标NF列表，UNC支持从NRF获取目标NF列表后，本地再按照优选区域匹配目标NF列表。  执行位置匹配的优先级不同。LOCALITY是首先使用优先级筛选后再根据位置进行匹配；而PREFERRED_LOCALITY是首先根据优选位置匹配，随后再针对匹配优选位置的目标NF根据优先级、权重进行选择。 执行位置匹配的算法不同。LOCALITY支持点分格式的字符串，支持指定长度的匹配；而PREFERRED_LOCALITY目标仅支持全字段匹配。 执行位置匹配的依赖条件不同。LOCALITY需要在UNC上打开匹配开关（详见SET NFDISCPLCY的LOCSELECT参数）；而PREFERRED_LOCALITY与NRF上的优选位置功能有关。 |

## 使用实例

当UE新建PDU Session时，不需要优选指定区域内的SMF，执行如下命令：

```
RMV NFLOC: NFTYPE=NfAMF, TGTNFTYPE=SMF;
```
