# 添加网元信息（ADD NFINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于为PCF网元增加其特定信息，包含3GPP TS 29.510协议中服务注册时需要使用的PcfInfo信息，通过**ADD NFSRV**关联索引后，向NRF注册。

该命令的参数索引关系如图1所示。

**图1** 命令参数的索引关系图

## 注意事项

如果“NFDNNGRP”和“DNNLIST”都有效，则优先使用“NFDNNGRP”。如果需要使用“DNNLIST”，则需要通过**MOD NFINFO**命令将“NFDNNGRP”配置为“NULL”。

## 参数说明

| 参数标识           | 参数名称          | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|:---------------|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINFOID       | 网元信息标识        | 可选必选说明：必选参数 参数含义：用于指定本端网元的信息标识。 取值范围：长度不超过32的字符串，字符串由数字、字母、“-”或“_”组成 默认值：无。 配置原则：该参数在全局唯一，不能重复，且配置时不能取值为“NULL”，否则无法被正常索引。                                                                                                                                                                                                                                                                                                                      |
| NFTYPE         | 网元类型          | 可选必选说明：必选参数 参数含义：用于指定本端网元的类型。 取值范围：PCF(策略控制功能) 默认值：PCF(策略控制功能) 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                         |
| NFGRPID        | 网元组ID         | 可选必选说明：可选参数 参数含义：用于指定本端网元的组ID。 取值范围：长度不超过128的字符串 默认值：无。 配置原则： 网元组ID需要提前规划，与NRF协商一致，通过此参数与NRF创建号段映射关系。主备局号段相同，应配置一致。该参数与“SUPI号段组”或“GPSI号段组”一般不同时配置，若同时配置了，则由NF Client判断两者优先级来决定号段路由方式。                                                                                                                                                                                                                                                          |
| NFSUPIRANGEGRP | SUPI号段组       | 可选必选说明：可选参数 参数含义：用于指定本端网元的SUPI号段。 取值范围：长度不超过32的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：该参数通过ADD NFRANGEINFO命令指定，取值为当“RANGETYPE”参数取值为“SUPI（用户永久标识）”时对应的“组名称”参数取值。  说明： 在PCF和对端NRF均未配置SUPI号段组的场景下，将会导致所有消息访问本设备，可能造成流量过载。如果PCF未配置此参数，需确认对端NRF是否已配置SUPI号段组。如果PCF和对端NRF均未配置，需明确不配置的使用场景是否为用户预期。                                                                                                                                                  |
| NFGPSIRANGEGRP | GPSI号段组       | 可选必选说明：可选参数 参数含义：用于指定本端网元的GPSI号段。 取值范围：长度不超过32的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：该参数通过ADD NFRANGEINFO命令指定，当“RANGETYPE”参数取值为“GPSI（通用公共用户标识）”时对应的“组名称”参数取值。  说明： 在PCF和对端NRF均未配置GPSI号段组的场景下，将会导致所有消息访问本设备，可能造成流量过载。如果PCF未配置此参数，需确认对端NRF是否已配置GPSI号段组。如果PCF和对端NRF均未配置，需明确不配置的使用场景是否为用户预期。                                                                                                                                                   |
| DNNLIST        | DNN列表         | 可选必选说明：可选参数 参数含义：用于指定本端网元的DNN列表。 取值范围：长度不超过4096的字符串，字符串由数字、字母、“-”，“.”或“,”组成，开头和结尾不能含有“-”、“.”或“,”，多值之间用“,”分隔，但不能连续使用两个“,”。 默认值：无。 配置原则： 该参数与“NFDNNGRP”都是指定本端网元的DNN列表，两者作用等效，即配置“DNNLIST”的方式添加DNN列表，与通过配置“NFDNNGRP”的方式添加DNN组作用一样。但是两者的配置差异点如下： 通过配置“DNNLIST”添加DNN列表的方式无法对本端网元支持的所有DNN进行分组管理，但是通过配置“NFDNNGRP”的方式能有效对本端网元支持的所有DNN进行分组管理。如果“NFDNNGRP”和“DNNLIST”均有配置，则优先使用“NFDNNGRP”。如果需要使用“DNNLIST”，则需要通过MOD NFINFO命令将“NFDNNGRP”配置为“NULL”。          |
| RXDIAMHOST     | Rx Diameter主机 | 可选必选说明：可选参数 参数含义：用于指定本端网元的Rx Diameter主机。 取值范围：长度不超过128的字符串，并且满足如下格式。 以字母（A～Z或a～z）和数字的组合开头。其次使用“-”连接字母（A～Z或a～z）和数字的组合。末尾使用“.”连接2个以上的小写字母。 例如：a01-b02.ccc 默认值：无。 配置原则：若PCF支持Rx接口且SMF内置BSF时，需要配置此参数，表示EPS Fallback场景下，SMF内置BSF需要获取的PCF的Diameter主机名。                                                                                                                                                                                               |
| RXDIAMREALM    | Rx Diameter域  | 可选必选说明：可选参数 参数含义：用于指定本端网元的Rx Diameter域。 取值范围：长度不超过128的字符串，并且满足如下格式。 以字母（A～Z或a～z）和数字的组合开头。中间使用“-”连接字母（A～Z或a～z）和数字的组合。其次使用“.”连接2个以上的小写字母。 例如：a01-b02.ccc 默认值：无。 配置原则：若PCF支持Rx接口且SMF内置BSF时，需要配置此参数，表示EPS Fallback场景下，SMF内置BSF需要获取的PCF的Diameter域名。                                                                                                                                                                                                 |
| NFDNNGRP       | DNN组          | 可选必选说明：可选参数 参数含义：用于指定本端网元的DNN组。 取值范围：长度不超过32的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则： 该参数通过ADD NFDNNGRP命令指定，对应为“组名称”参数取值。该参数不能配置为“NULL”，否则不生效。 该参数与“DNNLIST”都是指定本端网元的DNN列表，两者作用等效，即配置“DNNLIST”的方式添加DNN列表，与通过配置“NFDNNGRP”的方式添加DNN组作用一样。但是两者的配置差异点如下： 通过配置“DNNLIST”添加DNN列表的方式无法对本端网元支持的所有DNN进行分组管理，但是通过配置“NFDNNGRP”的方式能有效对本端网元支持的所有DNN进行分组管理。如果“NFDNNGRP”和“DNNLIST”均由配置，则优先使用“NFDNNGRP”。如果需要使用“DNNLIST”，则需要通过MOD NFINFO命令将“NFDNNGRP”配置为“NULL”。 |

## 使用实例

增加PCF网元的特定信息，其中，“网元信息标识”为“pcfinfo\_01”，“网元类型”为“PCF”，“网元组ID”为“1”，“SUPI号段组”为“supi-group-01”。

```
ADD NFINFO: NFINFOID="pcfinfo_01", NFTYPE=PCF, NFGRPID="1", NFSUPIRANGEGRP="supi-group-01";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|-------:|:--------------------|:-----------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------|
|    503 | 配置数据已存在。            | 新增的数据记录数据库中已经存在。                                                                                     | 执行LST NFINFO命令查询网元信息，根据实际情况，重新输入参数，确保新增的数据记录在数据库中不存在。                                                                     |
| 360041 | 参数值不合法。             | 输入的提示参数不合法。                                                                                          | 根据实际情况，请重新输入，确保输入的参数符合取值范围。                                                                                               |
| 360054 | 同一组内，RANGETYPE必须相同。 | 原因如下： “网元组ID”对应的记录已经存在，但是号段类型不同，号段类型包含“SUPI号段组”和“GPSI号段组”。“SUPI号段组”和“GPSI号段组”未通过ADD NFRANGEINFO命令配置。 | 执行LST NFINFO命令查询网元信息，处理建议如下： 当需要增加号段类型对应的“网元组ID”已经存在，重新输入对应号段类型的“网元组ID”后执行本命令。通过ADD NFRANGEINFO命令重新配置“SUPI号段组”和“GPSI号段组”。 |
|  58142 | NFDNNGRP不存在。        | 输入的“DNN组”未通过ADD NFDNNGRP命令配置。                                                                        | 执行LST NFDNNGRP命令查询网元DNN组信息，重新执行本命令，确保输入的“DNN组”已存在。                                                                        |
