# 设置公共软件参数比特位（SET COMMONSOFTPARAOFBIT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NEF、NWDAF**

该命令用于设置公共软件参数的比特位。

## 注意事项

- 该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称           | 参数说明                                                                                                                                                                                   |
|:------------|:---------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DT          | 数据类型           | 可选必选说明：必选参数  参数含义：该参数表示软件参数的数据类型。  数据来源：本端规划 取值范围： “DwCom（公共双字）”：公共双字  默认值：无。  配置原则：无                                                                                                  |
| DWORDCOMNUM | Common Dword索引 | 可选必选说明：该参数在"DT"配置为"DwCom"时为条件必选参数。  参数含义：该参数表示Common Dword类型软件参数的索引。  数据来源：本端规划  取值范围：整数类型，取值范围是1~1500。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST COMMONSOFTPARAOFBIT查询当前参数配置值。  配置原则：无 |
| VALUE       | 软参记录值          | 可选必选说明：必选参数  参数含义：该参数表示软件参数的值。  数据来源：本端规划 取值范围： VALUE_0（0）VALUE_1（1）  默认值：无。  配置原则：无                                                                                                   |
| POSITION    | 比特位            | 可选必选说明：必选参数  参数含义：该参数表示软件参数比特位的位置。  数据来源：本端规划  取值范围：整数类型，取值范围是1~32。  默认值：无。  配置原则：无                                                                                                    |

## 使用实例

设置公共双字类型1号软参Bit1值为0:

```
SET COMMONSOFTPARAOFBIT: DT=DwCom, DWORDCOMNUM=1, VALUE=VALUE_0, POSITION=1;
```
