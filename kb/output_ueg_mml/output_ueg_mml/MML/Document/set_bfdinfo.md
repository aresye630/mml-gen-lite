## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置UdmHttpService服务与CSLB服务的BFD探测参数，可以增加和修改探测参数。

系统通过配置开关开启BFD探测功能，周期性（系统默认为50毫秒）地向CSLB转发网发送UDP（User Datagram Protocol）探测数据包。如果在BFD探测收包周期（BFD最小接收间隔 \* BFD探测倍数）内，没有收到承载网的响应包，认为这条路径可能存在问题，系统通知UdmHttpService终止转发业务。当在BFD探测周期内，收到承载网网关的响应包时，系统通知UdmHttpService开启转发业务功能。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                 |
|:----------|:---------|:-----------------------------------------------------------------------------------------------------|
| BFDENABLE | BFD开关    | 可选必选说明：必选参数 参数含义：用于设置是否使能BFD。 取值范围： CLOSE(BFD关闭)：关闭BFDOPEN(BFD打开)：打开BFD 默认值：无。 配置原则：无。               |
| DM        | 探测倍数     | 可选必选说明：条件可选参数 参数含义：用于设置BFD的探测倍数。 取值范围：3～10 默认值：3。 配置原则：仅当本命令中的“BFD开关”参数为“OPEN(BFD打开)”时该参数有效。         |
| MTI       | 最小发送时间间隔 | 可选必选说明：条件可选参数 参数含义：用于设置BFD消息的最小发送时间间隔。 取值范围：1～100 默认值：50。 配置原则：仅当本命令中的“BFD开关”参数为“OPEN(BFD打开)”时该参数有效。 |
| MRI       | 最小接收时间间隔 | 可选必选说明：条件可选参数 参数含义：用于设置BFD消息的最小接收时间间隔。 取值范围：1～100 默认值：50。 配置原则：仅当本命令中的“BFD开关”参数为“OPEN(BFD打开)”时该参数有效。 |

## 使用实例

设置BFD信息，“BFD开关”为“OPEN”，“探测倍数”为“3”，“最小发送时间间隔”为“50”，“最小接收时间间隔”为“50”:

```
SET BFDINFO: BFDENABLE=OPEN, DM=3, MTI=50, MRI=50;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
