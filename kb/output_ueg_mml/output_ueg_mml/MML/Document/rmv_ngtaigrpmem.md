# 删除5G TAI组性能统计对象成员（RMV NGTAIGRPMEM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于为基于5G TAI组的性能统计对象删除TAI成员。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                                                                                                                                                               |
|:---------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NGTAIGPN | NG TAI组名 | 可选必选说明：必选参数  参数含义：该参数用于标识基于5G TAI组的性能统计对象名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~255。不区分大小写，不支持空格及“\”。5G TAI组性能统计对象名称通过ADD PERFNGTAIGROUP命令进行创建。  默认值：无  配置原则：无                                                                                                                        |
| BGNTAI   | 起始TAI    | 可选必选说明：必选参数  参数含义：该参数用于表示TAI组所包含的TAI起始值。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是11~12。TAI由MCC、MNC和TAC组成。其中MCC为3位数字，MNC为2个或者3位数字，填写时请遵循实际长度；TAC编码为16进制数，其固定为6位，若不足则左起补0。输入的起始TAI值必须小于或者等于结束TAI值。对于同一个5G TAI组性能统计对象，输入的起始TAI值和终止TAI值定义的TAI号段范围不允许与该对象其它记录定义的TAI号段范围相互交叉、包含或重合。  默认值：无  配置原则：无 |
| ENDTAI   | 终止TAI    | 可选必选说明：必选参数  参数含义：该参数用于表示TAI组所包含的TAI结束值。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是11~12。TAI由MCC、MNC和TAC组成。其中MCC为3位数字，MNC为2个或者3位数字，填写时请遵循实际长度；TAC编码为16进制数，其固定为6位，若不足则左起补0。输入的终止TAI值必须大于或者等于起始TAI值。  默认值：无  配置原则：无                                                                              |

## 使用实例

将跟踪区区间“46000112233”-“46000112255”，从命名为“Hangzhou”的TAI组性能统计对象中删除，执行如下命令：

```
RMV NGTAIGRPMEM: NGTAIGPN="Hangzhou", BGNTAI="46000112233", ENDTAI="46000112255";
```
