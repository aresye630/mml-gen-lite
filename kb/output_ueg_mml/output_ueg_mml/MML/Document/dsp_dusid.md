# 显示DUS ID（DSP DUSID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询数据的实际归属实例。一般用于需要知道指定会话或用户具体在哪个DUS服务实例存储时，可以采用此命令查询。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                        |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APPTYPE  | 应用类型   | 可选必选说明：必选参数。 参数含义：用于指示系统按照指定应用类型来查询DUS服务实例的数据归属。 取值范围：需要与LST APPTYPE的“应用类型”值对应。 默认值：无。 配置原则：无。                                                                                                                                              |
| TREENAME | 树名称    | 可选必选说明：必选参数。 参数含义：用于指示系统按照指定树名称来查询DUS服务实例的数据归属。 取值范围：长度不超过30的字符串。 默认值：无。 配置原则：无。                                                                                                                                                            |
| DATAKEY  | 数据键值   | 可选必选说明：必选参数。 参数含义：用于指示系统按照指定数据键值来查询DUS服务实例的数据归属。 取值范围：长度不超过2000的字符串。  说明： 键值给定的字符类型需要与对应的实际类型匹配。实际类型可以通过查询Schema配置获得。对于Schema配置中数据键值字符类型为Raw类型或VarRaw类型需要在数据键值前添加hextoraw进行转换。如数据键值为“123456FF”需要转换为“hextoraw(/q123456FF/q)”。 默认值：无。 配置原则：无。 |
| KEYTYPE  | 键值类型   | 可选必选说明：可选参数。 参数含义：用于指示系统按照指定键值类型来查询DUS服务实例的数据归属。其给定值需要与Schema中配置的键值类型对应。 取值范围：0~4294967295 默认值：无。 配置原则：无。  说明： 对于辅键路由，若未指定“键值类型”，则系统默认为主键路由，返回空结果。辅键路由在该版本暂不支持。                                                                             |

## 使用实例

查询“数据键值”为“5800000000002001”的实际归属的DUS服务实例。

```
DSP DUSID: APPTYPE = "SUP-DUS", TREENAME = "SDU_SUBSCRIBER", DATAKEY = "5800000000002001";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。各输出项含义请参见表1输出项解释的参数说明。

| 输出项名称   | 输出项解释                       |
|:--------|:----------------------------|
| 应用类型    | 用于表示指定数据所属的应用类型。            |
| 树名称     | 用于表示指定数据所属的表名称。             |
| 数据键值    | 用于表示指定数据对应的键值。              |
| 分片ID    | 用于表示指定数据对应的分片ID。            |
| 实例标识    | 用于表示该数据键值所在实例的实例标识。         |
| POD名称   | 用于表示服务实例所属于的POD的名称。         |
| 分片属性    | 用于表示指定分片的主备属性。 取值范围： 主分片备分片 |
| 键值类型    | 用于标识用户数据对应的主键。              |

该命令执行异常，会返回对应的错误码。常见错误码如表2错误码列表所示。

|   错误码 | 错误码解释     | 原因分析               | 处理建议                                            |
|------:|:----------|:-------------------|:------------------------------------------------|
| 67778 | 指定的表不存在   | 当前输入的“树名称”在系统中不存在。 | 检查Schema配置是否存在指定的“树名称”，修改后重新执行。                 |
| 67891 | 当前不支持查看辅键 | 指定了辅键的键值类型。        | 删除指定的“键值类型”后重新执行。对应的“键值类型”可以通过检查Schema配置。       |
| 67779 | 未知错误      | 当前查询的DUS服务实例异常。    | 待DUS服务实例状态正常后重新执行。DUS服务实例状态可以通过DSP DUSSTAT命令获取。 |

**说明** 

若选择的“数据键值”在系统中不存在，返回空结果，不会返回错误码。
