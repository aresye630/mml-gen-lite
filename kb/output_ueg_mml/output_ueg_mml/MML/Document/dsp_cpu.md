# 显示资源CPU使用信息（DSP CPU）

#### 命令功能

该命令用于显示资源的CPU使用率信息。

当设备运行缓慢、性能下降时，可使用本命令查看系统资源的CPU使用率是否过高，也可在进行某项操作之前确认当前CPU是否还有足够的处理能力。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                 |
|:-------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------|
| RESOURCENAME | 资源名称   | 可选必选说明：可选参数 参数含义：该参数用于指定要查询CPU使用率的资源名称。通过DSP RES命令可以查询资源信息。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：当不输入时显示所有资源的信息。 |

#### 使用实例

- 显示所有资源的CPU使用率：

  ```
  DSP CPU:;
  ```

  ```
  RETCODE = 0  操作成功

  结果如下:
  -------------------------
  资源名称        系统CPU使用率（%） 
  OMU1            13                 
  OMU2            6                  
  (结果个数 = 2)
  ---    END
  ```
- 显示名为OMU1的资源CPU使用率：

  ```
  DSP CPU:RESOURCENAME="OMU1";
  ```

  ```
  RETCODE = 0  操作成功

  结果如下:
  -------------------------
             资源名称  =  OMU1 
   系统CPU使用率（%）  =  13                 
  (结果个数 = 1)
  ---    END
  ```

#### 输出结果说明

| 输出项名称       | 输出项解释              |
|:------------|:-------------------|
| 资源名称        | 资源名称。              |
| 系统CPU使用率（%） | 当前资源的CPU使用率（单位：%）。 |
