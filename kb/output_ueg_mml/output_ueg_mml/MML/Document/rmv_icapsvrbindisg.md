# 删除ICAP服务器绑定关系（RMV ICAPSVRBINDISG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于解除指定名称的ICAP Server Group和ICAP Server实例的绑定关系。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称       | 参数说明                                                                                               |
|:---------------|:-----------|:---------------------------------------------------------------------------------------------------|
| ICAPSVRGRPNAME | ICAP服务器组名称 | 可选必选说明：必选参数 参数含义：该参数用于指定ICAP Server Group的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格。 默认值：无 配置原则：无 |
| ICAPSERVERNAME | ICAP服务器名称  | 可选必选说明：可选参数 参数含义：该参数用于指定ICAP Server的服务器名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格。 默认值：无 配置原则：无    |

#### 使用实例

删除ICAP Server服务器is1与ICAP服务器组isg1的绑定信息：

```
RMV ICAPSVRBINDISG:ICAPSVRGRPNAME="isg1",ICAPSERVERNAME="is1";
```
