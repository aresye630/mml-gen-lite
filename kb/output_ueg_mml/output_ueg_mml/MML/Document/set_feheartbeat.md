# 设置FE心跳功能开关（SET FEHEARTBEAT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来设置FE心跳功能开关。

#### 注意事项

- 该命令执行后立即生效。

- 该命令仅适用于NP卡加速模式场景。

系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| FEHBSW   |
|:---------|
| ON       |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                 |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------|
| FEHBSW | 心跳开关   | 可选必选说明：必选参数 参数含义：该参数用于设置心跳功能开关。 数据来源：本端规划 取值范围： “OFF”：表示关闭心跳开关。 “ON”：表示打开心跳开关。 默认值：无。 配置原则：建议值为“ON”。 |

#### 使用实例

设置FE心跳功能开关为启用：

```
SET FEHEARTBEAT: FEHBSW=ON;
```
