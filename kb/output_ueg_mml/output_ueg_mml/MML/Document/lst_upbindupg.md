# 查询用户模板组和用户模板的绑定关系（LST UPBINDUPG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-C、SMF**

本命令用于查询UsrProfGroup下绑定的UserProfile。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                                                   |
|:--------------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------|
| USERPROFGNAME | 用户模板组名称 | 可选必选说明：可选参数 参数含义：该参数用于指定用户模板组名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：配置的USERPROFGNAME必须是系统已经存在的UsrProfGroup对象名称。 |

#### 使用实例

查询UserProfGName为userprofg1的UPBindUPG配置：

```
LST UPBINDUPG:USERPROFGNAME="userprofg1";
```
