# 查询重定向配置信息(LST REDIRECTCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询重定向配置信息。

- 如果需要查询全部重定向置信息，请不要输入任何参数。
- 如果需要查询特定的重定向配置信息，请依据参数说明输入查询的条件。

## 注意事项

无。

## 参数说明

| 参数标识                | 参数名称      | 参数说明                                                                                 |
|:--------------------|:----------|:-------------------------------------------------------------------------------------|
| REDIRECTCONFIGID    | 重定向配置ID   | 用于指示UPCF需要按照哪个重定向配置ID来查询重定向的配置信息；若不输入，则表示所有的重定向配置ID。 取值范围：1～2048 默认值：无。              |
| REDIRECTDSTHOSTNAME | 重定向目的主机名  | 用于指示UPCF需要按照哪个重定向目的主机名来查询重定向的配置信息；若不输入，则表示所有的重定向目的主机名。 取值范围：长度不超过128字节的字符串。 默认值：无。   |
| REDIRECTORIHOSTNAME | 重定向发起方主机名 | 用于指示UPCF需要按照哪个重定向发起方主机名来查询重定向的配置信息；若不输入，则表示所有的重定向发起方主机名。 取值范围：长度不超过128字节的字符串。 默认值：无。 |
| REDIRECTPORT        | 重定向端口号    | 用于指示UPCF需要按照哪个重定向端口号来查询重定向的配置信息；若不输入，则表示所有的重定向端口号。 取值范围：0～65534 默认值：无。               |
| REDIRECTPROTOCOL    | 重定向协议类型   | 用于指示UPCF需要按照哪个重定向协议类型来查询重定向的配置信息；若不输入，则表示所有的重定向协议类型。 SCTP(SCTP)TCP(TCP) 默认值：无。       |
| DESCRIPTION         | 描述        | 用于指示UPCF需要按照哪个描述来查询重定向的配置信息；若不输入，则表示所有的描述信息。 取值范围：长度不超过64字节的字符串。 默认值：无。              |

## 使用实例

1. 查询全部的重定向配置信息。

   ```
   LST REDIRECTCFG:;
   ```

   ```
   %%LST REDIRECTCFG:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   重定向配置ID         重定向目的主机名          重定向发起方主机名          重定向端口号               重定向协议类型         描述                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          
   1                    PCRF01                    PCEF01                      0                          SCTP                   1
   2                    PCRF02                    PCEF02                      8001                       TCP                    1
   (结果个数 = 2)                                                                                                                                                                                                                                                                                   
   ---    END
   ```
2. 查询一条重定向配置信息。“重定向配置ID”为“1”。

   ```
   LST REDIRECTCFG: REDIRECTCONFIGID=1;
   ```

   ```
   %%LST REDIRECTCFG: REDIRECTCONFIGID=1;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
          重定向配置ID  =  1
       重定向目的主机名 =  PCRF01
    重定向发起方主机名  =  PCEF01
          重定向端口号  =  0
        重定向协议类型  =  SCTP
                  描述  =  1
   (结果个数 = 1)

   ---    END
   ```
