# 查询域名前后缀分隔符（LST CPDOMAINSEPARATOR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF、GGSN、PGW-C**

该命令用于查看已设置的前缀分割符和后缀分割符。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询已设置的前缀分隔符和后缀分隔符的配置信息：

```
%%LST CPDOMAINSEPARATOR:;%%
RETCODE = 0  操作成功

结果如下
--------
    前缀域名分隔符  =  @%
    后缀域名分隔符  =  #/
前缀域名分隔符开关  =  使能
后缀域名分隔符开关  =  使能

(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称     | 输出项解释                |
|:----------|:---------------------|
| 前缀域名分隔符   | 该参数用于指定作为前缀的分隔符。     |
| 后缀域名分隔符   | 该参数用于指定作为后缀的分隔符。     |
| 前缀域名分隔符开关 | 该参数用于打开或关闭前缀域名分隔符开关。 |
| 后缀域名分隔符开关 | 该参数用于打开或关闭后缀域名分隔符开关。 |
