# 查询授权服务列表（LST AUTHSERVLIST）

- 命令功能
- 注意事项
- 操作用户权限

#### 命令功能

**适用NF：UPF、MPF**

该命令用于查询授权服务列表。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                   |
|:-------|:---------|:-----------------------------------------------------------------------------------------------------------------------|
| NAME   | 授权服务列表名称 | 可选必选说明：可选参数 参数含义：该参数用于指定APP可访问的授权服务列表。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“.”组成，且只能以字母或者数字开头。 默认值：无 配置原则：无 |

#### 使用实例

- 查询全部授权服务列表：

  ```
  LST AUTHSERVLIST:;
  ```

  ```
  RETCODE = 0  操作成功

  授权服务列表
  ------------
  授权服务列表名称  

  serviceList       
  serviceList1      
  (结果个数 = 2)

  ---    END
  ```
- 查询名称为"serviceList"的授权服务列表：

  ```
  LST AUTHSERVLIST: NAME="serviceList";
  ```

  ```
  RETCODE = 0  操作成功

  授权服务列表
  ------------
  授权服务列表名称  =  serviceList
  (结果个数 = 1)

  ---    END
  ```
