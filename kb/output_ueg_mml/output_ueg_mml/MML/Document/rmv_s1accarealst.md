# 删除S1模式接入控制配置（RMV S1ACCAREALST）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于删除S1模式接入控制参数。

#### 注意事项

- 该命令执行后立即生效。
- 如果只指定了参数“AREA(区域范围)”而没有指定参数“SUBRANGE(用户范围)”，会将指定区域下的所有记录都删除，因此执行删除操作前请仔细确认。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                              |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AREA     | 区域范围   | 可选必选说明：必选参数 参数含义：待删除指定区域范围。 取值范围：“AG(区域组)”：表示该区域标识类型为区域组。“TA(指定跟踪区)”：表示该区域标识类型为指定跟踪区。“OTHER(其他)”：表示该区域标识类型为其他。 默认值：无  说明： 区域范围表示进行接入控制所适用的位置区域。区域范围按照粒度从粗到细分为以下几个级别：区域组，指定跟踪区，其他。相同粒度区域范围的各记录的区域范围不能交迭。                                                                                                                                                                                                                                           |
| MCC      | 移动国家码  | 可选必选说明：条件必选参数 参数含义：待删除指定移动国家代码。 前提条件：该参数在“AREA(区域范围)”参数设置为“TA(跟踪区)”时，才需要配置。 取值范围：3位十进制数字 默认值：无                                                                                                                                                                                                                                                                                                                                                    |
| MNC      | 移动网号   | 可选必选说明：条件必选参数 参数含义：待删除指定移动网号。 前提条件：该参数在“AREA(区域范围)”参数设置为“TA(跟踪区)”时，才需要配置。 取值范围：2～3的十进制数字 默认值：无                                                                                                                                                                                                                                                                                                                                                    |
| TAC      | 跟踪区域码  | 可选必选说明：条件必选参数 参数含义：待删除指定跟踪区域码。 前提条件：该参数在“AREA(区域范围)”参数设置为“TA(跟踪区)”时，才需要配置。 取值范围：0x0000～0xFFFF 默认值：无                                                                                                                                                                                                                                                                                                                                               |
| AREAID   | 区域群标识  | 可选必选说明：条件必选参数 参数含义：待删除用户的区域群标识。 前提条件：该参数在“AREA(区域范围)”参数设置为“AG(区域组)”时，才需要配置。 取值范围：1～50 默认值：无  说明： 该区域ID必须已经通过ADD AREAGPMEM命令添加成功，且在区域群成员表中的记录对应的“IDTYPE”只能为“TA”。可执行LST AREAGPMEM进行查看。                                                                                                                                                                                                                                                              |
| SUBRANGE | 用户范围   | 可选必选说明：可选参数 参数含义：待删除指定用户范围。 取值范围：“ALL_USER(所有用户)”：表示用户范围为所有用户。“SPECIAL_IMSIPRE(指定IMSI前缀)”：表示该用户范围为指定IMSI前缀。“USER_GROUP(用户群)”：表示用户范围为用户群。“SPECIAL_IMSI_RANGE(指定IMSI范围)”：表示该用户范围为指定IMSI范围。“UE_TYPE(终端类型)”:用于设置设备型号核准号码对应的终端类型。“FOREIGN_USER（外网用户）”：表示该用户范围为外网用户。“HOME_USER（本网用户）”：表示该用户范围为本网用户。 默认值：无                                                                                                                                               |
| IMSIPRE  | IMSI前缀 | 可选必选说明：条件必选参数 参数含义：待删除用户的IMSI前缀。 前提条件：该参数在“SUBRANGE(用户范围)”参数设置为“SPECIAL_IMSIPRE(指定IMSI前缀)”时，才需要配置。 取值范围：1～15位十进制数字 默认值：无  说明： 支持IMSI最长匹配的查询方式。                                                                                                                                                                                                                                                                                                    |
| IMSI     | IMSI   | 可选必选说明：条件必选参数 参数含义：该参数用于指定用户的IMSI，对该IMSI所在号段进行删除。 前提条件：该参数在“SUBRANGE(用户范围)”参数设置为“SPECIAL_IMSI_RANGE(指定IMSI范围)”时，才需要配置。 取值范围：1～15位十进制数字 默认值：无                                                                                                                                                                                                                                                                                                      |
| SUBID    | 用户群标识  | 可选必选说明：条件必选参数 参数含义：待删除的用户群标识。 前提条件：该参数在“SUBRANGE(用户范围)”参数设置“USER_GROUP(用户群)”时，才需要配置。 取值范围：1～100 默认值：无  说明： 该用户群标识必须已经通过ADD SUBGPMEM命令添加成功，可执行LST SUBGPMEM进行查看。                                                                                                                                                                                                                                                                                    |
| UETYPE   | 终端类型   | 可选必选说明：条件必选参数 参数含义：该参数用于设置需要进行接入限制的终端类型。 数据来源：本端规划 取值范围：“ANDROID(Android)”“BLACKBERRY(Black Berry)”“IOS(iOS)”“WINDOWS(Windows)”“CUSTOM_TYPE_1(自定义类型1)”“CUSTOM_TYPE_2(自定义类型2)”“CUSTOM_TYPE_3(自定义类型3)”“CUSTOM_TYPE_4(自定义类型4)”“CUSTOM_TYPE_5(自定义类型5)”“CUSTOM_TYPE_6(自定义类型6)”“CUSTOM_TYPE_7(自定义类型7)”“CUSTOM_TYPE_8(自定义类型8)”“CUSTOM_TYPE_9(自定义类型9)”“CUSTOM_TYPE_10(自定义类型10)”“CUSTOM_TYPE_11(自定义类型11)”“CUSTOM_TYPE_12(自定义类型12)”“ALL_IMEI(所有IMEI)” 默认值：无 |
| NOID     | 运营商标识  | 可选必选说明：条件必选参数 参数含义：该参数用于指定运营商标识。 前提条件：该参数在“SUBRANGE（用户范围）”配置为“FOREIGN_USER（外网用户）”或“HOME_USER（本网用户）”后生效。 数据来源：整网规划 取值范围：0～64，128～254 默认值：无 配置原则：当用户为MNO用户时，该参数需要配置为0或128～254之间的值，该取值必须和ADD MNO中配置的“MNOID”参数取值相同。若该参数需要配置为1～64之间的值时，须先在ADD MVNO中配置取值相同的“MVNOID”参数。                                                                                                                                                                                  |

#### 使用实例

删除一条S1模式接入控制参数记录，区域范围为其他：

RMV S1ACCAREALST: AREA=OTHER;
