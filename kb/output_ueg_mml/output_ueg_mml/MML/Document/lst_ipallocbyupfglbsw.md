# 查询基于UPF地址分配的全局开关（LST IPALLOCBYUPFGLBSW）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：PGW-C、SMF、GGSN**

该命令用于查询基于UPF地址分配的全局开关。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

无

## 使用实例

查询基于UPF地址分配的全局开关：

```
%%LST IPALLOCBYUPFGLBSW:;%%
RETCODE = 0 操作成功

结果如下
-----------------------------------------------
基于UPF分配IPv4地址的全局开关  =  使能
基于UPF分配IPv6地址的全局开关  =  使能
(结果个数 = 1)

--- END
```

## 输出结果说明

| 输出项名称              | 输出项解释                      |
|:-------------------|:---------------------------|
| 基于UPF分配IPv4地址的全局开关 | 该参数用于指定基于UPF分配IPv4地址的全局开关。 |
| 基于UPF分配IPv6地址的全局开关 | 该参数用于指定基于UPF分配IPv6地址的全局开关。 |
