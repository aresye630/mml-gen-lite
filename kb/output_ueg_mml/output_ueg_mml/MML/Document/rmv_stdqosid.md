# 删除标准QoS ID配置（RMV STDQOSID）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SGW-C、PGW-C、GGSN、SMF**

该命令用于删除标准QoS ID配置。

## 注意事项

- 该命令执行后只对新激活用户生效。

- 配置中的标准QoS ID被EXTENQCIATTR中的EXTQCIMAPDEFQCI或EXTENDQCIMAP中的STANDARDQCI使用时，该配置无法删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称      | 参数说明                                                                                                         |
|:----------|:----------|:-------------------------------------------------------------------------------------------------------------|
| QOSIDTYPE | QoS ID类型  | 可选必选说明：必选参数  参数含义：该参数用于指定QoS ID类型。  数据来源：本端规划 取值范围： “QCI（QCI）”：QCI“FIVEQI（5QI）”：5QI  默认值：无  配置原则：无           |
| QOSIDSV   | QoS ID起始值 | 可选必选说明：必选参数  参数含义：该参数用于指定QoS ID起始值。  数据来源：全网规划  取值范围：整数类型，取值范围是10~255。  默认值：无  配置原则：  该参数的值必须小于等于QoS ID的结束值。 |

## 使用实例

删除“QCI=90”的“标准QoS ID”配置：

```
RMV STDQOSID:QOSIDTYPE=QCI,QOSIDSV=90;
```
