# 显示HLB对端链路(DSP HLBPEERL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于在配置数据库中查询HLB和对端实体的链路状态信息。

- 如果需要显示所有对端类型的链路状态信息，请不要输入任何参数。
- 如果需要显示某种对端类型的链路状态信息，请依据参数说明输入查询条件。

## 注意事项

当**SET HTTPCLIENTCFG**命令中“LINKCTLMODE”参数设置为“NEW(新模式)”时，本命令仅支持查询动态链路信息，不支持查询“LINKTYPE”参数取值为“Static(静态配置链路)”的静态链路信息。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                     |
|:-----------|:-------|:---------------------------------------------------------------------------------------------------------|
| PEERID     | 对端标识   | 可选必选说明：可选参数 参数含义：用于指定系统按照哪个对端标识来查询链路状态信息；若不输入，则表示所有的对端标识。 取值范围：0～63 默认值：无。 配置原则：无。                       |
| LINKID     | 链路标识   | 可选必选说明：可选参数 参数含义：用于指定系统按照哪个链路标识来查询链路状态信息；若不输入，则表示所有的链路标识。 取值范围：0 默认值：无。 配置原则：无。                          |
| LINKSTATUS | 链路状态   | 可选必选说明：可选参数 参数含义：用于指定系统按照哪个链路状态来查询链路状态信息；若不输入，则表示所有的链路状态。 取值范围： UP(在线)DOWN(离线) 默认值：无。 配置原则：无。            |
| LINKTYPE   | 链路类型   | 可选必选说明：可选参数 参数含义：用于指定系统按照哪个链路类型来查询链路信息；若不输入，则表示所有的链路类型。 取值范围： Static(静态配置链路)Dynamic(动态链路) 默认值：无。 配置原则：无。 |

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义如表1。

| 输出项名称    | 输出项解释                                         |
|:---------|:----------------------------------------------|
| 对端标识     | 用于返回HLB对端链路的对端标识。 当“链路类型”为“动态链路”时该输出项为“NULL”。 |
| 链路标识     | 用于返回HLB对端链路的链路标识。 当“链路类型”为“动态链路”时该输出项为“NULL”。 |
| POD名称    | 用于返回HLB对端链路所在的POD名称。                          |
| 本端IP地址   | 用于返回HLB对端链路的本端IPV4/IPV6地址。                    |
| 本端端口号    | 用于返回HLB对端链路的本端端口号。                            |
| 对端IP地址   | 用于返回HLB对端链路的对端IPV4/IPV6地址。                    |
| 对端端口号    | 用于返回HLB对端链路的对端端口号。                            |
| 当前流数目    | 用于返回HLB对端链路的当前流数目。                            |
| 最大流数目    | 用于返回HLB对端链路的最大流数目。                            |
| 优先级      | 用于返回HLB对端链路的优先级。                              |
| 权重       | 用于返回HLB对端链路的权重数。                              |
| 链路状态     | 用于返回HLB对端链路的链路状态。                             |
| http连接ID | 用于返回HLB对端的http连接ID。                           |
| 工作模式     | 用于返回HLB本端是服务端还是客户端。                           |
| 链路类型     | 用于返回HLB对端链路的链路类型。                             |
