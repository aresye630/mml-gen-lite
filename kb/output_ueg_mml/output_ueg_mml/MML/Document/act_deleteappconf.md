# 删除APP配置（ACT DELETEAPPCONF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

**须知** 

本命令属于高危命令，此操作会删除APPD所有信息，将导致基于该appInstanceId的本地分流功能都不可用。

该命令用于在APPD配置残留场景下删除APPD配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                    |
|:--------------|:-------|:--------------------------------------------------------------------------------------------------------|
| APPINSTANCEID | 应用实例ID | 可选必选说明：必选参数 参数含义：指定APP实例号，可以通过DSP APPOPERATE查出所有的APP实例号。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：无 |

#### 使用实例

删除APPD配置信息，app实例号为“qq12580”。执行该命令后该app实例的所有APPD配置将会被全部删除：

```
ACT DELETEAPPCONF: APPINSTANCEID="qq12580";
```
