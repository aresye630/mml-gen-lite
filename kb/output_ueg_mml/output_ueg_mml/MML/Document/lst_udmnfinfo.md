# 查询网元信息（LST UDMNFINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询数据配置库中网元的特定配置信息：

- 若要查询全部网元的特定配置信息，请不要输入任何参数。
- 若要查询某个网元的特定配置信息，请输入“网元信息标识”或其他参数，或者“网元信息标识”和其他参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称           | 参数说明                                                                                                                                                                                         |
|:---------|:---------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINFOID | 网元信息标识         | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个网元信息标识来查询网元信息；若不输入，则表示查询所有网元信息标识的网元信息。 取值范围：长度不超过32位的字符串，字符串由数字、字母、“-”或“_”组成 默认值：无。 配置原则：无。                                                                       |
| NFTYPE   | 网元类型           | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个网元类型来查询某个网元信息；若不输入，则表示查询所有网元类型的网元信息。 取值范围： UDM(统一数据管理)AUSF(鉴权服务功能)5G-EIR(设备身份校验) 默认值：无。 配置原则：当“网元类型”参数取值设置为“5G-EIR(设备身份校验)”时，UDM向NRF发起注册的消息中携带的nfType信元取值为5G_EIR。 |
| REGRANGE | NRF注册时是否携带号段信息 | 可选必选说明：可选参数 参数含义：用于指示系统按照NRF注册时是否携带号段信息来查询某个网元信息；若不输入，则表示查询所有号段的网元信息。 取值范围：TRUE(上报)，携带号段信息。 默认值：无。 配置原则：无。  说明： 执行本命令，当“NFTYPE”参数值取为“5G-EIR(设备身份校验)”，“REGRANGE”参数值取为“TRUE(上报)”时，查询结果为空。      |

## 使用实例

1. 查询所有网元信息：

   ```
   LST UDMNFINFO:;
   ```

   ```
   %%LST UDMNFINFO:;%% 
   RETCODE = 0  操作成功
       
   操作结果如下:
   -------------
   网元信息标识组  网元类型          网元组ID  SUPI号段组  GPSI号段组  外部组标识范围组  路由指示  NRF注册时是否携带号段信息  号段配置检查  
   GPSI_01         统一数据管理      2         NULL        GPSI_01     NULL              NULL      上报                       TRUE
   udminfo_01      统一数据管理      1         SUPI_01     NULL        NULL              NULL      上报                       TRUE      

    (结果个数 = 2)  
   ---    END
   ```
2. 查询一条网元信息，“网元信息标识”为“udminfo\_01”：

   ```
   LST UDMNFINFO: NFINFOID="udminfo_01";
   ```

   ```
   %%LST UDMNFINFO: NFINFOID="udminfo_01";%% 
   RETCODE = 0  操作成功
         
   操作结果如下:
   -------------
                网元信息标识组  =  udminfo_01
                      网元类型  =  统一数据管理        
                      网元组ID  =  1
                    SUPI号段组  =  SUPI_01
                    GPSI号段组  =  NULL
              外部组标识范围组  =  NULL
                      路由指示  =  NULL 
     NRF注册时是否携带号段信息  =  上报
                  号段配置检查  =  TRUE
     
     (结果个数 = 1)

     ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD UDMNFINFO**命令的参数说明。
