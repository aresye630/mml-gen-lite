# 删除服务类型在POD实例下的静态权重（RMV STATICWTPOLICY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

如果配置不合理会导致不同POD间负载不均衡。

**适用NF：SGW-C、PGW-C、SMF、GGSN、AMF**

该命令用于删除服务类型在POD实例下的静态权重。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                               |
|:------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
| PODNAME     | POD名称  | 可选必选说明：必选参数  参数含义：该参数用于指定POD名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：  使用DSP POD命令查询sm/am的pod Name。                                   |
| SERVICETYPE | 服务类型   | 可选必选说明：必选参数  参数含义：该参数用于指定服务类型，配置对应的Token权重。  数据来源：本端规划 取值范围： “UAM_0（UAM_0）”：涉及如下类型POD：接入/移动性管理POD。“USM_0（USM_0）”：涉及如下类型POD：会话管理POD。  默认值：无  配置原则：无 |

## 使用实例

删除POD Name为xxx，服务类型为USM\_0，删除静态权重1000：

```
RMV STATICWTPOLICY:PODNAME="XXX",SERVICETYPE=USM_0,CONFIRM=Y;
```
