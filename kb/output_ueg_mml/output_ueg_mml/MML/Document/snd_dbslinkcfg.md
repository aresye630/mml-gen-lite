# 发送DBS链路配置(SND DBSLINKCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于DBS微服务向远端DSG广播本端DBS配置以及IP配置。

## 注意事项

- 当本端同时配置了远端的DSG配置和IP配置时，报文才会返回对端的操作结果。
- 在向对端发送完本端DBS配置以及IP配置之后，通过**ACT DBSIPDISP**命令且**ACT DBSIPDISP**命令入参“模式”选择“ALL(所有)”来激活链路，配置才能生效。

## 参数说明

无。

## 使用实例

向远端DSG模块发送本端DBS配置以及IP配置。

```
SND DBSLINKCFG:;
```

```
%%SND DBSLINKCFG:;%%
RETCODE = 0 操作成功

操作结果如下
----------------------
远端LocationID 业务类型 操作结果
5              SUP-FE   操作成功
(结果个数 = 1)

 --- END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称        | 输出项解释                                                                                                                                                                                                                                     |
|:-------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 远端Location标识 | 用于返回本端DBS所对接的远端Location标识。                                                                                                                                                                                                                |
| 业务类型         | 用于返回当前DBS的业务类型。                                                                                                                                                                                                                           |
| 操作结果         | 用于返回发送DBS链路通知的操作结果。 操作成功操作失败操作超时对端版本不支持本功能链路故障 说明： 需要对该命令返回报文内容进行判断，报文操作结果字段有如下情况： 操作成功 => 成功向远端DSG发送本端DBS配置以及IP配置。操作失败 => 重试当前操作，若仍不成功请联系华为技术支持。操作超时 => 重试当前操作，若仍不成功请联系华为技术支持。对端版本不支持本功能 => 请在对端网元进行手工链路配置或使用链路中心进行配置。链路故障 => 请联系华为技术支持。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释   | 原因分析                              | 处理建议                   |
|------:|:--------|:----------------------------------|:-----------------------|
|   520 | 部分成功。   | 存在部分DBS微服务故障。存在部分业务类型的DBS微服务全部故障。 | 重试当前操作，若仍不成功请联系华为技术支持。 |
