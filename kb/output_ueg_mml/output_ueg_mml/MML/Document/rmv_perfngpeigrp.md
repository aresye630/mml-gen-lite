# 删除NG PEI组性能统计对象（RMV PERFNGPEIGRP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于删除指定的NG PEI组性能统计对象。

## 注意事项

- 该命令执行后立即生效。

- 在执行本命令之前请首先通过RMV NGPEIGRPMEM删除NG PEI群组下的所有成员。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称       | 参数说明                                                                                                                                                       |
|:---------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| NGPEIGPN | NG PEI群组名称 | 可选必选说明：必选参数  参数含义：该参数用于标识NG PEI组的性能统计对象名称。NG PEI组内的PEI成员通过ADD NGPEIGRPMEM命令进行增加。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~128。不区分大小写，不支持空格及“\”且全局唯一。  默认值：无  配置原则：无 |

## 使用实例

删除群组名称为“phone\_xx”的PEI群组：

```
RMV PERFNGPEIGRP: NGPEIGPN="phone_xx";
```
