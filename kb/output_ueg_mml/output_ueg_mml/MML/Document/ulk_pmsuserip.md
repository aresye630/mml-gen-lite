# 解锁PMS用户WEB客户端IP(ULK PMSUSERIP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于解锁连续登录UPCF Web UI界面失败而被锁定的IP地址。

**说明** 

如果系统安全策略中“帐户&IP锁定策略”设置为启用，当同一IP地址通过UPCF Web UI界面首次登录系统失败后，再次连续登录失败次数达到“最大登录失败尝试次数(1..5)”，则系统会将该IP锁定，在锁定状态取消前，将禁止通过该IP地址登录UPCF Web UI。

在确保系统安全的前提下，您可以执行该命令，解锁被锁定的IP地址。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                        |
|:-------|:-------|:--------------------------------------------------------------------------------------------|
| IPVER  | IP地址类型 | 可选必选说明：必选参数 参数含义：解锁被锁定的IP地址类型，支持IPV4和IPV6两种IP地址。 取值范围： IPV4(IPV4) IPV6(IPV6) 默认值：无。 配置原则：无。 |
| IP     | IPV4地址 | 可选必选说明：可选参数 参数含义：解锁被锁定的IPV4地址。 取值范围：符合IPV4标准的IP地址 默认值：无。 配置原则：无。                            |
| IPV6   | IPV6地址 | 可选必选说明：可选参数 参数含义：解锁被锁定的IPV6地址。 取值范围：符合IPV6标准的IP地址 默认值：无。 配置原则：无。                            |

## 使用实例

- 解锁一个被锁定登录的IPv4地址。“IP地址类型”为“IPV4(IPV4)”，“IPV4地址”为“192.168.1.130”。

  ```
  ULK PMSUSERIP: IPVER=IPV4, IP="192.168.1.130"
  ```

- 解锁一个被锁定登录的IPv6地址。“IP地址类型”为“IPV6(IPV6)”，“IPV6地址”为“2001:0db8:80ff:fa01:0000:0000:0000:1515”。

  ```
  ULK PMSUSERIP: IPVER=IPV6, IPV6="2001:0db8:80ff:fa01:0000:0000:0000:1515"
  ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释    | 原因分析                   | 处理建议                          |
|-------:|:---------|:-----------------------|:------------------------------|
| 483018 | IP地址不合法。 | 输入的IP地址不符合IPV4或IPV6标准。 | 请在执行该命令时输入符合IPV4或IPV6标准的IP地址。 |
