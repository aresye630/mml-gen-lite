# 删除扩展包（RMV PLGPKG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

该命令属于高危命令，若删除的是冷扩展包，则该操作会重启系统，请谨慎使用。

该命令用于删除不需要的扩展包。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| PLGTYPE         | 扩展包类型  | 可选必选说明：必选参数 参数含义：该参数用于指定扩展包类型。可通过LST PLGPKG或者DSP PLGPKG查询获取。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无         |
| VERSIONID       | 版本号    | 可选必选说明：必选参数 参数含义：该参数用于指定扩展包版本号。可通过LST PLGPKG或者DSP PLGPKG查询获取。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无        |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

删除侦听功能扩展包：

```
RMV PLGPKG:PLGTYPE="Listening",VERSIONID="V100R020C00SPH153",SERVICEINSTANCE="vnfc";
```
