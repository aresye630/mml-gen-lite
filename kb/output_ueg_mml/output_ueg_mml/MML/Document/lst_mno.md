#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询MNO的配置。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                    |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MNOID  | MNO标识  | 可选必选说明：可选参数 参数含义：待查询MNO的标识。 取值范围：0，128~254 默认值：无  说明： 0为系统初始值。由于系统初始化后，已存在一条“MNOID”为0的记录，当“MNOID”参数为0时，执行ADD MNO的效果等同于执行MOD MNO命令可以输入参数查询，也可以不输入参数查询。如果输入“MNOID”参数，只是查询这个MNO的配置。如果不输入“MNOID”参数，查询所有的记录。 |

#### 使用实例

查看所有的MNO:

LST MNO:;

```
%%LST MNO:;%%
RETCODE = 0  操作成功。

操作结果如下
--------------
   MNO标识  =  128
运营商全称  =  bbb
运营商简称  =  b
(结果个数 = 1)
---    END
```
