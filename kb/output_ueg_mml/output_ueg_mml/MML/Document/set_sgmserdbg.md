# 设置SGM业务调试信息（SET SGMSERDBG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响系统性能与业务处理，需联系华为技术支持确认后再执行。

该命令用于SGM服务的调测与维护。具有导出全局数据功能，即：从SGM内存中导出全局数据。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
|:-----------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CMDTYPE    | 命令类型   | 可选必选说明：必选参数 参数含义：用于指定业务模块调试命令的操作类型。 取值范围： EXP_USER_SHARE_DATA(导出用户共享数据)：用于导出SGM服务中指定用户的共享数据。本地文件存放目录：/opt/csplog/{appID}/{service name}/export/log文件名命名格式：sgm_pub_(mid).logmid表示本SGM实例号例如：sgm_pub_66240.log CLR_DATA_FILE(清除数据文件)：用于清除“/opt/csplog/{appID}/{service name}/export/log”目录下查询数据任务生成的文件。EXP_GLB_DATA(导出全局数据)：用于导出全局数据到日志。从SGM内存中导出全局数据，生成文件的路径与文件名如下 本地文件存放目录：/opt/csplog/{appID}/{service name}/export/log文件名命名格式：globe_data_(smtype)_(mid)_(yyyymmddhhmmss).dat.gz，其中，(smtype)取值：sgm(mid)表示SGM实例号(yyyymmddhhmmss)表示生成文件时的时间戳例如：globe_data_sgm_66240_20190524011139.dat.gz  说明： 本地文件也可通过登录OM Portal窗口，选择“监控分析>运行日志”，在左侧导航栏中选择“服务日志收集”，右侧页面“应用名称”选择“UPCF应用”，“服务类型”勾选“PcfSgmService”服务，创建日志收集任务查看。 CHK_USER_DATA(校验用户数据)：用于校验用户数据，此时参数“用户标识”必选，触发用户重新查库并更新本地用户数据。 说明： 对于主从用户/企业组用户/M2M用户，“用户标识”必须填写主用户、组用户或父节点用户的用户标识，主/组/父节点用户先查库，主/组/父节点用户查库完成后通知在线从用户/成员用户/子节点用户重新查库。如果填写从用户、成员用户或子节点用户的用户标识，执行该命令不生效。 默认值：无 配置原则：无 |
| SUBID      | 用户标识   | 可选必选说明：当“CMDTYPE”选择“EXP_USER_SHARE_DATA”或“CHK_USER_DATA”时，显示参数“SUBID”，此时“SUBID”为必选参数。 参数含义：用于指定导出或校验哪个用户的会话数据。 取值范围：长度不超过255的字符串。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| INSTANCENO | SGM实例号 | 可选必选说明：当“CMDTYPE”选择“EXP_GLB_DATA”时，显示参数“INSTANCENO”，参数可选。 参数含义：用于指定调试命令对应的实例号。 取值范围：长度不超过256的字符串。 默认值：无。 配置原则：执行DSP SGMINFO命令获取返回服务的实例号。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |

## 使用实例

统计SGM服务的用户数据。“命令类型”为“EXP\_GLB\_DATA”。

```
SET SGMSERDBG: CMDTYPE=EXP_GLB_DATA;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
