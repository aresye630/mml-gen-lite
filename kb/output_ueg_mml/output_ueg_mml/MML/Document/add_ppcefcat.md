# 增加PCRF对端PCEF类别(ADD PPCEFCAT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

用于在配置数据库中增加一条对端PCEF类别的数据记录。在该命令中，系统通过“PCRF标识”和“对端PCEF类别标识”这两个参数来唯一标识一条对端PCEF类别数据记录。对端PCEF类别标识和对端PCEF类别是一一对应的。

## 注意事项

- 配置“对端PCEF类别标识”和“对端PCEF类别”都不允许重复。
- 增加、删除和修改对端PCEF的“APN标识”对在线会话不生效。

## 使用实例

1. 增加PCRF对端PCEF类别。PCRF实体标识为1，对端PCEF类别标识为1，对端PCEF类别为GGSN，会话超时后处理方式为默认值。

   ```
   ADD PPCEFCAT: PCRFID=1, PCEFCATID=1, PCEFCAT="GGSN", ISAPN=NO;
   ```
2. 增加PCRF对端PCEF类别。PCRF实体标识为1，对端PCEF类别标识为1，对端PCEF类别为DPI，会话超时后处理方式为ReleaseSingleSession，CCR\_T会话释放处理方式为ReleaseAllSession。

   ```
   ADD PPCEFCAT: PCRFID=1, PCEFCATID=1, PCEFCAT="DPI", TIMEOUTPROCESS=ReleaseSingleSession, TERMINALPROCESS=ReleaseAllSession, ISAPN=NO;
   ```
