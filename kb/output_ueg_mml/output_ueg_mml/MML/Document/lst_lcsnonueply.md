# 查询LCS UE无关的策略参数（LST LCSNONUEPLY）

- 命令功能
- 注意事项

#### 命令功能

**适用NF：LMF**

该命令用于查询LCS UE无关的策略参数。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询LCS UE无关的策略参数：

```
LST LCSNONUEPLY:;
```

