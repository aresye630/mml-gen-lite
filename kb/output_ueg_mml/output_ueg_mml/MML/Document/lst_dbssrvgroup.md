# 查询DBS业务类型分组(LST DBSSRVGROUP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询DBS支持多应用共存的业务分组中各个业务类型信息，实现对DBS多应用共存的配置和维护功能：

- 若要查询全部分组中的业务类型信息，请不要输入任何参数。
- 若要查询某个分组中的业务类型信息，请输入“分组名称”参数。

## 注意事项

无。

## 参数说明

| 参数ID      | 参数名称   | 参数说明                                                                                                                               |
|:----------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------|
| GROUPNAME | 分组名称   | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照分组名称来查询业务分组中各个业务类型信息；若不输入，则表示查询所有分组的业务类型信息。 取值范围：不超过128个字符的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询所有分组中的业务类型信息。

   ```
   LST DBSSRVGROUP:;
   ```

   ```
   %%LST DBSSRVGROUP:;%% 
   RETCODE = 0  操作成功  

   操作结果如下 
   ------------ 
   分组名称      业务类型  业务类型名称    
   GU-SUP-DNS      43      SUP-FE           
   GU-SUP-DNS      53      GU-HLR   
   (结果个数 = 2)  

   ---    END
   ```
2. 查询分组名称为“GU-SUP-DNS”的业务类型信息。

   ```
   LST DBSSRVGROUP: GROUPNAME="GU-SUP-DNS";
   ```

   ```
   %%LST DBSSRVGROUP: GROUPNAME="GU-SUP-DNS";%% 
   RETCODE = 0  操作成功  

   操作结果如下 
   ------------ 
   分组名称      业务类型  业务类型名称    
   GU-SUP-DNS      43      SUP-FE           
   GU-SUP-DNS      53      GU-HLR   
   (结果个数 = 2)  

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称   | 输出项解释            |
|:--------|:-----------------|
| 分组名称    | DBS支持多应用共存的分组名称。 |
| 业务类型    | 分组中的业务类型ID。      |
| 业务类型名称  | 分组中的业务类型名称。      |
