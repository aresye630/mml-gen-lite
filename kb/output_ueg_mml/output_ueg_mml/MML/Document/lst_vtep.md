# 查询VXLAN隧道端点（LST VTEP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询VXLAN隧道端点信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称        | 参数说明                                                                                             |
|:---------|:------------|:-------------------------------------------------------------------------------------------------|
| VTEPNAME | VXLAN隧道端点名称 | 可选必选说明：可选参数 参数含义：该参数用于配置VXLAN隧道端点名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不区分大小写，不支持空格。 默认值：无 配置原则：无 |

#### 使用实例

查询所有隧道端点的相关信息：

```
LST VTEP:;
```

```
RETCODE = 0 操作成功。

VXLAN隧道端点信息
-----------------
VXLAN隧道端点名称  =  vtep1            
IP协议版本  =  IPV4 
隧道对端端点的IPv4地址  =  192.168.1.1
隧道对端端点的IPv6地址  =  ::
--- END
```
