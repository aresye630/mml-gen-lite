# 增加服务接口过滤列表(ADD SBIFILTERLST)

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令用于在配置数据库中增加一个服务接口过滤列表。

使用场景：在安全加固场景下，通过该命令可以设置允许接入或者禁止访问的每个服务的IP地址列表。然后通过**SET SBIFILTERPARA**命令参数的“StatCheck(静态检查参数)”来设置系统的黑名单过滤或白名单过滤。从而实现在UPCF提供服务前，对白名单内的服务访问者进行静态授权检查，对黑名单内的服务访问者禁止接入和授权。

## 注意事项

- 系统中增加的服务接口过滤列表记录数不能超过1024条。
- IPv6类型的IP地址不支持混合方式表达，即xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:d.d.d.d，其中x表示一个十六进制数（0～9或A～F），而d.d.d.d表示一个IPv4地址。
- “IPV6地址”不支持以下特殊地址的配置，其中x表示一个十六进制数（0～9或A～F）：

  - 0000:0000:0000:0000:0000:0000:0000:0000
  - FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF
  - 0000:0000:0000:0000:0000:0000:0000:0001
  - FFxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE8x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE9x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEAx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEBx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                                          |
|:-----------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FILTERNAME | 过滤器名称    | 可选必选说明：必选参数 参数含义：用于在定义某个服务化客户端过滤名单中的过滤器名称，它唯一标识一条过滤记录。 取值范围：长度不超过127位的字符串，只允许输入：0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。                                                                           |
| TYPE       | 对端类型     | 可选必选说明：必选参数 参数含义：用于标识需要进行过滤的对端服务类型。 取值范围： AMF(AMF)SMF(SMF)AF(AF)VPCF(VPCF) 默认值：无。 配置原则：无。                                                                                                     |
| IPVER      | IP版本     | 可选必选说明：必选参数 参数含义：用于指定对端IP地址类型。 取值范围：IPV4(IPV4)：IPv4地址格式，当期望过滤的对端IP地址为IPv4地址格式时使用。IPV6(IPV6)：IPv6地址格式，当期望过滤的对端IP地址为IPv6地址格式时使用。 默认值：无。 配置原则：无。                                                 |
| IPADDRV4   | IPV4地址   | 可选必选说明：可选参数。仅当“IP版本”为“IPV4(IPV4版本)”时，该参数有效。 参数含义：用于指定一个IPv4格式的对端地址。 取值范围：IPV4地址 默认值：无。 配置原则：无。                                                                                                |
| IPADDRV6   | IPV6地址   | 可选必选说明：可选参数 参数含义：用于指定一个IPv6格式的对端地址。仅当“IP版本”为“IPV6(IPV6版本)”时，该参数有效。 取值范围：IPV6地址 默认值：无。 配置原则：无。                                                                                                 |
| MASKV4     | IPV4掩码   | 可选必选说明：可选参数 参数含义：用于指定IPv4格式的对端地址所使用的子网掩码位数。仅当“IP版本”为“IPV4(IPV4版本)”时，该参数有效。 取值范围：IPv4地址 默认值：无。 配置原则：无。                                                                                         |
| MASKV6     | IPV6前缀长度 | 可选必选说明：可选参数 参数含义：用于指定IPv6格式的对端地址所使用的IPV6前缀长度。仅当“IP版本”为“IPV6(IPV6版本)”时，该参数有效。 取值范围：1～128 默认值：无。 配置原则： 如果配置IPV6前缀长度是128，则代表一条对端IP地址记录。如果配置IPV6前缀长度是1～127，则代表一个对端IP地址网段。                         |
| OPTYPE     | 操作类型     | 可选必选说明：必选参数 参数含义：用于指定配置的对端IP地址所属操作类型。 取值范围： WHITELIST(白名单)：允许接入的对端IP地址或地址网段的列表。BLACKLIST(黑名单)：不允许接入的对端IP地址或地址网段的列表。 默认值：无。 配置原则： 相同服务类型（如相同的SMF类型），白名单内部的IP不能重叠；黑名单内部的IP不能重叠。黑名单和白名单的IP段可以重叠。 |

## 使用实例

增加一个服务接口过滤列表，允许SMF访问服务。“对端类型”为“aaa”，“服务名称”为“SMF”，“IP版本”为“IPV4”，“IPV4地址”为“192.168.0.130”，“IPV4掩码”为“255.255.255.0”，“操作类型”为“WHITELIST(白名单)”。

```
ADD SBIFILTERLST: FILTERNAME="aaa", TYPE=SMF, IPVER=IPV4, IPADDRV4="192.168.0.130", MASKV4="255.255.255.0", OPTYPE=WHITELIST;
```
