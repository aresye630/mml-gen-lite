# 查询字符串匹配策略（LST STRMATCHPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF**

该命令用于查询当前系统中配置的字符串匹配策略信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                             |
|:---------|:-------|:-------------------------------------------------------------------------------------------------|
| FILEPATH | 文件路径   | 可选必选说明：可选参数  参数含义：该参数表示调用匹配策略接口的函数所在文件的绝对路径。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~255。  默认值：无  配置原则：无 |
| LINEPOS  | 行号     | 可选必选说明：可选参数  参数含义：该参数表示调用匹配策略接口的函数所在行号。  数据来源：本端规划  取值范围：整数类型，取值范围是0~65534。  默认值：无  配置原则：无       |

## 使用实例

显示系统中配置的字符串匹配规则，执行如下命令：

```
%%LST STRMATCHPLCY:;%%
RETCODE = 0  操作成功

结果如下
--------
      文件路径  =  b/test.go
          行号  =  100
字符串匹配策略  =  SENSITIVITY
        版本号  =  23.1.0
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                      |
|:--------|:---------------------------|
| 文件路径    | 该参数表示调用匹配策略接口的函数所在文件的绝对路径。 |
| 行号      | 该参数表示调用匹配策略接口的函数所在行号。      |
| 字符串匹配策略 | 该参数用于配置字符串匹配策略。            |
| 版本号     | 该参数用于配置匹配策略支持的版本号（不包括补丁号）。 |
