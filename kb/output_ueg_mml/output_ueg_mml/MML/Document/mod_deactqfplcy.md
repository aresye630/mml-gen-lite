# 修改去活用户面专有QoS Flow策略（MOD DEACTQFPLCY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于修改当SMF接收到AMF发送的去激活用户面请求时，专有QoS Flow的处理策略。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

当需要修改SMF收到AMF发起的用户面去活请求携带原因值“radio-connection-with-ue-lost”时能够延迟释放专有QoS Flow的延迟时间为20秒时，执行如下命令：

```
MOD DEACTQFPLCY: NGAPCAUSEGROUP=RADIO_NETWORK, NGAPCAUSEVALUE=21, QFPLCY=DELAY_RELEASE, DELAYTIMER=20;
```
