# 删除基础扩展团体属性过滤器节点（RMV EXTENDCOMMUNITYFILTERNODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除基础扩展团体属性过滤器节点。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称          | 参数说明                                                                                            |
|:-------------|:--------------|:------------------------------------------------------------------------------------------------|
| NAME         | 扩展团体属性过滤器名字或号 | 可选必选说明：必选参数 参数含义：该参数用于指定扩展团体属性过滤器名字或扩展团体属性过滤器号。 数据来源：本端规划 取值范围：字符串类型，团体属性过滤器名称其长度范围是1～51。 默认值：无 |
| NODESEQUENCE | 扩展团体属性过滤器节点ID | 可选必选说明：必选参数 参数含义：该参数用于指定扩展团体属性过滤器节点ID。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无             |

#### 使用实例

删除基本扩展团体属性过滤器节点：

```
RMV EXTENDCOMMUNITYFILTERNODE:NODESEQUENCE=10,NAME="a";
```
