# 查询逻辑口（LST UDGNRMINTF）

- 命令功能
- 注意事项
- 操作用户权限

- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于查询逻辑口记录。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                              |
|:--------|:---------|:----------------------------------------------------------------------------------|
| INTNAME | 保留逻辑接口名称 | 可选必选说明：可选参数 参数含义：该参数用于配置保留的逻辑接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无 |

#### 使用实例

假设需要查询名称为pgwusxif的逻辑口记录，配置如下：

```
LST UDGNRMINTF: INTNAME="pgwusxif";
```
