# 删除指定NF在NRF上的时长信息（RMV NRFNFTIMER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NRF**

该命令用于删除指定NF在NRF上的时长信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                |
|:-------------|:-------|:------------------------------------------------------------------------------------|
| NFINSTANCEID | NF实例标识 | 可选必选说明：必选参数  参数含义：该参数用于表示NF实例标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~36。  默认值：无  配置原则：无 |

## 使用实例

运营商不需要在NRF上单独设置实例标识为"88888888-6666-1234-5678-123456789ABC"的时长信息时，执行如下命令。

```
RMV NRFNFTIMER: NFINSTANCEID="88888888-4444-1234-5678-123456789ABC";
```
