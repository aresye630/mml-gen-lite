# 查询全局扩展过滤器绑定配置（LST GLBEXTFILTER）

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询全局扩展过滤器绑定关系。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询全局扩展过滤器绑定关系，使用此命令：

```
LST GLBEXTFILTER:;
```
