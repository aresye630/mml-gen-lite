# 启动园区内AMF用户迁移任务（STR OFFLOADBYEDGEAMF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

执行此操作导致用户迁移到另外一个AMF，期间会短暂下线，进而影响用户使用业务。

**适用NF：AMF**

该命令执行后，涉及到的用户均以源AMF分配5G-GUTI的方案来进行用户迁移。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

| MNC         | 移动网号        | 可选必选说明：该参数在"OFFLOADTYPE"配置为"TAIRANGE"时为条件必选参数。  参数含义：该参数用于指定按TAIRANGE迁移用户时TAI范围的移动网号。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。字符串类型，输入长度范围是2~3。本参数由2~3个十进制数字组成。  默认值：无  配置原则：无                                                                                 |

| WAITHLCOMUE | 等待高延迟UE迁移完成 | 可选必选说明：可选参数  参数含义：该参数用于指定AMF是否等待处于空闲态使用eDRX的用户都被迁移完成之后才结束迁移任务。如果本参数配置为“NO(否)”，迁移结束时可能会存在部分eDRX用户未迁移。如果本参数配置为“YES(是)”则迁移的时长会延迟（eDRX用户最大延迟60分钟）。如需停止迁移，请执行STP OFFLOADAMF。  数据来源：全网规划 取值范围： NO（否）YES（是）  默认值：无  配置原则：  如果AMF已开启eDRX功能，建议迁移时将该参数设置为“YES(是)”。 |
| IMSI        | IMSI        | 可选必选说明：该参数在"OFFLOADTYPE"配置为"IMSI"时为条件必选参数。  参数含义：该参数用于指定待迁移用户的IMSI。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是5~15。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                                                                                                   |

## 使用实例

启动园区内AMF用户迁移任务

```
STR OFFLOADBYEDGEAMF:OFFLOADTYPE=RATE,OFFLOADRATE=1,AMFPOINTER="1f";
STR OFFLOADBYEDGEAMF: OFFLOADTYPE=TAIRANGE, AMFPOINTER="1f", MCC="460", MNC="00", TACSTART="840000", TACEND="840002", WAITHLCOMUE=YES;
```
