# 查询校验状态(DSP VRYNRFDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询NRFClient内存数据或NRFClient SDK内存数据和CSP内存数据以及NRFClient内存数据和NRF数据的校验状态。

- 若要查询NRFClient、UdmSub和AUSF微服务类型的校验状态，则输入“微服务类型”为“ALL”。
- 若要查询指定“微服务类型”的校验状态，则参数“微服务类型”需要设置为具体的微服务。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                    |
|:--------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MSTYPE  | 微服务类型   | 可选必选说明：可选参数 参数含义：用于指定待查询的NRFClient内存数据或NRFClient SDK内存数据和CSP内存数据校验状态的微服务类型。 取值范围： ALL(ALL)：NRFClient内存数据或NRFClient SDK内存数据和CSP的NRFClient、UdmSub和AUSF微服务类型的校验状态。NRFClient(NRFClient)：NRFClient内存数据或NRFClient SDK内存数据和CSP的NRFClient微服务类型以及NRFClient内存数据和NRF数据的校验状态。UdmSub(UdmSub)：NRFClient内存数据或NRFClient SDK内存数据和CSP的UdmSub微服务类型的校验状态。AUSF(AUSF)：NRFClient内存数据或NRFClient SDK内存数据和CSP的AUSF微服务类型的校验状态。 默认值：ALL(ALL) 配置原则：无 |
| MSINSID | 微服务实例ID | 可选必选说明：可选参数 参数含义：用于指定待查询的NRFClient内存数据或NRFClient SDK内存数据的微服务实例ID，通过执行命令DSP UDMSERVICE来查询微服务实例ID。如果不输入，则表示所有的微服务实例ID。 取值范围：长度不超过63位的字符串。 默认值：无 配置原则：当“微服务类型”取值为“NRFClient(NRFClient)”、“UdmSub(UdmSub)”或者“AUSF(AUSF)”时，该参数有效。                                                                                                                                                                                             |

## 使用实例

1. 查询所有的校验状态。

   ```
   DSP VRYNRFDATA:MSTYPE=ALL;
   ```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                            |
|:--------|:-------------------------------------------------------------------------------------------------|
| 校验类型    | 用于标识校验类型。 取值范围： OMDATA：校验NRFClient内存数据或NRFClient SDK内存数据和CSP的内存数据。NRFDATA：校验NRFClient内存数据和NRF数据。 |
| 校验状态    | 用于标识校验状态。 取值范围： 未校验校验中校验已结束数据修复中                                                                 |
| 校验开始时间  | 用于标识校验开始时间。                                                                                      |
| 校验结束时间  | 用于标识校验结束时间。                                                                                      |
| 校验结果    | 用于标识校验结果。 取值范围： 一致不一致且修复成功不一致且修复失败任务强制停止任务异常停止                                                   |
