# 查询GTP-C路径管理自定义策略(LST GTPCPATHDP)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限

- 输出结果说明

#### 命令功能

**适用网元：SGSN**

该命令用于查询GTP-C路径管理自定义策略。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                        |
|:-------|:-------|:------------------------------------------------------------|
| RANGE  | 路径范围   | 可选必选说明：可选参数 参数含义：该参数用于指定GTP-C路径范围。 取值范围：ROAMING（漫游路径） 默认值：无 |

#### 使用实例

查询GTP-C路径管理自定义策略：

LST GTPCPATHDP:;

```
%%LST GTPCPATHDP:;%%
RETCODE = 0  操作成功。

操作结果如下
--------------
          路径范围  =  漫游路径
  故障判定钝化系数  =  2
漫游路径告警ID控制  =  公共告警ID
(结果个数 = 1)

---    END
```
