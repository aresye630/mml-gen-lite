# 清空DNS客户端的缓存消息（CLR NGREQMSGCACHE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于清空请求消息缓存链中所有缓存消息。

AMF可向系统的DNS客户端微服务查询MME，当DNS客户端相关配置命令正确，但一直查询不到MME的IP，执行该命令。

## 注意事项

- 该命令执行后立即生效。

- 该命令执行后，消息缓存链中的请求消息会丢失，不会给AMF响应。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

无

## 使用实例

清空请求消息缓存链中所有缓存消息：

```
CLR NGREQMSGCACHE:
```
