# 停止用户退出VLR故障增强状态(STP VLRFAULTEXIT)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

该命令用于停止用户退出VLR故障增强状态的任务。当系统中执行了用户退出VLR故障增强状态(STR VLRFAULTEXIT)命令时，希望中途停止退出VLR故障增强状态任务，可以执行该命令。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

无

#### 使用实例

停止用户退出VLR故障增强状态任务，可用如下命令。

```
STP VLRFAULTEXIT:;
```
