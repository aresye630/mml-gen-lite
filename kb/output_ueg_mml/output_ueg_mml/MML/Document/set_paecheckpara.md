# 设置PAE寻呼反压流控检测参数(SET PAECHECKPARA)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MME、AMF**

该命令用于设置LINK节点相关资源过载检测参数，包括link-pod内pBuf资源和PAE与虚拟交换机间消息发送队列所使用的检测周期、检测次数等信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                         |
|:--------------|:--------|:---------------------------------------------------------------------------------------------|
| CHECKINTERVAL | 检测间隔（s） | 可选必选说明：可选参数 参数含义：该参数用于表示资源过载状态的检测间隔，单位为s。 数据来源：本端规划 取值范围：整数类型，取值范围1~255。 默认值：1s 配置原则： 无      |
| CHECKTIMES    | 检测次数    | 可选必选说明：可选参数 参数含义：该参数用于表示检测结果连续超过过载阈值或低于恢复阈值的次数。 数据来源：本端规划 取值范围：整数类型，取值范围1~255。 默认值：5 配置原则： 无 |

#### 使用实例

设置PAE寻呼反压流控的检测间隔（s）为10：

```
SET PAECHECKPARA: CHECKINTERVAL=10;
```
