# 查看SCTP偶联统计信息(DSP DBSSCTPAS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查看SCTP偶联统计信息。该命令主要是用于研发的问题定位，通过该命令，可以查看FE和BE之间处理消息包的情况。

若需要查询某条SCTP偶联统计信息，请输入参数“服务模块号”和“偶联号”。

## 注意事项

无。

## 参数说明

| 参数ID      | 参数名称   | 参数描述                                                                          |
|:----------|:-------|:------------------------------------------------------------------------------|
| SERVICENO | 服务模块号  | 可选必选说明：必选参数。 参数含义：用于请求系统显示哪个DBS服务模块号的SCTP偶联统计信息。 取值范围： 1～1024 默认值： 无。 配置原则：无。 |
| AID       | 偶联号    | 可选必选说明：必选参数。 参数含义：用于请求系统显示哪个偶联号的SCTP偶联统计信息。 取值范围： 0～65534 默认值： 无。 配置原则：无。     |

## 使用实例

查看SCTP偶联统计信息，“SERVICENO”为“121”，“AID”为“5”。

```
DSP DBSSCTPAS: SERVICENO=121, AID=5;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称          | 输出项解释                                                            |
|:---------------|:-----------------------------------------------------------------|
| 偶联号            | 用于请求系统显示哪个偶联号的SCTP偶联统计信息。                                        |
| 偶联建立T1定时器超时的次数 | 用于返回当前SCTP偶联中T1（INIT/COOKIE ECHO）定时器超时的次数，该值同时体现了该SCTP偶联建立发起的次数。 |
| 数据重传T2定时器超时的次数 | 用于返回当前SCTP偶联中T2（SHUTDOWN）定时器超时的次数，该值同时也体现了数据重传的次数。               |
| 重发的数据块个数       | 用于返回当前SCTP偶联重传的DATA数据块数量。                                        |
| 发送的数据块个数       | 用于返回当前SCTP偶联发送的DATA数据块数量。                                        |
| 接收的数据块个数       | 用于返回当前SCTP偶联接收的DATA数据块数量。                                        |
| 总共接收的SCTP包个数   | 用于返回当前SCTP偶联接收的SCTP包总数。                                          |
| 错误包数           | 用于返回当前SCTP偶联接收的错误SCTP数据包数量。                                      |
| 丢弃的包数          | 用于返回被当前SCTP偶联拒绝的包数。                                              |
| 对端地址个数         | 用于返回当前SCTP偶联对端传送地址的数量。                                           |
| 对端IP地址         | 用于返回当前SCTP偶联在对端的IP地址。                                            |
| 重传数据块的个数       | 因为等待证实超时所重传的数据块数。                                                |
