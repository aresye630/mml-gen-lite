# 强制生成用户话单（CRE CHGCDR）

#### 命令功能

**适用网元：SGSN**

该命令用于强制生成用户话单M-CDR或S-CDR。如果强制生成某一个用户的话单，强制生成话单结果可以实时得到。如果强制生成所有用户的话单，强制生成话单结果需要用命令**DSP CHGCDR**查询得到。

#### 注意事项

- 该命令执行后立即生效。
- 在强制生成所有用户话单时，耗时较长，占用系统资源较大，请谨慎使用。
- 如果对指定MSISDN生成话单，则对应的所有IMSI用户均生成话单。
- 若“MSISDN”与“IMSI”都不输入，表示强制生成所有用户的话单。
- 在multi IMSI功能开启的情况下，不支持根据MSISDN来强制生成话单。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                 |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------|
| CDR    | 话单类型   | 可选必选说明：必选参数 参数含义：该参数用于标识需要生成的话单类型。 数据来源：整网规划 取值范围： “S_CDR（S_CDR）”“M_CDR（M_CDR）” 默认值：无                |
| MSISDN | MSISDN | 可选必选说明：可选参数 参数含义：该参数用于标识模拟话单中包含的MSISDN。 数据来源：整网规划 取值范围：1～15位十进制字数字 默认值：无  说明： “MSISDN”和“IMSI”不能同时输入。 |
| IMSI   | IMSI   | 可选必选说明：可选参数 参数含义：该参数用于模拟话单中包含的IMSI。 数据来源：整网规划 取值范围：1～15位十进制数字 默认值：无                                  |

#### 使用实例

1. 强制生成IMSI为“123432708000017”用户的M-CDR话单：

   CRE CHGCDR: CDR=M\_CDR, IMSI="123432708000017";
2. 强制生成MSISDN为“8613902100004”用户的S-CDR话单：

   CRE CHGCDR: CDR=S\_CDR, MSISDN="8613902100004";
