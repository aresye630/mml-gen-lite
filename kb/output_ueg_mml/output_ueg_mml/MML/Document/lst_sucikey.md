# 查询SUCI密钥(LST SUCIKEY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询所有SUCI私钥记录信息：

- 若需要查询全部的SUCI私钥记录，请不要输入任何参数。
- 若需要查询某条SUCI私钥记录的详细信息，请输入参数“Key名称”。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                          |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------------|
| KEYNAME | Key名称  | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个Key名称来查询SUCI私钥记录；若不输入，则表示所有的SUCI私钥记录。 取值范围：1～16个字母、数字或特殊字符组成的字符串。 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询全部的SUCI私钥记录。

   ```
   LST SUCIKEY:;
   ```

   ```
   %%LST SUCIKEY:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   Key名称  SUCI 密钥类型  SUCI 密钥ID  归属网络标识  路由指示符  保存方式           SUCI密钥值  HSM密钥索引  

   key1     SUCI密钥类型A  1            35621         1342        SUCIKEY保存在HSM   *****       Profile:A:1
   key2     SUCI密钥类型B  3            35625         1346        SUCIKEY保存在本地  *****       NULL 
   key3     SUCI密钥类型A  5            FFFFFF        FFFF        SUCIKEY保存在本地  *****       NULL 
   (结果个数 = 3)

   ---    END
   ```
2. 查询“Key名称”为“key1”的SUCI私钥记录。

   ```
   LST SUCIKEY: KEYNAME="key1";
   ```

   ```
   %%LST SUCIKEY: KEYNAME="key1";%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
         Key名称  =  key1
   SUCI 密钥类型  =  SUCI密钥类型A
     SUCI 密钥ID  =  1
    归属网络标识  =  35621
      路由指示符  =  1342
        保存方式  =  SUCIKEY保存在HSM
      SUCI密钥值  =  *****
     HSM密钥索引  =  Profile:A:1
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD SUCIKEY**命令的参数说明。
