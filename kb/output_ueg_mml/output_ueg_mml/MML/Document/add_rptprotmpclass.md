# 增加业务报表映射承载协议分类配置（ADD RPTPROTMPCLASS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于增加业务报表映射承载协议分类配置。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为128。
- 该命令中的参数MpProtClassIdx取值需要和运营商协商，不可私自定义。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称       | 参数说明                                                                                            |
|:---------------|:-----------|:------------------------------------------------------------------------------------------------|
| MPPROTCLASSNM  | 映射承载协议分类名称 | 可选必选说明：必选参数 参数含义：该参数用于设置映射承载协议分类名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |
| MPPROTCLASSIDX | 映射承载协议分类索引 | 可选必选说明：必选参数 参数含义：该参数用于设置映射承载协议分类索引。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无 配置原则：无              |
| CFGDOMAINNAME  | 配置域名称      | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无              |

#### 使用实例

假如运营商需要增加一个业务报表映射承载协议分类配置：

```
ADD RPTPROTMPCLASS: MPPROTCLASSNM="p2p", MPPROTCLASSIDX=10;
```
