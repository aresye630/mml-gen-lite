# 修改替换AS路径值（MOD ASPATHSTRING）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令修改AS路径属性的操作值。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                                                  |
|:---------------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------|
| POLICYNAME     | 路由策略名字   | 可选必选说明：必选参数 参数含义：该参数用于指定路由策略名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无 配置原则：区分大小写。                                                                  |
| NODESEQUENCE   | 路由策略节点号  | 可选必选说明：必选参数 参数含义：该参数用于指定路由策略节点号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无                                                                              |
| SEQUENCENUMBER | AS属性值序列号 | 可选必选说明：必选参数 参数含义：该参数用于指定AS属性值序列号。序列号只能是1~63之间的数字。 数据来源：本端规划 取值范围：整数类型，取值范围为1～63。 默认值：无                                                                |
| STRINGVALUE    | AS路径值    | 可选必选说明：必选参数 参数含义：该参数用于指定AS属性值。支持两种格式的AS值： 1.整数形式，取值范围是1~4294967295。 2.点分式，形式为number<1-65535>.number<0-65535>。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～11。 默认值：无 |

#### 使用实例

修改AS路径属性的操作值：

```
MOD ASPATHSTRING:POLICYNAME="a",NODESEQUENCE=10,SEQUENCENUMBER=7,STRINGVALUE="30";
```
