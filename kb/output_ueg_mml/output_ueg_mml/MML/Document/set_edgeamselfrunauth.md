# 设置AMF自运行授权配置（SET EDGEAMSELFRUNAUTH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于设置AMF自运行授权开关及自运行定时器小时数，防止园区设备长期处于自运行状态。

## 注意事项

- 该命令执行后立即生效。

- 当前园区系统存在两套自运行授权配置，分别为SET EMERGAUTHTIMER和SET EDGEAMSELFRUNAUTH，用于设置园区自运行的持续时长，避免用户长期在园区接入运行。其中SET EMERGAUTHTIMER适用于风筝M，园区UPF与大网SMF断链，且用户从应急SMF接入的场景，授权时长控制点主要在UPF。SET EDGEAMSELFRUNAUTH适用于风筝L，园区AMF与大网UDM断链，且用户从应急UDM接入的场景，授权时长控制点主要在AMF。请根据网络布局设计对应的配置。
- 系统内部每10秒刷新一次自运行授权状态，命令执行后会延迟10秒生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| SWITCH   |   INTERVAL |
|:---------|-----------:|
| DISABLE  |       1024 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                                                                                                            |
|:---------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SWITCH   | 自运行授权开关 | 可选必选说明：必选参数  参数含义：该参数用于设置是否开启自运行授权功能。  数据来源：本端规划 取值范围： DISABLE（不使能）ENABLE（使能）  默认值：无。  配置原则：  如果参数设置为ENABLE，表示开启自运行授权开关，超过自运行定时器小时数，系统去活所有用户，并拒绝所有用户接入。如果参数设置为DISABLE，表示关闭自运行授权开关，此时新用户均可以在园区接入并持续运行。                                                           |
| INTERVAL | 时长（小时）  | 可选必选说明：该参数在"SWITCH"配置为"ENABLE"时为条件必选参数。  参数含义：该参数用于设置自运行定时器小时数。（当自运行授权开关为DISABLE时，自运行定时器小时数的值没有意义）。  数据来源：本端规划  取值范围：整数类型，取值范围是1~1024，单位是小时。  默认值：无。执行命令并不输入该参数时，该参数保持系统当前配置不变，可通过LST EDGEAMSELFRUNAUTH查询当前参数配置值。  配置原则：  与运营商协商在园区与中心网络的传输中断时允许园区设备处于自运行状态的时长。 |

## 使用实例

设置开启自运行授权功能，并指定自运行定时器小时数为2，执行如下命令：

```
SET EDGEAMSELFRUNAUTH: SWITCH=ENABLE, INTERVAL=2;
```
