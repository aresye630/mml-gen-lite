# 查询以太ACL规则匹配详细计数（DSP ACLETHRULECNTVERBOSE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询以太ACL规则的匹配计数详细信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                            |
|:------------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ACLNAME     | ACL规则组标识 | 可选必选说明：必选参数 参数含义：该参数用于指定所要查询计数的规则属于哪个规则组。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。可以指定字符串形式的ACL名称或者整数形式的ACL编号：字符串形式，不支持空格，区分大小写，以英文字母a～z或A～Z开始，可以是英文字母、数字、连字符“-”、下划线“_”或中文字符的组合。 默认值：无 |
| ACLRULENAME | 规则名称     | 可选必选说明：必选参数 参数含义：该参数用于指定所要查询计数的规则名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。不支持空格，区分大小写。 默认值：无                                                                                        |

#### 使用实例

查询当前ACL规则组4000下规则名称为"rule\_5"的详细匹配计数：

```
DSP ACLETHRULECNTVERBOSE:ACLNAME="4000",ACLRULENAME="rule_5";
```

```
RETCODE = 0  操作成功。

结果如下
--------
  ACL规则组标识  =  4000
       规则名称  =  rule_5
引用ACL的组件名  =  OCRM80840074
       匹配计数  =  0
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称     | 输出项解释            |
|:----------|:-----------------|
| 引用ACL的组件名 | 用于显示引用ACL的APP名称。 |
| 匹配计数      | 用于显示规则的匹配计数。     |

其余输出项请参见LST ACLGROUP的参数说明。
