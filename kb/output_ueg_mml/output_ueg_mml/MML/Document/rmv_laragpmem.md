# 删除位置区群组成员(RMV LARAGPMEM)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN**

此命令用于删除一个区域群的一条位置区或路由区类型的成员记录

#### 注意事项

- 此命令执行后立即生效。
- 删除位置区域群组成员时必须保证区域限制相关表中不存在该位置区域群组成员对应的区域群的相关记录。可执行**LST GBSUBRRLST**和**LST IUSUBRRLST**查看区域限制相关表的记录。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                                              |
|:---------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LARAGPID | 区域群标识   | 可选必选说明：必选参数 参数含义：该参数用于指定待删除的位置区和路由区的区域群标识。 数据来源：整网规划 取值范围：1～2048 默认值：无                                                                                                                            |
| IDTYPE   | 标识类型    | 可选必选说明：必选参数 参数含义：该参数用于指定待删除的区域的标识类型。 数据来源：整网规划 取值范围： “LA(位置区)”：表示该区域标识类型为位置区。“RA(路由区)”：表示该区域标识类型为路由区。 默认值：无                                                                                       |
| MCC      | 移动国家码   | 可选必选说明：条件必选参数 参数含义：该参数用于指定待删除的移动国家码。 前提条件：该参数在“IDTYPE(标识类型)”设置为“LA(位置区)”或“RA(路由区)”时生效。 数据来源：整网规划 取值范围：3位的十进制数字 默认值：无                                                                              |
| MNC      | 移动网号    | 可选必选说明：条件必选参数 参数含义：该参数用于指定待删除的移动网号。 前提条件：该参数在“IDTYPE(标识类型)”设置为“LA(位置区)”或“RA(路由区)”时生效。 数据来源：整网规划 取值范围：2～3位的十进制数字 默认值：无                                                                             |
| LAC      | 位置区域码   | 可选必选说明：条件必选参数 参数含义：该参数用于指定待删除的位置区域码。 前提条件：该参数在“IDTYPE(标识类型)”设置为“LA(位置区)”或“RA(路由区)”时生效。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无                                                                         |
| LACRANGE | 位置区域码范围 | 可选必选说明：可选参数 参数含义：该参数用于指定待删除的位置区域码范围。 前提条件：该参数在“IDTYPE(标识类型)”设置为“LA(位置区)”时生效。 数据来源：整网规划 取值范围：0x0000～0xFFFF 默认值：无 配置原则：该参数的取值需要大于或等于“LAC”。  说明： 该参数与“LAC”参数构成一个LAC区段，方便客户配置连续的位置区域。如果不输入，表示配置单个LAC。 |
| RAC      | 路由区域码   | 可选必选说明：条件必选参数 参数含义：该参数用于指定待删除的路由区域码。 前提条件：该参数在“IDTYPE(标识类型)”设置为“RA(路由区)”时生效。 数据来源：整网规划 取值范围：0x00～0xFF 默认值：无                                                                                       |
| RACRANGE | 路由区域码范围 | 可选必选说明：可选参数 参数含义：该参数用于指定待删除的路由区域码范围。 前提条件：该参数在“IDTYPE(标识类型)”设置为“RA(路由区)”时生效。 数据来源：整网规划 取值范围：0x00～0xFF 默认值：无 配置原则：该参数的取值需要大于或等于“RAC”。  说明： 该参数与“RAC”参数构成一个RAC区段，方便客户配置连续的路由区域。如果不输入，表示配置单个RAC。     |

#### 使用实例

删除一个跟踪区群组标识为55，标识类型为“LA(位置区)”，群组成员的移动国家码为123，移动网号为05，跟踪区域码为0x1234的记录：

RMV LARAGPMEM: LARAGPID=55, IDTYPE=LA, MCC="123", MNC="05", LAC="0x1234";
