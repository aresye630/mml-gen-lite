# 查询KPI监控参数(LST KPIMONPARA)

- 命令功能

- 本地用户权限

#### 命令功能

**适用网元：SGSN、MME**

该命令用于查询KPI监控功能的参数。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询KPI监控功能的参数：

`LST KPIMONPARA:;`

```
%%LST KPIMONPARA:;%%
RETCODE = 0  操作成功

操作结果如下：
--------------
 监控粒度=单进程
  监控开关= 打开  
关闭类型 =NULL 
关闭时长(分)= NULL   
告警开关=打开  
告警间隔周期（分）=60  
告警次数=3  
自愈开关=打开                               
(结果个数 = 1)

---    END
```

#### 输出结果说明

其中，参数值显示为“NULL”的表示没有实现该功能。其他参数，请参考命令**SET KPIMONPARA**的参数标识。
