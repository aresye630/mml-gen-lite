# 查询通知服务系统软参(LST NTSSSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询NTS系统软件参数的配置信息。

- 若需要查询全部软参数据记录的概要信息，请不要输入任何参数。
- 若需要查询某条参数数据记录的详细信息，请输入“系统配置参数”和“参数名”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
|:-------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SCP    | 系统配置参数  | 可选必选说明：可选参数 参数含义：用于指示系统按照系统配置参数来查询NTS系统软参；若不输入，则表示所有的系统配置参数。 取值范围： SYSPARAMETER(系统参数) 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| SPN    | 参数名     | 可选必选说明：可选参数 参数含义：用于指示系统按照参数名来查询NTS系统软参；若不输入，则表示所有的参数名。 取值范围： VRM_NTSCRLPOLICY(NTS数字证书CRL处理策略)VRM_NOTIFYRESENDINTERVAL(用户通知重发时间间隔)VRM_NOTIFYRESENDTIMES(用户通知重发次数)VRM_NOTIFYSENDSPEED(消息通知发送速度)VRM_NTFSENDCONTROL(通知重发控制)VRM_NTFRESENDTIMERANGE(重发通知有效期)VRM_NOTIFYSENDVALTIME(待发通知有效期)VRM_NOTIFYEXPORTTYPE(历史通知导出类型)VRM_NOTIFYRECOVERYVALUE(用户通知链路告警恢复阈值)VRM_NOTIFYALARMVALUE(用户通知链路告警上报阈值)VRM_NOTIFYWAITTEDALMTH(通知待发文件堆积告警阈值)VRM_NOTIFYRESENDALMTH(通知重发文件堆积告警阈值)VRM_NOTIFYALMTIME(通知文件堆积告警时长)VRM_NTSLINKPASSWDENCRYALGORITHM(NTS通知链路密码加密算法)VRM_SMTPHEARTBEATSWITCH（SMTP心跳开关） 详细信息请参考产品手册的“软件参数 > UPCF软件参数 > NTS系统参数”。 默认值：无。 配置原则：无。 |
| SPV    | 参数值     | 可选必选说明：可选参数 参数含义：用于指示系统按照参数值来查询NTS系统软参；若不输入，则表示所有的参数值。 取值范围：0～2147483647 详细信息请参考产品手册的“软件参数 > UPCF软件参数 > NTS系统参数”。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| DFTV   | 软件参数默认值 | 可选必选说明：可选参数 参数含义：用于指示系统按照软件参数默认值来查询NTS系统软参；若不输入，则表示所有的软件参数默认值。 取值范围：0～2147483647 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

## 使用实例

1. 查询NTS服务全部软参配置信息。

   ```
   LST NTSSSP:;
   ```

   ```
   LST NTSSSP: SCP=SYSPARAMETER, SPN=VRM_NTSCRLPOLICY;
   ```

   ```
   %%LST NTSSSP: SCP=SYSPARAMETER, SPN=VRM_NTSCRLPOLICY;%%

           参数名  =  NTS数字证书CRL处理策略
           参数值  =  0
   软件参数默认值  =  0
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**MOD NTSSSP**命令的参数说明。
