# 查询ND安全时间戳（DSP NDSECURITYTIMESTAMP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示ND安全时间戳。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                |
|:-------|:-------|:----------------------------------------------------------------------------------------------------|
| IFNAME | 接口名    | 可选必选说明：必选参数 参数含义：该参数用于指定接口名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。 |

#### 使用实例

显示ND安全时间戳：

```
DSP NDSECURITYTIMESTAMP:IFNAME="Ethernet65/0/8";
```

```
        RETCODE = 0  操作成功
        结果如下
        -------------------------
                                IPv6地址  =  2001:db8::11
        接收的上一个SEND报文中的时间戳值  =  1500
           接收上一个SEND报文的时间（s）  =  1500
        (结果个数 = 1)
        ---    END
```

#### 输出结果说明

| 输出项名称              | 输出项解释                   |
|:-------------------|:------------------------|
| IPv6地址             | 用于显示IPv6地址。             |
| 接收的上一个SEND报文中的时间戳值 | 用于显示接收的上一个SEND报文中的时间戳值。 |
| 接收上一个SEND报文的时间（s）  | 用于显示接收上一个SEND报文的时间（s）。  |
