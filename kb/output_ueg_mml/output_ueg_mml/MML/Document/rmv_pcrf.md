# 删除PCRF实体(RMV PCRF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

- 此命令是高危命令，如果执行不当会导致系统异常，影响业务处理，需联系华为技术支持确认后再执行。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令为配置类命令，用于从配置数据库中删除一条本端PCRF实体数据记录。

## 注意事项

删除了PCRF功能实体，业务功能不可用。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                   |
|:-------|:-------|:---------------------------------------|
| PCRFID | PCRF标识 | 用于在UPCF配置库中定义一个PCRF功能实体。 取值范围：1 默认值：无。 |

## 使用实例

删除本端PCRF实体。PCRF实体标识为1。

```
RMV PCRF: PCRFID=1;
```
