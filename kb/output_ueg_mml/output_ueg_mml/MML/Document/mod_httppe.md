# 修改对端HTTP实体(MOD HTTPPE)

## 命令功能

该命令用于对配置数据库中的一个对端HTTP实体数据记录的某些参数进行修改或调整。在该命令中，系统通过“对端HTTP实体标识”参数来唯一标识一个对端HTTP实体数据记录。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

执行该命令配置“对端域名”取值需要与命令**MOD HTTPPEHOST**中配置的对端域名保持一致。

## 参数说明

| 参数标识    | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                               |
|:--------|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PEID    | 对端HTTP实体标识 | 标识一条对端HTTP实体数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪一条对端HTTP实体数据记录的参数进行修改或调整，操作员可以使用LST HTTPPE命令查询获得。 取值范围：0～255。 默认值：无。 注意：该参数为必选参数。                                                                                                                                                                        |
| HOST    | 对端域名       | 用于指定标识HTTP对端实体的FQDN。对端域名与对端HTTP实体一一对应。 需要指出的是，该参数不区分大小写，在执行LST HTTPPE命令查询出的报文中为全小写形式。 取值范围：长度不超过127的字符串。 默认值：无。 注意：该参数为可选参数。                                                                                                                                                                       |
| PENAME  | 对端HTTP实体名  | 用于指定对端HTTP实体的名称。 取值范围：长度不超过127的字符串。 默认值：无。 注意：该参数为可选参数。                                                                                                                                                                                                                                            |
| LNKSMOD | 链路集选择模式    | 用于在配置数据库中指定当前对端实体与AS之间的链路集选择模式。若业务量较大，为了减少单条链路上的信令流流量，可采用轮询法；若业务量较少，可采用主备方式。 取值范围：POLLING(轮询法)：对HTTP实体下的所有链路集轮流选择，即在可用对端的链路集之间循环选择链路集。AORS(主备方式)：当前只有一条链路集主用，其余链路集都是备用。只有当主用链路集下的链路全部失效时，次优先级链路集启用为主用链路集。 说明： 链路集优先级由本命令定义的对端实体关联的ADD HTTPRSRV命令中定义的“链路集参数ID”参数取值控制，取值越小优先级越高。 默认值：无。 注意：该参数为可选参数。 |

## 使用实例

修改“对端HTTP实体标识”为“1”的对端HTTP实体，携带以下参数：

- “对端HTTP实体标识”为“1”
- “对端域名”为“ap.huawei.com”
- “对端HTTP实体名”为“ap”
- “链路选择模式”为“POLLING”

执行命令如下：

```
MOD HTTPPE: PEID=1, HOST="ap.huawei.com", PENAME="ap", LNKSMOD=POLLING;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                | 原因分析                         | 处理建议                                                                                                        |
|-------:|:---------------------|:-----------------------------|:------------------------------------------------------------------------------------------------------------|
| 360276 | 当前HTTP的对端域名被引用，不能操作。 | 待修改的对端HTTP实体信息对应的“对端域名”已被引用。 | 请按照以下步骤进行操作： 执行LST HTTPPE命令，查询已存在的对端HTTP实体记录。执行LST HTTPRSRV命令，查询已存在的远端服务器配置。执行该命令，重新输入已存在且未被引用“对端HTTP实体标识”。 |
