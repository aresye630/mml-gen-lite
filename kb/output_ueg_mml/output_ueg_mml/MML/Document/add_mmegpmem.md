# 增加MME群组成员(ADD MMEGPMEM)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

此命令用于为**ADD MMEGP**增加的MME群组添加一条成员记录。

#### 注意事项

- 该命令执行后立即生效。
- 此命令最大记录数为1024。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                            |
|:---------|:--------|:--------------------------------------------------------------------------------------------------------------------------------|
| MMEGPIDX | MME群组索引 | 可选必选说明：必选参数 参数含义：该参数用于指定MME群组索引。 数据来源：全网规划 取值范围：0~63 默认值：无 配置原则：“MME群组索引”已在ADD MMEGP中配置。                                        |
| MMEC     | MME编码   | 可选必选说明：必选参数 参数含义：该参数用于指定MME组内的MME编码。 前提条件：无 数据来源：全网规划 取值范围：2位16进制编码 默认值：无 配置原则：每个“MME群组索引”下最多配置32个MMEC。每个“MME群组索引”下配置的MMEC不能重复。 |
| CAP      | 设备能力    | 可选必选说明：可选参数 参数含义：该参数用于指定MME负荷能力在MME群组中的相对权重值。权重值越大优先级越高。 前提条件：无 数据来源：全网规划 取值范围：0~255 默认值：255 配置原则：MME群组中的MME成员的设备能力可以根据此参数进行调节。 |

#### 使用实例

1. 增加MME群组索引 =1，MME编码 =11，设备能力 =255的记录。

   ADD MMEGPMEM: MMEGPIDX=1, MMEC="11";
