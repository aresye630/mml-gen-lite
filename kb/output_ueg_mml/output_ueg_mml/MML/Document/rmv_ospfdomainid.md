# 删除OSPF域标识配置（RMV OSPFDOMAINID）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于恢复OSPF域标识符默认值。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称     | 参数说明                                                                                                                                |
|:----------------|:---------|:------------------------------------------------------------------------------------------------------------------------------------|
| PROCID          | 进程号      | 可选必选说明：必选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无                                                              |
| DOMAINID        | 域标识      | 可选必选说明：必选参数 参数含义：域标识。 数据来源：本端规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无                                                                        |
| DOMAINTYPEVALUE | 域标识符类型的值 | 可选必选说明：可选参数 参数含义：指定OSPF域标识符类型的值。 数据来源：本端规划 取值范围：十六进制整数类型，取值范围为0x0～0xFFFF。 默认值：无                                                     |
| DOMAINIDTYPE    | 域标识符的类型  | 可选必选说明：可选参数 参数含义：指定OSPF域标识符的类型。 数据来源：本端规划 取值范围：枚举类型。 Type0005：Type0005。Type0105：Type0105。Type0205：Type0205。Type8005：Type8005。 默认值：无 |

#### 使用实例

恢复OSPF进程1 VPN扩展中的默认VPN域标识符：

```
RMV OSPFDOMAINID:PROCID=1,DOMAINID="10.1.1.1",DOMAINTYPEVALUE="150",DOMAINIDTYPE=Type0005;
```
