# 删除区域性能统计对象和TAC段的绑定关系（RMV PERFREGTAC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SGW-C**

该命令用于删除区域性能统计对象和TAC段的绑定关系。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                |
|:-----------|:-------|:------------------------------------------------------------------------------------------------------------------------------------|
| REGNAME    | 区域名称   | 可选必选说明：必选参数  参数含义：该参数用于指定与TAC段绑定的区域名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。不支持空格，不区分大小写。  默认值：无  配置原则：  该参数使用ADD PERFREGION命令配置生成。   |
| TACSEGNAME | TAC段名称 | 可选必选说明：必选参数  参数含义：该参数用于指定与区域绑定的TAC段名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。不支持空格，不区分大小写。  默认值：无  配置原则：  该参数使用ADD PERFS1TACSEG命令配置生成。 |

## 使用实例

当运营商需要删除一个区域性能统计对象绑定的TAC号段时，执行如下命令：

```
RMV PERFREGTAC: REGNAME="beijing", TACSEGNAME="changping";
```
