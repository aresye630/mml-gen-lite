# 增加用于策略控制的网络切片群组成员（ADD PLCYNSGRPMEM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于为应用于AM策略或者UE策略控制的网络切片群组添加成员。

## 注意事项

- 该命令执行后立即生效。

- 一个群组内可添加的最大网络切片数量是128。

- 最多可输入128条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                                                     |
|:--------|:---------|:-------------------------------------------------------------------------------------------------------------------------|
| NSGRPID | 网络切片群组标识 | 可选必选说明：必选参数  参数含义：该参数用于指定网络切片群组标识。  数据来源：本端规划  取值范围：整数类型，取值范围是1~16。本参数通过ADD PLCYNSGRP命令进行配置。  默认值：无  配置原则：无              |
| NSIDX   | 网络切片索引   | 可选必选说明：必选参数  参数含义：该参数用于指定控制AM策略或UE策略的网络切片。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。本参数通过ADD PLMNNS命令进行配置。  默认值：无  配置原则：无 |

## 使用实例

将eMBB这个网络切片（索引为18）添加到策略控制群组（组ID为6），执行如下命令：

```
ADD PLCYNSGRPMEM: NSGRPID=6, NSIDX=18;
```
