# 添加HLB对端链路(ADD HLBPEERL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条HLB设备与对端实体的链路数据记录。

该命令在特定场景下才能使用，如需使用该命令增加HLB对端链路请联系华为技术支持。

## 注意事项

- 在该命令中，以下关键参数需要与对端服务器协商：
  - “对端IPV4地址”
  - “对端IPV6地址”
  - “对端端口”

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                                             |
|:----------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PEERID    | 对端标识     | 可选必选说明：必选参数 参数含义：用于定义HLB对端设备的标识。 取值范围：0～63 默认值：无。 配置原则： 该参数必须先由ADD HLBPEER命令定义，然后才能在此处引用。                                                                        |
| LINKID    | 链路标识     | 可选必选说明：必选参数 参数含义：用于定义HLB的一个对端链路。 取值范围：0 默认值：无。 配置原则：无。                                                                                                           |
| IPVER     | IP版本     | 可选必选说明：必选参数 参数含义：用于指定HLB本端和对端的IP地址版本。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。                                                               |
| LOCALIP   | 本端IPV4地址 | 可选必选说明：可选参数 参数含义：表示HLB与对端设备对接的参数之一，用于指定链路使用的本端IPV4地址，仅当“IP版本”选择“IPV4(IPV4)”时，可设置该参数。 取值范围：IPV4地址 默认值：无。 配置原则：此IP地址必须是本地实际的IP地址且必须先由ADD HLBDEVADDR命令定义，然后才能在此处引用。 |
| LOCALIPV6 | 本端IPV6地址 | 可选必选说明：可选参数 参数含义：表示HLB与对端设备对接的参数之一，用于指定链路使用的本端IPV6地址，仅当“IP版本”选择“IPV6(IPV6)”时，可设置该参数。 取值范围：IPV6地址 默认值：无。 配置原则：此IP地址必须是本地实际的IP地址且必须先由ADD HLBDEVADDR命令定义，然后才能在此处引用。 |
| PEERIP    | 对端IPV4地址 | 可选必选说明：可选参数 参数含义：表示HLB与对端设备对接的参数之一，用于指定链路使用的对端IPV4地址，此IP地址需要与对端协商一致。仅当“IP版本”选择“IPV4(IPV4)”时，可设置该参数。 取值范围：IPV4地址 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。                |
| PEERIPV6  | 对端IPV6地址 | 可选必选说明：可选参数 参数含义：表示HLB与对端设备对接的参数之一，用于指定链路使用的对端IPV6地址，此IP地址需要与对端协商一致。仅当“IP版本”选择“IPV6(IPV6)”时，可设置该参数。 取值范围：IPV6地址 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。                |
| PEERPORT  | 对端端口号    | 可选必选说明：必选参数 参数含义：表示HLB与对端设备对接的参数之一，用于指定链路使用的对端端口，此IP端口需要与对端协商一致。 取值范围：1～65535 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。                                                  |

## 使用实例

增加HLB和对端实体的链路配置。“对端标识”为“1”，“链路标识”为“0”，“IP版本”为“IPV4(IPV4)”，“本端IPV4地址”为“10 .173.8.128”，“对端IPV4地址”为“10.173.7.128”，“对端端口号”为“2”。

```
ADD HLBPEERL: PEERID=1, LINKID=0, IPVER=IPV4, LOCALIP="10.173.8.128", PEERIP="10.173.7.128", PEERPORT=2;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释           | 原因分析                                        | 处理建议                                                                |
|------:|:----------------|:--------------------------------------------|:--------------------------------------------------------------------|
| 53051 | 对端IP地址和端口已经在使用。 | 输入的对端IP地址和端口已经在使用。                          | 执行LST HLBPEERL命令查询系统中已存在的链路对端IP地址和端口，重新输入对端IP地址和端口号，确保取值不与查询结果存在重复。 |
| 57192 | 本地IP地址不存在。      | 输入的本端IP地址不存在，没有提前通过ADD HLBDEVADDR命令配置该本地IP。 | 执行LST HLBDEVADDR命令查询已配置的本端IP地址，输入查询到的IP地址后，重新执行该命令。                 |
| 57932 | HLBPEER对象不存在。   | 输入的对端标识不存在，没有提前通过ADD HLBPEER配置该对端标识。        | 执行LST HLBPEER命令查询已配置的对端信息，输入查询到的对端标识后，重新执行该命令。                      |
