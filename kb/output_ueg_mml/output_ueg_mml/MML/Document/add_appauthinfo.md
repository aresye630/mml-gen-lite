# 添加APP授权信息（ADD APPAUTHINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

该命令用于添加APP的授权信息，包括被授予访问权限的APP的身份信息和该APP可访问的授权服务列表。当APP被授予访问该授权服务列表的权限后，APP可访问该列表中的所有授权服务；授权服务指允许APP通过MEP平台访问的服务，包括1）通过MM5接口注册的服务；2）通过MP1接口注册的服务；3）MEP平台自身提供的服务。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为500。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称     | 参数说明                                                                                                                  |
|:----------------|:---------|:----------------------------------------------------------------------------------------------------------------------|
| APPID           | APP标识    | 可选必选说明：必选参数 参数含义：该参数用于指定APP访问MEC服务时的标识。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“_”组成。 默认值：无 配置原则：无            |
| APIKEY          | APP访问凭证  | 可选必选说明：必选参数 参数含义：该参数用于指定APP访问MEC服务时的凭证信息。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为40～60。由大小写字母，数字组成，不能和APPID取值相同。 默认值：无 配置原则：无    |
| SERVICELISTNAME | 授权服务列表名称 | 可选必选说明：必选参数 参数含义：该参数用于指定该APPID可访问的授权服务列表名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：该参数使用ADD AUTHSERVLIST命令配置生成。 |

#### 使用实例

添加APP授权信息，app标识为"app1"，app访问凭证为"123456789123456789123456789123456789123456789"，该APP可访问的服务列表为"serviceList"：

```
ADD APPAUTHINFO: APPID="app1", APIKEY="123456789123456789123456789123456789123456789", SERVICELISTNAME="serviceList";
```
