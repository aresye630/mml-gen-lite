# 增加归属网络信息(ADD HNOINFO)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：SGSN、MME**

该命令用于增加归属网络信息。

#### 注意事项

- 此命令最大记录数为192。
- 此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                                                                                                                                       |
|:--------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NOID    | 运营商标识   | 可选必选说明：必选参数 参数含义：该参数用于指定运营商标识。 数据来源：整网规划 取值范围：0～64，128～254 默认值：无 配置原则：若该参数需要配置为0或128～254之间的值时，请先在ADD MNO中配置取值相同的“MNOID”参数。若该参数需要配置为1～64之间的值时，须先在ADD MVNO中配置取值相同的“MVNOID”参数。                                                                |
| SGSNN   | 本局SGSN号 | 可选必选说明：可选参数 参数含义：该参数用于指定服务GPRS支持节点（SGSN）号码，是SGSN的E.164地址。 前提条件：该参数已增加，参见ADD SCCPOPC。 数据来源：整网规划 取值范围：1～16位十进制数 默认值：无  说明： 系统获取本端SGSN号的策略： 如果IMSICHAR表配置了，从IMSICHAR表中获取。如果IMSICHAR中没有配置，则从HNOINFO表中获取。如果IMSICHAR和HNOINFO都没有配置，则从SCCPOPC表中获取。 |
| LOINDEX | 本地实体索引  | 可选必选说明：可选参数 参数含义：该参数用于指定Diameter链路集对应的本地实体的索引。 前提条件：在“MML命令行-UEG”窗口上执行命令ADD CPDMLE设置此参数。 数据来源：本端规划 取值范围：0～31 默认值：无  说明： 系统获取Diameter链路集对应的本地实体索引的策略： 如果IMSICHAR表配置了，从IMSICHAR表中获取。如果IMSICHAR中没有配置，则从HNOINFO表中获取。                           |

#### 使用实例

增加一个HNOINFO，“运营商标识”为“128”，“本局SGSN号”为“123”：

ADD HNOINFO: NOID=128, SGSNN="123";
