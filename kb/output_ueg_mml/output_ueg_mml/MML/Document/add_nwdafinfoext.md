# 增加NWDAF扩展信息（ADD NWDAFINFOEXT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：NWDAF**

该命令用于增加NWDAF实例扩展信息，即向NRF注册时携带的NwdafInfoList。

## 注意事项

- 该命令执行后立即生效。

- 最多可输入32条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识         | 参数名称      | 参数说明                                                                                                                                                                                   |
|:-------------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INSTANCENAME | NWDAF实例名称 | 可选必选说明：必选参数  参数含义：该参数用于唯一指定某一个NWDAF实例。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~50。本参数的构成字符只能是字母A~Z或a~z、数字0~9、下划线“_”和中划线“-”，例如，NWDAF_Instance_0。  默认值：无  配置原则：  本参数来源于ADD NFUUID命令中的“NF实例名称”参数。 |
| ID           | ID        | 可选必选说明：必选参数  参数含义：该参数用于唯一标识NWDAF实例中的某个NwdafInfo。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~32。本参数的构成字符只能是字母A~Z或a~z、数字0~9、下划线“_”和中划线“-”。该参数大小写不敏感。  默认值：无  配置原则：无                                 |
| NWDAFEVENTS  | NWDAF事件类型 | 可选必选说明：必选参数  参数含义：该参数用于指定NWDAF支持的分析事件类型。  数据来源：本端规划 取值范围： QOS_ANALYSIS（QOS分析）QOS_EXP_ANALYSIS（体验感知信息分析）  默认值：无  配置原则：无                                                                 |

## 使用实例

增加NWDAF扩展信息配置，NWDAF实例名称为NWDAF\_Instance\_0，ID是central，支持的NWADFEVENTS类型为QOS\_ANALYSIS：

```
ADD NWDAFINFOEXT: INSTANCENAME="NWDAF_Instance_0", ID="central",NWDAFEVENTS=QOS_ANALYSIS-1;
```
