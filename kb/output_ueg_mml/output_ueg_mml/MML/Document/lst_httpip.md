# 查询HTTP IP(LST HTTPIP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于微服务查询对外提供的信令HTTP IP地址。

- 若需要查询所有的HTTP IP地址，不需要输入参数。
- 若需要查询某条“IP名称”对应的HTTP IP地址，请输入“IP名称”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                  |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------|
| IPNAME | IP名称   | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个IP名称来查询特定的IP地址数据；若不输入，则表示所有的IP地址数据。 取值范围：长度不超过128的由数字和字母组成的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询所有对外提供的HTTP IP地址信息：

   ```
   LST HTTPIP:;
   ```

   ```
   %%LST HTTPIP:;%%
   RETCODE = 0  操作成功

   IP名称    IP地址类型  IPV4地址        IPV6地址                   VPNINFO名称    最大传输单元(byte)      DSCP值      HTTP IP索引

   IP1       IPV4        192.168.177.99  NULL                       vpn1           1500                    0         1
   IPV6      IPV6        NULL            fc00:0:0:0:87:69:69:64     vpn1           1500                    0         2
   (结果个数 = 2)

   ---    END
   ```
2. 查询所有“IP名称”为“IP1”的HTTP IP地址信息：

   ```
   LST HTTPIP: IPNAME="IP1";
   ```

   ```
   %%LST HTTPIP: IPNAME="IP1";%%
   RETCODE = 0  操作成功

                 IP名称  =  IP1
             IP地址类型  =  IPV4
               IPV4地址  =  192.168.177.99
               IPV6地址  =  NULL
            VPNINFO名称  =  vpn1
     最大传输单元(byte)  =  1500
                 DSCP值  =  0
            HTTP IP索引  =  1
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见

**ADD HTTPIP**

命令的参数说明。表1列出的是未包含在

**ADD HTTPIP**

命令参数说明中的输出项。

| 输出项名称              | 输出项解释                                          |
|:-------------------|:-----------------------------------------------|
| HTTP IP索引（仅虚机场景涉及） | 用于返回HTTP IP配置的索引。在配置HTTP IP记录时系统按照配置顺序依次生成该索引。 |
