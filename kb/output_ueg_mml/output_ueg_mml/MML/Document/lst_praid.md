#### 命令功能

**适用网元：MME**

该命令用于查询PRA区域基本信息。

#### 注意事项

- 此命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                 |
|:-------|:-------|:---------------------------------------------------------------------|
| PRAID  | PRA标识  | 可选必选说明：可选参 参数含义：该参数表示PRA区域的标识 数据来源：整网规划 取值范围：0x800000～0xFFFFFF 默认值：无 |

#### 使用实例

查询PRA标识为“0x800001”的PRA区域基本信息。

LST PRAID: PRAID="0x800001";

```
%%LST PRAID: PRAID="0x800001";%%
RETCODE = 0  操作成功。

输出结果如下
-------------------------
             PRA标识  =  0x800001
本网异地用户可用开关  =  ON
             PRA名称  =  praname1
(结果个数 = 1)
---    END
```
