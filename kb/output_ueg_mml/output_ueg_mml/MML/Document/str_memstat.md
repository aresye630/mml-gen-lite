# 启动内存申请统计任务（STR MEMSTAT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会影响系统性能，需联系华为技术支持确认后再执行。

该命令主要用于现网快速定位内存泄漏问题的原因，例如现网上报告警ALM-34024 服务内存资源限制告警时，可以执行该命令统计PES服务内存申请的相关数据，协助内存泄漏问题定位。

## 注意事项

- 执行该命令的过程中，PES服务进程CPU和PES服务所在节点CPU的占用率最多可能会上升约15%，需联系华为技术支持后执行。
  - PES进程CPU占用率查询方法：在“CSP MML命令”界面执行命令查询进程资源信息（DSP PROCRESSTAT）可查询PES服务进程CPU占用率。命令示例如下：

    ```
    DSP PROCRESSTAT: DSPPROCSTAT_MEID=20, DSPPROCSTAT_RES_NAME=cpu, DSPPROCSTAT_QUERY_TYPE=byProcessType, DSPPROCSTAT_PROC_TYPE="pes";
    ```
  - PES服务所在节点CPU占用率查询方法：在“UPCF MML命令”界面执行命令查询Node的CPU信息（DSP NODECPUSTAT）（对应裸机场景查询pod CPU信息（DSP PODCPUSTAT））可以查询PES服务所在节点的CPU占用率。其中，参数“节点ID”信息可以从查询进程资源信息（DSP PROCRESSTAT）命令查询结果返回信息中“进程ID”获取。命令示例如下：

    ```
    DSP NODECPUSTAT: NODEID="***.***.***.***";
    ```

  **说明** 

  当PES进程CPU和PES服务所在节点CPU占用率均高于65%时，不建议执行该命令。
- 目前仅支持统计PES服务的内存申请信息，如果输入的“实例号”不是PES服务的实例号，命令将直接返回执行成功结果，但是不做内存申请统计动作。
- 需要等待上一次统计任务完成后才能执行下一次统计任务。
- 命令执行结束后，统计到的内存数据将存储到PES服务所在容器的“/opt/csplog/{APPID}/PcfPolicyEngineService/export/log”目录下，文件名格式为“mem\_data\_pes\_{processId}\_{timestamp}.csv”。
- 统计到的内存数据也可以通过OM Portal上“监控分析 > 运行日志”下载，具体下载步骤如下：
  1. 登录CSP Portal，选择“监控分析 > 运行日志”，在左侧导航栏中选择“服务日志收集”。
  2. 设置“应用名称”，然后从“服务类型”导航树中选中“PcfPolicyEngineService”节点下选择需要导出PES内存申请数据的节点。

     **说明** 

     导航树中选择的PES节点名称和执行该命令输入的“实例号”所属的“虚拟机IP”（裸机场景下为“容器IP”）保持一致，“虚拟机IP”（裸机场景下为“容器IP”）可以通过查询服务信息（DSP SERVICEINFO）命令查询获取。
  3. 设置参数“时间区间”，单击“开始收集”。
  4. 收集完成后，单击“日志下载地址”右侧的压缩包名称，可以将包含PES服务内存申请数据的日志文件保存至本地。

## 参数说明

| 参数标识         | 参数名称       | 参数说明                                                                                                                              |
|:-------------|:-----------|:----------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE  | 服务类型       | 可选必选说明：必选参数 参数含义：用于指定启动内存申请统计的服务类型。 取值范围：PcfPolicyEngineService 默认值：无。  说明： 目前仅支持对PES微服务进行内存申请统计操作。                               |
| INSTANCEID   | 实例号        | 可选必选说明：必选参数 参数含义：用于指定启动内存申请统计微服务的实例号。 取值范围：0~256长度字符串 默认值：无。  说明： 目前仅支持根据PES微服务的实例号进行内存申请统计，该参数可以通过查询服务信息（DSP SERVICEINFO）命令查询获取。 |
| DURATION     | 内存申请统计任务时长 | 可选必选说明：必选参数 参数含义：用于设置统计内存申请任务的时间长度。 取值范围：10-3600 单位：秒 默认值：60                                                                      |
| NEEDFLOWCTRL | 流控时是否自动停止  | 可选必选说明：必选参数 参数含义：用于设置UPCF启动流控任务时是否停止内存申请统计任务。 取值范围：枚举类型。 TRUE（是）：流控任务启动时停止内存申请统计任务。FALSE（否）：流控任务启动时继续执行内存申请统计任务。 默认值：TRUE（是）      |

## 使用实例

统计2分钟时间内的PES微服务内存申请数据，“实例号”为“4201903”，“流控时是否自动停止”为“TRUE（是）”。

```
STR MEMSTAT: SERVICETYPE=PcfPolicyEngineService, INSTANCEID="4201903", DURATION=120, NEEDFLOWCTRL=TRUE;;
```
