# 去活SIP注册上下文（DEA SIPCTX）

#### 命令功能

**适用网元：MME****、AMF**

该命令用于去活用户IMS域的SIP注册信息。

#### 注意事项

- 该命令执行后立即生效。
- 当“删除方式”为“ALL”时，单进程的去活速率为每秒去活50个用户，整系统去活速率为每秒去活（进程个数\*50）个用户。每个进程的用户数和总用户数可以通过**DSP SIPCTX**命令查询得到。
- 当“删除方式”为“ALL”时，未去活所有用户前，再次去活所有用户会执行失败。
- 此删除操作不会通知到UE，仅为删除本地资源，可能会导致终端脱网，谨慎执行。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                      |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
| DEAOPT | 删除方式   | 可选必选说明：必选参数。 参数说明：该参数用于指定去活用户IMS域的SIP注册信息的识别码类型。 取值范围： “ALL(所有用户)”：表示去活所有用户IMS域的SIP注册信息。 “BYIMSI(指定IMSI)”：表示根据IMSI去活用户IMS域的SIP注册信息。 默认值：“BYIMSI(指定IMSI)”。 |
| IMSI   | IMSI   | 可选必选说明：条件必选参数。 参数说明：该参数用于指定国际移动用户标识。 前提条件：此参数在“删除方式”设置为“BYIMSI(指定IMSI)”后生效。 取值范围：1～15位数字。 默认值：无。                                                          |

#### 使用实例

- 当去活方式为ALL时，去活所有用户IMS域的SIP注册信息。

  DEA SIPCTX: DEAOPT=ALL;

  ```
  %%DEA SIPCTX: DEAOPT=ALL;%% 
  RETCODE = 0  操作成功  
  ---    END
  ```

- 当去活方式为BYIMSI时，按照IMSI去活用户IMS域的SIP注册信息。

  DEA SIPCTX: DEAOPT=BYIMSI, IMSI="460080755012015";

  ```
  %%DEA SIPCTX: DEAOPT=BYIMSI, IMSI="460080755012015";%% 
  RETCODE = 0  操作成功  
  ---    END
  ```
