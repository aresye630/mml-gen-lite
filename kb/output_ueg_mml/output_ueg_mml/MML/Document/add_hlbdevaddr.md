# 添加HLB设备地址(ADD HLBDEVADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此命令配置有风险，HTTP协议不安全，推荐使用安全的HTTPS协议进行对接，请确认是否继续？

该命令为配置类命令，用于在配置数据库中增加一条HLB设备地址信息数据记录。当需要使用HLB服务时，需要为HLB服务配置IP地址，以便UPCF能够识别这个模块。

**说明** 

使用该命令为HLB服务配置IP地址，新的IPV4地址或IPV6地址将会在命令执行5秒钟后才会生效。

## 注意事项

- 如果通过**ADD HLBDEVADDR**命令只配置了一个本地IP地址，当HLB作为客户端发起建链流程时，默认使用唯一的本地IP建链。
- 如果通过**ADD HLBDEVADDR**命令在配置了多个本地IP地址，当HLB作为客户端发起建链流程时，请参考VRM\_PCFLIPSELECTMODE的取值确认IP地址。
- UPCF作为客户端动态发现BSF/CHF/SCP建链时，要求BSF/CHF/SCP的NFProfile信息携带的IP+端口的组合必须唯一。
- 对于IPv4地址，不支持配置以下地址：“127.0.0.1”、“0.0.0.0”、“255.255.255.255”、“224.0.0.1”。
- PMS/NTS/DRS/HLB/DLB/NLF/LDAP设备的IP地址（包括IPv4地址和IPv6地址）需要唯一，任意两种设备的IP地址不能重复。
- UPCF作为客户端与服务端同一个IP+端口建链时，仅支持HTTP或HTTPS中的一种。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                    |
|:------------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DEVAID      | 设备地址标识  | 可选必选说明：必选参数 参数含义：用于在UPCF配置库中定义一条本地设备地址信息。 取值范围：0～31 默认值：无。 配置原则：无。                                                                                                                      |
| VPNNAME     | VPN名称   | 可选必选说明：必选参数 参数含义：用于标识CSLB的业务IP的VPN名称。 取值范围：长度不超过32位的字符串 默认值：无。 配置原则：无。                                                                                                                  |
| IPVER       | IP版本    | 可选必选说明：必选参数 参数含义：用于指定设备IP地址的IP版本类型。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。                                                                                                           |
| IP          | IPV4地址  | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV4(IPV4)”时该参数有效，用于表示HLB设备的IPv4地址。 取值范围：IPv4地址 默认值：无。 配置原则：无。                                                                                              |
| IPV6        | IPV6地址  | 可选必选说明：可选参数 参数含义：仅当“IP版本”选择“IPV6(IPV6)”时该参数可配置，用于表示HLB设备的IPv6地址。 取值范围：IPv6地址 默认值：无。 配置原则：无。                                                                                             |
| HTTPSFUNC   | HTTPS功能 | 可选必选说明：可选参数 参数含义：表示是否开启HTTPS功能，启用TLS证书。 取值范围： ON(打开)：表示启用TLS证书。OFF(关闭)：表示不启用TLS证书。 默认值：ON(打开) 配置原则：无。  说明： 当该参数设置为“ON(打开)”时，HLB服务性能将会下降20%，如需开启请联系华为技术支持。                               |
| CERTSCENE   | 证书应用场景  | 可选必选说明：条件必选参数。 参数含义：表示注册HLB服务的TLS证书应用场景，仅当“HTTPS功能”配置为“ON(打开)”时该参数可配置且必须配置。 取值范围： UPCF_HLB_Lcert(UPCF_HLB_Lcert) 默认值：无。 配置原则：无。  说明： 证书应用场景下关联的证书文件，必须是设备证书文件、证书私钥文件和CA证书文件分别有且只有一个。    |
| TLSCFGID    | TLS配置ID | 可选必选说明：必选参数 参数含义：用于指定关联的TLS配置记录，该参数必须先由ADD HLBTLSCFG命令定义，然后才能在此处索引。仅当“HTTPS功能”配置为“ON(打开)”时该参数可配置且必须配置，配置值需要与对端协商一致。 取值范围：1～128 默认值：无。 配置原则：无。                                           |
| DESCRIPTION | 描述      | 可选必选说明：可选参数 参数含义：用于描述设备IP地址的用途。 取值范围：长度不超过32位的字符串 默认值：无。 配置原则：无。                                                                                                                        |
| DSCP        | DSCP优先级 | 可选必选说明：可选参数 参数含义：用于指定修改后的DSCP优先级。 取值范围：0～63，255 默认值：255。 配置原则：无。  说明： DSCP优先级有64级，为0～63，级别为63时，优先级最高。255表示不设置DSCP。                                                                      |
| TOEDGE      | 对接边缘    | 可选必选说明：可选参数 参数含义：用于标识是否对接边缘网元。 取值范围： YES(是)：表示该HLBDEVADDR用于对接边缘网元。NO(否)：表示该HLBDEVADDR用于对接大网网元。 默认值：NO(否)。 配置原则：无。  说明： 参数取值为“YES”的记录仅应用于SMF/AMF/NEF对端。若多条记录的“VPNNAME”值相同，则本参数的取值需要保持一致。 |

## 使用实例

1. 增加IPv4类型的HLB设备地址信息。“设备地址标识”为“1”，“VPN名称”为“VPN1”，“IP版本”为“IPV4(IPV4)”，“IPV4地址”为“192.168.0.130”，“HTTPS功能”为“ON(打开)”，“证书应用场景”为“UPCF\_HLB\_Lcert(UPCF\_HLB\_Lcert)”，“TLS配置ID”为“1”，“描述”为“HLB\_IPV4”，“DSCP优先级”为“255”，“对接边缘”为“NO”。

   ```
   ADD HLBDEVADDR: DEVAID=1, VPNNAME="VPN1", IPVER=IPV4, IP="192.168.0.130", HTTPSFUNC=ON, CERTSCENE=UPCF_HLB_Lcert, TLSCFGID=1, DESCRIPTION="HLB_IPV4", DSCP=255, TOEDGE=NO;
   ```
2. 增加IPv6类型的HLB设备地址信息。“设备地址标识”为“2”，“VPN名称”为“VPN1”，“IP版本”为“IPV6(IPV6)”，“IPV6地址”为“2001:0db8:11ff:ffff:ffff:ffff:ffff:ffff”，“HTTPS功能”为“ON(打开)”，“证书应用场景”为“UPCF\_HLB\_Lcert(UPCF\_HLB\_Lcert)”，“TLS配置ID”为“1”，“描述”为“HLB\_IPV6”，“DSCP优先级”为“255”，“对接边缘”为“NO”。

   ```
   ADD HLBDEVADDR: DEVAID=2, VPNNAME="VPN1", IPVER=IPV6, IPV6="2001:0db8:11ff:ffff:ffff:ffff:ffff:ffff", HTTPSFUNC=ON, CERTSCENE=UPCF_HLB_Lcert, TLSCFGID=1, DESCRIPTION="HLB_IPV6", DSCP=255, TOEDGE=NO;
   ```

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。
