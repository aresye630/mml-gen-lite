# 查询VPN实例（LST CPVPNINST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SGW-C、PGW-C、SMF、GGSN**

该命令用于查询配置的VPN实例信息。

## 注意事项

- “\_public\_”是公网缺省VPN的实例名，查询结果中不呈现。
- 默认为输出所有VPN实例；若想查看指定VPN的信息，可加参数VPNINSTANCE。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                           |
|:------------|:-------|:-----------------------------------------------------------------------------------------------|
| VPNINSTANCE | VPN实例名 | 可选必选说明：可选参数  参数含义：该参数用于指定VPN实例。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~31。区分大小写，不支持空格。  默认值：无  配置原则：无 |

## 使用实例

显示VPNInst业务配置：
LST CPVPNINST:;

```
%%LST CPVPNINST:;%%
RETCODE = 0  操作成功。

VPN实例信息
------------------------
VPN实例名  =  vpn1
(结果个数 = 1)
```

## 输出结果说明

| 输出项名称   | 输出项解释         |
|:--------|:--------------|
| VPN实例名  | 该参数用于指定VPN实例。 |
