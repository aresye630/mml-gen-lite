# 查询服务订阅信息(DSP NFSUBSINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询NRFClient服务订阅信息。

## 注意事项

无。

## 参数说明

| 参数标识         | 参数名称          | 参数说明                                                                                                                                                                                                                                                                                    |
|:-------------|:--------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFTYPE       | 网元类型          | 可选必选说明：必选参数 参数含义：用于指示系统查询哪个网元类型的服务订阅信息。 取值范围：AMF(AMF)SCP(SCP)SMF(SMF) 默认值：无。 配置原则：无。                                                                                                                                                                                                    |
| NFINSID      | 网元实例标识        | 可选必选说明：可选参数 参数含义：网元实例在系统中的序号，用于指示系统查询哪个网元实例标识的服务订阅信息。 取值范围：有效的UUIDv4格式，只允许输入0～9，a～f，A～F，“-”。 UUIDv4格式为“xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx”，例如：4947a69a-f61b-4bc1-b9da-47c9c5d14b64。 默认值：无。 配置原则： 若输入了本参数，则不允许输入“PLMN标识”、“AMF Region ID”和“AMF Set ID”参数。若输入了本参数，则不允许输入“服务范围”和“SCP域”参数。 |
| PLMNID       | PLMN标识        | 可选必选说明：条件可选参数 参数含义：用于指示系统查询哪个PLMN标识的服务订阅信息。 取值范围：5位或6位十进制数字组成的字符串。 默认值：无。 配置原则：“网元类型”参数取值为“AMF(AMF)”时该参数可选。若输入了本参数，则必须同时输入“AMF Region ID”和“AMF Set ID”参数。                                                                                                                               |
| AMFREGION    | AMF Region ID | 可选必选说明：条件可选参数 参数含义：用于指示系统查询哪个AMF Region ID的服务订阅信息。 取值范围：2位16进制字符串。 默认值：无。 配置原则：“网元类型”参数取值为“AMF(AMF)”时该参数可选。若输入了本参数，则必须同时输入“PLMN标识”和“AMF Set ID”参数。                                                                                                                                      |
| AMFSET       | AMF Set ID    | 可选必选说明：条件可选参数 参数含义：用于指示系统查询哪个AMF Set ID的服务订阅信息。 取值范围：3位16进制字符串，第1位的取值范围是0-3，后2位是16进制。 默认值：无。 配置原则：“网元类型”参数取值为“AMF(AMF)”时该参数可选。若输入了本参数，则必须同时输入“PLMN标识”和“AMF Region ID”参数。                                                                                                                |
| SERVINGSCOPE | 服务范围          | 可选必选说明：条件可选参数 参数含义：SCP服务发现携带的参数servingScope。用于指示系统查询哪个服务范围的服务订阅信息。 取值范围：长度不超过1024位的字符串。 默认值：无。 配置原则：“网元类型”参数取值为“SCP(SCP)”时该参数可选。本参数不能和“网元实例标识”、“SCP域”参数同时配置。                                                                                                                            |
| SCPDOMAINS   | SCP域          | 可选必选说明：条件可选参数 参数含义：SCP服务发现携带的参数scpDomains。用于指示系统查询哪个SCP域的服务订阅信息。 取值范围：长度不超过1024位的字符串。 默认值：无。 配置原则：“网元类型”参数取值为“SCP(SCP)”时该参数可选。本参数不能和“网元实例标识”、“服务范围”参数同时配置。                                                                                                                              |

## 使用实例

1. 查询“网元类型”标识为“SCP(SCP)”、“网元实例标识”为“33333333-3333-3333-3333-333333333333”的服务订阅信息。

   ```
   DSP NFSUBSINFO: NFTYPE=SCP, NFINSID="33333333-3333-3333-3333-333333333333";
   ```

   ```
   %%DSP NFSUBSINFO: NFTYPE=SCP, NFINSID="33333333-3333-3333-3333-333333333333";%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
                订阅号  =  SUBSCRIBEDID
              有效时间  =  2099-06-15 12:40:50
              有效时长  =  2433318674
   网元状态变更通知URI  =  http://192.168.1.39:8080/nrfc-notification-discovery
              Location  =  http://192.168.1.40:7070/namf-evts/subscriptions/01
   (结果个数 = 1)

   ---    END
   ```
2. 查询“网元类型”标识为“AMF(AMF)”、“网元实例标识”为“11112222-1111-2222-3333-111122223333”的服务订阅信息。

   ```
   DSP NFSUBSINFO: NFTYPE=AMF, NFINSID="11112222-1111-2222-3333-111122223333";
   ```

   ```
   %%DSP NFSUBSINFO: NFTYPE=AMF, NFINSID="11112222-1111-2222-3333-111122223333";%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
                订阅号  =  SUBSCRIBEDID2
              有效时间  =  2099-06-15 12:40:50
              有效时长  =  2433318513
   网元状态变更通知URI  =  http://192.168.1.39:8080/nrfc-notification-discovery
              Location  =  http://192.168.1.40:7070/namf-evts/subscriptions/02
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，参数解释如表1所示。

| 输出项名称       | 输出项解释                                                    |
|:------------|:---------------------------------------------------------|
| 订阅号         | 表示NRFClient给UdmSubService返回的订阅ID，每一个订阅对应一个订阅ID。          |
| 有效时间        | 表示UDM给NRFClient订阅其它网元（如AMF/SCP等）的订阅信息有效时间截止日期。           |
| 有效时长        | 表示UDM给NRFClient订阅其它网元（如AMF/SCP等）的订阅信息有效时长为多少秒。           |
| 网元状态变更通知URI | 表示UDM订阅的网元实例（如AMF/SCP等）发生变更时，NRFClient会通过本命令返回的URI通知UDM。 |
| Location    | 表示NRFClient给UDM返回的订阅资源信息，用于UDM下次续订阅、去订阅。                 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释                                       | 原因分析                                                                    | 处理建议                                                                                                 |
|-------:|:--------------------------------------------|:------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------|
| 360041 | 参数值不合法。                                     | 输入的提示参数不合法。                                                             | 重新输入提示错误的参数的取值，确保其取值符合要求。                                                                            |
| 360204 | 参数冲突：AMFSET与NFINSID不允许同时存在。                 | 查询“AMF(AMF)”网元类型的服务订阅信息时，同时输入了“网元实例标识”参数和“AMF Set ID”参数。                | 通过如下两种方式查询“AMF(AMF)”网元类型的服务订阅信息：输入“网元实例标识”参数即可，无需输入其他参数。同时输入“PLMN标识”、“AMF Region ID”和“AMF Set ID”参数。 |
| 360205 | 参数缺失： PLMNID、AMFREGION与AMFSET需要同时存在。        | 查询“AMF(AMF)”网元类型的服务订阅信息时，没有同时输入“PLMN标识”、“AMF Set ID”和“AMF Region ID”参数。 | 同时输入“PLMN标识”、“AMF Set ID”、“AMF Region ID”参数后执行本命令查询。                                                 |
| 360208 | SERVINGSCOPE/SCPDOMAINS/NFINSID必须存在且仅能存在1个。 | 查询“SCP(SCP)”网元类型的服务订阅信息时，“网元实例标识”、“服务范围”和“SCP域”参数一个都没有输入或者输入了多个。        | 输入“网元实例标识”、“服务范围”和“SCP域”参数中的任意一个参数查询“SCP(SCP)”网元类型的服务订阅信息。                                           |
