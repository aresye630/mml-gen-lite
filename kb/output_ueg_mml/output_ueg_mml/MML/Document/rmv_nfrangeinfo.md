# 删除网元号段信息(RMV NFRANGEINFO)

- 命令功能

- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致用户路由异常，影响业务处理，需联系华为技术支持确认后再执行。

该命令用于删除一个网元的号段信息。

## 注意事项

- 删除数据时，如果指定“索引”所在组的“组名称”已在**ADD NFINFO**的“SUPI号段组”或“GPSI号段组”中引用，且是所在组下最后一条记录，是则不允许删除。
- 删除数据成功，如果指定“索引”所在组的“组名称”已在**ADD NFINFO**的“SUPI号段组”或“GPSI号段组”中引用，且**ADD NFINFO**的“网元信息标识”在**ADD NFSRV**命令的“网元信息标识”中引用，且**ADD NFSRV**命令中的“网元状态”为“REGISTERED”时，将按照**ADD NFSRV**命令中“更新方式”参数中指定的更新模式60秒内向NRF发送Nnrf\_NFManagement\_NFUpdate Request消息请求更新。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                               |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
| GRPNAME | 组名称    | 可选必选说明：必选参数 参数含义：用于标识一组网元号段信息所属组的名称的关键字段之一。操作员可以使用LST NFRANGEINFO命令查询获得。和索引组成全局唯一对象关键字段。 取值范围：长度不超过32的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。 |
| INDEX   | 索引     | 可选必选说明：必选参数 参数含义：用于标识一条网元号段信息数据记录的关键字段之一。操作员可以使用LST NFRANGEINFO命令查询获得。和组名称组成全局唯一对象关键字段。 取值范围：1~40960。 默认值：无。 配置原则：无。                               |

## 使用实例

删除号段信息，“组名称”为“supi-group-01”，“索引”为“1”：

```
RMV NFRANGEINFO: GRPNAME="supi-group-01", INDEX=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释              | 原因分析                                       | 处理建议                                 |
|-------:|:-------------------|:-------------------------------------------|:-------------------------------------|
|    505 | 当前操作的配置数据不存在。      | “索引”不存在。                                   | 使用LST NFRANGEINFO命令查询获得“索引”，确保其值已存在。 |
| 360044 | 当前记录在其他命令中引用，无法删除。 | 该号段的“组名称”被ADD NFINFO的“SUPI号段组”或“GPSI号段组”引用 | 先删除网元信息对该号段所属组的引用，再删除该号段组。           |
