# 修改ACL规则组（MOD ACLGROUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改ACL规则组的配置，可以修改规则组的步长，以及规则组描述信息。

#### 注意事项

- 该命令执行后立即生效。
- ACL创建之后，ACLTYPE不可修改，修改的话会报错。
- 执行该命令前，需要提前配置ADD ACLGROUP命令添加ACL规则组。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                                                                                                                 |
|:---------------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ACLNAME        | ACL规则组标识 | 可选必选说明：必选参数 参数含义：该参数用于指定规则组名称或是编号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。不支持空格，区分大小写。以英文字母a～z或A～Z开始，可以是英文字母、数字、连字符“-”、下划线“_”或中文字符的组合。整数形式，取值范围是1000～1999（接口ACL），2000～2999（基本ACL），3000～3999（高级ACL），4000～4999（以太ACL）。 默认值：无 |
| ACLSTEP        | 规则组步长    | 可选必选说明：可选参数 参数含义：该参数用于指定规则组规则步长，仅当不指定规则ID时生效。 数据来源：本端规划 取值范围：整数类型，取值范围为1～20。 默认值：无                                                                                                                                   |
| ACLMATCHORDER  | 规则的匹配顺序  | 可选必选说明：可选参数 参数含义：该参数用于指定规则的匹配顺序是深度优先还是配置优先。 数据来源：本端规划 取值范围：枚举类型。 Config：配置优先。Auto：深度优先。 默认值：无                                                                                                                        |
| ACLDESCRIPTION | 规则组描述    | 可选必选说明：可选参数 参数含义：该参数用于指定ACL规则组描述信息。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～127。支持空格，区分大小写。 默认值：无 配置原则： 输入单空格将删除该参数已有配置项。建议取有实际意义的名称，以方便识别。                                                                                    |

#### 使用实例

为了便于维护，可以修改规则组2005的描述信息为"aclgroup"：

```
MOD ACLGROUP: ACLNAME="2005",ACLDESCRIPTION="aclgroup";
```
