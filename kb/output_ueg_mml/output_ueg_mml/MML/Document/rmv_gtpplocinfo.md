# 删除GTPP本端信息（RMV GTPPLOCINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-C、PGW-C、SMF**

该命令用来删除GTPP本端信息。

#### 注意事项

- 该命令执行后立即生效。
- 当前版本不支持此命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                |
|:---------|:-------|:------------------------------------------------------------------------------------|
| HOSTNAME | 本端主机名  | 可选必选说明：必选参数 参数含义：该参数用于指定本端主机名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格。 默认值：无 配置原则：无 |

#### 使用实例

删除GTPP本端信息，本端主机名为“test”：

```
RMV GTPPLOCINFO: HOSTNAME="test";
```
