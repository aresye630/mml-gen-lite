# 添加NLF对端链路(ADD NLFPEERLINKCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加一条NLF对端链路配置信息。

该命令的使用场景：NLF服务支持通知日志文件上传或下载，当NLF作为SFTP客户端，支持向DRS上传通知日志文件。

在该命令中，以下关键参数需要与对端服务器协商：

- “对端IP地址”
- “对端IPV6地址”
- “对端端口”

## 注意事项

- 对每个NLF对端系统最多只允许配置一条“本地角色”为“SFTPClient(SFTP客户端)”的链路。
- IP地址对应的IP版本指定后，不支持修改。
- IPv4类型的IP地址不能配置如下非法IP地址：“127.0.0.1”、“0.0.0.0”、“255.255.255.255”、“224.0.0.1”。
- IPv6类型的IP地址不支持混合方式表达，即xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:d.d.d.d，其中x表示一个十六进制数（0～9或A～F），而d.d.d.d表示一个IPv4地址。
- IPv6类型的IP地址不支持以下特殊地址的配置，其中x表示一个十六进制数（0～9或A～F），不区分大小写：

  - 0000:0000:0000:0000:0000:0000:0000:0000
  - FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF
  - 0000:0000:0000:0000:0000:0000:0000:0001
  - FFxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE8x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE9x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEAx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEBx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx

## 参数说明

|:------------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LINKID      | 链路ID     | 可选必选说明：必选参数 参数含义：用于标识一条NLF对端链路配置信息的数据记录。 取值范围：0～254 默认值：无。 配置原则：无。                                                                                                                                                 |

| LOCALROLE   | 本地角色     | 可选必选说明：必选参数 参数含义：用于标识本地角色。 取值说明： SFTPClient(SFTP客户端) 默认值：无。 配置原则：无。                                                                                                                                                |
| IPVER       | IP版本     | 可选必选说明：条件必选参数 参数含义：用于指定IP地址的IP版本类型。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。                                                                                                                                      |
| LOCALIP     | 本地IP地址   | 可选必选说明：条件必选参数 参数含义：仅当“IP版本”选择“IPV4(IPV4)”时该参数需配置，NLF与对端对接的参数之一，用于表示NLF设备的IPv4地址。 取值范围：IPv4地址 默认值：无。 配置原则：此IP地址必须是本地实际的IP地址且必须先由ADD NLFDEVADDR或ADD PMSDEVADDR（通过ADD NLFDEVADDR中配置的“PMS设备地址标识”进行索引关联）命令定义，然后才能在此处引用。 |
| LOCALIPV6   | 本地IPV6地址 | 可选必选说明：条件必选参数 参数含义：仅当“IP版本”选择“IPV6(IPV6)”时该参数需配置，NLF与对端对接的参数之一，用于表示NLF设备的IPv6地址。 取值范围：IPv6地址 默认值：无。 配置原则：此IP地址必须是本地实际的IP地址且必须先由ADD NLFDEVADDR或ADD PMSDEVADDR（通过ADD NLFDEVADDR中配置的“PMS设备地址标识”进行索引关联）命令定义，然后才能在此处引用。 |
| PEERIP      | 对端IP地址   | 可选必选说明：条件必选参数 参数含义：仅当“IP版本”选择“IPV4(IPV4)”时该参数需配置，NLF与对端对接的参数之一，用于表示对端设备的IPv4地址。 取值范围：IPv4地址 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。                                                                                      |
| PEERIPV6    | 对端IPV6地址 | 可选必选说明：条件必选参数 参数含义：仅当“IP版本”选择“IPV6(IPV6)”时该参数需配置，NLF与对端对接的参数之一，用于表示对端设备的IPv6地址。 取值范围：IPv6地址 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。                                                                                      |
| PEERPORT    | 对端端口     | 可选必选说明：条件必选参数 参数含义：NLF与对端对接的参数之一，用于指定链路使用的对端端口。 取值范围：1～65534 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。                                                                                                                     |
| USRNAME     | 用户名      | 可选必选说明：条件必选参数 参数含义：用于标识SFTP Server的登录用户。当“本地角色”选择为“SFTPClient(SFTP客户端)”时，该参数需要配置。 取值范围：长度不超过96的字符串 默认值：无。 配置原则：无。                                                                                                  |
| PASSWD      | 密码       | 可选必选说明：条件必选参数 参数含义：用于标识SFTP Server的登录密码。当“本地角色”选择为“SFTPClient(SFTP客户端)”时，该参数需要配置。 取值范围：长度为不超过255的字符串 默认值：无。 配置原则： 密码区分大小写。 在MML批处理页面或者MML编辑区下发命令时，如果密码的取值中存在"（双引号）、\（反斜杠）、;（分号），则需要输入转义字符\（反斜杠）。 密码中不能包含空格。        |
| CFM         | 确认密码     | 可选必选说明：条件必选参数 参数含义：用于标识SFTP Server的登录确认密码。当“本地角色”选择为“SFTPClient(SFTP客户端)”时，该参数需要配置。 取值范围：长度为不超过255的字符串 默认值：无。 配置原则：与参数“密码”保持一致。                                                                                    |
| PATH        | 对端路径     | 可选必选说明：可选参数 参数含义：用于指定SFTP对端的文件上传路径。仅当“本地角色”配置为“SFTPClient(SFTP客户端)”时，该参数可配置。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                                                                                                     |
| DESCRIPTION | 描述       | 可选必选说明：可选参数 参数含义：用于描述链路配置的用途。 取值范围：长度不超过32的字符串 默认值：无。 配置原则：无。                                                                                                                                                      |

## 使用实例

增加一条NLF对端链路配置信息的数据记录，“链路ID”为“4”，“对端ID”为“2”，“本地角色”为“SFTPClient(SFTP客户端)”，“IP版本”为“IPV4(IPV4)”，“本地IP地址”为“10.168.0.130”，“对端IP地址”为“10.85.52.32”，“对端端口”为“2030”，“用户名”为“upcf”，“密码”为“Hua#2020”，“确认密码”为“Hua#2020”。

```
ADD NLFPEERLINKCFG: LINKID=4, PEERID=2, LOCALROLE=SFTPClient, IPVER=IPV4, LOCALIP="10.168.0.130", PEERIP="10.85.52.32", PEERPORT=2030, USRNAME="upcf", PASSWD="*****", CFM="*****";
```

**说明** 

密码在命令行输入区域显示为\*\*\*\*\*。

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 58016 | 确认密码必须和密码一致。                   | 输入的“确认密码”和“密码”必须保持一致。                                             | 重新执行本命令，输入的“确认密码”和“密码”的取值要一致。                                                                                                                                                       |
