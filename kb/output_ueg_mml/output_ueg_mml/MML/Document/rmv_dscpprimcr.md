# 删除DSCP映射优先级配置表(RMV DSCPPRIMCR)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用网元：MME**

本命令用于删除DSCP映射优先级表。删除DSCP值的映射关系后，对应DSCP值的报文将入“优先级4”的队列。

#### 注意事项

- 该命令执行后立即生效。
- 该命令只能删除**ADD DSCPPRIMCR**添加的非默认记录。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                   |
|:-------|:-------|:---------------------------------------------------------------------------------------|
| SLTPR  | 选择操作类型 | 可选必选说明：可选参数 参数含义：本参数用于指示删除DSCP映射优先级表的操作类型。 数据来源：全网规划 取值范围： DSCP(DSCP映射关系) 默认值：无 配置原则：无 |
| DSCPV  | DSCP值  | 可选必选说明：条件必选参数 参数含义：本参数用于指示删除DSCP映射优先级表的DSCP值。 数据来源：全网规划 取值范围：0~63 默认值：无 配置原则：无         |

#### 使用实例

删除DSCP为50的映射关系表：

RMV DSCPPRIMCR: SLTPR=DSCP, DSCPV=50;
