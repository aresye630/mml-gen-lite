# 显示在线计费全局参数配置（LST OLNCHGPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于显示在线计费参数。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查看当前配置：

```
LST OLNCHGPARA:;
```

```
RETCODE = 0  操作成功

在线计费全局参数配置
--------------------
Reporting Level为SID时的配额申请方式  =  按RG申请配额
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见SET OLNCHGPARA的参数说明。
