# 增加PCRF对端PCEF能力字典(ADD PCEFABIDICT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条对端PCEF实体能力字典记录。UPCF在与PCEF对接时，需要在UPCF内部为PCEF指定一个能力字典，并将按照该能力字典对应的能力项进行相应的业务处理。

## 注意事项

PCEF能力字典ID取值范围是0~127，其中63~127是系统预置。输入预置范围的值时，系统返回成功但不会修改预置值。

## 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                               |
|:----------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
| ABILITYDICTID   | 能力字典ID | 用于标识PCEF能力字典的编号。 取值范围： 0~127 取值说明：63~127为预置数据，其中63为TDF，64为HuaweiGGSN，65为HuaweiSymaSIG，66为AllotPCEF，67为HuaweiGGSNR9，68为HuaweiPDNGW，69~127预留。 默认值： 无 |
| ABILITYDICTNAME | 能力字典名  | 用于具体描述一个PCEF能力字典的名称，以便于识别。其值域类型为字符串，不区分大小写。 取值范围： 长度不超过32的字符串 默认值： 无                                                                               |

## 使用实例

1. 增加一条PCEF能力字典。“能力字典ID”为“62”，“能力字典名”为“HUAWEIGGSN”。

   ```
   ADD PCEFABIDICT: ABILITYDICTID=62, ABILITYDICTNAME="HUAWEIGGSN";
   ```
