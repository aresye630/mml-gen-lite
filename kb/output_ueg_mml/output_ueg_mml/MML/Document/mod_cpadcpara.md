# 修改ADC参数（MOD CPADCPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-C、SMF**

该命令用于修改应用的流信息上报开关。流信息的上报功能是指对于需要进行检测上报的应用，在上报应用开始/结束上报时，同时上报当前业务的流信息，便于PCRF/PCF能够获取到应用与流的对应关系，从而可以下发更精确地策略对业务进行控制。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称    | 参数说明                                                                                                                                                          |
|:---------------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FLOWFILTERNAME | 流过滤器名称  | 可选必选说明：必选参数 参数含义：该参数用于设置应用对应的流过滤器名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD CPSVCFLOWFILTER命令配置生成。                                |
| FLOWINFORPT    | 流信息上报标识 | 可选必选说明：可选参数 参数含义：该参数用于设置流信息上报标识。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不上报流信息。ENABLE：上报流信息。 默认值：无 配置原则： DISABLE：在向PCRF上报应用开始/结束时，不上报流信息。ENABLE：在向PCRF上报应用开始/结束时，上报流信息。 |

#### 使用实例

假设运营商需要将指定应用修改为不上报流信息，指定应用对应的流过滤器名称为testflowfiltername：

```
MOD CPADCPARA:FLOWFILTERNAME="testflowfiltername",FLOWINFORPT=DISABLE;
```
