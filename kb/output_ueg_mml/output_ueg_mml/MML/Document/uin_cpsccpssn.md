# 解禁SCCP子系统(UIN CPSCCPSSN)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限

#### 命令功能

**适用网元：SGSN、MME、SMSF**

此命令用于解禁SCCP子系统。

#### 注意事项

- 系统会自行选取可用的信令进程，因此，执行该操作的时候要确保系统中有可用的信令进程。否则，操作将不能正常执行。
- 只有处于禁止状态的SCCP子系统才能执行解禁操作。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                           |
|:-------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NI     | 网络指示语   | 可选必选说明：必选参数 参数含义：该参数用于指定网络指示语。 取值范围：“INT(国际网)”“INTB(国际备用网)”“NAT(国内网)”“NATB(国内备用网)” 默认值：无  说明： 配置的信令网络指示语在信令属性表中应该配置为有效。                                                                                                                                                                                                                                        |
| DPC    | 目的信令点编码 | 可选必选说明：必选参数 参数含义：该参数用于指定目的信令点编码，可以采用14位信令点编码或24位信令点编码。 取值范围：长度不超过8的字符串 默认值：无 配置原则：取值为0x1~0x3FFF（对应14位编码），或0x1~0xFFFFFF（对应24位编码），不输入0x也取输入为十六进制值，即输入123等价于0x123。  说明： 配置的信令点编码结构需要和信令属性表中对应的信令网络的网络结构保持一致。                                                                                                                                                      |
| SSN    | 子系统号    | 可选必选说明：必选参数 参数含义：该参数用于指定子系统号。 取值范围：“NODEFINE(未定义)”“SCMG(1)”“STANDBY0(2)”“RANAP(142)”“OMAP(4)”“MAP(5)”“HLR(6)”“VLR(7)”“MSC(8)”“STANDBY1(11)”“INAP(12)”“CAP(146)”“SGSN(149)”“GGSN(150)”“BSSAP(254)”“BSSAP(BSSAP+)”“GMLC(145)”“EIR(9)” 默认值：无  说明： 每个信令点上应该配置一个管理子系统(SCMG)，一般SGSN上还需要配置SGSN(Gr)、CAP(Ge)、BSSAP+(Gs)子系统；HLR的目的信令点上还需要配置HLR子系统，SMC的目的信令点上还需要配置MSC子系统。 |
| OPC    | 本局信令点编码 | 可选必选说明：必选参数 参数含义：该参数用于指定本局信令点编码，可以采用14位信令点编码或24位信令点编码。 取值范围：长度不超过8的字符串 默认值：无 配置原则：取值为0x1~0x3FFF（对应14位编码），或0x1~0xFFFFFF（对应24位编码），不输入0x也取输入为十六进制值，即输入123等价于0x123。  说明： 配置的信令点编码结构需要和信令属性表中对应的信令网络的网络结构保持一致。                                                                                                                                                      |

#### 使用实例

解禁SCCP子系统：

UIN CPSCCPSSN: NI=NAT, DPC="0x290270", SSN=RANAP, OPC="0x290333";
