# 显示网元概述信息（DSP REGNFPROFILE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：AMF、SMF、NRF、SMSF、NCG、NSSF、NEF、NWDAF、SCF**

该命令用于显示本端NF向NRF注册过的网元概述信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                       |
|:-------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| QUERYTYPE    | 查询条件   | 可选必选说明：可选参数  参数含义：查询条件，默认查询所有本端网元，选择NfType为查询条件需要填写网元类型，选择NfInstanceID为查询条件需要填写网元实例ID。  数据来源：本端规划 取值范围： ALL（默认显示所有结果）NFTYPE（根据网元类型查询）NFINSTANCEID（根据网元实例ID查询）  默认值：ALL  配置原则：无                                             |
| NFINSTANCEID | NF实例ID | 可选必选说明：该参数在"QUERYTYPE"配置为"NFINSTANCEID"时为条件必选参数。  参数含义：该参数用于指定NF实例标识。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~50。本参数的构成字符只能是字母A～Z或a～z、数字0～9、中划线"-"和下划线"_"，例如，AMF_Instance_0。本参数应与LST CPNFPROFILE命令查询结果中的“NF实例名称”一致。  默认值：无  配置原则：无 |
| NFTYPE       | NF类型   | 可选必选说明：该参数在"QUERYTYPE"配置为"NFTYPE"时为条件必选参数。  参数含义：该参数用于指定NF类型。  数据来源：本端规划 取值范围： AMF（AMF）SMF（SMF）NRF（NRF）NSSF（NSSF）SMSF（SMSF）NCG（NCG）NEF（NEF）NWDAF（NWDAF）  默认值：无  配置原则：无                                                     |

## 使用实例

查询当前本端网元的概述信息。

```
DSP REGNFPROFILE:;
DSP REGNFPROFILE: QUERYTYPE=NFTYPE, NFTYPE=AMF;
DSP REGNFPROFILE: QUERYTYPE=NFINSTANCEID, NFINSTANCEID="AMF_Instance_0";
```
