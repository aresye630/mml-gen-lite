# 查询HTTP局向（LST HTTPOFC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询HTTP局向。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                   |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------------|
| OFCTYPE | 局向类型   | 可选必选说明：必选参数  参数含义：该参数用于设置局向类型。  数据来源：本端规划 取值范围： “NFTYPE（基于网元类型）”：基于网元类型“IPGROUP（基于IP组）”：基于IP组  默认值：无  配置原则：  该参数不支持修改。 |
| OFCIDX  | 局向索引   | 可选必选说明：可选参数  参数含义：该参数用于设置局向索引。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4095。  默认值：无  配置原则：无                                       |

## 使用实例

- 查询局向类型为NFTYPE的HTTP局向信息，可以用如下命令：

  ```
  %%LST HTTPOFC: OFCTYPE=NFTYPE;%%
  RETCODE = 0  操作成功

  结果如下
  -------
          局向索引  =  1
          局向类型  =  基于网元类型
      对端网元类型  =  NFTypeSMF
  基于NFTYPE控制项  =  HTRINTF
      本端网元类型  =  INVALID
          局向名称  =  N11
  (结果个数 = 1)

  ---    END
  ```
- 查询局向类型为IPGROUP的HTTP局向信息，可以用如下命令：

  ```
  %%LST HTTPOFC: OFCTYPE=IPGROUP;%%
  RETCODE = 0  操作成功

  结果如下
  -------
        局向索引  =  2
        局向类型  =  基于IP组
            IP组  =  1
  基于IP组控制项  =  HTRIPGRP
    本端网元类型  =  INVALID
        局向名称  =  AMF2SMFIPGRP
  (结果个数 = 1)

  ---    END
  ```

## 输出结果说明

| 输出项名称       | 输出项解释                                                                    |
|:------------|:-------------------------------------------------------------------------|
| 局向索引        | 该参数用于设置局向索引。                                                             |
| 局向类型        | 该参数用于设置局向类型。                                                             |
| IP组         | 该参数用于指定局向IP组。该参数来源于ADD HTTPFCIPGRP命令的“GROUP”参数，可通过LST HTTPFCIPGRP命令查询获取。 |
| 基于IP组控制项    | 该参数用于设置局向类型为"IPGROUP"时流控类型。                                              |
| 本端网元类型      | 该参数用于设置本端网元类型。                                                           |
| 局向名称        | 该参数用于设置局向名称。                                                             |
| 对端网元类型      | 该参数用于设置对端网元类型。                                                           |
| 基于NFTYPE控制项 | 该参数用于设置局向类型为"NFTYPE"时流控类型。                                               |
