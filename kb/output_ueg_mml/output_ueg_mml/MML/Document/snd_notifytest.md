# 发送通知测试(SND NOTIFYTEST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于完成UPCF与用户通知的短信/邮件/SOAP服务器之间创建的链路后，进行短信测试/邮件测试/SOAP测试，验证链路是否正常。

## 注意事项

无。

## 参数说明

| 参数标识                | 参数名称    | 参数说明                                                                                                                                                                                                            |
|:--------------------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LINKID              | 链路ID    | 可选必选说明：必选参数 参数含义：用于标识通知测试发送的链路ID。 取值范围：1～255 默认值：无。 配置原则：通过LST NTSPEERLINKCFG查询获取。                                                                                                                              |
| PEERTYPE            | 对端服务器类型 | 可选必选说明：必选参数 参数含义：用于标识通知任务服务对端服务器的应用类型。 取值范围： SMS(SMS协议)E-MAIL(E-MAIL协议)SOAP(SOAP协议)ThirdSOAP(SOAP协议) 默认值：无。 配置原则：通过LST NTSPEER查询获取。当选择为“ThirdSOAP(SOAP协议)”时，“链路ID”可在取值范围内任意取值。                                  |
| LANGUAGE            | 编码方式    | 可选必选说明：可选参数 参数含义：用于标识SMPP短信编码方式。 仅当“对端服务器类型”选择为“SMS(SMS协议)”时，需设置此参数。 取值范围： ASCIIISO8859-1USC2GBKGSM7 默认值：ASCII。 配置原则：该参数仅适用于SMPP短信，若进行CMPP短信测试时，该参数取值将被忽略。                                                      |
| SMSCONTACTADDRESS   | 短消息联系人  | 可选必选说明：可选参数 参数含义：用于标识接收短消息的用户手机号码。 仅当“对端服务器类型”选择为“SMS(SMS协议)”时，需设置此参数。 取值范围：长度不超过20的十进制数字 默认值：无。 配置原则：无。                                                                                                        |
| EMAILCONTACTADDRESS | 邮件联系人   | 可选必选说明：可选参数 参数含义：用于标识接收邮件的联系人地址。 仅当“对端服务器类型”选择为“E-MAIL(E-MAIL协议)”时，需设置此参数。 取值范围：长度不超过100的字符串 默认值：无。 配置原则：当“对端服务器类型”为“E-MAIL(E-MAIL协议)”时，“邮件联系人”的地址类型必须是电子邮箱格式。                                                  |
| TITLE               | 标题      | 可选必选说明：可选参数 参数含义：用于指定邮件标题。 仅当“对端服务器类型”选择为“E-MAIL(E-MAIL协议)”时，需设置此参数。 取值范围：长度不超过96的字符串 默认值：无。 配置原则：该参数不支持的特殊字符有：双引号（“”）、等号（=）、分号（；）、单引号（‘’）、逗号（，）。                                                               |
| CONTENT             | 通知内容    | 可选必选说明：必选参数 参数含义：用于标识SMS/EMAIL/SOAP/ThirdSOAP通知测试发送的内容。 取值范围：长度不超过3072的字符串 默认值：无。 配置原则： 当“对端服务器类型”选择为“SOAP(SOAP协议)”时，如果该参数包含“<”字符时，该参数取值必须为XML格式，如：<attribute><key>CONTENT</key><value>test</value></attribute> |

## 使用实例

检查UPCF与用户通知的邮件服务器之间创建的链路是否正常，“链路ID”为“1”，“对端服务器类型”为“E-MAIL(E-MAIL协议)”，“邮件联系人”为“test@huawei.com”，“标题”为“TEST”，“通知内容”为“This email is for test only.”。

```
SND NOTIFYTEST: LINKID=1, PEERTYPE=E-MAIL, EMAILCONTACTADDRESS="test@huawei.com", TITLE="TEST", CONTENT="This email is for test only.";
```
