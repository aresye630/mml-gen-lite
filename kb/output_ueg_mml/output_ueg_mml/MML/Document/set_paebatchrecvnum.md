# 设置PAE批量收包的数量（SET PAEBATCHRECVNUM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

PAE的批收数与转发性能有关，设置不当会降低转发性能。

该命令用于设置PAE批量收包的数量。

## 注意事项

- 该命令执行后立即生效。

- 设置批收数的对象包括：普通channel、svc channel、外联口channel、外联口、fabric口。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                                                                                                                                 |
|:-------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NUMBER | PAE批收数量 | 可选必选说明：必选参数  参数含义：该参数表示PAE批量收包的数量。  数据来源：本端规划 取值范围： “PAE_BATCHNUM_64（批收数64）”：批收数64“PAE_BATCHNUM_96（批收数96）”：批收数96“PAE_BATCHNUM_128（批收数128）”：批收数128“PAE_BATCHNUM_160（批收数160）”：批收数160“PAE_BATCHNUM_192（批收数192）”：批收数192“PAE_BATCHNUM_224（批收数224）”：批收数224  默认值：无。  配置原则：无 |

## 使用实例

设置PAE批量收包数量：

```
+++    UNC/*MEID:0 MENAME:project-v6*/        2024-01-24 14:40:06
O&M    #173
%%SET PAEBATCHRECVNUM: NUMBER=PAE_BATCHNUM_224;%%
RETCODE = 0  操作成功

---    END
```
