# 删除授权服务列表（RMV AUTHSERVLIST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

**须知** 

本命令属于高危命令，如果该授权服务列表已通过APPAUTHINFO相关命令授权给指定APP，删除本列表会导致MEP平台为指定APP所签发的token失效，其需要重新申请token才能继续访问，请谨慎删除。

该命令用于删除授权服务列表。

#### 注意事项

- 该命令执行后立即生效。
- 如果本授权服务列表已被关联至某个AUTHSERV对象，不允许删除本授权服务列表，如需删除请先执行RMV AUTHSERV命令解除AUTHSERV对象与本授权服务列表的绑定关系。
- 如果本授权服务列表已被关联至某个APPAUTHINFO对象，不允许删除本授权服务列表，如需删除请先执行RMV APPAUTHINFO命令解除APPAUTHINFO对象与本授权服务列表的绑定关系。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                   |
|:-------|:---------|:-----------------------------------------------------------------------------------------------------------------------|
| NAME   | 授权服务列表名称 | 可选必选说明：必选参数 参数含义：该参数用于指定APP可访问的授权服务列表。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“.”组成，且只能以字母或者数字开头。 默认值：无 配置原则：无 |

#### 使用实例

删除名称为"serviceList"的授权服务列表：

```
RMV AUTHSERVLIST: NAME="serviceList";
```
