# 查询智能分流ULCL部署模式（LST MULDNNULCLMODE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**适用NF：SMF**

该命令用于查询指定智能分流专网DNN的ULCL部署模式。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                                                                                                                                                        |
|:-------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DEDDNN | 智能分流专网DNN | 可选必选说明：可选参数  参数含义：该参数指定智能分流专网DNN名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

- 查询指定智能分流专网DNN的ULCL部署模式，智能分流专网DNN为“special.dnn”，ULCL部署模式为“只使用主锚点分流”。

  ```
  %%LST MULDNNULCLMODE: DEDDNN="special.dnn";%%
  RETCODE = 0  操作成功

  结果如下
  ------------
    智能分流专网DNN  =  special.dnn
       ULCL部署模式  =  只使用主锚点分流
  (结果个数 = 1)
  ```
- 查询全部智能分流专网DNN的ULCL部署模式。

  ```
  %%LST MULDNNULCLMODE:;%%
  RETCODE = 0  操作成功

  结果如下
  ------------
  智能分流专网DNN           ULCL部署模式

  special.dnn1              只使用主锚点分流
  special.dnn2              指定区域优先使用专网UPF分流
  (结果个数 = 2)
  ```

## 输出结果说明

| 输出项名称     | 输出项解释             |
|:----------|:------------------|
| 智能分流专网DNN | 该参数指定智能分流专网DNN名称。 |
| ULCL部署模式  | 该参数用于指定ULCL部署模式。  |
