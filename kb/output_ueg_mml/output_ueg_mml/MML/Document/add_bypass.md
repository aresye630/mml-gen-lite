# 增加Bypass配置(ADD BYPASS)

## 命令功能

**须知** 

此命令是高危命令，仅用于异常时业务紧急恢复，如果执行不当会影响业务处理，需联系华为技术支持确认后再执行。

该命令用于新增一条业务放通的配置信息。

## 注意事项

该命令只支持对N7、N15和N24接口的消息进行放通。

## 参数说明

| 参数ID        | 参数名称      | 参数描述                                                                                                                                                                                                                                                                                             |
|:------------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TYPE        | 放通业务类型    | 用于指定需要放通的业务类型。 取值范围： VOLTE(语音业务)：放通语音业务。N15POLICY(N15接口策略)：放通N15接口策略。N24POLICY(N24接口策略)：放通N24接口策略。 默认值：无。  说明： 当参数“放通业务类型”选择“N24POLICY(N24接口策略)”时，表示HPCF拒绝N24会话的接入。                                                                                                                              |
| VOLTEMETHOD | VoLTE应急手段 | 用于指定UPCF处理EPS Fallback方案下回落到VoLTE呼叫异常时的应急手段。仅当参数“放通业务类型”选择“VOLTE(语音业务)”时，该参数可显并为必选参数。 取值范围： REFUSEVONRN7(拒绝VONR N7会话)：表示UPCF拒绝N7会话的IMS信令承载建立。 默认值：无。  说明： 若现网EPS Fallback方案在UPCF拒绝Rx会话建立返回指定错误码场景下，不支持将5G EPS Fallback呼叫回落到4G VoLTE，且经过评估：在UPCF拒绝现网IMS信令承载建立后，终端产生的上线重试消息不会对现网设备产生较大的冲击，建议配置该参数。 |
| POLICYTYPE  | 策略类型      | 用于指定N15接口需要放通的策略类型。仅当参数“放通业务类型”选择“N15POLICY(N15接口策略)”时，该参数可显并为必选参数。 取值范围： AMPOLICY(AM策略)UEPOLICY(UE策略)ALL(全部策略) 默认值：无。                                                                                                                                                                           |

## 使用实例

增加一条语音业务放通记录。“放通业务类型”为“VOLTE(语音业务)”，“VoLTE应急手段”为“REFUSEVONRN7(拒绝VONR N7会话)”

```
ADD BYPASS: TYPE=VOLTE, VOLTEMETHOD=REFUSEVONRN7;
```
