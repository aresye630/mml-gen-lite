# 删除OSPF进程配置（RMV OSPF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 参考信息

#### 命令功能

该命令用于删除OSPF协议进程。

**须知** 

本命令属于高危命令，该操作会导致路由器之间的OSPF邻接关系中断，且以前的信息将无法恢复。

#### 注意事项

- 该命令执行后立即生效。
- 删除OSPF进程可能会导致业务受损。
- 删除OSPF进程会导致路由器之间的OSPF邻接关系中断。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                   |
|:-------|:-------|:-----------------------------------------------------------------------|
| PROCID | 进程号    | 可选必选说明：必选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 |

#### 使用实例

删除OSPF协议进程号为1的配置：

```
RMV OSPF: PROCID=1;
```

#### 参考信息

OSPF支持多进程，不同的OSPF进程，它们之间的路由功能互不影响，彼此独立。不同OSPF进程之间的路由交互相当于不同路由协议之间的路由交互。一个OSPF进程可以包含多个接口，但一个接口只能属于某一个OSPF进程。多进程可以用来隔离不同接口的路由区域。
