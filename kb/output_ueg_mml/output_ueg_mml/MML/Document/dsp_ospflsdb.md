# 查询OSPF链接状态数据库（DSP OSPFLSDB）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示OSPF的链路状态数据库LSDB信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                   |
|:-------|:-------|:-----------------------------------------------------------------------|
| PROCID | 进程号    | 可选必选说明：可选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 |
| AREAID | 区域标识   | 可选必选说明：可选参数 参数含义：区域标识。 数据来源：对端协商 取值范围：IPv4地址类型。点分十进制格式。 默认值：无          |

#### 使用实例

显示设备OSPF进程号为1的所有链路状态数据库信息：

```
DSP OSPFLSDB: PROCID=1;
```
