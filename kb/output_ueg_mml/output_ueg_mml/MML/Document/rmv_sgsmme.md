# 删除SGS MME实体(RMV SGSMME)

- 命令功能
- 注意事项
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SMSF**

该命令用于删除SGS MME实体指定配置。

#### 注意事项

- 该命令执行后立即生效。

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                   |
|:-------|:-------|:-----------------------------------------------------------------------|
| MMEX   | MME索引  | 可选必选说明：必选参数 参数含义：该参数用于指定一个MME实体，在全局范围内唯一。 数据来源：本端规划 取值范围：0～1999。 默认值：无 |

#### 使用实例

删除MME索引为1的SGS MME实体。

```
RMV SGSMME: MMEX=1;
```
