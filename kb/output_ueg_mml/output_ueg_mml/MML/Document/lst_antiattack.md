#### 命令功能

**适用网元：SGSN、MME**

该命令用来查询防报文攻击个数的上限值。

#### 注意事项

该命令执行后立即生效。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询防报文攻击上限:

LST ANTIATTACK:;

```
%%LST ANTIATTACK:;%%
RETCODE = 0  操作成功。

查询结果如下
------------
 GTP信令流量控制开关  =  启用
每秒接收信令个数上限  =  300
(结果个数 = 1)
---    END
```

#### 输出结果说明

请参考命令**SET ANTIATTACK**参数说明。
