# 创建远端用户数据同步服务器与公钥的绑定关系（ADD RSFTPBINDPUBLICKEY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UDM**

该命令用于创建远端用户数据同步服务器与公钥的绑定关系。如果本端没有使能首次认证，则必须为远端用户数据同步服务器绑定公钥。只有这样，本端SFTP客户端才可以验证对端服务器的公钥从而连接成功。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为10。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                              |
|:-----------|:-------|:------------------------------------------------------------------------------------------------------------------|
| SERVERNAME | 服务器名称  | 可选必选说明：必选参数 参数含义：远端用户数据同步服务器名称。 数据来源：本端规划 取值范围：由数字、字母和下划线组成的不超过16位的字符串。 默认值：无 配置原则：该参数使用ADD RDATASYNSERVER命令配置生成。 |
| KEYNAME    | 密钥名称   | 可选必选说明：必选参数 参数含义：密钥名称。 数据来源：本端规划 取值范围：由数字、字母和下划线组成的不超过63位的字符串。 默认值：无 配置原则：该参数使用ADD RSFTPPUBLICKEY命令配置生成。          |

#### 使用实例

创建远端数据同步服务器与指定公钥的绑定关系，服务器名称为rdata1，公钥名称为rsa1：

```
ADD RSFTPBINDPUBLICKEY: SERVERNAME = rdata1, KEYNAME= rsa1;
```
