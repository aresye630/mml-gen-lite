# 查询NF发现配置（LST NFDISCCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询已配置的NF发现配置信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

```
%%LST NFDISCCFG:;%% 
RETCODE = 0  操作成功 

结果如下--------   
服务类型   链路故障场景NF发现开关       向NRF发起服务发现开关
PES        CHF发现&BSF发现&NWDAF发现    NULL                
PES-NCS    NULL                         NWDAF发现     
(结果个数 = 2)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。

各参数含义请参见设置NF发现配置（SET NFDISCCFG）命令的参数说明。
