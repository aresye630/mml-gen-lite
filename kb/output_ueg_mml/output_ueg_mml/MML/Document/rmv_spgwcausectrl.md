# 删除SGW-C/PGW-C原因值控制参数（RMV SPGWCAUSECTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：PGW-C、SGW-C**

该命令用于删除PGW-C或融合的SGW-C/PGW-C的原因值控制参数。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                                                           |
|:--------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROCEDURETYPE | 流程类型   | 可选必选说明：必选参数  参数含义：该参数用于指定流程类型。  数据来源：本端规划 取值范围： CRT_SES_PROC（初始会话创建流程）MOD_BR_PROC（承载修改流程）  默认值：无  配置原则：无                                                                                                                       |
| CAUSESOURCE   | 异常来源   | 可选必选说明：必选参数  参数含义：该参数用于指定发生异常的来源。  数据来源：本端规划 取值范围： UPF（UPF）POLICY_PCF（PCF策略）CHG_3GPP（3GPP计费）POLICY_PCRF（PCRF策略）RADIUS_AUTH（Radius鉴权）INNER（内部异常）RADIUS_CHG（Radius计费）DIAMETER_AAA（Diameter AAA）CHF_3GPP（3GPP CHF）  默认值：无  配置原则：无 |

## 使用实例

删除会话创建流程中UPF异常的流程控制配置，执行如下命令：

```
RMV SPGWCAUSECTRL: PROCEDURETYPE=CRT_SES_PROC, CAUSESOURCE=UPF;
```
