# 增加指定APN的ULCL部署模式（ADD ULCLAPNDPMODE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF**

该命令用于增加指定APN的ULCL部署模式。

## 注意事项

- 该命令执行后立即生效。

- 增加本配置后，如果没有的更细粒度配置，在此APN内，整机的ULCL部署模式(默认为辅锚点分流优先)被本配置覆盖。

- 最多可输入20000条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|:---------------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN            | APN名称    | 可选必选说明：必选参数  参数含义：该参数指定APN名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。  默认值：无  配置原则：  该参数取值应与ADD CPAPN命令中参数“APN”保持一致。                                                                                                                                                                                                                                        |
| ULCLDEPLOYMODE | ULCL部署模式 | 可选必选说明：可选参数  参数含义：该参数用于指定ULCL部署模式。适用于5G通用分流场景。不影响4G ULCL分流、超级漫游分流场景。如果存在更细粒度的配置(ULCLDNAIDPMODE、ULCLAREADPMODE)，在细粒度上会被对应的配置覆盖。  数据来源：本端规划 取值范围： “AUXSHUNTPREFER（优先使用辅锚点分流）”：优先辅锚点分流。如果没有与辅锚点合设的ULCL，则使用分离的ULCL。在此基础上，如果依然没有分离的ULCL，则退出ULCL分流场景。“AUXSHUNTMUST（只使用辅锚点分流）”：只使用辅锚点分流。如果没有与辅锚点合设的ULCL，则退出ULCL分流场景。“PSASHUNTMUST（只使用主锚点分流）”：只使用主锚点分流。如果没有与主锚点合设的ULCL，则退出ULCL分流场景。  默认值：AUXSHUNTPREFER  配置原则：  整机默认的ULCL部署策略为优先使用辅锚点分流。APN为通用DNN时，考虑继承性影响，建议不配置或设置ULCL部署模式为辅锚点优先分流。 |

## 使用实例

- 增加SMF在APN内选择主锚点作为分流ULCL，APN为huawei1。

  ```
  ADD ULCLAPNDPMODE:APN="huawei1",ULCLDEPLOYMODE=PSASHUNTMUST;
  ```
- 增加SMF在APN内选择辅锚点作为分流ULCL，APN为huawei1。

  ```
  ADD ULCLAPNDPMODE:APN="huawei1",ULCLDEPLOYMODE=AUXSHUNTMUST;
  ```
