# 修改HLB对端链路(MOD HLBPEERL)

- 命令功能

- 输出结果说明

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致链路中断，影响业务处理，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于修改配置数据库中的HLB和对端设备的链路数据记录。

在该命令中，系统通过“对端标识”和“链路标识”参数来唯一标识一条HLB和对端设备的链路数据记录。

该命令在特定场景下才能使用，如需使用该命令修改HLB对端链路请联系华为技术支持。

## 注意事项

- 在该命令中，以下关键参数需要与对端服务器协商：
  - “对端IPV4地址”
  - “对端IPV6地址”
  - “对端端口”

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                                             |
|:----------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PEERID    | 对端标识     | 可选必选说明：必选参数 参数含义：用于定义HLB对端设备的标识。标识一条HLB和对端设备的链路数据记录器的关键字段，用于指定需要修改哪一条HLB和对端设备的链路数据记录，操作员可以使用LST HLBPEERL命令查询获得。 取值范围：0～63 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。      |
| LINKID    | 链路标识     | 可选必选说明：必选参数 参数含义：用于定义HLB的一个对端链路。标识一条HLB和对端设备的链路数据记录器的关键字段，用于指定需要修改哪一条HLB和对端设备的链路数据记录，操作员可以使用LST HLBPEERL命令查询获得。 取值范围：0 默认值：无。 配置原则：无。                            |
| IPVER     | IP版本     | 可选必选说明：可选参数 参数含义：用于指定HLB本端和对端的IP地址版本。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。                                                               |
| LOCALIP   | 本端IPV4地址 | 可选必选说明：可选参数 参数含义：表示HLB与对端设备对接的参数之一，用于指定链路使用的本端IPV4地址，仅当“IP版本”选择“IPV4(IPV4)”时，可设置该参数。 取值范围：IPV4地址 默认值：无。 配置原则：此IP地址必须是本地实际的IP地址且必须先由ADD HLBDEVADDR命令定义，然后才能在此处引用。 |
| LOCALIPV6 | 本端IPV6地址 | 可选必选说明：可选参数 参数含义：表示HLB与对端设备对接的参数之一，用于指定链路使用的本端IPV6地址，仅当“IP版本”选择“IPV6(IPV6)”时，可设置该参数。 取值范围：IPV6地址 默认值：无。 配置原则：此IP地址必须是本地实际的IP地址且必须先由ADD HLBDEVADDR命令定义，然后才能在此处引用。 |
| PEERIP    | 对端IPV4地址 | 可选必选说明：可选参数 参数含义：表示HLB与对端设备对接的参数之一，用于指定链路使用的对端IPV4地址，此IP地址需要与对端协商一致。仅当“IP版本”选择“IPV4(IPV4)”时，可设置该参数。 取值范围：IPV4地址 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。                |
| PEERIPV6  | 对端IPV6地址 | 可选必选说明：可选参数 参数含义：表示HLB与对端设备对接的参数之一，用于指定链路使用的对端IPV6地址，此IP地址需要与对端协商一致。仅当“IP版本”选择“IPV6(IPV6)”时，可设置该参数。 取值范围：IPV6地址 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。                |
| PEERPORT  | 对端端口号    | 可选必选说明：可选参数 参数含义：表示HLB与对端设备对接的参数之一，用于指定链路使用的对端端口，此IP端口需要与对端协商一致。 取值范围：1~65535 默认值：无。 配置原则：运营商统一规划，本端须与对端服务协商配置。                                                  |

## 使用实例

修改HLB和对端实体的链路配置信息。“对端标识”为“1”，“链路标识”为“0”，“IP版本”为“IPV4(IPV4)”，“本端IPV4地址”为“10 .173.8 .128”，“对端IPV4地址”为“10 .173.7.128”，“对端端口号”为“3”。

```
MOD HLBPEERL: PEERID=1, LINKID=0, IPVER=IPV4, LOCALIP="10.173.8.128", PEERIP="10.173.7.128", PEERPORT=3;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释           | 原因分析                                      | 处理建议                                                                |
|------:|:----------------|:------------------------------------------|:--------------------------------------------------------------------|
| 53051 | 对端IP地址和端口已经在使用。 | 输入的对端IP地址和端口已经在使用。                        | 执行LST HLBPEERL命令查询系统中已存在的链路对端IP地址和端口，重新输入对端IP地址和端口号，确保取值不与查询结果存在重复。 |
| 57192 | 本地IP地址不存在。      | 输入的本端IP地址不存在，没有通过ADD HLBDEVADDR命令配置该本地IP。 | 执行LST HLBDEVADDR命令查询已配置的本端IP地址，输入查询到的IP地址后，重新执行该命令。                 |
| 57988 | IP地址类型和IP地址不匹配。 | 输入的IP版本类型和IP地址所属类型不匹配。                    | 重新输入IP版本及IP地址，确保IP版本与IP地址所属类型相匹配。                                   |
