# 撤销删除团体属性过滤器设置（RMV APPLYCOMMUNITYFILTERDELETE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令删除根据团体属性过滤器中指定值删除BGP路由团体属性的规则。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识               | 参数名称        | 参数说明                                                                                                    |
|:-------------------|:------------|:--------------------------------------------------------------------------------------------------------|
| POLICYNAME         | 路由策略名字      | 可选必选说明：必选参数 参数含义：该参数用于指定路由策略名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无                                |
| NODESEQUENCE       | 路由策略节点号     | 可选必选说明：必选参数 参数含义：该参数用于指定路由策略节点号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无                                |
| COMMUNITYNAMEORNUM | 团体属性过滤器名字或号 | 可选必选说明：可选参数 参数含义：该参数用于指定团体属性过滤器名字或团体属性过滤器号。 数据来源：本端规划 取值范围：字符串类型，团体属性过滤器名称其长度范围是1～51。 默认值：无 配置原则：区分大小写。 |

#### 使用实例

删除根据团体属性过滤器中指定值删除BGP路由团体属性的规则：

```
RMV APPLYCOMMUNITYFILTERDELETE:POLICYNAME="a",NODESEQUENCE=10;
```
