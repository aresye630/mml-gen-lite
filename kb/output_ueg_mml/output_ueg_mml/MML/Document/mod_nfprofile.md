# 修改NF信息(MOD NFPROFILE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于修改或调整配置数据库中的一条网络功能信息的数据记录。在该命令中，系统通过“索引”参数来唯一标识一条网络功能信息的数据记录。

## 注意事项

无。

## 参数说明

| 参数标识         | 参数名称        | 参数说明                                                                                                                                                                                       |
|:-------------|:------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ID           | 索引          | 可选必选说明：必选参数 参数含义：标识一条NF信息数据记录的关键字段（其取值不能被修改），用于指定需要对哪一条NF信息数据记录的参数进行修改或调整，操作员可以使用LST NFPROFILE命令查询获得。 取值范围：1 默认值：无。 配置原则：无。                                                                |
| FQDN         | FQDN        | 可选必选说明：可选参数 参数含义：用于定义一个NF在NRF对端注册的FQDN，由运营商统一规划。 取值范围：长度不超过128位的字符串 默认值：无。 配置原则：无。                                                                                                         |
| CONFIGMODE   | 配置模式        | 可选必选说明：必选参数 参数含义：用于定义此PCF局点获取最大签约用户数的方式是手工还是自动。 取值范围： MANU（手工配置）AUTO（自动配置） 默认值：MANU（手工配置） 配置原则： 当该UPCF局点存在数据业务时，设置本参数值为“AUTO（自动配置）”，支持最大签约用户数自动获取。当该UPCF局点仅承载纯语音业务(VoLTE)，设置为“MANU（手工配置）”。 |
| MAXSUBNBR    | 最大签约用户数     | 可选必选说明：可选参数 参数含义：用于指定用户网管北向接口查询UPCF的最大签约用户数。 取值范围：0~2147483647 默认值：无。 配置原则：无。  说明： 当该参数选择为“AUTO（自动配置）”时，命令执行后需要等待6分钟，才能自动获取到最大签约用户数。                                                       |
| VNFINSTID    | VNF实例ID     | 可选必选说明：可选参数 参数含义：用于指定网管北向VNF实例ID。 取值范围：长度不超过64位的字符串 默认值：无。 配置原则：无。  说明： VNF实例ID获取方式：登录U2020 VNF LCM，在“VNF总览”中点击对应的UPCF网元，进入网元管理页面，获取“VNF ID”。                                              |
| UDRVNFINSTID | UDR VNF实例ID | 可选必选说明：可选参数 参数含义：用于指定网管北向UDR VNF实例ID。 取值范围：长度不超过128位的字符串 默认值：无。 配置原则：无。  说明： UDR VNF实例ID获取方式：登录U2020 VNF LCM，在“VNF总览”中点击对应的USCDB网元，进入网元管理页面，获取“VNF ID”。                                    |
| UDRVNFNAME   | UDR VNF名称   | 可选必选说明：可选参数 参数含义：用于指定网管北向UDR VNF的名称。 取值范围：长度不超过128位的字符串 默认值：无。 配置原则：无。  说明： UDR VNF名称获取方式：登录OM Portal，选择“应用管理 > MML”，进入MML命令界面。选择CSP网元执行LST ME命令，“网元类型”为“USCDB”的“网元名称”即“UDR VNF名称”。        |
| RESERVE1     | 预留1         | 可选必选说明：可选参数 参数含义：预留参数。 取值范围：长度不超过128位的字符串 默认值：无。 配置原则：无。                                                                                                                                   |
| RESERVE2     | 预留2         | 可选必选说明：可选参数 参数含义：预留参数。 取值范围：0~2147483647 默认值：无。 配置原则：无。                                                                                                                                    |

## 使用实例

修改最大签约用户数，“索引”为“1”，“配置模式”为“MANU（手工配置）”，“最大签约用户数”为“6000”。

```
MOD NFPROFILE: ID=1, CONFIGMODE=MANU, MAXSUBNBR=6000;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                                                     | 原因分析                                                                                                                       | 处理建议                                                                                              |
|------:|:----------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------|
| 58098 | 自动获取网元VNFID异常，请检查与MANO对接是否正常。                             | 在修改NF信息时，系统会同步从对接的MANO侧查询“VNF实例ID”自动添加到记录中（可通过LST NFPROFILE查看相关参数），若此时网元与MANO对接异常，则会导致所有NF信息添加失败。                          | 联系LCM运维人员，查看UPCF与LCM对接状态，确保UPCF与LCM对接正常，再执行本命令。                                                   |
| 58099 | 自动获取UDR网元VNFID和UDR网元名称异常，请检查PCF与UDR对接是否正常及UDR与MANO对接是否正常。 | 在修改NF信息时，系统会同步从对接的BE侧查询“UDR VNF实例ID”和“UDR VNF名称”，自动添加到记录中（可通过LST NFPROFILE查看相关参数），若此时FE与BE对接异常、或BE与LCM对接异常，则会导致所有NF信息添加失败。 | 查看FE和BE间是否存在DSG链路状态相关告警，若存在，请根据告警帮助清理告警，确保FE与BE对接正常。联系LCM运维人员，查看UDR与LCM对接状态，确保UDR与LCM对接正常，再执行本命令。 |
