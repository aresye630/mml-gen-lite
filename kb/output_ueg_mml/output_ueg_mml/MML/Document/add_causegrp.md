# 增加原因值映射组配置(ADD CAUSEGRP)

#### 命令功能

**适用网元：SGSN、MME**

此命令用于增加一个原因值映射组配置记录。每个原因值映射组表示一个原因值映射规则集合，通常将一个源接口和一个目标接口的原因值映射规则作为一个映射组，如Gr Cause to L3 cause，GTPC cause to L3 cause。CAUSEGRP通常是一组CAUSEMAP的集合。

#### 注意事项

- 此命令最大记录数为127。
- 此命令执行后立即生效。
- 当软参“BYTE\_EX\_B86”BIT5、“BYTE\_EX\_B86”BIT6、“BYTE\_EX\_B86”BIT7、“BYTE\_EX\_B86”BIT8、“BYTE\_EX\_B87”BIT1、“BYTE\_EX\_B87”BIT2中的任意一个设置为“1”时，如果使用了该配置，进行配置增删改操作时需要同时考虑软参控制的场景。

#### 本地用户权限

manage-ug；system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                             |
|:-----------|:-------|:---------------------------------------------------------------------------------|
| CAUSEGRPID | 原因值组标识 | 可选必选说明：必选参数 参数含义：该参数用于指定表示一个原因值映射规则集合的唯一数字ID。 数据来源：整网规划 取值范围：1～127 默认值：无         |
| CAUSEGRPNM | 原因值组名称 | 可选必选说明：可选参数 参数含义：该参数用于指定当前CAUSEGRPID对应的字符名称。 数据来源：整网规划 取值范围：1～32位的字符串 默认值：noname |

#### 使用实例

当某个协议的缺省原因值导致外围设备异常，要使用新增的原因值映射规则。增加一个CAUSEGRPID（原因值组标识）为126的原因值映射规则时，执行如下命令：

ADD CAUSEGRP: CAUSEGRPID=126, CAUSEGRPNM="default1";
