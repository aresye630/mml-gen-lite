# 修改NG接入CHR流程控制模板（MOD NGACCCHRPRCTMPL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

修改NG接入CHR流程控制模板。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 使用实例

修改索引为10的NG接入CHR流程控制模板，设置成功NGCHR流程全部开启，其他参数保持不变：

```
MOD NGACCCHRPRCTMPL: TMPLIDX=10, NGAPCHRSUCCPRC=OTHER-1&INITREG-1&MOBILREG-1&DEREG-1&SYSCHANGE-1&SRVREQ-1&PAGING-1&ANREL-1&N2HO-1&XNHO-1&PDUSESSNEST-1&PDUSESSNMOD-1&PDUSESSNREL-1&UECONUPD-1&LOCATIONREPORT-1&RESERVED2-1&RESERVED3-1&RESERVED4-1&RESERVED5-1&RESERVED6-1;
```
