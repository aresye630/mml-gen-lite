# 查询园区UDM的IP地址（LST EDGEUDMIP）

#### 命令功能

**适用NF：UDM**

该命令用于显示边缘UDM本端IP地址。

#### 注意事项

- 该命令执行后立即生效。
- 默认为输出所有边缘UDM的IP配置信息；若想查看指定边缘UDM配置信息，可指定UDM名称，如果输入的UDM名称在系统中不存在，则查询失败。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                         |
|:-------|:--------|:-------------------------------------------------------------------------------------------------------------|
| IPNAME | IP地址名称  | 可选必选说明：可选参数 参数含义：该参数用于配置园区UDM的IP地址名称。 数据来源：全网规划 取值范围：长度不超过31的由数字和字母组成的字符串，只允许输入0～9，a～z，A～Z和下划线。 默认值：无 配置原则：无 |
| IPTYPE | IP地址的类型 | 可选必选说明：可选参数 参数含义：用于标识园区UDM的IP地址的类型。 数据来源：全网规划 取值范围： DSM：用于用户数据同步。 默认值：无 配置原则：无                               |

#### 使用实例

显示边缘udm本端ip地址信息：

```
LST EDGEUDMIP:;
```
