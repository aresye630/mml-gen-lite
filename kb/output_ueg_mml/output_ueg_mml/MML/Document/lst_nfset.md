# 查询网元集合配置信息(LST NFSET)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询PCF向NRF注册时携带的网元集合配置信息。

- 若需要查询所有网元集合配置信息，不输入任何参数。
- 若需要查询某个组的网元集合配置信息，请输入“组名称”参数。
- 若需要查询某个网元集合配置信息，请输入“索引”参数。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                    |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------------------|
| GRPNAME | 组名称    | 可选必选说明：可选参数 参数含义：用于指示系统按照组名称来查询网元集合配置信息；若不输入，则表示所有的组名称。 取值范围：由数字、字母、“-”或“_”组成的长度不超过32的字符串 默认值：无。 配置原则：无。                |
| INDEX   | 索引     | 可选必选说明：可选参数 参数含义：用于指示系统按照索引来查询网元集合配置信息；若不输入，则表示所有的索引。 取值范围：1~1024 默认值：无。 配置原则：无。                                        |
| SETID   | 集合ID   | 可选必选说明：可选参数 参数含义：用于指示系统按照集合ID来查询网元集合配置信息；若不输入，则表示所有的集合ID。 取值范围：由数字、字母或“-”组成且以数字或字母结尾的长度不超过100的字符串，大小写不敏感 默认值：无。 配置原则：无。 |
| MCC     | 移动国家码  | 可选必选说明：可选参数 参数含义：用于指示系统按照移动国家码来查询网元集合配置信息；若不输入，则表示所有的移动国家码。 取值范围：3位的十进制数字组成的字符串 默认值：无。 配置原则：无。                          |
| MNC     | 移动网络码  | 可选必选说明：可选参数 参数含义：用于指示系统按照移动网络码来查询网元集合配置信息；若不输入，则表示所有的移动网络码。 取值范围：2位或3位的十进制数字组成的字符串 默认值：无。 配置原则：无。                       |

## 使用实例

1. 查询所有的网元集合配置信息：

   ```
   LST NFSET:;
   ```

   ```
   %%LST NFSET:;%%
   RETCODE = 0  操作成功

   操作结果如下 
   ------------------------ 
   组名称       索引   集合ID      移动国家码   移动网络码  
   nfset1       1      xyz         460          012 
   nfset2       2      xyz         460          23  
   (结果个数 = 2)   

   ---    END
   ```
2. 查询“组名称”为“nfset1”的网元集合配置信息：

   ```
   LST NFSET: GRPNAME="nfset1";
   ```

   ```
   %%LST NFSET: GRPNAME="nfset1";%%
   RETCODE = 0  操作成功 

   操作结果如下 
   ------------------------ 
       组名称  =  nfset1
         索引  =  1   
       集合ID  =  xyz    
   移动国家码  =  460
   移动网络码  =  012
   (结果个数 = 1)  

   ---    END
   ```
3. 查询“索引”为“1”的网元集合配置信息：

   ```
   LST NFSET: INDEX=1;
   ```

   ```
   %%LST NFSET: INDEX=1;%%
   RETCODE = 0  操作成功

   操作结果如下 
   ------------------------ 
       组名称  =  nfset1
         索引  =  1   
       集合ID  =  xyz    
   移动国家码  =  460
   移动网络码  =  012
   (结果个数 = 1) 

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见命令**ADD NFSET**的参数说明。
