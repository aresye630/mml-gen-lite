# 增加S1-U IP地址黑名单记录(ADD S1UBLACKLST)

- 使用实例

#### 命令功能

**适用网元：MME**

暂不支持本命令。该命令用于增加S1-U IP地址黑名单记录。当**SET S1UBLACKLSTPARA**中**SNDBLKLSTPLCY**配置为NO时，如果系统在流程中接收到S-GW发送的消息中携带的S1-U IP地址为该命令中配置的IP地址时，确保系统不向eNodeB发送携带该IP地址消息。

#### 注意事项

- 该命令执行后立即生效。
- 执行该命令后，因为S1-U IP地址可能匹配中黑名单记录，4G Attach、PDN连接、TAU、Handover、SR等流程的成功率会有所下降。
- 此命令的最大记录数为256。

#### 本地用户权限

manage-ug；system-ug；

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                              |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPTYPE | IP类型   | 可选必选说明：必选参数 参数含义：该参数用于指定IP地址类型，标识S1-U黑名单IP地址的类型。 数据来源：整网规划 取值范围：“IPV4(IPv4)”“IPV6(IPv6)” 默认值：无 配置原则：系统目前仅支持IPV4地址。                                                                                                                                                                |
| IPV4   | IPv4地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定需要配置的S1-U IPv4黑名单地址。 前提条件：该参数在"IP类型"参数配置为"IPV4"后生效。 数据来源：整网规划 取值范围：IPv4地址类型。 默认值：无 配置原则：IPv4地址不能为0.0.0.0、255.255.255.255和0.x.y.z。IPv4地址在本命令内必须唯一，即该命令配置的所有IPv4地址都不允许相同。                                                                                 |
| IPV6   | IPv6地址 | 可选必选说明：条件必选参数 参数含义：该参数用于指定需要配置的S1-U IPv6黑名单地址。 前提条件：该参数在"IP类型"参数配置为"IPV6"后生效。 数据来源：整网规划 取值范围：IPv6地址类型。 默认值：无 配置原则：IPv6地址必须是全球单播地址，不能为FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF、环回地址（::1）、未指定地址（::）、链路本地地址（FE80::/10）、组播地址（FF00::/8）和IPv4映射地址。IPv6地址在本命令内必须唯一，即该命令配置的所有IPv6地址都不允许相同。 |

#### 使用实例

配置系统不向eNodeB发送携带S1-U黑名单IP地址的消息，增加一条S1-U IP地址为"10.1.1.1"的黑名单记录:

ADD S1UBLACKLST: IPTYPE=IPV4, IPV4="10.1.1.1";
