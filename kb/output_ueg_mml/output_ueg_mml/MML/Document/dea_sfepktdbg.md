# 去激活报文调测过滤（DEA SFEPKTDBG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来去除报文调测过滤配置及去激活调测功能。

#### 注意事项

- 该命令执行后立即生效。
- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                      |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------|
| RUNAME | 资源单元名称 | 可选必选说明：可选参数 参数含义：该参数用来表示资源单元名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～60。 默认值：无 配置原则： 区分大小写，不支持空格。使用DSP RU查看RU名称。 |

#### 使用实例

去激活资源单元名称为“VNODE\_VNRS\_VNFC\_IPU\_0064”的所有配置信息：

```
DEA SFEPKTDBG: RUNAME="VNODE_VNRS_VNFC_IPU_0064";
```
