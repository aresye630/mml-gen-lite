# 查询网元实例信息(LST UDMNFSRV)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询网元实例数据。

- 若需要查询所有网元实例的信息，不输入任何参数。
- 若需要查询某个网元实例的详细信息，请输入“网元实例名称”或其他参数或这些参数的组合。

## 注意事项

- 当**ADD UDMNFSRV**命令里参数“配置方式”选择“Json模式”时：
  - 当查询结果仅显示必要字段信息或显示为“NULL”时，请使用**DSP UDMNFSRV**命令查询完整的网元实例信息。
- 当**ADD UDMNFSRV**命令里参数“配置方式”选择“命令模式”时，无法通过**LST UDMNFSRV**命令查询网元实例的详细信息，如需查询详细信息，请使用**DSP UDMNFSRV**命令查询。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                    |
|:-----------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSNAME  | 网元实例名称 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个网元实例名称来查询网元实例信息数据；若不输入，则表示所有网元实例名称的网元实例信息。 取值范围：长度不超过32位的字符串，只允许输入0～9，a～z，A～Z，“-”和“_”。 默认值：无。 配置原则：无。                                                                                                                                                      |
| NFINSID    | 网元实例标识 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个网元实例标识来查询网元实例信息数据；若不输入，则表示所有网元实例标识的网元实例信息。 取值范围：长度不超过32位的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                               |
| NFTYPE     | 网元类型   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个网元类型来查询网元实例信息数据；若不输入，则表示所有网元类型的网元实例信息。 取值范围： UDM(统一数据管理)AUSF(鉴权服务功能)5G-EIR(设备身份校验) 默认值：无。 配置原则：当“网元类型”参数取值设置为“5G-EIR(设备身份校验)”时，UDM向NRF发起注册的消息中携带的nfType信元取值为5G_EIR。                                                                                        |
| NMFLAG     | 上报网管标志 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个上报网管标志来查询网元实例信息数据；若不输入，则表示所有上报网管标志的网元实例信息。 取值范围：NO(不上报网管)YES(上报网管) 默认值：无。 配置原则：无。                                                                                                                                                                          |
| UPDATEFLAG | 更新标识   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个更新标识来查询网元实例信息数据；若不输入，则表示所有更新标识的网元实例信息。 取值范围： FALSE(不触发更新)：当网元实例信息发生变化时，不触发UDM/UTA向NRF发送更新消息。TRUE(触发更新)：当网元实例信息发生变化时，会触发UDM/UTA向NRF发送更新消息。不同的网元实例之间更新消息发送间隔时长为5s。当批量添加号段信息时，同一个网元实例如果需要多次更新消息，每个发送间隔时长可通过MOD UDMSOFTPARA命令的“NF更新发送时间间隔”参数设置。 默认值：无。 配置原则：无。 |
