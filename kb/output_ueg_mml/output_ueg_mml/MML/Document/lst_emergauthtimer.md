#### 命令功能

**适用NF：UPF**

该命令用于查询惯性运行/应急接入授权开关及授权时长。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询惯性运行/应急接入功能：

```
LST EMERGAUTHTIMER:;
```

```
RETCODE = 0 操作成功。

惯性运行/应急接入授权时长配置
-------------------------------------------
惯性运行/应急接入授权开关 = DISABLE
                     小时 = 1024
(结果个数 = 1)
---    END
```

#### 参考信息

当惯性运行/应急接入授权开关为DISABLE时，惯性运行/应急接入授权时长的值没有意义。

#### 输出结果说明

参见SET EMERGAUTHTIMER的参数说明。
