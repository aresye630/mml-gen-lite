# 查询全局数据加载状态(DSP GLBDATASTATUS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询全局数据加载状态。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询全局数据加载状态。

```
DSP GLBDATASTATUS:;
```

```
%%DSP GLBDATASTATUS:;%%
RETCODE = 0  操作成功

结果如下:
------------------------
PES实例号      开始加载时间           完成加载时间              当前加载表ID
4205999        2024-12-26 15:50:46    2024-12-26 15:50:46       0         
4218287        2024-12-26 15:50:50    2024-12-26 15:50:50       0
(结果个数 = 2)
---    END
```

## 输出结果说明

| 参数名称    | 参数描述                            |
|:--------|:--------------------------------|
| PES实例号  | 表示PES实例号。                       |
| 开始加载时间  | 表示开始加载时间。                       |
| 完成加载时间  | 表示完成加载时间。如果完成加载时间为NULL，表示正在加载中。 |
| 当前加载表ID | 表示当前加载表ID。                      |
