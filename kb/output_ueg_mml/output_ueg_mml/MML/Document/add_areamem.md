# 增加跟踪区成员（ADD AREAMEM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

一个区域由若干个跟踪区组成，该命令用于为指定的区域增加跟踪区成员。

## 注意事项

- 该命令执行后立即生效。

- AREAMEM重叠是指两条AREAMEM记录中MCC和MNC都相等，且TAC范围有重叠。
- 同一个AREACODE的AREAMEM记录之间不能重叠。
- 被NGACCAREALST、NITZPLCY、NGPARKPLCY或SRVAREARES命令中引用的AREACODE之间也不能出现AREAMEM互相重叠的情况。

- 最多可输入4096条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                                                        |
|:---------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AREACODE | 区域编码     | 可选必选说明：必选参数  参数含义：该参数用于标识AMF服务的某区域范围。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~128。  默认值：无  配置原则：  AREACODE参数依赖于AREACODE命令的AREACODE参数。                                               |
| MCC      | MCC      | 可选必选说明：必选参数  参数含义：该参数用于表示组成通用区域的位置区成员的移动国家码，与无线接入网的MCC一致。  数据来源：全网规划  取值范围：字符串类型，输入长度是3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：无                                                     |
| MNC      | MNC      | 可选必选说明：必选参数  参数含义：该参数用于表示组成通用区域的位置区成员的移动网号，与无线接入网的MNC一致。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是2~3。只允许输入十进制数字（0-9）。  默认值：无  配置原则：  两条记录间的MCC相同时，2位MNC与3位MNC的前两个数字不能相同。              |
| BGNTAC   | 跟踪区编码起始值 | 可选必选说明：必选参数  参数含义：该参数用于表示跟踪区编码的起始值。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。TAC编码为16进制数，按照字符串格式输入，字符串长度为6，只能由数字（0-9），字母（A-F、a-f）组成。字母大小写不敏感。  默认值：无  配置原则：无                           |
| ENDTAC   | 跟踪区编码结束值 | 可选必选说明：可选参数  参数含义：该参数用于表示跟踪区编码的结束值。  数据来源：全网规划  取值范围：字符串类型，输入长度是6。TAC编码为16进制数，按照字符串格式输入，字符串长度为6，只能由数字（0-9），字母（A-F、a-f）组成。字母大小写不敏感。本参数表示的跟踪区编码不能小于“跟踪区编码起始值”。  默认值：无  配置原则：无 |
| DESC     | 描述信息     | 可选必选说明：可选参数  参数含义：该参数是对区域成员的描述信息，在运维中起到助记的作用。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~32。  默认值：无  配置原则：无                                                                            |

## 使用实例

为编码为“jq001.pd006.sh.mcc123.mnc45”的区域增加一个跟踪区（MCC="460", MNC="03", TAC="120101"），执行如下命令：

```
ADD AREAMEM: AREACODE="jq001.pd006.sh.mcc123.mnc45", MCC="460", MNC="03", BGNTAC="120101";
```
