# 修改用户消息统计功能配置（MOD AMFIMRFUNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：AMF**

该命令用于修改消息统计任务，配置消息统计的用户范围和接口范围，以方便问题定位。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                 |
|:--------------|:-------|:-------------------------------------------------------------------------------------|
| SUBRANGE      | 用户范围   | 可选必选说明：必选参数  参数含义：该参数用于指定用户范围。  数据来源：本端规划 取值范围： “ALL_USER（所有用户）”：所有用户  默认值：无  配置原则：无 |
| INTERFACETYPE | 接口类型   | 可选必选说明：必选参数  参数含义：该参数用于指定接口类型。  数据来源：本端规划 取值范围： “NAS（Nas）”：Nas  默认值：无  配置原则：无        |

## 使用实例

修改“用户范围”为“所有用户”的记录，关闭Nas消息记录：

```
MOD AMFIMRFUNC:SUBRANGE=ALL_USER,INTERFACETYPE=NAS-0;
```
