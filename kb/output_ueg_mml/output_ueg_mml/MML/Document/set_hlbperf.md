# 设置HTTP2基准负荷(SET HLBPERF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成性能指标统计异常和负荷过载告警上报异常，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置HLB服务的基准负荷。即设置HLB服务对业务数据的处理能力基准。

## 注意事项

基准负荷设置不当，会导致性能指标统计异常，负荷过载告警的上报和恢复出现异常，因此需要与华为技术支持确认后才可以操作。

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                           |
|:--------|:--------|:-------------------------------------------------------------------------------|
| HLBLOAD | HLB基准负荷 | 可选必选说明：可选参数 参数含义：用于标识单个HLB服务每秒发送/接收消息数的能力。 取值范围：100～65535 系统初始设置值：9000 配置原则：无。 |

## 使用实例

设置HLB服务的“HLB基准负荷”为“9000”：

```
SET HLBPERF：HLBLOAD=9000;
```
