# 删除预定义规则关联的DNAI（RMV RULEBINDDNAI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**适用NF：SMF、PGW-C、GGSN**

该命令用于删除预定义规则关联的DNAI。

## 注意事项

- 该命令执行后立即生效。

- 如果DNAI为空， 删除预定义规则关联的所有DNAI。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识     | 参数名称      | 参数说明                                                                                                                                                          |
|:---------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RULENAME | 预定义规则名称   | 可选必选说明：必选参数  参数含义：该参数用于指定预定义规则名称。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。  默认值：无  配置原则：  该参数通过ADD CPRULE命令配置生成。                    |
| DNAI     | 数据网络访问标识符 | 可选必选说明：可选参数  参数含义：该参数用于指定数据网络访问标识符。该参数的数据规划上需要和PNFDNAI命令中的“数据网络访问标识”参数保持一致。  数据来源：全网规划  取值范围：字符串类型，输入长度范围是1~63。字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。  默认值：无  配置原则：无 |

## 使用实例

删除预定义规则关联的特定DNAI。
2. DNAI置为空时，删除预定义规则关联的所有DNAI。

```
RMV RULEBINDDNAI: RULENAME="rule1", DNAI="huawei.com";
```
