# 设置HTTP接口配置(SET HTTPCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于设置HTTP接口配置参数。

## 注意事项

在缺省的情况下，系统在初始化时已经在配置数据库中预置了该命令的参数信息：

- “ID”取值为“1”
- “HTTP2空闲拆链超时时间”取值为“1800”
- “HTTP请求参数校验开关”取值为“0”
- “信令消息重复键和NRF消息校验开关”取值为“0”

## 参数说明

| 参数标识           | 参数名称              | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
|:---------------|:------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ID             | ID                | 可选必选说明：必选参数 参数含义：用于设置HTTP接口配置参数的记录标识。 取值范围：1。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                          |
| HTTPIDLETIME   | HTTP2空闲拆链超时时间     | 可选必选说明：可选参数 参数含义：该参数用于设置HTTP2链路空闲拆链的超时时间。 取值范围：0~86400秒 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                |
| HTTPCHKSWITCH  | HTTP请求参数校验开关      | 可选必选说明：可选参数 参数含义：该参数用于控制UPCF是否对收到的HTTP请求/响应消息中的数据进行校验。 取值范围： 0：校验HTTP消息的数据。1：不校验HTTP消息的数据。 默认值：无。 配置原则：无。  说明： 该参数取值设置为“0”时，根据3GPP协议要求，系统默认对HTTP请求/响应消息中的数据进行校验： 检查HTTP消息的数据是否超过2MB，如果超过2MB，则UPCF处理HTTP请求/响应消息失败。检查HTTP消息的数据中最大的嵌套深度是否超过32层，如果超过32层，则UPCF处理HTTP请求/响应消息失败。检查HTTP消息的数据中叶子节点总数是否超过16000，如果超过16000，则UPCF处理HTTP请求/响应消息失败。检查HTTP消息的数据中的key是否重复，如果重复，则UPCF处理HTTP请求/响应消息失败。                                                                   |
| SIGKEYANDNRFSW | 信令消息重复键和NRF消息校验开关 | 可选必选说明：可选参数 参数含义：该参数用于控制UPCF是否校验信令消息中的重复键和Nnrf接口消息的数据。仅在“HTTP请求参数校验开关”取值为“0”时，该参数的配置才有效。 取值范围： 0：校验所有信令消息的重复键和Nnrf接口消息的数据。1：校验部分信令消息的重复键，不校验Nnrf接口消息的数据。 默认值：无。 配置原则：无。  说明： 该参数取值设置为“0”时，根据3GPP协议要求，系统默认对与NRF交互的Nnrf接口消息中的数据进行校验： 检查Nnrf接口消息的数据是否超过2MB，如果超过2MB，则UPCF处理Nnrf接口消息失败。检查Nnrf接口消息的数据中最大的嵌套深度是否超过32层，如果超过32层，则UPCF处理Nnrf接口消息失败。检查Nnrf接口消息的数据中叶子节点总数是否超过1600000，如果超过1600000，则UPCF处理Nnrf接口消息失败。检查Nnrf接口消息的数据中的key是否重复，如果重复，则UPCF处理Nnrf接口消息失败。 |

## 使用实例

设置HTTP接口配置。“ID”为“1”，“HTTP2空闲拆链超时时间”为“1024”，“HTTP请求参数校验开关”为“1”，“信令消息重复键和NRF消息校验开关”为“1”。

```
SET HTTPCFG: ID=1, HTTPIDLETIME=1024, HTTPCHKSWITCH=1, SIGKEYANDNRFSW=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
