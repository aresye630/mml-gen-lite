# 增加策略管理服务对端服务器(ADD PMSPEER)

- 注意事项

- 输出结果说明

## 命令功能

**须知** 

此命令配置有风险，FTP协议与SOAP（HTTP）协议不安全，推荐使用SFTP、REST或SOAP（HTTPS）协议，请确认是否继续操作。

该命令为配置类命令，用于在配置数据库中添加一条策略管理服务对端服务器的数据记录。

当需要指定策略管理服务对端服务器的类型时，如FTP协议、SFTP协议、SOAP或REST协议，可使用该命令来添加一个增加策略管理服务对端服务器，指定对端服务器类型来实现。

## 注意事项

对端所有服务器数量不能超过最大值255。

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                  |
|:---------|:--------|:------------------------------------------------------------------------------------------------------|
| PEERID   | 对端服务器ID | 可选必选说明：必选参数 参数含义：用于标识对端服务器的ID编号。 取值范围：1～255 默认值：无。 配置原则：无。                                            |
| PEERNAME | 对端服务器名称 | 可选必选说明：必选参数 参数含义：用于具体描述一个对端服务器的名称，以便于识别。值域类型为字符串，区分大小写；对端服务器名称不能重复。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。 |
| PEERTYPE | 对端服务器类型 | 可选必选说明：必选参数 参数含义：用于标识对端服务器的应用类型。 取值范围： FTP(FTP协议)SFTP(SFTP协议)SOAP(SOAP协议)REST(REST协议) 默认值：无。 配置原则：无。  |

## 使用实例

指定对端为FTP服务器。“对端服务器ID”为“1”，“对端服务器名称”为“PMSPEER1”，“对端服务器类型”为“FTP(FTP协议)”。

```
ADD PMSPEER: PEERID=1, PEERNAME="PMSPEER1", PEERTYPE=FTP;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释         | 原因分析            | 处理建议                                                                                    |
|------:|:--------------|:----------------|:----------------------------------------------------------------------------------------|
| 57822 | 对端服务器名称已经被使用。 | 输入的对端服务器名称已被使用。 | 执行LST PMSPEER命令查询全部对端服务器配置信息，结果显示已配置的对端服务器名称。 执行本命令，重新设置“对端服务器名称”，并确保和已存在的“对端服务器名称”不相同。 |
