# 删除APP授权信息（RMV APPAUTHINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

**须知** 

本命令属于高危命令，删除授权信息会导致MEP平台为本APPID所签发的token失效，需要使用该APPID的APP重新申请token才能继续访问，请谨慎删除。

该命令用于删除指定的APP授权信息，删除后使用该APP授权信息的APP无法访问该授权信息所包含的授权服务列表中的服务。

#### 注意事项

- 该命令执行后立即生效。
- 如果本授权信息已被关联至某个APPINSTANCE对象，不允许删除本授权信息。如需删除请先执行RMV AUTHAPPINSTANCE命令解除APPINSTANCE对象和本授权信息的绑定关系。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                       |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------|
| APPID  | APP标识  | 可选必选说明：必选参数 参数含义：该参数用于指定APP访问MEC服务时的标识。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“_”组成。 默认值：无 配置原则：无 |

#### 使用实例

删除标识为"app1"的APP授权信息：

```
RMV APPAUTHINFO: APPID="app1";
```
