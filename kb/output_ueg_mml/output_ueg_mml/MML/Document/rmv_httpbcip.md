# 删除HTTP均衡控制IP(RMV HTTPBCIP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除一条均衡控制HTTP链路的IP记录。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                   |
|:---------|:---------|:-----------------------------------------------------------------------------------------------------------------------|
| BCIPNAME | 均衡控制IP名称 | 可选必选说明：必选参数 参数含义：标识一条均衡控制IP名称的关键字段，用于指定需要删除哪一条均衡控制IP名称的记录，操作员可以使用命令LST HTTPBCIP查询获得。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。 |

## 使用实例

删除“均衡控制IP名称”为“bcipname\_1”的均衡控制HTTP链路的IP记录。

```
RMV HTTPBCIP:BCIPNAME="bcipname_1";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
