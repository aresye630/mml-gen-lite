# 增加PCRF对端AF链路(ADD PAFL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条PCRF实体与对端AF实体的链路数据记录。在该命令中，“对端IPV4地址”/“对端IPV6地址”、“对端端口”、“本端IPV4地址”/“本端IPV6地址”、“本地侦听端口”、“传输协议类型”和“本地端口模式”参数的配置需要与对端网元AF协商。

## 注意事项

- 相同“对端AF标识”下，只能存在一条“对端IPV4地址”/“对端IPV6地址”、“本端IPV4地址”/“本端IPV6地址”、“本地侦听端口”和“传输协议类型”取值都相同且“对端端口”为0的链路。
- 不同“对端AF标识”下，可以各存在一条“对端IPV4地址”/“对端IPV6地址”、“本端IPV4地址”/“本端IPV6地址”、“本地侦听端口”和“传输协议类型”取值都相同且“对端端口”为0的链路。
- IPv6类型的IP地址不支持混合方式表达，即xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:d.d.d.d，其中x表示一个十六进制数（0～9或A～F），而d.d.d.d表示一个IPv4地址。
- “对端IPV6地址”不支持以下特殊地址的配置，其中x表示一个十六进制数（0～9或A～F）：
  - FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF
  - 0000:0000:0000:0000:0000:0000:0000:0001
  - FFxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE8x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FE9x:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEAx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
  - FEBx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx
- 如果两双归属链路的本地端口号相同，且本地对应的链路及IP地址分别为链路1的本地IP1+双归属本地IP2与链路2的本地IP3+双归属本地IP4，此时存在如下几种情况会导致本端地址端口冲突：
  - 本地IP1=本地IP3，双归属本地IP2≠双归属本地IP4
  - 本地IP1=双归属本地IP4，双归属本地IP2≠本地IP3
  - 本地IP1≠本地IP3，双归属本地IP2=双归属本地IP4
  - 本地IP1≠双归属本地IP4，双归属本地IP2=本地IP3

## 参数说明

| 参数标识      | 参数名称        | 参数说明                                                                                                                                                                                                                                                                    |
|:----------|:------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PCRFID    | PCRF标识      | 用于标识PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处索引。 取值范围：1 默认值：无。                                                                                                                                                                                                                 |
| AFID      | 对端AF标识      | 用于标识对端AF实体，该参数必须先由ADD PAF命令定义，然后才能在此处索引。 取值范围：0～15 默认值：无。                                                                                                                                                                                                               |
| LNKID     | 对端链路标识      | 用于在UPCF的配置库中定义一个对端AF实体链路。该参数的配置原则：如果配置多个对端AF实体链路，从0开始顺序配置。实际可配置的最大值受系统软参VRM_MAXCONNECTIONPERPAF的限制，系统当前值可通过LST PCFINSP命令进行查询，具体软参功能及使用方法请参见《UPCF软件参数》。 取值范围：0～31 默认值：无。                                                                                                 |
| DISPMODE  | 分发模式        | 用于定义网络报文的分发模式。 取值范围： SpecialQuintuple（固定五元组转发）WellKnownPort（知名端口分发） 默认值：无。  说明： “知名端口分发”只支持“传输协议类型”为“TCP”，不支持“SCTP”传输协议类型。                                                                                                                                              |
| TPTYPE    | 传输协议类型      | 用于指定链路的传输协议类型，当前可以选择传输控制协议或者流量控制传输协议。 取值范围： TCP(传输控制协议)SCTP(流量控制传输协议) 默认值： 无。                                                                                                                                                                                           |
| DUALHOME  | 双归属开关       | 双归属开关，当“传输协议类型”为“SCTP”时，需要设置此参数。 取值说明： OFF(关闭)ON(打开) 默认值： 无。                                                                                                                                                                                                            |
| CROSSPATH | 交叉路径        | 双归属时的交叉路径配置。当“双归属开关”为“ON(打开)”时，需要设置此参数。 取值说明： OFF(关闭)：表示关闭交叉路径功能。ON(打开)：表示打开交叉路径功能。 默认值：ON(打开)                                                                                                                                                                          |
| DIPVER    | 双归属地址IP版本   | 当双归属开关打开时，需要设置此参数。用于指定本端和对端IP地址、双归属本端和对端IP地址的IP版本类型。 取值范围： IPV4IPV6 默认值：无。                                                                                                                                                                                              |
| IPVER     | IP版本        | 用于指定本端和对端IP地址的IP版本类型。 取值范围： IPV4IPV6 默认值：无。                                                                                                                                                                                                                             |
| DLIP      | 双归属本端IPV4地址 | PCRF与对端AF产品对接的参数之一，用于指定链路使用的双归属本端IPv4地址。需要PCRF与对端AF协商一致；若不一致，可能会导致两者之间的链路无法正常建立。该参数必须已经通过ADD DLBDEVADDR命令添加。 取值范围：IPv4地址 默认值：无。  说明： 当“双归属地址IP版本”选择“IPV4”时，可设置该参数。                                                                                                      |
| DLIPV6    | 双归属本端IPV6地址 | PCRF与对端AF产品对接的参数之一，用于指定链路使用的双归属本端IPv6地址。需要PCRF与对端AF协商一致；若不一致，可能会导致两者之间的链路无法正常建立。该参数必须已经通过ADD DLBDEVADDR命令添加。 取值范围：IPv6地址 默认值：无。  说明： 当“双归属地址IP版本”选择“IPV6”时，可设置该参数。当前UPCF只支持Gx和Rx两种信令接口配置该参数。                                                                            |
| LIP       | 本端IPV4地址    | PCRF与对端AF产品对接的参数之一，用于指定链路使用的本端IPv4地址。需要PCRF与对端AF协商一致；若不一致，可能会导致两者之间的链路无法正常建立。该参数必须已经通过ADD DLBDEVADDR命令添加。 取值范围：IPv4地址 默认值：无。  说明： 当“IP版本”选择“IPV4”时，可设置该参数。当“双归属开关”为“ON(打开)”，且“双归属地址IP版本”选择“IPV4”时，本参数作为PCRF侧diameter链路端点的主IP地址，与“PIP”组成主路径。                             |
| LIPV6     | 本端IPV6地址    | PCRF与对端AF产品对接的参数之一，用于指定链路使用的本端IPv6地址。需要PCRF与对端AF协商一致；若不一致，可能会导致两者之间的链路无法正常建立。该参数必须已经通过ADD DLBDEVADDR命令添加。 取值范围：IPv6地址 默认值：无。  说明： 当“IP版本”选择“IPV6”时，可设置该参数。当前UPCF只支持Gx和Rx两种信令接口配置该参数。当“双归属开关”为“ON(打开)”，且“双归属地址IP版本”选择“IPV6”时，本参数作为PCRF侧diameter链路端点的主IP地址，与“PIPV6”组成主路径。 |
| LPT       | 本地侦听端口      | 本地侦听端口，UPCF内部用于与指定的AF对端建立链路的端口。 取值范围：1～65534 默认值：无。  说明： 当“分发模式”选择“知名端口分发”时，不可设置该参数。                                                                                                                                                                                    |
| DPIP      | 双归属对端IPV4地址 | PCRF与对端AF产品对接的参数之一，用于指定连接使用的双归属对端IPv4地址。需要PCRF与AF协商一致；若不一致，可能会导致两者之间的链路无法正常建立。 取值范围：IPv4地址 默认值：无。  说明： 当“双归属地址IP版本”选择“IPV4”时，可设置该参数。                                                                                                                                    |
| DPIPV6    | 双归属对端IPV6地址 | PCRF与对端AF产品对接的参数之一，用于指定连接使用的双归属对端IPv6地址。需要PCRF与AF协商一致；若不一致，可能会导致两者之间的链路无法正常建立。 取值范围：IPv6地址 默认值：无。  说明： 当“双归属地址IP版本”选择“IPV6”时，可设置该参数。当前UPCF只支持Gx和Rx两种信令接口配置该参数。                                                                                                          |
| PIP       | 对端IPV4地址    | PCRF与对端AF产品对接的参数之一，用于指定连接使用的对端IPv4地址。需要PCRF与AF协商一致；若不一致，可能会导致两者之间的链路无法正常建立。 取值范围：IPv4地址 默认值：无。  说明： 当“IP版本”选择“IPV4”时，可设置该参数。当“双归属开关”为“ON(打开)”，且“双归属地址IP版本”选择“IPV4”时，系统把本参数作为对端AF侧diameter链路端点的主IP地址，与“LIP”组成主路径。                                                        |
| PIPV6     | 对端IPV6地址    | PCRF与对端AF产品对接的参数之一，用于指定连接使用的对端IPv6地址。需要PCRF与AF协商一致；若不一致，可能会导致两者之间的链路无法正常建立。 取值范围：IPv6地址 默认值：无。  说明： 当“IP版本”选择“IPV6”时，可设置该参数。当前UPCF只支持Gx和Rx两种信令接口配置该参数。当“双归属开关”为“ON(打开)”，且“双归属地址IP版本”选择“IPV6”时，系统把本参数作为对端AF侧diameter链路端点的主IP地址，与“LIPV6”组成主路径。                            |
| PPT       | 对端端口        | PCRF与对端AF产品对接的参数之一，用于指定连接使用的对端端口，需要PCRF与AF协商一致；若不一致，可能会导致两者之间的链路无法正常建立。当对端端口为0时，表示不对对端端口做限制，可以接受对端任意端口的连接。 取值范围：0～65534 默认值：无。                                                                                                                                          |
| ADSTS     | 链路管理状态      | 用于指定链路的管理状态，包括：“使能”、“去使能”。“链路管理状态”为“去使能”的链路是无法建立的。 取值范围： DISABLE(去使能)ENABLE(使能) 默认值：ENABLE(使能)                                                                                                                                                                          |
| LPTMODE   | 本地端口模式      | 本端端口模式。 取值范围： WellKnownPort(本地知名端口模式)：表示该链路对外呈现的端口为“本地侦听端口”参数指定的端口。MultiplePorts(本地多端口模式)：表示该链路对外呈现的端口为“本地侦听端口”参数指定的端口。 默认值：MultiplePorts(本地多端口模式)  说明： 该参数建议设置为“MultiplePorts(本地多端口模式)”。                                                                               |
| RPCRFID   | 容灾PCRF标识    | 用于指定一个容灾PCRF实体，该参数必须先由ADD RPCRF命令定义，然后才能在此处索引。 取值范围：0～255 默认值：255  说明： 该参数只在会话备份功能打开且有Rx接口时才需要配置，其他场景不需要配置。如果该参数为255则主备PCRF之间不转发Rx消息。                                                                                                                                   |

## 使用实例

1. 增加PCRF实体和对端AF实体链路（传输协议类型为TCP）。“PCRF标识”为“1”，“对端AF标识”为“0”，“对端链路标识”为“0”，“分发模式”为“固定五元组转发”，“传输协议类型”为“TCP”，“IP版本”为“IPV4”，“本端IPV4地址”为“192.168.11.90”，“本地侦听端口”为“9001”，“对端IPV4地址”为“192.168.11.1”，“对端端口”为“9000”，其他参数使用缺省值。

   ```
   ADD PAFL: PCRFID=1, AFID=0, LNKID=0, DISPMODE=SpecialQuintuple, TPTYPE=TCP, IPVER=IPV4, LIP="192.168.11.90", LPT=9001, PIP="192.168.11.1", PPT=9000;
   ```
2. 增加PCRF实体和对端AF实体链路（传输协议类型为SCTP）。“PCRF标识”为“1”，“对端AF标识”为0，“对端链路标识”为“3”，“分发模式”为“固定五元组转发”，“传输协议类型”为“SCTP”，“双归属开关”为“ON”，“交叉路径”为“ON”，“双归属地址IP版本”为“IPV4”，“双归属本端IPV4地址”为“192.168.11.91”，“本端IPV4”为“192.168.10.90”，“本地侦听端口”为“9004”，“双归属对端IPV4地址”为“192.168.11.4”，“对端IPV4地址”为“192.168.10.3”，“对端端口”为“9003”，“容灾PCRF标识”为“1”，其他参数使用缺省值。

   ```
   ADD PAFL: PCRFID=1, AFID=0, LNKID=3, DISPMODE=SpecialQuintuple, TPTYPE=SCTP, DUALHOME=ON, CROSSPATH=ON, DIPVER=IPV4, DLIP="192.168.11.91", LIP="192.168.10.90", LPT=9004, DPIP="192.168.11.4", PIP="192.168.10.3", PPT=9003, RPCRFID=1;
   ```

该命令执行正常，会返回命令执行成功的提示信息。
