# 查询PID信息(DSP PIDINF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于请求系统显示PID的资源使用情况，如CPU、内存、文件句柄资源等信息。

## 注意事项

指定PID号时，请确保PID号的有效性。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                  |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：用于请求系统显示某一个网元ID的PID信息。操作员可以通过执行LST MODULE命令查询获取网元ID。 取值范围：无。 默认值：无。 配置原则：无。                         |
| MN     | 模块号    | 可选必选说明：必选参数。 参数含义：用于请求系统显示某一个模块号的PID信息。操作员可以通过执行指定“网元ID”参数的LST MODULE命令查询对应的模块号，再根据模块号查询PID信息。 取值范围：无。 默认值：无。 配置原则：无。 |
| PID    | PID    | 可选必选说明：可选参数。 参数含义：用于请求系统显示某一个PID信息；若不输入，则表示所有的PID。 取值范围：无。 默认值：无。 配置原则：无。                                             |

## 输出结果说明

| 输出项名称       | 输出项解释                   |
|:------------|:------------------------|
| Pod名称       | 用于返回PID所属模块的Pod的名称。     |
| 位置描述        | 用于返回PID所属模块的Pod的位置信息。   |
| 网元ID        | 用于返回模块所属的网元ID。          |
| 模块号         | 用于返回模块号。                |
| 主备状态        | 用于返回PID所属模块的主备状态。       |
| PID         | 用于返回PID信息。              |
| 内存占用量(KB)   | 用于返回PID的内存占用量。          |
| 占用CPU时间(ms) | 用于返回PID的消息包处理所消耗的CPU时间。 |
| 接收消息包数量     | 用于返回PID接收消息包的数量。        |
| 发送消息包数量     | 用于返回PID发送消息包的数量。        |
| 发送消息包失败数量   | 用于返回PID发送消息包失败的数量。      |
| 申请消息包数量     | 用于返回PID申请消息包的数量。        |
| 申请消息包失败数量   | 用于返回PID申请消息包失败的数量。      |
| 时间戳(ms)     | 用于返回进程PID启动以来所运行的时间。    |
| 文件句柄        | 用于返回PID中占用文件句柄的个数。      |
