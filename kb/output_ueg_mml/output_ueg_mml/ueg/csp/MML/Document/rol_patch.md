# 回退补丁(ROL PATCH)

## 命令功能

**须知** 

本命令执行之后，将使相应网元进程的当前补丁不可用，从而会中断该补丁所涉及的业务，影响整个系统的正常运行，请慎重使用。

该命令用于请求系统对指定的模块执行回退补丁操作。

热补丁回退是把进程中的补丁从当前版本回退到上一个版本，命令运行成功后补丁回退到上一个版本并处于运行态。

该命令的使用场景为：当操作员使用**CON PATCH**命令确认补丁以后，发现所运行的补丁出现异常或其他原因需要返回到未打该补丁的状态，操作员可以使用该命令对补丁执行回退操作。

如果不输入模块号，表示对整个网元下所有相应的进程回退补丁操作。

## 注意事项

- 本命令执行之后，将使相应网元进程的当前补丁不可用，从而会中断该补丁所涉及的业务，影响整个系统的正常运行，请慎重使用。请操作员在执行该操作前仔细确认任务的可行性。
- 网元ID为0时是对CSP网元的模块进行操作，网元ID>4时是对业务网元的模块进行操作。
- 当部分进程加载失败，报文中显示“补丁正在初始化，操作失败”时，节点正在进行补丁恢复。请稍后重试此操作，如果重试三次问题仍然没有解决，请联系华为技术支持处理。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                 |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：标识一个补丁操作的关键字段，用于请求系统需要对哪一个网元实例实施操作。操作员可以通过在LST ME命令查询获得所有的网元实例ID。 取值范围： 0～1023。 默认值： 无。 配置原则：无。                                                                    |
| MN     | 模块号    | 可选必选说明：必选参数。 参数含义：用于请求系统需要对指定网元下哪一个模块实施操作。 取值范围：0～4294967294。 默认值：无。 配置原则：操作员可以通过在MEID指定的网元实例上使用LST MODULE命令查询模块号及对应的模块类型，然后根据模块号进行补丁操作。缺省为对指定网元下所有相应的模块实施补丁操作。对指定模块实施操作一般只用于故障处理场景。 |
| AS     | 主备标记   | 可选必选说明：必选参数。 参数含义：用于请求系统需要对指定模块的主或备进程实施补丁操作。 取值范围： “ACTIVE(主)”“STANDBY(备)” 默认值：无。 配置原则：其值域类型为枚举类型。缺省为对主、备进程都实施补丁操作。对指定模块的主备实施操作一般只用于故障处理场景。                                          |

## 使用实例

1. 回退热补丁：“网元ID”为“0”，“模块号”为“3017”，“主备标志”为“主”:

`ROL PATCH: MEID=0, MN=3017, AS=ACTIVE;`

```
%%ROL PATCH: MEID=0, MN=3017, AS=ACTIVE;%%
RETCODE = 0  操作成功

操作结果如下
------------
  网元ID  =  0
  模块号  =  3017
主备标记  =  主
补丁名称  =  SPH001
补丁状态  =  空闲
操作结果  =  成功
(结果个数 = 1)

---    END
```

2. 回退热补丁：“网元ID”为“5”，“主备标志”为“主”:

`ROL PATCH: MEID=5, AS=ACTIVE;`

```
%%ROL PATCH: MEID=5, AS=ACTIVE;%%
RETCODE = 0  操作成功

操作结果如下
------------
  网元ID  =  5
  模块号  =  1000
主备标记  =  主
补丁名称  =  SPH001
补丁状态  =  空闲
操作结果  =  成功
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                             |
|:--------|:------------------------------------------------------------------------------------------------------------------|
| 网元ID    | 该参数标识了网元ID。                                                                                                       |
| 模块号     | 该参数所加载补丁的模块号。                                                                                                     |
| 主备标记    | 该参数标识了执行补丁操作的模块状态。其值域类型为枚举类型。 取值说明： “ACTIVE(主)”“STANDBY(备)”                                                       |
| 补丁名称    | 用于标识补丁名称。命名规则是SPHXXX或HPXXXX，其中SPHXXX表示热补丁，HPXXXX表示紧急热补丁。以补丁名称进行操作时，是对补丁包中所有单个补丁文件进行相应操作。                          |
| 补丁状态    | 补丁操作的结果信息之一，用于表示补丁单元的运行状态。其值域范围为枚举类型。 取值说明： “运行”：表示补丁安装成功。“激活”：表示补丁安装过程中的中间状态。“去激活”：表示补丁安装过程中的中间状态。“空闲”：表示没有安装补丁。 |
| 操作结果    | 用于描述补丁操作的结果。                                                                                                      |
