# 修改表最大元组数配置(MOD MAXT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

执行该命令后，需要格式化并重启模块才能生效，可能会导致业务中断，请务必在华为技术支持人员的指导下操作。

该命令用于修改网元表的最大元组数。“最大元组数”是指网元表的最大记录个数。

## 注意事项

- 当“表号”为“76”时，“最大元组数”取值范围是：1~41024。
- 修改最大元组数需执行**FMT**命令进行格式化操作。
- 修改最大元组数需执行**RST MDUTYPE**重启pmu模块后才能生效。
- 如果操作员误操作修改了最大元组数，请立即恢复正确的配置数据，或在华为公司技术服务人员的指导下恢复正确的配置数据。

## 参数说明

| 参数ID   | 参数名称   | 参数描述                                                                                                  |
|:-------|:-------|:------------------------------------------------------------------------------------------------------|
| TID    | 表号     | 可选必选说明：必选参数。 参数含义：用于指定需要修改最大元组数的表的编号（其取值不能被修改）。 取值范围：下拉列表中给出的所有表。 默认值： 无。 配置原则：操作员可以通过LST MAXT命令查询获得。 |
| MAXT   | 最大元组数  | 可选必选说明：必选参数。 参数含义：用于指定表的最大记录数。 取值范围：1～4294967294 默认值： 无。 配置原则：无。                                      |

## 使用实例

修改一张表的最大元组数记录：“表号”为“TID76”，“最大元组数”修改为“41024”。

MOD MAXT: TID=TID76, MAXT=41024;

```
%%MOD MAXT: TID=TID76, MAXT=41024;%%
RETCODE = 0  操作成功
```

## 输出结果说明

- 该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|     错误码 | 错误码解释           | 原因分析                    | 处理建议             |
|--------:|:----------------|:------------------------|:-----------------|
|  100016 | 参数TID的值不在指定范围内。 | 执行命令时未输入TID或输入的TID为无效值。 | 输入正确的TID值。       |
| 5041097 | 配置的表最大元组数超过限制。  | 输入的表最大元组数，超过指定表允许设置的限制。 | 输入合理范围内的表最大元组数值。 |
