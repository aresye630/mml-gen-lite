# 查询模块配置(LST MODULE)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

本命令用于查询模块的静态配置信息:

- 若需要查询全部模块的配置信息，请不要输入任何参数。
- 若需要查询某个Pod上的模块的配置信息，输入“Pod名称”参数。

## 注意事项

系统在执行本命令时需要消耗一定的CPU资源，这种CPU资源消耗与操作员需要查询的进程数成正比，为尽量减少查询大量进程状态时对CPU资源的消耗，建议操作员输入具体的“网元ID”参数进行操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                      |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VMNAME | Pod名称  | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个Pod来查询模块数据；若不输入，则表示所有的Pod。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：操作员可以使用LST PODINFO命令查询获得。                                                                                                                                                                         |
| MEID   | 网元ID   | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个网元ID来查询模块数据；若不输入，则表示所有的网元ID。 取值范围：无。 默认值：无。 配置原则：无。                                                                                                                                                                                                         |
| MN     | 模块号    | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个模块号来查询模块数据；若不输入，则表示所有的模块号。 取值范围：无。 默认值：无。 配置原则：无。                                                                                                                                                                                                           |
| DESC   | 模块类型   | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个模块类型描述来查询模块数据；若不输入，则表示所有的模块类型描述。 取值范围：长度不超过200的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                          |
| ADMST  | 配置管理状态 | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个配置管理状态来查询模块数据；若不输入，则表示所有的配置管理状态。 取值范围：“LOCK(锁定)”：查询的模块支持管理状态，且当前处于锁定状态，不能处理任何服务。“UNLOCK(未锁定)”：查询的模块支持管理状态，且当前处于未锁定状态。处于该状态的模块，可以接入新的服务。 默认值：无。 配置原则：无。                                                                                                      |
| LODMOD | 加载模式   | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个加载模式来查询模块数据；若不输入，则表示所有的加载模式。 取值范围：“AUTOMATIC(自动)”:该模式下启动时，系统自动检测Pod本地保存的文件是否与OMU侧的文件一致，两者一致时优先从Pod本地启动，否则从OMU重新加载。“MANDATORY(强制)”:该模式下模块启动时，不检查Pod本地文件信息，强制从OMU加载并更新本地文件。当模块“加载模式”设置为“MANDATORY(强制)”，在进行第一次加载的60分钟后，加载模式会恢复为“AUTOMATIC(自动)”。 默认值：无。 配置原则：无。 |

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。返回结果请参见**MOD MODULE**命令的参数说明。

命令执行异常，会返回提示没有对应的查询结果。
