# 加载服务器补丁(LOD CPATCH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于请求系统对指定的网元执行加载服务器补丁操作。命令成功运行后参数指定的服务器补丁将被加载到OMU服务端，补丁状态由空闲态（去激活态）变为更新态。

本命令的使用场景为：当在网上运行的系统存在某种缺陷，且需要通过加载服务器补丁的方式解决时，操作员可以执行该命令对服务器补丁进行加载操作。

## 注意事项

- 在执行该操作之前，需要先执行MML命令**LOD PKG**，操作员可以通过**LST PKG**命令查询的结果，仔细确认补丁包的名称、大小和日期信息是否正确。
- 业务网元在进行服务器补丁加载和服务器补丁回退时需要对网元进行锁定，而且必须是进行服务器补丁操作的用户所执行的锁定，否则不能继续进行服务器补丁操作。
- 业务网元在进行服务器补丁加载时，如果该服务器补丁没有包含回退脚本且强制加载服务器补丁标识为NO，则系统会提示用户先进行数据库备份，请选择网络备份模式，将备份文件保存到指定的节点或目录下，备份完成后，再执行**LOD CPATCH**命令，参数强制加载服务器补丁标识选择YES，进行打服务器补丁操作。
- 如果服务器补丁包含了节点进程文件，则命令执行后还需执行**SYN CPATCH**使补丁在节点侧生效。
- 如果已经加载紧急冷补丁，则需要先将紧急冷补丁卸载后再加载当前冷补丁包。

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                                                                                                       |
|:-------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID   | 网元ID      | 可选必选说明：必选参数。 参数含义：标识一个补丁操作的关键字段之一，用于请求系统需要对哪一个网元实例实施操作。 取值范围： 5～1023。 默认值： 无。 配置原则：无。                                                                      |
| PNAME  | 补丁名称      | 可选必选说明：必选参数。 参数含义：标识补丁操作的关键字段之一。 取值范围：长度不超过32的字符串。 默认值：无。 配置原则：命名规则是SPCXXX或CPXXXX，其中SPCXXX表示冷补丁，CPXXXX表示紧急冷补丁。该参数大小写不敏感。                                   |
| FLOD   | 强制加载服务器补丁 | 可选必选说明：必选参数。 参数含义：强制加载服务器补丁标识，用于在服务器补丁没有提供回退脚本的情况下，强制打服务器补丁。 取值范围： “NO(否)”： 在没有回退脚本的情况下，系统不强制打服务器补丁。“YES(是)”： 在没有回退脚本的情况下，系统强制打服务器补丁。 默认值：“NO(否)”。 配置原则：无。 |

## 使用实例

加载服务器补丁：“网元ID”为“5”，“补丁名称”为“SPC001”:

`LOD CPATCH: MEID=5, PNAME="SPC001";`
