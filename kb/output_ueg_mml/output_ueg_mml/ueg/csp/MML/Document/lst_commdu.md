# 查询组件模块信息（LST COMMDU）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询当前系统已经加载的组件模块信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

1. 查询当前系统已经加载的组件模块信息:

`LST COMMDU;`

```
%%LST COMMDU:;%%
RETCODE = 0  操作成功

操作结果如下
------------
网元类型  =  CloudSE2980网元
  网元ID  =  100
组件名称  =  CloudSE2980_SDIR_V500R021C10SPC006T
组件状态  =  正常
(结果个数 = 1)
---    END
```

2. 查询当前系统已经加载的组件模块信息:

`LST COMMDU;`

```
%%LST COMMDU:;%% 
RETCODE = 0  操作成功  
没有查到相应的结果 
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。

| 输出项名称   | 输出项解释                        |
|:--------|:-----------------------------|
| 网元类型    | 用于表示当前系统已经加载组件模块的网元的类型。      |
| 网元ID    | 用于表示当前系统已经加载组件模块的网元的ID。      |
| 组件名称    | 用于表示当前系统已经加载的组件的名称。          |
| 组件状态    | 用于表示当前组件是否正常安装。 取值范围： 正常。异常。 |
