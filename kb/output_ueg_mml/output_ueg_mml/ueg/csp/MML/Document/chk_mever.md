# 检查网元版本(CHK MEVER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于检查网元指定范围内Pod的底层软件版本或进程版本是否与期望的版本一致。

本命令的使用场景为：在进行软件版本升级或者回退时，可以通过本命令检查升级或者回退后Pod的底层软件版本或进程版本是否与期望的版本一致。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                          |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------------------------|
| MEID    | 网元ID   | 可选必选说明：必选参数。 参数含义：用于唯一标识一个网元实例。 取值范围：5～1023 默认值：无。 配置原则：无。                                                                    |
| PLANEID | 工作平面标识 | 可选必选说明：必选参数。 参数含义：表示平面的唯一标识，用于指示系统需要检查哪个平面下的版本；若不输入，则表示所有的工作平面标识。 取值范围：“PLANE0(0平面)”“PLANE1(1平面)”“PLANE2(2平面)” 默认值：无。 配置原则：无。 |

## 使用实例

1. 检查网元5的Pod或进程的版本：

   `CHK MEVER: MEID=5;`

   ```
   %%CHK MEVER: MEID=5;%%
   RETCODE = 420004  部分操作超时

   软件版本检查失败信息
   --------------------

    Pod名称        位置描述      运行版本     期望版本     
    pod_omu0     10.6.111.112      NULL      V200R006C01  
    pod_omu0     10.6.111.112      NULL      V200R006C01  
    pod_omu0     10.6.111.112      NULL      V200R006C01  
   (结果个数 = 3)

   ---    END
   ```
2. 检查网元5的Pod或进程的版本：

   `CHK MEVER: MEID=5;`

   ```
   %%CHK MEVER: MEID=5;%%
   RETCODE = 0  操作成功

   ---    END
   ```

## 输出结果说明

| 输出项名称   | 输出项解释                 |
|:--------|:----------------------|
| Pod名称   | 表示Pod名字。              |
| 位置描述    | 表示Pod的位置。             |
| 运行版本    | 表示Pod底层软件或进程当前运行的版本号。 |
| 期望版本    | 表示Pod底层软件或进程的期望版本。    |
