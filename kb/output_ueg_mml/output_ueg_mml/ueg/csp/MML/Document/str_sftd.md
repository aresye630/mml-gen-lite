# 开始软件调试(STR SFTD)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令为专家维护命令，用于向节点发送软件调试命令。

## 注意事项

- 本命令执行会影响业务，需要慎重使用，使用时请联系华为技术有限公司技术支持获取调试命令全集列表，必须在华为技术支持人员的指导下操作。
- 不同的模块有不同的控制字，不同的控制字也有不同的PM参数，如果控制字和PM参数输入不准确，不会出现错误提示。

## 使用实例

常用的软调命令：

1. 查看注册参数：

   此软调命令可以查看一些重要的注册参数，“控制字”为“0x30”。

   `STR SFTD: MEID=81, MN=82, PID=183, CTRL="0X30";`
2. 查看节点指定类型跟踪的信息：

   此软调命令可以查看节点指定类型跟踪的信息，“控制字”为“0x40”，查看跟踪类型为“16”的跟踪信息。

   `STR SFTD: MEID=81, MN=82, PID=183, CTRL="0x40", PM0="16";`
3. 查看指定跟踪句柄的信息：

   此软调命令可以查看指定跟踪句柄的定位条件信息，组合条件信息，以及跟踪句柄下的任务号（组件内部的任务号），“控制字”为0x70。可以通过查看节点指定类型跟踪的信息获取句柄值，然后将十进制的句柄值转换为十六进制， 如21160 = 52 A8，其低八位（A8）对应PM0，高八位（52）对应PM1。

   `STR SFTD: MEID=81, MN=82, PID=183, CTRL="0x70", PM0="0xA8", PM1="0X52";`
4. 查看指定跟踪任务的信息：

   此软调命令可以查看指定跟踪任务的过滤条件等信息，“控制字”为“0x50”。跟踪任务号可以通过查看指定跟踪句柄的信息获取跟踪任务号，以跟踪任务号“4”为例。

   `STR SFTD: MEID=81, MN=82, PID=183, CTRL="0x50", PM0="4";`
5. 查看指定跟踪任务的跟踪消息的发送统计：

   此软调命令可以查看指定跟踪任务的跟踪消息的发送统计，“控制字”为“0xB2”。如果所有数据都为0，则统计结果不显示出来。 跟踪任务号可以通过查看指定跟踪句柄的信息获取跟踪任务号。以跟踪任务号“59”为例。

   `STR SFTD: MEID=81, MN=82, PID=183, CTRL="0xB2", PM0="59";`
6. 查看全局跟踪消息的发送统计：

   此软调命令可以查看全局跟踪消息的发送统计，“控制字”为“0xB0”。

   `STR SFTD: MEID=81, MN=82, PID=183, CTRL="0xB0";`
7. HA心跳超时时间处理：

   需要对模块的HA心跳超时时间进行设置，可以采用如下步骤进行：

   1. 设置HA超时时间。
      1. 使用**DSP HAMDU**命令查询仲裁PMU信息。

         `DSP HAMDU:;`

         ```
         %%DSP HAMDU:;%%
         RETCODE = 0  操作成功

         Pod结果如下
         --------------
                     网元ID  =  0
                   仲裁域ID  =  63
                     模块号  =  3017
                 Pod名称  =  cgplite-0
                   位置描述  =  10.7.50.20
                   主备状态  =  主用
                   可用状态  =  正常
             分配的内存(KB)  =  287070
         内存占用率(百分比)  =  63
          CPU占用率(百分比)  =  5
                   管理状态  =  不支持
         (结果个数 = 1)

         ---    END
         ```
      2. 开启仲裁PMU的心跳超时时间为开启状态。

         `STR SFTD: MEID=0, MN=3017, EX=ACTIVE,PID=128, CTRL="1", PM0="35", PM1="0", PM2="1";`

         查看PMU的开关是开启成功：

         ```
         EME [AMU_HB_PreTimeout]FUN-0 HA_AMU_HBPreTimeoutEnable ON M3017P128F63S00S 2014-05-05 21:12:59
         ```
      3. 设置HA的超时时间为20秒，自动恢复时间为60分钟。

         `STR SFTD: MEID=0, MN=3017, EX=ACTIVE,PID=128, CTRL="1", PM0="35", PM1="1", PM2="20", PM3="0", PM4="60";`
   2. 查看软调日志。

      确认心跳超时时间是否设置成功:

      ```
      EME [AMU_HB_PreTimeout]FUN-1 HA_AMU_HBPreTimeout 20 sec M3017P128F63S00M 2014-05-05 23:03:16 
      EME [AMU_HB_PreTimeout]FUN-1 HA_AMU_HBPreTimeout_AutoResume 60 min M3017P128F63S00M 2014-05-05 23:03:16
      ```
   3. 恢复设置。

      `STR SFTD: MEID=0, MN=3017, EX=ACTIVE,PID=128, CTRL="1", PM0="35", PM1="0", PM2="0";`

      查看软调日志，心跳超时时间是否关闭:

      ```
      EME [AMU_HB_PreTimeout]FUN-0 HA_AMU_HBPreTimeoutEnable OFF M3017P128F63S00M 2014-05-05 23:04:34
      ```
