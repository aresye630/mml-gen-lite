## 命令功能

**须知** 

该命令可能会影响模块上业务运行，请慎重使用该命令。

本命令用于请求系统对指定的模块执行倒换操作。模块倒换后，备用模块接替原主用模块工作，原主用模块处于备用状态。

本命令的使用场景为：

- 在开局、扩容和升级场景中，需要对主备工作的模块进行倒换验证。
- 在维护场景中，需要人为的将备用模块升为主用模块，主模块降为备模块，如对主备模块打补丁。

## 注意事项

- 被倒换的模块必须为主用，可以执行**DSP MODULE**命令查询模块的“主备状态”。
- 倒换可能会影响业务运行。执行倒换命令，最好避开话务高峰期，例如凌晨2:00～4:00。
- 本命令支持分权分域。当用户没有倒换模块的操作权限，不允许执行本命令。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                        |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：用于指示系统倒换哪个网元ID的模块。 取值范围：0～1023 默认值：无。 配置原则：无。                                                                                                                                                                                                                                             |
| MN     | 模块号    | 可选必选说明：必选参数。 参数含义：用于指示系统倒换哪个模块号的模块。 取值范围：0～4294967294 默认值：无。 配置原则：操作员可以使用LST MODULE命令查询获得。                                                                                                                                                                                                                  |
| FORCE  | 强制倒换模块 | 可选必选说明：可选参数。 参数含义：用于标识当前系统倒换模块的方式是否为强制倒换。 取值范围： “YES(是)”：在备进程状态正常的情况下，系统在倒换模块时，PMU不发消息给AMU咨询是否允许倒换，PMU直接强制倒换将模块进行复位操作。“NO(否)”：在备进程状态正常的情况下，系统在倒换模块时，PMU先发消息给AMU咨询是否允许倒换。若AMU回消息可以倒换，则PMU将倒换模块，进行复位操作，否则不进行倒换。如主备模块之间备份未完成或业务处理未完成，则可能不能完成模块的倒换。 默认值：“NO(否)”。 配置原则：通常系统无需强制倒换模块，只有当倒换不成功或者有特别强制要求时，才需要配置该参数。 |

## 使用实例

倒换Pod模块。

```
//查询与即将被倒换的模块对应备用模块的可用状态是否为正常。同时确认PMU模块的可用状态是否为正常，以确定模块是否能够进行倒换。
DSP MODULE:;
```

```
//倒换“网元ID”为“5”，“模块号”为“1520”的模块。
SWP MODULE: MEID=5, MN=1520;
```

```
//查询模块状态，对照检查倒换前的模块状态，以确定倒换是否成功。
DSP MODULE:;
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|      错误码 | 错误码解释         | 原因分析                       | 处理建议                                           |
|---------:|:--------------|:---------------------------|:-----------------------------------------------|
| 32100014 | 网元或模块不存在。     | 模块参数配置错误。                  | 请根据错误码提示信息并参考参数说明中的配置原则，重新输入参数后，再执行命令。         |
|   425137 | 指定模块的仲裁模块不存在。 | 当没有仲裁PMU模块时，所有模块都不能发生倒换。   | 使用DSP MODULE命令确认PMU模块状态。PMU模块正常后，再执行命令。        |
|   425616 | 模块状态故障。       | 当要倒换的模块状态故障时，无法倒换。         | 使用DSP MODULE命令确认PMU模块状态。PMU模块正常后，再执行命令。        |
|     4030 | 对端模块不是备用状态。   | 只有主备模块才能倒换，如果本模块没有备模块无法倒换。 | 使用DSP MODULE命令查询模块状态，确认是否本模块存在备份模块，如果不存在，不能倒换。 |
|     4031 | 对端模块不存在。      | 只有主备模块才能倒换，如果本模块没有备模块无法倒换。 | 使用DSP MODULE命令查询模块状态，确认是否本模块存在备份模块，如果不存在，不能倒换。 |
