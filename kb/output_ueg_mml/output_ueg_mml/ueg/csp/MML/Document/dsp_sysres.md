# 查询系统资源(DSP SYSRES)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于请求系统显示系统资源，如Pod内模块的内存分区、消息包、消息队列、定时器、文件句柄相关的资源的使用情况，以便及时了解系统运行状况。用户可以根据需要查询Pod内模块的不同资源。

## 注意事项

- 执行本命令时系统需要消耗主机一定的CPU资源，这种CPU资源消耗与操作员需要查询的系统资源数成正比，为尽量减少查询大量系统资源状态时对主机CPU资源的消耗，建议操作员输入具体的“Pod名称”参数进行操作，即不建议操作员只输入“查询方式”参数进行操作。
- Pod的内存资源有一部分会提供给文件系统使用，这部分资源同时会显示在磁盘资源的查询结果中。
- FusionSphere云平台下，如果组网方式是EVS或OVS，则对于MRFP网元和SBC网元应用类型存在预留核的Pod，该命令查询到的虚拟CPU为Pod配置的虚拟CPU，不包含预留虚拟CPU的信息。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RESTYPE | 查询方式   | 可选必选说明：必选参数。 参数含义：用于请求系统是按照哪种查询方式来显示资源信息。 取值范围：“MODULE(模块)”：该参数用于查询Pod内模块的内存分区，消息包，消息队列，定时器、文件句柄相关的资源信息。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| VMNAME  | Pod名称  | 可选必选说明：必选参数。 参数含义：用于请求系统显示哪个Pod上的系统资源；若不输入，则表示所有的Pod。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| MEID    | 网元ID   | 可选必选说明：可选参数。 参数含义：用于请求系统显示哪个网元ID的资源信息。 取值范围：无。 默认值：无。 配置原则：仅当本命令中的“查询方式”参数选择为“MODULE(模块)”时该参数有效，用于请求系统显示哪个网元ID的资源信息；若不输入，则表示查询所有的网元ID。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| MN      | 模块号    | 可选必选说明：可选参数。 参数含义：用于请求系统显示哪个模块号的资源信息。 取值范围：无。 默认值：无。 配置原则：仅当本命令中的“查询方式”参数选择为“MODULE(模块)”时有效，用于请求系统显示哪个模块号的资源信息；若不输入，则表示查询所有的模块号。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| RESID   | 模块资源ID | 可选必选说明：可选参数。 参数含义：用于请求系统是按照哪种模块资源ID来显示资源信息 取值范围： “ALL(所有)”：用于查询所有的模块资源信息。“SYSTEMMEM(系统内存分区)”：用于查询模块的系统内存分区信息。“USERMEM(用户内存分区)”：用于查询模块的用户内存分区信息。“EXTRAMEM(扩展内存分区)”：用于查询模块的扩展内存分区信息。“TOTALMEM(整个内存分区)”：用于查询模块的整个内存分区信息。“SYSMSG(系统消息包)”：用于查询模块的系统消息包信息。“APPMSG(应用消息包)”：用于查询模块的应用消息包信息。“VBUSQUE(系统消息队列)”：用于查询模块的系统消息队列信息。“ABSTMR(绝对定时器组)”：用于查询模块的绝对定时器组信息。“RELTMR(相对定时器)”：用于查询模块的相对定时器信息。“TCKTMR(Tick定时器)”：用于查询模块的Tick定时器信息。“SECTMR(秒定时器)”：用于查询模块的秒定时器信息。“MINTMR(分钟定时器)”：用于查询模块的分钟定时器信息。“FILEHANDLE(文件句柄)”：用于查询模块的文件句柄信息。 默认值：“ALL(所有)”。 配置原则：仅当本命令中的“查询方式”参数选择为“MODULE(模块)”时有效，用于请求系统是按照哪种模块资源ID来显示资源信息；若不输入，则表示查询模块所有的资源ID。 |

## 使用实例

1. 查询“Pod名称”为“cgplite-0”的Pod的用户内存资源信息：

   `DSP SYSRES: RESTYPE=MODULE, VMNAME="cgplite-0", RESID=USERMEM;`

   ```
   %%DSP SYSRES: RESTYPE=MODULE, VMNAME="cgplite-0", RESID=USERMEM;%%
   RETCODE = 0  操作成功

   Pod模块操作结果如下
   -------------------
      Pod名称  =  cgplite-0
        位置描述  =  10.7.90.60
          网元ID  =  0
          模块号  =  3016

          总数量  =  225280 KB
        空闲数量  =  73987 KB
   资源占用率(%)  =  67
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

| 输出项名称    | 输出项解释                                                                                                                                                                                                                |
|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Pod名称    | 用于标识服务实例对应Pod的名称。                                                                                                                                                                                                    |
| 网元ID     | 用于标识子网下的一个网元实例。                                                                                                                                                                                                      |
| 模块号      | 用于标识网元实例下的一个模块。                                                                                                                                                                                                      |
| 资源名称     | 用于返回查询的某种系统资源名称： “AbsTmr”：绝对定时器组“SysMem”：系统内存分区“TickTmr”：Tick定时器“SecTmr”：秒定时器“MinTmr”：分钟定时器“RelTmr”：相对定时器“UsrMem”：用户内存分区“VBUSQue”：系统消息队列“AppMsg”：应用消息包“SysMsg”：系统消息包“ExtraMem”：扩展内存分区“FileHdl”：文件句柄“TotalMem”：整个内存分区 |
| 总数量      | 用于返回查询的某种系统资源的总数量。                                                                                                                                                                                                   |
| 空闲数量     | 用于返回查询到的某种系统资源没有被占用的数量。                                                                                                                                                                                              |
| 资源占用率(%) | 用于返回查询的某种系统资源的占用率（%）。  说明： 对于磁盘资源，若是ext3文件系统，约5%的磁盘空间会预留给root用户，不算在占用率中。对于磁盘资源，此值的大小和在LINUX系统下用df命令查到的值保持一致。                                                                                                         |
| 位置描述     | 用于返回查询的Pod的位置信息。                                                                                                                                                                                                     |
