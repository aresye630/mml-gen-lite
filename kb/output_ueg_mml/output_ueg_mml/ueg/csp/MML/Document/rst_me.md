# 复位网元(RST ME)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

**须知** 

执行该命令后，将会复位网元的所有进程，中断网元业务，请务必在华为技术支持人员的指导下操作。

该命令用于复位该网元所有大颗粒服务的模块。

## 注意事项

该网元的业务中断后，可执行该命令重启网元的模块。

对于故障态的模块，如果模块正在启动，该命令不会重新启动该模块。

执行该命令会复位此网元的所有进程，在安装部署过程中执行可能会导致部署失败。

该命令为CGPLite独有命令，只能复位部署了大颗粒的网元。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                       |
|:-------|:-------|:-----------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：用于唯一标识一个网元实例。 取值范围：5～1023 默认值：无。 配置原则：无。 |

## 使用实例

部署Pod的场景下，复位一个网元下的所有模块，网元ID为6，执行如下命令：

`RST ME: MEID=6;`

```
%%RST ME: MEID=6;%%
RETCODE = 0  操作成功

Pod 操作结果如下
------------------

 pod001       10.16.20.18  1002        CCU       操作成功
 pod001       10.16.20.18  1003        CCU       操作成功
(结果个数 = 3)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释             |
|:--------|:------------------|
| Pod名称   | 用于标识模块属于哪个Pod。    |
| 位置描述    | 用于标识模块所在Pod的位置信息。 |
| 业务模块号   | 用于标识业务模块号也即逻辑模块号。 |
| 模块描述    | 用于标识主机侧模块的描述信息。   |
| 操作结果    | 用于标识操作的结果。        |
