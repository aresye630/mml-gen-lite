# 平面合并(CBN PLANE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于在网元的无损升级或扩容场景中将主备平面合并为一个主平面。

本命令的使用场景为：当操作员在执行**SYN MEVER**命令升级主备平面成功后，操作员可以使用本命令合并升级平面，结束升级或者扩容过程。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                    |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------|
| MEID     | 网元ID   | 可选必选说明：必选参数。 参数含义：用于唯一标识一个网元实例。 取值范围：5～1023 默认值：无。 配置原则：无。                                                                              |
| VER      | 版本号    | 可选必选说明：可选参数。 参数含义：指定合并平面后的进程版本号。如果该参数不输入，则合并平面后的进程版本号为主工作区的版本。 取值范围：长度不超过64的英文字符串。 默认值：无。 配置原则：无。                                       |
| OPERTYPE | 操作类型   | 可选必选说明：可选参数。 参数含义：用于指定该命令是在升级场景或者扩容场景下执行。如果该参数不输入，则按照升级场景处理。 取值范围： “UPGRADE(升级)”：表示升级场景下执行该命令。“EXPAND(扩容)”：表示扩容场景下执行该命令。 默认值：无。 配置原则：无。 |

## 使用实例

合并网元5的平面：

`CBN PLANE: MEID=5;`
