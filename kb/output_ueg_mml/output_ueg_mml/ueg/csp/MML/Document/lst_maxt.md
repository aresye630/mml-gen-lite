# 查询表最大元组数配置(LST MAXT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为用于查询表的最大元组数。最大元组数的概念请参见**MOD MAXT**命令的相关解释。

- 若需要查询所有表的最大元组数，请不要输入任何参数。
- 若需要查询某张表的最大元组数，请输入“表号”。

## 注意事项

无。

## 参数说明

| 参数ID   | 参数名称   | 参数描述                                                                   |
|:-------|:-------|:-----------------------------------------------------------------------|
| TID    | 表号     | 可选必选说明：必选参数。 参数含义：用于指定需要查询最大元组数的表的编号。 取值范围：下拉列表中给出的所有表。 默认值：无。 配置原则：无。 |

## 使用实例

查询某张表的最大元组数：“表号”为“TID76”。

`LST MAXT: TID=TID76;`

```
%%LST MAXT: TID=TID76;%%
RETCODE = 0  操作成功

操作结果如下
------------
      表号  =  76
最大元组数  =  41024
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项说明   | 输出项描述                  |
|:--------|:-----------------------|
| 表号      | 用于返回当前查询的最大元组数所在的表的编号。 |
| 最大元组数   | 用于返回当前查询的表的最大元组数。      |
