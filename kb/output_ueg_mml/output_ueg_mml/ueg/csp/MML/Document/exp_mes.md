# 导出网元数据(EXP MES)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于导出指定网元数据库表数据，但不会导出存储过程。命令成功后可以执行命令**LST EXPINFO**查看导出的二进制类型的文件信息和网元信息。导出网元数据功能用于导出CGPLite上的网元数据，供在镜像环境上进行导入网元数据使用。在OM Portal界面选择“系统 > 文件传输 > CGPLite文件 > 备份”选择exp\_backup或exp\_datatool，将导出的网元数据下载到本地。

导出的二进制格式数据文件从目录“exp\_backup”下载，导出的网元数据文件命名规则为：“Exp\_TabFile\_YYYYMMDDhhmmss.tar.gz”，其中*YYYYMMDDhhmmss*表示导出文件时的系统本地时间的年月日时分秒。

导出的文本格式数据文件从目录“exp\_datatool”下载，导出的网元数据文件命名规则如下：

- 如果不输入MEIDS和TBNAME参数时，文件命名规则为“exp\_datatool\_ALL.tar.gz”。
- 如果只输入MEIDS时，文件命名规则为“exp\_datatool\_NEX.tar.gz”，其中*X*表示导出文件时的网元ID。
- 如果只输入TBNAME参数时，文件命名规则为“exp\_datatool\_ALL\_YYYY.tar.gz”，其中*YYYY*表示导出的表格名称。
- 如果输入MEIDS和TBNAME参数时，文件命名规则为“exp\_datatool\_NEX\_YYYY.tar.gz”，其中*X*表示导出文件时的网元ID，*YYYY*表示导出的表格名称。

**说明** 

- 为了兼容网元信息收集场景能正常使用，导出的文本格式数据文件除了导出按照上述规则命令的文件，还额外生成一个命名为“exp\_datatool.tar.gz”的导出文件，两者的文件内容一致。

本命令的使用场景为：当系统需要测试或者系统出现故障时，可使用本命令导出指定网元数据库表数据，建立镜像环境进行相关测试和问题定位。

## 注意事项

- 导出网元数据每次都自动导出CSP网元的数据。
- 当用户需要导出的文件在“exp\_datatool”目录下已经存在时，如执行此命令导出文本格式文件，则导出文件自动覆盖OMU上已有的文本格式的数据导出文件。
- 当选择需要导出性能数据，并且网元的性能数据比较多时，请选择按照不同网元ID逐个导出。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                    |
|:------------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEIDS       | 网元ID      | 可选必选说明：必选参数。 参数含义：该参数指定需要导出的网元列表，不同的网元ID之间通过空格隔开。若不输入，则表示导出所有网元的数据。 取值范围：无。 默认值：无。 配置原则：无。                                                                                              |
| NEEDPDS     | 导出/导入性能数据 | 可选必选说明：必选参数。 参数含义：用于指定是否需要导出性能数据。如果不关心性能统计结果相关数据，此参数选用默认值NO(否)。 取值范围： “YES(是)”：导出性能数据。“NO(否)” ：不导出性能数据。 默认值: NO(否)。 配置原则：无。                                                             |
| EXPTYPE     | 导出文件类型    | 可选必选说明：可选参数。 参数含义：用于指定导出的数据的文件类型。 导出的二进制格式文件可以用于数据库表数据的恢复。而文本格式的导出文件一般用于数据检查工具检查系统数据的正确性。若不输入，则表示使用默认的二进制格式导出。 取值范围： “BIN(二进制)”：导出文件为二进制格式。“TEXT(文本)”：导出文件为文本格式。 默认值: BIN(二进制)。 配置原则：无。 |
| FASTEXPTYPE | 快速导出      | 可选必选说明：必选参数。 参数含义：当导出文件类型为文本类型时，可以通过输入快速导出参数，来选择是否只导出日常维护所必需的表数据。 取值范围： “YES(是)”：只导出日常维护所必需的表数据。“NO(否)” ：导出网元下所有表格数据或者导出单表数据。 默认值: NO(否)。 配置原则：无。                                       |
| TBNAME      | 表格名称      | 可选必选说明：可选参数。 参数含义：当导出文件类型为文本类型的时，可以输入表格名称参数导出单表。此参数不输入时，导出网元下所有表格数据。 取值范围：无。 默认值：无。 配置原则：无。                                                                                             |
| EXPCTR      | 导出控制      | 可选必选说明：可选参数。 参数含义：用于告警及事件相关数据的导出控制。 取值范围： “YES(是)”：不导出告警及事件相关数据。“NO(否)” ：导出告警及事件相关数据。 默认值: NO(否)。 配置原则：无。                                                                               |

## 使用实例

1. 导出网元ID为0和5的表格数据为二进制格式，并导出性能数据：

   `EXP MES: MEIDS="0 5", NEEDPDS=YES, EXPTYPE=BIN;`
2. 导出网元ID为0和5的表格数据为二进制格式，但不导出性能数据：

   `EXP MES: MEIDS="0 5", NEEDPDS=NO, EXPTYPE=BIN;`
3. 导出网元ID为0和5的表格数据为文本格式，并导出性能数据：

   `EXP MES: MEIDS="0 5", NEEDPDS=YES, EXPTYPE=TEXT;`
4. 导出名为"TBL\_LANGUAGEDESC"的表格数据为文本格式：

   `EXP MES: NEEDPDS=YES, EXPTYPE=TEXT, TBNAME="TBL_LANGUAGEDESC";`
5. 选择快速导出所有网元的表格数据为文本格式：

   `EXP MES: EXPTYPE=TEXT, FASTEXPTYPE=YES;`
6. 选择快速导出表名为"TBL\_LANGUAGEDESC"的表格数据为文本格式：

   `EXP MES: EXPTYPE=TEXT, TBNAME="TBL_LANGUAGEDESC", FASTEXPTYPE=YES;`
7. 导出名为"TBL\_LANGUAGEDESC"的表格数据为文本格式：

   `EXP MES: NEEDPDS=YES, EXPTYPE=TEXT, TBNAME="TBL_LANGUAGEDESC";`

   导出网元ID为0和5的表格数据为二进制格式，但不导出性能数据,不导出告警及事件相关数据：

   `EXP MES: MEIDS="0 5", NEEDPDS=NO, EXPTYPE=BIN, EXPCTR=YES;`
