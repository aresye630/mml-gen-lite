# 回退MML配置脚本(ROL MMLCONF)

## 命令功能

**须知** 

本命令执行之后可能会导致部署或者扩缩容流程变化，请慎重执行。

本命令用于回退指定的MML配置脚本。

本命令的使用场景为：如果执行**LOD MMLCONF**加载的MML配置脚本有误，可以指定网元和文件名称执行本命令进行回退，确保部署或者扩缩容成功。

## 注意事项

如果当前网元的部署或者扩缩容任务未结束，不要执行该命令。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                           |
|:-------|:-------|:-----------------------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：用于指示系统给哪个网元回退脚本。 取值范围：0～1023 默认值：无。 配置原则：无。                                  |
| FNM    | 文件名称   | 可选必选说明：必选参数。 参数含义：用于指示系统回退指定MML脚本的文件名称。 取值范围：MML配置脚本文件名称。 默认值：无。 配置原则：MML配置脚本文件的完整名称以“.xml”结尾。 |

## 使用实例

回退“网元ID”为“5”，“文件名称”为“tmp.xml”的MML配置文件。

`ROL MMLCONF: MEID=5, FNM="tmp.xml";`

```
%%ROL MMLCONF: MEID=5, FNM="tmp.xml";%%
RETCODE = 0   操作成功

---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|      错误码 | 错误码解释          | 原因分析                                                                           | 处理建议            |
|---------:|:---------------|:-------------------------------------------------------------------------------|:----------------|
| 32500006 | 文件名称无效。        | 文件名称超过128个字符。文件名称不是以.xml结尾。文件名称中含有除字母、数字、‘_’、‘-’，‘.’以外的字符。文件名称除去后缀（.xml）后长度为0。 | 请输入正确的文件名称。     |
| 32500007 | 指定脚本不存在。       | 网元ID或者文件名称输入不正确。指定的脚本已经回退。                                                     | 输入正确的网元ID和文件名称。 |
| 32500008 | 请在升级观察期结束后再执行。 | 回退脚本文件的当前网元正处于升级期、回退期或者升级观察期。                                                  | 观察期结束后再执行该操作。   |
