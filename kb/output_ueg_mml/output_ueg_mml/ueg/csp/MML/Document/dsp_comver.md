# 查询组件版本(DSP COMVER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于请求系统显示组件版本，包括节点进程组件版本、软件版本和OS版本信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                               |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VMNAME | Pod名称  | 可选必选说明：必选参数。 参数含义：用于请求系统显示哪个Pod上的节点进程组件版本、软件版本或OS版本信息。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：操作员可以通过执行LST MODULE命令查询获取Pod名称。                                                              |
| VERTP  | 版本类型   | 可选必选说明：可选参数。 参数含义：用于请求系统是按照哪种版本类型来显示节点进程组件版本、软件版本或OS版本信息；若不输入，则表示查询所有的版本类型。 取值范围：“COMVER(组件版本)”：用于查询节点进程组件版本信息。“SFTVER(软件版本)”：用于查询软件版本信息。“OS(OS版本)”：用于查询操作系统版本信息。 默认值：无。 配置原则：无。   |
| MEID   | 网元ID   | 可选必选说明：可选参数。 参数含义：仅当本命令中的“版本类型”参数为“COMVER(组件版本)”时该参数有效，用于请求系统显示哪个网元ID的节点进程组件版本信息；若不输入，则表示所有的网元ID。 取值范围：无。 默认值：无。 配置原则：无。                                                           |
| MN     | 模块号    | 可选必选说明：可选参数。 参数含义：仅当本命令中的“版本类型”参数为“COMVER(组件版本)”时该参数有效，用于请求系统显示哪个模块号的节点进程组件版本信息；若不输入，则表示所有的模块号。 取值范围：无。 默认值：无。 配置原则：操作员可以通过在MEID指定的网元实例上执行LST MODULE命令查询对应的模块号，再根据模块号查询节点进程组件版本信息。 |

## 使用实例

1. 查询“Pod名称”为“cgplite-0”的组件版本信息：

   `DSP COMVER: VMNAME="cgplite-0";%%`

   ```

   RETCODE = 0  操作成功

   cgplite-0  10.10.10.10 0       3016    V100R020C01SPC110  RUNLOG    RUNLOG V100R001C01           
   cgplite-0  10.10.10.10 0       3016    V100R020C01SPC110  ALARM     ALM V100R001C01

   cgplite-0  10.10.10.10 0       3016    V100R020C01SPC110  OAM       OAM V100R002C01             
   (结果个数 = 5)  

   Pod 软件版本信息 
   --------------------------------  
   Pod名称    位置描述         软件名称  软件版本信息                        
   cgplite-0  10.10.10.10      MONITOR   MON version V100R020C01SPC110      
   cgplite-0  10.10.10.10      BOOT      BOOT version V100R020C01SPC110     
   cgplite-0  10.10.10.10      STARTER   STARTER version V100R020C01SPC110

   (结果个数 = 1)  

   ---    END
   ```
2. 查询“Pod名称”为“cgplite-0”，“版本类型”为“SFTVER”的软件版本信息：

   `DSP COMVER: VMNAME="cgplite-0", VERTP=SFTVER;`

   ```
   %%DSP COMVER: VMNAME="cgplite-0", VERTP=SFTVER;%%
   RETCODE = 0  操作成功

   Pod软件版本信息
   ------------------
    Pod名称             位置描述     软件名称   软件版本信息

    cgplite-0           10.10.10.10  MONITOR    MON version V100R020C01SPC100
    cgplite-0           10.10.10.10  BOOT       BOOT version V100R020C01SPC100
    cgplite-0           10.10.10.10  STARTER    STARTER version V100R020C01SPC100     
   (结果个数 = 3)

   ---    END
   ```
3. 查询“Pod名称”为“cgplite-0”，“版本类型”为“OS”的版本信息：

   `DSP COMVER: VMNAME="cgplite-0", VERTP=OS;`

   ```
   %%DSP COMVER:VMNAME="cgplite-0", VERTP=OS;%%
   RETCODE = 0  操作成功

   Pod OS版本信息
   ----------------
           Pod名称   =  cgplite-0
           位置描述  =  10.10.10.10
   操作系统版本信息  =  Linux version 3.10.0-10.0.0.0.h47.eulerosv2r7.x86_64 #1 SMP Mon Jun 25 00:00:00 UTC 2018
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

| 输出项名称    | 输出项解释                                  |
|:---------|:---------------------------------------|
| Pod名称    | 用于返回进程所在Pod的名称。                        |
| 位置描述     | 用于返回Pod所在的位置信息。                        |
| 网元ID     | 用于返回进程所属的网元号信息，具体请参考各个业务网元的说明。         |
| 模块号      | 用于返回该进程的模块号信息。如果业务模块是主备的，则有两个模块对应该模块号。 |
| 平台版本号    | 用于返回CSP平台的版本号。                         |
| 组件名称     | 用于返回进程使用的组件名称。                         |
| 组件版本     | 用于返回进程使用的组件版本。                         |
| 软件名称     | 用于返回底层软件名称。                            |
| 软件版本信息   | 用于返回软件版本信息。                            |
| 操作系统版本信息 | 用于返回Pod上运行的操作系统版本信息。                   |
