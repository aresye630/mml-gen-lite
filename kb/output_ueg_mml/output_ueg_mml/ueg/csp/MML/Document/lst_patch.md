# 查询OMU侧补丁信息(LST PATCH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为专家维护命令，当需要获取热补丁在OMU侧的详细信息时，操作员可以使用该命令实现这一目的。

## 注意事项

- 若“显示详细信息”选择“是”，则生成的查询结果以模块号为单位表示各个模块的进程补丁状态，否则生成的查询结果以网元为单位表示各个网元最高版本的补丁状态。
- 当“显示详细信息”选择“否”时，若当前补丁状态表中的补丁状态为“部分运行”、“部分激活”、“部分去激活”或“空闲”，请再次执行该命令，“显示详细信息”选择“是”进行补丁查询，然后根据详细信息内容对补丁做相应处理。
- 网元ID为0时是对CSP网元的模块进行操作，网元ID>4时是对业务网元的模块进行操作。
- 补丁查询结果可能包含在线加载和离线加载的补丁。
- 该命令的报文中热补丁版本信息与**DSP PATCH**可能存在差异。热补丁的运行状态请以**DSP PATCH**为准。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                      |
|:-----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID       | 网元ID   | 可选必选说明：可选参数。 参数含义：用于请求系统需要对哪一个网元实例实施操作。如果不指定网元ID则默认为对所有网元进行操作。 取值范围：0～1023。 默认值：无。 配置原则：无。                                                                                |
| DETAILINFO | 显示详细信息 | 可选必选说明：必选参数。 参数含义：用于请求系统是否需要显示详细信息。若显示详细信息，则生成的查询结果以模块号为单位表示各个模块的进程补丁状态，否则生成的查询结果以网元为单位表示各个网元最高版本的补丁状态。 取值范围： “NO(否)”“YES(是)” 默认值：“NO(否)” 配置原则：无。                         |
| MN         | 模块号    | 可选必选说明：可选参数。 参数含义：用于请求系统需要对指定网元下哪一个模块实施操作。 取值范围：0～4294967294。 默认值：无。 配置原则：操作员可以通过LST MODULE命令查询模块号及对应的模块类型，然后根据模块号进行补丁操作。该参数仅当显示详细信息选择为“YES(是)”时有效。如果不指定模块号则默认为对所有模块进行操作。 |
| AS         | 主备标记   | 可选必选说明：可选参数。 参数含义：用于请求系统需要对指定模块的主或备进程实施补丁操作。取值范围： “ACTIVE(主)”“STANDBY(备)” 默认值：无。 配置原则：其值域类型为枚举类型。该参数仅当显示详细信息选择为“YES(是)”时有效。如果不指定主备标记则默认对主备模块均进行操作。                        |

## 使用实例

1. 查询OMU侧补丁状态：“网元ID”为“0”，其他参数不输入

   `LST PATCH: MEID=0, DETAILINFO=NO;`

   ```
   %%LST PATCH: MEID=0, DETAILINFO=NO;%%
   RETCODE = 0  操作成功

   当前补丁状态
   ------------
         网元ID   =  0
        模块类型  =  PMU
        补丁名称  =  SPH002
   OMU侧补丁状态  =  运行
   (结果个数 = 1)

   ---    END
   ```
2. 查询所有网元的补丁状态：“显示详细信息”为“YES”

   `LST PATCH: DETAILINFO=YES;`

   ```
   %%LST PATCH: DETAILINFO=YES;%%
   RETCODE = 0  操作成功

   当前补丁状态
   ------------
    网元ID  网元名称  模块号  模块类型  主备标记  补丁名称  OMU侧补丁状态

    0       站点管理  1300    PMU       主        SPH002    运行         
    5       MSX       1001    CCU       主        NULL      空闲         
   (结果个数 = 2)

   ---    END
   ```

## 输出结果说明

| 输出项名称    | 输出项解释                                                                                                                                                                                                                                            |
|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 网元ID     | 用于标识网元的ID。                                                                                                                                                                                                                                       |
| 网元名称     | 用于标识网元的名称。                                                                                                                                                                                                                                       |
| 模块号      | 用于标识已加载了热补丁的模块号。                                                                                                                                                                                                                                 |
| 模块类型     | 用于标识模块所属网元的类型。                                                                                                                                                                                                                                   |
| 主备标记     | 用于标识执行补丁操作的模块状态。其值域类型为枚举类型。 值: “ACTIVE(主)”“STANDBY(备)”                                                                                                                                                                                           |
| 补丁名称     | 用于标识补丁名称。命名规则是SPHXXX或HPXXXX，其中SPHXXX表示热补丁，HPXXXX表示紧急热补丁。以补丁名称进行操作时，是对补丁包中所有单个补丁文件进行相应操作。                                                                                                                                                         |
| OMU侧补丁状态 | 补丁操作的结果信息之一，用于表示补丁包或补丁单元的运行状态。其值域范围为枚举类型。 取值说明： “运行”：表示补丁安装成功，此状态为补丁安装的最终状态。“激活”：表示补丁安装过程中的中间状态。“去激活”：表示补丁安装过程中的中间状态。“空闲”：表示没有安装补丁。“部分运行”：表示存在部分模块没有正确安装补丁。请联系华为技术支持处理。“部分激活”：表示补丁安装过程中的异常中间状态。请联系华为技术支持处理。“部分去激活”：表示补丁安装过程中的异常中间状态。请联系华为技术支持处理。 |
