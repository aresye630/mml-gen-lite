## 命令功能

**须知** 

该命令为高危命令，会将指定网元下，CGPLite服务中的某个证书应用场景对应的证书同步至CertMgr服务，可能导致网元的TLS和HTTPS链路异常，请确认证书内容的正确性后再执行。

该命令用于将指定网元下，CGPLite服务中的某个证书应用场景对应的证书同步至CertMgr服务。

该命令的使用场景：当CGPLite服务本地证书与CertMgr服务证书不一致时，需要以CGPLite服务本地证书为准时，执行该命令将CGPLite服务本地证书信息同步至CertMgr服务。

**说明** 

该命令仅在非三方场景下支持。

- 该命令仅对部分网元生效，不支持的网元执行时会返回“519809 当前网元不支持此操作”错误码。
- 证书同步后，证书应用场景关联的证书名称可能会发生变更。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                  |
|:----------|:-------|:------------------------------------------------------------------------------------------------------|
| MEID      | 网元ID   | 可选必选说明：必选参数。 参数含义：网元ID。 取值范围：5~1023。 默认值：无。 配置原则：无。                                                   |
| SCENENAME | 场景名称   | 可选必选说明：必选参数。 参数含义：证书应用场景名称。 取值范围：长度不超过200个字符，只能包含英文字符、数字、中划线和下划线，且只能以字母开头。 默认值：无。 配置原则：场景名称和证书组一对一绑定。 |

## 使用实例

同步“网元ID”为“100”“场景名称”为“test”证书应用场景对应的证书信息：

```
SYN CERT: MEID=100, SCENENAME="test";
```

```
%%SYN CERT: MEID=100, SCENENAME="test";%%
RETCODE = 0  操作成功

---    END
```
