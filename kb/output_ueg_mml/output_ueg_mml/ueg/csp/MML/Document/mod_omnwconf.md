# 配置OM网络探测参数（MOD OMNWCONF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**须知** 

网络探测参数修改可能导致OMLB服务主备倒换，可能**导致网管或VNFM断链**；关闭网络探测时，会导致OM网络故障无法检测。

用于配置OM网络故障探测参数。

#### 注意事项

- 该命令仅限角色为Administrators的用户执行。

- 请勿将网络亚健康告警阈值设置过低，否则可能会导致ALM-136001 OM网络资源故障告警上报或清除异常。

该命令存在系统初始记录，参数的初始设置值如下：

| IPTYPE          | SWITCH   |   PERIOD |   SWITCHTHRESHOLD |
|:----------------|:---------|---------:|------------------:|
| VIRTUALIP(浮动IP) | ON(开)    |        2 |                 3 |

| IPTYPE           | SWITCH   | IPADDRTYPE             |   PERIOD |   ALARMTHRESHOLD |   SUBHEALTHTHRESHOLD |   SUBHEALTHPERIOD |
|:-----------------|:---------|:-----------------------|---------:|-----------------:|---------------------:|------------------:|
| PHYSICALIP(物理IP) | ON(开)    | IPV4/IPV6(IPv4/IPv6类型) |        2 |               15 |                    5 |                 5 |

#### 参数说明

| 参数标识               | 参数名称          | 参数说明                                                                                                                                                      |
|:-------------------|:--------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPTYPE             | IP类型          | 可选必选说明：必选参数。 参数含义：网络探测的IP类型。 取值范围： VIRTUALIP(浮动IP)：登录OM Portal的浮动IP。PHYSICALIP(物理IP)：服务器的物理IP。 默认值：VIRTUALIP(浮动IP)。 配置原则：无。                               |
| SWITCH             | 网络探测开关        | 可选必选说明：必选参数。 参数含义：网络探测开关状态。 取值范围： ON(开)。OFF(关)。 默认值：ON(开)。 配置原则：无。                                                                                        |
| IPADDRTYPE         | IP地址类型        | 可选必选说明：该参数在“IPTYPE”配置为“PHYSICALIP(物理IP)”时为条件必选参数。 参数含义：IP地址类型。 取值范围： IPV4(IPv4类型)。IPV6(IPv6类型)。IPV4/IPV6(IPv4/IPv6类型) 默认值：IPV4/IPV6(IPv4/IPv6类型)。 配置原则：无。 |
| PERIOD             | 探测周期（秒）       | 可选必选说明：必选参数。 参数含义：探测周期，单位秒(s)。 取值范围：1~3600。 默认值：2。 配置原则：无。                                                                                                |
| SWITCHTHRESHOLD    | 倒换阈值          | 可选必选说明：当IP类型为VIRTUALIP(浮动IP)时为必选参数。 参数含义：OMLB服务主备倒换的阈值，当网络探测失败次数达到倒换阈值时，主备倒换。 取值范围：1~3600。 默认值：3。 配置原则：无。                                                 |
| ALARMTHRESHOLD     | 告警阈值          | 可选必选说明：当IP类型为PHYSICALIP(物理IP)时为必选参数。 参数含义：告警阈值，当网络探测失败/成功次数达到告警阈值时，上报/清除ALM-136001 OM网络资源故障告警。 取值范围：1~3600。 默认值：15。 配置原则：无。                               |
| SUBHEALTHTHRESHOLD | 网络亚健康告警阈值（%）  | 可选必选说明：当IP类型为PHYSICALIP(物理IP)时为可选参数。 参数含义：用于指定在“网络亚健康检测周期（分钟）”内，丢包率达到该参数取值时，上报ALM-136001 OM网络资源故障告警。 取值范围：2~10。 默认值：5。 配置原则：无。                            |
| SUBHEALTHPERIOD    | 网络亚健康检测周期（分钟） | 可选必选说明：当IP类型为PHYSICALIP(物理IP)时为可选参数。 参数含义：用于指定执行网络亚健康检测时，统计丢包率的周期。 取值范围：5~30。 默认值：5。 配置原则：无。                                                              |

#### 使用实例

1. 配置浮动IP探测信息：

   ```
   %%MOD OMNWCONF: IPTYPE=VIRTUALIP, SWITCH=ON, PERIOD=10, SWITCHTHRESHOLD=3;%% 
   RETCODE = 0  操作成功  
   ---    END
   ```
2. 配置物理IP探测信息：

   ```
   %%MOD OMNWCONF: IPTYPE=PHYSICALIP, SWITCH=ON, IPADDRTYPE=IPV4/IPV6, PERIOD=2, ALARMTHRESHOLD=15, SUBHEALTHTHRESHOLD=10, SUBHEALTHPERIOD=5;%% 
   RETCODE = 0  操作成功  
   ---    END
   ```
