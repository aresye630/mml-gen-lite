# 设置仲裁PMU信息(SET HAMDU)

- 注意事项

## 命令功能

**须知** 

该命令会重新设置仲裁者，可能会影响业务正常运行，请慎重使用该命令。

本命令用于设置仲裁PMU。

本命令的使用场景为：当用户需要将仲裁功能从当前仲裁PMU迁移到其他PMU上时，可以执行此命令设置新的仲裁PMU。

## 注意事项

- 本命令为维护命令，使用本命令设置仲裁PMU后，系统后续也可能会动态选举出新的仲裁PMU。
- 只有PMU进程可以被指定为仲裁PMU。
- 请选择和主用OMU不在同一节点的PMU设置为仲裁PMU，如果将仲裁PMU和主用OMU设置到同一节点上可能会降低系统可靠性。

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                                           |
|:-------|:----------|:-----------------------------------------------------------------------------------------------|
| MDUNO  | 仲裁PMU的模块号 | 可选必选说明：必选参数。 参数含义：用于指定要设置为仲裁PMU的PMU模块号。 取值范围：0～4294967294 默认值：无。 配置原则：操作员可以使用LST MODULE命令查询获得。 |

## 使用实例

设置模块号为3016的PMU为仲裁PMU。

`SET HAMDU: MDUNO=3016;`

```
%%SET HAMDU: MDUNO=3016;%%
RETCODE = 0  操作成功

---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|      错误码 | 错误码解释      | 原因分析       | 处理建议                                    |
|---------:|:-----------|:-----------|:----------------------------------------|
| 32001370 | 指定的PMU未配置。 | 指定的PMU未配置。 | 使用LST MODULE命令查询CSP网元模块，确认输入已配置的PMU模块号。 |
