# 加载MML配置脚本(LOD MMLCONF)

## 命令功能

**须知** 

本命令执行之后可能会导致部署或者扩缩容流程变化，请慎重执行。

本命令用于将指定的MML配置脚本加载到OMU上。

本命令的使用场景为：如果MML配置脚本异常会导致网元部署或扩缩容失败，执行该命令加载正确的脚本，确保部署或者扩缩容成功。

## 注意事项

如果CSP部署时的MML配置脚本有误，需使用正确的MML配置脚本的CSP包重新部署。

如果当前网元的部署或者扩缩容任务未结束，不要执行该命令。

加载之前要保证MML配置脚本文件已经正确上传到cgplite容器中的“/opt/pub/software/tmp”目录下。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                     |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：用于指示系统给哪个网元加载脚本。 取值范围：0～1023 默认值：无。 配置原则：无。                                                                            |
| FNM    | 文件名称   | 可选必选说明：必选参数。 参数含义：用于指示系统加载指定MML脚本的文件名称。 取值范围：必须输入cgplite容器中的“/opt/pub/software/tmp”目录下的MML配置脚本文件名称。 默认值：无。 配置原则：MML配置脚本文件的完整名称以“.xml”结尾。 |

## 使用实例

加载“网元ID”为“5”，“文件名称”为“tmp.xml”的MML配置文件。

`LOD MMLCONF: MEID=5, FNM="tmp.xml";`

```
%%LOD MMLCONF: MEID=5, FNM="tmp.xml";%%
RETCODE = 0   操作成功

---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|      错误码 | 错误码解释          | 原因分析                                                                           | 处理建议                                                                          |
|---------:|:---------------|:-------------------------------------------------------------------------------|:------------------------------------------------------------------------------|
| 32500006 | 文件名称无效。        | 文件名称超过128个字符。文件名称不是以.xml结尾。文件名称中含有除字母、数字、‘_’、‘-’，‘.’以外的字符。文件名称除去后缀（.xml）后长度为0。 | 请输入正确的文件名称。                                                                   |
| 32500007 | 指定脚本不存在。       | 加载的文件未上传到“/opt/pub/software/tmp”目录。                                            | 上传MML脚本文件到cgplite容器中的“/opt/pub/software/tmp”目录下。                              |
| 32500008 | 请在升级观察期结束后再执行。 | 加载脚本文件的当前网元正处于升级期、回退期或者升级观察期。                                                  | 观察期结束后再执行该操作。                                                                 |
| 32500009 | 指定脚本解析失败。      | 加载的MML脚本不符合XML规范。加载的MML脚本文件权限不正确。                                              | 检查并修改加载的脚本，确保符合XML规范后，上传MML脚本文件到cgplite容器中的“/opt/pub/software/tmp”目录下，再执行该操作。 |
