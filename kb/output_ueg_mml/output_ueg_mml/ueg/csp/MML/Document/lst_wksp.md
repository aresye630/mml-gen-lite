# 查询工作区(LST WKSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询网元工作区信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：可选参数。 参数含义：用于指示系统需要查询哪个网元的工作区信息。若不输入，则表示查询全部网元的工作区信息。 取值范围：“0~1023”。 默认值：无。 配置原则：无。                                                                          |
| WKSPID | 工作区标识  | 可选必选说明：可选参数。 参数含义：用于指示系统是查询“WKSP1(工作区1)”还是“WKSP2(工作区2)”的工作区信息。若不输入，则表示查询全部工作区的信息。 取值范围： “WKSP1(工作区1)”“WKSP2(工作区2)” 默认值：无。 配置原则：无。                                   |
| WKSPST | 工作区状态  | 可选必选说明：可选参数。 参数含义：用于指示系统是查询工作区状态为“ACTIVE(主用)”还是“STANDBY(备用)”的工作区信息。若不输入，则表示查询工作区状态为“ACTIVE(主用)”和“STANDBY(备用)”的工作区信息。 取值范围： “ACTIVE(主用)”“STANDBY(备用)” 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询工作区信息:

   `LST WKSP:;`

   ```
   %%LST WKSP:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    域标识  子网标识  网元ID  工作区标识  网元的版本         工作区状态  网元类型        锁定状态

    1       0         0       工作区1     V200R002C00SPC200  主用        CSP网元         解锁状态
    1       0         5       工作区1     V200R006C01        主用        MSOFTX3000网元  锁定状态
    1       0         5       工作区2     V200R006C02        备用        MSOFTX3000网元  解锁状态
   (结果个数 = 3)

   ---    END
   ```
2. 查询5网元的工作区信息:

   `LST WKSP: MEID=5;`

   ```
   %%LST WKSP: MEID=5;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
       域标识  =  1
     子网标识  =  0
       网元ID  =  5
   工作区标识  =  工作区1
   网元的版本  =  V200R006C01
   工作区状态  =  主用
     网元类型  =  MSOFTX3000网元
     锁定状态  =  解锁状态
   (结果个数 = 1)

   ---    END
   ```
