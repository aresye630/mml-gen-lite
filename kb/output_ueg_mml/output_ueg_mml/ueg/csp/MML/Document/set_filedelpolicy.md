# 设置文件删除策略(SET FILEDELPOLICY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

策略开启时，不满足设置天数要求的文件会被定时删除。策略关闭后，该定时删除策略失效。

该命令用于配置文件删除策略。

该命令的使用场景为：基于数据隐私安全性考虑，需要对数据进行定期清理，操作员可以使用该命令配置文件删除策略。

## 注意事项

- 系统默认文件删除策略开启，默认最大保留天数为180天。
- 系统删除策略开启后，系统凌晨00:10会定时检测配置路径下的性能统计相关文件、导出文件、日志文件、网元文件，满足最大保留天数限制的文件会被清理掉。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                     |
|:------------|:----------|:-------------------------------------------------------------------------------------------------------------------------|
| STATUS      | 启用状态      | 可选必选说明：必选参数。 参数含义：用于指定系统文件删除策略的启用状态，系统初始状态为启用。 取值范围： “Enable(启用)”：文件删除策略开启。“Disable(未启用)”：文件删除策略未开启。 默认值：无。 配置原则：初始值：启用。 |
| MAXKEEPDAYS | 最大保留天数(天) | 可选必选说明：必选参数。 参数含义：用于指定系统支持文件最大的保留天数，系统初始值为180天。 取值范围：20~720。 默认值：无。 配置原则：无。                                              |

## 使用实例

设置“启用状态”为“Enable(启用)”，“最大保留天数（天）”为200天：

`SET FILEDELPOLICY: STATUS=Enable, MAXKEEPDAYS=200;`
