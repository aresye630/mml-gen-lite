# 查询进程(DSP PROCESS)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

本命令用于请求系统显示进程的状态信息和静态配置信息。

- 若需要查询全部进程的状态信息和静态配置信息，请不要输入任何参数。
- 若需要查询某个Pod上的进程的状态信息和静态配置信息，输入“Pod名称”参数。

## 注意事项

系统在执行本命令时需要消耗节点一定的CPU资源，这种CPU资源消耗与操作员需要查询的进程数成正比，为尽量减少查询大量进程状态时对节点CPU资源的消耗，建议操作员输入具体的“Pod名称”参数进行操作。

## 参数说明

| 参数标识      | 参数名称      | 参数说明                                                                                                                                                                                                                                                                    |
|:----------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VMNAME    | Pod名称     | 可选必选说明：可选参数。 参数含义：用于请求系统显示哪个Pod上的进程的状态信息和静态配置信息；若不输入，则表示所有的Pod。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：操作员可以通过执行LST PODINFO命令查询获得。                                                                                                                                              |
| PMID      | 平台模块号     | 可选必选说明：可选参数。 参数含义：用于请求系统显示哪个平台模块号的进程的状态信息和静态配置信息，每个进程的平台模块号都是唯一的；若不输入，则表示所有的平台模块号。 取值范围：0～4294967294。 默认值：无。 配置原则：无。                                                                                                                                                    |
| USEST     | 可用状态      | 可选必选说明：可选参数。 参数含义：用于请求系统是按照哪种可用状态来显示进程的状态信息和静态配置信息；若不输入，则表示所有的可用状态。 取值范围： “NORMAL(正常)”：用于表示进程可以提供服务。“NOT_READY(未就绪)”：用于表示进程已启动，此时正处于加载状态，不提供业务功能。“FAULT(故障)”：用于表示进程不可以提供服务。 默认值：无。 配置原则：无。                                                                              |
| HAST      | 主备状态      | 可选必选说明：可选参数。 参数含义：用于请求系统是按照哪种主备状态来显示进程的状态信息和静态配置信息；若不输入，则表示所有运行的状态。 取值范围： “UNASSIGNED(未指配)”：查询的进程的状态为未指配。在进程启动的初期，进程处于尚未指配主用或备用的状态。“STANDBY(备用)”：查询的进程的状态为备用。“ACTIVE(主用)”：查询的进程的状态为主用。“INVALID(无效)”：查询的进程的状态为未就绪，状态为无效。“UNCONFIGURED(未配置)”：查询的进程的状态为未配置。 默认值：无。 配置原则：无。 |
| ADMST     | 配置管理状态    | 可选必选说明：可选参数。 参数含义：用于请求系统是按照哪种配置管理状态来显示进程的状态信息和静态配置信息；若不输入，则表示所有的配置管理状态。 取值范围： “LOCK(锁定)”：用于表示该进程不可以提供服务。“UNLOCK(未锁定)”：用于表示该进程可以提供服务。 默认值：无。 配置原则：无。                                                                                                                     |
| OPTST     | 操作状态      | 可选必选说明：可选参数。 参数含义：用于请求系统是按照哪种操作状态来显示进程的状态信息和静态配置信息；若不输入，则表示所有的操作状态。 取值范围： “ENABLE(允许)”：用于表示该进程可以操作。“DISABLE(禁止)”：用于表示该进程不可以操作。 默认值：无。 配置原则：无。                                                                                                                           |
| HADMST    | 管理状态      | 可选必选说明：可选参数。 参数含义：用于请求系统是按照哪种管理状态来显示进程的状态信息和静态配置信息；若不输入，则表示所有的管理状态。 取值范围： “LOCK(锁定)”：用于表示该进程不可以提供服务。“UNLOCK(未锁定)”：用于表示该进程可以提供服务。“SHUTDOWN(正在锁定)”：用于表示该进程正在处于锁定状态，不提供服务。“UNSUPPORTED(不支持)”：用于表示该进程不支持服务。 默认值：无。 配置原则：无。                                                  |
| ALLOCM    | 分配的内存(KB) | 可选必选说明：可选参数。 参数含义：用于请求系统显哪种分配的内存大小的进程的状态信息和静态配置信息；若不输入，则表示所有分配的内存大小。 取值范围：无。 默认值：无。 配置原则：无。                                                                                                                                                                             |
| CPURT     | CPU占用率(%) | 可选必选说明：可选参数。 参数含义：用于请求系统显示哪个CPU占用率的进程的状态信息和静态配置信息；若不输入，则表示所有CPU占用率。 取值范围：无。 默认值：无。 配置原则：无。                                                                                                                                                                              |
| PVER      | 平台版本号     | 可选必选说明：可选参数。 参数含义：用于请求系统显示哪个CSP平台的版本号的进程的状态信息和静态配置信息；若不输入，则表示所有的CSP平台的版本号。 取值范围：无。 默认值：无。 配置原则：无。                                                                                                                                                                       |
| DESC      | 模块类型      | 可选必选说明：可选参数。 参数含义：用于请求系统显示哪种模块类型的进程的状态信息和静态配置信息；若不输入，则表示所有的模块类型。 取值范围：无。 默认值：无。 配置原则：无。                                                                                                                                                                                 |
| PLANEID   | 平面号       | 可选必选说明：可选参数。 参数含义：用于请求系统是按照哪个平面号来显示进程的状态信息和静态配置信息；若不输入，则表示所有的平面号。 取值范围： “PLANE0(平面0)”：用于表示该进程的平面标识ID为平面0。“PLANE1(平面1)”：用于表示该进程的平面标识ID为平面1。“PLANE2(平面2)”：用于表示该进程的平面标识ID为平面2。 默认值：无。 配置原则：无。                                                                              |
| BAKSWITCH | 备份开关      | 可选必选说明：可选参数。 参数含义：用于请求系统是按照哪个备份开关来显示进程的状态信息和静态配置信息；若不输入，则表示所有备份开关。 取值范围： “OFF(备份开关关闭)”：用于表示该进程的备份开关是关闭的。“ON(备份开关打开)”：用于表示该进程的备份开关是打开的。 默认值：无。 配置原则：无。                                                                                                                   |

## 使用实例

   `DSP PROCESS: VMNAME="cgplite-0";`

   ```
   %%DSP PROCESS: VMNAME="cgplite-0";%%
   RETCODE = 0  操作成功

   Pod进程信息

             位置描述  =  10.7.90.60
   ```

## 输出结果说明

| 输出项名称       | 输出项解释                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|:------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Pod名称       | 用于返回进程所在Pod的名称。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 位置描述        | 用于返回进程所属Pod的位置信息。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| 平台模块号       | 用于返回进程的平台模块号信息，每个进程的平台模块号都是唯一的。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 网元ID        | 用于返回进程所属的网元号信息，具体请参考各个业务网元的说明。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| 模块号         | 用于返回该进程的模块号信息。如果业务模块是主备的，则有两个模块对应该模块号。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| 可用状态        | 用于返回该进程的可用状态信息： “正常”：表示进程可以提供服务。“未就绪”：表示进程已启动，此时正处于加载状态，不提供业务功能。“故障”：表示进程不可以提供服务，需要对故障模块进行处理。                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| 主备状态        | 用于返回该进程的主备状态信息： “未指配”：表示该进程的状态为未指配。在进程启动的初期，进程处于尚未指配主用或者备用的状态。“备用”：表示该进程的状态为备用。“主用”：表示该进程的状态为主用。“无效”：表示该进程的状态为未就绪，状态为无效。“未配置”：表示该进程的状态为未配置。                                                                                                                                                                                                                                                                                                                                                                                                     |
| 配置管理状态      | 用于返回该进程的配置管理状态信息： “锁定”：表示该进程不可以提供服务。“未锁定”：表示该进程可以提供服务。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| 操作状态        | 用于返回该进程的操作状态信息： “允许”：表示该进程可以操作。“禁止”：表示该进程不可以操作。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 管理状态        | 用于返回该进程的管理状态信息： “锁定”：表示指定的对象不可以提供服务。“未锁定”：表示指定的对象可以提供服务。“正在锁定”：表示指定的对象正在处于锁定状态，不提供服务。“不支持”：表示指定的对象不支持服务。                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| 分配的内存(KB)   | 用于返回该进程的静态配置的内存大小，单位（KB）。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| 内存占用率(百分比)  | 用于返回进程的当前使用的内存与静态配置的内存的比例。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| CPU占用率(百分比) | 用于返回进程当前的CPU占用率。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| 版本号         | 用于返回CSP平台的版本号。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| 模块类型        | 用于返回进程的模块描述信息。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| 平面号         | 用于返回平面标识ID。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| 备份阶段        | 用于返回进程当前所处备份阶段： “版本检查”：对于主备类型进程：若备进程发生复位或重启，主进程此时显示“版本检查”，备进程状态正常后也显示为“版本检查”。若主进程发生复位或重启，有备进程时，则备进程升主进程，主进程降为备进程，主进程此时显示“版本检查”，备进程状态正常后也显示为“版本检查”。若主进程发生复位或重启，无备进程时，则主进程状态正常后一直显示“版本检查”。 对于负荷分担类型进程，不需要备份数据，进程正常后备份阶段一直显示为“版本检查”。 “初始化备份”：对于主备类型进程，主进程和备进程经“版本检查”后，主进程将需要备份的数据备份到备进程上，主进程的备份阶段此时显示为“初始化备份”。“日常备份”：对于主备类型进程，主进程在“初始化备份”后，若需要备份的数据发生变化时，自动把变化的数据备份到备进程上，主进程的备份阶段此时显示为“日常备份”。“数据备份”：对于主备类型进程，主进程的备份阶段为“初始化备份”或 “日常备份”时，备进程接收主进程的备份数据，备进程的备份阶段此时显示为“数据备份”。“不需要”：对于管理进程（例如PMU），不需要备份数据，备份阶段显示为“不需要”。“无效”：进程复位、重启或一直无法启动，备份阶段显示为“无效”。 |
| 备份进度        | 用于返回进程当前的备份进度： “以百分比显示”：对于主备类型进程，备份进度显示为百分比（已完成备份数据块的数量除以当前进程需要备份数据块的总数量*100）。“不需要”：对于负荷分担类型进程和管理进程（例如PMU），不需要备份数据，备份进度显示为“不需要”。“NULL”：当备份阶段显示为“无效”时，则备份进度显示为“NULL”。                                                                                                                                                                                                                                                                                                                                                                            |
| 备份开关        | 用于返回进程的备份开关： “打开”：表示进程的备份开关打开。“关闭”：表示进程的备份开关关闭。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 运行版本        | 用于返回进程的软件版本。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
