# 查询MML配置脚本(LST MMLCONF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询最新加载的MML配置脚本信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                      |
|:-------|:-------|:------------------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：用于指示系统需要按照哪个网元ID来查询最新加载的MML配置脚本信息；若不输入，则表示所有的网元。 取值范围：无。 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询系统中所有已加载的MML配置脚本文件信息：

   `LST MMLCONF:;`

   ```
   %%LST MMLCONF:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    网元ID  文件名称   

    5       tmp.xml
    6       mml.xml    
   (结果个数 = 2)

   ---    END
   ```
2. 查询指定网元最新加载的MML配置脚本文件信息：

   `LST MMLCONF: MEID=5;`

   ```
   %%LST MMLCONF: MEID=5;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
     网元ID  =  5
   文件名称  =  tmp.xml
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

| 输出项名称   | 输出项解释                |
|:--------|:---------------------|
| 网元ID    | 网元的ID编号              |
| 文件名称    | 用于标识最新加载的MML配置脚本文件名。 |
