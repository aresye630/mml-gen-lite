## 命令功能

**须知** 

该命令执行后可能会影响到目的IP的转发，请谨慎操作。

此命令用于增加指定IP的原端口到目的端口的转发规则，可用于SFTP端口的转换。

## 注意事项

- 该命令仅限角色为Administrators的用户执行。

- 同一目的IP和端口只能配置一条规则，若需修改，请先使用**RMV FWRULE**命令删除该规则后使用本命令重新配置。

## 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                               |
|:--------|:---------|:-----------------------------------------------------------------------------------|
| IPTYPE  | IP版本     | 可选必选说明：必选参数。 参数含义：IP类型。 取值范围： IPV4(IPv4类型)IPV6(IPv6类型) 默认值：IPV4(IPv4类型)。 配置原则：无。   |
| TGTIPV4 | 目的IPV4地址 | 可选必选说明：当“IP版本”为“IPV4(IPv4类型)”时为必选参数。 参数含义：目的IPV4地址。 取值范围：有效的IPv4地址。 默认值：无。 配置原则：无。 |
| TGTIPV6 | 目的IPV6地址 | 可选必选说明：当“IP版本”为“IPV6(IPv6类型)”时为必选参数。 参数含义：目的IPV6地址。 取值范围：有效的IPv6地址。 默认值：无。 配置原则：无。 |
| PORT    | 端口       | 可选必选说明：必选参数。 参数含义：目的IP地址的原端口。 取值范围：1~65535 默认值：无。 配置原则：无。                          |
| TGTPORT | 目的端口     | 可选必选说明：必选参数。 参数含义：目的IP地址的目的端口。 取值范围：1~65535 默认值：无。 配置原则：无。                         |

## 使用实例

假如运营商希望将发往192.168.1.1:22的请求转发到192.168.1.1:25，需要执行如下命令增加转发规则。

```
%%ADD FWRULE: IPTYPE=IPV4, TGTIPV4="192.168.1.1", PORT=22, TGTPORT=25;%%
RETCODE = 0  操作成功

---    END
```
