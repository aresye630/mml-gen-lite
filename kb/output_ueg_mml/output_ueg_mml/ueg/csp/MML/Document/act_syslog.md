# 打开系统日志级别(ACT SYSLOG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

执行该命令可能导致CPU产生较大的波动，如在话务高峰期需谨慎执行。

该命令用于打开节点文本日志的打印级别控制开关。

某些情况下，维护人员需要获取更为详细的系统日志信息，可以使用本命令使得该级别以及高于该级别的日志能够打印到日志文件中。

## 注意事项

该命令在对应模块的所有设置在该模块重启后失效，日志级别恢复为默认级别。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                                                                  |
|:-------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VMNAME | Pod名称    | 可选必选说明：必选参数。 参数含义：用于指定系统需要按照某个Pod来打开系统日志级别。操作员可以通过执行LST MODULE命令查询获得对应进程的Pod名称。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则： 该参数的值域范围为：大写字母“A～Z”、小写字母“a～z”、数字“0～9”、特殊字符 - _。 该参数必须以字母开头。 该参数区分大小写。 |
| MEID   | 网元ID     | 可选必选说明：必选参数。 参数含义：用于指定实施操作的网元。 取值范围：0～1023 默认值：无。 配置原则：无。                                                                                                                             |
| LCPUID | 模块号      | 可选必选说明：必选参数。 参数含义：用于指定打开日志打印级别控制开关对应的模块号。操作员可以通过LST MODULE命令查询模块号。 取值范围：0～4294967294 默认值：无。 配置原则：无。                                                                                   |
| HAST   | 主备状态     | 可选必选说明：可选参数。 参数含义：用于指定打开日志打印级别控制开关的模块状态。若不输入，则表示正常运行的所有状态。 取值范围： “ACTIVE(主用)”：指定打开日志打印级别控制开关的模块状态为主用。“STANDBY(备用)”：指定打开日志打印级别控制开关的模块状态为备用。 默认值：无。 配置原则：无。                             |
| PID    | PID      | 可选必选说明：必选参数。 参数含义：用于请求系统显示某一个PID信息。操作员可以通过DSP PIDINF命令查询PID。 取值范围：0～1023 默认值：无。 配置原则：无。                                                                                               |
| LEVEL  | 级别       | 可选必选说明：必选参数。 参数含义：用于指定日志信息的输出级别。 取值范围： DEB(调试信息)INF(信息级别)NOT(通知级别)WAR(警告级别)ERR(错误级别)CRI(重要级别)ALE(警报级别)EME(紧急级别) 默认值：INF(信息级别)。 配置原则：无。                                                |
| TIME   | 打开时长(分钟) | 可选必选说明：必选参数。 参数含义：用于指定日志信息的输出激活时间，超过这个时间后日志级别恢复到默认级别。如果想要永久激活，则将时间参数值置为空即可。 取值范围：1～600分钟 默认值：5分钟。 配置原则：无。                                                                             |

## 使用实例

打开系统日志打印级别控制开关，“Pod名称”为“Pod1”，“网元ID”为“0”，“模块号”为“1300”，“主备状态”为“ACTIVE(主用)”，“PID”为“184”，“级别”为“NOT(通知级别)”，“打开时长(分钟)”为“30”

`ACT SYSLOG:VMNAME="Pod1", MEID=0, LCPUID=1300, HAST=ACTIVE, PID=184, LEVEL=NOT, TIME=30;`

```
%%ACT SYSLOG: VMNAME="Pod1", MEID=0, LCPUID=1300, HAST=ACTIVE, PID=184, LEVEL=NOT, TIME=30;%%
RETCODE = 0  操作成功

操作结果如下
------------
 Pod名称  =  Pod1    
位置描述  =  NULL
  网元ID  =  0
  模块号  =  1300
主备状态  =  主用
操作结果  =  成功
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释           |
|:--------|:----------------|
| Pod名称   | 用于返回模块所在的Pod名称。 |
| 位置描述    | 用于返回模块的位置描述信息。  |
| 网元ID    | 用于返回模块所属的网元信息。  |
| 模块号     | 用于返回该进程的模块号信息。  |
| 主备状态    | 用于返回模块的主备状态。    |
| 操作结果    | 表示执行操作的结果：成功失败  |
