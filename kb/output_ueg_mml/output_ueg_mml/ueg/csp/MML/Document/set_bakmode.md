## 命令功能

**须知** 

该命令的操作对系统影响极大。关闭备份开关，可能造成主用模块和备用模块之间数据不一致，会影响主备模块倒换的平滑进行，请慎重使用该命令。

本命令用于请求系统对指定网元的模块的备份开关执行打开或者关闭操作。本命令主要用于打开或关闭某个主备模块间的备份开关，控制主用模块是否将动态数据备份到备用模块。本命令的使用场景为：

- 在开局、扩容或者升级的场景中，经常需要通过复位模块使某些设置生效（例如，模块加载了新的节点软件或修改了系统参数等），特别是在主备用工作方式的模块复位操作中，若主用模块复位，备用模块将承担原主模块所有的业务，这就要求主备用模块的数据时刻保持一致，操作员可以执行本命令设置模块的备份开关，使主用模块的数据实时的备份到备用模块。
- 系统在无损升级时，使用备模块进行版本升级。升级过程中需要保持主模块的备份开关为打开状态。操作员可以执行本命令设置模块的备份开关，使主用模块的数据实时的备份到备用模块。
- 当主用模块的备份开关打开时，主用模块数据备份到备用模块；当主用模块的备份开关关闭时，则主模块数据不备份到备用模块。

本命令支持对业务网元下的模块的备份开关进行批量和单独设置。

## 注意事项

- 升级过程中，需要确保模块的备份开关为打开状态。如果主用模块备份开关关闭，则正在进行版本升级的备模块无法收到备份数据。当备模块升级完成后，主备模块进行倒换，原备用模块升为主用，由于升级时原主模块数据未备份到原备模块，则导致升级后的主模块（原备模块）丢失业务数据。
- 当对模块进行补丁操作时，若补丁中模块数据备份结构发生变化，需要将主模块的备份开关关闭，然后执行相关的补丁操作。
- 此命令只对配置有主备模块，且模块状态为主用的模块进行操作。
- 负荷分担的模块，只配置主模块，不支持设置备份开关。
- 如果指定的模块未启动，则不支持设置备份开关。
- 主模块复位后，备份开关会自动打开。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                                                                     |
|:----------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VMNAME    | Pod名称  | 可选必选说明：可选参数。 参数含义：用于在模块备份中定义一个Pod，用于指示系统设置哪个Pod上的模块的备份开关。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：操作员可以通过执行LST MODULE命令查询获得。若不输入，则表示所有的Pod名称。                                                                                                                                     |
| MEID      | 网元ID   | 可选必选说明：必选参数。 参数含义：用于在模块备份中定义一个网元ID索引，用于指示系统设置哪个网元的模块的备份开关。 取值范围：0～1023。 默认值：无。 配置原则：操作员可以使用LST MODULE命令查询获得。                                                                                                                                                             |
| MN        | 模块号    | 可选必选说明：可选参数。 参数含义：用于在模块备份中定义一个模块号索引，用于指示系统设置哪个模块的备份开关；若不输入，则表示所有的模块号。 取值范围：0～4294967294 默认值：无。 配置原则：操作员可以使用LST MODULE命令查询获得。                                                                                                                                             |
| BAKSWITCH | 备份开关   | 可选必选说明：必选参数。 参数含义：用于在模块备份中定义一个备份开关，用于指示系统是否在主备模块之间进行数据备份。 取值范围： “OFF(备份开关关闭)”：设置模块的备份开关为关闭，主要应用在对模块进行补丁操作过程中，当补丁对模块数据备份结构发生变化时，需要将主模块的备份开关关闭，然后执行相关的补丁操作。“ON(备份开关打开)”：当模块在未设置备份开关前，备份开关一直为打开。当备用模块和主用模块之间数据需要保持一致时，需要将模块的备份开关设置为打开。 默认值：无。 配置原则：无。 系统初始设置值：“ON(备份开关打开)”。 |

## 使用实例

1. 批量设置“网元ID”为“5”，“备份开关”为“ON(备份开关打开)”的所有Pod上模块的备份模式：

   `SET BAKMODE: MEID=5, BAKSWITCH=ON;`

   ```
   %%SET BAKMODE: MEID=5, BAKSWITCH=ON;%%
   RETCODE = 0  操作成功

   Pod设置结果
   --------------
    网元ID  模块号  Pod名称                位置描述     结果  

    5       50      cgplite-0              10.7.90.60   不支持
    5       60      cgplite-0              10.7.90.60   不支持
    5       1080    testforamu-0           10.7.90.60   成功  
    5       1080    testforamu-1           10.7.90.60   不支持
    5       1081    testforamu-0           10.7.90.60   不支持
    5       1081    testforamu-1           10.7.90.60   成功  
   (结果个数 = 6)

   ---    END
   ```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                              |
|:--------|:-----------------------------------------------------------------------------------------------------------------------------------|
| 网元ID    | 用于返回进程所属的网元ID。                                                                                                                     |
| 模块号     | 用于返回该进程的模块号信息。如果业务模块是主备的，则有两个模块对应该模块号                                                                                              |
| Pod名称   | 用于标识服务实例对应Pod的名称                                                                                                                   |
| 位置描述    | 用于返回模块所在Pod的位置信息。                                                                                                                  |
| 结果      | 用于返回对模块进行备份开关设置的操作结果： “成功”：存在备用模块的主用模块运行正常时，返回该结果。“失败”：当模块处于故障状态时返回该结果。“不支持”：当设置的模块满足以下任意条件返回该结果：负荷分担的模块模块未配置备用模块主备模块中当前模块状态为备用的模块 |
