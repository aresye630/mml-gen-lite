# 查询数据库表空间信息（LST DBTBS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查看OMU数据库的表空间信息。

- 如果用于查看OMU数据库所有的表空间信息，请不要输入任何参数。
- 如果用于查看OMU数据库某个表空间的信息，请输入“表空间名称”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                          |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TBSN   | 表空间名称  | 可选必选说明：必选参数。 参数含义：用于指示系统按表空间名称来查询表空间的信息。 取值范围：长度不超过30个英文字符。 如果查询不到指定的表空间的信息，可以采取如下方案： 缩短查询时输入的字符串。不输入任何字符串查找所有的表空间的信息。 默认值：无。 配置原则：由数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“_”、空格符（这里空字符将被理解为一个字符）组成的字符串。 需要指出的是： 该参数不区分大小写。 该参数支持子串查询功能。 比如输入参数为“cgp”即可查询到所有包含“cgp”的表空间信息，如“cgp_1”、“cgp_2”、“gcgp”等。 |

## 使用实例

1. 查询系统中OMU数据库的所有表空间信息。

   `LST DBTBS:;`

   ```
   %%LST DBTBS:;%%
   RETCODE = 0  操作成功

   数据库表空间信息查询结果如下
   ----------------------------
    表空间名称  当前大小(MB)  最大大小(MB)  表空间路径                                             

    cgp_1       16            2048      /opt/HUAWEI/cgp/workshop/omu/data/tablespaces/cgp_1    
    common      0             100       /opt/HUAWEI/cgp/workshop/omu/data/tablespaces/common   
    pds         2             1024      /opt/HUAWEI/cgp/workshop/omu/data/tablespaces/pds      
    pds_ne0_1   0             128       /opt/HUAWEI/cgp/workshop/omu/data/tablespaces/PDS_NE0_1
    rsm         0             1024      /opt/HUAWEI/cgp/workshop/omu/data/tablespaces/RSM      
    rsm_temp    0             1024      /opt/HUAWEI/cgp/workshop/omu/data/tablespaces/RSM_TEMP 
   (结果个数 = 6)

   ---    END
   ```
2. 查询OMU数据库中的指定表空间信息。

   `LST DBTBS: TBSN="cgp_1";`

   ```
   %%LST DBTBS: TBSN="cgp_1";%%
   RETCODE = 0  操作成功

   数据库表空间信息查询结果如下
   ----------------------------
     表空间名称  =  cgp_1
   当前大小(MB)  =  16
   最大大小(MB)  =  2048
     表空间路径  =  /opt/HUAWEI/cgp/workshop/omu/data/tablespaces/cgp_1
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

| 输出项名称    | 输出项解释           |
|:---------|:----------------|
| 表空间名称    | 用于标识表空间的名称。     |
| 当前大小(MB) | 用于标识当前表空间的内存大小。 |
| 最大大小(MB) | 用于标识表空间的最大内存大小。 |
| 表空间路径    | 用于标识表空间的存储路径。   |
