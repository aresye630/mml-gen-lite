# 查询运行日志记录级别 (LST LOGLEVEL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询模块运行日志记录级别。

- 若需要查询全部模块的运行日志记录级别，请不要输入任何参数。
- 若需要查询某个模块的运行日志记录级别，请输入“OMU模块名称”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                         |
|:-------|:--------|:---------------------------------------------------------------------------------------------|
| OMUMN1 | OMU模块名称 | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个OMU模块名称来查询模块运行日志记录级别；若不输入，则表示所有OMU模块名称。 取值范围：无。 默认值：无。 配置原则：无。 |

## 使用实例

查询“CM”模块运行日志记录级别，设置“OMU模块名称”为“CM”：

`LST LOGLEVEL: OMUMN1="CM";`

```
%%LST LOGLEVEL: OMUMN1="CM";%%
RETCODE = 0  操作成功

OMU模块日志级别信息
-------------------
 日志级别  状态  

 INFO      关闭  
 WARNING   关闭  
 ERROR     开启  
 CRITICAL  开启  
 DEBUG     关闭  
 NOTICE    开启  
 STARTUP   开启  
 SHUTDOWN  开启  
 TRACE     关闭  
(结果个数 = 9)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                                                                                                                                          |
|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 日志级别    | 日志的输出级别。“INFO”：表示将信息日志打印到日志文件中。“WARNING”：表示将告警日志打印到日志文件中。“ERROR”：表示将错误日志打印到日志文件中。“CRITICAL”：表示将严重日志打印到日志文件中。“DEBUG”：表示将调试日志打印到日志文件中。“NOTICE”：表示将事件日志打印到日志文件中。“STARTUP”：表示将模块启动日志打印到日志文件中。“SHUTDOWN”：表示将模块停止日志打印到日志文件中。“TRACE”：表示将跟踪日志打印到日志文件中。 |
| 状态      | 日志级别的开关状态。“开启”：表示记录对应级别的日志。“关闭”：表示不记录对应级别的日志。                                                                                                                                                                                                  |
