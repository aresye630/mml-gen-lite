# 设置跨网元命令开关(SET CMSWITCH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于设置跨网元命令开关。

在升级观察期内，执行跨网元命令可能会影响升级回退，因此系统对这些命令做了限制，默认状态下不允许执行。如果需要在升级观察期内执行跨网元命令，请通过本命令打开跨网元命令开关。

## 注意事项

- 执行完跨网元命令后，请及时关闭该开关。
- 打开跨网元命令开关后执行的跨网元命令在升级回退前必须已完全回退，否则可能影响系统配置。
- 所有网元共用一个跨网元命令开关。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                               |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------|
| STS    | 开关状态   | 可选必选说明：必选参数。 参数含义：用于指定跨网元命令开关的状态。 取值范围： “OFF(关)”：表示跨网元命令开关关闭，升级观察期内不允许执行跨网元命令。 “ON(开)”：表示跨网元命令开关打开，升级观察期内允许执行跨网元命令。 默认值：无。 配置原则：无。 |

## 使用实例

设置跨网元命令开关：设置“开关状态”为“OFF(关)”。

`SET CMSWITCH: STS=OFF;`
