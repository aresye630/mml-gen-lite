## 命令功能

本命令用于Pod通信质量问题的跨层定界诊断和质量数据的统计呈现。

本命令的使用场景为：

- 系统上报“ALM-1010 管理平面丢包错包”、“ALM-1011 控制平面丢包错包”、“ALM-1012 控制平面通讯故障”、“ALM-1013 控制平面单平面通讯故障”、“ALM-9607 媒体平面通信故障”、“ALM-9608 媒体平面单平面通讯故障”、“ALM-9609 媒体平面丢包错包”、“ALM-6430 通信平面异常”、“ALM-8503 OMU双机连接故障”等通讯亚健康类告警时，执行此命令可诊断和查询DC内通信质量。
- 系统上报大量“ALM-1003 模块故障”告警时，执行此命令可诊断和查询DC内环境通信是否存在中断。
- 该命令支持两种诊断方式：一种为传统诊断方式，查询类型对应“DIAGNOSIS\_INFO(诊断信息)”和“COMMQLTY\_DATA(通信质量数据)”，另一种为模糊诊断方式，查询类型对应“FUZZY\_DIAGNOSIS\_INFO(模糊诊断信息)”和“FUZZY\_DIAGNOSIS\_DATA(模糊诊断数据)”。建议优选使用诊断能力更广的模糊诊断方式进行跨层定界诊断；传统诊断方式不支持内部通信完全中断下的诊断，但亚健康场景诊断精度可细化到Pod网口vNIC级别。

## 注意事项

- 针对传统诊断方式，当环境上存在通信异常，Pod被修复复位或迁移，只有30分钟后才可执行此命令，用于查询环境通信质量和确认问题是否已被修复。
- 系统出现PMU进程重启时，3分钟内执行此命令可能会导致所收集通讯质量数据不准确，影响模糊诊断结果的准确性。
- 本命令中对通信状态的统计采用的是30分钟平滑处理后的通信数据，稳定周期较长，需要等待30分钟之后再次确认是否恢复。
- 对于第三方云场景，因集成方案差异，导致Pod位置信息无法获取；该场景下不支持诊断，同时Pod的“位置描述”字段显示为“NULL”。
- 若系统处于升级观察期间，Pod的位置无法刷新，可能会造成Pod的“位置描述”字段显示不准确。
- 若系统处于恢复期，每隔一个周期（1分钟）执行该命令，可以通过两种方式来确认当前环境通信质量是否在逐渐趋于健康：
  - 一种为传统诊断方式，查询类型选择“COMMQLTY\_DATA(通信质量数据)”，若查询结果中的丢包率和错包率在逐渐减小，说明通信质量在逐渐变好。
  - 一种为模糊诊断方式，查询类型选择“FUZZY\_DIAGNOSIS\_INFO(模糊诊断信息)”，若查询结果中的异常路径数和异常路径比在逐渐减小，说明通信质量在逐渐变好。
- 若Pod的Fabric3、Fabric4端口支持信令转发功能，执行此命令不会显示与此Pod相关的媒体面通信质量数据。

## 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                     |
|:-----------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| QUERYTYPE  | 查询类型    | 可选必选说明：必选参数。 参数含义：用于请求系统显示哪种查询类型的通信质量。 取值范围： “DIAGNOSIS_INFO(诊断信息)”：查询当前环境的详细诊断信息，用于精准定位网口通信质量问题。“COMMQLTY_DATA(通信质量数据)”：查询当前环境源Pod到目的Pod的详细丢包错包数据。“FUZZY_DIAGNOSIS_INFO(模糊诊断信息)”：查询当前环境通信质量的模糊诊断信息，用于跨层定界诊断。查询结果按照最可能的故障点排序，最多显示32条。“FUZZY_DIAGNOSIS_DATA(模糊诊断数据)”：查询详细的模糊诊断数据，用于查看服务器或Pod的通信质量状态。查询结果中存在通信质量的服务器按照位置描述排序，Pod按照最大故障可能性排序。 默认值：“DIAGNOSIS_INFO”。 配置原则：无。 |
| SRCVMNAME  | 源Pod名称  | 可选必选说明：可选参数。 参数含义：仅当本命令中的“查询类型”参数选择为“COMMQLTY_DATA(通信质量数据)”时该参数有效。 用于请求系统显示哪个源Pod上的通信质量；若不输入，则表示源Pod为所有的Pod。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：操作员可以使用LST PODINFO命令查询获得。                                                                                                                                                                                                    |
| DESTVMNAME | 目的Pod名称 | 可选必选说明：可选参数。 参数含义：仅当本命令中的“查询类型”参数选择为“COMMQLTY_DATA(通信质量数据)”时该参数有效。 用于请求系统显示哪个目的Pod上的通信质量；若不输入，则表示目的Pod为所有的Pod。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：操作员可以使用LST PODINFO命令查询获得。                                                                                                                                                                                                  |

## 使用实例

1. 查询环境的通信质量数据：

   `DSP COMMQLTY: QUERYTYPE=COMMQLTY_DATA;`

   ```
   %%DSP COMMQLTY: QUERYTYPE=COMMQLTY_DATA;%%
   RETCODE = 0  操作成功

   存在问题的通信质量数据如下
   --------------------------
    源Pod名称            源位置描述   源端口名称  目的Pod名称          目的位置描述  目的端口名称  丢包率(千分比)  错包率(千分比)  数据是否可信

    cgplite-1            10.7.50.10   Fabric1     cgplite-0            10.7.50.10    Fabric1       4               52              是          
    cgplite-1            10.7.50.10   Fabric1     testforamu-0         10.7.50.10    Fabric1       4               44              是          
    cgplite-1            10.7.50.10   Fabric1     testforamu-1         10.7.50.10    Fabric1       3               58              是          
   (结果个数 = 3)

   共有3个报告
   ---    END
   ```
2. 查询“目的Pod名称”为“testforamu-0”的通信质量数据：

   `DSP COMMQLTY: QUERYTYPE=COMMQLTY_DATA, DESTVMNAME="testforamu-0";`

   ```
   %%DSP COMMQLTY: QUERYTYPE=COMMQLTY_DATA, DESTVMNAME="testforamu-0";%%
   RETCODE = 0  操作成功

   存在问题的通信质量数据如下
   --------------------------
     源Pod名称  =  cgplite-1
       源位置描述  =  10.7.50.10

   (结果个数 = 1)

   ```
3. 查询环境的通信质量的诊断信息：

   `DSP COMMQLTY： QUERYTYPE=DIAGNOSIS_INFO;`

   ```

   RETCODE = 0  操作成功

   存在通信质量问题的Pod如下

   (结果个数 = 1)

   共有3个报告
   ---    END
   ```
4. 查询环境的通信质量的模糊诊断信息：

   `DSP COMMQLTY： QUERYTYPE=FUZZY_DIAGNOSIS_INFO;`


## 输出结果说明

查询通信质量详细数据时，命令执行正常，会返回命令执行成功的信息，输出项说明如表1所示。

| 输出项名称    | 输出项解释                        |
|:---------|:-----------------------------|
| 源Pod名称   | 用于表示Pod间存在通信质量问题的本端Pod。      |
| 源位置描述    | 用于表示Pod间存在通信质量问题的本端Pod的位置信息。 |
| 源端口名称    | 用于表示存在通信质量问题的源端口的名称。         |
| 目的Pod名称  | 用于表示Pod间存在通信质量问题的对端Pod。      |
| 目的位置描述   | 用于表示Pod间存在通信质量问题的对端Pod的位置信息。 |
| 目的端口名称   | 用于表示存在通信质量问题的目的端口的名称。        |
| 丢包率(千分比) | 用于返回指定源Pod和其他目的Pod间的丢包情况。    |
| 错包率(千分比) | 用于返回指定源Pod和其他目的Pod间的错包情况。    |
| 数据是否可信   | 用于表示对应的通信质量数据是否可信： “是”“否”    |

| 端口名称    | 用于表示Pod存在通信质量问题的通信端口。  |
