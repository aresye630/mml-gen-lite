# 校验包(CHK PKG)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

本命令用于检查OMU上软件包文件的完整性与正确性。

本命令的使用场景为：维护阶段，加载软件包后，其他Pod从OMU安装软件包前，需要确保软件包的完整性和正确性时，使用本命令校验。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                             |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------|
| VMNAME | Pod名称  | 可选必选说明：可选参数。 参数含义：用于指定Pod名字。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                                                   |
| SOFTNM | 软件名称   | 可选必选说明：可选参数。 参数含义：用于指示系统校验的包的软件名称。 取值范围：无 默认值：无。 配置原则：通过LST PKG命令查询，从查询结果中软件包部分子报文，“软件名称”字段获取。若不输入，则表示校验所有的软件包。  |
| SOFTV  | 软件版本   | 可选必选说明：可选参数。 参数含义：校验的包的软件版本。如：10.2。 取值范围：无 默认值：无。 配置原则：通过LST PKG命令查询，从查询结果中软件包部分子报文，“软件版本”字段获取。若不输入，则表示校验所有的软件包。 |

## 使用实例

**实例1**

检查软件包一致性，“校验结果”字段为“异常”的软件包需要重新加载。

\\检查软件包一致性。

`CHK PKG: VMNAME="pod_omu0";`

```
%%CHK PKG: VMNAME="pod_omu0";%%
RETCODE = 0  操作成功

校验包结果报告
--------------
  软件名  =  SLES11.3LTSIMG64Q
软件版本  =  1.0
校验结果  =  异常
(结果个数 = 1)

共有3个报告
---    END
```

\\重新加载软件包。

`LOD PKG:FNM="SLES11.3LTSIMG64Q1.0.tar";`

**实例2**

检查“Pod名”为“pod\_omu0”的软件包：

`CHK PKG: VMNAME="pod_omu0";`

```
%%CHK PKG: VMNAME="pod_omu0";%%
RETCODE = 0  操作成功

校验包结果报告
--------------
校验结果  =  所有被检查的包都正常
(结果个数 = 1)

共有8个报告
---    END
```

## 输出结果说明

命令执行过程中，会返回命令执行的结果。如表1所示。

| 返回结果   | 输出项解释                                                                                                                             |
|:-------|:----------------------------------------------------------------------------------------------------------------------------------|
| 软件名    | 软件名称。如：“SLES11.3IMG64Q”。                                                                                                          |
| 软件版本   | 软件版本。如：1.3。                                                                                                                       |
| 校验结果   | 指示软件包是否可用来加载。 取值范围：“正常”：表示软件包可用。“异常”：表示软件包不可用。当软件包被人为或其他未知原因破坏时，校验结果为异常，此时软件包不可用，依赖此软件包的Pod无法安装。可以先执行RMV PKG删除，再重新执行LOD PKG加载软件包。 |

命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释          | 原因分析                                                                                                    | 处理建议                                                |
|-------:|:---------------|:--------------------------------------------------------------------------------------------------------|:----------------------------------------------------|
| 751039 | 没有符合条件的软件包。    | 指定的“软件名称”或“软件版本”在OMU的存放目录“/opt/pub/software/tmp”下没找到。指定的Pod上需要的软件包在OMU的存放目录“/opt/pub/software/tmp”下没找到。 | 使用LST PKG查询已经上传的软件包。确认需要使用的软件包都上传完毕。运行CHK PKG检查软件包。 |
| 750259 | Pod不存在或不支持此操作。 | 该Pod是第三方Pod。                                                                                            | 该命令不支持第三方Pod操作，请勿使用该命令处理第三方Pod。                     |
