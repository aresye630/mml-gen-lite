# 查询通信链路状态(DSP COMM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于请求系统显示源模块和对端模块，或源模块和OMU之间的通信链路状态。主要在日常通信链路维护中使用。

## 注意事项

执行本命令时需确保查询链路的源模块正常运行。操作员可以通过**DSP MODULE**查询到系统模块的“主备状态”是否为“主用”或“备用”。

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                               |
|:--------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SVMNAME | 源Pod名称  | 可选必选说明：必选参数。 参数含义：用于请求系统显示某个源端Pod上的源模块和对端模块，或和OMU之间的通信链路状态。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：操作员可以通过执行DSP MODULE命令查询通信链路源模块所在Pod名称。                                                                                                                                                                  |
| SNEID   | 源网元ID   | 可选必选说明：必选参数。 参数含义：用于请求系统显示某个源网元ID的源模块和对端模块，或和OMU之间的通信链路状态。 取值范围：无。 默认值：无。 配置原则：操作员可以通过执行DSP MODULE命令查询通信链路源模块的网元ID。                                                                                                                                                                                |
| SMID    | 源模块号    | 可选必选说明：必选参数。 参数含义：用于请求系统显示某个源模块号对应的源模块和对端模块，或和OMU之间的通信链路状态。 取值范围：无。 默认值：无。 配置原则：操作员可以通过执行DSP MODULE命令查询通信链路源模块的模块号。                                                                                                                                                                                |
| LKTYP   | 链路类型    | 可选必选说明：必选参数。 参数含义：用于请求系统是按照某个链路类型来显示源模块的通讯链路状态信息。 取值范围：“Q922(Q922)”：该链路用于需要高可靠通信的模块之间。存在于各个“主用”模块，“主用”模块和“备用”模块之间。“VP(VP)”：该链路用于发送维护平面上的业务消息。存在于不同类型的平台模块之间，以及Pod内部的平台模块和业务模块之间。“TCP(TCP)”：该链路直接应用TCP/IP协议中的TCP协议。在PMU模块和OMU通讯时用到。“UDP(UDP)”：该链路直接应用TCP/IP协议中的UDP协议，主要用于PMU模块之间的通信。 默认值：无。 配置原则：无。 |
| DVMNAME | 对端Pod名称 | 可选必选说明：必选参数。 参数含义：仅当“链路类型”参数选择为“Q922(Q922)”或“VP(VP)”时该参数有效。用于指定通信链路对端模块所在的Pod。用于请求系统显示源模块与指定Pod的对端模块间的通讯链路状态。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：操作员可以通过执行DSP MODULE命令查询通信链路对端模块的Pod名称，若不输入，则表示所有的Pod。                                                                                                 |
| DNEID   | 对端网元ID  | 可选必选说明：必选参数。 参数含义：仅当本命令中的“链路类型”参数选择为“Q922(Q922)”或“VP(VP)”时该参数有效。用于指定通信链路对端模块所处网元ID。用于请求系统显示源模块与指定网元ID的对端模块间的通讯链路状态。 取值范围：无。 默认值：无。 配置原则：操作员可以通过执行DSP MODULE命令查询通信链路对端模块的网元ID，若不输入，则表示所有的网元ID。                                                                                                      |
| DMID    | 对端模块号   | 可选必选说明：必选参数。 参数含义：仅当本命令中的“链路类型”参数选择为“Q922(Q922)”或“VP(VP)”时该参数有效。用于指定通信链路对端模块号。用于请求系统显示源模块与指定的对端模块号间的通讯链路状态。 取值范围：无。 默认值：无。 配置原则：操作员可以通过执行DSP MODULE命令查询通信链路的模块号，若不输入，则表示所有的模块号。                                                                                                                    |

## 使用实例

1. 查询“源Pod名称”为“cgplite-0”，“源网元ID”为“0”，“源模块号”为“3016”的模块的“链路类型”为“TCP”的所有对端模块间的链路状态：

   `DSP COMM: SVMNAME="cgplite-0",SNEID=0, SMID=3016, LKTYP=TCP;`

   ```
   %%DSP COMM: SVMNAME="cgplite-0", SNEID=0, SMID=3016, LKTYP=TCP;%%
   RETCODE = 0  操作成功

   TCP和UDP链路信息
   ----------------
                    链路类型  =  TCP
                    链路状态  =  正常
                    通道类型  =  Driver_tcp
                  通道一状态  =  正常
     源端IP地址(或MAC地址)一  =  172.16.191.0
   源端IP端口(或MAC帧类型)一  =  60980
     对端IP地址(或MAC地址)一  =  172.16.128.1
   对端IP端口(或MAC帧类型)一  =  1500
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

| 输出项名称            | 输出项解释                                                                                                                                                             |
|:-----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 对端位置描述           | 用于返回指定“链路类型”为“Q922(Q922)”或“VP(VP)”时对端模块所在Pod的位置信息。                                                                                                                |
| 对端模块类型           | 用于返回指定“链路类型”为“Q922(Q922)”或“VP(VP)”时对端的模块类型。                                                                                                                       |
| 链路类型             | 用于返回通讯链路的类型。 取值范围：“Q922”：该链路用于需要高可靠通信的模块之间。“VP”：该链路用于发送维护平面上的业务消息。“TCP”：该链路直接应用TCP/IP协议中的TCP协议。“UDP”：该链路直接应用TCP/IP协议中的UDP协议。                                      |
| 链路状态             | 用于返回指定源模块和其他对端模块建立的通信链路的链路状态： “正常”：表示指定的源模块与对端模块间的链路通讯正常。“故障”：表示指定的源模块与对端模块间的链路通讯故障，出现该状态会影响系统业务，请及时排除故障，具体请根据“ALM-2069 模块间通讯故障”进行处理。                             |
| 通道类型             | 用于返回指定源模块和其他对端模块建立的通信链路的通道类型： “Driver_udp” ：表示源模块和对端模块间通信基于UDP协议。“Mac”：表示源模块和对端模块间通信直接基于MAC地址。“Driver_tcp”：表示源模块和对端模块间通信基于TCP协议。“环回”：表示源模块和对端模块间通信直接基于环回网口的MAC地址。 |
| 通道一状态            | 用于返回两个模块间当前使用的第一个通信通道的连接状态： “正常”: 表示源模块和对端模块的通道连接通信正常。“故障”：表示源模块和对端模块的通道连接通信异常。“未配置”：表示源模块和对端模块的通道连接还没有配置。                                                        |
| 源端IP地址(或MAC地址)一  | 用于返回两个模块间当前使用的第一个通信通道的源地址，当“通道类型”为“Mac”或“环回”时，该参数显示为MAC地址，其他情况下该参数显示为IP地址。                                                                                        |
| 源端IP端口(或MAC帧类型)一 | 用于返回两个模块间当前使用的第一个通信通道的源地址类型，当源端地址为IP时，该参数显示为IP端口；当源端地址为MAC时，该参数显示为MAC帧类型。                                                                                         |
| 对端IP地址(或MAC地址)一  | 用于返回两个模块间当前使用的第一个通信通道的目的地址，当“通道类型”为“Mac”或“环回”时，该参数显示为MAC地址，其他情况下该参数显示为IP地址。                                                                                       |
| 对端IP端口(或MAC帧类型)一 | 用于返回两个模块间当前使用的第一个通信通道的目的地址类型，当对端地址为IP时，该参数显示为IP端口；当源端地址为MAC时，该参数显示为MAC帧类型。                                                                                        |
