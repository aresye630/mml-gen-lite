# 版本信息的配套检查(CHK VER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于检查网元版本与该网元下属模块的版本是否配套（用户可以使用**DSP VER**命令查询该网元下属模块版本信息）。不指定任何参数时校验所有网元与其下属模块的版本是否配套，否则检查指定网元与其下属模块的版本是否配套。

该命令用于维护场景，一般在安装补丁或者升级前进行健康检查时使用。

合法的版本配套关系默认是在**LOD PKG**时自动导入的。如果业务网元与该网元下属模块在系统中存在合法的版本配套关系，则在结果中显示“版本一致”，否则在对应的行显示“版本不一致”。

## 注意事项

- 本命令只检查业务网元与其下属模块的版本是否配套，业务网元与CSP版本的配套关系通过增加网元时输入参数的检查保证。
- 只有在模块正常的时候才能有校验结果，否则结果中会显示“无响应”。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                     |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：可选参数。 参数含义：用于请求系统需要对哪一个网元实例实施操作。 取值范围：0～1023。 默认值：无。 配置原则：需要指出的是，如果不指定具体网元ID，则默认会列出所有现存网元的版本配套信息。 |

## 使用实例

部署Pod的场景下，检查业务模块版本同网元的版本是否配套：“网元ID”为“5”:

`CHK VER: MEID=5;`

```
%%CHK VER: MEID=5;%%
RETCODE = 0  操作成功

Pod操作结果如下
------------------
 网元ID  模块号  模块描述  Pod名称  位置描述     主备标记  模块版本     版本校验结果

 5       1000    CCU       VM1         10.16.20.18  主        V200R006C01  版本一致    
 5       1001    CCU       VM2         10.16.20.18  主        V200R006C01  版本一致    
(结果个数 = 2)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                              |
|:--------|:-----------------------------------------------------------------------------------|
| 网元ID    | 用于唯一标识一个子网下的网元实例。                                                                  |
| 模块号     | 用于唯一标识一个网元实例下的模块。                                                                  |
| 模块描述    | 用于标识模块的描述信息。                                                                       |
| Pod名称   | 用于标识模块属于哪个Pod。                                                                     |
| 位置描述    | 用于标识模块的位置描述信息。                                                                     |
| 主备标记    | 该参数用于标识模块的主备标识。 取值说明： “主”：当前模块状态为主用。“备”：当前模块状态为备用。“NULL”：当前模块未返回状态信息，需要检查模块状态是否正常。 |
| 模块版本    | 用于指示模块版本查询结果中模块的版本。其值域类型为长度上限为40的英文字符。                                             |
| 版本校验结果  | 用于描述模块版本是否与网元版本相符合。 取值说明： “版本一致”“版本不一致”“无响应”：当前模块未返回版本信息，无校验结果，需要检测模块状态是否正常。       |
