# 查询节点BYPASS模式（DSP BYPASSMODE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明
- 参考信息

## 命令功能

**须知** 

该功能仅支持华为虚拟化层软件FusionSphere，不支持第三方虚拟化层软件。

存储BYPASS指VNF运行和存储解耦，当存储故障后，支持存储BYPASS的VNF在内存中继续正常运行，减少故障对业务的影响，该命令用于查询节点的BYPASS的运行状态。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                          |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：可选参数 参数含义：用于指示系统需要查询指定网元ID下的节点数据。当参数为空时查询所有网元下的节点数据。“网元ID”可以通过执行LST ME查询。 取值范围：0～65535。 默认值：无。 配置原则：无。 |

## 使用实例

1. “网元ID”为空时，查询所有节点的信息

   ```
   %%DSP BYPASSMODE:;%%
   RETCODE = 0  操作成功
   操作结果如下
   ------------
   网元ID  节点IP           节点BYPASS的运行状态  
   0       10.0.0.3          MemoryDiskMode                    
   0       10.0.0.2          MemoryDiskMode                    
   0       10.0.0.1          MemoryDiskMode
   110     10.0.0.4          MemoryDiskMode
   110     10.0.0.5          MemoryDiskMode
   (结果个数 = 5)
   ---    END
   ```
2. 查询“网元ID”为“0”的所有节点的信息

   ```
   %%DSP BYPASSMODE: MEID=0;%%
   RETCODE = 0  操作成功
   操作结果如下
   ------------
   网元ID  节点IP           节点BYPASS的运行状态  
   0       10.0.0.3          MemoryDiskMode                    
   0       10.0.0.2          MemoryDiskMode                    
   0       10.0.0.1          MemoryDiskMode                    
   (结果个数 = 3)
   ---    END
   ```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。输出结果说明如表1所示。

命令执行异常，请联系华为技术支持处理。输出结果说明如表2所示。

| 输出项名称         | 输出项解释                                                                    |
|:--------------|:-------------------------------------------------------------------------|
| 网元ID          | 节点所属的网元ID。                                                               |
| 节点IP          | 节点网络地址。                                                                  |
| 节点BYPASS的运行状态 | 表示该节点当前运行的bypass模式： MemoryDiskMode：内存bypass模式。None：非bypass模式。未知：节点运行模式未知 |

|    错误码 | 错误码解释     | 原因分析         | 处理建议         |
|-------:|:----------|:-------------|:-------------|
| 130004 | 部分成功      | 部分节点查询失败     | 请联系华为技术支持。   |
| 130013 | 操作失败      | 内部执行报错。      | 请联系华为技术支持。   |
| 130014 | 未知操作      | 不识别对应MML命令。  | 检查MML名称是否正确。 |
| 130015 | 没有符合条件的节点 | 没有网元ID对应的节点。 | 请检查网元是否正确。   |
| 130016 | 参数不合法     | 参数校验失败。      | 请检查参数是否标准。   |
