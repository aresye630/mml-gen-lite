# 查询超时数据(LST USD)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询OMU数据库中没有同步设定到主机的数据，这些数据可能是以下两种情况之一：

- 联机设定数据时，设定不成功的数据。
- 脱机设定数据时，尚未设定的数据。

查询时：

- 若要查询所有设定不成功或尚未设定的数据，请不要输入模块号。
- 若要查询某个模块中设定不成功或尚未设定的数据，请输入相应的模块号。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                             |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------|
| MN     | 模块号    | 可选必选说明：必选参数。 参数含义：用于指示系统需要按照哪个模块号来查询设定不成功或尚未设定的数据；若不输入，则表示查询所有模块设定不成功或尚未设定的数据。 取值范围：0～4294967294。 默认值：无。 配置原则：无。 |

## 使用实例

查询超时数据：

`LST USD:;`

```
%%LST USD:;%%
RETCODE = 0  操作成功

发送未成功数据列表
------------------
 模块号  表号    表名称             记录号  发送次数

 250     6       TBL_PLABOARD       8       3       
 250     6       TBL_PLABOARD       9       3       
 250     7       TBL_PLANETPORT     95      3       
 250     7       TBL_PLANETPORT     96      3       
(结果个数 = 4)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                       |
|:--------|:----------------------------|
| 模块号     | 设定不成功或尚未设定数据所属的模块标识。        |
| 表号      | 设定不成功或尚未设定数据所属的表ID。         |
| 表名称     | 设定不成功或尚未设定数据所属的表名称。         |
| 记录号     | 设定不成功或尚未设定数据对应所在表中的记录号。     |
| 发送次数    | 用于表示系统定时自动下发的超时未设定数据的已设定次数。 |
