# 查询网元重调度策略（LST VNFEVICTION）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

用于查询网元的重调度策略。

**说明** 

该命令仅在Full-stack虚机场景下支持。

#### 注意事项

无。

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                             |
|:-------|:-------|:-----------------------------------------------------------------|
| VNFID  | 网元ID   | 可选必选说明：必选参数。 参数含义：网元ID，可以通过LST ME获取。 取值范围：0～65535 默认值：无。 配置原则：无。 |

#### 使用实例

查询网元ID为0的网元重调度策略。

```
%%LST VNFEVICTION: VNFID=0;%%
RETCODE = 0  操作成功

操作结果如下
------------
网元ID  节点名称        节点IP          虚拟机ID                            重调度策略  

0       10.113.112.79   10.113.112.79   070b9dad6fd94a43af459db975465baf    开启        
0       10.113.112.197  10.113.112.197  d9524ba42dcf4d8fac2943666c3ca5dd    开启        
0       10.113.112.222  10.113.112.222  8cde48ddba05482bb0d03d01f824577b    开启        
(结果个数 = 3)

---    END
```

#### 输出结果说明

命令执行正常，会返回命令执行成功的提示信息及网元的重调度策略，输出结果项信息项目如表1 输出项说明。

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

| 输出项名称   | 输出项解释           |
|:--------|:----------------|
| 网元ID    | 用于返回查询的网元的ID。   |
| 节点名称    | 用于返回查询的节点名称。    |
| 节点IP    | 用于返回查询的节点的IP地址。 |
| 虚拟机ID   | 用于返回查询的虚拟机ID。   |
| 重调度策略   | 用于返回查询的重调度策略。   |

|    错误码 | 错误码解释       | 原因分析                                                              | 处理建议           |
|-------:|:------------|:------------------------------------------------------------------|:---------------|
| 150001 | 查询网元信息失败    | 查询网元信息失败。                                                         | 检查并修改为正确的网元ID。 |
| 150002 | MML命令参数校验失败 | MML命令参数校验失败。                                                      | 请联系华为技术支持。     |
| 150005 | 获取网元重调度信息失败 | 获取网元重调度信息失败。                                                      | 请联系华为技术支持。     |
| 150021 | 当前模式不支持此命令  | 该命令仅在Full-Stack虚机场景下支持，若在Full-Stack裸机及三方CaaS场景下执行该指令，会返回此错误码作为提示。 | 无需处理。          |
