## 命令功能

**须知** 

该命令会使模块复位，可能会影响运行在模块上的业务，请慎重使用该命令。

本命令用于指示系统对指定的模块执行复位操作。

本命令的使用场景为：

- 在开局、扩容或升级的过程中，需要为指定的模块加载新版本的节点软件。
- 在开局、扩容或升级的过程中，当系统配置出现重大修改（如修改表最大元组数）时，可能需要对相关模块执行复位操作使得修改生效。

## 注意事项

- 为确保系统的安全与稳定运行，除非紧急排除故障的需要，建议操作员在系统话务量少的时间段（例如凌晨2:00～4:00）执行本命令。
- 仲裁PMU模块的“可用状态”为“正常”是执行复位操作的基础，当仲裁PMU模块运行不正常时，将导致本仲裁域内主备模块不能被正常仲裁，可能会影响业务正常运行。
- 如果需要对PMU模块执行复位操作时，请先使用**DSP HAMDU**命令确认此模块是否仲裁PMU，如果仲裁PMU被复位，可能导致本仲裁域内最多5秒无仲裁PMU模块。
- 如果复位的是主模块，请使用**DSP MODULE**命令确认与之对应备用模块的可用状态是否为正常。
- 使用**DSP MODULE**命令查询“可用状态”为“故障”的模块，如果该模块正在启动，执行本命令不会重新启动该模块。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                               |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：用于指定系统复位哪个网元ID的模块。 取值范围：0～1023 默认值：无。 配置原则：无。                                                                                                                    |
| MN     | 模块号    | 可选必选说明：必选参数。 参数含义：用于指定系统复位哪个模块号的模块。 取值范围：0～4294967294 默认值：无。 配置原则：操作员可以使用LST MODULE命令查询获得。                                                                                         |
| VMNAME | Pod名称  | 可选必选说明：可选参数。 参数含义：用于指示系统复位哪一个Pod的模块。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：操作员可以使用LST MODULE命令查询获得。                                                                                       |
| HAST   | 主备状态   | 可选必选说明：可选参数。 参数含义：用于指示系统复位哪一种主备状态的模块数据的记录实体。 取值范围： “STANDBY(备用)”：查询的模块状态为备用。“ACTIVE(主用)”：查询的模块状态为主用。 默认值：无。 配置原则：当不选择Pod名称参数时，必须输入本参数，确定复位模块的状态，否则，命令执行失败。操作员可以使用DSP MODULE命令查询获得。 |

## 使用实例

**实例1**

复位Pod模块。

```
//查询与即将被复位的模块对应备用模块的可用状态是否为正常。同时确认PMU模块的可用状态是否为正常，以确定模块是否能够进行倒换。
DSP MODULE:;
```

```
///升级时，先复位“网元ID”为“0”，“模块号”为“3016”，“Pod名称”为“cgplite-0”，“主备状态”为“ACTIVE(主用)”的模块。
RST MODULE: MEID=0, MN=3016, VMNAME="cgplite-0", HAST=ACTIVE;
```

```
//查询模块状态，以确定复位是否成功。
DSP MODULE:;
```
