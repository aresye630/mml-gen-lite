# 设置性能插件(SET PMPLUG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

执行该命令会改变网元性能数据，执行不当会导致网元性能统计功能不可用，请慎重执行。

本命令用于设置性能插件。

本命令的使用场景为：系统调测的情况下在需要对指定网元进行插件的安装、卸载、升级、回退或者备份数据删除等操作时使用。

## 注意事项

- 一个网元最多可以设置10个插件。
- 使用该命令进行插件安装时，需要手动将插件包放至目录：“/opt/HUAWEI/cgp/workshop/nes/neX/workspceY/pm\_adapter\_data/”，其中X为网元ID，Y为网元当前工作区ID，插件包名称为PM\_PLUG\_Z，Z对应该命令的插件编号输入参数。
- 使用该命令进行插件升级时，需要手动将升级插件包放至目录：“/opt/HUAWEI/cgp/workshop/nes/neX/workspceY/pm\_adapter\_data/”，其中X为网元ID，Y为网元当前工作区ID，插件包名称为UPG\_PM\_PLUG\_Z，Z对应该命令的插件编号输入参数。
- 性能插件升级成功后，如果已经执行了备份数据的删除，则不能再进行性能插件的回退。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                         |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------------|
| MEID     | 网元ID   | 可选必选说明：必选参数。 参数含义：用于唯一标识一个网元实例。 取值范围：0～1023 默认值：无。 配置原则：无。                                                                   |
| PLUGID   | 插件编号   | 可选必选说明：必选参数。 参数含义：用于标识某网元下的一个性能插件。 取值范围：0～9 默认值：无。 配置原则：无。                                                                   |
| OPERTYPE | 操作类型   | 可选必选说明：必选参数。 参数含义：用于标识对插件执行何种类型操作。 取值范围： “INSTALL(安装)” “UNINSTALL(卸载)” “UPG(升级)” “ROLLBACK(回退)” “CLEAN(删除备份)” 默认值：无。 配置原则：无。 |

## 使用实例

1. 安装性能插件：

   `SET PMPLUG: MEID=10, PLUGID=1, OPERTYPE=INSTALL;`
2. 卸载性能插件：

   `SET PMPLUG: MEID=10, PLUGID=2, OPERTYPE=UNINSTALL;`
3. 升级性能插件：

   `SET PMPLUG: MEID=10, PLUGID=1, OPERTYPE=UPG;`
4. 回退性能插件：

   `SET PMPLUG: MEID=10, PLUGID=1, OPERTYPE=ROLLBACK;`
5. 删除性能插件备份：

   `SET PMPLUG: MEID=10, PLUGID=1, OPERTYPE=CLEAN;`
