# 复位指定类型的模块(RST MDUTYPE)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

**须知** 

本命令会复位指定类型的模块，操作不当会影响模块上运行的业务，请慎重使用该命令。

本命令用于快速复位指定类型的模块。

本命令的操作场景一般为：当系统出现故障导致业务运行异常时，操作员可以执行此命令，快速复位和业务相关的同一类型的所有模块，以恢复业务。

## 注意事项

- 复位主用模块会引起模块发生主备倒换。
- 对于故障态的模块，如果模块正在启动，该命令不会重新启动该模块。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                   |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：表示指定模块的网元号。 取值范围：0～1023 默认值：无。 配置原则：无。                                                                                                                                                                               |
| DESC   | 模块类型   | 可选必选说明：必选参数。 参数含义：表示指定模块的类型，用于指定需要复位哪种类型的模块。 取值范围：长度不超过200个英文字符（中文字符不超过100个）。 默认值：无。 配置原则：操作员可以使用DSP MODULE命令查询获得模块的类型。                                                                                                                |
| HAST   | 主备状态   | 可选必选说明：可选参数。 参数含义：表示指定模块的主备状态，操作员可以使用DSP MODULE命令查询获得模块的主备状态。 取值范围： “ALL(所有状态)”：所有状态的模块都复位。“STANDBY(备用)”：状态为备用的模块都复位。“ACTIVE(主用)”：状态为主用的模块都复位。 默认值：“ALL(所有状态)”。 配置原则：对于PMU类型的模块，如果选择复位的是主用状态PMU，将复位所有仲裁PMU，如果选择复位的是备用状态PMU，将复位所有普通PMU。 |

## 使用实例

1. 复位“网元ID”为“5”，“模块类型”为“CCU”的主用模块：

   `RST MDUTYPE: MEID=5, DESC="ccu", HAST=ACTIVE;`

   ```
   %%RST MDUTYPE: MEID=5, DESC="ccu", HAST=ACTIVE;%%
   RETCODE = 0  操作成功
   ```

## 输出结果说明

| 输出项名称   | 输出项解释                       |
|:--------|:----------------------------|
| Pod名称   | 用于返回指定类型的模块所属Pod的名称。        |
| 位置描述    | 用于返回指定类型的模块所属Pod的位置信息。      |
| 模块类型    | 用于返回模块的模块类型                 |
| 模块号     | 用于返回指定类型的模块对应的模块号。          |
| 主备状态    | 用于返回模块的主用或者备用状态             |
| 操作结果    | 用于返回本命令执行结果：“成功”，“失败”或“超时”。 |
