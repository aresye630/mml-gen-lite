# 显示仲裁PMU信息(DSP HAMDU)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于显示当前系统中所有仲裁域中的仲裁PMU信息。

## 注意事项

- 仲裁域是配置顺序上相邻的Pod的集合，在用户部署Pod时，由系统内部进行配置，一个仲裁域内最多可以包含32个Pod。
- 一个系统中最多可以有64个仲裁域，仲裁域ID的取值范围：0～63。

## 参数说明

无。

## 使用实例

查询系统中的仲裁PMU信息。

`DSP HAMDU:;`

```
%%DSP HAMDU:;%%
RETCODE = 0  操作成功

Pod结果如下
--------------
            网元ID  =  0
          仲裁域ID  =  63
            模块号  =  3019
        Pod名称  =  null_msxlsm20_LB_1
          位置描述  =  10.7.50.10
          主备状态  =  主用
          可用状态  =  正常
    分配的内存(KB)  =  287070
内存占用率(百分比)  =  63
 CPU占用率(百分比)  =  6
          管理状态  =  不支持
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称       | 输出项解释                                                              |
|:------------|:-------------------------------------------------------------------|
| 网元ID        | 用于返回仲裁PMU进程所属的网元ID。                                                |
| 仲裁域ID       | 用于返回仲裁PMU进程所属的仲裁域ID。                                               |
| 模块号         | 用于返回仲裁PMU进程对应的模块号。                                                 |
| Pod名称       | 用于返回仲裁PMU进程所属Pod的名称。                                               |
| 位置描述        | 用于返回仲裁PMU进程所属Pod的位置信息。                                             |
| 主备状态        | 用于返回仲裁PMU进程当前所处的运行状态。 “主用”：表示仲裁PMU进程的状态为主用。“未配置”：表示仲裁PMU进程的状态为未配置。 |
| 可用状态        | 用于返回仲裁PMU进程当前是否处于可以使用的状态。此值固定为“正常”，表示仲裁PMU可以提供服务。                  |
| 分配的内存(KB)   | 用于返回仲裁PMU进程分配的内存大小，单位为KB。                                          |
| 内存占用率(百分比)  | 用于返回仲裁PMU进程当前使用内存占用进程“分配的内存(KB)”的百分比。                              |
| CPU占有率(百分比) | 用于返回仲裁PMU进程当前的CPU占用率。                                              |
| 管理状态        | 用于返回仲裁PMU进程当前所处的管理状态信息。此值固定为“不支持”，表示仲裁PMU不支持管理状态。                  |
