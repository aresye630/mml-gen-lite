# 查询系统日志级别(DSP SYSLOG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询节点文本日志的打印级别控制开关状态，通过该命令可以查询所有模块各个PID的日志打印级别控制开关状态。

## 注意事项

执行本命令时，建议指定参数条件进行过滤，否则过多的报文可能会影响客户端与OMU之间通讯质量。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                 |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VMNAME | Pod名称  | 可选必选说明：必选参数。 参数含义：用于指定系统需要按照某个Pod来查询系统日志级别。操作员可以通过执行LST MODULE命令查询获得对应进程的Pod名称。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则： 该参数的值域范围为：大写字母“A～Z”、小写字母“a～z”、数字“0～9”、特殊字符 -_。 该参数必须以字母开头。 该参数区分大小写。 |
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：用于指定实施操作的网元。 取值范围：0～1023 默认值：无。 配置原则：无。                                                                                                                            |
| LCPUID | 模块号    | 可选必选说明：必选参数。 参数含义：用于指定查询日志打印级别控制开关对应的模块号。操作员可以通过LST MODULE命令查询模块号。 取值范围：0～4294967294 默认值：无。 配置原则：无。                                                                                  |
| HAST   | 主备状态   | 可选必选说明：必选参数。 参数含义：用于指定查询日志打印级别控制开关的模块状态。若不输入，则表示正常运行的所有状态。 取值范围： “ACTIVE(主用)”：指定查询日志打印级别控制开关的模块状态为主用。“STANDBY(备用)”：指定查询日志打印级别控制开关的模块状态为备用。 默认值：无。 配置原则：无。                            |
| PID    | PID    | 可选必选说明：必选参数。 参数含义：用于请求系统显示某一个PID信息。操作员可以通过DSP PIDINF命令查询PID。 取值范围：0～1023 默认值：无。 配置原则：无。                                                                                              |

## 使用实例

查询节点文本日志打印级别的控制状态，“Pod名称”为“Pod1”，“网元ID”为“0”，“模块号”为“1300”，“主备状态”为“ACTIVE(主用)”，“PID”为“184”。

`DSP SYSLOG: VMNAME="Pod1", MEID=0, LCPUID=1300, HAST=ACTIVE, PID=184;`

## 输出结果说明

| 输出项名称   | 输出项解释                 |
|:--------|:----------------------|
| Pod名称   | 用于返回模块所在的Pod名称。       |
| 位置描述    | 用于返回模块的位置描述信息。        |
| 网元ID    | 用于返回模块所属的网元信息。        |
| 模块号     | 用于返回该进程的模块号信息。        |
| 主备状态    | 用于返回模块的主备状态。          |
| PID     | 表示主机进程的PID。           |
| 调试      | 表示日志调试级别开关状态：禁止输出允许输出 |
| 信息      | 表示日志信息级别开关状态：禁止输出允许输出 |
| 通知      | 表示日志通知级别开关状态：禁止输出允许输出 |
| 警告      | 表示日志警告级别开关状态：禁止输出允许输出 |
| 错误      | 表示日志错误级别开关状态：禁止输出允许输出 |
| 重要      | 表示日志重要级别开关状态禁止输出允许输出  |
| 警报      | 表示日志警报级别开关状态：禁止输出允许输出 |
| 紧急      | 表示日志紧急级别开关状态：禁止输出允许输出 |
