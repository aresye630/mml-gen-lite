# 查询网元生命周期管理日志（LST LCMLOG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询指定网元版本变更信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                               |
|:-------|:-------|:-----------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个网元ID来查询。 取值范围：0~65535。 默认值：无。 配置原则：可以使用LST ME命令查询获得。 |

## 使用实例

查询网元生命周期管理日志：

```
%%LST LCMLOG: MEID=29;%% 
RETCODE = 0  操作成功

网元生命周期管理日志 
-------------------- 
网元名称  网元ID  网元类型  操作类型  操作时间             源版本号  目标版本号

test      29      TEST      安装网元  2020-08-28 22:17:45  21.1.0    null         
test      29      TEST      版本升级  2020-08-28 22:35:53  21.1.0    21.2.0       
test      29      TEST      版本回退  2020-08-28 22:36:01  21.2.0    21.1.0       
test      29      TEST      安装补丁  2020-08-28 22:36:13  21.1.0    21.1.0.1     
test      29      TEST      回退补丁  2020-08-28 22:36:20  21.1.0.1  21.1.0       
(结果个数 = 5) 

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息，输出项如表1 输出项说明所示。

该命令执行异常，会返回对应的错误码。常见错误码列表如表2 错误码列表所示。

| 输出项名称   | 输出项解释                          |
|:--------|:-------------------------------|
| 网元名称    | 网元名称。                          |
| 网元ID    | 网元ID。                          |
| 网元类型    | 网元类型。                          |
| 操作类型    | 安装网元、卸载网元、版本升级、安装补丁、版本回退、回退补丁。 |
| 操作时间    | 操作时间。                          |
| 源版本号    | 操作前网元版本号。                      |
| 目标版本号   | 操作后网元版本号。                      |

|    错误码 | 错误码解释         | 原因分析                              | 处理建议                    |
