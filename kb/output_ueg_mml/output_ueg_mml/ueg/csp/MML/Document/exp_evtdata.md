# 导出事件数据 (EXP EVTDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于导出事件数据。

本命令的使用场景为：日常操作维护中，需要对事件数据进行保存或者分析时，操作员可使用此命令将事件数据导出到文件中。

## 注意事项

事件数据导出后存放于CGPLite容器内“/opt/HUAWEI/cgp/workshop/omu/share/export/fm/alarminstance/manualexport/event”路径，在OM Portal界面选择“系统 > 文件传输 > CGPLite文件 > 导出文件 > fm > alarminstance >  manualexport > event”，选择“导出文件名称”参数指定的文件，将导出的网元数据下载到本地。

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
|:-------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID   | 网元ID      | 可选必选说明：可选参数 参数含义：用于指定系统需要对哪个网元进行操作；若不输入，则表示所有网元。 取值范围：0～1023 默认值：无 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| FNAME  | 导出文件名称    | 可选必选说明：必选参数 参数含义：用于指定导出文件的名称。 取值范围：长度不超过128个英文字符。 默认值：无 配置原则：其中不能包含如下特殊字符：“\”、“/”、“:”、“*”、“?”、“"”、“<”、“>”、“|”、“'”。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| MN     | 模块号       | 可选必选说明：可选参数 参数含义：用于指定主机的模块号；若不输入，则表示所有模块。 导出OMU进程的事件数据时，该参数统一填写为0。 取值范围：0～4294967294 默认值：无 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| SS     | 起始流水号     | 可选必选说明：可选参数 参数含义：用于指定导出事件数据时流水号的取值下限；若不输入，则表示没有下限。流水号：是在一个网元内对事件进行的编号。 取值范围：1～2147483646 默认值：无 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ES     | 结束流水号     | 可选必选说明：可选参数 参数含义：用于指定导出事件数据时流水号的取值上限；若不输入，则表示没有上限。 取值范围：1～2147483646 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| SEID   | 起始事件ID    | 可选必选说明：可选参数 参数含义：用于指示导出事件数据时事件ID的取值下限；若不输入，则表示没有下限。事件ID：用于确定一类事件，代表一种特定的事件，是事件项的唯一索引。 取值范围：1～200000 默认值：无 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| EEID   | 结束事件ID    | 可选必选说明：可选参数 参数含义：用于指示导出事件数据时事件ID的取值上限；若不输入，则表示没有上限。 取值范围：1～200000 默认值：无 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ET     | 事件类型      | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪种事件类型来导出事件数据；若不输入，则表示所有事件类型。事件类型：是对事件的一种基本分类，用来表明承载事件的事件报告类型。 取值范围：“POWER(电源系统)”：有关电源系统的事件（直流-48V）。“ENVIRONMENT(环境系统)”：有关机房环境（温度、湿度、门禁等）的事件。“SIGNALING(信令系统)”：有关随路信令（一号）和共路信令（七号）等事件。“TRUNK(中继系统)”：有关中继电路及中继板的事件。“HARDWARE(硬件系统)”：有关硬件设备的事件（如时钟、CPU等）。“SOFTWARE(软件系统)”：有关软件方面的事件。“RUNNING(运行系统)”：系统运行时产生的事件。“COMMUNICATION(通信系统)”：有关通信系统的事件（如前后台通信）。“QOS(业务质量)”：有关服务质量的事件。“PROCESS(处理出错)”：其他异常情况事件。“INTEGRITY(完整性违背)”：有关系统中数据被修改错误或删除的事件。“OPERATIONAL(操作违背)”：有关非法操作的事件。“PHYSICAL(物理违背)”：有关物理设备被非法操作的事件。“SECURITY(安全违背)”：被安全模块发现的安全相关的事件。“TIMEOUT(时间域违背)”：有关在非法时间下执行操作的事件。 默认值：无 配置原则：无。 |
| SGT    | 起始时间      | 可选必选说明：可选参数 参数含义：用于指示系统导出事件数据时事件产生时间的取值下限；若不输入，则表示没有下限。事件产生时间：表示被管对象产生该事件的时间。 取值范围：01/01/1990 00:00:00～31/12/2037 23:59:59 默认值：无 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| EGT    | 结束时间      | 可选必选说明：可选参数 参数含义：用于指示系统导出事件数据时事件产生时间的取值的上限；若不输入，则表示没有上限。 取值范围：01/01/1990 00:00:00～31/12/2037 23:59:59 默认值：无 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ECNT   | 导出的事件记录条数 | 可选必选说明：可选参数 参数含义：用于指定导出事件的记录条数。 取值范围：1～2147483647 默认值：无 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| EFMT   | 导出文件格式    | 可选必选说明：可选参数 参数含义：用于指定导出事件数据的格式。 取值范围：“XML(XML格式)”：导出为XML格式。“CSV(CSV格式)”：导出为CSV格式。 默认值：“XML(XML格式)” 配置原则： “导出文件格式”参数为“XML(XML格式)”时文件名称为“导出文件名称”参数指定的名称。 “导出文件格式”参数为“CSV(CSV格式)”时文件命名规则：“压缩标识”为“UNCOMPRESSED(非压缩模式)”时：导出后文件名称为“文件名_网元ID_00X.csv”，其中文件名指“导出文件名称”参数，X从1递增，每一个文件写满60000条记录后，会重新生成下一个文件 “压缩标识”为“COMPRESSED(压缩模式)”时：导出后文件名称为“文件名_CSV.tar.gz”，其中文件名指“导出文件名称”参数。                                                                                                                                                                                                                                             |
| CF     | 压缩标识      | 可选必选说明：可选参数 参数含义：用于指定导出事件数据的压缩模式。 取值范围：“UNCOMPRESSED(非压缩模式)”：导出时不进行压缩处理。“COMPRESSED(压缩模式)”：导出时进行压缩处理。 默认值：“UNCOMPRESSED(非压缩模式)” 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |

## 使用实例

导出事件数据文件：设置“网元ID”为“0”，“导出文件名称”为“aaa”，“模块号”为“0”，“起始流水号”设置为“1”，“结束流水号”为“1”，“起始事件ID”为“1”，“结束事件ID”为“1”，“事件类型”为“TRUNK(中继系统)”，“起始时间”为“2023.02.25 10:33:58”，“结束时间”为“2023.02.25 10:53:58”，“导出的事件记录条数”为“255”，“导出文件格式”为“XML(XML格式)”，“压缩标识”为“UNCOMPRESSED(非压缩模式)”。

```
EXP EVTDATA: MEID=0, FNAME="aaa", MN=0, SS=1, ES=1, SEID=1, EEID=1, ET=TRUNK-1, SGT=2023&02&25&10&33&58, EGT=2023&02&25&10&53&58, ECNT=255, EFMT=XML, CF=UNCOMPRESSED;
```
