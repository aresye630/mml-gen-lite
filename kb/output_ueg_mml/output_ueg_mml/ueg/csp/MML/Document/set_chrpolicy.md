## 命令功能

**注意** 

执行该命令将会改变CHR的传输配置信息，执行不当会导致CHR单据无法正常传输，请慎重执行。

本命令为配置类命令，用于设置CHR的传输策略。

本命令的使用场景为：在CGPLite传输业务进程生成CHR话单时，设置CHR传输策略，并对相关传输参数进行配置。

- 在“CHR本地保存开关”打开时，CHR单据保存在目录“/opt/HUAWEI/cgp/workshop/omu/share/export/pm/CHR”。如果开启VIPCHR单独存储功能，VIPCHR单据保存在目录“/opt/HUAWEI/cgp/workshop/omu/share/export/pm/VIPCHR”。
- 在“FTP传输开关”打开时，经过指定时间间隔，将该目录下的CHR单据依次上传至指定SFTP服务器的目标路径，上传成功后同时删除该目录下的本地存储，所有历史话单会存储在目录“/opt/HUAWEI/cgp/workshop/omu/share/export/pm/CHR4MAN”。

**说明** 

CHR单据在OM Portal的获取方式：依次单击“系统 > 文件传输 > CGPLite文件 > 导出文件 > pm”选择CHR或CHR4MAN或VIPCHR，下载CHR单据。

## 注意事项

- 在“CHR本地保存开关”关闭的情况下，CGPLite会将CHR单据丢弃不做处理。
- 在“CHR本地保存开关”打开时，且“FTP传输开关”打开的情况下，如果CGPLite与目的SFTP服务器连接长时间中断，会出现CHR单据丢失的现象。

**说明** 

在“CHR本地保存开关”打开的情况下，可能涉及个人数据，使用该功能时须遵循所使用国家的法律和运营商的用户隐私保护政策，并采取足够的措施，以确保用户的个人数据受到充分的保护。

## 参数说明

| 参数标识        | 参数名称         | 参数说明                                                                                                                                                                                                                   |
|:------------|:-------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LOCALSW     | CHR本地保存开关    | 可选必选说明：必选参数 参数含义：用于控制是否本地存储 。开关打开时，“FTP传输开关”生效。 取值范围： “ON（打开）”“OFF（关闭）” 默认值：无。 配置原则：无。                                                                                                                                 |
| FTPTRANSSW  | FTP传输开关      | 可选必选说明：CHR本地保存开关打开时为必选参数 参数含义：用于控制是否进行FTP传输 。开关打开时显示后面参数。 取值范围： “ON（打开）”“OFF（关闭）” 默认值：无。 配置原则：无。                                                                                                                       |
| IPTYPE      | IP版本         | 可选必选说明：CHR本地保存开关和FTP传输开关打开时为必选参数 参数含义：SFTP服务器IP地址类型。 取值范围： “IPV4（IPv4版本）”“IPV6（IPv6版本）” 默认值：无。 配置原则：无。                                                                                                                 |
| SERVERIP    | FTP服务器IPV4地址 | 可选必选说明：CHR本地保存开关和FTP传输开关打开时为必选参数 参数含义：SFTP服务器IPV4地址，是SFTP传输时的重要参数，需要与SFTP服务器协商一致；若不一致，文件上传会失败。 取值范围：无。 默认值：无。 配置原则：无。                                                                                                  |
| SERVERV6IP  | FTP服务器IPV6地址 | 可选必选说明：CHR本地保存开关和FTP传输开关打开时为必选参数 参数含义：SFTP服务器IPV6地址，是SFTP传输时的重要参数，需要与SFTP服务器协商一致；若不一致，文件上传会失败。 取值范围： 无。 默认值：无。 配置原则：无。                                                                                                 |
| SERVERPORT  | FTP服务器端口     | 可选必选说明：CHR本地保存开关和FTP传输开关打开时为必选参数 参数含义：FTP服务器端口号，是SFTP传输时的重要参数，需要与SFTP服务器协商一致；若不一致，文件上传会失败。 取值范围：“1~65535” 默认值：无。 配置原则：无。                                                                                               |
| FTPUSER     | FTP用户名       | 可选必选说明：CHR本地保存开关和FTP传输开关打开时为必选参数 参数含义：SFTP用户名，是SFTP传输时的重要参数，需要与SFTP服务器协商一致；若不一致，文件上传会失败。 取值范围：长度不超过256个英文字符。 默认值：无。 配置原则：无。                                                                                            |
| FTPPSSWD    | FTP密码        | 可选必选说明：CHR本地保存开关和FTP传输开关打开时为必选参数 参数含义：FTP用户密码，是SFTP传输时的重要参数，需要与SFTP服务器协商一致；若不一致，文件上传会失败。 取值范围：长度不超过128个英文字符。 默认值：无。 配置原则： 密码不支持中文字符。密码区分大小写。密码中不能含如下字符串：“%%”、“+++”、连续两个或者两个以上空格。密码中不能包含英文分号、英文单引号和双引号、英文逗号、英文反斜杠和英文等号。 |
| DSTPATH     | 目标目录         | 可选必选说明：CHR本地保存开关和FTP传输开关打开时为必选参数 参数含义：用于指定SFTP服务器上的目标路径。 取值范围：长度不超过256个英文字符。 默认值：无。 配置原则：不能包含英文分号、英文反斜线、英文冒号、英文问号、英文引号、英文尖括号和英文星号。                                                                                     |
| SNDINTERVAL | 发送间隔（秒）      | 可选必选说明：CHR本地保存开关和FTP传输开关打开时为必选参数 参数含义：每次进行CHR单据传输的时间间隔。 取值范围：“5~600” 默认值：无。 配置原则：无。                                                                                                                                    |

## 使用实例

1. 打开“CHR本地保存开关”，打开“FTP传输开关”，设置SFTP服务器的IP版本、IP地址、端口号、用户名、密码、目标路径和发送间隔：

   ```
   SET CHRPOLICY: LOCALSW=ON, FTPTRANSSW=ON, IPTYPE=IPV4, SERVERIP="127.0.0.1", SERVERPORT=22, FTPUSER="admin", FTPPSSWD="*****", DSTPATH="/tmp", SNDINTERVAL=30;
   ```

   ```
   %%SET CHRPOLICY: LOCALSW=ON, FTPTRANSSW=ON, IPTYPE=IPV4, SERVERIP="127.0.0.1", SERVERPORT=22, FTPUSER="admin", FTPPSSWD="*****", DSTPATH="/tmp", SNDINTERVAL=30;%%
   RETCODE = 0  操作成功
   ```
2. 关闭“CHR本地保存开关”：

   ```
   SET CHRPOLICY: LOCALSW=OFF;
   ```

   ```
   %%SET CHRPOLICY: LOCALSW=OFF;%%
   RETCODE = 0  操作成功
   ```
