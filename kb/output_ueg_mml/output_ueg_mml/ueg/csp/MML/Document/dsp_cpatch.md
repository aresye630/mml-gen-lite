# 查询服务器补丁(DSP CPATCH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询所有网元的服务器补丁状态。

本命令的使用场景为：当操作员想查看当前环境上各网元的服务器补丁情况时，均可以使用该命令对服务器补丁进行查询操作。

## 注意事项

- 当不输入网元ID查询时，查询结果中只显示打了服务器补丁网元的补丁信息。
- 该命令用于查询服务器补丁，若需要查询补丁是否正确打上，请执行**CHK CPATCHCRC**命令检查节点侧运行的进程文件和OMU侧是否一致，一致则认为打补丁成功。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                 |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：可选参数。 参数含义：用于请求系统需要对哪一个网元实例实施操作。 取值范围：0～1023。 默认值：无。 配置原则：需要指出的是，如果不指定网元ID，默认会列出所有网元的服务器补丁信息。 |

## 使用实例

1. 查询所有网元的服务器补丁信息:

   `DSP CPATCH:;`

   ```
   %%DSP CPATCH:;%%
   RETCODE = 0  操作成功

   当前服务器补丁的结果如下
   ------------------------
    网元ID  补丁名称  服务器补丁状态
                      
    0       SPC001    更新态          
    5       SPC001    更新态        
    6       SPC001    更新态          
   (结果个数 = 3)

   回退服务器补丁的结果如下
   ------------------------
    网元ID  补丁名称  服务器补丁状态
            
    0       SPC000    NULL            
    5       SPC000    NULL
    6       SPC000    NULL            
   (结果个数 = 3)

   ---    END
   ```
2. 查询5网元的服务器补丁信息:

   `DSP CPATCH:MEID=5;`

   ```
   %%DSP CPATCH: MEID=5;%%
   RETCODE = 0  操作成功

   当前服务器补丁的结果如下
   ------------------------
           网元ID  =  5
         补丁名称  =  SPC001
   服务器补丁状态  =  更新态
   (结果个数 = 1)

   回退服务器补丁的结果如下
   ------------------------
           网元ID  =  5
         补丁名称  =  SPC000
   服务器补丁状态  =  NULL
   (结果个数 = 1)
   ---    END
   ```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                                                   |
|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------|
| 网元ID    | 用于唯一标识一个子网下的网元实例。                                                                                                                                       |
| 补丁名称    | 用于标识服务器补丁的名称，命名规则是SPCXXX或CPXXXX，其中SPCXXX表示冷补丁，CPXXXX表示紧急冷补丁。SPC000表示该网元未打任何服务器补丁。                                                                       |
| 服务器补丁状态 | 用于标识服务器补丁的补丁状态。 取值说明： “更新态”：表示服务器补丁已经安装成功。“更新中”：表示服务器补丁正在安装或安装失败。请检查“监控分析 > 告警管理 > 活动告警”中是否存在“ALM-2377 网元补丁不完整”或“ALM-2376 补丁自动安装失败”告警，如果产生则参见其告警帮助进行处理。 |
