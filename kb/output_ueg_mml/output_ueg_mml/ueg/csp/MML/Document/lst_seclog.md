# 查询安全日志（LST SECLOG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询安全日志。

该命令获取日志与OM Portal界面“安全>日志审计>安全日志”相同。

## 注意事项

最大限度为1000条。如果超过最大限度，则返回满足条件的最新的1000条。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                             |
|:--------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------|
| OPERATIONUSER | 操作用户   | 可选必选说明：可选参数。 参数含义：用于命令按照操作用户名称来查询安全日志；若不输入，则表示查询前1000条安全日志。 取值范围：操作用户名称。可从菜单“安全>用户管理”中获取。 默认值：无。 配置原则：无。                                         |
| MENAME        | 网元名称   | 可选必选说明：可选参数。 参数含义：用于命令按照网元名称来查询安全日志，LST ME命令可获取；若不输入，则表示查询前1000条安全日志。 取值范围：字符串类型，输入长度范围为0~64。 默认值：无。 配置原则：无。                                     |
| LEVEL         | 级别     | 可选必选说明：可选参数。 参数含义：用于命令按照操作级别来查询安全日志；若不输入，则表示查询前1000条安全日志。 取值范围： Minor(次要)Important(重要)Urgent(紧急) 默认值：无。 配置原则：无。                                  |
| RESULT        | 操作结果   | 可选必选说明：可选参数。 参数含义：用于命令按照操作结果状态来查询安全日志；若不输入，则表示查询前1000条安全日志。 取值范围： Successful(成功)Failed(失败)PartiallySuccessful(部分成功)Executing(执行中) 默认值：无。 配置原则：无。 |
| SDT           | 开始时间   | 可选必选说明：可选参数。 参数含义：用于命令按照安全日志开始时间来查询安全日志；若不输入，则表示查询前1000条安全日志。 取值范围：1990/01/01 00:00:00-2037/12/31 23:59:59。 默认值：无。 配置原则：无。                       |
| EDT           | 结束时间   | 可选必选说明：可选参数。 参数含义：用于命令按照安全日志结束时间来查询安全日志；若不输入，则表示查询前1000条安全日志。 取值范围：1990/01/01 00:00:00-2037/12/31 23:59:59。 默认值：无。 配置原则：无。                       |
| OPERATIONNAME | 操作名称   | 可选必选说明：可选参数。 参数含义：用于命令按照操作名称来查询安全日志；若不输入，则表示查询前1000条安全日志。 取值范围：字符串类型，输入长度范围为0~100。 默认值：无。 配置原则：无。                                                |

## 使用实例

查询安全日志：

```
%%LST SECLOG:;%%
RETCODE = 0  操作成功

结果信息 
-------- 
操作名称                 级别   操作用户    用户类型    网元名称   开始时间              操作源IP      服务名称      操作结果    接入方式       详细信息

查询时间控制策略         重要   admin       本地用户    faircat    2020-04-17 00:58:58   10.0.0.0       Privilege    成功        本地终端       查询登录时间策略。 
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见如表1所示参数说明。

该命令执行异常，会返回对应的错误码。常见的错误码如表2所示。

| 输出项名称   | 输出项解释                               |
|:--------|:------------------------------------|
| 操作名称    | 用于表示产生安全日志的操作名称。                    |
| 级别      | 用于表示产生安全日志的级别。                      |
| 操作用户    | 用于表示产生安全日志的操作用户。                    |
| 用户类型    | 用于表示安全日志的用户类型。                      |
| 网元名称    | 用于表示产生安全日志的网元名称。                    |
| 开始时间    | 用于表示产生安全日志的开始时间。                    |
| 操作源IP   | 用于表示产生安全日志的设备源IP。                   |
| 服务名称    | 用于表示产生安全日志的服务名称。                    |
| 操作结果    | 用于表示产生安全日志的结果：成功、失败、部分成功或者执行中。      |
| 接入方式    | 用于表示产生安全日志的客户端：本地终端、华为网管、第三方网管。     |
| 详细信息    | 用于表示安全日志的详细信息，方便维护人员定位分析该操作对于系统的影响。 |

|    错误码 | 错误码解释   | 原因分析     | 处理建议          |
|-------:|:--------|:---------|:--------------|
| 101100 | 请求参数不合法 | 请求参数不合法。 | 请检查输入参数并重新输入。 |
| 101108 | 系统内部错误  | 系统内部错误。  | 请联系华为技术支持。    |
