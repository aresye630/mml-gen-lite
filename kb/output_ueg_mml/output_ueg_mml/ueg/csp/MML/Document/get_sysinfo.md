## 命令功能

**须知** 

根据系统信息文件大小，此命令的执行可能会耗费几分钟时间。

本命令用于将指定的Pod上的系统启动日志、黑匣子文件、文件或目录属性信息等上传到主用OMU Pod。

- 当“系统信息类型”为“HEALTHCHK(健康检查结果收集)”，文件上传目录：为/opt/HUAWEI/cgp/workshop/omu/share/run\_log/omu/cdp/hck。
- 当“系统信息类型”为其他选项，文件上传目录为“/opt/HUAWEI/cgp/workshop/omu/share/run\_log/omu/cdp”。

文件命名方式为Pod名，例如cgplite-0。

本命令的使用场景为：

- 定位模块异常退出的相关问题时，需要获取相应的黑匣子和monitor日志进行分析。
- 定位操作系统相关的问题时，需要获取操作系统运行状态相关的信息进行分析。
- 定位加载相关的问题时，需要获取启动日志等相关信息进行分析。

**说明** 

收集日志信息：请登录OM Portal，选择“监控分析>运行日志>日志下载”，收集csp下/CGPLite/omu/cdp路径里的服务日志。

## 注意事项

- 在同一时刻只能有一个客户端执行本命令获取系统信息。
- 本命令只负责已生成日志的传输下载，如果日志信息没有生成，执行本命令就获取不到信息，可以使用信息收集工具进行信息收集。
- Pod启动后，PMU进程会自动读取内核黑匣子文件收集项中的启动日志，在读取没有完成前（约10分钟），执行本命令获取日志可能失败。
- 本命令执行后生成带gz后缀的压缩文件，通过7zip解压缩软件可以解压。
- “系统信息类型”参数选择“ALL(所有文件)”时所获取的日志不包含该参数为“ATTRIBUTE(文件/目录属性)”、“HEALTHCHK(健康检查结果收集)”和“IPINFO(IP信息)”所能获取的日志。
- 黑匣子文件用于进程复位场景下的问题快速定位和故障排除，会记录进程复位前的部分内存信息。内存中可能涉及到敏感信息，建议谨慎使用并妥善保管黑匣子文件。
- 本命令只保留最后一次收集的信息。

|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TYPE    | 系统信息类型 | 可选必选说明：必选参数。 参数含义：用于请求系统是按照哪种系统信息类型显示系统信息。 取值范围： “ALL(所有文件)”：用于查询所有类型的系统信息。“STA(系统启动日志)”：用于查询系统启动日志信息，用于定位Pod启动相关问题的重要输入文件。“BBOX(进程黑匣子)”：用于提供指定Pod的指定网元或者指定模块（包括主备模块）的进程黑匣子日志。用于定位模块异常退出问题的重要输入文件。“ATTRIBUTE(文件/目录属性)”：用于提供指定Pod上的文件或目录的属性信息。“HOST(主机日志)”：用于提供Pod上的主机日志。“HEALTHCHK(健康检查结果收集)”：用于查询健康检查结果。“IPINFO(IP信息)”：用于提供指定Pod上的通信相关信息，具体包括：NETSTAT的结果、各网口的统计信息、TCP统计信息和IP统计信息等。 默认值：无。 配置原则：无。 |

## 使用实例

1. 获取“系统信息类型”为“BBOX(进程黑匣子)”，“Pod名称”为“cgplite-0”，“网元号”为“0”，“模块号”为“3016”，“起始时间”为“2014-12-18 21:10:22”，“结束时间”为“2014-12-18 21:12:22”的黑匣子信息：

   `GET SYSINFO: TYPE=BBOX, VMNAME="cgplite-0", MEID=0, MN=3016, BST=2014&12&18&21&10&22, BET=2014&12&18&21&12&22;`

   ```
   %%GET SYSINFO: TYPE=BBOX, VMNAME="cgplite-0", MEID=0, MN=3016, BST=2014&12&18&21&10&22, BET=2014&12&18&21&12&22;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   Pod名称  =  cgplite-0
     位置描述  =  10.7.90.60
     操作结果  =  成功
   (结果个数 = 1)

   共有3个报告
   ---    END
   ```
2. 获取“系统信息类型”为“BBOX(进程黑匣子)”，“Pod名称”为“cgplite-0”的黑匣子信息:

   `GET SYSINFO: TYPE=BBOX, VMNAME="cgplite-0";`

   ```
   %%GET SYSINFO: TYPE=BBOX, VMNAME="cgplite-0";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   Pod名称  =  cgplite-0
     位置描述  =  10.7.90.60
     操作结果  =  成功
   (结果个数 = 1)

   共有3个报告
   ---    END
   ```

## 输出结果说明

执行本命令时间较长，在执行过程中会定时上报命令执行进度。当进度达到100%时，给出命令执行的最终结果报文。

| 输出项名称   | 输出项解释                 |
|:--------|:----------------------|
| Pod名称   | 用于标识服务实例对应Pod的名称。     |
| 位置描述    | 用于返回所属Pod的位置信息。       |
| 操作结果    | 用于返回执行命令对应的Pod信息收集结果。 |
