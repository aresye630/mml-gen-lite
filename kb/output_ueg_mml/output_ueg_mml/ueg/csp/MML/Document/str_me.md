# 启动网元(STR ME)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

此网元的所有进程将被启动，请确认是否继续。

该命令用于启动该网元的所有模块。

## 注意事项

- 若在执行**STP ME**后第一次执行该命令，命令报文中出现一条或多条记录的“操作结果”为“模块正在退出”，请再次执行该命令。
- 该命令为CGPLite独有命令，只能启动部署了大颗粒的网元。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                        |
|:-------|:-------|:------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：用于唯一标识一个网元实例。 取值范围：5～1023。 默认值：无。 配置原则：无。 |

## 使用实例

部署Pod的场景下，启动一个网元下的所有模块，网元ID为6。执行如下命令：

`STR ME: MEID=6;`

```
%%STR ME: MEID=6;%%
RETCODE = 0  操作成功

Pod 操作结果如下
------------------

 Pod001       10.16.20.18  1002        CCU       操作成功
 Pod001       10.16.20.18  1003        CCU       操作成功
(结果个数 = 3)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释             |
|:--------|:------------------|
| Pod名称   | 用于标识模块属于哪个Pod。    |
| 位置描述    | 用于标识模块所在Pod的位置信息。 |
| 业务模块号   | 用于标识业务模块号也即逻辑模块号。 |
| 模块描述    | 用于标识主机侧模块的描述信息。   |
| 操作结果    | 用于标识操作的结果。        |
