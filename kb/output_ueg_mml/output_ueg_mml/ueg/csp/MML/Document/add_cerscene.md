# 新增证书应用场景信息 (ADD CERSCENE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于新增一个证书应用场景配置信息。

**说明** 

该命令仅在非三方场景下支持。

该命令仅对部分网元生效，不支持的网元执行时会返回“519809 当前网元不支持此操作”错误码。

当前命令仅支持添加CA、Device场景。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                           |
|:-----------|:-------|:---------------------------------------------------------------------------------------------------------------|
| MEID       | 网元ID   | 可选必选说明：必选参数。 参数含义：网元ID。 取值范围：5~1023。 默认值：无。 配置原则：无。                                                            |
| SCENENAME  | 场景名称   | 可选必选说明：必选参数。 参数含义：证书应用场景名称。 取值范围：长度不超过200个字符，只能包含英文字符、数字、中划线和下划线，且只能以字母开头。 默认值：无。 配置原则：场景名称和证书组一对一绑定。          |
| CRTGRPNAME | 证书组名称  | 可选必选说明：必选参数。 参数含义：证书组名称。 取值范围：长度不超过32个字符，只能包含英文字符、数字、中划线和下划线，且只能以字母开头。 默认值：无。 配置原则：证书组名称区分大小写。                 |
| CRTGRPTYPE | 证书组类型  | 可选必选说明：必选参数。 参数含义：证书组类型。 取值范围： “CA(CA) ” ：根证书。“Device(Device)”：设备证书。“CA+Device(CA+Device)”：证书集。 默认值：无。 配置原则：无。 |
| SCENEDESC  | 场景描述   | 可选必选说明：必选参数。 参数含义：场景描述。 取值范围：长度不超过254个字符，只能包含中文字符、英文字符、数字、中划线和下划线。 默认值：无。 配置原则：无。                              |

## 使用实例

新增证书应用场景信息：

```
ADD CERSCENE: MEID=100, SCENENAME="testadd", CRTGRPNAME="testadd", CRTGRPTYPE=CA+Device, SCENEDESC="testadd";
```

```
%%ADD CERSCENE: MEID=100, SCENENAME="testadd", CRTGRPNAME="testadd", CRTGRPTYPE=CA+Device, SCENEDESC="testadd";%%
RETCODE = 0  操作成功

---    END
```
