# 查询网元导出信息(LST EXPINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查看由命令**EXP MES**导出的二进制类型文件的网元数据信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                       |
|:-------|:-------|:---------------------------------------------------------------------------|
| FNM    | 文件名    | 可选必选说明：可选参数。 参数含义：该参数用于指定需要查询的文件名。若不输入，则表示查询所有文件信息。 取值范围：无。 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询所有的网元导出信息：

   `LST EXPINFO:;`

   ```
   %%LST EXPINFO:;%%
   RETCODE = 0  操作成功

   结果如下：
   ----------
    文件名                             网元ID  网元类型  网元版本           工作区

    Exp_TabFile_20140507161041.tar.gz  0       CSP       V200R002C00SPC200  1     
    Exp_TabFile_20140507161041.tar.gz  5       MSOFTX    V200R006C01        1     
    Exp_TabFile_20140507161142.tar.gz  0       CSP       V200R002C00SPC200  1     
    Exp_TabFile_20140507161142.tar.gz  5       MSOFTX    V200R006C01        1     
   (结果个数 = 4)

   ---    END
   ```
2. 查询“文件名”为Exp\_TabFile\_20140507161041.tar.gz包含的网元导出信息：

   `LST EXPINFO: FNM="Exp_TabFile_20140507161041.tar.gz";`

   ```
   %%LST EXPINFO: FNM="Exp_TabFile_20140507161041.tar.gz";%%
   RETCODE = 0  操作成功

   结果如下：
   ----------
    文件名                             网元ID  网元类型  网元版本           工作区

    Exp_TabFile_20140507161041.tar.gz  0       CSP       V200R002C00SPC200  1     
    Exp_TabFile_20140507161041.tar.gz  5       MSOFTX    V200R006C01        1     
   (结果个数 = 2)

   ---    END
   ```

## 输出结果说明

| 输出项名称   | 输出项解释                 |
|:--------|:----------------------|
| 文件名     | 用于标识由命令EXP MES导出的文件名。 |
| 网元ID    | 用于标识当前文件名中包含的一个网元ID。  |
| 网元类型    | 用于标识当前网元的类型。          |
| 网元版本    | 用于标识当前网元的版本号。         |
| 工作区     | 用于标识当前网元的工作区。         |
