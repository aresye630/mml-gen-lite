# 查询备份模式(DSP BAKMODE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于请求系统显示除了PMU以外模块的备份状态。模块的备份信息包括模块所在平面号、备份状态、备份进度、备份时间和备份开关状态。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                      |
|:-------|:-------|:------------------------------------------------------------------------------------------|
| VMNAME | Pod名称  | 可选必选说明：可选参数 参数含义：用于请求系统显示哪个Pod上的模块的备份状态；若不输入，则表示所有的Pod。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。 |
| MEID   | 网元ID   | 可选必选说明：可选参数 参数含义：用于请求系统显示哪个网元模块的备份状态；若不输入，则表示所有的网元ID。 取值范围：0～1023 默认值：无。 配置原则：无。          |
| MN     | 模块号    | 可选必选说明：可选参数 参数含义：用于请求系统显示哪个模块的备份状态；若不输入，则表示所有的模块号。 取值范围：0～4294967294 默认值：无。 配置原则：无。       |

## 使用实例

1. 查询所有Pod上模块的备份状态信息：`DSP BAKMODE:;`

   ```

   RETCODE = 0  操作成功

   Pod模块备份状态信息
   ----------------------
    网元ID  模块号  Pod名称            位置描述     平面号  备份状态  备份进度(百分比)  备份时间(秒)  备份开关    

    5       1080    null_90_180_msx_LB_0  10.7.90.60   平面0   备份完成  100               47            备份开关打开
    5       1080    null_90_180_msx_LB_1  10.7.90.60   平面0   备份完成  100               47            备份开关打开
    5       1081    null_90_180_msx_LB_0  10.7.90.60   平面0   备份完成  100               44            备份开关打开
    5       1081    null_90_180_msx_LB_1  10.7.90.60   平面0   备份完成  100               44            备份开关打开
   (结果个数 = 4)

   ---    END
   ```
2. 查询“网元ID”为“5”，“模块号”为“1080”的模块的备份状态信息：

   `DSP BAKMODE: MEID=5, MN=1080;`

   ```
   %%DSP BAKMODE: MEID=5, MN=1080;%%
   RETCODE = 0  操作成功

   Pod模块备份状态信息
   ----------------------
    网元ID  模块号  Pod名称            位置描述     平面号  备份状态  备份进度(百分比)  备份时间(秒)  备份开关

    5       1080    null_90_180_msx_LB_1  10.7.90.60   平面0   备份完成  100               47            备份开关打开
   (结果个数 = 2)

   ---    END
   ```

## 输出结果说明

| 输出项名称     | 输出项解释                                                                                                                                                                           |
|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 网元ID      | 用于返回进程所属的网元ID。                                                                                                                                                                  |
| 模块号       | 用于返回该进程的模块号信息。如果业务模块是主备的，则有两个模块对应该模块号。                                                                                                                                          |
| Pod名称     | 用于标识服务实例对应Pod的名称。                                                                                                                                                               |
| 位置描述      | 用于返回模块所在的Pod的位置信息。                                                                                                                                                              |
| 平面号       | 用于返回模块所处的平面标识ID: “平面0”：模块平面标识ID为平面0。“平面1”：模块平面标识ID为平面1。“平面2”：模块平面标识ID为平面2。                                                                                                      |
| 备份状态      | 用于返回模块的数据备份状态情况: “没有备份”：在未配置备用模块、备用模块故障、模块备份开关设置为关闭、主备模块的版本不一致无法启动备份时返回该状态。“正在备份”：正在备份数据时返回该状态。“备份完成”：完成数据备份后返回该状态。                                                             |
| 备份进度(百分比) | 用于返回模块间数据备份完成的百分比。                                                                                                                                                              |
| 备份时间(秒)   | 用于返回模块间数据备份完成所花费的时间，单位为秒。                                                                                                                                                       |
| 备份开关      | 用于指定是否在主备模块之间进行数据备份: “备份开关关闭”：设置模块的备份开关为关闭，主要应用在对模块进行补丁操作过程中，当补丁对模块数据备份结构发生变化时，需要将主模块的备份开关关闭，然后执行相关的补丁操作。“备份开关打开”：当模块在未设置备份开关前，备份开关一直为打开。当备用模块和主用模块之间数据需要保持一致时，需要将模块的备份开关设置为打开。 |
