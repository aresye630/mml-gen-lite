# 查询节点自动进入BYPASS开关（DSP BYPASSSWITCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**须知** 

该功能仅支持华为虚拟化层软件FusionSphere，不支持第三方虚拟化层软件。

本命令用于查询存储故障时，节点自动进入BYPASS开关的状态。

**说明** 

该命令仅在Full-stack虚机场景下支持。

#### 注意事项

无。

#### 参数说明

无。

#### 使用实例

1. 查询节点自动进入BYPASS开关，操作成功示例。

   ```
   %%DSP BYPASSSWITCH:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   节点名称  节点IP    节点自动进入BYPASS开关  

   10.0.0.1  10.0.0.1  开启                      
   10.0.0.2  10.0.0.2  开启                      
   10.0.0.3  10.0.0.3  开启                      
   (结果个数 = 3)

   ---    END
   ```
2. 查询节点自动进入BYPASS开关，部分成功示例。

   ```
   %%DSP BYPASSSWITCH:;%%
   RETCODE = 130004  部分成功

   操作结果如下
   ------------
   节点名称  节点IP    节点自动进入BYPASS开关  

   10.0.0.1  10.0.0.1  未知                 
   10.0.0.2  10.0.0.2  开启                      
   10.0.0.2  10.0.0.3  开启                      
   (结果个数 = 3)

   ---    END
   ```

#### 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。输出结果说明如表1所示。

命令执行异常，会返回提示对应的失败信息。错误码列表如表2所示。

| 输出项名称          | 输出项解释                                                                                                    |
|:---------------|:---------------------------------------------------------------------------------------------------------|
| 节点名称           | 用于返回节点名称。                                                                                                |
| 节点IP           | 用于返回节点IP地址。                                                                                              |
| 节点自动进入BYPASS开关 | 用于返回节点自动进入BYPASS开关状态。 取值范围： “开启”：节点自动进入BYPASS开关处于打开状态。“关闭”：节点自动进入BYPASS开关处于关闭状态。“未知”：查询节点自动进入BYPASS开关失败。 |

|    错误码 | 错误码解释   | 原因分析                    | 处理建议       |
|-------:|:--------|:------------------------|:-----------|
| 130002 | 操作失败    | 解析查询节点自动进入BYPASS开关参数失败。 | 请联系华为技术支持。 |
| 130004 | 部分成功    | 查询部分节点自动进入BYPASS开关失败。   | 请联系华为技术支持。 |
