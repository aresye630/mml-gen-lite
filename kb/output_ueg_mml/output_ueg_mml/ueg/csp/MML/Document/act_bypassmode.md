## 命令功能

**须知** 

降低磁盘故障引起业务完全不可用的风险。

该功能仅支持华为虚拟化层软件FusionSphere，不支持第三方虚拟化层软件。

BYPASS是将操作系统以及关键服务运行在指定的存储模式（存储模式由“BYPASS模式”开关控制）中的一种方案，激活BYPASS模式，下次重启会按照BYPASS要求将操作系统以及关键服务运行在指定的存储模式中。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

- 该命令仅限admin用户可以执行。
- 网元ID配置为0时，如果执行**DSP BYPASSMODE**命令查询“BYPASS模式”为“MemoryDiskMode”，则不支持执行**ACT BYPASSMODE**命令修改为“None”。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                              |
|:-----------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID       | 网元ID     | 可选必选说明：必选参数。 参数含义：用于指示系统需要修改指定网元ID下的节点数据。 取值范围：0～65535。 默认值：无。 配置原则：网元ID可以通过执行LST ME查询。                                                           |
| BYPASSMODE | BYPASS模式 | 可选必选说明：必选参数。 参数含义：标识是否激活指定网元的BYPASS的模式。 取值范围： “None（默认模式）”：不激活BYPASS模式，业务运行在系统创建时的存储中。“MemoryDiskMode（内存模式）”：激活BYPASS模式，业务运行在内存盘中。 默认值：无。 配置原则：无。 |

## 使用实例

```
%%ACT BYPASSMODE: MEID=0, BYPASSMODE=None;%%
RETCODE = 0  操作成功
操作结果如下
------------
网元ID  节点IP            结果  
0       10.0.0.3          成功
0       10.0.0.2          成功
0       10.0.0.1          成功
(结果个数 = 3)
---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。输出结果说明如表1 所示。

命令执行异常，请联系华为技术支持处理。输出结果说明如表2 所示。

| 输出项名称   | 输出项解释                                                                                                                    |
|:--------|:-------------------------------------------------------------------------------------------------------------------------|
| 网元ID    | 节点所属的网元ID。                                                                                                               |
| 节点IP    | 节点网络地址。                                                                                                                  |
| 结果      | 用于标识下次重启操作系统是否成功运行在指定的存储模式中 成功失败不支持：在thinpool磁盘缩减或者已被创建为逻辑卷（LV）使用或者容器引擎为containerd的节点，执行该命令且BYPASSMODE参数为None时，会返回"不支持"。 |

|    错误码 | 错误码解释     | 原因分析                    | 处理建议         |
|-------:|:----------|:------------------------|:-------------|
| 130013 | 操作失败      | 内部执行报错。                 | 请联系华为技术支持。   |
| 130014 | 未知操作      | 不识别对应MML命令。             | 检查MML名称是否正确。 |
| 130015 | 没有符合条件的节点 | 没有网元ID对应的节点。            | 请检查网元是否正确。   |
| 130016 | 参数不合法     | 参数校验失败。                 | 请检查参数是否标准。   |
| 130018 | 不支持此功能。   | 第三方虚拟化层不支持激活节点BYPASS模式。 | 请联系华为技术支持。   |
| 131501 | 部分成功      | 部分节点操作失败。               | 请联系华为技术支持。   |
