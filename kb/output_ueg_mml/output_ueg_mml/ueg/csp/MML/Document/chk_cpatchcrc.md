# 校验冷补丁程序CRC(CHK CPATCHCRC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于校验安装过冷补丁的进程文件或已安装的补丁版本在节点侧与OMU侧是否一致。默认检查上一次记录不一致的模块， 当选择所有模块时，将会重新检查系统中记录的上一次打过冷补丁的模块。

该命令仅适用于维护场景，当安装完冷补丁后，可以使用本命令进行检查。

## 注意事项

- 只有冷补丁包含了需要替换节点进程文件的内容时，才需要执行该命令。
- 当检查结果中发现有模块不一致时，可以执行**SYN CPATCH**同步。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                             |
|:---------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID     | 网元ID   | 可选必选说明：必选参数。 参数含义：标识一个补丁操作的关键字段之一，用于请求系统需要对哪一个网元实例实施操作。 取值范围： 5～1023。 默认值： 无。 配置原则：无。                                                                                            |
| CHKRANGE | 检查范围   | 可选必选说明：必选参数。 参数含义：用于设置CRC检查的范围，其值域类型为枚举类型。 取值范围：“ALL(所有打过冷补丁的模块)”：检查本次打过冷补丁的所有模块，无论之前的检查结果是否一致。“LAST(上一次CRC不一致的模块)”：只检查本次打过冷补丁的模块中CRC校验不一致的模块。 默认值：“LAST(上一次CRC不一致的模块)”。 配置原则：无。 |

## 使用实例

1. 校验冷补丁程序CRC，设置“网元ID”为“10”；

   `CHK CPATCHCRC: MEID=10;`

   ```
   %%CHK CPATCHCRC: MEID=10;%%
   RETCODE = 0  操作成功

   Pod程序文件CRC校验信息
   -------------------------
    模块号  模块类型  Pod名称  位置描述       校验结果标记   

    100     CCU       pod1     192.168.156.12    程序文件CRC一致
    100     CCU       pod2     192.168.156.12    程序文件CRC一致
   (结果个数 = 2)

   共有3个报告
   ---    END
   ```
2. 校验冷补丁版本（适用于SPG等网元），设置“网元ID”为“20”；

   `CHK CPATCHCRC: MEID=20;`

   ```
   %%CHK CPATCHCRC: MEID=20;%%
   RETCODE = 0  操作成功

   Pod冷补丁版本校验信息
   ------------------------
    Pod名称  位置描述      网元侧补丁  OMU侧补丁  检查结果     

    pod1       192.168.156.12   SPC003      SPC003     校验一致
    pod2       192.168.156.12   SPC003      SPC003     校验一致
   (结果个数 = 2)

   共有3个报告
   ---    END
   ```
3. 校验冷补丁版本（适用于OMP9360等网元），设置“网元ID”为“30”；

   `CHK CPATCHCRC: MEID=30;`

   ```
   %%CHK CPATCHCRC: MEID=30;%%
   RETCODE = 0  操作成功

   Pod冷补丁版本校验信息
   ------------------------
    Pod名称  位置描述      网元侧补丁  OMU侧补丁  检查结果     

    pod3       192.168.156.10   SPC001      SPC001     校验一致
    pod4       192.168.156.10   SPC001      SPC001     校验一致

   Pod程序文件CRC校验信息
   -------------------------
    模块号  模块类型  Pod名称  位置描述       校验结果标记   

    1100     CCU       pod3     192.168.156.10    程序文件CRC一致
    1100     CCU       pod4     192.168.156.10    程序文件CRC一致
   (结果个数 = 2)

   共有4个报告
   ---    END
   ```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                                                                                             |
|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 模块号     | 该参数标识了所加载冷补丁的模块号。                                                                                                                                                                                 |
| 模块类型    | 该参数标识了所加载冷补丁的模块类型。                                                                                                                                                                                |
| Pod名称   | 该参数标识了模块所处的Pod名称信息。                                                                                                                                                                               |
| 位置描述    | 该参数标识了模块所处的Pod位置描述信息。                                                                                                                                                                             |
| 网元侧补丁   | 该参数标识了网元侧补丁版本。                                                                                                                                                                                    |
| OMU侧补丁  | 该参数标识了OMU侧补丁版本。                                                                                                                                                                                   |
| 校验结果标记  | 用于指定前后台进程文件CRC校验结果。 取值说明： “程序文件CRC一致”：表示冷补丁安装完成。“程序文件CRC不一致”：表示冷补丁暂未安装完成。等待安装完毕后再进行检查，如果仍出现不一致，可以执行SYN CPATCH同步。若问题还存在，请联系华为技术支持处理。“程序文件CRC校验失败”：表示此时存在模块异常，请查看告警并消除。“进程未响应”：表示此时存在模块异常，请查看告警并消除。 |
| 检查结果    | 用于指定前后台补丁版本号的校验结果。 取值说明： “校验一致”：表示冷补丁已经安装完成。“校验不一致”：表示冷补丁安装暂未完成。等待安装完毕后再进行检查。若问题还存在，请联系华为技术支持处理。“校验失败”：表示存在模块异常，请查看告警并消除。“网元版本不一致”：表示冷补丁安装存在异常，请联系华为技术支持处理。“OMU侧补丁包不存在”：表示冷补丁安装存在异常，请联系华为技术支持处理。  |
