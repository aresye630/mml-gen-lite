# 查询通信质量采集参数(LST COLPARA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询通信质量采集参数，包括“RPTPERIOD(采样周期)”。

- 若需要查询所有的通信质量采集参数，请不要输入任何参数。
- 若需要查询某一项通信质量采集参数，请选择相应的“参数类型”参数。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                        |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------------|
| COMMPARA | 参数类型   | 可选必选说明：必选参数。 参数含义：用于指示系统需要按照哪种参数类型来查询通信质量采集参数；若不输入，则表示查询所有的通信质量采集参数。 取值范围：“RPTPERIOD(采样周期)”：用于查询系统的通信质量采样周期。 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询所有的通信质量采集参数：

   `LST COLPARA:;`

   ```
   %%LST COLPARA:;%%
   RETCODE = 0  操作成功

   网络质量诊断采样周期
   ------------
   探测周期(秒)  =  60
   (结果个数 = 1)

   ---    END
   ```
2. 查询采样周期：

   `LST COLPARA: COMMPARA=RPTPERIOD;`

   ```
   %%LST COLPARA: COMMPARA=RPTPERIOD;%%
   RETCODE = 0  操作成功

   网络质量诊断采样周期
   ------------
   探测周期(秒)  =  60
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

| 输出项名称   | 输出项解释                 |
|:--------|:----------------------|
| 探测周期(秒) | 用于返回通信质量诊断的采样周期，单位为秒。 |
