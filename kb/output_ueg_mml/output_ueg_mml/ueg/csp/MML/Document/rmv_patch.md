# 删除补丁(RMV PATCH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令执行之后，将使相应网元模块的补丁不可用，从而会中断该补丁所涉及的业务，影响整个系统的正常运行，请慎重使用。

该命令用于请求系统对指定的模块执行删除补丁操作。命令运行成功后指定的模块下所有的补丁全部被删除，补丁状态变为空闲态。

该命令的使用场景为：

- 系统正在运行的补丁已不再需要。
- 操作员使用**LOD PATCH**命令加载了错误的补丁，需要删除后加载正确补丁。

## 注意事项

- 可以使用该命令删除处于去激活、激活、运行状态的补丁。
- 删除补丁数据将使相应网元模块的补丁不可用，从而会中断该补丁所涉及的业务，影响整个系统的正常运行。请在执行该操作前仔细确认任务的必须性，建议在华为技术支持指导下在业务量小时执行。
- 当选择强制删除补丁时，不论节点返回成功与否，都将omu侧的补丁信息删除。
- 如果操作结果返回的不是“成功”，请参考输出结果说明中“操作结果”的描述进行处理。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：标识一个补丁操作的关键字段，用于请求系统需要对哪一个网元实例实施操作。 取值范围： 0～1023 默认值： 无。 配置原则：操作员可以通过LST ME命令查询获得。                                                                |
| MN     | 模块号    | 可选必选说明：可选参数。 参数含义：用于请求系统需要对指定网元下哪一个模块实施操作。 取值范围：0～4294967294 默认值：无。 配置原则：操作员可以通过在网元ID指定的网元实例上使用LST MODULE命令查询获得。如果不输入模块号，表示对整个网元下所有相应的模块删除补丁操作，缺省为对指定网元下所有模块实施补丁操作。 |
| AS     | 主备标记   | 可选必选说明：可选参数。 参数含义：用于请求系统需要对指定模块的主或备模块实施补丁操作。缺省为对主、备模块都实施补丁操作。 取值范围： “ACTIVE(主)”“STANDBY(备)” 默认值：无。 配置原则：无。                                                          |
| FORCE  | 强制删除补丁 | 可选必选说明：可选参数。 参数含义：用于指定是否强制删除OMU侧补丁信息。 取值范围： “NO(否)”：系统不强制删除OMU侧补丁信息。“YES(是)”：系统强制删除OMU侧补丁信息。 默认值：“NO(否)”。 配置原则：无。                                                   |

## 使用实例

1. 删除补丁：“网元ID”为“0”：

   `RMV PATCH: MEID=0, FORCE=YES;`

   ```
   %%RMV PATCH: MEID=0, FORCE=YES;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
     网元ID  =  0
     模块号  =  3017
   主备标记  =  主
   补丁名称  =  SPH002
   补丁状态  =  空闲
   操作结果  =  成功
   (结果个数 = 1)

   ---    END
   ```
2. 删除补丁：“网元ID”为“5”，“主备标志”为“主”：

   `RMV PATCH: MEID=5, AS=ACTIVE, FORCE=YES;`

   ```
   %%RMV PATCH: MEID=5, AS=ACTIVE, FORCE=YES;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
     网元ID  =  5
     模块号  =  1000
   主备标记  =  主
   补丁名称  =  SPH001
   补丁状态  =  空闲
   操作结果  =  成功
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                  |
|:--------|:-------------------------------------------------------------------------------------------------------|
| 网元ID    | 标识执行补丁删除操作的网元ID。                                                                                       |
| 模块号     | 标识执行补丁删除操作的模块号。                                                                                        |
| 主备标记    | 该参数标识执行补丁操作的模块状态。 取值说明： “ACTIVE(主)”“STANDBY(备)”                                                        |
| 补丁名称    | 标识补丁操作的关键字段之一，命名规则是SPHXXX或HPXXXX，其中SPHXXX表示热补丁，HPXXXX表示紧急热补丁。                                          |
| 补丁状态    | 补丁操作的结果信息之一，用于表示补丁单元的运行状态。 取值说明： “运行”：表示补丁安装成功。“激活”：表示补丁安装过程中的中间状态。“去激活”：表示补丁安装过程中的中间状态。“空闲”：表示没有安装补丁。 |
| 操作结果    | 用于描述执行补丁删除操作的返回结果。RMV PATCH强制删除补丁，永久返回“成功”。                                                            |
