## 命令功能

本命令用于备份CGPLite的数据库数据和CGPLite系统文件（数据库数据包括：配置数据、告警数据、性能数据；文件包括：程序文件、配置文件）。备份文件存放位置取决于备份类型：本地磁盘备份时，备份文件保存在CGPLite上；网络磁盘备份时，备份文件存放于备份服务器的目标目录下。

本命令的使用场景为：在系统升级或进行大批量数据配置前可以执行该命令先对CGPLite数据进行备份。

**须知** 

根据备份数据大小，此命令执行时间可能会超过十分钟，备份类型选择为“NET(网络磁盘)”时，协议类型中FTP是不安全协议，建议选择FTPS或者SFTP协议。请务必在华为技术支持人员的指导下使用该命令！

## 注意事项

- 备份服务器可以通过OMU浮动IP和OMU进行对接，备份服务器一般为网管备份服务器。“备份”目录可保存7份本地备份文件。手工备份时，如果同一天备份了多次，系统只保存当天最晚时间（即最新）的备份文件，覆盖同一天备份的文件。当备份文件超过7份时，自动覆盖生成时间最早的备份文件。
- 升级观察期内或剩余磁盘空间小于10G时，“备份”目录可保存本地备份文件最大个数为2。
- 基础备份只支持一键式WEBUI恢复。
- 备份文件中会记录网元的CRC校验结果，备份时备份文件中记录的CRC校验结果有可能和当前系统的校验结果不一致。因此在执行备份命令前，建议在OM Portal的每个网元下都执行一次**STR CRC: CRCTYPE=ALL;**命令，保证备份文件中记录的CRC校验结果和当前系统一致。
- 如果在执行本命令期间执行系统扩容部署、**ADD ME**命令或者**RMV ME**命令，则不归档备份包文件。请在系统扩容部署、**ADD ME**命令或者**RMV ME**命令执行完毕后，重新执行本命令。
- OMU作为FTP客户端连接FTP服务端时，默认使用“FTPS”协议。使用“FTP”协议存在安全风险，建议使用默认的“FTPS”协议或“SFTP”协议。

## 参数说明

| 参数标识         | 参数名称       | 参数说明                                                                                                                                                                                               |
|:-------------|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| BKTYPE       | 备份类型       | 可选必选说明：必选参数。 参数含义：用于标识备份系统的备份类型，包括本地磁盘备份和网络磁盘备份。 取值范围： “LOCAL(本地磁盘)”：备份数据库和文件到本地备份目录。“NET(网络磁盘)”：备份数据库和文件，并通过SFTP上传到备份服务器目标目录。 默认值：无。 配置原则：无。                                                      |
| BKCON        | 备份内容       | 可选必选说明：可选参数。 参数含义：用于标识系统备份的内容。备份类型选择为“LOCAL(本地磁盘)”时有效，若不输入，则表示备份所有的数据库和文件。 取值范围： “ALL(数据库和文件)”：同时备份数据库和文件。“DB(数据库)”：仅备份数据库，包括：配置数据告警数据性能数据 “FILE(文件)”：仅备份文件，包括：程序文件配置文件 默认值：“ALL(数据库和文件)”。 配置原则：无。 |
| PRTL         | 协议类型       | 可选必选说明：可选参数。 参数含义：用于指定备份服务器使用的FTP协议。备份类型选择为“NET(网络磁盘)”时有效。不输入时使用系统默认SFTP协议。 取值范围：无。 默认值：无。 配置原则：无。                                                                                                 |
| IPTYPE       | IP版本       | 可选必选说明：必选参数。 参数含义：用于指定备份服务器使用的IP版本。仅当本命令中的“备份类型”参数为“NET(网络磁盘)”时该参数有效。 取值范围： “IPV4(IPv4版本)”：IPv4地址类型。“IPV6(IPv6版本)”：IPv6地址类型。 默认值：“IPV4(IPv4版本)”。 配置原则：无。                                           |
| BKSERVERIP   | FTP服务器IP地址 | 可选必选说明：必选参数。 参数含义：用于标识备份服务器的IP地址。仅当本命令中的“IP版本”参数为“IPV4(IPv4版本)”时该参数可支持输入IPv4格式的备份服务器的IP地址。 取值范围：无。 默认值：无。 配置原则：无。                                                                                  |
| BKSERVERV6IP | FTP服务器IP地址 | 可选必选说明：必选参数。 参数含义：用于标识备份服务器的IP地址。仅当本命令中的“IP版本”参数为“IPV6(IPv6版本)”时该参数可支持输入IPv6格式的备份服务器的IP地址。 取值范围：无。 默认值：无。 配置原则：无。                                                                                  |
| PORT         | FTP服务器端口号  | 可选必选说明：必选参数。 参数含义：用于标识备份服务器的端口号。备份类型选择为“NET(网络磁盘)”时有效。 取值范围：无。 默认值：无。 配置原则：无。                                                                                                                      |
| FTPUSER      | FTP用户名     | 可选必选说明：必选参数。 参数含义：用于标识备份服务器的SFTP用户名。备份类型选择为“NET(网络磁盘)”时有效。 取值范围：无。 默认值：无。 配置原则：无。                                                                                                                  |
| FTPPSSWD     | FTP密码      | 可选必选说明：必选参数。 参数含义：用于标识备份服务器的FTP密码。备份类型选择为“NET(网络磁盘)”时有效。 取值范围：无。 默认值：无。 配置原则: 密码不能为空。 密码不支持中文字符。 密码区分大小写。 密码中不能含字符串：“%%”、“+++”、连续两个或者两个以上空格。 密码中不能包含英文分号、英文单引号和双引号、英文逗号、英文反斜杠和英文等号。                |
| BKPATH       | 目标目录       | 可选必选说明：必选参数。 参数含义：用于标识备份到服务器上的目标路径。备份类型选择为“NET(网络磁盘)”时有效。 取值范围：无。 默认值：无。 配置原则：无。                                                                                                                   |
| BKPITEM      | 自定义备份内容    | 可选必选说明：必选参数。 参数含义：用于标识自定义备份内容。备份类型选择为“NET(网络磁盘)”时有效。 取值范围： “BASE(基础备份)”：备份内容包括：配置数据告警数据配置文件 “ALL(全备份)”：同时备份数据库和文件 默认值：“ALL(全备份)”。 配置原则：无。                                                          |

## 使用实例

备份数据库和文件到网络磁盘，其中“备份类型”是网络磁盘，“协议类型”是FTP，“IP版本”是IPV4，“FTP服务器IP地址”是10.1.3.5，“FTP服务器端口号”是21，“FTP用户名”是omu，“FTP密码”是\*\*\*\*\*\*\*，“目标目录”是/opt/backup：

`BKP SYS: BKTYPE=NET, PRTL=FTP, IPTYPE=IPV4, BKSERVERIP="10.1.3.5", PORT=21, FTPUSER="omu", FTPPSSWD="*******", BKPATH="/opt/backup";`
