# 设置时区和夏令时(SET LITETZ)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令执行之后，如果时间设置错误会导致计费时间错乱，系统瘫痪，请慎重使用。

本命令用于设置时区和夏令时信息。

本命令的使用场景为：当设备所在的国家或地区实行夏令时制度时，为确保时间信息的准确性，操作员应使用本命令配置夏令时的自动调整参数，主要包括夏令时的开始时间、结束时间、时间偏移量等参数。

## 注意事项

- 修改时区和夏令时是重大的操作，会影响系统时间，从而影响话务统计、告警、日志等数据记录中时间信息的准确性，因此操作员要根据当地时区夏令时信息准确配置。在缺省的情况下，系统在初始化的时候已经在配置数据库中预置了时区夏令时信息，这些数据可以使用**LST TZ**命令查询得到。
- 夏令时开始日期不能设置为1月1日或2月29日。
- 夏令时结束日期不能设置为1月1日或2月29日。
- 本命令可以用来修改时区和夏令时信息，但夏令时期间，夏令时的配置不允许修改。
- 目前夏令时有两个国际标准，美洲标准和欧洲标准，这两个标准关于夏令时结束时间的表示方法是不同的：美洲标准，以当地时区时间作为夏令时结束时间；而欧洲标准，是以夏令时时间作为结束时间。
- 当前系统是以欧洲标准实现，请按照欧洲标准对夏令时的结束时间做相应的调整。

## 使用实例

1. 设置时区为GMT +01:00，且使用夏令时，夏令时开始及结束时间点的时间调整量为1个小时。每年从3月最后一个星期日的02:00:00开始跳变至03:00:00，进入夏令时，在10月最后一个星期日从03:00:00跳变至02:00:00，结束夏令时：

   `SET LITETZ:TZONE="E0100(GMT+01:00)",DST=YES,SM=WEEK,SMONTH=MAR,SWSEQ=LAST,SWEEK=SUN,ST=02&00&00,EM=WEEK,EMONTH=OCT,EWSEQ=LAST,EWEEK=SUN,ET=03&00&00,TO=60;`
2. 设置时区为东8时区，没有夏令时的配置信息：

   `SET LITETZ: TZONE="E0800", DST=NO;`
3. 使用手工输入方式设置时区，输入格式为简写格式，设置时区为东8:10时区，没有夏令时的配置信息：

   `SET TZ: TZONE="E0810", DST=NO;`
4. 使用手工输入方式设置时区，输入格式为完整格式，设置时区为东8:10时区，没有夏令时的配置信息：

   `SET TZ: TZONE="E0810(GMT+08:10)", DST=NO;`
