# 导出MML文件(EXP LITEMML)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于从CGPLite服务中以MML格式导出对象的配置数据。

**须知** 

本命令执行时间较长，导出类型选择为“NET(网络磁盘)”时，协议类型中FTP是不安全协议，建议选择“FTPS”或者“SFTP”协议，请务必在华为技术支持人员的指导下操作。

## 注意事项

- 本命令不支持SGSN、USN、eCNS、TSN和UIC网元，此类网元的导出请使用对应网元下的**EXP MMLEX**命令。
- 用户选择网络磁盘通过第三方FTP服务器传输配置数据文件到外部服务器时，如果网元名称含有中文字符，可能会出现导出的文件名中出现异常字符。这可能是第三方FTP服务器不支持linux系统下的中文向Windows系统下中文的转换，重命名文件即可。
- OMU作为FTP客户端连接FTP服务端时，默认使用“FTPS”协议。使用“FTP”协议存在安全风险，建议使用默认的“FTPS”协议或“SFTP”协议。

## 使用实例

导出MML数据：“网元ID”为“1023”，“网元类型”为“MSOFTX”，“导出类型”是网络磁盘，“协议类型”是“FTP”， “FTP服务器IP地址” 是“10.144.242.199”，“FTP服务器端口号”是“21”， “FTP用户名”是“omu”，“FTP密码”是“\*\*\*\*\*\*\*”，“目标目录”是“/opt”，“导出文件名称”是“Example”，“是否覆盖”是“YES(是)”，则运行以下命令：

`EXP LITEMML: MEID=1023, METYPE=MSOFTX, CF=COMPRESSED, EXPTYPE=NET, PRTL=FTP, IPTYPE=IPV4, BKSERVERIP="10.144.242.199", PORT=21, FTPUSER="omu", FTPPSSWD="******", BKPATH="/opt", FNM="Example", CVF=YES;`
