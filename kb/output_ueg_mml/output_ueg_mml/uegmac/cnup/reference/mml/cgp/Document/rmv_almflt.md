# 手工清除告警(RMV ALMFLT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于对指定的告警执行恢复操作。

## 注意事项

- 在手动清除告警时，系统自动产生此条告警的恢复告警，恢复时间是系统的当前时间，恢复状态为手动恢复，系统记录自动产生的恢复告警，并将恢复告警上报客户端。
- 如果系统存在公共服务，并且网元集成了公共服务的清除活动告警命令（如：VNFC-M与VNRS\_VNFC类型为**RTR ACTIVEALARM**，CSLB\_VNFC类型为**RTR ACTIVEALARMLB**，CSDB\_VNFC类型为**RTR ACTIVEALARMDB**），执行此命令会同时恢复公共服务下对应的活动告警。
- 在手动清除告警后，告警源必须重新上报告警才能在告警台呈现该告警。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                         |
|:-------|:-------|:---------------------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：标识一条活动告警数据记录的关键字段之一，用于指定需要清除哪个网元的数据记录。 取值范围：0～1023 默认值：无。 配置原则：无。          |
| SN     | 告警流水号  | 可选必选说明：必选参数。 参数含义：标识一条活动告警数据记录的关键字段之一，用于指定需要清除哪一条活动告警的数据记录。 取值范围：1～2147483646 默认值：无。 配置原则：无。 |

## 使用实例

手动清除告警，“网元ID”为“5”，“告警流水号”为“2”：

`RMV ALMFLT: MEID=5, SN=2;`
