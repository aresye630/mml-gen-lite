# 查询告警日志(LST ALMLOG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询告警日志信息：

- 若需要查询全部告警日志的概要信息，请不要输入任何参数。
- 若需要查询某条告警日志的详细信息，请输入“事件类型”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个网元来查询告警日志；若不输入，则表示所有网元。 取值范围：0～1023 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                  |

| MN     | 模块号    | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个模块号来查询告警日志信息；若不输入，则表示所有的模块号。 查询OMU进程的告警日志时，该参数统一填写为0。 取值范围：0～4294967294 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                              |
| SS     | 起始流水号  | 可选必选说明：可选参数。 参数含义：用于指示系统查询告警日志时流水号的取值下限；若不输入，则表示没有下限。流水号：是在一个网元内对故障告警进行的编号，恢复告警的流水号与其对应的故障告警流水号相同 取值范围：1～2147483646 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                |
| ES     | 结束流水号  | 可选必选说明：可选参数。 参数含义：用于指示系统查询告警日志时流水号的取值上限；若不输入，则表示没有上限。 取值范围：1～2147483646 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                            |
| SAID   | 起始告警ID | 可选必选说明：可选参数。 参数含义：用于指示系统查询告警日志时告警ID的取值下限；若不输入，则表示没有下限。告警ID：用于确定一类告警，代表一种特定的故障，是告警项的唯一索引。 取值范围：1～200000 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                             |
| EAID   | 结束告警ID | 可选必选说明：可选参数。 参数含义：用于指示系统查询告警日志时告警ID的取值上限；若不输入，则表示没有上限。 取值范围：1～200000 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                               |
| ALVL   | 告警级别   | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个告警级别来查询告警日志；若不输入，则表示所有告警级别。 取值范围：紧急告警：此类级别的故障影响到系统提供的服务，需要立即采取相应动作。如某设备或资源完全不可用，需进行恢复，即使该故障在非工作时间内发生，也需立即采取措施。重要告警：此类级别的故障影响到服务质量，需要采取紧急动作。如某设备或资源服务质量下降，需对其进行还原，恢复全部能力，需在工作时间内立即采取措施。次要告警：此类级别的故障还未影响到服务质量，但为了避免更严重的故障，需要在适当时候进行处理或进一步观察。提示告警：此类级别的故障指示可能有潜在的错误影响到提供的服务，相应的措施根据不同的错误进行处理。 默认值：无。 配置原则：无。                                                                                                                           |
| ET     | 事件类型   | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个事件类型来查询告警日志；若不输入，则表示所有事件类型。事件类型：是对告警的一种基本分类，用来表明承载告警的事件报告类型。 取值范围： “电源系统”：有关电源系统的告警（直流-48V）。“环境系统”：有关机房环境（温度、湿度、门禁等）的告警。“信令系统”：有关随路信令（一号）和共路信令（七号）等告警。“中继系统”：有关中继电路及中继板的告警。“硬件系统”：有关硬件设备的告警（如时钟、CPU等）。“软件系统”：有关软件方面的告警。“运行系统”：系统运行时产生的告警。“通信系统”：有关通信系统的告警（如前后台通信）。“业务质量”：有关服务质量的告警。“处理出错”：其他异常情况告警。“完整性违背”：有关系统中数据被修改错误或删除的告警。“操作违背”：有关非法操作的告警。“物理违背”：有关物理设备被非法操作的告警。“安全违背”：被安全模块发现的安全相关的告警。“时间域违背”：有关在非法时间下执行操作的告警。 默认值：无。 配置原则：无。 |
| SGT    | 起始时间   | 可选必选说明：可选参数。 参数含义：用于指示系统查询告警日志时告警产生时间的取值下限；若不输入，则表示没有下限。告警产生时间：表示被管对象产生该告警的时间。 取值范围：无。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                             |
| EGT    | 结束时间   | 可选必选说明：可选参数。 参数含义：用于指示系统查询告警日志时告警产生时间的取值上限；若不输入，则表示没有上限。 取值范围：无。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                   |
| SSSN   | 起始同步号  | 可选必选说明：可选参数。 参数含义：用于指示系统查询告警日志时同步号的取值下限；若不输入，则表示没有下限。同步号：是在一个网元内对故障告警、清除告警进行的编号；从0开始，系统每产生一条告警，同步号加1，以此逐步递加。 取值范围：1～2147483646 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                     |
| ESSN   | 结束同步号  | 可选必选说明：可选参数。 参数含义：用于指示系统查询告警日志时同步号的取值上限；若不输入，则表示没有上限。 取值范围：1～2147483646 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                            |
| SRTORD | 排序顺序   | 可选必选说明：可选参数。 参数含义：用于指示系统查询告警日志时查询结果按照告警发生时间的顺序排列，包含升序和降序两类；若不输入，则表示对查询结果不排序。 取值范围：无。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                               |
| CNT    | 返回记录数  | 可选必选说明：可选参数。 参数含义：用于指示系统返回记录条数的最大值；若不输入，则表示返回记录的最大数目是64。 取值范围：1～1000 默认值：64。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                              |

## 使用实例

1. 查询所有的告警日志信息：

   `LST ALMLOG:;`

   ```
   %%LST ALMLOG:;%%
   RETCODE = 0  操作成功

   ALARM  3           故障-->恢复  次要        CSP       753           硬件系统          
              告警同步号  =  3
                告警名称  =  告警箱处于离线状态
            告警发生时间  =  2011-01-21 11:30:08+00:00
                定位信息  =  告警箱状态=离线
              可自动清除  =  是
                恢复类型  =  复位恢复
                恢复时间  =  2011-01-21 12:19:19+00:00
            父告警流水号  =  0
                  节点ID  =  0
                  模块号  =  0(OMU)
            重复告警次数  =  0

   (结果个数 = 1)

   统计信息
   --------
   符合查询条件的总记录数 = 1
           实际返回记录数 = 1
   (结果个数 = 1)

   ---    END
   ```
2. 查询告警日志信息，“告警清除标志”为“已清除”，“起始告警ID”为“753”，“结束告警ID”为“753”，“告警级别”为“次要告警”：

   `LST ALMLOG: CLRFLG=CLEARED, SAID=753, EAID=753, ALVL=CRITICAL-0&MAJOR-0&MINOR-1&WARNING-0;`


## 输出结果说明

| 输出项名称       | 输出项解释                              |
|:------------|:-----------------------------------|
| 告警同步号       | 每产生一个告警或恢复告警，系统会自动将该流水号递增，用于标识该告警。 |
| 告警名称        | 告警名称。                              |
| 告警发生时间      | 告警产生的时间。                           |
| 定位信息        | 告警产生的相关信息，方便维护人员定位告警源。             |
| 可自动清除       | 用于标识告警是否能由系统自动恢复还是需要手工恢复。          |
| 恢复类型        | 标识告警恢复的类型。                         |
| 恢复时间        | 告警恢复的时间。                           |
| 父告警流水号      | 该参数暂未使用。                           |
| 节点ID        | 产生告警的子网ID。                         |
| 模块号         | 产生告警的模块的编号，OMU进程的模块号统一显示为“0(OMU)”。 |
| 重复告警次数      | 告警重复的次数。                           |
| 符合查询条件的总记录数 | 符合查询条件的总记录数。                       |
| 实际返回记录数     | 实际返回记录数。                           |
