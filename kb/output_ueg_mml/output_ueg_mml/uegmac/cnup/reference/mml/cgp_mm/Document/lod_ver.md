# 数据同步(LOD VER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于业务网元的升级，将CSP所在Pod上高低版本的进程信息和数据文件预加载到业务网元所在Pod上。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                     |
|:------------|:-------|:-------------------------------------------------------------------------|
| DMID        | 域标识    | 可选必选说明：必选参数。 参数含义：用于唯一标识一个域。 取值范围：1 默认值：1。 配置原则：无。                       |
| SNID        | 子网标识   | 可选必选说明：必选参数。 参数含义：用于唯一标识一个域下的子网。 取值范围：0～255 默认值：0。 配置原则：无。               |
| MEID        | 网元ID   | 可选必选说明：必选参数。 参数含义：用于唯一标识指定的网元实例。 取值范围：5～1023 默认值：无。 配置原则：无。              |
| MEVER       | 网元的版本  | 可选必选说明：必选参数。 参数含义：用于标识一个网元实例的版本。 取值范围：无。 默认值：无。 配置原则：无。                  |
| ONEWKSPFLAG | 单工作区标识 | 可选必选说明：必选参数。 参数含义：用于标识是否是单工作区。 取值范围： “YES(是)”“NO(否)” 默认值：“NO(否)” 配置原则：无。 |

## 使用实例

将CSP所在Pod上高低版本的进程信息和数据文件加载到业务网元10的Pod上：

`LOD VER: MEID=10, MEVER="V200R006C88";`
