# 查询跨网元命令的操作记录(LST MCDLOG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询跨网元命令的操作记录。跨网元命令是指在网元下执行，会同时修改网元和CSP数据的命令。

该命令的使用场景为：升级回退时，用来查询是否执行过跨网元命令。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                            |
|:-------|:-------|:--------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：标识网元对象，用于指示系统需要查询哪一个网元下的跨网元命令操作记录。 取值范围：5～1023 默认值：无。 配置原则：无。 |

## 使用实例

查询“网元ID”为“5”的网元下的跨网元命令操作记录：

`LST MCDLOG: MEID=5;`

## 输出结果说明

| 输出项名称    | 输出项解释           |
|:---------|:----------------|
| 业务网元工作区数 | 标识业务网元的工作区数。    |
| CSP工作区数  | 标识CSP的工作区数。     |
| 操作时间     | 标识跨网元命令的执行时间。   |
| 操作描述     | 标识跨网元命令的具体命令信息。 |
