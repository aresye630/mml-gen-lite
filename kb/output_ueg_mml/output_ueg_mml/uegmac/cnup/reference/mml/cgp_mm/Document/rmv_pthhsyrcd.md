# 删除补丁记录(RMV PTHHSYRCD)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除补丁操作记录，仅在补丁回退过程中使用。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                       |
|:------------|:--------|:-----------------------------------------------------------|
| MEID        | 网元ID    | 可选必选说明：必选参数。 参数含义：用于唯一标识一个网元实例。 取值范围：0～1023 默认值：无。 配置原则：无。 |
| LOWHPTHVER  | 低热补丁包版本 | 可选必选说明：必选参数。 参数含义：用于标识低版本的热补丁。 取值范围：无。 默认值：无。 配置原则：无。      |
| HIGHCPTHVER | 高冷补丁包版本 | 可选必选说明：必选参数。 参数含义：用于标识高版本的冷补丁。 取值范围：无。 默认值：无。 配置原则：无。      |

## 使用实例

删除补丁操作记录：

`RMV PTHHSYRCD: MEID=0, LOWHPTHVER="SPC000", HIGHCPTHVER="SPH000";`
