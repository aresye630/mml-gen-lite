# 查询补丁回退版本(LST PTHRBKVER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询补丁回退的目标版本信息，仅在补丁回退过程中使用。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询补丁回退的目标版本信息：

`LST PTHRBKVER:;`

## 输出结果说明

| 输出项名称      | 输出项解释                       |
|:-----------|:----------------------------|
| 域标识        | 用于唯一标识一个域。此处域标识只能为1。        |
| 子网标识       | 用于唯一标识一个域下的子网。目前此处子网标识只能为0。 |
| 网元ID       | 用于唯一标识一个网元实例。               |
| 网元名称       | 用于标识网元。                     |
| 网元版本       | 用于标识网元当前的版本。                |
| 网元类型       | 用于标识网元的类型。                  |
| 网元锁定状态     | 用于标识网元的锁定状态。                |
| 工作区ID      | 用于标识当前工作区。                  |
| 高版本补丁      | 用于标识高版本补丁。                  |
| 高版本补丁内部版本号 | 用于标识高版本补丁的内部版本号。            |
| 高版本热补丁     | 用于标识高版本的热补丁。                |
| 高版本冷补丁     | 用于标识高版本的冷补丁。                |
| 低版本补丁      | 用于标识低版本补丁。                  |
| 低版本补丁内部版本号 | 用于标识低版本补丁的内部版本号。            |
| 低版本热补丁     | 用于标识低版本的热补丁。                |
| 低版本冷补丁     | 用于标识低版本的冷补丁。                |
