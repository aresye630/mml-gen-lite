# 增加Pod信息(ADD PODINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于添加Pod信息，是提供给MANO自动部署时添加Pod信息的命令接口。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称       | 参数说明                                                                                                                                                  |
|:--------------|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------|
| PODNAME       | Pod名称      | 可选必选说明：必选参数。 参数含义：用于指定需要增加的Pod名称，唯一标识一个Pod。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：该参数的值域范围为：大写字母“A～Z”、小写字母“a～z”、数字“0～9”、特殊字符“-”、“_”、“.”。该参数必须以字母开头。该参数区分大小写。 |
| PODLOC        | 节点名称       | 可选必选说明：必选参数。 参数含义：用于指定需要增加的Pod的节点名称。 取值范围：长度不超过60的字符串。 默认值：无。 配置原则：该参数的值域范围为：大写字母“A～Z”、小写字母“a～z”、数字“0～9”、特殊字符“-”、“_”、“.”。该参数区分大小写。                    |
| APPTYPE       | 应用类型       | 可选必选说明：必选参数。 参数含义：用于指定需要增加的Pod是哪种应用类型。 取值范围： “OMU”：表示主备OMU。 默认值：无。 配置原则：无。                                                                            |
| BASE1MAC      | Base1平面MAC | 可选必选说明：必选参数。 参数含义：用于指定需要增加的Pod的Base1的MAC地址信息。 取值范围：长度不超过60的字符串。 默认值：无。 配置原则：无。                                                                        |
| BASE2MAC      | Base2平面MAC | 可选必选说明：必选参数。 参数含义：用于指定需要增加的Pod的Base2的MAC地址信息。 取值范围：长度不超过60的字符串。 默认值：无。 配置原则：无。                                                                        |
| BASE1IP       | BASE1 IP   | 可选必选说明：必选参数。 参数含义：用于指定需要增加的Pod的BASE1的IP地址。 取值范围：无。 默认值：无。 配置原则：无。                                                                                     |
| BASE2IP       | BASE2 IP   | 可选必选说明：必选参数。 参数含义：用于指定需要增加的Pod的BASE2的IP地址。 取值范围：无。 默认值：无。 配置原则：无。                                                                                     |
| FABRIC1IP     | FABRIC1 IP | 可选必选说明：必选参数。 参数含义：用于指定需要增加的Pod的FABRIC1的IP地址。 取值范围：无。 默认值：无。 配置原则：无。                                                                                   |
| FABRIC2IP     | FABRIC2 IP | 可选必选说明：必选参数。 参数含义：用于指定需要增加的Pod的FABRIC2的IP地址。 取值范围：无。 默认值：无。 配置原则：无。                                                                                   |
| BASEPORTNUM   | BASE网口个数   | 可选必选说明：必选参数。 参数含义：用于指定需要增加的Pod的BASE网口个数。 取值范围：1～4。 默认值：2。 配置原则：无。                                                                                     |
| FABRICPORTNUM | FABRIC网口个数 | 可选必选说明：必选参数。 参数含义：用于指定需要增加的Pod的FABRIC网口个数。 取值范围：0~4。 默认值：2。 配置原则：无。                                                                                   |
| SIGNALPORTNUM | 信令网口个数     | 可选必选说明：必选参数。 参数含义：用于指定需要增加的Pod的信令网口个数。 取值范围：0~24。 默认值：0。 配置原则：无。                                                                                      |
| VNFID         | VNF ID     | 可选必选说明：必选参数。 参数含义：用于指定需要增加Pod的VNF ID。 取值范围：长度不超过64的字符串。 默认值：无。 配置原则：无。                                                                                |
| OSARCH        | 架构类型       | 可选必选说明：必选参数。 参数含义：用于指定需要增加的Pod的架构类型。 取值范围： “X86”“ARM” 默认值：无。 配置原则：无。                                                                                  |

## 使用实例

增加“Pod名称”为“VNF\_OMU\_0”，“节点名称”为“10.10.10.10”，“应用类型”为“CSP”，“Base1平面MAC”为“00:50:56:01:00:04”，“Base2平面MAC”为“00:50:56:01:00:45”，“BASE1 IP”为“10.16.128.1”，“BASE2 IP”为“10.16.136.2”，“FABRIC1 IP”为“10.16.144.1”，“FABRIC2 IP”为“10.16.152.2”，“BASE网口个数”为“2”，“FABRIC网口个数”为“2”，“信令网口个数”为“0”，“VNF ID”为“98ea39a390c8414fa8a5ab8a6f65b273”，“OSARCH”为“X86”的CSP的POD信息：

`ADD PODINFO: PODNAME="VNF_OMU_0", PODLOC="10.10.10.10", APPTYPE=CSP, BASE1MAC="00:50:56:01:00:04", BASE2MAC="00:50:56:01:00:45", BASE1IP="10.16.128.1", BASE2IP="10.16.136.2", FABRIC1IP="10.16.144.1", FABRIC2IP="10.16.152.2", BASEPORTNUM=2, FABRICPORTNUM=2, SIGNALPORTNUM=0, VNFID="98ea39a390c8414fa8a5ab8a6f65b273", OSARCH=X86;`
