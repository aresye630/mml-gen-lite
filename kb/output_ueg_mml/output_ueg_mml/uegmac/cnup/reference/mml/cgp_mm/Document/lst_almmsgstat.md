# 查询告警统计结果 (LST ALMMSGSTAT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询告警统计结果。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询告警统计结果：

`LST ALMMSGSTAT:;`

## 输出结果说明

| 输出项名称    | 输出项解释         |
|:---------|:--------------|
| 接收事件总数   | 用于表示接收事件总数。   |
| 入库事件总数   | 用于表示入库事件总数。   |
| 接收故障告警总数 | 用于表示接收故障告警总数。 |
| 入库故障告警总数 | 用于表示入库故障告警总数。 |
| 接收恢复告警总数 | 用于表示接收恢复告警总数。 |
| 入库恢复告警总数 | 用于表示入库恢复告警总数。 |
| 统计开始时间   | 用于表示统计开始时间。   |
| 统计结束时间   | 用于表示统计结束时间。   |
| 统计开关状态   | 用于表示统计开关状态。   |
