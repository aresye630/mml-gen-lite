# 向指定的ftp下载指定的介质包到omu(PUS PKG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于从远端服务器下载文件到CSP Pod的指定目录，并根据参数确定是否执行加载动作。

## 注意事项

需要自动加载的文件不需要指定文件传输的目标路径，或将目标路径参数指定为“/opt/pub/software/tmp/”。

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                                         |
|:-------|:-----------|:-------------------------------------------------------------------------------------------------------------|
| FNM    | 文件名称       | 可选必选说明：必选参数。 参数含义：用于指定需要传输的文件名称。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                                           |
| SRCF   | 源文件/目录     | 可选必选说明：可选参数。 参数含义：用于指定需要传输的文件在服务器上存放的源路径。 取值范围：长度不超过256的字符串。 默认值：无。 配置原则：若不输入，则通过系统配置自动选择。                   |
| DSTF   | 目标目录       | 可选必选说明：必选参数。 参数含义：用于指定需要传输的文件存放在CSP所在Pod上的路径。 取值范围：长度不超过256的字符串。 默认值：“/opt/pub/software/tmp/”。 配置原则：无。       |
| IP     | FTP服务器IP地址 | 可选必选说明：可选参数。 参数含义：用于指定需要传输的文件所在FTP服务器的IP地址，该IP地址只能输入点分十进制格式的IPV4地址。 取值范围：IP地址。 默认值：无。 配置原则：若不输入，则通过系统配置自动选择。 |
| PORT   | FTP服务器端口号  | 可选必选说明：可选参数。 参数含义：用于指定需要传输的文件所在FTP服务器的端口号。 取值范围：1～65535。 默认值：无。 配置原则：若不输入，则通过系统配置自动选择。                       |
| USR    | FTP用户名     | 可选必选说明：必选参数。 参数含义：用于指定FTP用户名，用户名是FTP传输时的重要参数，需要与FTP服务器协商一致；若不一致，文件上传会失败。 取值范围：长度不超过32个英文字符。 默认值：无。 配置原则：无。   |
| PWD    | FTP密码      | 可选必选说明：必选参数。 参数含义：用于指定FTP密码，密码是FTP传输时的重要参数，需要与FTP服务器协商一致；若不一致，文件上传会失败。 取值范围：长度不超过512个英文字符。 默认值：无。 配置原则：无。    |
| KEY    | FTP密钥      | 可选必选说明：可选参数。 参数含义：用于配合密码参数进行解密运算。 取值范围：长度不超过128个英文字符。 默认值：无。 配置原则：若不输入，则认为所输入的密码参数为明文，不进行解密动作。               |
| TYPR   | 包类型        | 可选必选说明：必选参数。 参数含义：用于指定所上传的文件包类型。 取值范围： “PKG（软件包）”：传输完成后自动执行加载动作。“OTHER（其他）”：传输完成后命令即执行完成。 默认值：“PKG”。 配置原则：无。 |

## 使用实例

推送包：“文件名称”为“MSOFTX\_SRV\_V200R006C01.tar”，“源文件/目录”为“/opt/pub/”，“目标目录”为“/opt/pub/software/tmp/”，“FTP服务器IP地址”为“192.168.156.12”，“FTP服务器端口号”为“22”，“FTP用户名”为“Admin”，“FTP密码”为“00000020F36B16931B8565524A23D7D26DB8355733377673F180EB8C9D8F65BF1D13105B”，“FTP密钥”为“E490D59B6B4EFBED3138A11C6CF6058AACEB1E2E3E4592DEEE5595E72181CAD2”，“包类型”为“PKG”的文件包:

`PUS PKG: FNM="MSOFTX_SRV_V200R006C01.tar", SRCF="/opt/pub/", DSTF="/opt/pub/software/tmp", IP="192.168.156.12", PORT=22, USR="Admin", PWD="************************************************************************", KEY="****************************************************************", TYPR=PKG;`
