# 查询目标版本(LST DSTVER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询补丁包或者维护功能包目标版本信息，仅在补丁检查和自定义工具操作过程中使用。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                       |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------|
| DSTTYPE | 目标版本类型 | 可选必选说明：必选参数。 参数含义：用于标识要查询的目标版本类型。 取值范围： “PREPTHVER(补丁前检查版本)”“MTVER(维护包版本)”“SOSVER(信息收集包版本)” 默认值：无。 配置原则：无。 |

## 使用实例

查询目标版本：维护包版本

`LST DSTVER: DSTTYPE=MTVER;`

## 输出结果说明

| 输出项名称   | 输出项解释                       |
|:--------|:----------------------------|
| 域标识     | 用于唯一标识一个域。此处域标识只能为1。        |
| 子网标识    | 用于唯一标识一个域下的子网。目前此处子网标识只能为0。 |
| 网元ID    | 用于唯一标识一个网元实例。               |
| 网元名称    | 用于标识网元。                     |
| 网元类型    | 用于标识网元的类型。                  |
| 网元版本    | 用于标识当前网元的版本。                |
| 工作区ID   | 用于标识当前的工作区。                 |
| 目标版本    | 用于标识目标版本。                   |
| 目标版本包名称 | 用于标识目标版本包。                  |
| 高版本热补丁  | 用于标识高版本的热补丁。                |
| 高版本冷补丁  | 用于标识高版本的冷补丁。                |
| 配置参数标志  | 用于标识配置参数。                   |
| 网元补丁版本  | 用于标识网元补丁的版本。                |
