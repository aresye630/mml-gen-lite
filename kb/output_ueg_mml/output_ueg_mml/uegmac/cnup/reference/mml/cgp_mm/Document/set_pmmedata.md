# 设置网元的性能管理数据(SET PMMEDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置网元的性能管理数据。

该命令的使用场景为：当网元升级完成后，调用该命令更新其性能管理数据。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------------------|
| MEID    | 网元ID   | 可选必选说明：必选参数。 参数含义：用于唯一标识一个网元实例。 取值范围：0～1023 默认值：无。 配置原则：无。                                                          |
| OPTYPE  | 操作类型   | 可选必选说明：可选参数。 参数含义：用于标识操作类型，不设表示没有操作，设为“1”时，表示刷新CGPLite内存中的对象名称信息，设为“2”时，表示重新加载网元的性能管理数据。取值范围：1～65535 默认值：无。 配置原则：无。 |
| RESERVE | 预留字段   | 可选必选说明：可选参数。 参数含义：该参数为预留参数，暂未使用。其值域类型为字符串。 取值范围：不超过128个英文字符。 默认值：无。 配置原则：无。                                         |

## 使用实例

重新加载网元性能管理数据，“网元ID”为“15”：

`SET PMMEDATA: MEID=15, OPTYPE=2;`
