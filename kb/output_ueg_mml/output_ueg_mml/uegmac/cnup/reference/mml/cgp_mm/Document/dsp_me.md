# 查询网元配置信息(DSP ME)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询网元对象实例的配置信息，是提供给网管的命令接口。

## 注意事项

无。

## 输出结果说明

| 输出项名称   | 输出项解释                                |
|:--------|:-------------------------------------|
| 域标识     | 用于唯一标识一个域。此处域标识只能为1。                 |
| 子网标识    | 用于唯一标识一个域下的子网。目前此处子网标识只能为0           |
| 网元ID    | 用于标识查询到的网元ID。                        |
| 网元名称    | 用于标识查询到的网元名称。                        |
| 网元类型    | 用于标识一个网元的类型，其值域类型为枚举类型，详见参数标识中的枚举描述。 |
| 网元版本    | 用于标识网元对象的版本信息。如：“V200R008C02”。       |
| 网元制造商名称 | 用于标识网元的制造商名称。                        |
| 网元自定义状态 | 用于表示网元的自定义状态，目前只有“NORMAL”状态。         |
| 网元本地名称  | 用于表示网元的本地名称。                         |
| 网元锁定状态  | 标识网元当前的锁定状态。                         |
| 网元国家码   | 用于标识网元的国家码。                          |
| 网元接口ID  | 标识网元的接口ID信息。                         |
| 网元语言    | 用于标识网元对象实例的语言。                       |
| 网元补丁版本  | 用于标识网元的补丁版本。如果该网元没有安装补丁，则显示网元版本。     |
