# 查询平面定义(LST PLANE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询指定网元下的平面定义信息。平面定义信息是指网元进程或Pod双平面划分的结果。双平面是指网元为了减少升级时的业务中断，将网元的进程或Pod划分成主备平面。

## 注意事项

在升级完成或未升级的情况下，只有0平面的信息。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                             |
|:----------|:-------|:-------------------------------------------------------------------------------------------------|
| DMID      | 域标识    | 可选必选说明：必选参数。 参数含义：用于唯一标识一个域。 取值范围：无。 默认值：1。 配置原则：无。                                              |
| SNID      | 子网标识   | 可选必选说明：必选参数。 参数含义：用于唯一标识一个域下的子网。 取值范围：0～255 默认值：0。 配置原则：无。                                       |
| MEID      | 网元ID   | 可选必选说明：必选参数。 参数含义：用于唯一标识一个网元实例。 取值范围：0～1023 默认值：无。 配置原则：无。                                       |
| PLANEID   | 工作平面标识 | 可选必选说明：必选参数。 参数含义：用于指定平面ID。 取值范围： “PLANE0(0平面)”“PLANE1(1平面)”“PLANE2(2平面)” 默认值：无。 配置原则：无。         |
| PLANESTAT | 工作平面状态 | 可选必选说明：必选参数。 参数含义：用于标识工作平面的状态。 取值范围： “ACTIVE(主)”“STANDBY(备)” 默认值：无。 配置原则：无。                      |
| PMID      | 进程标识   | 可选必选说明：必选参数。 参数含义：用于唯一标识一个进程。 取值范围：0～4294967294 默认值：无。 配置原则：无。                                   |
| RDDCFLAG  | 进程冗余类型 | 可选必选说明：必选参数。 参数含义：用于标识进程冗余的类型。 取值范围： “ACTIVE/STANDBY(主备类型)”“LOAD_SHARING(负荷分担类型)” 默认值：无。 配置原则：无。 |

## 使用实例

查询CSP网元的平面：

`LST PLANE: MEID=0;`

## 输出结果说明

| 输出项名称   | 输出项解释                       |
|:--------|:----------------------------|
| 域标识     | 用于唯一标识一个域。此处域标识只能为1。        |
| 子网标识    | 用于唯一标识一个域下的子网。目前此处子网标识只能为0。 |
| 网元ID    | 用于唯一标识一个网元实例。               |
| 平面ID    | 用于标识当前所处的平面。                |
| 平面状态    | 用于标识平面的状态。                  |
| 进程ID    | 用于标识当前的进程。                  |
| 进程冗余类型  | 用于标识当前进程冗余的类型。              |
