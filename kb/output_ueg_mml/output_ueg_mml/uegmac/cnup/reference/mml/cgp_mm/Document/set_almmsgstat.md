# 设置告警统计功能开关 (SET ALMMSGSTAT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于设置告警统计功能开关。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                  |
|:-------|:-------|:----------------------------------------------------------------------|
| CSTAT  | 开关状态   | 可选必选说明：必选参数。 参数含义：用于指示告警统计功能开关状态。 取值范围： “OFF(关)”“ON(开)” 默认值：无。 配置原则：无 |

## 使用实例

设置告警统计功能开关状态为“ON(开)”:

`SET ALMMSGSTAT: CSTAT=ON;`
