# 查询日志统计结果(LST LOGMSGSTAT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询从统计开关打开到统计开关关闭时间内的主机日志统计结果。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询日志统计结果：

`LST LOGMSGSTAT:;`

## 输出结果说明

| 输出项名称       | 输出项解释           |
|:------------|:----------------|
| 接收到的文本日志总数  | 查询到接收到的文本日志总数。  |
| 保存的文本日志总数   | 查询到保存的文本日志总数。   |
| 接收到的二进制日志总数 | 查询到接收到的二进制日志总数。 |
| 保存的二进制日志总数  | 查询到保存的二进制日志总数。  |
| 接收到的呼叫日志总数  | 查询到接收到的呼叫日志总数。  |
| 保存的呼叫日志总数   | 查询到保存的呼叫日志总数。   |
| 统计开始时间      | 查询到统计开始时间。      |
| 统计结束时间      | 查询到统计的结束时间。     |
| 统计开关状态      | 统计开关状态：关闭打开     |
