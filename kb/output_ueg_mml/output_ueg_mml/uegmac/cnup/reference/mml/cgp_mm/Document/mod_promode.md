# 修改进程模式(MOD PROMODE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改进程的系统消息区的消息单元数、系统内存分区大小、最大消息包数目等模式信息。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                  |
|:--------|:-------|:------------------------------------------------------------------------------------------------------|
| PROMODE | 进程模式   | 可选必选说明：必选参数。 参数含义：用于指定需要修改的进程资源的分配模式。 取值范围： MODE_BIG（大模式）。MODE_MID（中模式）。MODE_LIT（小模式）。 默认值：无。 配置原则：无。 |

## 使用实例

修改进程资源的大模式。

`MOD PROMODE: PROMODE=MODE_BIG;`

## 输出结果说明

| 输出项名称   | 输出项解释               |
|:--------|:--------------------|
| 网元ID    | 用于返回修改进程对应的网元号。     |
| 模块号     | 用于返回修改进程对应的模块号。     |
| 主/备状态   | 用于返回修改进程的主备状态。      |
| 设定结果描述  | 用于返回本命令的执行结果。       |
| Pod名称   | 用于返回修改进程所在的Pod名称。   |
| 位置描述    | 用于返回修改进程所在Pod的位置信息。 |
