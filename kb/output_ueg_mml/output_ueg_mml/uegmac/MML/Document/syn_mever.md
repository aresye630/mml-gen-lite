# 同步更新网元版本(SYN MEVER)

## 命令功能

**须知** 

在强制升级/回退时，执行该命令可能导致业务Pod重启，引起业务中断。请务必在华为技术支持人员的指导下使用该命令！

本命令用于将网元指定范围内Pod的底层软件版本和进程版本更新为新版本。

本命令的使用场景为：

- 在双平面存在的情况下使用本命令，复位网元指定平面内的所有Pod或进程。在此方式下，需指定平面ID，对该网元指定平面内的所有版本不一致的Pod或进程进行复位处理。
- 在强制升级/回退流程中，复位网元所有版本不一致的Pod或进程。在此方式下，不用指定平面ID，对该网元所有版本不一致的Pod或进程进行复位处理。
- 在正常升级/回退流程结束后，进行修复更新时，触发复位网元所有版本没有更新成功的Pod或进程。在此方式下，不用指定平面ID，对该网元所有版本没有更新成功的Pod或进程进行复位处理。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                        |
|:--------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID    | 网元ID   | 可选必选说明：必选参数。 参数含义：用于唯一标识一个网元实例。 取值范围：5～1023 默认值：无。 配置原则：无。                                                                                                                                                                  |
| PLANEID | 工作平面标识 | 可选必选说明：可选参数。 参数含义：表示平面的唯一标识，用于指示系统需要同步更新哪个平面下的版本；若不输入，则表示所有的工作平面标识。 取值范围：“PLANE0(0平面)”“PLANE1(1平面)”“PLANE2(2平面)” 默认值：无。 配置原则：无。                                                                                             |
| SYNMOD  | 同步模式   | 可选必选说明：必选参数。 参数含义：用于指定网元同步更新版本的操作模式。 取值范围：“AUTOMATIC(自动同步)”：对所有运行版本与期望版本不一致的Pod或进程进行复位同步更新。“OS(OS级强制同步) ”：对所有Pod无条件进行复位同步更新。“PROCESS(进程级强制同步)”：对所有运行版本与期望版本不一致的Pod进行复位同步更新，对所有进程无条件进行复位同步更新。 默认值：“AUTOMATIC(自动同步)”。 配置原则：无。 |

## 使用实例

强制同步更新网元5的底层软件版本和进程版本：

`SYN MEVER: MEID=5;`


## 输出结果说明

| 输出项名称   | 输出项解释                    |
|:--------|:-------------------------|
| Pod名称   | 表示Pod名字。                 |
| 位置描述    | 表示Pod的位置。                |
| 模块号     | 表示进程的模块号。                |
| 模块类型    | 表示进程的模块类型。               |
| 运行版本    | 表示Pod底层软件或进程当前运行的版本号。    |
| 期望版本    | 表示Pod底层软件或进程的期望版本。       |
| 失败原因    | 表示Pod底层软件版本或进程版本更新失败的原因。 |
