# 结束升级观察期(FIN UPGWATCH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

执行该命令后所有网元将无法回退到升级前的版本，请务必在华为技术支持人员的指导下使用该命令！

本命令用于结束所有已升级网元的观察期，命令执行完成之后本次升级将无法回退。

## 注意事项

- 本命令不允许在升级或回退过程中执行。
- 本命令执行后会删除不再使用的软件包、低版本的版本包、低版本的升级包、当前版本的升级包及低版本的补丁包。

## 参数说明

无。

## 使用实例

结束升级观察期：

`FIN UPGWATCH:;`

```
%%FIN UPGWATCH:;%%
RETCODE = 0  操作成功

结束升级观察期操作结果报告
--------------------------
  网元ID  =  0
操作结果  =  成功
(结果个数 = 1)

共有26个报告
---    END
```
