# 查询升级观察期(LST UPGWATCH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询升级观察期、距离结束升级观察期天数信息。

## 注意事项

无

## 参数说明

无。

## 使用实例

显示观察期信息：

`LST UPGWATCH:;`

```
%%LST UPGWATCH:;%% 
RETCODE = 0  操作成功 
 
升级观察期信息 
--------------
观察期天数设置  =  7      
     剩余天数  =  0 
(结果个数 = 1)  

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                             |
|:--------|:------------------------------------------------------------------|
| 观察期天数设置 | 设置升级结束观察期的天数。如果值是永久，表示升级完成后，系统不会自动结束观察期，需要手动下发FIN UPGWATCH来结束观察期。 |
| 剩余天数    | 表示本次升级完成后距离自动结束观察期的天数。                                            |
