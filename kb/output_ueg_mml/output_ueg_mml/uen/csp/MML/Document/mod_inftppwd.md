# 修改内网FTP用户密码(MOD INFTPPWD)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于修改内网FTP用户的密码。

本命令的使用场景为：

- 开局结束后，系统管理员应及时修改内网FTP用户密码。
- 在日常维护过程中，系统管理员需要定期修改内网FTP用户密码。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                              |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USER   | 用户名称   | 可选必选说明：必选参数。 参数含义：用于指定需要修改密码的内网FTP用户名。 取值范围：长度不超过32的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                           |
| NEW    | 新密码    | 可选必选说明：必选参数。 参数含义：用于指定内网FTP用户名的新密码。 取值范围：长度为8～32的字符串。 默认值：无。 配置原则： 密码区分大小写。 密码必须是小写字母、大写字母、数字及特殊字符（~!@#%^&*()-_+|[{}].?）四类字符集的组合。 密码中不能含如下字符串：“%%”、“+++”。 密码不能与内网FTP用户名或用户名倒写字符串相同（密码与用户名比较时不区分大小写）。 为保证系统安全，建议新设置的密码不是最近5次已经使用过的密码。 新密码与旧密码不能相同。 |
| CFM    | 确认密码   | 可选必选说明：必选参数。 参数含义：用于指定内网FTP用户名的确认密码，确认密码应与新密码保持一致。 取值范围：长度为8～32的字符串。 默认值：无。 配置原则：无。                                                                                                                                                               |

## 使用实例

修改内网FTP用户“sftp”的密码：

`MOD INFTPPWD:USER="sftp", NEW="*****", CFM="*****";`
