# 查询性能插件(LST PMPLUG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询性能的插件信息：

- 若要查询全部插件的状态信息，请不要输入任何参数。
- 若要查询某个网元的插件状态信息，请输入“网元ID”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                            |
|:-------|:-------|:--------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个网元来查询插件信息数据；若不输入，则表示所有的网元。 取值范围：无。 默认值：无。 配置原则：无。 |

## 使用实例

1. 查看所有性能插件信息：

   `LST PMPLUG:;`

   ```
   %%LST PMPLUG:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------------------
    网元ID   网元名称  插件名称   插件状态

    291      BE3       PM_PLUG_0  运行中    
    191      BE2       PM_PLUG_0  运行中    
    91       HSS_BE    PM_PLUG_0  运行中    
    91       HSS_BE    PM_PLUG_1  运行中    
    31       BE1       PM_PLUG_0  运行中    
   (结果个数 = 5)

   ---    END
   ```
2. 查看指定网元的性能插件信息，设置“网元ID”为“5”：

   `LST PMPLUG: MEID=5;`

   ```
   %%LST PMPLUG: MEID=5;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    网元ID   网元名称  插件名称   插件状态

    5        5         PM_PLUG_0  运行中     
    5        5         PM_PLUG_1  正在安装   
    5        5         PM_PLUG_2  正在卸载   
    5        5         PM_PLUG_3  安装失败   
    5        5         PM_PLUG_4  卸载失败   
    5        5         PM_PLUG_5  未知状态   

   (结果个数 = 6)

   ---    END
   ```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                |
|:--------|:-----------------------------------------------------------------------------------------------------|
| 网元ID    | 唯一标识一个网元。                                                                                            |
| 网元名称    | 标识网元的名称。                                                                                             |
| 插件名称    | 唯一标识网元下的一个插件，和安装时的插件ID对应。                                                                            |
| 插件状态    | 某插件当前的工作状态。 取值说明：“运行中”：插件正在工作。“正在安装”：插件正在安装。“正在卸载”：插件正在卸载。“安装失败”：插件安装失败。“卸载失败”：插件卸载失败。“未知状态”：插件状态未知。 |
