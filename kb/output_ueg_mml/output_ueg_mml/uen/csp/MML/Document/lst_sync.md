# 查询同步状态(LST SYNC)

- 命令功能
- 注意事项

- 输出结果说明

## 命令功能

本命令用于查询HA（High Availability）模式下OMU的同步状态。本命令会查询出文件、数据库的同步类型及进度，同步失败的文件和数据库同步机制DBHA的连接状态。

执行本命令，得到的报文包括以下几类信息：

- OMU同步进度
- DBHA状态结果
- 未重播的日志
- 重播失败的日志

其中“主备OMU同步进度”和“DBHA状态结果”为查询时的固定输出，而“未重播的日志”和“重播失败的日志”则根据查询时环境的实际情况给出。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                         |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------------|
| PROCTYPE | 处理类型   | 可选必选说明：必选参数。 参数含义：用于标识按照哪种处理类型查询同步状态。 取值范围： “NORMAL(普通)”：查询当前的同步状态，上报当前同步的进度。“INNER(内部)”：查询同步是否完成。 默认值：“NORMAL(普通)”。 配置原则：无。 |

## 使用实例

1. 存在未重播日志时查询同步状态：

   `LST SYNC:;`

   ```
   %%LST SYNC:;%%
   RETCODE = 0  操作成功

   主备OMU同步进度
   ---------------
    同步种类  类型      进度  

    文件      增量同步  50%  
    数据库    增量同步  100%  
   (结果个数 = 2)

   数据库DBHA状态结果
   ----------------
   数据库名  =  omu
   DBHA状态  =  连接
   (结果个数 = 1)

   ---    END
   ```
2. 存在重播失败日志时查询同步状态：

   `LST SYNC:;`

   ```
   %%LST SYNC:;%%
   RETCODE = 0  操作成功

   主备OMU同步进度
   ---------------
    同步种类  类型      进度  

    文件      增量同步  100%  
    数据库    增量同步  100%  
   (结果个数 = 2)

   数据库DBHA状态结果
   ----------------
   数据库名  =  omu
     DBHA状态  =  连接
   (结果个数 = 1)
   ---    END
   ```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                                                                                                                                                                                                                                              |
|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 同步种类    | 同步种类表示当前进行的同步种类。 文件：表示是文件同步。数据库：表示是数据库同步。                                                                                                                                                                                                                                                                                                          |
| 类型      | 类型表示当前进行的同步类型。 全同步：表示当前正在进行全同步。CSP OMU容器里主目录“/opt/HUAWEI/cgp”下的文件采用全同步的方式进行同步，全同步通过周期同步或者下发同步命令RST SYNC的方式触发。增量同步：表示当前正在进行增量同步。除CSP OMU容器里主目录“/opt/HUAWEI/cgp”之外的目录采用增量同步的方式进行同步，增量同步通过周期同步、下发同步命令RST SYNC、以及各业务模块发送同步请求的方式触发。重建：表示当前正在进行数据库重建。DBHA故障：表示数据库同步机制故障。  说明： 在进行同步的过程中，如果达到全同步的条件，由于全同步的优先级高于增量同步，会暂停增量同步任务，优先进行全同步，等全同步完成之后，再恢复增量同步任务。 |
| 进度      | 进度表示当前进行的同步任务完成的百分比。  说明： 该命令查询同步进度信息时，默认使用的是增量同步。当增量同步进度为100%时，表明同步任务完成。                                                                                                                                                                                                                                                                          |
| 数据库名    | 数据库名表示当前数据库的名称。                                                                                                                                                                                                                                                                                                                                    |
| DBHA状态  | DBHA状态表示数据库同步机制的连接状态。当DBHA状态为断连和数据库链路拥挤时将导致主备OMU数据库数据无法同步，影响双机数据库同步功能。 连接：表示主备数据库间链路正常。断连：表示主备数据库间链路断开。数据库链路拥挤：表示主备数据库间有数据需要同步，差异总大小超过200M。                                                                                                                                                                                                        |
| 日志类型    | 日志类型表示日志记录的未重播（重播指根据日志记录将未同步或同步失败的文件重新向备用OMU或扩展OMU同步的过程）或重播失败的操作内容，包括Shell命令或文件的执行，以及目录或文件的各种操作。 Shell命令：表示正在执行Shell命令。Shell文件：表示正在执行Shell文件。添加一个目录：表示正在添加一个目录。删除一个目录：表示正在删除一个目录。更新一个目录：表示正在更新一个目录。添加一个文件：表示正在添加一个文件。删除一个文件：表示正在删除一个文件。更新一个文件：表示正在更新一个文件。                                                                                          |
| 日志信息    | 日志信息表示未重播或重播失败的目录或文件的路径及名称。                                                                                                                                                                                                                                                                                                                        |
