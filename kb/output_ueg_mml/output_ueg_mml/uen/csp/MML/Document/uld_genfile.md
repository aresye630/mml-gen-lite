# 一般文件上传 (ULD GENFILE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于文件上传操作。

该命令的使用场景为：操作员需要将文件上传到特定的FTP服务器。

在该命令中，以下关键参数需要与对端FTP服务器协商：

- “目的文件/目录”
- “FTP服务器IP地址”
- “FTP用户名”
- “FTP密码”

## 注意事项

- 操作员在使用该命令时，需要确认FTP客户端和FTP服务器使用的协议相同。
- 执行该命令的用户必须有“源文件/目录”的读权限和“目的文件/目录”的读写权限。
- ULD GENFILE只支持SFTP协议，确保FTP服务器配置协议为SFTP，端口为22。

## 参数说明

| 参数标识         | 参数名称         | 参数说明                                                                                                                                                                                                                     |
|:-------------|:-------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ULDSRCF      | 源文件/目录       | 可选必选说明：必选参数。 参数含义：用于指定Pod上源文件路径。 取值范围：长度不超过256个英文字符。 默认值：无。 配置原则是： 参数不能为空。参数中不能包含英文分号，英文引号和英文反斜线。参数目录中不能包含英文分号、英文引号、英文反斜线、英文冒号、英文问号和英文尖括号。参数中包含英文星号，且英文星号为首个或最后一个字符时，当通配符处理。如要上传文件名为123的文件，可以输入*23或者12*，不支持1*3这种方式的通配。   |
| ULDDSTF      | 目的文件/目录      | 可选必选说明：必选参数。 参数含义：用于指定FTP服务器上的目标文件路径。 取值范围：长度不超过256个英文字符。 默认值：无。 配置原则： 参数不能为空。参数中不能包含英文分号、英文反斜线、英文冒号、英文问号、英文引号、英文尖括号和英文星号。                                                                                               |
| IPTYPE       | FTP服务器IP地址类型 | 可选必选说明：必选参数。 参数含义：用于指定FTP服务器所使用的IP地址类型。 取值范围：“IPV4”：IPv4地址。“IPV6”：IPv6地址。 默认值：“IPV4”。 配置原则：无。                                                                                                                            |
| IP           | FTP服务器IPv4地址 | 可选必选说明：必选参数。 参数含义：用于指定FTP服务器地址，IPv4地址是FTP传输时的重要参数，需要与FTP服务器协商一致；若不一致，文件上传会失败。 取值范围：IP地址。 默认值：无。 配置原则：无。                                                                                                                  |
| IPV6         | FTP服务器IPv6地址 | 可选必选说明：必选参数。 参数含义：用于指定FTP服务器地址，IPv6地址是FTP传输时的重要参数，需要与FTP服务器协商一致；若不一致，文件上传会失败。 取值范围：IP地址。 默认值：无。 配置原则：无。                                                                                                                  |
| USR          | FTP用户名       | 可选必选说明：必选参数。 参数含义：用于指定FTP用户名，用户名是FTP传输时的重要参数，需要与FTP服务器协商一致；若不一致，文件上传会失败。 取值范围：长度不超过32个英文字符。 默认值：无。 配置原则：无。                                                                                                               |
| PWD          | FTP密码        | 可选必选说明：必选参数。 参数含义：用于指定FTP密码，密码是FTP传输时的重要参数，需要与FTP服务器协商一致；若不一致，文件上传会失败。 取值范围：长度不超过32个英文字符。 默认值：无。 配置原则： 密码不能为空。 密码中不能含如下字符串：“%%”、“+++”、连续两个或者两个以上空格。 密码中不能包含英文分号、英文双引号和英文反斜杠。                                             |
| GA           | 进度上报标识       | 可选必选说明：必选参数。 参数含义：用于指定是否上报进度报文。 取值范围：“Y(是)”：上报进度报文。“N(否)”：不上报进度报文。 默认值：“Y(是)”。 配置原则：无。                                                                                                                                   |
| CF           | 压缩标识         | 可选必选说明：必选参数。 参数含义：用于指定上传文件的压缩模式。 取值范围：“UNCOMPRESSED(非压缩模式)”：上传文件不进行压缩。“COMPRESSED(压缩模式)”：上传文件进行压缩。 默认值：“UNCOMPRESSED(非压缩模式)”。 配置原则：无。                                                                                    |
| ST           | 起始时间         | 可选必选说明：必选参数。 参数含义：用于指定起始时间，过滤文件时使用。 取值范围：01/01/1990 00:00:00～31/12/2037 23:59:59 默认值：无。 配置原则：无。                                                                                                                          |
| ET           | 终止时间         | 可选必选说明：必选参数。 参数含义：用于指定终止时间，过滤文件时使用。 取值范围：01/01/1990 00:00:00～31/12/2037 23:59:59 默认值：无。 配置原则：无。                                                                                                                          |
| HAVELASTFILE | 包含最近一个文件     | 可选必选说明：必选参数。 参数含义：用于指定是否包含文件修改时间和“终止时间”相差最小的文件，即距离“终止时间”最近修改的文件。 取值范围： “INCLUDE(包含)”：包含距离结束时间最近修改的文件。“NOINCLUDE(不包含)”：不包含距离结束时间最近修改的文件。 默认值：“NOINCLUDE(不包含)”。 配置原则：无。                                                    |
| DIRSTRATUM   | 目录递归层数       | 可选必选说明：必选参数。 参数含义：用于指定目录递归层数。 取值范围：0～5 默认值：0。 配置原则：无。                                                                                                                                                                    |
| ULDFILENUM   | 上传文件个数       | 可选必选说明：必选参数。 参数含义：用于指定允许上传文件的最大数量。 若参数值为“0”时，表示不限制上传文件的数量，上传所有符合其他参数设置的文件。 若参数值大于或等于符合其他参数设置的文件总数时，上传全部符合设置的文件。 若参数值小于符合其他参数设置的文件总数时，则对符合设置的文件以文件修改时间进行排序，上传修改时间距离“终止时间”最近的文件，上传文件个数为实际设置的参数值。 取值范围：0～1000 默认值：0 配置原则：无。 |

## 使用实例

指定一般文件上传，设置“源文件/目录”为“/opt/cgp\_install/”，“目的文件/目录”为“/Software/test”，“FTP服务器IP地址类型”为“IPV4”，“FTP服务器IPv4地址”为“10.144.196.248”，“FTP用户名”为“admin”，“FTP密码”为“testtolem”，“进度上报标识”为“Y(是)”，“压缩标识”为“COMPRESSED(压缩模式)”，“起始时间”为“2010.08.24 17:29:55”，“终止时间”为“2010.08.24 17:29:55”，“包含最近一个文件”为“NOINCLUDE(不包含)”，“目录递归层数”为“0”，“上传文件个数”为“10”：

`ULD GENFILE: ULDSRCF="/opt/cgp_install/", ULDDSTF="/Software/test", IPTYPE=IPV4, IP="10.144.196.248", USR="admin", PWD="*********", GA=Y, CF=COMPRESSED, ST=2010&08&24&17&29&55, ET=2010&08&24&17&29&55, HAVELASTFILE=NOINCLUDE, DIRSTRATUM=0, ULDFILENUM=10;`
