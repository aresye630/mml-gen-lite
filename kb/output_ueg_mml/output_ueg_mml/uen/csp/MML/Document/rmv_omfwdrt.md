# 删除OM转发路由 (RMV OMFWDRT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**须知** 

该命令执行后可能会影响外部访问内部指定服务，请谨慎操作。

此命令用于删除OM转发路由。

#### 注意事项

无。

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                           |
|:------------|:-------|:---------------------------------------------------------------------------------------------------------------|
| MEID        | 网元ID   | 可选必选说明：必选参数 参数含义：网元ID（用来标识网元） 取值范围：0~65535 默认值：无 配置原则：无                                                        |
| SERVICENAME | 服务名称   | 可选必选说明：必选参数 参数含义：管道服务名称 取值范围：不超过128字符，不包含中文以及如下特殊字符：`~!@#$%^&*()+=|{}':;,[]<>/?！￥…（）—【】‘；：”“’。，、？ 默认值：无 配置原则：无 |
| PORT        | 端口     | 可选必选说明：必选参数 参数含义：OMLB外出网络端口 取值范围：17100~17199 默认值：无 配置原则：无                                                      |
| BACKENDPORT | 后端端口   | 可选必选说明：必选参数 参数含义：转发目标服务端口 取值范围：0~65535 默认值：无 配置原则：无                                                            |

#### 使用实例

删除OM转发路由信息：

```
%%RMV OMFWDRT: MEID=0, SERVICENAME="OMG", PORT=17100, BACKENDPORT=22;%%
RETCODE = 0  操作成功

---    END
```
