## 命令功能

**须知** 

该命令会停止模块，可能会影响运行在模块上的业务，请慎重使用该命令。

本命令用于停止除了PMU以外的模块。本命令与启动模块命令**STR MODULE**相对应。

本命令的使用场景为：当某Pod的CPU占用率过高时，可以通过本命令暂时停止模块的工作。

## 注意事项

- 当模块通过本命令停止后，可以通过**STR MODULE**命令或**RST MODULE**命令正常启动。
- 本命令支持分权分域。当用户没有停止模块的操作权限，不允许执行本命令。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                        |
|:-------|:-------|:--------------------------------------------------------------------------------------------|
| VMNAME | Pod名称  | 可选必选说明：必选参数。 参数含义：用于指示系统停止哪个Pod的模块。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：操作员可以使用LST MODULE命令查询获得。 |
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：用于指示系统停止哪个网元ID的模块。 取值范围：0～1023 默认值：无。 配置原则：无。                             |
| MN     | 模块号    | 可选必选说明：必选参数。 参数含义：用于指示系统停止哪个模块号的模块。 取值范围：0～4294967294 默认值：无。 配置原则：操作员可以使用LST MODULE命令查询获得。  |

## 使用实例

**实例1**

停止Pod模块。

```
//查询模块状态，以待停止的模块可用状态为“正常”状态。
DSP MODULE:;
```

```
//停止“Pod名称”为“cgplite-0”，“网元ID”为“5”，“模块号”为“50”的模块。 
STP MODULE: VMNAME="cgplite-0",MEID=5, MN=50;
```

```
//查询模块状态，以确定停止是否成功。
DSP MODULE:;
```

| 424993 | 该网元ID不存在或者该网元未部署CGPBroker服务不支持此命令。 | 网元参数配置错误。      | 请根据错误码提示信息并参考参数说明中的配置原则，重新输入参数后，再执行命令。 |
