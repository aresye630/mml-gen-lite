# 停止网元(STP ME)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

执行该命令后，将中断网元业务，请务必在华为技术支持人员的指导下操作。

该命令用于停止该网元所有大颗粒服务的模块。

## 注意事项

- 执行该命令后，可使用**DSP MODULE**命令查看所有模块，对应网元模块的“可用状态”项都为“NULL”，则**STP ME**命令执行完成。
- 该命令为CGPLite独有命令，只能停止部署了大颗粒的网元。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                        |
|:-------|:-------|:------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：用于唯一标识一个网元实例。 取值范围：5～1023。 默认值：无。 配置原则：无。 |

## 使用实例

部署Pod的场景下，停止一个网元下的所有模块，网元ID为6。执行如下命令：

`STP ME: MEID=6;`

```
%%STP ME: MEID=6;%%
```

## 输出结果说明

| 输出项名称   | 输出项解释             |
|:--------|:------------------|
| Pod名称   | 用于标识模块属于哪个Pod。    |
| 位置描述    | 用于标识模块所在Pod的位置信息。 |
| 业务模块号   | 用于标识业务模块号也即逻辑模块号。 |
| 模块描述    | 用于标识主机侧模块的描述信息。   |
| 操作结果    | 用于标识操作的结果。        |
