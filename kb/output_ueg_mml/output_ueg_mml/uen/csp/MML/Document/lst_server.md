# 查询服务器 (LST SERVER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于运维人员查询服务器信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询服务器信息：

```
%%LST SERVER:;%%
RETCODE = 0  操作成功

查询结果如下
------------
服务器名称         节点IP        位置信息           

paas-192-168-2-2   192.168.2.2   框号-0/槽号-1  
paas-192-168-2-3   192.168.2.3   框号-0/槽号-2  
paas-192-168-2-4   192.168.2.4   框号-0/槽号-3  
paas-192-168-2-5   192.168.2.5   框号-0/槽号-4  
(结果个数 = 4)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。输出结果说明如表1所示。

| 输出项名称   | 输出项解释   |
|:--------|:--------|
| 服务器名称   | 服务器名称。  |
| 节点IP    | 节点IP。   |
| 位置信息    | 位置信息。   |
