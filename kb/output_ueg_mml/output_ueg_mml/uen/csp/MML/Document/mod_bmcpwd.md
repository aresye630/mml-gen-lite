# 修改BMC默认账户密码 (MOD BMCPWD)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

本命令用于修改硬件默认账户Administrator的密码。

**说明** 

维护阶段定期修改。

#### 注意事项

该命令中的“旧密码”、“新密码”和“确认密码”参数只校验密码长度，具体密码校验规则请参见硬件的密码校验规则。

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                      |
|:----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USR       | 用户名    | 可选必选说明：必选参数 参数含义：硬件的默认账户。 取值范围：长度不超过64的字符串。 默认值：Administrator 配置原则：无。                                                                                                     |
| MODE      | 模式     | 可选必选说明：必选参数 参数含义：修改密码的模式。 取值范围： ALL(所有)：修改所有硬件默认账户的密码SINGLE(单个)：修改对应框槽号默认账户的密码 默认值：ALL(所有) 配置原则：若需要将“模式”配置为“ALL”，需要将ALM-137611 iBMC对接失败告警清除后再执行此MML命令，否则可能会存在部分单板密码修改未生效。 |
| CHASSISID | 框号     | 可选必选说明：在“模式”为“SINGLE”的时候必选 参数含义：硬件框号。 取值范围：长度不超过64的字符串。 默认值：0 配置原则：无。                                                                                                     |
| BLADEID   | 槽号     | 可选必选说明：在“模式”为“SINGLE”的时候必选 参数含义：硬件槽号。 取值范围：长度不超过64的字符串。 默认值：1 配置原则：无。                                                                                                     |
| OLDPWD    | 旧密码    | 可选必选说明：必选参数 参数含义：默认账户的旧密码。 取值范围：8~20 默认值：无。 配置原则：无。                                                                                                                       |
| NEWPWD    | 新密码    | 可选必选说明：必选参数 参数含义：默认账户的新密码。 取值范围：8~20 默认值：无。 配置原则：无。                                                                                                                       |
| CPWD      | 确认密码   | 可选必选说明：必选参数 参数含义：用于用户确认新密码，确认密码应与新密码保持一致。 取值范围：8~20 默认值：无。 配置原则：无。                                                                                                        |

#### 使用实例

修改0框1槽单板的密码。

```
%%MOD BMCPWD: USR="Administrator", MODE=SINGLE, CHASSISID="0", BLADEID="1", OLDPWD="*****", NEWPWD="*****", CPWD="*****";%%
RETCODE = 0  操作成功
---    END
```

#### 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误描述。常见错误描述如表1所示。

| 描述解释             | 原因分析            | 处理建议            |
|:-----------------|:----------------|:----------------|
| 用户名或旧密码输入错误      | 用户名或旧密码输入错误     | 更换正确的用户名或旧密码重试  |
| 系统内部错误           | 系统内部错误          | 请联系华为技术支持       |
| 新密码禁止使用历史密码      | 新密码使用了历史密码      | 更换新密码重试         |
| 新密码与确认密码不一致      | 新密码与确认密码不一致     | 新密码与确认密码输入一致后重试 |
| 新密码禁止使用弱密码字典中的密码 | 新密码使用了弱密码字典中的密码 | 更换新密码重试         |
| 框槽号不存在           | 框槽号不存在          | 输入正确的框槽号后重试     |
