# 设置IFCM配置信息(SET IFCMCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

**执行该命令会改变IFCM系统配置，对故障诊断恢复结果造成影响，请慎重执行。**

该命令用于设置IDRService配置信息。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                                                                                |
|:----------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID      | 网元ID    | 可选必选说明：必选参数。 参数含义：指定要设置哪个网元的配置信息。 取值范围：0~65535。 默认值：无。 配置原则：无。                                                                                                                      |
| CFG_TYPE  | 配置名称    | 可选必选说明：必选参数。 参数含义：指定要配置项。 取值范围： “byME(网元故障阈值)”：配置网元级故障阈值。“byPod(Pod故障阈值)”：配置Pod级的故障阈值。“byPool(网元容灾阈值)”：配置网元级的容灾倒换阈值。 默认值：无。 配置原则：无。                                                 |
| THRESHOLD | 配置阈值(%) | 可选必选说明：必选参数。 参数含义：发送给服务的阈值信息。 取值范围：整数类型，当“配置名称”为“byME(网元故障阈值)”和“byPod(Pod故障阈值)”时取值范围为1~100，当“配置名称”为“byPool(网元容灾阈值)”时取值范围为5~100。“byME(网元故障阈值)”必须严格小于“byPool(网元容灾阈值)”。 默认值：无。 配置原则：无。 |

## 使用实例

设置网元容灾倒换阈值：

```
%%SET IFCMCFG: MEID=0, CFG_TYPE=byPool, THRESHOLD=18;%%
RETCODE = 0  操作成功
操作结果如下： 
-------------- 
操作结果  =  success 
(结果个数 = 1)  
---    END
```
