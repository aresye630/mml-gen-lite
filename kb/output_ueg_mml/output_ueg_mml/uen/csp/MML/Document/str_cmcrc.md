# 校验配置数据（STR CMCRC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

校验配置数据需要约3分钟完成，且会导致CPU产生一定的波动，如在业务高峰期需谨慎执行。

本命令用于校验网元的配置对象数据，然后显示校验配置数据的结果。

## 注意事项

校验配置数据需要约3分钟完成，且会导致CPU产生一定的波动，如在业务高峰期需谨慎执行。

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                   |
|:------------|:---------|:---------------------------------------------------------------------------------------|
| MEID        | 网元ID     | 可选必选说明：必选参数 参数含义：需要校验配置数据的网元ID。 取值范围：1~65535。 默认值：无。 配置原则：可以使用LST MELST ME命令查询获得。      |
| SERVICENAME | 服务名称     | 可选必选说明：可选参数 参数含义：配置对象所属的服务名称。 取值范围：长度不超过256的字符串。 默认值：无。 配置原则：服务名称和配置对象名称需同时设置或同时不设置取值。 |
| MOCNAME     | 配置对象名称   | 可选必选说明：可选参数 参数含义：配置对象名称。 取值范围：长度不超过256的字符串。 默认值：无。 配置原则：服务名称和配置对象名称需同时设置或同时不设置取值。      |
| SSR         | 显示数据一致记录 | 可选必选说明：可选参数 参数含义：是否显示配置中心的数据和网元服务的数据校验一致的记录。 取值范围： NO(不显示)YES(显示) 默认值：NO(不显示)。 配置原则：无。 |
