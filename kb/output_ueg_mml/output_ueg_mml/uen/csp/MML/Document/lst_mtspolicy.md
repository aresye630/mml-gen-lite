# 查询消息跟踪限制（LST MTSPOLICY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询对消息跟踪能力的限制。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                  |
|:-----------|:-------|:------------------------------------------------------------------------------------------------------|
| MEID       | 网元ID   | 可选必选说明：可选参数。 参数含义：标识网元ID，可以通过LST MELST ME命令查询获取。 取值范围：0~65535 默认值：无。 配置原则：无。                          |
| POLICYTYPE | 规则类型   | 可选必选说明：可选参数。 参数含义：限制消息跟踪的规则类型。 取值范围： DISABLE_BY_TYPE(限制跟踪类型)DISABLE_BY_SERVICE(限制服务名称) 默认值：无。 配置原则：无。 |

## 使用实例

查询跟踪消息限制：

```
%%LST MTSPOLICY:;%%
RETCODE = 0  操作成功
消息跟踪限制（限制跟踪类型）
----------------------------
网元ID  跟踪类型  
10      1002      
10      3001      
10      22222     
(结果个数 = 3)

消息跟踪限制（限制服务名称） 
------------------------   
网元ID    =  12 
跟踪类型  =  60905 
服务名称  =  CSPGoCommonServiceDemo 
(结果个数 = 1)
---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息，输出结果说明表1如所示。

命令执行异常，会返回提示对应的失败信息。错误码列表如表2所示。

| 输出项名称   | 输出项解释     |
|:--------|:----------|
| 网元ID    | 标识网元ID。   |
| 跟踪类型    | 标识跟踪类型。   |
| 服务名称    | 标识订阅服务名称。 |

|    错误码 | 消息解释   | 原因分析                 | 处理建议         |
|-------:|:-------|:---------------------|:-------------|
| 101601 | 系统异常   | 服务离线、数据库异常等。         | 请等待几分钟后重试。   |
| 101602 | 网元不存在  | “网元ID”输入非法，与实际环境不一致。 | 修改网元ID后重试。   |
| 101603 | 请求消息错误 | 请求消息错误。              | 请联系华为技术支持处理。 |
