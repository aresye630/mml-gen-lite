## 命令功能

该命令用于指定网元热补丁包的加载，命令成功运行后补丁状态为去激活态。

该命令的使用场景为：当在网上运行的系统存在某种缺陷，且需要通过在线热补丁的方式解决时，操作员可以执行该命令将补丁加载到相应模块的补丁区。

如果不输入模块号，表示对整个网元下所有相应的模块加载补丁操作。

## 注意事项

- 在执行该操作之前，请操作员先执行**LOD PKG**命令，然后执行**LST PKG**命令来确认补丁包的名称、大小和日期信息是否正确。
- 加载补丁成功后补丁文件中的所有补丁都处于去激活状态。
- 网元ID为0时是对CSP网元的模块进行操作，网元ID>4时是对业务网元的模块进行操作。
- 补丁文件路径各网元不一样，如CSP（网元号为0，工作区ID为1）网元补丁文件存放目录为：“/opt/HUAWEI/cgp/workshop/omu/workspace1/bin”，业务网元（网元号为X，工作区ID为1）网元补丁文件存放目录为：“/opt/HUAWEI/cgp/workshop/nes/neX/workspace1/bin”。
- 当部分进程加载失败，报文中显示“补丁正在初始化，操作失败”时，节点正在进行补丁恢复。请稍后重试此操作，如果重试三次问题仍然没有解决，请联系华为技术支持处理。
- 脱机加载补丁时，只提供**LOD PATCH**命令，不支持**ROL PATCH**命令，在因操作出错需要回退时，需使用**RMV PATCH**删除所有补丁后，再重新执行**LOD PATCH**命令。
- 脱机加载补丁时，不能输入模块号、主备标记参数。
- 如果已经加载紧急热补丁，则需要先将紧急热补丁卸载后再加载当前热补丁包。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID    | 网元ID   | 可选必选说明：必选参数。 参数含义：标识一个补丁操作的关键字段之一，用于请求系统需要对哪一个网元实例实施操作。 取值范围： 0～1023。 默认值： 无。 配置原则：无。                                                                                               |
| MN      | 模块号    | 可选必选说明：必选参数。 参数含义：用于请求系统需要对指定网元下哪一个模块实施操作。 取值范围：0～4294967294 默认值：无。 配置原则：操作员可以通过在MEID指定的网元实例上使用LST MODULE命令查询模块号及对应的模块类型，然后根据模块号进行补丁操作。缺省为对指定网元下所有相应的模块实施补丁操作。对指定模块实施操作一般只用于故障处理场景。 |
| AS      | 主备标记   | 可选必选说明：必选参数。 参数含义：用于请求系统需要对指定模块的主或备进程实施补丁操作。取值范围： “ACTIVE(主)”“STANDBY(备)” 默认值：无。 配置原则：其值域类型为枚举类型。缺省为对主、备进程都实施补丁操作。对指定模块的主备实施操作一般只用于故障处理场景。                                          |
| PNAME   | 补丁名称   | 可选必选说明：必选参数。 参数含义：标识补丁操作的关键字段之一。 取值范围：长度不超过32的字符串。 默认值：无。 配置原则：命名规则是SPHXXX或HPXXXX，其中SPHXXX表示热补丁，HPXXXX表示紧急热补丁。以补丁名称进行操作时，是对补丁包中所有单个补丁文件进行相应操作。该参数大小写不敏感。                            |
| OFFLINE | 脱机加载   | 可选必选说明：必选参数。 参数含义：用于脱机加载补丁。 取值范围： “NO(否)”：非脱机加载补丁“YES(是)”：脱机加载补丁 默认值：“NO(否)”。 配置原则：其值域类型为枚举类型。缺省为非脱机加载补丁。此选项只在重新安装系统自动安装补丁、系统升级过程中自动安装补丁场景下使用。                                      |

## 使用实例

1. 加载热补丁包：“网元ID”为“0”，“模块号”为“3017”，“主备标记”为“主”，“补丁名称”为“SPH001”:

   `LOD PATCH: MEID=0, MN=3017, AS=ACTIVE, PNAME="SPH001";`

   ```
   %%LOD PATCH: MEID=0, MN=3017, AS=ACTIVE, PNAME="SPH001";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
     网元ID  =  0
     模块号  =  3017
   主备标记  =  主
   补丁名称  =  SPH001
   补丁状态  =  去激活
   操作结果  =  成功
   (结果个数 = 1)

   共有3个报告

   ---    END
   ```
2. 加载热补丁包：“网元ID”为“5”，“补丁名称”为“SPH001”，“模块号”和“主备标记”参数均不输入:

   `LOD PATCH: MEID=5, PNAME="SPH001";`

   ```
   %%LOD PATCH: MEID=5, PNAME="SPH001";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
     网元ID  =  5
     模块号  =  55
   主备标记  =  主
   补丁名称  =  SPH001
   补丁状态  =  去激活
   操作结果  =  成功
   (结果个数 = 1)

   共有3个报告

   ---    END
   ```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                             |
|:--------|:------------------------------------------------------------------------------------------------------------------|
| 网元ID    | 该参数标识了网元ID。                                                                                                       |
| 模块号     | 该参数标识了所加载补丁的模块号。                                                                                                  |
| 主备标记    | 该参数标识了执行补丁操作的模块状态。其值域类型为枚举类型。 取值说明： “ACTIVE(主)”“STANDBY(备)”                                                       |
| 补丁名称    | 用于标识补丁名称。命名规则是SPHXXX或HPXXXX，其中SPHXXX表示热补丁，HPXXXX表示紧急热补丁。以补丁名称进行操作时，是对补丁包中所有单个补丁文件进行相应操作。                          |
| 补丁状态    | 补丁操作的结果信息之一，用于表示补丁单元的运行状态。其值域范围为枚举类型。 取值说明： “运行”：表示补丁安装成功。“激活”：表示补丁安装过程中的中间状态。“去激活”：表示补丁安装过程中的中间状态。“空闲”：表示没有安装补丁。 |
| 操作结果    | 用于描述补丁操作的结果。                                                                                                      |
