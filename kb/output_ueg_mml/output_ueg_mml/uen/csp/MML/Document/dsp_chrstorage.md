# 查询CHR存储空间信息(DSP CHRSTORAGE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令为维护类命令，用于查询CHR存储空间信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询CHR存储空间信息：

```
%%DSP CHRSTORAGE:;%%
RETCODE = 0  操作成功

CHR磁盘资源结果如下
-------------------
 Pod名称    CHR文件目录  总空间（MB）  已用空间（MB）  可用空间（MB）

 cgplite-0  CHR          5120          1               5119          
 cgplite-0  CHR4MAN      5120          1               5119          
 cgplite-0  VIPCHR       256           1               255           
 cgplite-1  CHR          5120          1               5119          
 cgplite-1  CHR4MAN      5120          1               5119          
 cgplite-1  VIPCHR       256           1               255           
(结果个数 = 6)

---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息，输出结果说明如表1所示。

| 输出项名称    | 输出项解释                                                                                                                                                                                                                                                        |
|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Pod名称    | 用于返回CGPLite容器的Pod名称。                                                                                                                                                                                                                                         |
| CHR文件目录  | 用于返回保存CHR文件的目录名称。 取值说明：“CHR”：表示“/opt/HUAWEI/cgp/workshop/omu/share/export/pm/CHR”目录，用于保存CHR单据。“CHR4MAN”：表示“/opt/HUAWEI/cgp/workshop/omu/share/export/pm/CHR4MAN”目录，用于保存历史单据。“VIPCHR”：表示“/opt/HUAWEI/cgp/workshop/omu/share/export/pm/VIPCHR”目录，用于保存VIPCHR单据。 |
| 总空间（MB）  | 用于返回该目录的总大小。                                                                                                                                                                                                                                                 |
| 已用空间（MB） | 用于返回该目录的已用空间大小。                                                                                                                                                                                                                                              |
| 可用空间（MB） | 用于返回该目录的可用空间大小，取值为“总空间（MB）”减去“已用空间（MB）”。  说明： 若当前系统实际剩余空间小于“总空间（MB）”减去“已用空间（MB）”时，则“可用空间（MB）”取值为系统实际剩余空间。                                                                                                                                                    |
