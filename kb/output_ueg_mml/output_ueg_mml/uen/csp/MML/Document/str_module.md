# 启动模块(STR MODULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于启动除PMU以外的模块。启动模块时，模块会自动加载新的程序。

本命令的使用场景为：与停止模块命令**STP MODULE**相对应，仅用于启动执行**STP MODULE**命令停止的模块。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                        |
|:-------|:-------|:--------------------------------------------------------------------------------------------|
| VMNAME | Pod名称  | 可选必选说明：必选参数。 参数含义：用于指示系统启动哪个Pod的模块。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：操作员可以使用LST MODULE命令查询获得。 |
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：用于指示系统启动哪个网元ID的模块。 取值范围：0～1023 默认值：无。 配置原则：无。                             |
| MN     | 模块号    | 可选必选说明：必选参数。 参数含义：用于指示系统启动哪个模块号的模块。 取值范围：0～4294967294 默认值：无。 配置原则：操作员可以使用LST MODULE命令查询获得。  |

## 使用实例

**实例1**

启动Pod模块。

```
//启动“Pod名称”为“cgplite-0”，“网元ID”为“5”，“模块号”为“50”的模块。
STR MODULE: VMNAME="cgplite-0", MEID=5, MN=50;
```

```
//查询模块状态，以确定启动是否成功。
DSP MODULE:;
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                              | 原因分析           | 处理建议                                   |
|-------:|:-----------------------------------|:---------------|:---------------------------------------|
| 478001 | 该资源未配置对应的应用。                       | 输入的模块配置信息错误。   | 使用DSP MODULE命令查询模块，确认参数信息，再执行复位操作。     |
| 424993 | 该网元ID不存在或者该网元未部署CGPBroker服务不支持此命令。 | 网元参数配置错误。      | 请根据错误码提示信息并参考参数说明中的配置原则，重新输入参数后，再执行命令。 |
| 425011 | 指定的模块不存在。                          | 模块参数配置错误。      | 请根据错误码提示信息并参考参数说明中的配置原则，重新输入参数后，再执行命令。 |
| 421046 | 模块正在运行。                            | 正在运行的模块不能再次启动。 | 确认待启动的模块可用状态是否已经正常，如果正常，就无需再执行此命令。     |
