# 查询时间(DSP INTIME)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于请求系统显示Pod的系统时间和运行时间或Pod的模块启动时间和运行时间。

## 注意事项

检查Pod系统时间和OMU上的时间是否一致，时间正常误差范围在2秒内。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                            |
|:--------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TMQRYTP | 查询类型   | 可选必选说明：必选参数。 参数含义：用于请求系统是按照哪个查询类型显示时间信息。 取值范围：“VMTIME(Pod时间)”：查询Pod上的时间信息。“VMMODTIME(模块时间)”：查询Pod上的模块的时间信息。 默认值：无。 配置原则：无。                                      |
| VMNAME  | Pod名称  | 可选必选说明：必选参数。 参数含义：仅当本命令中的“查询类型”参数选择为“VMTIME(Pod时间)”或“VMMODTIME(模块时间)”时该参数有效。用于请求系统显示哪个Pod上的时间信息。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：操作员可以通过执行LST MODULE命令查询获取Pod名称。 |
| MEID    | 网元ID   | 可选必选说明：可选参数。 参数含义：用于请求系统显示哪个网元ID上模块的运行时间信息。 取值范围：无。 默认值：无。 配置原则：仅当本命令中的“查询类型”参数选择为“VMMODTIME(模块时间)”时该参数有效。用于请求系统显示哪个网元ID上模块的运行时间信息；若不输入，则表示所有的网元ID。             |
| MN      | 模块号    | 可选必选说明：可选参数。 参数含义：用于请求系统显示哪个模块的运行时间信息。 取值范围：无。 默认值：无。 配置原则：仅当本命令中的“查询类型”参数选择为“VMMODTIME(模块时间)”时该参数有效。用于请求系统显示哪个模块的运行时间信息；若不输入，则表示所有的模块号。                        |

## 使用实例

1. 查询“查询类型”为“VMTIME(Pod时间)”，“Pod名称”为“cgplite-0”的Pod系统时间：

   `DSP INTIME: TMQRYTP=VMTIME, VMNAME="cgplite-0";`

   ```
   %%DSP INTIME: TMQRYTP=VMTIME, VMNAME="cgplite-0";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   Pod名称  =  cgplite-0
     位置描述  =  10.7.50.10
     系统时间  =  2014-08-08 01:53:48.122+00:00
     运行时间  =  0天1时37分5秒
   (结果个数 = 1)

   ---    END
   ```
2. 查询“查询类型”为“VMMODTIME(模块时间)”，“Pod名称”为“cgplite-0”，“模块号”为“3016”的运行时间：

   `DSP INTIME: TMQRYTP=VMMODTIME, VMNAME="cgplite-0", MN=3016;`

   ```
   %%DSP INTIME: TMQRYTP=VMMODTIME, VMNAME="cgplite-0", MN=3016;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   Pod名称  =  cgplite-0
     位置描述  =  10.7.50.10
       网元ID  =  0
       模块号  =  3016
     主备状态  =  主用
     启动时间  =  2014-08-08 00:19:56.732+00:00
     运行时间  =  0天1时48分11秒
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

| 输出项名称   | 输出项解释                        |
|:--------|:-----------------------------|
| Pod名称   | 用于返回进程所在Pod的名称。              |
| 位置描述    | 用于返回Pod所在的位置信息。              |
| 系统时间    | 用于返回Pod的系统时间。仅在查询Pod时间时有效。   |
| 主备状态    | 用于返回模块的主备状态。仅在查询Pod内模块时间时有效。 |
| 启动时间    | 用于返回模块的启动时间。仅在查询Pod内模块时间时有效。 |
| 运行时间    | 用于返回Pod或模块的运行时间。             |
