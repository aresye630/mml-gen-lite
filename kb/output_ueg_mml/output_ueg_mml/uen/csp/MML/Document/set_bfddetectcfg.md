# 设置fabric平面BFD协议探测参数(SET BFDDETECTCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明
- 参考信息

## 命令功能

该命令用于设置fabric平面BFD协议探测参数。

## 注意事项

无。

## 参数说明

| 参数标识                        | 参数名称        | 参数说明                                                                                                              |
|:----------------------------|:------------|:------------------------------------------------------------------------------------------------------------------|
| DETECTION_CYCLE             | 检测周期(s)     | 可选必选说明：可选参数。 参数含义：需要设置的fabric平面BFD协议的检测周期。 取值范围：整数类型，取值范围40~1200。 默认值：无。 配置原则：填写的检测周期必须是40的倍数。                    |
| DETECTION_THRESHOLD         | 检测阈值(%)     | 可选必选说明：可选参数。 参数含义：需要设置的fabric平面BFD协议的检测阈值。 取值范围：整数类型，取值范围5~50。 默认值：无。 配置原则：填写检测阈值时必须填写恢复阈值，并且检测阈值要大于恢复阈值。         |
| RECOVERY_THRESHOLD          | 恢复阈值(%)     | 可选必选说明：可选参数。 参数含义：需要设置的fabric平面BFD协议的恢复阈值。 取值范围：整数类型，取值范围1~49。 默认值：无。 配置原则：填写恢复阈值时如果没填写检测阈值，填写的恢复阈值必须小于当前环境的检测阈值。 |
| SWITCHING_INHIBITION_TIME   | 倒换抑制时间(s)   | 可选必选说明：可选参数。 参数含义：需要设置的sRouter倒换抑制时间。 取值范围：整数类型，取值范围2~100。 默认值：无。 配置原则：无。                                         |
| SWITCHING_INHIBITION_PERIOD | 倒换抑制周期(min) | 可选必选说明：可选参数。 参数含义：需要设置的sRouter倒换抑制时长重置周期。 取值范围：整数类型，取值范围1~100。 默认值：无。 配置原则：无。                                     |

## 使用实例

设置fabric平面BFD协议探测的检测周期为40s、检测阈值是20%、恢复阈值是5%，设置sRouter的倒换抑制时间为2s、时长重置周期是1min成功。

```
SET BFDDETECTCFG: DETECTION_CYCLE=40, DETECTION_THRESHOLD=20, RECOVERY_THRESHOLD=5, SWITCHING_INHIBITION_TIME=2, SWITCHING_INHIBITION_PERIOD=1;
```

```
%%SET BFDDETECTCFG: DETECTION_CYCLE=40, DETECTION_THRESHOLD=20, RECOVERY_THRESHOLD=5, SWITCHING_INHIBITION_TIME=2, SWITCHING_INHIBITION_PERIOD=1;%%
RETCODE = 0  操作成功
---    END
```

设置fabric平面BFD协议探测的检测周期为41s失败。

```
SET BFDDETECTCFG: DETECTION_CYCLE=41;
```

```
%%SET BFDDETECTCFG: DETECTION_CYCLE=41;%% 
RETCODE = 15500516  填写的检测周期必须是40的倍数
---    END
```
