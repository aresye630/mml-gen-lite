# 显示模块(DSP MODULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于请求系统显示模块的状态信息，如模块的“主备状态”、“管理状态”、“CPU占用率”或“内存占用率”等信息。

## 注意事项

- 系统在执行本命令时需要消耗节点一定的CPU资源，这种CPU资源消耗与操作员需要查询的模块数成正比，为尽量减少查询大量模块状态时对节点CPU资源的消耗，建议操作员输入具体的“网元ID”参数进行操作。
- 如果网元应用类型不支持PMU部署，命令返回报文中“分配的内存(KB)”、“内存占用率(百分比)”和“CPU占用率(百分比)”都为“NULL”。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                 |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VMNAME | Pod名称  | 可选必选说明：可选参数。 参数含义：用于请求系统显示哪个Pod上的模块的运行状态。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：操作员可以使用LST MODULE命令查询获得。若不输入，则表示显示所有Pod模块的状态信息。                                                                                                                                                                                                             |
| MEID   | 网元ID   | 可选必选说明：可选参数。 参数含义：用于请求系统显示哪个网元ID的模块的运行状态。 取值范围：0～1023。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                |
| MN     | 模块号    | 可选必选说明：可选参数。 参数含义：用于请求系统显示哪个模块号对应的模块的运行状态；若不输入，则表示所有的模块号。 取值范围：0～4294967294。 默认值：无。 配置原则：操作员可以使用LST MODULE命令查询获得。若不输入，则表示显示所有模块的状态信息。                                                                                                                                                                                                |
| DESC   | 模块类型   | 可选必选说明：可选参数。 参数含义：用于请求系统显示哪种模块类型的模块的运行状态。 取值范围：长度不超过200的字符串。 默认值：无。 配置原则：操作员可以使用LST MODULE命令查询获得。若不输入，则表示所有的模块的状态信息。详细的模块类型和功能信息，请参见产品文档中的《软件描述》。                                                                                                                                                                                    |
| HAST   | 主备状态   | 可选必选说明：可选参数。 参数含义：用于请求系统是按照哪种主备状态来显示模块的运行状态。 取值范围：“UNASSIGNED(未指配)”：查询的模块的状态为未指配。在模块启动的初期，模块处于尚未指配主用或备用的状态。“STANDBY(备用)”：查询的模块的状态为备用。“ACTIVE(主用)”：查询的模块的状态为主用。“INVALID(无效)”：查询的模块的状态为未就绪，状态为无效。“UNCONFIGURED(未配置)”：查询的模块的状态为未配置。 默认值：无。 配置原则：若不输入，则表示所有的模块的状态信息。                                                                     |
| HADMST | 管理状态   | 可选必选说明：可选参数。 参数含义：用于请求系统是按照哪种管理状态来显示模块的管理状态。 取值范围：“LOCK(锁定)”：查询的模块支持管理状态，且当前处于锁定状态，不能处理任何服务。“UNLOCK(未锁定)”：查询的模块支持管理状态，且当前处于未锁定状态。处于该状态的模块，可以接入新的服务。“SHUTDOWN(正在锁定)”：查询的模块支持管理状态，且处于正在锁定状态。此状态属于暂态。处于该状态的模块不允许接入新的服务，但是会处理已有的服务。当所有的服务都退出后，模块自动进入“LOCK(锁定)”状态。“UNSUPPORTED(不支持)”：查询的模块不支持管理状态，如PMU模块。 默认值：无。 配置原则：若不输入，则表示所有的模块的状态信息。 |

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。输出结果说明如表1所示。

命令执行异常，会返回命令执行异常的提示信息。

| 输出项名称       | 输出项解释                                                                                                                                                                        |
|:------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Pod名称       | 用于标识服务实例对应Pod的名称。                                                                                                                                                            |
| 位置描述        | 用于返回模块所在Pod的位置信息。                                                                                                                                                            |
| 网元ID        | 用于返回模块所属的网元ID。                                                                                                                                                               |
| 模块号         | 用于返回模块的模块号                                                                                                                                                                   |
| 模块类型        | 用于返回模块的模块类型                                                                                                                                                                  |
| 主备状态        | 用于返回模块的主用或者备用状态                                                                                                                                                              |
| 可用状态        | 用于返回模块当前是否处于可以使用的状态： “正常”：表示模块可以提供服务。“未就绪”：表示模块已启动，此时正处于加载状态，不提供业务功能。“故障”或“NULL”：表示模块不可以提供服务，需要对故障模块进行处理。详细的故障处理方法，请参见产品文档中的《故障处理》手册中的“模块故障”章节。                              |
| 分配的内存(KB)   | 用于返回模块分配的内存大小，单位为KB。                                                                                                                                                         |
| 内存占用率(百分比)  | 用于返回模块当前使用内存占用模块“分配的内存(KB)”的百分比。                                                                                                                                             |
| CPU占用率(百分比) | 用于返回模块当前的CPU占用率。                                                                                                                                                             |
| 管理状态        | 用于返回模块的管理状态信息： “LOCK(锁定)”：表示目前不能处理任何服务。“UNLOCK(未锁定)”：表示目前可以接入新的服务。“SHUTDOWN(正在锁定)”：表示目前不允许接入新的服务，但是会处理已有的服务。当所有的服务都退出后，模块自动进入“LOCK(锁定)”状态。“UNSUPPORTED(不支持)”：表示查询的模块不支持管理状态。 |
