# 增加以太网交换机(ADD LSW)

## 命令功能

本命令用于增加以太网交换机。

## 注意事项

增加交换机时输入的认证密码和加密密码不能一致，同一环境交换机添加数量上限为4个。

## 参数说明

| 参数标识     | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                                                    |
|:---------|:-------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LSNAME   | 以太网交换机名称     | 可选必选说明：必选参数。 参数含义：用于指示添加的以太网交换机名称。 取值范围：长度不超过64的字符串，支持字母和数字（A~Z、a~z、0~9）。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                |
| IPTYPE   | 以太网交换机IP地址版本 | 可选必选说明：必选参数。 参数含义：用于指示添加的以太网交换机IP地址版本。 取值范围： IPV4(IPv4版本)。IPV6(IPv6版本)。 默认值：IPV4(IPv4版本)。 配置原则：无。                                                                                                                                                                                                                       |
| LSIP     | 以太网交换机IPv4地址 | 可选必选说明：在“以太网交换机IP地址版本”为“IPV4(IPv4版本)”的时候必选。 参数含义：用于指示添加的以太网交换机IPv4地址。 取值范围：IPv4地址。 默认值：无。 配置原则：必须和OM网段地址在同一子网，OM IP可以通过LST OMIP查询。                                                                                                                                                                                      |
| LSIPV6   | 以太网交换机IPv6地址 | 可选必选说明：在“以太网交换机IP地址版本”为“IPV6(IPv6版本)”的时候必选。 参数含义：用于指示添加的以太网交换机IPv6地址。 取值范围：IPv6地址。 默认值：无。 配置原则：必须和OM网段地址在同一子网，OM IP可以通过LST OMIP查询。                                                                                                                                                                                      |
| USER     | SNMP用户名      | 可选必选说明：必选参数。 参数含义：用于指示添加交换机的SNMP用户名，需要从交换机对端获取，CSP仅作为客户端存储使用。 取值范围：请控制在6到20个字符，支持字母、数字和下划线（A~Z、a~z、0~9、_）。 默认值：无。 配置原则：无。                                                                                                                                                                                               |
| PORT     | 以太网交换机端口     | 可选必选说明：必选参数。 参数含义：用于指示设备侧的SNMP协议侦听的以太网交换机端口。 取值范围：1~65535之间的整数。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                          |
| PROTVER  | 协议版本         | 可选必选说明：必选参数。 参数含义：用于指示添加的以太网交换机的协议版本。 取值范围：SNMPv3(SNMPv3)。 默认值：SNMPv3。 配置原则：无。                                                                                                                                                                                                                                          |
| AUTHPROT | 认证协议         | 可选必选说明：必选参数。 参数含义：用于指示添加的以太网交换机的认证协议。 取值范围： SHA256(SHA256)。SHA384(SHA384)。SHA512(SHA512)。 默认值：SHA512(SHA512)。 配置原则：无。                                                                                                                                                                                                   |
| AUTHKEY  | 认证密码         | 可选必选说明：必选参数。 参数含义：用于指示添加的以太网交换机的认证密码，需要从交换机对端获取，CSP仅作为客户端存储使用。 取值范围：长度在10~64之间的字符串。 默认值：无。 配置原则： 不能与“加密密码”一致。至少包括1个大写字母（A~Z），1个小写字母（a~z），1个数字（0~9）和一个特殊字符（包括!"#$%&'()*+,-./:;<=>?@[]^`{_|}~）。不能包含3位及以上的连续字母、数字（如abc、123），或3位及以上的重复字母、数字、特殊字符（如xxx、666、^^^）。不能由2个及以上完全重复的字符串组成。不能包含用户名或用户名的倒序，用户名不能包含密码或密码的倒序，该校验不区分大小写。 |
| PRVPROT  | 加密协议         | 可选必选说明：必选参数。 参数含义：用于指示添加的以太网交换机的加密协议。 取值范围：AES256(AES256)。 默认值：AES256(AES256)。 配置原则：无。                                                                                                                                                                                                                                  |
| PRVKEY   | 加密密码         | 可选必选说明：必选参数。 参数含义：用于指示添加的以太网交换机的加密密码，需要从交换机对端获取，CSP仅作为客户端存储使用。 取值范围：长度在10~64之间的字符串。 默认值：无。 配置原则： 不能与“认证密码”一致。至少包括1个大写字母（A~Z），1个小写字母（a~z），1个数字（0~9）和一个特殊字符（包括!"#$%&'()*+,-./:;<=>?@[]^`{_|}~）。不能包含3位及以上的连续字母、数字（如abc、123），或3位及以上的重复字母、数字、特殊字符（如xxx、666、^^^）。不能由2个及以上完全重复的字符串组成。不能包含用户名或用户名的倒序，用户名不能包含密码或密码的倒序，该校验不区分大小写。 |

## 使用实例

使用“USER”为“AdminUser”的SNMP用户添加“LSNAME”为“LSW1”，“LSIP”为“10.0.0.0”的交换机。

```
%%ADD LSW: LSNAME="LSW1", IPTYPE=IPV4, LSIP="10.0.0.0", USER="AdminUser", PORT=161, PROTVER=SNMPv3, AUTHPROT=SHA512, AUTHKEY="*****", PRVPROT=AES256, PRVKEY="*****";%%
RETCODE = 0  操作成功
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误描述。常见错误描述如表1 错误码列表所示。

|    错误码 | 错误码解释                                  | 原因分析                                         | 处理建议                        |
|-------:|:---------------------------------------|:---------------------------------------------|:----------------------------|
| 150201 | 设备数量达到上限                               | 当前已添加交换机设备数量已经达到上限4个。                        | 删除已添加交换机重新添加。               |
| 150207 | 认证密码和加密密码不能一致                          | 添加交换机时输入的认证密码和加密密码一致。                        | 更改认证密码或加密密码后重新添加。           |
| 150210 | 设备不可达或配置异常，请稍后重试。请注意，频繁输入配置信息将导致交换机被锁定 | 设备不可达或配置异常。如果是配置异常，交换机将进行失败处理并锁定，请间隔一段时间后重试。 | 确认输入的交换机信息正确后重试。            |
| 150211 | 交换机名称或IP已存在                            | 当前环境已添加相同名称或IP的交换机。                          | 更改添加的交换机名称或IP后重新添加。         |
| 150213 | 密码不符合要求                                | 添加交换机时输入的认证密码或加密密码不满足要求。                     | 根据认证密码或加密密码的配置原则修改密码后重新添加。  |
| 150214 | 操作失败                                   | 内部执行报错。                                      | 请联系华为技术支持。                  |
| 150215 | 交换机名或用户名格式不正确                          | 添加交换机时输入的交换机名或SNMP用户名格式不满足要求。                | 根据交换机名或SNMP用户名的格式要求修改后重新添加。 |
