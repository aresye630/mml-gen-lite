# 查询加载扩展包（LST COMPKG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令可以查询已加载的扩展域组件包名称、组件版本、当前组件包状态信息。

#### 注意事项

无。

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                             |
|:-------|:-------|:-----------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：网元ID，可以通过LST ME获取。 取值范围：0～65535 默认值：无。 配置原则：无。 |

#### 使用实例

查询网元ID为5的网元信息。

```
%%LST COMPKG: MEID=5;%%
RETCODE = 0 操作成功

操作结果如下
------------
网元类型  =  APPTYPE
网元ID    =  5
组件名称  =  APP_TYPE_XXX_V100200300400
组件版本  =  V100200300400
组件状态  =  正常
(结果个数 = 1)

---    END
```

#### 输出结果说明

命令执行正常，会返回命令执行成功的提示信息及网元组件信息。输出结果说明如表1所示。

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

| 输出项名称   | 输出项解释         |
|:--------|:--------------|
| 网元类型    | 用于返回查询的网元类型。  |
| 网元ID    | 用于返回查询的网元ID。  |
| 组件名称    | 用于返回查询的组件包名称。 |
| 组件版本    | 用于返回查询的组件包版本。 |
| 组件状态    | 用于返回查询的组件包状态。 |

|    错误码 | 错误码解释           | 原因分析                      | 处理建议           |
|-------:|:----------------|:--------------------------|:---------------|
| 150019 | 查询扩展域网元信息失败     | 输入的网元ID对应的网元在扩展域可能不存在。    | 检查并修改为正确的网元ID。 |
| 150011 | 查询CGPBroker状态失败 | 查询CGPBroker组件包信息的执行结果失败。  | 请联系华为技术支持。     |
| 150016 | 与CGPBroker通信异常  | 与CGPBroker通信查询信息异常。       | 请联系华为技术支持。     |
| 150021 | 当前模式不支持此命令      | 无需部署CGPBroker服务的模式不支持此命令。 | 无需处理。          |
