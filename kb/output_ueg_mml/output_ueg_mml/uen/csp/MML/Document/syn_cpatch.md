# 同步冷补丁(SYN CPATCH)

## 命令功能

**须知** 

本命令执行之后，会导致模块复位，影响运行在模块上的业务，请慎重使用。

该命令用于复位加载过冷补丁的业务网元节点进程，命令成功运行后，冷补丁将生效。

该命令的操作场景一般为：当操作员己经执行过**LOD CPACTH**成功加载冷补丁并且想使该补丁生效时，操作员均可以使用该命令进行同步操作。

## 注意事项

- 该命令会导致模块复位，影响运行在模块上的业务。
- 只有冷补丁包含了需要替换节点进程文件的内容时，才需要执行该命令，操作员可以通过**CHK CPATCHCRC**命令先进行校验。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：标识一个补丁操作的关键字段之一，用于请求系统需要对哪一个网元实例实施操作。操作员可以通过在LST ME命令查询获得所有的网元实例ID。 取值范围： 5～1023。 默认值： 无。 配置原则：无。 |

## 使用实例

1. 复位打过冷补丁的进程，设置“网元ID”为“10”：

`SYN CPATCH: MEID=10;`

```
%%SYN CPATCH: MEID=10;%%
RETCODE = 0  操作成功

Pod操作结果如下
------------------
 模块号  模块类型  Pod名称  位置描述        操作结果

 100     CCU       pod1     192.168.156.12     操作成功
 100     CCU       pod2     192.168.156.12     操作成功
(结果个数 = 2)

共有3个报告
---    END
```

2. 复位打过冷补丁的进程(适用于OMP9360等网元)，设置“网元ID”为“20”：

`SYN CPATCH: MEID=20;`

```
%%SYN CPATCH: MEID=20;%%
RETCODE = 0  操作成功

进度报告
--------
已完成  =  0%
(结果个数 = 1)
---    END

%%SYN CPATCH: MEID=20;%%
RETCODE = 0  操作成功

进度报告
--------
已完成  =  60%
(结果个数 = 1)
---    END

%%SYN CPATCH: MEID=20;%%
RETCODE = 0  操作成功

进度报告
--------
已完成  =  100%
(结果个数 = 1)
---    END

%%SYN CPATCH: MEID=20;%%
RETCODE = 0  操作成功

共有4个报告
---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                 |
|:--------|:----------------------|
| 模块号     | 该参数标识了所加载冷补丁的模块号。     |
| 模块类型    | 该参数标识了所加载冷补丁的模块类型。    |
| Pod名称   | 该参数标识了模块所处的Pod名称信息。   |
| 位置描述    | 该参数标识了模块所处的Pod位置描述信息。 |
| 操作结果    | 用于描述补丁操作的结果。          |
