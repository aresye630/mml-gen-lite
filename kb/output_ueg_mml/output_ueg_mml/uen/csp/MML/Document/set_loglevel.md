# 设置运行日志记录级别 (SET LOGLEVEL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置运行日志记录级别。

该命令的使用场景为：在日常操作维护中，操作员可根据实际需要使用该命令设置运行日志记录的级别，以便获取详细的系统运行信息。

## 注意事项

- 模块重启后，日志级别恢复为系统初始设置的级别。
- 操作员可在模块重启后，通过**LST LOGLEVEL**命令查询获得系统初始设置值。

## 参数说明

| 参数标识      | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|:----------|:-------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OMUMN1    | OMU模块名称      | 可选必选说明：必选参数。 参数含义：用于指定OMU的模块名称。 取值范围：无。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                      |
| LOGLV     | 日志级别         | 可选必选说明：必选参数。 参数含义：用于指定OMU模块的日志级别。 取值范围：“INFO(Info)”：表示将信息日志打印到日志文件中。“WARNING(Warning)”：表示将告警日志打印到日志文件中。“ERROR(Error)”：表示将错误日志打印到日志文件中。“CRITICAL(Critical)”：表示将严重日志打印到日志文件中。“DEBUG(Debug)”：表示将调试日志打印到日志文件中。“NOTICE(Notice)”：表示将事件日志打印到日志文件中。“STARTUP(Startup)”：表示将模块启动日志打印到日志文件中。“SHUTDOWN(Shutdown)”：表示将模块停止日志打印到日志文件中。“TRACE(Trace)”：表示将跟踪日志打印到日志文件中。 默认值：无。 系统初始设置值：“ERROR(Error)”、“CRITICAL(Critical)”、“NOTICE(Notice)”、“STARTUP(Startup)”和“SHUTDOWN(Shutdown)”。 配置原则：无。 |
| LOGVLTIME | 日志级别有效时间(分钟) | 可选必选说明：必选参数。 参数含义：用于指定日志信息的输出有效时间，超过这个时间后日志级别恢复到默认级别。单位为：分钟。 取值范围：1～30 默认值：5。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                       |

## 使用实例

设置运行日志记录级别，设置“OMU模块名称”为“CM”模块，“日志级别”为“TRACE(Trace)”，“日志级别有效时间(分钟)”为“5”：

`SET LOGLEVEL: OMUMN1="CM", LOGLV=TRACE-1, LOGVLTIME=5;`
