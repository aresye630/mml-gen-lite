# 查询文件删除策略(LST FILEDELPOLICY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询文件删除策略的配置信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询文件删除策略状态：

`LST FILEDELPOLICY:;`

```
%%LST FILEDELPOLICY:;%%
RETCODE = 0  操作成功

操作结果如下
------------
        启用状态  =  启用
最大保留天数(天)  =  30
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称     | 输出项解释                                                       |
|:----------|:------------------------------------------------------------|
| 启用状态      | 表示删除策略的启用状态。“Enable(启用)”：文件删除策略开启。“Disable(未启用)”：文件删除策略未开启。 |
| 最大保留天数(天) | 表示系统支持的文件最大保留天数。                                            |
