# 查询高危时间段提示状态（LST HIGHRISKPERIOD）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询高危时间段提示状态、高危时间段和高危命令提示信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询高危时间段提示状态：

```
%%LST HIGHRISKPERIOD:;%% 
RETCODE = 0  操作成功

操作结果如下 
------------ 
高危时间段提示状态  =  开启           
          起始时间  =  09:36           
          结束时间  =  23:36           
          提示信息  =  SFWEFGSDF 
(结果个数 = 1)
 
---    END
```

## 输出结果说明

命令执行正常，会返回当前系统高危时间段提示状态。输出结果说明如表1所示。

命令执行异常，请联系华为技术支持处理。输出错误码说明如表2所示。

| 输出项名称     | 输出项解释                                     |
|:----------|:------------------------------------------|
| 高危时间段提示状态 | 高危时间段提示功能的状态。 关闭：关闭高危时间段提示。 开启：开启高危时间段提示。 |
| 起始时间      | 高危时间段的具体起始时间。                             |
| 结束时间      | 高危时间段的具体结束时间。                             |
| 提示信息      | 高危时间段执行高危命令的提示信息。                         |

|    错误码 | 错误码解释   | 原因分析           | 处理建议           |
|-------:|:--------|:---------------|:---------------|
| 101009 | 未知的命令名称 | 输入的MML命令名称不存在。 | 请输入正确的MML命令名称。 |
| 101099 | 数据库执行失败 | 执行数据库操作失败。     | 请联系华为技术支持。     |
