# 查询事件统计告警配置(LST STATALM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询事件统计告警的配置信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                          |
|:-------|:-------|:------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数 参数含义：用于指示系统需要对哪个网元进行操作。 取值范围：0~1023 默认值：无。 配置原则：无。                |
| EID    | 事件ID   | 可选必选说明：可选参数 参数含义：用于指示系统需要对哪个事件进行操作；若不输入，则表示所有事件。 取值范围：1~200000 默认值：无。 配置原则：无。 |

## 使用实例

查询事件统计告警配置，“网元ID”为“0”：

`LST STATALM: MEID=0;`

```
%%LST STATALM: MEID=0;%%
RETCODE = 0  操作成功

事件统计告警配置信息
--------------------
      网元ID  =  0
      事件ID  =  5005
    事件名称  =  鉴权失败
    产生阈值  =  20
    恢复阈值  =  10
统计周期(秒)  =  15
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释       |
|:--------|:------------|
| 网元ID    | 系统操作的网元ID。  |
| 事件ID    | 系统操作的事件ID。  |
| 事件名称    | 系统操作的事件名称。  |
| 产生阈值    | 事件统计告警产生阈值。 |
| 恢复阈值    | 事件统计告警恢复阈值。 |
| 统计周期（秒） | 事件统计周期的时长。  |
