# 查询CHR传输策略(LST CHRPOLICY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令为维护类命令，用于查询CHR传输策略。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询CHR传输策略参数：

```
%%LST CHRPOLICY:;%%
RETCODE = 0  操作成功

操作结果如下
------------
CHR本地保存开关  =  关
    FTP传输开关  =  关
       IP版本号  =  NULL
FTP服务器IP地址  =  NULL
  FTP服务器端口  =  NULL
      FTP用户名  =  NULL
       目标目录  =  NULL
       发送间隔  =  NULL
(结果个数 = 1)

---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息，输出结果说明如表1所示。

| 输出项名称      | 输出项解释                                                                                  |
|:-----------|:---------------------------------------------------------------------------------------|
| CHR本地保存开关  | 用于返回CHR话单本地存储的开关状态。 取值说明：“开”：表示CHR本地保存开关开启，CHR单据将会保存在本地路径。“关”：表示CHR本地保存开关关闭。           |
| FTP传输开关    | 用于返回CHR话单FTP传输开关状态。 取值说明：“开”：表示FTP上传开关开启，CHR单据将通过SFTP协议传输到命令指定的FTP服务器。“关”：表示FTP上传开关关闭。 |
| IP版本号      | 用于返回FTP服务器的IP版本号。                                                                      |
| FTP服务器IP地址 | 用于返回FTP服务器的IP地址。                                                                       |
| FTP服务器端口   | 用于返回FTP服务器的IP端口。                                                                       |
| FTP用户名     | 用于返回FTP服务器的用户名。                                                                        |
| 目标目录       | 用于返回FTP服务器的目的传输地址。                                                                     |
| 发送间隔       | 用于返回每次进行CHR单据传输的时间间隔。                                                                  |
