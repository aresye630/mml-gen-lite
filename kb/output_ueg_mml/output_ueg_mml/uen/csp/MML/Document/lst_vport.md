# 查询Pod端口(LST VPORT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询Pod端口的配置信息。

- 若需要查询所有Pod全部端口的配置信息，请不要输入任何参数。
- 若需要查询某个Pod端口的详细信息，输入“Pod名称”参数。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                                                                                                |
|:-----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VMNAME     | Pod名称  | 可选必选说明：可选参数。 参数含义：用于指示系统需要查询哪个Pod上的端口信息。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：操作员可以使用LST PODINFO命令查询获得。若不输入，则表示该参数不作为查询的限制条件。                                                                                                                                             |
| VMPORTNAME | 端口名称   | 可选必选说明：可选参数。 参数含义：用于指示系统需要查询哪个端口名称的信息。 取值范围：“Base1(Base1)”～“Base4(Base4)”：Base平面内网口。“Fabric1(Fabric1)”～“Fabric4(Fabric4)”：Fabric平面内网口。“VNIC1(VNIC1)”～“VNIC30(VNIC30)”：外出网口。“PXE_Base1(PXE_Base1)”～“PXE_Base2(PXE_Base2)”：安装加载网口。 默认值：无。 配置原则：若不输入，则表示该参数不作为查询的限制条件。 |

## 使用实例

**实例1**

查询所有Pod全部端口的配置信息。

`LST VPORT:;`

```
%%LST VPORT:;%%
RETCODE = 0  操作成功

操作结果如下
------------
 Pod名称              位置描述     端口名称

 
 cgplite-0            10.10.10.10   Base1   
 cgplite-0            10.10.10.10   Base2   
 cgplite-0            10.10.10.10   Fabric1 
 cgplite-0            10.10.10.10   Fabric2 
 cgplite-0            10.10.10.10   PXE_Base1
 cgplite-0            10.10.10.10   PXE_Base2
 cgplite-1            10.10.10.10   Base1      
 cgplite-1            10.10.10.10   Base2   
 cgplite-1            10.10.10.10   Fabric1 
 cgplite-1            10.10.10.10   Fabric2 
 cgplite-1            10.10.10.10   PXE_Base1
 cgplite-1            10.10.10.10   PXE_Base2
 

(结果个数 = 12)

---    END
```

**实例2**

查询“Pod名称”为“cgplite-0”，“端口名称”为“Base1”的Pod端口配置信息。

`LST VPORT: VMNAME="cgplite-0", VMPORTNAME=Base1;`

```
%%LST VPORT: VMNAME="cgplite-0", VMPORTNAME=Base1;%%
RETCODE = 0  操作成功

操作结果如下
------------
  Pod名称   =  cgplite-0
  位置描述  =  10.10.10.10          
  端口名称  =  Base1
(结果个数 = 1)

---    END
```
