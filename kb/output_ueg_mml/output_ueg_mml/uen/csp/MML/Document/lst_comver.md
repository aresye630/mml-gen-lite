# 查询组件版本配置(LST COMVER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询系统组件的版本配置信息：

- 若需要查询全部的系统组件的版本配置信息，请不要输入任何参数。
- 若需要查询某个Pod上的系统组件的版本配置信息，输入“Pod名称”参数。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                       |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------|
| VMNAME | Pod名称  | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照某个Pod来查询系统组件版本配置信息。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：操作员可以从下拉框获得。若不输入，则表示所有的Pod。 |

## 使用实例

1. 查询所有Pod上系统组件版本配置的所有信息：

   `LST COMVER:;`

   ```
   %%LST COMVER:;%%
   RETCODE = 0  操作成功

   Pod底层软件版本信息
   ----------------------
    Pod名称                   位置描述     当前使用版本  网元ID  工作区1版本  工作区2版本

    
    cgplite-0                 10.10.10.10  1.0.1190912   0       1.0.1190912  NULL       
    cgplite_1                 10.10.10.10  1.0.1190912   0       1.0.1190912  NULL       
    
         
   (结果个数 = 2)

   ---    END
   ```
2. 查询“Pod名称”为“cgplite-0”的系统组件版本配置信息：

   `LST COMVER: VMNAME="cgplite-0``"`

   ```
   %%LST COMVER: VMNAME="cgplite-0";%%
   RETCODE = 0  操作成功

   Pod底层软件版本信息
   ----------------------
        Pod名称  =  cgplite-0
       位置描述  =  10.10.10.10      
   当前使用版本  =  1.0.1190912
         网元ID  =  0
    工作区1版本  =  1.0.1190912
    工作区2版本  =  NULL
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

| 输出项名称   | 输出项解释               |
|:--------|:--------------------|
| Pod名称   | 用于返回进程所在Pod的名称。     |
| 位置描述    | 用于返回Pod的位置信息。       |
| 当前使用版本  | 用于返回Pod当前使用的系统组件版本。 |
| 网元ID    | 用于返回指定的网元。          |
| 工作区1版本  | 用于返回网元工作区1的系统组件版本。  |
| 工作区2版本  | 用于返回网元工作区2的系统组件版本。  |
