# 结束升级观察期(FIN UPGRADEWATCH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

执行此命令会结束所有网元升级观察期后，且无法回退到升级前的版本，请谨慎操作。

该命令用于结束所有网元的升级观察期。

## 注意事项

- 执行此命令后会尝试结束大颗粒服务观察期，即使无网元处于升级观察期状态也会执行此操作。

## 参数说明

无。

## 使用实例

结束升级观察期。

```
%%FIN UPGRADEWATCH:;%%
RETCODE = 0  操作成功

---    END
```

## 输出结果说明

该命令执行正常，会返回操作成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释        | 原因分析                                | 处理建议                           |
|-------:|:-------------|:------------------------------------|:-------------------------------|
| 112004 | 内部错误         | 升级工具处理MML命令异常。                      | 请联系华为技术支持处理。                   |
| 112005 | 无网元处于观察期     | 无网元处于观察期，无需处理。                      | 无需执行结束观察期命令。                   |
| 112006 | 结束某些网元的观察期失败 | 结束大颗粒服务观察期失败。观察期回调接口调用失败。清理观察期数据失败。 | 参考告警的定位信息及失败原因进行处理或联系华为技术支持处理。 |
