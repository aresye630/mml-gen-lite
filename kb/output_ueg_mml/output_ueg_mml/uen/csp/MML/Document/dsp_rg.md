# 查询资源组状态(DSP RG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于请求系统显示资源组状态。

具有相互依赖关系的进程组合称为资源组。资源组包含的进程都必须具有互助进程，也就是资源组也有主备的概念。主资源组里面所有进程可能的状态为主用或者故障，但要确保至少有一个进程状态为主用。备资源组里面所有进程可能的状态为备用或者故障。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                     |
|:-------|:-------|:-----------------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：可选参数。 参数含义：用于请求系统显示某一个网元下的资源组的状态信息；若不输入，则表示所有的网元ID。 取值范围：无。 默认值：无。 配置原则：无。        |
| RGNAME | 资源组名称  | 可选必选说明：可选参数。 参数含义：用于请求系统显示某一个资源组的状态信息；若不输入，则表示所有的资源组名称。 取值范围：长度不超过32的字符串。 默认值：无。 配置原则：无。 |

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                                  |
|:--------|:-----------------------------------------------------------------------------------------------------------------------|
| 网元ID    | 用于返回模块所属的网元ID。                                                                                                         |
| 资源组名称   | 用于返回资源组名称。                                                                                                             |
| 资源组状态   | 用于返回资源组当前状态，资源组处于不同的阶段可能的状态有以下几种：“主用”：正常情况的主用状态。“备用”：正常情况的备用状态。“故障”：故障状态。“预处理”：资源组主备倒换时状态。“回退”：当预处理失败时，进入回退状态。         |
| 模块号     | 用于返回资源组所包含的模块号信息。                                                                                                      |
| 主备状态    | 用于返回资源组所包含的模块的状态信息：“未指配”：模块的状态为未指配。在模块启动的初期，模块处于尚未指配主用或备用的状态。“备用”：模块的状态为备用。“主用”：模块的状态为主用。“无效”：模块的可用状态为未就绪或故障时，主备状态为无效。 |
| 模块类型    | 用于返回资源组所包含的模块的类型信息。                                                                                                    |
| Pod名称   | 用于返回资源组所包含模块的Pod的名称。                                                                                                   |
| 位置描述    | 用于返回资源组所包含模块的Pod的位置信息。                                                                                                 |
