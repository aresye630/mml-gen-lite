## 命令功能

**须知** 

本命令执行之后，操作不当会导致网元数据丢失，请慎重使用。

本命令用于将**EXP MES**命令导出的二进制格式数据文件压缩包导入到数据库。导入前可以通过执行**LST EXPINFO**命令查看当前系统中存在的二进制格式数据文件压缩包名称和压缩包中包含网元的信息。

本命令的使用场景为：在现网环境中执行**EXP MES**命令导出二进制格式数据文件后，在对应的镜像环境中通过执行本命令将数据导入到镜像环境的数据库中，进行问题定位分析。

## 注意事项

- 本命令会自动导入网元0的数据。
- 在现网环境中不能执行本命令。
- 目标环境必须是源环境的镜像环境，OMU所在Pod的名称，软件的语言、版本号、补丁号、网元列表和节点名一致。

  在进行导入之前，需要在OM Portal界面执行**DSP OMU** 和 **LST OMIP**命令，查询到当前主用节点名所对应的IP信息。通过putty工具登录该IP，进入CGPLite容器，把导入的二进制格式数据文件压缩包上传到目录“/opt/HUAWEI/cgp/workshop/omu/share/backup/exp\_backup”下。
- 本命令导入数据仅包含数据库中表数据，其他的比如存储过程、表结构都没有导入。
- 如果需要导入性能数据，则需要在导出操作时选择导出性能数据，否则会导入失败。这里的性能数据包括话务统计任务和话务统计结果数据。
- 执行本命令可能会破坏数据库中现有的所有数据，请确保执行本命令前已经备份了数据库。
- 在执行本命令之后，请执行**RST OMU**重启OMU服务。

## 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                                                       |
|:--------|:----------|:---------------------------------------------------------------------------------------------------------------------------|
| FNM     | 文件名       | 可选必选说明：必选参数。 参数含义：指定需要导入二进制格式数据文件压缩包的文件名全称。可以通过执行LST EXPINFO命令查看当前系统中存在的二进制格式数据文件压缩包文件名。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。 |
| MEIDS   | 网元ID      | 可选必选说明：可选参数。 参数含义：指定文件中需要导入的网元ID，不同的网元ID之间用空格隔开。如果该参数不输入，则要导入指定压缩包中的所有网元。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                |
| CHECK   | 导入校验      | 可选必选说明：必选参数。 参数含义：指定是否校验网元导入结果。 取值范围： “YES(是)”：校验网元导入结果，导入失败则终止导入。“NO(否)”：不校验网元导入结果，尽量导入所有网元的数据。 默认值：“YES(是)”。 配置原则：无。     |
| NEEDPDS | 导出/导入性能数据 | 可选必选说明：必选参数。 参数含义：指定是否需要导入性能数据。不导入性能数据不影响OMU正常运行。 取值范围： “YES(是)”：导入性能数据。“NO(否)”：不导入性能数据。 默认值：“NO(否)”。 配置原则：无。              |

## 使用实例

将文件Exp\_TabFile\_20140305144310.tar.gz中网元ID为0和5的表数据导入数据库，导入性能数据，校验网元导入结果：

`IMP MES: FNM="Exp_TabFile_20140305144310.tar.gz", MEIDS="0 5", CHECK=YES, NEEDPDS=YES;`

```
%%IMP MES: FNM="Exp_TabFile_20140305144310.tar.gz", MEIDS="0 5", CHECK=YES, NEEDPDS=YES;%%
RETCODE = 0  操作成功

```
