## 命令功能

**须知** 

该操作可能会影响模块上运行的业务，产生呼损，请慎重使用该命令。

本命令用于对一个模块的配置信息进行修改或者调整。在本命令中，系统通过“Pod名称”、“网元ID”、“模块号”关键参数的组合来唯一标识一条模块数据记录。

本命令支持以下多种方式对某个网元下的模块进行批量或单独修改：

- 当修改某个网元下的所有模块的属性，只输入“网元ID”和要修改的属性。
- 当修改某个网元下某个Pod上的所有模块属性，则“Pod名称”、“网元ID”都必须输入。
- 当修改具体某个Pod模块的属性时，则“Pod名称”、“网元ID”和“模块号”都必须输入。

## 注意事项

- 本命令支持分权分域。当用户没有修改模块的操作权限，不允许执行本命令。
- 使用本命令修改“配置管理状态”时，必须输入“模块号”。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                      |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VMNAME | Pod名称  | 可选必选说明：可选参数。 参数含义：标识一条模块数据的关键字段之一，用于指定需要对哪个Pod的数据记录进行修改或者调整。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：操作员可以使用LST MODULE命令查询获得。                                                                                                                                                                                                      |
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：标识一条模块数据记录的关键字段之一，用于指定需要对哪个网元ID的数据记录进行修改或者调整。 取值范围：0～1023 默认值：无。 配置原则：操作员可以使用LST MODULE命令查询获得。                                                                                                                                                                                                          |
| MN     | 模块号    | 可选必选说明：可选参数。 参数含义：标识一条模块数据记录的关键字段之一，用于指定需要对哪个模块号的数据记录进行修改或者调整。 取值范围：0～4294967294 默认值：无。 配置原则：操作员可以使用LST MODULE命令查询获得。                                                                                                                                                                                                     |
| ADMST  | 配置管理状态 | 可选必选说明：可选参数。 参数含义：用于标识模块的配置管理状态。用于人为设置指定的模块是否提供服务。当确定要对模块的接入服务进行控制时，修改模块该参数的配置。 取值范围：“LOCK(锁定)”：当模块支持管理状态，且模块不需要再接入新的服务时选择该参数。“UNLOCK(未锁定)”：模块默认管理状态为未锁定，当支持管理状态的模块已经锁定，但又需要接入新的服务时选择该参数。 默认值：无。 系统初始设置值：“UNLOCK(未锁定)”。 配置原则：无。                                                                                           |
| LODMOD | 加载模式   | 可选必选说明：可选参数。 参数含义：用于标识模块的加载模式，用于对模块启动时加载文件的模式的设置。 取值范围：“AUTOMATIC(自动)”：选择该加载模式可以提高加载效率，该模式下启动时，系统自动检测Pod本地保存的文件是否与OMU侧的文件一致，两者一致时优先从Pod本地启动，否则从OMU重新加载。“MANDATORY(强制)”：该模式下模块启动时，不检查Pod本地文件信息，强制从OMU加载并更新本地文件。当模块“加载模式”设置为“MANDATORY(强制)”，在进行第一次加载的60分钟后，加载模式会恢复为“AUTOMATIC(自动)”。 默认值：无。 系统初始设置值：“AUTOMATIC(自动)”。 配置原则：无。 |

## 使用实例

修改“网元ID”为“0”的所有模块，把“加载模式”设置为“强制”。

`MOD MODULE: MEID=0, LODMOD=MANDATORY;`

## 输出结果说明

命令执行正常，会返回命令执行成功的信息，输出项说明如表1所示。

| 输出项名称   | 输出项解释                                                                                                  |
|:--------|:-------------------------------------------------------------------------------------------------------|
| 网元ID    | 用于返回执行本命令后，需要联机设定数据到的网元。该网元ID固定为0。                                                                     |
| 模块号     | 用于返回模块的模块号。                                                                                            |
| Pod名称   | 用于标识服务实例对应Pod的名称。                                                                                      |
| 位置描述    | 用于返回模块所在Pod的位置信息。                                                                                      |
| 主/备状态   | 用于返回模块的主用或者备用状态。                                                                                       |
| 设定结果描述  | 用于返回执行本命令后，网元0中各个模块的联机设定结果。当结果不为“操作成功”时，需要检查下对应的模块状态是否正常，对故障模块进行相应的处理操作，具体请参见产品文档中的《故障处理》手册中的“模块故障”章节。 |

| 32100015 | 执行此命令修改模块的配置管理状态时必须输入模块号。          | 修改模块的配置管理状态时未输入模块号。 | 请使用LST MODULE命令查询对应的模块号。              |
|   478001 | 该资源未配置对应的应用。                       | 输入的模块配置信息错误。        | 请使用DSP MODULE命令查询模块，确认参数信息，再执行修改模块操作。 |
