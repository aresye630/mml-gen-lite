# 查询电子标签（DSP ELABEL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明
- 参考信息

## 命令功能

本命令用于查询硬件电子标签。

## 注意事项

- 本命令仅支持部分机型，具体以当前实际环境为准。
- 在查询“FAN(风扇模块)”的电子标签时，部分机型需要输入槽位号，具体以当前实际环境为准。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                                                              |
|:----------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OBJTYPE   | 对象类型   | 可选必选说明：必选参数。 参数含义：查询的对象类型。 取值范围： ALL(所有电子标签)CHASSIS(机框)BLADE(计算板)SMM(管理模块)PSU(电源)FAN(风扇模块) 默认值：无。 配置原则：无。                                                                                                                                                         |
| CHASSISID | 机框号    | 可选必选说明：当“对象类型”为“CHASSIS(机框)”、“BLADE(计算板)”、“SMM(管理模块)”、“PSU(电源)”、“FAN(风扇模块)”时，为必选参数。 参数含义：机框号。 取值范围：长度不超过255的字符串。 默认值：无。 配置原则：无。                                                                                                                                   |
| SLOTID    | 槽位号    | 可选必选说明：当“对象类型”为“BLADE(计算板)”时，为必选参数。当“对象类型”为“FAN(风扇模块)”时，为可选参数。 参数含义：槽位号。 取值范围： Slot1(计算板1)Slot2(计算板2)Slot3(计算板3)Slot4(计算板4)Slot5(计算板5)Slot6(计算板6)Slot7(计算板7)Slot8(计算板8) 默认值：无。 配置原则：无。                                                                            |
| SMMID     | 管理模块名称 | 可选必选说明：当“对象类型”为“SMM(管理模块)”时，为必选参数。 参数含义：管理模块名称。 取值范围： SMM1(管理模块1)SMM2(管理模块2) 默认值：无。 配置原则：无。                                                                                                                                                                       |
| PSUID     | 电源名称   | 可选必选说明：当“对象类型”为“PSU(电源)”时，为必选参数。 参数含义：电源名称。 取值范围： PSU1(电源1)PSU2(电源2)PSU3(电源3)PSU4(电源4)PSU5(电源5)PSU6(电源6)PSU7(电源7)PSU8(电源8) 默认值：无。 配置原则：无。                                                                                                                         |
| FANID     | 风扇名称   | 可选必选说明：当“对象类型”为“FAN(风扇模块)”时，为必选参数。 参数含义：风扇名称。 取值范围： Fan1(风扇模块1)Fan2(风扇模块2)Fan3(风扇模块3)Fan4(风扇模块4)Fan5(风扇模块5)Fan6(风扇模块6)Fan7(风扇模块7)Fan8(风扇模块8)Fan9(风扇模块9)Fan10(风扇模块10)Fan11(风扇模块11)Fan12(风扇模块12)Fan13(风扇模块13)Fan14(风扇模块14)Fan15(风扇模块15)Fan16(风扇模块16) 默认值：无。 配置原则：无。 |
