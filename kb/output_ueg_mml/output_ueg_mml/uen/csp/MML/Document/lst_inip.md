# 查询内网IP(LST INIP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询所有网元部署的Pod内网口IP信息。

- 若需要查询所有Pod的内网口IP信息，请不要输入任何参数。
- 若需要查询指定Pod的内网口IP信息，输入“Pod名称”参数。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                 |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：可选参数。 参数含义：用于指示系统需要查询哪个网元的Pod的数据。 取值范围：0～1023。 默认值：无。 配置原则：操作员可以使用LST ME命令查询获得。若不输入，则表示该参数不作为查询的限制条件。         |
| VMNAME | Pod名称  | 可选必选说明：可选参数。 参数含义：用于指示系统需要查询哪个Pod的数据。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：操作员可以使用LST PODINFO命令查询获得。若不输入，则表示该参数不作为查询的限制条件。 |

## 使用实例

**实例1**

查询所有网元部署的Pod内网口IP信息。

`LST INIP:;`

```
%%LST INIP:;%%
RETCODE = 0  操作成功

内网IP信息
----------
 网元ID  Pod名称          端口名称   内网IP       

 0       cgplite-0        Base1    172.16.191.0 
 0       cgplite-0        Base2    172.16.191.0 
 0       cgplite-0        Fabric1  172.18.191.0 
 0       cgplite-0        Fabric2  172.19.191.0 
 0       cgplite-1        Base1    172.16.191.8 
 0       cgplite-1        Base2    172.16.191.8 
 0       cgplite-1        Fabric1  172.18.191.8 
 0       cgplite-1        Fabric2  172.19.191.8 
(结果个数 = 8)

---    END
```

**实例2**

查询“Pod名称”为“cgplite-0”的Pod的内网口IP信息。

`LST INIP: VMNAME="cgplite-0";`

```
%%LST INIP: VMNAME="cgplite-0";%%
RETCODE = 0  操作成功

内网IP信息
----------
 网元ID  Pod名称        端口名称   内网IP      

 0       cgplite-0      Base1    172.16.191.0
 0       cgplite-0      Base2    172.16.191.0
 0       cgplite-0      Fabric1  172.18.191.0
 0       cgplite-0      Fabric2  172.19.191.0
(结果个数 = 4)

---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。输出结果说明如表1所示。

命令执行异常，请联系华为技术支持处理。

| 输出项名称   | 输出项解释            |
|:--------|:-----------------|
| 网元ID    | 用于返回Pod所在的网元。    |
| Pod名称   | 用于返回Pod的名称。      |
| 端口名称    | 用于返回端口的名称。       |
| 内网IP    | 用于返回Pod的内网口IP信息。 |
