# 删除用户(RMV USER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**须知** 

该操作将删除用户，同时清除该用户所有信息。

本命令用于删除一个已创建的OM Portal用户。

#### 注意事项

不支持删除默认用户。

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                             |
|:--------|:-------|:---------------------------------------------------------------------------------|
| USRNAME | 用户名称   | 可选必选说明：必选参数。 参数含义：用户名称，可在OM Portal的“安全 > 用户管理”查询 取值范围：长度不超过32个字符。 默认值：无。 配置原则：无。 |

#### 使用实例

删除用户test01：

```
%%RMV USER: USRNAME="test01";%% 
RETCODE = 0  操作成功  

---    END
```
