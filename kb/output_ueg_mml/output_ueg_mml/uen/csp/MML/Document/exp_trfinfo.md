## 命令功能

该命令用于导出性能统计资源信息。

**说明** 

在遇到性能统计结果丢失或者不可信时，收集性能内部统计信息，支撑问题定位。导出文件保存在OMU服务器上，其路径为：“/opt/HUAWEI/cgp/workshop/omu/share/export/pm/perf\_trf\_info”。导出类型分为两种：

- 内部统计信息：“导出信息类型”为“STAINNER（内部统计信息）”，则导出性能内部信息，包括话统流量、北向信息等。
- 性能树信息：“导出信息类型”为“TREE（性能树）”，则导出指定网元的测量性能树信息。

## 注意事项

- 当性能统计结果延迟时，系统会自动生成性能树信息，并保存在OMU服务器上，其路径为：“/opt/HUAWEI/cgp/workshop/omu/share/export/pm/perf\_trf\_info/NE/NEx（x代表网元ID）”。
- 频繁执行导出性能树操作，会影响系统运行性能，可能会导致性能统计出结果延迟或者不可信。
- 系统仅保留最新导出的性能统计资源信息。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                            |
|:----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------|
| EXPTYPE   | 导出信息类型 | 可选必选说明：必选参数。 参数含义：导出的信息类型。 取值范围： “STAINNER（内部统计信息）”“TREE（性能树）” 默认值：无。 配置原则：无。                                                   |
| BEGINDATE | 开始日期   | 可选必选说明：必选参数。 参数含义：仅当本命令中“导出信息类型”为“STAINNER（内部统计信息）”时，该参数有效。用于标识导出内部统计信息的起始日期。 取值范围：无。 默认值：无。 配置原则：无。                            |
| ENDDATE   | 结束日期   | 可选必选说明：必选参数。 参数含义：仅当本命令中“导出信息类型”为“STAINNER（内部统计信息）”时，该参数有效。用于标识导出内部统计信息的结束日期。 取值范围：无。 默认值：无。 配置原则：无。                            |
| MEID      | 网元ID   | 可选必选说明：必选参数。 参数含义：仅当本命令中“导出信息类型”为“TREE（性能树）”时，该参数有效。用于标识导出性能树的网元ID 。 取值范围：0～1023 默认值：无。 配置原则：无。                                 |
| MUID      | 测量单元ID | 可选必选说明：必选参数。 参数含义：仅当本命令中“导出信息类型”为“TREE（性能树）”时，该参数有效。用于标识导出性能树的测量单元；若不输入，则导出的性能树包含该网元下所有的测量单元。 取值范围：0～2147483646。 默认值：无。 配置原则：无。 |

## 使用实例

1. 导出内部统计信息，开始日期是2011/7/13，结束日期是2011/7/14：

   `EXP TRFINFO: EXPTYPE=STAINNER, BEGINDATE=2011&07&13, ENDDATE=2011&07&14;`

   ```
   %%EXP TRFINFO: EXPTYPE=STAINNER, BEGINDATE=2011&07&13, ENDDATE=2011&07&14;%%
   RETCODE = 0  操作成功

   ---    END
   ```
2. 导出性能树信息，网元ID为6，所有的测量单元：

   `EXP TRFINFO: EXPTYPE=TREE, MEID=6;`

   ```
   %%EXP TRFINFO: EXPTYPE=TREE, MEID=6;%%
   RETCODE = 0  操作成功

   ---    END
   ```
