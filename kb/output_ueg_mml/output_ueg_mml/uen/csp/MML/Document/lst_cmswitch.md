# 查询跨网元命令开关(LST CMSWITCH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询当前系统配置的跨网元命令开关状态。

在升级观察期内，执行跨网元命令可能会影响升级回退，因此系统对这些命令做了限制，默认状态下不允许执行跨网元命令，只有开关打开时才允许执行。

## 注意事项

所有网元共用一个跨网元命令开关。

## 参数说明

无。

## 使用实例

查询跨网元命令开关：

`LST CMSWITCH:;`

```
%%LST CMSWITCH:;%%
RETCODE = 0  操作成功

操作结果如下
----------
开关状态  =  关
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                               |
|:--------|:----------------------------------------------------|
| 开关状态    | 用于返回跨网元命令开关状态。 “OFF(关)”：跨网元命令开关关闭 “ON(开)”：跨网元命令开关打开 |
