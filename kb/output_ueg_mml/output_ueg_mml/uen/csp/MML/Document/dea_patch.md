# 去激活补丁(DEA PATCH)

## 命令功能

**须知** 

本命令执行之后，补丁状态将迁移回去激活状态。该操作将中断该补丁涉及的业务，并可能影响整个系统的正常运行，请慎重使用。

该命令用于请求系统对指定的模块执行去激活补丁操作，命令成功运行后参数指定的补丁状态变为去激活态。去激活补丁之前可以用**ACT PATCH**命令来激活补丁。

该命令的使用场景为：在对程序打补丁的过程中，当已经激活的补丁出现运行异常，或者影响系统其他业务正常运行时，需要退出补丁程序，运行原有的节点程序，操作员可以使用该命令实现这一目的。

如果不输入模块号，表示对整个网元下所有补丁状态处于激活态的进程进行去激活操作。

## 注意事项

- 操作人员在使用命令**ACT PATCH**将补丁激活后，可以使用此命令对补丁进行去激活操作，使补丁状态迁移回去激活状态。该操作将中断该补丁涉及的业务，并可能影响整个系统的正常运行。请操作员在执行该命令时仔细确认任务的可行性。
- 只能去激活处于激活状态的补丁。
- 去激活成功后补丁状态变成去激活。
- 网元ID为0时是对平台模块进行操作，网元ID>4时是对业务网元的模块进行操作。
- 在去激活补丁时主备进程都需要进行去激活。AS参数不选择时，同时去激活主备进程。
- 当部分进程加载失败，报文中显示“补丁正在初始化，操作失败”时，节点正在进行补丁恢复。请稍后重试此操作，如果重试三次问题仍然没有解决，请联系华为技术支持处理。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：标识一个补丁操作的关键字段之一，用于请求系统需要对哪一个网元实例实施操作。 取值范围： 0～1023。 默认值： 无。 配置原则：操作员可以通过在LST ME命令查询获得所有的网元实例ID。                                                                                   |
| MN     | 模块号    | 可选必选说明：必选参数。 参数含义：标识一个补丁操作的关键字段之一，用于请求系统需要对指定网元下哪一个模块实施操作。 取值范围：0～4294967294。 默认值：无。 配置原则：操作员可以通过在MEID指定的网元实例上使用LST MODULE命令查询模块号及对应的模块类型，然后根据模块号进行补丁操作。默认对指定网元下所有相应的模块实施补丁操作。对指定模块实施操作一般只用于故障处理场景。 |
| AS     | 主备标记   | 可选必选说明：必选参数。 参数含义：用于请求系统需要对指定模块的主或备进程实施补丁操作。 取值范围： “ACTIVE(主)”“STANDBY(备)” 默认值：无。 配置原则：其值域类型为枚举类型。默认对主、备进程都实施补丁操作。对指定模块的主备实施操作一般只用于故障处理场景。                                                          |
| PNAME  | 补丁名称   | 可选必选说明：必选参数。 参数含义：用于标识补丁名称。取值范围： 长度不超过32的字符串。 默认值：无。 配置原则：命名规则是SPHXXX或HPXXXX，其中SPHXXX表示热补丁，HPXXXX表示紧急热补丁。以补丁名称进行操作时，是对补丁包中所有单个补丁文件进行相应操作。该参数大小写不敏感。                                                 |

## 使用实例

1. 去激活主用模块补丁，“网元ID”为“0”，“模块号”为“3017”，“主备标志”为“主”，“补丁名称”为“SPH001”:

`DEA PATCH: MEID=0, MN=3017, AS=ACTIVE, PNAME="SPH001";`

```
%%DEA PATCH: MEID=0, MN=3017, AS=ACTIVE, PNAME="SPH001";%%
RETCODE = 0  操作成功

操作结果如下
------------
  网元ID  =  0
  模块号  =  3017
主备标记  =  主
补丁名称  =  SPH001
补丁状态  =  去激活
操作结果  =  成功
(结果个数 = 1)

---    END
```

2. 去激活备用模块补丁，“网元ID”为“5”，“主备标志”为“备”，“补丁名称”为“SPH001”:

`DEA PATCH: MEID=5, AS=STANDBY, PNAME="SPH001";`

```
%%DEA PATCH: MEID=5, AS=STANDBY, PNAME="SPH001";%%
RETCODE = 0  操作成功

操作结果如下
------------
  网元ID  =  5
  模块号  =  1000
主备标记  =  备
补丁名称  =  SPH001
补丁状态  =  去激活
操作结果  =  成功
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                                                             |
|:--------|:------------------------------------------------------------------------------------------------------------------|
| 网元ID    | 该参数标识了网元ID。                                                                                                       |
| 模块号     | 该参数标识了所加载补丁的模块号。                                                                                                  |
| 主备标记    | 用于请求系统需要对指定模块的主或备进程实施补丁操作。其值域类型为枚举类型。 取值说明： “ACTIVE(主)”“STANDBY(备)”                                               |
| 补丁名称    | 标识补丁操作的关键字段之一，命名规则是SPHXXX或HPXXXX，其中SPHXXX表示热补丁，HPXXXX表示紧急热补丁。以补丁名称进行操作时，是对补丁包中所有单个补丁文件进行相应操作。                     |
| 补丁状态    | 补丁操作的结果信息之一，用于表示补丁单元的运行状态。其值域范围为枚举类型。 取值说明： “运行”：表示补丁安装成功。“激活”：表示补丁安装过程中的中间状态。“去激活”：表示补丁安装过程中的中间状态。“空闲”：表示没有安装补丁。 |
| 操作结果    | 用于描述补丁操作的结果。                                                                                                      |
