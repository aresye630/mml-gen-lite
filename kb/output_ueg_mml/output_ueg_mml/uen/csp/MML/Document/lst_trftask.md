# 查询性能统计任务信息（LST TRFTASK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明
- 参考信息

## 命令功能

本命令用于查询当前系统登记到网管以及网元上的性能测量任务、测量对象的详细信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                        |
|:-------|:-------|:------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：用于唯一标识一个网元实例。 取值范围：0～1023。 默认值：无。 配置原则：无。 |

## 使用实例

查询网元ID为0的性能测量任务信息:

`LST TRFTASK: MEID=0;`

## 输出结果说明

| 输出项名称     | 输出项解释                                      |
|:----------|:-------------------------------------------|
| 测量对象类ID   | 测量对象类的ID，唯一标识一个测量对象类。                      |
| 网管测量对象类ID | 网管测量对象类的ID，唯一标识一个网管测量对象类。                  |
| 测量对象类名称   | 测量对象类的名称。                                  |
| 测量单元ID    | 测量单元的ID，唯一标识一个测量单元。                        |
| 网管测量单元ID  | 网管测量单元的ID，唯一标识一个网管测量单元。                    |
| 测量单元名称    | 测量单元的名称。                                   |
| 指标计算类型    | 指标计算类型所属: “主机”： 由主机计算的指标。“OMU”： 由OMU计算的指标。 |
| 测量周期（分钟）  | 测量的周期，分为以下几类：5分钟，15分钟，30分钟，60分钟，1440分钟     |
| 任务所属      | 该测量任务的任务所属。                                |
| 对象实例个数    | 测量单元上添加的测量对象实例的个数。                         |
