# 同步配置数据（SYN CMDATA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

同步配置数据需要一定时间完成，且会导致CPU产生一定的波动，如在业务高峰期需谨慎执行。

本命令用于将配置中心的数据同步到网元服务，然后显示同步结果。

## 注意事项

同步配置数据需要一定时间完成，且会导致CPU产生一定的波动，如在业务高峰期需谨慎执行。

## 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                                       |
|:------------|:-----------|:---------------------------------------------------------------------------------------------------------------------------|
| MEID        | 网元ID       | 可选必选说明：必选参数 参数含义：要获取配置数据的网元ID。 取值范围：1~65535。 默认值：无。 配置原则：可以使用LST MELST ME命令查询获得。                                           |
| SERVICENAME | 服务名称       | 可选必选说明：必选参数 参数含义：配置对象所属的服务名称。 取值范围：长度不超过256的字符串。 默认值：无。 配置原则：可以参考STR CMCRC命令的执行结果。                                         |
| MOCNAME     | 配置对象名称     | 可选必选说明：必选参数 参数含义：配置对象名称。 取值范围：长度不超过256的字符串。 默认值：无。 配置原则：可以参考STR CMCRC命令的执行结果。                                              |
| SUBSERV     | 订阅服务名称     | 可选必选说明：可选参数 参数含义：订阅服务名称。 取值范围：字符串类型，长度不超过256个字符。 默认值：无。 配置原则： 可以参考STR CMCRC命令的执行结果。订阅服务名称、订阅服务IP地址类型、订阅服务端口号需同时设置或同时不设置取值。 |
| IPTYPE      | 订阅服务IP地址类型 | 可选必选说明：可选参数 参数含义：订阅服务IP地址类型。 取值范围： IPv4(订阅服务IPv4地址)IPv6(订阅服务IPv6地址) 默认值：无。 配置原则：订阅服务名称、订阅服务IP地址类型、订阅服务端口号需同时设置或同时不设置取值。    |
| IPV4ADD     | 订阅服务IPv4地址 | 可选必选说明：该参数在“订阅服务IP地址类型”配置为“IPv4(订阅服务IPv4地址)”时为条件必选参数。 参数含义：订阅服务IPv4地址。 取值范围：有效的IPv4地址。 默认值：无。 配置原则： 可以参考STR CMCRC命令的执行结果。  |
| IPV6ADD     | 订阅服务IPv6地址 | 可选必选说明：该参数在“订阅服务IP地址类型”配置为“IPv6(订阅服务IPv6地址)”时为条件必选参数。 参数含义：订阅服务IPv6地址。 取值范围：有效的IPv6地址。 默认值：无。 配置原则： 可以参考STR CMCRC命令的执行结果。  |
| PORT        | 订阅服务端口号    | 可选必选说明：可选参数 参数含义：订阅服务端口号。 取值范围：0~65535。 默认值：无。 配置原则： 可以参考STR CMCRC命令的执行结果。订阅服务名称、订阅服务IP地址类型、订阅服务端口号需同时设置或同时不设置取值。          |
