# 禁用端口（DEA PORT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**须知** 

该命令**可能造成网络不通，导致上报网口故障相关告警，使用该网口的业务可能会受到影响**。

本命令用于禁用硬件设备的指定端口。

#### 注意事项

- 本命令只针对高密度框式服务器适用，仅在容灾场景和业务调测场景下使用。
- 本命令只支持外出标卡，不支持LOM卡。

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                          |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------|
| SRN    | 框号     | 可选必选说明：必选参数。 参数含义：用于指示系统需要禁用哪个框号上的端口。 取值范围：长度不超过64的字符串。 默认值：无。 配置原则：无。                                                                        |
| SN     | 槽号     | 可选必选说明：必选参数。 参数含义：用于指示系统需要禁用哪个槽号上的端口。 取值范围：长度不超过64的字符串。 默认值：无。 配置原则：无。                                                                        |
| CARDN  | 所在位置   | 可选必选说明：必选参数。 参数含义：用于指示系统需要禁用的端口所在网卡的位置。 取值范围： Card1(网卡1)Card2(网卡2)Card3(网卡3)Card4(网卡4)Card5(网卡5)Card6(网卡6)Card7(网卡7)Card8(网卡8) 默认值：无。 配置原则：无。 |
| PORTN  | 端口号    | 可选必选说明：必选参数。 参数含义：用于指示系统需要禁用的端口号。 取值范围： 1(端口1)2(端口2)3(端口3)4(端口4) 默认值：无。 配置原则：无。                                                               |

#### 使用实例

禁用指定单板的指定端口，例如禁用0框1槽上Card8的端口1。“框号”输入“0”，“槽号”输入“1”，“所在位置”选择“Card8(网卡8)”，“端口号”选择“1(端口1)”，则执行结果示例如下：

```
%%DEA PORT: SRN="0", SN="1", CARDN=Card8, PORTN=1;%%
RETCODE = 0  操作成功

---    END
```
