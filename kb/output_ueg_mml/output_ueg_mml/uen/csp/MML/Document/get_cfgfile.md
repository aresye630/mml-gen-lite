# 获取配置同步文件（GET CFGFILE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令是将网元的配置对象数据生成XML文件，通过SFTP协议把XML文件同步到命令中指定的目录上。

## 注意事项

本命令链接SFTP服务器默认使用22端口，如果实际环境中SFTP服务器端口非22需要使用**ADD FWRULE**命令增加转发规则。

## 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                                                                   |
|:--------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------|
| MEID    | 网元ID      | 可选必选说明：必选参数 参数含义：要获取配置数据的网元ID。 取值范围：0~65535。 默认值：无。 配置原则：无。                                                                            |
| MOCLIST | 配置对象      | 可选必选说明：可选参数 参数含义：要收集配置数据的配置对象名称。 取值范围：长度不超过1000的字符串。 默认值：无。 配置原则：只能是一个配置对象的名称。                                                         |
| NELABEL | 对象标签      | 可选必选说明：可选参数 参数含义：配置对象的标签。 取值范围：0~4294967294的整数。 默认值：无。 配置原则：用户不要填写，否则可能会无法导出配置数据。                                                      |
| IP      | 服务器IP     | 可选必选说明：必选参数 参数含义：SFTP服务器IP地址。 取值范围：IPV4或IPV6地址。 默认值：无。 配置原则：无。                                                                         |
| USR     | 用户名       | 可选必选说明：必选参数 参数含义：SFTP用户名。 取值范围：长度不超过1000的字符串。 默认值：无。 配置原则：无。                                                                           |
| PWD     | 密码        | 可选必选说明：必选参数 参数含义：SFTP用户密码。 取值范围：长度不超过1000的密码。 默认值：无。 配置原则：无。                                                                           |
| DSTF    | 服务端文件目录路径 | 可选必选说明：必选参数 参数含义：用于标识SFTP传输的目标路径（含文件名）。 取值范围：长度不超过1000的字符串。 默认值：无。 配置原则：文件名不能为点（.）或点点（..）；不能包含如下特殊字符：* : ? " < > | ' ` ! $ # & ( )和空格。 |
