# 设置OMU软参(SET OMUSFTD)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为专家维护命令，用于设置OMU软参值。

该命令仅适用于开局阶段调测或者维护的操作场景，当需要获取环境上特定信息时，操作员可以使用该命令实现这一目的。

## 注意事项

无。

## 使用实例

1. 打印内存泄漏检测软调的帮助信息：

   `SET OMUSFTD: MN=11, CTRL=1, PM0=0;`
2. 打开MIT模块的内存泄漏检测开关：

   `SET OMUSFTD: MN=11, CTRL=1, PM0=2;`
3. 关闭MIT模块的内存泄漏检测开关：

   `SET OMUSFTD: MN=11, CTRL=1, PM0=1;`
4. 打印MIT模块的内存泄漏信息：

   `SET OMUSFTD: MN=11, CTRL=1, PM0=4;`
5. 打印MIT模块的管道流控软调的帮助信息：

   `SET OMUSFTD: MN=11, CTRL=2, PM0=0;`
6. 打印MIT模块的管道流控丢包记录：

   `SET OMUSFTD: MN=11, CTRL=2, PM0=1;`
7. 设置MIT模块的管道流控丢包记录打印周期，打印周期为5秒：

   `SET OMUSFTD: MN=11, CTRL=2, PM0=2, PM1=5;`
8. 清除MIT模块的管道流控丢包记录：

   `SET OMUSFTD: MN=11, CTRL=2, PM0=3;`
