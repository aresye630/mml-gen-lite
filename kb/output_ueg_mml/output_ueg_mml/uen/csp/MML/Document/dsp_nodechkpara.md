# 查询节点检测参数（DSP NODECHKPARA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询节点内存检测、节点CPU过载检测、inotify实例检测、inotify监控检测、节点信号量集检测、节点文件句柄检测、关键部件检测、IP互串冲突预防、节点内存故障检测和智算单元资源检测参数。

## 注意事项

为了防止大容量场景下NRSAgent同时访问NRSMaster出现性能问题，当NRSAgent启动后会随机暂停一段时间（最多3分钟），建议在NRSAgent启动3分钟后再执行本命令进行查询。

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|:-------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RESTYPE      | 资源类型   | 可选必选说明：必选参数。 参数含义：用于指定需要查询的资源类型。 取值范围： “SERVER(服务器)”：用于裸机容器部署场景。 “VM(虚拟机)”：用于虚拟机容器部署场景。 默认值：无。 配置原则：裸机容器场景，需要设置为“SERVER(服务器)”。                                                                                                                                                                                                                                                                                                              |
| PARAMTYPE    | 参数类型   | 可选必选说明：必选参数。 参数含义：用于指定需要查询的参数类型。 取值范围： “CHKNODEMEM(节点内存检测)”“CHKNODECPU(节点CPU过载检测)”“CHKINOTIFYINSTANCE(inotify实例检测)”“CHKINOTIFYWATCH(inotify监控检测)”“CHKNODESEMARRAY(节点信号量集检测)”“CHKNODEFILEHANDLE(节点文件句柄检测)”“CHKPORT(网卡检测)”“CHKIPROUTE(IP路由检测)”“CHKKEYFILE(关键文件检测)”“CHKPART(分区过载检测)”“CHKPROC(进程数检测)”“CHKINODE(inode使用率检测)”“CHKCNTSTOR(容器存储空间检测)”“CHKIPCONFLICT(IP互串冲突预防)”“CHKSMCU(智算单元资源检测)” 默认值：无。 配置原则：裸机容器部署场景无需配置该参数。                      |
| APPID        | 网元ID   | 可选必选说明：NA。 参数含义：用于指定系统需要查询的网元ID。 取值范围：0～65535 默认值：无。 配置原则：裸机容器部署场景无需配置该参数。                                                                                                                                                                                                                                                                                                                                                                  |
| VDUTYPE      | 虚拟机类型  | 可选必选说明：可选参数。 参数含义：无。 取值范围：无。 默认值：无。 配置原则：裸机容器部署场景无需配置该参数。                                                                                                                                                                                                                                                                                                                                                                                   |
| PARAMTYPE_SV | 参数类型   | 可选必选说明：必选参数。 参数含义：用于指定裸机容器部署场景需要查询的参数类型。 取值范围： “CHKNODEMEM(节点内存检测)”“CHKNODECPU(节点CPU过载检测)”“CHKINOTIFYINSTANCE(inotify实例检测)”“CHKINOTIFYWATCH(inotify监控检测)”“CHKNODESEMARRAY(节点信号量集检测)”“CHKNODEFILEHANDLE(节点文件句柄检测)”“CHKPORT(网卡检测)”“CHKIPROUTE(IP路由检测)”“CHKKEYFILE(关键文件检测)”“CHKPART(分区过载检测)”“CHKPROC(进程数检测)”“CHKINODE(inode使用率检测)”“CHKCNTSTOR(容器存储空间检测)”“CHKIPCONFLICT(IP互串冲突预防)”“CHKNODEMEMFAULT(节点内存故障检测)”“CHKSMCU(智算单元资源检测)” 默认值：无。 配置原则：无。 |
| SERVERNAME   | 服务器名称  | 可选必选说明：可选参数。 参数含义：用于指定裸机容器部署场景系统需要查询除“CHKNODEMEM(节点内存检测)”以外的其他参数类型的服务器名称。 取值范围：无。 默认值：无。 配置原则： 若不输入，则表示查询所有节点的信息。 裸机容器部署场景，用户可以通过LST SERVER命令查看相应的服务器名称。                                                                                                                                                                                                                                                                                    |
| NODENAME     | 节点名称   | 可选必选说明：可选参数。 参数含义：用于指示系统需要查询哪个节点的检测参数。 取值范围：不超过128位字符串。 默认值：无。 配置原则：裸机容器部署场景无需配置该参数。                                                                                                                                                                                                                                                                                                                                                        |

## 使用实例

1. 查询所有节点“节点CPU过载检测”参数信息。

   ```
   %%DSP NODECHKPARA: RESTYPE=SERVER, PARAMTYPE_SV=CHKNODECPU;%%
   RETCODE = 0  操作成功
   操作结果如下
   ------------------------ 
   资源类型      参数类型           节点IP        服务器名称        检测开关  检测阈值（%）  

   服务器        节点CPU过载检测    10.0.0.1      paas-10.0.0.1      开启        66             
   服务器        节点CPU过载检测    10.0.0.2      paas-10.0.0.2      开启        66             
   服务器        节点CPU过载检测    10.0.0.3      paas-10.0.0.3      开启        66 
   (结果个数 = 3)

   ---    END
   ```
2. 查询“服务器名称”为“paas-10.0.0.1”的“节点CPU过载检测”参数信息。

   ```
   %%DSP NODECHKPARA: RESTYPE=SERVER, PARAMTYPE_SV=CHKNODECPU, SERVERNAME="paas-10.0.0.1";%%
   RETCODE = 0  操作成功
     
   操作结果如下 
   ------------
            资源类型  =  服务器
            参数类型  =  节点CPU过载检测
              节点IP  =  10.0.0.1

            检测开关  =  开启
       检测阈值（%）  =  85
   (结果个数 = 1)

   ---    END
   ```
3. 查询所有节点“节点内存故障检测”参数信息。

   ```

   ```
4. 查询所有节点“网卡检测”参数信息。

   ```

   RETCODE = 0  操作成功
   ```
