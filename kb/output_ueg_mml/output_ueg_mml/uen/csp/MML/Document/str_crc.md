## 命令功能

**须知** 

整表校验需要大约5分钟完成，且会导致CPU产生一定的波动，如在话务高峰期需谨慎执行，请务必在华为技术支持人员的指导下操作。

本命令用于对OMU数据文件与主机数据、OMU数据文件与OMU数据库的数据进行CRC校验，检查数据是否一致，可以定位到数据表级的数据错误。

本命令的使用场景为：

- 日常维护过程中，如备份与恢复时，使用本命令检查OMU数据文件与节点的数据或OMU数据文件与OMU数据库的数据是否一致。
- 每天凌晨3:00，OMU自动执行本命令对所有数据表进行CRC校验，若存在不一致的情况，系统上报“ALM-4756 数据表自动CRC校验错误”告警。

## 注意事项

- 本命令只能定位到数据表级的数据错误，如果需要定位到记录级错误，请参考命令**CHK DATA**。
- 执行本命令后，系统进行CRC校验期间，不要执行其他命令，否则可能会引起CRC校验结果不一致。

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                                                                                    |
|:---------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MN       | 模块号     | 可选必选说明：可选参数。 参数含义：标识要进行数据校验模块，用于指定需要对哪一模块进行校验。使用LST MODULE命令查询模块号。 取值范围：0~4294967294。 默认值：无。 配置原则：模块号必须是属于“网元ID”为“0”的模块号。若不输入，则表示校验“网元ID”为“0”的所有模块。                                                                                     |
| TID      | 表号      | 可选必选说明：可选参数。 参数含义：标识要进行数据校验表，用于指定需要对哪张表进行校验。 取值范围：下拉列表中给出的所有表。 默认值：无。 配置原则：若不输入，则表示校验属于指定模块的所有表。                                                                                                                                        |
| CRCTYPE  | 校验类型    | 可选必选说明：可选参数。 参数含义：用于指定校验类型。 取值范围：“FILE(数据文件和主机校验)”：表示OMU数据文件和主机数据校验。“DB(数据库和数据文件校验)”：表示OMU数据库和OMU数据文件校验。“ALL(全部)”：包括以上两种方式。 默认值：“FILE(数据文件和主机校验)”。 配置原则：升级、打补丁或重大配置调整时，必须选择“ALL(全部)”。此时，系统校验时间最长，尽量在非忙时执行。联机设定失败时可仅执行“FILE(数据文件和主机校验)”。 |
| PROCTYPE | 处理类型    | 可选必选说明：可选参数。 参数含义：用于标识校验结果类型。 取值范围：“NORMAL(正常命令)”：表示需要显示校验的详细信息。“INNER(内部命令)”：表示只显示最终的返回码。 默认值：“NORMAL(正常命令)”。 配置原则：无。                                                                                                                  |
| SSR      | 显示成功记录  | 可选必选说明：可选参数。 参数含义：用于标识是否显示校验数据一致性成功的表记录。 取值范围：“YES(显示成功记录)”：表示显示校验数据一致性成功的表记录。“NO(不显示成功记录)”：表示不显示校验数据一致性成功的表记录。 默认值：“NO(不显示成功记录)”。 配置原则：无。                                                                                              |
| CRCAMU   | 是否校验AMU | 可选必选说明：可选参数。 参数含义：仅当本命令中的“校验类型”参数选择为“FILE(数据文件和主机校验)”或“ALL(全部)”时该参数有效。用于指定是否对AMU表进行校验。AMU表是保存在OMU侧的网元的临时配置表。 取值范围：“TRUE(是)”：表示对AMU表进行校验。“FALSE(否)”：表示不对AMU表进行校验。 默认值：“FALSE(否)”。 配置原则：该参数选择“TRUE(是)”时“模块号”参数由于系统限制不能输入取值。               |

处理建议：

- 当校验失败的表为通配符表、模块软参表或公共软参表时，则表ID为NULL，参考如下步骤处理：

  1. 执行**FMT**命令进行格式化操作。
  2. 执行**RST MODULE**命令复位相应模块。
- 当某模块类型的0号表（表描述表）、1号表（表字段描述表）或2号表（索引描述表）CRC校验出错时，请查看报文中“CRC检查结果”是否有表号大于3的校验错误表。
  - 如果有参考如下步骤处理：

    - 如果是数据文件和节点数据的校验错误，参考如下步骤处理：
      1. 收集以下信息：
         1. 登录OM Portal，选择“应用管理 > MML”，根据告警信息中的网元ID，选择对应网元，执行**STR CRC: MN=\*\*,CRCTYPE=ALL;**命令查询不一致的表号，“MN”为CRC不一致的模块号。
         2. 根据**a**中查询到的表号，在OM Portal，选择“应用管理 > MML”执行**DSP TBL:MEID=\*\*,MN=\*\*,STATUS=Active, TABLEID=\*\*, SUBCMD=Table;**命令，查询节点的最大元组数，“TABLEID”为不一致的表号。
         3. 登录OM Portal，选择“应用管理 > MML”，根据告警信息中的网元ID，选择对应网元，执行**CHK DATA: MN=\*\*, TID=\*\*,CRCTYPE=ALL;**命令查询前后台不一致表的记录号。
         4. 登录OM Portal选择“应用管理 > MML”，执行**DSP TBL:MEID=\*\*,MN=\*\*,STATUS=Active, TABLEID=\*\*, SUBCMD= Tuple,TPLID=2;**查询节点记录内容，“TPLID”为**c**中查询不一致的记录号。
         5. 登录OM Portal选择“应用管理 > MML”，执行**EXP MES: MEIDS="\*\*", EXPTYPE=TEXT, TBNAME="\*\*";**命令导出表中的数据，“TBNAME”是**b**中的查询到的表名称。
      2. 确认OMU数据库的数据正确后，执行**SND CRCERR**命令，将指定模块的不一致的表数据设定到节点。
      3. 重新执行**STR CRC**，查看是否仍然存在校验错误。
         - 是 => 请及时联系华为技术支持处理。
         - 否 => 处理完毕。
    - 如果是数据库和数据文件的校验错误，参考如下步骤处理：
      1. 执行**FMT**命令格式化配置数据为配置数据文件。
      2. 重新执行**STR CRC**，校验类型选择“ALL(全部)”，查看报文“文件和数据库间CRC校验统计数据”是否存在不一致。
         - 是 => 请及时联系华为技术支持处理。
         - 否 => 步骤 3
      3. 查看报文“文件和节点间CRC校验统计数据”是否存在不一致。
         - 是 => 请参考数据文件和主机数据的校验错误处理步骤进行处理。
         - 否 => 处理完毕。
  - 如果没有，执行**FMT**命令进行格式化操作，然后执行**RST MODULE**命令复位相应模块。
