# 移除加载扩展包（RMV COMPKG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**须知** 

- 此命令为高危命令，请谨慎使用并联系华为技术支持协助操作。
- 如果涉及组件包的移除，组件包移除成功后CGPLite服务会自动重启，正常情况下重启需要一分钟左右的时间，重启期间CGPLite相关业务不可用。

该命令用于删除网元已加载的扩展域的组件包、适配包。

#### 注意事项

移除加载扩展包会导致扩展域功能不可用。

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                             |
|:-------|:-------|:-----------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：网元ID，可以通过LST ME获取。 取值范围：0～65535 默认值：无。 配置原则：无。 |

#### 使用实例

删除网元ID为5的扩展域的组件包、适配包。

```
%%RMV COMPKG: MEID=5;%%
RETCODE = 0 操作成功
```
