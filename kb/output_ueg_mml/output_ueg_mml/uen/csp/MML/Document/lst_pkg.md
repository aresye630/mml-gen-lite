# 查询包(LST PKG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询网元相关包信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PKGT   | 包类型    | 可选必选说明：可选参数。 参数含义：用于指示系统是按照哪种包类型查询包信息，如：补丁包、版本包等。 取值范围： “PATPKG(补丁包)”：给网元打补丁时使用。“VERPKG(版本包)”：即网元包，在增加网元时使用。“UPGPKG(升级包)”：网元需要升级时使用。“SFTPKG(软件包)”：操作系统和数据库安装包，用来给Pod安装操作系统或数据库用。“MTPKG(维护功能包)”：给网元做特定维护时使用。 默认值：无。 配置原则：若不输入，则表示查询所有类型包的包信息。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| LODFLG | 加载标志   | 可选必选说明：可选参数。 参数含义：用于指示系统是按照加载标志为“LOADED(已加载)”还是“NOTLOADED(未加载)”来查询包信息。 取值范围： “LOADED(已加载)”：即已经通过LOD PKG命令加载到OMU上的软件包。“NOTLOADED(未加载)”：即需要使用但还未通过LOD PKG命令加载到OMU上的软件包。 默认值：无。 配置原则：该参数仅当包类型选择为“SFTPKG(软件包)”时有效。若不输入，则表示查询加载标志为“LOADED(已加载)”的包信息。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| SOFTNM | 软件名称   | 可选必选说明：可选参数。 参数含义：用于指示系统查询指定软件名称的包信息。 取值范围：无。 默认值：无。 配置原则：该参数仅当包类型选择为“SFTPKG(软件包)”时有效。若不输入，则表示查询所有软件包。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |

## 使用实例

**实例1**

查询系统中所有与网元相关的包和已加载的软件包信息。

`LST PKG:;`

```
%%LST PKG:;%%
RETCODE = 0  操作成功

网元相关的包如下
----------------
网元类型  =  MSOFTX3000网元
  包类型  =  版本包
网元版本  =  V200R006C01
文件名称  =  MSOFTX_SRV_V200R006C01.tar
(结果个数 = 1)

软件包如下
----------
 软件名称         软件版本           软件大小  软件状态  使用状态  软件描述                               

 CSP              V200R002C00SPC200  775MB     正常      使用      CSP OMU安装包                          
 UPGTOOLS         V200R002C00SPC200  29MB      正常      未使用    升级工具                               
(结果个数 = 2)

---    END
```

**实例2**

查询网元的版本包信息。

`LST PKG: PKGT=VERPKG;`

```
%%LST PKG: PKGT=VERPKG;%%
RETCODE = 0  操作成功

网元相关的包如下
----------------
网元类型  =  MSOFTX3000网元
  包类型  =  版本包
网元版本  =  V200R006C01
文件名称  =  MSOFTX_SRV_V200R006C01.tar
(结果个数 = 1)

---    END
```

**实例3**

查询已加载的软件包信息。

`LST PKG: PKGT=SFTPKG, LODFLG=LOADED;`

```
%%LST PKG: PKGT=SFTPKG, LODFLG=LOADED;%%
RETCODE = 0  操作成功

软件包如下
----------
 软件名称         软件版本           软件大小  软件状态  使用状态  软件描述

 UPGTOOLS         V200R002C00SPC200  29MB      正常      未使用    升级工具                               
(结果个数 = 2)

---    END
```
