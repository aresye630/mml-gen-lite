# 发送整表数据(SND SPD)

## 命令功能

**须知** 

执行该命令发送整表的数据量大时，会导致CPU产生一定的波动，如在话务高峰期需慎重执行。

本命令用于发送指定表中的数据到主机，使主机和OMU的数据保持一致。

本命令的使用场景为：在维护过程中，当操作员使用**STR CRC**命令对所有的数据表进行CRC校验时，若发现主机与OMU的数据不一致，则可以执行本命令向主机发送主机数据库与OMU数据库中不一致的数据表，使主机数据库的数据与OMU数据库的数据保持一致。

**说明** 

用户可以通过本命令发送某个模块实例中一张表的数据，也可以输入参数“开始记录号”和“结束记录号”发送一张表中的某部分数据。由于格式化文件中按最大元组数为每张表预留存储空间，因此“开始记录号”和“结束记录号”参数的范围检查是按照最大元组数进行的，例如某张表的最大元组数为1024，里面实际有10条记录，使用该命令时令STD=100，ETD=500的用法是正确的。

## 注意事项

本命令执行不当会导致业务中断，执行前请联系华为技术支持确认数据正确性和表数据的依赖关系。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                               |
|:-------|:-------|:-----------------------------------------------------------------------------------|
| MN     | 模块号    | 可选必选说明：必选参数。 参数含义：标识发送数据所在的模块，用于指定需要发送哪一模块的数据到主机。 取值范围：0～4294967294 默认值：无。 配置原则：无。 |
| TID    | 表号     | 可选必选说明：必选参数。 参数含义：标识发送数据所在的表，用于指定需要发送哪一张表的数据到主机。 取值范围：下拉列表中给出的所有表。 默认值：无。 配置原则：无。  |
| STD    | 开始记录号  | 可选必选说明：必选参数。 参数含义：标识数据的起始记录号。 取值范围：0～5000000 默认值：无。 配置原则：无。                        |
| ETD    | 结束记录号  | 可选必选说明：必选参数。 参数含义：标识数据的结束记录号。 取值范围：0～5000000 默认值：无。 配置原则：无。                        |

## 使用实例

发送“模块号”为“200”，“表号”为“TID10”的数据到主机：

`SND SPD: MN=200, TID=TID10;`
