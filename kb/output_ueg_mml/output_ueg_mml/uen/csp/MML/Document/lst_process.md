# 查询进程配置(LST PROCESS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询进程的静态配置信息:

- 若需要查询全部进程的静态配置信息，请不要输入任何参数。
- 若需要查询某个Pod上的进程的静态配置信息，输入“Pod名称”参数。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                           |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| VMNAME | Pod名称  | 可选必选说明：必选参数。 参数含义：用于指示系统需要按照哪个Pod来查询进程的静态配置信息。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：操作员可以通过执行LST PODINFO命令查询获得。若不输入，则表示所有的Pod名称。                     |
| PMID   | 平台模块号  | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个平台模块号来查询进程的静态配置信息，每个进程的平台模块号都是唯一的；若不输入，则表示所有的平台模块号。 取值范围：0～4294967294。 默认值：无。 配置原则：无。                            |
| APPNE  | 网元ID   | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个网元ID来查询进程的静态配置信息；若不输入，则表示所有的网元ID。 取值范围：0～1023。 默认值：无。 配置原则：无。                                                    |
| LCPUID | 模块号    | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个模块号来查询进程的静态配置信息，如果业务模块是主备的，则有两个模块对应该模块号；若不输入，则表示所有的模块号。 取值范围：0～4294967294。 默认值：无。 配置原则：无。                        |
| ADMST  | 配置管理状态 | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个配置管理状态来查询进程的静态配置信息；若不输入，则表示所有的配置管理状态。 取值范围：“LOCK(锁定)”：用于表示该进程不可以提供服务。“UNLOCK(未锁定)”：用于表示该进程可以提供服务。 默认值：无。 配置原则：无。 |
| DESC   | 模块类型   | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个模块类型来查询进程的静态配置信息；若不输入，则表示所有的模块类型。 取值范围：长度不超过200的字符串。 默认值：无。 配置原则：无。                                              |

   `LST PROCESS:;`


## 输出结果说明

| 输出项名称   | 输出项解释                                                            |
|:--------|:-----------------------------------------------------------------|
| Pod名称   | 用于返回进程所在Pod的名称。                                                  |
| 位置描述    | 用于返回进程所在Pod的位置信息。                                                |
| 平台模块号   | 用于返回进程的平台模块号信息，每个进程的平台模块号都是唯一的。                                  |
| 网元ID    | 用于返回进程所属的网元号信息，具体请参考各个业务网元的说明。                                   |
| 模块号     | 用于返回进程所属的模块号信息。如果业务模块是主备的，则有两个模块对应该模块号。                          |
| 配置管理状态  | 用于返回进程是否提供服务： “LOCK(锁定)”：表示该进程不可以提供服务。“UNLOCK(未锁定)”：表示该进程可以提供服务。 |
| 模块类型    | 用于返回进程的模块类型信息。                                                   |
