# 查询级联配置(DSP SCMCONFIG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明
- 参考信息

## 命令功能

该命令用于查询多框环境的级联配置信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询级联配置。

```
%%DSP SCMCONFIG:;%% 
RETCODE = 0  操作成功  

级联基础配置如下 
------------------ 
         级联开关 = 打开 
         主框框号 = 0 
      检测周期(s) = 40
      检测阈值(%) = 20
      恢复阈值(%) = 5
  倒换抑制时间(s) = 2
倒换抑制周期(min) = 1
(结果个数 = 1)  

级联链路配置如下 
-------------- 
主框级联端口                   从框级联端口          
框号-0/槽号-3/网卡-6/端口-1    框号-1/槽号-1/网卡-6/端口-2
框号-0/槽号-4/网卡-6/端口-1    框号-1/槽号-2/网卡-6/端口-2
框号-0/槽号-3/网卡-6/端口-2    框号-2/槽号-1/网卡-6/端口-2
框号-0/槽号-4/网卡-6/端口-2    框号-2/槽号-2/网卡-6/端口-2
框号-0/槽号-3/网卡-7/端口-1    框号-3/槽号-1/网卡-6/端口-2
框号-0/槽号-4/网卡-7/端口-2    框号-3/槽号-2/网卡-6/端口-2 
(结果个数 = 6)  
---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息，输出项如表1所示。

命令执行异常，会返回对应的错误码。错误码列表如表2所示。

| 输出项名称       | 输出项解释               |
|:------------|:--------------------|
| 级联开关        | 级联开关。 打开关闭          |
| 主框框号        | 主框所在的机框号。           |
| 检测周期(s)     | fabric平面BFD协议的检测周期。 |
| 检测阈值(%)     | fabric平面BFD协议的检测阈值。 |
| 恢复阈值(%)     | fabric平面BFD协议的恢复阈值。 |
| 倒换抑制时间(s)   | sRouter倒换抑制时间。      |
| 倒换抑制周期(min) | sRouter倒换抑制时长重置周期。  |
| 主框级联端口      | 级联线连接的主框端口。         |
| 从框级联端口      | 级联线连接的从框端口。         |

|      错误码 | 错误码解释   | 原因分析                   | 处理建议                          |
|---------:|:--------|:-----------------------|:------------------------------|
| 15500515 | 不支持当前操作 | 当级联配置开关为关闭状态时，不支持当前操作。 | 请检查级联配置，如果级联开关为关闭状态，不建议执行该命令。 |
