# 修改数据库密码(MOD DBPWD)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

执行该操作后，数据库登录用户的密码将被修改。

本命令用于修改数据库应用帐号或系统帐号的密码。

本命令的使用场景为：

- 开局结束后，系统管理员应及时修改数据库密码。
- 在日常维护过程中，系统管理员需要定期修改数据库密码。

## 注意事项

在系统升级观察期内，执行MOD DBPWD命令，系统会报错，无法修改数据库密码，请在结束升级观察期后，再修改数据库密码。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                            |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TYPE   | 帐号类型   | 可选必选说明：必选参数。 参数含义：用于标识要修改的数据库帐号类型。 取值范围： “APP(应用帐号)”：数据库应用程序帐号，用户名为“cgp”。“SYS(系统帐号)”：数据库系统帐号，用户名为“sys”。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                          |
| OLD    | 旧密码    | 可选必选说明：必选参数。 参数含义：用于标识数据库系统帐号的旧密码。 取值范围：长度不超过30的字符串。 默认值：无。 配置原则：需要指出的是，由于数据库系统帐号是属于数据库最高管理员级别帐号，从安全性角度考虑，当修改的帐号类型为“SYS(系统帐号)”时，要求提供旧密码。                                                                                                                                                                                                                                                                        |
| NEW    | 新密码    | 可选必选说明：必选参数。 参数含义：用于标识数据库帐号新密码。 取值范围：长度介于8～30之间的字符串。 默认值：无。 配置原则： 新密码只能包含小写字母（a～z），大写字母（A～Z），数字（0～9）及特殊字符（~!@#%^&*()_-+[]{}<>/?|和空格），且需同时包含这四种字符，首字符必须为字母。新密码中不能包含三个或以上连续的字母或数字（区分大小写，如ABC连续，ABc不连续，321不连续）。新密码中不能包含三个或以上连续相同的字母、数字或特殊字符（区分大小写，如AAA相同，AAa不相同）。新密码中不能含如下字符串：“%%”、“+++”、连续两个或者两个以上空格。新密码与旧密码不能相同。密码不能与最近N天系统曾使用的密码相同（N取值范围为：0～365，默认值为90）。密码不能与最近N次系统曾用过的密码相同（N取值范围为：0～10，默认值为5）。密码不能使用弱口令字典中的成员。 |
| CFM    | 确认密码   | 可选必选说明：必选参数。 参数含义：用于标识数据库帐号确认密码，用于用户确认新密码，确认密码应与新密码保持一致。 取值范围：长度介于8～30之间的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                    |

## 使用实例

1. 修改数据库应用程序帐号密码:

   `MOD DBPWD: TYPE=APP, NEW="********", CFM="********";`
2. 修改数据库系统帐号密码:

   `MOD DBPWD: TYPE=SYS, OLD="********", NEW="********", CFM="********";`
