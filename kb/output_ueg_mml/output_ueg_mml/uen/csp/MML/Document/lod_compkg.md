# 加载扩展包（LOD COMPKG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**须知** 

- 此命令为高危命令，请谨慎使用并联系华为技术支持协助操作。
- 如果涉及组件包的加载，组件包加载成功后CGPLite服务会自动重启，正常情况下复位需要一分钟左右的时间，重启期间CGPLite相关业务不可用。

网元采用扩容方式上线扩展域业务，需要执行此命令完成扩展域适配包、组件包的加载。

#### 注意事项

无。

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                                         |
|:-------------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------|
| MEID         | 网元ID    | 可选必选说明：必选参数。 参数含义：网元ID，可以通过LST ME获取。 取值范围：0～65535 默认值：无。 配置原则：无。                                                                             |
| PKGNAME      | 网元包名称   | 可选必选说明：可选参数。 参数含义：上线扩展域网元业务时所需的组件包所在的解决方案包名称。可以在软件中心>软件仓库>应用仓库中查看的软件包名称，如XXX.zip。 取值范围：长度不超过50的字符串。 默认值：无。 配置原则：网元包名称和适配包名称不能同时为空。           |
| PATCHPKGNAME | 网元补丁包名称 | 可选必选说明：可选参数。 参数含义：基于补丁版本上线扩展域网元业务时所需的组件补丁包所在的解决方案包名称，可以在软件中心>软件仓库>应用仓库中查看的软件包名称，如XXX.zip。 取值范围：长度不超过50的字符串。 默认值：无。 配置原则：输入网元补丁包名称时必须输入网元包名称。 |
| OMANAME      | 适配包名称   | 可选必选说明：可选参数。 参数含义：上线扩展域网元业务时所需的适配包所在的解决方案包名称。可以在软件中心>软件仓库>应用仓库中查看的软件包名称，如XXX.zip。 取值范围：长度不超过50的字符串。 默认值：无。 配置原则：网元包名称和适配包名称不能同时为空。           |
| PATCHOMANAME | 补丁适配包名称 | 可选必选说明：可选参数。 参数含义：基于补丁版本上线扩展域网元业务时所需的补丁适配包所在的解决方案包名称，可以在软件中心>软件仓库>应用仓库中查看的软件包名称，如XXX.zip。 取值范围：长度不超过50的字符串。 默认值：无。 配置原则：输入补丁适配包名称时必须输入适配包名称。 |

#### 使用实例

加载网元ID为5，适配包名称为APP\_23.1.X.zip的适配包。

```
%%LOD COMPKG: MEID=5, OMANAME="APP_23.1.X.zip";%%
RETCODE = 0  正在下载适配包

进度报告
--------
已完成 = 20%
(结果个数 = 1)

%%LOD COMPKG: MEID=5, OMANAME="APP_23.1.X.zip";%%
RETCODE = 0  正在推送适配包

进度报告
--------
已完成 = 50%
(结果个数 = 1)

---    END

%%LOD COMPKG: MEID=5, OMANAME="APP_23.1.X.zip";%%
RETCODE = 0  更新堆栈信息

进度报告
--------
已完成 = 60%
(结果个数 = 1)

---    END

%%LOD COMPKG: MEID=5, OMANAME="APP_23.1.X.zip";%%
RETCODE = 0  操作成功

共有18个报告
---    END
```
