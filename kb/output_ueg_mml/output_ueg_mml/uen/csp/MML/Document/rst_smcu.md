# 复位智算单元 (RST SMCU)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

**须知** 

复位智算单元，可能会导致业务受到影响，请慎重使用该命令。

该命令用于复位指定节点的指定智算单元。

## 注意事项

- 业务运行过程中，请慎用此命令。
- 在系统上报ALM-135555 智算单元故障告警且告警不自动清除的情况下，再执行该命令复位故障的智算单元。
- 调用该命令前，请确保需要复位的智算单元上无业务运行。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                             |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------|
| NODEIP | 节点IP   | 可选必选说明：必选参数。 参数含义：用于指示系统需要复位的指定节点的智算单元。 取值范围：不超过128位字符串。 默认值：无。 配置原则：请输入ALM-135555 智算单元故障告警附加信息中的“告警源位置”对应的节点IP。 |
| SCUID  | SCU ID | 可选必选说明：必选参数。 参数含义：用于指示系统需要复位的智算单元。 取值范围：0～128。 默认值：无。 配置原则：请输入ALM-135555 智算单元故障告警定位信息中的“SCU ID”对应的值。             |

## 使用实例

复位智算单元：“节点IP”为“10.0.0.1”，“SCU ID”为“0”。

```
%%RST SMCU: NODEIP="10.0.0.1", SCUID=0;%% 
RETCODE = 0  操作成功  
操作结果如下 
------------
    状态  =  Success 
详细信息  =  操作成功 
(结果个数 = 1)  
---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。输出结果说明如表1所示。

命令执行异常，请联系华为技术支持处理。输出结果说明如表2所示。

| 输出项名称   | 输出项解释                                                         |
|:--------|:--------------------------------------------------------------|
| 状态      | 用于返回复位智算单元操作的状态。 取值范围： “Success”：复位智算单元成功。“Failure”：复位智算单元失败。 |
| 详细信息    | 用于返回复位智算单元操作的详细信息。                                            |

|    错误码 | 错误码解释     | 原因分析                     | 处理建议         |
|-------:|:----------|:-------------------------|:-------------|
| 130013 | 操作失败      | 复位对象不在线、复位对象状态异常或内部执行报错。 | 联系华为技术支持。    |
| 130015 | 没有符合条件的节点 | 没有对应的节点。                 | 请检查节点IP是否正确。 |
| 130018 | 不支持此功能    | 当前场景不支持此功能。              | 当前场景不支持此功能。  |
