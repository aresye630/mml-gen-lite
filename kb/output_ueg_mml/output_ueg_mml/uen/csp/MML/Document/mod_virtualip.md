# 修改浮动IP (MOD VIRTUALIP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**须知** 

执行该命令可能会**导致OM Portal断链以及网管断链，**需使用修改后IP重新登录OM Portal，并重新对接网管。该命令若执行不当，**会导致所有业务中断**。

用于修改登录OM Portal的浮动IP地址。

#### 注意事项

- IPv4不支持变更为IPv6，IPv6不支持变更为IPv4。
- IPv4或IPv6单栈环境可以通过此命令变更为双栈环境。

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                    |
|:-------------|:-------|:------------------------------------------------------------------------|
| IPTYPE       | 浮动IP类型 | 可选必选说明：必选参数 参数含义：浮动IP类型 取值范围： IPv4(IPv4类型)IPv6(IPv6类型) 默认值：无 配置原则：无     |
| IPV4ADDR     | IPv4地址 | 可选必选说明：当浮动IP类型为IPv4时，此为必选参数 参数含义：IPv4地址 取值范围：有效的IPv4地址 默认值：无 配置原则：无     |
| IPV4GW       | IPv4网关 | 可选必选说明：当浮动IP类型为IPv4时，此为必选参数 参数含义：IPv4网关 取值范围：有效的IPv4地址 默认值：无 配置原则：无     |
| NETMASK      | 子网掩码   | 可选必选说明：当浮动IP类型为IPv4时，此为必选参数 参数含义：IPv4子网掩码 取值范围：有效的IPv4子网掩码 默认值：无 配置原则：无 |
| IPV6ADDR     | IPv6地址 | 可选必选说明：当浮动IP类型为IPv6时，此为必选参数 参数含义：IPv6地址 取值范围：有效的IPv6地址 默认值：无 配置原则：无     |
| IPV6GW       | IPv6网关 | 可选必选说明：当浮动IP类型为IPv6时，此为必选参数 参数含义：IPv6网关 取值范围：有效的IPv6地址 默认值：无 配置原则：无     |
| PREFIXLENGTH | 前缀长度   | 可选必选说明：当浮动IP类型为IPv6时，此为必选参数 参数含义：IPv6前缀长度 取值范围：有效的IPv6前缀长度 默认值：无 配置原则：无 |

#### 使用实例

更新当前登录OM Portal的IP为:192.168.40.47，网关为:192.168.40.1，子网掩码为:255.255.255.0：

```
%%MOD VIRTUALIP: IPTYPE=IPv4, IPV4ADDR="192.168.40.47", IPV4GW="192.168.40.1", NETMASK="255.255.255.0";%%
RETCODE = 0  操作成功

---    END
```
