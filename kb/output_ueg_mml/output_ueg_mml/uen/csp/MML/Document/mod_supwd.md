# 修改CGPLite机机用户密码(MOD SUPWD)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于修改CGPLite机机用户密码。

## 注意事项

无

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                         |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NEW    | 新密码    | 可选必选说明：必选参数。 参数含义：用于修改密码时，标识用户输入的新密码。 取值范围：长度不超过32个英文字符。 默认值：无。 配置原则： 密码不能为空。 密码区分大小写。 密码中不能包含有当前帐户名称。 密码中不能包含帐号倒写字符串。 密码中不能含字符串：“%%”、“+++”、连续两个或者两个以上空格。 密码中不能包含三个或三个以上连续的字母或数字（区分大小写，如ABC连续，123连续，ABc不连续，321不连续）。 密码中不能包含三个或以上连续相同的字母、数字或特殊字符（区分大小写，如AAA相同，AAa不相同）。 密码中不能包含英文分号、英文单引号、英文双引号、英文逗号、英文反斜杠和英文等号。 新密码不能与默认密码相同。 |
| CFM    | 确认密码   | 可选必选说明：必选参数。 参数含义：用于修改密码时，标识用户输入的确认密码。该参数的配置原则是：确认密码不能为空，且须与新密码一致。 取值范围：长度不超过32个英文字符。 默认值：无。 配置原则：无。                                                                                                                                                                                                                         |

## 使用实例

修改CGPLite机机用户密码：

`MOD SUPWD: NEW="*****", CFM="*****";`
