# 查询异常系统资源(DSP ABNMSYSRES)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

用于查询系统的异常资源信息。

## 注意事项

- 目前仅支持模块内存异常资源的查询。
- 本命令涉及到的区间划分方式：区间1代表[T，2T)，区间2代表[2T，3T)，区间3代表[3T，5T)，区间4代表[5T，无穷大)。业务进程启动一小时之内，T取值为0小时，业务进程启动在24小时之内，T取值为1小时，其余情况的T可以通过执行本命令，由返回报文的“存活时间过长阈值(小时)”字段获得。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                          |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RESID   | 资源类型   | 可选必选说明：必选参数。 参数含义：用于请求系统显示哪种资源类型的异常系统资源信息。 取值范围： “MDUMEM(模块内存)”：用于查询模块的异常内存信息。 默认值：“MDUMEM(模块内存)”。 配置原则：无。                                                    |
| DSPTYPE | 查询方式   | 可选必选说明：必选参数。 参数含义：用于请求系统按照哪种方式查询异常系统资源信息。 取值范围： “STATINFO(汇总信息)”：用于查询模块异常系统资源的汇总信息。“DETAILINFO(详细信息)”：用于查询模块异常系统资源的详细信息。 默认值：“STATINFO(汇总信息)”。 默认值：无。 配置原则：无。 |
| DESC    | 模块类型   | 可选必选说明：必选参数。 参数含义：用于请求系统显示哪个模块类型的异常系统资源信息。 取值范围：无。 默认值：无。 配置原则：无。                                                                                             |
| VMNAME  | Pod名称  | 可选必选说明：必选参数。 参数含义：用于请求系统查询哪个Pod上的模块的异常系统资源信息。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：操作员可以使用LST MODULE命令查询获得。若不输入，则表示显示所有Pod模块的异常系统资源信息。                              |
| MEID    | 网元ID   | 可选必选说明：必选参数。 参数含义：用于请求系统显示哪个网元的异常系统资源信息。 取值范围：0～1023。 默认值：无。 配置原则：无。                                                                                          |
| MN      | 模块号    | 可选必选说明：必选参数。 参数含义：用于请求系统显示哪个模块号对应的模块的异常系统资源信息。 取值范围：0～4294967294。 默认值：无。 配置原则：无。                                                                              |
| SHOWALL | 显示全部   | 可选必选说明：必选参数。 参数含义：用于请求系统是否显示所有异常系统资源信息。 取值范围： “YES(是)”：显示所有模块的异常系统资源信息。“NO(否)”：只显示存在异常系统资源的模块相关信息。 默认值：“NO(否)”。 配置原则：无。                                       |
