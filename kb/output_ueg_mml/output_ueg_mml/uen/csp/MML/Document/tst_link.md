# 测试连接(TST LINK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于测试指定Pod与OMU Pod连接是否正常。主要在日常通信连接维护中使用。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                         |
|:-------|:-------|:---------------------------------------------------------------------------------------------|
| VMNAME | Pod名称  | 可选必选说明：必选参数。 参数含义：用于指示测试哪个Pod的链路状态。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：操作员可以使用LST PODINFO命令查询获得。 |

## 使用实例

测试Pod“cgplite-0”的链路状态：

`TST LINK: VMNAME="cgplite-0";`

```
%%TST LINK: VMNAME="cgplite-0";%%
RETCODE = 0  操作成功

操作结果如下
------------
连接状态  =  连接正常
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                        |
|:--------|:-------------------------------------------------------------|
| 连接状态    | “连接正常”: Pod与OMU连接正常。 “连接断开”: Pod与OMU连接断开。出现该状态会影响业务，请及时排除故障。 |
