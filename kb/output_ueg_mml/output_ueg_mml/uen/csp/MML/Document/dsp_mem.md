# 查询进程内存数据信息(DSP MEM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该操作有可能查询到内存中敏感数据。

本命令用于请求系统显示进程内存数据信息。

## 注意事项

- 查询用户态内存数据时，支持查询容器类型的AMU和PMU模块。
  - 32位系统下32位进程用户态内存的开始地址范围：0～3G。
  - 64位系统下32位进程用户态内存的开始地址范围：0～4G。
  - 64位系统下64位进程用户态内存的开始地址范围：0～128T。
- 执行本命令需要具有业务管理员操作权限。
- 执行本命令，可能查询到内存中敏感数据，请慎重执行。

## 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                                                |
|:--------------|:---------|:--------------------------------------------------------------------------------------------------------------------|
| VMNAME        | Pod名称    | 可选必选说明：必选参数。 参数含义：用于请求系统显示哪个容器上的进程内存数据信息。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：操作员可以使用LST MODULE命令查询获得。                   |
| MEID          | 网元ID     | 可选必选说明：必选参数。 参数含义：用于请求系统显示哪个网元ID上进程内存数据信息。操作员可以通过执行LST MODULE命令查询获取网元ID。 取值范围：无。 默认值：无。 配置原则：无。                     |
| MN            | 模块号      | 可选必选说明：必选参数。 参数含义：用于请求系统显示哪个模块号的进程内存数据信息。操作员可以通过执行LST MODULE命令查询获取模块号。 取值范围：无。 默认值：无。 配置原则：无。                       |
| STARTADDRHIGH | 开始地址高4字节 | 可选必选说明：必选参数。 参数含义：与开始地址低4字节字段配合使用，用于请求系统显示哪个开始地址的进程内存数据信息。 取值范围：0～2147483647（或h'00000000～h'7fffffff） 默认值：0。 配置原则：无。 |
| STARTADDRLOW  | 开始地址低4字节 | 可选必选说明：必选参数。 参数含义：与开始地址高4字节字段配合使用，用于请求系统显示哪个开始地址的进程内存数据信息。 取值范围：0～4294967295（或h'00000000～h'ffffffff） 默认值：无。 配置原则：无。 |

   `DSP MEM: VMNAME="cgplite-0", MEID=0, MN=3016, STARTADDRLOW=142516212;`
