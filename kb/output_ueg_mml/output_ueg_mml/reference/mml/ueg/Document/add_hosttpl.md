# 增加HOST模板(ADD HOSTTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中增加一个HOST头域模板，HOST头域用于指定访问设备（转发AP或AS）的主机名称。

操作员使用该命令添加HOST模板后，执行**ADD APRULE**命令配置AP转发规则时，只需要签约HOST模板ID即可，从而简化系统配置流程。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                               |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
| ID     | 索引     | 可选必选说明：必选参数 用于标识待增加的HOST模板在系统中的索引。该参数在UIM中唯一，不能重复。 取值范围：1～255 默认值：无。                                                                               |
| HOST   | HOST   | 可选必选说明：必选参数 用于标识AP转发规则中要匹配的HTTP请求消息的HOST头域，即访问设备（转发AP或AS）的主机名称。该参数在UIM中唯一，不能重复。 取值范围：1～127位字符串。 默认值：无。 说明：该参数不区分大小写，在执行LST HOSTTPL命令查询出的报文中为全小写形式。 |

## 使用实例

配置AP转发规则中的HOST头域匹配原则，操作员需要配置以下数据。

1. 增加一个HOST模板，“索引”为“1”，“HOST”为“huawei.com”：

   ```
   ADD HOSTTPL: ID=1, HOST="huawei.com";
   ```
2. 执行**ADD APRULE**命令配置AP转发规则中的HOST头域匹配原则。

   ```
   ADD APRULE: ID=1, HOSTID=1, IMPUE=FALSE, PEID=1;
   ```
