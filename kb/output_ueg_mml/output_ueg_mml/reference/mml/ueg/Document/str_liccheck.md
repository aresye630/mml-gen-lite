## 命令功能

**须知** 

本命令属于高危命令，执行过程中USCDB CPU会升高，执行不当会造成业务呼损或系统严重过载，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于启动License校验，统计相关数量并刷新数据。该命令涉及的License控制项如表1所示。

| License控制项名称     | 部件编码     | 对应License文件控制项缩写编号   |
|:-----------------|:---------|:---------------------|
| 动态合同用户数          | 82200274 | LKW6TUSER01          |
| LTE FE基本软件       | 82203361 | LKQ7FELTEB01         |
| M2M FE基本软件       | 82203684 | LKQ7FEM2M01          |
| HSS FE 用户数量-每用户  | 82301217 | LMI5HSSFEU01         |
| UDM与UEG用户数据协同园区数 | 82200DUS | LKQ7UDMBE12          |

## 注意事项

- 周期性校验与执行该命令触发的校验同一时间只能有一个任务在执行中。
- 同一时间执行该命令触发的校验只能有一个任务在执行中。
- 本命令不支持校验EIR、ENS和UIM网元形态下的License。
- 执行该命令会造成USCDB的DMA模块CPU使用率上涨、进而引起RSU POD、RSU虚机CPU使用率上涨。建议在系统低负荷时执行该命令。

## 参数说明

无。

## 使用实例

启动License校验功能。

```
STR LICCHECK:;
```
