# 增加Diameter路由组(ADD DMRTS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在Diameter路由组表中增加一条路由组数据记录，使UDM实现对Diameter的路由处理及Diameter路由信息分组管理功能，完成对业务的认证和消息的转发。

在该命令中，以下关键参数需要与对端网元（对端局）协商：

- 目标域名
- 应用类型

## 注意事项

- 在系统中，最多允许配置64条路由组记录，其中0～11为系统默认路由组。
- 路由组表中，每条路由组记录对应的“目标域名”和“应用类型”的组合是唯一的。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RTSNAME  | 路由组名称  | 用于标识一个Diameter路由组名称。 取值范围：长度不超过127的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| RN       | 目标域名   | 用于标识一个Diameter路由组的目标域名。系统采用最长匹配原则进行路由选择。例如：若对端A的域名为hss.ims.huawei.com，对端B的域名为hss.ims.huawei.cn，目标域名为hss.ims.huawei.com.cn，则UDM在进行Diameter路由时会将路由信息发送给对端A。 取值范围：长度不超过127的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| APPID    | 应用类型   | 用于标识路由组处理的Diameter消息所对应的接口类型。 取值范围：Cx/Dx(Cx/Dx)：Cx接口用于I-CSCF与IMS-HSS、S-CSCF与IMS-HSS之间，Dx接口用于I-CSCF与IMS-SLF、S-CSCF与IMS-SLF之间。Sh(Sh)：Sh接口用于AS与IMS-HSS之间。S13(S13/S13')：S13接口用于MME和EIR之间，或用于EIR和AAA之间。S13'接口用于S4-SGSN和EIR之间。 S6A/S6D(S6a/S6d)：S6a接口用于MME和SAE-HSS之间，S6d接口用于S4-SGSN和SAE-HSS之间。SWX(SWx)：SWx接口用于AAA和SAE-HSS之间。SLh(SLh)：SLh接口用于GMLC和SAE-HSS之间。Zh(Zh)：Zh接口用于BSF与IMS-HSS之间。Ml(Ml)：Ml接口用于E-CSCF与LRF之间。SLg(SLg)：SLg接口用于GMLC和UTA之间。S6b(S6b)：UIM和P-GW（Public Data Network Gateway）之间的接口。SWm(SWm)：SWm接口位于UIM与ePDG之间，用于完成Non-3GPP接入用户的认证和授权。STa/SWa(STa/SWa)：STa接口位于Non-3GPP接入网关和UIM之间，用于完成可信接入Non-3GPP用户的授权认证。SWa接口位于UIM与非可信网络之间，用于完成用户接入非可信网络的认证。Zn(Zn)：BSF和AP之间的接口，用于AP向BSF获取UE和AP的共享密钥，以及业务访问的USS信息。 默认值：S6A/S6D(S6a/S6d) |
| RTYPE    | 路由组类型  | 用于标识Diameter本端与对端连接时的路由组类型。 取值范围： NORMAL(普通路由组)：普通路由，需要匹配目标域名。DEFAULT(默认路由组)：默认路由，不需要匹配目标域名。 默认值：NORMAL(普通路由组) 说明：在系统进行路由组选择时，若根据“目标域名”找不到对应的域名，系统会选择该“应用类型”对应的默认路由组。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ACTION   | 消息路由方式 | 用于控制本端处理接收的Diameter消息路由方式。 取值范围： LOCAL(本地处理)：系统设置为此选项时处理方式如下：当本端设备接收的消息中不包含目的主机名时，则在本地处理。当本端设备接收的消息中包含目的主机名，但是目的主机名未配置在本端信息表（执行ADD DMLE命令配置）中，则系统返回错误。 RELAY(路由到下一跳)：仅适用于ADD DMLE命令中参数“本端设备类型”取值为“IMS-SLF(IMS-SLF)”的场景。系统设置为此选项，当消息中不包含目的主机名，或者包含但是目的主机名未配置在本端信息表中，则根据路由配置选择对应的对端并转发消息。 默认值：LOCAL(本地处理) 说明：以下处理方式不受该参数影响。如果消息中包含目的主机名，且目的主机名已配置在本端信息表中，则UDM在本地处理。如果消息中包含目的主机名，且目的主机名已配置在对端信息表中，则转发消息到指定的对端（通过MOD DIAMPP命令设置“Diameter协议参数值”参数的“NOTRELAYMSGTODRA(是否关闭给DRA转发消息)”取值来控制是否转发此消息给DRA）。                                                                                                                                                                                                                              |
| SMODE    | 路由选择模式 | 用于标识路由组处理的Diameter消息所对应的路由选择模式。该参数枚举值中描述的优先级是由ADD DMPE命令参数“Diameter对端实体优先级”定义，取值越小优先级越高。 取值范围：POLLING(轮询方式)：对路由组下的所有对端实体轮流选择，即在可用对端之间循环选择。AORS(主备方式)：当前只有一个对端为主用，其余对端都是备用。只有当主用对端失效时，才会选择备用。ACTIVE(激活方式)：从第0个对端开始选择第一个存在激活链路的对端来工作。当该对端所有链路不可用时，则向后选择下一个存在激活链路的对端。ACTIVEWITHPRI(基于优先级的激活方式)：选择优先级最高的一个对端的激活链路来工作，优先级相同的对端中按照ACTIVE激活方式选择。当该对端所有链路不可用时，则向后选择下一个对端的激活链路。POLLINGWITHPRI(基于优先级的轮询方式)：对所有对端轮流选择，始终选择优先级最高的可用对端。存在多个优先级相同的对端时，在这些对端之间轮询选择。 默认值：POLLING(轮询方式)                                                                                                                                                                                                                                                       |
| LOCALNAM | 本端实体名称 | 用于标识一个Diameter本端实体的名称，实现Diameter路由组与Diameter本端实体关联。该参数必须先由ADD DMLE命令定义，然后才能在此处引用。 取值范围：长度不超过127的字符串。 默认值：无。 说明：不同的Diameter路由组记录可以引用相同的本端实体。系统预置的默认Diameter路由组记录，该参数设置为空。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

## 使用实例

增加Diameter路由组，“路由组名称”为“TEST\_RT”，“目标域名”为“huawei.com”，“应用类型”为“S6A/S6D(S6a/S6d)”，“路由选择模式”为“POLLING(轮询方式)”：

```
ADD DMRTS: RTSNAME="TEST_RT", RN="huawei.com", APPID=S6A/S6D, SMODE=POLLING;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 299508 | 目标域名对应的应用类型已经存在，请执行LST DMRTS查看已存在的DMRTS对象。 | 输入的“目标域名”和“应用类型”参数的组合已经存在。 | 根据实际情况，重新输入“目标域名”和“应用类型”参数的取值，确保其取值符合路由组表中，每条路由组记录对应的“目标域名”和“应用类型”的组合是唯一的。已存在的“目标域名”和“应用类型”参数的组合可以执行LST DMRTS命令查询。 |
