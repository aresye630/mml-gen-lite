# 增加M3UA链路集(ADD M3LKS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条M3UA链路集数据记录。在该命令中，以下关键参数需要与对端M3UA信令设备协商：

- 业务模式
- 工作模式

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
|:---------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LSNM     | 链路集名称   | 用于在本局的配置数据库中定义一个M3UA链路集。由于一个M3UA链路集即代表一条M3UA信令路由，因此，本地实体（即本局）与某个相邻目的实体之间只能配置一个M3UA链路集。 取值范围：长度不超过32的字符串。 默认值：无。 说明：需要指出的是：对于操作员在客户端输入的字符串，系统在操作OMU数据库之前将自动进行如下处理：将该字符串中的所有英文字母全部转换成大写、并将该字符串中最左边与最右边的空格删除掉。例如，假设操作员在客户端输入的字符串为“ 区域abc ”，则系统在操作OMU数据库之前将自动将该字符串转换为“区域ABC”。 对于操作员通过本命令配置的某一条具体的数据记录而言，假设该数据记录中“链路集名称”字段的原取值为A，如果操作员后续需要将该字段的取值由A修改为B，则其可以通过MOD M3LKS命令中的“新链路集名称”参数重新进行定义。此时，对于配置数据库中索引了取值为A的所有数据记录的“链路集名称”字段，系统将自动把这些字段的值由A修改为B。                                                                                                                                                                                                                                                                                                                                           |
| ADNM     | 相邻实体名称  | 用于指定与本局存在直达信令路由的目的实体。该参数必须先由ADD M3DE命令定义，然后才能在此处索引。 取值范围：长度不超过32的字符串。 默认值：无。 说明：其配置原则是：在非对等组网模式中，当目的实体为与本局直联的SG时，该SG为相邻目的实体。 在对等组网模式中，无论目的实体为何种设备，均为相邻目的实体。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| SLSM     | 链路选择掩码  | 用于指示本局在该链路集下的多条M3UA链路之间如何实现信令业务的负荷分担。 取值范围： “B0000(链路集选择掩码0)” “B0001(链路集选择掩码1)” “B0010(链路集选择掩码2)” “B0011(链路集选择掩码3)” “B0100(链路集选择掩码4)” “B0101(链路集选择掩码5)” “B0110(链路集选择掩码6)” “B0111(链路集选择掩码7)” “B1000(链路集选择掩码8)” “B1001(链路集选择掩码9)” “B1010(链路集选择掩码10)” “B1011(链路集选择掩码11)” “B1100(链路集选择掩码12)” “B1101(链路集选择掩码13)” “B1110(链路集选择掩码14)” “B1111(链路集选择掩码15)” 默认值：“B1111(链路集选择掩码15)”。 说明：该参数的配置原则是：当某个M3UA链路集内配置的信令链路数仅为1时，该参数可以设为任意有效值。 当某个M3UA链路集内配置的信令链路数为2时，该参数中“1”的个数必须大于或等于1，例如为B0001、B1100、B1111。 当某个M3UA链路集内配置的信令链路数为3～4时，该参数中“1”的个数必须大于或等于2，例如为B0011、B1100、B1111。 当某个M3UA链路集内配置的信令链路数为5～8时，该参数中“1”的个数必须大于或等于3，例如为B1011、B1110、B1111。 当某个M3UA链路集内配置的信令链路数为9～16时，该参数只能设为B1111。 为避免出现同摆的现象，操作员不能将链路集选择掩码（由ADD M3DE命令配置）与各链路集的链路选择掩码设成同一个编码，一般建议将两个掩码中“1”的位置错开。例如，假设链路集选择掩码为0110，则链路选择掩码可设为1001。 |
| TM       | 业务模式    | 本局与M3UA信令设备的对接参数之一，用于指定该M3UA链路集所采用的业务模式。 取值范围： “OVERRIDE(主备用)”：即N+1备份模式，在这种模式中，链路集中仅有一条链路处于激活状态，其余链路则均处于备份状态；当处于激活状态的链路故障时，处于备份状态的某条链路将被立即激活并传输业务。 “LOADSHARE(负荷分担)”：在这种模式中，链路集中所有的链路均处于激活状态，各链路以负荷分担的方式传输业务。 默认值：“LOADSHARE(负荷分担)”。 说明：在本局与M3UA信令设备对接时，对接的链路集其两端的业务模式必须保持一致（一般推荐采用负荷分担模式），否则M3UA链路将不能正常工作。                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| WM       | 工作模式    | 本局与M3UA信令设备的对接参数之一，用于指定该M3UA链路集的工作模式。 取值范围： “ASP(ASP)” “SGP(SGP)” “IPSP(IPSP)” 默认值：无。 说明：该参数的配置原则是：在非对等组网模式中，如果本局为AS应用模式，该参数设为“ASP”。 在非对等组网模式中，如果本局为SG应用模式，该参数设为“SGP”。 在对等组网模式中，例如本局通过M3UA链路（不通过SG转发）直接与MSC、SCP、固定软交换、移动软交换等设备对接时，该参数设为“IPSP”。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| CHLKSCFG | 链路集匹配检测 | 用于指示建立链路的两端是否进行配置正确性检查。 取值范围：  “FALSE(不支持)” “TRUE(支持)” 各参数选项的含义是：支持：表示本端发送的M3UA的ASP UP消息中将携带“源信令点编码”、“目的信令点编码”、“网络指示”的相关信息，如果对端也是HUAWEI设备，并且开启了该功能，将对这些消息进行检测，若检测发现配置有误，则链路不能激活。 不支持：表示不进行配置正确性检查。 默认值：“TRUE(支持)”。 说明：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |

## 使用实例

1、增加M3UA链路集,“链路集名称”为“M3LKS”，“相邻实体名称”为“M3DE”，“业务模式”为“负荷分担”，“工作模式”为“IPSP”：

```
ADD M3LKS: LSNM="M3LKS", ADNM="M3DE", TM=LOADSHARE, WM=IPSP;
```

2、增加M3UA链路集,“链路集名称”为“M3LKS”，“相邻实体名称”为“M3DE”，“业务模式”为“主备用”，“工作模式”为“SGP”：

```
ADD M3LKS: LSNM="M3LKS", ADNM="M3DE", TM=OVERRIDE, WM=SGP;
```

3、增加M3UA链路集,“链路集名称”为“M3LKS”，“相邻实体名称”为“M3DE”，“业务模式”为“负荷分担”，“工作模式”为“ASP”：

```
ADD M3LKS: LSNM="M3LKS", ADNM="M3DE", TM=LOADSHARE, WM=ASP;
```
