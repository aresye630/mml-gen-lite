# 设置话统比对参数（SET SYSSTAT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于在配置数据库中设置话统比对的最少样本值和阈值。

## 注意事项

无。

| SAMPLE | 最少样本数  | 用于设置话统比对的最少样本数，只有测量指标的个数在话统比对周期内大于或者等于最少样本数才对该测量指标的值进行比对，否则不进行比对。  说明： 该最少样本数设置的是5分钟话统周期，如果比较周期为15分钟时， 实际使用的最少样本数=当前设置的最少样本数*3，如果比较周期为30分钟时，实际使用的最少样本数=当前设置的最少样本数*6，如果比较周期为1个小时，实际使用的最小样本数=当前设置的最少样本数*12。 取值范围：1～65535。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| THD1   | 阈值(%)  | 用于设置测量指标变化的阈值，当测量指标的值变化超过这个阈值后，话统比对结果中会显示超过阈值的测量指标数据。 当测量指标为：成功率(%)、位置更新成功响应率(%)、鉴权成功响应率(%)、取消位置登记成功响应率(%)、插入用户数据成功响应率(%)、用户注册状态查询请求成功响应率(%)、S-CSCF注册注销通知请求成功响应率(%)、被叫用户位置查询请求成功响应率(%)、用户鉴权请求成功响应率(%)、网络侧注销请求成功响应率(%)、用户数据更新请求成功响应率(%)、AS读取用户数据请求成功响应率(%)、AS更新透明数据请求成功响应率(%)、AS数据变化订阅请求成功响应率(%)、HSS发起的订阅通知成功响应率(%)。 取值范围为：1～100，单位为：百分比。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| THD2   | 阈值(次)  | 用于设置测量指标变化的阈值，当测量指标的值变化超过这个阈值后，话统比对结果中会显示超过阈值的测量指标数据。 当测量指标为：操作请求(次)、系统失败(次)。实际比对时，使用的阈值=当前查询出来的阈值*实际选择的话统周期/5分钟。 取值范围为：1～10000，单位为：次。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

## 使用实例

设置话统比对的阈值，在进行比对的话统周期内，当“全MAP测量”的“位置更新流程(0)”的“成功率(%)”下降超过5%，比对结果会显示比较前后的“成功率(%)”指标值。“测量单元”为“ALLMAP(全MAP测量)”，“测量对象”为“UpdateLocation(位置更新流程(0))”，“测量指标”为“PR(成功率(%))”，“阈值(%)”设置为“5”。

SET SYSSTAT: MU=ALLMAP, MO=UpdateLocation, ETY=PR, THD1=5;

返回结果如下：

