# 查询公共参数(LST PUBPRM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于在配置数据库中查询公共参数数据的配置信息：

- 若需要查询全部公共参数数据记录的概要信息，请不要输入任何参数。
- 若需要查询某些公共参数数据记录的概要信息，请输入“参数”参数。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                       |
|:-------|:-------|:-------------------------------------------|
| ID     | 参数     | 用于指示系统需要按照哪个参数标识来查询公共参数数据；若不输入，则表示所有的参数标识。 |

## 使用实例

查询公共参数，“参数”为“1”：

```
LST PUBPRM: ID=P1;
```

返回结果如下：

```
    %%LST PUBPRM: ID=P1;%%                      
    RETCODE = 0  操作成功                       
                                                
    公共参数                                    
    --------                                    
        参数 = 1                              
    参数名称 = TCAP对话状态机个数                     
          值 = 40000  
      默认值 = 40000                     
                                                
    (结果个数 = 1)                              
                                                
    ---    END
```

## 输出结果说明

| 输出项名称   | 输出结果解释           |
|:--------|:-----------------|
| 参数      | 表示公共参数表中参数标识。    |
| 参数名称    | 表示公共参数的简要用途描述名称。 |
| 值       | 表示公共参数的取值。       |
| 默认值     | 表示公共参数的缺省值。      |
