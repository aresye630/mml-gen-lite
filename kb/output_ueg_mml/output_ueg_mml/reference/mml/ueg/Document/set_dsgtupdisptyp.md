# 设置DSG五元组分发类型(SET DSGTUPDISPTYP)

## 命令功能

该命令用于设置DSG的SCTP及LDAP五元组的分配方式。

## 注意事项

- 该命令在USCDB 25.1.0版本不生效，执行本命令后会上报错误码“797000 操作数据库时发生异常”。
- 执行该命令时，如果“业务基值端口”（通过**LST DSGSCTPPARA**命令查询）配置超过“30000”，则不允许设置DSG的SCTP及LDAP五元组为“通配”方式。
- 在执行该命令将“非通配”改为“通配”之前，请务必保证先进行工程改造，经华为技术支持确认后，才能执行该命令。
- 本命令执行时，建议不要将“通配”改为“非通配”，当前不支持此场景下的工程改造。
- 如果由于误操作执行该命令修改了“五元组分发类型”，请联系华为技术支持处理。
- 系统在初始化时已经自动配置的初始值如下所示：

  ```
  五元组分发类型  =  通配
  ```
- 当“五元组分发类型”为“非通配”时，不支持通过**EXP MML**命令导出此配置，避免通过本网元导出的数据配置新安装的网元将“五元组分发类型”修改为“非通配”，影响性能。
- 该命令不允许进行批操作。
- UDM不支持该命令。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                  |
|:------------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------|
| TUPDISPTYPE | 五元组分发类型 | 用于标识DSG的SCTP及LDAP五元组分配方式。 取值范围：SPECIFIC（非通配）：表示五元组中指定DSG类型的IP作为本端IP地址。GENERAL（通配）：表示五元组中使用“0.0.0.0”或“0:0:0:0:0:0:0:0”作为本端IP地址。 默认值：无。 |

## 使用实例

设置DSG的SCTP及LDAP五元组的分配方式为“通配”。

```
SET DSGTUPDISPTYP: TUPDISPTYPE=GENERAL;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                                       | 原因分析                                              | 处理建议                                                                |
|-------:|:------------------------------------------------------------|:--------------------------------------------------|:--------------------------------------------------------------------|
| 302537 | DSGSCTPPARA中设置的业务基值端口超过30000，不能使用通配方式，请通过LST DSGSCTPPARA查询。 | “业务基值端口”（通过LST DSGSCTPPARA命令查询）配置超过“30000”。       | 通过执行SET DSGSCTPPARA命令修改“业务基值端口”的值不超过“30000”，再执行SET DSGTUPDISPTYP命令。 |
| 302569 | 五元组分发类型改成非通配模式时，非通配模式的五元组条数超过最大值。                           | 当五元组分发记录数（DSG总个数*DSG的IP总个数*2）大于5000条时，不能修改成非通配模式。 | 当五元组分发记录条数超过5000条时，不能修改成非通配模式。                                      |
