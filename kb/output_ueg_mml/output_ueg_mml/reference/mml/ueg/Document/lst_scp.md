# 查询系统配置参数(LST SCP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询系统配置参数的配置信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                   |
|:-------|:-------|:-------------------------------------------------------|
| SYSCP  | 系统配置参数 | 此参数用于设置系统配置参数。 取值范围：SYSPARA(系统参数)。 缺省值：无。 说明：该参数是可选参数。 |

## 使用实例

查询系统配置参数的配置信息。

```
LST SCP:;
```

```
%%LST SCP:;%%
RETCODE = 0  操作成功

操作结果如下
------------
系统配置参数  =  系统参数
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释       |
|:--------|:------------|
| 系统配置参数  | 用于返回系统配置参数。 |
