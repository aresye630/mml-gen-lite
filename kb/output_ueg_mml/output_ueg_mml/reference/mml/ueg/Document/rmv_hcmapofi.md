# 删除HSS CDMA MAP信息(RMV HCMAPOFI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除HSS模拟CDMA MAP信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                     |
|:-------|:-------|:-------------------------|
| LEX    | 本地实体标识 | 本地实体标识。 取值范围：0～15 默认值：无。 |

## 使用实例

删除HSS模拟CDMA MAP信息。LEX为0。

`RMV HCMAPOFI: LEX=0;`
