# 设置3GPP AAA事件日志格式(SET EVENTLOG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

- UDM-UIM作AAA认证功场景：该命令用于对Non-3GPP用户的鉴权日志信息进行打印设置。
- UDM-UIM作GBA认证功能场景：该命令用于对USIM/ISIM卡用户的鉴权日志信息进行打印设置。

为方便维护人员对Non-3GPP用户、USIM/ISIM卡用户消息的情况进行分析，UDM-UIM需要支持打印这些的重要鉴权信息，例如：时间戳、IMSI及错误码等。操作员执行**SET EVENTLOG**命令后，维护人员可通过UDM-UIM打印的日志信息获取到用户接入网络的概况，同时根据鉴权失败的用户数据，了解用户接入失败的原因，进而制定相应解决策略，为现网出现的类似问题提供参考依据。

若维护人员需要详细了解日志命名、日志存储路径及日志内容等信息，请参考3GPP AAA事件日志格式管理 > 相关概念。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

- 启用日志打印功能后，会对UDM-UIM性能有所影响，如：ACF模块的CPU占用率升高，影响程度可忽略不计。
- 对于STa接口的DER消息，系统初始配置为：成功和失败日志消息都打印。
- 对于Ut接口的GBA认证结果消息，系统初始配置为：只打印失败日志消息。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IF      | 接口     | 用于指定待打印日志信息的接口名称。 取值范围：STa(STa)：STa接口位于HSGW和UDM-UIM之间，用于完成Non-3GPP用户的认证和授权。Wa/Wm(Wa/Wm)：Wa接口位于UDM-UIM与BRAS/AC之间，Wm接口位于UDM-UIM与PDG/TTG之间，用于传递用户信息和计费信息，以授权用户接入IWLAN网络。Ut(Ut)：Ut接口位于USIM/ISIM卡用户和UDM-UIM之间，用于在执行补充业务操作时使用GBA认证方法对用户进行认证，以保证用户的合法性和安全性。 默认值：无。 配置原则：该参数在当前版本仅支持配置为“STa(STa)”和“Ut(Ut)”。                                                                                                                                                                                             |
| MSG     | 消息     | 用于指定待打印日志信息的消息类型。 取值范围：DER(DER)：仅当“接口”参数为“STa(STa)”时，该参数有效。DER消息通过STa接口传递，HSGW通过DER消息与UDM-UIM进行交互，完成Non-3GPP用户身份认证。RADIUSAUTHENTICATION(RADIUSAUTHENTICATION)：仅当“接口”参数为“Wa/Wm(Wa/Wm)”时，该参数有效。RADIUS鉴权消息通过Wa/Wm接口传递，（BRAS/AC）/PDG/TTG通过RADIUS消息与UDM-UIM进行交互，完成IWLAN用户身份认证。ProxyAccounting(ProxyAccounting)：仅当“接口”参数为“Wa/Wm(Wa/Wm)”时，该参数有效。UDM-UIM提供代理功能时，将接收到的计费消息转发到指定归属服务器。GBA(GBA)：仅当“接口”参数为“Ut”时该参数有效。UDM-UIM采用GBA认证方法对用户进行认证，确保用户的合法性和安全性。 默认值：无。 配置原则：该参数在当前版本仅支持配置为“DER(DER)”和“GBA(GBA)”。 |
| SCOPE   | 范围     | 用于指定“消息”的处理结果。例如：UDM-UIM打印处理成功的DER消息的日志信息。 取值范围：FAIL(失败)：打印处理失败的消息的日志信息。SUCCESS(成功)：打印处理成功的消息的日志信息。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                      |
| ISPRINT | 是否打印   | 用于指定是否打印日志信息。 取值范围：NO(NO)：不打印日志信息。YES(YES)：打印日志信息。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                       |

## 使用实例

设置日志打印功能，携带以下参数：

- “接口”为“STa(STa)”
- “消息”为“DER(DER)”
- “范围”为“SUCCESS(成功)”
- “是否打印”为“YES(YES)”

执行命令如下：

```
SET EVENTLOG: IF=STa, MSG=DER, SCOPE=SUCCESS, ISPRINT=YES;
```
