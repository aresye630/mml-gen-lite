# 删除HLRSN与本局信息(RMV HLRSNOFI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条HLRSN与本局信息的对应关系数据。

## 注意事项

当执行该命令删除HLRSN与本局信息的对应关系数据时，会造成用户不能正常使用业务，请谨慎操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                |
|:-------|:-------|:--------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 标识HLRSN与本局信息记录的关键字段，用于指定删除哪条HLRSN与本局信息记录，操作员可以使用LST HLRSNOFI命令查询获得。 |

## 使用实例

删除一条HLRSN与本局信息的对应关系数据，“HLR序列号”为“1”。命令如下：

```
RMV HLRSNOFI: HLRSN=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                   | 原因分析                | 处理建议                                            |
|-------:|:----------------------------------------|:--------------------|:------------------------------------------------|
| 264053 | 指定的HLRSN不存在，请执行LST HLRSNOFI查询已经配置的HLRSN | “HLR序列号”参数对应的数据不存在。 | 使用LST HLRSNOFI命令查询后，重新确认要删除哪条HLRSN与本局信息的对应关系数据。 |
