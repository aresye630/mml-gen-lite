# 设置系统参数(SET SYS)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会影响网管上的网元形态及性能指标，因此执行该命令前，需要与华为技术支持确认后才可以实施，且未执行完成时不允许连续执行该命令。

本命令用于设置系统参数。

## 注意事项

- 修改“系统功能”的值可能会导致网管清除历史数据。因此，修改“系统功能”的操作务必谨慎。 修改“系统功能”的值后，需要在网管上对CGP先执行同步网元配置数据，再执行自动发现核心网网元。
- 该命令不允许进行批操作。
- 在GSM/UMTS/EPS网络和IMS网络分离融合的场景下，使用**ADD ME**增加两个UDM网元：一个UDM网元实现GSM/UMTS/EPS中HLR、SAE-HSS的功能；另外一个实现IMS网络中IMS-HSS的功能。在安装FE插件包时，“FE加载模式”应选为“MAT（多应用类型）”。

  其中，IMS-HSS网元的“系统功能”必须配置为“IMS-HSS”。如果将“系统功能”配置为“HSS9860”，将导致全局数据加载失败。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
|:-----------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SYSFUNC    | 系统功能   | 系统功能用于指定网元在网管上的网元形态。 取值范围： “SAE-HSS(SAE-HSS)”“GU-HLR(GU-HLR)”“HSS9860(HSS9860)”“IMS-HSS(IMS-HSS)”“ENS(ENS)”“UEIR(UEIR)”“SLF(SLF)”“LRF(LRF)”“UIM(UIM)” 缺省值：无。 说明：指定网元形态后，网管系统上的性能指标ID显示为对应网元形态下的网管ID。网元形态和网管ID的对应关系可以在support网站下载ReleaseDoc获取。以“系统功能”设置为“HSS9860(HSS9860)”网元形态举例，下载ReleaseDoc后，在“zh>19.网管适配包加载指导书>iManagerOSS_HSS9860_MATCH_CHS_版本号>07.NorthBound>版本号+性能数据指标列表”查看。 “SAE-HSS(SAE-HSS)”：iManagerOSS_SAE-HSS_MATCH_CHS_版本号“GU-HLR(GU-HLR)”：iManagerOSS_GU-HLR-FE_MATCH_CHS_版本号“HSS9860(HSS9860)”：iManagerOSS_HSS9860_MATCH_CHS_版本号“IMS-HSS(IMS-HSS)”：iManagerOSS_HSS_MATCH_CHS_版本号“ENS(ENS)”：iManagerOSS_ENS_MATCH_CHS_版本号“UEIR(UEIR)”：iManagerOSS_UEIR_MATCH_CHS_版本号“SLF(SLF)”：iManagerOSS_HSS_MATCH_CHS_版本号“LRF(LRF)”：iManagerOSS_HSS9860_MATCH_CHS_版本号“UIM(UIM)”：iManagerOSS_UDM-UIM_MATCH_CHS_版本号 |
| FEPLUGTYPE | FE插件类型 | 当“系统功能”选择为“HSS9860(HSS9860)”时，该参数用于指定FE与BE对接的DCI接口类型 取值范围： “HSS9860(HSS9860)”“IMS-HSS(IMS-HSS)” 缺省值：HSS9860(HSS9860)。 说明：可选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |

## 使用实例

将“系统功能”设置为“HSS9860(HSS9860)”，执行如下命令：

`SET SYS: SYSFUNC=HSS9860;`
