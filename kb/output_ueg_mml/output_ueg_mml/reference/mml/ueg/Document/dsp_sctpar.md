# 显示SCTP偶联运行信息(DSP SCTPAR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于请求系统显示指定SCTP协议偶联的运行信息。操作员利用此数据信息来调试参数，找出偶联中的错误。

## 注意事项

无。

## 参数说明

| 参数ID   | 参数名称   | 参数描述                                                                                   |
|:-------|:-------|:---------------------------------------------------------------------------------------|
| MN     | 模块号    | 用于请求系统显示哪个BSG模块内的SCTP偶联运行信息。 取值范围：1～1023 默认值： 无。 说明： 无。                                |
| AID    | 偶联号    | 用于请求系统显示哪个偶联号的SCTP偶联运行信息。使用命令DSP M3LNK查询获得M3UA链路的SCTP偶联号。 取值范围： 0～65535 默认值： 无。 说明： 无。 |

## 使用实例

显示SCTP偶联运行信息，BSG模块号为100，偶联号为9:

```
DSP SCTPAR: MN=100, AID=9;
```

## 输出结果说明

| 参数名称       | 参数描述                                                                                                                  |
|:-----------|:----------------------------------------------------------------------------------------------------------------------|
| 偶联号        | 用于请求系统显示哪个偶联号的SCTP偶联信息。使用命令DSP M3LNK查询获得M3UA链路的SCTP偶联号。                                                               |
| 当前接收窗口大小   | 用于返回当前SCTP偶联所接收数据的最大数量，单位：字节。                                                                                         |
| 待应答的数据块个数  | 用于返回当前SCTP偶联已发送并等待对端证实的数据块的数量。                                                                                        |
| 待发送的数据块个数  | 用于返回当前SCTP偶联尚未发送的数据块的数量。                                                                                              |
| 待接收的数据块个数  | 用于返回当前SCTP偶联已到达并等待用户接收的数据块的数量。                                                                                        |
| 接收累计TSN    | 用于返回当前SCTP偶联接收对端的DATA数据块的累积传输顺序号。                                                                                     |
| 对端地址个数     | 用于返回当前SCTP偶联对端传送地址的数量。 本端一个SCTP传送地址可以与对端多个SCTP传送地址建立偶联关系。                                                             |
| 最近发送TSN    | 用于返回当前SCTP偶联本端最近发送的DATA数据块的传输顺序号。                                                                                     |
| IP地址       | 用于返回当前SCTP偶联对端的IP地址。                                                                                                  |
| 对端IP状态     | 用于返回当前SCTP偶联对端的IP状态： 激活：表示对端IP地址可用。 未激活：表示对端IP地址不可用。                                                                  |
| 等待证实的数据块个数 | 用于返回当前SCTP偶联已发送到该IP地址并等待证实的数据块的数量。                                                                                    |
| 拥塞窗口大小     | 用于返回当前SCTP偶联在该地址为避免网络拥塞而允许传输的最大消息流量，当发送的消息流量大于该值时，就会出现网络拥塞。                                                           |
| 缓慢启动门限     | 慢启动阈值。慢启动：当在一个状态不明的网络或者是空闲了相当长时间的网络上开始传送数据时，则要求SCTP去向网络探询一下以确定其可用的容量。出于这个目的，在开始传送数据时或者是对重发定时器检出的丢失消息进行重发时，就使用慢启动算法。   |
| 等候应答数据     | 用于返回当前SCTP偶联到达该IP地址并等待证实的数据总量。                                                                                        |
| 重传超时时间     | 用于返回在当前SCTP偶联上所允许的消息连续重传的时间，单位：毫秒。 例如，若该输出项的值为1000，则表示当某个SCTP偶联上的消息在发送后等待1000毫秒内，如果还没有收到对端返回的确认消息，SCTP偶联将会向对端重新发送该消息。 |
| 双向传播时间     | 用于返回SCTP偶联从消息发送到接收到对端确认消息的时间，单位：毫秒。该输出项的值表征当前网络的传输质量情况。                                                               |
| 双向传播时间变化   | 用于返回当前SCTP偶联中消息双向传播时间与历史消息双向传播时间平均值的一个变化量，该输出项的值通过系统内部算法得出，表征当前网络的抖动状况。                                               |
