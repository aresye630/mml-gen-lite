# 检查用户数据(CHK USERDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，可完成对单个用户的数据完整性检查。

## 注意事项

无。

## 参数说明

| 参数ID        | 参数名称   | 参数描述                                                                                                                                                        |
|:------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USERTYPE    | 用户类型   | 用于指定用户类型。 取值范围： “SUBID(SUBID)”：为了唯一标识一个签约IMS业务的用户，必须为每一个用户分配一个唯一的ID。“IMPI(IMPI)”：用户私有标识。“IMPU(IMPU)”：用户公有标识。“PISI(PISI)”：私有业务标识。“PUSI(PUSI)”：公有业务标识。 默认值：无。 |
| USERID      | 用户标识   | 用于指定用户标识。 取值范围：长度不超过127位的字符串。 默认值：无。                                                                                                                        |
| CCUMOUDLEID | CCU模块号 | 用于指定CCU模块号。 取值范围：1～1023。 默认值：无。                                                                                                                             |

## 使用实例

检查用户数据：

`CHK USERDATA: USERTYPE=IMPU,
USERID="sip:IMPU-LM-FUN-008-027_2@huawei.com", CCUMOUDLEID=2;`

```
%%CHK USERDATA: USERTYPE=IMPU, USERID="sip:IMPU-LM-FUN-008-027_2@huawei.com", CCUMOUDLEID=2;%%
RETCODE = 0  操作成功

检测结果为
----------
检查结果  =  0
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                   |
|:--------|:----------------------------------------|
| 核查结果    | 指示核查的结果。 核查结果取值如下： 0：用户数据完整。非0：用户数据不完整。 |
