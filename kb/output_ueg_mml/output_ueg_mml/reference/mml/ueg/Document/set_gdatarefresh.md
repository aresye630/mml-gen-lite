## 命令功能

**须知** 

此命令对性能有影响，建议在话务量低时执行。执行该命令前，需要与华为技术支持确认后才可以实施。

该命令是用于强制刷新CCU/ACF中的内存数据。

## 注意事项

- 该命令不允许进行批操作。
- 此命令对性能有影响，建议在话务量低时执行。
