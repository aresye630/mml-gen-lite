# 增加CHR话单功能输出策略(ADD CHRPLCY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中增加UDM网元的CHR话单输出策略的记录。支持失败消息和所有消息话单输出可选择配置，且支持按照号段进行CHR话单功能开启。

## 注意事项

- 当前版本不支持此功能，执行该命令后会返回错误码：“335607 暂不支持该功能”。
- 最多允许添加255条CHR配置记录。

## 参数说明

| 参数标识         | 参数名称         | 参数说明                                                                                                                                                            |
|:-------------|:-------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MSGINTERFACE | 消息接口         | 用于标识UDM生成CHR话单指定的接口类型。 取值范围：S6a(S6a)：S6a接口。 默认值：无。                                                                                                              |
| CHRMSG       | 消息类型         | 用于标识UDM生成CHR话单指定的消息类型。 取值范围：全部选中全部清空全部灰化AIR_AIA(AIR_AIA)ULR_ULA(ULR_ULA)NOR_NOA(NOR_NOA)IDR_IDA(IDR_IDA)CLR_CLA(CLR_CLA)DSR_DSA(DSR_DSA)PUR_PUA(PUR_PUA) 默认值：无。 |
| IMSIPREFIX   | IMSI号段       | 用于标识UDM生成CHR话单指定的号段。若不输入，表示CHR话单的输出策略针对所有号段生效。 取值范围：1～15位十进制数字组成的字符串 默认值：无。 说明：系统默认记录无号段的话单输出策略，每种消息类型对应的无号段的话单输出策略只能有一条记录。                                     |
| CHRSUPP      | 是否支持CHR功能    | 用于标识UDM是否支持CHR话单生成的功能。 取值范围：NO(不支持)YES(支持) 默认值：无。                                                                                                               |
| CHRPLCY      | CHR输出策略      | 仅当本命令的参数“是否支持CHR功能”取值为“YES(支持)”时，该参数有效。用于标识UDM网元输出CHR话单的策略。 取值范围：ONLYFAILED(只输出异常消息单据)ALL(输出所有成功失败消息单据) 默认值：无。                                                  |
| ANMCHR       | 是否进行CHR匿名化处理 | 仅当本命令的参数“是否支持CHR功能”取值为“YES(支持)”时，该参数有效。用于标识生成CHR话单时是否需要对CHR单据中的个人敏感信息（IMSI、MSISDN）进行匿名化处理。 取值范围：NO(不作匿名化)YES(匿名化) 默认值：无。                                        |

## 使用实例

增加一条CHR话单输出策略的记录，“消息接口”为“S6a(S6a)”，“消息类型”为“ULR\_ULA(ULR\_ULA)”和“AIR\_AIA(AIR\_AIA)”的组合，“IMSI号段”为“00123456789”，开启CHR话单功能并只输出异常信息话单，匿名化处理个人敏感信息。

```
ADD CHRPLCY: MSGINTERFACE=S6a, CHRMSG=ULR_ULA-1&AIR_AIA-1, IMSIPREFIX="00123456789", CHRSUPP=YES, CHRPLCY=ONLYFAILED, ANMCHR=YES;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释           | 原因分析                   | 处理建议                                                                                                  |
|-------:|:----------------|:-----------------------|:------------------------------------------------------------------------------------------------------|
| 335607 | 暂不支持该功能。        | 当前版本不支持此功能。            | 无需处理。                                                                                                 |
| 335819 | CHR配置记录已经达到最大值。 | CHR话单输出策略记录总数不能超过255条。 | 执行命令LST CHRPLCY查询已添加的所有CHR单据生成策略记录，确认哪些是不需要的并执行命令RMV CHRPLCY删除，再执行本命令添加记录。                            |
| 335820 | 记录已存在。          | 要增加的CHR话单输出策略记录已存在。    | 请按照一下步骤进行操作： 执行命令LST CHRPLCY查询已添加的所有CHR单据生成策略记录。根据查询结果重新输入参数“消息接口”，“消息类型”或“IMSI号段”，确保这三个参数唯一确定的记录未添加。 |
