# 发送超时数据(SND USD)

## 命令功能

**须知** 

执行该命令发送整表的数据量大时，会导致CPU产生一定的波动，如在话务高峰期需慎重执行。

本命令用于发送OMU数据库中还没有对主机数据库进行同步设定的数据，使主机数据与OMU数据保持一致。

本命令的使用场景为：当操作员在脱机方式下使用MML命令对OMU数据库进行数据配置后，如果操作员使用**LST USD**命令查询到OMU数据库中还存在没有对主机数据库进行同步设定的数据表，则在操作员执行了**LON**命令的前提下，可以使用本命令对主机数据库予以重新设定。

## 注意事项

- 执行前请查看模块是否运行正常，查看模块状态可使用CSP网元下的**DSP MODULE**命令。如果模块运行不正常，请联系华为技术支持处理。
- 在联机设定开关状态为打开时，每隔十分钟，OMU会自动联机设定一次，如果数据发送失败次数达到50次，此数据将不再进行联机设定，系统上报“ALM-4754 联机设定失败”告警。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                           |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------|
| MN     | 模块号    | 标识联机设定超时数据所在的模块号，用于指定需要对哪一模块的超时未设定数据进行设定，操作员可以通过LST USD命令查询获得。若不输入，则表示设定所有模块的超时未设定数据。 取值范围：0～4294967294 默认值：无。 |

## 使用实例

发送指定模块的超时数据：设置“模块号”为“502”。

```
SND USD: MN=502;
```
