# 显示MTP路由(DSP N7RT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询指定MTP路由的状态信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                   |
|:-------|:-----------|:-----------------------------------------------------------------------|
| MN     | CCU/BSG模块号 | 用于请求系统显示哪个CCU/BSG模块内MTP路由的状态信息，若不输入，则表示所有模块。 取值范围：1～1023 默认值：无。 说明：无。  |
| DPNM   | 目的信令点名称    | 用于请求系统显示哪个目的信令点的MTP路由状态信息，若不输入，则表示所有目的信令点。 取值范围：1～32 位字符串 默认值：无。 说明：无。 |
| LSNM   | 链路集名称      | 用于请求系统显示哪个链路集内MTP路由的状态信息。 取值范围：1～32 位字符串 默认值：无。 说明：无。                  |

## 使用实例

显示MTP路由，“目的信令点名称”为“STP”:

```
DSP N7RT: DPNM="STP";
```

返回结果如下:

```
%%DSP N7RT: DPNM="STP";%%
RETCODE = 0  操作成功

MTP路由信息
---------------------
                 目的信令点名称  =  STP
                     链路集名称  =  STP
                           状态  =  正常
                  传输禁止/允许  =  传输允许
                    使用/未使用  =  使用
           受控/未受控重选路由   =  未受控重选路由
                 信令链路选择码  =  000102030405060708090A0B0C0D0E0F
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称         | 说明                                                                                                                                                                                                          |
|:--------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 目的信令点名称       | 用于返回指定的目的信令点名称。                                                                                                                                                                                             |
| 链路集名称         | 用于返回指定的链路集名称。                                                                                                                                                                                               |
| 状态            | 用于返回当前路由的状态信息： 故障：表示该MTP路由对应的链路集故障，不能传输MTP用户层业务信令消息。 正常：表示该MTP路由对应的链路集正常，可以传输MTP用户层业务信令消息。                                                                                                                  |
| 传输禁止/允许       | 用于返回当前MTP路由的传输状态： 禁止：表示该MTP路由对应的链路集内所有的链路故障，不能传输MTP用户层业务信令消 允许：表示该MTP路由对应的链路集内至少有一条链路运行正常，可以传输MTP用户层业务信令消息。                                                                                                 |
| 使用/未使用        | 用于返回当前MTP路由的使用信息： 使用：表示当前路由正在传输MTP用户层信令业务消息。 未用：表示当前路由没有传输MTP用户层信令业务消息。                                                                                                                                     |
| 受控/未受控重选路由    | 源信令点和目的信令点之间通过信令转接点进行转接，例如源信令点A到目的信令点B有两条路由，一条是“A->C->B”，另外一条是“A->C->D->B”，系统默认取最短的路由。如果C到B之间的路由故障，系统才会选择第二条路由进行消息传递。当C到B之间的路由恢复时才会出现下述的两种情况： 未受控重选路由：表示消息传递还按照原有路由进行，不恢复到系统默认路由。 受控重选路由：表示消息传递恢复到系统默认路由进行。 |
| 信令链路选择码(十六进制) | 用于返回同一链路集下多条链路之间信令业务负荷分担的相关信息。例如，当前链路的信令链路选择码为01 02 03 ，则表示上层用户如果填写的信令链路选择码为01、02或者03时，系统则可以选择该链路发送信令消息。                                                                                                    |
