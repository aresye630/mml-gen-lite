# 修改用户数据统计扩展对象(MOD STRNGEX)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改用户数据统计对象的配置信息。在该命令中，系统通过以下参数唯一标识一条用户数据统计对象的配置信息记录。

- “统计对象ID”
- “统计类型”

## 注意事项

- 该命令的配置信息必须与USCDB网元侧STRNGEX配置信息同步并保持一致。
- 该命令中的“PLMN”和“GUMMEI”参数必须且只能存在一个。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                            |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OBJECTID | 统计对象ID | 标识用户数据统计对象关键字段之一（其取值不能被修改），用于指定需要对哪个用户数据统计对象的参数进行修改或调整，操作员可以使用LST STRNGEX命令查询获得。                                                                                                |
| TYPE     | 统计类型   | 标识用户数据统计对象关键字段之一（其取值不能被修改），用于指定需要对哪种统计类型的参数进行修改或调整，操作员可以使用LST STRNGEX命令查询获得。                                                                                                    |
| BEGINNUM | 统计起始号码 | 仅当本命令中的“统计类型”为“STAT_NUMBER（按号段统计）”时该参数有效。用于标识以哪个MSISDN号码作为起始号码的号段的用户数据统计信息进行修改。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                   |
| ENDNUM   | 统计结束号码 | 仅当本命令中的“统计类型”为“STAT_NUMBER（按号段统计）”时该参数有效。用于标识以哪个MSISDN号码作为结束号码的号段的用户数据统计信息进行修改。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                   |
| HLRSN    | HLR序列号 | 仅当本命令中的“统计类型”为“STAT_RN（按RN统计）”时该参数有效。用于标识需要修改哪个虚拟HLR的用户数据统计信息。 取值范围：1～255 默认值：无。                                                                                                |
| RN       | 路由码    | 仅当本命令中的“统计类型”为“STAT_RN（按RN统计）”时该参数有效。用于标识需要修改哪个路由码的用户数据统计信息。 取值范围：1～10位字母或十进制数字组成的字符串。 默认值：无。 说明：该参数一般由运营商规划，用于标识不同运营商的不同网络，操作员在配置时可向运营商获取。                                     |
| SRCRN    | 源路由码   | 仅当本命令中的“统计类型”为“STAT_MULTIRN（按源RN和目的RN统计）”时该参数有效。用于标识对以哪个路由码为源路由码的用户数据统计信息进行修改。 取值范围：1～10位字母或十进制数字组成的字符串。 默认值：无。                                                                 |
| DESRN    | 目的路由码  | 仅当本命令中的“统计类型”为“STAT_MULTIRN（按源RN和目的RN统计）”时该参数有效。用于标识对以哪个路由码为目的路由码的用户数据统计信息进行修改。 取值范围：1～10位字母或十进制数字组成的字符串。 默认值：无。                                                                |
| MMEHOST  | MME主机名 | 仅当本命令中的“统计类型”为“STAT_MMEHOST（按MME主机名统计）”时该参数有效。用于标识对哪个MME主机名下的用户数据统计信息进行修改。 取值范围：1～128位字母或字母与十进制数字（字母在前）组成的字符串。 默认值：无。                                                           |
| GUMMEI   | GUMMEI | 仅当本命令中的“统计类型”为“STAT_MMEHOST（按MME主机名统计）”时该参数有效。用于标识需要修改的用户数据统计信息属于哪个GUMMEI。GUMMEI用于标识网管上MME显示的名称，可以命名为Globally Unique MME Identifier，即MME全球识别码。 取值范围：1～32位字母或十进制数字组成的字符串。 默认值：无。 |
| VLRNUM   | VLR号码  | 仅当本命令中的“统计类型”为“STAT_VLRNUMPREFIX（按VLRNUM前缀统计）”时该参数有效。用于标识需要修改哪个VLR的用户数据统计信息。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                      |
| PLMN     | PLMN   | 仅当本命令中的“统计类型”为“STAT_MMEHOST（按MME主机名统计）”时该参数有效。用于标识需要修改的用户数据统计信息属于哪个PLMN。 取值范围：由1～32位字母或十进制数字组成的字符串。 默认值：无。                                                                      |

## 使用实例

1. 修改用户数据统计对象，“统计对象ID”为“OBJECT2”，按HLRSN统计，“HLR序列号”为“2”：

   ```
   MOD STRNGEX: OBJECTID=OBJECT2, TYPE=STAT_SN, HLRSN=2;
   ```
2. 修改用户数据统计对象，“统计对象ID”为“OBJECT3”，按号段统计，“统计起始号码”为“13500000000”，“统计结束号码”为“13899999999”：

   ```
   MOD STRNGEX: OBJECTID=OBJECT3, TYPE=STAT_NUMBER, BEGINNUM="13500000000", ENDNUM="13899999999";
   ```
3. 修改用户数据统计对象，“统计对象ID”为“OBJECT4”，按路由码统计，“路由码”值为“11111ABCDE”：

   ```
   MOD STRNGEX: OBJECTID=OBJECT4, TYPE=STAT_RN, RN="11111ABCDE";
   ```
4. 修改用户数据统计对象，“统计对象ID”为“OBJECT5”，按源路由码和目的路由码统计，“源路由码”值为“13777ABCDE”，“目的路由码”值为“13888ABCDE”：

   ```
   MOD STRNGEX: OBJECTID=OBJECT5, TYPE=STAT_MULTIRN, SRCRN="13777ABCDE", DESRN="13888ABCDE";
   ```
5. 修改用户数据统计对象，“统计对象ID”为“OBJECT6”，按MME主机名统计，“MME主机名”为“mme.huawei.com”，“PLMN”为“huawei500”：

   ```
   MOD STRNGEX: OBJECTID=OBJECT6, TYPE=STAT_MMEHOST, MMEHOST="mme.huawei.com", PLMN="huawei500";
   ```
6. 修改用户数据统计对象，“统计对象ID”为“OBJECT7”，按VLRNUM前缀统计，“VLR号码”为“123456789012345”：

   ```
   MOD STRNGEX: OBJECTID=OBJECT7, TYPE=STAT_VLRNUMPREFIX, VLRNUM="123456789012345";
   ```
