# 删除远端FE信息(RMV REMOTEFE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在配置数据库中删除一条远端FE的信息记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称          | 参数说明                                                                 |
|:-------|:--------------|:---------------------------------------------------------------------|
| RLOCID | 远端Location ID | 标识一条远端FE信息记录的关键字段，用于指定在配置数据库中要删除哪一条远端FE信息记录。操作员可以使用LST REMOTEFE查询获取。 |

## 使用实例

删除“远端Location ID”为“1”的远端FE的属性记录。命令如下：

```
RMV REMOTEFE: RLOCID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                    | 原因分析                             | 处理建议                                                           |
|-------:|:-----------------------------------------|:---------------------------------|:---------------------------------------------------------------|
| 335813 | 指定的RLOCID不存在，请执行LST REMOTEFE查看已经存在的记录信息。 | “远端Location ID”参数指定的远端FE信息记录不存在。 | 使用LST REMOTEFE命令查询已增加的远端FE信息记录后，重新输入需要删除的远端FE的“远端Location ID”。 |
