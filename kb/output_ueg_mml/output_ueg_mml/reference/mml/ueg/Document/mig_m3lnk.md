# 自动迁移M3UA链路(MIG M3LNK)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于迁移M3UA链路，实现扩缩容和日常维护场景触发M3UA链路迁移以达到UISU Pod的负载均衡。

- 扩容场景通过新增UISU Pod支持更大的业务流量，增加新的UISU Pod后可以执行该命令将M3UA链路迁移到新的UISU Pod上。
- 缩容场景通过删除UISU Pod的方式来节省信令流量的处理能力，由于待删除UISU上面仍然有链路，需要先把UISU上的链路迁移到其他Pod再进行模块隔离，然后进行删除模块和Pod等操作。
- 日常维护场景可以执行该命令触发M3UA链路迁移。

## 注意事项

- 该命令只能迁移弹性链路，是否弹性链路可以执行**LST M3LNK**命令查询。
- 该命令只支持UISU类型Pod的链路迁移。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                         |
|:-----------|:-------|:-----------------------------------------------------------------------------|
| MIGVMNAME1 | 迁移POD1 | 用于标识待迁移M3UA链路的源Pod名称1。可以执行LST PODINFO命令查询UDM已部署的Pod。 取值范围：1～128位的字符串。 默认值：无。 |
| MIGVMNAME2 | 迁移POD2 | 用于标识待迁移M3UA链路的源Pod名称2。可以执行LST PODINFO命令查询UDM已部署的Pod。 取值范围：1～128位的字符串。 默认值：无。 |

## 使用实例

1. 迁移M3UA链路，“迁移POD1”为“udm-uisu-pod-0-100-0”，“迁移POD2”为“udm-uisu-pod-0-100-1”：

   ```
   MIG M3LNK: MIGVMNAME1="udm-uisu-pod-0-100-0", MIGVMNAME2="udm-uisu-pod-0-100-1";
   ```
2. 迁移M3UA链路，不输入参数：

   ```
   MIG M3LNK: ;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释                | 原因分析                                     | 处理建议                                                |
|-------:|:--------------------|:-----------------------------------------|:----------------------------------------------------|
|    299 | 指定的POD不存在           | 输入的“迁移POD1”或“迁移POD2”参数所指定的Pod不存在。        | 使用LST PODINFO命令查询后，重新输入数据库中已存在的“迁移POD1”或“迁移POD2”参数。 |
|    300 | 指定的POD非信令POD        | 输入的“迁移POD1”或“迁移POD2”参数所指定的Pod不是UISU Pod。 | 使用LST PODINFO命令查询后，重新输入数据库中已存在的UISU Pod。            |
| 336078 | 当前有迁移任务正在执行，请稍后再执行。 | 当前有主机侧触发迁移任务。                            | 等待当前迁移任务结束后再做处理。                                    |
