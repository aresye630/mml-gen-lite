# 增加Diameter本端实体(ADD DMLE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行该命令可能导致ESN变动，ESN变动后需要在60天内重新申请并加载License文件。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在配置数据库中增加一条Diameter本端实体的数据记录。当用户需要配置一条通过Diameter信令与对端网元对接的链路时，首先需要配置一条Diameter本端实体的数据记录。

## 注意事项

- UDM产品的ESN信息与License有关，当局点的ESN信息中存在主机名时，若执行该命令增加一条Diameter本端实体的数据记录，使本局Diameter本端实体表中Index值最小的主机名发生改变，则会导致ESN变动，需要重新申请License文件，请谨慎操作。

  系统依次获取“IMS-HSS”、“IMS-SLF”、“SAE-HSS”网元类型索引值最小的主机名作为本局Diameter本端实体表中Index值最小的主机名。当“IMS-HSS”、“IMS-SLF”、“SAE-HSS”网元类型都不存在时，则此字段为空。
- 如果系统中已经存在与待添加本端实体相同设备类型的本端实体，则需要先设置一个已有的相同设备类型的本端实体作为默认本端实体，否则Diameter消息无法正常发送出去。相同设备类型的Diameter本端实体最多只能设置一个为默认本端实体。
- 最大支持128条Diameter本端实体配置。
- UDM-UIM的GBA功能与AAA功能互斥，若“本端设备类型”为“AAA(AAA)”，则该UDM-UIM中实体的“本端设备类型”不能再设置为“BSF(BSF)”或“AP(AP)”；反之，若“本端设备类型”为“BSF(BSF)”或“AP(AP)”，则该UDM-UIM中实体的“本端设备类型”不能再设置为“AAA(AAA)”。
- GBA场景下，当BSF和AP合一部署场景：
  - 系统允许**ADD DMPE**配置的“Diameter对端实体类型”为“AP(AP)”的对端实体的主机名和**ADD DMLE**配置的“本端设备类型”为“AP(AP)”的本端实体的主机名相同。
  - 系统允许**ADD DMPE**配置的“Diameter对端实体类型”为“BSF(BSF)”的对端实体的主机名和**ADD DMLE**配置的“本端设备类型”为“BSF(BSF)”的本端实体的主机名相同。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| EN       | 实体名称   | 用于标识一个Diameter本端实体的名称，全局唯一。 取值范围：长度不超过127的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| LOCTYPE  | 本端设备类型 | 用于标识Diameter本端设备的网元类型。 取值范围：IMS-HSS(IMS-HSS)：UDM产品作为IMS-HSS部署在IMS网络，其对端网元类型可为AS、S-CSCF、I-CSCF、GGSN、SAE、BSF、IMS-HSS和OTHER。IMS-SLF(IMS-SLF)：UDM产品作为IMS-SLF部署在IMS网络，其对端网元类型可为AS、S-CSCF、I-CSCF、BSF和OTHER。SAE-HSS(SAE-HSS)：UDM产品作为SAE-HSS部署在EPS网络，其对端网元类型可为AS、SAE、IMS-HSS和OTHER。UEIR(UEIR)：UDM产品作为EIR部署在GSM/UMTS/EPS网络，其对端网元类型可为OTHER。LRF(LRF)：UDM产品作为LRF部署在IMS网络，其对端网元类型可为IMS-HSS、E-CSCF和OTHER。IWF(IWF)：UDM产品作为UTA部署在4G/5G共存网络，模拟MME/I-CSCF与HSS对接。IWF-EIR(IWF-EIR)：UDM产品模拟MME与EIR对接。AAA(AAA)：UDM产品作为AAA部署在EPS网络，其对端网元类型可为P-GW、ePDG、HSGW、Non-3GPP接入网关、SAE和OTHER。BSF(BSF)：UDM产品实现GBA认证功能时，作为BSF功能实体部署在IMS网络。AP(AP)：UDM产品实现GBA认证功能时，作为AP功能实体部署在IMS网络。 默认值：无。 说明：融合部署场景，需要执行本命令为每种网元形态增加本端实体。例如SAE-HSS和IMS-HSS融合部署，执行本命令增加本端实体时“本端设备类型”分别选择“SAE-HSS”和“IMS-HSS”。 |
| DN       | 域名     | 用于标识Diameter本端设备所属域的域名。 取值范围：1～127位由数字、字母、“.”和“-”组成的字符串。 默认值：无。 该参数的配置原则：该参数可以配置为绝对域名或相对域名。绝对域名的长度不超过127，相对域名的长度不超过126。后面带有“.”的就是绝对域名，其他都是相对域名，例如：“huawei.com.”就是绝对域名，“huawei.com”就是相对域名。所有字符只能是数字（0～9）、字母（a～z或A～Z）、“.”或“-”。首字符必须是数字（0～9）或字母（a～z或A～Z），最后一个字符必须是数字（0-9）、字母（a～z或A～Z）或“.”。 “.”不能连续出现且“.”和“-”不能相邻，“..”、“.-”或“-.”为错误配置。 最后一个“.”后面的第一个字符必须为字母（a～z或A～Z）。例如“as.huawei.com”中的最后一个“.”后面的字符串“com”的第一个字符必须为字母。                                                                                                                                                                                                                                                                                                                                      |
| HN       | 主机名    | 用于标识Diameter本端设备在所属域中的网络主机名。 取值范围：1～127位由数字、字母、“.”和“-”组成的字符串。 默认值：无。 该参数的配置原则：所有字符只能是数字（0～9）、字母（a～z或A～Z）、“.”或“-”。 首字符必须是数字（0～9）或字母（a～z或A～Z），最后一个字符必须是数字（0-9）、字母（a～z或A～Z）或“.”。 “.”不能连续出现且“.”和“-”不能相邻，“..”、“.-”或“-.”为错误配置。 最后一个“.”后面的第一个字符必须为字母（a～z或A～Z）。例如“as.huawei.com”中的最后一个“.”后面的字符串“com”的第一个字符必须为字母。                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| DEFLOCAL | 默认本端实体 | 用于标识待添加的Diameter本端实体是否为默认本端实体。 取值范围： NO(否)：使用Diameter消息中携带的Origin-Host对应的本端实体和对端实体之间的链路发送消息。YES(是)：当Diameter消息中携带的Origin-Host对应的本端实体和对端实体之间无可用链路时，则使用该默认本端实体和对端实体之间的链路发送消息。 默认值：NO(否)。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |

## 使用实例

增加一个Diameter本端实体，“实体名称”为“HSS”，“本端设备类型”为“SAE-HSS”，“域名”为“huawei.com”，“主机名”为“hss.huawei.com”，“默认本端实体”为“NO(否)”。

```
ADD DMLE: EN="HSS", LOCTYPE=SAE-HSS, DN="huawei.com", HN="hss.huawei.com", DEFLOCAL=NO;
```
