# 查询Diameter SCTP协议参数的配置信息 (LST SCTPPP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询Diameter SCTP协议参数的配置信息：

- 若需要查询全部Diameter SCTP协议参数的配置信息，请不要输入任何参数。
- 若需要查询某个Diameter SCTP协议参数的详细配置信息，请输入“SCTP协议参数名称”或其它参数或这些参数的组合。

## 注意事项

无。

## 使用实例

   LST SCTPPP:;
   ```

   操作结果如下

    报文重发间隔最小值                                  500                   500               没有被修改的软参
    报文重发间隔最大值                                  1500                  1500              没有被修改的软参
    RTOα                                               12                    12                没有被修改的软参
    RTOβ                                               25                    25                没有被修改的软参
    Cookie有效生命期                                    60000                 60000             没有被修改的软参
    偶联最大重传次数                                    10                    10                没有被修改的软参
    路径最大重传次数                                    5                     5                 没有被修改的软参
    初始化最大重传次数                                  10                    10                没有被修改的软参
    心跳消息间隔                                        3000                  3000              没有被修改的软参
    发送数据时增加校验和                                1                     1                 没有被修改的软参
    接收数据时检查校验和                                1                     1                 没有被修改的软参
    校验和运算法则                                      1                     1                 没有被修改的软参
    绑定标识                                            1                     1                 没有被修改的软参
    Diameter消息Payload protocol identifier信元取值     0                     0                 没有被修改的软参

    接收窗口计算方法                                    2                     2                 没有被修改的软参
   (结果个数 = 17)                                      

   ---    END
   ```
2. 查询Diameter SCTP协议参数的配置信息，“SCTP协议参数名称”为“RTOINITIAL(报文重发间隔初始值)”：

   ```
   LST SCTPPP: SCTPPN=RTOINITIAL;
   ```

   ```
   %%LST SCTPPP: SCTPPN=RTOINITIAL;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   SCTP协议参数名称  =  报文重发间隔初始值
     SCTP协议参数值  =  500
         参数默认值  =  500
         参数值标识  =  没有被修改的软参
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

| 输出项名称      | 输出项解释                               |
|:-----------|:------------------------------------|
| SCTP协议参数名称 | 用于返回承载Diameter的SCTP协议相关软参名称。        |
| SCTP协议参数值  | 用于返回承载Diameter的SCTP协议相关软参值。         |
| 参数默认值      | 用于返回承载Diameter的SCTP协议相关软参的默认值。      |
| 参数值标识      | 用于返回承载Diameter的SCTP协议相关软参的默认值是否被修改。 |
