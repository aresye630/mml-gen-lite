# 查询CCU模块状态(DSP CCUMODULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询指定CCU模块的状态信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                        |
|:-------|:-------|:--------------------------------------------------------------------------------------------|
| CCUMID | CCU模块号 | 此参数用于请求系统显示指定CCU模块的配置信息。模块号是通过ADD MODULE定义，通过LST MODULE可以查询模块号。 取值范围：1～1023 默认值：无。 说明：必选参数。 |

## 使用实例

显示CCU模块号为3的状态信息：

```
DSP CCUMODULE: CCUMID=3;
```

返回结果如下：

```
%%DSP CCUMODULE: CCUMID=3;%%

RETCODE = 0  操作成功

操作结果如下
------------
CCU模块号  =  3
CCU状态  =  Active
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出结果解释                                   |
|:--------|:-----------------------------------------|
| CCU模块号  | 用于显示当前查询的CCU模块号。                         |
| CCU状态   | 用于返回CCU模块的状态信息。 取值说明： ActiveLoadingFault |
