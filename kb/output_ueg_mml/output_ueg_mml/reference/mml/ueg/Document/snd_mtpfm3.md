# 发送MTP三层伪消息(SND MTPFM3)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为维护类命令，用于请求系统在指定的MTP链路上发送MTP三层伪消息。

该命令仅适用于测试场景，例如在IOT（interoperability test）测试中，操作员可以通过该命令提供仿真协议接口以完成某些特定的测试项目，而在其他情况下，请勿使用该命令。

## 注意事项

- MTP三层伪消息由主机下发到负责信令处理的模块，这些消息可能对信令链路造成严重影响，请操作员在执行该操作之前仔细确认任务的可行性。
- 在使用该命令前，请使用**DSP N7DSP**命令查询目的信令点的状态，只有在目的信令点的状态为“可达”时，系统才能发送伪消息。
- 在使用该命令前，请使用**DSP N7LNK**命令查询发送伪消息的MTP链路的状态，只有在MTP链路的状态为“使用”时，系统才能发送伪消息。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                           |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LNKNM  | 链路名称   | 标识一条MTP链路的关键字段，用于指定系统在哪一条MTP链路上发送伪消息，操作员可以用LST N7LNK命令查询MTP链路配置情况。 取值范围：1～32 位字符串。 默认值：无。                                                                      |
| LEN    | 消息长度   | 用于指定伪消息长度，应包括SIO（业务信息指示语）长度。 取值范围：1～31。 默认值：无。                                                                                                                 |
| SIO    | SIO值   | 用于指定伪消息的SIO值。 取值范围：0～255。 默认值：无。                                                                                                                               |
| PM     | 参数     | 用于指定消息内容（十六进制格式），格式如下所示： |----DPC----|----OPC----|----SLS----| 14/24比特 14/24比特 1字节中的4比特 需与MTP三层协议（Q.704）指定的消息格式一致，且参数的字节顺序必须为网络的字节顺序。 取值范围：0～30 字节的码流串。 默认值：无。 |

## 使用实例

发送MTP三层伪消息，“链路名称”为“DD1”，“消息长度”为“27”，“SIO值”为“129”，“参数”为“AA AA AA BB BB BB 00 09 81 03 08 0D 05 43 AA AA AA 0C 05 43 BB BB BB 0C 01 00”

```
SND MTPFM3: LNKNM="DD1", LEN=27, SIO=129, PM="AA AA AA BB BB BB 00 09 81 03 08 0D 05 43 AA AA AA 0C 05 43 BB BB BB 0C 01 00";
```
