# 查询外部SAE设备链路的配置信息(LST HSAEL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询HSS与SAE设备之间的Diameter链路的配置信息：

- 若需要查询全部SAE数据记录的信息，请不要输入任何参数。
- 若需要查询某条HSS与SAE设备之间的Diameter链路数据记录的详细信息，请输入“链路名称”或其他参数或这些参数的组合。

## 注意事项

当HSS的“工作模式”被指定为“SERVER(服务器)”时，返回结果中参数“分发端口号”表示内部分发端口号，HSS整体对外端口号为3868，在进行对端配置的时候需配置HSS的对外端口号为3868。

## 参数说明

| 参数标识    | 参数名称       | 参数说明                                                                                                                                                                                                                                             |
|:--------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HSSN    | HSS名称      | 用于指示系统需要按照哪个“HSS名称”来查询HSS与SAE设备之间的Diameter链路数据记录；若不输入，则表示所有的HSS实体名称。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。                                                                                                                                           |
| SAEN    | SAE名称      | 用于指示系统需要按照哪个“SAE名称”来查询HSS与SAE设备之间的Diameter链路数据记录；若不输入，则表示所有的“SAE名称”。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。                                                                                                                                           |
| LNKN    | 链路名称       | 用于指示系统需要按照哪个“链路名称”来查询HSS与SAE设备之间的Diameter链路数据记录；若不输入，则表示所有的“链路名称”。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。                                                                                                                                             |
| PTYPE   | 传输协议类型     | 用于指示系统需要按照哪个“传输协议类型”来查询HSS与SAE设备之间的Diameter链路数据记录；若不输入，则表示所有的“传输协议类型”。 取值范围： SCTP(SCTP协议类型) TCP(TCP协议类型) UDP(UDP协议类型) 默认值：无。 说明：可选参数。                                                                                                            |
| WMODE   | 工作模式       | 用于指示系统需要按照哪个“工作模式”来查询HSS与SAE设备之间的Diameter链路数据记录；若不输入，则表示所有的“工作模式”。 取值范围： CLIENT(客户端)：HSS在当前链路中作为客户端，会主动向对端服务器发起建链请求。 SERVER(服务器)：HSS在当前链路中作为服务器端，在建链时不会主动发起建链请求，会等待对端的建链请求。 SERVERMULTPORT(服务端多端口)：当HSS在当前链路中作为服务端多端口时，需要指定分发端口。 默认值：无。 说明：可选参数。 |
| HSFMID  | HSF模块号     | 用于指示系统需要按照哪个“HSF模块号”来查询HSS与SAE设备之间的Diameter链路数据记录；若不输入，则表示所有的“HSF模块号”。 取值范围：1～1023 默认值：无。 说明：可选参数。                                                                                                                                               |
| ADDRN   | HSS地址名称    | 用于指示系统需要按照哪个“HSS地址名称”来查询HSS与SAE设备之间的Diameter链路数据记录；若不输入，则表示所有的“HSS地址名称”。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。                                                                                                                                       |
| SADDRN  | HSS备用地址名称  | 用于指示系统需要按照哪个“HSS备用地址名称”来查询HSS与SAE设备之间的Diameter链路数据记录；若不输入，则表示所有的“HSS备用地址名称”。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。                                                                                                                                   |
| LPT     | 分发端口号      | 用于指示系统需要按照哪个“分发端口号”来查询HSS与SAE设备之间的Diameter链路数据记录；若不输入，则表示所有的“分发端口号”。 取值范围：1025～65534 默认值：无。 说明：可选参数。                                                                                                                                             |
| PIPVER  | 对端IP地址版本   | 用于指示系统需要按照哪个“对端IP地址版本”来查询HSS与SAE设备之间的Diameter链路数据记录；若不输入，则表示所有的“对端IP地址版本”。 取值范围： IPV4(IPV4) IPV6(IPV6) 默认值：无。 说明：可选参数。                                                                                                                           |
| PIPV4   | 对端IPV4地址   | 用于指示系统需要按照哪个“对端IPV4地址”来查询HSS与SAE设备之间的Diameter链路数据记录；若不输入，则表示所有的“对端IPV4地址”。 取值范围：IPv4地址 默认值：无。 说明：“对端IP地址版本”为“IPV4(IPV4)”时，是可选参数。                                                                                                                 |
| PIPV6   | 对端IPV6地址   | 用于指示系统需要按照哪个“对端IPV6地址”来查询HSS与SAE设备之间的Diameter链路数据记录；若不输入，则表示所有的“对端IPV6地址”。 IPV6格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如，fc00:7864:0266:0000:0000:0000:7864:0266。 取值范围：IPv6地址 默认值：无。 说明：“对端IP地址版本”为“IPV6(IPV6)”时，是可选参数。                    |
| SPIPVER | 对端备用IP地址版本 | 用于指示系统需要按照哪个“对端备用IP地址版本”来查询HSS与SAE设备之间的Diameter链路数据记录；若不输入，则表示所有的“对端备用IP地址版本”。 取值范围： IPV4(IPV4) IPV6(IPV6) 默认值：无。 说明：可选参数。                                                                                                                       |
| SPIPV4  | 对端备用IPV4地址 | 用于指示系统需要按照哪个“对端备用IPV4地址”来查询HSS与SAE设备之间的Diameter链路数据记录；若不输入，则表示所有的“对端备用IPV4地址”。 取值范围：IPv4地址 默认值：无。 说明：“对端备用IP地址版本”为“IPV4(IPV4)”时，是可选参数。                                                                                                           |
| SPIPV6  | 对端备用IPV6地址 | 用于指示系统需要按照哪个“对端备用IPV6地址”来查询HSS与SAE设备之间的Diameter链路数据记录；若不输入，则表示所有的“对端备用IPV6地址”。 IPV6格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如，fc00:7864:0266:0000:0000:0000:7864:0266。 取值范围：IPv6地址 默认值：无。 说明：“对端备用IP地址版本”为“IPV6(IPV6)”时，是可选参数。              |
| PPT     | 对端端口号      | 用于指示系统需要按照哪个“对端端口号”来查询HSS与SAE设备之间的Diameter链路数据记录；若不输入，则表示所有的“对端端口号”。 取值范围：0～65534 默认值：无。 说明：可选参数。                                                                                                                                                |

## 输出结果说明

以下列出的是未包含在本命令参数说明中的输出项，其他输出项的详细说明请参见本命令的参数说明。

| 输出项名称   | 输出项解释                                       |
|:--------|:--------------------------------------------|
| HSS索引   | 用于在配置数据库中定义一条HSS设备数据记录索引，该索引仅供内部使用，无实际含义。   |
| SAE索引   | 用于在配置数据库中定义一条SAE设备数据记录索引，该索引仅供内部使用，无实际含义。   |
| 链路索引    | 用于在配置数据库中定义一条SAE设备链路数据记录索引，该索引仅供内部使用，无实际含义。 |
