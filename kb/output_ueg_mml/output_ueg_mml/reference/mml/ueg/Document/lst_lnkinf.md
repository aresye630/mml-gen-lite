# 查询模块链路信息(LST LNKINF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在配置数据库中查询模块链路信息。若需要查询某条模块链路数据记录的详细信息，请输入“BSG模块号”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                          |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------------|
| MN      | BSG模块号 | 用于指示系统需要按照哪个BSG模块号来查询链路数据；若不输入，则表示所有的BSG模块。 取值范围：1～1023 默认值：无。 说明：可选参数。                                       |
| LNKNM   | 链路名称   | 用于指示系统需要按照哪个链路名称来查询链路数据；若不输入，则表示所有的链路名称。 取值范围：长度不超过32的字符串 默认值：无。 说明：可选参数。                                     |
| LNKTYPE | 链路类型   | 用于指示系统需要按照哪个链路类型来查询链路数据；若不输入，则表示所有的链路类型。 取值范围： “MTP(MTP链路)”“M3UA(M3UA链路)”“ALL(所有链路)” 默认值：“ALL(所有链路)” 说明：可选参数。 |

## 使用实例

1、查询本局所有模块链路信息：

```
LST LNKINF: LNKTYPE=ALL;
```

返回结果如下：

```
%%LST LNKINF: LNKTYPE=ALL;%%
RETCODE = 0  操作成功

M3UA链路表
----------
 M3UA链路名称  BSG模块号  M3UA链路集名称  链路号 

 TOSTP01       1000        TOSTP01        0      
 TOSTP02       1000        TOSTP02        1      
(结果个数 = 2)

---    END
```

2、查询本局模块链路信息：“BSG模块号”为“1000”，“链路名称”为“TOSTP01”，“链路类型”为“ALL”：

```
LST LNKINF: MN=1000, LNKNM="TOSTP01", LNKTYPE=ALL;
```

返回结果如下：

```
%%LST LNKINF: MN=1000, LNKNM="TOSTP01", LNKTYPE=ALL;%%
RETCODE = 0  操作成功

M3UA链路表
----------
  链路名称  =  TOSTP01
 BSG模块号  =  1000
链路集名称  =  TOSTP01
    链路号  =  1
(结果个数 = 1)

---    END
```
