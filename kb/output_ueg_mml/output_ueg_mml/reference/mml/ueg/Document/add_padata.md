# 增加协议适配数据(ADD PADATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于增加各种协议类型的适配数据，目前只支持给SMPP协议类型增加相应的信息。

## 注意事项

当前版本不支持此功能，执行该命令后会返回错误码：335607 暂不支持该功能。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                              |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROTTYPE | 协议类型   | 用于指定当前支持的协议类型。 取值范围： “SMPP(SMPP)”：短消息点对点传输协议。 默认值：无。 说明：必选参数。                                                                                                                                                                                                                                                                                                                                                                     |
| OPTYPE   | 操作类型   | 用于指定当前操作是增加用户信息还是增加前缀信息。 该参数的配置原则是：在增加前缀信息之前首先要增加用户信息，否则系统会提示“用户不存在”。 取值范围： “USER(用户)”：增加用户信息。“PREX(前缀)”：增加前缀信息。 默认值：无。 说明：必选参数。                                                                                                                                                                                                                                                                                                  |
| USERNAME | 用户名    | 用于指定用户名。 取值范围：1～15字符串 默认值：无。 说明：必选参数。                                                                                                                                                                                                                                                                                                                                                                                             |
| USERPWD  | 密码     | 仅当本命令中的“操作类型”参数为“USER(用户)”时该参数有效。用于标识用户密码。 取值范围：1～16位字符串。 默认值：无。 说明：如果MOD INSP命令中将“软件参数类型”为“HSS9860”的“PWD_COMP_SWITCH（密码兼容开关）”参数设为“1”，则该参数为取值为1～16位字符串。如果MOD INSP命令中将“软件参数类型”为“HSS9860”的“PWD_COMP_SWITCH（密码兼容开关）”参数设为“0”，则该参数遵循如下配置原则：密码必须至少包含以下四个类别中的三类：英文大写字母英文小写字母数字：0～9特殊字符：~ ! # % ^ * ( ) _ - + [ ] { } | < > . ? 不允许使用三个或三个以上连续的字母或数字（例如：ABC、123）。密码不能和帐号或者帐号的逆序一样。不允许使用三个或三个以上连续的相同字符（例如：AAA）。密码长度不能少于8位字符。密码的第一个字符必须是字母。 |
| PREX     | 前缀     | 用于指定前缀。 取值范围：1～16数字字符串 默认值：无。 说明：当“操作类型”等于“PREX”时，必选参数。                                                                                                                                                                                                                                                                                                                                                                           |

## 使用实例

1、增加SMPP类型的适配数据。添加用户信息。

```
ADD PADATA: PROTTYPE=SMPP, OPTYPE=USER, USERNAME="test", USERPWD="****";
```

2、增加SMPP类型的适配数据。添加用户名为test的前缀信息。

```
ADD PADATA: PROTTYPE=SMPP, OPTYPE=PREX, USERNAME="test", PREX="135";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释              | 原因分析                       | 处理建议                               |
|-------:|:-------------------|:---------------------------|:-----------------------------------|
| 260071 | 用户不存在              | 增加前缀信息时，输入的参数“用户名”未增加用户信息。 | 在增加用户的前缀信息之前必须先增加用户信息。             |
| 335607 | 暂不支持该功能。           | 当前版本不支持此功能。                | 无需处理。                              |
| 352054 | 参数取值无效：该密码的设定不符合要求 | 增加用户信息时，输入的参数“密码”不符合要求。    | 根据实际情况，重新输入参数“密码”，确保其格式符合参数说明中的要求。 |
| 352055 | 密码长度不能小于8个字符       | 增加用户信息时，输入的参数“密码”过短。       | 根据实际情况，重新输入参数“密码”，确保其格式符合参数说明中的要求。 |
