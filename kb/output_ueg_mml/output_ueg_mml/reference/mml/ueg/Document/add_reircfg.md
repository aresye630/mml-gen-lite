# 增加远端EIR配置(ADD REIRCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加一条远端EIR的数据记录。当UDM将自己模拟为MME与远端EIR通信时，需要先配置一条远端EIR的数据记录。

UDM将自己模拟为MME，主动向EIR发送S13接口请求消息，目的主机名和目的域名需要填写“远端EIR主机名”和“远端EIR域名”。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

系统中最多允许配置5个远端EIR。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                       |
|:---------|:---------|:---------------------------------------------------------------------------------------------------------------------------|
| EIRNAME  | 远端EIR名称  | 可选必选说明：必选参数 参数含义：用于标识一个远端EIR的名称，全局唯一。 取值范围：长度不超过127的字符串。 默认值：无。 配置原则：该参数不能只输入一个空格，并且字母不区分大小写。                              |
| EIRHOST  | 远端EIR主机名 | 可选必选说明：必选参数 参数含义：用于标识远端EIR的主机名。 取值范围：1～127位由十进制数字、字母、“_”、“.”或“@”组成的字符串。 默认值：无。 配置原则： 该参数不能只输入一个空格，并且字母不区分大小写。远端EIR主机名不能重复。 |
| EIRREALM | 远端EIR域名  | 可选必选说明：必选参数 参数含义：用于标识远端EIR的域名。 取值范围：长度不超过127的字符串。 默认值：无。 配置原则：该参数不能只输入一个空格，并且字母不区分大小写。该参数不允许配置以“.”开头或结尾，或者中间连续两个“.”。       |
| PRI      | 优先级      | 可选必选说明：必选参数 参数含义：用于标识远端EIR的优先级。 取值范围：1～250 默认值：无。 配置原则： 取值越小，优先级越高，取值相同时表示优先级相同。业务使用时优先选取优先级高的记录，如果存在多条相同优先级的记录，则轮询选择。     |

## 使用实例

当UDM将自己模拟为MME与远端EIR通信时，执行该命令增加一条远端EIR数据记录，“远端EIR名称”为“EIR01”，“远端EIR主机名”为“eir.huawei.com”，“远端EIR域名”为“huawei.com”，“优先级”为“5”。

```
ADD REIRCFG: EIRNAME="EIR01", EIRHOST="eir.huawei.com", EIRREALM="huawei.com", PRI=5;
```
