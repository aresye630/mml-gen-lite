# 删除应用类型远端Location信息(RMV SRVRLOCATION)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当可能会影响本端网元设备与远端网元设备进行通信，导致业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于支持在FE侧网元删除相关应用类型远端网元的优先级。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称         | 参数说明                                                                                                  |
|:------------|:-------------|:------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 业务类型         | 用于定义FE存在多应用的场景下，本端网元的某种业务类型。 取值范围：长度不超过128的字符串。 默认值：无。                                                |
| RLOCID      | 远端Location标识 | 用于指定本端网元设备对应的远端网元设备的Location标识。 一个远端Location标识唯一对应一个远端网元，该此参数可通过执行LST RLOCATION获得。 取值范围：1～512。 默认值：无。 |

## 使用实例

```
删除“业务类型”为“SUP-FE”以及“远端Location标识”为“1”的优先级配置：
RMV SRVRLOCATION: SERVICETYPE="SUP-FE", RLOCID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                         | 原因分析                | 处理建议                                              |
|-------:|:------------------------------|:--------------------|:--------------------------------------------------|
| 302003 | 远端location不存在。                | 参数“远端Location标识”错误。 | 通过LST RLOCATION命令查询已配置的远端location，并正确填写，然后重新执行命令。 |
| 302532 | 输入的业务类型不属于业务分组内，请输入正确的业务类型参数。 | 参数“业务类型”错误。         | 通过LST SERVICEGROUP命令查询已配置的业务类型，并正确输入业务分组的业务类型参数。  |
| 302579 | 应用类型远端location不存在。            | 指定的记录不存在。           | 通过LST SRVRLOCATION命令查询已存在的配置，并正确填写，然后重新执行命令。      |
