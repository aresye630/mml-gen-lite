# 删除E2E跟踪任务(RMV E2ETSK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除UDM中某用户的E2E跟踪任务记录。

## 注意事项

- 操作员执行此删除操作，如果删除正在运行的跟踪任务，则会导致全网跟踪任务异常。
- 该命令属于维护命令，用来删除网管上创建或删除跟踪任务时产生的垃圾数据。如果需要删除网管上创建的跟踪任务，需要通过网管去操作。

| MSISDN    | MSISDN | 可选必选说明：条件必选参数。 参数含义：标识一条用户E2E跟踪任务数据记录的关键字段，用于指定需要删除哪一条“MSISDN”数据记录，操作员可以使用LST E2ETSK命令查询获得。 取值范围：1～15位的十进制数字组成的字符串。 默认值：无 配置原则：当“用户标识类型”为“MSISDN(MSISDN)”时该参数有效。                                  |
| IMPU      | IMPU   | 可选必选说明：条件必选参数。 参数含义：标识一条用户E2E跟踪任务数据记录的关键字段，用于指定需要删除哪一条“IMPU”数据记录，操作员可以使用LST E2ETSK命令查询获得。 取值范围：长度不超过127的字符串。 默认值：无 配置原则：当“用户标识类型”为“IMPU(IMPU)”时该参数有效。                                             |
| TRCREF    | 跟踪参考号  | 可选必选说明：可选参数。 参数含义：标识一条用户E2E跟踪任务数据记录的关键字段，用于指定需要删除哪一条“跟踪参考号”数据记录，操作员可以使用LST E2ETSK命令查询获得。 取值范围：长度为12~13字符串。 默认值：无 配置原则：当“用户标识类型”为空时，该参数有效。                                                         |

## 使用实例

1. 删除UDM某用户单条E2E跟踪任务，“网络类型”为**LTE-SAE(LTE-SAE)**，“用户标识类型”为**IMSI(IMSI)**，“IMSI”为**23252627**，执行命令如下：

   ```
   RMV E2ETSK: NETTYPE=LTE-SAE, USRIDTYPE=IMSI, IMSI="222222222222222", TRCREF="46000-00CD4F";
   ```
