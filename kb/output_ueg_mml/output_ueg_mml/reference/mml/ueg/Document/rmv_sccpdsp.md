# 删除SCCP目的信令点(RMV SCCPDSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于从配置数据库中删除一条或者一组SCCP目的信令点数据。

## 注意事项

- 如果命令执行成功，且删除的数据为已有性能统计任务中登记的对象实例，则该对象实例后续上报的指标值为0。命令涉及的测量单元有：SCCP流量测量。
- 在正常情况下，删除一条SCCP目的信令点数据记录的操作步骤为：**RMV SCCPGT**-->**RMV SCCPSSN**-->****RMV SCCPDSP****。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                 |
|:-------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
| DPNM   | 目的信令点名称 | 标识一条SCCP目的信令点数据记录的关键字段之一，用于指定需要删除哪一条SCCP目的信令点数据记录，操作员可以使用LST SCCPDSP命令查询获得。 取值范围：长度不超过32的字符串，名称只允许输入：0-9，a-z，A-Z，“-”、“_”、“.”、空格符、和中文字符。 默认值：无。 说明：无。 |

## 使用实例

删除SCCP目的信令点，“目的信令点名称”为“SCCPDSP”：

```
RMV SCCPDSP: DPNM="SCCPDSP";
```
