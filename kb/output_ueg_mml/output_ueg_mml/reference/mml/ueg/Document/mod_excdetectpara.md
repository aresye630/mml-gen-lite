## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改或调整单用户异常流程冲击防护检测功能配置信息。用于开启或关闭2G/3G、4G、IMS业务流程中异常流程防护能力，当检测到相应消息数超出系统设置的最大阈值时，系统启动检测功能并进行日志打印。降低因为单用户异常流程消息冲击触发设备过载流控引起正常业务受损的风险，从而提升产品的定位定界能力。

## 注意事项

存储Bypass场景不支持配置异常流程防护策略。

## 参数说明

| 参数标识         | 参数名称         | 参数说明                                                                                                                                                                     |
|:-------------|:-------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DETECTPERIOD | 检测周期         | 可选必选说明：可选参数 参数含义：用于标识异常消息的检测周期。 取值范围：1～20，单位：秒。 系统初始设置值：1 配置原则： 当前流控的检测周期是1秒，该功能是为了能够在流控发生前记录异常用户信息，因此检测周期设置和流控检测周期保持一致。异常冲击检测很多是瞬时的冲击，周期设置太长将会无法记录下瞬时冲击的异常，建议不要轻易修改默认值。 |
| MAPMSGNUM    | MAP消息允许最大消息数 | 可选必选说明：可选参数 参数含义：用于标识检测周期内单个进程单用户所允许的最大的2G/3G消息数量。 取值范围：0～1500 系统初始设置值：8 配置原则：参数取值为“0”表示功能关闭，不再对MAP消息的单用户异常流程冲击进行检测。                                                     |
| EPSMSGNUM    | 4G消息允许最大消息数  | 可选必选说明：可选参数 参数含义：用于标识检测周期内单个进程单用户所允许的最大的4G消息数量。 取值范围：0～1500 系统初始设置值：7 配置原则：参数取值为“0”表示功能关闭，不再对4G消息的单用户异常流程冲击进行检测。                                                         |
| IMSMSGNUM    | IMS消息允许最大消息数 | 可选必选说明：可选参数 参数含义：用于标识周期时间内单个进程单用户所允许通过的最大的IMS消息数量。 取值范围：0～1500 系统初始设置值：21 配置原则：参数取值为“0”表示功能关闭，不再对IMS消息的单用户异常流程冲击进行检测。                                                    |
| CACHEMAXNUM  | 支持同时检测的用户数   | 可选必选说明：可选参数 参数含义：用于标识允许同时进行异常流程冲击防护的最大用户数。 取值范围：1000～1500 系统初始设置值：1000 配置原则：无。                                                                                           |

## 使用实例

设置单用户异常流程冲击防护检测功能配置信息。参数设置如下：

- “检测周期”为“1”
- “MAP消息允许最大消息数”为“8”
- “4G消息允许最大消息数”为“7”
- “IMS消息允许最大消息数”为“21”
- “支持同时检测的用户数”为“1000”

命令执行如下：

```
MOD EXCDETECTPARA: DETECTPERIOD=1, MAPMSGNUM=8, EPSMSGNUM=7, IMSMSGNUM=21, CACHEMAXNUM=1000;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
