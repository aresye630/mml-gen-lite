# 发送信令链路探测消息(SND RDUCHECK)

## 命令功能

该命令用于手动发送MAP信令链路探测消息进行信令可用性探测。

- 如果系统已上报“ALM-16013 容灾FE业务自动探测异常”告警，则探测成功时恢复系统上报的还未恢复的该告警，同时返回是否探测成功的结果。
- 如果系统未上报“ALM-16013 容灾FE业务自动探测异常”告警，则只返回是否探测成功的结果。现网局点在割接、容灾倒换等操作前会使用该命令进行信令可用性探测。

客户端提交命令请求后，由联动倒换控制中心CCU模块进行探测，探测消息不检查用户动态信息中VLR/SGSN号码与“对端GT”参数是否相同，不检查源地址，直接向“对端GT”参数对应的VLR/SGSN下发ISD请求消息，当ISD响应消息返回notice、abort或超时的情况时命令返回探测失败，其它场景命令返回操作成功，并在系统已上报“ALM-16013 容灾FE业务自动探测异常”告警时发送恢复告警消息恢复该告警。

## 注意事项

无。

## 参数说明

| 参数ID     | 参数名称   | 参数说明                                                                                                                                                                      |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PEERGT   | 对端GT   | 用于标识待发送MAP信令链路探测消息的VLR/SGSN的GT地址。如果需要手动恢复系统上报的还未恢复的“ALM-16013 容灾FE业务自动探测异常”告警，该参数需要从系统上报的告警信息中获取。如果在割接、容灾倒换等操作前使用该命令进行信令可用性探测，该参数由操作员统一规划。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。  |
| PEERTYPE | 对端类型   | 用于标识待发送MAP信令链路探测消息的对端类型。如果需要手动恢复系统上报的还未恢复的“ALM-16013 容灾FE业务自动探测异常”告警，该参数需要从系统上报的告警信息中获取。如果在割接、容灾倒换等操作前使用该命令进行信令可用性探测，该参数由操作员统一规划。 取值范围：VLR(VLR)SGSN(SGSN) 默认值：无。          |
| IMSI     | IMSI   | 用于标识待发送MAP信令链路探测消息的用户IMSI，确保用户未签约多卡多号类业务，多卡多号类业务包括MSIM、MIMSI、GroupSIM、CommonISDN、ALS、LinkSIM、一卡多号多Profile、Home Zone、Follow Me。由运营商提供测试IMSI。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 |

## 使用实例

发送MAP信令链路探测消息，“对端GT”为“8613901000”，“对端类型”为“VLR”，“IMSI”为“460011365002011”：

```
SND RDUCHECK: PEERGT="8613901000", PEERTYPE=VLR, IMSI="460011365002011";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|-------:|:------------------------------------|:------------------------------------------|:-----------------------------------------------------------------------|
|    217 | 信令链路探测失败                            | 可能原因为如下之一：对端GT不存在。用户在UDM中未开户。FE与对端设备断开连接。 | 根据实际情况，重新输入参数并再次执行命令，若命令执行失败，请参考“ALM-16013 容灾FE业务自动探测异常”告警的“处理步骤”进行处理。 |
| 335539 | 参数取值无效：参数IMSI的取值为6~15位十进制数字组成的字符串   | 输入的参数不符合取值要求。                             | 根据实际情况，重新输入不符合取值要求参数的取值，确保其取值符合要求。                                     |
| 335856 | 参数取值无效：参数PEERGT的取值为6~15位十进制数字组成的字符串 | 输入的参数不符合取值要求。                             | 根据实际情况，重新输入不符合取值要求参数的取值，确保其取值符合要求。                                     |
