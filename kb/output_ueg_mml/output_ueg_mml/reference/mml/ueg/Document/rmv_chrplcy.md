# 删除CHR话单功能输出策略(RMV CHRPLCY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中删除UDM网元的CHR话单功能输出策略的记录。

## 注意事项

当前版本不支持此功能，执行该命令后会返回错误码：“335607 暂不支持该功能”。

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                  |
|:-------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MSGINTERFACE | 消息接口   | 标识用户CHR话单输出策略记录的关键字段之一，用于指定需要删除哪个消息接口的CHR话单输出策略的记录。 取值范围：S6a(S6a)：S6a接口。                                                                                                              |
| CHRMSG       | 消息类型   | 标识用户CHR话单输出策略记录的关键字段之一，用于指定需要删除哪个消息类型的CHR话单输出策略的记录。 取值范围：全部选中全部清空全部灰化AIR_AIA(AIR_AIA)ULR_ULA(ULR_ULA)NOR_NOA(NOR_NOA)IDR_IDA(IDR_IDA)CLR_CLA(CLR_CLA)DSR_DSA(DSR_DSA)PUR_PUA(PUR_PUA) |
| IMSIPREFIX   | IMSI号段 | 标识用户CHR话单输出策略记录的关键字段之一，用于指定需要删除哪个IMSI号段的CHR话单输出策略的记录。若不输入，表示只删除当前已存在的不区分号段的记录。若需要删除区分号段的记录，该参数必须输入。 取值范围：1～15位十进制数字组成的字符串                                                             |

## 使用实例

删除一条“消息接口”为“S6a(S6a)”，“消息类型”为“ULR\_ULA(ULR\_ULA)”和“AIR\_AIA(AIR\_AIA)”组合且不区分号段的CHR话单输出策略记录。

```
RMV CHRPLCY: MSGINTERFACE=S6a, CHRMSG=ULR_ULA-1&AIR_AIA-1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释    | 原因分析                | 处理建议                                                                                                     |
|-------:|:---------|:--------------------|:---------------------------------------------------------------------------------------------------------|
| 335607 | 暂不支持该功能。 | 当前版本不支持此功能。         | 无需处理。                                                                                                    |
| 335821 | 记录不存在。   | 要删除的CHR话单输出策略记录不存在。 | 请按照一下步骤进行操作： 执行命令LST CHRPLCY查询已添加的所有消息的CHR单据生成策略记录。根据查询结果重新输入参数“消息接口”，“消息类型”或“IMSI号段”，确保这三个参数唯一确定的记录已存在。 |
