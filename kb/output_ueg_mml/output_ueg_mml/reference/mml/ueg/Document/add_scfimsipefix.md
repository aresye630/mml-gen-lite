## 命令功能

**须知** 

本命令属于高危命令，执行不当会导致用户鉴权失败、无法正常接入网络。因此执行该命令前，请仔细检查配置的正确性，确认无误后方可执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用于在IMSI号段组中增加一条IMSI号段的记录。当UDM需要通过指定的IMSI号段信息拒绝用户请求消息时，通过本命令在已配置的IMSI号段组（通过**ADD SCFIMSIGRP**命令配置）中添加一条IMSI号段信息记录，然后通过**ADD SCFCFG**命令引用该IMSI号段组来增加业务控制功能。

## 注意事项

- 该命令不允许进行批操作。
- 一个IMSI号段组中最多支持增加20条IMSI号段信息记录，UDM最多支持增加300条IMSI号段信息记录。

## 参数说明

| 参数标识      | 参数名称      | 参数说明                                                                                                   |
|:----------|:----------|:-------------------------------------------------------------------------------------------------------|
| GRPNAME   | IMSI号段组名称 | 用于标识一个IMSI号段组的名称。该参数必须先由ADD SCFIMSIGRP命令定义，然后才能在此处引用。 取值范围：长度不超过32的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 |
| IMSIPEFIX | IMSI号段    | 用于标识一个待增加的IMSI号段。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                        |

## 使用实例

配置一条IMSI号段记录，需要进行如下配置。

1. 根据图1中的参数索引关系，确认准备条件是否完成。

   执行**LST SCFIMSIGRP**命令查询待增加IMSI号段对应的IMSI号段组是否已增加。若未增加，需执行**ADD SCFIMSIGRP**命令增加该IMSI号段组，IMSI号段组的“IMSI号段组名称”为“GRPNAME1”。

   ```
   ADD SCFIMSIGRP: GRPNAME="GRPNAME1";
   ```
2. 执行本命令，增加IMSI号段记录。“IMSI号段组名称”为“GRPNAME1”，“IMSI号段”为“1831234567”。

   ```
   ADD SCFIMSIPEFIX: GRPNAME="GRPNAME1", IMSIPEFIX="1831234567";
   ```
