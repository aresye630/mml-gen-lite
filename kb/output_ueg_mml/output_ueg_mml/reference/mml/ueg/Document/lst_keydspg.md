# 查询关键SS7信令点组(LST KEYDSPG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为查询类命令，用于在FE/BE整体倒换功能中查询关键SS7信令点组。

- 若需要查询全部关键SS7信令点组数据记录的概要信息，请不要输入任何参数。
- 若需要查询某个关键SS7信令点组数据记录的详细信息，请输入“关键SS7信令点组名称”参数。

该命令的操作场景为：当使用FE/BE整体倒换功能时，查询关键SS7信令点组信息、关键SS7信令点组中配置的关键SS7信令点信息。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称        | 参数说明                                       |
|:----------|:------------|:-------------------------------------------|
| KEYDSPGNM | 关键SS7信令点组名称 | 用于指示系统需要按照哪个关键SS7信令点组名称来查询关键SS7信令点组及信令点信息。 |

## 使用实例

1. 查询所有关键SS7信令点组:

   ```
   LST KEYDSPG:;
   ```

   ```
   %%LST KEYDSPG:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    关键SS7对端组名称  关键SS7对端组在联动倒换中的比例（%）

    HSS01              70                                  
    SAE                80                                  
    HSS                90                                  
    IMS00              100                                 
    HLR02              100                                 
    IMS-HSS            99                                  
    HLR01              100                                 
   (结果个数 = 7)

   ---    END
   ```
2. 查询指定关键SS7信令点组，“关键SS7信令点组名称”为“KEY STP”:

   ```
   LST KEYDSPG: KEYDSPGNM="HLR01";
   ```

   ```
   %%LST KEYDSPG: KEYDSPGNM="HLR01";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
                      关键SS7对端组名称  =  HLR01
   关键SS7对端组在联动倒换中的比例（%）  =  100
   (结果个数 = 1)

   关键SS7对端如下
   ---------------
    关键SS7对端名称

    D001485883     
    W001964463     
    D001485882     
    W001964461     
    L001755091     
    L001755093     
    C001514791     
   (结果个数 = 7)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释                                        | 原因分析            | 处理建议                          |
|-------:|:--------------------------------------------|:----------------|:------------------------------|
| 317102 | 名称参数只允许输入： 0-9，a-z，A-Z，中划线，下划线，小数点，空格以及中文字符 | 输入的关键参数不能为非法字符。 | 根据实际情况，重新输入关键参数的取值，确保其取值符合要求。 |
