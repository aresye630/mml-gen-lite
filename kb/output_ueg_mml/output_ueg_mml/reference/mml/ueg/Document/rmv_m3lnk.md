# 删除M3UA链路(RMV M3LNK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于从配置数据库中删除一条M3UA链路数据记录。

## 注意事项

- 如果命令执行成功，且删除的数据为已有性能统计任务中登记的对象实例，则该对象实例后续上报的指标值为0。命令涉及的测量单元有：M3UA信令链路测量；命令涉及的对象有：M3UA信令链路。
- 如果本局与M3UA信令设备之间配置有2条或以上的M3UA链路（操作员可以使用**LST M3LNK**命令查询），则删除一条M3UA链路数据记录的操作步骤为：**RMV M3LNK**。
- 如果本局与M3UA信令设备之间仅配置有1条M3UA链路（操作员可以使用**LST M3LNK**命令查询），为确保本局与M3UA信令设备之间M3UA信令的通信连接，请确认必须删除时，再使用该命令执行删除操作。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                               |
|:-------|:---------|:---------------------------------------------------------------------------------------------------|
| LNKNM  | 链路名称     | 标识一条M3UA链路数据记录的关键字段，用于指定需要删除哪一条M3UA链路数据记录，操作员可以使用LST M3LNK命令查询获得。 取值范围: 长度不超过32的字符串 默认值: 无。 说明: 无。 |
| FRLF   | 删除最后链路标志 | 当该M3UA链路是相应M3UA链路集中的最后一条链路时，用于指示系统是否强制删除该M3UA链路。 取值范围: “TRUE(是)”“FALSE(否)” 默认值: FALSE(否)。 说明: 无。   |

## 使用实例

删除M3UA链路，“链路名称”为“M3LNK1-TOBAM2”,“删除最后链路标志”为“是”：

```
RMV M3LNK: LNKNM="M3LNK1-TOBAM2", FRLF=TRUE;
```
