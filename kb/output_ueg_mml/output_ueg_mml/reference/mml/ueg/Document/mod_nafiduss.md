# 修改所有用户必签指定NAFID的USS列表(MOD NAFIDUSS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在配置数据库中对某个网络应用功能组的必选USS信息进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识指定网络应用功能组的USS信息：

- “FQDN”
- “旧GSID”

  **说明** 

  该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                     |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FQDN    | FQDN   | 标识USS信息的关键字段之一（其取值不能被修改），用于指定需要对哪一个网络应用功能组的USS信息进行修改或调整，操作员可以使用LST NAFIDUSS命令查询获得。 需要指出的是，该参数不区分大小写，在执行LST NAFIDUSS命令查询出的报文中为全小写形式。 取值范围：长度不超过127的字符串。 默认值：无。 注意：该参数为必选参数。                                                                                                               |
| OLDGSID | 旧GSID  | 标识USS信息的关键字段之一，用于指定需要对哪一个网络应用功能组的USS信息进行修改或调整，操作员可以使用LST NAFIDUSS命令查询获得。 取值范围：0～999999。 默认值：无。 注意：该参数为必选参数。                                                                                                                                                                              |
| NEWGSID | 新GSID  | 用于在配置数据库中指定一个新的GBA业务标识。“新GSID”参数需要与对端IMS-HSS协商，运营商需要提前在IMS-HSS上配置GSID。 在用户接入权限检测过程中，UIM会将本命令配置的GSID与IMS-HSS上配置的GSID进行比较。满足以下两种情况，则检查通过：UIM通过该命令配置的GSID中有一个与IMS-HSS下发的GSID相同。UIM未通过该命令配置GSID。  说明： 针对VoLTE，推荐将“新GSID”参数配置为“2”，即“AUTHENTICATION_PROXY”。 取值范围：0～999999。 默认值：无。 注意：该参数为必选参数。 |

## 使用实例

修改用户必签指定的网络应用功能组的USS列表信息，携带以下参数：

- “FQDN”为“1”
- “旧GSID”为“1”
- “新GSID”为“2”

执行命令如下：

```
MOD NAFIDUSS: FQDN="1", OLDGSID=1, NEWGSID=2;
```
