# 查看SLF用户统计结果(DSP SSUBCT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行该命令会对性能有影响，建议在话务量低时执行。

该命令用于请求系统SLF用户实时统计结果。

- 若需要查询全部SLF用户数据记录的信息，请不要输入任何参数。
- 若需要查询某条SLF用户数据记录的详细信息，请输入“SLF用户统计类型”和“SLF用户统计匹配字符串”。

## 注意事项

- 该命令不允许进行批操作。
- 当前版本不支持此功能，执行该命令后会返回错误码：336360 当前网元不支持该命令。

## 参数说明

| 参数标识     | 参数名称         | 参数说明                                                                                                                                                                                                                                            |
|:---------|:-------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SCTTYPE  | SLF用户统计类型    | 用于指定需要统计的SLF用户类型。 取值说明： “SLF_IMPI（统计IMPI用户数量）”“SLF_DIMPU（统计DIMPU用户数量）”“SLF_WIMPU（统计WIMPU用户数量）”“SLF_PISI（统计PISI用户数量）”“SLF_DPUSI（统计非通配PUSI用户数量）”“SLF_WPUSI（统计通配PUSI用户数量）”“SLF_IMSI（统计IMSI用户数量）”“SLF_MSISDN（统计MSISDN用户数量）”“SLF_PU（统计PU的数量）” 默认值：无。 |
| SMTCHSTR | SLF用户统计匹配字符串 | 用于指定SLF用户统计的匹配字符串。只有匹配该字符串的用户号码才会被统计。 该参数为条件必选，当SCTTYPE值为SLF_PU时该参数必须存在。 取值范围：长度不超过127的字符串。 默认值：无。                                                                                                                                              |

## 使用实例

1. 查询SLF中的各种用户的数量。

   `DSP SSUBCT:;`

   ```
   %%DSP SSUBCT:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    SLF用户统计类型         SLF用户统计结果

    统计IMPI用户数量        0              
    统计非通配IMPU用户数量  0              
    统计通配IMPU用户数量    0              
    统计PISI用户数量        0              
    统计非通配PUSI用户数量  0              
    统计通配PUSI用户数量    0              
    统计IMSI用户数量        0              
    统计MSISDN用户数量      0              
   (结果个数 = 8)

   ---    END
   ```
2. 通配查询关键字为sip的所有PU用户数量。

   `DSP SSUBCT: SCTTYPE=SLF_PU, SMTCHSTR="sip";`

   ```
   %%DSP SSUBCT: SCTTYPE=SLF_PU, SMTCHSTR="sip";%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
   SLF用户统计类型  =  统计PU的数量
   SLF用户统计结果  =  0
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义如表1所示。

| 输出项名称     | 输出结果解释             |
|:----------|:-------------------|
| SLF用户统计类型 | 用于指定需要统计的SLF用户的类型。 |
| SLF用户统计结果 | 用于显示该SLF用户类型的个数。   |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释       | 原因分析        | 处理建议   |
|-------:|:------------|:------------|:-------|
| 336360 | 当前网元不支持该命令。 | 当前版本不支持此功能。 | 无需处理。  |
