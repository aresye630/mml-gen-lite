# 查询外部AS设备链路的配置信息(LST SLFASL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询SLF与AS设备之间的Diameter链路的配置信息：

- 若需要查询全部AS数据记录的信息，请不要输入任何参数。
- 若需要查询某条SLF与AS设备之间的Diameter链路数据记录的详细信息，请输入“链路名称”或其他参数或这些参数的组合。

## 注意事项

当SLF的“工作模式”被指定为“SERVER(服务器)”时，返回结果中参数“分发端口号”表示内部分发端口号，SLF整体对外端口号为3868，在用ADD DMLNK命令进行对端配置的时候需配置SLF的对外端口号为3868。

## 参数说明

| 参数标识    | 参数名称       | 参数说明                                                                                                                                                                                                       |
|:--------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SLFN    | SLF名称      | 用于标识查询SLF与AS设备之间的Diameter链路数据记录的SLF名称。 取值范围：1～127位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                   |
| ASN     | AS名称       | 用于标识查询SLF与AS设备之间的Diameter链路数据记录的AS名称。 取值范围：1～40位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                     |
| LNKN    | 链路名称       | 用于标识查询SLF与AS设备之间的Diameter链路数据记录的链路名称。 取值范围：1～127位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                    |
| PTYPE   | 传输协议类型     | 用于标识查询SLF与AS设备之间的Diameter链路数据记录的传输协议类型。 取值范围： SCTP(SCTP协议类型) TCP(TCP协议类型) UDP(UDP协议类型) 默认值：无。                                                                                                              |
| WMODE   | 工作模式       | 用于标识查询SLF与AS设备之间的Diameter链路数据记录的工作模式。 取值范围： CLIENT(客户端)：SLF在当前链路中作为客户端，会主动向对端服务器发起建链请求。 SERVER(服务器)：SLF在当前链路中作为服务器端，在建链时不会主动发起建链请求，会等待对端的建链请求。 SERVERMULTPORT(服务端多端口)：当SLF在当前链路中作为服务端多端口时，需要指定分发端口。 默认值：无。 |
| HSFMID  | HSF模块号     | 用于标识查询SLF与AS设备之间的Diameter链路数据记录的HSF模块号。 取值范围：1～1023 默认值：无。                                                                                                                                                 |
| ADDRN   | SLF地址名称    | 用于标识查询SLF与AS设备之间的Diameter链路数据记录的SLF地址名称。 取值范围：1～127位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                 |
| SADDRN  | SLF备用地址名称  | 用于标识查询SLF与AS设备之间的Diameter链路数据记录的SLF备用地址名称。 取值范围：1～127位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                               |
| LPT     | 分发端口号      | 用于标识查询SLF与AS设备之间的Diameter链路数据记录的分发端口号。 取值范围：1025～65534 默认值：无。                                                                                                                                              |
| PIPVER  | 对端IP地址版本   | 用于标识查询SLF与AS设备之间的Diameter链路数据记录的对端IP地址版本。 取值范围： IPV4(IPV4) IPV6(IPV6) 默认值：无。                                                                                                                               |
| PIPV4   | 对端IPV4地址   | 仅当本命令中的“对端IP地址版本”参数为“IPV4(IPV4)”时该参数有效。用于标识查询SLF与AS设备之间的Diameter链路数据记录的对端IPV4地址。 取值范围：IPv4地址。 默认值：无。                                                                                                       |
| PIPV6   | 对端IPV6地址   | 仅当本命令中的“对端IP地址版本”参数为“IPV6(IPV6)”时该参数有效。用于标识查询SLF与AS设备之间的Diameter链路数据记录的对端IPV6地址。 IPV6格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如，fc00:7864:0266:0000:0000:0000:7864:0266。 取值范围：IPv6地址。 默认值：无。          |
| SPIPVER | 对端备用IP地址版本 | 用于标识查询SLF与AS设备之间的Diameter链路数据记录的对端备用IP地址版本。 取值范围： IPV4(IPV4) IPV6(IPV6) 默认值：无。                                                                                                                             |
| SPIPV4  | 对端备用IPV4地址 | 用于标识查询SLF与AS设备之间的Diameter链路数据记录的对端备用IPV4地址。 取值范围：IPv4地址。 默认值：无。 说明：仅当本命令中的“对端备用IP地址版本”参数为“IPV4(IPV4)”时，该参数有效。                                                                                              |
| SPIPV6  | 对端备用IPV6地址 | 仅当本命令中的“对端备用IP地址版本”参数为“IPV6(IPV6)”时该参数有效。用于标识查询SLF与AS设备之间的Diameter链路数据记录的对端备用IPV6地址。 IPV6格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如，fc00:7864:0266:0000:0000:0000:7864:0266。 取值范围：IPv6地址。 默认值：无。      |
| PPT     | 对端端口号      | 用于标识查询SLF与AS设备之间的Diameter链路数据记录的对端端口号。 取值范围：0～65534 默认值：无。                                                                                                                                                 |

## 使用实例

1. 查询SLF设备与AS间链路的配置信息，“链路名称”为“LINK5”：

   ```
   LST SLFASL: LNKN="LINK5";
   ```

## 输出结果说明

以下列出的是未包含在本命令参数说明中的输出项，其他输出项的详细说明请参见本命令的参数说明。

| 输出项名称   | 输出项解释                               |
|:--------|:------------------------------------|
| SLF索引   | 用于返回一条SLF设备数据记录索引，该索引仅供内部使用，无实际含义。  |
| AS索引    | 用于返回一条AS设备数据记录索引，该索引仅供内部使用，无实际含义。   |
| 链路索引    | 用于返回一条AS设备链路数据记录索引，该索引仅供内部使用，无实际含义。 |
