# 增加Diameter链路集(ADD DMLKS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加一条Diameter链路集记录。

该命令使用场景：配置UDM通过Diameter信令与对端网元的对接数据时，通过本命令增加Diameter链路集。

该命令的参数索引关系如图1所示：

**图1** 命令参数的索引关系图

## 注意事项

- 一个Diameter本端实体和一个Diameter对端实体之间，只允许配置一个链路集。
- 系统最多允许配置128个Diameter链路集。

## 参数说明

| 参数标识     | 参数名称           | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|:---------|:---------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LINKSNAM | 链路集名称          | 用于标识UDM和对端网元之间的Diameter链路集名称。 取值范围：长度不超过127的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| LOCALNAM | Diameter本端实体名称 | 用于标识一个Diameter本端实体的名称。该参数必须先由ADD DMLE命令定义，然后才能在此处引用。 取值范围：长度不超过127的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| PEERNAM  | Diameter对端实体名称 | 用于标识一个Diameter对端实体的名称。该参数必须先由ADD DMPE命令定义，然后才能在此处引用。 取值范围：长度不超过127的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| LNKMOD   | 链路选择模式         | 用于标识该链路集内的Diameter链路选择模式。系统通过该参数决定使用哪条链路传输对接数据。 取值范围：SESSIONIDBASED(基于会话ID)：按照Session ID随机选取其中链路进行通信。如果Session ID AVP无效，就会默认选择第0条链路。POLLING(轮询方式)：对Diameter对端实体下的所有链路轮流选择，即在可用链路之间循环选择。AORS(主备方式)：当前只有一条链路主用，其余链路都是备用。只有当主用链路失效时，备用链路中的一条任意可用链路自动启用为主用链路。默认第0条链路为主链路，当第0条链路不可用时，会自动选择其他可用链路。ACTIVE(激活方式)：从第0条开始选择第一条激活的链路来工作。当该链路不可用时，则向后选择下一条激活链路。ACTIVEWITHPRI(基于优先级的激活方式)：选择优先级最高的一条激活链路来工作。优先级相同，则选择路由表中设置最靠前的一条激活链路。POLLINGWITHPRI(基于优先级的轮询方式)：对所有链路轮流选择，始终选择优先级最高的可用链路。存在多个优先级相同的链路时，在这些链路之间轮询选择。 默认值：无。 |

## 使用实例

配置UDM通过Diameter信令与对端网元的对接数据时需要增加Diameter链路集，需要进行如下配置。

1. 根据图1中的参数索引关系，确认准备条件是否完成。
   1. 执行**LST DMLE**命令查询待增加链路集对应的Diameter本端实体是否已增加。若未增加，需执行**ADD DMLE**命令增加该Diameter本端实体，Diameter本端实体的“实体名称”为“UDM”。

      ```
      ADD DMLE: EN="UDM", LOCTYPE=SAE-HSS, DN="huawei.com", HN="hss.huawei.com", DEFLOCAL=NO;
      ```
   2. 执行**LST DMPE**命令查询待增加链路集对应的Diameter对端实体是否已增加。若未增加，需执行**ADD DMPE**命令增加该Diameter对端实体，Diameter对端实体的“实体名称”为“MME”。

      ```
      ADD DMPE: EN="MME", PEERTYPE=OTHER, HN="peer.huawei.com";
      ```
2. 执行本命令，增加Diameter链路集。

   ```
   ADD DMLKS: LINKSNAM="HSS_MME", LOCALNAM="UDM", PEERNAM="MME", LNKMOD=POLLING;
   ```
