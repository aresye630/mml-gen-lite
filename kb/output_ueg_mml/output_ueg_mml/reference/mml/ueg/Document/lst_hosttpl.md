# 查询HOST模板(LST HOSTTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询HOST模板配置信息。

- 若需要查询全部HOST模板配置信息，请不要输入任何参数。
- 若需要查询某个HOST模板配置信息，请输入“索引”参数或“HOST”参数或这两个参数的组合。

  **说明** 

  该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                            |
|:-------|:-------|:------------------------------------------------|
| ID     | 索引     | 用于指示系统需要按照哪个“索引”查询HOST模板配置信息；若不输入，则表示所有的索引。     |
| HOST   | HOST   | 用于指示系统需要按照哪个“HOST”查询HOST模板配置信息；若不输入，则表示所有的HOST。 |

## 使用实例

1. 查询所有的HOST模板配置信息，不携带参数：

   ```
   LST APRULE:;
   ```

   ```
   %%LST HOSTTPL:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    索引    HOST  

    1       huawei.com 
    2       huawei2.com  
   (结果个数 = 2)

   ---    END
   ```
2. 查询“索引”为“1”，“HOST”为“huawei.com”的HOST模板配置信息：

   ```
   LST HOSTTPL: ID=1, HOST="huawei.com";
   ```

   ```
   %%LST HOSTTPL: ID=1, HOST="huawei.com";%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
     索引  =  1
     HOST  =  huawei.com
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD HOSTTPL**命令的参数说明。
