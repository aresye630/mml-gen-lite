# 去激活M3UA目的实体(DEA M3DE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为维护类命令，用于请求系统对处于激活状态的M3UA目的实体执行去激活操作，其对应的恢复命令为**ACT M3DE**。

该命令仅适用于测试或维护的操作场景。如果操作员不希望往某M3UA目的实体发送M3UA用户层信令，则操作员可以使用该命令实现这一目的。

执行该命令后，M3UA目的实体进入“去激活”状态，M3UA的用户将不能往此目的实体发送消息。

如果本局与某M3UA目的实体之间同时配有M3UA和MTP数据，并且M3UA路由和MTP路由均可用，则用户需要同时去激活M3UA目的实体和MTP目的信令点，才能中断本局与该目的实体之间的全部业务。

## 注意事项

对于被去激活的M3UA目的实体而言，执行该操作将可能导致其与本局的部分或全部M3UA用户层信令业务中断，其对系统运行的影响如下，请操作员在执行该操作之前仔细确认任务的可行性。

- 如果本局与该目的实体之间配置了MTP路由数据，并且MTP路由是可用的，则该操作不会使本局到目的实体的业务全部中断，但会加重MTP路由的负荷。
- 如果本局与该目的实体之间没有配置MTP路由数据，或者配置的MTP路由不可用，则该操作将使本局到目的实体的业务全部中断。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                         |
|:-------|:-------|:-------------------------------------------------------------|
| DENM   | 目的实体名称 | 标识某个M3UA目的实体的关键字段，用于指示系统去激活哪个M3UA目的实体。操作员可以使用LST M3DE命令查询获得。 |

## 使用实例

去激活M3UA目的实体，“目的实体名称”为“DE\_LXT”：

```
DEA M3DE: DENM="DE_LXT";
```
