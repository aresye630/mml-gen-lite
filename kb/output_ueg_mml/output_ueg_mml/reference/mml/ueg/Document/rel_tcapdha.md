# 释放TCAP对话资源(REL TCAPDHA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为维护类命令，用于请求系统释放用于TCAP对话的系统资源，避免资源闲置。

该命令的应用场景一般为：当TCAP或上层用户异常导致对话资源全部被占用时，操作员使用该命令可以释放对话资源。

## 注意事项

执行该命令后，系统将终止指定的TCAP对话，并导致相关的智能业务通话中断，请操作员在执行该操作之前仔细确认任务的可行性。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                              |
|:-------|:-------|:----------------------------------------------------------------------------------|
| MN     | 模块号    | 用于指定处理TCAP协议的CCU进程的模块号。可通过使用命令LST MODULE查询获得相应的模块号信息。 取值范围：1～1023 默认值：无。 说明：必选参数。 |
| PRT    | 协议类型   | 用于指定TCAP的协议类型。 取值范围： “ITU-T(ITU-T)”“ANSI(ANSI)” 默认值：“ITU-T(ITU-T)” 说明：可选参数。       |
| DLG    | 对话索引   | 用于指定需要释放资源的TCAP对话，可以在调试窗口的打印信息中找到被不正常占用的索引号。 取值范围：0～65535 默认值：无。 说明：可选参数。         |

## 使用实例

释放TCAP对话资源，“模块号”为“1000”：

```
REL TCAPDHA: MN=1000;
```
