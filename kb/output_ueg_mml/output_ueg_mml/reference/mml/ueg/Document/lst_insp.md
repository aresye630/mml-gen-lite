# 查询软件参数(LST INSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询软件参数的配置信息：

- 若需要查询全部软件参数的配置信息，请不要输入任何参数。
- 若需要查询某些软件参数的详细配置信息，请输入“软件参数类型”或其它参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                        |
|:---------|:--------|:----------------------------------------------------------------------------|
| INSPT    | 软件参数类型  | 用于指示系统需要按照哪个软件参数类型来查询软件参数的配置信息；若不输入，则表示所有的软件参数类型。                           |
| INSPN    | 软件参数名称  | 用于指示系统需要按照哪个软件参数名称来查询软件参数的配置信息；若不输入，则表示所有的软件参数名称。                           |
| INSPV    | 软件参数值   | 用于指示系统需要按照哪个软件参数值来查询软件参数的配置信息；若不输入，则表示所有的软件参数值。                             |
| INSPVD   | 软件参数默认值 | 用于标识需要查询的软件参数默认值。 取值范围：0～4294967294 默认值：无。                                  |
| INSPTYPE | 软件参数值标识 | 用于标识需要查询的软件参数标识。 取值范围： ALL（所有软参）MODIFIED（被修改的软参）UNMODIFIED（没有被修改的软参） 默认值：无。 |

## 使用实例

1. 查询修改过的软件参数配置信息：

```
LST INSP: INSPTYPE=MODIFIED;
```

```
%%LST INSP: INSPTYPE=MODIFIED;%%
RETCODE = 0  操作成功

操作结果如下
------------
 系统配置参数  软件参数类型  软件参数名称    软件参数值  软件参数默认值  软件参数值标识

 系统参数      HSS9860       UDT最大长度     254         230             被修改的软参  
 系统参数      全局数据管理  全局表同步时间  5           20              被修改的软参  
(结果个数 = 2)

---    END
```

2. 查询“软件参数类型”为“RELIABILITY(系统可靠性)”，“软件参数名称”为“WHOLESITESWITCH（是否支持FE-BE断链后倒换信令）”的配置信息：

```
LST INSP: INSPT=RELIABILITY, INSPN=WHOLESITESWITCH;
```

```
%%LST INSP: INSPT=RELIABILITY, INSPN=WHOLESITESWITCH;%%
RETCODE = 0  操作成功

操作结果如下
------------
  系统配置参数  =  系统参数
  软件参数类型  =  系统可靠性
  软件参数名称  =  是否支持FE-BE断链后倒换信令
    软件参数值  =  0
软件参数默认值  =  0
软件参数值标识  =  没有被修改的软参
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**MOD INSP**命令中的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释        | 原因分析           | 处理建议                             |
|-------:|:-------------|:---------------|:---------------------------------|
| 100016 | 参数的值不在指定范围内。 | 报错的参数值不在取值范围内。 | 请根据报错的参数取值范围，重新输入正确的参数值后重新执行本命令。 |
