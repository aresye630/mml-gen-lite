# 删除IMSI号段组(RMV SCFIMSIGRP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会导致用户鉴权失败、无法正常接入网络。因此执行该命令前，请仔细检查配置的正确性，确认无误方可执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用于从配置数据库中删除一条IMSI号段组记录。

## 注意事项

当系统已经通过**ADD SCFIMSIPEFIX**和**ADD SCFCFG**命令关联该IMSI号段组时，禁止删除该IMSI号段组。

## 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                     |
|:--------|:----------|:-------------------------------------------------------------------------|
| GRPNAME | IMSI号段组名称 | 用于标识一条IMSI号段组数据记录的关键字段，用于指定删除哪一条IMSI号段组数据记录，操作员可以使用LST SCFIMSIGRP命令查询获得。 |

## 使用实例

删除一条IMSI号段组记录。“IMSI号段组名称”为“group02”。

```
RMV SCFIMSIGRP: GRPNAME="group02";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                           | 原因分析                                                | 处理建议                                                                                                    |
|-------:|:------------------------------------------------|:----------------------------------------------------|:--------------------------------------------------------------------------------------------------------|
| 335609 | 指定GRPNAME不存在，请执行LST SCFIMSIGRP查询已经存在的记录。        | 输入的“IMSI号段组名称”参数不存在。                                | 根据实际情况，重新输入“IMSI号段组名称”参数的取值，确保其取值在系统中存在。已存在的“IMSI号段组名称”参数可以执行LST SCFIMSIGRP命令查询。                        |
| 335611 | 记录已经被引用，请执行LST SCFIMSIPEFIX、LST SCFCFG查询使用中的记录。 | 输入的“IMSI号段组名称”参数已经在ADD SCFIMSIPEFIX或ADD SCFCFG中被引用。 | 根据实际情况，确定是否要删除该IMSI号段组。如果确实需要删除，先通过RMV SCFIMSIPEFIX或MOD SCFCFG命令去引用该“IMSI号段组名称”，与该号段组解除关联关系，然后才能执行该令删除。 |
