# 增加它网RN数据(ADD ROUTNUM)

## 命令功能

该组命令用于增加号码携转业务中它网RN（Route Number）路由的数据记录信息，命令中携带参数包括对应网络名称和路由码。

在号码携带业务中，设置完成短消息互通网关用户数据后，需要给用户设置短消息RN路由。NPMSC根据用户携出的短消息RN路由将MAP信令消息转换为Deliver消息转发给短信互通网关，完成短消息下发。短消息RN路由即它网RN路由，该数据一般由运营商规划，用于标识不同运营商的不同网络，操作员在配置时可向运营商获取。该组命令用户设置标识本网络的路由码。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                          |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------|
| NAME   | 网络名称   | 用于标识待设置它网RN路由数据的网络名称。 取值范围：1～20个字母或数字组成的字符串。 默认值：无                                                            |
| RN     | 路由码    | 用于标识待设置它网RN路由数据的路由码。 取值范围：由0～9数字或a～e字符组成的1～10位字符串，不区分大小写。 默认值：无 说明：该参数取值由运营商规划，用于标识不同运营商的不同网络，操作员在配置时可向运营商获取。 |

## 使用实例

为保证号码携带业务用户的短消息业务能够顺利转发，操作员需要配置路由码信息。其中“网络名称”为“name1”，“路由码”为“1113”，执行命令如下：

```
ADD ROUTNUM: NAME="name1", RN="1113";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释   | 原因分析              | 处理建议                            |
|-------:|:--------|:------------------|:--------------------------------|
| 352044 | 用户已存在   | “路由码”指定的数据记录已存在。  | 使用LST ROUTNUM命令查询，确保输入的数据记录不存在。 |
| 352047 | 参数取值无效  | “路由码”参数输入不符合取值范围。 | 根据实际情况，重新输入“路由码”，确保其取值符合取值范围。   |
