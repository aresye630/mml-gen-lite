# 增加SCCP目的负荷分担信令点(ADD SCCPLDSH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条SCCP目的负荷分担信令点数据记录。

## 注意事项

仅当本局与对端设备之间的SCCP信令路由需要支持互助功能时，操作员才需要使用**ADD SCCPLDSH**

- 主备用：假设A的备用节点为B，当本局需要向A发送SCCP信令消息时，在正常情况下，本局将把SCCP信令消息直接发往A；当本局到A的SCCP信令路由不可用时，本局将把SCCP信令消息发往B。
- 负荷分担：假设A的负荷分担节点为B，当本局需要向A发送SCCP信令消息时，本局将把50%的SCCP信令消息直接发往A；把50%的SCCP信令消息发往B。

需要指出的是，如果本局与某个信令设备（如MSC）之间的SCCP信令路由是基于被叫用户地址中的GT码来寻址的话，即SCCP消息中的地址表示语字段中的“路由表示语”比特为0，则运营商可以通过使用SCCP目的信令点的互助功能来提高SCCP信令路由的可靠性。

| LSDP1  | 1号负荷分担信令点名称  | 对应于上述SCCP目的信令点，用于指定其互助的SCCP目的信令点的名称，该参数必须先由ADD SCCPDSP命令定义，然后才能在此处索引。 取值范围：长度不超过32的字符串。 默认值：无。 说明：需要指出的是，配置负荷分担信令点时，需要从1号负荷分担信令点开始依次配置，不可以间隔配置。                                                                                                                                                                                                                |
| PLSDP1 | 1号负荷分担信令点优先级 | 用于指定各负荷分担信令点的优先级。 取值范围：0～8。 默认值：无。 说明：该参数的配置原则是：若输入0：表示SCCP信令路由的互助功能采用负荷分担的方式。若操作员配置的优先级为0的负荷分担信令点有N个，则在正常情况下，每个负荷分担信令点承载的SCCP信令负荷为1/(N+1)。 若输入1～8：表示SCCP信令路由的互助功能采用主备用的方式。若操作员配置的优先级为1～8的负荷分担信令点有多个，则系统将首先按照优先级进行分组，优先级相同的信令点为一组，组内按平均百分比实现SCCP信令路由的负荷分担，组间则按优先级（数字越小、优先级越高）进行选择。对于优先级不同的信令点而言，只有当高优先级的信令点不可达时，本局才选择向低优先级的信令点发送SCCP信令消息，其余情况依此类推。 若不输入，则默认为0。 |

## 使用实例

1、增加SCCP负荷分担目的信令点，“DSP名称”为“DSP”，“1号负荷分担信令点名称”为“DSP1”，“对应的优先级”为“0”：

```
ADD SCCPLDSH: DPNM="DSP", LSDP1="DSP1", PLSDP1=0;
```

2、增加SCCP负荷分担目的信令点，“DSP名称”为“DSP”，“1号负荷分担信令点名称”为“DSP1”，“对应的优先级”为“0”，“2号负荷分担信令点名称”为“DSP2”，“对应的优先级”为“1”：

```
ADD SCCPLDSH: DPNM="DSP", LSDP1="DSP1", PLSDP1=0, LSDP2="DSP2", PLSDP2=1;
```
