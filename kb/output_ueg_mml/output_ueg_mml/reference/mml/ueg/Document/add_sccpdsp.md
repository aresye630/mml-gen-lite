# 增加SCCP目的信令点(ADD SCCPDSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条SCCP目的信令点数据记录。在该命令中，以下关键参数需要与对端信令设备协商：

- 网络指示
- 目的信令点编码
- 源信令点编码
- 信令规范

## 注意事项

SCCP DPC (目的信令点)：SCCP目的信令点编码用于指明信息传送的目的节点。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|:-------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DPNM   | 目的信令点名称 | 用于在本局的配置数据库中唯一标识一个SCCP目的信令点。 取值范围：长度不超过32位的字符串，字符串只允许输入：0-9，a-z，A-Z，“-”、“_”、“.”、空格符、和中文字符。 默认值：无。 说明：操作员在本命令配置的“SCCP目的信令点名称”与其使用ADD M3DE命令定义的“目的实体名称”是不同的参数，其相互之间没有任何索引与被索引的关系。 对于操作员在客户端输入的字符串，系统在操作OMU数据库之前将自动进行如下处理：将该字符串中的所有英文字母全部转换成大写、并将该字符串中最左边与最右边的空格删除掉。例如，假设操作员在客户端输入的字符串为“ 区域abc ”，则系统在操作OMU数据库之前将自动将该字符串转换为“区域ABC”。 对于操作员通过本命令配置的某一条具体的数据记录而言，假设该数据记录中“目的信令点名称”字段的原取值为A，如果操作员后续需要将该字段的取值由A修改为B，则其可以通过MOD SCCPDSP命令中的“新目的信令点名称”参数重新进行定义。此时，对于配置数据库中索引了取值为A的所有数据记录的“目的信令点名称”字段，系统将自动把这些字段的值由A修改为B。 |
| NI     | 网络指示    | 本局与对端设备的对接参数之一，用于指定对端设备的信令点编码属于哪一个信令网。 取值范围： “INT(国际主用网)”“INTB(国际备用网)”“NAT(国内主用网)”“NATB(国内备用网)” 默认值：无。 说明：操作员应根据实际情况进行设置。                                                                                                                                                                                                                                                                                                                                                                                    |
| DPC    | 目的信令点编码 | 本局与对端设备的对接参数之一，用于在本局的配置数据库中定义一个SCCP目的信令点。 取值范围： 当信令点进制类型为十六进制时，信令点编码允许以下方式输入：十六进制字符串（如：1AB2AB或H'1AB2AB）。中间不允许有空格和其他非十六进制字符。范围是0x0～0xFFFFFF（24位信令点编码）或0x0～0x003FFF（14位信令点编码）。 当信令点进制类型为十进制整数格式时，信令点编码允许以下方式输入：十进制整数字符串（如：1749675）。中间不允许有空格、其他非十进制字符。范围是0～16777215（24位信令点编码）或0～16383（14位信令点编码）。 默认值：无。 说明：该参数必须输入、且必须先由ADD M3DE命令定义，然后才能在此处索引。当本局与MSC、SCP、SGSN、GMLC等设备进行对接时，由于MAP、BSSAP/INAP、CAP-等协议均基于SCCP进行传输，因此，操作员需要在本局侧将这些设备的信令点编码均定义为SCCP目的信令点。                                                          |
| OPC    | 源信令点编码  | 本局与对端设备的对接参数之一，当本局在向对端设备发送SCCP信令消息时，用于指定在相应的SCCP信令消息中将携带哪个源信令点编码。 取值范围： 当信令点进制类型为十六进制时，信令点编码允许以下方式输入：十六进制字符串（如：1AB2AB或H'1AB2AB）。中间不允许有空格和其他非十六进制字符。范围是0x0～0xFFFFFF（24位信令点编码）或0x0～0x003FFF（14位信令点编码）。 当信令点进制类型为十进制整数格式时，信令点编码允许以下方式输入：十进制整数字符串（如：1749675）。中间不允许有空格、其他非十进制字符。范围是0～16777215（24位信令点编码）或0～16383（14位信令点编码）。 默认值：无。 说明：该参数必须先由SET OFI或ADD OFI命令定义，然后才能在此处索引。                                                                                                                                        |
| PRT    | 信令规范    | 本局与No.7信令设备的对接参数之一，用于指示本局与该目的信令点之间的No.7信令遵循哪个组织制定的规范。若本局与遵循ANSI规范的信令点设备进行对接，则该参数必须选择“ANSI”，否则，两信令设备之间的MTP链路将不能正常运行。 取值范围： “ITU-T(ITU-T)”“ANSI(ANSI)” 默认值：“ITU-T(ITU-T)”。 说明：无。                                                                                                                                                                                                                                                                                                                               |

## 使用实例

1、增加SCCP目的信令点，“目的信令点名称”为“TMSC1”，“网络指示”为“国内主用网”，“目的信令点编码”为“0x0DFF03”（网络结构为SP24），“源信令点编码”为“0x00122F”（网络结构为SP24），“信令规范”为“ANSI”：

```
ADD SCCPDSP: DPNM="TMSC1",NI=NAT, DPC="0DFF03", OPC="00122F",PRT=ANSI;
```

2、增加SCCP目的信令点，“目的信令点名称”为“TMSC1”，“网络指示”为“国内主用网”，“目的信令点编码”为“0x0DFF03”（网络结构为SP24），其余参数使用默认值：

```
ADD SCCPDSP: DPNM="TMSC1", NI=NAT, DPC="0DFF03" ;
```
