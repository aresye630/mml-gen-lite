# 修改业务条件操作统计对象(MOD STATSTRNG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行该命令后同时增加业务条件统计任务会对性能有影响，建议在话务量低时执行。

该命令用于对统计对象的配置信息进行修改。

该命令的使用场景：对系统中已存在的一个统计对象的配置信息进行修改。

## 注意事项

- 统计功能会消耗较多系统资源，请在业务空闲时执行。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|:----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OBJECTID  | 统计对象ID | 标识一个统计对象配置信息的关键字段，用于指定需要对哪一个统计对象进行修改，操作员可以使用LST STATSTRNG命令查询获得。 统计对象ID无法通过该命令进行修改。如果统计对象ID错误，操作员应执行RMV STATSTRNG命令删除错误的统计对象信息，然后再执行ADD STATSTRNG添加正确的统计对象信息。 取值范围：“OBJECT1(OBJECT1)”～“OBJECT64(OBJECT64)” 默认值：无。                                                                                                                                                                                                                                       |
| TYPE      | 统计类型   | 标识一个统计对象配置信息的关键字段。用于指定需要对哪一个统计对象进行修改，操作员可以使用LST STATSTRNG命令查询获得。该参数不能被修改。 取值范围：“STAT_STRING_FORGT(按GT局向统计)”“STAT_PRE_FIX_FORGT(按前缀GT局向统计)”“STAT_REVERSE_FORGT(按STRING以外GT局向统计)”“STAT_PLMN(按PLMN统计)”“STAT_SRCODE(按SRCODE统计)”“STAT_DIAMHOST(按DIAMHOST统计)”“STAT_IMSHOST_FORREPSYNC(按IMSHOST统计透明数据同步消息)” 默认值：无。                                                                                                                                             |
| PARAMETER | 参数     | 用于定义待修改统计对象的实际参数值。 取值范围：“统计类型”为“STAT_STRING_FORGT(按GT局向统计)”，“STAT_PRE_FIX_FORGT(按前缀GT局向统计)”，“STAT_REVERSE_FORGT(按STRING以外GT局向统计)”时，“参数”是长度不超过15的数字字符串。“统计类型”为“STAT_PLMN(按PLMN统计)”时，“参数”是长度为5～6位的数字字符串。当长度为6时，第六个字符可以为‘F’。“统计类型”为“STAT_SRCODE(按SRCODE统计)”时，“参数”是由‘*’，‘#’，数字组成的长度不超过16的字符串。“统计类型”为“STAT_DIAMHOST(按DIAMHOST统计)”时，“参数”是由长度为1～127位的数字、字母、“_”、“.”和“@”组成字符串。“统计类型”为“STAT_IMSHOST_FORREPSYNC(按IMSHOST统计透明数据同步消息)”时，“参数”是由长度不超过127的字符串组成。 默认值：无。 |

## 使用实例

1. 在系统运行过程中，由于操作失误，导致添加的统计对象“OBJECT1(OBJECT1)”的“参数”值错误。修改“参数”为“6688545”：

   `MOD STATSTRNG: OBJECTID=OBJECT1, PARAMETER="6688545";`
2. 在系统运行过程中，由于业务需要，修改统计对象“OBJECT2(OBJECT2)”的“参数”为“98333”：

   `MOD STATSTRNG: OBJECTID=OBJECT2, PARAMETER="98333";`

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                                                  | 原因分析                 | 处理建议                       |
|-------:|:-----------------------------------------------------------------------|:---------------------|:---------------------------|
| 335110 | 统计类型不能修改                                                               | 统计类型被修改。             | 统计类型不能被修改，根据实际情况修改“参数”的取值。 |
| 451553 | 参数取值无效：当参数TYPE的取值是STAT_DIAMHOST时，参数PARAMETER是由0~9，a-z，A-Z，@，.，_组合的字符串。 | “参数”输入值不对，不在其取值范围之内。 | 根据实际情况,重新输入“参数”的值。         |
