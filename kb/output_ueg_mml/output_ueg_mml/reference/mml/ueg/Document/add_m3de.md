# 增加M3UA目的实体(ADD M3DE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条M3UA目的实体数据记录。在该命令中，以下关键参数需要与对端M3UA信令设备协商：

- 目的实体信令点编码
- 目的实体类型
- 路由上下文
- M3UA协议版本
- 外部网络指示
- 网络外貌

## 注意事项

最大支持512条M3UA目的实体配置。

## 参数说明

| 参数标识      | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|:----------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DENM      | 目的实体名称    | 用于在本局的配置数据库中定义一个M3UA目的实体。当对端信令设备与本局之间存在着直达的M3UA信令路由时，则操作员必须将该信令设备定义为目的实体。例如： 当本局通过M3UA链路直接与SG、MSC、SCP、固定软交换、移动软交换等设备对接时，则操作员需将这些设备定义为目的实体。当对端信令设备为目的信令点时，则操作员必须将该信令设备定义为目的实体。例如，当本局通过SG、STP的转接后与5个MSC、2个PSTN交换机对接时，则操作员需将MSC、PSTN交换机均定义为目的实体（不包括STP），共7个。 取值范围：长度不超过32的字符串。 默认值：无。 说明： 对于操作员在客户端输入的字符串，系统在操作OMU数据库之前将自动进行如下处理：将该字符串中的所有英文字母全部转换成大写、并将该字符串中最左边与最右边的空格删除掉。例如，假设操作员在客户端输入的字符串为“ 区域abc ”，则系统在操作OMU数据库之前将自动将该字符串转换为“区域ABC”。 对于操作员通过本命令配置的某一条具体的数据记录而言，假设该数据记录中“目的实体名称”字段的原取值为A，如果操作员后续需要将该字段的取值由A修改为B，则其可以通过MOD M3DE命令中的“新目的实体名称”参数重新进行定义。此时，对于配置数据库中索引了取值为A的所有数据记录的“目的实体名称”字段，系统将自动把这些字段的值由A修改为B。                                                                                                                                 |
| LENM      | 本地实体名称    | 当本局在向对端M3UA目的实体发送M3UA消息时，用于指定在相应的M3UA消息中将携带哪个本地实体的源信令点编码，该参数必须先由ADD M3LE命令定义，然后才能在此处引用。 取值范围：长度不超过32的字符串。 默认值：无。 说明：如果用户不输入此参数，系统则默认为第一个本地实体。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| NI        | 网络指示      | 即内部网络指示语，用于指定该目的实体的信令点编码在本局的内部属于哪一个信令网，它可以是国际主用网、国际备用网、国内主用网或国内备用网。 取值范围：“INT(国际主用网)”“INTB(国际备用网)”“NAT(国内主用网)”“NATB(国内备用网)” 默认值：“NAT(国内主用网)”	。 说明：该参数与本命令中的“外部网络指示”参数配合使用，以实现内部网络指示语与外部网络指示语之间的转换功能，其配置原则是：若该目的实体的DPC与本局的OPC位于同一个信令网、且它们具有相同的编码结构（即同为14位或同为24位），则操作员仅需要将内部网络指示语设置成与目的信令点保持一致即可，而无需配置外部网络指示语。 若该目的实体的DPC与本局的OPC位于同一个信令网、但它们具有不同的编码结构（即一个为14位、另一个为24位），则操作员需要将外部网络指示语设置成与目的实体保持一致，而将内部网络指示语设置成对应的备用网或主用网。例如，假设DPC位于国际主用网，则操作员在本局侧需将该DPC的外部网络指示语设为“国际主用网”，而将内部网络指示语设为“国际备用网”；又如，假设DPC位于国内主用网，则操作员在本局侧需将该DPC的外部网络指示语设为“国内主用网”，而将内部网络指示语设为“国内备用网”；其余情况依此类推。                                                                                                                                                                        |
| DPC       | 目的实体信令点编码 | 本局与M3UA信令设备的对接参数之一，用于指定该目的实体在No.7信令网中的信令点编码。 取值范围：长度不超过11的字符串。 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| STPF      | STP标志     | 用于指定该目的实体是否具备信令转接（STP）的功能，仅当目的实体为与本局直联的SG设备时，该参数设为“TRUE(是)”，其余情况均设为“FALSE(否)”。 取值范围： “TRUE(是)”“FALSE(否)” 默认值：“FALSE(否)”。 说明：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| SLSSM     | 链路集选择掩码   | 用于指示本局在去往该目的实体的多个M3UA链路集之间如何实现信令业务的负荷分担。 取值范围： “B0000(链路集选择掩码0)”“B0001(链路集选择掩码1)”“B0010(链路集选择掩码2)”“B0011(链路集选择掩码3)”“B0100(链路集选择掩码4)”“B0101(链路集选择掩码5)”“B0110(链路集选择掩码6)”“B0111(链路集选择掩码7)”“B1000(链路集选择掩码8)”“B1001(链路集选择掩码9)”“B1010(链路集选择掩码10)”“B1011(链路集选择掩码11)”“B1100(链路集选择掩码12)”“B1101(链路集选择掩码13)”“B1110(链路集选择掩码14)”“B1111(链路集选择掩码15)” 默认值：“B1111(链路集选择掩码15)”。 说明：当本局与目的实体之间仅存在一个链路集时，该参数可以设为任意值。 当本局与目的实体之间存在2个链路集时，该参数中“1”的个数必须大于或等于1，例如为B0001、B1100、B1111。 当本局与目的实体之间存在3～4个链路集时，该参数中“1”的个数必须大于或等于2，例如为B0011、B1100、B1111。 当本局与目的实体之间存在5～8个链路集时，该参数中“1”的个数必须大于或等于3，例如为B1011、B1110、B1111。 当本局与目的实体之间存在9～16个链路集时，该参数只能设为B1111。 为避免出现同摆的现象，操作员不能将链路集选择掩码与各链路集的链路选择掩码（由ADD M3LKS命令配置）设成同一个编码，一般建议将两个掩码中“1”的位置错开。例如，假设链路集选择掩码为0110，则链路选择掩码可设为1001。 |
| DET       | 目的实体类型    | 本局与M3UA信令设备的对接参数之一，用于指定该目的实体在M3UA链路集中的应用模式。 取值范围： “SP(信令点)”“SG(信令网关)”“AS(应用服务器)” 默认值：无。 说明：在非对等组网模式中，当目的实体为通过SG与本局对接的MSC、SCP等设备时，该参数设为“SP(信令点)”。 在非对等组网模式中，当目的实体为与本局直联的SG设备时，该参数设为“SG(信令网关)”。 在对等组网模式中，当目的实体为与本局直联的MSC、SCP、固定软交换等设备时，该参数设为“AS(应用服务器)”。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ADJF      | 相邻标志      | 仅当本命令中的“目的实体类型”参数为“SG(信令网关)”或“AS(应用服务器)”时该参数有效，用于指定本局与对端目的实体之间是否存在直达的M3UA信令路由。 取值范围： “TRUE(是)”“FALSE(否)” 默认值：“TRUE(是)”。 说明：当目的实体与本局之间的M3UA消息不需要经过SG转发时，该参数设为“TRUE(是)”；当目的实体与本局之间的M3UA消息需要经过SG转发时，该参数设为“FALSE(否)”。例如：在非对等组网模式中，当目的实体为通过SG与本局对接的MSC、SCP等设备时，该参数设为“FALSE(否)”。 在非对等组网模式中，当目的实体为与本局直联的SG时，该参数设为“TRUE(是)”。 在对等组网模式中，无论目的实体为何种设备，该参数一律设为“TRUE(是)”。                                                                                                                                                                                                                                                                                                                                                                                   |
| NM        | 网络模式      | 仅当本命令中的“目的实体类型”参数为“AS(应用服务器)”或者“SG(信令网关)”时该参数有效。用于指定与本局对接的该网元是独占一个信令点编码（独占信令点），还是与其他网元共享一个信令点编码（非独占信令点）。 取值范围： “INCLUSIVE(共享信令点)”“EXCLUSIVE(独占信令点)” 默认值：“EXCLUSIVE(独占信令点)”。 说明：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| RC        | 路由上下文     | 仅当本命令中的“目的实体类型”参数为“AS(应用服务器)”时该参数有效。用于定义该应用服务器作为客户端在向本局发送注册请求时的选路关键字。 取值范围：0～2147483647。 默认值：无。 说明：路由上下文可以为一个十进制的数字，也可以为空（不配置），具体对接时需要双方协商一致。 若输入“2147483647”，则表示路由上下文为空，即不使用路由上下文。 路由上下文在系统内必须唯一。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| DEVER     | M3UA协议版本  | 本局与M3UA信令设备的对接参数之一，用于指定目的实体支持哪个版本的M3UA协议。 取值范围： “RFC3332(RFC3332)”“DRAFT10(DRAFT10)” 默认值：“RFC3332(RFC3332)”。 说明：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| EXNI      | 外部网络指示    | 本局与M3UA信令设备的对接参数之一，用于指定该目的实体的信令点编码属于哪一个信令网，它可以是国际主用网、国际备用网、国内主用网或国内备用网。该参数与本命令中的“内部网络指示”参数配合使用，以实现内部网络指示语与外部网络指示语之间的转换功能，其配置原则请参考“内部网络指示语”的相关说明。 取值范围： “INT(国际主用网)”“INTB(国际备用网)”“NAT(国内主用网)”“NATB(国内备用网)” 默认值：无。 说明：在默认的情况下，若操作员不指定外部网络指示语的类型，则系统默认该目的实体的外部网络指示语与内部网络指示语为同一种类型。                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| PRIORITY  | 网络优先级     | 用于指定到该目的信令点所使用的网络优先级。 系统将会首先尝试使用选定的网络进行消息发送。如果发送失败，系统才会尝试使用其他网络发送消息。 取值范围：“0：M3UA优先”“1：MTP3优先” 默认值：“0：M3UA优先”。 说明：该参数只有在执行MOD MSFP命令将M3DE网络优先级软参（33号软参bit7）设置为“0”后才起作用。M3DE网络优先级软参默认值为“1”。为保证一致性，在增加新的目的实体时，如果在记录中已存在NI、DPC、OPC均与新增实体相同的记录，那么新目的实体的网络优先级的值必须与已有记录相同，否则增加操作将无法成功。                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| PRT       | 协议类型      | 用于设定24位网络结构下，主动下发的消息中SLS“信令链路选择掩码”，是按照“ITU-T”协议计算还是按照“ANSI”协议计算。 取值范围： “ITU-T(ITU-T)”“ANSI(ANSI)” 默认值：“ITU-T(ITU-T)”。 说明：当设置为“ITU-T(ITU-T)”协议时，“扩展ANSI SLS功能”软参（MOD MSFP60号软参）无效，主动下发的消息中SLS“信令链路选择掩码”默认为4bit。当设置为“ANSI(ANSI)”协议时，“扩展ANSI SLS功能”软参生效，支持设定主动下发的消息中SLS“信令链路选择掩码”为4bit、5bit或8bit。                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| NETAPPEAR | 网络外貌      | 本局与M3UA信令设备的对接参数之一，用于指定目的实体使用的网络外貌取值。 网络外貌取值可以为一个十进制的数字，也可以为空（不配置），具体对接时需要双方协商一致。若输入“4294967295”，则表示网络外貌取值为空，即不使用网络外貌取值。 取值范围：0~4294967295 默认值：4294967295。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |

## 使用实例

1、增加M3UA目的实体，“目的实体名称”为“M3DE”，“目的实体类型”为“AS(应用服务器)”，“目的信令点编码”为“F3333F”：

```
ADD M3DE: DENM="M3DE", DPC="F3333F", DET=AS;
```

2、增加M3UA目的实体，“目的实体名称”为“M3DE”，“本地实体名称”为“M3LE”，“目的实体类型”为“AS(应用服务器)”，“目的信令点编码”为“666666”：

```
ADD M3DE: DENM="M3DE", LENM="M3LE", DPC="666666", DET=AS;
```
