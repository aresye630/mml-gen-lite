# 增加鉴权向量下发策略(ADD AUTHVECCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中增加鉴权向量下发策略的记录。

仅当操作员通过**MOD INSP**命令将“QUINTUPLETNUMCTR(基于局向的鉴权五元组数控制)”参数设为“1”时配置的数据会在业务流程中生效。

## 注意事项

最多允许添加100条鉴权向量下发策略的记录。

## 参数说明

| 参数标识                   | 参数名称                            | 参数说明                                                                                                                                                                                  |
|:-----------------------|:--------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CFGNAME                | 策略名称                            | 用于在本局的配置数据库中唯一标识一条鉴权向量下发策略数据。 取值范围：长度不超过32位的字符串 默认值：无。 说明： 字符串只允许输入：0-9，a-z，A-Z，“-”、“_”、“.”、空格符、和中文字符。该参数仅对CS/PS域鉴权流程生效。必选参数。                                                         |
| ADDRTYPE               | 地址类型                            | 用于定义一条记录中生效的设备地址类型。 取值范围：SPC(信令点)GT(GT) 默认值：无。 说明：必选参数。                                                                                                                               |
| SPC                    | 信令点                             | 仅当本命令的参数“地址类型”取值为“SPC(信令点)”时，该参数有效。用于定义一条记录中生效的设备的SPC地址。 取值范围：长度不超过11位的十六进制字符串 默认值：无。 说明：必选参数。                                                                                        |
| GT                     | GT                              | 仅当本命令的参数“地址类型”取值为“GT(GT)”时，该参数有效。用于定义一条记录中生效的设备的GT地址。 取值范围：长度不超过20位的BCD码 默认值：无。 说明：必选参数。                                                                                              |
| CONTROLOFQUINTUPLETNUM | 控制VLR/SGSN请求鉴权五元组时HLR下发鉴权五元组的组数 | 用于标识UDM在VLR/SGSN通过SAI（Send Authentication Information）消息请求鉴权五元组时返回的最大组数。 取值范围：0：不限制鉴权向量组数。1～5：限制的鉴权向量最大组数。 默认值：无。 说明： 使用该参数对下发的鉴权五元组进行限制时，以VLR/SGSN请求的鉴权数量和本参数取值两者中的最小值为准返回鉴权向量。必选参数。 |

## 使用实例

增加一条鉴权向量下发策略的记录，“策略名称”为“XFCL01”，“地址类型”为“SPC(信令点)”，“SPC地址名称”为“12345”，“控制VLR/SGSN请求鉴权五元组时HLR下发鉴权五元组的组数”为“1”。

```
ADD AUTHVECCFG: CFGNAME="XFCL01", ADDRTYPE=SPC, SPC="12345", CONTROLOFQUINTUPLETNUM=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                                     | 原因分析                     | 处理建议                                                                      |
|-------:|:----------------------------------------------------------|:-------------------------|:--------------------------------------------------------------------------|
| 335814 | 记录达到最大数量。                                                 | 增加的鉴权向量下发策略记录超过限定值100。   | 请先使用LST AUTHVECCFG命令查询已添加过的策略，使用RMV AUTHVECCFG命令删除不需要的鉴权向量下发策略记录后重新执行本命令。 |
| 335874 | 指定名称的记录已经存在。                                              | 指定的策略名称的记录已经存在。          | 请先使用LST AUTHVECCFG命令查询已添加过的策略。然后根据查询结果重新输入“策略名称”。                         |
| 335875 | 指定地址的记录已经存在。                                              | 要增加的SPC/GT地址信息与已有记录完全一致。 | 请先使用LST AUTHVECCFG命令查询已添加过的策略。然后根据查询结果重新输入“地址类型”、“信令点”或“GT”。              |
| 335877 | 参数值无效：参数CFGNAME取值只允许输入：0-9，a-z，A-Z，“-”、“_”、“.”、空格符、和中文字符。 | 输入的“策略名称”参数的取值不符合取值范围。   | 参考参数说明中的取值范围，重新输入该参数。                                                     |
