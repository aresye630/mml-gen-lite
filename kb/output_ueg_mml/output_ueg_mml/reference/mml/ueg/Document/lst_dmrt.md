# 查询Diameter路由(LST DMRT)

- 注意事项

## 命令功能

该命令用于在Diameter路由表中查询已配置的Diameter路由信息：

- 若需要查询全部Diameter路由的配置信息，请不要输入任何参数。
- 若需要查询某些Diameter路由的配置信息，请输入“路由组名称”参数或“对端标识名称”参数或这两个参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                             |
|:---------|:-------|:-----------------------------------------------------------------|
| RTNAME   | 路由组名称  | 用于指示系统按照哪个Diameter路由组名称来查询Diameter路由信息；若不输入，则表示所有的Diameter路由组名称。 |
| PEERNAME | 对端标识名称 | 用于指示系统按照哪个Diameter对端标识名称来查询Diameter路由信息；若不输入，则表示所有的Diameter对端实体。 |

## 使用实例

1. 查询所有Diameter路由表的配置信息。

   ```
   LST DMRT:;
   ```

   ```
   %%LST DMRT:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    路由组名称  对端标识名称 

    CX/DX       AS13
    Ml          AS13
    S13         AS13
    S6A/S6D     AS13
    SH          AS13
    SLH         AS13
    SWX         AS13
    ZH          AS13
   (结果个数 = 8)

   ---    END
   ```
2. 查询路由表中一个指定的Diameter路由组相关路由配置信息，路由组名称为“CX/DX”。

   ```
   LST DMRT: RTNAME="CX/DX";
   ```

   ```
   %%LST DMRT: RTNAME="CX/DX";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
     路由组名称  =  CX/DX
   对端标识名称  =  AS13
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD DMRT**命令的参数说明。
