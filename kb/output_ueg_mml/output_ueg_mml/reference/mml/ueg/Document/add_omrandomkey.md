# 增加随机密钥(ADD OMRANDOMKEY)

- 命令功能
- 注意事项

## 命令功能

**须知** 

- 本命令属于高危命令，执行本命令会生成新的密钥，如果携带“是否默认密钥”参数为“TRUE(是)”，会同时替换系统默认的加密密钥，系统最大支持的密钥记录数有限，执行不当会造成资源不足，或系统默认加密密钥被非预期替换。因此执行该命令前，需要与华为技术支持确认后才可以实施。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于增加随机密钥数据记录。

## 注意事项

- 执行该命令会增加随机密钥数据记录，增加后不能删除，系统中最多可增加3500条随机密钥数据记录。
- 系统初始化时会在数据库中添加一条随机密钥数据记录，“密钥ID”为“1”，“是否默认密钥”为“TRUE(是)”。
- 系统同时只允许存在一条默认记录。
- 执行该命令当“密钥ID”取值为3001~3500时，“是否为默认密钥”不允许设置为“TRUE(是)”。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                              |
|:-------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
| KEYID  | 密钥ID    | 可选必选说明：必选参数 参数含义：用于标识密钥ID。 取值范围：1～3500 默认值：无。 配置原则：无。                                                                                             |
| ISDEF  | 是否为默认密钥 | 可选必选说明：可选参数 参数含义：用于标识是否是默认密钥。 取值范围： TRUE(是)：执行命令时UDM会将已有默认密钥设置为非默认，将该参数对应的密钥设置为默认密钥。FALSE(否)：执行命令时UDM会将“密钥ID”参数对应的密钥设置为非默认。 默认值：FALSE(否)。 配置原则：无。 |

## 使用实例

1. 执行命令增加随机密钥数据记录，“密钥ID”为“2”，“是否为默认密钥”为“FALSE(否)”。

   ```
   ADD OMRANDOMKEY: KEYID=2, ISDEF=FALSE;
   ```
2. 执行命令增加随机密钥数据记录，“密钥ID”为“3”，“是否为默认密钥”为“TRUE(是)”。

   ```
   ADD OMRANDOMKEY: KEYID=3, ISDEF=TRUE;
   ```
