# 增加所有用户必签指定NAFID的USS列表(ADD NAFIDUSS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在配置数据库中增加某个网络应用功能组的必选USS信息，在GBA架构下，交互过程中，UIM根据用户签约的GUSS（GBA User Security Settings）信息中包含的本次访问AS域名所对应GSID（GAA Service Identifier）的USS信息，从而对用户终端的访问权限进行限制。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

- 若**ADD ASATTRIBUTE**命令中“AP认证和接入控制粒度”参数设置为“AP(GBA参与者)”，该命令无需配置。
- 若**ADD ASATTRIBUTE**命令中“AP认证和接入控制粒度”参数不为“AP(GBA参与者)”，运营商可根据实际需要对该命令进行配置。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                  |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FQDN   | FQDN   | 用于指定待增加USS信息所在网络应用功能组的全量域名，在IMS域中唯一标识一个AP的FQDN，当UIM采用GBA认证时“FQDN”与“Ua接口安全协议标识”（遵循3GPP标准协议，以保证用户通过Ua接口进行业务互操作的安全性）共同组成“NAFID”（“NAFID”用于标识合法的网络应用功能组）。 需要指出的是，该参数不区分大小写，在执行LST NAFIDUSS命令查询出的报文中为全小写形式。 取值范围：长度不超过127的字符串。 默认值：无。 注意：该参数为必选参数。                                                          |
| GSID   | GSID   | 用于指定用户终端发起访问请求服务的业务类型编码，标识用户具有访问权限的业务。“GSID”参数需要与对端IMS-HSS协商，运营商需要提前在IMS-HSS上配置GSID。 在用户接入权限检测过程中，UIM会将本命令配置的GSID与IMS-HSS上配置的GSID进行比较。满足以下两种情况，则检查通过：UIM通过该命令配置的GSID中有一个与IMS-HSS下发的GSID相同。UIM未通过该命令配置GSID。  说明： 针对VoLTE，推荐将“GSID”参数配置为“2”，即“AUTHENTICATION_PROXY”。 取值范围：0～999999。 默认值：无。 注意：该参数为必选参数。 |

## 使用实例

增加用户必签指定网络应用功能组的USS列表，携带以下参数：

- “FQDN”为“1”
- “GSID”为“2”

执行命令如下：

```
ADD NAFIDUSS: FQDN="1", GSID=2;
```
