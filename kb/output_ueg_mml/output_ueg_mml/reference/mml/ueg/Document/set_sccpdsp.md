# 设置SCCP目的信令点状态(SET SCCPDSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于在配置数据库中设置一条SCCP目的信令点在本局的状态数据记录。在该命令中，关键参数“网络指示”需要与对端信令设备协商。

## 注意事项

- 需要指出的是，如果SCCP目的信令点的状态设置为“禁止”，将导致信令业务中断。请谨慎使用此命令！
- 使用此命令不会影响远端的信令点。
- 手工禁止和手工允许是一一相对的，即只有将其设置为禁止后才能设置为允许（默认是手工允许）。另外，进行手工设置的前提是SCCPDSP可达。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                            |
|:-------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OP     | 设置操作    | 用于指定要设置的SCCP目的信令点状态为启用或者禁止。 取值范围： “ALLOW(设置DSP状态启用)”“PROHIBIT(设置DSP状态禁用)” 默认值： “ALLOW(设置DSP状态启用)” 说明：可选参数。                                                                                                                                                                                      |
| NI     | 网络指示    | 即内部网络指示语，用于指定该目的实体的信令点编码位于哪一个信令网中，它可以是国际主用网、国际备用网、国内主用网或国内备用网，用户应根据实际情况进行设置。 取值范围： “INT(国际主用网)”“INTB(国际备用网)”“NAT(国内主用网)”“NATB(国内备用网)” 默认值：无。 说明：必选参数。                                                                                                                                           |
| DPC    | 目的信令点编码 | 用于指定要显示的SCCP目的信令点编码。 取值范围： 当信令点进制类型为十六进制时，信令点编码允许以下方式输入：十六进制字符串（如：1AB2AB或H'1AB2AB）。中间不允许有空格和其他非十六进制字符。范围是0x0～0xFFFFFF（24位信令点编码）或0x0～0x003FFF（14位信令点编码）。 当信令点进制类型为十进制整数格式时，信令点编码允许以下方式输入：十进制整数字符串（如：1749675）。中间不允许有空格、其他非十进制字符。范围是0～16777215（24位信令点编码）或0～16383（14位信令点编码）。 默认值：无。 说明：必选参数。        |
| OPC    | 源信令点编码  | 用于指定要显示的SCCP目的信令点对应的源信令点编码。 取值范围： 当信令点进制类型为十六进制时，信令点编码允许以下方式输入：十六进制字符串（如：1AB2AB或H'1AB2AB）。中间不允许有空格和其他非十六进制字符。范围是0x0～0xFFFFFF（24位信令点编码）或0x0～0x003FFF（14位信令点编码）。 当信令点进制类型为十进制整数格式时，信令点编码允许以下方式输入：十进制整数字符串（如：1749675）。中间不允许有空格、其他非十进制字符。范围是0～16777215（24位信令点编码）或0～16383（14位信令点编码）。 默认值：无。 说明：必选参数。 |

## 使用实例

设置SCCP DSP状态，“设置操作”为“设置DSP状态启用”，“网络指示语”为“国内主用”，“目的信令点”为“101010”，“源信令点”为“202020”：

```
SET SCCPDSP: NI=NAT, DPC="101010", OPC="202020";
```
