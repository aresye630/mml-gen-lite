# 查询协议默认端口号的配置信息(LST DEFPORT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询UDM中各种应用协议对应的默认端口号。

- 若需要查询全部协议默认端口号，请不要输入任何参数。
- 需要查询某个协议默认端口号，请输入“应用协议类型”和“知名端口号”参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                               |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------|
| SRVTYPE | 应用协议类型 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个应用协议类型来查询应用协议对应的默认端口号；若不输入，则表示查询所有的协议默认端口号。 取值范围： DIAMETER(Diameter协议)RADIUS(Radius协议) 默认值：无。 配置原则：无。 |
| DEFPORT | 知名端口号  | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个知名端口号来查询应用协议对应的默认端口号；若不输入，则表示查询所有应用协议对应的默认端口号。 取值范围：1024～65534 默认值：无。 配置原则：无。                         |

## 使用实例

1. 查询协议默认端口配置信息。不携带参数，命令执行如下：

   ```
   LST DEFPORT:;
   ```

   ```
   %%LST DEFPORT:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------------------
    应用协议类型   知名端口号

    Diameter      3868               
    Radius        1813               
   (结果个数 = 2)

   ---    END
   ```
2. 查询协议默认端口号，“应用协议类型”为“DIAMETER(Diameter协议)”，命令执行如下：

   ```
   LST DEFPORT: SRVTYPE=DIAMETER;
   ```

   ```
   %%LST DEFPORT: SRVTYPE=DIAMETER;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   应用协议类型  =  Diameter协议
     知名端口号  =  3868
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见本命令的参数说明。
