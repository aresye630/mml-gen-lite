# 设置SCTP协议参数(SET SCTPPARA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于在配置数据库中设置SCTP协议参数数据记录。

## 注意事项

在本局中，SCTP协议可以用于承载M3UA的SCTP用户层信令，操作员在使用SET SCTPPARA命令设置SCTP协议参数时，其设置结果将对全局所有的SCTP偶联产生影响。因此，操作员在使用此命令时应十分谨慎，如果确实需要修改某些SCTP协议参数，请仔细阅读命令中该参数的详细解释及相关的注意事项。 另外，需要指出的是，本命令中所描述的初始设置值，是指操作员通过LST SCTPPARA命令查询得出的系统初始化的参数值。 如果上层链路上配置了SCTP参数，则上层链路上配置的SCTP参数优先适用。

## 参数说明

| 参数ID       | 参数名称       | 参数描述                                                                                                                                                                                                                                                                                                                |
|:-----------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RTOMIN     | RTO最小值     | 用于定义RTO（Retransmission Time-Out，重传超时时间）定时器的最小时长，单位为“毫秒”， 系统推荐值为500。该参数的配置原则是： RTO最小值应小于RTO最大值。 RTO初始值应大于或等于RTO最小值，且小于或等于RTO最大值。 取值范围： 1～65534 系统初始设置值：500 说明： 无。                                                                                                                                                    |
| RTOMAX     | RTO最大值     | 用于定义RTO（Retransmission Time-Out，重传超时时间）定时器的最大时长，单位为“毫秒”，系统推荐值为1500。 该参数的配置原则是： RTO最小值应小于RTO最大值。 RTO初始值应大于或等于RTO最小值，且小于或等于RTO最大值。 取值范围： 1～65534 系统初始设置值：1500。 说明： 无。                                                                                                                                                 |
| RTOINIT    | RTO初始值     | 用于定义RTO（Retransmission Time-Out，重传超时时间）定时器的初始时长，单位为“毫秒”，系统推荐值为500。 该参数的配置原则是： RTO最小值应小于RTO最大值。 RTO初始值应大于或等于RTO最小值，且小于或等于RTO最大值。 取值范围： 1～65534 系统初始设置值：500。 说明： 无。                                                                                                                                                   |
| RTOALPHA   | RTO alpha值 | 用于定义RTO（Retransmission Time-Out，重传超时时间）定时器的alpha参数，其取值范围为0～100、单位为“%”，系统推荐值为12。 该参数的配置原则是： RTO alpha值应小于或等于RTO beta值。 RTO alpha参数主要用于支持计算与更新RTO定时器的时长，其具体的使用方法请参考RFC2960协议的相关描述 取值范围： 0～100 系统初始设置值：12。 说明： 无。                                                                                                      |
| RTOBETA    | RTO beta值  | 用于定义RTO（Retransmission Time-Out，重传超时时间）定时器的beta参数，其取值范围为0～100、单位为“%”，系统推荐值为25。 该参数的配置原则是： RTO alpha值应小于或等于RTO beta值。 RTO beta参数主要用于支持计算与更新RTO定时器的时长，其具体的使用方法请参考RFC2960协议的相关描述。 取值范围： 0～100 系统初始设置值：25。 说明： 无。                                                                                                       |
| HBINTER    | 心跳间隔       | 如果在一定的时间内SCTP偶联未向某个特定的IP地址发送数据，SCTP偶联将向该IP地址发送心跳消息，以检查远端IP地址是否处于激活状态，该参数即用于定义本局在上述情况下向远端IP地址发送心跳消息的周期，单位为“毫秒”，系统推荐值为1500。 取值范围： 1～65534 系统初始设置值：1500。 说明： 无。                                                                                                                                                        |
| MAXARETR   | 偶联最大重传次数   | 用于定义在一个SCTP偶联上所允许的消息连续重传的最大次数。例如，若将该参数设为4，则当某个SCTP偶联上的消息连续重传次数超过4次时，本局将认为对端SCTP端点不可达，此时，本局将自动关闭该SCTP偶联，并通知SCTP用户层（如M3UA）该SCTP偶联不可用。系统推荐值为4，其配置原则是： 偶联最大重传次数不能大于一个SCTP偶联所有远端地址的“路径最大重传次数”的总和。 偶联最大重传次数不能小于路径最大重传次数。 取值范围： 1～254 系统初始设置值：4。 说明： 无。                                                                    |
| MAXPRETR   | 路径最大重传次数   | 用于定义在一个SCTP偶联上所允许的向某个特定的IP地址进行消息连续重传的最大次数。例如，若将该参数设为2，则当某个SCTP偶联上向某个特定的IP地址进行消息连续重传的最大次数超过2次时，本局将认为对端IP地址不可达，此时，如果数据配置了多个对端目的IP，本局将自动将当前使用的目的IP切换为下一个可用的IP地址，系统推荐值为2。需要指出的是，如果本局优先使用主用IP，则当主用IP从不可用状态变为可用状态时，该SCTP偶联将自动切换到主用IP上。 取值范围： 1～254 系统初始设置值：2。 说明： 无。                                                      |
| CNGLEVELNO | 无拥塞级阈值     | 当SCTP偶联进入拥塞状态以后，用于定义SCTP偶联的信令负荷解除拥塞状态时的阈值，该参数的取值范围为1～100、单位为“%”，系统推荐值为40。实际配置时，无拥塞级阈值应小于低拥塞级阈值，低拥塞级阈值应小于高拥塞级阈值。 本阈值，是指信令发送缓冲区被占用的百分比。例如，若将“无拥塞级阈值”参数设为40，当SCTP偶联进入拥塞状态以后，如果后续已经使用的发送缓冲区与总发送缓冲区的比值小于40%时，则系统将解除SCTP偶联的拥塞状态。 取值范围： 1～100 系统初始设置值：40。 说明： 无。                                                           |
| CNGLEVELL  | 低拥塞级阈值     | 低拥塞级阈值，用于定义SCTP偶联的信令负荷处于低拥塞状态时的阈值，该参数的取值范围为1～100、单位为“%”，系统推荐值为60。实际配置时，无拥塞级阈值应小于低拥塞级阈值，低拥塞级阈值应小于高拥塞级阈值。 本阈值，是指信令发送缓冲区被占用的百分比。例如，若将“低拥塞级阈值”参数设为60、“高拥塞级阈值”参数设为80，则当已经使用的发送缓冲区与总发送缓冲区的比值大于60%、但小于或等于80%时，系统认为SCTP偶联处于低拥塞状态。 取值范围： 1～100 系统初始设置值：60。 说明： 无。                                                            |
| CNGLEVELH  | 高拥塞级阈值     | 用于定义SCTP偶联的信令负荷处于高拥塞状态时的阈值，该参数的取值范围为1～100、单位为“%”，系统推荐值为80。实际配置时，无拥塞级阈值应小于低拥塞级阈值，低拥塞级阈值应小于高拥塞级阈值。 本阈值，是指信令发送缓冲区被占用的百分比。例如，若将“高拥塞级阈值”参数设为80，则当已经使用的发送缓冲区与总发送缓冲区的比值大于80%时，系统认为SCTP偶联处于高拥塞状态。 取值范围： 1～100 系统初始设置值：80。 说明： 无。                                                                                            |
| CHKSUMTX   | 发送消息时计算校验和 | 用于指示本局在发送SCTP消息时是否计算校验和，系统推荐值为“TRUE(是)”。若设为“FALSE(否)”，则对端SCTP端点必须支持不检查SCTP消息中的“校验和”字段，否则SCTP偶联将无法建立。 取值范围： FALSE(否)TRUE(是) 系统初始设置值：TRUE(是)。 说明： 无。                                                                                                                                                                  |
| CHKSUMRX   | 接收消息时检查校验和 | 用于指示本局是否对接收到的SCTP消息检查其中的“校验和”字段，系统推荐值为“TRUE(是)”。 取值范围： FALSE(否)TRUE(是) 系统初始设置值：TRUE(是)。 说明： 无。                                                                                                                                                                                                                      |
| CHKSUMTYPE | 校验和算法      | 用于指定本局侧的SCTP协议支持哪种校验和算法，即是支持ADLER32算法还是CRC32算法，系统推荐值为“CRC32”。SCTP检验和算法需要在SCTP偶联的两端保持一致，若不一致，则一端发送的SCTP消息将因校验和不正确而被接收的另一端丢弃。 由于本参数的设置将对全局所有的SCTP偶联产生影响。因此，当本局与媒体网关、内嵌式信令网关等设备对接时，如果双方SCTP协议缺省的检验和算法不一致，一般建议通过修改媒体网关或内嵌式信令网关侧SCTP协议的校验和算法来解决双方的对接问题。 取值范围： ADLER32(ADLER32)CRC32(CRC32) 系统初始设置值： CRC32(CRC32)。 说明： 无。 |

## 使用实例

设置SCTP协议参数，RTO最小值为500：

**SET SCTPPARA: RTOMIN=500;**
