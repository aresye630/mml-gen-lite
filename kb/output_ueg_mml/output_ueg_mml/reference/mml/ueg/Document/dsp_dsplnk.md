# 显示MTP,M3UA链路状态(DSP DSPLNK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询指定的目的信令点各种承载链路（包括MTP和M3UA链路）的状态信息。

## 注意事项

因系统在执行DSP DSPLNK命令时需要消耗主机一定的CPU资源，而这种CPU资源消耗与操作员需要查询的链路数成正比，因此，为尽量减少查询大量链路状态时对主机CPU资源的消耗，请操作员输入具体的查询条件。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                 |
|:-------|:--------|:-----------------------------------------------------------------------------------------------------|
| BT     | 承载类型    | 用于请求系统显示哪种类型链路的状态信息，包括MTP链路、M3UA链路和所有链路类型。 取值范围：MTP(MTP链路)M3UA(M3UA链路)ALL(所有链路) 默认值: ALL(所有链路) 说明：无。 |
| DSPNM  | 目的信令点名称 | 用于请求系统显示到达指定目的信令点的链路的状态信息；若不输入，则表所有目的信令点。 取值范围：1～32 位字符串 默认值：无。 说明：无。                                |
| LSNM   | 链路集名称   | 用于查询指定链路集内链路的状态信息；若不输入，则表示所有链路集。 取值范围：1～32 位字符串 默认值：无。 说明：无。                                         |
| MN     | BSG模块号  | 用于查询指定BSG模块内链路的状态信息；若不输入，则表示所有模块。 取值范围：1～1023 默认值：无。 说明：无。                                           |

## 使用实例

显示所有已配置的链路状态信息:

```
DSP DSPLNK: LSNM="M3LKS11", MN=1;
```

## 输出结果说明

| 输出项名称         | 输出结果解释                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 网络指示          | 用于返回当前链路所属的信令网信息，它可以是“国际主用网”、“国际备用网”、“国内主用网”或“国内备用网”。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| 目的信令点编码       | 用于返回当前目的信令点在No.7信令网中的信令点编码。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| 源信令点编码        | 用于返回当前目的信令点对应的源信令点在No.7信令网中的信令点编码。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| 模块号           | 用于返回当前链路所在的模块号。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| 链路号           | 用于返回当前链路在所属链路集内的编号，它由系统自动生成，仅用于系统内部标识。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| 链路名称          | 用于返回当前链路的名称。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| 链路集名称         | 用于返回当前链路所属链路集的名称。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| 目的信令点名称       | 用于返回当前目的信令点的名称。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| 承载类型          | 用于返回当前链路的承载类型信息。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| 链路状态          | 用于返回当前链路的运行状态： MTP链路的状态包括： 正在使用：表示MTP链路已经建立，可以传输MTP用户层信令业务消息。 失败：表示MTP链路建立失败，不能传输MTP用户层信令业务消息。 M3UA链路的状态包括： 未建立：表示SCTP偶联没有建立。若客户端M3UA没有创建到对端节点的SCTP偶联或服务器端M3UA没有收到SCTP偶联成功创建的指示，此时M3UA链路处于链路未建立状态。 已建立：表示SCTP偶联成功创建后，ASP/IPSP（客户端）M3UA没有收到ASP UP ACK消息或SGP/IPSP（服务器端）M3UA没有收到ASP UP消息，此时M3UA链路处于“已建立”状态。处于“已建立”状态的M3UA链路可以发送和接收ASPSM消息（包括ASP UP、ASP DOWN、ASP UP ACK、ASP DOWN ACK），但是不能发送和接收ASPTM消息（包括ASP ACTIVE、ASP ACTIVE ACK、ASP INACTIVE、ASP INACTIVE ACK），SSNM消息（包括NOTIFY、ERROR）和DATA消息。 未激活：表示SCTP偶联已经建立，但是链路还没有被激活。处于“已建立”状态的M3UA链路在ASP/IPSP（客户端）M3UA层收到ASP UP ACK消息或SGP/IPSP（服务器端）M3UA收到ASP UP消息时，状态变为“未激活”；处于“激活”状态的M3UA链路在ASP/IPSP（客户端）M3UA层收到ASP INACTIVE ACK消息或ASP INACTIVE消息时，状态变为“未激活”。此时，M3UA可以发送ASPSM、ASPTM、SSNM等非数据消息。 已激活：表示SCTP偶联已经建立，且链路已经被激活。处于“未激活”状态的M3UA链路在ASP/IPSP（客户端）M3UA层收到ASP ACTIVE ACK消息或ASP ACTIVE消息时，状态变为“已激活”。此时，M3UA可以发送包括数据消息和非数据消息在内的所有的消息类型，如ASPSM、ASPTM、SSNM、DATA消息。 |
| 信令链路选择码(十六进制) | 用于返回同一链路集下多条链路之间信令业务负荷分担的相关信息。例如，当前链路的信令链路选择码为01 02 03 ，则表示上层用户如果填写的信令链路选择码为01、02或者03时，系统则可以选择该链路发送信令消息。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
