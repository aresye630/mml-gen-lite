# 删除MTP路由(RMV N7RT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于从配置数据库中删除一条MTP路由数据记录。

## 注意事项

- 如果操作员删除某条MTP路由数据记录，将导致本局到相应网元的目的信令点不可达，可能引发业务中断的重大事故，请操作员在执行该操作之前仔细确认任务的可行性。
- 在正常情况下，删除一条MTP路由信息数据记录的操作步骤为：**RMV N7RT**。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                       |
|:-------|:--------|:-----------------------------------------------------------------------------------------------------------|
| DPNM   | 目的信令点名称 | 标识一条MTP路由数据记录的关键字段之一，用于指定需要删除的MTP路由数据记录所对应的目的信令点名称，操作员可以使用LST N7RT命令查询获得。 取值范围：长度不超过32的字符串 默认值：无。 说明：必选参数。 |
| LSNM   | 链路集名称   | 标识一条MTP路由数据记录的关键字段之一，用于指定需要删除的MTP路由数据记录所对应的链路集名称，操作员可以使用LST N7RT命令查询获得。 取值范围：长度不超过32的字符串 默认值：无。 说明：必选参数。   |

## 使用实例

删除MTP路由，“目的信令点名称”为“N7DSP”，“链路集名称”为“N7LKS”：

```
RMV N7RT: DPNM="N7DSP", LSNM="N7LKS";
```
