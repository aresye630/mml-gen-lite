# 查询外部BSF设备的配置信息(LST HBSF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询BSF的配置信息：

- 若需要查询全部BSF数据记录的信息，请不要输入任何参数。
- 若需要查询某条BSF数据记录的详细信息，请输入“BSF名称”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                |
|:-------|:-------|:----------------------------------------------------|
| HSSN   | HSS名称  | 用于指示系统需要按照哪个“HSS名称”来查询BSF数据记录；若不输入，则表示所有的HSS实体名称。   |
| BSFN   | BSF名称  | 用于指示系统需要按照哪个“BSF名称”来查询BSF数据记录；若不输入，则表示所有的“BSF名称”。   |
| HN     | 主机名    | 用于指示系统需要按照哪个“主机名”来查询BSF数据记录；若不输入，则表示所有的“主机名”。       |
| LNKMOD | 链路选择模式 | 用于指示系统需要按照哪个“链路选择模式”来查询BSF数据记录；若不输入，则表示所有的“链路选择模式”。 |

## 使用实例

1. 查询所有BSF的信息：

   `LST HBSF:;`

   ```
   %%LST HBSF:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    HSS名称  BSF名称  主机名           链路选择模式  HSS索引  BSF索引

    HSS9860  BSF1     bsf1.huawei.com  轮询方式        0        1      
    HSS9860  BSF2     bsf2.huawei.com  轮询方式        0        2      
   (结果个数 = 2)

   ---    END
   ```
2. 查询BSF的信息，“HSS名称”为“HSS9860”，“主机名”为“bsf1.huawei.com”：

   `LST HBSF: HSSN="HSS9860", HN="bsf1.huawei.com";`

   ```
   %%LST HBSF: HSSN="HSS9860", HN="bsf1.huawei.com";%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
        HSS名称  =  HSS9860
        BSF名称  =  BSF1
         主机名  =  bsf1.huawei.com
   链路选择模式  =  轮询方式
        HSS索引  =  0
        BSF索引  =  1
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明
