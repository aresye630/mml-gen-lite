# 查询Diameter对端实体能力(LST DMPECAP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

用于查询Diameter对端实体能力：

- 若需要查询UDM全部对端实体的能力信息，不需要输入任何参数。
- 若需要查询UDM指定对端实体的能力信息，请输入“实体名称”和“Diameter对端实体类型”等参数。

## 注意事项

无。

## 参数说明

| 参数ID     | 参数名称           | 参数描述                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
|:---------|:---------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PEERNAME | 实体名称           | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个实体名称来查询Diameter对端实体能力；若不输入，则表示查询所有实体名称的Diameter对端实体能力。 取值范围：长度不超过127的字符串。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                      |
| PEERTYPE | Diameter对端实体类型 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个Diameter对端实体类型来查询Diameter对端实体能力；若不输入，则表示查询所有Diameter对端实体类型的Diameter对端实体能力。 取值范围： OTHER(OTHER)AS(AS)S-CSCF(S-CSCF)I-CSCF(I-CSCF)GGSN(GGSN)SAE(SAE)BSF(BSF)IMS-HSS(IMS-HSS)E-CSCF(E-CSCF)P-GW(P-GW)ePDG(ePDG)HSGW(HSGW)Non-3GPP(Non-3GPP)AP(AP) 默认值：无 配置原则：无                                                                                                                                                                                  |
| HN       | 主机名            | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个主机名来查询Diameter对端实体能力；若不输入，则表示查询所有主机名的Diameter对端实体能力。 取值范围：1～127位由数字、字母、“.”和“-”组成的字符串。 默认值：无 配置原则： 所有字符只能是数字（0～9）、字母（a～z或A～Z）、“.”或“-”。首字符必须是数字（0～9）或字母（a～z或A～Z），最后一个字符必须是数字（0-9）、字母（a～z或A～Z）或“.”。 “.”不能连续出现且“.”和“-”不能相邻，“..”、“.-”或“-.”为错误配置。 最后一个“.”后面的第一个字符必须为字母（a～z或A～Z）。例如“as.huawei.com”中的最后一个“.”后面的字符串“com”的第一个字符必须为字母。                                                                                                                 |
| DN       | 域名             | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个域名来查询Diameter对端实体能力；若不输入，则表示查询所有域名的Diameter对端实体能力。 取值范围：1～127位由数字、字母、“.”和“-”组成的字符串。 默认值：无 配置原则： 该参数可以配置为绝对域名或相对域名。绝对域名的长度不超过127，相对域名的长度不超过126。后面带有“.”的就是绝对域名，其他的都是相对域名，例如：“huawei.com.”就是绝对域名，“huawei.com”就是相对域名。 所有字符只能是数字（0～9）、字母（a～z或A～Z）、“.”或“-”。首字符必须是数字（0～9）或字母（a～z或A～Z），最后一个字符必须是数字（0-9）、字母（a～z或A～Z）或“.”。 “.”不能连续出现且“.”和“-”不能相邻，“..”、“.-”或“-.”为错误配置。 最后一个“.”后面的第一个字符必须为字母（a～z或A～Z）。例如“as.huawei.com”中的最后一个“.”后面的字符串“com”的第一个字符必须为字母。 |

## 使用实例

1. 查询全部实体名称对应的Diameter对端实体能力：

   ```
   LST DMPECAP:;
   ```

   ```

   AS1             AS               NULL              NULL                    NULL                   NULL                        Notif-Eff            2           1.huawei.com       huawei.com
   SCSCF1          S-CSCF           NULL              NULL                    NULL                   NULL                        Notif-Eff            10          2.huawei.com       huawei.com
   ICSCF_DYX       I-CSCF           NULL              NULL                    NULL                   NULL                        NULL                 0           3.huawei.com       huawei.com

   ```
   LST DMPECAP: PEERNAME="DMPE_AS", PEERTYPE=AS;

**SET DMPECAP**

**SET DMPECAP**

命令参数说明中的输出项。

| 输出项名称          | 输出项解释                      |
|:---------------|:---------------------------|
| Diameter对端实体标识 | 用于返回一个Diameter对端实体的数据记录索引。 |
