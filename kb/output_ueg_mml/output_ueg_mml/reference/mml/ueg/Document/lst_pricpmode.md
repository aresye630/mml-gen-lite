# 查询优先级配比模式记录(LST PRICPMODE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护命令，用于在消息流控的场景下查询优先级配比模式记录。

- 根据每秒收到的各类消息数量是否超过“最小消息数”设置的值来判断是否流控，当每秒收到的各类消息数量超过“最小消息数”设置的值，则对超过最小消息数的消息进行流控。
- 若需要查询全部优先级配比模式数据记录的信息，不输入任何参数。
- 若需要查询某条消息名称的优先级配比模式数据记录的信息，输入要查询消息的“消息名称”参数。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                           |
|:---------|:-------|:-------------------------------|
| CPMODEID | 消息名称   | 用于指示系统按照哪一个消息名称查询对应的优先级配比模式记录。 |
| CPNUM    | 最小消息数  | 用于标识当前消息在流控发生的情况下最低放行的消息数量。    |

## 输出结果说明

| 输出项名称   | 输出项解释                          |
|:--------|:-------------------------------|
| 消息名称    | 该参数用于标识一个协议中的消息名称。             |
| 消息OP码   | 该参数用于标识一个协议中的消息OP码。            |
| 消息应用类型  | 该参数用于标识一个协议中的消息应用类型。           |
| 配比模式比率  | 该参数用于标识当前优先级配比模式所对应的比率。        |
| 最小消息数   | 该参数用于标识当前消息在流控发生的情况下最低放行的消息数量。 |
