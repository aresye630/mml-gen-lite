# 去激活MTP链路(DEA N7LNK)

- 命令功能

- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为维护类命令，用于请求系统对指定的MTP链路执行去激活操作，其对应的恢复命令为**ACT N7LNK**。

该命令仅适用于测试或维护的操作场景，当某MTP链路因误码率高、传输时延大等原因而出现频繁闪断现象时，操作员可以执行此操作。

## 注意事项

对于被去激活的MTP链路而言，执行该操作将导致其无法承载MTP用户层信令业务，其对系统运行的影响如下，请操作员在执行该操作之前仔细确认任务的可行性。

- 在相应的MTP链路集中，如果处于“已激活”状态的MTP链路数大于或等于2条，如果去激活其中的一条MTP链路，则其他MTP链路的负荷将加重，此时，系统运行的可靠性与稳定性将有一定程度的下降。如果该MTP链路集目前承载的信令负载较重，该操作将导致相应的MTP链路集出现信令业务过载的告警。
- 在相应的MTP链路集中，如果处于“已激活”状态的MTP链路数仅为1条，如果去激活该条MTP链路，则将导致相应的目的信令点不可达，从而出现局部阻塞甚至全局阻塞的严重事故。
- 该命令不允许进行批操作。

此外，操作员在使用该命令时，还应了解以下限制信息：

- 操作员使用该命令前，需要确认MTP链路处于“激活”状态，可以用**DSP N7LNK**命令查询MTP链路状态。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                        |
|:-------|:-------|:--------------------------------------------------------------------------------------------|
| LNKNM  | 链路名称   | 标识一条MTP链路的关键字段，用于指示系统去激活哪一条MTP链路，操作员可以使用LST N7LNK命令查询MTP链路状态 取值范围：1～32 位字符串 默认值：无。 说明：必选参数。 |

## 使用实例

去激活MTP链路，“链路名称”为“C9-1”：

```
DEA N7LNK: LNKNM="C9-1";
```
