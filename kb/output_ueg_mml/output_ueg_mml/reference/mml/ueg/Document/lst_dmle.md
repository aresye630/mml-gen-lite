# 查询Diameter本端实体(LST DMLE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询Diameter本端实体的配置信息：

- 若需要查询全部Diameter本端实体记录的概要信息，请不要输入任何参数。
- 若需要查询某些Diameter本端实体记录的详细信息，请输入“实体名称”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                 |
|:---------|:-------|:-----------------------------------------------------|
| EN       | 实体名称   | 用于指示系统按照哪个实体名称来查询Diameter本端实体信息；若不输入，则表示所有的实体名称。     |
| LOCTYPE  | 本端设备类型 | 用于指示系统按照哪种本端设备类型来查询Diameter本端实体信息；若不输入，则表示所有的本端设备类型。 |
| DN       | 域名     | 用于指示系统按照哪个域名来查询Diameter本端实体信息；若不输入，则表示所有的域名。         |
| HN       | 主机名    | 用于指示系统按照哪个主机名来查询Diameter本端实体信息；若不输入，则表示所有的主机名。       |
| DEFLOCAL | 默认本端实体 | 用于指示系统查询是否为默认本端实体的Diameter本端实体信息；若不输入，则表示所有的本端实体。    |

## 使用实例

1. 查询所有Diameter本端实体的配置信息：

   ```
   LST DMLE:;
   ```

   ```
   %%LST DMLE:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    实体名称  本端设备类型  主机名          域名        Diameter本端实体标识  默认本端实体

    HSS       SAE-HSS       hss.huawei.com  huawei.com  0                     是          
    IMS       IMS-HSS       ims.huawei.com  huawei.com  1                     否          
   (结果个数 = 2)

   ---    END
   ```
2. 查询某个Diameter本端实体的配置信息，“实体名称”为“HSS”：

   ```
   LST DMLE: EN="HSS";
   ```

   ```
   %%LST DMLE: EN="HSS";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
               实体名称  =  HSS
           本端设备类型  =  SAE-HSS
                 主机名  =  hss.huawei.com
                   域名  =  huawei.com
   Diameter本端实体标识  =  0
           默认本端实体  =  是
   (结果个数 = 1)

   ---    END
   ```
