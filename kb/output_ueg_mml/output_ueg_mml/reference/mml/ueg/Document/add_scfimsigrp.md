# 增加IMSI号段组(ADD SCFIMSIGRP)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会导致用户鉴权失败、无法正常接入网络。因此执行该命令前，请仔细检查配置的正确性，确认无误方可执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用于在配置数据库中增加一个IMSI号段组数据记录。在网络拥塞场景下，为避免用户终端尝试重新附着网络而不断发送请求消息到UDM，导致UDM长时间故障，设置业务控制功能支持按照号段拒绝指定业务流程。

系统通过**ADD SCFCFG**命令为对应号段组增加业务控制功能配置信息，实现对此号段组内用户消息进行流控，拒绝用户接入。

## 注意事项

系统中增加的IMSI号段组记录数不能超过50条。

## 参数说明

| 参数标识    | 参数名称      | 参数说明                                                               |
|:--------|:----------|:-------------------------------------------------------------------|
| GRPNAME | IMSI号段组名称 | 用于标识一个IMSI号段组的名称。 取值范围：长度不超过32的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 |

## 使用实例

增加IMSI号段组，“IMSI号段组名称”为“group01”：

```
ADD SCFIMSIGRP: GRPNAME="group01";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                        | 原因分析                   | 处理建议                                                                                                                                    |
|-------:|:---------------------------------------------|:-----------------------|:----------------------------------------------------------------------------------------------------------------------------------------|
| 335608 | 指定名称已经存在，请执行LST SCFIMSIGRP查询已经存在的记录。         | 输入的“IMSI号段组名称”参数已存在。   | 根据实际情况，重新输入“IMSI号段组名称”参数的取值，确保其取值在系统中不存在。已存在的“IMSI号段组名称”参数可以执行LST SCFIMSIGRP命令查询。                                                       |
| 335625 | 添加的IMSI号段组已经达到上限，请执行LST SCFIMSIGRP查询已经存在的记录。 | 系统中增加的IMSI号段组记录数超过50条。 | 根据实际情况，如需增加IMSI号段组名称，处理步骤如下： 执行LST SCFIMSIGRP命令，查询已存在的IMSI号段组名称。执行RMV SCFIMSIGRP命令删除不必要的IMSI号段组名称。执行该命令增加IMSI号段组，确保增加的IMSI号段组名称在规定范围之内。 |
