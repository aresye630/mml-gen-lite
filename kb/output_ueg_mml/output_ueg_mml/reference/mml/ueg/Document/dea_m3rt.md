# 去激活M3UA路由(DEA M3RT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为维护类命令，用于请求系统对处于激活状态的M3UA路由执行去激活操作（保持M3UA链路、释放M3UA路由），其对应的恢复命令为**ACT M3RT**。

该命令仅适用于测试或维护的操作场景。如果操作员不希望在某条路由上传输M3UA用户层信令、仅希望其传递M3UA层信令，则操作员可以使用该命令实现这一目的。

执行该命令后，M3UA路由进入“去激活”状态，M3UA的用户将不能使用此路由发送消息。

## 注意事项

对于被去激活的M3UA路由而言，执行该操作将导致其无法承载M3UA用户层信令业务，其对系统运行的影响如下，请操作员在执行该操作之前仔细确认任务的可行性。

- 在到相应M3UA目的实体的所有路由中，如果处于“正常”状态的M3UA路由数大于或等于2条，去激活其中的一条M3UA路由会使其他M3UA路由的负荷加重，此时，系统运行的可靠性与稳定性将有一定程度的下降。
- 在到相应M3UA目的实体的所有路由中，如果处于“正常”状态的M3UA路由数仅为1条，去激活该条M3UA路由将导致相应的目的实体不可达，从而出现局部阻塞甚至全局阻塞的严重事故。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                             |
|:-------|:-------|:-----------------------------------------------------------------|
| DENM   | 目的实体名称 | 标识某个M3UA目的实体的关键字段，用于指示系统去激活到哪个M3UA目的实体的路由，操作员可以使用LST M3DE命令查询获得。 |
| LSNM   | 链路集名称  | 标识一条M3UA链路集的关键字段，用于指示系统去激活的路由对应的M3UA链路集，操作员可以使用LST M3LKS命令查询获得。  |

## 使用实例

去激活M3UA路由，“目的实体名称”为“DE\_LXT”，“链路集名称”为“LKS\_LXT”：

```
DEA M3RT: DENM="DE_LXT", LSNM="LKS_LXT";
```
