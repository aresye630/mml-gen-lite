# 查询超时数据(LST USD)

## 命令功能

本命令用于查询OMU数据库中没有对主机数据库进行同步设定的数据表，这些数据表可能是以下两种情况之一：

- 联机设定数据时，设定不成功的数据表。
- 脱机设定数据时，尚未设定的数据表。

查询时：

- 若要查询全部的超时数据，请不要输入任何参数。
- 若要查询某个模块中的超时数据，请输入相应的模块号。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                          |
|:-------|:-------|:----------------------------------------------|
| MN     | 模块号    | 用于指示系统需要按照哪个模块号来查询超时未设定的数据；若不输入，则表示查询所有模块的数据。 |

## 使用实例

1. 查询全部的超时数据

   `LST USD:;`

   ```
   %%LST USD:;%%
   RETCODE = 0  操作成功

   发送未成功数据列表
   ------------------
    模块号  表号    表名称      记录号  发送次数

    200     34      TBL_NEINST  0       0       
    505     34      TBL_NEINST  0       0       
   (结果个数 = 2)

   ---    END
   ```
2. 查询指定模块的超时数据：设置“模块号”为“200”。

   `LST USD: MN=200;`

   ```
   %%LST USD: MN=200;%%
   RETCODE = 0  操作成功

   发送未成功数据列表
   ------------------
     模块号  =  200
       表号  =  34
     表名称  =  TBL_NEINST
     记录号  =  0
   发送次数  =  1
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。输出结果说明如表1所示。

命令执行异常，请联系华为技术支持处理。

| 输出项名称   | 输出项解释                     |
|:--------|:--------------------------|
| 模块号     | 表示超时未设定数据所属的模块信息。         |
| 表号      | 表示超时未设定数据所属的表信息。          |
| 表名称     | 表示超时未设定数据所属的表描述信息。        |
| 记录号     | 表示超时未设定数据对应所在表的记录号信息。     |
| 发送次数    | 表示系统定时自动下发的超时未设定数据的已发送次数。 |
