# 删除NAFGROUP群组名称(RMV NAFGROUP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于从配置数据库中删除一个网络应用功能群组。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

删除网络应用功能群组时，若该网络应用功能群组已经关联网络应用功能数据信息，则无法删除。

在正常情况下，删除网络应用功能群组的操作步骤为：**RMV NAFGRPDATA**-->**RMV NAFGROUP**。

## 参数说明

| 参数标识   | 参数名称        | 参数说明                                                                                               |
|:-------|:------------|:---------------------------------------------------------------------------------------------------|
| NAFGRP | NAF GROUP编号 | 标识一个网络应用功能群组的关键字段，用于指定需要删除哪一个网络应用功能群组，操作员可以使用LST NAFGROUP命令查询获得。 取值范围：1～65535。 默认值：无。 注意：该参数为必选参数。 |

## 使用实例

删除网络应用功能群组，“NAF GROUP编号”为“1”：

执行命令如下：

```
RMV NAFGROUP: NAFGRP=1;
```
