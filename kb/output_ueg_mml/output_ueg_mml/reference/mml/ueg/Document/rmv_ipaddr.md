# 删除网元IP地址(RMV IPADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行该命令可能导致ESN变动，ESN变动后需要在60天内重新申请并加载License文件。命令执行不当会造成UDM无法与其他实体通信，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于删除IP地址。

## 注意事项

- 除了在开局初始配置时，其他情况下随意删除IP地址会导致无法与远端Location通信，引起业务处理中断，请谨慎使用。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                             |
|:-------|:-------|:---------------------------------|
| IPNAME | IP地址名称 | 用于标识一个IP地址。 取值范围：127位字符串。 默认值：无。 |

## 使用实例

删除外出IP地址，IP地址名称为“BSGIP”：

```
RMV IPADDR: IPNAME="BSGIP";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                 | 原因分析                             | 处理建议                                                                             |
|-------:|:----------------------|:---------------------------------|:---------------------------------------------------------------------------------|
| 335809 | 指定的IP地址已经配置了ENSLINK记录 | 输入的“IP地址名称”参数已经在ADD ENSLINK中被引用。 | 根据实际情况，确定是否要删除该网元IP地址。如果确实需要删除，先通过RMV ENSLINK命令删除该“IP地址名称”配置的ENSLINK记录，再重新执行本命令。 |
| 335959 | 指定的IP地址已经配置了M3LNK记录   | 输入的“IP地址名称”参数已经在ADD M3LNK中被引用。   | 根据实际情况，确定是否要删除该网元IP地址。如果确实需要删除，先通过RMV M3LNK命令删除该“IP地址名称”配置的M3LNK记录，再重新执行本命令。     |
