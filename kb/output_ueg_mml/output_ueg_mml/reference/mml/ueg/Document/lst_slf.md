# 查询SLF的配置信息(LST SLF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询SLF的配置信息：

- 若需要查询全部SLF配置信息，请不要输入任何参数。
- 若需要查询某条SLF的详细配置信息，请输入“实体名称”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                     |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| EN     | 实体名称   | 用于标识SLF配置信息的实体名称。 取值范围：1～127位由数字、字母、“.”、“—”、“_”、空格或中文字符等组成的字符串。 默认值：无。                                                                                                                                                                                                                   |
| DN     | 域名     | 用于标识SLF配置信息的域名。该参数的配置原则是： 所有字符只能是数字（0～9）、字母（a～z或A～Z）、“.”或“-”。 第一个字符必须是数字（0～9）或字母（a～z或A～Z）。 “.”或“-”不能连续出现且“.”和“-”不能相邻。例如“..”、“--”、“.-”或“-.”为错误配置。 最后一个字符不允许是“-”。 最后一个“.”后面的第一个字符必须为字母（a～z或A～Z）。例如“slf.huawei.com”中的最后一个“.”后面的字符串“com”的第一个字符必须为字母。 取值范围：1～127位由数字、字母、“.”或“-”组成的字符串。 默认值：无。 |
| HN     | 主机名    | 用于标识SLF配置信息的主机名。该参数的配置原则是 所有字符只能是数字（0～9）、字母（a～z或A～Z）、“.”或“-”。 第一个字符必须是数字（0～9）或字母（a～z或A～Z）。 “.”或“-”不能连续出现且“.”和“-”不能相邻。例如“..”、“--”、“.-”或“-.”为错误配置。 最后一个字符不允许是“-”。 最后一个“.”后面的第一个字符必须为字母（a～z或A～Z）。例如“slf.huawei.com”中的最后一个“.”后面的字符串“com”的第一个字符必须为字母。 取值范围：1～127位由数字、字母、“.”或“-”组成的字符串。 默认值：无。 |

## 使用实例

1. 查询指定SLF的配置信息：

   ```
   LST SLF: EN="SLF1";
   ```

   ```
   %%LST SLF: EN="SLF1";%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
   实体名称  =  SLF1
       域名  =  huawei.com
     主机名  =  slf1.huawei.com
    SLF索引  =  0
   (结果个数 = 1)

   ---    END
   ```
2. 查询所有SLF的配置信息：

   ```
   LST SLF:;
   ```

   ```
   %%LST SLF:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    实体名称  域名        主机名            SLF索引

    SLF1      huawei.com  slf1.huawei.com   0      
    SLF10     huawei.com  slf10.huawei.com  9      
    SLF2      huawei.com  slf2.huawei.com   1      
    SLF3      huawei.com  slf3.huawei.com   2      
    SLF4      huawei.com  slf4.huawei.com   3      
    SLF5      huawei.com  slf5.huawei.com   4      
    SLF6      huawei.com  slf6.huawei.com   5      
    SLF7      huawei.com  slf7.huawei.com   6      
    SLF8      huawei.com  slf8.huawei.com   7      
    SLF9      huawei.com  slf9.huawei.com   8      
   (结果个数 = 10)

   ---    END
   ```
