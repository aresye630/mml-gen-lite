# 设置Diameter对端实体能力(SET DMPECAP)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成系统产生致命错误，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用来设置Diameter对端实体能力，即配置与UDM对接网元所支持的特性，如I-CSCF网元支持的特性，S-CSCF网元支持的特性等。

该命令的使用场景：UDM作为IMS-HSS网元与I-CSCF、S-CSCF、GGSN、AS等网元对接时或UDM作为UIM网元（仅虚机场景涉及）与P-GW、ePDG、HSGW、Non-3GPP、AP等网元对接时，通过**ADD DMPE**命令增加完对端实体后，需要执行本命令配置Diameter对端实体能力。

## 注意事项

- Diameter对端实体能力决定对端是否可以正常从UDM获取指定用户数据，因此所有的实体能力必须严格按照统一规划配置。
- 该命令不允许进行批操作。
- “Diameter对端实体类型”为“AS”，如果由**SET DMPECAP**增加的记录数超过256时，**SET HSYSTEMPARA**命令的参数“ASIDMODE”需要设置为“STORE\_IN\_USCDB”。
- **SET DMPECAP**设置的Diameter对端实体最多可以设置1024个。

## 使用实例

设置Diameter对端实体能力:

```
SET DMPECAP: PEERNAME="TEST", OPTYPE=ADD, PEERTYPE=S-CSCF, CSCFFEATURELIST=SharedIFC-0, HN="scscf.huawei.com", DN="huawei.com";
```
