# 查询M3UA链路(LST M3LNK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在配置数据库中查询M3UA链路数据的配置信息：

- 若需要查询全部M3UA链路数据记录的概要信息，所有参数都不用输入。
- 若需要查询某些M3UA链路数据记录的详细信息，请输入相关参数或参数组合。

## 注意事项

该命令的“链路集名称”、“链路名称”参数支持模糊查询功能。模糊查询功能是指操作员输入查询参数时，对于字符串或BCD码类型的查询参数而言，

- 如果操作员输入的是一个完整的字符串或BCD码，则表示系统将按照完全匹配的方式执行查询操作。
- 如果操作员在输入的某个字符串或BCD码的末尾添加通配字符“%”，则表示系统将按照模糊匹配的方式执行查询操作。

在查询结果中，如果增加M3UA链路时没有输入ASP标识，那么在查看M3UA链路结果中ASP标识将显示为2147483647，这个ASP标识值是无效值。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                      |
|:----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MN        | BSG模块号 | 用于指示系统需要按照哪个BSG模块号来查询M3UA链路数据；若不输入，则表示所有的BSG模块号。 取值范围:1～1023 默认值: 无。 说明: 无。                                                                                                                                                                                                                                                                                               |
| LNKNM     | 链路名称   | 用于指示系统需要按照哪个链路名称来查询M3UA链路数据；若不输入，则表示所有的链路名称。 取值范围: 长度不超过32的字符串 默认值: 无。 说明: 配置原则是：该参数的值域范围为：数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、空格符、中文。 操作员只能在字符串或BCD码的末尾添加通配字符“%”，而不能在字符串或BCD码的前面、中间添加通配字符“%”。例如，“A市%”、“1390123%”是合法的输入，而“%A市”、“A市%区”、“%1390123”、“139%0123”均是不合法的输入。 如果某个命令同时存在有多个字符串或BCD码类型的查询参数，则操作员在一次查询操作中，只能对其中的一个查询参数使用模糊查询方式，而不能同时对两个或两个以上的查询参数使用模糊查询方式。   |
| LSNM      | 链路集名称  | 用于指示系统需要按照哪个链路集名称来查询M3UA链路数据；若不输入，则表示所有的链路集名称。 取值范围: 长度不超过32的字符串 默认值: 无。 说明: 配置原则是：该参数的值域范围为：数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、空格符、中文。 操作员只能在字符串或BCD码的末尾添加通配字符“%”，而不能在字符串或BCD码的前面、中间添加通配字符“%”。例如，“A市%”、“1390123%”是合法的输入，而“%A市”、“A市%区”、“%1390123”、“139%0123”均是不合法的输入。 如果某个命令同时存在有多个字符串或BCD码类型的查询参数，则操作员在一次查询操作中，只能对其中的一个查询参数使用模糊查询方式，而不能同时对两个或两个以上的查询参数使用模糊查询方式。 |
| SCALEFLAG | 是否弹性链路 | 用于标识该链路是否支持在Pod间弹性迁移，即链路根据UISU Pod的资源占有率、链路负荷和链路分布情况，弹性迁移实现负载均衡。 例如：当系统流量在高峰期时弹性扩容（增加UISU Pod），低峰期时弹性缩容（删除UISU Pod），链路能够在UISU Pod之间弹性迁移。 取值范围： NO(否)：当前的链路不支持弹性迁移。YES(是)：当前的链路支持弹性迁移。 默认值：无。                                                                                                                                                                              |
