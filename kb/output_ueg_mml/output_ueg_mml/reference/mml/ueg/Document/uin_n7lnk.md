# 解除管理禁止MTP链路(UIN N7LNK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为维护类命令，用于请求系统对指定的MTP链路执行解除管理禁止操作。该命令的操作场景一般为：

- 操作员使用**INH N7LNK**命令对某MTP链路执行了管理禁止操作。
- 操作员使用**DSP N7LNK**命令查询该MTP链路的状态，发现其状态为“本端管理禁止”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                       |
|:-------|:-------|:-------------------------------------------------------------------------------------------|
| LNKNM  | 链路名称   | 标识一条MTP链路的关键字段，用于指示系统解除管理禁止哪一条MTP链路，操作员可以使用LST N7LNK命令查询获得。 取值范围：1～32 位字符串 默认值：无。 说明：必选参数。 |

## 使用实例

解除管理禁止MTP链路，“链路名称”为“STP”：

```
UIN N7LNK: LNKNM="STP";
```
