# 修改SCCP目的信令点(MOD SCCPDSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于对配置数据库中的一条SCCP目的信令点数据记录的某些参数进行修改或调整。在该命令中，系统通过“目的信令点名称”参数来唯一标识一条SCCP目的信令点数据记录。

## 注意事项

- 修改信令点编码时，请确保此信令点上没有配置SCCP SSN或SCCP GT翻译结果。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
|:-------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DPNM   | 目的信令点名称  | 该参数是标识一条SCCP目的信令点数据记录的关键字段，用于指定需要对哪一条SCCP目的信令点数据记录的参数进行修改或调整，操作员可以使用LST SCCPDSP命令查询获得。 取值范围：长度不超过32的字符串。 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                                                           |
| NI     | 网络指示     | 本局与对端设备的对接参数之一，用于指定对端设备的信令点编码属于哪一个信令网，它可以是国际主用网、国际备用网、国内主用网或国内备用网，操作员应根据实际情况进行设置。 取值范围： “INT(国际主用网)”“INTB(国际备用网)”“NAT(国内主用网)”“NATB(国内备用网)” 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                         |
| DPC    | 目的信令点编码  | 本局与对端设备的对接参数之一，用于在本局的配置数据库中定义一个SCCP目的信令点，该参数必须输入、且必须先由ADD N7DSP或ADD M3DE命令定义，然后才能在此处索引。 当本局与MSC、SCP、SGSN、GMLC等设备进行对接时，由于MAP、BSSAP/INAP、CAP等协议均基于SCCP进行传输，因此，操作员需要在本局侧将这些设备的信令点编码均定义为SCCP目的信令点。 取值范围： 当信令点进制类型为十六进制时，信令点编码允许以下方式输入：十六进制字符串（如：1AB2AB或H'1AB2AB）。中间不允许有空格和其他非十六进制字符。范围是0x0～0xFFFFFF（24位信令点编码）或0x0～0x003FFF（14位信令点编码）。 当信令点进制类型为十进制整数格式时，信令点编码允许以下方式输入：十进制整数字符串（如：1749675）。中间不允许有空格、其他非十进制字符。范围是0～16777215（24位信令点编码）或0～16383（14位信令点编码）。 默认值：无。 说明：无。 |
| OPC    | 源信令点编码   | 本局与对端设备的对接参数之一，当本局在向对端设备发送SCCP信令消息时，用于指定在相应的SCCP信令消息中将携带哪个源信令点编码，该参数必须先由SET OFI或ADD OFI命令定义，然后才能在此处索引。在缺省的情况下，若操作员不输入OPC，则系统默认OPC为由SET OFI命令定义的本局信令点编码。 取值范围： 当信令点进制类型为十六进制时，信令点编码允许以下方式输入：十六进制字符串（如：1AB2AB或H'1AB2AB）。中间不允许有空格和其他非十六进制字符。范围是0x0～0xFFFFFF（24位信令点编码）或0x0～0x003FFF（14位信令点编码）。 当信令点进制类型为十进制整数格式时，信令点编码允许以下方式输入：十进制整数字符串（如：1749675）。中间不允许有空格、其他非十进制字符。范围是0～16777215（24位信令点编码）或0～16383（14位信令点编码）。 默认值：无。 说明：无。                                        |
| PRT    | 信令规范     | 本局与SS7信令设备的对接参数之一，用于指示本局与该目的信令点之间的SS7信令遵循哪个组织制定的规范。若本局与遵循ANSI规范的信令点设备进行对接，则该参数必须选择“ANSI”，否则，两信令设备之间的MTP链路将不能正常运行。 取值范围： “ITU-T(ITU-T)”“ANSI(ANSI)” 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                 |
| DPNM1  | 新目的信令点名称 | 对于由本命令中“目的信令点名称”字段所标识的某条具体的数据记录而言，用于指示系统是否需要对该数据记录中“目的信令点名称”字段的取值重新进行定义，其值域类型为字符串、最大长度为32。 取值范围：长度不超过32位的字符串，字符串只允许输入：0-9，a-z，A-Z，“-”、“_”、“.”、空格符、和中文字符。 默认值：无。 说明：该参数的配置原则是： 若不输入任何字符：表示不对该数据记录中“目的信令点名称”字段的取值重新进行定义。 若输入一个字符串：表示需要对该数据记录中“目的信令点名称”字段的取值重新进行定义，且输入的字符串不能在相应的数据表中已经被定义。假设本命令中“目的信令点名称”字段的取值为A、“新目的信令点名称”字段的取值为B，则对于配置数据库中索引了取值为A的所有数据记录的“目的信令点名称”字段，系统将自动把这些字段的值由A修改为B。                                                                         |

## 使用实例

1、修改SCCP目的信令点，“目的信令点名称”为“SCCPDSP”，“目的信令点编码”为“0x0DFFFF”：

```
MOD SCCPDSP: DPNM="SCCPDSP", DPC="0DFFFF";
```

2、修改SCCP目的信令点，“目的信令点名称”为“SCCPDSP”，“网络指示”为“国内主用网”，“目的信令点名称”为“NEWSCCPDSP”：

```
MOD SCCPDSP: DPNM="SCCPDSP", NI=NAT, DPNM1="NEWSCCPDSP";
```
