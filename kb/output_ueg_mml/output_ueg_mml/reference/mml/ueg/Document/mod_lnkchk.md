# 修改SCTP/TCP链路传输质量检测参数（MOD LNKCHK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于修改一条SCTP/TCP链路传输质量检测参数数据记录。

在该命令中，系统通过关键参数“传输层协议类型”来唯一标识一条SCTP/TCP链路传输质量检测信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称         | 参数说明                                                                                                                                   |
|:-------|:-------------|:---------------------------------------------------------------------------------------------------------------------------------------|
| PROTO  | 传输层协议类型      | 标识一条链路传输质量检测参数数据记录的关键字段（其取值不能被修改），用于指定需要对哪种类型的链路传输质量检测参数数据记录进行修改或调整。操作员可以使用LST LNKCHK命令查询获得。 取值范围： SCTP（SCTP协议类型） TCP（TCP协议类型） 默认值：无。  |
| ENLTQD | 启动链路传输质量检测功能 | 用于标识系统是否开启链路传输质量检测功能。 取值范围： “NO(否)”：关闭检测功能。 “YES(是)”：开启检测功能。 默认值：无。 系统初始设置值为：YES(是)。                                                   |
| DP     | 检测周期         | 仅当“启动链路传输质量检测功能”为“YES(是)”时，该参数有效。用于标识系统链路传输质量的检测周期。操作员可以使用LST LNKCHK命令查询获得。 取值范围：5～60，单位为“秒”。 默认值：无。 系统初始设置值为：5。                       |
| AP     | 告警周期         | 仅当“启动链路传输质量检测功能”为“YES(是)”时，该参数有效。用于标识系统上报链路传输质量下降告警的周期。此周期必须大于“检测周期”。操作员可以使用LST LNKCHK命令查询获得。 取值范围：60～360，单位为“秒”。 默认值：无。 系统初始设置值为：300。 |
| RRT    | 消息重传比例阈值     | 仅当“启动链路传输质量检测功能”为“YES(是)”时，该参数有效。用于标识链路重传数据比率的门限。消息重传比率=重传的消息数/发送的消息数×100%。 取值范围：1～100，单位为“%”。 默认值：无。 系统初始设置值为：5。                      |
| AAD    | 消息平均确认时延阈值   | 仅当“启动链路传输质量检测功能”为“YES(是)”时，该参数有效。用于标识用户链路双向平滑时延（链路上消息的平均确认时延）的门限。消息平均确认时延=消息确认时延总和/发送消息数。 取值范围：1～2000，单位为“毫秒”。 默认值：无。 系统初始设置值为：1000。   |
| ADEV   | 消息确认时延平均偏差阈值 | 仅当“启动链路传输质量检测功能”为“YES(是)”时，该参数有效。用于标识链路消息确认时延平均偏差的门限。消息确认时延平均偏差=消息确认时延偏差总和/发送消息数。 取值范围：1～2000，单位为“毫秒”。 默认值：无。 系统初始设置值为：500。            |

## 使用实例

修改SCTP链路传输质量检测参数，“传输层协议类型”为“SCTP(SCTP)”，“消息平均确认时延阈值”为“500”。

```
MOD LNKCHK: PROTO=SCTP, AAD=500;
```
