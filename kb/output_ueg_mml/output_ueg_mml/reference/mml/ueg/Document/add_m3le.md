# 增加M3UA本地实体(ADD M3LE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条M3UA本地实体数据记录。在该命令中，以下关键参数需要与对端M3UA信令设备协商：

- 网络指示
- 本地实体信令点编码
- 本地实体类型
- 路由上下文

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|:-------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LENM   | 本地实体名称    | 用于在本局的配置数据库中定义一个M3UA本地实体。需要配置多少个本地实体取决于由M3UA承载信令的本局信令点编码的个数。例如： 本局同时位于国际网与国内网，其中，国际网为单信令点编码，国内网为4信令点编码。若国际网与国内网全部通过M3UA承载信令，则操作员需定义5个本地实体。 取值范围：长度不超过32的字符串。 默认值：无。 说明： 对于操作员在客户端输入的字符串，系统在操作OMU数据库之前将自动进行如下处理：将该字符串中的所有英文字母全部转换成大写、并将该字符串中最左边与最右边的空格删除掉。例如，假设操作员在客户端输入的字符串为“区域abc”，则系统在操作OMU数据库之前将自动将该字符串转换为“区域ABC”。对于操作员通过本命令配置的某一条具体的数据记录而言，假设该数据记录中“本地实体名称”字段的原取值为A，如果操作员后续需要将该字段的取值由A修改为B，则其可以通过MOD M3LE命令中的“新本地实体名称”参数重新进行定义。此时，对于配置数据库中索引了取值为A的所有数据记录的“本地实体名称”字段，系统将自动把这些字段的值由A修改为B。 |
| NI     | 网络指示      | 本局与M3UA信令设备的对接参数之一，用于指定该本地实体的信令点编码属于哪一个信令网。 取值范围： “INT(国际主用网)”“INTB(国际备用网)”“NAT(国内主用网)”“NATB(国内备用网)” 默认值：“NAT(国内主用网)”。 说明：操作员在本命令配置的源信令点编码的“网络指示”属性应与其使用SET OFI或ADD OFI命令配置的相应的本局信令点编码的“网络指示”属性保持一致，否则，系统将出错。                                                                                                                                                                                                                                                                               |
| OPC    | 本地实体信令点编码 | 本局与M3UA信令设备的对接参数之一，用于指定该本地实体所对应的本局信令点编码，该参数必须先由SET OFI或ADD OFI命令定义，然后才能在此处索引。 取值范围：长度不超过11的字符串。 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                                                                                                |
| LET    | 本地实体类型    | 本局与M3UA信令设备的对接参数之一，用于指定本局在M3UA链路中的应用模式。 取值范围： “SG(信令网关)”“AS(应用服务器)” 默认值：无。 说明： 在非对等组网模式中，当本局通过SG与No.7信令网中的MSC、SCP等设备对接时，该参数设为“AS(应用服务器)”。 在非对等组网模式中，当本局作为综合信令网关应用时，该参数设为“SG(信令网关)”。 在对等组网模式中，当本局通过M3UA链路（不通过SG转发）直接与MSC、SCP、固定软交换、移动软交换等设备对接时，该参数设为“AS(应用服务器)”。                                                                                                                                                                                                                             |
| RC     | 路由上下文     | 仅当本命令中的“本地实体类型”参数为“AS(应用服务器)”时该参数有效。用于定义本局作为客户端在向对端发送注册请求时的选路关键字。 取值范围：0～2147483647。 默认值：2147483647。 说明： 路由上下文可以为一个十进制的数字，也可以为空（不配置），具体对接时需要双方协商一致。若输入2147483647，则表示路由上下文为空，即不使用路由上下文。                                                                                                                                                                                                                                                                                                      |

## 使用实例

1、增加M3UA本地实体，“本地实体名称”为“M3LE”，“本地实体类型”为“AS(应用服务器)”，“本地实体信令点编码”为“454511”：

```
ADD M3LE: LENM="M3LE", OPC="454511", LET=AS;
```

2、增加M3UA本地实体，“本地实体名称”为“MODIFIED”，“本地实体类型”为“SG(信令网关)”，“本地实体信令点编码”为“666666”：

```
ADD M3LE: LENM="MODIFIED", OPC="666666", LET=SG;
```
