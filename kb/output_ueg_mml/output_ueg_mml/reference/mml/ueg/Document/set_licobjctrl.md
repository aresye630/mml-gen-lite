# 设置License统计对象获取方式(SET LICOBJCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于设置按照哪种方式创建License控制项测量对象。License控制项测量对象是指将每一个License控制项作为一个测量对象来统计该license控制项授权的用户数量。

## 注意事项

无。

## 参数说明

| 参数ID    | 参数名称            | 参数描述                                                                                                                                                           |
|:--------|:----------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OBJTYPE | License统计对象获取方式 | 用于标识创建License控制项测量对象的方式。 取值范围：OFF(关闭统计功能)：不创建License控制项测量对象。ALL(统计所有控制项)：创建所有License控制项测量对象。LICFILE(按license文件所申请控制项统计)：只创建License文件中申请的License控制项测量对象。 默认值：无。 |

## 使用实例

按照“对象获取方式”为“LICFILE(按license文件所申请控制项统计)”的方式，创建License控制项测量对象。

```
SET LICOBJCTRL: OBJTYPE=LICFILE;
```
