## 命令功能

**须知** 

本命令属于高危命令，执行该命令可能导致ESN变动，ESN变动后需要在60天内重新申请并加载License文件。命令执行不当会造成UDM无法与其他实体通信，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于修改IP地址。

## 注意事项

- 如果修改的是DSG的IP地址配置信息，则执行完该命令后需要执行**ACT IPDISP**命令，使修改的IP地址生效。
- 该命令不允许进行批操作。
- 执行该命令将IP地址从IPV4地址修改为IPV6地址，或将IP地址从IPV6地址修改为IPV4地时，系统会返回错误：“IP地址的类型不同”。
- 为防止操作不当影响业务，当IP地址被其他记录引用时，不支持修改。如果需要修改，请先删除引用关系。被限制修改的场景包括：
  - 当网关类型为DSG的IP地址被**ADD HSMCLIENT**命令配置的HSM链路所引用时。
  - 当网关类型为BSG的IP地址被**ADD M3LNK**命令配置的M3UA链路所引用时。
  - 当网关类型为PAU的IP地址被**ADD PATYPE**命令配置的适配数据所引用时。
- 由本命令配置的IP地址和**ADD HTTPIP**配置的IP地址不能重复，否则会导致IP地址冲突，影响业务。
- 当软参“MAP\_DIAM\_IP\_SHARE\_SWITCH(Map与Diameter信令IP共用开关)”取值为“1”时，通过本命令配置IP地址，“网关类型”取值为“BSG(BSG)”和“HSF(HSF)”时，“BSG(BSG)”和“HSF(HSF)”之间可配置相同的IP。

## 使用实例

修改外出IP地址。IP地址名称为“DSG1”，新IP地址名称为“DSG2”，网关类型为“DSG”，IP地址类型为“IPV4”，IP地址1为:192.168.165.66：

```
MOD IPADDR: IPNAME="DSG1", IPNEWNAME="DSG2", GATEWAYTYPE=DSG, IPTYPE=IPV4, IPV4IP1="192.168.165.66";
```
