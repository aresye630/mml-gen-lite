# 增加MTP链路(ADD N7LNK)

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条MTP链路数据记录。在该命令中，参数“信令链路编码”需要与对端No.7信令设备协商。

## 注意事项

- 两个相邻的信令点之间最多可以开通16条MTP信令链路，这16条MTP信令链路称为一个信令链路集。为了在一个信令链路集唯一标识一条MTP信令链路，No.7信令使用了SLC（Signaling Link Code），即信令链路编码。
- 执行该命令之前，与所增加的MTP链路相关的以下信息必须已经配置成功：

  - 源信令点（**ADD OFI**）
  - 目的信令点（**ADD N7DSP**）
  - MTP信令链路集（**ADD N7LKS**）
- 一个BSG模块上最多可以配置8条TDM 2Mbit/s的MTP链路或者128条TDM 64kbit/s的MTP链路。一个单板上的所有BSG模块最多可以配置16条TDM 2Mbit/s的MTP链路或者256条TDM 64kbit/s的MTP链路。
- 执行该命令之前，需要通过**LST MODULE**命令查询BSG主备情况，禁止在主备BSG模块上部署MTP链路。

## 参数说明

| 参数标识    | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                                                                                              |
|:--------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LNKNM   | 链路名称       | 用于在配置数据库中定义一个MTP链路。MTP链路名称在全局内唯一，不能重复。 需要指出的是： 对于操作员在LMT输入的字符串，系统在操作OMU数据库之前将自动进行如下处理：将该字符串中的所有英文字母全部转换成大写、并将该字符串中最左边与最右边的空格删除掉。例如，假设操作员在LMT输入的字符串为“ 区域abc ”，则系统在操作OMU数据库之前将自动将该字符串转换为“区域ABC”。 对于操作员通过本命令配置的某一条具体的数据记录而言，假设该数据记录中“链路名称”字段的原取值为A，如果操作员后续需要将该字段的取值由A修改为B，则其可以通过MOD N7LNK命令中的“新链路名称”参数重新进行定义。此时，对于配置数据库中索引了取值为A的所有数据记录的“链路名称”字段，系统将自动把这些字段的值由A修改为B。 取值范围：长度不超过32的字符串 默认值：无。 说明：必选参数。 |
| LSNM    | 链路集名称      | 用于指定该MTP链路所属的MTP链路集，该参数必须先由ADD N7LKS命令定义，然后才能在此处引用。 取值范围：长度不超过32的字符串 默认值：无。 说明：必选参数。                                                                                                                                                                                                                                                                                                              |
| LNKTYPE | 链路类型       | 用于指定该MTP链路的链路类型，操作员应根据实际组网正确配置该参数，否则，MTP链路将不能正常工作。各参数选项的含义是： TDM 64kbit/s：基于TDM承载的64kbit/s的MTP链路。 TDM 2Mbit/s：基于TDM承载的2Mbit/s的MTP链路。 ATM：基于ATM承载的MTP链路。 该参数的配置原则是： 提供MTP链路时（基于TDM承载），请选择“TDM 64kbit/s”或“TDM 2Mbit/s”。 提供MTP链路时（基于ATM承载），请选择“ATM”。 取值范围： “TDM0(TDM 64kbit/s)”“TDM1(TDM 2Mbit/s)”“ATM(ATM)” 默认值：无。 说明：必选参数。                                                                         |
| FN      | 逻辑框号       | 用于指定ETIA单板所在机框的逻辑编号。 取值范围：0～19 默认值：无。 说明：仅当“链路类型”为TDM 64kbit/s或者TDM 2Mbit/s时，此参数有效。                                                                                                                                                                                                                                                                                                               |
| SLN     | 槽位号        | 用于指定ETIA单板所在槽位的编号。 取值范围：0～13 默认值：无。 说明：仅当“链路类型”为TDM 64kbit/s或者TDM 2Mbit/s时，此参数有效。                                                                                                                                                                                                                                                                                                                 |
| MN      | BSG模块号     | 当指定MTP链路基于TDM承载时，该参数用于指定处理MTP2协议的BSG模块号；当指定MTP链路基于ATM承载时，该参数用于指定处理PVC链路的BSG模块号，此模块号必须与PVC链路的处理模块号一致，操作员可使用LST PVCLNK命令查询获得处理模块号。需要指出的是: 若输入了模块号，应该保证其在逻辑框号与槽号指定的单板上。 取值范围：1～1023 默认值：无。 说明：可选参数。                                                                                                                                                                                                  |
| E1      | E1端口号      | 用于指定该MTP链路所占用的E1端口号，该参数的配置原则是： MTP链路只能占用本框内ETIA板的E1端口，不能跨框占用。 当操作员指定了处理MTP2协议的BSG模块后，要求此链路所占用的E1端口由BSG所在单板对应的ETIA板提供。 取值范围：0～31 默认值：无。 说明：仅当“链路类型”为TDM 64kbit/s或者TDM 2Mbit/s时，此参数有效。                                                                                                                                                                                                              |
| TS      | E1内部时隙号    | 用于指定该MTP链路所占用的E1时隙号，该参数的配置原则是： MTP链路只能占用本框内ETIA板的E1时隙，不能跨框占用。 当操作员指定了处理MTP2协议的BSG模块后，要求此链路所占用的E1时隙由BSG所在单板对应的ETIA板提供。 MTP链路不能占用每个E1的0时隙（同步时隙）。 取值范围：1～31 默认值：无。 说明：仅当“链路类型”为TDM 64kbit/s或者TDM 2Mbit/s时，此参数有效。                                                                                                                                                                                     |
| SLOTNUM | 时隙数        | 用于指定该2Mbit/s链路占用多少个64kbit/s时隙，该参数需要与对端No.7信令设备保持一致。 取值范围：1～31 默认值：31 说明：仅当“链路类型”为TDM 2Mbit/s时，此参数有效。                                                                                                                                                                                                                                                                                              |
| SLC     | 信令链路编码     | 本局与No.7信令设备（直联方式）的对接参数之一，用于指定该MTP链路在所属MTP链路集内的逻辑编号。根据MTP协议的规定，SLC（即信令链路编码）为4比特的字段，其十进制取值范围只能为0～15，并且同一链路集内各信令链路的SLC必须统一编码，不能重复。 取值范围：0～15 默认值：无。 说明：必选参数。                                                                                                                                                                                                                                         |
| SLCS    | 信令链路编码发送   | 该参数主要用于本局内两条MTP链路的自环测试，其配置原则是： 当本局不启动MTP链路的自环测试时，信令链路编码发送、信令链路编码必须设置为同一值，否则将导致信令对接不成功。 当本局启动MTP链路的自环测试时，信令链路编码发送、信令链路编码不能设置为同一值，同时还应满足“链路1的信令链路编码＝链路2的信令链路编码发送、链路2的信令链路编码＝链路1的信令链路编码发送”的数据配置原则。 取值范围：0～15 默认值：无。 说明：可选参数。                                                                                                                                                                         |
| PLNM    | PVC链路名称    | 仅当本命令中“链路类型”参数设置为“ATM(ATM)”时该参数有效。用于标识PVC链路的名称。 取值范围：不超过32位的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                           |
| PRI     | 链路优先级      | 用于设定该条MTP链路的选路优先级，即优先级别高的链路将被优先选择，而优先级别较低的链路只能在比它优先级别较高的链路全部变成不可利用以后才能承载信令业务。其中，0为最高优先级，1次之，其余情况依此类推。 取值范围：0～254 默认值：0 说明：可选参数。                                                                                                                                                                                                                                                                   |
| SATF    | 卫星链路标志     | 用于标识该MTP链路是否承载在卫星电路上，操作员应根据实际情况设置，一般情况下应设为“否”。 取值范围： “TRUE(是)”“FALSE(否)” 默认值：“FALSE(否)” 说明：可选参数。                                                                                                                                                                                                                                                                                                  |
| LCT     | 低级拥塞阈值     | 当链路当前负荷达到低级拥塞阈值时，启动拥塞控制。 取值范围：1～100 默认值：70 说明：阈值指信令链路发送缓冲区被占用的百分比，单位为“%”。 当负荷达到此阈值时，认为发生低级传输拥塞，启动低级拥塞控制处理，减少一定比例的MSU发送。 “低级拥塞阈值”的取值应大于“拥塞结束阈值”且小于“中级拥塞阈值”。                                                                                                                                                                                                                                        |
| MCT     | 中级拥塞阈值     | 当链路当前负荷达到低级拥塞阈值时，启动拥塞控制。 取值范围：1～100 默认值：80 说明：阈值指信令链路发送缓冲区被占用的百分比，单位为“%”。 当负荷达到此阈值时，认为发生中级传输拥塞，启动中级拥塞控制处理，减少一定比例的MSU发送。 “中级拥塞阈值”的取值应大于“低级拥塞阈值”且小于“高级拥塞阈值”。                                                                                                                                                                                                                                        |
| HCT     | 高级拥塞阈值     | 当链路当前负荷达到低级拥塞阈值时，启动拥塞控制。 取值范围：1～100 默认值：90 说明：阈值指信令链路发送缓冲区被占用的百分比，单位为“%”。 当负荷达到此阈值时，认为发生高级传输拥塞，启动高级拥塞控制处理，减少一定比例的MSU发送。 “高级拥塞阈值”的取值应大于“中级拥塞阈值”。                                                                                                                                                                                                                                                   |
| CET     | 拥塞结束阈值     | 当MTP链路进入拥塞状态以后，用于定义MTP链路的信令负荷解除拥塞状态时的阈值，单位为“%”。 所谓阈值，是指信令发送缓冲区被占用的百分比。例如，若将“拥塞结束阈值”参数设为60，当MTP链路进入拥塞状态以后，如果后续已经使用的发送缓冲区与总发送缓冲区的比值小于60%时，则系统将解除MTP链路的拥塞状态。 取值范围：1～100 默认值：60 说明：实际配置时，“拥塞结束阈值”应小于“低级拥塞阈值”。                                                                                                                                                                                         |

| TCLEN   | 测试码长度      | 当需要进行MTP链路测试时，用于指定本局往SLTM消息中填充的测试码的长度，单位为“字节”。 取值范围：1～15 默认值：10 说明：可选参数。                                                                                                                                                                                                                                                                                                                          |
| PSLTM   | 周期性发送SLTM  | 用于指示本局是否通过该MTP链路周期性（周期为60秒）地向对端信令设备发送SLTM消息（即信令链路测试消息），系统默认为发送。 若将该参数设为“是”，则当本局通过该MTP链路向对端信令设备发送SLTM消息后，在正常情况下，对端信令设备将通过该MTP链路向本局响应SLTA消息（即信令链路测试证实消息），通过此功能，本局可以定期检测该MTP链路的可用性。 取值范围： “TRUE(是)”“FALSE(否)” 默认值：“TRUE(是)” 说明：可选参数。                                                                                                                                                                 |
| HLTHD   | 负荷过载告警阈值   | 用于指定链路上报负荷过载告警时的阈值。当链路的负荷达到此阈值时，系统将上报负荷过载告警，该参数单位为“%”。 取值范围：1～100 默认值：40 说明：“负荷过载告警阈值”应大于“负荷过载告警消除阈值”。                                                                                                                                                                                                                                                                                            |
| LLTHD   | 负荷过载告警消除阈值 | 用于指定链路消除负荷过载告警时的阈值。当链路的负荷降低到此阈值时，系统将消除负荷过载告警，该参数单位为“%”。 取值范围：1～100 默认值：20 说明：“负荷过载告警消除阈值”应小于“负荷过载告警阈值”。                                                                                                                                                                                                                                                                                           |

## 使用实例

1、增加MTP链路，“BSG模块号”为“1000”，“链路名称”为“N7LNK”,“链路类型”为“TDM 64kbit/s”，“E1端口号”为“6”，“E1内部时隙号”为“2”，“链路集名称”为“N7LKS”，“信令链路编码”为“1”，其他参数使用默认值：

```
ADD N7LNK: MN=1000, FN=0, SLN=2, LNKNM="N7LNK", LNKTYPE=TDM0, E1=6, TS=2, LSNM="N7LKS", SLC=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释                       | 原因分析                               | 处理建议                                                               |
|-------:|:---------------------------|:-----------------------------------|:-------------------------------------------------------------------|
| 306979 | 指定的BSG模块是主备模块，不能用来配置N7LNK。 | 输入的“BSG模块号”对应的进程为主备模式，不能用来配置MTP链路。 | 执行LST MODULE命令查询配置为负荷分担模式的BSG模块对应的“模块号”，重新输入“BSG模块号”的取值，确保其取值符合要求。 |
