# 查询DCI内部软件参数的配置信息(LST DCIINSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为维护类命令，查询DCI内部软件参数的配置信息。

## 注意事项

在执行此命令前请注意：

- 若需要查询全部DCI软参数据记录的概要信息，请不要输入任何参数。
- 若需要查询某条参数数据记录的详细信息，请输入“软件参数名称”和“软件参数值”。

## 参数说明

| 参数ID   | 参数名称   | 参数描述                                                                              |
|:-------|:-------|:----------------------------------------------------------------------------------|
| INSPN  | 软件参数名称 | 标识一条软参数据记录的关键字段之一（其取值在枚举值内取得），用于指定需要对哪一类软参数据记录的参数进行查询。 取值说明： 请参见DCI软件参数管理。 缺省值：无。 |
| INSPV  | 软件参数值  | 标识一条软参数据记录的关键字段之一，此处取值应在取值范围内取值。 取值说明： 请参见DCI软件参数管理。 缺省值：无。                       |

## 使用实例

查询DCI软参。软件参数名称为OUTERHEARTBEATTIMEOUT。

```
LST DCIINSP: INSPN=OUTERHEARTBEATTIMEOUT;
```

```
%%LST DCIINSP: INSPN=OUTERHEARTBEATTIMEOUT;%%
RETCODE = 0  操作成功

操作结果如下
------------
软件参数名称  =  局间心跳超时时长(毫秒)
  软件参数值  =  16000
(结果个数 = 1)

---    END
```
