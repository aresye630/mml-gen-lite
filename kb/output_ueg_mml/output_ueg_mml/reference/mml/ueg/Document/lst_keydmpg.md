# 查询关键DIAMETER对端组(LST KEYDMPG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为查询类命令，用于在FE/BE整体倒换功能中查询关键DIAMETER对端组。

- 若需要查询全部关键DIAMETER对端组数据记录的概要信息，请不要输入任何参数。
- 若需要查询某个关键DIAMETER对端组数据记录的详细信息，请输入“关键DIAMETER对端组名称”参数。

该命令的操作场景为：当使用FE/BE整体倒换功能时，查询关键DIAMETER对端组信息、关键DIAMETER对端组中配置的关键DIAMETER对端信息。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称            | 参数说明                                           |
|:----------|:----------------|:-----------------------------------------------|
| KEYDMPGNM | 关键DIAMETER对端组名称 | 用于指示系统需要按照哪个关键DIAMETER对端组名称来查询关键DIAMETER对端组数据。 |

## 使用实例

1. 查询关键DIAMETER对端组：

   `LST KEYDMPG:;`

   ```
   +++    UDM/*MEID:101 MENAME:HSS-LJW*/        2014-05-30 11:26:19+08:00
   O&M    #18254
   %%LST KEYDMPG:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    关键DIAMETER对端组名称  关键DIAMETER对端组在联动倒换中的比例

    KEYDRA                  50                                  
    KEYPRA                  50                                  
   (结果个数 = 2)

   ---    END
   ```
2. 查询关键DIAMETER对端，“关键DIAMETER对端组名称”为“KEYDRA”:

   `LST KEYDMPG: KEYDMPGNM="KEYDRA";`

   返回结果如下：

   ```
   +++    UDM/*MEID:101 MENAME:HSS-LJW*/        2014-05-23 15:49:14+08:00
   O&M    #296
   %%LST KEYDMPG: KEYDMPGNM="KEYDRA";%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
                 关键DIAMETER对端组名称  =  KEYDRA
   关键DIAMETER对端组在联动倒换中的比例  =  50
   (结果个数 = 1)

   关键Diameter对端如下
   --------------------
    关键DIAMETER对端名称

    BSF1                
    AS1                 
   (结果个数 = 2)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释          | 原因分析            | 处理建议                          |
|-------:|:--------------|:----------------|:------------------------------|
| 264034 | 关键参数取值不能为一个空格 | 输入的关键参数不能为一个空格。 | 根据实际情况，重新输入关键参数的取值，确保其取值符合要求。 |
