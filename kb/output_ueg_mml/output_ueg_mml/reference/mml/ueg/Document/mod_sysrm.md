# 修改系统的运行模式(MOD SYSRM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

- 本命令属于高危命令，执行不当会造成系统运行异常从而影响用户业务运行，因此执行该命令前，需要与华为技术支持确认后才可以实施。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于修改系统运行模式配置信息。

该命令主要运用于容灾场景下的手工倒换和手工倒回的场景。当主用网元需要退出服务进行维护（例如升级），这时可以对网元进行手工倒换：

1. 将“系统运行状态”设置为“DEACTIVE(去激活模式)”状态使网元暂时退出服务。根据容灾机制，业务处理将转移到容灾网元进行处理。
2. 在确认网元恢复正常后，再将“系统运行状态”设置为“ACTIVE(激活模式)”状态使该网元重新处理业务，此时可以通过手工倒回的方式将业务从容灾网元重新倒回到主用网元。
3. FE-BE链路故障引起联动倒换时，FE自动闭锁信令链路。如果FE-BE链路恢复，可以使用命令**MOD SYSRM**，将参数“系统运行状态”设置为“ACTIVE(激活模式)”一键式恢复系统。

   **说明** 

   不管**LST SYSRM**查询结果是否是“ACTIVE(激活模式)”，都要执行**MOD SYSRM**命令。

   ```
   MOD SYSRM: FS=ACTIVE;
   ```

## 注意事项

- 在系统初始化时已将“系统运行状态”预置为“ACTIVE(激活模式)”。
- 该命令不能在单局点执行，并且不能同时在主备容灾局执行，执行时需要确保容灾局可以进行容灾接管。
- 该命令不允许进行批操作。
- 该命令执行后设备的运行状态如下：
  - UDM连续加载全局数据失败。
  - DSG、BSG和HSF模块故障，显示模块未就绪。
  - DCS或者HLB配置动态链路后建链失败或者发送消息时建链失败。
  - MAP和Diamter链路断链。
  - FE和BE之间的DSG和DBS链路是激活状态。
  - 本端局点和远端局点中的远端DSG模块号未配置或者配置错误。
  - 此时上报的告警如下：
    - ALM-1811 M3UA链路故障
    - ALM-1815 M3UA路由不可用
    - ALM-1817 M3UA目的实体不可达
    - ALM-2752 SCCP目的信令点禁止
    - ALM-2754 SCCP子系统禁止
    - ALM-12043 局间DSG模块心跳超时
    - ALM-12046 退出服务
    - ALM-13020 Diameter对端实体故障
    - ALM-13021 Diameter链路故障
    - ALM-15050 模块未就绪
    - ALM-15063 FE向BE设置FE不可用
    - ALM-15058 网元退出服务
    - ALM-18412 TCP协议栈连续丢包
    - ALM-18601 UDM或AUSF不可用
    - ALM-18900 微服务未就绪
- 该命令执行之后要执行**DSP DMLNK**和**DSP M3LNK**确认链路状态是否全部断链，有时会出现链路状态未全部断链的情况，需要手动将未断链的链路去激活，否则会出现呼损。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                     |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------|
| FS     | 系统运行状态 | 用于指定系统的运行状态。 取值范围： ACTIVE(激活模式)：表示网元处于正常工作状态，在此状态下，该网元可以处理业务。DEACTIVE(去激活模式)：表示网元处于去激活状态，在此状态下，该网元不能处理任何业务，请谨慎使用。 默认值：无。 |

## 使用实例

修改系统的运行模式。“系统运行状态”修改为“ACTIVE(激活模式)”：

```
MOD SYSRM: FS=ACTIVE;
```
