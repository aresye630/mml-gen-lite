# 修改AP转发规则(MOD APRULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于对配置数据库中的一条AP转发规则数据记录进行修改或调整。在该命令中，UIM系统通过“索引”参数来唯一标识一条AP转发规则数据记录。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
|:-------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ID     | 索引       | 可选必选说明：必选参数 标识一条AP转发规则数据记录的关键字段（其取值不能被修改）。用于指定需要对哪一条AP转发规则数据记录的配置信息进行修改或调整，操作员可以使用LST APRULE命令查询获得。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| HOSTID | HOST索引   | 可选必选说明：可选参数 用于标识一个HOST模板。该参数必须先由ADD HOSTTPL命令定义，才能在此引用。 取值范围：0：不配置HOST模板1～255：根据索引值配置HOST模板 默认值：无。 说明：HOST模板命令组中的“索引”参数即为此处的“HOST索引”参数，操作员可以使用LST HOSTTPL命令查询获得。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| AUIDID | 应用区分标识索引 | 可选必选说明：可选参数 用于标识一个AUID（应用区分标识）模板。该参数必须先由ADD AUIDTPL命令定义，才能在此引用。 取值范围：0：不配置AUID模板1～255：根据索引值配置AUID模板 默认值：无。 说明：AUID模板命令组中的“索引”参数即为此处的“应用区分标识索引”参数，操作员可以使用LST AUIDTPL命令查询获得。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| IMPUE  | IMPU存在   | 可选必选说明：可选参数 用于标识是否需要匹配HTTP请求消息中的“IMPU”。 取值范围TRUE(是)：匹配IMPU。FALSE(否)：不匹配IMPU。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| IMPU   | IMPU     | 可选必选说明：条件必选参数 仅当本命令中的“IMPU存在”参数为“TRUE(是)”时该参数有效。用于标识要匹配的HTTP请求消息中的IMPU数据信息。IMPU即IP多媒体公共标识，该标识是用户对外可寻址的标识，用于请求和其他用户通信。 该参数的配置原则为：若AP为认证&转发AP，使用SIP格式的IMPU域名转发，操作员要先通过MOD INSP命令将软参“IMPUPROXYMODE(IMPU转发模式)”值设置为“1”。 “IMPU”参数配置为标准sip格式IMPU的域名信息（如果配置的是完整IMPU，则此规则无效）。 例如，标准sip格式IMPU为：sip:+8613499999999@beijing.ims.mnc000.mcc460.3gppnetwork.org，“IMPU”参数需要配置为“beijing.ims.mnc000.mcc460.3gppnetwork.org”。 若AP为认证&转发AP，使用SIP格式的IMPU前缀号段转发，操作员要先通过MOD INSP命令将软参“IMPUPROXYMODE(IMPU转发模式)”值设置为“2”。 “IMPU”参数配置为标准sip格式IMPU的前缀号段（如果配置的是完整IMPU，则此规则无效）。 例如，标准sip格式IMPU为：sip:+8613499999999@beijing.ims.mnc000.mcc460.3gppnetwork.org，“IMPU”参数可以配置为“sip:+8613499”。 若AP为认证&转发AP，使用SIP格式的IMPU前缀号段和域名转发，操作员要先通过MOD INSP命令将软参“IMPUPROXYMODE(IMPU转发模式)”值设置为“3”。 “IMPU”参数配置为标准sip格式IMPU的前缀号段+@+IMPU域名信息。 例如，标准sip格式IMPU为：sip:+8613499999999@beijing.ims.mnc000.mcc460.3gppnetwork.org，“IMPU”参数可以配置为“sip:+8613499@beijing.ims.mnc000.mcc460.3gppnetwork.org”。 若AP为转发AP，使用TEL格式的前缀号段转发，操作员要先通过MOD INSP命令将软参“IMPUPROXYMODE(IMPU转发模式)”值设置为“0”。 “IMPU”参数配置为标准tel格式的IMPU的前缀号段（如果配置的是完整IMPU，则此规则无效）。 例如，标准tel格式IMPU为：tel:+8613499999999，则“IMPU”参数可以配置为“tel:+8613499”。 取值范围：1～127位字符串。 默认值：无。 说明：该参数不区分大小写，在执行LST APRULE命令查询出的报文中为全小写形式。 |
| PEID   | HTTPPE索引 | 可选必选说明：可选参数 用于标识要将满足本条匹配规则的HTTP消息转发到哪个HTTP实体对应的转发AP或AS上。该参数必须先通过ADD HTTPPEHOST命令配置，然后才能在此处引用， 取值范围：0～255。 默认值：无。 说明：HTTPPEHOST命令组中的“对端HTTP实体标识”参数即为此处的“HTTPPE索引”参数，操作员可以使用LST HTTPPEHOST命令查询获得。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

## 使用实例

修改一条“索引”为“1”AP转发规则数据记录，匹配的“HOST索引”为“1”，“应用区分标识索引”为“1”，“HTTPPE索引”为“2”：

```
MOD APRULE: ID=1, HOSTID=1, AUIDID=1, IMPUE=FALSE, PEID=2;
```
