# 查询NAFID群组数据(LST NAFGRPDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询网络应用功能组下的NAFID列表信息：

- 若需要查询某个网络应用功能组下的NAFID列表信息，请输入“NAF GROUP编号”。
- 若需要查询所有网络应用功能组下的NAFID列表信息，请不要输入任何参数。
- FQDN不区分大小写，在执行本命令查询出的报文中为全小写形式。

  **说明** 

  该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称        | 参数说明                                                                                                    |
|:-------|:------------|:--------------------------------------------------------------------------------------------------------|
| NAFGRP | NAF GROUP编号 | 用于指示系统需要按照哪个NAF GROUP编号来查询NAFID列表配置信息；若不输入，则表示查询所有网络应用功能组下的NAFID列表信息。 取值范围：1～65535。 默认值：无。 注意：该参数为可选参数。 |

## 使用实例

1. 查询NAFID群组数据，不携带参数：

   ```
   LST NAFGRPDATA:;
   ```

   返回结果如下：

   ```
   %%LST NAFGRPDATA:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    NAF GROUP编号  FQDN 

    1              1     
    7              7     
   (结果个数 = 2)

   ---    END
   ```
2. 查询NAFID群组数据，“NAF GROUP编号”为“1”：

   执行命令如下：

   ```
   LST NAFGRPDATA: NAFGRP=1;
   ```

   返回结果如下：

   ```
   %%LST NAFGRPDATA: NAFGRP=1;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
   NAF GROUP编号  =  1
          FQDN  =  1
   (结果个数 = 1)

   ---    END
   ```
