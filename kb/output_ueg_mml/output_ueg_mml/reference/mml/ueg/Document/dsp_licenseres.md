# 显示License资源（DSP LICENSERES）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查看License资源数目以及使用情况。

## 注意事项

- 系统中使用的用户数资源，指的是系统在线用户数的使用数目。
- 该命令执行后立即生效。
- 当License文件未激活时，查询结果为空，激活后只能查询购买量不等于0且支持显示的资源项。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询License资源：

```
%%DSP LICENSERES:;%%
RETCODE = 0  操作成功

操作结果如下
------------
资源项         资源名称                              资源总数    已使用资源    使用率
LKV7RIPV601    支持用户面IPv6 PDP（每千PDP/承载）    12000       0             0%    
LKV7CDRS01     每秒话单数（CDR/秒）                  32000       0             0%    
(结果个数 = 2)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                    |
|:--------|:-------------------------|
| 资源项     | 该参数用于指定License资源项的ID。    |
| 资源名称    | 该参数用于指定License资源项的名称。    |
| 资源总数    | 该参数用于指定License资源的总的数量。   |
| 已使用资源   | 该参数用于指定License资源已被使用的数量。 |
| 使用率     | 该参数用于指定License资源的使用率。    |
