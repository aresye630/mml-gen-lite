# 增加HSS CDMA MAP信息(ADD HCMAPOFI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于HSS在与CDMA HLR对接时增加HSS CDMA MAP信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                    |
|:-------|:-------|:----------------------------------------|
| LEX    | 本地实体标识 | 用于标识服务提供商定义的一个唯一实体。 取值范围：0～15 默认值：无。    |
| MKTID  | 市场标识   | 用于标识服务提供商定义的一个唯一市场。 取值范围：0～65535 默认值：无。 |
| SWNO   | 转换号码   | 用于标识服务提供商定义的一个唯一号码。 取值范围：0～255 默认值：无。   |

## 使用实例

增加HSS CDMA MAP信息，“LEX”为“0”，“MKTID”为“1”，“SWNO”为“2”：

```
ADD HCMAPOFI: LEX=0, MKTID=1, SWNO=2;
```
