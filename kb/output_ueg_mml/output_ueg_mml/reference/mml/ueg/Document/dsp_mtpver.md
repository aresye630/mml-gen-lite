# 显示MTP版本(DSP MTPVER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询指定MTP协议的版本信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                  |
|:-------|:-----------|:------------------------------------------------------|
| MN     | CCU/BSG模块号 | 用于请求系统显示哪个模块号内MTP协议的版本信息。 取值范围：1～1023 默认值：无。 说明：必选参数。 |

## 使用实例

显示MTP软件版本信息，“模块号”为“1022”:

```
DSP MTPVER: MN=1022;
```

返回结果如下：

```
 %%DSP MTPVER: MN=1022;%%                          
    RETCODE = 0  操作成功                           
    显示MTP版本                                     
    -----------                                     
    MTP版本 = VPP SS7 v1.2.1.1(ANSI-MTP3) (ITU-T 1996)  
    (结果个数 = 1)

    ---    END
```

## 输出结果说明

| 输出项名称   | 输出结果解释                                                   |
|:--------|:---------------------------------------------------------|
| MTP版本   | 用于返回当前MTP协议栈的版本信息，其版本信息的结构为：发布部门+软件模块+软件版本号+软件补丁号（协议类型）。 |
