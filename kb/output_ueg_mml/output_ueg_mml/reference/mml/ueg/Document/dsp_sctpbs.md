# 显示SCTP全部统计信息(DSP SCTPBS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于请求系统显示SCTP全部的偶联(两个SCTP端点通过SCTP协议规定的4步握手机制建立起来的进行数据传递的逻辑联系或者通道)统计信息。

该命令与**DSP SCTPAS**不同的是，**DSP SCTPAS**统计的是指定的单个偶联的统计信息，而**DSP SCTPBS**是查询SCTP所有偶联的统计信息。

## 注意事项

无。

## 参数说明

| 参数ID   | 参数名称   | 参数描述                                                |
|:-------|:-------|:----------------------------------------------------|
| MN     | 模块号    | 用于请求系统显示哪个BSG模块内的SCTP全部偶联统计信息。 取值范围： 1～1023 默认值： 无。 |

## 输出结果说明

| 输出项名称        | 输出项解释                     |
|:-------------|:--------------------------|
| 偶联总数         | 用于返回当前模块的偶联总数。            |
| 本端发起的偶联个数    | 用于返回本端发起的偶联数量。            |
| 对端发起的偶联个数    | 用于返回对端发起的偶联数量。            |
| 本端发起的偶联失败次数  | 用于返回本端发起的偶联的失败次数。         |
| 对端发起的偶联失败次数  | 用于返回对端发起的偶联的失败次数。         |
| 关联异常关闭次数     | 用于返回异常关闭的偶联数量。            |
| 关联正常关闭次数     | 用于返回正常关闭的偶联数量。            |
| 接收的非预期的数据块个数 | 用于返回接收的out of Blue数据块的数量。 |
| 发送的控制块个数     | 用于返回发送的控制数据块的数量。          |
| 发送的有序数据块个数   | 用于返回发送的有序DATA数据块的数量。      |
| 发送的无序数据块个数   | 用于返回发送的非顺序DATA数据块的数量。     |
| 接收的控制块个数     | 用于返回接收的控制数据块的数量。          |
| 接收的有序数据块个数   | 用于返回接收的有序DATA数据块的数量。      |
| 接收的无序数据块个数   | 用于返回接收的非顺序DATA数据块的数量。     |
| 重发的数据块个数     | 用于返回重传的DATA数据块的数量。        |
| 发送的用户消息未分片数  | 用于返回不以分段模式发送的上层用户数据消息的数量。 |
| 发送的用户消息分片数   | 用于返回以分段模式发送的上层用户数据消息的数量。  |
| 接收的校验和错误的总包数 | 用于返回接收的带错误检验和的分组数量。       |
| 总共发送的SCTP包个数 | 用于返回SCTP发送的分组总数。          |
| 总共接收的SCTP包个数 | 用于返回SCTP接收的分组总数。          |
| 丢弃的总包数       | 某个模块上被SCTP偶联所拒绝包数的总数。     |
