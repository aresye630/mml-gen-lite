# 查询MOC名称和索引(LST MOCTRC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于在数据库中查询MOC名称和索引。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                   |
|:----------|:-------|:-----------------------|
| MOCNAME   | MOC名称  | 用于指示系统需要按照哪个MOC名称来查询。  |
| MOCMODULE | MOC模块号 | 用于指示系统需要按照哪个MOC模块号来查询。 |
| MOCINDEX  | MOC索引  | 用于指示系统需要按照哪个MOC索引来查询。  |
| MOCTYPE   | MOC类型  | 用于指示系统需要按照哪个MOC类型来查询。  |

## 使用实例

查询“MOC类型”为“1”的MOC名称和索引：

```
LST MOCTRC: MOCTYPE=1;
```
