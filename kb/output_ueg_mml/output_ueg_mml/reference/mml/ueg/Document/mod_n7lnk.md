# 修改MTP链路(MOD N7LNK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于对配置数据库中的一条MTP链路数据记录的某些参数进行修改或调整。 在该命令中，系统通过“链路名称”参数来唯一标识一条MTP链路数据记录。

## 注意事项

- UDM不支持该命令。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                       |
|:-------|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LNKNM  | 链路名称       | 标识一条MTP链路数据记录的关键字段，用于指定需要对哪一条MTP链路数据记录的参数进行修改或调整，操作员可以使用LST N7LNK命令查询获得。 取值范围：长度不超过32的字符串 默认值：无。 说明：必选参数。                                                                                                                                                                                                                  |
| PRI    | 链路优先级      | 用于设定该条MTP链路的选路优先级，即优先级别高的链路将被优先选择，而优先级别较低的链路只能在比它优先级别较高的链路全部变成不可利用以后才能承载信令业务。其中，0为最高优先级，1次之，其余情况依此类推。 取值范围：0～254 默认值：无。 说明：可选参数。                                                                                                                                                                                           |
| SATF   | 卫星链路标志     | 用于标识该MTP链路是否承载在卫星电路上，操作员应根据实际情况设置，一般情况下应设为“否”。 取值范围： “TRUE(是)”“FALSE(否)” 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                   |
| LCT    | 低级拥塞阈值     | 当链路当前负荷达到低级拥塞阈值时，启动拥塞控制。 取值范围：1～100 默认值：无。 说明：阈值指信令链路发送缓冲区被占用的百分比，单位为“%”。 当负荷达到此阈值时，认为发生低级传输拥塞，启动低级拥塞控制处理，减少一定比例的MSU发送 “低级拥塞阈值”的取值应大于“拥塞结束阈值”且小于“中级拥塞阈值”。                                                                                                                                                                  |
| MCT    | 中级拥塞阈值     | 当链路当前负荷达到低级拥塞阈值时，启动拥塞控制。 取值范围：1～100 默认值：无。 说明：阈值指信令链路发送缓冲区被占用的百分比，单位为“%”。 当负荷达到此阈值时，认为发生中级传输拥塞，启动中级拥塞控制处理，减少一定比例的MSU发送。“中级拥塞阈值”的取值应大于“低级拥塞阈值”且小于“高级拥塞阈值”。                                                                                                                                                                  |
| HCT    | 高级拥塞阈值     | 当链路当前负荷达到低级拥塞阈值时，启动拥塞控制。 取值范围：1～100 默认值：无。 说明：阈值指信令链路发送缓冲区被占用的百分比，单位为“%”。 当负荷达到此阈值时，认为发生高级传输拥塞，启动高级拥塞控制处理，减少一定比例的MSU发送。 “高级拥塞阈值”的取值应大于“中级拥塞阈值”。                                                                                                                                                                            |
| CET    | 拥塞结束阈值     | 当MTP链路进入拥塞状态以后，用于定义MTP链路的信令负荷解除拥塞状态时的阈值，该参数的取值范围为0～100、单位为“%”。 所谓阈值，是指信令发送缓冲区被占用的百分比。例如，若将“拥塞结束阈值”参数设为60，当MTP链路进入拥塞状态以后，如果后续已经使用的发送缓冲区与总发送缓冲区的比值小于60%时，则系统将解除MTP链路的拥塞状态。 取值范围：1～100 默认值：无。 说明：实际配置时，“拥塞结束阈值”应小于“低级拥塞阈值”。                                                                                                   |
| TC     | 测试码        | 当需要进行MTP链路测试时，用于指定本局往SLTM消息中填充的测试码，该参数为2位长度的十六进制数值（0～9，A～F）。 配置测试码的主要用途是为了实时检测MTP链路的可用性，即本局在MTP链路上发送SLTM消息，期待对端响应SLTA消息。 取值范围：长度不超过2的字符串 默认值：无。 说明：可选参数。                                                                                                                                                                   |
| TCLEN  | 测试码长度      | 当需要进行MTP链路测试时，用于指定本局往SLTM消息中填充的测试码的长度，该参数的取值范围为1～15、单位为“字节”。 取值范围：1～15 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                     |
| PSLTM  | 周期性发送SLTM  | 用于指示本局是否通过该MTP链路周期性（周期为60秒）地向对端信令设备发送SLTM消息（即信令链路测试消息）。 若将该参数设为“是”，则当本局通过该MTP链路向对端信令设备发送SLTM消息后，在正常情况下，对端信令设备将通过该MTP链路向本局响应SLTA消息（即信令链路测试证实消息），通过此功能，本局可以定期检测该MTP链路的可用性。 取值范围： “TRUE(是)”“FALSE(否)” 默认值：无。 说明：可选参数。                                                                                                         |
| HLTHD  | 负荷过载告警阈值   | 用于指定链路上报负荷过载告警时的阈值。当链路的负荷达到此阈值时，系统将上报负荷过载告警，该参数单位为"%"。 取值范围：1～100 默认值：无。 说明：“负荷过载告警阈值”应大于“负荷过载告警消除阈值”。                                                                                                                                                                                                                     |
| LLTHD  | 负荷过载告警消除阈值 | 用于指定链路消除负荷过载告警时的阈值。当链路的负荷降低到此阈值时，系统将消除负荷过载告警，该参数单位为"%"。 取值范围：1～100 默认值：无。 说明：“负荷过载告警消除阈值”应小于“负荷过载告警阈值”。                                                                                                                                                                                                                    |
| LNKNM1 | 新链路名称      | 对于由本命令中“链路名称”字段所标识的某条具体的数据记录而言，用于指示系统是否需要对该数据记录中“链路名称”字段的取值重新进行定义，其值域类型为字符串、最大长度为32。该参数的配置原则是： 若不输入任何字符：表示不对该数据记录中“链路名称”字段的取值重新进行定义。 若输入一个字符串：表示需要对该数据记录中“链路名称”字段的取值重新进行定义，且输入的字符串不能在相应的数据表中已经被定义。假设本命令中“链路名称”字段的取值为A、“新链路名称”字段的取值为B，则对于配置数据库中索引了取值为A的所有数据记录的“链路名称”字段，系统将自动把这些字段的值由A修改为B。 取值范围：长度不超过32的字符串 默认值：无。 说明：可选参数。 |

## 使用实例

1、修改MTP链路，“链路名称”为“MTP3LNK”，“链路优先级”为“2”：

```
MOD N7LNK: LNKNM="MTP3LNK", PRI=2;
```
