# 修改SLF路由(MOD SLFROUTE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在配置数据库中修改一条SLF(Subscription Locator Function)路由的配置数据。在该命令中，系统通过“路由名称”参数来唯一标识一条SLF路由的配置信息。

**说明** 

该命令暂不支持。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称         | 参数说明                                                                                                                                                       |
|:--------|:-------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| RTNAME  | 路由名称         | 标识SLF路由的配置数据记录的关键字段（其取值不能被修改）。用于指定需要对哪个路由名称对应的SLF路由的配置数据记录进行修改或调整。操作员可以使用LST SLFROUTE命令查询获得。                                                               |
| NRTNAME | 新路由名称        | 用于标识新路由信息的名称，新路由信息的名称唯一。 取值范围：长度不超过127位的字符串。 默认值：无。                                                                                                        |
| RTTYPE  | Route信息的类型   | 用于标识在UDM的配置数据库中定义SLF路由信息的类型，即可以对哪些用户标识进行路由匹配。 取值范围： “SIPSUFFIX(Sip后缀)”“TELPREFIX(Tel前缀)”“MSISDNPREFIX(Msisdn前缀)”“NUMBERSEGPREFIX(Number Segment前缀)” 默认值：无。 |
| USERID  | 用户标识的前后缀     | 用于标识在UDM的配置数据库中定义SLF路由匹配信息。即以下各种用户标识的前后缀信息: Sip后缀、Tel前缀、Msisdn前缀和Number Segment前缀。 取值范围：长度不超过127位的字符串。 默认值：无。                                              |
| DN      | 用户所在的域       | 用于标识在UDM的配置数据库中定义用户所在的域。 取值范围：长度不超过127位的字符串。 默认值：无。                                                                                                        |
| HN      | 用户归属的HSS地址   | 用于标识在UDM的配置数据库中定义用户归属的HSS地址。 取值范围：长度不超过127位的字符串。 默认值：无。                                                                                                    |
| HN2     | 用户归属的备选HSS地址 | 用于标识在UDM的配置数据库中定义用户归属的备选HSS地址。 取值范围：长度不超过127位的字符串。 默认值：无。                                                                                                  |

## 使用实例

修改一条SLF路由配置。“路由名称”为“SLFROUTENAME”，“新路由名称”为“NSLFROUTENAME”，“Route信息的类型”为“Msisdn前缀”，“用户标识的前后缀”改为“111”，“用户归属的HSS地址”修改为“hss1.huawei.com”。

`MOD SLFROUTE: RTNAME="SLFROUTENAME", NRTNAME="NSLFROUTENAME", RTTYPE=MSISDNPREFIX, USERID="111", HN="hss1.huawei.com";`
