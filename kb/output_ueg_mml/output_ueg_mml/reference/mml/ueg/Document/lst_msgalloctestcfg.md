# 查询消息包申请测试配置信息(LST MSGALLOCTESTCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于查询UDM注册给CSP的消息包申请测试配置信息：

- 若需要查询全部的消息包申请测试配置信息，请不要输入任何参数。
- 若需要查询某个模块类型的消息包申请测试配置信息，请输入“模块类型”参数。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                                          |
|:-----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MODULETYPE | 模块类型   | 可选必选说明：可选参数 参数含义：用于标识按哪个“模块类型”查询UDM注册给CSP的消息包申请测试配置模块类型。 取值范围：BSG(BSG)：模块类型值41 CCU(CCU)：模块类型值42 HSF(HSF)：模块类型值20ACF(ACF)：模块类型值81ERU(ERU)：模块类型值46APF(APF)：模块类型值84 默认值：无 配置原则：“ACF(ACF)”和“APF(APF)”模块仅在虚机场景下支持。 |

## 使用实例

- 查询“模块类型”为“CCU(CCU)”的消息包申请测试配置信息。

  ```
  LST MSGALLOCTESTCFG: MODULETYPE=CCU;
  ```
