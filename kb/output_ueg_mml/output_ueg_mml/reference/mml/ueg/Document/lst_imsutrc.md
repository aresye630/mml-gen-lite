# 查询联合用户跟踪任务(LST IMSUTRC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询联合用户跟踪任务。

- 若需要查询全部联合用户跟踪任务，请不要输入任何参数。
- 若需要查询某个联合用户跟踪任务，请输入“跟踪参考号”或其他参数或这些参数的组合。

## 注意事项

当前版本不支持此功能，执行该命令后会返回错误码：335607 暂不支持该功能。

## 参数说明

| 参数ID         | 参数名称      | 参数描述                                                                    |
|:-------------|:----------|:------------------------------------------------------------------------|
| TRCREFERENCE | 跟踪参考号     | 用于标识查询全网跟踪任务的全网跟踪参考号。 取值范围：0～65535 默认值：无。                               |
| IMPU         | IP多媒体公共标识 | 用于标识查询全网跟踪任务的IMPU。 取值范围：1～128位由字母、数字、“.”、“_”、“-”、空格或中文字符等组成的字符串。 默认值：无。 |

## 使用实例

查询全网跟踪任务：

```
LST IMSUTRC:;
```

```
%%LST IMSUTRC:;%%
RETCODE = 0  操作成功

联合用户跟踪任务表
------------------
 跟踪参考  IP多媒体公共标识              任务有效天数  跟踪内部模块  日志开关  开始时间             内部跟踪编号

 20734     sip:SNR1_impu_1_1@huawei.com  7             否            否        2013-07-11-18.03.20  10          
 24634     sip:UDR1_impu_1_1@huawei.com  7             否            否        2013-07-11-14.04.30  11          
(结果个数 = 2)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数请参见本命令的参数说明。表1列出的是未包含在本命令参数说明中的输出项。

| 输出项名称   | 输出项解释             |
|:--------|:------------------|
| 任务有效天数  | 用于返回跟踪任务创建后的有效天数。 |
| 跟踪内部模块  | 用于返回任务是否跟踪内部模块。   |
| 日志开关    | 用于返回是否打开日志开关。     |
| 开始时间    | 用于返回全网跟踪任务启动时间。   |
| 内部跟踪编号  | 用于返回网元内部跟踪任务编号。   |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释    | 原因分析        | 处理建议   |
|-------:|:---------|:------------|:-------|
| 335607 | 暂不支持该功能。 | 当前版本不支持此功能。 | 无需处理。  |
