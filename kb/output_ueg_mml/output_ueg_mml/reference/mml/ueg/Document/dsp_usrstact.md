# 查询系统中REG、UNREG和PENDING状态的用户数量(DSP USRSTACT)

## 命令功能

**须知** 

本命令属于高危命令，执行该命令会对性能有影响，建议在话务量低时执行。

该命令用于查询系统中REG（注册用户）、UNREG（未注册用户）和PENDING（挂起用户）状态的用户数量。

- REG状态：已注册的IMS用户，即在线状态。
- UEREG状态：IMS用户并没有完全注册，但是保存了一定的用户动态信息，用户可正常使用未注册业务（如关机语音信箱等）的场景。
- PENDING状态：注册过程的一个中间状态，即S-CSCF给UDM下发MAR消息获取鉴权数据，但未下发SAR消息获取用户数据时，UDM更新用户状态为PENDING状态。

## 注意事项

该命令不允许进行批操作。

## 参数说明

无。

## 使用实例

查询系统中REG、UNREG和PENDING状态的用户数量。

`DSP USRSTACT:;`

```
%%DSP USRSTACT:;%%
RETCODE = 0  操作成功

查询结果如下
------------
    Reg状态的IU对数量  =  1
  Unreg状态的IU对数量  =  0
Pending状态的IU对数量  =  0
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称           | 输出结果解释                   |
|:----------------|:-------------------------|
| Reg状态的IU对数量     | 用于返回注册用户的IMPI/IMPU对用户数量  |
| Unreg状态的IU对数量   | 用于返回未注册用户的IMPI/IMPU对用户数量 |
| Pending状态的IU对数量 | 用于返回挂起用户的IMPI/IMPU对用户数量  |
