# 显示M3UA版本(DSP M3VER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询指定M3UA协议栈的版本信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                          |
|:-------|:-------|:--------------------------------------------------------------|
| MN     | 模块号    | 用于请求系统显示哪个BSG/CCU模块号内M3UA协议栈的版本信息。 取值范围：1～1023 默认值：无。 说明：必选参数 |

## 使用实例

显示当前M3UA协议版本：

```
DSP M3VER: MN=1;
```

返回结果如下：

```
%%DSP M3VER: MN=1;%%
RETCODE = 0  操作成功

M3UA VPP组件版本
----------------
M3UA版本  =  VPP SS7 v1.2.1.1(M3UA)(RFC3332)
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出结果解释                                                    |
|:--------|:----------------------------------------------------------|
| M3UA版本  | 用于返回当前M3UA协议栈的版本信息，其版本信息的结构为：发布部门+软件模块+软件版本号+软件补丁号（协议类型）。 |
