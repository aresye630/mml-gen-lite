# 增加MTP链路集(ADD N7LKS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于当源信令点和MTP目的信令点都配置成功时在配置数据库中增加一条MTP链路集数据记录。

## 注意事项

- 相邻信令点之间只能配置一条MTP链路集，一个信令点最多只能配置16条MTP信令链路集。
- 在执行该命令之前，与所增加的MTP链路集相关的以下信息必须已经配置成功。

  - 源信令点（可通过**ADD OFI**进行配置）
  - MTP目的信令点（可通过**ADD N7DSP**进行配置）

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
|:-------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LSNM   | 链路集名称     | 用于标识在配置数据库中定义一个MTP链路集，该参数的配置原则是： 由于一个链路集即代表一条信令路由，因此，本局与某个相邻目的信令点之间只能配置一个MTP链路集。 对于操作员在LMT输入的字符串，系统在操作BAM数据库之前将自动进行如下处理：将该字符串中的所有英文字母全部转换成大写、并将该字符串中最左边与最右边的空格删除掉。例如，假设操作员在LMT输入的字符串为“ 区域abc ”，则系统在操作OMU数据库之前将自动将该字符串转换为“区域ABC”。 对于操作员通过本命令配置的某一条具体的数据记录而言，该数据记录中“链路集名称”字段的原取值为A，如果操作员后续需要将该字段的取值由A修改为B，则其可以通过MOD N7LKS命令中的“新链路集名称”参数重新进行定义。此时，对于配置数据库中索引了取值为A的所有数据记录的“链路集名称”字段，系统将自动把这些字段的值由A修改为B。 取值范围：1～32位的字符串，字符类型包括：数字“0～9”、大小写字母、特殊字符“-”、“_”、“.”、空格符及中文字符等。 默认值：无。                                                                                                                                                                                                                                        |
| ASPNM  | 相邻目的信令点名称 | 用于标识与本局存在直达信令路由的目的信令点名称。该参数必须先由ADD N7DSP命令定义，然后才能在此处引用，并且只能是以下两种情况之一： 与本局以直联方式对接的STP的目的信令点名称。 与本局以直联方式（不通过STP转发信令）对接的MSC、SGSN等信令设备的目的信令点名称。 取值范围：1～32位的字符串，字符类型包括：数字“0～9”、大小写字母、特殊字符“-”、“_”、“.”、空格符及中文字符等。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| SLSM   | 链路选择掩码    | 用于标识本局在该链路集下的多条MTP链路之间如何实现信令业务的负荷分担，建议取系统的默认值B1111。该参数的配置原则是： 当某个链路集内配置的信令链路数仅为1时，该参数可以设为任意值。 当某个链路集内配置的信令链路数为2时，该参数中“1”的个数必须大于或等于1，例如为B0001、B1100、B1111。 当某个链路集内配置的信令链路数为3～4时，该参数中“1”的个数必须大于或等于2，例如为B0011、B1100、B1111。 当某个链路集内配置的信令链路数为5～8时，该参数中“1”的个数必须大于或等于3，例如为B1011、B1110、B1111。 当某个链路集内配置的信令链路数为9～16时，该参数只能设为B1111。  说明： 为避免出现同摆（所谓同摆，是指信令单元在选择链路集与信令链路时，每次总是使用相同的链路集号与信令链路号）的现象，操作员不能将链路集选择掩码（由ADD N7DSP命令配置）与各链路集的链路选择掩码设成同一个编码，建议将两个掩码中“1”的位置错开。例如，链路集选择掩码为0110，则链路选择掩码可设为1001。 取值范围： B0000(B0000)B0001(B0001)B0010(B0010)B0011(B0011)B0100(B0100)B0101(B0101)B0110(B0110)B0111(B0111)B1000(B1000)B1001(B1001)B1010(B1010)B1011(B1011)B1100(B1100)B1101(B1101)B1110(B1110)B1111(B1111) 默认值：B1111(B1111) |
| EMGF   | 紧急建链标志    | 用于标识系统该链路集内的链路是否启用紧急建链，当MTP3链路首次启动或MTP3链路发生故障后进行恢复时，用于指示本局在启动SAAL链路的定位控制过程时是否采用紧急定位程序。若将该参数设为“否”，表示采用正常定位程序；若将该参数设为“是”，则表示采用紧急定位程序（主要是SAAL链路初始建立后的验收周期比正常定位程序短）。 取值范围： TRUE(是)FALSE(否) 默认值：FALSE(否)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |

## 使用实例

1、增加MTP链路集，“链路集名称”为“N7LKS”，“相邻目的信令点名称”为“N7DSP”：

```
ADD N7LKS: LSNM="N7LKS", ASPNM="N7DSP";
```

2、增加MTP链路集，“链路集名称”为“N7LKS”，“相邻目的信令点名称”为“N7DSP”，“链路选择掩码”为“B1010”：

```
ADD N7LKS: LSNM="N7LKS", ASPNM="N7DSP", SLSM=B1010;
```
