# 查询短信互通网关用户(LST SMSCLISUB)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询短信互通网关用户的用户数据，查询的结果只显示用户名，不显示用户密码。

## 注意事项

当前版本不支持此功能，执行该命令后会返回错误码：335607 暂不支持该功能。

## 参数说明

无。

## 使用实例

查询短信互通网关用户，执行命令如下：

LST SMSCLISUB:;

```
%%LST SMSCLISUB:;%%
RETCODE = 0  操作成功

操作结果如下
------------
      用户名称  =  user1
  连续错误次数  =  0
锁定状态标志位  =  解锁
      锁定时间  =  NULL
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见

**ADD SMSCLISUB**

命令的参数说明。表1列出的是未包含在

**ADD SMSCLISUB**

命令参数说明中的输出项。

| 输出项名称   | 输出项解释                                            |
|:--------|:-------------------------------------------------|
| 用户名称    | 用于显示已存在短信互通网关用户的用户名。                             |
| 连续错误次数  | 用于显示SMG接入认证时的连续认证失败的次数。                          |
| 锁定状态标志位 | 用于显示目前账号的锁定状态。锁定：账号处于锁定状态，拒绝认证。解锁：账号处于解锁状态，可以认证。 |
| 锁定时间    | 用于显示连续认证失败次数达到最大次数后的锁定时间。                        |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释    | 原因分析        | 处理建议   |
|-------:|:---------|:------------|:-------|
| 335607 | 暂不支持该功能。 | 当前版本不支持此功能。 | 无需处理。  |
