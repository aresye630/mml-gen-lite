# 修改M3UA本地实体(MOD M3LE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于对配置数据库中的一条M3UA本地实体数据记录的某些参数进行修改或调整。在该命令中，系统通过“本地实体名称”参数来唯一标识一条M3UA本地实体数据记录。

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称    | 参数描述                                                                                                                                                                                                                                                                                                           |
|:-------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LENM   | 本地实体名称  | 标识一条M3UA本地实体数据记录的关键字段，用于指定需要对哪一条M3UA本地实体数据记录的参数进行修改或调整，操作员可以使用LST M3LE命令查询获得。 取值范围: 长度不超过32的字符串。 默认值: 无。 说明: 无。                                                                                                                                                                                                |
| RC     | 路由上下文   | 仅当本命令中“本地实体名称”对应的本地实体类型为“AS(应用服务器)”时该参数有效。用于定义本局作为客户端在向对端发送注册请求时的选路关键字。 取值范围: 0～2147483647。 默认值: 无。 说明: 路由上下文可以为一个十进制的数字，也可以为空（不配置），具体对接时需要双方协商一致。 若输入“2147483647”，则表示路由上下文为空，即不使用路由上下文。                                                                                                                       |
| ASLE   | 互助本地实体  | 用于在本局的配置数据库中定义一个该本地实体对应的互助实体，当该本地实体所在路由不可用，可以利用互助本地实体收发消息。 取值范围: 全部选中全部清空全部灰化“LE0(本地实体索引0)”～“LE253(本地实体索引253)” 默认值: 无。 说明: 互助本地实体互助关系是单向的。即当某一个M3UA本地实体不可用时，其互助实体可以对它互助，但反过来则不行。 在数据库中某一个M3UA本地实体的互助实体最多能配置16个。 只能通过MOD M3LE设置互助关系。                                                                            |
| LENM1  | 新本地实体名称 | 对于由本命令中“本地实体名称”所标识的某条具体的数据记录而言，用于指示系统是否需要对该数据记录中“本地实体名称”的取值重新进行定义。 取值范围: 长度不超过32的字符串。 默认值: 无。 说明: 若不输入任何字符：表示不对该数据记录中“本地实体名称”字段的取值重新进行定义。 若输入一个字符串：表示需要对该数据记录中“本地实体名称”字段的取值重新进行定义，且输入的字符串不能在相应的数据表中已经被定义。假设本命令中“本地实体名称”字段的取值为“A”、“新本地实体名称”字段的取值为“B”，则对于配置数据库中索引了取值为A的所有数据记录的“本地实体名称”字段，系统将自动把这些字段的值由“A”修改为“B”。 |

## 使用实例

1、修改M3UA本地实体，“本地实体名称”为“MODIFIED”，“路由上下文”为“0”：

```
MOD M3LE: LENM="MODIFIED", RC=0;
```

2、修改M3UA本地实体，“本地实体名称”为“MODIFIED”，“新本地实体名称”为“NEWLE”：

```
MOD M3LE: LENM="MODIFIED", LENM1="NEWLE";
```
