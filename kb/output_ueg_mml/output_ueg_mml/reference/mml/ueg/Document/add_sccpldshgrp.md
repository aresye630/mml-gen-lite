# 增加SCCP目的负荷分担信令点组(ADD SCCPLDSHGRP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条SCCP目的负荷分担信令点组数据记录。

## 注意事项

- 仅当本局与对端设备之间的SCCP信令路由需要支持互助功能时，操作员才需要使用**ADD SCCPLDSHGRP**命令增加SCCP负荷分担目的信令点组。SCCP负荷分担信令点组包含一个主信令点和最多8个负荷分担信令点，主信令点优先级固定为0，负荷分担信令点优先级可配置，优先级一样的信令点码就是负荷分担关系，优先级不一样的信令点就是主备关系。对于主备关系和负荷分担关系的描述可参考ADD SCCPDSP中的描述。负荷分担信令点组的提出是为了实现基于GT的负荷分担，具体可参考**ADD SCCPGT**中的描述。
- 主信令点和负荷分担目的信令点必须先在MTP DSP表或M3UA DE表中配置（由本局与目的信令点之间的信令承载方式决定配置在哪个数据表中）。通过**LST N7DSP**或**LST M3DE**命令，可分别查看上述数据表中的配置信息。

## 使用实例

1、增加SCCP负荷分担信令点组，“负荷分担信令点组名称”为“LoadShareDspGrp”，“主目的信令点名称”为“MainDSP”，“1号负荷分担信令点名称”为“DSP1”，“对应的优先级”为“1”：

```
ADD SCCPLDSHGRP: LSDGNM="LoadShareDspGrp", MDNM="MainDSP", LSDP1="DSP1", PLSDP1=1;
```

2、增加SCCP负荷分担信令点组，“负荷分担信令点组名称”为“LoadShareDspGrp”，“主目的信令点名称”为“MainDSP”，“1号负荷分担信令点名称”为“DSP1”，“对应的优先级”为“1”，“2号负荷分担信令点名称”为“DSP2”，“对应的优先级”为“3”：

```
ADD SCCPLDSHGRP: LSDGNM="LoadShareDspGrp", MDNM="MainDSP", LSDP1="DSP1", PLSDP1=1, LSDP2="DSP2", PLSDP2=3;
```
