# 查询队列流控配置信息(LST QFCCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询网元上配置的队列流控全局数据，使操作员了解当前流控策略，更好的指导操作员根据实际情况进行网络优化和扩容，提高系统处理业务请求的能力，保证高峰期系统正常进行业务。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                     |
|:-------|:-------|:-------------------------|
| MT     | 模块类型   | 用于指示系统按照哪种模块来查询队列流量控制数据。 |

## 使用实例

查询CCU类型模块队列流控的全局数据。其中“模块类型”为“CCU(CCU)”，执行命令如下：

```
LST QFCCFG: MT=CCU;
```

```
%%LST QFCCFG: MT=CCU;%%
RETCODE = 0  操作成功

查询结果如下
------------
        模块类型  =  CCU
    队列流控策略  =  关闭
  最小首消息门限  =  7000
最大中间消息门限  =  7500
(结果个数 = 1)

---    END
```
