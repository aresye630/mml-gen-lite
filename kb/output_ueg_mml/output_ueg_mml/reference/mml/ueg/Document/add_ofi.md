# 增加本局信令点 (ADD OFI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条本局信令点编码记录，支持本局多信令点配置。

## 注意事项

- 当本局需要开通多信令点编码功能时，本局的扩展信令点编码（本局信令点索引从1开始编号）由操作员通过**ADD OFI**命令增加，本局的缺省信令点编码（其本局信令点索引固定为0）通过**SET OFI** 命令配置。
- 开通多信令点编码功能时，多个信令点需要归属于同一个网络平面（国际主用网/国际备用网/国内主用网/国内备用网）。如果UDM和多个平面同时对接，则UDM设备仅支持主备组网，即仅一个UDM FE设备处理信令消息，且需要将“REDUNDANCYCHECK(是否支持容灾可用性自动探测功能)”软参设置为“0”。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
|:-------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IDX    | 本局信令点索引 | 用于在本局内部标识一个本局信令点编码。 取值范围：1～15 默认值：无。 说明：必选参数。                                                                                                                                                                                                                                                                                                                                                                                                        |
| OFN    | 本局名称    | 用于为本局的一个信令点指定一个本局名称。当本局配置多信令点编码时，可用该参数描述对应信令点的相关信息。 取值范围：长度不超过32的字符串 默认值：无。 说明：对于本局不同的信令点本局名称可重复。                                                                                                                                                                                                                                                                                                                                                    |
| INTC   | 国际主用网编码 | 用于定义本局在国际主用网中的信令点编码，其按照系统设置可以以十六进制、十进制整数格式指定。 取值范围： 当信令点进制类型为十六进制时，信令点编码允许以下方式输入：十六进制字符串（如：1AB2AB或H'1AB2AB）。中间不允许有空格和其他非十六进制字符。范围是0x0～0xFFFFFF（24位信令点编码）或0x0～0x003FFF（14位信令点编码）。 当信令点进制类型为十进制整数格式时，信令点编码允许以下方式输入：十进制整数字符串（如：1749675）。中间不允许有空格、其他非十进制字符。范围是0～16777215（24位信令点编码）或0～16383（14位信令点编码）。 默认值：无。 说明：与信令网编码相关的参数“国际主用网有效”、“国际备用网有效”、“国内主用网有效”、“国内备用网有效”、“国际主用网结构”、“国际备用网结构”、“国内主用网结构”、“国内备用网结构”由操作员通过SET OFI 命令设置。以上相关参数对信令网编码的影响请参见 SET OFI。 |
| INTBC  | 国际备用网编码 | 用于定义本局在国际备用网中的信令点编码，其按照系统设置可以以十六进制、十进制整数格式指定。 取值范围： 当信令点进制类型为十六进制时，信令点编码允许以下方式输入：十六进制字符串（如：1AB2AB或H'1AB2AB）。中间不允许有空格和其他非十六进制字符。范围是0x0～0xFFFFFF（24位信令点编码）或0x0～0x003FFF（14位信令点编码）。 当信令点进制类型为十进制整数格式时，信令点编码允许以下方式输入：十进制整数字符串（如：1749675）。中间不允许有空格、其他非十进制字符。范围是0～16777215（24位信令点编码）或0～16383（14位信令点编码）。 默认值：无。 说明：详细说明请参见“国际主用网编码”的参数说明。                                                                                                                   |
| NATC   | 国内主用网编码 | 用于定义本局在国内主用网中的信令点编码，其按照系统设置可以以十六进制、十进制整数格式指定。 取值范围： 当信令点进制类型为十六进制时，信令点编码允许以下方式输入：十六进制字符串（如：1AB2AB或H'1AB2AB）。中间不允许有空格和其他非十六进制字符。范围是0x0～0xFFFFFF（24位信令点编码）或0x0～0x003FFF（14位信令点编码）。 当信令点进制类型为十进制整数格式时，信令点编码允许以下方式输入：十进制整数字符串（如：1749675）。中间不允许有空格、其他非十进制字符。范围是0～16777215（24位信令点编码）或0～16383（14位信令点编码）。 默认值：无。 说明：详细说明请参见“国际主用网编码”的参数说明。                                                                                                                   |
| NATBC  | 国内备用网编码 | 用于定义本局在国内备用网中的信令点编码，其按照系统设置可以以十六进制、十进制整数格式指定。 取值范围： 当信令点进制类型为十六进制时，信令点编码允许以下方式输入：十六进制字符串（如：1AB2AB或H'1AB2AB）。中间不允许有空格和其他非十六进制字符。范围是0x0～0xFFFFFF（24位信令点编码）或0x0～0x003FFF（14位信令点编码）。 当信令点进制类型为十进制整数格式时，信令点编码允许以下方式输入：十进制整数字符串（如：1749675）。中间不允许有空格、其他非十进制字符。范围是0～16777215（24位信令点编码）或0～16383（14位信令点编码）。 默认值：无。 说明：详细说明请参见“国际主用网编码”的参数说明。                                                                                                                   |

## 使用实例

增加本局信令点编码，“新增信令点编码索引值”为“1”，其“国内主用网信令点编码”为“0x2A1321”，其“国际主用网信令点编码”、“国际备用网信令点编码”和“国内备用网信令点编码”都设置为“0x000000”:

```
ADD OFI: IDX=1, INTC="000000", INTBC="000000", NATC="2A1321", NATBC="000000";
```
