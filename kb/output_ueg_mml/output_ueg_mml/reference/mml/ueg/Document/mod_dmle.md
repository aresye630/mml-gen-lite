# 修改Diameter本端实体(MOD DMLE)

## 命令功能

**须知** 

本命令属于高危命令，执行该命令可能导致ESN变动，ESN变动后需要在60天内重新申请并加载License文件。执行不当可能导致Diameter本端实体与对端实体间的业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一条Diameter本端实体数据记录的某些参数进行修改或调整。在该命令中，系统通过“实体名称”参数来唯一标识一条Diameter本端实体数据记录。

## 注意事项

修改Diameter本端实体的主机名和域名后，通过以下任意一种操作使修改参数生效：

- 重启HSF类型的模块。
- 通过**DEA DMPE**命令去激活Diameter对端实体，再通过**ACT DMPE**命令激活Diameter对端实体。
- UDM产品的ESN信息与License有关，当局点的ESN信息中存在主机名时，若执行该命令修改一条Diameter本端实体的数据记录，使本局Diameter本端实体表中Index值最小的主机名发生改变，则会导致ESN变动，需要重新申请License文件，请谨慎操作。
- 如果修改的Diameter本端实体中的主机名，已经在HLRSNOFI命令中配置使用，修改Diameter本端实体将导致HLRSNOFI多主机名业务处理异常。请在华为技术支持指导下执行该操作。
- 如果修改的Diameter本端实体名称已经在DMRTS命令中配置使用，修改Diameter本端实体时系统会报错。如确认修改该Diameter本端实体记录，请先执行**MOD DMRTS**命令删除该Diameter本端实体与Diameter路由组的关联关系，再执行本命令修改该Diameter本端实体记录。

GBA场景下，当BSF和AP合一部署场景：

- 系统允许**MOD DMPE**配置的“Diameter对端实体类型”为“AP(AP)”的对端实体的主机名和**MOD DMLE**配置的“本端设备类型”为“AP(AP)”的本端实体的主机名相同。
- 系统允许**MOD DMPE**配置的“Diameter对端实体类型”为“BSF(BSF)”的对端实体的主机名和**MOD DMLE**配置的“本端设备类型”为“BSF(BSF)”的本端实体的主机名相同。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
|:---------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| EN       | 实体名称   | 标识一条Diameter本端实体数据记录的关键字段，用于指定需要对哪一条Diameter本端实体数据记录的参数进行修改或调整，操作员可以使用LST DMLE命令查询获得。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| NEN      | 新实体名称  | 用于标识一个Diameter本端实体的新名称。 取值范围：长度不超过127的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| LOCTYPE  | 本端设备类型 | 用于标识Diameter本端设备的网元类型。 取值范围：IMS-HSS(IMS-HSS)：UDM产品作为IMS-HSS部署在IMS网络，其对端网元类型可为AS、S-CSCF、I-CSCF、GGSN、SAE、BSF、IMS-HSS和OTHER。IMS-SLF(IMS-SLF)：UDM产品作为IMS-SLF部署在IMS网络，其对端网元类型可为AS、S-CSCF、I-CSCF、BSF和OTHER。SAE-HSS(SAE-HSS)：UDM产品作为SAE-HSS部署在EPS网络，其对端网元类型可为AS、SAE、IMS-HSS和OTHER。UEIR(UEIR)：UDM产品作为EIR部署在GSM/UMTS/EPS网络，其对端网元类型可为OTHER。LRF(LRF)：UDM产品作为LRF部署在IMS网络，其对端网元类型可为IMS-HSS、E-CSCF和OTHER。IWF(IWF)：UDM产品作为UTA部署在4G/5G共存网络，模拟MME/I-CSCF与HSS对接。IWF-EIR(IWF-EIR)：UDM产品模拟MME与EIR对接。AAA(AAA)：UDM产品作为AAA部署在EPS网络，其对端网元类型可为P-GW、ePDG、HSGW、Non-3GPP接入网关、SAE和OTHER。BSF(BSF)：UDM产品实现GBA认证功能时，作为BSF功能实体部署在IMS网络。AP(AP)：UDM产品实现GBA认证功能时，作为AP功能实体部署在IMS网络。 默认值：无。 |
| DN       | 域名     | 用于标识Diameter本端设备所属域的域名。 取值范围：1～127位由数字、字母、“.”和“-”组成的字符串。 默认值：无。 该参数的配置原则：该参数可以配置为绝对域名或相对域名。绝对域名的长度不超过127，相对域名的长度不超过126。后面带有“.”的就是绝对域名，其他都是相对域名，例如：“huawei.com.”就是绝对域名，“huawei.com”就是相对域名。所有字符只能是数字（0～9）、字母（a～z或A～Z）、“.”或“-”。首字符必须是数字（0～9）或字母（a～z或A～Z），最后一个字符必须是数字（0-9）、字母（a～z或A～Z）或“.”。 “.”不能连续出现且“.”和“-”不能相邻，“..”、“.-”或“-.”为错误配置。 最后一个“.”后面的第一个字符必须为字母（a～z或A～Z）。例如“as.huawei.com”中的最后一个“.”后面的字符串“com”的第一个字符必须为字母。                                                                                                                                                                                                                                    |
| HN       | 主机名    | 用于标识Diameter本端设备在所属域中的网络主机名。 取值范围：1～127位由数字、字母、“.”和“-”组成的字符串。 默认值：无。 该参数的配置原则：所有字符只能是数字（0～9）、字母（a～z或A～Z）、“.”或“-”。 首字符必须是数字（0～9）或字母（a～z或A～Z），最后一个字符必须是数字（0-9）、字母（a～z或A～Z）或“.”。 “.”不能连续出现且“.”和“-”不能相邻，“..”、“.-”或“-.”为错误配置。 最后一个“.”后面的第一个字符必须为字母（a～z或A～Z）。例如“as.huawei.com”中的最后一个“.”后面的字符串“com”的第一个字符必须为字母。                                                                                                                                                                                                                                                                                                                                              |
| DEFLOCAL | 默认本端实体 | 用于标识待修改的Diameter本端实体是否为默认本端实体。 取值范围：NO(否)：使用Diameter消息中携带的Origin-Host对应的本端实体和对端实体之间的链路发送消息。YES(是)：当Diameter消息中携带的Origin-Host对应的本端实体和对端实体之间无可用链路时，则使用该默认本端实体和对端实体之间的链路发送消息。 默认值：NO(否)。                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |

## 使用实例

在增加Diameter本端实体时输入的“实体名称”、“域名”和“主机名”参数有误。运行以下命令，为“实体名称”为“HSS”的Diameter本端实体设置“新实体名称”为“NEWHSS”、“域名”为“domainname.com”、“主机名”为“hss.domainname.com”。

```
MOD DMLE: EN="HSS", NEN="NEWHSS", DN="domainname.com", HN="hss.domainname.com";
```
