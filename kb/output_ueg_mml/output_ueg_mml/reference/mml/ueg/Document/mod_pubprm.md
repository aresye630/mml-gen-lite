## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成系统性能受到严重影响，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于对配置数据库中的公共参数数据记录的某些参数进行修改或调整。在该命令中，系统通过“参数”参数来唯一标识一条公共参数数据记录。

## 注意事项

- 在缺省的情况下，系统在初始化的时候已经预置了公共参数数据表中的部分数据，这些数据的主要内容可以参见“参数”参数中的各选项。
- 修改公共参数后，必须进行格式转换，然后复位所有Pod，并加载数据至前台以保持一致。
- 此命令的修改可能严重影响系统的运行情况，修改时请联系华为技术工程师进行操作。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                |
|:-------|:-------|:------------------------------------------------------------------------------------|
| ID     | 参数     | 标识一条公共参数数据记录的关键字段（其取值不能被修改），用于指定需要对哪一条公共参数数据记录的参数标识进行修改或调整，操作员可以使用LST PUBPRM命令查询获得。 |
| VAL    | 值      | 用于标识需要修改的公共参数的参数值，该参数值的取值范围由公共参数名称确定。各公共参数取值及取值具体含义请参见产品手册的“UDM MAP软件参数 > 公共参数”。    |

## 使用实例

修改公共参数信息，“参数”ID为“每个对话的平均TCAP组件数”，“值”为“1”：

```
MOD PUBPRM: ID=P0, VAL=1;
```
