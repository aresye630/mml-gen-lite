# 增加远端DSG(ADD RDSG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于增加远端DSG。远端DSG用于和本Location的DSG进行通信。远端DSG模块是相对的，具体如下：

- 对于主用局FE，它的远端DSG模块指主用局USCDB、容灾局USCDB对外的DSG模块。
- 对于主用局USCDB，它的远端DSG模块指主用局FE、容灾局FE、容灾局USCDB的DSG模块。
- 对于容灾局FE，它的远端DSG模块指容灾局USCDB、主用局USCDB对外的DSG模块。
- 对于容灾局USCDB，它的远端DSG模块指容灾局FE、主用局FE、主用局USCDB对外的DSG模块。

## 注意事项

- 首先通过**ADD RLOCATION**命令配置远端Location后，才能通过该命令配置远端DSG。
- 远端Location中需要存在DSG模块。
- 需要配置远端Location中所有存在的DSG模块。

## 参数说明

| 参数标识    | 参数名称         | 参数说明                                                                                                                                                                                                                                             |
|:--------|:-------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RLOCID  | 远端Location标识 | 远端Location的标识，远端Location和远端网元一一对应。远端Location是相对的，具体如下：对于主用局FE，它的远端Location指主用局USCDB、容灾局USCDB。对于主用局USCDB，它的远端Location指主用局FE、容灾局FE、容灾局USCDB。对于容灾局FE，它的远端Location指容灾局USCDB、主用局USCDB。对于容灾局USCDB，它的远端Location指容灾局FE、主用局FE、主用局USCDB。 取值范围：1-512 默认值：无。 |
| RDSGMID | 远端DSG模块号     | 远端DSG模块号。 取值范围：1-2047 默认值：无。                                                                                                                                                                                                                     |

## 使用实例

增加远端DSG。远端Location标识为3，远端DSG模块号为3。

ADD RDSG: RLOCID=3, RDSGMID=3;
