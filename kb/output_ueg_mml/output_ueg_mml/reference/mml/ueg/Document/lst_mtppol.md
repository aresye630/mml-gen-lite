# 查询MTP屏蔽策略(LST MTPPOL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在配置数据库中查询MTP屏蔽策略配置信息：若需要查询某条MTP屏蔽策略配置的详细信息，请输入“MTP屏蔽策略名称”参数。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                                     |
|:-------|:----------|:-----------------------------------------------------------------------------------------|
| MTPNM  | MTP屏蔽策略名称 | 用于指示系统需要按照哪个MTP屏蔽策略名称来查询MTP屏蔽策略数据；若不输入，则表示所有的MTP屏蔽策略名称。 取值范围：长度不超过32的字符串 默认值：无。 说明：可选参数。 |

## 使用实例

1、查询所有屏蔽策略记录：

```
LST MTPPOL:;
```

返回结果如下：

```
%%LST MTPPOL:;%%
RETCODE = 0  操作成功

MTP屏蔽策略表
-------------
 MTP屏蔽策略名称  目的信令点编码  源信令点编码  链路集名称  网络指示    业务指示语  流量阈值  流量单位  MTP屏蔽策略索引

 MTPPOL_1         H'AA0033        NULL          STP_LKS     国内主用网  SCCP        0         每小时    1              
 MTPPOL           NULL            H'BB0033      NULL        国内主用网  SCCP        100       每小时    0              
(结果个数 = 2)

---    END
```

2、查询MTP屏蔽策略，“MTP屏蔽策略名称”为“MTPPOL”:

```
LST MTPPOL: MTPNM="MTPPOL";
```

返回结果如下：

```

MTP屏蔽策略表
-------------

       流量阈值  =  0
       流量单位  =  每小时
```
