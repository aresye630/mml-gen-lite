# 查询流控状态(DSP FLOWCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于请求系统显示指定模块的流控状态。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                               |
|:-------|:-------|:-------------------------------------------------------------------|
| MT     | 模块类型   | 用于指定流控模块的类型。 取值范围： “BSG(BSG)”“CCU(CCU)”“HSF(HSF)”“ACF(ACF)” 默认值：无。 |
| MID    | 模块号    | 用于指定要查询的模块号。 取值范围：1～1023。 默认值：无。                                   |

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**MOD FLOWCTRL**命令的参数说明。这里列出的是未包含在**MOD FLOWCTRL**命令中的参数。

| 输出项名称             | 输出结果解释                                       |
|:------------------|:---------------------------------------------|
| 模块流控状态            | 模块的流控状态，如启控，解控等。                             |
| 模块流控丢弃率           | 模块当前周期丢弃消息数和总消息数的比例。                         |
| 模块当前周期收到的消息总数     | 模块当前周期下接受收到的所有消息的总数。                         |
| 当前消息的延迟时间         | 模块当前周期消息队列所处理消息延迟的时间。 单位：ms                  |
| 模块当前周期CPU占用率      | 模块和虚机（裸机Pod）中当前周期使用CPU比例的最大值。                |
| 当前的MAP自动机的个数      | 当前周期MAP自动机个数。                                |
| 当前的Diameter自动机的个数 | 当前的Diameter自动机的个数。                           |
| 目的信令点索引           | SCCP下行流控起控的目的信令点索引。                          |
| 目的信令点名称           | SCCP下行流控起控的目的信令点名称。                          |
| SCCP系统下行处理能力      | SCCP系统下行处理能力（在每个“SCCP业务统计周期”里最大可以处理的下行消息个数）。 |
| SCCP下行流控丢弃率       | 当前周期SCCP下行流控丢弃消息占用SCCP收到的下行消息总数百分比(%)。       |
| SCCP当前周期收到的下行消息总数 | 当前周期SCCP收到的下行消息总数。                           |
| DRU当前起控比率         | 当前周期启动流控的DRU模块占所有DRU模块的比例。                   |
| DSU当前起控比率         | 当前周期启动流控的DSU模块占所有DSU模块的比例。                   |
| DSG当前起控比率         | 当前周期启动流控的DSG模块占所有DSG模块的比例。                   |
| FE DSG当前起控比率      | 当前周期启动流控的FE DBS模块的消息丢弃比例。                    |
