## 命令功能

**须知** 

本命令属于高危命令，执行不当会导致用户鉴权失败、无法正常接入网络。因此执行该命令前，请仔细检查配置的正确性，确认无误方可执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用于在配置数据库中增加一个业务控制功能配置数据记录，使UDM实现对局向或IMSI号段信息管理功能。

在网络拥塞场景下，为避免用户终端尝试频繁附着网络而不断发送请求消息到UDM，导致UDM长时间故障，UDM从局向或IMSI用户号段的维度进行业务控制丢弃部分请求业务，拒绝用户终端频繁附着网络请求，降低了业务处理量，从而保证整个网络系统能正常运行。

当参数“业务控制的用户范围”的值设置为“ASSIGN(指定用户)”或“REVERSE(指定号码以外)”时，参数“IMSI号段组名称”的索引关系如图1所示。

## 注意事项

- 当存在多条业务控制功能配置数据记录时，消息满足任何一条规则，则对消息进行业务控制。
- 系统中增加的业务控制功能配置的总记录数不能超过100条。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识     | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                      |
|:---------|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CFGNAME  | 业务控制功能配置名称 | 用于标识一个待增加的业务控制功能的名称。 取值范围：长度不超过32的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。                                                                                                                                                                                                                     |
| DESTTYPE | 业务控制方式     | 用于标识从局向维度进行业务控制的方式。 取值范围：ALL(不区分局向)：对所有对端进行业务控制。CS(CS局向)：与对端MSC间通过SAI消息进行业务控制。PS(PS局向)：与对端SGSN间通过SAI消息进行业务控制。S6a/S6d(S6a/S6d局向)：与对端MME/S4-SGSN间通过AIR/AIA消息进行业务控制。SWx(SWx局向)：与对端AAA间通过MAR/MAA消息进行业务控制。Cx/Dx(Cx/Dx局向)：与对端S-CSCF间通过MAR/MAA消息进行业务控制。Zh(Zh局向)：与对端BSF间通过MAR/MAA消息进行业务控制。 默认值：无。 |
| ADDR     | VLR/SGSN地址 | 仅当本命令中的“业务控制方式”参数为“CS局向”或“PS局向”时该参数有效。用于标识一个待增加的VLR/SGSN地址。 取值范围：长度不超过20位的数字和A～E字母组成的BCD码。 默认值：无。                                                                                                                                                                                         |
| HN       | 主机名        | 仅当本命令中的“业务控制方式”参数为“S6a/S6d局向”、“SWx局向”、“Cx/Dx局向”或“Zh局向”时该参数有效。用于标识一个待增加的主机名。 取值范围：1～127位的数字、字母、“_”、“.”和“@”组成的字符串。 默认值：无。                                                                                                                                                                   |
| USERTYPE | 业务控制的用户范围  | 用于标识从IMSI号段维度进行业务控制的用户范围。 取值范围：ALL(不区分用户)：对所有用户进行业务控制。ASSIGN(指定用户)：对参数“IMSI号段组名称”范围内的用户进行业务控制。REVERSE(指定号码以外)：对除参数“IMSI号段组名称”之外的用户进行业务控制。 默认值：无。                                                                                                                                          |
| GRPNAME  | IMSI号段组名称  | 仅当本命令中的“业务控制的用户范围”参数为“ASSIGN(指定用户)”或“REVERSE(指定号码以外)”时该参数有效。用于标识一个IMSI号段组的名称。该参数必须先由ADD SCFIMSIGRP命令定义，然后才能在此处引用。 取值范围：长度不超过32的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。                                                                                                                        |

## 使用实例

配置一条业务控制功能配置记录，需要进行如下配置：

1. 执行**ADD SCFIMSIGRP**命令，增加IMSI号段组记录。“IMSI号段组名称”为“123”。

   ```
   ADD SCFIMSIGRP: GRPNAME="123";
   ```
2. 执行**ADD SCFIMSIPEFIX**命令，增加IMSI号段记录。“IMSI号段组名称”为“123”，“IMSI号段”为“1831234567”。

   ```
   ADD SCFIMSIPEFIX: GRPNAME="123", IMSIPEFIX="1831234567";
   ```
3. 根据图1中的参数索引关系，确认IMSI号段组及IMSI号段信息已配置完成后，设置该命令的参数“业务控制功能配置名称”为“123”、“业务控制方式”为“S6a/S6d(S6a/S6d局向)”、“主机名”为“123”、“业务控制的用户范围”为“ASSIGN(指定用户)”、“IMSI号段组名称”为“123”：

   ```
   ADD SCFCFG: CFGNAME="123", DESTTYPE=S6a/S6d, HN="123", USERTYPE=ASSIGN, GRPNAME="123";
   ```
