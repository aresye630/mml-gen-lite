# 增加NAFID群组数据(ADD NAFGRPDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在配置数据库中为网络应用功能组增加NAF列表信息，为下一步配置网络应用功能AP信息和USS列表信息做准备。

当UIM采用GBA架构对用户进行认证时，通过网络应用功能组和其关联的网络应用功能组信息数据可以从HSS获取用户的GUSS签约信息，完成GBA架构下对用户的认证。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                              |
|:-------|:------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NAFGRP | NAF GROUP编号 | 用于指定待增加NAF列表信息的网络应用功能组的标识。该参数必须先由ADD NAFGROUP命令定义，然后才能在此处引用。 取值范围：1～65535。 默认值：无。 注意：该参数为必选参数。                                                                                                                                                                                                    |
| FQDN   | FQDN        | 用于指定网络应用功能组的全量域名FQDN（Fully Qualified Domain Name），在IMS域中唯一标识一个AP的FQDN。当UIM采用GBA认证时“FQDN”与“Ua接口安全协议标识”（遵循3GPP标准协议，以保证用户通过Ua接口进行业务互操作的安全性）共同组成“NAFID”（“NAFID”用于标识合法的网络应用功能组）。同一“NAF GROUP编号”下的“FQDN”不能重复。 需要指出的是，该参数不区分大小写，在执行LST NAFGRPDATA命令查询出的报文中为全小写形式。 取值范围：长度不超过127的字符串。 默认值：无。 注意：该参数为必选参数。 |

## 使用实例

增加NAFID群组数据，携带以下参数：

- “NAF GROUP编号”为“1”
- “FQDN”为“FQDN”

执行命令如下：

```
ADD NAFGRPDATA: NAFGRP=1, FQDN="FQDN";
```
