# 删除MTP链路集(RMV N7LKS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于从配置数据库中删除一条MTP链路集数据记录。

## 注意事项

- 如果命令执行成功且删除的数据为已有性能统计任务中登记的对象实例，则该对象实例后续上报的指标值为0。命令涉及的测量单元有：MTP信令链路集测量，命令涉及的测量对象有：MTP信令链路集。
- 在正常情况下，删除一条MTP链路集信息数据记录的操作步骤为：**RMV N7RT**->**RMV N7LNK**->**RMV N7LKS**。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                              |
|:-------|:-------|:------------------------------------------------------------------|
| LSNM   | 链路集名称  | 标识一条MTP链路集数据记录的关键字段，用于指定需要删除哪一条MTP链路集数据记录，操作员可以使用LST N7LKS命令查询获得。 |

## 使用实例

删除MTP链路集，“链路集名称”为“N7LKS”：

```
RMV N7LKS: LSNM="N7LKS";
```
