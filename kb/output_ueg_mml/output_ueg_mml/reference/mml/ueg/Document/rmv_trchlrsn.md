# 删除跟踪HLRSN(RMV TRCHLRSN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除一条跟踪HLRSN记录。

## 注意事项

如果给指定用户添加了跟踪HLRSN记录，则该用户在创建用户消息跟踪时，只能对指定的HLR号段内的用户号码做跟踪。

如果用户没有添加任何跟踪HLRSN，则该用户在创建用户消息跟踪时，不受号段限制。

查看用户是否设定有跟踪HLRSN，请使用**LST TRCHLRSN**命令查询

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                         |
|:-------|:-------|:---------------------------------------------------------------------------------------------|
| USER   | 用户名称   | 标识跟踪HLRSN记录的关键字段之一，用于指定要删除的跟踪HLRSN对应的用户名称。可使用LST TRCHLRSN命令查询获用户名称。 取值说明：长度不超过32个英文字符 默认值：无。 |
| HLRSN  | HLR序列号 | 标识跟踪HLRSN记录的关键字段之一，用于指定要删除的跟踪HLRSN对应的HLR序列号。可使用LST TRCHLRSN命令查询获取HLR序列号。 取值范围：1～255 默认值：无。   |

## 使用实例

删除一条跟踪HLRSN记录。用户名称为“admin”，对应的HLR序列号为12。

`RMV TRCHLRSN: USER="admin", HLRSN=12;`
