# 设置NP配置对象参数(SET NPPARA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成系统运行异常从而影响用户业务运行，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置NP配置对象参数。

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
|:----------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PARANAME  | 携转软参名称 | 用于指定NP配置对象的软参名称。 取值范围： “UPLTRYTIME(位置更新重试次数)”：位置更新失败后重试次数。 “UPLINTERVAL(位置更新时间间隔)”：位置更新失败再次位置更新的时间间隔。 “CNLANDUPLINTERVAL(Cancel后的位置更新间隔)”：NPMSC收到Cancel消息后发位置更新时间间隔。 “UPLNUM(每秒位置更新请求数量)”：NPMSC收到Reset消息后每秒发起模拟位置更新请求数量。 “SMSFAILTRYTIME(短消息转发失败重试次数)”：短消息转发失败重试次数。 “ENQUIRE_LINK_TIMER(SMPP查询消息的时间间隔)”：SMPP查询消息的时间间隔。 “INACTIVITY_TIMER(SMPPSession有效期)”：NPMSC与SMG之间建立的SMPP Session有效期。 “RESPONSE_TIMER(SMPP响应消息超时时长)”：SMPP响应消息超时时长。 “SMNUM_PERSEC(每秒处理短消息个数)”：NPMSC每秒处理的短消息个数。 “PERIODICUPLTIMER(周期位置更新周期)”：周期性位置更新的周期。 “OVERTIME_SUBMIT(超时短信回执处理方式)”：NPMSC对于超时后的短信回执处理方式。 “MESSAGEID_HEX(MESSAGEID采用十六进制字符串)”：消息交互过程中MESSAGEID是否采用十六进制字符串。当NPMSC与SMG对接时使用SMPP3.4协议该参数生效。 “SMPPLINKNUM(同一个PAU模块同一个短信互通网关用户名的最大链路限制数)”：同一个PAU模块同一个短信互通网关用户名可以建立的SMPP链路数。 “SMPPLINK_MANAGER_ENHANCED(增强SMPP链路管理方式)”：增强SMPP链路管理方式。 默认值：无。 说明：必选参数。 |
| PARAVALUE | 软参值    | 此参数用于指定携转软参的参数值。该参数值的取值范围由携转软参名称确定。 取值范围： UPLTRYTIME: 0～3，单位：次，默认值：1。 UPLINTERVAL: 0～65535，单位：秒，默认值：20秒。 CNLANDUPLINTERVAL: 0～65535，单位：秒，默认值：5秒。 UPLNUM: 0～500，默认值：100 SMSFAILTRYTIME: 0～5，默认值：2。 ENQUIRE_LINK_TIMER: 1～3，单位：秒，默认值：1秒 INACTIVITY_TIMER: 10～300，单位：秒，默认值：30秒。 RESPONSE_TIMER: 1～90，单位：秒，默认值：25秒。 SMNUM_PERSEC: 0～10000，0表示不限制，默认值：0。 PERIODICUPLTIMER: 1～24，单位：小时，默认值：12小时 OVERTIME_SUBMIT: 0：Discard，丢弃不处理。 1：Respond，直接回响应。 默认值：0 MESSAGEID_HEX: 0：MESSAGEID采用十进制字符串。 1：MESSAGEID采用十六进制字符串。当NPMSC接收到SMG发送的Deliver_SM_Resp消息，NPMSC会检查消息中携带的MESSAGEID是否为十六进制字符串，如果不是则拒绝该消息。当NPMSC接收到SMG发送的Submit_SM消息，NPMSC将消息中携带的十进制ID字符串转化为十六进制字符串。 默认值：0 SMPPLINKNUM: 2～32，默认值：2。 SMPPLINK_MANAGER_ENHANCED: 0：不支持增强链路管理，NPMSC只能配置一对SMPP协议类型的主备的PAU模块。 1：支持增强链路管理，NPMSC可以配置多个SMPP协议类型的PAU模块。 默认值：0 说明：必选参数。                     |

## 使用实例

设置NP配置对象参数。携转软参名称为“SMSFAILTRYTIME”，软参值为“3”。

SET NPPARA: PARANAME=SMSFAILTRYTIME, PARAVALUE=3;
