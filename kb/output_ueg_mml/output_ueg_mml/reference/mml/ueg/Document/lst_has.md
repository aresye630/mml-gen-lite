# 查询外部AS设备的配置信息(LST HAS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询AS的配置信息：

- 若需要查询全部AS数据记录的信息，请不要输入任何参数。
- 若需要查询某条AS数据记录的详细信息，请输入“AS名称”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                          |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HSSN   | HSS名称  | 用于指示系统需要按照哪个“HSS名称”来查询AS数据记录；若不输入，则表示所有的HSS实体名称。 取值范围：长度不超过127位的字符串 默认值：无。                                                                                                                                                                                                                                                                                                                    |
| ASN    | AS名称   | 用于指示系统需要按照哪个“AS名称”来查询AS数据记录；若不输入，则表示所有的“AS名称”。 取值范围：长度不超过127位的字符串 默认值：无。                                                                                                                                                                                                                                                                                                                      |
| HN     | 主机名    | 用于指示系统需要按照哪个“主机名”来查询AS数据记录；若不输入，则表示所有的“主机名”。 取值范围：长度不超过127位的字符串 默认值：无。                                                                                                                                                                                                                                                                                                                        |
| DN     | 域名     | 用于指示系统需要按照哪个“域名”来查询AS数据记录；若不输入，则表示所有的“域名”。 取值范围：长度不超过127位的字符串 默认值：无。                                                                                                                                                                                                                                                                                                                          |
| LNKMOD | 链路选择模式 | 用于指示系统需要按照哪个“链路选择模式”来查询AS数据记录；若不输入，则表示所有的“链路选择模式”。 取值范围： SESSIONIDBASED(基于会话ID)：同一个会话的所有信令消息都在同一条链路上传输。多个会话的消息按照轮选的方式在多条链路负荷分担。 POLLING(轮询方式)：当配置多条链路，信令消息在每条链路上负荷分担。 AORS(主备方式)：在主备链路选择方式下，如果主链路故障，则将某条备用链路升为主链路。默认第0条链路为主链路，当第0条链路不可用时，会自动选择其他可用链路。 ACTIVE(激活方式)：根据链路的激活状态，从第0条开始选择第一条激活的链路，将信令消息发往该链路。 ACTIVEWITHPRI(基于优先级的激活方式)：基于优先级的激活方式。 POLLINGWITHPRI(基于优先级的轮询方式)：基于优先级的轮询方式。 默认值：无。 |
