## 命令功能

**须知** 

提交事务需要大约10分钟完成，请务必在华为技术支持人员的指导下操作。

本命令用于确认提交事务。用户使用本命令提交事务，该事务中的配置命令进行的修改此时生效，这时会自动进入试运行模式，主机会使用被本事务修改过了的配置数据试运行以验证配置的正确性，试运行阶段本事务中所做的修改仍然可以使用**RBK TST**命令进行回退。

本命令的使用场景为：开始一个事务后，进行一系列的配置命令，若要观察这些配置命令执行的结果时，可以用本命令对该事务进行确认，使事务进入试运行模式。

## 注意事项

- 确认提交事务后，在事务模式下的所有操作都将设定到主机侧（进行格式化、和联机设定操作）。
- 在进入事务模式后，如果执行完配置命令后24小时内不提交事务，系统将视为超时，用户在进入事务模式后的所有操作将进行回滚，恢复到进入事务模式之前的状态。系统在超时前2小时将会上报告警。
- 确认提交事务后，系统自动进入试运行状态。

## 参数说明

无。

## 使用实例

确认提交事务：

```
CMT TRAN:;
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，请联系华为技术支持处理。
