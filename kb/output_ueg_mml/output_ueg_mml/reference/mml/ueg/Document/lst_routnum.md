# 查询它网RN数据(LST ROUTNUM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询短消息RN（Route Number）路由数据，查询的结果显示路由码和对应的网络名称。

- 若需要查询全部它网RN路由信息，不输入任何参数。
- 若需要查询某个它网RN路由信息，请输入“路由码”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                         |
|:-------|:-------|:---------------------------------------------|
| RN     | 路由码    | 用于指示系统按照哪个路由码来查询它网RN路由数据信息；若不输入，则表示所有的路由码信息。 |

## 使用实例

1. 查询所有的它网RN路由数据信息。命令如下：

   ```
   LST ROUTNUM:;
   ```

   ```
   %%LST ROUTNUM:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    网络名称  路由码

    1         1113  
    2         2     
   (结果个数 = 2)

   ---    END
   ```
2. 查询“路由码”为“1113”的它网RN路由数据信息。命令如下：

   ```
   LST ROUTNUM: RN="1113";
   ```

   ```
   %%LST ROUTNUM: RN="1113";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   网络名称  =  1
     路由码  =  1113
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD ROUTNUM**命令的参数说明。
