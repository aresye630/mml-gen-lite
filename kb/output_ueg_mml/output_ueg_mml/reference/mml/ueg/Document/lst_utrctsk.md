# 查询用户跟踪数据 (LST UTRCTSK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询指定用户的跟踪数据。

## 注意事项

当前版本不支持此功能，执行该命令后会返回错误码：335607 暂不支持该功能。

## 参数说明

| 参数标识           | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                       |
|:---------------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NETTYPE        | 网络类型       | 用于指定用户跟踪数据的号码所在网络类型。 取值范围：E2E_2G(2G/3G)：2G/3G网络端到端跟踪。LTE-SAE(LTE-SAE)：LTE(Long Term Evolution)网络跟踪，该网络功能由SAE-HSS提供。IMS(IMS)：IMS（IP multimedia subsystem）网络跟踪，该网络功能由IMS-HSS网元提供。 默认值：无。 说明：当需要查询通过网管下发任务创建的“网络类型”为“E2E_2G(2G/3G)”或“LTE-SAE(LTE-SAE)”的用户跟踪数据时，该参数应选“IMS(IMS)”。                                                                                                                               |
| CT             | 用户号码类型     | 查询用户跟踪数据的号码类型。 取值范围： IMSI(IMSI)：根据IMSI查询MSISDN/MDN(MSISDN/MDN)；根据MSISDN/MDN查询TRACEREFERENCE(跟踪参考)：根据跟踪参考查 默认值：无。 说明：当参数“网络类型”为“E2E_2G(2G/3G)”时，此参数可见。此参数为必选参数。                                                                                                                                                                                                                                             |
| UN             | 用户号码       | 查询跟踪任务的用户的号码。据CT号码取值，UN号码为如下2种类型。 IMSI号码，E.212格式的编码，为6～15位的十进制数字。 MSISDN/MDN号码，E.164格式的编码，为1～15位的十进制数字。 默认值：无。 说明：当参数“网络类型”为“E2E_2G(2G/3G)”，CT为IMSI或MSISDN/MDN时，该参数有效。                                                                                                                                                                                                                                     |
| TRACEREFERENCE | 跟踪参考       | 用于查询指定用户跟踪任务的记录号。 取值范围：1～65535。 默认值：无。 说明：当参数“网络类型”为“E2E_2G(2G/3G)”，CT为TRACEREFERENCE时，该参数有效。                                                                                                                                                                                                                                                                                                              |
| IDTYPE         | 用户标识类型     | 用于指定删除用户跟踪数据的号码类型。 取值范围：0～2。 默认值：无。 说明：当参数“网络类型”为“LTE-SAE”时，此参数可见。当“用户标识类型”为0时，必须输入“跟踪任务标识”，且“IMSI”、“MSISDN/MDN”必须为空；当“用户标识类型”为1时，必须输入“IMSI”，且“跟踪任务标识”、“MSISDN/MDN”必须为空； 当“用户标识类型”为2时，必须输入“MSISDN/MDN”，且“跟踪任务标识”、“IMSI”必须为空。                                                                                                                                                                               |
| TRCID          | 跟踪任务标识     | 仅当本命令中的“网络类型”参数取值为“LTE-SAE(LTE-SAE)”或“IMS(IMS)”时该参数有效。且当“网络类型”参数取值为“LTE-SAE(LTE-SAE)”时，若“用户标识类型”参数取值为“0”，该参数必须设定；若“用户标识类型”参数取值为“1”或“2”，该参数必须为空。用于指定要查询的用户跟踪任务的记录号。 取值范围：0～16777215。 默认值：无。                                                                                                                                                                                                                 |
| IMSI           | IMSI       | 用于查询的用户跟踪任务对应用户的IMSI。 取值范围： E.212格式的编码，为6～15位的十进制数字。 默认值：无。 说明：当参数“网络类型”为“LTE-SAE”时，此参数可见。且当“用户标识类型”为1时，该参数必须设定；当“用户标识类型”为其他值时，该参数必须为空。                                                                                                                                                                                                                                                                    |
| MSISDN         | MSISDN/MDN | 用于查询的用户跟踪任务对应用户的MSISDN/MDN。 取值范围： E.164格式的编码，为1～15位的十进制数字。 默认值：无。 说明：当参数“网络类型”为“LTE-SAE”时，此参数可见。且当“用户标识类型”为2时，该参数必须设定；当“用户标识类型”为其他值时，该参数必须为空。                                                                                                                                                                                                                                                              |
| IMPU           | IP多媒体公共标识  | 仅当本命令中的“网络类型”参数取值为“IMS(IMS)”时该参数有效。用于指定用户标识，该标识是用户对外可寻址的标识，用于请求和其他用户通信，全局唯一。 取值范围：长度不超过127的字符串。 默认值：无。 说明：当需要查询通过网管下发任务创建的“网络类型”为“E2E_2G(2G/3G)”或“LTE-SAE(LTE-SAE)”的用户跟踪数据时，该参数为创建用户跟踪任务时对应用户的“IMSI”或“MSISDN/MDN”。如果需要根据“IMSI”查询用户跟踪数据，则该参数取值为“IMSI+0”。例如，用户“IMSI”为“460111002004”，则该参数取值“4601110020040”。如果需要根据“MSISDN”查询用户跟踪数据，则该参数取值为“MSISDN+1”。例如，用户“MSISDN/MDN+1”为“460111002006”，则该参数取值“4601110020061”。 |

## 使用实例

1. 查询用户跟踪数据，“网络类型”为“IMS(IMS)”，“IP多媒体公共标识”为“sip:lll.huawei.com”：

   ```
   LST UTRCTSK: NETTYPE=IMS, IMPU="sip:lll.huawei.com";
   ```

   ```
   %%LST UTRCTSK: NETTYPE=IMS, IMPU="sip:lll.huawei.com";%%
   RETCODE = 0  操作成功

   联合用户跟踪任务表
   ------------------
           跟踪参考  =  185
           用户标识  =  sip:lll.huawei.com
       任务有效天数  =  7
       跟踪内部模块  =  是
           日志开关  =  是
           开始时间  =  2014-11-13-19.12.32
       内部跟踪编号  =  846
   (结果个数 = 1)

   ---    END
   ```
2. 查询网管下发以IMSI创建的用户跟踪数据，“网络类型”为“IMS(IMS)”，“IP多媒体公共标识”为“460111002004”：

   ```
   LST UTRCTSK: NETTYPE=IMS, IMPU="4601110020040";
   ```

   ```
   %%LST UTRCTSK: NETTYPE=IMS, IMPU="4601110020040";%%
   RETCODE = 0  操作成功

   联合用户跟踪任务表
   ------------------
           跟踪参考  =  0
           用户标识  =  4601110020040
       任务有效天数  =  7
       跟踪内部模块  =  是
           日志开关  =  是
           开始时间  =  2014-11-13-19.11.32
       内部跟踪编号  =  843
   (结果个数 = 1)

   ---    END
   ```
3. 查询网管下发以MSISDN创建的用户跟踪数据，“网络类型”为“IMS(IMS)”，“IP多媒体公共标识”为“460111002006”：

   ```
   LST UTRCTSK: NETTYPE=IMS, IMPU="4601110020061";
   ```

   ```
   %%LST UTRCTSK: NETTYPE=IMS, IMPU="4601110020061";%%
   RETCODE = 0  操作成功

   联合用户跟踪任务表
   ------------------
           跟踪参考  =  1
           用户标识  =  4601110020061
       任务有效天数  =  7
       跟踪内部模块  =  是
           日志开关  =  是
           开始时间  =  2014-11-13-20.22.32
       内部跟踪编号  =  849
   (结果个数 = 1)

   ---    END
   ```
