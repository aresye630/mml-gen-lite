# 删除Diameter链路集(RMV DMLKS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除一条Diameter链路集数据记录。

## 注意事项

- 删除Diameter链路集前，必须先通过**RMV DMLNK**命令删除相关的Diameter链路。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                         |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------------|
| LINKSNAM | 链路集名称  | 可选必选说明：必选参数 参数含义：标识一条Diameter链路集数据记录的关键字段，用于指定删除哪一条Diameter链路集数据记录，操作员可以使用LST DMLKS命令查询获得。 取值范围：长度不超过127的字符串。 默认值：无。 配置原则：无。 |

## 使用实例

删除Diameter链路集。“链路集名称”为“HSS\_BSF”。

```
RMV DMLKS: LINKSNAM="HSS_BSF";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释                                           | 原因分析                       | 处理建议                                                                                        |
|-------:|:-----------------------------------------------|:---------------------------|:--------------------------------------------------------------------------------------------|
| 264029 | 指定的DMLKS对象不存在。请执行LST DMLKS查看已经存在的DMLKS对象。      | 输入的“链路集名称”参数不存在。           | 根据实际情况，重新输入“链路集名称”参数的取值，确保其取值已存在。已存在的链路集名称可以执行LST DMLKS命令查询。                                |
| 264031 | 指定的DMLKS已经配置了DMLNK记录。请执行RMV DMLNK删除存在的DMLNK记录。 | 输入的“链路集名称”参数对应的链路集已经配置了链路。 | 根据实际情况，重新输入“链路集名称”参数的取值，确保其对应的链路集没有配置链路。已配置链路的链路集可以执行LST DMLNK命令查询。如果需要删除链路可以执行RMV DMLNK命令。 |
