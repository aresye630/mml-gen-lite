# 查询对端HTTP实体域名(LST HTTPPEHOST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询系统中对端HTTP实体域名配置：

- 若需要查询所有对端HTTP实体域名配置，请不要输入任何参数。
- 若需要查询某条具体对端HTTP实体域名配置，请输入“对端HTTP实体标识”参数。

  **说明** 

  该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                     |
|:-------|:-----------|:-------------------------------------------------------------------------|
| PEID   | 对端HTTP实体标识 | 可选必选说明：可选参数。 参数含义：用于指定待查询的对端HTTP实体域名配置的对端实体标识。 取值范围：0～255 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询全部对端HTTP实体域名配置：

   ```
   LST HTTPPEHOST:;
   ```

   ```
   LST HTTPPEHOST:; 
   RETCODE = 0  操作成功。 
   结果如下: 
   PEID         HOST           
   1          ap.huawei.com
   2          ap1.huawei.com 
   (结果个数 = 2)
   ---    END
   ```
2. 查询“对端HTTP实体标识”为“1”的配置：

   ```
   LST HTTPPEHOST: PEID=1;
   ```

   返回结果如下：

   ```
   %LST HTTPPEHOST: PEID=1;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
           PEID  =  1
           HOST  =  ap.huawei.com
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
