# 查询外部BSF设备链路的配置信息(LST HBSFL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询HSS与BSF设备之间的Diameter链路的配置信息：

- 若需要查询全部HSS与BSF设备之间的Diameter链路的配置信息，请不要输入任何参数。
- 若需要查询某条HSS与BSF设备之间的Diameter链路配置的详细信息，请输入“HSS名称”或其他参数或这些参数的组合。

## 注意事项

当HSS的“工作模式”被指定为“SERVER(服务器)”时，返回结果中参数“分发端口号”表示内部分发端口号，HSS整体对外端口号为3868，在进行对端配置的时候需配置HSS的对外端口号为3868。

## 参数说明

| 参数标识    | 参数名称       | 参数说明                                                                                                                                                                                                        |
|:--------|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HSSN    | HSS名称      | 用于标识查询HSS与BSF设备之间Diameter链路的配置信息的HSS名称。 取值范围：长度不超过127的字母或数字组成的字符串。 默认值：无。                                                                                                                                   |
| BSFN    | BSF名称      | 用于标识查询HSS与BSF设备之间Diameter链路的配置信息的BSF名称。 取值范围：长度不超过127的字母或数字组成的字符串。 默认值：无。                                                                                                                                   |
| LNKN    | 链路名称       | 用于标识查询HSS与BSF设备之间Diameter链路的配置信息的链路名称。 取值范围：长度不超过127的字母或数字组成的字符串。 默认值：无。                                                                                                                                    |
| PTYPE   | 传输协议类型     | 用于标识查询HSS与BSF设备之间Diameter链路的配置信息的传输协议类型。 取值范围： SCTP(SCTP协议类型) TCP(TCP协议类型) UDP(UDP协议类型) 默认值：无。                                                                                                              |
| WMODE   | 工作模式       | 用于标识查询HSS与BSF设备之间Diameter链路的配置信息的工作模式。 取值范围： CLIENT(客户端)：HSS在当前链路中作为客户端，会主动向对端服务器发起建链请求。 SERVER(服务器)：HSS在当前链路中作为服务器端，在建链时不会主动发起建链请求，会等待对端的建链请求。 SERVERMULTPORT(服务端多端口)：当HSS在当前链路中作为服务端多端口时，需要指定分发端口。 默认值：无。 |
| HSFMID  | HSF模块号     | 用于标识查询HSS与BSF设备之间Diameter链路的配置信息的HSF模块号。 取值范围：1～1023 默认值：无。                                                                                                                                                 |
| ADDRN   | HSS地址名称    | 用于标识查询HSS与BSF设备之间Diameter链路的配置信息的HSS地址名称。 取值范围：长度不超过127的字母或数字组成的字符串。 默认值：无。                                                                                                                                 |
| SADDRN  | HSS备用地址名称  | 用于标识查询HSS与BSF设备之间Diameter链路的配置信息的HSS备用地址名称。 取值范围：长度不超过127的字母或数字组成的字符串。 默认值：无。                                                                                                                               |
| LPT     | 分发端口号      | 用于标识查询HSS与BSF设备之间Diameter链路的配置信息的分发端口号。 取值范围：1025～65534 默认值：无。                                                                                                                                              |
| PIPVER  | 对端IP地址版本   | 用于标识查询HSS与BSF设备之间Diameter链路的配置信息的对端IP地址版本。 取值范围： IPV4(IPV4) IPV6(IPV6) 默认值：无。                                                                                                                               |
| PIPV4   | 对端IPV4地址   | 用于标识查询HSS与BSF设备之间Diameter链路的配置信息的对端IPV4地址。 取值范围：IPv4地址。 默认值：无。 说明：“对端IP地址版本”为“IPV4(IPV4)”时，该参数有效。                                                                                                           |
| PIPV6   | 对端IPV6地址   | 用于标识查询HSS与BSF设备之间Diameter链路的配置信息的对端IPV6地址。 取值范围：IPv6地址 默认值：无。 说明：“对端IP地址版本”为“IPV6(IPV6)”时，该参数有效。IPV6格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如，fc00:7864:0266:0000:0000:0000:7864:0266。                |
| SPIPVER | 对端备用IP地址版本 | 用于标识查询HSS与BSF设备之间Diameter链路的配置信息的对端备用IP地址版本。 取值范围： IPV4(IPV4) IPV6(IPV6) 默认值：无。                                                                                                                             |
| SPIPV4  | 对端备用IPV4地址 | 用于标识查询HSS与BSF设备之间Diameter链路的配置信息的对端备用IPV4地址。 取值范围：IPv4地址。 默认值：无。 说明：“对端备用IP地址版本”为“IPV4(IPV4)”时，该参数有效。                                                                                                       |
| SPIPV6  | 对端备用IPV6地址 | 用于标识查询HSS与BSF设备之间Diameter链路的配置信息的对端备用IPV6地址。 取值范围：IPv6地址。 默认值：无。 说明：“对端IP地址版本”为“IPV6(IPV6)”时，该参数有效。IPV6格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如，fc00:7864:0266:0000:0000:0000:7864:0266。             |
| PPT     | 对端端口号      | 用于标识查询HSS与BSF设备之间Diameter链路的配置信息的对端端口号。 取值范围：0～65534 默认值：无。                                                                                                                                                 |

## 使用实例

1. 查询HSS设备与BSF之间所有链路的配置信息：

   ```
   LST HBSFL:;
   ```

## 输出结果说明

以下列出的是未包含在本命令参数说明中的输出项，其他输出项的详细说明请参见本命令的参数说明。

| 输出项名称   | 输出项解释                                      |
|:--------|:-------------------------------------------|
