# 修改HOST模板(MOD HOSTTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于对配置数据库中的一个HOST模板配置信息进行修改。在该命令中，系统通过“索引”参数来唯一标识一个HOST模板配置信息。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

HOST模板内容发生改变后，引用该模板的AP转发规则的HOST头域匹配原则也会相应改变。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                          |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------|
| ID     | 索引     | 可选必选说明：必选参数 标识一个HOST模板配置信息的关键字段（其取值不能被修改）。用于指定需要对哪一个HOST模板的配置信息进行修改，操作员可以使用LST HOSTTPL命令查询获得。 默认值：无。                                          |
| HOST   | HOST   | 可选必选说明：可选参数 用于标识AP转发规则中要匹配的HTTP请求消息的HOST头域信息，HOST头域用于指定访问设备（转发AP或AS）的主机名称。 取值范围：1～127位字符串。 默认值：无。 说明：该参数不区分大小写，在执行LST HOSTTPL命令查询出的报文中为全小写形式。 |

## 使用实例

修改一条“索引”为“1”的HOST模板数据记录，“HOST”为“huawei.com”：

```
MOD HOSTTPL: ID=1, HOST="huawei.com";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释                                  | 原因分析            | 处理建议                                                                        |
|-------:|:--------------------------------------|:----------------|:----------------------------------------------------------------------------|
| 377898 | 指定的HOST已经存在。请执行LST HOSTTPL查询已存在的HOST。 | 输入的“HOST”参数已存在。 | 根据实际情况，重新输入参数，确保输入的“HOST”参数与系统中已存在的不重复。可执行LST HOSTTPL命令查询系统中已存在的“HOST”参数记录。 |
| 377899 | 指定的ID不存在。请执行LST HOSTTPL查询已存在的ID。      | 输入的“索引”参数已存在。   | 根据实际情况，重新输入参数，确保输入的“索引”参数与系统中已存在的不重复。可执行LST HOSTTPL命令查询系统中已存在的“索引”参数记录。     |
