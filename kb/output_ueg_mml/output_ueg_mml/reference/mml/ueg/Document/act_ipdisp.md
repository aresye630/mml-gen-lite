# 激活IP链路(ACT IPDISP)

## 命令功能

**须知** 

该命令属于高危命令，如果执行不当会导致FE访问BE的业务失败，需联系华为技术支持确认后再执行。

该命令用于请求系统激活IP配置，使本端DSG和远端DSG模块进行网络连接。在USCDB和对端网元对接配置时，需要通过此命令激活IP链路，使USCDB网元与对端网元进行通信。

## 注意事项

为确保用户能够正确使用此命令，在执行此命令前需要先通过执行以下三个命令进行USCDB配置对接：

1. 通过**ADD RLOCATION**命令增加远端Location标识。
2. 通过**ADD RDSG**命令增加远端DSG模块。
3. 通过**ADD RIPADDR**命令增加远端IP地址。

执行此命令，一般要求：

1. 只能在开局初始配置或者扩容时执行，其他情况下可能会导致FE访问BE的业务失败。
2. 在一端执行了激活IP链路命令后，本端的DSG可能会重新分配本端IP与对端的IP，造成FE与BE（或者BE与BE）之间的DSG链路中断。故执行此命令必须要在一端执行完后立刻在另外一端执行，否则会造成业务呼损甚至中断。
3. 先在BE执行（对于容灾组网的局点，Location小的BE先执行，Location大的BE后执行），然后在FE执行。

## 参数说明

无。

## 使用实例

某局点需要激活IP链路，其配置方式如下：

1. 执行**ADD RLOCATION**命令增加远端Location标识。
2. 执行**ADD RDSG**命令增加远端DSG模块。
3. 执行**ADD RIPADDR**命令增加远端IP地址。
4. 执行**ACT IPDISP**命令激活IP配置。

   ```
   ACT IPDISP:;
   ```
