# 查询网元IP地址(LST IPADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询IP地址及其相关信息。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|:------------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPNAME      | IP地址名称  | 用于标识一个IP地址。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| GATEWAYTYPE | 网关类型    | 用于指示系统需要按照哪种网关类型来查询网元IP地址信息；若不输入，则表示查询所有网关类型的IP地址信息。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| IPTYPE      | IP地址类型  | 用于指定IP地址的类型。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| IPV4IP1     | IPV4地址1 | 仅当参数“IP地址类型”取值为“IPV4(IPV4版本)”时该参数有效。用于指定访问远端Location的本地IP地址，由运营商统一规划。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| IPV6IP1     | IPV6地址1 | 仅当参数“IP地址类型”取值为“IPV6(IPV6版本)”时该参数有效。用于指定访问远端Location的本地IP地址，由运营商统一规划。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| IPQOSTYPE   | QoS协议类型 | 仅当参数“网关类型”取值为“HSF(HSF)”时，该参数有效。 用于标识QoS协议类型选择采用DSCP还是TOS进行配置。 取值范围： TOS(TOS)DSCP(DSCP) 默认值：无。 说明：设置参数值后已经建立的链路不会立即生效，需要链路重建后才能生效。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| IPQOSVALUE  | QoS协议值  | 仅当参数“网关类型”取值为“HSF(HSF)”时，该参数有效。 用于标识QoS协议类型取值为DSCP或TOS时，对应的QoS协议值取值。 此参数按BIT输入，位BIT0表示最高BIT，位BIT7表示最低BIT。 取值范围： BIT0(bit0)BIT1(bit1)BIT2(bit2)BIT3(bit3)BIT4(bit4)BIT5(bit5)BIT6(bit6)BIT7(bit7) 默认值：无。 说明： 设置参数值后已经建立的链路不会立即生效，需要链路重建后才能生效。当“QoS协议类型”选择“DSCP(DSCP)”时，DSCP的比特结构如图所示。|------------DSCP值-----------|--未用--|  0 1 2 3 4 5 6 7 在图中，6个BIT表示DSCP值，其它2个BIT目前保留未用。遵循《RFC2474》标准实现优先级标记。 当“QoS协议类型”选择“TOS(TOS)”时，TOS的比特结构如图所示。|-优先权子字段-|------TOS子字段---|-未用-|  0 1 2 3 4 5 6 7 在图中，优先权子字段占用3个比特，之后的4个BIT位表示TOS子字段，从BIT3～BIT6分别表示：最小时延、最大吞吐量、最高可靠性和最小花费（4个BIT中只能有一个BIT设置为1，如果4个BIT均为0，则表示一般服务），最后的1个BIT位保留未用。遵循《RFC791》标准实现优先级标记。 |
| VPNNAME     | VPN名称   | 用于指示系统需要按照哪个VPN名称来查询网元IP地址信息；若不输入，则表示查询所有VPN名称的网元IP地址信息。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |

## 使用实例

查询外出IP地址。

```
LST IPADDR: IPNAME="BSG2";
```

```
%%LST IPADDR: IPNAME="BSG2";%%
RETCODE = 0  操作成功

查询结果如下
------------
             IP地址名称  =  BSG2
               网关类型  =  BSG
             IP地址类型  =  IPV4版本
              IPV4地址1  =  192.168.167.66
              IPV6地址1  =  NULL
            QoS协议类型  =  DSCP
              QoS协议值  =  bit0,bit1,bit2
                 VPN名称 = public
(结果个数 = 1)

---    END
```
