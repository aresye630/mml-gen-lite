# 增加跟踪HLRSN(ADD TRCHLRSN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于增加一条跟踪HLRSN记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                 |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------|
| USER   | 用户名称   | 用于指定要添加的跟踪HLRSN对应的用户名称。 取值说明：长度不超过32个英文字符 默认值：无。                                                     |
| HLRSN  | HLR序列号 | 用于指定要添加的HLRSN对应的HLR序列号。 该参数必须由命令ADD HLRSNRNG添加，才能在此引用。可使用LST HLRSNRNG命令查询获取HLR序列号。 取值范围：1～255 默认值：无。 |

## 使用实例

增加一条跟踪HLRSN记录。用户名称为“admin”，对应的HLR序列号为12。

`ADD TRCHLRSN: USER="admin", HLRSN=12;`
