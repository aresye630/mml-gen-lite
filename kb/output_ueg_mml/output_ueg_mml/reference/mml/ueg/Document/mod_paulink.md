# 修改PAU链路(MOD PAULINK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改PAU链路的配置信息。在该命令中，系统通过“链路名称”参数来唯一标识一条PAU链路的配置信息。

## 注意事项

本命令只支持修改PAU链路的优先级。如果需要修改链路所属模块、本端IP、本端端口、远端IP或远端端口，请执行**RMV PAULINK**命令删除链路，再通过**ADD PAULINK**命令重新添加。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                          |
|:---------|:-------|:----------------------------------------------------------------------------------------------|
| LINKNAME | 链路名称   | 标识一条PAU链路配置信息的关键字段（其取值不能被修改），用于指定需要对哪一条PAU链路进行修改或调整，操作员可以LST PAULINK命令查询获得。                   |
| PRI      | 链路优先级  | 用于标识PAU链路的优先级。 取值范围：1～32 默认值：无。 说明：该参数取值越大优先级越高，数值相同表示优先级相同。链路优先级不区分模块，只和链路相关，即多个模块链路同时判断优先级。 |

## 使用实例

修改链路信息，将“链路名称”为“PAULINK\_1”的链路的“链路优先级”改为“2”：

```
MOD PAULINK: LINKNAME="PAULINK_1",PRI=2;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释         | 原因分析            | 处理建议                                                   |
|-------:|:--------------|:----------------|:-------------------------------------------------------|
| 335486 | 对象PAULINK不存在。 | 输入的“链路名称”参数不存在。 | 请重新输入“链路名称”参数，确保其存在。已存在的“链路名称”参数可以通过LST PAULINK命令查询获得。 |
