# 修改短消息RN路由(MOD SMSRNROUT)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成短消息业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改短消息RN（Route Number）路由数据。该命令中，系统通过“短信中心客户端用户名”参数来唯一标识一个短消息RN路由数据记录。

## 注意事项

- 操作员随意执行该命令修改RN路由数据，会造成短信互通网关无法准确给用户下发短消息，请谨慎操作。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                                                         |
|:-------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------|
| UNAME  | 短信中心客户端用户名 | 标识一条短消息RN路由数据记录的关键字段，用于指定需要对哪个用户的路由码进行修改，操作员可以通过执行LST SMSRNROUT命令查询获得。                                                       |
| RN     | 路由码        | 用于标识待修改短消息RN数据的路由码。路由码用于标识接收短消息的网络。 取值范围：由数字0～9或字母a～e组成的1～10位字符串，不区分大小写。 默认值：无 说明：该参数一般由运营商规划，用于标识不同运营商的不同网络，操作员在配置时可向运营商获取。 |

## 使用实例

修改短消息RN路由数据，“短信中心客户端用户名”为“username”，“路由码”为“1113”。命令如下：

```
MOD SMSRNROUT: UNAME="username", RN="1113";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释   | 原因分析                      | 处理建议                                     |
|-------:|:--------|:--------------------------|:-----------------------------------------|
| 352045 | 用户不存在   | “短信中心客户端用户名”参数指定的数据记录不存在。 | 使用LST SMSRNROUT命令查询后，重新确认要修改哪个用户对应的数据记录。 |
| 352047 | 参数取值无效  | “路由码”参数输入不符合取值范围。         | 根据实际情况，重新输入“路由码”，确保其取值符合取值范围。            |
