# 查询DSG链路条数(LST LINKNUM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询DSG之间的链路配置条数。

## 注意事项

系统中LINKNUM默认为8，不修改默认值的情况下，不需要设置LINKNUM，也无法使用**LST LINKNUM**查询系统默认值。 需要修改LINKNUM默认值的时候，需要用**SET LINKNUM**命令。

## 参数说明

| 参数ID    | 参数名称   | 参数描述                                  |
|:--------|:-------|:--------------------------------------|
| LINKNUM | 链路数    | 用于查询FE与BE之间的链路条数。 取值范围： 4～512 默认值： 无。 |

## 使用实例

查询所有模块的配置信息。

**LST LINKNUM:;**

```
%%LST LINKNUM:;%%
RETCODE = 0  操作成功

操作结果如下
------------
  链路数  =  16
(结果个数 = 1)

---    END
```
