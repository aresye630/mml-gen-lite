## 命令功能

该命令用于对一条FE平面信息的数据记录的某些参数进行修改或调整。在该命令中，系统通过“平面信息标识”参数来唯一标识一条FE平面信息数据记录。

ADD

## 注意事项

修改FE平面可能会导致升级或扩容过程中出现业务中断，降低系统可靠性，请谨慎使用。

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                       |
|:----------|:--------|:-------------------------------------------------------------------------------------------|
| PLAINFOID | 平面信息标识  | 标识一条FE平面信息数据记录的关键字段，用于指定需要对哪一条FE平面信息数据记录的参数进行修改或调整，操作员可以使用LST FEPLAINFO命令查询获得。 取值范围：0～1023 |
| PLA0POD   | 平面0 Pod | 用于标识FE平面信息的平面0 Pod。 取值范围：长度不超过128的字符串。 默认值：无。                                              |
| PLA1POD   | 平面1 Pod | 用于标识FE平面信息的平面1 Pod。 取值范围：长度不超过128的字符串。 默认值：无。                                              |

## 使用实例

修改FE平面信息。“平面信息标识”为“1”，“平面0 Pod”为“pod0”，“平面1 Pod”为“pod1”：

```
MOD FEPLAINFO: PLAINFOID=1, PLA0POD="pod0", PLA1POD="pod1";
```
