## 命令功能

**须知** 

本命令属于高危命令，执行不当会对性能有影响，建议在话务量低时执行，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于打印CCU/ACF进程中表在内存中的实际值。

通过比较内存数据和内存数据库，增加问题定位手段。

打印结果输出至CCU/ACF进程所在目录下printResult/目录下，名称为：GlobData\_网元ID\_模块ID\_表名.txt。

要使用此功能，需要先在“UDM MML命令”界面上进行软参设置：

```
MOD INSP: INSPT=GLOBALDATA, INSPN=PRINTGLOBDATA, INSPV=1;
```

## 注意事项

该命令不允许进行批操作。
