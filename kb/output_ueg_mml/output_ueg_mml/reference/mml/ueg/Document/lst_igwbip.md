# 查询iGWB IP地址配置信息(LST IGWBIP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**说明** 

该命令功能暂不支持。

该命令用于查询与EIR的PAU模块对接的ACM（归属于iGWB）模块的IP和端口数据。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询iGWB IP地址配置信息：

```
LST IGWBIP:;
```

```
%%LST IGWBIP:;%%
RETCODE = 0  操作成功

操作结果如下
------------
  IP地址类型  =  IPV4版本
主用IPV4地址  =  172.16.129.1
  主用端口号  =  8182
备用IPV4地址  =  172.17.129.1
  备用端口号  =  8182
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数请参见**SET IGWBIP**命令的参数。
