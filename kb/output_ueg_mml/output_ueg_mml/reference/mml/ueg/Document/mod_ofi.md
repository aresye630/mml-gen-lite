## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成本局与其它网元的链路不通，局点业务异常甚至中断，因此执行该命令前，请详细阅读本命令的联机帮助和注意事项，并评估规划数据的正确性，商用局点禁止执行该命令。操作前必须由华为工程师提交RFC至华为机关审核操作实施方案、测试方案和回退方案后才可以实施。如有疑问请联系华为公司处理。

该命令为配置类命令，用于对配置数据库中的本局信令点的互助节点的信息及属性进行修改或调整。当本局的一个信令点与对局连接的链路发生故障的情况下，可以使用本信令点的互助节点上的链路来传输信令，增加了系统的可靠性。在该命令中，系统通过以下关键参数的组合来唯一标识一条本局互助节点数据记录：“本局信令点索引。”

## 注意事项

- 在本局开通多信令点编码功能的前提下，假设本局具有两个源信令点编码A、B，目的信令点编码为C，在一般情况下，A→C、B→C之间的信令路由各自独立，相互之间没有备份的关系。为进一步提高本局到目的局的信令路由的可靠性，本局提供了多信令点互助功能，即在A→C的信令路由发生故障的情况下，A→C的信令业务可自动切换为由B→C的信令路由承载，反之亦然。
- 若需为本局的各源信令点编码定义互助节点，则操作员必须使用**MOD OFI** 命令修改本局信息。
- 该命令不允许进行批操作。

## 参数说明

| IDX    | 本局信令点索引   | 标识一条本局互助节点数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪一条本局互助节点数据记录的参数进行修改或调整，操作员可以使用LST OFI 命令查询获得。 取值范围：0～15 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                                 |

| PA1    | 互助节点1网络指示 | 用于指定该互助节点的信令点编码属于哪一个信令网。 取值范围： “INT(国际主用网)”“INTB(国际备用网)”“NAT(国内主用网)”“NATB(国内备用网)” 默认值：无。 说明：互助节点所在的信令网与被互助节点所在的信令网必须要保持一致，否则，该数据将被判断为无效。                                                                                                                                                                                                                                                                                     |

## 使用实例

修改本局互助节点信息，“本局信令点索引”为“3”，“互助节点1网络指示”为“国内主用网”，“互助节点1编码”为“100002”，“互助节点2网络指示”为“国内备用网”，“互助节点2编码”为“000E02”:

```
MOD OFI:IDX=3, PA1=NAT, PAC1="100002", PA2=NATB, PAC2="000E02";
```
