# 修改手动流控策略配置(MOD TCAPPOL)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于在配置数据库中修改一条手动流控策略数据记录。

## 注意事项

- 当修改了手动流控策略，系统会根据新的手动流控策略进行流控，原先定义的手动流控策略将不会生效，会影响各类消息允许通过的最大数量，可能会导致业务呼损变多，因此现网执行该操作时需要慎重。
- 该命令不允许进行批操作。

## 使用实例

修改流控策略，参数修改为以下值：

- “流控策略索引”=0；
- “允许最大消息数”=100；
- “允许最大位置更新消息数”=10；
- “允许最大鉴权消息数”=10；
- “允许最大被叫取路由消息数”=10；
- “允许最大短消息被叫取路由消息数”=10；
- “允许最大GPRS位置更新消息数”=10；

```
MOD TCAPPOL: TCIDX=0, TOTAL_NUM=100, UPL_NUM=10, AUC_NUM=10, SRI_NUM=10, SRI_SM_NUM=10, GPRS_UPL_NUM=10;
```
