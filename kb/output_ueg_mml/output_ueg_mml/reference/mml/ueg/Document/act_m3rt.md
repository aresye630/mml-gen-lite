# 激活M3UA路由(ACT M3RT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为维护类命令，用于请求系统对处于去激活状态的M3UA路由执行激活操作。

该命令的操作场景一般为：当操作员使用**DSP M3RT**命令查询某M3UA路由的状态时，发现其“状态”为“去激活”，例如操作员使用DEA
M3RT命令对某M3UA路由执行了去激活操作。

## 注意事项

- 仅当被操作的M3UA路由的状态为“去激活”时，操作员才能使用该命令。
- 如果被操作的M3UA路由处于“不可用”状态，则操作员不能使用该命令使路由处于“可用”状态。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                            |
|:-------|:-------|:----------------------------------------------------------------|
| DENM   | 目的实体名称 | 标识某个M3UA目的实体的关键字段，用于指示系统激活到哪个M3UA目的实体的路由，操作员可以使用LST M3DE命令查询获得。 |
| LSNM   | 链路集名称  | 标识一条M3UA链路集的关键字段，用于指示系统激活的路由对应的M3UA链路集，操作员可以使用LST M3LKS命令查询获得。  |

## 使用实例

激活M3UA路由，“目的实体名称”为“DE\_LXT”，“链路集名称”为“LKS\_LXT”：

```
ACT M3RT: DENM="DE_LXT", LSNM="LKS_LXT";
```
