# 显示指定链路集的M3UA链路(DSP M3LSLNK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于请求系统显示链路集内M3UA链路的运行状态。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MN     | BSG模块号 | 用于请求系统显示哪个BSG模块内M3UA链路的运行状态；若不输入，则表示所有模块。 取值范围：1～1023 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                |
| LSNM   | 链路集名称  | 用于请求系统显示哪个链路集内M3UA链路的运行状态。该参数支持模糊查询功能，其配置原则是： 操作员只能在字符串或BCD码的末尾添加通配字符“%”，而不能在字符串或BCD码的前面、中间添加通配字符“%”。例如，合法的输入：“A市%”、“1390123%”；不合法的输入：“%A市”、“A市%区”、“%1390123”、“139%0123”。 如果某个命令同时存在有多个字符串或BCD码类型的查询参数，则操作员在一次查询操作中，只能对其中的一个查询参数使用模糊查询方式，而不能同时对两个或两个以上的查询参数使用模糊查询方式。 取值范围：1～32位字母、数字、特殊字符“-”、“_”、“.”、空格符或中文组成的字符串。 默认值：无。 说明：模糊查询功能是指操作员在客户端输入查询参数时，对于字符串或BCD码类型的查询参数而言，如果操作员输入的是一个完整的字符串或BCD码，则表示系统将按照完全匹配的方式执行查询操作；如果操作员在输入的某个字符串或BCD码的末尾添加通配字符“%”，则表示系统将按照模糊匹配的方式执行查询操作。 |
| LS     | 链路状态   | 用于请求系统显示哪个特性的链路状态。 取值范围：UEST(未建立)EST(已建立)INACT(未激活)ACT(已激活)ALL(所有状态) 默认值：ALL(所有状态)                                                                                                                                                                                                                                                                                                                                                                                          |

## 使用实例

1. 显示指定链路集的M3UA链路，“BSG模块号”为“1”、“链路集名称”为“M3UA\_LKS”：

   ```
   DSP M3LSLNK: MN=1, LSNM="M3UA_LKS";
   ```

   ```
   %%DSP M3LSLNK: MN=1, LSNM="M3UA_LKS";%%
   RETCODE = 0  操作成功

   M3UA链路集中的链路状态
   ----------------------
        BSG模块号  =  1
         链路名称  =  M3UA_LNK

         锁定信息  =  已解锁

     本地释放信息  =  未被手工释放
     链路拥塞信息  =  未拥塞
     实际输入流数  =  17

   信令链路选择码  =  00 02 04 06 08 0A 0C 0E
             状态  =  已激活
   (结果个数 = 1)

   ---    END
   ```
2. 显示链路集名称前缀为“M3UA”的M3UA链路：

   ```
   DSP M3LSLNK: LSNM="M3UA%";
   ```

   ```

   RETCODE = 0  操作成功

   (结果个数 = 2)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数请参见**DSP M3LNK**命令的输出结果说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释      | 原因分析       | 处理建议                                     |
|-------:|:-----------|:-----------|:-----------------------------------------|
| 304256 | 查询记录数最大为32 | 链路集超过了32条。 | 链路集超过32条时，请执行DSP M3LNK命令查询指定M3UA链路的运行状态。 |
