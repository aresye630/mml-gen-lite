# 查询分发配置记录（LST PORTCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询端口配置参数的配置信息。

## 注意事项

无。

## 参数说明

| 参数ID      | 参数名称   | 参数描述                                                         |
|:----------|:-------|:-------------------------------------------------------------|
| LINKNAME  | 链路名称   | 此参数用于设置链路名称。 取值范围：长度不超过32的字符串。 说明：该参数是可选参数。                  |
| LINKTYPE  | 链路类型   | 链路类型。 取值范围： M3UA(M3UA) DIAMETER(DIAMETER) 说明：该参数是可选参数。       |
| ENDTYPE   | 端口模式   | 此参数用于设置端口模式。 取值范围： Client（客户端） Server（服务器端） 说明：该参数是可选参数。     |
| LOCALIP   | 本端地址   | 此参数用于设置本端地址。 取值范围：IPV4/IPV6地址格式的字符串。 说明：该参数是可选参数。            |
| LOCALPORT | 本端端口   | 此参数用于设置本端端口号。 取值范围：0～65535。 说明：该参数是可选参数。                     |
| TRANSPROT | 协议类型   | 此参数用于设置协议类型。 取值范围： TCP(TCP) UDP(UDP) SCTP(SCTP) 说明：该参数是可选参数。 |

## 使用实例

查询端口配置信息。

```
LST PORTCFG:;
```

```
%%LST PORTCFG:;%%
RETCODE = 0  操作成功

操作结果如下
------------
 分发模块  链路名称  链路类型  协议类型  本端地址        本端端口  内部端口  对端地址  对端端口  端口模式

 2         uname     NULL      TCP       10.100.30.100   4050      4050      10.0.0.0   0        NULL    
 2         uname     NULL      SCTP      10.100.30.100   2002      2002      10.0.0.0   0        NULL    
(结果个数 = 2)

---    END
```
