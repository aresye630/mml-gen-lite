# 删除本局信令点 (RMV OFI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成本局与其它网元的链路不通，局点业务异常甚至中断，因此执行该命令前，请详细阅读本命令的联机帮助和注意事项，并评估规划数据的正确性，商用局点禁止执行该命令。操作前必须由华为工程师提交RFC至华为机关审核操作实施方案、测试方案和回退方案后才可以实施。如有疑问请联系华为公司处理。

该命令为配置类命令，当本局配置有多信令点时，用于从配置数据库中删除一组已配置的本局信令点编码。

## 注意事项

- 不能删除“信令点索引”为“0”的本局信令点。
- 如果命令执行成功，且删除的数据为已有性能统计任务中登记的对象实例，则该对象实例后续上报的指标值为0。命令涉及的测量单元有：SCCP可用性测量；涉及的测量对象有：OPC。
- 本局信令点编码数据属于本局的基础数据，该命令仅在开局时由开局工程师在数据调测的过程中使用。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                   |
|:-------|:--------|:-----------------------|
| IDX    | 本局信令点索引 | 取值范围：0～15 默认值：无。 说明：无。 |

## 使用实例

删除本局信令点编码，“本局信令点索引”为“2”：

```
RMV OFI: IDX=2;
```
