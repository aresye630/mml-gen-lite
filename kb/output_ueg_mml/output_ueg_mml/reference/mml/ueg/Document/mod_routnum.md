# 修改它网RN数据(MOD ROUTNUM)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该组命令用于修改号码携转业务中它网RN（Route Number）路由的数据记录信息。该命令中，系统通过“路由码”参数来唯一标识一个它网RN路由数据记录。

## 注意事项

- 操作员随意执行该命令修改它网RN路由数据，会造成短信互通网关无法准确给用户下发短消息，请谨慎操作。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                  |
|:-------|:-------|:----------------------------------------------------------------------|
| NAME   | 网络名称   | 用于标识待设置它网RN路由数据的网络名称。 取值范围：1～20个字母或数字组成的字符串。 默认值：无                    |
| RN     | 路由码    | 标识一条它网RN路由数据记录的关键字段，用于指定需要对哪个它网RN路由数据进行修改，操作员可以通过执行LST ROUTNUM命令查询获得。 |

## 使用实例

修改它网RN路由数据，“网络名称”为“name1”，“路由码”为“1113”。执行命令如下：

```
MOD ROUTNUM: NAME="name1", RN="1113";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释   | 原因分析               | 处理建议                              |
|-------:|:--------|:-------------------|:----------------------------------|
| 352045 | 用户不存在   | “路由码”参数指定的数据记录不存在。 | 使用LST ROUTNUM命令查询后，重新确认要删除哪个数据记录。 |
| 352047 | 参数取值无效  | “路由码”参数输入不符合取值范围。  | 根据实际情况，重新输入“路由码”，确保其取值符合取值范围。     |
