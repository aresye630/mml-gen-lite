# 显示M3UA链路集(DSP M3LKS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询指定M3UA链路集的状态信息。

## 注意事项

该命令的“链路集名称”参数支持模糊查询功能。模糊查询功能是指操作员在客户端输入查询参数时，对于字符串或BCD码类型的查询参数而言，如果操作员输入的是一个完整的字符串或BCD码，则表示系统将按照完全匹配的方式执行查询操作；如果操作员在输入的某个字符串或BCD码的末尾添加通配字符“%”，则表示系统将按照模糊匹配的方式执行查询操作。对于此类参数，其配置原则是：

- 该参数的值域范围为：数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“\_”、“.”、空格符、中文。
- 操作员只能在字符串或BCD码的末尾添加通配字符“%”，而不能在字符串或BCD码的前面、中间添加通配字符“%”。例如，“A市%”、“1390123%”是合法的输入，而“%A市”、“A市%区”、“%1390123”、“139%0123”均是不合法的输入。
- 如果某个命令同时存在有多个字符串或BCD码类型的查询参数，则操作员在一次查询操作中，只能对其中的一个查询参数使用模糊查询方式，而不能同时对两个或两个以上的查询参数使用模糊查询方式。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                             |
|:-------|:-------|:-----------------------------------------------------------------|
| MN     | 模块号    | 用于请求系统显示哪个模块内M3UA链路集的状态信息，若不输入，则表示所有模块。 取值范围：1～1023 默认值：无。 说明：无。 |
| LSNM   | 链路集名称  | 用于请求系统显示哪个链路集的状态信息。 取值范围：1～32 位字符串。 默认值：无。 说明：必选参数。              |

## 使用实例

1、显示M3UA链路集，“链路集名称”为“M3UA\_LKS”：

```
DSP M3LKS: LSNM="M3UA_LKS";
```

返回结果如下：

```
%%DSP M3LKS: LSNM="M3UA_LKS";%%
RETCODE = 0  操作成功

M3UA链路集状态信息
------------------
链路集名称  =  M3UA_LKS
链路集状态  =  不可用
(结果个数 = 1)

---    END
```

2、显示名称前缀为的“M3UA”的M3UA链路集：

```
DSP M3LKS: LSNM="M3UA%";
```

返回结果如下：

```
%%DSP M3LKS: LSNM="M3UA%";%%
RETCODE = 0  操作成功

M3UA链路集状态信息
------------------
 链路集名称  链路集状态

 M3UA        不可用      
 M3UA_LKS    不可用      
(结果个数 = 2)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义如表1所示。

| 输出项名称     | 输出结果解释                                                                                                                                                                                                                                                                                     |
|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 链路集名称     | 用于返回当前M3UA链路集的名称。                                                                                                                                                                                                                                                                          |
| M3UA链路集状态 | 用于返回当前M3UA链路集的状态： 不可用：表示指定的M3UA链路集内没有建立一条M3UA链路。 未激活：表示指定的M3UA链路集中至少有一条M3UA链路处于未激活状态、其他的链路处于断开状态，并且链路集不在“挂起”状态。 已激活：表示指定的M3UA链路集内至少有一条M3UA链路处于激活状态。 挂起：表示指定的M3UA链路集内所有的M3UA链路均处于不可用状态，并且Pending定时器没有超时的一个中间状态。该状态是一个短暂状态，当Pending定时器超时后，系统会查询链路集内各链路的状态，并根据查询结果，使状态迁移至“未建立”、“未激活”或者“激活”状态。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释      | 原因分析                                                             | 处理建议                                                                                                                                     |
|-------:|:-----------|:-----------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------|
| 304256 | 查询记录数最大为32 | 当输入“链路集名称”参数值为某个字符串或BCD码末尾添加通配字符“%”，系统按照模糊匹配的方式执行查询操作，查询结果超过32条。 | 建议通过下面两种方式查询链路集的状态信息。精确查询：选择系统已配置的“链路集名称”，查询指定M3UA链路集的状态信息。模糊查询：根据系统已配置的“链路集名称”，尽量输入多个字符串或BCD码末尾添加通配字符“%”组合，确保查询结果记录不超过32条，查询多个链路集的状态信息。 |
