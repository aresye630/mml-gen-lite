# 查看SCTP所有偶联的统计信息(DSP DSGSCTPBS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查看SCTP所有偶联的统计信息。该命令主要是用于研发的问题定位，通过该命令，可以查看DSG模块之间的通信状态，处理的消息包的情况。

## 注意事项

无。

## 参数说明

| 参数ID   | 参数名称   | 参数描述                                   |
|:-------|:-------|:---------------------------------------|
| MID    | DSG模块号 | 查看链路状态信息所在的DSG模块号。 取值范围： 1～2047 默认值： 无 |

## 使用实例

查看DSG偶联统计信息。MID为121。

**DSP DSGSCTPBS: MID=121;**

