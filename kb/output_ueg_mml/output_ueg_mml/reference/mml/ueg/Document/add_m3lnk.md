# 增加M3UA链路(ADD M3LNK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条M3UA链路数据记录。在该命令中，以下关键参数需要与对端M3UA信令设备协商：

- 本地IPv4地址1/本地IPv6地址1
- 本地IPv4地址2/本地IPv6地址2
- 本地端口号
- 对端IPv4地址1/对端IPv6地址1
- 对端IPv4地址2/对端IPv6地址2
- 对端端口号
- 客户端/服务器端模式

## 注意事项

- 在SIGTRAN协议中，“本地IP地址”、“本地端口号”、“对端IP地址”、“对端端口号”等四个参数用于唯一标识一个SCTP偶联；在本局中，它是一条M3UA链路。因此，操作员在增加上述链路时，应遵循以下配置原则：
  - 本地IP地址、本地SCTP端口号、对端IP地址与对端SCTP端口号属于SIGTRAN协议的对接数据，需要双方协商一致。
  - 当本地IP地址与对端IP地址被确定以后，两信令设备之间的链路将由本地SCTP端口号与对端SCTP端口号两个参数组合确定，也就是说，如果各链路所使用的对端SCTP端口号相同，则本地SCTP端口号不能重复，反之亦然。
  - 当新增链路的本地端口号与已有记录相同，且链路为服务器端时，本地IP地址1和本地IP地址2配置与已有的记录的本地IP地址1和本地IP地址2需完全相同，或者本地IP地址均不相同。
  - 如有两条链路使用同一个本地IP地址和本地端口号，则“客户端/服务器端模式”必须配置一致，不允许一条配置为客户端，一条配置为服务器端。
- 增加M3UA链路时，系统分为平面0和平面1两个平面。在指定BSG模块号时，若不输入则由系统按照负荷分担原则自动配置在两个平面的BSG模块上。若有特殊要求时，可输入BSG模块号，则系统将该链路配置到指定平面的BSG模块上。
- 负荷分担原则如下。
  - 一个局向或链路集的链路，满足在所有虚机（裸机POD）上都有配置，以达到最高的可靠性要求。
  - 一个局向或链路集的链路，在平面0和平面1的虚机（裸机POD）间均匀分布。当某个平面复位的时候，局向/链路集内至少一半的链路仍可用。
  - 宽带链路均匀配置后，BSG模块的负荷基本相等。
- 一个BSG模块最多支持配置M3UA链路的条数由“是否启用链路性能增强模式”软参控制：
  - 如果不启用链路性能增强模式（执行**MOD MSFP**命令，将“P66”号软参的0比特位的值设为“0”），一个BSG模块最多支持配置64条M3UA链路。
  - 如果启用链路性能增强模式（执行**MOD MSFP**命令，将“P66”号软参的0比特位的值设为“1”），一个BSG模块最多支持配置8条M3UA链路。
- 当本端有两个信令IP而对端只有1个信令IP时，优先考虑配置多条单路径链路，即链路中仅配置“本地IPv4地址1”和“对端IPv4地址1”参数，或者“本地IPv6地址1”和“对端IPv6地址1”参数。
- 当本端只有1个信令IP时，优先考虑扩容本端信令IP。如果无法扩容本端信令IP，而对端有两个IP时，优先考虑配置多条单路径链路，即链路中仅配置“本地IPv4地址1”和“对端IPv4地址1”参数，或者“本地IPv6地址1”和“对端IPv6地址1”参数。
- 通过**ADD IPADDR**命令配置IP地址，当“网关类型”取值为“BSG(BSG)”和“HSF(HSF)”且“BSG(BSG)”和“HSF(HSF)”之间共用IP时， Diameter和M3UA链路不允许配置相同的本端IP与和本端端口号。

## 使用实例

1、增加M3UA链路，“BSG模块号”为“1”，“链路名称”为“M3LNK”，“IP版本”为“IPV4”，“本地IPv4地址1”为“172.16.200.63”，“本地端口号”和“对端端口号”均为“9900”，“对端IPv4地址1”为“172.16.200.43”，“链路集名称”为“M3LKS”，“客户端/服务器端模式”为“客户端”，其他参数使用缺省值：

```
ADD M3LNK: MN=1, LNKNM="M3LNK", IPVER=IPV4, LOCIPV4IP1="172.16.200.63", LOCPORT=9900, PEERIPV4IP1="172.16.200.43", PEERPORT=9900, CS=C, LSNM="M3LKS", QOS=TOS, TOS=MIN_COST;
```

2、增加M3UA链路，“BSG模块号”为“1”，“链路名称”为“M3LNK”，“IP版本”为“IPV4”，“本地IPv4地址1”为“172.16.200.63”，“本地端口号”和“对端端口号”均为“9902”，“对端IPv4地址1”为“172.16.200.43”，“链路集名称”为“M3LKS”，“客户端/服务器端模式”为“服务器端”，其他参数使用缺省值：

```
ADD M3LNK: MN=1, LNKNM="M3LNK", IPVER=IPV4, LOCIPV4IP1="172.16.200.63", LOCPORT=9902, PEERIPV4IP1="172.16.200.43", PEERPORT=9902, CS=S, LSNM="M3LKS", QOS=TOS, TOS=MIN_COST;
```
