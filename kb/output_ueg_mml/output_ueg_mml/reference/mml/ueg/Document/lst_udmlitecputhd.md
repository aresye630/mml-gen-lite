# 查询模块CPU过载阈值(LST UDMLITECPUTHD)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询模块CPU过载告警的上报阈值和恢复阈值：

- 若要查询所有模块CPU过载告警的上报阈值和恢复阈值，请不要输入任何参数。
- 若要查询某个模块CPU过载告警的上报阈值和恢复阈值，请输入“模块类型”参数。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                            |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MT     | 模块类型   | 可选必选说明：可选参数 参数含义：用于指示系统按照模块类型来查询模块CPU过载告警的上报阈值和恢复阈值，如果不输入该参数，则表示所有的模块类型。 取值范围： HSF(HSF)BSG(BSG)CCU(CCU)DSG(DSG)ERU(ERU)：该模块类型为预留值。ACF(ACF)APF(APF) 默认值：无 配置原则：无 |

## 使用实例

1. 查询所有模块CPU过载告警上报阈值和恢复阈值：

   ```
   LST UDMLITECPUTHD:;
   ```

   ```
   %%LST UDMLITECPUTHD:;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
   模块类型  一级过载告警阈值  一级过载告警恢复阈值  二级过载告警阈值  二级过载告警恢复阈值  三级过载告警阈值  三级过载告警恢复阈值  

   HSF       50                40                    80                75                    90                85                 
   DSG       40                35                    80                75                    90                85               
   BSG       40                35                    80                75                    90                85                               
   CCU       50                49                    80                75                    90                85
   ERU       75                70                    80                75                    90                85                  
   ACF       75                70                    80                75                    90                85                  
   APF       75                70                    80                75                    90                85  
                   
   (结果个数 = 7)

   ---    END
   ```
2. 查询“模块类型”为“HSF”的模块CPU过载告警上报阈值和恢复阈值：

   ```
   LST UDMLITECPUTHD: MT=HSF;
   ```

   ```
   %%LST UDMLITECPUTHD: MT=HSF;%%
   RETCODE = 0  操作成功

   操作结果如下:
   -------------
               模块类型  =  HSF
       一级过载告警阈值  =  50
   一级过载告警恢复阈值  =  40
       二级过载告警阈值  =  80
   二级过载告警恢复阈值  =  75
       三级过载告警阈值  =  90
   三级过载告警恢复阈值  =  85
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET UDMLITECPUTHD**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释      | 原因分析                  | 处理建议                           |
|-------:|:----------|:----------------------|:-------------------------------|
| 100016 | 参数不在指定范围内 | 输入的参数“模块类型”取值不在取值范围内。 | 根据参数的取值范围，重新输入参数的取值，确保其取值符合要求。 |
