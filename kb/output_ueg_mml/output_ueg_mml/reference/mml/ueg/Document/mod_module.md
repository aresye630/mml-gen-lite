## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对模块的配置信息（如：模块名称）进行修改。在该命令中，系统通过参数“模块号”来唯一标识一条模块配置信息。

该命令的使用场景：当操作员添加了错误的模块信息，可通过该命令修改对应的模块配置信息。

## 注意事项

- 随意修改模块配置信息可能会导致系统出错，请谨慎使用。
- 要修改的模块必须存在，且只能修改本UDM网元增加的模块，其他网元自己添加的模块无法修改。
- 模块个数不能超过应用类型设置的最大模块个数。
- 不能修改模块的类型。
- 修改模块时，对应Pod名称通过**LST PODINFO**查询。
- 对于BSG和HSF模块，只允许对已经配置为主备模式模块修改备用模块信息，不允许将负荷分担模块修改为主备模块。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                         |
|:---------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MID      | 模块号     | 标识一条模块配置信息的关键字段（其取值不能被修改），用于指定需要对哪一条模块配置信息进行修改，操作员可以使用LST MODULE命令查询获得。 模块号无法通过该命令进行修改。如果模块号错误，操作员应执行RMV MODULE命令删除错误的节点信息，然后再执行ADD MODULE添加正确的模块。模块号对应的模块必须是本UDM网元内的模块，否则命令执行失败。 取值范围：1～1023 默认值：无。                                                                                                                         |
| MT       | 模块类型    | 用于定义待修改模块的模块类型，当需要明确待修改模块时可填写该参数，该参数必须与模块号对应，否则命令执行失败，因此不推荐填写该参数。 该参数的修改原则： 模块类型无法通过该命令进行修改。如果模块类型错误，操作员应执行RMV MODULE命令删除错误的节点信息，然后再执行ADD MODULE命令添加正确的模块。 取值范围： “DPU(DPU)”“DSG(DSG)”“BSG(BSG)”“CCU(CCU)”“PAU(PAU)”“HSF(HSF)”“NSF(NSF)”“ACF(ACF)”“ERU(ERU)”：该模块类型为预留值。“APF(APF)” 默认值：无。 说明：“ACF(ACF)”和“APF(APF)”模块仅在虚机场景下支持。 |
| APPTYPE  | 模块应用类型  | 仅当本命令中的“模块类型”参数为“CCU(CCU)”时该参数有效。用于标识一个模块的应用类型。 配置原则：HLR_SAE类型的CCU模块不能只部署在一个Pod上。IMS类型的CCU模块不能只部署在一个Pod上。不能同时部署HLR_SAE和ALL类型的CCU模块。不能同时部署IMS和ALL类型的CCU模块。 取值范围： ALL(ALL)HLR_SAE(2/3/4G)IMS(IMS) 默认值：无。 说明：模块类型设置不合理会导致模块CPU负荷不均匀。                                                                                            |
| PODNAME1 | 主用Pod名称 | 用于定义待修改模块所属主用Pod的名称。 取值范围：通过LST PODINFO命令查询后输入，也可通过下拉框直接选择。 默认值：无。                                                                                                                                                                                                                                                           |
| PODNAME2 | 备用Pod名称 | 用于定义待修改模块所属备用Pod的名称。 取值范围：通过LST PODINFO命令查询后输入，也可通过下拉框直接选择。 默认值：无。 说明：条件可选参数。当“模块类型”取值为DPU、BSG、PAU和HSF时，如果需要修改备模块信息，则设置该参数。                                                                                                                                                                                                  |
| MNAME    | 模块名称    | 用于指定一个模块的名称。配置原则：为便于识别，建议模块名称包含模块类型和相应编号。 取值范围：长度不超过32的字符串。 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                  |

## 使用实例

在开局场景下，由于操作失误，导致模块名称不是推荐的命名方式。例如：“模块号”为“1”的DSG模块的“模块名称”为“BSG\_02”。运行以下命令，将“模块名称”改为“DSG\_02”：

```
MOD MODULE: MID=1, MNAME="DSG_02";
```

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 360078 | 指定的PODNAME1不存在。                     | “主用Pod名称”参数不存在，添加模块必须在已有Pod上添加。        | 通过执行LST PODINFO命令查询主用Pod对象。                                 |
| 360079 | 指定的PODNAME2不存在。                     | “备用Pod名称”参数不存在，添加模块必须在已有Pod上添加。        | 通过执行LST PODINFO命令查询备用Pod对象。                                 |
| 260048 | 参数MID指定的模块没有配置备进程，因此更改备进程位置的操作不能执行。 | 输入的“模块号”指定的模块没有配置备进程，因此更改备进程位置的操作不能执行。 | 执行LST MODULE命令查询配置为主备模式的模块对应的“模块号”，重新输入该“模块号”的取值，确保其取值符合要求。 |
