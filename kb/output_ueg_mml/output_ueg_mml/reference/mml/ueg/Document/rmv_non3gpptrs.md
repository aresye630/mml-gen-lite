# 删除非3GPP信任关系(RMV NON3GPPTRS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中删除一条非3GPP信任关系。在该命令中，系统通过“标识”参数来唯一标识一条非3GPP信任关系信息数据记录。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

操作员随意执行该命令，会导致终端用户（UE）认证流程发生变化，造成认证失败，因此，请谨慎操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                          |
|:-------|:-------|:------------------------------------------------------------------------------|
| ID     | 标识     | 标识一条非3GPP信任关系数据记录的关键参数，用于指定需要删除哪一个非3GPP信任关系的记录进行。操作员可以使用LST NON3GPPTRS操作查询获得。 |

## 使用实例

删除一条非3GPP信任关系配置信息，“标识”为“6”，执行命令如下：

```
RMV NON3GPPTRS: ID=6;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释            | 原因分析                                 | 处理建议                                                                  |
|-------:|:----------------|:-------------------------------------|:----------------------------------------------------------------------|
| 377918 | 接入类型、对端主机名不能重复。 | “接入类型”参数和“对端主机名”所指定的非3GPP信任关系记录已经存在。 | 使用LST NON3GPPTRS命令查询已经存在的记录，确保重新输入的“接入类型”参数和“对端主机名”参数所指定的记录与已存在记录不重复。 |
| 377920 | 指定的ID不存在。       | “标识”参数指定的非3GPP信任记录不存在。               | 使用LST NON3GPPTRS命令查询后，重新输入“标识”。                                       |
