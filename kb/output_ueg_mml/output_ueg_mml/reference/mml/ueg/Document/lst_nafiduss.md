# 查询所有用户必签指定NAFID的USS列表(LST NAFIDUSS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询某个网络应用功能组的必选USS信息：

- 若需要查询某个网络应用功能组的USS信息，请输入“FQDN”。
- 若需要查询所有网络应用功能组的USS信息，请不要输入任何参数。

  **说明** 

  该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                           |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| FQDN   | FQDN   | 用于指示系统需要按照哪个网络应用功能组的全量域名来查询对应的USS信息；若不输入，表示查询所有网络应用功能组全量域名的USS信息。 需要指出的是，该参数不区分大小写，在执行本命令查询出的报文中为全小写形式。 取值范围：长度不超过127的字符串。 默认值：无。 注意：该参数为可选参数。 |

## 使用实例

1. 查询全部用户必签指定网络应用功能组的USS列表，执行命令：

   ```
   LST NAFIDUSS:;
   ```

   返回结果如下：

   ```
   %%LST NAFIDUSS:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    FQDN   GSID  

    1       1     
    aa      2     
   (结果个数 = 2)

   ---    END
   ```
2. 查询用户必签指定网络应用功能组的USS列表，“FQDN”为“1”，执行命令：

   ```
   LST NAFIDUSS: FQDN="1";
   ```

   返回结果如下：

   ```
   %%LST NAFIDUSS: FQDN="1";%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    FQDN  =  1
    GSID  =  1
   (结果个数 = 1)

   ---    END
   ```
