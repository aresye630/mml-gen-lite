# 查询SCCP新全局翻译码(LST SCCPNGT)

## 命令功能

该命令为维护类命令，用于在配置数据库中查询SCCP新全局翻译码数据：

- 若需要查询全部SCCP新全局翻译码数据的概要信息，请不要输入任何参数。
- 若需要查询某条SCCP新全局翻译码数据的详细信息，请输入“新全局翻译码名称”参数。

## 注意事项

使用本命令查询出的“全局翻译码地址信息”中包含了长度为8位的前缀参数，前缀参数包含了翻译类型、编号计划、编码方案和地址性质指示语信息。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                 |
|:-------|:---------|:-----------------------------------------------------|
| NGTNM  | 新全局翻译码名称 | 用于指示系统需要按照哪个新全局翻译码名称来查询新全局翻译码数据；若不输入，则表示所有的新全局翻译码名称。 |

## 使用实例

1. 查询全部SCCP全局翻译码：

   ```
   LST SCCPNGT:;
   ```

   返回结果如下：

   ```
   %%LST SCCPNGT:;%%
   RETCODE = 0  操作成功

   SCCP新GT表
   ----------
    新全局翻译码名称  处理方式  新的GT长度  全局翻译码地址信息  新GT索引

    NGTNM             替换      9           040011048613902700  0       
    STP               替换      7           04001204861360      1       
   (结果个数 = 2)

   ---    END
   ```
2. 查询SCCP全局翻译码，“新全局翻译码名称”为“NGTNM”：

   ```
   LST SCCPNGT: NGTNM="NGTNM";
   ```

   返回结果如下：

   ```
   %%LST SCCPNGT: NGTNM="NGTNM";%%
   RETCODE = 0  操作成功

   SCCP新GT表
   ----------
     新全局翻译码名称  =  NGTNM
             处理方式  =  替换
           新的GT长度  =  9
   全局翻译码地址信息  =  040011048613902700
             新GT索引  =  0
   (结果个数 = 1)

   ---    END
   ```
