# 重置定时器为缺省值(RST TIMER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为维护类命令，用于请求系统恢复内部定时器值为缺省值。如果操作员在执行**MOD TIMER**命令修改某个定时器的取值后需要恢复该定时器的缺省值，则可以对相应的定时器执行**RST TIMER**命令。

## 注意事项

内部定时器之间有相互的约束关系。如果操作员在执行**MOD TIMER**命令时修改的是具有相互约束关系的一组定时器，那么执行**RST TIMER**命令时，需要统一恢复这一组定时器为缺省值。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                |
|:-------|:-------|:------------------------------------------------------------------------------------|
| RTMD   | 恢复方式   | 用于指定恢复内部定时器为缺省值的方式。各参数选项的含义是： ALL(全部恢复)：表示将全部的定时器恢复为缺省值。 ONE(单个恢复)：表示将某一个定时器恢复为缺省值。 |
| MPID   | 模块 PID | 仅当本命令中的“恢复方式”参数为“ONE(单个恢复)”时该参数有效，用于指定内部定时器的模块PID，其取值范围为0～65535。                    |
| TMRIDX | 定时器索引  | 仅当本命令中的“恢复方式”参数为“ONE(单个恢复)”时该参数有效，用于指定内部定时器的定时器索引，其取值范围为0～255。                      |
| TMRSEQ | 定时器序号  | 仅当本命令中的“恢复方式”参数为“ONE(单个恢复)”时该参数有效，用于指定内部定时器的定时器序号，其取值范围为0～255。                      |

## 使用实例

1、重置定时器为缺省值，“恢复方式”为“ALL(全部恢复)”：

```
RST TIMER: RTMD=ALL;
```

返回结果如下：

2、重置定时器为缺省值，“恢复方式”为“ONE(单个恢复)”，“模块 PID”为“257”，“定时器索引”为“1”，“定时器序号”为“1”：

```
RST TIMER: RTMD=ONE, MPID=257, TMRIDX=1, TMRSEQ=1;
```
