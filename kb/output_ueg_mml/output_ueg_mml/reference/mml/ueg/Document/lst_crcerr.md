# 查询CRC校验失败的数据(LST CRCERR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询数据文件和主机数据校验不一致的记录：

- 若要查询全部模块中数据文件和主机数据校验不一致的记录，请不要输入任何参数。
- 若要查询某个模块或者某张表中数据文件和主机数据校验不一致的记录，请输入模块号或者表号或者这两个参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                      |
|:-------|:-------|:--------------------------------------------------------------------------|
| MN     | 模块号    | 用于指示系统需要按照哪个模块号来查询CRC校验失败的数据；若不输入，则表示所有的模块号。                              |
| TID    | 表号     | 用于指示系统需要按照哪张表来查询CRC校验失败的数据；若不输入，则表示所有的表。 取值范围：下拉列表中给出的所有表。 默认值：无。 配置原则：无。 |

## 使用实例

查询所有CRC校验失败的数据：

`LST CRCERR:;`

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。输出结果说明如表1所示。

命令执行异常，请联系华为技术支持处理。

| 输出项名称   | 输出项解释                                                      |
|:--------|:-----------------------------------------------------------|
| 模块号     | 表示当前CRC校验不一致记录对应的模块信息。                                     |
| Pod名称   | 表示当前CRC校验不一致记录对应模块所处的Pod名称信息。                              |
| 位置描述    | 表示当前CRC校验不一致记录对应模块所处的Pod位置描述信息。                            |
| 表号      | 表示当前CRC校验不一致记录对应的表信息。                                      |
| 表名称     | 表示当前CRC校验不一致记录对应的表描述信息。                                    |
| 记录ID    | 表示当前CRC校验不一致记录对应表的记录编号，执行CHK DATA命令校验出系统存在不一致的数据时，才会出现该字段。 |
