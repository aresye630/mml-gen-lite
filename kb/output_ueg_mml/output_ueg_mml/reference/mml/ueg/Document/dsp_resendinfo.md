# 查询重发信息(DSP RESENDINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询重发消息的信息:

- 若需要查询所有模块的重发队列信息，请不要输入任何参数。
- 若需要查询某个模块的重发队列信息，请输入参数“模块号”，其他参数不输入。
- 若需要查询某个用户的所有重发信息，请输入参数“用户标识类型”和“用户标识”，其他参数不输入。

## 注意事项

- “用户标识类型”和“用户标识”两个参数必须同时输入或同时不输入。
- “模块号”一定不能与“用户标识类型”或“用户标识”同时存在。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                |
|:-----------|:-------|:--------------------------------------------------------------------|
| MID        | 模块号    | 用于标识需要查询重发信息的CCU模块号。该参数必须先通过ADD MODULE命令定义才能在此处引用。                  |
| USERIDTYPE | 用户标识类型 | 用于标识需要查询重发信息的用户标识类型。 取值范围：IMSI：用户标识是IMSI。MSISDN：用户标识是MSISDN。 默认值：无。 |
| USERID     | 用户标识   | 用于标识需要查询重发信息的用户标识。 取值范围：长度不超过127的字符串。 默认值：无。                        |

## 使用实例

1. 查询所有重发队列信息：

   ```
   DSP RESENDINFO:;
   ```

   ```
   %%DSP RESENDINFO:;%%
   RETCODE = 0 操作成功

   查询结果如下
   ------------
   模块号 最大队列长度 已经使用的队列长度 队列使用比率(%)

   70 1000 0 0.0000 
   62 1000 0 0.0000 
   (结果个数 = 2)

   --- END
   ```
2. 查询“模块号”为“70”的重发队列信息：

   ```
   DSP RESENDINFO: MID=70;
   ```

   ```
   %%DSP RESENDINFO: MID=70;%%
   RETCODE = 0 操作成功

   查询结果如下
   ------------
   模块号 = 70
   最大队列长度 = 1000
   已经使用的队列长度 = 0
   队列使用比率(%) = 0.0000
   (结果个数 = 1)

   --- END
   ```
3. 查询“用户标识类型”为“IMSI”，“用户标识”为“460011789005011”的用户的所有重发信息：

   ```
   DSP RESENDINFO: USERIDTYPE=IMSI, USERID="460011789005011";
   ```

   ```
   %%DSP RESENDINFO: USERIDTYPE=IMSI, USERID="460011789005011";%%
   RETCODE = 0 操作成功

   查询结果如下
   ------------
   模块号 用户标识 消息类型 对端地址

   62 460011789005011 CS_CLR 86514031
   62 460011789005011 UDCD 86514031
   (结果个数 = 2)

   --- END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义如表1所示。

| 输出项名称     | 输出项解释                                                                                                                                                                                                                                                 |
|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 模块号       | 用于返回查询重发信息的模块号。                                                                                                                                                                                                                                       |
| 最大队列长度    | 用于返回模块中所设置的重发队列的最大长度。                                                                                                                                                                                                                                 |
| 已经使用的队列长度 | 用于返回在重发消息时已经使用的队列长度。                                                                                                                                                                                                                                  |
| 队列使用比率    | 用于返回“已经使用的队列长度”在“最大队列长度”中所占的百分比。                                                                                                                                                                                                                      |
| 用户ID      | 用于返回要查询重发信息的用户标识。                                                                                                                                                                                                                                     |
| 消息类型      | 用于返回所查询的用户进行重发时的消息类型。 取值范围：CS_ISD：CS域的插入用户数据消息CS_DSD：CS域的删除用户数据消息CS_CLR：CS域的cancel消息PS_ISD：PS域的插入用户数据消息PS_DSD：PS域的删除用户数据消息PS_CLR：PS域的cancel消息S6a_IDR：S6a接口的下发用户数据消息S6a_CLR：S6a接口的cancel消息S6d_IDR：S6d接口的下发用户数据消息S6d_CLR：S6d接口的cancel消息UDCD：MAP的ADD通知消息 |
| 对端地址      | 用于返回重发消息发送的对端设备地址。                                                                                                                                                                                                                                    |
