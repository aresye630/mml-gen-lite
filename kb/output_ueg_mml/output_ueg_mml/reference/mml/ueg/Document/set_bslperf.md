# 设置SCTP基准负荷(SET BSLPERF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于在配置数据库中设置SCTP基准负荷，即设置链路和模块在SCTP层对业务数据的处理能力基准。

## 注意事项

- 在缺省的情况下，系统初始化的时候已经在配置数据库中预置了BSG模块和各种宽带链路的基准负荷，可以通过**LST BSLPERF**命令查询。
- 一般情况下不需要另外单独配置SCTP基准负荷，如果根据实际情况确实需要对BSG模块和各种宽带链路的基准负荷进行修改，请谨慎配置。
- 链路承载在BSG模块之上，且一个BSG模块可以承载一个或多个链路，所以使用本命令时，“链路的基准负荷”应小于等于“BSG基准负荷”。

## 参数说明

| 参数标识     | 参数名称         | 参数说明                                    |
|:---------|:-------------|:----------------------------------------|
| LNKLOAD  | 链路的基准负荷(PPS) | 用于设定链路的基准负荷。 取值范围： 100～65535 默认值： 无。    |
| BRDLOADC | BSG基准负荷(PPS) | 用于设定BSG模块的基准负荷。 取值范围： 100～65535 默认值： 无。 |

## 使用实例

设置SCTP基准负荷，“链路的基准负荷(PPS)”为“4000”，“BSG基准负荷(PPS)”为“5000”：

`SET BSLPERF: LNKLOAD=4000, BRDLOADC=5000;`
