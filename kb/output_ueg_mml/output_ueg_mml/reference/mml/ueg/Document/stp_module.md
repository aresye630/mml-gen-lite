## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为维护类命令，用于停止指定模块对应的进程。如果进程为主备进程，则停止主进程，备进程自动接管。

## 注意事项

- 模块通过停止模块命令被停止后，只能通过**STR MODULE**命令和**RST MODULE**命令的方式正常启动。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                |
|:-------|:-------|:----------------------------------------------------|
| MID    | 模块号    | 标识一条模块配置信息的关键字段，用于指定待停止的模块，该参数可以使用LST MODULE命令查询获得。 |

## 使用实例

停止业务进程。模块号为3。

**STP MODULE: MID=3;**

```
%%STP MODULE: MID=3;%%
RETCODE = 0  操作成功

操作结果如下
------------
        模块号  =  3
      模块类型  =  BSG
  模块应用类型  =  ALL
   主用Pod名称  =  FE_ENS_1
      模块名称  =  BSG29
    平台模块号  =  3205758978
      操作结果  =  成功
(结果个数 = 1)

---    END
```
