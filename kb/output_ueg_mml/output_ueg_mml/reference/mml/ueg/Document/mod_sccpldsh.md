# 修改SCCP目的负荷分担信令点(MOD SCCPLDSH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于对配置数据库中的一条SCCP目的负荷分担信令点数据记录的某些参数进行修改或调整。在该命令中，系统通过“DSP名称”参数来唯一标识一条SCCP目的负荷分担信令点数据记录。

## 注意事项

- SCCP目的信令点和负荷分担目的信令点必须先在MTP DSP表或M3UA DE表中配置（由本局与目的信令点之间的信令承载方式决定配置在哪个数据表中）。通过**LST N7DSP**或**LST M3DE**命令，可分别查看上述数据表中的配置信息。
- 该命令不允许进行批操作。

| DPNM   | DSP名称        | 该参数是标识一条SCCP目的负荷分担信令点数据记录的关键字段（其取值不能被修改），用于指定需要对哪一条SCCP目的负荷分担信令点数据记录的参数进行修改或调整，操作员可以使用LST SCCPLDSH命令查询获得。 取值范围：长度不超过32的字符串。 默认值：无。 说明：无。                                                                                                                                                                                                                       |
| LSDP1  | 1号负荷分担信令点名称  | 对应于上述SCCP目的信令点，用于指定其互助的SCCP目的信令点的名称，该参数必须先由ADD SCCPDSP命令定义，然后才能在此处索引。 需要指出的是，配置负荷分担信令点时，需要从1号负荷分担信令点开始依次配置，不可以间隔配置。 取值范围：长度不超过32的字符串。 默认值：无。 说明：无。                                                                                                                                                                                                             |
| PLSDP1 | 1号负荷分担信令点优先级 | 用于指定各负荷分担信令点的优先级。 取值范围：0～8。 默认值：无。 说明：该参数的配置原则是：若输入0：表示SCCP信令路由的互助功能采用负荷分担的方式。若操作员配置的优先级为0的负荷分担信令点有N个，则在正常情况下，每个负荷分担信令点承载的SCCP信令负荷为1/(N+1)。 若输入1～8：表示SCCP信令路由的互助功能采用主备用的方式。若操作员配置的优先级为1～8的负荷分担信令点有多个，则系统将首先按照优先级进行分组，优先级相同的信令点为一组，组内按平均百分比实现SCCP信令路由的负荷分担，组间则按优先级（数字越小、优先级越高）进行选择。对于优先级不同的信令点而言，只有当高优先级的信令点不可达时，本局才选择向低优先级的信令点发送SCCP信令消息，其余情况依此类推。 若不输入，则默认为0。 |

## 使用实例

1、修改SCCP负荷分担目的信令点，“DSP名称”为“DSP”，“1号负荷分担信令点对应的优先级”改为“0”：

```
MOD SCCPLDSH: DPNM="DSP", PLSDP1=0;
```

2、修改SCCP负荷分担目的信令点，“DSP名称”为“DSP”，“2号负荷分担信令点名称”改为“DSP2”，“对应的优先级”改为“1”，“3号负荷分担信令点名称”改为“DSP3”，“对应的优先级”改为“2”：

```
MOD SCCPLDSH: DPNM="DSP", LSDP2="DSP2", PLSDP2=1, LSDP3="DSP3", PLSDP3=2;
```
