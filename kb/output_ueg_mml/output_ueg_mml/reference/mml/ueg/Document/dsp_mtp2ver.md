# 显示MTP2软件版本(DSP MTP2VER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于请求系统显示指定MTP2协议的版本信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                      |
|:-------|:-------|:----------------------------------------------------------|
| MN     | 模块号    | 用于请求系统显示哪个BSG模块号内MTP2协议的版本信息。 取值范围： 1～1023 默认值： 无。 说明： 无。 |

## 使用实例

用来显示模块号为10的MTP2VER信息。

`DSP MTP2VER: MN=10;`

```
%%DSP MTP2VER: MN=10;%%
RETCODE = 0  操作成功。

MTP2版本
------------
MTP版本  =  CGA MTPdrv Current Verison : V100R002C01B01c 20081015142909
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称    | 输出结果解释           |
|:---------|:-----------------|
| MTP2软件版本 | 用于返回MTP2协议的版本信息。 |
