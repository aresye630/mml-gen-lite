# 分析业务异常日志(EXC LOGAS)

## 命令功能

**须知** 

执行该命令会导致OMU虚拟机CPU占用率由平均15%上升至25%左右，峰值可能会达30%，影响时长约为两分多钟，建议于话务量低时执行。执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对业务异常日志进行分析，支持针对输入参数对日志进行筛选，并以文件形式输出结果内容。

## 注意事项

- UDM同时只能运行一次该命令，若重复执行则系统返回错误。
- 执行命令时UDM会预判断剩余磁盘空间是否充足（10G以上剩余空间），空间不足则系统返回失败。
- 该命令只能分析当前主OMU Pod上的业务异常日志。
- 执行该命令会导致OMU Pod的CPU占用率由平均15%上升至25%左右，峰值可能会达30%，影响时长约为两分多钟，建议于话务量低时执行。
- 该命令不允许进行批操作。
