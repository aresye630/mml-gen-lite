# 查询NP配置对象参数(LST NPPARA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询NP配置对象参数。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                    |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------|
| PTYPE  | 参数值标识  | 用于标识NP配置对象参数的值是否被修改。 取值范围：ALL(所有软参)：所有的参数。MODIFIED(被修改的软参)：参数值被修改，与其默认值不一致。UNMODIFIED(没有被修改的软参)：参数值未被修改，与其默认值一致。 默认值：无。 |

## 使用实例

1. 查询全部NP配置对象参数的信息。“参数值标识”为“ALL(ALL)”

   ```
   LST NPPARA: PTYPE=ALL;
   ```

   ```
   %%LST NPPARA: PTYPE=ALL;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    携转软参名称                                              软参值  参数默认值  参数值标识      

    位置更新重试次数                                          2       1           被修改的软参    
    位置更新时间间隔                                          20      20          没有被修改的软参
    Cancel后的位置更新间隔                                    5       5           没有被修改的软参
    每秒位置更新请求数量                                      100     100         没有被修改的软参
    短消息转发失败重试次数                                    2       2           没有被修改的软参
    SMPP查询消息的时间间隔                                    1       1           没有被修改的软参
    SMPP Session有效期                                        30      30          没有被修改的软参
    SMPP 响应消息超时时长                                     25      25          没有被修改的软参
    每秒处理短消息个数                                        0       0           没有被修改的软参
    周期位置更新周期                                          12      12          没有被修改的软参
    超时短信回执处理方式                                      0       0           没有被修改的软参
    MESSAGEID采用十六进制字符串                               0       0           没有被修改的软参
    同一个PAU模块同一个短信互通网关用户名的最大链路限制数     2       2           没有被修改的软参
    增强SMPP链路管理方式                                      0       0           没有被修改的软参

   (结果个数 = 14)

   ---    END
   ```
2. 查询默认值被修改的NP配置对象参数。“参数值标识”为“MODIFIED(MODIFIED)”

   ```
   LST NPPARA: PTYPE=MODIFIED;
   ```

   ```
   %%LST NPPARA: PTYPE=MODIFIED;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   携转软参名称  =  位置更新重试次数
         软参值  =  2
     参数默认值  =  1
     参数值标识  =  被修改的软参
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

| 输出项名称   | 输出项解释                  |
|:--------|:-----------------------|
| 携转软参名称  | 用于返回NP配置对象的软参名称 。      |
| 软参值     | 用于返回NP配置对象的软参值。        |
| 参数默认值   | 用于返回NP配置对象的软参默认值。      |
| 参数值标识   | 用于返回NP配置对象的软参默认值是否被修改。 |
