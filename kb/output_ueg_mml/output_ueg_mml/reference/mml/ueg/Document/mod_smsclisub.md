# 修改短信互通网关用户(MOD SMSCLISUB)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成短消息业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改短信互通网关用户的用户密码。该命令中，系统通过以下关键参数的组合来唯一标识一个短信互通网关用户信息：

- “用户名称”
- “当前密码”

## 注意事项

- 在号码携带业务发放数据配置中，若随意修改该配置，会造成短信互通网关无法给用户下发短消息，请谨慎操作。
- “新密码”参数和“当前密码”参数不能相同，“确认密码”参数和“新密码”参数必须同时输入且相同。
- 该命令不允许进行批操作。
- SMPP（Short Message Peer to Peer）3.4标准中定义的用户名长度最大为15位、密码长度最大为8位。
- 当前版本不支持此功能，执行该命令后会返回错误码：335607 暂不支持该功能。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UNAME   | 用户名称   | 标识一条短信互通网关用户数据记录的关键字段，用于指定需要对哪一条短信互通网关用户数据记录的参数进行修改，操作员可以使用LST SMSCLISUB命令查询获得。                                                                                                                                                                                                                                                                                                                                                        |
| CURPWD  | 当前密码   | 用于标识短信互通网关用户当前的密码。 取值范围：6～10位的字符串。 默认值：无 配置原则：密码区分大小写，其复杂度需同时满足下列条件：密码必须至少包含以下四个类别中的三类：英文大写字母英文小写字母数字：0～9特殊字符：~ ! # % ^ * ( ) _ - + [ ] { } | < > . ? 不允许使用三个或三个以上连续的字母或数字（例如：ABC、123）。密码不能和帐号或者帐号的逆序一样。不允许使用三个或三个以上连续的相同字符（例如：AAA）。如果MOD INSP命令中将“软件参数类型”为“HSS9860”的“PWD_COMP_SWITCH（密码兼容开关）”参数设为“0”，则密码长度不能少于8位字符。如果MOD INSP命令中将“软件参数类型”为“HSS9860”的“PWD_COMP_SWITCH（密码兼容开关）”参数设为“1”，则密码长度不能少于6位字符。密码的第一个字符必须是字母。 符合要求的密码，如：a1B2#3c4。 |
| NEWPWD  | 新密码    | 用于标识短信互通网关用户新修改的密码。该参数的配置原则请参看“当前密码”的配置原则。 取值范围：6～8位的字符串。 默认值：无                                                                                                                                                                                                                                                                                                                                                                        |
| PWDCNFM | 确认密码   | 用于标识确认密码。确认密码用于和新密码比对，确认两者是否相同。 取值范围：6～8位的字符串。 默认值：无                                                                                                                                                                                                                                                                                                                                                                                   |

## 使用实例

修改短信互通网关用户的用户密码，其中“用户名称”为“username1”，“当前密码”为“a1B2#3d4”，“新密码”为“A2b2#4d3”。命令如下：

MOD SMSCLISUB: UNAME="username1", CURPWD="\*\*\*\*\*", NEWPWD="\*\*\*\*\*", PWDCNFM="\*\*\*\*\*";

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 352045 | 用户不存在               | “用户名称”参数指定的用户不存在。       | 使用LST SMSCLISUB命令查询后，重新确认要修改哪个用户对应的数据记录。 |
| 352046 | 当前密码错误              | “用户名称”对应的“当前密码”参数输入不正确。 | 请确认输入正确的“当前密码”。如有需要请联系华为技术支持。            |
| 352054 | 参数取值无效：该密码的设定不符合要求。 | “新密码”参数输入不符合取值范围。       | 根据实际情况，重新输入“新密码”，确保其取值符合取值范围。            |
| 352056 | 密码与确认密码必须相同         | 输入的“新密码”和“确认密码”参数不相同。   | 根据实际情况，重新输入“新密码”和“确认密码”参数，确保其取值相同。       |
| 352057 | 密码与确认密码必须同时输入       | “新密码”和“确认密码”参数没有同时输入。   | 根据实际情况，重新输入“新密码”和“确认密码”参数，确保其全部输入。       |
| 352058 | 新旧密码不能相同            | 输入的“当前密码”和“新密码”参数相同。    | 根据实际情况，重新输入“当前密码”和“新密码”参数，确保其取值不相同。      |
