# 查询HSS实体的配置信息(LST HSS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询HSS实体数据的配置信息：

- 若需要查询全部HSS实体数据记录的信息，请不要输入任何参数。
- 若需要查询某条HSS实体数据记录的详细信息，请输入“实体名称”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                      |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| EN     | 实体名称   | 用于指示系统需要按照哪个“实体名称”来查询HSS实体数据的配置信息；若不输入，则表示所有的HSS“实体名称”。 取值范围：长度不超过127的字符串 默认值：无。                                                                                                                                                                                          |
| DN     | 域名     | 用于指示系统需要按照哪个“域名”来查询HSS实体数据的配置信息；若不输入，则表示所有的HSS“域名”。该参数的配置原则是： 所有字符只能是数字（0～9）、字母（a～z或A～Z）、“.”或“-”。 首字符必须是数字（0～9）或字母（a～z或A～Z）。 任意两个“.”或“-”不允许相邻。 最后一个字符不允许是“-”。 最后一个“.”后面的第一个字符必须为字母（a～z或A～Z）。例如“huawei.com”中的最后一个“.”后面的字符串“com”的第一个字符必须为字母。 取值范围：长度不超过127的字符串 默认值：无。       |
| HN     | 主机名    | 用于指示系统需要按照哪个“主机名”来查询HSS实体数据的配置信息；若不输入，则表示所有的HSS“主机名”。该参数的配置原则是： 所有字符只能是数字（0-9）、字母（a～z或A～Z）、“.”或“-”。 首字符必须是数字（0～9）或字母（a～z或A～Z）。 任意两个“.”或“-”不允许相邻。 最后一个字符不允许是“-”。 最后一个“.”后面的第一个字符必须为字母（a～z或A～Z）。例如“hss.huawei.com”中的最后一个“.”后面的字符串“com”的第一个字符必须为字母。 取值范围：长度不超过127的字符串 默认值：无。 |

## 使用实例

1. 查询所有HSS设备的配置信息：

   ```
   LST HSS:;
   ```

   ```
   %%LST HSS:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    实体名称  域名        主机名           HSS索引  默认本端实体

    HSS1      huawei.com  hss1.huawei.com  0        是          
    HSS2      huawei.com  hss2.huawei.com  1        否          
    HSS3      huawei.com  hss3.huawei.com  2        否          
   (结果个数 = 3)

   ---    END
   ```
2. 查询“实体名称”为“HSS1”的设备的配置信息：

   ```
   LST HSS: EN="HSS1";
   ```

   ```
   %%LST HSS: EN="HSS1";%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
       实体名称  =  HSS1
           域名  =  huawei.com
         主机名  =  hss1.huawei.com
        HSS索引  =  0
   默认本端实体  =  是
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

以下列出的是未包含在本命令参数说明中的输出项，其他输出项的详细说明请参见本命令的参数说明。

| 输出项名称   | 输出项解释                                                                                                                                                                                                               |
|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HSS索引   | 用于在配置数据库中定义一条HSS设备数据记录索引，该索引仅供内部使用，无实际含义。                                                                                                                                                                           |
| 默认本端实体  | 用于返回是否为默认本端实体。只有一条记录时该参数显示为“是”。有多条记录时该参数的值取决于LST DMLE命令查询的“默认本端实体”参数的值：当LST DMLE命令查询的“默认本端实体”参数的值不都为“否”时，该参数的值与LST DMLE命令查询的“默认本端实体”参数的值保持一致。当LST DMLE命令查询的“默认本端实体”参数取值都为“否”时，则将本命令“HSS索引”参数最小的一条记录的该参数显示为“是”，其余为否。 |
