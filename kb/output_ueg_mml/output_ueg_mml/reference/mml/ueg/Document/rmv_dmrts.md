# 删除Diameter路由组(RMV DMRTS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于从Diameter路由组表中删除一条Diameter路由组记录。

## 注意事项

- 若该Diameter路由组被**ADD DMRT**命令引用，则该Diameter路由组不能被删除。如果要删除该Diameter路由组配置，必须先执行**RMV DMRT**命令删除相关的Diameter路由配置。
- 路由组表中，“目标域名”为“default”的路由组不允许被删除。可使用**LST DMRTS**命令查看Diameter路由组的“目标域名”。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                      |
|:--------|:-------|:--------------------------------------------------------------------------|
| RTSNAME | 路由组名称  | 标识一条Diameter路由组数据记录的关键字段，用于指定删除哪一条Diameter路由组数据记录，操作员可以使用LST DMRTS命令查询获得。 |

## 使用实例

从Diameter路由组表中删除一条Diameter路由组记录。“路由组名称”为“TEST\_RT”。

```
RMV DMRTS: RTSNAME="TEST_RT";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释                                        | 原因分析                            | 处理建议                                                                                     |
|-------:|:--------------------------------------------|:--------------------------------|:-----------------------------------------------------------------------------------------|
| 299505 | 指定的DMRTS对象不存在。请执行LST DMRTS查看已经存在的DMRTS对象。   | 输入的“路由组名称”参数不存在。                | 根据实际情况，重新输入“路由组名称”参数的取值，确保其取值在系统中存在。已存在的“路由组名称”参数可以执行LST DMRTS命令查询。                      |
| 299516 | 默认路由组不允许删除。                                 | 输入的“路由组名称”参数对应的路由组是默认路由组，不允许删除。 | 根据实际情况，重新输入“路由组名称”参数的取值，确保该路由组不是默认路由组。默认路由组可以执行LST DMRTS命令查询。                            |
| 336061 | 指定的DMRTS已经配置了DMRT记录。请执行LST DMRT查看存在的DMRT记录。 | 输入的“路由组名称”参数对应的路由组已经配置了路由。      | 根据实际情况，重新输入“路由组名称”参数的取值，确保其对应的路由组没有配置路由。已配置路由的路由组可以执行LST DMRT命令查询。如果需要删路由可以执行RMV DMRT命令。 |
