# 查询队列流控状态(DSP FCSTATUS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于请求系统显示指定模块类型对应模块号的队列流控统计信息，使操作员了解当前队列流控统计信息，更好的指导操作员根据实际情况进行网络优化和扩容，提高系统处理业务请求的能力，保证高峰期系统正常进行业务。

## 注意事项

当返回的流控状态为关闭时，查询出来的信息参数值无参考意义。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                          |
|:-------|:-------|:------------------------------------------------------------------------------|
| MT     | 模块类型   | 用于请求系统显示哪种模块类型的队列流控统计信息。 取值范围： CCU(CCU)：呼叫控制单元模块。ACF(ACF)：鉴权/认证控制单元模块。 默认值：无。 |
| MID    | 模块号    | 用于请求系统显示哪个模块号的队列流控统计信息；若不输入，则表示所有的模块号。 取值范围：1～1023 默认值：无。                     |

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称             | 输出项解释                                                                                        |
|:------------------|:---------------------------------------------------------------------------------------------|
| 流控状态              | 用于返回模块的流控状态。 取值说明：未起控起控关闭 说明：当返回的流控状态为关闭时，则表示MOD QFCCFG命令中的队列流控功能未打开（即“队列流控策略”参数取值为“CLOSE”）。 |
| 消息类型              | 用于返回队列流控的消息类型。                                                                               |
| 消息队列长度            | 用于返回消息队列长度，单位为“条”。                                                                           |
| 放行业务量             | 用于返回CGP放行的业务消息数量，单位为“条”。                                                                     |
| 流控拒绝业务量           | 用于返回CGP流控的业务消息数量，单位为“条”。                                                                     |
| 当前周期消息放行比例（%）     | 用于返回当前周期内消息的放行比例。                                                                            |
| 当前的MAP自动机的个数      | 当前周期的MAP自动机个数。                                                                               |
| 当前的Diameter自动机的个数 | 当前周期的Diameter自动机的个数。                                                                         |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释                            | 原因分析                  | 处理建议                                                  |
|-------:|:---------------------------------|:----------------------|:------------------------------------------------------|
|    100 | 模块%d不存在或者输入的范围不对  说明： “%d”表示模块号。 | 输入的模块号不存在。            | 通过LST MODULE命令查询数据库中的模块，确保模块存在于数据库中。                  |
| 100016 | 参数的值不在指定范围内。                     | 报错的参数值不在取值范围内。        | 请根据报错的参数取值范围，重新输入正确的参数值后重新执行本命令。                      |
|     27 | 模块号错误或异常                         | 指定“模块号”与对应的“模块类型”不匹配。 | 先执行LST MODULE命令查询已存在的模块，输入正确的“模块号”和“模块类型”参数后，重新执行本命令。 |
