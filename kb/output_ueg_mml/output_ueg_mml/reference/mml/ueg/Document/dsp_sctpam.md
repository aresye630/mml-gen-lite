# 显示SCTP偶联信息(DSP SCTPAM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于请求系统显示指定SCTP协议的偶联基本管理信息，例如本端和对端端口号，对端IP地址及其状态，偶连创建时间等信息，这些信息是有效且很少改变的。

## 注意事项

此命令主要用于查询，但当偶联出现问题，则需要优化网络状态下的基本SCTP配置，如调整重传超时时间RTO（Retransmission Time-Out）的值或调整关联发送缓冲和接收缓冲的大小。

## 参数说明

| 参数ID   | 参数名称   | 参数描述                                                                                 |
|:-------|:-------|:-------------------------------------------------------------------------------------|
| MN     | 模块号    | 用于请求系统显示哪个BSG模块内SCTP偶联的基本信息。 取值范围：1～1023 默认值： 无。 说明： 无。                              |
| AID    | 偶联号    | 用于请求系统显示哪个偶联号的SCTP偶联信息。使用命令DSP M3LNK查询获得M3UA链路的SCTP偶联号。 取值范围： 0～65535 默认值： 无。 说明： 无。 |

## 使用实例

显示SCTP偶联信息，BSG模块号为241，偶联号为46：

```
DSP SCTPAM: MN=241, AID=46;
```
