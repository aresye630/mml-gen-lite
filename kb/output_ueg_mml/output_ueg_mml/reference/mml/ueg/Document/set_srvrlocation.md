# 设置应用类型远端Location信息(SET SRVRLOCATION)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当可能会影响本端网元设备与远端网元设备进行通信，导致业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于按应用类型设置远端网元的优先级，以满足同一个网元下不同的应用类型按照不同的优先级访问USCDB网元的数据。

## 注意事项

- 执行**SET GROUPSWITCH**命令打开FE侧业务分组功能后，才允许通过“SET SRVRLOCATION”命令按照应用设置远端Location优先级，否则返回分组开关未打开。
- 通过“SET SRVRLOCATION”命令修改对应的应用远端Location优先级时，需要确认应用类型和远端Location存在才允许执行修改，否则返回对应类型或远端Location不存在。

## 参数说明

| 参数标识        | 参数名称         | 参数说明                                                                                                                       |
|:------------|:-------------|:---------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 业务类型         | 用于定义FE存在多应用的场景下，本端网元的某种业务类型。 取值范围：长度不超过128的字符串。 默认值：无。                                                                     |
| RLOCID      | 远端Location标识 | 用于指定本端网元设备对应的远端网元设备的Location标识。 一个远端Location标识唯一对应一个远端网元，该此参数可通过执行LST RLOCATION获得。 取值范围：1～512。 默认值：无。                      |
| LP          | 位置ID优先级      | 用于指定远端网元设备Location优先级。 该参数的配置原则是：设置的优先级值越小，则其优先级越高。如果一个本端网元设备对应多个远端网元设备，则本端网元会按照优先级从高到低的顺序选择远端网元设备进行访问。 取值范围：1～512。 默认值：无。 |

## 使用实例

```
配置“业务类型”为“SUP-FE”的“远端Location标识”为“1”的优先级为“1”：
SET SRVRLOCATION: SERVICETYPE="SUP-FE", RLOCID=1, LP=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                         | 原因分析                       | 处理建议                                                            |
|-------:|:------------------------------|:---------------------------|:----------------------------------------------------------------|
| 302532 | 输入的业务类型不属于业务分组内，请输入正确的业务类型参数。 | 参数“业务类型”错误。                | 通过LST SERVICEGROUP命令查询已配置的业务类型，并正确输入业务分组的业务类型参数。                |
| 302003 | 远端Location不存在。                | 参数“远端Location标识”错误。        | 通过LST RLOCATION命令查询已配置的远端Location，并正确填写，然后重新执行命令。               |
| 302580 | 业务分组功能未打开。                    | 分组开关未打开。                   | 通过SET GROUPSWITCH命令打开业务分组功能，然后重新执行命令。                           |
| 301251 | 远端Location中该网元类型已经存在相同的优先级。   | 远端Location优先级未发生变更。        | 通过LST SRVRLOCATION命令查询该业务类型下此远端Location的优先级，然后输入不同的优先级，重新执行命令。  |
| 302577 | 该业务类型已经存在相同优先级的远端Location     | 该业务类型已经存在相同优先级的远端Location。 | 通过LST SRVRLOCATION命令查询该业务类型下所有远端Location的优先级，然后输入不同的优先级，重新执行命令。 |
