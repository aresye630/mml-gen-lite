# 查询DSG路由目的Location(DSP DSGROUTING)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于请求系统显示目前FE网元的各DSG模块发送消息的目的Location。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                             |
|:-------|:-------|:-------------------------------------------------|
| MID    | DSG模块号 | 用于请求系统显示哪个DSG模块发送消息的目的Location；若不输入，则表示所有的DSG模块。 |

## 使用实例

查询所有DSG模块发送消息的目的Location。

```
DSP DSGROUTING:;
```

```
RETCODE = 0  操作成功

操作结果如下
------------
 DSG模块号  目的Location标识  最高优先级Location标识  业务类型  操作结果

 1          335               335                     SUP-FE    操作成功
 2          335               335                     SUP-FE    操作成功
(结果个数 = 2)

---    END
```

## 输出结果说明

| 输出项名称           | 输出结果解释                            |
|:----------------|:----------------------------------|
| DSG模块号          | 用于返回DSG模块的标识。                     |
| 目的Location标识    | 用于返回目前DSG消息发送的Location。           |
| 最高优先级Location标识 | 用于返回FE DSG发现的当前状态正常的高优先级Location。 |
| 业务类型            | 用于返回业务类型。                         |
| 操作结果            | 表示返回执行的操作结果。                      |
