# 查询GSID业务属性数据(LST ASATTRIBUTE)

- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询GSID业务属性数据：

- 若需要查询某条GSID的配置信息，请输入“索引”参数。
- 若需要查询所有的GSID配置信息，请不要输入任何参数。

  **说明** 

  该命令仅在Full-stack虚机场景下支持。

## 注意事项

该命令组中的“请求URI”和“应用区分标识”参数不区分大小写，在执行该命令查询出的报文中为全小写形式。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                            |
|:-------|:-------|:----------------------------------------------------------------|
| ID     | 索引     | 用于指定系统需要按照哪个“索引”查询GSID业务属性数据记录。 取值范围：1～255。 默认值：无。 注意：该参数为可选参数。 |

## 使用实例

1. 查询全部GSID业务属性数据记录，执行命令如下：

   ```
   LST ASATTRIBUTE:;
   ```

   返回结果如下：

   ```
   %%LST ASATTRIBUTE:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    索引    URI存在  URI     AUID存在  应用区分标识                 GSID    AP认证和接入控制粒度  传递的用户标识类型

    1       是       test    否        NULL                         2       用户附着标识通过检查的AS可识别的应用授权用户             IMPU              
    2       是       123     是        simservs.ngn.etsi.org        2       用户附着标识通过检查的AS可识别的应用授权用户             IMPU              
   (结果个数 = 2)

   ---    END
   ```
2. 查询某条GSID业务属性数据记录，“索引”为“2”，执行命令如下：

   ```
   LST ASATTRIBUTE: ID=2;
   ```

   返回结果如下：

   ```
   %%LST ASATTRIBUTE: ID=2;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
                   索引  =  2
                URI存在  =  是
                    URI  =  123
               AUID存在  =  是
           应用区分标识  =  simservs.ngn.etsi.org
                   GSID  =  2
   AP认证和接入控制粒度  =  用户附着标识通过检查的AS可识别的应用授权用户
     传递的用户标识类型  =  IMPU
   (结果个数 = 1)

   ---    END
   ```
