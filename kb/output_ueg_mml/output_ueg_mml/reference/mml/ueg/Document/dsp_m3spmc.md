# 显示M3UA SPMC(DSP M3SPMC)

## 命令功能

该命令用于请求系统显示指定M3UA SPMC或DPC的状态信息。

- 信令点管理簇（SPMC）：以特定的网络外貌和特定信令点码在No.7信令网中表示的一组AS。简单认为是所有属于同一信令点（SP）的AS的集合，用于描述一个SP的状态。SPMC是为了支持SG的MTP3管理程序，用于汇聚分布在IP域的No.7信令目的地点码的可用性/拥塞/用户部分状态。在某些情况，SG自身也可以是SPMC的成员，所以，在考虑支持MTP3管理动作时，还必须考虑SG的可用性/拥塞/用户部分状态。
- 目的信令点编码（DPC）：用于指定对端局在相应信令网中的信令点编码。一般情况下，一个局向只需要配置一个目的信令点；当对端局采用多信令点编码时，一个局向最多可以配置16个属于同一网络标识的目的信令点编码。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                                     |
|:-------|:----------|:-----------------------------------------------------------------------------------------|
| MN     | BSG模块号    | 用于请求系统显示哪个模块内M3UA SPMC或DPC的状态信息。 取值范围：1～1023 默认值：无。                                      |
| NI     | 网络指示      | 用于请求系统显示哪个信令网内M3UA SPMC或DPC的状态信息。 取值范围：INT(国际主用网)INTB(国际备用网)NAT(国内主用网)NATB(国内备用网) 默认值：无。 |
| OPC    | 本地实体信令点编码 | 用于请求系统显示哪个本局信令点的M3UA SPMC或DPC的状态信息。 取值范围：1～11位字符串。 默认值：无。                                |
| DPC    | 目的实体信令点编码 | 用于请求系统显示哪个目的信令点的M3UA SPMC或DPC的状态信息。 取值范围：1～11位字符串。 默认值：无。                                |

## 使用实例

显示M3UA SPMC或DPC，“模块号”为“1”，“网络指示”为“国内主用”，“源信令点编码”为“96”，“目的信令点编码”为“93”：

```
DSP M3SPMC: MN=1, NI=NAT, OPC="96", DPC="93";
```

```
%%DSP M3SPMC: MN=1, NI=NAT, OPC="96", DPC="93";%%

-----------------

    状态  =  可达
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出结果解释                                                                                                                                                                               |
|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 链路拥塞信息  | 用于返回M3UA链路的拥塞状态，实际反映的是SCTP的拥塞状况： 拥塞：表示该SCTP链路流量过大而产生拥塞。 未拥塞：表示该SCTP链路流量正常。                                                                                                           |
| 状态      | 用于返回当前M3UA SPMC或DPC的状态： 可达：表示该SPMC中至少还有一个M3UA目的实体处于可达状态。 不可达：表示该SPMC中所有的M3UA目的实体均处于不可达状态。 拥塞：表示该SPMC中所有的M3UA目的实体均处于拥塞状态。 受限：表示该SPMC中所有的M3UA目的实体均处于受限状态。 不存在：表示该SPMC中所有的M3UA目的实体均不存在。 |
