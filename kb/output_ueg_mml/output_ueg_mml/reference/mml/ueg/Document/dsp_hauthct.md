# 按照鉴权模式查询用户数(DSP HAUTHCT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行该命令会对性能有影响，建议在话务量低时执行。

该命令用于请求系统显示按照鉴权模式查询到的用户数。

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                 |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ATHSCHM | 鉴权模式   | 用于指定系统按照哪个鉴权模式进行用户数查询。若不输入，则表示所有鉴权模式对应的用户数。 取值说明： “Digest-AKAv1-MD5（AKA鉴权）”“HTTP_DIGEST_MD5（HDA鉴权）”“Early-IMS-Security（EIA鉴权）”“NASS-Bundled（NBA鉴权）”“Early-AKA-Security（EAA鉴权）”“Trusted_Access（TAA鉴权）”“SIP_DIGEST_MD5（SDA鉴权）”“CAVE_AKA（CAA鉴权）” 默认值：无。 |

## 使用实例

1. 按所有鉴权模式显示用户数量：

   ```
   DSP HAUTHCT:;
   ```

   ```
   %%DSP HAUTHCT:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    鉴权模式  IMPI的数量

    AKA鉴权   838       
    HDA鉴权   26        
    EIA鉴权   3         
    NBA鉴权   16        
    EAA鉴权   5         
    TAA鉴权   56        
    SDA鉴权   5         
    CAA鉴权   0         
   (结果个数 = 8)

   ---    END
   ```
2. 按“EAA鉴权”模式显示用户数量：

   ```
   DSP HAUTHCT: ATHSCHM=Early-AKA-Security;
   ```

   ```
   %%DSP HAUTHCT: ATHSCHM=Early-AKA-Security;%%
   RETCODE = 0  操作成功
   查询结果如下
   ------------
     鉴权模式  =  EAA鉴权
   IMPI的数量  =  0
   (结果个数 = 1)
   ---    END
   ```

## 输出结果说明

| 输出项名称   | 输出结果解释                |
|:--------|:----------------------|
| IMPI的数量 | 按照HSS用户的鉴权模式统计的对应用户数。 |
