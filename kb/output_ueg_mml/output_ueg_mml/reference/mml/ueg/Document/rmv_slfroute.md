# 删除SLF路由(RMV SLFROUTE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在配置数据库中删除一条SLF路由的数据记录。

**说明** 

该命令暂不支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                         |
|:-------|:-------|:---------------------------------------------|
| RTNAME | 路由名称   | 标识SLF路由的数据记录的关键字段，用于指定需要删除哪个“路由名称”对应的路由数据记录。 |

## 使用实例

删除一条SLF路由配置。“路由名称”为“SLFROUTENAME”：

`RMV SLFROUTE: RTNAME="SLFROUTENAME";`
