# 启动软参CRC校验(STR SPCRC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于校验OMU系统的软件参数，当软参配置的取值和软参实际生效的取值存在不一致，在系统周期性检测是否存在未生效软参时，上报“ALM-15076 系统软参修改未生效”告警。处理“ALM-15076 系统软参修改未生效”告警时，使用该命令检查未生效的软参，依次重启软参对应的模块。

## 注意事项

同一时刻只允许执行一条**STR SPCRC**命令。

## 参数说明

无。

## 使用实例

- 存在未生效的软参时，启动软参CRC校验。

  ```
  STR SPCRC;
  ```

  ```
  %%STR SPCRC:;%%
  RETCODE = 0  操作成功
  软参当前值和配置值不一致结果
  ----------------------------
   模块号  模块类型  软参类型  软参名称                   软参配置值  软参当前值
   203     CCU       HSS9860   SMPPLINK_MANAGER_ENHANCED  1           0         
   204     CCU       HSS9860   SMPPLINK_MANAGER_ENHANCED  1           0         
   208     CCU       HSS9860   SMPPLINK_MANAGER_ENHANCED  1           0         
   210     CCU       HSS9860   SMPPLINK_MANAGER_ENHANCED  1           0         
  (结果个数 = 4)
  ---    END
  ```
- 无未生效的软参时，启动软参CRC校验。

  ```
  STR SPCRC;
  ```

  ```
  %%STR SPCRC:;%%
  RETCODE = 0  操作成功

  没有查到响应的结果
  ---    END
  ```
- 全部模块无响应时，启动软参CRC校验。

  ```
  STR SPCRC;
  ```

  ```
  %%STR SPCRC:;%%
  RETCODE = 351003  操作超时

  ---    END
  ```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。输出结果说明如表1所示。

| 输出项名称   | 输出项解释                          |
|:--------|:-------------------------------|
| 模块号     | 表示当前CRC校验不一致记录对应的模块信息。         |
| 模块类型    | 表示当前CRC校验不一致记录对应的模块类型。         |
| 软参类型    | 表示当前CRC校验不一致记录对应的软参类型。         |
| 软参名称    | 表示当前CRC校验不一致记录对应的软参名称。         |
| 软参配置值   | 表示当前CRC校验不一致记录对应的软参在系统配置的软参取值。 |
| 软参当前值   | 表示当前CRC校验不一致记录对应软参生效的取值。       |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释   | 原因分析                | 处理建议                  |
|-------:|:--------|:--------------------|:----------------------|
| 351003 | 操作超时    | 可能原因为如下之一：网络故障链路故障  | 请参考对应告警帮助处理告警，再执行该命令。 |
| 351004 | 操作部分超时  | 可能原因为如下之一：模块未就绪模块故障 | 请参考对应告警帮助处理告警，再执行该命令。 |
