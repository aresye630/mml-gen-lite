# 查询外部AS设备的配置信息(LST SLFAS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询SLF设备侧的外部AS设备的配置信息：

- 若需要查询全部AS数据记录的信息，请不要输入任何参数。
- 若需要查询某条AS数据记录的详细信息，请输入“AS名称”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                  |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SLFN   | SLF名称  | 用于标识查询SLF的AS设备配置信息的SLF名称。 取值范围：1～127位字母或十进制数字组成的字符串 默认值：无。                                                                                                                                                                                                                                                                                                            |
| ASN    | AS名称   | 用于标识查询SLF的AS设备配置信息的AS名称。 取值范围：1～40位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                             |
| HN     | 主机名    | 用于标识查询SLF的AS设备配置信息的主机名。 取值范围：1～127位字母或字母与十进制数字（字母在前）组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                    |
| DN     | 域名     | 用于标识查询SLF的AS设备配置信息的域名。 取值范围：1～127位字母或字母与十进制数字（字母在前）组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                     |
| LNKMOD | 链路选择模式 | 用于标识查询SLF的AS设备配置信息的链路选择模式。 取值范围： SESSIONIDBASED(基于会话ID)：同一个会话的所有信令消息都在同一条链路上传输。多个会话的消息按照轮选的方式在多条链路负荷分担。 POLLING(轮询方式)：当配置多条链路，信令消息在每条链路上负荷分担。 AORS(主备方式)：在主备链路选择方式下，如果主链路故障，则将某条备用链路升为主链路。默认第0条链路为主链路，当第0条链路不可用时，会自动选择其他可用链路。 ACTIVE(激活方式)：根据链路的激活状态，从第0条开始选择第一条激活的链路，将信令消息发往该链路。 ACTIVEWITHPRI(基于优先级的激活方式)：基于优先级的激活方式。 POLLINGWITHPRI(基于优先级的轮询方式)：基于优先级的轮询方式。 默认值：无。 |

## 使用实例

1. 查询一个AS设备的配置信息，“AS名称”为“AS5”：

   ```
   LST SLFAS: ASN="AS5";
   ```

   ```
   %%LST SLFAS: ASN="AS5";%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
        SLF名称  =  SLF5
         AS名称  =  AS5
         主机名  =  as5.huawei.com
           域名  =  huawei.com
   链路选择模式  =  轮询方式
        SLF索引  =  5
         AS索引  =  7
   (结果个数 = 1)

   ---    END
   ```
2. 查询所有AS设备的配置信息：

   ```
   LST SLFAS: ;
   ```

   ```
   %%LST SLFAS: ;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    SLF名称  AS名称  主机名          域名        链路选择模式  SLF索引  AS索引

    SLF5     AS5     as5.huawei.com  huawei.com  轮询方式        5        7     
    SLF6     AS6     as6.huawei.com  huawei.com  轮询方式        4        6     
   (结果个数 = 2)

   ---    END
   ```
