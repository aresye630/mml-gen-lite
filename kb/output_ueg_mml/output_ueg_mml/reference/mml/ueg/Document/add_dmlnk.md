# 增加Diameter链路(ADD DMLNK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加一条UDM和对端网元通信的Diameter链路。

该命令使用场景：配置UDM通过Diameter信令与对端网元的对接数据时，通过**ADD DMLKS**命令增加了链路集后，需要通过本命令在链路集中增加Diameter链路，用于和对端网元通信。

在该命令中，以下关键参数需要与对端网元协商：

- 对端IP地址
- 对端备用IP地址
- 对端端口号

**说明** 

执行此命令增加链路后，链路会自动激活。

## 注意事项

- 当本命令中的“工作模式”参数为“CLIENT(客户端)”或“SERVER(服务器)”时，系统中每条链路由IP五元组唯一确定，IP五元组至少要有一个属性不同。当本命令中的“工作模式”参数为“SERVERMULTPORT(服务端多端口)”时，同一链路集下的链路由IP五元组唯一确定，IP五元组至少要有一个属性不同，不同链路集下链路的IP五元组可以重复。链路的IP五元组为：
  - 传输协议类型
  - IP地址名称1(IP地址名称2)
  - 本端端口号
  - 对端IP地址（对端备用IP地址）
  - 对端端口号
- 一个Diameter链路集中最多允许配置128条链路。
- 一个HSF模块最多允许配置128条链路。
- UDM最多支持配置1024条Diameter双归属链路。
- UDM最多支持256个IP地址用来和Diameter对端通信。
- 为保证各IPU（Interface Processing Unit）之间实现负载均衡，需要在HSF模块上配置多个IP。同时，在配置链路时需要将链路均分到多个IP上。
- 当本命令中的“工作模式”参数设为“SERVERMULTPORT(服务端多端口)”时：
  - 为避免与“SERVER(服务器)”工作模式链路的内部分发端口号及外部端口号（3868）重复，建议“本端端口号”的取值大于4892。
  - 如果“对端端口号”参数设为“0”，则对端网元可以任意配置其端口号。
  - 由于本端端口与HSF模块一一对应，为保证各HSF模块之间实现负载均衡，在配置链路时需要在多个HSF模块上配置不同的本端端口。同时，将对端的链路配置均分到多个本端端口上。
- 当“工作模式”参数设置为“SERVER(服务器)”或“SERVERMULTPORT(服务端多端口)”且“传输协议类型”参数设置为“SCTP(SCTP协议类型)”或“UDP(UDP协议类型)”时，同一“HSF模块号”上，不允许配置“本端端口号”相同而本端IP地址不完全相同的链路，详细配置要求请参见错误码“335714”。可通过**LST DMLNK**命令查询已配置的信息。
- HSF负荷分担场景下，当**MOD DIAMPP**命令的“Diameter协议参数名称”取值为“CHECKIMSLINKPORT(是否检查IMS链路端口)”并且“Diameter协议参数值”取值为“1”，则在增加Diameter链路时，以HSF所在的平面控制对端端口或者本端端口的奇偶性。
  - UDM网元做客户端时，HSF所在的平面检查本端端口的奇偶性。HSF所在平面为1，本端端口为奇数；HSF所在平面为0，本端端口为偶数。
  - UDM网元做服务端时，HSF所在的平面检查对端端口的奇偶性。HSF所在平面为1，对端端口为奇数；HSF所在平面为0，对端端口为偶数。对端在规划端口号时，需将奇数和偶数的端口个数规划均匀，否则将会导致链路分布不均，模块CPU负荷不均匀。
- 当本端有两个信令IP而对端只有1个信令IP时，优先考虑配置多条单路径链路，即链路中仅配置“IP地址名称1”和“对端IPV4地址”参数，或者“IP地址名称1”和“对端IPV6地址”参数。
- 当本端只有1个信令IP时，优先考虑扩容本端信令IP。如果无法扩容本端信令IP，而对端有两个IP时，优先考虑配置多条单路径链路，即链路中仅配置“IP地址名称1”和“对端IPV4地址”参数，或者“IP地址名称1”和“对端IPV6地址”参数。
- 通过**ADD IPADDR**命令配置IP地址，当“网关类型”取值为“BSG(BSG)”和“HSF(HSF)”且“BSG(BSG)”和“HSF(HSF)”之间共用IP时， Diameter和M3UA链路不允许配置相同的本端IP与和本端端口号。

## 使用实例

配置UDM通过Diameter信令与对端网元的对接数据时，需要执行以下步骤。

1. 使用**ADD DMLE**命令增加Diameter本端实体。

   ```
   ADD DMLE:EN="UDM",LOCTYPE=SAE-HSS,DN="huawei.com",HN="UDM.huawei.com";
   ```
2. 使用**ADD DMPE**命令增加Diameter对端实体。

   ```
   ADD DMPE:EN="MME",PEERTYPE=OTHER,HN="peer.huawei.com",PEPRI=15;
   ```
3. 使用**ADD DMLKS**命令增加Diameter链路集。

   ```
   ADD DMLKS:LINKSNAM="Diameter_sae",LOCALNAM="UDM",PEERNAM="MME",LNKMOD=ACTIVE;
   ```
4. 增加Diameter链路。“链路名称”为“HSS\_sae”，“Diameter链路集名称”为“Diameter\_sae”，“HSF模块号”为“3”，“传输协议类型”为“SCTP协议类型”，“工作模式”为“服务器”，“IP地址名称1”为“HSF”，“对端IP地址版本”为“IPV4”，“对端IPV4地址”为“10.5.24.55”，“对端端口号”为“8000”，“Diameter对端链路优先级”为“15”，“交叉路径是否可用”为“否”，“负荷是否监控”为“FALSE”。

   ```
   ADD DMLNK: LNKNAME="HSS_sae", LINKSNAM="Diameter_sae", HSFMID=3, PTYPE=SCTP, WMODE=SERVER, IPNAM1="HSF", PIPVER=IPV4, PIPV4="10.5.24.55", PPT=8000,LINKPRI=15,CROSSPATHFLAG=NO, LOADCHECK=FALSE;
   ```
