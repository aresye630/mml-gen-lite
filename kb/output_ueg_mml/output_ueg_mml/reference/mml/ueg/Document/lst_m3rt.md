# 查询M3UA路由(LST M3RT)

## 命令功能

该命令为配置类命令，用于在配置数据库中查询M3UA路由数据的配置信息：

- 若需要查询全部M3UA路由数据记录的概要信息，请不要输入任何参数。
- 若需要查询某些M3UA路由数据记录的详细信息，请输入相关参数或参数组合。

该命令的“目的实体名称”、“路由名称”、“链路集名称”参数支持模糊查询功能。模糊查询功能是指操作员在客户端输入查询参数时，对于字符串或BCD码类型的查询参数而言，如果操作员输入的是一个完整的字符串或BCD码，则表示系统将按照完全匹配的方式执行查询操作；如果操作员在输入的某个字符串或BCD码的末尾添加通配字符“%”，则表示系统将按照模糊匹配的方式执行查询操作。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数描述                                                                                                                                                                                                                                                                                                                                                                      |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DENM   | 目的实体名称 | 用于指示系统需要按照哪个目的实体名称来查询M3UA路由数据；若不输入，则表示所有的目的实体名称。 取值范围：长度不超过32的字符串。 默认值：无。 说明：配置原则是：该参数的值域范围为：数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、空格符、中文。 操作员只能在字符串或BCD码的末尾添加通配字符“%”，而不能在字符串或BCD码的前面、中间添加通配字符“%”。例如，“A市%”、“1390123%”是合法的输入，而“%A市”、“A市%区”、“%1390123”、“139%0123”均是不合法的输入。 如果某个命令同时存在有多个字符串或BCD码类型的查询参数，则操作员在一次查询操作中，只能对其中的一个查询参数使用模糊查询方式，而不能同时对两个或两个以上的查询参数使用模糊查询方式。 |
| RTNM   | 路由名称   | 用于指示系统需要按照哪个路由名称来查询M3UA路由数据；若不输入，则表示所有的路由名称。 取值范围：长度不超过32的字符串。 默认值：无。 说明： 此参数为可以联想的MOC对象。执行了ADD M3RT或者MOD M3RT之后参数值列表可以立刻更新，执行了RMV M3RT后，参数值列表1小时之内可以自动更新，如果要手动刷新，请单击右键，在弹出的菜单中选择“更新联想参数值”。                                                                                                                                                                               |
| LSNM   | 链路集名称  | 用于指示系统需要按照哪个链路集名称来查询M3UA路由数据；若不输入，则表示所有的链路集名称。 取值范围：长度不超过32的字符串。 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                             |

## 使用实例

1、查询本局M3UA路由：

```
LST M3RT:;
```

返回结果如下：

```
%%LST M3RT:;%%
RETCODE = 0  操作成功

到目的实体的所有M3UA路由
------------------------
 路由名称  目的实体名称  链路集名称  路由优先级  路由索引

 M3UA_RT   M3UA_DE     M3UA_LKS    0           0    
 STP       STP         STP         0           1    
(结果个数 = 2)

---    END
```

2、查询本局M3UA路由，“目的实体名称”为“M3UA\_RT”：

```
LST M3RT: DENM="M3UA_RT";
```

返回结果如下：

```
%%LST M3RT: DENM="M3UA_RT";%%
RETCODE = 0  操作成功

到目的实体的所有M3UA路由
------------------------
    路由名称  =  M3UA_RT
目的实体名称  =  M3UA_DE
  链路集名称  =  M3UA_LKS
  路由优先级  =  0
    路由索引  =  0
(结果个数 = 1)

---    END
```

3、查询本局名称前缀为“M3UA”的M3UA路由：

```
LST M3RT: DENM="M3UA%";
```

返回结果如下：

```
%%LST M3RT: DENM="M3UA%";%%
RETCODE = 0  操作成功

到目的实体的所有M3UA路由
------------------------
    路由名称  =  M3UA_RT
目的实体名称  =  M3UA_DE
  链路集名称  =  M3UA_LKS
  路由优先级  =  0
    路由索引  =  0
(结果个数 = 1)

---    END
```
