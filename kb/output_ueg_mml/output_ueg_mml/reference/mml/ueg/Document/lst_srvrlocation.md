# 查询应用类型远端Location信息(LST SRVRLOCATION)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询在FE侧配置的应用类型远端网元的优先级。

- 若需要查询全部应用类型远端网元的优先级，不需要输入参数。
- 若需要查询某个应用类型远端网元的优先级，请输入“业务类型”或其它参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称         | 参数说明                                                                                                                                             |
|:------------|:-------------|:-------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 业务类型         | 用于定义FE存在多应用的场景下，本端网元的某种业务类型。若不输入该参数，表示查询所有业务类型。 取值范围：长度不超过128的字符串。 默认值：无。                                                                        |
| RLOCID      | 远端Location标识 | 用于指定本端网元设备对应的远端网元设备的Location标识。若不输入该参数，表示查询所有远端Location标识。 一个远端Location标识唯一对应一个远端网元，该此参数可通过执行LST RLOCATION获得。 取值范围：1～512。 默认值：无。                 |
| LP          | 位置ID优先级      | 用于指定远端网元设备Location优先级。若不输入该参数，表示查询所有位置ID优先级。 该参数的配置原则是：设置的优先级值越小，则其优先级越高。如果一个本端网元设备对应多个远端网元设备，则本端网元会按照优先级从高到低的顺序选择远端网元设备进行访问。 取值范围：1～512。 默认值：无。 |

## 使用实例

```
查询全部应用类型远端Location的优先级：
LST SRVRLOCATION:;
```

```
%%LST SRVRLOCATION:;%%
RETCODE = 0  操作成功

操作结果如下
------------------------
 业务类型      远端Location标识    位置ID优先级   
 GU-HLR        5                   1     
 GU-HLR        6                   2     
(结果个数 = 2)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                         | 原因分析                | 处理建议                                              |
|-------:|:------------------------------|:--------------------|:--------------------------------------------------|
| 302532 | 输入的业务类型不属于业务分组内，请输入正确的业务类型参数。 | 参数“业务类型”错误。         | 通过LST SERVICEGROUP命令查询已配置的业务类型，并正确输入业务分组的业务类型参数。  |
| 302003 | 远端Location不存在。                | 参数“远端Location标识”错误。 | 通过LST RLOCATION命令查询已配置的远端location，并正确填写，然后重新执行命令。 |
