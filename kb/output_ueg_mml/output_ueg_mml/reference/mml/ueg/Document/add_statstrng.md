# 增加业务条件操作统计对象(ADD STATSTRNG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行该命令后同时增加业务条件统计任务会对性能有影响，建议在话务量低时执行。

该命令用于增加一个按照业务条件操作的统计对象。

该命令的使用场景：该命令仅限特定维护场景进行精细化指标分析时使用，比如对网上重大问题等进行故障定位、以及现网割接升级等工程操作时使用，在现网局点业务正常运行期间不开启应用（不配置统计对象）。创建业务条件操作统计对象数据后，可以通过对应的性能指标统计该测量对象的相关数据。

## 注意事项

- 统计功能会消耗较多系统资源，请在业务空闲时执行。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                |
|:----------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OBJECTID  | 统计对象ID | 用于表示统计对象ID，系统内唯一。 取值范围：“OBJECT1(OBJECT1)”～“OBJECT64(OBJECT64)” 默认值：无。                                                                                                                                                                                                                                                                                                                                                                               |
| TYPE      | 统计类型   | 用于表示统计对象的统计类型。 取值范围：“STAT_STRING_FORGT(按GT局向统计)”“STAT_PRE_FIX_FORGT(按前缀GT局向统计)”“STAT_REVERSE_FORGT(按STRING以外GT局向统计)”“STAT_PLMN(按PLMN统计)”“STAT_SRCODE(按SRCODE统计)”“STAT_DIAMHOST(按DIAMHOST统计)”“STAT_IMSHOST_FORREPSYNC(按IMSHOST统计透明数据同步消息)” 默认值：无。                                                                                                                                                                                                    |
| PARAMETER | 参数     | 用于表示统计参数的实际含义。 取值范围：“统计类型”为“STAT_STRING_FORGT(按GT局向统计)”，“STAT_PRE_FIX_FORGT(按前缀GT局向统计)”，“STAT_REVERSE_FORGT(按STRING以外GT局向统计)”时，“参数”是长度不超过15的数字字符串。“统计类型”为“STAT_PLMN(按PLMN统计)”时，“参数”是长度为5～6位的数字字符串。当长度为6时，第六个字符可以为‘F’。“统计类型”为“STAT_SRCODE(按SRCODE统计)”时，“参数”是由‘*’，‘#’，数字组成的长度不超过16的字符串。“统计类型”为“STAT_DIAMHOST(按DIAMHOST统计)”时，“参数”是由长度为1～127位的数字、字母、“_”、“.”和“@”组成字符串。“统计类型”为“STAT_IMSHOST_FORREPSYNC(按IMSHOST统计透明数据同步消息)”时，“参数”是由长度不超过127的字符串组成。 默认值：无。 |

## 使用实例

1. 系统运行过程中，由于业务需要，在系统中增加一个按照GT统计的业务条件操作统计对象。“统计对象ID”为“OBJECT1(OBJECT1)”，“统计类型”为“STAT\_STRING\_FORGT(按GT局向统计)”，“参数”为“6688541”：

   ```
   ADD STATSTRNG: OBJECTID=OBJECT1, TYPE=STAT_STRING_FORGT, PARAMETER="6688541";
   ```
2. 系统运行过程中，由于业务需要，在系统中增加一个按照主机名统计的业务条件操作统计对象。“统计对象ID”为“OBJECT2(OBJECT2)”，“统计类型”为“STAT\_PRE\_FIX\_FORGT(按前缀GT局向统计)”，“参数”为“98776”：

   ```
   ADD STATSTRNG: OBJECTID=OBJECT2, TYPE=STAT_PRE_FIX_FORGT, PARAMETER="98776";
   ```
3. 系统运行过程中，由于业务需要，在系统中增加一个按照GT码以外统计的业务条件操作统计对象。“统计对象ID”为“OBJECT3(OBJECT3)”，“统计类型”为“STAT\_REVERSE\_FORGT(按STRING以外GT局向统计)”，“参数”为“98777”：

   ```
   ADD STATSTRNG: OBJECTID=OBJECT3, TYPE=STAT_REVERSE_FORGT, PARAMETER="98777";
   ```
4. 系统运行过程中，由于业务需要，在系统中增加一个按照PLMNID统计的业务条件操作统计对象。“统计对象ID”为“OBJECT4(OBJECT4)”，“统计类型”为“STAT\_PLMN(按PLMN统计)”，“参数”为“98778”：

   ```
   ADD STATSTRNG: OBJECTID=OBJECT4, TYPE=STAT_PLMN, PARAMETER="98778";
   ```
5. 系统运行过程中，由于业务需要，在系统中增加一个按照SRCODE统计的业务条件操作统计对象。“统计对象ID”为“OBJECT5(OBJECT5)”，“统计类型”为“STAT\_SRCODE(按SRCODE统计)”，“参数”为“98779”：

   ```
   ADD STATSTRNG: OBJECTID=OBJECT5, TYPE=STAT_SRCODE, PARAMETER="98779";
   ```
6. 系统运行过程中，由于业务需要，在系统中增加一个按对端主机标识统计的业务条件操作统计对象。“统计对象ID”为“OBJECT6(OBJECT6)”，“统计类型”为“STAT\_DIAMHOST(按DIAMHOST统计)”，“参数”为“hw1@huawei.com”：

   ```
   ADD STATSTRNG: OBJECTID=OBJECT6, TYPE=STAT_DIAMHOST, PARAMETER="hw1@huawei.com";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                                                  | 原因分析                     | 处理建议                                              |
|-------:|:-----------------------------------------------------------------------|:-------------------------|:--------------------------------------------------|
| 335109 | 对象STATSTRNG已经存在                                                        | 已添加了一条相同“统计对象ID”的记录。     | 通过LST STATSTRNG命令查询已配置的所有业务条件操作统计对象，添加未使用的统计对象ID。 |
| 451553 | 参数取值无效：当参数TYPE的取值是STAT_DIAMHOST时，参数PARAMETER是由0~9，a-z，A-Z，@，.，_组合的字符串。 | 参数“统计类型”输入值不对，不在其取值范围之内。 | 根据实际情况,重新输入“参数”的值。                                |
