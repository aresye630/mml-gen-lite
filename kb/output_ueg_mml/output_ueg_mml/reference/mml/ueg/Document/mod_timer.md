# 修改定时器值(MOD TIMER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成系统运行异常从而影响用户业务运行，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于对配置数据库中的一条内部定时器数据记录的定时器值进行调整或修改。在该命令中，系统通过以下关键参数的组合来唯一标识一条定时器数据记录：

- “模块PID”
- “定时器索引”
- “定时器序号”

## 注意事项

- 不同的定时器，其允许修改的范围是不一样的。
- 只提供修改某些特定的定时器值。
- 需要重启所有CCU、ACF（仅虚机场景涉及）和BSG模块才能生效。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                  |
|:-------|:--------|:----------------------------------------------------------------------------------------------------------------------|
| MPID   | 模块 PID  | 标识一条定时器数据记录的关键字段之一，用于指定需要对哪一条定时器数据记录的参数进行修改或调整，操作员可以使用LST TIMER 命令查询获得。 说明：每个定时器的三个参数的取值是固定的，故针对于每个定时器，其对应的参数组合不能被修改。 |
| TMRIDX | 定时器索引   | 标识一条定时器数据记录的关键字段之一，用于指定需要对哪一条定时器数据记录的参数进行修改或调整，操作员可以使用LST TIMER 命令查询获得。 说明：每个定时器的三个参数的取值是固定的，故针对于每个定时器，其对应的参数组合不能被修改。 |
| TMRSEQ | 定时器序号   | 标识一条定时器数据记录的关键字段之一，用于指定需要对哪一条定时器数据记录的参数进行修改或调整，操作员可以使用LST TIMER 命令查询获得。 说明：每个定时器的三个参数的取值是固定的，故针对于每个定时器，其对应的参数组合不能被修改。 |
| TMRVAL | 定时器值(秒) | 用于指定定时器值，其取值范围为0～7200。                                                                                                |

## 使用实例

修改定时器值，“模块PID”为“257”，“定时器索引”为“0”，“定时器序号”为“1”，“定时器值”为“2”：

```
MOD TIMER: MPID=257, TMRIDX=0, TMRSEQ=1, TMRVAL=2;
```
