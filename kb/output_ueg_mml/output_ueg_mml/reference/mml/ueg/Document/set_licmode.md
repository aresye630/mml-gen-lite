# 设定License的工作模式(SET LICMODE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令在由独立HSS模式改造为融合模式时使用，用于设定License的工作模式。License模式发生变化后，需重新申请License。

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数ID    | 参数名称   | 参数描述                                                                                            |
|:--------|:-------|:------------------------------------------------------------------------------------------------|
| COMFLAG | 兼容模式   | 用于指定软件当前版本是否兼容旧版本的License。 取值范围： “OFF(关)”：不兼容。“ON(开)”：兼容。 默认值：无。                                |
| APPMODE | 应用模式   | 用于指定License文件应用模式。 取值范围： “USCMODE(USC模式)”：融合模式，使用USC模板。“IMSMODE(IMS模式)”：独立HSS模式，使用IMS模板。 默认值：无。 |

## 使用实例

设置License的工作模式，“应用模式”为“IMSMODE”：

`SET LICMODE: APPMODE=IMSMODE;`
