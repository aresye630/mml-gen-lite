# 修改队列流控配置信息(MOD QFCCFG)

## 命令功能

该命令为配置类命令，当系统出现不稳定时，如频繁的起流控，需要按照模块修改默认的队列流控参数信息，使系统恢复稳定。

业务首消息是流控的重点对象，需要放入相对优先级队列，通过**MOD QFCMQW**命令设置首消息业务类型的调度权重，即设置对应优先级队列的权重。系统针对不同业务消息按照其所在队列的权重优先级进行单位时间内的处理。当队列中首消息的放行量远小于首消息的增加量，即如果队列满则丢弃相应业务首消息，如果不满则放行，系统实现优先级自然溢出功能。

## 注意事项

系统初始化时会在数据库中增加如下两条队列流控配置信息，可以通过执行**LST QFCCFG**命令查询。查询报文如下所示：

```
%%LST QFCCFG:;%%
RETCODE = 0  操作成功

查询结果如下
------------
 模块类型  队列流控策略  最小首消息门限  最大中间消息门限

 CCU       关闭          7000            7500            
 ACF       关闭          7000            7500            
(结果个数 = 2)

---    END
```

## 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                                                                          |
|:--------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------|
| MT      | 模块类型     | 用于标识模块类型。 取值范围： CCU(CCU)：即呼叫控制单元模块。ACF(ACF)：即鉴权/认证控制单元模块。 默认值：无。                                                                              |
| QFCMODE | 队列流控策略   | 用于标识队列流控的策略。 取值范围： AUTO(自动)：开启队列流控功能时，无需设置系统最小允许放行的首消息数。CLOSE(关闭)：关闭队列流控功能。MANUAL(手动)：开启队列流控功能时，需要通过“最小首消息门限”参数设置系统指定允许放行的首消息数。 默认值：AUTO(自动)。 |
| WALMIN  | 最小首消息门限  | 仅当本命令中的“队列流控策略”参数选择为“MANUAL(手动)”时该参数有效。用于标识最小允许放行的首消息数。 取值范围：1～7500 默认值：7000。 说明：执行该命令并且不输入该参数时，系统会设置初始值“7000”。                               |
| WALMAX  | 最大中间消息门限 | 仅当本命令中的“队列流控策略”参数选择为“MANUAL(手动)”时该参数有效。用于标识最大允许放行的中间消息数。 取值范围：10～7500 默认值：7500。 说明：执行该命令并且不输入该参数时，系统会设置初始值“7500”。                             |

## 使用实例

1. 修改CCU模块的系统队列流控全局参数为自动状态。其携带参数如下：
   - “模块类型”为“CCU(CCU)”
   - “队列流控策略”为“AUTO(自动)”

   ```
   MOD QFCCFG: MT=CCU, QFCMODE=AUTO;
   ```
2. 关闭CCU模块的队列流控功能。其携带参数如下：
   - “模块类型”为“CCU(CCU)”
   - “队列流控策略”为“CLOSE(关闭)”

   ```
   MOD QFCCFG: MT=CCU, QFCMODE=CLOSE;
   ```
3. 修改CCU模块的系统队列流控全局参数为手动状态。其携带参数如下：
   - “模块类型”为“CCU(CCU)”
   - “队列流控策略”为“MANUAL(手动)”
   - “最小首消息门限”为“7500”
   - “最大中间消息门限”为“7000”

   ```
   MOD QFCCFG: MT=CCU, QFCMODE=MANUAL, WALMIN=7000, WALMAX=7500;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释              | 原因分析                                         | 处理建议                                    |
|-------:|:-------------------|:---------------------------------------------|:----------------------------------------|
| 260008 | 参数未修改，请至少指定一个修改参数。 | “模块类型”和“队列流控策略”参数指定的数据记录与数据库存储记录相比，没有任何修改变化。 | 使用LST QFCCFG命令查询后，重新输入需要修改的“模块类型”或其他参数。 |
