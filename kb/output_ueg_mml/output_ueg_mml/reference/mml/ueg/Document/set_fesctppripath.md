# 设置SCTP主用路径(SET FESCTPPRIPATH)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为维护类型命令，当主用路径不可达或需要切换SCTP双归属链路中路径优先级时，该命令用来手动设置SCTP主用路径。

## 注意事项

- 执行该命令可能会发生路径切换，操作员在使用此命令时应慎重。
- 本命令只支持平行路径设置SCTP主用路径。平行路径请参看命令**ADD M3LNK**。
- 该命令不允许进行批操作。
- 该命令仅适用于Diameter链路场景。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                |
|:----------|:-------|:--------------------------------------------------------------------|
| LINKNAME  | 链路名称   | 用于标识需要设置的SCTP主用路径所在的链路名称。 取值范围：长度不超过127的由字母、数字或特殊字符组成的字符串。 默认值：无。   |
| LINKSNAME | 链路集名称  | 用于标识需要设置的SCTP主用路径所在的链路集名称。 取值范围：长度不超过127的由字母、数字或特殊字符组成的字符串。 默认值：无。  |
| IPNAME    | IP地址名称 | 用于标识需要设置的SCTP主用路径的本端IP地址名称。 取值范围：长度不超过127的由字母、数字或特殊字符组成的字符串。 默认值：无。 |

## 使用实例

设置SCTP主用路，“链路名称”为“IMS.SCSCF.LNK”，“链路集名称”为“IMS.SCSCF.LKS”，“IP地址名称”为“BSG180”：

```
SET FESCTPPRIPATH: LINKNAME="IMS.SCSCF.LNK", LINKSNAME="IMS.SCSCF.LKS", IPNAME="BSG180";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释           | 原因分析                    | 处理建议                                              |
|-------:|:----------------|:------------------------|:--------------------------------------------------|
| 264022 | 指定的DMLNK对象不存在。  | 输入的参数“链路名称”或“链路集名称”不存在。 | 请重新输入参数“链路名称”或“链路集名称”，确保其存在。该参数可以通过命令LST DMLNK查询。 |
| 335427 | IP名称不存在。        | 输入的参数“IP地址名称”不存在。       | 请重新输入参数“IP地址名称”，确保其存在。该参数可以通过命令LST IPADDR查询。      |
| 335428 | 链路名称与IP地址名称不匹配。 | 输入的参数“链路名称”和“IP地址名称”匹配。 | 请重新输入参数“链路名称”和“IP地址名称”，确保其匹配。                     |
