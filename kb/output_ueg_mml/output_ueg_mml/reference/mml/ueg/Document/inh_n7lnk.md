# 管理禁止MTP链路(INH N7LNK)

- 参数说明

## 命令功能

该命令为维护类命令，用于请求系统对指定的MTP链路执行管理禁止操作（保持MTP连接、但禁止传递MTP用户层信令），其对应的恢复命令为**UIN N7LNK** 。

该命令仅适用于测试或维护的操作场景，当某MTP链路因传输误码率高、传输时延大等原因而出现频繁闪断现象时，对于该MTP链路而言，如果操作员仅希望在其上禁止传递MTP用户层信令、但希望在其上继续传递MTP管理信令，则操作员可以使用该命令实现这一目的。

在实际使用中， **INH N7LNK** 、**DEA N7LNK** 命令分别用于对MTP链路执行管理禁止、去激活操作，它们的主要差别是：

- 操作员在使用 **INH N7LNK** 命令，系统不允许操作员管理禁止链路集中所有的MTP链路。例如，某个链路集配置有10条MTP链路，则操作员最多只能管理禁止其中的9条MTP链路。
- 操作员在使用**DEA N7LNK** 命令，系统允许操作员去激活链路集中所有的MTP链路。例如，某个链路集配置有10条MTP链路，则操作员可以去激活全部的10条MTP链路。
- 在相应的MTP链路集中，如果操作员管理禁止了其中的几条MTP链路，当没有被管理禁止的MTP链路全部发生故障时，系统将自动对处于“本端管理禁止”状态的MTP链路执行解除管理禁止操作。
- 在相应的MTP链路集中，如果操作员去激活了其中的几条MTP链路，当没有被去激活的MTP链路全部发生故障时，系统将不能自动对处于“去激活”状态的MTP链路执行激活操作（此时需要人工执行**ACT N7LNK** 命令）。

## 注意事项

- UDM不支持该命令。
- 对于被管理禁止的MTP链路而言，执行该操作将导致其无法承载MTP用户层信令业务，其对系统运行的影响是：在相应的MTP链路集中，如果处于“本端管理禁止”状态的MTP链路数大于或等于2条，如果管理禁止其中的一条MTP链路，则其他MTP链路的负荷将加重，此时，系统运行的可靠性与稳定性将有一定程度的下降。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                      |
|:-------|:-------|:------------------------------------------------------------------------------------------|
| LNKNM  | 链路名称   | 标识一条MTP链路的关键字段，用于指示系统管理禁止哪一条MTP链路，操作员可以使用LST N7LNK 命令查询获得。 取值范围：1～32 位字符串 默认值：无。 说明：必选参数。 |

## 使用实例

管理禁止MTP链路，“链路名称”为“DD1”：

```
INH N7LNK: LNKNM="DD1";
```
