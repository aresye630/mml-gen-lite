# 删除Diameter对端实体(RMV DMPE)

## 命令功能

**须知** 

本命令属于高危命令，执行不当可能导致Diameter本端实体与对端实体间的业务中断，导致业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于从配置数据库中删除一条Diameter对端实体记录。

## 注意事项

- 删除对端实体前，请先执行**LST DMPE**查询对端是否为AS，若是AS请在“UDM业务管理”界面执行**LST HSYSTEMPARA**查看“ASIDMODE”参数取值，取值为“1”表示ASID和AS对端实体间的对应关系存储在OMU，删除前请先确认AS已废弃不再使用，才能执行该命令删除AS。
- 删除非AS类型的对端实体前，先通过**LST DMLKS**查询是否存在Diameter链路集，确认Diameter对端实体和UDM的对接方式：
  - 存在Diameter链路集，UDM和Diameter对端实体为直连方式。请先确认Diameter对端实体已废弃不再使用，再执行**RMV DMLNK**和**RMV DMLKS**命令删除相关的Diameter链路和链路集，然后才能执行该命令删除Diameter对端实体。
  - 不存在Diameter链路集，UDM和Diameter对端实体为转接方式，可执行该命令直接删除Diameter对端实体。

- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                          |
|:-------|:-------|:----------------------------------------------------------------------------------------------|
| EN     | 实体名称   | 可选必选说明：必选参数 参数含义：标识一条Diameter对端实体数据记录的关键字段，用于指定需要删除哪一条Diameter对端实体数据记录，操作员可以使用LST DMPE命令查询获得。 |

## 使用实例

删除Diameter对端实体。Diameter对端“实体名称”为“AS”。

```
RMV DMPE: EN="AS";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释                                 | 原因分析            | 处理建议                                                         |
|-------:|:-------------------------------------|:----------------|:-------------------------------------------------------------|
| 264007 | 指定的DMPE不存在。请执行LST DMPE查看已经存在的DMPE对象。 | 输入的“实体名称”参数不存在。 | 根据实际情况，重新输入参数，确保输入的“实体名称”参数已存在。已存在的“实体名称”参数可以执行LST DMPE命令查询。 |
