# 设置显式Diameter路由 (SET EXPDMRT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于设置显式Diameter路由。

- 如果对于同一个目的对端，同时配置了直连链路和非直连链路：
  - 如果未配置显式路由，则优先选择直连链路，即直连链路的优先级高于非直连链路。
  - 如果配置了显式路由，则优先选择非直连链路，即非直连链路的优先级高于直连链路。
- 同一个目的对端可以配置多个路由对端（当前最大支持10个），支持轮询和主备路由方式。主备方式下，根据添加路由对端的顺序确定优先级，顺序靠前的优先级高，即“路由对端名称1”参数对应的路由优先级最高。

## 注意事项

该命令的“路由对端名称1～10”参数所对应的路由必须属于“路由组名称”参数所对应的路由组。

## 使用实例

设置通过路由对端DRA转接到达目的对端MME的路由：

1. 增加Diameter对端实体，命令如下：

   ```
   ADD DMPE: EN="MME", PEERTYPE=OTHER, HN="huawei1.com";
   ADD DMPE: EN="DRA1", PEERTYPE=OTHER, HN="huawei2.com";
   ADD DMPE: EN="DRA2", PEERTYPE=OTHER, HN="huawei3.com";
   ```
2. 增加一个Diameter路由组，“路由组名称”为“DRA\_RT”，命令如下：

   ```
   ADD DMRTS: RTSNAME="DRA_RT", RN="huawei.com", APPID=S6A/S6D, SMODE=AORS;
   ```
3. 增加与“路由组名称”为“DRA\_RT”的Diameter路由组相关的路由记录，命令如下：

   ```
   ADD DMRT: RTNAME="DRA_RT", PEERNAME="DRA1"; 
   ADD DMRT: RTNAME="DRA_RT", PEERNAME="DRA2";
   ```
4. 设置通过DRA转接到达目的对端MME的路由。携带参数如下：
   - “路由组名称”为“DRA\_RT”
   - “目的对端名称”为“MME”
   - “路由操作类型”为“ADD/MOD(增加/修改) ”
   - “路由选择模式”为“AORS(主备方式) ”
   - “路由对端名称1”为“DRA1”
   - “路由对端名称2”为“DRA2”

   ```
   SET EXPDMRT: RTNAME="DRA_RT", DPEERNAME="MME", RTOPTYPE=ADD/MOD, SMODE=AORS, RPEERNAME1="DRA1", RPEERNAME2="DRA2";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释                | 原因分析                      | 处理建议                              |
|-------:|:--------------------|:--------------------------|:----------------------------------|
| 335386 | Diameter路由对端名称不能相同。 | 输入的“路由对端名称1～10”参数存在相同的取值。 | 重新输入“路由对端名称1～10”，保证设置的该参数不存在相同取值。 |
