# 删除所有用户必签指定NAFID的USS列表(RMV NAFIDUSS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在配置数据库中删除某个网络应用功能组的必选USS信息。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

删除网络应用功能组的必选USS信息，会对用户访问操作的安全性造成影响，请谨慎操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                       |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| FQDN   | FQDN   | 标识USS信息的关键字段之一，用于指定需要删除哪一个网络应用功能组的USS信息，操作员可以使用LST NAFIDUSS命令查询获得。 需要指出的是，该参数不区分大小写，在执行LST NAFIDUSS命令查询出的报文中为全小写形式。 取值范围：长度不超过127的字符串。 默认值：无。 注意：该参数为必选参数。 |
| GSID   | GSID   | 标识USS信息的关键字段之一，用于指定需要删除哪一个网络应用功能组的USS信息，操作员可以使用LST NAFIDUSS命令查询获得。 取值范围：0～999999。 默认值：无。 注意：该参数为必选参数。                                                      |

## 使用实例

删除用户必签指定网络应用功能组的USS列表，携带以下参数：

- “FQDN”为“1”
- “GSID”为“2”

执行命令如下：

```
RMV NAFIDUSS: FQDN="1", GSID=2;
```
