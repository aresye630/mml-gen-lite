# 测试SCCP全局翻译码(TST SCCPGT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于请求系统测试SCCP全局码的翻译配置，检查翻译结果是否正确。

该命令的操作场景一般为：在SCCP翻译失败时执行该命令来检查SCCP全局码的配置。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|:--------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MN      | CCU模块号    | 用于指定CCU进程的模块号。 如果输入的模块号为1024，则将命令下发给所有状态正常的CCU模块。 该参数可通过命令LST MODULE查询获得。 取值范围：1～1024 默认值：无。 说明：必选参数。                                                                                                                                                                                                                                                                                                                                   |
| GTI     | 全局翻译码类型   | 全局翻译码类型，本局执行GT码翻译的条件之一，当某个GT码的类型符合此处指定的参数值时，本局才可能执行GT码翻译。各参数选项的含义是： ITU类型1：全局码由地址性质指示语和地址信息构成。 ITU类型2：全局码由翻译类型和地址信息构成。 ITU类型3：全局码中包含翻译类型、编号计划、编码方案和地址信息。 ITU类型4：全局码中包含翻译类型、编号计划、编码方案、地址性质指示语和地址信息。 ANSI类型1：全局码中包含翻译类型、编号计划、全局翻译码地址信息和编码方案。 ANSI类型2：全局码中包含翻译类型和全局翻译码地址信息。 取值范围： “GT1(ITU类型1)”“GT2(ITU类型2)”“GT3(ITU类型3)”“GT4(ITU类型4)”“GT5(ANSI类型1)”“GT6(ANSI类型2)” 默认值：“GT4(ITU类型4)” 说明：可选参数。                                              |
| TRANTYP | 翻译类型      | 本局执行GT码翻译的条件之一，当某个GT码的翻译类型符合此处指定的参数值时，本局才可能执行GT码翻译。该参数的值域类型为十六进制数字。该参数目前未使用，请直接使用“00”，表示不使用翻译类型。 取值范围：长度不超过2的字符串 默认值：00 说明：可选参数。                                                                                                                                                                                                                                                                                                        |
| NUMPLAN | 编号计划      | 本局执行GT码翻译的条件之一，当某个GT码的编号计划符合此处指定的参数值时，本局才可能执行GT码翻译。该参数一般取“ISDN/电话编号计划”。 取值范围： “UNDEF(未知)”“ISDN(ISDN/电话编号计划)”“STANDBY(通用编号计划)”“DATA(数据编号计划)”“TELEX(电传编号计划)”“MARINE(海事移动编号计划)”“LAND(陆地移动编号计划)”“ISDNMOV(ISDN/移动编号计划)”“RESERVED_8(保留编号计划8)”“RESERVED_9(保留编号计划9)”“RESERVED_10(保留编号计划10)”“RESERVED_11(保留编号计划11)”“RESERVED_12(保留编号计划12)”“RESERVED_13(保留编号计划13)”“RESERVED_14(保留编号计划14)”“RESERVED_15(保留编号计划15)” 默认值：“ISDN(ISDN/电话编号计划)” 说明：可选参数。 |
| ADDREXP | 地址性质指示语   | 本局执行GT码翻译的条件之一，当某个GT码的地址性质指示语符合此处指定的参数值时，本局才可能执行GT码翻译。该参数一般取“国际号码”。 取值范围： “FREE(未知)”“USRCODE(用户号码)”“NS(国内备用)”“NM(国内有效号码)”“INTER(国际号码)”“NA005(地址性质指示语5)”~“NA127(地址性质指示语127)” 默认值：“INTER(国际号码)” 说明：可选参数。                                                                                                                                                                                                                                  |
| ADDR    | 全局翻译码地址信息 | 本局执行GT码翻译的条件之一，当某个GT码的地址信息匹配此处指定的参数值时，本局才可能执行GT码翻译。 需要指出的是，系统按照最大匹配的原则对GT码的地址信息与此处指定的地址信息进行匹配，也就是说，对于一个具体的GT码，系统在所有的地址信息中查找与该GT码的地址信息最相近的一个进行匹配。 取值范围：BCD码 默认值：无。 说明：必选参数。                                                                                                                                                                                                                                                              |

## 使用实例

测试SCCP全局码，“CCU模块号”为“22”，“GT类型”为“GT4”，“全局翻译码地址信息”为“99999999”：

```
TST SCCPGT: MN=22, GTI=GT4, ADDR=K'99999999;
```

返回结果如下：

