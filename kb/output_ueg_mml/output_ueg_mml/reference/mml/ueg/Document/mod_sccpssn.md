# 修改SCCP子系统(MOD SCCPSSN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于对配置数据库中的一条SCCP子系统号数据记录的某些参数进行修改或调整。在该命令中，系统通过“SCCP子系统名称”参数来唯一标识一条SCCP子系统号数据记录。

## 注意事项

- 修改子系统时，请确保子系统上没有配置SCCP GT翻译结果。
- 执行**MOD SCCPSSN**命令时，如果输入的“SSN名称”和“信令点编码”不是同一个对端，“SSN名称”对应对端的SCCPSSN数据会被强制改写“信令点编码”。UDM到原“SSN名称”对应的对端会因为缺少SCCPSSN而导致消息出局失败。请在华为技术支持指导下执行该操作。
- 该命令不允许进行批操作。

## 使用实例

1、修改SCCP子系统号数据，“SSN名称”为“SCCPSSN”，“SSN”为“VLR”：

```
MOD SCCPSSN: SSNNM="SCCPSSN", SSN=VLR;
```

2、修改SCCP子系统号数据，“SSN名称”为“SCCPSSN”，“新SSN名称”为“NEWSSN”：

```
MOD SCCPSSN: SSNNM="SCCPSSN", SSNNM1="NEWSSN";
```
