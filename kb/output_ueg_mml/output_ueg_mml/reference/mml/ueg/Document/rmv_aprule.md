# 删除AP转发规则(RMV APRULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于从配置数据库中删除一条AP转发规则数据记录。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

执行本命令前系统不会检查要删除的AP转发规则是否正在被使用，若删除会导致GBA认证功能无法正常使用，请谨慎操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                               |
|:-------|:-------|:-------------------------------------------------------------------|
| ID     | 索引     | 标识一条AP转发规则数据记录的关键字段，用于指定需要删除哪一条AP转发规则数据记录，操作员可以使用LST APRULE命令查询获得。 |

## 使用实例

删除“索引”为“1”的AP转发规则数据记录：

```
RMV APRULE: ID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释                            | 原因分析                       | 处理建议                                                                      |
|-------:|:--------------------------------|:---------------------------|:--------------------------------------------------------------------------|
| 377876 | 指定的ID不存在。请执行LST APRULE查询已存在的ID。 | 输入的“索引”参数对应的AP转发规则数据记录不存在。 | 根据实际情况，重新输入参数，确保输入的“索引”参数对应的AP转发规则已定义。可执行LST APRULE命令查询系统中已存在的AP转发规则数据记录。 |
