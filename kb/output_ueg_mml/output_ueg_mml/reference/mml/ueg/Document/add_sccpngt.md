# 增加SCCP新全局翻译码(ADD SCCPNGT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条SCCP新全局翻译码数据记录。

## 注意事项

- 当操作员在使用**ADD SCCPGT**命令配置全局翻译码数据时，如果翻译的结果类型为“SPC + NEW GT”，则操作员必须预先使用**ADD SCCPNGT**命令定义新全局翻译码。
- 最多增加1024条SCCP新全局翻译码数据记录。

## 参数说明

| 参数标识       | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|:-----------|:-------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NGTNM      | 新全局翻译码名称     | 用于在本局的配置数据库中唯一标识一个新全局翻译码。 取值范围：长度不超过32位的字符串，字符串只允许输入：0-9，a-z，A-Z，“-”、“_”、“.”、空格符、和中文字符。 默认值：无。 说明：需要指出的是：对于操作员在客户端输入的字符串，系统在操作OMU数据库之前将自动进行如下处理：将该字符串中的所有英文字母全部转换成大写、并将该字符串中最左边与最右边的空格删除掉。例如，假设操作员在客户端输入的字符串为“ 区域abc ”，则系统在操作OMU数据库之前将自动将该字符串转换为“区域ABC”。 对于操作员通过本命令配置的某一条具体的数据记录而言，假设该数据记录中“新全局翻译码名称”字段的原取值为A，如果操作员后续需要将该字段的取值由A修改为B，则其可以通过MOD SCCPNGT命令中的“新全局翻译码名称”参数重新进行定义。此时，对于配置数据库中索引了取值为A的所有数据记录的“新全局翻译码名称”字段，系统将自动把这些字段的值由A修改为B。 |
| HANDMODE   | 处理方式         | 用于指定本局需要对原全局翻译码执行哪种操作。 取值范围： “REPLACE(替换)”“CHANGE(改变)” 各参数选项的含义是：替换：表示可以对全局翻译码中的所有字段（包括翻译类型、编号计划、编码方案、地址性质指示语和地址信息等）进行变换，但操作员在对地址信息进行变换时，其变换的结果只能是一个固定的地址信号。 改变：表示可以对全局翻译码中的所有字段（包括翻译类型、编号计划、编码方案、地址性质指示语和地址信息等）进行变换，但操作员在对地址信息进行变换时，其可以根据需要进行插号、改号、删号等号码变换操作，其变换的结果可以不唯一。 默认值：无。 说明：无。                                                                                                                                                 |
| GTI        | 替换方式的全局翻译码标识 | 当处理方式为“替换”时，用于指定该新全局翻译码的类型。 取值范围： “GT1(ITU类型1)”“GT2(ITU类型2)”“GT3(ITU类型3)”“GT4(ITU类型4)”“GT5(ANSI类型1)”“GT6(ANSI类型2)” 各参数选项的含义是：ITU类型1：全局翻译码包含地址性质指示语和地址信息。 ITU类型2：全局翻译码包含翻译类型和地址信息。 ITU类型3：全局翻译码包含翻译类型、编号计划、编码方案和地址信息。 ITU类型4：全局翻译码包含翻译类型、编号计划、编码方案、地址性质指示语和地址信息。 ANSI类型1：全局翻译码包含翻译类型、编号计划和全局翻译码地址信息。 ANSI类型2：全局翻译码包含翻译类型和地址信息。 默认值： “GT4(ITU类型4)”。 说明：无。                                                                                 |
| TRANTYP    | 替换方式的翻译类型    | 当处理方式为“替换”时，用于指定该新全局翻译码所采用的翻译功能，即如何把SCCP消息的地址信息翻译成新的SPC、SSN与GT的不同组合，其值域类型为十六进制数字。 取值范围：长度不超过2的字符串。 默认值：00。 说明：如果全局翻译码类型为ANSI，当消息中地址信息的全局翻译码为IMSI，则翻译类型为9，消息中地址信息的全局翻译码为MSISDN时，翻译类型为E。系统默认值为“00”（表示不使用翻译类型）。                                                                                                                                                                                                                            |
| NUMPLAN    | 替换方式的编号计划    | 当处理方式为“替换”时，用于指定该新全局翻译码所采用的编号计划。 取值范围： “UNDEF(未知)”“ISDN(ISDN/电话编号计划)”“STANDBY(通用编号计划)”“DATA(数据编号计划)”“TELEX(电传编号计划)”“MARINE(海事移动编号计划)”“LAND(陆地移动编号计划)”“ISDNMOV(ISDN/移动编号计划)”“RESERVED_8(保留编号计划8)”～ “RESERVED_15(保留编号计划15)” 默认值： “ISDN(ISDN/电话编号计划)”。 说明：该参数一般选择“ISDN/电话编号计划”。                                                                                                                                                            |
| ADDREXP    | 替换方式的地址性质指示语 | 当处理方式为“替换”时，用于指定该新全局翻译码的地址性质。 取值范围： “FREE(未知)”“USRCODE(用户号码)”“NS(国内备用)”“NM(国内有效号码)”“INTER(国际号码)”“NA005(地址性质指示语5)”～“NA127(地址性质指示语127)” 默认值： “INTER(国际号码)” 说明：该参数一般选择“国际号码”。                                                                                                                                                                                                                                                              |
| ADDR       | 全局翻译码地址信息    | 当处理方式为“替换”时，用于指定该新全局翻译码的地址信息。 取值范围：BCD码。 默认值：无。 说明：其取值范围为0～9、A～E，最大长度为20位。                                                                                                                                                                                                                                                                                                                                                              |
| CHGGTI     | 改变方式的全局翻译码标识 | 当处理方式为“改变”时，用于指定该新全局翻译码的类型。若操作员不希望改变原全局翻译码的类型，请不要选择任何一个有效的参数选项。 取值范围： “GT1(ITU类型1)”“GT2(ITU类型2)”“GT3(ITU类型3)”“GT4(ITU类型4)”“GT5(ANSI类型1)”“GT6(ANSI类型2)” 各参数选项的含义是： ITU类型1：全局翻译码包含地址性质指示语和地址信息。 ITU类型2：全局翻译码包含翻译类型和地址信息。 ITU类型3：全局翻译码包含翻译类型、编号计划、编码方案和地址信息。 ITU类型4：全局翻译码包含翻译类型、编号计划、编码方案、地址性质指示语和地址信息。 ANSI类型1：全局翻译码包括翻译类型、编号计划和地址信息。 ANSI类型2：全局翻译码包含翻译类型和地址信息。 默认值：无。 说明：无。                                                              |
| CHGTRANTYP | 改变方式的翻译类型    | 当处理方式为“改变”时，本局执行GT码翻译的条件之一，当某个GT码的翻译类型符合此处指定的参数值时，本局才可能执行GT码翻译。 取值范围：长度不超过2的字符串。 默认值：无。 说明：该参数的值域类型为十六进制数字。 如果全局翻译码类型为ANSI，当消息中地址信息的全局翻译码为IMSI，则翻译类型为9，消息中地址信息的全局翻译码为MSISDN时，翻译类型为E。                                                                                                                                                                                                                                                    |
| CHGNUMPLAN | 改变方式的编号计划    | 当处理方式为“改变”时，用于指定该新全局翻译码所采用的编号计划。 取值范围： “UNDEF(未知)”“ISDN(ISDN/电话编号计划)”“STANDBY(通用编号计划)”“DATA(数据编号计划)”“TELEX(电传编号计划)”“MARINE(海事移动编号计划)”“LAND(陆地移动编号计划)”“ISDNMOV(ISDN/移动编号计划)”“RESERVED_8(保留编号计划8)”“RESERVED_9(保留编号计划9)”“RESERVED_10(保留编号计划10)”“RESERVED_11(保留编号计划11)”“RESERVED_12(保留编号计划12)”“RESERVED_13(保留编号计划13)”“RESERVED_14(保留编号计划14)”“RESERVED_15(保留编号计划15)” 默认值：无。 说明：该参数一般选择“ISDN/电话编号计划”。                                         |
| CHGADDREXP | 改变方式的地址性质指示语 | 当处理方式为“改变”时，用于指定该新全局翻译码的地址性质。 取值范围： “FREE(未知)”“USRCODE(用户号码)”“NS(国内备用)”“NM(国内有效号码)”“INTER(国际号码)”“NA005(地址性质指示语5)”～“NA127(地址性质指示语127)” 默认值：无。 说明：该参数一般选择“国际号码”。                                                                                                                                                                                                                                                                          |
| INSERTLOC  | 插入位置         | 当处理方式为“改变”时，用于指定对原全局翻译码中的地址信号进行插号操作时的起始位置（在原号码前插入），其中第一个号码的位置编号为0。若操作员不输入任何参数，则表示不进行插号操作。 取值范围：0～20。 默认值：无。 说明：需要指出的是，系统在进行改号或删号操作时，如果“变换起始位置＋号码变换长度”＞原号码长度，则此次号码变换将无效；在进行插号操作时，如果“变换起始位置＞原号码长度”，则此次号码变换也将无效。                                                                                                                                                                                                                           |
| INSERTNUM  | 插入号码         | 当处理方式为“改变”、且需要对原全局翻译码中的地址信号进行插号操作时，用于指定在原地址信号的插入位置前插入的新号码。 取值范围：BCD码。 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                                                                      |
| MODLOC     | 修改位置         | 当处理方式为“改变”时，用于指定对原全局翻译码中的地址信号进行改号操作时的起始位置，其中第一个号码的位置编号为0。若操作员不输入任何参数，则表示不进行改号操作。 取值范围：0～20。 默认值：无。 说明：需要指出的是，系统在进行改号或删号操作时，如果“变换起始位置＋号码变换长度”＞原号码长度，则此次号码变换将无效；在进行插号操作时，如果“变换起始位置＞原号码长度”，则此次号码变换也将无效。                                                                                                                                                                                                                                    |
| MODLENGTH  | 修改号码长度       | 当处理方式为“改变”、且需要对原全局翻译码中的地址信号进行改号操作时，用于指定需要替换的号码串的长度。 取值范围：1～20。 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                                                                             |
| ORINUM     | 原号码          | 当处理方式为“改变”、且需要对原全局翻译码中的地址信号进行改号操作时，用于指定替换前的号码串。 取值范围：BCD码。 默认值：无。 说明：该参数的配置原则是：若操作员输入某个具体的号码串、且其长度与本命令中的“修改号码长度”参数保持一致，则表示从修改位置开始，系统仅对原地址信号中与“原号码”完全匹配的号码串执行改号操作。 若操作员不输入任何号码，则表示从修改位置开始，无论原地址信号中对应的号码串为何值，系统均按照本命令中的“修改号码长度”参数的要求对原地址信号中对应的号码串执行改号操作。 该参数支持通配符“E”，即一个“E”可以代表任意的数字。但当操作员在使用通配符时，其输入的原号码的长度必须要与本命令中的“修改号码长度”参数保持一致。例如，若操作员输入“13E”，则其代表的号段为“130～139”；又如，若操作员输入“139E0”，则其代表的号段为“13900～13990”；其余情况依此类推。                     |
| NEWNUM     | 新号码          | 当处理方式为“改变”、且需要对原全局翻译码中的地址信号进行改号操作时，用于指定替换后的号码串。 取值范围：BCD码。 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                                                                                 |

| DELLEN     | 删除号码长度       | 当处理方式为“改变”、且需要对原全局翻译码中的地址信号进行删号操作时，用于指定需要删除的号码串的长度。 取值范围：1～20。 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                                                                             |
| DELNUM     | 删除号码         | 当处理方式为“改变”、且需要对原全局翻译码中的地址信号进行删号操作时，用于指定需要删除的号码串。 取值范围：BCD码。 默认值：无。 说明：该参数的配置原则是：若操作员输入某个具体的号码串、且其长度与本命令中的“删除号码长度”参数保持一致，则表示从删除位置开始，系统仅对原地址信号中与“原号码”完全匹配的号码串执行删号操作。 若操作员不输入任何号码，则表示从删除位置开始，无论原地址信号中对应的号码串为何值，系统均按照本命令中的“删除号码长度”参数的要求对原地址信号中对应的号码串执行删号操作。 该参数支持通配符“E”，即一个“E”可以代表任意的数字。但当操作员在使用通配符时，其输入的原号码的长度必须要与本命令中的“删除号码长度”参数保持一致。例如，若操作员输入“13E”，则其代表的号段为“130～139”；又如，若操作员输入“139E0”，则其代表的号段为“13900～13990”；其余情况依此类推。                    |

## 使用实例

1、增加SCCP新全局翻译码，“新全局翻译码名称”为“SCCPNGT”，“处理方式是”为“替换”，“全局翻译码地址信息”为“86138586”，其余参数使用默认值：

```
ADD SCCPNGT: NGTNM="SCCPNGT", HANDMODE=REPLACE, GTI=GT4, ADDR=K'86138586;
```

2、增加SCCP新全局翻译码，“新全局翻译码名称”为“SCCPNGT”，“处理方式”为“改变”，“全局翻译码标识”为“ITU类型4”，“翻译类型”为“00”，“编号计划”为“ISDN/电话编号计划”，“地址性质指示语”为“国际号码”，“插入位置”为“2”，“插入号码”为“139”：

```
ADD SCCPNGT: NGTNM="SCCPNGT", HANDMODE=CHANGE, CHGGTI=GT4, CHGTRANTYP="00", CHGNUMPLAN=ISDN, CHGADDREXP=INTER, INSERTLOC=2, INSERTNUM=K'139;
```

3、增加SCCP新全局翻译码，“新全局翻译码名称”为“SCCPNGT”，“处理方式”为“改变”，“全局翻译码标识”为“ITU类型4”，“翻译类型”为00，“编号计划”为“ISDN/电话编号计划”，“地址性质指示语”为“国际号码”，“修改位置”为“2”，“修改号码长度”为“3”，“原号码”为“138”，“新号码”为“139”：

```
ADD SCCPNGT: NGTNM="SCCPNGT", HANDMODE=CHANGE, CHGGTI=GT4, CHGTRANTYP="00", CHGNUMPLAN=ISDN, CHGADDREXP=INTER, MODLOC=2, MODLENGTH=3, ORINUM=K'138, NEWNUM=K'139;
```

4、增加SCCP新全局翻译码，“新全局翻译码名称”为“SCCPNGT”，“处理方式”为“改变”，“全局翻译码标识”为“ITU类型4”，“翻译类型”为“00”，“编号计划”为“ISDN/电话编号计划”，“地址性质指示语”为“国际号码”，“删除位置”为“2”，“删除号码长度”为“3”，“删除号码”为“138”：

```
ADD SCCPNGT: NGTNM="SCCPNGT", HANDMODE=CHANGE, CHGGTI=GT4, CHGTRANTYP="00", CHGNUMPLAN=ISDN, CHGADDREXP=INTER, DELLOC=2, DELLEN=3, DELNUM=K'138;
```
