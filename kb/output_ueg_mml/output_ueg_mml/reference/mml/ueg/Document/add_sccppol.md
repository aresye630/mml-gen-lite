# 增加SCCP屏蔽策略(ADD SCCPPOL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条SCCP屏蔽策略数据记录。

## 注意事项

当本局与移动网络中VLR、MSC、SMC、SCP、SGSN等设备对接时，为将由这些设备发起的MAP、CAP等入局信令消息的流量控制在一个设定的范围之内，防止本局与这些设备之间的信令链路拥塞或过载，保障信令网的安全，运营商可以通过使用本局的SCCP屏蔽功能来解决这个问题。

此时，操作员需要使用**ADD SCCPPOL**命令增加SCCP屏蔽策略。这样，当本局接收到由其他设备发起的MAP、CAP等入局信令消息以后，本局可以在SCCP层根据消息中所携带的SCCP主被叫地址中的SPC、SSN、GT等信息来启动SCCP屏蔽控制：如果在单位时间内本局接收到的SCCP信令消息包的数量超过设定的阈值，则本局将丢弃此SCCP信令消息而不执行下一步的消息处理。

| DNUMPLAN     | 被叫编码计划     | 本局启动SCCP屏蔽控制的过滤条件之一，当屏蔽策略中包含有基本屏蔽策略“被叫地址GTSSN”时该参数有效。当某条SCCP信令消息携带的被叫GT码的编号计划符合此处指定的参数值时，本局才可能启动SCCP屏蔽控制。 取值范围： “UNDEF(未知)”“ISDN(ISDN/电话编号计划)”“STANDBY(通用编号计划)”“DATA(数据编号计划)”“TELEX(电传编号计划)”“MARINE(海事移动编号计划)”“LAND(陆地移动编号计划)”“ISDNMOV(ISDN/移动编号计划)”“RESERVED_8(保留编号计划8)”“RESERVED_9(保留编号计划9)”“RESERVED_10(保留编号计划10)”“RESERVED_11(保留编号计划11)”“RESERVED_12(保留编号计划12)”“RESERVED_13(保留编号计划13)”“RESERVED_14(保留编号计划14)”“RESERVED_15(保留编号计划15)” 默认值：“ISDN(ISDN/电话编号计划)”。 说明：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| DADIIND      | 被叫地址性质指示语  | 本局启动SCCP屏蔽控制的过滤条件之一，当屏蔽策略中包含有基本屏蔽策略“被叫地址GTSSN”时该参数有效。当某条SCCP信令消息携带的被叫GT码的地址性质指示语符合此处指定的参数值时，本局才可能启动SCCP屏蔽控制。 取值范围： “FREE(未知)”“USRCODE(用户号码)”“NS(国内备用)”“NM(国内有效号码)”“INTER(国际号码)”“NA005(地址性质指示语5)”～“NA127(地址性质指示语127)” 默认值：“INTER(国际号码)”。 说明：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| DADINFO      | 被叫GT码地址信息  | 本局启动SCCP屏蔽控制的过滤条件之一，当屏蔽策略中包含有基本屏蔽策略“被叫地址GTSSN”时该参数有效。当某条SCCP信令消息携带的被叫GT码的地址信息匹配此处指定的参数值时，本局才可能启动SCCP屏蔽控制。 取值范围：BCD码。 默认值：无。 说明：需要指出的是，系统按照最大匹配的原则对GT码的地址信息与此处指定的地址信息进行匹配，也就是说，对于一个具体的GT码，系统在所有的地址信息中查找与该GT码的地址信息最相近的一个进行匹配。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| TRAFFICUNIT  | 流量单位       | 用于指示本局按照什么样的时间单位来对本局接收到的SCCP信令消息实施流量控制。 取值范围： “PER_HOUR(每小时)”“PER_DAY(每天)”“PER_MONTH(每月)”“PER_YEAR(每年)” 默认值：“PER_HOUR(每小时)”。 说明：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| MAXTRAFFIC   | 流量阈值       | 用于指定在单位时间内所允许通过的SCCP信令消息包（MSU）的最大数量。 取值范围：0～2147483647。 默认值：0。 说明：假设操作员在本命令中将“流量单位”参数设为“每小时”、将“流量阈值”设为1000，则本局的各CCU模块将以“小时”为单位对本局接收的SCCP信令消息实施流量控制：如果在1小时内，本局CCU模块所接收到的SCCP信令消息包小于1000，则本局将不实施流量控制；如果在1小时内，本局CCU模块所接收到的SCCP信令消息包已经达到1000，则在本小时的其余时间内，本局将丢弃该CCU模块后续所接收到的所有SCCP信令消息包。当下一个时间单位开始时，本局将对本局接收到的SCCP信令消息包重新进行统计（即将相应的统计计数器清零）。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |

## 使用实例

1、增加SCCP屏蔽策略，“SCCP屏蔽策略名称”为“SCCPPOL”，“主叫信令点编码”为“AA0033”，“屏蔽策略”为“主叫地址OPCSSN屏蔽”，“主叫SCCP 子系统号”为“MAP”，“流量单位”为“每小时”，“流量阈值”为“100”：

```
ADD SCCPPOL: SCCPNM="SCCPPOL", NI=NAT, SCRMODE=SCR_0, CGADPC="AA0033", CGASSN=MAP, TRAFFICUNIT=PER_HOUR, MAXTRAFFIC=100;
```

2、增加SCCP屏蔽策略，“SCCP屏蔽策略名称”为“SCCPPOL”，“被叫信令点编码”为“AA0033”，“ 屏蔽策略”为“被叫地址DPCSSN屏蔽”，“被叫SCCP 子系统号”为“SCMG”，“流量单位”为“每小时”，“流量阈值”为“100”：

```
ADD SCCPPOL: SCCPNM="SCCPPOL", NI=NAT, SCRMODE=SCR_3, CDADPC="AA0033", CDASSN=SCMG, TRAFFICUNIT=PER_HOUR, MAXTRAFFIC=100;
```
