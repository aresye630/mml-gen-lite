# 删除业务条件操作统计对象(RMV STATSTRNG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除系统内一个业务条件操作的统计对象。

该命令的使用场景：存在冗余的统计对象。

## 注意事项

删除统计对象会导致已建立的话统任务失效，请确认统计对象是否必须要删除。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                  |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------|
| OBJECTID | 统计对象ID | 用于标识一个统计对象的配置信息的关键字段，指定需要删除哪一个对象的配置记录，该参数可以使用LST STATSTRNG命令查询获得。 取值范围：“OBJECT1(OBJECT1)”～“OBJECT64(OBJECT64)” 默认值：无。 |

## 使用实例

在系统运行过程中，由于业务需要，删除系统中已存在的一个业务统计操作的统计对象。“统计对象ID”为“OBJECT1(OBJECT1)”：

`RMV STATSTRNG: OBJECTID=OBJECT1;`
