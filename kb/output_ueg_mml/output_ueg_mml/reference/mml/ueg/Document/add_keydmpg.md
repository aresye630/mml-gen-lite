# 增加关键DIAMETER对端组(ADD KEYDMPG)

## 命令功能

该命令为配置类命令，用于在FE/BE整体倒换功能中增加关键DIAMETER对端组。

关键DIAMETER对端组可以根据需要将关键对端灵活的组合到一起，通过以下方式确定是否进行整体倒换或者倒回操作：

- 确认软参“NOTIFYSIGNSTATTOBE（是否支持信令链路状态通知到USCDB）”是否设置为支持信令链路状态通知到USCDB。
- 通过该命令配置关键局向，监控Diameter信令链路状态。
  - CCU底层获取到信令链路（即关键DIAMETER对端组）发生了故障（“关键SS7信令点组的权重”+“关键Diameter对端组的权重” >= 100%），通知CCU业务处理层信令链路的状态，CCU业务处理层接收到信令链路状态发生变化后，如果持续时间超出了设定的门限值则通知BE进行整体倒换。通过软参“SIGNALFAULTDELAY（信令链路故障检测时间）”设置该门限值。
  - CCU底层获取到信令链路（即关键DIAMETER对端组）故障恢复后（“关键SS7信令点组的权重”+“关键Diameter对端组的权重” < 100%），通知CCU业务处理层信令链路的状态，CCU业务处理层接收到信令链路状态发生变化后，如果持续时间超出了设定的门限值则通知BE进行倒回。通过软参“SIGNALRECOVERDELAY（信令链路恢复检测时间）”设置该门限值。

**说明** 

- 关键SS7信令点组的权重：所有链路状态发生变化的关键信令点组对应的“关键SS7信令点组在联动倒换中的比例”之和。
- 关键Diameter对端组的权重：所有链路状态发生变化的关键Diameter对端组对应的“关键DIAMETER对端组在联动倒换中的比例”之和。

## 注意事项

- 仅将软参“NOTIFYSIGNSTATTOBE（是否支持信令链路状态通知到USCDB）”值设置为“1”时，该命令配置的数据才能生效。
- 系统中增加的关键DIAMETER对端组记录数不能超过128条。

## 参数说明

| 参数标识        | 参数名称                      | 参数说明                                                                                                     |
|:------------|:--------------------------|:---------------------------------------------------------------------------------------------------------|
| KEYDMPGNM   | 关键DIAMETER对端组名称           | 用于在本局的配置数据库中唯一标识一条关键DIAMETER对端组数据。 取值范围：长度不超过31位的字符串。包括：0-9，a-z，A-Z，-，_，小数点，空格以及中文字符。 默认值：无 说明：不能全部输入空格。 |
| WEIGHT_RATE | 关键DIAMETER对端组在联动倒换中的比例(%) | 用于标识关键DIAMETER对端组在联动倒换中的权重比例。 取值范围：0～100 单位：% 默认值：0                                                      |

## 使用实例

增加关键DIAMETER对端组，“关键DIAMETER对端组名称”为“KEYDRA”，“关键DIAMETER对端组在联动倒换中的比例(%)”为“50”：

`ADD KEYDMPG: KEYDMPGNM="KEYDRA", WEIGHT_RATE=50;`
