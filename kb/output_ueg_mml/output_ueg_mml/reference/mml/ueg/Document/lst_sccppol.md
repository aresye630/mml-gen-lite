# 查询SCCP屏蔽策略(LST SCCPPOL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在配置数据库中查询SCCP屏蔽策略配置信息：

- 若需要查询全部SCCP屏蔽策略配置的概要信息，请不要输入任何参数。
- 若需要查询某条SCCP屏蔽策略配置的详细信息，请输入相关参数或参数组合。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
|:--------|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SCCPNM  | SCCP屏蔽策略名称 | 用于指示系统需要按照哪个SCCP屏蔽策略名称来查询SCCP屏蔽策略数据；若不输入，则表示所有的SCCP屏蔽策略名称。 取值范围：长度不超过32的字符串 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| SCRMODE | 屏蔽策略       | 用于指示系统需要按照哪种屏蔽策略类型来查询系统的SCCP屏蔽策略数据；若不输入，则表示所有的屏蔽策略类型。 取值范围： “SCR_0(主叫地址OPCSSN屏蔽)”“SCR_1(主叫地址GTSSN屏蔽)”“SCR_2(主叫地址GTT屏蔽)”“SCR_3(被叫地址DPCSSN屏蔽)”“SCR_4(被叫地址GTSSN屏蔽)”“SCR_5(被叫地址GTT屏蔽)”“SCR_6(主叫地址GTSSN＋被叫地址GTSSN屏蔽)”“SCR_7(主叫地址OPCSSN＋被叫地址DPCSSN屏蔽)”“SCR_8(主叫地址GTSSN＋被叫地址DPCSSN屏蔽)”“SCR_9(主叫地址OPCSSN＋被叫地址GTSSN屏蔽)”“SCR_10(主叫地址GTSSN＋被叫地址GTT屏蔽)”“SCR_11(主叫地址GTT＋被叫地址GTSSN屏蔽)”“SCR_12(被叫地址GTSSN＋被叫地址GTT屏蔽)”“SCR_13(主叫地址GTSSN+主叫地址GTT屏蔽)”“SCR_14(主叫OPCSSN＋被叫GTSSN屏蔽＋被叫GTT屏蔽)”“SCR_15(主叫地址OPCSSN＋被叫地址GTT屏蔽)”“SCR_16(主叫GTSSN＋被叫GTSSN＋被叫GTT屏蔽)”“SCR_17(主叫GTSSN＋主叫GTT＋被叫GTT屏蔽)”“SCR_18(主叫GTSSN＋主叫GTT＋被叫DPCSSN屏蔽)”“SCR_19(主叫地址GT＋主叫地址GTT＋被叫地址GT屏蔽)”“SCR_20(主叫GTSSN＋主叫GTT＋被叫GTSSN屏蔽＋被叫GTT屏蔽)”“SCR_21(主叫地址GTT＋被叫地址DPCSSN屏蔽)”“SCR_22(主叫GTT＋被叫GTSSN屏蔽＋被叫GTT屏蔽)”“SCR_23(主叫GTT＋被叫GTT屏蔽)” 默认值：无。 说明：无。 |

```
LST SCCPPOL:;
```
