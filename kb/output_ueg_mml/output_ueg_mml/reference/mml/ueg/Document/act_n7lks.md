# 激活MTP链路集 (ACT N7LKS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于激活MTP链路集。

## 注意事项

激活MTP链路集前，必须使用**ADD N7LKS**先配置MTP链路集，可以使用**LST N7LKS**命令查询MTP链路集的配置情况。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                               |
|:-------|:-------|:-------------------------------------------------------------------|
| LSNM   | 链路集名称  | 标识一条MTP链路集数据记录的关键字段，用于指定需要对哪一条MTP链路集进行激活操作，操作员可以使用LST N7LKS命令查询获得。 |

## 使用实例

激活MTP链路集，“链路集名称”为“TEST”：

```
ACT N7LKS: LSNM="TEST";
```
