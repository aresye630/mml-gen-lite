# 增加IMSI前缀和HLRSN(ADD IMSIHLRSN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加IMSI前缀和HLRSN的对应关系数据记录。

仅当操作员在PGW Web LMT通过执行**SET MAPSERV**命令将“本局信息选取方式”参数设为“OMU\_IMSIPREFIX”时配置的数据会在业务流程中生效。

- 在业务流程中首先按照实际正在使用业务的用户IMSI，根据本命令配置的IMSI前缀和HLRSN的对应关系获取HLRSN，然后使用**ADD HLRSNOFI**命令配置的对应关系来获取“本局GT”、“本局HLR号码”、“本局主机名”和“本局域名”等数据。
- 在这种场景中需要同时执行**ADD HLRSNOFI**命令和**ADD IMSIHLRSN**命令来配置数据。

## 注意事项

通过本命令最多可配置1024条IMSI前缀和HLRSN的对应关系数据记录。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                          |
|:-----------|:-------|:------------------------------------------------------------------------------|
| IMSIPREFIX | IMSI前缀 | 用于标识待增加的和HLRSN关联的IMSI前缀。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                        |
| HLRSN      | HLR序列号 | 用于标识待增加的和IMSI前缀关联的HLR序列号。该参数必须先由ADD HLRSNOFI命令定义，然后才能在此处引用。 取值范围：1～255 默认值：无。 |

## 使用实例

“本局信息选取方式”参数设为“OMU\_IMSIPREFIX”时：

1. 操作员登录OM Portal在“UDM MML命令”界面上执行**ADD HLRSNOFI**命令增加一条HLRSN与本局信息数据的对应关系数据。命令如下：

   ```
   ADD HLRSNOFI: HLRSN=1, LOCGT=K'8613901000, HLRNO="123456", LOCALHOST="test1", LOCALREALM="huawei1.com", DEFGT=K'8613901001, DEFHLRNO="654321";
   ```
2. 操作员登录OM Portal在“UDM MML命令”界面上执行**ADD IMSIHLRSN**命令增加一条IMSI前缀与HLRSN的对应关系数据记录，“IMSI前缀”为“460142”，“HLR序列号”为“1”。命令如下：

   ```
   ADD IMSIHLRSN: IMSIPREFIX="460142", HLRSN=1;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                    | 原因分析                                | 处理建议                                                                      |
|-------:|:-----------------------------------------|:------------------------------------|:--------------------------------------------------------------------------|
| 264050 | 参数IMSIPREFIX只允许输入：0～9。                   | 输入的“IMSI前缀”参数的取值不是1～15位十进制数字组成的字符串。 | 重新输入“IMSI前缀”参数，确保其取值是1～15位十进制数字组成的字符串。                                    |
| 264051 | 指定的IMSI前缀已经存在                            | 输入的“IMSI前缀”参数已经存在。                  | 重新输入“IMSI前缀”参数，确保其取值不存在。已存在的“IMSI前缀”参数可以通过LST IMSIHLRSN命令查询获得。            |
| 264053 | 指定的HLRSN不存在，请执行LST HLRSNOFI查询已经配置的HLRSN。 | 输入的“HLR序列号”参数在ADD HLRSNOFI命令中未定义。   | 重新输入“HLR序列号”参数，确保其取值在ADD HLRSNOFI命令中已定义。已定义的“HLR序列号”可以通过LST HLRSNOFI命令查询。 |
