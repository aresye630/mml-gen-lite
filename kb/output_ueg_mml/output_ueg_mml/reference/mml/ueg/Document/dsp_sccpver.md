# 显示SCCP版本(DSP SCCPVER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询指定的SCCP版本信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                    |
|:-------|:-------|:--------------------------------------------------------|
| MN     | CCU模块号 | 用于请求系统显示哪个CCU模块内SCCP协议栈的版本信息。 取值范围：1～1023。 默认值：无。 说明：无。 |

## 使用实例

显示2模块SCCP版本：

```
DSP SCCPVER: MN=2;
```

返回结果如下：

```
%%DSP SCCPVER: MN=2;%%
RETCODE = 0  操作成功

显示SCCP版本
------------
SCCP版本  =  VPP SS7 v1.2.1.1(SCCP) (ITU-T 1996)
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出结果解释                                               |
|:--------|:-----------------------------------------------------|
| SCCP版本  | 用于返回当前SCCP协议栈的版本信息，其版本信息的结构为：软件模块+软件版本号+软件补丁号（协议类型）。 |
