# 删除模块(RMV MODULE)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于删除一个模块。

## 注意事项

- 要删除的模块必须存在。
- 除了在开局初始配置时，其他情况下随意删除模块会导致业务进程无法启动，系统可能会产生致命错误，请谨慎使用。
- 该命令不允许进行批操作。
- “POD名称”和“模块类型”参数必须同时使用，且“模块号”参数和“Pod名称”、“模块类型”参数的组合必须只能存在一个。
- 如果需要删除某条特定模块号的数据记录，则删除时必须携带“模块号”参数，且取值为特定模块号。
- 如果删除时未携带“模块号”参数，同时待删除的数据记录中存在多条“模块类型”相同且“主用Pod名称”相同的数据记录，那么本命令则删除当前模块号最大的数据记录。已存在的模块数据记录可以通过**LST MODULE**命令查询。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                |
|:--------|:-------|:--------------------------------------------------------------------|
| MID     | 模块号    | 标识一条模块配置信息的关键字段之一，用于指定需要删除哪一条模块配置记录，该参数可以使用LST MODULE命令查询获得。        |
| PODNAME | Pod名称  | 标识一条模块配置信息的关键字段之一，用于指定需要删除哪一个Pod上的模块的配置记录，该参数可以使用LST PODINFO命令查询获得。 |
| MT      | 模块类型   | 标识一条模块配置信息的关键字段之一，用于指定需要删除哪一种类型的模块的配置记录，该参数可以使用LST MODULE命令查询获得。    |

## 使用实例

1. 删除“模块号”为“1”的模块信息：

   ```
   RMV MODULE: MID=1;
   ```
2. 删除“Pod名称”为“pod0”、“模块类型”为“CCU”的模块信息：

   ```
   RMV MODULE: PODNAME="pod0", MT=CCU;
   ```
