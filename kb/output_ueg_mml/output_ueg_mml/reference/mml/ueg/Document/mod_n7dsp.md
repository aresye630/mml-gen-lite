# 修改MTP目的信令点(MOD N7DSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于对配置数据库中的一条MTP目的信令点数据记录的某些参数进行修改或调整。在该命令中，系统通过“目的信令点名称”参数来唯一标识一条MTP目的信令点数据记录。

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
|:-------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DPNM   | 目的信令点名称  | 标识一条MTP目的信令点数据记录的关键字段，用于指定需要对哪一条MTP目的信令点数据记录的参数进行修改或调整，操作员可以使用LST N7DSP命令查询获得。 取值范围：长度不超过32的字符串 默认值：无。 说明：必选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| STPF   | STP标志    | 用于指定该目的信令点是否具备信令转接（STP）的功能，仅当目的信令点为与本局直联的STP设备时，该参数设为“是”，其余情况均设为“否”。 取值范围：  “TRUE(是)” “FALSE(否)” 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ADJF   | 相邻标志     | 用于指定本局与对端目的信令点之间是否存在直达的MTP信令路由，该参数的配置原则是： 若对端设备为以直联方式与本局对接的STP，该参数设为“是”。 若对端设备为以直联方式与本局对接的MSC、SGSN，该参数设为“是”。 若对端为以准直联方式与本局对接的MSC或SGSN（即需要通过STP转发信令），该参数设为“否”。 取值范围：  “TRUE(是)” “FALSE(否)” 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| SLSSM  | 链路集选择掩码  | 用于指示本局在去往该目的信令点的多个MTP链路集之间如何实现信令业务的负荷分担，一般情况下建议取系统的默认值B1111。该参数的配置原则是： 当本局与目的信令点之间仅存在一个链路集时，该参数可以设为任意值。 当本局与目的信令点之间存在2个链路集时，该参数中“1”的个数必须大于或等于1，例如为B0001、B1100、B1111。 当本局与目的信令点之间存在3～4个链路集时，该参数中“1”的个数必须大于或等于2，例如为B0011、B1100、B1111。 当本局与目的信令点之间存在5～8个链路集时，该参数中“1”的个数必须大于或等于3，例如为B1011、B1110、B1111。 当本局与目的信令点之间存在9～16个链路集时，该参数只能设为B1111。 为避免出现同摆的现象，操作员不能将链路集选择掩码与各链路集的链路选择掩码（由ADD N7LKS命令配置）设成同一个编码，一般建议将两个掩码中“1”的位置错开。例如，假设链路集选择掩码为0110，则链路选择掩码可设为1001。 取值范围：  “B0000(B0000)” “B0001(B0001)” “B0010(B0010)” “B0011(B0011)” “B0100(B0100)” “B0101(B0101)” “B0110(B0110)” “B0111(B0111)” “B1000(B1000)” “B1001(B1001)” “B1010(B1010)” “B1011(B1011)” “B1100(B1100)” “B1101(B1101)” “B1110(B1110)” “B1111(B1111)” 默认值：无。 说明：可选参数。 |
| EXNI   | 外部网络指示   | 本局与No.7信令设备的对接参数之一，用于指定该目的信令点的信令点编码属于哪一个信令网，它可以是国际主用网、国际备用网、国内主用网或国内备用网。 取值范围：  “INT(国际主用网)” “INTB(国际备用网)” “NAT(国内主用网)” “NATB(国内备用网)” 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| DPNM1  | 新目的信令点名称 | 对于由本命令中“目的信令名称”字段所标识的某条具体的数据记录而言，用于指示系统是否需要对该数据记录中“目的信令名称”字段的取值重新进行定义，其值域类型为字符串、最大长度为32。该参数的配置原则是： 若不输入任何字符：表示不对该数据记录中“目的信令名称”字段的取值重新进行定义。 若输入一个字符串：表示需要对该数据记录中“目的信令名称”字段的取值重新进行定义，且输入的字符串不能在相应的数据表中已经被定义。假设本命令中“目的信令名称”字段的取值为A、“新目的信令名称”字段的取值为B，则对于配置数据库中索引了取值为A的所有数据记录的“目的信令名称”字段，系统将自动把这些字段的值由A修改为B。 取值范围：长度不超过32的字符串 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                                                                                                        |

## 使用实例

1、修改MTP目的信令点，“目的信令点名称”为“N7DSP”，“链路集选择掩码”为“B0000”：

```
MOD N7DSP: DPNM="N7DSP", SLSSM=B0000;
```

2、修改MTP目的信令点，“目的信令点名称”为“N7DSP”，“STP标志”为“是”：

```
MOD N7DSP: DPNM="N7DSP",STPF=TRUE;
```
