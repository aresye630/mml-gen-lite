## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成系统运行异常从而影响用户业务运行，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于在配置数据库中对一条软件参数数据记录的某些参数进行修改或调整。在该命令中，系统通过“参数”参数来唯一标识一条软件参数的数据记录。

## 注意事项

- 在缺省的情况下，系统在初始化的时候已经预置了软件参数数据表中的部分数据，这些数据的主要内容可以参见“参数”参数中的各选项。
- 软件参数值都有特定含义，此命令的修改可能严重影响系统的运行情况，修改时请联系技术支持人员进行操作。
- 该命令不允许进行批操作。
- 执行该命令设置“参数”为“P50”，“修改方式”为“按参数值修改”，“参数值”为“8080”或设置“参数”为“P50”，“修改方式”为“按比特位修改”，“比特位”为“1”，“比特位值”为“1”时，需要通过**ADD SCCPGT**添加一条翻译记录，将**SET INTROFF**配置的本地HLR号码翻译为OPC。

  ```
  ADD SCCPGT: GTNM="origin_hlr", NI=NAT, GTI=GT4, NUMPLAN=ISDN, ADDREXP=INTER, ADDR=K'86139139, RESULTT=LSPC2, SPC="139139";
  ```

  其中，部分参数的取值如下：

  - ADDR（全局翻译码地址信息）：取值为**SET INTROFF**命令中的本地HLR号码参数值
  - RESULTT（翻译结果类型）：LSPC2（固定值）
  - SPC（信令点编码）：本局信令点

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                        |
|:--------|:-------|:----------------------------------------------------------------------------------------------------------------------------|
| ID      | 参数     | 标识一条软件参数数据记录的关键字段（其取值不能被修改），用于指定需要对哪一条软件参数数据记录的参数标识进行修改或调整，操作员可以使用LST MSFP命令查询获得。 取值范围："P0(保留参数 0)"~"P80(保留参数 80)"          |
| MODTYPE | 修改方式   | 用于指定系统软件参数的修改方式，各参数选项的含义是： P0(按参数值修改)：软件参数的值按参数值修改。若软参值是一个整体，则使用按值修改比较方便。 P1(按比特位修改)：软件参数的值按比特位修改。若软参值的各位有不同功能，则采用按位修改比较方便。 |
| VALUE   | 参数值    | 仅当本命令中的“修改方式”参数为“按参数值修改”时该参数有效，用于指定修改后的参数值，其值域类型为十六进制 取值范围：0000～FFFF。 默认值：无。                                                |
| BIT     | 比特位    | 仅当本命令中的“修改方式”参数为“按比特位修改”时该参数有效，用于指定对应要修改的比特位。 取值范围：0～15。                                                                    |
| BITVAL  | 比特位值   | 当参数“修改方式”为“按比特位修改”时，该参数有效。用于指定对应比特位的值，其值域类型为二进制。 取值范围：0～1。                                                                  |

## 使用实例

修改软件参数，“参数”为“TCAP主叫轮选设置”、“修改方式”为“按参数值修改”、“参数值”为“0001”：

```
MOD MSFP: ID=P50, MODTYPE=P0, VALUE="0001";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                             | 原因分析                               | 处理建议                                                                 |
|-------:|:----------------------------------|:-----------------------------------|:---------------------------------------------------------------------|
| 306978 | 存在BSG上配置链路数超过8条的情况，开启增强模式会导致链路失效。 | 当一个BSG上配置链路数超过8条时，执行本命令开启链路性能增强模式。 | 请确保开启链路性能增强模式时不存在BSG上配置链路数超过8条的情况。某个BSG上已配置的M3UA链路可以通过LST M3LNK命令查询。 |
