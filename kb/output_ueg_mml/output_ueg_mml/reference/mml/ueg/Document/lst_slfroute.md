# 查询SLF路由的配置信息(LST SLFROUTE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询SLF路由的配置信息。

- 若需要查询全部SLF路由的配置信息，请不要输入任何参数值。
- 若需要查询某个具体的SLF路由配置信息，请输入“路由名称”参数或其他参数或这些参数的组合。

**说明** 

该命令暂不支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称         | 参数说明                                           |
|:-------|:-------------|:-----------------------------------------------|
| RTNAME | 路由名称         | 用于指示系统按照哪个路由信息的名称查询SLF路由信息；若不输入，则表示所有的路由信息的名称。 |
| RTTYPE | Route信息的类型   | 用于指示系统按照哪个Route信息的类型查询SLF路由信息。                 |
| USERID | 用户标识的前后缀     | 用于指示系统按照哪个用户标识的前后缀查询SLF路由信息。                   |
| DN     | 用户所在的域       | 用于指示系统按照哪个用户所在的域查询SLF路由信息。                     |
| HN     | 用户归属的HSS地址   | 用于指示系统按照哪个用户归属的HSS地址查询SLF路由信息。                 |
| HN2    | 用户归属的备选HSS地址 | 用于指示系统按照哪个用户归属的备选HSS地址查询SLF路由信息。               |

## 使用实例

1. 查询所有SLF路由的配置信息。

   `LST SLFROUTE:;`

   ```
   %%LST SLFROUTE:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    路由名称       Route信息的类型  用户标识的前后缀  用户所在的域  用户归属的HSS地址  用户归属的备选HSS地址  路由索引

    SLFROUTENAME1  Sip后缀          hss               huawei.com    hlr.huawei.com     hss.huawei.com         0       
    SLFROUTENAME2  Msisdn前缀       111               huawei.com    hlr.huawei.com     hss.huawei.com         1       
   (结果个数 = 2)

   ---    END
   ```
2. 查询某条SLF路由的配置信息，其中“Route信息的类型”为“Sip后缀”。

   `LST SLFROUTE: RTTYPE=SIPSUFFIX;`

   ```
   %%LST SLFROUTE: RTTYPE=SIPSUFFIX;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
                路由名称  =  SLFROUTENAME1
         Route信息的类型  =  Sip后缀
        用户标识的前后缀  =  hss
            用户所在的域  =  huawei.com
       用户归属的HSS地址  =  hlr.huawei.com
   用户归属的备选HSS地址  =  hss.huawei.com
                路由索引  =  0
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

| 输出项名称        | 输出项解释                                     |
|:-------------|:------------------------------------------|
| 路由名称         | 用于在UDM的配置数据库中定义SLF路由信息的名称。                |
| Route信息的类型   | 用于在UDM的配置数据库中定义SLF路由信息的类型。                |
| 用户标识的前后缀     | 用于在UDM的配置数据库中定义SLF路由匹配信息。                 |
| 用户所在的域       | 用于在UDM的配置数据库中标识用户所在的域。                    |
| 用户归属的HSS地址   | 用于在UDM的配置数据库中定义用户归属的HSS地址。                |
| 用户归属的备选HSS地址 | 用于在UDM的配置数据库中定义用户归属的备选HSS地址。              |
| 路由索引         | 用于在配置数据库中定义一条SLF路由数据记录索引，该索引仅供内部使用，无实际含义。 |
