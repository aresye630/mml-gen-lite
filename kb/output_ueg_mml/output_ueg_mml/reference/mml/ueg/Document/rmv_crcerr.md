# 删除CRC错误数据(RMV CRCERR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于从数据库中删除系统已登记的CRC校验错误数据。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                        |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------|
| MN     | 模块号    | 标识需要删除CRC校验错误数据的模块，用于指定需要对哪一模块的CRC校验错误数据进行删除，操作员可以通过LST CRCERR命令查询获得。若不输入，则删除所有模块的CRC校验错误数据。                                |
| TID    | 表号     | 标识需要删除CRC校验错误数据的表，用于指定需要对哪一张表的CRC校验错误数据进行删除，操作员可以通过LST CRCERR命令查询获得。若不输入，则删除所有表的CRC校验错误数据。 取值范围：下拉列表中给出的所有表。 默认值：无。 配置原则：无。 |

## 使用实例

删除所有模块的CRC错误数据：

```
RMV CRCERR:;
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，请联系华为技术支持处理。
