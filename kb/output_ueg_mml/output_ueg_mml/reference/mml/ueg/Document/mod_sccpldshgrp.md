# 修改SCCP目的负荷分担信令点组(MOD SCCPLDSHGRP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于对配置数据库中的一条SCCP目的负荷分担信令点组数据记录的某些参数进行修改或调整。在该命令中，系统通过“负荷分担信令点组名称”参数来唯一标识一条SCCP目的负荷分担信令点组数据记录。

## 注意事项

- 主信令点和负荷分担目的信令点必须先在MTP DSP表或M3UA DE表中配置（由本局与目的信令点之间的信令承载方式决定配置在哪个数据表中）。通过**LST N7DSP**或**LST M3DE**命令，可分别查看上述数据表中的配置信息。
- 该命令不允许进行批操作。

## 使用实例

1. “负荷分担信令点组名称”为“LoadShareDspGrp”，“主目的信令点名称”为“NewMainDSP”，“1号负荷分担信令点名称”为“DSP1”。则修改1号负荷分担目的信令点优先级的命令为：

   ```
   MOD SCCPLDSHGRP: LSDGNM="LoadShareDspGrp", MDNM="NewMainDSP", LSDP1="DSP1", PLSDP1=1;
   ```
2. “负荷分担信令点组名称”为“LoadShareDspGrp”。则修改负荷分担信令点组名称的命令为：

   ```
   MOD SCCPLDSHGRP: LSDGNM="LoadShareDspGrp", NLSDGNM="NewLoadShareDspGrp";
   ```
3. “负荷分担信令点组名称”为“LoadShareDspGrp”，“主目的信令点名称”为“NewMainDSP”，“1号负荷分担信令点名称”为“DSP1”，“2号负荷分担信令点名称”为“DSP2”，“3号负荷分担信令点名称”为“DSP3”。则删除SCCP负荷分担目的信令点组中2号负荷分担信令点的命令为：

   ```
   MOD SCCPLDSHGRP: LSDGNM="LoadShareDspGrp", MDNM="NewMainDSP", LSDP1="DSP1", LSDP2="DSP3", LSDP3="DEFAULT";
   ```
