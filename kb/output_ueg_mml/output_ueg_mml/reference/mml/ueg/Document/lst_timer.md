# 查询定时器值(LST TIMER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于在配置数据库中查询内部定时器的值。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                      |
|:-------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------|
| QT     | 查询方式    | 查询定时器的方式。可以根据内部索引和定时器协议名称两种方式查询定时器。 取值范围： “DTK(内部索引)”：内部索引即根据模块PID，定时器索引和定时器序号查询“NTK(定时协议名称)”：定时协议名称查询方式则根据定时器对应的协议名称进行查询 默认值：“DTK(内部索引)” |
| MPID   | 模块 PID  | 业务模块的PID。                                                                                                                                 |
| TMRIDX | 定时器索引   | 业务模块的定时器索引。                                                                                                                               |
| TMRSEQ | 定时器序号   | 业务模块的定时器序号。                                                                                                                               |
| TPNM   | 定时器协议名称 | 该定时器对应的协议名称。                                                                                                                              |

## 使用实例

查询定时器值，“查询方式”为“内部索引”，“模块 PID”为“257”，“定时器索引”为“1”，“定时器序号”为“1”：

```
LST TIMER: QT=DTK, MPID=257, TMRIDX=1, TMRSEQ=1;
```

返回结果如下：


## 输出结果说明

| 输出项名称    | 输出结果解释              |
|:---------|:--------------------|
| 是否和默认值相等 | 用于返回定时器当前值和默认值是否相等。 |
| 模块PID    | 业务模块的PID。           |
| 定时器索引    | 业务模块的定时器索引。         |
| 定时器序号    | 业务模块的定时器序号。         |
| 定时器值     | 定时器当前的取值。单位是s。      |
| 定时器默认值   | 定时器的系统默认取值。单位是s。    |
| 定时器名称    | 该定时器的简要含义描述名称。      |
| 定时器协议名称  | 该定时器的对应的协议名称。       |
