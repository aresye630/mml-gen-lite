# 查询SCCP目的信令点(LST SCCPDSP)

## 命令功能

该命令为配置类命令，用于在配置数据库中查询SCCP目的信令点数据的配置信息：

- 若需要查询全部SCCP目的信令点数据记录的概要信息，请不要输入任何参数。
- 若需要查询某条SCCP目的信令点数据记录的详细信息，请输入相关参数或参数组合。
- 若需要指定查询结果以哪种排序方式显示，请输入“新排序方式”参数。

该命令的“目的信令点名称”参数支持模糊查询功能。模糊查询功能是指操作员在客户端输入查询参数时，对于字符串或BCD码类型的查询参数而言，如果操作员输入的是一个完整的字符串或BCD码，则表示系统将按照完全匹配的方式执行查询操作；如果操作员在输入的某个字符串或BCD码的末尾添加通配字符“%”，则表示系统将按照模糊匹配的方式执行查询操作。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                            |
|:--------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DPNM    | 目的信令点名称 | 用于指示系统需要按照哪个目的信令点名称来查询SCCP目的信令点数据；若不输入，则表示所有的目的信令点名称。 取值范围：长度不超过32的字符串 默认值：无。 说明：配置原则是：该参数的值域范围为：数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、空格符、中文字符。 操作员只能在字符串或BCD码的末尾添加通配字符“%”，而不能在字符串或BCD码的前面、中间添加通配字符“%”。例如，“A市%”、“1390123%”是合法的输入，而“%A市”、“A市%区”、“%1390123”、“139%0123”均是不合法的输入。 如果某个命令同时存在有多个字符串或BCD码类型的查询参数，则操作员在一次查询操作中，只能对其中的一个查询参数使用模糊查询方式，而不能同时对两个或两个以上的查询参数使用模糊查询方式。 |
| NI      | 网络指示    | 用于指示系统需要按照哪个网络指示来查询SCCP目的信令点数据；若不输入，则表示所有的网络指示。 取值范围： “INT(国际主用网)”“INTB(国际备用网)”“NAT(国内主用网)”“NATB(国内备用网)” 默认值：无。 说明：无。                                                                                                                                                                                                                                                           |
| DPC     | 目的信令点编码 | 用于指示系统需要按照哪个目的信令点编码来查询SCCP目的信令点数据；若不输入，则表示所有的目的信令点编码。 取值范围： 当信令点进制类型为十六进制时，信令点编码允许以下方式输入：十六进制字符串（如：1AB2AB或H'1AB2AB）。中间不允许有空格和其他非十六进制字符。范围是0x0～0xFFFFFF（24位信令点编码）或0x0～0x003FFF（14位信令点编码）。 当信令点进制类型为十进制整数格式时，信令点编码允许以下方式输入：十进制整数字符串（如：1749675）。中间不允许有空格、其他非十进制字符。范围是0～16777215（24位信令点编码）或0～16383（14位信令点编码）。 默认值：无。 说明：无。                                                          |
| OPC     | 源信令点编码  | 用于指示系统需要按照哪个源信令点编码来查询SCCP目的信令点数据；若不输入，则表示所有的源信令点编码。 取值范围： 当信令点进制类型为十六进制时，信令点编码允许以下方式输入：十六进制字符串（如：1AB2AB或H'1AB2AB）。中间不允许有空格和其他非十六进制字符。范围是0x0～0xFFFFFF（24位信令点编码）或0x0～0x003FFF（14位信令点编码）。 当信令点进制类型为十进制整数格式时，信令点编码允许以下方式输入：十进制整数字符串（如：1749675）。中间不允许有空格、其他非十进制字符。范围是0～16777215（24位信令点编码）或0～16383（14位信令点编码）。 默认值：无。 说明：无。                                                            |
| NEWSORT | 新排序方式   | 用于指示查询结果是否启用新的排序方式显示。 取值范围：NO(否)：以“目的信令点名称”参数值的升序排序。YES(是)：依次以“国际主用网目的信令点编码”、“国际备用网目的信令点编码”、“国内主用网目的信令点编码”、“国内备用网目的信令点编码”、“源信令点编码”参数值的升序排序。 默认值：NO(否)。                                                                                                                                                                                                                          |
