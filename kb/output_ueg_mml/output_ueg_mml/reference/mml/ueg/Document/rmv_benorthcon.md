# 删除BE北向配置信息(RMV BENORTHCON)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条BE北向配置信息。

## 注意事项

当使用本命令删除某条北向配置信息后，对应的EpRpStaUdFe和EpRpStaUdBe北向配置文件数据将无法生成。

## 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                             |
|:--------|:---------|:---------------------------------------------------------------------------------|
| OBJNAME | 对象名称     | 可选必选说明：必选参数 参数含义：用于标识待删除BE北向配置信息的对象名称。 取值范围： UD(Ud)RS(Rs) 默认值：无。 配置原则：无。         |
| ID      | ID       | 可选必选说明：必选参数 参数含义：用于标识待删除BE北向配置信息的ID。 取值范围：由长度不超过127位的字符串组成。 默认值：无。 配置原则：无。       |
| LOCIP   | 本端网元IP地址 | 可选必选说明：必选参数 参数含义：用于标识待删除BE北向配置信息的本端网元IP地址。 取值范围：由长度不超过255位的字符串组成。 默认值：无。 配置原则：无。 |
| PEERIP  | 对端网元IP地址 | 可选必选说明：必选参数 参数含义：用于标识待删除BE北向配置信息的对端网元IP地址。 取值范围：由长度不超过255位的字符串组成。 默认值：无。 配置原则：无。 |

## 使用实例

删除一条BE北向配置信息：“对象名称”为“UD(Ud)”，“ID”为“abc”，“本端网元IP地址”为“127.12.0.23”，“对端网元IP地址”为“10.5.11.55”。

```
RMV BENORTHCON: OBJNAME=UD, ID="abc", LOCIP="127.12.0.23", PEERIP="10.5.11.55";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释   | 原因分析               | 处理建议                                                   |
|-------:|:-------|:-------------------|:-------------------------------------------------------|
| 260183 | 记录不存在  | 系统中没有待删除的BE北向配置信息。 | 该命令所有参数唯一标识一条记录，请重新输入一条已存在的数据记录，可通过LST BENORTHCON命令查询。 |
