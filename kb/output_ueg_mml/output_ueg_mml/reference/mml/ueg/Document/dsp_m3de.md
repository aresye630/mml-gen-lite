# 显示M3UA目的实体状态(DSP M3DE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询M3UA目的实体的运行状态。

## 注意事项

该命令的“目的实体名称”参数支持模糊查询功能。模糊查询功能是指操作员在客户端输入查询参数时，对于字符串或BCD码类型的查询参数而言，如果操作员输入的是一个完整的字符串或BCD码，则表示系统将按照完全匹配的方式执行查询操作；如果操作员在输入的某个字符串或BCD码的末尾添加通配字符“%”，则表示系统将按照模糊匹配的方式执行查询操作。对于此类参数，其配置原则是：

- 该参数的值域范围为：数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“\_”、“.”、空格符、中文。
- 操作员只能在字符串或BCD码的末尾添加通配字符“%”，而不能在字符串或BCD码的前面、中间添加通配字符“%”。例如，“A市%”、“1390123%”是合法的输入，而“%A市”、“A市%区”、“%1390123”、“139%0123”均是不合法的输入。
- 如果某个命令同时存在有多个字符串或BCD码类型的查询参数，则操作员在一次查询操作中，只能对其中的一个查询参数使用模糊查询方式，而不能同时对两个或两个以上的查询参数使用模糊查询方式。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                  |
|:-------|:-------|:----------------------------------------------------------------------|
| MN     | 模块号    | 用于请求系统显示哪个模块的M3UA目的实体的运行状态，若不输入，则表示最小模块。 取值范围：1～1023 默认值：无。 说明：无。     |
| DENM   | 目的实体名称 | 用于请求系统显示哪个M3UA目的实体名称的运行状态，若不输入，则表示所有目的实体。 取值范围：1～32 位字符串 默认值：无。 说明：无。 |

## 使用实例

1、显示M3UA目的实体，“目的实体名称”为“M3UA\_DE”：

```
DSP M3DE: DENM="M3UA_DE";
```

返回结果如下：

```
%%DSP M3DE: DENM="M3UA_DE";%%
RETCODE = 0  操作成功

局向信息
--------
目的实体名称  =  M3UA_DE
    拥塞信息  =  未拥塞
        状态  =  可达
(结果个数 = 1)

---    END
```

2、显示名称前缀为“M3U”的M3UA目的实体：

```
DSP M3DE: DENM="M3U%";
```

返回结果如下：

```
%%DSP M3DE: DENM="M3U%";%%
RETCODE = 0  操作成功

局向信息
--------
 目的实体名称  拥塞信息  状态 

 M3UA          未拥塞    可达
 M3UA_DE       未拥塞    可达
(结果个数 = 2)

---    END
```

## 输出结果说明

| 输出项名称   | 输出结果解释                                                                                                                    |
|:--------|:--------------------------------------------------------------------------------------------------------------------------|
| 目的实体名称  | 用于返回当前M3UA目的实体的名称。                                                                                                        |
| 拥塞信息    | 用于返回当前M3UA链路在此目的实体的拥塞信息： 拥塞：表示到达该M3UA目的实体的链路消息流量过大而产生拥塞。 未拥塞：表示到达该M3UA目的实体的链路消息流量正常。                                      |
| 状态      | 用于返回当前M3UA目的实体的状态： 不可达：表示到达该M3UA目的实体的链路均出现异常，不能传输信令业务消息。 可达：表示到达该M3UA目的实体的链路至少有一条运行正常，可以传输信令业务消息。 去激活：表示该M3UA目的实体处于去激活状态。 |
