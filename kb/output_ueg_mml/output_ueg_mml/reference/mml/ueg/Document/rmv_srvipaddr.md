# 删除网元业务IP地址(RMV SRVIPADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除网元业务IP地址。

## 注意事项

- 删除网元业务IP地址会导致FE和BE或者BE与BE的通信中断，导致业务中断，请谨慎执行此命令。
- 如果该IP地址被DSG链路中心引用时，不允许删除此IP。可以使用**LST DSGLINKCTRL**命令查询DSG链路中心配置。
- 该命令不允许进行批操作。
- UDM不支持该命令。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                |
|:---------|:-------|:--------------------------------------------------------------------|
| SRVINDEX | 业务IP索引 | 标识一个IP地址的关键字段，用于指定需要删除哪一条业务IP索引配置的IP地址。 操作员可以使用LST SRVIPADDR命令查询获得。 |

## 使用实例

删除业务IP地址，“业务IP索引”为“1”：

```
RMV SRVIPADDR: SRVINDEX=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                     | 原因分析               | 处理建议                                                              |
|-------:|:--------------------------|:-------------------|:------------------------------------------------------------------|
| 256034 | 记录不存在。                    | 输入的“业务IP索引”错误。     | 执行LST SRVIPADDR查询已存在的记录，然后执行本命令删除，确保删除的为可查询记录。                    |
| 302023 | IP地址已经被其它记录引用。            | IP地址已经被其它记录引用。     | 此IP被其他记录引用，可执行LST RIPADDR命令查看IP地址是否被引用，确认引用后再执行RMV RIPADDR命令进行删除。 |
| 302545 | IP被链路中心使用，请先修改DSG链路中心的IP。 | 待删除的IP地址已经被链路中心使用。 | 执行LST DSGLINKCTRL命令查询DSG链路中心配置，如果要删除此IP，请先修改或删除DSG链路中心配置。         |
