# 校验用户数据(VRY USERDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，对于单个用户的数据，在DRU与DSU中不一致，或者Master与Slave中不一致时，本命令可完成数据校验。

## 注意事项

无。

## 参数说明

| 参数ID        | 参数名称   | 参数描述                                                                                  |
|:------------|:-------|:--------------------------------------------------------------------------------------|
| USERTYPE    | 用户类型   | 用于指定用户类型。 取值范围： “SUBID(SUBID)”“IMPI(IMPI)”“IMPU(IMPU)”“PISI(PISI)”“PUSI(PUSI)” 默认值：无。 |
| USERID      | 用户标识   | 用于指定用户标识。 取值范围：长度不超过127的字符串 默认值：无。                                                    |
| CCUMOUDLEID | CCU模块号 | 用于指定CCU模块号。 取值范围：1～1023 默认值：无。                                                        |

## 使用实例

校验用户数据：

`VRY USERDATA: USERTYPE=IMPI,
USERID="impi123", CCUMOUDLEID=641;`

```
%%VRY USERDATA: USERTYPE=IMPI, USERID="impi123", CCUMOUDLEID=641;%%
RETCODE = 0  操作成功

校验结果为
----------
校验结果  =  检验成功
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                         |
|:--------|:----------------------------------------------|
| 校验结果    | 指示用户数据的校验结果。 校验结果取值如下： 校验成功用户数据不存在用户数据被破坏系统错误 |
