# 显示SCTP偶联统计信息(DSP SCTPAS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于请求系统显示指定的SCTP偶联统计信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                          |
|:-------|:-------|:------------------------------------------------------------------------------|
| MN     | 模块号    | 用于请求系统显示哪个BSG模块的SCTP偶联统计信息 取值范围： 1～1023 默认值： 无。                               |
| AID    | 偶联号    | 用于请求系统显示哪个偶联号的SCTP偶联统计信息。用DSP M3LNK命令查询获得M3UA链路的SCTP偶联号 取值范围： 0～65535 默认值： 无。 |

## 使用实例

显示SCTP偶联统计信息，BSG“模块号”为“100”，“偶联号”为“9”:

```
DSP SCTPAS: MN=100, AID=9;
```

## 输出结果说明

| 输出项名称          | 输出项解释                                                            |
|:---------------|:-----------------------------------------------------------------|
| 偶联建立T1定时器超时的次数 | 用于返回当前SCTP偶联中T1（INIT/COOKIE ECHO）定时器超时的次数，该值同时体现了该SCTP偶联建立发起的次数。 |
| 数据重传T2定时器超时的次数 | 用于返回当前SCTP偶联中T2（SHUTDOWN）定时器超时的次数，该值同时也体现了数据重传的次数。               |
| 重发的数据块个数       | 用于返回当前SCTP偶联重传的DATA数据块数量。                                        |
| 发送的数据块个数       | 用于返回当前SCTP偶联发送的DATA数据块数量。                                        |
| 接收的数据块个数       | 用于返回当前SCTP偶联接收的DATA数据块数量。                                        |
| 收到包数           | 用于返回当前SCTP偶联接收的SCTP数据包数量。                                        |
| 错误包数           | 用于返回当前SCTP偶联接收的错误SCTP数据包数量。                                      |
| 丢弃的包数          | 用于返回当前SCTP用户发送数据时被SCTP偶联所拒绝的包数。                                  |
| 对端地址个数         | 用于返回当前SCTP偶联对端传送地址的数量。 本端一个SCTP传送地址可以与对端多个SCTP传送地址建立偶联关系。        |
| 对端IP地址         | 用于返回当前SCTP偶联在对端的IP地址。                                            |
| 重传数据块的个数       | 用于返回当前SCTP偶联因为等待证实超时所重传的数据块数。                                    |
