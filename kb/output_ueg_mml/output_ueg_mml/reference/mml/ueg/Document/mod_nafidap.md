# 修改网络应用功能AP列表数据(MOD NAFIDAP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在BSF上对一组AP的FQDN与AP域名或AP IP地址的映射关系进行修改或调整。在该命令中，系统通过以下组合来唯一标识一组AP的FQDN与AP域名或AP IP地址的映射关系：

- FQDN+ REALM
- FQDN+ ADDRTYPE+ IP

  **说明** 

  该命令仅在Full-stack虚机场景下支持。

## 注意事项

“AP域名”和“AP IP地址”必须配置且只能配置一个。

## 参数说明

| 参数标识     | 参数名称        | 参数说明                                                                                                                                                                                                   |
|:---------|:------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FQDN     | FQDN        | 可选必选说明：必选参数 标识AP的FQDN的关键字段之一（其取值不能被修改），用于指定需要对哪一个AP的FQDN对应的AP域名进行修改或调整，操作员可以使用LST NAFIDAP命令查询获得。 需要指出的是，该参数不区分大小写，在执行LST NAFIDAP命令查询出的报文中为全小写形式。 取值范围：长度不超过127的字符串。 默认值：无。                             |
| OLDREALM | 旧域名         | 可选必选说明：可选参数 标识AP的FQDN与AP域名映射关系的关键字段之一，用于指定需要对哪一个AP的FQDN对应的AP域名进行修改或调整，操作员可以使用LST NAFIDAP命令查询获得。 需要指出的是，该参数不区分大小写，在执行LST NAFIDAP命令查询出的报文中为全小写形式。 取值范围：长度不超过127的字符串。 默认值：无。 说明：该参数用于Zn接口使用DIAMETER协议的场景。 |
| NEWREALM | 新域名         | 可选必选说明：可选参数 用于指定一个新FQDN。同一“FQDN”下的AP域名“REALM”不能重复。 需要指出的是，该参数不区分大小写，在执行LST NAFIDAP命令查询出的报文中为全小写形式。 取值范围：长度不超过127的字符串。 默认值：无。 说明：该参数用于Zn接口使用DIAMETER协议的场景。                                              |
| ADDRTYPE | IP地址类型      | 可选必选说明：可选参数 标识AP的FQDN与AP IP地址映射关系的关键字段之一，用于指定需要对哪一个AP的FQDN对应的IP地址类型进行修改或调整。 取值范围：IPV4(IPV4)：IPv4类型的IP地址。 IPV6(IPV6)：IPv6类型的IP地址。 默认值：无。                                                                |
| OLDIPV4  | 旧NAF IPv4地址 | 可选必选说明：条件必选参数 仅当本命令的“IP地址类型”参数为“IPV4(IPV4)”时该参数有效。标识AP的FQDN与AP IP地址映射关系的关键字段之一，用于指定需要对哪一个AP的FQDN对应的IPv4地址进行修改或调整。操作员可以使用LST NAFIDAP命令查询获得。 取值范围：有效的IPv4地址。 默认值：无。                                      |
| NEWIPV4  | 新NAF IPv4地址 | 可选必选说明：条件必选参数 仅当本命令的“IP地址类型”参数为“IPV4(IPV4)”时该参数有效。用于指定一个新的NAF IPv4地址。 取值范围：有效的IPv4地址。 默认值：无。                                                                                                           |
| OLDIPV6  | 旧NAF IPv6地址 | 可选必选说明：条件必选参数 仅当本命令的“IP地址类型”参数为“IPV6(IPV6)”时该参数有效。标识AP的FQDN与AP IP地址映射关系的关键字段之一，用于指定需要对哪一个AP的FQDN对应的IPv6地址进行修改或调整。操作员可以使用LST NAFIDAP命令查询获得。 取值范围：有效的IPv6地址。 默认值：无。                                      |
| NEWIPV6  | 新NAF IPv6地址 | 可选必选说明：条件必选参数 仅当本命令的“IP地址类型”参数为“IPV6(IPV6)”时该参数有效。用于指定一个新的NAF IPv6地址。 取值范围：有效的IPv6地址。 默认值：无。                                                                                                           |

## 使用实例

修改一组AP的FQDN与AP域名的映射关系，其中“FQDN”为“bsf.huawei.com”，携带以下参数：

- “旧域名”为“huawei.com”
- “新域名”为“huawei1.com”

执行命令如下：

```
MOD NAFIDAP: FQDN="bsf.huawei.com", OLDREALM="huawei.com", NEWREALM="huawei1.com";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                      | 原因分析                                  | 处理建议                                                                                            |
|-------:|:---------------------------|:--------------------------------------|:------------------------------------------------------------------------------------------------|
| 377479 | NAFIDAP表中要修改的新记录已存在。       | 要修改的新记录在系统中已存在。                       | 执行LST NAFIDAP命令查询后，重新输入参数“FQDN”，“FQDN”+“域名”的组合或“FQDN”+“IP地址类型”+IP地址的组合，确保要修改的新记录与系统中已经存在的记录不重复。 |
| 377480 | NAFIDAP表中要修改的旧记录不存在。       | 要修改的旧记录在系统中未定义。                       | 执行LST NAFIDAP命令查询后，重新输入参数“FQDN”，“FQDN”+“域名”的组合或“FQDN”+“IP地址类型”+IP地址的组合，再执行本命令修改某条记录。            |
| 378307 | IPv4网段255.255.255.255是非法值。 | 参数“NAF IPv4地址”不能取值为“255.255.255.255”。 | 重新输入“NAF IPv4地址”参数，确保其取值不为“255.255.255.255”。                                                    |
| 378309 | 域名和IP地址类型不能同时配置。           | “AP域名”和“AP IP地址”同时只能配置一个。             | 删除参数“域名”或“IP地址类型”与IP地址的组合的取值后重新执行该命令，确保“AP域名”和“AP IP地址”同时只能配置一个。                                |
