# 显示指定DPC的MTP链路(DSP N7DLNK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询指定目的信令点的MTP链路的运行状态。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                       |
|:-------|:--------|:-------------------------------------------------------------------------------------------|
| NI     | 网络指示    | 用于请求系统按照网络指示来显示MTP链路的运行状态。 取值范围：INT(国际主用网)INTB(国际备用网)NAT(国内主用网)NATB(国内备用网) 默认值：无。 说明：必选参数。 |
| DPC    | 目的信令点编码 | 用于请求系统按照指定目的信令点编码显示MTP链路的运行状态。可以使用命令LST N7DSP查询获得该参数。 取值范围：1～11位字符串 默认值：无。 说明：无。           |
| OPC    | 源信令点编码  | 用于请求系统按照源信令点编码来显示MTP链路的运行状态。可以使用命令LST N7DSP查询获得该参数。 取值范围：1～11位字符串 默认值：无。 说明：无。             |
| LS     | 链路状态    | 用于请求系统显示哪种特性的链路状态。 取值范围：IU(使用中)FAIL(失败)ALL(所有状态) 默认值：ALL(所有状态) 说明：无。                       |
| DPNAME | 目的信令点名称 | 用于请求系统哪个目的信令点的MTP链路的运行状态。 取值范围：1～32 位字符串 默认值：无。 说明：无。                                      |

## 使用实例

显示指定DPC为“000092”的MTP链路，“网络指示”为“国内主用网”:

```
DSP N7DLNK: NI=NAT, DPC="000092";
```

输出信息如下:

```
%%DSP N7DLNK: NI=NAT, DPC="000092";%%

```

## 输出结果说明

| 输出项名称         | 说明                                                                                                                                                                                                                                             |
|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 链路名称          | 用于返回当前MTP链路的名称。                                                                                                                                                                                                                                |
| 是否使用          | 用于返回当前MTP链路的使用信息： 正在使用：表示该链路正在传输业务信令消息。 空闲：表示该链路没有传输信令业务消息。                                                                                                                                                                                    |
| 是否故障          | 用于返回当前MTP链路的故障信息： 正常：表示该链路运行正常，可以传输信令业务消息。 故障：表示该链路已经故障，不能传输信令业务消息。                                                                                                                                                                            |
| 是否闭塞          | 用于返回当前MTP链路的闭塞信息： 闭塞：表示该链路的远端处理机故障，不能投入使用。 解闭塞：表示该链路的远端处理机运行正常，可以投入使用。                                                                                                                                                                         |
| 是否激活          | 用于返回当前MTP链路的激活信息： 激活：表示链路已经建立成功，并且已经被激活，可以传输信令业务消息。 未激活：表示底层的链路已经建立，其用户层链路没有建立成功，不能传输用户层信令业务消息。                                                                                                                                                |
| 本端是否禁止        | 用于返回当前MTP链路的本地管理禁止信息： 本地管理禁止：表示操作员通过INH N7LNK命令对该链路执行了管理禁止操作，处于该状态的链路不能传输信令业务消息。 本地管理解禁：表示本端链路没有被管理禁止，可以传输信令业务消息。 “管理禁止”是一种信令网管理操作，该操作不会引起MTP-2层链路状态的改变，但禁止使用该链路来传送有关业务（TUP、ISUP）的消息，其测试、管理等消息仍可以传送。此时系统将产生一系列的信令网管理消息使原来选择该链路发送和接收的消息不再选择该链路。 |
| 对端是否禁止        | 用于返回当前MTP链路的对端管理禁止信息： 对端管理禁止：表示操作员在对端设备对该链路执行了管理禁止操作，处于该状态的链路不能传输信令业务消息。 对端管理解禁：表示对端链路没有被管理禁止，可以传输信令业务消息。                                                                                                                                      |
| 是否拥塞          | 用于返回当前MTP链路的拥塞信息： 拥塞：表示该链路上消息流量过大，致使信令传递时延过长。 未拥塞：表示该链路上消息流量正常。 当链路出现拥塞时，系统将自动执行拥塞控制机制，限制低优先级别信令消息的发送；当拥塞解除后，系统将自动恢复正常。                                                                                                                        |
| 是否倒换          | 用于返回当前MTP链路的倒换状态： 未发生倒换：表示该链路没有发生倒换，可以正常投入业务使用。 正在倒换：表示该链路正在执行倒换操作，该链路上的业务转移到其他链路上进行处理。                                                                                                                                                        |
| 是否倒回          | 用于返回当前MTP链路的倒回状态： 未发生倒回：表示该链路被倒换后一直没有被倒回。 正在倒回：表示该链路正在执行倒回操作，转移至其他链路处理的业务倒换回该链路进行处理。                                                                                                                                                           |
| 信令链路选择码(十六进制) | 用于返回同一链路集下多条链路之间信令业务负荷分担的相关信息。例如，当前链路的信令链路选择码为01 02 03 ，则表示上层用户如果填写的信令链路选择码为01、02或者03时，系统则可以选择该链路发送信令消息。                                                                                                                                       |
