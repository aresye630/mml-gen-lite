# 修改远端Location信息(MOD RLOCATION)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当可能会影响本端网元设备与远端网元设备进行通信，导致业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在配置数据库中修改一个远端Location的位置ID优先级。

## 注意事项

无。

## 参数说明

| 参数ID   | 参数名称         | 参数描述                                                                                                                                                                                                                                                                        |
|:-------|:-------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RLOCID | 远端Location标识 | 远端Location的标识，远端Location和远端网元一一对应。用户可以通过LST RLOCATION命令查询获得。远端Location是相对的，具体如下：对于主用局FE，它的远端Location指主用局USCDB、容灾局USCDB。对于主用局USCDB，它的远端Location指主用局FE、容灾局FE、容灾局USCDB。对于容灾局FE，它的远端Location指容灾局USCDB、主用局USCDB。对于容灾局USCDB，它的远端Location指容灾局FE、主用局FE、主用局USCDB。 取值范围：1～512 默认值： 无。 |
| LP     | 位置ID优先级      | 远端Location优先级。优先级值越小，优先级越高。如果配置了多个远端Location，优先访问优先级高的远端Location。 取值范围：1～512 默认值： 无。                                                                                                                                                                                        |

## 使用实例

修改远端Location配置。远端Location ID为3，位置ID优先级值为1。

`MOD RLOCATION: RLOCID=3, LP=1;`
