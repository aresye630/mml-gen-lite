# 修改M3UA链路集(MOD M3LKS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于对配置数据库中的一条M3UA链路集数据记录的某些参数进行修改或调整。在该命令中，系统通过“链路集名称”参数来唯一标识一条M3UA链路集数据记录。

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识     | 参数名称    | 参数描述                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|:---------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LSNM     | 链路集名称   | 标识一条M3UA链路集数据记录的关键字段，用于指定需要对哪一条M3UA链路集数据记录的参数进行修改或调整，操作员可以使用LST M3LKS命令查询获得。 取值范围: 长度不超过32的字符串。 默认值: 无。 说明: 无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| SLSM     | 链路选择掩码  | 用于指示本局在该链路集下的多条M3UA链路之间如何实现信令业务的负荷分担，一般情况下建议取系统的默认值B1111。 取值范围: “B0000(链路集选择掩码0)” “B0001(链路集选择掩码1)” “B0010(链路集选择掩码2)” “B0011(链路集选择掩码3)” “B0100(链路集选择掩码4)” “B0101(链路集选择掩码5)” “B0110(链路集选择掩码6)” “B0111(链路集选择掩码7)” “B1000(链路集选择掩码8)” “B1001(链路集选择掩码9)” “B1010(链路集选择掩码10)” “B1011(链路集选择掩码11)” “B1100(链路集选择掩码12)” “B1101(链路集选择掩码13)” “B1110(链路集选择掩码14)” “B1111(链路集选择掩码15)” 默认值: 无。 说明: 该参数的配置原则是：当某个M3UA链路集内配置的信令链路数仅为1时，该参数可以设为任意有效值。 当某个M3UA链路集内配置的信令链路数为2时，该参数中“1”的个数必须大于或等于1，例如为B0001、B1100、B1111。 当某个M3UA链路集内配置的信令链路数为3～4时，该参数中“1”的个数必须大于或等于2，例如为B0011、B1100、B1111。 当某个M3UA链路集内配置的信令链路数为5～8时，该参数中“1”的个数必须大于或等于3，例如为B1011、B1110、B1111。 当某个M3UA链路集内配置的信令链路数为9～16时，该参数只能设为B1111。 |
| CHLKSCFG | 链路集匹配检测 | 用于指示建立链路的两端是否进行配置正确性检查。 取值范围: “FALSE(不支持)”：表示本端发送的M3UA的ASP UP消息中将携带“源信令点编码”、“目的信令点编码”、“网络指示”的相关信息，如果对端也是HUAWEI设备，并且开启了该功能，将对这些消息进行检测，若检测发现配置有误，则链路不能激活。  “TRUE(支持)”：表示不进行配置正确性检查。 默认值: 无。 说明: 无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| LSNM1    | 新链路集名称  | 对于由本命令中“链路集名称”字段所标识的某条具体的数据记录而言，用于指示系统是否需要对该数据记录中“链路集名称”字段的取值重新进行定义。 取值范围: 长度不超过32的字符串 默认值: 无。 说明: 该参数的配置原则是：若不输入任何字符：表示不对该数据记录中“链路集名称”字段的取值重新进行定义。 若输入一个字符串：表示需要对该数据记录中“链路集名称”字段的取值重新进行定义，且输入的字符串不能在相应的数据表中已经被定义。假设本命令中“链路集名称”字段的取值为A、“新链路集名称”字段的取值为B，则对于配置数据库中索引了取值为A的所有数据记录的“链路集名称”字段，系统将自动把这些字段的值由A修改为B。                                                                                                                                                                                                                                                                                                                                                                  |

## 使用实例

1、修改M3UA链路集，“链路集名称”为“MODIFIED”，“链路选择掩码”为“B0010”：

```
MOD M3LKS: LSNM="MODIFIED", SLSM=B0010;
```

2、修改M3UA链路集，“链路集名称”为“MODIFIED”，“新链路集名称”为“NEWLKS”：

```
MOD M3LKS: LSNM="MODIFIED", LSNM1="NEWLKS";
```
