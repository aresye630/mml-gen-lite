# 增加SCCP全局翻译码(ADD SCCPGT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条SCCP全局翻译码数据记录。在该命令中，关键参数“网络指示”需要与对端信令设备协商。

## 注意事项

- 当出现以下两种情况之一时，本局均需要执行GT码的翻译过程，**ADD SCCPGT**命令即用于配置GT码的翻译策略。
  - 在发送方向上：当本局需要向MSC、SGSN、SMC、SCP等设备发送MAP、CAP、INAP等协议消息时，由于在本局的软件内部，MAP、CAP、INAP等软件模块通过TCAP传递给SCCP软件模块的主被叫地址信息一般为“SSN+GT”（即不包含SPC），因此，本局必须将主被叫地址中的GT码翻译成相应的OPC或DPC后才能使SCCP获得符合SS7信令网要求的路由信息。
  - 在接收方向上：当本局接收到1条SCCP信令消息时，如果SCCP消息中的地址表示语字段中的“路由表示语”比特为0（表示根据GT码选择路由），则本局首先对该SCCP消息中主被叫地址中的GT码执行翻译，然后再根据被叫GT码的翻译结果决定后续操作。如果对被叫GT码执行翻译后的DPC为本局信令点编码，则本局将把此消息送内部TCAP软件模块处理；否则，本局将向相应的DPC转发此SCCP消息。
- 该命令支持配置SCCP信令点负荷分担功能，当选择翻译类型为“STP3(DSP group+ OLD GT)”或者“STP4(DSP group + NEW GT)”时，可以配置到某个SCCP信令点的负荷分担信令点，具体可参考**ADD SCCPLDSHGRP**中的描述。
- 该命令支持配置回退。系统最多允许配置5000条SCCP全局翻译码记录。
- 配置本局与对端的对接数据时，配置了对端的GT码后，本局需要配置与对端相同的“全局翻译码类型”、“翻译类型”、“编号计划”和“地址性质指示语”四个参数以及“全局翻译码地址信息”参数为本局GT码的记录。例如：

  当前配置的本局信息为：

  ```
  SET OFI: OFN="HSS_LOCAL", NN=YES, SN1=NAT, NPC="333333", NNS=SP24, LOCGT=K'861850298333;
  ```

  配置对端的GT码为：

  ```
  ADD SCCPGT: GTNM="MSC_001", NI=NAT, GTI=GT4, TRANTYP="35", NUMPLAN=LAND, ADDREXP=NS, ADDR=K'8613500802, RESULTT=LSPC2, SPC="123123";
  ```

  ```
  ADD SCCPGT: GTNM="MSC_002", NI=NAT, GTI=GT4, TRANTYP="32", NUMPLAN=LAND, ADDREXP=NS, ADDR=K'8613500803, RESULTT=LSPC2, SPC="123124";
  ```

  则需要配置与对端GT参数一致的本局GT数据：

  ```
  ADD SCCPGT: GTNM="HSS_LOCAL_001", NI=NAT, GTI=GT4, TRANTYP="35", NUMPLAN=LAND, ADDREXP=NS, ADDR=K'861850298333, RESULTT=LSPC2, SPC="333333";
  ```

  ```
  ADD SCCPGT: GTNM="HSS_LOCAL_002", NI=NAT, GTI=GT4, TRANTYP="32", NUMPLAN=LAND, ADDREXP=NS, ADDR=K'861850298333, RESULTT=LSPC2, SPC="333333";
  ```

| SSN     | SSN        | 仅当翻译结果类型为“LSPC1(SPC + SSN)”时该参数有效，用于指定翻译结果中的SSN，该参数必须先由ADD SCCPSSN命令定义，然后才能在此处索引。 取值范围： “UNDEF(未定义)”“SCMG(SCMG 0x01)”“RESERVED(保留 0x02)”“ISUP(ISUP 0x03)”“OMAP(OMAP 0x04)”“MAP(MAP 0x05)”“HLR(HLR 0x06)”“VLR(VLR 0x07)”“MSC(MSC 0x08)”“EIR(EIR 0x09)”“AUC(AUC 0x0A)”“MC(MC 0x0B)”“OTAF(OTAF 0x0C)”“SCP(SCP 0x0E)”“GMLC(GMLC 0x91)”“CAP(CAP 0x92)”“GSMSCF(GSM SCF 0x93)”“SGSN(SGSN 0x95)”“GGSN(GGSN 0x96)”“MPC(MPC 0xFA)”“GS(GS 0xFC)”“BSSAP/INAP(BSSAP/INAP 0xFE)”“SSN13(子系统号13)”“SSN15(子系统号15)”～“SSN144(子系统号144)”“SSN151(子系统号151)”～“SSN249(子系统号249)”“SSN251(子系统号251)”“SSN253(子系统号253)” 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |

## 使用实例

1、增加SCCP全局翻译码，“全局翻译码名称”为“SCCP\_GT”，“全局翻译码类型”为“GT4”，“编号计划”为“ISDN/电话编号计划”，“全局翻译码地址信息”为“861390576000”，“翻译结果类型”为“LSPC2（SPC）”，“目的信令点编码”为“0x0DFF40”，其余参数使用默认值：

```
ADD SCCPGT: GTNM="SCCP_GT", GTI=GT4, NUMPLAN=ISDN, ADDR=K'861390576000, RESULTT=LSPC2, SPC="0DFF40";
```

2、增加SCCP全局翻译码，“全局翻译码名称”为“SCCP\_GT”，“全局翻译码类型”为“GT4”，“编号计划”为“ISDN/电话编号计划”，“全局翻译码地址信息”为“861390576000”，“翻译结果类型”为“LSPC1（SPC+SSN）”，“SSN”为“MAP(MAP 0x05)”，“目的信令点编码”为“0x0DFF40”，其余参数使用默认值：

```
ADD SCCPGT: GTNM="SCCP_GT", GTI=GT4, NUMPLAN=ISDN, ADDR=K'861390576000, RESULTT=LSPC1, SSN=MAP, SPC="0DFF40";
```

3、增加SCCP全局翻译码，“全局翻译码名称”为“SCCP\_GT”，“全局翻译码类型”为“GT4”，“编号计划”为“ISDN/电话编号计划”，“全局翻译码地址信息”为“861390576000”，“翻译结果类型”为“STP1（SPC+OLD GT）”，“目的信令点编码”为“0x0DFF40”，其余参数使用默认值：

```
ADD SCCPGT: GTNM="SCCP_GT", GTI=GT4, NUMPLAN=ISDN, ADDR=K'861390576000, RESULTT=STP1, SPC="0DFF40";
```

4、增加SCCP全局翻译码，“全局翻译码名称”为“SCCP\_GT”，“全局翻译码类型”为“GT4”，“编号计划”为“ISDN/电话编号计划”，“全局翻译码地址信息”为“861390576000”，“翻译结果类型”为“STP2（SPC+NEW GT）”，“目的信令点编码”为“0x0DFF40”，“新全局翻译码名称”为“NGT”，其余参数使用默认值：

```
ADD SCCPGT: GTNM="SCCP_GT", GTI=GT4, NUMPLAN=ISDN, ADDR=K'861390576000, RESULTT=STP2, SPC="0DFF40", NGTNM="NGT";
```
