# 查询远端FE信息(LST REMOTEFE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于在配置数据库中查询已配置的远端FE的信息记录。

- 若需要查询全部远端FE的信息记录，请不要输入任何参数。
- 若需要查询某个远端FE的信息记录，请输入“远端Location ID”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称          | 参数说明                                       |
|:-------|:--------------|:-------------------------------------------|
| RLOCID | 远端Location ID | 用于指示系统查询哪个远端FE的信息记录；若不输入，则表示查询所有的远端FE信息记录。 |

## 使用实例

1. 查询所有远端FE的信息记录。命令如下：

   ```
   LST REMOTEFE:;
   ```

   ```
   %%LST REMOTEFE:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    远端Location ID  检测标识

    2                Not must
    1                Not must
    6                Not must
   (结果个数 = 3)

   ---    END
   ```
2. 查询“远端Location ID”为“1”的远端FE的信息记录。命令如下：

   ```
   LST REMOTEFE: RLOCID=1;
   ```

   ```
   %%LST REMOTEFE: RLOCID=1;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
   远端Location ID  =  1
          检测标识  =  Must
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD REMOTEFE**命令的参数说明。
