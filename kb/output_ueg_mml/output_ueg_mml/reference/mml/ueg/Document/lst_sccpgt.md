# 查询SCCP全局翻译码(LST SCCPGT)

## 命令功能

该命令为配置类命令，用于在配置数据库中查询SCCP全局翻译码数据配置信息：

- 若需要查询全部SCCP全局翻译码数据配置的概要信息，请不要输入任何参数。
- 若需要查询某条SCCP全局翻译码数据配置的详细信息，请输入相关参数或参数组合。
- 若需要指定查询结果以哪种排序方式显示，请输入“新排序方式”参数。

该命令的“全局翻译码名称”和“全局翻译码地址信息”参数支持模糊查询功能。模糊查询功能是指操作员在客户端输入查询参数时，对于字符串或BCD码类型的查询参数而言，如果操作员输入的是一个完整的字符串或BCD码，则表示系统将按照完全匹配的方式执行查询操作；如果操作员在输入的某个字符串或BCD码的末尾添加通配字符“%”，则表示系统将按照模糊匹配的方式执行查询操作。

无。

## 参数说明

|:----------|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GTNM      | 全局翻译码名称    | 用于指示系统需要按照哪个全局翻译码名称来查询SCCP全局翻译码数据；若不输入，则表示所有的全局翻译码名称。 取值范围：长度不超过32的字符串。 默认值：无。 说明：配置原则是：该参数的值域范围为：数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、空格符、中文。 操作员只能在字符串或BCD码的末尾添加通配字符“%”，而不能在字符串或BCD码的前面、中间添加通配字符“%”。例如，“A市%”、“1390123%”是合法的输入，而“%A市”、“A市%区”、“%1390123”、“139%0123”均是不合法的输入。 如果某个命令同时存在有多个字符串或BCD码类型的查询参数，则操作员在一次查询操作中，只能对其中的一个查询参数使用模糊查询方式，而不能同时对两个或两个以上的查询参数使用模糊查询方式。                                                                                                                                                                                             |
| ADDR      | 全局翻译码地址信息  | 用于指示系统需要按照哪个全局翻译码地址信息来查询SCCP全局翻译码数据；若不输入，则表示所有的全局翻译码地址信息。 取值范围：BCD码。 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| QSTY      | 查询模式       | 用于指示系统需要按照哪种查询模式来查询全局翻译码地址信息数据，有精确匹配查询、最大匹配查询、最小匹配查询三种方式： 精确匹配：查询出与输入的“全局翻译码地址信息”完全匹配的记录； 最大匹配：查询出前缀是输入的“全局翻译码地址信息”的所有记录； 最小匹配：查询出与输入的“全局翻译码地址信息”匹配位数最多的记录； 如果用户在“全局翻译码地址信息”末尾添加了通配符“%”，则按最大匹配原则查询。在这种情况下，该参数无效。 取值范围： “RIGHT(精确匹配查询)”“ANALOG(最大匹配查询)”“SIMULATE(最小匹配查询)” 默认值：“RIGHT(精确匹配查询)”。 说明：无。                                                                                                                                                                                                                                                                        |
| NI        | 网络指示       | 用于指示系统需要按照哪个网络指示来查询SCCP全局翻译码数据；若不输入，则表示所有的网络指示。 取值范围： “INT(国际主用网)”“INTB(国际备用网)”“NAT(国内主用网)”“NATB(国内备用网)” 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| NUMPLAN   | 编号计划       | 用于指示系统需要按照哪个编号计划来查询SCCP全局翻译码数据；若不输入，则表示所有的编号计划。 取值范围： “UNDEF(未知)”“ISDN(ISDN/电话编号计划)”“STANDBY(通用编号计划)”“DATA(数据编号计划)”“TELEX(电传编号计划)”“MARINE(海事移动编号计划)”“LAND(陆地移动编号计划)”“ISDNMOV(ISDN/移动编号计划)”“RESERVED_8(保留编号计划8)”“RESERVED_9(保留编号计划9)”“RESERVED_10(保留编号计划10)”“RESERVED_11(保留编号计划11)”“RESERVED_12(保留编号计划12)”“RESERVED_13(保留编号计划13)”“RESERVED_14(保留编号计划14)”“RESERVED_15(保留编号计划15)” 默认值：无。 说明：无。                                                                                                                                                                                |
| RESULTT   | 翻译结果类型     | 用于指示系统需要按照哪个翻译结果类型来查询SCCP全局翻译码数据；若不输入，则表示所有的翻译结果类型。 取值范围： “STP1(SPC+OLD GT)”“LSPC1(SPC+SSN)”“STP2(SPC+NEW GT)”“LSPC2(SPC)”“STP3(DSP group+ OLD GT)”“STP4(DSP group + NEW GT)” 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                                                                                                 |
| SPC       | 信令点编码      | 用于指示系统需要按照哪个信令点编码来查询SCCP全局翻译码数据；若不输入，则表示所有的信令点编码。 取值范围：长度不超过11的字符串。 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| SSN       | SSN        | 用于指示系统需要按照哪个SCCP子系统号来查询SCCP全局翻译码数据；若不输入，则表示所有的SCCP子系统号。 取值范围： “UNDEF(未定义)”“SCMG(SCMG 0x01)”“RESERVED(保留 0x02)”“ISUP(ISUP 0x03)”“OMAP(OMAP 0x04)”“MAP(MAP 0x05)”“HLR(HLR 0x06)”“VLR(VLR 0x07)”“MSC(MSC 0x08)”“EIR(EIR 0x09)”“AUC(AUC 0x0A)”“MC(MC 0x0B)”“OTAF(OTAF 0x0C)”“SCP(SCP 0x0E)”“GMLC(GMLC 0x91)”“CAP(CAP 0x92)”“GSMSCF(GSM SCF 0x93)”“SGSN(SGSN 0x95)”“GGSN(GGSN 0x96)”“MPC(MPC 0xFA)”“GS(GS 0xFC)”“BSSAP/INAP(BSSAP/INAP 0xFE)”“SSN13(子系统号13)”“SSN15(子系统号15)”～“SSN144(子系统号144)”“SSN151(子系统号151)”～“SSN249(子系统号249)”“SSN251(子系统号251)”“SSN253(子系统号253)” 默认值：无。 说明：无。 |
| LSDGNM    | 负荷分担信令点组名称 | 仅当翻译结果类型为“DSP group+ OLD GT”或“DSP group + NEW GT”时该参数有效，用于指定翻译结果中的负荷分担信令点组名称，该参数必须先由ADD SCCPLDSHGRP命令定义，然后才能在此处索引。 取值范围：长度不超过32的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                                                                                                                  |
| RETRUNNUM | 返回记录数      | 用于限定执行一次查询操作最多能返回多少条全局翻译码信息。 取值范围：0～65535。 默认值：1800。 说明：如果参数值为0，则表示不对返回记录数进行控制，直接返回全部匹配的记录。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| NEWSORT   | 新排序方式      | 用于指示查询结果是否启用新的排序方式显示。 取值范围：NO(否)：以“全局翻译码名称”参数值的升序排序。YES(是)：依次以“全局翻译码地址信息”、“编号计划”、“全局翻译码名称”参数值的升序排序。 默认值：NO(否)。                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
