# 设置通知端口状态 (SET TTOLCM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于管理员在OMU的LMT上设置通知通道6000端口开启状态。通知任务是HLR向MSC发送自定义MAP消息，MSC可以根据此消息提供定制化业务。

## 注意事项

无。

## 参数说明

| 参数ID     | 参数名称   | 参数描述                            |
|:---------|:-------|:--------------------------------|
| OLCMPORT | 通知端口状态 | 取值范围： “OFF(关)” “ON(开)” 说明：必选参数。 |

## 使用实例

设置在线呼叫通知的端口状态。

SET TTOLCM: OLCMPORT=OFF;

```
%%SET TTOLCM: OLCMPORT=OFF;%%
RETCODE = 0  操作成功

操作结果为
----------
设置通知端口的状态  =  关闭
(结果个数 = 1)

---    END
```
