# 修改M3UA目的实体(MOD M3DE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于对配置数据库中的一条M3UA目的实体数据记录的某些参数进行修改或调整。在该命令中，系统通过“目的实体名称”参数来唯一标识一条M3UA目的实体数据记录。

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识      | 参数名称     | 参数描述                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|:----------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DENM      | 目的实体名称   | 标识一条M3UA目的实体数据记录的关键字段，用于指定需要对哪一条M3UA目的实体数据记录的参数进行修改或调整，操作员可以使用LST M3DE命令查询获得。 取值范围: 长度不超过32的字符串。 默认值: 无。 说明: 无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| STPF      | STP标志    | 用于修改该目的实体是否具备信令转接（STP）的功能。 取值范围: “TRUE(是)”“FALSE(否)” 默认值: 无。 说明: 仅当目的实体为与本局直联的SG设备时，该参数设为“TRUE(是)”，其余情况均设为“FALSE(否)”。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| SLSSM     | 链路集选择掩码  | 用于指示本局在去往该目的实体的多个M3UA链路集之间如何实现信令业务的负荷分担。 取值范围: “B0000(链路集选择掩码0)”“B0001(链路集选择掩码1)”“B0010(链路集选择掩码2)”“B0011(链路集选择掩码3)”“B0100(链路集选择掩码4)”“B0101(链路集选择掩码5)”“B0110(链路集选择掩码6)”“B0111(链路集选择掩码7)”“B1000(链路集选择掩码8)”“B1001(链路集选择掩码9)”“B1010(链路集选择掩码10)”“B1011(链路集选择掩码11)”“B1100(链路集选择掩码12)”“B1101(链路集选择掩码13)”“B1110(链路集选择掩码14)”“B1111(链路集选择掩码15)” 默认值: 无。 说明: 当本局与目的实体之间仅存在一个链路集时，该参数可以设为任意值。 当本局与目的实体之间存在2个链路集时，该参数中“1”的个数必须大于或等于1，例如为B0001、B1100、B1111。 当本局与目的实体之间存在3～4个链路集时，该参数中“1”的个数必须大于或等于2，例如为B0011、B1100、B1111。 当本局与目的实体之间存在5～8个链路集时，该参数中“1”的个数必须大于或等于3，例如为B1011、B1110、B1111。 当本局与目的实体之间存在9～16个链路集时，该参数只能设为B1111。 为避免出现同摆的现象，操作员不能将链路集选择掩码与各链路集的链路选择掩码（由ADD M3LKS命令配置）设成同一个编码，一般建议将两个掩码中“1”的位置错开。例如，假设链路集选择掩码为0110，则链路选择掩码可设为1001。 |
| RC        | 路由上下文    | 仅当本命令中“目的实体名称”对应的目的实体类型为“AS(应用服务器)”时该参数有效。用于定义该应用服务器作为客户端在向本局发送注册请求时的选路关键字。 取值范围: 0～2147483647。 默认值: 无。 说明: 路由上下文可以为一个十进制的数字，也可以为空（不配置），具体对接时需要双方协商一致。 若输入“2147483647”，则表示路由上下文为空，即不使用路由上下文。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| DEVER     | M3UA协议版本 | 本局与M3UA信令设备的对接参数之一，用于修改目的实体支持哪个版本的M3UA协议。 取值范围: “RFC3332(RFC3332)”“DRAFT10(DRAFT10)” 默认值: 无。 说明: 无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| EXNI      | 外部网络指示   | 本局与M3UA信令设备的对接参数之一，用于修改该目的实体的信令点编码属于哪一个信令网，它可以是国际主用网、国际备用网、国内主用网或国内备用网。该参数与本命令中的“内部网络指示”参数配合使用，以实现内部网络指示语与外部网络指示语之间的转换功能，其配置原则请参考“内部网络指示语”的相关说明。 取值范围: “INT(国际主用网)”“INTB(国际备用网)”“NAT(国内主用网)”“NATB(国内备用网)” 默认值: 无。 说明: 在缺省的情况下，若操作员不指定外部网络指示语的类型，则系统默认该目的实体的外部网络指示语与内部网络指示语为同一种类型。                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| PRIORITY  | 网络优先级    | 用于指定到该目的信令点所使用的网络优先级： 0：M3UA优先 1：MTP3优先 取值范围: 0～1。 默认值: 无。 说明: 该参数只有在执行MOD MSFP命令将M3DE网络优先级软参（33号软参bit7）设置为“0”后才起作用。M3DE网络优先级软参默认值为“1”。如果修改了该参数，那么与该目的实体NI、OPC、DPC相同的目的实体记录的优先级都将被刷新，与本次修改的数值一致。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| NM        | 网络模式     | 当目的实体类型为“应用服务器”或者“信令网关”时该参数有效，用于指定与本局对接的该应用服务器是独占一个信令点编码（独占信令点），还是与其他应用服务器共享一个信令点编码（非独占信令点）。 取值范围: “INCLUSIVE(共享信令点)”“EXCLUSIVE(独占信令点)” 默认值: 无。 说明: 无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| DENM1     | 新目的实体名称  | 对于由本命令中“目的实体名称”所标识的某条具体的数据记录而言，用于指示系统是否需要对该数据记录中“目的实体名称”的取值重新进行定义。 取值范围: 长度不超过32的字符串。 默认值: 无。 说明: 若不输入任何字符：表示不对该数据记录中“目的实体名称”字段的取值重新进行定义。 若输入一个字符串：表示需要对该数据记录中“目的实体名称”字段的取值重新进行定义，且输入的字符串不能在相应的数据表中已经被定义。假设本命令中“目的实体名称”字段的取值为A、“新目的实体名称”字段的取值为B，则对于配置数据库中索引了取值为A的所有数据记录的“目的实体名称”字段，系统将自动把这些字段的值由“A”修改为“B”。                                                                                                                                                                                                                                                                                                                                                                                                                     |
| PRT       | 协议类型     | 用于设定24位网络结构下，主动下发的消息中SLS“信令链路选择掩码”，是按照“ITU-T”协议计算还是按照“ANSI”协议计算。 取值范围： “ITU-T(ITU-T)”“ANSI(ANSI)” 默认值: 无。 说明：当设置为“ITU-T(ITU-T)”协议时，“扩展ANSI SLS功能”软参（MOD MSFP60号软参）无效，主动下发的消息中SLS“信令链路选择掩码”默认为4bit。当设置为“ANSI(ANSI)”协议时，“扩展ANSI SLS功能”软参生效，支持设定主动下发的消息中SLS“信令链路选择掩码”为4bit、5bit或8bit。                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| NETAPPEAR | 网络外貌     | 本局与M3UA信令设备的对接参数之一，用于指定目的实体使用的网络外貌取值。 网络外貌取值可以为一个十进制的数字，也可以为空（不配置），具体对接时需要双方协商一致。若输入“4294967295”，则表示网络外貌取值为空，即不使用网络外貌取值。 取值范围：0~4294967295 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |

## 使用实例

1、修改M3UA目的实体，“目的实体名称”为M3DE，“新目的实体名称”为“MODIFIED”，“链路集选择掩码”为“B0010(链路集选择掩码2)”：

```
MOD M3DE: DENM="M3DE", DENM1="MODIFIED", SLSSM=B0010;
```

2、修改M3UA目的实体，“目的实体名称”为“M3DE”，“STPF标志”为“TRUE(是)”：

```
MOD M3DE: DENM="M3DE", STPF=TRUE;
```
