# 查询Diameter对端实体状态(DSP DMPE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于请求系统显示指定的Diameter对端实体的运行状态信息。

- 若需要请求系统显示全部Diameter对端实体的状态信息，请不要输入任何参数。
- 若需要请求系统显示某个Diameter对端实体的状态信息，请输入“实体名称”参数。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                  |
|:-------|:-------|:----------------------------------------------------------------------|
| EN     | 实体名称   | 可选必选说明：可选参数 参数含义：用于请求系统显示哪个Diameter对端实体的状态信息；若不输入，则表示所有的Diameter对端实体。 |

## 使用实例

1. 显示所有Diameter对端实体的状态信息：

   ```
   DSP DMPE:;
   ```

   ```
   %%DSP DMPE:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    实体名称           对端状态  主机名                        域名            Diameter对端实体优先级  Diameter对端实体标识

    SAEHSS1            对端断开  saehss1.huawei.com            NULL            15                      22                  
    GGSN22             对端正常  ggsn22.huawei.com             NULL            15                      65                  
    AS                 对端断开  as.domainname.com             domainname.com  1                       66                  
   (结果个数 = 3)

   ---    END
   ```
2. 显示Diameter对端实体的状态信息，“实体名称”为“AS”：

   ```
   DSP DMPE: EN="AS";
   ```

   ```
   %%DSP DMPE: EN="AS";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
                 实体名称  =  AS
                 对端状态  =  对端断开
                   主机名  =  as.domainname.com
                     域名  =  domainname.com
   Diameter对端实体优先级  =  1
     Diameter对端实体标识  =  66
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见

**ADD DMPE**

命令的参数说明，表1列出的是未包含在

**ADD DMPE**

命令参数说明中的输出项。

| 输出项名称          | 输出项解释                                                                                                                                      |
|:---------------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| 对端状态           | 用于返回与UDM连接的对端设备状态。对端正常：对端处于正常状态，可正常通信。对端断开：当UDM与对端直联时，表示对端处于断开状态，不可通信。当UDM通过DRA与对端连接时，表示UDM未与对端直接连接，对端状态不可知。 对端拥塞：对端处于拥塞状态，网络通信质量差或者业务量过大。 |
| Diameter对端实体标识 | 用于返回一个Diameter对端实体的数据记录索引。                                                                                                                 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 消息解释                                | 原因分析                      | 处理建议                                                                |
|-------:|:------------------------------------|:--------------------------|:--------------------------------------------------------------------|
| 377102 | 指定的对端没有配置链路。请执行ADD DMLNK为指定的对端添加链路。 | 输入的“实体名称”参数对应的对端实体没有配置链路。 | 根据实际情况，重新输入“实体名称”参数的取值，确保其对应的对端实体已配置链路。已配置链路的实体名称可以执行LST DMLNK命令查询。 |
