## 命令功能

该命令为维护类命令，用于查询License的工作模式配置信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询License的工作模式：

`LST LICMODE:;`

```
%%LST LICMODE:;%%
RETCODE = 0  操作成功

查询结果如下
------------
兼容模式  =  关
应用模式  =  IMS模式
(结果个数 = 1)

---    END
```
