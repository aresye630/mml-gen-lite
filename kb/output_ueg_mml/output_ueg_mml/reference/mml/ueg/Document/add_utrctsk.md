# 创建用户跟踪任务 (ADD UTRCTSK)

## 命令功能

该命令为维护类命令，用于创建指定用户的跟踪任务。

## 注意事项

- CS域创建跟踪任务的用户是在本网已经注册且激活跟踪任务的用户。用户的“网络接入模式”为“BOTH”或“MSC”。

  **说明** 

  “网络接入模式”可以通过**ADD SUB**命令给用户开户时进行设置，并通过**MOD NAM**命令进行修改。
- PS域不支持用户全网跟踪。
- EPC域支持S6a/S6d接口的跟踪，不区分本网/它网用户，跟踪任务的下发需要MME或S4SGSN支持。用户的“网络接入模式”为“BOTH”、“SGSN”或者“NONE”。
- IMS域创建跟踪任务的用户不区分本网/它网用户，不会下发跟踪消息。
- 全网跟踪任务会占用少量系统资源。
- 当前版本不支持此功能，执行该命令后会返回错误码：335607 暂不支持该功能。

## 使用实例

为IMSI号码为852147996的用户创建跟踪任务，跟踪号为566，网管ID为74859869871065，触发事件的集合为IE0，MSC和BSS不参与。

```
ADD UTRCTSK: NETTYPE=E2E_2G, CT=IMSI, UN="852147996", TRACEREFERENCE=566, OMCID="85274859869871065", INVOKINGEVENTS=IE0, MSCTRACE=BASIC, BSSTRACE=BASIC, PRIORITYINDICATION=NoPriority;
```
