# 启动业务进程(STR MODULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于启动指定模块对应的进程。如果进程为主备进程，则启动主进程。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                |
|:-------|:-------|:----------------------------------------------------|
| MID    | 模块号    | 标识一条模块配置信息的关键字段，用于指定待启动的模块，该参数可以使用LST MODULE命令查询获得。 |

## 使用实例

启动业务进程。模块号为3。

```
STR MODULE: MID=3;
```

```
%%STR MODULE: MID=3;%%
RETCODE = 0  操作成功

操作结果如下
------------
        模块号  =  3
      模块类型  =  BSG
  模块应用类型  =  ALL
   主用Pod名称  =  FE_ENS_1
      模块名称  =  BSG29
    平台模块号  =  3205758978
      操作结果  =  成功
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见

**ADD MODULE**

命令的参数说明。表1列出的是未包含在

命令参数说明中的输出项。

| 输出项名称   | 输出项解释                                                 |
|:--------|:------------------------------------------------------|

| 操作结果    | 该参数是启动模块、停止模块、重启模块等命令的操作结果参数，用于描述命令是否执行成功。            |
