# 查询DSG链路中心(LST DSGLINKCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询DSG链路中心。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询所有DSG链路中心配置：

```
LST DSGLINKCTRL:;
```

```
%%LST DSGLINKCTRL:;%%
RETCODE = 0  操作成功

操作结果如下
------------
      模块号  =  1
      IP类型  =  IPV4
本端IPV4地址  =  10.14.39.40
本端IPV6地址  =  NULL
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称    | 输出结果解释         |
|:---------|:---------------|
| 模块号      | 网元的DSG模块号。     |
| IP类型     | IP地址类型。        |
| 本端IPV4地址 | IPV4类型的本地IP地址。 |
| 本端IPV6地址 | IPV6类型的本地IP地址。 |
