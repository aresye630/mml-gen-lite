# 增加短消息RN路由(ADD SMSRNROUT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加号码携转业务中短消息RN（Route Number）路由数据，命令中携带参数包括用户名和对应路由码。

在号码携带业务中，设置完成短消息互通网关用户数据后，需要给用户设置短消息RN路由。NPMSC根据用户携出的短消息RN路由将MAP信令消息转换为Deliver消息转发给短信互通网关，完成短消息下发。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                                                                                                                                                 |
|:-------|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UNAME  | 短信中心客户端用户名 | 用于标识待增加短消息RN数据的客户端用户名称。NPMSC在收到SMSC下发的短消息后，查询用户携出信息，将RN路由加在短消息目的地址前，然后通过SMPP进程将短消息根据RN路由至与携出网络对应的SMG（Short Message Gateway）。 取值范围：1～20个字母或数字组成的字符串。 默认值：无。 说明：为保证号码携转用户能够成功接收短消息，建议配置该参数与ADD SMSCLISUB的参数“用户名称”保持一致。 |
| RN     | 路由码        | 用于标识待增加短消息RN数据的路由码。路由码用于标识用户签约或接收短消息的网络。 取值范围：由数字0～9或字母a～e组成的1～10位字符串，不区分大小写。 默认值：无 说明：该参数一般由运营商规划，用于标识不同运营商的不同网络，操作员在配置时可向运营商获取。                                                                                    |

## 使用实例

若用户由运营商A携号转网至运营商B，运营商A为用户签约号码携带业务，其业务发放基本流程如下：

1. 登录PGW Web LMT，执行**ADD NPDONORSUB**命令增加本网携出用户。

   ```
   ADD NPDONORSUB: IMSI="4601075003001",ISDN="86131075003001", RN="1112";
   ```
2. 登录OMU客户端，执行**ADD SMSCLISUB**增加与短信互通网关相连的用户名、密码。其中该用户的“用户名称”为“username1”，“用户密码”为“a1B2#3”，命令如下：

   ```
   ADD SMSCLISUB: UNAME="username1", PWD="*****";
   ```
3. 执行该命令增加用户的短消息RN路由。

   ```
   ADD SMSRNROUT: UNAME="username1", RN="1112";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释   | 原因分析                       | 处理建议                                   |
|-------:|:--------|:---------------------------|:---------------------------------------|
| 352044 | 用户已存在   | “短信中心客户端用户名”参数指定的数据记录已经存在。 | 使用LST SMSRNROUT命令查询后，重新输入“短信中心客户端用户名”。 |
| 352047 | 参数取值无效  | “路由码”参数输入不符合取值范围。          | 根据实际情况，重新输入“路由码”，确保其取值符合取值范围。          |
