# 显示M3UA链路(DSP M3LNK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询指定M3UA链路的运行状态。

## 注意事项

该命令的“链路名称”参数支持模糊查询功能。模糊查询功能是指操作员在客户端输入查询参数时，对于字符串或BCD码类型的查询参数而言，如果操作员输入的是一个完整的字符串或BCD码，则表示系统将按照完全匹配的方式执行查询操作；如果操作员在输入的某个字符串或BCD码的末尾添加通配字符“%”，则表示系统将按照模糊匹配的方式执行查询操作。对于此类参数，其配置原则是：

- 该参数的值域范围为：数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“\_”、“.”、空格符、中文。
- 操作员只能在字符串或BCD码的末尾添加通配字符“%”，而不能在字符串或BCD码的前面、中间添加通配字符“%”。例如，“A市%”、“1390123%”是合法的输入，而“%A市”、“A市%区”、“%1390123”、“139%0123”均是不合法的输入。
- 如果某个命令同时存在有多个字符串或BCD码类型的查询参数，则操作员在一次查询操作中，只能对其中的一个查询参数使用模糊查询方式，而不能同时对两个或两个以上的查询参数使用模糊查询方式。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                   |
|:-------|:-------|:-------------------------------------------------------|
| MN     | BSG模块号 | 用于请求系统显示哪个BSG模块内的M3UA链路的运行状态。 取值范围：1～1023 默认值：无。 说明：无。 |
| LNKNM  | 链路名称   | 用于请求系统显示哪条M3UA链路的运行状态。 取值范围：1～32 位字符串。 默认值：无。 说明：无。    |

## 使用实例

1、显示M3UA链路，“链路名称”为“M3UA\_LNK”：

```
DSP M3LNK: LNKNM="M3UA_LNK";
```

## 输出结果说明

| 输出项名称      | 输出结果解释                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 模块号        | 用于返回指定的BSG模块号。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| 链路名称       | 用于返回指定的M3UA链路名称。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| SCTP偶联标识   | 用于返回当前SCTP偶联编号，它由系统自动生成，仅用于系统内部标识。  说明： 如果取值为“NULL”，代表SCTP链路未建立成功。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 锁定信息       | 用于返回当前M3UA链路的锁定状态信息： 锁定：表示操作员已经使用LCK M3LNK命令对该电路执行了锁定操作。处于该状态下的链路，M3UA链路的状态仍然可以改变，除非链路状态改变为“不可用（ASP_DOWN）”，此时将不能因收到ASP UP消息而转变为“未激活（Inactive）”状态；M3UA链路一旦被锁定，如不对其解锁，则此链路无法被激活，此命令仅在SGP侧或IPSP服务器侧有效。 解锁：表示操作员没有使用LCK M3LNK命令对该电路执行锁定操作或者操作员使用ULK M3LNK命令对处于“锁定”状态的电路执行了解锁操作。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| 本地去激活信息    | 用于返回操作员是否使用DEA M3LNK命令对M3UA链路执行了去激活操作： 未手动去激活：表示操作员没有使用DEA M3LNK命令对M3UA链路执行激活操作或者该链路处于系统默认状态。 手动去激活：表示操作员使用DEA M3LNK命令对M3UA链路执行了去激活操作。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| 本地释放信息     | 用于返回操作员是否使用REL M3LNK命令对M3UA链路执行了释放操作： 未被手工释放：表示操作员没有使用REL M3LNK命令对M3UA链路执行建立操作或者该链路处于系统默认状态。 强制释放：表示操作员使用REL M3LNK命令对M3UA链路执行了释放操作。 优雅释放：表示操作员先使用DEA M3LNK命令去激活该链路，使其处于“未激活”状态，再使用REL M3LNK命令对M3UA链路执行释放操作。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| 链路拥塞信息     | 用于返回M3UA链路的拥塞状态，实际反映的是SCTP的拥塞状况： 拥塞：表示该M3UA链路消息流量过大而产生拥塞。 未拥塞：表示该M3UA链路消息流量正常。 当拥塞发生后，系统将自动执行拥塞控制机制，限制低优先级别信令消息的发送；当拥塞解除后，系统将自动恢复正常。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| 实际输入流数     | 用于返回指定的SCTP偶联接收流的个数，即SCTP偶联最大接收流。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| 实际输出流数     | 用于返回指定的SCTP偶联发送流的个数，即SCTP偶联最大发送流。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| 信令链路选择码    | 用于返回同一链路集下多条链路之间信令业务负荷分担的相关信息。例如，当前链路的信令链路选择码为01 02 03 ，则表示上层用户如果填写的信令链路选择码为01、02或者03时，系统则可以选择该链路发送信令消息。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| 发送负荷(%)    | 用于返回当前M3UA链路实际发送负荷占用总负荷的情况，单位为“%”。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 接收负荷(%)    | 用于返回当前M3UA链路实际接收负荷的占用总负荷的情况，单位为“%”。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| CPU的贡献率(%) | 用于返回当前M3UA链路占用CPU资源的情况，单位为“%”。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| 状态         | 用于返回当前M3UA链路的状态： 未建立：表示SCTP偶联没有建立。若客户端M3UA没有创建到对端节点的SCTP偶联或服务器端M3UA没有收到SCTP偶联成功创建的指示，此时M3UA链路处于链路未建立状态。 已建立：表示SCTP偶联成功创建后，ASP/IPSP（客户端）M3UA没有收到ASP UP ACK消息或SGP/IPSP（服务器端）M3UA没有收到ASP UP消息，此时M3UA链路处于“已建立”状态。处于“已建立”状态的M3UA链路可以发送和接收ASPSM消息（包括ASP UP、ASP DOWN、ASP UP ACK、ASP DOWN ACK），但是不能发送和接收ASPTM消息（包括ASP ACTIVE、ASP ACTIVE ACK、ASP INACTIVE、ASP INACTIVE ACK），SSNM消息（包括NOTIFY、ERROR）和DATA消息。 未激活：表示SCTP偶联已经建立，但是链路还没有被激活。处于“已建立”状态的M2UA链路在ASP/IPSP（客户端）M3UA层收到ASP UP ACK消息或SGP/IPSP（服务器端）M3UA收到ASP UP消息时，状态变为“未激活”；处于“已激活”状态的M3UA链路在ASP/IPSP（客户端）M2UA层收到ASP INACTIVE ACK消息或ASP INACTIVE消息时，状态变为“未激活”。此时，M3UA链路可以发送ASPSM、ASPTM、SSNM等非数据消息。 已激活：表示SCTP偶联已经建立，且已经被激活。处于“未激活”状态的M3UA链路在ASP/IPSP（客户端）M3UA层收到ASP ACTIVE ACK消息或ASP ACTIVE消息时，状态变为“已激活”。此时，M3UA链路可以发送包括数据消息和非数据消息在内的所有的消息类型，如ASPSM、ASPTM、SSNM、DATA消息。 |
