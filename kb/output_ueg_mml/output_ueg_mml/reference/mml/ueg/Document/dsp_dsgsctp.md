# 查看DSG链路状态信息(DSP DSGSCTP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查看DSG模块链路状态信息。

## 注意事项

若输入“远端DSG模块号”则必须输入“远端Location标识”，输入“远端Location标识”不必须输入“远端DSG模块号”。

## 参数说明

| 参数ID    | 参数名称         | 参数描述                                                                      |
|:--------|:-------------|:--------------------------------------------------------------------------|
| MID     | DSG模块号       | 用于请求系统显示哪个DSG模块号的链路状态信息；若不输入，则表示所有的DSG模块号。 取值范围：1～2047 默认值： 无。            |
| RLOCID  | 远端Location标识 | 用于请求系统显示哪个远端Location标识的链路状态信息；若不输入，则表示所有的远端Location标识。 取值范围：1～512 默认值： 无。 |
| RDSGMID | 远端DSG模块号     | 用于请求系统显示哪个远端DSG模块号的链路状态信息；若不输入，则表示所有的远端DSG模块号。 取值范围：1～2047 默认值：无。         |
| IPVER   | IP类型         | 用于请求系统显示哪种IP类型的链路，若不输入，表示显示所有IP类型的链路。 取值范围：IPV4IPV6 默认值：无。                |

## 使用实例

1. 查看DSG链路状态信息。MID为50。

   DSP DSGSCTP: MID=50;

   ```
   %%DSP DSGSCTP: MID=50;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
          DSG模块号  =  50
   远端Location标识  =  5
      远端DSG模块号  =  5
             偶联号  =  5
           链路状态  =  链路已激活
           激活状态  =  未被手工去激活
           健康状态  =  健康
           拥塞状态  =  无拥塞
        发送负荷(%)  =  0
        接收负荷(%)  =  0
             IP类型  =  IPV4
   (结果个数 = 1)

   ---    END
   ```
2. 查看所有DSG链路状态信息。

   DSP DSGSCTP:;

   ```
   %%DSP DSGSCTP:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   DSG模块号  远端Location标识  远端DSG模块号  偶联号  链路状态    激活状态        健康状态  拥塞状态  发送负荷(%)  接收负荷(%)  IP类型

    5          5                 10             1       链路已激活  未被手工去激活   健康     无拥塞     0            0           IPV4    
    5          5                 12             2       链路已激活  未被手工去激活   健康     无拥塞     0            0           IPV4    
   (结果个数 = 2)

   ---    END
   ```

## 输出结果说明

| 参数名称         | 参数描述                                                                 |
|:-------------|:---------------------------------------------------------------------|
| DSG模块号       | 查看链路状态信息所在的DSG模块号。                                                   |
| 远端Location标识 | 本网元所连接的FE和容灾USCDB网元的Location标识。                                      |
| 远端DSG模块号     | 远端DSG模块号。                                                            |
| 偶联号          | 用于确定一条SCTP偶联。                                                        |
| 链路状态         | 用于确定链路状态。共有三种状态：链路已激活、链路去激活和链路拥塞。                                    |
| 激活状态         | 用于确定链路是否被手工去激活。共有两种状态：未被手工去激活和已被手工去激活。                               |
| 健康状态         | 用于确定链路的健康状态。共有两种状态：健康和亚健康。                                           |
| 拥塞状态         | 用于确定链路是否拥塞的实时状态。共有两种状态：无拥塞和最大拥塞。 链路拥塞告警的上报和恢复不是实时的，与此命令查询到的结果可能会不一致。 |
| 发送负荷(%)      | 用于返回SCTP链路发送信息的负荷。                                                   |
| 接收负荷(%)      | 用于返回SCTP链路接收信息的负荷。                                                   |
| IP类型         | 用于返回SCTP链路的IP类型。共有两种类型：IPV4和IPV6。                                    |
