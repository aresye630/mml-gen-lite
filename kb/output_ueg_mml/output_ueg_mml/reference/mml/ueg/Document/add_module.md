## 命令功能

**须知** 

本命令属于高危命令，针对CCU模块如果应用类型设置不合理会导致模块CPU负荷不均匀，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于增加一个模块，启动一个业务进程。

## 注意事项

- 增加模块时，对应Pod名称通过**LST PODINFO**查询。
- 仅当对端对链路总数有限制时，UDM采用主备HSF、BSG模式配置，确保一个Pod故障之后，另外一个备用模块所在Pod能够继续提供业务，从而提升链路冗余性。
- 由于一个Pod上配置的模块个数有限，正常情况下主备模块只有主模块正常工作，当HSF、BSG配置为主备模式时会降低整个系统链路部署的总数。

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                                                                                                                    |
|:---------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MID      | 模块号     | 用于唯一标识一个模块，模块即Pod上运行的进程。该参数的配置原则：模块号在UDM网元内唯一，可以和对端的模块号配置相同。根据实际组网情况，BSG和HSF可以为负荷分担工作模式或者主备工作模式，当为主备工作模式时，需要指定“备用Pod名称”。DSG、ACF（仅虚机场景涉及）、APF（仅虚机场景涉及）和CCU模块为负荷分担工作模式。 取值范围：1～1023 默认值：无。                                                |
| MT       | 模块类型    | 用于指定一个模块的类型。 取值范围： “DPU(DPU)”“DSG(DSG)”“BSG(BSG)”“CCU(CCU)”“PAU(PAU)”“HSF(HSF)”“NSF(NSF)”“ACF(ACF)”“ERU(ERU)”：该模块类型为预留值。“APF(APF)” 默认值：无。 说明：“ACF(ACF)”和“APF(APF)”模块仅在虚机场景下支持。                                                          |
| APPTYPE  | 模块应用类型  | 仅当本命令中的“模块类型”参数为“CCU(CCU)”时该参数有效。用于标识一个模块的应用类型。 取值范围： ALL(ALL)HLR_SAE(2/3/4G)IMS(IMS) 默认值：ALL(ALL) 配置原则：HLR_SAE类型的CCU模块不能只部署在一个Pod上。IMS类型的CCU模块不能只部署在一个Pod上。不能同时部署HLR_SAE和ALL类型的CCU模块。不能同时部署IMS和ALL类型的CCU模块。 说明：模块类型设置不合理会导致模块CPU负荷不均匀。 |
| PODNAME1 | 主用Pod名称 | 用于定义待增加模块所属主用Pod名称。 取值范围：通过LST PODINFO命令查询后输入，也可通过下拉框直接选择。 默认值：无。                                                                                                                                                                       |
| PODNAME2 | 备用Pod名称 | 用于定义待增加模块所属备用Pod名称。 取值范围：通过LST PODINFO命令查询后输入，也可通过下拉框直接选择。 默认值：无。 说明：条件可选参数。当“模块类型”取值为DPU、BSG、PAU和HSF时，如果需要增加备模块，则设置该参数。                                                                                                                |
| MNAME    | 模块名称    | 用于指定一个模块的名称。配置原则：为便于识别，建议模块名称包含模块类型和相应编号。 取值范围：长度不超过32的字符串。 默认值：无。 说明：可选参数。                                                                                                                                                             |

## 使用实例

在开局场景下，为HLR Pod配置DSG模块，此时需要进行如下配置。

1. 登录“ CSP MML命令”界面，执行**LST PODINFO**命令查询“Pod名称”。
2. 由于HLR Pod下的DSG模块为负荷的工作方式，因此执行如下命令，添加DSG模块。

   待增加模块的其它参数配置信息如下：“模块号”为“1”，“模块类型”为“DSG”，“主用Pod名称”为“vApp\_UDM\_01”，“模块名称”为“DSG\_01”。

   ```
   ADD MODULE: MID=1, MT=DSG, PODNAME1="vApp_UDM_01", MNAME="DSG_01";
   ```

该命令执行正常，会返回命令执行成功的提示信息。

| 260021 | 记录已存在，不能增加重复记录  | 本次操作输入的“模块号”在数据库中已存在。           | 通过执行LST MODULE命令查询系统已有模块号，避免重复配置。 |
| 360078 | 指定的PODNAME1不存在。 | “主用Pod名称”参数不存在，添加模块必须在已有Pod上添加。 | 通过执行LST PODINFO命令查询主用Pod对象。       |
| 360079 | 指定的PODNAME2不存在。 | “备用Pod名称”参数不存在，添加模块必须在已有Pod上添加。 | 通过执行LST PODINFO命令查询备用Pod对象。       |
