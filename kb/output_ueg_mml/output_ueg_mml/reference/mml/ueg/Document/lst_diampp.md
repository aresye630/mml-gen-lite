# 查询Diameter协议参数的配置信息(LST DIAMPP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询Diameter协议参数的配置信息：

- 若需要查询全部Diameter协议参数的配置信息，请不要输入任何参数。
- 若需要查询某些Diameter协议参数的详细配置信息，请输入“Diameter协议参数名称”或其它参数或这些参数的组合。

## 注意事项

无。

## 使用实例

1. 查询Diameter协议参数的配置信息，“Diameter协议参数名称”为“MAXPRQLEN(待响应请求队列长度)”：

   ```
   LST DIAMPP: DIAMPN=MAXPRQLEN;
   ```

   ```
   %%LST DIAMPP: DIAMPN=MAXPRQLEN;%%
   RETCODE = 0  操作成功
   ```
