# 查询外部S-CSCF设备的配置信息(LST SLFSCSCF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询SLF的S-CSCF设备的配置信息：

- 若需要查询全部S-CSCF数据记录的信息，请不要输入任何参数。
- 若需要查询某条SLF的S-CSCF数据记录的详细信息，请输入“S-CSCF名称”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                  |
|:-------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SLFN   | SLF名称    | 用于标识查询S-CSCF设备数据记录的SLF名称。 取值范围：1～127位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                           |
| CSCFN  | S-CSCF名称 | 用于标识查询S-CSCF设备数据记录的S-CSCF名称。 取值范围：1～127位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                        |
| HN     | 主机名      | 用于标识查询S-CSCF设备数据记录的主机名。 取值范围：1～127位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                             |
| LNKMOD | 链路选择模式   | 用于标识查询S-CSCF设备数据记录的链路选择模式。 取值范围： SESSIONIDBASED(基于会话ID)：同一个会话的所有信令消息都在同一条链路上传输。多个会话的消息按照轮选的方式在多条链路负荷分担。 POLLING(轮询方式)：当配置多条链路，信令消息在每条链路上负荷分担。 AORS(主备方式)：在主备链路选择方式下，如果主链路故障，则将某条备用链路升为主链路。默认第0条链路为主链路，当第0条链路不可用时，会自动选择其他可用链路。 ACTIVE(激活方式)：根据链路的激活状态，从第0条开始选择第一条激活的链路，将信令消息发往该链路。 ACTIVEWITHPRI(基于优先级的激活方式)：基于优先级的激活方式。 POLLINGWITHPRI(基于优先级的轮询方式)：基于优先级的轮询方式。 默认值：无。 |

## 使用实例

1. 查询SLF所有S-CSCF的配置信息：

   ```
   LST SLFSCSCF:;
   ```

   ```
   %%LST SLFSCSCF:;%%
   RETCODE = 0  操作成功

   查询结果如下

   ------------
    SLF名称  S-CSCF名称  主机名             链路选择模式  SLF索引  S-CSCF索引

    SLF10    SCSCF2      scscf2.huawei.com  轮询方式        0        5         
    SLF3     SCSCF3      scscf3.huawei.com  轮询方式        7        4         
    SLF4     SCSCF4      scscf4.huawei.com  轮询方式        6        3         
   (结果个数 = 3)

   ---    END
   ```
2. 查询SLF的S-CSCF的配置信息，“S-CSCF名称”为“SCSCF2”：

   ```
   LST SLFSCSCF: CSCFN="SCSCF2";
   ```

   ```
   %%LST SLFSCSCF: CSCFN="SCSCF2";%%
   RETCODE = 0  操作成功

   查询结果如下

   ------------
        SLF名称  =  SLF10
     S-CSCF名称  =  SCSCF2
         主机名  =  scscf2.huawei.com
   链路选择模式  =  轮询方式
        SLF索引  =  0
     S-CSCF索引  =  5
   (结果个数 = 1)
   ```
