# 修改IMSI前缀和HLRSN(MOD IMSIHLRSN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改IMSI前缀和HLRSN的对应关系数据记录。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                          |
|:-----------|:-------|:------------------------------------------------------------------------------|
| IMSIPREFIX | IMSI前缀 | 用于标识待修改的和HLRSN关联的IMSI前缀。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                        |
| HLRSN      | HLR序列号 | 用于标识待修改的和IMSI前缀关联的HLR序列号。该参数必须先由ADD HLRSNOFI命令定义，然后才能在此处引用。 取值范围：1～255 默认值：无。 |

## 使用实例

修改IMSI前缀和HLRSN的对应关系数据记录，“IMSI前缀”为“460142”，“HLR序列号”为“2”。命令如下：

```
MOD IMSIHLRSN: IMSIPREFIX="460142", HLRSN=2;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                    | 原因分析                                | 处理建议                                                                        |
|-------:|:-----------------------------------------|:------------------------------------|:----------------------------------------------------------------------------|
| 264050 | 参数IMSIPREFIX只允许输入：0～9。                   | 输入的“IMSI前缀”参数的取值不是1～15位十进制数字组成的字符串。 | 重新输入“IMSI前缀”参数，确保其取值是1～15位十进制数字组成的字符串。                                      |
| 264053 | 指定的HLRSN不存在，请执行LST HLRSNOFI查询已经配置的HLRSN。 | 输入的“HLR序列号”参数在ADD HLRSNOFI命令中未定义。   | 重新输入“HLR序列号”参数，确保其取值在ADD HLRSNOFI命令中已定义。已定义的“HLR序列号参数”可以通过LST HLRSNOFI命令查询。 |
| 264055 | 指定的IMSI前缀不存在。                            | 输入的“IMSI前缀”参数取值不存在。                 | 重新输入“IMSI前缀”参数，确保其取值已存在。已存在的“IMSI前缀”可以通过LST IMSIHLRSN命令查询。                  |
