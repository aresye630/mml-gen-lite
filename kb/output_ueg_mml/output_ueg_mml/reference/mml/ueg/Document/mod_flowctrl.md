# 修改流量控制参数(MOD FLOWCTRL)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，当系统出现不稳定时，如频繁的起流控，需要修改默认的流量控制参数信息，使系统恢复稳定。

## 注意事项

- 该命令不允许进行批操作。
- 该命令中所描述的系统初始设置值，是指操作员通过**LST FLOWCTRL**命令查询得出的系统在初始化时的预置参数值。
- 当UDM的HSF/BSG/CCU/ACF模块的负荷过高产生流控启用告警时，如果通过执行本命令将流控开关参数修改为关闭，流控状态不会解除，告警也不会清除，除非开启流控开关且模块负荷恢复正常后，告警和流控状态才会解除。

## 使用实例

按如下信息修改CCU模块流控参数：

- 模块类型：CCU
- 模块CPU起控门限：100
- 模块CPU解控门限：70
- 虚拟机CPU起控门限：100
- 虚拟机CPU解控门限：80
- 消息队列消息堆积时间重度起控门限(毫秒)：1200
- 消息队列消息堆积时间轻度起控门限(毫秒)：1000
- 消息队列消息堆积时间解控门限(毫秒)：100
- 模块消息队列占用率流控上限：50
- 模块消息队列占用率流控下限：30
- CCU模块流控开关：ON
- SCCP下行消息流控开关：OFF
- USCDB协控开关：ON
- DRU/DSU/DSG协控起控比率：10
- DRU/DSU/DSG协控解控比率：6
- FE DSG协控起控比率：10
- FE DSG协控解控比率：6

```
MOD FLOWCTRL:MT=CCU,CPUFSG=100,CPUFEG=70,BRDCPUFSG=100,BRDCPUFEG=80,MTHSSG=1200,MTLSSG=1000,MTSEG=100,LSTUSEUP=50,LSTUSEDW=30,CCUFCF=ON,SAUFCF=OFF,ASSBECF=ON,RSUFCSTR=10,RSUFCSTP=6,FEDSGFCSTR=10,FEDSGFCSTP=6;
```
