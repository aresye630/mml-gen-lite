# 显示SCTP偶联路径状态(DSP SCTPAP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于请求系统按照模块号和偶联号显示指定SCTP偶联的路径信息，例如当前主路径和次选路径，路径的状态及其最近故障时间，偶联重传超时时间等信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                   |
|:-------|:-------|:---------------------------------------------------------------------------------------|
| MN     | 模块号    | 用于请求系统显示哪个BSG模块内SCTP偶联的基本信息。 取值范围： 1～1023 默认值： 无。                                      |
| AID    | 偶联号    | 用于请求系统显示哪个偶联号的SCTP偶联运行信息。使用命令DSP M3LNK查询获得M3UA链路的SCTP偶联号。 取值范围： 0～65535 默认值： 无。 说明： 无。 |

## 使用实例

显示SCTP偶联路径状态，“模块号”为“100”，“偶联号”为“2”：

`DSP SCTPAP: MN=100, AID=2;`

## 输出结果说明

| 输出项名称    | 输出项解释                                                                                                                  |
|:---------|:-----------------------------------------------------------------------------------------------------------------------|
| 路径       | 用于返回所指定偶联的路径。                                                                                                          |
| 当前主路径    | 用于返回当前路径是否当前运行主路径。                                                                                                     |
| 次选主路径    | 用于返回当前路径是否次选路径。                                                                                                        |
| 状态       | 用于返回当前路径的状态。 激活：表示路径可用。 未激活：表示路径不可用。                                                                                   |
| 故障时间     | 用于返回未激活路径的故障时间，如果路径状态为激活，则最近故障时间显示为NULL。                                                                               |
| 重传超时时间   | 用于返回在当前SCTP偶联上所允许的消息连续重传的时间，单位：毫秒。 例如，若该输出项的值为“1000”，则表示当某个SCTP偶联上的消息在发送后等待1000毫秒，如果还没有收到对端返回的确认消息，SCTP偶联将会向对端重新发送该消息。 |
| 双向传播时间   | 用于返回SCTP偶联从消息发送到接收到对端确认消息的时间，单位：毫秒。该输出项的值表征当前网络的传输质量情况。                                                                |
| 双向传播时间变化 | 用于返回当前SCTP偶联中消息双向传播时间与历史消息双向传播时间平均值的一个变化量，该输出项的值通过系统内部算法得出，表征当前网络的抖动状况。                                                |
