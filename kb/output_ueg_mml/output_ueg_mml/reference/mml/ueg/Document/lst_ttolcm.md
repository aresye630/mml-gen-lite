# 查询通知端口状态 (LST TTOLCM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于管理员在OMU的LMT上查询通知通道6000端口的开启状态。通知任务是HLR向MSC发送自定义MAP消息，MSC可以根据此消息提供定制化业务。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询在线呼叫通知的端口状态。

LST TTOLCM:;

```
%%LST TTOLCM:;%%
RETCODE = 0  操作成功

操作结果为
----------
通知端口的状态  =  关闭
(结果个数 = 1)

---    END
```
