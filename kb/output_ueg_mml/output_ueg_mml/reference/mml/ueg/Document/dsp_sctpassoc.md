# 显示DSG SCTP偶联配置(DSP SCTPASSOC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于请求系统显示DSG模块SCTP偶联配置信息，并生成SCTP偶联话统统计对象。

## 注意事项

- 该命令所显示的DSG模块SCTP偶联配置信息，是最后一次执行**ACT IPDISP**命令请求系统激活IP配置后，DSG模块的偶联配置信息。
- 如果链路配置发生变化，需要在执行**ACT IPDISP**命令后，执行本命令用以更新SCTP偶联话统统计对象信息。如果没有执行本命令，那么SCTP偶联话统统计对象信息不会自动更新，将停留在上次执行本命令的状态。

## 参数说明

无。

## 使用实例

显示DSG SCTP偶联配置信息，执行命令如下：

```
DSP SCTPASSOC:;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1。

| 输出项名称   | 输出项解释                   |
|:--------|:------------------------|
| 偶联对象标识  | 用于返回SCTP偶联测量对象标识。       |
| 本端IP地址1 | 用于返回DSG链路连接的本端设备的IP地址1。 |
| 本端IP地址2 | 用于返回DSG链路连接的本端设备的IP地址2。 |
| 本端端口号   | 用于返回DSG链路连接的本端设备的端口号。   |
| 远端IP地址1 | 用于返回DSG链路连接的远端设备的IP地址1。 |
| 远端IP地址2 | 用于返回DSG链路连接的远端设备的IP地址2。 |
| 远端端口号   | 用于返回DSG链路连接的远端设备的端口号。   |
| DSG业务类型 | 用于返回DSG业务类型。            |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释             | 原因分析         | 处理建议                                    |
|-------:|:------------------|:-------------|:----------------------------------------|
| 385001 | DSG模块没有配置。        | 没有配置DSG模块。   | 通过ADD MODULE命令增加DSG模块的配置。               |
| 385004 | DSG返回SCTP偶联配置不完整。 | 存在DSG模块状态异常。 | 请在DSG状态正常后再重新执行该命令。 请参见产品手册的“模块故障”进行处理。 |
