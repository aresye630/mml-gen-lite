# 修改Diameter对端实体(MOD DMPE)

- 命令功能
- 注意事项
- 参数说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一条Diameter对端实体数据记录的某些参数进行修改或调整。在该命令中，系统通过“实体名称”参数来唯一标识一条Diameter对端实体数据记录。

## 注意事项

- 该命令不允许进行批操作。
- GBA场景下，当BSF和AP合一部署场景：
  - 系统允许**MOD DMPE**配置的“Diameter对端实体类型”为“AP(AP)”的对端实体的主机名和**MOD DMLE**配置的“本端设备类型”为“AP(AP)”的本端实体的主机名相同。
  - 系统允许**MOD DMPE**配置的“Diameter对端实体类型”为“BSF(BSF)”的对端实体的主机名和**MOD DMLE**配置的“本端设备类型”为“BSF(BSF)”的本端实体的主机名相同。

## 参数说明

| 参数标识     | 参数名称             | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|:---------|:-----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| EN       | 实体名称             | 可选必选说明：必选参数 参数含义：标识一条Diameter对端实体数据记录的关键字段，用于指定需要对哪一条Diameter对端实体数据记录的参数进行修改或调整，操作员可以使用LST DMPE命令查询获得。                                                                                                                                                                                                                                                                                                                                                                                     |
| NEN      | 新实体名称            | 可选必选说明：可选参数 参数含义：用于标识一个Diameter对端实体的新名称。 取值范围：长度不超过127的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                         |
| PEERTYPE | Diameter对端实体类型   | 可选必选说明：可选参数 参数含义：用于标识Diameter对端实体的网元类型。 取值范围：OTHER(OTHER)：MME、S4-SGSN、AAA或DRA等网元。AS(AS)：应用服务器。S-CSCF(S-CSCF)：服务呼叫会话控制功能实体。I-CSCF(I-CSCF)：查询-呼叫会话控制功能实体。GGSN(GGSN)：网关GPRS支持节点。SAE(SAE)：归属用户服务器（EPS）。BSF(BSF)：引导服务器功能实体。IMS-HSS(IMS-HSS)：归属用户服务器（IMS）。E-CSCF(CSCF)：紧急-呼叫会话控制功能实体。P-GW(P-GW)：分组数据网关。ePDG(ePDG)：演进分组数据网关。HSGW(HSGW)：HRPD服务网关。Non-3GPP(Non-3GPP)：Non-3GPP接入网关。AP(AP)：业务访问认证代理和转发实体。 默认值：无。                                                                                      |
| HN       | 主机名              | 可选必选说明：可选参数 用参数含义：于标识Diameter对端设备在所属域中的网络主机名。 取值范围：1～127位由数字、字母、“.”和“-”组成的字符串。 默认值：无。 该参数的配置原则：所有字符只能是数字（0～9）、字母（a～z或A～Z）、“.”或“-”。 首字符必须是数字（0～9）或字母（a～z或A～Z），最后一个字符必须是数字（0-9）、字母（a～z或A～Z）或“.”。 “.”不能连续出现且“.”和“-”不能相邻，“..”、“.-”或“-.”为错误配置。 最后一个“.”后面的第一个字符必须为字母（a～z或A～Z）。例如“as.huawei.com”中的最后一个“.”后面的字符串“com”的第一个字符必须为字母。                                                                                                                                                                  |
| DN       | 域名               | 可选必选说明：可选参数 参数含义：仅当本命令中的“Diameter对端实体类型”取值类型为“AS”、“SAE”、“IMS-HSS”时该参数有效。用于标识Diameter对端设备所属域的域名。 取值范围：1～127位由数字、字母、“.”和“-”组成的字符串。 默认值：无。 该参数的配置原则：该参数可以配置为绝对域名或相对域名。绝对域名的长度不超过127，相对域名的长度不超过126。后面带有“.”的就是绝对域名，其他都是相对域名，例如：“huawei.com.”就是绝对域名，“huawei.com”就是相对域名。所有字符只能是数字（0～9）、字母（a～z或A～Z）、“.”或“-”。首字符必须是数字（0～9）或字母（a～z或A～Z），最后一个字符必须是数字（0-9）、字母（a～z或A～Z）或“.”。 “.”不能连续出现且“.”和“-”不能相邻，“..”、“.-”或“-.”为错误配置。 最后一个“.”后面的第一个字符必须为字母（a～z或A～Z）。例如“as.huawei.com”中的最后一个“.”后面的字符串“com”的第一个字符必须为字母。 |
| PEPRI    | Diameter对端实体优先级  | 可选必选说明：可选参数 参数含义：用于标识一个Diameter对端实体的优先级。取值越小优先级越高。该参数仅当同时满足以下条件时生效。该命令中“Diameter对端实体类型”参数为“OTHER(OTHER)”且对端为DRA网元。通过ADD DMRTS命令或MOD DMRTS命令配置的Diameter路由组中“路由选择模式”参数为“基于优先级的激活方式”或“基于优先级的轮询方式”。通过ADD DMRT命令将DRA类型的对端添加到路由组中。 取值范围：0～15 默认值：无。                                                                                                                                                                                                                                              |
| DEVICEID | Diameter对端实体设备标识 | 可选必选说明：可选参数 参数含义：仅当本命令中的“Diameter对端实体类型”参数为“AS(AS)”时该参数有效。用于标识一个Diameter对端实体的设备标识。 取值范围：0～65534 默认值：无。 说明：该参数在AS设备内唯一，即AS类型设备之间不允许存在重复的设备标识，但AS类型设备的设备标识可以与其他非AS类型的设备标识重复。                                                                                                                                                                                                                                                                                                                 |

## 使用实例

在增加Diameter对端实体时输入的“实体名称”、“域名”和“主机名”参数有误。运行以下命令，为“实体名称”为“AS”的Diameter本端实体设置“新实体名称”为“NEWAS”、“主机名”为“as.domainname.com”、“域名”为“domainname.com”、“Diameter对端实体优先级”为“1”、“Diameter对端实体设备标识”为“67”。

```
MOD DMPE: EN="AS", NEN="NEWAS", PEERTYPE=AS, HN="as.domainname.com", DN="domainname.com", PEPRI=1, DEVICEID=67;
```
