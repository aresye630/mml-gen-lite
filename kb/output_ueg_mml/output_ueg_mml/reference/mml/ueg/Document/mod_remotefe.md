# 修改远端FE信息(MOD REMOTEFE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在配置数据库中修改一条远端FE的信息记录。在该命令中，系统通过关键参数“远端Location ID”来唯一标识一条远端FE信息记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称          | 参数说明                                                                                                                                                                  |
|:-------|:--------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RLOCID | 远端Location ID | 标识一条远端FE信息记录的关键字段，用于指定在配置数据库中要修改哪一条远端FE信息记录。操作员可以使用LST REMOTEFE查询获取。 取值范围：1～512 默认值：无。                                                                                |
| FLAG   | 检测标识          | 用于标识本端FE触发自动闭锁信令链路时，远端FE的状态。 同一个局点下所有远端FE的信息中该参数必须设置为同一个值。 取值范围：MUST（Must）：应用于多FE接管1个FE的场景，所有远端FE设备必须全部可用。NOT_MUST（Not must）：应用于1个FE接管1个FE的场景，所有远端FE设备中有可用的设备。 默认值：无。 |

## 使用实例

修改“远端Location ID”为“1”的远端FE的“检测标识”为“MUST（Must）”。命令如下：

```
MOD REMOTEFE: RLOCID=1, FLAG=MUST;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                            | 原因分析                              | 处理建议                                                          |
|-------:|:-------------------------------------------------|:----------------------------------|:--------------------------------------------------------------|
| 335813 | 指定的RLOCID不存在，请执行LST REMOTEFE查看已经存在的记录信息。         | “远端Location ID”参数指定的远端FE信息记录不存在。  | 使用LST REMOTEFE命令查询已增加的远端FE信息后，重新输入需要修改的远端FE的“远端Location ID”。  |
| 335817 | 指定的FLAG跟已有记录的FLAG不一致。请执行LST REMOTEFE查看已经存在的记录信息。 | “检测标识”参数的值与数据库中已经存在记录的“检测标识”值不一致。 | 同一个局点下所有远端FE的“检测标识”必须设置为同一个值，请执行LST REMOTEFE命令查询已添加的远端FE信息记录。 |
