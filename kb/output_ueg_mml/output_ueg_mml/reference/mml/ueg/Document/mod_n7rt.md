# 修改MTP路由(MOD N7RT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于对配置数据库中的一条MTP路由数据记录的某些参数进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一条MTP路由数据记录：

- 目的信令点名称
- 链路集名称

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                              |
|:-------|:--------|:----------------------------------------------------------------------------------------------------------------------------------|
| DPNM   | 目的信令点名称 | 标识一条MTP路由数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪一条MTP路由数据记录的参数进行修改或调整，操作员可以使用LST N7RT命令查询获得。 取值范围：长度不超过32的字符串 默认值：无。 说明：必选参数。              |
| LSNM   | 链路集名称   | 标识一条MTP路由数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪一条MTP路由数据记录的参数进行修改或调整，操作员可以使用LST N7RT命令查询获得。 取值范围：长度不超过32的字符串 默认值：无。 说明：必选参数。              |
| RTNM   | 路由名称    | 其值域类型为字符串，用于具体描述一个MTP路由，以便于识别。可以通过该参数修改路由的名称。 取值范围：长度不超过32的字符串 默认值：无。 说明：可选参数。                                                    |
| PRI    | 路由优先级   | 用于设定该MTP路由的选路优先级，即优先级别高的路由将被优先选择，而优先级别较低的路由只能在比它优先级别较高的信令路由全部变成不可利用以后才能承载信令业务。其中，0为最高优先级，1次之，其余情况依此类推。 取值范围：0～254 默认值：无。 说明：可选参数。 |

## 使用实例

1、修改MTP路由，“目的信令点名称”为“N7DSP”，“链路集名称”为“N7LKS”，“路由名称”改为“MODIFIED”：

```
MOD N7RT: DPNM="N7DSP", LSNM="N7LKS", RTNM="MODIFIED";
```

2、修改MTP路由，“目的信令点名称”为“N7DSP”，“链路集名称”为“N7LKS”，“路由优先级”改为“1”：

```
MOD N7RT: DPNM="N7DSP", LSNM="N7LKS", PRI=1;
```
