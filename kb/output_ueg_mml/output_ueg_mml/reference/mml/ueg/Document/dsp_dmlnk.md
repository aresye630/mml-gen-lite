# 查询Diameter链路状态(DSP DMLNK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询Diameter本端实体到Diameter对端实体之间的Diameter链路的状态信息。

**说明** 

通过查看“ALM-15061 SCTP路径故障告警”可以判断SCTP链路状态，如果有该告警上报，说明告警中链路出现故障。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称          | 参数说明                                              |
|:---------|:--------------|:--------------------------------------------------|
| LINKSNAM | Diameter链路集名称 | 用于指示系统查询哪个Diameter链路集中的链路；若不输入，则表示所有的Diameter链路集。 |
| LNKNAME  | 链路名称          | 用于指示系统查询哪条链路的配置信息；若不输入，则表示所有的Diameter链路。          |

**ADD DMLNK**

命令参数说明中的输出项。

| 输出项名称          | 输出项解释                                                                                                                              |

| Diameter链路状态   | UDM与对端实体之间的Diameter链路状态。 链路正常：链路处于正常状态，可通信。链路断开：链路处于断开状态，不可通信。链路拥塞：链路处于拥塞状态，可通信，质量差。手动去激活：操作员使用DEA DMLNK命令手动去激活该Diameter链路，信令业务中断。 |

| 接收负荷(%)        | 用于返回当前Diameter链路实际接收负荷占用总负荷的情况，单位为“%”。                                                                                             |
