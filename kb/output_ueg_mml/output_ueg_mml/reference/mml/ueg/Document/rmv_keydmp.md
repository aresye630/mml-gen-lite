# 删除关键DIAMETER对端(RMV KEYDMP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在FE/BE整体倒换功能中删除关键DIAMETER对端组中的关键DIAMETER对端。

## 注意事项

只有通过**ADD KEYDMP**命令增加的关键DIAMETER对端才可以在这里删除。

## 参数说明

| 参数标识      | 参数名称            | 参数说明                                                                                                                         |
|:----------|:----------------|:-----------------------------------------------------------------------------------------------------------------------------|
| KEYDMPGNM | 关键DIAMETER对端组名称 | 用于标识在本局的配置数据库中关键DIAMETER对端组，该参数必须先由ADD KEYDMPG命令定义，然后才能在此处索引 取值范围：长度不超过31位的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无 说明：参数取值不能为一个空格 |
| KEYDMP    | 关键Diameter对端名称  | 用于标识对关键DIAMETER对端组中关键DIAMETER对端，该参数必须先由ADD KEYDMP命令定义，然后才能在此处索引。 取值范围：长度不超过127的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。           |

## 使用实例

删除关键Diameter对端，“关键DIAMETER对端组名称”为“KEYDMPG1”，“关键DIAMETER对端名称”为“MME1”：

```
RMV KEYDMP: KEYDMPGNM="KEYDMPG1", KEYDMP="MME1";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释              | 原因分析                             | 处理建议                                                                                                     |
|-------:|:-------------------|:---------------------------------|:---------------------------------------------------------------------------------------------------------|
| 264034 | 关键参数取值不能为一个空格      | 输入的关键参数不能为一个空格。                  | 根据实际情况，重新输入关键参数的取值，确保其取值符合要求。                                                                            |
| 264045 | 指定的关键Diameter对端不存在 | 指定的关键Diameter对端不在关键Diameter对端组中。 | 根据实际情况，重新输入的“关键Diameter对端”存在于对应的“关键DIAMETER对端组”。请执行LST KEYDMPG查看已经存在的“关键DIAMETER对端组”中所包含的“关键DIAMETER对端”。 |
