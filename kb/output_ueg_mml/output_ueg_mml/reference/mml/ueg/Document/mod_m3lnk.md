# 修改M3UA链路(MOD M3LNK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于对配置数据库中的一条M3UA链路数据记录的某些参数进行修改或调整。在该命令中，系统通过“链路名称”参数来唯一标识一条M3UA链路数据记录。

## 注意事项

该命令不允许进行批操作。

## 使用实例

1、修改M3UA链路，“链路名称”为“MODIFIED”，“优先级”为“1”：

```
MOD M3LNK: LNKNM="MODIFIED", PRI=1;
```

2、修改M3UA链路，“链路名称”为“LXT”，“拥塞起始阈值”为80，“拥塞结束阈值”为“30”：

```
MOD M3LNK: LNKNM="LXT", COT=80, CDT=30;
```
