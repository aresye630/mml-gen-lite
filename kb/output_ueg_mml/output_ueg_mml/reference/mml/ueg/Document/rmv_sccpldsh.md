# 删除SCCP目的负荷分担信令点(RMV SCCPLDSH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于从配置数据库中删除一条或者一组SCCP目的负荷分担信令点数据。

## 注意事项

- 如果操作员删除某条SCCP目的负荷分担信令点数据记录，将导致本局与对端设备之间的基于SCCP信令路由的互助功能不可用，请操作员在执行该操作之前仔细确认任务的可行性。
- 在正常情况下，删除一条SCCP目的负荷分担信令点数据记录的操作步骤为：****RMV SCCPLDSH****。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                               |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------|
| DPNM   | DSP名称  | 标识一条SCCP目的负荷分担信令点数据记录的关键字段之一，用于指定需要删除哪一条SCCP目的负荷分担信令点数据记录，操作员可以使用LST SCCPLDSH命令查询获得。 取值范围：长度不超过32的字符串 默认值：无。 说明：无。 |

## 使用实例

删除SCCP负荷分担目的信令点，“DSP名称”为“DSP”：

```
RMV SCCPLDSH: DPNM="DSP";
```
