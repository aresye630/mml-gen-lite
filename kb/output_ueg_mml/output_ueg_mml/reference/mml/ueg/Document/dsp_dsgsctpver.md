# 查看DSG模块SCTP组件版本(DSP DSGSCTPVER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于在配置数据库中查询一个DSG模块所用SCTP组件的版本。

## 注意事项

无。

## 参数说明

| 参数ID   | 参数名称   | 参数描述                                           |
|:-------|:-------|:-----------------------------------------------|
| MID    | DSG模块号 | 用于请求系统显示哪个DSG模块内的SCTP组件协议版本。 取值范围：1～2047 默认值：无 |

## 使用实例

查看DSG模块SCTP组件版本，DSG模块号为102。

**DSP DSGSCTPVER: MID=102;**

```
%%DSP DSGSCTPVER: MID=102;%%
RETCODE = 0  操作成功

操作结果如下
------------
SCTP版本号  =  VPP V300R003C28SPC212B080 (SCTP) EULER 2.0 EULEROS2 GCC4.8.5

(结果个数 = 1)

---    END
```

## 输出结果说明

| 参数名称    | 参数描述                                |
|:--------|:------------------------------------|
| SCTP版本号 | 指定模块的SCTP协议版本号。 如需定位SCTP问题，需提供该版本号。 |
