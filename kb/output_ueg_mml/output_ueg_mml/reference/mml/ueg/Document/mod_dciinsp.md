# 修改DCI内部软件参数(MOD DCIINSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致系统异常，影响业务处理，需联系华为技术支持确认后再执行。

修改DCI内部软件参数的值，包括局内心跳超时时长、局间心跳超时时长、升级状态等。

## 注意事项

在执行此命令前请注意：

- 该命令用于在配置DCI软参数据时，只需要对DCI软参作适当修改以得到所需要的配置数据，而不需要添加或删除软参的操作。
- 在缺省的情况下，系统在初始化的时候已经预置了DCI软参数据表中的全部数据。
- 一般情况下，操作员使用默认值。如果操作员确实需要修改软件参数，请联系华为公司技术服务工程师处理，禁止随意修改。

## 参数说明

| 参数ID   | 参数名称   | 参数描述                                                                                      |
|:-------|:-------|:------------------------------------------------------------------------------------------|
| INSPN  | 软件参数名称 | 标识一条软参数据记录的关键字段之一（其取值在枚举值内取得），用于指定需要对哪一类软参数据记录的参数进行查询。 取值说明： 请参见DCI软件参数管理。 缺省值：无。 说明：必选参数 |
| INSPV  | 软件参数值  | 标识一条软参数据记录的关键字段之一，此处取值应在取值范围内取值。 取值说明： 请参见DCI软件参数管理。 缺省值：无。 说明：必选参数                       |

## 使用实例

修改DCI软参。软件参数名称为OUTERHEARTBEATTIMEOUT，软件参数值为20000。

```
MOD DCIINSP: INSPN=OUTERHEARTBEATTIMEOUT, INSPV=20000;
```
