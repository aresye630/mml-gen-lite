# 查询测量单元描述的配置信息(LST MSUNIT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询当前系统中测量单元描述的配置信息：

- 若需要查询全部测量单元描述的概要配置信息，不输入任何参数。
- 若需要查询某个测量单元描述的详细配置信息，请输入“测量单元标识”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                |
|:-------|:--------|:--------------------------------------------------------------------------------------------------------------------|
| UNITID | 测量单元标识  | 用于唯一标识一个测量单元。 取值范围：0～65535 默认值：无。                                                                                   |
| ENNUM  | 测量指标数目  | 用于标识测量指标数目。 取值范围：0～65535 默认值：无。                                                                                     |
| OBJID  | 测量对象ID  | 用于唯一标识一个被测对象。 取值范围：0～65535 默认值：无。                                                                                   |
| PERIOD | 输出结果周期  | 用于标识输出测量结果的周期。 取值范围： ONEMINUTE(1分钟)FIVEMINUTES(5分钟)FIFTEENMINUTES(15分钟)THIRTYMINUTES(30分钟)SIXTYMINUTES(60分钟) 默认值：无。 |
| ISUSED | 系统中是否使用 | 用于标识系统中是否使用该测量单元。 取值范围： NOTUSED(没有使用)USED(使用) 默认值：无。                                                                |

## 使用实例

1. 查询测量单元描述的配置信息，“测量单元标识”为“512”，“输出结果周期”为“FIVEMINUTES”，“系统中是否使用”为“USED”：

   ```
   LST MSUNIT: UNITID=512, PERIOD=FIVEMINUTES, ISUSED=USED;
   ```
