# 修改对端HTTP实体域名(MOD HTTPPEHOST)

- 注意事项

- 输出结果说明

## 命令功能

该命令用于修改系统中的一条对端HTTP实体域名配置。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

执行该命令配置“对端域名”取值需要与命令**MOD HTTPPE**中配置的对端域名保持一致。

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                                          |
|:-------|:-----------|:--------------------------------------------------------------------------------------------------------------|
| PEID   | 对端HTTP实体标识 | 可选必选说明：必选参数。 参数含义：用于指定待修改的对端HTTP实体域名配置的对端实体标识。 取值范围：0～255 默认值：无。 配置原则：无。                                      |
| HOST   | 对端域名       | 可选必选说明：必选参数。 参数含义：用于指定标识HTTP对端实体的对端域名。 取值范围：1～127字符串。 默认值：无。 配置原则：该参数不区分大小写，在执行LST HTTPPEHOST命令查询出的报文中为全小写形式。 |

## 使用实例

修改“对端HTTP实体标识”为“1”的“对端域名”为“ap1.huawei.com”:

```
MOD HTTPPEHOST: PEID=1, HOST="ap1.huawei.com";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释   | 原因分析                    | 处理建议                                                     |
|-------:|:--------|:------------------------|:---------------------------------------------------------|
| 335821 | 记录不存在。  | 输入的“对端HTTP实体标识”参数取值不存在。 | 执行LST HTTPPEHOST命令查询已配置的“对端HTTP实体标识”，重新输入该参数，再执行本命令进行修改。 |
