# 删除MTP屏蔽策略(RMV MTPPOL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于从配置数据库中删除一条MTP屏蔽策略数据记录。

## 注意事项

- 如果命令执行成功，且删除的数据为已有性能统计任务中登记的对象实例，则该对象实例后续上报的指标值为0。命令涉及的测量单元有：MTP屏蔽测量与MTP目的信令点测量。
- 如果操作员删除某条MTP屏蔽策略数据记录，则对于特定的入局MAP信令消息而言，本局将不能对这些入局MAP信令消息进行屏蔽，从而有可能导致本局与相关网元之间的信令链路拥塞或过载，请操作员在执行该操作之前仔细确认任务的可行性。
- 在正常情况下，删除一条MTP屏蔽策略数据记录的操作步骤为：**RMV MTPPOL**。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                                                    |
|:-------|:----------|:--------------------------------------------------------------------------------------------------------|
| MTPNM  | MTP屏蔽策略名称 | 标识一条MTP屏蔽策略数据记录的关键字段之一，用于指定需要删除哪一条MTP屏蔽策略数据记录，操作员可以使用LST MTPPOL命令查询获得。 取值范围：长度不超过32的字符串 默认值：无。 说明：必选参数。 |

## 使用实例

删除MTP屏蔽策略，“MTP屏蔽策略名称”为“MTPPOL”:

```
RMV MTPPOL: MTPNM="MTPPOL";
```
