# 查询本端模拟MME配置(LST LMMECFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询已配置的本端模拟MME数据记录。

- 若需要查询某个本端模拟MME的配置信息，请输入“本端模拟MME名称”参数。
- 若需要查询全部本端模拟MME的配置信息，请不输入任何参数。

  **说明** 

  该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                                      |
|:--------|:----------|:----------------------------------------------------------------------------------------------------------|
| MMENAME | 本端模拟MME名称 | 可选必选说明：可选参数 参数含义：用于指定系统按照哪个本端模拟MME名称查询本端模拟MME数据记录。若不输入，则表示所有的本端模拟MME名称。 取值范围：长度不超过127的字符串。 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询“本端模拟MME名称”为“MME01”的本端模拟MME数据记录。

   ```
   LST LMMECFG: MMENAME="MME01";
   ```

   ```
   %%LST LMMECFG: MMENAME="MME01";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
     本端模拟MME名称  =  MME01
   本端模拟MME主机名  =  mme.huawei.com
     本端模拟MME域名  =  huawei.com
   (结果个数 = 1)

   ---    END
   ```
2. 查询所有的本端模拟MME数据记录。

   ```
   LST LMMECFG:;
   ```

   ```
   %%LST LMMECFG: ;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
     本端模拟MME名称  =  MME01
   本端模拟MME主机名  =  mme.huawei.com
     本端模拟MME域名  =  huawei.com
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD LMMECFG**命令的参数说明。
