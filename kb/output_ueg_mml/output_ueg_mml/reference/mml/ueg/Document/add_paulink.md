# 增加PAU链路(ADD PAULINK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于增加UDM与ADD Server之间的TCP链路信息。

UDM用作EIR网元功能时，UDM通过PAU模块和ADD Server之间建立TCP链路。UDM实现将TCP类型的ADD消息发送给ADD Server，运营商在ADD Server上定制业务时根据业务需求将用户数据通过短消息更新到用户终端。

## 注意事项

一个PAU模块允许最大支持16条链路。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                       |
|:-----------|:---------|:---------------------------------------------------------------------------------------------------------------------------|
| LINKNAME   | 链路名称     | 用于标识待增加的PAU链路的名称。 取值范围：1～64位的字符串。 默认值：无。                                                                                   |
| MID        | PAU模块号   | 用于标识待增加的PAU链路所属PAU模块的模块号。该参数必须先由ADD MODULE命令定义，且“模块类型”为“PAU”，然后才能在此处引用。 取值范围：0～1023 默认值：无。                                 |
| PROTTYPE   | 协议类型     | 用于标识待增加的PAU链路所属PAU模块支持的协议类型。 取值范围： “TCP(TCP)”：传输控制协议。 默认值：无。                                                               |
| IPVER      | IP版本     | 用于指定IP地址的类型。该地址类型必须和远端网元的配置保持一致。 取值范围： “IPV4(IPV4版本)”：配置IPV4类型IP地址时使用。 “IPV6(IPV6版本)”：配置IPV6类型IP地址时使用。 默认值：无。              |
| LOCALIPV4  | 本端IPV4地址 | 仅当参数“IP版本”取值为“IPV4(IPV4版本)”时该参数有效。用于标识待增加的PAU链路本端的IPV4地址。该参数必须先由ADD IPADDR命令定义，且“网关类型”为“PAU”，然后才能在此处引用。 取值范围：IPV4地址 默认值：无。 |
| LOCALIPV6  | 本端IPV6地址 | 仅当参数“IP版本”取值为“IPV6(IPV6版本)”时该参数有效。用于标识待增加的PAU链路本端的IPV6地址。该参数必须先由ADD IPADDR命令定义，且“网关类型”为“PAU”，然后才能在此处引用。 取值范围：IPV6地址 默认值：无。 |
| LOCALPORT  | 本端端口号    | 用于标识待增加的PAU链路本端的端口号。 取值范围：0～65535 默认值：无。                                                                                   |
| REMOTEIPV4 | 远端IPV4地址 | 仅当参数“IP版本”取值为“IPV4(IPV4版本)”时该参数有效。用于标识待增加的PAU链路远端的IPV4地址。 取值范围：IPV4地址 默认值：无。                                               |
| REMOTEIPV6 | 远端IPV6地址 | 仅当参数“IP版本”取值为“IPV6(IPV6版本)”时该参数有效。用于标识待增加的PAU链路远端的IPV6地址。 取值范围：IPV6地址 默认值：无。                                               |
| REMOTEPORT | 远端端口号    | 用于标识待增加的PAU链路远端的端口号。 取值范围：1～65535 默认值：无。                                                                                   |
| PRI        | 链路优先级    | 用于标识待增加的PAU链路的优先级。 取值范围：1～32 默认值：1 说明：该参数取值越大优先级越高，数值相同表示优先级相同。链路优先级不区分模块，只和链路相关，即多个模块链路同时判断优先级。                           |

## 使用实例

UDM通过PAU模块和ADD Server之间建立一条TCP链路，“链路名称”为“PAULINK\_1”，“PAU模块号”为“1”，“协议类型”为“TCP(TCP)”，“IP版本”为“IPV4(IPV4)”，“本端IPV4地址”为“10.100.25.209”，“本端端口号”为“3568”，“远端IPV4地址”为“10.100.2.36”，“远端端口号”为“3001”，“链路优先级”为“1”：

```
ADD PAULINK: LINKNAME="PAULINK1", MID=1, PROTTYPE=TCP, IPVER=IPV4, LOCALIPV4="10.100.25.209", LOCALPORT=3586, REMOTEIPV4="10.100.2.36", REMOTEPORT=3001, PRI=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                     | 原因分析                                | 处理建议                                                              |
|-------:|:--------------------------|:------------------------------------|:------------------------------------------------------------------|
| 335485 | 单PAU模块不允许配置超过16条链路。       | 已经在输入的“PAU模块号”参数代表的模块上设置了16条链路。     | 请重新输入“PAU模块号”参数，确保在该模块配置的链路没有超过16条。已配置的链路可以通过LST PAULINK命令查询获得。   |
| 335499 | 参数LOCALIPV4和LOCALPORT已存在。 | 输入的“本端IPV4地址”参数和“本端端口号”参数配置的链路已经存在。 | 请重新输入“本端IPV4地址”参数和“本端端口号”参数，确保其未配置链路。已配置的链路可以通过LST PAULINK命令查询获得。 |
