# 查询系统资源(DSP SYSRES)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于请求系统显示系统资源信息，如资源总数、已经使用的资源及资源使用率，以便及时了解系统运行状况。

## 注意事项

无。

## 参数说明

| 参数ID    | 参数名称   | 参数说明                                                 |
|:--------|:-------|:-----------------------------------------------------|
| RESTYPE | 资源类型   | 用于请求系统显示资源类型。 取值范围： PCDR(PCDR缓冲区) 默认值：无。             |
| MID     | 模块号    | 用于请求系统显示一个指定模块，并用作模块数据记录索引。 取值范围：0～4294967294 默认值：无。 |

## 使用实例

查询系统资源，“资源类型”为“PCDR”：

```
DSP SYSRES: RESTYPE=PCDR;
```

```
%%DSP SYSRES: RESTYPE=PCDR;%%
RETCODE = 0  操作成功

查询结果如下
------------
 模块号  资源类型    资源总数  已经使用的资源  资源使用率(百分比)

 5       PCDR缓冲区  31457280  0               0                 
 6       PCDR缓冲区  31457280  0               0                 
(结果个数 = 2)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见本命令的参数说明，表1列出的是未包含在本命令参数说明中的输出项。

| 输出项名称      | 输出项解释          |
|:-----------|:---------------|
| 资源总数       | 用于返回系统资源的总数量。  |
| 已经使用的资源    | 用于返回系统资源已使用数量。 |
| 资源使用率(百分比) | 用于返回系统资源使用率。   |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释     | 原因分析                                                  | 处理建议                                                                                                        |
|-------:|:----------|:------------------------------------------------------|:------------------------------------------------------------------------------------------------------------|
| 335667 | HSF模块不存在。 | “资源类型”参数设为“PCDR(PCDR缓冲区)”且未输入“模块号”参数时，系统不存在HSF或ACF模块。 | 根据实际情况，重新输入各参数的取值，确保满足当“资源类型”参数设为“PCDR(PCDR缓冲区)”且未输入“模块号”参数时，系统存在HSF或ACF模块。已存在的HSF或ACF模块可以通过LST MODULE命令查询。 |
