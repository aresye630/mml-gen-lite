# 删除GBA用户信息(RMV GBAUSER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于从配置数据库中删除GBA用户的所有信息，包括TMPI和IMPI的配对信息、用户的鉴权信息以及用户的GUSS信息。当用户数据迁移、数据同步等，TMPI和IMPI配对信息会发生相应变化，从而产生垃圾数据，通过该命令可以删除GBA用户的垃圾数据信息。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                                                                                        |
|:-------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------|
| IMPI   | IP多媒体私有标识 | 标识一条GBA用户信息的关键字段，用于指定需要删除哪一条GBA用户信息数据记录。 取值范围：长度不超过127的字符串。 默认值：无。 注意：该参数为必选参数。  说明： “IMPI”参数在HSS业务发放系统中通过ADD HSUB命令进行设置，可通过LST HSUB命令查询获得。 |

## 使用实例

删除GBA用户信息，“IP多媒体私有标识”为“460123456789huawei”：

执行命令如下：

```
RMV GBAUSER: IMPI="460123456789huawei";
```
