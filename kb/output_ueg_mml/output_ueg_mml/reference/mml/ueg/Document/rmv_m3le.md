# 删除M3UA本地实体(RMV M3LE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于从配置数据库中删除一条M3UA本地实体数据记录。

## 注意事项

- 如果本地实体为其他本地实体的互助本地实体，则操作员必须先使用**MOD M3LE**命令删除互助关系。
- 在正常情况下，该命令仅在开局时由开局工程师在数据调测的过程中使用。删除一个M3UA本地实体的步骤：**RMV M3LNK**-->**RMV M3LKS**-->**RMV M3DE**-->**RMV M3LE**。

## 参数说明

| 参数标识   | 参数名称   | 参数描述                                                                                                   |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------|
| LENM   | 本地实体名称 | 标识一条M3UA本地实体数据记录的关键字段，用于指定需要删除哪一条M3UA本地实体数据记录，操作员可以使用LST M3LE命令查询获得。 取值范围: 长度不超过32的字符串。 默认值: 无。 说明: 无。 |

## 使用实例

删除M3UA本地实体，“本地实体名称”为“MODIFIED”：

```
RMV M3LE: LENM="MODIFIED";
```
