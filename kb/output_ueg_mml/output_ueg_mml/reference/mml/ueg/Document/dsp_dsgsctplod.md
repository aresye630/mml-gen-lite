# 查看SCTP负荷信息(DSP DSGSCTPLOD)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，查看SCTP负荷信息。

## 注意事项

无。

## 参数说明

| 参数ID   | 参数名称   | 参数描述                                            |
|:-------|:-------|:------------------------------------------------|
| MID    | DSG模块号 | 用于请求系统显示哪个DSG模块内的SCTP负荷信息。 取值范围： 1～2047 默认值： 无。 |

## 使用实例

查看SCTP负荷信息，DSG模块号为102。

**DSP DSGSCTPLOD: MID=102;**

```
%%DSP DSGSCTPLOD: MID=102;%%
RETCODE = 0  操作成功

操作结果如下
------------
 偶联号  发送负荷(%)  接收负荷(%)

 3       0            0          
 5       0            0          
(结果个数 = 2)

---    END
```

## 输出结果说明

| 参数名称    | 参数描述                                  |
|:--------|:--------------------------------------|
| 偶联号     | SCTP偶联号码。                             |
| 发送负荷(%) | SCTP链路发送信息的负荷。 通过此参数可以查看当前偶联的发送负荷的高低。 |
| 接收负荷(%) | SCTP链路接收信息的负荷。 通过此参数可以查看当前偶联的接收负荷的高低。 |
