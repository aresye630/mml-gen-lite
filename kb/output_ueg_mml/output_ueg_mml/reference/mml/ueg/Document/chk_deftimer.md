# 校验定时器默认值(CHK DEFTIMER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于在配置数据库中查询当前值和默认值不一致的定时器值的配置信息。

该命令的操作场景一般为：操作员通过该命令校验当前的后台数据，当定时器当前值和定时器默认值有差异时，操作员可以对有差异的定时器值分析是否存在错误。

## 注意事项

无。

## 参数说明

无。

## 使用实例

校验定时器默认值：

```
CHK DEFTIMER:;
```

返回结果如下：

```
%%CHK DEFTIMER:;%%
RETCODE = 0  操作成功

定时器值校验
------------
是否和默认值相等  =  不相等
        模块 PID  =  257
      定时器索引  =  1
      定时器序号  =  1
    定时器值(秒)  =  3
定时器默认值(秒)  =  2
      定时器名称  =  M3UA_FSM_ASPM
  定时器协议名称  =  ASPSM/ASPTM
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称    | 输出结果解释              |
|:---------|:--------------------|
| 是否和默认值相等 | 用于返回定时器当前值和默认值是否相等。 |
| 模块PID    | 业务模块的PID。           |
| 定时器索引    | 业务模块的定时器索引。         |
| 定时器序号    | 业务模块的定时器序号。         |
| 定时器值     | 定时器当前的取值。单位是s。      |
| 定时器默认值   | 定时器的系统默认取值。单位是s。    |
| 定时器名称    | 该定时器的简要含义描述名称。      |
| 定时器协议名称  | 该定时器的对应的协议名称。       |
