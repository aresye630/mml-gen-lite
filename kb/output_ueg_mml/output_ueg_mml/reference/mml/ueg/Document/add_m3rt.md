# 增加M3UA路由(ADD M3RT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条M3UA路由数据记录。

## 注意事项

除SG（Signaling Gateway）以外，对于所有通过**ADD M3DE**命令定义的目的实体，操作员均需通过此命令为该目的实体定义M3UA路由。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                 |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RTNM   | 路由名称   | 用于具体描述一个M3UA路由，以便于识别。 取值范围：长度不超过32的字符串。 默认值：无。 说明： 此参数为可以联想的MOC对象。执行了ADD M3RT或者MOD M3RT之后参数值列表可以立刻更新，执行了RMV M3RT后，参数值列表1小时之内可以自动更新，如果要手动刷新，请单击右键，在弹出的菜单中选择“更新联想参数值”。 |
| DENM   | 目的实体名称 | 用于定义该M3UA路由所指向的目的实体，该参数必须先由ADD M3DE命令定义，然后才能在此处引用。 取值范围：长度不超过32的字符串 默认值：无。 说明：无。                                                                                     |
| LSNM   | 链路集名称  | 用于指定到达该的目的实体的M3UA路由，即本局通过哪个M3UA链路集传输信令，该参数必须先由ADD M3LKS命令定义，然后才能在此处引用。 取值范围：长度不超过32的字符串 默认值：无。 说明：无。                                                                 |
| PRI    | 路由优先级  | 用于设定该M3UA链路集（信令路由）的选路优先级，即优先级别高的链路集将被优先选择，而优先级别较低的链路集只能在比它优先级别较高的信令路由全部变成不可利用以后才能承载信令业务。 取值范围：0～254。 默认值：0。 说明：0为最高优先级，1次之，即数值越高，优先级越低。                              |

## 使用实例

1、增加M3UA路由，“目的实体名称”为“M3DE”，“链路集名称”为“M3LKS”：

```
ADD M3RT: DENM="M3DE", LSNM="M3LKS";
```

2、增加M3UA路由，“路由名称”为“M3RT”，“目的实体名称”为“M3DE”，“链路集名称”为“M3LKS”，“路由优先级”为“1”：

```
ADD M3RT: RTNM="M3RT", DENM="M3DE", LSNM="M3LKS", PRI=1;
```
