# 删除远端网元IP地址(RMV RIPADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于删除远端网元IP地址。

## 注意事项

- 要删除的远端网元IP地址必须存在。
- 删除远端网元IP地址后，请使用**ACT IPDISP**命令使修改生效。
- 删除远端网元IP地址将影响本端DSG和远端DSG的网络连接，导致业务中断，请谨慎使用。
- UDM不支持该命令。

## 参数说明

| 参数标识   | 参数名称              | 参数说明                                                                                                    |
|:-------|:------------------|:--------------------------------------------------------------------------------------------------------|
| RLOCID | 远端Location标识      | 远端Location的标识。远端Location和远端网元一一对应。 取值范围：1~512 默认值：无。                                                    |
| ID     | 远端DPU模块号/远端业务IP索引 | 标识一个远端网元IP地址的关键字段之一，用于指定需要删除哪一个远端DPU模块号/远端业务IP索引的远端网元IP地址。 操作员可以使用LST RIPADDR命令查询获得。 取值范围：1～4080 默认值：无。 |

## 使用实例

删除远端网元IP地址。远端Location标识为3，ID为1。

RMV RIPADDR: RLOCID=3, ID=1;
