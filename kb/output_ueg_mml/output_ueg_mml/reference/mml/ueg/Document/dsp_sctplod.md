# 查询SCTP负荷信息(DSP SCTPLOD)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于请求系统显示指定的SCTP链路的负荷信息。

## 注意事项

无。

## 参数说明

| 参数ID   | 参数名称   | 参数描述                                                                                                                                                            |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MN     | 模块号    | 用于请求系统显示哪个BSG模块内的SCTP链路负荷信息。 当输入模块号时，输出的信息是该BSG模块内的SCTP链路的负荷信息。当不输入模块号时，输出的信息是每个BSG模块内的负荷信息，即所有协议负荷的总和。需要注意的是，此结果表示模块在当前工作状态的瞬时负荷情况。 取值范围：1～1023 默认值： 无。 说明： 无。 |

## 使用实例

1. 显示所有BSG模块内Pod的SCTP链路负荷信息：

   ```
   DSP SCTPLOD:;
   ```

   ```
   %%DSP SCTPLOD:;%%
   RETCODE = 0  操作成功

   SCTP模块负荷信息
   ----------------
    模块号  发送负荷(%)  接收负荷(%)  负荷占用比率(%)

    29      0            0            0              
    80      0            0            0              
    81      0            0            0              
    82      0            0            0              
    83      0            0            0              
    84      0            0            0              
    85      0            0            0              
    86      0            0            0              
    87      0            0            0              
   (结果个数 = 9)

   ---    END
   ```
2. 显示BSG模块内Pod的SCTP链路负荷信息，“模块号”为“29”：

   ```
   DSP SCTPLOD: MN=29;
   ```

   ```
   %%DSP SCTPLOD: MN=29;%%
   RETCODE = 0  操作成功

   SCTP协议负荷信息
   ----------------
          协议类型  =  M3UA
       发送负荷(%)  =  0
       接收负荷(%)  =  0
   负荷占用比率(%)  =  0
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

| 参数名称      | 参数描述                         |
|:----------|:-----------------------------|
| 模块号       | 用于请求系统显示哪个BSG模块内的SCTP链路负荷信息。 |
| 协议类型      | 用于返回单个BSG模块上的SCTP链路的协议类型。    |
| 发送负荷(%)   | 用于返回SCTP链路发送信息的负荷。           |
| 接收负荷(%)   | 用于返回SCTP链路接收信息的负荷。           |
| 负荷占用比率(%) | 用于返回SCTP链路的负荷占用情况。           |
