# 查询SCTP流量控制参数(LST SCTPFCPARA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于在数据库中查询SCTP流控参数。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询SCTP流控参数：

**LST SCTPPARA:;**

```
%%LST SCTPFCPARA:;%%
RETCODE = 0  操作成功

SCTP流控参数
------------
一级阈值  =  70
二级阈值  =  90
统计周期  =  1
(结果个数 = 1)

---    END
```

## 输出结果说明

| 参数名称   | 参数描述                                                          |
|:-------|:--------------------------------------------------------------|
| 一级阈值   | 用于定义SCTP流控过载的一级阈值，单位为“百分比”， 系统推荐值为50。该参数的配置原则是： 一级阈值应小于二级阈值。  |
| 二级阈值   | 用于定义SCTP流控过载的二级阈值，单位为“百分比”， 系统推荐值为90。 该参数的配置原则是： 二级阈值应大于一级阈值。 |
| 统计周期   | 用于定义SCTP流控过载的统计周期，单位为“秒”， 系统推荐值为1。                            |
