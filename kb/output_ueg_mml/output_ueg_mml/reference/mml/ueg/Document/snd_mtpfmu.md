# 发送MTP用户层伪消息(SND MTPFMU)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为维护类命令，用于请求系统在指定的MTP链路上发送MTP用户伪消息。

该命令仅适用于测试场景，例如在IOT（Inter Operability Test）测试中，操作员可以通过该命令提供仿真协议接口以完成某些特定的测试项目，而在其他情况下，请勿使用该命令。

## 注意事项

- MTP用户层伪消息由主机下发到负责信令处理的模块，这些消息可能对信令链路造成严重影响，请操作员在执行该操作之前仔细确认任务的可行性。
- 在使用该命令前，请使用**DSP N7DSP**命令查询目的信令点的状态，只有在目的信令点的状态为“可达”时，系统才能发送伪消息。
- 在使用该命令前，请使用**DSP N7LNK**命令查询发送伪消息的MTP链路的状态，只有在MTP链路的状态为“使用”时，系统才能发送伪消息。

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                                                                                                   |
|:-------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MN     | CCU/BSG模块号 | 用于指定发送MTP用户层伪消息的模块号。 取值范围：1～1023 默认值：无。 说明：必选参数。                                                                                                                       |
| MPT    | 单位消息数      | 用于指定一个单位发送周期内发送的消息数，推荐配置为1。 取值范围：1～30 默认值：无。 说明：必选参数。                                                                                                                  |
| TCK    | 单位发送周期     | 用于指定一个单位发送周期的时长，单位发送周期用滴答（tick）数表示，1个滴答等于10毫秒。推荐配置为1。 取值范围：0～255 默认值：无。 说明：必选参数。                                                                                       |
| NUM    | 单位消息组数     | 用于指定单位消息组数，推荐配置为1。该参数的配置原则是： 如果单位消息组数为0，表示不断地连续发送用户伪消息。 如果单位消息组数不为0（如1）时，表示发送一定数量的伪消息，直到发完为止。 发送的总消息数=单位消息组数*单位消息数。 取值范围：0～65534 默认值：无。 说明：必选参数。                       |
| LEN    | 消息长度       | 用于指定伪消息长度，应包括SIO长度。 取值范围：1～273 默认值：无。 说明：必选参数。                                                                                                                         |
| SIO    | SIO值       | 用于指定伪消息的SIO值。 取值范围：0～255 默认值：无。 说明：必选参数。                                                                                                                               |
| PM     | 参数         | 用于指定消息内容（十六进制格式），格式如下所示： |----DPC----|----OPC----|----SLS----| 14/24比特 14/24比特 1字节中的4比特 需与MTP三层协议(Q.704)指定的消息格式一致，且参数的字节顺序应为网络的字节顺序。 取值范围：0～272 字节的码流串 默认值：无。 说明：必选参数。 |
| DIR    | 方向         | 用于指定伪消息发送的方向是“上行”还是“下行”。 取值范围：UP(上行)DOWN(下行) 默认值：DOWN(下行) 说明：无。                                                                                                        |
| LNKNM  | 链路名称       | 仅当本命令中的参数“方向”为“上行”时该参数有效，用于指定消息是从哪条链路收上来的。 需要指出的是链路必须已经建链成功才会正确的发送伪消息，否则消息无法发送出来。 取值范围：1～32 为字符串 默认值：无。 说明：无。                                                          |

## 使用实例

发送MTP用户层伪消息，“模块号”为“1022”，“单位消息数”为“1”，“单位发送周期”为“1”，“单位消息组数”为“10”，“消息长度”为“27”，“SIO值”为“129”，“参数”为“AA AA AA BB BB BB 00 09 81 03 08 0D 05 43 AA AA AA 0C 05 43 BB BB BB 0C 01 00”：

```
SND MTPFMU: MN=1022, MPT=1, TCK=1, NUM=10, LEN=27, SIO=129, PM="AA AA AA BB BB BB 00 09 81 03 08 0D 05 43 AA AA AA 0C 05 43 BB BB BB 0C 01 00";
```
