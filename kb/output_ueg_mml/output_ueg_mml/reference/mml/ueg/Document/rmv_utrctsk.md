# 删除用户跟踪任务 (RMV UTRCTSK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于删除指定用户的跟踪任务。

## 注意事项

当前版本不支持此功能，执行该命令后会返回错误码：335607 暂不支持该功能。

## 参数说明

| 参数标识           | 参数名称       | 参数说明                                                                                                                                                                                                                         |
|:---------------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NETTYPE        | 网络类型       | 用于标识用户跟踪数据的号码所在网络类型。 取值范围：E2E_2G(2G/3G)：2G/3G网络端到端跟踪。LTE-SAE(LTE-SAE)：LTE(Long Term Evolution)网络跟踪，该网络功能由SAE-HSS提供。IMS(IMS)：IMS（IP multimedia subsystem）网络跟踪，该网络功能由IMS-HSS网元提供。 默认值：无。                                       |
| CT             | 用户号码类型     | 删除用户跟踪数据的号码类型。 取值范围： IMSI(IMSI)：根据IMSI删除MSISDN/MDN(MSISDN/MDN)；根据MSISDN/MDN删除TRACEREF(跟踪参考)：根据跟踪参考删除 默认值：无。 说明：当参数“网络类型”为“E2E_2G(2G/3G)”时，此参数可见。此参数为必选参数。                                                                    |
| UN             | 用户号码       | 删除跟踪任务的用户的号码。据CT号码取值，UN号码为如下2种类型。 IMSI号码，E.212格式的编码，为6～15位的十进制数字。 MSISDN/MDN号码，E.164格式的编码，为1～15位的十进制数字。 默认值：无。 说明：当参数“网络类型”为“E2E_2G(2G/3G)”，CT为IMSI或MSISDN/MDN时，该参数有效。                                                       |
| TRACEREFERENCE | 跟踪参考       | 用于删除用户跟踪任务的记录号。 取值范围：1～65535。 默认值：无。 默认值：无。 说明：当参数“网络类型”为“E2E_2G(2G/3G)”，CT为TRACEREF时，该参数有效。                                                                                                                                 |
| IDTYPE         | 用户标识类型     | 用于指定删除用户跟踪数据的号码类型。 取值范围：0～2。 默认值：无。 说明：当参数“网络类型”为“LTE-SAE”时，此参数可见。当“用户标识类型”为0时，必须输入“跟踪任务标识”，且“IMSI”、“MSISDN/MDN”必须为空；当“用户标识类型”为1时，必须输入“IMSI”，且“跟踪任务标识”、“MSISDN/MDN”必须为空； 当“用户标识类型”为2时，必须输入“MSISDN/MDN”，且“跟踪任务标识”、“IMSI”必须为空。 |
| TRCID          | 跟踪任务标识     | 仅当本命令中的“网络类型”参数取值为“LTE-SAE(LTE-SAE)”或“IMS(IMS)”时该参数有效。且当“网络类型”参数取值为“LTE-SAE(LTE-SAE)”时，若“用户标识类型”参数取值为“0”，该参数必须设定；若“用户标识类型”参数取值为“1”或“2”，该参数必须为空。用于标识要删除的用户跟踪任务的记录号。 取值范围：0～16777215。 默认值：无。                                   |
| IMSI           | IMSI       | 用于删除用户跟踪任务对应用户的IMSI。 取值范围： E.212格式的编码，为6～15位的十进制数字。 默认值：无。 说明：当参数“网络类型”为“LTE-SAE”时，此参数可见。且当“用户标识类型”为1时，该参数必须设定；当“用户标识类型”为其他值时，该参数必须为空。                                                                                       |
| MSISDN         | MSISDN/MDN | 用于删除用户跟踪任务对应用户的MSISDN/MDN。 取值范围： E.164格式的编码，为1～15位的十进制数字。 默认值：无。 说明：当参数“网络类型”为“LTE-SAE”时，此参数可见。且当“用户标识类型”为2时，该参数必须设定；当“用户标识类型”为其他值时，该参数必须为空。                                                                                 |
| IMPU           | IP多媒体公共标识  | 仅当本命令中的“网络类型”参数取值为“IMS(IMS)”时该参数有效。用于标识IP多媒体公共标识，该标识是用户对外可寻址的标识，用于请求和其他用户通信，全局唯一。 取值范围：长度不超过127的字符串。 默认值：无。                                                                                                                  |

## 使用实例

删除IMSI号码为“4603038006008”的“2G/3G端到端”用户跟踪任务。

`RMV UTRCTSK: NETTYPE=E2E_2G, CT=IMSI, UN="4603038006008";`
