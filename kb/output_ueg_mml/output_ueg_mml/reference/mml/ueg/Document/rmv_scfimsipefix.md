## 命令功能

**须知** 

本命令属于高危命令，执行不当会导致用户鉴权失败、无法正常接入网络。因此执行该命令前，请仔细检查配置的正确性，确认无误后方可执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用于从IMSI号段组中删除一条IMSI号段信息记录。

## 注意事项

- 当“IMSI号段组名称”对应的IMSI号段组中只有一条IMSI号段信息并且该IMSI号段组已经被业务控制功能配置引用，则该IMSI号段信息不能被删除。如果要删除该IMSI号段信息，必须先执行**MOD SCFCFG**或**RMV SCFCFG**命令去引用该“IMSI号段组名称”对应的IMSI号段组。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识      | 参数名称      | 参数说明                                                                                |
|:----------|:----------|:------------------------------------------------------------------------------------|
| GRPNAME   | IMSI号段组名称 | 标识一条IMSI号段数据记录的关键字段之一，用于指定需要删除与哪一条IMSI号段组相关的IMSI号段数据记录，操作员可以使用LST SCFIMSIGRP命令查询获得。 |
| IMSIPEFIX | IMSI号段    | 标识一条IMSI号段数据记录的关键字段之一，用于指定需要删除哪一条IMSI号段数据记录，操作员可以使用LST SCFIMSIPEFIX命令查询获得。          |

## 使用实例

从IMSI号段组中删除一条与IMSI号段组相关的IMSI号段记录。“IMSI号段组名称”为“GRPNAME1”，“IMSI号段”为“1318527”：

```
RMV SCFIMSIPEFIX: GRPNAME="GRPNAME1", IMSIPEFIX="1318527";
```
