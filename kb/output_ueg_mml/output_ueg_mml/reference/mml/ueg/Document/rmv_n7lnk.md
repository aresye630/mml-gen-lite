# 删除MTP链路(RMV N7LNK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于从配置数据库中删除一条MTP链路数据记录。

## 注意事项

- 如果命令执行成功，且删除的数据为已有性能统计任务中登记的对象实例，则该对象实例后续上报的指标值为0。命令涉及的测量单元有：MTP信令链路测量；命令涉及的测量对象有：MTP信令链路。
- 如果本局与对端信令设备之间配置有2条或以上的MTP链路（操作员可以使用**LST N7LNK**命令查询），则删除一条MTP链路数据记录的操作步骤为：**RMV N7LNK**。
- 如果本局与对端信令设备之间仅配置有1条MTP链路（操作员可以使用**LST N7LNK**命令查询），为确保本局与对端信令设备之间MTP信令的通信连接，请勿使用该命令执行删除操作。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                                                                                                                    |
|:-------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LNKNM  | 链路名称     | 标识一条MTP链路数据记录的关键字段，用于指定需要删除哪一条MTP链路数据记录，操作员可以使用LST N7LNK命令查询获得。 取值范围：长度不超过32的字符串 默认值：无。 说明：必选参数。                                                                                                                                        |
| FRLF   | 删除最后链路标志 | 当该MTP链路是相应MTP链路集中的最后一条链路时，用于指示系统是否强制删除该MTP链路，系统默认值为“否”。各参数选项的含义是： 是：表示强制删除该MTP链路。这样将导致相应的MTP链路集所承载的信令业务全部中断，请操作员在执行该操作之前仔细确认任务的可行性。 否：表示不强制删除该MTP链路。即保护相应的MTP链路集内至少还有一条MTP链路可以承载信令业务。 取值范围： “TRUE(是)”“FALSE(否)” 默认值：“FALSE(否)” 说明：可选参数。 |

## 使用实例

1、删除MTP链路，“链路名称”为“N7LNK\_1”, “删除最后链路标志”为“是”：

```
RMV N7LNK: LNKNM="N7LNK_1", FRLF=TRUE;
```
