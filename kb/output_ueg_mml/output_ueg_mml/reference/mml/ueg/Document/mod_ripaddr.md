# 修改远端网元IP地址(MOD RIPADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于修改远端网元IP地址。

## 注意事项

- 该操作将影响本端DSG和远端DSG的网络连接，导致业务中断，请谨慎使用。
- 修改远端网元IP地址后，需要执行**ACT IPDISP**激活IP链路。
- UDM不支持该命令。

## 参数说明

| 参数标识    | 参数名称               | 参数说明                                                                                                                                                                      |
|:--------|:-------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RLOCID  | 远端Location标识       | 标识一个远端网元IP地址的关键字段之一，用于指定要修改的远端网元IP地址的远端Location。此参数必须在远端网元中已经配置完毕。 操作员可以使用LST RIPADDR命令查询获得远端Location和远端网元IP地址的对应关系。 取值范围：1～512 默认值：无。                                    |
| ID      | 远端DPU模块号/远端业务IP索引  | 标识一个远端网元IP地址的关键字段之一，用于指定需要对哪一个远端DPU模块号/远端业务IP索引的网元IP地址进行修改或调整。此参数必须在远端网元中已经配置完毕。 操作员可以使用LST RIPADDR命令查询获得。 取值范围：1～4080 默认值：无。                                             |
| IPVER   | IP类型               | 用于表示IP地址类型。 取值范围： IPV4：配置IPV4类型IP使用IPV6：配置IPV6类型IP使用 默认值：无。                                                                                                               |
| IPV4IP1 | 远端Location IPV4地址1 | 远端网元的Location IP地址。这个地址必须在远端网元中已经配置完毕。 取值范围：IPV4地址 默认值：无。                                                                                                                 |
| IPV6IP1 | 远端Location IPV6地址1 | 远端网元的Location IP地址。这个地址必须在远端网元中已经配置完毕。 当参数“IP类型”设置为“IPV6(IPV6)”时，该参数有效，格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如：2001:DB8:8432:4098:4782:5784::。 取值范围：IPV6地址 默认值：无。 |
| IPV4IP2 | 远端Location IPV4地址2 | 远端网元的Location IP地址。这个地址必须在远端网元中已经配置完毕。 取值范围：IPV4地址 默认值：无。                                                                                                                 |
| IPV6IP2 | 远端Location IPV6地址2 | 远端网元的Location IP地址。这个地址必须在远端网元中已经配置完毕。 当参数“IP类型”设置为“IPV6(IPV6)”时，该参数有效，格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如：2001:DB8:8432:4098:4782:5784::。 取值范围：IPV6地址 默认值：无。 |

## 使用实例

修改远端网元IP地址：设置“远端Location标识”为“3”，“远端DPU模块号/远端业务IP索引”为“1”，“IP类型”为“IPV4”，“远端Location IPV4地址1”为“192.168.128.12”，“远端Location IPV4地址2”为“192.168.129.12”。执行如下命令：

```
MOD RIPADDR: RLOCID=3, ID=1, IPVER=IPV4, IPV4IP1="192.168.128.12", IPV4IP2="192.168.129.12";
```
