# 删除GSID业务属性数据(RMV ASATTRIBUTE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在配置数据库中删除一条GSID业务属性数据。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

删除GSID业务属性数据，可能会导致用户终端的业务访问操作受限及业务操作的安全性降低，请谨慎操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                        |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------|
| ID     | 索引     | 标识一条GSID业务属性数据记录的关键字段，用于指定需要删除哪一条GSID配置信息数据记录，操作员可以使用LST ASATTRIBUTE命令查询获得。 取值范围：1～255。 默认值：无。 注意：该参数为必选参数。 |

## 使用实例

删除一条GSID业务属性数据，“索引”为“1”，执行命令如下：

```
RMV ASATTRIBUTE: ID=1;
```
