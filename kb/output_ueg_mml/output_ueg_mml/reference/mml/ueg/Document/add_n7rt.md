# 增加MTP路由(ADD N7RT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条MTP路由数据记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                     |
|:-------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------|
| RTNM   | 路由名称    | 其值域类型为字符串，用于具体描述一个MTP路由，以便于识别。 取值范围：长度不超过32的字符串 默认值：无。 说明：可选参数。                                                                          |
| DPNM   | 目的信令点名称 | 用于指定该MTP路由所指向的目的信令点，该参数必须先由ADD N7DSP命令定义，然后才能在此处引用。需要指出的是，除STP以外，所有通过ADD N7DSP命令定义的目的信令点均需通过此命令定义MTP路由。 取值范围：长度不超过32的字符串 默认值：无。 说明：必选参数。 |
| LSNM   | 链路集名称   | 用于指定到达相应的目的信令点的MTP路由，即本局通过哪个MTP链路集传输信令，该参数必须先由ADD N7LKS命令定义，然后才能在此处引用。 取值范围：长度不超过32的字符串 默认值：无。 说明：必选参数。                                  |
| PRI    | 路由优先级   | 用于设定该MTP路由的选路优先级，即优先级别高的路由将被优先选择，而优先级别较低的路由只能在比它优先级别较高的信令路由全部变成不可利用以后才能承载信令业务。其中，0为最高优先级，1次之，其余情况依此类推。 取值范围：0～254 默认值：0 说明：可选参数。         |

## 使用实例

1、增加MTP路由，“目的信令点名称”为“N7DSP”，“链路集名称”为“N7LKS”：

```
ADD N7RT: DPNM="N7DSP",LSNM="N7LKS";
```

2、增加MTP路由，“路由名称”为“N7RT”，“目的信令点名称”为“N7DSP”，“链路集名称”为“N7LKS”，“路由优先级”为“1”：

```
ADD N7RT: RTNM="N7RT", DPNM="N7DSP", LSNM="N7LKS",PRI=1;
```
