## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为维护类命令，用于请求系统对指定的模块执行倒换操作。模块倒换后，备用模块接替原主用模块工作，原主用模块处于备用状态。

## 注意事项

- 仅当模块的主备状态为主用状态时才可成功执行该命令。
- 倒换可能会影响业务运行。执行倒换命令，最好避开话务高峰。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                     |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------|
| MID    | 模块号    | 标识一条模块配置信息的关键字段，用于指定待倒换的主备模块，该参数可以使用LST MODULE命令查询获得。                                                                                    |
| FORCE  | 是否强制倒换 | 用于指定是否进行模块的强制倒换。强制倒换是不管倒换的进程是否在处理业务，直接倒换进程，这样容易造成业务中断。非强制倒换是如果进程不提供业务，则倒换成功，如果进程提供业务，则进程倒换失败。 取值范围： “NO(否)”“YES(是)” 默认值：“NO(否)” 说明：可选参数。 |

## 使用实例

倒换业务进程。模块号为1，采用非强制倒换方式。

```
SWP MODULE: MID=1, FORCE=NO;
```
