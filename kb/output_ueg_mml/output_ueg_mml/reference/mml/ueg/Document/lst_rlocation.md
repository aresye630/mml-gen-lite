# 查询远端Location信息(LST RLOCATION)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询远端Location信息。

## 注意事项

无。

## 参数说明

| 参数ID   | 参数名称         | 参数描述                                                                                                                                                                                                                                               |
|:-------|:-------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RLOCID | 远端Location标识 | 远端Location的标识，远端Location和远端网元一一对应。远端Location是相对的，具体如下：对于主用局FE，它的远端Location指主用局USCDB、容灾局USCDB。对于主用局USCDB，它的远端Location指主用局FE、容灾局FE、容灾局USCDB。对于容灾局FE，它的远端局Location指容灾局USCDB、主用局USCDB。对于容灾局USCDB，它的远端Location指容灾局FE、主用局FE、主用局USCDB。 取值范围：1～512 默认值： 无。 |
| RMT    | 远端网元类型       | 远端网元的类型。 取值范围：USCDB(USCDB) 默认值：无。                                                                                                                                                                                                                  |
| LP     | 位置ID优先级      | 远端Location优先级。优先级值越小，优先级越高。如果配置了多个远端Location，优先访问优先级高的远端Location。 取值范围：1～512 默认值： 无。                                                                                                                                                               |

## 使用实例

查询本端配置的远端Location。

LST RLOCATION:;

```
%%LST RLOCATION:;%%
RETCODE = 0  操作成功

操作结果如下
------------
                        远端Location标识  =  89
                            远端网元类型  =  USCDB
                            位置ID优先级  =  1
(结果个数 = 1)

---    END
```
