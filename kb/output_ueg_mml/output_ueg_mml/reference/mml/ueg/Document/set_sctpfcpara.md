# 设置SCTP流量控制参数(SET SCTPFCPARA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于在配置数据库中设置SCTP流控参数数据记录。

## 注意事项

在本局中，SCTP协议可以用于承载M3UA的SCTP用户层信令，操作员在使用**SET SCTPFCPARA**命令设置SCTP流控参数时，其设置结果将对全局所有的SCTP偶联产生影响。因此，操作员在使用此命令时应十分谨慎，如果确实需要修改某些SCTP流控参数，请仔细阅读命令中该参数的详细解释及相关的注意事项。 另外，需要指出的是，本命令中所描述的初始设置值，是指操作员通过**LST SCTPFCPARA**命令查询得出的系统初始化的参数值。 如果上层链路上配置了SCTP流控参数，则上层链路上配置的SCTP流控参数优先适用。

## 参数说明

| 参数ID       | 参数名称   | 参数描述                                                                                    |
|:-----------|:-------|:----------------------------------------------------------------------------------------|
| CTRLVAL1   | 一级阈值   | 用于定义SCTP流控过载的一级阈值，单位为“百分比”， 系统推荐值为50。该参数的配置原则是： 一级阈值应小于二级阈值。 取值范围： 1～98 默认值： 无。 说明： 无。  |
| CTRLVAL2   | 二级阈值   | 用于定义SCTP流控过载的二级阈值，单位为“百分比”， 系统推荐值为90。 该参数的配置原则是： 一级阈值应小于二级阈值。 取值范围： 1～99 默认值： 无。 说明： 无。 |
| STATPERIOD | 统计周期   | 用于定义SCTP流控过载的统计周期，单位为“秒”， 系统推荐值为1。 取值范围： 1～10 默认值： 无。 说明： 无。                            |

## 使用实例

设置SCTP流控参数，一级阈值为60，二级阈值为90，统计周期为1：

`SET SCTPFCPARA: CTRLVAL1=60, CTRLVAL2=90, STATPERIOD=1;`
