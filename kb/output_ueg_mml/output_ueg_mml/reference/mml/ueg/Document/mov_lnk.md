## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于将指定链路从当前所在BSG模块，迁移到指定的BSG模块上。

## 注意事项

- 本命令会将链路从当前所在模块删除，并根据原有的链路配置信息，在目的BSG模块上加载链路。
- 执行本命令会导致链路重建。在迁移链路前，请先用**DEA N7LNK**或者**DEA M3LNK**去激活链路以避免呼损。
- 执行该命令之前，需要通过**LST MODULE**命令查询BSG主备情况，禁止在主备BSG模块上部署MTP链路。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                                                                                                |
|:---------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LNKTYPE  | 链路类型     | 用于指定要迁移的链路类型。各参数选项的含义是： 需要指出的是： 当迁移基于TDM承载的MTP链路时，操作员需要完成ETIA后插板的E1端口连接。 当迁移基于ATM承载的MTP链路时，将同时迁移该链路对应的PVC链路。 取值范围: “M3LNK(M3UA link)”“TDMN7LNK(N7LNK over TDM)”“ATMN7LNK(N7LNK over ATM)” 默认值: 无。 说明: 无。            |
| LNKNM    | 链路名称     | 此选项含义如下： 当链路类型为“M3LNK”时：输入M3UA链路名称。操作员可以使用LST M3LNK命令查询获得。 当链路类型为“TDMN7LNK”时：输入基于TDM承载的MTP链路名称。操作员可以使用LST N7LNK命令查询获得。 当链路类型为“ATMN7LNK”时：输入基于ATM承载的MTP链路名称。操作员可以使用LST N7LNK命令查询获得。 取值范围: 长度不超过32的字符串 默认值: 无。 说明: 无。 |
| DMN      | 目的模块号    | 用于指定链路迁移的目的模块号。必须先在ADD MODULE中定义，可以用LST MODULE命令查询BSG模块号。 需要指出的是，当“链路类型”为“TDMN7LNK”时: 如果不输入目的模块号，则必须同时输入目的框号、目的槽号、目的TDM端口号和目的时隙号 取值范围:1～1023 默认值: 无。 说明: 无。                                                         |
| SRN      | 目的框号     | 当“链路类型”为“TDMN7LNK”时显示，用于指定迁移的MTP链路的目的框位号。 需要指出的是： 必须同时输入目的槽号、目的TDM端口号和目的时隙号。 取值范围：0～19 默认值：无。 说明：无。                                                                                                                 |
| SLOT     | 目的槽号     | 当“链路类型”为“TDMN7LNK”时显示，用于指定迁移的MTP链路的目的槽位号。 需要指出的是： 必须同时输入目的框号、目的TDM端口号和目的时隙号。 取值范围：0～13 默认值：无。 说明：无。                                                                                                                 |
| TDMPORT  | 目的TDM端口号 | 当“链路类型”为“TDMN7LNK”时显示，用于指定该MTP链路迁移后所占用的E1端口号。 需要指出的是： 必须同时输入目的框号、目的槽号和目的时隙号。 如果E1端口号变更，对端需要重新配置链路。 取值范围：0～31 默认值：无。 说明：无。                                                                                           |
| TIMESLOT | 目的时隙号    | 当“链路类型”为“TDMN7LNK”时显示，用于指定该MTP链路迁移后所占用的E1内部时隙号。 需要指出的是： 必须同时输入目的槽号、目的槽号和目的TDM端口号。 如果时隙号变更，对端需要重新配置链路。 取值范围：0～31 默认值：无。 说明：无。                                                                                        |

## 使用实例

迁移链路，“链路类型”为“M3LNK”，“链路名称”为“M3UALINK”，“目的模块号”为“1”：

```
MOV LNK: LNKTYPE=M3LNK, LNKNM="M3UALINK", DMN=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释                       | 原因分析                                      | 处理建议                                                               |
|-------:|:---------------------------|:------------------------------------------|:-------------------------------------------------------------------|
| 306979 | 指定的BSG模块是主备模块，不能用来配置N7LNK。 | 输入的“BSG模块号”对应的进程为主备模式，不能用来配置MTP链路，因此迁移失败。 | 执行LST MODULE命令查询配置为负荷分担模式的BSG模块对应的“模块号”，重新输入“BSG模块号”的取值，确保其取值符合要求。 |
