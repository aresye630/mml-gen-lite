# 查询队列流控消息权重(LST QFCMQW)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询队列流控消息的权重信息：

- 若需要查询全部队列流控消息权重信息，请不要输入任何参数。
- 若需要查询某个队列流控消息权重的详细信息，请输入“消息名称”参数。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                 |
|:-------|:-------|:-----------------------------------------------------|
| QFCMN  | 消息名称   | 用于指示系统按照哪个消息名称来查询队列流控消息权重信息；若不输入，则表示查询所有的队列流控消息权重信息。 |

## 使用实例

   ```
   LST QFCMQW:;
   ```

2. 查询“消息名称”为“AAAA”的队列流控消息的权重信息，命令如下：

   ```
   LST QFCMQW: QFCMN=AAAA;
   ```

   ```
   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见

**MOD QFCMQW**

命令的参数说明。表1列出的是未包含在

**MOD QFCMQW**

命令参数说明中的输出项。

| 输出项名称   | 输出项解释                                 |
|:--------|:--------------------------------------|
| 消息OP码   | 用于返回业务流程中消息的OP码。                      |
| 消息应用类型  | 用于返回业务流程中消息的应用类型。 取值范围：ENSIMSSAEGUAAA |
