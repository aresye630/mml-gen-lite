# 修改关键DIAMETER对端组(MOD KEYDMPG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在FE/BE整体倒换功能中对某一条关键DIAMETER对端组数据进行修改或调整。在该命令中，系统通过“关键DIAMETER对端组名称”参数来唯一标识一条关键DIAMETER对端组数据记录。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称                      | 参数说明                                                                                                                          |
|:------------|:--------------------------|:------------------------------------------------------------------------------------------------------------------------------|
| KEYDMPGNM   | 关键DIAMETER对端组名称           | 标识一条关键DIAMETER对端组数据记录的关键字段（其取值不能被修改），用于指定需要对哪一条关键DIAMETER对端组数据记录的参数进行修改或调整，操作员可以使用LST KEYDMPG命令查询获得。                          |
| KEYDMPGNNM  | 新的关键DIAMETER对端组名称         | 用于在本局的配置数据库中唯一标识一条关键DIAMETER对端组数据，不能与已有关键DIAMETER对端组数据重复。操作员可以使用LST KEYDMPG命令查询获得。 取值范围：长度不超过31位的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 |
| WEIGHT_RATE | 关键DIAMETER对端组在联动倒换中的比例(%) | 用于标识关键DIAMETER对端组在联动倒换中的权重比例。 取值范围：0～100 单位：%                                                                                 |

## 使用实例

修改关键DIAMETER对端组，“关键DIAMETER对端组名称”为“KEYDRA”，“新的关键DIAMETER对端组名称”为“KEYPRA”，“关键DIAMETER对端组在联动倒换中的比例(%)”为“50”：

`MOD KEYDMPG: KEYDMPGNM="KEYDRA", KEYDMPGNNM="KEYPRA", WEIGHT_RATE=50;`
