# 增加MTP屏蔽策略(ADD MTPPOL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于在配置数据库中增加一条MTP屏蔽策略数据记录。

## 注意事项

- 为了网络拥塞时灵活地对来自其他网元的消息进行屏蔽。
- 此时，操作员需要使用**ADD MTPPOL**命令增加MTP屏蔽策略。本局在收到其他网元的消息时，MTP层可以按照NI、DPC、OPC、SI、信令链路集或者消息流量来决定是否丢弃。对于符合屏蔽策略的消息，本局在MTP层直接丢弃，否则正常传送。
- 为保证信令网状态正常，不对信令网测试消息和信令网管理消息进行屏蔽。
- 用户在运用此功能的过程中，需谨慎的添加屏蔽条件，确保不要将本网正常的业务消息屏蔽掉。对于不再需要的屏蔽条件，应及时删除掉，以避免产生不必要的业务损失。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
|:------------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MTPNM       | MTP屏蔽策略名称 | 用于在配置数据库中唯一标识一条MTP屏蔽策略数据，其值域类型为字符串，最大长度为32。需要指出的是： MTP屏蔽控制功能对所有入局的MTP信令消息有效，而对出局的MTP信令消息无效。 MTP屏蔽控制功能不对信令网测试消息和信令网管理消息进行屏蔽。 对于操作员在OMU Client输入的字符串，系统在操作OMU数据库之前将自动进行如下处理：将该字符串中的所有英文字母全部转换成大写、并将该字符串中最左边与最右边的空格删除掉。例如，假设操作员输入的字符串为“ 区域abc ”，则系统在操作OMU数据库之前将自动将该字符串转换为“区域ABC”。 对于操作员通过本命令配置的某一条具体的数据记录而言，假设该数据记录中“MTP屏蔽策略名称”字段的原取值为A，如果操作员后续需要将该字段的取值由A修改为B，则其可以通过MOD MTPPOL命令中的“新MTP屏蔽策略名称”参数重新进行定义。此时，对于配置数据库中索引了取值为A的所有数据记录的“MTP屏蔽策略名称”字段，系统将自动把这些字段的值由A修改为B。 名称只允许输入: 0～9，a-z，A-Z，“-”和中文字符。 取值范围：长度不超过32的字符串 默认值：无。 说明：必选参数。 |
| NI          | 网络指示      | 启动MTP屏蔽控制的过滤条件之一，当本局所接收到的某条MTP信令消息中的网络指示语字段符合此处指定的参数值时，本局才可能启动MTP屏蔽控制。 当信令点编码有效时，此参数必须输入。 取值范围： “INT(国际主用网)”“INTB(国际备用网)”“NAT(国内主用网)”“NATB(国内备用网)” 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                                                                               |
| DPC         | 目的信令点编码   | 启动MTP屏蔽控制的过滤条件之一，当本局所接收到的某条MTP信令消息中携带的DPC参数符合此处指定的参数值时，本局才可能启动MTP屏蔽控制。 本局与No.7信令设备的对接参数之一，用于指定该目的信令点在No.7信令网中的信令点编码。 取值范围：长度不超过11的字符串 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                                                                                            |
| OPC         | 源信令点编码    | 启动MTP屏蔽控制的过滤条件之一，当本局所接收到的某条MTP信令消息中携带的OPC参数符合此处指定的参数值时，本局才可能启动MTP屏蔽控制。 取值范围：长度不超过11的字符串 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                                                                                                                                          |
| LSNM        | 链路集名称     | 启动MTP屏蔽控制的过滤条件之一，用于指定按照MTP链路所属的链路集来进行屏蔽。对于某条MTP信令消息，根据它携带的DPC和SLS信息查询到的链路集名称符合此处指定的链路集名称时，本局才可能启动MTP屏蔽控制。 取值范围：长度不超过32的字符串 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                                                                                                       |
| MAXTRAFFIC  | 流量阈值      | 启动MTP屏蔽控制的过滤条件之一，用于指定在单位时间内所允许通过的MTP信令消息包（MSU）的最大数量。 假设操作员在本命令中将“流量单位”参数设为“每小时”、将“流量阈值”设为1000，则本局将以“小时”为单位对本局接收的MTP信令消息实施流量控制：如果在1小时内，本局所接收到的MTP信令消息包小于1000，则本局将不实施流量控制；如果在1小时内，本局所接收到的MTP信令消息包已经达到1000，则在本小时的其余时间内，本局将丢弃后续所接收到的所有MTP信令消息包。当下一个时间单位开始时，本局将对本局接收到的MTP信令消息包重新进行统计（即将相应的统计计数器清零）。 取值范围：0～2147483647 默认值：0 说明：可选参数                                                                                                                                                                                                   |
| TRAFFICUNIT | 流量单位      | 对应于上述启动MTP屏蔽控制的组合过滤条件，用于指示按照什么样的时间单位来对本局接收到的MTP信令消息实施流量控制。 取值范围： “PER_HOUR(每小时)”“PER_DAY(每天)”“PER_MONTH(每月)”“PER_YEAR(每年)” 默认值：“PER_HOUR(每小时)” 说明：可选参数。                                                                                                                                                                                                                                                                                                                                                                          |

## 使用实例

1、增加MTP屏蔽策略,“MTP屏蔽策略名称”为“MTPPOL”,“网络指示”为“国内主用网”，“源信令点编码”为“BB0033”,“流量阈值”为“100”，“流量单位”为“每小时”：

```
ADD MTPPOL: MTPNM="MTPPOL", NI=NAT, OPC="BB0033", TRAFFICUNIT=PER_HOUR, MAXTRAFFIC=100;
```

2、增加MTP屏蔽策略,“MTP屏蔽策略名称”为“MTPPOL”,“目的信令点编码”为“AA0033”,“链路集名称”为“TEST”：

```
ADD MTPPOL: MTPNM="MTPPOL", NI=NAT, DPC="AA0033", LSNM="TEST";
```
