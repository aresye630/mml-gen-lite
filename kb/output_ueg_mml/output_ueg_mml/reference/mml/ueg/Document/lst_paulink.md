# 查询PAU链路(LST PAULINK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询PAU链路的配置信息：

- 若需要查询全部链路的配置信息，请不要输入任何参数值。
- 若需要查询某些链路的配置信息，请输入“链路名称”参数或“模块号”参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                             |
|:---------|:-------|:-------------------------------------------------|
| LINKNAME | 链路名称   | 用于指示系统按照哪个PAU链路名称来查询PAU链路信息；若不输入，则表示所有的PAU链路信息。  |
| MID      | PAU模块号 | 用于指示系统按照哪个PAU模块号来查询PAU链路信息；若不输入，则表示所有模块的PAU链路信息。 |

## 使用实例

1. 查询全部链路的配置信息：

   ```
   LST PAULINK:;
   ```

   ```
   %%LST PAULINK:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   链路名称         PAU模块号     协议类型    IP版本      本端IPV4地址      本端IPV6地址   本端端口号      远端IPV4地址      远端IPV6地址       远端端口号      链路优先级 
   PAULINK_1        1             TCP         IPV4版本    10.100.25.209     NULL            3568           10.100.2.36       NULL               3001            1 
   PAULINK_2        1             TCP         IPV4版本    10.100.25.210     NULL            3567           10.100.2.36       NULL               3001            1 
   (结果个数 = 2)

   ---    END
   ```
2. 查询“链路名称”为“PAULINK\_1”，“PAU模块号”为“1”的链路配置信息：

   ```
   LST PAULINK: LINKNAME="PAULINK_1", MID=1;
   ```

   ```
   %%LST PAULINK: LINKNAME="PAULINK_1", MID=1;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
       链路名称  =  PAULINK1
      PAU模块号  =  20
       协议类型  =  TCP
         IP版本  =  IPV4版本
   本端IPV4地址  =  192.168.10.155
   本端IPV6地址  =  NULL
     本端端口号  =  3586
   远端IPV4地址  =  10.144.163.59
   远端IPV6地址  =  NULL
     远端端口号  =  3001
     链路优先级  =  1
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD PAULINK**命令中的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释         | 原因分析            | 处理建议                                                   |
|-------:|:--------------|:----------------|:-------------------------------------------------------|
| 335486 | 对象PAULINK不存在。 | 输入的“链路名称”参数不存在。 | 请重新输入“链路名称”参数，确保其存在。已存在的“链路名称”参数可以通过LST PAULINK命令查询获得。 |
