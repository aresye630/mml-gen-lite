## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于修改协议适配数据

## 注意事项

- “密码”参数和“确认密码”参数必须同时输入且相同。
- 该命令不允许进行批操作。
- 当前版本不支持此功能，执行该命令后会返回错误码：335607 暂不支持该功能。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                             |
|:------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROTTYPE    | 协议类型   | 用于指定当前支持的协议类型。 取值范围： “SMPP(SMPP)”：短消息点对点传输协议。 默认值：无。 说明：必选参数。                                                                                                                                                                                                                                                                                                                                    |
| USERNAME    | 用户名    | 用于指定用户名。 取值范围：1～15字符串 默认值：无。 说明：必选参数。                                                                                                                                                                                                                                                                                                                                                            |
| USERPWD     | 密码     | 用于标识用户密码。 取值范围：1～16位字符串。 默认值：无。 说明：如果MOD INSP命令中将“软件参数类型”为“HSS9860”的“PWD_COMP_SWITCH（密码兼容开关）”参数设为“1”，则该参数为取值为1～16位字符串。如果MOD INSP命令中将“软件参数类型”为“HSS9860”的“PWD_COMP_SWITCH（密码兼容开关）”参数设为“0”，则该参数遵循如下配置原则：密码必须至少包含以下四个类别中的三类：英文大写字母英文小写字母数字：0～9特殊字符：~ ! # % ^ * ( ) _ - + [ ] { } | < > . ? 不允许使用三个或三个以上连续的字母或数字（例如：ABC、123）。密码不能和帐号或者帐号的逆序一样。不允许使用三个或三个以上连续的相同字符（例如：AAA）。密码长度不能少于8位字符。密码的第一个字符必须是字母。 |
| USERPWDCNFM | 确认密码   | 用于标识确认密码。确认密码用于和“密码”比对，确认两者是否相同。 取值范围：1～16位的字符串。 默认值：无                                                                                                                                                                                                                                                                                                                                           |

## 使用实例

修改SMPP类型的适配数据。修改用户名为test的密码。

```
MOD PADATA: PROTTYPE=SMPP, USERNAME="test", USERPWD="*****", USERPWDCNFM="*****";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释              | 原因分析                        | 处理建议                                                                         |
|-------:|:-------------------|:----------------------------|:-----------------------------------------------------------------------------|
| 260071 | 用户不存在              | 输入的参数“用户名”未增加用户信息。          | 根据实际情况，重新输入参数“用户名”，确保输入的“用户名”已增加用户信息。执行该命令前，可以先执行LST PADATA命令查询已增加用户信息的所有用户。 |
| 335607 | 暂不支持该功能。           | 当前版本不支持此功能。                 | 无需处理。                                                                        |
| 352054 | 参数取值无效：该密码的设定不符合要求 | 输入的参数“密码”不符合要求。             | 根据实际情况，重新输入参数“密码”，确保其格式符合参数说明中的要求。                                           |
| 352055 | 密码长度不能小于8个字符       | 增加用户信息时，输入的参数“密码”过短。        | 根据实际情况，重新输入参数“密码”，确保其格式符合参数说明中的要求。                                           |
| 352056 | 密码与确认密码必须相同        | 输入的参数“密码”和“确认密码”不相同，系统无法通过。 | 根据实际情况，重新输入参数“密码”和“确认密码”，确保二者完全相同。                                           |
