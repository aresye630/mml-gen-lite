# 增加Diameter主机名域名配置(ADD DIAMNAMECFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加一条被割接局点用户所在MME的Diameter主机名与域名关联记录。

UDM支持自动发送消息至被割接局点获取用户的动态地址信息，由于获取的动态信息只包含用户所在MME主机名，无法获取到MME域名信息，通过本命令配置被割接局点用户所在MME的Diameter主机名与域名的关联关系，然后UDM根据用户的动态信息驱赶用户下线功能。

## 注意事项

系统中通过执行该命令增加的最大记录数为10000条。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                                                           |
|:----------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CFGINDEX  | 索引     | 可选必选说明：必选参数 参数含义：用于标识一条被割接局点用户所在MME的Diameter主机名域名关联记录的索引。 取值范围：1~10000。 默认值：无。 配置原则：该参数全局唯一，不能重复。                                                                                                                                                              |
| HOSTNAME  | 主机名    | 可选必选说明：必选参数 参数含义：用于标识被割接局点用户所在MME的所属域中的网络主机名。 取值范围：长度不超过127的字符串。 默认值：无。 配置原则： 所有字符只能是数字（0-9）、字母（a～z或A～Z）、“.”或“-”。 首字符必须是数字（0～9）或字母（a～z或A～Z）。 任意两个“.”或“-”不允许相邻。 最后一个字符不允许是“-”。 最后一个“.”后面的第一个字符必须为字母（a～z或A～Z）。例如“hss.huawei.com”中的最后一个“.”后面的字符串“com”的第一个字符必须为字母。 |
| REALMNAME | 域名     | 可选必选说明：必选参数 参数含义：用于标识被割接局点用户所在MME的所属域的域名。 取值范围：长度不超过127的字符串。 默认值：无。 配置原则： 所有字符只能是数字（0～9）、字母（a～z或A～Z）、“.”或“-”。 首字符必须是数字（0～9）或字母（a～z或A～Z）。 任意两个“.”或“-”不允许相邻。 最后一个字符不允许是“-”。 最后一个“.”后面的第一个字符必须为字母（a～z或A～Z）。例如“huawei.com”中的最后一个“.”后面的字符串“com”的第一个字符必须为字母。         |

## 使用实例

增加一条被割接局点用户所在MME的Diameter主机名域名关联记录。参数设置如下：

- “索引”取值为“2”
- “主机名”取值为“hss2.huawei.com”
- “域名”取值为“huawei.com”

```
ADD DIAMNAMECFG: CFGINDEX=2, HOSTNAME="hss2.huawei.com", REALMNAME="huawei.com";
```
