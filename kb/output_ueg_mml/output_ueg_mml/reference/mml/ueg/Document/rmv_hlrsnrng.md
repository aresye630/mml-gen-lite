# 删除HLR号段(RMV HLRSNRNG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除一条HLR号段记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                      |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------|
| TYPE   | 前缀类型   | 标识HLR号段记录的关键字段之一，用于指定要删除的HLR号段的前缀类型。可使用LST HLRSNRNG命令查询获取前缀类型。 取值说明： “IMSI(IMSI)” “MSISDN(MSISDN)” 默认值：无。 |
| PREFIX | 号码前缀   | 标识HLR号段记录的关键字段之一，用于指定要删除的HLR号段的前缀。可使用LST HLRSNRNG命令查询获取号码前缀。 取值范围：长度不超过15个数字字符串 默认值：无。                    |

## 使用实例

删除一条HLR号段记录。前缀类型为IMSI，号码前缀为“189919”。

`RMV HLRSNRNG: TYPE=IMSI, PREFIX="189919";`
