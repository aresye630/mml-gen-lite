# 增加MTP目的信令点(ADD N7DSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条MTP目的信令点数据记录。在该命令中，以下关键参数需要与对端No.7信令设备协商：

- 目的信令点编码
- 源信令点编码
- 信令规范
- 外部网络指示

## 注意事项

- 信令点是信令消息的起源点（OPC）和目的点（DPC），它可以是具有No.7信令功能的各种软交换设备，如MSC；也可以是其他具有No.7信令功能的各种非交换设备，如SCP、SGSN、STP等。信令点编码用于在一个信令网中唯一标识一个信令点。
- 如需通过本命令配置目的信令点，请确保与该目的信令点相对应的源信令点（**ADD OFI**）必须已经配置成功。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|:-------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DPNM   | 目的信令点名称 | 用于在配置数据库中定义一个MTP目的信令点，其值域类型为字符串，最大长度为32。 需要指出的是： 对于操作员在OMU Client输入的字符串，系统在操作OMU数据库之前将自动进行如下处理：将该字符串中的所有英文字母全部转换成大写、并将该字符串中最左边与最右边的空格删除掉。例如，假设操作员在LMT输入的字符串为“ 区域abc ”，则系统在操作BAM数据库之前将自动将该字符串转换为“区域ABC”。 对于操作员通过本命令配置的某一条具体的数据记录而言，假设该数据记录中“目的信令点名称”字段的原取值为A，如果操作员后续需要将该字段的取值由A修改为B，则其可以通过MOD N7DSP命令中的“新目的信令点名称”参数重新进行定义。此时，对于配置数据库中索引了取值为A的所有数据记录的“目的信令点名称”字段，系统将自动把这些字段的值由A修改为B。 取值范围：长度不超过32的字符串 默认值：无。 说明：必选参数。                                                                                                                                                                                                                                                                                                          |
| NI     | 网络指示    | 即内部网络指示语，用于指定该目的信令点的信令点编码在本局的内部属于哪一个信令网。该参数与本命令中的“外部网络指示”参数配合使用，以实现内部网络指示语与外部网络指示语之间的转换功能，其配置原则是： 若该目的信令点的DPC与本局的OPC位于同一个信令网、且它们具有相同的编码结构（即同为14位或同为24位），则操作员仅需要将内部网络指示语设置成与目的信令点保持一致即可，而无需配置外部网络指示语。 若该目的信令点的DPC与本局的OPC位于同一个信令网、但它们具有不同的编码结构（即一个为14位、另一个为24位），则操作员需要将外部网络指示语设置成与目的信令点保持一致，而将内部网络指示语设置成对应的备用网或主用网。例如，假设DPC位于国际主用网，则操作员在本局侧需将该DPC的外部网络指示语设为“国际主用网”，而将内部网络指示语设为“国际备用网”；又如，假设DPC位于国内主用网，则操作员在本局侧需将该DPC的外部网络指示语设为“国内主用网”，而将内部网络指示语设为“国内备用网”；其余情况依此类推。 取值范围： “INT(国际主用网)”“INTB(国际备用网)”“NAT(国内主用网)”“NATB(国内备用网)” 默认值： “NAT(国内主用网)” 说明：可选参数。                                                                                                                                                                         |
| DPC    | 目的信令点编码 | 本局与No.7信令设备的对接参数之一，用于指定该目的信令点在No.7信令网中的信令点编码。 取值范围：长度不超过11的字符串 默认值：无。 说明：必选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| OPC    | 源信令点编码  | 本局与No.7信令设备的对接参数之一，当本局在向对端No.7信令设备发送No.7信令消息时，用于指定在相应的No.7信令消息中将携带哪个源信令点编码，该参数必须先由SET OFI或ADD OFI命令定义，然后才能在此处索引。在缺省的情况下，若操作员不输入OPC，则系统默认OPC为由SET OFI命令定义的本局信令点编码。 取值范围：长度不超过11的字符串 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| STPF   | STP标志   | 用于指定该目的信令点是否具备信令转接（STP）的功能，仅当目的信令点为与本局直联的STP设备时，该参数设为“是”，其余情况均设为“否”。 取值范围： “TRUE(是)”“FALSE(否)” 默认值： “FALSE(否)” 说明：可选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ADJF   | 相邻标志    | 用于指定本局与对端目的信令点之间是否存在直达的MTP信令路由，该参数的配置原则是： 若对端设备为以直联方式与本局对接的STP，该参数设为“TRUE(是)”。 若对端设备为以直联方式与本局对接的MSC、SGSN，该参数设为“TRUE(是)”。 若对端为以准直联方式与本局对接的MSC或SGSN（即需要通过STP转发信令），该参数设为“FALSE(否)”。 取值范围： “TRUE(是)”“FALSE(否)” 默认值： “TRUE(是)” 说明：可选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| SLSSM  | 链路集选择掩码 | 用于指示本局在去往该目的信令点的多个MTP链路集之间如何实现信令业务的负荷分担，一般情况下建议取系统的默认值B1111。该参数的配置原则是： 当本局与目的信令点之间仅存在一个链路集时，该参数可以设为任意值。 当本局与目的信令点之间存在2个链路集时，该参数中“1”的个数必须大于或等于1，例如为B0001、B1100、B1111。 当本局与目的信令点之间存在3～4个链路集时，该参数中“1”的个数必须大于或等于2，例如为B0011、B1100、B1111。 当本局与目的信令点之间存在5～8个链路集时，该参数中“1”的个数必须大于或等于3，例如为B1011、B1110、B1111。 当本局与目的信令点之间存在9～16个链路集时，该参数只能设为B1111。 为避免出现同摆的现象，操作员不能将链路集选择掩码与各链路集的链路选择掩码（由ADD N7LKS命令配置）设成同一个编码，一般建议将两个掩码中“1”的位置错开。例如，假设链路集选择掩码为0110，则链路选择掩码可设为1001。 取值范围： “B0000(B0000)”“B0001(B0001)”“B0010(B0010)”“B0011(B0011)”“B0100(B0100)”“B0101(B0101)”“B0110(B0110)”“B0111(B0111)”“B1000(B1000)”“B1001(B1001)”“B1010(B1010)”“B1011(B1011)”“B1100(B1100)”“B1101(B1101)”“B1110(B1110)”“B1111(B1111)” 默认值： “B1111(B1111)” 说明：可选参数。 |
| PRT    | 信令规范    | 本局与No.7信令设备的对接参数之一，用于指示本局与该目的信令点之间的No.7信令遵循哪个组织制定的规范。若本局与遵循ANSI规范的信令点设备进行对接，则该参数必须选择“ANSI”，否则，两信令设备之间的MTP链路将不能正常运行。 取值范围： “ITU-T(ITU-T)”“ANSI(ANSI)” 默认值： “ITU-T(ITU-T)” 说明：可选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| EXNI   | 外部网络指示  | 本局与No.7信令设备的对接参数之一，用于指定该目的信令点的信令点编码属于哪一个信令网。该参数与本命令中的“内部网络指示”参数配合使用，以实现内部网络指示语与外部网络指示语之间的转换功能，其配置原则请参考“内部网络指示语”的相关说明。 需要指出的是，在缺省的情况下，若操作员不指定外部网络指示语的类型，则系统默认该目的信令点的外部网络指示语与内部网络指示语为同一种类型。 取值范围： “INT(国际主用网)”“INTB(国际备用网)”“NAT(国内主用网)”“NATB(国内备用网)” 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                           |

## 使用实例

1、增加MTP目的信令点，“目的信令点名称”为“N7DSP”，“目的信令点编码”为“F3333F”，其余参数使用默认值：

```
ADD N7DSP: DPNM="N7DSP", DPC="F3333F";
```

2、增加MTP目的信令点，“目的信令点名称”为“LOOP”，“目的信令点编码”为“555555”，其余参数使用默认值：

```
ADD N7DSP: DPNM="LOOP", DPC="555555";
```
