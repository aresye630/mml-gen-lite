# 增加DMC参数(ADD DMCPARAM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在配置数据库中增加一条DMC参数记录。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                |
|:-------|:-------|:----------------------------------------------------|
| NAME   | 参数名称   | 用于在配置数据库中定义一个DMC参数的参数名称。 取值范围：长度不超过128位的字符串。 默认值：无。 |
| VALUE  | 参数值    | 用于在配置数据库中定义一个DMC参数的参数值。 取值范围：长度不超过128位的字符串。 默认值：无。  |

## 使用实例

在配置数据库中增加一条DMC参数记录。DMC参数名称为“service”，参数值为“carrier\_name”。

`ADD DMCPARAM: NAME="service", VALUE="carrier_name";`
