# 查询Diameter路由状态(DSP DMRT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于请求系统显示指定的Diameter路由的状态信息。

- 若需要请求系统显示全部Diameter路由的状态信息，请不要输入任何参数。
- 若需要请求系统显示某个Diameter路由的状态信息，请输入“路由组名称”参数。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                     |
|:-------|:-------|:---------------------------------------------------------|
| RTNAME | 路由组名称  | 用于请求系统显示与哪个Diameter路由组相关的路由的状态信息；若不输入，则表示所有的Diameter路由组。 |

## 使用实例

1. 显示所有Diameter路由表中的路由配置状态信息：

   ```
   DSP DMRT:;
   ```

   ```
   %%DSP DMRT:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    路由组名称  对端标识名称   Diameter路由状态

    CX/DX       AS13           正常            
    Ml          AS13           断开            
    S13         AS13           断开            
    S6A/S6D     AS13           断开            
    SH          AS13           断开            
    SLH         AS13           断开            
    SWX         AS13           断开             
    ZH          AS13           断开 
               
   (结果个数 = 8)

   ---    END
   ```
2. 显示Diameter路由组表中的一条路由组配置状态信息，“路由组名称”为“CX/DX”：

   ```
   DSP DMRT: RTNAME="CX/DX";
   ```

   ```
   %%DSP DMRT: RTNAME="CX/DX";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
         路由组名称  =  CX/DX
       对端标识名称  =  AS13
   Diameter路由状态  =  正常
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见

**ADD DMRT**

命令的参数说明。表1列出的是未包含在

**ADD DMRT**

命令参数说明中的输出项。

| 输出项名称        | 输出项解释                                                                                                                                                      |
|:-------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| Diameter路由状态 | 用于标识Diameter路由的工作状态：正常：Diameter路由处于正常状态。断开：Diameter路由处于断开状态。当本端出现故障、对端故障或网络通信故障时，会造成Diameter路由断开。拥塞：Diameter路由处于拥塞状态。当本端出现业务量过大或者网络通信质量差时，会造成Diameter路由拥塞。 |
