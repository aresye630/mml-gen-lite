# 查询话统比对参数（LST SYSSTAT）

- 命令功能
- 注意事项

## 命令功能

该命令为配置类命令，用于在数据库中查询话统比对数据的配置信息：

- 若需要查询全部话统比对数据的配置信息，不需要输入任何参数。
- 若需要查询具体某个测量单元的配置信息，请选择具体的测量单元。

## 注意事项

- 查询结果中，对应测量指标的最少样本数为NULL，表示该测量指标没有最少样本数。
- 查询结果中，对应测量指标的阈值为NULL，表示该测量指标没有阈值。

## 使用实例

查询“全MAP测量”中“位置更新流程(0)”的“成功率”下降阈值。“测量单元”为“ALLMAP(全MAP测量)”，“测量对象”为“UpdateLocation(位置更新流程(0))”，“测量指标”为“PR(成功率)”：

LST SYSSTAT: MU=ALLMAP, MO=UpdateLocation, ETY=PR;

返回结果如下：

```
%%LST SYSSTAT: MU=ALLMAP, MO=UpdateLocation, ETY=PR;%%
RETCODE = 0  操作成功

KPI话统结果比对配置信息
-----------------------
  测量单元  =  全MAP测量
  测量对象  =  位置更新流程(0)
  测量指标  =  成功率(%)
最少样本数  =  NULL
      阈值  =  5
(结果个数 = 1)
```

## 输出结果说明

| 输出项名称   | 输出结果解释                                                                                                                                                                                                                                                                                                                                                                         |
|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 测量单元    | 话统比对的测量单元名称。                                                                                                                                                                                                                                                                                                                                                                   |
| 测量对象    | 话统比对的测量对象名称。                                                                                                                                                                                                                                                                                                                                                                   |
| 测量指标    | 话统比对的测量指标名称。                                                                                                                                                                                                                                                                                                                                                                   |
| 最少样本数   | 最少样本数表示在话统比对时，在比对话统周期内，该测量指标的值大于或者等于设置的最少样本数值才进行比对，如果查询结果的最少样本数值为NULL， 表示该测量指标没有最少样本数。 查询出来的最少样本数的值是指5分钟周期的样本数值。如果比较周期为15分钟时， 实际使用的最少样本数=当前设置的最少样本数*3，如果比较周期为30分钟时，实际使用的最少样本数=当前设置的最少样本数*6，如果比较周期为1个小时，实际使用的最小样本数=当前设置的最少样本数*12。                                                                                                                                               |
| 阈值      | 测量指标变化的阈值： 当测量指标为：成功率(%)、位置更新成功响应率(%)、鉴权成功响应率(%)、取消位置登记成功响应率(%)、插入用户数据成功响应率(%)、用户注册状态查询请求成功响应率(%)、S-CSCF注册注销通知请求成功响应率(%)、被叫用户位置查询请求成功响应率(%)、用户鉴权请求成功响应率(%)、网络侧注销请求成功响应率(%)、用户数据更新请求成功响应率(%)、AS读取用户数据请求成功响应率(%)、AS更新透明数据请求成功响应率(%)、AS数据变化订阅请求成功响应率(%)、HSS发起的订阅通知成功响应率(%)。 取值范围为：1～100，单位为：百分比。 当测量指标为：操作请求(次)、系统失败(次)。实际比对时，使用的阈值=当前查询出来的阈值*实际选择的话统周期/5分钟。 取值范围为：1～10000，单位为：次。 |
