# 设置模块CPU过载阈值(SET UDMLITECPUTHD)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成CPU过载告警上报和恢复异常，需要与华为技术支持确认后才可以实施。

该命令用于设置模块CPU过载告警上报阈值和恢复阈值。

该命令的使用场景：各模块通过内部定时器，以5秒为周期定时检查自己占用的CPU使用率，并判断是否要上报模块CPU过载告警。

- 当某个模块的CPU使用率连续三个周期超过配置的过载告警上报阈值时，该模块上报模块CPU过载告警。
- 当某个模块的CPU使用率连续三个周期小于配置的过载告警恢复阈值时，该模块恢复模块CPU过载告警。
- 如果修改了过载告警阈值或恢复阈值，模块会恢复已触发的模块CPU过载告警，并按照最新阈值重新判断是否上报模块CPU过载告警。

## 注意事项

各级告警阈值与恢复阈值需满足如下限制：

- “三级过载告警阈值”大于“三级过载告警恢复阈值”
- “三级过载告警恢复阈值”大于或等于“二级过载告警阈值”
- “二级过载告警阈值”大于“二级过载告警恢复阈值”
- “二级过载告警恢复阈值”大于或等于“一级过载告警阈值”
- “一级过载告警阈值”大于“一级过载告警恢复阈值”

## 使用实例

设置“模块类型”为“HSF”的模块的“一级过载告警阈值”为“75”，“一级过载告警恢复阈值”为“70”，“二级过载告警阈值”为“80”，“二级过载告警恢复阈值”为“75”，“三级过载告警阈值”为“90”，“三级过载告警恢复阈值”为“85”：

```
SET UDMLITECPUTHD: MT=HSF, LV1ALARMTHD=75, LV1RESTORETHD=70, LV2ALARMTHD=80, LV2RESTORETHD=75, LV3ALARMTHD=90, LV3RESTORETHD=85;
```
