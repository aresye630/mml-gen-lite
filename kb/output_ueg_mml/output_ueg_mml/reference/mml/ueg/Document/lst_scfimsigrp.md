# 查询IMSI号段组(LST SCFIMSIGRP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询IMSI号段组数据的记录。

- 若需要查询全部IMSI号段组数据记录的信息，请不要输入任何参数。
- 若需要查询某个IMSI号段组数据记录的信息，请输入“IMSI号段组名称”参数。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称      | 参数说明                                                      |
|:--------|:----------|:----------------------------------------------------------|
| GRPNAME | IMSI号段组名称 | 用于指示系统按照哪个Diameter路由组名称来查询IMSI号段组信息；若不输入，则表示所有的IMSI号段组名称。 |

## 使用实例

1. 查询所有IMSI号段组配置信息。

   ```
   LST SCFIMSIGRP:;
   ```

   ```
   %%LST SCFIMSIGRP:;%%
   RETCODE = 0  操作成功

   执行结果如下
   ------------
    IMSI号段组名称

    GROUP02   
    GROUP01   
   (结果个数 = 2)

   ---    END
   ```
2. 查询某个IMSI号段组的配置信息，“IMSI号段组名称”为“GROUP01”。

   ```
   LST SCFIMSIGRP: GRPNAME="GROUP01";
   ```

   ```
   %%LST SCFIMSIGRP: GRPNAME="GROUP01";%%
   RETCODE = 0  操作成功

   执行结果如下
   ------------
   IMSI号段组名称 = GROUP01
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD SCFIMSIGRP**命令的参数说明。
