# 查询HSS CDMA MAP信息(LST HCMAPOFI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询HSS CDMA MAP信息:

- 若需要查询HSS CDMA MAP信息的全部配置信息，请不要输入任何参数。
- 若需要查询HSS CDMA MAP信息的某条详细信息，请输入“本地实体标识”或“市场标识”或“转换号码”或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                   |
|:-------|:-------|:-------------------------------------------------------|
| LEX    | 本地实体标识 | 用于指示系统需要按照哪个本地实体标识来查询HSS CDMA MAP信息；若不输入，则表示所有的本地实体标识。 |
| MKTID  | 市场标识   | 用于指示系统需要按照哪个市场标识来查询HSS CDMA MAP信息；若不输入，则表示所有的市场标识。     |
| SWNO   | 转换号码   | 用于指示系统需要按照哪个转换号码来查询HSS CDMA MAP信息；若不输入，则表示所有的转换号码。     |

## 使用实例

查询HSS CDMA MAP的配置信息，“LEX”为“0”：

```
LST HCMAPOFI: LEX=0;
```

```
%%LST HCMAPOFI: LEX=0;%%
RETCODE = 0  操作成功

查询结果如下
-------------------------
 本地实体标识      =  0
    市场标识      =  1
    转换号码      =  2
(结果个数 = 1)

---    END
```
