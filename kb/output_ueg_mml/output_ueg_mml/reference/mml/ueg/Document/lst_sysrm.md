# 查询系统的运行模式配置信息(LST SYSRM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询系统运行模式配置信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                 |
|:-------|:-------|:-------------------------------------|
| FS     | 系统运行状态 | 用于指示系统需要按照哪种系统运行状态来查询配置信息数据，该参数必须选择。 |

## 使用实例

查询系统的运行模式配置信息：

```
LST SYSRM:;
```

```
%%LST SYSRM:;%%
RETCODE = 0  操作成功

查询结果如下
--------------
系统运行状态  =  激活模式
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数请参见该命令的参数说明。
