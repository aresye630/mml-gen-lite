# 删除DMC参数(RMV DMCPARAM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在配置数据库中删除一条DMC参数记录。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                     |
|:-------|:-------|:---------------------------------------------------------|
| NAME   | 参数名称   | 标识DMC参数的关键字段，用于指定需要删除哪一条DMC参数记录，操作员可以使用LST DMCPARAM查询获得。 |

## 使用实例

删除一条DMC参数记录。DMC参数名称为"service"。

`RMV DMCPARAM: NAME="service";`
