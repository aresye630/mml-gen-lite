# 查询IMSI前缀和HLRSN(LST IMSIHLRSN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询IMSI前缀和HLRSN的对应关系数据记录：

- 若需要查询全部的IMSI前缀和HLRSN对应关系数据记录，请不要输入任何参数。
- 若需要查询某条IMSI前缀和HLRSN对应关系数据记录的详细信息，请输入“IMSI前缀”。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                         |
|:-----------|:-------|:-----------------------------------------------------------------------------|
| IMSIPREFIX | IMSI前缀 | 用于指示系统按照哪个IMSI前缀来查询IMSI前缀和HLRSN的对应关系数据记录；若不输入，则表示查询所有的IMSI前缀和HLRSN的对应关系数据记录。 |

## 使用实例

1. 查询全部的IMSI前缀和HLRSN对应关系数据记录。命令如下：

   ```
   LST IMSIHLRSN:;
   ```

   ```
   %%LST IMSIHLRSN:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    IMSI前缀  HLR序列号

    460142    1        
    460143    1        
   (结果个数 = 2)

   ---    END
   ```
2. 查询一条IMSI前缀和HLRSN的对应关系数据，“IMSI前缀”为“460142”。命令如下：

   ```
   LST IMSIHLRSN: IMSIPREFIX="460142";
   ```

   ```
   %%LST IMSIHLRSN: IMSIPREFIX="460142";%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    IMSI前缀  =  460142
   HLR序列号  =  1
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD IMSIHLRSN**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                  | 原因分析                                | 处理建议                                   |
|-------:|:-----------------------|:------------------------------------|:---------------------------------------|
| 264050 | 参数IMSIPREFIX只允许输入：0-9。 | 输入的“IMSI前缀”参数的取值不是1～15位十进制数字组成的字符串。 | 重新输入“IMSI前缀”参数，确保其取值是1～15位十进制数字组成的字符串。 |
