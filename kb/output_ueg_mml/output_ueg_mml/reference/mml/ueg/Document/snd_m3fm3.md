# 发送M3UA三层伪消息(SND M3FM3)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为维护类命令，用于请求系统在指定的M3UA链路上发送M3UA伪消息。

该命令仅适用于测试场景，例如在IOT（Inter Operability Test）测试中，操作员可以通过该命令提供仿真协议接口以完成某些特定的测试项目，而在其他情况下，请勿使用该命令。

## 注意事项

- M3UA伪消息由主机下发到负责信令处理的虚机（裸机POD），这些消息可能对信令链路造成严重影响，请操作员在执行该操作之前仔细确认任务的可行性。
- 在使用该命令前，请使用**DSP M3LNK**命令查询发送伪消息的M3UA链路的状态，只有在M3UA链路的状态为“已激活”时，系统才能发送伪消息。

## 参数说明

| 参数标识   | 参数名称   | 参数描述                                                                                                                                                                                                                                                                              |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LNKNM  | 链路名称   | 标识一条M3UA链路的关键字段，用于指定系统在哪一条M3UA链路上发送伪消息，操作员可以用LST M3LNK命令查询M3UA链路配置情况。                                                                                                                                                                                                             |
| SNO    | 流号     | 用于指定相应的SCTP消息包中的流号。 取值范围: 0～16 默认值: 0                                                                                                                                                                                                                                             |
| MLEN   | 消息长度   | 用于指定M3UA三层伪消息长度。 取值范围: 4～280 默认值: 无。                                                                                                                                                                                                                                              |
| MSU    | 消息信令单元 | 用于指定M3UA三层伪消息内容，该参数的配置原则是： 消息参数为十六进制格式。 消息内容的数据格式必须与M3UA协议标准中指定的消息格式保持一致。后续的消息内容必须符合用户部分协议（例如，SNM、SCCP、ISUP等）的格式，协议类型由SIO中的业务指示语字段指定。 参数的字节顺序应为网络字节顺序。 M3UA三层伪消息的格式如下所示： |---版本---|---保留---|---消息类型---|---类别---| 各字段的长度如下： 版本：8 bit保留：8 bit消息类型：8 bit类别：8 bit 允许长度：560 bit 默认值：无。 |

## 使用实例

发送M3UA三层伪消息，“链路名称”为“LNK\_1”，“消息长度”为“16”，“消息信令单元”为“01000202000000100012000800123456”：

```
SND M3FM3: LNKNM="LNK_1", MLEN=16, MSU="01000202000000100012000800123456";
```
