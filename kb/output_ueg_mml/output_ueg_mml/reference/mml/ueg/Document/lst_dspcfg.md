# 查询MTP/M3UA目的信令点数据配置(LST DSPCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在配置数据库中查询MTP/M3UA目的信令点数据的配置信息（包括路由、链路集、链路等）。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                               |
|:-------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------|
| OPC    | 源信令点编码  | 用于指示系统需要按照哪个源信令点编码来查询目的信令点的配置信息。 取值范围：长度不超过11的字符串 默认值：无。 说明：必选参数。                                                                  |
| DPC    | 目的信令点编码 | 用于指示系统需要按照哪个目的信令点编码来查询目的信令点的配置信息。 取值范围：长度不超过11的字符串 默认值：无。 说明：必选参数。                                                                 |
| NI     | 网络指示    | 用于指示系统需要按照哪个网络指示来查询目的信令点的配置信息；若不输入，则表示所有的网络指示。 取值范围： “INT(国际主用网)”“INTB(国际备用网)”“NAT(国内主用网)”“NATB(国内备用网)” 默认值： “NAT(国内主用网)” 说明：可选参数。 |

## 使用实例

查询相关目的信令点的配置数据，“源信令编码”为“5658”，“目的信令编码”为“6364”：

```
LST DSPCFG: OPC="5658", DPC="6364";
```
