# 修改M3UA路由(MOD M3RT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于对配置数据库中的一条M3UA路由数据记录的某些参数进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一条M3UA路由数据记录：

- 目的实体名称
- 链路集名称

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称   | 参数描述                                                                                                                                                                                            |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DENM   | 目的实体名称 | 该参数是标识一条M3UA路由数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪一条M3UA路由数据记录的参数进行修改或调整，操作员可以使用LST M3RT命令查询获得。 取值范围: 长度不超过32的字符串。 默认值: 无。 说明: 无。                                                                     |
| LSNM   | 链路集名称  | 用于指定到达该的目的实体的M3UA路由，即本局通过哪个M3UA链路集传输信令，该参数必须先由ADD M3LKS命令定义，然后才能在此处引用。 取值范围：长度不超过32的字符串。 默认值：无。 说明: 无。                                                                                          |
| RTNM   | 路由名称   | 其值域类型为字符串，用于具体描述一个M3UA路由，以便于识别。可以通过该参数修改路由的名称。 取值范围: 长度不超过32的字符串。 默认值: 无。 说明： 此参数为可以联想的MOC对象。执行了ADD M3RT或者MOD M3RT之后参数值列表可以立刻更新，执行了RMV M3RT后，参数值列表1小时之内可以自动更新，如果要手动刷新，请单击右键，在弹出的菜单中选择“更新联想参数值”。 |
| PRI    | 路由优先级  | 用于设定该M3UA链路集（信令路由）的选路优先级，即优先级别高的链路集将被优先选择，而优先级别较低的链路集只能在比它优先级别较高的信令路由全部变成不可利用以后才能承载信令业务。 取值范围: 0～254。 默认值: 无。 说明: 0为最高优先级，1次之，其余情况依此类推。                                                         |

## 使用实例

1、修改M3UA路由，“目的实体名称”为“M3DE”，“链路集名称”为“M3LKS”，“路由优先级”为“2”：

```
MOD M3RT: DENM="M3DE", LSNM="M3LKS", PRI=2;
```

2、修改M3UA路由，“目的实体名称”为“M3DE”，“链路集名称”为“M3LKS”，“路由名称”为“MODIFIED”：

```
MOD M3RT: DENM="M3DE", LSNM="M3LKS", RTNM="MODIFIED";
```
