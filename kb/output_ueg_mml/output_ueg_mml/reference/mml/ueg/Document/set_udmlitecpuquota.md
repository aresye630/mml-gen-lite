# 设置模块CPU配额(SET UDMLITECPUQUOTA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置模块的CPU配额。

通过该命令设置的CPU配额可以计算出模块的相对CPU，相对CPU=（绝对CPU/模块CPU配额）\*100%。当相对CPU超过由**MOD FLOWCTRL**设置的阈值，则触发流控告警。

## 注意事项

- 在缺省的情况下，系统初始化的时候已经在配置数据库中预置了各模块的CPU配额，可以通过**LST FLOWCTRL**命令查询。
- “模块CPU配额”配置不当会造成CPU过载告警上报和恢复异常，请谨慎配置。如果需要对CPU配额进行修改，请先与华为技术支持确认。

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                             |
|:---------|:--------|:---------------------------------------------------------------------------------|
| MT       | 模块类型    | 可选必选说明：必选参数 参数含义：用于标识设置模块CPU配额的模块类型。 取值范围：CCU(CCU)ACF(ACF)APF(APF) 默认值：无 配置原则：无。 |
| CPUQUOTA | 模块CPU配额 | 可选必选说明：可选参数 参数含义：用于标识模块的CPU配额。 取值范围：100～800 默认值：无 配置原则：无。                        |

## 使用实例

设置某CCU模块的CPU配额：

- “模块类型”：“CCU”
- “模块CPU配额”：“200”

```
SET UDMLITECPUQUOTA：MT=CCU,CPUQUOTA=200;
```
