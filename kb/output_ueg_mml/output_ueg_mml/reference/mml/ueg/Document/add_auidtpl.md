# 增加AUID模板(ADD AUIDTPL)

- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

该命令用于在配置数据库中增加一个AUID（application unique ID ）模板，即应用区分标识模板，应用区分标识用于指定用户的业务请求类型。

操作员使用该命令添加AUID模板后，执行**ADD APRULE**命令配置AP转发规则时，只需要签约AUID模板ID即可，从而简化系统配置流程。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                           |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------|
| ID     | 索引     | 可选必选说明：必选参数 用于标识待增加的AUID模板在系统中的索引。该参数在UIM中唯一，不能重复。 取值范围：1～255 默认值：无。                                                           |
| AUID   | 应用区分标识 | 可选必选说明：必选参数 用于标识AP转发规则中要匹配的HTTP请求消息的业务请求类型。该参数在UIM中唯一，不能重复。 取值范围：1～127位字符串。 默认值：无。 说明：该参数不区分大小写，在执行LST AUIDTPL命令查询出的报文中为全小写形式。 |

## 使用实例

配置AP转发规则中的AUID匹配原则，操作员需要配置以下数据。

1. 增加一个AUID模板，“索引”为“1”，“应用区分标识”为“simservs.ngn.etsi.org”：

   ```
   ADD AUIDTPL: ID=1, AUID="simservs.ngn.etsi.org";
   ```
2. 执行**ADD APRULE**命令配置AP转发规则中的应用区分标识匹配原则。

   ```
   ADD APRULE: ID=1, AUIDID=1, IMPUE=FALSE, PEID=1;
   ```

| 377902 | 指定的AUID已经存在。请执行LST AUIDTPL查询已存在的AUID。 | 输入的“应用区分标识”参数已存在。 | 根据实际情况，重新输入参数，确保输入的“应用区分标识”参数与系统中已存在的不重复。可执行LST AUIDTPL命令查询系统中已存在的“应用区分标识”参数记录。 |
