# 同步远端IP信息到本端(SYN RIPADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于手工同步对端IP地址信息到本端网元。

## 注意事项

- 首先通过**ADD RLOCATION**命令配置远端Location后，才能通过该命令同步对端IP地址信息。
- 在手工同步对端IP地址信息到本端配置之后，通过**ACT IPDISP**命令激活链路，配置才能生效。

## 参数说明

| 参数标识   | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                        |
|:-------|:-------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RLOCID | 远端Location标识 | 用于指定一个远端网元标识。该参数须在对接的远端USCDB网元或者FE网元中先定义，然后在本端网元通过ADD RLOCATION命令配置后，才能在此处索引。远端Location是相对的，具体如下：对于主用局FE，它的远端Location指主用局USCDB或容灾局USCDB。对于主用局USCDB，它的远端Location指主用局FE、容灾局FE或容灾局USCDB。对于容灾局FE，它的远端Location指容灾局USCDB或主用局USCDB。对于容灾局USCDB，它的远端Location指容灾局FE、主用局FE或主用局USCDB。 取值范围：1～512 默认值：无。 |

## 使用实例

当本端与远端IP地址信息不一致时，手工同步远端IP地址信息到本端网元，“远端Location标识”为“77”。命令示例如下：

```
SYN RIPADDR: RLOCID=77;
```
