# 查询系统参数(LST SYS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询系统参数。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询系统参数，执行如下命令：

`LST SYS:;`

```
%%LST SYS:;%% 
RETCODE = 0  操作成功  

操作结果如下 
------------ 
  系统功能  =  HSS9860 
网元接口ID  =  HSS9860V500R020C30SPC100B000 
FE插件类型  =  HSS9860 
 (结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释           |
|:--------|:----------------|
| 系统功能    | 用于指定网元所呈现的功能实体。 |
| 网元接口ID  | 用于指定网元的接口ID。    |
| FE插件类型  | 用于指定网元的FE插件类型。  |
