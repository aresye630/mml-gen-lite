# 显示SCCP目的负荷分担信令点组(DSP SCCPLDSHGRP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于请求系统显示指定的显示SCCP负荷分担信令点组的基本信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                            |
|:-------|:-----------|:--------------------------------------------------------------------------------|
| MN     | CCU模块号     | 用于请求系统显示指定CCU模块内SCCP目的信令点的状态信息。 取值范围：1～1023。 默认值：无。 说明：无。                       |
| LSDGNM | 负荷分担信令点组名称 | 用于指定要显示的SCCP负荷分担信令点组的名字。 取值范围：长度不超过32的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 说明：无。 |

## 使用实例

显示“负荷分担信令点组名称”为“TEST”的SCCP目的信令点组

```
DSP SCCPLDSHGRP: LSDGNM="TEST";
```

## 输出结果说明

| 输出项名称      | 输出结果解释                                                                                                      |
|:-----------|:------------------------------------------------------------------------------------------------------------|
| 模块号        | 用于返回所请求显示的SCCP目的信令点组的状态信息的CCU模块号。                                                                           |
| 负荷分担信令点组名称 | 用于返回指定的负荷分担信令点组名称。                                                                                          |
| 主信点编码      | 用于返回指定的负荷分担信令点组的主信点编码                                                                                       |
| 目的信令点名称    | 用于返回指定的负荷分担信令点组中各负荷分担信令点的名称。                                                                                |
| 信令点状态      | 用于返回当前目的信令点的状态：允许：表示基于该信令点的三层协议可达，信令业务正常。 禁止：表示基于该信令点的三层协议不可达。 手动去激活：操作员使用SET SCCPDSP命令手动设置该目的信令点禁止，信令业务中断。 |
| SCCP状态     | 用于返回当前目的信令点的管理子系统的状态：允许：表示该管理子系统运行正常。 禁止：表示到该子系统的底层链路不通、对端信令点不可达或者操作员使用SET SCCPSSN命令手动配置本端子系统禁止，子系统业务中断。    |
| 拥塞状态       | 用于返回当前SCCP链路在此目的信令点的拥塞信息： 拥塞：表示该SCCP链路在此目的信令点的消息流量过大，致使信令传递时延过长。 未拥塞：表示该SCCP链路在此目的信令点的消息流量正常。               |
| 目的信令点编码    | 用于返回指定的负荷分担信令点组中各负荷分担信令点的编码。                                                                                |
| 优先级        | 用于返回指定的负荷分担信令点组中各负荷分担信令点的优先级。                                                                               |
