# 修改CHR话单功能输出策略(MOD CHRPLCY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中修改UDM网元的CHR话单输出策略的记录。在该命令中，系统通过以下参数唯一标识一条CHR话单输出策略的记录。

- 消息接口
- 消息类型
- IMSI号段

## 注意事项

当前版本不支持此功能，执行该命令后会返回错误码：“335607 暂不支持该功能”。

## 参数说明

| 参数标识         | 参数名称         | 参数说明                                                                                                                                                                                                              |
|:-------------|:-------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MSGINTERFACE | 消息接口         | 标识用户CHR话单输出策略记录的关键字段之一，用于指定需要对哪个消息接口的参数进行修改或调整，操作员可以使用LST CHRPLCY命令查询获得。 取值范围：S6a(S6a)：S6a接口。 默认值：无。                                                                                                              |
| CHRMSG       | 消息类型         | 标识用户CHR话单输出策略记录的关键字段之一，用于指定需要对哪种消息类型的参数进行修改或调整，操作员可以使用LST CHRPLCY命令查询获得。 取值范围：全部选中全部清空全部灰化AIR_AIA(AIR_AIA)ULR_ULA(ULR_ULA)NOR_NOA(NOR_NOA)IDR_IDA(IDR_IDA)CLR_CLA(CLR_CLA)DSR_DSA(DSR_DSA)PUR_PUA(PUR_PUA) 默认值：无。 |
| IMSIPREFIX   | IMSI号段       | 标识用户CHR话单输出策略记录的关键字段之一，用于指定需要对哪个IMSI号段的参数进行修改或调整，操作员可以使用LST CHRPLCY命令查询获得。若不输入，表示只修改当前已存在的不区分号段的记录。若需要修改区分号段的记录，该参数必须输入。 取值范围：1～15位十进制数字组成的字符串 默认值：无。                                                             |
| CHRSUPP      | 是否支持CHR功能    | 用于标识UDM是否支持CHR话单生成的功能。 取值范围：NO(不支持)YES(支持) 默认值：无。                                                                                                                                                                 |
| CHRPLCY      | CHR输出策略      | 仅当本命令的参数“是否支持CHR功能”取值为“YES(支持)”时，该参数有效。用于标识UDM网元输出CHR话单的策略。 取值范围：ONLYFAILED(只输出异常消息单据)ALL(输出所有成功失败消息单据) 默认值：无。                                                                                                    |
| ANMCHR       | 是否进行CHR匿名化处理 | 仅当本命令的参数“是否支持CHR功能”取值为“YES(支持)”时，该参数有效。用于标识生成CHR话单时是否需要对CHR单据中的个人敏感信息（IMSI、MSISDN）进行匿名化处理。 取值范围：NO(不作匿名化)YES(匿名化) 默认值：无。                                                                                          |

## 使用实例

修改一条“消息接口”为“S6a(S6a)”，“消息类型”为“ULR\_ULA(ULR\_ULA)”和“AIR\_AIA(AIR\_AIA)”的组合、“IMSI号段”为“00123456789”的CHR话单输出策略记录中“是否支持CHR功能”为“NO(不支持)”。

```
MOD CHRPLCY: MSGINTERFACE=S6a, CHRMSG=ULR_ULA-1&AIR_AIA-1, IMSIPREFIX="00123456789", CHRSUPP=NO;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释    | 原因分析                | 处理建议                                                                                                  |
|-------:|:---------|:--------------------|:------------------------------------------------------------------------------------------------------|
| 335607 | 暂不支持该功能。 | 当前版本不支持此功能。         | 无需处理。                                                                                                 |
| 335821 | 记录不存在。   | 要修改的CHR话单输出策略记录不存在。 | 请按照一下步骤进行操作： 执行命令LST CHRPLCY查询已添加的所有CHR单据生成策略记录。根据查询结果重新输入参数“消息接口”，“消息类型”或“IMSI号段”，确保这三个参数唯一确定的记录已存在。 |
