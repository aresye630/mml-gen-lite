# 修改HSS CDMA MAP信息(MOD HCMAPOFI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于对HSS模拟CDMA MAP信息的配置信息某些参数进行修改或调整。在该命令中，系统通过“本地实体标识”来唯一标识一条HSS模拟CDMA MAP信息数据记录的配置信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                               |
|:-------|:-------|:---------------------------------------------------------------------------------------------------|
| LEX    | 本地实体标识 | 标识由服务提供商提供的唯一本地实体的关键字段（其取值不能被修改），用于指定需要对哪一个本地实体进行修改或调整，操作员可以使用LST HCMAPOFI命令查询获得。 取值范围：0～15 默认值：无。 |
| MKTID  | 市场标识   | 用于标识服务提供商定义的一个唯一市场。 取值范围：0～65535 默认值：无。                                                            |
| SWNO   | 转换号码   | 用于标识服务提供商定义的一个唯一号码。 取值范围：0～255 默认值：无。                                                              |

## 使用实例

修改HSS模拟CDMA MAP信息，“LEX”为“0”，“MKTID”为“1”，“SWNO”为“3”：

```
MOD HCMAPOFI: LEX=0, MKTID=1, SWNO=3;
```
