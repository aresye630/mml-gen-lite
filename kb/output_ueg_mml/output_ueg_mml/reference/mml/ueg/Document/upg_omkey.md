# 更新随机密钥(UPG OMKEY)

## 命令功能

**须知** 

- 本命令属于高危命令，执行本命令会对系统配置数据的存储密钥进行更新，执行不当会造成系统配置数据失效，因此执行该命令前，需要与华为技术支持确认后才可以实施。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于更新某种类型的敏感数据的加密密钥。

执行此命令时，针对“类型”参数对应的数据记录，将旧的密钥加密的数据，先使用旧的密钥进行解密，然后使用“密钥ID”参数指定的随机密钥加密后存储。

## 注意事项

- 执行该命令返回“操作失败”时，可以查看系统是否上报“ALM-15072 随机密钥材料丢失”告警。
  - 是 => 请参考“ALM-15072 随机密钥材料丢失”告警联机帮助的“处理步骤”进行处理。
  - 否 => 请联系华为技术支持。
- 执行该命令后还需要在“UDM MML命令”界面执行以下命令才能保证主机和OMU侧的数据一致。

  ```
  FMT:;
  STR CRC: CRCTYPE=ALL, SSR=NO;
  SND CRCERR: FS=NO;
  ```
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                      |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TYPE   | 类型     | 可选必选说明：必选参数 参数含义：用于标识更新加密方式敏感数据信息的类型。 取值范围：PATYPE(PATYPE)：ADD PATYPE命令增加的数据。PADATA(PADATA)：ADD PADATA命令增加的数据。LDAPLINKINFO(LDAPLINKINFO)：该枚举值为保留枚举值，暂不启用。DMPECAP(DMPECAP)：SET DMPECAP命令设置的数据。VERIF(VERIF)：该枚举值为保留枚举值，暂不启用。NAIKEY(NAIKEY)：SET NAIKEY命令增加的数据。 默认值：无。 配置原则：无。 |
| KEYID  | 密钥ID   | 可选必选说明：可选参数 参数含义：用于标识密钥ID。执行命令不携带该参数时，使用LST OMRANDOMKEY命令查询出的输出项“ISDEF”为“TRUE”的默认随机密钥ID。 取值范围：1～3000 默认值：无。 配置原则：该参数必须先通过ADD OMRANDOMKEY命令配置才能在此处引用。                                                                                                                      |

## 使用实例

1. 更新一条敏感数据信息的加密密钥，“类型”参数为“LDAPLINKINFO(LDAPLINKINFO)”：

   ```
   UPG OMKEY: TYPE=LDAPLINKINFO;
   ```
2. 更新一条敏感数据信息的加密密钥，“类型”参数为“PATYPE(PATYPE)”，“密钥ID”参数为“1”：

   ```
   UPG OMKEY: TYPE=PATYPE, KEYID=1;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释      | 原因分析                                   | 处理建议                                                                                                 |
|-------:|:-----------|:---------------------------------------|:-----------------------------------------------------------------------------------------------------|
| 335950 | 修改类型中无添加记录 | “类型”参数对应的数据记录不存在。                      | 根据实际情况重新输入“类型”参数，确保系统中存在“类型”参数对应的数据。可以执行对应的查询命令查询系统是否已配置对应的数据。                                       |
| 335951 | 随机密钥记录不存在  | “密钥ID”参数对应的随机密钥数据记录不存在。                | 根据实际情况重新输入“密钥ID”参数，确保该参数已通过ADD OMRANDOMKEY命令配置。可以执行LST OMRANDOMKEY命令查询系统已配置的“KEYID”为1~3000的随机密钥数据记录。 |
| 335955 | 密钥ID未变化    | 数据库中待更新加密方式的数据已经是随机密钥加密方式，并且随机密钥ID未变化。 | 根据实际情况重新输入“密钥ID”参数，再次执行该命令。                                                                          |
