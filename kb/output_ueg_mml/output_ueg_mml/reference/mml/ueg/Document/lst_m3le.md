# 查询M3UA本地实体(LST M3LE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在配置数据库中查询M3UA本地实体数据的配置信息。

- 若需要查询全部M3UA本地实体数据记录的概要信息，请不要输入任何参数。
- 若需要查询某些M3UA本地实体数据记录的详细信息，请输入相关参数或参数组合。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数描述                                                                              |
|:-------|:-------|:----------------------------------------------------------------------------------|
| LENM   | 本地实体名称 | 用于指示系统需要按照哪个本地实体名称来查询M3UA本地实体数据；若不输入，则表示所有的本地实体名称。 取值范围：长度不超过32的字符串。 默认值：无。 说明：无。 |

## 使用实例

1、查询本局所有M3UA本地实体：

```
LST M3LE:;
```

返回结果如下：

```
%%LST M3LE:;%%
RETCODE = 0  操作成功

M3UA本地实体表
--------------
 本地实体名称  本地实体类型  网络指示    本地实体信令点编码  路由上下文  本地实体号

 M3UA_LOCAL    应用服务器    国内主用网  H'002368            NULL        0       
 LOCAL_56      应用服务器    国内主用网  H'833208            NULL        1         
  
(结果个数 = 2)

---    END
```

2、查询本局M3UA本地实体，“本地实体名称”为“M3UA\_LOCAL”：

```
LST M3LE: LENM="M3UA_LOCAL";
```

返回结果如下：

```
%%LST M3LE: LENM="M3UA_LOCAL";%%
RETCODE = 0  操作成功

M3UA本地实体表
--------------
      本地实体名称  =  M3UA_LOCAL
      本地实体类型  =  应用服务器
          网络指示  =  国内备用网
本地实体信令点编码  =  H'002368
        路由上下文  =  NULL
      互助本地实体  =  NULL
        本地实体号  =  0
(结果个数 = 1)

---    END
```
