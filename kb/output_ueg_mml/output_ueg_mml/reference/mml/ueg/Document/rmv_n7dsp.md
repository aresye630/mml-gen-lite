# 删除MTP目的信令点(RMV N7DSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于从配置数据库中删除一条MTP目的信令点数据记录。

## 注意事项

- 如果命令执行成功，且删除的数据为已有性能统计任务中登记的对象实例，则该对象实例后续上报的指标值为0。本命令涉及的测量单元有：MTP目的信令点测量；命令涉及的测量对象有：MTP目的信令点。
- 在正常情况下，该命令仅在开局时由开局工程师在数据调测的过程中使用。而在日常维护过程中不建议操作员使用该命令。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                   |
|:-------|:--------|:-------------------------------------------------------------------------------------------------------|
| DPNM   | 目的信令点名称 | 标识一条MTP目的信令点数据记录的关键字段，用于指定需要删除哪一条MTP目的信令点数据记录，操作员可以使用LST N7DSP命令查询获得。 取值范围：长度不超过32的字符串 默认值：无。 说明：必选参数。 |

## 使用实例

删除MTP目的信令点，“目的信令点名称”为“N7DSP”：

```
RMV N7DSP: DPNM="N7DSP";
```
