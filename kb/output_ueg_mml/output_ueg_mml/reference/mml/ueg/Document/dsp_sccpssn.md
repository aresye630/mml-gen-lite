# 显示SCCP子系统(DSP SCCPSSN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询指定的SCCP子系统的基本信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MN     | CCU模块号 | 用于指定处理SCCP协议的CCU的模块号。 取值范围：1～1024。 默认值：无。 说明：可以使用LST MODULE命令查询已经存在的CCU模块号。如果输入的模块号为1024，则将命令下发给所有状态正常的CCU模块。                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| NI     | 网络指示   | 即内部网络指示语，用于指定该目的实体的信令点编码位于哪一个信令网中，用户应根据实际情况进行设置。 取值范围：INT(国际主用网)INTB(国际备用网)NAT(国内主用网)NATB(国内备用网) 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| SPC    | 信令点编码  | 用于指定SCCP子系统所对应的目的信令点编码。 取值范围：无。 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| OPC    | 源信令点编码 | 用于指定SCCP子系统所对应的源信令点编码。 取值范围：无。 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| SSN    | SSN    | 用于指定SCCP子系统号，代表各子系统用户。可以使用LST SCCPSSN命令查询已存在的SCCP子系统。 取值范围： “UNDEF(未定义)”“SCMG(SCMG 0x01)”“RESERVED(保留 0x02)”“ISUP(ISUP 0x03)”“OMAP(OMAP 0x04)”“MAP(MAP 0x05)”“HLR(HLR 0x06)”“VLR(VLR 0x07)”“MSC(MSC 0x08)”“EIR(EIR 0x09)”“AUC(AUC 0x0A)”“MC(MC 0x0B)”“OTAF(OTAF 0x0C)”“SCP(SCP 0x0E)”“GMLC(GMLC 0x91)”“CAP(CAP 0x92)”“GSMSCF(GSM SCF 0x93)”“SGSN(SGSN 0x95)”“GGSN(GGSN 0x96)”“MPC(MPC 0xFA)”“GS(GS 0xFC)”“BSSAP/INAP(BSSAP/INAP 0xFE)”“SSN13(子系统号13)”“SSN15(子系统号15)”～“SSN144(子系统号144)”“SSN148(子系统号148)”“SSN151(子系统号151)”～“SSN249(子系统号249)”“SSN251(子系统号251)”“SSN253(子系统号253)” 默认值：无。 说明：无。 |

## 使用实例

显示SCCP子系统，“CCU模块号”为“2”，“网络指示”为“国内主用网”，“信令点编码”是“000096”，“源信令点编码”是“000096”，“SSN”为“HLR”：

```
DSP SCCPSSN: MN=2, NI=NAT, SPC="000096", OPC="000096", SSN=HLR;
```

返回结果如下：

```
%%DSP SCCPSSN: MN=2, NI=NAT, SPC="000096", OPC="000096", SSN=HLR;%%
RETCODE = 0  操作成功

SCCP子系统状态查询结果
----------------------
              CCU模块号  =  2
                SSN状态  =  允许
            备用SSN状态  =  禁止
SSN是否处于协调等待状态  =  否
  SSN是否处于被测试状态  =  否
 是否忽略子系统状态测试  =  否
(结果个数 = 1)
```

## 输出结果说明

| 输出项名称         | 输出结果解释                                                                                                                                              |
|:--------------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| CCU模块号        | 用于返回CCU模块号。                                                                                                                                         |
| 子系统状态         | 用于返回当前SCCP子系统的状态： 允许：表示当前目的信令点下该子系统运行正常。 禁止：表示当前目的信令点下该子系统被禁止不可用。                                                                                   |
| 备用子系统状态       | 用于返回当前SCCP备用子系统的状态： 允许：表示当前备用子系统运行正常。 禁止：表示当前备用子系统被禁止不可用。                                                                                           |
| 子系统是否处于协调等待状态 | 用于返回当前子系统是否处于协调等待状态： 是：表示子系统处于协调等待状态。 否：表示子系统没有处于协调等待状态。 协调等待状态是子系统收到对端“子系统禁止指示”消息后所处的状态。                                                           |
| 子系统是否处于被测试状态  | 用于返回当前子系统是否处于被测试状态： 是：表示此子系统处于测试状态。 否：表示此子系统处于非测试状态。 当目的子系统状态由允许变为禁止时，SCCP不断发送“子系统状态测试消息（SST）”对该子系统状态进行测试，以检测该子系统状态是否变为允许，当子系统收到“子系统测试”消息后将处于被测试状态。 |
| 是否忽略子系统状态测试   | 用于返回当前子系统是否忽略子系统状态测试： 是：表示远端SSN收到SST消息时，不向本端SSN返回SSA（SCCP子系统允许）消息。 否：表示远端SSN收到SST消息后，进行被测试状态，开始对子系统的状态进行检测，系统默认不忽略子系统状态测试。                          |
