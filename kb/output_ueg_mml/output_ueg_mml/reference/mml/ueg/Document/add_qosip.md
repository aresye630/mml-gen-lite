# 增加QOS测量IP地址对(ADD QOSIP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加QoS测量的IP地址对数据。

## 注意事项

该命令最多能添加512对IP地址。

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                                                                                 |
|:----------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPTYPE    | IP地址类型   | 用于指定IP地址的类型。 取值范围： IPV4(IPV4版本)IPV6(IPV6版本) 默认值：无。                                                                                                                                                   |
| LOCALIP   | 本端IP地址   | 本端IP地址。仅当参数“IP地址类型”设置为“IPV4(IPV4版本)”时，该参数有效。 该参数必须由ADD IPADDR定义，然后才能在此处引用。 IPV4格式为“xxx.xxx.xxx.xxx”，例如，10.51.0.1。 取值范围：IPV4地址。 默认值：无                                                                 |
| PEERIP    | 对端IP地址   | 对端IP地址。仅当参数“IP地址类型”设置为“IPV4(IPV4版本)”时，该参数有效。 该参数的配置原则是：该地址必须和对端设备协商好，和对端设备的配置保持一致。 IPV4格式为“xxx.xxx.xxx.xxx”，例如，10.51.0.1。 取值范围：IPV4地址。 默认值：无                                                         |
| LOCALIPV6 | 本端IPV6地址 | 本端IPV6地址。仅当参数“IP地址类型”设置为“IPV6(IPV6版本)”时，该参数有效。 该参数必须由ADD IPADDR定义，然后才能在此处引用。 IPV6格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如，2001:0DB8:8432:4098:4782:5784:8938:12EC。 取值范围：IPV6地址。 默认值：无         |
| PEERIPV6  | 对端IPV6地址 | 对端IPV6地址。仅当参数“IP地址类型”设置为“IPV6(IPV6版本)”时，该参数有效。 该参数的配置原则是：该地址必须和对端设备协商好，和对端设备的配置保持一致。 IPV6格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如，2001:0DB8:8432:4098:4782:5784:8938:12EC。 取值范围：IPV6地址。 默认值：无 |

## 使用实例

增加QoS测量的IP地址对数据，参数IP地址类型设置为IPV4，本端IP:192.168.165.198，对端IP:192.168.165.199。

```
ADD QOSIP: IPTYPE=IPV4, LOCALIP="192.168.165.198", PEERIP="192.168.165.199";
```

| 352049 | 本端IP地址和对端IP地址重复。      | 输入的本端IP数据与对端IP数据相同。        | 请检查确保输入的正确的本端IP数据与正确的对端IP数据。               |
