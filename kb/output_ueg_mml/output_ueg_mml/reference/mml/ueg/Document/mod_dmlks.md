# 修改Diameter链路集(MOD DMLKS)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一条Diameter链路集的数据记录的某些参数进行修改或调整。在该命令中，系统通过“链路集名称”参数来唯一标识一条Diameter链路集数据记录。

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|:------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LINKSNAM    | 链路集名称  | 标识一条Diameter链路集数据记录的关键字段，用于指定需要对哪一条Diameter链路集数据记录的参数进行修改或调整，操作员可以使用LST DMLKS命令查询获得。                                                                                                                                                                                                                                                                                                                                                                                                                           |
| NEWLINKSNAM | 新链路集名称 | 用于标识UDM和对端网元之间的Diameter链路集的新名称。 取值范围：长度不超过127的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| LNKMOD      | 链路选择模式 | 用于标识该链路集内的Diameter链路选择模式。系统通过该参数决定使用哪条链路传输对接数据。 取值范围：SESSIONIDBASED(基于会话ID)：按照Session ID随机选取其中链路进行通信。如果Session ID AVP无效，就会默认选择第0条链路。POLLING(轮询方式)：对Diameter对端实体下的所有链路轮流选择，即在可用链路之间循环选择。AORS(主备方式)：当前只有一条链路主用，其余链路都是备用。只有当主用链路失效时，备用链路中的一条任意可用链路自动启用为主用链路。默认第0条链路为主链路，当第0条链路不可用时，会自动选择其他可用链路。ACTIVE(激活方式)：从第0条开始选择第一条激活的链路来工作。当该链路不可用时，则向后选择下一条激活链路。ACTIVEWITHPRI(基于优先级的激活方式)：选择优先级最高的一条激活链路来工作。优先级相同，则选择路由表中设置最靠前的一条激活链路。POLLINGWITHPRI(基于优先级的轮询方式)：对所有链路轮流选择，始终选择优先级最高的可用链路。存在多个优先级相同的链路时，在这些链路之间轮询选择。 默认值：无。 |

## 使用实例

在配置链路集信息时输入的“链路集名称”和“链路选择模式”有误。运行以下命令，为“链路集名称”为“HSS\_BSF”的链路集设置“新链路集名称”为“HSS\_AS”、“链路选择模式”为“SESSIONIDBASED(基于会话ID)”。

```
MOD DMLKS: LINKSNAM="HSS_BSF", NEWLINKSNAM="HSS_AS", LNKMOD=SESSIONIDBASED;
```
