# 查询Diameter对端实体(LST DMPE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询Diameter对端实体的配置信息：

- 若需要查询全部Diameter对端实体记录的概要信息，请不要输入任何参数。
- 若需要查询某些Diameter对端实体记录的详细信息，请输入“实体名称”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称            | 参数说明                                                                                    |
|:---------|:----------------|:----------------------------------------------------------------------------------------|
| EN       | 实体名称            | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个实体名称来查询Diameter对端实体信息；若不输入，则表示所有的实体名称。                       |
| PEERTYPE | Diameter对端实体类型  | 可选必选说明：可选参数 参数含义：用于指示系统按照哪种Diameter对端实体类型来查询Diameter对端实体信息；若不输入，则表示所有的Diameter对端实体类型。   |
| HN       | 主机名             | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个主机名来查询Diameter对端实体信息；若不输入，则表示所有的主机名。                         |
| DN       | 域名              | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个域名来查询Diameter对端实体信息；若不输入，则表示所有的域名。                           |
| PEPRI    | Diameter对端实体优先级 | 可选必选说明：可选参数 参数含义：用于指示系统按照哪种Diameter对端实体优先级来查询Diameter对端实体信息；若不输入，则表示所有的Diameter对端实体优先级。 |

## 使用实例

1. 查询所有Diameter对端实体的配置信息：

   ```
   LST DMPE:;
   ```

   ```
   %%LST DMPE:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    实体名称           Diameter对端实体类型  主机名                        域名            Diameter对端实体优先级  Diameter对端实体设备标识  Diameter对端实体标识

    SAEHSS1            OTHER                 saehss1.huawei.com            NULL            15                      22                        22                  
    GGSN22             GGSN                  ggsn22.huawei.com             NULL            15                      65                        65                  
    AS                 AS                    as.domainname.com             domainname.com  1                       67                        66                  
   (结果个数 = 2)

   ---    END
   ```
2. 查询Diameter对端实体名称为“AS”的设备的配置信息。

   ```
   LST DMPE: EN="AS";
   ```

   ```
   %%LST DMPE: EN="AS";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
                   实体名称  =  AS
       Diameter对端实体类型  =  AS
                     主机名  =  as.domainname.com
                       域名  =  domainname.com
     Diameter对端实体优先级  =  1
   Diameter对端实体设备标识  =  67
       Diameter对端实体标识  =  66
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见

**ADD DMPE**

命令的参数说明，表1列出的是未包含在

**ADD DMPE**

命令参数说明中的输出项。

| 输出项名称            | 输出项解释                      |
|:-----------------|:---------------------------|
| Diameter对端实体设备标识 | 用于返回一个Diameter对端实体的设备标识。   |
| Diameter对端实体标识   | 用于返回一个Diameter对端实体的数据记录索引。 |
