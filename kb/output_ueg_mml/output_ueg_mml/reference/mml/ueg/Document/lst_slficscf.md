# 查询外部I-CSCF设备的配置信息(LST SLFICSCF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询SLF的I-CSCF设备的配置信息：

- 若需要查询全部I-CSCF数据记录的信息，请不要输入任何参数。
- 若需要查询某条I-CSCF数据记录的详细信息，请输入“I-CSCF名称”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                       |
|:-------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SLFN   | SLF名称    | 用于指示系统需要按照哪个“SLF名称”来查询I-CSCF数据记录；若不输入，则表示所有的SLF实体名称。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                                     |
| CSCFN  | I-CSCF名称 | 用于指示系统需要按照哪个“I-CSCF名称”来查询I-CSCF数据记录；若不输入，则表示所有的“I-CSCF名称”。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                               |
| HN     | 主机名      | 用于指示系统需要按照哪个“主机名”来查询I-CSCF数据记录；若不输入，则表示所有的“主机名”。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                                         |
| LNKMOD | 链路选择模式   | 用于指示系统需要按照哪个“链路选择模式”来查询I-CSCF数据记录；若不输入，则表示所有的“链路选择模式”。 取值范围： SESSIONIDBASED(基于会话ID)：同一个会话的所有信令消息都在同一条链路上传输。多个会话的消息按照轮选的方式在多条链路负荷分担。 POLLING(轮询方式)：当配置多条链路，信令消息在每条链路上负荷分担。 AORS(主备方式)：在主备链路选择方式下，如果主链路故障，则将某条备用链路升为主链路。默认第0条链路为主链路，当第0条链路不可用时，会自动选择其他可用链路。 ACTIVE(激活方式)：根据链路的激活状态，从第0条开始选择第一条激活的链路，将信令消息发往该链路。 ACTIVEWITHPRI(基于优先级的激活方式)：基于优先级的激活方式。 POLLINGWITHPRI(基于优先级的轮询方式)：基于优先级的轮询方式。 默认值：无。 说明：可选参数。 |

## 使用实例

1. 查询SLF所有I-CSCF的配置信息：

   `LST SLFICSCF:;`

   ```
   %%LST SLFICSCF:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    SLF名称  I-CSCF名称  主机名             链路选择模式  SLF索引  I-CSCF索引

    SLF1     ICSCF3      icscf1.huawei.com  轮询方式       9        2         
    SLF2     ICSCF2      icscf2.huawei.com  轮询方式       8        1         
    SLF9     ICSCF1      icscf1.huawei.com  轮询方式       1        0         
   (结果个数 = 3)

   ---    END
   ```
2. 查询SLF某个I-CSCF的配置信息，“I-CSCF名称”为“ICSCF2”：

   `LST SLFICSCF: CSCFN="ICSCF2";`

   ```
   %%LST SLFICSCF: CSCFN="ICSCF2";%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
        SLF名称  =  SLF2
     I-CSCF名称  =  ICSCF2
         主机名  =  icscf2.huawei.com
   链路选择模式  =  轮询方式 
        SLF索引  =  8
     I-CSCF索引  =  1
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

以下列出的是未包含在本命令参数说明中的输出项，其他输出项的详细说明请参见本命令的参数说明。

|:---------|:---------------------------------------------|
