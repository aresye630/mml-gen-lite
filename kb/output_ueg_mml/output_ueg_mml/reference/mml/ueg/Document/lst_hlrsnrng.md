# 查询HLR号段(LST HLRSNRNG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询HLR号段记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                          |
|:-------|:-------|:------------------------------------------------------------------------------|
| TYPE   | 前缀类型   | 用于指示系统需要按照哪种前缀类型来查询命令；若不输入，则表示查询所有。 取值说明： “IMSI(IMSI)”“MSISDN(MSISDN)” 默认值：无。 |
| PREFIX | 号码前缀   | 用于指示系统需要按照哪种号码前缀来查询命令；若不输入，则表示查询所有。 取值范围：长度不超过15个数字字符串 默认值：无。                 |
| HLRSN  | HLR序列号 | 用于指示系统需要按照哪种HLR序列号来查询命令；若不输入，则表示查询所有。取值范围：1～255 默认值：无。                        |

## 使用实例

查询所有HLR号段记录。

`LST HLRSNRNG:;`

```
%%LST HLRSNRNG:;%%
RETCODE = 0  操作成功

操作结果如下
------------
   前缀类型 = IMSI
   号码前缀 = 189919
  HLR序列号 = 12
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释             |
|:--------|:------------------|
| HLR序列号  | 跟踪HLRSN对应的HLR序列号。 |
| 前缀类型    | 跟踪HLRSN对应的号段前缀类型。 |
| 号码前缀    | 跟踪HLRSN对应的号段前缀。   |
