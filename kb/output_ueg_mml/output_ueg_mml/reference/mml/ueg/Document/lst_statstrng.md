# 查询业务条件操作统计对象(LST STATSTRNG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询业务条件操作统计对象的配置信息。

查询链路组配置的相关方法如下：

- 若需要查询全部统计对象的配置信息，请不要输入任何参数值。
- 若需要查询某个统计对象的配置信息，请在“统计对象ID”中输入对应的参数值。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|:----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OBJECTID  | 统计对象ID | 用于表示待查询统计对象ID，系统内唯一。 取值范围：“OBJECT1(OBJECT1)”～“OBJECT64(OBJECT64)” 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                |
| TYPE      | 统计类型   | 用于表示待查询统计对象的统计类型。 取值范围：“STAT_STRING_FORGT(按GT局向统计)”“STAT_PRE_FIX_FORGT(按前缀GT局向统计)”“STAT_REVERSE_FORGT(按STRING以外GT局向统计)”“STAT_PLMN(按PLMN统计)”“STAT_SRCODE(按SRCODE统计)”“STAT_DIAMHOST(按DIAMHOST统计)”“STAT_IMSHOST_FORREPSYNC(按IMSHOST统计透明数据同步消息)” 默认值：无。                                                                                                                                                                                                     |
| PARAMETER | 参数     | 用于表示待查询统计对象的实际参数值。 取值范围：“统计类型”为“STAT_STRING_FORGT(按GT局向统计)”，“STAT_PRE_FIX_FORGT(按前缀GT局向统计)”，“STAT_REVERSE_FORGT(按STRING以外GT局向统计)”时，“参数”是长度不超过15的数字字符串。“统计类型”为“STAT_PLMN(按PLMN统计)”时，“参数”是长度为5～6位的数字字符串。当长度为6时，第六个字符可以为‘F’。“统计类型”为“STAT_SRCODE(按SRCODE统计)”时，“参数”是由‘*’，‘#’，数字组成的长度不超过16的字符串。“统计类型”为“STAT_DIAMHOST(按DIAMHOST统计)”时，“参数”是由长度为1～127位的数字、字母、“_”、“.”和“@”组成字符串。“统计类型”为“STAT_IMSHOST_FORREPSYNC(按IMSHOST统计透明数据同步消息)”时，“参数”是由长度不超过127的字符串组成。 默认值：无。 |

## 使用实例

1. 查询一个具体统计对象的配置信息，“统计对象ID”为“OBJECT1(OBJECT1)”：

   `LST STATSTRNG: OBJECTID=OBJECT1;`

   ```
   %%LST STATSTRNG: OBJECTID=OBJECT1;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------------------
   统计对象ID  =  统计对象1
     统计类型  =  按GT局向统计
         参数  =  6688541
   (结果个数 = 1)

   ---    END
   ```
2. 查询所有统计对象的配置信息：

   `LST STATSTRNG:;`

   ```
   %%LST STATSTRNG:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------------------
    统计对象ID             统计类型             参数  

    统计对象1              按GT局向统计         6688541    
    统计对象2              按前缀GT局向统计     9945678
   (结果个数 = 2)

   ---    END
   ```
