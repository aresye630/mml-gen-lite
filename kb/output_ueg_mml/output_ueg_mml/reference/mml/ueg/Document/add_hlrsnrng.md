# 增加HLR号段(ADD HLRSNRNG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于增加一条HLR号段记录。

## 注意事项

相同号段前缀与前缀类型的组合不能添加到两个HLRSN下。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                           |
|:-------|:-------|:---------------------------------------------------------------|
| TYPE   | 前缀类型   | 用于指定要添加的HLR号段的前缀类型。 取值说明： “IMSI(IMSI)” “MSISDN(MSISDN)” 默认值：无。 |
| PREFIX | 号码前缀   | 用于指定要添加的HLR号段的前缀。 取值范围：长度不超过15个数字字符串 默认值：无。                    |
| HLRSN  | HLR序列号 | 用于指定要添加的HLR号段关联的HLR序列号。 取值范围：1～255 默认值：无。                      |

## 使用实例

增加一条HLR号段记录。前缀类型为IMSI，号码前缀为“189919”，关联HLR序列号为12。

`ADD HLRSNRNG: TYPE=IMSI, PREFIX="189919", HLRSN=12;`
