# 查询E2E跟踪任务(LST E2ETSK)

## 命令功能

本命令用于查询UDM是否已有某用户的E2E跟踪任务。

- 若网管要查询用户是否在UDM注册，网管向UDM(HSS)发送**DSP USERONHSS**命令来查询。若用户已注册，网管需要向注册的UDM(HSS)发送**LST E2ETSK**命令查询该用户的E2E跟踪任务。若没有注册，则需要向UDM发送创建任务跟踪的消息。
- 若网管要查询用户指定的UDM，网管向指定的UDM(HSS)发送**LST E2ETSK**命令查询是否已有某用户的E2E跟踪任务，若已有E2E跟踪任务，则网管接受跟踪任务消息；若没有E2E跟踪任务，则网管需要向指定的UDM发送创建任务跟踪的消息。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                     |
|:----------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NETTYPE   | 网络类型   | 可选必选说明：必选参数。 参数含义：用于指示系统按照用户所在的“网络类型”来查询已有用户的E2E跟踪任务。 取值范围： LTE-SAE(LTE-SAE)IMS(IMS) 默认值：无 配置原则：无                                                                        |
| USRIDTYPE | 用户标识类型 | 可选必选说明：可选参数。 参数含义：用于指示系统按照“用户标识类型”来查询E2E跟踪任务；若不输入，则表示所有的“用户标识类型”。 取值范围： 当“网络类型”为“LTE-SAE(LTE-SAE)”时：IMSI(IMSI)MSISDN(MSISDN) 当“网络类型”为“IMS(IMS)”时：IMPU(IMPU) 默认值：无 配置原则：无 |
| IMSI      | IMSI   | 可选必选说明：条件必选参数。 参数含义：用于指示系统按照“IMSI”来查询E2E跟踪任务。 取值范围：6～15位的十进制数字组成的字符串。 默认值：无 配置原则：当“用户标识类型”参数为“IMSI(IMSI)”时该参数有效。                                                         |
| MSISDN    | MSISDN | 可选必选说明：条件必选参数。 参数含义：用于指示系统按照“MSISDN”来查询E2E跟踪任务。 取值范围：1～15位的十进制数字组成的字符串。 默认值：无 配置原则：当“用户标识类型”为“MSISDN(MSISDN)”时该参数有效。                                                     |
| IMPU      | IMPU   | 可选必选说明：条件必选参数。 参数含义：用于指示系统按照“IMPU”来查询E2E跟踪任务。 取值范围：长度不超过127的字符串。 默认值：无 配置原则：当“用户标识类型”为“IMPU(IMPU)”时该参数有效。                                                                |
| TRCREF    | 跟踪参考号  | 可选必选说明：可选参数。 参数含义：用于指示系统按照“跟踪参考号”来查询E2E跟踪任务；若不输入，则表示所有的“跟踪参考号”。 取值范围：长度为12~13字符串。 默认值：无 配置原则：当“用户标识类型”为空时，该参数有效。                                                         |
