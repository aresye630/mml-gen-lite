# 查询手工流控策略(LST TCAPPOL)

## 命令功能

该命令为维护类命令，用于在配置数据库中查询手工流控策略配置信息。

- 若需要查询全部流控策略配置信息，请将“流控策略索引”参数不输入，“流控策略”参数不输入。
- 若需要查询某种类型流控策略配置的详细信息，请输入“流控策略”参数。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| TCIDX  | 流控策略索引 | 用于指示系统需要按照哪个流控策略索引来查询流控策略配置数据；若不输入，则表示所有的流控策略索引。 取值范围：0～255 默认值：无。 说明：可选参数。                                                                         |
| TCMODE | 流控策略   | 用于指示系统需要按照哪种流控策略方式来查询流控策略配置数据；若不输入，则表示所有的流控策略方式。 取值范围： “LSPC1(OPC+SSN)”“LSPC2(GT+SSN)”“LSPC3(不区分局向)”“DPC1(被叫GT+SSN)”“DPC2(不区分被叫局向)” 默认值：无。 说明：可选参数。 |
