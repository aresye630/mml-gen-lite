# 增加网络应用功能AP列表数据(ADD NAFIDAP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在BSF上配置AP的FQDN与AP域名或AP IP地址之间的映射关系。在GBA架构下，

- BSF进行Diameter路由或使用内部Zn接口时，AP作为业务访问认证代理和转发实体，当用户请求接入时，BSF通过AP的FQDN与AP域名的映射关系，判断AP访问AS的合法性，以提高用户访问操作的安全性。
- BSF使用SOAP接口时，当用户请求接入时，BSF通过AP的FQDN与AP IP地址的映射关系，判断AP访问AS的合法性，以提高用户访问操作的安全性。

  **说明** 

  该命令仅在Full-stack虚机场景下支持。

## 注意事项

“AP域名”和“AP IP地址”必须配置且只能配置一个。

## 参数说明

| 参数标识     | 参数名称       | 参数说明                                                                                                                                                                                                                                                         |
|:---------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FQDN     | FQDN       | 可选必选说明：必选参数 用于指定待配置网络应用功能的全量域名（Fully Qualified Domain Name），在本命令中用于标识AP的FQDN。当UIM采用GBA认证时“FQDN”与“Ua接口安全协议标识”（遵循3GPP标准协议，以保证用户通过Ua接口进行业务互操作的安全性）共同组成“NAFID”（“NAFID”用于标识合法的网络应用功能组）。 需要指出的是，该参数不区分大小写，在执行LST NAFIDAP命令查询出的报文中为全小写形式。 取值范围：长度不超过127的字符串。 默认值：无。 |
| REALM    | 域名         | 可选必选说明：可选参数 用于指定可以通过访问认证的域名，即合法请求AP域名。同一“FQDN”下的AP域名不能重复，且最多可配置64条AP域名信息。若对该NAFID中AP的域名不进行配置，表示对该请求的AP不限制。 需要指出的是，该参数不区分大小写，在执行LST NAFIDAP命令查询出的报文中为全小写形式。 取值范围：长度不超过127的字符串。 默认值：无。 说明：该参数用于Zn接口使用DIAMETER协议的场景。                                            |
| ADDRTYPE | IP地址类型     | 可选必选说明：可选参数 用于标识IP地址的类型。 取值范围：IPV4(IPV4)：IPv4类型的IP地址。 IPV6(IPV6)：IPv6类型的IP地址。 默认值：无。                                                                                                                                                                         |
| IPV4     | NAF IPv4地址 | 可选必选说明：条件必选参数 仅当本命令的“IP地址类型”参数为“IPV4(IPV4)”时该参数有效。用于标识AP的IPv4地址，即合法请求AP地址。 取值范围：有效的IPv4地址。 默认值：无。 说明：该参数用于Zn接口使用SOAP协议的场景。                                                                                                                                   |
| IPV6     | NAF IPv6地址 | 可选必选说明：条件必选参数 仅当本命令的“IP地址类型”参数为“IPV6(IPV6)”时该参数有效。用于标识AP的IPv6地址，即合法请求AP地址。 取值范围：有效的IPv6地址。 默认值：无。 说明：该参数用于Zn接口使用SOAP协议的场景。                                                                                                                                   |

## 使用实例

增加一组AP的FQDN与AP域名的映射关系，携带以下参数：

- “FQDN”为“bsf.huawei.com”
- “域名”为“huawei.com”

执行命令如下：

```
ADD NAFIDAP: FQDN="bsf.huawei.com", REALM="huawei.com";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                      | 原因分析                                                          | 处理建议                                                                 |
|-------:|:---------------------------|:--------------------------------------------------------------|:---------------------------------------------------------------------|
| 378304 | 域名和IP地址类型必须配置其中一个。         | “AP域名”和“AP IP地址”均未配置。                                         | 输入参数“域名”或“IP地址类型”与IP地址的组合后重新执行该命令，确保“AP域名”和“AP IP地址”至少设置一个。          |
| 378305 | IPv6网段全F是非法值。              | 参数“NAF IPv6地址”不能取值为“FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF”。 | 重新输入“NAF IPv6地址”参数，确保其取值不为“FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF”。 |
| 378307 | IPv4网段255.255.255.255是非法值。 | 参数“NAF IPv4地址”不能取值为“255.255.255.255”。                         | 重新输入“NAF IPv4地址”参数，确保其取值不为“255.255.255.255”。                         |
| 378309 | 域名和IP地址类型不能同时配置。           | “AP域名”和“AP IP地址”同时只能配置一个。                                     | 删除参数“域名”或“IP地址类型”与IP地址的组合的取值后重新执行该命令，确保“AP域名”和“AP IP地址”同时只能配置一个。     |
