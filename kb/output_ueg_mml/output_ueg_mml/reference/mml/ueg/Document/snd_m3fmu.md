# 发送M3UA应用层伪消息(SND M3FMU)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为维护类命令，用于请求系统发送M3UA用户伪消息。

该命令仅适用于测试场景，例如在IOT（interoperability test）测试中，操作员可以通过该命令提供仿真协议接口以完成某些特定的测试项目，而在其他情况下，请勿使用该命令。

## 注意事项

- M3UA伪消息由主机下发到负责信令处理的单板，这些消息可能对信令链路造成严重影响，请操作员在执行该操作之前仔细确认任务的可行性。
- 在使用该命令前，请使用**DSP M3LKS**命令查询发送伪消息的M3UA链路集的状态，只有在M3UA链路集的状态为“已激活”时，系统才能发送伪消息 。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MN     | BSG模块号 | 标识一个BSG模块号的关键字段，用于指定系统在哪一个BSG模块上发送伪消息，操作员可以用LST M3LNK命令查询M3UA协议的BSG模块号情况。 取值范围:1～1023 默认值:无。                                                                                                                                                                                                        |
| MSGN   | 单位消息数  | 用于指定一个单位发送周期内发送的消息数。 取值范围: 1～30，推荐配置为1。 默认值: 无。                                                                                                                                                                                                                                                     |
| TPC    | 单位发送周期 | 用于指定一个单位发送周期的时长。 取值范围: 0～255，单位发送周期用滴答（tick）数表示，1个滴答等于10毫秒。推荐配置为1。 默认值:无。                                                                                                                                                                                                                           |
| NUM    | 单位消息组数 | 用于指定单位消息组数，推荐配置为1。该参数的配置原则是： 如果单位消息组数为0，表示不断地连续发送用户伪消息。 如果单位消息组数不为0（如1）时，表示发送一定数量的伪消息，直到发完为止。发送的总消息数=单位消息组数*单位消息数。 取值范围:0～65534 默认值: 无。                                                                                                                                                             |
| MLEN   | 消息长度   | 用于指定伪消息长度。 取值范围: 1～273 默认值: 无。                                                                                                                                                                                                                                                                      |
| MSU    | 消息信令单元 | 用于指定M3UA用户伪消息内容，该参数的配置原则是： 消息参数为十六进制格式。 消息内容的数据格式必须与M3UA协议标准中指定的消息格式保持一致。后续的消息内容必须符合用户部分协议（例如，SNM、SCCP等）的格式，协议类型由SIO中的业务指示语字段指定。 参数的字节顺序应为网络字节顺序。 M3UA用户伪消息格式如下所示： |----SIO----|----DPC----|----OPC----|----SLS----| 各字段的长度如下： SIO：8 bit DPC：14/24 bit OPC：14/24 bit SLS：4 bit 允许长度：546 bit 默认值: 无。 |
| DIR    | 方向     | 用于指定伪消息发送的方向。 取值范围: UP(上行) DOWN(下行) 默认值: DOWN(下行)。                                                                                                                                                                                                                                                  |
| LNKNM  | 链路名称   | 仅当本命令中的“方向”参数为“UP(上行)”时该参数有效。用于标识一条M3UA链路。 取值范围：长度不超过32的字符串。 默认值：无。                                                                                                                                                                                                                                 |

## 使用实例

发送M3UA伪消息，“BSG模块号”为“134”，“单位消息数”为“1”，“单位发送周期”为“1”，“单位消息组数”为“1”，“消息长度”为“12”，“消息信令单元”为“850100210100200101001000”：

```
SND M3FMU: MN=134, MSGN=1, TPC=1, NUM=1, MLEN=12, MSU="850100210100200101001000", DIR=DOWN;
```
