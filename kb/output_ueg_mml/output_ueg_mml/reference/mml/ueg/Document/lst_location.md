# 查询Location信息(LST LOCATION)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询Location信息。location有以下几种：主用局FE、主用局USCDB、容灾局FE、容灾局USCDB。

## 注意事项

无。

## 参数说明

| 参数ID   | 参数名称       | 参数描述                                                                               |
|:-------|:-----------|:-----------------------------------------------------------------------------------|
| LOCID  | Location标识 | 用于标识一个网元，所有的网元标识唯一。location有以下几种：主用局FE、主用局USCDB、容灾局FE、容灾局USCDB。 取值范围：1～512 默认值： 无。 |

## 使用实例

查询Location配置信息。

LST LOCATION:;

```
%%LST LOCATION:;%%
RETCODE = 0  操作成功

操作结果如下
------------
Location标识  =  6
    网元类型  =  SUP-FE
(结果个数 = 1)

---    END
```

## 输出结果说明

| 参数名称       | 参数描述                |
|:-----------|:--------------------|
| Location标识 | 用于标识一个网元，所有的网元标识唯一。 |
| 网元类型       | 本location的网元类型。     |
