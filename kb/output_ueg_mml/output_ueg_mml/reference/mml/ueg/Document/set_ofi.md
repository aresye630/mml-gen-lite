## 命令功能

**须知** 

本命令属于高危命令，该操作可能导致ESN变动，需要在60天内重新申请并加载License。执行不当会造成本局与其它网元的链路不通，局点业务异常甚至中断，因此执行该命令前，请详细阅读本命令的联机帮助和注意事项，并评估规划数据的正确性，商用局点禁止执行该命令。操作前必须由华为工程师提交RFC至华为机关审核操作实施方案、测试方案和回退方案后才可以实施。如有疑问请联系华为公司处理。

该命令为配置类命令，用于在配置数据库中设置本局信息的第一个信令点。

## 注意事项

- ESN信息与License有关，当局点的ESN信息中存在GT地址时，若执行SET OFI导致本局GT地址发生改变，则会导致ESN变动（本局为ENS网元时，不会导致ESN变动），需要重新申请License文件，请谨慎操作。
- 如果本局基本信息设定不正确，将会导致系统运行异常。请操作员在执行该操作之前仔细确认任务的可行性。
- 本局支持多信令点编码功能，**SET OFI** 命令仅用于配置本局的缺省信令点编码（其本局信令点索引固定为0）。如果本局开通了多信令点编码功能，则本局的扩展信令点编码（本局信令点索引从1开始编号）由操作员通过**ADD OFI** 命令增加。开通多信令点编码功能时，多个信令点需要归属于同一个网络平面（国际主用网/国际备用网/国内主用网/国内备用网）。如果UDM和多个平面同时对接，则UDM设备仅支持主备组网，即仅一个UDM FE设备处理信令消息，且需要将“REDUNDANCYCHECK(是否支持容灾可用性自动探测功能)”软参设置为“0”。
- 本局信息在配置数据库中是重要的基础数据，其所定义的本局的缺省信令点编码将在局向数据表、目的信令点数据表等多处被索引，请勿随意修改本局信息的参数配置。
- 执行本命令修改数据后需要分平面重启FE网元的所有模块。
- 本命令中信令网结构相关参数（“国际主用网结构”/“国际备用网结构”/“国内主用网结构”/“国内备用网结构”）以及PGW Web LMT上**SET MAPSERV**中“信令点编码类型”参数必须和客户现网实际规划保持一致，否则会导致业务对接失败。
- 该命令不允许进行批操作。

## 使用实例

设置本局信息如下：

- “本局名称”: “LOCAL”，
- “国际主用网有效”: “NO(否)”，
- “国际备用网有效”: “NO(否)”，
- “国内主用网有效”: “YES(是)”，
- “国内备用网有效”: “YES(是)”，
- “第一搜索网络”和“第三搜索网络”: “NAT(国内主用网)”，
- “第二搜索网络”和“第四搜索网络”: “NATB(国内备用网)”，
- “国际主用网结构”和“国际备用网结构”: “SP14(14位信令点编码)”，
- “国际主用网编码”和“国际备用网编码”: “0x000000”，
- “国内主用网结构”: “SP24(24位信令点编码)”，
- “国内主用网编码”: “0x2A1331”，
- “国内备用网结构”: “SP14(14位信令点编码)”，
- “国内备用网编码”: “0x0000BB”，
- “STP功能标志”: “NO(否)”，
- “重启动功能标志”: “NO(否)”，
- “本局GT”: “861390270”。

```
SET OFI: OFN="LOCAL", IN=NO, IN2=NO, NN=YES, NN2=YES, SN1=NAT, SN2=NATB, SN3=NAT, SN4=NATB, IPC="000000", IP2C="000000", NPC="2A1331",NP2C="0000BB", INS=SP14, IN2S=SP14, NNS=SP24, NN2S=SP14, STP=NO, RSF=NO, LOCGT=K'861390270 ;
```
