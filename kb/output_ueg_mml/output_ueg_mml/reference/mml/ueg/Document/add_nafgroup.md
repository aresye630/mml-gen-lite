# 增加NAFGROUP群组名称(ADD NAFGROUP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在配置数据库中增加一个网络应用功能组和名称，为下一步配置网络应用功能数据做准备，同时该命令可以使运营商对网络应用功能数据按组进行划分，将用户签约的网络应用功能数据信息独立的归属于某个网络应用功能组，便于维护和管理。当UIM采用GBA架构对用户进行认证，其功能实现体BSF（Bootstrapping Server Function）需要从IMS-HSS获取用户的GUSS（GBA User Security Settings）签约信息，该信息在IMS-HSS中通过群组进行配置，在UIM中设置对应的网络应用功能组数据，便于UIM从IMS-HSS获取用户的GUSS签约信息，完成GBA架构下对用户的认证。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称        | 参数说明                                                                                                                                                                                                                                             |
|:-------|:------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NAFGRP | NAF GROUP编号 | 用于指定一个网络应用功能群组的标识。“NAF GROUP编号”全局唯一。在GBA架构下，运营商可对NAF（Network Application Function）数据信息按组进行划分，NAF作为GSID（GAA Service Identifier）业务的提供者，在同一网络应用功能组中，对该GSID业务的USS用户安全性设置要求相同。 取值范围：1～65535。 默认值：无。 注意：该参数为必选参数。                                      |
| NAME   | NAF GROUP名称 | 用于指定一个网络应用功能群组的名称。“NAF GROUP名称”全局唯一，不能重复。  说明： 若用户的GUSS签约信息中包含NAF群组信息，“NAF GROUP名称”参数需要与对端IMS-HSS进行协商，“NAF GROUP名称”参数要与IMS-HSS上配置的NAF群组信息保持一致。若用户的GUSS签约信息中不包含NAF群组信息，IMS-HSS下发USS信息后，UIM不对NAF群组的一致性进行判断。 取值范围：长度不超过127的字符串。 默认值：无。 注意：该参数为必选参数。 |

## 使用实例

增加网络应用功能组，携带以下参数：

- “NAF GROUP编号”为“1”
- “NAF GROUP名称”为“NAF1”

执行命令如下：

```
ADD NAFGROUP: NAFGRP=1, NAME="NAF1";
```
