# 查询FE平面信息(LST FEPLAINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询FE平面数据的配置信息：

- 若需要查询全部FE平面数据记录的概要信息，请不要输入任何参数。
- 若需要查询某条FE平面数据记录的详细信息，请输入“平面信息标识”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                             |
|:----------|:--------|:-------------------------------------------------|
| PLAINFOID | 平面信息标识  | 用于指示系统需要按照哪个平面信息标识来查询FE平面数据；若不输入，则表示所有的平面信息标识。   |
| PLA0POD   | 平面0 Pod | 用于指示系统需要按照哪个平面0 Pod来查询FE平面数据；若不输入，则表示所有的平面0 Pod。 |
| PLA1POD   | 平面1 Pod | 用于指示系统需要按照哪个平面1 POD来查询FE平面数据；若不输入，则表示所有的平面1 Pod。 |

## 使用实例

1. 查询FE平面的配置信息，“平面信息标识”为“0”：

   ```
   LST FEPLAINFO: PLAINFOID=0;
   ```

   ```
   %%LST FEPLAINFO: PLAINFOID=0;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
          平面信息标识  =  0    
             平面0 Pod  =  pod0    
             平面1 Pod  =  pod1

   (结果个数 = 1)

   ---    END
   ```
2. 查询所有FE平面的配置信息：

   ```
   LST FEPLAINFO:;
   ```

   ```
   %%LST FEPLAINFO:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    平面信息标识    平面0 Pod    平面1 Pod
    0               pod0         pod1
    1               vUDM         NULL
   (结果个数 = 2)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD FEPLAINFO**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释        | 原因分析           | 处理建议                             |
|-------:|:-------------|:---------------|:---------------------------------|
| 100016 | 参数的值不在指定范围内。 | 报错的参数值不在取值范围内。 | 请根据报错的参数取值范围，重新输入正确的参数值后重新执行本命令。 |
