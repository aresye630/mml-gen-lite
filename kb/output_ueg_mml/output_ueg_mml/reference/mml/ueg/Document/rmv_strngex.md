# 删除用户数据统计扩展对象(RMV STRNGEX)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除用户数据统计对象的配置信息记录。

## 注意事项

删除统计对象会导致已建立的话统任务失效，请在操作时确认统计对象是否必须要删除。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                               |
|:---------|:-------|:-------------------------------------------------------------------|
| OBJECTID | 统计对象ID | 标识用户数据统计对象的关键字段，用于指定在哪个统计对象ID上删除用户数据统计对象，操作员可以使用LST STRNGEX命令查询获得。 |

## 使用实例

删除用户数据统计对象，“统计对象ID”为“OBJECT1(统计对象1)”：

```
RMV STRNGEX: OBJECTID=OBJECT1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释    | 原因分析                           | 处理建议                                                          |
|-------:|:---------|:-------------------------------|:--------------------------------------------------------------|
| 260183 | 记录不存在    | 用户输入的“统计对象ID”参数值对应的信息未添加。      | 请按照一下步骤进行操作： 先使用LST STRNGEX命令查询已添加过的统计数据。根据查询结果重新输入需要删除的参数值。  |
| 260224 | 不允许操作对象0 | “统计对象ID”参数取值为“OBJECT0(统计对象0)”。 | 请重新选择“统计对象ID”参数值，确保其取值为“OBJECT1(统计对象1)”～“OBJECT829(统计对象829)”。 |
