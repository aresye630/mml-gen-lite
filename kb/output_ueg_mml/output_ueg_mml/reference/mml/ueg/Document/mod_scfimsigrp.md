# 修改IMSI号段组(MOD SCFIMSIGRP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会导致用户鉴权失败、无法正常接入网络。因此执行该命令前，请仔细检查配置的正确性，确认无误方可执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用于对配置数据库的一条IMSI号段组记录的“IMSI号段组名称”进行修改或调整。在该命令中，系统通过“IMSI号段组名称”参数来唯一标识一条IMSI号段组记录。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称       | 参数说明                                                                              |
|:-----------|:-----------|:----------------------------------------------------------------------------------|
| GRPNAME    | IMSI号段组名称  | 标识一条IMSI号段组数据记录的关键字段，用于指定需要对哪一条IMSI号段组数据记录的参数进行修改或调整，操作员可以使用LST SCFIMSIGRP命令查询获得。 |
| NEWGRPNAME | 新IMSI号段组名称 | 用于标识一个IMSI号段组的新名称。 取值范围：长度不超过32的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。               |

## 使用实例

修改IMSI号段组记录。“IMSI号段组名称”为“group01”，“新IMSI号段组名称”为“group02”：

```
MOD SCFIMSIGRP: GRPNAME="group01", NEWGRPNAME="group02";
```

该命令执行正常，会返回命令执行成功的提示信息。
