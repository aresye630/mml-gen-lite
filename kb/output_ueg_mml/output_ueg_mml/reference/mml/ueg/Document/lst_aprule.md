# 查询AP转发规则(LST APRULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询AP转发规则数据记录。

- 若需要查询全部AP转发规则数据记录，请不要输入任何参数。
- 若需要查询某条AP转发规则数据记录，请输入“索引”、“HOST索引”、“应用区分标识索引”、“IMPU查询方式”或“IMPU”参数或它们的组合。

  **说明** 

  该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                          |
|:---------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------|
| ID       | 索引       | 用于指示系统需要按照哪个“索引”查询AP转发规则数据记录；若不输入，则表示所有的索引。                                                                                                   |
| HOSTID   | HOST索引   | 用于指示系统需要按照哪个“HOST索引”查询AP转发规则数据记录；若不输入，则表示所有的HOST索引。                                                                                           |
| AUIDID   | 应用区分标识索引 | 用于指定系统需要按照哪个“应用区分标识索引”查询AP转发规则数据记录；若不输入，则表示所有的应用区分标识索引。                                                                                       |
| IMPUMODE | IMPU查询方式 | 用于标识按照哪种“IMPU查询方式”查询AP转发规则数据记录；若不输入，则表示所有的IMPU。 取值范围：PREFIX(前缀匹配查询)：IMPU前缀号段匹配方式查询AP转发规则数据记录。POSTFIX(后缀匹配查询)：IMPU后缀域名匹配方式查询AP转发规则数据记录。 默认值：无。 |
| IMPU     | IMPU     | 仅当本命令中的“IMPU查询方式”参数设置时该参数有效，用于指示系统需要按照哪个“IMPU”查询AP转发规则数据记录。                                                                                   |

## 使用实例

1. 查询所有的AP转发规则数据记录，不携带参数：

   ```
   LST APRULE:;
   ```

   ```
   %%LST APRULE:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    索引    HOST索引  应用区分标识索引  IMPU存在  IMPU                                                                  HTTPPE索引

    1       0         0                 否        NULL                                                                  2         
    2       1         0                 否        NULL                                                                  2         
    3       0         1                 是        tel:+8613499999999                                                    2         
    4       1         1                 是        beijing.ims.mnc000.mcc460.3gppnetwork.org                             2         
   (结果个数 = 4)

   ---    END
   ```
2. 查询“索引”为“4”的AP转发规则数据记录：

   ```
   LST APRULE: ID=4;
   ```

   ```
   %%LST APRULE: ID=4;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
               索引  =  4
           HOST索引  =  1
   应用区分标识索引  =  1
           IMPU存在  =  是
               IMPU  =  beijing.ims.mnc000.mcc460.3gppnetwork.org
         HTTPPE索引  =  2
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD APRULE**命令的参数说明。
