# 查询协议适配数据(LST PADATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询个协议类型添加的适配数据。

## 注意事项

当前版本不支持此功能，执行该命令后会返回错误码：335607 暂不支持该功能。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                          |
|:---------|:-------|:--------------------------------------------------------------|
| PROTTYPE | 协议类型   | 用于指定当前支持的协议类型。 取值范围： “SMPP(SMPP)”：短消息点对点传输协议。 默认值：无。 说明：必选参数。 |
| USERNAME | 用户名    | 用于指定用户名。 取值范围：1～15字符串 默认值：无。 说明：可选参数。                         |

## 使用实例

查询SMPP协议适配数据信息。

LST PADATA: PROTTYPE=SMPP;

```
%%LST PADATA: PROTTYPE=SMPP;%%
RETCODE = 0  操作成功

操作结果如下
------------
协议类型  =  SMPP
  用户名  =  test
    前缀  =  135
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD PADATA**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释    | 原因分析        | 处理建议   |
|-------:|:---------|:------------|:-------|
