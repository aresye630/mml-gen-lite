# 删除AUID模板(RMV AUIDTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于从配置数据库中删除一条AUID（application unique ID ）模板数据记录。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

- 如果已经通过**ADD APRULE**命令引用该模板，当执行该命令删除AUID模板时，系统会提示“377907：当AUIDTPL被APRULE引用时，不能删除AUIDTPL，请先执行RMV命令删除相应的APRULE。”的错误信息，该AUID模板不能被删除。可以使用**LST APRULE**命令查询正在被引用该模板的AP转发规则。如果要删除该模板，必须先执行**RMV APRULE**命令删除引用该模板的AP转发规则。
- “索引”和“应用区分标识”两个参数至少输入一个。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                             |
|:-------|:-------|:-----------------------------------------------------------------|
| ID     | 索引     | 标识一个AUID模板配置信息的关键字段之一，用于指定需要删除哪个AUID模板，操作员可以使用LST AUIDTPL命令查询获得。 |
| AUID   | 应用区分标识 | 标识一个AUID模板配置信息的关键字段之一，用于指定需要删除哪个AUID模板，操作员可以使用LST AUIDTPL命令查询获得。 |

## 使用实例

1. 删除“索引”为“1”的AUID模板信息：

   ```
   RMV AUIDTPL: ID=1;
   ```
2. 删除“应用区分标识”为“simservs.ngn.etsi.org”的AUID模板信息：

   ```
   RMV AUIDTPL: AUID="simservs.ngn.etsi.org";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释                                                 | 原因分析                                   | 处理建议                                                                                |
|-------:|:-----------------------------------------------------|:---------------------------------------|:------------------------------------------------------------------------------------|
| 377842 | 记录不存在。                                               | 输入的“索引”或“应用区分标识”参数对应的AUID模板数据记录不存在。    | 根据实际情况，重新输入参数，确保输入的“索引”或“应用区分标识”参数对应的AUID模板已定义。可执行LST AUIDTPL命令查询系统中已存在的AUID模板数据记录。 |
| 377900 | 请至少输入一个参数。                                           | “索引”或“应用区分标识”两个参数一个都没有输入。              | 根据实际情况，重新输入参数，确保“索引”和“应用区分标识”两个参数至少输入一个。                                            |
| 377907 | 当AUIDTPL被APRULE引用时，不能删除AUIDTPL，请先执行RMV命令删除相应的APRULE。 | 输入的“索引”或“应用区分标识”参数对应的HOST模板已被AP转发规则引用。 | 根据实际情况，确定是否要删除该模板。如果确实需要删除，先通过RMV APRULE命令删除引用该模板的AP转发规则，然后再执行该命令删除该AUID模板。         |
