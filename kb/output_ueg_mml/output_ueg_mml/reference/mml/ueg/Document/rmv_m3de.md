# 删除M3UA目的实体(RMV M3DE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于从配置数据库中删除一条M3UA目的实体数据记录。

## 注意事项

- 如果命令执行成功，且删除的数据为已有性能统计任务中登记的对象实例，则该对象实例后续上报的指标值为0。命令涉及的测量单元有：M3UA目的实体测量；命令涉及的对象有：M3UA目的实体。
- 在正常情况下，该命令仅在开局时由开局工程师在数据调测的过程中使用。删除一个M3UA目的实体的步骤：**RMV M3LNK**-->**RMV M3LKS**-->**RMV M3DE**。

## 参数说明

| 参数标识   | 参数名称   | 参数描述                                                                                                   |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------|
| DENM   | 目的实体名称 | 标识一条M3UA目的实体数据记录的关键字段，用于指定需要删除哪一条M3UA目的实体数据记录，操作员可以使用LST M3DE命令查询获得。 取值范围: 长度不超过32的字符串。 默认值: 无。 说明: 无。 |

## 使用实例

1、删除M3UA目的实体，“目的实体名称”为“MODIFIED”：

```
RMV M3DE: DENM="MODIFIED";
```

2、删除M3UA目的实体，“目的实体名称”为“M3DE”：

```
RMV M3DE: DENM="M3DE";
```
