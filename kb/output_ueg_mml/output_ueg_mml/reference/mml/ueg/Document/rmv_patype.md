# 删除协议适配类型(RMV PATYPE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于删除各种协议类型的适配数据。

## 注意事项

- 该命令不允许进行批操作。
- 当前版本不支持此功能，执行该命令后会返回错误码：335607 暂不支持该功能。

## 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                                                                   |
|:---------------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MID            | 模块号      | PAU类型的模块号。该参数必须先由ADD MODULE命令定义，然后才能在此处索引。 取值范围：1～1023 默认值：无。 说明：必选参数。                                                                                                 |
| CS             | 客户端/服务器端 | 用于指定当前模块是做为客户端还是服务器端。 取值范围： “Client(客户端)”：指定模块为客户端。“Server(服务器)”：指定模块为服务器端。 默认值：无。 说明：必选参数。                                                                            |
| PROTTYPE       | 协议类型     | 仅当本命令中的参数“客户端/服务器端”取值为“Client(客户端)”时该参数有效。用于指定当前模块支持的协议类型。 取值范围： “HTTP(HTTP)”：超文本传输协议。“SMTP(SMTP)”：简单邮件传输协议。“SMPP(SMPP)”：短消息点对点传输协议。“SWP(SWP)”：滑动窗口协议。 默认值：无。 说明：必选参数。 |
| PROTTYPEFORSER | 协议类型     | 仅当本命令中的参数“客户端/服务器端”取值为“Server(服务器)”时该参数有效。用于指定当前模块支持的协议类型。 取值范围： “SMPP(SMPP)”：短消息点对点传输协议。“AUC(AUC)”：鉴权中心。 默认值：无。 说明：必选参数。                                              |

## 使用实例

删除SMTP类型的适配数据。PAU模块号22，客户端/服务器端为Client。

**RMV PATYPE: MID=22, CS=Client, PROTTYPE=SMTP;**

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。
