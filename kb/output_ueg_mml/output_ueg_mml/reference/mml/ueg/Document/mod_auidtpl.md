# 修改AUID模板(MOD AUIDTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于对配置数据库中的一个AUID（application unique ID ）模板配置信息进行修改。在该命令中，系统通过“索引”参数来唯一标识一个AUID模板配置信息。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

AUID模板内容发生改变后，引用该模板的AP转发规则的AUID匹配原则也会相应改变。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                           |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------|
| ID     | 索引     | 可选必选说明：必选参数 标识一个AUID模板配置信息的关键字段（其取值不能被修改）。用于指定需要对哪一个AUID模板的配置信息进行修改，操作员可以使用LST AUIDTPL命令查询获得。 默认值：无。           |
| AUID   | 应用区分标识 | 可选必选说明：可选参数 用于标识AP转发规则中要匹配的HTTP请求消息的业务请求类型。 取值范围：1～127位字符串。 默认值：无。 说明：该参数不区分大小写，在执行LST AUIDTPL命令查询出的报文中为全小写形式。 |

## 使用实例

修改一条“索引”为“1”的AUID模板数据记录，“应用区分标识”为“simservs.ngn.etsi.org”：

```
MOD AUIDTPL: ID=1, AUID="simservs.ngn.etsi.org";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释                                  | 原因分析                   | 处理建议                                                                            |
|-------:|:--------------------------------------|:-----------------------|:--------------------------------------------------------------------------------|
| 377902 | 指定的AUID已经存在。请执行LST AUIDTPL查询已存在的AUID。 | 输入的“应用区分标识”参数已存在。      | 根据实际情况，重新输入参数，确保输入的“应用区分标识”参数与系统中已存在的不重复。可执行LST AUIDTPL命令查询系统中已存在的“应用区分标识”参数记录。 |
| 377903 | 指定的ID不存在。请执行LST AUIDTPL查询已存在的ID。      | 输入的“索引”参数对应的AUID模板不存在。 | 根据实际情况，重新输入参数，确保输入的“索引”参数与系统中已存在的不重复。可执行LST AUIDTPL命令查询系统中已存在的“索引”参数记录。         |
