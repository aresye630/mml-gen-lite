# 设置iGWB IP地址配置信息(SET IGWBIP)

- 命令功能

## 命令功能

**说明** 

该命令功能暂不支持。

该命令用于在配置数据库中设置与EIR的PAU模块对接的ACM（归属于iGWB）模块的IP和端口数据。UDM与iGWB通信，为PAU模块设置接入的具体地址，保证UDM与iGWB之间的可靠合理连接。

## 注意事项

- 该命令因涉及修改网元IP和端口号，有可能对话单产生很大的影响，建议操作员在系统话务量少的时间段（例如凌晨2:00～4:00）执行该命令。
- 如操作员误修改了配置参数，请立即恢复正确的配置参数，或在华为公司技术服务人员的指导下恢复正确的配置数据。
- 当运营商融合部署时，需要设置与EIR的PAU模块连接的ACM（属于iGWB网元）模块的IP和端口，在设置ACM配置参数前，请操作员在iGWB网元下执行**MOD ACTRL**命令修改iGWB侧的IP地址和端口，然后执行本命令修改UDM侧的IP和端口，UDM侧和iGWB侧的数据配置必须一致。
- 如果命令执行成功，请操作员在iGWB网元下执行**DSP ACTRL**命令，查看ACM与对端网元链路状态，以确保链路的正常。
- 该命令只能配置一条数据记录。
- UDM在系统初始化的时候已经预置一条默认数据记录，可以使用**LST IGWBIP**命令查询系统初始设置值。

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                            |
|:----------|:---------|:----------------------------------------------------------------------------------------------------------------|
| IPTYPE    | IP地址类型   | 用于标识IP地址的类型。 取值范围：IPV4(IPV4版本)IPV6(IPV6版本) 默认值：无。 系统初始设置值：IPV4(IPV4版本)                                          |
| PIPV4ADDR | 主用IPV4地址 | 仅当本命令中的“IP地址类型”参数为“IPV4(IPV4版本)”时该参数有效。用于标识PAU模块连接的ACM模块主用IPV4地址。 取值范围：IPv4地址 默认值：无。 系统初始设置值：172.16.129.1       |
| PIPV6ADDR | 主用IPV6地址 | 仅当本命令中的“IP地址类型”参数为“IPV6(IPV6版本)”时该参数有效。用于标识PAU模块连接的ACM模块主用IPV6地址。 取值范围：IPv6地址 默认值：无。                            |
| PPORT     | 主用端口号    | 仅当本命令中的“IP地址类型”参数为“IPV4(IPV4版本)”或“IPV6(IPV6版本)”或时该参数有效。用于标识PAU模块连接的ACM模块主用端口号。 取值范围：0～65535 默认值：无。 系统初始设置值：8182 |
| SIPV4ADDR | 备用IPV4地址 | 仅当本命令中的“IP地址类型”参数为“IPV4(IPV4版本)”时该参数有效。用于标识EIR的PAU模块连接的ACM模块备用IPV4地址。 取值范围：IPv4地址 默认值：无。 系统初始设置值：172.17.129.1   |
| SIPV6ADDR | 备用IPV6地址 | 仅当本命令中的“IP地址类型”参数为“IPV6(IPV6版本)”时该参数有效。用于标识EIR的PAU模块连接的ACM模块备用IPV6地址。 取值范围：IPv6地址 默认值：无。                        |
| SPORT     | 备用端口号    | 仅当本命令中的“IP地址类型”参数为“IPV4(IPV4版本)”或“IPV6(IPV6版本)”时该参数有效。用于标识PAU模块连接的ACM模块备用端口号。 取值范围：0～65535 默认值：无。 系统初始设置值：8182  |

## 使用实例

设置iGWB IP地址配置信息，“IP地址类型”为“IPV4(IPV4版本)”，“主用IPV4地址”为“172.16.129.2”：

```
SET IGWBIP: IPTYPE=IPV4, PIPV4ADDR="172.16.129.2";
```

- 当UDM未配置PAU模块，该命令执行正常，会返回命令执行成功的提示信息。

  ```
  %%SET IGWBIP: IPTYPE=IPV4, PIPV4ADDR="172.16.129.2";%%
  RETCODE = 0  操作成功

  ---    END
  ```
- 当UDM已配置PAU模块，该命令执行正常，会返回命令执行成功的提示信息和相关参数。

  ```
  %%SET IGWBIP: IPTYPE=IPV4, PIPV4ADDR="172.16.129.2";%%
  RETCODE = 0  操作成功

  虚拟机联机设置结果
  ------------------
        网元ID  =  211
        模块号  =  222
    虚拟机名称  =  UEIR_167_ZL_211_UEIRFEU_VDU1_0
      位置描述  =  D5921602-5748-7783-E811-25D1D092789D
     主/备状态  =  主用
  设定结果描述  =  操作成功
  (结果个数 = 1)

  ---    END
  ```

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义如表1所示。

| 输出项名称   | 输出项解释                       |
|:--------|:----------------------------|
| 网元ID    | 用于返回PAU模块所在的网元ID。           |
| 模块号     | 用于返回PAU模块的模块号。              |
| 虚拟机名称   | 用于返回PAU模块所在虚拟机（裸机POD）的名称。   |
| 位置描述    | 用于返回PAU模块所在虚拟机（裸机POD）的位置描述。 |
| 主/备状态   | 用于返回PAU模块的主/备状态。            |
| 设定结果描述  | 用于返回命令执行的结果描述。              |

| 335889 | 输入参数不完整         | 本次输入的“IP地址类型”参数与执行LST IGWBIP显示的“IP地址类型”输出项不一致时，未输入全部参数。               | 本次输入的“IP地址类型”参数与LST IGWBIP显示的“IP地址类型”输出项不一致时，需要输入以下任一组参数。主用IPV4地址、主用端口号、备用IPV4地址、备用端口号主用IPV6地址、主用端口号、备用IPV6地址、备用端口号 |
