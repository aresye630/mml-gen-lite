# 查询鉴权向量下发策略(LST AUTHVECCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询鉴权向量下发策略。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                        |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------|
| CFGNAME | 策略名称   | 用于在本局的配置数据库中唯一标识一条鉴权向量下发策略数据。 取值范围：长度不超过32位的字符串 默认值：无。 说明： 字符串只允许输入：0-9，a-z，A-Z，“-”、“_”、“.”、空格符、和中文字符。可选参数。 |

## 使用实例

查询鉴权向量下发策略：

```
LST AUTHVECCFG:;
```

```
%%LST AUTHVECCFG:;%%
RETCODE = 0  操作成功

查询结果如下
------------
策略名称     地址类型     信令点       GT        控制VLR/SGSN请求鉴权五元组时HLR下发鉴权五元组的组数                                                  
 name5        GT           NULL        868193     2   
 name2        信令点       000022      NULL       0 
(结果个数 = 2)

---    END
```
