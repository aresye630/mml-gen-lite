# 查询外部BSF设备的配置信息(LST SLFBSF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询SLF的BSF设备的配置信息：

- 若需要查询全部BSF数据记录的信息，请不要输入任何参数。
- 若需要查询某条BSF数据记录的详细信息，请输入“BSF名称”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                          |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SLFN   | SLF名称  | 用于标识在配置数据库中查询SLF的BSF设备配置信息的SLF名称。 取值范围：1～127位的字符串，字符串类型包括：数字“0～9”、大小写字母、特殊字符“-”、“_”、“.”、空格符及中文字符等。 默认值：无。                                                                                                                                                                                                                                                                     |
| BSFN   | BSF名称  | 用于标识在配置数据库中查询SLF的BSF设备配置信息的BSF名称。 取值范围：1～127位的字符串，字符串类型包括：数字“0～9”、大小写字母、特殊字符“-”、“_”、“.”、空格符及中文字符等。 默认值：无。                                                                                                                                                                                                                                                                     |
| HN     | 主机名    | 用于标识在配置数据库中查询SLF的BSF设备配置信息的主机名称。 取值范围：1～127位字母或字母与数字（字母在前）组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                      |
| LNKMOD | 链路选择模式 | 用于标识在配置数据库中查询SLF的BSF设备配置信息的链路选择模式。 取值范围： SESSIONIDBASED(基于会话ID)：同一个会话的所有信令消息都在同一条链路上传输。多个会话的消息按照轮选的方式在多条链路负荷分担。 POLLING(轮询方式)：当配置多条链路，信令消息在每条链路上负荷分担。 AORS(主备方式)：在主备链路选择方式下，如果主链路故障，则将某条备用链路升为主链路。默认第0条链路为主链路，当第0条链路不可用时，会自动选择其他可用链路。 ACTIVE(激活方式)：根据链路的激活状态，从第0条开始选择第一条激活的链路，将信令消息发往该链路。 ACTIVEWITHPRI(基于优先级的激活方式)：基于优先级的激活方式。 POLLINGWITHPRI(基于优先级的轮询方式)：基于优先级的轮询方式。 默认值：无。 |

## 使用实例

1. 查询SLF所有BSF的配置信息：

   ```
   LST SLFBSF:;
   ```

   ```
   %%LST SLFBSF:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    SLF名称  BSF名称  主机名           链路选择模式  SLF索引  BSF索引

    SLF      BSF1     bsf1.huawei.com  轮询方式      0        3      
    SLF      BSF2     bsf2.huawei.com  激活方式      0        4      
   (结果个数 = 2)

   ---    END
   ```
2. 查询SLF某个BSF的配置信息，“BSF名称”为“BSF2”：

   ```
   LST SLFBSF: BSFN="BSF2";
   ```

   ```
   %%LST SLFBSF: BSFN="BSF2";%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
        SLF名称  =  SLF
        BSF名称  =  BSF2
         主机名  =  bsf2.huawei.com
   链路选择模式  =  激活方式
        SLF索引  =  0
        BSF索引  =  4
   (结果个数 = 1)

   ---    END
   ```
