# 修改非3GPP信任关系(MOD NON3GPPTRS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中修改一条非3GPP信任关系。在该命令中，系统通过“标识”参数来唯一标识一条非3GPP信任关系信息数据记录。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

- 操作员随意执行该命令，会导致终端用户（UE）认证流程发生变化，造成认证失败，因此，请谨慎操作。
- UIM系统不允许存在“接入类型”和“对端主机名”都相同的记录，请操作员修改前做好数据准备。

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|:--------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ID      | 标识      | 标识一条非3GPP信任关系数据记录的关键参数（其取值不能被修改），用于指定需要对哪一条非3GPP信任关系的记录进行修改或调整。操作员可以使用LST NON3GPPTRS操作查询获得。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| RATTYPE | 接入类型    | 用于指定用户终端（UE）的无线接入技术类型。 取值范围：WLAN(WLAN)：表示RAT的类型为WLAN。VIRTUAL(VIRTUAL)：表示RAT的类型为其他未知类型，详见3GPP TS 29.274。UTRAN(UTRAN)：表示RAT的类型为UTRAN，详见3GPP TS 29.060。GERAN(GERAN)：表示RAT的类型为GERAN，详见3GPP TS 29.060。GAN(GAN)：表示RAT的类型为GAN，详见3GPP TS 29.060和3GPP TS 43.318。HSPA_EVOLUTION(HSPA_EVOLUTION)：表示RAT的类型为HSPA Evolution，详见3GPP TS 29.060。EUTRAN(EUTRAN)：表示RAT的类型为EUTRAN，详见3GPP TS 29.274。CDMA2000_1X(CDMA2000_1X)：表示RAT的类型为CDMA2000 1X，详见3GPP2 X.S001。HRPD(HRPD)：表示RAT的类型为HRPD，详见3GPP2 X.S0011。UMB(UMB)：表示RAT的类型为UMB，详见3GPP2 X.S0011。EHRPD(EHRPD)：表示RAT的类型为eHRPD，详见3GPP2 X.S0057。 默认值：无。 |
| HOSTE   | 对端主机名存在 | 用于指定是否对“对端主机名”修改。 取值范围：FALSE(FALSE)TRUE(TRUE) 默认值：无。 说明：若该参数取值为“FALSE(FALSE)”，则表示将已有记录的对端主机名设置为空。                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| HOST    | 对端主机名   | 仅当本命令中的“对端主机名存在”参数设置为“TRUE(TRUE)”时，该参数才需要设置。用于指定配置Non-3GPP信任关系的对端源主机名。 取值范围：长度不超过127的字符串。 默认值：无。 说明：该参数统一存储为小写字母，支持后向最大匹配。例如：配置了主机名es.huawei.com以及sz.es.huawei.com，用户消息携带的对端主机名为bantian.sz.es.huawei.com，则最大匹配符合sz.es.huawei.com。                                                                                                                                                                                                                                                                                                                                              |
| REL     | 信任关系    | 用于指定用户终端（UE）与对端源主机的信任关系。 取值范围：UNTRUSTED(UNTRUSTED)：非可信接入。TRUSTED(TRUSTED)：可信接入。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

## 使用实例

修改一个非3GPP信任关系配置信息，携带参数如下：

- “标识”为“6”
- “接入类型”为“WLAN(WLAN)”
- “对端主机名存在”为“TRUE(TRUE)”
- “对端主机名”为“es.huawei.com”
- “信任关系”为“TRUSTED(TRUSTED)”

执行命令如下：

```
MOD NON3GPPTRS: ID=6, RATTYPE=WLAN, HOSTE=TRUE, HOST="es.huawei.com", REL=TRUSTED;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释            | 原因分析                                 | 处理建议                                                                  |
|-------:|:----------------|:-------------------------------------|:----------------------------------------------------------------------|
| 377918 | 接入类型、对端主机名不能重复。 | “接入类型”参数和“对端主机名”所指定的非3GPP信任关系记录已经存在。 | 使用LST NON3GPPTRS命令查询已经存在的记录，确保重新输入的“接入类型”参数和“对端主机名”参数所指定的记录与已存在记录不重复。 |
| 377920 | 指定的ID不存在。       | “标识”参数指定的非3GPP信任记录不存在。               | 使用LST NON3GPPTRS命令查询后，重新输入“标识”。                                       |
