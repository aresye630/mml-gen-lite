# 增加协议适配类型(ADD PATYPE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于增加各种协议类型的适配数据。

## 注意事项

- 执行此命令之前，必须先添加PAU类型的模块和PAU类型对应的本地IP信息。
- 当CS为Client并且PROTTYPE等于SWP时，界面输入参数REMOTEIPV4，REMOTEIPV6，REMOTEPORT，APMID，BAKIPV4，BAKIPV6，BAKPORT需要与iGWB网元下执行的**LST APINFO**命令的查询结果中返回值对应。
- 当CS等于Client时，PROTTYPE合法值为HTTP，SMTP，SMPP和SWP，其他取值非法；当CS等于Server时，PROTTYPE合法值为SMPP和AUC，其他取值非法。
- 当前版本不支持此功能，执行该命令后会返回错误码：335607 暂不支持该功能。

## 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                                                                                                                         |
|:---------------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MID            | 模块号      | PAU类型的模块号。该参数必须先由ADD MODULE命令定义，然后才能在此处索引。取值范围：1～1023 默认值：无。 说明：必选参数。                                                                                                                                                        |
| CS             | 客户端/服务器端 | 用于指定当前模块是做为客户端还是服务器端。 取值范围： “Client(客户端)”：指定模块为客户端。“Server(服务器)”：指定模块为服务器端。 默认值：无。 说明：必选参数。                                                                                                                                  |
| PROTTYPE       | 协议类型     | 仅当本命令中的参数“客户端/服务器端”取值为“Client”时该参数有效。用于指定当前模块支持的协议类型。 取值范围： “HTTP(HTTP)”：超文本传输协议。“SMTP(SMTP)”：简单邮件传输协议。“SMPP(SMPP)”：短消息点对点传输协议。“SWP(SWP)”：滑动窗口协议。 默认值：无。 说明：必选参数。                                                            |
| IPVER          | IP版本     | 仅当本命令中的参数“客户端/服务器端”取值为“Client”且“协议类型”取值为“HTTP”、“SMTP”时该参数有效。用于指定IP地址的类型。 取值范围： “IPV4(IPV4版本)”：配置IPV4类型IP地址时使用。 “IPV6(IPV6版本)”：配置IPV6类型IP地址时使用。 默认值：IPV4(IPV4版本)。                                                             |
| IPVERFORSMPP   | IP版本     | 仅当本命令中的参数“客户端/服务器端”取值为“Client”且“协议类型”取值为“SMPP”时该参数有效。用于指定IP地址的类型。 取值范围： “IPV4(IPV4版本)”：配置IPV4类型IP地址时使用。 “IPV6(IPV6版本)”：配置IPV6类型IP地址时使用。 默认值：IPV4(IPV4版本)。                                                                    |
| IPVERFORSWP    | IP版本     | 仅当本命令中的参数“客户端/服务器端”取值为“Client”且“协议类型”为“SWP”时该参数有效。用于指定IP地址的类型。 取值范围： “IPV4(IPV4版本)”：配置IPV4类型IP地址时使用。 “IPV6(IPV6版本)”：配置IPV6类型IP地址时使用。 默认值：IPV4(IPV4版本)。                                                                       |
| PROTTYPEFORSER | 协议类型     | 仅当本命令中的参数“客户端/服务器端”取值为“Server(服务器)”时该参数有效。用于指定当前模块支持的协议类型。 取值范围： “SMPP(SMPP)”：短消息点对点传输协议。“AUC(AUC)”：鉴权中心。 默认值：无。 说明：必选参数。                                                                                                    |
| IPVERFORSER    | IP版本     | 仅当本命令中的参数“客户端/服务器端”取值为“Server(服务器)”时该参数有效。用于指定IP地址的类型。 取值范围： “IPV4(IPV4版本)”：配置IPV4类型IP地址时使用。 “IPV6(IPV6版本)”：配置IPV6类型IP地址时使用。 默认值：IPV4(IPV4版本)。                                                                               |
| LOCALIPV4      | 本端IPV4地址 | 仅当本命令中的参数“协议类型”取值为“HTTP”、“SMTP”、“SMPP”、“AUC”且“IP版本”取值为“IPV4(IPV4版本)”时该参数有效。用于指定本端IP地址。 取值范围：IPV4类型的IP地址。 默认值：无。                                                                                                              |
| LOCALIPV6      | 本端IPV6地址 | 仅当本命令中的参数“协议类型”取值为“HTTP”、“SMTP”、“SMPP”、“AUC”且“IP版本”取值为“IPV6(IPV6版本)”时该参数有效。用于指定本端IP地址。 取值范围：IPV6类型的IP地址。 默认值：无。                                                                                                              |
| LOCALPORT      | 本端端口号    | 仅当本命令中的参数“协议类型”取值为“HTTP”、“SMTP”、“SMPP”、“AUC”时该参数有效。用于指定本端端口。 取值范围：0～39999 默认值：无。                                                                                                                                             |
| REMOTEIPV4     | 远端IPV4地址 | 仅当本命令中的参数“客户端/服务器端”取值为“Client”且“IP版本”取值为“IPV4(IPV4版本)”时该参数有效。用于指定远端IP地址。 取值范围：IPV4类型的IP地址。 默认值：无。                                                                                                                            |
| REMOTEIPV6     | 远端IPV6地址 | 仅当本命令中的参数“客户端/服务器端”取值为“Client”且“IP版本”取值为“IPV6(IPV6版本)”时该参数有效。用于指定远端IP地址。 取值范围：IPV6类型的IP地址。 默认值：无。                                                                                                                            |
| REMOTEPORT     | 远端端口号    | 仅当本命令中的参数“客户端/服务器端”取值为“Client”时该参数有效。用于指定远端端口。 取值范围：1～65535 默认值：无。                                                                                                                                                           |
| APMID          | AP模块号    | 仅当本命令中的参数“协议类型”取值为“SWP”时该参数有效。用于指定iGWB的AP模块号。该参数必须与iGWB网元下执行的LST APINFO命令的结果中的AP模块号一致。 取值范围：1804～1904。 默认值：无。                                                                                                                |
| BAKIPV4        | 备份IPV4地址 | 仅当本命令中的参数“协议类型”取值为“SWP”且“IP版本”取值为“IPV4(IPV4版本)”时该参数有效。用于指定链接iGWB的AP的备份IP地址。 取值范围：IPV4类型的IP地址。 默认值：无。                                                                                                                         |
| BAKIPV6        | 备份IPV6地址 | 仅当本命令中的参数“协议类型”取值为“SWP”且“IP版本”取值为“IPV6(IPV6版本)”时该参数有效。用于指定链接iGWB的AP的备份IP地址。 取值范围：IPV6类型的IP地址。 默认值：无。                                                                                                                         |
| BAKPORT        | 备份端口号    | 仅当本命令中的参数“协议类型”取值为“SWP”时该参数有效。用于指定链接iGWB的AP的备份端口号。 取值范围：1～65535 默认值：无。                                                                                                                                                       |
| USERNAME       | 用户名      | 仅当本命令中的参数“协议类型”取值为“SMPP”时该参数有效。用于指定用户名。 取值范围：1～15字符串 默认值：无。 说明：“客户端/服务器端”取值为“Client”时，该参数为必选参数。当“客户端/服务器端”取值为“Server”时，无需在此命令中输入“用户名”，应通过ADD SMSCLISUB命令配置相应的“用户名”和“密码”。                                                     |
| USERPWD        | 密码       | 仅当本命令中的参数“协议类型”取值为“SMPP”时该参数有效。用于标识用户密码。 取值范围：1～8位字符串。 默认值：无。 说明：当“客户端/服务器端”取值为“Client”时，该参数为必选参数。当“客户端/服务器端”取值为“Server”时，无需在此命令中输入“密码”，应通过ADD SMSCLISUB命令配置相应的“用户名”和“密码”。为了提高密码安全性，建议将该参数设置为6位以上字符串，并至少包含大小写字母、数字和特殊字符中的两种。 |
| INTERVAL       | 心跳间隔     | 仅当本命令中的参数“协议类型”取值为“SMPP”且“客户端/服务器端”取值为“Client”时该参数有效。用于指定心跳间隔。 取值范围：1～100，单位：秒 默认值：无。                                                                                                                                        |

## 使用实例

增加SMTP类型的适配数据。PAU模块号22，客户端/服务器端为Client，协议类型为SMTP，IP版本为IPV4，LOCALIPV4:172.16.144.255，LOCALPORT:1010，REMOTEIPV4:172.16.145.255，REMOTEPORT:1010。

**ADD PATYPE: MID=22, CS=Client, PROTTYPE=SMTP, IPVER=IPV4, LOCALIPV4="172.16.144.255", LOCALPORT=1010, REMOTEIPV4="172.16.145.255", REMOTEPORT=1010;**

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。
