# 激活M3UA目的实体(ACT M3DE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为维护类命令，用于请求系统对处于去激活状态的M3UA目的实体执行激活操作。

该命令的操作场景一般为：当操作员使用**DSP M3DE**命令查询某M3UA目的实体的状态时，发现其“状态”为“去激活”，例如操作员使用DEA M3DE命令对某M3UA目的实体执行了去激活操作。

## 注意事项

- 仅当被操作的M3UA目的实体的状态为“去激活”时，操作员才能使用该命令。
- 如果被操作的M3UA目的实体处于“不可达”状态，则操作员不能使用该命令使目的实体处于“可达”状态。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                        |
|:-------|:-------|:------------------------------------------------------------|
| DENM   | 目的实体名称 | 标识某个M3UA目的实体的关键字段，用于指示系统激活哪个M3UA目的实体，操作员可以使用LST M3DE命令查询获得。 |

## 使用实例

激活M3UA目的实体，“目的实体名称”为“DE\_LXT”：

```
ACT M3DE: DENM="DE_LXT";
```
