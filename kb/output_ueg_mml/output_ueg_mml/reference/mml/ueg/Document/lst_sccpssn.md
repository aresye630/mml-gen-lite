# 查询SCCP子系统(LST SCCPSSN)

- 命令功能
- 注意事项

## 命令功能

该命令为配置类命令，用于在配置数据库中查询SCCP子系统数据的配置信息：

- 若需要查询全部SCCP子系统数据记录的概要信息，请不要输入任何参数。
- 若需要查询某条SCCP子系统数据记录的详细信息，请输入相关参数或参数组合。
- 若需要指定查询结果以哪种排序方式显示，请输入“新排序方式”参数。

该命令的“SSN名称”参数支持模糊查询功能。模糊查询功能是指操作员在客户端输入查询参数时，对于字符串或BCD码类型的查询参数而言，如果操作员输入的是一个完整的字符串或BCD码，则表示系统将按照完全匹配的方式执行查询操作；如果操作员在输入的某个字符串或BCD码的末尾添加通配字符“%”，则表示系统将按照模糊匹配的方式执行查询操作。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SSNNM   | SSN名称  | 用于指示系统需要按照哪个SCCP子系统名称来查询SCCP子系统数据；若不输入，则表示所有的SCCP子系统名称。 取值范围：长度不超过32的字符串。 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| NI      | 网络指示   | 用于指示系统需要按照哪个网络指示来查询SCCP子系统数据；若不输入，则表示所有的网络指示。 取值范围： “INT(国际主用网)”“INTB(国际备用网)”“NAT(国内主用网)”“NATB(国内备用网)” 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| SSN     | SSN    | 用于指示系统需要按照哪个SCCP子系统号来查询SCCP子系统数据；若不输入，则表示所有的SCCP子系统号。 取值范围： “UNDEF(未定义)”“SCMG(SCMG 0x01)”“RESERVED(保留 0x02)”“ISUP(ISUP 0x03)”“OMAP(OMAP 0x04)”“MAP(MAP 0x05)”“HLR(HLR 0x06)”“VLR(VLR 0x07)”“MSC(MSC 0x08)”“EIR(EIR 0x09)”“AUC(AUC 0x0A)”“MC(MC 0x0B)”“OTAF(OTAF 0x0C)”“SCP(SCP 0x0E)”“GMLC(GMLC 0x91)”“CAP(CAP 0x92)”“GSMSCF(GSM SCF 0x93)”“SGSN(SGSN 0x95)”“GGSN(GGSN 0x96)”“MPC(MPC 0xFA)”“GS(GS 0xFC)”“BSSAP/INAP(BSSAP/INAP 0xFE)”“SSN13(子系统号13)”“SSN15(子系统号15)”～“SSN144(子系统号144)”“SSN148(子系统号148)”“SSN151(子系统号151)”～“SSN249(子系统号249)”“SSN251(子系统号251)”“SSN253(子系统号253)” 默认值：无。 说明：无。 |
| SPC     | 信令点编码  | 用于指示系统需要按照哪个信令点编码来查询SCCP子系统数据；若不输入，则表示所有的信令点编码。 取值范围：长度不超过11的字符串。 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| OPC     | 源信令点编码 | 用于指示系统需要按照哪个源信令点编码来查询SCCP子系统数据；若不输入，则表示所有的源信令点编码。 取值范围：长度不超过11的字符串。 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| NEWSORT | 新排序方式  | 用于指示查询结果是否启用新的排序方式显示。 取值范围：NO(否)：以“SSN名称”参数值的升序排序。YES(是)：依次以“信令点编码”、“源信令点编码”、“SSN”、“SSN名称”参数值的升序排序。 默认值：NO(否)。                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
