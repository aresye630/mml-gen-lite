# 自动迁移diameter链路(MIG DMLNK)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于迁移Diameter链路，实现扩缩容场景触发Diameter链路迁移以达到Diameter链路数量均衡，从而通过Diameter链路数量的均衡实现Diameter链路均衡。

## 注意事项

- 在执行以下操作重新均衡分配链路的过程中，会导致链路中断，可能会上报“ALM-13021 Diameter链路故障”告警。
  - 扩容场景通过新增UISU类型Pod支持更大的业务流量，增加新的UISU类型Pod后可以执行该命令，操作员无需输入参数，系统会自动选择扩容的UISU类型Pod将Diameter链路移到新的UISU类型Pod上。
  - 缩容场景通过删除UISU类型Pod的方式来节省信令流量的处理能力，由于待删除UISU类型Pod上面仍然有链路，需要执行该命令，操作员需要同时输入两个参数选择待删除的UISU类型不同平面的一对Pod，先把UISU类型Pod上的链路迁移到其他Pod再进行模块隔离，然后进行删除模块和Pod等操作。

- 该命令只能迁移弹性链路，是否弹性链路可以执行**LST DMLNK**命令查询。
- 该命令只支持UISU类型Pod的链路迁移。
- 该命令不允许进行批操作。
- 缩容场景下，执行该命令迁移链路时，需要输入UISU类型不同平面的一对Pod。
  - 输入“迁移POD1”和“迁移POD2”参数不能是同一个平面的同一个Pod。
  - 输入“迁移POD1”和“迁移POD2”参数不能是同一个平面的不同Pod。
  - 当系统只存在一对Pod时，不允许执行该命令。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                             |
|:------------|:-------|:---------------------------------------------------------------------------------|
| MIGPODNAME1 | 迁移POD1 | 用于标识待迁移Diameter链路的源Pod名称1。可以执行LST PODINFO命令查询UDM已部署的Pod。 取值范围：1～128位的字符串。 默认值：无。 |
| MIGPODNAME2 | 迁移POD2 | 用于标识待迁移Diameter链路的源Pod名称2。可以执行LST PODINFO命令查询UDM已部署的Pod。 取值范围：1～128位的字符串。 默认值：无。 |

## 使用实例

1. 迁移Diameter链路，“迁移POD1”为“uisu-a-pod100-1”，“迁移POD2”为“uisu-b-pod100-1”：

   ```
   MIG DMLNK: MIGPODNAME1="uisu-a-pod100-1", MIGPODNAME2="uisu-b-pod100-1";
   ```
2. 迁移Diameter链路，不输入参数：

   ```
   MIG DMLNK: ;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释                | 原因分析          | 处理建议             |
|-------:|:--------------------|:--------------|:-----------------|
| 336078 | 当前有迁移任务正在执行，请稍后再执行。 | 当前有主机侧触发迁移任务。 | 等待当前迁移任务结束后再做处理。 |
