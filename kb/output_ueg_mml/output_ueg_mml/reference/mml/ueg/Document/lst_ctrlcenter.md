# 查询控制中心(LST CTRLCENTER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询FE&BE容灾自动倒换控制中心所在的CCU/ACF模块号。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                           |
|:---------|:-------|:-------------------------------------------------------------------------------|
| CTRLTYPE | 控制中心类型 | 此参数用于标识控制中心的类型。 取值范围： SiteSwitchover(SiteSwitchover)：标识FE&BE容灾自动倒换控制中心。 默认值：无。 |

## 使用实例

查询所有控制中心：

```
LST CTRLCENTER: CTRLTYPE=SiteSwitchover;
```

```
%%LST CTRLCENTER: CTRLTYPE=SiteSwitchover;%%
RETCODE = 0  操作成功

操作结果如下
------------
 控制中心类型 = SiteSwitchover
       模块号 = 62     
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**MOD CTRLCENTER**命令的参数说明。
