# 查询软件参数(LST MSFP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在配置数据库中查询软件参数的配置信息：

- 若需要查询全部软件参数数据记录的概要信息，请不要输入任何参数。
- 若需要查询某个软件参数数据记录的概要信息，请输入需要查询的“参数”参数。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                   |
|:-------|:-------|:---------------------------------------|
| ID     | 参数     | 用于指示系统需要按照哪个参数来查询软件参数数据；若不输入，则表示所有的参数。 |

## 使用实例

查询软件参数，“参数”为“50”：

```
LST MSFP: ID=P50;
```

返回结果如下：

```
%%LST MSFP: ID=P50;%%
RETCODE = 0  操作成功

参数ID
------
            参数  =  50
        参数名称  =  TCAP主叫轮选设置
          参数值  =  0000 ( 0000 0000 0000 0000 )
      参数默认值  =  0000 ( 0000 0000 0000 0000 )
是否和默认值相等  =  是
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称    | 输出结果解释                  |
|:---------|:------------------------|
| 参数       | 表示软参标识。                 |
| 参数名称     | 表示软参名称。                 |
| 参数值      | 表示软参值，括号里是按位显示的值。       |
| 参数默认值    | 表示软件参数的默认值，括号里是按位显示的值。  |
| 是否和默认值相等 | 表示当前软件参数取值是否和软件参数默认值相等。 |
