# 修改随机密钥(MOD OMRANDOMKEY)

## 命令功能

**须知** 

- 本命令属于高危命令，执行本命令会替换系统默认的加密密钥，执行不当会造成系统默认加密密钥被非预期替换。因此执行该命令前，需要与华为技术支持确认后才可以实施。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于修改默认随机密钥，将指定密钥ID的随机密钥设置为默认密钥。在该命令中，系统通过“密钥ID”参数来唯一标识一条随机密钥数据记录。

## 注意事项

- 系统同时只允许存在一条默认记录。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                   |
|:-------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------|
| KEYID  | 密钥ID    | 可选必选说明：必选参数 参数含义：标识随机密钥数据记录的关键字段（其取值不能被修改），用于标识密钥ID。 取值范围：1～3000 默认值：无。 配置原则：无                                                         |
| ISDEF  | 是否为默认密钥 | 可选必选说明：必选参数 参数含义：用于标识是否是默认密钥。 取值范围：TRUE(是)：执行命令时UDM会将已有默认密钥设置为非默认，将该参数对应的密钥设置为默认密钥。FALSE(否)：不允许选择该取值，执行命令选择该取值，系统会返回错误。 默认值：无。 配置原则：无。 |

## 使用实例

执行命令修改随机密钥数据记录，“密钥ID”为“2”，“是否为默认密钥”为“TRUE(是)”。

```
MOD OMRANDOMKEY: KEYID=2, ISDEF=TRUE;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                          | 原因分析                              | 处理建议                                               |
|-------:|:-----------------------------------------------|:----------------------------------|:---------------------------------------------------|
| 335951 | 随机密钥记录不存在                                      | “密钥ID”参数对应ID的随机密钥记录不存在。           | 使用LST OMRANDOMKEY命令查询后，重新确认要修改哪个“密钥ID”对应的随机密钥数据记录。 |
| 335954 | 执行MOD OMRANDOMKEY命令修改KEYID时，参数ISDEF取值不允许为false | 执行该命令不允许携带“是否为默认密钥”参数为“FALSE(否)”。 | 执行该命令携带“是否为默认密钥”参数时，该值必须为“TRUE(是)”。                |
