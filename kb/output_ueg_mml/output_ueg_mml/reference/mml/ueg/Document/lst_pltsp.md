# 查询平台软件参数 (LST PLTSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询平台软参的配置信息。

## 注意事项

无。

## 参数说明

| 参数ID   | 参数名称     | 参数描述                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
|:-------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MT     | 模块类型     | 此参数用于指定平台软件参数作用在哪一种类型模块。 取值范围：DPU(DPU)DSG(DSG)BSG(BSG)CCU(CCU)PAU(PAU)HSF(HSF)NSF(NSF)ACF(ACF)ERU(ERU)APF(APF) 缺省值：无。 说明：该参数是可选参数。“ACF(ACF)”和“APF(APF)”模块仅在虚机场景下支持。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| PLTSPN | 平台软件参数名称 | 此参数用于标识数据库中定义的各个平台软参的参数名。 取值范围：MEMDOPRAPTSIZE(DOPRA内存容量)。DOPRA预先申请内存，用于DOPRA平台本身的内存申请以及内存数据库的内存申请。调低这个参数值，会造成DRU或者DSU节点加载失败。调高这个参数值，会造成系统内存使用率上升，影响稳定性；也有可能因为无法向操作系统申请到足够的内存而造成进程无法启动。MEMUSERPTSIZE(USER内存容量)。DOPRA平台内部使用，减小该软参值有可能会造成进程初始化失败。增大该软参值会造成Pod内存使用率上升，影响稳定性。MEMEXTRAPTSIZE(EXTRA内存容量)。DOPRA平台内部使用，减小该软参值有可能造成进程初始化失败。增大该软参值，会造成Pod内存使用率上升，影响稳定性。MEMRESERVEDSIZE(黑匣子预留容量)。当进程重启时，会生成黑匣子文件，用于问题定位。黑匣子文件主要保存进程重启前的堆栈信息、正在处理的消息信息和资源信息等。在进程重启前，这些信息保存在内存中。调低该参数值，会造成一些信息无法记录下来。调高该参数值，可以保存更多的信息，但会降低性能，并且造成Pod内存使用率上升，影响稳定性。目前预留容量已经满足要求。BOXHIGHMEMSIZE(黑匣子高优先级区容量)。一般来说，黑匣子中部分内容对问题定位有着关键作用，例如堆栈信息、处理时长过长的消息等。这部分内容保存在高优先级区。提高高优先级区容量，可以记录更多的关键信息，但会造成信息不全面。BOXLOWMEMSIZE(黑匣子低优先级区容量)。黑匣子中部分内容对问题定位有着次要作用，例如正常处理的消息等。这部分内容保存在低优先级区。提高低优先级区容量可以记录更多的信息，但是可能会减少关键信息的记录，影响问题定位。减小低优先级区容量可以记录更多的关键信息，但会造成信息不全面。MAXSYSMSGUNIT(系统消息区消息单元数)。在DOPRA平台下，一部分消息属于系统内部消息，如进程内部的心跳等。增加该参数值，会造成Pod内存使用率上升，影响稳定性。降低该参数值，可能会导致消息分配失败，造成进程状态异常。MAXMSGUNIT(用户消息区消息单元数)。在DROP平台下，业务进程之间发送的消息是用户消息。增加该参数值，会造成Pod内存使用率上升，影响稳定性。降低该参数值，可能会导致消息分配失败，引起业务失败。MAXSYSMSGS(最大消息包数)。DRPRA平台中最多可以缓存的消息包个数。增大该参数值，可以提高系统的吞吐量，但也会造成Pod内存使用率上升，影响稳定性。减小该软数值，可能会造成消息失败。MAXRELTIMERS(最大相对定时器数)。DOPRA平台中最多可以申请的相对定时器个数。减小该参数值，会造成定时器申请失败，影响业务。增大该参数值，会造成Pod内存使用率上升。DBLOGBUFFERLEN(DB日志缓冲区大小)。运行过程中的错误日志先记录在缓冲区，然后上报到OMU客户端。增大缓冲区，会缓存更多的日志，但如果进程异常重启，会丢失更多的日志，同时也会造成Pod内存使用率上升，影响稳定性。减小缓冲区可以保证日志及量及时地记录，但会提高磁盘的访问，降低性能。 缺省值：无。 说明：该参数是可选参数。 |
| PLTSPV | 平台软件参数值  | 此参数用于在配置数据库中定义各个平台软参的参数值。 取值范围：0～2147483647。 说明：该参数是可选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| PTYPE  | 参数值标识    | 用于标识平台软件参数的值是否被修改。 取值范围：ALL(所有软参)：所有的参数。MODIFIED(被修改的软参)：参数值被修改，与其默认值不一致。UNMODIFIED(没有被修改的软参)：参数值未被修改，与其默认值一致。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |

## 使用实例

查询DSG模块DOPRA内存大小。

```
LST PLTSP: MT=DSG, PLTSPN=MEMDOPRAPTSIZE;
```

```
%%LST PLTSP: MT=DSG, PLTSPN=MEMDOPRAPTSIZE;%%
RETCODE = 0  操作成功

操作结果如下
------------
        模块类型  =  DSG
平台软件参数名称  =  DOPRA内存容量
  平台软件参数值  =  134217728
      参数默认值  =  134217728
      参数值标识  =  没有被修改的软参
(结果个数 = 1)

---    END
```
