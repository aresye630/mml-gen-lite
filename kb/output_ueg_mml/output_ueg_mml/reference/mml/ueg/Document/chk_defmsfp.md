# 校验软件参数默认值(CHK DEFMSFP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于在配置数据库中查询当前值和默认值不一致的软件参数的配置信息。

该命令的操作场景一般为：操作员通过该命令校验当前的后台数据，当软参当前值和软参默认值有差异时，操作员可以对有差异的软参进行分析，并根据结果判断软参是否存在错误。

## 注意事项

无。

## 参数说明

无。

## 使用实例

校验软件参数默认值：

```
CHK DEFMSFP:;
```

返回结果如下：

```
%%CHK DEFMSFP:;%%
RETCODE = 0  操作成功

软件参数校验
------------
          参数ID  =  50
        参数名称  =  TCAP主叫轮选设置
          参数值  =  0001  ( 0000 0000 0000 0001 )
      参数默认值  =  0000  ( 0000 0000 0000 0000 )
是否和默认值相等  =  否
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1。

| 输出项名称    | 输出结果解释                  |
|:---------|:------------------------|
| 参数ID     | 表示软件参数的标识。              |
| 参数名称     | 表示软件参数的名称。              |
| 参数值      | 表示当前软件参数的取值，括号里是按位显示的值。 |
| 参数默认值    | 表示软件参数的默认值，括号里是按位显示的值。  |
| 是否和默认值相等 | 表示当前软件参数取值是否和软件参数默认值相等。 |
