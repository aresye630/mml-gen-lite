# 增加远端网元IP地址(ADD RIPADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于配置远端网元IP地址，用于本端网元和远端USCDB或者远端FE网元链路互通。

## 注意事项

- 当配置BE间的容灾环境时，远端DPU业务类型必须配置为远端对应的业务类型，而不能配置成USCDB类型。
- UDM不支持该命令。

## 参数说明

| 参数标识    | 参数名称               | 参数说明                                                                                                                                                                                                                                                                                                     |
|:--------|:-------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RLOCID  | 远端Location标识       | 远端Location的标识用以唯一标识一个远端网元。该参数须在对接的远端USCDB网元或者FE网元中先定义，然后在本端网元通过ADD RLOCATION命令配置后，才能在此处索引。远端Location是相对的，具体如下：对于主用局FE，它的远端Location指主用局USCDB、容灾局USCDB。对于主用局USCDB，它的远端Location指主用局FE、容灾局FE、容灾局USCDB。对于容灾局FE，它的远端Location指容灾局USCDB、主用局USCDB。对于容灾局USCDB，它的远端Location指容灾局FE、主用局FE、主用局USCDB。 取值范围：1～512 默认值：无。 |
| ID      | 远端DPU模块号/远端业务IP索引  | 用于指定远端网元IP地址对应的远端DPU模块号/远端业务IP索引。在与远端ATCA或NFV USCDB对接场景下，需要配置“远端DPU模块号”；在与远端PaaS USCDB或FE网元对接场景下，需要配置“远端业务IP索引”。 该参数必须在对接的远端USCDB网元或者FE网元中先定义，然后才能在此处索引。 取值范围：1～4080 默认值：无。                                                                                                                              |
| IPVER   | IP类型               | 用于表示IP地址类型。 取值范围： IPV4：配置IPV4类型IP使用IPV6：配置IPV6类型IP使用 默认值：无。                                                                                                                                                                                                                                              |
| IPV4IP1 | 远端Location IPV4地址1 | 远端网元的Location IP地址。这个地址必须在对接的远端USCDB网元或者FE网元中已经配置完毕。 取值范围：IPV4地址 默认值：无。                                                                                                                                                                                                                                  |
| IPV6IP1 | 远端Location IPV6地址1 | 远端网元的Location IP地址。这个地址必须在对接的远端USCDB网元或者FE网元中已经配置完毕。 当参数“IP类型”设置为“IPV6(IPV6)”时，该参数有效，格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如：2001:DB8:8432:4098:4782:5784::。 取值范围：IPV6地址 默认值：无。                                                                                                                  |
| IPV4IP2 | 远端Location IPV4地址2 | 远端网元的Location IP地址。这个地址必须在对接的远端USCDB网元或者FE网元中已经配置完毕。 取值范围：IPV4地址 默认值：无。                                                                                                                                                                                                                                  |
| IPV6IP2 | 远端Location IPV6地址2 | 远端网元的Location IP地址。这个地址必须在对接的远端USCDB网元或者FE网元中已经配置完毕。 当参数“IP类型”设置为“IPV6(IPV6)”时，该参数有效，格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如：2001:DB8:8432:4098:4782:5784::。 取值范围：IPV6地址 默认值：无。                                                                                                                  |

## 使用实例

增加远端网元IP地址：“远端Location标识”为“3”，“远端DPU模块号/远端业务IP索引”为“1”，“IP类型”为“IPV4”，“远端Location IPV4地址1”为“192.168.128.24”，“远端Location IPV4地址2”为“192.168.128.25”。执行如下命令：

```
ADD RIPADDR: RLOCID=3, ID=1, IPVER=IPV4, IPV4IP1="192.168.128.24", IPV4IP2="192.168.128.25";
```

## 输出结果说明

无。
