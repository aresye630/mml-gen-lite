# 查询业务控制功能配置(LST SCFCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询业务控制功能配置信息：

- 若需要查询业务控制功能的配置信息，无需输入参数。
- 若需要查询某个业务控制功能的配置信息，请输入“业务控制功能配置名称”。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称       | 参数说明                                                     |
|:--------|:-----------|:---------------------------------------------------------|
| CFGNAME | 业务控制功能配置名称 | 用于指示系统按照哪个业务控制功能配置名称来查询业务控制功能配置信息数据；若不输入，则表示所有的业务控制功能配置。 |

## 使用实例

1. 查询业务控制功能配置信息。

   ```
   LST SCFCFG:;
   ```

   ```
   %%LST SCFCFG:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    业务控制功能配置名称  业务控制方式  VLR/SGSN地址  主机名  业务控制的用户范围  IMSI号段组名称

    134                   CS局向        134           NULL    指定用户            134           
    123                   S6a/S6d局向   NULL          123     指定用户            123          
   (结果个数 = 2)

   ---    END
   ```
2. 查询业务控制功能配置信息，“业务控制功能配置名称”为“123”：

   ```
   LST SCFCFG: CFGNAME="123";
   ```

   ```
   %%LST SCFCFG: CFGNAME="123";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   业务控制功能配置名称  =  123
           业务控制方式  =  S6a/S6d局向
           VLR/SGSN地址  =  NULL
                 主机名  =  123
     业务控制的用户范围  =  指定用户
         IMSI号段组名称  =  123
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD SCFCFG**命令的参数说明。
