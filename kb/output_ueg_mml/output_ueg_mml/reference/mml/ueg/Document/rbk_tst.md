## 命令功能

**须知** 

回退试运行需要大约10分钟完成，请务必在华为技术支持人员的指导下操作。

本命令用于回退试运行状态。

试运行回退：用户使用本命令回退试运行进入事务模式，用户可以对数据进行新的配置操作，此时主机使用事务开始前的配置数据。

本命令的使用场景为：事务模式下进行的配置操作在试运行模式下产生的结果不符合预期时，可以使用本命令回退到事务模式，重新进行配置。

无。

无。

## 使用实例

回退试运行状态：

```

```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。
