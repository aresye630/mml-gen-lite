# 查询License统计对象获取方式(LST LICOBJCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询配置库中当前按照哪种方式创建License控制项测量对象。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询当前对象获取方式。

```
LST LICOBJCTRL:;
```

```
%%LST LICOBJCTRL:;%%
RETCODE = 0  操作成功

查询结果如下
------------
License统计对象获取方式  =  统计所有控制项
(结果个数 = 1)

---    END
```
