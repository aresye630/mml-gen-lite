# 加载远端DSG模块信息(LOD RDSG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于将同步到本端网元OMU表中的RDSG配置信息加载到USCDB网元的DSG模块中。

## 注意事项

- 该命令需要在执行**SYN RDSG**后执行。
- UDM不支持该命令。

## 参数说明

| 参数标识   | 参数名称         | 参数说明                                                                                                                                                                                                                                                    |
|:-------|:-------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RLOCID | 远端Location标识 | 用于标识远端Location，远端Location和远端网元一一对应。远端Location在不同场景下是相对的，具体如下：对于主用局FE，它的远端Location指主用局USCDB、容灾局USCDB。对于主用局USCDB，它的远端Location指主用局FE、容灾局FE、容灾局USCDB。对于容灾局FE，它的远端Location指容灾局USCDB、主用局USCDB。对于容灾局USCDB，它的远端Location指容灾局FE、主用局FE、主用局USCDB。 取值范围：1～512 默认值：无。 |

## 使用实例

加载OMU表中配置的“远端Location标识”为“3”的RDSG数据，此时需要进行如下操作：

```
LOD RDSG:  RLOCID=3;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释          | 原因分析                           | 处理建议                                                                                                                                                                                        |
|-------:|:---------------|:-------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 302003 | 远端Location不存在。 | 远端Location不存在，必须先配置远端Location。 | 通过ADD RLOCATION命令先配置远端Location，再在本命令中引用。                                                                                                                                                    |
| 302551 | 本端链路中心未配置。     | 本端网元指定的DSG链路中心未配置。             | 在本端“MML命令行 - USCDB”窗口下执行LST DSGLINKCTRL命令查询DSG链路中心。 若本端DSG链路中心已配置，执行命令时输入正确的“远端Location标识”。若本端DSG链路中心未配置，执行ADD DSGLINKCTRL配置DSG链路中心后，重新执行该命令。                                               |
| 302553 | 远端链路中心未配置。     | 本端网元指定的远端Location DSG链路中心未配置。  | 在本端网元下执行LST RDSGLINKCTRL命令查询远端Location DSG链路中心。 若本端网元远端Location DSG链路中心已配置，执行命令时输入正确的“远端Location标识”。若本端网元远端Location DSG链路中心未配置，在对端网元下执行ADD RDSGLINKCTRL配置远端Location DSG链路中心后，在本端网元下重新执行该命令。 |
