# 查询HLR ID(LST FUNCID)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于用户查询HLR标识符，即本局HLR的功能ID，由运营商通过业务发放系统中SET INTROFF命令进行自定义。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询HLR标识符：

```
LST FUNCID:;
```

```
%%LST FUNCID:;%%
RETCODE = 0  操作成功

操作结果如下
------------
本局HLR的标识符  =  12345
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称     | 输出结果解释       |
|:----------|:-------------|
| 本局HLR的标识符 | 即本局HLR的功能ID。 |
