# 发送MTP二层伪消息(SND MTPFM2)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为维护类命令，用于请求系统在指定的MTP链路上发送MTP二层伪消息。

该命令仅适用于测试场景，例如在IOT（interoperability test）测试中，操作员可以通过该命令提供仿真协议接口以完成某些特定的测试项目，而在其他情况下，请勿使用该命令。

## 注意事项

- MTP二层伪消息由主机下发到负责信令处理的单板，这些消息可能对信令链路造成严重影响，请操作员在执行该操作之前仔细确认任务的可行性。
- 在使用该命令前，请使用**DSP N7DSP**命令查询目的信令点的状态，只有在目的信令点的状态为“可达”时，系统才能发送伪消息。
- 在使用该命令前，请使用**DSP N7DLNK**命令查询发送伪消息的MTP链路的状态，只有在MTP链路的状态为“使用”时，系统才能发送伪消息。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                            |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------|
| LNKNM  | 链路名称   | 标识一条MTP链路的关键字段，用于指定系统在哪一条MTP链路上发送伪消息，操作员可以用LST N7LNK命令查询MTP链路配置情况。 取值范围: 长度不超过32的字符串 默认值: 无。 说明: 无。             |
| CMD    | 命令码    | MTP二层伪消息对应的命令码。 取值范围: 0～255 默认值: 无。 说明: 关于MTP二层伪消息的命令码和格式，请参考MTP三层与信令处理板之间的通讯协议。                                |
| PM     | 参数     | 用于指定消息参数，为16进制数，数字之间以空格隔开。 取值范围: 最多为7个16进制数 默认值: 无。 说明: 需要指出的是消息参数需与MTP二层协议（Q.704）指定的消息格式一致，且参数的字节顺序必须为网络的字节顺序。 |

## 使用实例

发送MTP二层伪消息，“链路名称”为“C9-1”，“命令码”为“4”，“参数”为“FF”：

```
SND MTPFM2: LNKNM="C9-1", CMD=4, PM="FF";
```
