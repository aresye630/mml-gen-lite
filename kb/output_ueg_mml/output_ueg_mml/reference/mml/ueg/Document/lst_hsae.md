# 查询外部SAE设备的配置信息(LST HSAE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询SAE的配置信息：

- 若需要查询全部SAE数据记录的信息，请不要输入任何参数。
- 若需要查询某条SAE数据记录的详细信息，请输入“SAE名称”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HSSN   | HSS名称  | 用于指示系统需要按照哪个“HSS名称”来查询SAE数据记录；若不输入，则表示所有的HSS实体名称。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                                                                                                             |
| SAEN   | SAE名称  | 用于指示系统需要按照哪个“SAE名称”来查询SAE数据记录；若不输入，则表示所有的“SAE名称”。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                                                                                                             |
| HN     | 主机名    | 用于指示系统需要按照哪个“主机名”来查询SAE数据记录；若不输入，则表示所有的“主机名”。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                                                                                                                 |
| LNKMOD | 链路选择模式 | 用于指示系统需要按照哪个“链路选择模式”来查询SAE数据记录；若不输入，则表示所有的“链路选择模式”。 取值范围： SESSIONIDBASED(基于会话ID)：同一个会话的所有信令消息都在同一条链路上传输。多个会话的消息按照轮选的方式在多条链路负荷分担。 POLLING(轮询方式)：当配置多条链路，信令消息在每条链路上负荷分担。 AORS(主备方式)：在主备链路选择方式下，如果主链路故障，则将某条备用链路升为主链路。默认第0条链路为主链路，当第0条链路不可用时，会自动选择其他可用链路。 ACTIVE(激活方式)：根据链路的激活状态，从第0条开始选择第一条激活的链路，将信令消息发往该链路。 ACTIVEWITHPRI(基于优先级的激活方式)：选择优先级最高的一条激活链路来工作。优先级相同，则选择路由表中设置最靠前的一条激活链路。POLLINGWITHPRI(基于优先级的轮询方式)：对所有链路轮流选择，始终选择优先级最高的可用链路。存在多个优先级相同的链路时，在这些链路之间轮询选择。 默认值：无。 说明：可选参数。 |

## 使用实例

1. 查询所有SAE的信息：

   `LST HSAE:;`

   ```
   %%LST HSAE:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    HSS名称  SAE名称   主机名            链路选择模式   HSS索引  SAE索引

    HSS1     SAE9      sae9.huawei.com   轮询方式       5        9          
    HSS2     SAE10     sae10.huawei.com  轮询方式       4        8          
   (结果个数 = 2)

   ---    END
   ```
2. 查询“SAE名称”为“SAE9”的SAE的信息：

   `LST HSAE: SAEN="SAE9";`

   ```
   %%LST HSAE: SAEN="SAE9";%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
             HSS名称  =  HSS1
             SAE名称  =  SAE9
              主机名  =  sae9.huawei.com
        链路选择模式  =  轮询方式
             HSS索引  =  5
             SAE索引  =  9
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

以下列出的是未包含在本命令参数说明中的输出项，其他输出项的详细说明请参见本命令的参数说明。

|:--------|:------------------------------------------|
