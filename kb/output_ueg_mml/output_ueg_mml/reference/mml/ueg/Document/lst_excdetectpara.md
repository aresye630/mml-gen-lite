# 查询单用户异常流程冲击防护检测参数(LST EXCDETECTPARA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询单用户异常流程冲击防护检测功能配置信息。

## 注意事项

存储Bypass场景不支持配置异常流程防护策略。

## 参数说明

无。

## 使用实例

查询单用户异常流程冲击防护检测功能配置信息。

```
LST EXCDETECTPARA:;
```

```
%%LST EXCDETECTPARA:;%%
RETCODE = 0  操作成功 

操作结果如下
------------------------
             检测周期  =  1
MAP消息允许最大消息数  =  8
 4G消息允许最大消息数  =  7
IMS消息允许最大消息数  =  21
 支持同时检测的用户数  =  1000
(结果个数 = 1)

---    END
```
