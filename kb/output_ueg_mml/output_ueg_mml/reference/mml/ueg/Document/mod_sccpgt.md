# 修改SCCP全局翻译码(MOD SCCPGT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于对配置数据库中的一条SCCP全局翻译码数据记录的某些参数进行修改或调整。在该命令中，系统通过一条GT码唯一标识一条SCCP全局翻译码数据记录，以下关键参数的不同组合确定一条GT码：

- 全局翻译码类型
- 翻译类型
- 编号计划
- 地址性质指示语
- 全局翻译码地址信息

## 注意事项

- GT（全局码）翻译结果中的信令点必须已经在SCCP DSP表或本局信息表中配置。使用**LST SCCPDSP**或**LST OFI**命令，可以查询相关的配置信息。
- 当翻译结果类型修改为“SPC + SSN”时，“SSN”（子系统）必须已经在SCCP SSN表中配置（通过**ADD SCCPSSN**命令）。使用**LST SCCPSSN**命令，可以查询SCCP SSN表的配置信息。
- 当翻译结果类型修改为“SPC + New GT”时，“New GT”（新全局码）必须已经在SCCP New GT表中配置（通过**ADD SCCPNGT**命令）。使用**LST SCCPNGT**命令，可以查询SCCP New GT表的配置信息。
- 该命令支持配置回退。
- 该命令不允许进行批操作。

## 使用实例

1、修改SCCP全局翻译码，“全局翻译码类型”为“ITU类型4”，“翻译类型”为“00”，“编号计划”为“ISDN/电话编号计划”，“地址性质指示语”为“国际号码”，“全局翻译码地址信息”为“99999999”，“全局翻译码新名称”为“CYH”：

```
MOD SCCPGT: GTI=GT4, TRANTYP="00", NUMPLAN=ISDN, ADDREXP=INTER, ADDR=K'99999999, GTNM1="CYH";
```

2、修改SCCP全局翻译码，“翻译结果类型”为“SPC”，“信令点编码修改”为“666666”，“全局翻译码类型”为“ITU类型4”，“翻译类型”为“00”，“编号计划”为“ISDN/电话编号计划”，“地址性质指示语”为“国际号码”，“全局翻译码地址信息”为“99999999”：

```
MOD SCCPGT: GTI=GT4, TRANTYP="00", NUMPLAN=ISDN, ADDREXP=INTER, ADDR=K'99999999, RESULTT=LSPC2, SPC="666666";
```
