# 查询远端DSG(LST RDSG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询远端DSG配置信息。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称         | 参数说明                                                 |
|:--------|:-------------|:-----------------------------------------------------|
| RLOCID  | 远端Location标识 | 远端Location的标识。远端location和远端网元一一对应。 取值范围：1～512 默认值：无。 |
| RDSGMID | 远端DSG模块号     | 远端DSG模块号。 取值范围：1～2047 默认值：无。                         |

## 使用实例

查询远端DSG。

LST RDSG:;

```
%%LST RDSG:;%%
RETCODE = 0  操作成功

操作结果如下
------------------------
      远端Location标识  =  3
         远端DSG模块号  =  3
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称        | 输出结果解释        |
|:-------------|:--------------|
| 远端Location标识 | 远端Location标识。 |
| 远端DSG模块号     | 远端DSG模块号。     |
