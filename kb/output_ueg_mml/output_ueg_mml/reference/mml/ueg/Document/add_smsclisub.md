# 增加短信互通网关用户(ADD SMSCLISUB)

## 命令功能

该命令用于增加短信互通网关用户的用户名和密码。

在号码携带业务中，用户可以在不改变号码的情况下加入到其他运营商的网络，享受新运营商带来的服务。开通NPMSC特性，需要通过SOA（Service Order Administration）系统同步各个运营商中的相关数据，如配置携出用户数据、携转用户数据、短消息RN路由数据等，用户需要在满足工信部以及原运营商的条件下开通。用户不能通过手机自己签约开通。本特性可以应用于GSM网络或UMTS网络中。

例如，用户由运营商A携号转网至运营商B，此时运营商A会在NPMSC中增加携出用户。原所在网络将给该携出用户发短消息，短消息中心会向NPMSC发MT-Forward操作，NPMSC根据用户携出的RN转换为Deliver消息投递给短信互通网关。短信互通网关根据与NPMSC绑定用户的用户名和密码，完成短消息下发通知。

## 注意事项

- SMPP（Short Message Peer to Peer）3.4标准中定义的用户名长度最大为15位、密码长度最大为8位。
- 当前版本不支持此功能，执行该命令后会返回错误码：335607 暂不支持该功能。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UNAME  | 用户名称   | 用于标识待增加短信互通网关用户名称。 取值范围：1～15个字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                     |
| PWD    | 用户密码   | 用于标识待增加短信互通网关用户密码。 取值范围：6～8位的字符串。 默认值：无。 配置原则：密码区分大小写，其复杂度需同时满足下列条件：密码必须至少包含以下四个类别中的三类：英文大写字母英文小写字母数字：0～9特殊字符：~ ! # % ^ * ( ) _ - + [ ] { } | < > . ? 不允许使用三个或三个以上连续的字母或数字（例如：ABC、123）。密码不能和帐号或者帐号的逆序一样。不允许使用三个或三个以上连续的相同字符（例如：AAA）。如果MOD INSP命令中将“软件参数类型”为“HSS9860”的“PWD_COMP_SWITCH（密码兼容开关）”参数设为“0”，则密码长度不能少于8位字符。如果MOD INSP命令中将“软件参数类型”为“HSS9860”的“PWD_COMP_SWITCH（密码兼容开关）”参数设为“1”，则密码长度不能少于6位字符。 密码的第一个字符必须是字母。 符合要求的密码，如：a1B2#3c4。 |

## 使用实例

若用户由运营商A携号转网至运营商B，运营商A为用户签约号码携带业务，其业务发放基本流程如下：

1. 登录PGW Web LMT，执行**ADD NPDONORSUB**命令增加本网携出用户。

   ```
   ADD NPDONORSUB: IMSI="4601075003001",ISDN="86131075003001", RN="1112";
   ```
2. 登录OMU客户端执行该命令增加与短信互通网关相连的用户名、密码。其中该用户的“用户名称”为“username1”，“用户密码”为“a1B2#3D4”，命令如下：

   ```
   ADD SMSCLISUB: UNAME="username1", PWD="*****";
   ```
3. 执行**ADD SMSRNROUT**命令增加短消息RN路由。

   ```
   ADD SMSRNROUT: UNAME="username1", RN="1112";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释               | 原因分析               | 处理建议                             |
|-------:|:--------------------|:-------------------|:---------------------------------|
| 335607 | 暂不支持该功能。            | 当前版本不支持此功能。        | 无需处理。                            |
| 352044 | 用户已存在               | “用户名称”参数指定的用户已经存在。 | 使用LST SMSCLISUB命令查询后，重新输入“用户名称”。 |
| 352054 | 参数取值无效：该密码的设定不符合要求。 | “用户密码”参数输入不符合取值范围。 | 根据实际情况，重新输入“用户密码”，确保其取值符合取值范围。   |
