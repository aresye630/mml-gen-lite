# 话统比对（CMP SYSSTAT）

## 命令功能

该命令用于对升级或网改操作前后的话统指标数据进行比对，在MML客户端上显示出测量指标大于等于阈值的数据。当操作员执行该命令时，系统可能返回三种比较结果：

- 差值大于等于阈值的数据。
- 话统结果不可信的数据。
- 没有话统结果。

## 注意事项

- 话统比对的前提条件是下表中的测量单元和对应测量指标在WEBUI上已经创建，如果没有创建，则不支持进行比对。
- 话统比对仅支持在WEBUI上创建的话统任务，不支持在M2000上创建的话统任务，同时不支持在M2000上执行此命令进行比对。
- 对于升级的操作类型，只能在升级后的七天的观测期内进行比对，同时不支持24小时内连续升级两次的话统数据比对。
- 在话统比对时，建议选择不同日期相同时间的话统进行比对。

## 参数说明

| 参数标识    | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:--------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OT      | 操作类型        | 指定话统比对的操作类型，有如下两种操作类型： UP(升级)NR(网改)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| DM      | 操作前比对日期     | 指定操作前的比对日期。  说明： 对于升级操作，该日期必须是升级前的日期，否则话统比对没有结果。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| TM      | 操作前比对时间     | 指定操作前的比对时间，该操作时间必须为话统周期的倍数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| DA      | 操作后比对日期     | 指定操作后的比对日期。  说明： 对于升级操作，该日期必须是升级后的日期，否则话统比对没有结果。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| TA      | 操作后比对时间     | 指定操作后的比对时间，该操作时间必须为话统周期的倍数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| PERIOD  | 话统周期        | 指定话统比对的周期，有如下四种类型： M5(5分钟) M15(15分钟) M30(30分钟) M60(60分钟) 默认值：M5(5分钟)。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| MUMO    | 测量单元或测量对象   | 指定要比对的测量单元或测量对象。 取值范围： 全部选中全部清空全部灰化RSV0(位置更新流程(0)) RSV1(位置取消流程(1)) RSV2(独立插入用户数据流程(3)) RSV3(鉴权失败报告流程(11)) RSV4(取路由信息流程(15)) RSV5(GPRS位置更新流程(16)) RSV6(短消息取路由信息流程(22)) RSV7(取鉴权集流程(26)) RSV8(处理非结构化补充业务操作请求(29)) RSV9(SAE-位置更新消息测量) RSV10(SAE-鉴权消息测量) RSV11(SAE-取消位置登记消息测量) RSV12(SAE-插入用户数据消息测量) RSV13(用户注册状态查询消息统计) RSV14(S-CSCF注册注销通知消息统计) RSV15(被叫用户位置查询消息统计) RSV16(用户鉴权消息统计) RSV17(HSS发起的网络侧注销消息统计) RSV18(HSS发起的用户数据更新消息统计) RSV19(AS读取用户数据消息统计) RSV20(AS更新透明数据消息统计) RSV21(AS数据变化订阅消息统计) RSV22(HSS下发订阅通知消息统计) RSV23(MAP鉴权测量) RSV24~RSV31：保留位 默认值：全部灰化。 |
| DAL     | 显示所有结果      | 是否在客户端上显示所有超过阈值的比对结果。默认每个测量单元或测量对象最多显示10个对象的比对结果。 取值范围如下：NO(否)YES(是)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| CHKMUMO | 检查测量单元或测量对象 | 用于设置系统是否检查“测量单元或测量对象”携带的测量单元或测量对象在对比升级或网改操作前后两个时间点都已经创建。 TRUE(检查):若已经创建，则报文中正常显示该测量单元或测量对象记录。若都没有创建，则报文中忽略该测量单元或测量对象记录。 FALSE(不检查)：报文中正常显示该测量单元或测量对象记录。 默认值：FALSE                                                                                                                                                                                                                                                                                                                                                                                         |

## 使用实例

比较指定时间的话统结果，“操作类型”为“网改”，“操作前比对日期”为“17/01/2015”，“操作前比对时间”为“02:00”，“操作后比对日期”为“19/01/2015”，“操作后比对时间”为“08:00”，“话统周期”为“5分钟”，“测量单元或测量对象”为“位置更新流程(0)”,“显示所有结果”为“NO(否)”。

CMP SYSSTAT: OT=NR, DM=2015&01&17, TM=02&00, DA=2015&01&19, TA=08&00, PERIOD=M5, MUMO=RSV0-1, DAL=NO;

## 输出结果说明

| 输出项名称   | 输出结果解释                                                                                                                                                                                                                                                |
|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 测量单元    | 进行话统比对的测量单元名称。                                                                                                                                                                                                                                        |
| 测量指标    | 进行话统比对的测量指标名称，只显示超过阈值的测量指标。                                                                                                                                                                                                                           |
| 测量对象名称  | 测量对象的名称。                                                                                                                                                                                                                                              |
| 操作前话统结果 | 操作前的测量指标值。                                                                                                                                                                                                                                            |
| 操作后话统结果 | 操作后的测量指标值。                                                                                                                                                                                                                                            |
| 操作前开始时间 | 操作前的实际开始时间。                                                                                                                                                                                                                                           |
| 操作后开始时间 | 操作后的实际开始时间。                                                                                                                                                                                                                                           |
| 话统周期    | 实际比对的话统周期。  说明： 如果输入的比对话统周期在话统数据库表不存在，则按如下顺序获取数据，前面的没有就获取后面的。 当输入周期为60分钟时没有话统结果，则依次获取周期为30分钟、5分钟、15分钟的话统结果。 当输入周期为30分钟时没有话统结果，则依次获取周期为15分钟、5分钟、60分钟的话统结果。 当输入周期为15分钟时没有话统结果，则依次获取周期为5分钟、30分钟、60分钟的话统结果。 当输入周期为5分钟时没有话统结果，则依次获取周期为15分钟、30分钟、60分钟的话统结果。 |
