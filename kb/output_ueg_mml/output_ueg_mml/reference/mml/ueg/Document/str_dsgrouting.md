# 设置DSG路由目的Location(STR DSGROUTING)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

FE DSG增加一个DSG消息选择路由的命令，下发此命令后，FE DSG消息自动选择到正常的最高优先的BE局点。

## 注意事项

当FE DSG与DBS配置同一本端Location标识时，需同时执行**STR DSGROUTING**和**STR DBSROUTING**命令，且两条命令间隔不超过20s，如果超过，则FE的数据访问无法选择到正常高优先级BE局点。

## 参数说明

无。

## 使用实例

启动DSG消息选择路由操作。执行命令如下：

```
STR DSGROUTING:;
```

```
%%STR DSGROUTING:;%%
RETCODE = 0  操作成功

操作结果如下
------------------------
 DSG模块号          目的Location标识         操作结果   

 40                 88                       操作成功
 41                 88                       操作成功
(结果个数 = 2)

---    END
```

## 输出结果说明

| 输出项名称        | 输出项解释                                                                                                                                                                                                                                         |
|:-------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DSG模块号       | DSG模块号。                                                                                                                                                                                                                                       |
| 目的Location标识 | 目的Location标识。                                                                                                                                                                                                                                 |
| 操作结果         | 操作结果。 操作成功操作失败操作超时对端局点为正常的最高优先级局点：表示当前DSG路由目的Location已经是状态正常的最高优先级Location。当前DSG路由目的Location可以通过DSP DSGROUTING命令查询。接管状态不能操作：表示当前USCDB局点处于容灾接管状态，执行该命令失败。 说明： 如果“操作结果”参数显示为“接管状态不能操作”时，需要在接管USCDB上执行STP TAKEOVER停止接管后，再执行本命令设置DSG路由目的Location。 |
