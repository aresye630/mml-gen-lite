# 查询日志抑制(LST LOGSUPPRESSION)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于查询UDM主机侧ERR级别的运行文本日志的抑制周期。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询所有UDM主机侧ERR级别的运行文本日志的抑制周期：

```
LST LOGSUPPRESSION:;
```

```
%%LST LOGSUPPRESSION:;%%
RETCODE = 0  操作成功

操作结果如下:
------------------------
自动调节开关  =  ON
    加速速率  =  3000
    减速速率  =  30
    复位速率  =  3
    最小周期  =  100
    最大周期  =  600000
        步长  =  100
(结果个数 = 1)

---    END
```
