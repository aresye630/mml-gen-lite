# 显示TCAP版本(DSP TCAPVER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于请求系统显示TCAP协议的版本信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                              |
|:-------|:-------|:--------------------------------------------------------------------------------------------------|
| MN     | CCU模块号 | 用于请求系统显示哪个模块内的TCAP协议的版本信息。 取值范围：1～1023 默认值：无。 说明：必选参数。                                            |
| PRT    | 协议类型   | 用于请求系统显示哪种TCAP协议类型的版本信息，协议类型为ITU-T。 取值范围： “ITU-T(ITU-T)”“ANSI(ANSI)” 默认值： “ITU-T(ITU-T)” 说明：可选参数。 |

## 使用实例

显示22模块的TCAP版本：

```
DSP TCAPVER: MN=22;
```

返回结果如下：

```
%%DSP TCAPVER: MN=22;%%
RETCODE = 0  操作成功

显示TCAP版本
------------
TCAP版本号  =  SS7 V1.2.1.1 (TCAP)(ITU-T 1996)
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出结果解释                              |
|:--------|:------------------------------------|
| TCAP版本  | 用于返回当前模块的TCAP版本信息，括号中的内容表示TCAP协议类型。 |
