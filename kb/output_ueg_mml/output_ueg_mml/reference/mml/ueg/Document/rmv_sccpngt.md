# 删除SCCP新全局翻译码(RMV SCCPNGT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于从配置数据库中删除一条SCCP新全局翻译码数据记录。

## 注意事项

- 在正常情况下，删除一条SCCP新全局翻译码数据记录的操作步骤为：**RMV SCCPGT**-->****RMV SCCPNGT****。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                        |
|:-------|:---------|:------------------------------------------------------------------------------------------------------------|
| NGTNM  | 新全局翻译码名称 | 标识一条SCCP新全局翻译码数据记录的关键字段之一，用于指定需要删除哪一条SCCP新全局翻译码数据记录，操作员可以使用LST SCCPNGT命令查询获得。 取值范围：长度不超过32的字符串 默认值：无。 说明：无。 |

## 使用实例

删除SCCP新全局翻译码，“新全局翻译码名称”为“SCCPNGT”：

```
RMV SCCPNGT: NGTNM="SCCPNGT";
```
