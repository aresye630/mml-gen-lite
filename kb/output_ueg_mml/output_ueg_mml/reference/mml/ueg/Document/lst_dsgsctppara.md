# 查询DSG模块SCTP参数配置信息(LST DSGSCTPPARA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询DSG模块的SCTP配置信息。

## 注意事项

在FE侧存在多应用类型的场景下，若分组开关打开，则查询“DSG自动回切开关”参数值需要使用**LST DSGSERVICEPARA**命令。

## 参数说明

| 参数标识                  | 参数名称        | 参数说明                                                                                                                                                                                                |
|:----------------------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RTOINIT               | 报文重发间隔初始值   | 用于定义RTO（Retransmission Time-Out，重传超时时间）初始时长。 该参数的配置原则是：RTO最小值应小于RTO最大值。RTO初始值应大于或等于RTO最小值，且小于或等于RTO最大值。                                                                                             |
| RTOMIN                | 报文重发间隔最小值   | 用于定义RTO最小时长。 该参数的配置原则是：RTO最小值应小于RTO最大值。RTO初始值应大于或等于RTO最小值，且小于或等于RTO最大值。                                                                                                                             |
| RTOMAX                | 报文重发间隔最大值   | 用于定义RTO最大时长。 该参数的配置原则是：RTO最小值应小于RTO最大值。RTO初始值应大于或等于RTO最小值，且小于或等于RTO最大值。                                                                                                                             |
| RTOALPHA              | Rto Alpha值  | 该值是用来在协议栈运行期间计算双向时延和RTO值的常量。 该值必须小于或等于100和Rto Beta值。                                                                                                                                                |
| RTOBETA               | Rto Beta值   | 该值是用来在协议栈运行期间计算双向传播时间和RTO值的常量。 该值必须小于或等于100和大于或等于Rto Alpha值。                                                                                                                                        |
| COOKIELIFE            | Cookie有效生命期 | 在该时间里，在接收到来自SCTP服务器的INIT ACK后，Cookie Echo消息必须由SCTP客户端发送返回。即，在这段时间里，当接收到Cookie Echo消息时，用户可允许SCTP服务器不发送“Stale Cookie错误”到对端。在超过Cookie有效生命期时间后，如果SCTP收到Cookie Echo消息，将返回“Stale Cookie”作为原因的错误消息。空值不被接受。 |
| MAXARETR              | 偶联最大重传次数    | 偶联可承受的最大重传次数。如果对于一个给定的偶联，重传的次数超过这个值，删除偶联，并发送ABORT到对端。向上层报告状态变为DOWN。 该值必须大于或等于路径最大重传次数。                                                                                                              |
| MAXPRETR              | 路径最大重传次数    | 偶联的一条路径可承受的最大重传次数。如果偶联的一条路径，重传的次数超过这个值，该路径被自动设置为INACTIVE。向上层上报目的状态变为DOWN。 该值必须小于或等于偶联最大重传次数。                                                                                                        |
| INITMAXRETR           | 初始化最大重传次数   | 偶联中INIT块最大重传次数。如果对于一个给定的偶联，重传INIT块的次数超过这个值，删除偶联，并发送ABORT到对端。向上层报告状态变为DOWN。空值不被接受。                                                                                                                   |
| HBINTER               | 心跳消息间隔      | 心跳间隔时间。用于计算在空闲时间时，来自SCTP主机的2条心跳消息的间隔。心跳传送不仅依赖于此参数，也依赖于偶联的当前RTO。但是2条心跳消息的时间间隔一直要大于心跳消息间隔的值。空值不被接受。                                                                                                   |
| CHKSUMTX              | 发送消息时计算校验和  | 用来指示当SCTP块被送到对端时是否加校验和的标识。当使用设置为FALSE时，关闭校验和。校验和用于数据完整性，极大地影响性能。 该值为布尔值。                                                                                                                            |
| CHKSUMRX              | 接收消息时检查校验和  | 用来指示当从对端接收SCTP块时是否计算校验和的标识。当使用设置为FALSE时，关闭校验和。 该值为布尔值。                                                                                                                                              |
| CHKSUMTYPE            | 校验和算法       | 用来表示校验和的算法。 取值范围： ADLER32(ADLER32)CRC32(CRC32)                                                                                                                                                      |
| CNGLEVELNO            | 无拥塞级阈值      | 用于定义无拥塞的发送缓存中数据占用率。该值必须小于低拥塞级阈值。                                                                                                                                                                    |
| CNGLEVELL             | 低拥塞级阈值      | 用于定义低拥塞的发送缓存中数据占用率。该值必须大于无拥塞级阈值并且小于高拥塞级阈值。                                                                                                                                                          |
| CNGLEVELH             | 高拥塞级阈值      | 用于定义高拥塞的发送缓存中数据占用率。该值必须大于低拥塞级阈值。                                                                                                                                                                    |
| TOS                   | DSCP值       | 用于指定DSCP差分服务代码点（Differentiated Services Code Point）的取值。                                                                                                                                             |
| CONGESTIONFLAG        | 拥塞控制开关      | 设置发送数据时是否使用拥塞控制开关。                                                                                                                                                                                  |
| SERVICEPORT           | 业务基值端口      | FE DSG和USCDB DSG之间创建偶联时获取该基值端口和模块号生成通信端口。                                                                                                                                                           |
| BUNDINGFLAG           | 绑定开关        | 是否使用SCTP数据块绑定机制的标识。如果设置该标识，SCTP可以把多个块（控制数据）捆绑到同一个数据包里。在SCTP中处理，捆绑并不影响用户数据传输。                                                                                                                        |
| MAXNUMASSOC           | 最大偶联数       | 当前可以使用的最大偶联数量。                                                                                                                                                                                      |
| AUTOSWITCHBACK        | DSG自动回切开关   | 用于控制USCDB主用局恢复后，FE业务是否自动回切到主用局。USCDB主用局故障后，FE业务切到USCDB容灾局。                                                                                                                                          |
| LINKMODE              | 建链模式        | 本端DSG的建链模式。                                                                                                                                                                                         |
| SUBHEALTHYCHECKSWITCH | 亚健康检测开关     | 用于指示承载网亚健康监控及切换功能是否打开。                                                                                                                                                                              |
| SUBHEALTHYNETPLR      | 亚健康网络丢包率    | 承载网亚健康时的网络丢包率。用于指示系统根据亚健康网络丢包率的阈值判断偶联是否处于亚健康状态。                                                                                                                                                     |
| SUBHEALTHYSERVICETOR  | 亚健康业务超时失败率  | 承载网亚健康时的业务超时失败率。用于指示系统根据业务超时失败率的阈值判断是否需要进行BE局点切换。                                                                                                                                                   |
| MAXPFASTRETR          | 最大快速重传次数    | 路径可承受的最大快速重传次数。用于指示系统根据消息包重传次数，作为路径故障触发的条件，当快速重传次数达到所设置的值，则置该路径为故障，切换到备路径。                                                                                                                          |
| MAXNUMHB              | 最大变长心跳包探测次数 | 探测变长心跳包的最大次数。用于指示系统根据最大变长心跳包探测次数，作为路径恢复的其中一个条件。SCTP检测心跳消息长度支持六种心跳消息长度（32，128，256，512，1024，1472），消息长度单位为字节，当探测到六种消息长度的心跳消息都正常时，且达到产品配置的探测次数则置当前路径恢复。                                                 |
| SUBHEALTHYRCI         | 亚健康恢复检查间隔   | 偶联亚健康状态恢复检查的时间间隔。                                                                                                                                                                                   |
| PINGBYPASS            | 旁路ping结果    | 用于指定DSG是否旁路ping结果来判断承载网亚健康状态。若不输入，则表示不旁路，使用ping结果作为判断承载网亚健康的依据。                                                                                                                                     |

## 输出结果说明

如果该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                               | 原因分析                                          | 处理建议                                  |
|-------:|:------------------------------------|:----------------------------------------------|:--------------------------------------|
| 230528 | 业务分组功能打开，自动回切开关请使用DSGSERVICEPARA命令。 | 业务分组功能打开，不能使用LST DSGSCTPPARA命令查询“DSG自动回切开关”值。 | 执行LST DSGSERVICEPARA命令查询“DSG自动回切开关”值。 |
