# 查询用户是否在HSS上（DSP USERONHSS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用来查询指定用户在HSS上是否存在。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                          |
|:-------|:-------|:------------------------------------------------------------------------------|
| IDTYPE | 用户标识类型 | 用户标识类型。 取值范围： “IMSI(IMSI)”：查询IMSI号码。“MSISDN(MSISDN)”：查询MSISDN号码。 说明：该参数是必选参数。 |
| IMSI   | IMSI   | 用户IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 说明：该参数是可选参数，仅在用户标识类型为IMSI(IMSI)时必须输入。        |
| MSISDN | MSISDN | 用户MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 说明：该参数是可选参数，仅在用户标识类型为MSISDN(MSISDN)时必须输入。  |

## 使用实例

1. 查询IMSI号码为460775702200012的用户是否存在。

   ```
   DSP USERONHSS: IDTYPE=IMSI, IMSI="460775702200012";
   ```

   若用户在HSS上存在，则返回如下：

   ```
   %%DSP USERONHSS: IDTYPE=IMSI, IMSI="460775702200012";%%
   RETCODE = 0  操作成功

   ---    END
   ```
2. 查询IMSI号码为460775702200013的用户是否存在。

   ```
   DSP USERONHSS: IDTYPE=IMSI, IMSI="460775702200013";
   ```

   若用户在HSS上不存在，则返回如下：

   ```
   %%DSP USERONHSS: IDTYPE=IMSI, IMSI="460775702200013";%%
   RETCODE = 377168  指定的用户不存在

   ---    END
   ```
3. 查询IMSI号码为4607的用户是否存在。

   ```
   DSP USERONHSS: IDTYPE=IMSI, IMSI="4607";
   ```

   若输入的IMSI号码为无效值，则返回如下：

   ```
   %%DSP USERONHSS: IDTYPE=IMSI, IMSI="4607";%%
   RETCODE = 377165  无效的参数

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释    | 原因分析                               | 处理建议                                                  |
|-------:|:---------|:-----------------------------------|:------------------------------------------------------|
| 377165 | 无效的参数    | 输入的“IMSI”或“MSISDN”参数为无效值。          | 请根据“IMSI”和“MSISDN”参数的取值范围，重新输入“IMSI”或“MSISDN”参数执行该命令。 |
| 377168 | 指定的用户不存在 | 输入的“IMSI”或“MSISDN”参数对应的用户在HSS上不存在。 | 无。                                                    |
