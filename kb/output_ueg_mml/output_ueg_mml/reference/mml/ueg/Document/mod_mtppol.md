# 修改MTP屏蔽策略(MOD MTPPOL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于对配置数据库中的一条MTP屏蔽策略数据记录的某些参数进行修改或调整。在该命令中，系统通过“MTP屏蔽策略名称”参数来唯一标识一条MTP屏蔽策略数据记录。

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                                                                                         |
|:------------|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MTPNM       | MTP屏蔽策略名称  | 该参数是标识一条MTP屏蔽策略数据记录的关键字段，用于指定需要对哪一条MTP屏蔽策略数据记录的参数进行修改或调整，操作员可以使用LST MTPPOL命令查询获得。 取值范围：长度不超过32的字符串 默认值：无。 说明：必选参数。                                                                                                                                                                                                                                                                           |
| MAXTRAFFIC  | 流量阈值       | 流量阈值，本局启动MTP屏蔽控制的过滤条件之一，用于指定在单位时间内所允许通过的MTP信令消息包（MSU）的最大数量。 假设操作员在本命令中将“流量单位”参数设为“每小时”、将“流量阈值”设为1000，则本局将以“小时”为单位对本局接收的MTP信令消息实施流量控制：如果在1小时内，本局所接收到的MTP信令消息包小于1000，则本局将不实施流量控制；如果在1小时内，本局所接收到的MTP信令消息包已经达到1000，则在本小时的其余时间内，本局将丢弃后续所接收到的所有MTP信令消息包。当下一个时间单位开始时，本局将对本局接收到的MTP信令消息包重新进行统计（即将相应的统计计数器清零）。 取值范围：0～2147483647 默认值：无。 说明：可选参数。                                                      |
| TRAFFICUNIT | 流量单位       | 对应于上述启动MTP屏蔽控制的组合过滤条件，用于指示本局按照什么样的时间单位来对本局接收到的MTP信令消息实施流量控制。 取值范围： “PER_HOUR(每小时)”“PER_DAY(每天)”“PER_MONTH(每月)”“PER_YEAR(每年)” 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                 |
| MTPNM1      | 新MTP屏蔽策略名称 | 对于由本命令中“MTP屏蔽策略名称”字段所标识的某条具体的数据记录而言，用于指示系统是否需要对该数据记录中“MTP屏蔽策略名称”字段的取值重新进行定义，其值域类型为字符串、最大长度为32。该参数的配置原则是： 若不输入任何字符：表示不对该数据记录中“MTP屏蔽策略名称”字段的取值重新进行定义。 若输入一个字符串：表示需要对该数据记录中“MTP屏蔽策略名称”字段的取值重新进行定义，且输入的字符串不能在相应的数据表中已经被定义。假设本命令中“MTP屏蔽策略名称”字段的取值为A、“新MTP屏蔽策略名称”字段的取值为B，则对于配置数据库中索引了取值为A的所有数据记录的“MTP屏蔽策略名称”字段，系统将自动把这些字段的值由A修改为B。 名称只允许输入: 0～9，a-z，A-Z，“-”和中文字符。 取值范围：长度不超过32的字符串 默认值：无。 说明：可选参数。 |

## 使用实例

1、修改MTP屏蔽策略,“MTP屏蔽策略名称”为“MTPPOL”，“流量单位”为“每小时”，“流量阈值”为“100”：

```
MOD MTPPOL: MTPNM="MTPPOL", MAXTRAFFIC=100, TRAFFICUNIT=PER_HOUR;
```

2、修改MTP屏蔽策略,“MTP屏蔽策略名称”为“MTPPOL”，“新MTP屏蔽策略名称”为“NEWPOL”：

```
MOD MTPPOL: MTPNM="MTPPOL", MTPNM1="NEWPOL";
```
