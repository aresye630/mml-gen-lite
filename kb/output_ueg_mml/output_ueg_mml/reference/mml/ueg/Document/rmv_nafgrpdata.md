# 删除NAFID群组数据(RMV NAFGRPDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于从配置数据库中删除网络应用功能组下的NAF列表信息。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

删除NAFID群组数据后，可能会导致BSF（Bootstrapping Server Function）无法从HSS中获取到用户的GUSS（GBA User Security Settings）签约信息，请谨慎操作。

## 参数说明

| 参数标识   | 参数名称        | 参数说明                                                                                                                                                              |
|:-------|:------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NAFGRP | NAF GROUP编号 | 标识NAFID列表信息的关键字段，用于指定需要删除哪一个网络应用功能组下的NAFID列表信息，操作员可以使用LST NAFGROUP命令查询获得。 取值范围：1～65535。 默认值：无。 注意：该参数为必选参数。                                                       |
| FQDN   | FQDN        | 标识NAFID列表信息的关键字段，用于指定需要删除哪一个网络应用功能组的全量域名信息，操作员可以使用LST NAFGRPDATA命令查询获得。 需要指出的是，该参数不区分大小写，在执行LST NAFGRPDATA命令查询出的报文中为全小写形式。 取值范围：长度不超过127的字符串。 默认值：无。 注意：该参数为必选参数。 |

## 使用实例

删除NAFID群组数据，携带以下参数：

- “NAF GROUP编号”为“1”
- “FQDN”为“FQDN”

执行命令如下：

```
RMV NAFGRPDATA: NAFGRP=1, FQDN="FQDN";
```
