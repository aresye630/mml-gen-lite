# 显示SCTP偶联流量控制信息(DSP SCTPFCPARA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于请求系统显示指定SCTP协议偶联的流量控制信息。

## 注意事项

无。

## 参数说明

| 参数ID   | 参数名称   | 参数描述                                                                                   |
|:-------|:-------|:---------------------------------------------------------------------------------------|
| MN     | 模块号    | 用于请求系统显示哪个BSG模块内的SCTP偶联统计信息。 取值范围： 1～1023 默认值： 无。 说明： 无。                               |
| AID    | 偶联号    | 用于请求系统显示哪个偶联号的SCTP偶联统计信息。使用命令DSP M3LNK查询获得M3UA链路的SCTP偶联号。 取值范围： 0～65535 默认值： 无。 说明： 无。 |

## 使用实例

显示SCTP偶联流量控制信息，BSG模块号为100，偶联号为9:

```
DSP SCTPFCPARA: MN=100, AID=9;
```
