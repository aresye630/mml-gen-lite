# 删除SCCP全局翻译码(RMV SCCPGT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于从配置数据库中删除一条或者一组SCCP全局翻译码数据。

## 注意事项

- 该命令支持配置回退。
- 如果操作员删除某条SCCP全局翻译码数据记录，将可能导致本局与MSC、SGSN、SMC、SCP等设备之间的MAP、CAP、INAP等协议消息的通信中断，可引发业务中断的重大事故，请操作员在执行该操作之前仔细确认任务的可行性。
- 在正常情况下，删除一条SCCP全局翻译码数据记录的操作步骤为：**RMV SCCPGT**。
- 该命令不允许进行批操作。

## 使用实例

删除SCCP全局翻译码，“全局翻译码类型”为“ITU类型4”，“翻译类型”为“00”，“编号计划”为“ISDN/电话编号计划”，“地址性质指示语”为“国际号码”，“全局翻译码地址信息”为“99999999”：

```
RMV SCCPGT: GTI=GT4, TRANTYP="00", NUMPLAN=ISDN, ADDREXP=INTER, ADDR=K'99999999;
```
