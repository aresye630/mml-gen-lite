# 增加GSID业务属性数据(ADD ASATTRIBUTE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在配置数据库中增加一条GSID业务属性数据。在GBA架构下，交互过程中，UIM的功能实体AP根据用户接入请求信息中的GSID业务信息，获取其归属USS签约信息，并根据指定的GSID业务配置进行策略控制（UIM对USS信息检查力度），提高用户访问操作的安全性

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

- 不允许添加“URI存在”和“AUID存在”参数全为“FALSE”的GSID业务属性数据记录。
- 不允许添加“URI存在”、“URI”、“AUID存在”和“应用区分标识”参数全部相同的两条GSID业务属性数据记录。

## 参数说明

| 参数标识    | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                |
|:--------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ID      | 索引          | 用于标识一条GSID业务属性数据记录，全局唯一。 取值范围：1～255 默认值：无。 注意：该参数为必选参数。                                                                                                                                                                                                                                                                                                                                             |
| URIE    | URI存在       | 用于指定本命令中的“URI”参数是否存在。 取值范围TRUE(是)：URI参数存在。FALSE(否)：URI参数不存在。 默认值：FALSE(否)。 注意：该参数为可选参数。                                                                                                                                                                                                                                                                                                             |
| URI     | URI         | 用于指定URI（Uniform Resource Identifier）信息。URI可以定位Web上可用的每种资源，包括HTML文档、图像、视频片段、程序等。仅当本命令中的“URI存在”参数为“TRUE(是)”时该参数有效。 需要指出的是，该参数不区分大小写，在执行LST ASATTRIBUTE命令查询出的报文中为全小写形式。 取值范围：长度不超过127的字符串。 默认值：无。 注意：该参数为条件必选参数。                                                                                                                                                                                       |
| AUIDE   | AUID存在      | 用于指定本命令中的“AUID”参数是否存在。 取值范围TRUE(是)：应用区分标识参数存在。FALSE(否)：应用区分标识参数不存在。 默认值：FALSE(否)。 注意：该参数为可选参数。                                                                                                                                                                                                                                                                                                      |
| AUID    | 应用区分标识      | 用于指定要匹配的业务请求类型，如“simservs.ngn.etsi.org”。仅当本命令中的“AUID存在”参数为“TRUE(是)”时该参数有效。 需要指出的是，该参数不区分大小写，在执行LST ASATTRIBUTE命令查询出的报文中为全小写形式。 取值范围：长度不超过127的字符串。 默认值：无。 注意：该参数为条件必选参数。                                                                                                                                                                                                                             |
| GSID    | GSID        | 用于指定GBA业务标识，即用户终端发起访问请求服务的业务类型编码。“GSID”参数需要与对端IMS-HSS协商，运营商需要提前在IMS-HSS上配置GSID，“GSID”参数要与IMS-HSS上配置的GSID信息保持一致。  说明： 针对VoLTE，推荐将“GSID”参数配置为“2”，即“AUTHENTICATION_PROXY”。 取值范围：0～999999 默认值：无。 注意：该参数为必选参数。                                                                                                                                                                                           |
| APROLE  | AP认证和接入控制粒度 | 用于指定对AP的认证授权、GBA参与者能力和对应用授权用户进行认证的支持能力，在GBA架构下UIM根据此参数决定AP检查USS信息的力度。推荐设置为“AU_AssertedID_CheckID(用户附着标识通过检查的AS可识别的应用授权用户)”。 取值范围：AP(GBA参与者)：不检查USS信息，也不传递用户标识。AU_Anonymous(对AS匿名的应用授权用户)：检查USS信息，不传递用户标识。AU_AssertedID(AS可识别的应用授权用户)：检查USS信息并传递USS中的用户标识。AU_AssertedID_CheckID(用户附着标识通过检查的AS可识别的应用授权用户)：检查USS信息和用户标识，并传递USS中的用户标识。 默认值：AU_AssertedID_CheckID(用户附着标识通过检查的AS可识别的应用授权用户)。 注意：该参数为可选参数。 |
| UIDTYPE | 传递的用户标识类型   | 用于指定UIM在GBA检测时传递用户标识的类型。 取值范围：“IMPU(IMPU)”。 默认值：“IMPU(IMPU)”。 注意：该参数为可选参数。  说明： IMPU为用户公有标识，是用户对外可寻址的标识，用于请求和其他用户通信，全局唯一。IMPU类似于GSM网络中的MSISDN，为用户固化数据（即签约用户固有的数据），存储在IMS-HSS和S-CSCF中。                                                                                                                                                                                                               |

## 使用实例

增加GSID业务属性数据，携带以下参数：

- “索引”为“1”
- “URI存在”为“TRUE(是)”
- “URI”为“123”
- “AUID存在”为“TRUE(是)”
- “应用区分标识”为“simservs.ngn.etsi.org”
- “GSID”为“2”
- “AP认证和接入控制粒度”为“AU\_AssertedID\_CheckID(用户附着标识通过检查的AS可识别的应用授权用户)”
- “传递的用户标识类型”为“IMPU(IMPU)”

执行命令如下：

```
ADD ASATTRIBUTE: ID=1, URIE=TRUE, URI="123", AUIDE=TRUE, AUID="simservs.ngn.etsi.org", GSID=2, APROLE=AU_AssertedID_CheckID, UIDTYPE=IMPU;
```
