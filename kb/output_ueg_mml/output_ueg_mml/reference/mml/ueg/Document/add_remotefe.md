# 增加远端FE信息(ADD REMOTEFE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条远端FE的信息记录。

容灾场景下，当本端FE关键局向故障权重大于等于100%时，需要检查远端FE状态，如果有远端FE状态正常且没有进入接管状态，则更新自身状态并闭锁本端FE所有对外信令链路，进行FE自动倒换。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称          | 参数说明                                                                                                                                                                  |
|:-------|:--------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RLOCID | 远端Location ID | 用于标识远端FE设备的Location标识。一个远端Location标识唯一对应一个远端FE。 取值范围：1～512 默认值：无。                                                                                                     |
| FLAG   | 检测标识          | 用于标识本端FE触发自动闭锁信令链路时，远端FE的状态。 同一个局点下所有远端FE的信息中该参数必须设置为同一个值。 取值范围：MUST（Must）：应用于多FE接管1个FE的场景，所有远端FE设备必须全部可用。NOT_MUST（Not must）：应用于1个FE接管1个FE的场景，所有远端FE设备中有可用的设备。 默认值：无。 |

## 使用实例

增加一条远端FE信息记录，其中“远端Location ID”为“1”，“检测标识”为“MUST（Must）”。命令如下：

```
ADD REMOTEFE: RLOCID=1, FLAG=MUST;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 335814 | 记录达到最大数量。                                        | 增加的远端FE信息记录超过限定值10。                         | 执行LST REMOTEFE命令查询已添加的远端FE信息记录。 若所需的远端FE信息记录已添加，请直接使用。若所需的远端FE信息记录未添加，请先执行RMV REMOTEFE命令删除不需要的远端FE信息记录，再重新执行本命令添加所需要的远端FE信息记录。 |
