# 查询远端EIR配置(LST REIRCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询已配置的远端EIR数据记录。

- 若需要查询某个远端EIR的配置信息，请输入“远端EIR名称”参数。
- 若需要查询全部远端EIR的配置信息，请不输入任何参数。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                |
|:--------|:--------|:----------------------------------------------------------------------------------------------------|
| EIRNAME | 远端EIR名称 | 可选必选说明：可选参数 参数含义：用于指定系统按照哪个远端EIR名称查询远端EIR数据记录。若不输入，则表示所有的远端EIR名称。 取值范围：长度不超过127的字符串。 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询“远端EIR名称”为“EIR01”的远端EIR数据记录。

   ```
   LST REIRCFG: EIRNAME="EIR01";
   ```

   ```
   %%LST REIRCFG: EIRNAME="EIR01";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
     远端EIR名称  =  EIR01
   远端EIR主机名  =  eir01.huawei.com
     远端EIR域名  =  huawei.com
          优先级  =  5
   (结果个数 = 1)

   ---    END
   ```
2. 查询所有的远端EIR数据记录。

   ```
   LST REIRCFG:;
   ```

   ```
   %%LST REIRCFG:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    远端EIR名称  远端EIR主机名     远端EIR域名  优先级

    EIR01        eir01.huawei.com  huawei.com   5     
    EIR02        eir02.huawei.com  huawei.com   6     
   (结果个数 = 2)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD REIRCFG**命令的参数说明。
