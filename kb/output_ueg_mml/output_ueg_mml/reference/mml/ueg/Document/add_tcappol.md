# 增加手动流控策略配置(ADD TCAPPOL)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损或系统严重过载甚至崩溃，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于在配置数据库中增加一条手动流控策略数据记录。

## 注意事项

- 仅当UDM网元中的话务量超过系统允许的最大容量，会对系统运行稳定产生重大影响时才使用此命令增加流控策略以针对话务量进行流控保障系统的稳定运行。
- 增加流控策略配置后必须通过修改软参（25号软参(HDFLOWCTRLSWITCH)，0：关闭，1：打开）打开流控开关才能使流控策略得到实施。
- 增加流控策略时，允许通过消息数量是针对单个CCU进程，而UDM的业务量会由配置的所有CCU进程共同分担，所以UDM每秒允许通过的总消息数应该是设置的每秒允许通过消息数量与CCU进程个数的乘积。
- 当流控策略为“LSPC1(OPC+SSN)”，如果上行到UDM的消息中没有携带OPC信息，消息将不能被流控。检查消息中是否携带OPC信息的方法请参考检查消息是否携带OPC的方法。
- 已经添加了“流控策略”为“LSPC3(不区分局向)”的记录时，不允许添加“流控策略”为“LSPC1(OPC+SSN)”或“LSPC2(GT+SSN)”的记录。
- 该命令不允许进行批操作。

## 使用实例

1. 增加流控策略，参数按照以下值进行配置：
   - “流控策略索引”=0；
   - “网络指示语”=NAT(国内主用网)；
   - “流控策略”=LSPC1(OPC+SSN)；
   - “主叫信令点编码”=111111；
   - “允许最大消息数”=100；
   - “允许最大位置更新消息数”=10；
   - “允许最大鉴权消息数”=10；
   - “允许最大被叫取路由消息数”=10；
   - “允许最大短消息被叫取路由消息数”=10；
   - “主叫地址子系统号”=SCMG(SCMG 0x01)；
   - “允许最大GPRS位置更新消息数”=10；

   ```
   ADD TCAPPOL: TCIDX=0, NI=NAT, TCMODE=LSPC1, OPC="111111", TOTAL_NUM=100, UPL_NUM=10, AUC_NUM=10, SRI_NUM=10, SRI_SM_NUM=10, SSN=SCMG, GPRS_UPL_NUM=10;
   ```
2. 增加流控策略，参数按照以下值进行配置：
   - “流控策略索引”=1；
   - “网络指示语”=NAT(国内主用网)；
   - “流控策略”=GT+SSN；
   - “主叫GT地址信息”=861390270；
   - “主叫GT类型”=GT4(ITU-T类型4)；
   - “主叫编码计划”=ISDN(ISDN/电话编号计划)；
   - “主叫地址信息指示语”=INTER(国际号码)；
   - “允许最大消息数”=100；
   - “允许最大位置更新消息数”=10；
   - “允许最大鉴权消息数”=10；
   - “允许最大被叫取路由消息数”=10；
   - “允许最大短消息被叫取路由消息数”=10；
   - “主叫地址子系统号”=SCMG(SCMG 0x01)；
   - “允许最大GPRS位置更新消息数”=10；

   ```
   ADD TCAPPOL: TCIDX=1, NI=NAT, TCMODE=LSPC2, GTINFO=K'861390270, GGTIND=GT4, GNUMPLAN=ISDN, GADDRINFOIND=INTER, TOTAL_NUM=100, UPL_NUM=10, AUC_NUM=10, SRI_NUM=10, SRI_SM_NUM=10, SSN=SCMG, GPRS_UPL_NUM=10;
   ```
