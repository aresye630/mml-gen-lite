# 增加本端模拟MME配置(ADD LMMECFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加一条本端模拟MME的数据记录。当UDM将自己模拟为MME与远端EIR通信时，需要先配置一条本端模拟MME的数据记录。

UDM将自己模拟为MME，主动向EIR发送S13接口请求消息，源主机名和源域名需要填写“本端模拟MME主机名”和“本端模拟MME域名”。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

系统中只允许配置一条本端模拟MME数据记录。

## 参数说明

| 参数标识     | 参数名称       | 参数说明                                                                                                                   |
|:---------|:-----------|:-----------------------------------------------------------------------------------------------------------------------|
| MMENAME  | 本端模拟MME名称  | 可选必选说明：必选参数 参数含义：用于标识一个本端模拟MME的名称，全局唯一。 取值范围：长度不超过127的字符串。 默认值：无。 配置原则：该参数不能只输入一个空格，并且字母不区分大小写。                        |
| MMEHOST  | 本端模拟MME主机名 | 可选必选说明：必选参数 参数含义：用于标识本端模拟MME的主机名。 取值范围：1～127位由十进制数字、字母、“_”、“.”或“@”组成的字符串。 默认值：无。 配置原则：该参数不能只输入一个空格，并且字母不区分大小写。         |
| MMEREALM | 本端模拟MME域名  | 可选必选说明：必选参数 参数含义：用于标识本端模拟MME的域名。 取值范围：长度不超过127的字符串。 默认值：无。 配置原则：该参数不能只输入一个空格，并且字母不区分大小写。该参数不允许配置以“.”开头或结尾，或者中间连续两个“.”。 |

## 使用实例

当UDM将自己模拟为MME与远端EIR通信时，执行该命令增加一条本端模拟MME，“本端模拟MME名称”为“MME01”，“本端模拟MME主机名”为“mme.huawei.com”，“本端模拟MME域名”为“huawei.com”。

```
ADD LMMECFG: MMENAME="MME01", MMEHOST="mme.huawei.com", MMEREALM="huawei.com";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释              | 原因分析                                           | 处理建议                                                     |
|-------:|:-------------------|:-----------------------------------------------|:---------------------------------------------------------|
| 264034 | 关键参数取值不能为一个空格      | “本端模拟MME名称”、“本端模拟MME主机名”或“本端模拟MME域名”参数只输入一个空格。 | “本端模拟MME名称”、“本端模拟MME主机名”或“本端模拟MME域名”参数不能只输入一个空格。         |
| 335620 | 参数取值无效：主机名的设定不符合要求 | 输入的“本端模拟MME主机名”参数不在相应的参数取值范围内。                 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                         |
| 335669 | 对象记录达到最大数目         | 系统中只允许配置一条本端模拟MME数据记录。                         | 根据实际情况，执行RMV LMMECFG命令删掉本端模拟MME数据记录，再执行本命令增加本端模拟MME数据记录。 |
| 335675 | 域名不合法              | 输入的“本端模拟MME域名”参数不合法。                           | 根据实际情况，重新输入“本端模拟MME域名”参数，确保满足“本端模拟MME域名”参数的配置原则。         |
