# 删除关键SS7信令点(RMV KEYDSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在FE/BE整体倒换功能中删除关键信令点。

当使用FE/BE整体倒换功能时，FE判断是否关键信令点都故障或正常，如果是，则可以通知BE进行切换或倒回。

## 注意事项

- 使用**LST INSP**查询“NOTIFYSIGNSTATTOBE（是否支持信令链路状态通知到USCDB）”参数，取值为1则该命令有效。
- 删除关键信令点时，使用**RMV SCCPDSP**也可以删除该关键信令点，删除后**LST SCCPDSP**查询不到该信令点信息，同时**RMV KEYDSP**命令的“关键SS7信令点名称”也选择不到已设置的关键信令点。

## 参数说明

| 参数标识      | 参数名称        | 参数说明                                                   |
|:----------|:------------|:-------------------------------------------------------|
| KEYDSPGNM | 关键SS7信令点组名称 | 标识一条SS7关键信令点对端组数据记录的关键字段之一，用于指定需要删除哪一条SS7关键信令点对端组数据记录。 |
| KEYDSPNM  | 关键SS7信令点名称  | 标识一条SS7关键信令点对端数据记录的关键字段之一，用于指定需要删除哪一条SS7关键信令点对端数据记录。   |

## 使用实例

调测SCCP信令的SS7关键对端时，发现“关键SS7信令点组名称”为“HLR01”的关键信令点配置错误，需要将“关键SS7信令点名称”为“C001514792”的关键信令点删除，再执行**ADD KEYDSP**命令新增“D001485883”关键信令点，执行脚本如下：

```
RMV KEYDSP: KEYDSPGNM="HLR01", KEYDSPNM="C001514792";
ADD KEYDSP: KEYDSPGNM="HLR01", KEYDSPNM="D001485883";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释                                 | 原因分析                          | 处理建议                                                          |
|-------:|:-------------------------------------|:------------------------------|:--------------------------------------------------------------|
| 306971 | 关键信令点组不存在，请执行LST KEYDSPG查看配置的关键信令点组。 | 增加关键信令点时，输入的“关键SS7信令点组名称”不存在。 | 执行LST KEYDSPG查看配置的关键信令点组，重新输入“关键SS7信令点组名称”的取值，确保其取值存在、符合要求。   |
| 306973 | 指定的关键信令点不存在。                         | 删除关键信令点时，输入的“关键SS7信令点名称”不存在。  | 执行LST KEYDSPG命令查看已经存在的关键信令点，重新输入“关键SS7信令点名称”的取值，确保其取值存在、符合要求。 |
