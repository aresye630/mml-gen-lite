# 增加关键SS7信令点(ADD KEYDSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在FE/BE整体倒换功能中增加关键信令点。

当使用FE/BE整体倒换功能时，FE判断是否关键信令点都故障或正常，如果是，则可以通知BE进行切换或倒回。

## 注意事项

- 使用**LST INSP**查询“NOTIFYSIGNSTATTOBE（是否支持信令链路状态通知到USCDB）”参数，取值为1则该命令有效。
- 一组关键信令点中最多可以设置6个信令点。
- 一个关键信令点组中不能存在两个相同的关键信令点。
- 一个关键信令点不能同时存在于两个及以上的关键信令点组中。

## 参数说明

| 参数标识      | 参数名称        | 参数说明                                                                                                                                  |
|:----------|:------------|:--------------------------------------------------------------------------------------------------------------------------------------|
| KEYDSPGNM | 关键SS7信令点组名称 | 用于在本局的配置数据库中增加一条唯一标识一个关键信令点组数据。该参数必须先由ADD KEYDSPG命令定义，然后才能在此处索引。 取值范围：长度不超过32位的字符串，字符串只允许输入：0-9，a-z，A-Z，“-”、“_”、“.”、空格符、和中文字符。 默认值：无。 |
| KEYDSPNM  | 关键SS7信令点名称  | 用于在本局的配置数据库中增加一条关键信令点数据，该参数必须先由ADD SCCPDSP命令定义，然后才能在此处索引。 取值范围：长度不超过32的字符串。 默认值：无。                                                    |

## 使用实例

调测SCCP信令的SS7关键对端时，需要为“关键SS7信令点组名称”增加关键信令点。以“关键SS7信令点组名称”取值“HLR01”，“关键SS7信令点名称”取值“D001485883”举例，配置脚本如下：

```
ADD KEYDSP: KEYDSPGNM="HLR01", KEYDSPNM="D001485883";
```
