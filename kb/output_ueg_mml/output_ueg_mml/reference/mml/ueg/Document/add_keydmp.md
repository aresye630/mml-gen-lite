# 增加关键DIAMETER对端(ADD KEYDMP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在FE/BE整体倒换功能中给关键DIAMETER对端组增加关键DIAMETER对端。

将需要监控的Diameter对端链路，设置为关键Diameter对端，并根据需要可以将1～6个关键DIAMETER对端灵活组合到一起，成为关键DIAMETER对端组，实现整体倒换倒回操作。

## 注意事项

- 仅将软参“NOTIFYSIGNSTATTOBE（是否支持信令链路状态通知到USCDB）”值设置为“1”时，该命令配置的数据才能生效。
- 只有通过**ADD DMPE**命令设置的Diameter对端才可以在该命令中增加。通过**RMV DMPE**删除的对端时，如果该对端为关键Diameter对端也将被删除。
- 一个关键DIAMETER对端组最多只支持6个DIAMETER对端。

## 参数说明

| 参数标识      | 参数名称            | 参数说明                                                                                                                                     |
|:----------|:----------------|:-----------------------------------------------------------------------------------------------------------------------------------------|
| KEYDMPGNM | 关键DIAMETER对端组名称 | 用于标识需要增加关键DIAMETER对端的关键DIAMETER对端组的名称。该参数必须先由ADD KEYDMPG命令定义，然后才能在此处索引。 取值范围：长度不超过31位的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 说明：参数取值不能为一个空格 |
| KEYDMP    | 关键Diameter对端名称  | 用于标识需要在关键DIAMETER对端组增加的DIAMETER对端的名称。 取值范围：长度不超过127的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。                                                  |

## 使用实例

增加关键Diameter对端，“关键DIAMETER对端组名称”为“KEYDMPG1”，“关键Diameter对端名称”为“SGSN1”：

```
ADD KEYDMP: KEYDMPGNM="KEYDMPG1", KEYDMP="SGSN1";
```
