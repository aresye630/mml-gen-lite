# 增加Diameter对端实体(ADD DMPE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中增加一条Diameter对端实体的数据记录。当用户需要配置一条通过Diameter信令与对端网元的对接链路时，需要配置一条Diameter对端实体的数据记录。

在该命令中，以下关键参数需要与对端网元（对端局）协商：

- Diameter对端实体类型
- 主机名
- 域名

## 注意事项

- 系统最多允许配置256个Diameter对端实体。
- GBA场景下，当BSF和AP合一部署场景：
  - 系统允许**ADD DMPE**配置的“Diameter对端实体类型”为“AP(AP)”的对端实体的主机名和**ADD DMLE**配置的“本端设备类型”为“AP(AP)”的本端实体的主机名相同。
  - 系统允许**ADD DMPE**配置的“Diameter对端实体类型”为“BSF(BSF)”的对端实体的主机名和**ADD DMLE**配置的“本端设备类型”为“BSF(BSF)”的本端实体的主机名相同。

## 使用实例

UDM需要向对端设备发送一个Diameter请求时，需要添加一个Diameter对端实体。“实体名称”为“AS”，“Diameter对端实体类型”为“AS(AS)”，“主机名”为“as.huawei.com”，“域名”为“huawei.com”，“Diameter对端实体优先级”为“15”。

```
ADD DMPE: EN="AS", PEERTYPE=AS, HN="as.huawei.com", DN="huawei.com", PEPRI=15;
```
