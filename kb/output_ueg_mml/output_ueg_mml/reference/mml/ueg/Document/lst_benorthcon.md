# 查询BE北向配置信息(LST BENORTHCON)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询已配置的BE北向配置信息。

- 当需要查询所有的BE北向配置信息时，请不要输入任何参数。
- 当需要查询某一个对象对应的BE北向配置信息时，请输入“对象名称”参数。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                           |
|:--------|:-------|:-----------------------------------------------------------------------------------------------|
| OBJNAME | 对象名称   | 可选必选说明：可选参数 参数含义：用于标识待查询BE北向配置信息的对象名称，当不输入时，标识查询所有的BE北向配置信息。 取值范围： UD(Ud)RS(Rs) 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询所有BE北向配置信息。

   ```
   LST BENORTHCON:;
   ```

   ```
   %%LST BENORTHCON:;%%
   RETCODE = 0  操作成功

   对象名称   ID         本端网元IP地址    对端网元IP地址                                                                                                                                                                                                                                                                                                                                                   
   Ud         abc        127.12.0.23       10.5.11.55	
   Rs         def        127.12.0.25       10.5.11.60

   (结果个数 = 2)
   ---    END
   ```
2. 查询“对象名称”为“UD(Ud)”的BE北向配置信息。

   ```
   LST BENORTHCON: OBJNAME=UD;
   ```

   ```
   %%LST BENORTHCON: OBJNAME=UD;%%
   RETCODE = 0  操作成功

         对象名称 = Ud
               ID = abc
   本端网元IP地址 = 127.12.0.23
   对端网元IP地址 = 10.5.11.55

   (结果个数 = 1)
   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET BENORTHCON**命令的参数说明。
