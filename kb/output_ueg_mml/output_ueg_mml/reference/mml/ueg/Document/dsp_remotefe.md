# 查询远端FE状态(DSP REMOTEFE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于在配置数据库中查询远端FE的状态信息。

- 若需要查询全部远端FE的状态信息，请不要输入任何参数。
- 若需要查询某个远端FE的状态信息，请输入“远端Location ID”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称          | 参数说明                                       |
|:-------|:--------------|:-------------------------------------------|
| RLOCID | 远端Location ID | 用于指示系统查询哪个远端FE的状态信息；若不输入，则表示查询所有的远端FE状态信息。 |

## 使用实例

1. 查询所有远端FE的状态信息。命令如下：

   ```
   DSP REMOTEFE:;
   ```

   ```
   %%DSP REMOTEFE:;%%
   RETCODE = 0  操作成功

   远端FE信息
   ----------
    远端location ID  检测标识  关键局向故障权重  亚健康状态   亚健康容灾执行结果   时间戳             

    252              MUST      0                 正常态       倒换成功             2017-12-24 04:22:58
    253              MUST      0                 故障态       倒换失败             2017-12-24 04:22:57
   (结果个数 = 2)

   ---    END
   ```
2. 查询“远端Location ID”为“252”的远端FE的状态信息。命令如下：

   ```
   DSP REMOTEFE： RLOCID=252;
   ```

   ```
   %%DSP REMOTEFE: RLOCID=252;%%
   RETCODE = 0  操作成功

   远端FE信息
   ----------
     远端location ID  =  252
            检测标识  =  MUST
    关键局向故障权重  =  10
          亚健康状态  =  正常态
   亚健康容灾执行结果 =  倒换成功
              时间戳  =  2017-12-26 03:22:55
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，表1列出的参数是未包含在**ADD REMOTEFE**命令中的输出项，其他输出项的详细说明请参见**ADD REMOTEFE**命令的参数说明。

| 输出项名称     | 输出项解释                                                                                                                                                                                                                                                                                                                                          |
|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 检测标识      | 表示远端FE的状态检测标识。 说明：当返回的“检测标识”为空时，表示数据库中存在冗余数据，可根据如下情况进行处理：远端FE实际的Location ID已经被修改，此时无法通过该命令查询远端FE状态。“远端Location ID”跟实际远端FE的Location ID不匹配，请修改“远端Location ID”与实际相符后再通过本命令查询远端FE状态。                                                                                                                                                               |
| 关键局向故障权重  | 表示远端FE故障关键局向的权重。 说明：当返回的“关键局向故障权重”为空时，表示数据库中数据缺失，可根据如下情况进行处理：OMU侧配置的远端FE数据冗余，请通过RMV REMOTEFE命令删除冗余配置。“远端Location ID”跟实际远端FE的Location ID不匹配，请修改“远端Location ID”与实际相符后再通过本命令查询远端FE状态。远端FE&本端BE或本端BE&远端BE之间对接异常，请先恢复远端FE&本端BE或本端BE&远端BE之间对接关系后再通过本命令查询远端FE状态。                                                                                      |
| 亚健康状态     | 表示本地FE的亚健康状态。 说明： 初始态正常态故障态非稳态未知态                                                                                                                                                                                                                                                                                                              |
| 亚健康容灾执行结果 | 表示本地FE亚健康倒换执行结果。 说明： 初始态未倒换倒换失败倒换成功                                                                                                                                                                                                                                                                                                            |
| 时间戳       | 表示远端FE状态的更新时间。 说明：当返回的“时间戳”为空时，表示数据库中数据缺失，可根据如下情况进行处理：OMU侧配置的远端FE数据冗余，请通过RMV REMOTEFE命令删除冗余配置。“远端Location ID”跟实际远端FE的Location ID不匹配，请修改“远端Location ID”与实际相符后再通过本命令查询远端FE状态。远端FE&本端BE或本端BE&远端BE之间对接异常，请先恢复远端FE&本端BE或本端BE&远端BE之间对接关系后再通过本命令查询远端FE状态。 当返回的“时间戳”连续多次无变化时，表示远端FE&本端BE或本端BE&远端BE之间对接异常，请先恢复远端FE&本端BE或本端BE&远端BE之间对接关系后再通过本命令查询远端FE状态。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释      | 原因分析       | 处理建议                                                                         |
|------:|:-----------|:-----------|:-----------------------------------------------------------------------------|
|   216 | 查询BE数据库失败。 | 查询BE数据库超时。 | 通过DSP NODE命令检查BE状态和DSP DSGSCTP命令检查FE&BE链接状态，确保BE状态和FE&BE链接正常后再执行本命令查询远端FE状态。 |
