# 修改NAFID群组数据(MOD NAFGRPDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于对配置数据库中某个网络应用功能组下的NAFID列表信息进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识网络应用功能组下的NAFID列表信息：

- NAF GROUP编号
- 旧FQDN

  **说明** 

  该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称        | 参数说明                                                                                                                                                                       |
|:--------|:------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NAFGRP  | NAF GROUP编号 | 标识NAFID列表信息的关键字段之一（其取值不能被修改），用于指定需要对哪一个网络应用功能组下的NAFID列表信息进行修改或调整，操作员可以使用LST NAFGROUP命令查询获得。 取值范围：1～65535。 默认值：无。 注意：该参数为必选参数。                                              |
| OLDFQDN | 旧FQDN       | 标识NAFID列表信息的关键字段之一，用于指定需要对哪一个网络应用功能组下的全量域名信息进行修改或调整，操作员可以使用LST NAFGRPDATA命令查询获得。 需要指出的是，该参数不区分大小写，在执行LST NAFGRPDATA命令查询出的报文中为全小写形式。 取值范围：长度不超过127的字符串。 默认值：无。 注意：该参数为必选参数。 |
| NEWFQDN | 新FQDN       | 用于在配置数据库中为指定的网络应用功能组定义一个AP的新全量域名信息。 需要指出的是，该参数不区分大小写，在执行LST NAFGRPDATA命令查询出的报文中为全小写形式。 取值范围：长度不超过127的字符串。 默认值：无。 注意：该参数为必选参数。                                              |

## 使用实例

修改NAFID群组数据，携带以下参数：

- “NAF GROUP编号”为“1”
- “旧FQDN”为“1”
- “新FQDN”为“2”

执行命令如下：

```
MOD NAFGRPDATA: NAFGRP=1, OLDFQDN="1", NEWFQDN="2";
```
