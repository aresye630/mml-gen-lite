# 显示SCCP屏蔽流量(DSP SCCPPOL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询指定的SCCP屏蔽流量的基本信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                                |
|:-------|:-----------|:----------------------------------------------------------------------------------------------------|
| MN     | CCU模块号     | 用于请求系统按照哪个模块号（处理SCCP协议的CCU进程的模块号）来显示SCCP屏蔽流量信息。可以使用LST MODULE命令查询已经存在的模块。 取值范围：1～1023。 默认值：无。 说明：无。 |
| SCCPNM | SCCP屏蔽策略名称 | 用于请求系统按照哪个SCCP屏蔽策略名称来查询SCCP屏蔽流量信息。 取值范围：无。 默认值：无。 说明：无。                                             |

## 使用实例

显示SCCP屏蔽流量“模块号”为“2”，“SCCP屏蔽策略名称”为“SCCPPOL”：

```
DSP SCCPPOL: MN=2, SCCPNM="SCCPPOL";
```

返回结果如下：

```
%%DSP SCCPPOL: MN=2, SCCPNM="SCCPPOL";%%
RETCODE = 0  操作成功。

SCCP屏蔽流量信息
----------------
SCCP屏蔽策略名称  =  SCCPPOL
        流量单位  =  每小时
          流量值  =  0
        流量阈值  =  0
        是否溢出  =  否
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出结果解释                                                                         |
|:--------|:-------------------------------------------------------------------------------|
| 屏蔽策略名称  | 用于返回SCCP屏蔽策略的名称。                                                               |
| 流量单位    | 用于返回系统按照什么样的时间单位来对本局接收到的SCCP信令消息实施流量控制，系统默认值为“小时”。                             |
| 流量值     | 用于返回在单位时间内通过的SCCP信令消息包（MSU）的实际数量。                                              |
| 流量阈值    | 用于返回在单位时间内各CCU所允许通过的SCCP信令消息包（MSU）的最大数量。                                       |
| 是否溢出    | 用于返回SCCP信令消息包是否溢出。 是：表示CCU接收到的SCCP信令消息包数已超过流量阈值。 否：表示CCU接收到的SCCP信令消息包数在流量阈值以内。 |
