# 添加用户数据统计扩展对象(ADD STRNGEX)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加一个用户数据统计对象的配置信息。

该命令的使用场景为：用户数据在配置库中已存在，基本属性已设置及相关业务已开通的情况下，需要统计某种维度用户数量时使用。

## 注意事项

该命令的配置信息必须与USCDB网元侧STRNGEX配置信息同步并保持一致。

请先在

“USCDB MML命令”

界面，执行

**ADD STRNGEX**

命令添加

“网元类型”

为

“HSS9860”

的统计对象，然后在

“UDM MML命令”

界面执行本命令添加

“统计对象ID”

与USCDB侧STRNGEX相同，

“统计类型”

与USCDB侧STRNGEX相匹配的扩展统计对象。在USCDB和UDM上添加了相应的统计对象后，才能在网管上创建测量任务。UDM与USCDB统计类型对应关系如表1所示。

| USCDB侧                           | UDM侧                           |
|:---------------------------------|:-------------------------------|
| STAT_ALL（对所有用户进行统计）              | STAT_ALL（对所有用户进行统计）            |
| STAT_SN（按HLRSN统计）                | STAT_SN（按HLRSN统计）              |
| STAT_NUMBER（按号段统计）               | STAT_NUMBER（按号段统计）             |
| STAT_RN（按RN统计）                   | STAT_RN（按RN统计）                 |
| STAT_MULTIRN（按源RN和目的RN统计）        | STAT_MULTIRN（按源RN和目的RN统计）      |
| STAT_MMEHOSTPOSTFIX（按MME主机名后缀统计） | STAT_MMEHOST（按MME主机名统计）        |
| STAT_VLRNUMPREFIX（按VLRNUM前缀统计）   | STAT_VLRNUMPREFIX（按VLRNUM前缀统计） |

- 当“统计类型”参数取值为“STAT\_MMEHOST”时，该命令中的“PLMN”和“GUMMEI”参数必须且只能存在一个。

- 主备容灾场景下，主用局执行该命令增加一个用户数据统计对象时，备用局需要同步增加。

## 参数说明

| 参数ID     | 参数名称   | 参数描述                                                                                                                                                                                                                                                                                                                                                                                 |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OBJECTID | 统计对象ID | 用于标识用户数据库中一个唯一统计对象ID。 取值范围：OBJECT0(统计对象0)～OBJECT829(统计对象829) 默认值：无。 说明：在加载业务网元插件包时，系统自动增加一个对象ID为OBJECT0的统计对象，针对所有用户进行统计，因此统计对象OBJECT0只允许查询，不允许添加、删除和修改。                                                                                                                                                                                                                              |
| TYPE     | 统计类型   | 用于标识待添加的用户统计对象属于哪个统计类型。 取值范围： STAT_ALL（对所有用户进行统计）：表示对所有用户数据进行统计。STAT_SN（按HLRSN统计）：表示按照HLR序列号对用户数据进行统计。STAT_NUMBER（按号段统计）：表示按照号段对用户数据进行统计。STAT_RN（按RN统计）：表示按照路由码对用户数据进行统计。STAT_MULTIRN（按源RN和目的RN统计）：表示于统计指定源路由码和目的路由码范围内的用户数量。与按RN统计区别是：按源RN与目的RN统计包含于按RN统计，明确用户从哪个运营商转到哪个运营商。STAT_MMEHOST（按MME主机名统计）：表示按照MME主机名对用户数据进行统计。STAT_VLRNUMPREFIX（按VLRNUM前缀统计）：表示按照VLR号码前缀对用户数据进行统计。 默认值：无。 |
| BEGINNUM | 统计起始号码 | 仅当本命令中的“统计类型”为“STAT_NUMBER（按号段统计）”时该参数有效。用于标识以哪个MSISDN号码为起始号码的号段进行用户数据统计。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                              |
| ENDNUM   | 统计结束号码 | 仅当本命令中的“统计类型”为“STAT_NUMBER（按号段统计）”时该参数有效。用于标识以哪个MSISDN号码为结束号码的号段进行用户数据统计。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                              |
| HLRSN    | HLR序列号 | 仅当本命令中的“统计类型”为“STAT_SN（按HLRSN统计）”或“STAT_RN（按RN统计）”时该参数有效。用于标识对哪个虚拟HLR的用户数据进行统计。 取值范围：1～255 默认值：无。                                                                                                                                                                                                                                                                                    |
| RN       | 路由码    | 仅当本命令中的“统计类型”为“STAT_RN（按RN统计）”时该参数有效。用于标识对哪个路由码的用户数据进行统计。 取值范围：1～10位字母或十进制数字组成的字符串。 默认值：无。 说明：该参数一般由运营商规划，用于标识不同运营商的不同网络，操作员在配置时可向运营商获取。                                                                                                                                                                                                                                             |
| SRCRN    | 源路由码   | 仅当本命令中的“统计类型”为“STAT_MULTIRN（按源RN和目的RN统计）”时该参数有效。用于标识对以哪个路由码为源路由码的用户数据进行统计。 取值范围：1～10位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                          |
| DESRN    | 目的路由码  | 仅当本命令中的“统计类型”为“STAT_MULTIRN（按源RN和目的RN统计）”时该参数有效。用于标识对以哪个路由码为目的路由码的用户数据进行统计。 取值范围：1～10位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                         |
| MMEHOST  | MME主机名 | 仅当本命令中的“统计类型”为“STAT_MMEHOST（按MME主机名统计）”时该参数有效。用于标识对哪个MME主机名下的用户数据进行统计。 取值范围：1～128位字母或字母与十进制数字（字母在前）组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                    |
| GUMMEI   | GUMMEI | 仅当本命令中的“统计类型”为“STAT_MMEHOST（按MME主机名统计）”时该参数有效。用于标识按MME主机名统计时，需要统计的用户数据属于哪个GUMMEI。GUMMEI用于标识网管上MME显示的名称，可以命名为Globally Unique MME Identifier，即MME全球识别码。 取值范围：1～32位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                               |
| VLRNUM   | VLR号码  | 仅当本命令中的“统计类型”为“STAT_VLRNUMPREFIX（按VLRNUM前缀统计）”时该参数有效。用于标识对哪个VLR的用户数据进行统计。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                              |
| PLMN     | PLMN   | 仅当本命令中的“统计类型”为“STAT_MMEHOST（按MME主机名统计）”时该参数有效。用于标识按MME主机名统计时，需要统计的用户数据属于哪个PLMN。 取值范围：由1～32位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                    |

## 使用实例

1. 增加用户数据统计对象，“统计对象ID”为“OBJECT2”，按HLRSN统计，“HLR序列”号为“1”：

   ```
   ADD STRNGEX: OBJECTID=OBJECT2, TYPE=STAT_SN, HLRSN=1;
   ```
2. 增加用户数据统计对象，“统计对象ID”为“OBJECT3”，按号段统计，“统计起始号码”为“13500000000”，“统计结束号码”为“13599999999”：

   ```
   ADD STRNGEX: OBJECTID=OBJECT3, TYPE=STAT_NUMBER, BEGINNUM="13500000000", ENDNUM="13599999999";
   ```
3. 增加用户数据统计对象，“统计对象ID”为“OBJECT4”，按路由码统计，“路由码”为“12345ABCDE”：

   ```
   ADD STRNGEX: OBJECTID=OBJECT4, TYPE=STAT_RN, RN="12345ABCDE";
   ```
4. 增加用户数据统计对象，“统计对象ID”为“OBJECT5”，按源路由码和目的路由码统计，“源路由码”为“13555ABCDE”，“目的路由码”为“13666ABCDE”：

   ```
   ADD STRNGEX: OBJECTID=OBJECT5, TYPE=STAT_MULTIRN, SRCRN="13555ABCDE", DESRN="13666ABCDE";
   ```
5. 增加用户数据统计对象，“统计对象ID”为“OBJECT6”，按MME主机名统计，“MME主机名”为“mme.huawei.com”，“PLMN”为“huawei500”：

   ```
   ADD STRNGEX: OBJECTID=OBJECT6, TYPE=STAT_MMEHOST, MMEHOST="mme.huawei.com", PLMN="huawei500";
   ```
6. 增加用户数据统计对象，“统计对象ID”为“OBJECT7”，按VLRNUM前缀统计，“VLR号码”为“123456789012345”：

   ```
   ADD STRNGEX: OBJECTID=OBJECT7, TYPE=STAT_VLRNUMPREFIX, VLRNUM="123456789012345";
   ```
