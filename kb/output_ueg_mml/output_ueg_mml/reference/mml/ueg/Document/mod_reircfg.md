# 修改远端EIR配置(MOD REIRCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改一条远端EIR数据记录。在该命令中，系统通过“远端EIR名称”参数来唯一标识一条远端EIR配置信息。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                                                |
|:---------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| EIRNAME  | 远端EIR名称  | 可选必选说明：必选参数 参数含义：标识一条远端EIR数据记录的关键字段（其取值不能被修改），用于指定需要对哪个远端EIR名称对应的远端EIR数据记录进行修改或调整，操作员可以使用LST REIRCFG命令查询获得。 取值范围：长度不超过127的字符串。 默认值：无。 配置原则：该参数不能只输入一个空格，并且字母不区分大小写。 |
| EIRHOST  | 远端EIR主机名 | 可选必选说明：可选参数 参数含义：用于标识远端EIR的主机名。 取值范围：1～127位由十进制数字、字母、“_”、“.”或“@”组成的字符串。 默认值：无。 配置原则： 该参数不能只输入一个空格，并且字母不区分大小写。远端EIR主机名不能重复。                                          |
| EIRREALM | 远端EIR域名  | 可选必选说明：可选参数 参数含义：用于标识远端EIR的域名。 取值范围：长度不超过127的字符串。 默认值：无。 配置原则： 该参数不能只输入一个空格，并且字母不区分大小写。该参数不允许配置以“.”开头或结尾，或者中间连续两个“.”。                                               |
| PRI      | 优先级      | 可选必选说明：可选参数 参数含义：用于标识远端EIR的优先级。 取值范围：1～250。 默认值：无。 配置原则： 取值越小，优先级越高，取值相同时表示优先级相同。业务使用时优先选取优先级高的记录，如果存在多条相同优先级的记录，则轮询选择。                                             |

## 使用实例

修改一条远端EIR数据记录，“远端EIR名称”为“EIR01”，“远端EIR主机名”为“eir01.huawei.com”，“远端EIR域名”为“huawei.com”。

```
MOD REIRCFG: EIRNAME="EIR01", EIRHOST="eir01.huawei.com", EIRREALM="huawei.com";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释              | 原因分析                                    | 处理建议                                                                                |
|-------:|:-------------------|:----------------------------------------|:------------------------------------------------------------------------------------|
| 264034 | 关键参数取值不能为一个空格      | “远端EIR名称”参数只输入一个空格。                     | “远端EIR名称”参数不能只输入一个空格。                                                               |
| 335620 | 参数取值无效：主机名的设定不符合要求 | 输入的“远端EIR主机名”参数不在相应的参数取值范围内。            | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                    |
| 335675 | 域名不合法              | 输入的“远端EIR域名”参数不合法。                      | 根据实际情况，重新输入“远端EIR域名”参数，确保满足“远端EIR域名”参数的配置原则。                                        |
| 335876 | 指定的名称不存在           | “远端EIR名称”参数对应的远端EIR数据记录不存在。             | 可以先通过LST REIRCFG命令查询“远端EIR名称”对应的远端EIR数据记录是否存在。                                      |
| 335964 | 主机名已存在             | 输入的“远端EIR主机名”参数与系统中已存在的EIR远端数据记录的主机名相同。 | 根据实际情况，重新输入参数，确保输入的“远端EIR主机名”参数和系统中已存在的不重复。可执行LST REIRCFG命令查询系统中是否已存在待增加的远端EIR数据记录。 |
