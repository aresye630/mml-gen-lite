# 增加Diameter局向统计对象(ADD STATDIAMHOST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加Diameter局向消息的统计对象。

在对Diameter局向消息进行统计时，执行此命令增加Diameter局向消息的统计对象。

## 注意事项

最多增加800个Diameter局向统计对象。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                        |
|:-----------|:-------|:----------------------------------------------------------------------------|
| OBJECTNAME | 统计对象名称 | 用于标识Diameter局向统计对象的名称。 取值范围：长度不超过127的字符串。 默认值：无。                            |
| MSGAPP     | 消息应用类型 | 用于标识Diameter局向统计对象的指定消息接口类型。 取值范围：S6a(S6a) 默认值：无。                           |
| HN         | 主机名    | 用于标识Diameter局向统计对象在所属域中的网络主机名。 取值范围：长度不超过127的字符串。 默认值：无。 说明：“主机名”为对端网元的主机名。 |

## 使用实例

增加Diameter局向统计对象，“统计对象名称”为“mme\_1”，“消息应用类型”为“S6a(S6a)”，“主机名”为“mme.huawei1.com”：

```
ADD STATDIAMHOST: OBJECTNAME="mme_1", MSGAPP=S6a, HN="mme.huawei1.com";
```

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。
