# 查询CHR话单功能输出策略(LST CHRPLCY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询所有消息的CHR单据生成策略。

## 注意事项

当前版本不支持此功能，执行该命令后会返回错误码：“335607 暂不支持该功能”。

## 参数说明

无。

## 使用实例

查询所有消息的CHR单据生成策略：

```
LST CHRPLCY:;
```

```
%%LST CHRPLCY:;%%
RETCODE = 0  操作成功

查询结果如下
------------

```

## 输出结果说明

请参见**ADD CHRPLCY**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释    | 原因分析                | 处理建议                                                                                                     |
|-------:|:---------|:--------------------|:---------------------------------------------------------------------------------------------------------|
| 335607 | 暂不支持该功能。 | 当前版本不支持此功能。         | 无需处理。                                                                                                    |
| 335821 | 记录不存在。   | 要删除的CHR话单输出策略记录不存在。 | 请按照一下步骤进行操作： 执行命令LST CHRPLCY查询已添加的所有消息的CHR单据生成策略记录。根据查询结果重新输入参数“消息接口”，“消息类型”或“IMSI号段”，确保这三个参数唯一确定的记录已存在。 |
