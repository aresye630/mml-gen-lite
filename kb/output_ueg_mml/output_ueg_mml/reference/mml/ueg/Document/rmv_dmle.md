# 删除Diameter本端实体(RMV DMLE)

## 命令功能

**须知** 

本命令属于高危命令，执行该命令可能导致ESN变动，ESN变动后需要在60天内重新申请并加载License文件。执行不当可能导致Diameter本端实体与对端实体间的业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除一条Diameter本端实体数据记录。

## 注意事项

- 在正常情况下，该命令仅在开局时由开局工程师在数据调测的过程中使用。
- 删除Diameter本端实体前，必须先使用**RMV DMLNK**和**RMV DMLKS**命令删除相关的Diameter链路和链路集。
- 该命令不允许进行批操作。
- UDM产品的ESN信息与License有关，当局点的ESN信息中存在主机名时，若执行该命令删除一条Diameter本端实体的数据记录，使本局Diameter本端实体表中Index值最小的主机名发生改变，则会导致ESN变动，需要重新申请License文件，请谨慎操作。
- 如果删除的Diameter本端实体中的主机名，已经在HLRSNOFI命令中配置使用，删除Diameter本端实体将导致HLRSNOFI多主机名业务处理异常。请在华为技术支持指导下执行该操作。
- 如果删除的Diameter本端实体名称已经在DMRTS命令中配置使用，删除Diameter本端实体时系统会报错。如确认删除该Diameter本端实体记录，请先执行**MOD DMRTS**命令删除该Diameter本端实体与Diameter路由组的关联关系，再执行本命令删除该Diameter本端实体记录。
- 如果删除的Diameter本端实体名称已经在LOCALINFO命令中配置使用，删除Diameter本端实体时系统会报错。如确认删除该Diameter本端实体记录，请先执行**RMV LOCALINFO**命令删除为该Diameter本端实体配置的本局信息，再执行本命令删除该Diameter本端实体记录。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                       |
|:-------|:-------|:---------------------------------------------------------------------------|
| EN     | 实体名称   | 标识一条Diameter本端实体数据记录的关键字段，用于指定删除哪一条Diameter本端实体数据记录，操作员可以使用LST DMLE命令查询获得。 |

## 使用实例

删除Diameter本端实体。“实体名称”为“HSS”。

```
RMV DMLE: EN="HSS";
```
