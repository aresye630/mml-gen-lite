# 设置DSG链路条数(SET LINKNUM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致业务呼损，需联系华为技术支持确认后再执行。

用于设置DSG之间的链路条数，DSG建链只限定与同应用类型之间的DSG，不同应用类型之间的DSG无链路。搭建网元时，为避免大容量场景下DSG链路数过多的问题，可以使用**SET LINKNUM**来设定DSG之间的链路条数，以达到减少链路条数的目的。最小链路条数为4。

## 注意事项

该命令不允许进行批操作。

FE与BE互联时，假设FE的DSG个数为m，BE的DSG个数为n，分为以下几种场景：

- 当n小于等于8时，采用全互联的方式，不需要设置LINKNUM。

- 当n大于8时，BE侧DSG个数除以FE侧DSG个数大于4时，即x=n/m，当4<x时，FE侧DSG只向BE侧发起x个DSG发送建链请求，不需要设置LINKNUM。

- 当n大于8时，BE的DSG个数除以FE的DSG个数小于4时，即x=n/m， 当x<=4时，FE的DSG向BE的DSG按照配置建立LINKNUM条链路，但是实际链路数不超过全互联的链路数；当链路数大于32时，需要设置LINKNUM为小于32的值。

- FE和BE的链路数LINKNUM设置需一致。系统中LINKNUM默认为8，不修改默认值的情况下，不需要设置LINKNUM，也无法使用LST LINKNUM查询系统默认值。 需要修改LINKNUM默认值的时候，需要用**SET LINKNUM**命令。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                           |
|:--------|:-------|:-----------------------------------------------|
| LINKNUM | 链路数    | 用于设置FE与BE之间的链路条数。 取值范围： 4～512 默认值：无。 系统初始设置值：8 |

## 使用实例

1. 设置DSG链路数为16，执行如下命令：

   ```
   SET LINKNUM: LINKNUM=16;
   ```
