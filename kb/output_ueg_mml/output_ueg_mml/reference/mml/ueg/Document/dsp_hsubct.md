# 查看HSS用户统计结果(DSP HSUBCT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行该命令会对性能有影响，建议在话务量低时执行。

该命令用于按照HSS用户的类型查询用户数的实时统计结果。

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识     | 参数名称               | 参数说明                                                                                                                                                                                                                                                                                                                                         |
|:---------|:-------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HCTTYPE  | HSS用户统计类型          | 用于标识需要统计的HSS用户的类型。 取值范围： “HSS_IMPI(统计IMPI用户数量)”“HSS_DIMPU(统计非通配IMPU用户数量)”“HSS_WIMPU(统计通配IMPU用户数量)”“HSS_PISI(统计PISI用户数量)”“HSS_DPUSI(统计非通配PUSI用户数量)”“HSS_WPUSI(统计通配PUSI用户数量)”“HSS_IMSI(统计IMSI用户数量)”“HSS_MSISDN(统计MSISDN用户数量)”“HSS_SUBID(统计SUBID用户数量)”“HSS_SP_IMPU(统计Service Provider用户数量)”“HSS_PU(统计PU的数量)”“HSS_ALL_USERID(统计各种用户标识数量)” 默认值：无。 |
| SPID     | Service provider标识 | 仅当本命令中的“HSS用户统计类型”参数为“HSS_SP_IMPU”时该参数有效。用于标识HSS用户的服务提供商。 取值范围：长度不超过40位的字符串。 默认值：无。                                                                                                                                                                                                                                                          |
| HMTCHSTR | HSS用户统计匹配字符串       | 仅当本命令中的“HSS用户统计类型”参数为“HSS_PU”时该参数有效。用于标识HSS用户统计的匹配字符串。只有匹配该字符串的用户号码才会被统计。 取值范围：长度不超过127位的字符串。 默认值：无。 说明：“HSS用户统计类型”参数为“HSS_PU”指统计开户的IMPU数量。                                                                                                                                                                                                  |

## 使用实例

1. 查询IMPI用户数量。

   `DSP HSUBCT: HCTTYPE=HSS_IMPI;`

   ```
   %%DSP HSUBCT: HCTTYPE=HSS_IMPI;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
   HSS用户统计类型  =  统计IMPI用户数量
   HSS用户统计结果  =  3
   (结果个数 = 1)

   ---    END
   ```
2. 通配查询关键字为sip的所有的PU用户数量。

   `DSP HSUBCT: HCTTYPE=HSS_PU, HMTCHSTR="sip";`

   ```
   %%DSP HSUBCT: HCTTYPE=HSS_PU, HMTCHSTR="sip";%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
   HSS用户统计类型  =  统计PU的数量
   HSS用户统计结果  =  61
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

| 输出项名称     | 输出结果解释            |
|:----------|:------------------|
| HSS用户统计类型 | 用于返回已统计的HSS用户类型。  |
| HSS用户统计结果 | 用于返回该用户类型对应的用户个数。 |
