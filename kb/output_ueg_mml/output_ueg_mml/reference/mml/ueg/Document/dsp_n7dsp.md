# 显示MTP目的信令点(DSP N7DSP)

- 命令功能

- 参数说明

- 输出结果说明

## 命令功能

该命令为维护类命令，用于请求系统显示MTP目的信令点状态信息。

网络层是MTP的第三级功能（MTP3），它完成OSI第三层（网络层）的功能，用于在信令网中当信令链路和信令转接点发生故障的情况下，为保证可靠地传递各种信令消息，在信令点之间传送管理消息。

## 注意事项

该命令的“目的信令点名称”参数支持模糊查询功能。模糊查询功能是指操作员在LMT输入查询参数时，对于字符串或BCD码类型的查询参数而言，如果操作员输入的是一个完整的字符串或BCD码，则表示系统将按照完全匹配的方式执行查询操作；如果操作员在输入的某个字符串或BCD码的末尾添加通配字符“%”，则表示系统将按照模糊匹配的方式执行查询操作。对于此类参数，其配置原则是：

- 该参数的值域范围为：数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“\_”、“.”、空格符、中文。
- 操作员只能在字符串或BCD码的末尾添加通配字符“%”，而不能在字符串或BCD码的前面、中间添加通配字符“%”。例如，“A市%”、“1390123%”是合法的输入，而“%A市”、“A市%区”、“%1390123”、“139%0123”均是不合法的输入。
- 如果某个命令同时存在有多个字符串或BCD码类型的查询参数，则操作员在一次查询操作中，只能对其中的一个查询参数使用模糊查询方式，而不能同时对两个或两个以上的查询参数使用模糊查询方式。

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                               |
|:-------|:-----------|:-----------------------------------------------------------------------------------|
| MN     | CCU/BSG模块号 | 用于指定处理该MTP链路协议的BSG模块的模块号。该参数必须先由ADD MODULE命令定义，然后才能在此处索引。 取值范围：1～1023 默认值：无。 说明：无。 |
| DPNM   | 目的信令点名称    | 用于请求系统显示哪个MTP目的信令点的状态信息。 取值范围：1～32 位字符串 默认值：无。 说明：无。                               |

## 使用实例

1、显示MTP目的信令点，“目的信令点名称”为“STP”：

```
DSP N7DSP: DPNM="STP";
```

返回结果如下:

```
%%DSP N7DSP: DPNM="STP";%%
RETCODE = 0  操作成功

查询DSP状态响应
---------------
                  目的信令点名称  =  STP
                       网络指示  =  国内主用网
                  目的信令点编码  =  H'000092
                    源信令点编码  =  H'000096
                         访问性  =  可达
                       拥塞信息  =  未拥塞

(结果个数 = 1)

---    END
```

2、显示名称前缀为“STP”的MTP目的信令点：

```
DSP N7DSP: DPNM="STP%";
```

返回结果如下:

```
%%DSP N7DSP: DPNM="STP%";%%
RETCODE = 0  操作成功

查询DSP状态响应成功
-------------------
 目的信令点名称  网络指示    目的信令点编码  源信令点编码  访问性  拥塞信息

 STP1            国内主用网  H'888888        H'000092      未知    未拥塞  
 STP             国内主用网  H'000092        H'000092      可达    未拥塞  
(结果个数 = 2)

---    END
```

## 输出结果说明

| 输出项名称   | 输出结果解释                                                                                         |
|:--------|:-----------------------------------------------------------------------------------------------|
| 目的信令点名称 | 用于返回指定目的信令点对应的名称。                                                                              |
| 目的信令点编码 | 用于返回当前目的信令点在No.7信令网中的信令点编码。                                                                    |
| 源信令点编码  | 用于返回当前目的信令点对应的源信令点在No.7信令网中的信令点编码。                                                             |
| 网络指示    | 用于返回当前链路所属的信令网，它可以是“国际主用网”、“国际备用网”、“国内主用网”或“国内备用网”。                                            |
| 访问性     | 用于返回当前目的信令点的状态： 不可达：表示到达该MTP目的信令点的链路均出现异常，不能传输信令业务消息。 可达：表示到达该MTP目的信令点的链路至少有一个运行正常，可以传输信令业务消息。 |
| 拥塞信息    | 用于返回当前目的信令点间的拥塞信息： 拥塞：表示到达该MTP目的信令点的链路消息流量过大而产生拥塞。 未拥塞：表示到达该MTP目的信令点的链路消息流量正常。                 |
