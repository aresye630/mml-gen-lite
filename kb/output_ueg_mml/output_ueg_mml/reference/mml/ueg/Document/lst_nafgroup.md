# 查询NAFGROUP群组名称(LST NAFGROUP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询网络应用功能群组信息：

- 若需要查询某个网络应用功能群组信息，请输入“NAF GROUP编号”。
- 若需要查询所有的网络应用功能群组信息，请不要输入任何参数。

  **说明** 

  该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称        | 参数说明                                                                                           |
|:-------|:------------|:-----------------------------------------------------------------------------------------------|
| NAFGRP | NAF GROUP编号 | 用于指示系统需要按照哪个NAF GROUP编号来查询网络应用功能群组信息；若不输入，表示查询所有的网络应用功能群组信息。 取值范围：1～65535。 默认值：无。 注意：该参数为可选参数。 |

## 使用实例

1. 查询网络应用功能群组信息，不携带参数：

   ```
   LST NAFGROUP:;
   ```

   返回结果如下：

   ```
   %%LST NAFGROUP:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    NAF GROUP编号  NAF GROUP名称

    1              NAF1        
    2              NAF2        
    7              NAF7        
   (结果个数 = 3)

   ---    END
   ```
2. 查询网络应用功能群组信息，“NAF GROUP编号”为“1”：

   ```
   LST NAFGROUP: NAFGRP=1;
   ```

   返回结果如下：

   ```
   %%LST NAFGROUP: NAFGRP=1;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
   NAF GROUP编号  =  1
   NAF GROUP名称  =  NAF1
   (结果个数 = 1)

   ---    END
   ```
