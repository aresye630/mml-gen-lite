# 查询本局信令点 (LST OFI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于在配置数据库中查询本局信息、本局相关信令点的属性及已配置的其他属性的相关信息。

- 若需要查询全部本局信息数据记录的概要信息，无需输入参数。
- 若需要查询某条本局信息数据记录的详细信息，请输入“本局信令点索引”或“本局名称”参数。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                    |
|:-------|:--------|:------------------------------------------------------------------------|
| IDX    | 本局信令点索引 | 用于指示系统需要按照哪个本局信令点索引来查询本局信息数据；若不输入，则表示所有的本局信令点索引。 取值范围：0～15 默认值：无。 说明：无。 |
| OFN    | 本局名称    | 用于指示系统按照哪个本局名称来查询信令点的相关配置信息 取值范围：长度不超过32的字符串 默认值：无。 说明：无。               |

## 使用实例

查询所有本局信息：

```
LST OFI:;
```
