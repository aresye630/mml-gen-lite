# 删除IMSI前缀和HLRSN(RMV IMSIHLRSN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条IMSI前缀和HLRSN的对应关系数据记录。

## 注意事项

当执行该命令删除IMSI前缀和HLRSN的对应关系数据后，系统将无法通过IMSI前缀获取用户的本局相关信息，会造成用户不能正常使用业务，请谨慎操作。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                    |
|:-----------|:-------|:----------------------------------------------------------------------------------------|
| IMSIPREFIX | IMSI前缀 | 标识IMSI前缀和HLRSN对应关系数据记录的关键字段，用于指定需要删除哪条IMSI前缀和HLRSN对应关系的数据记录，操作员可以使用LST IMSIHLRSN命令查询获得。 |

## 使用实例

删除一条IMSI前缀和HLRSN的对应关系数据记录，“IMSI前缀”为“460142”。命令如下：

```
RMV IMSIHLRSN: IMSIPREFIX="460142";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                  | 原因分析                                | 处理建议                                                       |
|-------:|:-----------------------|:------------------------------------|:-----------------------------------------------------------|
| 264050 | 参数IMSIPREFIX只允许输入：0～9。 | 输入的“IMSI前缀”参数的取值不是1～15位十进制数字组成的字符串。 | 重新输入“IMSI前缀”参数，确保其取值是1～15位十进制数字组成的字符串。                     |
| 264055 | 指定的IMSI前缀不存在。          | 输入的“IMSI前缀”参数取值不存在。                 | 重新输入“IMSI前缀”参数，确保其取值已存在。已存在的“IMSI前缀”可以通过LST IMSIHLRSN命令查询。 |
