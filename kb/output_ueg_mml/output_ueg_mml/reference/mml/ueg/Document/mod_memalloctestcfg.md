# 修改内存申请测试配置信息(MOD MEMALLOCTESTCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改或调整UDM注册给CSP的内存申请测试配置信息。UDM注册CSP的接口如下：

- 内存申请测试大小接口
- 内存申请周期接口
- 内存申请测试次数接口

UDM在所有进程初始化时，调用平台接口将对应进程类型的内存申请测试大小、内存申请测试周期以及内存申请测试次数取值设置给平台。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                |
|:--------------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MODULETYPE    | 模块类型     | 可选必选说明：必选参数 参数含义：用于标识UDM注册给CSP的内存申请测试配置的模块类型。 取值范围：DPU(DPU)：模块类型值21 DSG(DSG)：模块类型值40 BSG(BSG)：模块类型值41 CCU(CCU)：模块类型值42 PAU(PAU)：模块类型值43 HSF(HSF)：模块类型值20 NSF(NSF)：模块类型值45ACF(ACF)：模块类型值81ERU(ERU)：模块类型值46（该模块类型值为预留值。）APF(APF)：模块类型值84 默认值：无 配置原则：“ACF(ACF)”和“APF(APF)”模块仅在虚机场景下支持。 |
| MEMALLOCSIZE  | 内存申请测试大小 | 可选必选说明：可选参数 参数含义：用于标识UDM注册给CSP的内存申请测试配置的模块运行时申请的内存大小。 取值范围：1～100 单位：MB 默认值：无 配置原则： 执行该命令并且不输入该参数时，系统会设置初始值100。该参数为可选参数。该参数取值修改后下一次测试时才会生效。                                                                                                                                          |
| MEMALLOCTIME  | 内存申请测试周期 | 可选必选说明：可选参数 参数含义：用于标识UDM注册给CSP的内存申请测试配置的模块尝试运行的测试周期。 取值范围：10～600000 单位：ms 默认值：无 配置原则： 执行该命令并且不输入该参数时，系统会设置初始值2000。该参数为可选参数。该参数取值修改后下一次测试时才会生效。                                                                                                                                      |
| MEMALLOCCOUNT | 内存申请测试次数 | 可选必选说明：可选参数 参数含义：用于标识UDM注册给CSP的内存申请测试配置的模块尝试发起的测试次数。 取值范围：3～300 单位：次 默认值：无 配置原则： 执行该命令并且不输入该参数时，系统会设置初始值10。该参数为可选参数。该参数取值修改后立即生效。                                                                                                                                                   |

## 使用实例

修改内存申请测试配置信息，参数配置如下：

- “模块类型”取值为“DPU(DPU)”
- “内存申请测试大小”取值为“30”
- “内存申请测试周期”取值为“2000”
- “内存申请测试次数”取值为“10”

```
MOD MEMALLOCTESTCFG: MODULETYPE=DPU, MEMALLOCSIZE=30, MEMALLOCTIME=2000, MEMALLOCCOUNT=10;
```
