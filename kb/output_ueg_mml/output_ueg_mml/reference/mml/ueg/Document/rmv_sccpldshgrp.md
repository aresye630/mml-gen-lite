# 删除SCCP目的负荷分担信令点组(RMV SCCPLDSHGRP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于从配置数据库中删除一条SCCP目的负荷分担信令点组数据。

## 注意事项

- 如果某个负荷分担信令点组被GT翻译引用，则不能删除该记录。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                                                                           |
|:-------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| LSDGNM | 负荷分担信令点组名称 | 标识一条SCCP目的负荷分担信令点组数据记录的关键字段，用于指定需要删除哪一条SCCP目的负荷分担信令点组数据记录，操作员可以使用LST SCCPLDSHGRP命令查询获得。 取值范围：长度不超过32的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 说明：无。 |

## 使用实例

删除SCCP负荷分担目的信令点组，“负荷分担信令点组名称”为“LoadShareDSPGrp”：

```
RMV SCCPLDSHGRP: LSDGNM="LoadShareDSPGrp";
```
