# 添加FE平面信息(ADD FEPLAINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在开局的情况下配置UDM基础数据时增加一条FE平面信息。

为了避免在升级、扩容等操作时出现业务中断，需要增加FE平面信息数据将FE逻辑划分到平面0和平面1，使用平面0或平面1其中之一的Pod负荷业务，另一平面中Pod进行升级或扩容等操作，从而提升系统可靠性。

## 注意事项

- 一条FE平面信息记录中，平面0 Pod和平面1 Pod需要成对配置。当平面1 Pod设置为空时，则平面0 Pod独自成对且该独自成对的Pod不能配置链路，只能做业务的负荷分担。
- 系统最多可以添加33条FE平面信息。

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:----------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PLAINFOID | 平面信息标识  | 用于标识一条FE平面信息数据记录。 取值范围：0～1023 默认值：无。 说明：执行该命令并且不输入该参数时，系统会按照顺序自动设置。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ALOMODE   | 分配模式    | 用于标识FE平面的分配模式。 取值范围：Specify(指定分配)：通过“平面0 Pod”和“平面1 Pod”参数分别为对应的平面配置指定的Pod。Automatic(自动分配)：只需设置“平面0 Pod”参数的取值，但是系统会根据现有平面信息自动分配当前Pod的平面。即当系统中所有的平面信息标识都已有“平面0 Pod”和“平面1 Pod”，则系统会将输入的“平面0 Pod”自动分配到新增平面标识的平面0；当系统中某平面信息标识下只有一个平面分配了Pod，则系统会将输入的“平面0 Pod”自动分配到该平面标识的另一个平面下。例如：系统已有“平面信息标识”为“0”，“平面0 Pod”为“pod0”，“平面1 Pod”为“pod1”的记录，添加“平面0 Pod”为“pod2”的平面时则生成“平面信息标识”为“1”，“平面0 Pod”为“pod2”记录；再添加“平面0 Pod”为“pod3”的平面时则生成“平面信息标识”为“1”，“平面1 Pod”为“pod3”记录。 默认值：Specify(指定分配)。 说明：当该参数为“Specify(指定分配)”时，“平面0 Pod”和“平面1 Pod”参数至少输入一个。当该参数为“Automatic(自动分配)”时，必须且只能输入“平面0 Pod”参数。 |
| PLA0POD   | 平面0 Pod | 用于标识FE平面信息的平面0 Pod。 取值范围：长度不超过128的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| PLA1POD   | 平面1 Pod | 仅当本命令的“分配模式”参数为“Specify(指定分配)”时该参数有效。用于标识FE平面信息的平面1 Pod。 取值范围：长度不超过128的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |

## 使用实例

1. 在开局的情况下配置UDM基础数据时增加一条FE平面信息。“平面信息标识”为“0”，“平面0 Pod”为“pod0”，“平面1 Pod”为“pod1”：

   ```
   ADD FEPLAINFO: PLAINFOID=0, PLA0POD="pod0", PLA1POD="pod1";
   ```
2. 增加一条“平面0 Pod”为“pod0”且“分配模式”为“Automatic”的平面信息记录。

   ```
   ADD FEPLAINFO: ALOMODE=Automatic, PLA0POD="pod0";
   ```
