# 修改NAFGROUP群组名称(MOD NAFGROUP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于对配置数据库中一个网络应用功能群组的名称进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一个网络应用功能群组：

- NAF GROUP编号
- NAF GROUP旧名称

  **说明** 

  该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称         | 参数说明                                                                                                                                                                                                                       |
|:--------|:-------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NAFGRP  | NAF GROUP编号  | 标识一个网络应用功能群组的关键字段之一（其取值不能被修改），用于指定需要对哪一个网络应用功能群组的参数进行修改或调整，操作员可以使用LST NAFGROUP命令查询获得。 取值范围：1～65535。 默认值：无。 注意：该参数为必选参数。                                                                                                    |
| OLDNAME | NAF GROUP旧名称 | 标识一个网络应用功能群组的关键字段之一，用于指定需要对哪一个网络应用功能群组的名称进行修改或调整，操作员可以使用LST NAFGROUP命令查询获得。 取值范围：长度不超过127的字符串。 默认值：无。 注意：该参数为必选参数。                                                                                                         |
| NEWNAME | NAF GROUP新名称 | 用于指定网络应用功能群组的新名称。  说明： 若用户的GUSS签约信息中包含NAF群组信息，“NAF GROUP新名称”参数需要与对端IMS-HSS进行协商，“NAF GROUP新名称”参数要与IMS-HSS上配置的NAF群组信息保持一致。若用户的GUSS签约信息中不包含NAF群组信息，IMS-HSS下发USS信息后，UIM不对NAF群组的一致性进行判断。 取值范围：长度不超过127的字符串。 默认值：无。 注意：该参数为必选参数。 |

## 使用实例

修改网络应用功能组名称，携带以下参数：

- “NAF GROUP编号”为“1”
- “NAF GROUP旧名称”为“NAF1”
- “NAF GROUP新名称”为“NAF2”

执行命令如下：

```
MOD NAFGROUP: NAFGRP=1, OLDNAME="NAF1", NEWNAME="NAF2";
```
