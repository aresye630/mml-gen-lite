# 查询License校验状态(DSP LICCHECK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询License校验状态。

## 注意事项

本命令不支持查询EIR、ENS和UIM网元形态下的License校验状态。

## 参数说明

无。

## 使用实例

查询License校验状态。

```
DSP LICCHECK:;
```

```
%%DSP LICCHECK:;%%
RETCODE = 0  操作成功  

操作结果为 
----------             
    校验类型  =  周期性全校验              
    校验状态  =  校验完成
校验开始时间  =  2024-02-04 21:38:02
校验结束时间  =  2024-02-04 21:39:02
(结果个数 = 1)  

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义如表1所示。

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

| 输出项名称   | 输出项解释                                                                    |
|:--------|:-------------------------------------------------------------------------|
| 校验类型    | 用于返回License校验类型。 周期性全校验MML全校验 说明：系统刚启动未执行过任何校验时，执行该命令查询时该输出项显示为“周期性全校验”。 |
| 校验状态    | 用于返回License校验状态。 未校验校验中校验完成                                              |
| 校验开始时间  | 用于返回License校验开始时间。 说明：当“校验状态”输出项显示为“未校验”时，该输出项显示为“NULL”。                 |
| 校验结束时间  | 用于返回License校验结束时间。 说明：当“校验状态”输出项显示为“未校验”/“校验中”时，该输出项显示为“NULL”。           |

|    错误码 | 错误码解释   | 原因分析                | 处理建议                               |
|-------:|:--------|:--------------------|:-----------------------------------|
| 335607 | 暂不支持该功能 | 当前网元形态为UIM、ENS或EIR。 | UIM、ENS和EIR不涉及License校验，不支持查询校验状态。 |
