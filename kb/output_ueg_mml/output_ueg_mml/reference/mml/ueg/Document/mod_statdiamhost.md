# 修改Diameter局向统计对象(MOD STATDIAMHOST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改Diameter局向统计对象信息，在该命令中，系统通过“统计对象名称”参数来唯一标识一条局向数据记录。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                      |
|:-----------|:-------|:------------------------------------------------------------------------------------------|
| OBJECTNAME | 统计对象名称 | 标识一条Diameter局向统计对象的关键字段，用于指定需要对哪一条Diameter局向统计对象的参数进行修改或调整，操作员可以使用LST STATDIAMHOST命令查询获得。 |
| MSGAPP     | 消息应用类型 | 用于标识Diameter局向统计对象的指定消息接口类型。 取值范围：S6a(S6a)                                                |
| HN         | 主机名    | 用于标识Diameter局向统计对象在所属域中的网络主机名。                                                            |

## 使用实例

修改Diameter局向统计对象，将“统计对象名称”为“mme\_1”的Diameter局向统计对象的“主机名”改为“mme.huawei2.com”：

```
MOD STATDIAMHOST:OBJECTNAME="mme_1",HN="mme.huawei2.com";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                         | 原因分析          | 处理建议                                                      |
|-------:|:----------------------------------------------|:--------------|:----------------------------------------------------------|
| 335703 | 指定OBJECTNAME不存在，请执行LST STATDIAMHOST查询已经存在的记录。 | 对应的统计对象名称不存在。 | 使用LST STATDIAMHOST命令查询后，重新确认要修改哪个统计对象名称对应的Diameter局向统计对象。 |
