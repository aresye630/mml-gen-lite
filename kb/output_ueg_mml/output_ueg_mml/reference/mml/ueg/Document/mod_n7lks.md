# 修改MTP链路集(MOD N7LKS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对配置数据库中的一条MTP链路集数据记录的某些参数进行修改或调整。在该命令中，系统通过“链路集名称”参数来唯一标识一条MTP链路集数据记录。

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                               |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LSNM   | 链路集名称  | 标识一条MTP链路集数据记录的关键字段，用于指定需要对哪一条MTP链路集数据记录的参数进行修改或调整，操作员可以使用LST N7LKS命令查询获得。                                                                                                                                                                                                                                                         |
| SLSM   | 链路选择掩码 | 用于指定需要对哪一条链路选择掩码数据记录的参数进行修改或调整，操作员可以使用LST N7LKS命令查询获得。 取值范围： B0000(B0000)B0001(B0001)B0010(B0010)B0011(B0011)B0100(B0100)B0101(B0101)B0110(B0110)B0111(B0111)B1000(B1000)B1001(B1001)B1010(B1010)B1011(B1011)B1100(B1100)B1101(B1101)B1110(B1110)B1111(B1111) 默认值：B1111(B1111)                                                     |
| LKSDIR | 链路集指向  | 用于标识系统该链路集的指向，即该链路集所连接对端目的信令点的设备类型，操作员可以使用LST N7LKS命令查询获得。 取值范围： Null(Null)Hstp(Hstp)Lstp(Lstp)Gmsc(Gmsc)Msc(Msc)Hlr(Hlr)Mc(Mc)Scp(Scp)Bsc(Bsc)CncPstn(CncPstn)CtPstn(CtPstn)Cmcc(Cmcc)Ctt(Ctt)VoiceMailBox(VoiceMailBox)ColorRing(ColorRing)Cdma(Cdma)CustomerCentor(CustomerCentor)Others(Others) 默认值：无。                         |
| EMGF   | 紧急建链标志 | 用于指定需要对哪一条链路选择掩码数据记录的参数进行修改或调整，操作员可以使用LST N7LKS命令查询获得。 取值范围： TRUE(是)FALSE(否)                                                                                                                                                                                                                                                       |
| LSNM1  | 新链路集名称 | 用于标识系统对该数据记录中链路集名称字段的取值重新进行定义的新链路集名称。操作员可以使用LST N7LKS命令查询获得。 若不输入任何字符：表示不对该数据记录中“链路集名称”字段的取值重新进行定义。 若输入一个字符串：表示需要对该数据记录中“链路集名称”字段的取值重新进行定义，且输入的字符串不能在相应的数据表中已经被定义。假设本命令中“链路集名称”字段的取值为A、“新链路集名称”字段的取值为B，则对于配置数据库中索引了取值为A的所有数据记录的“链路集名称”字段，系统将自动把这些字段的值由A修改为B。 取值范围：1～32位的字符串，字符类型包括：数字“0～9”、大小写字母、特殊字符“-”、“_”、“.”、空格符及中文字符等。 默认值：无。 |

## 使用实例

1、修改MTP链路集，“链路集名称”为“N7LKS”，“链路选择掩码”为“B0010”：

```
MOD N7LKS: LSNM="N7LKS", SLSM=B0010;
```

2、修改MTP链路集，“链路集名称”为“N7LKS”，“新链路集名称”为“NEWN7LKS”：

```
MOD N7LKS: LSNM="N7LKS", LSNM1="NEWN7LKS";
```
