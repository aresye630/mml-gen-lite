# 查询DSG五元组分发类型(LST DSGTUPDISPTYP)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明
- 参考信息

## 命令功能

该命令用于查询DSG的SCTP及LDAP五元组的分配方式。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询DSG的SCTP及LDAP五元组的分配方式。

```
LST DSGTUPDISPTYP:;
```

```
%%LST DSGTUPDISPTYP:;%%
RETCODE = 0  操作成功

操作结果如下
----------
五元组分发类型  =  通配
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET DSGTUPDISPTY**命令的参数说明。
