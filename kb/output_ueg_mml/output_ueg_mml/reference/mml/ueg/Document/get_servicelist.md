# 获取业务列表（GET SERVICELIST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于获取网元上配置的业务特性列表。

## 注意事项

当通过**LST SYS**命令查询系统配置的网元形态为ENS或UIM时，不支持此功能。

## 参数说明

无。

## 使用实例

显示网元上配置的业务特性列表。

```
GET SERVICELIST:;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义如表1所示。

| 输出项名称   | 输出项解释                              |
|:--------|:-----------------------------------|
| 平台      | 用于返回网元所在的平台类型。                     |
| 系统功能    | 用于返回网元在网管上的网元形态。                   |
| 连接域     | 用于返回网元的链路数据信息。                     |
| 数据接口类型  | 用于返回网元的数据接口类型。                     |
| 容灾组网    | 用于返回网元的容灾组网类型。                     |
| 业务类型    | 用于返回网元的业务特性类型。                     |
| 是否使用    | 用于返回该业务特性是否使用。 “1”：表示使用。“0”：表示未使用。 |
| 签约用户数   | 用于返回该业务特性的签约用户数。                   |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释         | 原因分析             | 处理建议                                                                   |
|------:|:--------------|:-----------------|:-----------------------------------------------------------------------|
|   224 | 没有配置可用的CCU模块。 | 没有配置可用的CCU模块。    | 请检查系统中是否正确配置CCU模块。可以通过LST MODULE命令查询模块状态，若确定没有配置，请先通过ADD MODULE命令进行配置。 |
|   225 | 最小CCU模块故障。    | 模块号最小的CCU模块出现故障。 | 请检查CCU进程，确保“模块号”最小的CCU模块正常运行。                                          |
|   226 | 无效的网元形态。      | 网元形态未正确配置。       | 请检查系统中是否正确配置网元形态。可以通过LST SYS命令查询，通过SET SYS命令进行配置。                      |
