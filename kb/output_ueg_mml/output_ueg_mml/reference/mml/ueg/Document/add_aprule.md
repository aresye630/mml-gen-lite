# 增加AP转发规则(ADD APRULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中增加一条AP转发规则数据记录。在GBA认证过程中，认证&转发AP或转发AP根据该转发规则与前端网元HTTP消息中的HOST头域、应用区分标识和IP多媒体公共标识进行匹配，若匹配成功，将消息转发给指定的转发AP或AS。

**说明** 

该命令仅在Full-stack虚机场景下支持。

该命令中配置的“HOST索引”和“应用区分标识索引”和“HTTPPE索引”必须先通过**ADD HOSTTPL**、**ADD AUIDTPL**和**ADD HTTPPEHOST**命令配置才能在此引用，命令索引关系图如图1所示：

**图1** 命令关系图

## 注意事项

不允许添加“HOST索引”、“应用区分标识索引”和“IMPU”全部相同的两条AP转发规则。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
|:-------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ID     | 索引       | 可选必选说明：必选参数 用于标识一条AP转发规则。该参数在UIM中唯一，不能重复。 取值范围：1～65535 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| HOSTID | HOST索引   | 可选必选说明：可选参数 用于标识一个HOST模板。该参数必须先由ADD HOSTTPL命令定义，才能在此引用。 取值范围：0～2550：不配置HOST模板1～255：根据索引值配置HOST模板 默认值：0 说明：HOST模板命令组中的“索引”参数即为此处的“HOST索引”参数，操作员可以使用LST HOSTTPL命令查询获得。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| AUIDID | 应用区分标识索引 | 可选必选说明：可选参数 用于标识一个AUID（应用区分标识）模板。该参数必须先由ADD AUIDTPL命令定义，才能在此引用。 取值范围：0～2550：不配置AUID模板1～255：根据索引值配置AUID模板 默认值：0 说明：AUID模板命令组中的“索引”参数即为此处的“应用区分标识索引”参数，操作员可以使用LST AUIDTPL命令查询获得。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| IMPUE  | IMPU存在   | 可选必选说明：可选参数 用于标识是否需要匹配HTTP请求消息中的“IMPU”。 取值范围TRUE(是)：匹配IMPU。FALSE(否)：不匹配IMPU。 默认值：FALSE(否)。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| IMPU   | IMPU     | 可选必选说明：条件必选参数 仅当本命令中的“IMPU存在”参数为“TRUE(是)”时该参数有效。用于标识要匹配的HTTP请求消息中的IMPU数据信息。IMPU即IP多媒体公共标识，该标识是用户对外可寻址的标识，用于请求和其他用户通信。 该参数的配置原则为：若AP为认证&转发AP，使用SIP格式的IMPU域名转发，操作员要先通过MOD INSP命令将软参“IMPUPROXYMODE(IMPU转发模式)”值设置为“1”。 “IMPU”参数配置为标准sip格式IMPU的域名信息（如果配置的是完整IMPU，则此规则无效）。 例如，标准sip格式IMPU为：sip:+8613499999999@beijing.ims.mnc000.mcc460.3gppnetwork.org，“IMPU”参数需要配置为“beijing.ims.mnc000.mcc460.3gppnetwork.org”。 若AP为认证&转发AP，使用SIP格式的IMPU前缀号段转发，操作员要先通过MOD INSP命令将软参“IMPUPROXYMODE(IMPU转发模式)”值设置为“2”。 “IMPU”参数配置为标准sip格式IMPU的前缀号段（如果配置的是完整IMPU，则此规则无效）。 例如，标准sip格式IMPU为：sip:+8613499999999@beijing.ims.mnc000.mcc460.3gppnetwork.org，“IMPU”参数可以配置为“sip:+8613499”。 若AP为认证&转发AP，使用SIP格式的IMPU前缀号段和域名转发，操作员要先通过MOD INSP命令将软参“IMPUPROXYMODE(IMPU转发模式)”值设置为“3”。 “IMPU”参数配置为标准sip格式IMPU的前缀号段+@+IMPU域名信息。 例如，标准sip格式IMPU为：sip:+8613499999999@beijing.ims.mnc000.mcc460.3gppnetwork.org，“IMPU”参数可以配置为“sip:+8613499@beijing.ims.mnc000.mcc460.3gppnetwork.org”。 若AP为转发AP，使用TEL格式的前缀号段转发，操作员要先通过MOD INSP命令将软参“IMPUPROXYMODE(IMPU转发模式)”值设置为“0”。 “IMPU”参数配置为标准tel格式的IMPU的前缀号段（如果配置的是完整IMPU，则此规则无效）。 例如，标准tel格式IMPU为：tel:+8613499999999，则“IMPU”参数可以配置为“tel:+8613499”。 取值范围：1～127位字符串。 默认值：无。 说明：该参数不区分大小写，在执行LST APRULE命令查询出的报文中为全小写形式。 |
| PEID   | HTTPPE索引 | 可选必选说明：必选参数 用于标识要将满足本条匹配规则的消息转发到哪个HTTP实体（转发AP或AS）。该参数必须先通过ADD HTTPPEHOST命令配置，然后才能在此处引用。 取值范围：0～255。 默认值：无。 说明：HTTPPEHOST命令组中的“对端HTTP实体标识”参数即为此处的“HTTPPE索引”参数，操作员可以使用LST HTTPPEHOST命令查询获得。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |

## 使用实例

1. 增加一条匹配HOST模板，AUID模板和IMPU的认证&转发AP的转发规则数据记录，操作员需要配置以下数据：
   1. 增加一个HOST模板，“索引”为“1”，“HOST”为“huawei.com”：

      ```
      ADD HOSTTPL: ID=1, HOST="huawei.com";
      ```
   2. 增加一个AUID模板，“索引”为“1”，“应用区分标识”为“simservs.ngn.etsi.org”：

      ```
      ADD AUIDTPL: ID=1, AUID="simservs.ngn.etsi.org";
      ```
   3. 增加一条对端HTTP实体域名记录，“对端HTTP实体标识”为“12” ，“对端域名”为“ap.huawei.com”。

      ```
      ADD HTTPPEHOST: PEID=12, HOST="ap.huawei.com";
      ```
   4. 执行**ADD APRULE**命令配置认证&转发AP的转发规则，匹配上面配置的HOST模板和AUID模板，且“IMPU”为“beijing.ims.mnc000.mcc460.3gppnetwork.org”，“HTTPPE索引”为“12”：

      ```
      ADD APRULE: ID=1, HOSTID=1, AUIDID=1, IMPUE=TRUE, IMPU="beijing.ims.mnc000.mcc460.3gppnetwork.org", PEID=12;
      ```
2. 增加一条匹配HOST模板，AUID模板和IMPU的转发AP的转发规则数据记录，操作员需要配置以下数据：
   1. 增加一个HOST模板，“索引”为“2”，“HOST”为“huawei1.com”：

      ```
      ADD HOSTTPL: ID=2, HOST="huawei1.com";
      ```
   2. 增加一个AUID模板，“索引”为“2”，“应用区分标识”为“simservs.ngn.etsi.org”：

      ```
      ADD AUIDTPL: ID=2, AUID="simservs.ngn.etsi.org";
      ```
   3. 增加一条对端HTTP实体域名记录，“对端HTTP实体标识”为“10” ，“对端域名”为“ap1.huawei.com”。

      ```
      ADD HTTPPEHOST: PEID=10, HOST="ap1.huawei.com";
      ```
   4. 执行**ADD APRULE**命令配置转发AP的转发规则，匹配上面配置的HOST模板和AUID模板，且“IMPU”为“tel:+8613499999999”，“HTTPPE索引”为“10”：

      ```
      ADD APRULE: ID=2, HOSTID=2, AUIDID=2, IMPUE=TRUE, IMPU="tel:+8613499999999", PEID=10;
      ```
3. 增加一条AP转发规则数据记录，不匹配HOST模板、AUID模板和IMPU，操作员需要配置以下数据：
   1. 增加一条对端HTTP实体域名记录，“对端HTTP实体标识”为“13” ，“对端域名”为“ap.huawei.com”。

      ```
      ADD HTTPPEHOST: PEID=13, HOST="ap.huawei.com";
      ```
   2. 执行**ADD APRULE**命令配置AP转发规则，“HTTPPE索引”为“13”：

      ```
      ADD APRULE: ID=2, HOSTID=0, AUIDID=0, IMPUE=FALSE, PEID=13;
      ```
