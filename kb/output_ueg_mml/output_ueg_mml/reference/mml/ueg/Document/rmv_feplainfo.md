# 删除FE平面信息(RMV FEPLAINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条FE平面信息的数据记录。

## 注意事项

- 删除FE平面可能会导致升级或扩容过程中出现业务中断，降低系统可靠性。
- “平面信息标识”和“Pod名称”参数必须有且只能有一个参数出现。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                  |
|:----------|:-------|:----------------------------------------------------------------------|
| PLAINFOID | 平面信息标识 | 标识一条FE平面数据记录的关键字段之一，用于指定需要删除哪一条FE平面数据记录，操作员可以使用LST FEPLAINFO命令查询获得。   |
| PODNAME   | Pod名称  | 标识一条FE平面数据记录的关键字段之一，用于指定需要删除哪一个Pod的平面数据记录，操作员可以使用LST FEPLAINFO命令查询获得。 |

## 使用实例

1. 删除“平面信息标识”为“1”的所有FE平面信息：

   ```
   RMV FEPLAINFO: PLAINFOID=1;
   ```
2. 删除“Pod名称”为“pod0”的FE平面信息而不删除同一平面信息标识的其他FE平面信息：

   ```
   RMV FEPLAINFO: PODNAME="pod0";
   ```
