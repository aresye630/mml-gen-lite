# 查询冷备传统功能参数(LST THIRDDCFUNC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询本局点容灾属性和容灾状态。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询本局点的冷备传统功能配置信息。

```
LST THIRDDCFUNC:;
```

```
%%LST THIRDDCFUNC:;%%
RETCODE = 0  操作成功
操作结果如下
------------
局点类型  =  冷备
容灾状态  =  接管状态
(结果个数 = 1)
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET THIRDDCFUNC**命令的参数说明。
