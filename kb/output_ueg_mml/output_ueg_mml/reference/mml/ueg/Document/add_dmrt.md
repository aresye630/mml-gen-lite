## 命令功能

该命令用于在Diameter路由表中增加一条与Diameter路由组相关的路由记录。每个路由组对应的目的域名和Diameter接口类型都并不相同，因此需要单独添加Diameter路由记录。设置Diameter路由后，UDM可以实现基于Diameter路由规则转发消息包（不会更改消息体）的功能，减少客户端和服务端之间配置的复杂性。

## 注意事项

- 每个路由组中最大支持配置64个对端设备。
- 系统最多允许配置1024个Diameter路由。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                   |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------|
| RTNAME   | 路由组名称  | 用于标识一个Diameter路由组的名称。该参数必须先由ADD DMRTS命令定义，然后才能在此处引用。 取值范围：长度不超过127的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 |
| PEERNAME | 对端标识名称 | 用于标识一个Diameter对端实体的名称。该参数必须先由ADD DMPE命令定义，然后才能在此处引用。 取值范围：长度不超过127的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 |

## 使用实例

配置一条与Diameter路由组相关的路由记录，需要进行如下配置。

1. 根据图1中的参数索引关系，确认准备条件是否完成。
   1. 执行**LST DMRTS**命令查询待增加路由对应的路由组是否已增加。若未增加，需执行**ADD DMRTS**命令增加该Diameter路由组，Diameter路由组的“路由组名称”为“TEST\_RT”。

      ```
      ADD DMRTS: RTSNAME="TEST_RT", RN="huawei.com", APPID=S6A/S6D, SMODE=POLLING;
      ```
   2. 执行**LST DMPE**命令查询待增加路由对应的Diameter对端实体是否已增加。若未增加，需执行**ADD DMPE**命令增加该Diameter对端实体，Diameter对端实体的“实体名称”为“MME”。

      ```
      ADD DMPE: EN="MME", PEERTYPE=OTHER, HN="mme.huawei.com", PEPRI=15;
      ```
2. 执行本命令，增加Diameter路由。

   ```
   ADD DMRT: RTNAME="TEST_RT", PEERNAME="MME";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 264007 | 指定的DMPE不存在。请执行LST DMPE查看已经存在的DMPE对象。      | 输入的“对端标识名称”参数不存在。                     | 根据实际情况，重新输入“对端标识名称”参数的取值，确保其取值已存在。已存在的对端标识名称可以执行LST DMPE命令查询。                          |
