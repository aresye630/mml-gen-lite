# 修改队列流控消息权重(MOD QFCMQW)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于设置首消息业务类型的调度权重，即设置队列流控消息的权重。系统针对不同业务消息按照其所在队列的权重优先级进行单位时间内的处理。当队列中首消息的放行量远小于首消息的增加量，即如果队列满则丢弃相应业务首消息，如果不满则放行，系统实现优先级自然溢出功能。操作员根据实际情况通过本命令设置队列流控消息权重，可以提高系统处理业务请求的能力，保证高峰期系统正常进行业务。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                           |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| QFCMN  | 消息名称   | 用于标识业务流程中首消息的名称。 取值范围：A(A)AAAA(AAAA)SRV(SRV)NAPTR(NAPTR)UAR(UAR)SAR(SAR)LIR(LIR)MAR(MAR)UDR(UDR)PUR(PUR)SNR(SNR)ULR(ULR)AIR(AIR)PUR_SAE(PUR_SAE)NOR(NOR)SAR_SAE(SAR_SAE)MAR_SAE(MAR_SAE)RIR(RIR)INI_SND(主动下发类)LOC_MND(位置管理类)SRI_S(路由类)PAGE(呼叫类)DER(DER)AAR(AAR)STR(STR)RTR(RTR)PPR(PPR) 默认值：无。 |
| QFCMQW | 消息队列权重 | 用于标识业务流程中首消息在系统进行一次轮循调度队列消息操作时可以被连续调度的次数。 取值范围：1～10 默认值：无。                                                                                                                                                                                                                                     |

## 使用实例

修改系统队列流量控制消息权重。“消息名称”为“AAAA”，“消息队列权重”为“2”，命令如下：

```
MOD QFCMQW: QFCMN=AAAA, QFCMQW=2;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释              | 原因分析                                    | 处理建议                                                                     |
|-------:|:-------------------|:----------------------------------------|:-------------------------------------------------------------------------|
| 260008 | 参数未修改，请至少指定一个修改参数。 | 可能原因如下：没有输入“消息队列权重”参数。输入的“消息队列权重”参数未变化。 | 根据实际情况，重新输入“消息队列权重”参数的取值，确保其取值与修改前的不一致。修改前的“消息队列权重”参数可以通过LST QFCMQW命令查询。 |
| 100016 | 参数的值不在指定范围内。       | 报错的参数值不在取值范围内。                          | 请根据报错的参数取值范围，重新输入正确的参数值后重新执行本命令。                                         |
