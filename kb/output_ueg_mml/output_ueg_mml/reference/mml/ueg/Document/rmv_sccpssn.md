# 删除SCCP子系统(RMV SCCPSSN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于从配置数据库中删除一条或者一组SCCP子系统号数据。

## 注意事项

- 在正常情况下，删除一条SCCP子系统号数据记录的操作步骤为：**RMV SCCPGT**-->****RMV SCCPSSN****。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                                                                                                                                   |
|:-------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SSNNM  | SSN名称     | 标识一条SCCP子系统数据记录的关键字段，用于指定需要删除哪一条SCCP子系统数据记录，操作员可以使用LST SCCPSSN命令查询获得。 取值范围：长度不超过32的字符串 默认值：无。 说明：无。                                                                                    |
| RMCNF  | 删除本局SSN标志 | 是否删除本局SSN的标志。 取值范围： “TRUE(是)” “FALSE(否)” 默认值：“FALSE(否)” 说明：当SSN子系统号为MSC SSN、SCMG SSN、VLR SSN、CAP SSN、BSSAP/INAP SSN，并且该SSN是本局的SSN时，该SSN记录为重要记录，要删除该SSN记录，需要用户确认；当删除本局SSN标志为TRUE时，才能删除。 |

## 使用实例

删除SCCP子系统号，“子系统名称”为“SCCPSSN”：

```
RMV SCCPSSN: SSNNM="SCCPSSN";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。各参数含义请见**ADD SCCPSSN**命令。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释                                                | 原因分析                      | 处理建议                                                                                     |
|-------:|:----------------------------------------------------|:--------------------------|:-----------------------------------------------------------------------------------------|
| 306396 | 该SCCP子系统已经被其他SCCP子系统所引用，删除前请先执行MOD SCCPSSN命令取消备份关系。 | 所要删除的SCCP子系统被其他SCCP子系统引用。 | 请先执行MOD SCCPSSN命令，将参数“备用SSN名称”设置为“DEFAULT”取消该SCCP子系统与其他SCCP子系统的备份关系，然后才能执行本命令删除该SCCP子系统。 |
