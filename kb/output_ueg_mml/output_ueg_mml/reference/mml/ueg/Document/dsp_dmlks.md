# 查询Diameter链路集状态(DSP DMLKS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于请求系统显示Diameter链路集的状态信息。

- 若需要请求系统显示全部Diameter链路集记录的状态信息，请不要输入任何参数。
- 若需要请求系统显示某些Diameter链路集记录的状态信息，请输入“链路集名称”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称           | 参数说明                                                     |
|:---------|:---------------|:---------------------------------------------------------|
| LINKSNAM | 链路集名称          | 用于请求系统显示哪条Diameter链路集的状态信息；若不输入，则表示所有的Diameter链路集。       |
| LOCALNAM | Diameter本端实体名称 | 用于请求系统显示哪个本端实体的Diameter链路集的状态信息；若不输入，则表示所有的Diameter本端实体。 |
| PEERNAM  | Diameter对端实体名称 | 用于请求系统显示哪个对端实体的Diameter链路集的状态信息；若不输入，则表示所有的Diameter对端实体。 |

## 使用实例

1. 显示所有Diameter链路集的状态信息：

   ```
   DSP DMLKS:;
   ```

   ```
   %%DSP DMLKS:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    链路集名称         Diameter本端实体名称  Diameter对端实体名称  链路集状态  链路选择模式  Diameter本端实体标识  Diameter对端实体标识  Diameter链路集标识

    HSS_BSF            HSS9860               BSF                   链路正常    激活方式      0                     0                     0                 
    HSS_AS             HSS9860               AS                    链路断开    基于会话ID    0                     1                     1                 
   (结果个数 = 2)

   ---    END
   ```
2. 显示Diameter链路集的状态信息，“链路集名称”为“HSS\_AS”。

   ```
   DSP DMLKS: LINKSNAM="HSS_AS";
   ```

   ```
   %%DSP DMLKS: LINKSNAM="HSS_AS";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
             链路集名称  =  HSS_AS
   Diameter本端实体名称  =  HSS9860
   Diameter对端实体名称  =  AS
             链路集状态  =  链路断开
           链路选择模式  =  基于会话ID
   Diameter本端实体标识  =  0
   Diameter对端实体标识  =  2
     Diameter链路集标识  =  1
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见

**ADD DMLKS**

命令的参数说明，表1列出的是未包含在

**ADD DMLKS**

命令参数说明中的输出项。

| 输出项名称          | 输出项解释                                                                             |
|:---------------|:----------------------------------------------------------------------------------|
| 链路集状态          | 用于返回Diameter链路集的状态：链路正常：链路集处于正常状态，可通信。链路断开：链路集处于断开状态，不可通信。链路拥塞：链路集处于拥塞状态，可通信，质量差。 |
| Diameter本端实体标识 | 用于返回Diameter本端实体数据记录索引。                                                           |
| Diameter对端实体标识 | 用于返回Diameter对端实体数据记录索引。                                                           |
| Diameter链路集标识  | 用于返回Diameter链路集索引。                                                                |
