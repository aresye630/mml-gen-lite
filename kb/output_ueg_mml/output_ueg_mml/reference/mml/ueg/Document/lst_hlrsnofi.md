# 查询HLRSN与本局信息(LST HLRSNOFI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询HLRSN与本局信息的对应关系数据：

- 若需要查询所有HLRSN与本局信息的概要配置信息，请不要输入参数。
- 若需要查询某个HLRSN与本局信息的详细配置信息，请输入“HLR序列号”参数。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                          |
|:-------|:-------|:--------------------------------------------------------------|
| HLRSN  | HLR序列号 | 用于指示系统按照哪个HLR序列号来查询HLRSN与本局信息的对应关系数据；若不输入，则表示查询所有的HLRSN与本局信息。 |

## 使用实例

1. 查询所有HLRSN与本局信息，不输入参数：

   ```
   LST HLRSNOFI:;
   ```

   ```
   %%LST HLRSNOFI:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    HLR序列号  本局GT      本局HLR号码  本局主机名  本局域名     归属GT      归属HLR号码      IMS本局主机名  IMS本局域名

    1          8613801     8613901      test1       huawei1.com  8613801001   8613901001      test2         huawei11.com
    2          8613811     8613911      test11      huawei2.com  8613801011   8613901011      test3         huawei33.com
   (结果个数 = 2)

   ---    END
   ```
2. 查询某个HLRSN与本局信息。“HLR序列号”为“1”：

   ```
   LST HLRSNOFI: HLRSN=1;
   ```

   ```
   %%LST HLRSNOFI: HLRSN=1;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
      HLR序列号  =  1
         本局GT  =  8613801
    本局HLR号码  =  8613901
     本局主机名  =  test1
       本局域名  =  huawei1.com
         归属GT  =  8613801001
    归属HLR号码  =  8613901001
   IMS本局主机名 =  test2
    IMS本局域名  =  huawei11.com
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD HLRSNOFI**命令的参数说明。
