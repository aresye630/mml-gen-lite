# 删除QOS测量IP地址对(RMV QOSIP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除QoS测量的IP地址对数据。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                           |
|:----------|:---------|:-------------------------------------------------------------------------------|
| IPTYPE    | IP地址类型   | 用于指定需要删除的IP地址的类型，操作员可以使用LST QOSIP命令查询获得。 取值范围： IPV4(IPV4版本)IPV6(IPV6版本) 默认值：无。 |
| LOCALIP   | 本端IP地址   | 用于指定需要删除的本端IP地址，操作员可以使用LST QOSIP命令查询获得。仅当参数“IP地址类型”设置为“IPV4(IPV4版本)”时，该参数有效。   |
| PEERIP    | 对端IP地址   | 用于指定需要删除的对端IP地址，操作员可以使用LST QOSIP命令查询获得。仅当参数“IP地址类型”设置为“IPV4(IPV4版本)”时，该参数有效。   |
| LOCALIPV6 | 本端IPV6地址 | 用于指定需要删除的本端IPV6地址，操作员可以使用LST QOSIP命令查询获得。仅当参数“IP地址类型”设置为“IPV6(IPV6版本)”时，该参数有效。 |
| PEERIPV6  | 对端IPV6地址 | 用于指定需要删除的对端IPV6地址，操作员可以使用LST QOSIP命令查询获得。仅当参数“IP地址类型”设置为“IPV6(IPV6版本)”时，该参数有效。 |

## 使用实例

删除QoS测量的IP地址对数据，参数IP地址类型设置为IPV4，本端IP:192.168.165.198，对端IP:192.168.165.199。

```
RMV QOSIP: IPTYPE=IPV4, LOCALIP="192.168.165.198", PEERIP="192.168.165.199";
```
