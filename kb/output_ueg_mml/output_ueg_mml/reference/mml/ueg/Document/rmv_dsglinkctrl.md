# 删除DSG链路中心(RMV DSGLINKCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除DSG链路中心。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                               |
|:-------|:-------|:-------------------------------------------------------------------|
| MID    | 模块号    | 用于指定网元的DSG模块号。DSG模块号先由ADD MODULE命令定义，然后才能在此处索引。 取值范围：1～2047 默认值：无。 |

## 使用实例

删除DSG链路中心，“模块号”为“52”。命令示例如下：

```
RMV DSGLINKCTRL: MID=52;
```
