# 查询远端网元IP地址(LST RIPADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询远端网元IP地址：

- 若需要查询远端网元IP地址，请不要输入任何参数。
- 若需要查询满足某个条件的远端网元IP地址，请输入“远端Location标识”，“远端DPU模块号/远端业务IP索引”，“远端Location IP地址1”， 或“远端Location IP地址2”参数。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称               | 参数说明                                                                                                                                                                                                                |
|:--------|:-------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RLOCID  | 远端Location标识       | 用于指示系统需要按照哪个远端Location来查询远端网元IP地址信息；若不输入，则表示查询满足所有Location的远端网元IP地址信息。 取值范围：1～512 默认值：无。                                                                                                                            |
| ID      | 远端DPU模块号/远端业务IP索引  | 用于指示系统需要按照哪个远端DPU模块号/远端业务IP索引来查询远端网元IP地址信息；若不输入，则表示查询所有远端DPU模块号/远端业务IP索引对应的远端网元IP地址信息。 取值范围：1～4080 默认值：无。                                                                                                           |
| IPVER   | IP类型               | 用于表示IP地址类型。 取值范围： IPV4：配置IPV4类型IP使用IPV6：配置IPV6类型IP使用 默认值：无。                                                                                                                                                         |
| IPV4IP1 | 远端Location IPV4地址1 | 用于指示系统需要按照哪个远端Location IP地址来查询远端网元IP地址；若不输入，则表示查询所有远端Location IP地址对应的远端网元IP地址信息。 取值范围：IPV4地址 默认值：无。                                                                                                                 |
| IPV6IP1 | 远端Location IPV6地址1 | 用于指示系统需要按照哪个远端Location IP地址来查询远端网元IP地址；若不输入，则表示查询所有远端Location IP地址对应的远端网元IP地址信息。 当参数“IP类型”设置为“IPV6(IPV6)”时，该参数有效，格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如：2001:DB8:8432:4098:4782:5784::。 取值范围：IPV6地址 默认值：无。 |
| IPV4IP2 | 远端Location IPV4地址2 | 用于指示系统需要按照哪个远端Location IP地址来查询远端网元IP地址；若不输入，则表示查询所有远端Location IP地址对应的远端网元IP地址信息。 取值范围：IPV4地址 默认值：无。                                                                                                                 |
| IPV6IP2 | 远端Location IPV6地址2 | 用于指示系统需要按照哪个远端Location IP地址来查询远端网元IP地址；若不输入，则表示查询所有远端Location IP地址对应的远端网元IP地址信息。 当参数“IP类型”设置为“IPV6(IPV6)”时，该参数有效，格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如：2001:DB8:8432:4098:4782:5784::。 取值范围：IPV6地址 默认值：无。 |

## 使用实例

1. 查询所有远端网元IP地址：

   ```
   LST RIPADDR:;
   ```
