# 设置日志抑制(SET LOGSUPPRESSION)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置UDM主机侧各模块（包含DPU/DSG/BSG/CCU/HSF模块）ERR级别的运行文本日志的抑制周期。在抑制周期内，相同内容的运行文本日志只会输出一条记录，但系统会记录具体的输出条数，方便维护人员进行统计，提高定位问题的效率。

UDM主机侧各模块（包含DPU/DSG/BSG/CCU/HSF模块）在进程启动时加载日志抑制参数，联机设定时更新日志抑制参数。

## 注意事项

- 系统只能增加一条日志抑制规则。
- 使用此功能CCU模块所在的虚拟机（裸机Pod）CPU占用率增加1%～4%，对系统正常使用无影响。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                      |
|:----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SWITCH    | 自动调节开关 | 用于标识UDM是否支持日志抑制功能。 取值范围：OFF(关闭)：表示系统不支持日志抑制功能，直接输出日志。ON(打开)：表示系统支持日志抑制功能，首次输出日志时，则取最小周期为初始日志抑制周期值。 默认值：无                                                                                                                  |
| ACCRATE   | 加速速率   | 仅当本命令中的“自动调节开关”参数为“ON(打开)”时该参数有效。用于标识UDM日志抑制周期的加速速率。“加速速率”必须大于“减速速率”。 当每5分钟输出日志的数量达到“加速速率”设置的值时，则需要在抑制周期的基础上增加一个“步长”，抑制周期不可大于“最大周期”的取值。例如原抑制周期为200毫秒，“步长”为100毫秒，则现在抑制周期变为300毫秒。 单位：每5分钟日志打点数 取值范围：3000～30000 默认值：3000     |
| DECRATE   | 减速速率   | 仅当本命令中的“自动调节开关”参数为“ON(打开)”时该参数有效。用于标识UDM日志抑制周期的减速速率。“减速速率”必须大于“复位速率”，小于“加速速率”。 当每5分钟输出日志的数量达到“减速速率”设置的值时，则需要在抑制周期的基础上减少一个“步长”，抑制周期不可小于“最小周期”的取值。例如原抑制周期为200毫秒，“步长”为100毫秒，则现在抑制周期变为100毫秒。 单位：每5分钟日志打点数 取值范围：30～2700 默认值：30 |
| RSTRATE   | 复位速率   | 仅当本命令中的“自动调节开关”参数为“ON(打开)”时该参数有效。用于标识UDM日志抑制周期的复位速率。“复位速率”必须小于“减速速率”。 当每5分钟输出日志的数量达到“复位速率”设置的值时，则需要将抑制周期重置为初始日志抑制周期值。 单位：每5分钟日志打点数 取值范围：1～27 默认值：3                                                                        |
| MINPERIOD | 最小周期   | 仅当本命令中的“自动调节开关”参数为“ON(打开)”时该参数有效。用于标识UDM日志抑制的最小周期。“最小周期”必须大于等于“步长”，小于“最大周期”。 单位：毫秒 取值范围：10～1000 默认值：100                                                                                                                   |
| MAXPERIOD | 最大周期   | 仅当本命令中的“自动调节开关”参数为“ON(打开)”时该参数有效。用于标识UDM日志抑制的最大周期。“最大周期”必须大于“最小周期” 单位：毫秒 取值范围：30000～300000 默认值：60000                                                                                                                      |
| STEP      | 步长     | 仅当本命令中的“自动调节开关”参数为“ON(打开)”时该参数有效。用于标识UDM日志抑制周期的步长。 单位：毫秒 取值范围：10～1000 默认值：100                                                                                                                                             |

## 使用实例

新增一个日志抑制规则。参数设置如下：

- “自动调节开关”为“ON(打开)”
- “加速速率”为“3500”
- “减速速率”为“35”
- “复位速率”为“5”
- “最小周期”为“200”
- “最大周期”为“70000”
- “步长”为“200”

命令执行如下：

```
SET LOGSUPPRESSION: SWITCH=ON, ACCRATE=3500, DECRATE=35, RSTRATE=5, MINPERIOD=200, MAXPERIOD=70000, STEP=200;
```
