# 显示PAU链路状态(DSP PAULINK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示PAU链路的状态信息。

- 若需要显示全部链路的信息，请不要输入任何参数值。
- 若需要显示某些链路的配置信息，请输入“链路名称”参数或“PAU模块号”参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                          |
|:---------|:-------|:----------------------------------------------|
| LINKNAME | 链路名称   | 用于请求系统显示哪个链路名称的PAU链路运行状态；若不输入，则表示所有的PAU链路信息。  |
| MID      | PAU模块号 | 用于请求系统显示哪个模块的PAU链路的运行状态；若不输入，则表示所有模块的PAU链路信息。 |

## 使用实例

1. 显示全部链路的配置信息：

   ```
   DSP PAULINK:;
   ```

   ```
   %%DSP PAULINK:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   链路名称       PAU模块号    协议类型     链路状态     IP版本       本端IPV4地址     本端IPV6地址    本端端口号    远端IPV4地址     远端IPV6地址   远端端口号     链路优先级 
   PAULINK_1      138          TCP          正常         IPV4版本     10.140.1.64       NULL           12356         10.100.2.47       NULL           23567          1 
   PAULINK_2      139          TCP          异常         IPV4版本     10.140.1.63       NULL           5689          10.100.2.99       NULL           2356           1 
   (结果个数 = 2)

   ---    END
   ```
2. 显示“链路名称”为“PAULINK\_1”，“PAU模块号”为“138”的链路配置信息：

   ```
   DSP PAULINK: LINKNAME="PAULINK_1", MID=138;
   ```

   ```

   RETCODE = 0  操作成功

   操作结果如下

   本端IPV6地址  =  NULL
     本端端口号  =  12356

   远端IPV6地址  =  NULL
     远端端口号  =  23567

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见

**ADD PAULINK**

命令中的参数说明。表1列出的是未包含在

**ADD PAULINK**

命令参数说明中的输出项。

| 输出项名称   | 输出项解释                                   |
|:--------|:----------------------------------------|
| 链路状态    | 用于返回PAU链路的状态：正常：表示该链路连接正常。异常：表示该链路连接异常。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释         | 原因分析            | 处理建议                                                   |
|-------:|:--------------|:----------------|:-------------------------------------------------------|
| 335486 | 对象PAULINK不存在。 | 输入的“链路名称”参数不存在。 | 请重新输入“链路名称”参数，确保其存在。已存在的“链路名称”参数可以通过LST PAULINK命令查询获得。 |
