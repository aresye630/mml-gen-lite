# 查询MTP链路集(LST N7LKS)

## 命令功能

该命令用于在配置数据库中查询MTP链路集数据的配置信息：

- 若需要查询全部MTP链路集数据记录的概要信息，请不要输入任何参数。
- 若需要查询某条MTP链路集数据记录的详细信息，请输入“链路集名称”或“相邻目的信令点名称”或这两个参数的组合。

## 注意事项

该命令的“链路集名称”和“相邻目的信令点名称”参数支持模糊查询功能。

模糊查询功能是指操作员在LMT输入查询参数时，对于字符串或BCD码类型的查询参数而言：

- 如果操作员输入的是一个完整的字符串或BCD码，则表示系统将按照完全匹配的方式执行查询操作。
- 如果操作员在输入的某个字符串或BCD码的末尾添加通配字符“%”，则表示系统将按照模糊匹配的方式执行查询操作。因此，若要执行模糊查询，操作员只能在字符串或BCD码的末尾添加通配字符“%”，而不能在字符串或BCD码的前面、中间添加通配字符“%”。例如，“A市%”、“1390123%”是合法的输入，而“%A市”、“A市%区”、“%1390123”、“139%0123”均是不合法的输入。

**说明** 

若某个命令同时存在有多个字符串或BCD码类型的查询参数，则操作员在一次查询操作中，只能对其中的一个查询参数使用模糊查询方式，而不能同时对两个或两个以上的查询参数使用模糊查询方式。

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                   |
|:-------|:----------|:-------------------------------------------------------|
| LSNM   | 链路集名称     | 用于指示系统需要按照哪个MTP链路集名称来查询MTP链路集数据；若不输入，则表示所有的MTP链路集。     |
| ASPNM  | 相邻目的信令点名称 | 用于指示系统需要按照哪个相邻目的信令点名称来查询MTP链路集数据；若不输入，则表示所有的相邻目的信令点名称。 |

## 使用实例

1、查询MTP链路集:

```
LST N7LKS:;
```

```
%%LST N7LKS:;%%
RETCODE = 0  操作成功。

------------

        链路集指向  =  Null
      紧急建链标志  =  否
        链路集索引  =  0
(结果个数 = 1)

---    END
```

2、查询MTP链路集,“链路集名称”为“N7LKS”:

```
LST N7LKS: LSNM="N7LKS";
```
