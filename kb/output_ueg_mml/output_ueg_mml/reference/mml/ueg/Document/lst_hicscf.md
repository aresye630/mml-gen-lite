# 查询外部I-CSCF设备的配置信息(LST HICSCF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询I-CSCF的配置信息：

- 若需要查询全部I-CSCF数据记录的信息，请不要输入任何参数。
- 若需要查询某条I-CSCF数据记录的详细信息，请输入“I-CSCF名称”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                       |
|:-------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HSSN   | HSS名称    | 用于指示系统需要按照哪个“HSS名称”来查询I-CSCF数据记录；若不输入，则表示所有的HSS实体名称。 取值范围：1～127位十进制数字或字母组成的字符串。 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                            |
| CSCFN  | I-CSCF名称 | 用于指示系统需要按照哪个“I-CSCF名称”来查询I-CSCF数据记录；若不输入，则表示所有的“I-CSCF名称”。 取值范围：1～127位十进制数字或字母组成的字符串。 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                      |
| HN     | 主机名      | 用于指示系统需要按照哪个“主机名”来查询I-CSCF数据记录；若不输入，则表示所有的“主机名”。 取值范围：1～127位字母或字母与数字组成的字符串。 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                                |
| LNKMOD | 链路选择模式   | 用于指示系统需要按照哪个“链路选择模式”来查询I-CSCF数据记录；若不输入，则表示所有的“链路选择模式”。 取值范围： SESSIONIDBASED(基于会话ID)：同一个会话的所有信令消息都在同一条链路上传输。多个会话的消息按照轮选的方式在多条链路负荷分担。 POLLING(轮询方式)：当配置多条链路，信令消息在每条链路上负荷分担。 AORS(主备方式)：在主备链路选择方式下，如果主链路故障，则将某条备用链路升为主链路。默认第0条链路为主链路，当第0条链路不可用时，会自动选择其他可用链路。 ACTIVE(激活方式)：根据链路的激活状态，从第0条开始选择第一条激活的链路，将信令消息发往该链路。 ACTIVEWITHPRI(基于优先级的激活方式)：基于优先级的激活方式。 POLLINGWITHPRI(基于优先级的轮询方式)：基于优先级的轮询方式。 默认值：无。 说明：可选参数。 |

## 使用实例

1. 查询所有I-CSCF的信息：

   ```
   LST HICSCF:;
   ```

   ```
   %%LST HICSCF:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    HSS名称  I-CSCF名称  主机名             链路选择模式  特性列表                   HSS索引  I-CSCF索引

    HSS1     ICSCF1      icscf1.huawei.com  轮询方式        共享IFC, 别名ID, CSCF容灾  5        1         
    HSS2     ICSCF2      icscf2.huawei.com  轮询方式        共享IFC, 别名ID, CSCF容灾  4        0         
   (结果个数 = 2)

   ---    END
   ```
2. 查询I-CSCF的信息，“HSS名称”为“HSS1”，“主机名”为“icscf1.huawei.com”：

   ```
   LST HICSCF: HSSN="HSS1", HN="icscf1.huawei.com";
   ```

   ```
   %%LST HICSCF: HSSN="HSS1", HN="icscf1.huawei.com";%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
        HSS名称  =  HSS1
     I-CSCF名称  =  ICSCF1
         主机名  =  icscf1.huawei.com
   链路选择模式  =  轮询方式
       特性列表  =  共享IFC
                 =  别名ID
                 =  CSCF容灾
        HSS索引  =  5
     I-CSCF索引  =  1
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

以下列出的是未包含在本命令参数说明中的输出项，其他输出项的详细说明请参见本命令的参数说明。

| 输出项名称    | 输出项解释                                        |
|:---------|:---------------------------------------------|
| HSS索引    | 用于在配置数据库中定义一条HSS设备数据记录索引，该索引仅供内部使用，无实际含义。    |
| I-CSCF索引 | 用于在配置数据库中定义一条I-CSCF设备数据记录索引，该索引仅供内部使用，无实际含义。 |
