# 显示M3UA路由(DSP M3RT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询M3UA路由的状态信息。

## 注意事项

从源实体到目的实体的通道叫做M3UA路由，一条M3UA路由在归属端对应一个M3UA链路集。在ASP或IPSP（客户端）侧，通常只有一条路由从本地实体到特定目的实体；但是在SGP或IPSP（服务器端）侧，可以有多条路由从本地实体到特定目的实体。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                  |
|:-------|:-------|:----------------------------------------------------------------------|
| MN     | 模块号    | 用于查询模块号内M3UA路由的状态信息，若不输入，则表示所有模块。 取值范围：1～1023 默认值：无。 说明：无。            |
| DENMO  | 目的实体名称 | 用于请求系统显示哪个M3UA目的实体的M3UA路由的状态信息。 取值范围：1～32 位字符串。 默认值：无。 说明：无。          |
| LSNM   | 链路集名称  | 用于请求系统显示哪个链路集的M3UA路由的状态信息，若不输入，则表示所有链路集。 取值范围：1～32 位字符串。 默认值：无。 说明：无。 |

## 使用实例

显示“目的实体名称”为“LXT”的M3UA路由状态:

```
DSP M3RT: DENMO="LXT";
```

返回结果如下：

```
%%DSP M3RT: DENMO="LXT";%%
RETCODE = 0  操作成功

M3UA查询路由状态
----------------
  目的实体名称  =  LXT
    链路集名称  =  LXT
  传输允许状态  =  允许
  传输受限状态  =  未受限
    链路集状态  =  故障
信令链路选择码  =  NULL
      路由状态  =  不可用
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出结果解释                                                                                                                                                               |
|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 目的实体名称  | 用于返回指定的目的实体名称。                                                                                                                                                       |
| 链路集名称   | 用于返回指定的链路集名称。                                                                                                                                                        |
| 传输允许状态  | 用于返回当前M3UA路由的传输状态： 禁止：表示该M3UA路由对应的链路集内所有的链路故障，不能传输业务信令消息。 允许：表示该M3UA路由对应的链路集内至少有一条链路运行正常，可以传输业务信令消息。                                                                 |
| 传输受限状态  | 用于返回M3UA路由传输的受限状态： 受限：表示该M3UA路由受到约束条件（如消息发送优先级）的限制。 未受限：表示该M3UA路由不受任何条件限制。 本产品暂时不支持对于传输受限进行设置，系统对此只有一个状态（即未受限）。只有当收到对端设备发送的受限消息时，系统才会出现“受限”状态，其不会对M3UA链路的路由状态产生任何影响。 |
| 链路集状态   | 用于返回指定链路集的状态： 正常：表示该链路集中至少有一条链路处于正常状态。 故障：表示该链路集中所有的链路均处于故障状态。                                                                                                       |
| 信令链路选择码 | 用于返回同一链路集下多条链路之间信令业务负荷分担的相关信息。例如，当前链路的信令链路选择码为01 02 03 ，则表示上层用户如果填写的信令链路选择码为01、02或者03时，系统则可以选择该链路发送信令消息。                                                             |
| 路由状态    | 用于返回当前M3UA路由的状态： 可用：表示该路由的传输允许状态为“允许”，并且其对应的链路集状态为“正常”。当新增一条M3UA路由时，其默认状态为“可用”。 不可用：表示该路由的传输允许状态为“不允许”或者其对应的链路集状态为“故障”。 去激活：操作员使用DEA M3RT命令手动去激活M3UA路由，信令业务中断。       |
