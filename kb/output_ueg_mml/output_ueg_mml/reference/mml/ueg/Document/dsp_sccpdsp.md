# 显示SCCP目的信令点(DSP SCCPDSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询指定的SCCP目的信令点的基本信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
|:-------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MN     | CCU模块号  | 用于请求系统显示指定CCU模块内SCCP目的信令点的状态信息。 取值范围：1～1024。 默认值：无。 说明：如果输入的模块号为1024且查询的SCCP目的信令点只有一个时，将查询命令下发给所有状态正常的CCU模块。 如果输入的模块号为1024但查询的SCCP目的信令点不止一个时返回出错。 如果没有输入模块号，则将命令下发给状态正常的最小CCU模块。                                                                                                                                                                                                                                                                                                                                  |
| NI     | 网络指示    | 用于指定该目的实体的信令点编码位于哪一个信令网中，用户应根据实际情况进行设置。 取值范围： INT(国际主用网)INTB(国际备用网)NAT(国内主用网)NATB(国内备用网) 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                                                                                                                             |
| DPC    | 目的信令点编码 | 用于指定要显示的SCCP目的信令点编码。 取值范围：无。 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| OPC    | 源信令点编码  | 用于指定要显示的SCCP目的信令点对应的源信令点编码。 取值范围：无。 默认值：无。 说明：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| DPNM   | 目的信令点名称 | 用于请求系统显示哪个SCCP目的信令点的状态信息。 取值范围：长度不超过32的字符串。 默认值：无。 说明：该参数支持模糊查询功能。模糊查询功能是指操作员在LMT输入查询参数时，对于字符串或BCD码类型的查询参数而言:如果操作员输入的是一个完整的字符串或BCD码，则表示系统将按照完全匹配的方式执行查询操作。 如果操作员在输入的某个字符串或BCD码的末尾添加通配字符“%”，则表示系统将按照模糊匹配的方式执行查询操作。 该参数配置原则是：该参数的值域范围为：数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“_”、“.”、空格符、中文。 操作员只能在字符串或BCD码的末尾添加通配字符“%”，而不能在字符串或BCD码的前面、中间添加通配字符“%”。例如，“A市%”、“1390123%”是合法的输入，而“%A市”、“A市%区”、“%1390123”、“139%0123”均是不合法的输入。 如果某个命令同时存在有多个字符串或BCD码类型的查询参数，则操作员在一次查询操作中，只能对其中的一个查询参数使用模糊查询方式，而不能同时对两个或两个以上的查询参数使用模糊查询方式。 |

## 使用实例

1、显示“目的信令点名称”为“STP”的SCCP目的信令点：

```
DSP SCCPDSP: DPNM="STP";
```

返回结果如下：

## 输出结果说明

| 输出项名称     | 输出结果解释                                                                                                        |
|:----------|:--------------------------------------------------------------------------------------------------------------|
| 模块号       | 用于返回所请求显示的SCCP目的信令点的状态信息的CCU模块号。                                                                              |
| 信令点状态     | 用于返回当前目的信令点的状态： 允许：表示基于该信令点的三层协议可达，信令业务正常。 禁止：表示基于该信令点的三层协议不可达。 人工禁止：表示操作员使用SET SCCPDSP命令手动设置该目的信令点禁止，信令业务中断。 |
| SCCP状态    | 用于返回当前目的信令点的管理子系统的状态： 允许：表示该管理子系统运行正常。 禁止：表示到该子系统的底层链路不通、对端信令点不可达或者操作员使用SET SCCPSSN命令手动配置本端子系统禁止，子系统业务中断。     |
| 拥塞状态      | 用于返回当前SCCP链路在此目的信令点的拥塞信息： 拥塞：表示该SCCP链路在此目的信令点的消息流量过大，致使信令传递时延过长。 未拥塞：表示该SCCP链路在此目的信令点的消息流量正常。                 |
| 负荷分担信令点   | 用于返回该SCCP目的信令点的负荷分担信令点索引。                                                                                     |
| 负荷分担信令点状态 | 用于返回该SCCP目的信令点的负荷分担信令点状态。 允许：表示基于该信令点的三层协议可达，信令业务正常。 禁止：表示基于该信令点的三层协议不可达。                                     |
