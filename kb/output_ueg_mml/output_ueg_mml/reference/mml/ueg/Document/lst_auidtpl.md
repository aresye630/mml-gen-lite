# 查询AUID模板(LST AUIDTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询AUID（application unique ID ）模板配置信息。

- 若需要查询全部AUID模板配置信息，请不要输入任何参数。
- 若需要查询某个AUID模板配置信息，请输入“索引”参数或“应用区分标识”参数或这两个参数的组合。

  **说明** 

  该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                            |
|:-------|:-------|:------------------------------------------------|
| ID     | 索引     | 用于指示系统需要按照哪个“索引”查询AUID模板配置信息；若不输入，则表示所有的索引。     |
| AUID   | 应用区分标识 | 用于指示系统需要按照哪个“应用区分标识”查询AUID模板配置信息；若不输入，则表示所有的索引。 |

## 使用实例

1. 查询所有的AUID模板配置信息，不携带参数：

   ```
   LST AUIDTPL:;
   ```

   ```
   %%LST AUIDTPL:;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
    索引   应用区分标识

    1      simservs.ngn.etsi.org      
    2      simservs2.ngn.etsi.org        
   (结果个数 = 2)

   ---    END
   ```
2. 查询“索引”为“1”，“应用区分标识”为“simservs.ngn.etsi.org”的AUID模板配置信息：

   ```
   LST AUIDTPL: ID=1, AUID="simservs.ngn.etsi.org";
   ```

   ```
   %%LST AUIDTPL: ID=1, AUID="simservs.ngn.etsi.org";%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
           索引  =  1
   应用区分标识  =  simservs.ngn.etsi.org
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD AUIDTPL**命令的参数说明。
