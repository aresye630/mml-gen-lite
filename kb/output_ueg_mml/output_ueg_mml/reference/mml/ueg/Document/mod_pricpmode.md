# 修改优先级配比模式记录(MOD PRICPMODE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成消息查询的成功率和系统可靠性下降，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为维护命令，用于在消息流控的场景下修改优先级配比模式记录。

- 当每秒收到的各类消息数量小于“最小消息数”设置的值，则放行所有该类消息，不对其进行流控。
- 当每秒接收到的某类消息数量超过“最小消息数”设置的值，则对超过最小消息数的消息进行流控。

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CPMODEID | 消息名称   | 该参数用于标识一个协议中的消息名称。 取值范围： “UAR(UAR)”“SAR_IMS(SAR)”“LIR(LIR)”“MAR_IMS(MAR)”“UDR(UDR)”“PUR_IMS(PUR)”“SNR(SNR)”“ULR(ULR)”“AIR(AIR)”“PUR_SAE(PUR)”“NOR(NOR)”“SAR_SAE(SAR_SAE)”“MAR_SAE(MAR_SAE)”“RTR_SAE(RTR_SAE)”“RIR(RIR)”“MEID_CHECK(MEID_CHECK)”“SNR_LRF(SNR_LRF)”“A(A)”“AAAA(AAAA)”“SRV(SRV)”“NAPTR(NAPTR)”“INI_SND(主动下发类)”“LOC_MND(位置管理类)”“PAGE(呼叫类)”“SRI_S(路由类)”“MAR_IMS_ZH(MAR_IMS_ZH)”“CLR(CLR)”“IDR(IDR)”“DSR(DSR)”“RSR(RSR)”“PLR(PLR)”“DER(DER)”“AAR(AAR)”“STR(STR)”“RTR_AAA(RTR_AAA)”“PPR(PPR)” 默认值：无。 |
| CPRATIO  | 配比模式比率 | 该参数用于标识当前优先级配比模式所对应的比率。 取值范围：0～100 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| CPNUM    | 最小消息数  | 该参数用于标识当前消息的最低放行数量。 取值范围：0～65535 0：表示不对当前消息做最低放行数量保护。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                  |

## 使用实例

修改优先级配比模式记录信息，“消息名称”为“SAR\_IMS(SAR)”，“配比模式比率”为“40”，“最小消息数”为“100”：

`MOD PRICPMODE: CPMODEID=SAR_IMS, CPRATIO=40, CPNUM=100;`
