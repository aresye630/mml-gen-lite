# 删除Diameter主机名域名配置(RMV DIAMNAMECFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除一条系统配置的被割接局点用户所在MME的Diameter主机名域名关联记录。

## 注意事项

随意删除一条被割接局点用户所在MME的Diameter主机名域名关联记录会导致UDM无法与被割接局点正常通信，导致业务中断。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                  |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CFGINDEX | 索引     | 可选必选说明：必选参数 参数含义：标识一条被割接局点用户所在MME的Diameter主机名域名关联记录的关键参数。用于指定根据哪个索引来删除一条已配置被割接局点用户所在MME的Diameter主机名域名关联记录。操作员可以使用LST DIAMNAMECFG 命令查询获得。 取值范围：1~10000。 默认值：无。 配置原则：无。 |

## 使用实例

当不再使用某条被割接局点用户所在MME的Diameter主机名域名关联记录时，需要将其删除，配置举例如下：

```
RMV DIAMNAMECFG: CFGINDEX=2;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释   | 原因分析                                          | 处理建议                                                          |
|-------:|:-------|:----------------------------------------------|:--------------------------------------------------------------|
| 335821 | 记录不存在  | 输入“索引”对应的一条被割接局点用户所在MME的Diameter主机名域名关联记录不存在。 | 根据实际情况，重新输入参数，确保输入的“索引”参数已存在。已存在的“索引”可以执行LST DIAMNAMECFG命令查询。 |
