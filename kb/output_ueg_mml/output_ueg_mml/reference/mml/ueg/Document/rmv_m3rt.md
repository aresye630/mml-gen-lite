# 删除M3UA路由(RMV M3RT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于从配置数据库中删除一条M3UA路由数据记录。

## 注意事项

- 在正常情况下，删除一条M3UA路由数据记录的操作步骤为：**RMV M3RT**。
- 该命令不允许进行批操作。

**须知** 

如果操作员删除某条M3UA路由数据记录，将导致本局到相应网元的目的信令点不可达，可引发业务中断的重大事故，请操作员谨慎执行。

## 参数说明

| 参数标识   | 参数名称   | 参数描述                                                                                                  |
|:-------|:-------|:------------------------------------------------------------------------------------------------------|
| DENM   | 目的实体名称 | 标识一条M3UA路由数据记录的关键字段之一，用于指定需要删除哪一条M3UA路由数据记录，操作员可以使用LST M3RT命令查询获得。 取值范围：长度不超过32的字符串。 默认值：无。 说明：无。     |
| LSNM   | 链路集名称  | 用于指定到达该的目的实体的M3UA路由，即本局通过哪个M3UA链路集传输信令，该参数必须先由ADD M3LKS命令定义，然后才能在此处引用。 取值范围：长度不超过32的字符串。 默认值：无。 说明：无。 |

## 使用实例

删除M3UA路由，“目的实体名称”为“M3DE”，“链路集名称”为“M3LKS”：

```
RMV M3RT: DENM="M3DE", LSNM="M3LKS";
```
