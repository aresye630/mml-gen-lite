# 查询SCTP/TCP链路传输质量检测参数（LST LNKCHK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询链路传输质量检测参数数据记录。

- 若需要查询全部SCTP/TCP链路传输质量检测参数数据记录，请不要输入任何参数。
- 若需要查询某条SCTP/TCP链路传输质量检测参数数据记录，请输入参数“传输层协议类型”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                            |
|:-------|:--------|:--------------------------------|
| PROTO  | 传输层协议类型 | 用于指定系统按照哪个传输层协议类型来查询链路传输质量检测参数。 |

## 使用实例

1. 查询全部SCTP/TCP链路传输质量检测参数：

   `LST LNKCHK:;`

   ```
   %%LST LNKCHK:;%%
   RETCODE = 0  操作成功

   查询结果如下
   -----------
   传输层协议类型  启动链路传输质量检测功能  检测周期  告警周期  消息重传比例阈值  消息平均确认时延阈值  消息确认时延平均偏差阈值

    TCP协议类型     是                        5         300       5                 1000                  500                     
    SCTP协议类型    是                        5         300       5                 1000                  500                     
   (结果个数 = 2)

   ---    END
   ```
2. 查询“传输层协议类型”为“SCTP”的链路传输质量检测参数：

   `LST LNKCHK: PROTO=SCTP;`

   ```
   %%LST LNKCHK: PROTO=SCTP;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
             传输层协议类型  =  SCTP协议类型
   启动链路传输质量检测功能  =  是
                   检测周期  =  5
                   告警周期  =  300
           消息重传比例阈值  =  5
       消息平均确认时延阈值  =  1000
   消息确认时延平均偏差阈值  =  500
   (结果个数 = 1)

   ---    END
   ```
