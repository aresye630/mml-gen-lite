# 设置BE北向配置信息(SET BENORTHCON)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令设置BE北向配置信息，生成EpRpStaUdFe和EpRpStaUdBe北向配置文件，用于北向配置数据导出。

该命令的使用场景：在网元部署及数据对接完成后进行设置。

## 注意事项

系统中设置的BE北向配置信息记录数不能超过1024条。

## 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                                      |
|:--------|:---------|:----------------------------------------------------------------------------------------------------------|
| OBJNAME | 对象名称     | 可选必选说明：必选参数 参数含义：用于标识BE北向配置信息的对象名称。 取值范围： UD(Ud)：用于表示BE与FE之间的拓扑关系。RS(Rs)：用于表示BE与BE之间的备份关系。 默认值：无。 配置原则：无。 |
| ID      | ID       | 可选必选说明：必选参数 参数含义：用于标识BE北向配置信息的ID。 取值范围：由长度不超过127位的字符串组成。 默认值：无。 配置原则：无。                                   |
| LOCIP   | 本端网元IP地址 | 可选必选说明：必选参数 参数含义：用于标识BE北向配置信息的本端网元IP地址。 取值范围：由长度不超过255位的字符串组成。 默认值：无。 配置原则：无。                             |
| PEERIP  | 对端网元IP地址 | 可选必选说明：必选参数 参数含义：用于标识BE北向配置信息的对端网元IP地址。 取值范围：由长度不超过255位的字符串组成。 默认值：无。 配置原则：无。                             |

## 使用实例

设置BE北向配置信息：“对象名称”为“UD(Ud)”，“ID”为“abc”，“本端网元IP地址”为“127.12.0.23”，“对端网元IP地址”为“10.5.11.55”。

```
SET BENORTHCON: OBJNAME=UD, ID="abc", LOCIP="127.12.0.23", PEERIP="10.5.11.55";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释               | 原因分析                               | 处理建议                                                                                   |
|-------:|:-------------------|:-----------------------------------|:---------------------------------------------------------------------------------------|
| 260182 | 记录已经存在             | 系统中已存在相同配置信息的数据记录。                 | 该命令所有参数唯一标识一条记录，请重新输入一条未被配置的数据记录，已配置的BE北向配置信息可通过LST BENORTHCON命令查询。                    |
| 335977 | 参数LOCIP或PEERIP已存在。 | 参数“本端网元IP地址”或“对端网元IP地址”指定的IP地址已存在。 | 根据实际情况，重新输入参数“本端网元IP地址”或“对端网元IP地址”的取值，确保其取值与已存在IP地址不冲突。已存在的IP地址可以执行LST BENORTHCON命令查询。 |
