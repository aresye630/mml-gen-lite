# 查询模块CPU配额(LST UDMLITECPUQUOTA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于查询模块的CPU配额。

- 若要查询全部模块类型的配置信息，请不要输入任何参数。
- 若要查询某种模块类型的配置信息，请输入“模块类型”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                    |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------|
| MT     | 模块类型   | 可选必选说明：可选参数 参数含义：用于指示系统按照模块类型来查询模块的CPU配额信息；若不输入，则表示所有的模块类型。 取值范围：CCU(CCU)ACF(ACF)APF(APF) 默认值：无 配置原则：无。 |

## 使用实例

1. 查询某个模块类型的配置信息：

   “模块类型”：“CCU”

   ```
   LST UDMLITECPUQUOTA：MT=CCU;
   ```

   ```
   %%LST UDMLITECPUQUOTA: MT=CCU;%%
   RETCODE = 0  操作成功
   操作结果如下
   ------------
      模块类型  =  CCU
   模块CPU配额  =  150
   (结果个数 = 1)
   ---    END
   ```
