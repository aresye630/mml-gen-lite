# 删除远端EIR配置(RMV REIRCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条远端EIR的数据记录。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

随意删除远端EIR配置会导致UDM无法与远端EIR正常通信。

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                                     |
|:--------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------|
| EIRNAME | 远端EIR名称 | 可选必选说明：必选参数 参数含义：标识远端EIR数据记录的关键字段，用于指定需要删除哪一条远端EIR数据记录，操作员可以使用LST REIRCFG命令查询获得。 取值范围：长度不超过127的字符串。 默认值：无。 配置原则：该参数不能只输入一个空格，并且字母不区分大小写。 |

## 使用实例

删除“远端EIR名称”为“EIR01”的远端EIR数据记录。

```
RMV REIRCFG: EIRNAME="EIR01";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释         | 原因分析                        | 处理建议                                           |
|-------:|:--------------|:----------------------------|:-----------------------------------------------|
| 264034 | 关键参数取值不能为一个空格 | “远端EIR名称”参数只输入一个空格。         | “远端EIR名称”参数不能只输入一个空格。                          |
| 335876 | 指定的名称不存在      | “远端EIR名称”参数对应的远端EIR数据记录不存在。 | 可以先通过LST REIRCFG命令查询“远端EIR名称”对应的远端EIR数据记录是否存在。 |
