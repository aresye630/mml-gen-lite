# 增加网元业务IP地址(ADD SRVIPADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加FE与BE设备之间业务通信的IP地址。

## 注意事项

- 当“IP类型”为“IPV4(IPV4)”时，地址、网关和子网掩码匹配的IP类型必须为IPv4。
- 当“IP类型”为“IPV6(IPV6)”时，地址、网关和前缀长度匹配的IP类型必须为IPv6。
- 当HLR/HSS服务和dbbroker共Location部署时，FE上**ADD SRVIPADDR**添加的DSG IP地址与IP索引和dbbroker上**ADD DBSIPADDR**添加的IP地址与IP索引一致才能确保链路正常。
- 在执行本命令前，请执行**LST L3VPNINST**、**LST VPNINSTAF**和**LST AUTOSCALINGSERVICE**命令查询待配置的VPN名称是否在报文中存在，如果**LST L3VPNINST**、**LST VPNINSTAF**和**LST AUTOSCALINGSERVICE**报文中不存在，请使用**ADD L3VPNINST**、**ADD VPNINSTAF**和**ADD AUTOSCALINGSERVICE**命令进行配置。
- 该命令不允许进行批操作。
- 当“业务IP类型”取值为“DSG(DSG)”时，IP个数需根据交换机是否支持“SCTP协议基于端口号的ECMP负载均衡”功能确定：

  **说明** 

  当交换机不是华为设备时，请联系对应厂商确认交换机是否支持“SCTP协议基于端口号的ECMP负载均衡”功能。

  - 当交换机不支持“SCTP协议基于端口号的ECMP负载均衡”功能时，IP个数需根据IPU虚拟机（裸机场景为IPU POD，即cslbipc8-pod）个数决定，IPU个数为偶数时，IP数量与IPU个数相同。IPU个数为奇数时，IP数量则为IPU个数加一。
  - 当交换机支持“SCTP协议基于端口号的ECMP负载均衡”功能时，申请1个IP地址。
- UDM不支持该命令。

## 使用实例

在某开局场景下，增加本端网元的业务IP地址：“业务IP索引”为“1”，“业务IP类型”为“DSG”，“IP类型”为“IPV4(IPV4)”，“IP地址1的VPN名称”为“VN1”，“本地Location IPV4地址1”为“192.168.100.1”，“本地Location IPV4网关1”为“192.168.100.0”，“本地Location IPV4子网掩码1”为“255.255.255.255”，“IP地址2的VPN名称”为“VN2”，“本地Location IPV4地址2”为“192.168.200.1”，“本地Location IPV4网关2”为“192.168.200.0”，“本地Location IPV4子网掩码2”为“255.255.255.255”：

```
ADD SRVIPADDR: SRVINDEX=1, SRVIPTYPE=DSG, IPVER=IPV4, IP1VPNNAME="VN1", IPV4IP1="192.168.100.1", IPV4GW1="192.168.100.0", IPV4MASK1="255.255.255.255",  IP2VPNNAME="VN2", IPV4IP2="192.168.200.1", IPV4GW2="192.168.200.0", IPV4MASK2="255.255.255.255";
```
