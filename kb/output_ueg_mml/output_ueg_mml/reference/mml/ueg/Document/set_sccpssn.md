# 设置SCCP子系统状态(SET SCCPSSN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为配置类命令，用于在配置数据库中设置一条SCCP子系统在本局的状态数据记录。在该命令中，关键参数“网络指示”需要与对端信令设备协商。

## 注意事项

- 该命令为测试人员提供一个维护接口，以设置SCCP子系统在本局所显示的状态，并不会影响到远端的信令点。
- 需要指出的是，如果SCCP子系统的状态设置为“禁止”，将导致信令业务中断。请谨慎使用此命令！
- 如果SCCP子系统所在的信令点的状态设置为“禁止”，则子系统的状态设置操作将会失败。
- 该命令不允许进行批操作。

## 使用实例

设置SCCP子系统状态，“网络指示”为“国内主用网”，“信令点编码”是“0C0304”，“源信令点编码”是“0C0204”，“SSN”为“MAP”：

```
SET SCCPSSN:OP=PROHIBIT, NI=NAT, SPC="0C0304", OPC="0C0204", SCCPSSN=MAP;
```
