# 查询短消息RN路由(LST SMSRNROUT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询短消息RN（Route Number）路由数据。

- 若需要查询全部短消息RN路由信息，不输入任何参数。
- 若需要查询某个短消息RN路由信息，请输入“路由码”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                          |
|:-------|:-------|:----------------------------------------------|
| RN     | 路由码    | 用于指示系统按照哪个路由码来查询短消息RN路由数据信息；若不输入，则表示所有的路由码信息。 |

## 使用实例

1. 查询所有的短消息RN路由数据信息。命令如下：

   ```
   LST SMSRNROUT:;
   ```

   ```
   %%LST SMSRNROUT:;%%
   RETCODE = 0  操作成功

   短消息外携路由信息
   ------------------
    客户端                号码        链路状态      协议版本

    460000009123456       1112        Disconnected  NULL    
    460000009123457       1113        Disconnected  NULL    
    admin                 1112        Disconnected  NULL    
   (结果个数 = 3)

   ---    END
   ```
2. 查询“路由码”为“1112”的短消息RN路由数据信息。命令如下：

   ```
   LST SMSRNROUT: RN="1112";
   ```

   ```
   %%LST SMSRNROUT: RN="1112";%%
   RETCODE = 0  操作成功

   短消息外携路由信息
   ------------------
     客户端  =  admin
       号码  =  1112
   链路状态  =  Disconnected
   协议版本  =  NULL
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

以下列出的是未包含在本命令输入参数中的输出项，其他输出项的详细说明请参见

**ADD SMSRNROUT**

。

| 输出项名称   | 输出项解释                 |
|:--------|:----------------------|
| 客户端     | 用于显示短消息RN路由的客户端名称。    |
| 号码      | 用于显示短消息RN路由的路由号码。     |
| 链路状态    | 用于显示短消息RN路由对应链路的链路状态。 |
| 协议版本    | 用于显示短消息RN路由使用的协议版本。   |

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释             | 原因分析             | 处理建议                   |
|------:|:------------------|:-----------------|:-----------------------|
|   440 | 没有找到活动模块进行通讯，操作中止 | PAU模块对应的数据记录不存在。 | 增加PAU模块信息，重新执行该命令查询数据。 |
