# 显示指定链路集的MTP链路(DSP N7LSLNK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询指定链路集内MTP链路的运行状态。

## 注意事项

该命令的“链路集名称”参数支持模糊查询功能。模糊查询功能是指操作员在LMT输入查询参数时，对于字符串或BCD码类型的查询参数而言，如果操作员输入的是一个完整的字符串或BCD码，则表示系统将按照完全匹配的方式执行查询操作；如果操作员在输入的某个字符串或BCD码的末尾添加通配字符“%”，则表示系统将按照模糊匹配的方式执行查询操作。对于此类参数，其配置原则是：

- 该参数的值域范围为：数字“0～9”、大写字母“A～Z”、小写字母“a～z”、特殊字符“-”、“\_”、“.”、空格符、中文。
- 操作员只能在字符串或BCD码的末尾添加通配字符“%”，而不能在字符串或BCD码的前面、中间添加通配字符“%”。例如，“A市%”、“1390123%”是合法的输入，而“%A市”、“A市%区”、“%1390123”、“139%0123”均是不合法的输入。
- 如果某个命令同时存在有多个字符串或BCD码类型的查询参数，则操作员在一次查询操作中，只能对其中的一个查询参数使用模糊查询方式，而不能同时对两个或两个以上的查询参数使用模糊查询方式。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                 |
|:-------|:-------|:---------------------------------------------------------------------|
| LSNM   | 链路集名称  | 用于请求系统显示哪个链路集内MTP链路的运行状态，若不输入，则表示所有链路集。 取值范围：1～32 位字符串 默认值：无。 说明：无。  |
| LS     | 链路状态   | 用于请求系统显示哪种特定的状态信息。 取值范围：IU(使用中)FAIL(失败)ALL(所有状态) 默认值：ALL(所有状态) 说明：无。 |

DSP N7LSLNK: LSNM="STP";

## 输出结果说明

| 输出项名称   | 输出结果解释                                                                                                                                                                                                                                         |
|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ID      | 用于返回当前记录中链路集名称字段对应的链路集索引，链路集索引由系统根据操作员配置数据的先后顺序自动分配、且仅在系统内部使用，它与链路集名称一一对应。                                                                                                                                                                     |
| 链路集名称   | 用于返回指定的链路集名称。                                                                                                                                                                                                                                  |
| 是否使用    | 用于返回MTP链路的使用信息： 正在使用：表示该链路正在传输业务信令消息。 空闲：表示该链路没有传输信令业务消息。                                                                                                                                                                                      |
| 是否故障    | 用于返回当前链路的故障信息： 正常：表示该链路运行正常。 故障：表示该链路运行出现故障，不能传输信令业务消息。                                                                                                                                                                                        |
| 是否闭塞    | 用于返回当前链路的闭塞信息： 闭塞：表示链路远端处理机故障，不能传输信令业务消息。 未闭塞：表示链路的远端处理机正常，可以传输信令业务消息。                                                                                                                                                                         |
| 是否激活    | 用于返回当前链路的激活信息： 已激活：表示链路已经建立成功，并且已经被激活，可以传输信令业务消息。 未激活：表示底层的链路已经建立，其用户层链路没有建立成功，不能传输用户层信令业务消息。                                                                                                                                                  |
| 本端是否禁止  | 用于返回当前MTP链路的本地管理禁止信息： 本地管理禁止：表示操作员通过INH N7LNK命令对该链路执行了管理禁止操作，处于该状态的链路不能传输信令业务消息。 本地管理解禁：表示本端链路没有被管理禁止，可以传输信令业务消息。 “管理禁止”是一种信令网管理操作，该操作不会引起MTP-2层链路状态的改变，但禁止使用该链路来传送有关业务（TUP、ISUP）的消息，其测试、管理等消息仍可以传送。此时系统将产生一系列的信令网管理消息使原来选择该链路发送和接收的消息不再选择该链路。 |
| 对端是否禁止  | 用于返回当前MTP链路的对端管理禁止信息： 对端管理禁止：表示操作员在对端设备对该链路执行了管理禁止操作，处于该状态的链路不能传输信令业务消息。 对端管理解禁：表示对端链路没有被管理禁止，可以传输信令业务消息。                                                                                                                                      |
| 是否拥塞    | 用于返回当前MTP链路的拥塞信息： 拥塞：表示该MTP链路上消息流量过大而产生拥塞。 未拥塞：表示该链路上消息流量正常。 当链路出现拥塞时，系统将自动执行拥塞控制机制，限制低优先级别信令消息的发送；当拥塞解除后，系统将自动恢复正常。                                                                                                                           |
| 是否倒换    | 用于返回当前MTP链路的倒换状态： 未发生倒换：表示该MTP链路没有发生倒换，可以正常投入业务使用。 正在倒换：表示该MTP链路正在执行倒换操作，该链路上的业务转移到其他链路上进行处理。                                                                                                                                                  |
| 是否倒回    | 用于返回当前MTP链路的倒回状态： 未发生倒回：表示该MTP链路被倒换后一直没有被倒回。 正在倒回：表示该MTP链路正在执行倒回操作，转移至其他链路处理的业务倒换回该链路进行处理。                                                                                                                                                     |
| 信令链路选择码 | 用于返回同一链路集下多条链路之间信令业务负荷分担的相关信息。例如，当前链路的信令链路选择码为01 02 03 ，则表示上层用户如果填写的信令链路选择码为01、02或者03时，系统则可以选择该链路发送信令消息。                                                                                                                                       |
