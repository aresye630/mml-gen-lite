# 查询3GPP AAA事件日志格式(LST EVENTLOG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询UDM-UIM打印的日志信息：

- 若需要查询UDM-UIM打印的全部日志信息，请不要输入任何参数。
- 若需要查询某个接口打印的日志信息，请输入“接口”参数和其它参数的组合。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                    |
|:--------|:-------|:--------------------------------------------------------|
| IF      | 接口     | 用于指示系统需要按照哪个接口名称查询UDM-UIM打印的日志信息；若不输入，则表示查询所有接口打印的日志信息。 |
| MSG     | 消息     | 用于指示系统需要按照哪个消息名称查询UDM-UIM打印的日志信息；若不输入，则表示查询所有消息的日志信息。   |
| SCOPE   | 范围     | 用于指示系统需要打印成功还是失败的日志信息；若不输入，则表示查询所有成功和失败的日志信息。           |
| ISPRINT | 是否打印   | 用于指示系统是否需要打印日志信息。                                       |

## 使用实例

1. 查询某条日志信息，携带参数如下：
   - “接口”为“STa(STa)”
   - “范围”为“SUCCESS(成功)”

   执行命令如下：

   ```
   LST EVENTLOG: IF=STa, SCOPE=SUCCESS;
   ```

   返回结果如下：

   ```
   %%LST EVENTLOG: IF=STa, SCOPE=SUCCESS;%%
   RETCODE = 0  操作成功

   查询结果如下
   ------------
       接口  =  STa
       消息  =  DER
       范围  =  成功
   是否打印  =  YES
   (结果个数 = 1)

   ---    END
   ```
