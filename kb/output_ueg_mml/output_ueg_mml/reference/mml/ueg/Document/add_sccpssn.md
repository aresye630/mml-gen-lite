# 增加SCCP子系统(ADD SCCPSSN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于在配置数据库中增加一条SCCP子系统号数据记录。在该命令中，关键参数“SCCP子系统号”需要与对端信令设备协商。

## 注意事项

通常情况下按照如下原则配置，当对端网元有特殊要求时，以对端网元要求为准。

- HSS9860上需要配置“SSN”为如下取值的本端子系统：“SCMG(SCMG 0x01)”、“HLR(HLR 0x06)”、“EIR(EIR 0x09)”（仅当本局作为EIR网元工作时添加）、“MSC(MSC 0x08)”（仅当本局使用短消息前转业务时添加），即信令点编码和源信令点编码相同的记录。
- HSS9860与对端连接时，需要配置“SSN”为如下取值的远端子系统：
  - 与VMSC对接数据时增加：“SCMG(SCMG 0x01)”、“MSC(MSC 0x08)”、“VLR(VLR 0x07)”。
  - 与GMSC对接数据时增加：“SCMG(SCMG 0x01)”、“MSC(MSC 0x08)”。
  - 与SGSN对接数据时增加：“SCMG(SCMG 0x01)”、“SGSN(SGSN 0x95)”。
  - 与STP对接数据时增加：“SCMG(SCMG 0x01)”。
  - 与SG对接数据时增加：“SCMG(SCMG 0x01)”。
  - 与SMSC对接数据时增加：“SCMG(SCMG 0x01)”、“MSC(MSC 0x08)”。
  - 与SCP对接数据时增加：“SCMG(SCMG 0x01)”、“GSMSCF(GSM SCF 0x93)”。
  - 与GMLC对接数据时增加：“SCMG(SCMG 0x01)”、“GMLC(GMLC 0x91)”。
  - 与NPDB对接数据时，根据协议，需要配置“SSN”为如下取值的远端子系统：
    - 基于MAP协议，需要增加“SCMG(SCMG 0x01)”、“HLR(HLR 0x06)”、“MAP(MAP 0x05)”。
    - 基于INAP协议，需要增加“SCMG(SCMG 0x01)”、“OTAF(OTAF 0x0C)”。
    - 基于CAP协议，需要增加“SCMG(SCMG 0x01)”、“CAP(CAP 0x92)”。

## 参数说明

| SSNNM   | SSN名称    | 用于在本局的配置数据库中唯一标识一个SCCP子系统号，其值域类型为字符串。 取值范围：长度不超过32位的字符串，字符串只允许输入：0-9，a-z，A-Z，“-”、“_”、“.”、空格符、和中文字符。 默认值：无。 说明：需要指出的是：对于操作员在客户端输入的字符串，系统在操作OMU数据库之前将自动进行如下处理：将该字符串中的所有英文字母全部转换成大写、并将该字符串中最左边与最右边的空格删除掉。例如，假设操作员在客户端输入的字符串为“区域abc ”，则系统在操作OMU数据库之前将自动将该字符串转换为“区域ABC”。 对于操作员通过本命令配置的某一条具体的数据记录而言，假设该数据记录中“SCCP子系统名称”字段的原取值为A，如果操作员后续需要将该字段的取值由A修改为B，则其可以通过MOD SCCPSSN命令中的“新SCCP子系统名称”参数重新进行定义。此时，对于配置数据库中索引了取值为A的所有数据记录的“SCCP子系统名称”字段，系统将自动把这些字段的值由A修改为B。                                                                                                                                                                                                      |

## 使用实例

1、增加SCCP子系统号，“SSN名称分别”为“Local\_SCMG”和“Local\_MSC”，“SSN”为“SCMG”和“MSC”，“网络指示”为“国内主用网”，“信令点编码”和“源信令点编码”均为“0x0DFF9E”（本局信令点编码），其余参数使用默认值：

```
ADD SCCPSSN: SSNNM="Local_SCMG", NI=NAT, SSN=SCMG, SPC="0DFF9E", OPC="0DFF9E";
```

```
ADD SCCPSSN: SSNNM="Local_MSC", NI=NAT, SSN=MSC, SPC="0DFF9E", OPC="0DFF9E";
```

2、增加SCCP子系统号，“SSN名称分别”为“SCCP\_SCMG”和“SCCP\_SSN”，“SSN”为“SCMG”和“HLR”，“信令点编码”为“0x0DFF40”，“源信令点编码”为“0x0DFF9E”：

```
ADD SCCPSSN: SSNNM="SCCP_SCMG", NI=NAT, SSN=SCMG, SPC="0DFF40", OPC="0DFF9E";
```

```
ADD SCCPSSN: SSNNM="SCCP_SSN", NI=NAT, SSN=HLR, SPC="0DFF40", OPC="0DFF9E";
```
