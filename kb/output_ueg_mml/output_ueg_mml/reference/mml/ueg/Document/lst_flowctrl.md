# 查询流量控制参数(LST FLOWCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于在配置数据库中查询流量控制参数。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询流量控制参数。

```
LST FLOWCTRL:;
```
