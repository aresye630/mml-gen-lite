# 删除远端DSG(RMV RDSG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，如果执行不当会导致业务中断，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于删除远端DSG。

## 注意事项

- 删除远端DSG将影响本端DSG和远端DSG的网络连接，导致业务中断，请谨慎使用。
- 要删除的远端DSG配置必须存在。
- 删除远端DSG之后，必须在远端的Location上通过执行**RMV MODULE**命令删除对应的DSG模块，然后分别在本Location和远端Location执行**ACT IPDISP**，重新激活链路。

## 参数说明

| 参数标识    | 参数名称         | 参数说明                                                 |
|:--------|:-------------|:-----------------------------------------------------|
| RLOCID  | 远端Location标识 | 远端Location的标识。远端Location和远端网元一一对应。 取值范围：1～512 默认值：无。 |
| RDSGMID | 远端DSG模块号     | 远端DSG模块号。 取值范围：1～2047 默认值：无。                         |

## 使用实例

删除远端DSG。远端Location标识为3，远端DSG模块号为3。

`RMV RDSG: RLOCID=3, RDSGMID=3;`
