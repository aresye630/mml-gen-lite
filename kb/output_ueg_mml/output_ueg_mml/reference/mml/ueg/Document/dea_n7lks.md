# 去激活MTP链路集 (DEA N7LKS)

- 命令功能

- 参数说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

命令为维护类命令，用于请求系统对指定的MTP链路集执行去激活。

该命令仅适用于测试或维护的操作场景，当某MTP链路集因误码率高、传输时延大等原因造成内部多条链路出现频繁闪断现象时，操作员可以执行此操作。

**说明** 

误码率是指错误接收的码元数在传送总码元中所占的比例。

## 注意事项

- 1次操作只能去激活1个MTP链路集。
- 必须保证所去激活的MTP链路集在MTP链路集表中存在。 MTP链路集可以通过输入“链路集名称”进行定位。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                |
|:-------|:-------|:--------------------------------------------------------------------|
| LSNM   | 链路集名称  | 标识一条MTP链路集数据记录的关键字段，用于指定需要对哪一条MTP链路集进行去激活操作，操作员可以使用LST N7LKS命令查询获得。 |

## 使用实例

去激活MTP链路集，“链路集名称”为“TEST”：

```
DEA N7LKS: LSNM="TEST";
```
