# 查询SCTP基准负荷(LST BSLPERF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询SCTP基准负荷。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询SCTP基准负荷：

`LST BSLPERF:;`

```
%%LST BSLPERF:;%%
RETCODE = 0  操作成功

BSG模块链路基准负荷
-------------------
           协议类型  =  M3UA
链路的基准负荷(PPS)  =  5000
   BSG基准负荷(PPS)  =  8000
(结果个数 = 1)

---    END
```

## 输出结果说明

输出参数的详细描述，请参考命令**SET BSLPERF**。
