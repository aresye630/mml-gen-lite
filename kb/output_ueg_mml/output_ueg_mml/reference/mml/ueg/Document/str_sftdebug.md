## 命令功能

**须知** 

该命令属于高危命令，该操作可能会导致系统处理能力下降。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令为维护类命令，用于设置UDM软件调试开关。在调试阶段，可打开软件调试开关，将所有的日志输出到磁盘，以便了解软件运行状态是否正常，发现问题后能及时定位并处理。软件调试命令包含了OM特性的公共软调控制部分和各个模块进程私有的软调控制部分。

**说明** 

使用本命令打开软件调试开关时，输出的日志即为主机日志，包括：运行日志、调试日志和操作系统日志。当未设置“参数48”时，对于DEBUG级别的日志，系统默认会在1分钟后自动关闭该级别日志输出，该命令的各参数详细说明参见“UDM软件调试命令专家维护参数”。

日志文件存放于UDM的“/opt/ne/MEID/proc/workspace0/prog”目录下，可使用文件传输进行下载。关于主机日志的相关信息，具体请参见产品文档的“主机日志”。

## 注意事项

- 打开软件调试开关会造成性能急剧下降，只供华为技术支持工程师在调测阶段使用，严禁网上局点打开此开关。
- 当完成软件调试任务之后，需要把“参数0”～“参数49”所有参数设置为“0”以关闭此开关。
- 该命令不允许进行批操作。

## 使用实例

输出本地日志文件设置。设置模块号为5，PID为181的进程输出日志到本地文件。

```
STR SFTDEBUG: MID=5, EX=ACTIVE, LN=FRONT, PID=181, CTRL=52, PM0=2, PM1=1;
```
