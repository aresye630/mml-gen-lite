# 删除网络应用功能AP列表数据(RMV NAFIDAP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于从配置数据库中删除一组AP的FQDN与AP域名或AP IP地址的映射关系。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

删除AP的FQDN与AP域名的映射关系，可能会导致网络的安全性降低，请谨慎操作。

## 参数说明

| 参数标识     | 参数名称       | 参数说明                                                                                                                                                          |
|:---------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FQDN     | FQDN       | 标识AP的FQDN的关键字段之一，用于指定需要删除哪个AP的FQDN与AP域名的映射关系信息。操作员可以使用LST NAFIDAP命令查询获得。 需要指出的是，该参数不区分大小写，在执行LST NAFIDAP命令查询出的报文中为全小写形式。 取值范围：长度不超过127的字符串。                   |
| REALM    | 域名         | 标识AP的FQDN与AP域名映射关系的关键字段之一，用于指定需要删除哪个AP域名对应的某组AP的FQDN与AP域名的映射关系信息。操作员可以使用LST NAFIDAP命令查询获得。 需要指出的是，该参数不区分大小写，在执行LST NAFIDAP命令查询出的报文中为全小写形式。 取值范围：长度不超过127的字符串。 |
| ADDRTYPE | IP地址类型     | 标识AP的FQDN与AP IP地址映射关系的关键字段之一，用于指定需要删除哪个类型的IP地址对应的某组AP的FQDN与AP IP地址的映射关系信息。操作员可以使用LST NAFIDAP命令查询获得。 取值范围：IPV4(IPV4)：IPv4类型的IP地址。 IPV6(IPV6)：IPv6类型的IP地址。      |
| IPV4     | NAF IPv4地址 | 标识AP的FQDN与AP IP地址映射关系的关键字段之一，用于指定需要删除哪个IPv4地址对应的某组AP的FQDN与AP IP地址的映射关系信息。操作员可以使用LST NAFIDAP命令查询获得。 取值范围：有效的IPv4地址。                                            |
| IPV6     | NAF IPv6地址 | 标识AP的FQDN与AP IP地址映射关系的关键字段之一，用于指定需要删除哪个IPv6地址对应的某组AP的FQDN与AP IP地址的映射关系信息。操作员可以使用LST NAFIDAP命令查询获得。 取值范围：有效的IPv6地址。                                            |

## 使用实例

删除一组AP的FQDN与AP域名的映射关系信息。携带以下参数：

- “FQDN”为“bsf.huawei.com”
- “域名”为“huawei.com”

执行命令如下：

```
RMV NAFIDAP: FQDN="bsf.huawei.com", REALM="huawei.com";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释               | 原因分析               | 处理建议                                                                                 |
|-------:|:--------------------|:-------------------|:-------------------------------------------------------------------------------------|
| 377481 | NAFIDAP表中要删除的记录不存在。 | 要删除的记录在系统中未定义。     | 执行LST NAFIDAP命令查询后，重新输入参数“FQDN”，“FQDN”+“域名”的组合或“FQDN”+“IP地址类型”+IP地址的组合，再执行本命令删除某条记录。 |
| 378312 | 请选择要删除的域名或IP地址。     | “域名”和IP地址必须至少输入一个。 | 执行LST NAFIDAP命令查询后，输入参数“域名”或“IP地址类型”与IP地址的组合后重新执行该命令。确保“域名”和IP地址必须至少输入一个。            |
