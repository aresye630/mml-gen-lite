# 查询TMPI和IMPI配对关系(DSP TIMPIPAIR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询TMPI与IMPI的数据关系配置信息。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                          |
|:-------|:----------|:------------------------------------------------------------------------------|
| IMPI   | IP多媒体私有标识 | 用于指示系统需要按照哪个IP多媒体私有标识查询TMPI与IMPI的数据关系。 取值范围：长度不超过127的字符串。 默认值：无。 注意：该参数为必选参数。 |

## 使用实例

查询TMPI与IMPI配对关系，“IP多媒体私有标识”为“BSFAP023056@huawei.com”：

```
DSP TIMPIPAIR: IMPI="BSFAP023056@huawei.com";
```

返回结果如下：

```
%%DSP TIMPIPAIR: IMPI="BSFAP023056@huawei.com";%%
RETCODE = 0 操作成功

查询结果如下
------------
IP多媒体私有标识 = BSFAP023056@huawei.com
临时多媒体私有标识 = tJlfiCtUV3dv+SXBK6H3YLUrvrTw122k@tmpi.huawei.com
(结果个数 = 1)

--- END
```

## 输出结果说明

| 输出项名称     | 输出项解释            |
|:----------|:-----------------|
| IP多媒体私有标识 | 用于返回IP多媒体私有标识。   |
| 临时多媒体私有标识 | 用于返回临时IP多媒体私有标识。 |
