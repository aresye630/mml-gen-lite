# 删除协商规则(RMV NEGORULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于从配置数据库中删除一条方法协商规则记录。

**说明** 

该命令仅在Full-stack虚机场景下支持。

## 注意事项

如果操作员删除方法协商规则，将会造成EAP鉴权算法不可用（不会影响非EAP鉴权算法），请操作员在执行该操作之前仔细确认任务的可行性。

## 参数说明

| 参数标识              | 参数名称   | 参数说明                                                                                                                               |
|:------------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------|
| IDENTITY          | 匹配规则   | 标识一条协商规则数据记录的关键字段，用于指定需要删除哪一条协商规则数据记录，操作员可以使用LST NEGORULE命令查询获得。 取值范围：长度不超过127的字符串。 默认值：无。 注意：该参数为必选参数。                            |
| METHOD_USED_PHASE | 方法使用阶段 | 用于指定待删除的方法协商规则是用于TLS隧道建立前还是建立后。 取值范围： PHASE1(第一阶段)：表示在TLS隧道建立前使用方法协商规则的阶段。PHASE2(第二阶段)：表示在TLS隧道建立后使用方法协商规则的阶段。 默认值：无。 注意：该参数为可选参数。 |

## 使用实例

删除协商规则，携带以下参数：

- “匹配规则”为“30”
- “方法使用阶段”为“PHASE1(第一阶段)”

```
RMV NEGORULE: IDENTITY="30", METHOD_USED_PHASE=PHASE1;
```
