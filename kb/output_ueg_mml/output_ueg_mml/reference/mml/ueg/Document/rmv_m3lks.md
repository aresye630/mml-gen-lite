# 删除M3UA链路集(RMV M3LKS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于从配置数据库中删除一条M3UA链路集数据记录。

## 注意事项

- 如果命令执行成功，且删除的数据为已有性能统计任务中登记的对象实例，则该对象实例后续上报的指标值为0。命令涉及的测量单元有：M3UA信令链路集测量；命令涉及的对象有：M3UA信令链路集。
- 在正常情况下，删除一条M3UA链路集数据记录的操作步骤为：**RMV M3RT**-->**RMV M3LNK**--> **RMV M3LKS**。

## 参数说明

| 参数标识   | 参数名称   | 参数描述                                                                                                  |
|:-------|:-------|:------------------------------------------------------------------------------------------------------|
| LSNM   | 链路集名称  | 标识一条M3UA链路集数据记录的关键字段，用于指定需要删除哪一条M3UA链路集数据记录，操作员可以使用LST M3LKS命令查询获得。 取值范围: 长度不超过32的字符串。 默认值: 无。 说明: 无。 |

## 使用实例

删除M3UA链路集，“链路集名称”为“M3LKS”：

```
RMV M3LKS: LSNM="M3LKS";
```
