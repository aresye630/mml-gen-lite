# 查询Diameter链路(LST DMLNK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询Diameter链路配置信息。

- 若需要查询全部链路的配置，请不要输入任何参数。
- 若需要查询某条链路的配置信息，请输入链路属性相关参数。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称            | 参数说明                                                                                    |
|:--------------|:----------------|:----------------------------------------------------------------------------------------|
| LINKSNAM      | Diameter链路集名称   | 用于指示系统查询哪个Diameter链路集中的链路；若不输入，则表示所有的Diameter链路集。                                       |
| LNKNAME       | 链路名称            | 用于指示系统查询哪条链路的配置信息；若不输入，则表示所有的Diameter链路。                                                |
| HSFMID        | HSF模块号          | 用于指示系统查询使用哪个HSF模块的链路；若不输入，则表示所有的HSF模块。                                                  |
| PTYPE         | 传输协议类型          | 用于指示系统查询使用哪种传输协议类型的链路；若不输入，则表示所有的传输协议类型。                                                |
| WMODE         | 工作模式            | 用于指示系统查询使用哪种工作模式的链路；若不输入，则表示所有的工作模式。                                                    |
| IPNAM1        | IP地址名称1         | 用于指示系统查询使用哪个主用IP地址的链路；若不输入，则表示所有的主用IP地址。                                                |
| IPNAM2        | IP地址名称2         | 用于指示系统查询使用哪个备用IP地址的链路；若不输入，则表示所有的备用IP地址                                                 |
| LPT           | 本端端口号           | 用于指示系统查询使用哪个本端端口号的链路；若不输入，则表示所有的端口号。                                                    |
| PIPVER        | 对端IP地址版本        | 用于指示系统查询对端IP地址使用哪个版本的链路；若不输入，则表示所有的版本。                                                  |
| PIPV4         | 对端IPV4地址        | 仅当本命令中的“对端IP地址版本”参数为“IPV4(IPV4)”时该参数有效。用于指示系统查询对端使用哪个IPV4地址的链路；若不输入，则表示所有的IPV4地址。       |
| PIPV6         | 对端IPV6地址        | 仅当本命令中的“对端IP地址版本”参数为“IPV6(IPV6)”时该参数有效。用于指示系统查询对端使用哪个IPV6地址的链路；若不输入，则表示所有的IPV6地址。       |
| SPIPVER       | 对端备用IP地址版本      | 用于指示系统查询对端备用IP地址使用哪个版本的链路；若不输入，则表示所有的版本。                                                |
| SPIPV4        | 对端备用IPV4地址      | 仅当本命令中的“对端备用IP地址版本”参数为“IPV4(IPV4)”时该参数有效。用于指示系统查询对端使用哪个备用IPV4地址的链路；若不输入，则表示所有的备用IPV4地址。 |
| SPIPV6        | 对端备用IPV6地址      | 仅当本命令中的“对端备用IP地址版本”参数为“IPV6(IPV6)”时该参数有效。用于指示系统查询对端使用哪个备用IPV6地址的链路；若不输入，则表示所有的备用IPV6地址。 |
| PPT           | 对端端口号           | 用于指示系统查询对端使用哪个端口号的链路；若不输入，则表示所有的端口号。                                                    |
| LINKPRI       | Diameter对端链路优先级 | 用于指示系统查询哪个链路优先级的链路；若不输入，则表示所有的优先级。                                                      |
| CROSSPATHFLAG | 交叉路径是否可用        | 用于指示系统查询的链路交叉路径是否可用；若不输入，则表示查询时不限交叉路径是否可用。                                              |
| SCALEFLAG     | 是否弹性链路          | 用于指示系统查询的链路是否是弹性链路；若不输入，则表示查询时不限是否是弹性链路。                                                |

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见

**ADD DMLNK**

命令的参数说明。表1列出的是未包含在

**ADD DMLNK**

命令参数说明中的输出项。

| 输出项名称         | 输出项解释                           |
|:--------------|:--------------------------------|
| Diameter链路集标识 | Diameter链路集记录。                  |
| 链路标识          | Diameter本端实体与Diameter对端实体间链路记录。 |
