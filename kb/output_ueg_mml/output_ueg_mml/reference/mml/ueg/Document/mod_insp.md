## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成系统运行异常从而影响业务运行，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对软件参数的值进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一条软件参数配置信息数据记录：

- 软件参数名称
- 软件参数值

## 注意事项

- 软件参数值都有特定含义，此命令的修改可能严重影响系统的运行，修改时，请联系华为技术支持处理。
- 该命令不允许进行批操作。
- “软件参数类型”取值为“SRVCTRL(业务控制功能)”的软参功能只能在机关研发指导下使用，且仅能在华为UDM故障场景下使用，其它场景禁止使用。该类软参设置后对系统的影响如下：
  - 该类软参为全局软参，设置后对所有用户生效。
  - 如果存在远程控制终端，可能存在远程控制终端不能及时实施重新开关机，导致该类终端业务长时间无法恢复。
  - 软参设置后会导致用户掉网，影响用户业务使用。掉网用户在网络拥塞恢复之后，只有在该类软参设置为“0”以后，对终端重新开关机才能重新附着网络，恢复用户业务。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                         |
|:-------|:-------|:-----------------------------------------------------------------------------|
| INSPT  | 软件参数类型 | 用于标识按功能模块划分的软件参数名称所归属的大类。详细信息请参考产品手册的“UDM软件参数”。                              |
| INSPN  | 软件参数名称 | 标识一条软件参数数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪一个软件参数名称进行修改或调整，操作员可以使用LST INSP命令查询获得。 |
| INSPV  | 软件参数值  | 用于标识需要修改的软件参数的参数值，该参数值的取值范围由软件参数名称确定。各软参取值及取值具体含义请参见产品手册的“UDM软件参数”。          |

## 使用实例

修改内部软件参数，“软件参数类型”为“RELIABILITY(系统可靠性)”，“软件参数名称”为“WHOLESITESWITCH(是否支持FE-BE断链后倒换信令)”，“软件参数值”为“1”：

```
MOD INSP: INSPT=RELIABILITY, INSPN=WHOLESITESWITCH, INSPV=1;
```
