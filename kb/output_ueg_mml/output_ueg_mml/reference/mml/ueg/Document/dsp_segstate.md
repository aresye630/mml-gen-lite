# 查询隔离状态(DSP SEGSTATE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示指定的业务模块的隔离状态。

- 若需要请求系统显示指定Pod上的业务模块的状态信息，请首先输入“隔离模式”参数并取值为“POD(POD)”，然后输入“Pod名称”参数。
- 若需要请求系统显示某个模块上的业务模块的状态信息，请首先输入“隔离模式”参数并取值为“MODULE(MODULE)”，然后输入“模块号”参数。
- 若需要请求系统显示某个Pod下某种模块类型中模块号最大的业务模块的状态信息，请首先输入“隔离模式”参数并取值为“POD\_MAX\_MODULE(POD最大模块)”，然后输入“Pod名称”参数和“模块类型”参数。
- 若需要请求系统显示某个平面上的业务模块的状态信息，请首先输入“隔离模式”参数并取值为“PLANE(平面)”，然后输入“平面信息”参数。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                          |
|:--------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------|
| TYPE    | 隔离模式   | 用于指定隔离模式。 取值范围：POD(POD)：按照Pod模式进行隔离。MODULE(MODULE)：按照模块模式进行隔离。POD_MAX_MODULE(POD最大模块)：按照指定Pod下的模块类型中模块号最大的模块进行隔离。PLANE(平面)：按照平面模式进行隔离。 默认值：无。 |
| PODNAME | Pod名称  | 仅当本命令中“隔离模式”参数为“POD(POD)”或“POD_MAX_MODULE(POD最大模块)”时，该参数有效。用于指定Pod名称。                                                                         |
| MID     | 模块号    | 仅当本命令中“隔离模式”参数为“MODULE(MODULE)”时，该参数有效。用于指定需要显示隔离状态的业务模块号。该参数必须由ADD MODULE命令定义，然后才能在此处索引。 取值范围：1～1023                                         |
| MTYPE   | 模块类型   | 仅当本命令中“隔离模式”参数为“POD_MAX_MODULE(POD最大模块)”时，该参数有效。用于指定模块类型。 取值范围： CCU(CCU)ACF(ACF)DSG(DSG)BSG(BSG)APF(APF) 默认值：无。                               |
| PLAINFO | 平面信息   | 仅当本命令中“隔离模式”参数为“PLANE(平面)”时，该参数有效。用于指定平面信息。 取值范围： PLANE0(PLANE0)：平面0 PodPLANE1(PLANE1)：平面1 Pod 默认值：无。                                         |

## 使用实例

1. 显示“Pod名称”为“vUDM\_98”的业务模块的隔离状态，命令执行如下：

   ```
   DSP SEGSTATE: TYPE=POD, PODNAME="vUDM_98";
   ```

   ```
   %%DSP SEGSTATE: TYPE=POD, PODNAME="vUDM_98";%%
   RETCODE = 0  操作成功

   业务模块状态信息
   ----------------
    业务模块  Pod名称   模块状态     隔离处理来源

    45        vUDM_98   非隔离       NULL 
    36        vUDM_98   非隔离       NULL 
    43        vUDM_98   非隔离       NULL 
    42        vUDM_98   非隔离       NULL 
   (结果个数 = 4)

   ---    END
   ```
2. 显示所有业务模块的隔离状态，命令执行如下：

   ```
   DSP SEGSTATE: TYPE=MODULE;
   ```

   ```
   %%DSP SEGSTATE: TYPE=MODULE;%%
   RETCODE = 0  操作成功

   业务模块状态信息
   ----------------
    业务模块  POD名称   模块状态    隔离处理来源

    36        vUDM_98   非隔离      NULL 
    45        vUDM_98   非隔离      NULL 
    42        vUDM_98   非隔离      NULL 
    43        vUDM_98   非隔离      NULL 
   (结果个数 = 4)

   ---    END
   ```
3. 显示“Pod名称”为“vUDM\_98”对应Pod下“模块类型”为“CCU”中模块号最大的模块的隔离状态，命令执行如下：

   ```
   DSP SEGSTATE: TYPE=POD_MAX_MODULE, PODNAME="vUDM_98", MTYPE=CCU;
   ```

   ```
   %%DSP SEGSTATE: TYPE=POD_MAX_MODULE, PODNAME="vUDM_98", MTYPE=CCU;%%
   RETCODE = 0  操作成功

   业务模块状态信息
   ----------------
       业务模块  =  45
        Pod名称  =  vUDM_98  
       模块状态  =  隔离
   隔离处理来源  =  NULL
   (结果个数 = 1)

   ---    END
   ```
4. 显示“平面信息”为“PLANE0(PLANE0)”的隔离状态，命令执行如下：

   ```
   DSP SEGSTATE: TYPE=PLANE, PLAINFO=PLANE0;
   ```

   ```

   RETCODE = 0  操作成功

   业务模块状态信息
   ----------------
    业务模块  POD名称        模块状态    隔离处理来源

    0         ufeus-a466-0   非隔离      NULL 
    20        ufeus-a466-0   非隔离      NULL 
    21        ufeus-a466-0   非隔离      NULL 
    22        ufeus-a466-0   非隔离      NULL 
   (结果个数 = 4)

   ---    END
   ```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**MOD SEGSTATE**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释        | 原因分析                                                                                               | 处理建议                                    |
|------:|:-------------|:---------------------------------------------------------------------------------------------------|:----------------------------------------|
|   180 | 指定模块不存在。     | 当“隔离模式”参数为“MODULE(MODULE)”时，“模块号”参数指定的模块不存在。                                                       | 使用LST MODULE命令查询后，重新输入“模块号”参数。          |
|   181 | 指定模块不是激活业务模块 | 当“隔离模式”参数为“MODULE(MODULE)”时，“模块号”参数指定的模块不是激活的业务模块。                                                 | 使用LST MODULE命令查询后，重新输入激活的“模块号”参数。       |
|   182 | 没有业务模块       | 当“隔离模式”参数为“POD_MAX_MODULE(POD最大模块)”时，“Pod名称”对应的Pod未配置指定“模块类型”对应的模块。                                | 使用LST MODULE命令查询后，重新输入“Pod名称”和“模块类型”参数。 |
|   183 | 没有激活的业务模块    | 可能原因为如下之一： 当“隔离模式”参数为“POD(POD)”时，“Pod名称”对应的Pod未配置指定的模块。当“隔离模式”参数为“MODULE(MODULE)”时，该网元下不存在激活的业务模块。 | 根据实际情况执行ADD MODULE命令配置业务模块。             |
