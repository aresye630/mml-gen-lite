# 修改消息包申请测试配置信息(MOD MSGALLOCTESTCFG)

## 命令功能

该命令用于修改或调整UDM注册给CSP的大小消息包申请测试配置信息。“大小消息包检测功能开关”开启后，大小消息包在申请测试失败场景下，按照配置重新申请测试或重启模块进行自愈。

UDM在所有进程初始化时，调用平台接口将对应进程类型的大小消息包申请测试配置信息设置给平台。

## 注意事项

- 系统只能增加一条消息包申请测试配置信息，再次执行该命令时，会覆盖系统中保存的消息包申请测试配置信息取值。
- 重启的模块1小时内消息包申请失败监测功能失效，1小时后该功能恢复正常。
- “资源占用率(%)”超过95%，消息包申请失败监测功能失效；“资源占用率(%)”超过95%且持续3分钟，模块重启。

  **说明** 

  “资源占用率(%)”可以在“CSP MML命令”窗口执行**DSP SYSRES**命令查询，请查看“资源名称”为“SysMsg”、“AppMsg”的“资源占用率(%)”。

## 使用实例

修改消息包申请测试配置信息。参数设置如下：

- “模块类型”为“CCU(CCU)”
- “大小消息包检测功能开关”为“ON(打开)”
- “消息包大小阈值”为“1000”
- “大消息包测试周期”为“1000”
- “大消息包测试次数”为“60”
- “大消息包重试失败比例”为“100”
- “大消息包复位策略”为“RST(复位)”
- “小消息包测试周期”为1000
- “小消息包测试次数”为“60”
- “小消息包重试失败比例”为“100”
- “小消息包复位策略”为“RST(复位)”

命令执行如下：

```
MOD MSGALLOCTESTCFG: MODULETYPE=CCU, MSGSIZESWITCH=ON, MSGTHRESHOLDSIZE=1000, BIGMSGTIME=1000, BIGMSGCOUNT=60, BIGMSGFAILURERATE=100, BIGMSGRSTFLAG=RST, SMALLMSGTIME=1000, SMALLMSGCOUNT=60, SMALLMSGFAILURERATE=100, SMALLMSGRSTFLAG=RST;
```
