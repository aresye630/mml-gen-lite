# 查询NGC 3GPP接入用户数(DSP NGCSUBCNT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询数据配置库中NGC 3GPP接入用户数，包括静态和动态用户。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询局点当前数据库中NGC 3GPP接入的用户数。

```
DSP NGCSUBCNT:;
```

```
%%DSP NGCSUBCNT:;%%
RETCODE = 0  操作成功
 
NGC 3GPP接入用户数信息
----------------------
NGC 3GPP接入静态用户数 = 1
NGC 3GPP接入动态用户数 = 0

(结果个数 = 1)  

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，表1列出的是报文中参数含义的输出项。

| 输出项名称           | 输出项解释                          |
|:----------------|:-------------------------------|
| NGC 3GPP接入静态用户数 | 用于返回数据配置库中存在的NGC 3GPP接入静态用户数量。 |
| NGC 3GPP接入动态用户数 | 用于返回数据配置库中存在的NGC 3GPP接入动态用户数量。 |
