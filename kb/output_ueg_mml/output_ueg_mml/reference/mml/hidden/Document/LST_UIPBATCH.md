# 批处理查询IP地址段(LST UIPBATCH)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

**说明** 

当前版本不支持该命令功能。

该命令用于查询一个IP地址池内的IP地址信息。

## 注意事项

- 查询IP地址请使用**LST UIPSECTIONEX**命令。
- 指定“IPv4地址数量”或“IPv6地址数量”参数，命令执行成功后，系统会返回Batch ID，否则不返回。操作员登录“PGW Web LMT”的“系统管理”界面，使用**CHK BATSTAT**命令查看Batch ID操作任务的详细输出信息，可通过“文件管理器”下载详细的输出报告。
- 查询的IP地址数量不能超过10000条。

## 参数说明

| 参数标识            | 参数名称       | 参数说明                                                                                                                                                                                                                                              |
|:----------------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| POOLID          | IP地址池索引    | 标识IP地址池的关键字段之一，用于指定需要查询哪一个IP地址池中的IP地址，操作员可以使用LST UIPPOOLTPL命令查询获得。                                                                                                                                                                                |
| IPTYPE          | IP类型       | 用于指定IP地址段内IP地址的类型。 取值范围：IPv4IPv6                                                                                                                                                                                                                  |
| STARTIPV4       | 起始IPv4     | 仅当该命令中“IP类型”参数为“IPv4”时，该参数有效且必须输入。用于指定IP地址段的起始IPv4地址。 取值范围：有效的IPv4地址。 默认值：无。                                                                                                                                                                      |
| STARTIPV6PREFIX | 起始IPv6地址前缀 | 仅当该命令中“IP类型”参数为“IPv6”时，该参数有效且必须输入。用于指定IP地址段的起始IPv6地址前缀。 取值范围：有效的IPv6地址。 默认值：无。 注意：格式为X:X:X:X:X:X:X:X，每个“X”表示四个十六进制数。输入IPv6前缀时，只需要输入前缀部分，不满足IPv6长度的部分由系统自动补充为0。例如，前缀长度为64的IPv6前缀只需要输入FE80:0:0:1。不支持IPv6简写。例如，IPv6前缀为FE80:0:0:FE80，不能简写为FE80::FE80。 |
| IPV4COUNT       | IPv4地址数量   | 仅当该命令中“IP类型”参数为“IPv4”时，该参数有效。用于指定从起始IPv4地址开始的IP地址数量。 取值范围：1～10000。 默认值：无。 说明：若只有1条记录，该参数可以不输入。                                                                                                                                                    |
| IPV6COUNT       | IPv6地址数量   | 仅当该命令中“IP类型”参数为“IPv6”时，该参数有效。用于指定从起始IPv6地址开始的IP地址数量。 取值范围：1～10000。 默认值：无。 说明：若只有1条记录，该参数可以不输入。                                                                                                                                                    |

## 使用实例

- 为“IP地址池索引”为“1”，“起始IPv4”为“192.168.1.1”中的IPV4类型IP地址，执行命令如下：

  ```
  LST UIPBATCH: POOLID=1, IPTYPE=IPv4, STARTIPV4="192.168.1.1";
  ```

  ```
  %%LST UIPBATCH: POOLID=1, IPTYPE=IPv4, STARTIPV4="192.168.1.1";%%
  RETCODE = 0 Operation is successful

                            IPV4 = 192.168.1.1
                        IPSTATUS = FREE
             ALLOCATION_IPSTATUS = NORMAL
                          USERID = 8613993180118@huawei.com
                     CHANGE_TIME = 2016-09-05 12:00:00

  Total count = 5

  There is together 1 report
  ```
- 为“IP地址池索引”为“1”，“起始IPv6地址前缀”为“FE80:0:0:FE80”中的IPV6类型IP地址，执行命令如下：

  ```
  LST UIPBATCH: POOLID=1, IPTYPE=IPv6, STARTIPV6PREFIX="FE80:0:0:FE80";
  ```

  ```
  %%LST UIPBATCH: POOLID=1, IPTYPE=IPv6, STARTIPV6PREFIX="FE80:0:0:FE80";%%
  RETCODE = 0 Operation is successful

                            IPV6 = fe80:0000:0000:fe80:0000:0000:0000:0000
                        IPSTATUS = FREE
             ALLOCATION_IPSTATUS = NORMAL
                          USERID = 8613993180118@huawei.com
                     CHANGE_TIME = 2016-09-05 12:00:00

  Total count = 5

  There is together 1 report
  ```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息和相关参数，具体参数说明请参见表1。

| 输出项名称               | 输出结果解释                                        |
|:--------------------|:----------------------------------------------|
| IPV4                | 用于返回IPv4地址。                                   |
| IPV6                | 用于返回IPv6地址前缀。                                 |
| IPSTATUS            | 用于返回IP地址状态。FREE：该IP地址为空闲状态。IN_USE：该IP已经分配给用户。 |
| ALLOCATION_IPSTATUS | 用于返回IP地址的分配状态。NORMAL：可正常分配给用户。FORBID：禁止分配给用户。 |
| USERID              | 用于返回使用该IP地址的用户标识。                             |
| CHANGE_TIME         | 用于返回IP地址分配或释放的时间。                             |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|       错误码 | 消息解释          | 原因分析                           | 处理建议                                   |
|----------:|:--------------|:-------------------------------|:---------------------------------------|
| 400001016 | IP地址池模板ID不存在。 | 参数“IP地址池索引”指定的IP地址池模板不存在。      | 使用LST UIPPOOLTPL命令查询后，重新输入“IP地址池索引”参数。 |
| 400002134 | IPV4 不存在。     | 参数“起始IPv4”指定的IPv4地址不存在。        | 请重新指定“起始IPv4”参数，确保其取值是存在的。             |
| 400002136 | IPV6不存在       | 参数“起始IPv6地址前缀”指定的IPv6地址前缀不存在。  | 请重新指定“起始IPv6地址前缀”参数，确保其取值是存在的。         |
| 400002138 | IPV6格式错误。     | 参数“起始IPv6地址前缀”指定的IPv6地址前缀格式错误。 | 重新指定“起始IPv6地址前缀”参数，确保其取值符合要求。          |
