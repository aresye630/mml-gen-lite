# 回退FE插件（RBK FEPLUG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于回退升级失败的FE插件升级包。

## 注意事项

在回退FE插件时，升级框架自动执行该命令。其他场景严禁执行该命令。

## 参数说明

| 参数ID       | 参数名称    | 参数描述          |
|:-----------|:--------|:--------------|
| UPFILENAME | FE插件包名称 | 用于标识FE插件包的名称。 |

## 使用实例

```
RBK FEPLUG:;
```

```
%%RBK FEPLUG:;%%
RETCODE = 0  操作成功
---    END
```

## 输出结果说明

无。
