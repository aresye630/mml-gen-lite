# 操作员登录（LGI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此命令用于操作员登录，不能直接在PGW客户端界面输入。

## 注意事项

无。

## 参数说明

| 参数ID   | 参数名称   | 参数描述                                                                |
|:-------|:-------|:--------------------------------------------------------------------|
| HLRSN  | HLR序列号 | HLR序列号，在PGW支持容灾功能或虚拟HLR功能时设置。 取值范围：1～255。 默认值：无。                    |
| OPNAME | 操作员名称  | 该参数用于设置输入操作员名称。 取值范围：不超过32位的字符串，由数字和字母组成，且首字符必须为字母。 默认值：无。 说明：必选参数。 |
| PWD    | 操作员口令  | 该参数用于设置输入操作员口令。 取值范围：6～32位的字符串。 默认值：无。 说明：必选参数。                     |

## 使用实例

操作员登录。“HLR序列号”为“6”，“操作员名称”为“NKR”，“操作员口令”为“sysadmin”。命令如下：

LGI: HLRSN=6, OPNAME="NKR", PWD="\*\*\*\*\*\*";
