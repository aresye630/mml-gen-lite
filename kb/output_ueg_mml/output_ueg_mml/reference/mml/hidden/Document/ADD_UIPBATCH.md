# 批处理添加IP地址段(ADD UIPBATCH)

## 命令功能

**说明** 

当前版本不支持该命令功能。

该命令用于批量为IP地址段增加IP地址信息。

UIM基于增强IP分配策略为WCDMA用户匹配动态IP地址时，根据匹配到的**IP分配规则**中签约的IP地址池，在对应的IP地址池内寻找空闲IP地址下发给用户。通过批处理方式批量增加IP地址信息，可提高配置效率。

## 注意事项

- 添加IP地址请使用**ADD UIPSECTIONEX**命令。
- 指定“IPv4地址数量”或“IPv6地址数量”参数，命令执行成功后，系统会返回Batch ID，否则不返回。操作员登录“PGW Web LMT”的“系统管理”界面，使用**CHK BATSTAT**命令查看Batch ID操作任务的详细输出信息，可通过“文件管理器”下载详细的输出报告。
- 系统允许批处理增加的IP地址数量最多为65536个，请操作员在执行该命令前妥善规划，仔细确认任务的可行性。

## 参数说明

| 参数标识            | 参数名称       | 参数说明                                                                                                                                                                                                                                              |
|:----------------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SEGMENTID       | IP地址段索引    | 用于指定IP地址段的序号。“IP地址段索引”全局唯一，不能重复。 取值范围：1～65535。 默认值：无。                                                                                                                                                                                             |
| POOLID          | IP地址池索引    | 用于指定IP地址池模板序号。该参数由ADD UIPPOOLTPL命令定义后，才能在此引用。 取值范围：1～255。 默认值：无。                                                                                                                                                                                  |
| IPTYPE          | IP类型       | 用于指定IP地址段内IP地址的类型。 取值范围：IPv4IPv6                                                                                                                                                                                                                  |
| STARTIPV4       | 起始IPv4     | 仅当该命令中“IP类型”参数为“IPv4”时，该参数有效且必须输入。用于指定IP地址段的起始IPv4地址。 取值范围：有效的IPv4地址。 默认值：无。                                                                                                                                                                      |
| STARTIPV6PREFIX | 起始IPv6地址前缀 | 仅当该命令中“IP类型”参数为“IPv6”时，该参数有效且必须输入。用于指定IP地址段的起始IPv6地址前缀。 取值范围：有效的IPv6地址。 默认值：无。 注意：格式为X:X:X:X:X:X:X:X，每个“X”表示四个十六进制数。输入IPv6前缀时，只需要输入前缀部分，不满足IPv6长度的部分由系统自动补充为0。例如，前缀长度为64的IPv6前缀只需要输入FE80:0:0:1。不支持IPv6简写。例如，IPv6前缀为FE80:0:0:FE80，不能简写为FE80::FE80。 |
| IPv6PREFIXLEN   | IPv6地址前缀长度 | 仅当该命令中“IP类型”参数为“IPv6”时，该参数有效。用于指定IPv6地址前缀的长度。 取值范围：0～128。 默认值：无。                                                                                                                                                                                  |
| IPV4COUNT       | IPv4地址数量   | 仅当该命令中“IP类型”参数为“IPv4”时，该参数有效。用于指定从起始IPv4地址开始的IP地址数量。 取值范围：1～65536。 默认值：无。 说明：若只有1条记录，该参数可以不输入。                                                                                                                                                    |
| IPV6COUNT       | IPv6地址数量   | 仅当该命令中“IP类型”参数为“IPv6”时，该参数有效。用于指定从起始IPv6地址开始的IP地址数量。 取值范围：1～65536。 默认值：无。 说明：若只有1条记录，该参数可以不输入。                                                                                                                                                    |

## 使用实例

为“IP地址段索引”为“1”的IP地址段增加20条IPV4类型地址，携带如下参数：

- “IP地址池索引”为“1”
- “起始IPv4”为“192.168.1.1”

执行命令如下：

```
ADD UIPBATCH: SEGMENTID=1, POOLID=1, IPTYPE=IPv4, STARTIPV4="192.168.1.1", IPV4COUNT=20;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 消息解释          | 原因分析                            | 处理建议                                           |
|----------:|:--------------|:--------------------------------|:-----------------------------------------------|
| 400001016 | IP地址池模板ID不存在。 | 参数“IP地址池索引”指定的IP地址池模板信息不存在。     | 执行LST UIPPOOLTPL命令查询后，重新输入“IP地址池索引”参数，确保其取值存在。 |
| 400002133 | IPV4 已存在      | 参数“起始IPv4”指定的IPv4地址已经存在。        | 请重新指定“起始IPv4”参数，确保其取值和已经存在的不重复。                |
| 400002135 | IPV6 已存在。     | 参数“起始IPv6地址前缀”指定的IPv6地址前缀已经存在。  | 请重新指定“起始IPv6地址前缀”参数，确保其取值和已经存在的不重复。            |
| 400002138 | IPV6格式错误。     | 参数“起始IPv6地址前缀”指定的IPv6地址前缀格式不正确。 | 重新指定“起始IPv6地址前缀”参数，确保其取值符合要求。                  |
