# 批处理删除IP地址段(RMV UIPBATCH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**说明** 

当前版本不支持该命令功能。

该命令用于批量删除一个IP地址段内的IP地址信息。通过批处理方式删除IP地址池信息，可提高配置效率。

## 注意事项

- 删除IP地址请使用**RMV UIPSECTIONEX**命令。
- 指定“IPv4地址数量”或“IPv6地址数量”参数，命令执行成功后，系统会返回Batch ID，否则不返回。操作员登录“PGW Web LMT”的“系统管理”界面，使用**CHK BATSTAT**命令查看Batch ID操作任务的详细输出信息，可通过“文件管理器”下载详细的输出报告。
- 强制批量删除地址段内用户正在使用的IP地址，UIM会向用户发送DM（Disconnect message）消息，将用户下线，请谨慎操作。

## 参数说明

| 参数标识            | 参数名称       | 参数说明                                                                                                                                                                                                                                              |
|:----------------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SEGMENTID       | IP地址段索引    | 标识IP地址段的关键字段之一，用于指定需要删除哪一个IP地址段，操作员可以使用LST UIPBATCH命令查询获得。                                                                                                                                                                                        |
| POOLID          | IP地址池索引    | 标识IP地址段的关键字段之一，用于指定需要删除哪一个IP地址池，操作员可以使用LST UIPPOOLTPL命令查询获得。                                                                                                                                                                                      |
| IPTYPE          | IP类型       | 用于指定IP地址段内IP地址的类型。 取值范围：IPv4IPv6                                                                                                                                                                                                                  |
| STARTIPV4       | 起始IPv4     | 仅当该命令中“IP类型”参数为“IPv4”时，该参数有效且必须输入。用于指定IP地址段的起始IPv4地址。 取值范围：有效的IPv4地址。 默认值：无。                                                                                                                                                                      |
| STARTIPV6PREFIX | 起始IPv6地址前缀 | 仅当该命令中“IP类型”参数为“IPv6”时，该参数有效且必须输入。用于指定IP地址段的起始IPv6地址前缀。 取值范围：有效的IPv6地址。 默认值：无。 注意：格式为X:X:X:X:X:X:X:X，每个“X”表示四个十六进制数。输入IPv6前缀时，只需要输入前缀部分，不满足IPv6长度的部分由系统自动补充为0。例如，前缀长度为64的IPv6前缀只需要输入FE80:0:0:1。不支持IPv6简写。例如，IPv6前缀为FE80:0:0:FE80，不能简写为FE80::FE80。 |
| IPV4COUNT       | IPv4地址数量   | 仅当该命令中“IP类型”参数为“IPv4”时，该参数有效。用于指定从起始IPv4地址开始的IP地址数量。 取值范围：1～65536。 默认值：无。 说明：若只有1条记录，该参数可以不输入。                                                                                                                                                    |
| IPV6COUNT       | IPv6地址数量   | 仅当该命令中“IP类型”参数为“IPv6”时，该参数有效。用于指定从起始IPv6地址开始的IP地址数量。 取值范围：1～65536。 默认值：无。 说明：若只有1条记录，该参数可以不输入。                                                                                                                                                    |
| FORCEFLAG       | 强制删除标识     | 用于指示当要删除的IP地址段中有IP地址正在被用户使用时，是否能够强制删除该IP地址。 取值范围：TRUE：可以强制删除IP地址。FALSE：不能强制删除IP地址。 默认值：FALSE。                                                                                                                                                     |

## 使用实例

1. 删除“IP地址段索引”为“1”，“IP地址池索引”为“1”中的IPV4类型IP地址，“起始IPv4”为“192.168.1.1”，执行命令如下：

   ```
   RMV UIPBATCH: SEGMENTID=1, POOLID=1, IPTYPE=IPv4, STARTIPV4="192.168.1.1", FORCEFLAG=TRUE;
   ```
2. 删除“IP地址段索引”为“1”，“IP地址池索引”为“1”，“起始IPv4”为“192.168.1.30”的10个IPV4类型IP地址，执行命令如下：

   ```
   RMV UIPBATCH: SEGMENTID=1, POOLID=1, IPTYPE=IPv4, STARTIPV4="192.168.1.30", IPV4COUNT=10, FORCEFLAG=FALSE;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 消息解释          | 原因分析                           | 处理建议                                           |
|----------:|:--------------|:-------------------------------|:-----------------------------------------------|
| 400001016 | IP地址池模板ID不存在。 | 输入的“IP地址池索引”参数指定的IP地址池模板信息不存在。 | 执行LST UIPPOOLTPL命令查询后，重新输入“IP地址池索引”参数，确保其取值存在。 |
| 400002134 | IPV4 不存在。     | 参数“起始IPv4”指定的IPv4地址不存在。        | 请重新指定“起始IPv4”参数，确保其取值是存在的。                     |
| 400002145 | IP地址段不存在。     | 参数“IP地址段索引”指定的IP地址段不存在。        | 使用LST UIPSECTIONEX命令查询后，重新输入“IP地址段索引”参数。       |
| 400002136 | IPV6不存在       | 参数“起始IPv6地址前缀”指定的IPv6地址前缀不存在。  | 请重新指定“起始IPv6地址前缀”参数，确保其取值是存在的。                 |
| 400002138 | IPV6格式错误。     | 参数“起始IPv6地址前缀”指定的IPv6地址前缀格式错误。 | 重新指定“起始IPv6地址前缀”参数，确保其取值符合要求。                  |
