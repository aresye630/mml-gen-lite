# 批处理回收IP地址段(RECYCLE UIPBATCH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**说明** 

当前版本不支持该命令功能。

该命令用于回收IP地址池中的IP地址。通过该命令，操作员可以灵活管理IP地址状态：

- 将正在使用的IP地址设置为空闲状态，IP可以再次分配给用户。
- 将正在使用的IP地址设置为禁用状态，IP不再分配给用户。
- 将禁止分配的IP地址设置为可分配状态，IP可以分配给用户。

## 注意事项

- 回收IP地址请使用**RECYCLE UIPSECTIONEX**命令。
- 指定“IPv4地址数量”或“IPv6地址数量”参数，命令执行成功后，系统会返回Batch ID，否则不返回。操作员登录“PGW Web LMT”的“系统管理”界面，使用**CHK BATSTAT**命令查看Batch ID操作任务的详细输出信息，可通过“文件管理器”下载详细的输出报告。
- 回收IP地址数量不能超过65536条。

## 参数说明

| 参数标识            | 参数名称       | 参数说明                                                                                                                                                                                                                                              |
|:----------------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| POOLID          | IP地址池索引    | 标识IP地址池的关键字段之一，用于指定需要回收哪一个IP地址池，操作员可以使用LST UIPPOOLTPL命令查询获得。                                                                                                                                                                                      |
| IPTYPE          | IP类型       | 用于指定IP地址段内IP地址的类型。 取值范围：IPv4IPv6 默认值：无。                                                                                                                                                                                                           |
| STARTIPV4       | 起始IPv4     | 仅当该命令中“IP类型”参数为“IPv4”时，该参数有效且必须输入。用于指定回收IP地址段的起始IPv4地址。 取值范围：有效的IPv4地址。 默认值：无。                                                                                                                                                                    |
| STARTIPV6PREFIX | 起始IPv6地址前缀 | 仅当该命令中“IP类型”参数为“IPv6”时，该参数有效且必须输入。用于指定IP地址段的起始IPv6地址前缀。 取值范围：有效的IPv6地址。 默认值：无。 注意：格式为X:X:X:X:X:X:X:X，每个“X”表示四个十六进制数。输入IPv6前缀时，只需要输入前缀部分，不满足IPv6长度的部分由系统自动补充为0。例如，前缀长度为64的IPv6前缀只需要输入FE80:0:0:1。不支持IPv6简写。例如，IPv6前缀为FE80:0:0:FE80，不能简写为FE80::FE80。 |
| IPV4COUNT       | IPv4地址数量   | 仅当该命令中“IP类型”参数为“IPv4”时，该参数有效。用于指定从起始IPv4地址开始的IP地址数量。 取值范围：1～65536。 默认值：无。 说明：若只有1条记录，该参数可以不输入。                                                                                                                                                    |
| IPV6COUNT       | IPv6地址数量   | 仅当该命令中“IP类型”参数为“IPv6”时，该参数有效。用于指定从起始IPv6地址开始的IP地址数量。 取值范围：1～65536。 默认值：无。 说明：若只有1条记录，该参数可以不输入。                                                                                                                                                    |
| RECYMODE        | 回收方式       | 用于指定IP的回收方式。 取值范围：RECYCLE：回收，直接将已使用IP地址设置为空闲状态。FORBID：禁用，将IP地址设置为禁用后，该IP地址不再对外分配。NORMAL：启用，将禁用IP地址设置为启用后，该IP地址可用于对外分配。 默认值：RECYCLE。                                                                                                               |
| SNDDM           | 是否将用户下线    | 仅当该命令中“回收方式”参数为“RECYCLE”或“FORBID”时，该参数有效。用于指定回收IP地址时，是否将已使用IP地址的用户下线。 取值范围：YESNO 默认值：YES。                                                                                                                                                         |

## 使用实例

1. 回收“IP地址池索引”为“1”中的IPV4类型IP地址，“起始IPv4”为“192.168.1.10”设置为空闲状态。执行命令如下：

   ```
   RECYCLE UIPBATCH: POOLID=1, IPTYPE=IPv4, STARTIPV4="192.168.1.10", RECYMODE=RECYCLE, SNDDM=YES;
   ```
2. 回收“IP地址池索引”为“1”，“起始IPv4”为“192.168.1.30”的IPV4类型IP地址，共计30条，设置为空闲状态。执行命令如下：

   ```
   RECYCLE UIPBATCH: POOLID=1, IPTYPE=IPv4, STARTIPV4="192.168.1.30", IPV4COUNT=30, RECYMODE=RECYCLE, SNDDM=YES;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 消息解释          | 原因分析                           | 处理建议                                           |
|----------:|:--------------|:-------------------------------|:-----------------------------------------------|
| 400001016 | IP地址池模板ID不存在。 | 输入的“IP地址池索引”参数指定的IP地址池模板信息不存在。 | 执行LST UIPPOOLTPL命令查询后，重新输入“IP地址池索引”参数，确保其取值存在。 |
| 400002134 | IPV4 不存在。     | 参数“起始IPv4”指定的IPv4地址不存在。        | 请重新指定“起始IPv4”参数，确保其取值是存在的。                     |
| 400002136 | IPV6不存在       | 参数“起始IPv6地址前缀”指定的IPv6地址前缀不存在。  | 请重新指定“起始IPv6地址前缀”参数，确保其取值是存在的。                 |
| 400002138 | IPV6格式错误。     | 参数“起始IPv6地址前缀”指定的IPv6地址前缀格式错误。 | 重新指定“起始IPv6地址前缀”参数，确保其取值符合要求。                  |
