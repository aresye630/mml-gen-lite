# 查询SCTP链路信息(LST PSCTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询SCTP链路信息。

## 注意事项

无。

## 参数说明

| 参数ID     | 参数名称      | 参数描述                                                                 |
|:---------|:----------|:---------------------------------------------------------------------|
| PCRFID   | PCRF标识    | 用于标识PCRF实体，该参数必须先由ADD PCRF命令定义，然后才能在此处引用。 取值范围：1 默认值：无。              |
| PEERID   | 对端标识      | 用于指定一个对端。 取值范围：0～1 默认值：无。                                            |
| PEERTYPE | 对端类型      | 用于定义对端类型。 取值范围：AFPCEFDRAOCSRPCRFSPRTDF 默认值：无。                        |
| LNKID    | 对端链路标识    | 用于在UPCF的配置库中定义一个对端链路。 该参数的配置原则：如果配置多个对端链路，从0开始顺序配置。 取值范围：0～11 默认值：无。 |
| LIP      | 本端IP地址    | 用于指定链路使用的本端IP地址，此IP地址必须是本地实际的IP地址。 取值范围：长度不超过40的字符串 默认值：无。           |
| LPT      | 本地侦听端口    | 本地侦听端口，UPCF内部用于与指定的对端建立链路的端口。 取值范围：1～65534 默认值：无。                    |
| PIP      | 对端IP地址    | 用于指定链路使用的对端IP地址，此IP地址需要与对端协商一致。 取值范围：长度不超过40的字符串 默认值：无。              |
| PPT      | 对端端口      | 用于指定链路使用的对端端口，此IP端口需要与对端协商一致 取值范围：0～65534 默认值：无。                     |
| DLIP     | 双归属本端IP地址 | 用于指定链路使用的双归属本端IP地址，此IP地址必须是本地实际的IP地址。 取值范围：长度不超过40的字符串 默认值：无。        |
| DPIP     | 双归属对端IP地址 | 用于指定链路使用的双归属对端IP地址，此IP地址需要与对端协商一致。 取值范围：长度不超过40的字符串 默认值：无。           |

## 使用实例

查询所有的SCTP链路信息。

```
LST PSCTPL:;
```
