# 设置灰度升级配置管理(SET UPDABTEST)

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 参数说明
- 使用实例

#### 命令功能

此命令用于设置灰度升级相关配置信息。

#### 注意事项

- 该命令执行后立即生效。
- 升级流程开始调用开启；升级流程结束调用关闭。

#### 本地用户权限

manage-ug; system-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                           |
|:-------|:-------|:-----------------------------------------------------------------------------------------------|
| STATUS | 灰度升级   | 可选必选说明：必选参数。 参数含义：该参数用于指定系统是否处于灰度升级阶段。 数据来源：本端规划。 取值范围：枚举类型。 RUNNING：灰度升级期间 STOP：非灰度升级期间 默认值：无 |

#### 使用实例

系统进入灰度升级阶段:

```
%%SET UPGABTEST: STATUS=RUNNING;%% 
RETCODE = 0  操作成功

---    END
```
