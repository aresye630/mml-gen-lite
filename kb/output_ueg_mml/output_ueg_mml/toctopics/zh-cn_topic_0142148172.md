# 网管配置同步（GET CFGFILE）

- 命令功能
- 注意事项
- 参数说明

#### 命令功能

本命令是网管下发的配置数据同步命令，网元把配置对象数据生成XML文件，通过SFTP协议把XML同步到网管，保证网管与网元之间配置数据一致。

#### 注意事项

GET CFGFILE是机机命令，由网管下发执行。

本命令链接SFTP服务器默认使用22端口，如果实际环境中SFTP服务器端口非22需要使用**ADD FWRULE**命令增加转发规则。

#### 参数说明

| 参数名称    | 数据类型、取值范围                                             | 参数描述                | 参数约束                       |
|:--------|:------------------------------------------------------|:--------------------|:---------------------------|
| MEID    | 整型，{0~65535}                                          | 被管对象类所在的网元ID        | 必选                         |
| MOCLIST | 字符串，char(128)                                         | 被管对象类名称列表           | 可选，若不填，表示导出所有配置数据          |
| NELABEL | 整型，{0~4294967294}                                     | 网元总标签               | 可选，若不填，表示导出MOCLIST所有配置数据   |
| IP      | IP地址类型                                                | SFTP服务器IP地址         | 必选                         |
| USR     | 字符串，char(20)                                          | 登录SFTP服务器所使用的用户名    | 必选                         |
| PWD     | 密码类型，char(128)                                        | 对应与SFTP服务器用户名的登录密码  | 必选                         |
| DSTF    | 字符串，char(256)                                         | 目标文件在SFTP服务器上全路径的名称 | 必选                         |
| CF      | 枚举： CFType1（注：不压缩） CFType2（注：压缩） CFType3（注：压缩，tar.gz） | 压缩类型                | 可选，没有输入，则认为不需要压缩，即为CFTYPE1 |
