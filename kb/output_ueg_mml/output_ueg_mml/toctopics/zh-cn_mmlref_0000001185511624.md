# 配置电子保单信息（SET DIGIW）

## 命令功能

该命令用于网管配置网元的服务起始时间和服务年限。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                     |
|:---------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID     | 网元ID   | 可选必选说明：必选参数。 参数含义：用于指示系统根据哪个网元ID配置电子保单信息。 取值范围：0~65535。 默认值：无。 配置原则：可以使用LST ME命令查询获网元ID。                                                                                                                                                                                                                 |
| LIFESPAN | 保单信息   | 可选必选说明：必选参数。 参数含义：标识需要配置的保单信息。 取值范围：字符串类型，输入长度范围为0~20480。 默认值：无。 配置原则： 参数格式为“LIFESPAN0##LIFESPAN1##LIFESPANn”（LIFESPANn的数据格式为“INDEX&SN&STARTPOINT&SESSION”，INDEX代表序号（0代表网元软件数据，大于0代表网元硬件数据，取值不超过65535），SN代表序列号（非空），STARTPOINT代表服务起始时间（时间格式为yyyy-MM-dd），SESSION代表服务年限(取值大于0，小于600)），必须包含网元软件数据，n的取值小于256。 |

## 使用实例

配置电子保单信息：

```
SET DIGIW: MEID="0",LIFESPAN="0&210305965710L4000062&2021-06-10&120##1&210305965710L4000063&2021-06-10&120";
```

该命令执行异常，会返回对应的错误码。常见错误码列表如
