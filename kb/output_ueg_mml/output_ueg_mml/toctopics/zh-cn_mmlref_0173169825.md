# 设置平面内的节点为master（SET PLANENODE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于置平面内所有DRU/DSU节点状态为master。设置某平面节点为master，则另一个平面所有节点状态变为slave。在升级另一个平面时，可以减小重启节点造成的呼损。

## 注意事项

该命令在升级时会调用，其他场景下使用无效。

## 参数说明

| 参数ID   | 参数名称   | 参数描述                                                    |
|:-------|:-------|:--------------------------------------------------------|
| PLNID  | 平面ID   | 用于标识平面ID。 取值范围：0～1。                                     |
| UPGMOD | 升级模式   | 升级模式，该参数是必选参数。 取值范围：VER：版本升级。FEPLUG：插件包升级。CPATCH：冷补丁升级。 |

## 使用实例

```
SET PLANENODE:PLNID=0,UPGMOD=VER;
```

```
%%SET PLANENODE:PLNID=0,UPGMOD=VER;%%

---    END
```
