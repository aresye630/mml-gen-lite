# 恢复升级参数（RST UPGINSP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于在配置数据库中删除升级参数信息。

## 注意事项

该命令在升级时会自动调用，其他场景下严禁使用。

## 参数说明

| 参数ID    | 参数名称   | 参数描述                                                                                                                         |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------------------|
| ISFORCE | 恢复模式   | 用于标识恢复模式。 取值范围：NORMAL(正常恢复)：当执行命令SET UPGINSP之后，系统会自动将升级参数进行备份。选择恢复模式为NORMAL时，将从备份的参数进行恢复。FORCED(强制恢复)：系统强制将升级参数设置为默认值。 默认值：无 |

## 使用实例

使用正常模式恢复升级参数。

```
RST UPGINSP: ISFORCE=NORMAL;
```

```
%%RST UPGINSP: ISFORCE=NORMAL;%%
RETCODE = 0  操作成功
```
