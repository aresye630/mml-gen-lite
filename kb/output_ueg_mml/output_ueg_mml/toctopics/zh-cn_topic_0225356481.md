# 上传任务文件(ULD DEFMEAS)

- 命令功能
- 注意事项
- 参数说明
- 输出结果说明

#### 命令功能

通过ULD DEFMEAS命令可获得网元上的任务文件。文件传送采用SFTP方式进行。

#### 注意事项

在升级场景下，由于需要兼容低版本网管，系统会在对接SFTP时针对安全算法使用兼容方式处理。

#### 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                |
|:-------|:--------|:------------------------------------------------------------------------------------|
| FT     | 任务文件类型  | 可选必选说明：必选参数。 参数含义：任务文件类型。 取值范围： 0(Active)1(Standby) 默认值：无。 配置原则：无。                  |
| IP     | 服务器IP地址 | 可选必选说明：必选参数。 参数含义：网管SFTP服务器IP地址。 取值范围：IPV4或IPV6地址。 默认值：无。 配置原则：无。                   |
| NEID   | 网元ID    | 可选必选说明：必选参数。 参数含义：标识收集的网元ID。 取值范围：0~1023的整数。 默认值：无。 配置原则：无。                         |
| PWD    | 密码      | 可选必选说明：必选参数。 参数含义：网管SFTP用户密码。 取值范围：长度不超过128的密码。 默认值：无。 配置原则：无。                      |
| USR    | 用户名     | 可选必选说明：必选参数。 参数含义：网管SFTP用户名。 取值范围：长度不超过32的字符串。 默认值：无。 配置原则：无。                       |
| GA     | 是否上报进度  | 可选必选说明：可选参数。 参数含义：是否上报进度。 取值范围： 0(不上报)1(上报) 默认值：无。 配置原则：无。                          |
| DSTF   | 目标文件名称  | 可选必选说明：必选参数。 参数含义：用于输入目标文件名称。 取值范围：长度不超过256的字符串。 默认值：无。 配置原则：无。                     |
| FN     | 本地文件名称  | 可选必选说明：可选参数。 参数含义：用于输入本地文件名称。 取值范围：长度不超过256的字符串。 默认值：无。 配置原则：无。                     |
| EMS    | 网管类型    | 可选必选说明：必选参数。 参数含义：网管类型。 取值范围：1-65535。 默认值：无。 配置原则：无。                                |
| PORT   | 服务器端口号  | 可选必选说明：可选参数。 参数含义：网管SFTP服务器端口号。 取值范围：1-65535。 默认值：22。 配置原则：与实际服务器上sftp服务启动指定的端口号一致。 |

#### 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，请联系华为技术支持处理。输出错误码说明如表1错误码列表所示。

|    错误码 | 错误码解释       | 原因分析                  | 处理建议          |
|-------:|:------------|:----------------------|:--------------|
| 650016 | 参数错误        | 命令参数个数错误。             | 检查必选参数个数是否正确。 |
| 650100 | 连接SFTP服务器出错 | 获取服务器IP失败。            | 请联系华为技术支持。    |
| 650102 | 网元未接入       | 获取网元ID失败。             | 请联系华为技术支持。    |
| 650116 | 网元加载中       | 加载过程中可能存在网络故障，出现此种情况。 | 等待几分钟，重试执行。   |
