# 增加Pod信息(ADD PODINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于添加Pod信息。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
|:--------------|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PODNAME       | Pod名称      | 用于指定需要增加的Pod名称，唯一标识一个Pod。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：该参数的值域范围为：大写字母“A～Z”、小写字母“a～z”、数字“0～9”、特殊字符“-”、“_”、“.”。该参数必须以字母开头。该参数区分大小写。                                                                                                                                                                                                                                                                                                                      |
| PODLOC        | 节点名称       | 用于指定需要增加的Pod的节点名称。 取值范围：长度不超过60的字符串。 默认值：无。 配置原则：该参数的值域范围为：大写字母“A～Z”、小写字母“a～z”、数字“0～9”、特殊字符“-”、“_”、“.”。该参数区分大小写。                                                                                                                                                                                                                                                                                                                                         |
| APPTYPE       | 应用类型       | 用于指定需要增加的Pod是哪种应用类型。 取值范围：USDIU(USDIU)USDSU(USDSU)USDRU(USDRU)USDMU(USDMU)USDMU2(USDMU2) USDMU3(USDMU3)USDPU(USDPU)USDMD(USDMD)USDID(USDID)USDID3(USDID3)USRSU(USRSU)USCAG(USCAG)USPGW(USPGW)USPMU(USPMU)USPMU3(USPMU3)USPID3(USPID3)MNAHU(MNAHU)MNAHU3(MNAHU3)ENSIU(ENSIU)UAMU(UAMU)UMSU(UMSU)UMHU(UMHU)UTAU(UTAU)UPSU(UPSU)UBSF(UBSF)UAPU(UAPU)USISU(USISU)USRSUF(USRSUF)USRSUM(USRSUM)USRSUMF(USRSUMF)USPID(USPID)PAPPTYPE_TEST(PAPPTYPE_TEST) 默认值：无。 |
| BASE1MAC      | Base1平面MAC | 用于指定需要增加的Pod的Base1的MAC地址信息。 取值范围：长度不超过60的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                     |
| BASE2MAC      | Base2平面MAC | 用于指定需要增加的Pod的Base2的MAC地址信息。 取值范围：长度不超过60的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                     |
| BASE1IP       | BASE1 IP   | 用于指定需要增加的Pod的BASE1的IP地址。 取值范围：无。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                  |
| BASE2IP       | BASE2 IP   | 用于指定需要增加的Pod的BASE2的IP地址。 取值范围：无。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                  |
| FABRIC1IP     | FABRIC1 IP | 用于指定需要增加的Pod的FABRIC1的IP地址。 取值范围：无。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                |
| FABRIC2IP     | FABRIC2 IP | 用于指定需要增加的Pod的FABRIC2的IP地址。 取值范围：无。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                |
| FABRIC3IP     | FABRIC3 IP | 用于指定修改后的Pod的FABRIC3的IP地址。 取值范围：无。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                 |
| FABRIC4IP     | FABRIC4 IP | 用于指定修改后的Pod的FABRIC4的IP地址。 取值范围：无。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                 |
| BASEPORTNUM   | BASE网口个数   | 用于指定需要增加的Pod的BASE网口个数。 取值范围：1～4。 默认值：2。                                                                                                                                                                                                                                                                                                                                                                                                                  |
| FABRICPORTNUM | FABRIC网口个数 | 用于指定需要增加的Pod的FABRIC网口个数。 取值范围：0~4。 默认值：2。                                                                                                                                                                                                                                                                                                                                                                                                                |
| SIGNALPORTNUM | 信令网口个数     | 用于指定需要增加的Pod的信令网口个数。 取值范围：0~24。 默认值：0。                                                                                                                                                                                                                                                                                                                                                                                                                   |
| VNFID         | VNF ID     | 用于指定需要增加的Pod在MANO侧的编号，唯一标识一个Pod所属的VNF域。 取值范围：长度不超过64的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                         |
| OSARCH        | 架构类型       | 用于指定需要增加的Pod的架构类型。 取值范围： X86ARM 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                   |

## 使用实例

增加“Pod名称”为“VNF\_MSX\_0”，“节点名称”为“10.10.10.10”，“应用类型”为“USDRU”，“Base1平面MAC”为“00:50:56:01:00:10”，“Base2平面MAC”为“00:50:56:01:00:55”，“BASE1 IP”为“10.16.128.11”，“BASE2 IP”为“10.16.136.12”，“FABRIC1 IP”为“10.16.144.11”，“FABRIC2 IP”为“10.16.152.12”，“BASE网口个数”为“2”，“FABRIC网口个数”为“2”，“信令网口个数”为“0”，“VNF ID”为“785d39a390c8414fa8a5ab8a6f65a468”，“OSARCH”为“X86”的CSP的POD信息：

`ADD PODINFO: PODNAME="VNF_MSX_0", PODLOC="10.10.10.10", APPTYPE=USDRU, BASE1MAC="00:50:56:01:00:10", BASE2MAC="00:50:56:01:00:55", BASE1IP="10.16.128.3", BASE2IP="10.16.136.4", FABRIC1IP="10.16.144.3", FABRIC2IP="10.16.152.4", BASEPORTNUM=2, FABRICPORTNUM=2, SIGNALPORTNUM=0, VNFID="785d39a390c8414fa8a5ab8a6f65a468", OSARCH=X86;`
