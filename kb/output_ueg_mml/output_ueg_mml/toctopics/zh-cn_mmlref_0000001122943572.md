## 命令功能

文件导入任务管理，可对文件导入任务进行查询及停止操作。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                    |
|:---------|:-------|:----------------------------------------------------------------------------------------|
| TASKID   | 任务ID   | 可选必选说明：必选参数。 参数含义：任务ID，用于查询IMP MML下发的任务。 取值范围：长度不超过48的字符串。 默认值：无。 配置原则：由字母和数字组成。        |
| OPERTION | 执行操作   | 可选必选说明：可选参数。 参数含义：查询任务或者终止任务。 取值范围： PROGRESS(查询进度)END(终止任务) 默认值：PROGRESS(查询进度)。 配置原则：无。 |

## 使用实例

1. 查询任务进度：

   ```
   %%IMP STATUS:TASKID="f6230c88-d381-11eb-8000-bc6b00000053",OPERTION=PROGRESS;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
        状态  =  运行中
   进度（%）  =  47
    当前位置  =  1885
   (结果个数 = 1)

   ---    END
   ```
2. 终止任务：

   ```
   %%IMP STATUS:TASKID="f6230c88-d381-11eb-8000-bc6b00000053",OPERTION=END;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
        状态  =  被动终止
   进度（%）  =  63
    当前位置  =  2529
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息，输出项说明见输出项说明所示。

命令执行异常，请联系华为技术支持处理。输出结果说明如错误码列表所示。

| 输出项名称   | 输出项解释                        |
|:--------|:-----------------------------|
| 状态      | 标识指定任务的执行情况。 运行中运行结束异常中断被动终止 |
| 进度（%）   | 标识指定任务执行的程度（以百分比计算）。         |
| 当前位置    | 标识指定任务当前执行命令在导入文件中的行号。       |

|    错误码 | 错误码解释            | 原因分析                  | 处理建议       |
|-------:|:-----------------|:----------------------|:-----------|
| 100101 | 任务不存在。           | 客户输入的任务ID没有执行过。       | 请联系华为技术支持。 |
| 100102 | 任务已停止。           | 当执行操作选择终止任务时，所选任务已停止。 | 请联系华为技术支持。 |
| 100103 | 系统内部组件异常，请联系管理员。 | 内部模块故障。               | 请联系华为技术支持。 |
