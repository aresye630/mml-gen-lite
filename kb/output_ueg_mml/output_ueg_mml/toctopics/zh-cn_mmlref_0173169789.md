# 回退DSG模块的内存数据库（RBK MTNIMDB）

- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

该命令为维护类命令，用于升级场景下回退DSG模块在业务虚拟机（裸机Pod）上保存的旧版本内存数据库备份文件。

- 若需要回退所有DSG模块的内存数据库备份文件，请不要输入任何参数。
- 若需要回退指定的某一个DSG模块的内存库备份文件，请输入“模块号”，无需输入“平面号”。
- 若需要回退指定平面的DSG模块的内存库备份文件，请输入“平面号”，无需输入“模块号”。

## 注意事项

- 在升级时，升级框架会自动执行该命令。其他场景下严禁执行该命令。
- 当输入参数“平面号”和“模块号”时，会忽略“模块号”，按照平面下发命令。

## 参数说明

| 参数ID   | 参数名称   | 参数描述                                                                                                                                                                                    |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MID    | 模块号    | 在配置数据库中定义一个模块，模块即虚拟机（裸机Pod）上运行的进程。该参数是通过ADD MODULE定义后在此引用。 取值范围： 1～2047 默认值： 无。                                                                                                         |
| PLNID  | 平面号    | DSG模块所处的平面，在升级过程中，升级工具会将DSG模块划分成两个平面。 取值范围：0：表示选取0平面的DSG模块。1：表示选取1平面的DSG模块。 该参数的设置原则是：版本升级或者插件包升级场景下，只允许分平面回退DSG模块的内存数据库备份文件，必须输入参数“平面号”。在其他场景下，无需输入“平面号”，只需输入“模块号”来指定DSG模块回退内存数据库备份文件。 |

## 使用实例

1. 回退所有DSG模块的内存数据库备份文件。执行如下命令：

   ```
   RBK MTNIMDB:;
   ```
2. 在升级场景下回退平面1的DSG模块的内存数据库备份文件：设置“平面号”为“1”。执行如下命令：

   ```
   RBK MTNIMDB: PLNID=1;
   ```
3. 回退指定模块号21的DSG模块的内存数据库备份文件：设置“模块号”为“21”。执行如下命令：

   ```
   RBK MTNIMDB: MID=21;
   ```
