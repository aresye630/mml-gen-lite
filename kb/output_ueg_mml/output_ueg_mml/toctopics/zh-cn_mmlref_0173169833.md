# 显示DSG模块的状态（DSP DSGNODE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于按照“升级类型”或者“平面ID”显示指定的DSG模块运行状态，若“升级类型”和“平面ID”都没有输入，则显示USCDB网元所有DSG模块的运行状态。升级场景下，升级工具自动调用此命令来检查升级后的新版本的DSG模块的状态。在其他场景下，也可手动执行此命令来检查DSG模块状态。

## 注意事项

- 处于升级场景下，依据不同的升级场景，“升级类型”取值为“VER(版本升级)”或者“FEPLUG(插件包升级)”。
- 在其他场景下，“升级类型”可以不输入或者取值为“NOUPG(无升级)”。
- 当输入“升级类型”的参数值为“VER(版本升级)”或者“FEPLUG(插件包升级)”时，参数“平面ID”必须要输入，否则上报“参数平面号缺失”的报文。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                       |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TYPE   | 升级类型   | 用于标识升级类型。 取值范围：VER(版本升级)：版本升级。FEPLUG(插件包升级)：插件包升级。NOUPG(无升级)：不处于升级场景。CPATCH（冷补丁升级）：冷补丁升级。 该参数的设置原则是：版本升级场景下，“升级类型”取值为“VER(版本升级)”。插件包升级场景下，“升级类型”取值为“FEPLUG(插件包升级)”。在其他场景下，“升级类型”可以不输入，或者取值为“NOUPG(无升级)”。冷补丁升级场景下，“升级类型”取值为“CPATCH（冷补丁升级）”。 |
| PLNID  | 平面ID   | 用于标识平面ID。 取值范围：0：表示显示0平面的DSG模块的状态。1：表示显示1平面的DSG模块的状态。 该参数的设置原则是：版本升级或者插件包升级场景下，只允许分平面查询DSG模块运行状态，必须输入参数“平面ID”。在其他场景下，无论输入“平面ID”与否，都显示USCDB全部的DSG模块运行状态。                                                                                    |

## 使用实例

1. 显示所有DSG模块的运行状态：

   ```
   DSP DSGNODE:;
   ```

   ```
   %%DSP DSGNODE:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    模块标识  节点状态  

    11        初始化完成
    12        初始化完成
    124       初始化完成
    125       初始化完成
    126       初始化完成
    127       初始化完成
   (结果个数 = 6)

   ---    END
   ```
2. 在版本升级场景下显示平面1的DSG模块的运行状态：设置“升级类型”为“VER(版本升级)” ，“平面ID”为“1”。

   ```
   DSP DSGNODE: TYPE=VER, PLNID=1;
   ```

   ```
   %%DSP DSGNODE: TYPE=VER, PLNID=1;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    模块标识  节点状态  

    12        初始化完成
    125       初始化完成
    127       初始化完成
   (结果个数 = 3)

   ---    END
   ```

## 输出结果说明

| 输出项名称   | 输出项解释                                                                         |
|:--------|:------------------------------------------------------------------------------|
| 模块标识    | 在配置数据库中定义一个模块，模块即虚拟机（裸机Pod）上运行的进程。该参数是通过ADD MODULE定义后在此引用。 取值范围：1～2047 默认值:无。 |
| 节点状态    | 用于表示该节点所处的状态。 取值说明： 初始化:表示DSG模块尚未准备好对外承接业务。初始化完成：表示DSG模块完成初始化，可以对外承接业务。       |
