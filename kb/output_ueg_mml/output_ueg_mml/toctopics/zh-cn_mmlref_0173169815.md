# 激活指定平面内的节点（ACT PLANENODE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于激活平面的DRU/DSU节点。在升级一个平面时，使用命令**DEA PLANENODE**去激活该平面的DRU/DSU节点，执行升级。在对节点升级完成之后，激活DRU/DSU节点，恢复服务。

## 注意事项

该命令在升级时会执行，其他场景下严禁执行该命令。

## 参数说明

| 参数ID   | 参数名称   | 参数描述                                               |
|:-------|:-------|:---------------------------------------------------|
| PLNID  | 平面ID   | 用于标识平面ID。 取值范围：0～1。                                |
| UPGMOD | 升级模式   | 用于标识升级模式。 取值范围：VER：版本升级。FEPLUG：插件包升级。CPATCH：冷补丁升级。 |

## 使用实例

```
ACT PLANENODE:PLNID=0,UPGMOD=VER;
```

```
%%ACT PLANENODE:PLNID=0,UPGMOD=VER;%%

```
