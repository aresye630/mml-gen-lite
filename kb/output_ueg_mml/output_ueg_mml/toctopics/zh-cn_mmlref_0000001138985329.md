# 获取弹性伸缩资源信息（DSP SCALEINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**说明** 

该命令仅在Full-stack虚机场景下支持。

该命令为维护类命令，目前用于获取系统自动扩容所需增加虚拟机或POD的数量。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
|:------------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SCALETYPE   | 弹性伸缩方式   | 可选必选说明：必选参数 参数含义：标识本次弹性伸缩的方式，包括扩容和缩容两类。 取值范围： scale_out：标识为扩容操作。scale_in：标识为缩容操作。 默认值：无 配置原则：通过CSP获得此信息。                                                                                                                                                                                                                                                                                                                                                        |
| SCALEGROUP  | 弹性伸缩组分类  | 可选必选说明：必选参数 参数含义：弹性伸缩组分类，包括VDU和APP两类。 取值范围： VDU：标识为虚拟机扩缩容场景。APP：标识为POD扩缩容场景。 默认值：无 配置原则：通过CSP获得此信息。                                                                                                                                                                                                                                                                                                                                                             |
| SCALEPOLICY | 弹性伸缩策略   | 可选必选说明：必选参数 参数含义：定义弹性伸缩的策略。 取值范围： 0：强制 1：优雅 默认值：1 配置原则：预留字段，暂未使用。                                                                                                                                                                                                                                                                                                                                                                                               |
| SCALECLASS  | 弹性伸缩对象类型 | 可选必选说明：必选参数 参数含义：标识弹性伸缩的对象类型。 取值范围： 扩缩容虚拟机阶段： 0：弹性伸缩采用按虚拟机比例方式 1：弹性伸缩采用按APP即POD方式 2：弹性伸缩采用按虚拟机方式 扩缩容应用服务POD阶段： 0：弹性扩缩容目标APP数量 配置原则：在扩缩容虚拟机时透传MANO请求的字段。                                                                                                                                                                                                                                                                                                         |
| SCALESTEP   | 弹性伸缩步长   | 可选必选说明：必选参数 参数含义：即一次弹性伸缩指定类型资源个数。 取值范围：0~100 默认值：0 配置原则：预留参数。从VNFD里获取作为参考值。当前未对该值做处理。                                                                                                                                                                                                                                                                                                                                                                           |
| SCALEINFO   | 弹性伸缩资源信息 | 可选必选说明：可选参数 参数含义：一次弹性伸缩所涉及的资源信息列表。 取值范围：长度不超过2048的字符串。 例1：{/QSCALE_NUM/Q:1/c/QSG_NAME/Q:/QUSRSU-OA_VDU1/Q}/c{/QSCALE_NUM/Q:1/c/QSG_NAME/Q:/QUSRSU-OA_VDU2/Q} 例2：{/QSCALE_NUM/Q:2/c/QSG_NAME/Q:/Qusrsuoa-application/Q/c/QVDU_INFO/Q:/QUSRSU-OA_VDU1/Q}/c{/QSCALE_NUM/Q:2/c/QSG_NAME/Q:/Qusrsuob-application/Q/c/QVDU_INFO/Q:/QUSRSU-OA_VDU2/Q} 其中"/"为转义符，“/Q”表示双引号，两个“/Q”中间内容说明是字符串。“/c”表示逗号，用于分隔作用。冒号前面表示参数名称，冒号后面表示参数取值。 默认值：无 配置原则：从CSP收到MANO做扩缩容操作的查询请求中获取。 |

## 使用实例

查看指定类型虚拟机所要弹性扩容增加的虚拟机数量。

```
DSP SCALEINFO: SCALETYPE="scale_out", SCALEGROUP="VDU", SCALEPOLICY=1, SCALECLASS=2, SCALESTEP=1, SCALEINFO="{/QSCALE_NUM/Q:1/c/QSG_NAME/Q:/QSUPFERSUF_VDU1/Q}/c{/QSCALE_NUM/Q:2/c/QSG_NAME/Q:/QSUPFERSUO_VDU2/Q}";
```

```
%%DSP SCALEINFO: SCALETYPE="scale_out", SCALEGROUP="VDU", SCALEPOLICY=1, SCALECLASS=2, SCALESTEP=1, SCALEINFO="{/QSCALE_NUM/Q:1/c/QSG_NAME/Q:/QSUPFERSUF_VDU1/Q}/c{/QSCALE_NUM/Q:2/c/QSG_NAME/Q:/QSUPFERSUO_VDU2/Q}";%%
RETCODE = 0  操作成功

操作结果如下
------------------------ 
弹性伸缩方式   弹性伸缩组分类   弹性伸缩资源组名   弹性伸缩资源数量  弹性伸缩策略  弹性伸缩对象类型  
scale_out      VDU              SUPFERSUF_VDU1     2                 1             2           
scale_out      VDU              SUPFERSUO_VDU2     2                 1             2         
(结果个数 = 2)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称       | 输出项解释                                                                                                             |
|:------------|:------------------------------------------------------------------------------------------------------------------|
| SCALETYPE   | 参数含义：标识本次弹性伸缩的方式，包括扩容和缩容两类。 取值范围： scale_out：标识为扩容操作。scale_in：标识为缩容操作。                                             |
| SCALEGROUP  | 参数含义：弹性伸缩组分类，包括VDU和APP两类。 取值范围： VDU：标识为虚拟机扩缩容场景。APP：标识为POD扩缩容场景。                                                  |
| SGNAME      | 参数含义：弹性伸缩资源组名，从入参“弹性伸缩资源信息”中“SG_NAME”获得。 取值范围：长度不超过128的字符串。                                                       |
| SCALENUM    | 参数含义：弹性伸缩资源的数量。单位：个。 取值范围：0~65535                                                                                 |
| SCALEPOLICY | 参数含义：定义弹性伸缩的策略。 取值范围： 0：强制 1：优雅                                                                                   |
| SCALECLASS  | 参数含义：标识弹性伸缩的对象类型。 取值范围： 扩缩容虚拟机阶段： 0：弹性伸缩采用按虚拟机比例方式 1：弹性伸缩采用按APP即POD方式 2：弹性伸缩采用按虚拟机方式 扩缩容应用服务POD阶段： 0：弹性扩缩容目标APP数量 |
