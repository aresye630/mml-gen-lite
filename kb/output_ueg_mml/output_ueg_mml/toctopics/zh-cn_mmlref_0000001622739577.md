# 查询DCI错误码测量对象（LST DCIERRCODEOBJ）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询USCDB网元下的DCI错误码测量对象信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询DCI错误码测量对象信息。

```
LST DCIERRCODEOBJ:;
```

```
%%LST DCIERRCODEOBJ:;%% 
RETCODE = 0  操作成功  

操作结果如下 
------------ 
 FE类型     数据类型    消息源      
 33         全局数据    FE        
 33         全局数据    本地              
 33         全局数据    复制
 33         全局数据    转发  
 33         用户数据    FE       
 33         用户数据    本地       
 33         用户数据    复制       
 33         用户数据    转发       
(结果个数 = 8)  

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称   | 输出项解释                |
|:--------|:---------------------|
| FE类型    | 用于表示DCI错误码测量对象的FE类型。 |
| 数据类型    | 用于表示DCI错误码测量对象的数据类型。 |
| 消息源     | 用于表示DCI错误码测量对象的消息源。  |
