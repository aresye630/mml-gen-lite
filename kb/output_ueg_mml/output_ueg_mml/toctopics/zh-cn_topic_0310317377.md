# 导入MML文件（IMP MML）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

本命令可以将EXP MML命令导出的配置数据进行导入，提升导入效率。

#### 注意事项

无。

#### 参数说明

| 参数标识        | 参数名称          | 参数说明                                                                                                                                                               |
|:------------|:--------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPTYPE      | SFTP服务器IP地址类型 | 可选必选说明：必选参数。 参数含义：标识SFTP服务器IP地址类型。 取值范围： IPV4(IPV4)IPV6(IPV6) 默认值：无。 配置原则：无。                                                                                       |
| IPV4        | SFTP服务器IP地址   | 可选必选说明：该参数在“SFTP服务器IP地址类型”配置为“IPV4(IPV4)”时为条件必选参数。 参数含义：用于标识SFTP服务器的IP地址。 取值范围：IPv4地址。 默认值：无。 配置原则：无。                                                              |
| IPV6        | SFTP服务器IP地址   | 可选必选说明：该参数在“SFTP服务器IP地址类型”配置为“IPV6(IPV6)”时为条件必选参数。 参数含义：用于标识SFTP服务器的IP地址。 取值范围：IPv6地址。 默认值：无。 配置原则：无。                                                              |
| FTPUSER     | SFTP用户名       | 可选必选说明：必选参数。 参数含义：用于标识登录SFTP服务器的用户名。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：不支持逗号（,）、分号（;），等号（=）、双引号（"）、单引号（'），两个及以上的百分号（%），两个及以上的空格（ ）、mml报文起始符标识（+++）、mml报文结束符（--- END）。 |
| FTPPSSWD    | SFTP密码        | 可选必选说明：必选参数。 参数含义：用于标识登录SFTP服务器的密码。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：不支持特殊符号(')，且密码字符串中不能包含父目录符号（../）。                                                               |
| SSTF        | 导入文件目录        | 可选必选说明：必选参数。 参数含义：需导入的配置文件所在的目录。 取值范围：长度不超过256的字符串。 默认值：无。 配置原则：由数字、字母（a~z,A~Z）及特殊符号（~!@*()^_-+{}[]\:./?）组成，且不能包含父目录符号（../）。                                       |
| SFNM        | 导入文件名称        | 可选必选说明：必选参数。 参数含义：需导入的配置文件的名称。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：由数字、字母（a~z,A~Z）及特殊符号（~@^_-+{}[]）组成，且不能包含父目录符号（../）。                                                  |
| DSTF        | 结果文件目录        | 可选必选说明：必选参数。 参数含义：命令执行结果会写入结果文件，参数是结果文件需要上传到的目录。 取值范围：长度不超过256的字符串。 默认值：无。 配置原则：数字、字母（a~z,A~Z）及特殊符号（~!@*()^_-+{}[]\:./?）组成，且不能包含父目录符号（../）。                        |
| DFNM        | 结果文件名称        | 可选必选说明：可选参数。 参数含义：结果文件的名称。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：由数字、字母（a~z,A~Z）及特殊符号（~@^_-+{}[]）组成，且不能包含父目录符号（../）。                                                      |
| FTPPORT     | SFTP端口号       | 可选必选说明：可选参数。 参数含义：用于标识SFTP服务器的端口号。 取值范围：1～65535。 默认值：22。 配置原则：需要和真实的SFTP服务器端口一致，不填写则使用默认端口22。                                                                      |
| ONLYERRINFO | 是否只记录失败结果     | 可选必选说明：可选参数。 参数含义：是否只记录失败结果。 取值范围： TRUE(是)FALSE(否) 默认值：FALSE(否)。 配置原则：结果文件只记录失败结果选择是，不选择默认为记录全部执行结果。                                                               |
| DFNMR       | 失败命令文件名称      | 可选必选说明：可选参数。 参数含义：记录执行失败命令的文件，记录在结果文件目录。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：由数字、字母（a~z,A~Z）及特殊符号（~@^_-+{}[]）组成，且不能包含父目录符号（../）。                                        |
| STRATEGY    | 执行错误处理策略      | 可选必选说明：可选参数。 参数含义：遇到执行失败的命令后，当前任务的处理策略。 取值范围： IGNORE(跳过继续执行)STOP(终止) 默认值：IGNORE(跳过继续执行)。 配置原则：无。                                                                   |
| LINENUM     | 行号            | 可选必选说明：可选参数。 参数含义：用于指定从文件的哪行开始执行。 取值范围：1~200000 默认值：1。 配置原则：无。                                                                                                     |
| TASKID      | 任务ID          | 可选必选说明：可选参数。 参数含义：任务ID，用于解决任务重复执行和续传。 取值范围：长度不超过48的字符串。 默认值：无。 配置原则：由字母和数字及特殊符号（~!@#$^&*()_+{}|:<>？`-[]\/.）组成。                                                     |
| COMPRESS    | 是否压缩          | 可选必选说明：可选参数。 参数含义：结果报文是否压缩。 取值范围： TRUE(是)FALSE(否) 默认值：FALSE(否)。 配置原则：无。                                                                                            |

#### 使用实例

1. 导入配置文件：

   ```
   %%IMP MML: IPTYPE=IPV6, IPV6="fc00::40c5:156:110:225:37", FTPUSER="paas", FTPPSSWD="*****", SSTF="/home/paas/", SFNM="EXPMML_ALLME_25.0.RC1_CSP_20240829211947347257.txt", DSTF="/home/paas/", DFNM="IMPRESULT", ONLYERRINFO=FALSE, DFNMR="dragonErr-3", STRATEGY=IGNORE, LINENUM=10, TASKID="", COMPRESS=FALSE;%%
   RETCODE = 0  操作成功
   进度报文
   --------
   上报类型  =  IMP MML    
       状态  =  进行中    
       进度  =  92%  
   执行行号  =  4852
     会话号  =  501
     任务号  =  6b6cf676-d38b-11eb-8000-bc6b00000053
   (结果个数 = 1)

   ---    END

   %%IMP MML: IPTYPE=IPV6, IPV6="fc00::40c5:156:110:225:37", FTPUSER="paas", FTPPSSWD="*****", SSTF="/home/paas/", SFNM="EXPMML_ALLME_25.0.RC1_CSP_20240829211949201523.txt", DSTF="/home/paas/", DFNM="IMPRESULT", ONLYERRINFO=FALSE, DFNMR="dragonErr-3", STRATEGY=IGNORE, LINENUM=10, TASKID="", COMPRESS=FALSE;%%
   RETCODE = 0  操作成功
   进度报文
   --------
   上报类型  =  IMP MML    
       状态  =  成功     
   执行行号  =  5245
     会话号  =  501
     任务号  =  6b6cf676-d38b-11eb-8000-bc6b00000053
   (结果个数 = 1)

   共有2个报告
   ---    END
   ```

#### 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。输出项说明如输出项说明所示。
