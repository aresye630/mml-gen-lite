# 删除VDU模块（RMV VDUMODULE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，删除模块可能导致致命错误。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于云模式下，在导入VNFD文件自动部署的时候删除Pod上的模块。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                               |
|:--------|:--------|:-------------------------------------------------------------------------------------------------------------------|
| VMNAME1 | 主用Pod名称 | 用于描述主用Pod名称。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：该参数的值域范围为：大写字母“A～Z”、小写字母“a～z”、数字“0～9”、特殊字符“-”、“_”。该参数必须以字母开头。该参数区分大小写。 |
| VMNAME2 | 备用Pod名称 | 用于描述备用Pod名称。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：该参数的值域范围为：大写字母“A～Z”、小写字母“a～z”、数字“0～9”、特殊字符“-”、“_”。该参数必须以字母开头。该参数区分大小写。 |

## 使用实例

在云模式下，使用该命令删除Pod上的模块。命令示例如下：

```
RMV VDUMODULE:VMNAME1="BE94_HSSDID3_VDU1_0",VMNAME2="BE94_HSSDID3_VDU2_0";
```

在裸机场景下，使用该命令删除Pod上的模块。命令示例如下：

```
RMV VDUMODULE:VMNAME1="udr-usrsuo-pod-0-81-0",VMNAME2="udr-usrsuo-pod-0-81-1";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                              | 原因分析                              | 处理建议                                              |
|-------:|:-----------------------------------|:----------------------------------|:--------------------------------------------------|
| 337079 | 参数VMNAME1和VMNAME2的值不允许相同。          | 参数“主用Pod名称”和“备用Pod名称”输入的值相同。      | 请确保输入的参数“主用Pod名称”和“备用Pod名称”输入的值不同。                |
| 260337 | 非USPGW类型VDU须同时输入VMNAME1和VMNAME2参数。 | 未输入“备用Pod名称”，非USPGW Pod必须成对删除。    | 非USPGW类型的Pod删除模块时，同时输入“主用Pod名称”和“备用Pod名称”，再执行此命令。 |
| 257123 | 要删除的对象不存在。                         | 参数“主用Pod名称”和“备用Pod名称”指定的待删除对象不存在。 | 检查参数“主用Pod名称”和“备用Pod名称”的值，输入正确的参数值重新执行该命令。        |
