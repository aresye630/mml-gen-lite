# 获取弹性伸缩KPI指标值（DSP SCALEKPINE）

## 命令功能

**说明** 

该命令仅在Full-stack虚机场景下支持。

该命令为维护类命令，用于获取系统当前弹性伸缩KPI指标值。弹性伸缩KPI指标值包含CPU占用率和DRU/DSU内存占用率。

- 对于CPU占用率：系统获取资源组对应的自定义指标虚拟机CPU占用率当前值。网元通过KPI命名可以判断出是采集虚拟机的CPU占用率，如：cpuUsageVM。
- 对于内存占用率：系统获取资源组对应的自定义指标对应网元节点内存占用率当前值。网元通过KPI命名可以判断出是采集DRU或者DSU的内存占用率。如：memLoadDru，memLoadDsu。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                  |
|:--------|:--------|:--------------------------------------------------------------------------------------|
| KPILIST | KPI指标列表 | 可选必选说明：必选参数 参数含义：弹性伸缩指标列表信息，用于查询指定弹性伸缩指标列表中多个KPI指标值。 取值范围：长度不超过2048的字符串。 默认值：无 配置原则：无 |

## 使用实例

查看指定弹性伸缩指标信息列表对应的多个KPI指标值信息。

```
DSP SCALEKPINE: KPILIST="{/Qsg_name/Q:/QSUPFEDID3_VDU1/Q/c/Qkpi/Q:/QcpuUsageVM/Q}/c{/Qsg_name/Q:/QSUPFEDID3_VDU2/Q/c/Qkpi/Q:/QcpuUsageVM/Q}/c{/Qsg_name/Q:/QSUPFERSUF_VDU1/Q/c/Qkpi/Q:/QcpuUsageVM/Q}/c{/Qsg_name/Q:/QSUPFERSUF_VDU2/Q/c/Qkpi/Q:/QcpuUsageVM/Q}";
```

```
%%DSP SCALEKPINE: KPILIST="{/Qsg_name/Q:/QSUPFEDID3_VDU1/Q/c/Qkpi/Q:/QcpuUsageVM/Q}/c{/Qsg_name/Q:/QSUPFEDID3_VDU2/Q/c/Qkpi/Q:/QcpuUsageVM/Q}/c{/Qsg_name/Q:/QSUPFERSUF_VDU1/Q/c/Qkpi/Q:/QcpuUsageVM/Q}/c{/Qsg_name/Q:/QSUPFERSUF_VDU2/Q/c/Qkpi/Q:/QcpuUsageVM/Q}";%%
RETCODE = 0 操作成功

操作结果如下
------------
资源组名       KPI指标名   请求的KPI指标值

SUPFEDID3_VDU1 cpuUsageVM  26
SUPFEDID3_VDU2 cpuUsageVM  24
SUPFERSUF_VDU1 cpuUsageVM  8
SUPFERSUF_VDU2 cpuUsageVM  9
(结果个数 = 4)

--- END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称     | 输出项解释                            |
|:----------|:---------------------------------|
| 资源组名      | VDU名称，用于表示弹性伸缩资源组名称。             |
| KPI指标名    | KPI名称，用于表示弹性伸缩指标名称。              |
| 请求的KPI指标值 | 弹性伸缩指标值，用于表示弹性伸缩指标汇总计算后所得KPI指标值。 |
