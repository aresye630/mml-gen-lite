# 查询测量结果文件(LST MEASRST)

- 命令功能
- 注意事项
- 参数说明
- 输出结果说明

#### 命令功能

通过LST MEASRST命令可获得网元上的测量结果文件，用于采集或者补采集网元上的测量结果文件。

#### 注意事项

无。

#### 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                         |
|:-------|:--------|:-------------------------------------------------------------------------------------------------------------|
| SDT    | 开始时间    | 可选必选说明：可选参数。 参数含义：查询起始时间。 取值范围：年月日时分秒，规则为YYYY/MM/DD HH:MM:SS。 默认值：无。 配置原则：若不输入，则表示该参数不作为查询的限制条件。             |
| PRD    | 周期      | 可选必选说明：可选参数。 参数含义：标识查询的周期。 取值范围： 0(全部)1(5分钟)2(15分钟)3(30分钟)4(1小时)5(一天) 默认值：0(全部)。 配置原则：若不输入，则表示该参数不作为查询的限制条件。 |
| NEID   | 网元ID    | 可选必选说明：必选参数。 参数含义：标识网元ID。 取值范围：0~65535。 默认值：无。 配置原则：无。                                                       |
| EDT    | 结束时间    | 可选必选说明：可选参数。 参数含义：查询结束时间。 取值范围：年月日时分秒，规则为YYYY/MM/DD HH:MM:SS。 默认值：无。 配置原则：若不输入，则表示该参数不作为查询的限制条件。             |
| ISULD  | 是否已上报网管 | 可选必选说明：可选参数。 参数含义：测量结果文件是否已上报网管。 取值范围： 0(未上报)1(已上报)2(全部) 默认值：2(全部)。 配置原则：若不输入，则使用默认值作为查询的限制条件。               |
| EMS    | 网管类型    | 可选必选说明：必选参数。 参数含义：网管类型。 取值范围：1-65535。 默认值：无。 配置原则：联系相应的网管运维人员获取网管类型。                                         |

#### 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，请联系华为技术支持处理。输出错误码说明如表1错误码列表所示。
