# 查看FE号码类型配置信息（LST FENUMTYPE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于在数据库中查询FE号码类型记录。

## 注意事项

无。

## 参数说明

| 参数ID       | 参数名称   | 参数描述                                                                     |
|:-----------|:-------|:-------------------------------------------------------------------------|
| FETYPENAME | FE类型名称 | FE类型的名字。 取值范围取决于USCDB网元中加载的FE类型。例如，USCDB网元中加载了SUP-FE的FE类型，则取值范围就是SUP-FE。 |

## 使用实例

查看SUP-FE中用户号码类型。

```
LST FENUMTYPE: FETYPENAME="SUP-FE";
```

```
%%LST FENUMTYPE: FETYPENAME="SUP-FE";%%
```
