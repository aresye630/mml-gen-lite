# 升级内存数据库（UPG IMDB）

## 命令功能

该命令为维护类命令，用于升级内存数据库。

## 注意事项

- 在升级时，升级框架会自动执行该命令。其他场景下严禁执行该命令。
- 在升级过程中，DSG模块故障时该命令无法执行。

## 参数说明

| 参数ID     | 参数名称   | 参数描述                                                                                                            |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------|
| PLANEID  | 平面ID   | 平面ID。标识需升级内存库的USCDB节点所在平面号。 取值范围：PLANE0：平面0。PLANE1：平面1。 默认值：无                                                   |
| APPTYPE1 | 业务类型1  | 需升级内存库的USCDB节点的业务类型，取决于加载的FE插件包。如果该USCDB网元是IMS-HSS、GU-HLR的融合网元，那么取值范围就是IMS-HSS和GU-HLR。 取值范围：长度不超过128的字符串。 默认值：无 |
| PKGNAME1 | 升级包名称1 | 与指定业务类型对应的升级包名。 取值范围：长度不超过128的字符串。 默认值：无                                                                        |

| PKGNAME2 | 升级包名称2 | 与指定业务类型对应的升级包名。 取值范围：长度不超过128的字符串。 默认值：无                                                                        |
| APPTYPE3 | 业务类型3  | 需升级内存库的USCDB节点的业务类型，取决于加载的FE插件包。如果该USCDB网元是IMS-HSS、GU-HLR的融合网元，那么取值范围就是IMS-HSS和GU-HLR。 取值范围：长度不超过128的字符串。 默认值：无 |
| PKGNAME3 | 升级包名称3 | 与指定业务类型对应的升级包名。 取值范围：长度不超过128的字符串。 默认值：无                                                                        |

| PKGNAME5 | 升级包名称5 | 与指定业务类型对应的升级包名。 取值范围：长度不超过128的字符串。 默认值：无                                                                        |

## 使用实例

```
UPG IMDB:PLANEID=PLANE0,APPTYPE1="SUP-FE";
```
