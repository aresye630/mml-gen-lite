# 修改Pod隔离状态（MOD SEGSTATEBYPOD）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，该操作将隔离业务处理模块，操作不当将导致负载不均、业务损失等严重问题。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该用命令用于将指定Pod上、指定模块类型的模块进行隔离。

## 注意事项

- 执行本命令隔离特定的DRU/DSU模块后，后续DSG模块将不再向隔离的DRU/DSU模块转发消息，系统总处理能力下降。如果系统剩余DRU/DSU模块已经满负荷运转，不能接管隔离的DRU/DSU模块的业务量，则会产生业务损失。
- 执行本命令进行隔离和解隔离操作后，操作可以通过执行**LST SEGSTATE**命令确认模块的隔离状态。
- 紧急排除故障的情况下执行本命令，需要华为技术工程师对操作方案进行评估，评估通过后方可实施。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                          |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------|
| SEGTYPE  | 隔离类型   | 可选必选说明：可选参数 参数含义：用于指定隔离类型。 取值范围： MIGRATESEG（迁移隔离） 默认值：无。 配置原则：如果不输入该参数，则系统默认取值为“MIGRATESEG（迁移隔离）”。            |
| MT       | 模块类型   | 可选必选说明：必选参数 参数含义：用于指定隔离的模块类型。 取值范围： DRU(DRU)DSU(DSU) 默认值：无。 配置原则：无。                                           |
| PODNAME  | Pod名称  | 可选必选说明：必选参数 参数含义：用于指定隔离的Pod名称。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                                              |
| SEGSTATE | 隔离状态   | 可选必选说明：必选参数 参数含义：用于指定隔离的状态。 取值范围： FALSE(非隔离)：对处于隔离状态的Pod设置为非隔离状态。TRUE(隔离)：对处于非隔离状态的Pod设置为隔离状态。 默认值：无。 配置原则：无。 |

## 使用实例

修改Pod隔离状态，“隔离类型”为“MIGRATESEG（迁移隔离）”，“模块类型”为“DSU(DSU)”，“Pod名称”为“usdid3aservice5-0”，“隔离状态”为“TRUE(隔离)”。

```
MOD SEGSTATEBYPOD:SEGTYPE=MIGRATESEG,MT=DSU,PODNAME="usdid3aservice5-0",SEGSTATE=TRUE;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 260008 | 参数未修改。请至少指定一个待修改的参数。 | 指定“Pod名称”和“模块类型”的“隔离状态”与实际的隔离状态一致。                                                                                 | 使用LST SEGSTATE命令查询模块的隔离状态后，重新执行该命令，确保指定“Pod名称”和“模块类型”的“隔离状态”与实际的隔离状态不一致。                                                                                        |
| 260685 | 指定隔离的Pod中不存在DSU或DRU。 | 指定的“Pod名称”中不存在DSU或DRU模块。                                                                                           | 使用LST MODULE命令查询模块的配置信息后，重新执行该命令，确保指定的“Pod名称”中存在DSU或DRU模块。                                                                                                      |
| 260345 | 隔离类型不允许修改。           | 可能原因如下： “隔离类型”为“故障隔离”、“隔离状态”为“非隔离”的模块被修改为“隔离类型”为“迁移隔离”、“隔离状态”为“非隔离”。“隔离类型”为“故障隔离”、“隔离状态”为“隔离”的模块被修改为“隔离类型”为“迁移隔离”。 | 使用LST SEGSTATE命令查询模块的隔离状态后，重新输入各参数取值，确保满足以下情况： “隔离类型”为“故障隔离”、“隔离状态”为“非隔离”的模块不允许被修改为“隔离类型”为“迁移隔离”、“隔离状态”为“非隔离”。“隔离类型”为“故障隔离”、“隔离状态”为“隔离”的模块不允许被修改为“隔离类型”为“迁移隔离”。 |
