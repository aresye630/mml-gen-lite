# 重启平面内的节点（RST PLGPLANE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于重启指定平面内的模块。在升级某一个平面时，会重启该平面的模块，从而更新进程文件以及配置，进行升级。

## 注意事项

该命令在升级时会自动调用，其他场景下无法使用。

## 参数说明

| 参数ID    | 参数名称   | 参数描述                                                                               |
|:--------|:-------|:-----------------------------------------------------------------------------------|
| PLNID   | 平面ID   | 用于标识平面ID。 取值范围：0～1。                                                                |
| VERTYPE | FE版本类型 | 用于标识FE版本类型。 取值范围：OLD(老版本)：表示重启与源版本信息不一致的节点，回退时使用。NEW(新版本)：表示重启与目标版本信息不一致的节点，升级时使用。 |

## 使用实例

```
RST PLGPLANE:PLNID=1,VERTYPE=OLD;
```

```
%%RST PLGPLANE:PLNID=1,VERTYPE=OLD;%%
RETCODE = 0  操作成功
---    END
```

## 输出结果说明

无。
