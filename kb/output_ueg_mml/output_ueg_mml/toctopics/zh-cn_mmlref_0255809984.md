# 修改Pod信息(MOD PODINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于修改Pod信息。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|:--------------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PODNAME       | Pod名称      | 用于指定需要修改相关属性的Pod名称，唯一标识一个Pod。操作员可以使用LST PODINFO查询获取。 取值范围：长度不超过128的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                          |
| PODLOC        | 节点名称       | 用于指定需要修改相关属性的节点名称。操作员可以使用LST PODINFO查询获取。 取值范围：长度不超过60的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                      |
| APPTYPE       | 应用类型       | 用于指定修改后的Pod是哪种应用类型。 取值范围：USDIU(USDIU)USDSU(USDSU)USDRU(USDRU)USDMU(USDMU)USDMU2(USDMU2) USDMU3(USDMU3)USDPU(USDPU)USDMD(USDMD)USDID(USDID)USDID3(USDID3)USRSU(USRSU)USCAG(USCAG)USPGW(USPGW)USPMU(USPMU)USPMU3(USPMU3)USPID3(USPID3)MNAHU(MNAHU)MNAHU3(MNAHU3)ENSIU(ENSIU)UAMU(UAMU)UMSU(UMSU)UMHU(UMHU)UTAU(UTAU)UPSU(UPSU)UBSF(UBSF)UAPU(UAPU)USISU(USISU)USRSUF(USRSUF)USRSUM(USRSUM)USRSUMF(USRSUMF)USPID(USPID)PAPPTYPE_TEST(PAPPTYPE_TEST) 默认值：无。 |
| BASE1MAC      | Base1平面MAC | 用于指定修改后的Pod的Base1的MAC地址信息。 取值范围：长度不超过60的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                     |
| BASE2MAC      | Base2平面MAC | 用于指定修改后的Pod的Base2的MAC地址信息。 取值范围：长度不超过60的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                     |
| BASE1IP       | BASE1 IP   | 用于指定修改后的Pod的BASE1的IP地址。 取值范围：无。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                  |
| BASE2IP       | BASE2 IP   | 用于指定修改后的POD的BASE2的IP地址。 取值范围：无。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                  |
| FABRIC1IP     | FABRIC1 IP | 用于指定修改后的Pod的FABRIC1的IP地址。 取值范围：无。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                |
| FABRIC2IP     | FABRIC2 IP | 用于指定修改后的Pod的FABRIC2的IP地址。 取值范围：无。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                |
| FABRIC3IP     | FABRIC3 IP | 用于指定修改后的Pod的FABRIC3的IP地址。 取值范围：无。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                |
| FABRIC4IP     | FABRIC4 IP | 用于指定修改后的Pod的FABRIC4的IP地址。 取值范围：无。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                |
| BASEPORTNUM   | BASE网口个数   | 用于指定修改后的Pod的BASE网口个数。 取值范围：1～4。 默认值：2。                                                                                                                                                                                                                                                                                                                                                                                                                  |
| FABRICPORTNUM | FABRIC网口个数 | 用于指定修改后的Pod的FABRIC网口个数。 取值范围：0~4。 默认值：2。                                                                                                                                                                                                                                                                                                                                                                                                                |
| SIGNALPORTNUM | 信令网口个数     | 用于指定修改后的Pod的信令网口个数。 取值范围：0~24。 默认值：0。                                                                                                                                                                                                                                                                                                                                                                                                                   |
| VNFID         | VNF ID     | 用于指定修改后的Pod在MANO侧的编号，唯一标识一个Pod所属的VNF域。 取值范围：长度不超过64的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                         |

## 使用实例

修改“Pod名称”为“VNF\_MSX\_0”的Pod，“Base1平面MAC”为“02:02:05:DE:09:F0”，“Base2平面MAC”为“02:02:05:DE:09:F1”：

`MOD PODINFO: PODNAME="VNF_MSX_0", BASE1MAC="02:02:05:DE:09:F0", BASE2MAC="02:02:05:DE:09:F1";`
