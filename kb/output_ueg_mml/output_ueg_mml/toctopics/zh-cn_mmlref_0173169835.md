# 设置插件包模式（SET PLUGMODE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置自动加载多个插件包中的某一个插件包的加载模式，且与**LOD FEPLUG**命令配合使用。

- 当**LOD FEPLUG**未输入加载模式时，加载模式由**SET PLUGMODE**命令设置：

  - 如果通过**SET PLUGMODE**设置了插件包加载类型，则按照指定模式加载。
  - 如果未通过**SET PLUGMODE**设置插件包加载类型，则按照SAT模式加载。
- 当**LOD FEPLUG**输入加载模式时，**SET PLUGMODE**设置的加载模式无效。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                             |
|:------------|:--------|:---------------------------------------------------------------------------------|
| PLUGNAMEPRE | 插件包名称前缀 | 用于描述FE插件包的名称前缀；通常取FE类型。例如“SUP-FE_PLUG_V900R008C02.tar”表示该插件包前缀为“SUP-FE”。         |
| LODMODE     | 插件包加载模式 | 用于描述插件包加载模式。 取值范围：SAT(单应用类型)：插件包加载后只呈现一个FE类型。MAT(多应用类型)：插件包加载后呈现多个FE类型。 默认值：SAT。 |

## 使用实例

在云模式下，设置FE插件包的加载模式。命令示例如下：

```
SET PLUGMODE: PLUGNAMEPRE="HSS9860", LODMODE=MAT;
```
