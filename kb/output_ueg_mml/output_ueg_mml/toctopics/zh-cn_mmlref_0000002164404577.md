# 设置版本信息（SET VERSIONINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为配置类命令，用于设置网元的基线版本号和补丁版本号。

## 注意事项

该命令在升级、打补丁或回退场景下会自动调用，其他场景下严禁使用。

## 参数说明

| 参数ID         | 参数名称   | 参数描述                                                              |
|:-------------|:-------|:------------------------------------------------------------------|
| BASEVERSION  | 基线版本号  | 可选必选说明：必选参数 参数含义：用于设置网元的基线版本号。 取值范围：长度不超过1024的字符串。 默认值：无。 配置原则：无。 |
| PATCHVERSION | 补丁版本号  | 可选必选说明：必选参数 参数含义：用于设置网元的补丁版本号。 取值范围：长度不超过1024的字符串。 默认值：无。 配置原则：无。 |

```
SET VERSIONINFO: BASEVERSION="V020R025C10", PATCHVERSION="V020R025C10SPC001";
```
