# 检查升级节点状态（CHK UPGNODE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于检查节点升级状态。

## 注意事项

该命令在升级时会自动调用，其他场景下严禁使用。

## 参数说明

| 参数ID      | 参数名称   | 参数描述                                                                                                                                              |
|:----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
| CHECKTYPE | 检查状态   | 检查状态。 取值范围：NORMAL：DRU/DSU节点状态为master或者slave状态时，检查成功。否则检查失败。LOADING：DRU/DSU节点状态为加载状态时，检查成功。否则检查失败。INACTIVE: DRU/DSU节点状态为未激活状态时，检查成功。否则检查失败。 默认值：无。 |
| LOADSTYLE | 加载状态   | 标识处于升级场景还是回退场景。 取值范围： UPGRADE：升级场景。ROLLBACK：回退场景。 默认值：无。                                                                                          |
| FETYPEN   | 网元类型   | 标识升级节点所属的FE网元类型，此参数在USCDB下唯一，通过LOD FEPLUG命令成功加载FE插件后在此引用。 取值范围：长度不超过128的字符串。 默认值：无。                                                               |

## 使用实例

```
CHK UPGNODE: CHECKTYPE=NORMAL;
```

```
%%CHK UPGNODE: CHECKTYPE=NORMAL;%%
RETCODE = 0  操作成功
---    END
```

该命令执行正常，会返回命令执行成功的提示信息。
