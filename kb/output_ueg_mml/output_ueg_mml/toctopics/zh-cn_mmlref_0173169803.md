# 查询云部署测量对象信息（LST CLOUDOBJ）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查看USCDB网元下的云部署性能测量对象信息。该命令供网管使用。

## 注意事项

无。

## 参数说明

无。

## 使用实例

```
LST CLOUDOBJ:;
```

```
%%LST CLOUDOBJ:;%%
RETCODE = 0  操作成功

操作结果如下
------------
测量对象ID     FE类型     Partition/Region标识    云部署类型     用户数据类型
1              53                6                Partition      User Data
2              53                7                Partition      User Data
(结果个数 = 2)

---    END
```

## 输出结果说明

| 输出项名称              | 输出项解释                 |
|:-------------------|:----------------------|
| 测量对象ID             | 用于标识测量对象ID。           |
| FE类型               | 用于标识FE类型。             |
| Partition/Region标识 | 用于标识Partition/Region。 |
| 云部署类型              | 用于标识云部署类型。            |
| 用户数据类型             | 用于标识用户数据类型。           |
