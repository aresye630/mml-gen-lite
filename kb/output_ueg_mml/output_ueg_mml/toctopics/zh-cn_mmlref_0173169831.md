# 检查内存库升级约束（CHK IMDBUPGCONS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于检查内存库和数据字典的字段顺序是否一致。

## 注意事项

该命令在升级时会执行，其他场景下严禁执行该命令。

## 参数说明

| 参数ID     | 参数名称   | 参数描述                                         |
|:---------|:-------|:---------------------------------------------|
| FETYPEID | FE类型ID | 用于标识FE类型ID。 取值范围：1～1023。                     |
| CHKTYPE  | 检查类型   | 用于标识检查类型。LOW：低版本。HIGH：高版本。LOWTOHIGH：低版本到高版本。 |

## 使用实例

```
CHK IMDBUPGCONS:FETYPEID=53,CHKTYPE=LOW;
```

```
%%CHK IMDBUPGCONS:FETYPEID=53,CHKTYPE=LOW;%%
RETCODE = 0  操作成功
---    END

操作结果如下
------------
 模块标识   FE类型ID  数据类型                检查结果

 61        53       Route data             Consistent
 86        53       User data              Consistent

(结果个数 = 2)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                             |
|:--------|:------------------------------------------------------------------|
| 模块标识    | 用于标识模块号。                                                          |
| FE类型ID  | 用于标识FE类型ID。                                                       |
| 数据类型    | 用于标识数据类型。                                                         |
| 检查结果    | 用于标识检查结果。 取值范围：NULL：无效返回码。Consistent：检查结果一致。Inconsistent：检查结果不一致。 |
