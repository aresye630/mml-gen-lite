# 获取审计日志文件（GET LOGFILE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于获取审计日志文件，审计日志包含操作日志、安全日志、系统日志。

审计日志文件也可在OM Portal界面“安全>日志审计”导出获取。

## 注意事项

该命令最多支持导出10万条记录。

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                                                   |
|:---------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------|
| SDT      | 开始时间    | 可选必选说明：可选参数。 参数含义：日志收集起始时间。 取值范围：1990/01/01 00:00:00-2037/12/31 23:59:59。 默认值：无。 配置原则：无。                                               |
| EDT      | 结束时间    | 可选必选说明：可选参数。 参数含义：收集日志结束时间。 数据来源：用户输入。 取值范围：1990/01/01 00:00:00-2037/12/31 23:59:59。 默认值：无。 配置原则：无。                                    |
| IP       | 服务器IP   | 可选必选说明：必选参数。 参数含义：SFTP服务器IP地址。 取值范围：长度不超过100个字符串。 默认值：无。 配置原则：无。                                                                       |
| USR      | 用户名     | 可选必选说明：必选参数。 参数含义：SFTP用户名，从对端获取。 取值范围：长度不超过32的字符串。 默认值：无。 配置原则：无。                                                                      |
| PWD      | 密码      | 可选必选说明：必选参数。 参数含义：SFTP用户密码，从对端获取。 取值范围：长度不超过128的密码。 默认值：无。 配置原则：无。                                                                     |
| DSTF     | 服务端文件路径 | 可选必选说明：必选参数。 参数含义：用于标识SFTP传输的目标路径（含文件名）。 取值范围：长度不超过256的字符串。 默认值：无。 配置原则：文件名不能为点（.）或点点（..）；不能包含如下特殊字符：* : ? " < > | ' ` ! $ # & ( )和空格。 |
| LT       | 日志类型    | 可选必选说明：必选参数。 参数含义：标识收集日志的类型。 取值范围： OPERATING_LOG(操作日志) SECURITY_LOG(安全日志) SYSTEM_LOG(系统日志) 默认值：无。 配置原则：无。                              |
| MEID     | 网元ID    | 可选必选说明：可选参数。 参数含义：标识收集的网元ID。可以通过执行LST ME命令获取。 取值范围：整数类型，取值范围为0~65535。 默认值：无。 配置原则：无。                                                   |
| RSVFILE  | 是否保留文件  | 可选必选说明：可选参数。 参数含义：标识是否保留文件。目前无作用。 取值范围： NO(否) YES(是) 默认值：NO（否）。 配置原则：无。                                                                |
| FILETYPE | 文件类型    | 可选必选说明：可选参数。 参数含义：标识输出的文件类型。 取值范围： XML(XML) CSV(CSV) 默认值：无，如果不输入该参数，系统按照缺省值XML导出。 配置原则：无。                                              |
| LAN      | 日志语言    | 可选必选说明：可选参数。 参数含义：标识输出的日志语言。 取值范围： ZH(中文) EN(英文) 默认值：EN(英文)。 配置原则：无。                                                                   |
| PORT     | 端口      | 可选必选说明：可选参数。 参数含义：SFTP服务器端口。 取值范围：整数类型，取值范围为1~65535。 默认值：22。 配置原则：与实际服务器上sftp服务启动指定端口号一致。                                              |
| MODE     | 内容格式    | 可选必选说明：当“FILETYPE”取值为“XML”时，该参数为条件可选。 参数含义：XML文件内容的格式。 取值范围： NORMAL(普通) STANDARD(标准) 默认值：NORMAL(普通) 。 配置原则：无。                          |
