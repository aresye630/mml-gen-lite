# 校验各模块的平面信息是否正确（CHK PLGPLANE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于校验模块的平面信息。在执行完成**DEF PLGPLANE**之后，升级框架会校验各模块平面信息是否正确，从而保证升级的正确性。

## 注意事项

该命令在升级时会自动调用，其他场景下无法使用。

## 参数说明

无。

## 使用实例

```
CHK PLGPLANE:;
```

```
%%CHK PLGPLANE:;%%
RETCODE = 0  操作成功
---    END
```

## 输出结果说明

无。
