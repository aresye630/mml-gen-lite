# 设置升级参数（SET UPGINSP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为配置类命令，用于在配置数据库中增加升级参数信息。

## 注意事项

该命令在升级时会自动调用，其他场景下严禁使用。

## 参数说明

| 参数ID   | 参数名称   | 参数描述                                                                  |
|:-------|:-------|:----------------------------------------------------------------------|
| UPGMOD | 升级模式   | 升级模式。 取值范围：VER(版本升级)：版本升级FEPLUG(插件包升级)：插件包升级CPATCH(冷补丁)：冷补丁升级。 默认值：无。 |

## 使用实例

设置升级模式为插件包升级。

```
SET UPGINSP: UPGMOD=FEPLUG;
```

```
%%SET UPGINSP: UPGMOD=FEPLUG;%%
RETCODE = 0  操作成功
```
