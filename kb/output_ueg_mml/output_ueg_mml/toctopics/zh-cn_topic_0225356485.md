# 增加测量对象(ADD MEASOBJ)

- 命令功能
- 注意事项
- 参数说明
- 输出结果说明

#### 命令功能

通过ADD MEASOBJ命令来请求网元增加非缺省测量对象的统计，网元完成指令的合法性检查后性能统计会在紧接着的下个统计周期生效。

#### 注意事项

无。

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                              |
|:----------|:---------|:------------------------------------------------------------------|
| MOCID     | 测量对象类ID  | 可选必选说明：必选参数。 参数含义：标识测量对象类ID。 取值范围：0~2147483646的整数。 默认值：无。 配置原则：无。 |
| NEID      | 网元ID     | 可选必选说明：必选参数。 参数含义：标识网元ID。 取值范围：0~1023的整数。 默认值：无。 配置原则：无。          |
| MOIIDNAME | 测量对象实例名称 | 可选必选说明：可选参数。 参数含义：标识测量对象实例名称。 取值范围：长度不超过256的字符串。 默认值：无。 配置原则：无。   |
| MOIID     | 对象实例ID   | 可选必选说明：必选参数。 参数含义：标识对象实例ID。 取值范围：长度不超过256的字符串。 默认值：无。 配置原则：无。     |
| EMS       | 网管类型     | 可选必选说明：必选参数。 参数含义：网管类型。 取值范围：1-65535。 默认值：无。 配置原则：无。              |

#### 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，请联系华为技术支持处理。输出错误码说明如表1错误码列表所示。

|    错误码 | 错误码解释           | 原因分析                  | 处理建议                 |
|-------:|:----------------|:----------------------|:---------------------|
| 650007 | 命令解析失败          | 请求消息错误。               | 请联系华为技术支持。           |
| 650104 | 激活测量对象失败        | 网元ID或测量对象类ID不正确。      | 请确认网元ID或测量对象类ID是否正确。 |
| 650116 | 网元加载中           | 加载过程中可能存在网络故障，出现此种情况。 | 等待几分钟，重试执行。          |
| 650114 | MOI超过最大上限       | 测量对象个数超过限制。           | 删除部分测量对象后重试。         |
| 650117 | 网元测量指标量已超限      | 网元测量指标量已超限。           | 删除部分测量对象后重试。         |
| 650118 | 网元CGP子任务数已超限    | 网元CGP子任务数已超限。         | 删除部分CGP测量对象后重试。      |
| 650119 | 网元CGP话务类子任务数已超限 | 网元CGP话务类子任务数已超限。      | 关闭部分CGP话务类测量任务后重试。   |
