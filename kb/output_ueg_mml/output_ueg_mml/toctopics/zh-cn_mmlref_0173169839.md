# 激活或去激活指定平面的pgw模块（SET PGWMODSTAT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于激活或去激活指定平面的PGW模块或所有PGW。在对某平面执行升级或者打补丁过程中，去激活该平面的PGW模块，保证消息通过另一个平面的PGW模块接入，避免呼损。在升级或补丁操作完成之后，激活该平面的PGW模块，继续提供业务。

## 注意事项

该命令在升级或补丁操作时会自动调用，其他场景下使用无效。

## 参数说明

| 参数ID    | 参数名称   | 参数描述                                                          |
|:--------|:-------|:--------------------------------------------------------------|
| PLNID   | 平面ID   | 用于标识平面ID。 取值范围：0～1。                                           |
| SETTYPE | 操作类型   | 用于标识操作类型。 取值范围：ACTIVE：激活PGW节点。DEACTIVE：去激活PGW节点。RESTART：重启节点。 |
| UPGMOD  | 升级模式   | 用于标识升级模式。 取值范围：VER：版本升级。FEPLUG：插件包升级。CPATCH：冷补丁。              |

## 使用实例

```
SET PGWMODSTAT:PLNID=1,SETTYPE=DEACTIVE,UPGMOD=FEPLUG;
```

```
%%SET PGWMODSTAT:PLNID=1,SETTYPE=DEACTIVE,UPGMOD=FEPLUG;%%
RETCODE = 0  操作成功
---    END
```
