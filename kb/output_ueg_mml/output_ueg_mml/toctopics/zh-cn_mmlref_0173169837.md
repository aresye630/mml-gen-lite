# 添加VDU模块（ADD VDUMODULE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于云模式下，在导入VNFD文件进行自动部署的时候为Pod添加模块。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                               |
|:--------|:--------|:-------------------------------------------------------------------------------------------------------------------|
| VDUNAME | VDU名称   | 该参数用于定义模块添加到哪个VDU上面。VDU名称的命名规则为：Pod类型名_FE类型名_VDU_主备编号。                                                             |
| VMNAME1 | 主用Pod名称 | 用于描述主用Pod名称。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：该参数的值域范围为：大写字母“A～Z”、小写字母“a～z”、数字“0～9”、特殊字符“-”、“_”。该参数必须以字母开头。该参数区分大小写。 |
| VMNAME2 | 备用Pod名称 | 用于描述备用Pod名称。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：该参数的值域范围为：大写字母“A～Z”、小写字母“a～z”、数字“0～9”、特殊字符“-”、“_”。该参数必须以字母开头。该参数区分大小写。 |

## 使用实例

在云模式下，使用该命令往Pod上添加模块。命令示例如下：

```
ADD VDUMODULE:VDUNAME="USPID3_HSS9860_VDU_1",VMNAME1="BE94_HSSDID3_VDU1_0",VMNAME2="BE94_HSSDID3_VDU2_0";
```
