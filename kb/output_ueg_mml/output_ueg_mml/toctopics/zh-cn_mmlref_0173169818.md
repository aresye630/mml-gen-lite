# 查询云部署营帐测量对象信息（LST CPROVSTATOBJ）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查看USCDB网元下的云部署营帐测量对象信息。该命令供网管使用。

## 注意事项

无。

## 参数说明

| 参数ID        | 参数名称        | 参数说明             |
|:------------|:------------|:-----------------|
| PMID        | PM标识        | 用于表示PM标识。        |
| PARTITIONID | Partition标识 | 用于表示Partition标识。 |
| SERVICETYPE | 业务类型        | 用于标识业务类型。        |

## 使用实例

```
LST CPROVSTATOBJ:;
```

```
%%LST CPROVSTATOBJ:;%%
RETCODE = 0  操作成功

操作结果如下
------------
 PM标识     Partition标识    业务类型    
 6001       1                SUP-FE
 6000       1                SUP-FE
(结果个数 = 2)

---    END
```

|:------------|:-----------------|

| Partition标识 | 用于表示Partition标识。 |
| 业务类型        | 用于标识业务类型。        |
