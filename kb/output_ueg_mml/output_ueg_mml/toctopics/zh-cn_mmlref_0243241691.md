# 查询网元版本和信息(LST ME)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

LST ME命令，用于查询网元版本和信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                                        |
|:-------|:----------|:--------------------------------------------------------------------------------------------|
| MEID   | 网元ID      | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个网元ID来查询网元对象实例的配置信息。                                           |
| DMID   | 域标识       | 可选必选说明：可选参数， 该参数仅在Soap通道使用；在MML通道不使用，MML配置文件中无该参数。 参数含义：用于唯一标识一个域。                          |
| SNID   | 子网标识      | 可选必选说明：可选参数， 该参数仅在Soap通道使用；在MML通道不使用，MML配置文件中无该参数。 参数含义：用于唯一标识一个域下的子网。                      |
| MENAME | 网元名称      | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照网元名称来查询网元对象实例的配置信息。                                             |
| METYPE | 网元类型      | 可选必选说明：可选参数， 该参数仅在Soap通道使用；在MML通道不使用，MML配置文件中无该参数。 参数含义：用于指示系统需要按照网元类型询网元对象实例的配置信息。         |
| MEVER  | 网元版本      | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照网元版本来查询网元对象实例的配置信息。                                             |
| MEVD   | 网元制造商名称   | 可选必选说明：可选参数， 该参数仅在Soap通道使用；在MML通道不使用，MML配置文件中无该参数。 参数含义：用于指示系统需要按照网元制造商名称来查询网元对象实例的配置信息。    |
| MEUDS  | 网元自定义状态   | 可选必选说明：可选参数， 该参数仅在Soap通道使用；在MML通道不使用，MML配置文件中无该参数。 参数含义：用于指示系统需要按照网元自定义状态来查询网元对象实例的配置信息。    |
| MELN   | 网元本地名称    | 可选必选说明：可选参数， 该参数仅在Soap通道使用；在MML通道不使用，MML配置文件中无该参数。 参数含义：用于指示系统需要按照网元的本地名称来查询网元对象实例的配置信息。    |
| MELS   | 网元锁定状态    | 可选必选说明：可选参数， 该参数仅在Soap通道使用；在MML通道不使用，MML配置文件中无该参数。 参数含义：用于指示系统需要按照网元锁定状态来查询网元对象实例的配置信息。     |
| MECC   | 网元国家（地区）码 | 可选必选说明：可选参数， 该参数仅在Soap通道使用；在MML通道不使用，MML配置文件中无该参数。 参数含义：用于指示系统需要按照网元的国家（地区）码来查询网元对象实例的配置信息。 |
| MEIID  | 网元接口ID    | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照网元接口ID来查询网元对象实例的配置信息。                                           |
| MELAN  | 网元语言      | 可选必选说明：可选参数， 该参数仅在Soap通道使用；在MML通道不使用，MML配置文件中无该参数。 参数含义：用于指示系统需要按照哪个网元语言来查询网元对象实例的配置信息。     |
