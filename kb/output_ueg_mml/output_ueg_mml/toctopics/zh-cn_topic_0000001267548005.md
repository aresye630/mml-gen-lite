# 获取硬件数据（GET HARDWAREDATA）

- 命令功能
- 注意事项
- 参数说明

#### 命令功能

本命令用于网管侧获取硬件收集数据。

#### 注意事项

GET HARDWAREDATA是机机命令，由网管下发执行。

#### 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                         |
|:-------|:----------|:-----------------------------------------------------------------------------|
| IP     | 服务器IP     | 可选必选说明：必选参数 参数含义：sftp服务服务端IP。 取值范围：长度不超过100的字符串。                             |
| USR    | 用户名       | 可选必选说明：必选参数 参数含义：sftp服务账户。 取值范围：长度不超过32的字符串。                                 |
| PWD    | 密码        | 可选必选说明：必选参数 参数含义：sftp服务密码。 取值范围：长度不超过128的字符串。                                |
| DSTF   | 服务端文件目录路径 | 可选必选说明：必选参数 参数含义：文件上传路径。 取值范围：长度不超过256的字符串。                                  |
| TYPE   | 数据类型      | 可选必选说明：必选参数 参数含义：收集数据类型。 取值范围： HARDWARELOG(日志)：硬件日志收集HARDWAREINFO(信息)：硬件信息收集 |
