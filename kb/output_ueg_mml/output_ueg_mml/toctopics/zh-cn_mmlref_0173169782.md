# 回退内存数据库（RBK IMDB）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于回退内存数据库。

## 注意事项

- 在升级时，升级框架会自动执行该命令。其他场景下严禁执行该命令。
- 在升级过程中，DSG模块故障时该命令无法执行。

## 参数说明

| 参数ID     | 参数名称   | 参数描述                                                         |
|:---------|:-------|:-------------------------------------------------------------|
| APPTYPE1 | 业务类型1  | 业务类型，取值范围依赖于加载的FE插件。例如加载的FE插件类型为GU-HLR，那么取值范围就是GU-HLR和USCDB。 |

## 使用实例

```
RBK IMDB:APPTYPE1="SUP-FE";
```

```
%%RBK IMDB:APPTYPE1="SUP-FE";%%
RETCODE = 0  操作成功
```
