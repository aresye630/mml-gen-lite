# 记录SQN动态同步日志（SND DYNSQNSYNC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

#### 命令功能

该命令用于记录SQN动态同步日志。

割接场景下，UDM本地保存SQN异常，连续鉴权重同步后，可以触发从HSS动态获取SQN。

#### 注意事项

该命令为系统自动触发，无法手动执行。

#### 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                             |
|:-------|:--------|:-------------------------------------------------------------------------------------------------|
| IMSI   | 用户IMSI  | 可选必选说明：必选参数 参数含义：用于记录触发SQN动态同步的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                          |
| MID    | 模块号     | 可选必选说明：必选参数 参数含义：用于记录触发SQN动态同步的CCU模块号。 取值范围：1～1023。 默认值：无。                                       |
| OLDSQN | 旧SQN    | 可选必选说明：条件必选参数 参数含义：用于记录触发SQN动态同步的旧SQN。当“SQN同步状态”参数取值为“SUCCESS”时本参数必选。 取值范围：长度为12的十六进制字符串。 默认值：无。 |
| NEWSQ  | 新SQN    | 可选必选说明：条件必选参数 参数含义：用于记录触发SQN动态同步的新SQN。当“SQN同步状态”参数取值为“SUCCESS”时本参数必选。 取值范围：长度为12的十六进制字符串。 默认值：无。 |
| STATES | SQN同步状态 | 可选必选说明：必选参数 参数含义：用于记录触发SQN动态同步的状态。 取值范围：SUCCESS FAILURE 默认值：无。                                   |
