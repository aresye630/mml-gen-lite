# 记录消息重发日志（RSEND MSG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

#### 命令功能

该命令用于在触发消息重发流程时记录空口日志。

#### 注意事项

该命令为系统自动触发，无法手动执行。

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                       |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| MSGTYPE  | 消息类型   | 参数含义：用于记录主动下发消息的类型。 取值范围： Cancel：CS、PS的cancel消息ISD：CS、PS的插入用户数据消息DSD：CS、PS的删除用户数据消息CLR：EPC的cancel消息IDR：EPC的下发用户数据消息UDCD：MAP的ADD通知消息 默认值：无。 |
| KEY      | 序列号    | 参数含义：用于标识记录重发消息的序列号。 取值范围：长度不超过64位的字符串。 默认值：无。                                                                                             |
| MID      | 模块号    | 参数含义：用于标识记录重发消息的CCU模块号。 取值范围：长度不超过64位的字符串。 默认值：无。                                                                                          |
| PEERTYPE | 对端类型   | 参数含义：用于标识对端网元的对端类型。 取值范围： ADDVLRSGSNMMES4SGSN 默认值：无。                                                                                       |
| PEERADD  | 对端地址   | 参数含义：用于记录重发消息发送的对端设备地址。 取值范围：长度不超过64位的字符串。 默认值：无。                                                                                          |
| SKEY     | 用户SID  | 参数含义：用于记录用户的SID。 取值范围：16位十六进制数字组成的字符串。 默认值：无。                                                                                              |

#### 使用实例

无。
