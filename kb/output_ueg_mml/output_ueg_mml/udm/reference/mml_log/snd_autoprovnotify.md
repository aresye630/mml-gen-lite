# 记录自动开户日志（SND AUTOPROVNOTIFY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

#### 命令功能

该命令用于在触发自动开户业务流程时记录空口日志。

该命令不能在业务窗口上执行，是在FE触发自动开户后，BE的PGW模块向业务发放系统发送5G自动开户通知消息，业务发放系统向BE返回响应消息后，FE向BE发送该空口日志记录的命令。

#### 注意事项

该命令为系统自动触发，无法手动执行。

#### 参数说明

| 参数标识         | 参数名称         | 参数说明                                                                                                                                                                   |
|:-------------|:-------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SRVCC        | SRVCC功能      | 参数含义：用于标识UDM记录的5G自动开户用户终端是否支持SRVCC功能。 取值范围： TRUE：支持FALSE：不支持 默认值：无。                                                                                                    |
| AUTOPROVTYPE | 5G自动开户用户开户方式 | 参数含义：用于标识UDM记录的5G自动开户用户的开户方式。 取值范围：1：记录的是通过MOD NGCAUTOIMSI命令的“是否启用5G自动开户特性”参数配置为“4G-5G”时的开户日志。2：记录的是通过MOD NGCAUTOIMSI命令的“是否启用5G自动开户特性”参数配置为“4G_VoLTE-5G”时的开户日志。 默认值：无。 |
| IMPI         | IMPI         | 用于标识用户的IMPI。 取值范围：长度不超过127的字符串 默认值：无。                                                                                                                                  |
| MID          | SF实例号        | 参数含义：用于标识CSP服务管理中的SF实例号。可通过DSP UDMSERVICE命令查询获得。 取值范围：长度不超过65位的字符串。 默认值：无。                                                                                             |
| SKEY         | 用户SID        | 参数含义：仅当用户在5G自动开户之前是在非本地UDM上开户的场景下使用。用于记录用户的SID。可通过LST SIDIMSI命令查询获得。 取值范围：16位十六进制数字组成的字符串。 默认值：无。                                                                      |

#### 使用实例

无。
