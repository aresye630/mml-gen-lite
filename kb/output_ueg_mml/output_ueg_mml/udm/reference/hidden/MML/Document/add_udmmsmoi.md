# 增加UDM微服务进程测量对象(ADD UDMMSMOI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加UDM微服务进程测量对象。

该命令的使用场景：

- 由于性能指标在网管侧按微服务进程呈现，所以需要通过配置UDM微服务进程测量对象向网管同步对象信息。
- HttpDisCtrlService微服务订阅其它服务的上下线通知，负责管理微服务进程测量对象。在服务上线时增加测量对象，服务下线时候删除测量对象。

## 注意事项

UDM微服务进程测量对象为系统自动识别，即微服务上线后，且状态为Ready的状态时，自动添加一条该上线服务的数据，不需要手工执行。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                           |
|:--------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ST      | 服务类型   | 可选必选说明：必选参数 参数含义：用于标识待增加测量对象所属的服务类型。 取值范围： UdmAppCtrlService(UdmAppCtrlService)NRFClient(NRFClient)HttpDisCtrlService(HttpDisCtrlService)UdmSubService(UdmSubService)UdmAuthService(UdmAuthService)UdmTcpService(UdmTcpService)UdmHttpService(UdmHttpService)UdmAlbService(UdmAlbService)EnumService(EnumService) 默认值：无 配置原则：无 |
| NODEID  | 节点ID   | 可选必选说明：必选参数 参数含义：用于标识待增加测量对象所属的节点ID。 取值范围：长度不超过128位的字符串。 默认值：无 配置原则：无。                                                                                                                                                                                                                                                         |
| PODNAME | POD名称  | 可选必选说明：必选参数 参数含义：用于标识POD名称。 取值范围：长度不超过128位的字符串。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                   |
| INSID   | 服务实例ID | 可选必选说明：必选参数 参数含义：用于标识待增加测量对象的服务实例号。 取值范围：长度不超过64位的字符串。 默认值：无 配置原则：该参数值可以通过执行DSP UDMSERVICE命令获取，对应参数名称为“SF实例号”。                                                                                                                                                                                                                 |

## 使用实例

增加“服务类型”为“UdmTcpService”，“节点ID”为“172.19.239.71”，“POD名称”为“hlb-a-pod439-6f95f7cbf4-k47v7”，“服务实例ID”为“11663530850187870750”的微服务进程测量对象：

```
ADD UDMMSMOI: ST=UdmTcpService, NODEID="172.19.239.71", PODNAME="hlb-a-pod439-6f95f7cbf4-k47v7", INSID="11663530850187870750";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
