# 增加HLB链路话统对象实例(ADD UDMHTTPLNKMOI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于增加UdmHttpService或UdmTcpService服务链路负荷统计对象实例。用于创建网管测量UDM HTTP2链路指标和TCP链路指标的对象实例。

## 注意事项

该命令在UDM初始配置完成后，由系统自动调用。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                    |
|:-----------|:-------|:--------------------------------------------------------------------------------------------------------|
| INSID      | 服务实例ID | 可选必选说明：必选参数 参数含义：用于标识待增加的服务实例号。该参数值可以通过执行DSP UDMSERVICE命令获取，对应参数名称为“HLB实例ID”。 取值范围：长度不超过36位的字符串。 默认值：无。 |
| SERVERNAME | 服务名称   | 可选必选说明：必选参数 参数含义：用于标识待增加实例所属的服务名称为UdmHttpService或UdmTcpService。 取值范围：长度不超过36位的字符串。 默认值：无。               |

## 使用实例

```
新增“服务实例ID”为“13564655801154191991”，“服务名称”为“UdmHttpService”的服务链路负荷统计对象实例：
```

```
ADD UDMHTTPLNKMOI: INSID="13564655801154191991", SERVERNAME="UdmHttpService";
```

## 输出结果说明

该命令执行异常，会返回对应的错误码。常见错误码如下表1所示。

|    错误码 | 消息解释   | 原因分析              | 处理建议                                                   |
|-------:|:-------|:------------------|:-------------------------------------------------------|
| 360041 | 参数值不合法 | 输入的“服务实例ID”参数不合法。 | 根据实际情况，请重新输入该参数值，确保输入的参数符合取值范围。                        |
| 360042 | 参数值已存在 | 输入的“服务实例ID”参数已存在。 | 请执行LST UDMHTTPLNKMOI命令查询已存在的“服务实例ID”，重新输入该参数值后再次执行本命令。 |
