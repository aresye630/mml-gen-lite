# 删除ESN特征信息(RMV MSESNFEATURE)

- 命令功能
- 注意事项
- 参数说明

## 命令功能

该命令用于删除一条ESN特征信息数据记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                   |
|:-------|:-------|:-----------------------------------------------------------------------|
| INDEX  | INDEX  | 可选必选说明：必选参数。 参数含义：用于标识待删除的ESN特征信息索引。 取值范围：0～4294967295。 默认值：无。 配置原则：无。 |
