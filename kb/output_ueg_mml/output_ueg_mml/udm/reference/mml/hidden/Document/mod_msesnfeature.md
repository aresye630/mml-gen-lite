# 修改ESN特征信息(MOD MSESNFEATURE)

- 命令功能
- 注意事项
- 参数说明

## 命令功能

该命令用于修改一条ESN特征信息数据记录。

## 注意事项

无。

## 参数说明

| 参数标识         | 参数名称         | 参数说明                                                                   |
|:-------------|:-------------|:-----------------------------------------------------------------------|
| INDEX        | INDEX        | 可选必选说明：必选参数。 参数含义：用于标识待修改的ESN特征信息索引。 取值范围：0～4294967295。 默认值：无。 配置原则：无。 |
| IPINFO       | IPINFO       | 可选必选说明：可选参数。 参数含义：用于标识生成ESN的IP地址材料。 取值范围：长度不超过577的字符串。 默认值：无。 配置原则：无。  |
| HOSTNAMEINFO | HOSTNAMEINFO | 可选必选说明：可选参数。 参数含义：用于标识生成ESN的主机名材料。 取值范围：长度不超过577的字符串。 默认值：无。 配置原则：无。   |
| GTINFO       | GTINFO       | 可选必选说明：可选参数。 参数含义：用于标识生成ESN的GT材料。 取值范围：长度不超过577的字符串。 默认值：无。 配置原则：无。    |
| FLAG         | FLAG         | 可选必选说明：可选参数。 参数含义：用于标识ESN特征信息标识符。 取值范围： 0：即将失效。1：正在生效。 默认值：无。 配置原则：无。  |
| DATE         | DATE         | 可选必选说明：可选参数。 参数含义：用于标识数据记录的修改时间。 取值范围：长度不超过32的字符串。 默认值：无。 配置原则：无。      |
