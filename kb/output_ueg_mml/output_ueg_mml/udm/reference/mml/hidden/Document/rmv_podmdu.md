# 删除POD模块配置(RMV PODMDU)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除Pod模块配置，是提供给CSM自动部署时删除业务网元下指定Pod上所有模块配置的内部命令接口。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                       |
|:--------|:-------|:-------------------------------------------|
| PODNAME | Pod名称  | 用于指定需要删除所有模块的Pod名称。操作员可以使用LST PODINFO查询获取。 |

## 使用实例

删除“Pod名称”为“UDM\_01”的Pod上所有模块配置：

```
RMV PODMDU: PODNAME="UDM_01";
```
