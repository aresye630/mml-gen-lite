# 修改SCTP四元组的配置(MOD SCTPCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令仅用于适应网管上创建SCTP消息测量任务。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                            |
|:-------|:----------|:------------------------------------------------|
| ID     | SCTP四元组序号 | SCTP四元组序号，该参数为专家维护参数。 取值范围：0～4294967295。 默认值：无。 |

## 使用实例

修改SCTP四元组配置：

MOD SCTPCFG:ID=1;
