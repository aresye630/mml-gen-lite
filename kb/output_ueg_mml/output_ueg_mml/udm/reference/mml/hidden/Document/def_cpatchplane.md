# 定义冷补丁平面(DEF CPATCHPLANE)

## 命令功能

该命令为维护类命令，用于设置待执行补丁操作网元的补丁平面。

网元打补丁时为了减少业务中断，会执行该命令将网元的所有进程划分成两部分，这两个部分称为双平面，分别为0平面和1平面。打补丁过程中先让0平面成为主平面，1平面成为备平面，先操作备平面，然后对平面进行倒换，再操作新备平面。

## 注意事项

该命令在网元打补丁时会自动执行，其他场景下严禁使用。

## 参数说明

无。

## 使用实例

设置网元的补丁平面。

`DEF CPATCHPLANE:;`

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
