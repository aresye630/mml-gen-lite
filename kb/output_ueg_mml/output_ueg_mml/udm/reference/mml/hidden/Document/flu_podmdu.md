# 刷新POD模块配置（FLU PODMDU）

- 命令功能
- 注意事项

- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于刷新POD模块数量，是提供给升级过程中自动刷新指定POD上CCU模块数量的内部命令接口。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                         |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------|
| PODNAME1 | Pod名称  | 可选必选说明：可选参数。 参数含义：用于指定需要刷新模块数量的POD名称。 数据来源：全网规划。 取值范围：字符串类型，输入长度范围为0~128。 默认值：无。 配置原则：本参数可以从LST PODINFO查询获取。 |
| PODTYPE  | Pod类型  | 可选必选说明：必选参数。 参数含义：用于指定需要刷新的Pod类型。 数据来源：全网规划。 取值范围：UCCU_A(UCCU_A)。 默认值：无。 配置原则：无。                             |
| MT       | 模块类型   | 可选必选说明：必选参数。 参数含义：用于指定需要刷新的模块类型。 数据来源：全网规划。 取值范围：CCU(CCU) 默认值：无。 配置原则：无。                                     |
| MDUNUM   | 模块数量   | 可选必选说明：必选参数。 参数含义：用于指定刷新后的模块数量。 数据来源：全网规划。 取值范围：0~8。 默认值：无。 配置原则：无。                                          |

## 使用实例

刷新“Pod名称”为“uccu-pod411-0”的Pod上CCU模块个数为5：

```
FLU PODMDU: PODNAME1="uccu-pod411-0", PODTYPE=UCCU_A, MT=CCU, MDUNUM=5;
```

## 输出结果说明

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释        | 原因分析                       | 处理建议                         |
|-------:|:-------------|:---------------------------|:-----------------------------|
| 336027 | 删除控制CCU模块失败。 | 控制CCU不允许直接删除，必须先修改控制CCU模块。 | 使用MOD CTRLCENTER命令修改控制CCU模块。 |
| 260183 | 记录不存在        | 不存在POD名称或者PODTYPE对应的记录     | 输入正确的POD名称和PODTYPE。          |
