# 修改License话务高峰信息(MOD LICPEAK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于对一条License话务高峰信息数据记录的某些参数进行修改。在该命令中，系统通过以下关键参数的组合来唯一标识一条License话务高峰信息：

- “License控制项”
- “年份”
- “日期”

#### 注意事项

无。

#### 参数说明

| 参数标识         | 参数名称           | 参数说明                                                                                                                                                                                                                                                                                                    |
|:-------------|:---------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LICITEM      | License控制项     | 可选必选说明：必选参数 参数含义：用于指定License控制项名称。 取值范围：AUSF_Basic_TPS 默认值：无。 配置原则：无。                                                                                                                                                                                                                                   |
| PEAKYEAR     | 年份             | 可选必选说明：必选参数 参数含义：用于指定License控制项信息存储的年份，区分新数据还是旧数据。 取值范围： THIS_YEAR：存储年份为今年，是新数据。LAST_YEAR：存储年份为去年，是旧数据。 默认值：无。 配置原则：无。                                                                                                                                                                                  |
| PEAKDATE     | 日期             | 可选必选说明：必选参数 参数含义：用于指定License控制项数据为具体的某天的数据。 取值范围：无。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                      |
| PEAKTPS      | 峰值TPS          | 可选必选说明：可选参数 参数含义：用于指定当前环境对应日期的最大TPS峰值。 取值范围：0~2147483647 默认值：无。 配置原则：无。                                                                                                                                                                                                                                 |
| PEAKTIMES    | 过载次数           | 可选必选说明：可选参数 参数含义：用于指定License控制项的过载次数。DCS定期5分钟（整5分钟时刻，比如0分、5分等）检测当前使用的TPS License控制项使用值与授权的TPS License控制项授权值的百分比是否达到过载告警门限，如果达到则上报“ALM-18802 TPS License超过过载阈值告警”，过载次数+1。 取值范围：0~2147483647 默认值：无。 配置原则：无。                                                                                               |
| LICUSEDPEAKS | License已使用高峰次数 | 可选必选说明：可选参数 参数含义：用于指定License已使用高峰次数。当发生license过载时，不管当天（每日0点～24点）出现了几次，都计为1个过载天数。连续过载天数达到“单次AUSF TPS高峰最少连续过载天数”时，“每年内最大AUSF TPS高峰次数”License已使用高峰次数+1，可用的话务高峰天数-1。 记录一次峰值后，最少连续过载天数重置为0，重新开始计数。比如“单次AUSF TPS高峰最少连续过载天数”为3，当连续3天出现过载时记为一次高峰，并重置最少连续过载天数为0。当第4天也出现过载时，记录连续过载天数为1。 取值范围：0~255 默认值：无。 配置原则：无。 |

#### 使用实例

假如需要修改一条“License控制项” 为“AUSF\_Basic\_TPS”，“年份” 为“THIS\_YEAR”，“日期”为“2019-10-31”的License话务高峰信息，将“峰值TPS”改为“300”，“过载次数”为“1352”。

```
MOD LICPEAK: LICITEM=AUSF_Basic_TPS, PEAKYEAR=LAST_YEAR, PEAKDATE=2019&10&31, PEAKTPS=300, PEAKTIMES=1352, LICUSEDPEAKS=0;
```

#### 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释      | 原因分析                                             | 处理建议                                                  |
|-------:|:----------|:-------------------------------------------------|:------------------------------------------------------|
| 100016 | 参数不在指定范围内 | 输入的参数值不在取值范围内。                                   | 根据各参数的取值范围，重新输入参数的取值，确保其取值符合要求。                       |
| 100015 | 参数的值无效    | 输入的参数“License控制项”、“年份”、“日期”、“峰值TPS”或“过载次数”格式不正确。 | 根据实际情况，重新输入正确格式的参数值。例如：“日期”格式为“XXXX-XX-XX”，确保其取值符合要求。 |
