# 设置DSG自动回切（SET AUTOSWITCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令为维护类命令，用于设置DSG的自动回切开关。

## 注意事项

该命令在升级或补丁时会自动执行，其他场景下严禁使用。

## 参数说明

| 参数标识            | 参数名称      | 参数说明                                                                                                                                                                    |
|:----------------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AUTOSWITCHVALUE | DSG自动回切开关 | 用于设置当前系统的DSG是否支持容灾业务倒换。 取值范围：0：主用局BE故障情况下，FE业务会自动切换到容灾BE。主用局BE恢复情况下，系统不会自动切回。1：主用局BE故障情况下，FE业务会自动切换到容灾BE。主用局BE恢复情况下，系统自动切回。2：主用局BE故障情况下，FE业务不会自动切换到容灾BE。 默认值：无 说明：必选参数。 |
| SERVICETYPE     | 业务类型      | UDM的DSG模块不支持配置多种业务类型，此参数暂不启用。                                                                                                                                           |

## 使用实例

设置DSG自动回切开关取值为2。

```
SET AUTOSWITCH: AUTOSWITCHVALUE=2;
```
