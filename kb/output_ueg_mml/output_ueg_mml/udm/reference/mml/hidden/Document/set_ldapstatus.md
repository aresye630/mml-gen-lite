# 设置模块状态（SET LDAPSTATUS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于设置指定平面上同一类型的所有模块状态。

## 注意事项

该命令在升级时会自动执行，其他场景下严禁使用。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                   |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------|
| PLNID   | 平面ID   | 用于标识系统设置哪个平面的模块状态。 取值范围：0～1。 默认值：无。 说明：必选参数。                                                                                           |
| MT      | 模块类型   | 用于标识系统设置哪种模块类型的模块状态。 取值范围： DPU(DPU)DSG(DSG)BSG(BSG)CCU(CCU)PAU(PAU)HSF(HSF)NSF(NSF)ACF(ACF)APF(APF)ERU(ERU)：该模块类型为预留值。 默认值：无。 说明：必选参数。 |
| SETTYPE | 模块状态   | 用于标识系统设置模块为哪种状态。 取值范围： ACTIVE(ACTIVE)INACTIVE(INACTIVE) 默认值：无。 说明：必选参数。                                                                |

## 使用实例

设置0平面的DSG模块为激活状态。

`SET LDAPSTATUS: PLNID=0, MT=DSG, SETTYPE=ACTIVE;`

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
