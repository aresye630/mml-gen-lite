# 增加AppID信息(ADD APPIDINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

融合数据场景下为简化服务类型，每个产品定义一个统一的appctrl，负责网元内服务间通信策略以及CSLB策略下发。

该命令用于新增一条微服务实例对应的App信息。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称        | 参数说明                                                                       |
|:--------|:------------|:---------------------------------------------------------------------------|
| APPID   | App ID      | 可选必选说明：必选参数 参数含义：用于指定UDM某一服务实例的App ID，该参数全局唯一。 取值范围：1~65535 默认值：无。 配置原则：无。 |
| APPTYPE | App Type    | 可选必选说明：可选参数 参数含义：用于指定该APP的类型。 取值范围：1~65535 默认值：无。 配置原则：无。                  |
| INSTID  | Instance ID | 可选必选说明：可选参数 参数含义：用于指定UDM中各微服务的实例ID。 取值范围：长度不超过20位的字符串 默认值：无。 配置原则：无。       |

## 使用实例

增加一条AppID信息，“App ID”为“32000”，“App Type”为“3006”，“Instance ID”为“13579981867965655234”。

```
ADD APPIDINFO: APPID=32000, APPTYPE=3006, INSTID="13579981867965655234";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
