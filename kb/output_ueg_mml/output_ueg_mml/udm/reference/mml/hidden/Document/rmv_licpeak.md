# 删除License话务高峰信息(RMV LICPEAK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于删除License话务高峰信息数据。CSP OM表中的License话务高峰信息记录保存2年，在每年1月1日凌晨0点需删除2年前的记录。

#### 注意事项

无。

#### 参数说明

| 参数标识     | 参数名称       | 参数说明                                                                                                                   |
|:---------|:-----------|:-----------------------------------------------------------------------------------------------------------------------|
| LICITEM  | License控制项 | 可选必选说明：必选参数 参数含义：用于指定License控制项名称。 取值范围：AUSF_Basic_TPS 默认值：无。 配置原则：无。                                                  |
| PEAKYEAR | 年份         | 可选必选说明：必选参数 参数含义：用于指定License控制项信息存储的年份，区分新数据还是旧数据。 取值范围： THIS_YEAR：存储年份为今年，是新数据。LAST_YEAR：存储年份为去年，是旧数据。 默认值：无。 配置原则：无。 |
| PEAKDATE | 日期         | 可选必选说明：必选参数 参数含义：用于指定License控制项数据为具体的某天的数据。 取值范围：无。 默认值：无。 配置原则：无。                                                     |

#### 使用实例

假如需要删除一条“License控制项” 为“AUSF\_Basic\_TPS”，“年份” 为“THIS\_YEAR”，“日期”为“2019-11-01”的License话务高峰信息。

```
RMV LICPEAK: LICITEM=AUSF_Basic_TPS, PEAKYEAR=THIS_YEAR, PEAKDATE=2019&11&01;
```

#### 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 100015 | 参数的值无效       | 输入的参数“License控制项”、“年份”、“日期”、“峰值TPS”或“过载次数”格式不正确。 | 根据实际情况，重新输入正确格式的参数值。例如：“日期”格式为“XXXX-XX-XX”，确保其取值符合要求。 |
