# 修改POD模块配置(MOD PODMDU)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改Pod模块配置，是提供给CSM自动部署时调整Pod模块配置的内部命令接口。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|:--------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PODNAME | Pod名称  | 用于指定需要修改的Pod名称，唯一标识一个Pod。操作员可以使用LST PODINFO查询获取。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：该参数的值域范围为：大写字母“A～Z”、小写字母“a～z”、数字“0～9”、特殊字符“-”、“_”。该参数必须以字母开头。该参数区分大小写。                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| PODTYPE | Pod类型  | 用于指定修改后的Pod的类型（不同的Pod类型对应不同的模块信息）。 取值范围： UCCU(UCCU)：表示修改后Pod的类型是UCCU。UISU(UISU)：表示修改后Pod的类型是UISU。UFEUS(UFEUS)：表示修改后Pod的类型是UFEUS。UCCU_A(UCCU_A)：表示修改后Pod的类型是UCCU_A。UCCU_I(UCCU_I)：表示修改后Pod的类型是UCCU_I。UCCU_L1(UCCU_L1)：表示修改后Pod的类型是UCCU_L1。UISU_L1(UISU_L1)：表示修改后Pod的类型是UISU_L1。UFUNC(UFUNC)：表示修改后Pod的类型是UFUNC。UERU(UERU)：表示修改后Pod的类型是UERU。UFEUE(UFEUE)：表示修改后Pod的类型是UFEUE。UENS-NP(UENS-NP)：表示修改后Pod的类型是UENS-NP。UISU_B(UISU_B)：表示修改后Pod的类型是UISU_B。UAAA-E(UAAA-E)：表示修改后Pod的类型是UAAA-E。UAAA(UAAA)：表示修改后Pod的类型是UAAA。UGBA(UGBA)：表示修改后Pod的类型是UGBA。UBSF(UBSF) ：表示修改后Pod的类型是UBSF。UAP(UAP)：表示修改后Pod的类型是UAP。 默认值：无。 |

## 使用实例

修改“Pod名称”为“UDM\_01”的Pod的模块配置信息为“Pod类型”为“UCCU(UCCU)”时对应的Pod模块配置：

```
MOD PODMDU: PODNAME="UDM_01", PODTYPE=UCCU;
```
