# 删除Tcp Mss配置（RMV TCPMSS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

**须知** 

本命令属于高危命令，删除配置后会影响对应APN下传输的TCP报文长度。

该命令用于关闭基于用户归属属性指定APN的TCP MSS调整功能并删除TCP MSS配置。

#### 注意事项

- 该命令执行后立即生效。
- 删除某个APN实例时，会同步删除它的MSS配置。
- 删除配置后，可能导致该APN下的终端和Server协商的TCPMSS过大，造成传输过程中分片报文过多。配置后不建议删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                 |
|:------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN         | APN名称  | 可选必选说明：必选参数 参数含义：该参数用于表示APN的名字。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。 默认值：无 配置原则：无                                                                                                  |
| ROAMINGTYPE | 用户漫游类型 | 可选必选说明：可选参数 参数含义：该参数用于配置用户归属的属性。 数据来源：本端规划 取值范围：位域类型。 HOME：表示本地用户。ROAMING：表示漫游用户。VISITING：表示拜访用户。 默认值：无 配置原则： SELECT ALL：表示HOME，ROAMING，VISITING 3种类型都选择。CLEAR ALL：表示HOME，ROAMING，VISITING 3种类型都不选择。GREYED ALL：表示HOME，ROAMING，VISITING 3种类型都置灰，都不选择，并保持参数的原始值。当选择参数类型后，参数类型后的-1代表使能这个参数，-0代表不使能这个参数。 |

#### 使用实例

关闭apn apn1.com漫游用户的TCP MSS调整功能：

```
RMV TCPMSS: APN="apn1.com", ROAMINGTYPE=ROAMING-1;
```
