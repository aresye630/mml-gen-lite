#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询URL过滤功能业务模式。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询内容过滤本地缓存参数：

```
LST CFSRVMODE:;
```

