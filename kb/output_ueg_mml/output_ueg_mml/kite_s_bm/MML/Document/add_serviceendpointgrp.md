# 添加服务端点组（ADD SERVICEENDPOINTGRP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

该命令用于添加服务端点组信息。一个服务端点组可以包含多个服务端点，服务端点指服务对外提供的访问入口信息。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1000。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                             |
|:----------|:--------|:-----------------------------------------------------------------------------------------------------------------|
| GROUPNAME | 服务端点组名称 | 可选必选说明：必选参数 参数含义：该参数用于指定服务端点组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“.”组成，且只能以字母或者数字开头。 默认值：无 配置原则：无 |

#### 使用实例

添加SERVICEENDPOINTGRP对象，添加的SERVICEENDPOINTGRP对象名称为"service\_endpoint\_grp"：

```
ADD SERVICEENDPOINTGRP: GROUPNAME="service_endpoint_grp";
```
