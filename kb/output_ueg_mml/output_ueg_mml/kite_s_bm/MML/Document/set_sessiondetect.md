# 设置用户检测开关（SET SESSIONDETECT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

设置用户检测开关。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 系统最多支持每个POD选择1000个用户作为检测用户。
- 当检测开关由开变为关时，检测用户信息不进行保留，检测用户变为非检测用户；当检测开关由关变为开时，立即选定检测用户。
- 故障倒换场景下，选定的检测用户可能会变为非检测用户。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | SWITCH   |   TIME |
|:-------|:---------|-------:|
| 初始值    | DISABLE  |      2 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                           |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------|
| SWITCH | 用户检测开关 | 可选必选说明：必选参数 参数含义：该参数用于指定用户检测开关。 数据来源：本端规划 取值范围： DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无                                            |
| TIME   | 带宽检测周期 | 可选必选说明：条件可选参数 前提条件：该参数在“SWITCH”配置为“ENABLE”时为可选参数。 参数含义：带宽检测周期。 数据来源：本端规划 取值范围：整数类型，取值范围为1～10，单位是分钟。 默认值：无 配置原则：参数默认值为参数的初始设置值。 |

#### 使用实例

配置开启检测用户开关，带宽检测周期配置为2：

```
SET SESSIONDETECT: SWITCH=ENABLE;
```
