# 查询L2TP隧道的相关信息（DSP L2TPTUNNEL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查看L2TP隧道相关的信息。运营商可以分别根据APN名字、接口名字等信息查询L2TP的隧道信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                                                    |
|:--------------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------|
| SHOWTYPE      | 查询方式    | 可选必选说明：必选参数 参数含义：该参数用于指定查询方式。 数据来源：本端规划 取值范围：枚举类型。 INTERFACE：表示根据Gi接口名字查询隧道信息。APN：表示根据APN名字查询隧道信息。 默认值：无 配置原则：无                         |
| INTERFACENAME | 接口名称    | 可选必选说明：条件必选参数 前提条件：该参数在“SHOWTYPE”配置为“INTERFACE”时为必选参数。 参数含义：该参数用于指定查询的Gi接口名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无            |
| TUNNELID      | L2TP隧道号 | 可选必选说明：条件可选参数 前提条件：该参数在“SHOWTYPE”配置为“INTERFACE”时为可选参数。 参数含义：该参数用于指定查询的L2TP隧道号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～64000。 默认值：无 配置原则：无           |
| APN           | APN实例名称 | 可选必选说明：条件必选参数 前提条件：该参数在“SHOWTYPE”配置为“APN”时为必选参数。 参数含义：该参数用于表示APN实例名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格以及特殊字符：_、#、$等。 默认值：无 配置原则：无 |

#### 使用实例

运营商如果需要查看giif1/0/0接口下，ID为1的隧道的信息：

```
DSP L2TPTUNNEL: SHOWTYPE=INTERFACE,INTERFACENAME="giif1/0/0",TUNNELID=1;
```

#### 输出结果说明

| 输出项名称        | 输出项解释                |
|:-------------|:---------------------|
| APN实例名称      | 用于表示APN实例名字。         |
| 对端名称         | 用于表示远端LNS的名称。        |
| L2TP组号       | 用于表示隧道所属的L2TP组号。     |
| 本端隧道ID       | 用于表示本端的隧道号。          |
| 对端隧道ID       | 用于表示远端LNS的隧道号。       |
| 对端端口号        | 用于表示远端LNS的端口号。       |
| 会话数          | 用于表示隧道相关的会话数。        |
| Giif接口名称     | 用于表示隧道绑定的Giif接口名称。   |
| 创建时长         | 用于表示隧道已建立的时长。        |
| 发送窗口大小       | 发送窗口大小。              |
| IP类型         | 用于指定IP地址类型。          |
| Giif接口IPv4地址 | 用于表示隧道绑定的Giif接口IP地址。 |
| Giif接口IPv6地址 | 用于隧道绑定的Giif接口IPv6地址。 |
| 对端IPv4地址     | 用于表示远端LNS的IPv4地址。    |
| 对端IPv6地址     | 用于表示远端LNS的IPv6地址。    |
