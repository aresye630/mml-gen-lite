# 查询VNRS链路（DSP VNRSLINK）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询到VNRS的链路信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                           |
|:-----------|:-------|:-----------------------------------------------------------------------------------------------|
| RUNAME     | RU名称   | 可选必选说明：可选参数 参数含义：该参数用于指定RU的名称，通过LST SERVICERUSTATE获得。 数据来源：本端规划 默认值：无 取值范围：0 ~ 63位字符串          |
| PROCTYPE   | 进程类型   | 可选必选说明：可选参数 参数含义：该参数用于指定进程类型。 数据来源：本端规划 默认值：无 取值范围：“PROC_TYPE_MNCP(PROC_MNCP) ”                |
| PROCNO     | 进程号    | 可选必选说明：可选参数 参数含义：该参数用于指定进程号。 数据来源：本端规划 默认值：无 取值范围：0~63                                         |
| LINKINDEX  | 链路索引   | 可选必选说明：可选参数 参数含义：该参数用于表示链路索引。 数据来源：本端规划 默认值：无 取值范围：0~127                                       |
| LINKSTATUS | 链路状态   | 可选必选说明：可选参数 参数含义：该参数用于表示链路状态。 数据来源：本端规划 默认值：无 取值范围：“LINK NOTCONNECTED(未连接) ”“LINK NORMAL(正常) ” |

`DSP VNRSLINK:;`
