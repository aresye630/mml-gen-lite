# 设置NSH头增强功能开关（SET APNNSHHEADENFUNC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于设置NSH头增强功能开关。

#### 注意事项

- 该命令执行后，开关值修改为关，对新数据流生效；开关值修改为开，对用户激活或更新后的新数据流生效。
- 系统最多支持配置10000条。
- 初始值均为DISABLE。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                 |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN    | APN    | 可选必选说明：必选参数 参数含义：该参数用于指定APN名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。 默认值：无 配置原则：该参数使用ADD APN命令配置生成。 |
| SWITCH | 功能开关   | 可选必选说明：必选参数 参数含义：该参数用于配置指定APN的NSH头增强功能开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能（关闭）。ENABLE：使能（开启）。 默认值：无 配置原则：无                                                                                                           |

#### 使用实例

为了开启APN NSH头增强功能，设置APN为apn的NSH头增强功能开关为ENABLE：

```
SET APNNSHHEADENFUNC: APN="apn", SWITCH=ENABLE;
```
