# 删除IKE提议（RMV IKEPROPOSAL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

删除IKE提议，影响业务流量使用IPSEC进行加解密功能，有业务影响。

该命令用于删除IKE安全提议配置。

## 注意事项

- 该命令执行后立即生效。

- 当IKE安全提议被IKE对等体配置时，IKE安全提议不能被删除。如果需要删除IKE安全提议，必须先删除安全IKE对等体中的配置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                           |
|:---------------|:-------|:-----------------------------------------------------------------------------------------------|
| PROPOSALNUMBER | 安全提议号  | 可选必选说明：必选参数  参数含义：提议编号。  数据来源：本端规划  取值范围：整数类型，取值范围是1~4294967295。101不支持配置，但可以查询。  默认值：无  配置原则：无 |

## 使用实例

删除IKE安全提议号为1的IKE安全提议：

```
RMV IKEPROPOSAL:PROPOSALNUMBER=1;
```
