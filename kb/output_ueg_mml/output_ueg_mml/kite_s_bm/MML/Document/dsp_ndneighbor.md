# 显示IPv6 ND邻居表项（DSP NDNEIGHBOR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示ND表项。

不指定参数时，查询设备上所有ND表项信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                         |
|:------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------|
| QUERYCOND   | 查询条件   | 可选必选说明：可选参数 参数含义：该参数用于指定ND邻居表项查询条件。 数据来源：本端规划 取值范围：枚举类型。 IPV6ADDRESS：IPv6地址。VRFNAME：VPN名称。IFNAME：接口名称。 默认值：无                                 |
| IPV6ADDRESS | IPv6地址 | 可选必选说明：条件必选参数 前提条件：该参数在“QUERYCOND”配置为“IPV6ADDRESS”时为必选参数。 参数含义：该参数用于显示IPv6地址。 数据来源：全网规划 取值范围：IPv6地址类型。 默认值：无                                 |
| VRFNAME     | VPN名称  | 可选必选说明：条件必选参数 前提条件：该参数在“QUERYCOND”配置为“VRFNAME”时为必选参数。 参数含义：该参数用于显示VPN名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                             |
| IFNAME      | 接口名    | 可选必选说明：条件必选参数 前提条件：该参数在“QUERYCOND”配置为“IFNAME”时为必选参数。 参数含义：该参数用于显示接口名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。 |

#### 使用实例

显示ND表项：

```
DSP NDNEIGHBOR:QUERYCOND=IFNAME,IFNAME="Ethernet65/0/8";
```

```
RETCODE = 0  操作成功。
```
