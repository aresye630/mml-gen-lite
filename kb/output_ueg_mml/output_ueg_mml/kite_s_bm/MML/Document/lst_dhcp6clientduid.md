# 查询DHCPv6客户端DUID生成方式（LST DHCP6CLIENTDUID）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询DHCPv6客户端的DUID生成方式。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询当前DHCPv6客户端的DUID生成方式：

```
LST DHCP6CLIENTDUID:;
```

```
RETCODE = 0  操作成功

结果如下
------------------------
DUID生成方式  =  链路地址加虚拟局域网标识号模式
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见SET DHCP6CLIENTDUID的参数说明。
