# 增加多框级联配置（ADD NPDIRECTCONNECTPORT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，仅适用于NP多框场景或者NP单框改造成NP多框场景，错误配置可能会造成业务流量损失，请谨慎使用并联系华为技术支持协助操作。

该命令用于新增一条多框级联配置。

## 注意事项

- 该命令执行后立即生效。

- 该命令仅适用于NP卡加速模式场景，并且该命令在非省交换场景下不能执行。
- 该命令在NP卡名称（通过DSP NPNODE查询）为NP121时不生效。
- 该命令不适用于单框场景。执行该命令后，对应的外联口会变成级联口，请谨慎使用。
- 通过MOD INTERFACE命令操作级联口，可能导致ALM-139591683 接口状态down误告警，需要手动清除。

- 最多可输入100条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                          |
|:--------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------|
| SUBRACK | 框号     | 可选必选说明：必选参数  参数含义：该参数用于表示多框级联配置的框号。  数据来源：本端规划 取值范围： Subrack_0（0）Subrack_1（1）Subrack_2（2）  默认值：无  配置原则：无                                      |
| SLOTID  | 槽位号    | 可选必选说明：必选参数  参数含义：该参数用于表示多框级联配置的槽位号。  数据来源：本端规划 取值范围： Slot_1（1）Slot_2（2）Slot_3（3）Slot_4（4）Slot_5（5）Slot_6（6）Slot_7（7）Slot_8（8）  默认值：无  配置原则：无 |
| PORTID  | 端口号    | 可选必选说明：必选参数  参数含义：该参数用于表示多框级联配置的端口号。  数据来源：本端规划 取值范围： P1（P1）P2（P2）P3（P3）P4（P4）  默认值：无  配置原则：无                                                 |

## 使用实例

新增一条框号为0，槽号为1，端口号为P1的级联口配置：

```
ADD NPDIRECTCONNECTPORT: SUBRACK=Subrack_0, SLOTID=Slot_1, PORTID=P1;
```
