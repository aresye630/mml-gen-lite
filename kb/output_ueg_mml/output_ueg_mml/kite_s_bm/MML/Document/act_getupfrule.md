# 获取UPF规则配置（ACT GETUPFRULE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于触发向指定UPF查询特定类型的规则请求。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                          |
|:---------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UPFNAME  | UPF名称  | 可选必选说明：必选参数 参数含义：UPF名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：可以通过LST UPFINFO查出对接的UPF名称。                                                                                                                                                                               |
| RULENAME | 规则名称   | 可选必选说明：必选参数 参数含义：指定规则名称。 数据来源：本端规划 取值范围：枚举类型。 DYN_DNS_RULE：查询动态DNS规则信息。TRAFFIC_RULE：查询流规则的信息。DNS_REDIRECT_RULE：查询DNS重定向规则的信息。ACL_RULE：查询ACL规则信息。BW_ALLOCATION_RULE：查询带宽分配规则的信息。 默认值：无 配置原则：无                                                                                  |
| APPNAME  | 应用名称   | 可选必选说明：必选参数 参数含义：指定应用名称，可以通过DSP APPLICATIONINFO查出所有的应用名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无                                                                                                                                                                      |
| RULEID   | 规则ID   | 可选必选说明：条件可选参数 前提条件：该参数在“RULENAME”配置为“BW_ALLOCATION_RULE”、“DNS_REDIRECT_RULE”、“DYN_DNS_RULE” 或 “TRAFFIC_RULE”时为可选参数。 参数含义：对端UPF上指定规则ID。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～95。 默认值：无 配置原则：可以在对端的UPF上通过DSP TRAFFICRULE, DSP DNSRULE, DSP BWALLOCATION, DSP DNSREDIRECTRULE查出指定的规则ID。 |

#### 使用实例

向MPF对接的指定UPF查询指定的规则信息：

```
ACT GETUPFRULE: UPFNAME="upfnameinfo", RULENAME=BW_ALLOCATION_RULE, APPNAME="test", RULEID="test";
```
