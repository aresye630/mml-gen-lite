# 删除IMSI和MSISDN号段组（RMV UPIMSIMSISDNG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用来删除IMSI/MSISDN号码段组，删除号段组的同时，该号段组下所有的号段绑定关系同步删除。

#### 注意事项

- 该命令执行后立即生效。
- 可以解除该IMSI/MSISDN号码段组与一个IMSI/MSISDN号码段的绑定关系，也可以解除该IMSI/MSISDN号码段组下所有IMSI/MSISDN号码段的绑定信息并删除该IMSI/MSISDN号码段组。如果此IMSI/MSISDN号码段组被绑定，则不允许删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称             | 参数说明                                                                                                                                       |
|:-------------|:-----------------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| SEGGROUPNAME | IMSI/MSISDN号段组名称 | 可选必选说明：可选参数 参数含义：该参数用于指定IMSI/MSISDN号码段组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无                                     |
| SEGMENTNAME  | IMSI/MSISDN号段名称  | 可选必选说明：可选参数 参数含义：该参数用于指定IMSI/MSISDN号码段名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：如果指定SEGMENTNAME参数，必须先指定SEGGROUPNAME参数。 |

#### 使用实例

删除IMSI/MSISDN号码段组，其中IMSI/MSISDN号段组名称为huawei：

```
RMV UPIMSIMSISDNG:SEGGROUPNAME="huawei";
```
