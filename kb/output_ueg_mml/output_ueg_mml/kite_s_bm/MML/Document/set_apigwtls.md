# 设置API GW TLS配置（SET APIGWTLS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

**须知** 

本命令属于高危命令，执行该命令后，API GW server端支持的TLS版本会发生变更，请谨慎修改。

该命令用于设置是否使能API GW服务端对TLSv1.2和TLSv1.3的支持。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 为避免安全问题，设置TLS v1.2和TLS v1.3均为不使能时，MML将执行失败。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | TLSV12   | TLSV13   |
|:-------|:---------|:---------|
| 初始值    | ENABLE   | ENABLE   |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                |
|:-------|:---------|:--------------------------------------------------------------------------------------------------------------------|
| TLSV12 | TLS v1.2 | 可选必选说明：必选参数 参数含义：API GW server端是否使能TLSv 1.2。 数据来源：本端规划 取值范围：枚举类型。 ENABLE：TLSv1.2使能。DISABLE：TLSv1.2不使能。 默认值：无 配置原则：无 |
| TLSV13 | TLS v1.3 | 可选必选说明：必选参数 参数含义：API GW server端是否使能TLSv 1.3。 数据来源：本端规划 取值范围：枚举类型。 ENABLE：TLSv1.3使能。DISABLE：TLSv1.3不使能。 默认值：无 配置原则：无 |

#### 使用实例

设置API GW server端TLS版本：

```
SET APIGWTLS: TLSV12=ENABLE, TLSV13=ENABLE;
```
