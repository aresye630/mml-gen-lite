# 创建IPsec提议（ADD IPSECPROPOSAL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于创建IP安全提议。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为100。
- 该命令中的一些配置可能是不安全的。
- 认证算法中md5和sha1都是不安全的，建议使用sha2\_256算法。
- 加密算法中3des和des都是不安全的，建议使用aes\_256算法。
- 当认证和加密算法选择null或unconfigure时，存在安全风险。
- AH认证算法不能为空，当选择unconfigure时，下发默认值。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称       | 参数说明                                                                                                                                                                                                                                                               |
|:---------------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROPOSALNAME   | Proposal名称 | 可选必选说明：必选参数 参数含义：Proposal名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～15。不区分大小写。 默认值：无                                                                                                                                                                                        |
| IPSECPROTOCOL  | IPsec安全协议  | 可选必选说明：可选参数 参数含义：IPsec协议：AH / ESP。 数据来源：对端协商 取值范围：枚举类型。 ah：AH协议。esp：ESP协议。 默认值：esp                                                                                                                                                                                 |
| ESPAUTHALGO    | ESP认证算法    | 可选必选说明：条件可选参数 前提条件：该参数在“IPSECPROTOCOL”配置为“esp”时为可选参数。 参数含义：ESP认证算法：MD5 / SHA1 / SHA2-256 / SHA2-384 / SHA2-512 / NULL。 数据来源：对端协商 取值范围：枚举类型。 md5：md5算法。sha1：sha1算法。sha2_256：sha2-256算法。sha2_384：sha2-384算法。sha2_512：sha2-512算法。null：空。unconfigure：未配置。 默认值：sha2_256 |
| ESPENCRYPTALGO | ESP加密算法    | 可选必选说明：条件可选参数 前提条件：该参数在“IPSECPROTOCOL”配置为“esp”时为可选参数。 参数含义：加密算法：DES / 3DES / AES-128 / AES-192 / AES-256。 数据来源：对端协商 取值范围：枚举类型。 3des：3DES算法。des：DES算法。aes_128：128位AES算法。aes_192：192位AES算法。aes_256：256位AES算法。null：空。unconfigure：未配置。 默认值：aes_256                     |
| AHAUTHALGO     | AH认证算法     | 可选必选说明：条件可选参数 前提条件：该参数在“IPSECPROTOCOL”配置为“ah”时为可选参数。 参数含义：认证算法：MD5 / SHA1 / SHA2-256 / SHA2-384 / SHA2-512。 数据来源：对端协商 取值范围：枚举类型。 md5：md5算法。sha1：sha1算法。sha2_256：sha2-256算法。sha2_384：sha2-384算法。sha2_512：sha2-512算法。unconfigure：未配置。 默认值：sha2_256                   |
| ENCAPMODE      | 封装模式       | 可选必选说明：可选参数 参数含义：封装模式。 数据来源：对端协商 取值范围：枚举类型。 transport：传输模式。 默认值：transport                                                                                                                                                                                          |

#### 使用实例

增加名称为“asdf2”的IP安全提议：

```
ADD IPSECPROPOSAL:PROPOSALNAME="asdf2",IPSECPROTOCOL=ah,AHAUTHALGO=sha2_256,ENCAPMODE=transport;
```
