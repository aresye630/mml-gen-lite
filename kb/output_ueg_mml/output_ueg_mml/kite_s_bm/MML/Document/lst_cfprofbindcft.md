# 查询内容过滤策略绑定关系（LST CFPROFBINDCFT）

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于显示内容过滤模板中绑定的内容过滤策略。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                   |
|:---------------|:---------|:-----------------------------------------------------------------------------------------------------------------------|
| CFTEMPLATENAME | 内容过滤模板名称 | 可选必选说明：可选参数 参数含义：该参数用于设置内容过滤模板名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD CFTEMPLATE命令配置生成。 |
| CFPROFILENAME  | 内容过滤策略名称 | 可选必选说明：可选参数 参数含义：该参数用于设置内容过滤策略名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD CFPROFILE命令配置生成。  |

#### 使用实例

显示内容过滤模板中绑定的内容过滤策略：

```
LST CFPROFBINDCFT:;
```
