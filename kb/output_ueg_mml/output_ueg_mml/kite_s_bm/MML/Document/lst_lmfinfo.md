# 查询LMF信息（LST LMFINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询LMF信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询LMF信息：

```
LST LMFINFO:;
```

```
RETCODE = 0  操作成功

LMF信息
---------------
LMF标识  =  123
(结果个数  = 1)

---    END
```
