# 增加分类属性（ADD CATEGORYPROP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于配置带宽控制属性，用户进行带宽控制时，通过CATEPROPNAME匹配到相应的带宽控制策略，以完成带宽控制功能，用于关联预定义规则中的过滤条件进行ADC检测上报。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为500。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                        |
|:--------------|:-------|:--------------------------------------------------------------------------------------------|
| CATEPROPNAME  | 分类属性名称 | 可选必选说明：必选参数 参数含义：该参数用于设置分类属性名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |
| CFGDOMAINNAME | 配置域名称  | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无          |

#### 使用实例

配置带宽控制属性：CATEPROPNAME为test：

```
ADD CATEGORYPROP:CATEPROPNAME="test";
```
