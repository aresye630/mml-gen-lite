# 添加UPF信息（ADD UPFINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于添加当前MPF对接的UPF配置信息。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为32。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称       | 参数说明                                                                                                                                                                |
|:-------------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UPFNAME      | UPF名称      | 可选必选说明：必选参数 参数含义：UPF名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无                                                                                              |
| IPTYPE       | IP地址类型     | 可选必选说明：必选参数 参数含义：IP地址类型。 数据来源：对端协商 取值范围：枚举类型。 IPV4：表示地址类型为IPv4。IPV6：表示地址类型为IPv6。 默认值：无 配置原则：无                                                                       |
| UPFV4ADDRESS | UPF IPv4地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPTYPE”配置为“IPV4”时为必选参数。 参数含义：UPF的IPv4地址。 数据来源：对端协商 取值范围：IPv4地址类型。 默认值：无 配置原则：根据与当前MPF对接的UPF上通过ADD MPFLOGICINF命令配置的capif1/0/0逻辑口的IPv4地址进行配置。 |
| UPFV6ADDRESS | UPF IPv6地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPTYPE”配置为“IPV6”时为必选参数。 参数含义：UPF IPv6地址。 数据来源：对端协商 取值范围：IPv6地址类型。 默认值：无 配置原则：根据与当前MPF对接的UPF上通过ADD MPFLOGICINF命令配置的capif1/0/0逻辑口的IPv6地址进行配置。 |

#### 使用实例

添加UPF名称为isp.upf001，地址类型为IPv4，地址为10.1.1.1的UPF配置信息：

```
ADD UPFINFO: UPFNAME="isp.upf001", IPTYPE=IPv4, UPFV4ADDRESS="10.1.1.1";
```
