# 修改QoS接口信任（MOD QOSIFTRUST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来修改在太主接口绑定的DS域，根据dscp值进行简单流分类，对IP报文的优先级进行修改。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                        |
|:----------|:--------|:----------------------------------------------------------------------------------------------------------------------------|
| IFNAME    | 接口名称    | 可选必选说明：必选参数 参数含义：该参数用于指定一个接口。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：使用LST INTERFACE命令查看可用接口。                         |
| DSNAME    | DS域名    | 可选必选说明：必选参数 参数含义：该参数用于指定DS域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：区分大小写，不支持空格。                                   |
| FLAG8021P | 8021p标志 | 可选必选说明：可选参数 参数含义：该参数用于指定映射的优先级。 数据来源：本端规划 取值范围：枚举类型。 false：不支持以太子接口上根据802.1p的值进行简单流分类。true：支持以太子接口上根据802.1p的值进行简单流分类。 默认值：无 |

#### 使用实例

修改在以太主接口Ethernet66/0/3绑定DS域ds1：

```
MOD QOSIFTRUST:DSNAME="ds1",IFNAME="Ethernet66/0/3";
```
