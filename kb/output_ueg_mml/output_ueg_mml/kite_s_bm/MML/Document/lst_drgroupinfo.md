# 查询容灾组信息（LST DRGROUPINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询容灾组信息。

## 注意事项

- 该命令只用于在UEG-L/UEN网元采用主备（冷备）容灾模式下执行。
- 该命令只用于在UEG-M/UEG网元采用主备（热备）容灾模式下执行。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                             |
|:----------|:-------|:-------------------------------------------------------------------------------------------------|
| DRGROUPID | 容灾组标识  | 可选必选说明：可选参数  参数含义：该参数用于标识一条容灾组信息，不同容灾组信息的该标识不能相同。  数据来源：全网规划  取值范围：整数类型，取值范围是1~8。  默认值：无  配置原则：无 |

## 使用实例

查询容灾组信息：

```
%%LST DRGROUPINFO: DRGROUPID=1;%%
RETCODE = 0  操作成功

结果如下
--------
              容灾组标识  =  1
              容灾组名称  =  HafGTnGrp
        本端容灾实例标识  =  222
        本端默认运行模式  =  配置主
        对端容灾实例标识  =  111
对端容灾控制通道IPv4地址  =  0.0.0.0
对端容灾控制通道IPv6地址  =  ::
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称          | 输出项解释                                              |
|:---------------|:---------------------------------------------------|
| 容灾组标识          | 该参数用于标识一条容灾组信息，不同容灾组信息的该标识不能相同。                    |
| 容灾组名称          | 该参数用于表示容灾组的名称。                                     |
| 本端容灾实例标识       | 该参数用于表示容灾组中本端的网元标识。                                |
| 本端默认运行模式       | 该参数用于配置默认的运行模式，容灾功能运行后，会根据该默认的运行模式，与对端协商真实使用的运行模式。 |
| 对端容灾实例标识       | 该参数用于表示容灾组中对端的网元标识。                                |
| 对端容灾控制通道IPv4地址 | 该参数用于配置对端容灾控制通道的IPv4地址。                            |
| 对端容灾控制通道IPv6地址 | 该参数用于配置对端容灾控制通道的IPv6地址。                            |
