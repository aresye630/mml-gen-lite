# 查询QoS PHB（LST QOSPHB）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查看当前域的下行IP报文在路由器内部的服务等级，还有相应的报文着色如何映射成对应的外部优先标识。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                   |
|:-------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DSNAME       | DS域名   | 可选必选说明：可选参数 参数含义：该参数用于指定差分服务域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                                                                                              |
| PHBTYPE      | PHB类型  | 可选必选说明：可选参数 参数含义：该参数用于指定修改的差分服务域下行映射类型。 数据来源：本端规划 取值范围：枚举类型。 8021p：对出方向的VLAN报文8021p值进行修改。ip_dscp：对出方向的IP报文DSCP(差分服务码点)值进行修改。mpls_exp：对出方向的MPLS报文EXP(实验比特位)值进行修改。 默认值：无 |
| PHBVALUE     | PHB值   | 可选必选说明：可选参数 参数含义：该参数用于指定需要映射的优先级。 数据来源：本端规划 取值范围：整数类型，取值范围为0～63。802.1p的取值范围是0到7;DSCP值的范围是0到63。取值越大优先级越高。 默认值：无                                                         |
| SERVICECLASS | 服务分类   | 可选必选说明：可选参数 参数含义：该参数用于指定映射前的内部服务等级。 数据来源：本端规划 取值范围：枚举类型。 be：尽力而为。af1：确保转发等级1。af2：确保转发等级2。af3：确保转发等级3。af4：确保转发等级4。ef：加速转发。cs6：类选择码6。cs7：类选择码7。 默认值：无                    |
| COLOR        | 颜色分类   | 可选必选说明：可选参数 参数含义：该参数用于指定映射前报文的着色。 数据来源：本端规划 取值范围：枚举类型。 green：报文颜色，绿色报文的丢弃优先级最低。yellow：报文颜色，黄色报文的丢弃优先级介于绿色红色之间。red：报文颜色，红色报文的丢弃优先级最高。 默认值：无                             |

#### 使用实例

查询DS域default的下行报文在路由器内部的服务等级与报文着色如何映射成对应的外部优先标识：

```
LST QOSPHB:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
DS域名    PHB类型    PHB值       服务分类    颜色分类
default   8021p      0           be          绿
default   8021p      1           be          红
default   8021p      2           af2         绿
default   8021p      3           af3         绿
default   8021p      4           af4         绿 
(结果个数 = 5)
---    END
```

#### 输出结果说明

|:--------|:------------|
| DS域名    | 该参数表示DS域名称。 |
| PHB类型   | 该参数表示映射类型。  |
| PHB值    | 该参数表示优先级。   |
| 服务分类    | 该参数表示服务等级。  |
| 颜色分类    | 该参数表示报文颜色。  |
