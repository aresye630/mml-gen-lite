# 删除防欺诈可信代理服务器（RMV AFPROXYSERVER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，删除防欺诈可信代理服务器可能会改变业务匹配结果，导致用户业务受损，请谨慎使用并联系华为支持协助操作。

该命令用于删除指定的可信代理服务器IP。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称        | 参数说明                                                                                                                                                                                             |
|:----------|:------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IPVERSION | IP地址版本类型    | 可选必选说明：必选参数 参数含义：该参数用于指定IP地址版本类型。 数据来源：本端规划 取值范围：枚举类型。 IPV4：IPv4地址类型。IPV6：IPv6地址类型。 默认值：无 配置原则：无                                                                                                 |
| IPV4ADDR  | 代理服务器IPv4地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV4”时为必选参数。 参数含义：该参数用于指定IPv4地址。 数据来源：本端规划 取值范围：IPv4地址类型。采用点分十进制"X.X.X.X"格式。 默认值：无 配置原则：IPv4地址必须是A、B或者C类地址，不能为环回地址（127.x.y.z）、组播地址（240.x.y.z）或（255.0.0.0）。 |
| IPV6ADDR  | 代理服务器IPv6地址 | 可选必选说明：条件必选参数 前提条件：该参数在“IPVERSION”配置为“IPV6”时为必选参数。 参数含义：该参数用于指定IPv6地址。 数据来源：本端规划 取值范围：IPv6地址类型。采用冒号分十六进制X:X:X:X:X:X:X:X格式。 默认值：无 配置原则：无                                                          |

#### 使用实例

删除指定的可信的代理服务器地址：

```
RMV AFPROXYSERVER:IPVERSION=IPV4,IPV4ADDR="192.168.0.2";
```
