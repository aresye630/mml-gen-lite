# 显示Vtep状态（DSP VTEPSTAT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于显示与指定VXLAN Group绑定的VTEP的信息，包括VTEP的名称。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称       | 参数说明                                                                                            |
|:-------------|:-----------|:------------------------------------------------------------------------------------------------|
| VXLANGRPNAME | VXLAN隧道组名称 | 可选必选说明：必选参数 参数含义：该参数用于表示VXLAN链路组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

查询与VXLAN Group“test”绑定的VTEP信息：

```
DSP VTEPSTAT: VXLANGRPNAME="test";
```

```
RETCODE = 0  操作成功。

VTEP状态
-----------
VXLAN隧道端点名称   =  test
地址信息  =  10.0.0.1
服务器状态 =  正常
(结果个数 = 1)

---    END
```

#### 输出结果说明

| 输出项名称       | 输出项解释            |
|:------------|:-----------------|
| VXLAN隧道端点名称 | 用于表示VXLAN隧道端点名称。 |
| 地址信息        | 用于表示VTEP的地址信息。   |
| 服务器状态       | 用于表示Vtep服务器状态。   |
