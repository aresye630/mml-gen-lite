# 设置开启内容过滤的协议列表（SET CFPROTOCOLLST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于指定要开启内容过滤功能的特定协议列表。

#### 注意事项

- 该命令执行后对新数据流生效。
- 该命令最大记录数为1。
- HTTP与WAP协议无需配置，缺省做内容过滤。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   |   PROTOCOL |
|:-------|-----------:|
| 初始值    |        nan |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:--------------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROTOCOL      | 内容过滤协议名称 | 可选必选说明：必选参数 参数含义：该参数用于指定要开启内容过滤功能的特定协议。 数据来源：本端规划 取值范围：位域类型。 HTTPS：开启HTTPS协议的内容过滤功能。GOOGLE_QUIC：开启GOOGLE_QUIC协议的内容过滤功能。QUIC：开启QUIC协议的内容过滤功能。 默认值：无 配置原则： 如果运营商需要指定要开启内容过滤功能的特定协议，需要配置该参数。若不指定该参数，默认HTTPS协议与GOOGLE_QUIC协议的报文均不做内容过滤，该参数显示为NULL。若运营商想要指定开启某一种协议的内容过滤功能，则将对应的BIT位设置为1。若需要对明文QUIC做内容过滤，则需将SET SACOMMONPARA命令的QUICSASW置为ENABLE。若需要对密文QUIC做内容过滤，则需加载HTTP3.0解析license，并将SET SACOMMONPARA命令的QUICIDENFUNCEN和QUICPSRFUNCEN置为ENABLE。 |
| CFGDOMAINNAME | 配置域名称    | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                        |

#### 使用实例

开启HTTPS协议的内容过滤功能：

```
SET CFPROTOCOLLST: PROTOCOL=HTTPS-1&GOOGLE_QUIC-0;
```
