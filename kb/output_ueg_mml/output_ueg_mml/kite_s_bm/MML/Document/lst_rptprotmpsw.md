#### 命令功能

**适用NF：UPF**

该命令用来查询业务报表承载协议映射开关。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询业务报表承载协议映射开关：

```
LST RPTPROTMPSW:;
```

```
RETCODE = 0  操作成功.

业务报表承载协议映射开关
-------------------------------------------------
功能开关  =  使能
(结果个数 = 1)
--- END
```
