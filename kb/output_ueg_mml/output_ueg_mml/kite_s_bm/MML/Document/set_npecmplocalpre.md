# 设置优选本单板TRUNK出接口开关（SET NPECMPLOCALPRE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来设置NP优选本单板TRUNK出接口开关。

#### 注意事项

- 该命令执行后立即生效。

- 该命令仅适用于NP卡加速模式场景。

系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

|   LOCALPREDISABLE |
|------------------:|
|                 0 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称              | 参数说明                                                                                                                              |
|:----------------|:------------------|:----------------------------------------------------------------------------------------------------------------------------------|
| LOCALPREDISABLE | 关闭优选本单板TRUNK出接口开关 | 可选必选说明：必选参数。 参数含义：该参数用于指定关闭优选本单板TRUNK出接口开关状态。 数据来源：本端规划。 取值范围： “FALSE”：开启优选本单板TRUNK出接口开关。“TRUE”：关闭优选本单板TRUNK出接口开关。 默认值：无。 配置原则：无。 |

#### 使用实例

设置关闭优选本单板TRUNK出接口开关：

```
SET NPECMPLOCALPRE: LOCALPREDISABLE=TRUE;
```
