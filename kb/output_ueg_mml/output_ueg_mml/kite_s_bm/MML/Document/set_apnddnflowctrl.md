# 设置基于APN的下行数据DDN寻呼流控方式（SET APNDDNFLOWCTRL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

设置基于APN的下行数据DDN寻呼流控方式。

#### 注意事项

- 该命令执行后立即生效。
- 系统最多支持配置10000条。
- 该命令需要与byte686和bit1230配合使用。
- 配置该命令时，对于语音类APN，建议配置时长模式，且时长检查时间不大于3s。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | FLOWCTRLMODE   |
|:-------|:---------------|
| 初始值    | DEFAULT        |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                    |
|:-------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN          | APN    | 可选必选说明：必选参数 参数含义：该参数用于指定APN实例名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”等特殊字符，不区分大小写。 默认值：无 配置原则：该参数必须已经通过ADD APN命令配置。 |
| FLOWCTRLMODE | 流控模式   | 可选必选说明：必选参数 参数含义：该参数用于控制下行数据报文触发DDN的流控模式。报文模式指按报文个数进行流控；时间模式指按时间进行流控。 数据来源：本端规划 取值范围：枚举类型。 DEFAULT：缺省流控模式。PKTNUM：报文流控模式，按报文个数进行流控。TIME：时间流控模式，按时间进行流控。 默认值：无 配置原则：无                                                     |
| PACKETNUM    | 报文个数   | 可选必选说明：条件必选参数 前提条件：该参数在“FLOWCTRLMODE”配置为“PKTNUM”时为必选参数。 参数含义：该参数表示收到多少下行报文后重复触发一次DDN寻呼。 数据来源：本端规划 取值范围：1~1000。 默认值：无 配置原则：无                                                                                             |
| TIMEINTERVAL | 时间间隔   | 可选必选说明：条件必选参数 前提条件：该参数在“FLOWCTRLMODE”配置为“TIME”时为必选参数。 参数含义：该参数表示重复触发一次DDN寻呼间隔的时间，单位为秒。 数据来源：本端规划 取值范围：1~10。 默认值：无 配置原则：无                                                                                                |

#### 使用实例

设置基于APN的下行数据DDN寻呼流控方式：

```
SET APNDDNFLOWCTRL: APN="aaa", FLOWCTRLMODE=DEFAULT;
```
