# 配置指纹采集终端信息（ADD FPUEPOS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

新增FPUEPOS对象，支持配置1000个记录。

#### 注意事项

该命令最大记录数为1000。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称          | 参数说明                                                                                                                                           |
|:------------|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| UEID        | UE标识          | 可选必选说明：必选参数 参数含义：该参数用于设置UE标识。 数据来源：本端规划 取值范围：字符串类型 0~20字节。 默认值：无 配置原则：无                                                                        |
| MAPID       | 地图标识          | 可选必选说明：必选参数 参数含义：该参数用于设置地图标识。 数据来源：本端规划 取值范围：字符串类型，长度0~20字节。字符串内容为10进制数，取值范围为-9223372036854775808～9223372036854775807。 默认值：无 配置原则：无            |
| HEIGHT      | UE高度（厘米）      | 可选必选说明：必选参数 参数含义：该参数用于设置UE高度，单位：厘米。 数据来源：本端规划 取值范围：字符串类型，长度0~20字节。字符串内容为10进制数，取值范围为-9223372036854775808～9223372036854775807。 默认值：无 配置原则：无      |
| POSITIONX   | UE相对位置X信息（厘米） | 可选必选说明：必选参数 参数含义：该参数用于设置UE相对位置X信息，单位：厘米。 数据来源：本端规划 取值范围：字符串类型，长度0~20字节。字符串内容为10进制数，取值范围为-9223372036854775808～9223372036854775807。 默认值：无 配置原则：无 |
| POSITIONY   | UE相对位置Y信息（厘米） | 可选必选说明：必选参数 参数含义：该参数用于设置UE相对位置Y信息，单位：厘米。 数据来源：本端规划 取值范围：字符串类型，长度0~20字节。字符串内容为10进制数，取值范围为-9223372036854775808～9223372036854775807。 默认值：无 配置原则：无 |
| DESCRIPTION | 描述信息          | 可选必选说明：可选参数 参数含义：该参数用于设置UE指纹位置描述信息。 数据来源：全网规划 取值范围：字符串类型 0~32字节。 默认值：无 配置原则：无                                                                  |

#### 使用实例

新增FPUEPOS对象，配置指纹点信息：

```
ADD FPUEPOS: UEID="123", MAPID="456", HEIGHT="789", POSITIONX="890", POSITIONY="890";
```
