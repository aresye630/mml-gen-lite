# 清除UDP报文统计（RTR UDPSTATISTIC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于清除UDP报文统计信息。

如果需要统计在某一时间内的UDP报文统计信息，这时必须在统计开始前清除原有的UDP报文统计信息后，使用DSP UDPSTATISTIC命令查看UDP报文统计信息。不。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                           |
|:----------|:-------|:-----------------------------------------------------------------------------------------------|
| IPVERSION | IP版本   | 可选必选说明：可选参数 参数含义：该参数用于指定UDP报文统计的IP版本。 数据来源：本端规划 取值范围：枚举类型。 IPv4：IPv4协议族。IPv6：IPv6协议族。 默认值：IPv4 |

#### 使用实例

清除当前系统的UDP报文统计：

```
RTR UDPSTATISTIC:IPVERSION=IPv4;
```
