# 设置容器CPU告警阈值（SET CNTCPUTHD）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置容器CPU告警阈值。

## 注意事项

- 该命令执行后立即生效。

- 系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

|   WARNTHD |   RECVTHD |
|----------:|----------:|
|        80 |        70 |

#### 操作用户权限

G\_1，管理员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                            |
|:--------|:-------|:----------------------------------------------------------------------------------------------------------------|
| WARNTHD | 告警上报门限 | 可选必选说明：必选参数  参数含义：该参数用于指定告警上报门限。  数据来源：本端规划  取值范围：整数类型，取值范围是0~100，单位是百分比。  默认值：无。  配置原则：  “告警恢复门限”必须小于“告警上报门限”。 |
| RECVTHD | 告警恢复门限 | 可选必选说明：必选参数  参数含义：该参数用于指定告警恢复门限。  数据来源：本端规划  取值范围：整数类型，取值范围是0~100，单位是百分比。  默认值：无。  配置原则：  “告警恢复门限”必须小于“告警上报门限”。 |

## 使用实例

设置容器CPU告警上报门限为90，恢复门限为80。

```
SET CNTCPUTHD: WARNTHD=90,RECVTHD=80;
```
