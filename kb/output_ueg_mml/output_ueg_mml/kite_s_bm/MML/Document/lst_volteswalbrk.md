# 显示VoLTE滑窗相关参数（LST VOLTESWALBRK）

#### 命令功能

**适用NF：PGW-U**

该命令用于显示VoLTE吞字断续检测的相关参数。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

显示VoLTE吞字断续检测的相关参数：

```
LST VOLTESWALBRK:;
```

```
RETCODE = 0  操作成功

VoLTE吞字断续检测参数
---------------------
      功能开关  =  不使能（关闭）
  吞字滑窗大小  =  20
吞字的滑窗阈值  =  12
  断续滑窗大小  =  50
断续的滑窗阈值  =  30
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见SET VOLTESWALBRK的参数说明。
