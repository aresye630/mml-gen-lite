# 重置OSPF进程（RST OSPF）

- 注意事项
- 操作用户权限

#### 命令功能

**须知** 

本命令属于高危命令，操作不当会导致路由器之间的OSPF邻接关系中断，且以前的信息将无法恢复，请谨慎使用并联系华为技术支持协助操作。

该命令用于重置OSPF进程。

#### 注意事项

- 该命令执行后立即生效。
- 重置OSPF进程可能会导致业务受损。
- 只有在配置了OSPF进程后才能使用此命令。
- 复位OSPF进程会导致路由器之间的OSPF邻接关系中断，且以前的信息将无法恢复。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                |
|:-------|:-------|:----------------------------------------------------------------------------------------------------|
| PROCID | 进程号    | 可选必选说明：可选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 配置原则：如果不输入该参数，则表示匹配所有OSPF进程。 |

#### 使用实例

重置所有进程号为1的OSPF进程：

```
RST OSPF: PROCID=1;
```
