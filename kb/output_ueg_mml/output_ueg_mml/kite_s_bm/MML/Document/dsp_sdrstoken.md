# 显示SDRS中的TOKEN信息（DSP SDRSTOKEN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询SDRS中指定APP的TOKEN策略信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                   |
|:--------|:--------|:-----------------------------------------------------------------------------------------------------------------------|
| APPTYPE | app类型   | 可选必选说明：必选参数  参数含义：参数标识下发APP路由策略的APP类型，可以使用DSP SDRSAPPTYPE命令获取。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无 |
| CELLID  | Cell ID | 可选必选说明：必选参数  参数含义：该参数用于指定SDR调试消息发送的CELLID，可以通过使用命令DSP MSPROCESS获取。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~127。  默认值：无  配置原则：无 |

## 使用实例

使用如下命令查询SDRS中缓存的TOKEN策略信息：

```
%%DSP SDRSTOKEN: APPTYPE=1003, CELLID="vusn-pod-5bccb87b-d4d4v10-30-0-111__103__0";%%
RETCODE = 0  操作成功
```

## 输出结果说明

| 输出项名称       | 输出项解释                                            |
|:------------|:-------------------------------------------------|
| app类型       | 参数标识下发APP路由策略的APP类型，可以使用DSP SDRSAPPTYPE命令获取。     |
| Cell ID     | 该参数用于指定SDR调试消息发送的CELLID，可以通过使用命令DSP MSPROCESS获取。 |
| 令牌组数量       | 该参数用于表示令牌组数量。                                    |
| 令牌组         | 该参数用于表示TOKEN策略的令牌组。                              |
| 根令牌         | 该参数用于表示根令牌。                                      |
| 主链路链路实例是否故障 | 该参数用于表示主链路链路实例是否故障，其中0表示正常 ，1表示故障。               |
| 主实例ID       | 该参数用于表示TOKEN策略的主实例ID。                            |
| 新主实例ID      | 该参数用于表示TOKEN策略的新主实例ID。                           |
| 版本号         | 该参数用于表示token策略资源的版本号。                            |
| 推送状态        | 该参数用于表示推送状态，其中0表示已推送，1表示未推送。                     |
