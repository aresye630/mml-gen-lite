# 修改OSPFv3区域内路由聚合配置（MOD OSPFV3ABRSUMMARY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改OSPFv3区域内路由聚合。

#### 注意事项

- 该命令执行后立即生效。
- 只有配置了OSPFv3进程和OSPFv3区域后才能使用此命令。
- 本命令只适用于ABR，对区域内的路由进行路由聚合。
- 在相同进程的不同区域下，ABR不能配置路由聚合。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                                                                                                   |
|:------------|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROCID      | OSPFv3进程号  | 可选必选说明：必选参数 参数含义：OSPFv3进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 配置原则：OSPFv3进程必须已经存在。请使用LST OSPFV3命令查看可用的OSPFv3进程。                                                             |
| AREAID      | OSPFv3区域ID | 可选必选说明：必选参数 参数含义：OSPFv3区域ID。 数据来源：全网规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无                                                                                                                    |
| TOPOID      | 拓扑标识       | 可选必选说明：必选参数 参数含义：拓扑标识。 数据来源：全网规划 取值范围：整数类型，取值范围为0。 默认值：无                                                                                                                               |
| IPADDRESS   | IPv6地址     | 可选必选说明：必选参数 参数含义：IPv6地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无                                                                                                                                |
| IPV6MASKLEN | IPv6前缀长度   | 可选必选说明：必选参数 参数含义：IPv6前缀长度。 数据来源：本端规划 取值范围：整数类型，取值范围为1～128。 默认值：无                                                                                                                       |
| ADVERTISE   | 发布路由标识     | 可选必选说明：可选参数 参数含义：是否发布这条聚合路由。缺省时发布聚合路由。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无 配置原则：缺省情况下，发布聚合路由。                                                                              |
| CONFIGCOST  | 使能开销配置     | 可选必选说明：可选参数 参数含义：表示开销配置使能/去使能。 数据来源：本端规划 取值范围：枚举类型。 FALSE：不使能。TRUE：使能。 默认值：无                                                                                                           |
| COST        | 聚合路由的开销    | 可选必选说明：条件必选参数 前提条件：该参数在“CONFIGCOST”配置为“TRUE”时为必选参数。 参数含义：设置聚合路由的开销，当此参数缺省时，则取所有被聚合的路由中最大的那个开销值作为聚合路由的开销。 数据来源：本端规划 取值范围：整数类型，取值范围为0～16777214。 默认值：无 配置原则：缺省情况下，聚合路由的开销值是所有被聚合路由的最大开销值。 |

#### 使用实例

修改OSPFv3进程1区域1下2001:db8::1的区域内路由聚合的Cost值为200：

```
MOD OSPFV3ABRSUMMARY:PROCID=1,AREAID="0.0.0.1",TOPOID=0,IPADDRESS="2001:db8::1",IPV6MASKLEN=64,CONFIGCOST=TRUE,COST=200;
```
