# 查询路由管理生产者详细信息（DSP RMPRODUCERDETAIL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询路由管理生产者详细信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称       | 参数说明                                                                                           |
|:--------------|:-----------|:-----------------------------------------------------------------------------------------------|
| ADDRESSFAMILY | 地址族        | 可选必选说明：必选参数 参数含义：该参数用于表示地址族。 数据来源：本端规划 取值范围：枚举类型。 ipv4unicast：IPv4单播。ipv6unicast：IPv6单播。 默认值：无 |
| PARTNER       | Partner ID | 可选必选说明：可选参数 参数含义：该参数用于表示Partner ID。 数据来源：本端规划 取值范围：十六进制整数类型，取值范围为0x0～0xFFFFFFFF。 默认值：无         |
| VPNNAME       | VPN实例名称    | 可选必选说明：可选参数 参数含义：该参数用于表示VPN实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                       |
| VRFINDEX      | VRF索引      | 可选必选说明：可选参数 参数含义：该参数用于表示VRF索引。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                    |
| ALL           | 所有实例       | 可选必选说明：可选参数 参数含义：该参数用于表示所有实例。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无                  |
| VPID          | VP ID      | 可选必选说明：可选参数 参数含义：该参数用于表示VP ID。 数据来源：本端规划 取值范围：十六进制整数类型，取值范围为0x0～0xFFFFFFFF。 默认值：无              |

#### 使用实例

查询路由管理生产者详细信息：

```
DSP RMPRODUCERDETAIL:ADDRESSFAMILY=ipv4unicast,VRFINDEX=1;
```
