# 网络配置（MOD NETWORK）

#### 命令功能

**须知** 

执行该命令后可能会**导致OM Portal断链以及网管断链**，需重新登录OM Portal，并重新对接网管；如果部署补丁后，执行该命令修改扩展域VLANID，则不允许进行回退操作，否则会导致无法登录OM Portal。

用于修改系统网络的网卡VLANID。

#### 注意事项

- 执行该命令前，通过**LST OMIP**查询得到修改VLANID所对应的IP地址。
- 执行该命令前，请确保修改VLANID后的网络通畅。
- 修改容器网络VLANID后需重启节点生效。

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                              |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------|
| IPTYPE | IP类型   | 可选必选说明：必选参数 参数含义：网络的IP类型。 取值范围： IPV4(IPV4类型)IPV6(IPV6类型)IPV4/IPV6(IPV4/IPV6类型)：双栈环境，同时支持IPV4和IPV6。 默认值：无。 配置原则：无。 |
| NWNAME | 网络名称   | 可选必选说明：必选参数 参数含义：网络名称。 取值范围： 1~512的字符串。 默认值：无。 配置原则：网络名称需要与服务适配包里定义的nwName完全一致（注意大小写及空白字符），否则无法识别。                |
| VLANID | VLANID | 可选必选说明：必选参数 参数含义：网络的VLANID。 取值范围：0~4094，CSP默认占用4083-4093。 默认值：无。 配置原则：无。                                          |

#### 使用实例

修改VLANID信息：

```
%%MOD NETWORK: IPTYPE=IPV6, NWNAME="OM", VLANID=158;%%
RETCODE = 0  操作成功
```
