# 查询软件生命周期信息（LST SWLCINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询软件服务年限及当前状态等生命周期相关信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询软件生命周期信息：

```
%%LST SWLCINFO:;%%
RETCODE = 0  操作成功
 
操作结果如下
------------
        网元名称  =  test
        网元类型  =  TEST
        网元版本  =  24.1.RC1
软件版本服务年限  =  2023-05-01
         当前状态 =  接近到期
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息，输出项表1如所示。

| 输出项名称    | 输出项解释        |
|:---------|:-------------|
| 网元名称     | 网元名称。        |
| 网元类型     | 网元类型。        |
| 网元版本     | 网元版本。        |
| 软件版本服务年限 | 软件服务截止时间。    |
| 当前状态     | 正常。接近到期。已过期。 |

该命令执行异常，会返回对应的错误码。常见错误码列表如表2所示。

|   错误码 | 错误码解释          | 原因分析                  | 处理建议      |
|------:|:---------------|:----------------------|:----------|
|   500 | 系统内部错误，请联系管理员。 | 可能存在网络故障或者服务不可用等异常因素。 | 等待几分钟后重试。 |
