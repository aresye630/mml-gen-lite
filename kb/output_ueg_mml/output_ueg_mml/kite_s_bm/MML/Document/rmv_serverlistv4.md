# 删除IPv4服务器列表（RMV SERVERLISTV4）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于删除IPv4服务器列表或列表中的IP地址。

#### 注意事项

- 该命令执行后30s生效。
- 删除指定服务器列表时，服务器列表如果被边缘接入控制命令引用，提示不允许删除，须先删除引用关系。
- 删除服务器列表中的IP地址时，如果该IP为服务器列表中的最后一个IP，则提示不允许删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称    | 参数说明                                                                                             |
|:---------------|:--------|:-------------------------------------------------------------------------------------------------|
| SERVERLISTV4NM | 服务器列表名称 | 可选必选说明：可选参数 参数含义：该参数用于指定IPv4服务器列表名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |
| IPV4ADDR       | IPv4地址  | 可选必选说明：可选参数 参数含义：该参数用于指定IPv4地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无 配置原则：无                            |

#### 使用实例

删除名称为test01的IPv4服务器列表，命令为：

```
RMV SERVERLISTV4:SERVERLISTV4NM="test01";
```
