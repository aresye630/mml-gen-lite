# 删除带宽管理规则（RMV BWMRULE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令,执行本命令后将删除默认用户组或具体用户组的指定或所有带宽管理规则，可能导致用户无法进行带宽控制，请谨慎使用。

该命令用于删除默认用户组、或具体用户组的带宽管理规则。当运营商希望删除某个或全部带宽控制规则时，则执行该命令。

#### 注意事项

- 该命令执行后立即生效。
- 如果指定用户组类型，而不指定带宽管理规则名称，可以删除用户组下的所有带宽管理规则，包括默认的规则。
- 如果TOS类型的组级BWMRULE已经生效，修改该BWMRULE下的BWMCONTROLLER，只对新用户或重新激活用户生效，所有组级用户生效前可能会导致带宽控制不准。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                                                                                                                                                                                                   |
|:--------------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USERGROUPTYPE | 用户组类型    | 可选必选说明：必选参数 参数含义：该参数用于配置带宽管理用户组的类型。 数据来源：本端规划 取值范围：枚举类型。 DEFAULT_GROUP：默认用户组。SPECIFIC_GROUP：特定用户组。 默认值：无 配置原则：无                                                                                                                                        |
| USERGROUPNAME | 用户组名称    | 可选必选说明：条件必选参数 前提条件：该参数在“USERGROUPTYPE”配置为“SPECIFIC_GROUP”时为必选参数。 参数含义：该参数用于配置具体用户组的名称，该参数由增加带宽管理用户组定义。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                     |
| BWMRULETYPE   | 带宽管理规则类型 | 可选必选说明：条件可选参数 前提条件：该参数在“USERGROUPTYPE”配置为“SPECIFIC_GROUP” 或 “DEFAULT_GROUP”时为可选参数。 参数含义：该参数用于配置带宽管理规则的类型。 数据来源：本端规划 取值范围：枚举类型。 GROUP_DEFAULT：用户组级别默认规则。SUBSCRIBER_DEFAULT：用户级别默认规则。GROUP_SPECIFIC：用户组级别特定规则。SUBSCRIBER_SPECIFIC：用户级别特定规则。 默认值：无 配置原则：无 |
| BWMRULENAME   | 带宽管理规则名称 | 可选必选说明：条件必选参数 前提条件：该参数在“BWMRULETYPE”配置为“GROUP_SPECIFIC” 或 “SUBSCRIBER_SPECIFIC”时为必选参数。 参数含义：该参数用于配置带宽管理规则的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                              |

#### 使用实例

- 假如运营商需要删除默认用户组下用户组级默认带宽管理规则：

  ```
  RMV BWMRULE:USERGROUPTYPE=DEFAULT_GROUP,BWMRULETYPE=SUBSCRIBER_DEFAULT;
  ```
- 假如运营商需要删除具体用户组“testbwmusergroup”下的所有的带宽管理规则：

  ```
  RMV BWMRULE:USERGROUPTYPE=SPECIFIC_GROUP,USERGROUPNAME="testbwmusergroup";
  ```
