# 修改报表服务器（MOD RPTSVR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于修改报表服务器配置。

#### 注意事项

- 该命令执行后立即生效。
- 当报表消息类型为SUBSCRIPTION时，SUCCESSLT参数无效。FAILURELT和TIMERTHD的乘积为报表服务器的链路故障时间，当参数TIMERTHD取值为0时，链路故障时间设置为一分钟；当乘积大于一小时时，链路故障时间设置为一小时。
- 当报表消息类型为EXP时，SVRFUNC参数无效，此类型的服务器仅对SSU生效。
- 不允许将EXP类型报表服务器修改为其他类型，不允许将其他类型报表服务器修改为EXP类型。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称        | 参数说明                                                                                                                                                                                                                                                |
|:-----------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RPTSVRNAME | 报表服务器名称     | 可选必选说明：必选参数 参数含义：设置报表服务器名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                                                                                             |
| RPTSVRTYPE | 报表消息类型      | 可选必选说明：可选参数 参数含义：该参数用于设置报表消息类型。 数据来源：本端规划 取值范围：枚举类型。 UFDR：表示报表话单为UFDR格式。ADR：表示ADR上报使用的报表Server。SUBSCRIPTION：表示订阅消息下发使用的报表Server。BASIC：表示上报基础信息使用的报表Server。BTDR：表示上报基础信息使用的M+服务器类型。ALLTYPE：表示所有报表话单类型（不含EXP）。EXP：表示上报体验分析信息使用的报表Server。 默认值：无 配置原则：无 |
| SUCCESSLT  | 心跳检测成功次数阈值  | 可选必选说明：可选参数 参数含义：该参数设置达到链路恢复状态的心跳检测成功的次数。 数据来源：本端规划 取值范围：整数类型，取值范围为1～10，单位是次数。 默认值：无 配置原则：无                                                                                                                                                         |
| FAILURELT  | 心跳检测的失败次数门限 | 可选必选说明：可选参数 参数含义：该参数设置达到链路故障状态的心跳检测失败的次数。 数据来源：本端规划 取值范围：整数类型，取值范围为1～10，单位是次数。 默认值：无 配置原则：无                                                                                                                                                         |
| TIMERTHD   | 心跳消息发送时间间隔  | 可选必选说明：可选参数 参数含义：该参数用于设置心跳消息发送时间间隔，取值为0表示关闭心跳发送功能。 数据来源：本端规划 取值范围：整数类型，取值范围为0～1440，单位是秒。 默认值：无 配置原则：无                                                                                                                                               |
| SVRFUNC    | 服务器功能       | 可选必选说明：可选参数 参数含义：该参数用于设置报表服务器功能。 数据来源：本端规划 取值范围：位域类型。不支持空格，不区分大小写。 RPT：普通报表服务器。SSU：智能板单据的报表服务器。 默认值：无 配置原则：无                                                                                                                                        |

#### 使用实例

修改报表服务器配置：

```
MOD RPTSVR: RPTSVRNAME="report01", RPTSVRTYPE=UFDR, SUCCESSLT=10, FAILURELT=10, TIMERTHD=100, SVRFUNC=RPT-1&SSU-1;
```
