# 添加MEP反向代理（ADD MEPREVERSEPROXY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

该命令用于添加反向代理对象，根据该对象所关联的HTTP服务端和HTTP客户端类型不同提供不同功能，包含：

API GW对外部网元提供访问内部服务的代理功能。

API GW对外部网元提供访问外部网元的代理功能。

API GW对内部服务提供通知外部网元相关事件的代理功能。

API GW对内部服务提供向外部网元如UPF提供规则下发的代理功能。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为128。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识             | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                                                 |
|:-----------------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROXYNAME        | 反向代理名称     | 可选必选说明：必选参数 参数含义：该参数用于指定反向代理名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“.”组成，且只能以字母或者数字开头。 默认值：无 配置原则：无                                                                                                                                                                                                                                      |
| MEPHTTPSERVERGRP | HTTP服务端索引组 | 可选必选说明：必选参数 参数含义：该参数用于指定本反向代理对象所关联的HTTP服务端索引组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“.”组成，且只能以字母或者数字开头。 默认值：无 配置原则： 该参数使用ADD MEPHTTPSERVERGRP命令配置生成。HTTP服务端索引组内所关联的HTTP服务端当前仅支持一个。同一个HTTP服务端索引组内相同类型的HTTP服务端所关联的“TLSPARANAME”必须相同。同一个HTTP服务端索引组内的HTTP服务端所关联的"ServerCommParaName"必须相同。                                                    |
| MEPHTTPCLIENTGRP | HTTP客户端索引组 | 可选必选说明：必选参数 参数含义：该参数用于指定本反向代理对象所关联的HTTP客户端索引组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“.”组成，且只能以字母或者数字开头。 默认值：无 配置原则： 该参数使用ADD MEPHTTPCLIENTGRP命令配置生成。HTTP客户端索引组内所关联的HTTP客户端中最多关联一个“TO_CONNECT_INTERNAL_MES”类型的HTTP客户端。同一个HTTP客户端索引组内配置相同PeerServiceTag属性的HTTP客户端所关联的“TLSPARANAME”必须相同。同一个HTTP客户端索引组内的HTTP客户端所关联的"ClientCommParaName"必须相同。 |

#### 使用实例

添加MEPREVERSEPROXY对象，添加的MEPREVERSEPROXY对象名称为"proxy"，关联的服务端组名为"servergrp"，关联的客户端组名为"clientgrp"：

```
ADD MEPREVERSEPROXY: PROXYNAME="proxy", MEPHTTPSERVERGRP="servergrp", MEPHTTPCLIENTGRP="clientgrp";
```
