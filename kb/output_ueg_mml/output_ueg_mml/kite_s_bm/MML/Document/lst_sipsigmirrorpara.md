# 查询镜像SIP信令功能（LST SIPSIGMIRRORPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-U、UPF**

该命令用于查询SIP镜像功能是否使能。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

该命令用于查询SIP镜像功能是否使能：

```
LST SIPSIGMIRRORPARA:;
```

```
RETCODE = 0  操作成功

结果如下
--------
       镜像功能开关  =  不使能
内层IPv6报文分片MTU  =  0
          重定向VPN  =  NULL
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见SET SIPSIGMIRRORPARA的参数说明。
