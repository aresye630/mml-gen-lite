# 配置NSH头增强全局策略（SET GLBNSHHDNPLY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于设置NSH头增强全局策略。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- NSH头增强名称需要在NSHHEADEN中存在配置。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | REDIRIPVER   | REDIRIPV4   | REDIRIPV6                               |   DSTSERVERPORT |
|:-------|:-------------|:------------|:----------------------------------------|----------------:|
| 初始值    | IPV4         | 0.0.0.0     | 0000:0000:0000:0000:0000:0000:0000:0000 |            6633 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称       | 参数说明                                                                                                                                                          |
|:--------------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NSHNAME       | NSH头增强名称   | 可选必选说明：必选参数 参数含义：该参数用于设置NSH头增强名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                 |
| REDIRIPVER    | 重定向IP协议版本  | 可选必选说明：可选参数 参数含义：该参数用于设置IP地址类型。 数据来源：本端规划 取值范围：枚举类型。 IPV4：添加重定向IP的版本为IPv4。IPV6：添加重定向IP的版本为IPv6。IPVER_ALL：添加重定向IP的版本为IPv4和IPv6。 默认值：无 配置原则：无                   |
| REDIRIPV4     | 重定向IPV4地址  | 可选必选说明：条件必选参数 前提条件：该参数在“REDIRIPVER”配置为“IPV4” 或 “IPVER_ALL”时为必选参数。 参数含义：该参数用于设置重定向服务器的IPv4地址。 数据来源：本端规划 取值范围：IPv4地址类型。采用点分十进制"X.X.X.X"格式。 默认值：无 配置原则：无         |
| REDIRIPV6     | 重定向IPV6地址  | 可选必选说明：条件必选参数 前提条件：该参数在“REDIRIPVER”配置为“IPV6” 或 “IPVER_ALL”时为必选参数。 参数含义：该参数用于设置重定向服务器的IPv6地址。 数据来源：本端规划 取值范围：IPv6地址类型。采用冒号分十六进制X:X:X:X:X:X:X:X格式。 默认值：无 配置原则：无 |
| DSTSERVERPORT | NSH对端设备端口号 | 可选必选说明：可选参数 参数含义：该参数用于设置NSH对端设备端口号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无 配置原则：无                                                                            |

#### 使用实例

设置名称为“nsh” 的NSH头增强配置，IP协议版本为IPv4，IP地址为10.0.0.0，则按如下命令配置：

```
SET GLBNSHHDNPLY: NSHNAME="nsh", REDIRIPVER=IPV4, REDIRIPV4="10.0.0.0";
```
