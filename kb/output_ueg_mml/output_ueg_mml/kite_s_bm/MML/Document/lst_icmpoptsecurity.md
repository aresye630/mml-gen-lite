# 查询ICMP选项安全配置（LST ICMPOPTSECURITY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询ICMP选项安全配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询ICMP选项安全配置：

```
LST ICMPOPTSECURITY:;
```

```
        RETCODE = 0  操作成功

        结果如下
        ------------------------
              RU名称  =  VNODE_VNRS_VNFC_IPU_0064
        ICMP安全类型  =  TTL超时报文
        (结果个数 = 1)
        ---    END
```

#### 输出结果说明

参见ADD ICMPOPTSECURITY的参数说明。
