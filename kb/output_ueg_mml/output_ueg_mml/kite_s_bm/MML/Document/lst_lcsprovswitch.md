# 显示LCS预备开关（LST LCSPROVSWITCH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于显示LCS API是否开放的开关信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

假如UE Tester查询LCS预备开关信息：

```
LST LCSPROVSWITCH:;
```

```
RETCODE = 0  操作成功

LCS预备开关
-----------
LCS 预备开关  =  开关打开
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见SET LCSPROVSWITCH的参数说明。
