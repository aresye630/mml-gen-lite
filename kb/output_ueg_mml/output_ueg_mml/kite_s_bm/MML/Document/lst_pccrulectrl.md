#### 命令功能

**适用NF：PGW-U、UPF**

此命令用于显示PCC动态Rule生成的QoS Rule优先级是否按照PCF下发的优先级进行控制。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

当运营商需要查询QosRulePrio参数当前的值时，需要执行：

```
LST PCCRULECTRL:;
```

```
RETCODE = 0 操作成功。

PCC QoS相关控制参数
------------------------
QoS Rule优先级设置原则 = 等于PCC Rule优先级
(结果个数 = 1)
--- END
```

#### 输出结果说明

参见SET PCCRULECTRL的参数说明。
