# 增加接口IPv4地址（ADD IFIPV4ADDRESSIPSEC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于配置接口的IP地址，包括逻辑接口及物理接口。物理接口是真实存在的接口。逻辑接口是指能够实现数据交换功能但物理上不存在、需要通过配置建立的接口。

## 注意事项

- 该命令执行后立即生效。

- 该接口需要支持配置IP地址。
- 该命令在版本升级过程中禁止执行。
- 每个主用接口最大允许配置256个接口IP地址：1个主IP地址和255个从IP地址。
- 该命令的必选参数IFNAME可通过**LST INTERFACEIPSEC**命令查询到。

- 最多可输入65535条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                                              |
|:-----------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ADDRTYPE   | IPv4地址类型 | 可选必选说明：可选参数  参数含义：地址类型。  数据来源：本端规划 取值范围： “Main（主地址）”：主地址“Sub（从地址）”：从地址“Brwd（被借用地址）”：被借用地址“Brw（借用地址）”：借用地址  默认值：Main  配置原则：无                                                                       |
| IFNAME     | 接口名      | 可选必选说明：必选参数  参数含义：该参数用于指定需要配置IP地址的接口名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。接口名称由接口类型+接口编号组成。  默认值：无  配置原则：  请使用LST INTERFACEIPSEC命令查看可用接口。                                                        |
| SUBNETMASK | IPv4地址掩码 | 可选必选说明：必选参数  参数含义：该参数用于指定需要配置的接口IPv4地址的网络掩码。  数据来源：本端规划  取值范围：IPv4地址类型。0.0.0.0～255.255.255.255。  默认值：无  配置原则：  使用网络规划的接口IP所属网段的掩码。  除Loopback接口外，其它接口不能配置255.255.255.255的掩码。                      |
| IFIPADDR   | IPv4地址   | 可选必选说明：必选参数  参数含义：该参数用于指定需要配置的接口IP地址。  数据来源：本端规划  取值范围：IPv4地址类型。0.0.0.0～255.255.255.255。  默认值：无  配置原则：  IPv4地址不能配置为0.0.0.0、255.255.255.255和环回地址(127.0.0.1)。  IPv4地址必须是A、B或者C类地址。  IPv4地址在系统内必须唯一。 |

## 使用实例

配置LoopBack4的地址为192.168.1.1，地址掩码为255.255.255.0，类型为主地址：

```
ADD IFIPV4ADDRESSIPSEC: ADDRTYPE=Main, IFNAME="LoopBack4", SUBNETMASK="255.255.255.0", IFIPADDR="192.168.1.1";
```
