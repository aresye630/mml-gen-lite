# 显示扩展的多级重定向密码（LST MULTREDIRECTEX）

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于显示多级重定向字段加密的密码。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

假如运营商想要查询加密，配置如下：

```
LST MULTREDIRECTEX:;
```

```
RETCODE = 0  操作成功

---------------------------

   AES 加密模式  =  GCM
   AES256 密码  =  *****

---    END
```
