# 设置ICMP快回配置（SET SECICMPREPLY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于设置ICMP快回使能配置。

当业务繁忙时，网络流量增大，Device的负载增大，这时会导致Device发送Ping报文应答延时较大。可以使用该命令使能设备Ping快回功能，达到避免Ping报文延时的目的。

#### 注意事项

- 该命令执行后立即生效。
- 该命令存在系统初始记录，参数的初始设置值如下表：

|   FASTRLYEN |
|------------:|
|           1 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                |
|:----------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| RUNAME    | RU名称   | 可选必选说明：必选参数 参数含义：资源单元名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。区分大小写。 默认值：无 配置原则：区分大小写，不支持空格，下发本MML命令前可使用DSP RU指定VNRS_VNFC（举例：VNRS_VNFC_999）查看转发板资源单元信息。 |
| FASTRLYEN | 使能标记   | 可选必选说明：必选参数 参数含义：使能标记。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：无                                                                              |

#### 使用实例

添加ICMP快回使能配置：

```
SET SECICMPREPLY:RUNAME="VNODE_VNRS_VNFC_IPU_0064",FASTRLYEN=TRUE;
```
