# 查询SAI差异化控制功能（LST SAIFUNC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明

#### 命令功能

**适用NF：UPF、PGW-U**

该命令用于查询SAI差异化控制功能状态。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询SAI差异化控制功能状态：

```
LST SAIFUNC:;
```

```
RETCODE = 0  操作成功

结果如下
--------
功能开关  =  不使能
(结果个数 = 1)

---    END
```
