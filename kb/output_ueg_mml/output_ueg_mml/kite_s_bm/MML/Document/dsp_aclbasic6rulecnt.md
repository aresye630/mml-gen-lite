# 显示基本IPv6 ACL规则匹配计数（DSP ACLBASIC6RULECNT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示基本IPv6 ACL规则的匹配计数信息。可应用于路由策略等使用场景的匹配计数信息查询。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称          | 参数说明                                                                                                                                                   |
|:------------|:--------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
| ACLNAME     | IPv6 ACL规则组标识 | 可选必选说明：必选参数 参数含义：该参数用于指定IPv6 ACL规则属于哪个IPv6 ACL规则组。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。不支持空格，区分大小写。以英文字母a～z或A～Z开始，可以是英文字母、数字、连字符“-”、下划线“_”或中文字符的组合。 默认值：无 |
| ACLRULENAME | 规则名称          | 可选必选说明：必选参数 参数含义：该参数用于指定IPv6 ACL规则名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。不支持空格，区分大小写。 默认值：无                                                              |

#### 使用实例

显示当前ACL规则组2000下规则名称为"rule\_5"的匹配计数：

```
DSP ACLBASIC6RULECNT:ACLNAME="2000",ACLRULENAME="rule_5";
```

```
RETCODE = 0  操作成功。

结果如下
--------
IPv6 ACL规则组标识  =  2000
          规则名称  =  rule_5
          匹配计数  =  0
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                |
|:--------|:---------------------|
| 匹配计数    | 用于显示IPv6 ACL规则的匹配计数。 |

其余输出项请参见LST ACLGROUP6的参数说明。
