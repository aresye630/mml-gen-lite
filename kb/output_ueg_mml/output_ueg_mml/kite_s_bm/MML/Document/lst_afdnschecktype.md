# 查询需要进行防欺诈检查的DNS报文类型（LST AFDNSCHECKTYPE）

- 注意事项

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询所有的进行防欺诈检查的DNS报文类型。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

如果运营商要查询所有的进行防欺诈检查的DNS报文类型，则命令如下：

```
LST AFDNSCHECKTYPE:;
```

```
RETCODE = 0  操作成功。

DNS防欺诈检查类型信息
---------------------
Dns防欺诈检查类型值  =  5
(结果个数 = 1)
--- END
```
