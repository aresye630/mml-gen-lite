# 回退升级操作（RBK PACKAGE）

#### 命令功能

**须知** 

本命令属于高危命令，会回退升级操作，若回退升级的版本号是冷补丁版本号或基础软件包版本号，会重启系统，请谨慎使用并联系华为支持协助操作。

该命令用于回退升级操作，当升级后的版本没有达到预期结果时，可使用该命令回退系统。

#### 注意事项

- 该命令执行后立即生效。
- 系统只有升级过，才能执行该命令。
- 可以通过**DSP RBKVER**，查询可回退版本。
- 该命令执行后，可通过**DSP UPDVER**查询该操作是否成功。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识              | 参数名称     | 参数说明                                                                                                                            |
|:------------------|:---------|:--------------------------------------------------------------------------------------------------------------------------------|
| RBKTYPE           | 回退类型     | 可选必选说明：可选参数 参数含义：该参数用于指定回退类型。 数据来源：本端规划 取值范围：枚举类型。 LAST：上一个版本。BASESOFTWARE：基础版本。PATCH：补丁。 默认值：LAST                              |
| UPDOBJECT         | 升级对象     | 可选必选说明：可选参数 参数含义：该参数用于指定升级对象。 数据来源：本端规划 取值范围：枚举类型。 BaseSoftware：只有基础版本。All：基础版本和补丁。 默认值：无                                       |
| BASICPKGVERSIONID | 基础软件包版本号 | 可选必选说明：条件必选参数，该参数在“UPDOBJECT”配置为“BaseSoftware” 或 “All”时为必选参数。 参数含义：该参数用于指定要加载的基础软件包版本号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 |
| PATCHPKGVERSIONID | 补丁版本号    | 可选必选说明：条件必选参数，该参数在“UPDOBJECT”配置为“All”时为必选参数。 参数含义：该参数用于指定要加载的补丁版本。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                      |
| RBTMODE           | 重启模式     | 可选必选说明：可选参数 参数含义：该参数用于指定允许的重启模式。 数据来源：本端规划 取值范围：枚举类型。 NO：不重启。SOFT：软重启，不需要重启资源。 默认值：NO                                           |
| SERVICEINSTANCE   | 服务实例     | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。                    |

#### 使用实例

回退升级操作：

```
RBK PACKAGE:UPDOBJECT=All,BASICPKGVERSIONID="V100R005C00B020",PATCHPKGVERSIONID="SPH0001",RBKTYPE=BASESOFTWARE,RBTMODE=SOFT,SERVICEINSTANCE="vnfc";
```
