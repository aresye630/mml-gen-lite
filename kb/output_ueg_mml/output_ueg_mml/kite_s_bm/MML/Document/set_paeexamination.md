# 设置PAE故障检测使能开关（SET PAEEXAMINATION）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于开启或关闭PAE故障检测功能。

PAE故障检测功能提供了转发线程死循环、通道过载、通道破坏、队列过载等检测能力。

使能PAE故障检测时，当PAE检测到故障后，会根据业务订阅的故障类型，将对应的故障上报给业务，同时PAE会根据故障恢复策略执行故障恢复。

在故障检测去使能的情况下，PAE不会对故障做检测。

建议保持该开关为默认的使能状态。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                  |
|:-----------|:-------|:--------------------------------------------------------------------------------------|
| ENABLEFLAG | 使能标志   | 可选必选说明：必选参数 参数含义：该参数用于开启和关闭故障检测功能。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：TRUE |

#### 使用实例

去使能PAE故障检测功能：

```
SET PAEEXAMINATION:ENABLEFLAG=FALSE;
```
