# 查询软件生命周期预警策略（LST SWLCALMPOLICY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询生命周期预警策略，包含预警开关及预警阈值。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询软件生命周期预警策略：

```
%%LST SWLCALMPOLICY:;%%
RETCODE = 0  操作成功 
 
操作结果如下
------------
        预警开关  =  开启
        预警阈值  =  270
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET SWLCALMPOLICY**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码列表如表1所示。

|   错误码 | 错误码解释          | 原因分析                  | 处理建议      |
|------:|:---------------|:----------------------|:----------|
|   500 | 系统内部错误，请联系管理员。 | 可能存在网络故障或者服务不可用等异常因素。 | 等待几分钟后重试。 |
