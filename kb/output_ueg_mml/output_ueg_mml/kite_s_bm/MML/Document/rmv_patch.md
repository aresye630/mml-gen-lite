# 删除补丁（RMV PATCH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

本命令属于高危命令，会删除系统补丁，涉及冷补丁时，会重启系统，请谨慎使用并联系华为技术支持协助操作。

该命令用于当系统中补丁存在问题时，删除系统补丁。

#### 注意事项

- 该命令执行后立即生效。
- 该命令会删除系统补丁，无补丁、已加载补丁，已激活补丁，执行该操作的结果都是成功。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                        |
|:----------------|:-------|:----------------------------------------------------------------------------------------------------------------------------|
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识，但不能填写0，0表示VNFP。 |

#### 使用实例

删除系统补丁：

```
RMV PATCH:SERVICEINSTANCE="vnfc";
```
