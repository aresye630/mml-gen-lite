# 设置PAE多队列功能开关（SET PAEMULTQUE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

如果修改该配置可能会造成业务流量损失，修改配置后需要复位对应的Pod。

该命令用于设置PAE多队列功能是否使能。

#### 注意事项

该命令为高危命令，如果修改该配置可能会造成业务流量损失，修改配置后需要复位对应的Pod。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组。

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                  |
|:-------|:-------|:------------------------------------------------------------------------------------------------------|
| ENABLE | 功能是否开启 | 可选必选说明：必选参数。 参数含义：该参数表示是否使能PAE多队列功能。 数据来源：本端规划。 取值范围：枚举类型。 disable：去使能。enable：使能。 默认值：enable。 配置原则：无。 |

#### 使用实例

开启PAE多队列功能：

```
%%SET PAEMULTQUE: ENABLE=enable;%%
RETCODE = 0  操作成功

---    END
```
