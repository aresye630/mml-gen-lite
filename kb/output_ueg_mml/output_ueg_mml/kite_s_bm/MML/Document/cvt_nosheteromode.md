# 转换NOS异构模式(CVT NOSHETEROMODE)

#### 命令功能

**须知** 

该命令属于高危命令，执行该命令会影响主备OMU的同步等功能，导致主备OMU的关键文件、软件包等存在差异，会对系统造成一定的影响，请谨慎使用。

该命令用来转换NOS异构模式。

该命令仅在Full-stack虚机场景下支持。

#### 注意事项

只有主备板CPU类型一致时，才能执行该命令。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称    | 参数说明                                                                                                                                |
|:----------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------|
| OMUHETEROSWITCH | OMU异构开关 | 可选必选说明：必选参数 参数含义：该参数表示OMU是否打开OMU异构开关。 数据来源：本端规划 取值范围：枚举类型。 On(打开)：OMU异构开关状态为打开。Off(关闭)：OMU异构开关状态为关闭。 默认值：无 配置原则：该参数系统初始值为“Off(关闭)”。 |
| SERVICEINSTANCE | 服务实例    | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。                        |

#### 使用实例

转换NOS异构模式：

```
CVT NOSHETEROMODE:OMUHETEROSWITCH=On,SERVICEINSTANCE="vnfc";
```
