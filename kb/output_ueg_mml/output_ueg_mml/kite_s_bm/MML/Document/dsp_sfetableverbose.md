# 按摘要和详情两种方式显示SFE表项信息（DSP SFETABLEVERBOSE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

按摘要和详情两种方式显示SFE的表项信息。

#### 注意事项

该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 使用实例

显示指定资源单元的SFE表详细信息：

```
DSP SFETABLEVERBOSE:RUNAME="VNODE_VNRS_VNFC_IPU_0066", TABLETYPE=VPN, VERBOSE=1;
```
