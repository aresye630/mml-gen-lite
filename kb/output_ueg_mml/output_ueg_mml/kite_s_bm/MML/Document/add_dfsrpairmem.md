# 增加双发选收结对成员配置（ADD DFSRPAIRMEM）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于新增双发选收结对成员IMSI。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为4096。
- 双发选收结对存在。
- 双发选收结对下成员数量最多2个。
- 如果此IMSI以IMSI方式配置在ADD MULTICASTSOURCE中，那么IMSI就不能配置为结对成员。
- IMSI绑定到双发选收结对时，如果结对已经绑定到了静态组播组，且绑定到双发选收结对中的IMSI和静态组播组中已绑定的IMSI重复，绑定失败。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                        |
|:-----------|:---------|:--------------------------------------------------------------------------------------------|
| DFSRPAIRID | 双发选收结对ID | 可选必选说明：必选参数 参数含义：该参数用于配置双发选收结对ID。 数据来源：本端规划 取值范围：整数类型，取值范围1-2048。 默认值：无 配置原则：无              |
| IMSI       | IMSI     | 可选必选说明：必选参数 参数含义：双发选收结对成员IMSI。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～15，每个字符必须为0~9的数字。 默认值：无 配置原则：无 |

#### 使用实例

向双发选收结对1中添加结对成员，imsi为460111111111111：

```
ADD DFSRPAIRMEM: DFSRPAIRID=1, IMSI="460111111111111";
```
