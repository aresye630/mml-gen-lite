# 修改MEP HTTP服务端（MOD MEPHTTPSERVER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

该命令用于修改MEP HTTP服务端。

#### 注意事项

- 该命令执行后立即生效。
- 如果本服务端已被关联至反向代理对象，修改会对关联本服务端的所有反向代理对象生效。
- 修改IP地址信息时，需确保修改后的IP地址在MPF逻辑接口信息中存在，可以通过LST MPFLOGICINF命令查询具体MPF逻辑接口信息。否则，修改MEP HTTP服务端命令会因IP地址不存在而下发失败。
- 当MPF逻辑接口由配置IPv4和IPv6变更为仅配置IPv4或者IPv6时，需要使用本命令将MEP HTTP服务端中的IP地址修改为新配置的IP地址。同时，需要在不再支持的“IPv4地址”或“IPv6地址”项处输入“0”清空原有配置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识               | 参数名称          | 参数说明                                                                                                                                                                                                                                                                   |
|:-------------------|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVERNAME         | MEP HTTP服务端名称 | 可选必选说明：必选参数 参数含义：该参数用于指定MEP HTTP服务端名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“.”组成，且只能以字母或者数字开头。 默认值：无 配置原则：无                                                                                                                                                 |
| MEPHTTPSERVERGRP   | MEP HTTP服务端组  | 可选必选说明：可选参数 参数含义：该参数用于指定本MEP HTTP服务端所属MEP HTTP服务端组的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则： 该参数使用ADD MEPHTTPSERVERGRP命令配置生成。输入单空格将删除该参数已有配置项。                                                                                                                 |
| IPV4               | IPv4地址        | 可选必选说明：可选参数 参数含义：该参数用于指定MEP HTTP服务端提供服务的IPv4地址。 数据来源：全网规划 取值范围：IPv4地址类型。0.0.0.0～255.255.255.255。 默认值：无 配置原则： 对于“FOR_EXTERNAL_NE”类型的MEP HTTP服务端而言IPV4和IPV6最少配置一个，地址配置必须通过运行ADD MPFLOGICINF命令来完成。其余场景不需要配置IP。输入“0”将删除该参数已有配置项。                                           |
| IPV6               | IPv6地址        | 可选必选说明：可选参数 参数含义：该参数用于指定MEP HTTP服务端提供服务的IPv6地址。 数据来源：全网规划 取值范围：IPv6地址类型。冒号分十六进制，格式为X:X:X:X:X:X:X:X。除了组播地址、链路本地地址、环回地址或未指定的地址为非法地址外，其他都为合法地址。 默认值：无 配置原则： 对于“FOR_EXTERNAL_NE”类型的MEP HTTP服务端而言IPV4和IPV6最少配置一个，地址配置必须通过运行ADD MPFLOGICINF命令来完成。其余场景不需要配置IP。输入0将删除该参数已有配置项。 |
| PORT               | 端口号           | 可选必选说明：可选参数 参数含义：该参数用于指定MEP HTTP服务端提供服务的端口号。 数据来源：本端规划 取值范围：当前仅支持配置为8443。 默认值：无 配置原则：当配置“FOR_EXTERNAL_NE”类型的MEP HTTP服务端时需要配置，其余场景不需要配置该参数。                                                                                                                             |
| TLSFLG             | 是否启用TLS       | 可选必选说明：可选参数 参数含义：该参数用于指定MEP HTTP服务端是否启用加密传输功能。 数据来源：对端协商 取值范围： ENABLE：使能TLS。DISABLE：不使能TLS。 默认值：无 配置原则：建议设置为ENABLE。如果设置为DISABLE，则报文将会以明文进行传输，存在信息泄露的风险，请谨慎设置。                                                                                                          |
| TLSPARANAME        | TLS参数名称       | 可选必选说明：条件必选参数 前提条件：该参数在“TLSFLG”配置为“ENABLE”时为必选参数。 参数含义：该参数用于指定MEP HTTP服务端所使用的TLS参数名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“.”组成，且只能以字母或者数字开头。 默认值：无 配置原则：该参数使用ADD MEPTLSPARA命令配置生成。                                                                         |
| SERVERCOMMPARANAME | HTTP服务端通信参数名称 | 可选必选说明：可选参数 参数含义：该参数用于指定本服务端所使用的HTTP服务端通信参数的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“.”组成，且只能以字母或者数字开头。 默认值：无 配置原则： 该参数使用ADD MEPSERVERCOMMPARA命令配置生成。输入单空格将删除该参数已有配置项。                                                                                      |

#### 使用实例

修改MEPHTTPSERVER对象，修改的MEPHTTPSERVER对象名称为"server"，隶属的服务端组名修改为"servergrp"，IPV4地址修改为"192.168.1.1"，服务端端口修改为"8443"，TLS参数是否使用修改为"ENABLE"，使用的TLS参数名修改为"tls"，修改HTTP服务端通信参数名称为"DefaultServerPara"：

```
MOD MEPHTTPSERVER: SERVERNAME="server", MEPHTTPSERVERGRP="servergrp", IPV4="192.168.1.1", PORT=8443, TLSFLG=ENABLE, TLSPARANAME="tls", SERVERCOMMPARANAME="DefaultServerPara";
```
