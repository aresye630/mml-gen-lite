# 查询API GW TLS配置（LST APIGWTLS）

- 注意事项

#### 命令功能

**适用NF：UPF、MPF**

该命令用于查询API GW支持的TLS版本。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询API GW server端TLS版本：

```
LST APIGWTLS:;
```

```
RETCODE = 0  操作成功

API GW的TLS版本为：
-------------------
TLS v1.2  =  使能
TLS v1.3  =  使能
(结果个数 = 1)

---    END
```
