# 查询容灾组信息（DSP LBGRGRP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询容灾组信息。

#### 注意事项

该命令批量下发可能导致执行超时。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                         |
|:----------|:-------|:-----------------------------------------------------------------------------|
| GRGROUPID | 容灾组ID  | 可选必选说明：可选参数 参数含义：该参数用于表示容灾组的标识。 数据来源：全网规划 取值范围：整数类型，取值范围为0~4294967295。 默认值：无 |

#### 使用实例

查询容灾组。

`DSP LBGRGRP:;`

```
%%DSP LBGRGRP:;%%
RETCODE = 0  操作成功。

操作结果如下：
--------------
  容灾组名称    =  gr_grp0
  容灾组ID     =  0
  容灾组优先级  =  100
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                                             |
|:--------|:--------------------------------------------------|
| 容灾组名称   | 参数含义：该参数用于表示容灾组的名称。 取值范围：字符串类型，输入长度范围为0~31。       |
| 容灾组ID   | 参数含义：该参数用于表示容灾组的标识。 取值范围：整数类型，取值范围为0~4294967295。  |
| 容灾组优先级  | 参数含义：该参数用于表示容灾组的优先级。 取值范围：整数类型，取值范围为0~4294967295。 |
