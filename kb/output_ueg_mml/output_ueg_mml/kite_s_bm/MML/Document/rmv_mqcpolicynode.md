# 删除流策略节点（RMV MQCPOLICYNODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于取消指定流分类在流策略中的使用。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                                              |
|:---------------|:-------|:------------------------------------------------------------------------------------------------------------------|
| POLICYNAME     | 策略名称   | 可选必选说明：必选参数 参数含义：指定流策略的名称，不允许为系统预定义策略default。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：区分大小写，不支持空格。           |
| CLASSIFIERNAME | 分类名称   | 可选必选说明：必选参数 参数含义：指定流分类的名称。类名不允许为系统预定义类的名称default-class。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：区分大小写，不支持空格。 |
| BEHAVIORNAME   | 行为名称   | 可选必选说明：必选参数 参数含义：指定流行为名称。定义的行为名不允许为系统预定义的流行为be。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：区分大小写，不支持空格。         |

#### 使用实例

取消流分类c1在流策略p1中的应用：

```
RMV MQCPOLICYNODE:POLICYNAME="p1",CLASSIFIERNAME="c1",BEHAVIORNAME="b1";
```
