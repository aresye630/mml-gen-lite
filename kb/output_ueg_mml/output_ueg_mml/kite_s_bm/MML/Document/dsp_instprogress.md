# 查询VNFC实例化进度(DSP INSTPROGRESS)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查看实例化进度。

#### 注意事项

- 实例化中，执行该命令，查到的进度有5%、10%、35%、50%、70%。
- 实例化完成后，执行该命令，查到的进度一直为100%。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                             |
|:----------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识，不支持对"VNFC类型名称"为VNFP、VNRS_VNFC、ACS、IPSEC_VNFC的RU状态查询。 |

#### 使用实例

显示当前实例化进度：

```
DSP INSTPROGRESS:SERVICEINSTANCE="CSLB_VNFC_999";
```

```
RETCODE = 0  操作成功。

结果如下
--------
VNFC实例化进度  =  70%
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称     | 输出项解释                                 |
|:----------|:--------------------------------------|
| VNFC实例化进度 | VNFC实例化进度。 取值范围：整数类型，取值范围为0～100，单位：%。 |
