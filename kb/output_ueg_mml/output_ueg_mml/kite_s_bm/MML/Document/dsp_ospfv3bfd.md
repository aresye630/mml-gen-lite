# 查询OSPFv3 BFD状态（DSP OSPFV3BFD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示OSPFv3 BFD信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                         |
|:------------|:----------|:---------------------------------------------------------------------------------------------|
| PROCID      | OSPFv3进程号 | 可选必选说明：可选参数 参数含义：OSPFv3进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无                     |
| NBRROUTERID | 邻居路由器标识   | 可选必选说明：可选参数 参数含义：邻居路由器标识。 数据来源：对端协商 取值范围：IPv4地址类型。点分十进制格式。 默认值：无                             |
| AREAID      | OSPFv3区域号 | 可选必选说明：可选参数 参数含义：OSPFv3区域号。 数据来源：全网规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无                           |
| IFNAME      | 接口名       | 可选必选说明：可选参数 参数含义：接口名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。 |

#### 使用实例

在设备上建立OSPFv3进程1，建立邻居并配置BFD，然后查询：

```
DSP OSPFV3BFD: PROCID=1;
```
