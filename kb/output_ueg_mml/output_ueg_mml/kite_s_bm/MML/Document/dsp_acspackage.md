# 显示系统软件信息（DSP ACSPACKAGE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示系统软件包的信息，如软件包类型、版本号和运行状态等。

本命令只适用于ACS服务，其他微服务请使用DSP PACKAGE命令。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                                                                                                                 |
|:--------------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PACKAGETYPE   | 包类型     | 可选必选说明：可选参数 参数含义：该参数用于表示包类型。 数据来源：本端规划 取值范围：枚举类型。 Version：软件版本包，包括基础版本包、冷补丁、热补丁等几种。RiskCheckPackage：风险排查包。AppPackage：App软件包。 默认值：无                                                                   |
| VERSIONTYPE   | 版本类型    | 可选必选说明：可选参数 参数含义：该参数用于表示版本类型。 数据来源：本端规划 取值范围：枚举类型。 BaseSoftware：包含网元或APP运行所需所有软件的全版本。ColdPatch：为网元或APP运行所需的部分软件，为对基础版本的补充，冷补丁不能独立运行，冷补丁升级往往会中断业务。HotPatch：为对基础版本或冷补丁的热补充，热补丁不能独立运行，热补丁升级不中断业务。 默认值：无 |
| VERSIONID     | 版本号     | 可选必选说明：可选参数 参数含义：该参数用于表示版本号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                                                                                                                                 |
| APPTYPE       | 版本应用类型  | 可选必选说明：可选参数 参数含义：该参数用于表示版本应用类型。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无                                                                                                                              |
| VERSIONSTATUS | 版本状态    | 可选必选说明：可选参数 参数含义：该参数用于表示版本状态。 数据来源：本端规划 取值范围：枚举类型。 Ready：软件包已准备好，可用。Prepared：软件包处于加载状态。Running：软件包处于运行状态。RunningAndPrepared：软件包处于运行和已加载状态。 默认值：无                                                     |
| CPUARCHTYPE   | CPU架构类型 | 可选必选说明：可选参数 参数含义：CPU架构类型。 数据来源：本端规划 取值范围：枚举类型。 X86：CPU架构类型是X86。ARM：CPU架构类型是ARM。Any：不区分CPU架构类型。 默认值：无                                                                                                 |
| BASEVERSIONID | 基础包版本号  | 可选必选说明：可选参数 参数含义：该参数用于描述基础版本号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                                                                                                                               |

#### 使用实例

显示系统软件包：

```
DSP ACSPACKAGE:;
```


#### 输出结果说明

| 输出项名称   | 输出项解释                                           |
|:--------|:------------------------------------------------|
| 包类型     | 表示包的类型，包括版本包，风险排查包和App软件包。                      |
| 版本类型    | 表示版本类型，包括基础版本、冷补丁、热补丁。                          |
| 版本号     | 表示软件包的版本号。                                      |
| 版本应用类型  | 表示版本应用类型。                                       |
| 版本状态    | 表示版本状态，包括可用、已加载、运行和运行&已加载。                      |
| CPU架构类型 | CPU架构类型包含“X86”、“ARM”和“Any”；其中“Any”表示不区分CPU架构类型。 |
| 基础版本号   | 表示软件包的基础版本号。                                    |
