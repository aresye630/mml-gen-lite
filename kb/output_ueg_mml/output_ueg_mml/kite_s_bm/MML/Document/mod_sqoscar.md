# 修改流行为CAR配置（MOD SQOSCAR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来修改流行为CAR配置。

#### 注意事项

该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

修改流行为的CAR配置：

```
MOD SQOSCAR:BEHAVIORNAME="b1",CIR=20,PIR=20,CBS=30,PBS=40,GREENACTION=remark,GREENSERVICECLASS=af1,GREENSERVICECOLOR=green,YELLOWACTION=remark,YELLOWSERVICECLASS=be,YELLOWSERVICECOLOR=green,REDACTION=remark,REDSERVICECLASS=af1,REDSERVICECOLOR=green;
```
