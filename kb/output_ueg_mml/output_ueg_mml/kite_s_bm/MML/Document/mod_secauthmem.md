# 修改二次授权命令（MOD SECAUTHMEM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

用于更新二次授权MML命令的提示信息。

#### 注意事项

- 网元ID必须在系统中存在。
- 命令名称和网元ID对应的MML命令必须存在。
- 该命令仅限具有Administrators角色的用户可以执行。在扩展域，仅限系统管理员可以执行。

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                         |
|:--------|:-------|:-------------------------------------------------------------|
| MEID    | 网元ID   | 可选必选说明：必选参数 参数含义：网元ID。 取值范围：0～65535。 默认值：无。 配置原则：无。          |
| COMMAND | 命令名称   | 可选必选说明：必选参数 参数含义：MML命令名称。 取值范围：长度不超过80的英文字符串。 默认值：无。 配置原则：无。 |
| TIPS    | 提示信息   | 可选必选说明：必选参数 参数含义：命令提示信息。 取值范围：长度不超过512字节字符串。 默认值：无。 配置原则：无。  |

#### 使用实例

修改二次授权的MML命令：

```
%%MOD SECAUTHMEM: MEID=0, COMMAND="LST ME", TIPS="提示";%%
RETCODE = 0  操作成功

---    END
```
