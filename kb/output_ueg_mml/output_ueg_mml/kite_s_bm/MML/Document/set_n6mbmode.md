# 配置N6mb接口数据传输的优选方式及端口范围（SET N6MBMODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

**须知** 

本命令属于高危命令，端口范围与已有端口冲突时可能导致端到端业务不通。

该命令用于配置N6mb接口的数据传输的优选方式及端口范围。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 只支持配置最大3000个端口号。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | MODE    |   UDPSTARTPORT |   UDPENDPORT |
|:-------|:--------|---------------:|-------------:|
| 初始值    | UNICAST |           1024 |         4023 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称            | 参数说明                                                                                                               |
|:-------------|:----------------|:-------------------------------------------------------------------------------------------------------------------|
| MODE         | N6mb接口数据传输的优选方式 | 可选必选说明：必选参数 参数含义：配置N6mb接口优选的传输方式。 数据来源：对端协商 取值范围：枚举类型。 UNICAST：N6mb接口优选单播传输方式。 默认值：无 配置原则：无                        |
| UDPSTARTPORT | 起始的UDP端口号       | 可选必选说明：条件必选参数 前提条件：该参数在“MODE”配置为“UNICAST”时为必选参数。 参数含义：起始的UDP端口号。 数据来源：本端规划 取值范围：整数类型，取值范围为1024～65535。 默认值：无 配置原则：无 |
| UDPENDPORT   | 结束的UDP端口号       | 可选必选说明：条件必选参数 前提条件：该参数在“MODE”配置为“UNICAST”时为必选参数。 参数含义：结束的UDP端口号。 数据来源：本端规划 取值范围：整数类型，取值范围为1024～65535。 默认值：无 配置原则：无 |

#### 使用实例

配置N6mb接口的数据传输优选方式为单播传输方式，起始端口号为1024，结束端口号为4023：

```
SET N6MBMODE: MODE=UNICAST, UDPSTARTPORT=1024, UDPENDPORT=4023;
```
