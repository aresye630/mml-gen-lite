# 查询VPN组（LST SQOSVPNGROUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询VPN组的信息。

#### 注意事项

该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                              |
|:-------------|:-------|:------------------------------------------------------------------------------------------------------------------|
| VPNGROUPNAME | VPN组名称 | 可选必选说明：必选参数 参数含义：该参数用于指定VPN组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无 配置原则：区分大小写，不支持空格。 |

#### 使用实例

查询VPN组的配置信息：

```
LST SQOSVPNGROUP:VPNGROUPNAME="vg1";
```

```
RETCODE = 0  操作成功。                                              
                                                                                
结果如下                                                        
------------------------                                                        
VPN组名称 = vg1
  VPN名称 = vpn1 
VPN优先级 = 1                                                              
(结果个数 = 1)                                                         
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                         |
|:--------|:------------------------------|
| VPN名称   | 用于指定VPN名称，若该组下没有VPN实例则显示NULL。 |
| VPN优先级  | 用于指定VPN优先级，若改组下没有VPN实例则显示0。   |

其余输出项请参见ADD SQOSVPNGROUP的参数说明。
