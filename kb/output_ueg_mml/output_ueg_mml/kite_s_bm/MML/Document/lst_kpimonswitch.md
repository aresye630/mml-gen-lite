# 查询KPI异常检测功能开关（LST KPIMONSWITCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询KPI异常检测功能开关。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询KPI异常检测功能开关状态。

```
%%LST KPIMONSWITCH:;%%
RETCODE = 0  操作成功

结果如下
--------
KPI异常检测开关  =  开启
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称     | 输出项解释             |
|:----------|:------------------|
| KPI异常检测开关 | 该参数用于指定KPI异常检测开关。 |
