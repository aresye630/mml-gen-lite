# 删除HTTPS证书检查功能配置（RMV AFHTTPSCTCK）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用来删除HTTPS证书检查功能的配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                 |
|:-------------|:-------|:---------------------------------------------------------------------------------------------------------------------|
| PROTOCOLNAME | 协议名称   | 可选必选说明：条件必选参数 前提条件：该参数在“CFGPROTMODE”配置为“SPECIFIC”时为必选参数。 参数含义：该参数用于设置协议名称。 数据来源：本端规划 取值范围：不支持空格，不区分大小写。 默认值：无 配置原则：无 |
| CFGPROTMODE  | 协议配置方式 | 可选必选说明：必选参数 参数含义：该参数用于设置HTTPS证书检查功能协议的配置方式。 数据来源：本端规划 取值范围： ALL：所有协议。SPECIFIC：指定协议。 默认值：无 配置原则：无                     |

#### 使用实例

- 删除所有协议的HTTPS证书检查功能配置：

  ```
  RMV AFHTTPSCTCK: CFGPROTMODE=ALL;
  ```
- 删除Facebook协议的HTTPS证书检查功能配置：

  ```
  RMV AFHTTPSCTCK: CFGPROTMODE=SPECIFIC, PROTOCOLNAME="facebook";
  ```
