# 查询证书到期提醒时间（LST REMINDTIME）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询系统内所有证书到期提醒时间。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询证书到期提醒时间。

```
%%LST REMINDTIME:;%% 
RETCODE = 0  操作成功 

操作结果如下
------------ 
证书到期提醒时间（天） =  44 
(结果个数 = 1)

  ---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息，输出结果说明如表1所示。

命令执行异常，请联系华为技术支持处理。输出结果说明如表2所示。

|:------------|:-------------|
| 证书到期提醒时间（天） | 证书到期提前多少天提醒。 |

|    错误码 | 错误码解释   | 原因分析    | 处理建议       |
|-------:|:--------|:--------|:-----------|
| 101025 | 服务执行失败  | 服务执行失败  | 请联系华为技术支持。 |
| 101099 | 数据库执行失败 | 数据库执行失败 | 请联系华为技术支持。 |
