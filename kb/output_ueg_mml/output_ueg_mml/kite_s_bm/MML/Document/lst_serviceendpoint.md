# 查询服务端点（LST SERVICEENDPOINT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF、MPF**

该命令用于查询服务端点。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                            |
|:-------------|:-------|:----------------------------------------------------------------------------------------------------------------|
| ENDPOINTNAME | 服务端点名称 | 可选必选说明：可选参数 参数含义：该参数用于指定服务端点名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“_”组成，且只能以字母或者数字开头。 默认值：无 配置原则：无 |

#### 使用实例

- 查询全部的SERVICEENDPOINT对象：

  ```
  LST SERVICEENDPOINT:;
  ```

  ```
  RETCODE = 0  操作成功

  服务端点
  --------
  服务端点名称  =  service_endpoint
    服务端点组  =  service_endpoint_grp
  服务端点类型  =  IPv4地址类型
      IPv4地址  =  192.168.1.1
      IPv6地址  =  ::
        端口号  =  8081
  (结果个数 = 1)

  ---    END
  ```
- 查询SERVICEENDPOINT对象，查询的SERVICEENDPOINT对象名称为"service\_endpoint"：

  ```
  LST SERVICEENDPOINT: ENDPOINTNAME="service_endpoint";
  ```

  ```
  RETCODE = 0  操作成功

  服务端点
  --------
  服务端点名称  =  service_endpoint
    服务端点组  =  service_endpoint_grp
  服务端点类型  =  IPv4地址类型
      IPv4地址  =  192.168.1.1
      IPv6地址  =  ::
        端口号  =  8081
  (结果个数 = 1)

  ---    END
  ```
