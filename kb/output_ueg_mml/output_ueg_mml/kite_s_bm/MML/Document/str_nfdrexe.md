# 启动人工执行容灾倒换（STR NFDREXE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，操作不当可能会误倒换网元，影响现网业务，请谨慎使用并联系华为技术支持协助操作。

该命令用于启动基于业务KPI的容灾倒换。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                          |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数  参数含义：该参数用于设置执行容灾倒换处理的网元ID。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~40。  默认值：无  配置原则：  可以通过MML命令LST ME获取。 |

## 使用实例

人工执行容灾倒换。

```
%%STR NFDREXE: MEID="0";%%
RETCODE = 0  操作成功

---    END
```
