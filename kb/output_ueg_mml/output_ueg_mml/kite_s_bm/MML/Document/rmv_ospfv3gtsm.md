# 删除OSPFv3 GTSM配置（RMV OSPFV3GTSM）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于用来去使能OSPFv3 GTSM特性。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                           |
|:--------|:-------|:-------------------------------------------------------------------------------|
| VRFNAME | VPN实例名 | 可选必选说明：必选参数 参数含义：VPN实例名。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：默认为公网配置。 |

#### 使用实例

去使能OSPFv3 GTSM功能：

```
RMV OSPFV3GTSM:VRFNAME="abc";
```
