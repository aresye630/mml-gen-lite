# 查询静态路由迭代隧道功能开关（LST SRROUTERELAYTUNNEL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询静态路由迭代隧道功能开关。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询静态路由迭代隧道功能开关：

```
LST SRROUTERELAYTUNNEL:;
```

```
RETCODE = 0  操作成功.
结果如下
------------------------
    迭代隧道使能开关 =  TRUE
          前缀列表名 =  NULL
         隧道策略名  =  tp
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见SET SRROUTERELAYTUNNEL的参数说明。
