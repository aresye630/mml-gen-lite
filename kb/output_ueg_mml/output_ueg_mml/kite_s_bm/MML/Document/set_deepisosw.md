# 设置转发线程深度隔离开关（SET DEEPISOSW）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

**须知** 

本命令属于高危命令，转发线程深度隔离功能会修改转发线程的调度方式，影响系统的CPU占用率。

该命令用于设置转发线程深度隔离开关。

#### 注意事项

- 该命令执行后需要重新启动系统才能生效。
- 该命令最大记录数为1。
- 该转发线程深度度隔离功能仅用于ARM硬件，E9000H-2，裸机形态的UEG-S。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | SWITCH   |
|:-------|:---------|
| 初始值    | DISABLE  |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                         |
|:-------|:-----------|:---------------------------------------------------------------------------------------------|
| SWITCH | 转发线程深度隔离开关 | 可选必选说明：必选参数 参数含义：该参数用于设置转发线程深度隔离开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无 |

#### 使用实例

打开转发线程深度隔离功能开关：

```
SET DEEPISOSW: SWITCH=ENABLE;
```
