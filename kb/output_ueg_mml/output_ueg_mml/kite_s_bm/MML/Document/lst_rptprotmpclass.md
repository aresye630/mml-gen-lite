# 查询业务报表映射承载协议分类配置（LST RPTPROTMPCLASS）

- 命令功能
- 注意事项
- 操作用户权限

- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询业务报表映射承载协议分类信息。当运营商希望查询业务报表映射承载协议分类信息时，则执行该命令。

#### 注意事项

如果不输入映射承载协议分类名称，则查询系统所有配置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识           | 参数名称       | 参数说明                                                                                            |
|:---------------|:-----------|:------------------------------------------------------------------------------------------------|
| MPPROTCLASSNM  | 映射承载协议分类名称 | 可选必选说明：可选参数 参数含义：该参数用于设置映射承载协议分类名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |
| MPPROTCLASSIDX | 映射承载协议分类索引 | 可选必选说明：可选参数 参数含义：该参数用于设置映射承载协议分类索引。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无 配置原则：无              |

#### 使用实例

假如运营商需要查询业务报表映射承载协议分类信息：

```
LST RPTPROTMPCLASS:;
```

```
RETCODE = 0  操作成功。

业务报表映射承载协议分类信息：
--------------------
映射承载协议分类名称    映射承载协议分类索引
p2p                     20
(结果个数 = 1)
---    END
```
