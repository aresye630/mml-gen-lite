# 查询ARP静态黑名单（LST ARPSTATICBLACKLIST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询ARP静态黑名单。

当设备上创建了ARP静态黑名单，可用该命令查询已创建的ARP静态黑名单信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                              |
|:--------|:-------|:--------------------------------------------------------------------------------------------------|
| IPADDR  | IP地址   | 可选必选说明：可选参数 参数含义：该参数用于指定ARP静态黑名单的IP地址。 数据来源：本端规划 取值范围：IPv4地址类型。IP地址0.0.0.0～255.255.255.255。 默认值：无 |
| MACADDR | MAC地址  | 可选必选说明：可选参数 参数含义：该参数用于指定ARP静态黑名单的MAC地址。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～48。 默认值：无                   |

#### 使用实例

不指定参数时，查询VNFC上所有ARP静态黑名单：

```
LST ARPSTATICBLACKLIST:;
```

```
RETCODE = 0  操作成功。

结果如下
--------
 IP地址  =  10.1.1.2
MAC地址  =  00E0-FC12-3456
(结果个数 = 1)
---    END
```

|:--------|:-----------------------|

| MAC地址   | 该参数用于指定ARP静态黑名单的MAC地址。 |
