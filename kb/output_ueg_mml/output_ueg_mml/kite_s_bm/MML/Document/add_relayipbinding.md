# 增加媒体中继服务IP绑定配置（ADD RELAYIPBINDING）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、PGW-U**

该命令用于增加媒体中继服务IP配置和媒体中继模板名称的绑定关系。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为10。
- 每个媒体中继模板仅支持绑定两个媒体中继IP地址信息。
- 每个媒体中继IP地址信息仅支持被一个媒体中继模板绑定。
- 每个媒体中继模板不支持绑定VPN相同的两个媒体中继IP地址信息。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称       | 参数说明                                                                                                                                                                  |
|:--------------|:-----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RELAYTPLNAME  | 媒体中继模板名称   | 可选必选说明：必选参数 参数含义：该参数用于表示媒体中继模板名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数使用ADD RELAYTEMPLATE命令配置生成。配置时需要确保RELAYTPLNAME已经配置（ADD RELAYTEMPLATE）。 |
| RELAYIPNAME   | 媒体中继IP地址名称 | 可选必选说明：必选参数 参数含义：该参数用于表示媒体中继服务IP配置。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数使用ADD RELAYIPINFO命令配置生成。配置时需要确保RELAYIPNAME已经配置（ADD RELAYIPINFO）。    |
| CFGDOMAINNAME | 配置域名称      | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。                                                                    |

#### 使用实例

增加服务IP配置为testIP，模板名为test的绑定关系：

```
ADD RELAYIPBINDING: RELAYIPNAME="testIP", RELAYTPLNAME="test";
```
