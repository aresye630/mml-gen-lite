# 上传跟踪本地文件（ULD TRACELOCFILE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

**须知** 

本命令属于高危命令，命令执行成功会将FileSver已经存在的文件删除

该命令用于上传指定pod下用户跟踪存盘文件到文件服务器上。

#### 注意事项

- 该命令执行后立即生效。
- 使用ULD命令时需要去掉末尾分片标识与“.zip”等后缀。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                    |
|:------------|:-------|:----------------------------------------------------------------------------------------|
| PODNAMEACT  | POD名称  | 可选必选说明：必选参数 参数含义：POD名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：无      |
| FILENAMEACT | 文件名    | 可选必选说明：必选参数 参数含义：文件名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～255。不支持空格，区分大小写。 默认值：无 配置原则：无       |
| FILESTARTNO | 文件起始序号 | 可选必选说明：必选参数 参数含义：文件起始序号。 数据来源：本端规划 取值范围：1~4294967295。 默认值：无 配置原则：无                      |
| FILEENDNO   | 文件结束序号 | 可选必选说明：可选参数 参数含义：文件结束序号。 数据来源：本端规划 取值范围：1~4294967295。 默认值：无 配置原则：结束序号和开始序号之差不能大于或者等于50。 |

#### 使用实例

上传ssgpod-0的user\_trace\_20210918-163654\_part2.zip文件和user\_trace\_20210918-163654\_part3.zip文件到文件服务器上：

```
ULD TRACELOCFILE: PODNAMEACT="ssgpod-0", FILENAMEACT="user_trace_20210918-163654", FILESTARTNO=2, FILEENDNO=3;
```
