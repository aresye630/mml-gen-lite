# 删除本地地址池中冲突IPv4地址（RMV CONFLICTIP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于在某个本地地址池中取消指定IPv4地址或所有IPv4地址的冲突状态。

#### 注意事项

- 该命令执行后只对新激活用户生效。
- 设备地址不再和系统上配置的地址池中地址冲突时，需要使用RMV CONFLICTIP命令取消被设置地址的冲突状态。不使用的设备地址允许分配给终端用户，避免造成地址浪费。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                                        |
|:----------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
| POOLNAME  | 地址池名称    | 可选必选说明：必选参数 参数含义：该参数用于指定地址池的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～79，单位是字节。由“_”、“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”，不区分大小写。 默认值：无 配置原则：该参数使用ADD POOL命令配置生成。 |
| IPADDRESS | 冲突IPv4地址 | 可选必选说明：可选参数 参数含义：该参数用于指定冲突IPv4地址。 数据来源：全网规划 取值范围：IPv4地址类型。 默认值：无 配置原则：无                                                                                     |

#### 使用实例

在本地地址池lap删除指定地址的冲突状态，POOLNAME为“lap”，IPADDRESS为“10.1.1.1”：

```
RMV CONFLICTIP:POOLNAME="lap",IPADDRESS="10.1.1.1";
```
