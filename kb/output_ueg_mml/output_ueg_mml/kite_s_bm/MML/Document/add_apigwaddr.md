# 新增API GW地址（ADD APIGWADDR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

**须知** 

本命令属于高危命令，执行该命令后，会修改API GW的访问地址，请确认配置的IP地址是正确规划的地址。

该命令仅在使用主机型网络时，配置API GW的IP地址。建议使用MPF逻辑接口配置，MPF逻辑接口配置要求按照路由型网络组网。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为2。
- 使用本命令配置主机型网络时，如果提示“已配置MPF逻辑接口配置，建议使用路由型组网”，请使用LST MPFLOGICINF命令查询并使用MOD MPFLOGICINF命令修改IP地址配置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称              | 参数说明                                                                                                                       |
|:--------------|:------------------|:---------------------------------------------------------------------------------------------------------------------------|
| ADDRESSTYPE   | 访问地址类型            | 可选必选说明：必选参数 参数含义：API GW 主机型访问地址IP类型。 数据来源：本端规划 取值范围：枚举类型。 IPv4：API GW主机型网络地址类型为IPv4。IPv6：API GW主机型网络为IPv6。 默认值：无 配置原则：无    |
| APIGWIPV4ADDR | API GW IPv4地址     | 可选必选说明：条件必选参数 前提条件：该参数在“ADDRESSTYPE”配置为“IPv4”时为必选参数。 参数含义：API GW使用主机型网络时的地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无 配置原则：无         |
| APIGWIPV4GW   | API GW IPv4网关     | 可选必选说明：条件必选参数 前提条件：该参数在“ADDRESSTYPE”配置为“IPv4”时为必选参数。 参数含义：API GW 使用主机型网络时IPv4默认网关地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无 配置原则：无 |
| APIGWIPV6ADDR | API GW IPv6地址     | 可选必选说明：条件必选参数 前提条件：该参数在“ADDRESSTYPE”配置为“IPv6”时为必选参数。 参数含义：API GW使用主机型网络时的IPv6地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无 配置原则：无     |
| APIGWIPV6GW   | API GW IPv6网关     | 可选必选说明：条件必选参数 前提条件：该参数在“ADDRESSTYPE”配置为“IPv6”时为必选参数。 参数含义：API GW 使用主机型网络时IPv6默认网关地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无 配置原则：无 |
| APIGWNETMASK  | API GW IPv4掩码地址   | 可选必选说明：条件必选参数 前提条件：该参数在“ADDRESSTYPE”配置为“IPv4”时为必选参数。 参数含义：API GW使用主机型网络时的IPv4掩码地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无 配置原则：无   |
| APIGWPREFIX   | API GW IPv6地址掩码长度 | 可选必选说明：条件必选参数 前提条件：该参数在“ADDRESSTYPE”配置为“IPv6”时为必选参数。 参数含义：API GW IPv6地址掩码长度。 数据来源：本端规划 取值范围：整数类型，取值范围为1～128。 默认值：无 配置原则：无  |

#### 使用实例

配置IPv4地址为10.0.0.2，网关地址为10.0.0.1：

```
ADD APIGWADDR: ADDRESSTYPE=IPv4, APIGWIPV4ADDR="10.0.0.2", APIGWIPV4GW="10.0.0.1", APIGWNETMASK="255.0.0.0";
```
