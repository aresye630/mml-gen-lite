# 显示FES对账信息（DSP FESVERIFICATION）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示FES对账信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                             |
|:-------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IDENTITYFLAG | 身份标志位  | 可选必选说明：可选参数 参数含义：该参数用于表示身份标志位。 数据来源：本端规划 取值范围：枚举类型。 RUNAME：表示输入资源单元名称。COMPID：表示输入组件ID。 默认值：无                                                                     |
| COMPONENTID  | 组件ID   | 可选必选说明：条件必选参数 前提条件：该参数在“IDENTITYFLAG”配置为“COMPID”时为必选参数。 参数含义：该参数用来表示组件ID。 数据来源：本端规划 取值范围：十六进制整数类型，取值范围为0x0～0xFFFFFFFF。 默认值：无                                     |
| RUNAME       | 资源单元名称 | 可选必选说明：条件必选参数 前提条件：该参数在“IDENTITYFLAG”配置为“RUNAME”时为必选参数。 参数含义：该参数用来表示资源单元名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：区分大小写，不支持空格，下发本MML命令前可使用DSP RU查看资源单元信息。 |

#### 使用实例

显示FES对账信息：

```
DSP FESVERIFICATION:;
```

```
RETCODE = 0 操作成功

结果如下
-------------------------
对账时间间隔（s） =  3600
上一次慢对账时间  =  2017-09-30 05:33:02
下一次慢对账时间  =  2017-09-30 06:33:02
(结果个数 = 1)
---    END
```

| 输出项名称     | 输出项解释         |
|:----------|:--------------|
| 对账时间间隔（s） | 用来表示对账时间间隔。   |
| 上一次慢对账时间  | 用来表示上一次慢对账时间。 |
| 下一次慢对账时间  | 用来表示下一次慢对账时间。 |
