# 查询APN防欺诈功能（LST APNAFFUNC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

此命令用于查询指定APN下的防欺诈开关配置信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                               |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN    | APN    | 可选必选说明：必选参数 参数含义：该参数用于指定APN的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”特殊字符，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

假如运营商需要查询APN为“abc”的防欺诈功能配置，则命令如下：

```
LST APNAFFUNC:APN="abc";
```

```
RETCODE = 0  操作成功。

APN防欺诈功能信息
-----------------
       APN  =  abc
防欺诈开关  =  使能
(结果个数 = 1)
---    END
```
