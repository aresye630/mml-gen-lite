# 查询UE Ping逻辑接口开关（LST UEPINGINF）

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于查询UE ping逻辑口的开关状态。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询UE ping逻辑口的开关状态：

```
LST UEPINGINF:;
```

```
RETCODE = 0  操作成功。

UE Ping逻辑接口开关
-------------------
Ping开关  =  使能
(结果个数 = 1)
---    END
```

#### 输出结果说明

参见SET UEPINGINF的参数说明。
