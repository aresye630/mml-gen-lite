# 显示路由策略信息（DSP ROUTEPOLICYINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示路由策略的基本信息。包括匹配计数信息的显示。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                      |
|:-----------|:-------|:--------------------------------------------------------------------------|
| POLICYNAME | 路由策略名字 | 可选必选说明：可选参数 参数含义：该参数用来指定路由策略的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无 |

#### 使用实例

显示路由策略基本信息：

```
DSP ROUTEPOLICYINFO:;
```

```
RETCODE = 0  操作成功

结果如下
-------------------------

```

#### 输出结果说明

| 输出项名称    | 输出项解释              |
|:---------|:-------------------|
| 路由策略节点号  | 用来指定路由策略的节点序列号。    |
| 匹配模式     | 用来指定路由策略的匹配模式。     |
| 路由策略名字   | 用来指定路由策略的名称。       |
| 路由策略节点描述 | 用来指定路由策略节点的描述信息。   |
| 匹配路由数    | 用来指定当前路由策略匹配的路由数量。 |
| 路由策略类型   | 用来指定路由策略的类型。       |
| 引用计数     | 用来表示路由策略被引用的计数。    |
