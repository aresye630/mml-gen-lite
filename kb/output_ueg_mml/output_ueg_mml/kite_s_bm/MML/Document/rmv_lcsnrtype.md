# 删除基站类型配置（RMV LCSNRTYPE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

删除基站类型配置。

#### 注意事项

- 执行该命令后，重新发起的定位请求才会用到修改后的参数值。
- 不填参数时，会批量删除所有配置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称    | 参数说明                                                                                          |
|:----------------|:--------|:----------------------------------------------------------------------------------------------|
| GNODEBIDSEGNAME | 基站标识段名称 | 可选必选说明：可选参数 参数含义：该参数用于指定基站标识段名称。 数据来源：本端规划 取值范围：字符串类型，不区分大小写，不能包含空格，输入长度范围为1～31。 默认值：无 配置原则：无 |

#### 使用实例

删除基站类型配置：

```
RMV LCSNRTYPE: GNODEBIDSEGNAME="client1";
```
