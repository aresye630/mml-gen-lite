# 删除OSPFv3接口认证配置（RMV OSPFV3INTERFACEAUTH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除OSPFv3接口上所使用的验证模式及验证口令。

#### 注意事项

- 该命令执行后立即生效。
- 删除OSPFv3接口认证，请确保和邻居认证配置相同，否则会导致邻接关系中断，影响业务。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                         |
|:-----------|:----------|:---------------------------------------------------------------------------------------------|
| PROCID     | OSPFv3进程号 | 可选必选说明：必选参数 参数含义：OSPFv3进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无                     |
| AREAID     | OSPFv3区域号 | 可选必选说明：必选参数 参数含义：OSPFv3区域号。 数据来源：对端协商 取值范围：IPv4地址类型。点分十进制格式。 默认值：无                           |
| IFNAME     | 接口名       | 可选必选说明：必选参数 参数含义：接口名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。 |
| INSTANCEID | 实例号       | 可选必选说明：必选参数 参数含义：实例号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～255。 默认值：无                                  |

#### 使用实例

删除接口Ethernet64/0/3下OSPFv3 HMAC-SHA256验证模式：

```
RMV OSPFV3INTERFACEAUTH:PROCID=1,AREAID="0.0.0.0",IFNAME="Ethernet64/0/3",INSTANCEID=0;
```
