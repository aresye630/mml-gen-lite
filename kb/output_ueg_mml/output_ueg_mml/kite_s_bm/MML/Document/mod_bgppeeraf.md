# 修改BGP对等体地址族（MOD BGPPEERAF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改相应BGP IPv4或IPv6对等体地址族。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

- 修改相应BGP IPv4对等体地址族：

  ```
  MOD BGPPEERAF:VRFNAME="_public_",AFTYPE=ipv4uni,REMOTEADDRESS="10.2.2.2",ALLOWASLOOPENABLE=FALSE;
  MOD BGPPEERAF:VRFNAME="vrf1",AFTYPE=ipv4uni,REMOTEADDRESS="10.2.2.2",DEFAULTRTADVENABLE=TRUE;
  ```
- 修改相应BGP IPv6对等体地址族：

  ```
  MOD BGPPEERAF:VRFNAME="_public_",AFTYPE=ipv6uni,ADDRESSTYPE=ipv6,REMOTEADDRESSV6="2001:db8:1:1:1:1:1:1",ALLOWASLOOPENABLE=FALSE;
  MOD BGPPEERAF:VRFNAME="_public_",AFTYPE=ipv6uni,ADDRESSTYPE=ipv6,REMOTEADDRESSV6="2001:db8:1:1:1:1:1:1",DEFAULTRTADVENABLE=TRUE;
  ```
