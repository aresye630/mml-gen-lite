# 查询基于NG-RAN的TRP开关（LST LCSTRPNRSW）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：LMF**

该命令用于查询显示基于NG-RAN的TRP开关配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称    | 参数说明                                                                                          |
|:----------------|:--------|:----------------------------------------------------------------------------------------------|
| GNODEBIDSEGNAME | 基站标识段名称 | 可选必选说明：可选参数 参数含义：该参数用于指定基站标识段名称。 数据来源：本端规划 取值范围：字符串类型，不区分大小写，不能包含空格，输入长度范围为1～31。 默认值：无 配置原则：无 |

#### 使用实例

查询显示基于NG-RAN的TRP开关配置：

```
LST LCSTRPNRSW: GNODEBIDSEGNAME="seg1";
```

