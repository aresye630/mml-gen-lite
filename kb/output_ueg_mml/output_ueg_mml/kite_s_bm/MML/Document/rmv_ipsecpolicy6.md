# 删除IPsec IPv6策略（RMV IPSECPOLICY6）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

删除IPsec Ipv6策略，影响业务流量使用IPSEC进行加解密功能，有业务影响。

该命令用于删除IPsec Ipv6策略。

## 注意事项

- 该命令执行后立即生效。

- 当IPsec策略被IPsec隧道引用时，IPsec策略不能被删除。如果需要删除IPsec策略，必须先删除IPsec策略的引用。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                                                                                 |
|:---------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
| POLICYNAME     | 策略名称   | 可选必选说明：必选参数  参数含义：策略名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~15。不区分大小写。  默认值：无  配置原则：无                                                                     |
| SEQUENCENUMBER | 序列号    | 可选必选说明：必选参数  参数含义：序列号。  数据来源：对端协商  取值范围：整数类型，取值范围是1~10000。  默认值：无  配置原则：无                                                                            |
| POLICYMODE     | 策略模式   | 可选必选说明：必选参数  参数含义：该参数用于指定策略模式。  数据来源：对端协商 取值范围： “Isakmp（ISAKMP模式）”：使用IKE建立IPsec安全联盟的模式  默认值：无  配置原则：无                                                |
| TEMPLATEMODE   | 模板模式   | 可选必选说明：必选参数  参数含义：模板模式-绑定一个策略模板到ISAKMP（使用策略模板建立IPsec安全联盟）。  数据来源：对端协商 取值范围： None（无）“PolicyTemplate（策略模板模式）”：使用策略模板模式创建策略，仅支持用户级IPsec。  默认值：无  配置原则：无 |

## 使用实例

删除策略名称为“pol2”，序列号为1，策略模式为“Isakmp”，模板模式为“None”的IPsec Ipv6策略：

```
RMV IPSECPOLICY6:POLICYNAME="pol2",SEQUENCENUMBER=1,POLICYMODE=Isakmp,TEMPLATEMODE=None;
```
