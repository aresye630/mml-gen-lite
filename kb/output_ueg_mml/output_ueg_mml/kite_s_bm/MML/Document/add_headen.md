# 增加头增强（ADD HEADEN）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于添加头增强的相关配置。配置头增强功能，可以将用户相关信息插入协议头部，传递给Web服务器，Web服务器获取到这些信息以后可以用于结算、折扣、提示等，便于灵活开展业务。

#### 注意事项

- 该命令执行后立即生效。
- 整机最多支持100个不同名称的头增强的实例配置。
- 整机最多支持500个HeadEn前缀字段的命令配置。
- 整机最多支持对32个不同前缀字段名称的头增强插入项启动防欺诈检测。
- 单个报文最多支持16个不同前缀字段名称的头增强插入防欺诈检测。
- 如果使用头增强功能，所有报文都需要进行SA处理，对系统性能造成影响。
- 头增强防欺诈检测开启后，系统会增加报文内容的检测和修正处理，因此会增加系统处理开销，需要根据现网实际使用情况决定是否通过ANTIFRAUD参数开启头增强插入字段的防欺诈检测。
- 当前只有MSISDN、IMSI、IMEI和MSIP数据类型支持加密算法配置为RSA3072、RSA2048或者RSA1024。
- 同一头增强名称最多可以配置40种不同的数据类型。
- EncryAlgori、PswdKey、PswdKeyConfirm、SaltSW等和加密算法及编码相关的参数需要和对端服务器协商。
- ParaDataType1、ParaDataType2、ParaDataType3不能同时设置为NONE，并且任意两个不能设置为非NONE的相同值。
- 如果用户使用的APN在UPF上没有配置，则不支持插入APN类型的字段。
- 当用户RAT类型为NR时，不支持插入SGSNIP类型的字段。
- 如果配置头增强插入BILLINGTYPE字段，需要SMF设置SET PFCPPVTEXT: FEATURE=CHARGING\_TYPE, SWITCH=ENABLE;
- 如果配置头增强插入SESSIONID字段，需要SMF设置SET PFCPPVTEXT: FEATURE=AUTH\_CLASS, SWITCH=ENABLE;
- 如果配置头增强插入USERPROFALIAS字段，插入的总字符长度超过HEADERFLDLEN配置值，则超过总字符长度的用户模板别名信息不做头增强插入处理;

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

假如运营商希望头增强支持插入MSISDN，前缀名称为TEST，防欺诈功能不开启，选择AES128加密方式，加密模式为CBC，密钥为XXXXXX：

```
ADD HEADEN:HEADERENNAME="headen1",DATATYPE=MSISDN1,PREFIXNAME="TEST",ENCRYALGORI=AES128,PSWDKEY="******",PSWDKEYCONFIRM="******",ANTIFRAUD=DISABLE;
```
