# 显示UPF信息（LST UPFINFO）

#### 命令功能

**适用NF：MPF**

该命令用于显示当前MPF对接的UPF配置信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                   |
|:--------|:-------|:-----------------------------------------------------------------------|
| UPFNAME | UPF名称  | 可选必选说明：可选参数 参数含义：UPF名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无 |

#### 使用实例

- 显示MPF对接的所有UPF的配置信息：

  ```
  LST UPFINFO:;
  ```

  ```
  RETCODE = 0  操作成功

  UPF信息
  --------------------
  UPF名称     IP地址类型  UPF IPv4地址  UPF IPv6地址          

  isp.upf001  IPV4        10.1.1.1      ::                    
  isp.upf002  IPV6        0.0.0.0       FC00::1  
  (结果个数 = 2)

  ---    END
  ```
- 显示MPF对接的名称为isp.upf001的UPF配置信息：

  ```
  LST UPFINFO: UPFNAME="isp.upf001";
  ```

  ```
  RETCODE = 0  操作成功

  UPF信息
  -------
       UPF名称  =  isp.upf001
    IP地址类型  =  IPV4
  UPF IPv4地址  =  10.1.1.1
  UPF IPv6地址  =  ::
  (结果个数 = 1)

  ---    END
  ```
