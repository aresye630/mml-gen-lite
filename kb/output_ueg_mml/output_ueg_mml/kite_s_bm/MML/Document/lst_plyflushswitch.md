# 查询集合类型策略刷新开关状态（LST PLYFLUSHSWITCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询集合类型策略刷新开关状态和刷新周期。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

无

## 使用实例

查询集合类型策略刷新开关和周期。

```
%%LST PLYFLUSHSWITCH:;%%
RETCODE = 0  操作成功

结果如下
------------------------
       集合类型策略刷新开关  =  打开集合类型策略刷新开关
集合类型策略刷新周期 (分钟)  =  1440
(结果个数 = 1)

---    结束
```

## 输出结果说明

| 输出项名称           | 输出项解释                               |
|:----------------|:------------------------------------|
| 集合类型策略刷新开关      | 该参数用于设置是否开启集合类型策略刷新，ON表示开启，OFF表示关闭。 |
| 集合类型策略刷新周期 (分钟) | 该参数用于设置集合类型策略刷新周期，单位分钟。             |
