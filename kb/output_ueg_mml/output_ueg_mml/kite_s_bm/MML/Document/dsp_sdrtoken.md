# 查询SDRC中的TOKEN信息（DSP SDRTOKEN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询SDRC中指定AppType的TOKEN策略信息。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                         |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------|
| APPTYPE | App类型  | 可选必选说明：必选参数  参数含义：该参数用于表示该Token所归属业务的类型，可通过DSP SDRPOLICYKEYS: POLICYTYPE=Token;命令获取。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无 |

## 使用实例

使用如下命令查询SDRC中缓存的token策略信息：

```
%%DSP SDRTOKEN: APPTYPE=1035;%%
RETCODE = 0  操作成功

结果如下
--------
根令牌ID  主实例ID              新主实例ID            令牌组  下一跳组ID  App类型  多进程模式  内部进程号  外部进程号

0         13568649970415061474  13568649970415061474     0      0          1035       0            0           0
1         13568649970415061474  13568649970415061474     0      0          1035       0            0           0
(结果个数 = 2)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                                              |
|:--------|:-------------------------------------------------------------------|
| 根令牌ID   | 该参数用于表示TOKEN策略的根令牌ID。                                              |
| 主实例ID   | 该参数用于表示TOKEN策略的主实例ID。                                              |
| 新主实例ID  | 该参数用于表示TOKEN策略的新主实例ID。                                             |
| 令牌组     | 该参数用于表示TOKEN策略的令牌组。                                                |
| 下一跳组ID  | 该参数用于表示TOKEN策略的下一跳组id。                                             |
| App类型   | 该参数用于表示该Token所归属业务的类型，可通过DSP SDRPOLICYKEYS: POLICYTYPE=Token;命令获取。 |
| 多进程模式   | 该参数用于表示Token是否属于多进程模式。                                             |
| 内部进程号   | 该参数用于表示Token对应的内部通信进程号。                                            |
| 外部进程号   | 该参数用于表示Token对应的外部通信进程号。                                            |
