# 设置惯性运行/应急接入授权时长（SET EMERGAUTHTIMER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于设置惯性运行和应急接入持续时长，防止用户长期在园区以惯性/应急接入状态运行。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 当前园区系统存在两套自运行授权配置，分别为SET EMERGAUTHTIMER和SET EDGEAMSELFRUNAUTH，用于设置园区自运行的持续时长，避免用户长期在园区接入运行。其中SET EMERGAUTHTIMER适用于风筝M，园区UPF与大网SMF断链，且用户从应急SMF接入的场景，授权时长控制点主要在UPF。SET EDGEAMSELFRUNAUTH适用于风筝L，园区AMF与大网UDM断链，且用户从应急UDM接入的场景，授权时长控制点主要在AMF。请根据网络布局设计对应的配置。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | SWITCH   |   HOURS |
|:-------|:---------|--------:|
| 初始值    | ENABLE   |    1024 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称          | 参数说明                                                                                                                                                                                               |
|:-------|:--------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SWITCH | 惯性运行/应急接入授权开关 | 可选必选说明：必选参数 参数含义：该参数用于设置惯性运行/应急接入授权开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：如果参数设置为ENABLE，表示开启自运行授权配置开关，超过授权时长，系统拒绝从应急SMF接入的用户。如果参数设置为DISABLE，表示关闭自运行授权开关，此时新用户均可以在应急SMF接入并持续运行。 |
| HOURS  | 小时            | 可选必选说明：条件必选参数 前提条件：该参数在“SWITCH”配置为“ENABLE”时为必选参数。 参数含义：惯性运行/应急接入授权时长。 数据来源：本端规划 取值范围：整数类型，取值范围为1～1024。 默认值：无 配置原则：与运营商协商在园区与中心网络的传输中断时允许园区新用户应急接入的授权时长。                                            |

#### 使用实例

配置使能惯性运行/应急接入授权功能，授权时长为1小时：

```
SET EMERGAUTHTIMER: SWITCH=ENABLE, HOURS=1;
```
