# 清除端口流量策略报文统计（RTR SQOSPOLICYSTC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来清除端口流量策略报文统计。

#### 注意事项

该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                  |
|:----------|:-------|:----------------------------------------------------------------------------------------------------------------------|
| IFNAME    | 接口名称   | 可选必选说明：必选参数 参数含义：该参数用来指定接口。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：与设备接口名称保持一致，下发本MML命令前可使用LST INTERFACE查看设备接口。 |
| DIRECTION | 方向     | 可选必选说明：必选参数 参数含义：该参数用来指定应用流策略的方向。 数据来源：本端规划 取值范围：枚举类型。 inbound：入方向。outbound：出方向。 默认值：无                                |

#### 使用实例

清除Ethernet66/0/2端口流量策略报文统计：

```
RTR SQOSPOLICYSTC:IFNAME="Ethernet66/0/2",DIRECTION=inbound;
```
