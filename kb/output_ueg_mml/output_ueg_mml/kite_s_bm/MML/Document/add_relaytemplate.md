# 增加媒体中继模板（ADD RELAYTEMPLATE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于添加媒体中继模板。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为5。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称            | 参数说明                                                                                                                                                                            |
|:----------------|:----------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RELAYTPLNAME    | 媒体中继模板名称        | 可选必选说明：必选参数 参数含义：该参数用来指定媒体中继模板名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                   |
| DNSCNAME        | DNS规范名称         | 可选必选说明：可选参数 参数含义：该参数用来指定DNS的规范名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为0～63。不支持空格，不区分大小写。仅支持数字、字母、'.'和'-'进行组合，必须以数字或字母开头和结尾，不能出现连续两个'.'。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。                    |
| DNSLIVETIME     | DNS存活时间（秒）      | 可选必选说明：可选参数 参数含义：该参数用来指定DNS的存活时间。 数据来源：本端规划 取值范围：整数类型，取值范围是为30～1800，默认值为60，单位是秒。 默认值：60 配置原则：无                                                                                  |
| DNSIPNOTMTACT   | DNS IP不匹配操作     | 可选必选说明：可选参数 参数含义：该参数用来指定DNS请求的IP类型与配置的媒体中继IP类型不匹时，DNS代理的处理动作。只对IPv4IPv6双栈用户生效。 数据来源：本端规划 取值范围：枚举类型。 BYPASS：不做DNS代理，消息透传给DNS服务器。RETNOTFOUND：代理DNS响应，携带“xxx”原因。 默认值：BYPASS 配置原则：无 |
| TLSCFGNAME      | TLS配置名称         | 可选必选说明：可选参数 参数含义：该参数用于设置该Relay业务TLS配置描述。 数据来源：本端规划 取值范围：字符串类型，输入长度范围是0~31。不区分大小写。 默认值：无 配置原则： 该取值必须和ADD RELAYTLSCFG中配置的“TLSCONFIGNAME”参数取值相同。输入单空格将删除该参数已有配置项。                  |
| UNKNOWNDMACT    | UE访问未知域名处理动作    | 可选必选说明：可选参数 参数含义：该参数用于设置UE访问未知域名的处理动作。 数据来源：本端规划 取值范围：枚举类型。 REDIRECT：重定向。FORBIDDEN：拒绝。 默认值：FORBIDDEN 配置原则：无                                                                     |
| VENDORID        | 厂商ID            | 可选必选说明：可选参数 参数含义：该参数用于设置媒体厂商ID，用于进行媒体厂商差异化控制。 数据来源：本端规划 取值范围：取值范围0~5，默认值为0。 默认值：0 配置原则：无                                                                                        |
| MEDIAAGETIME    | 媒体文件老化时间（小时）    | 可选必选说明：可选参数 参数含义：该参数用来指定媒体文件老化时间。 数据来源：本端规划 取值范围：整数类型，取值范围为1~720，默认值为168，单位为小时。 默认值：168 配置原则：无                                                                                  |
| MEDIAAUTHTIME   | 媒体文件有效性校验时长（分钟） | 可选必选说明：可选参数 参数含义：该参数用来指定媒体文件有效性校验时长。 数据来源：本端规划 取值范围：整数类型，取值范围为5~1440，默认值为15，单位为分钟。 默认值：15 配置原则：无                                                                                |
| MEDIAAUTHMETHOD | 媒体文件有效性校验方式     | 可选必选说明：可选参数 参数含义：该参数用来指定媒体文件有效性校验方式。 数据来源：本端规划 取值范围：枚举类型。 GET：GET请求方式。HEAD：HEAD请求方式。 默认值：HEAD 配置原则：无                                                                            |
| MEDIAINFOUPDTM  | 媒体属性更新时间（秒）     | 可选必选说明：可选参数 参数含义：该参数用来指定媒体属性更新时间。 数据来源：本端规划 取值范围：整数类型，取值范围为1~3600，默认值为60，单位为秒。 默认值：60 配置原则：无                                                                                    |
| CFGDOMAINNAME   | 配置域名称           | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。                                                                              |

#### 使用实例

假如需要创建一组媒体中继模板，则命令如下：

```
ADD RELAYTEMPLATE: RELAYTPLNAME="test", DNSLIVETIME=120, DNSIPNOTMTACT=RETNOTFOUND, UNKNOWNDMACT=REDIRECT, VENDORID=2, MEDIAAUTHMETHOD=GET, CFGDOMAINNAME="testDomain";
```
