# 配置 URL过滤业务模式（SET CFSRVMODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，操作不当会导致URL过滤业务故障，请谨慎使用并联系华为技术支持协助操作。

该命令用于设置URL过滤业务模式。

#### 注意事项

- 该命令执行后立即生效。
- 如果DBMODE要设置为CUSTOMIZATION1，需要保证ADD CFPROFILE配置的CFPROFILENAME必须包含“&”且“&”不在字符串首尾，并且不同CFPROFILENAME“&”之前的字符串不一致。否则无法将DBMODE设置为CUSTOMIZATION1。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | DBMODE   | ENCRYALGORI   |
|:-------|:---------|:--------------|
| 初始值    | STANDARD | NONE          |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称       | 参数说明                                                                                                                                                                                                                                |
|:---------------|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DBMODE         | URL过滤策略库模式 | 可选必选说明：必选参数 参数含义：该命令用于配置URL过滤策略库模式。 数据来源：本端规划 取值范围： STANDARD：使用华为推荐模式。CUSTOMIZATION1：客户定制模式1，使用前请联系华为工程师。CUSTOMIZATION2：客户定制模式2，使用前请联系华为工程师。 默认值：无 配置原则：无                                                                           |
| ENCRYALGORI    | 加密算法       | 可选必选说明：条件必选参数 前提条件：该参数在“DBMODE”配置为“CUSTOMIZATION1”或“CUSTOMIZATION2”时为必选参数。 参数含义：该参数用于指定对携带的参数的加密方式。 数据来源：本端规划 取值范围： NONE：不进行加密，有安全风险，不建议使用。SHA256：加密类型为SHA256。 默认值：无 配置原则：ENCRYALGORI参数仅在DBMODE配置为CUSTOMIZATION1或CUSTOMIZATION2时生效。 |
| PSWDKEY        | 加密算法密钥     | 可选必选说明：条件必选参数 前提条件：该参数在“ENCRYALGORI”配置为“SHA256”时为必选参数。 参数含义：该参数用于设置参数加密算法的密钥。 数据来源：本端规划 取值范围：输入长度范围为1~256.不支持空格。 默认值：无 配置原则：无                                                                                                       |
| PSWDKEYCONFIRM | 加密算法密钥确认   | 可选必选说明：条件必选参数 前提条件：该参数在“ENCRYALGORI”配置为“SHA256”时为必选参数。 参数含义：该参数用于确认加密算法的密钥。 数据来源：本端规划 取值范围：输入长度范围为1~256.不支持空格。 默认值：无 配置原则：无                                                                                                         |
| CFGDOMAINNAME  | 配置域参数      | 可选必选说明：条件可选参数 前提条件：该参数在“DBMODE”配置为“STANDARD”、“CUSTOMIZATION1” 或 “CUSTOMIZATION2”时为可选参数。 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1~31.。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。                                                     |

#### 使用实例

配置URL过滤策略库模式为STANDARD：

```
SET CFSRVMODE: DBMODE=STANDARD;
```
