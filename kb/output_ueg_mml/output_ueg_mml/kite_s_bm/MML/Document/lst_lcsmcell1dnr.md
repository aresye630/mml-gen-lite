# 查询LCS宏站一维算法NR（LST LCSMCELL1DNR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

查询LCS宏站算法参数。

#### 注意事项

不填参数时会查询全部配置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                |
|:---------|:-------|:------------------------------------------------------------------------------------|
| GNODEBID | 基站标识   | 可选必选说明：可选参数 参数含义：该参数用于设置基站标识。 数据来源：全网规划 取值范围：整型数字类型，取值范围为0~4294967295。 默认值：无 配置原则：无 |

#### 使用实例

查询LCS宏站算法参数：

```
LST LCSMCELL1DNR;
```

```
RETCODE = 0 操作成功

LCS宏站算法参数
---------------
基站标识 小区标识

190041   NULL
190042   1
(结果个数 = 2)

--- END
```

#### 输出结果说明

| 输出项名称   | 输出项解释     |
|:--------|:----------|
| 小区标识    | 用于配置小区标识。 |

其余输出项请参见ADD LCSMCELL1DNR的参数说明。
