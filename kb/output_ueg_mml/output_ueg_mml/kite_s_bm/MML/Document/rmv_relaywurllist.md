# 删除媒体中继白名单URL列表（RMV RELAYWURLLIST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、PGW-U**

该命令用于删除媒体中继URL白名单列表。

#### 注意事项

- 该命令执行后立即生效。
- 当RELAYWURLLIST被RELAYRFCHKRULE绑定时无法删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称        | 参数说明                                                                                       |
|:---------------|:------------|:-------------------------------------------------------------------------------------------|
| RELAYURLLISTNM | 媒体中继URL列表名称 | 可选必选说明：必选参数 参数含义：该参数用于指定媒体中继URL列表名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不区分大小写。 默认值：无 配置原则：无 |
| RELAYURLNAME   | 媒体中继URL名称   | 可选必选说明：可选参数 参数含义：该参数用于指定媒体中继URL名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围是1~31。不区分大小写。 默认值：无 配置原则：无   |

#### 使用实例

删除媒体中继URL白名单列表：

```
RMV RELAYWURLLIST: RELAYURLLISTNM="list01";
```
