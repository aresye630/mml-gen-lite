# 修改用户信息统计功能（MOD USERSTATISTICS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用来修改用户信息统计功能的相关参数。

#### 注意事项

该命令执行后只对之后发生承载更新的用户或者新激活用户生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称             | 参数说明                                                                                                                                                                                                    |
|:----------------|:-----------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FUNCTION        | 功能开关             | 可选必选说明：必选参数 参数含义：该参数用于配置功能开关。 数据来源：本端规划 取值范围：枚举类型。 HIGH_RATE_USRSTATS：高带宽用户统计功能。 默认值：无 配置原则：无                                                                                                           |
| RECORDMODE      | 业务信息记录方式         | 可选必选说明：条件可选参数 前提条件：该参数在“FUNCTION”配置为“HIGH_RATE_USRSTATS”时为可选参数。 参数含义：该参数用于配置业务信息的记录方式。 数据来源：本端规划 取值范围：枚举类型。 DGBCNT：调试计数器。HIGH_USR_LEARN：高带宽用户自学习。DGBCNT_AND_HIGH_USR_LEARN：调试计数器&高带宽用户自学习。 默认值：无 配置原则：无 |
| CALCPERIOD      | 用户瞬间速率的计算周期      | 可选必选说明：条件可选参数 前提条件：该参数在“FUNCTION”配置为“HIGH_RATE_USRSTATS”时为可选参数。 参数含义：该参数用于配置用户瞬间速率的计算周期。 数据来源：本端规划 取值范围：整数类型，取值范围为100～5000，单位是毫秒。 默认值：无 配置原则：无                                                          |
| HBUSERTHRESHOLD | 高带宽用户速率门限（兆比特/秒） | 可选必选说明：条件可选参数 前提条件：该参数在“RECORDMODE”配置为“HIGH_USR_LEARN” 或 “DGBCNT_AND_HIGH_USR_LEARN”时为可选参数。 参数含义：该参数用于配置识别高带宽用户的最低速率门限值。 数据来源：本端规划 取值范围：整数类型，取值范围为100～5000，单位是兆比特每秒。 默认值：无 配置原则：无                       |

#### 使用实例

把高带宽用户统计功能的瞬间速率计算周期，修改为2000毫秒：

```
MOD USERSTATISTICS: FUNCTION=HIGH_RATE_USRSTATS, CALCPERIOD=2000;
```
