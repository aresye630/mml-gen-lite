# 查询接口IPv4地址（LST IFIPV4ADDRESS）

#### 命令功能

该命令用于查询接口的配置地址，借用地址以及被借用地址。配置地址类型包括主地址和从地址。借用地址代表本接口借用了另一个接口的主地址，被借用地址代表本接口的主地址被另一个接口借用。请使用ADD IFIPV4UNNUM命令配置地址借用关系。

不指定IFNAME参数时，查询设备上所有接口的信息；当指定IFNAME参数时，可以查询指定接口的配置信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                           |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------|
| IFNAME | 接口名    | 可选必选说明：可选参数 参数含义：该参数用于指定需要配置IP地址的接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。接口名称由接口类型+接口编号组成。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。 |

#### 使用实例

查询GigabitEthernet0/0/1的信息：

```
LST IFIPV4ADDRESS: IFNAME="GigabitEthernet0/0/1";
```

```
RETCODE = 0  操作成功

结果如下
-------------------------
              接口名  =  GigabitEthernet0/0/1
            IPv4地址  =  192.168.1.1
        IPv4地址掩码  =  255.255.255.0
        IPv4地址类型  =  主地址
(结果个数 = 1)

---   END
```

#### 输出结果说明

| 输出项名称    | 输出项解释            |
|:---------|:-----------------|
| 接口名      | 用于表示接口名。         |
| IPv4地址   | 用于显示接口的IPv4地址。   |
| IPv4地址掩码 | 用于显示接口的IPv4地址掩码。 |
| IPv4地址类型 | 用于显示接口的IPv4地址类型。 |
