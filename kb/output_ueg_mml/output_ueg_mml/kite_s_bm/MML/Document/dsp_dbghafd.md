# 显示HAFD调试命令结果（DSP DBGHAFD）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于CMF内部功能调试。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                 |
|:----------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CELLID    | 进程标识   | 可选必选说明：必选参数  参数含义：该参数是进程唯一的身份标识。通过执行OPR DBGDATA：DBGTYPE=CELLTYPE，CELLTYPE=156，DEBUGNAME=“DSP MSACTIVE 102|999”；获取dcfctrl的主进程ID。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~1024。  默认值：无  配置原则：无 |
| DEBUGNAME | 调试命令   | 可选必选说明：必选参数  参数含义：该参数是用户输入的调试命令，例如：cmf agent。 ，用于获取输入命令者所期望获取的查询信息。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~1024。  默认值：无  配置原则：无                                                             |

## 使用实例

查询调试命令结果

```
%%DSP DBGHAFD: CELLID="cmf-pod-2__167__0", DEBUGNAME="cmf agent";%%
RETCODE = 0  操作成功

结果如下

(结果个数 = 32)
```
