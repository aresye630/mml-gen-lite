# 修改SMF的NodeID（MOD CPNODEID）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于修改SMF实例的信息。

#### 注意事项

- 该命令执行后只对新激活用户生效。
- 不同SMF实例的NODEID不可以相同。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称             | 参数说明                                                                                                                                                                                    |
|:--------------|:-----------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CPNAME        | SMF名称            | 可选必选说明：必选参数 参数含义：SMF的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～255。由“_”、“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”，不区分大小写。 默认值：无 配置原则：无                                                            |
| CPNODEIDTYPE  | CP NodeID 类型     | 可选必选说明：可选参数 参数含义：NodeID类型。 数据来源：本端规划 取值范围：枚举类型。 IPV4：NodeID类型是IPv4。IPV6：NodeID 类型是IPv6。FQDN：NodeID 类型是FQDN。 默认值：无 配置原则：无                                                                |
| IPV4NODEID    | IPv4地址类型的Node Id | 可选必选说明：条件可选参数 前提条件：该参数在“CPNODEIDTYPE”配置为“IPV4”时为可选参数。 参数含义：IPv4类型的SMF Node Id。 数据来源：对端协商 取值范围：IPv4地址类型。 默认值：无 配置原则：无                                                                    |
| IPV6NODEID    | IPv6地址类型的Node Id | 可选必选说明：条件可选参数 前提条件：该参数在“CPNODEIDTYPE”配置为“IPV6”时为可选参数。 参数含义：IPv6类型的SMF Node Id。 数据来源：对端协商 取值范围：IPv6地址类型。 默认值：无 配置原则：无                                                                    |
| FQDNNODEID    | FQDN类型的Node Id   | 可选必选说明：条件可选参数 前提条件：该参数在“CPNODEIDTYPE”配置为“FQDN”时为可选参数。 参数含义：FQDN类型的SMF Node Id。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～255。不区分大小写，支持的字符类型包括：大小写字母、数字、“-”、“.”，大小写不敏感。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。 |
| LOCALEMERNODE | 本地应急接入节点         | 可选必选说明：可选参数 参数含义：本地应急接入节点。 数据来源：本端规划 取值范围：枚举类型。 FALSE：非本地应急接入。TRUE：本地应急接入。 默认值：无 配置原则：无                                                                                                 |

#### 使用实例

修改名为smfnode1的IPv4地址为10.10.1.1：

```
MOD CPNODEID: CPNAME="smfnode1", CPNODEIDTYPE=IPV4, IPV4NODEID="10.10.1.1", LOCALEMERNODE=FALSE;
```
