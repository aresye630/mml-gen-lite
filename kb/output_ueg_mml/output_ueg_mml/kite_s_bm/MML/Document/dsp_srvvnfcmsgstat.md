# 查询服务VNFC消息统计（DSP SRVVNFCMSGSTAT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询业务VFNC业务消息统计情况

#### 注意事项

- DSP SRVVNFCMSGSTAT命令的统计值在MLBP进程复位后会被清零。
- 该命令批量下发可能导致执行超时。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                                                                                                                                                              |
|:-----------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PEERVNFCID | 服务VNFC ID | 可选必选说明：必选参数 参数含义：该参数用于指定业务VNFC的唯一标识，通过在业务VNFC下执行LST NODE获得，所得NODEID即为服务VNFC ID。 数据来源：本端规划 默认值：无                                                                                                                                   |
| DATATYPE   | 数据类型      | 可选必选说明：必选参数 参数含义：该参数用于指定数据类型。 数据来源：本端规划 默认值：无 取值范围：“SRV_DATA_TYPE_LBPLY(负载均衡策略) ”“SRV_DATA_TYPE_NEXTHOP(下一跳) ”“SRV_DATA_TYPE_XTUPLE(X元组) ”“SRV_DATA_TYPE_ENEXTHOP(扩展下一跳) ”“SRV_DATA_TYPE_EXCHANGE(交换表) ”“SRV_DATA_TYPE_VPN(VPN) ” |
| POLICYID   | 策略索引      | 可选必选说明：可选参数 默认值：无                                                                                                                                                                                                                 |

#### 使用实例

`%%DSP SRVVNFCMSGSTAT: PEERVNFCID=4, DATATYPE=SRV_DATA_TYPE_LBPLY, POLICYID=0;%%`

`RETCODE = 0 操作成功`
