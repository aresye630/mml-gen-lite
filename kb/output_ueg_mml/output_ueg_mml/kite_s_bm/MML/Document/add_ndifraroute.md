# 增加接口上ND RA路由配置信息（ADD NDIFRAROUTE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于增加IPv6接口上RA路由配置信息。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为17。
- 执行该命令行前需要先在接口使能IPv6。
- 接口名称可以通过LST INTERFACE命令获取。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称      | 参数说明                                                                                                |
|:-------------|:----------|:----------------------------------------------------------------------------------------------------|
| IFNAME       | 接口名       | 可选必选说明：必选参数 参数含义：该参数用于指定接口名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。 |
| PREFIX       | IPv6地址前缀  | 可选必选说明：必选参数 参数含义：该参数用于指定IPv6地址前缀。 数据来源：全网规划 取值范围：IPv6地址类型。 默认值：无                                    |
| PREFIXLENGTH | 前缀长度      | 可选必选说明：必选参数 参数含义：该参数用于指定前缀长度。 数据来源：全网规划 取值范围：整数类型，取值范围为0～128。 默认值：无                                 |
| LIFETIME     | 路由存活时间（s） | 可选必选说明：必选参数 参数含义：该参数用于指定路由存活时间。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295，单位是秒。 默认值：无                   |
| PREFERENCE   | 路由器优先级    | 可选必选说明：可选参数 参数含义：该参数用于指定路由器优先级。 数据来源：本端规划 取值范围：枚举类型。 LOW：低优先级。MEDIUM：中优先级。HIGH：高优先级。 默认值：MEDIUM     |

#### 使用实例

增加接口上ND RA路由配置信息：

```
ADD NDIFRAROUTE: IFNAME="Ethernet65/0/8",PREFIX="2001:db8::11",PREFIXLENGTH=70,LIFETIME=888,PREFERENCE=LOW;
```
