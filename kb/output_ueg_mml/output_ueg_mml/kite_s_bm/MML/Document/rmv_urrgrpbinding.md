# 删除用户模板的URR组绑定关系（RMV URRGRPBINDING）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，删除UrrGrpBinding可能会影响业务计费。
删除UrrGrpBinding可能会导致用户激活失败。

该命令用于根据指定名字删除使用量上报规则的绑定。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称     | 参数说明                                                                                                                                                                                                                                           |
|:----------------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USERPROFILENAME | 用户模板名称   | 可选必选说明：必选参数 参数含义：该参数用于指定用户模板名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格及“,”、“;”、“"”等特殊字符，不区分大小写。 默认值：无 配置原则：无                                                                                                                                   |
| URRGROUPTYPE    | URR组绑定类型 | 可选必选说明：必选参数 参数含义：该参数用于指定URR组绑定类型。 数据来源：全网规划 取值范围：枚举类型。 SERVICE：业务URR组。SIGNALING：信令URR组。TCP：TCP重传URR组。REDIRECT：重定向URR组。 默认值：无 配置原则： SERVICE：设定计费属性绑定类型为业务计费属性。SIGNALING：设定计费属性绑定类型为信令计费属性。TCP：设定计费属性绑定类型为TCP重传计费属性。REDIRECT：设定计费属性绑定类型为重定向计费属性。 |

#### 使用实例

假如运营商希望取消名称为“TestUserProfileName”的用户模板下的信令使用量上报规则：

```
RMV URRGRPBINDING: USERPROFILENAME="TestUserProfileName", URRGROUPTYPE=SIGNALING;
```
