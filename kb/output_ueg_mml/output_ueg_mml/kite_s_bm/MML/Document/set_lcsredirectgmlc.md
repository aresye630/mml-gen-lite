# 配置重定向GMLC参数（SET LCSREDIRECTGMLC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于配置重定向GMLC参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 只有当SET LCSGLBATTR命令中AMFFAULTRETCODE参数或者LMFFAULTRETCODE参数配置为307时，该配置才会生效。
- 重定向的IPv4、IPv6地址需要根据局点的网络规划进行配置。
- 执行SET LCSREDIRECTGMLC命令时，需要至少输入一个参数；否则，命令执行失败。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | REDIRECTGMLCSW   |   REDIRGMLCIPVER | GMLCIPV4ADDR   | GMLCIPV6ADDR                            |
|:-------|:-----------------|-----------------:|:---------------|:----------------------------------------|
| 初始值    | DISABLE          |              nan | 0.0.0.0        | 0000:0000:0000:0000:0000:0000:0000:0000 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称         | 参数说明                                                                                                                                                                                     |
|:---------------|:-------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| REDIRECTGMLCSW | 重定向GMLC开关    | 可选必选说明：可选参数 参数含义：该参数用于设置是否使能GMLC重定向功能。 数据来源：本端规划 取值范围： DISABLE：开关去使能。ENABLE：开关使能。 默认值：无 配置原则：无                                                                                           |
| REDIRGMLCIPVER | 重定向GMLC IP版本 | 可选必选说明：条件可选参数 前提条件：该参数在“REDIRECTGMLCSW”配置为“ENABLE”时为可选参数。 参数含义：该参数用于设置重定向的GMLC IP地址类型。 数据来源：全网规划 取值范围： IPv4：IPv4。IPv6：IPv6。IPv4v6：IPv4和IPv6。 默认值：无 配置原则：无                                |
| GMLCIPV4ADDR   | GMLC IPv4地址  | 可选必选说明：条件可选参数 前提条件：该参数在“REDIRGMLCIPVER”配置为“IPv4” 或 “IPv4v6”时为可选参数。 参数含义：该参数用于指示重定向的GMLC IPv4地址。 数据来源：全网规划 取值范围：IPv4地址类型。采用点分十进制"X.X.X.X"格式。除A、B、C类地址合法外，其余都为非法地址。 默认值：无 配置原则：无           |
| GMLCIPV6ADDR   | GMLC IPv6地址  | 可选必选说明：条件可选参数 前提条件：该参数在“REDIRGMLCIPVER”配置为“IPv6” 或 “IPv4v6”时为可选参数。 参数含义：该参数用于指示重定向的GMLC IPv6地址。 数据来源：全网规划 取值范围：IPv6地址类型。采用冒号分十六进制X:X:X:X:X:X:X:X格式。除单播、任播和组播地址合法外，其余都为非法地址。 默认值：无 配置原则：无 |

#### 使用实例

配置重定向GMLC参数：

```
SET LCSREDIRECTGMLC: REDIRECTGMLCSW=ENABLE, REDIRGMLCIPVER=IPv4, GMLCIPV4ADDR="192.168.0.0";
```
