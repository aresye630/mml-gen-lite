# 查询话统指标统计趋势(DSP MEASTREND)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询网元的话统指标统计趋势。

## 注意事项

- 当系统处于存储故障状态时，只支持查询KPI类型的指标统计趋势，查询结果不支持“最近一周同时间段(按时间倒序)”数据的对比。
- 网元升级后未结束升级观察期期间，支持查询高低版本指标统计趋势；结束升级观察期后，普通域仅支持查询高版本指标统计趋势。
- 该命令返回结果条数存在如下限制：最多返回1000条。最多返回10000条。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                             |
|:-----------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID       | 网元ID   | 可选必选说明：可选参数。 参数含义：标识网元ID，可以通过LST MELST ME命令查询获取。 取值范围：0~65535。 默认值：无。 配置原则：无。                                                                                                                    |
| PRD        | 测量周期   | 可选必选说明：必选参数。 参数含义：标识指标查询的测量周期。 取值范围： FIVE(5分钟)FIFTEEN(15分钟)THIRTY(30分钟)SIXTY(1小时)ONE_DAY(一天) 默认值：FIVE(5分钟)。 配置原则：无。                                                                              |
| QRY_TYPE   | 查询类型   | 可选必选说明：必选参数。 参数含义：话统指标时间的查询类型。取值范围： STD_QUERY(标准查询) ，整周期数据完整后才支持查询。REAL_QUERY(实时查询)，不依赖整周期数据是否完整，数据入库后即可查询。 默认值：STD_QUERY(标准查询)。 配置原则： 当配置“查询类型”为“REAL_QUERY(实时查询)”时，最新一个周期的数据可能为因为没有统计结果显示为nil。 |
| TYPE       | 指标分类   | 可选必选说明：必选参数。 参数含义：指标分类。 取值范围： KPI(KPI指标) ALL(不限分类) 默认值：KPI(KPI指标)。 配置原则：无。                                                                                                                       |
| MUID       | 测量单元ID | 可选必选说明：该参数在“指标分类”配置为“ALL(不限分类)”时为条件可选参数。 参数含义：测量单元ID，可以通过LST MEASUNIT命令查询获取。 取值范围：整数类型，取值范围为0~4294967294。 默认值：无。 配置原则：无。                                                                         |
| MUNAME     | 测量单元名称 | 可选必选说明：该参数在“指标分类”配置为“ALL(不限分类)”时为条件可选参数。 参数含义：测量单元名称，支持中英文模糊搜索。 取值范围：字符串类型，长度不超过256个字符。 默认值：无。 配置原则：若不输入，则表示该参数不作为查询的限制条件。                                                                       |
| METRICID   | 测量指标ID | 可选必选说明：该参数在“指标分类”配置为“ALL(不限分类)”时为条件可选参数。 参数含义：测量指标ID，可以通过LST MEASUNIT命令查询获取。 取值范围：整数类型，取值范围为0~4294967294。 默认值：无。 配置原则：无。                                                                         |
| METRICNAME | 测量指标名称 | 可选必选说明：该参数在“指标分类”配置为“ALL(不限分类)”时为条件可选参数。 参数含义：测量指标名称，支持中英文模糊搜索。 取值范围：字符串类型，长度不超过256个字符。 默认值：无。 配置原则：若不输入，则表示该参数不作为查询的限制条件。                                                                       |
| MOIID      | 对象实例ID | 可选必选说明：该参数在“指标分类”配置为“ALL(不限分类)”时为条件可选参数。 参数含义：对象实例ID，可以通过DSP MEASOBJ命令查询获取。 取值范围：字符串类型，长度不超过256个字符。 默认值：无。 配置原则：无。                                                                               |
