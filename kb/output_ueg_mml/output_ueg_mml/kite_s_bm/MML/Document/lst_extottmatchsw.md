# 查询OTT业务规则匹配功能是否使能配置（LST EXTOTTMATCHSW）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用来查询OTT业务规则匹配功能是否使能。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询外置OTT业务规则匹配功能是否使能信息：

```
LST EXTOTTMATCHSW:;
```

```
RETCODE = 0 操作成功.

外置OTT业务规则匹配功能开关信息
--------------------------------------------
外置OTT业务规则匹配功能开关IPv4 = ENABLE
外置OTT业务规则匹配功能开关IPv6 = ENABLE

(结果个数 = 1)
--- END
```

#### 输出结果说明

参见SET EXTOTTMATCHSW的参数说明。
