# 批量删除接口下IP地址（RMV ALLIFIPADDRESS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于批量删除接口下地址。

**须知** 

本命令属于高危命令，该操作将清除该接口下的所有IPv4或IPv6配置。

#### 注意事项

- 该命令执行后立即生效。
- 该操作可能会导致业务流量中断。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                           |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------|
| IFNAME | 接口名    | 可选必选说明：必选参数 参数含义：该参数用于指定需要删除IP地址的接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。接口名称由接口类型+接口编号组成。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。 |
| OPTYPE | 操作类型   | 可选必选说明：必选参数 参数含义：该参数用于指定操作类型。 数据来源：本端规划 取值范围：枚举类型。 AllIPv4：清除接口IPv4地址。AllIPv6：清除接口IPv6地址。AllIPAddress：清除接口所有IP地址。 默认值：无        |

#### 使用实例

- 删除接口下所有IPv4地址：

  ```
  RMV ALLIFIPADDRESS:IFNAME="ethernet64/0/3",OPTYPE=AllIPv4;
  ```
- 删除接口下所有IPv6地址：

  ```
  RMV ALLIFIPADDRESS:IFNAME="ethernet64/0/3",OPTYPE=AllIPv6;
  ```
- 删除接口下所有IP地址：

  ```
  RMV ALLIFIPADDRESS:IFNAME="ethernet64/0/3",OPTYPE=AllIPAddress;
  ```
