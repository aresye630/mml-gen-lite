# 设置PCC QoS相关控制参数（SET PCCRULECTRL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

此命令用于控制PCC动态Rule生成的QoS Rule优先级是否按照PCF下发的优先级进行控制。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 此命令SMF也需要同步支持。对接的SMF与UPF需要统一规划此开关。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | QOSRULEPRIO         |
|:-------|:--------------------|
| 初始值    | INTERNAL_ALLOCATION |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称            | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|:------------|:----------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| QOSRULEPRIO | QoS Rule优先级设置原则 | 可选必选说明：必选参数 参数含义：该参数用于配置QoS Rule优先级的设置原则。 数据来源：对端协商 取值范围：枚举类型。 INTERNAL_ALLOCATION：内部分配（默认）。EQUAL_PCCRULE_PRECEDENCE：等于PCC Rule优先级。 默认值：无 配置原则： 当运营商不需要根据PCF下发的优先级分配QoS Rule的优先级时，需要将参数配置为INTERNAL_ALLOCATION。当运营商需要根据PCF下发的优先级分配QoS Rule的优先级时，需要将参数配置为EQUAL_PCCRULE_PRECEDENCE。当参数为EQUAL_PCCRULE_PRECEDENCE时，所有绑定过QoSprop（通过pccpolicygrp或者通过qos类型的rule绑定）的规则的优先级不能低于255。当参数从INTERNAL_ALLOCATION修改为EQUAL_PCCRULE_PRECEDENCE时，所有绑定过QoSprop（通过pccpolicygrp或者通过qos类型的rule绑定）的规则的优先级，如果有高于255的，则不允许修改。 |

#### 使用实例

当运营商需要根据PCF下发的优先级分配QoS Rule的优先级时，配置如下：

```
SET PCCRULECTRL: QOSRULEPRIO=EQUAL_PCCRULE_PRECEDENCE;
```
