# 删除OSPFv3认证配置（RMV OSPFV3AUTH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除在OSPFv3进程下的认证。

**须知** 

本命令属于高危命令，如果OSPFv3进程认证与邻居配置不同，可能会使此进程的OSPFv3邻接关系中断，造成业务影响。

#### 注意事项

- 该命令执行后立即生效。
- 删除OSPFv3进程认证，请确保和邻居认证配置相同，否则会导致邻接关系中断，影响业务。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                     |
|:-------|:----------|:-------------------------------------------------------------------------|
| PROCID | OSPFv3进程号 | 可选必选说明：必选参数 参数含义：OSPFv3进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 |

#### 使用实例

删除OSPFv3进程1下的认证：

```
RMV OSPFV3AUTH:PROCID=1;
```
