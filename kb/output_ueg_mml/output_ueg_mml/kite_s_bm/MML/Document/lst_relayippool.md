# 查询媒体中继IP池（LST RELAYIPPOOL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询媒体中继IP池。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                          |
|:---------|:-------|:----------------------------------------------------------------------------------------------|
| POOLNAME | IP池名   | 可选必选说明：可选参数 参数含义：该参数用于配置媒体中继IP池名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

假设需要查询媒体中继IP池，则命令如下：

```
LST RELAYIPPOOL:;
```

```
RETCODE = 0  操作成功

结果如下
--------
 IP池名 = pool_relay
VPN名称 = _public_
(结果个数 = 1)

---    END
```
