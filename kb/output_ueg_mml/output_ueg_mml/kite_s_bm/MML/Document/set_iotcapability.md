# 设置物联网能力上报（SET IOTCAPABILITY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

设置UPF的物联网能力上报功能选择指示。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | NBIOT   |
|:-------|:--------|
| 初始值    | ENABLE  |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称         | 参数说明                                                                                                   |
|:-------|:-------------|:-------------------------------------------------------------------------------------------------------|
| NBIOT  | NB-IoT接入能力上报 | 可选必选说明：可选参数 参数含义：该参数用来打开或者关闭UPF的NB-IoT用户接入功能。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无 |

#### 使用实例

配置UPF的NB-IoT用户接入能力上报功能开关为ENABLE：

```
SET IOTCAPABILITY:NBIOT=ENABLE;
```
