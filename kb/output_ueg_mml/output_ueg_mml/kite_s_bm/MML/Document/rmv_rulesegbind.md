# 删除Rule IMSI/MSISDN号段组绑定（RMV RULESEGBIND）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于删除IMSI/MSISDN号段组与Rule的绑定关系。当运营商希望删除IMSI/MSISDN号段组与Rule的绑定时，则执行该命令。

#### 注意事项

- 该命令执行后对新数据流生效。
- 如果不输入规则名称，表示删除指定号段名称对应的所有的规则与号段组的绑定关系。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称             | 参数说明                                                                                                    |
|:-----------|:-----------------|:--------------------------------------------------------------------------------------------------------|
| IMSIMSSEGG | IMSI/MSISDN号段组名称 | 可选必选说明：必选参数 参数含义：该参数用于指定要绑定的IMSI/MSISDN号段组。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |
| RULENAME   | Rule名称           | 可选必选说明：可选参数 参数含义：该参数用于指定要绑定的Rule。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无           |

#### 使用实例

假如运营商需要删除指定号段组与其对应所有规则的绑定关系：

```
RMV RULESEGBIND: IMSIMSSEGG="testseg";
```
