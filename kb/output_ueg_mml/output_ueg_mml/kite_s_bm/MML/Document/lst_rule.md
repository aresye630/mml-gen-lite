# 查询规则（LST RULE）

- 命令功能

- 操作用户权限

- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询规则。

#### 注意事项

支持批量查询。如果不输入策略名称，则查询系统中所有的规则。如果输入了策略类型，则查询系统中配置为本策略类型的所有规则。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|:-------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RULENAME     | 规则名称   | 可选必选说明：可选参数 参数含义：该参数用于设置规则名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：设置该参数时表示查询指定名称的规则，未设置该参数时表示查询系统中所有的规则。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| POLICYTYPE   | 策略类型   | 可选必选说明：可选参数 参数含义：该参数用于设置策略类型。 数据来源：本端规划 取值范围：枚举类型。 PCC：计费与策略控制，代表该规则可以配置PCC策略，用于实现计费和策略控制功能。BWM：带宽管理，代表该规则可以配置带宽管理分类策略，其分类结果可以用于带宽管理的策略匹配功能。HEADEN：头增强，代表该规则可以配置头增强策略，可以基于配置的头增强策略向HTTP/RTSP请求报文头域中插入字段。WEBPROXY：Web Proxy，代表该规则可以配置WebProxy的IPFarm对象名称，用于设置WebProxy选择的服务器地址池。IPREDIR：IP重定向，代表该规则可以配置IP重定向的目标IP地址，支持IPv4和IPv6两种类型的IP地址。SMARTREDIRECT：智能重定向，代表该规则可以配置CaptivePortal业务对应的IPFarm的名称，HTTP智能重定向的名称，DNS重写动作的名称或者重定向的名称。REMARK_FPI：Remark、FPI或者SAI，代表该规则可以配置IP报文的DSCP重标记值、FPI策略或SAI策略。SRV_TRIGGER：Service Trigger Radius，代表该规则可以配置业务触发Radius消息交互功能标识，并配置Radius交互过程中报文处理方式。TRAFFICCLASS：Traffic Classifier，代表该规则可以配置Service Chain对象名称，用于实现业务链功能，此参数当前不支持。LBO：Local Break Out，代表该规则可以用于本地业务分流，此参数当前不支持。FIREWALL：防火墙，代表该规则可以配置防火墙策略。ADC：代表该规则用于应用检测与控制功能。QOS：代表该规则可以配置QoS策略，可以基于配置的QoS策略进行业务级QoS处理。WORKER：代表该规则用于通用Rule业务。 默认值：无 配置原则：根据部署的业务策略选择相应的策略类型。 |
| RULESPECTYPE | 规则规格类型 | 可选必选说明：可选参数 参数含义：该参数用于指定规则类型，当取值为SPECIFICATION_LIMITED时，表示规格受限规则，表示会话安装的规则数和被USERPROFILE绑定的规则数量均存在一定限制。 数据来源：全网规划 取值范围： DEFAULT：默认配置。SPECIFICATION_LIMITED：规格受限配置。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
