# 删除指纹采集终端信息（RMV FPUEPOS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

移除FPUEPOS对象。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                    |
|:-------|:-------|:------------------------------------------------------------------------|
| UEID   | UE标识   | 可选必选说明：必选参数 参数含义：该参数用于设置UE标识。 数据来源：本端规划 取值范围：字符串类型 0~20字节。 默认值：无 配置原则：无 |

#### 使用实例

移除FPUEPOS对象：

```
RMV FPUEPOS: UEID="123";
```
