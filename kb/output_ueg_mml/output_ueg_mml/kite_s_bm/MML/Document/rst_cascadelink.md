# 复位级联链路(RST CASCADELINK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

复位级联链路可能导致跨框业务受损，请慎重使用。

该命令用于复位多框级联链路。

## 注意事项

复位级联链路可能导致业务受损。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                        |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CHASSIS | 机框号    | 可选必选说明：必选参数。 参数含义：需要复位的机框号。 取值范围：长度不超过20的字符串。如果取值为“all”，则表示复位所有级联链路。 默认值：无。 配置原则：无。                                                                         |
| SLOT    | 槽位号    | 可选必选说明：可选参数。 参数含义：需要复位的槽位号。 取值范围：长度不超过10的字符串。如果取值为“all”，则表示复位该机框所有槽位的级联链路。在“机框号”为“all”的情况下，该参数不作为限制条件。 默认值：无。 配置原则：若“槽位号”参数取值为空，则按“all”处理，系统复位该机框所有槽位的级联链路。 |

## 使用实例

1. 复位单个级联链路：

   ```
   %%RST CASCADELINK: CHASSIS="0", SLOT="3";%%
   RETCODE = 0  操作成功

   操作结果如下
   ——————
   机框号  =  0
   槽位号  =  3
     状态  =  成功
     描述  =  复位成功
   （结果个数 = 1）

   ---    END
   ```
2. 复位单机框全部槽位的级联链路：

   ```
   %%RST CASCADELINK: CHASSIS="0", SLOT="all";%%
   RETCODE = 0  操作成功

   操作结果如下
   ——————
   机框号  槽位号  状态  描述
   0       3       成功  复位成功
   0       4       成功  复位成功
   （结果个数 = 2）

   ---    END
   ```
3. 复位全部级联链路：

   ```
   %%RST CASCADELINK: CHASSIS="all", SLOT="all";%%
   RETCODE = 0  操作成功

   操作结果如下
   ——————
   机框号  槽位号  状态  描述
   0       3       成功  复位成功
   0       4       成功  复位成功
   1       1       成功  复位成功
   1       2       成功  复位成功
   （结果个数 = 4）

   ---    END
   ```
