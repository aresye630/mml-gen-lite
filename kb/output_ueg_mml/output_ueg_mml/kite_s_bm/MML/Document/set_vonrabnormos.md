# 指定MOS值的异常门限值（SET VONRABNORMOS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于设置MOS（Mean Opinion Score）值的异常门限值。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   |   MOSABNORMTHD |
|:-------|---------------:|
| 初始值    |             10 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称           | 参数说明                                                                                    |
|:-------------|:---------------|:----------------------------------------------------------------------------------------|
| MOSABNORMTHD | VoNR MOS值的异常门限 | 可选必选说明：必选参数 参数含义：该参数用于指定MOS值的异常门限值。 数据来源：本端规划 取值范围：整数类型，取值范围为5～20, 粒度是200。 默认值：无 配置原则：无 |

#### 使用实例

设置异常MOS值的门限值为15：

```
SET VONRABNORMOS: MOSABNORMTHD=15;
```
