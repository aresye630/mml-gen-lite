# 查询业务报表全局开关（LST RPTGLBCFG）

#### 命令功能

**适用NF：PGW-U、UPF**

此命令用于查询业务报表全局开关。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

假如运营商需要查询业务报表开关：

```
LST RPTGLBCFG:;
```
