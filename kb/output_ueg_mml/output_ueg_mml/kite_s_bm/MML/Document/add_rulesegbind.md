# 增加Rule IMSI/MSISDN号段组绑定（ADD RULESEGBIND）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于增加IMSI/MSISDN号段组与Rule的绑定关系。当运营商希望通过IMSI/MSISDN号段组实现不同用户使用不同的规则控制，则使用该配置增加号段组与Rule的映射关系，当用户归属于配置的号段组时，用户的业务流选择用户安装的Rule与号段组绑定的Rule中优先级较高的。

#### 注意事项

- 该命令执行后对新数据流生效。
- 该命令最大记录数为100000。
- 每个IMSI/MSISDN号段组最多可绑定2000个Rule。
- 在已绑定Rule的号段组中增加或删除号段，对新数据流生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称             | 参数说明                                                                                                                                                     |
|:--------------|:-----------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSIMSSEGG    | IMSI/MSISDN号段组名称 | 可选必选说明：必选参数 参数含义：该参数用于指定要绑定的IMSI/MSISDN号段组。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD UPIMSIMSISDNG命令配置生成。                      |
| RULENAME      | Rule名称           | 可选必选说明：必选参数 参数含义：该参数用于指定要绑定的Rule。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数使用ADD RULE命令配置生成。IP重定向、智能重定向中的URL重定向和防火墙规则生效，其他类型的规则不生效。 |
| CFGDOMAINNAME | 配置域名称            | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无                                                                       |

#### 使用实例

假如运营商希望将名为“testrule”的Rule与名为“testseg”的号段组绑定：

```
ADD RULESEGBIND: IMSIMSSEGG="testseg", RULENAME="testrule";
```
