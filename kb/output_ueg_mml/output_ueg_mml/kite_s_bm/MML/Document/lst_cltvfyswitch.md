# 查询双向认证开关（LST CLTVFYSWITCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明
- 参考信息

## 命令功能

此命令用于查询双向认证开关的开关状态。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询双向认证开关：

```
LST CLTVFYSWITCH;
```

```
%%LST CLTVFYSWITCH:;%%
RETCODE = 0  操作成功  
操作结果如下 
------------ 
端口  开关    
6443  关      
9000  关      
(结果个数 = 2)

---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。输出结果说明如表1所示。

命令执行异常，请联系

华为

技术支持处理。错误码说明如表2所示。

|:--------|:-----------|
| 端口      | 双向认证的端口。   |
| 开关      | 双向认证的开关状态。 |
