# 增加删除团体属性过滤器设置（ADD APPLYCOMMUNITYFILTERDELETE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用来根据团体属性过滤器中指定的值删除BGP路由团体属性。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为65535。
- 配置该命令前，必须已经通过ADD ROUTEPOLICY配置了指定路由策略的名字以及通过ADD ROUTEPOLICYNODE配置了该策略下的节点。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识               | 参数名称        | 参数说明                                                                                                    |
|:-------------------|:------------|:--------------------------------------------------------------------------------------------------------|
| POLICYNAME         | 路由策略名字      | 可选必选说明：必选参数 参数含义：该参数用于指定路由策略名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无 配置原则：区分大小写。                    |
| NODESEQUENCE       | 路由策略节点号     | 可选必选说明：必选参数 参数含义：该参数用于指定路由策略节点号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无                                |
| COMMUNITYNAMEORNUM | 团体属性过滤器名字或号 | 可选必选说明：必选参数 参数含义：该参数用于指定团体属性过滤器名字或团体属性过滤器号。 数据来源：本端规划 取值范围：字符串类型，团体属性过滤器名称其长度范围是1～51。 默认值：无 配置原则：区分大小写。 |

#### 使用实例

增加对BGP路由团体属性删除规则：

```
ADD APPLYCOMMUNITYFILTERDELETE:POLICYNAME="a",NODESEQUENCE=10,COMMUNITYNAMEORNUM="a";
```
