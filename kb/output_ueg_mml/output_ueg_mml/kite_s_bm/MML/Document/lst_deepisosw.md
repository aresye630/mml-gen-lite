# 查询转发线程深度隔离开关（LST DEEPISOSW）

- 命令功能
- 注意事项

#### 命令功能

**适用NF：UPF**

该命令用于查询转发线程深度隔离开关。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询当前系统设置的转发线程深度隔离开关：

```
LST DEEPISOSW:;
```

#### 输出结果说明

参见SET DEEPISOSW的参数说明。
