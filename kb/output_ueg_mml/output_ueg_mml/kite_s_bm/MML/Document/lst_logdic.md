# 查询日志模型信息（LST LOGDIC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询日志字典，日志字典中包含定义日志模型的基本信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

全量查询日志字典（模型）信息，可通过如下命令查询：

```
LST LOGDIC:SERVICEINSTANCE="vnfc";
```

#### 输出结果说明

| 输出项名称      | 输出项解释                              |
|:-----------|:-----------------------------------|
| 日志ID       | 日志ID。                              |
| 日志名称       | 日志名称。                              |
| 模块ID       | 模块ID。                              |
| 特性名称       | 日志所属特性名称。                          |
| 级别         | 日志的级别。                             |
