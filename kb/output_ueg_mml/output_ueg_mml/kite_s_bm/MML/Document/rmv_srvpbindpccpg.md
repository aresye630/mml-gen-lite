# 删除PCC组业务属性绑定（RMV SRVPBINDPCCPG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令,执行本命令后将删除指定PCC组与指定或所有业务属性间的绑定关系，可能会导致计费或控制策略发生变化，请谨慎使用。

此命令用于删除PCC策略组业务属性绑定组合。

支持删除指定PCCPOLICYGRPNM或所有的PCC策略组业务属性绑定组合。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                     |
|:---------------|:---------|:-----------------------------------------------------------------------------------------|
| PCCPOLICYGRPNM | PCC策略组名称 | 可选必选说明：必选参数 参数含义：设置PCC策略组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无 |
| SRVPROPNAME    | 业务属性名称   | 可选必选说明：可选参数 参数含义：设置业务属性名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无   |

#### 使用实例

删除TestPccPolicyGrpName的PCC策略组的PCC策略组业务属性绑定组合，即删除所有非默认组合：

```
RMV SRVPBINDPCCPG:PCCPOLICYGRPNM ="TestPccPolicyGrpName";
```
