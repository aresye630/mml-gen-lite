# 显示MPF Mp2属性配置（LST MPFMP2ATTR）

#### 命令功能

**适用NF：MPF**

该命令用于显示MPF Mp2链路探测功能开关状态与链路探测的周期。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

显示MPF Mp2属性配置：

```
LST MPFMP2ATTR:;
```

```
RETCODE = 0  操作成功

MPF Mp2链路属性
----------------------
Mp2链路探测开关  =  DISABLE
Mp2链路探测周期（秒）  =  60
(结果个数 = 1)
```

#### 输出结果说明

参见SET MPFMP2ATTR的参数说明。
