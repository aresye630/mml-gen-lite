# 修改MEC服务（MOD MECSERVICE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

该命令用于修改指定MEC服务的注册信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                   |
|:------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICENAME | 服务名称   | 可选必选说明：必选参数 参数含义：该参数用于指定服务名称。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“_”组成，且只能以字母或者数字开头。 默认值：无 配置原则：无                                                                                          |
| SERVICETAG  | 服务标签   | 可选必选说明：可选参数 参数含义：该参数用于指定服务标签。 数据来源：本端规划 取值范围： MP1SERVICE：通过Mp1接口注册的服务。MEPSERVICE：MEP平台提供的服务。MM5SERVICE：通过MM5接口注册的服务。LESERVICE：通过Le接口开放的服务。MP2SERVICE：通过Mp2接口开放的服务。 默认值：无 配置原则：根据MEP平台对接该服务时所使用的接口类型配置。 |
| PROTOCOL    | 协议类型   | 可选必选说明：可选参数 参数含义：该参数用于指定服务所使用的协议。 数据来源：对端协商 取值范围： HTTP：HTTP协议。HTTPS：HTTPS协议。 默认值：无 配置原则：根据该服务的协议类型配置。                                                                                                  |
| ENDPOINTGRP | 服务端点组  | 可选必选说明：可选参数 参数含义：该参数用于指定服务所使用的服务端点组。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“_”组成，且只能以字母或者数字开头。 默认值：无 配置原则： 该参数使用ADD SERVICEENDPOINTGRP命令配置生成。输入单空格将删除该参数已有配置项。                                |

#### 使用实例

修改服务名称为"mec\_service"的MECSERVICE对象的服务标签为MP2SERVICE，协议类型为HTTPS，服务端点组为"service\_endpoint\_grp"：

```
MOD MECSERVICE: SERVICENAME="mec_service", SERVICETAG=MP2SERVICE, PROTOCOL=HTTPS, ENDPOINTGRP="service_endpoint_grp";
```
