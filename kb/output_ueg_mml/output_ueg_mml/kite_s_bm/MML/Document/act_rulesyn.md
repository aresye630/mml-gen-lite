# 规则同步（ACT RULESYN）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：MPF**

该命令用于向与MPF对接的UPF同步Rule配置信息，支持以下三种场景：

（1）向MPF对接的指定UPF推送指定APP的Rule配置信息。

（2）向MPF对接的指定UPF推送全部APP的Rule配置信息。

（3）向MPF对接的全部UPF推送全部APP的Rule配置信息。

#### 注意事项

- 该命令执行后立即生效。
- 对于向MPF对接的指定UPF推送全部APP的Rule配置信息和向MPF对接的全部UPF推送全部APP的Rule配置信息两种场景，两次同步命令执行间隔不少于2分钟。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                     |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------|
| UPFNAME | UPF名称  | 可选必选说明：可选参数 参数含义：UPF名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无                                   |
| APPNAME | 应用名称   | 可选必选说明：可选参数 参数含义：指定应用名称，可以通过DSP APPLICATIONINFO查出所有的应用名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无 |

#### 使用实例

向MPF对接的全部UPF推送全部APP的Rule配置信息：

```
ACT RULESYN:;
RETCODE = 0  操作成功

---    END
```
