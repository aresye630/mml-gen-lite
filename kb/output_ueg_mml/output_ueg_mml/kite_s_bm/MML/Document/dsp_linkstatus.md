# 查询链路状态(DSP LINKSTATUS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明
- 参考信息

## 命令功能

该命令用于查询多框环境的链路配置信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

```
%%DSP LINKSTATUS:;%% 
RETCODE = 0  操作成功  

级联链路状态如下 
------------------ 
主框级联端口                    从框级联端口                    链路状态    主备状态
框号-0/槽位-3/网卡-6/端口-1     框号-1/槽位-1/网卡-6/端口-2     健康        主用
框号-0/槽位-4/网卡-6/端口-1     框号-1/槽位-2/网卡-6/端口-2     不健康      备用
框号-0/槽位-3/网卡-6/端口-2     框号-2/槽位-1/网卡-6/端口-2     健康        主用
框号-0/槽位-4/网卡-6/端口-2     框号-2/槽位-2/网卡-6/端口-2     不健康      备用
框号-0/槽位-3/网卡-7/端口-1     框号-3/槽位-1/网卡-6/端口-2     初始化      主用
框号-0/槽位-4/网卡-7/端口-2     框号-3/槽位-2/网卡-6/端口-2     初始化      备用
(结果个数 = 6)  

sRouter状态如下 
--------------           
主框sRouter       从框sRouer        sRouter状态     主备状态
框号-0/槽位-3     框号-1/槽位-1     健康            主用
框号-0/槽位-4     框号-1/槽位-2     不健康          备用
框号-0/槽位-3     框号-2/槽位-1     健康            主用
框号-0/槽位-4     框号-2/槽位-2     不健康          备用
框号-0/槽位-3     框号-3/槽位-1     初始化          主用
框号-0/槽位-4     框号-3/槽位-2     初始化          备用
(结果个数 = 6)  
---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息，输出项如表1所示。

命令执行异常，会返回对应的错误码。错误码列表如表2所示。

| 输出项名称     | 输出项解释                     |
|:----------|:--------------------------|
| 主框级联端口    | 级联链路连接的主框端口。              |
| 从框级联端口    | 级联链路连接的从框端口。              |
| 链路状态      | 级联链路的状态。 空闲初始化未知 健康不健康    |
| 主备状态      | 级联链路的主备状态。 主用备用初始化        |
| 主框sRouter | sRouter服务所在的主框框槽号。        |
| 从框sRouer  | sRouter服务所在的从框框槽号。        |
| sRouter状态 | sRouter的状态。 空闲初始化未知 健康不健康 |
| 主备状态      | sRouter的主备状态。 主用备用初始化     |

|      错误码 | 错误码解释   | 原因分析                   | 处理建议                          |
|---------:|:--------|:-----------------------|:------------------------------|
| 15500515 | 不支持当前操作 | 当级联配置开关为关闭状态时，不支持当前操作。 | 请检查级联配置，如果级联开关为关闭状态，不建议执行该命令。 |
