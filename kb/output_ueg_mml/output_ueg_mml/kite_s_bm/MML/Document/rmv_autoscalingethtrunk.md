# 删除以太网隧道自动化多虚拟网卡配置模板（RMV AUTOSCALINGETHTRUNK）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除以太网隧道多虚拟网卡自动化配置模板。

#### 注意事项

- 该命令执行后立即生效。
- 该命令在自动化配置开关为关闭的状态下才能执行，请先使用SET AUTOCONFIG命令关闭自动配置开关。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称        | 参数说明                                                                      |
|:--------------|:------------|:--------------------------------------------------------------------------|
| ETHTRUNKTMPID | 以太Trunk模板ID | 可选必选说明：必选参数 参数含义：该参数用来指定以太Trunk模板ID。 数据来源：本端规划 取值范围：整数类型，取值范围为1～99。 默认值：无 |

#### 使用实例

删除以太网隧道多虚拟网卡自动化配置模板：

```
RMV AUTOSCALINGETHTRUNK: ETHTRUNKTMPID=1;
```
