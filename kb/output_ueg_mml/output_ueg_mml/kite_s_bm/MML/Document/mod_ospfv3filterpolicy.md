# 修改OSPFv3过滤策略配置（MOD OSPFV3FILTERPOLICY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改OSPFv3过滤策略。

#### 注意事项

- 该命令执行后立即生效。
- 若待修改的FilterPolicy不存在，则会执行失败。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识              | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                                                              |
|:------------------|:-------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROCID            | OSPFv3进程号    | 可选必选说明：必选参数 参数含义：OSPFv3进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 配置原则：OSPFv3进程必须已经存在。请使用LST OSPFV3命令查看可用的OSPFv3进程。                                                                                                                                                                                                        |
| TOPOID            | 拓扑标识         | 可选必选说明：必选参数 参数含义：拓扑标识。 数据来源：全网规划 取值范围：整数类型，取值范围为0。 默认值：无 配置原则：目前只支持默认拓扑0。                                                                                                                                                                                                                                                         |
| FILTERTYPE        | 过滤方向         | 可选必选说明：必选参数 参数含义：该参数用于指定过滤方向是import还是export。 数据来源：本端规划 取值范围：枚举类型。 import：引入方向的过滤。export：发布方向的过滤。 默认值：无 配置原则： import表示对接收到的区域内，区域间和自治系统外部的路由进行过滤。export表示对通过引入路由（OSPFv3）命令引入的路由信息向外发布时进行过滤。该命令需要配置在ASBR上。                                                                                                                          |
| TYPE              | 过滤规则类型       | 可选必选说明：必选参数 参数含义：该参数用于指定过滤类型。 数据来源：本端规划 取值范围：枚举类型。 acl_name：ACL名称。ip_prefix：IPv6前缀过滤策略名称。route_policy：路由策略名。acl_num：ACL号。 默认值：无                                                                                                                                                                                                   |
| ACLNAMEORNUM      | ACL名称或ACL号   | 可选必选说明：条件必选参数 前提条件：该参数在“TYPE”配置为“acl_name” 或 “acl_num”时为必选参数。 参数含义：该参数用于指定ACL规则组名称或是编号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则： 当过滤类型指定为acl_name或者acl_num时生效。配置时，ACL名称或ACL号实际下发由内部自动区分，不依照过滤类型。不支持空格，区分大小写。当输入ACL名称时以英文字母a～z或A～Z开始，可以是英文字母、数字、连字符“-”或下划线“_”的组合。当输入ACL号时，取值范围是2000~2999。请使用LST ACLGROUP6命令查看已配置的IPv6 ACL规则组。 |
| IPPREFIX          | IPv6前缀过滤策略名称 | 可选必选说明：条件必选参数 前提条件：该参数在“TYPE”配置为“ip_prefix”时为必选参数。 参数含义：该参数用于指定待过滤的IPv6前缀过滤策略名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～169。 默认值：无 配置原则：请使用LST IPV6PREFIXFILTERNODE命令查看已配置的IPv6前缀过滤器节点。                                                                                                                                                    |
| ROUTEPLYNAME      | 路由策略名称       | 可选必选说明：条件必选参数 前提条件：该参数在“TYPE”配置为“route_policy”时为必选参数。 参数含义：该参数用于指定路由策略名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无 配置原则：请使用LST ROUTEPOLICY命令查看已配置的路由策略。                                                                                                                                                                           |
| PROTOCOL          | 协议号          | 可选必选说明：条件可选参数 前提条件：该参数在“FILTERTYPE”配置为“export”时为可选参数。 参数含义：该参数用于指定对某一种协议的路由进行过滤。 数据来源：本端规划 取值范围：枚举类型。 direct：直连路由。static：静态路由。bgp：BGP协议。ospfv3：OSPFv3协议。wlr：无线路由。 默认值：无                                                                                                                                                           |
| PROTOCOLPROCESSID | 协议进程号        | 可选必选说明：条件必选参数 前提条件：该参数在“PROTOCOL”配置为“ospfv3”时为必选参数。 参数含义：该参数用于指定对某一进程的路由进行过滤。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 配置原则： OSPFv3引入外部路由后，为了避免路由环路的产生，通过过滤策略命令对引入的路由在发布时进行过滤，只将满足条件的外部路由转换为Type-5LSA并发布出去。通过指定protocol或process-id对特定的某一种协议或者某一进程的路由进行过滤。如果没有指定protocol和process-id，则OSPFv3将对所有进入的路由信息进行过滤。                    |

#### 使用实例

在设备上OSPFv3进程1下，修改为acl 2222：

```
MOD OSPFV3FILTERPOLICY: PROCID=1,TOPOID=0,FILTERTYPE=import,TYPE=acl_num,ACLNAMEORNUM="2222";
```
