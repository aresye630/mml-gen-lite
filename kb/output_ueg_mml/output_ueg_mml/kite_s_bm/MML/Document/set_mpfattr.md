# 设置MPF属性配置（SET MPFATTR）

#### 命令功能

**适用NF：MPF**

**须知** 

本命令属于高危命令，“Mm5接口消息类型”的APPD类型和指定SPEC\_RULE类型互斥，配置成功后会导致另一种类型消息不作处理，请谨慎执行。

该命令用于设置MPF上Mm5接口可以处理的消息类型和MepId标识，支持以下两种配置：

（1）APPD（app descriptor）类型，会在Mm5接口的一条HTTPS请求消息中的APPD配置中同时携带动态DNS Rule、动态Traffic Rule、第三方APP依赖的服务以及第三方APP提供的服务等信息。

（2）指定SPEC\_RULE类型，会在Mm5接口的一条HTTPS请求消息中只携带动态DNS Rule或动态Traffic Rule信息，该场景下请求消息中会携带MepId标识，无需通过SET MPFATTR命令本地配置。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 当Mm5接口消息类型为指定SPEC\_RULE时，通过SET MPFATTR命令配置的MepId无效。
- 该命令属于整机控制，切换Mm5接口消息类型请注意以下几点：
  1. 如果当前消息类型为APPD，需切换为SPEC\_RULE类型时，需要将APPD类型相关配置全部删除，可通过管理面MEPM或者执行ACT DELETEAPPCONF命令删除
  2. 如果当前消息类型为SPEC\_RULE，需切换为APPD类型时，需要将SPEC\_RULE类型下的动态规则和MepId删除，可通过管理面MEPM或者按照配置残留手动删除。手动删除：先执行ACT DELETERULE命令删除动态规则，再执行ACT DELETEMEPID删除MepId标识
  3. 执行ACT DELETERULE命令删除动态规则会导致无法进行对应的业务，切换模式请谨慎操作。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | MM5MSGTYPE   | MEPID   |
|:-------|:-------------|:--------|
| 初始值    | APPD         | mpf     |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                                                                               |
|:-----------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
| MM5MSGTYPE | Mm5接口消息类型 | 可选必选说明：必选参数 参数含义：该参数用于设置Mm5接口可以处理的消息类型。 数据来源：全网规划 取值范围：枚举类型。 APPD：表示rule模式为APPD模式。SPEC_RULE：表示rule模式为指定rule模式。 默认值：无 配置原则：无                        |
| MEPID      | MEP ID    | 可选必选说明：条件可选参数 前提条件：该参数在“MM5MSGTYPE”配置为“APPD”时为可选参数。 参数含义：该参数用于配置MEP ID信息。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～31。取值范围为大小写字母、数字、短中划线、下划线、等号。 默认值：无 配置原则：无 |

#### 使用实例

设置MPF属性配置：

```
SET MPFATTR: MM5MSGTYPE=APPD, MEPID="mepid";
```
