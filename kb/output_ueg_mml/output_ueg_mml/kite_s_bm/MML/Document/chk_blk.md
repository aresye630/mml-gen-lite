# CSDB检查闭塞RU（CHK BLK）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于CSDB服务端检查能否闭塞指定SCALEGROUP包含的RU。

#### 注意事项

- 该命令在容器场景下不支持。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                                                     |
|:-----------|:--------|:-------------------------------------------------------------------------------------------------------------------------|
| SCALEGROUP | 物理资源组名称 | 可选必选说明：必选参数 参数含义：该参数用于指定唯一一个物理资源组。 数据来源：该物理资源组名称可以通过LST SERVICERUSTATE命令查询获取，对应ScaleGroup的名字。 取值范围：字符串类型，长度为1～63。 默认值：无。 |

#### 使用实例

检查SG1\_CSDB\_ForCommon物理资源组是否可以闭塞RU:

```
CHK BLK: SCALEGROUP="SG1_CSDB_ForCommon";
RETCODE = 0  操作成功。

操作结果如下：
--------------
是否支持闭塞RU  =  支持闭塞RU
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称    | 参数说明                                                                                                    |
|:---------|:--------------------------------------------------------------------------------------------------------|
| 是否支持闭塞RU | 检查是否支持闭塞指定SCALEGROUP包含的RU。 取值范围： “支持闭塞RU”：支持闭塞指定SCALEGROUP包含的RU的操作。“不支持闭塞RU”：不支持闭塞指定SCALEGROUP包含的RU的操作。 |
