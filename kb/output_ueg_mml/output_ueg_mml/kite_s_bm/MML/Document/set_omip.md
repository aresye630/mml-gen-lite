# 设置OM IP (SET OMIP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**须知** 

该类命令执行之后可能会**导致OM Portal断链以及网管断链，**需使用修改后IP重新登录OM Portal，并重新对接网管。该命令若执行不当，**会导致所有业务中断**。

用于修改系统OM网络配置参数，包括外部浮动IP地址、外部物理IP、子网掩码（IPV4场景）/前缀长度（IPV6场景）、默认网关。

#### 注意事项

该命令仅限角色为Administrators的用户执行。

#### 使用实例

设置浮动IP信息：

```
%%SET OMIP: OMIPTYPE=IPV4, OMSETTYPE=SET_IP, OMFIPADDR="192.168.1.100", OMNETMASK="255.255.255.0", OMIPV4GATEWAY="192.168.1.1", OMHOST1IPV4="192.168.1.99", OMHOST2IPV4="192.168.1.98";%%
RETCODE = 0  操作成功
```

删除浮动IP信息：

```
%%SET OMIP: OMIPTYPE=IPV4, OMSETTYPE=DELETE_FLOAT_IP;%%
RETCODE = 0  操作成功
```

删除物理IP信息：

```
%%SET OMIP: OMIPTYPE=IPV4, OMSETTYPE=DELETE_PHYSICAL_IP;%%
RETCODE = 0  操作成功
```
