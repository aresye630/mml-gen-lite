# 显示指定的线性表记录（DSP SFELINEARTABLE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于根据索引显示指定的线性表记录。

#### 注意事项

该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 使用实例

显示指定资源单元、指定索引号的线性表：

```
DSP SFELINEARTABLE:STRINDEX="1",TABLETYPE=VPN,RUNAME="VNODE_VNRS_VNFC_IPU_0066";
```
