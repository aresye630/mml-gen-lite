# 显示系统中正在监控的KPI信息（DSP KPIMONSTATE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示系统中正在监控的KPI信息。

## 注意事项

若输出结果中“状态”为异常，可以执行DSP KPIMONVALUE命令查询具体的异常指标值。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                     |
|:-----------|:-------|:-----------------------------------------------------------------------------------------|
| METRICTYPE | 指标类型   | 可选必选说明：必选参数  参数含义：该参数用于指定指标类型。  数据来源：本端规划 取值范围： KPI（KPI）  默认值：无  配置原则：无                  |
| METRICID   | 测量指标ID | 可选必选说明：可选参数  参数含义：该参数用于指定测量指标ID。  数据来源：本端规划  取值范围：整数类型，取值范围是0~4294967295。  默认值：无  配置原则：无 |
| MOIID      | 对象实例ID | 可选必选说明：可选参数  参数含义：该参数用于指定对象实例ID。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无     |
| MONSTAT    | 状态     | 可选必选说明：可选参数  参数含义：该参数用于指定检测状态。  数据来源：本端规划 取值范围： NORMAL（正常）ABNORMAL（异常）  默认值：无  配置原则：无    |

## 使用实例

显示系统中正在监控的所有KPI异常检测信息。

```
%%DSP KPIMONSTATE: METRICTYPE=KPI;%%
RETCODE = 0  操作成功

结果如下
```
