# 删除LCS客户端策略（RMV LCSCLIENTPLY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除LCS Client的策略。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                           |
|:------------|:---------|:-------------------------------------------------------------------------------|
| LCSCLIENTID | LCS客户端标识 | 可选必选说明：必选参数 参数含义：该字段用于标识LCS客户端。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无 |

#### 使用实例

将CLIENTID为“app1”的LCS客户端策略删除：

```
RMV LCSCLIENTPLY: LCSCLIENTID="app1";
```
