# 清除LCS UE无关信息（CLR LCSNONUEINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

**须知** 

本命令属于高危命令，此操作会清除获取的UE无关信息，请确认是否继续？

该命令用于删除本地保存的LCS UE无关信息。

#### 注意事项

- 该命令执行后立即生效。
- 删除本地保存的LCS UE无关信息时，会触发非UE N2信息去订阅消息，后续再发起该基站下的用户定位时，重新触发非UE N2消息订阅流程。
- 不输入基站ID时，会清除所有基站的LCS UE无关信息。
- 执行该命令两分钟后，会删除基站信息。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                |
|:---------|:-------|:------------------------------------------------------------------------------------|
| GNODEBID | 基站ID   | 可选必选说明：可选参数 参数含义：该参数用于指定基站ID。 数据来源：全网规划 取值范围：整型数字类型，取值范围为0~4294967295。 默认值：无 配置原则：无 |

#### 使用实例

删除本地保存的基站ID为190041的LCS UE无关信息：

```
CLR LCSNONUEINFO: GNODEBID=190041;
```
