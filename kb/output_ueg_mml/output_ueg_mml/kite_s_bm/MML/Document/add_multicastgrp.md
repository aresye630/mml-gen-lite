# 增加组播组配置（ADD MULTICASTGRP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于新增静态组播组配置。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为8192。
- 单个名称只能绑定一个组播MAC地址。
- 多个组名可以绑定同一个组播MAC地址。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                                        |
|:-------------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------|
| MCASTGRPNAME | 组播组名称   | 可选必选说明：必选参数 参数含义：该参数用于配置组播组的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63，区分大小写。 默认值：无 配置原则：无                                                        |
| MCASTMACADDR | 组播MAC地址 | 可选必选说明：必选参数 参数含义：该参数用于配置组播MAC地址。 数据来源：本端规划 取值范围：字符串类型，输入长度为17位。字符串应符合MAC地址格式，如11-11-11-11-11-11。组播类型的MAC地址从左到右第一个字节的最后一个bit为1。 默认值：无 配置原则：无 |

#### 使用实例

增加静态组播组配置：

```
ADD MULTICASTGRP: MCASTGRPNAME="group", MCASTMACADDR="11-11-11-11-11-11";
```
