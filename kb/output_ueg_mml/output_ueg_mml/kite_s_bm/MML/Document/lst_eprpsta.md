# 查询EPRPSTA对象（LST EPRPSTA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：SGW-U、PGW-U**

该命令用于查询EpRpSta对象。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                           |
|:--------------|:-------|:---------------------------------------------------------------------------------------------------------------|
| INTERFACETYPE | 接口类型   | 可选必选说明：必选参数 参数含义：接口类型。 数据来源：本端规划 取值范围：枚举类型。 SXA：接口类型为Sxa。SXB：接口类型为Sxb。SXBGSN：接口类型为Sxb，且用户角色为GGSN。 默认值：无 配置原则：无 |

#### 使用实例

查询接口类型为SXA的EpRpSta对象：

```
LST EPRPSTA: INTERFACETYPE=SXA;
```
