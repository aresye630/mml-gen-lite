# 增加硬件设备信息（ADD HW）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

本命令用于增加硬件设备信息。

#### 注意事项

该命令中的“设备名称”为唯一标识，重复添加相同的“设备名称”会覆盖之前的数据。

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                              |
|:----------|:-------|:----------------------------------------------------------------------------------|
| HWNAME    | 设备名称   | 可选必选说明：必选参数。 参数含义：设备名称。 取值范围：长度不超过64的字符串。 默认值：2。 配置原则：无。                          |
| HWTYPE    | 设备类型   | 可选必选说明：必选参数。 参数含义：设备类型。 取值范围：。 EXTERNAL(外置)：标识此设备为外置硬件。 默认值：EXTERNAL(外置)。 配置原则：无。 |
| CHASSISID | 硬件框号   | 可选必选说明：必选参数。 参数含义：硬件框号。 取值范围：0~999999。 默认值：2。 配置原则：无。                             |
| BLADEID   | 硬件槽号   | 可选必选说明：必选参数。 参数含义：硬件槽号。 取值范围：0~999999。 默认值：1。 配置原则：无。                             |

#### 使用实例

修改0框1槽单板的密码。

```
%%ADD HW: HWNAME="2", HWTYPE=EXTERNAL, CHASSISID=2, BLADEID=2;%%
RETCODE = 0  操作成功
---    END
```

#### 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误描述。常见错误描述如表1 错误码列表所示。
