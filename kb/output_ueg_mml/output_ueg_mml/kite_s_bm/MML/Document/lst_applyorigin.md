# 查询BGP路由信息的路由源设置（LST APPLYORIGIN）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询BGP路由信息的路由源设置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                     |
|:-----------|:-------|:-------------------------------------------------------------------------|
| POLICYNAME | 路由策略名字 | 可选必选说明：可选参数 参数含义：该参数用来表示路由策略名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无 |

#### 使用实例

查询路由策略节点下的路由源类型：

```
LST APPLYORIGIN:;
```

```
RETCODE = 0  操作成功。

结果如下
--------
  路由策略名字  =  policy
路由策略节点号  =  10
    路由源类型  =  内部路由
          AS号  =  NULL
(结果个数 = 1)
---    END
```
