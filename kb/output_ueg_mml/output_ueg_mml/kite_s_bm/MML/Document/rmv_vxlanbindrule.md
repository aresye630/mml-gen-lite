# 删除VXLAN隧道组绑定Rule（RMV VXLANBINDRULE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，删除配置会导致匹配到对应规则的数据报文无法转发给MEP。

该命令用于删除VXLAN隧道组与Rule的绑定关系。

#### 注意事项

- 该命令执行后立即生效。
- 执行该命令时，删除Rule绑定的Vxlan组会改变业务流的转发流程,匹配到该rule的数据报文由转发给MEP修改为直接路由转发或转发到新的MEP。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                 |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RULENAME | 规则名称   | 可选必选说明：必选参数 参数含义：该参数用于设置规则名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数必须已经通过ADD RULE命令配置。ADD RULE命令中POLICYTYPE为WORKER，WORKERNAME为traffic-fd。其他类型的规则不能绑定VXLAN组。 |

#### 使用实例

删除所有VXLAN隧道组与testrule的绑定关系：

```
RMV VXLANBINDRULE: RULENAME="rule";
```
