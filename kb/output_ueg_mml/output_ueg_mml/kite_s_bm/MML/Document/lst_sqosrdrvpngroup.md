# 查询QoS重定向VPN组（LST SQOSRDRVPNGROUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询指定流行为中重定向VPN动作的信息。

#### 注意事项

该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                           |
|:-------------|:-------|:---------------------------------------------------------------------------------------------------------------|
| BEHAVIORNAME | 行为名称   | 可选必选说明：必选参数 参数含义：该参数用于指定流动作。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无 配置原则：区分大小写，不支持空格。 |

#### 使用实例

查询流行为b5中重定向VPN动作：

```
LST SQOSRDRVPNGROUP:BEHAVIORNAME="b5";
```

```
RETCODE = 0  操作成功。

结果如下
-------------------------
VPN组名称 = vg1
行为名称  = b5
(结果个数 = 1)
---    END
```
