# 添加授权服务（ADD AUTHSERV）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

该命令用于添加授权服务到指定的授权服务列表，当APP被授予访问该授权服务列表的权限后，APP可访问该列表中的所有授权服务。授权服务指允许APP通过MEP平台访问的服务，包括1）通过MM5接口注册的服务；2）通过MP1接口注册的服务；3)MEP平台自身提供的服务。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为3000。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                    |
|:----------------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICENAME     | 授权服务名称      | 可选必选说明：必选参数 参数含义：该参数用于指定授权服务名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～127。该服务名称由服务提供商提供，可通过DSP MECSERVICE命令查询到。 默认值：无 配置原则：无                                                                                                                                                                    |
| SERVICELISTNAME | 授权服务列表名称    | 可选必选说明：必选参数 参数含义：该参数用于指定授权服务列表名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：该参数使用ADD AUTHSERVLIST命令配置生成。                                                                                                                                                                             |
| AUTHVALIDTIME   | 授权有效时间的截止时间 | 可选必选说明：可选参数 参数含义：该参数用于指定授权有效期的截止时间。 数据来源：本端规划 取值范围：1、格式：YYYY/MM/DD/ HH:MM:SS YYYY（年份）：2021~2099 MM（月份）：1~12 DD（日期）：1~31 HH（小时）：00~23 MM（分钟）：00~59 SS（秒）：00~59。 2、闰年时月份等于02时，日期最大为29；平年时月份等于02时，日期最大为28；月份等于04/06/09/11时，日期最大为30。 3、不早于当前系统时间。 默认值：无 配置原则：根据期望的授权截止时间进行配置，如果为空，即为授权永久有效。 |

#### 使用实例

添加授权服务信息，服务名称为"app01\_service2"，绑定服务列表为"serviceList"，授权有效期截止时间为"2022/01/13 11:02:59"：

```
ADD AUTHSERV: SERVICENAME="app01_service2", SERVICELISTNAME="serviceList", AUTHVALIDTIME=2022&01&13&11&02&59;
```
