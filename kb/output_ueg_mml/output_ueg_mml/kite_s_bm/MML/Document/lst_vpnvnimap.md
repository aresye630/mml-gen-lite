# 查询VPN VNI映射（LST VPNVNIMAP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询VNI与VPN的映射关系。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                      |
|:------------|:-------|:------------------------------------------------------------------------------------------|
| VPNINSTANCE | VPN实例名 | 可选必选说明：可选参数 参数含义：该参数用于配置VPN实例。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，区分大小写。 默认值：无 配置原则：无 |
| RULENAME    | 规则名称   | 可选必选说明：可选参数 参数含义：该参数用于设置规则名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

查询所有VNI与VPN的映射关系：

```
LST VPNVNIMAP:;
```

```
RETCODE = 0 操作成功。

```
