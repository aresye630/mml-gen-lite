# 删除Diameter字典加载路径（RMV UPDIAMDICTPATH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

**须知** 

本命令属于高危命令，该操作会删除Diameter字典加载路径，可能影响下一次字典加载。

该命令用于删除Diameter字典加载路径。

#### 注意事项

- 该命令执行后立即生效。
- 对于第一套字典执行RMV命令时，表示第一套字典加载路径恢复为EPC标准字典加载路径。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                  |
|:------------|:-------|:--------------------------------------------------------------------------------------|
| APPLICATION | 应用     | 可选必选说明：可选参数 参数含义：该参数用于指定字典的Diameter应用。 数据来源：本端规划 取值范围：枚举类型。 SWM：SWM接口应用。 默认值：无 配置原则：无 |
| DICTNO      | 字典序号   | 可选必选说明：可选参数 参数含义：该参数用于指定字典编号。 数据来源：本端规划 取值范围：整数类型，取值范围为1。 默认值：无 配置原则：无                |

#### 使用实例

当需要将SWM应用的第一套字典加载路径恢复成EPC标准字典时：

```
RMV UPDIAMDICTPATH: APPLICATION=SWM, DICTNO=1;
```
