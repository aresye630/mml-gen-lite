# 查询过载限速参数（LST OVERLOADQOSCTRL）

- 命令功能

- 操作用户权限

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于查询过载限速参数。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询过载限速功能配置，执行如下命令：

```
LST OVERLOADQOSCTRL:;
```

