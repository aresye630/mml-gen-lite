# 增加应用防攻击策略（ADD SECPOLICYCFG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 参考信息

#### 命令功能

该命令用来添加应用防攻击策略。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1024。
- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------------|
| RUNAME   | RU名称   | 可选必选说明：必选参数 参数含义：资源单元名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。区分大小写。 默认值：无 配置原则：区分大小写，不支持空格，下发本MML命令前可使用DSP RU查看资源单元信息。 |
| POLICYID | 安全策略编号 | 可选必选说明：必选参数 参数含义：安全策略号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～30。 默认值：无 配置原则：需要先添加安全策略，下发本MML命令前可使用LST SECPOLICY查看已添加的安全策略。    |

#### 使用实例

添加应用防攻击策略：

```
ADD SECPOLICYCFG: RUNAME="VNODE_VNRS_VNFC_IPU_0064", POLICYID=1;
```

#### 参考信息

需要先添加安全策略。
