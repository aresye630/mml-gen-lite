# 创建OSPFv3 GTSM配置（ADD OSPFV3GTSM）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于用来使能OSPFv3 GTSM特性，并配置需要检测的TTL值。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为8016。
- 如果在ADD OSPFV3GTSM命令中指定了VPN实例，并且接口绑定了该VPN实例，则当配置的TTL值小于实际网络中TTL值时，发送到该接口的所有单播报文将被丢弃。
- 如果配置了虚连接或伪连接，配置的TTL值需要与实际的TTL值一致，即将虚连接和伪连接所经过的路由器的数量计算在内，否则从虚连接或伪连接的邻居发来的报文将被丢弃。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                            |
|:--------|:-------|:----------------------------------------------------------------------------------------------------------------|
| VRFNAME | VPN实例名 | 可选必选说明：可选参数 参数含义：VPN实例名。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：_public_ 配置原则： 默认为公网配置。使用LST L3VPNINST命令查看可用VPN。 |
| TTL     | TTL值   | 可选必选说明：必选参数 参数含义：TTL值。 数据来源：本端规划 取值范围：整数类型，取值范围为1～255。 默认值：无 配置原则：如果配置了GTSM，被检测的报文的TTL值有效范围为[ 255–TTL+1, 255 ]。 |

#### 使用实例

使能OSPFv3 GTSM功能，配置允许接收的私网OSPFv3报文的最大跳数为5：

```
ADD OSPFV3GTSM:VRFNAME="abc",TTL=5;
```
