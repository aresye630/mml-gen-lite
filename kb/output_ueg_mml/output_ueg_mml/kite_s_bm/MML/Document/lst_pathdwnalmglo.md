# 查询单条路径断告警抑制参数全局配置（LST PATHDWNALMGLO）

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用来查询单条路径断告警抑制参数。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询ALM-81018 GTPU路径断告警抑制参数：

```
LST PATHDWNALMGLO:;
```

```
RETCODE = 0  操作成功。

单路径告警抑制参数全局配置
--------------------------
告警上报的连续中断次数  =  5
    告警上报的探测次数  =  5
告警上报的累计中断次数  =  3
告警恢复的连续正常次数  = 5
(结果个数 = 1)
---    END
```
