# 查询调度组详细统计信息（DSP MSSSCHGRPFIX）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询调度组统计工作组信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                   |
|:----------|:--------|:-------------------------------------------------------------------------------------------------------|
| RUNAME    | RU名称    | 可选必选说明：必选参数 参数含义：该参数用于指定RU名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：使用DSP RU查看RU名称。 |
| INGROUPID | 输入调度组ID | 可选必选说明：必选参数 参数含义：该参数用于表示输入调度组ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                          |

#### 使用实例

查询调度组的统计工作组信息：

```
DSP MSSSCHGRPFIX:INGROUPID = 0,RUNAME = "VNODE_VNRS_VNFC_IPU_0064";
```
