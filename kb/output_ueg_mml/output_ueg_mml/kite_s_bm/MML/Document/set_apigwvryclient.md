# 设置API GW对端证书校验开关（SET APIGWVRYCLIENT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

**须知** 

本命令属于高危命令，关闭证书校验开关后，API GW将对所有的接口调用不进行证书校验，可能存在因为对端设备被仿冒导致的安全风险，请谨慎关闭。

该命令用于控制是否使能API GW对对端设备的证书校验。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令仅适用于未配置反向代理的场景，可通过LST MEPREVERSEPROXY命令查询当前环境是否配置反向代理。
- 关闭证书校验开关后，API GW将对所有的接口调用不进行证书校验，可能存在因为对端设备被仿冒导致的安全风险，请谨慎关闭。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | VRYSWITCH   |
|:-------|:------------|
| 初始值    | ENABLE      |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                                  |
|:----------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------|
| VRYSWITCH | 校验对端证书开关 | 可选必选说明：必选参数 参数含义：是否使能API GW对对端设备的证书校验。 数据来源：本端规划 取值范围：枚举类型。 ENABLE：开启API GW校验对端证书。DISABLE：关闭API GW校验对端证书。关闭后有安全风险，不建议使用。 默认值：无 配置原则：无 |

#### 使用实例

开启校验对端证书开关：

```
SET APIGWVRYCLIENT: VRYSWITCH=ENABLE;
```
