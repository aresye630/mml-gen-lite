# 查询L2TP N4密码配置（LST L2TPN4KEY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查看已设置的N4密钥。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询已设置的N4密钥：

```
LST L2TPN4KEY:;
```

```
RETCODE = 0  操作成功

L2TP N4密码配置
---------------
    N4密钥  =  *****
确认N4密钥  =  *****
(结果个数 = 1)

---    END
```
