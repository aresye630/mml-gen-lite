# 删除应用性能统计（RMV APPPERFSTAT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、PGW-U**

该命令用于删除一组应用性能统计。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                      |
|:--------|:-------|:------------------------------------------------------------------------------------------|
| APPNAME | 应用名称   | 可选必选说明：必选参数 参数含义：该参数用来指定应用名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

该命令用于删除一组应用性能统计，则配置命令如下：

```
RMV APPPERFSTAT:APPNAME="test";
```
