# 查询APP操作信息（DSP APPOPERATE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：MPF**

该命令用于查看APP操作信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                    |
|:--------------|:-------|:------------------------------------------------------------------------|
| APPINSTANCEID | APP实例号 | 可选必选说明：可选参数 参数含义：APP实例号。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：无 |

#### 使用实例

- 查看指定APP的配置操作信息，APP实例号为"202005140731"：

  ```
  DSP APPOPERATE: APPINSTANCEID="202005140731";
  ```

  ```
  RETCODE = 0  操作成功

  APP操作信息
  -----------
        任务ID  =  202005140731
     APP实例号  =  202005140731
      操作类型  =  ADD
      配置结果  =  SUCCESS
      配置进度  =  100%
      详细信息  =  appd configuration success

  任务结束时间  =  2020-05-14 19:32:05
  (结果个数 = 1)

  ---    END
  ```
- 查看所有APP的配置操作信息，不输入app实例号：

  ```
  DSP APPOPERATE:;
  ```


#### 输出结果说明

| 输出项名称   | 输出项解释                     |
|:--------|:--------------------------|
| 任务ID    | 任务ID。                     |
| APP实例号  | APP实例号。                   |
| 操作类型    | 操作类型，值有"ADD"和 "DELETE"两种。 |
| 配置结果    | 当前操作阶段的配置结果。              |
| 配置进度    | 当前增加或者删除配置的进度。            |
| 详细信息    | 当前操作阶段的详细描述信息。            |
| 任务创建时间  | APP配置任务创建时间。              |
| 任务结束时间  | APP配置任务执行结束时间。            |
