# 修改VXLAN隧道端点绑定隧道组（MOD VTEPBINDGRP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于修改VXLAN隧道端点与隧道组的绑定关系的主备用类型。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                                                    |
|:-------------|:---------|:------------------------------------------------------------------------------------------------------------------------|
| VXLANGRPNAME | VXLAN组名称 | 可选必选说明：必选参数 参数含义：该参数用于指定VXLAN隧道组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用 ADD VXLANGRP命令配置生成。 |
| VTEPNAME     | VTEP名称   | 可选必选说明：必选参数 参数含义：该参数用于指定VXLAN隧道端点名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用 ADD VTEP命令配置生成。    |
| PRIFLAG      | 主备用类型    | 可选必选说明：必选参数 参数含义：指定VXLAN隧道端点主备用类型。 数据来源：本端规划 取值范围：枚举类型。 PRIMARY：主用。SECONDARY：备用。 默认值：无 配置原则：无                           |

#### 使用实例

将绑定在VXLAN隧道组vxlangrp的隧道端点vtep1修改为备用：

```
MOD VTEPBINDGRP: VXLANGRPNAME="vxlangrp", VTEPNAME="vtep1", PRIFLAG=SECONDARY;
```
