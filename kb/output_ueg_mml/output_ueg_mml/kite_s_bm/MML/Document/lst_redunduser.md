# 查询静态地址用户路由冗余功能（LST REDUNDUSER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用来显示当前设备静态地址用户路由冗余功能使能状态。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

显示静态地址用户路由冗余功能是否使能：

```
LST REDUNDUSER:;
```

```
RETCODE = 0 操作成功。
结果如下 
---------------------- 
开关 = 不使能 (结果个数 = 1) 
--- END
```

#### 输出结果说明

参见SET REDUNDUSER的参数说明。
