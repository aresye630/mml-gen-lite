# 增加LMF信息（ADD LMFINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于添加LMF信息。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该配置为可选配置，初始配置为NULL，如果不设置LmfId，则LMF给GMLC上报用户位置时，不携带LmfId信元。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                 |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------|
| LMFID  | LMF标识  | 可选必选说明：必选参数 参数含义：该参数用于指定LMF标识。 数据来源：全网规划 取值范围：字符串类型，输入长度范围是1~255。本参数的构成字符只能是字母A～Z或a～z、数字0～9、中划线"-"和下划线"_"组成的字符串。大小写不敏感。 默认值：无 配置原则：无 |

#### 使用实例

添加LMF信息：

```
ADD LMFINFO: LMFID="123";
```
