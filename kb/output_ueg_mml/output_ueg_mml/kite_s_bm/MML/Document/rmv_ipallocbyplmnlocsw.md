# 删除基于位置区+PLMN分配地址的开关（RMV IPALLOCBYPLMNLOCSW）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于删除基于位置区+PLMN分配地址开关配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LOCATIONGRPTYPE | 位置区组类型 | 可选必选说明：必选参数 参数含义：该参数用于指定位置区组类型。 数据来源：本端规划 取值范围：枚举类型。只能选取一个选项。 LAC：LAC。TAC：TAC。 默认值：无 配置原则：无                                                                                                                  |
| LOCATIONGRPNAME | 位置区组名称 | 可选必选说明：必选参数 参数含义：该参数用于指定位置区组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则：无                                                                                                                               |
| MCC             | 移动国家码  | 可选必选说明：必选参数 参数含义：该参数用于指定移动国家码。 数据来源：全网规划 取值范围：字符串类型，为3位数字，000～999。 默认值：无 配置原则：无                                                                                                                              |
| MNC             | 移动网络号  | 可选必选说明：必选参数 参数含义：该参数用于指定移动网络号。 数据来源：全网规划 取值范围：字符串类型，可为2或3位数字，00~99或000~999。 默认值：无 配置原则：MNC有效配置长度为两位或三位。配置长度取决于PFCP Session Establishment Request消息ULI信元中携带的MNC有效值的长度，两位有效数字即配置两位，三位有效数字需配置三位。不受ADD MNCLEN影响。 |

#### 使用实例

删除位置区组名为tacgrp1，plmn为460011的 ‘基于位置区+PLMN分配地址开关-ADD IPALLOCBYPLMNLOCSW’ 的配置：

```
RMV IPALLOCBYPLMNLOCSW: LOCATIONGRPTYPE=TAC, LOCATIONGRPNAME="tacgrp1", MCC="460", MNC="01";
```
