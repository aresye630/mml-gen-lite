# 删除APP ID IMSI/MSISDN号段组绑定（RMV APPIDSEGBIND）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于删除APP ID和IMSI/MSISDN与本地APP ID的绑定关系。当运营商希望删除APP ID和IMSI/MSISDN与本地APP ID的绑定时，则执行该命令。

#### 注意事项

- 该命令执行后对新数据流生效。
- 如果不输入号段组名称，表示删除指定APP ID名称对应的所有的APP ID和号段组与本地APP ID的绑定关系。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称             | 参数说明                                                                                                    |
|:-----------|:-----------------|:--------------------------------------------------------------------------------------------------------|
| APPID      | APP ID名称         | 可选必选说明：必选参数 参数含义：该参数用于指定要绑定的APP ID。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无         |
| IMSIMSSEGG | IMSI/MSISDN号段组名称 | 可选必选说明：可选参数 参数含义：该参数用于指定要绑定的IMSI/MSISDN号段组。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |
| LOCALAPPID | 本地APP ID名称       | 可选必选说明：可选参数 参数含义：该参数用于指定本地APP ID。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：无           |

#### 使用实例

假如运营商需要删除指定APP ID与其对应所有本地APP ID的绑定关系：

```
RMV APPIDSEGBIND: APPID="testappid";
```
