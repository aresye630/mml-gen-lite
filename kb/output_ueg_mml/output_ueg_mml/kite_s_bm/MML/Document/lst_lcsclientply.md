# 查询LCS客户端策略（LST LCSCLIENTPLY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询LCS Client的策略。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                           |
|:------------|:---------|:-------------------------------------------------------------------------------|
| LCSCLIENTID | LCS客户端标识 | 可选必选说明：可选参数 参数含义：该字段用于标识LCS客户端。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无 |

#### 使用实例

查询所有的LCS客户端策略：

```
LST LCSCLIENTPLY:;
RETCODE = 0 操作成功

LCS客户端策略
--------------------
       LCS客户端标识  =  app1
    携带算法类型开关  =  DISABLE
周期定位用户缺省类型  =  Normal
    周期定位上报次数  =  1
        心跳上报开关  =  ENABLE
(结果个数 = 1)

---    END
```
