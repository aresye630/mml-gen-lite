# 查询分片方式（LST IFMTUFRAGMODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用来查询当前分片方式。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询当前接口分片方式：

```
LST IFMTUFRAGMODE:;
```

```
RETCODE = 0 操作成功                                                
                                                                                

结果如下                                                        
------------------------                                                        
分片方式  =  标签加IP分片方式                                                                
(结果个数 = 1)                                                                                                             
---    END
```

#### 输出结果说明

参见SET IFMTUFRAGMODE的参数说明。
