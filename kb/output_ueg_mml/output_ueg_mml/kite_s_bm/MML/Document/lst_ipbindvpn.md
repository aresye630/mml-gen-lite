# 查询接口绑定VPN（LST IPBINDVPN）

- 操作用户权限

#### 命令功能

该命令用于查询接口绑定VPN。

若不指定IFNAME参数时，则查询所有接口绑定的VPN；若指定IFNAME参数时，则查询指定接口绑定的VPN。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                       |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------|
| IFNAME | 接口名    | 可选必选说明：可选参数 参数含义：该参数用于表示绑定VPN的接口名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。接口名称由接口类型+接口编号组成。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。 |

#### 使用实例

查询接口绑定VPN：

```
LST IPBINDVPN:IFNAME="Ethernet64/0/1";
```

```
RETCODE = 0  操作成功。

结果如下
------------------------
      接口名  =  Ethernet64/0/1

(结果个数 = 1)
---    END
```
