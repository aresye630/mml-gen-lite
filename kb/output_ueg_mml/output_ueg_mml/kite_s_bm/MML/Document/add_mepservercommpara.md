# 添加MEP HTTP服务端通信参数（ADD MEPSERVERCOMMPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

服务端通信参数指MEP平台作为服务端和客户端通信时使用的参数，该命令用于添加一组服务端通信参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为128。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识                 | 参数名称          | 参数说明                                                                                                                           |
|:---------------------|:--------------|:-------------------------------------------------------------------------------------------------------------------------------|
| PARANAME             | HTTP服务端通信参数名称 | 可选必选说明：必选参数 参数含义：该参数用于指定HTTP服务端通信参数名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“.”组成，且只能以字母或者数字开头。 默认值：无 配置原则：无         |
| WAITREQHEADERTIMEOUT | 读取客户端请求头超时时间  | 可选必选说明：可选参数 参数含义：该参数用于指定API GW读取客户端请求头的超时时间。 数据来源：本端规划 取值范围：整数类型，取值范围为1～300。 默认值：60 配置原则：无                                     |
| WAITREQBODYTIMEOUT   | 读取客户端请求体超时时间  | 可选必选说明：可选参数 参数含义：该参数用于指定API GW读取客户端请求体的超时时间。超时仅设置在两个连续读取操作之间的时间段内，而不是用于整个请求体的传输。 数据来源：本端规划 取值范围：整数类型，取值范围为1-300。 默认值：60 配置原则：无 |
| SENDRSPTIMEOUT       | 向客户端发送响应超时时间  | 可选必选说明：可选参数 参数含义：该参数用于指定API GW向客户端发送响应的超时时间。超时仅在两个连续写操作之间设置，而不是用于传输整个响应。 数据来源：本端规划 取值范围：整数类型，取值范围为1-300。 默认值：60 配置原则：无         |
| KEEPALIVETIMEOUT     | 连接保活超时时间      | 可选必选说明：可选参数 参数含义：该参数用于指定客户端连接在API GW服务器端保持开启状态的超时时间。 数据来源：本端规划 取值范围：整数类型，取值范围为1-7200.。 默认值：75 配置原则：无                           |
| KEEPALIVEMAXREQNUM   | 保活连接可处理的最大请求数 | 可选必选说明：可选参数 参数含义：该参数用于指定API GW通过一个保活连接可处理的最大请求数。当在本连接上处理的请求数超出限制后，本连接将被关闭。 数据来源：本端规划 取值范围：整数类型，取值范围为1-100000。 默认值：1000 配置原则：无  |

#### 使用实例

添加MEPSERVERCOMMPARA对象，添加的MEPSERVERCOMMPARA对象名称为"srv-comm-para"，读取客户端请求头超时时间为"60"，读取客户端请求体超时时间为"60"，向客户端发送响应超时时间为"60"，连接保活超时时间为"75"，保活连接可处理的最大请求数为"1000"：

```
ADD MEPSERVERCOMMPARA: PARANAME="srv-comm-para", WAITREQHEADERTIMEOUT=60, WAITREQBODYTIMEOUT=60, SENDRSPTIMEOUT=60, KEEPALIVETIMEOUT=75, KEEPALIVEMAXREQNUM=1000;
```
