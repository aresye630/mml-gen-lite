# 新增多终端聚类组（ADD LCSUECLUSGRP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

配置多终端聚类组。

#### 注意事项

- 该命令最大记录数为1000。
- 某一个UEID只能出现在一个用户组中，而且只能出现一次。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                          |

| UEID1       | 终端1标识    | 可选必选说明：必选参数 参数含义：该参数用于指定UE1的标志。 数据来源：本端规划 取值范围：整数类型，取值范围为0～18446744073709551615。 默认值：无 配置原则：无 |
| UEID2       | 终端2标识    | 可选必选说明：必选参数 参数含义：该参数用于指定UE2的标志。 数据来源：本端规划 取值范围：整数类型，取值范围为0～18446744073709551615。 默认值：无 配置原则：无 |
| UEID3       | 终端3标识    | 可选必选说明：可选参数 参数含义：该参数用于指定UE3的标志。 数据来源：本端规划 取值范围：整数类型，取值范围为0～18446744073709551615。 默认值：无 配置原则：无 |
| UEID4       | 终端4标识    | 可选必选说明：可选参数 参数含义：该参数用于指定UE4的标志。 数据来源：本端规划 取值范围：整数类型，取值范围为0～18446744073709551615。 默认值：无 配置原则：无 |
| UEID5       | 终端5标识    | 可选必选说明：可选参数 参数含义：该参数用于指定UE5的标志。 数据来源：本端规划 取值范围：整数类型，取值范围为0～18446744073709551615。 默认值：无 配置原则：无 |
| DESCRIPTION | 描述信息     | 可选必选说明：可选参数 参数含义：该参数用于设置多终端聚合组配置描述信息。 数据来源：本端规划 取值范围：字符串类型，长度为32位。 默认值：无 配置原则：无               |

#### 使用实例

新增多终端聚类组：

```
ADD LCSUECLUSGRP: GROUPID=1, UEID1="33456789012342", UEID2="33456789012353";
```
