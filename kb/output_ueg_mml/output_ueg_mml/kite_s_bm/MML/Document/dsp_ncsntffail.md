# 显示通知消息发送失败信息（DSP NCSNTFFAIL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示通知消息发送失败信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| BOARDTYPE       | OMU类型  | 可选必选说明：可选参数 参数含义：OMU类型。 数据来源：本端规划 取值范围：枚举类型。 master：主OMU。slave：备OMU。 默认值：master                              |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

显示通知消息发送失败信息：

```
DSP NCSNTFFAIL:BOARDTYPE=master,SERVICEINSTANCE="vnfc";
```

#### 输出结果说明

| 输出项名称   | 输出项解释        |
|:--------|:-------------|
| 会话ID    | NETCONF会话标识。 |
| 通知时间戳   | 通知消息发送失败的时间。 |
| 事件类     | 通知的事件类型。     |
| 事件ID    | 通知的事件标识。     |
| 错误详细信息  | 通知发送失败的详细信息。 |
