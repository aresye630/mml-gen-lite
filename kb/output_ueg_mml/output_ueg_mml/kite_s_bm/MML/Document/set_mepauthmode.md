# 设置授权模式（SET MEPAUTHMODE）

- 命令功能
- 注意事项
- 操作用户权限

- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

**须知** 

本命令属于高危命令，修改授权模式后，更新前授权模式下配置的授权参数失效，APP无法继续使用MEP平台已签发的token访问已授权的服务，请谨慎修改。

该命令用于设置APP授权模式，在需要对访问MEP服务的APP进行访问权限控制时，可根据需要设置授权模式，当前支持如下三种授权模式：

（1）BYLOCALPARA：通过本地命令配置方式下发身份和访问权限信息对APP进行授权。

（2）BYMM5PARA：通过MM5接口下发身份和访问权限信息对APP进行授权。

（3）BYAPPD：通过APP描述文件描述身份和访问权限信息方式对APP进行授权。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | AUTHMODE    |
|:-------|:------------|
| 初始值    | BYLOCALPARA |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                |
|:---------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AUTHMODE | 授权模式   | 可选必选说明：必选参数 参数含义：该参数用于指定APP授权模式。 数据来源：本端规划 取值范围： BYLOCALPARA：通过本地命令配置方式下发身份和访问权限信息对客户端进行授权。BYMM5PARA：通过MM5接口下发身份和访问权限信息对客户端进行授权。BYAPPD：通过APP描述文件描述身份和访问权限信息方式对客户端进行授权。 默认值：无 配置原则：无 |

#### 使用实例

修改MEP授权模式为"BYAPPD"：

```
SET MEPAUTHMODE: AUTHMODE=BYAPPD;
```
