# 增加APP ID IMSI/MSISDN号段组绑定（ADD APPIDSEGBIND）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于增加APP ID和IMSI/MSISDN与本地APP ID的绑定关系。当运营商希望通过IMSI/MSISDN号段组实现不同用户使用不同的分流规则，则使用该配置增加号段组与本地APP ID的映射关系，当用户安装APP ID并且用户归属于配置的号段组时，则用户业务流按对应的本地APP ID进行分流。

#### 注意事项

- 该命令执行后对新数据流生效。
- 该命令最大记录数为50000。
- 每个APP ID最多可绑定100个号段组。
- 在已绑定APP ID的号段组中增加或删除号段，对新数据流生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称             | 参数说明                                                                                                                                                           |
|:--------------|:-----------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APPID         | APP ID名称         | 可选必选说明：必选参数 参数含义：该参数用于指定要绑定的APP ID。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数需要与PDR中携带的APP ID一致，且使用ADD FLOWFILTER或ADD FLOWFILTERGRP命令配置生成。 |
| IMSIMSSEGG    | IMSI/MSISDN号段组名称 | 可选必选说明：必选参数 参数含义：该参数用于指定要绑定的IMSI/MSISDN号段组。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD UPIMSIMSISDNG命令配置生成。                            |
| LOCALAPPID    | 本地APP ID名称       | 可选必选说明：必选参数 参数含义：该参数用于指定本地APP ID。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD FLOWFILTER或ADD FLOWFILTERGRP命令配置生成。                       |
| CFGDOMAINNAME | 配置域名称            | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无                                                                             |

#### 使用实例

假如运营商希望将名为“testappid”的APP ID和名为“testgroup”的号段组绑定本地APP ID“testlocalappid”：

```
ADD APPIDSEGBIND: APPID="testappid", IMSIMSSEGG="testgroup", LOCALAPPID="testlocalappid";
```
