# 设置VNRS IP消息跟踪的流控使能配置 (SET SFETRACEFCCFG)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

如果设置流控不使能，可能会导致业务呼损。

当CPU负载超阈值时，该命令用来设置VNRS IP消息跟踪的CPU流控功能是否开启。

#### 注意事项

- 该命令执行后立即生效。

- 该命令仅适用于非NP卡场景和NP卡非加速模式场景。

该命令存在系统初始记录（NP卡加速模式场景无需关注此初始记录），参数的初始设置值如下表：

| FLOWCTRLEN   |
|:-------------|
| TRUE（是）      |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                    |
|:-----------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------|
| FLOWCTRLEN | 流控使能标记 | 可选必选说明：必选参数 参数含义：该参数用于指定当CPU负载超阈值时，是否开启VNRS IP消息跟踪的CPU流控功能。 数据来源：本端规划 取值范围： “TRUE（是）”：表示CPU流控功能开启。“FALSE（否）”：表示CPU流控功能关闭。 默认值：无 配置原则：无。 |

#### 使用实例

```
关闭VNRS IP消息跟踪的CPU流控功能：
SET SFETRACEFCCFG: FLOWCTRLEN=FALSE;
```
