# 显示接口ACL规则（DSP ACLRULEIF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示当前系统中接口ACL规则的状态，也可以显示规则组下所有规则状态。

#### 注意事项

查询ACL规则前必须先执行ADD ACLRULEIF创建相应规则。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                       |
|:------------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| ACLNAME     | ACL规则组标识 | 可选必选说明：必选参数 参数含义：该参数用于指定规则属于哪个规则组。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。不支持空格，区分大小写。以英文字母a～z或A～Z开始，可以是英文字母、数字、连字符“-”、下划线“_”或中文字符的组合。整数形式，取值范围是1000～1999。 默认值：无 |
| ACLRULENAME | 规则名称     | 可选必选说明：可选参数 参数含义：该参数用于指定规则名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。不支持空格，区分大小写。 默认值：无                                                                          |

#### 使用实例

- 显示当前ACL规则组1000下所有规则的状态：

  ```
  DSP ACLRULEIF:ACLNAME="1000";
  ```

  ```
  RETCODE = 0  操作成功。

  结果如下
  --------
  ACL规则组标识    规则名称    规则ID    规则行为                  所有的接口    激活状态    规则描述    接口名

  1000             rule_5      5         指定匹配模式为允许模式    TRUE          激活        NULL        NULL
  1000             rule_10     10        指定匹配模式为允许模式    FALSE         激活        NULL        Ethernet64/0/3
  (结果个数 = 2)
  ---    END
  ```
- 显示当前ACL规则组1000中规则名称为"rule\_5"的规则状态：

  ```
  DSP ACLRULEIF:ACLNAME="1000",ACLRULENAME="rule_5";
  ```

  ```
  RETCODE = 0  操作成功。

  结果如下
  --------
  ACL规则组标识  =  1000
       规则名称  =  rule_5
         规则ID  =  5
       规则行为  =  指定匹配模式为允许模式
     所有的接口  =  TRUE
       激活状态  =  激活
       规则描述  =  NULL
         接口名  =  NULL
  (结果个数 = 1)
  ---    END
  ```

#### 输出结果说明

| 输出项名称    | 输出项解释                  |
|:---------|:-----------------------|
| ACL规则组标识 | 该参数用于表示所要创建的规则属于哪个规则组。 |
| 规则名称     | 该参数用于表示所要创建的规则名称。      |
| 规则ID     | 该参数用于表示创建的规则的ID。       |
| 规则行为     | 该参数用于表示对符合本规则的报文采取的动作。 |
| 所有的接口    | 该参数用于表示规则是否匹配所有接口。     |
| 激活状态     | 该参数表示规则在当前时间是否生效。      |
| 规则描述     | 该参数用于表示规则描述。           |
| 接口名      | 该参数用于表示规则要匹配的接口名称。     |
