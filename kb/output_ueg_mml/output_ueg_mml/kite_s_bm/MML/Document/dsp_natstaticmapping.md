# 查询NAT静态地址映射关系（DSP NATSTATICMAPPING）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询NAT静态地址映射关系。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称       | 参数说明                                                                                                             |
|:--------------|:-----------|:-----------------------------------------------------------------------------------------------------------------|
| QUERYTYPE     | 查询类型       | 可选必选说明：必选参数 参数含义：查询类型。 数据来源：本端规划 取值范围：枚举类型。 INSIDEIPV4：私网IPv4地址。GLOBALIPV4：公网IPv4地址。 默认值：无 配置原则：无                |
| STATICMAPNAME | 静态地址映射关系名称 | 可选必选说明：必选参数 参数含义：静态地址映射关系名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无                                      |
| INSIDEIPV4    | 私网IPv4地址   | 可选必选说明：条件必选参数 前提条件：该参数在“QUERYTYPE”配置为“INSIDEIPV4”时为必选参数。 参数含义：私网IPv4地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无 配置原则：无    |
| GLOBALIPV4    | 公网IPv4地址   | 可选必选说明：可选参数 参数含义：公网IPv4地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无 配置原则：无                                                 |
| PORT          | 端口         | 可选必选说明：条件必选参数 前提条件：该参数在“QUERYTYPE”配置为“GLOBALIPV4”时为必选参数。 参数含义：端口。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无 配置原则：无 |

#### 使用实例

该命令用于查询NAT静态地址映射关系：

```
DSP NATSTATICMAPPING: QUERYTYPE=INSIDEIPV4, STATICMAPNAME="map1", INSIDEIPV4="10.2.2.8";
```

```
RETCODE = 0  Operation Success.

Static Mapping Information:
---------------------------

                  Inside IPv4 Address  =  10.2.2.8

  End Port of the Global IPv4 Address  =  4095
(Number of results = 1)
---    END
```
