# 查询MEC服务（LST MECSERVICE）

- 命令功能
- 注意事项
- 操作用户权限

- 输出结果说明

#### 命令功能

**适用NF：UPF、MPF**

该命令用于查询MEC服务。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                          |
|:------------|:-------|:--------------------------------------------------------------------------------------------------------------|
| SERVICENAME | 服务名称   | 可选必选说明：可选参数 参数含义：该参数用于指定服务名称。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“_”组成，且只能以字母或者数字开头。 默认值：无 配置原则：无 |

#### 使用实例

- 查询全部的MECSERVICE对象：

  ```
  LST MECSERVICE:;
  ```

  ```
  RETCODE = 0  操作成功

  MEC服务
  -------
    服务名称  =  mec_service
    服务标签  =  MP2接口服务
    协议类型  =  HTTPS协议
  服务端点组  =  service_endpoint_grp
  (结果个数 = 1)

  ---    END
  ```
- 查询MECSERVICE对象，查询的MECSERVICE对象名称为"mec\_service"：

  ```
  LST MECSERVICE: SERVICENAME="mec_service";
  ```

  ```
  RETCODE = 0  操作成功

  MEC服务
  -------
    服务名称  =  mec_service
    服务标签  =  MP2接口服务
    协议类型  =  HTTPS协议
  服务端点组  =  service_endpoint_grp
  (结果个数 = 1)

  ---    END
  ```
