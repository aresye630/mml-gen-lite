# 查询NSH头增强（LST NSHHEADEN）

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询NSH头增强全部配置信息，或根据输入名称显示指定NSH头增强的配置信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                                                                                   |
|:---------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NSHNAME  | NSH头增强名称 | 可选必选说明：可选参数 参数含义：该参数用于设置NSH头增强名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                                          |
| DATATYPE | 数据类型     | 可选必选说明：可选参数 参数含义：该参数用于设置NSH头增强的数据类型。 数据来源：本端规划 取值范围：枚举类型。 MSISDN1：指定插入项的类型为MSISDN。IMSI1：指定插入项的类型为IMSI。IMEI1：指定插入项的类型为IMEI。RAT1：指定插入项的类型为RAT。ULI1：指定插入项的类型为ULI。MCC_MNC1：指定插入项的类型为MCC_MNC1。 默认值：无 配置原则：无 |

#### 使用实例

假如运营商想查看所有的NSH头增强记录：

```
LST NSHHEADEN:;
```
