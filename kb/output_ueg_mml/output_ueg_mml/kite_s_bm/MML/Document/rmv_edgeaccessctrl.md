# 删除边缘接入控制（RMV EDGEACCESSCTRL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于删除边缘接入控制策略。

#### 注意事项

该命令执行后30s生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                 |
|:--------------|:-------|:-------------------------------------------------------------------------------------|
| CONDITIONTYPE | 边缘接入控制 | 可选必选说明：可选参数 参数含义：此参数用于设置边缘接入控制的条件类型。 数据来源：本端规划 取值范围：枚举类型。 DEFAULT：缺省类型。 默认值：无 配置原则：无 |

#### 使用实例

如果用户需要删除边缘接入控制策略：

```
RMV EDGEACCESSCTRL: CONDITIONTYPE=DEFAULT;
```
