# 查询VXLAN隧道组绑定APN（LST VXLANBINDAPN）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询VXLAN隧道组与apn的绑定关系。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                            |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------|
| APN    | APN    | 可选必选说明：可选参数 参数含义：该参数用于指定APN实例名。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数必须已经通过ADD APN命令配置。 |

#### 使用实例

查询所有与APN绑定的VXLAN隧道组：

```
LST VXLANBINDAPN:;
```

```
RETCODE = 0  操作成功

VXLAN隧道绑定APN信息
--------------------
        APN  =  apn1
VXLAN组名称  =  vxlangrp2
(结果个数 = 1)

---    END
```
