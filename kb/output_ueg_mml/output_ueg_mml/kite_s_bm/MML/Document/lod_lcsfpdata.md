# 加载LCS指纹数据（LOD LCSFPDATA）

- 操作用户权限

#### 命令功能

**适用NF：UPF**

该命令用于加载LCS指纹数据。

#### 注意事项

- 该命令执行后立即生效。
- 新增指纹数据可以通过网管/MAE的“网元文件传输”功能或者OM Portal的“文件传输”功能进行指纹文件上传。
- 指纹数据文件加载的时间和数据量有关，全量数据的加载大约需要8分钟，加载过程可使用DSP LODFPSTAT命令来查看当前加载的状态。如果重复执行加载，建议在上一次加载结束后再执行加载命令，否则会加载失败。
- 指纹数据文件如果手动修改过，需将checksum字段置为0，表示不做CRC校验。
- 对于指纹重复的数据，系统会做更新操作。
- 如果手动修改指纹数据，文件编码格式需要保持Unix格式，不可修改为其他格式。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

无。

#### 使用实例

加载LCS指纹数据：

```
LOD LCSFPDATA:;
```
