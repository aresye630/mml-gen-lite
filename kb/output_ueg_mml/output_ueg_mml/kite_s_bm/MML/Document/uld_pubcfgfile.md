# 上传绑定配置域信息（ULD PUBCFGFILE）

- 命令功能

- 输出结果说明

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

本命令用于将某一域的配置文件上传至FileServer。

#### 注意事项

- 该命令执行后立即生效。
- 若执行该命令时与上次域核查之间有配置变动，则无法上传文件，需要重新核查之后才能上传。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称          | 参数说明                                                                      |
|:---------|:--------------|:--------------------------------------------------------------------------|
| FILEPATH | CfgDomainName | 可选必选说明：必选参数 参数含义：FilePath。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无 |

#### 使用实例

将域名为domain\_a的配置文件上传到FileServer：

```
ULD PUBCFGFILE: FILEPATH="domain_a";
```
