# 查询PAE多队列功能开关（LST PAEMULTQUE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询PAE多队列功能是否使能。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询PAE多队列功能开关：

```
%%LST PAEMULTQUE:;%%
RETCODE = 0  操作成功

结果如下:
---------
功能是否开启  =  是
(结果个数 = 1)

---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释             |
|:--------|:------------------|
| 功能是否开启  | 用于表示PAE多队列功能是否使能。 |
