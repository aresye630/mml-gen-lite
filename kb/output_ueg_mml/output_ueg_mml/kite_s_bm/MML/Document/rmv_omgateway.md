# 删除OM网关（RMV OMGATEWAY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**须知** 

执行该命令后可能会影响OM网络与外部通信，请谨慎操作。

本命令用于删除OMU浮动IP的路由，命令执行成功后，系统会自动删除OMU浮动IP到目的网段的路由。

本命令的使用场景为：当某个外部网络需要与OMU断开通信时，可使用本命令删除相应的路由。

#### 注意事项

该命令仅限角色为Administrators的用户执行。

#### 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                   |
|:------------|:-----------|:---------------------------------------------------------------------------------------|
| IPTYPE      | IP类型       | 必选说明：必选参数。 参数含义：IP类型。 取值范围： IPV4(IPv4类型)IPV6(IPv6类型) 默认值：IPV4(IPv4类型) 配置原则：无。          |
| DIPV4ADDR   | 目的IPv4地址   | 可选必选说明：当“IP类型”为“IPV4”时，此参数为必选参数。 参数含义：用于指定目的IPv4地址。 取值范围：有效的IPv4地址。 默认值：无。 配置原则：无。     |
| DIPV4MASK   | 目的IPv4掩码   | 可选必选说明：当“IP类型”为“IPV4”时，此参数为必选参数。 参数含义：用于指定目的IPv4掩码。 取值范围：有效的IPv4 子网掩码。 默认值：无。 配置原则：无。  |
| DIPV6ADDR   | 目的IPv6地址   | 可选必选说明：当“IP类型”为“IPV6”时，此参数为必选参数。 参数含义：用于指定目的IPv6地址。 取值范围：有效的IPv6地址。 默认值：无。 配置原则：无。     |
| DIPV6PREFIX | 目的IPv6前缀长度 | 可选必选说明：当“IP类型”为“IPV6”时，此参数为必选参数。 参数含义：用于指定目的IPv6前缀长度。 取值范围：有效的IPv6前缀长度。 默认值：无。 配置原则：无。 |

#### 使用实例

删除“IP类型”为“IPV4”，“目的IPv4地址”为“192.168.0.0”，“目的IPv4掩码”为“255.255.0.0”，的外部路由：

```
%%RMV OMGATEWAY: IPTYPE=IPV4, DIPV4ADDR="192.168.0.0", DIPV4MASK="255.255.0.0";%%
RETCODE = 0  操作成功
```
