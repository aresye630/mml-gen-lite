# 删除用户信息统计功能（RMV USERSTATISTICS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于根据功能开关FUNCTION，删除指定功能的配置信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                          |
|:---------|:-------|:----------------------------------------------------------------------------------------------|
| FUNCTION | 功能开关   | 可选必选说明：必选参数 参数含义：该参数用于配置功能开关。 数据来源：本端规划 取值范围：枚举类型。 HIGH_RATE_USRSTATS：高带宽用户统计功能。 默认值：无 配置原则：无 |

#### 使用实例

删除高带宽用户统计功能：

```
RMV USERSTATISTICS: FUNCTION=HIGH_RATE_USRSTATS;
```
