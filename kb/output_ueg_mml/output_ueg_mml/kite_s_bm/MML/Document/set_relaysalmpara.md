# 设置媒体中继业务告警参数配置（SET RELAYSALMPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于配置媒体中继业务告警参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

假如需要配置媒体中继业务告警参数，则命令如下：

```
SET RELAYSALMPARA:ALAMCHECKTIME=10;
```
