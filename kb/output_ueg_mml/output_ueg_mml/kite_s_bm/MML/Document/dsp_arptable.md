# 显示ARP表项（DSP ARPTABLE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示接口上或设备上的所有ARP表项信息。查询条件组合如下：通过接口查询，通过VPN实例名称查询，通过RU名称查询，通过VPN实例名称+RU名称查询。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                       |
|:--------|:--------|:-----------------------------------------------------------------------------------------------------------|
| VRFNAME | VPN实例名称 | 可选必选说明：可选参数 参数含义：该参数用于指定ARP表项的VPN名称。 数据来源：本端规划 取值范围：字符串类型，取值范围是1～31。 默认值：无                                 |
| IFNAME  | 接口名称    | 可选必选说明：可选参数 参数含义：该参数用于设置表项接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。以太网接口名称由接口类型和接口编号组成。 默认值：无                |
| RUNAME  | RU名称    | 可选必选说明：可选参数 参数含义：查询指定资源单元的ARP表项。通过DSP RU命令可以查询资源单元信息。如果名称中包含空格则非法。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 |

#### 使用实例

显示所有ARP表项：

```
DSP ARPTABLE:;
```

```
RETCODE = 0  操作成功

结果如下
--------

            MAC地址  =  00E0-FC12-3456
```

#### 输出结果说明

| 输出项名称       | 输出项解释                                               |
|:------------|:----------------------------------------------------|
| IP地址        | 用于显示指定（目的）IPv4地址的ARP表项。                             |
| MAC地址       | 表示MAC地址。当值为FFFF-FFFF-FFFF时，表示该表项为假表项。               |
| 表项老化时间（min） | 表示表项老化时间。                                           |
| 表项类型        | 该参数用于显示指定表项类型的ARP表项。 静态表项：静态表项。动态表项：动态表项。接口表项：接口表项。 |
| VPN实例名称     | 用于指定ARP表项的VPN名称。                                    |
| 接口名称        | 用于设置表项接口名称。                                         |
| RU名称        | 查询指定资源单元的ARP表项。通过DSP RU命令可以查询资源单元信息。如果名称中包含空格则非法。   |
