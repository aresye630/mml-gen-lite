# 查询IP地址白名单列表（LST CFIPWHITELIST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于显示配置IP地址。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                      |
|:-------|:-------|:------------------------------------------------------------------------------------------|
| IPTYPE | IP地址类型 | 可选必选说明：可选参数 参数含义：该参数用于设置Ip地址类型。 数据来源：本端规划 取值范围： IPV4：IPv4地址类型。IPV6：IPv6地址类型。 默认值：无 配置原则：无 |

#### 使用实例

查询IP地址白名单列表：

```
LST CFIPWHITELIST: IPTYPE=IPV4;
```

```
RETCODE = 0  操作成功。

IPV4地址白名单
----------------
IP地址    IP地址掩码长度  配置域名称

0.0.0.0         32        NULL
127.0.0.0       24        NULL
(结果个数 = 2)
---    END
```
