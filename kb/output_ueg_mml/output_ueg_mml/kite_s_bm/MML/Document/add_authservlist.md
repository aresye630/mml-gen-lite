# 添加授权服务列表（ADD AUTHSERVLIST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

该命令用于添加授权服务列表，添加授权服务列表后，可将授权服务添加至该列表中，并将该服务授权列表授权给指定APP。当APP被授予访问该授权服务列表的权限后，APP可访问该列表中的所有授权服务；授权服务指允许APP通过MEP平台访问的服务，包括1）通过MM5接口注册的服务；2）通过MP1接口注册的服务；3)MEP平台自身提供的服务。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为500。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                   |
|:-------|:---------|:-----------------------------------------------------------------------------------------------------------------------|
| NAME   | 授权服务列表名称 | 可选必选说明：必选参数 参数含义：该参数用于指定APP可访问的授权服务列表。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“.”组成，且只能以字母或者数字开头。 默认值：无 配置原则：无 |

#### 使用实例

添加授权服务列表，名称为"servicelist"：

```
ADD AUTHSERVLIST: NAME="serviceList";
```
