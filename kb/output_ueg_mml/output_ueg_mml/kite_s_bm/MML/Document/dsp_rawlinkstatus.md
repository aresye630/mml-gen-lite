# 查询Raw-link状态（DSP RAWLINKSTATUS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查看Raw-link连接状态信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称       | 参数说明                                                                                 |
|:---------|:-----------|:-------------------------------------------------------------------------------------|
| APPCID   | APP组件CID   | 可选必选说明：可选参数 参数含义：该参数用于指定APP组件CID。 数据来源：本端规划 取值范围：十六进制整数类型，取值范围为0x0～0xFFFFFFFF。 默认值：无 |
| SOCKETFD | Socket实例ID | 可选必选说明：可选参数 参数含义：该参数用于指定Socket实例ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～2147418111。 默认值：无     |

#### 使用实例

显示当前系统的Raw-link状态：

```
DSP RAWLINKSTATUS:;
```

```
        RETCODE = 0  操作成功

        结果如下
        --------------------------
        APP组件CID    Socket实例ID

        0x807703FD    1
        0x8069042E    2
        0x8069042E    3
        0x8069042E    4
        0x807703FD    6
        0x8069042E    7
        (结果个数 = 6)
        ---    END
```

#### 输出结果说明

| 输出项名称      | 输出项解释           |
|:-----------|:----------------|
| APP组件CID   | 用于指定APP组件CID。   |
| Socket实例ID | 用于指定Socket实例ID。 |
