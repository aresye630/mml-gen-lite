# 查询配置的MOS值异常门限值信息（LST VONRABNORMOS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询异常MOS值的门限值。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询异常MOS值的门限值：

```
LST VONRABNORMOS:;
```

```
RETCODE = 0  操作成功

MOS值的异常门限值
-----------------
VoNR MOS值的异常门限  =  10
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见SET VONRABNORMOS的参数说明。
