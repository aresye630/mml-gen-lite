# 获取摘要(GET PUBCFGDIGEST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明
- 参考信息

## 命令功能

该命令用于网管下发公共配置获取摘要。

## 注意事项

该命令为机机接口命令，无法在MML界面手动执行。

## 参数说明

| 参数标识          | 参数名称              | 参数说明                                                                                                                                           |
|:--------------|:------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| CFGDOMAINNAME | 配置域名称             | 可选必选说明：可选参数。 参数含义：该参数用于指定需要核查的域名称。 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无。                                                                 |
| BASEVERSION   | 基线版本号             | 可选必选说明：必选参数。 参数含义：该参数指定当前集中配置管理组MML基线版本号。 取值范围：1-65535。 默认值：无。                                                                                 |
| SERVERIP      | FTP服务器IPv4或IPv6地址 | 可选必选说明：必选参数。 参数含义：该参数用于设置远端FTP服务器IP。 取值范围：字符串类型，输入长度1-20。 默认值：无。 配置原则：机机接口，不对IP地址格式做下发前合法性判定。                                                  |
| SERVERPORT    | FTP服务器端口          | 可选必选说明：必选参数。 参数含义：该参数用于设置远端FTP服务器端口。 取值范围：0~65536。 默认值：无。                                                                                      |
| SERVERUSER    | FTP服务器用户名         | 可选必选说明：可选参数。 参数含义：该参数用于设置FTP服务器的用户名。 取值范围：字符串类型，输入长度范围为1～63。 默认值：无。                                                                            |
| SERVERPWD     | FTP服务器密码          | 可选必选说明：可选参数。 参数含义：该参数用于设置远端FTP服务器密码。 取值范围：密码类型，输入长度范围为1～432。 默认值：无。                                                                            |
| SERVERDIR     | 上传服务器路径           | 可选必选说明：可选参数。 参数含义：网管远端目录。 取值范围：名称规则是空格、数字、英文字符、中文以及特殊字符-，_，+，=，.，:，()，%，@，/，[]。 正则表达式： "^[- a-zA-Z\u4e00-\u9fa50-9._+=()%\\[\\]@/:]+$"。 默认值：无。 |
| SYSPUBCFGCHK  | 系统级公共配置是否核查       | 可选必选说明：必选参数。 参数含义：是否核查系统级公共配置。 取值范围： ENABLE：核查。DISABLE：不核查。 默认值：ENABLE。                                                                        |
| MMLFILE       | MML文件             | 可选必选说明：可选参数。 参数含义：MML导出结果文件URL。 取值范围：字符串类型，输入长度范围为0~255。 默认值：无。                                                                                |
| PUBCFGGRPNAME | 公共配置组名称           | 可选必选说明：可选参数。 参数含义：该参数用于指定网元在网管侧所属配置组。 取值范围：字符串类型，输入长度范围为0～31。不支持空格，不区分大小写。 默认值：无。                                                              |
