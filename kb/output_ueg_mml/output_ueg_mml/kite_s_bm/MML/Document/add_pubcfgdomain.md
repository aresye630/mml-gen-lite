# 添加配置域名称（ADD PUBCFGDOMAIN）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

本命令用于将网元添加到某一配置域内，配置域也称为集中配置管理组。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为8。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                   |
|:--------------|:-------|:-----------------------------------------------------------------------|
| CFGDOMAINNAME | 域名称    | 可选必选说明：必选参数 参数含义：配置域名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无 |

#### 使用实例

将网元加入到名为domain\_a的域中：

```
ADD PUBCFGDOMAIN: CFGDOMAINNAME="domain_a";
```
