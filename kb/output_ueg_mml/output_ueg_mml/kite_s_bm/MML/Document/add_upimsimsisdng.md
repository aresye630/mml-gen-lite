# 增加IMSI和MSISDN号段组（ADD UPIMSIMSISDNG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用来配置IMSI/MSISDN号码段组。

#### 注意事项

- 该命令执行后立即生效。
- 如果绑定多个IMSI/MSISDN号码段，需多次执行此命令。
- 系统最大支持配置1000条IMSI/MSISDN号码段组。每条IMSI/MSISDN号码段组最大绑定12000条IMSI/MSISDN号码段。
- 配置UpImsiMsisdnG前，需要首先配置UpImsiMsSeg。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称             | 参数说明                                                                                                                            |
|:--------------|:-----------------|:--------------------------------------------------------------------------------------------------------------------------------|
| SEGGROUPNAME  | IMSI/MSISDN号段组名称 | 可选必选说明：必选参数 参数含义：该参数用于指定IMSI/MSISDN号码段组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无                          |
| SEGMENTNAME   | IMSI/MSISDN号段名称  | 可选必选说明：必选参数 参数含义：该参数用于指定IMSI/MSISDN号码段名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD UPIMSIMSSEG命令配置生成。 |
| CFGDOMAINNAME | 配置域名称            | 可选必选说明：可选参数 参数含义：该参数表示命令所属公共配置域的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则：无                                              |

#### 使用实例

配置IMSI/MSISDN号码段组内添加一个号段，其中IMSI/MSISDN号段组名称为huawei，IMSI/MSISDN号段名称为imsi：

```
ADD UPIMSIMSISDNG:SEGGROUPNAME="huawei",SEGMENTNAME="imsi";
```
