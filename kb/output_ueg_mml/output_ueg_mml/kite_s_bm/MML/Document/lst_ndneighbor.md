# 查询静态ND邻居表项（LST NDNEIGHBOR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于IPv6 ND静态表项的查询。

若不指定IFNAME参数时，则显示所有接口的ND静态表项信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                |
|:-------|:-------|:----------------------------------------------------------------------------------------------------|
| IFNAME | 接口名    | 可选必选说明：可选参数 参数含义：该参数用于指定接口名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。 |

#### 使用实例

查询IPv6 ND静态表项：

```
LST NDNEIGHBOR:IFNAME="Ethernet65/0/8";
```

```
        结果如下
        --------
        接口名            IPv6地址        MAC地址

        Ethernet65/0/8   2001:db8::11     00e0-fc03-0004
        Ethernet65/0/8   2001:db8::12     00e0-fc02-0003
        (结果个数 = 2)
        ---    END
```
