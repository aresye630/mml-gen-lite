# 增加基于应用的质差上报策略（ADD APPPOLICYCTRL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于增加基于应用的质差上报策略。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为3000。
- APPIDNAME最多配置100个。
- 当配置MOS进行质差检测时，不会再使用POLICYCONDITION配置中相关质差基线检测。
- 当前版本MOS分检测能力依赖QoE模型库与协议特征库能力。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称         | 参数说明                                                                                                                                                                                                                                               |
|:--------------|:-------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APPIDNAME     | 应用ID         | 可选必选说明：必选参数 参数含义：该参数用于指定重点业务保障的应用组名称。 数据来源：全网规划 取值范围：字符串类型，区分大小写，长度为1-63位。 默认值：无 配置原则：与NWDAF的应用组配置一致。                                                                                                                                              |
| SUBAPPIDNAME  | 子应用ID        | 可选必选说明：必选参数 参数含义：该参数用于指定重点业务保障的应用名称。 数据来源：全网规划 取值范围：字符串类型，区分大小写，长度为1-63位。 默认值：无 配置原则：与NWDAF的应用配置一致。                                                                                                                                                |
| DEFPRTGRPNAME | 自定义协议组名称     | 可选必选说明：必选参数 参数含义：该参数用于指定自定义的三级协议组名称。 数据来源：本端规划 取值范围：参数来源于ADD SSUPROTCOLGROUP中的DEFPRTGRPNAME。 默认值：无 配置原则：无                                                                                                                                          |
| QOEDETPRD     | 基于应用的质差上报周期  | 可选必选说明：可选参数 参数含义：该参数指定该应用下UPF检测用户业务发生质差时向NWDAF上报单据的时间间隔。 数据来源：本端规划 取值范围：整数类型，取值范围为1~300，单位为秒，必须大于等于SET VVIPBASICFUNC中配置的SAMPLEPERIOD。建议按5秒、10秒和15秒的粒度配置。 默认值：无 配置原则：无                                                                              |
| NONQOEDETPRD  | 基于应用的非质差上报周期 | 可选必选说明：可选参数 参数含义：该参数指定该应用下UPF检测用户业务未发生质差时向NWDAF上报单据的时间间隔。 数据来源：本端规划 取值范围：整数类型，取值范围为1~300，单位为秒。1. 必须大于等于SET VVIPBASICFUNC中配置的SAMPLEPERIOD。2. 建议按60秒粒度配置。3. 体验单据配置周期应当大于BYTE1115中配置的应用结束时延时间，如果BYTE1115未配置，体验单据配置周期应当大于BYTE1115默认值（2秒）。 默认值：无 配置原则：无 |
| MOS           | 平均意见分        | 可选必选说明：可选参数 参数含义：该参数用于配置平均意见分，UPF检测到应用实际的平均意见分不大于该值时，认为该应用质差。 数据来源：本端规划 取值范围：字符串类型，长度不超过3个字符。 默认值：无 配置原则： 请填写浮点数，精确到十分位，取值范围为1～5。输入一个空格表示清除已设置的值。                                                                                                  |
| QOERPTPOLICY  | 应用质差上报策略     | 可选必选说明：可选参数 参数含义：该参数用于设置应用质差时的单据上报策略。 数据来源：本端规划 取值范围： QOE_REPORT_ONCE：检测到质差时新流触发上报。QOE_REPORT_PERIOD：检测到质差时周期触发上报。 默认值：QOE_REPORT_ONCE 配置原则：无                                                                                                      |

#### 使用实例

配置基于应用的质差策略，应用ID为zhibo，子应用ID为huya，自定义协议组名称为testhttp，执行如下命令：

```
ADD APPPOLICYCTRL: APPIDNAME="zhibo", SUBAPPIDNAME="huya", DEFPRTGRPNAME="testhttp";
```
