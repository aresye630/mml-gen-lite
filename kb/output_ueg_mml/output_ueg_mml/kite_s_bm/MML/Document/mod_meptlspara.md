# 修改MEP TLS参数（MOD MEPTLSPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

**须知** 

本命令属于高危命令，关闭校验对端证书开关时，API GW将关闭对绑定本TLS参数的MEPHTTPSERVER/MEPHTTPCLIENT对象所对接的设备进行证书校验的功能，可能存在因为对端设备被仿冒导致的安全风险，请谨慎关闭。

该命令用于修改一组TLS参数。

#### 注意事项

- 该命令执行后立即生效。
- 该命令中“校验对端证书”参数用于指定是否验证对端证书。“校验对端证书”参数仅在通过LST MEPREVERSEPROXY命令查询当前环境已配置反向代理且反向代理的服务端/客户端关联该TLS参数时生效。
- 由于openssl特殊约束，如果“PROTOCOL”参数只选择“TLS1.3”，那么“CIPHERSUITES”参数就需要全部配置，不支持单独勾选。
- 由于API GW作为客户端对接不同网元时使用的算法套件为同一个，因此配置用于客户端类型的“CIPHERSUITES”参数时，以关联到对接外部网元场景的TLS参数中的“CIPHERSUITES”参数为准，且如下两个算法套件为必选：TLS\_ECDHE\_RSA\_WITH\_AES\_128\_GCM\_SHA256，TLS\_ECDHE\_RSA\_WITH\_AES\_256\_GCM\_SHA384。
- 不同的算法套件、不同的椭圆曲线、密钥长度均影响TLS加解密性能，且性能差距较大。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 使用实例

修改MEPTLSPARA对象，修改的MEPTLSPARA名称为"tls"，TLS使用的版本修改为"不使用TLS1.2、使用TLS1.3"，是否校验对端证书修改为"ENABLE"，校验深度修改为"12"，设备证书场景修改为"MP1\_DEV\_CERT\_SCENE"，CA证书场景修改为"MP1\_CA\_CERT\_SCENE"，TLS使用的算法套件修改为"TLS\_AES\_128\_GCM\_SHA256-1&TLS\_AES\_256\_GCM\_SHA384-1&TLS\_CHACHA20\_POLY1305\_SHA256-1&TLS\_ECDHE\_ECDSA\_WITH\_AES\_128\_CCM-1&TLS\_ECDHE\_ECDSA\_WITH\_AES\_128\_CCM\_8-1&TLS\_ECDHE\_ECDSA\_WITH\_AES\_128\_GCM\_SHA256-1&TLS\_ECDHE\_ECDSA\_WITH\_AES\_256\_CCM-1&TLS\_ECDHE\_ECDSA\_WITH\_AES\_256\_CCM\_8-1&TLS\_ECDHE\_ECDSA\_WITH\_AES\_256\_GCM\_SHA384-1&TLS\_ECDHE\_RSA\_WITH\_AES\_128\_GCM\_SHA256-1&TLS\_ECDHE\_RSA\_WITH\_AES\_256\_GCM\_SHA384-1"：

```
MOD MEPTLSPARA: TLSPARANAME="tls", PROTOCOL=TLSv12-0&TLSv13-1, VERIFYPEER=ENABLE, VERIFYDEPTH=12, DEVCERTSCENE=MP1_DEV_CERT_SCENE, CACERTSCENE=MP1_CA_CERT_SCENE, CIPHERSUITES=TLS_AES_128_GCM_SHA256-1&TLS_AES_256_GCM_SHA384-1&TLS_CHACHA20_POLY1305_SHA256-1&TLS_ECDHE_ECDSA_WITH_AES_128_CCM-1&TLS_ECDHE_ECDSA_WITH_AES_128_CCM_8-1&TLS_ECDHE_ECDSA_WITH_AES_128_GCM_SHA256-1&TLS_ECDHE_ECDSA_WITH_AES_256_CCM-1&TLS_ECDHE_ECDSA_WITH_AES_256_CCM_8-1&TLS_ECDHE_ECDSA_WITH_AES_256_GCM_SHA384-1&TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256-1&TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384-1;
```
