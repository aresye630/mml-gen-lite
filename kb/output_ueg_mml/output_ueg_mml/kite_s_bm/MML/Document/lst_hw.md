# 查询硬件设备信息（LST HW）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

本命令用于查询硬件设备信息。

#### 注意事项

无。

#### 参数说明

无。

#### 使用实例

查询所有设备信息成功。

```
%%LST HW:;%% 
RETCODE = 0  操作成功  
结果信息 
-------- 
设备名称  设备类型  硬件框号  硬件槽号   
 2         外置      2         2         
 3         外置      1         2         
 (结果个数 = 2)
---    END
```

#### 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。输出结果说明如表1 输出项说明所示。

该命令执行异常，会返回对应的错误描述。常见错误描述如表2 错误码列表所示。

| 输出项名称   | 输出项解释                   |
|:--------|:------------------------|
| 设备名称    | 硬件设备的名称。                |
| 设备类型    | 硬件设备的类型。 取值范围：外置。       |
| 硬件框号    | 硬件设备的框号。 取值范围：0~999999。 |
| 硬件槽号    | 硬件设备的槽号。 取值范围：0~999999。 |

|    错误码 | 错误码解释     | 原因分析         | 处理建议         |
|-------:|:----------|:-------------|:-------------|
| 150214 | 操作失败      | 系统内部错误       | 请联系华为技术支持    |
| 150312 | 硬件设备信息不存在 | 当前硬件设备信息列表为空 | 请添加硬件设备信息后重试 |
