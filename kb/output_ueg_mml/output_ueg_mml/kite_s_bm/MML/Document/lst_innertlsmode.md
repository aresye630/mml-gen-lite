# 查询TLS模式（LST INNERTLSMODE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此命令用于查询服务的TLS模式。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                    |
|:------------|:-------|:----------------------------------------------------------------------------------------|
| SERVICETYPE | 服务类型   | 可选必选说明：可选参数  参数含义：该参数用于表示服务类型。  数据来源：本端规划 取值范围： HAFETCD（HAFETCD）CMF（CMF）  默认值：无  配置原则：无 |

## 使用实例

查询服务的TLS模式：

```
%%LST INNERTLSMODE:;%%
RETCODE = 0  操作成功

结果如下
--------
服务类型  =  HAFETCD
 TLS模式  =  HTTP协议
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释         |
|:--------|:--------------|
| 服务类型    | 该参数用于表示服务类型。  |
| TLS模式   | 该参数用于表示TLS模式。 |
