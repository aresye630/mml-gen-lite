# 增加OM网关（ADD OMGATEWAY）

- 命令功能
- 注意事项

- 输出结果说明

#### 命令功能

**须知** 

执行该命令后可能会影响OM网络与外部通信，请谨慎操作。

本命令用于为OMU浮动IP增加路由，命令执行成功后，系统会自动配置OMU浮动IP到目的网段的路由。

本命令的使用场景为：当某个外部网络需要与OMU进行通信而缺少相应路由时，可使用本命令进行配置。

#### 注意事项

- 该命令仅限角色为Administrators的用户执行。
- 同一IP类型最多只允许增加15条路由。
- 浮动IP和外网网关地址需要在同一个网段。
- 目的IP地址和目的掩码/前缀长度需要匹配。
- 修改VLANID或跨网段修改浮动IP会影响已配置的网段路由，需要删除对应的网段路由，再重新配置。

#### 使用实例

增加“IP类型”为“IPV4”，“目的IPv4地址”为“192.168.0.0”，“目的IPv4掩码”为“255.255.0.0”，“外网IPv4网关地址”为“172.16.1.253”的外部路由：

```
%%ADD OMGATEWAY: IPTYPE=IPV4, DIPV4ADDR="192.168.0.0", DIPV4MASK="255.255.0.0", GIPV4ADDR="172.16.1.253";%%
RETCODE = 0  操作成功
```
