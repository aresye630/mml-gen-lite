# 删除IPv6 RA通告前缀（RMV IFIPV6NDRAPREFIX）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除接口IPv6 RA通告前缀。

#### 注意事项

- 该命令执行后立即生效。
- 指定的前缀不能为链路本地地址（fe80::）、组播地址（ff00::）以及其他接口已经使用的前缀（包括接口地址前缀和RA消息携带的前缀）。
- 该命令可以在VNRS\_VNFC的Ethernet接口，Ethernet子接口以及Tunnel口上配置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                       |
|:---------------|:---------|:---------------------------------------------------------------------------------------------------------------------------|
| IFNAME         | 接口名      | 可选必选说明：必选参数 参数含义：该参数用于指定IPV6前缀接口名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。接口名称由接口类型+接口编号组成。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。 |
| IPV6ADDRPREFIX | IPv6地址   | 可选必选说明：必选参数 参数含义：该参数用于指定IPv6前缀地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无                                                           |
| PREFIXLEN      | IPv6前缀长度 | 可选必选说明：必选参数 参数含义：该参数用于指定接口IPv6地址前缀长度。 数据来源：本端规划 取值范围：整数类型，取值范围为0～128。 默认值：无                                                |

#### 使用实例

删除接口IPv6 RA通告前缀：

```
RMV IFIPV6NDRAPREFIX:IFNAME="ethernet64/0/3",IPV6ADDRPREFIX="2001:db8::1",PREFIXLEN=64;
```
