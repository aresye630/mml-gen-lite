# 修改边缘接入控制（MOD EDGEACCESSCTRL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于修改边缘接入控制策略。

#### 注意事项

- 该命令执行后30s生效。
- 如果需要修改访问控制白名单，请先确定访问的ServerListV4/ServerListV6全集，否则会导致部分server访问不通。
- 该功能生效需要同时开启软参bit1577。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称        | 参数说明                                                                                                                             |
|:---------------|:------------|:---------------------------------------------------------------------------------------------------------------------------------|
| CONDITIONTYPE  | 边缘接入控制      | 可选必选说明：必选参数 参数含义：此参数用于设置边缘接入控制的条件类型。 数据来源：本端规划 取值范围：枚举类型。 DEFAULT：缺省类型。 默认值：无 配置原则：无                                             |
| SERVERLISTV4NM | IPv4服务器列表名称 | 可选必选说明：可选参数 参数含义：该参数用于配置IPv4服务器列表名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则： 该参数使用ADD SERVERLISTV4命令配置生成。输入单空格将删除该参数已有配置项。 |
| SERVERLISTV6NM | IPv6服务器列表名称 | 可选必选说明：可选参数 参数含义：该参数用于设置IPv6服务器列表名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 配置原则： 该参数使用ADD SERVERLISTV6命令配置生成。输入单空格将删除该参数已有配置项。 |

#### 使用实例

如果用户需要修改边缘接入控制策略：

```
MOD EDGEACCESSCTRL: CONDITIONTYPE=DEFAULT;
```
