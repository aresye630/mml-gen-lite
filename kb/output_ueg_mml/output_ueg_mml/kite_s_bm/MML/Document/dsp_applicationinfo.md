# 查询应用信息（DSP APPLICATIONINFO）

#### 命令功能

**适用NF：UPF、MPF**

该命令用于查看应用信息，根据选择不同的规则名称查询不同的规则应用信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                       |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RULENAME | 规则名称   | 可选必选说明：必选参数 参数含义：指定规则名称。 数据来源：本端规划 取值范围：枚举类型。 DYN_DNS_RULE：查询动态DNS规则的应用信息。STA_DNS_RULE：查询静态DNS规则的应用信息。TRAFFIC_RULE：查询流规则的应用信息。DNS_REDIRECT_RULE：查询DNS重定向规则的应用信息。ACL_RULE：查询ACL规则的应用信息。BW_ALLOCATION_RULE：查询带宽分配规则的应用信息。LBS_RULE：查询负载均衡规则应用信息。 默认值：无 配置原则：无 |

#### 使用实例

- 在MPF下查询流规则的应用信息：

  ```
  DSP APPLICATIONINFO: RULENAME=TRAFFIC_RULE;
  ```

  ```
  RETCODE = 0 操作成功

  应用信息
  --------
  应用名称  = APPid_20201112101
  APP实例号 = appd_2abcdefghijklmnopqrstuvwxyz
    MEP ID = NULL
  (结果个数 = 1)

  --- END
  ```
- 在MPF下查询动态DNS规则的应用信息：

  ```
  DSP APPLICATIONINFO: RULENAME=DYN_DNS_RULE;
  ```

  ```
  RETCODE = 0 操作成功

  应用信息
  --------
  应用名称             APP实例号                             MEP ID                         
   
  APPid_20201112101  appd_2abcdefghijklmnopqrstuvwxyz      NULL    
  APPid_20201112101  appd_abcdefghijklmnopqrstuvwxyz1      NULL   
  (结果个数 = 2)

  ---    END
  ```

#### 输出结果说明

| 输出项名称   | 输出项解释                                        |
|:--------|:---------------------------------------------|
| 应用名称    | 用于标识应用名称。                                    |
| APP实例号  | 指定APP实例号。                                    |
| MEP ID  | 指定MEP ID，可以通过DSP APPLICATIONINFO查出所有的MEP ID。 |
