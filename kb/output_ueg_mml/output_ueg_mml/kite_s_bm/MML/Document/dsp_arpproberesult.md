# 查询ARP探测结果（DSP ARPPROBERESULT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示ARP探测的结果。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称          | 参数说明                                                                                                                                                 |
|:-------------|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
| IFTYPE       | 接口类型          | 可选必选说明：必选参数 参数含义：该参数用于指定ARP探测会话的接口类型。 数据来源：本端规划 取值范围：枚举类型。 EthTrunk：Eth-Trunk接口。 默认值：无                                                               |
| IFNAME       | 探测会话接口名称      | 可选必选说明：条件可选参数 前提条件：该参数在“IFTYPE”配置为“EthTrunk”时为可选参数。 参数含义：该参数用于指定ARP探测会话的接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。 |
| MEMBERIFNAME | 成员口名称         | 可选必选说明：条件可选参数 前提条件：该参数在“IFTYPE”配置为“EthTrunk”时为可选参数。 参数含义：该参数用于显示成员口的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。       |
| SESSIONIP    | ARP探测会话IPv4地址 | 可选必选说明：条件可选参数 前提条件：该参数在“IFTYPE”配置为“EthTrunk”时为可选参数。 参数含义：该参数用于显示ARP探测会话的目的IPv4地址。 数据来源：本端规划 取值范围：IPv4地址类型。 默认值：无                                     |

#### 使用实例

显示ARP探测的结果：

```
DSP ARPPROBERESULT:IFTYPE=EthTrunk,IFNAME="Eth-Trunk1.1";
```

```
RETCODE = 0  操作成功

结果如下
--------
   探测会话接口名称 = Eth-Trunk1.1
         成员口名称 = Ethernet64/0/3
ARP探测会话IPv4地址 = 10.10.10.10
        ARP探测结果 = 探测成功
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称         | 输出项解释                    |
|:--------------|:-------------------------|
| 探测会话接口名称      | 该参数用于指定ARP探测会话的接口名称。     |
| 成员口名称         | 该参数用于显示成员口的名称。           |
| ARP探测会话IPv4地址 | 该参数用于显示ARP探测会话的目的IPv4地址。 |
| ARP探测结果       | 该参数用于显示ARP探测结果。          |
