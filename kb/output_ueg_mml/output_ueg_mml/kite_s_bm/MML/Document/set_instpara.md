## 命令功能

**须知** 

该命令为高危命令，可能会导致无法登录系统运维界面，需要近端执行。请确认参数正确后，再执行此操作。

该命令用于设置安装参数。

## 注意事项

- 执行完此命令之后，需要重启对应的单板。
- 在修改OM物理端口时，如果是特殊情况（例如：维护人员无法接近设备，需要非近端操作），经过华为技术支持同意后，需要执行如下命令先关闭网口故障自愈开关。

  ```
  SET NODECHKPARA: RESTYPE=SERVER, PARAMTYPE_SV=CHKIPROUTE, CHKSWITCH=OFF, REPSWITCH=OFF;
  ```

  重启节点后需执行如下命令再次打开网口故障自愈开关。

  ```
  SET NODECHKPARA: RESTYPE=SERVER, PARAMTYPE_SV=CHKIPROUTE, CHKSWITCH=ON, REPSWITCH=ON;
  ```

- 该命令禁止在升级期间执行。
- 在升级观察期内执行该命令需要手动结束观察期。
- 修改OM物理端口后，未重启服务器前，不能执行修改OM网络的MML命令，如MOD VIRTUALIP、SET OMIP、MOD NETWORK等。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                    |
|:-----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------|
| PARATYPE   | 参数类型   | 可选必选说明：必选参数 参数含义：用于标识需要配置安装参数的参数类型。 取值范围：OMPORT(OM物理端口)。 默认值：OMPORT(OM物理端口)。 配置原则：无。                                                                    |
| SERVERNAME | 服务器名称  | 可选必选说明：必选参数 参数含义：用于标识物理服务器名称。 取值范围：长度为1-64的字符串。 默认值：无。 配置原则：通过LST INSTPARA命令查询到的服务器名称。                                                                  |
| PORTTYPE   | 网口类型   | 可选必选说明：必选参数 参数含义：用于标识OM物理端口的网口类型。 取值范围： 0(单网口)1(bond) 默认值：0(单网口)。 配置原则：无。                                                                               |
| PORTNAME   | 网口名称   | 可选必选说明：必选参数 参数含义：用于标识需要配置安装参数的网口名称。 取值范围：仅能包含数字、大小写字母、中划线和下划线，长度不能超过9位。 默认值：无。 配置原则：单网口填物理网口名称，bond网口时填bond名称。                                          |
| SUBPORT    | 子网口    | 可选必选说明：该参数在“PORTTYPE”配置为“1(bond)”时为条件必选参数。 参数含义：用于指定bond模式时子网口的名称。 取值范围：仅能包含数字、大小写字母、中划线、下划线和冒号。 默认值：无。 配置原则：两个物理网口，用“:”隔开。                             |
| BONDMODE   | bond模式 | 可选必选说明：该参数在“PORTTYPE”配置为“1(bond)”时为条件必选参数。 参数含义：用于标识OM物理端口的组bond模式。 取值范围： 4(lacp)1(active-standby) 默认值：4(lacp)。 配置原则：无。                                 |
| LACPRATE   | 网卡存活检测 | 可选必选说明：条件可选参数。该参数在“PORTTYPE”配置为“1(bond)”且“BONDMODE”配置为“4(lacp)”时为条件可选参数。 参数含义：用于标识网卡存活检测速度。 取值范围： 1(快)： 每1秒传输一次 0(慢)： 每30秒传输一次 默认值：1(快)。 配置原则：无。        |
| HASHPOLICY | HASH策略 | 可选必选说明：条件可选参数。该参数在“PORTTYPE”配置为“1(bond)”且“BONDMODE”配置为“4(lacp)”时为条件可选参数。 参数含义：用于标识数据包在两个子网口之间的分发策略。 取值范围： 0(MAC)1(IP+端口)2(MAC+IP) 默认值：1(IP+端口)。 配置原则：无。 |

## 使用实例

设置安装参数：

```
%%SET INSTPARA: PARATYPE=OMPORT, SERVERNAME="paas-192-168-2-3", PORTTYPE=1, PORTNAME="bond-svc1", SUBPORT="eth11:eth21", BONDMODE=4, LACPRATE=1, HASHPOLICY=1;%% 
RETCODE = 0  操作成功，请重启服务器
---    END
```
