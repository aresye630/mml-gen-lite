# 导出LCS指纹数据（EXP LCSFPDATA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于导出LCS指纹数据。

#### 注意事项

- 该命令执行后立即生效。
- 导出的指纹数据文件可以通过网管/MAE的“网元文件传输”功能或者OM Portal的“文件传输”功能查看，系统只保留最近两次导出的数据文件。
- 每天凌晨1点会自动导出指纹数据文件。
- 在系统实例化、升级等操作之前，通过网管/MAE的“网元文件传输”功能或者OM Portal的“文件传输”功能下载指纹数据保存到本地PC上作为备份。
- 指纹数据采集生成后，及时导出数据备份。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

无。

#### 使用实例

导出LCS指纹数据：

```
EXP LCSFPDATA:;
```
