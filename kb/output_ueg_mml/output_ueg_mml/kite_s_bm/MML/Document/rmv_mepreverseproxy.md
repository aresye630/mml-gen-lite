# 删除MEP反向代理（RMV MEPREVERSEPROXY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

**须知** 

本命令属于高危命令，删除该反向代理对象将导致对应的反向代理功能不可用，请谨慎删除。

该命令用于删除指定反向代理对象。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                            |
|:----------|:-------|:----------------------------------------------------------------------------------------------------------------|
| PROXYNAME | 反向代理名称 | 可选必选说明：必选参数 参数含义：该参数用于指定反向代理名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“.”组成，且只能以字母或者数字开头。 默认值：无 配置原则：无 |

#### 使用实例

删除MEPREVERSEPROXY对象，删除的MEPREVERSEPROXY对象名称为"proxy"：

```
RMV MEPREVERSEPROXY: PROXYNAME="proxy";
```
