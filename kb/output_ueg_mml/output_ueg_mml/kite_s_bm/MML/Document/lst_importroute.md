# 查询指定协议中的入口路由配置（LST IMPORTROUTE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询设备上BGP VPN实例下通过Import方式引入其他协议路由的配置信息。

#### 注意事项

- 该命令执行后立即生效。
- 如果未指定引入路由协议类型，将查询指定BGP VPN实例下所有通过Import方式引入其他协议路由的配置信息。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称    | 参数说明                                                                                                                                     |
|:----------------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------|
| VRFNAME         | VPN实例名称 | 可选必选说明：可选参数 参数含义：该参数用于指定BGP VPN实例。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无                                                               |
| AFTYPE          | 地址族类型   | 可选必选说明：可选参数 参数含义：该参数用于指定BGP VPN实例下的地址族。 数据来源：本端规划 取值范围：枚举类型。 ipv4uni：IPv4地址族。ipv6uni：IPv6地址族。 默认值：无                                      |
| IMPORTPROTOCOL  | 路由协议    | 可选必选说明：可选参数 参数含义：用户设定引入其他协议路由时的策略名称。 数据来源：本端规划 取值范围：枚举类型。 direct：直连路由。ospf：开放式最短路径优先协议。static：静态路由。ospfv3：OSPFv3协议。wlr：WLR协议。 默认值：无      |
| IMPORTPROCESSID | 路由进程号   | 可选必选说明：条件必选参数 前提条件：该参数在“IMPORTPROTOCOL”配置为“ospf” 或 “ospfv3”时为必选参数。 参数含义：该参数用于指定所引入路由的协议进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 |

#### 使用实例

查询名称为“vrf1”的BGP VPN实例下所引入路由的协议信息：

```
LST IMPORTROUTE:VRFNAME="vrf1",AFTYPE=ipv4uni;
```
