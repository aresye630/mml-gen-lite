# 查询是否放通管道大颗粒readiness就绪探测（LST PSPKUBEPROBE）

- 命令功能
- 注意事项
- 本地用户权限
- 网管用户权限
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询当前是否放通管道大颗粒readiness就绪探测。

#### 注意事项

无。

#### 本地用户权限

manage-ug；system-ug；monitor-ug

#### 网管用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

```
%%LST PSPKUBEPROBE: SERVICEINSTANCE="CSDB_VNFC";%% 
RETCODE = 0  操作成功
 
结果如下 
-------- 
Ru就绪状态检测  =  真实检测 
(结果个数 = 1) 
 
---    END
```
