# 设置API GW HTTP 参数（SET APIGWHTTPPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

**须知** 

本命令属于高危命令，设置http参数需要重启API GW业务进程，可能导致业务中断。设置后长连接的会话时长和请求超时时间会发生变化，请谨慎修改。

该命令用于配置API GW对长连接请求的会话时长和超时时间。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   |   KEEPALIVE |   TIMEOUT |
|:-------|------------:|----------:|
| 初始值    |          60 |        60 |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                   |
|:----------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| KEEPALIVE | 会话时长   | 可选必选说明：可选参数 参数含义：APP跟API GW进行HTTP长连接建链，API GW作为服务端，每个HTTP连接的保活时间。如果超出这个时间APP没有发消息，API GW会拆除链路。单位：秒。 数据来源：本端规划 取值范围：整数类型，取值范围为30～360。 默认值：无 配置原则：当有大报文请求，需要根据报文大小将该值配置成一个较大的合理值，防止超时断连。 |
| TIMEOUT   | 超时时间   | 可选必选说明：可选参数 参数含义：API GW http请求的超时时间。单位：秒。 数据来源：本端规划 取值范围：整数类型，取值范围为30～360。 默认值：无 配置原则：无                                                                                                |

#### 使用实例

配置会话时长为300s，超时时长为60s：

```
SET APIGWHTTPPARA: KEEPALIVE=300, TIMEOUT=60;
```
