# 查询IP选项安全开关（LST IPSECURITYSWITCH）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询CSLB中IP选项安全开关配置。

#### 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组；

#### 参数说明

无

#### 使用实例

查询CSLB中IP选项安全开关的配置。

```
%%LST IPSECURITYSWITCH:;%%
RETCODE = 0  操作成功

操作结果如下：
--------------
      IPv4选项安全配置开关  =  IP安全开关关闭
IPv6扩展头选项安全配置开关  =  IP安全开关关闭
(结果个数 = 1)

---    END
```

#### 输出结果说明

参见**SET IPSECURITYSWITCH**的参数说明。
