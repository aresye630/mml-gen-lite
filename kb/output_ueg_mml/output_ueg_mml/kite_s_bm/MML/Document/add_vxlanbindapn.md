# 新增VXLAN隧道组绑定APN（ADD VXLANBINDAPN）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于配置VXLAN隧道组与APN的绑定关系。

#### 注意事项

- 该命令最大记录数为1000。
- 执行该命令时，新增Vxlan组绑定APN会改变业务数据转发流程，数据报文会转发到MEP。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                                                                     |
|:-------------|:---------|:-------------------------------------------------------------------------------------------------------------------------|
| APN          | APN      | 可选必选说明：必选参数 参数含义：该参数用于指定APN实例名。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数必须已经通过ADD APN命令配置。          |
| VXLANGRPNAME | VXLAN组名称 | 可选必选说明：必选参数 参数含义：该参数用于指定VXLAN隧道组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数必须已经通过ADD VXLANGRP命令配置。 |

#### 使用实例

配置VXLAN隧道组与APN的绑定关系，执行如下命令：

```
ADD VXLANBINDAPN: APN="apn1", VXLANGRPNAME="vxlangrp";
```
