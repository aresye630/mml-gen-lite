# 添加一个新的LAC组（ADD LACGROUP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用来在LAC组内绑定LAC号段。当需要在指定LAC组内绑定某个LAC号段时，使用该命令。

#### 注意事项

- 该命令执行后只对新激活用户生效。
- 该命令最大记录数为3000。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                       |
|:-------------|:--------|:-------------------------------------------------------------------------------------------|
| LACGROUPNAME | 指定LAC组名 | 可选必选说明：必选参数 参数含义：该参数用于指定LAC组名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

假设运营商需要去添加一个新的LAC组beijing：

```
ADD LACGROUP:LACGROUPNAME="beijing";
```
