# 删除服务API（RMV SERVICEAPI）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

该命令用于删除指定服务的所有API信息或者删除指定的服务API信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                              |
|:------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICENAME | 服务名称   | 可选必选说明：必选参数 参数含义：API所属服务名称。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～127。取值1-127字节的字符串。该服务名称由服务提供商提供，且该服务已经通过MP1口注册至MEP，可通过DSP MECSERVICE命令查询到。 默认值：无 配置原则：无 |
| APINAME     | API名称  | 可选必选说明：可选参数 参数含义：API名称。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～127。取值1-127字节的字符串。服务内不允许重复。由大小写字母，数字，“_”，“-”组成，且只能以字母开头。 默认值：无 配置原则：无                       |

#### 使用实例

删除服务名称为"photo"，API名称为"getphoto"的ServiceAPI对象：

```
RMV SERVICEAPI: SERVICENAME="photo", APINAME="getphoto";
```
