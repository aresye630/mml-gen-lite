# 查询MEP API流控配置（LST MEPAPITRAFFICCTRL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询MEP API流控配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称      | 参数说明                                                                           |
|:----------------|:----------|:-------------------------------------------------------------------------------|
| TRAFFICCTRLNAME | API流控策略名称 | 可选必选说明：可选参数 参数含义：该参数用于配置流控策略名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无 |

#### 使用实例

查询MEP API流控配置：

```
LST MEPAPITRAFFICCTRL:;
```

```
RETCODE = 0  操作成功

MEP API流控配置
-------------------------------------
    API流控策略名称  =  1
          服务名称  =  GmlcExecSvc
          API名称  =  One-shot Location
          API方法  =  GET
  流控阈值（个/秒）  =  5
(结果个数 = 1)

---    END
```
