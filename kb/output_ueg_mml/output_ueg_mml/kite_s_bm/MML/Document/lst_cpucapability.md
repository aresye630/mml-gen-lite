# 查询CPU能力基线(LST CPUCAPABILITY)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询所有CPU对应的能力基线值。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组； G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                           |
|:----------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。该参数不能取值为VNFP、ACS、VNRS_VNFC的服务实例名称。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

查询所有的CPU能力基线值，执行以下命令：

LST CPUCAPABILITY:SERVICEINSTANCE="vnfc";

```
RETCODE = 0  操作成功。

结果如下
--------
  CPU类型  =  x86_64
  CPU代数  =  Gold 6161 CPU
  CPU主频  =  2100
CPU基线值  =  1000
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释             |
|:--------|:------------------|
| CPU类型   | 该CPU对应的类型。        |
| CPU代数   | 该CPU所使用的代数。       |
| CPU主频   | 该CPU对应的主频，单位为MHz。 |
| CPU基线值  | 该CPU对应的能力基线值。     |
