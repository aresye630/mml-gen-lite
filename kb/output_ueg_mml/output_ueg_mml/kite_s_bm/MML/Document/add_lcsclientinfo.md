# 配置LCS客户端信息（ADD LCSCLIENTINFO）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于添加LCS Client与黑白名单MSISDN号段组的绑定关系。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为100。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称           | 参数说明                                                                                                                                               |
|:----------------|:---------------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
| LCSCLIENTID     | LCS客户端标识       | 可选必选说明：必选参数 参数含义：该字段用于指定LCS客户端标识。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无                                                                   |
| SEGGROUPNAME    | 白名单MSISDN号段组名称 | 可选必选说明：必选参数 参数含义：该参数用于指定白名单MSISDN号段组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：必须存在指定名称的LcsSubSebGrp。                           |
| BLACKSEGGROUPSW | 黑名单MSISDN号段组开关 | 可选必选说明：可选参数 参数含义：该参数用于指定是否使能黑名单MSISDN号段组。 数据来源：本端规划 取值范围： DISABLE：开关去使能。ENABLE：开关使能。 默认值：DISABLE 配置原则：无                                            |
| BLACKSEGGRPNAME | 黑名单MSISDN号段组名称 | 可选必选说明：条件必选参数 前提条件：该参数在“BLACKSEGGROUPSW”配置为“ENABLE”时为必选参数。 参数含义：该参数用于指定黑名单MSISDN号段组名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

添加LCS客户端标识为"app1"，白名单号段组名为"group1"，黑名单MSISDN号段组开关为"ENABLE"，黑名单号段组名为"group2"的CLIENTINFO：

```
ADD LCSCLIENTINFO: LCSCLIENTID="app1", SEGGROUPNAME="group1", BLACKSEGGROUPSW=ENABLE, BLACKSEGGRPNAME="group2";
```
