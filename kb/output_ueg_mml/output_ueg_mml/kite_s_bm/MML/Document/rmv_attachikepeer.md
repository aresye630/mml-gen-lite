# 删除绑定IKE对等体（RMV ATTACHIKEPEER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除IPSEC策略和IKE对等体的绑定关系。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                              |
|:---------------|:---------|:------------------------------------------------------------------------------------------------------------------|
| POLICYNAME     | 策略名称     | 可选必选说明：必选参数  参数含义：策略名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~15。不区分大小写。  默认值：无  配置原则：无                                 |
| SEQUENCENUMBER | 序列号      | 可选必选说明：必选参数  参数含义：序列号。  数据来源：对端协商  取值范围：整数类型，取值范围是1~10000。  默认值：无  配置原则：无                                         |
| POLICYMODE     | 策略模式     | 可选必选说明：必选参数  参数含义：策略模式。  数据来源：对端协商 取值范围： “Isakmp（ISAKMP模式）”：使用IKE建立IPsec安全联盟的模式  默认值：无  配置原则：无                    |
| TEMPLATEMODE   | 模板模式     | 可选必选说明：必选参数  参数含义：模板模式。  数据来源：对端协商 取值范围： None（无）“PolicyTemplate（策略模板模式）”：使用策略模板模式创建策略，仅支持用户级IPsec。  默认值：无  配置原则：无 |
| IKEPEERNAME    | IKE对等体名称 | 可选必选说明：必选参数  参数含义：IKE对等体名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~15。不区分大小写。  默认值：无  配置原则：无                             |

## 使用实例

删除IKE Peer绑定关系：

```
RMV ATTACHIKEPEER:POLICYNAME="pol2",SEQUENCENUMBER=1,POLICYMODE=Isakmp,TEMPLATEMODE=None,IKEPEERNAME="aa";
```
