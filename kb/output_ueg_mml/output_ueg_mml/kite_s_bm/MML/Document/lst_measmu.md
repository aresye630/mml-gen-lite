# 查询话统测量单元模型(LST MEASMU)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询网元的测量单元模型信息。

## 注意事项

无。

## 参数说明

| 参数标识               | 参数名称    | 参数说明                                                                                                             |
|:-------------------|:--------|:-----------------------------------------------------------------------------------------------------------------|
| MEID               | 网元ID    | 可选必选说明：必选参数。 参数含义：标识网元ID，可以通过LST MELST ME命令查询获取。 取值范围：0~65535。 默认值：无。 配置原则：无。                                    |
| MOCNAME            | 测量对象类名称 | 可选必选说明：可选参数。 参数含义：测量对象类名称，支持中英文模糊搜索。 取值范围：字符串类型，长度不超过256个字符。 默认值：无。 配置原则：若不输入，则表示该参数不作为查询的限制条件。                  |
| MUNAME             | 测量单元名称  | 可选必选说明：可选参数。 参数含义：测量单元名称，支持中英文模糊搜索。 取值范围：字符串类型，长度不超过256个字符。 默认值：无。 配置原则：若不输入，则表示该参数不作为查询的限制条件。                   |
| MUID               | 测量单元ID  | 可选必选说明：可选参数。 参数含义：测量单元ID，可以通过LST MEASUNIT命令查询获取。 取值范围：整数类型，取值范围为0~4294967294。 默认值：无。 配置原则：若不输入，则表示该参数不作为查询的限制条件。 |
| SW_CREDIBLE_ENABLE | 支持开关可信  | 可选必选说明：可选参数。 参数含义：是否支持开关可信。 取值范围：枚举 YES(是)NO(否) 默认值：无。 配置原则：无。                                                   |
| DEFMEAS            | 默认测量    | 可选必选说明：可选参数。 参数含义：任务是否默认测量。 取值范围：枚举 YES(是)NO(否) 默认值：无。 配置原则：无。                                                   |
