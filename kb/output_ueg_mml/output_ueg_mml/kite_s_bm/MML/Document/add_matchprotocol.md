# 增加路由协议匹配路由策略（ADD MATCHPROTOCOL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于增加路由协议匹配路由策略。通过ADD MATCHPROTOCOL命令可对路由的类型进行过滤，即只允许指定路由协议类型的路由通过策略。

#### 注意事项

- 该命令最大记录数为6。
- 配置该命令前，必须首先配置ADD ROUTEPOLICYNODE命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                              |
|:-------------|:--------|:----------------------------------------------------------------------------------------------------------------------------------|
| POLICYNAME   | 路由策略名字  | 可选必选说明：必选参数 参数含义：该参数用来表示路由策略名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无                                                          |
| NODESEQUENCE | 路由策略节点号 | 可选必选说明：必选参数 参数含义：该参数用来表示路由策略节点号。 数据来源：本端规划 取值范围：整数类型，取值范围为0～65535。 默认值：无                                                          |
| PROTOCOLTYPE | 协议类型    | 可选必选说明：必选参数 参数含义：该参数用来表示路由类型。 数据来源：本端规划 取值范围：枚举类型。 DIRECT：直连路由。OSPF：OSPF路由。STATIC：静态路由。BGP：BGP路由。OSPFV3：OSPFv3路由。WLR：WLR路由。 默认值：无 |

#### 使用实例

配置policy路由策略10节点下，协议匹配路由策略设置为OSPF：

```
ADD MATCHPROTOCOL:POLICYNAME="policy",NODESEQUENCE=10,PROTOCOLTYPE=OSPF;
```
