# 删除IP地址白名单列表（RMV CFIPWHITELIST）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

**须知** 

本命令属于高危命令，删除IP地址白名单列表，可能会影响用户ICAP业务匹配，导致用户业务受损，请谨慎使用并联系华为支持协助操作。

该命令用于删除配置IP地址白名单。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                    |
|:------------|:-----------|:--------------------------------------------------------------------------------------------------------|
| IPTYPE      | IP地址类型     | 可选必选说明：必选参数 参数含义：该参数用于设置Ip地址类型。 数据来源：本端规划 取值范围： IPV4：IPv4地址类型。IPV6：IPv6地址类型。 默认值：无 配置原则：无               |
| IPV4ADDR    | IPv4地址     | 可选必选说明：条件必选参数 前提条件：该参数在“IPTYPE”配置为“IPV4”时为必选参数。 参数含义：该参数用于指定IPv4地址。 数据来源：本端规划 取值范围：NA。 默认值：无 配置原则：无     |
| IPV4MASKLEN | IPv4地址掩码长度 | 可选必选说明：条件必选参数 前提条件：该参数在“IPTYPE”配置为“IPV4”时为必选参数。 参数含义：该参数用于指定IPv4地址掩码长度。 数据来源：本端规划 取值范围：NA。 默认值：无 配置原则：无 |
| IPV6ADDR    | IPv6地址     | 可选必选说明：条件必选参数 前提条件：该参数在“IPTYPE”配置为“IPV6”时为必选参数。 参数含义：该参数用于设置Ipv6地址。 数据来源：本端规划 取值范围：NA。 默认值：无 配置原则：无     |
| IPV6MASKLEN | IPv6地址掩码长度 | 可选必选说明：条件必选参数 前提条件：该参数在“IPTYPE”配置为“IPV6”时为必选参数。 参数含义：该参数用于指定IPv6地址掩码长度。 数据来源：本端规划 取值范围：NA。 默认值：无 配置原则：无 |

#### 使用实例

删除IP地址列表RMV CFIPWHITELIST：

```
RMV CFIPWHITELIST: IPTYPE=IPV4, IPV4ADDR="0.0.0.0", IPV4MASKLEN=1;
```
