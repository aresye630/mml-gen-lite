# 删除接口绑定VPN（RMV IPBINDVPNIPSEC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

删除接口和VPN的绑定关系，影响该隧道下的地址信息，有业务影响。

该命令用于配置接口去绑定VPN。

## 注意事项

- 该命令执行后立即生效。

- 执行该命令将清除该接口下所有的IP配置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                 |
|:--------|:--------|:-----------------------------------------------------------------------------------------------------|
| IFNAME  | 接口名     | 可选必选说明：必选参数  参数含义：用于设置绑定VPN的接口名。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~63。接口名称由接口类型+接口编号组成。  默认值：无  配置原则：无 |
| VRFNAME | VPN实例名称 | 可选必选说明：必选参数  参数含义：该参数用于指定接口绑定的VPN实例名称。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是1~31。  默认值：无  配置原则：无            |

## 使用实例

配置接口去绑定VPN：

```
RMV IPBINDVPNIPSEC:IFNAME="Loopback1",VRFNAME="vrf1";
```
