# 添加基站类型配置（ADD LCSNRTYPE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

新增基于基站ID段的基站类型配置。

#### 注意事项

- 该命令最大记录数为1000。
- 执行该命令后，重新发起的定位请求才会用到修改后的参数值。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称    | 参数说明                                                                                                 |
|:----------------|:--------|:-----------------------------------------------------------------------------------------------------|
| GNODEBIDSEGNAME | 基站标识段名称 | 可选必选说明：必选参数 参数含义：该参数用于指定基站标识段名称。 数据来源：本端规划 取值范围：字符串类型，不区分大小写，不能包含空格，输入长度范围为1～31。 默认值：无 配置原则：无        |
| GNODEBIDSTART   | 基站起始标识  | 可选必选说明：必选参数 参数含义：该参数用于配置基站起始标识。 数据来源：全网规划 取值范围：整型数字类型，取值范围为0~4294967295。 默认值：无 配置原则：无                |
| GNODEBIDEND     | 基站结束标识  | 可选必选说明：必选参数 参数含义：该参数用于配置基站结束标识。 数据来源：全网规划 取值范围：整型数字类型，取值范围为0~4294967295。 默认值：无 配置原则：无                |
| GNODEBTYPE      | 基站类型    | 可选必选说明：必选参数 参数含义：该参数用于设置解算算法关联的基站类型。 数据来源：本端规划 取值范围：小站/宏站。 SMALL_CELL：小站。MACRO_CELL：宏站。 默认值：无 配置原则：无 |

#### 使用实例

新增基于基站ID段的基站类型配置：

```
ADD LCSNRTYPE: GNODEBIDSEGNAME="client1", GNODEBIDSTART=190040, GNODEBIDEND=190050, GNODEBTYPE=MACRO_CELL;
```
