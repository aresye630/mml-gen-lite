# 设置FE心跳故障复位功能开关（SET FEHBRESET）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

当设置心跳复位开关为使能状态时，心跳故障会进行复位单板操作。

该命令用来设置FE心跳故障复位功能开关。

#### 注意事项

- 该命令执行后立即生效。

- 该命令仅适用于NP卡加速模式场景。

系统部署完成后，已经存在初始记录，参数的初始记录值如下表：

| SWITCH   |
|:---------|
| Disable  |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                         |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------|
| SWITCH | 心跳复位开关 | 可选必选说明：必选参数 参数含义：FE心跳故障时，是否需要复位单板。 数据来源：本端规划 取值范围： “Enable”：表示心跳故障后，复位单板。 “Disable”：表示心跳故障后，不复位单板。 默认值：无。 配置原则：建议值为“Enable”。 |

#### 使用实例

设置FE心跳故障复位单板功能开关为启用：

```
SET FEHBRESET: SWITCH=Enable;
```
