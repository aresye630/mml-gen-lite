# 设置User Profile操作系统级带宽管理开关（SET UPOSLELBWMSW）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

如果运营商希望设置以操作系统类型匹配相应带宽控制策略，可使用该命令来设置User Profile下操作系统级带宽管理开关。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为105000。
- 此命令的生效范围限于User Profile。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称                    | 参数说明                                                                                                                                                                                                 |
|:----------------|:------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USERPROFILENAME | User Profile名称          | 可选必选说明：必选参数 参数含义：该参数用于指定User Profile名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数使用ADD USERPROFILE命令配置生成。配置的USERPROFILENAME必须是系统已经存在的UserProfile对象名称。                           |
| ISENABLE        | User Profile操作系统级带宽管理开关 | 可选必选说明：必选参数 参数含义：User Profile操作系统级带宽管理开关。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能（关闭）User Profile下操作系统级带宽管理开关。ENABLE：使能（开启）User Profile操作系统级带宽管理开关。INHERIT：继承SET APNOSLELBWMSW命令的ISENABLE参数配置。 默认值：无 配置原则：无 |

#### 使用实例

假如运营商需使能名称为“testuserprofile”的User Profile的操作系统带宽管理功能：

```
SET UPOSLELBWMSW: USERPROFILENAME="testuserprofile", ISENABLE=ENABLE;
```
