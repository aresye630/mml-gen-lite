# 查询全局默认配额开关（LST UPDEFAULTQUOTA）

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询在线计费默认配额使能开关。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询默认配额使能开关：

```
LST UPDEFAULTQUOTA:;
```
