# 查询防欺诈可信DNS服务器（LST AFDNSSERVER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明

- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询当前防欺诈功能配置的可信DNS服务器信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

显示当前可信dns服务器IP地址：

```
LST AFDNSSERVER:;
```

```
RETCODE = 0  操作成功。

防欺诈DNS服务器信息
-------------------
 IP地址版本类型  =  IPV4
DNS服务器IP地址  =  192.168.0.1
(结果个数 = 1)
---    END
```
