# 增加LCS小站二维定位TRP（ADD LCSSCELL2DTRP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：LMF**

该命令用于增加LCS小站二维定位的TRP配置。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为20000。
- 执行该命令配置成2维TRP，不能再执行ADD LCSSCELLALONETRP将其配置为0维TRP，反之相同。
- 若不执行ADD LCSSCELLALONETRP或ADD LCSSCELL1DTRPPAIR命令配置0维或1维TRP，则该TRP缺省支持2维定位；若执行ADD LCSSCELL1DTRPPAIR命令将其配置为1维TRP，同时需要其参与2维定位，需要执行该命令将其配置为2维TRP，否则不参与2维定位。
- 执行该命令后，重新发起定位请求时修改生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                |
|:---------|:-------|:------------------------------------------------------------------------------------|
| GNODEBID | 基站标识   | 可选必选说明：必选参数 参数含义：该参数用于设置基站标识。 数据来源：全网规划 取值范围：整型数字类型，取值范围为0~4294967295。 默认值：无 配置原则：无 |
| TRPID    | TRP标识  | 可选必选说明：必选参数 参数含义：该参数用于设置TRP标识。 数据来源：全网规划 取值范围：整型数字类型，取值范围为1~65535。 默认值：无 配置原则：无     |

#### 使用实例

增加LCS小站二维定位的TRP配置：

```
ADD LCSSCELL2DTRP: GNODEBID=190041, TRPID=1;
```
