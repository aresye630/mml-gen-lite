# 删除IPv6前缀过滤器节点（RMV IPV6PREFIXFILTERNODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于删除基于IPv6信息的前缀过滤器。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称        | 参数说明                                                                                           |
|:-------------|:------------|:-----------------------------------------------------------------------------------------------|
| NAME         | IPv6前缀列表名字  | 可选必选说明：必选参数 参数含义：IP前缀列表名字。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～169。 默认值：无                            |
| NODESEQUENCE | IPv6前缀列表节点号 | 可选必选说明：可选参数 参数含义：IP前缀列表节点号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 配置原则：当不输入此参数时，删除所有节点。 |

#### 使用实例

删除IPv6前缀过滤器：

```
RMV IPV6PREFIXFILTERNODE:NAME="c",NODESEQUENCE=25;
```
