# 查询物联网能力上报（LST IOTCAPABILITY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用来查看UPF的物联网接入能力上报功能选择指示。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

查询UPF的物联网接入能力上报功能开关配置：

```
LST IOTCAPABILITY:;
```

```
RETCODE = 0 操作成功。

物联网能力
------------------------------------
NB-IoT接入能力上报 = ENABLE
(结果个数 = 1)
--- END
```

#### 输出结果说明

参见SET IOTCAPABILITY的参数说明。
