# 显示已部署的Pod的版本号（DSP UPGPODINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

在升级阶段中，可以用来查询pod版本号信息。

## 注意事项

该命令只能在灰度升级阶段使用。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                                              |
|:-----------|:--------|:------------------------------------------------------------------------------------------------------------------|
| PODTYPE    | Pod类型   | 可选必选说明：可选参数  参数含义：该参数用于表示Pod类型，如sfm-pod，具体类型定义请参考tosca模板中的定义。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~200。  默认值：无  配置原则：无 |
| VNFVERSION | 归属的网元版本 | 可选必选说明：可选参数  参数含义：该参数用于表示VNF版本。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~200。  默认值：无  配置原则：无                               |

## 使用实例

DSP UPGPODINFO:;

```
%%DSP UPGPODINFO:;%%
RETCODE = 0  操作成功

结果如下
------------------------
Pod类型      Pod标识                 Pod版本号        归属的网元版本
vusn-pod     vusn-pod-at133es4ed     22.1.RC1.B070    22.1.RC1.B070
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释                                       |
|:--------|:--------------------------------------------|
| Pod类型   | 该参数用于表示Pod类型，如sfm-pod，具体类型定义请参考tosca模板中的定义。 |
| Pod标识   | 该参数用于表示Pod标识。                               |
| Pod版本号  | 该参数用于表示Pod版本。                               |
| 归属的网元版本 | 该参数用于表示VNF版本。                               |
