# 查询日志代理丢弃的日志信息（DSP LOGAGENTSTC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询日志代理丢弃的日志信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| LOGCLASS        | 日志类别   | 可选必选说明：必选参数 参数含义：日志类别。 数据来源：本端规划 取值范围：枚举类型。 log：普通日志。debug：调试信息（包括诊断日志）。alarm：告警信息。operlog：操作日志。 默认值：无       |
| PROCESSID       | 进程ID   | 可选必选说明：可选参数 参数含义：进程ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                          |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

查询日志代理丢弃的告警日志统计信息，可通过如下命令查询：

```
DSP LOGAGENTSTC:LOGCLASS=alarm,PROCESSID=3,SERVICEINSTANCE="vnfc";
```
