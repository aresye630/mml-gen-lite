# 删除网络实例配置（RMV NETWORKINSTVPNMAP）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于删除网络实例和VPN的绑定关系。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                               |
|:----------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------|
| NETWORKINSTANCE | 网络实例名称 | 可选必选说明：可选参数 参数含义：网络实例标识。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～100，单位是字节。由“_”、“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”，不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

删除名为"net1"的网络实例：

```
RMV NETWORKINSTVPNMAP: NETWORKINSTANCE="net1";
```
