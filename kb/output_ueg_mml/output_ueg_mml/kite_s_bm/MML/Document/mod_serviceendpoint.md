# 修改服务端点（MOD SERVICEENDPOINT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

该命令用于修改服务端点。服务端点指服务对外提供的访问入口信息，服务可拥有多个服务端点，多个服务端点以服务端点组的形式关联至某个服务。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                             |
|:-------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ENDPOINTNAME | 服务端点名称 | 可选必选说明：必选参数 参数含义：该参数用于指定服务端点名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“_”组成，且只能以字母或者数字开头。 默认值：无 配置原则：无                                                                  |
| ENDPOINTGRP  | 服务端点组  | 可选必选说明：可选参数 参数含义：该参数用于指定本服务端点所属的服务端点组的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“_”组成，且只能以字母或者数字开头。 默认值：无 配置原则： 该参数使用ADD SERVICEENDPOINTGRP命令配置生成。输入单空格将删除该参数已有配置项。     |
| TYPE         | 服务端点类型 | 可选必选说明：可选参数 参数含义：该参数用于指定服务端点类型。 数据来源：对端协商 取值范围： IPv4：IPv4地址类型。IPv6：IPv6地址类型。 默认值：无 配置原则：无                                                                                        |
| IPV4         | IPv4地址 | 可选必选说明：条件必选参数 前提条件：该参数在“TYPE”配置为“IPv4”时为必选参数。 参数含义：该参数用于指定服务端点的IPv4地址。 数据来源：对端协商 取值范围：IPv4地址类型。0.0.0.0～255.255.255.255。 默认值：无 配置原则：无                                             |
| IPV6         | IPv6地址 | 可选必选说明：条件必选参数 前提条件：该参数在“TYPE”配置为“IPv6”时为必选参数。 参数含义：该参数用于指定服务端点的IPv6地址。 数据来源：对端协商 取值范围：IPv6地址类型。冒号分十六进制，格式为X:X:X:X:X:X:X:X。除了组播地址、链路本地地址、环回地址或未指定的地址为非法地址外，其他都为合法地址。 默认值：无 配置原则：无 |
| PORT         | 端口号    | 可选必选说明：可选参数 参数含义：该参数用于指定服务端点的端口号。 数据来源：对端协商 取值范围：整数类型，取值范围为1～65535。 默认值：无 配置原则：无                                                                                                 |

#### 使用实例

修改SERVICEENDPOINT对象，修改的SERVICEENDPOINT对象名称为"service\_endpoint"，隶属的服务端点组名修改为"service\_endpoint\_grp"，服务端点类型修改为IPv4，IPV4地址修改为"192.168.1.1"，端口号修改为8081：

```
MOD SERVICEENDPOINT: ENDPOINTNAME="service_endpoint", ENDPOINTGRP="service_endpoint_grp", TYPE=IPv4, IPV4="192.168.1.1", PORT=8081;
```
