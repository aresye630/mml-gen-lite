# 删除MEC服务（RMV MECSERVICE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

该命令用于删除MEC服务。

#### 注意事项

- 该命令执行后立即生效。
- 删除MEC服务后，APP不能通过MEP平台访问该服务，请谨慎删除。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                          |
|:------------|:-------|:--------------------------------------------------------------------------------------------------------------|
| SERVICENAME | 服务名称   | 可选必选说明：必选参数 参数含义：该参数用于指定服务名称。 数据来源：对端协商 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“_”组成，且只能以字母或者数字开头。 默认值：无 配置原则：无 |

#### 使用实例

删除服务名称为"mec\_service"的MECSERVICE对象：

```
RMV MECSERVICE: SERVICENAME="mec_service";
```
