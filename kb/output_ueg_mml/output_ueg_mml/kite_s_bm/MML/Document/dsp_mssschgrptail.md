# 查询调度组统计信息（DSP MSSSCHGRPTAIL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询调度组统计信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                   |
|:----------|:-------|:-------------------------------------------------------------------------------------------------------|
| RUNAME    | RU名称   | 可选必选说明：必选参数 参数含义：该参数用于指定RU名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：使用DSP RU查看RU名称。 |
| INGROUPID | 调度组ID  | 可选必选说明：必选参数 参数含义：该参数用于表示调度组ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                            |

#### 使用实例

查询调度组的统计信息：

```
DSP MSSSCHGRPTAIL:INGROUPID = 0,RUNAME = "VNODE_VNRS_VNFC_IPU_0064";
```

```
RETCODE = 0  操作成功。

结果如下
--------
        队列号  =  4
  调度队列权重  =  10
    队列读成功  =  100401
    队列写成功  =  100401
    队列读失败  =  20
    队列写失败  =  0
      队列长度  =  4096
队列已使用单元  =  0
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称   | 输出项解释         |
|:--------|:--------------|
| 队列号     | 用于表示队列号。      |
| 调度队列权重  | 用于表示调度队列权重。   |
| 队列读成功   | 用于表示队列读成功的个数。 |
| 队列写成功   | 用于表示队列写成功的个数。 |
| 队列读失败   | 用于表示队列读失败的次数。 |
| 队列写失败   | 用于表示队列写失败的次数。 |
| 队列长度    | 用于表示队列长度。     |
| 队列已使用单元 | 用于表示队列已使用单元。  |
