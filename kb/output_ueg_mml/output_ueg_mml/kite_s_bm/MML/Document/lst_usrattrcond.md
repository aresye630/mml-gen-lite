# 查询用户属性过滤条件（LST USRATTRCOND）

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询用户属性过滤条件。

#### 注意事项

如果不输入用户属性过滤条件名称，表示查询系统中所有过滤条件。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                   |
|:------------|:---------|:-----------------------------------------------------------------------------------------------------------------------|
| CONDNAME    | 过滤条件名称   | 可选必选说明：可选参数 参数含义：该参数用于设置过滤条件名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无                            |
| ITEMID      | 过滤条件项目索引 | 可选必选说明：可选参数 参数含义：该参数用于设置用户过滤条件项目索引。 数据来源：本端规划 取值范围：整数类型 ，取值范围是1~4294967295。 默认值：无 配置原则：无                               |
| CONTENTTYPE | 内容类型     | 可选必选说明：可选参数 参数含义：该参数用于设置过滤条件内容类型。 数据来源：本端规划 取值范围：枚举类型。 USER_PROFILE：用户模板。APN：APN。RAT：RAT类型。MSISDN：MSISDN。 默认值：无 配置原则：无 |

#### 使用实例

- 假如运营商需要查询名称为user\_cond1的用户属性过滤条件：

  ```
  %%LST USRATTRCOND: CONDNAME="user_cond1";
  ```

  ```
  %%
  RETCODE = 0  操作成功

  用户属性过滤条件
  ----------------
      过滤条件名称  =  user_cond1
  过滤条件项目索引  =  1
          内容类型  =  USERPROFILE
           APN名称  =  NULL
      用户模板名称  =  up1
           RAT类型  =  RESERVED
            MSISDN  =  NULL
  (结果个数 = 1)

  ---    END
  ```
- 假如运营商需要查询所有的用户属性过滤条件：

  ```
  %%LST USRATTRCOND:;
  ```

  ```
  %%
  RETCODE = 0  操作成功

  用户属性过滤条件
  ----------------
  过滤条件名称  过滤条件项目索引  内容类型     APN名称  用户模板名称  RAT类型   MSISDN  

  user_cond1    1                 USERPROFILE  NULL     up1           RESERVED  NULL    
  user_cond2    1                 USERPROFILE  NULL     up1           RESERVED  NULL    
  (结果个数 = 2)

  ---    END
  ```
