# 查询以太网交换机(LST LSW)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明
- 参考信息

## 命令功能

本命令用于查询以太网交换机。

## 注意事项

无。

## 参数说明

无。

## 使用实例

1、查询环境中的以太网交换机，只有一个交换机的场景。

```
%%LST LSW:;%%
RETCODE = 0  操作成功

操作结果如下 
------------   
  以太网交换机名称  =  LSW1
以太网交换机IP地址  =  10.0.0.0               
              状态  =  正常               
              用户  =  AdminUser               
              端口  =  161           
          协议版本  =  SNMPv3           
          认证协议  =  SHA512           
          加密协议  =  AES256 
(结果个数 = 1)

---    END
```

2、查询环境中的以太网交换机，有多个交换机的场景。

```
%%LST LSW:;%%
RETCODE = 0  操作成功

操作结果如下 
------------   
以太网交换机名称   以太网交换机IP地址    状态     用户        端口  协议版本  认证协议   加密协议   
LSW1               10.0.0.0              正常     AdminUser  161    SNMPv3    SHA512     AES256
LSW2               10.0.0.1              正常     AdminUser  161    SNMPv3    SHA512     AES256 
(结果个数 = 2) 

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。输出结果说明如表1 输出项说明所示。

该命令执行异常，会返回对应的错误描述。常见错误描述如表2 错误码列表所示。

| 输出项名称      | 输出项解释                                       |
|:-----------|:--------------------------------------------|
| 以太网交换机名称   | 以太网交换机的名称。                                  |
| 以太网交换机IP地址 | 以太网交换机的IP地址。                                |
| 状态         | 以太网交换机的连接状态。 取值范围： “正常”“未知”                 |
| 用户         | 以太网交换机的SNMP用户名。                             |
| 端口         | 以太网交换机的端口。                                  |
| 协议版本       | 以太网交换机的协议版本。 取值范围：“SNMPv3”                  |
| 认证协议       | 以太网交换机的认证协议。 取值范围： “SHA256”“SHA384”“SHA512” |
| 加密协议       | 以太网交换机的加密协议。 取值范围：“AES256”                  |

|    错误码 | 错误码解释   | 原因分析                | 处理建议                  |
|-------:|:--------|:--------------------|:----------------------|
| 150212 | 交换机不存在  | 当前环境中不存在已添加的以太网交换机。 | 确认当前环境是否存在已添加的以太网交换机。 |
| 150214 | 操作失败    | 内部执行报错。             | 请联系华为技术支持。            |
