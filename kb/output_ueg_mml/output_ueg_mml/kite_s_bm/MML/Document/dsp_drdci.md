# 显示DC间通信通道运行状态（DSP DRDCI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询DC间通信通道运行状态。

## 注意事项

- 该命令只用于在UEG-L/UEN网元采用主备（冷备）容灾模式下执行。
- 该命令只用于在UEG-M/UEG网元采用主备（热备）容灾模式下执行。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                 |
|:----------|:-------|:---------------------------------------------------------------------------------------------------------------------|
| DRGROUPID | 容灾组标识  | 可选必选说明：可选参数  参数含义：该参数用于指定容灾组标识。  数据来源：全网规划  取值范围：整数类型，取值范围是1~8。  默认值：无  配置原则：  可使用LST DRGROUPINFO返回的DRGROUPID作为参数输入。 |

## 使用实例

查询DC间通信通道运行状态。

```
%%DSP DRDCI:;%%
RETCODE = 0  操作成功
结果如下
--------
容灾组标识      隧道组索引     DC间通信通道状态
1               1              主备容灾实例之间握手成功，处于连接状态                                                              
1               2              主备容灾实例之间握手失败，处于断连状态                                                                                                                         
(结果个数 = 2)

---    END
```

## 输出结果说明

| 输出项名称     | 输出项解释                                                                                                                                                                                                                            |
|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 容灾组标识     | 该参数用于指定容灾组标识。                                                                                                                                                                                                                    |
| 隧道组索引     | 该参数用于指定隧道组索引。                                                                                                                                                                                                                    |
| DC间通信通道状态 | 该参数用于指定DC间通信通道状态。 若输出结果为NULL，可使用工程命令DSP DRMODE查询当前环境的容灾模式。当DRMODE为ACTIVE-STANDBY时，表示当前处于初始态；当DRMODE为LOADBALANCE或NULL时，表示未使能容灾功能。 取值说明： NULL（未使能容灾功能或初始态，其状态无效。）CONNECTED（主备容灾实例之间握手成功，处于连接状态。）DISCONNECTED（主备容灾实例之间握手失败，处于断连状态。） |
