# 查询APP实例授权（LST AUTHAPPINSTANCE）

- 命令功能
- 注意事项
- 操作用户权限

- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF、MPF**

该命令用于查询APP实例和APPID的绑定关系，可以根据此绑定关系了解APP实例能够访问哪些服务。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                                |
|:--------------|:--------|:----------------------------------------------------------------------------------------------------|
| APPINSTANCEID | APP实例ID | 可选必选说明：可选参数 参数含义：该参数用于指定APP实例标识。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“_”组成。 默认值：无 配置原则：无 |

#### 使用实例

- 查询所有APP实例授权信息：

  ```
  LST AUTHAPPINSTANCE:;
  ```

  ```
  RETCODE = 0  操作成功

  APP实例授权信息
  ---------------
  APP实例ID     APP标识  

  appInstance1  app1     
  appInstance2  app1     
  (结果个数 = 2)

  ---    END
  ```
- 查询APP实例ID为"appInstance1"的APP实例授权信息：

  ```
  LST AUTHAPPINSTANCE: APPINSTANCEID="appInstance1";
  ```

  ```
  RETCODE = 0  操作成功

  APP实例授权信息
  ---------------
  APP实例ID  =  appInstance1
    APP标识  =  app1
  (结果个数 = 1)

  ---    END
  ```
