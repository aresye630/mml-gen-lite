# 删除MEP TLS参数（RMV MEPTLSPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

该命令用于删除一组TLS参数配置。

#### 注意事项

- 该命令执行后立即生效。
- 当本TLS参数被一个MEPHTTPSERVER/MEPHTTPCLIENT对象所引用时，不允许删除本条记录；如需删除，请确保没有任何MEPHTTPSERVER/MEPHTTPCLIENT对象引用本条记录。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                             |
|:------------|:--------|:-----------------------------------------------------------------------------------------------------------------|
| TLSPARANAME | TLS参数名称 | 可选必选说明：必选参数 参数含义：该参数用于指定TLS参数名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。由大小写字母，数字，“-”，“.”组成，且只能以字母或者数字开头。 默认值：无 配置原则：无 |

#### 使用实例

删除MEPTLSPARA对象，删除的MEPTLSPARA对象的名称为“tls”：

```
RMV MEPTLSPARA: TLSPARANAME="tls";
```
