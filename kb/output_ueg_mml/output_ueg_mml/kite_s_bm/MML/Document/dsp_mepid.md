# 查询MEP标识（DSP MEPID）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：MPF**

该命令用于显示当通过SET MPFATTR命令配置Mm5接口消息类型为SPEC\_RULE时，动态DNS Rule或Traffic Rule下发携带的MepId标识信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

无。

#### 使用实例

显示MepId标识信息：

```
DSP MEPID:;
```

```
RETCODE = 0 操作成功

-------
MEP ID = mpf
(结果个数 = 1)

--- END
```

#### 输出结果说明

| 输出项名称   | 输出项解释                |
|:--------|:---------------------|
| MEP ID  | 用于显示Mm5接口下发的MepId信息。 |
