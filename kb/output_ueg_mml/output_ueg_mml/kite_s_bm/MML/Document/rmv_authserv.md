# 删除授权服务（RMV AUTHSERV）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

**须知** 

本命令属于高危命令，如果该服务所在的授权服务列表已通过APPAUTHINFO相关命令授权给指定APP，删除本服务会导致MEP平台为指定APP所签发的token失效，其需要重新申请token才能继续访问，请谨慎删除。

该命令用于从指定的授权服务列表中删除指定的授权服务。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称     | 参数说明                                                                                                                 |
|:----------------|:---------|:---------------------------------------------------------------------------------------------------------------------|
| SERVICENAME     | 授权服务名称   | 可选必选说明：必选参数 参数含义：该参数用于指定授权服务名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～127。该服务名称由服务提供商提供，可通过DSP MECSERVICE命令查询到。 默认值：无 配置原则：无 |
| SERVICELISTNAME | 授权服务列表名称 | 可选必选说明：必选参数 参数含义：该参数用于指定授权服务列表名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：该参数使用LST AUTHSERVLIST命令配置生成。          |

#### 使用实例

删除服务名称为"app01\_service2"、服务列表为"serviceList"的授权服务信息：

```
RMV AUTHSERV: SERVICENAME="app01_service2", SERVICELISTNAME="serviceList";
```
