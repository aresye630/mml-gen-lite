# 删除API GW地址（RMV APIGWADDR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

**须知** 

本命令属于高危命令，执行该命令后，API GW的IP地址会被删除。

该命令仅在使用主机型网络时, 删除API GW的IP地址。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                    |
|:------------|:-------|:------------------------------------------------------------------------------------------------------------------------|
| ADDRESSTYPE | 访问地址类型 | 可选必选说明：必选参数 参数含义：API GW 主机型访问地址IP类型。 数据来源：本端规划 取值范围：枚举类型。 IPv4：API GW主机型网络地址类型为IPv4。IPv6：API GW主机型网络为IPv6。 默认值：无 配置原则：无 |

#### 使用实例

删除API GW的IPv4地址：

```
RMV APIGWADDR: ADDRESSTYPE=IPv4;
```
