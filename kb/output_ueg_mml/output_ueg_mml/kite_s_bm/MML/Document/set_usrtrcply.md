# 设置用户跟踪策略（SET USRTRCPLY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于设置用户跟踪策略。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 匿名化开关默认开启，建议运营商遵从所在国家的相关法律关闭。为更好地保护用户个人隐私，请及时开启匿名化开关。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   |   LOCALFILEDAYS | ANONYMOUSSWITCH   |
|:-------|----------------:|:------------------|
| 初始值    |               7 | ENABLE            |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                              |
|:----------------|:-------|:--------------------------------------------------------------------------------------------------|
| LOCALFILEDAYS   | 最大保留天数 | 可选必选说明：可选参数 参数含义：跟踪存盘文件最大保留天数，本地时间3:00定时删除超期文件。 数据来源：本端规划 取值范围：整数类型，取值范围为1～720，单位是天。 默认值：无 配置原则：无 |
| ANONYMOUSSWITCH | 匿名化开关  | 可选必选说明：可选参数 参数含义：跟踪存盘文件匿名化策略开关。 数据来源：本端规划 取值范围：枚举类型。 ENABLE：使能。DISABLE：不使能。 默认值：无 配置原则：无          |

#### 使用实例

设置跟踪文件删除策略为7天：

```
SET USRTRCPLY: LOCALFILEDAYS=7;
```
