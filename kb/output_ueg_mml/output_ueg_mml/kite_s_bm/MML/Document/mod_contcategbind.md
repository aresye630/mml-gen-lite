# 修改内容分类组绑定关系（MOD CONTCATEGBIND）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于修改内容分类组绑定关系。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称        | 参数说明                                                                                                                                                        |
|:--------------|:------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CFPROFILENAME | 内容过滤策略名称    | 可选必选说明：必选参数 参数含义：该参数用于设置内容过滤策略名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则：该参数使用ADD CFPROFILE命令配置生成。                                       |

| ACTION        | 动作          | 可选必选说明：可选参数 参数含义：该参数用于设置动作。 数据来源：本端规划 取值范围： PASS：报文转发。BLOCK：报文丢弃。REDIRECT：报文重定向。 默认值：无 配置原则：无                                                               |

#### 使用实例

修改内容分类组动作为报文丢弃：

```
MOD CONTCATEGBIND: CFPROFILENAME="cf_profile1", CONTCATEGNAME="cf_contcategrprange1", ACTION=BLOCK;
```
