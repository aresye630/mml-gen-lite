# 添加LCS客户端策略（ADD LCSCLIENTPLY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于添加LCS Client的策略。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为100。
- LCS Client不携带终端类型且没有通过此配置添加周期定位用户缺省类型时，GMLC使用普通终端AMF位置上报消息超时时长。
  首次上报心跳的定时器时长为1~订阅消息中携带的周期定位间隔\*LmfNoEvtNtyNum之间的随机值，后续按照订阅消息中携带的周期定位间隔\*LmfNoEvtNtyNum时间定时上报。用户切换稳态后不再上报。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称       | 参数说明                                                                                                                                                                   |
|:---------------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LCSCLIENTID    | LCS客户端标识   | 可选必选说明：必选参数 参数含义：该字段用于标识LCS客户端。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无                                                                                         |
| ALGOSWITCH     | 携带算法类型开关   | 可选必选说明：可选参数 参数含义：用于配置GMLC给APP返回定位结果时是否携带算法类型。当前只支持携带小站算法类型。 数据来源：全网规划 取值范围： DISABLE：开关去使能。ENABLE：携带算法开关使能。 默认值：无 配置原则：无                                                |
| DEFUSERTYPEPER | 周期定位用户缺省类型 | 可选必选说明：可选参数 参数含义：该参数用于配置周期定位用户的缺省类型。当LCS Client发起周期定位订阅请求但请求消息中未携带终端类型时，GMLC取本配置的缺省终端类型作为周期定位的终端类型进行后续的定位处理。 数据来源：本端规划 取值范围： NORMAL：普通用户。LOW_POWER：低功耗用户。 默认值：无 配置原则：无 |
| PERPOSRPTAMT   | 周期定位上报次数   | 可选必选说明：可选参数 参数含义：该参数用于配置GMLC给AMF发送周期定位请求消息时携带的周期定位上报次数。 数据来源：对端协商 取值范围：整数类型，取值范围为0~4800，默认值为0。 默认值：无 配置原则：无                                                            |
| HEARTBEATRPTSW | 心跳上报开关     | 可选必选说明：可选参数 参数含义：该参数用于配置周期定位时GMLC是否发送心跳消息给LCS Client。 数据来源：本端规划 取值范围： DISABLE：开关去使能。ENABLE：开关使能。 默认值：无 配置原则：无                                                          |

#### 使用实例

添加CLIENTID为“app1”，开关状态为“ENABLE”，用户类型为"NORMAL"，周期定位上报次数为“1”，上报心跳消息开关为“ENABLE”的LCS客户端策略：

```
ADD LCSCLIENTPLY: LCSCLIENTID="app1", ALGOSWITCH=ENABLE, DEFUSERTYPEPER=NORMAL, PERPOSRPTAMT=1, HEARTBEATRPTSW=ENABLE;
```
