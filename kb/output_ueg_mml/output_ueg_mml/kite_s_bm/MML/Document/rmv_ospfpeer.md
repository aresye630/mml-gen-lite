# 删除OSPF的NBMA网络邻居路由器配置（RMV OSPFPEER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于取消在NBMA网络上指定相邻路由器的IP地址。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称      | 参数说明                                                                   |
|:----------|:----------|:-----------------------------------------------------------------------|
| PROCID    | 进程号       | 可选必选说明：必选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 |
| IPADDRESS | 邻居路由器IP地址 | 可选必选说明：必选参数 参数含义：邻居路由器IP地址。 数据来源：对端协商 取值范围：IPv4地址类型。点分十进制格式。 默认值：无     |

#### 使用实例

取消在NBMA网络上指定相邻路由器的10.1.1.1的IP地址：

```
RMV OSPFPEER:PROCID=1,IPADDRESS="10.1.1.1";
```
