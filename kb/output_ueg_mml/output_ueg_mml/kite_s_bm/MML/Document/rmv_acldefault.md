# 删除缺省Acl绑定（RMV ACLDEFAULT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于删除默认的ACL。默认ACL是在APN下没有配置任何ACL时，如果APN需要使用ACL，则会使用默认ACL。

#### 注意事项

- 该命令执行后立即生效。
- 当需要删除某一默认ACL时需指明方向。
- 当需要删除所有默认ACL时，Driection字段应置为空。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                   |
|:----------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DIRECTION | 方向     | 可选必选说明：可选参数 参数含义：该参数用于指定默认ACL的方向。 数据来源：本端规划 取值范围：枚举类型。 UPIN：APN绑定ACL的方向为上行进系统。UPOUT：APN绑定ACL的方向为上行出系统。DOWNIN：APN绑定ACL的方向为下行进系统。DOWNOUT：APN绑定ACL的方向为下行出系统。 默认值：无 配置原则：无 |

#### 使用实例

- 假如运营商需要删除上行、进系统方向的默认ACL：

  ```
  RMV ACLDEFAULT:DIRECTION=UPIN;
  ```
- 假如运营商需要删除系统当前所有的默认ACL：

  ```
  RMV ACLDEFAULT:;
  ```
