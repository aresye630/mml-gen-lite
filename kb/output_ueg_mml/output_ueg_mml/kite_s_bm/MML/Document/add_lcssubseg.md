# 增加LCS用户号段（ADD LCSSUBSEG）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

该命令用于添加配置LCS用户标识的号段。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为4000。
- 当增加MSISDN号段时，配置SegStart和SegEnd的前导零会被忽略。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                                                                                                                             |
|:------------|:-----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SEGMENTNAME | MSISDN号段名称 | 可选必选说明：必选参数 参数含义：该字段用于指定MSISDN号段名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无                                                                                                                  |
| SEGMENTTYPE | MSISDN号段类型 | 可选必选说明：必选参数 参数含义：该参数用于指定MSISDN号段类型。 数据来源：全网规划 取值范围： MSISDN：MSISDN。MSISDNWILDCARD：MSISDN通配。 默认值：无 配置原则：无                                                                                                          |
| SEGSTART    | 起始号段       | 可选必选说明：条件必选参数 前提条件：该参数在“SEGMENTTYPE”配置为“MSISDN”时为必选参数。 参数含义：该参数用于指定起始号段。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～15，仅包含数字，必须小于等于SegEnd。 默认值：无 配置原则：SEGSTART必须小于等于SEGEND。                                                   |
| SEGEND      | 结束号段       | 可选必选说明：条件必选参数 前提条件：该参数在“SEGMENTTYPE”配置为“MSISDN”时为必选参数。 参数含义：该参数用于指定结束号段。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～15，仅包含数字，必须大于等于SegStart。 默认值：无 配置原则：SEGEND必须大于等于SEGSTART。                                                 |
| WILDCARDSEG | 号段通配       | 可选必选说明：条件必选参数 前提条件：该参数在“SEGMENTTYPE”配置为“MSISDNWILDCARD”时为必选参数。 参数含义：该参数用于指定号段通配。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～15。仅支持“*”、“?”和数字，至多包含一个"*"。 默认值：无 配置原则：“?”可代替一个字符，“*”可代替零个或多个字符。 WILDCARDSEG中最多只能携带一个“*”，最大长度为15。 |

#### 使用实例

添加号段名为"seg1"，号段类型为MSISDN，号段起始字符串为"123000"，号段终止字符串为"123999"的LCS用户标识号段：

```
ADD LCSSUBSEG: SEGMENTNAME="seg1", SEGMENTTYPE=MSISDN, SEGSTART="123000", SEGEND="123999";
```
