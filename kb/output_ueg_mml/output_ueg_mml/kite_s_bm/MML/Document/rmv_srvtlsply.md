# 删除TLS认证策略（RMV SRVTLSPLY）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、PGW-U**

该命令用于删除TLS认证策略。

#### 注意事项

该命令执行后对新数据流生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                     |
|:--------|:-------|:-----------------------------------------------------------------------------------------|
| PLYNAME | 策略名称   | 可选必选说明：必选参数 参数含义：该参数用于设置TLS认证策略描述。 数据来源：本端规划 取值范围：字符串类型，输入长度范围是1~31。不区分大小写。 默认值：无 配置原则：无 |

#### 使用实例

删除TLS认证策略：

```
RMV SRVTLSPLY: PLYNAME="ply1";
```
