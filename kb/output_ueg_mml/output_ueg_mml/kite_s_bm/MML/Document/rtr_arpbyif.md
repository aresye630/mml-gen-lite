# 根据接口清除ARP动态表项（RTR ARPBYIF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

本命令属于高危命令，操作不当会导致业务故障，请谨慎使用并联系华为技术支持协助操作。

该命令用于基于接口清除ARP动态表项。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                            |
|:------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------|
| IFNAME      | 接口名称   | 可选必选说明：必选参数 参数含义：该参数用于指定要重置ARP表项的接口。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。以太网接口名称由接口类型和接口编号组成。 默认值：无 配置原则：请使用LST INTERFACE命令查看可用接口。 |
| IPADDRVALUE | IP地址   | 可选必选说明：可选参数 参数含义：该参数用于指定要重置的具体表项。 数据来源：本端规划 取值范围：IPv4地址类型。IP地址0.0.0.0～255.255.255.255。 默认值：无                                    |

#### 使用实例

重置Ethernet64/0/5的动态表项：

```
RTR ARPBYIF:IFNAME="Ethernet64/0/5";
```
