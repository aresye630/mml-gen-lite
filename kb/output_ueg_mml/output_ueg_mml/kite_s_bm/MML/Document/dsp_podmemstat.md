# 查询pod内存信息（DSP PODMEMSTAT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询所有被资源管理器管理的pod或指定pod内存信息。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                              |
|:--------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
| PODTYPE | pod类型  | 可选必选说明：可选参数  参数含义：本参数用于指定pod类型。该值来自于DSP PODINFO返回结果中的Pod类型。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~100。  默认值：无  配置原则：  本命令不加参数可以查询所有支持的pod类型。            |
| PODID   | Pod ID | 可选必选说明：可选参数  参数含义：本参数用于指定Pod ID。该值来自于DSP PODINFO返回结果中的PODID去掉最后的IP地址。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~100。  默认值：无  配置原则：  本命令不加参数可以查询所有支持的pod ID。 |
| MEID    | 网元ID   | 可选必选说明：可选参数  参数含义：该参数用于指定网元来查询pod的内存信息。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~100。  默认值：无  配置原则：  本命令不加参数可以查询所有支持的网元ID。                                 |

## 使用实例

- 查询所有被资源管理器管理的Pod内存信息。

  ```
  %%DSP PODMEMSTAT:;%%
  RETCODE = 0  操作成功

  结果如下
  --------
  Pod类型   Pod ID                网元ID   内存使用量(MB)     内存使用率(%)      内存总量(MB)   内存使用率历史最大值(%)  告警上报阈值(%)    告警恢复阈值(%)  

  sfm-pod   sfm-pod-mkpjm          0         306              0.67              46014            1.70                   80               70
  sfm-pod   sfm-pod-q6h5f          0         261              1.20              21822            1.90                   80               70
  sfm-pod   sfm-pod-fnnmt          0         339              1.56              21822            1.88                   80               70
  (结果个数 = 3)
  ```
- 查询进程类型为sfm-pod的所有Pod内存信息。

  ```
  %%DSP PODMEMSTAT:PODTYPE="sfm-pod";%%
  RETCODE = 0  操作成功

  结果如下
  --------
  Pod类型   Pod ID                网元ID   内存使用量(MB)     内存使用率(%)      内存总量(MB)   内存使用率历史最大值(%)  告警上报阈值(%)  告警恢复阈值(%)

  sfm-pod   sfm-pod-mkpjm          0         306              0.67              46014            1.70                   80               70
  sfm-pod   sfm-pod-q6h5f          0         261              1.20              21822            1.90                   80               70
  sfm-pod   sfm-pod-fnnmt          0         339              1.56              21822            1.88                   80               70
  (结果个数 = 3)
  ```
- 查询Pod ID为sfm-pod-mkpjm的Pod内存信息。

  ```
  %%DSP PODMEMSTAT: PODID="sfm-pod-mkpjm";%%
  RETCODE = 0  操作成功

  结果如下
  ---------
                 Pod类型   =  sfm-pod
                  Pod ID   =  sfm-pod-mkpjm
                 网元 ID   =   0
           内存使用量(MB)  =  306
            内存使用率(%)  =  0.67
             内存总量(MB)  =  46014
  内存使用率历史最大值(%)  =  1.70
          告警上报阈值(%)  =  80
          告警恢复阈值(%)  =  70
  (结果个数 = 1)
  ```
- 查询Pod类型为sfm-pod，且Pod id为sfm-pod-mkpjm的Pod的内存信息。

  ```
  %%DSP PODMEMSTAT: PODTYPE="sfm-pod", PODID="sfm-pod-mkpjm";%%
  RETCODE = 0  操作成功

  结果如下
  --------
                 Pod类型   =  sfm-pod
                  Pod ID   =  sfm-pod-mkpjm
                 网元 ID   =   0
           内存使用量(MB)  =  306
            内存使用率(%)  =  0.67
             内存总量(MB)  =  46014
  内存使用率历史最大值(%)  =  1.70
          告警上报阈值(%)  =  80
          告警恢复阈值(%)  =  70
     
  (结果个数 = 1)
  ```

## 输出结果说明

| 输出项名称      | 输出项解释                                               |
|:-----------|:----------------------------------------------------|
| pod类型      | 本参数用于指定pod类型。该值来自于DSP PODINFO返回结果中的Pod类型。           |
| Pod ID     | 本参数用于指定Pod ID。该值来自于DSP PODINFO返回结果中的PODID去掉最后的IP地址。 |
| 网元ID       | 该参数用于指定网元来查询pod的内存信息。                               |
| 内存使用量(MB)  | 本参数用于指定内存使用量。                                       |
| 内存使用率(%)   | 本参数用于指定内存使用率。                                       |
| 内存总量(MB)   | 本参数用于指定内存总量。                                        |
| 最大内存使用率(%) | 本参数用于指定进程启动以来最大内存使用率。                               |
| 告警上报阈值     | 本参数用于指定告警上报阈值。                                      |
| 告警恢复阈值     | 本参数用于指定告警恢复阈值。                                      |
