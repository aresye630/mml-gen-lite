# 显示跟踪文件（DSP TRCFILE）

- 输出结果说明

#### 命令功能

该命令用于显示网元跟踪文件信息。创建上报方式为文件类型的跟踪任务，达到文件生成周期之后，可通过该命令获取跟踪文件信息。上报方式为消息上报类型的跟踪任务，通过该命令获取不到跟踪文件信息。上报类型和文件生成周期均可通过命令DSP TRCTASK获取。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| TRACETASKID     | 跟踪任务号  | 可选必选说明：可选参数 参数含义：跟踪任务ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967294。 默认值：无                                        |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

显示跟踪任务号为1的跟踪任务生成的跟踪文件信息，可通过如下命令显示：

```
DSP TRCFILE: TRACETASKID=1,SERVICEINSTANCE="vnfc";
```

```

```
