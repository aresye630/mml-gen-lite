# 查询5G LAN属性配置（LST NGLANATTR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询指定5G LAN组的属性配置。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                  |
|:-----------|:----------|:--------------------------------------------------------------------------------------|
| VNINSTANCE | 5G LAN组名称 | 可选必选说明：可选参数 参数含义：该参数用于指定5G LAN会话实例名称。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为18～37。 默认值：无 配置原则：无 |

#### 使用实例

查询指定5G LAN组总的MAC地址超限个数：

```
LST NGLANATTR: VNINSTANCE="a0000001-460-003-50";
```

```
%%LST NGLANATTR: VNINSTANCE="a0000001-460-003-50";%%
RETCODE = 0 操作成功

结果如下
--------

(结果个数 = 1)

---    END
```
