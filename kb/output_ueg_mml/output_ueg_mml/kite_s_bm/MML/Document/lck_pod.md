# 锁定/解锁POD（LCK POD）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

**须知** 

本命令属于高危命令，POD锁定后无法激活新用户，请及时解锁。

锁定POD，POD锁定后无法激活新用户。

#### 注意事项

- 该命令执行后立即生效。
- 此命令不导出。
- 当参数MULPDN为DISABLE，并且一直有多PDN用户激活时，基于POD去活可能有部分多PDN用户未被去活。如需去活全部去活，建议将MULPDN设置为ENABLE再执行去活命令。
- 只支持锁定spu-pod或isu-pod。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称                   | 参数说明                                                                                                                                                                             |
|:-------------|:-----------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PODNAME      | POD名称                  | 可选必选说明：必选参数 参数含义：POD名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：无                                                                                               |
| LOCKSWITCH   | 锁定POD开关                | 可选必选说明：必选参数 参数含义：该参数使能时，POD为锁定状态，该参数为不使能时，POD为解锁状态。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：无 配置原则：无                                                                     |
| MULPDN       | 多PDN接入开关               | 可选必选说明：条件可选参数 前提条件：该参数在“LOCKSWITCH”配置为“ENABLE”时为可选参数。 参数含义：该参数不使能时，允许多PDN接入，使能时，不允许多PDN接入。 数据来源：本端规划 取值范围：枚举类型。 DISABLE：不使能。ENABLE：使能。 默认值：DISABLE 配置原则：无                        |
| FULLMESHNGVN | FullMesh 5G LAN组会话接入开关 | 可选必选说明：条件可选参数 前提条件：该参数在“LOCKSWITCH”配置为“ENABLE”时为可选参数。 参数含义：该参数不使能时，允许FullMesh 5G LAN组会话接入，使能时，不允许FullMesh 5G LAN组会话接入。 数据来源：本端规划 取值范围： DISABLE：不使能。ENABLE：使能。 默认值：DISABLE 配置原则：无 |

#### 使用实例

锁定POD, 名称为ssgpod-0：

```
LCK POD: PODNAME="ssgpod-0", LOCKSWITCH=ENABLE, MULPDN=DISABLE,FULLMESHNGVN=DISABLE;
```
