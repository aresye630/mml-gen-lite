# 查询LCS软件参数指定比特位的值（LST LCSSOFTPARAOFBIT）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

该命令用于查询软件参数某比特位的值。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识          | 参数名称          | 参数说明                                                                                                                         |
|:--------------|:--------------|:-----------------------------------------------------------------------------------------------------------------------------|
| DT2           | 软参记录数据类型      | 可选必选说明：必选参数 参数含义：软件参数的数据类型。 数据来源：本端规划 取值范围：枚举类型。 默认值：无 配置原则： 配置BYTE表示需要设置字节类型软件参数。配置DWORD表示需要设置双字类型软件参数。                     |
| BYTENUM       | Byte索引        | 可选必选说明：条件必选参数 前提条件：该参数在“DT2”配置为“BYTE”时为必选参数。 参数含义：字节类型软件参数的索引。 数据来源：本端规划 取值范围：整数类型，取值范围为1～960。取值范围在1到960之间的整数。 默认值：无 配置原则：无  |
| BYTEPOSITION  | Byte软参BIT位位置  | 可选必选说明：条件必选参数 前提条件：该参数在“DT2”配置为“BYTE”时为必选参数。 参数含义：Byte软参指定的BIT位位置。 数据来源：本端规划 取值范围：整数类型，取值范围为1～8。 默认值：无 配置原则：无                |
| DWORDNUM      | DWord索引       | 可选必选说明：条件必选参数 前提条件：该参数在“DT2”配置为“DWORD”时为必选参数。 参数含义：双字类型软件参数的索引。 数据来源：本端规划 取值范围：整数类型，取值范围为1～120。取值范围在1到120之间的整数。 默认值：无 配置原则：无 |
| DWORDPOSITION | Dword软参BIT位位置 | 可选必选说明：条件必选参数 前提条件：该参数在“DT2”配置为“DWORD”时为必选参数。 参数含义：Dword软参指定的BIT位位置。 数据来源：本端规划 取值范围：整数类型，取值范围为1～32。 默认值：无 配置原则：无             |

#### 使用实例

查询当前参数索引为1的单字节类型软参的第一个比特位的值：

```
LST LCSSOFTPARAOFBIT: DT2=BYTE, BYTENUM=1, BYTEPOSITION=1;
```

```
RETCODE = 0  操作成功

结果如下
--------
  软参记录数据类型  =  BYTE
            软参号  =  1
     软参BIT位位置  =  1
软件参数比特位的值  =  0
(结果个数 = 1)
```
