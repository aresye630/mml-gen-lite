# 查询ApnImsAttr配置（LST APNIMSATTR）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：UPF**

命令用来查询APN的IMS属性信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                        |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------|
| APN    | APN名称  | 可选必选说明：可选参数 参数含义：该参数用于指定APN实例名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格以及特殊字符：“_”、“#”、“$”、“&”等。 默认值：无 配置原则：无 |

#### 使用实例

- 显示当前APN huawei.com的IMS属性信息：

  ```
  LST APNIMSATTR: APN="huawei.com";
  ```

  ```
  RETCODE = 0  操作成功。

  APN的IMS配置信息
  ----------------
           APN名称  =  huawei.com
           IMS开关  =  使能
  信令空口增强开关  =  使能
   (结果个数 = 1)
  ---    END
  ```
- 显示当前所有APN的IMS属性信息：

  ```
  LST APNIMSATTR:;
  ```

  ```
  RETCODE = 0  操作成功

  APN的IMS配置信息
  ----------------
  APN名称        IMS开关  

  testapn.com  使能         
  huawei.com     使能        
  (结果个数 = 2)

  ---    END
  ```
