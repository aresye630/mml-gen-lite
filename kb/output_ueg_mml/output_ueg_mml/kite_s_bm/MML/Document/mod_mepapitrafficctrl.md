# 修改MEP API流控配置（MOD MEPAPITRAFFICCTRL）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**须知** 

本命令属于高危命令，设置限流值过小可能导致部分业务请求被拒绝。

该命令用于修改MEP API流控配置。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识            | 参数名称      | 参数说明                                                                                             |
|:----------------|:----------|:-------------------------------------------------------------------------------------------------|
| TRAFFICCTRLNAME | API流控策略名称 | 可选必选说明：必选参数 参数含义：该参数用于配置流控策略名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：无                   |
| SERVICENAME     | 服务名称      | 可选必选说明：可选参数 参数含义：该参数用于指定服务名称。 数据来源：本端规划 取值范围： GMLC_EXEC_SVC：GMLC服务。 默认值：无 配置原则：无                 |
| APINAME         | API名称     | 可选必选说明：可选参数 参数含义：该参数用于指定API名称。 数据来源：本端规划 取值范围： ONE_SHOT_LOC：单次定位。PERIODIC_LOC：周期定位。 默认值：无 配置原则：无 |
| APIMETHOD       | API方法     | 可选必选说明：可选参数 参数含义：该参数用于指定API方法。 数据来源：本端规划 取值范围： POST：提交。DELETE：删除。GET：查询。 默认值：无 配置原则：无            |
| TRAFFICCTRLTHR  | 流控阈值（个/秒） | 可选必选说明：可选参数 参数含义：该参数用于配置流控阈值。 数据来源：本端规划 取值范围：整数类型，取值范围为0~1500，单位是个/秒。取值为0时不做流控。 默认值：无 配置原则：无     |

#### 使用实例

修改MEP API流控配置：

```
MOD MEPAPITRAFFICCTRL: TRAFFICCTRLNAME="1", SERVICENAME=GMLC_EXEC_SVC, APINAME=ONE_SHOT_LOC, APIMETHOD=POST, TRAFFICCTRLTHR=5;
```
