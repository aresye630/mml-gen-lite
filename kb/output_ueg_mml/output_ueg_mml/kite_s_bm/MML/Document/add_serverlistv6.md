# 增加IPv6服务器列表（ADD SERVERLISTV6）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于增加IPv6服务器列表。

#### 注意事项

- 该命令执行后30s生效。
- 系统最多支持配置2048条。
- 如果该服务器列表中已经存在该IP地址，则提示记录已经存在，否则添加一条IP到此服务器列表中。
- 如果需要配置访问控制白名单功能，请先配置该命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                             |
|:---------------|:---------|:-------------------------------------------------------------------------------------------------|
| SERVERLISTV6NM | 服务器列表名称  | 可选必选说明：必选参数 参数含义：该参数用于指定IPv6服务器列表名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写。 默认值：无 配置原则：无 |
| IPV6ADDR       | IPv6地址   | 可选必选说明：必选参数 参数含义：该参数用于指定IPv6地址。 数据来源：本端规划 取值范围：IPv6地址类型。 默认值：无 配置原则：无                            |
| MASKVALUE      | IPv6地址掩码 | 可选必选说明：必选参数 参数含义：该参数用于指定IPv6地址掩码。 数据来源：本端规划 取值范围：整数类型，取值范围为48～128。 默认值：无 配置原则：无                  |

#### 使用实例

增加名称为test01的IPv6服务器列表：

```
ADD SERVERLISTV6: SERVERLISTV6NM="test01", IPV6ADDR="fc00:0:0:0:0:0:0:1", MASKVALUE=48;
```
