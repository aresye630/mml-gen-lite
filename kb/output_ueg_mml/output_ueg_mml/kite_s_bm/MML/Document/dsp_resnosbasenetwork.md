# 查询NOS Base平面网络信息（DSP RESNOSBASENETWORK）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询NOS Base平面网络信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                     |
|:---------|:-------|:---------------------------------------------------------------------------------------------------------|
| RESOURCE | 资源名称   | 可选必选说明：可选参数 参数含义：该参数用于表示资源名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：请使用DSP RES查看资源名称。 |

#### 使用实例

查询“资源名称”为“OMU1”的NOS Base平面网络信息：

```
DSP RESNOSBASENETWORK: RESOURCE="OMU1";
```

