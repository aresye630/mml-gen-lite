# 配置位置定位参数（SET UPLCSPARA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

用来设置LCS的相关参数。

#### 注意事项

- 该命令最大记录数为1。
- 执行该命令后，LocIggTimeAlgo立即生效，重新发起的定位请求才会用到GnbIdLen/DefgNodeBType修改后的参数值。
- 小站忽略时间戳测量用户位置，建议将ADD/MOD LcsAlgoPara的LCS算法开关UTDOA\_AUTO\_TAE关闭。
- 执行SET UPLCSPARA命令时，需要至少输入一个参数；否则，命令执行失败。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   |   GNBIDLEN | DEFGNODEBTYPE   | LOCIGGTIMEALGO   |
|:-------|-----------:|:----------------|:-----------------|
| 初始值    |         24 | SMALL_CELL      | DISABLE          |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称            | 参数说明                                                                                                                                                   |
|:---------------|:----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
| GNBIDLEN       | gNB ID长度        | 可选必选说明：可选参数 参数含义：该参数用于配置NrCellID中gNB ID的长度。 数据来源：全网规划 取值范围：整数类型，取值范围为22~32。 默认值：无 配置原则：无                                                               |
| DEFGNODEBTYPE  | 缺省基站类型          | 可选必选说明：可选参数 参数含义：该参数用于配置LCS用户接入的基站缺省类型。当接入的基站未使用ADD LCSNRTYPE命令配置基站类型时，使用本参数作为基站的类型配置。 数据来源：本端规划 取值范围：小站/宏站。 SMALL_CELL：小站。MACRO_CELL：宏站。 默认值：无 配置原则：无 |
| LOCIGGTIMEALGO | 小站测量用户位置忽略时间戳开关 | 可选必选说明：可选参数 参数含义：该参数用于配置小站测量用户位置时是否忽略时间戳。 数据来源：全网规划 取值范围： DISABLE：开关去使能。ENABLE：开关使能。 默认值：无 配置原则：无                                                      |

#### 使用实例

配置GNODEBID的长度为22，基站缺省类型为小站，忽略小站测量用户位置时间戳：

```
SET UPLCSPARA: GNBIDLEN=22, DEFGNODEBTYPE=SMALL_CELL, LOCIGGTIMEALGO=ENABLE;
```
