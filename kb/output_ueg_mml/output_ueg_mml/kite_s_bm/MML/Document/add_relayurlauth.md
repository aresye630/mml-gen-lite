# 增加媒体中继URL鉴权配置（ADD RELAYURLAUTH）

- 命令功能

- 操作用户权限

#### 命令功能

**适用NF：UPF、PGW-U**

**须知** 

本命令属于高危命令，执行该命令后，会影响媒体中继防盗链校验功能。

该命令用于增加媒体中继URL鉴权配置。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为100。
- 当URLAUTHMETHOD为TYPED时，AUTHFIELDNAME需手动配置为x-signature，TIMESTAMPNAME需手动配置为x-expires。
- 当URLAUTHMETHOD为TYPED时，ALGORITHM仅支持配置为HMAC\_SHA1。HMAC\_SHA1也仅支持URLAUTHMETHOD为TYPED时配置。
- 鉴权算法MD5、HMAC\_SHA1属于不安全算法，建议优先使用SHA256算法。出于业务对接需要，必须使用MD5或HMAC\_SHA1算法进行URL鉴权时，需要告知客户或服务厂商存在的安全风险并达成一致。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

| URLAUTHMETHOD  | URL鉴权方法     | 可选必选说明：必选参数 参数含义：该参数用于指定URL鉴权方法。 数据来源：本端规划 取值范围：枚举类型。 TYPEA：鉴权方式A。TYPEB：鉴权方式B。TYPEC1：鉴权方式C1。TYPEC2：鉴权方式C2。TYPED：鉴权方式D。 默认值：无 配置原则：无                                                                                                |

#### 使用实例

新增媒体中继URL鉴权配置：

```
ADD RELAYURLAUTH: RELAYURLAUTHNM="urlauth", RELAYAUTHKEYNM="auth1", URLAUTHMETHOD=TYPEB, ALGORITHM=SHA256, TIMESTAMPFMT=DEFAULT, AUTHFAILACT=FORBIDDEN, DASHAUTHEXTSW=DISABLE;
```
