# 惯性运行/应急接入授权（ACT EMERGAUTHACCESS）

#### 命令功能

**适用NF：UPF**

执行ACT EMERGAUTHACCESS命令后，UPF不再拒绝从应急SMF申请接入的新用户，并停止主动去激活惯性运行/应急接入用户。

#### 注意事项

- 该命令执行后立即生效。
- 系统处于锁定状态，才能执行该命令。可以通过DSP EMERGAUTHSTATUS命令确认系统是否处于锁定状态。
- 执行该命令后，系统先切换到惯性运行/应急接入状态。
- 执行该命令后，如果大网SMF的N4链路恢复并且无应急接入用户，系统切换到备用状态。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

无。

#### 使用实例

恢复惯性运行/应急接入授权：

```
ACT EMERGAUTHACCESS:;
```
