# 查询负载均衡配置（DSP LBSRULE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：MPF**

该命令用于查询管理面动态下发的负载均衡规则。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                   |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APPNAME | 应用名称   | 可选必选说明：必选参数 参数含义：指定应用名称，可以通过DSP LBSRULE查出动态下发的指定appName下的负载均衡规则。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则：可以通过将DSP APPLICATION命令的RULENAME参数配置为LBS_RULE，可以查询所有已经动态下发负载均衡规则的appName。 |

#### 使用实例

查看指定的appName对应的负载均衡规则，appName为“appName1”：

```
DSP LBSRULE: APPNAME="appName1";
```


#### 输出结果说明

| 输出项名称         | 输出项解释                                         |
|:--------------|:----------------------------------------------|
| appName       | app实例名称。                                      |
| lbsRule       | 负载均衡规则类型，有轮询以及权重两种方式（当前版本仅支持轮询）。              |
| vip           | 虚地址信息，最多携带两个虚IP，分别为IPv4地址类型的虚IP和IPv6地址类型的虚IP。 |
| ipType        | IP地址类型，包括IPv4，IPv6。                           |
| ipAddress     | 虚地址IP。                                        |
| appInstances  | app实例信息。                                      |
| appInstanceIP | app实例IP。                                      |
| appInstanceId | app实例ID。                                      |
| weight        | app实例权重(当前版本不支持)。                             |
