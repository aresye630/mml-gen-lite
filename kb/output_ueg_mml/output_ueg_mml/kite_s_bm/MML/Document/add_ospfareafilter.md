# 创建区域过滤策略配置（ADD OSPFAREAFILTER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于配置对区域内的Type 3 LSA进行过滤。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为8016。
- 只有执行ADD OSPF配置了OSPF进程和ADD OSPFAREA配置了OSPF区域后才能使用此命令。
- 此命令仅在ABR上配置。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称              | 参数说明                                                                                                                                                                                                                                                                                          |
|:-------------|:------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PROCID       | OSPF进程号           | 可选必选说明：必选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 配置原则：OSPF进程必须已经存在。请使用LST OSPF命令查看可用的OSPF进程。                                                                                                                                                                            |
| AREAID       | 区域ID              | 可选必选说明：必选参数 参数含义：区域ID。 数据来源：对端协商 取值范围：IPv4地址类型。点分十进制格式。 默认值：无                                                                                                                                                                                                                                 |
| TOPONAME     | 拓扑标识              | 可选必选说明：必选参数 参数含义：拓扑标识。 数据来源：全网规划 取值范围：枚举类型。 base：基础类型。 默认值：无                                                                                                                                                                                                                                  |
| FILTERTYPE   | 过滤方向              | 可选必选说明：必选参数 参数含义：该参数用于指定过滤方向。 数据来源：本端规划 取值范围：枚举类型。 import：引入方向的过滤。export：发布方向的过滤。 默认值：无                                                                                                                                                                                                       |
| TYPE         | 过滤规则类型            | 可选必选说明：必选参数 参数含义：过滤规则类型。 数据来源：本端规划 取值范围：枚举类型。 acl_name：ACL名称。ip_prefix：IP前缀列表。route_policy：路由策略名。acl_num：ACL号。 默认值：无                                                                                                                                                                          |
| ACLNAMEORNUM | ACL名称或ACL号        | 可选必选说明：条件必选参数 前提条件：该参数在“TYPE”配置为“acl_name” 或 “acl_num”时为必选参数。 参数含义：该参数用于指定ACL规则组名称或是编号。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～32。 默认值：无 配置原则： 当过滤类型指定为acl_name或者acl_num时生效。配置时，ACL名称或ACL号实际下发由内部自动区分，不依照过滤类型。不支持空格，区分大小写。当输入ACL名称时以英文字母a～z或A～Z开始，可以是英文字母、数字、连字符“-”或下划线“_”的组合。当输入ACL号时，取值范围是2000~2999。 |
| IPPREFIX     | IP前缀过滤策略名称        | 可选必选说明：条件必选参数 前提条件：该参数在“TYPE”配置为“ip_prefix”时为必选参数。 参数含义：IP前缀过滤策略名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～169。 默认值：无 配置原则：不支持空格，区分大小写。                                                                                                                                                                |
| ROUTEPOLICY  | 路由策略名称            | 可选必选说明：条件必选参数 前提条件：该参数在“TYPE”配置为“route_policy”时为必选参数。 参数含义：路由策略名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～200。 默认值：无 配置原则：不支持空格，区分大小写。                                                                                                                                                                 |
| INCAGGRFLAG  | 包括ABR Summary LSA | 可选必选说明：条件可选参数 前提条件：该参数在“FILTERTYPE”配置为“import”时为可选参数。 参数含义：包括ABR Summary LSA。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：FALSE                                                                                                                                                             |

#### 使用实例

在进程1的区域0.0.0.1下配置出方向的类型为ip-prefix的过滤策略：

```
ADD OSPFAREAFILTER:PROCID=1,AREAID="0.0.0.1",TOPONAME=base,FILTERTYPE=export,TYPE=ip_prefix,IPPREFIX="ip-prefix";
```
