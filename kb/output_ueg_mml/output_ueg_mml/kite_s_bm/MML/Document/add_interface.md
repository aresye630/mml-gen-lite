# 增加接口（ADD INTERFACE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于创建逻辑接口并初始化该接口的相关配置，逻辑接口是指能够实现数据交换功能但物理上不存在、需要通过配置建立的接口，包括Loopback接口、NULL0接口等。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为65535。
- 该命令在版本升级过程中禁止执行。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称           | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|:--------------|:---------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IFNAME        | 接口名            | 可选必选说明：必选参数 参数含义：该参数用于指定接口名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。接口名称由接口类型+接口编号组成。接口编号是十进制自然数，当编号为0时填写为“0”，其他情况不得以“0”开头。 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| IFDESCR       | 接口描述           | 可选必选说明：可选参数 参数含义：该参数用于指定接口描述，可标识接口的用途。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～242。 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| IFADMINSTATUS | 管理状态           | 可选必选说明：可选参数 参数含义：该参数用于设置该接口的管理状态。 数据来源：本端规划 取值范围：枚举类型。 down：接口Down。up：接口Up。 默认值：无 配置原则：如果不设置该参数，Ethernet接口默认值为down，其他支持IFADMINSTATUS参数配置的接口默认值为up。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| IFMTU         | 接口最大传输单元（byte） | 可选必选说明：可选参数 参数含义：该参数用于设置该接口的最大传输单元。当用户需要进行设备间线性测试时，如10M的以太网接口线性转发指标是14880pps，即1秒钟内有14880个64字节的以太网帧被转发。此时，可设置接口的MTU值为46，提高接口的转发速率。 数据来源：本端规划 取值范围：整数类型，取值范围为46～9600，单位是字节。 默认值：无 配置原则： 如果不设置参数，接口MTU默认值为1500，Loopback口，Null0口，GigabitEthernet0/0/1口，Fabric-tunnel接口MTU值不允许修改。正常通信情况下，建议MTU的值不要随意更改，采用系统默认值1500。由于部分协议对最小报文有限制，如果配置过小会导致协议邻居无法建立。MTU优先级：配置MTU值>DHCP分配MTU值>默认配置MTU值，因此建议配置时，手工配置MTU值为规划值，避免MTU值被覆盖为非规划值，导致丢包。由于实际环境上不同网卡支持的MTU范围不一样，所以配置过大或者过小的MTU值可能会不成功，建议配置的MTU为1500~9000之间的值。IPv6报文入IPv4 GRE隧道场景，如果转发IPv4 GRE报文的接口MTU小于1312（1280+32），IPv6报文发送端学习的IPv6 Path MTU将小于1280，导致转发不通。本参数参与自动化配置，请在下发本MML命令前使用DSP OPSASSISTSTATE命令查询自动化配置维护助手autoscaling_autoconfig.py，确保当前设备是否在自动化配置过程中。如果当前正在自动化配置过程中，不要做本业务的增删改操作，否则最终生效的配置将不可预期。 |
| IFDF          | 接口不分片标记        | 可选必选说明：可选参数 参数含义：该参数用于设置该接口是否启用IP报文强制分片功能。IP报文头中包含一个用于指示是否允许对报文分片的标志位DF（Don't Fragment）。通常情况下，如果DF被置为1，则设备不能再对该报文分片。当IP报文长度大于接口的MTU时，例如由于协议封装导致长度增加，该报文将被丢弃并发送ICMP差错报文，从而引起数据丢失。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。TRUE：在出接口上启用IP报文强制分片功能。FALSE：在出接口上取消IP报文强制分片功能。 默认值：FALSE                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| IFSTATIENABLE | 接口统计使能标记       | 可选必选说明：可选参数 参数含义：该参数用于设置该接口统计使能标志。若用户需要查看接口接收、发送报文的统计计数时，必须先使能接口流量统计功能。 数据来源：本端规划 取值范围：枚举类型。 NONE：默认值。TRUE：使能。FALSE：不使能。 默认值：无 配置原则：如果不设置该参数，Ethernet、400GE、200GE、100GE、25GE、Eth-Trunk、Loopback、Fabric-Tunnel、GigabitEthernet0/0/1、NULL0这些类型接口默认一直开启功能，其他类型接口需要通过命令手动开启功能。                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| IFTRAPENABLE  | 接口Trap使能标记     | 可选必选说明：可选参数 参数含义：该参数用于设置是否使能接口Down的告警上报。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。FALSE：去使能接口Down告警上报。TRUE：使能接口Down告警上报。 默认值：无 配置原则：如果不设置该参数，支持IFTRAPENABLE参数配置的接口默认值为TRUE。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| IFSTATITVL    | 接口统计时间间隔（s）    | 可选必选说明：可选参数 参数含义：该参数用于设置接口的流量统计时间间隔。 数据来源：本端规划 取值范围：整数类型，取值范围为5～600，单位是秒。 默认值：无 配置原则：统计间隔必须是5的倍数。如果接口上配置了流量统计间隔，该接口实际生效的流量统计间隔为接口上配置值；如果不设置该参数，则该接口上实际生效的流量统计间隔则为全局流量统计间隔配置值。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |

#### 使用实例

新建Loopback接口LoopBack4，并将接口description设置为“huawei”：

```
ADD INTERFACE: IFNAME="LoopBack4", IFDESCR="huawei";
```
