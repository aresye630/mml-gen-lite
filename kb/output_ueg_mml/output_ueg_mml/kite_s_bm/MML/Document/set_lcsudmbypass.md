# 配置UDM Bypass开关参数（SET LCSUDMBYPASS）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

**须知** 

本命令属于高危命令，该操作只能在风筝L下执行，否则可能导致定位失败。

该命令用于配置UDM Bypass开关参数。

#### 注意事项

- 该命令最大记录数为1。
- 该命令修改后对所有新用户生效。
- 跳过UDM仅风筝L场景使用，风筝S/M不使用。
- 配置开启时，GMLC向AMF发起定位请求时仅会携带GPSI，AMF在1号多卡的情况下，仅会选择一个卡发起定位。
- 配置开启后周期定位流程中，GMLC在没有收到LMF的位置上报消息前，或收到LMF的位置上报消息无supi信息时，无法取消周期定位。此时若需要取消定位，请使用DEA LCSSESSION命令手动触发。
- 配置开启时，不支持基于IMSI创建跟踪。
- 执行SET LCSUDMBYPASS命令时，需要至少输入一个参数；否则，命令执行失败。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | UDMBYPASSSW   |
|:-------|:--------------|
| 初始值    | DISABLE       |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识        | 参数名称             | 参数说明                                                                                              |
|:------------|:-----------------|:--------------------------------------------------------------------------------------------------|
| UDMBYPASSSW | 定位流程UDM Bypass开关 | 可选必选说明：可选参数 参数含义：该参数用于设置定位流程是否跳过和UDM交互流程。 数据来源：全网规划 取值范围： DISABLE：开关去使能。ENABLE：开关使能。 默认值：无 配置原则：无 |

#### 使用实例

修改UDM Bypass开关参数：

```
SET LCSUDMBYPASS: UDMBYPASSSW=DISABLE;
```
