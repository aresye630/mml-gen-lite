# 删除MPF逻辑接口（RMV MPFLOGICINF）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF、MPF**

**须知** 

本命令属于高危命令，此操作会删除MPF逻辑接口，可能导致相关业务中断。

该命令用于删除指定的MPF逻辑接口。

#### 注意事项

- 该命令执行后立即生效。
- 删除的MPF逻辑接口需为系统中存在的逻辑接口，否则命令执行失败。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                            |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NAME   | 逻辑接口名称 | 可选必选说明：必选参数 参数含义：该参数用于配置逻辑接口名称，确保逻辑接口的唯一性。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 配置原则： 逻辑接口名称格式固定为：逻辑接口类型ISU组号/实例类型/逻辑接口号，如capif1/0/0、cap-lif1/0/0、leif1/0/0-leif1/0/9；第二个数字为实例类型；第三个数字为逻辑接口号，各逻辑接口类型有各自的配置范围。逻辑接口类型：capif，cap-lif，leif。ISU组号：1。ISU实例类型：0或1。0表示组级类型，1表示Instance级类型。capif，cap-lif，leif仅支持组级0。逻辑接口号：capif：0，cap-lif：0，leif：0-9。 |

#### 使用实例

- 删除逻辑接口capif1/0/0：

  ```
  RMV MPFLOGICINF: NAME="capif1/0/0";
  ```
- 删除逻辑接口cap-lif1/0/0：

  ```
  RMV MPFLOGICINF: NAME="cap-lif1/0/0";
  ```
- 删除逻辑接口leif1/0/0：

  ```
  RMV MPFLOGICINF: NAME="leif1/0/0";
  ```
