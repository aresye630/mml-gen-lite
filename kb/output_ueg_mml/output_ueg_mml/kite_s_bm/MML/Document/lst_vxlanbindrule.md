# 查询VXLAN隧道组绑定Rule（LST VXLANBINDRULE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

**适用NF：PGW-U、UPF**

该命令用于查询VXLAN隧道组与Rule的绑定关系。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                 |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RULENAME | 规则名称   | 可选必选说明：可选参数 参数含义：该参数用于设置规则名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则： 该参数必须已经通过ADD RULE命令配置。ADD RULE命令中POLICYTYPE为WORKER，WORKERNAME为traffic-fd。其他类型的规则不能绑定VXLAN组。 |

#### 使用实例

查询所有与Rule绑定的VXLAN隧道组：

```
LST VXLANBINDRULE:;
```

```
RETCODE = 0 操作成功。

VXLAN隧道绑定Rule信息
----------------------------------
规则名称 = rule
VXLAN组名称 = vxlangrp2
(结果个数 = 1)
--- END
```
