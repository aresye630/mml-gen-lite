# 查询组播定时器信息（DSP MCASTTIMER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示组播定时器信息。

#### 注意事项

该命令仅适用于非NP卡场景和NP卡非加速模式场景。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                  |
|:-------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------|
| COMPONENTYPE | 组件类型   | 可选必选说明：可选参数 参数含义：该参数用于表示组件类型。 数据来源：本端规划 取值范围：枚举类型。 PIMCORE：PIMCORE组件。DGMP：DGMP组件。PIMBSR：PIMBSR组件。PIMAGENT：PIMAGENT组件。MGM：MGM组件。 默认值：无 |
| PID          | 组件PID  | 可选必选说明：可选参数 参数含义：该参数用于表示组件PID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                                           |

#### 使用实例

查询组播定时器信息：

```
DSP MCASTTIMER:COMPONENTYPE=MGM;
```
