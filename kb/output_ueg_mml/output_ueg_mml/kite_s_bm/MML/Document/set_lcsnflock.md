# 配置LCS NF锁定开关（SET LCSNFLOCK）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：UPF**

**须知** 

本命令属于高危命令，该操作会改变NF的锁定状态，如果配置为锁定，会导致请求定位用户失败，是否继续？

该命令用于配置对指定的NF进行锁定操作。当NF锁定后，对于后续激活的用户定位失败，对于已经在线的用户无影响。缺省情况下NF未锁定。

#### 注意事项

- 该命令执行后立即生效。
- 该命令最大记录数为1。
- 该命令执行后只对新激活用户生效。
- 如果NF的锁定状态配置为锁定后，会导致请求定位的用户定位失败。
- 执行SET LCSNFLOCK命令时，需要至少输入一个参数；否则，命令执行失败。
- 该命令存在系统初始记录，参数的初始设置值如下表：

| 参数标识   | GMLCLOCKSWITCH   | LMFLOCKSWITCH   |
|:-------|:-----------------|:----------------|
| 初始值    | DISABLE          | DISABLE         |

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                           |
|:---------------|:---------|:-------------------------------------------------------------------------------------------------------------------------------|
| GMLCLOCKSWITCH | GMLC锁定开关 | 可选必选说明：可选参数 参数含义：该参数用于配置GMLC进行锁定操作。 数据来源：全网规划 取值范围： DISABLE：开关去使能。ENABLE：开关使能。 默认值：无 配置原则：该参数使能时，GMLC为锁定状态，该参数为不使能时，GMLC为解锁状态。 |
| LMFLOCKSWITCH  | LMF锁定开关  | 可选必选说明：可选参数 参数含义：该参数用于配置LMF进行锁定操作。 数据来源：全网规划 取值范围： DISABLE：开关去使能。ENABLE：开关使能。 默认值：无 配置原则：该参数使能时，LMF为锁定状态，该参数为不使能时，LMF为解锁状态。    |

#### 使用实例

修改LCS NF的锁定开关：

```
SET LCSNFLOCK: GMLCLOCKSWITCH=ENABLE, LMFLOCKSWITCH=ENABLE;
```
