# 修改OSPF运行的接口及所属区域（MOD OSPFNETWORK）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 参考信息

#### 命令功能

该命令用于在OSPF进程下的区域修改网段的配置。

#### 注意事项

- 该命令执行后立即生效。
- 只有配置了OSPF进程、OSPF区域和区域下的网段后才能使用该命令。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                           |
|:-------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------|
| PROCID       | 进程号    | 可选必选说明：必选参数 参数含义：OSPF进程号。 数据来源：本端规划 取值范围：整数类型，取值范围为1～4294967295。 默认值：无 配置原则：OSPF进程号必须已经存在。请使用LST OSPF命令查看可用的OSPF进程。            |
| AREAID       | 区域号    | 可选必选说明：必选参数 参数含义：OSPF区域号。 数据来源：对端协商 取值范围：IPv4地址类型。点分十进制格式。 默认值：无 配置原则：OSPF区域号必须已经存在。请使用LST OSPFAREA命令查看可用的OSPF区域。              |
| IPADDRESS    | IP地址   | 可选必选说明：必选参数 参数含义：接口所在的网段地址。 数据来源：全网规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无 配置原则：该参数与IP地址通配符一起指定需要启用OSPF协议的接口，接口IP地址落在该网段内，则接口运行OSPF协议。 |
| WILDCARDMASK | 反掩码    | 可选必选说明：必选参数 参数含义：IP地址的反掩码。 数据来源：全网规划 取值范围：IPv4地址类型。点分十进制格式。 默认值：无 配置原则：相当于将IP地址的掩码反转（0变1，1变0）。其中，“1”表示忽略IP地址中对应的位，“0”表示必须保留此位。 |
| DESCRIPTION  | 描述     | 可选必选说明：可选参数 参数含义：对网段进行描述信息。 数据来源：全网规划 取值范围：字符串类型，输入长度范围为1～80。 默认值：无 配置原则：输入单空格将删除该参数已有配置项。                                     |

#### 使用实例

在OSPF进程下1区域0.0.0.0下网段192.168.0.0/24增加描述：

```
MOD OSPFNETWORK: PROCID=1, AREAID="0.0.0.0",IPADDRESS="192.168.0.0",WILDCARDMASK="0.0.0.255",DESCRIPTION="HUAWEI";
```

#### 参考信息

该命令用于修改运行OSPF协议的接口所在的网段及所属的区域。如果接口的IP地址在命令指定的网段范围内，接口就会运行OSPF协议。接口可以是电口以太网或以太网Trunk接口。
