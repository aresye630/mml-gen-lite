# 增加Acl绑定关系（ADD ACLBINDAPN）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

**适用NF：SGW-U、PGW-U、UPF**

该命令用于增加对于APN，数据流四个方向的ACL绑定规则的配置。

#### 注意事项

- 系统最多支持配置40000条。
- 生效方式：若配置时指定一个时间段，以此来指示ACL生效时间；如果没有指定时间段，则表示ACL是立即生效的。
- 区分down-link in-bound、down-link out-bound、up-link in-bound、up-link out-bound四个方向的绑定。如果ACL下绑定的节点中动作不符合要求，则返回失败；如果ACL下未绑定ACL节点，则不做检查。（由于系统对生效的ACL需要建立快速搜索表，建议配置时1秒不超过1个）。
- 命令SET SGWACLFUNC用来控制入口APN在ACL下的功能对SGW是否生效，默认生效。
- SGW作为一个透传设备，不进行remark功能。
- ACL绑定到APN中或从APN中解绑时，需要等待30s后生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                                                                                              |
|:--------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| APN           | APN    | 可选必选说明：必选参数 参数含义：该参数用于指定APN实例名。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。只能由“-”、数字、大小写字母和“.”组成，不能以“.”开头且不能出现连续两个“.”。不支持空格及“_”、“#”、“$”、“&”、“%”、“^”、“（”、“）”、“，”、“/”、“;”、“:”、“””、“`”特殊字符，不区分大小写。 默认值：无 配置原则：无                                                                |
| DIRECTION     | 方向     | 可选必选说明：必选参数 参数含义：该参数用于指定APN绑定ACL的down-link in-bound、down-link out-bound、up-link in-bound、up-link out-bound四个方向。 数据来源：本端规划 取值范围：枚举类型。 UPIN：APN绑定ACL的方向为上行进系统。UPOUT：APN绑定ACL的方向为上行出系统。DOWNIN：APN绑定ACL的方向为下行进系统。DOWNOUT：APN绑定ACL的方向为下行出系统。 默认值：无 配置原则：按实际需要控制的方向来置值。 |
| ACLNAME       | ACL名称  | 可选必选说明：必选参数 参数含义：该参数用于指定ACL名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，不区分大小写。 默认值：无 配置原则： 当参数DIRECTION配置为UPIN、DOWNIN时，该参数只能配置ACL节点的动作为gate、remark的ACL名称。当参数DIRECTION配置为UPOUT、DOWNOUT时，该参数只能配置ACL节点的动作为redirect的ACL名称。                                             |
| TIMERANGENAME | 时间段名称  | 可选必选说明：可选参数 参数含义：该参数用于设置绑定关系生效时间。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。不支持空格，不区分大小写，以字母开头。 默认值：无 配置原则： 该参数使用ADD TIMERANGE命令配置生成。如果期望APN下绑定的ACL规则在指定的时间段生效则需要设置此参数；不配置此参数时，APN下绑定的ACL规则立即生效。                                                                           |

#### 使用实例

假如运营商需要在APN“testapn”的上行、进系统方向增加一个ACL的绑定关系：

```
ADD ACLBINDAPN:APN="testapn",DIRECTION=UPIN,ACLNAME="testacl1";
```
