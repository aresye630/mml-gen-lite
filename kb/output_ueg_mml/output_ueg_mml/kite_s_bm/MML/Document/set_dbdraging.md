# 设置CSDB容灾数据老化开关(SET DBDRAGING)

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于设置CSDB容灾数据老化开关。此开关打开，本端残留的异地数据定期删除。此开关关闭，本端不处理残留的异地数据。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组

#### 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                                                                  |
|:----------|:---------|:----------------------------------------------------------------------------------------------------------------------|
| LDRINSTID | 本端容灾实例ID | 可选必选说明：必选参数。 参数含义：该参数用于指定本端容灾实例ID，可以通过LST DRINST命令查询获取，如果该命令查询结果为空，可以再通过DSP DRINFO命令查询获取。 数据来源：全网规划 取值范围：0～63。 默认值：无。 |
| PDRINSTID | 对端容灾实例ID | 可选必选说明：必选参数。 参数含义：该参数用于指定对端容灾实例ID，可以通过LST DRCOMM命令查询获取，如果该命令查询结果为空，可以再通过DSP DRINFO命令查询获取。 数据来源：全网规划 取值范围：0~63。 默认值：无。 |
| SWITCH    | 容灾老化开关   | 可选必选说明：必选参数。 参数含义：该参数用于开启或关闭老化开关。 数据来源：本端规划 取值范围：“CLOSE_DR_AGING”：关闭容灾老化功能“OPEN_DR_AGING”：开启容灾老化功能 默认值：无。             |

#### 使用实例

打开“本端容灾实例ID”为“0”，“对端容灾实例ID”为“1”的容灾老化开关：

```
SET DBDRAGING: LDRINSTID=0, PDRINSTID=1, SWITCH=OPEN_DR_AGING;
```
