# 删除转移配额信息（RMV PTSFQUOTA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于删除用户的转移配额信息。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                      |
|:--------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 标识一条用户转移配额信息数据记录的关键字段之一，用于指定需要删除哪个用户的配额转移信息。 取值范围：长度不超过255的字符串。 默认值：无。                                                                                                                    |
| QTANAME       | 配额名称   | 标识一条用户转移配额信息数据记录的关键字段之一，用于指定需要删除哪个转移配额的信息。 取值范围：长度不超过32的字符串。 默认值：无。                                                                                                                       |
| TRANSTIME     | 转移时间   | 标识一条用户转移配额信息数据记录的关键字段之一，用于指定需要删除在哪个时间进行配额转移的数据记录。可以通过执行LST PTSFQUOTA命令查询。 如果不输入该参数，会将该配额的所有配额转移记录删除。 取值范围：19700101000000～20371231235959，表示1970年01月01日00:00:00至2037年12月31日23:59:59。 默认值：无。 |

## 使用实例

1. 删除“用户标识”为“46010381014\*\*\*\*”，“配额名称”为“Quota\_01”的所有配额转移记录：

   `RMV PTSFQUOTA: USRIDENTIFIER="46010381014****", QTANAME="Quota_01";`
2. 删除“用户标识”为“46010381014\*\*\*\*”，“配额名称”为“Quota\_01”，“转移时间”为“2015&02&11&15&11&34”的配额转移记录：

   `RMV PTSFQUOTA: USRIDENTIFIER="46010381014****", QTANAME="Quota_01";TRANSTIME=2015&02&11&15&11&34;`

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释        | 原因分析                                                                            | 处理建议                                          |
|------:|:-------------|:--------------------------------------------------------------------------------|:----------------------------------------------|
|  1151 | 启动TPS控制      | 在通过SET PGWTPSCTRL命令设置的上报周期内，该操作员执行的命令条数超过了其上限值。操作员的上限在PGW Web LMT上的ADD OPR命令中设置 | 在下一个控制周期即可自动解控。控制周期可通过LST PGWTPSCTRL命令查询。     |
| 12302 | 用户不存在        | 输入的指定的用户在系统中不存在。                                                                | 检查输入的用户标识是否正确，重新执行本命令。                        |
| 12303 | 配额不存在        | 输入的要删除的配额在系统中不存在。                                                               | 执行LST PQUOTA命令查询用户的配额信息，选择要删除的配额转移记录，重新执行本命令。 |
| 90483 | 指定的转移配额记录不存在 | 输入的配额没有进行配额转移操作。                                                                | 返回该错误码说明输入的要删除的配额没有进行过配额转移操作。                 |
| 90394 | 虚拟配额不支持该操作   | 输入的指定配额是虚拟配额。                                                                   | 执行LST PQUOTA命令查询用户的配额信息，输入非虚拟配额名称，重新执行本命令。    |
