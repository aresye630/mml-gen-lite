# 修改签约套餐信息（MOD PSRVPKG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于对用户签约某个套餐的签约信息进行修改或调整，包括订购时间、生效时间、截止时间、漫游类型和联系方式等。

## 注意事项

- 修改签约套餐的信息，可能会导致用户签约其他套餐失败，或者影响用户使用套餐的时间，请操作员在执行该操作之前仔细确认任务的可行性。
- 套餐订购时间可晚于系统当前时间。
- 套餐生效时间与订购时间之间没有限制。
- 套餐截止时间需晚于套餐订购时间和生效时间，且晚于系统当前时间。
- 若用户的“付费类型”是“Prepaid”，且套餐中业务关联的帐户或配额的“结帐周期模式”是“自然月”，如果修改用户签约信息的“生效时间”，用户帐户或配额的“Next Reset Date Time”不变，但在手动复位或到达复位时间之后，会根据修改后的签约信息的“生效时间”重新计算。
- 当配额累计方式配置为“剩余额处理方式”中的“有效期累积”时，若执行**MOD PSRVPKG**/**MOD PSRV**命令修改用户签约套餐/业务的“生效时间”或“截止时间”，则会将该业务关联配额的上周期剩余累积配额清空。

## 参数说明

| 参数标识                | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
|:--------------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER       | 用户标识   | 标识用户签约信息的关键字段之一（其取值不能被修改），用于指定需要修改哪个用户的签约信息。 取值范围：长度不超过255的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| SRVPKGNAME          | 套餐     | 标识用户签约信息关键字段之一（其取值不能被修改），用于指定需要修改用户的哪个套餐。 取值范围：长度不超过32的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| SRVPKGSUBSCRIBEDATE | 订购时间   | 表示用户订购套餐的时间，时间格式为YYYY&MM&DD&HH&MM&SS。 取值范围：可通过控件配置时间。 默认值：无。  说明： 手动输入参数值“-1”：表示清除SRVPKGSUBSCRIBEDATE属性。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| SRVPKGSTARTDATETIME | 生效时间   | 表示用户订购套餐的生效时间，时间格式为YYYY&MM&DD&HH&MM&SS。 取值范围：可通过控件配置时间。 默认值：无。  说明： 手动输入参数值“-1”：表示清除SRVPKGSTARTDATETIME属性。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| SRVPKGENDDATETIME   | 截止时间   | 表示用户所订购套餐的失效时间，时间格式为YYYY&MM&DD&HH&MM&SS，当系统时间等于截止时间后，用户不能使用该套餐。 取值范围：可通过控件配置时间。 默认值：无。  说明： 手动输入参数值“-1”：表示清除SRVPKGENDDATETIME属性。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| SRVPKGROAMINGTYPE   | 漫游类型   | 表示用户签约套餐的漫游类型，用于判断套餐与套餐间的生效时间与截止时间的区间是否有重复。 取值范围：“NULL”：表示签约的套餐不是本地、漫游类型。“Local”：表示签约的套餐为本地类型。“Roaming”：表示签约的套餐为漫游类型。 默认值：无。  说明： 用户同时签约两个或以上的漫游或者本地类型的业套餐时，需要判断生效时间与截止时间的区间是否有重复，有重复则新订购的套餐失败。若签约套餐的漫游类型既不是漫游也不是本地，则生效时间与截止时间的区间不做限制。若签约套餐的生效时间和截止时间没有配置，则不需判断生效时间与截止时间的区间是否有重复。用户订购套餐对于时间区间重复，针对主、从用户特性，不做限制，即主、从用户都订购了同一个套餐，生效时间与截止时间以自己的为准。 下面以“漫游类型”为“漫游”举例： 用户没有订购漫游类型的套餐，现在需要新订购漫游类型的套餐，则不受约束。用户已订购了漫游类型的套餐，现在需要新订购漫游类型的套餐。新订购套餐时，必须保证新订购套餐的“生效时间”和“截止时间”与所有已订购的套餐的“生效时间”和“截止时间”时间之间没有交叉。若存在新订购套餐“生效时间”为空，则必须保证其“截止时间”与原订购套餐的“生效时间”和“截止时间”之间没有交叉。若存在新订购套餐“截止时间”为空，则必须保证其“生效时间”与原订购套餐的“生效时间”和“截止时间”之间没有交叉。若存在已订购套餐的“生效时间”和“截止时间”均为空的情况，则新订购套餐不受此订购关系的约束。 手动输入参数值“-1”：表示清除SRVPKGROAMINGTYPE属性。 |
| SRVPKGCONTACTMETHOD | 联系方式   | 用于指定用户使用该套餐时的通知消息方式。 取值范围： “SMS”：表示以短信方式发送用户通知消息。“E-Mail”：表示以电子邮件方式发送用户通知消息。“SMS&E-Mail”：表示以短信和电子邮件方式发送用户通知消息。“None”：表示用户通知消息方式以开户（ADD PSUB）命令中设置的为准。 默认值：无。  说明： 联系方式也能在开户（ADD PSUB）命令中设置，当该命令设置的联系方式为“SMS”、“E-Mail”或“SMS&E-Mail”时，联系方式以本命令设置的为准。                                                                                                                                                                                                                                                                                                                                                                                                                                                  |

## 使用实例

修改签约套餐信息：“用户标识”为“46010381014\*\*\*\*”，“套餐”为“Volume\_ServPkg”，“订购时间”为“2010&11&23&16&05&49”,“生效时间”为“2010&11&24&16&05&50”，“截止时间”为“2010&12&01&00&00&00”，“漫游类型”为“Local”，“联系方式”为“SMS”：

```
MOD PSRVPKG: USRIDENTIFIER="46010381014****", SRVPKGNAME="Volume_ServPkg", SRVPKGSUBSCRIBEDATE=2010&11&23&16&05&49, SRVPKGSTARTDATETIME=2010&11&24&16&05&50, SRVPKGENDDATETIME=2010&12&01&00&00&00, SRVPKGROAMINGTYPE=Local, SRVPKGCONTACTMETHOD=SMS;
```
