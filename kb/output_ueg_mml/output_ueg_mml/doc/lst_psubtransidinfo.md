# 查询用户TransactionID信息（LST PSUBTRANSIDINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询用户的TransactionID记录信息。

## 注意事项

每个用户最多保存5条TransactionID记录信息。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                            |
|:--------------|:-------|:----------------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 用于指定系统需要按照哪个用户标识来查询用户的TransactionID信息。取值范围：长度不超过255的字符串。 默认值：无。 |

## 使用实例

查询用户TransactionID信息：“用户标识”为“user1”：

```
LST PSUBTRANSIDINFO: USRIDENTIFIER="user1";
```

## 输出结果说明

| 输出项名称          | 输出项解释                                                                                                                             |
|:---------------|:----------------------------------------------------------------------------------------------------------------------------------|
| Subscriber ID  | 表示需要查询TransactionID信息的用户标识。取值范围：长度不超过255的字符串。                                                                                     |
| Transaction ID | 表示用户的TransactionID。取值范围：长度不超过32的字符串。                                                                                              |
| TimeStamp      | 表示该条记录的时间戳。 取值范围： NULL1970-01-01 00:00:00 000～2037-12-31 23:59:59 999：表示1970年01月01日00时00分00秒000毫秒到2037年12月31日23时59分59秒999毫秒之间的时间。 |
