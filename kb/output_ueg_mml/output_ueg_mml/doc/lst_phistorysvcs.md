# 查询用户历史签约（LST PHISTORYSVCS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询指定用户的历史签约数据。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                |
|:--------------|:-------|:----------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 用于指示系统按照哪个用户标识进行查询用户历史签约数据。 取值范围：不超过255的字符串。 默认值：无。 |

## 使用实例

查询“用户标识”为“460975451002001”的历史签约数据：

```
LST PHISTORYSVCS: USRIDENTIFIER="460975451002001";
```

输出结果如下：


## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息，返回结果如表1所示。

| 输出项名称                     | 输出项解释                                                       |
|:--------------------------|:------------------------------------------------------------|
| Service Name              | 用户的业务名称。                                                    |
| Record Insert TimeStamp   | 用户的业务记录插入时间。                                                |
| History Subscription Info | 用户的历史签约信息，有两种结果显示： 显示为空：是由于该用户虽然存在，但是未签约。 显示不为空：内容为运营商定制字段。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释   | 原因分析                               | 处理建议                                         |
|------:|:--------|:-----------------------------------|:---------------------------------------------|
|     0 | 操作成功    | 用户存在，但历史签约表没有记录。原因为：该用户虽然存在，但是未签约。 | 该情况为系统正常返回结果，无需进一步处理。                        |
| 12302 | 用户不存在   | 输入的用户在系统中不存在。                      | 执行LST PSUB命令查询用户信息，输入系统中查询出来的“用户标识”，重新执行本命令。 |
