# 复位帐户信息（RST PACCOUNT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于复位用户帐户的信息，将用户帐户剩余额置为帐户初始值，用户帐户消耗额置为零，用户帐户状态置为初始状态。

## 注意事项

- 复位帐户时，若帐户剩余额处理方式为累积复位，那么帐户剩余额的值是原帐户剩余额的值与帐户初始值之和，若帐户剩余额处理方式为清零复位，那么帐户剩余额的值为帐户初始值。
- 帐户所属用户的所有通知抑制记录将会被清除；如果该用户为主用户，其从用户的所有通知抑制记录也会被清除。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                            |
|:--------------|:-------|:------------------------------------------------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 标识一条用户信息数据记录的关键字段，用于指定需要复位哪一个用户的帐户信息。 取值范围：长度不超过255的字符串。 默认值：无。                                 |
| ACTNAME       | 帐户名称   | 标识一条用户帐户信息数据记录的关键字段，用于指定需要复位的用户帐户。 帐户名称必须是已存在的帐户且该帐户需要在UPCF Web UI上配置。 取值范围：长度不超过32的字符串。 默认值：无。 |

## 使用实例

复位帐户信息：“用户标识”为“46010381014\*\*\*\*”，“帐户名称”为“Bill\_001”：

```
RST PACCOUNT: USRIDENTIFIER="46010381014****", ACTNAME="Bill_001";
```
