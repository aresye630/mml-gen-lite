# 业务充值（RECHRG PSRV）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于为用户签约的业务充值。一个业务可以关联多个配额，业务充值可能充值多个配额；而充值配额就只是充值单一个配额。

## 注意事项

- 业务充值时，该用户此业务配额相关的通知抑制记录将会被清除；如果该用户下存在从用户，其从用户除了虚拟配额通知抑制记录不会被清除，其他与此配额相关的所有通知抑制记录都会被清除。
- 如果业务只签约了Sy类型的配额，则无法通过本命令为该业务充值。
- 如果业务只携带了在线时长或者时长类型的配额，则通过本命令为该业务充值时，配额的累计范围不能为会话累计。
- 如果业务关联了UPCC Dynamic类型的配额，则无法通过本命令为该业务充值。
- 不支持对转移配额进行充值操作。当充值的业务下的基础配额存在转移配额时，不涉及对转移配额的处理。
- 被充值的业务可以关联多个配额，但只能关联1个Provisioning或UPCC类型的配额。
- 业务充值与配额充值的区别：一个业务可以关联多个配额，业务充值可能充值多个配额；而配额充值就只是充值单一个配额。
- 如果配额关联“重复订购方式”为“多配额记录重复订购”的业务，则该配额无法通过本命令充值。
- 如果配额关联“M2M共享业务”为“Yes”的业务，则该配额无法通过本命令充值。

## 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:---------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER  | 用户标识   | 标识一条用户信息数据记录，用于指定需要充值哪一个用户的配额信息。 取值范围：长度不超过255的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| SRVNAME        | 业务名称   | 标识用户签约信息的关键字段之一，用于指定给用户的哪一个业务下所关联的唯一的可充值配额进行充值。 业务名称必须是已存在的业务且该业务需要在UPCF Web UI上配置。 取值范围：长度不超过64的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| QTACLASS       | 配额类型   | 用于指定配额类型。 取值范围：“Volume”：表示按照用户使用业务产生的流量进行设置。“OnlineDuration”：表示按照用户使用业务的在线时长进行设置。“Duration”：表示按照用户使用业务的时长进行设置。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| RECHARGEDVALUE | 充值额度   | 表示要充值的配额大小，单位为KB或秒。 取值范围：0～4294967294。 默认值：无。  说明： 流量类型的配额使用“KB”为单位，在线时长和时长类型的配额使用“秒”为单位。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| REALTIMEFLAG   | 实时模式   | 用于控制是否按照实时模式处理。 取值范围： “False”：按照非实时模式处理。“True”：按照实时模式处理。 默认值：False。  说明： 实时模式是指基于用户实际使用量的数据操作，这需要UPCF下发RAR消息要求PCEF立即上报使用量。在实时模式下营帐命令与更新用户使用量是串行执行的，即UPCF处理营帐命令前，先下发RAR消息要求PCEF立即上报使用量，PCEF上报使用量后，才处理充值/修改/查询配额的操作。实时模式设置生效的前提是：在“USCDB MML命令”网元下通过LST NOTIFYCFG查询“SYNCHROSWITCH”参数取值为“SYNC”，且“REMOTEID”的取值与LST PSYSPARA命令中“SyncRemoteID”参数保持一致。非实时模式是指基于本地数据库中用户数据的数据操作，不需要UPCF下发RAR消息要求PCEF立即上报使用量。只有在线的普通用户支持实时模式，主用户、从用户、组用户和组成员都不支持实时模式。以下配额不支持按照实时模式处理：“配额管理归属”为“Sy”或“Pre-Sy”的配额“配额类型”为“在线时长”或“时长”的配额 批操作的命令是并行处理的，同一个用户可能会有多个并行处理的命令。在实时模式下，如果某个用户的前一个命令没有处理完成，后面的命令会直接返回错误，指示本次命令不能执行。N7接口暂不支持该参数。 |

## 使用实例

业务充值：“用户标识”为“46010381014\*\*\*\*”，“业务名称”为“Volume\_5M”，“充值额度”为“50”，“配额类型”为“Volume”：

```
RECHRG PSRV: USRIDENTIFIER="46010381014****", SRVNAME="Volume_5M", RECHARGEDVALUE=50, QTACLASS=Volume;
```
