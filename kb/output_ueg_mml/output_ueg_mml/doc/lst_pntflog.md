# 查询用户通知日志（LST PNTFLOG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询用户的通知日志信息。

## 注意事项

当对指定用户进行如下操作时，该用户的历史通知日志将被清除。

- 业务充值
- 配额修改
- 配额清除
- 配额复位
- 帐户修改
- 帐户清除
- 帐户复位
- 自定义阈值修改

历史通知日志清除的范围由PGW软件参数“PreciseDelete”控制。

- 当该软参值为1时，在签约、重复签约、去签约及过期业务处理场景，可根据业务ID删除短信抑制记录；在配额充值、复位、清零、修改场景，可根据“唯一键”选择配额对象的属性删除短信抑制记录。
- 当该软参值为0时，清除用户所有的历史通知日志。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                 |
|:--------------|:-------|:-----------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 用于指示系统需要按照哪个用户标识来查询用户通知日志。 取值范围：长度不超过255的字符串。 默认值：无。 |

## 使用实例

查询用户通知日志：“用户标识”为“46010381014\*\*\*\*”：

```
LST PNTFLOG: USRIDENTIFIER="46010381014****";
```

输出结果如下：

```
%%LST PNTFLOG: USRIDENTIFIER="46010381014****";%%
RETCODE = 0 Operation succeeded

Notify Type     Title                Send Time             Result      Generate Time         Link ID    Service Name    Quota Name
SMS             equipment_template   2015-01-16 11:27:24   Failure     2015-01-16 11:04:21   Default    FUP_Service     FUP_Quota

Total count = 1

There is together 1 report

---    END
```

## 输出结果说明

| 输出项名称         | 输出项解释                                                                                                                                                                                                                                                                                 |
|:--------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Notify Type   | 消息的通知类型。 取值范围：SMS：表示手机短信。Email：表示Email邮件。SOAP：表示基于SOAP协议的通知。Third SOAP：表示第三方SOAP订阅通知。                                                                                                                                                                                                 |
| Title         | 通知信息的标题。 取值范围：长度为1～96字节的字符串。                                                                                                                                                                                                                                                          |
| Send Time     | 消息通知的发送时间。 取值范围： 1970-01-01 00:00:00～2037-12-31 23:59:59：表示1970年01月01日00时00分00秒到2037年12月31日23时59分59秒之间的时间。                                                                                                                                                                            |
| Result        | 信息发送结果。 取值范围：“Sending”：表示正在发送中。有两种情况：首次发送，还未发出去。首次发送失败，等待重发。 “Success”：表示通知已发送成功。“Failure”：表示通知发送时由于通知链路问题、内容不符合对端要求等原因发送失败。包括但不限于以下场景：首次发送失败，不会重发。重发达到最大重发次数，还是发送失败。 “Overdue”: 表示已过期，不再发送。即当VRM_NTFOVERDUEMODE（通知过期处理模式）非“0”时，满足以下任一条件：超出通知模板“发送时间段”。待发通知，超过待发通知有效期。重发通知，超过重发通知有效期。 |
| Generate Time | 通知生成时间。 取值范围： 1970-01-01 00:00:00～2037-12-31 23:59:59：表示1970年01月01日00时00分00秒到2037年12月31日23时59分59秒之间的时间。                                                                                                                                                                               |
| Link ID       | 表示发送通知的链路ID。 取值范围：4～60000或者Default。4～60000，与在UPCF WebUI上配置通知模板时配置的链路ID一致。Default，表示UPCF WebUI上配置通知模板时未指定SOAP服务器。                                                                                                                                                                      |
| Service Name  | 表示触发通知的业务名称。 取值范围：长度不超过64的字符串。                                                                                                                                                                                                                                                        |
| Quota Name    | 表示触发通知的配额名称。 取值范围：长度不超过32的字符串。                                                                                                                                                                                                                                                        |
