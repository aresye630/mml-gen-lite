# 修改组成员（MOD PGRPMBR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加、修改和删除组成员的共享配额信息，包括共享配额名称、总量和余额。

## 注意事项

- 增加组成员的共享配额时，输入的配额名称必须已被组用户签约。
- 支持使用组成员的第二标识修改组成员的共享配额信息。
- 该命令中涉及到的配额名称和总量、余额信息仅限于基础配额信息。
- 如果组共享业务为多配额实例组业务：
  - 修改组成员用户共享配额时，分配给组成员用户的配额为虚拟配额，且虚拟配额总量可以小于等于或大于组用户配额总量。
  - 修改组成员用户的虚拟配额总量或者余额，导致配额状态由大变小时，系统删除虚拟配额的通知抑制记录，不删除共享配额的通知抑制记录。
- 如果组共享业务不是多配额实例组业务：
  - 修改组成员用户共享配额时，设定的共享配额总量必须小于等于组用户的配额总量。
  - 修改组成员用户的虚拟配额总量或者余额，导致配额状态由大变小时，此用户该配额相关的所有通知抑制记录都会被清除。
- 如果成员用户只属于1个组，那么该成员用户的虚拟配额总数不能超过“MaxGrpSrvNumPerGrpSub”取值；如果成员用户属于2个组，那么该成员用户的虚拟配额总数不能超过20个；如果成员用户属于2个以上组，那么该成员用户的虚拟配额总数不能超过25个。

## 参数说明

| 参数标识                 | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                   |
|:---------------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER        | 成员用户标识 | 用于指定对哪个组成员的共享配额信息进行修改。 取值范围：长度不超过255的字符串。 默认值：无。  说明： 该参数必须先由ADD PSUB命令定义，然后才能在此处索引。                                                                                                                                                                                                                                                   |
| ENOPERATIONTYPE      | 操作类型   | 用于指定对组成员的共享配额的操作类型。 取值范围： “Add”：表示增加一个共享配额。“Modify”：表示修改一个已经存在的共享配额。“Delete”：表示删除一个已经存在的共享配额。 默认值：Add。  说明： “配额管理归属”是“Pre-Sy”类型的配额不支持“Modify”操作。“Add”操作：同一个配额只允许配置一条虚拟配额记录；如果不同的组有相同的组配额，那么不允许重复添加相同配额的虚拟配额记录。                                                                                                                         |
| GRPQUOTANAME         | 配额名称   | 用于指定组成员共享的配额名称。 取值范围：长度不超过32的字符串。 默认值：无。                                                                                                                                                                                                                                                                                               |
| GRPSHAREQUOTAVALUE   | 总量     | 用于指定组用户分配给组成员的共享配额大小。 取值范围：1～4294967294。 单位：KB。 默认值：无。  说明： 当“ENOPERATIONTYPE”参数为“Add”时，如果“GRPQUOTANAME”参数设置的配额名称对应配额的“配额管理归属”是“Pre-Sy”，则不需要设置此参数。当“ENOPERATIONTYPE”参数为“Add”时，如果“GRPQUOTANAME”参数设置了非“Pre-Sy”的“配额管理归属”的配额名称，则必须设置此参数。该值必须小于等于组用户的配额总量。当配额属性“组配额分配方式”取值为“实际分配”时：若修改后的值大于原先的取值，则差值从组配额的余额中扣减。若修改后的值小于原先的取值，则差值增加到组配额的余额中。 |
| GRPSHAREQUOTABALANCE | 余额     | 用于指定组成员的剩余配额大小。 取值范围：0～4294967294。 单位：KB。 默认值：无。  说明： 当“ENOPERATIONTYPE”参数为“Add”时，如果“GRPQUOTANAME”参数设置的配额名称对应配额的“配额管理归属”是“Pre-Sy”，则不需要设置此参数。此参数不指定时，余额等于总量。                                                                                                                                                                            |
| GRPIDENTIFIER        | 组用户标识  | 用于指定需要修改的组成员的组标识。 取值范围：长度不超过255的字符串。 默认值：无。  说明： 该参数必须先由ADD PSUB命令定义，然后才能在此处索引。如果成员用户只属于一个组，那么此参数为可选参数，若携带则必须和所属组用户标识一致；如果用户已经属于多个组，那么此参数为必选参数，且必须是用户所属组的其中一个组用户标识。                                                                                                                                                                    |

## 使用实例

1. 修改组成员的共享配额信息，“成员用户标识”为“46010381014\*\*\*\*”，“操作类型”为“Modify”，“配额名称”为“Q1”，“总量”为“50”：

   ```
   MOD PGRPMBR: USRIDENTIFIER="46010381014****", ENOPERATIONTYPE=Modify, GRPQUOTANAME="Q1", GRPSHAREQUOTAVALUE=50;
   ```
2. 增加组成员的共享配额信息，“成员用户标识”为“46010381014\*\*\*\*”，“操作类型”为“Add”，“配额名称”为“Q1”，“总量”为“50”：

   ```
   MOD PGRPMBR: USRIDENTIFIER="46010381014****", ENOPERATIONTYPE=Add, GRPQUOTANAME="Q1", GRPSHAREQUOTAVALUE=50;
   ```
3. 删除组成员的共享配额信息，“成员用户标识”为“46010381014\*\*\*\*”，“操作类型”为“Delete”，“配额名称”为“Q1”：

   ```
   MOD PGRPMBR: USRIDENTIFIER="46010381014****", ENOPERATIONTYPE=Delete, GRPQUOTANAME="Q1";
   ```

## 输出结果说明

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释              | 原因分析                                  | 处理建议                               |
|------:|:-------------------|:--------------------------------------|:-----------------------------------|
| 90525 | 用户不属于该组。           | 所输入的“成员用户标识”不属于该组。                    | -                                  |
| 90605 | 用户属于多个组，必须指定组用户标识。 | 该用户属于多个组，当修改用户的组用户标识时，需要指定对应的“组用户标识”。 | 重新执行本命令修改组成员的组用户标识时，需要携带“组用户标识”参数。 |
