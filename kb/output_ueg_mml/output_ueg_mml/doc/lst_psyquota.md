# 查询Sy配额信息（LST PSYQUOTA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询用户的Sy配额信息。

## 注意事项

- 当**SET PSYSPARA**中参数“CalcSyCycleTime”取值为“1”时，该命令仅可以查询到已上线过用户的Sy配额信息，从未上线过的用户查询不到。
- 当**SET PSYSPARA**中参数“CalcSyCycleTime”取值为“0”时，该命令查询不到用户的Sy配额信息。
- 该命令不会触发重新计算用户Sy配额的周期开始时间和结束时间。
- 当**SET PSYSPARA**中参数“CalcSyCycleTime”取值为“1”时：
  - 业务下的Sy配额的“结帐模式”为“自定义周期”且“周期单位”为“小时”，或者“结帐模式”为“自定义周期”、“周期单位”为“天”且“复位时间类型”为“指定时间”，以业务下的订购时间计算Sy配额的周期起止时间。如果业务的订购时间为空，则用户上线时不会生成Sy配额的周期起止时间。
  - 业务下的Sy配额的“结帐模式”为“自然月”，如果用户是预付费类型，以业务下的生效时间计算Sy配额的周期起止时间。如果用户没有设置付费类型，则用户上线时将无法生成Sy配额的周期起止时间。
  - 业务下的Sy配额的“结帐模式”为“自然日历”、“复位周期类型”为“月”且“复位日期”为“生效日”，以业务下的生效时间计算Sy配额的周期起止时间。
  - 业务下的Sy配额的“结帐模式”为“自定义周期”、“周期单位”为“天”且“复位时间类型”为“开始时间”，以业务下的订购时间或者生效时间计算Sy配额的周期起止时间。
- 当Sy配额所属的业务被重复签约时，使用当前新签约业务的订购时间或生效时间计算Sy配额周期起止时间。
- 当修改用户结账日、业务生效时间时，系统不立即修改Sy配额周期起止时间，要到下一个周期才会用修改后的数据计算Sy配额周期起止时间。
- 当业务下的Sy配额的“结帐模式”为“自定义周期”时，如果已经生成Sy配额的周期起止时间，再修改业务的订购时间和生效时间，不影响后续Sy配额的起止周期时间计算。
- 执行**LST PSYQUOTA**命令时，不显示过期业务或者过期套餐下的配额。
- 执行**LST PSYQUOTA**命令时，只支持查询当前用户的配额信息，不支持从用户查询主用户的共享配额，也不支持成员用户查询组用户的共享配额。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                               |
|:--------------|:-------|:-----------------------------------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 用于指示系统需要按照哪个用户标识来查询用户配额信息数据。 取值范围：长度为1～255的字符串。 默认值：无。                             |
| QTANAME       | 配额名称   | 用于指定需要查询用户的哪个配额的信息。 配额名称必须是已存在的Sy配额且该配额需要在UPCF Web UI上配置。 取值范围：长度为1～32的字符串。 默认值：无。 |

## 使用实例

查询用户的Sy配额信息：“用户标识”为“46010381014\*\*\*\*”：

```
LST PSYQUOTA: USRIDENTIFIER="46010381014****";
```


## 输出结果说明

| 输出项名称                       | 输出项解释                                                                                                                    |
|:----------------------------|:-------------------------------------------------------------------------------------------------------------------------|
| Quota Name                  | 表示Sy配额的名称。 取值范围：长度不超过32的字符串。                                                                                             |
| Service Name                | 表示使用该Sy配额的业务。 取值范围：长度不超过64的字符串。                                                                                          |
| Quota Cycle Start Date Time | 表示该Sy配额的配额周期起始时间。 取值范围： NULL1970-01-01 00:00:00～2037-12-31 23:59:59：表示1970年01月01日00时00分00秒到2037年12月31日23时59分59秒之间的时间。    |
| Quota Cycle End Date Time   | 表示该Sy配额的配额周期截止时间。 取值范围： NULL1970-01-01 00:00:00～2037-12-31 23:59:59：表示1970年01月01日00时00分00秒到2037年12月31日23时59分59秒之间的时间。    |
| Updated Time                | 表示数据库中用户Sy配额记录的更新时间。 取值范围： NULL1970-01-01 00:00:00～2037-12-31 23:59:59：表示1970年01月01日00时00分00秒到2037年12月31日23时59分59秒之间的时间。 |
