# 设置自定义用户属性（SET PSUB）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置某用户的自定义用户属性值和扩展属性值。

- 当UPCF系统中不存在此用户时，先开户，再设置自定义用户属性值，其他用户属性为默认值。
- 当UPCF系统中存在此用户时，直接修改用户的自定义用户属性值。

## 注意事项

无。

## 使用实例

设置某用户的自定义属性值为“101”：“用户标识”为“46010381014\*\*\*\*”，“自定义用户属性”为“101”：

```
SET PSUB: USRIDENTIFIER="46010381014****", CUSTOMATTR=101;
```
