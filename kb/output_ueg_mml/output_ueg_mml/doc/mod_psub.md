## 命令功能

**须知** 

修改从用户为主用户，会导致虚拟配额丢失；修改结账日可能触发配额复位时间及余额重新计算，详见产品手册注意事项；因此执行该命令前，需要与华为技术支持确认后才可以实施。

本命令用于对用户的基本信息进行修改或调整，包括旧用户标识、移动用户MSISDN号、用户状态、归属服务区、付费类型、用户类别、用户身份、主用户标识、联系方式、结帐日、签约终端类型等。

## 注意事项

- 修改用户信息，可能会改变用户所属的动态用户组，导致用户无法使用原用户组下的业务，请操作员在执行该操作之前仔细确认任务的可行性。
- 若修改了从用户所属的主用户，或者将从用户修改为主用户，会导致虚拟配额丢失，改变从用户的业务体验。
- 如果修改了用户的“联系方式”和“Email”地址，此修改将在用户下次上线时生效。
- 如果修改了“结帐日”，不影响当前正在使用的配额，此修改会在用户最近一个结帐日过后生效。
- 如果主用户被修改为从用户或者修改了从用户所属的主用户，当系统软参VRM\_DIAREDIRECTSWITCH = 1时，此用户被强制下线；当系统软参VRM\_DIAREDIRECTSWITCH = 0时，此用户保持在线。
- 若主用户改号，则系统会强制主从用户都下线；若从用户改号，则系统会仅强制从用户下线。
- 如果修改后的新结账日早于旧结账日，只会重新计算配额的下次复位时间，不会对配额的余额进行重新计算。
- 如果修改后的新结账日晚于旧结账日，且重新计算后的配额下次复位时间是在原来的下次复位时间之后，则会对配额的余额进行补偿计算。具体余额的补偿折算公式如下：

  折算后总余额 = 当前余额 + （配额总值 \*（新结账日-旧结账日）/ 下次复位时间所在月的天数）。

  **说明** 

  配额余额的补偿折算举例：当前是6月1号，把结账日从10号改到20号，当前余额是10KB，配额总值是30KB的话，那么折算后总余额 = 10KB +（30KB\*（20-10）/30天）= 20KB。

## 使用实例

修改用户信息：“用户标识”为“46010381014\*\*\*\*”，“联系方式”为“SMS”，“用户第二标识”为“18718050630”：

```
MOD PSUB: USRIDENTIFIER="46010381014****", USRCONTACTMETHOD=SMS, USRSECONDIDENTIFIER="18718050630";
```
