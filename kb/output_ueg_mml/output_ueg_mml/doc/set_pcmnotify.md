# 设置PCM用户通知（SET PCMNOTIFY）

- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于从PGW强制触发SLU查询外置SPR中某个指定用户数据。SLU收到**SET PCMNOTIFY**命令后，SLU会发起外置SPR数据查询。

- 对已开户的用户：执行**SET PCMNOTIFY**命令后，当查询数据与BE保存的用户数据有变化时，由SLU调用**MOD PSUB**命令，对用户数据进行修改保存到BE，并通知FE。
- 对未开户的用户：执行**SET PCMNOTIFY**命令后，触发外置SPR数据查询，SLU会调用**ADD PSUB**命令，对未开户用户进行开户操作。

该命令支持批处理查询外置SPR指定列表用户数据，最大批操作数为PGW模块个数乘以软参“MAXBATNUMBER”的取值。

**说明** 

当前版本该命令功能暂不支持。

## 注意事项

- PGW在成功将消息发送给SLU后即直接返回成功，不判断用户数据是否修改成功。SLU侧是否成功对用户数据进行修改保存，则需根据“CheckSub”命令的ITLOG进行判断。
- 执行**SET PCMNOTIFY**命令前，需确保系统参数“PCMSwitch”的取值为1。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                          |
|:--------------|:-------|:--------------------------------------------------------------|
| REQ           | 请求类型   | 用于设置请求类型。 取值范围：CheckSub（校验用户数据）。 默认值：无。 配置原则：固定取值为“CheckSub”。 |
| USRIDENTIFIER | 用户标识   | 用于唯一指定需要查询的用户。 取值范围：长度不超过255的字符串。 默认值：无。                      |

## 使用实例

设置PCM命令通知，“请求类型”为“CheckSub”，“用户标识”为“460103901200002”:

```
SET PCMNOTIFY: REQ=CheckSub, USRIDENTIFIER="460103901200002";
```

## 输出结果说明

系统参数“PCMSwitch”开启，执行该命令，会返回命令执行成功的提示信息。

系统参数“PCMSwitch”关闭，该命令执行异常，会返回对应的错误码。错误码如表1所示。

|   错误码 | 错误码解释   | 原因分析         | 处理建议                                     |
|------:|:--------|:-------------|:-----------------------------------------|
|  1001 | 命令非法    | PCM子系统功能未开启。 | 执行SET PSYSPARA命令，设置系统参数“PCMSwitch”的取值为1。 |
