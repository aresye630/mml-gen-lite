# 用户数据更新通知(NTY PSPAINTLFSUB)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于SPR(PGW)向UPCF发送更新用户数据的通知。

## 注意事项

本命令属局点定制。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                    |
|:--------------|:-------|:--------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 用于表示向UPCF发送的用户数据更新通知里携带的用户标识。 取值范围：长度不超过255的字符串。 默认值：无。 |

## 使用实例

通知UPCF更新某一用户的用户数据：“用户标识”为“186\*\*\*\*0856”。

```
NTY PSPAINTLFSUB: USRIDENTIFIER="186****0856";
```
