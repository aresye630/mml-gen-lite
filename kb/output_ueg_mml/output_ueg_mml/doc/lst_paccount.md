# 查询帐户信息（LST PACCOUNT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询用户帐户数据的配置信息。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                   |
|:--------------|:-------|:-------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 用于指示系统需要按照哪个用户标识来查询用户帐户信息数据。 取值范围：长度不超过255的字符串。 默认值：无。 |

## 使用实例

查询帐户信息：“用户标识”为“46010381014\*\*\*\*”：

```
LST PACCOUNT: USRIDENTIFIER="46010381014****";
```

## 输出结果说明

| 输出项名称                | 输出项解释                                                                                                                                                                 |
|:---------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Initial Value        | 表示用户的消费限额，此参数是金额，不是流量。 数据类型：浮点数，精确到小数点后四位。若显示的小数点后不足四位，则表示低位为0不显示。 取值范围：0～10000000。                                                                                   |
| Balance              | 表示用户的剩余额。 数据类型：浮点数，精确到小数点后四位，不做四舍五入。若显示的小数点后不足四位，则表示低位为0不显示。 取值范围：0～10000000。                                                                                         |
| Consumption          | 表示用户已经消费的金额。 数据类型：浮点数，精确到小数点后四位，不做四舍五入。若显示的小数点后不足四位，则表示低位为0不显示。 取值范围：0～10000000。                                                                                      |
| Privilege            | 表示用户帐户权限，包括正常(Normal)、PrivilegeA、PrivilegeB、PrivilegeC、不受限(Unrestricted)五种。                                                                                           |
| Last Reset Date Time | 帐户上次复位的时间。 取值范围： NULL1970-01-01 00:00:00～2037-12-31 23:59:59：表示1970年01月01日00时00分00秒到2037年12月31日23时59分59秒之间的时间。                                                        |
| Next Reset Date Time | 帐户下次复位的时间。 取值范围： NULL1970-01-01 00:00:00～2037-12-31 23:59:59：表示1970年01月01日00时00分00秒到2037年12月31日23时59分59秒之间的时间。                                                        |
| Status               | 表示帐户所处状态，即根据需要触发额度事件时已使用的配额占总配额的百分比，划分为十二个级别，分别是：Normal、Level1、Level2、Level3、Level4、Level5、Level6、Level7、Level8、Level9、Level10和Exhaust。 例如：“Status = Exhaust”，表示帐户耗尽。 |
| Personalized Value   | 表示用户自定义帐户限额，此参数是金额，不是流量。 数据类型：浮点数，精确到小数点后四位，不做四舍五入。若显示的小数点后不足四位，则表示低位为0不显示。 取值范围：0～10000000。                                                                          |
| CustomStatus         | 表示自定义配额/帐户状态，即根据需要触发消息通知时已使用的配额占总配额的百分比，包括初始状态（Invalid）以及三个有效状态：CustomLevel1、CustomLevel2和CustomLevel3。                                                               |
| Account Name         | 表示用户的帐户名称。 取值范围：长度为1～32字节的字符串。                                                                                                                                        |
