# 清除帐户信息（CLR PACCOUNT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于清除帐户信息，将用户帐户剩余额置为零，用户帐户消耗额置为帐户初始值，用户帐户状态置为耗尽。

## 注意事项

- 清除帐户信息，可能使用户无法使用业务，请谨慎操作。
- 清除帐户信息时，该用户下此帐户相关的通知抑制记录将会被清除；如果该用户下存在从用户，其从用户下所有帐户相关的所有通知抑制记录都会被清除。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                |
|:--------------|:-------|:----------------------------------------------------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 标识一条用户帐户信息数据记录的关键字段之一，用于指定需要清除哪一个用户的帐户信息。 取值范围：长度不超过255的字符串。 默认值：无。                                 |
| ACTNAME       | 帐户名称   | 标识一条用户帐户信息数据记录的关键字段之一，用于指定需要清除信息的用户帐户。 帐户名称必须是已存在的帐户且该帐户需要在UPCF Web UI上配置。 取值范围：长度不超过32的字符串。 默认值：无。 |

## 使用实例

清除帐户信息：“用户标识”为“46010381014\*\*\*\*”，“帐户名称”为“Bill\_001”：

```
CLR PACCOUNT: USRIDENTIFIER="46010381014****", ACTNAME="Bill_001";
```
