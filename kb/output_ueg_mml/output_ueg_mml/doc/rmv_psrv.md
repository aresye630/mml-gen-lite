# 删除签约信息（RMV PSRV）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令携带RMVALLSERVICE=Yes时，可能删除多条签约业务及重复订购记录，详见产品手册注意事项。因此执行该命令前，需要与华为技术支持确认后才可以实施。

本命令用于删除用户签约某个业务的签约信息，包括业务名称、订购时间、生效时间、截止时间、漫游类型等。

用户签约的某个业务信息被删除后，用户将不能再使用该业务。

## 注意事项

- 当用户所签约的业务和套餐都被删除时，用户将无法接入网络，请操作员在执行该操作之前仔细确认任务的可行性。
- 当用户所签约的业务被删除时，该用户下此业务相关的通知抑制记录将会被清除。如果该用户下存在从用户，那么从用户下该业务相关的通知抑制记录也会被清除。
- 执行本命令时，不生成转移配额的EDR记录。
- 如果输入“用户标识”且“删除所有业务”取值为“Yes”时，无论是否输入“业务”，执行本命令后都会删除对应业务的所有签约记录（包含多业务记录重复订购和多配额记录重复订购）。

## 参数说明

| 参数标识                | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
|:--------------------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER       | 用户标识     | 标识用户签约信息的关键字段之一，用于指定需要删除哪一个用户的签约信息。 取值范围：长度不超过255的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| SRVNAME             | 业务       | 标识用户签约信息的关键字段之一，用于指定需要删除用户哪个业务的签约信息。 取值范围：长度不超过64的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| TERMIND             | 终止类型     | 删除签约的方式。 取值范围： “Immediate termination”：表示命令执行后，立即删除签约的业务。“Valid till expiry date”：表示命令执行后，周期复位的配额中最近的一个下次复位时间时，该业务过期。“Valid till expiry date and allow quota accumulated”：表示命令执行后，关联的配额中最近的一个下次复位时间时，该业务过期，同时业务的“用户订购类型”更新为“Subscribed_KeepUntilQuotaNextResetDate”。执行MOD PQUOTA命令修改配额“状态”为“Exhaust”时，如果业务的“用户订购类型”为“Subscribed_KeepUntilQuotaNextResetDate”，系统将去签约该业务和业务关联的配额、帐户。“Immediate termination for subscribe counter”：表示命令执行后，不管签约的业务是否为计数器形式，直接删除该业务。 默认值：Immediate termination。  说明： 当删除的用户签约业务关联了“配额管理归属”为“UPCC Dynamic”的配额时，“终止类型”只能设置为“Immediate termination”或“Immediate termination for subscribe counter”。当选择“Valid till expiry date”或“Valid till expiry date and allow quota accumulated”时，系统取配额下次复位时间（如果业务下有多个配额，取下次复位时间最近的那个配额）和签约业务失效时间（LST PSRV查询结果中“Expiry Date”项的内容）中的较小值作为该业务真正的签约失效时间。当删除的用户业务的“重复订购方式”配置为“多配额记录重复订购”时，“终止类型”只能设置为“Immediate termination”。当删除的用户业务的“M2M共享业务”配置为“Yes”时，“终止类型”只能设置为“Immediate termination”。 |
| SRVSTARTDATETIME    | 生效时间     | 用于指定需要为用户去订购某个生效时间对应的业务订购记录，时间格式为YYYY&MM&DD&HH&MM&SS。仅当删除的用户业务的“重复订购方式”配置为“多记录重复订购”时，该参数有效。 取值范围：可通过控件配置时间。 默认值：无。  说明： 当删除的用户业务的“重复订购方式”配置为“多配额记录重复订购”时，系统不支持该参数的处理。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| SRVDELETESUBSCRIBER | 自动删除用户   | 用于标识用户去订购业务时是否自动删除用户。 取值范围： “No”：表示不自动删除用户。“Yes”：表示用户无可用业务时自动删除用户。“Yes check USRCUSTOMERATTR as well”：表示用户无可用业务且用户自定义属性无效时自动删除用户。 默认值：No。  说明： 仅当同时满足以下条件时，则认为该用户无可用业务。除当前请求业务外，用户没有签约其它业务或者所签约业务均已过期。仅检查外置SPR业务和静态签约业务，不对动态业务进行检查。用户没有主从关系，并且不是组用户，也不是组成员。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| RMVALLSERVICE       | 删除所有业务   | 用于删除用户订购的所有业务。 取值范围： “No”：表示只删除指定用户的某个业务的签约信息。“Yes”：表示删除指定用户的所有业务的签约信息。 默认值：No  说明： 当“终止类型”设置为“Immediate termination”或“自动删除用户”设置为“No”时，该参数才显示。当该参数设置为“Yes”时，该命令其他参数不生效。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| RMVALLRECORDS       | 删除业务所有记录 | 用于删除指定业务所有的重复订购记录。 取值范围： “Yes”：表示只删除指定业务所有的重复订购记录，和PGW参数“UnSubscribeReService”取值为“2”的能力相同。“No”：表示根据PGW参数“UnSubscribeReService”取值能力删除业务对应的重复订购记录。 默认值：No  说明： 当“终止类型”取值为“Immediate termination”且“生效时间”为空时，本参数才能设置为“Yes”。当“删除所有业务”为“Yes”时，本参数不生效。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

## 使用实例

删除签约信息：“用户标识”为“46010381014\*\*\*\*”，“业务”为“Volume\_5M”：

```
RMV PSRV: USRIDENTIFIER="46010381014****", SRVNAME="Volume_5M";
```
