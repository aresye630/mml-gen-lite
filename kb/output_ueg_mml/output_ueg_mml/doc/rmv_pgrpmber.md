# 删除组成员（RMV PGRPMBR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于从用户组中删除组成员。组成员被删除后，不能再共享组用户签约的配额。

## 注意事项

- 删除组成员时，如果该成员在线，且软参“VRM\_RMVGRPMEMBERACT”配置为“0”，该成员将被强制下线。
- 支持使用组成员的第二标识删除组成员。
- 当组配额属性“组配额分配方式”取值为“实际分配”，且该组成员已分配了配额时，删除该用户后：
  - 组配额的消耗量将减去该用户分配的配额的余额。
  - 组配额的余额将增加该用户分配的配额的余额。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                            |
|:--------------|:-------|:------------------------------------------------------------------------------------------------|
| USRIDENTIFIER | 成员用户标识 | 用于指定删除哪一个组成员。 取值范围：长度不超过255的字符串。 默认值：无。  说明： 该参数必须先由ADD PSUB命令定义，然后才能在此处索引。                     |
| GRPIDENTIFIER | 组用户标识  | 用于指定需要删除的组成员的组标识。 如果携带了该参数，则该组成员从组标识指定的组中退出。如果未携带该参数，则该组成员从所属的全部组中退出。 取值范围：长度不超过255的字符串。 默认值：无。 |

## 使用实例

删除组成员，“成员用户标识”为“46010381014\*\*\*\*”：

```
RMV PGRPMBR: USRIDENTIFIER="46010381014****";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释    | 原因分析            | 处理建议            |
|------:|:---------|:----------------|:----------------|
| 90525 | 用户不属于该组。 | 需要退出的用户不属于指定的组。 | 请携带用户当前所属组的组标识。 |
