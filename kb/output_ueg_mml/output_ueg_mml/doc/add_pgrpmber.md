# 增加组成员（ADD PGRPMBR）

## 命令功能

本命令用于将用户加入某个用户组，包括成员用户标识和组用户标识；同时支持用户加入用户组时指定共享配额，包括配额名称、总量和余额。只有用户加入用户组后，才能共享组用户签约的配额。

## 注意事项

- 即将加入用户组的用户不能是家庭共享配额组的主用户或从用户。
- 当组成员用户开户到SPR时，组成员个数不能超过最大成员限制，一个用户组最大的组成员为50000个，不包括组用户本身。
- 如果用户组是测试用户组，组成员必须是测试用户；如果用户组是非测试用户组，组成员也必须是非测试用户。
- 通过外置SPR开户的用户与默认PCC开户的用户不能成为组成员。
- 如果用户在线加入用户组，将被强制下线。
- 该命令中涉及到的配额名称和总量、余额信息仅限于基础配额信息。
- 一个组用户可签约的组业务数量受“MaxGrpSrvNumPerGrpSub”限制：
  - 若某用户仅加入1个组，那么该用户的虚拟配额最大个数为“MaxGrpSrvNumPerGrpSub”取值。
  - 若某用户同时加入2个组，那么该用户的虚拟配额最大个数为20个。
  - 若某用户同时加入组的个数大于2个，那么该用户的虚拟配额最大个数为25个。
- 当组成员用户开户到UDR，单群组中的最大成员数超过200个时，需要购买群组业务共享增值包扩充容量。群组业务共享基本体验包场景可配置的单群祖最大成员数量为200个，群组业务共享增值包场景可配置的单群祖最大成员数量为50000个。
- 如果组共享业务为多配额实例组业务，用户加入用户组设定共享配额时，分配给组成员用户的配额为虚拟配额，且虚拟配额总量可以小于等于或大于组用户配额总量。
- 如果组共享业务不是多配额实例组业务，用户加入用户组设定共享配额时，设定的共享配额总量必须小于等于组用户的配额总量。

## 参数说明

| 参数标识                 | 参数名称   | 参数说明                                                                                                                                                                                                                                   |
|:---------------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER        | 成员用户标识 | 用于指定将哪个用户加入用户组中。 取值范围：长度不超过255的字符串。 默认值：无。 配置原则：不支持英文逗号（,）、英文分号（;），等号（=）、英文双引号（"）、英文单引号（'），连续两个及以上的百分号（%%），连续两个及以上的空格（ ）、mml报文起始符标识（+++）。  说明： 该参数必须先由ADD PSUB命令定义，然后才能在此处索引。                                                          |
| GRPIDENTIFIER        | 组用户标识  | 用于指定用户要加入的某个组。 取值范围：长度不超过254的字符串。 默认值：无。  说明： 该参数必须先由ADD PSUB命令定义，然后才能在此处索引。                                                                                                                                                           |
| GRPQUOTANAME         | 配额名称   | 用于指定组成员共享的配额名称。 取值范围：长度不超过32的字符串。 默认值：无。  说明： 该配额名称必须已被组用户签约。该配额名称不能与组成员已签约的配额名称相同。                                                                                                                                                    |
| GRPSHAREQUOTAVALUE   | 总量     | 用于指定组用户分配给组成员的共享配额大小。 取值范围：1～4294967294。 单位：KB。 默认值：无。  说明： 如果“GRPQUOTANAME”参数设置的配额名称对应配额的“配额管理归属”是“Pre-Sy”，则不需要设置此参数。如果“GRPQUOTANAME”参数设置了非“Pre-Sy”的“配额管理归属”的配额名称，则必须设置此参数。当配额属性“组配额分配方式”取值为“实际分配”时，设置的配额值将从组配额的余额中扣减，该配额为组成员独立使用的配额。 |
| GRPSHAREQUOTABALANCE | 余额     | 用于指定组成员的剩余配额大小。 取值范围：0～4294967294。 单位：KB。 默认值：无。  说明： 如果“GRPQUOTANAME”参数设置的配额名称对应配额的“配额管理归属”是“Pre-Sy”，则不需要设置此参数。此参数不指定时，余额等于总量。                                                                                                        |
| CREATESUBSCRIBER     | 自动创建用户 | 用于标识是否需要创建用户。用户加入组时，如果用户不存在，是否自动创建用户并把用户添加到组。 取值范围：“No”：表示不支持自动创建用户。“Yes”：表示支持自动创建用户。 默认值：No。                                                                                                                                          |
| CREATEGROUP          | 自动创建组  | 用于标识是否需要创建组。用户加入组时，如果组用户不存在，是否自动创建组并把用户添加到组。 取值范围：“No”：表示不支持自动创建组。“Yes”：表示支持自动创建组。 默认值：No。                                                                                                                                             |

## 使用实例

1、添加组成员时不指定共享配额，“成员用户标识”为“46010381014\*\*\*\*”，“组用户标识”为“Group001”：

```
ADD PGRPMBR: USRIDENTIFIER="46010381014****", GRPIDENTIFIER="Group001";
```

2、添加组成员时指定共享配额，“成员用户标识”为“46010381014\*\*\*\*”，“组用户标识”为“Group001”，“配额名称”为“Quota01”，“总量”为“100”：

```
ADD PGRPMBR: USRIDENTIFIER="46010381014****", GRPIDENTIFIER="Group001", GRPQUOTANAME="Quota01", GRPSHAREQUOTAVALUE=100;
```
