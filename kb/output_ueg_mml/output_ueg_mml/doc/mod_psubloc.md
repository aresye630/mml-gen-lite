# 修改用户位置信息（MOD PSUBLOC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于对一条用户位置信息的数据记录进行修改。修改位置信息后，用户在指定的位置区享有不同的QoS和资费。

在用户接入网络时，UPCF将用户位置信息（PRA list）下发给PCEF/SMF，用户使用移动数据业务过程中，当PCEF/SMF检测到用户位置信息发生变化时上报给UPCF，UPCF根据PCEF/SMF上报的用户位置区域标识和位置区域状态判断用户是进入或离开PRA（Presence Reporting Area）进行策略调整。如果运营商希望修改用户位置信息，可以通过该命令进行修改。

## 注意事项

无。

## 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER   | 用户标识   | 用于指定为哪个用户修改位置信息。该参数必须先由ADD PSUB命令定义，然后才能在此处索引。 取值范围：长度不超过255的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| SRVNAME         | 业务     | 用于指定修改哪个业务的位置区。该参数必须先由ADD PSRV命令定义，然后才能在此处索引。 取值范围：长度不超过64的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| USRLOCATION     | 位置区    | 用于指定用户已签约业务的位置区。该参数为必选参数。 取值范围：长度不超过1024的字符串。该参数取值配置原则：type-value[\,type-value]...[\,type-value]。 type表示位置区的类型，取值范围：0：CGI，由MCC、MNC、LAC、CI组成。1：SAI，由MCC、MNC、LAC、SAC组成。2：RAI，MCC、MNC、LAC、RAC组成。128：TAI，由MCC、MNC、TAC组成。129：ECGI，由MCC、MNC、ECI组成。130：TAI+ECGI，由MCC、MNC、TAC、ECI组成。135：NCGI，由MCC、MNC、NCI组成。137：TAI+NCGI，由MCC、MNC、TAC、NCI组成。256：Macro eNodeB，由MCC、MNC、Macro eNodeB ID组成。257：Home eNodeB，由MCC、MNC、Home eNodeB ID组成。258：eNodeB ID或者gNodeB ID。其中，eNodeB ID由Macro eNodeB ID或者Home eNodeB ID组成，gNodeB ID由5G基站ID组成。259：LAC，由单独的位置区码LAC组成。 value为位置区对应的具体编号，取值范围：MCC：移动国家码，长度为3的十进制数字。MNC：移动网码，长度为2或3的十进制数字。LAC：位置区码，取值范围为0～65535的十进制数。当位置区的类型不为259时，长度不足5位时，需要在数字前面补0确保位数为5位。当位置区的类型为259时，不需要在数字前面补0。 CI（小区标识）、SAC（服务区码）、RAC（路由区编码）：长度为1～5的十进制数字，当长度不足5位时，需要在数字前面补0确保位数为5位。TAC：跟踪区域码，长度为4位或6位的十六进制数（转换为十进制数字为1～5位或1～8位的十进制数字）。当4位十六进制数的TAC转换为十进制数字长度不足5位时，需要在数字前面补0确保位数为5位。当6位十六进制数的TAC转换为十进制数字长度不足8位时，需要在数字前面补0确保位数为8位。ECI：E-UTRAN小区标识，长度为1～9的十进制数字，当长度不足9位时，需要在数字前面补0确保位数为9位。NCI：NR小区标识，长度为1～11的十进制数字。当NCI长度不足11位时，需要在数字前面补0确保位数为11位。Macro eNodeB ID：宏基站eNodeB的ID，长度为7位十进制数字，取值范围为0～1048575的十进制数。当Macro eNodeB ID长度不足7位时，需要在数字前面补0确保位数为7位。Home eNodeB ID：家庭基站eNodeB的ID，长度为9位十进制数字，取值范围为0～268435455的十进制数。当Home eNodeB ID长度不足9位时，需要在数字前面补0确保位数为9位。eNodeB ID：Macro eNodeB ID或者Home eNodeB ID。Macro eNodeB ID表示宏基站eNodeB的ID，长度为7位十进制数字，取值范围为0～1048575的十进制数，当Macro eNodeB ID长度不足7位时，不需要在数字前面补0。Home eNodeB ID表示家庭基站eNodeB的ID，长度为9位十进制数字，取值范围为0～268435455的十进制数，当Home eNodeB ID长度不足9位时，不需要在数字前面补0。 gNodeB ID：5G基站ID，长度为10位十进制数，取值范围为0~4294967295的十进制数。当gNodeB ID的长度不足10位时，不需要在数字前面补0。 “-”：type与value之间的连接符。“,”：多个type-value段间的连接符，当要表达多个type-value段时，必须在“,”前增加转义符“\”，比如0-123456789100001\,1-123456789100009。转义符“\”不影响参数长度计算，只要求去掉转义符之后的总长度不大于1024字节，即允许输入的包括转义符在内的总长度大于1024字节。 默认值：无。  说明： 混合组网下，该参数需设置为长度不超过256的字符串。 |
| USRLOCATIONTYPE | 位置信息类型 | 参数含义：用于指定用户已签约业务的位置信息类型。该参数为可选参数。 取值范围： 0：表示2/3/4G位置信息或4G位置信息。1：表示3G位置信息。 默认值：0。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |

## 使用实例

1. 修改用户位置信息，“用户标识”为“46010381014\*\*\*\*”，“业务”为“Volume\_5M”，“位置区”为“1-123456531100009”：

   ```
   MOD PSUBLOC: USRIDENTIFIER="46010381014****", SRVNAME="Volume_5M", USRLOCATION="1-123456531100009";
   ```
2. 修改用户位置信息，“用户标识”为“46010381012\*\*\*\*”，“业务”为“Volume\_10M”，“位置区”为“0-123456530100002\,1-123456530100009”：

   ```
   MOD PSUBLOC: USRIDENTIFIER="46010381012****", SRVNAME="Volume_10M", USRLOCATION="0-123456530100002\,1-123456530100009";
   ```
