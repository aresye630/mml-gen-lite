# 查询用户自定义阈值（LST PCTLEVEL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询用户配额数据的配置信息。

## 注意事项

该命令不支持查询从用户的虚拟配额中自定义阈值属性。

## 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                            |
|:--------------|:--------|:------------------------------------------------------------------------------------------------|
| USRIDENTIFIER | 用户标识    | 用于指示系统需要按照哪个用户标识来查询用户配额信息数据。 取值范围：长度不超过255的字符串。 默认值：无。                                          |
| LEVELTYPE     | 阈值类型    | 用于设置修改用户自定义阈值的类型。 取值范围： “Quota”“Account” 默认值：无。                                                 |
| QTAACTNAME    | 配额/帐户名称 | 用于指定需要查询用户的哪个配额/帐户的自定义阈值。 配额/帐户名称必须是已存在的配额/帐户且该配额/帐户需要在UPCF Web UI上配置。 取值范围：长度不超过32的字符串。 默认值：无。 |

## 使用实例

查询自定义阈值：“用户标识”为“46010381014\*\*\*\*”，“阈值类型”为“Quota”：

```
LST PCTLEVEL: USRIDENTIFIER="46010381014****", LEVELTYPE=Quota;
```

## 输出结果说明

| 输出项名称        | 输出项解释                                                         |
|:-------------|:--------------------------------------------------------------|
| LEVELTYPE    | 表示查询的用户自定义阈值的哪种类型。 取值范围： “Quota”“Account”                     |
| QANAME       | 表示配额/帐户的名称。 取值范围：长度不超过32的字符串。                                 |
| CUSTOMLEVEL1 | 表示需要触发消息通知时，CUSTOMLEVEL1已使用的配额占总配额的百分比。 阈值范围：1～500000。 单位：% 。 |
| CUSTOMLEVEL2 | 表示需要触发消息通知时，CUSTOMLEVEL2已使用的配额占总配额的百分比。 阈值范围：1～500000。 单位：% 。 |
| CUSTOMLEVEL3 | 表示需要触发消息通知时，CUSTOMLEVEL3已使用的配额占总配额的百分比。 阈值范围：1～500000。 单位：% 。 |
