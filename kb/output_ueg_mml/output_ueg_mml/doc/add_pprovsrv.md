# 用户签约营帐业务（ADD PPROVSRV）

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

本命令用于为用户签约一个业务，通过该命令可以指定业务下关联的多个Provisioning类型配额的初始值。

## 注意事项

- 执行该命令时，一次仅可以为一个用户签约一个业务。每个业务最多允许指定20个Provisioning类型配额的初始值。
- 执行该命令时，如果设置配额，则配额必须为用户所订购业务关联的Provisioning类型的配额。
- 执行该命令进行重复订购时，如果没有设置配额，则已订购业务的Provisioning类型配额的余额按不累积处理。
- 用户再次签约有平滑期业务时，按本次签约业务生效时间重新计算激活业务，忽略上次业务的平滑期。
- 组用户不支持签约M2M共享业务。
- 从用户或关联了从用户的主用户不支持签约M2M共享业务。
- 存在第二标识的用户不支持签约M2M共享业务。
- 指定M2M共享业务下关联的Provisioning类型配额的初始值不能为0。
- 用户签约的业务为M2M共享业务时，如果未设置生效时间，则默认采用当前系统时间减5秒的时间为该业务生效时间。

## 参数说明

| 参数标识             | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                |
|:-----------------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER    | 用户标识    | 用于指定为哪个用户签约业务，必须是已存在的用户。该参数必须先由ADD PSUB命令定义，然后才能在此处索引 取值范围：长度不超过255的字符串。 默认值：无。 配置原则：不支持英文逗号（,）、英文分号（;），等号（=）、英文双引号（"）、英文单引号（'），连续两个及以上的百分号（%%），连续两个及以上的空格（ ）、mml报文起始符标识（+++）。                                                                                                                      |
| SRVNAME          | 业务      | 用于指定用户要签约的某个业务，必须是已存在的业务且该业务需要在UPCF上配置。 取值范围：长度不超过64的字符串。 默认值：无。                                                                                                                                                                                                                                    |
| SRVSTARTDATETIME | 生效时间    | 用于指定用户订购业务的时间，时间格式为YYYY&MM&DD&HH&MM&SS。 取值范围：1970-01-01 00:00:00～2037-12-31 23:59:59：表示1970年01月01日00时00分00秒到2037年12月31日23时59分59秒之间的时间。 NULL：表示未设置业务的生效时间。 默认值：NULL。  说明： “生效时间”要小于“截止时间”。 当该命令未设置业务的“生效时间”时： 如果设置了业务“有效期”，则业务的“生效时间”为业务“截止时间”减去业务“有效期”。 如果未设置业务“有效期”，则业务立即生效。                       |
| SRVENDDATETIME   | 截止时间    | 用于指定用户所订购业务的失效时间，时间格式为YYYY&MM&DD&HH&MM&SS，当系统时间等于截止时间后，用户不能使用该业务。 取值范围：1970-01-01 00:00:00～2037-12-31 23:59:59：表示1970年01月01日00时00分00秒到2037年12月31日23时59分59秒之间的时间。 NULL：表示未设置业务的失效时间。 默认值：NULL。  说明： “截止时间”要大于系统时间。 当该命令未设置业务的“截止时间”时： 如果设置了业务“有效期”，则业务的“截止时间”为业务“生效时间”加上“有效期”。 如果未设置业务“有效期”，则业务一直有效。 |

## 使用实例

用户签约：“用户标识”为“46010381014\*\*\*\*”，“业务”为“Volume\_5M”，“生效时间”为“2010&11&24&15&11&21”，“截止时间”为“2010&12&01&00&00&00”，“签约状态”为“Normal”, “配额名称\_1”为“Quota1”, “总量\_1”为“2048”，“配额名称\_2”为“Quota2”, “总量\_2”为“3072”：

```
ADD PPROVSRV: USRIDENTIFIER="46010381014****", SRVNAME="Volume_5M", SRVSTARTDATETIME=2010&11&24&15&11&21, SRVENDDATETIME=2010&12&01&00&00&00, SRVSTATUS=Normal, QTANAME_1="Quota1", QTAVALUE_1=2048, QTANAME_2="Quota2", QTAVALUE_2=3072;
```
