# 删除别名（RMV PALIAS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令暂时停止使用。执行该命令只检查命令参数规范，如参数符合规范，则命名执行成功，并不产生任何数据变化。

## 注意事项

无。

## 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                      |
|:----------------|:-------|:--------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER   | 用户标识   | 用于唯一标识一个用户，且用户标识不能和已有的用户标识重名。 取值范围：长度不超过255的字符串。 默认值：无。                                                                   |
| ALIASTYPE       | 别名类型   | 别名类型。 取值范围： “MSISDN”：用户MSISDN。“IMSI”：用户IMSI。“SIPURI”：用户SIP URI。“NAI”：用户NAI。“USERPRIVATE”：credit-control服务器自定义用户标识。 默认值：无。 |
| ALIASVALUE      | 用户别名   | 用户别名取值。 取值范围：长度不超过255的字符串。 默认值：无。                                                                                         |
| ALIASEXPIREDATE | 别名过期时间 | 用于指定别名过期时间。时间格式为YYYY&MM&DD&HH&MM&SS。 取值范围：1970&01&01&00&00&00～2037&12&31&23&59&59。 默认值：无。                                 |

## 使用实例

删除别名：“用户标识”为“46010381014\*\*\*\*”，“别名类型”为“MSISDN”，“用户别名”为“13817103516”：

```
RMV PALIAS: USRIDENTIFIER="46010381014****", ALIASTYPE=MSISDN, ALIASVALUE="13717103516";
```
