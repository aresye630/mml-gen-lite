# 查询累计项（LST PACCUM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询累计项的配置信息。

## 注意事项

当累计项的“累计类型”为“会话累计”时，累计项无“滑动窗口长度”和“当前周期个数”，所以字段“滑动窗口长度”和“当前周期个数”显示为“NULL”。

当累计项的“累计类型”为“会话累计”时，“使用量”和“累计项状态”仅在当前会话内有效，临时信息不写入数据库，所以查询时“使用量”和“累计项状态”均显示为“NULL”。

当累计项的“累计类型”为“周期累计”时，“检测时间间隔”无意义，所以此字段显示为“NULL”。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                 |
|:--------------|:-------|:-----------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 用于指示系统根据哪个用户标识来查询累计项数据。 取值范围：长度不超过255的字符串。 默认值：无。    |
| ACCNAME       | 累计项名称  | 用于指示系统根据用户的哪个累计项名称来查询累计项数据。 取值范围：长度不超过32的字符串。 默认值：无。 |

## 使用实例

查询累计项：“用户标识”为“46010381014\*\*\*\*”，“累计项名称”为“ACC”：

```
LST PACCUM: USRIDENTIFIER="46010381014****", ACCNAME="ACC";
```
