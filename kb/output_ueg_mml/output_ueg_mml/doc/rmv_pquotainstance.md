# 删除配额实例（RMV PQUOTAINSTANCE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除一条用户的配额实例记录。

当用户某个配额的配额实例记录达到255条后，如果还需重复订购该配额，可通过执行此命令删除已失效的配额实例。

## 注意事项

若删除正在使用的配额实例，该配额相关的通知抑制记录也将会被清除。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                               |
|:--------------|:-------|:-----------------------------------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 用于指定删除哪一个用户的配额实例信息。 取值范围：长度不超过255的字符串。 默认值：无。                                      |
| QTANAME       | 配额名称   | 用于指定删除哪一个用户配额的配额实例信息。 配额名称必须是已存在的配额且该配额需要在UPCF Web UI上配置。 取值范围：长度不超过32的字符串。 默认值：无。 |
| SEQUENCEID    | 实例序列号  | 用于指定删除哪一个配额实例序号的配额实例信息。 取值范围： 0～254。 默认值：无。                                        |

## 使用实例

删除用户配额实例：“用户标识”为“46010381014\*\*\*\*”，“配额名称”为“Volume\_Quota”，“实例序列号”为“12”：

```
RMV PQUOTAINSTANCE: USRIDENTIFIER="46010381014****", QTANAME="Volume_Quota", SEQUENCEID=12;
```
