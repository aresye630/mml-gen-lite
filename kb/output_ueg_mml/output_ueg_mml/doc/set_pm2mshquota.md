# 设置M2M虚拟配额（SET PM2MSHQUOTA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令携带ENOPERATIONTYPE=Delete时，若所有的配额名称参数均不设置，则删除该子节点用户共享该父节点用户的全部虚拟配额，详见产品手册注意事项。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对M2M用户进行虚拟配额设置，包括虚拟配额总量、余额和优先级。

该命令应用场景如下：

- 父节点用户给子节点用户分配虚拟配额
- 删除父节点用户分配给子节点用户的虚拟配额
- 父节点用户给自己分配虚拟配额
- 删除父节点用户分配给自己的虚拟配额

## 注意事项

- 本命令仅对M2M用户生效，即父节点用户和子节点用户的“用户身份”均为“Master”且不存在与之关联的从用户。

- 单个父节点用户下最多存在100个子节点用户（包括自己）。

- 单个子节点用户最多同时属于5个父节点用户（不包括自己）。

- 存在第二标识的用户不支持共享M2M虚拟配额。

- 单个子节点用户可以签约的非M2M虚拟配额个数加上从父节点用户当中共享的M2M虚拟配额个数不能超过105（PGW系统参数“MaxQuotaNumPerSub”最大值+25）。

- 单个子节点用户签约的业务加上从父节点用户获取的共享业务的总数最多64个（通过PGW系统参数“MaxSrvNumPerSub”控制）。

- 修改子节点用户的虚拟配额总量或者余额，导致配额状态由大变小时，此用户被该父节点用户共享的对应虚拟配额相关的所有通知抑制记录都会被清除。

- 父节点用户签约M2M共享业务后，如果执行此命令把分配给自己的虚拟配额删除了，则该父节点用户无法使用该配额关联的M2M共享业务。

- 当“操作类型”设置为“Delete”，若所有的配额名称参数均不设置，则删除该子节点用户共享该父节点用户的全部虚拟配额；若设置的配额名称在该用户中不存在，则系统忽略不处理；设置的配额总量、配额余量、优先级参数，系统忽略不处理。

当

“操作类型”

设置为

“Modify”

，通过该命令修改配额记录时，UPCF会根据表1 中参数修改后的计算结果计算配额的状态。

| 虚拟配额   | 参数修改项     | 参数修改后计算结果                              |
|:-------|:----------|:---------------------------------------|
| 已存在    | 总量        | 配额初始值=总量余额=MAX（0，总量-使用量）使用量保持不变优先级保持不变 |
| 已存在    | 余额        | 总量保持不变余额=修改后的余额使用量保持不变优先级保持不变          |
| 已存在    | 优先级       | 总量保持不变余额保持不变使用量保持不变优先级=修改后的优先级         |
| 已存在    | 总量、余额和优先级 | 配额初始值=总量余额=修改后的余额使用量保持不变优先级=修改后的优先级    |
| 已存在    | 无         | 总量保持不变余额保持不变使用量保持不变优先级保持不变             |
| 不存在    | 总量        | 配额初始值=总量余额=总量使用量=0优先级=254              |
| 不存在    | 余额        | 命令执行失败                                 |
| 不存在    | 优先级       | 配额初始值=总量余额=总量使用量=0优先级=修改后的优先级          |
| 不存在    | 总量、余额和优先级 | 配额初始值=总量余额=修改后的余额使用量=0优先级=修改后的优先级      |
| 不存在    | 无         | 配额初始值=父节点用户的总量余额=父节点用户的总量使用量=0优先级=254  |

| ENOPERATIONTYPE    | 操作类型     | 可选必选说明：必选参数 参数含义：用于设置M2M用户虚拟配额的操作类型。 取值范围：Modify：表示为子节点用户设置M2M虚拟配额的总量、余额或优先级。Delete：表示删除子节点用户的M2M虚拟配额信息。 默认值：Modify。 配置原则：无。                                                                                                                                                                                                                              |

## 使用实例

为子节点用户新增一个虚拟配额： “用户标识”为“46010381014\*\*\*\*”，“操作类型”为“Modify”，“子节点用户标识”为“46010381015\*\*\*\*”，“M2M配额名称”为“M2M\_Quota”，“M2M配额总量”为“560000”，“M2M配额余量”为“280000”，“M2M优先级”为“1”：

```
SET PM2MSHQUOTA: USRIDENTIFIER="46010381014****", ENOPERATIONTYPE=Modify, CHILDUSRIDENTIFIER="46010381015****", M2MQTANAME="M2M_Quota", M2MQUOTAVALUE=560000, M2MQUOTABALANCE=280000, M2MPRIORITY=1;
```
