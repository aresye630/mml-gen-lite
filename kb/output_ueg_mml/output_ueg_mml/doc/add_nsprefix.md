# 添加号段配置信息（ADD NSPREFIX）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，增加新号段，如果此号段的前段和已有号段相同，并指向新的Partition，会导致用户查找不到，产生垃圾数据。因此执行该命令前，需联系华为技术支持确认后再执行。

该命令为配置类命令，用于在配置数据库中增加一条号段配置信息的记录。

该命令的使用场景：在混合组网下，通过配置“Partition标识”，实现不同Partition间的负荷分担。通过配置“SPR Partition标识”，实现营帐MCI订阅通知消息可以发送到指向的SPR。

## 注意事项

- 当**SET PTSELSYSPARA**命令中参数“MixedNetworkSwitch”设置为1时，仅在营帐开户场景下，且用户为非从用户，配置的号段信息才生效。
- 在与UPCC组成混合组网N:1全路由组网场景，即**SET PARTITIONMODE**设置组网模式为“GLOBALROUTEBETRANS(全局路由BE转发)”时，才需要配置SPR Partition标识。

## 参数说明

| 参数标识        | 参数名称            | 参数说明                                                                                                                                                                                                                                                                |
|:------------|:----------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NSP         | 号段前缀            | 用于标识用户的号段前缀。用户开户，在进行号段匹配时，采用最大前缀匹配。例如，用户标识是1234，在号段配置中配置了123和1234，那么最终匹配的是1234。 取值范围：长度不超过15的字符串，大小写敏感。 默认值：无。  说明： 系统最多可配置40960条号段。配置为“default”时，表示当所配置的其他号段都匹配不上时，系统才会匹配到该配置。且配置需满足如下原则：仅在SET PARTITIONMODE命令中参数“Partition模式”设置为“全局路由BE转发”时才可配置。大小写不敏感。系统最多可配置1条。 |
| PID         | Partition标识     | 用于标识NSP号段所属的Partition ID。 取值范围：1～250。 默认值：无。                                                                                                                                                                                                                        |
| SPRPID      | SPR Partition标识 | 混合组网N:1全路由组网场景下必须携带，用于营帐操作触发的MCI订阅通知消息指定发送到对应的SPR。 在UPCF对接的多个SPR中，标识需要收到订阅通知的SPR Partition ID。 取值范围：1～250。 默认值：无。  说明： 本参数标识的SPR配置的号段前缀需要与DRA指向的UPCC号段前缀一致，即保证DRA通过号段指向FE对应的SPR与本参数对应的SPR为同一个。                                                                      |
| DESCRIPTION | 描述              | 用于标识号段的描述信息。 取值范围：长度不超过64字节的字符串。 默认值：无。                                                                                                                                                                                                                             |

## 使用实例

添加号段配置信息：“号段前缀”为“861234567\*\*\*\*”，“Partition标识”为“5”，“描述”为“abc”：

```
ADD NSPREFIX: NSP="861234567****", PID=5, DESCRIPTION="abc";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。
