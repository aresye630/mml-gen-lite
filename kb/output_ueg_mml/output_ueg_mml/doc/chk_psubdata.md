# 校验用户数据（CHK PSUBDATA）

## 命令功能

**须知** 

用户数据校验可能对USRSU虚拟机（对应裸机场景的usrsu-pod）性能产生影响，当任一USRSU虚拟机（对应裸机场景的usrsu-pod）的CPU高于60%时不建议执行本命令。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令以DSU Master节点数据为基准，对内存数据库中各节点的用户数据进行一致性校验。

## 注意事项

- 单用户校验数据，会对DRU性能有一定影响，因此不能用来做批操作处理。
- 执行本命令前，请在OM Portal“USCDB MML命令”界面执行**DSP NODECPUSTAT**（对应裸机场景DSP PODCPUSTAT）命令，查看虚拟机/裸机Pod的CPU信息，如果所有USRSU类型的虚拟机（对应裸机场景的usrsu-pod）CPU使用率不高于60%，可以直接执行本命令；如果任意一个USRSU虚拟机（对应裸机场景的usrsu-pod）的CPU使用率高于60%，请联系华为技术支持确认后再执行。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                             |
|:--------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 用于唯一标识一个用户的第一标识，用户的第一标识不允许与已有用户的第一标识和第二标识重名。对于移动和固定网络共存场景下，UPCF支持如下用户标识的组合： MSISDN+NAI：针对移动网络用户，开户时可采用MSISDN作为用户标识。针对固定网络用户，开户时可采用NAI作为用户标识。此时软参VRM_SUBSRCIPTIONIDTYPE取值应设置为0。IMSI+NAI：针对移动网络用户，开户时可采用IMSI作为用户标识。针对固定网络用户，开户时可采用NAI作为用户标识。此时软参VRM_SUBSRCIPTIONIDTYPE取值应设置为1。 取值范围：长度不超过255的字符串。 默认值：无。  说明： 移动网络中此参数类型受“VRM_SUBSRCIPTIONIDTYPE”软参控制，默认为“IMSI”。在CSP OM Portal “UPCF MML命令”界面执行MOD INSP命令可以修改该软参。软参的具体介绍请参见《软件参数》。 |

## 使用实例

单用户校验：“用户标识”为“460103901200002”：

```
CHK PSUBDATA: USRIDENTIFIER="460103901200002";
```
