# 清除配额信息（CLR PQUOTA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于清除配额信息，将用户配额剩余额置为零，用户消耗额置为配额初始值，用户配额状态置为耗尽。

## 注意事项

- 清除配额信息，可能使用户无法使用包含该配额的业务，请谨慎操作。
- 清除配额信息时，如果该配额有转移配额，则会把转移配额记录直接删除，且不生成转移配额的EDR记录。
- 配额所属用户的所有通知抑制记录将会被清除；如果该用户为主用户，其从用户除了虚拟配额的通知抑制记录不会被清除，其他所有与该配额相关通知抑制记录都会被清除。
- Sy类型的配额信息无法通过本命令清除。
- Pre-Sy类型的配额信息无法通过本命令清除。
- 从用户的虚拟配额信息无法通过本命令清除。
- UPCC Dynamic类型的配额无法通过本命令清除。
- 如果配额关联“重复订购方式”为“多配额记录重复订购”的业务，则该配额无法通过本命令清除。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                    |
|:--------------|:-------|:--------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 标识一条用户配额信息数据记录的关键字段之一，用于指定需要清除哪一个用户的配额信息。 取值范围：长度不超过255的字符串。 默认值：无。                                     |
| QTANAME       | 配额名称   | 标识一条用户配额信息数据记录的关键字段之一，用于指定需要清除用户的哪一个配额的信息。 配额名称必须是已存在的配额且该配额需要在UPCF Web UI上配置。 取值范围：长度不超过32的字符串。 默认值：无。 |

## 使用实例

清除配额信息：“用户标识”为“46010381014\*\*\*\*”，“配额名称”为“Volume\_Quota”：

```
CLR PQUOTA: USRIDENTIFIER="46010381014****", QTANAME="Volume_Quota";
```
