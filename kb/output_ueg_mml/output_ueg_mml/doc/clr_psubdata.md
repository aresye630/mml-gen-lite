# 清除用户数据（CLR PSUBDATA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

清理用户数据可能对USRSU虚拟机（对应裸机场景的usrsu-pod）性能产生影响，当任一USRSU虚拟机（对应裸机场景的usrsu-pod）的CPU高于60%时不建议执行本命令；同时可能删除主从所有数据，详见产品手册注意事项。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于强制删除用户的数据记录，包括用户的基本信息、用户签约业务信息、用户签约套餐信息、用户配额信息、用户帐户信息等。

当用户数据出现异常时，可使用此命令将用户数据清理掉。

## 注意事项

- 执行本命令会对DSU模块的性能有较大影响，不能在批操作中使用此命令。且执行本命令前，请在OM Portal“USCDB MML命令”界面执行**DSP NODECPUSTAT**（对应裸机场景DSP PODCPUSTAT）命令，查看虚拟机/裸机Pod的CPU信息，如果所有USRSU类型的虚拟机（对应裸机场景的usrsu-pod）CPU使用率不高于60%，可以直接执行本命令；如果任意一个USRSU虚拟机（对应裸机场景的usrsu-pod）的CPU使用率高于60%，请联系华为技术支持确认后再执行。
- 执行本命令后对于主从用户的数据会全部被清除。
- 该命令会强制清除用户数据，请在华为技术支持的指导下操作。
- 如果要清理的用户为组用户，且组内有成员用户存在，则返回失败，不允许执行该操作。
- 在主从用户场景下，不管是对主用户还是对从用户执行本命令时，都将删除这个主从关系内所有用户的数据。
- 直接清除企业配额场景下的成员用户，会导致“实际分配”的虚拟配额无法返还给组用户。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                       |
|:--------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 用于指定需要清除哪一条用户的数据记录，必须是已存在的用户。该参数必须先由ADD PSUB命令定义，然后才能在此处索引。 取值范围：长度不超过255的字符串。 默认值：无。                                                                                      |
| CLEARTYPE     | 清理类型   | 用于指定清理用户数据的类型。 取值范围： “All”：表示清除与该用户相关的所有的用户数据，包括主从用户关系内的所有用户数据。“Subscription”：表示清理该用户的签约数据中存在但全局数据中不存在的记录，包括用户签约的业务、套餐、配额和帐户，不会清理主从用户关系内的其他用户的签约数据，不支持对测试用户执行此操作。 默认值：All。 |

## 使用实例

清理普通用户（查不到主从用户数据）数据场景：强制清除用户ID为46010381014\*\*\*\*的用户数据，命令如下：

```
CLR PSUBDATA: USRIDENTIFIER="46010381014****";
```

清理主从用户数据场景：主用户ID为46010381014\*\*\*\*，从用户ID为460103810124002，若要强制清除主从用户数据，执行如下任意一条命令即可：

```
CLR PSUBDATA: USRIDENTIFIER="46010381014****";
CLR PSUBDATA: USRIDENTIFIER="460103810124002";
```

清理组用户（组内无成员用户）数据场景：强制清除用户ID为460103810124003的组用户数据，命令如下：

```
CLR PSUBDATA: USRIDENTIFIER="460103810124003";
```
