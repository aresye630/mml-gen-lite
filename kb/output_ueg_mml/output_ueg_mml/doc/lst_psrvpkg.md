# 查询用户签约套餐（LST PSRVPKG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询某个用户签约套餐的信息，包含套餐名称、套餐标识、订购时间、生效时间、截止时间、漫游类型和联系方式等信息。当用户漫游到其他时区后，为了站在用户的角度显示与时间相关的参数，包括套餐的订购时间、套餐的生效时间、套餐的截止时间，查询时可以指定用户的时区与用户时区的夏令时标识。

## 注意事项

夏令时参数用于标识查询的时区是否进入夏令时，因此不能只携带夏令时标识而不携带时区。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
|:--------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 用于指示系统需要按照哪个用户标识来查询用户签约套餐的信息。 取值范围：长度不超过255的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| TIMEZONE      | 时区     | 用于指示要查询用户所处的时区。 取值范围：“UTC-12:00”“UTC-11:00”“UTC-10:00”“UTC-09:30”“UTC-09:00”“UTC-08:00”“UTC-07:00”“UTC-06:00”“UTC-05:00”“UTC-04:30”“UTC-04:00”“UTC-03:30”“UTC-03:00”“UTC-02:00”“UTC-01:00”“UTC”“UTC+01:00”“UTC+02:00”“UTC+03:00”“UTC+03:30”“UTC+04:00”“UTC+04:30”“UTC+05:00”“UTC+05:30”“UTC+05:45”“UTC+06:00”“UTC+06:30”“UTC+07:00”“UTC+08:00”“UTC+09:00”“UTC+09:30”“UTC+10:00”“UTC+10:30”“UTC+11:00”“UTC+11:30”“UTC+12:00”“UTC+12:45”“UTC+13:00”“UTC+14:00” 默认值：无。  说明： 如果命令中没有携带时区，表示按当时地区进行查询。 |
| DSTFLAG       | 夏令时标识  | 用于指定用户所处时区是否进行夏令时。 取值范围：“Standard time”：表示正常时间。“Daylight saving time”：表示夏令时。“Winterzeit”：表示冬令时。 默认值：无。  说明： 如果命令中没有携带夏令时标识，表示按正常时间进行查询。                                                                                                                                                                                                                                                                                                                                                           |

## 使用实例

查询用户签约套餐：“用户标识”为“46010381014\*\*\*\*”：

```
LST PSRVPKG: USRIDENTIFIER="46010381014****";
```

输出结果如下：

```
%%LST PSRVPKG: USRIDENTIFIER="46010381014****";%%

Total count = 1

---    END
```

## 输出结果说明

| 输出项名称                 | 输出项解释                                                                                                                                                           |
|:----------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Service Package Name  | 用户签约的套餐名称。 取值范围：长度不超过32的字符串。                                                                                                                                    |
| Subscription Date     | 用户签约套餐的时间。 取值范围： NULL1970-01-01 00:00:00～2037-12-31 23:59:59：表示1970年01月01日00时00分00秒到2037年12月31日23时59分59秒之间的时间。                                                  |
| Start Date            | 用户签约套餐的生效时间。 取值范围： NULL1970-01-01 00:00:00～2037-12-31 23:59:59：表示1970年01月01日00时00分00秒到2037年12月31日23时59分59秒之间的时间。                                                |
| Expiry Date           | 用户签约套餐的失效时间。 取值范围： NULL1970-01-01 00:00:00～2037-12-31 23:59:59：表示1970年01月01日00时00分00秒到2037年12月31日23时59分59秒之间的时间。                                                |
| Roaming Type          | 用户签约套餐的漫游类型，具体可参考ADD PSRVPKG命令中关于“漫游类型”的解释。 取值范围：“NULL”：表示签约的套餐不是本地、漫游类型。“Local”：表示签约的套餐为本地类型。“Roaming”：表示签约的套餐为漫游类型。                                           |
| Contact Method        | 用于指定用户使用该套餐时的通知消息方式。 取值范围： “SMS”：表示以短信方式发送用户通知消息。“E-Mail”：表示以电子邮件方式发送用户通知消息。“SMS&E-Mail”：表示以短信和电子邮件方式发送用户通知消息。“None”：表示用户通知消息方式以开户（ADD PSUB）命令中设置的为准。           |
| Remained valid period | 用于标识套餐的剩余有效期。 取值范围：“DDDDHHMM”：1~4位表示天，5~6位表示小时，7~8位表示分钟，其取值范围为00000000~99992359。“NULL”：表示无法获取业务截止时间。“99992359”：当剩余有效期的天大于9999天。“00000000”：当剩余有效期的天、时、分都为0，秒不为0。 |
| Description           | 用于表示对该套餐的描述说明。 取值范围：长度为0～256字节的字符串。                                                                                                                             |
