# 转移配额信息（TSF PQUOTA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于执行配额转移操作，将指定用户的指定配额转给另一个用户的指定配额。

## 注意事项

- 用户接收的转移配额不支持转移给其他用户。

- 用户的累积配额不支持转移操作。
- 关联了允许重复订购业务的配额不支持转移操作。
- 每个用户最多可以有50个转移配额，每个用户的每个配额最多可以有10个转移配额。
- 转移配额不支持累积功能。
- 如果在转移配额的有效期内，接收用户的配额发生了复位，该用户仍然可以继续使用转移配额。
- 如果接收用户的同一个配额存在多个有效的转移配额，按照转移操作的时间先后顺序使用。
- 只有“是否支持配额转移”设置为“是”、“配额管理归属”为“UPCC”且“配额类型”为“流量”的配额支持转移操作。
- 组用户不支持配额转移操作，其成员用户共享使用组用户的虚拟配额也不支持配额转移操作，成员用户的签约配额支持配额转移操作。
- 主从用户单独签约的配额支持配额转移操作，主用户的转移配额可以共享给从用户使用，从用户的虚拟配额不支持转移操作。
- 转移配额的生效时间和截止时间以系统内设置的时间为准，不考虑时区间转换。
- 转移配额过期时不支持发送通知。
- 同一秒钟内，只支持对同一个用户同一个配额进行一次转入操作。
- 如果通过命令**SET PSYSPARA**设置参数“ReSubscription”的值为“4”且配额的“结账模式”为“不复位”或者配额的类型是单次型配额，不支持配额转移操作。如果设置参数“ReSubscription”的值不为“4”，系统内存在重复签约记录时，进行配额转移操作会将已有的重复签约记录删除。

## 参数说明

| 参数标识                 | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                    |
|:---------------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER        | 用户标识   | 用于指定需要从哪个用户的配额中转出。 取值范围：长度不超过255的字符串 默认值：无                                                                                                                                                                                                                                                              |
| QTANAME              | 配额名称   | 用于指定从转出用户的哪个配额下转出。 配额名称必须是已存在的配额且该配额需要在UPCF Web UI上配置。 取值范围：长度不超过32的字符串 默认值：无                                                                                                                                                                                                                           |
| TRANSINUSRIDENTIFIER | 转入用户标识 | 用于指定需要将配额转移给哪个用户。 取值范围：长度不超过255的字符串 默认值：无                                                                                                                                                                                                                                                               |
| TRANSINQTANAME       | 转入配额名称 | 用于指定需要将配额转移给转入用户的哪个配额。 取值范围：长度不超过32的字符串。 默认值：无。                                                                                                                                                                                                                                                         |
| TRANSFERREDVALUE     | 转移值    | 用于表示转移配额的大小。 取值范围：1～4294967294 单位：KB 默认值：无                                                                                                                                                                                                                                                              |
| STARTDATETIME        | 生效时间   | 用于表示转移配额的生效时间。生效时间要晚于系统当前时间，早于截止时间。如果不设置生效时间，表示立即生效。 取值范围：19700101000000～20371231235959，表示1970年01月01日00:00:00至2037年12月31日23:59:59。NULL，表示未设置转移配额生效时间。 默认值：NULL                                                                                                                                          |
| ENDDATETIME          | 截止时间   | 用于表示转移配额的截止时间。截止时间要晚于系统当前时间。如果不设置截止时间，以配额下次复位时间为准。如果配额下次复位时间早于生效时间，依次向后累加复位周期，直到复位时间晚于生效时间为止。 取值范围：19700101000000～20371231235959，表示1970年01月01日00:00:00至2037年12月31日23:59:59。NULL，表示未设置转移配额截止时间。 默认值：NULL                                                                                                 |
| NOTIFYINDICATION     | 通知指示   | 用于表示配额发生转移时，要发送通知给转出用户还是转入用户。 取值范围：None：表示转入用户和转出用户都不能接收通知All：表示转入用户和转出用户都能接收通知TransIn Only：表示只有转入用户能接收通知TransOut Only：表示只有转出用户能接收通知 默认值：无  说明： 该参数的取值与转入方通知和转出方通知的配置原则如下：如果“通知指示”设置为“All”或“TransIn Only”，需要在转入方配额中配置“转入方通知”，否则不能正常发送通知。如果“通知指示”设置为“All”或“TransOut Only”，需要在转出方配额中配置“转出方通知”，否则不能正常发送通知。 |

## 使用实例

用户标识为“46010381014\*\*\*\*”，配额为“Quota\_01”，转移10M配额给用户“460103810124002”，接收配额为“Quota\_02”：

`TSF PQUOTA: USRIDENTIFIER="46010381014****", QTANAME="Quota_01", TRANSINUSRIDENTIFIER="460103810124002", TRANSINQTANAME="Quota_02", TRANSFERREDVALUE=10240;`
