# 复位用户所有配额（RST PSUBALLQUOTA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于复位用户所有配额的信息。

## 注意事项

- 复位配额时，若配额剩余额处理方式为累积复位，那么配额剩余额的值是原配额剩余额的值与配额初始值之和，若配额剩余额处理方式为清零复位，那么配额剩余额的值为配额初始值。
- 本命令仅支持普通用户，组成员，主用户的配额复位，如果主用户下存在从用户，其从用户的虚拟配额也可复位。
- 本命令“复位方式”设置为“1”时，复位用户配额需要用户的所有配额满足复位条件才进行复位，如果有部分配额没到复位时间则不进行复位，即要么全部复位，要么全部不复位。
- 本命令对各类型配额的支持能力：
  1. Sy类型的配额无法通过本命令复位。
  2. UPCC Dynamic类型的配额无法通过本命令复位。
  3. 允许对Pre-Sy类型的私有配额进行复位处理，但只修改配额状态并计算下次复位时间，不涉及初始值、余额、消耗量的修改。
- 在累积配额按可配次数清零复位的场景中，通过该命令复位配额时，配额的已累积次数参数不会变化。
- 如果配额关联“重复订购方式”为“多配额记录重复订购”的业务，则该配额无法通过本命令复位。

## 参数说明

| 参数标识                   | 参数名称      | 参数说明                                                                                                                                                |
|:-----------------------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER          | 用户标识      | 标识一条用户信息数据记录，用于指定需要复位哪一个用户的配额信息。该参数必须先由ADD PSUB命令定义，然后才能在此处索引。该参数仅支持为用户的第一标识，不允许为用户的第二标识。 取值范围：长度不超过255的字符串。 默认值：无。                                 |
| RESETFLAG              | 复位方式      | 用于指示配额复位处理方式。 取值范围：0：表示强制复位，复位配额时不检查下次复位时间。1：表示复位配额时检查下次复位时间，若系统时间≥下次复位时间，则复位配额并根据配额复位类型计算下次复位时间；若当前系统时间＜下次复位时间，则不做复位也不更新下次复位时间，并返回90512错误码。 默认值：0。 |
| RESETSLAVEVIRTUALQUOTA | 复位从用户虚拟配额 | 用于指示在复位主用户共享配额时是否对从用户的虚拟配额进行复位。 取值范围：False：复位主用户共享配额时不复位从用户虚拟配额。True：复位主用户共享配额时复位从用户虚拟配额。 默认值：无。未携带该参数时，按取值“False”处理。                               |

## 使用实例

复位用户所有的配额信息：“用户标识”为“46010381014\*\*\*\*”，“复位方式”为“0”：

```
RST PSUBALLQUOTA: USRIDENTIFIER="46010381014****", RESETFLAG=0;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                  | 原因分析                               | 处理建议                                                    |
|------:|:-----------------------|:-----------------------------------|:--------------------------------------------------------|
| 90415 | 允许重复订购的业务，不允许复位配额信息。   | 重复订购业务，关联的配额是周期性复位类型的配额。           | 重复订购业务，只能关联一个非周期复位类型的配额，即One-Off或者Not Reset类型的配额。       |
| 90471 | 动态配额不支持此操作。            | 用户存在“配额管理归属”为“UPCC Dynamic”的配额。    | 确保用户所有配额的“配额管理归属”设置为“UPCC”或其他支持该操作的类型，重新执行本命令。          |
| 90512 | 系统时间小于下次复位时间，不允许复位配额。  | 复位配额时检查下次复位时间，且当前系统时间小于下次复位时间。     | 设置“复位方式”为“0”，重新执行本命令。                                   |
| 90552 | 不支持多配额记录重复订购类型业务。      | 复位的用户配额关联了“重复订购方式”为“多配额记录重复订购”的业务。 | 复位的用户配额不支持关联“重复订购方式”为“多配额记录重复订购”的业务。                    |
| 90714 | 当前用户没有可复位的配额。          | 用户无可复位的配额信息。                       | 无需复位。                                                   |
| 90715 | 该命令不支持复位组用户、从用户和M2M用户。 | 不支持该用户的配额复位。                       | 执行LST PSUB，获取“用户身份”为“MASTER”的用户标识。确认用户为非M2M用户后，重新执行本命令。 |
