# 查询M2M用户列表（LST PM2MUSERLIST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询M2M用户列表。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                    |
|:--------------|:-------|:------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 可选必选说明：必选参数 参数含义：用于指定M2M的父节点用户进行其子节点用户列表查询，必须是已经存在的用户，该参数必须先通过ADD PSUB命令定义，然后才能在此处索引。 取值范围：长度不超过255的字符串。 默认值：无。 配置原则：无。 |

## 使用实例

查询M2M用户列表，M2M父节点用户的“用户标识”为“46010381014\*\*\*\*”：

```
LST PM2MUSERLIST: USRIDENTIFIER="46010381014****";
```

输出结果如下：

```
%%LST PM2MUSERLIST: USRIDENTIFIER="46010381014****";%%
RETCODE = 0 Operation succeeded

Basic Information

2

Child List
46010381015****
46010381014****

Total count = 3

There is together 1 report

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息，输出项说明如表1所示。

该命令执行异常，会返回对应的错误码。

| 输出项名称        | 输出项解释                                        |
|:-------------|:---------------------------------------------|
| Child Number | 用于表示M2M的父节点用户下子节点用户的数量。 取值范围：1~100。          |
| Child List   | 用于表示M2M的父节点用户下子节点用户的用户标识。 取值范围：长度不超过255的字符串。 |
