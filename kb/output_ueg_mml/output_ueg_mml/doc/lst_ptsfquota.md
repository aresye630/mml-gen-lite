# 查询转移配额信息（LST PTSFQUOTA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询用户转移配额的信息：

- 如果要查询用户所有配额的转移记录，只需要输入“用户标识”参数。
- 如果要查询用户指定配额的转移记录，需要输入“用户标识”参数和“配额名称”参数。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                              |
|:--------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 用于指示系统需要按照哪个用户标识来查询用户转移配额信息。 取值范围：长度不超过255的字符串。 默认值：无。                                                                            |
| QTANAME       | 配额名称   | 用于指定需要查询用户的哪个转移配额的信息。如果不输入，表示查询该用户所有配额的转移记录。 该参数有以下注意事项：配额名称必须是已存在的配额且该配额需要在UPCF Web UI上配置。输入的配额不能是虚拟配额。 取值范围：长度不超过32的字符串。 默认值：无。 |

## 使用实例

1. 查询指定用户所有配额的转移配额记录。例如：查询用户“460103810124002”所有配额转移记录。

   ```
   LST PTSFQUOTA: USRIDENTIFIER="460103810124002";
   ```

   返回结果如下：

   ```
   %%LST PTSFQUOTA: USRIDENTIFIER="460103810124002";%%
   RETCODE = 0 Operation succeeded

   Quota Name                        Transfer Time                     Transferred Value                                                 Transferred Quota Balance                                         Transferred Quota Consumption                                     Transferred Quota Start Time                                      Transferred Quota End Time
   Quota02                           2015-05-16 12:33:56               10240                                                             10240                                                             0                                                                 2015-05-16 12:33:56                                               2015-05-17 01:00:00
   Quota01                           2015-05-16 12:31:13               2048                                                              2048                                                              0                                                                 2015-05-16 12:31:13                                               2015-05-17 01:00:00

   Total count = 2

   There is together 1 report

   ```
2. 查询用户指定配额的转移记录。例如：查询用户“460103810124002”的配额“Quota01”的转移记录。

   ```
   LST PTSFQUOTA: USRIDENTIFIER="460103810124002", QTANAME="Quota01";
   ```

   返回结果如下：

   ```
   %%LST PTSFQUOTA: USRIDENTIFIER="460103810124002", QTANAME="Quota01";%%

   ```

## 输出结果说明

该命令查询结果中各参数的含义如表1所示。

| 输出项名称                         | 输出项解释                                                                                                        |
|:------------------------------|:-------------------------------------------------------------------------------------------------------------|
| Quota Name                    | 表示转移的配额名称。 取值范围：长度不超过32的字符串。                                                                                 |
| Transfer Time                 | 表示配额转移的时间。 取值范围：19700101000000～20371231235959，表示1970年01月01日00:00:00至2037年12月31日23:59:59。                     |
| Transferred Value             | 表示配额转移值。 取值范围：0～4294967294。 单位：KB                                                                            |
| Transferred Quota Balance     | 表示转移配额剩余值。 取值范围：0～4294967294。 单位：KB                                                                          |
| Transferred Quota Consumption | 表示转移配额消耗值。 取值范围：0～4294967294。 单位：KB                                                                          |
| Transferred Quota Start Time  | 表示转移配额生效时间。 取值范围：19700101000000～20371231235959，表示1970年01月01日00:00:00至2037年12月31日23:59:59。NULL，表示未设置转移配额生效时间。 |
| Transferred Quota End Time    | 表示转移配额截止时间。 取值范围：19700101000000～20371231235959，表示1970年01月01日00:00:00至2037年12月31日23:59:59。NULL，表示未设置转移配额生效时间。 |

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释       | 原因分析                        | 处理建议                                                         |
|------:|:------------|:----------------------------|:-------------------------------------------------------------|
| 12302 | 用户不存在       | 输入的用户不存在。                   | 检查用户的标识是否正确，重新执行本命令。                                         |
| 12303 | 配额不存在       | 输入的要查询的配额不存在。               | 执行LST PQUOTA查询用户配额信息，检查输入的配额名称与对应用户的配额名称是否一致，重新执行本命令。        |
| 90394 | 虚拟配额不支持该操作  | 输入的要查询的配额是虚拟配额。             | 执行LST PQUOTA查询用户配额信息，核对要查询的配额名称，重新执行本命令。                     |
| 90482 | 指定的配额没有转移配额 | 输入的要查询的配额没有转移操作记录或转移配额已经过期。 | 出现该错误码说明当前系统中没有该配额的转移记录或转移配额已经过期。当只输入“用户标识”时能够查询用户所有配额的转移记录。 |
