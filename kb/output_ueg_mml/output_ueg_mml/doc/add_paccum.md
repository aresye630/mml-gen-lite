# 签约累计项（ADD PACCUM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在配置数据库中增加一条累计项数据记录。

一般意义上，累计项是指一段时间内用户累计消耗的流量配额或时间配额，系统可以通过定时检测历史累计项，来不断调整用户累计状态，从而根据累计状态的改变情况动态调整策略的下发。

## 注意事项

- 系统最多可以配置255个累计项。
- 一个用户可以分别签约多个会话累计项和周期累计项，但是累计项总数不得超过8个。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                             |
|:--------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 用于指定为哪个用户签约累计项，必须是已存在的用户。该参数必须先由ADD PSUB命令定义，然后才能在此处索引。 取值范围：长度不超过255的字符串。 默认值：无。 配置原则：不支持英文逗号（,）、英文分号（;），等号（=）、英文双引号（"）、英文单引号（'），连续两个及以上的百分号（%%），连续两个及以上的空格（ ）、mml报文起始符标识（+++）。 |
| ACCNAME       | 累计项名称  | 用于指定用户要签约的某个累计项，必须是已存在的累计项且该累计项需要在UPCF上配置。 取值范围：长度不超过32的字符串。 默认值：无。                                                                                                              |

## 使用实例

签约累计项：“用户标识”为“46010381014\*\*\*\*”，“累计项名称”为“AccuMulation\_01”：

```
ADD PACCUM: USRIDENTIFIER="46010381014****", ACCNAME="AccuMulation_01";
```
