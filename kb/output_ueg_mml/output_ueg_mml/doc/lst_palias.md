# 查询别名（LST PALIAS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令暂时停止使用。执行该命令只检查命令参数规范，如参数符合规范，则命名执行成功，并不返回任何查询结果。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                 |
|:--------------|:-------|:-----------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 用于指示系统需要按照哪个用户标识来查询用户别名数据。 取值范围：长度不超过255的字符串。 默认值：无。 |

## 使用实例

查询用户信息：“用户标识”为“46010381014\*\*\*\*”：

```
LST PALIAS: USRIDENTIFIER="46010381014****";
```

输出结果如下：

```
%%LST PALIAS: USRIDENTIFIER="46010381014****";%%
RETCODE = 0 Operation succeeded

There is together 1 report

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见本命令的参数说明。
