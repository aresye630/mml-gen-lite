## 命令功能

- 本命令用于对用户的配额信息进行修改，包括配额总量，用户配额剩余额和配额状态。
- 修改Pre-Sy类型配额的状态时，结合系统参数AddSubSwitch和AddServiceSwitch选项，有如下几种场景：
  - 对于正常开户，并且已签约该配额的用户，直接修改配额状态。
  - 对于正常开户，若该配额为用户的虚拟配额，不仅可以修改配额状态，还可以修改下次复位时间。
  - 对于未开户用户，AddSubSwitch和AddServiceSwitch值都为1时，自动开户并签约该配额关联的业务；否则，不自动开户和签约业务。
  - 对于动态开户的用户，AddSubSwitch和AddServiceSwitch值都为1时，删除动态用户数据后进行自动开户并签约该配额关联的业务；否则，不删除动态用户数据，也不自动开户和签约业务。

## 注意事项

- 通过本命令签约的业务，在签约时，“订购时计算”有效期的设置不生效。

- 在用户签约“多记录重复订购”业务场景下：
  - 用户首次签约业务但还未使用业务时，执行本命令修改配额“使用量”和“余额”不生效。
  - 用户首次签约业务且业务已在使用时，本命令支持修改配额“使用量”和“余额”。
  - 用户存在多条订购业务记录时，本命令不允许修改配额信息，返回错误码90418。

  **说明** 

  90418：允许重复订购的业务，不允许修改配额信息。

- 修改配额总量和剩余额时，配额所属用户的所有通知抑制记录将会被清除；如果该用户为主用户，其从用户的所有通知抑制记录也会被清除。

本命令对各类型配额的支持范围：

UPCC类型：

- 不允许修改配额状态。

用户是否允许修改配额复位时间具体请见表1所示。

| 用户类型   | 私有业务配额   | 普通业务共享配额   | 组业务共享配额   | M2M共享业务配额   | 虚拟配额   |
|:-------|:---------|:-----------|:----------|:------------|:-------|
| 普通用户   | 允许修改     | -          | 不允许修改     | -           | -      |
| 主用户    | 允许修改     | 允许修改       | 不允许修改     | -           | -      |
| 从用户    | 允许修改     | 不允许修改      | 不允许修改     | -           | 不允许修改  |
| 组用户    | 允许修改     | -          | 不允许修改     | -           | 不允许修改  |
| 成员用户   | 允许修改     | -          | 不允许修改     | -           | 不允许修改  |
| 父节点用户  | 允许修改     | -          | -         | 允许修改        | 不允许修改  |
| 子节点用户  | 允许修改     | -          | -         | -           | 不允许修改  |

- Pre-Sy类型：
  1. 仅允许修改配额状态和下次复位时间。
     - 配额状态，不管是普通用户、主从用户，还是组用户和成员用户，都可以修改生效。
     - 下次复位时间：普通用户、主用户、组用户和成员用户可以修改生效；如果是从用户的虚拟配额并携带下次复位时间参数，系统将忽略该参数，而从用户的私有配额的下次复位时间可以修改生效。
  2. 如果触发了开户流程，开户的用户类型只能是普通用户，不能是主从用户或者组用户、成员用户。

- Sy类型：无法通过本命令修改。

Provisioning类型：

- 不允许修改配额状态。

用户是否允许修改配额复位时间具体请见表2所示。

| 用户类型   | 私有业务配额   | 普通业务共享配额   | 组业务共享配额   | M2M共享业务配额   | 虚拟配额   |
|:-------|:---------|:-----------|:----------|:------------|:-------|
| 普通用户   | 允许修改     | -          | 不允许修改     | -           | -      |
| 主用户    | 允许修改     | 允许修改       | 不允许修改     | -           | -      |
| 从用户    | 允许修改     | 不允许修改      | 不允许修改     | -           | 不允许修改  |
| 组用户    | 允许修改     | -          | 不允许修改     | -           | 不允许修改  |
| 成员用户   | 允许修改     | -          | 不允许修改     | -           | 不允许修改  |
| 父节点用户  | 允许修改     | -          | -         | 允许修改        | 不允许修改  |
| 子节点用户  | 允许修改     | -          | -         | -           | 不允许修改  |

- 修改配额的余额仅本周期有效。

- 修改配额参数时不支持自动开户。

- 修改配额的总量的生效方式受PGW软参“ProvQtaValueModifyMode”控制。
  - 0：修改Provisioning类型配额的总量在本复位周期及后续复位周期一直生效。
  - 1：修改Provisioning类型配额的总量仅在本复位周期内生效，下一个复位周期恢复成签约时指定的配额总量。

- External SPR类型：不允许修改配额状态和复位时间。

- UPCC Dynamic类型：无法通过本命令修改。

- 如果配额关联“重复订购方式”为“多配额记录重复订购”的业务，则该配额无法通过本命令修改。

  **说明** 

  参数DEFQTASHAREVALUEFLAG、DEFQTASHAREVALUE、DEFQTASHAREPERCENT仅支持UPCC类型和Provisioning类型配额且不支持“一个配额属于多个业务”的场景。

- 本命令自动签约的支持范围：
  1. 主用户签约业务S1，S1中包含配额Q1，当从用户设置可以共享主用户配额Q1的虚拟配额时，系统不支持从用户通过本命令自动签约包含配额Q1的业务。
  2. 一个用户不能通过本命令自动签约多个关联同一Pre-Sy类型配额的业务。

- 执行本命令时，如果基础配额需要复位，需要先处理配额复位，如果存在过期的转移配额，则需要先清理过期的转移配额记录。

- 本命令对组共享业务支持范围：
  1. 当组用户签约的配额中“组配额分配方式”为“实际分配”时，不支持对组用户配额的总量进行修改，支持对组用户配额的余额进行修改。
  2. 组成员只能订购非组业务（GroupService=False），不能订购组业务（GroupService=True）。组用户既可以订购组业务，也可以订购非组业务。
  3. 对于Pre-Sy类型的配额，该命令只能为成员用户设定虚拟配额，不能为组用户设定虚拟配额。
  4. 单个组成员可设置的最大虚拟配额个数是5个。
  5. 不支持对成员用户虚拟配额的使用量和Delta消耗量进行修改，且修改组用户配额的使用量和Delta消耗量后，成员用户虚拟配额的使用量和Delta消耗量不会变化。
  6. 对于UPCC或Provisioning类型的配额，不允许修改复位时间。
  7. 本命令不支持非组用户订购组业务。

- 主从用户场景下，不支持对从用户虚拟配额的使用量和Delta消耗量进行修改，且修改主用户配额的使用量和Delta消耗量后，从用户虚拟配额的使用量和Delta消耗量不会变化。

- M2M用户（父子节点用户）场景下，不支持对子节点用户M2M虚拟配额的使用量和Delta消耗量进行修改，且修改父节点用户M2M配额的使用量和Delta消耗量后，子节点用户M2M虚拟配额的使用量和Delta消耗量不会变化。

## 使用实例

修改用户配额信息：“用户标识”为“46010381014\*\*\*\*”，“配额名称”为“Volume\_Quota”，“总量”为“300”：

```
MOD PQUOTA: USRIDENTIFIER="46010381014****", QTANAME="Volume_Quota", QTAVALUE=300;
```
