# IPv6地址查询会话信息（LST PSESSIONINFOBYIPV6）

- 注意事项

## 命令功能

该命令用于根据IPv6地址查询指定IPv6地址下的会话信息。

若要查询某个IPv6地址的会话，请输入“用户IPv6地址”。

## 注意事项

- 当前版本仅支持64位长度的IPv6地址进行查询，如果输入的IPv6地址超出64位，系统会自动匹配前64位进行查询。
- 查询到的结果包含用户的个人数据，如：IMSI、MSISDN等。因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护。例如：
  1. 采用安全的文件传输协议（如SFTP）传输文件。
  2. 并严格控制文件的访问权限。
  3. 及时清理数据文件。

  在从运营商网络获取数据前，必须要获得运营商的授权。

  若需从运营商网络中获取必要的数据，需要运营商维护人员对其中的个人数据进行匿名化处理，匿名化后的数据由运营商维护人员审核后提供，以防止个人数据泄露。匿名化处理工具可以在https://support.huawei.com/获取，获取方法请参见产品手册“匿名化工具安全策略”页面。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                 |
|:-------|:---------|:---------------------------------------------------------------------------------------------------------------------|
| UEIPv6 | 用户IPv6地址 | 可选必选说明：必选参数 参数含义：用于指定需要被查询会话信息的IPv6地址。 取值范围：符合IPv6格式要求的IPv6地址。 默认值：无。 配置原则：当前版本仅支持查询64位长度的IPv6地址，并且该IPv6地址暂不支持/64后缀。 |

## 使用实例

以IPv6地址为例查询该IP地址下的会话数据信息：“用户IPv6地址”为“2001:0db8:0000:0000:0000:0000:0000:0000”：

```
LST PSESSIONINFOBYIPV6: UEIPv6="2001:0db8:0000:0000:0000:0000:0000:0000";
```

输出结果如下：

```
%%LST PSESSIONINFOBYIPV6: UEIPv6="2001:0db8:0000:0000:0000:0000:0000:0000";%%
RETCODE = 0 Operation succeeded

Session Type      UEIP                                         USRMSISDN          APN
Gx                2001:0db8:0000:0000:0000:0000:0000:0000      46010381014****    ne

Total count = 1

There is together 1 report

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

| 输出项名称        | 输出项解释                  |
|:-------------|:-----------------------|
| Session Type | 表示该会话的接口类型。 取值范围： GxN7 |
| UEIP         | 表示该会话的用户IPv6地址。        |
| USRMSISDN    | 表示该会话的用户ID。            |
| APN          | 表示该会话所属的APN信息。         |

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释   | 原因分析                  | 处理建议                   |
|------:|:--------|:----------------------|:-----------------------|
| 98510 | 会话不存在。  | 使用“用户IPv6地址”查找会话信息失败。 | 重新输入其他的“用户IPv6地址”进行查询。 |
