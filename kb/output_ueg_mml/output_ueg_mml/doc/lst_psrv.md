# 查询用户签约（LST PSRV）

## 命令功能

本命令用于查询某个用户签约业务的信息，包含业务名称、订购时间、生效时间、截止时间、使用状态、漫游类型、业务有效天数、工作日生效时间段、休息日生效时间段和联系方式等信息。当用户漫游到其他时区后，为了站在用户的角度显示与时间相关的参数，包括订购时间、生效时间、截止时间、下次激活时间、激活开始时间、激活结束时间，查询时可以指定用户的时区与用户时区的夏令时标识。

## 注意事项

- 夏令时参数用于标识查询的时区是否进入夏令时，因此不能只携带夏令时标识而不携带时区。
- 仅支持查询用户未过期业务，用户已过期业务可通过**ADD EXPTASK**命令添加导出任务导出用户数据进行查询。
