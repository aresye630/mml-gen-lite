# 查询用户位置信息（LST PSUBLOC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询用户的位置信息。查询时如果有多条位置信息，则返回多条记录。

## 注意事项

- 本命令只针对当前指定用户的签约数据进行处理，不涉及从用户或组成员继承的共享业务。
- 位置信息的记录条数受软参VRM\_AUTORECUSRLOC的控制。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                         |
|:--------------|:-------|:---------------------------------------------|
| USRIDENTIFIER | 用户标识   | 用于指定需要查询哪个用户的位置信息。 取值范围：长度不超过255的字符串。 默认值：无。 |

## 使用实例

查询用户的位置信息，“USRIDENTIFIER”为“46010381014\*\*\*\*”。

```
LST PSUBLOC: USRIDENTIFIER="46010381014****";
```

## 输出结果说明

| 输出项名称                       | 输出项解释                                                                                                          |
|:----------------------------|:---------------------------------------------------------------------------------------------------------------|
| Service Name                | 用于表示业务名称。 取值范围：长度不超过64的字符串。                                                                                    |
| User Location Information   | 用于表示用户在相关业务放行小区成功使用业务的位置信息。 取值范围：长度不超过1024的字符串。                                                                |
| Failed Location Information | 用于表示用户在相关业务放行小区以外的其他小区使用业务失败的位置信息。 取值范围：长度不超过64的字符串。                                                           |
| Failed Time                 | 用于表示用户在相关业务放行小区以外的其他小区使用业务失败的时间。 取值范围：19700101000000～20371231235959，表示1970年01月01日00:00:00至2037年12月31日23:59:59。 |
