# 删除用户位置信息（RMV PSUBLOC）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于删除用户的位置信息。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                   |
|:--------------|:-------|:-------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 用于指定需要删除哪个用户的位置信息。该参数为必选参数。 取值范围：长度不超过255的字符串。 默认值：无。  |
| SRVNAME       | 业务名称   | 用于指定需要删除用户哪个业务的位置信息。该参数为必选参数。 取值范围：长度不超过64的字符串。 默认值：无。 |

## 使用实例

删除一条用户位置信息：“USRIDENTIFIER”为“46010381014\*\*\*\*”，“SRVNAME”为“s1”。

```
RMV PSUBLOC: USRIDENTIFIER="46010381014****", SRVNAME="s1";
```
