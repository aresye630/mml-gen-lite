# 修改签约状态（MOD PSRVSTATUS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于对用户签约某个业务的签约状态进行修改。

## 注意事项

修改用户签约状态，可能会中断用户正在使用的业务，请操作员在执行该操作之前仔细确认任务的可行性。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                     |
|:--------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 标识用户签约信息的关键字段之一（其取值不能被修改），用于指定需要修改哪个用户的签约状态。 取值范围：长度不超过255的字符串。 默认值：无。                                                                                                                   |
| SRVNAME       | 业务     | 标识用户签约信息关键字段之一（其取值不能被修改），用于指定需要修改用户哪个业务的签约状态。 取值范围：长度不超过64的字符串。 默认值：无。                                                                                                                   |
| SRVSTATUS     | 签约状态   | 用于指定用户签约业务的状态，用于确定该业务是否可用。 取值范围：“Normal”：表示用户签约的业务是正常状态。“Frozen”：表示用户签约的业务是冻结状态。 默认值：无。  说明： 如果用户签约的业务是“Frozen”状态，该用户无法使用该业务，用户如果需要使用该业务则要把签约状态修改为“Normal”。如果是Turbo Button业务则用户不能修改签约状态。 |

## 使用实例

修改用户签约状态：“用户标识”为“46010381014\*\*\*\*”，“业务”为“Volume\_5M”，“签约状态”为“Frozen”：

```
MOD PSRVSTATUS: USRIDENTIFIER="46010381014****",SRVNAME="Volume_5M",SRVSTATUS=Frozen;
```
