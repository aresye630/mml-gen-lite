# 修改用户签约数据（MOD PSUBVER）

## 命令功能

**须知** 

该命令属于高危命令，修改用户签约数据，如果执行不当会影响业务处理。因此执行该命令前，需联系华为技术支持确认后再执行。

该命令用于对指定用户进行签约数据改造，与策略生命周期管理功能配合使用，提前观察目标版本的策略数据实际上线的效果。

## 注意事项

- 该命令执行成功后会将正式用户修改为测试用户，为避免破坏系统当前正式用户及签约数据，在执行该命令前新建一个正式用户并签约若干业务，再对该用户执行该命令。
- 如果要观察用户签约数据改造的结果，需要在UPCF Web UI上将相应的Release或Draft版本提交在线测试（Testing）。
- 不支持对测试用户进行签约数据改造。
- 不支持对从用户或者从用户的主用户进行签约数据改造。
- 不支持对在线用户进行签约数据改造。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                              |
|:--------------|:-------|:----------------------------------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 用于指定为哪个用户修改签约数据，必须是已存在的用户。用户标识必须输入用户的第一标识，不允许使用用户的第二标识。 取值范围：长度不超过255的字符串。 默认值：无。 |
| TARGETVERID   | 目标版本ID | 标识期望用户使用的Release或Draft版本ID，可通过在UPCF Web UI界面查看版本信息确定。 取值范围：0～3。 默认值：无。            |

## 使用实例

使用版本ID为2的策略数据，对用户46010381014\*\*\*\*的签约数据进行修改。

```
MOD PSUBVER: USRIDENTIFIER="46010381014****", TARGETVERID=2;
```
