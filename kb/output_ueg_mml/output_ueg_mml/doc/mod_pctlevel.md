# 修改用户自定义阈值（MOD PCTLEVEL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于给指定用户修改指定Quota或指定Account下的自定义阈值，包括自定义阈值1、自定义阈值2和自定义阈值3等。

## 注意事项

- 自定义阈值1、自定义阈值2和自定义阈值3至少要填充一个。
- 配额或帐户所属用户的所有通知抑制记录将会被清除；如果当前用户是主用户，则删除其从用户的通知抑制记录。
- 该命令不支持修改从用户的虚拟配额中自定义阈值属性。
- 如果配额关联“重复订购方式”为“多配额记录重复订购”的业务，则该配额的自定义阈值无法通过本命令修改。

## 参数说明

| 参数标识          | 参数名称    | 参数说明                                                                                            |
|:--------------|:--------|:------------------------------------------------------------------------------------------------|
| USRIDENTIFIER | 用户标识    | 标识用户签约信息的关键字段之一（其取值不能被修改），用于指定需要修改哪个用户的签约信息。 取值范围：长度不超过255的字符串。 默认值：无。                          |
| LEVELTYPE     | 阈值类型    | 用于设置修改用户自定义阈值的类型。 取值范围： “Quota”“Account” 默认值：无。                                                 |
| QTAACTNAME    | 配额/帐户名称 | 用于指定需要修改用户的哪个配额/帐户的自定义阈值。 配额/帐户名称必须是已存在的配额/帐户且该配额/帐户需要在UPCF Web UI上配置。 取值范围：长度不超过32的字符串。 默认值：无。 |
| CUSTOMLEVEL1  | 自定义阈值1  | 设置级别为CustomLevel1时的具体阈值。 取值范围：0～500000。 默认值：无。                                                  |
| CUSTOMLEVEL2  | 自定义阈值2  | 设置级别为CustomLevel2时的具体阈值。 取值范围：0～500000。 默认值：无。                                                  |
| CUSTOMLEVEL3  | 自定义阈值3  | 设置级别为CustomLevel3时的具体阈值。 取值范围：0～500000。 默认值：无。                                                  |

## 使用实例

修改自定义阈值：“用户标识”为“46010381014\*\*\*\*”，“阈值类型”为“Quota”，“配额名称”为“Volume\_Quota”，“自定义阈值1”为“50”，“自定义阈值3”为“90”：

```
MOD PCTLEVEL: USRIDENTIFIER="46010381014****", LEVELTYPE=Quota, QTAACTNAME="Volume_Quota", CUSTOMLEVEL1=50, CUSTOMLEVEL3=90;
```
