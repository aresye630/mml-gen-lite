# 查询操作日志（LST PLOG）

## 命令功能

**须知** 

查询营帐日志可能对USPMU/USPID3虚拟机（对应裸机场景的uspid3-pod）性能产生影响，当USPMU/USPID3虚拟机（对应裸机场景的uspid3-pod）的CPU高于60%时不建议执行本命令。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于查询UPCF业务操作日志记录。

## 注意事项

- 执行本命令前，在OM Portal“USCDB MML命令”界面执行**DSP NODECPUSTAT**（对应裸机场景DSP PODCPUSTAT）命令，查看虚拟机/裸机Pod的CPU信息，如果所有USPMU/USPID3类型的虚拟机（对应裸机场景的uspid3-pod）CPU使用率不高于60%，可以直接执行本命令。如果任意一个USPMU/USPID3虚拟机（对应裸机场景的uspid3-pod）的CPU使用率高于60%，且所有PGW模块都部署在USPID3虚拟机（对应裸机场景的uspid3-pod）上，此时执行本命令可能会导致营帐消息处理性能有所下降，会影响系统性能与业务处理，需要联系华为技术支持确认后再执行。如果任意一个USPMU /USPID3虚拟机（对应裸机场景的uspid3-pod）的CPU使用率高于70%，执行本命令会导致营帐消息处理性能大幅下降，会严重影响系统性能与业务处理，此时禁止执行本命令。

- 此查询命令功能类似于System Management下的LST LOG命令。需要区分的是：
  - 如果只需要查询UPCF的业务操作日志记录，不需要查询其他网元的操作日志，建议使用LST PLOG，否则请使用LST LOG。
  - 如果需要查询某用户标识相关的UPCF操作日志记录，建议使用LST PLOG，否则也可使用LST LOG。

## 参数说明

| 参数标识            | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                                                                        |
|:----------------|:------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OPNAME          | 操作员名称       | 操作员名称。 取值范围：不超过32位的字符串，由数字和字母组成，且首字符必须为字母。 缺省值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                  |
| USRIDENTIFIER   | 用户标识        | 指定查询哪个用户的操作日志。 取值范围：不超过255位的字符串。 缺省值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                            |
| STARTTIME       | 开始时间        | 用于指示系统需要按照指定的“开始时间”来查询操作日志；若不输入，则表示查询所有时间的操作日志。 取值范围：为19位的字符串，“YYYY&MM&DD&HH&MM&SS”的字符串。 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                    |
| ENDTIME         | 结束时间        | 用于指示系统需要按照指定的“结束时间”来查询操作日志；若不输入，则表示查询所有时间的操作日志。 取值范围：为19位的字符串，“YYYY&MM&DD&HH&MM&SS”的字符串。 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                    |
| CMD             | 命令名         | 用于指示系统需要按照指定的“命令名”来查询操作日志；若不输入，则表示查询所有命令名称的操作日志。 取值范围：不超过20位的字符串。 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                           |
| RESULT          | 执行结果        | 用于指示系统需要按照指定的“执行结果”来查询操作日志；若不输入，则表示查询所有执行结果的操作日志。 取值范围：SUCCESSERROR 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                         |
| MSGTYPE         | 消息类型        | 用于指示系统需要按照指定的“消息类型”来查询操作日志；若不输入，则表示查询所有消息类型的操作日志。 取值范围：MMLSOAP 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                              |
| SAVEAS          | 保存文件名       | 用于指示系统需要按照指定的“保存文件名”来保存操作日志到文件。 如果此参数没有输入值，则不会保存为文件，查询结果显示在“PGW Web LMT”上，最大记录数为150。如果此参数有输入值，则会保存为文件，查询结果保存在文件中，最大记录数为1000000。所指定的文件，可以通过“PGW Web LMT”界面右上角的“文件管理器”下载。“保存文件名”参数指定的文件存放在主备PGW模块所在虚拟机/裸机Pod上，虚拟机/裸机Pod目录为“/opt/pgw/pgwtmpfile/SYSNO+OPNAME”。SYSNO默认为3位数字，不足3位时前面补0。如：SYSNO=1，OPNAME=admin时，最后一层目录为001admin。 取值范围：不超过20位的字符串。 默认值：无。 说明：可选参数。 |
| INCLUDEBAT      | 是否包含批操作命令   | 用于指示系统是否需要在查询的操作日志中包含批操作任务中执行的命令。 如果查询时该参数取值为“YES”，则查询的结果中包含批操作中执行的命令；如果查询时该参数取值“NO”，则查询的结果中不包含批操作中执行的命令；如果查询时该参数不输入，则需看TASKID是否有输入：如果有输入，则包括此批操作任务中执行的命令；否则不包含批操作任务中执行的命令。 取值范围：YESNO 默认值：无。 说明：可选参数。                                                                                                                                                      |
| TASKID          | 批操作任务ID     | 用于指示系统按照指定的“批操作任务ID”来查询操作日志。 如果查询时该参数不输入，则需看INCLUDEBAT是否有输入。如果有输入且为YES，查询的结果中包含所有批操作中执行的命令；否则查询的结果中不包含批操作中执行的命令。如果查询时该参数有输入，则查询的结果中包含此批操作任务中执行的命令。 可以在System Management下使用CHK BATSTAT命令来查询批操作任务ID。 取值范围：1～2147483647 默认值：无。 说明：可选参数。                                                                                                                        |
| DISPLAYOPRLOGIP | 是否显示IP和端口信息 | 用于指示系统是否需要在查询的操作日志中显示执行命令的客户端的IP和端口号。 如果查询时该参数取值为“YES”，则查询的结果中显示操作日志的IP和端口信息；如果查询时该参数取值“NO”或者该参数未输入，则查询的结果中不显示操作日志的IP和端口信息。 取值范围：YESNO 默认值：无。 说明：可选参数。                                                                                                                                                                                                      |
