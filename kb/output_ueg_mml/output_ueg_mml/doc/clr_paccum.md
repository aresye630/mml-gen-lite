# 清除累计项值（CLR PACCUM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令根据清除类型，清除配置数据库中用户的当前周期累计数据或历史累计数据。

## 注意事项

清除累计项值，会使用户累计量处于初始状态，从而改变用户的业务体验，请操作员在执行该操作之前仔细确认任务的可行性。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                          |
|:--------------|:-------|:--------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 标识一条用户累计项数据记录的关键字段之一（其取值不能被修改），用于指定需要清除哪一个用户的累计项配置数据记录。 取值范围：长度不超过255的字符串。 默认值：无。                             |
| ACCNAME       | 累计项名称  | 标识一条用户累计项数据记录的关键字段之一（其取值不能被修改），用于指定需要清除用户哪一条累计项数据记录，操作员可以使用LST PACCUM命令查询获得。 取值范围：长度不超过32的字符串。 默认值：无。         |
| ACCCLEARTYPE  | 清除类型   | 用于指定需要清除累计项值的类型。 取值范围： “Current”：表示清除当前周期累计数据。“History”：表示清除历史累计数据。“All”：表示清除累计项当前周期累计数据和历史累计数据。 默认值：Current。 |

## 使用实例

清除累计项值：“用户标识”为“46010381014\*\*\*\*”，“累计项名称”为“AccuMulation\_01”，“清除类型”为“History”：

```
CLR PACCUM: USRIDENTIFIER="46010381014****", ACCNAME="AccuMulation_01", ACCCLEARTYPE=History;
```
