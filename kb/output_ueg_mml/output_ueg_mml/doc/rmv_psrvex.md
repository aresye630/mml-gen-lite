# 删除签约信息增强（RMV PSRVEX）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令执行不当可能删除多条签约业务及重复订购记录，详见产品手册注意事项。因此执行该命令前，需要与华为技术支持确认后才可以实施。

本命令用于删除用户签约中所有过期业务的签约信息。若不指定业务名称，则删除用户签约中所有过期业务；若指定删除的业务名称，则也可删除未过期业务。

## 注意事项

- 重复订购场景下，若不指定业务名称，重复签约记录都过期，删除全部记录，如果只有部分过期，则删除过期的记录；若指定删除的业务名称，则删除所有指定的业务记录。
- 执行本命令时如果携带业务名，则删除对应业务的所有签约记录(包含过期、未过期的多业务重复订购记录和多配额重复订购记录)。
- 执行本命令时如果未携带业务名，则删除所有业务的所有签约记录中过期的记录（包含过期的多业务重复订购记录和多配额重复订购记录）。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                 |
|:--------------|:-------|:-------------------------------------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 标识用户签约信息的关键字段之一，用于指定需要删除哪一个用户的签约信息。 取值范围：长度不超过255的字符串。 默认值：无。                        |
| SRVNAME       | 业务     | 标识用户签约信息的关键字段之一，用于指定需要删除用户哪个业务的签约信息。如果指定该参数，删除的业务可以是过期或未过期。 取值范围：长度不超过64的字符串。 默认值：无。 |

## 使用实例

删除用户所有过期业务：“用户标识”为“46010381014\*\*\*\*”：

```
RMV PSRVEX: USRIDENTIFIER="46010381014****";
```
