# 删除签约套餐信息（RMV PSRVPKG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于删除用户签约某个套餐的签约信息，包括套餐名称、订购时间、生效时间、截止时间、漫游类型等。

用户签约的某个套餐信息被删除后，用户将不能再使用该套餐。

## 注意事项

- 当用户所签约的业务和套餐都被删除时，用户将无法接入网络，请操作员在执行该操作之前仔细确认任务的可行性。
- 当用户所签约的套餐被删除时，该用户此套餐的所有业务相关的通知抑制记录将会被清除。如果该用户下存在从用户，那么从用户下此套餐的所有业务相关的通知抑制记录也会被清除。
- 执行本命令时，不生成转移配额的EDR记录。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                  |
|:--------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 标识用户签约信息的关键字段之一，用于指定需要删除哪一个用户的签约信息。 取值范围：长度不超过255的字符串。 默认值：无。                                                                                         |
| SRVPKGNAME    | 套餐     | 标识用户签约信息的关键字段之一，用于指定需要删除用户哪个套餐的签约信息。 取值范围：长度不超过32的字符串。 默认值：无。                                                                                         |
| TERMIND       | 终止类型   | 删除签约的方式。 取值范围： “Immediate termination”：表示命令执行后，立即删除签约的套餐。“Valid till expiry date”：表示命令执行后，周期复位的配额中最近的一个下次复位时间时，该套餐和套餐业务过期。 默认值：Immediate termination。 |

## 使用实例

删除签约套餐信息：“用户标识”为“46010381014\*\*\*\*”，“套餐”为“Volume\_ServPkg”：

```
RMV PSRVPKG: USRIDENTIFIER="46010381014****", SRVPKGNAME="Volume_ServPkg";
```
