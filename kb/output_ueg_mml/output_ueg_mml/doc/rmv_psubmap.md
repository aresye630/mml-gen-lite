# 删除多卡用户关联关系（RMV PSUBMAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用来删除多卡用户与从用户的关联关系。

## 注意事项

无。

## 参数说明

| 参数标识               | 参数名称   | 参数说明                                         |
|:-------------------|:-------|:---------------------------------------------|
| USRTHIRDIDENTIFIER | 多卡用户标识 | 用于标识Multi-SIM用户的标识。 取值范围：长度不超过20的字符串。 默认值：无。 |

## 使用实例

删除多卡用户关联关系：“多卡用户标识”为“1sa1multisim01”：

```
RMV PSUBMAP: USRTHIRDIDENTIFIER="1sa1multisim01";
```
