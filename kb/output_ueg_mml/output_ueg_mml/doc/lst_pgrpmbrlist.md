# 查询组成员列表（LST PGRPMBRLIST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询某个用户组的成员列表，包括组成员个数和组成员标识列表。

## 注意事项

- 如果组成员个数小于等于100，则显示用户组下所有成员的标识。
- 如果组成员个数超过100，只显示用户组下的成员个数，并提示通过**ADD EXPTASK**命令添加导出任务导出组用户标识和组成员标识列表。若导出指定组的所有成员列表，则采用的导出模板为Assigned\_GroupTemplate\_Online.xml；若导出系统中所有组的所有成员列表，则采用的导出模板为GroupTemplate\_Online.xml。
- 如果组成员列表里的成员大量退组或者销户，则需要通过离线扫描任务更新组成员列表。在混合组网下，会优先将先进行离线扫描分区里的组成员刷新到组成员列表。
- 如果用户组中没有成员，则查询结果返回组成员个数为0，不返回组成员标识列表。
- 支持使用组用户的第二标识查询，查询结果显示组成员的第一标识。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                             |
|:--------------|:-------|:---------------------------------------------------------------------------------|
| GRPIDENTIFIER | 组用户标识  | 用于指定查询哪一个用户组的成员列表。 取值范围：长度不超过255的字符串。 默认值：无。  说明： 该参数必须先由ADD PSUB命令定义，然后才能在此处索引。 |

## 使用实例

查询组成员列表，“组用户标识”为“Group001”：

```
LST PGRPMBRLIST: GRPIDENTIFIER="Group001";
```

## 输出结果说明

| 输出项名称         | 输出项解释                              |
|:--------------|:-----------------------------------|
| Member Number | 表示组成员个数。 取值范围：0～10000              |
| Member List   | 表示用户组下的组成员用户标识。 取值范围：长度不超过255的字符串。 |
