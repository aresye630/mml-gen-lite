# 修改签约信息（MOD PSRV）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于对用户签约某个业务的签约信息进行修改或调整，包括订购时间、生效时间、截止时间、使用状态、漫游类型、有效期、工作日生效时间段选择、休息日生效时间段选择和联系方式等。

修改Provisioning管理的配额初始值。

## 注意事项

- 修改签约信息，可能会导致用户不能签约其他业务，或者影响用户使用业务的时间，请操作员在执行该操作之前仔细确认任务的可行性。
- 当业务属于某个套餐时，除了业务下的“联系方式”之外，其他参数不能修改。
- 业务订购时间可晚于系统当前时间。
- 业务生效时间可早于或晚于订购时间，两者不做限制。
- 业务截止时间需晚于业务订购时间和生效时间，且晚于系统当前时间。
- 若用户的“付费类型”是“Prepaid”，且业务关联的帐户或配额的“结帐周期模式”是“自然月”，如果修改用户签约信息的“生效时间”，用户帐户或配额的“Next Reset Date Time”不变，但在手动复位或到达复位时间之后，会根据修改后的签约信息的“生效时间”重新计算。
- 修改工作日或者休息日时间段选择参数时，勾选DELETEALL选项表示用户签约的自定义时间段业务在工作日或休息日所有时间段无效。
- 修改Provisioning管理的配额初始值成功后，要到下个复位周期生效。
- 当用户通过更新签约信息来激活Turbo Button业务时，如果该业务下所有配额已经耗尽，且激活时长开关已打开，返回激活失败。
- 该命令不用于修改组业务的“订购时间”，修改组业务时如果携带了参数“订购时间”，系统将会对该参数不做处理。
- 当用户业务的“重复订购方式”配置为“多配额记录重复订购”时，则通过本命令仅支持修改该业务的“签约状态”。
- 当配额累计方式配置为“剩余额处理方式”中的“有效期累积”时，若执行**MOD PSRVPKG**/**MOD PSRV**命令修改用户签约套餐/业务的“生效时间”或“截止时间”，则会将该业务关联配额的上周期剩余累积配额清空。
