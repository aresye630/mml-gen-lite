# 替换签约信息（SWP PSRV）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于为用户删除一个旧业务的同时签约一个新的业务。

## 注意事项

- 一个用户最多可签约的业务数（包含已实例化的动态签约业务数）由PGW系统参数“MaxSrvNumPerSub”控制，默认签约32个业务，最多支持签约64个业务（其中MULTI\_SERVICE\_APN类型的业务不能超过10个，BOD\_SERVICE类型的业务不能超过10个，BOD\_SERVICE类型且默认激活的业务最多一个）。
- 一个用户只能有一个帐户，即用户所签约的业务中，若为业务配置了帐户，则必需是同一个帐户。
- 当用户签约业务时，该用户下与此业务相关的通知抑制记录将会被清除。如果该用户下存在从用户，则从用户下此业务相关的通知抑制记录也会被清除。当本次操作为重复签约时，不删除通知记录，只影响业务的有效期。
- 从用户默认共享主用户的业务、帐户和配额。
- 主、从用户签约含有相同配额的业务时，处理方式如下：
  - 主用户签约业务S1，S1中包含配额Q1，因为从用户默认签约主用户签约的业务，因此不建议从用户签约含有Q1配额的业务。
  - 从用户签约业务S1，S1中包含配额Q1，因为从用户默认签约主用户签约的业务，因此不建议主用户签约含有Q1配额的业务。
  - 主用户签约业务S1，S1中包含配额Q1，当从用户设置可以共享主用户配额Q1的虚拟配额时，系统不支持从用户签约包含配额Q1的业务。
- 一个用户不能签约多个关联同一Provisioning定义配额的业务。
- 当用户通过签约业务来激活Turbo Button业务时，如果该业务的所有配额已经耗尽，且激活时长开关已打开，则返回激活失败。
- “所属网络类型”为“LocalService”的用户仅支持签约“VRM\_BD\_SERVICE\_LOCAL”类型的业务，其他网络类型的用户不支持签约“VRM\_BD\_SERVICE\_LOCAL”类型的业务。

- 仅支持普通用户，组成员，主从用户进行业务替换。
- 新旧业务均需有且仅关联一个“配额类型”为“UPCC”或“Provisioning”的配额。
- 如果新业务与已签约的旧业务属于订购互斥组中，则不支持业务替换。
- 不支持M2M用户且不支持M2M业务进行替换。
- 不支持“重复订购方式”为“多记录重复订购”和“多配额记录重复订购”的业务。
- 如果旧业务属于平滑期业务，则不支持业务替换。

## 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                                          |
|:---------------|:-------|:--------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER  | 用户标识   | 用于指定为哪个用户替换签约业务，必须是已存在的用户。该参数必须先由ADD PSUB命令定义，然后才能在此处索引。该参数仅支持为用户的第一标识，不允许为用户的第二标识。 取值范围：长度不超过255的字符串。 默认值：无。 |
| OLDSERVICENAME | 旧的业务名称 | 用于指定用户要删除的某个业务，必须是已存在的业务且该业务需要在UPCF上配置。 取值范围：长度不超过64的字符串。 默认值：无。  说明： 该参数不支持设置为平滑期业务。                         |
| NEWSERVICENAME | 新的业务名称 | 用于指定用户要签约的某个业务，必须是已存在的业务且该业务需要在UPCF上配置。 取值范围：长度不超过64的字符串。 默认值：无。                                              |

## 使用实例

替换用户的签约业务：“用户标识”为“46010381014\*\*\*\*”，“旧的业务名称”为“Volume\_5M”，“新的业务名称”为“Volume\_20M”：

```
SWP PSRV: USRIDENTIFIER="46010381014****", OLDSERVICENAME="Volume_5M", NEWSERVICENAME="Volume_20M";
```
