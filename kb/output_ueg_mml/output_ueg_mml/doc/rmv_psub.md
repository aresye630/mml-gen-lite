# 销户（RMV PSUB）

## 命令功能

本命令用于删除某个用户的数据记录，包括用户的基本信息、用户签约业务信息、用户签约套餐信息、用户配额信息、用户帐户信息等。

## 注意事项

- 若删除的是主用户，则必须保证主用户下没有从用户，否则不允许删除主用户，若删除的是从用户，从用户关联的多卡用户也会被删除。
- 删除用户后，用户将无法接入网络，若用户在线，将会被迫下线，请操作员在执行该操作之前仔细确认任务的可行性。
- 若删除的是组用户，且组用户下面有成员用户，则不允许删除。
- 若删除的是成员用户，则强制成员用户退出用户组，并删除其数据记录。
- 执行本命令时，不生成转移配额的EDR记录。
- 当一个用户属于多个组，如果在退组过程中失败，则不需要回滚，系统会返回错误码，由营帐侧逐个退组后再删除用户。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                  |
|:--------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 标识一条用户数据记录的关键字段，用于指定需要删除哪一条用户数据记录。用户标识可以为用户第一标识，也可以为用户第二标识。 取值范围：长度不超过255的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                 |
| USRFORCERMV   | 强制删除用户 | 用于标识是否强制删除用户。 取值范围： “No”：用户无可用业务时才进行删除。“Yes”：强制删除用户。“No check USRCUSTOMERATTR as well”：用户无可用业务且用户自定义属性无效时才进行删除。 默认值：Yes。  说明： 若“强制删除用户”为“No”，仅当同时满足以下条件时，则认为用户没有可用业务。用户没有主从关系，并且不是组用户，也不是组成员，也不是父节点用户，也不是子节点用户。用户没有签约业务或者所签业务均已过期。仅检查静态签约业务，包括套餐业务，不包括动态业务和外置SPR业务。 若“强制删除用户”为“No check USRCUSTOMERATTR as well”，仅当同时满足以下条件时，则认为用户没有可用业务。用户没有主从关系，并且不是组用户，也不是组成员。用户没有签约业务或者所签业务均已过期。仅检查静态签约业务，包括套餐业务，不包括动态业务和外置SPR业务。 |

## 使用实例

销户：“用户标识”为“46010381014\*\*\*\*”，强制删除用户：

```
RMV PSUB: USRIDENTIFIER="46010381014****", USRFORCERMV=Yes;
```

## 输出结果说明

该命令执行异常，会返回对应的错误码。常见错误码如错误码列表所示：

|   错误码 | 错误码解释                   | 原因分析                          | 处理建议            |
|------:|:------------------------|:------------------------------|:----------------|
| 90601 | 用户退组失败。                 | 当一个用户属于多个组，并在退组过程中失败时，返回此错误码。 | 需由营帐逐个退组后再删除用户。 |
| 90659 | 混合组网时，组用户不在本地，请在UDR上操作。 | 混合组网时，组用户不在本地。                | -               |
