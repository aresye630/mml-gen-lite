# 查询测试用户信息（LST PTESTSUB）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询当前系统中的所有测试用户标识，方便统计管理测试用户信息。

## 注意事项

当前支持测试用户数量为100。

命令无参数，查询结果返回数据库中所有测试用户。

## 参数说明

无。

## 使用实例

查询测试用户信息：

```
LST PTESTSUB:;
```

```
%%LST PTESTSUB:;%%
RETCODE = 0 操作成功

Subscriber ID
460103901200002
460103901200001
460103901200003
460103901200004
460103901200005
460103901200006

Total count = 6

There is together 1 report

---    END
```

## 输出结果说明

| 输出项名称         | 输出项解释                         |
|:--------------|:------------------------------|
| Subscriber ID | 测试用户的第一标识。 取值范围：长度不超过255的字符串。 |
