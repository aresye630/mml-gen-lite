# 修改帐户信息（MOD PACCOUNT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于修改用户帐户信息，包括帐户余额、状态和截止时间。

## 注意事项

- 对用户帐户信息的修改，立即生效，且只在下一次周期复位或手动复位之前有效。
- 修改帐户初始值、余额、状态、截止时间或自定义总量时，该用户下此帐户相关的通知抑制记录将会被清除；如果该用户下存在从用户，其从用户下所有帐户相关的所有通知抑制记录都会被清除。

## 参数说明

| 参数标识                 | 参数名称   | 参数说明                                                                                                                                                                                         |
|:---------------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER        | 用户标识   | 标识一条用户帐户信息数据记录的关键字段，用于指定需要修改哪一个用户的帐户信息。 取值范围：长度不超过255的字符串。 默认值：无。                                                                                                                            |
| ACTBALANCE           | 余额     | 表示帐户剩余额。 取值范围：0.0000～10000000.0000 默认值：无。  说明： 不支持“余额”与“自定义总量”同时修改。                                                                                                                          |
| ACTSTATUS            | 状态     | 表示帐户所处状态，即当需要触发额度事件时已使用的帐户占总帐户的百分比。各状态的含义由运营商自定义，例如：“Status = Exhaust”表示帐户耗尽。 取值范围：“Normal”“Level1”“Level2”“Level3”“Level4”“Level5”“Level6”“Level7”“Level8”“Level9”“Level10”“Exhaust” 默认值：无。 |
| ACTEXPIREDATE        | 截止时间   | 用于指定帐户余额、状态等复位的时间。时间格式为YYYY&MM&DD&HH&MM&SS。 取值范围：1970&01&01&00&00&00～2037&12&31&23&59&59。 默认值：无。  说明： 手动输入参数值“-1”：表示清除ACTEXPIREDATE属性。                                                       |
| ACTPERSONALIZEDVALUE | 自定义总量  | 表示用户自定义帐户限额。如果需要取消帐户自定义消费限额，修改用户帐户的自定义限额为0。 取值范围：0.0000～10000000.0000。 默认值：无。  说明： 不支持“余额”与“自定义总量”同时修改。                                                                                      |

## 使用实例

修改帐户信息：“用户标识”为“46010381014\*\*\*\*”，“状态”为“Normal”：

```
MOD PACCOUNT: USRIDENTIFIER="46010381014****", ACTSTATUS=Normal;
```
