# 设置共享配额（SET PSHQUOTA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

- 该命令用于对从用户进行共享配额设置，包括配额初始值，用户配额剩余额，和从用户使用量。
- 该命令应用场景如下：

  从用户可以共享使用主用户的配额，当主用户需要限制从用户可以使用的配额时，使用此命令可以设置从用户可以使用配额的最大值。

## 注意事项

- 本命令仅对从用户有效，主用户不能使用。

- 一个用户最多可以签约80个配额，从用户的共享配额数也计入从用户签约的配额总数。

- 只有系统管理员级别的操作员具有本命令的操作权限。

- 在以下场景中，不能使用该命令为从用户进行共享配额设置:
  - 当主从用户都签约关联配额(Q1)的业务时；
  - 当主用户签约配额的“配额管理归属”为“Sy”或“UPCC Dynamic”时；
  - 当主用户签约配额的“配额类型”为“时长”且累计的范围为“会话累计”时；
  - 当主用户配额的“配额类型”为“在线时长”时。

- 当主用户签约配额的“配额管理归属”为“Pre-Sy”时，参数“总量”和“余额”值不生效。

- “用户身份”为“Group”的用户或“用户身份”为“Master”的用户的所属网络类型不一致时，不允许设置共享配额。

- 所属网络类型类为非eMBB的从用户，无法使用主用户的eMBB业务及配额。

- 所属网络类型类为非eMBB的成员用户，无法使用组用户的eMBB业务及配额。

- 所属网络类型类为eMBB-SA的用户，无法对主从用户或组用户进行共享配额设置。

- 参数QTAVALUEFLAG、QTASHAREPERCENT仅支持UPCC类型和Provisioning类型配额。

- 当“操作类型”设置为“Modify”，通过该命令新增虚拟配额记录时，“直接更新”为“Yes”或“No”的处理原则是一样的，命令必须携带“总量”，“总量”和“余额”的取值均为命令所携带的“总量”值。

当

“操作类型”

设置为

“Modify”

，通过该命令修改已有配额记录时：

- 如果“直接更新”设置为“Yes”，则直接按照命令携带的“总量”、“余额”和“使用量”更新此虚拟配额的值，并根据修改之后的值计算虚拟配额状态；
- 如果“直接更新”设置为“No”，UPCF会根据表1 中参数修改后的计算结果计算配额的状态。

| 参数修改项     | 参数修改后计算结果                                    |
|:----------|:---------------------------------------------|
| 总量、余额和使用量 | 总量=修改后的总量余额=修改后的余额使用量=修改后的使用量                |
| 总量和余额     | 总量=修改后的总量余额=修改后的余额使用量保持不变                    |
| 余额和使用量    | 总量保持不变余额=修改后的余额使用量=修改后的使用量                   |
| 总量和使用量    | 总量=修改后的总量使用量=修改后的使用量余额=MAX（0，修改后的总量-修改后的使用量） |
| 总量        | 总量=修改后的总量余额=MAX（0，修改后的总量-使用量）使用量保持不变         |
| 余额        | 总量保持不变余额=修改后的余额使用量保持不变                       |
| 使用量       | 总量保持不变余额保持不变使用量=修改后的使用量                      |

## 参数说明

| 参数标识            | 参数名称       | 参数说明                                                                                                                                                                                                                                                      |
|:----------------|:-----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER   | 用户标识       | 用于指定需要为哪个从用户进行共享配额设置，必须是已经存在的用户，该参数必须先通过ADD PSUB命令定义，然后才能在此处索引。本参数是必选参数。 取值范围：长度不超过255的字符串。 默认值：无。                                                                                                                                                        |
| ENOPERATIONTYPE | 操作类型       | 用于设置从用户共享配额的操作类型。本参数是必选参数。 取值范围：“Modify”：为从用户设置可以共享主用户配额的总量或余额。“Delete”：删除从用户设置共享主用户的配额信息。 默认值：Modify。                                                                                                                                                    |
| QTANAME         | 配额名称       | 标识一条用户配额信息数据记录，用于指定需要设置用户的哪一个配额信息。 配额名称必须是从用户所关联主用户已经签约的配额且该配额需要在UPCF Web UI上配置。 本参数是条件可选参数，当“操作类型”选择Delete时，如果指定了QuotaName，则删除从用户指定QuotaName的共享配额，否则删除从用户所有的共享配额。当“操作类型”选择Modify时，如果指定的QuotaName是从用户已经共享的配额则进行修改，否则新增一条共享的配额记录。 取值范围：长度不超过32的字符串。 默认值：无。 |
| QTAVALUE        | 总量         | 用于设置从用户可以共享主用户配额总量的大小。 取值范围：1～4294967294。 默认值：无。 单位：KB或秒。  说明： 从用户可以共享主用户配额总量的大小不能大于主用户的配额初始值。                                                                                                                                                            |
| QTABALANCE      | 余额         | 用于设置从用户可以共享主用户配额的余额大小。 取值范围：0～4294967294。 默认值：无。 单位：KB或秒。                                                                                                                                                                                                 |
| QTAVALUEFLAG    | 虚拟配额初始值标识  | 用于标识虚拟配额的初始值与共享业务主配额的初始值是否相同。 取值范围： “False”：虚拟配额的初始值与共享业务主配额的初始值不相同。“True”：虚拟配额的初始值与共享业务主配额的初始值相同。 默认值：无。                                                                                                                                                 |
| QTASHAREPERCENT | 虚拟配额初始值百分比 | 用于标识默认虚拟配额初始值百分比。 取值范围：0～100。 默认值：无。                                                                                                                                                                                                                      |
| QTACONSUMPTION  | 使用量        | 用于设置从用户可以共享主用户配额的使用量大小。 取值范围：0～4294967294。 默认值：无。 单位：KB或秒。                                                                                                                                                                                                |
| DIRECTCHANGE    | 直接更新       | 用于设置命令携带的配额总量、配额余额、配额使用量是否直接更新到系统中。 取值范围： “Yes”：按照命令携带的配额总量、配额余额、配额使用量值更新此虚拟配额的值“No”：按照命令携带的配额总量、配额余额、配额使用量经过计算后更新虚拟配额的值 默认值：无                                                                                                                            |

## 使用实例

为从用户新增一个共享配额： 从用户的“用户标识”为“46010381014\*\*\*\*”，“操作类型”为“Modify”，共享主用户的“配额名称”为“Volume\_Quota”，共享配额的“总量”为“300”：

```
SET PSHQUOTA: USRIDENTIFIER="46010381014****", ENOPERATIONTYPE=Modify, QTANAME="Volume_Quota", QTAVALUE=300;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释                                            | 原因分析                                                      | 处理建议                                                                  |
|------:|:-------------------------------------------------|:----------------------------------------------------------|:----------------------------------------------------------------------|
| 90529 | 组共享业务不允许设置从用户虚拟配额。                               | 该用户签约的是组共享业务。                                             | 请输入其他“用户标识”，并确保该“用户标识”没有订购组共享业务，即该“用户标识”签约的业务中“是否组业务”设置为“No”，重新执行本命令。 |
| 90631 | qtaValueFlag、 qtaSharePercent、qtaValue不能同时设置有效值。 | 命令中同时携带了qtaValueFlag、qtaSharePercent、qtaValue两个及以上参数的有效值。 | 三个参数最多只能有一个参数携带有效值。                                                   |
