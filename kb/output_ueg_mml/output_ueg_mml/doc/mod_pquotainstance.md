# 修改配额实例（MOD PQUOTAINSTANCE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于对用户的配额实例进行修改，包括配额实例总量、余额、使用量、过期时间、扩展属性、扩展属性1、扩展属性2、扩展属性3、使用量增量和余额增量。当需要修改用户某个配额的实例信息时，可以执行此命令。

## 注意事项

- 修改配额实例的总量、余额、使用量增量或者余额增量时，会根据修改后的参数更新配额实例状态。
- 对于多配额实例组业务，修改正在使用的配额实例的使用量、余额或者余额增量，导致配额状态由大变小时，删除共享配额的通知抑制记录，不删除虚拟配额的通知抑制记录。
- 对于多配额实例非组业务，修改正在使用的配额实例的使用量、余额或者余额增量，导致配额状态由大变小时，此用户该配额相关的所有通知抑制记录都会被清除。

## 参数说明

| 参数标识                    | 参数名称    | 参数说明                                                                                                                                                                                                           |
|:------------------------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER           | 用户标识    | 标识一条用户配额实例数据记录的关键字段之一，用于指定需要修改哪一个用户的配额实例信息。 取值范围：长度不超过255的字符串。 默认值：无。                                                                                                                                          |
| QTANAME                 | 配额名称    | 标识一条用户配额实例数据记录的关键字段之一，用于指定需要修改哪一个用户配额的配额实例信息。 配额名称必须是已存在的配额且该配额需要在UPCF Web UI上配置。 取值范围：长度不超过32的字符串。 默认值：无。                                                                                                     |
| SEQUENCEID              | 实例序列号   | 标识一条用户配额实例数据记录的关键字段之一，用于指定需要修改哪一个实例序号的配额实例信息。每次订购递增，若已达到254，则从取值范围中取最小空闲值。 取值范围： 0～254。 默认值：无。                                                                                                                 |
| QTAVALUE                | 总量      | 用于设置用户配额实例配额总量的大小，单位为KB。 取值范围：1～4294967294。 默认值：无。                                                                                                                                                             |
| QTABALANCE              | 余额      | 用于设置用户配额实例剩余额的大小，单位为KB。 取值范围：0～4294967294。 默认值：无。                                                                                                                                                              |
| QTACONSUMPTION          | 使用量     | 用于设置用户配额实例使用量的大小，单位为KB。修改后的配额实例使用量即为该参数设置的使用量。 取值范围：0～4294967294。 默认值：无。                                                                                                                                       |
| INSTANCEEXPIREDTIME     | 过期时间    | 用于指定用户配额实例的过期时间，时间格式为“YYYY&MM&DD&HH&MM&SS”。 取值范围：1970-01-01 00:00:00～2037-12-31 23:59:59，可通过控件配置时间。 默认值：无。  说明： 手动输入参数值“-1”：表示配额实例永不过期。如果配额的“结帐模式”是“不复位”，则该字段表示配额实例的过期时间。如果配额的“结帐模式”不是“不复位”，则该字段表示配额实例的下次复位时间。 |
| QTAEXTATTR              | 配额扩展属性  | 用于指定用户配额实例的扩展属性。 取值范围：长度为1～64字节的字符串。 默认值：无。                                                                                                                                                                    |
| QTAEXTATTR1             | 配额扩展属性1 | 用于指定用户配额实例的扩展属性1。 取值范围：长度为1～64字节的字符串。 默认值：无。                                                                                                                                                                   |
| QTACONSUMPTIONINCREMENT | 使用量增量   | 用于设置使用量增量，单位为KB。修改使用量增量时，余额和使用量的值会进行重新计算： “总量”保持不变新“余额”=旧“余额”-“使用量增量”新“使用量”=旧“使用量”+“使用量增量” 取值范围：1～4294967294。 默认值：无。  说明： 不支持同时修改“使用量增量”与“余额增量”。不支持“使用量增量”与“总量”、“余额”或“使用量”同时修改。                                |
| QTABALANCEINCREMENT     | 余额增量    | 用于设置余额增量，单位为KB。修改余额增量时，余额和使用量的值会进行重新计算： “总量”保持不变新“余额”=旧“余额”+“余额增量”新“使用量”=旧“使用量”-“余额增量” 取值范围：1～4294967294。 默认值：无。  说明： 不支持同时修改“余额增量”与“使用量增量”。不支持“余额增量”与“总量”、“余额”或“使用量”同时修改。                                     |
| QTAEXTATTR2             | 配额扩展属性2 | 用于指定用户自定义的通知内容。自定义的通知内容作为短信/邮件模板的“内容”。 取值范围：长度为1～64字节的字符串。 默认值：无。  说明： 手动输入参数值“NULL”：表示清除QTAEXTATTR2属性。                                                                                                        |
| QTAEXTATTR3             | 配额扩展属性3 | 该属性用于设置条件组，以实现平滑的配额本地位置区转移。该属性也可以作为短信/邮件模板的“内容”。 取值范围：长度为1～64字节的字符串。 默认值：无。  说明： 手动输入参数值“NULL”：表示清除QTAEXTATTR3属性。                                                                                              |

## 使用实例

修改用户配额信息：“用户标识”为“46010381014\*\*\*\*”，“配额名称”为“Volume\_Quota”，“实例序列号”为“12”，“总量”为“300”：

```
MOD PQUOTAINSTANCE: USRIDENTIFIER="46010381014****", QTANAME="Volume_Quota", SEQUENCEID=12, QTAVALUE=300;
```
