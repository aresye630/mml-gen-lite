# 添加多卡用户关联关系（ADD PSUBMAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用来增加多卡用户与从用户的关联关系。

## 注意事项

混合组网不支持添加多卡用户关联关系。

## 参数说明

| 参数标识                   | 参数名称   | 参数说明                                                                                                                                         |
|:-----------------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------|
| USRTHIRDIDENTIFIER     | 多卡用户标识 | 用于标识Multi-SIM用户的标识。 取值范围：长度不超过20的字符串。 默认值：无。                                                                                                 |
| USRTHIRDIDENTIFIERTYPE | 多卡用户类型 | 用于标识Multi-SIM用户的类型。 取值范围： 0:END_USER_E1641:END_USER_IMSI2:END_USER_SIP_URI3:END_USER_NAI4:END_USER_PRIVATE 默认值：无。                            |
| USRIDENTIFIER          | 公共用户标识 | 用于标识多卡用户所属的从用户的用户标识。 取值范围：长度不超过20的字符串。 默认值：无。 配置原则：不支持英文逗号（,）、英文分号（;），等号（=）、英文双引号（"）、英文单引号（'），连续两个及以上的百分号（%%），连续两个及以上的空格（ ）、mml报文起始符标识（+++）。 |

## 使用实例

添加多卡用户关联关系：“多卡用户标识”为“1sa1multisim01”，“多卡用户类型”为“END\_USER\_E164”，“公共用户标识”为“slave101”：

```
ADD PSUBMAP: USRTHIRDIDENTIFIER="1sa1multisim01", USRTHIRDIDENTIFIERTYPE=END_USER_E164, USRIDENTIFIER="slave101";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释        | 原因分析                                              | 处理建议                                                              |
|------:|:-------------|:--------------------------------------------------|:------------------------------------------------------------------|
| 12302 | 用户不存在        | 输入的用户在系统中不存在。                                     | 执行LST PSUB命令查询用户信息，输入系统中查询出来的“用户标识”，重新执行本命令。                      |
| 90628 | 用户类型不是从用户    | 输入的USRIDENTIFIER用户的用户类型不是slave。                   | 执行LST PSUB命令查询USRIDENTIFIER用户的用户类型，确保输入的USRIDENTIFIER的用户类型是slave。 |
|  1037 | 记录已存在        | 输入的USRTHIRDIDENTIFIER用户在系统中已存在。                   | 确保输入的在系统中不存在或者先删除已存在的记录再添加。                                       |
| 90632 | 单用户记录数超过最大限制 | 单个USRIDENTIFIER用户下添加的USRTHIRDIDENTIFIER用户数超过128个。 | 当前系统限制，无处理建议。                                                     |
