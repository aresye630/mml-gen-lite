# 查询历史通知记录数（LST PNTFINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

实时统计全库通知记录数可能对USRSU虚拟机（对应裸机场景的usrsu-pod）性能产生影响，当任一USRSU虚拟机（对应裸机场景的usrsu-pod）的CPU高于60%时不建议执行本命令。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于查询通知抑制表中的记录数。

## 注意事项

- 该操作可能对系统性能产生影响，仅系统管理员级别的操作员有操作权限，请在低业务量的时候进行操作。执行本命令前，在OM Portal“USCDB MML命令”界面执行**DSP NODECPUSTAT**（对应裸机场景DSP PODCPUSTAT）命令，查看虚拟机/裸机Pod的CPU信息，如果所有USRSU类型的虚拟机（对应裸机场景的usrsu-pod）CPU使用率不高于60%，可以直接执行本命令。如果任意一个USRSU虚拟机（对应裸机场景的usrsu-pod）的CPU使用率高于60%，禁止批量执行本命令，必须等上一条命令执行完毕后才能开始执行本命令。如果任意一个USRSU虚拟机（对应裸机场景的usrsu-pod）的CPU使用率高于70%，禁止执行本命令。
- 混合组网场景，5G设备执行本命令查询历史通知记录数。如果指定用户标识，则返回该用户所在DSU Cluster的通知抑制表中的记录数；如果不携带用户标识参数，则返回4G用户和5G用户的所有DSU的通知抑制表中总的记录数。
- 混合组网场景，4G设备执行本命令查询历史通知记录数。如果指定用户标识，则返回该用户所在DSU Cluster的通知抑制表中的记录数；不携带用户标识参数，则返回4G用户的所有DSU的通知抑制表中总的记录数。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                                                       |
|:--------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 用于指示系统需要按照哪个用户标识来查询该用户所在DSU Cluster的通知抑制表中的记录数。 如果命令中携带用户标识参数，则返回该用户所在DSU Cluster的通知抑制表中的记录数。如果命令不携带用户标识参数，则返回所有DSU的通知抑制表中总的记录数。 取值范围：长度不超过255的字符串。 默认值：无。  说明： 系统每5分钟统计一次每个DSU的通知抑制表中的记录数，因此当指定用户标识查询历史通知记录数时，返回的数值不是实时的。 |

## 使用实例

查询历史通知记录数：“用户标识”为“46010381014\*\*\*\*”。

```
LST PNTFINFO: USRIDENTIFIER="46010381014****";
```

输出结果如下：

```
%%LST PNTFINFO: USRIDENTIFIER="46010381014****";%%
RETCODE = 0 Operation succeeded

            Record Number of notify restricted = 2

Total count = 1

There is together 1 report

---    END
```

## 输出结果说明

| 输出项名称                              | 输出项解释      |
|:-----------------------------------|:-----------|
| Record Number of notify restricted | 通知抑制表中记录数。 |
