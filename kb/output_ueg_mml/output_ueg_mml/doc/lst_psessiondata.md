# 查询会话数据用户标识（LST PSESSIONDATA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询会话数据的用户标识。

若要查询某个会话数据的用户标识，请输入“用户IP地址”和“PGW主机名”。

## 注意事项

- 该命令目前仅支持Gx接口查询会话数据用户标识，暂不支持N7接口。
- 查询到的结果包含用户的个人数据，如：IMSI、MSISDN等。因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护。例如：
  1. 采用安全的文件传输协议（如SFTP）传输文件。
  2. 并严格控制文件的访问权限。
  3. 及时清理数据文件。

  在从运营商网络获取数据前，必须要获得运营商的授权。

  若需从运营商网络中获取必要的数据，需要运营商维护人员对其中的个人数据进行匿名化处理，匿名化后的数据由运营商维护人员审核后提供，以防止个人数据泄露。匿名化处理工具可以在https://support.huawei.com/获取，获取方法请参见产品手册“匿名化工具安全策略”页面。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UEIP   | 用户IP地址 | 可选必选说明：必选参数 参数含义：用于指定需要被查询用户的IP地址。 取值范围：长度不超过255的字符串，支持IPv4和IPv6，IPv4的格式是点分十进制，IPv6对地址是全校验，其格式为XXXX:XXXX:XXXX:XXXX:XXXX:XXXX:XXXX:XXXX/64。 默认值：无。 配置原则：无。  说明： 本参数的取值为IPv4类型时：仅支持设置绑定配置(SET BINDCFG)中参数“IPv4IPDomain”配置为“Support(支持)”的场景。本参数的取值为IPv6类型时：仅支持设置绑定配置(SET BINDCFG)中参数“IPv6IPDomain”配置为“Support(支持)”的场景。 |
| PGWID  | PGW主机名 | 可选必选说明：必选参数 参数含义：用于指定需要被查询用户的P-GW主机名。用户上线时，该参数由Origin-Host AVP携带。 取值范围：长度不超过255的字符串。 默认值：无。 配置原则： 第三方发送的P-GW主机名大小写格式需要与PCF协商一致。该参数取值最多只能包含5个主机名，其格式为：hostname1\，hostname2\，hostname3\，hostname4\，hostname5                                                                                                          |

## 使用实例

查询会话数据用户标识，以IPv6为例：“用户IP地址”为“2001:2001:2001:0:0:0:0:\*\*\*\*/64”,“PGW主机名”为“pcef1”：

```
LST PSESSIONDATA: UEIP="2001:2001:2001:0:0:0:0:****/64", PGWID="pcef1";
```

输出结果如下：

```
%%LST PSESSIONDATA: UEIP="2001:2001:2001:0:0:0:0:****/64", PGWID="pcef1";%%

USRMSISDN
460983721804***

Total count = 1

There is together 1 report

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

| 输出项名称     | 输出项解释        |
|:----------|:-------------|
| USRMSISDN | 表示在线会话的用户ID。 |

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释   | 原因分析                          | 处理建议                          |
|------:|:--------|:------------------------------|:------------------------------|
| 98510 | 会话不存在。  | 使用“用户IP地址”和“PGW主机名”查找用户手机号失败。 | 重新输入其他的“用户IP地址”和“PGW主机名”进行查询。 |
