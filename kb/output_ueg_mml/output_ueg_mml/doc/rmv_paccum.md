# 去签约累计项（RMV PACCUM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于从配置数据库中删除一条签约累计项数据记录。

## 注意事项

- 操作员在执行此命令时，一次最多只能删除一条签约累计项。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                 |
|:--------------|:-------|:---------------------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 标识一条用户累计项数据记录的关键字段之一，用于指定去签约哪一个用户的累计项数据记录。 取值范围：长度不超过255的字符串。 默认值：无。 |
| ACCNAME       | 累计项名称  | 标识一条用户累计项数据记录的关键字段之一，用于指定需要清除用户哪一条累计项数据记录。 取值范围：长度不超过32的字符串。 默认值：无。  |

## 使用实例

去签约累计项：“用户标识”为“46010381014\*\*\*\*”，“累计项名称”为“AccuMulation\_01”：

```
RMV PACCUM: USRIDENTIFIER="46010381014****", ACCNAME="AccuMulation_01";
```
