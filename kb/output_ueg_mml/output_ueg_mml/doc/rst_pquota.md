# 复位配额信息（RST PQUOTA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于复位用户配额的信息，将用户配额剩余额置为配额初始值，用户配额消耗额置为零，用户配额状态置为初始状态。

## 注意事项

- 复位配额时，若配额剩余额处理方式为累积复位，那么配额剩余额的值是原配额剩余额的值与配额初始值之和，若配额剩余额处理方式为清零复位，那么配额剩余额的值为配额初始值。
- 复位配额信息时，该用户下此配额相关的通知抑制记录将会被清除；如果该用户下存在从用户，其从用户下此配额相关的所有通知抑制记录也会被清除。
- 本命令对各类型配额的支持能力：
  1. Sy类型的配额无法通过本命令复位。
  2. UPCC Dynamic类型的配额无法通过本命令复位。
  3. 允许对Pre-Sy类型的私有配额或者组配额进行复位处理，但只修改配额状态并计算下次复位时间，不涉及初始值、余额、消耗量的修改。
- 从用户的虚拟配额无法通过本命令复位。
- 在累积配额按可配次数清零复位的场景中，通过该命令复位配额时，配额的已累积次数参数不会变化。
- 如果配额关联“重复订购方式”为“多配额记录重复订购”的业务，则该配额无法通过本命令复位。

## 参数说明

| 参数标识                   | 参数名称      | 参数说明                                                                                                                                                |
|:-----------------------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER          | 用户标识      | 标识一条用户信息数据记录，用于指定需要复位哪一个用户的配额信息。 取值范围：长度不超过255的字符串。 默认值：无。                                                                                          |
| QTANAME                | 配额名称      | 标识一条用户配额信息数据记录，用于指定需要复位用户的哪一个配额信息。 配额名称必须是已存在的配额且该配额需要在UPCF Web UI上配置。 取值范围：长度不超过32的字符串。 默认值：无。                                                     |
| RESETFLAG              | 复位方式      | 用于指示配额复位处理方式。 取值范围：0：表示强制复位，复位配额时不检查下次复位时间。1：表示复位配额时检查下次复位时间，若系统时间≥下次复位时间，则复位配额并根据配额复位类型计算下次复位时间；若当前系统时间＜下次复位时间，则不做复位也不更新下次复位时间，并返回90512错误码。 默认值：0。 |
| RESETSLAVEVIRTUALQUOTA | 复位从用户虚拟配额 | 用于指示在复位主用户共享配额时是否对从用户的虚拟配额进行复位。 取值范围：False：复位主用户共享配额时不复位从用户虚拟配额。True：复位主用户共享配额时复位从用户虚拟配额。 默认值：无。未携带该参数时，按取值“False”处理。                               |

## 使用实例

复位配额信息：“用户标识”为“46010381014\*\*\*\*”，“配额名称”为“Volume\_Quota”，“复位方式”为“0”：

```
RST PQUOTA: USRIDENTIFIER="46010381014****", QTANAME="Volume_Quota", RESETFLAG=0;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                | 原因分析                                   | 处理建议                                       |
|------:|:---------------------|:---------------------------------------|:-------------------------------------------|
| 90394 | 虚拟配额不支持该操作           | 如果“复位从用户虚拟配额”设置为“True”，“用户标识”不能为从用户标识。 | 执行LST PSUB，获取“用户身份”为“MASTER”的用户标识后重新执行本命令。 |
| 90512 | 系统时间小于下次复位时间，不允许复位配额 | 复位配额时检查下次复位时间，且当前系统时间小于下次复位时间。         | 设置“复位方式”为“0”，重新执行本命令。                      |
