# 修改组用户为M2M用户（MOD PGRPTOM2MUSER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令为高危命令，仅在企业组用户增量割接改为M2M用户时使用，且必须一晚上改造，不可分开改造，避免数据异常。

该命令用于将组用户修改为M2M用户。

Group-Member场景改造为Master-Master场景时，可以使用本命令将组用户/成员用户改造为M2M用户，即成员用户改造为子节点用户，组用户改造为父节点用户。

## 注意事项

- 仅支持在Group-Member用户增量割接改为Master-Master用户时使用，且同一局点用户必须选择在同一晚上改造，不可分批改造，避免数据异常。
- 仅支持对用户数据保存在UDR上的Group-Member用户进行改造。
- 不支持对存在实际分配配额的Group-Member用户进行改造。
- 进行改造的组用户下关联的成员用户需不超过99个。
- 组业务未修改为M2M共享业务时不支持改造。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                     |
|:--------------|:-------|:---------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 可选必选说明：必选参数 参数含义：用于指定成员用户标识，必须是已经存在的用户，该参数必须先通过ADD PSUB命令定义，然后才能在此处索引。 取值范围：长度不超过255的字符串。 默认值：无。 配置原则：无。 |
| GRPIDENTIFIER | 组用户标识  | 可选必选说明：必选参数 参数含义：用于指定组用户标识，必须是已经存在的用户，该参数必须先通过ADD PSUB命令定义，然后才能在此处索引。 取值范围：长度不超过255的字符串。 默认值：无。 配置原则：无。  |

## 使用实例

修改组用户为M2M用户，“用户标识”为“46010381013\*\*\*\*”，“组用户标识”为“46010381012\*\*\*\*”：

```
MOD PGRPTOM2MUSER: USRIDENTIFIER="46010381013****", GRPIDENTIFIER="46010381012****";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                 | 原因分析                                        | 处理建议                                                                                                                 |
|------:|:----------------------|:--------------------------------------------|:---------------------------------------------------------------------------------------------------------------------|
| 90711 | 组或成员用户在SPR，不支持改造。     | 输入的组用户或成员用户标识对应的用户数据保存在SPR上，不支持直接通过此命令进行改造。 | 请确认是否需要改造此组用户或成员用户：如果需要，先将此组用户或成员用户迁移到UDR后，再重新执行此命令时输入其用户标识；如果不需要，重新执行本命令时输入其他的用户数据在UDR上的需要改造的组用户和成员用户标识。            |
| 90712 | 组或成员用户存在实际分配配额，不支持改造。 | 输入的组用户或成员用户存在实际分配配额，不支持直接通过此命令进行改造。         | 请确认是否需要改造此组用户或成员用户：如果需要，先将此组用户或成员用户签约的实际分配配额的业务进行去签约后，再重新执行此命令时输入其用户标识；如果不需要，重新执行本命令时输入其他的不存在实际分配配额的需要改造的组用户和成员用户标识。 |
| 90722 | 组成员用户数超过99，不支持改造。     | 输入的组用户下关联的成员数超过99，不支持直接通过此命令进行改造。           | 请确认是否需要改造此组用户和成员用户：如果需要，先将此组用户下关联的成员数调整至不超过99，再重新执行此命令时输入其用户标识；如果不需要，重新执行本命令时输入其他的组成员用户个数不超过99的需要改造的组用户和成员用户标识。      |
