# 去激活用户会话（DEA PSESSION）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于当局点系统故障需快速应急恢复时，去激活用户会话，强制在线用户下线。如果能获取用户列表，可通过批处理快速的去激活批量用户会话。

## 注意事项

- 若软参“VRM\_VOLTEQRYSPR”取值为“0”，用户同时存在语音会话和数据会话在线，执行**DEA PSESSEION**时仅强制下线该用户的数据会话，保持语音会话在线。
- 若软参“VRM\_VOLTEQRYSPR”取值为“1”，用户同时存在语音会话和数据会话在线，执行**DEA PSESSEION**时该用户的语音会话和数据会话都强制下线。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                   |
|:--------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 用于指定需要去激活哪一个用户的会话。用户标识可以为用户第一标识，也可以为用户第二标识。 取值范围：长度不超过255的字符串。 默认值：无。  说明： 在企业用户场景下，去激活组用户会话时，不会影响成员用户会话。在主从用户场景下，去激活主用户会话时，不会影响从用户会话。 |

## 使用实例

去激活用户会话：“用户标识”为“46010381014\*\*\*\*”：

```
DEA PSESSION: USRIDENTIFIER="46010381014****";
```
