# 查询配额信息（LST PQUOTA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中查询用户配额数据的配置信息。

## 注意事项

- Sy类型的配额信息无法通过本命令查询。
- UPCC Dynamic类型的配额信息可以通过本命令查询。
- 使用本命令查询动态配额时，系统不会做过滤直接返回所有已经实例化的动态配额记录；若配额已过复位时间，也返回记录。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
|:--------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 用于指示系统需要按照哪个用户标识来查询用户配额信息数据。 取值范围：长度不超过255的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| QTANAME       | 配额名称   | 用于指定需要查询用户的哪个配额的信息。 配额名称必须是已存在的配额且该配额需要在UPCF Web UI上配置。 取值范围：长度不超过32的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| REALTIMEFLAG  | 实时模式   | 用于控制是否按照实时模式处理。 取值范围： “False”：按照非实时模式处理。“True”：按照实时模式处理。 默认值：False。  说明： 实时模式是指基于用户实际使用量的数据操作，这需要UPCF下发RAR消息要求PCEF立即上报使用量。在实时模式下营帐命令与更新用户使用量是串行执行的，即UPCF处理营帐命令前，先下发RAR消息要求PCEF立即上报使用量，PCEF上报使用量后，才处理充值/修改/查询配额的操作。实时模式设置生效的前提是：在“USCDB MML命令”网元下通过LST NOTIFYCFG查询“SYNCHROSWITCH”参数取值为“SYNC”，且“REMOTEID”的取值与LST PSYSPARA命令中“SyncRemoteID”参数保持一致。非实时模式是指基于本地数据库中用户数据的数据操作，不需要UPCF下发RAR消息要求PCEF立即上报使用量。只有在线的普通用户支持实时模式，主用户、从用户、组用户、组成员和M2M用户都不支持实时模式。以下配额不支持按照实时模式处理：“配额管理归属”为“Sy”或“Pre-Sy”的配额“配额类型”为“在线时长”或“时长”的配额 批操作的命令是并行处理的，同一个用户可能会有多个并行处理的命令。在实时模式下，如果某个用户的前一个命令没有处理完成，后面的命令会直接返回错误，指示本次命令不能执行。对于同时查询用户多个配额的场景，UPCF会要求PCEF上报多个配额的使用量，如果PCEF只上报了部分配额的使用量，则UPCF直接将上报的使用量进行入库处理，并返回查询结果，不会等全部使用量上报。N7接口暂不支持该参数。 |
