# 设置用户迁移（SET PSUBMIGRATE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，执行不当可能会造成用户数据丢失。因此执行该命令前，需联系华为技术支持确认后再执行。

该命令用于混合组网场景下，将UPCC SPR中存储的用户数据迁移到UPCF的UDR中，或者将UPCF UDR中存储的用户数据迁移到UPCC的SPR中。如果能获取用户列表，可通过PGW批处理快速迁移用户数据。

## 注意事项

- 混合组网场景下，一个主用户和其关联的从用户需要同时存储在相同的数据库（UDR或SPR）。针对主从用户进行迁移时，本命令需要携带主用户的用户标识来触发整体迁移，迁移完成后会将主用户和其关联的从用户会一并迁移到UDR中，不支持单独对从用户进行迁移操作。
- 当用户的“所属网络类型”为“eMBB-SA”时，不支持执行该命令。
- 当用户为从用户时，不支持执行该命令。
- 当用户签约了M2M共享业务或者含有M2M虚拟配额时，不支持执行该命令将用户从UDR迁移到SPR。
- 不支持在vSP上执行该命令。

## 参数说明

| 参数标识             | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|:-----------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER    | 用户标识   | 用于指定需要被迁移用户的用户标识。用户标识仅支持为用户第一标识，不允许为用户第二标识。 取值范围：长度不超过255的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| MIGRATEDIRECTION | 迁移方向   | 用于指定需要被迁移用户的迁移方向。 对于普通用户，迁移的时候按单个用户迁移到UDR或者SPR。对于主从用户，该命令不支持单独迁移从用户，通过该命令迁移主用户时，会同时将主用户下的所有从用户一起迁移到UDR或者SPR。对于组用户和组成员用户，迁移的时候按单个用户迁移到UDR或者SPR。 取值范围： ToUDR：表示从SPR迁移用户到UDR。ToSPR：表示从UDR迁移用户到SPR。 默认值：无。 系统初始值：ToUDR  说明： 该参数设置为“ToUDR”：根据号段去匹配“PartitionID”，再检查“PartitionID”是否指向UDR；如果没有匹配到“PartitionID”或匹配到的“PartitionID”指向非UDR，则默认取vRSP分区的“PartitionID”。该参数设置为“ToSPR”：BE转发模式下，根据号段去匹配“PartitionID”：若“PartitionID”指向UDR，则不触发迁移。若“PartitionID”指向非UDR，则向SP分区迁移。 全局路由BE转发模式下，因当前有多个SPR，系统迁移用户时需要按号段（含“default”号段）选择SPR，若匹配不到号段则不迁移。全局路由模式下，系统迁移用户时需要按号段选择SPR，若匹配不到号段则不迁移。 |

## 使用实例

迁移用户到UPCF的UDR：“用户标识”为“46010381014\*\*\*\*”,“迁移方向”为“ToUDR”：

```
SET PSUBMIGRATE: USRIDENTIFIER="46010381014****", MIGRATEDIRECTION=ToUDR;
```
