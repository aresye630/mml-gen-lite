# 解散企业组（RMV PGROUP）

## 命令功能

**须知** 

解散组命令会同时销户组用户，因此执行该命令前，需要与华为技术支持确认后才可以实施。

本命令用于解散组。组解散后，成员用户不能再共享组用户签约的配额。

## 注意事项

- 执行本命令后在解散组的同时会销户组用户。
- 混合组网下，不支持该命令。
- 解散组时，如果成员用户在线，则根据软参“VRM\_RMVGRPMEMBERACT”的配置控制是否需要强制成员用户下线。
- 新上线的成员用户，如果其组用户状态为解散，则成员用户不能再使用组用户签约的业务及配额。
- 解散组后，如果UPCF不强制用户下线，则UPCF需要根据组网情况，发送消息到外置SPR或OCS查询用户数据，以便更改策略。
- 解散组后，系统会立即对组的信息进行清除。在清除的过程中，不能对解散组进行查询、修改等操作，也不能添加与该组相同用户标识的组，需等该组的数据清除（可通过**LST PSUB**命令查询组是否存在）后，才能重新添加该组。
- 解散组时，如果软参“VRM\_RMVGRPMEMBERACT”设置为“1”，则成员用户在组内消耗的最后一个组共享配额的分片不能从组共享配额中扣减。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                       |
|:--------------|:-------|:-------------------------------------------|
| GRPIDENTIFIER | 组用户标识  | 用于指示UPCF需要解散哪个组。 取值范围：长度不超过255的字符串。 默认值：无。 |

## 使用实例

解散组：“组用户标识”为“Group001”。

```
RMV PGROUP: GRPIDENTIFIER="Group001";
```

输出结果说明
