## 命令功能

**须知** 

该命令属于高危命令，增加营帐虚拟运营商号段会造成扩大既有操作员的号段范围。因此执行该命令前，需联系华为技术支持确认后再执行。

该命令用于添加营帐虚拟运营商号段。当运营商需要对USRIDENTIFIER号段进行权限控制时，需要通过本命令增加虚拟运营商号段。

该命令的参数索引关系如图1所示。

**图1** 命令参数的索引关系图

## 注意事项

- 该命令的参数“NSP（号段前缀）”与**ADD NSPREFIX**命令的参数“NSP（号段前缀）”无关联关系。
- 添加营帐虚拟运营商号段之前必须先通过**ADD SYSNO**命令添加系统序列号以及**ADD MVNO**命令添加虚拟运营商序列号。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                     |
|:-------|:---------|:---------------------------------------------------------------------------------------------------------|
| NSP    | 号段前缀     | 用于指定USRIDENTIFIER号码前缀。 取值范围：长度为1~32的字符串。 默认值：无。 说明： 系统支持最大记录数为40960条。系统不支持如下字符：“:”、“\'”、“=”、“,”、“\"”、“/” |
| MVNO   | 虚拟运营商序列号 | 用于指定虚拟运营商的序列号。该参数必须先由ADD MVNO命令定义，然后才能在此处索引。 取值范围：1～255 默认值：无。                                           |

## 使用实例

添加“虚拟运营商序列号”为“1”，“号段前缀”为“2234”的虚拟运营商号段，操作步骤如下：

1. 登录PGW Web LMT MML命令界面，选择“系统管理”，添加一个值为“1”的“系统序列号”，此系列号与**OM Portal**上“MML命令行 - USCDB”执行**LST SYSNO**命令查询的“系统序列号”一致。

   ```
   ADD SYSNO: SYSNO=1, SYSNAME="MASTERNO1", STATUS=MASTER;
   ```
2. 选择“系统管理”，系统需要添加虚拟运营商，其“虚拟运营商序列号”为“1”，“虚拟运营商名称”为“huawei”，PGW为简单模式：

   ```
   ADD MVNO: MVNO=1, MVNONAME="huawei";
   ```
3. 选择“UPCF业务管理”，添加营帐虚拟运营商号段，其“号段前缀”为“2234”，“虚拟运营商序列号”为“1”：

   ```
   ADD PMVNONSP: NSP="2234", MVNO=1;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释            | 原因分析                      | 处理建议                                                |
|------:|:-----------------|:--------------------------|:----------------------------------------------------|
| 90622 | 虚拟运营商号段达到最大记录上限。 | 添加的号段记录数超过了系统支持的最大值40960。 | 建议合理划分号段 。                                          |
| 90624 | 虚拟运营商号段已经存在。     | 新添加的虚拟运营商号段已经存在。          | 执行LST PMVNONSP命令查询已经存在的营帐虚拟运营号段，确保要新增的号段与已经存在号段不相同。 |
| 90625 | 虚拟运营商不存在。        | 虚拟运营商不存在。                 | 执行ADD MVNO命令增加“虚拟运营商”。                              |
