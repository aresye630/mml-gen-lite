# 用户标识查询会话信息（LST PSESSIONINFOBYMSISDN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于根据用户标识查询指定用户的会话信息。

若要查询某个用户的会话信息，请输入“用户标识”。

## 注意事项

- 当软参“VRM\_SUBSRCIPTIONIDTYPE”设置为“0”时，该命令使用MSISDN作为用户标识进行查询。当软参“VRM\_SUBSRCIPTIONIDTYPE”设置为“1”时，该命令需使用IMSI作为用户标识进行查询。
- 查询到的结果包含用户的个人数据，如：IMSI、MSISDN等。因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护。例如：
  1. 采用安全的文件传输协议（如SFTP）传输文件。
  2. 并严格控制文件的访问权限。
  3. 及时清理数据文件。

  在从运营商网络获取数据前，必须要获得运营商的授权。

  若需从运营商网络中获取必要的数据，需要运营商维护人员对其中的个人数据进行匿名化处理，匿名化后的数据由运营商维护人员审核后提供，以防止个人数据泄露。匿名化处理工具可以在https://support.huawei.com/获取，获取方法请参见产品手册“匿名化工具安全策略”页面。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                |
|:----------|:-------|:--------------------------------------------------------------------|
| USRMSISDN | 用户标识   | 可选必选说明：必选参数 参数含义：用于指定需要被查询用户的用户ID。 取值范围：长度不超过255的字符串 默认值：无。 配置原则：无。 |

## 使用实例

以用户标识为例查询会话数据信息：“用户标识”为“460983721804\*\*\*”：

```
LST PSESSIONINFOBYMSISDN: USRMSISDN="460983721804***";
```

输出结果如下：


## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

| 输出项名称              | 输出项解释                              |
|:-------------------|:-----------------------------------|
| Session Type       | 表示该会话的接口类型。 取值范围： GxN7N15 UEN15 AM |
| UEIP               | 表示该会话的用户IPv6地址。                    |
| USRMSISDN          | 表示该会话的用户ID。                        |
| APN                | 表示该会话所属的APN信息。                     |
| SESSIONID/POLICYID | 表示该会话的会话/策略ID。                     |
| SERVINGPCRF        | 表示该会话的服务PCRF。                      |

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释   | 原因分析              | 处理建议               |
|------:|:--------|:------------------|:-------------------|
| 98510 | 会话不存在。  | 使用“用户标识”查找会话信息失败。 | 重新输入其他的“用户标识”进行查询。 |
