# 批量删除签约记录（CON PBATRMVSRV）

## 命令功能

**须知** 

该命令属于高危命令，批量删除签约记录操作可能对系统性能产生影响。因此执行该命令前，需联系华为技术支持确认后再执行。

该命令用于批量删除指定业务的所有签约记录，以方便运营商删除该业务。

该命令的使用场景：如果业务被用户订购后，则不能删除该业务，可通过本命令批量去签约后删除该业务。

## 注意事项

- 该命令会对满足签约了指定业务的用户进行批量删除签约处理，请谨慎执行。
- 混组场景下，该命令只能去签约5G侧的用户。
- 已过期的业务，无法使用该命令去签约。

## 参数说明

| 参数标识    | 参数名称     | 参数说明                                        |
|:--------|:---------|:--------------------------------------------|
| SRVNAME | 业务       | 用于指定删除哪个业务。 取值范围：长度不超过64的字符串。 默认值：无。        |
| MCIFLAG | 数据修改通知标志 | 用于设置是否发送数据修改通知消息给FE。 取值范围： FalseTrue 默认值：无。 |

## 使用实例

批量删除指定业务的所有签约记录：“业务”为“Service01”，“数据修改通知标志”为“False”。

```
CON PBATRMVSRV:SRVNAME="Service01",MCIFLAG=False;
```
