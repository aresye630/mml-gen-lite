# 查询营帐虚拟运营商号段（LST PMVNONSP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询营帐虚拟运营商号段。

## 注意事项

该命令最多支持显示999条营帐虚拟运营商号段记录。如果要查询全部记录，可以登录OM Portal界面，在“应用管理>MML”中选择“USCDB”网元，先后执行**LST MODULE**和**GET NODEINFO**命令获取全部营帐虚拟运营商号段记录，命令示例如下：

1. 执行**LST MODULE**命令查询模块号，设置“模块类型”为“PGW”，查询得到“模块号”为“9”。

   ```
   LST MODULE: MT=PGW;
   ```
2. 执行**GET NODEINFO**命令获取全部营帐虚拟运营商号段记录，设置“节点信息类型”为“GLOBALDATA”，“模块号”为“9”，“全局数据表名”为“P\_MVNO\_RANGE\_SUBID”。

   ```
   GET NODEINFO: TYPE=GLOBALDATA, MID=9, TABLE="P_MVNO_RANGE_SUBID";
   ```

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                    |
|:-------|:---------|:--------------------------------------------------------------------------------------------------------|
| NSP    | 号段前缀     | 用于指定系统按照某个号码前缀来查询号段信息；若不输入则表示所有的号码前缀。 取值范围：长度为1~32的字符串。 默认值：无。  说明： 系统不支持如下字符：“:”、“\'”、“=”、“,”、“\"”、“/” |
| MVNO   | 虚拟运营商序列号 | 用于指定系统按照某个虚拟运营商序列号来查询号段信息；若不输入则表示所有的虚拟运营商序列号。 取值范围：1～255 默认值：无。                                         |

## 使用实例

查询所有营帐虚拟运营商号段：

```
LST PMVNONSP:;
```

```
%%LST PMVNONSP:;%%

Total count = 1  
There is together 1 report  
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释         | 原因分析            | 处理建议                   |
|------:|:--------------|:----------------|:-----------------------|
| 90623 | 虚拟运营商号段记录不存在。 | 营帐虚拟运营商号段记录不存在。 | 确保要删除的营帐虚拟运营号段是已经存在的。  |
| 90625 | 虚拟运营商不存在。     | 虚拟运营商不存在。       | 执行ADD MVNO命令增加“虚拟运营商”。 |
