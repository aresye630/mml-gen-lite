# 修改帐户权限（CHG PACCOUNT）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于修改用户帐户权限，当用户帐户耗尽之后，系统会根据帐户权限决定是否下发流量，用户帐户权限包括正常和不受限两种。

## 注意事项

- 修改帐户权限，涉及到用户在帐户耗尽之后是否继续下发分片计算金额，请谨慎操作。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                                                                                                                           |
|:--------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER | 用户标识   | 标识一条用户帐户信息数据记录的关键字段之一，用于指定需要修改哪一个用户的帐户权限。 取值范围：长度不超过255的字符串。 默认值：无。                                                                                                                                            |
| ACTNAME       | 帐户名称   | 标识一条用户帐户信息数据记录的关键字段之一，用于指定需要修改的用户帐户。 帐户名称必须是已存在的帐户且该帐户需要在UPCF Web UI上配置。 取值范围：长度不超过32的字符串。 默认值：无。                                                                                                              |
| ACTPRIVILEGE  | 权限     | 标识一条用户帐户的权限信息，用于指定将用户帐户修改为哪种权限。 取值范围：“Normal”：表示用户帐户权限为正常。“PrivilegeA”：表示用户帐户权限为PrivilegeA。“PrivilegeB”：表示用户帐户权限为PrivilegeB。“PrivilegeC”：表示用户帐户权限为PrivilegeC。“Unrestricted”：表示用户帐户权限为Unrestricted。 默认值：Normal。 |

## 使用实例

修改帐户权限：“用户标识”为“46010381014\*\*\*\*”，“帐户名称”为“Bill\_001”，“权限”为“Normal”：

```
CHG PACCOUNT: USRIDENTIFIER="46010381014****", ACTNAME="Bill_001", ACTPRIVILEGE=Normal;
```
