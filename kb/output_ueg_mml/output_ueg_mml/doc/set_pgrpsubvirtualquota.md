# 设置组用户虚拟配额（SET PGRPSUBVIRTUALQUOTA）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于给组用户设置虚拟配额。

## 注意事项

当配额的“配额管理归属”为“UPCC”或“Provisioning”时，才可以设置组用户的虚拟配额。配额的“组配额分配方式”可以为“实际分配”或“缺省分配”。

## 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                                                                                                                |
|:----------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER   | 用户标识   | 用于指定需要设置哪一个组用户的虚拟配额。 取值范围：长度不超过255的字符串。 默认值：无。  说明： 该参数必须先由ADD PSUB命令定义，然后才能在此处索引。该用户不能是家庭共享配额组的主用户或从用户。                                                                                                                                            |
| ENOPERATIONTYPE | 操作类型   | 用于指定组用户设置的虚拟配额的操作类型。 取值范围：Modify：表示为组用户设置虚拟配额的总量或余额。Delete：表示删除组用户虚拟配额信息。 默认值：Modify。                                                                                                                                                               |
| QTANAME         | 配额名称   | 用于指定组用户的虚拟配额名称。 取值范围：长度不超过32的字符串。 默认值：无。  说明： 该配额名称必须已被组用户签约。当参数“ENOPERATIONTYPE”设置为“Modify”时，则必须设置此参数。当参数“ENOPERATIONTYPE”设置为“Delete”时，如果设置了此参数，则表示删除组用户指定配额名称的虚拟配额，否则删除组用户所有的虚拟配额，但当组用户同时拥有“组配额分配方式”为“实际分配”和“缺省分配”的虚拟配额时，不指定配额名称时，无法删除组用户所有的虚拟配额。 |
| QTAVALUE        | 总量     | 用于指定分配给组用户的虚拟配额大小。 取值范围：1～4294967294。 单位：KB。 默认值：无。  说明： 当配额的“组配额分配方式”为“实际分配”时，该参数值必须小于组用户配额的余额和可分配的配额值；当配额的“组配额分配方式”为“缺省分配”时，该参数值必须小于组用户配额的初始值。当参数“ENOPERATIONTYPE”设置为“Modify”时，则必须设置此参数。                                                          |

## 使用实例

1、指定为组用户设置的虚拟配额的“操作类型”为“Modify”，“用户标识”为“46010381014\*\*\*\*”，“配额名称”为“Quota01”，“总量”为“100”：

```
SET PGRPSUBVIRTUALQUOTA: USRIDENTIFIER="46010381014****", ENOPERATIONTYPE=Modify, QTANAME="Quota01", QTAVALUE=100;
```

2、指定为组用户设置的虚拟配额的“操作类型”为“Delete”，“用户标识”为“46010381014\*\*\*\*”，“配额名称”为“Quota01”：

```
SET PGRPSUBVIRTUALQUOTA: USRIDENTIFIER="46010381014****", ENOPERATIONTYPE=Delete, QTANAME="Quota01";
```
