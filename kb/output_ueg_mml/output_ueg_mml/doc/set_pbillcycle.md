# 设置用户结账日（SET PBILLCYCLE）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

修改结账日可能触发配额复位时间及余额重新计算，详见产品手册注意事项。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置某用户的结账日属性。必须在用户存在的情况下，设置此属性。命令执行后立即生效。

## 注意事项

修改用户的结账日可能会触发配额复位时间及余额的重新计算。

- 如果修改后的新结账日早于旧结账日，只会重新计算配额的下次复位时间，不会对配额的余额进行重新计算。
- 如果修改后的新结账日晚于旧结账日，且重新计算后的配额下次复位时间是在原来的下次复位时间之后，则会对配额的余额进行补偿计算。具体余额的补偿折算公式如下：

  折算后总余额 = 当前余额 + （配额总值 \*（新结账日-旧结账日）/ 下次复位时间所在月的天数）。

  **说明** 

  配额余额的补偿折算举例：当前是6月1号，把结账日从10号改到20号，当前余额是10KB，配额总值是30KB的话，那么折算后总余额 = 10KB +（30KB\*（20-10）/30天）= 20KB。

## 参数说明

| 参数标识             | 参数名称   | 参数说明                                                                                                                                                                                                                                                                              |
|:-----------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USRIDENTIFIER    | 用户标识   | 用于指定需要修改结账日的用户，且用户是已经存在的用户。该参数必须先由ADD PSUB命令增加，然后在此引用。 取值范围：长度不超过255的字符串。 默认值：无。                                                                                                                                                                                                  |
| USRBILLCYCLEDATE | 结帐日    | 用于设置用户的结帐日。 取值范围： 1～31：每月第几天为结帐日。97：每月倒数第三天为结帐日。例如：4月有30天，28号为结帐日。98：每月倒数第二天为结帐日。例如：4月有30天，29号为结帐日。99：每月最后一天为结帐日。例如：4月有30天，30号为结帐日。 默认值：无。  说明： 如果“结帐日”的值大于当月最大天数，并且“日期不存在则顺延”的取值为“是”，则结账日为下月第一天。如果“结帐日”的值大于当月最大天数，并且“日期不存在则顺延”的取值为“否”，则结账日为该月最后一天。29、30、31在二月均表示28号；在闰年的二月表示29号。 |

## 使用实例

修改用户账单日：“用户标识”为“46010381014\*\*\*\*”；修改“结帐日”为“3”

```
SET PBILLCYCLE: USRIDENTIFIER="46010381014****", USRBILLCYCLEDATE=3;
```
