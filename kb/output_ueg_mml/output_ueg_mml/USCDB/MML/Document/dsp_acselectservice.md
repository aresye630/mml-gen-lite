# 查询仲裁服务状态（DSP ACSELECTSERVICE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询仲裁服务状态。

本命令只适用于ACS服务，其他微服务请使用DSP ELECTSERVICE命令。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

无。

#### 使用实例

查询仲裁服务开关状态：

```
DSP ACSELECTSERVICE:;
```

```
RETCODE = 0  操作成功

结果如下:
-------------------------
       仲裁服务开关状态 =  使能
(结果个数 = 1)
 ---    END
```

#### 输出结果说明

| 输出项名称    | 输出项解释                                                                         |
|:---------|:------------------------------------------------------------------------------|
| 仲裁服务开关状态 | 该参数用于表示仲裁服务的开关状态。 使能：仲裁服务使能。去使能：仲裁服务去使能。未就绪：仲裁服务未就绪。当使用仲裁服务的部件未全部就绪时，会出现此种情况。 |
