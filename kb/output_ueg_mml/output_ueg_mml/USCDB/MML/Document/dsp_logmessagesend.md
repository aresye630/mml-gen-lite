# 查询日志发送的信息（DSP LOGMESSAGESEND）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询日志发送的信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| TARGET          | 目标     | 可选必选说明：必选参数 参数含义：日志消息发送目标。 数据来源：本端规划 取值范围：枚举类型。 NETCONF：NETCONF组件。 默认值：无                                     |
| TYPE            | 消息类型   | 可选必选说明：必选参数 参数含义：消息类型。 数据来源：本端规划 取值范围：枚举类型。 REPORT-EVENT：事件上报。 默认值：无                                         |
| BOARDTYPE       | 主控类型   | 可选必选说明：可选参数 参数含义：指定主控类型。 数据来源：本端规划 取值范围：枚举类型。 master：主主控。slave：备主控。 默认值：master                               |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

查询日志上报Notification的信息：

```
DSP LOGMESSAGESEND:TARGET=NETCONF,TYPE=REPORT-EVENT,SERVICEINSTANCE="vnfc";
```
