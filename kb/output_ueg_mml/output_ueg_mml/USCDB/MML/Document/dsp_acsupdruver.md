# 显示RU版本信息（DSP ACSUPDRUVER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询RU版本信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识              | 参数名称     | 参数说明                                                                             |
|:------------------|:---------|:---------------------------------------------------------------------------------|
| RUNAME            | RU名称     | 可选必选说明：可选参数 参数含义：该参数用于表示资源单元名称。 数据来源：本端规划 取值范围：1-63位字符串，区分大小写，不支持空格。 默认值：无       |
| BASICPKGVERSIONID | 基础软件包版本号 | 可选必选说明：可选参数 参数含义：该参数用于指定要加载的基础软件包版本号。 数据来源：本端规划 取值范围：1-63位字符串，区分大小写，不支持空格。 默认值：无 |

#### 使用实例

显示RU版本信息：

```
DSP ACSUPDRUVER:;
```

```
RETCODE = 0  操作成功 

结果如下:
-------------------------  
RU名称                     基础软件包版本号 
VNODE_UGW_VNFC_OMU_0001    V100R020C00B021
VNODE_UGW_VNFC_OMU_0002    V100R020C00B021
VNODE_UGW_VNFC_SPU_0064    V100R020C00B021
VNODE_UGW_VNFC_SPU_0065    NULL
(结果个数 = 4)  
---    END
```

#### 输出结果说明

| 输出项名称    | 输出项解释       |
|:---------|:------------|
| RU名称     | 表示资源单元名称。   |
| 基础软件包版本号 | 表示基础软件包版本号。 |
