# 查询流控参数（LST LASFLOWCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询LAS的流控参数信息：

- 若需要查询LAS的当前所有流控参数的信息，请不要输入任何参数。
- 若需要查询满足某一条件的LAS当前流控参数的信息，请输入“流控开关参数”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称                   | 参数说明                                                                                                                                                 |
|:----------|:-----------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
| FLWCTRFLG | 流控开关参数                 | 可选必选说明：可选参数 参数含义：用于指示系统需要按照是否开启“流控开关参数”来查询流控参数。 取值范围：OFF（关）：表示流控功能关闭。ON（开）：表示流控功能开启。MSGFC（仅消息阻塞流控）：表示仅消息阻塞流控。 默认值：无。 配置原则：系统初始设置值为“MSGFC(仅消息阻塞流控)”。  |
| CPUFLWSTR | CPU起控门限                | 可选必选说明：可选参数 参数含义：用于指示系统需要按照“CPU起控门限”的值来查询流控参数。 取值范围：10～100，单位为％。 默认值：无。 配置原则：仅当“流控开关参数”为“ON（开）”时该参数有效。系统初始设置值为“95”。                                  |
| CPUFLWEND | CPU解控门限                | 可选必选说明：可选参数 参数含义：用于指示系统需要按照“CPU解控门限”的值来查询流控参数。 取值范围：0～90，单位为％。 默认值：无。 配置原则：仅当“流控开关参数”为“ON（开）”时该参数有效。系统初始设置值为“85”。                                    |
| LDAPTSSTR | LDAP消息队列消息堆积时间起控门限(毫秒) | 可选必选说明：可选参数 参数含义：用于指示系统需要按照“LDAP消息队列消息堆积时间起控门限（毫秒）”的值来查询流控参数。 取值范围：40～200，单位为ms。 默认值：无。 配置原则：仅当“流控开关参数”为“ON（开）”或“MSGFC（仅消息阻塞流控）”时该参数有效。系统初始设置值为“80”。 |
| LDAPTSEND | LDAP消息队列消息堆积时间解控门限(毫秒) | 可选必选说明：可选参数 参数含义：用于指示系统需要按照“LDAP消息队列消息堆积时间解控门限（毫秒）”的值来查询流控参数。 取值范围：20～180，单位为ms。 默认值：无。 配置原则：仅当“流控开关参数”为“ON（开）”或“MSGFC（仅消息阻塞流控）”时该参数有效。系统初始设置值为“50”。 |

## 使用实例

查询LAS的流控参数信息。

```
LST LASFLOWCTRL:;
```

```
%%LST LASFLOWCTRL:;%%

RETCODE = 0  操作成功

操作结果如下
------------
                          流控开关参数  =  仅消息阻塞流控
                           CPU起控门限  =  95
                           CPU解控门限  =  85
LDAP消息队列消息堆积时间起控门限(毫秒)  =  80
LDAP消息队列消息堆积时间解控门限(毫秒)  =  50
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令操作成功的提示信息和相关参数，各参数含义请参见**MOD LASFLOWCTRL**命令的参数说明。
