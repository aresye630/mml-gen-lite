# 显示组件状态机信息（DSP DEVCOMPFSM）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示资源单元上指定组件的组件状态机信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                        |
|:----------------|:-------|:----------------------------------------------------------------------------------------------------------------------------|
| RUNAME          | RU名称   | 可选必选说明：必选参数 参数含义：该参数表示资源单元名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：使用DSP RU查看RU名称。                      |
| COMPTYPE        | 组件类型   | 可选必选说明：必选参数 参数含义：该参数表示组件类型。 数据来源：本端规划 取值范围：枚举类型。 DEVMA：DEVMA组件，该组件用于收集本资源单元设备属性、运行状态和设备事件数据上报给总控模块，同时执行来自总控模块的各种设备操作。 默认值：无 |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。                |

#### 使用实例

显示资源单元上指定组件的组件状态机信息：

```
DSP DEVCOMPFSM:RUNAME="CSDB_OM_RU_0001",COMPTYPE=DEVMA,SERVICEINSTANCE="vnfc";
```
