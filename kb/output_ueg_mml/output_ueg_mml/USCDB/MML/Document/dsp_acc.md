# 显示加速器信息（DSP ACC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示加速器的信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                        |
|:----------------|:-------|:----------------------------------------------------------------------------------------------------------------------------|
| RUNAME          | RU名称   | 可选必选说明：可选参数 参数含义：用于表示资源单元的名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。不支持空格，区分大小写。 默认值：无 配置原则：使用DSP RU查看RU名称。                      |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识，但不能填写0，0表示VNFP。 |

#### 使用实例

- 显示所有资源单元上的加速器信息：

  ```
  DSP ACC:SERVICEINSTANCE="vnfc";
  ```

  ```
  RETCODE = 0  操作成功

  结果如下:
  ------------------------
  RU名称                     加速器索引    加速器名称    加速器类型    加速器在位状态    加速器状态    配置错误码    状态错误码 

  CSDB_SD_RU_0067            0             acc0          sa            在位              不正常        0x0           0x4               
  CSDB_SD_RU_0068            0             acc0          sa            在位              不正常        0x0           0x4
  (结果个数 = 2)
  ---    END
  ```
- 显示指定资源单元上的所有加速器的信息，资源单元名称为CSDB\_SD\_RU\_0067：

  ```
  DSP ACC:RUNAME="CSDB_SD_RU_0067",SERVICEINSTANCE="vnfc";
  ```

  ```
  RETCODE = 0  操作成功

  结果如下:
  ------------------------
          RU名称  =  CSDB_SD_RU_0067
      加速器索引  =  0
      加速器名称  =  acc0
      加速器类型  =  sa
  加速器在位状态  =  在位
      加速器状态  =  不正常
      配置错误码  =  0x0
      状态错误码  =  0x4
  (结果个数 = 1)
  ---    END
  ```

#### 输出结果说明

| 输出项名称   | 输出项解释                                               |
|:--------|:----------------------------------------------------|
| RU名称    | 用于表示资源单元的名称。                                        |
| 加速器索引   | 用于表示加速器在资源单元内的索引。                                   |
| 加速器名称   | 用于表示加速器的名称。                                         |
| 加速器类型   | 用于表示加速器的类型。                                         |
| 加速器在位状态 | 用于表示加速器在位状态。 不在位：加速器为不在位状态。在位：加速器为在位状态。离线：加速器为离线状态。 |
| 加速器状态   | 用于表示加速器的状态。 正常：加速器状态正常。不正常：加速器状态不正常。                |
| 配置错误码   | 用于表示配置错误的错误码。                                       |
| 状态错误码   | 用于表示状态错误的错误码。                                       |
