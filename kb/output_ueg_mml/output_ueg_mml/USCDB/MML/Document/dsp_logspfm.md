# 显示日志中心性能统计信息（DSP LOGSPFM）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示日志中心性能统计信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

显示日志中心性能统计信息：

```
DSP LOGSPFM:SERVICEINSTANCE="vnfc";
```

```
RETCODE = 0  操作成功

结果如下:
--------
日志类型     日志数量    日志处理时间（毫秒）

普通日志     7530        378  
诊断日志     24181       838 
(结果个数 = 2)
---    END
```

#### 输出结果说明

| 输出项名称      | 输出项解释                                                     |
|:-----------|:----------------------------------------------------------|
| 日志类型       | 用来表示日志类型： 普通日志：包括事件日志、操作日志、安全日志、告警日志。诊断日志：记录网元模块间的维护定位信息。 |
| 日志数量       | 用来表示日志数量。                                                 |
| 日志处理时间（毫秒） | 用来表示日志处理时间，单位为毫秒。                                         |
