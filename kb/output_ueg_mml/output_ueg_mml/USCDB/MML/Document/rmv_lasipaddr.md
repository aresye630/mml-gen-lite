# 删除LAS IP地址（RMV LASIPADDR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，该操作可能会导致业务中断。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除USCDB侧LAS服务的IP地址。

## 注意事项

- 删除LAS服务的IP地址可能会导致第三方FE和LAS服务之间的业务中断，请谨慎执行此命令。
- 执行本命令之后，需要登录“USCDB MML命令”界面执行如下命令重启所有LAS服务才能生效。

  ```
  RST MSPROCESS: PROCOBJECT=PROCNAME, PROCNAME="CELL_UdrLas";
  ```
- 该命令不允许进行批操作。

## 参数说明

| 参数标识       | 参数名称         | 参数说明                                                                                                            |
|:-----------|:-------------|:----------------------------------------------------------------------------------------------------------------|
| LASIPINDEX | UDR LAS IP索引 | 可选必选说明：必选参数 参数含义：标识一个LAS服务IP地址的关键字段，用于指定需要删除哪一条索引配置的IP地址。操作员可以使用LST LASIPADDR命令查询获得。 取值范围：1～1024 默认值：无。 配置原则：无。 |

## 使用实例

删除LAS服务的IP地址，“UDR LAS IP索引”为“1”。

```
RMV LASIPADDR: LASIPINDEX=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
