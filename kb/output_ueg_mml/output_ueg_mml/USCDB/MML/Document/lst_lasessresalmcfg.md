# 查询LAS关键资源告警配置（LST LASESSRESALMCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询LAS微服务关键资源监控的告警上报阈值，告警恢复阈值，阈值类型以及是否开启监控功能。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                         |
|:---------|:-------|:---------------------------------------------------------------------------------------------|
| ESSRESID | 关键资源   | 可选必选说明：可选参数。 参数含义：用于标识需查询监控关键资源不足告警上报阈值和恢复阈值的关键资源类型。 取值范围：SERVICEMEMORY(服务内存) 默认值：无。 配置原则：无。 |

## 使用实例

查询LAS微服务关键资源告警配置信息。

```
LST LASESSRESALMCFG: ESSRESID=SERVICEMEMORY;
```

```
%%LST LASESSRESALMCFG: ESSRESID=SERVICEMEMORY;%%

```
