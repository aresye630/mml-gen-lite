# 查询虚拟节点信息（LST VNODE）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查询虚拟节点信息。

#### 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                           |
|:---------|:---------|:-------------------------------------------------------------------------------|
| VNFCNAME | VNFC实例名称 | 可选必选说明：必选参数 参数含义：该参数用于指定VNFP或VNFC实例名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～63。 默认值：无 |

#### 使用实例

查询虚拟节点信息：

```
LST VNODE:VNFCNAME="kk";
```

```
RETCODE = 0  操作成功

结果如下:
-------------------------
                虚拟节点名称   = VNODE_VNRS_VNFC_OMU_0001 
            虚拟节点类型名称   = VNODE_VNRS_VNFC_OMU
      虚拟节点亲和组实例名称   = VNODEG_XXX_OMU_001
                VNFC实例名称   = kk
(结果个数 = 1)
---    END
```

#### 输出结果说明

| 输出项名称       | 输出项解释              |
|:------------|:-------------------|
| 虚拟节点名称      | 用于表示虚拟节点名称。        |
| 虚拟节点类型名称    | 用于表示虚拟节点类型。        |
| 虚拟节点亲和组实例名称 | 用于表示虚拟节点亲和组实例名称。   |
| VNFC实例名称    | 用于表示VNFP或VNFC实例名称。 |
