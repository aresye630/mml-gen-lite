# 查询LDAP客户端IP地址(LST LDAPIP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在LDAP服务端查询数据，此数据存放在LDAP服务端的第三方FE IP地址列表内，供LDAP服务端鉴权使用。

- 若需要查询全部LDAP客户端IP地址的信息，不需要输入参数。
- 若需要查询某个LDAP客户端IP地址的信息，请输入“LDAP客户端IP地址”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称        | 参数说明                                                                                                    |
|:-------|:------------|:--------------------------------------------------------------------------------------------------------|
| IPV4IP | LDAP客户端IP地址 | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个LDAP客户端IP地址来查询数据记录；若不输入，则表示所有LDAP客户端的IP地址。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。 |
| IPDESC | IP描述        | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个IP描述来查询数据记录；若不输入，则表示所有LDAP客户端IP的描述。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。        |

## 使用实例

1. 查询USCDB内的LDAP客户端IP地址。

   ```
   LST LDAPIP:;
   ```

   ```
   %%LST LDAPIP:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   LDAP客户端IP地址        IP描述  

   192.168.10.16           test1   
   192.168.5.24            mrk     
   (结果个数 = 2)

   ---    END
   ```
2. 查询USCDB内的LDAP客户端IP地址，“LDAP客户端IP地址”为“192.168.10.16”。

   ```
   LST LDAPIP: IPV4IP="192.168.10.16";
   ```

   ```
   %%LST LDAPIP: IPV4IP="192.168.10.16";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------

         LDAP客户端IP地址  =  192.168.10.16
                   IP描述  =  test1
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令操作成功的提示信息和相关参数，各参数含义请参见**ADD LDAPIP**命令的参数说明。
