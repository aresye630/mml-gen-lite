# 增加LDAP客户端IP地址(ADD LDAPIP)

## 命令功能

该命令用于在LDAP服务端增加客户端IP地址，只有通过该命令增加的有效IP地址，才允许LDAP客户端建立与此LDAP服务端的连接，否则请求会被拒绝。此数据存放在LDAP服务端的第三方FE IP地址列表内，供LDAP服务端鉴权使用。

作为BE的USCDB网元通过LAS服务提供了标准的LDAP接口，可以与第三方FE通信。

BE与第三方FE之间通过IP建立连接。在LDAP连接中：

- BE作为LDAP服务端
- 第三方FE作为LDAP客户端

出于安全考虑，BE通过以下两个信息对第三方FE进行鉴权，只有二者同时满足，第三方FE才被允许建立与BE的通信。

- LDAP客户端的IP地址
- LDAP服务端为LDAP客户端定义的用户名和密码

LDAP客户端使用**ADD LDAPUSER**增加的客户端用户名和密码，并用通过该命令增加的IP登录，才能通过LDAP服务端的鉴权。

## 注意事项

最大支持100个LDAP客户端IP。

## 参数说明

| 参数标识   | 参数名称        | 参数说明                                                                                                                                   |
|:-------|:------------|:---------------------------------------------------------------------------------------------------------------------------------------|
| IPV4IP | LDAP客户端IP地址 | 可选必选说明：必选参数 参数含义：用于指定要增加的LDAP客户端的IP地址。此IP地址需要先由第三方FE定义后才能在此引用。其类型必须与LDAP服务端的IP地址相匹配，统一为IPv4类型且在同一网段。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。 |
| IPDESC | IP描述        | 可选必选说明：可选参数 参数含义：用于描述该IP地址用途的说明性文字。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                                                                  |

## 使用实例

某第三方FE需要通过LDAP接口对USCDB进行访问，此时需要为此第三方FE添加“LDAP客户端IP地址”为“192.168.123.111”，“IP描述”为“for test”的LDAP客户端IP地址。

```
ADD LDAPIP: IPV4IP="192.168.123.111", IPDESC="for test";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释         | 原因分析                                | 处理建议                                                                       |
|-------:|:--------------|:------------------------------------|:---------------------------------------------------------------------------|
| 279522 | 记录数已经达到最大元组数。 | USCDB对表中可存的记录数有限制，当记录数达到100时，不能再添加。 | 达到最大元组数限制后，不允许再添加。                                                         |
| 279523 | 该IP地址无效。      | 输入的“LDAP客户端IP地址”类型与LDAP服务端IP地址不匹配。  | 输入的IP地址类型必须与LDAP服务端的IP地址相匹配，统一为IPv4类型且在同一网段。此IP地址需要先由第三方FE定义后才能在此引用。       |
| 279524 | 该IP地址已存在。     | 输入的“LDAP客户端IP地址”取值在系统中已存在。          | 执行LST LDAPIP命令查询系统中已存在的“LDAP客户端IP地址”。重新输入参数“LDAP客户端IP地址”取值，确保取值不与查询结果存在重复。 |
