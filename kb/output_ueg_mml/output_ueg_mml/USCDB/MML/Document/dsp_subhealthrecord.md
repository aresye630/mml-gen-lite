# 显示base平面亚健康链路历史信息（DSP SUBHEALTHRECORD）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示base平面亚健康链路历史信息。

当系统上报“ALM-100319 Base平面Pod级亚健康告警”时，可以执行该命令辅助定位。

## 注意事项

无

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

## 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                             |
|:---------------|:---------|:---------------------------------------------------------------------------------|
| SRCPODID       | 源端Pod ID | 可选必选说明：可选参数  参数含义：源端Pod ID。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~127。  默认值：无  配置原则：无  |
| ALARMSTARTTIME | 查询告警起始时间 | 可选必选说明：可选参数  参数含义：查询告警的起始时间。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无 |
| ALARMENDTIME   | 查询告警结束时间 | 可选必选说明：可选参数  参数含义：查询告警结束时间。  数据来源：本端规划  取值范围：字符串类型，输入长度范围是0~255。  默认值：无  配置原则：无  |

## 使用实例

显示base平面亚健康链路历史信息。

```
%%DSP SUBHEALTHRECORD:;%%
RETCODE = 0  操作成功

结果如下
--------
  源端Pod ID  =  sfm-pod-59948bf4d8-fg9qx
目的端Pod ID  =  netcssim-pod-bdc87787d-l4wt2
告警上报时间  =  2023-06-21 14:25:25
(结果个数 = 1)

---    END
```
