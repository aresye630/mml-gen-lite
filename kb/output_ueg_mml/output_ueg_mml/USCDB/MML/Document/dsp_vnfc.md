# 显示VNFC（DSP VNFC）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于查看VNFC信息，比如VNFC的ID、名称、类型、状态，以及启动时间等信息，通过这些信息可以了解启动的VNFC是否正确，及当故障发生时，依据查询到的信息进行故障诊断。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组；G\_2，操作员级别命令组；G\_3，用户级别命令组

#### 参数说明

| 参数标识     | 参数名称   | 参数说明                                                             |
|:---------|:-------|:-----------------------------------------------------------------|
| VNFCNAME | VNFC名称 | 可选必选说明：可选参数 参数含义：VNFC名称。 数据来源：本端规划 取值范围：字符串类型，输入长度范围为1～31。 默认值：无 |

#### 使用实例

显示VNFC：

```
DSP VNFC:;
```

#### 输出结果说明

| 输出项名称      | 输出项解释                                                                                             |
|:-----------|:--------------------------------------------------------------------------------------------------|
| VNFC ID    | VNFC ID。                                                                                          |
| VNFC状态     | VNFC状态，包含运行态和初始态。                                                                                 |
| VNFC创建时间   | VNFC创建时间。                                                                                         |
| 内联管理口IP    | 内联管理口IP地址。                                                                                        |
| VNFC名称     | VNFC名称。                                                                                           |
| VNFC类型名称   | VNFC类型名称。                                                                                         |
| 资源类型       | 资源分配规则，共享或互斥。不指定此参数创建VNFC，VNFC主控与VNFP主控共部署。                                                       |
| VM1的名称     | 指定部署VNFC主控的VM名称。VM1和VM2互为主备。由系统选择主备。  说明： Full-stack裸机场景下，VM1的名称为NULL。                            |
| VM2的名称     | 指定部署VNFC主控的VM名称。VM2和VM1互为主备。由系统选择主备。  说明： Full-stack裸机场景下，VM2的名称为NULL。                            |
| 基础版本       | VNFC基础版本（通过DSP SOFTWARE命令获取）。如果执行DSP VERSION查询出VNFP版本号带有补丁版本号，则必须通过DSP SOFTWARE查询出对应的基线版本号，在此处配置。 |
| 补丁版本       | 补丁版本（通过DSP SOFTWARE命令获取）。                                                                         |
| 初始启动配置文件名称 | 初始启动配置文件的名称。                                                                                      |
