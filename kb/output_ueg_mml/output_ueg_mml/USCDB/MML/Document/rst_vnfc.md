#### 命令功能

**须知** 

本命令属于高危命令，操作不当会导致业务故障，如果是强制重启，可能会导致正在操作的配置丢失。请谨慎使用并联系华为技术支持协助操作。

该命令用于重启系统。

#### 注意事项

- 该命令执行后立即生效。
- 在VNFC上运行该命令后，只复位该VNFC上所有的资源块，资源块所在资源并不复位，重新启动后处于正常运行状态，该复位命令会保存配置信息，复位期间运行在该VNFC上的业务会中断。
- 对于多次尝试使用该命令默认参数重启系统时，一直提示“系统正忙，请稍后重试。”，如果确认系统有故障需要强制重启，可以通过输入参数ISFORCEOPER=TRUE，强制重启系统。但是，可能系统重启后，会因为部分配置未提交成功而丢失。需谨慎操作。
- 如需要通过日志查看历史操作记录，可通过操作日志或者诊断日志确认，具体操作请参考产品文档“日志存储”章节。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                                                                            |
|:----------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ISFORCEOPER     | 强制操作标志 | 可选必选说明：可选参数 参数含义：该参数用于指定是否强制重启。对于多次尝试使用该参数默认值“FALSE”或不输入该参数重启系统时，一直提示“系统正忙，请稍后重试。”，如果确认系统有故障需要强制重启，可以通过指定该参数为“TRUE”，强制重启系统。 数据来源：本端规划 取值范围：布尔类型，输入格式为“TRUE”或者“FALSE”。 默认值：FALSE |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。                                                                    |

#### 使用实例

重启系统：

```
RST VNFC:SERVICEINSTANCE="vnfc";
```
