# 查询LAS IP地址(LST LASIPADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询LAS服务IP地址配置信息：

- 若需要查询LAS服务的全部IP地址配置信息，请不要输入任何参数。
- 若需要查询LAS服务的满足某个条件的IP地址配置信息，请输入对应的“UDR LAS IP索引”或其他参数或这些参数的组合 。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称              | 参数说明                                                                                                                                                                                     |
|:-----------|:------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LASIPINDEX | UDR LAS IP索引      | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个LAS IP索引来查询LAS的IP地址信息；若不输入，则表示查询所有LAS IP索引所对应的LAS服务的IP地址信息。 取值范围：1～1024 默认值：无。 配置原则：无。                                                                     |
| IPVER      | IP类型              | 可选必选说明：可选参数。 参数含义：用于指示系统需要按照哪个IP类型来查询LAS服务IP地址信息；若不输入，则表示查询所有IP类型所对应的LAS服务IP地址信息。 取值范围： IPV4(IPV4)：当系统要求使用IPv4类型的IP地址时选择此选项。默认值：无。 配置原则：无。                                               |
| IPVPNNAME  | IP地址的VPN名称        | 可选必选说明：条件可选参数。 参数含义：用于指示系统需要按照哪个IP地址的VPN名称来查询LAS服务的IP地址信息；若不输入，则表示查询所有IP地址的VPN名称的LAS服务IP地址信息。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：该参数必须先由ADD L3VPNINST命令定义后才能在此处引用，仅当本命令中的“IP类型”参数取值有效时该参数有效。 |
| IPV4IP     | 本地Location IPV4地址 | 可选必选说明：条件可选参数。 参数含义：用于指示系统按照哪个IPv4地址来查询LAS服务IP地址信息；若不输入，则表示查询所有LAS服务IP地址信息。 取值范围：IPv4格式的地址。 默认值：无。 配置原则：仅当本命令中的“IP类型”参数取值为“IPV4(IPV4)”时该参数有效。                                            |

## 使用实例

查询指定LAS服务的IP配置信息，“IP类型”为“IPV4”。

```
LST LASIPADDR: IPVER=IPV4;
```

返回结果如下：

```
%%LST LASIPADDR: IPVER=IPV4;%%
RETCODE = 0  操作成功

操作结果如下
------------
        UDR LAS IP索引  =  1
                IP类型  =  IPV4
       IP地址的VPN名称  =  VRF_CC_DATA 
 本地Location IPV4地址  =  192.168.100.1
 (结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD LASIPADDR**命令的参数说明。
