## 命令功能

**须知** 

该命令属于高危命令，该操作将修改流控参数，操作不当将导致流控不能触发或过早触发，并导致业务严重呼损。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对流控参数信息进行修改或调整。

流控即消息的流量控制，是系统的一种自我保护机制。当系统在大话务量冲击下，通过流控特性保持健康的运行状态，始终提供最大能力的消息响应服务，防止由于负载过大而导致设备瘫痪。流控功能开启后，LDAP接口流量控制可对第三方FE通过LDAP接口发送的请求消息进行控制，负责流控功能的软件模块会根据当前LAS的负荷状态和配置的流控参数信息，自动开启流控和解除流控。

该命令的使用场景：用于异常场景下的调测，当出现系统不稳定，如频繁起控解控，操作员可以使用本命令修改流控参数以使系统保持健康的运行状态，始终提供最大能力的消息响应服务。

## 注意事项

- 各参数起控门限的值一定要大于解控门限的值。
- 起控后，将限制访问LAS的请求消息的处理，可能造成部分业务请求失败。
- 在缺省的情况下，系统预置了如下参数取值:

  ```
                            流控开关参数  =  仅消息阻塞流控
                             CPU起控门限  =  95
                             CPU解控门限  =  85
  LDAP消息队列消息堆积时间起控门限(毫秒)  =  80
  LDAP消息队列消息堆积时间解控门限(毫秒)  =  50
  ```
- 当LAS的负荷过高产生流控上报“ALM-15300 LAS流控启用”时，如果通过执行本命令将流控开关参数修改为关闭，流控状态不会立刻解除，告警也不会立刻清除，需等待LAS负荷恢复正常状态。
- 该命令不允许进行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。

## 参数说明

| 参数标识      | 参数名称                   | 参数说明                                                                                                                                                                                                |
|:----------|:-----------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FLWCTRFLG | 流控开关参数                 | 可选必选说明：必选参数 参数含义：用于指定流控功能是否开启。 取值范围：OFF（关）：表示流控功能关闭。ON（开）：表示流控功能开启。MSGFC（仅消息阻塞流控）：表示仅消息阻塞流控。 默认值：无。 配置原则：系统初始设置值为“MSGFC(仅消息阻塞流控)”。                                                                  |
| CPUFLWSTR | CPU起控门限                | 可选必选说明：可选参数 参数含义：用于指定当CPU的使用率大于或等于该值时开启流控。“CPU起控门限”的值必须比“CPU解控门限”的值至少大10。 取值范围：10～100，单位为％。 默认值：无。 配置原则：仅当“流控开关参数”为“ON（开）”时该参数有效。系统初始设置值为“95”。                                                      |
| CPUFLWEND | CPU解控门限                | 可选必选说明：可选参数 参数含义：用于指定当CPU的使用率小于或等于该值时解除流控。“CPU解控门限”的值必须比“CPU起控门限”的值至少小10。 取值范围：0～90，单位为％。 默认值：无。 配置原则：仅当“流控开关参数”为“ON（开）”时该参数有效。系统初始设置值为“85”。                                                        |
| LDAPTSSTR | LDAP消息队列消息堆积时间起控门限(毫秒) | 可选必选说明：可选参数 参数含义：用于指定当LDAP队列消息堆积时间大于或等于该值时开启流控。“LDAP消息队列消息堆积时间起控门限(毫秒)”必须比“LDAP消息队列消息堆积时间解控门限(毫秒)”的值至少大20。 取值范围：40～200，单位为ms。 默认值：无。 配置原则：仅当“流控开关参数”为“ON（开）”或“MSGFC（仅消息阻塞流控）”时该参数有效。系统初始设置值为“80”。   |
| LDAPTSEND | LDAP消息队列消息堆积时间解控门限(毫秒) | 可选必选说明：可选参数 参数含义：用于指定当LDAP队列消息堆积时间小于或等于该值时解除流控。“LDAP消息队列消息堆积时间解控门限(毫秒)”的值必须比“LDAP消息队列消息堆积时间起控门限(毫秒)”的值至少小20。 取值范围：20～180，单位为ms。 默认值：无。 配置原则：仅当“流控开关参数”为“ON（开）”或“MSGFC（仅消息阻塞流控）”时该参数有效。系统初始设置值为“50”。 |

## 使用实例

修改流控参数，设置“流控开关参数”为“ON(开)”，“CPU起控门限”为“95”，“CPU解控门限”为“85”，“LDAP消息队列消息堆积时间起控门限(毫秒)”为“80”，“LDAP消息队列消息堆积时间解控门限(毫秒)”为“50”：

```
MOD LASFLOWCTRL: FLWCTRFLG=ON, CPUFLWSTR=95, CPUFLWEND=85, LDAPTSSTR=80, LDAPTSEND=50;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
