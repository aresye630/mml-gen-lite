## 命令功能

**须知** 

该命令属于高危命令，该操作将修改TLS协议配置，操作不当将造成业务严重损失，且必须重启服务才能生效。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置LDAP接口使用的TLS协议相关配置。

该命令的使用场景：系统LDAP接口启用TLS协议后，用于修改TLS的协议配置。

## 注意事项

- 执行**LST LASINSP**命令，查询软参“LDAPTLSSWITCH”的值，当软参“LDAPTLSSWITCH”设置为“1”时，本命令设置才有效。否则，执行**MOD LASINSP**命令，修改软参“LDAPTLSSWITCH”的值为“1”后，再执行本命令。
- 执行本命令之后，需要登录“USCDB MML命令”界面执行如下命令重启所有LAS服务才能生效。

  ```
  RST MSPROCESS: PROCOBJECT=PROCNAME, PROCNAME="CELL_UdrLas";
  ```

## 使用实例

用户需要配置使用安全的TLS协议及算法用于LAS的LDAP接口时，需要执行该命令进行TLS协议版本和算法的配置：“协议版本”为“TLS1.2”、“强加密套件”为“全部选中”、“TLS配置描述”为“TLS Config”。

```
SET LASTLSCFG: PROTOCOLVER=TLS1.2-1, STRONGSUITE=TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256-1&TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384-1&TLS_DHE_RSA_WITH_AES_128_GCM_SHA256-1&TLS_DHE_RSA_WITH_AES_256_GCM_SHA384-1&TLS_DHE_DSS_WITH_AES_128_GCM_SHA256-1&TLS_DHE_DSS_WITH_AES_256_GCM_SHA384-1&TLS_ECDHE_ECDSA_WITH_AES_128_GCM_SHA256-1&TLS_ECDHE_ECDSA_WITH_AES_256_GCM_SHA384-1, DESCRIPTION="TLS Config";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                   | 原因分析                     | 处理建议                          |
|-------:|:------------------------|:-------------------------|:------------------------------|
| 275391 | “强加密套件”和“兼容加密套件”不能同时为空。 | “强加密套件”和“兼容加密套件”不能同时为空。  | 输入“强加密套件”或者“兼容加密套件”，再重新执行本命令。 |
| 275445 | PROTOCOLVER参数不能都清除。     | 配置“协议版本”时，不能将所有“协议版本”清除。 | 请至少选择一个“协议版本”后再重新执行该命令。       |
