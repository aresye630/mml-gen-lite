# 增加LAS IP地址（ADD LASIPADDR）

- 注意事项

## 命令功能

**须知** 

该命令属于高危命令，该操作可能会导致业务中断。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于增加USCDB侧LAS服务的IP地址。

当第三方FE需要通过LDAP接口访问USCDB时，需要增加USCDB侧LAS服务的IP地址，用于实现USCDB与第三方FE之间的通信。

## 注意事项

- 执行本命令之后，需要登录“USCDB MML命令”界面执行如下命令重启所有LAS服务才能生效。

  ```
  RST MSPROCESS: PROCOBJECT=PROCNAME, PROCNAME="CELL_UdrLas";
  ```
- 该命令只能添加一条“IP类型”为“IPv4”的IP地址记录。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识       | 参数名称              | 参数说明                                                                                                                                                             |
|:-----------|:------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| LASIPINDEX | UDR LAS IP索引      | 可选必选说明：必选参数 参数含义：本参数用于指定LAS服务IP地址对应的IP索引，该索引在系统中唯一。 取值范围：1～1024 默认值：无。 配置原则：无。                                                                                   |
| IPVER      | IP类型              | 可选必选说明：必选参数 参数含义：用于指定IP地址类型。 取值范围： IPV4(IPV4)：当系统要求使用IPv4类型的IP地址时选择此选项。默认值：无。 配置原则：无。                                                                            |
| IPVPNNAME  | IP地址的VPN名称        | 可选必选说明：条件必选参数 参数含义：用于指定“本地Location IPV4地址”或“本地Location IPV6地址”的VPN名称。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：该参数必须先由ADD L3VPNINST命令定义后才能在此处引用，仅当本命令中的“IP类型”参数取值有效时该参数有效。 |
| IPV4IP     | 本地Location IPV4地址 | 可选必选说明：条件必选参数 参数含义：用于指定IPv4类型的本地IP地址，由运营商统一规划。 取值范围：IPv4格式的地址。 默认值：无。 配置原则：仅当本命令中的“IP类型”参数取值为“IPV4(IPV4)”时该参数有效。                                                 |

## 使用实例

在某开局场景，增加LAS服务IP地址，“UDR LAS IP索引”为“1”，“IP类型”为“IPV4(IPV4)”，“IP地址的VPN名称”为“VRF\_CC\_VPN”，“本地Location IPV4地址”为“192.168.100.1”：

```
ADD LASIPADDR: LASIPINDEX=1, IPVER=IPV4, IPVPNNAME="VRF_CC_VPN", IPV4IP="192.168.100.1";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
