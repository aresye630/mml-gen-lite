# 显示RU版本信息（DSP UPDRUVER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示RU版本信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识              | 参数名称     | 参数说明                                                                                                                        |
|:------------------|:---------|:----------------------------------------------------------------------------------------------------------------------------|
| RUNAME            | RU名称     | 可选必选说明：可选参数 参数含义：该参数用于表示资源单元名称。 数据来源：本端规划 取值范围：1-63位字符串，区分大小写，不支持空格。 默认值：无                                                  |
| BASICPKGVERSIONID | 基础软件包版本号 | 可选必选说明：可选参数 参数含义：该参数用于指定要加载的基础软件包版本号。 数据来源：本端规划 取值范围：1-63位字符串，区分大小写，不支持空格。 默认值：无                                            |
| SERVICEINSTANCE   | 服务实例     | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识，但不能填写0，0表示VNFP。 |

#### 使用实例

显示RU版本信息：

```
DSP UPDRUVER:SERVICEINSTANCE="vnfc";
```


|:---------|:------------|
