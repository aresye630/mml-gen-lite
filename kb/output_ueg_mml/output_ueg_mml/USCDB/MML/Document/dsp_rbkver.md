# 显示升级可回退版本信息（DSP RBKVER）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例
- 输出结果说明

#### 命令功能

该命令用于显示升级维护可回退版本信息。

在日常的维护和版本升级时，可使用本命令显示系统可回退的基础软件包和补丁版本信息。

#### 注意事项

无。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| RBKTYPE         | 回退类型   | 可选必选说明：可选参数 参数含义：该参数用于指定回退类型。 数据来源：本端规划 取值范围：枚举类型。 LAST：上一个版本。BASESOFTWARE：基础版本。PATCH：补丁。 默认值：LAST           |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

显示可回退版本信息：

```
DSP RBKVER:SERVICEINSTANCE="vnfc";
```

```
RETCODE = 0  操作成功 

结果如下:  
------------------------- 
        回退类型 = 基础版本
基础软件包版本号 = V100R005C00
      补丁版本号 = SPH0010
(结果个数 = 1)  
---    END
```

#### 输出结果说明

| 输出项名称    | 输出项解释                   |
|:---------|:------------------------|
| 回退类型     | 表示回退类型。                 |
| 基础软件包版本号 | 表示针对一种回退类型，回退后系统的基础版本号。 |
| 补丁版本号    | 表示针对一种回退类型，回退后系统的补丁版本号。 |
