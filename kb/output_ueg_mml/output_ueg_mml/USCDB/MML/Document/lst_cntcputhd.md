# 查询容器CPU阈值（LST CNTCPUTHD）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询容器CPU阈值。

## 注意事项

该命令执行后立即生效。

#### 操作用户权限

G\_1，管理员级别命令组

## 参数说明

无

## 使用实例

查询容器CPU告警阈值。

```
%%LST CNTCPUTHD:;%%
RETCODE = 0  操作成功

结果如下
------------------------
告警上报门限  =  90
告警恢复门限  =  80
(结果个数 = 1)
```

## 输出结果说明

| 输出项名称   | 输出项解释          |
|:--------|:---------------|
| 告警上报门限  | 该参数用于指定告警上报门限。 |
| 告警恢复门限  | 该参数用于指定告警恢复门限。 |
