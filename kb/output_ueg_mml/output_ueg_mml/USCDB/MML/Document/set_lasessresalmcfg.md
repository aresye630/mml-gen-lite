# 设置LAS关键资源告警配置（SET LASESSRESALMCFG）

## 命令功能

该命令用于设置LAS微服务关键资源监控的告警上报阈值、告警恢复阈值以及是否开启监控功能。

该命令的使用场景：系统通过内部定时器，以5秒为周期定时检查LAS微服务关键资源的使用率，并判断是否要上报**ALM-15301 关键资源使用率过高**告警或**ALM-15302 关键资源不足**告警。

如果修改了告警上报阈值或恢复阈值，系统会在下一次检查时按照最新阈值重新判断是否上报或恢复**ALM-15301 关键资源使用率过高**告警或**ALM-15302 关键资源不足**告警。

## 注意事项

- 各级告警阈值与恢复阈值需满足如下限制：
  - “一级告警阈值”大于“一级告警恢复阈值”。
  - “一级告警恢复阈值”大于“二级告警阈值”。
  - “二级告警阈值”大于“二级告警恢复阈值”。
  - “二级告警恢复阈值”大于“0”。
  - “一级告警阈值”对于百分比类型需要小于等于“100”。

系统初始设置的LAS微服务关键资源取值如下表1所示：

| 关键资源   | 阈值类型   |   二级告警阈值 |   二级告警恢复阈值 |   一级告警阈值 |   一级告警恢复阈值 | 状态   |
|:-------|:-------|---------:|-----------:|---------:|-----------:|:-----|
| 服务内存   | 百分比    |       93 |         91 |       98 |         96 | ON   |

## 参数说明

| 参数标识            | 参数名称     | 参数说明                                                                                                         |
|:----------------|:---------|:-------------------------------------------------------------------------------------------------------------|
| ESSRESID        | 关键资源     | 可选必选说明：必选参数 参数含义：用于标识需设置监控关键资源不足告警上报阈值和恢复阈值的关键资源类型。 取值范围：SERVICEMEMORY(服务内存) 默认值：无。 配置原则：无。                  |
| LEVEL2ALMTHD    | 二级告警阈值   | 可选必选说明：条件可选参数 参数含义：用于标识二级过载告警阈值。 取值范围：0～100。 默认值：无。 配置原则： “二级告警阈值”需要小于“一级告警恢复阈值”，且大于“二级告警恢复阈值”。              |
| LEVEL2ALMRCYTHD | 二级告警恢复阈值 | 可选必选说明：条件可选参数 参数含义：用于标识二级过载告警恢复阈值。 取值范围：0～100。 默认值：无。 配置原则： “二级告警恢复阈值”需要小于“二级告警阈值”，且大于“0”。                   |
| LEVEL1ALMTHD    | 一级告警阈值   | 可选必选说明：条件可选参数 参数含义：用于标识一级过载告警阈值。 取值范围：0～100。 默认值：无。 配置原则： “一级告警阈值”需要大于“一级告警恢复阈值”，“一级告警阈值”对于百分比类型需要小于等于“100”。 |
| LEVEL1ALMRCYTHD | 一级告警恢复阈值 | 可选必选说明：条件可选参数 参数含义：用于标识一级过载告警恢复阈值。 取值范围：0～100。 默认值：无。 配置原则： “一级告警恢复阈值”需要小于“一级告警阈值”，且大于“二级告警阈值”。              |
| ENABLESTATUS    | 状态       | 可选必选说明：可选参数 参数含义：用于标识是否监控关键资源上报告警。 取值范围： OFF(关闭)：表示系统不监控某项关键资源。ON(打开)：表示系统会监控某项关键资源。 默认值：无。 配置原则：无。          |

## 使用实例

设置“服务内存”关键资源告警相关配置信息为：二级告警阈值为“85”，二级告警恢复阈值为“82”，一级告警阈值为“95”，一级告警恢复阈值为“92”且监控该关键资源时，配置命令示例如下：

```
SET LASESSRESALMCFG: ESSRESID=SERVICEMEMORY, LEVEL2ALMTHD=85, LEVEL2ALMRCYTHD=82, LEVEL1ALMTHD=95, LEVEL1ALMRCYTHD=92, ENABLESTATUS=ON;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。
