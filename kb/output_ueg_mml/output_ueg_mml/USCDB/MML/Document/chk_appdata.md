# 检查APP配置数据（CHK APPDATA）

- 命令功能
- 注意事项
- 操作用户权限
- 参数说明
- 使用实例

#### 命令功能

该命令用于检查APP配置数据和OMU配置数据是否一致。如果数据不一致，则记录差异信息。用户可以通过**DSP APPDATADIFF**命令查询差异信息。

#### 注意事项

- 该命令执行后立即生效。
- 执行该命令会对系统加锁，导致配置命令无法执行。操作结束后，可以正常进行配置。

#### 操作用户权限

G\_1，管理员级别命令组

#### 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                         |
|:----------------|:-------|:-------------------------------------------------------------------------------------------------------------|
| PROCESSID       | 进程ID   | 可选必选说明：必选参数 参数含义：进程ID。 数据来源：本端规划 取值范围：整数类型，取值范围为0～4294967295。 默认值：无                                          |
| SERVICEINSTANCE | 服务实例   | 可选必选说明：必选参数 参数含义：该参数表示大颗粒服务实例名称。 数据来源：本端规划 取值范围：字符串类型，通过LST VNFC命令获取。 默认值：无 配置原则：只能填写通过LST VNFC命令查询到的管理代理标识。 |

#### 使用实例

检查3号进程APP配置数据和OMU是否一致：

```
CHK APPDATA:PROCESSID=3,SERVICEINSTANCE="vnfc";
```
