# 加载远端DSG模块信息(LOD RDSG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**说明** 

该命令在25.1.0版本不支持，命令功能已由**SYN RDSG**命令替代。

该命令用于将同步到本端网元OMU表中的RDSG配置信息加载到USCDB网元的DSG模块中。

## 注意事项

该命令需要在执行**SYN RDSG**后执行。

## 参数说明

| 参数标识   | 参数名称         | 参数说明                                                                                                                                                                                                                                                    |
|:-------|:-------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RLOCID | 远端Location标识 | 用于标识远端Location，远端Location和远端网元一一对应。远端Location在不同场景下是相对的，具体如下：对于主用局FE，它的远端Location指主用局USCDB、容灾局USCDB。对于主用局USCDB，它的远端Location指主用局FE、容灾局FE、容灾局USCDB。对于容灾局FE，它的远端Location指容灾局USCDB、主用局USCDB。对于容灾局USCDB，它的远端Location指容灾局FE、主用局FE、主用局USCDB。 取值范围：1～512 默认值：无。 |
| RDSGST | 远端DSG业务类型    | 用于表示远端DSG的业务类型，此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。当进行BE间的容灾对接配置时，远端DSG业务类型必须配置为该远端DSG在远端Location上所配置的业务类型，而不能配置成USCDB类型。 取值范围：长度不超过128的字符串。 默认值：无。                                                                                                  |

## 使用实例

1. USCDB需要加载OMU表中配置的“远端Location标识”为“3”且“远端DSG业务类型”为“SUP-FE”的RDSG数据，此时需要进行如下操作：

   ```
   LOD RDSG:  RLOCID=3, RDSGST="SUP-FE";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 275124 | 参数取值无效：参数RDSGST所示的插件包不存在，请确认已经加载了该FE插件。  | 输入的“远端DSG业务类型”在系统中不存在。         | 通过执行LST FEPLUG命令查询加载的“FE类型”，“FE类型”即“远端DSG业务类型”。 若“FE类型”加载成功，请在执行该命令时输入正确的“远端DSG业务类型”。若“FE类型”加载不成功或者没有加载，通过LOD FEPLUG命令加载成功后，重新执行该命令。                                                                    |

| 302551 | 本端链路中心未配置。                               | 本端网元指定的DSG链路中心未配置。             | 在本端“USCDB MML命令” 界面执行LST DSGLINKCTRL命令查询DSG链路中心。 若本端DSG链路中心已配置，执行命令时输入正确的“远端Location标识”和“远端DSG业务类型”。若本端DSG链路中心未配置，执行ADD DSGLINKCTRL配置DSG链路中心后，重新执行该命令。                                                  |
