# 删除适配插件(CLR ADPPLUG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令属于高危命令，执行此命令将导致原有适配插件包失效。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于清除适配插件。

本命令的使用场景如下：

- 当不需要使用某适配插件时，此时可执行本命令进行清除。
- 当某适配插件需要被替换更新时，需要使用本命令清除此插件，然后在执行**LOD ADPPLUG**命令重新加载。

## 注意事项

- 执行完本命令后，需要执行**RST MODULE**命令重新启动所有PGW模块才能生效。
- 该命令不允许进行批操作。

## 参数说明

无。

## 使用实例

当适配插件不再使用时，需要清除此适配插件，执行命令如下：

```
CLR ADPPLUG:;
```
