# 查询TPS使用信息（DSP TPSINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于请求系统显示一天中系统TPS（Transaction Per Second）的使用情况。

根据输入的日期，显示当天用户最大的TPS使用记录，该命令一次只能显示一天的记录。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                                                                                                                        |
|:--------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TPSDATE | TPS使用日期 | 可选必选说明：可选参数。 参数含义：用于指定需要查看TPS使用情况的日期，若不输入，默认查询系统当天的TPS使用情况。 取值范围：格式为“YYYY&MM&DD”的字符串。 默认值：无。 配置原则：该参数指定的时间点需要为系统本地时间，例如“2014&08&01”表示选择的备份文件日期为2014年8月1日，即查询2014年8月1日的TPS使用情况。  说明： 系统中最多可保存1万条TPS数据记录，当超过1万条记录时，最远的记录会被删除。 |

## 使用实例

- 查询2014年7月29日系统TPS的使用情况。

`DSP TPSINFO: TPSDATE=2014&07&29;`

```
%%DSP TPSINFO: TPSDATE=2014&07&29;%%
RETCODE = 0  操作成功

操作结果如下
----------
 名称                访问类型     最大TPS数     产生时间

 admin               SOAP/MML         3         2014-07-29 00:00:03
 HTTPNotification    订阅通知         2         2014-07-29 00:00:03
(结果个数 = 2)

---    END
```

- 不输入参数，默认查询系统当天的TPS使用情况。

`DSP TPSINFO:;`

```
%%DSP TPSINFO:;%%
RETCODE = 0  操作成功

操作结果如下
----------
 名称                  访问类型     最大TPS数     产生时间

 HTTPNotification      订阅通知         2         2014-08-01 11:19:54
 admin                 SOAP/MML         4         2014-08-01 11:19:54
(结果个数 = 2)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1的参数说明。

| 输出项名称   | 输出项解释                                                                                                                                             |
|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
| 名称      | 访问类型对应的名称： SOAP/MML类型显示为操作员名称，当操作员名称为空时，显示为NoneOperator，当存在自动触发的定时备份、周期性导出任务时，操作员名称显示为PGWSystemLogger。订阅通知类型显示为HTTPNotification或SOAPNotification。 |
| 访问类型    | 包括两种访问类型： SOAP/MML订阅通知                                                                                                                            |
| 最大TPS数  | 表示当天最高的TPS值。                                                                                                                                      |
| 产生时间    | 表示产生最高TPS的时间。                                                                                                                                     |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释   | 原因分析                     | 处理建议                |
|------:|:--------|:-------------------------|:--------------------|
|  2086 | 模块异常。   | USCDB的全局DRU模块或主备PGW模块故障。 | 请参见产品手册的“模块故障”进行处理。 |
