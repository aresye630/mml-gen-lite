# 查询DSG SCTP偶联配置(LST SCTPASSOC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于请求系统显示DSG模块SCTP偶联配置信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                    |
|:-------|:-------|:----------------------------------------|
| FETYPE | FE类型名称 | 用于指示系统需要按照指定FE类型来查询DSG的SCTP偶联统计对象的配置信息。 |

## 使用实例

1. 查询所有SCTP偶联配置信息。

   ```
   LST SCTPASSOC:;
   ```

   ```
    601        192.168.1.151      192.168.1.152      2006        192.168.1.200       192.168.1.199       2007         SUP-FE          
    602        192.168.1.151      192.168.1.152      2006        192.168.1.198       192.168.1.201       2008         SUP-FE

   ---    END
   ```

   ```
   LST SCTPASSOC: FETYPE="SUP-FE";
   ```

## 输出结果说明

各输出项含义请参见表1。

| 输出项名称       | 输出项解释                   |
|:------------|:------------------------|
| 测量对象ID      | 用于返回SCTP偶联测量对象标识。       |
| SCTP偶联本地IP1 | 用于返回DSG链路连接的本端设备的IP地址1。 |
| SCTP偶联本地IP2 | 用于返回DSG链路连接的本端设备的IP地址2。 |
| SCTP偶联本地端口号 | 用于返回DSG链路连接的本端设备的端口号。   |
| SCTP偶联对端IP1 | 用于返回DSG链路连接的远端设备的IP地址1。 |
| SCTP偶联对端IP2 | 用于返回DSG链路连接的远端设备的IP地址2。 |
| SCTP偶联对端端口号 | 用于返回DSG链路连接的远端设备的端口号。   |
| FE类型名称      | 用于返回DSG业务类型。            |
