# 增加MCI链路（ADD MCILNK）

- 参数说明

- 输出结果说明

## 命令功能

该命令用于添加一条MCI链路。

MCI链路为订阅通知提供了MCI消息通道，通过本组命令可以配置MCI链路的“Location标识”，“服务名称”等基本信息。一条或两条MCI链路组成一个MCI链路集，使用命令**ADD SUBSCRIBER**添加订阅者时，需要指定该订阅者关联的链路集。当需要给订阅者发送订阅通知消息时，使用该订阅者关联的链路集的一条链路作为消息通道。

## 注意事项

- 一个链路集最多配置两条链路。
- 在配置MCI链路时，对于MCI消息通知按照如下原则处理：
  - 如果未配置“Location标识”参数，则自动选择该“FE类型”的一个优先级别高的FE对端发送。优先级别可以通过**LST RLOCATION**查询。
  - 如果配置了“Location标识”参数，则此条MCI消息通知将只会发送给该指定“Location标识”的FE对端。

## 参数说明

| 参数标识        | 参数名称        | 参数说明                                                                                                                  |
|:------------|:------------|:----------------------------------------------------------------------------------------------------------------------|
| LNKID       | 链路ID        | 可选必选说明：必选参数 参数含义：本参数用于标识一条MCI链路。 取值范围：1～50。 默认值：无。 配置原则：无。                                                            |
| LKSID       | 链路集ID       | 可选必选说明：必选参数 参数含义：本参数用于标识一个MCI链路集。 取值范围：1～50。 默认值：无。 配置原则：无。                                                           |
| FETYPE      | FE类型        | 可选必选说明：必选参数 参数含义：本参数用于描述成功加载的插件包FE类型（可通过LST FEPLUG命令查询）。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                            |
| RLOCID      | Location标识  | 可选必选说明：可选参数 参数含义：该Location标识用于定义一个接收MCI订阅通知消息的网元标识。当配置该参数为非0值时，需保证该值为真实存在的远端“Location标识”。 取值范围：0～512。 默认值：0。 配置原则：无。  |
| SERVICENAME | 服务名称        | 可选必选说明：必选参数 参数含义：本参数用于指定远端用于接收订阅通知服务的服务名称（可通过LST NTFSRVNAME命令查询）。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                   |
| PID         | Partition标识 | 可选必选说明：可选参数 参数含义：本参数用于指定一个接收MCI订阅通知消息接收端的Partition标识。 取值范围：0～255。 默认值：无。 配置原则：当配置该参数为非0值时，需保证该值为真实存在的远端“Partition标识”。 |
| LNKDESC     | 链路描述        | 可选必选说明：可选参数 参数含义：本参数用于标识MCI链路的描述信息。 取值范围：长度不超过32的字符串。 默认值：无。 配置原则：无。                                                  |

## 使用实例

添加一条MCI链路，设置“链路ID”为“1”，“链路集ID”为“1”，“FE类型”为“SUP-FE”，“Location标识”为“81”，“服务名称”为“abc”。

```
ADD MCILNK: LNKID=1, LKSID=1, FETYPE="SUP-FE", RLOCID=81, SERVICENAME="abc";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释             | 原因分析                 | 处理建议                                                                                  |
|-------:|:-----------------|:---------------------|:--------------------------------------------------------------------------------------|
| 274630 | 链路已经存在。          | MCI“链路ID”在系统中已添加。    | 先执行LST MCILNK命令查询已经存在的“链路ID”，然后重新执行本命令，确保要添加的“链路ID”与查询的值不相同。                          |
| 274642 | 链路集已经存在两条链路。     | 一个链路集中最多只有两条链路。      | 执行本命令将该“链路ID”添加到另外一个包含不到两条链路的链路集中，确保该“链路集ID”与之前的不重复。                                  |
| 275434 | 指定的FE类型不存在该服务名称。 | 指定的“FE类型”不存在该“服务名称”。 | 先执行LST NTFSRVNAME命令查询指定“FE类型”已经存在的“服务名称”，然后重新执行本命令，确保要添加的“服务名称”在查询的结果中存在，并且与“FE类型”对应。 |
