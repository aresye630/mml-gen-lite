# 增加日志手动控制(ADD LOGCTRL)

## 命令功能

该命令用于增加日志手动控制记录。

当出现高频无效垃圾日志影响现网巡检效率和运维时，可执行该命令增加手工控制功能，屏蔽高频无效的垃圾日志。

## 注意事项

- 网元升级、补丁安装或模块重启后，所添加的对应模块类型的日志手动控制记录会失效，需要重新设置。
- 支持添加重复记录，即“模块类型”、“文件名”和“行号”均相同，重复记录在模块内只保存一条。
- 单模块类型最多支持配置20条日志手动控制记录。后面增加的记录会覆盖最先增加的记录，如第21条记录会覆盖第1条记录。
- 只对级别为ERROR的日志进行控制。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                          |
|:-----------|:-------|:------------------------------------------------------------------------------------------------------------------------------|
| TYPE       | 模块类型   | 可选必选说明：必选参数 参数含义：用于指定需要增加日志手动控制记录的模块类型。 取值范围： DPU(DPU)NDF(NDF)DBG(DBG)DSG(DSG)DRU(DRU)DSU(DSU)PGW(PGW)DMA(DMA) 默认值：无。 配置原则：无。 |
| FILENAME   | 文件名    | 可选必选说明：必选参数 参数含义：用于指定需要控制的日志文件名。 取值范围：长度不超过64字节的字符串，区分字母的大小写。 默认值：无。 配置原则：无。                                                  |
| LINENUMBER | 行号     | 可选必选说明：必选参数 参数含义：用于指定需要控制的日志所在行号。 取值范围：1~65535 默认值：无。 配置原则：无。                                                                 |

## 使用实例

增加日志的手动控制信息，“模块类型”为“PGW”，“文件名”为“globaldata.cpp”，“行号”为“187”。

```
ADD LOGCTRL: TYPE=PGW, FILENAME="globaldata.cpp", LINENUMBER=187;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释   | 原因分析                               | 处理建议                                          |
|------:|:--------|:-----------------------------------|:----------------------------------------------|
|  1710 | 无可用模块。  | 系统中未添加指定“模块类型”的模块。指定“模块类型”的模块全部异常。 | 根据原因进行对应的处理： 无需处理。请参见产品手册的“模块故障”进行处理后重新执行该命令。 |
|  1967 | 部分操作超时。 | 指定“模块类型”的部分模块异常。                   | 请参见产品手册的“模块故障”进行处理后重新执行该命令。                   |
