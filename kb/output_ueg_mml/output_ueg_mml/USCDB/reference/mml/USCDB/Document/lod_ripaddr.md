# 加载远端IP信息(LOD RIPADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**说明** 

该命令在25.1.0版本不支持，命令功能已由**SYN RIPADDR**命令替代。

该命令用于将同步到OMU表中的RIPADDR数据，加载到主机模块中。

## 注意事项

该命令需要在执行**SYN RIPADDR**后执行。

## 参数说明

| 参数标识   | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                        |
|:-------|:-------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RLOCID | 远端Location标识 | 用于指定一个远端网元标识。该参数须在对接的远端USCDB网元或者FE网元中先定义，然后在本端网元通过ADD RLOCATION命令配置后，才能在此处索引。远端Location是相对的，具体如下：对于主用局FE，它的远端Location指主用局USCDB或容灾局USCDB。对于主用局USCDB，它的远端Location指主用局FE、容灾局FE或容灾局USCDB。对于容灾局FE，它的远端Location指容灾局USCDB或主用局USCDB。对于容灾局USCDB，它的远端Location指容灾局FE、主用局FE或主用局USCDB。 取值范围：1～512 默认值：无。 |
| RDPUST | 远端IP地址业务类型   | 用于指示远端IP地址的业务类型，此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。 取值范围：长度不超过128的字符串。 默认值：无。                                                                                                                                                                                                           |

## 使用实例

1. USCDB需要加载OMU表中配置的“远端Location标识”为“3”且“远端IP地址业务类型”为“SUP-FE”的RIPADDR数据，此时需要进行如下操作：

   ```
   LOD RIPADDR:  RLOCID=3, RDPUST="SUP-FE";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|-------:|:-----------------------------------------|:-------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 302003 | 远端Location不存在。                           | 远端Location不存在，必须先配置远端Location。 | 通过ADD RLOCATION命令先配置远端Location，再在本命令中引用。                                                                                                                                                                 |
| 275315 | 参数取值无效：参数RDPUST所示的插件包不存在，请确认已经加载了该FE插件。  | 输入的“远端IP地址业务类型”在系统中不存在。        | 通过执行LST FEPLUG命令查询加载的“FE类型”，“FE类型”即“远端IP地址业务类型”。 若“FE类型”加载成功，请在执行该命令时输入正确的“远端IP地址业务类型”。若“FE类型”加载不成功或者没有加载，通过LOD FEPLUG命令加载成功后，重新执行该命令。                                                                   |
| 302539 | 业务类型不能指定为USCDB。                          | 参数“远端IP地址业务类型”不能指定为“USCDB”。    | 通过执行LST FEPLUG命令查询加载的“FE类型”，“FE类型”即“远端IP地址业务类型”。请输入加载成功的“FE类型”。                                                                                                                                          |
| 275316 | 参数RLOCID指定远端局点网元类型与参数“RDPUST”指定的业务类型不一致。 | “远端IP地址业务类型”与“RLOCID”的网元类型不匹配。 | 通过执行LST RLOCATION命令查询“远端网元类型”，请确保输入的“远端IP地址业务类型”与“远端网元类型”一致。                                                                                                                                             |
| 302551 | 本端链路中心未配置。                               | 本端网元指定的DSG链路中心未配置。             | 在本端“USCDB MML命令” 界面执行LST DSGLINKCTRL命令查询DSG链路中心。 若本端DSG链路中心已配置，执行命令时输入正确的“远端Location标识”和“远端IP地址业务类型”。若本端DSG链路中心未配置，执行ADD DSGLINKCTRL配置DSG链路中心后，重新执行该命令。                                                  |
| 302553 | 远端链路中心未配置。                               | 远端网元指定的远端Location DSG链路中心未配置。  | 在对端网元下执行LST RDSGLINKCTRL命令查询远端Location DSG链路中心。 若对端网元远端Location DSG链路中心已配置，执行命令时输入正确的“远端Location标识”和“远端IP地址业务类型”。若对端网元远端Location DSG链路中心未配置，在对端网元下执行ADD RDSGLINKCTRL配置远端Location DSG链路中心后，在本端网元下重新执行该命令。 |
