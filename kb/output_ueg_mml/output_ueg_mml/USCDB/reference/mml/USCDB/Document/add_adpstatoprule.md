# 添加适配测量操作员规则对象(ADD ADPSTATOPRULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

当用户需要按操作员对业务发放命令进行统计时，使用该命令添加一条适配测量操作员规则记录。

## 注意事项

最多可以配置5000条适配测量操作员规则记录。

## 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                   |
|:---------------|:---------|:---------------------------------------------------------------------------------------|
| ADPSTATOBJNAME | 适配测量对象名称 | 用于标识一条适配测量对象的名称。此参数在USCDB网元下唯一，由ADD ADPSTATOBJ命令添加。 取值范围：长度不超过127的字符串。 默认值：无。          |
| OPERATOR       | 操作员名称    | 用于标识一个操作员的名称。此参数为在PGW Web LMT上使用LST OPR命令查询出来的操作员或系统默认的超级管理员。 取值范围：长度不超过32的字符串。 默认值：无。 |

## 使用实例

添加适配测量操作员规则时需要先添加适配测量对象，配置方式如下：

1. 添加适配测量对象，设置“适配测量对象ID”为“1”，“适配测量对象名称”为“TestObj”，“业务类型”为“SUP-FE”：

   ```
   ADD ADPSTATOBJ: ADPSTATOBJID=1, ADPSTATOBJNAME="TestObj", SERVICETYPE="SUP-FE";
   ```
2. 添加适配测量操作员规则，设置“适配测量对象名称”为“TestObj”，“操作员名称”为“opr1”：

   ```
   ADD ADPSTATOPRULE: ADPSTATOBJNAME="TestObj", OPERATOR="opr1";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释         | 原因分析                        | 处理建议                                                                                                                            |
|-------:|:--------------|:----------------------------|:--------------------------------------------------------------------------------------------------------------------------------|
|   2330 | 操作员不存在。       | 输入的“操作员名称”在系统中不存在。          | 在PGW Web LMT上执行LST OPR命令查询系统中已存在的操作员，重新执行本命令，其中参数“操作员名称”为LST OPR命令中查询出来的结果或系统默认的超级管理员。                                          |
| 256032 | 记录已存在。        | 数据库中已经存在相同的记录。              | 执行LST ADPSTATOPRULE命令查询适配测量操作员规则记录，重新输入“适配测量对象名称”和“操作员名称”，确保其与查询结果不重复。                                                          |
| 274597 | PGW模块未配置。     | PGW模块未配置。                   | 请执行ADD MODULE命令添加PGW模块。                                                                                                         |
| 274598 | PGW模块状态异常。    | PGW模块状态异常。                  | 请参见产品手册的“模块故障”进行处理。                                                                                                             |
| 301252 | 记录数已经达到最大元组数。 | 数据库中保存的适配测量操作员规则记录已经达到最大数量。 | 达到最大元组数限制后，不允许再添加，可以先执行LST ADPSTATOPRULE命令查询已经存在的适配测量操作员规则记录。如果要添加，请执行RMV ADPSTATOPRULE命令删除无效的适配测量操作员规则后再执行ADD ADPSTATOPRULE添加。 |
