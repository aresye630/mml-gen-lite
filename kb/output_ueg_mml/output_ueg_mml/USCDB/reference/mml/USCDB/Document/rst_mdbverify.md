# 重置内存库校验(RST MDBVERIFY)

## 命令功能

该命令用于重置各节点开始新一轮周期性内存库校验。

在现网局点中，由于承载网故障、节点异常等场景，容易导致节点间的数据不一致，尤其是主用局与容灾局之间。在做容灾倒换时，需要先确保主用、容灾数据完全一致，在数据不一致的情况下做容灾倒换容易产生很多未知问题。因此在重大操作前需要确认主用、容灾数据是否一致。可以使用**DSP MDBVERIFY**命令查询各节点间数据是否一致，但是由于各节点周期性校验任务启动时间不一致，无法确定各节点间数据是否一致。通过本命令可重置各节点开始新一轮周期性校验，使各节点在同一个时间内启动周期性校验任务。

## 注意事项

- 该命令仅支持串行处理，如果上一条命令未执行完成，重复执行该命令，则返回错误，请稍后再试。
- 在校验开关（涉及软参为：FWDVFYSWT（正向校验开关）、REVVFYSWT（反向校验开关）、FWDRTVFYSWT（正向路由校验开关）、REVRTVFYSWT（反向路由校验开关））关闭情况下，执行本命令并不会发起新的一轮校验，只有当校验开关打开后才会发起新的一轮校验。校验开关操作请参考命令**MOD INSP**。
- 在软参“DELSUBDATASWT（老化数据删除开关）”关闭的情况下，执行本命令不会重置老化数据删除任务，只有当“DELSUBDATASWT（老化数据删除开关）”打开时才会重置老化数据删除任务。
- 标识为1的Cluster为系统自动生成，其内部DRU的业务类型对外不体现，若需要校验该Cluster内部的DRU，请不要输入“业务类型”参数，此命令会重置所有业务类型的DRU、DSU的内存库校验。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                               |
|:------------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 业务类型      | 用于指定待重置内存库校验的业务类型，该参数需要通过执行LOD FEPLUG命令加载FE插件包，然后才能在此引用，可通过执行LST FEPLUG命令查询获取。 若不输入该参数，则对所有业务类型的DRU、DSU进行重置内存库校验。 取值范围：长度不超过128的字符串。 默认值：无。                                                                                                                                                                                                                                        |
| MDBVT       | 校验类型      | 用于指定待校验内存库数据的校验类型。 各参数选项的含义是：INNER(局内)：重置局内水平正向校验、局内水平反向校验、局内正向路由校验、局内反向路由校验、垃圾数据清理。OUTERREDUN(容灾局间)：重置局间用户数据正向校验、局间用户数据反向校验、局间全局数据正向校验、局间全局数据反向校验。OUTERCLOUD(云部署局间)：重置云部署全局数据正向校验、云部署全局数据反向校验、云部署用户全局路由正向校验、云部署用户全局路由反向校验。 默认值：无。                                                                                                                                                 |
| VERIFYNUM   | 每周期校验记录个数 | 用于重置待校验内存库数据的每周期校验记录个数。 该参数将重置如下软参的取值：DRUFRWDVFYUNITNUM（获取DRU正向校验的个数）DSUFRWDVFYUNITNUM（获取DSU正向校验的个数）REVVFYUNITNUM（反向校验每周期校验对象个数）FWDRTVFYUNITNUM（正向路由校验每周期校验路由信息条数）REVRTVFYUNITNUM（反向路由校验每周期校验路由信息条数） 取值范围：1～500 单位：个 默认值：无。 说明： 如果该参数的取值超过了对应软参的最大值，则实际校验个数为软参对应的最大值。MOD INSP命令可以修改该参数的取值，即如果先执行该命令修改该参数的取值，再通过MOD INSP修改软参的取值，则以MOD INSP修改的软参取值为准。如果校验开关关闭，则该参数设置的“每周期校验记录个数”不生效。 |
| VERIFYPRD   | 校验周期      | 用于重置待校验内存库数据的校验周期。 该参数将重置如下软参的取值：PRDFWDVFY（正向校验周期）PRDREVVFY（反向校验周期）PRDFWDRTVFY（正向路由校验周期）PRDREVRTVFY（反向路由校验周期） 取值范围：1～6000 单位：秒 默认值：无。 说明： MOD INSP命令可以修改该参数的取值，即如果先执行该命令修改该参数的取值，再通过MOD INSP修改软参的取值，则以MOD INSP修改的软参取值为准。如果校验开关关闭，则该参数设置的“校验周期”不生效。                                                                                                                                 |

   RST MDBVERIFY:;

   ```
   RST MDBVERIFY: SERVICETYPE="SUP-FE";

   ```
   RST MDBVERIFY:  MDBVT=INNER;

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1的参数说明。

| 输出项名称     | 输出项解释                                                                                                                                                                       |
|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Cluster标识 | 用于表示节点所属的Cluster标识。                                                                                                                                                         |
| 节点标识      | 用于表示节点的节点标识，此参数在Location内唯一。节点标识和模块号一一对应。                                                                                                                                   |
| 模块号       | 用于表示模块的模块标识，此参数在Location内唯一。                                                                                                                                                |
| 设定结果描述    | 用于表示重置内存库校验的操作结果。 各参数选项的含义是：操作成功：重置节点内存库校验成功。操作超时：重置节点内存库校验未响应，请重新操作。模块异常：重置节点内存库校验的模块处于异常状态，请检查异常模块，并查看是否有“ALM-1003 模块故障”告警，如有则按告警帮助进行处理。操作失败：重置节点内存库校验失败，请联系华为技术支持排查失败原因。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释            | 原因分析                                                    | 处理建议                                                                                                  |
|------:|:-----------------|:--------------------------------------------------------|:------------------------------------------------------------------------------------------------------|
|  2059 | 指定的业务类型不存在       | 输入的“业务类型”不存在。                                           | 执行LST FEPLUG命令查看已加载的FE插件包，即业务类型。 FE插件包加载成功，在执行该命令时输入正确的业务类型。FE插件包加载失败，通过LOD FEPLUG命令加载FE插件包后，重新执行该命令。 |
|  2086 | 模块异常             | 输入的“业务类型”没有对应的进程需要重启。                                   | 请参见产品手册的“模块故障”进行处理。                                                                                   |
|  2786 | 该命令不支持设置分区间校验速率。 | 当“校验类型”取值为“OUTERCLOUD(云部署局间)”时，输入了“每周期校验记录个数”或“校验周期”参数。 | 当“校验类型”取值为“OUTERCLOUD(云部署局间)”时，请不要输入“每周期校验记录个数”或“校验周期”参数。                                             |
