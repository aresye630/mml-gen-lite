# 查看SCTP偶联统计信息(DSP DSGSCTPAS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于请求系统显示某条SCTP偶联的统计信息。该命令主要用于维护过程的问题定位。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                         |
|:-------|:-------|:-----------------------------|
| MID    | DSG模块号 | 用于请求系统显示哪个DSG模块号的SCTP偶联统计信息。 |
| AID    | 偶联号    | 用于请求系统显示哪个偶联号的SCTP偶联运行信息。    |

## 使用实例

查看“DSG模块号”为“4”、“偶联号”为“3”的DSG偶联统计信息，执行命令如下：

```
DSP DSGSCTPAS: MID=4, AID=3;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1。

| 输出项名称          | 输出项解释                                                          |
|:---------------|:---------------------------------------------------------------|
| 偶联号            | 用于返回当前偶联号。                                                     |
| 偶联建立T1定时器超时的次数 | 用于返回当前SCTP偶联中T1（INIT/COOKIE ECHO）定时器超时的次数，该值体现了该SCTP偶联建立发起的次数。 |
| 数据重传T2定时器超时的次数 | 用于返回当前SCTP偶联中T2（SHUTDOWN）定时器超时的次数，该值也体现了数据重传的次数。               |
| 重发的数据块个数       | 用于返回当前SCTP偶联重传的数据块数量。                                          |
| 发送的数据块个数       | 用于返回当前SCTP偶联发送的数据块数量。                                          |
| 接收的数据块个数       | 用于返回当前SCTP偶联接收的数据块数量。                                          |
| 总共接收的SCTP包个数   | 用于返回SCTP接收的包个数。                                                |
| 对端IP地址         | 用于返回当前SCTP偶联对端的IP地址。                                           |
| 重传数据块的个数       | 用于返回等待证实超时所重传的数据块数。                                            |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释      | 原因分析                        | 处理建议                                           |
|-------:|:-----------|:----------------------------|:-----------------------------------------------|
| 302019 | DSG 模块不存在。 | 查看SCTP偶联统计信息所在的“DSG模块号”不存在。 | 通过LST MODULE命令查询DSG的模块号，输入查询到的DSG模块号后，重新执行该命令。 |
| 302020 | 指定的AID不存在。 | 输入的“偶联号”在系统中不存在。            | 通过DSP DSGSCTP命令查询已存在的偶联号并正确设置，然后重新执行本命令。       |
