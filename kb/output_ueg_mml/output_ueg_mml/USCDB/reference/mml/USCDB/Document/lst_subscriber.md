# 查询订阅者(LST SUBSCRIBER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询PGW订阅者的相关配置信息。

若需要查询全部的订阅者信息，请不要输入任何参数。

若需要查询某条订阅者的详细信息，请输入“订阅者ID”参数或者其他参数或者这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                          |
|:----------|:-------|:----------------------------------------------------------------------------------------------|
| SUBERID   | 订阅者ID  | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个订阅者ID来查询订阅者信息；若不输入，则表示查询所有的订阅者信息。 取值范围：1~255。 默认值：无。 配置原则：无。       |
| SUBERNAME | 订阅者名称  | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个订阅者名称来查询订阅者信息；若不输入，则表示查询所有的订阅者信息。 取值范围：长度不超过32的字符串。 默认值：无。 配置原则：无。 |

## 使用实例

1.查询订阅者，“订阅者ID”为“1”的订阅者的相关配置信息。

```
LST SUBSCRIBER: SUBERID=1, SUBERNAME="huawei";
```
