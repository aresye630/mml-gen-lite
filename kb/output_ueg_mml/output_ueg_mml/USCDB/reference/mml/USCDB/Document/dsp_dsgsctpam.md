# 查看SCTP偶联管理信息(DSP DSGSCTPAM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查看SCTP偶联管理信息，维护时用于故障定位。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                          |
|:-------|:-------|:----------------------------------------------|
| MID    | DSG模块号 | 用于请求系统显示哪个DSG模块的SCTP偶联管理信息；若不输入，则表示所有的DSG模块号。 |
| AID    | 偶联号    | 用于请求系统显示哪个偶联号的SCTP偶联管理信息；若不输入，则表示所有的偶联号。      |

## 使用实例

查看SCTP偶联管理信息，“DSG模块号”为“102”。

```
DSP DSGSCTPAM: MID=102;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称    | 输出项解释                                                                                                                                                |
|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
| 偶联号      | 用于返回SCTP偶联号码。                                                                                                                                        |
| 对端SCTP端口 | 用于返回对端SCTP端口号。                                                                                                                                       |
| 对端主用地址   | 用于返回当前SCTP偶联对端主用的IP地址。                                                                                                                               |
| 偶联心跳间隔   | 用于定义DSG在上述情况下向远端IP地址发送心跳消息的周期，其单位为“毫秒”。 在一定的时间内SCTP偶联未向某个特定的IP地址发送数据，SCTP偶联将向该IP地址发送心跳消息（SCTP的一种消息类别，用于监视到某个目的地址的可达性），以检查远端IP地址是否处于激活状态。             |
| 偶联状态     | 用于返回当前SCTP偶联的偶联状态，为标准的SCTP协议栈状态。 偶联状态取值： CLOSEDCOOKIE ACKCOOKIE ECHOESTABLISHEDSHUTDOWN_PENDINGSHUTDOWN_SENTSHUTDOWN_RECEIVEDSHUTDOWN_ACK_SENTTCB已删除 |
| 入流数      | 用于返回当前SCTP偶联在接收方向上的流个数。                                                                                                                              |
| 出流数      | 用于返回当前SCTP偶联在发送方向上的流个数。                                                                                                                              |
| 偶联最大重传次数 | 用于返回在一个SCTP偶联上所允许的消息连续重传的最大次数。                                                                                                                       |
| 对端地址个数   | 用于返回当前SCTP偶联对端传送地址的数量。                                                                                                                               |
| 对端IP地址   | 用于返回当前SCTP偶联在对端的IP地址。                                                                                                                                |
| 对端IP状态   | 用于返回当前SCTP偶联对端的IP状态。 IP状态取值： 激活未激活                                                                                                                   |
| 对端心跳标志   | 用于返回对端是否使用心跳进行链路状态。 心跳标志取值： 0：表示使用心跳进行链路状态检测。1：表示不使用心跳进行链路状态检测。                                                                                      |
| 路径最大重传次数 | 用于返回在一个SCTP偶联上所允许的向某个特定的IP地址进行消息连续重传的最大次数。                                                                                                           |
| PMTU     | PMTU（Patch Most Transmission Unit，路径最大传输单元），表示一个SCTP偶联上所允许的向某个特定的IP地址进行消息传输的最大数据帧长度。 单位：字节                                                           |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释      | 原因分析                | 处理建议                                       |
|-------:|:-----------|:--------------------|:-------------------------------------------|
| 302019 | DSG模块不存在。  | 输入的“DSG模块号”在系统中不存在。 | 通过LST MODULE命令查询已加载的DSG模块号并正确设置，然后重新执行本命令。 |
| 302020 | 指定的AID不存在。 | 输入的“偶联号”在系统中不存在。    | 通过DSP DSGSCTP命令查询已存在的偶联号并正确设置，然后重新执行本命令。   |
