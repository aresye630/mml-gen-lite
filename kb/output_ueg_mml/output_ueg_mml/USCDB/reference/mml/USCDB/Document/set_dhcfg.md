# 设置DH配置(SET DHCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，2048比特长度为兼容性保留，建议设置为大于等于3072比特的长度。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置DH域参数的长度。

## 注意事项

- 为了在提升安全性的同时兼顾CPU的数据处理速率和OM Portal界面响应时长，建议将“素数bit数”的值设置为“3072(3072)”。如果设置了素数bit数的长度为“2048(2048)”，算法安全性较低，系统会上报“ALM-10031 系统存在不安全的配置项”告警。
- 该命令生成的DH域参数要满足强素数的条件是有随机性的，选择“素数bit数”为“4096(4096)”时命令的执行时长可能需要15～20分钟。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                 |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
| NUMBITS | 素数bit数 | 可选必选说明：必选参数 参数含义：用于设置DH域参数的长度。 取值范围： 2048(2048)：表示将DH域参数长度设置为2048。3072(3072)：表示将DH域参数长度设置为3072。4096(4096)：表示将DH域参数长度设置为4096。 默认值：3072(3072)。 配置原则：无。 |

## 使用实例

1. 用户需要设置DH域参数长度时，可将“素数bit数”设置为3072(3072)，执行命令如下：

   ```
   SET DHCFG: NUMBITS=3072;
   ```
2. 执行**RST MODULE**命令重启PGW进程使配置生效。

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释               | 原因分析                                                  | 处理建议                                                            |
|-------:|:--------------------|:------------------------------------------------------|:----------------------------------------------------------------|
| 483018 | 参数NUMBITS的值不在指定范围内。 | 参数“素数bit数”的值不在枚举值2048(2048)、3072(3072)、4096(4096)范围内。 | 重新执行本命令，输入参数“素数bit数”的取值在枚举值2048(2048)、3072(3072)、4096(4096)范围内。 |
