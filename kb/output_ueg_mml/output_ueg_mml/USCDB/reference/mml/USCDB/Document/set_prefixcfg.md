# 设置路由前缀长度(SET PREFIXCFG)

## 命令功能

**须知** 

- 该命令属于高危命令，该操作将修改路由键前缀长度，操作不当将导致用户数据无法访问。因此执行该命令前，需要与华为技术支持确认后才可以实施。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于设置路由前缀长度。

该命令的使用场景：在开局场景下，根据业务规划，设置路由前缀长度。

## 注意事项

- 路由前缀长度一旦配置完成，在插件包激活后不能再更改。设置前请联系产品业务专家，确保该值设置合理。
- 该命令不允许进行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。
- 局点商用后，严禁执行该操作。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                              |
|:------------|:-------|:------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 业务类型   | 路由前缀长度对应的业务类型。此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。 取值范围：长度不超过128的字符串。 默认值：无。                                   |
| LENGTH      | 前缀长度   | 路由前缀长度。前缀长度一旦被设定，将影响到用户的路由数据，该值需要根据FE的使用场景进行设定，请确保已经作了充分的评估，使用户请求按前缀长度计算路由后均衡到各路由DRU Cluster。 取值范围： 1～128 默认值： 无。 |

## 使用实例

设置路由前缀长度：设置“业务类型”为“SUP-FE”，“前缀长度”为“10”。执行如下命令：

```
SET PREFIXCFG:SERVICETYPE="SUP-FE", LENGTH=10;
```
