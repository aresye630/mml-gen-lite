# 添加营帐设备登录类型(ADD PROVLGITYPE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于添加营帐客户端登录类型。

当营帐客户端需要交互式登录PGW，使用该命令添加该营帐客户端的登录类型为“TELNET”。

## 注意事项

如果没有配置营帐客户端的登录类型，默认登录类型为“HW”，非交互式登录。

## 参数说明

| 参数标识        | 参数名称        | 参数说明                                                                                   |
|:------------|:------------|:---------------------------------------------------------------------------------------|
| LGIID       | 登录ID        | 用于标识一个营帐客户端登录配置。 取值范围：1～256 默认值：无。                                                     |
| IPVER       | IP类型        | 用于表示IP地址类型。 取值范围： IPV4：当系统要求使用IPv4类型的IP地址时选择此选项。 IPV6：当系统要求使用IPv6类型的IP地址时选择此选项。 默认值：无。 |
| RIPV4       | 营帐客户端IPV4地址 | 仅当本命令中的“IP类型”参数选择为“IPV4”时该参数有效，用于指定营帐客户端的IPv4地址。 取值范围：IPv4格式的地址。 默认值：无。                |
| RIPV6       | 营帐客户端IPV6地址 | 仅当本命令中的“IP类型”参数选择为“IPV6”时该参数有效，用于指定营帐客户端的IPv6地址。 取值范围：IPv6格式的地址。 默认值：无。                |
| LPORT       | PGW本端端口     | PGW端的接入端口。该端口必须可以通过LST PORT命令查询并且端口类型必须为“PORT_FOR_MML”。 取值范围：1～65535 默认值：无。            |
| TYPE        | 登录类型        | 营帐客户端的登录类型。 取值范围： TELNET（交互式登录）HW（非交互式登录） 默认值：无。                                       |
| DESCRIPTION | 登录描述        | 营帐客户端的登录描述信息。 取值范围：长度不超过64的字符串。 默认值：无。                                                 |

## 使用实例

1. 添加营帐客户端登录类型，“登录ID”为“1”，“IP类型”为“IPV4”，“营帐客户端IPV4地址”为“192.168.2.120”，“PGW本端端口”为“7776”，“登录类型”为“TELNET”。

   ```
   ADD PROVLGITYPE: LGIID=1, IPVER=IPV4, RIPV4="192.168.2.120", LPORT=7776, TYPE=TELNET;
   ```
2. 添加营帐客户端登录类型，“登录ID”为“2”，“IP类型”为“IPV4”，“营帐客户端IPV4地址”为“192.168.2.121”，“PGW本端端口”为“7776”，“登录类型”为“HW”。

   ```
   ADD PROVLGITYPE: LGIID=2, IPVER=IPV4, RIPV4="192.168.2.121", LPORT=7776, TYPE=HW;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 274670 | 登录ID或者IP与端口已存在。                                     | “登录ID”或者“营帐客户端IP地址”和“PGW本端端口”的组合不能重复。                   | 请执行LST PROVLGITYPE命令查询“登录ID”或者“营帐客户端IP地址”和“PGW本端端口”的组合，请使用不重复的“登录ID”或者“营帐客户端IP地址”和“PGW本端端口”的组合作为新记录的登录ID或者IP和端口。 |
