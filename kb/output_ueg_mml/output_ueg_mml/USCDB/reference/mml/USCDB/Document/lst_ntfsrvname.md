# 查询订阅通知服务的服务名称（LST NTFSRVNAME）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询接收订阅通知服务的服务名称。

- 若要查询全部订阅通知服务的服务名称信息时，请不要输入任何参数。
- 若要查询指定订阅通知服务的服务名称信息时，请根据实际情况输入“FE类型”、“服务名称”参数。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                     |
|:------------|:-------|:-----------------------------------------------------------------------------------------|
| FETYPE      | FE类型   | 可选必选说明：可选参数 参数含义：本参数用于描述成功加载的插件包FE类型（可通过LST FEPLUG命令查询）。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则： |
| SERVICENAME | 服务名称   | 可选必选说明：可选参数 参数含义：本参数用于指定订阅通知服务的服务名称。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                   |

## 使用实例

1. 查询指定“FE类型”的订阅通知服务名称信息，该“FE类型”为“SUP-FE”。

   ```
   LST NTFSRVNAME: FETYPE="SUP-FE";
   ```

   ```
   %%LST NTFSRVNAME: FETYPE="SUP-FE";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    FE类型  服务名称  服务ID

    SUP-FE  CCU       35        
    SUP-FE  PES       36        
   (结果个数 = 2)

   ---    END
   ```
2. 查询指定订阅通知服务的服务名称信息，该“服务名称”为“CCU”。

   ```
   LST NTFSRVNAME: SERVICENAME="CCU";
   ```

   ```
   %%LST NTFSRVNAME: SERVICENAME="CCU";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    FE类型  服务名称  服务ID

    GU-HLR  CCU       35              
    SUP-FE  CCU       35              
   (结果个数 = 2)

   ---    END
   ```
3. 查询所有订阅通知服务的服务名称信息。

   ```
   LST NTFSRVNAME:;
   ```

   ```
   %%LST NTFSRVNAME:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    FE类型  服务名称  服务ID

    GU-HLR  CCU       35        
    GU-HLR  PES       36        
    SUP-FE  CCU       35        
    SUP-FE  PES       36        
   (结果个数 = 4)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，具体参数含义请参见表1的参数说明。

| 输出项名称       | 输出项解释              |
|:------------|:-------------------|
| FETYPE      | 用于标识FE插件包类型。       |
| SERVICENAME | 用于标识接收订阅通知服务的服务名称。 |
| SERVICID    | 用于标识接收订阅通知服务的服务ID。 |
