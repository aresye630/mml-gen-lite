## 命令功能

**须知** 

该命令属于高危命令，该操作恢复物理库数据，会清除数据库中的营帐操作日志。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于恢复USCDB物理数据库。当物理数据库因故障、升级等原因造成数据丢失或不一致等情形时，需要使用本命令对物理数据库数据进行恢复。在恢复物理数据库之前，可以先通过**DSP BKPLIST**命令查询系统中已备份的列表，再根据时间情况选择恢复的时间点。

## 注意事项

- 在执行此命令前需要先通过**LST MODULE**查看NDF模块是否已配置，若未配置则必须通过**ADD MODULE**命令进行添加，否则会导致命令执行失败。
- 备份配置“备份数据保存方式”参数的不同取值将会采用不同的恢复策略（在USCDB MML界面执行**LST BACKUP**命令，可查询备份配置的“备份数据保存方式”；执行**MOD BACKUP**命令，可修改备份配置参数）。

  - 如果“备份数据保存方式”选择为“FTPSERVER(保存到FTP服务器)”或“SFTPSERVER(保存到SFTP服务器)”，在恢复时表示从远程备份服务器上进行恢复。明文方式传输的FTP协议存在安全隐患，建议使用安全的SFTP协议。
  - 如果“备份数据保存方式”选择为“NOSTOSERVER(不保存到服务器)”，在恢复时表示从本地虚拟机硬盘（裸机硬盘）上进行恢复。
- 在执行本命令恢复物理数据库时，若不设置任何参数，则系统默认选择最近一次的备份对物理数据库进行恢复。
- 恢复物理数据库时需要保证业务发放系统没有正在进行的业务处理操作（如开销户等），否则会导致业务失败。
- 如果USCDB物理数据库存在ALM-11002 物理数据库备份或恢复失败告警，且原因不是数据库恢复失败时，则备份文件不能用于恢复。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                       |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| RDATE  | 恢复日期   | 用于指定待恢复文件的日期信息。 该参数的配置原则是：格式必须为“YYYY&MM&DD”，可通过执行DSP BKPLIST命令查询。例如“2012&04&20”表示选择的备份文件日期为2012年4月20日。 取值范围：日期格式。 默认值：无。  说明： 该参数在当前版本不生效。 |
| RTIME  | 恢复时间   | 用于指定待恢复文件的时间信息。 该参数的配置原则是：格式必须为“HH&MM&SS”，可通过执行DSP BKPLIST命令查询。例如“02&30&30”表示选择的备份文件时间点为2点30分30秒。 取值范围：时间格式。 默认值：无。  说明： 该参数在当前版本不生效。      |

## 使用实例

选择最近一次的备份文件对物理数据库进行恢复：

```
RST DB:;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                  | 原因分析                          | 处理建议                                       |
|-------:|:-----------------------|:------------------------------|:-------------------------------------------|
| 256051 | 升级或回退正在执行，不能进行物理库还原操作。 | 不能同时对数据库进行升级、回退以及恢复操作。        | 执行DSP PHYDB命令查看数据库的任务状态，在数据库任务完成后，重新执行本命令。 |
| 260117 | 恢复日期和恢复时间必须同时指定或同时为空。  | 必须同时输入“恢复日期”、“恢复时间”参数，或者都不输入。 | 同时输入“恢复日期”、“恢复时间”参数，或者都不输入，然后重新执行本命令。      |
| 272008 | 物理数据库任务正在运行。           | 不能同时运行多个物理数据库任务。              | 执行DSP PHYDB命令查看数据库的任务状态，在数据库任务完成后，重新执行本命令。 |
