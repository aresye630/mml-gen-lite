## 命令功能

**须知** 

开始事务需要大约2分钟完成，请务必在华为技术支持人员的指导下操作。

本命令用于启动事务模式。执行完本命令后，执行本命令的用户对该网元下发的后续配置命令（可以通过OM Portal或者网管客户端下发）都被作为事务中的一条命令，直到该用户使用**RBK TRAN**回退事务或**CMT TRAN**提交事务为止，admin用户还可以用**STP TRAN**命令强行中止任何用户开始的事务。

事务：事务是OMU的一种运行模式，用户显式开始事务后可以下发一系列的配置命令，然后显式提交该事务，提交事务之前的配置命令不会生效。OMU保证该事务内的配置命令的原子性（所有配置命令要么都被提交，要么都不提交）、一致性（事务模式下能保证OMU配置数据的一致性约束）、隔离性（事务之间是隔离的，由于目前OMU不允许事务并发，因此不必考虑这个特性）和持久性（OMU确保已提交的事务对配置数据的更新是持久的）（即：ACID）。

本命令的使用场景为：执行某些配置命令后，不能确定其结果，可以执行本命令进入事务模式，进行相关的配置操作，通过试运行观察这些配置命令的结果。如果这些结果符合预期，可以执行**CMT TRAN**提交事务；如果这些结果不符合预期，可以执行**RBK TRAN**回退事务，进入执行事务之前的正常模式。

## 注意事项

- 事务模式下无法执行某些命令。

  这些命令包括：**MOD MAXT**、**CFM TST**、**CNL TST**、**STP TST**。

  在事务模式下，不允许对PG或MODULE对象进行配置操作。

  由于目前OMU不允许使用嵌套事务，因此在事务模式下**BGN TRAN**命令不能执行。
- 事务模式下的增删改等命令直到提交该事务之后才会被设定到主机侧。

## 参数说明

无。

## 使用实例

开始一个事务：

```
BGN TRAN:;
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，请联系华为技术支持处理。
