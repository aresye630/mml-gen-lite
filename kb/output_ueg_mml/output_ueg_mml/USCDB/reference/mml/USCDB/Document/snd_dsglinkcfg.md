# 发送DSG链路配置(SND DSGLINKCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于DSG模块向远端DSG或DBS发送本端DSG配置以及IP配置。

## 注意事项

- 当本端同时配置了远端的DSG或DBS配置和IP配置时，报文才会返回对端的操作结果。
- 不支持向远端FE DSG发送本端DSG配置以及IP配置。
- 在向对端发送完本端DSG配置以及IP配置之后，通过ACT IPDISP命令且ACT IPDISP命令入参“模式”选择“ALL(所有)”来激活链路，配置才能生效。

## 参数说明

无。

## 使用实例

向远端DSG或DBS模块发送本端DSG配置以及IP配置。

```
SND DSGLINKCFG:;
```

```
%%SND DSGLINKCFG:;%%
RETCODE = 0 操作成功
 
操作结果如下
----------------------
远端Location标识 业务类型 操作结果
20               SUP-FE   操作成功
(结果个数 = 1)

--- END
```

## 输出结果说明

各输出项含义请参见表1。

| 输出项名称        | 输出项解释                                                                                                                                                                                                                                         |
|:-------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 远端Location标识 | 用于返回本端DSG所对接的远端Location标识。                                                                                                                                                                                                                    |
| 业务类型         | 用于返回当前DSG的业务类型。                                                                                                                                                                                                                               |
| 操作结果         | 用于返回发送DSG链路通知的操作结果。 操作成功操作失败操作超时对端版本不支持本功能链路故障 说明： 需要对该命令返回报文内容进行判断，报文操作结果字段有如下情况： 操作成功 => 成功向远端DSG或DBS发送本端DSG配置以及IP配置。操作失败 => 重试当前操作，若仍不成功请联系华为技术支持。操作超时 => 重试当前操作，若仍不成功请联系华为技术支持。对端版本不支持本功能 => 请在对端网元进行手工链路配置或使用链路中心进行配置。链路故障 => 请联系华为技术支持。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释      | 原因分析                            | 处理建议                                |
|-------:|:-----------|:--------------------------------|:------------------------------------|
|   2648 | 部分操作失败。    | 存在部分DSG模块故障。存在部分业务类型的DSG模块全部故障。 | 重试当前操作，若仍不成功请联系华为技术支持。              |
|   2649 | DSG模块状态异常。 | 所有DSG模块全部故障。                    | 请联系华为技术支持。                          |
| 385001 | DSG模块没有配置。 | 没有配置DSG模块。                      | 通过ADD MODULE命令增加DSG模块的配置后，再重新执行此命令。 |
