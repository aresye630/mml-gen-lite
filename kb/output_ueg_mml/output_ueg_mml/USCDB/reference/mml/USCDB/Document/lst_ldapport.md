# 查询LDAP端口号(LST LDAPPORT)

- 注意事项

- 输出结果说明

## 命令功能

**说明** 

该命令在25.1.0版本不支持。

该命令用于查看USCDB网元下的LDAP服务器端口配置信息。

- 若需要查询全部LDAP端口号数据记录的概要信息，请不要输入任何参数。
- 若需要查询某条LDAP端口号数据记录的详细信息，请输入“端口类型”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                            |
|:---------|:-------|:------------------------------------------------|
| PORTTYPE | 端口类型   | 用于指示系统需要按照哪种端口类型来查询LDAP服务器端口数据；若不输入，则表示所有的端口类型。 |
| PORTNUM  | 端口号    | 用于指示系统需要按哪个端口号来查询LDAP服务器端口数据；若不输入，则表示所有的端口号。    |

## 使用实例

1. 查询USCDB网元下所有的LDAP服务器端口配置信息，执行如下命令：

   ```
   LST LDAPPORT:;
   ```

   ```
   %%LST LDAPPORT:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    端口类型     端口号

    LDAPPORT     2     
   (结果个数 = 1)

   ---    END
   ```
2. 查询USCDB网元下“端口号”为“2”的LDAP服务器端口信息，执行如下命令：

   ```
   LST LDAPPORT: PORTNUM=2;
   ```

   ```
   %%LST LDAPPORT: PORTNUM=2;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   端口类型  =  LDAPPORT
     端口号  =  2
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET LDAPPORT**命令的参数说明。
