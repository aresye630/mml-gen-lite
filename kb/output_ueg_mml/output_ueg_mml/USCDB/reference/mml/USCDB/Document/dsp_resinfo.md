# 查询各模块关键资源的占用（DSP RESINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询各模块的关键资源占用信息。

## 注意事项

大多数情况下，以下资源的“资源占用率（%）”均为“0”，只有当消息队列出现消息堆积时才能查询到非0的数值。

- Message queue of priority 0
- Message queue of priority 1
- Message queue of priority 2
- Message queue of priority 3
- Message queue of priority 4

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                              |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MID    | 模块号    | 可选必选说明：可选参数 参数含义：用于指定需要查询关键资源占用信息的模块号。若不输入，则表示查询所有模块号的关键资源占用信息。 取值范围：1~4080 默认值：无。 配置原则：无。                                                                                                        |
| MT     | 模块类型   | 可选必选说明：可选参数 参数含义：用于指定需要查询关键资源占用信息的模块类型。若不输入，则表示查询所有模块类型的关键资源占用信息。 取值范围： DPU(DPU)NDF(NDF)DBG(DBG)DRU(DRU)DSU(DSU)DSG(DSG)PGW(PGW)DMA(DMA)CAG(CAG) 默认值：无。 配置原则：当前版本仅支持查询DSG、DRU、DSU、PGW模块的关键资源占用信息。 |

## 使用实例

当需要查询“模块号”为“3”的关键资源占用信息时:

```
DSP RESINFO: MID=3;
```

| 模块类型     | 用于返回查询到的关键资源占用信息对应的模块类型。                                                                                                                                                                                                                                                                                                                                                                                      |

| 总量       | 用于返回查询的某种系统资源的总量。                                                                                                                                                                                                                                                                                                                                                                                             |

| 资源占用率（%） | 用于返回查询到的系统资源的占用率。                                                                                                                                                                                                                                                                                                                                                                                             |
