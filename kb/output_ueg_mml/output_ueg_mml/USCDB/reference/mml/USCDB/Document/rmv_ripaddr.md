# 删除远端网元IP地址(RMV RIPADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，该操作可能会导致业务中断。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除远端网元IP地址。

## 注意事项

- 删除远端网元IP地址将影响本端DSG和远端DSG的网络连接，导致业务中断，请慎重执行此命令。
- 执行该命令后需要通过**ACT IPDISP**命令激活IP链路之后配置才能生效。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称              | 参数说明                                                                                 |
|:-------|:------------------|:-------------------------------------------------------------------------------------|
| RLOCID | 远端Location标识      | 标识一个远端网元IP地址的关键字段之一，用于指定需要删除哪一个远端Location标识的远端网元IP地址。操作员可以使用LST RIPADDR命令查询获得。       |
| ID     | 远端DPU模块号/远端业务IP索引 | 标识一个远端网元IP地址的关键字段之一，用于指定需要删除哪一个远端DPU模块号/远端业务IP索引的远端网元IP地址。 操作员可以使用LST RIPADDR命令查询获得。 |
| RDPUST | 远端IP地址业务类型        | 标识一个远端网元IP地址的关键字段之一，用于指定需要删除哪一种业务类型的远端网元IP地址。 取值范围：长度不超过128的字符串。 默认值：无。              |

## 使用实例

删除远端网元IP地址，“远端Location标识”为“3”，“远端DPU模块号/远端业务IP索引”为“1”，“远端IP地址业务类型”为“SUP-FE”：

```
RMV RIPADDR: RLOCID=3, ID=1, RDPUST="SUP-FE";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                    | 原因分析                  | 处理建议                                                                                         |
|-------:|:-------------------------|:----------------------|:---------------------------------------------------------------------------------------------|
| 302013 | 该RDPU IP配置不存在。           | 参数“DPU模块号”的IP地址配置未设置。 | 请执行LST SRVIPADDR查询DPU的IP地址配置，在存在的IP地址配置中执行本命令。                                               |
| 302533 | 输入的业务类型不正确，请输入正确的业务类型参数。 | 输入的“远端IP地址业务类型”参数有误。  | 执行LST RIPADDR命令，查询指定“远端Location标识”和“远端DPU模块号/远端业务IP索引”添加了哪些“远端IP地址业务类型”，输入要删除“远端IP地址业务类型”参数。 |
