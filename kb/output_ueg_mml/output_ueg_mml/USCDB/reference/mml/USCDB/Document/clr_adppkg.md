# 删除适配包(CLR ADPPKG)

## 命令功能

**须知** 

该命令属于高危命令，该操作将删除已经加载的适配包，操作不当将导致导入导出任务无法正常执行。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除已加载的适配包。

本命令的使用场景如下：

- 当不需要使用某适配包时，此时可执行本命令进行删除。
- 当某适配包需要被替换更新时，需要使用本命令删除此适配包，然后在执行**LOD ADPPKG**命令重新加载。

## 注意事项

在执行此命令前请注意：

- 当前系统存在使用已加载的适配包进行的数据导出任务，执行**CLR ADPPKG**删除适配包之后，适配包删除，正在运行的导出任务会继续执行直至任务完成。
- 系统存在导入任务时，不能删除导入适配包。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识            | 参数名称    | 参数说明                                              |
|:----------------|:--------|:--------------------------------------------------|
| ADAPTERTYPENAME | 适配包类型名称 | 标识一个适配包的关键字段。用于指定系统删除哪个适配包；操作员可以使用LST ADPPKG查询获取。 |

## 使用实例

USCDB上已加载的SUP-FE插件包需要进行更新。此时需要进行如下操作：

1. 登录“USCDB MML命令” 界面，删除旧的适配包，“适配包类型”为“LDAP(LDAP)”。执行命令如下：

   ```
   CLR ADPPKG: ADAPTERTYPENAME="LDAP";
   ```
2. 登录“USCDB MML命令” 界面，执行**LOD ADPPKG**加载新的插件包。
