# 增加限制Partition营帐操作配置(ADD PROVRESTRICTED)

## 命令功能

**须知** 

该命令属于高危命令，该操作会影响部分营帐命令的执行。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于增加限制Partition营帐操作配置记录。

该命令的使用场景：在混合组网场景下，当某个Partition升级，根据运营商的需求或实际的现网情况需要按Partition限制营帐操作时，使用该命令增加限制Partition营帐操作配置记录。

## 注意事项

- 在混合组网场景下，当某个Partition升级时，只需要增加限制该Partition的营帐操作配置记录。当输入的“Partition标识”为vRSP时，表示增加限制混合组网场景中从vRSP接入的所有Partition营帐操作配置。当升级完成后，需要执行**RMV PROVRESTRICTED**命令及时删除Patition营帐限制。
- 该命令仅限制用户数据操作。
- 该命令不允许进行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。

## 参数说明

| 参数标识        | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                                   |
|:------------|:------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PARTITIONID | Partition标识 | 可选必选说明：必选参数 参数含义：本参数用于指定需要限制营帐操作的Partition ID。 取值范围：1～250 默认值：无。 配置原则：无                                                                                                                                                                                                                                                |
| RSPFLAG     | 是否返回响应报文    | 可选必选说明：可选参数 参数含义：本参数用于控制当Partition对应的营帐操作已被限制时，是否返回超时响应报文。 取值范围：YES：返回超时响应报文。NO：不返回响应消息。 默认值：NO。 配置原则： 对于同时限制混合组网中多个Partition的场景：如果被限制的Partition中包含vRSP，则是否返回响应报文取决于vRSP的此参数设置。如果被限制的Partition中不包含vRSP且营帐消息跨分区广播时，只有在所有Partition的此参数均设置为“YES”的情况下，才会返回超时响应报文，否则不返回响应消息。 当参数“是否返回响应报文”配置为“YES”时，在营帐侧必须适配错误码ERR1019（超时）。 |

## 使用实例

添加限制Partition营帐操作配置信息，“Partition标识”为“1”：

```
ADD PROVRESTRICTED: PARTITIONID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释           | 原因分析                     | 处理建议                                                                                |
|-------:|:----------------|:-------------------------|:------------------------------------------------------------------------------------|
| 275428 | Partition ID不存在 | 输入的“Partition标识”在系统中不存在。 | 通过LST PARTITION和LST RPARTITION命令查询已配置的“Partition标识”和“远端Partition标识”并正确填写，然后重新执行本命令。 |
