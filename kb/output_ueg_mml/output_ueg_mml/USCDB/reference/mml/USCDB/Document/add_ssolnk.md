# 添加SSO链路（ADD SSOLNK）

## 命令功能

该命令用于添加一条SSO链路。

当PGW Web LMT使用SSO（Single Sign On）功能时，需要使用该命令添加一条SSO链路信息。

## 注意事项

- 系统中只允许添加一条SSO链路。
- 密码长期使用会增加被盗窃和破解的风险，而且使用的时间越长，被盗窃和破解的风险越高。定期修改密码可以有效防范这种情况的发生，因此强烈建议您定期修改密码。

## 使用实例

添加一条SSO链路，设置“链路ID”为“1”，“客户端IP类型”为“IPV4(IPV4)”，“客户端IPV4地址”为“192.168.2.119”，“服务器端IP类型”为“IPV4(IPV4)”，“服务器端IPV4地址”为“192.168.20.19”，“服务器端端口”为“31943”。

```
ADD SSOLNK: LNKID=1, CIPVER=IPV4, CIPV4="192.168.2.119", SIPVER=IPV4, SIPV4="192.168.20.19", SPORT=31943;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释                             | 原因分析                           | 处理建议                                                                        |
|-------:|:---------------------------------|:-------------------------------|:----------------------------------------------------------------------------|
| 274630 | 链路已经存在。                          | SSO链路在系统中已添加。                  | 可执行LST SSOLNK命令查询已经存在的SSO链路信息。如需修改，可执行MOD SSOLNK命令修改。                       |
| 274703 | Client IP不存在，请使用ADD SRVIPADDR添加。 | 输入的“客户端IPV4地址”或“客户端IPV6地址”不存在。 | 执行ADD SRVIPADDR命令添加“业务IP类型”为“PGW”的“客户端IPV4地址”或“客户端IPV6地址”，确保成功添加后，再重新执行本命令。 |
| 275466 | 登录用户名和登录密码参数必须同时输入。              | 当输入“登录用户名”，此时“登录密码”必须同时输入。     | 请同时输入“登录用户名”、“登录密码”参数，然后重新执行本命令。                                            |

## 参考信息

SSO（Single Sign-On）：单点登录，是目前比较流行的服务于企业业务整合的解决方案之一，SSO使得在多个应用系统中，用户只需要登录一次，就可以访问所有相互信任的应用系统。
