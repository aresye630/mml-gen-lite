# 删除虚拟远端Location信息(RMV VRLOCATION)

- 命令功能
- 注意事项

- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，执行此命令会导致FE访问BE的业务失败。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在配置数据库中删除一条虚拟远端Location信息。

## 注意事项

- 如果本地的虚拟远端Location标识已被远端Location配置引用，则无法删除该虚拟远端Location。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识    | 参数名称           | 参数说明                                                                                                 |
|:--------|:---------------|:-----------------------------------------------------------------------------------------------------|
| VRLOCID | 虚拟远端Location标识 | 可选必选说明：必选参数 参数含义：用于指定需要删除的远端网元设备的虚拟远端Location标识，操作员可以使用LST VRLOCATION命令查询获得。 取值范围：1～512 默认值：无 配置原则：无 |

## 使用实例

执行**RMV VRLOCATION**命令删除虚拟远端Location标识为12的远端网元设备的虚拟远端Location信息。

```
RMV VRLOCATION: VRLOCID=12;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                         | 原因分析                                              | 处理建议                                                         |
|-------:|:------------------------------|:--------------------------------------------------|:-------------------------------------------------------------|
| 260526 | 虚拟远端Location标识已被远端Location引用。 | 先执行RMV RLOCATION命令删除对应的记录之后，才能执行RMV VRLOCATION命令。 | 先执行RMV RLOCATION命令删除对应的记录，再重新执行此命令。                          |
| 260542 | 指定的虚拟远端Location标识不存在。         | 输入的“虚拟远端Location标识”参数不存在。                         | 请先执行LST VRLOCATION命令查看已存在的“虚拟远端Location标识”，再执行本命令重新输入已存在的参数。 |
