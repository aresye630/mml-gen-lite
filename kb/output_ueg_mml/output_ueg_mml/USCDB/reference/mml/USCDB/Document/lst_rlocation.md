# 查询远端Location信息(LST RLOCATION)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询远端网元设备的Location信息。为用户对远端网元设备进行操作提供支持。

- 若需要查询全部远端网元设备的Location信息记录的概要信息，请不要输入任何参数。
- 若需要查询某条远端网元设备的Location信息记录的详细信息，请输入“远端Location标识”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称         | 参数说明                                                                               |
|:-------|:-------------|:-----------------------------------------------------------------------------------|
| RLOCID | 远端Location标识 | 可选必选说明：可选参数。 用于指示系统需要按照哪个远端Location标识来查询远端网元设备的Location信息；若不输入，则表示所有的远端Location标识。 |
| RMT    | 远端网元类型       | 可选必选说明：可选参数。 用于指示系统需要按照哪个远端网元类型来查询远端网元设备的Location信息；若不输入，则表示所有的远端网元类型。             |
| LP     | 位置ID优先级      | 可选必选说明：可选参数。 用于指示系统需要按照哪个位置ID优先级来查询远端网元设备的Location信息；若不输入，则表示所有的位置ID优先级。           |

## 使用实例

1. 查询全部远端网元设备的Location信息记录的概要信息：

   ```
   LST RLOCATION:;
   ```

   ```
   %%LST RLOCATION:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   远端Location标识     远端网元类型     位置ID优先级     是否容灾关系
   96                   USCDB            1                是            
   128                  USCDB            2                否             
   160                  USCDB            3                否  
   (结果个数 = 3)

   ---    END
   ```
2. 查询“远端Location标识”为“96”的远端网元设备的Location信息记录的详细信息：

   ```
   LST RLOCATION: RLOCID=96;
   ```

   ```
   %%LST RLOCATION: RLOCID=96;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   远端Location标识  =  96
       远端网元类型  =  USCDB
       位置ID优先级  =  1
       是否容灾关系  =  是
   (结果个数 = 1)

   ---    END
   ```
