# 删除异构模型映射关系（RMV SCHEMAMAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，错误删除映射配置会导致业务处理异常。因此执行该命令前，需要与华为技术支持确认后才可以实施。

当涉及KV型DCI消息转HETER型DCI消息时，若UDB已存在对应的表ID，可执行该命令将其对应的映射关系在异构模型映射关系表中移除黑名单。

## 注意事项

主备局的异构模型映射关系表需要保持一致。

## 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                                                                                                                                                     |
|:--------|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FETYPE  | FE类型     | 可选必选说明：必选参数 参数含义：用于指定删除哪个FE类型的异构模型映射关系，此参数在USCDB下唯一，通过“MML命令行 - USCDB”的LOD FEPLUG加载FE插件后在此引用。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：该参数是联想参数，不能手动输入，必须选择加载后的插件类型。                                                               |
| OPTYPE  | 操作类型     | 可选必选说明：必选参数 参数含义：用于指定删除哪种操作类型的异构模型映射关系。 取值范围：BLACKLIST(黑名单)。 默认值：无。 配置原则：无。  说明： 以下两种情况不进行异构转换处理： schemamap.xml文件“TableNodeMapList”配置项中不存在的映射关系。schemamap.xml文件“TableNodeMapList”配置项中存在的映射关系且异构模型映射关系表中设置该映射关系的操作类型为黑名单。 |
| TABLEID | 关系模型表ID  | 可选必选说明：必选参数 参数含义：用于指定UDB的表ID。 取值范围：0~32767 默认值：无。 配置原则：无。                                                                                                                                                                |
| NODEID  | KV模型节点ID | 可选必选说明：必选参数 参数含义：用于指定UDR的节点ID。 取值范围：0~32767 默认值：无。 配置原则：无。                                                                                                                                                               |

## 使用实例

删除一条异构模型映射关系记录：设置“FE类型”为“SUP-FE”，“操作类型”为“BLACKLIST”，“关系模型表ID”为“6000”，“KV模型节点ID”为“6000”。

```
RMV SCHEMAMAP: FETYPE="SUP-FE", OPTYPE=BLACKLIST, TABLEID=6000, NODEID=6000;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释   | 原因分析                        | 处理建议                                            |
|-------:|:--------|:----------------------------|:------------------------------------------------|
| 260667 | 记录不存在。  | 执行该命令删除的异构模型映射关系记录在数据库中不存在。 | 执行LST SCHEMAMAP命令查询数据库中存在的异构模型映射关系记录，然后重新执行本命令。 |
