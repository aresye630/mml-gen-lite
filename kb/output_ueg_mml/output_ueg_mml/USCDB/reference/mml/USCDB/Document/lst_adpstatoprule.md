# 查询适配测量操作员规则对象(LST ADPSTATOPRULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询适配测量操作员规则信息。

- 若需要查询全部适配测量操作员规则的概要信息，请不要输入任何参数。
- 若需要查询某个适配测量操作员规则的详细信息，请输入“适配测量对象名称”或者“操作员名称”。

## 注意事项

无。

## 参数说明

| 参数标识           | 参数名称     | 参数说明                                            |
|:---------------|:---------|:------------------------------------------------|
| ADPSTATOBJNAME | 适配测量对象名称 | 用于标识一条适配测量操作员规则记录的关键字段之一；若不输入，则表示查询所有的适配测量对象名称。 |
| OPERATOR       | 操作员名称    | 用于标识一条适配测量操作员规则记录的关键字段之一；若不输入，则表示查询所有的操作员名称。    |

## 使用实例

1. 查询指定适配测量操作员规则记录，该“适配测量对象名称”为“TestObj”，“操作员名称”为“opr1”。

   ```
   LST ADPSTATOPRULE: ADPSTATOBJNAME="TestObj", OPERATOR="opr1";
   ```

   ```
   %%LST ADPSTATOPRULE: ADPSTATOBJNAME="TestObj", OPERATOR="opr1";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------------------
   适配测量对象名称  =  TestObj
         操作员名称  =  opr1
   (结果个数 = 1)

   ---    END
   ```
2. 查询适配测量操作员规则的所有记录。

   ```
   LST ADPSTATOPRULE:;
   ```

   ```
   %%LST ADPSTATOPRULE:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------------------
    适配测量对象名称  操作员名称

    THREE             opr3          
    TestObj           opr1         
   (结果个数 = 2)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数详见**ADD ADPSTATOPRULE**命令的参数说明。
