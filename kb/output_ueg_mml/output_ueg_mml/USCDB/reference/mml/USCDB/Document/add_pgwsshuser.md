# 增加PGW SSH用户(ADD PGWSSHUSER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于添加SSH用户。

当营帐客户端需要通过SSH加密的方式和PGW交互时，使用该命令添加通过SSH登录的用户。

**说明** 

当营帐客户端使用SSH加密的方式和PGW交互时，如果该局点没有直接连接MML端口，建议将系统软参PGWMMLSWITCH（PGW MML开关）设置为0，禁止客户端连接MML端口。

## 注意事项

- PGW只支持MML协议的SSH加密。
- SSH服务使用端口由软参“SSHSFTPSRVSEPARATION（SSH与SFTP服务分离开关）”控制：
  - 当软参取值为0时，SSH与SFTP服务不分离，此时SSH与SFTP服务的端口为22端口。
  - 当软参取值为1时，SSH与SFTP服务分离，此时SFTP服务的端口为22端口，SSH服务的端口为20022端口。
- 密码长期使用会增加被盗窃和破解的风险，而且使用的时间越长，被盗窃和破解的风险越高。定期修改密码可以有效防范这种情况的发生，因此强烈建议您定期修改密码。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                  |
|:------------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USERNAME    | 用户名     | 用于指定通过SSH登录的用户名，由数字、字母组成，且必须以字母开头。用户名不能与操作系统保留的用户同名，操作系统保留的用户名请参见产品手册的“USCDB默认帐号”页面。 取值范围：长度不超过31的字符串。 默认值：无。                                                                                                                                                                                                         |
| PWD         | 新密码     | 用于指定通过SSH登录的用户的密码。 密码区分大小写，其复杂度需同时满足下列条件：密码必须至少包含以下四个类别中的三类：英文大写字母。英文小写字母。数字：0～9。特殊字符：~ ! # % ^ * ( ) _ - + [ ] { } | < > . ?。 不允许使用三个或三个以上连续的字母或数字（例如：ABC、123）。密码不能和用户名或者用户名的逆序一样，且不能包含用户名或者用户名的逆序。不允许使用三个或三个以上连续的相同字符（例如：AAA）。密码长度最短8个字符。密码的第一个字符必须是字母。 取值范围：长度不超过30的字符串。 默认值：无。  说明： 当密码包含用户名中三个连续字符时，ssh登录PGW会失败。 |
| CFM         | 确认密码    | 用于指定通过SSH登录的用户的确认密码。 取值范围：长度不超过30的字符串。 默认值：无。                                                                                                                                                                                                                                                                         |
| PORT        | PGW服务端口 | 用于指定PGW与SSH连接的服务端口。“PGW服务端口”可以通过LST PORT命令查询获得，使用“端口类型”为“PORT_FOR_PROV”，“端口子类型”为“PORT_FOR_MML”对应的端口作为“PGW服务端口”。 取值范围：0～65535 默认值：无。                                                                                                                                                                                   |
| DESCRIPTION | 用户描述    | 用于描述SSH用户，取值不能包含逗号、反斜杠、大于号和小于号。 取值范围：长度不超过64的字符串。 默认值：无。                                                                                                                                                                                                                                                              |

## 使用实例

1. 添加SSH用户，“用户名”为“sshuser”，“密码”为“ab12CD34#56”，“确认密码”为“ab12CD34#56”，“PGW服务端口”为“7776”，“用户描述”为“user info”，。

   ```
   ADD PGWSSHUSER: USERNAME="sshuser", PWD="*****", CFM="*****", PORT=7776, DESCRIPTION="user info";
   ```

**说明** 

- 密码在命令行输入区域显示为\*\*\*\*\*。
- 执行本命令时，若“密码”取值为样例中的弱口令“ab12CD34#56”，执行结果会返回“260566”错误码。
