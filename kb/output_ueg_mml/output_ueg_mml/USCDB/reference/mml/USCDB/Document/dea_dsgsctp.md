# 去激活SCTP链路(DEA DSGSCTP)

## 命令功能

**须知** 

- 该命令属于高危命令，该操作将去激活链路，操作不当将导致业务中断、链路过载等问题。因此执行该命令前，需要与华为技术支持确认后才可以实施。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于去激活一条指定SCTP链路或一键式去激活当局和指定远端局点的所有链路，其对应的恢复命令为**ACT DSGSCTP**。

该命令的使用场景：在异常场景下，用于故障定位及修复使用。

## 注意事项

- 去激活链路可能会导致业务呼损，须谨慎操作。
- 该命令不允许执行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。

## 参数说明

| 参数标识    | 参数名称         | 参数说明                                                                 |
|:--------|:-------------|:---------------------------------------------------------------------|
| MID     | DSG模块号       | 可选必选说明：可选参数 参数含义：用于指定需要去激活链路的DSG模块号。 取值范围：1～2047 默认值：无。 配置原则：无。      |
| RLOCID  | 远端Location标识 | 可选必选说明：必选参数 参数含义：用于指定需要去激活链路的远端Location标识。 取值范围：1～512 默认值：无。 配置原则：无。 |
| RDSGMID | 远端DSG模块号     | 可选必选说明：可选参数 参数含义：用于指定需要去激活链路的远端DSG模块号。 取值范围：1～2047 默认值：无。 配置原则：无。    |

## 使用实例

1. 去激活一条链路，“DSG模块号”为“2”,“远端Location标识”为“6”，“远端DSG模块号”为“3”。

   ```
   DEA DSGSCTP: MID=2, RLOCID=6, RDSGMID=3;
   ```
2. 去激活本局和“远端Location标识”为“6”的局点的所有链路：

   ```
   DEA DSGSCTP: RLOCID=6;
   ```
3. 去激活“DSG模块号”为“2”和“远端Location标识”为“6”的局点所有链路。

   ```
   DEA DSGSCTP: MID=2, RLOCID=6;
   ```
4. 去激活本局所有DSG的链路和“远端Location标识”为“6”、“远端DSG模块号”为“3”的链路。

   ```
   DEA DSGSCTP: RLOCID=6, RDSGMID=3;
   ```
