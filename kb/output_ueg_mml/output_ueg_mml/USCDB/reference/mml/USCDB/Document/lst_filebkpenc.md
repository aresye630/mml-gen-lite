# 查询文件备份加密信息(LST FILEBKPENC)

- 注意事项
- 参数说明

## 命令功能

该命令用于查询文件备份加密信息：

- 若要查询最新的文件备份加密信息，请不要输入任何参数。
- 若要查询某些或某个文件备份加密信息，请输入“密钥编号”或其他参数，或者“密钥编号”和其他参数的组合。

## 注意事项

- 当不指定任何参数时，则从“密钥编号”最大的一条记录开始，显示最新的最多20条记录。
- 当指定某个参数时，显示结果如下：
  - 指定“密钥编号”，则查询结果显示“密钥编号”以及依次小于这个密钥编号的最多20条记录。
  - 指定“更新时间”，则显示等于和早于这个时间的最多20条记录。
  - 指定“盐值”，则显示符合条件的最多20条记录。
  - 指定“描述”，则显示符合条件的最多20条记录。
- 当指定某两个或两个以上参数时，则显示符合条件的最多20条记录。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                  |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NO      | 密钥编号   | 可选必选说明：可选参数 参数含义：用于指示系统按照密钥编号来查询文件备份加密信息；若不输入，则表示所有的密钥编号。 取值范围：0~1023 默认值：无。 配置原则：密钥编号由系统自动生成，从0开始，编号数字越大密钥越新。                                                                                        |
| SALT    | 盐值     | 可选必选说明：可选参数 参数含义：用于指示系统按照盐值来查询文件备份加密信息；若不输入，则表示所有的盐值。 取值范围：长度不超过32的十六进制字符串。 默认值：无。 配置原则：无。                                                                                                            |
| UPDTIME | 更新时间   | 可选必选说明：可选参数 参数含义：用于指示系统按照更新时间来查询文件备份加密信息；若不输入，则表示所有的更新时间。 取值范围：格式为“YYYY&MM&DD&HH&MM&SS”的字符串。各部分的取值范围分别如下： YYYY（年份）：1990~2037MM（月份）：1~12DD（日期）：1~31HH（小时）：00~23MM（分钟）：00~59SS（秒）：00~59。 默认值：无。 配置原则：无。 |
| DESC    | 描述     | 可选必选说明：可选参数 参数含义：用于指示系统按照描述来查询文件备份加密信息；若不输入，则表示所有的描述。 取值范围：长度不超过32的字符串。 默认值：无。 配置原则：无。                                                                                                                |

## 使用实例

1. 查询最新的文件备份加密信息。

   ```
   LST FILEBKPENC:;
   ```

   ```
   %%LST FILEBKPENC:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------------------
    密钥编号  盐值                              更新时间                   描述

    0         811F687EE52EBFCE7388A2E63D90091B  2021-09-13 15:32:17+00:00  11         
    1         5A78271F22CB1DC1DDCD9FD550832BDF  2021-09-13 15:32:20+00:00  11         
   (结果个数 = 2)

   ---    END
   ```
2. 查询“盐值”为“811F687EE52EBFCE7388A2E63D90091B”的文件备份加密信息。

   ```
   LST FILEBKPENC: SALT="811F687EE52EBFCE7388A2E63D90091B";
   ```

   ```
   %%LST FILEBKPENC: SALT="811F687EE52EBFCE7388A2E63D90091B";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------------------
        密钥编号  =  0
            盐值  =  811F687EE52EBFCE7388A2E63D90091B
        更新时间  =  2021-09-13 15:32:17+00:00
            描述  =  11
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见

**SET FILEBKPENC**

命令的参数说明。表1列出的是未包含在

**SET FILEBKPENC**

命令参数说明中的输出项。

| 输出项名称   | 输出项解释                                        |
|:--------|:---------------------------------------------|
| 密钥编号    | 用于唯一标识文件备份加密信息。 密钥编号由系统自动生成，从0开始，编号数字越大密钥越新。 |
| 更新时间    | 用于表示密钥更新的时间。                                 |
