# 设置恢复目录(SET RESTOREDIR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，在执行前请联系华为技术支持确认。

该命令用于指定Pod上的数据备份目录，用于通过指定目录恢复备份数据到内存数据库。

## 注意事项

- 命令成功执行需满足条件：指定目录恢复开关“SPCFDIRRSTSWT（指定目录恢复开关）”参数值为“1”。
- 该命令仅适用于升级回退和紧急数据恢复场景。其他场景使用会导致模块故障，禁止使用。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|:------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 服务类型   | 用于指定具体的服务类型。                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| DIRECTORY   | 目录     | 用于设置指定系统恢复的目录。 取值范围： UPGPLANE1(1平面/opt/uscdb/SNP_UPG/目录)UPGPLANE0(0平面/opt/uscdb/SNP_UPG/目录)EMGRST(紧急恢复目录)：目录为“/opt/uscdb/emgRst”。CURRENT(今日周期备份)：目录“/opt/uscdb/snp”中当天周期性备份文件。LAST(昨日周期备份)：目录“/opt/uscdb/snp”中前一天周期性备份文件。 默认值：无。 说明：在0点到周期备份完成前，选择“CURRENT(今日周期备份)”进行恢复，将会导致加载源缺失，无法成功恢复。在选择“CURRENT(今日周期备份)”或“LAST(昨日周期备份)”进行恢复时，需要关闭周期性备份，防止恢复时，恢复源被删除。指定“CURRENT(今日周期备份)”或“LAST(昨日周期备份)”进行恢复不适用于恢复过程跨天的场景，如有该场景存在，需要选择“EMGRST(紧急恢复目录)”进行恢复。 |

## 使用实例

设置“服务类型”为“SUP-FE”的指定恢复目录信息。

```
SET RESTOREDIR: SERVICETYPE="SUP-FE", DIRECTORY=UPGPLANE1;
```

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|------:|:--------------------|:--------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------|
|  2059 | 指定的业务类型不存在。         | 输入的“服务类型”不存在。                                     | 通过LST FEPLUG命令查询加载的“FE类型名称”，“FE类型名称”即“服务类型”。 若“服务类型”加载成功，请在执行该命令时输入正确的服务类型名称。若“服务类型”加载不成功或者没有加载，通过LOD FEPLUG命令加载成功后，重新执行该命令。 |
|  2459 | 软参SPCFDIRRSTSWT未打开。 | 指定服务类型的指定目录恢复开关“SPCFDIRRSTSWT（指定目录恢复开关）”参数值不为“1”。 | 执行MOD INSP命令将指定服务类型的指定时间恢复开关“SPCFDIRRSTSWT（指定目录恢复开关）”的值修改为“1”。                                                               |
