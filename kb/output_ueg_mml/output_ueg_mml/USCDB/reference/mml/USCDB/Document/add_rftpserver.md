# 添加远端FTP服务器(ADD RFTPSERVER)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

该命令用于添加远端FTP服务器，添加后，可从外部的FTP服务器下载文件到本地，或将本地的文件上传到外部的FTP服务器。

## 注意事项

- “远端服务器类型”和“远端服务器名称”作为一个远端FTP服务器配置的唯一识别，不允许重复。
- 如果对端的设备是第三方FTP服务器，远端FTP服务器的IP地址需要根据第三方的配置决定。
- 当USCDB从远端服务器下载文件时，文件大小等于或超过2G的单个文件会下载失败。
- 远端FTP/SFTP服务器的本端工作目录只能有一个配置为BACKUPNODE。
- 远端服务器只能是第三方服务器，不能是本网元内的服务器，即参数“服务端IPV4地址”或“服务端IPV6地址”所填写的IP地址不能为本网元内规划的IP。
- 成功添加远端FTP服务器后，需要通过配置FTPCLIENTPACKETSIZE（FTP客户端包大小），FTPCLIENTFLOWCTRLSENDTASKDELAY（FTP客户端发包流控时间）和FTPCLIENTSENDPACKETCOUNT（FTP客户端发送包数量）软参控制系统作为FTP客户端发送文件的速度，若不对发送速度进行控制，则可能导致系统上报ALM-100339 Fabric链路出现亚健康告警。
- 远端FTP服务器个数不建议配置超过50个，超过50个可能导致上报**ALM-14030 FTP/SFTP链路故障**告警。
- 密码长期使用会增加被盗窃和破解的风险，而且使用的时间越长，被盗窃和破解的风险越高。定期修改密码可以有效防范这种情况的发生，因此强烈建议您定期修改密码。
- 备份内存数据库到第三方服务器时，“传输方向”需分别配置对应的“UPLOAD(上传)”和“DOWNLOAD(下载)”两条数据记录。

## 参数说明

| 参数标识           | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                                      |
|:---------------|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVERTYPE     | 远端服务器类型    | 用于指定远端FTP服务器的类型。 取值范围： PROV(业务)：表示为支持营帐功能的远端FTP服务器，该类型的远端FTP服务器添加后，由网关类型为PGW的DPU创建远端FTP服务器实例。DATAMTN(维护)：表示为支持导出功能的远端FTP服务器，该类型的远端FTP服务器添加后，由网关类型为DMA的DPU创建远端FTP服务器实例。 默认值：无。                                                                                                                                                             |
| SERVERNAME     | 远端服务器名称    | 用于指定远端FTP服务器的名称。 取值范围：由数字、字母和下划线组成的不超过127位的字符串。 默认值：无。                                                                                                                                                                                                                                                                                    |
| IPVER          | IP类型       | 用于表示IP地址类型。 取值范围：IPV4：当系统要求使用IPv4类型的IP地址时选择此选项。IPV6：当系统要求使用IPv6类型的IP地址时选择此选项。 默认值：无。                                                                                                                                                                                                                                                      |
| SERVERIPV4     | 服务端IPV4地址  | 仅当本命令中的“IP类型”参数选择为“IPV4”时该参数有效，用于指定远端FTP服务器提供服务的IPv4地址，输入的IPv4地址是配置前已获取的服务器IPv4地址。 取值范围：符合IPv4格式要求。 默认值：无。                                                                                                                                                                                                                                |
| SERVERIPV6     | 服务端IPV6地址  | 仅当本命令中的“IP类型”参数选择为“IPV6”时该参数有效，用于指定远端FTP服务器提供服务的IPv6地址，输入的IPv6地址是配置前已获取的服务器IPv6地址。 取值范围：符合IPv6格式要求。 默认值：无。                                                                                                                                                                                                                                |
| SERVERPORT     | 服务端端口      | 用于指定远端FTP服务器提供服务的端口号。 取值范围：1～65535 默认值：无。                                                                                                                                                                                                                                                                                                 |
| USERNAME       | 用户名称       | 用于指定远端FTP服务器提供服务的用户名。 取值范围：长度不超过31位的字符串。 默认值：无。                                                                                                                                                                                                                                                                                           |
| PWD            | 密码         | 用于指定远端FTP服务器提供服务用户名的密码，输入的密码是第三方服务器按各自密码规则已经设置的密码。 取值范围：长度不超过31位的字符串。 默认值：无。                                                                                                                                                                                                                                                              |
| CFM            | 确认密码       | 用于指定远端FTP服务器提供服务用户名的确认密码。 取值范围：长度不超过31位的字符串。 默认值：无。                                                                                                                                                                                                                                                                                       |
| RWORKDIR       | FTP远端工作目录  | 用于指定远端FTP服务器上用户名称对应的工作目录。该工作目录为相对远端FTP服务器根目录的路径，需确保指定的工作目录存在。例如远端工作目录为服务器根目录下realtime目录，则设置为“realtime”。 取值范围：长度不超过127的字符串，不支持特殊字符：“，”、“'”和“；”。 默认值：无。                                                                                                                                                                                     |
| LWORKDIR       | FTP本端工作目录  | 用于指定USCDB工作目录，该参数为联想参数列表，不能手动输入，其取值为LST FTPWORKDIR命令查询获得的“配置名称”输出参数。 默认值：无。                                                                                                                                                                                                                                                               |
| FILTER         | 过滤条件       | 仅当“远端服务器类型”选择“PROV(业务)”时该参数有效，用于指定USCDB传输文件的过滤条件。 配置USCDB传输文件的过滤条件时，需要使用如下格式：[前缀]*[后缀]。例如：HLR001*DAT，即过滤了“前缀名”为“HLR001”且“后缀名”为“DAT”的文件。 取值范围：长度不超过63的字符串，不支持特殊字符：“，”、“'”和“；”。 默认值：无。                                                                                                                                                      |
| TRANSDIRECTION | 传输方向       | 仅当“远端服务器类型”参数输入时该参数有效，用于指定USCDB传输文件的方向。 取值范围： UPLOAD(上传)：文件从USCDB传输到远端FTP服务器。DOWNLOAD(下载)：文件从远端FTP服务器传输到USCDB。TIMDOWNLOAD(定时下载)：文件定时从远端FTP服务器传输到USCDB。 默认值：无。 说明： N+1实时主备容灾场景下，该参数必须设置为“DOWNLOAD(下载)”。当“远端服务器类型”选择“DATAMTN(维护)”时，该参数不能设置为“TIMDOWNLOAD(定时下载)”。当“远端服务器类型”选择“DATAMTN(维护)”且“FTP本端工作目录”的值不为“BACKUPNODE”时，该参数只能设置为“UPLOAD(上传)”。 |
| BACKUPFLAG     | 是否备份标示     | 仅当“远端服务器类型”选择“PROV(业务)”且“传输方向”选择“UPLOAD（上传）”时该参数有效，用于标识USCDB传输文件成功后是否需要备份。 取值范围： NO(否)YES(是) 默认值：无。 说明： 当该参数取值为“YES(是)”时，USCDB上传文件后，会将文件放入备份目录进行压缩备份。备份目录中的文件个数达到1000个或文件总大小超过400MB时会删除存放时间最长的文件，当新上传文件的大小超过400MB时，将清空备份目录。执行该命令并且不输入该参数时，系统会设置初始值“NO(否)”。                                                                                |
| DELFILEFLAG    | 删除文件标示     | 仅当“远端服务器类型”选择“PROV(业务)”且“传输方向”选择“DOWNLOAD(下载)”时，用于指定USCDB从远端FTP服务器下载文件后，是否删除远端FTP服务器的文件。 取值范围： YES(是)NO(否) 默认值：无。 说明：执行该命令并且不输入该参数时，系统会设置初始值“NO(否)”。                                                                                                                                                                                      |
| CYCLE          | 获取周期       | 仅当“远端服务器类型”选择“PROV(业务)”且“传输方向”选择“DOWNLOAD(下载)”时该参数有效，用于指定USCDB从远端FTP服务器下载文件的周期。如果有多个文件下载则同时下载多个文件。 取值范围：长度不超过15的字符串，由天、小时、分钟、秒组成，格式为n1Dn2Hn3Mn4S，所表示的时间必须大于等于5秒。n1表示天数，取值范围是0～365，后面的D表示天。n2表示小时数，取值范围是0～23，后面的H表示小时。n3表示分钟数，取值范围是0～59，后面的M表示分钟。n4表示秒数，取值范围是0～59，后面的S表示秒。 默认值：无。                                                          |
| STRTIME        | 开始时间       | 仅当本命令中的“远端服务器类型”选择“PROV(业务)”且“传输方向”为“TIMDOWNLOAD(定时下载)”时该参数有效。用于指定每天定时传输文件到本地的开始时间。 取值范围：00:00:00～23:59:59。 默认值：00:00:00。                                                                                                                                                                                                                 |
| ENDTIME        | 结束时间       | 仅当本命令中的“远端服务器类型”选择“PROV(业务)”且“传输方向”为“TIMDOWNLOAD(定时下载)”时该参数有效。用于指定每天定时传输文件到本地的结束时间，若文件较大，到了配置的结束时间仍没有传输完，会继续传输。待文件传输完成后，任务结束。输入的“结束时间”必须晚于“开始时间”。 取值范围：00:00:00～23:59:59。 默认值：00:00:00。                                                                                                                                                   |
| FTPWORKMODE    | FTP客户端工作模式 | 用于指定USCDB工作模式。当发现USCDB无法上传或下载数据时，可以尝试修改USCDB工作模式以完成上传或下载。 取值范围： ACTIVE(主动模式)：表示在建立数据通道时由FTP服务器分配端口。PASSIVE(被动模式)：表示在建立数据通道时由USCDB指定端口。 默认值：ACTIVE(主动模式)。 说明：当远端为严格按照协议实现的FTP服务器（控制端口为21，数据端口为20）时，该参数需要配置为“PASSIVE(被动模式)”。                                                                                                                |
| LOCALIPV4      | 本端IPV4地址   | 用于指定USCDB提供服务的IPv4地址。 取值范围：符合IPv4格式要求。 默认值：无。 说明： 当“远端服务器类型”为“PROV(业务)”时，该IPv4地址必须为网关类型为PGW的DPU模块的IPv4地址。当“远端服务器类型”为“DATAMTN(维护)”时，该IPv4地址必须为网关类型为DMA的DPU模块的IPv4地址。                                                                                                                                                                       |
| LOCALIPV6      | 本端IPV6地址   | 用于指定USCDB提供服务的IPv6地址。 取值范围：符合IPv6格式要求。 默认值：无。 说明： 当“远端服务器类型”为“PROV(业务)”时，该IPv6地址必须为网关类型为PGW的DPU模块的IPv6地址。当“远端服务器类型”为“DATAMTN(维护)”时，该IPv6地址必须为网关类型为DMA的DPU模块的IPv6地址。                                                                                                                                                                       |
| DESCRIPTION    | 服务器描述      | 用于描述远端FTP服务器。 取值范围：长度不超过63的字符串，取值不能包含逗号和反斜杠。 默认值：无。                                                                                                                                                                                                                                                                                       |
| TRANSFERTYPE   | 传输类型       | 用于设置传输类型。 取值范围： BINARY(二进制传输)：表示采用二进制传输方式进行传输。ASCII(ASCII传输)：表示采用ASCII传输方式进行传输。 默认值：BINARY(二进制传输)。                                                                                                                                                                                                                                        |

## 使用实例

某局点需要添加远端FTP服务器配置:

- “远端服务器类型”：“PROV”
- “远端服务器名称”：“ftpserver”
- “IP类型”：“IPV4”
- “服务端IPV4地址”：“10.94.1.131”
- “服务端端口”：“21”
- “用户名称”：“name”
- “密码”：“\*\*\*\*\*\*\*\*\*\*\*”
- “确认密码”：“\*\*\*\*\*\*\*\*\*\*\*”
- “FTP远端工作目录”：“realtime”
- “FTP本端工作目录”：“TESTPATH”
- “过滤条件”：“\*”
- “传输方向”：“DOWNLOAD(下载)”
- “本端IPV4地址”：“10.93.1.131”

```
ADD RFTPSERVER: SERVERTYPE=PROV, SERVERNAME="ftpserver", IPVER=IPV4, SERVERIPV4="10.94.1.131", SERVERPORT=21, USERNAME="name", PWD="***********", CFM="***********", RWORKDIR="realtime", LWORKDIR="TESTPATH", FILTER="*", TRANSDIRECTION=DOWNLOAD, LOCALIPV4="10.93.1.131";
```
