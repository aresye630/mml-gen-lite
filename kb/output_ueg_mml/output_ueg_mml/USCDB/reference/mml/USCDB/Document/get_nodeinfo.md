## 命令功能

**须知** 

该命令属于高危命令，该操作可能产生短时间内Pod CPU使用率较高，导致业务受损。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令主要用于维护和故障处理场景下获取节点的相关信息，便于故障定位。

- 系统根据模块信息获取相关节点信息，不同类型的模块支持获取的不同类型的节点信息。
  - DRU模块支持获取除全局数据、全局数据刷新状态以外的节点信息。
  - DSU模块支持获取除全局数据、全局数据刷新状态以外的节点信息。
  - DSG模块支持获取心跳、CHANNEL、本地日志、流控日志类型的节点信息。
  - NDF模块支持获取本地日志类型的节点信息，检查OS和物理库用户的默认密码是否修改。
  - PGW模块支持获取本地日志、全局数据、全局数据刷新状态和模块资源的节点信息。
  - DBG模块支持获取各节点间的用户数据校验结果信息和分布式批量修改用户数据失败的日志信息。
  - DPU模块只支持获取本地日志类型的节点信息。
  - CAG模块只支持获取心跳类型的节点信息，相关原理请参见心跳消息管理。
  - DMA模块支持获取GMDB状态和模块资源的节点信息。
  - 其它类型的模块不支持通过该命令获取节点信息。
- 系统根据用户信息一键式获取指定用户的分析日志，分析日志包括：
  - 指定用户所在DRU/DSU的模块日志。
  - 指定用户的校验日志。
  - 指定用户的用户轨迹日志。
  - 指定用户的营帐日志。
  - 指定用户的历史FDB备份数据日志。
  - 指定用户的OMU主机日志。
  - 指定用户的分布式批量修改用户数据失败日志。

## 注意事项

- 此命令在执行过程中可能会导致虚拟机CPU（裸机Pod CPU）短时间内上升较高，话务高峰时可导致业务呼损，请在华为研发工程师指导下使用该命令。
- 执行此命令一键式收集指定用户日志信息，由于该类日志文件通常较大，会大量占用系统磁盘空间，因此完成文件下载后需定期清理该类文件，确保系统平稳运行。
- 执行此命令前请确保系统留有充足的磁盘空间，且建议在非业务繁忙期间执行此任务。
- USCDB\_NODEINFO目录下文件大小不允许超过10G，否则命令执行失败。如果超过10G，请删除USCDB\_NODEINFO目录。
- 当USCDB\_NODEINFO目录和其第一层子目录用户属组不是omu:oinstall，权限小于'rwx------'时，命令执行失败，需要手工将USCDB\_NODEINFO及其第一层子目录的权限修改为omu:oinstall，权限不小于'rwx------'。
- 当某个模块异常，无法处理命令时，需要手工到虚拟机（裸机Pod）上获取节点信息。
- 获取主备PGW模块的日志时，将会同时获取DMS WebUI的本地调试日志。
- 获取PGW模块的本地日志时，如果路径下存在securitylog目录，则会将该目录下的安全审计日志文件一起获取。
- 执行命令之后，经过初始化、写文件、上传、清理临时文件等过程，获取到的文件存放在CGPLite的“/opt/HUAWEI/cgp/workshop/omu/share/nefile/USCDB\_NODEINFO/”目录下。
- 下载到本地的方式：单击“系统 > 文件传输”打开文件传输窗口，再单击“CGPLite文件 > 网元文件 > USCDB\_NODEINFO”，选择指定网元的文件下载获取。
- 命令中节点信息类型参数标记①的文件包含用户的个人数据，如：IMSI、MSISDN等，因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护。例如：
  1. 采用安全的文件传输协议（如SFTP）传输的文件。
  2. 并严格控制文件的访问权限。
  3. 及时清理文件。

  在从运营商网络获取数据前，必须要获得运营商的授权。

  建议您采用安全的文件传输协议（如SFTP）传输文件，并严格控制文件的访问权限。

  若需从运营商网络中获取必要的数据，需要运营商维护人员对其中的个人数据进行匿名化处理，匿名化后的数据由运营商维护人员审核后提供，以防止个人数据泄露。匿名化处理工具可以在https://support.huawei.com/获取，获取方法请参见产品手册“匿名化工具安全策略”页面。
- Redo归档收集和过滤分析，会引起虚拟机（裸机Pod）资源占用增加，当业务繁忙和系统资源不足时，不建议进行此类操作。
- 命令执行时间可能较长（5~150分钟），影响该命令的后续再执行，维护人员需谨慎操作。
- 该命令不允许进行批操作。
- 获取营帐日志时，如果按输入条件未查询到记录，执行命令返回失败，报文返回“未查询到匹配的记录”，此时请检查输入条件是否正确。
- 获取营帐日志时，如果符合条件的记录超出30000条，执行命令返回失败，报文返回“数据量过大，超出30000条限制”，请调整过滤周期。
- 若要获取DSU模块的Redo文本，因现网Redo过多，可能导致获取超时。建议按小时粒度获取Redo日志或按照“Redo日志类型”为“NONETEXT”获取后在本地解析。

## 使用实例

1. 获取心跳信息：

   ```
   GET NODEINFO: TYPE=HEARTBEAT;
   ```
2. 获取CHANNEL信息：

   ```
   GET NODEINFO: TYPE=CHANNEL;
   ```
3. 获取Redo日志信息，设置参数Redo日志类型为“PARTTEXT”，“模块号”为“1093”：

   ```
   GET NODEINFO: TYPE=REDOLOG, REDOTYPE=PARTTEXT, MID=1093;
   ```
4. 按小时获取Redo日志信息，设置参数“Redo日志类型”“FULLTEXT”，“模块号”为“1093”，“历史Redo日志小时数”为“Hours\_2(2)”：

   ```
   GET NODEINFO: TYPE=REDOLOG, REDOTYPE=FULLTEXT, MID=1093, HOURS=Hours_2-1;
   ```
5. 按小时获取Redo日志信息，设置参数“Redo日志类型”“NONETEXT”，“模块号”为“1093”，“历史Redo日志小时数”为“Hours\_1(1)”：

   ```
   GET NODEINFO: TYPE=REDOLOG, REDOTYPE=NONETEXT, MID=1093, HOURS=Hours_1-1;
   ```
6. 按小时过滤某一天的Redo日志信息，设置参数“过滤方式”为“MODULE”，“模块号”为“1093”，“过滤条件”为“aBCdef”，“历史Redo日志天数”为“Day\_2(2)”，“历史Redo日志小时数”为“Hours\_2(2)”：

   ```
   GET NODEINFO: TYPE=REDOFILTER, METHOD=MODULE, MID=1, FILTER="aBCdef", HISTORY=Day_2-1, HOURS=Hours_2-1;
   ```
7. 获取过滤Redo日志信息，设置参数过滤方式为“USER”，业务类型为“SUP-FE”，“用户号码类型”为“IMSI(SUP-FE)”，“用户号码”为“460000009123456”：

   ```
   GET NODEINFO: TYPE=REDOFILTER, METHOD=USER, AT="SUP-FE", CT="IMSI(SUP-FE)", UN="460000009123456";
   ```
8. 获取FDB信息，设置参数MID为60，FDBTYPE为NEW：

   ```
   GET NODEINFO: TYPE=FDB, MID=60, FDBTYPE=NEW;
   ```
9. 获取本地日志，设置参数MID为60：

   ```
   GET NODEINFO: TYPE=LOCALLOG, MID=60;
   ```
10. 获取校验日志，校验结果为CORRECTED：

    ```
    GET NODEINFO: TYPE=VERIFYDATA, VERIFYRESULT=CORRECTED;
    ```
11. 获取物理库日志，LOGTYPE为备份日志：

    ```
    GET NODEINFO: TYPE=DBLOG, LOGTYPE=BACKUP;
    ```
12. 获取脚本日志：

    ```
    GET NODEINFO: TYPE=SHELLSCRIPT;
    ```
13. 获取PGW Web LMT登录用户名与密码，设置参数TYPE为“GLOBALDATA”，参数MID为“30”，参数TABLE为“PGW\_OPR\_USER”：

    ```
    GET NODEINFO: TYPE=GLOBALDATA, MID=30, TABLE="PGW_OPR_USER";
    ```
14. 获取异常用户列表文件，设置参数MID为“60”：

    ```
    GET NODEINFO: TYPE=EXCUSERLISTLOG, MID=60;
    ```
15. 获取升级关键信息：

    ```
    GET NODEINFO: TYPE=UPGINFO;
    ```
16. 检查物理库账户的默认密码是否修改：

    ```
    GET NODEINFO: TYPE=DBPWDSECCHK;
    ```
17. 检查PGW admin账户的默认密码是否修改：

    ```
    GET NODEINFO: TYPE=PGWPWDSECCHK;
    ```
18. 检查PGW的安全设置是否配置：

    ```
    GET NODEINFO: TYPE=PGWSECURITYCFG;
    ```
