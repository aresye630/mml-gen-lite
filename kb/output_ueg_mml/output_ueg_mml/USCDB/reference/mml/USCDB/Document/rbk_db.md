# 回退物理数据库(RBK DB)

## 命令功能

该命令用于回退物理数据库、回退数据库软件补丁。

当升级失败或者打补丁失败时，可通过本命令将物理数据库或者数据库软件补丁回退到之前稳定运行的版本，确保数据库软件的正常运行。

## 注意事项

- 在回退时，升级系统会自动执行该命令回退物理数据库。回退数据库软件补丁时，需要参考相应的升级、补丁安装指导书进行操作。其他场景严禁执行该命令。
- 异构升级场景下，执行本命令会自动删除升级过程中生成的ClickHouse数据库相关冗余数据，如果ClickHouse关联目录（如/opt/USCDB\_APP/physical\_db）下没有文件，则默认为删除成功。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                   |
|:-----------|:-------|:-------------------------------------------------------|
| FETYPENAME | 网元类型   | 用于指定网元类型。取值范围取决于安装的网元类型。可通过在“CSP MML命令”界面执行LST ME命令查询。 |
| OLDVER     | 旧插件包版本 | 用于指定需要回退的旧插件包版本。                                       |
| NEWVER     | 新插件包版本 | 用于指定新插件包版本。                                            |

## 使用实例

当FE网元升级失败时，执行本命令进行回退物理数据库，以“SUP-FE”网元类型为例：

```
RBK DB: FETYPENAME="SUP-FE", OLDVER="V300R005C01", NEWVER="V300R005C01SPC100";
```
