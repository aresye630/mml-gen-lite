# 设置接管标记（SET TAKEOVERFLAG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

- 该命令属于高危命令，该操作在承载网故障场景下将触发业务接管，执行该命令可能导致业务呼损。因此执行该命令前，需要与华为技术支持确认后才可以实施。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于在容灾倒换场景下，为特定的业务类型设置接管标记。完成接管标记设置后，若本局与容灾局之间的承载网故障，本局将会上报“ALM-12086 系统处于手工接管状态”告警。

## 注意事项

无。

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                 |
|:-------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE  | 业务类型   | 可选必选说明：必选参数。 参数含义：用于指定具体的业务类型。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。                                                |
| TAKEOVERFLAG | 接管标记   | 可选必选说明：必选参数。 参数含义：用于设置接管标记。设置接管标记后，若本局与容灾局之间的承载网故障，本局将会上报“ALM-12086 系统处于手工接管状态”告警。 取值范围： ON(开)：设置接管标记。 OFF(关)：未设置接管标记。 默认值：无。 配置原则：无。                |
| AUTORECOVER  | 自动恢复   | 可选必选说明：条件必选参数。 参数含义：用于标识是否自动恢复手工接管状态。仅当本命令中的“接管标记”参数为“ON(开)”时该参数有效。 取值范围： YES(是)：当检测到局间数据一致时，自动结束接管状态。 NO(否)：不自动恢复接管状态，由人工结束接管状态。 默认值：NO(否)。 配置原则：无。 |
| CFM          | 确认     | 可选必选说明：条件必选参数。 参数含义：用于确认是否强制结束接管。仅当本命令中的“接管标记”参数为“OFF(关)”时该参数有效。 取值范围：YES(是)：若当前网元已设置接管标记，强制结束接管。 NO(否)：若当前网元已设置接管标记，则本次设置无效。 默认值：NO(否)。 配置原则：无。     |

## 使用实例

设置接管标记：设置“业务类型”为“SUP-FE”，“接管标记”为“ON(开)”，“自动恢复”为“YES(是)”。

```
SET TAKEOVERFLAG: SERVICETYPE="SUP-FE", TAKEOVERFLAG=ON, AUTORECOVER=YES;
```
