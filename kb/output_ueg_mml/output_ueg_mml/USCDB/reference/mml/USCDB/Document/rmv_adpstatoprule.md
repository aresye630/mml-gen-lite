# 删除适配测量操作员规则对象(RMV ADPSTATOPRULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除适配测量操作员规则记录。

## 注意事项

无。

## 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                         |
|:---------------|:---------|:-----------------------------------------------------------------------------|
| ADPSTATOBJNAME | 适配测量对象名称 | 用于标识一条适配测量操作员规则记录的关键字段之一，用于指定需要删除哪一条适配测量操作员规则记录，可以使用LST ADPSTATOPRULE命令查询获得。 |
| OPERATOR       | 操作员名称    | 用于标识一条适配测量操作员规则记录的关键字段之一，用于指定需要删除哪一条适配测量操作员规则记录，可以使用LST ADPSTATOPRULE命令查询获得。 |

## 使用实例

删除指定适配测量操作员规则记录，该“适配测量对象名称”为“TestObj”，“操作员名称”为“opr1”。

```
RMV ADPSTATOPRULE: ADPSTATOBJNAME="TestObj", OPERATOR="opr1";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释     | 原因分析                    | 处理建议                                                                                  |
|-------:|:----------|:------------------------|:--------------------------------------------------------------------------------------|
| 275016 | 指定的记录不存在。 | 系统配置中不存在指定的适配测量操作员规则记录。 | 执行LST ADPSTATOPRULE命令查询适配测量操作员规则，再重新执行RMV ADPSTATOPRULE命令，输入“适配测量对象名称”和“操作员名称”，确保其存在。 |
