# 查询用户号码归属ClusterID(DSP CLUSTERID)

- 注意事项

- 输出结果说明

## 命令功能

用于查询特定用户号码归属Cluster的具体信息。如：归属Cluster的ID和类型、Cluster内的模块和节点信息等。

该命令的使用场景：

- 开局场景，该命令可用于验证业务发放系统的对接情况、主用容灾的一致性。如：在完成与业务发放系统的对接后，操作员先通过业务发放系统新增一个测试用户，然后登录操作维护终端，通过该命令验证用户信息是否已添加。
- 维护场景。在故障定位时，有时需要获取某个用户所在节点的详细信息（如运行日志），此时可以使用**DSP CLUSTERID**来获取用户所在节点的节点ID，Pod名称的信息。

## 注意事项

无

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                         |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AT     | 业务类型   | 用于指定一个待查询用户号码归属Cluster的业务类型。此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。 取值范围：长度不超过128的字符串。                                                                                                                       |
| CT     | 用户号码类型 | 用于指定一个待查询用户号码的号码类型。该参数的取值在FE插件包中定义，通过LOD FEPLUG命令加载插件包后可由下拉框处选择。 取值范围：长度不超过128的字符串。                                                                                                                          |
| UN     | 用户号码   | 用于指定一个待查询用户号码。 取值范围：长度不超过1536的字符串。 输入原则： 如果取值中存在“'”字符，则需要输入转义字符“/q”。如果取值中存在“=”字符，则需要输入转义字符“/e”。如果取值中存在“,”字符，则需要输入转义字符“/c”。如果取值中存在“;”字符，则需要输入转义字符“/s”。如果取值中存在“\"”字符，则需要输入转义字符“/Q”。如果取值中存在“/”字符，则需要输入转义字符“//”。 |

## 使用实例

开局场景下，验证业务发放系统的对接是否成功。

1. 在业务发放系统侧新增一个用户。用户的号码为460000009123456，号码类型为IMSI，FE类型为SUP-FE。
2. 执行**DSP CLUSTERID**查询该用户信息是否已成功存储于USCDB Pod上。

   ```
   DSP CLUSTERID: AT="SUP-FE", CT="IMSI(SUP-FE)", UN="460000009123456";
   ```

   ```
   %%DSP CLUSTERID: AT="SUP-FE", CT="IMSI(SUP-FE)", UN="460000009123456";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    节点标识  Pod名称  模块号  Cluster标识  Cluster类型  是否可信  Partition标识  

    100       vUSCDB10_1  100     10           DRU          是        NULL                 
    121       vUSCDB10_2  121     12           DSU          是        NULL                 
   (结果个数 = 2)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称       | 输出项解释                                                                                                                                                                                                                            |
|:------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 节点标识        | 用于返回用户号码归属Cluster内的所有节点。 取值范围：1～32768                                                                                                                                                                                            |
| Pod名称       | 用于返回用户号码归属Cluster内的所有节点所在Pod的名称。                                                                                                                                                                                                 |
| 模块号         | 用于返回用户号码归属Cluster内的所有节点对应的模块号。 取值范围：1～4080                                                                                                                                                                                       |
| Cluster标识   | 用于返回用户号码归属Cluster的Cluster标识。 该参数应遵守如下配置原则：从“2”到“30”，从“1025”到“4078”分配给存储全局数据的DRU Cluster。从“31”到“100”，从“513”到“612”，从“1025”到“4078”分配给存储路由数据的DRU Cluster。从“101”到“512”，从“613”到“1024”，从“1025”到“4078”分配给存储用户数据的DSU Cluster。 取值范围：2～4096 |
| Cluster类型   | 用于返回用户号码归属Cluster的Cluster类型。 取值范围： DRUDSU                                                                                                                                                                                        |
| 是否可信        | 用于返回查询结果是否可信。当DRU中存在用户的路由信息，且DSU中存在该用户的用户数据时，结果可信。当DRU中存在用户的路由信息，但DSU中不存在该用户的用户数据时，结果不可信。 取值范围： 是否                                                                                                                               |
| Partition标识 | 用于返回用户号码归属的USCDB局点的Partition标识。 取值范围： 1～250NULL  说明： 本局点为非云部署组网下的USCDB局点时，本字段显示为NULL。                                                                                                                                            |

| 330015 | 用户号码类型与业务类型不匹配，请选择正确的用户号码类型。 | 输入的“用户号码”与“业务类型”不匹配，无法返回查询结果。 | 请确认并正确填写“用户号码”对应的“业务类型”，然后重新执行本命令。                                                                                           |
