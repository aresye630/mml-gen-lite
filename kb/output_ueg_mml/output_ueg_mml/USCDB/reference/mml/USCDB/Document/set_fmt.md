## 命令功能

**须知** 

执行该命令关闭格式化开关后进行数据配置，需要重启网元和CGPLite所有进程，请慎重执行。

本命令用于设置网元的格式化开关状态。

本命令的使用场景为：开局过程中利用批处理脚本运行大量MML命令时，具体步骤是：先执行**SET FMT: STS=OFF;**命令关闭格式化开关，配置完数据后，再执行**SET FMT: STS=ON;**命令打开格式化开关，将配置数据格式化到配置数据文件中，最后重启业务网元和CGPLite所有主机进程加载配置数据，具体方法如下：

- 在CSP下执行**RST MDUTYPE**，模块类型输入“PMU”，主备状态选择“ALL”，重启CGPLite所有主机进程。
- 在CSP网元下执行**RST ME**，重启对应业务网元进程。

当关闭格式化开关后，如果执行了配置命令，再次打开格式化开关时，将会自动执行**FMT**命令，并且会上报格式化进度报文；如果没有执行任何配置命令，再次打开格式化开关时，不会自动执行**FMT**命令。

有关格式化文件的概念请参见**FMT**命令的相关解释。

## 注意事项

- 除了开局，其它情况下必须让网元的格式化开关处于打开状态。
- 本命令为系统级命令，只有在需要进行大量配置操作例如开局时才使用，其它场景请在技术支持人员指导下使用该命令。
- 如果设置格式化开关为“OFF”状态，OMU将不能保证数据库与数据配置文件的一致性，请在数据操作完后及时将格式化开关修改为“ON”状态，并执行**FMT**以转换所有的配置数据，最后重启业务网元和CGPLite所有主机进程加载配置数据。
- 在格式化开关关闭时，如果执行了配置命令或者修改最大元组数命令，打开格式化开关会对当前网元和CSP网元执行格式化操作。
- 打开当前网元的格式化开关时，会同时打开CSP的格式化开关；关闭当前网元的格式化开关时，如果其他网元的格式化开关都已经关闭，则CSP的格式化开关关闭。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                           |
|:-------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| STS    | 格式化开关状态 | 用于描述格式化开关的状态。 各参数选项的含义是： “OFF(关闭格式化开关)”：表示格式化开关关闭，数据库的变化不会格式化到数据配置文件，不能保证数据库和数据配置文件的数据一致。“ON(打开格式化开关)”：表示格式化开关打开，数据库的变化会及时格式化到数据配置文件，保证数据库和数据配置文件的数据一致。 默认值：无。 |

## 使用实例

1. 设置当前网元下的格式化开关为开启状态：

   ```
   SET FMT: STS=ON;
   ```
2. 设置当前网元下的格式化开关为关闭状态：

   ```
   SET FMT: STS=OFF;
   ```
