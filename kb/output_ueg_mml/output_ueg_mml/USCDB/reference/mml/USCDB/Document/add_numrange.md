# 增加号段范围(ADD NUMRANGE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加某个城市的MSISDN或IMSI号段范围信息。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                    |
|:-----------|:---------|:--------------------------------------------------------|
| CITY       | 城市       | 用于指定需要增加号段范围信息的城市。 取值范围：长度不超过128的字符串。 默认值：无。            |
| OBJECTID   | 对象ID     | 用于标识统计对象。 取值范围：OBJECT0～OBJECT829 默认值：无。                 |
| ISDNBEGNUM | ISDN起始号码 | 用于标识参数“CITY”指定的城市的MSISDN起始号码。 取值范围：长度不超过128的字符串。 默认值：无。 |
| ISDNENDNUM | ISDN结束号码 | 用于标识参数“CITY”指定的城市的MSISDN结束号码。 取值范围：长度不超过128的字符串。 默认值：无。 |
| IMSIBEGNUM | IMSI起始号码 | 用于标识参数“CITY”指定的城市的IMSI起始号码。 取值范围：长度不超过128的字符串。 默认值：无。   |
| IMSIENDNUM | IMSI结束号码 | 用于标识参数“CITY”指定的城市的IMSI结束号码。 取值范围：长度不超过128的字符串。 默认值：无。   |

## 使用实例

增加城市“A”的号段范围信息：

```
ADD NUMRANGE: CITY="A", OBJECTID=OBJECT1, ISDNBEGNUM="0000", ISDNENDNUM="1111", IMSIBEGNUM="2222", IMSIENDNUM="3333";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                 | 原因分析                 | 处理建议                                      |
|-------:|:----------------------|:---------------------|:------------------------------------------|
| 260256 | 已经存在相同的CITY属性，不能重复添加。 | 输入的“CITY”参数在系统中已经配置。 | 执行LST NUMRANGE命令，查看指定“CITY”的号段范围信息是否已经存在。 |
| 275492 | 参数CITY取值无效。           | 参数“CITY”的取值不能只为空格。   | 请重新输入，确保输入的“CITY”符合参数的取值范围。               |
