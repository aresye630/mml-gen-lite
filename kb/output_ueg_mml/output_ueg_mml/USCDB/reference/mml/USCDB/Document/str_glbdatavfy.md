## 命令功能

**须知** 

该命令属于高危命令，该命令将触发局间全局数据校验。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令有以下使用场景：

- 在容灾局处于自动接管状态下执行，用于启动局间全局数据校验，以便将业务发放自动接管期间在容灾局修改的全局数据同步到主用局。如果配置了时间戳字段，以时间戳新的为准，时间戳不存在以主用局为准。如果没有配置时间戳字段，在容灾局执行该命令，会将主用局的全局数据校正为与容灾局的全局数据一致；在主用局执行，会将主用局比容灾局多的全局数据删除。
- 在混合组网场景下，用于启动云部署局间全局数据校验，以便将SP/RSP/vSP上的全局数据割接到新建的vRP/vRSP上。在SP/RSP/vSP上执行该命令，会将SP/RSP/vSP上全局数据校验到vRP/vRSP上；在vRP/vRSP上执行该命令，会将vRP/vRSP比指定SP/RSP/vSP/vRSP\_R多的全局数据删除。
- 在Global Local 2.0组网场景下，用于启动vSP（Local BE）与vRSP（Global BE）间的全局数据校验，以便将vSP（Local BE）上的全局数据割接到新建的vRSP（Global BE）上。

校验启动后，每10秒定期上报一次状态，直到校验完成或异常终止。

该命令支持两地容灾组网和混合组网。

## 注意事项

- 在启动校验后，如果出现如下任意一种情况，校验都将会异常终止：
  - 全局DRU的Master/Slave节点进行了倒换操作。
  - 局间校验开关关闭。
  - 升级开关打开，即将“UPGRADESTATUS（升级状态）”设置为了“1”或“2”。该种情况仅适用于“组网模式”选择为“Hybrid(混合组网)”的场景。
- “组网模式”选择为“Active-standby(主备容灾组网)”时，启动校验后，在校验没有完成之前，如果出现如下任意一种情况，校验将会异常终止，容灾局在自动接管期间修改的全局数据将丢失而导致业务呼损：
  - 执行**STP TAKEOVER**命令停止了自动接管。
  - 执行**MOD CLUSTER**命令修改容灾局的主备标识为“ACTIVE(主用)”。
  - 设置不支持业务发放自动接管功能。
- 对端全局数据DRU Master节点处于应急加载模式，执行此命令无效，请联系华为技术支持工程师进行应急加载模式下的数据恢复。
- “组网模式”选择为“Hybrid(混合组网)”时，只允许在SP/RSP/vSP、vRP/vRSP上执行，不允许在RP、vRSP\_R上执行。
  - 在SP/RSP/vSP命令执行成功的条件如下：
    - 本分区为主用局。
    - SP/RSP/vSP主用局和vRP/vRSP都是处于混合组网模式。
    - 当前不存在跨分区全局数据割接正向校验。
    - 关闭升级开关，即将“UPGRADESTATUS（升级状态）”设置为“0”。
  - 在vRP/vRSP上执行成功的条件如下：
    - 本分区为主用局。
    - SP/RSP/vSP/vRSP\_R主用局和vRP/vRSP都是处于混合组网模式。
    - 当前不存在跨分区全局数据割接反向校验。
    - 输入的参数“SP分区ID”是有效存在的SP/RSP/vSP/vRSP\_R或者不输入“SP分区ID”参数。
    - 关闭升级开关，即将“UPGRADESTATUS（升级状态）”设置为“0”。
- 在Global Local 2.0组网场景下，只有在Global主用局BE和Local主用局BE上**SET PARTITIONPARA**命令的参数“GLBDATAMIGSWITCH”取值均为“On（打开）”时，才能执行该命令。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|:------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 业务类型   | 用于指定对某个业务类型的全局数据进行校验，该参数必须先通过LOD FEPLUG命令加载FE插件，然后才能在此引用。                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| NETWORKTYPE | 组网模式   | 用于指定对某个组网模式的全局数据进行校验。 取值范围： Active-standby(主备容灾组网)Hybrid(混合组网)在混合组网和Global Local 2.0组网场景下，选择“Hybrid(混合组网)”。混合组网场景下，仅在NETWORKMODE（组网模式）软参取值为“1”时有效。Global Local 2.0组网场景下立即生效，无需受NETWORKMODE（组网模式）软参限制。 默认值：Active-standby(主备容灾组网)                                                                                                                                                                                                                                                            |
| SPPID       | SP分区ID | 仅当“组网模式”为“Hybrid(混合组网)”时该参数有效。用于指定对某个SP分区的全局数据进行校验。 取值范围：1～255 默认值：无。 说明： 在混合组网场景下：在SP/RSP/vSP上执行该命令时，该参数取值不生效。在vRP/vRSP上执行该命令时，如果该参数不输入，则由系统默认选择一个SP/RSP/vSP分区进行校验。选择策略如下：如果存在RSP，则选择RSP的主用局。如果不存在RSP，则从SP中选择一个ID最小的SP主用局。如果不存在SP，则从vSP中选择一个ID最小的vSP主用局。  说明： 混合组网改造场景下，在vRP/vRSP上执行该命令启动反向校验时，需输入有效的“SP分区ID”参数，确保混合组网改造场景下局间全局数据校验处理符合预期。 在Global Local 2.0组网场景下:在vSP（Local BE）上执行该命令时，该参数取值不生效，默认向vRSP（Global BE）校验全局数据。当在vRSP（Global BE） 执行该命令时，如果该参数不输入，则选择SP分区ID最小的vSP（Local BE）进行校验。 |

## 使用实例

对业务类型为SUP-FE的全局DRU启动局间全局数据校验功能，执行如下命令：

```
STR GLBDATAVFY: SERVICETYPE="SUP-FE";
```

```
%%STR GLBDATAVFY: SERVICETYPE="SUP-FE";%%
```
