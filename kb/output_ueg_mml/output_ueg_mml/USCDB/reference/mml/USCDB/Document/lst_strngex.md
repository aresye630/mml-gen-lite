# 查询用户数据统计对象(LST STRNGEX)

- 参数说明

## 命令功能

该命令用于查询用户数据统计对象的配置信息。

- 若需要查询全部用户数据统计对象的概要信息，请将不要输入任何参数。
- 若需要查询某条用户数据统计对象的详细信息，请输入“网元类型”或其他参数或这些参数的组合。

## 注意事项

- 在加载业务网元插件包时，系统自动增加一个对象ID为OBJECT0的统计对象，针对所有用户进行统计，对象OBJECT0只允许查询，不允许添加、删除和修改。
- 以下九种类型的统计对象允许进行查询、添加、删除和修改操作：对所有用户进行统计、按HLRSN统计、按号段统计、按RN统计、按源RN和目的RN统计、按MME主机名后缀统计、按VLRNUM前缀统计、按APN名称统计、按NPRN统计。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
|:---------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NETTYP   | 网元类型   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照网元类型来查询用户数据统计对象的配置信息；若不输入，则表示查询所有用户数据统计对象的配置信息。 取值范围：长度不超过128的字符串。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                       |
| OBJECTID | 统计对象ID | 可选必选说明：可选参数 参数含义：用于指示系统需要按照统计对象ID来查询用户数据统计对象的配置信息；若不输入，则表示查询所有用户数据统计对象的配置信息。  说明： “统计对象ID”为“OBJECT0”的对象是加载业务网元插件包时系统自动增加的统计对象，针对所有用户进行统计，对象“OBJECT0”只允许查询，不允许添加、删除和修改。 取值范围：OBJECT1～OBJECT829 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                       |
| TYPE     | 统计类型   | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪种统计类型来查询用户数据统计对象的配置信息；若不输入，则表示查询所有用户数据统计对象的配置信息。 取值范围： STAT_ALL（对所有用户进行统计）：用于统计所有用户数量。 STAT_SN（按HLRSN统计）：用于统计指定HLR序列号范围内的用户数量。STAT_NUMBER（按号段统计）：用于统计指定号段范围内的用户数量。STAT_RN（按RN统计）：用于统计指定路由码范围内的用户数量。STAT_MULTIRN（按源RN和目的RN统计）：用于统计指定源路由码和目的路由码范围内的用户数量。与按RN统计区别是：按源RN与目的RN统计包含于按RN统计，明确用户从哪个运营商转到哪个运营商。STAT_MMEHOSTPOSTFIX（按MME主机名后缀统计）：用于统计指定MME主机名后缀的用户数量。STAT_VLRNUMPREFIX（按VLRNUM前缀统计）：用于统计指定VLRNUM前缀的用户数量。STAT_APN（按APN名称统计）：用于统计指定APN的用户数量。STAT_NPRN（按NPRN统计）：用于统计指定路由码的号码可携带用户数量。 默认值：无 配置原则：无 |

## 使用实例

1. 查询所有统计任务。

   ```
   LST STRNGEX:;
   ```

   ```

   RETCODE = 0  操作成功

    统计结束号码  =  NULL
      MVNO/HLRSN  =  0
              RN  =  NULL
            源RN  =  NULL
          目的RN  =  NULL
   MME主机名后缀  =  NULL
      VLRNUM前缀  =  NULL
         APN名称  =  NULL
            NPRN  =  0
         MME类型  =  NULL

   ```

   ```
   LST STRNGEX: NETTYP="SUP-FE", OBJECTID=OBJECT1, TYPE=STAT_NUMBER;
   ```

## 输出结果说明

该命令执行正常，会返回命令操作成功的提示信息和相关参数，各参数含义请参见**ADD STRNGEX**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                       | 原因分析          | 处理建议                                                                                                             |
|-------:|:--------------------------------------------|:--------------|:-----------------------------------------------------------------------------------------------------------------|
| 250098 | 参数取值无效：参数SERVICETYPE的取值不存在，请确认已经成功加载了该FE插件。 | 参数的“网元类型”不存在。 | 请先执行LST FEPLUG命令查看FE插件包即“网元类型”。 若FE插件包加载成功，请在执行该命令时输入正确的“网元类型”名称。若“网元类型”加载不成功或者没有加载，通过LOD FEPLUG命令加载成功后，重新执行该命令。 |
| 274675 | 存在多余的参数。                                    | 输入多余的参数。      | 请重新输入参数，输入仅需要设置的参数。多余的参数是指“网元类型”、“统计对象ID”与“统计类型”之外的其他参数。                                                         |
