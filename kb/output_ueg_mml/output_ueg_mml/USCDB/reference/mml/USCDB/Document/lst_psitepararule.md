# 查询PSITE参数替换规则配置(LST PSITEPARARULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询PSITE参数替换规则的配置记录：

- 若需要查询全部PSITE参数替换规则配置的信息，请不要输入任何参数。
- 若需要查询某个PSITE参数替换规则配置的详细信息，请输入“Rule ID”或“参数名”，或者“Rule ID”和“参数名”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                           |
|:-------|:--------|:---------------------------------------------------------------------------------------------------------------|
| RULEID | Rule ID | 可选必选说明：可选参数 参数含义：唯一标识一条号段配置，用于指定需要查询哪一个Rule ID对应的PSITE参数替换规则配置，若不输入，则表示所有的Rule ID。 取值范围：1～65535 默认值：无。 配置原则：无。 |
| NAME   | 参数名     | 可选必选说明：可选参数 参数含义：用于指定需要查询哪一个参数名对应的PSITE参数替换规则配置，若不输入，则表示所有的参数名。 取值范围：1～32位的由数字和大写字母组成的字符串。 默认值：无。 配置原则：无。      |

## 使用实例

1. 查询所有PSITE参数替换规则配置。

   ```
   LST PSITEPARARULE:;
   ```

   ```
   %%LST PSITEPARARULE:;%%
   RETCODE = 0 操作成功

   操作结果如下
   ------------------------
    Rule ID  参数名    新参数名  参数值  新参数值  描述信息

    11       USCSN     NULL      29      30        NULL       
    12       USCSN     NULL      29      33        NULL       
   (结果个数 = 2) 

   ---    END
   ```
2. 查询PSITE参数替换规则配置，“Rule ID”为“11”。

   ```
   LST PSITEPARARULE: RULEID=11;
   ```

   ```
   %%LST PSITEPARARULE: RULEID=11;%%
   RETCODE = 0 操作成功

   操作结果如下
   ------------------------
          Rule ID  =  11
           参数名  =  USCSN
         新参数名  =  NULL
           参数值  =  29
         新参数值  =  30
         描述信息  =  NULL
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD PSITEPARARULE**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                         | 原因分析                                 | 处理建议                                      |
|-------:|:------------------------------|:-------------------------------------|:------------------------------------------|
| 275480 | 参数NAME只能由数字(0～9)、大写字母(A～Z)组成。 | 输入的“参数名”中包含了除数字(0～9)、大写字母(A～Z)以外的字符。 | 请确保输入的“参数名”只包含数字(0～9)和大写字母(A～Z)后，重新执行该命令。 |
