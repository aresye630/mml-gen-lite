# 删除远端DSG链路中心(RMV RDSGLINKCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除远端DSG或DBS链路中心。

## 注意事项

无。

## 参数说明

| 参数标识            | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                        |
|:----------------|:-------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RLOCID          | 远端Location标识 | 用于指定一个远端网元标识。该参数须在对接的远端USCDB网元或者FE网元中先定义，然后在本端网元通过ADD RLOCATION命令配置后，才能在此处索引。远端Location是相对的，具体如下：对于主用局FE，它的远端Location指主用局USCDB或容灾局USCDB。对于主用局USCDB，它的远端Location指主用局FE、容灾局FE或容灾局USCDB。对于容灾局FE，它的远端Location指容灾局USCDB或主用局USCDB。对于容灾局USCDB，它的远端Location指容灾局FE、主用局FE或主用局USCDB。 取值范围：1～512 默认值：无。 |
| RDSGST          | 远端DSG业务类型    | 用于指定维护链路的远端网元类型名称。该参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。 取值范围：长度不超过128的字符串。 默认值：无。                                                                                                                                                                                                         |
| RLINKCENTERTYPE | 远端链路中心类型     | 用于指定远端FE Location链路中心类型。 取值范围： DSG：表示大颗粒DSG链路中心。DBS：表示dbbroker微服务链路中心。 默认值：DSG                                                                                                                                                                                                              |

## 使用实例

删除远端DSG链路中心，“远端Location标识”为“77”，“远端DSG业务类型”为“SUP-FE”，“远端链路中心类型”为“DSG”。命令示例如下：

```
RMV RDSGLINKCTRL: RLOCID=77, RDSGST="SUP-FE", RLINKCENTERTYPE=DSG;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                     | 原因分析                                  | 处理建议                                                                                                                                 |
|-------:|:------------------------------------------|:--------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------|
| 275129 | 参数取值无效：参数RDSGST所示的插件包不存在，请确认已经成功加载了该FE插件。 | 输入的“远端DSG业务类型”在系统中不存在。                | 通过执行LST FEPLUG命令查询加载的“FE类型”，“FE类型”即“远端DSG业务类型”。 若“FE类型”加载成功，请在执行该命令时输入正确的“远端DSG业务类型”。若“FE类型”加载不成功或者没有加载，通过LOD FEPLUG命令加载成功后，重新执行该命令。 |
| 302550 | 远端配置不存在。                                  | 指定“远端Location标识”和“远端DSG业务类型”对应的配置不存在。 | 执行LST RDSGLINKCTRL命令查询远端DSG或DBS链路中心配置，请重新输入已经配置的“远端Location标识”和“远端DSG业务类型”。                                                          |
