# 查询备份列表(DSP BKPLIST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询USCDB物理数据库备份镜像文件及其时间戳信息。

## 注意事项

- 在执行此命令前NDF模块必须已配置。
- 当“备份数据保存方式”为“FTPSERVER(保存到FTP服务器)”或“SFTPSERVER(保存到SFTP服务器)”（可通过**LST BACKUP**命令进行查询）时，执行**DSP BKPLIST**命令会连接到FTP/SFTP服务器查询备份列表。如果频繁执行本命令进行查询，当上一次命令还没有收到响应，再次执行该命令会因为阻塞引起命令超时，导致操作失败。

## 参数说明

无。

## 使用实例

查询数据库备份列表。

```
DSP BKPLIST:;
```

```
%%DSP BKPLIST:;%%
RETCODE = 0  操作成功

操作结果如下
------------
 数据库标识  备份列表标识    时间戳信息                 操作结果  操作结果描述
 数据库      数据库备份列表  2009-09-19 04:03:37        成功      操作成功。  
 数据库      数据库备份列表  2009-09-20 22:36:18        成功      操作成功。  
(结果个数 = 2)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称   | 输出项解释                                                                                                                                                     |
|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
| 数据库标识   | 用来标识一个物理数据库。 取值说明：目前此值固定为“数据库”。                                                                                                                           |
| 备份列表标识  | 用来标识物理数据库列表。 取值说明：目前此值固定为“数据库备份列表”。                                                                                                                       |
| 时间戳信息   | 用于描述备份镜像开始的时间。                                                                                                                                            |
| 操作结果    | 用于描述物理数据库备份的状态信息。 取值范围： 成功。失败。                                                                                                                            |
| 操作结果描述  | 用于描述查询操作的执行结果。 取值范围： 操作成功。操作失败：NDF模块状态异常，请检查NDF模块状态。如果NDF状态正常，请联系华为技术支持处理。操作超时：重新执行该命令。如果重试多次不成功，请联系华为技术支持处理。连接服务器失败：请检查物理数据库虚拟机（裸机Pod）与服务器之间的网络连接状态是否正常。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释               | 原因分析                                                            | 处理建议                                                                                                    |
|-------:|:--------------------|:----------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------|
| 330001 | 在当前系统中，未找到运行该命令的模块。 | 在执行此命令前NDF模块未添加。                                                | 通过执行命令ADD MODULE添加NDF模块，再重新执行该命令。                                                                       |
| 275118 | 连接服务器失败。            | “服务器IP地址”，“服务器用户名”，或“服务器密码”配置不正确。 物理数据库虚拟机（裸机Pod）与服务器之间网络连接不正常。 | 请检查“服务器IP地址”是否可用，“服务器用户名”和“服务器密码”配置是否正确。如果不正确请执行MOD BACKUP命令修改为正确值。请检查物理数据库虚拟机（裸机Pod）与服务器之间的网络连接状态是否正常。 |
