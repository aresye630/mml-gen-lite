# 查询虚拟远端Location信息(LST VRLOCATION)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询虚拟远端Location信息。为用户对远端网元设备进行操作提供支持。

- 若需要查询全部远端网元设备的虚拟远端Location信息记录的概要信息，请不要输入任何参数。
- 若需要查询某条远端网元设备的虚拟远端Location信息记录的详细信息，请输入“虚拟远端Location标识”。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称           | 参数说明                                                                                                             |
|:--------|:---------------|:-----------------------------------------------------------------------------------------------------------------|
| VRLOCID | 虚拟远端Location标识 | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个虚拟远端Location标识查询虚拟远端Location位置信息；若不输入，则表示所有的虚拟远端Location位置信息。 取值范围：1～512 默认值：无 配置原则：无 |

## 使用实例

1. 查询全部远端网元设备的虚拟远端Location信息记录的概要信息：

   ```
   LST VRLOCATION:;
   ```

   ```
   %%LST VRLOCATION:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   虚拟远端Location标识     远端Partition标识     远端Location标识
   100                      20                    81                           
   101                      20                    82                          
   (结果个数 = 2)

   ---    END
   ```
2. 查询“虚拟远端Location标识”为“100”的远端网元设备的虚拟Location信息记录的详细信息：

   ```
   LST VRLOCATION: VRLOCID=100;
   ```

   ```
   %%LST VRLOCATION: VRLOCID=100;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   虚拟远端Location标识  =  100
      远端Partition标识  =  20
       远端Location标识  =  81
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD VRLOCATION**命令的参数说明。
