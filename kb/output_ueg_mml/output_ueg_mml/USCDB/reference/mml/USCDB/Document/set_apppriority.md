# 设置应用优先级(SET APPPRIORITY)

- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，该操作修改特定用户LDAP请求消息的优先级，可能影响消息处理成功率。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置当USCDB作为LDAP服务器对接的多个第三方FE应用的优先级，USCDB启动流控，优先级越高消息处理的成功率越高。

## 注意事项

- 该命令只适用于对其他厂商提供的通过CAG模块接入的第三方FE进行优先级设置。
- 第三方FE的优先级不能设置都相同，否则表示不使用优先级进行控制。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                              |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USERNAME | 用户名    | 其值域类型为字符串，用于描述第三方FE应用使用的用户名。 取值范围：长度不超过128的字符串。 默认值：无。                                                                                                                                                                                            |
| PRIORITY | 优先级    | 用于定义第三方FE应用的优先级。优先级越高，消息处理的成功率越高。 各参数选项的含义是： LOW(低)：表示该应用的优先级为低，当USCDB启动流控时，该应用的消息处理成功率低。MEDIUM(中)：表示该应用的优先级为中等，当USCDB启动流控时，该应用的消息处理成功率中等。HIGH(高)：表示该应用的优先级为高，当USCDB启动流控时，该应用的消息处理成功率高。HIGHEST(最高)：表示该应用的优先级为最高，当USCDB启动流控时，该应用的消息处理成功率最高。 默认值：无。 |

## 使用实例

设置应用优先级，“用户名”为“user\_low”，“优先级”为“LOW（低）”:

```
SET APPPRIORITY: USERNAME="user_low", PRIORITY=LOW;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释      | 原因分析        | 处理建议                                           |
|-------:|:-----------|:------------|:-----------------------------------------------|
| 260060 | 要修改的对象不存在。 | 输入的“用户名”错误。 | 通过执行LST LDAPUSER命令查询“用户名”，输入正确的“用户名”后，重新执行该命令。 |
