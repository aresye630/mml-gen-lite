# 发送CRC校验失败的数据(SND CRCERR)

## 命令功能

**须知** 

执行该命令发送大量不一致数据会花费较长时间，且会导致CPU产生一定的波动，如在话务高峰期需谨慎执行，请务必在华为技术支持人员的指导下操作。

本命令用于请求系统将OMU数据库中登记的CRC校验错误的表或记录联机设定到主机。

本命令的使用场景为：用户手工执行**STR CRC**、**CHK DATA**或系统每天定时执行CRC校验后，如果出现CRC校验错误，系统将登记这些校验错误的表或记录。用户在确认OMU数据库的数据正确后，可以使用本命令来联机设定这些表或记录，使主机与OMU数据库的数据保持一致。

## 注意事项

本命令使用不当可能会造成业务中断，请详细阅读以下注意事项，并联系华为技术支持协助操作。

- 脱机配置数据和恢复数据库的场景，严禁使用本命令来发送不一致数据。
- 本命令执行不当会导致业务中断，执行前请联系华为技术支持确认数据正确性和表数据的依赖关系。
- 本命令仅适用于发送少量数据不一致的场景。
- 若OMU数据库中表数据为空，将提示该数据可能非法，需要确认数据的正确性，避免主机数据被全部删除。请联系华为技术支持确认数据正确后，再选择强制发送空表。
- 若该命令返回报文提示“存在数据大小超过最大值的表，不能对整个表执行数据设定”，可执行**CHK DATA**命令，将表的校验错误定位到记录级，再执行本命令联机设定不一致的记录。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                       |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------|
| MN     | 模块号    | 标识要发送CRC校验失败数据的模块，用于指定需要对哪一模块的CRC校验失败数据进行发送，操作员可以通过LST CRCERR命令查询获得。若不输入，则发送所有模块的CRC校验失败数据。 取值范围：0～4294967294 默认值：无。       |
| TID    | 表号     | 标识要发送CRC校验失败数据的表，用于指定需要对哪一张表的CRC校验失败数据进行发送，操作员可以通过LST CRCERR命令查询获得。若不输入，则发送所有表的CRC校验失败数据。 取值范围：下拉列表中给出的所有表。 默认值：无。 配置原则：无。 |
| FS     | 强制发送空表 | 标识发送CRC校验失败数据是否强制发送空表。 各参数选项的含义： “NO(否)”：表示不强制发送空表，主机数据不会被删除。“YES(是)”：表示强制发送空表，主机数据会被删除。 默认值：“NO(否)”。                      |

## 使用实例

发送CRC校验错误的数据：

```
SND CRCERR:;
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，请联系华为技术支持处理。
