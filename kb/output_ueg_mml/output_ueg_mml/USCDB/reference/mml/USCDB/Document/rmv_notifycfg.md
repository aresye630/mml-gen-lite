# 删除PGW订阅通知配置(RMV NOTIFYCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，删除正在使用的订阅通知配置，会造成对端设备接收不到订阅通知。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除业务发放订阅通知的订阅配置信息，使对端FE接收不到订阅通知。PGW修改全局数据或用户数据后，FE不能针对数据变更作出必要处理。

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识     | 参数名称      | 参数说明                                                                         |
|:---------|:----------|:-----------------------------------------------------------------------------|
| FETYPE   | 订阅通知的FE类型 | 用于标识一条业务发放订阅通知数据记录的关键字段之一，用于指定需要删除哪一条业务发放订阅通知数据记录，操作员可通过LST NOTIFYCFG命令查询获得。 |
| REMOTEID | 订阅通知对端的ID | 用于标识一条业务发放订阅通知数据记录的关键字段之一，用于指定需要删除哪一条业务发放订阅通知数据记录，操作员可通过LST NOTIFYCFG命令查询获得。 |
| FEID     | FE标识      | 用于标识一条业务发放订阅通知数据记录的关键字段之一，用于指定需要删除哪一条业务发放订阅通知数据记录，操作员可通过LST NOTIFYCFG命令查询获得。 |

## 使用实例

删除“SUP-FE”类型的FE订阅通知配置信息。假如配置“订阅通知的FE类型”为“SUP-FE”，“订阅通知对端的ID”为“1”，“FE标识”为“5”：

```
RMV NOTIFYCFG: FETYPE="SUP-FE", REMOTEID=1, FEID=5;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                  | 原因分析                                                      | 处理建议                                                                                              |
|-------:|:---------------------------------------|:----------------------------------------------------------|:--------------------------------------------------------------------------------------------------|
| 275016 | 指定的记录不存在。                              | 要删除的“订阅通知的FE类型”、“订阅通知对端的ID”和“FE标识”对应的业务发放订阅通知配置记录在系统中不存在。 | 执行LST NOTIFYCFG命令查询系统中已存在的订阅通知配置记录，输入要删除的“订阅通知的FE类型”、“订阅通知对端的ID”和“FE标识”对应的业务发放订阅通知配置记录，然后重新执行本命令。 |
| 275020 | 参数取值无效：参数FETYPE的取值不存在，请确认已经成功加载了该FE插件。 | 输入的“订阅通知的FE类型”在系统中不存在。                                    | 执行LST NOTIFYCFG命令查询系统中已存在的订阅通知配置记录，输入查询结果中存在的“订阅通知的FE类型”，重新执行本命令。                                 |
