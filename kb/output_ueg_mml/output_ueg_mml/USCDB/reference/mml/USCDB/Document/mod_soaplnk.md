# 修改SOAP链路(MOD SOAPLNK)

## 命令功能

**须知** 

该命令属于高危命令，如果SOAP链路参数配置不合理，将导致对端设备接收不到订阅通知。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改SOAP链路配置，包括服务器端IP地址，服务器端口，客户端IP地址等。

## 注意事项

1. 只有当MSGQUEUELEN和MSGSENDRATE参数都不为0时，才能控制SOAP消息的发送速率。
2. 业务触发的订阅通知的速率大于MSGSENDRATE时，消息队列会缓存订阅通知消息直至超时。建议MSGQUEUELEN值应大于业务触发的订阅通知速率乘以ADD SUBSCRIBER中配置的超时时间。
3. MSGSENDRATE或MSGQUEUELEN设置较小时，消息队列容易被堆满，此时将不接收新的订阅通知消息，影响业务。
4. 该命令不允许进行批操作。

## 参数说明

| 参数标识           | 参数名称       | 参数说明                                                                                                                   |
|:---------------|:-----------|:-----------------------------------------------------------------------------------------------------------------------|
| LNKID          | 链路ID       | 用于标识一条SOAP链路数据记录的关键字段之一，用于指定需要修改哪一条SOAP链路，操作员可以使用LST SOAPLNK命令查询获得。                                                    |
| IPVER          | IP类型       | 用于表示IP地址类型。 取值范围： IPV4：当系统要求使用IPv4类型的IP地址时选择此选项。IPV6：当系统要求使用IPv6类型的IP地址时选择此选项。 默认值：无。                                  |
| SIPV4          | 服务器端IPV4地址 | 仅当本命令中的“IP类型”参数选择为“IPV4”时该参数有效，用于标识SOAP链路服务器端的IPv4地址。 取值范围：符合IPv4格式要求。 默认值：无。                                          |
| SIPV6          | 服务器端IPV6地址 | 仅当本命令中的“IP类型”参数选择为“IPV6”时该参数有效，用于标识SOAP链路服务器端的IPv6地址。 取值范围：符合IPv6格式要求。 默认值：无。                                          |
| SPORT          | 服务器端端口     | 用于指定SOAP链路服务器端的端口号。 取值范围：1～65534                                                                                       |
| CIPV4          | 客户端IPV4地址  | 仅当本命令中的“IP类型”参数选择为“IPV4”时该参数有效，用于标识SOAP链路客户端的IPv4地址。该IP地址必须为ADD SRVIPADDR命令添加的IPv4地址。 取值范围：符合IPv4格式要求。 默认值：无。          |
| CIPV6          | 客户端IPV6地址  | 仅当本命令中的“IP类型”参数选择为“IPV6”时该参数有效，用于标识SOAP链路客户端的IPv6地址。该IP地址必须为ADD SRVIPADDR命令添加的IPv6地址。 取值范围：符合IPv6格式要求。 默认值：无。          |
| URL            | URL        | 用于标识SOAP服务器URL。 取值范围：长度不超过255的字符串。 配置原则：该参数不能配置绝对路径的URL，只能输入域名之后的URL片段。 说明：当操作人员在输入URL前多输入一个空格时，系统默认该参数与未输入空格的URL地址一样。 |
| LNKDESC        | 链路描述       | 用于标识SOAP链路的描述信息。 取值范围：长度不超过32的字符串。                                                                                     |
| MSGQUEUELEN    | 消息队列长度     | 用于标识SOAP链路的消息队列长度。 取值范围：0～100000                                                                                       |
| MSGSENDRATE    | 消息发送速率     | 用于控制SOAP链路在单个PGW中的消息发送速率。当有多个PGW模块时，网元的最大的SOAP消息发送速率为PGW个数乘以消息发送速率。 取值范围：0～1000 单位：条/秒                                 |
| REQUESTTIMEOUT | 请求超时时间     | 用于控制SOAP链路连接超时时间，在设定时间内连接上没有任何消息，则PGW将关闭此连接。 取值范围：20～245 单位：秒。                                                         |

## 使用实例

1. 修改一条SOAP链路的服务器端IP地址，指定“链路ID”为“1”，修改“服务器端IPV4地址”为“192.168.2.119”。

   ```
   MOD SOAPLNK: LNKID=1, SIPV4="192.168.2.119";
   ```
2. 修改一条SOAP链路的URL，设置“链路ID”为“1”，“URL”为“/cxf/api/v1/updatelocationasync?wsdl”。

   ```
   MOD SOAPLNK: LNKID=1, URL="/cxf/api/v1/updatelocationasync?wsdl";
   ```

| 274632 | 链路不存在。                           | 只能修改已经存在的链路。                   | 先执行LST SOAPLNK命令查询已经添加的“链路ID”，再重新执行本命令，确保要修改的“链路ID”在查询结果中。       |
