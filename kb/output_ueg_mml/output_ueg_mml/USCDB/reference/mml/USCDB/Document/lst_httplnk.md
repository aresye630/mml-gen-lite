# 查询HTTP链路（LST HTTPLNK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询HTTP链路信息。

**说明** 

当操作员通过**ADD HTTPLNK**或**MOD HTTPLNK**命令添加或修改服务端URL地址时，如果输入URL前携带空格时，通过该命令查询的URL地址信息也会携带空格。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                         |
|:-------|:-------|:-------------------------------------------------------------|
| LNKID  | 链路ID   | 用于指示系统按照哪个链路ID查询HTTP链路信息；若不输入，则表示所有的链路ID。 取值范围：1～50。 默认值：无   |
| LKSID  | 链路集ID  | 用于指示系统按照哪个链路集ID查询HTTP链路信息；若不输入，则表示所有的链路集ID。 取值范围：1～50。 默认值：无 |

## 使用实例

1. 查询指定HTTP链路的配置，该“链路ID”为“1”。

   ```
   LST HTTPLNK: LNKID=1;
   ```

   ```

   ```
