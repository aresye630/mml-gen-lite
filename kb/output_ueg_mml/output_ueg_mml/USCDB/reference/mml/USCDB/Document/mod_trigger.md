# 修改触发器(MOD TRIGGER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，修改触发器会造成对端设备接收不到订阅通知。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改触发器配置，包括输出内容，触发器状态等。

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识          | 参数名称     | 参数说明                                                               |
|:--------------|:---------|:-------------------------------------------------------------------|
| SUBID         | 订阅ID     | 用于标识一条数据订阅配置记录。此参数在USCDB网元下唯一，由ADD SUBSCRIPTION命令添加而来。 取值范围：1～1024 |
| TRIGGERTPLID  | 触发器模板ID  | 用于标识一条触发器模板记录。此参数在USCDB网元下唯一，由ADD TRIGGERTPL命令添加而来。 取值范围：1～100     |
| OUTPUT        | 输出内容     | 用于标识一条触发器的输出内容，内容来源于FE插件包所配置的发布数据，多个属性使用“&”分割。 取值范围：长度不超过1023的字符串。 |
| TRIGGERSTATUS | 触发器状态    | 用于标识一条触发器状态。 取值范围：Active(激活)：表示触发器可用。Inactive(未激活)：表示触发器不可用。       |
| SAVNOTIFYLOG  | 记录订阅通知日志 | 用于标识记录订阅通知日志。 取值范围：YES(是)NO(否) 默认值：无                               |

## 使用实例

修改一条触发器记录，指定“订阅ID”为“1”，“触发器模板ID”为“1”，修改“输出内容”为“IMEI”,“触发器状态”为“Inactive”，“记录订阅通知日志”为“YES”。

```
MOD TRIGGER: SUBID=1, TRIGGERTPLID=1, OUTPUT="IMEI", TRIGGERSTATUS=Inactive, SAVNOTIFYLOG=YES;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                | 原因分析                                             | 处理建议                                                           |
|-------:|:---------------------|:-------------------------------------------------|:---------------------------------------------------------------|
| 259213 | 参数OUTPUT格式不对。        | “输出内容”格式不对。                                      | “输出内容”支持的配置的格式为：[ATTR]&[ATTR]。重新输入“输出内容”，确保其格式正确。              |
| 260008 | 参数未修改。请至少指定一个待修改的参数。 | 指定“订阅ID”和“触发器模板ID”记录的“输出内容”和“触发器状态”和修改前的一致，未作修改。 | 先执行LST TRIGGER命令查询已经添加的触发器模记录，在重新输入“输出内容”和“触发器状态”，确保其中至少一项不重复。 |
| 275016 | 指定的记录不存在。            | 触发器模板中不存在指定“订阅ID”和“触发器模板ID”的记录。                  | 先执行LST TRIGGER命令查询所有触发器，再重新执行本命令，确保要修改的“订阅ID”和“触发器模板ID”在查询结果中。 |
