# 查询承载网质量(LST IPQOS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询各FE和BE（含容灾系统）之间的承载网质量指标，用于评估FE网元和BE网元之间的承载网质量状况。

**说明** 

当**SET DSGSCTPPARA**命令中“旁路ping结果”参数设置为“TRUE（是）”时，执行该命令查询结果为空，网管侧“DSG承载网质量测量”测量单元下所有指标值均为零。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称              | 参数说明                                                                                                                                                         |
|:--------|:------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| METYPE  | 远端网元类型            | 用于指示系统查询本端网元和哪个远端网元之间的承载网质量指标。 当本参数为“USCDB”时，表示查询的是USCDB主用局和容灾局之间的承载网质量指标。除USCDB之外的其他网元类型需要通过LOD FEPLUG命令加载FE插件后在此引用，可通过LST FEPLUG命令查询获取。 取值范围：长度不超过128的字符串。 |
| DSGMID  | DSG模块号            | 用于指示系统按照本端网元的哪个DSG模块号来查询本端网元和对应的远端网元之间的承载网质量指标；若不输入，则表示查询本端网元所有DSG模块号与远端网元之间的承载网质量指标。 取值范围：1～4080 默认值：无。                                                     |
| RLID    | 远端Location标识      | 用于指示系统查询本端网元和哪个远端Location标识对应的远端网元之间的承载网质量指标。 取值范围：1～512 默认值：无。                                                                                              |
| RDSGMID | 远端DSG模块号/DBS服务模块号 | 用于指示系统查询本端网元和远端网元哪个DSG模块号/DBS服务模块号之间的承载网质量指标；若不输入，则表示查询本端网元和远端所有DSG模块号/DBS服务模块号之间的承载网质量指标。 取值范围：1～4080 默认值：无。                                                |

## 使用实例

查询本端网元和“远端Location标识”为“22”、“远端网元类型”为“SUP-FE”之间的承载网质量。

```
LST IPQOS: METYPE="SUP-FE", RLID=22;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1的参数说明。

| 输出项名称             | 输出项解释                                             |
|:------------------|:--------------------------------------------------|
| 远端网元类型            | 远端网元类型表示与本端网元对应的远端网元类型。                           |
| DSG模块号            | DSG模块号表示本端网元的DSG模块号。                              |
| 远端Location标识      | 远端Location标识表示远端网元所在的Location标识。                  |
| 远端DSG模块号/DBS服务模块号 | 远端DSG模块号/DBS服务模块号表示远端网元的DSG模块号或DBS服务模块号。          |
| 本地Location IP地址   | 本地Location IP地址表示本端网元的IP地址。                       |
| 远端Location IP地址   | 远端Location IP地址表示远端网元的IP地址。                       |
| 平均时延              | 平均时延表示本端网元和远端网元之间的承载网的网络时延。 平均时延越小，表示网络越稳定。 单位：毫秒 |
| 最大时延              | 最大时延表示本端网元和远端网元之间的承载网的网络最大时延。 单位：毫秒               |
| 最小时延              | 最小时延表示本端网元和远端网元之间的承载网的网络最小时延。 单位：毫秒               |
| 丢包率(%)            | 丢包率表示本端网元和远端网元之间的承载网的网络数据丢包率。 丢包率越低，表示网络越稳定。 单位：% |
| 周期                | 周期表示系统对本端网元和远端网元之间的承载网质量指标进行统计的周期时间。固定为5分钟。 单位：分钟 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释                              | 原因分析                                            | 处理建议                                                                                                                                                        |
|-------:|:-----------------------------------|:------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 260140 | 指定的DSG模块不存在。                       | 输入的本端“DSG模块号”参数在系统中不存在。                         | 执行LST MODULE命令查询本端网元已配置的“模块类型”为“DSG(DSG)”的“模块号”，然后再执行本命令查询FE和BE之间的承载网质量情况。                                                                                  |
| 260096 | 该远端location不存在。                    | 输入的“远端Location标识”参数在系统中不存在。                     | 执行LST RLOCATION命令查询已经配置的远端location，然后再执行本命令查询FE和BE之间的承载网质量情况。                                                                                               |
| 260191 | DSG模块对应的业务类型与参数metype不匹配。          | 本地网元与指定的远端网元不是通过查询条件中的“DSG模块”进行连接。              | 执行LST MODULE命令查询“模块类型”为“DSG(DSG)”所对应的远端应用类型（即“业务类型”），输入与远端网元相对应的本端“DSG模块号”，然后重新执行本命令。                                                                       |
| 385008 | 远端location标识指定的远端DSG模块/DBS服务模块不存在。 | 输入的“远端Location标识”对应的“远端DSG模块号/DBS服务模块号”在系统中不存在。 | 执行LST RDSG命令，不输入任何参数，查询出已配置的远端DSG模块号（即“远端DSG类型”为“DSG”的“远端DSG模块号”），和远端DBS服务模块号（即“远端DSG类型”为“DBS”的“远端DSG模块号”），并确认对应的“远端Location标识”，然后重新执行本命令查询FE和BE之间的承载网质量情况。 |
