## 命令功能

**须知** 

该命令属于高危命令，该操作增加模块可能导致系统内存不足而引发Pod或虚拟机重启。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于为USCDB网元下的Pod添加模块。

该命令的使用场景：在开局或扩容场景下，需要对新增加Pod添加对应的模块。

## 注意事项

- 增加模块（除NDF模块）前，必须保证FE插件包已正常加载，否则将导致后续的操作将无法正常进行。加载FE插件包请参考**LOD FEPLUG**命令。
- 增加DRU或DSU模块后，需要在30分钟内执行**ADD NODE**命令，否则会导致OMU侧节点数据与主机侧数据不一致。
- 增加DPU模块后，请执行**ADD SRVIPADDR**命令增加IP地址。如果增加的DPU模块未配置IP地址，在CSP网元执行**DSP MODULE**命令查询模块主备状态时会显示“未配置”。
- 增加PGW模块后，请执行**ADD SRVIPADDR**命令增加网关类型为PGW的IP地址。
- 如果软参LDAPSWITCH的值为1，DSG模块也需执行**ADD SRVIPADDR**命令增加网关类型为DSG的IP地址才能激活。
- PGW模块支持单配模式，即只有一个Pod的情况下，PGW模块仍然能以主备工作方式提供服务，此时备Pod名应配置为32个F。
- 一个网元下只能添加一个备Pod为32个F的PGW模块，且一旦配置了该模块，则不能再指定主备Pod添加主备PGW模块。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                            |
|:------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MID         | 模块号     | 用于定义一个待增加模块的模块编号。 该参数的配置原则： 同一Pod中模块的编号奇偶属性必须一致。 对于DRU、DSU，同一Cluster内不同Node对应的模块须部署在不同的Pod。 取值范围：1～4080 默认值：无。 说明：DRU/DSU模块号取值范围为1025～4078。DMA模块号取值范围为1027～4080。DSG模块号取值范围为1～2047。其他类型模块号的取值范围是1～1024。                                                                                          |
| MT          | 模块类型    | 用于定义待增加模块的模块类型。USCDB网元下的模块类型有DPU、NDF、DSG、DBG、DRU、DSU、PGW、CAG。 取值范围：DPU(DPU)NDF(NDF)DSG(DSG)DBG(DBG)DRU(DRU)DSU(DSU)PGW(PGW)DMA(DMA)CAG(CAG) 默认值：无。 说明： 新增加的模块类型是DRU、DSU时，系统自动增加DMA模块。 新增加1个DRU模块，系统自动增加1个DMA模块，DMA模块号为DRU模块号加2。新增加1个DSU模块，系统自动增加1个DMA模块，DMA模块号为DSU模块号加2。                        |
| SERVICETYPE | 业务类型    | 用于定义待增加模块的业务类型，仅当本命令中的“模块类型”参数为“DSG”、“DPU”时，该参数有效。该参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。 该参数的配置原则：待增加模块类型为DSG时，业务类型设置为对应的插件包类型。待增加模块类型为DPU模块时，需要根据DPU所在Pod判断对应的业务类型：Pod中只有PGW\CAG模块时，业务类型设置为USCDB。Pod中只有DSG模块时，业务类型设置为对应的插件包类型。若Pod中存在以上多种模块时，需要为各类模块添加对应业务类型的DPU模块。 取值范围：长度不超过128的字符串。 默认值：无。 |
| VMNAME1     | 主用Pod名称 | 用于定义待增加模块所属主用Pod的名称。 该参数的配置原则： 主用进程所在的Pod名称和备用进程所在的Pod名称不能完全相同。 取值范围：长度不超过128的字符串。 默认值：无。 说明：增加DRU/DSU模块时，系统自动增加的DMA模块与DRU/DSU模块在同一个主用Pod上，Pod名称相同。                                                                                                                                             |
| VMNAME2     | 备用Pod名称 | 用于定义待增加模块所属备用Pod的名称。 当该局点为单机部署时，需要配置PGW模块的该参数应配置为32个F。 该参数的配置原则： 主用进程所在的Pod名称和备用进程所在的Pod名称不能完全相同。 取值范围：长度不超过128的字符串。 默认值：无。                                                                                                                                                                     |
| MNAME       | 模块名称    | 用于定义待增加模块的模块名称。 该参数的配置原则： 为便于识别，模块名称应包含模块类型和相应的模块编号。如：模块号为5的DPU模块建议命名为DPU5。 取值范围：长度不超过32的字符串。 默认值：无。                                                                                                                                                                                            |

## 使用实例

1. 为USCDB的USPID3 Pod添加NDF模块，此时需要进行如下配置。
   1. 根据图1中的参数索引关系，确认准备条件是否完成。

      1. 登录“USCDB MML命令” 界面，通过**LST PODINFO**命令查询是否已添加模块所属Pod。
   2. 由于USPID3 Pod下的NDF模块为主备的工作方式，因此执行如下命令，添加NDF模块。待增加模块的其它参数配置信息如下：模块号为161，模块类型为NDF，模块名称为NDF161。

      ```
      ADD MODULE: MID=161, MT=NDF, VMNAME1="USPID3_1", VMNAME2="USPID3_2", MNAME="NDF161";
      ```
