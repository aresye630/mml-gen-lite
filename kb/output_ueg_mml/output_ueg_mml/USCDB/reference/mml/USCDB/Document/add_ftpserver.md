# 添加FTP服务器(ADD FTPSERVER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，“FTP”协议是不安全的协议，建议使用安全的“SFTP”协议。如果使用“FTP”协议会存在安全隐患。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于添加本端FTP服务器。添加之后，USCDB作为本端FTP服务器用于与FTP客户端进行文件传输。

## 注意事项

- 同一种“IP类型”，每种“服务类型”只能添加一条本端FTP服务器。
- 使用FTP传输协议方式时，传输数据时不加密，安全性低，系统会上报“ALM-10031 系统存在不安全的配置”告警。使用SFTP传输协议方式时，会对传输数据进行加密，安全性较高。明文方式传输的“FTP”协议存在安全隐患，对安全要求高的用户建议使用“SFTP”协议。
- 当新添加FTP服务器时，如果软参“SSHSFTPSRVSEPARATION”的取值为“1”（执行**LST INSP**命令查看软参“SSHSFTPSRVSEPARATION”的取值是否为“1”。），则此时“服务器端口”参数取值不能为“20022”，否则会添加失败，并返回错误码275435。

## 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                                                                                                                              |
|:-----------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVERTYPE | 服务类型      | 用于指定本端FTP服务器的类型。 取值范围： PROV(业务)：表示该FTP为营帐相关功能提供服务，且FTP服务由网关类型为PGW的DPU提供。DATAMTN(维护)：表示该FTP为数据维护（数据导出、数据备份）相关功能提供服务，且FTP服务由网关类型为DMA的DPU提供。 默认值：无。                                                  |
| IPVER      | IP类型      | 用于表示IP地址类型。 取值范围：IPV4：当系统要求使用IPv4类型的IP地址时选择此选项。IPV6：当系统要求使用IPv6类型的IP地址时选择此选项。 默认值：无。                                                                                                              |
| SERVERIPV4 | 服务器IPV4地址 | 仅当本命令中的“IP类型”参数选择为“IPV4”时该参数有效，用于指定本端FTP服务器提供服务的IPv4地址。 取值范围：符合IPv4格式要求。 默认值：无。 说明： 当“服务器类型”为“PROV(业务)”时，该IPv4地址必须为网关类型为PGW的DPU模块的IPv4地址。当“服务器类型”为“DATAMTN(维护)”时，该IPv4地址必须为网关类型为DMA的DPU模块的IPv4地址。 |
| SERVERIPV6 | 服务器IPV6地址 | 仅当本命令中的“IP类型”参数选择为“IPV6”时该参数有效，用于指定本端FTP服务器提供服务的IPv6地址。 取值范围：符合IPv6格式要求。 默认值：无。 说明： 当“服务器类型”为“PROV(业务)”时，该IPv6地址必须为网关类型为PGW的DPU模块的IPv6地址。当“服务器类型”为“DATAMTN(维护)”时，该IPv6地址必须为网关类型为DMA的DPU模块的IPv6地址。 |
| SERVERPORT | 服务器端口     | 用于指定本端FTP服务器提供服务的端口号。 取值范围：1～65535 默认值：无。                                                                                                                                                         |

## 使用实例

某局点需要添加本端FTP服务器配置:

- “服务类型”：“PROV”
- “IP类型”：“IPV4”
- “服务器IPV4地址”：“10.94.1.131”
- “服务器端口”：“5555”

```
ADD FTPSERVER: SERVERTYPE=PROV, IPVER=IPV4, SERVERIPV4="10.94.1.131", SERVERPORT=5555;
```
