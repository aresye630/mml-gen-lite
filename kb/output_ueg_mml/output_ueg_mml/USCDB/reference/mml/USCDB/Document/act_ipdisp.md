# 激活IP链路(ACT IPDISP)

## 命令功能

**须知** 

该命令属于高危命令，该操作将激活IP配置信息。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于请求系统激活IP配置，使本端DSG和远端DSG模块进行网络连接。在USCDB和对端网元对接配置时，需要通过此命令激活IP链路，使USCDB网元与对端网元进行通信。

## 注意事项

- 为确保用户能够正确使用此命令，在执行此命令前需要先依次执行以下三个命令进行USCDB配置对接：
  1. 通过**ADD RLOCATION**命令增加远端Location标识。
  2. 通过**ADD RDSG**命令增加远端DSG模块。
  3. 通过**ADD RIPADDR**命令增加远端IP地址。
- 执行**ACT IPDISP**命令要求如下：
  - 只能在开局初始配置或者扩缩容时执行，其他情况下可能会导致FE访问BE的业务失败。
  - 在一端执行了激活IP链路命令并且“模式”选择为“LOCAL(本地)”或者不填时，本端的DSG可能会重新分配本端IP与对端的IP，造成FE与BE（或者BE与BE）之间的DSG链路中断。故执行此命令必须要在一端执行完后立刻在另外一端执行，否则会造成业务呼损甚至中断。
  - 先在BE执行（对于容灾组网的局点，Location小的BE先执行，Location大的BE后执行），然后在FE执行。
  - 如果本端和远端的链路配置未发生变化，则不会触发链路重建，不会造成业务呼损。
- 该命令不允许进行批操作。
- 当本端同时配置了远端的DSG或DBS配置和IP配置，并且命令参数“模式”为“ALL(所有)”时，报文才会返回对端的操作结果。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                         |
|:--------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ACTMODE | 模式     | 可选必选说明：可选参数 参数含义：本参数用于设置远端局点激活链路的模式。 取值范围： LOCAL(本地)：手工执行命令激活链路。ALL(所有)：将选择链路正常且模块号最小的DSG模块通知远端局点激活链路配置。 说明： 参数“ALL(所有)”只能在扩缩容场景下进行选择。 默认值：LOCAL(本地) 配置原则：无。 |

## 使用实例

1. 某局点需要激活IP链路，其配置方式如下：
   1. 执行**ADD RLOCATION**命令增加远端Location标识。
   2. 执行**ADD RDSG**命令增加远端DSG模块。
   3. 执行**ADD RIPADDR**命令增加远端IP地址。
   4. 执行**ACT IPDISP**命令激活IP配置。

      ```
      ACT IPDISP:;
      ```
2. 某局点已完成扩缩容需要激活IP链路，并且配置“模式”为“ALL(所有)”：
   1. 执行**SND DSGLINKCFG**命令发送本端DSG配置和IP配置。
   2. 执行本命令激活IP配置，并且配置“模式”为“ALL(所有)”。

      ```
      ACT IPDISP: ACTMODE=ALL;
      ```

      ```
      %%ACT IPDISP: ACTMODE=ALL;%%
      RETCODE = 0 操作成功
       
      操作结果如下
      ----------------------
      远端Location标识 业务类型 操作结果
      20               SUP-FE   操作成功
      (结果个数 = 1)

      --- END
      ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。各输出项含义请参见表1的参数说明。

| 输出项名称        | 输出项解释                                                                                                                                                                                                                                                                                                    |
|:-------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 远端Location标识 | 用于返回本端DSG所对接的远端Location标识。                                                                                                                                                                                                                                                                               |
| 业务类型         | 用于返回当前DSG的业务类型。                                                                                                                                                                                                                                                                                          |
| 操作结果         | 用于返回发送DSG链路通知的操作结果。 操作成功操作失败操作超时对端版本不支持本功能链路故障 说明： 需要对该命令返回报文内容进行判断，报文操作结果字段有如下情况： 操作成功 => 链路激活完成。操作失败 => 重试当前操作，若仍不成功请联系华为技术支持。操作超时 => 重试当前操作，若仍不成功请联系华为技术支持。对端版本不支持本功能 => 请在本端网元和对端网元手动执行激活IP链路命令，并且配置命令参数“模式”为“LOCAL(本地)”。链路故障 => 请联系华为技术支持。当命令参数“模式”不填或者为“LOCAL(本地)”时，如果返回报文中有“没有查到相应结果”字段，该内容不需要关注。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释               | 原因分析                                  | 处理建议                                          |
|-------:|:--------------------|:--------------------------------------|:----------------------------------------------|
| 483018 | 参数ACTMODE的值不在指定范围内。 | 参数“模式”的值不是“LOCAL(本地)”或“ALL(所有)”。      | 检查参数“模式”填写的值是否为“LOCAL(本地)”或者“ALL(所有)”并重新执行命令。 |
|   2648 | 部分操作失败。             | 存在部分DSG模块故障没有执行成功。存在部分业务类型的DSG模块全部故障。 | 重试当前操作，若仍不成功请联系华为技术支持。                        |
|   2649 | DSG模块状态异常。          | 所有DSG模块全部故障。                          | 请联系华为技术支持。                                    |
| 385001 | DSG模块没有配置。          | 没有配置DSG模块。                            | 通过ADD MODULE命令增加DSG模块的配置后，再重新执行此命令。           |
