# 查询PSITE参数过滤规则配置(LST PSITECMDRULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询PSITE参数过滤规则的配置记录：

- 若需要查询全部PSITE参数过滤规则配置的信息，请不要输入任何参数。
- 若需要查询某个PSITE参数过滤规则配置的详细信息，请输入“Site ID”或“命令名称”，或者“Site ID”和“命令名称”。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                                                       |
|:--------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| SITEID  | Site ID | 可选必选说明：必选参数 参数含义：唯一标识一个远端业务发放站点，用于指定需要查询哪一个Site ID对应的PSITE参数过滤规则配置，若不输入，则表示所有的Site ID。 取值范围：1～1024 默认值：无。 配置原则：无。                                          |
| CMDNAME | 命令名称    | 可选必选说明：必选参数 参数含义：用于指定需要查询哪一个命令名称对应的PSITE参数过滤规则配置，若不输入，则表示所有的命令名称。 取值范围：长度为1~32个字符的字符串，字符串只能由数字（0～9）、大写英文字母（A～Z）、空格和下划线组成，必须以字母开头且末尾字符不能为空格。 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询所有PSITE参数过滤规则配置。

   ```
   LST PSITECMDRULE:;
   ```

   ```
   %%LST PSITECMDRULE:;%%
   RETCODE = 0 操作成功

   操作结果如下
   ------------------------
    Site ID  命令名称                    参数类型     命令参数      

    5        ADD ALLTYPE_SUB1_INFO5_TPL  Whitelist    USCSN&SUB1_INFO5_TPL_ID
    5        ADD ALLTYPE_SUB1_INFO6_TPL  Blacklist    STR128_1               
   (结果个数 = 2)

   ---    END
   ```
2. 查询PSITE参数过滤规则配置，“命令名称”为“ADD ALLTYPE\_SUB1\_INFO5\_TPL”。

   ```
   LST PSITECMDRULE: CMDNAME="ADD ALLTYPE_SUB1_INFO5_TPL";
   ```

   ```
   %%LST PSITECMDRULE: CMDNAME="ADD ALLTYPE_SUB1_INFO5_TPL";%%
   RETCODE = 0 操作成功

   操作结果如下
   ------------------------
             Site ID  =  5
            命令名称  =  ADD ALLTYPE_SUB1_INFO5_TPL
            参数类型  =  Whitelist
            命令参数  =  USCSN&SUB1_INFO5_TPL_ID
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD PSITECMDRULE**命令的参数说明。
