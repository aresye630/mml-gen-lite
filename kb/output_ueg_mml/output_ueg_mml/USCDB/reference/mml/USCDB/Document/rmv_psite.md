# 删除远端营帐配置(RMV PSITE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，该操作将删除远端业务发放站点配置，操作不当将造成业务中断。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在配置数据库中删除一条远端营账站点配置数据记录。

该命令的使用场景：

- 开局场景：开局根据网设规划配置PSITE时，用于删除错误配置。
- 网络改造场景：根据客户组网规划，需要调整部分远端业务发放站点配置。

## 注意事项

- 该命令不允许进行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                |
|:-------|:--------|:--------------------------------------------------------------------|
| SITEID | Site ID | 标识一条远端业务发放站点数据记录的关键字段，用于指定需要删除哪一条远端业务发放站点数据，操作员可以使用LST PSITE命令查询获得。 |

## 使用实例

删除“Site ID”为“1”的远端业务发放站点数据：

```
RMV PSITE: SITEID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                 | 原因分析                        | 处理建议                                                                                                                         |
|-------:|:--------------------------------------|:----------------------------|:-----------------------------------------------------------------------------------------------------------------------------|
| 256034 | 记录不存在。                                | 只能删除已经存在的记录。                | 先执行LST PSITE命令查看当前已存在的记录，然后在已存在的记录上执行本命令进行删除。                                                                                |
| 275326 | SITEID正在使用，请执行RMV PSITERULE命令删除配置。    | 远端业务发放站点管理记录被远端业务发放站点规则使用。  | 请参照如下步骤执行： 执行LST PSITERULE命令查询出使用该“Site ID”的远端业务发放站点规则记录。执行RMV PSITERULE命令删除该远端业务发放站点规则记录。重新执行本命令删除远端业务发放站点管理记录。             |
| 275490 | SITEID正在使用，请执行RMV PSITECMDRULE命令删除配置。 | 远端业务发放站点管理记录被PSITE参数过滤规则使用。 | 请参照如下步骤执行： 执行LST PSITECMDRULE命令查询出使用该“Site ID”的PSITE参数过滤规则配置记录。执行RMV PSITECMDRULE命令删除该PSITE参数过滤规则配置记录。重新执行该命令删除远端业务发放站点配置记录。 |
