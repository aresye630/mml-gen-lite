# 修改系统的运行模式(MOD SYSRM)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，该操作将修改系统服务状态，操作不当将导致整局业务中断。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改系统的运行模式，系统运行模式用于指示系统是否可以提供数据服务。

该命令的使用场景：

- 在故障场景下，当主用局或容灾局业务异常时，经过人工评估，由于内存库数据异常或者其他异常情况导致系统的数据服务异常，USCDB网元不对外提供数据服务时，通过该命令修改为去激活模式停止数据服务，需要整体退服时，使用该命令将当前局点退出服务。
- 在恢复场景下，当USCDB网元故障修复后，通过该命令修改为激活模式恢复数据服务。

## 注意事项

- 当“业务类型”选定时，该命令只对此业务类型所属的模块生效，不影响公共的CAG模块的LDAP端口和PGW的公共业务发放端口的使用。
- 当“业务类型”没有选定时，该命令对所有的业务类型生效，同时影响公共的CAG模块的LDAP端口和PGW的公共业务发放端口的使用。
- 使用该命令修改运行模式时，配套的设置去激活模式与设置激活模式中的“业务类型”必须保持一致。如果在执行该命令进行去激活时，没有选定“业务类型”，则在进行激活时，也不能选定“业务类型”。如由于数据服务异常将HSS9860修改为去激活模式，当USCDB网元故障修复后，将HSS9860修改为激活模式。
- 通过该命令修改运行模式后，无需重启立即生效。
- 该命令不允许进行批处理操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。
- 单局点不能执行该命令，否则会导致整局业务完全中断，触发网络事故。
- 执行该命令时，要确保对应的容灾局点可以正常接管业务。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                    |
|:------------|:-------|:------------------------------------------------------------------------|
| SERVICETYPE | 业务类型   | 用于指定具体的业务类型。 取值范围：长度不超过128的字符串。 默认值：无。                                  |
| FS          | 系统运行状态 | 用于指定系统的运行模式。 各参数选项的含义是：ACTIVE：激活模式，表示可提供数据服务。DEACTIVE：去激活模式，表示不可提供数据服务。 |

## 使用实例

1. 某局点故障已修复，设置“系统运行状态”为“ACTIVE”恢复数据服务：

   ```
   MOD SYSRM: FS=ACTIVE;
   ```

   ```
   MOD SYSRM: FS=DEACTIVE;
   ```

   该局点故障修复后，不选定“业务类型”，设置“系统运行状态”为“ACTIVE”恢复数据服务：

   ```
   MOD SYSRM: FS=ACTIVE;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|-------:|:--------------------------------------------|:-------------------|:-------------------------------------------------------------------------------------------------------------------------|
| 250098 | 参数取值无效：参数SERVICETYPE的取值不存在，请确认已经成功加载了该FE插件。 | 输入的“业务类型”不存在。      | 通过LST FEPLUG命令查询加载的“FE类型名称”，“FE类型名称”即“业务类型”。 若业务类型加载成功，请在执行该命令时输入正确的业务类型名称。若业务类型加载不成功或者没有加载，通过LOD FEPLUG命令加载成功后，重新执行该命令。 |
| 260405 | 当前局点未配置容灾局，不允许去激活。                          | 当前局点未配置容灾局，不允许去激活。 | 请确保在有配置容灾局的局点执行本命令。 局点是否配置容灾局，可通过执行LST RLOCATION命令查看。如果存在“远端网元类型”为“USCDB”且“是否容灾关系”为“是”的记录，则有配置容灾局，否则未配置。                 |
