# 查询触发器(LST TRIGGER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询触发器信息。

- 若需要查询全部触发器的概要信息，请不要输入任何参数。
- 若需要查询某个触发器的详细信息，请输入“订阅ID”、“触发器模板ID”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称     | 参数说明                                                 |
|:--------------|:---------|:-----------------------------------------------------|
| SUBID         | 订阅ID     | 用于标识一条数据订阅配置记录；若不输入，则表示查询所有的订阅ID。                    |
| TRIGGERTPLID  | 触发器模板ID  | 用于标识一条触发器模板记录；若不输入，则表示查询所有的触发器模板ID。                  |
| OUTPUT        | 输出内容     | 用于标识一条触发器的输出内容，内容来源于FE插件包所配置的发布数据；若不输入，则表示查询所有的输出内容。 |
| TRIGGERSTATUS | 触发器状态    | 用于标识一条触发器的状态；若不输入，则表示查询所有的触发器状态。                     |
| SAVNOTIFYLOG  | 记录订阅通知日志 | 用于标识记录订阅通知日志。 取值范围：YES(是)NO(否) 默认值：无                 |

## 使用实例

1. 查询指定触发器记录，该“订阅ID”为“1”，“触发器模板ID”为“1”，“记录订阅通知日志”为“YES”。

   ```
   LST TRIGGER: SUBID=1, TRIGGERTPLID=1, SAVNOTIFYLOG=YES;
   ```

   ```
   %%LST TRIGGER: SUBID=1, TRIGGERTPLID=1, SAVNOTIFYLOG=YES;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
         订阅ID  =  1
   触发器模板ID  =  1
       输出内容  =  IMSI
     触发器状态  =  Active
    记录订阅通知日志 = YES
   (结果个数 = 1)

   ---    END
   ```
2. 查询触发器的所有记录。

   ```
   LST TRIGGER:;
   ```

   ```
   %%LST TRIGGER:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    订阅ID  触发器模板ID  输出内容  触发器状态        记录订阅通知日志
    1       1             IMSI      Active          YES 1       2             MSISDN    Active          YES(结果个数 = 2)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数详见**ADD TRIGGER**命令的参数说明。
