# 查询资源监控配置信息(LST MONITOR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询资源监控配置信息。资源监控配置信息包括系统配置参数、监控配置信息标识、平台资源监控开关、监控资源列表。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询平台资源监控列表配置信息。

```
LST MONITOR:;
```

```
%%LST MONITOR:;%%
RETCODE = 0  操作成功

操作结果如下
------------
    系统配置参数  =  系统参数
监控配置信息标识  =  0
平台资源监控开关  =  开
    监控资源列表  =  磁阵的状态
                  =  数据库状态
                  =  集群服务状态
                  =  主备机信任主机关系
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1的参数说明。

| 输出项名称    | 输出项解释                                                   |
|:---------|:--------------------------------------------------------|
| 系统配置参数   | 用于返回在配置数据库中定义的系统配置参数。当前取值固定为“系统参数”，该值不能被修改。             |
| 监控配置信息标识 | 用于返回在配置数据库中定义平台资源监控配置信息的标识，当前该值取值固定为“0”，不能被修改。          |
| 平台资源监控开关 | 用于返回平台资源监控开关的设置情况，通过这个参数控制是否进行平台资源监控。 取值说明： 关开          |
| 监控资源列表   | 用于返回当前平台已配置哪些资源监控项。平台资源监控项包括： 磁阵的状态数据库状态集群服务状态主备机信任主机关系 |
