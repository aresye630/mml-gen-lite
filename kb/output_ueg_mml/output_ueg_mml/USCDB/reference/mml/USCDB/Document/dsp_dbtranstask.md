# 显示数据库转换任务（DSP DBTRANSTASK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

在物理数据库从PT数据库升级到ClickHouse数据库时，该命令用于查询PT数据库中的数据转换到ClickHouse数据库中的进度。

## 注意事项

无。

## 参数说明

无。

## 使用实例

某局点需要查询物理数据库中的数据转换进度：

```
DSP DBTRANSTASK:;
```

返回结果如下：

```
%%DSP DBTRANSTASK:;%% 
RETCODE = 0  操作成功  

操作结果如下
------------------------  
       Pod名称  =  USCDB_PID3_0    
          状态  =  Normal
          进度  =  Running       
    转换表数量  =  138
成功转换表数量  =  130
      启动时间  =  2021-12-10 09:18:18
      结束时间  =  null
  预计剩余时间  =  8h9min
(结果个数 = 1) 

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1的输出结果解释。

| 输出项名称   | 输出结果解释                                                                                             |
|:--------|:---------------------------------------------------------------------------------------------------|
| Pod名称   | 用于返回当前物理库所在的POD名称。                                                                                 |
| 状态      | 用于返回数据库当前的数据转换状态： Normal：运行正常Abnormal：异常停止Stop By Rollback：因回退停止Stop By Install：因建库停止              |
| 进度      | 用于返回数据库当前的数据转换进度： No Start：物理库转换任务未开始Running：正在执行数据转换Merging：正在执行数据合并Loading：正在执行远端加载Completed：已完成 |
| 转换表数量   | 用于返回数据库总共的转换表数量。                                                                                   |
| 成功转换数量  | 用于返回数据库当前已经转换的表数量。                                                                                 |
| 启动时间    | 用于返回数据转换启动时间。                                                                                      |
| 结束时间    | 用于返回数据转换结束时间。                                                                                      |
| 预计剩余时间  | 用于返回数据转换预计剩余时间。                                                                                    |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释               | 原因分析                                                                              | 处理建议                             |
|------:|:--------------------|:----------------------------------------------------------------------------------|:---------------------------------|
|  2704 | 物理数据库状态异常。          | 物理数据库状态异常。                                                                        | 物理数据库状态异常，请联系华为技术支持。             |
|  1712 | 在当前系统中，未找到运行该命令的模块。 | NDF模块具有物理数据库管理功能和平台资源监控功能，USCDB需要先添加该模块，然后才能执行本命令查询PT数据库中的数据转换到ClickHouse数据库中的进度。 | 执行ADD MODULE命令增加NDF模块，然后重新执行本命令。 |
|  2741 | 当前无数据转换任务。          | 仅支持异构升级的数据转换进度查询，其他场景无数据转换任务，不支持执行该命令。                                            | 请在异构升级时执行该命令查询数据转换进度。            |
