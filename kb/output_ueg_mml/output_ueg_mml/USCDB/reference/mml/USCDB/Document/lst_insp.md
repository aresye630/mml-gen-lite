# 查询软件参数的配置信息(LST INSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于查询软件参数的配置信息：

- 若需要查询全部软件参数数据记录的概要信息，请不要输入任何参数。
- 若需要查询某条软件参数数据记录的详细信息，请输入“软件参数类型”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                |
|:----------|:--------|:----------------------------------------------------|
| INSPT     | 软件参数类型  | 用于指示系统需要按照哪个软件参数类型来查询软件参数的配置信息；若不输入，则表示所有的软件参数类型。   |
| INSPN     | 软件参数名称  | 用于指示系统需要按照哪个软件参数名称来查询软件参数的配置信息；若不输入，则表示所有的软件参数名称。   |
| INSPV     | 软件参数值   | 用于指示系统需要按照哪个软件参数值来查询软件参数的配置信息；若不输入，则表示所有的软件参数值。     |
| INSPVD    | 软件参数默认值 | 用于指示系统需要按照哪个软件参数默认值来查询软件参数的配置信息；若不输入，则表示所有的软件参数默认值。 |
| INSPVFLAG | 软件参数值标识 | 用于指示系统需要按照哪个软件参数值标识来查询软件参数的配置信息；若不输入，则表示所有的软件参数值标识。 |
| FETYPEN   | 网元类型    | 用于指示系统需要按照哪个网元类型来查询软件参数的配置信息；若不输入，则表示所有的网元类型。       |

## 使用实例

1. 查询某类软件参数配置信息。“软件参数类型”为“PCDR（性能管理）”。

   ```
   LST INSP: INSPT=PCDR;
   ```

   ```
   %%LST INSP: INSPT=PCDR;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    系统配置参数  软件参数类型  软件参数名称                                  软件参数值  软件参数默认值  软件参数值标识  网元类型

    系统参数      性能管理      话统清除时间                                  1025        1025            否              USCDB   
    系统参数      性能管理      缓冲区剩余空间比例                            2590        2590            否              USCDB   
    系统参数      性能管理      CPU过载阈值                                   95          95              否              USCDB
    系统参数      性能管理      话统滑窗大小                                  8           8               否              USCDB   
    (结果个数 = 4)

   ---    END
   ```
2. 查询某条软件参数配置信息。“软件参数类型”为“FE（前端）”，“软件参数名称”为“LDRSOURCE（加载数据源，热配置）”，“软件参数值”为“0”，“软件参数值标识”为“FALSE（否）”，“网元类型”为“SUP-FE”：

   ```
   LST INSP: INSPT=FE, INSPN=LDRSOURCE, INSPV=0, INSPVFLAG=FALSE, FETYPEN="SUP-FE";
   ```

   ```
   %%LST INSP: INSPT=FE, INSPN=LDRSOURCE, INSPV=0, INSPVFLAG=FALSE, FETYPEN="SUP-FE";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
     系统配置参数  =  系统参数
     软件参数类型  =  前端
     软件参数名称  =  加载数据源，热配置
       软件参数值  =  0
   软件参数默认值  =  0
   软件参数值标识  =  否
         网元类型  =  SUP-FE
   (结果个数 = 1)

   ---    END
   ```
