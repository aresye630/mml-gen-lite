# 查询异构模型映射关系（LST SCHEMAMAP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询异构模型映射关系表中已配置为黑名单的KV型DCI消息转HETER型DCI消息映射关系记录。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询全部已配置的异构模型映射关系记录。

```
LST SCHEMAMAP:;
```

```
%%LST SCHEMAMAP:;%%
RETCODE = 0  操作成功

操作结果如下
------------
FE类型      操作类型      关系模型表ID  KV模型节点ID
GU-HLR      BLACKLIST     100           101
SUP-FE      BLACKLIST     100           101
(结果个数 = 2)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD SCHEMAMAP**命令的参数说明。
