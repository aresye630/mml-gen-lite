# 删除ADD服务器配置(RMV ADDCONFIG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，删除ADD服务器配置会造成用户数据无法通过短消息或者USSD消息更新到用户终端。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除ADD服务器的相关配置信息，关于ADD业务请参考自动设备检查配置管理的功能描述。

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                  |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------|
| IPVER    | IP类型   | 标识一条ADD服务器配置的数据记录的关键字段之一，用于指定需要删除哪一种IP地址类型对应的ADD服务器配置数据记录 ，操作员可以使用LST ADDCONFIG命令查询获得。                                |
| IPV4ADDR | IPV4地址 | 仅当本命令中的“IP类型”参数选择为“IPV4”时该参数有效。标识一条ADD服务器配置的数据记录的关键字段之一，用于指定需要删除哪一个IPv4地址对应的ADD服务器配置数据记录 ，操作员可以使用LST ADDCONFIG命令查询获得。 |
| IPV6ADDR | IPV6地址 | 仅当本命令中的“IP类型”参数选择为“IPV6”时该参数有效。标识一条ADD服务器配置的数据记录的关键字段之一，用于指定需要删除哪一个IPv6地址对应的ADD服务器配置数据记录 ，操作员可以使用LST ADDCONFIG命令查询获得。 |

## 使用实例

删除ADD服务器配置信息，ADD服务器“IP类型”为“IPV4”，“IPV4地址”为“10.85.165.185”：

```
RMV ADDCONFIG: IPVER=IPV4, IPV4ADDR="10.85.165.185";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释    | 原因分析                      | 处理建议                                                                               |
|-------:|:---------|:--------------------------|:-----------------------------------------------------------------------------------|
| 275033 | IP地址不存在。 | 要删除的“IPV4地址”或“IPV6地址”不存在。 | 通过LST ADDCONFIG命令查看当前添加的ADD服务器的“IPV4地址”或“IPV6地址”，输入查询到的“IPV4地址”或“IPV6地址”后，重新执行该命令。 |
