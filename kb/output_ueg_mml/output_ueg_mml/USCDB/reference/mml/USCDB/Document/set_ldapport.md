# 设置LDAP端口号(SET LDAPPORT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令在25.1.0版本不支持。

该命令属于高危命令，该操作将修改LDAP服务端口，操作不当将导致第三方FE业务访问中断。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置USCDB网元下的LDAP服务器端口号。

当第三方FE需要访问BE数据库时，需要使用本命令对LDAP服务端端口号进行配置。在该命令中，关键参数“端口号”需要与对端网元协商一致。

- LDAP服务端：提供LDAP接口的USCDB网元（BE）。
- LDAP客户端：通过LDAP接口访问USCDB的业务网元（FE）。

该命令的使用场景：

- 开局或对接联调场景：设置LDAP服务端口，以便第三方FE访问数据。
- 网络改造场景：调整LDAP服务端口，该操作需要和对端网元协同实施。

## 注意事项

- 在缺省的情况下，系统在初始化的时候已经预置了“LDAPPORT”端口类型对应的“端口号”的值。需要指出的是，本命令中所描述的初始设置值是在未改变初始值的情况下执行**LST LDAPPORT**命令查询得到的值。系统默认配置参数如下：

  ```
  端口类型     端口号

   LDAPPORT     389
  ```
- 该命令不允许进行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                |
|:---------|:-------|:------------------------------------------------------------------------------------|
| PORTTYPE | 端口类型   | 用于指定LDAP服务器的端口类型，目前固定取值为“LDAPPORT”，指端口类型为普通端口，表示FE与BE之间通过TCP进行连接。 默认值：无。            |
| PORTNUM  | 端口号    | USCDB网元与第三方FE对接的参数之一，用于指定LDAP服务器（BE）的端口号；若不一致，第三方FE将无法正常访问BE数据库。 取值范围：1～4048 默认值：无。 |

## 使用实例

设置第三方FE访问BE数据库的LDAP服务器“端口号”为“2”，执行如下命令：

```
SET LDAPPORT: PORTTYPE=LDAPPORT, PORTNUM=2;
```
