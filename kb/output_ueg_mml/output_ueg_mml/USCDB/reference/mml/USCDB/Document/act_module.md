# 激活模块(ACT MODULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于激活DSG模块。

该命令的使用场景：在升级场景，需要对升级Pod进行激活。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                   |
|:-------|:-------|:-----------------------------------------------------------------------|
| MID    | 模块号    | 标识一条模块配置信息的关键字段，用于指定待激活的模块，该参数可以使用LST MODULE命令查询获得。 取值范围：1～2047 默认值：无。 |

## 使用实例

在升级场景下，激活4号模块。

```
ACT MODULE: MID=4;
```

```
%%ACT MODULE: MID=4;%%
RETCODE = 0  操作成功

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释        | 原因分析                                                       | 处理建议                                                                           |
|-------:|:-------------|:-----------------------------------------------------------|:-------------------------------------------------------------------------------|
| 260140 | 指定的DSG模块不存在。 | 以下两种情况会产生此错误码。 输入的“模块号”在系统中未添加。输入的“模块号”在系统中已添加，但模块类型不是DSG。 | 通过LST MODULE命令查询DSG的模块号。 若系统中不存在DSG模块，则无需处理。若系统中存在DSG模块，输入查询到的DSG模块号后，重新执行该命令。 |
