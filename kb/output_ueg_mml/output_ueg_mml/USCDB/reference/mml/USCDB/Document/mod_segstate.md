# 修改隔离状态(MOD SEGSTATE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，该操作将隔离业务处理模块，操作不当将导致负载不均、业务损失等严重问题。因此执行该命令前，需要与华为技术支持确认后才可以实施。

本命令用于配置是否对业务进程（DRU或DSU）进行隔离。

本命令的相关介绍：

- 当系统需要缩容时，使用该命令隔离需要调整的DRU/DSU进程。如果某个DRU/DSU进程被隔离，则后续的业务将会被转发到其他DRU/DSU进程进行处理。
- 在网元扩容场景下，当希望新扩容的业务模块暂时不处理业务时，可执行本命令将业务模块设置为隔离状态。
- 本命令只在扩容缩容和处理异常模块时需要主动隔离业务的场景下使用。

## 注意事项

- 执行本命令隔离特定的DRU/DSU模块后，后续DSG模块将不再向该DRU/DSU模块转发消息，系统总处理能力下降。如果系统剩余DRU/DSU模块已经满负荷运转，不能接管这部分隔离的DRU/DSU模块的业务量，则会产生业务损失。
- 执行本命令进行隔离和解隔离操作后，操作可以通过执行**LST SEGSTATE**命令确认模块的隔离状态。
- 紧急排除故障的情况下执行本命令，需要华为技术工程师对操作方案进行评估，评估通过后方可实施。
- 当模块的“隔离类型”为“FAULTSEG(故障隔离)”时，如果需要将该模块的“隔离状态”修改为“FALSE(非隔离)”，则当前模块必须是同一Cluster内最后被隔离模块。可以通过执行**LST SEGSTATE**命令查询该Cluster中所有节点的隔离启动时间。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                            |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------|
| SEGTYPE  | 隔离类型   | 用于指定隔离类型。 取值范围： MIGRATESEG(迁移隔离)：在扩容缩容业务模块时，设置为迁移隔离状态。FAULTSEG(故障隔离)：在处理异常业务模块时，设置为故障隔离状态。 默认值：MIGRATESEG(迁移隔离) |
| MID      | 模块号    | 用于指定隔离的业务模块号。操作员可以使用LST MODULE命令查询获得。业务进程的模块类型只允许为DRU或DSU。 取值范围：1～4080 默认值：无。                                   |
| SEGSTATE | 隔离状态   | 用于指定业务模块的隔离状态。 取值范围：FALSE(非隔离)：对处于隔离状态的业务进程设置为非隔离状态。TRUE(隔离)：对处于非隔离状态的业务进程设置为隔离状态。 默认值：无。                       |

## 使用实例

1. 需要通过设置模块的隔离状态，使模块不对外提供服务。例如：“模块号”为“1033”的模块需要被隔离。运行以下命令，将该模块的“隔离状态”修改为“TRUE(隔离)”。
   - “隔离类型”为“FAULTSEG(故障隔离)”
   - “模块号”为“1033”
   - “隔离状态”为“TRUE(隔离)”

   ```
   MOD SEGSTATE: SEGTYPE=FAULTSEG, MID=1033, SEGSTATE=TRUE;
   ```
2. 由于局点话务量长期降低，为有效利用资源，经过讨论、评估，最终确认需要对局点业务模块进行缩容。携带参数如下：
   - “隔离类型”为“MIGRATESEG(迁移隔离)”
   - “模块号”为“1085”
   - “隔离状态”为“TRUE(隔离)”

   ```
   MOD SEGSTATE: SEGTYPE=MIGRATESEG, MID=1085, SEGSTATE=TRUE;
   ```
