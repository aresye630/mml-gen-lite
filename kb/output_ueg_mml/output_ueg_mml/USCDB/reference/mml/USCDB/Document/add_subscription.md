# 增加订阅配置信息(ADD SUBSCRIPTION)

## 命令功能

该命令用于增加对某数据集的订阅配置信息，该订阅配置用于数据层订阅通知，使FE/第三方设备能获取到所订阅的数据变更。

FE网元将可供订阅的数据定义为一个数据集，包含在对应的插件包中。当需要订阅该数据集时，在通过**LOD FEPLUG**命令加载了该FE插件包之后，才能使用本命令增加对应数据订阅的配置信息。

该命令的参数索引关系如图1所示。

**图1** 命令参数的索引关系图

## 注意事项

- 只有被发布出来的数据集才允许通过本组命令订阅。
- 每个被加载到USCDB中的FE都可以发布自己的数据集供其他FE/第三方设备订阅。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                         |
|:-----------|:-------|:---------------------------------------------------------------------------------------------|
| SUBID      | 订阅ID   | 用于表示增加的数据订阅配置的标识。此参数在USCDB网元下唯一。 取值范围：1～1024 默认值：无。                                          |
| SUBFETYPE  | 订阅者类型  | 用于表示订阅者FE网元的业务类型，通过LOD FEPLUG命令加载FE插件后在此引用。其中参数值“USCDB”是系统安装时自动生成。 取值范围：长度不超过128的字符串。 默认值：无。 |
| SUBDATA    | 订阅的数据  | 用于表示被订阅的数据集，该参数通过LOD FEPLUG命令加载包含有订阅数据集配置的FE插件包后在此引用。 取值范围：长度不超过64的字符串 默认值：无。                |
| SUBERGRPID | 订阅组ID  | 用于指定要订阅数据配置的订阅组ID，该参数通过ADD SUBSCRIBERGRP添加后在此引用。 取值范围：1～255 默认值：无。                           |

## 使用实例

增加一条数据订阅配置：设置“订阅ID”为“1”，“订阅者类型”为“SUP-FE”，“订阅的数据”为“SUP-FE\_GROUP\_1”，“订阅组ID”为“1”。

```
ADD SUBSCRIPTION: SUBID=1, SUBFETYPE="SUP-FE", SUBDATA="SUP-FE_GROUP_1", SUBERGRPID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释             | 原因分析                                        | 处理建议                                                                                                                       |
|-------:|:------------------|:--------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------|
| 273006 | 指定的SUBERGRPID不存在。 | 输入的“订阅组ID”没有通过ADD SUBSCRIBERGRP命令添加。        | 通过LST SUBSCRIBERGRP命令查询已添加的“订阅组ID”。 若查询结果中包含所需的“订阅组ID”，输入正确的值后重新执行该命令。若查询结果中不包含所需的“订阅组ID”，通过ADD SUBSCRIBERGRP命令添加后重新执行该命令。 |
| 275319 | 该订阅ID已经存在。        | “订阅ID”全局唯一。                                 | 通过LST SUBSCRIPTION命令查询当前已经使用的“订阅ID”，重新执行该命令，确保输入的“订阅ID”的值与已查询到的值不同。                                                        |
| 275320 | 该订阅配置已经存在。        | 由“订阅者类型”和“订阅的数据”唯一确定一条数据订阅配置，不能添加同一条数据订阅配置。 | 由“订阅者类型”和“订阅的数据”唯一确定一条数据订阅配置，如果需要请重新执行该命令，确保这两个参数的值不与通过LST SUBSCRIPTION命令查询的一组值完全相同。                                       |
| 275322 | 该订阅者类型不存在。        | 输入的“订阅者类型”没有通过LOD FEPLUG命令成功加载。             | 若“订阅者类型”下拉列表中有所需的“订阅者类型”，选择正确的值后重新执行该命令。若“订阅者类型”下拉列表中没有所需的“订阅者类型”，通过LOD FEPLUG命令成功加载FE插件包后，重新执行该命令。                        |
| 275323 | 该订阅数据不存在。         | 该FE插件包没有开放该“订阅的数据”供其他FE订阅。                  | 若“订阅的数据”下拉列表中有所需的“订阅的数据”，选择正确的值后重新执行该命令。若“订阅的数据”下拉列表中没有所需的“订阅的数据”，则无需处理。                                                   |
