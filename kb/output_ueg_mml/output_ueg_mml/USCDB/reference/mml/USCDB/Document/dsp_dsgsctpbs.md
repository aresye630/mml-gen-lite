# 查看SCTP所有偶联的统计信息(DSP DSGSCTPBS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于请求系统显示SCTP所有偶联的统计信息。在维护进行问题定位时，通过该命令可以查看DSG模块之间的通信状态和处理消息包的情况。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                          |
|:-------|:-------|:------------------------------|
| MID    | DSG模块号 | 用于请求系统显示哪个DSG模块号的SCTP偶联的统计信息。 |

## 使用实例

查看“DSG模块号”为“121”的DSG偶联统计信息，执行命令如下：

```
DSP DSGSCTPBS: MID=121;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1。

| 输出项名称        | 输出项解释                                                  |
|:-------------|:-------------------------------------------------------|
| 当前偶联数        | 用于返回当前偶联个数。                                            |
| 本端发起的偶联个数    | 用于返回本端发起的偶联个数。                                         |
| 对端发起的偶联个数    | 用于返回对端发起的偶联个数。                                         |
| 本端发起的偶联失败次数  | 用于返回本端发起的偶联请求失败次数。                                     |
| 对端发起的偶联失败次数  | 用于返回对端发起的偶联请求失败次数。                                     |
| 关联异常关闭次数     | 用于返回偶联非优雅关闭次数，即本端不通知对端，直接关闭偶联的次数。                      |
| 关联正常关闭次数     | 用于返回偶联优雅关闭次数，即本端通知对端关闭偶联，并且对方端根据请求关闭偶联。                |
| 接收的错误消息包个数   | 用于返回接收到的错误消息包个数。                                       |
| 发送的控制块个数     | 用于返回发送的控制块个数。                                          |
| 发送的有序数据块个数   | 用于返回发送的有序数据块个数。                                        |
| 发送的无序数据块个数   | 用于返回发送的无序数据块个数。                                        |
| 接收的控制块个数     | 用于返回接收的控制块个数。                                          |
| 接收的有序数据块个数   | 用于返回接收的有序数据块个数。                                        |
| 接收的无序数据块个数   | 用于返回接收的无序数据块个数。                                        |
| 重发的数据块个数     | 用于返回重发的数据块个数。如果数据块发送成功，但没有收到响应，则会在超时进行重发。              |
| 被分片的消息个数     | 用于返回被分片的消息个数。如果一个消息包特别大，则要分成若干片发送。                     |
| 重组的消息个数      | 用于返回重组的消息个数。如果一个消息包特别大，则要分成若干片发送。本端在接收时，会将消息片重组为一个消息包。 |
| 接收的校验和错误的总包数 | 用于返回接收的校验和错误的总包数。                                      |
| 总共发送的SCTP包个数 | 用于返回总共发送的SCTP包个数。                                      |
| 总共接收的SCTP包个数 | 用于返回总共接收的SCTP包个数。                                      |
| 丢弃的总包数       | 用于返回丢弃的总包数。                                            |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释      | 原因分析                        | 处理建议                                           |
|-------:|:-----------|:----------------------------|:-----------------------------------------------|
| 302019 | DSG 模块不存在。 | 查看SCTP偶联统计信息所在的“DSG模块号”不存在。 | 通过LST MODULE命令查询DSG的模块号，输入查询到的DSG模块号后，重新执行该命令。 |
