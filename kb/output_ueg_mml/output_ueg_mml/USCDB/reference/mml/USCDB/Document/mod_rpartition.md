# 修改远端Partition信息(MOD RPARTITION)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，如果远端PARTITION参数配置不合理，将会对云部署业务访问产生影响。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对远端Partition的配置信息进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一条远端Partition信息：

- 远端Partition标识
- 远端Location标识

## 注意事项

- 此命令仅能修改远端Partition的RBETYPE参数取值和描述信息，其他参数均不可修改。如果需要修改远端Partition的其他参数，必须首先执行**RMV RPARTITION**命令删除已有的远端Partition配置信息，再执行**ADD RPARTITION**命令增加修改后的远端Partition配置信息。
- 该命令不允许进行批处理操作。

## 参数说明

| 参数标识         | 参数名称          | 参数说明                                                                                                             |
|:-------------|:--------------|:-----------------------------------------------------------------------------------------------------------------|
| RPARTITIONID | 远端Partition标识 | 标识一条远端Partition配置记录的关键字段之一（其取值不能被修改），用于指定需要对哪一个远端PartitionID对应的配置信息进行修改或调整，操作员可以使用LST RPARTITION命令查询获得。          |
| RLOCID       | 远端Location标识  | 标识一条远端Partition配置记录的关键字段之一（其取值不能被修改），用于指定需要对哪一个远端Partition Location标识对应的配置信息进行修改或调整，操作员可以使用LST RPARTITION命令查询获得。 |
| RBETYPE      | 远端BE网元类型      | 该参数为可选参数，用于修改对应远端分区的BE网元类型，操作员可以使用LST RPARTITION命令查询获得。                                                          |
| DESCRIPTION  | 描述            | 用于修改的远端Partition的描述。 取值范围：不超过64位的字符串。 默认值：无。                                                                     |

## 使用实例

修改远端Partition的信息，“远端Partition标识”为“5”，“远端Location标识”为“83”，“远端BE网元类型”为“UDR”。

```
MOD RPARTITION: RPARTITIONID=5, RLOCID=83, RBETYPE=UDR, DESCRIPTION="RemotePartition";
```
