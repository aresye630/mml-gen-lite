# 增加业务发放统计规则(ADD PROVSTATRULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于添加业务发放统计对象的匹配规则，在网管服务器上做话务统计时，可通过本命令进行添加。

## 注意事项

- 在同一个业务发放统计对象下，同一个命令只能配置一个匹配规则。
- 一个匹配规则里，“业务发放统计对象名称”标识规则所属的对象，“命令名”标识规则对应的MML命令，而其他参数则表示具体的匹配规则。这些参数之间的关系即：“第一个匹配参数的名称”和“第一个匹配参数对应的值”对应，标识MML命令中第一个需匹配的参数的名称和取值，可以只配置参数名称或者同时配置参数名称和取值，其它参数以此类推。
- 流控场景的话统，丢弃的消息统计到“USCDB业务发放统计测量”为“ALL Commands Statistic”的话统上或通过该命令仅配置了被流控命令的“命令名称”的话统上。

  例如：

  ```
  ADD PROVSTATRULE: PROVSTATOBJNAME="1", CMDNAME="ADD SUB"; 
  ADD PROVSTATRULE: PROVSTATOBJNAME="2", CMDNAME="ADD SUB", PARA1NAME="IMSI", PARA1VALUE="13845698745";
  ```

  如果**ADD SUB**被流控了，则只会统计到“ALL Commands Statistic”或“业务发放统计对象名称”为“1”的话统上，不会统计到“业务发放统计对象名称”为“2”的话统上。

## 参数说明

|:----------------|:------------|:----------------------------------------------------------------------------------------------------------------------------|

| PARA2VALUE      | 第二个匹配参数对应的值 | 用于指定业务发放统计规则的第二个匹配参数的值，所输入的值则必须是“第二个匹配参数的名称”对应参数的取值。 取值范围：长度不超过127位的字符串。 默认值：无。                                             |

## 使用实例

某局点在网管上做话务统计时需要添加业务发放统计规则，配置方式如下：

1. 添加业务发放统计对象，“业务发放统计对象索引”为“1”，“业务发放统计对象名称”为“HSS9860 Commands Statistic”：

   ```
   ADD PROVSTATOBJ: PROVSTATOBJID=1, PROVSTATOBJNAME="HSS9860 Commands Statistic";
   ```
2. 添加业务发放统计规则，“业务发放统计对象名称”为“HSS9860 Commands Statistic”，“命令名”为“LGI”：

   ```
   ADD PROVSTATRULE: PROVSTATOBJNAME="HSS9860 Commands Statistic", CMDNAME="LGI";
   ```
