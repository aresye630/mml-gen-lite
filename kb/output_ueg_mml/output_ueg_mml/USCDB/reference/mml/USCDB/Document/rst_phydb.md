# 重启物理数据库（RST PHYDB）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令。该操作将重启物理库，物理库连接会中断，请谨慎操作，操作前请务必联系华为技术支持工程师确认。

执行该命令为系统高危操作，需要第二个具有授权权限的用户授权后才能执行该操作。

该命令用于重新启动物理数据库。当出现物理数据库业务中断时，可执行该命令重启物理数据库。

## 注意事项

无。

## 参数说明

无。

## 使用实例

某局点需要执行物理数据库重启操作时：

```
RST PHYDB:;
```

返回结果如下：

```
%%RST PHYDB:;%% 
RETCODE = 0  操作成功  
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释      | 原因分析              | 处理建议                                     |
|------:|:-----------|:------------------|:-----------------------------------------|
|  1730 | 部分操作失败。    | 主用或备用NDF模块其中一个异常。 | 请联系华为技术支持。                               |
|  2742 | 启动物理数据库失败。 | 文件配置异常导致物理数据库异常。  | 使用RST PHYDB命令再重启一次物理数据库，如果还有异常请联系华为技术支持。 |
