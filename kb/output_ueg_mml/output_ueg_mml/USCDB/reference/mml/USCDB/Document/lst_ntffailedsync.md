# 查询通知失败同步配置(LST NTFFAILEDSYNC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

当完成订阅通知失败同步配置时，使用此命令查询通知失败同步配置的结果。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                              |
|:-----------|:-------|:----------------------------------|
| SUBERGRPID | 订阅组ID  | 用于标识订阅组ID。 取值范围：整型(1～255)。 默认值：无。 |

## 使用实例

查询通知失败同步配置，输入“订阅组ID”为“1”：

```
LST NTFFAILEDSYNC: SUBERGRPID=1;
```

## 输出结果说明

该命令执行完成后，会返回命令执行成功的提示信息和查询结果。
