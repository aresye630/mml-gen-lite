# 查看DSG链路状态信息(DSP DSGSCTP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于请求系统显示DSG模块的链路状态信息。

## 注意事项

若输入“远端DSG模块号”则必须输入“远端Location标识”，输入“远端Location标识”不必须输入“远端DSG模块号”。

## 参数说明

| 参数标识    | 参数名称         | 参数说明                                                   |
|:--------|:-------------|:-------------------------------------------------------|
| MID     | DSG模块号       | 用于请求系统显示哪个DSG模块号的链路状态信息；若不输入，则表示所有的DSG模块号。             |
| RLOCID  | 远端Location标识 | 用于请求系统显示哪个远端Location标识的链路状态信息；若不输入，则表示所有的远端Location标识。 |
| RDSGMID | 远端DSG模块号     | 用于请求系统显示哪个远端DSG模块号的链路状态信息；若不输入，则表示所有的远端DSG模块号。         |
| IPVER   | IP类型         | 用于请求系统显示哪种IP类型的链路，若不输入，表示显示所有IP类型的链路。                  |

## 使用实例

1. 维护过程中，查看所有DSG链路状态信息，执行命令如下：

   ```
   DSP DSGSCTP:;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1。

| 输出项名称        | 输出项解释                                                                                                                                                                                                                                       |
|:-------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DSG模块号       | 用于返回SCTP链路对应的本端DSG模块号。                                                                                                                                                                                                                      |
| 远端Location标识 | 用于返回本网元所连接的FE或容灾USCDB网元的Location标识。                                                                                                                                                                                                         |
| 远端DSG模块号     | 用于返回本网元所连接的FE或容灾USCDB网元的DSG模块号。                                                                                                                                                                                                             |
| 业务类型         | 用于返回DSG模块的业务类型，此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。                                                                                                                                                                                      |
| 偶联号          | 用于返回SCTP链路的偶联号，相同的偶联号可确定一条SCTP偶联。                                                                                                                                                                                                           |
| 链路状态         | 用于返回SCTP链路状态。共有三种状态： 链路已激活链路去激活链路拥塞                                                                                                                                                                                                         |
| 激活状态         | 用于返回链路是否被手工去激活。共有两种状态：未被手工去激活和已被手工去激活。                                                                                                                                                                                                      |
| 拥塞状态         | 用于返回链路是否拥塞的实时状态。共有两种状态：无拥塞和最大拥塞。 ALM-22003 DSG SCTP链路拥塞告警的上报和恢复不是实时的，与此命令查询到的结果会不一致。                                                                                                                                                        |
| 发送负荷(%)      | 用于返回SCTP链路发送信息的负荷。                                                                                                                                                                                                                          |
| 接收负荷(%)      | 用于返回SCTP链路接收信息的负荷。                                                                                                                                                                                                                          |
| IP类型         | 用于返回SCTP链路的IP类型。共有两种类型：IPV4和IPV6。                                                                                                                                                                                                           |
| 链路加密状态       | 用于返回链路是否加密。 取值范围： 非加密加密                                                                                                                                                                                                                     |
| 健康状态         | 用于返回链路的健康状态。 取值范围： 健康：有以下三种情况：“亚健康检测开关”设置为“0”。链路丢包率等于或小于“亚健康网络丢包率”。“旁路ping结果”设置为“TRUE（是）”。 亚健康：有以下两种情况：“旁路ping结果”设置为“FALSE（否）”，“亚健康检测开关”设置为“1”且链路丢包率大于“亚健康网络丢包率”。大包丢包率为100%。  说明： “亚健康网络丢包率”、“亚健康检测开关”和“旁路ping结果”可以通过LST DSGSCTPPARA命令查询得到。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释        | 原因分析                              | 处理建议                                           |
|-------:|:-------------|:----------------------------------|:-----------------------------------------------|
| 300150 | 参数RLOCID未指定。 | 当指定“远端DSG模块号”时，“远端Location标识”未指定。 | 当指定“远端DSG模块号”时，请配置“远端Location标识”。              |
| 302019 | DSG 模块不存在。   | “DSG模块号”对应的模块不存在。                 | 通过LST MODULE命令查询DSG的模块号，输入查询到的DSG模块号后，重新执行该命令。 |
