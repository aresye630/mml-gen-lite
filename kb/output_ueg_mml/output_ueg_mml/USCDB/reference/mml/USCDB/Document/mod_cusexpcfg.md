# 修改定制导出配置(MOD CUSEXPCFG)

## 命令功能

**须知** 

该命令属于高危命令，该操作可能会导致当前园区数据导出失败。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改园区定制导出配置。

该命令用于对某条园区定制导出配置进行修改或调整。在该命令中，系统通过“FE类型”、“园区名称”来唯一标识一条用户数据记录。

## 注意事项

- 同一园区配置的“旧密码”、“密码”及“确认密码”三个参数必须同时输入或者同时不输入。
- 密码长期使用会增加被盗窃和破解的风险，而且使用的时间越长，被盗窃和破解的风险越高。定期修改密码可以有效防范这种情况的发生，因此强烈建议您定期修改密码。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                            |
|:-----------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FETYPE     | FE类型   | 可选必选说明：必选参数 参数含义：标识一条园区定制导出配置数据记录的关键字段之一（其取值不能被修改），用于指定需要删除哪一个FE类型对应的园区配置，操作员可以使用LST FEPLUG命令查询获得。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                            |
| CAMPUSNAME | 园区名称   | 可选必选说明：必选参数 参数含义：标识一个园区的关键字段之一（其取值不能被修改），用于指定需要删除哪一个园区对应的定制导出操作对象。 取值范围：由数字（0~9）、字母（a~z和A~Z）或下划线组成的长度不超过63的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                  |
| OLDPWD     | 旧密码    | 可选必选说明：可选参数 参数含义：用于指定导出园区文件的旧加密密码。 取值范围：长度不超过31的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                             |
| PWD        | 密码     | 可选必选说明：可选参数 参数含义：用于指定导出园区文件的新加密密码。 密码区分大小写，其复杂度需同时满足下列条件： 密码必须至少包含以下四个类别中的三类：英文大写字母。英文小写字母。数字：0～9。特殊字符：~ ! # % ^ * ( ) _ - + [ ] { } | < > . ?。 不允许使用三个或三个以上连续的字母或数字（例如：ABC、123）。密码不能和园区名称或者园区名称的逆序一样，且不能包含园区名称或者园区名称的逆序。不允许使用三个或三个以上连续的相同字符（例如：AAA）。密码长度最短8个字符。密码的第一个字符必须是字母。 取值范围：长度不超过31的字符串。 默认值：无。 配置原则：无。 |
| CFM        | 确认密码   | 可选必选说明：可选参数 参数含义：用于指定导出园区文件的确认密码，该字符串必须与“密码”相同。 取值范围：长度不超过31的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                |
| DESC       | 配置描述   | 可选必选说明：可选参数 参数含义：用于指定园区的配置描述。 取值范围：由数据、字母、下划线组成的长度不超过64的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                     |

## 使用实例

某园区需要修改定制导出配置：

- “FE类型”：“SUP-FE”
- “园区名称”：“CAMPUStest000”
- “旧密码”：“AB12cd34\_56”
- “密码”：“ab12CD34#56”
- “确认密码”：“ab12CD34#56”
- “配置描述”：“NULL”

```
MOD CUSEXPCFG: FETYPE="SUP-FE", CAMPUSNAME="CAMPUStest000", OLDPWD="*****", PWD="*****", CFM="*****", DESC="CAMPUStest000 Config";
```

**说明** 

执行本命令时，若“密码”取值为样例中的弱口令“ab12CD34#56”，执行结果会返回“260566”错误码。
