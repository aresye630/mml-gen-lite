# 设置迁移用户恢复状态(SET RESTRANSDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，该操作仅在数据紧急修复场景下执行，其他场景下执行该命令可能损坏用户数据，导致业务呼损。因此执行该命令前，需要与华为技术支持确认后才可以实施

该命令用于启动和停止迁移用户数据的恢复任务。

在紧急修复场景下，维护工具会自动调用该命令用于恢复升级过程中和升级后迁入主用局的用户数据。

## 注意事项

- 该命令仅适用于数据紧急修复场景。其他场景下执行该命令可能损坏用户数据，导致业务呼损，禁止使用。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识        | 参数名称          | 参数说明                                                                                                                                                                                                                                        |
|:------------|:--------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 业务类型          | 可选必选说明：必选参数 参数含义：用于指定设置哪个业务类型的迁移用户恢复状态。 取值范围：长度不超过128的字符串 默认值：无。 配置原则：此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。                                                                                                                               |
| RESTAT      | 恢复状态          | 可选必选说明：必选参数 参数含义：用于启动或停止迁移用户数据的恢复任务。 取值范围： START(启动恢复)STOP(停止恢复) 默认值：无。 配置原则：无。                                                                                                                                                             |
| STARTTIME   | 开始时间          | 可选必选说明：条件必选参数 参数含义：用于指定系统恢复哪个时间点及之后的迁入用户数据。 取值范围：格式为“YYYY&MM&DD&HH&MM&SS”的字符串。各部分的取值范围分别如下： YYYY（年份）：1990~2037MM（月份）：1~12DD（日期）：1~31HH（小时）：00~23MM（分钟）：00~59SS（秒）：00~59 默认值：无。 配置原则： 该参数在“恢复状态”参数取值为“START(启动恢复)”时为必选参数。该参数指定的时间点需要为系统本地时间。 |
| ENDTIME     | 结束时间          | 可选必选说明：条件必选参数 参数含义：用于指定系统恢复哪个时间点及之前的迁入用户数据。 取值范围：格式为“YYYY&MM&DD&HH&MM&SS”的字符串。各部分的取值范围分别如下： YYYY（年份）：1990~2037MM（月份）：1~12DD（日期）：1~31HH（小时）：00~23MM（分钟）：00~59SS（秒）：00~59 默认值：无。 配置原则： 该参数在“恢复状态”参数取值为“START(启动恢复)”时为必选参数。该参数指定的时间点需要为系统本地时间。 |
| CID         | DSU cluster标识 | 可选必选说明：可选参数 参数含义：用于指定对哪个DSU Cluster进行迁移数据的启动或停止恢复操作，若不输入，则表示对该业务类型的所有DSU Cluster进行操作。 取值范围：2～4096 默认值：无。 配置原则：无。                                                                                                                            |

## 使用实例

在数据紧急修复流程中，启动恢复“业务类型”为“SUP-FE”的迁移用户数据的恢复状态，“开始时间”为“2021&06&02&15&40&39”，“结束时间”为“2021&06&03&15&40&41”。

```
SET RESTRANSDATA: SERVICETYPE="SUP-FE", RESTAT=START, STARTTIME=2021&06&02&15&40&39, ENDTIME=2021&06&03&15&40&41;
```
