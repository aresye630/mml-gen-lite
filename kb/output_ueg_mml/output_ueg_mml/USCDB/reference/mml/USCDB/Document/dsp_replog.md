# 显示复制队列信息(DSP REPLOG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于请求系统显示以下信息：

- 局内复制队列信息
- 局间复制队列信息
- 快速校验队列信息

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称       | 参数说明                                                               |
|:------------|:-----------|:-------------------------------------------------------------------|
| SERVICETYPE | 业务类型       | 用于请求系统显示指定业务类型查询复制队列信息。若不输入，则表示显示所有业务类型查询复制队列信息。                   |
| CID         | Cluster标识  | 用于请求系统显示需要查询复制队列的Cluster标识。若不输入，则表示显示所有复制队列信息的Cluster标识。           |
| LID         | Location标识 | 用于请求系统显示指定需要查询复制队列信息的Location标识。若不输入，则表示显示所有需要查询复制队列信息的Location标识。 |
| SHOWALL     | 显示空队列记录    | 用于请求系统是否显示队列均为空的记录。若不输入，则表示显示所有记录。                                 |
| QUEUETYPE   | 队列类型       | 用于请求系统显示指定队列类型查询复制队列信息。若不输入，则表示显示所有队列类型的复制队列信息。                    |

## 使用实例

- 显示“业务类型”为“SUP-FE”、“显示空队列记录”为“NO”的复制队列信息：

  ```
  DSP REPLOG: SERVICETYPE="SUP-FE", SHOWALL=NO;
  ```

  ```
  %%DSP REPLOG: SERVICETYPE="SUP-FE", SHOWALL=NO;%%
  RETCODE = 0  操作成功

  操作结果如下
  ------------
   业务类型  Cluster标识  节点标识  Location标识  主表表名             复制队列消息数量  快速校验队列对象数量  最近的异常时间

   SUP-FE    2            51        1             NULL                 5                 0                     NULL                               
   SUP-FE    3            61        1             RAW_PK_DATA          3                 0                     NULL                   
   SUP-FE    3            61        1             SID_DATA             0                 1                     NULL  
  (结果个数 = 3)

  ---    END
  ```
- 显示“业务类型”为“USCDB”、“显示空队列记录”为“NO”、“队列类型”为“REPLICATION”的复制队列信息：

  ```
  DSP REPLOG: SERVICETYPE="USCDB", SHOWALL=NO, QUEUETYPE=REPLICATION;
  ```

  ```
  %%DSP REPLOG: SERVICETYPE="USCDB", SHOWALL=NO, QUEUETYPE=REPLICATION;%%
  RETCODE = 0  操作成功

  操作结果如下
  ------------
   业务类型  Cluster标识  节点标识  Location标识  主表表名             复制队列消息数量  快速校验队列对象数量  最近的异常时间

  ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。

| 输出项名称      | 输出项解释                                                                                                                                                                                                                                                                                     |
|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 业务类型       | 用于返回复制队列的业务类型信息。                                                                                                                                                                                                                                                                          |
| Cluster标识  | 用于返回Cluster，此参数在同一USCDB下唯一。 当添加USCDB网元时，系统自动生成“Cluster标识”为“1”的Cluster供内部使用。                                                                                                                                                                                                               |
| 节点标识       | 用于返回节点，此参数在Location内唯一。为方便维护，节点标识和模块号的取值通常相同。                                                                                                                                                                                                                                             |
| Location标识 | 用于返回Location。                                                                                                                                                                                                                                                                             |
| 主表表名       | 用于返回节点中主键数据表的名称。主键数据表只存在于DSU节点中，DRU节点中该列显示为NULL。                                                                                                                                                                                                                                          |
| 复制队列消息数量   | 用于返回该节点中复制队列消息中堆积的复制消息个数。 复制队列消息包括两种：局间复制队列消息和局内复制队列消息。 局间复制消息队列的最大长度由软参“DSUOUTERREPQUEUESIZE（DSU局间复制队列长度）”或“DRUINNERREPQUEUESIZE（DRU局内复制队列长度）”的取值确定。 局内复制消息队列的最大长度由软参“DSUINNERREPQUEUESIZE（DSU局内复制队列长度）”或“DRUOUTERREPQUEUESIZE（DRU局间复制队列长度）”的取值确定。 当系统正常运行情况下，复制消息队列大小显示为0。节点一般不会堆积复制消息。 |
| 快速校验队列对象数量 | 用于返回该节点中等待快速校验的用户个数。 快速校验消息队列的最大长度由软参“LENQUKVFYQUE（快速校验队列长度）”的值决定。如果某类型FE的“REDUNAUTOTAKEOVER（业务发放自动接管功能开关）”取值为“1”，则该类型FE需要根据其单个DSU的容量合理调整此参数值。 当系统正常运行情况下，校验消息队列大小显示为0。节点一般不会堆积校验消息。                                                                                                      |
| 最近的异常时间    | 用于返回主用局和容灾局最近一次数据不一致的时间，便于维护人员进行故障定位时，通过查看节点日志在该时间点前后所记录的操作，从而定位是什么原因导致主用局和容灾局出现数据不一致。 此列只显示用户数据的异常时间，即DSU节点出现数据不一致时才显示异常时间信息，DRU节点中该列显示为NULL。如果主用局和容灾局数据一直保持一致，DSU节点也显示为NULL。                                                                                                            |
