# 设置TLS协议配置(SET TLSCFG)

- 命令功能

## 命令功能

**须知** 

该命令属于高危命令，兼容加密套件是不安全的，建议使用强加密套件。如果使用不安全的加密套件会存在TLS/SSL传输的数据泄露或者被篡改风险。因此执行该命令前，需要与华为技术支持确认后才可以实施。

此命令用于设置PGW Web LMT，PGW的MML、SOAP、HTTP、THIRDNOTIFY或REST接口和DMS WebUI的TLS协议相关配置。

## 注意事项

- 使用本命令配置TLS协议，应该尽可能使用安全的协议版本和强加密套件。当选择不安全的协议或兼容加密套件时，会存在TLS/SSL传输的数据泄露或者被篡改风险。
- 安全的TLS协议版本是指TLS1.2和TLS1.3版本，其他版本只有在对端不支持TLS1.2和TLS1.3版本协议的时候才能够使用。兼容加密套件也只有在对端不支持强加密套件的时候才能够使用。使用TLS1.0，TLS1.1协议版本或兼容加密套件后系统会上报“ALM-10031 系统存在不安全的配置项”告警。
- 对于PGW的SOAP接口，当软参“TLSMODE”设置为“3”时，该命令设置才有效。
- 对于PGW的MML接口，当通过**ADD PORT**/**MOD PORT**命令设置MML端口使用HTTPS协议后，该命令设置才有效。即通过**ADD PORT**/**MOD PORT**命令设置参数“端口子类型”为“PORT\_FOR\_MML”或“PORT\_FOR\_LMT\_MML ”且“是否使用HTTPS”为“YES”。
- 对于PGW的REST接口，当通过**ADD PORT**/**MOD PORT**命令设置REST端口使用HTTPS协议后，该命令设置才有效。即通过**ADD PORT**/**MOD PORT**命令设置参数“端口类型”为“PORT\_FOR\_PROV”、“端口子类型”为“PORT\_FOR\_REST”且“是否使用HTTPS”为“YES”。
- 对于PGW的HTTP接口，当通过**ADD PORT**/**MOD PORT**命令设置HTTP端口使用HTTPS协议后，该命令设置才有效。即通过**ADD PORT**/**MOD PORT**命令设置参数“端口类型”为“PORT\_FOR\_PROV”、“端口子类型”为“PORT\_FOR\_HTTP”且“是否使用HTTPS”为“YES”。
- 对于PGW Web LMT，当软参“WEBLMTHTTPSSWITCH”设置为“1”时，该命令设置才有效。
- 执行本命令设置“服务端类型”后，需要执行**RST MODULE**命令重启所有PGW模块后配置才能生效。
- “兼容加密套件”在当前版本不支持所有的PSK协议，如下：
  - DHE\_PSK\_AES\_256\_CBC\_SHA(DHE\_PSK\_AES\_256\_CBC\_SHA)
  - DHE\_PSK\_AES\_128\_CBC\_SHA(DHE\_PSK\_AES\_128\_CBC\_SHA)
  - PSK\_AES\_128\_CBC\_SHA(PSK\_AES\_128\_CBC\_SHA)
  - PSK\_AES\_256\_CBC\_SHA(PSK\_AES\_256\_CBC\_SHA)
  - DHE\_PSK\_3DES\_EDE\_CBC\_SHA(DHE\_PSK\_3DES\_EDE\_CBC\_SHA)
  - PSK\_3DES\_EDE\_CBC\_SHA(PSK\_3DES\_EDE\_CBC\_SHA)
  - DHE\_PSK\_RC4\_128\_SHA(DHE\_PSK\_RC4\_128\_SHA)
  - PSK\_RC4\_128\_SHA(PSK\_RC4\_128\_SHA)
  - DHE\_PSK\_NULL\_SHA(DHE\_PSK\_NULL\_SHA)
  - PSK\_NULL\_SHA(PSK\_NULL\_SHA)
- “协议版本”选择“TLS1.3(TLS1.3)”时，仅可选择“强加密套件”中的“TLS1\_3\_AES\_128\_GCM\_SHA256(TLS1\_3\_AES\_128\_GCM\_SHA256)”和“TLS1\_3\_AES\_256\_GCM\_SHA384(TLS1\_3\_AES\_256\_GCM\_SHA384)”。
- “协议版本”选择“TLS1.0(TLS1.0)”、“TLS1.1(TLS1.1)”或“TLS1.2(TLS1.2)”时，“强加密套件”仅可选择除“TLS1\_3\_AES\_128\_GCM\_SHA256(TLS1\_3\_AES\_128\_GCM\_SHA256)”和“TLS1\_3\_AES\_256\_GCM\_SHA384(TLS1\_3\_AES\_256\_GCM\_SHA384)”以外的选项。
- “协议版本”同时选择“TLS1.3(TLS1.3)”和其他协议版本时，“强加密套件”均可选择，但对于“TLS1.3(TLS1.3)”，实际生效的“强加密套件”仅为“TLS1\_3\_AES\_128\_GCM\_SHA256(TLS1\_3\_AES\_128\_GCM\_SHA256)”和“TLS1\_3\_AES\_256\_GCM\_SHA384(TLS1\_3\_AES\_256\_GCM\_SHA384)”。对于其他协议，实际生效的“强加密套件”仅为除“TLS1\_3\_AES\_128\_GCM\_SHA256(TLS1\_3\_AES\_128\_GCM\_SHA256)”和“TLS1\_3\_AES\_256\_GCM\_SHA384(TLS1\_3\_AES\_256\_GCM\_SHA384)”以外的选项。
- 该命令中“强加密套件”和“兼容加密套件”参数用于选择加密算法，DHE相关的算法性能较差，在大量建链场景下会导致本端CPU占用过高以及长时间无法建链的问题，请谨慎使用，建议选择ECDHE算法。

## 使用实例

用户需要使用安全的TLS协议及算法用于PGW的SOAP接口时，需要执行该命令进行TLS协议版本和算法的配置，输入“用途类型”为“SERVER”，“接口类型”为“SOAP”，“协议版本”为“TLS1.2-1”，“强加密套件”为“TLS\_ECDHE\_RSA\_WITH\_AES\_128\_GCM\_SHA256-1&TLS\_ECDHE\_RSA\_WITH\_AES\_256\_GCM\_SHA384-1&TLS\_DHE\_RSA\_WITH\_AES\_128\_GCM\_SHA256-1&TLS\_DHE\_RSA\_WITH\_AES\_256\_GCM\_SHA384-1&TLS\_DHE\_DSS\_WITH\_AES\_128\_GCM\_SHA256-1&TLS\_DHE\_DSS\_WITH\_AES\_256\_GCM\_SHA384-1&TLS\_ECDHE\_ECDSA\_WITH\_AES\_128\_GCM\_SHA256-1&TLS\_ECDHE\_ECDSA\_WITH\_AES\_256\_GCM\_SHA384-1”，“加密套件排序”为“TRUE”。

```
SET TLSCFG: USTYPE=SERVER, INFTYPE=SOAP, PROTOCOLVER=TLS1.2-1, STRONGSUITE=TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256-1&TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384-1&TLS_DHE_RSA_WITH_AES_128_GCM_SHA256-1&TLS_DHE_RSA_WITH_AES_256_GCM_SHA384-1&TLS_DHE_DSS_WITH_AES_128_GCM_SHA256-1&TLS_DHE_DSS_WITH_AES_256_GCM_SHA384-1&TLS_ECDHE_ECDSA_WITH_AES_128_GCM_SHA256-1&TLS_ECDHE_ECDSA_WITH_AES_256_GCM_SHA384-1,CIPHERSUITEORDER=TRUE;
```
