# 设置日志跟踪(SET LOGTRACE)

## 命令功能

**须知** 

该命令属于高危命令，该操作会导致系统处理能力下降。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置对单个用户的日志信息进行跟踪。

当收到用户反馈时，可通过本命令进行跟踪单用户日志信息，从而对用户反馈问题进行定位处理。

## 注意事项

- 该命令属于高危命令，该操作会导致系统处理能力下降。因此执行该命令前，需要与华为技术支持确认后才可以实施。日志跟踪功能使用完毕后请及时关闭。
- 一个“业务类型”同时只能对一个用户日志进行跟踪。当对同一“业务类型”重复使用本命令设置单用户日志跟踪信息时，最后一次的设置用户会覆盖上一次的设置用户。
- 该命令不允许进行批操作。
- 执行该命令对单个用户的日志信息进行跟踪前，需要将软参“USCDBLOGFLAG（日志开关）”设置为“4”，打开日志跟踪开关。
- 该命令用户在本局DSU时，支持该用户的日志信息跟踪。
- 当用户在本局DSU时该命令才生效，涉及到本局用户的DCI操作时支持日志信息跟踪。
- PGW模块不支持单用户日志信息跟踪。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                |
|:--------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AT      | 业务类型   | 用于配置单用户所属的业务类型，此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。 取值范围：长度不超过128的字符串。 默认值：无。                                                                                                                    |
| OT      | 操作类型   | 用于指定操作类型，即设置是否对单用户日志进行跟踪。 取值说明: SET(设置)：设置单用户日志跟踪。 CANCEL(取消)：取消单用户日志跟踪。 默认值：无。                                                                                                                     |
| CT      | 用户号码类型 | 用于指定需要跟踪的用户的号码类型。 各参数选项的含义是： IMSI：表示用户号码类型为IMSI。MSISDN：表示用户号码类型为MSISDN。TAC：表示用户号码类型为TAC。 默认值：无。                                                                                                     |
| UN      | 用户号码   | 用于指定需要跟踪的用户号码。 取值范围：长度不超过1536的字符串。 默认值：无。                                                                                                                                                           |
| TT      | 跟踪时长   | 仅当“操作类型”选择为“设置”时有效。用于指定需要跟踪的单用户日志消息的时长。 单位：分钟 取值范围：1～30 默认值：5                                                                                                                                       |
| MID     | 模块号    | 仅当“操作类型”选择为“取消”时有效。用于表示取消日志消息跟踪的单用户所在的模块号。 取值范围：1～4080 默认值：无。 说明： 当按用户号码取消日志跟踪任务，输入“用户号码类型”、“用户号码”参数时，则无论“模块号”是否输入，均无意义，表示停止所有模块号的跟踪任务。当按模块号取消日志跟踪任务，输入“模块号”，不能同时输入“用户号码类型”或“用户号码”参数，表示停止指定模块的跟踪任务。 |
| TRCTYPE | 跟踪类型   | 用于表示获取单用户日志跟踪类型。 取值说明: DCICONTENT(记录DCI消息内容)：表示DSG、DRU、DSU模块记录详细的DCI信息。 默认值：DCICONTENT(记录DCI消息内容)。                                                                                                  |

## 使用实例

在测试过程中，发现某用户的业务失败，启动该用户的日志跟踪任务。

```
SET LOGTRACE: AT="SUP-FE", OT=SET, CT="IMSI", UN="4600138", TT=6;
```

指定模块号取消日志跟踪任务。

```
SET LOGTRACE: AT="SUP-FE", OT=CANCEL, MID=52;
```

指定用户取消日志跟踪任务。

```
SET LOGTRACE: AT="SUP-FE", OT=CANCEL, CT="AUC1", UN="560001";
```
