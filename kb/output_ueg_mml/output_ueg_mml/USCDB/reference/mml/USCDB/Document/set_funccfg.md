# 设置业务配置信息(SET FUNCCFG)

- 注意事项

## 命令功能

**须知** 

该命令属于高危命令，该操作修改网元在网管上的资源配置信息，操作不当将影响网管对网元的管理。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置业务配置信息。在生产预安装时，或者设备运行维护过程中，可通过本命令设置网元的资源配置信息，以便于生成设备档案信息。

## 注意事项

该命令只支持网元类型“HSS9860”。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                             |
|:------------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 网元类型    | 用于表示FE网元的业务类型，此参数在USCDB下唯一，通过命令LOD FEPLUG加载FE插件后在此引用。 取值范围：长度不超过128的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                  |
| ITEMNAME    | FE配置项名称 | 用于指定配置项的名称。 可设置的FE配置项包括： AUCMaxNumImsi：当HSS9860作为独立鉴权中心的时候，最大可存储的IMSI个数。HLRmaxNumPdpAddress：指HSS9860作为HLR部署在GSM/UMTS网络时，最大可存储的PDP地址数。HLRMaxNumMsisdn：指HSS9860作为HLR部署在GSM/UMTS网络时，最大可存储的MSISDN个数。HLRMaxNumImsi：指HSS9860作为HLR部署在GSM/UMTS网络时，最大可存储的IMSI个数。DevicProvider：指设备的供应商。DevicHardware：指设备硬件平台的类型。DevicType：指当前的设备型号。DevicName：指设备的名称。ISSEPARATING：FE和BE是否分离部署。取值为0（否）或1（是）。 |
| ITEMVALUE   | FE配置项值  | 用于指定FE配置项的值。                                                                                                                                                                                                                                                                                                                                                                     |

## 使用实例

生产预安装时，HSS9860需要作为独立鉴权中心，设置其最大可以存储的IMSI个数为1000，执行命令如下：

```
SET FUNCCFG: SERVICETYPE="HSS9860", ITEMNAME="AUCMaxNumImsi", ITEMVALUE="1000";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释         | 原因分析                 | 处理建议                                                               |
|-------:|:--------------|:---------------------|:-------------------------------------------------------------------|
| 332671 | 该属性不属于对应的网元类型 | 该命令只支持网元类型“HSS9860”。 | 在“CSP MML命令”界面执行LST ME命令查询该局点是否有“HSS9860”网元，如有则重新执行本命令；如果没有，则无需处理。 |
