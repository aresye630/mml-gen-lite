# 查询NF信息(LST NFPROFILE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询NF（Network Function）信息。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                    |
|:---------|:-------|:------------------------|
| NFINSID  | 服务实例ID | 用于指示系统按照服务实例ID来查询NF信息。  |
| FQDN     | 全量域名   | 用于指示系统按照全量域名来查询NF信息。    |
| VNFINSID | 网元实例ID | 用于指示系统按照哪个北向功能实体查询NF信息。 |

## 使用实例

查询所有NF信息。

```
LST NFPROFILE:;
```

```
%%LST NFPROFILE:;%%
RETCODE = 0 操作成功

操作结果如下:
------------------------
服务实例ID = 4947a69a-f61b-4bc1-b9da-47c9c5d14b64
  全量域名 = udr001.5gc.mnc012.mcc345.3gppnetwork.org
网元实例ID = 4bfc1-bd9da-47c9c5d14b64
(结果个数 = 1)

--- END
```

## 输出结果说明

该命令执行正常，会返回命令操作成功的提示信息和相关参数，各参数含义请参见**SET NFPROFILE**命令的参数说明。
