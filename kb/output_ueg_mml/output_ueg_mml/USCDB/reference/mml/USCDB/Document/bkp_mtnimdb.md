# 备份DSG模块的内存数据库(BKP MTNIMDB)

- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于备份DSG模块的channel数据。该channel数据保存在于DSG模块所在Pod的“/opt/uscdb/snp”目录，文件命名为“MtnCenter\_Location ID\_模块号.txt”。备份时，会将“/opt/uscdb/snp”目录下的channel数据备份到“/opt/uscdb/upgBakSnp”目录。在升级场景下，升级工具自动调用该命令备份DSG模块中的Channel数据。非升级场景下，用户可以根据实际需要使用该命令来备份DSG的channel数据。例如，进行DRU模块扩容之前需要备份channel数据。

- 若需要备份所有DSG模块的channel数据，请不要输入任何参数。
- 若需要备份指定的某一个DSG模块的channel数据，请输入“模块号”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                 |
|:-------|:-------|:---------------------------------------------------------------------|
| MID    | 模块号    | 用于对指定DSG模块的channel数据进行备份，操作员可以使用LST MODULE命令查询获得。 取值范围：1～2047 默认值：无。 |

## 使用实例

1. 某局点DRU扩容之前，需要备份所有DSG模块的channel数据：

   ```
   BKP MTNIMDB;
   ```
2. 在某维护局点，用户对“模块号”为“21”的DSG模块的channel数据进行备份：

   ```
   BKP MTNIMDB:MID=21;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释     | 原因分析              | 处理建议                                               |
|-------:|:----------|:------------------|:---------------------------------------------------|
| 260046 | 该模块不存在。   | 输入的“模块号”对应的模块不存在。 | 请输入已存在的“模块号”，可用LST MODULE命令查看已存在的模块。               |
| 302019 | DSG模块不存在。 | DSG模块未加载。         | 请先执行LST MODULE查询确认DSG模块不存在，再执行ADD MODULE命令加载DSG模块。 |
