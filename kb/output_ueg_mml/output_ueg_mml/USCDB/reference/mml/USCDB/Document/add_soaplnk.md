# 增加SOAP链路(ADD SOAPLNK)

- 输出结果说明

## 命令功能

**须知** 

该命令为高危命令，SECTRANS参数取值为YES时为安全加密传输，如果对端服务器配置不合理，会导致订阅通知发送失败。因此参数选择YES时，需要确保服务器和客户端的配置匹配。

当配置数据层订阅通知使用SOAP接口方式时，使用该命令添加一条SOAP链路。

## 注意事项

- 一个链路集最多配置两条SOAP链路。
- 只有当MSGQUEUELEN和MSGSENDRATE参数都不为0时，才能控制SOAP消息的发送速率。
- 业务触发的订阅通知的速率大于MSGSENDRATE时，消息队列会缓存订阅通知消息直至超时。建议MSGQUEUELEN值应大于业务触发的订阅通知的速率乘以ADD SUBSCRIBER中配置的超时时间。
- MSGSENDRATE或MSGQUEUELEN设置较小时，消息队列容易被堆满，此时将不接收新的订阅通知消息，影响业务。
- “安全传输”参数取值为“YES(是)”时为安全加密传输，如果对端服务器配置不合理，会导致订阅通知发送失败。因此参数选择YES时，需要确保服务器和客户端的配置匹配。
- 当通过该命令与第三方服务器建立链路进行通信时，参数“安全传输”选择“YES(是)”，需要同时进行如下配置。
  1. 当**SET NEWCERTSWITCH**的参数“证书开关”取值为“OFF（关闭）”时，执行**LOD VERIF**命令，参数“用途类型”选择“CLIENT(客户端)”，“连接类型”选择“THIRDNOTIFY”，加载安全证书文件。

     当**SET NEWCERTSWITCH**的参数“证书开关”取值为“ON（打开）”时，加载PGW作为客户端，“证书场景名称”为“USCDB\_THIRODNOTIFY\_CLIENT\_USCDB”的数字证书，加载和更新方法请参考产品手册“通过网管MAE-Access加载或更新证书”或“通过OM Portal加载或更新证书”章节。

     **说明** 

     - **SET NEWCERTSWITCH**的参数“证书开关”取值可通过在“CSP MML命令”界面执行**LST NEWCERTSWITCH**命令查询。
     - 添加证书时，需要确保本端与对端都加载了同一机构颁发的证书。否则，会导致链路通信失败。
  2. 执行**SET TLSCFG**命令，参数“用途类型”选择“CLIENT(客户端)”，“接口类型”选择“THIRDNOTIFY(THIRDNOTIFY)”，设置TLS协议相关配置信息。
- 第三方订阅通知开启安全传输会导致系统性能下降；不开启安全传输会存在数据被篡改、泄露等安全风险。
- 新升级的场景默认不开启安全传输，建议开启持安全传输。

## 参数说明

| 参数标识           | 参数名称       | 参数说明                                                                                                                          |
|:---------------|:-----------|:------------------------------------------------------------------------------------------------------------------------------|
| LNKID          | 链路ID       | 用于标识一条SOAP链路。 取值范围：1～50 默认值：无。                                                                                                |
| LKSID          | 链路集ID      | 用于标识一个SOAP链路集。 取值范围：1～50 默认值：无。                                                                                               |
| IPVER          | IP类型       | 用于表示IP地址类型。 取值范围： IPV4：当系统要求使用IPv4类型的IP地址时选择此选项。IPV6：当系统要求使用IPv6类型的IP地址时选择此选项。 默认值：无。                                         |
| SIPV4          | 服务器端IPV4地址 | 仅当本命令中的“IP类型”参数选择为“IPV4”时该参数有效，用于标识SOAP链路服务器端的IPv4地址。 取值范围：符合IPv4格式要求。 默认值：无。                                                 |
| SIPV6          | 服务器端IPV6地址 | 仅当本命令中的“IP类型”参数选择为“IPV6”时该参数有效，用于标识SOAP链路服务器端的IPv6地址。 取值范围：符合IPv6格式要求。 默认值：无。                                                 |
| SPORT          | 服务器端端口     | 用于标识SOAP链路服务器端的端口号。 取值范围：1～65534 默认值：无。                                                                                       |
| CIPV4          | 客户端IPV4地址  | 仅当本命令中的“IP类型”参数选择为“IPV4”时该参数有效，用于标识SOAP链路客户端的IPv4地址。该IP地址必须为ADD SRVIPADDR命令添加的IPv4地址。 取值范围：符合IPv4格式要求。 默认值：无。                 |
| CIPV6          | 客户端IPV6地址  | 仅当本命令中的“IP类型”参数选择为“IPV6”时该参数有效，用于标识SOAP链路客户端的IPv6地址。该IP地址必须为ADD SRVIPADDR命令添加的IPv6地址。 取值范围：符合IPv6格式要求。 默认值：无。                 |
| URL            | URL        | 用于标识SOAP服务器URL。 取值范围：长度不超过255的字符串。 默认值：无。 配置原则：该参数不能配置绝对路径的URL，只能输入域名之后的URL片段。 说明：当操作人员在输入URL前多输入一个空格时，系统默认该参数与未输入空格的URL地址一样。 |
| LNKDESC        | 链路描述       | 用于标识SOAP链路的描述信息。 取值范围：长度不超过32的字符串。 默认值：无。                                                                                     |
| MSGQUEUELEN    | 消息队列长度     | 用于标识SOAP链路的消息队列长度。 取值范围：0～100000 默认值：0。                                                                                       |
| MSGSENDRATE    | 消息发送速率     | 用于控制SOAP链路在单个PGW中的消息发送速率。当有多个PGW模块时，网元的最大的SOAP消息发送速率为PGW个数乘以消息发送速率。 取值范围：0～1000 单位：条/秒。 默认值：0。                                |
| REQUESTTIMEOUT | 请求超时时间     | 用于控制SOAP链路连接超时时间，在设定时间内连接上没有任何消息，则PGW将关闭此连接。 取值范围：20～245 单位：秒。 默认值：22。                                                        |
| SECTRANS       | 安全传输       | 用于设置第三方订阅通知是否支持安全传输。 取值范围： NO(否)：不支持安全传输。YES(是)：支持安全传输。 默认值：无。 配置原则：如果选择支持安全传输，必须确保对端服务器已加载安全证书文件并配置TLS加密套件。                  |

## 使用实例

1. 添加一条SOAP链路，设置“链路ID”为“1”，“链路集ID”为“1”，“IP类型”为“IPV4”，“服务器端IPV4地址”为“192.168.2.119”，“服务器端端口”为“2013”，“客户端IPV4地址”为“192.168.2.123”，“安全传输”为“YES”。

   ```
   ADD SOAPLNK: LNKID=1, LKSID=1, IPVER=IPV4, SIPV4="192.168.2.119", SPORT=2013, CIPV4="192.168.2.123", SECTRANS=YES;
   ```
2. 添加一条SOAP链路，设置“链路ID”为“1”，“链路集ID”为“1”，“IP类型”为“IPV4”，“服务器端IPV4地址”为“192.168.2.119”，“服务器端端口”为“2013”，“客户端IPV4地址”为“192.168.2.123”，“URL”为“/cxf/api/v1/updatelocationasync?wsdl”，“安全传输”为“YES”。

   ```
   ADD SOAPLNK: LNKID=1, LKSID=1, IPVER=IPV4, SIPV4="192.168.2.119", SPORT=2013, CIPV4="192.168.2.123", URL="/cxf/api/v1/updatelocationasync?wsdl", SECTRANS=YES;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                            | 原因分析                           | 处理建议                                                                                                                        |
|-------:|:---------------------------------|:-------------------------------|:----------------------------------------------------------------------------------------------------------------------------|
| 274630 | 链路已经存在。                          | SOAP“链路ID”在系统中已添加。             | 先执行LST SOAPLNK命令查询已经存在的“链路ID”，然后重新执行本命令，确保要添加的“链路ID”与查询的值不相同。                                                               |
| 274642 | 链路集已经存在两条链路。                     | 一个链路集中最多只有两条链路。                | 执行本命令将该“链路ID”添加到另外一个链路集中，确保该“链路集ID”与已添加的不重复。                                                                                |
| 274703 | Client IP不存在，请使用ADD SRVIPADDR添加。 | 输入的“客户端IPV4地址”或“客户端IPV6地址”不存在。 | 执行ADD SRVIPADDR命令添加所需的“客户端IPV4地址”或“客户端IPV6地址”，确保成功添加后，再重新执行本命令。                                                             |
| 275437 | 相同链路集的链路选择的SECTRANS参数值必须相同。      | 同一链路集的两条链路配置的“安全传输”方式不一致。      | 执行LST SOAPLNK命令，查询同一链路集已配置的链路的“安全传输”，输入相同的“安全传输”方式，然后重新执行本命令。执行RMV SOAPLNK命令，删除同一链路集已配置的链路，然后重新执行本命令，确保新配置的两条链路的“安全传输”方式一致。 |
