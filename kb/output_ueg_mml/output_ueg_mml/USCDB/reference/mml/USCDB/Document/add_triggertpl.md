# 增加触发器模板(ADD TRIGGERTPL)

## 命令功能

当配置数据层订阅通知过滤条件时，使用该命令添加一条触发器模板记录。

该命令的参数索引关系如图1所示。

**图1** 命令参数的索引关系图

## 注意事项

最多可以配置100条触发器模板记录。

## 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|:-------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TRIGGERTPLID | 触发器模板ID | 用于标识一条触发器模板记录。 取值范围：1～100 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| CONDITION    | 过滤条件    | 用于标识一条触发器模板记录的过滤条件，过滤条件来源于FE插件包所配置的发布数据，配置格式为[ATTR][OPERATOR][VALUES]，ATTR、OPERATOR、VALUES之间需要有空格分隔。ATTR，属性名称，默认表示修改后属性名称。如需要表示修改前属性，则格式为BEFORE.ATTR。OPERATOR，操作符，支持如下几种形式“EQ”（等于）、“NE”（不等于）、“IN”（在范围内）。VALUES，属性取值，单值或多值。多值时OPERATOR只能为IN，多个值之间用|连接。 一组[ATTR][OPERATOR][VALUES]组合表达一个属性的关系，多个属性的组合关系需要关系运算符。关系运算符支持“&&”（与）、“||”（或）。多组属性的各个属性之间需要用“()”分隔。“&&”（与）的优先级高于“||”（或）。以IMSI属性为例：IMSI取值为470000000000000，表达式为IMSI EQ 470000000000000。IMSI取值可以为470000000000000、480000000000000、490000000000000，表达式为IMSI IN 470000000000000|480000000000000|490000000000000。IMSI的修改前不等于修改后值，即IMSI取值发生变化，表达式为IMSI NE BEFORE.IMSI。 以IMSI、DEVICE属性为例：IMSI取值为470000000000000，且DEVICE取值为A，表达式为(IMSI EQ 470000000000000) && (DEVICE EQ A)。IMSI取值可以为470000000000000、480000000000000、490000000000000，且DEVICE取值为A、B，表达式为(IMSI IN 470000000000000|480000000000000|490000000000000) && (DEVICE IN A|B)。 取值范围：长度不超过1023的字符串。 默认值：无。 |
| NAME         | 触发器模板名称 | 用于标识一条触发器模板的名称。 取值范围：长度不超过127的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |

## 使用实例

添加一条触发器模板记录，设置“触发器模板ID”为“1”，“过滤条件”为“IMSI IN 470000000000000”，“触发器模板名称”为“IMSITPL”。

```
ADD TRIGGERTPL: TRIGGERTPLID=1, CONDITION="IMSI IN 470000000000000", NAME="IMSITPL";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释            | 原因分析                         | 处理建议                                                     |
|-------:|:-----------------|:-----------------------------|:---------------------------------------------------------|
| 259210 | 参数CONDITION格式不对。 | “过滤条件”格式不对。                  | 请参照上述参数说明中“过滤条件”的格式重新输入“过滤条件”，确保其格式正确。                   |
| 301265 | 表中记录已经存在。        | 触发器模板中已经存在与指定“触发器模板ID”相同的记录。 | 执行LST TRIGGERTPL命令查询触发器模板记录，重新输入“触发器模板ID”，确保取值与查询结果中不重复。 |
