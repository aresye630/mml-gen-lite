# 查询路由数据迁移状态(DSP ROUTETRANS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

在路由数据迁移、回退、删除数据过程中，运行该命令查询维护中心Master节点中保存的路由数据迁移各阶段状态。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                  |
|:-------|:-------|:----------------------------------------------------------------------|
| FETYPE | FE类型   | 用于指定需要查询哪个FE类型的路由数据迁移的状态。该参数在USCDB下唯一，在通过LOD FEPLUG命令加载FE插件包之后才能在此引用。 |

## 使用实例

查询“FE类型”为“SUP-FE”的路由数据迁移状态。

```
DSP ROUTETRANS: FETYPE="SUP-FE";
```

执行结果如下：

```
%%DSP ROUTETRANS: FETYPE="SUP-FE";%%
RETCODE = 0  操作成功

操作结果如下
------------
路由数据迁移状态  =  正常状态
(结果个数 = 1)

---    END
```

|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
