# 启动模块(STR MODULE)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

该命令用于启动指定模块。如果进程为主备进程，则主备进程同时启动。

本命令的使用场景为：当执行**STP MODULE**命令后，模块将停止工作，此时需要执行本命令恢复已停止的模块。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                   |
|:-------|:-------|:-----------------------------------------------------------------------|
| MID    | 模块号    | 标识一条模块配置信息的关键字段，用于指定待启动的模块，该参数可以使用LST MODULE命令查询获得。 取值范围：1～4080 默认值：无。 |

## 使用实例

维护场景下，需要启动之前由于特殊原因停止的模块。已停止模块的“模块号”为“1”。

```
STR MODULE: MID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释          | 原因分析               | 处理建议                                               |
|-------:|:---------------|:-------------------|:---------------------------------------------------|
| 330005 | 参数MID指定的进程不存在。 | 输入的“模块号”取值在系统中不存在。 | 通过执行LST MODULE命令查看当前添加的“模块号”，输入查询到的“模块号”后，重新执行该命令。 |
| 331054 | 模块正在退出。        | 该模块已经收到了优雅退出指令。    | 等待大于5秒后再重新执行该命令。                                   |
