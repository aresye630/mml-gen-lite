# 查询系统的运行模式配置信息(LST SYSRM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询系统的运行模式配置信息。

- 若需要查询全部的系统运行模式配置概要信息，请不要输入任何参数。
- 若需要查询某条系统的运行模式配置详细信息，请输入“业务类型”。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                     |
|:------------|:-------|:-------------------------------------------------------------------------|
| SERVICETYPE | 业务类型   | 用于指示系统需要按照业务类型来查询运行模式；若不输入，则表示查询所有业务类型的系统运行模式。 取值范围：长度不超过128的字符串。 默认值：无。 |

## 使用实例

1. 查询所有业务类型的系统运行模式：

   ```
   LST SYSRM:;
   ```

   ```
   %%LST SYSRM:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    业务类型  系统运行状态

    SUP-FE    激活模式    
    SUP-FE    激活模式    
   (结果个数 = 2)

   ---    END
   ```
2. 查询“业务类型”为“SUP-FE”的系统运行模式：

   ```
   LST SYSRM: SERVICETYPE="SUP-FE";
   ```

   ```
   %%LST SYSRM: SERVICETYPE="SUP-FE";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
       业务类型  =  SUP-FE
   系统运行状态  =  激活模式
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**MOD SYSRM**命令的参数说明。
