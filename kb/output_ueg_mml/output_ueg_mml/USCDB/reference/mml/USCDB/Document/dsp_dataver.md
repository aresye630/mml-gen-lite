# 查询数据版本信息(DSP DATAVER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于请求系统显示内存数据库的数据版本信息。当系统在新建局、升级、插件包补丁等场景下，该命令可以查询USCDB类型和FE类型的当前内存库数据版本号。对于FE类型，该命令还可以检查内存库数据版本号与FE插件包版本号是否一致。

- 新建局：用于查询USCDB类型和FE类型的当前内存库数据版本号。对于FE类型，检查当前内存库数据版本号与FE插件包版本号是否一致。
- 升级：用于查询升级后的USCDB类型和FE类型的内存库数据版本号。对于FE类型，检查升级后的内存库数据版本号与FE插件包版本号是否一致。
- 插件包补丁：用于查询安装插件包补丁后的FE类型的内存库数据版本号。对于FE类型，检查安装插件包补丁后的内存库数据版本号与FE插件包版本号是否一致。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                                                                              |
|:-------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MT     | 数据版本模块类型 | 用于请求系统显示指定的模块类型查询的数据版本信息；若不输入，则表示根据参数取值中的所有模块类型查询的数据版本信息。 各参数选项含义是： DRU：查询DRU节点内存数据库中的数据版本信息。DSU：查询DSU节点内存数据库中的数据版本信息。                                                                            |
| MID    | 模块号      | 用于请求系统显示指定的模块查询的数据版本信息；若不输入，则表示所有模块查询的数据版本信息。 当“数据版本模块类型”参数被指定，则“模块号”参数表示的模块必须属于指定的模块类型。                                                                                                          |
| TP     | 查询类型     | 用于请求系统显示指定的“查询类型”查询数据版本信息；若不输入，则根据参数取值中的“CURRENT”类型执行查询。 各参数选项含义是： ALL：查询FE或者USCDB的所有数据版本信息，包括新建环境、升级或者插件包补丁场景中生成的版本信息。对于每个FE或者USCDB，它的所有数据版本信息中，只存在一个当前版本的数据版本信息。CURRENT：查询FE或者USCDB当前版本的数据版本信息。 |

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。如表1所示。

| 输出项名称      | 输出项解释                                                                                                                                                                                      |
|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 模块号        | 用于返回DRU或DSU的模块号。 取值范围：1～4080                                                                                                                                                               |
| 数据库类型      | 用于返回数据库的类型。数据库类型只有内存数据库，故仅显示为“0”。                                                                                                                                                          |
| 应用类型       | 用于返回FE类型编号或者USCDB类型编号。“FE类型”根据USCDB网元加载的插件包类型决定。“FE类型编号”由FE在插件包中固定分配，此编号可以通过LST FEPLUG命令查询得到。 取值范围：0～1023                                                                                  |
| 应用类型名称     | 用于返回FE类型名称或者USCDB类型名称。 取值范围：长度不超过32的字符串。                                                                                                                                                   |
| 数据版本号      | 用于返回内存库数据版本号。                                                                                                                                                                              |
| 数据版本信息生成时间 | 用于返回数据版本信息的生成时间。 取值说明：时间格式是“YYYY-MM-DD HH:MM:SS”，其中“YYYY”表示年，“MM”表示月，“DD”表示天，“HH”表示小时，“MM”表示分钟，“SS”表示秒。                                                                                    |
| 描述信息       | 用于返回数据版本信息的生成描述。根据此描述信息，可以区分数据版本信息的生成场景。 取值说明： create：创建。表示数据版本信息由新建环境时生成。upgrade：升级后的目标版本。表示数据版本信息是升级时生成的目标版本信息。feplugpatch：插件包补丁。表示数据版本信息由插件包补丁生成。upg base：升级前的源版本。表示数据版本信息是升级时生成的源版本信息。 |
| 状态标识       | 对于FE类型，用于标识内存库数据版本号与插件包版本号是否一致。FE的插件包版本号可以通过LST FEPLUG命令查询获取。对于USCDB类型，无对应插件包，故不进行版本号的检查且仅显示为“1”。 取值说明： 0：内存库数据版本号与插件包版本号不一致或查询异常。1：内存库数据版本号与插件包版本号一致。                                     |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释                 | 原因分析               | 处理建议                                                           |
|------:|:----------------------|:-------------------|:---------------------------------------------------------------|
|  1909 | 模块号不存在。               | 未添加该模块。            | 执行ADD MODULE命令添加所需的模块，重新执行本命令。                                 |
|  2144 | 模块类型与模块号不匹配。          | “模块类型”与“模块号”不匹配。   | 先执行LST MODULE命令查询已存在的“模块类型”与“模块号”，再输入与“模块号”相匹配的“模块类型”，重新执行本命令。 |
|  2174 | 参数模块号指定的模块不是DRU或者DSU。 | 输入的“模块号”不是DRU或DSU。 | 执行LST MODULE命令查询已存在的模块，再输入正确的“模块号”，重新执行本命令。                    |
