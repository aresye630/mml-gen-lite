# 设置LDAP连接数阈值(SET LDAPCONNTHD)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

**说明** 

该命令在25.1.0版本不支持。

该命令用于设置LDAP连接数告警阈值。

## 注意事项

- 该命令设置的LDAP连接数告警阈值，在打开LDAP连接数阈值告警开关**LDAPCONNTHDALMSWT**后生效。
- 系统在初始化时已经自动配置的初始值如下所示：

  ```
      一级告警阈值  =  80
      二级告警阈值  =  85
  一级告警恢复阈值  =  75
  二级告警恢复阈值  =  80
  ```

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                         |
|:-------|:---------|:-------------------------------------------------------------|
| LV1    | 一级告警阈值   | 用于指定一级告警阈值，该参数的配置原则是：一级告警阈值小于二级告警阈值。 取值范围：50～99 默认值：无。       |
| LV2    | 二级告警阈值   | 用于指定二级告警阈值，该参数的配置原则是：二级告警阈值大于一级告警阈值。 取值范围：50～99 默认值：无。       |
| LR1    | 一级告警恢复阈值 | 用于指定一级告警恢复阈值，该参数的配置原则是：一级告警恢复阈值小于二级告警恢复阈值。 取值范围：50～99 默认值：无。 |
| LR2    | 二级告警恢复阈值 | 用于指定二级告警恢复阈值，该参数的配置原则是：二级告警恢复阈值大于一级告警恢复阈值。 取值范围：50～99 默认值：无。 |

## 使用实例

当LDAP服务端需要修改LDAP连接数告警阈值时，需要执行命令如下：

```
SET LDAPCONNTHD: LV1=70, LV2=75, LR1=65, LR2=70;
```
