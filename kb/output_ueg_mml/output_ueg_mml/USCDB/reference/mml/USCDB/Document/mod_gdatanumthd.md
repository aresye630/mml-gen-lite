# 修改全局数据记录数超限阈值（MOD GDATANUMTHD）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于对配置数据库中的一条全局数据记录数超限阈值记录的参数进行修改或调整。

## 注意事项

修改全局数据记录数超限阈值配置对业务本身无影响，但阈值设置不合理可能导致上报“ALM-12085 全局数据记录数超限”告警。

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                               |
|:-------------|:-------|:---------------------------------------------------------------------------------------------------|
| SERVICETYPE  | 业务类型   | 可选必选说明：必选参数。 参数含义：用于指定具体的服务类型，包括USCDB和FE的插件包类型。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                  |
| TABLENAME    | 表名称    | 可选必选说明：必选参数。 参数含义：用于指定内存库全局数据的表名。表名可通过执行DSP NODECOUNT命令查询获取。 取值范围：长度不超过64的字符串。 默认值：无。 配置原则：无。      |
| RECORDNUMTHD | 记录数阈值  | 可选必选说明：必选参数。 参数含义：用于指定全局数据表记录阈值，如果超过该阈值会上报“ALM-12085 全局数据记录数超限”告警。 取值范围：1~10000000。 默认值：无。 配置原则：无。 |

## 使用实例

修改一条全局数据记录数超限阈值记录：设置“业务类型”为“SUP-FE”，“表名称”为“G\_ALLTYPE\_SUB1\_INFO7\_TPL”，“记录数阈值”为“5”。

```
MOD GDATANUMTHD: SERVICETYPE="SUP-FE", TABLENAME="G_ALLTYPE_SUB1_INFO7_TPL", RECORDNUMTHD=5;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                    | 原因分析             | 处理建议                                                                                                                         |
|-------:|:-------------------------|:-----------------|:-----------------------------------------------------------------------------------------------------------------------------|
| 260681 | 全局数据记录数超限阈值不存在。          | 待修改的记录不存在。       | 执行LST GDATANUMTHD命令查询已存在的全局数据记录数超限阈值记录： 若识别为参数取值输入错误，则使用查询获取的正确数据重新执行本命令。若需修改的记录不存在，且需要设置，请执行ADD GDATANUMTHD命令添加全局数据记录数超限阈值。 |
| 302533 | 输入的业务类型不正确，请输入正确的业务类型参数。 | 输入的“业务类型”参数取值有误。 | 输入正确的“业务类型”后重新执行本命令。 若为非USCDB的应用类型，则需要通过LOD FEPLUG命令加载对应的网元插件包之后才能在此处进行设置。                                                   |
