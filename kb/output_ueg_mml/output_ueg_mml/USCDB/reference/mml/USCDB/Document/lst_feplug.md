# 查询FE插件包信息(LST FEPLUG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于在配置数据库中查询在USCDB上已加载的FE插件包数据记录。

- 若需要查询已加载的全部FE插件包信息，请不要输入任何参数。
- 若需要查询某个已加载的FE插件包信息，请输入“FE类型”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识             | 参数名称       | 参数说明                                                                                                                           |
|:-----------------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------|
| FETYPE           | FE类型       | 用于指示系统需要按照哪个FE类型来查询FE插件包信息；若不输入，则表示所有的FE类型。                                                                                    |
| FETYPENAME       | FE类型名称     | 用于指示系统需要按照哪个FE类型名称来查询FE插件包信息；可选FE类型由LOD FEPLUG命令执行后自动生成。若不输入，则表示所有的FE类型名称。                                                     |
| FETYPEVER        | FE类型版本     | 用于指示系统需要按照哪个FE类型版本来查询FE插件包信息；若不输入，则表示所有的FE类型版本。                                                                                |
| UPFILENAME       | FE插件包名称    | 用于指示系统需要按照哪个FE插件包名称来查询FE插件包信息；若不输入，则表示所有的FE插件包名称。                                                                              |
| LOADFILENAME     | FE插件加载包名称  | 用于指示系统需要按照哪个FE插件加载包名称来查询FE插件包信息。若不输入，则表示所有的FE插件加载包名称。 需要指出的是，同一条记录中的“FE插件加载包名称”和“FE插件包名称”都代表同一个FE插件包。此参数主要用于系统对插件包进行识别和调用。     |
| FEPLUGLOADSTATUS | FE插件主机加载状态 | 用于指示系统需要按照FE插件包在USCDB侧的哪种加载状态来查询FE插件包信息。若不输入，则表示所有的加载状态。各参数选项的含义是： 加载未成功：显示FE插件在主机侧没有加载成功的FE插件包信息。加载成功：显示FE插件在主机侧加载成功的FE插件包信息。 |
| LODMODE          | FE插件包加载模式  | 用于指示系统需要按照FE插件包采用哪种加载模式来查询FE插件包信息。若不输入，则表示所有的加载模式。各参数选项的含义是： 单应用类型：插件包加载后只呈现一个FE类型。多应用类型：插件包加载后呈现多个FE类型。                       |

## 使用实例

1. 查询所有FE插件包，执行命令如下：

   ```
   LST FEPLUG:;
   ```

   ```
   操作结果如下
   ------------
   FE类型    FE类型名称    FE类型版本             FE插件包名称                         FE插件加载包名称     FE插件主机加载状态  FE插件包加载模式
   3         IMS-HSS       V900R008C20SPC010      HSS9860_PLUG_V900R008C20SPC010.tar   FEPLUG_1.tar         加载成功            多应用类型
   33        HSS9860       V900R008C20SPC010      HSS9860_PLUG_V900R008C20SPC010.tar   FEPLUG_0.tar         加载成功            多应用类型
   (结果个数 = 2)

   ---    END
   ```
2. 查询FE类型为33的插件包，执行命令如下：

   ```
   LST FEPLUG: FETYPE=33;
   ```

   ```
   操作结果如下
   ------------
               FE类型  =  33
           FE类型名称  =  HSS9860
           FE类型版本  =  V900R008C20SPC010
         FE插件包名称  =  HSS9860_PLUG_V900R008C20SPC010.tar
     FE插件加载包名称  =  FEPLUG_0.tar
   FE插件主机加载状态  =  加载成功
     FE插件包加载模式  =  多应用类型
   (结果个数 = 1)

   ---    END
   ```
