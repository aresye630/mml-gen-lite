# 查看SCTP负荷信息(DSP DSGSCTPLOD)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查看SCTP链路负荷信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                       |
|:-------|:-------|:---------------------------|
| MID    | DSG模块号 | 用于请求系统显示哪个DSG模块内的SCTP负荷信息。 |

## 使用实例

查看SCTP负荷信息，“DSG模块号”为“102”。

```
DSP DSGSCTPLOD: MID=102;
```

```
%%DSP DSGSCTPLOD: MID=102;%%
RETCODE = 0  操作成功

操作结果如下
------------
 偶联号  发送负荷(%)  接收负荷(%)

 3       0            0          
 5       0            0          
(结果个数 = 2)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称   | 输出项解释                                     |
|:--------|:------------------------------------------|
| 偶联号     | 用于返回SCTP偶联号码。                             |
| 发送负荷(%) | 用于返回SCTP链路发送信息的负荷。 通过此参数可以查看当前偶联的发送负荷的高低。 |
| 接收负荷(%) | 用于返回SCTP链路接收信息的负荷。 通过此参数可以查看当前偶联的接收负荷的高低。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释     | 原因分析                | 处理建议                                       |
|-------:|:----------|:--------------------|:-------------------------------------------|
| 302019 | DSG模块不存在。 | 输入的“DSG模块号”在系统中不存在。 | 通过LST MODULE命令查询已加载的DSG模块号并正确设置，然后重新执行本命令。 |
