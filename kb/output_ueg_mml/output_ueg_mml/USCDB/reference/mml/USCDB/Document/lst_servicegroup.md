# 查询业务类型分组（LST SERVICEGROUP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明
- 参考信息

## 命令功能

该命令用于查询FE侧支持多应用共存的业务分组中各个业务类型信息。

## 注意事项

无。

## 参数说明

| 参数ID      | 参数名称   | 参数说明                                    |
|:----------|:-------|:----------------------------------------|
| GROUPNAME | 分组名称   | FE侧支持多应用共存的分组名称。若不输入，则表示查询所有分组中的业务类型信息。 |

## 使用实例

1.查询所有分组中的业务类型信息。

```
%%LST SERVICEGROUP:;%%
RETCODE = 0  操作成功

操作结果如下
------------
 分组ID  分组名称    业务类型  业务类型名称

 33      GU-SUP-DNS  10        SUP-FE      
 33      GU-SUP-DNS  33        GU-HLR      
 33      GU-SUP-DNS  40        SUP-FE      
 109     MVAS        109       MVAS        
 109     MVAS        110       EIR         
(结果个数 = 5)

---    END
```

2.查询分组名称为“GU-SUP-DNS”的业务类型信息。

```
%%LST SERVICEGROUP: GROUPNAME="GU-SUP-DNS";%%
RETCODE = 0  操作成功

操作结果如下
------------
 分组ID  分组名称    业务类型  业务类型名称

 33      GU-SUP-DNS  10        SUP-FE      
 33      GU-SUP-DNS  33        GU-HLR      
 33      GU-SUP-DNS  40        SUP-FE      
(结果个数 = 3)

---    END
```

## 输出结果说明

| 参数名称   | 描述                    |
|:-------|:----------------------|
| 分组ID   | FE侧支持多应用共存的分组名称对应的ID。 |
| 分组名称   | FE侧支持多应用共存的分组名称。      |
| 业务类型   | 分组中的业务类型ID。           |
| 业务类型名称 | 分组中的业务类型名称。           |
