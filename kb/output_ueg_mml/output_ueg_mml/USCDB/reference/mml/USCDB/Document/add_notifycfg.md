## 命令功能

该命令用于添加业务发放订阅通知的订阅配置信息，使FE能获取到所订阅的数据变更。

操作员通过PGW修改全局数据或用户数据后，PGW负责通知FE相关的修改内容，以便FE针对数据变更作出必要的处理。

- 当“订阅通知的接口类型”为“MCI”、“SOAP”或“FILE”时，只需执行本命令就可以完成业务发放订阅通知的配置。
- 当“订阅通知的接口类型”为“THIRDPARTY”（即订阅通知接口采用协议为HTTP、SOAP或者TCP）时，完整业务发放订阅通知配置步骤如图1所示。

## 注意事项

- 单个“订阅通知的FE类型”下最多允许添加100个“订阅通知对端的ID”，并且多个“订阅通知的FE类型”之间的“订阅通知对端的ID”取值可以相同。
- “订阅通知的接口类型”为“SOAP”的订阅通知最多允许添加50个。
- 某一“订阅通知的FE类型”下可添加不同的“订阅通知的接口类型”类型。
- 同一个“订阅通知对端的ID”下的所有“FE标识”对应的“订阅通知的接口类型”必须相同。
  - 如果是“SOAP”，则可以配置多个SOAP接口类型的“FE标识”。
  - 如果是“MCI”，若配置“订阅通知发送的Location标识”为“0”，则只能添加一个MCI接口类型的“FE标识”；若配置“订阅通知发送的Location标识”为非0值，则可以配置多个MCI接口类型的“FE标识”。
  - 如果是“FILE”，则只能添加一个FILE接口类型的“FE标识”。
- 当发送一条订阅通知请求中涉及到多个“订阅通知对端的ID”时，如果配置之间有冲突，则按照如下原则处理。
  - 如果多个“订阅通知对端的ID”的等待同步响应消息接收到一个或多个失败响应，则本次订阅通知返回失败响应。
  - 如果多个“订阅通知对端的ID”的等待同步响应消息均接收到了成功响应，则本次订阅通知返回成功响应。
- 某一“订阅通知的FE类型”下，某条订阅通知配置的“订阅通知的接口类型”为“MCI”时，对于用户数据通知按照如下原则处理。
  - 如果未填写“订阅通知发送的Location标识”参数，则自动选择该“订阅通知的FE类型”的一个优先级别高的FE对端发送。优先级别可以通过**LST RLOCATION**查询。
  - 如果填写了“订阅通知发送的Location标识”参数，则此条订阅通知配置数据将只会发送给该指定“订阅通知发送的Location标识”的FE对端。
- 同一个客户端只支持加载一套证书，且第三方订阅通知服务端使用同一机构颁发的证书。

## 使用实例

1. 添加“SUP-FE”类型的FE订阅通知配置信息，其中PGW和FE之间采用“SOAP”接口传递订阅通知消息，“订阅通知对端的ID”为“2”, “IP类型”为“IPV4”，“SOAP服务器IPV4地址1”为“192.168.2.119”，“SOAP客户端IPV4地址1”为“192.168.2.123”，“SOAP服务器端口号1”为“2010”：

   ```
   ADD NOTIFYCFG: FETYPE="SUP-FE", REMOTEID=2, FEID=2, INFTYPE=SOAP, IPVER=IPV4, SOAPSERVERIPV4IP1="192.168.2.119", SOAPSERVERPORT1=2010, SOAPCLIENTIPV4IP1="192.168.2.123";
   ```
2. 添加“SUP-FE”类型的FE订阅通知配置信息，设置“订阅通知对端的ID”为“1”，PGW和FE之间采用“MCI”接口传递订阅通知消息：

   ```
   ADD NOTIFYCFG: FETYPE="SUP-FE", REMOTEID=1, FEID=3, INFTYPE=MCI, SYNCHROSWITCH=ASYNC;
   ```
3. 添加“SUP-FE”类型的FE订阅通知配置信息，设置“订阅通知对端的ID”为“3”，PGW和FE之间采用“FILE”接口传递订阅通知消息，生成的文件保存在/download/SUP-FE目录下：

   ```
   ADD NOTIFYCFG: FETYPE="SUP-FE", REMOTEID=3, FEID=4, INFTYPE=FILE;
   ```
4. 添加“SUP-FE”类型的FE订阅通知配置信息，设置“订阅通知对端的ID”为“5”，PGW和FE之间采用“FILE”接口传递订阅通知消息，生成的文件保存在/download/SUP-FE/IMEI目录下：

   ```
   ADD NOTIFYCFG: FETYPE="SUP-FE", REMOTEID=5, FEID=5, INFTYPE=FILE, SAVEPATH="IMEI";
   ```
5. 添加“SUP-FE”类型的FE订阅通知配置信息，设置“订阅通知对端的ID”为“6”，PGW和FE之间采用第三方定制接口传递订阅通知消息，“订阅组ID”为“3”：

   1. 执行**ADD TCPLNK**、**ADD SOAPLNK**或者**ADD HTTPLNK**命令添加链路。
   2. 执行**ADD SUBSCRIBER**命令添加订阅者。
   3. 执行**ADD SUBSCRIBERGRP**命令添加订阅组。
   4. 执行**ADD NOTIFYCFG**命令添加业务发放订阅通知。

      ```
       ADD NOTIFYCFG: FETYPE="SUP-FE", REMOTEID=6, FEID=6, INFTYPE=THIRDPARTY, SUBERGRPID=3;
      ```
