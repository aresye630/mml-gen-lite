# 查询PGW SSH用户(LST PGWSSHUSER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询SSH用户信息：

- 若需要查询全部用户的详细信息，请不要输入任何参数。
- 若需要查询某个用户的详细信息，请输入“USERNAME”或其它参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                |
|:------------|:--------|:----------------------------------------------------|
| USERNAME    | 用户名     | 用于指示系统需要按照“用户名”来查询SSH用户信息；若不输入，则表示查询所有SSH用户的信息。     |
| PORT        | PGW服务端口 | 用于指示系统需要按照“PGW服务端口”来查询SSH用户信息；若不输入，则表示查询所有SSH用户的信息。 |
| DESCRIPTION | 用户描述    | 用于指示系统需要按照“用户描述”来查询SSH用户信息；若不输入，则表示查询所有SSH用户的信息。    |

## 使用实例

1. 查询所有SSH用户。

   ```
   LST PGWSSHUSER:;
   ```

   ```
   %%LST PGWSSHUSER:;%% 
   RETCODE = 0  操作成功  

   操作结果如下 
   ------------  
   用户名    新密码  PGW服务端口  用户描述    
   sshuser1  *****   7776         user info  
   sshuser2  *****   7776         user info 
   (结果个数 = 2)  

   ---    END
   ```
2. 查询“PGW服务端口”为“7776”的SSH用户。

   ```
   LST PGWSSHUSER: PORT=7776;
   ```

   ```
   %%LST PGWSSHUSER: PORT=7776;%% 
   RETCODE = 0  操作成功  

   操作结果如下 
   ------------  
   用户名    新密码  PGW服务端口  用户描述    
   sshuser1  *****   7776         user info  
   sshuser2  *****   7776         user info 
   (结果个数 = 2)  

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD PGWSSHUSER**命令的参数说明。
