# 查看FE插件列表和状态(DSP FEPLUG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询分别加载在USCDB主机上和OMU上的FE插件版本信息和校验结果是否一致。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                    |
|:-----------|:-------|:------------------------------------------------------------------------|
| FETYPENAME | FE类型名称 | 用于请求系统显示哪个FE类型的FE插件包版本信息和校验结果。由LOD FEPLUG命令执行后自动生成，可通过LST FEPLUG命令进行查询。 |

## 使用实例

查询网元SUP-FE的OMU侧和主机侧的插件包版本信息和校验结果，执行命令如下：

```
DSP FEPLUG: FETYPENAME="SUP-FE";
```

```
操作结果
--------
        模块号  =  22
 OMU记录版本号  =  SUP-FE9820V900R006C00
主机记录版本号  =  SUP-FE9820V900R006C00
      校验结果  =  校验一致
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称    | 输出结果解释                                                                                                                                                                                                             |
|:---------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 模块号      | 用于FE插件包信息校验对应的模块编号。                                                                                                                                                                                                |
| OMU记录版本号 | 用于返回FE插件在USCDB的OMU侧的版本信息。                                                                                                                                                                                          |
| 主机记录版本号  | 用于返回FE插件在USCDB主机侧的版本信息。                                                                                                                                                                                            |
| 校验结果     | 用于返回系统对主机侧和OMU侧的FE插件版本信息的校验结果。结果类型以及代表的含义如下： “校验一致”：表示主机加载的插件包和OMU上的插件包一致，属于正常情况。“校验不一致”：表示主机加载的插件包和OMU上的插件包不一致。当出现此结果时，建议用户在不影响业务的情况下，执行RST MODULE命令重启校验不一致的模块后，重新执行DSP FEPLUG进行检查。如果校验结果仍为“校验不一致”，请联系华为技术支持定位处理。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释   | 原因分析                                            | 处理建议                                  |
|------:|:--------|:------------------------------------------------|:--------------------------------------|
|  1710 | 无可用模块。  | PGW、NDF、CAG、DBG模块，以及业务类型所对应的DRU、DSU、DSG模块同时不存在。 | 执行ADD MODULE命令添加所需模块，确保成功添加后，重新执行本命令。 |
