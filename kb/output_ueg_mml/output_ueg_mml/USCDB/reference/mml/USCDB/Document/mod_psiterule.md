# 修改号段配置(MOD PSITERULE)

## 命令功能

**须知** 

该命令属于高危命令，修改号段配置会造成营帐命令无法转发到其他设备。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对号段的配置信息进行修改或调整。

当用户号码的号段区域或描述发生变化时，可以通过本命令修改用户号段的配置信息。

在该命令中，系统通过“Rule ID”参数来唯一标识一条号段配置数据记录。

## 注意事项

- 此命令仅能修改号段的主设备、割接状态、区域信息和相关描述。如果需要修改站点ID和号段类型或号段前缀之间的关联关系，必须首先执行**RMV PSITERULE**命令删除已有的关联关系，再执行**ADD PSITERULE**命令增加修改后的新关联关系。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                               |
|:------------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------|
| RULEID      | Rule ID | 标识一条号段设置数据记录的关键字段（其取值不能被修改），用于指定需要对哪一个Rule ID对应的号段配置数据进行修改或调整，操作员可以使用LST PSITERULE命令查询获得。 取值范围：1～65535 默认值：无。                      |
| ACTIVE      | 主设备     | 仅当ADD PSITE命令中的“业务场景”参数取值为“DUALPROV(营帐双发)”时该参数有效，用于指定配置号段的主设备。 取值范围： LOCAL(本端为主设备)REMOTE(远端为主设备) 默认值：无。                            |
| CUTOVER     | 割接状态    | 仅当ADD PSITE命令中的“业务场景”参数取值为“DUALPROV(营帐双发)”时该参数有效，用于指定配置号段的割接状态。 取值范围： TRUE(TRUE)：号段已割接。FALSE(FALSE)：号段未割接。NONE(NONE)：非双发号段。 默认值：无。 |
| AREA        | 号段区域    | 用于指定业务发放指令携带的用户号码的号段所分配到区域的描述。例如“Beijing”、“Shenzhen”等。 取值范围：不超过64位的字符串。 默认值：无。                                                     |
| DESCRIPTION | 描述      | 用于指定业务发放指令携带的用户号码的号段配置描述信息。 取值范围：不超过128位的字符串。 默认值：无。                                                                               |

## 使用实例

某局点的远端业务发放站点对应的号段区域发生改变，需要修改号段配置数据。“Rule ID”为“1”，“号段区域”为“Beijing”，“描述”为“Beijing”：

```
MOD PSITERULE: RULEID=1, AREA="Beijing", DESCRIPTION="Beijing";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                 | 原因分析                                                      | 处理建议                                                                 |
|-------:|:--------------------------------------|:----------------------------------------------------------|:---------------------------------------------------------------------|
| 256034 | 记录不存在。                                | 只能修改已经存在的记录。                                              | 执行LST PSITERULE命令查看当前已存在的记录，然后在已存在的记录上执行本命令进行修改。                     |
| 260008 | 参数未修改。请至少指定一个待修改的参数。                  | 参数未修改。                                                    | 请至少输入一个待修改的参数。                                                       |
| 275474 | 未割接号段的主设备必须为远端。                       | 输入的“割接状态”参数取值为“FALSE(FALSE)”时，“主设备”参数的取值为“LOCAL(本端为主设备)”。 | 重新执行该命令，确保输入的“割接状态”参数取值为“FALSE(FALSE)”时，“主设备”参数的取值为“REMOTE(远端为主设备)”。 |
| 275495 | CUTOVER参数配置为NONE时，ACTIVE参数必须配置为LOCAL。 | 输入的“割接状态”参数取值为“NONE(NONE)”时，“主设备”参数的取值为“REMOTE(远端为主设备)”。  | 重新执行该命令，确保输入的“割接状态”参数取值为“NONE(NONE)”时，“主设备”参数的取值为“LOCAL(本端为主设备)”。    |
