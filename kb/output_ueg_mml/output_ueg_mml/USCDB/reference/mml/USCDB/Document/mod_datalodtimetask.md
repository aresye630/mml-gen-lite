## 命令功能

**须知** 

- 该命令属于高危命令，执行该操作可能启动定时加载任务，会从第三方加载内存库数据，同时模块将定时重启。因此执行该命令前，需要与华为技术支持确认后才可以实施。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于对一个冷备USCDB从第三方服务器加载备份数据的定时加载任务的某些参数进行修改或调整。在该命令中，系统通过“FE类型”参数来唯一标识一个加载任务。

## 注意事项

- “UPGRADESTATUS（升级状态）”软参取值为“0”时，才允许设置“定时加载开关”为“ON”，打开定时加载功能。
- 数据加载过程中关掉定时加载任务时，对应的DSU、DRU和DSG模块会重启，上报12077 定时加载任务失败告警。
- 定时加载开始的时间不能配置为“夏令时跳变时间”，否则会存在DSG channel数据和DRU/DSU数据不匹配、当天重复加载或未加载的问题。

  **说明** 

  夏令时跳变时间：
  - 进入夏令时：假设在9点钟进入夏令时，时间会在9点时跳变为10点，9点到10点之间的时间为夏令时跳变时间。
  - 退出夏令时：假设在9点钟退出夏令时，时间会在9点时跳变为8点，8点到9点之间的时间为夏令时跳变时间。

## 参数说明

| 参数标识    | 参数名称                | 参数说明                                                                                                                                                                                                                        |
|:--------|:--------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FETYPE  | FE类型                | 可选必选说明：必选参数 参数含义：标识一条加载备份数据的定时加载任务的关键字段，用于指定需要对哪个FE类型的定时加载任务的参数进行修改。 取值范围：长度不超过128位字符组成的字符串。 默认值：无。 配置原则：此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。                                                                            |
| HOUR    | 定时加载开始的小时           | 可选必选说明：可选参数 参数含义：用于指定启动内存库定时加载的小时数。 取值范围：0~23。 默认值：无。 配置原则：无。                                                                                                                                                               |
| MINUTE  | 定时加载开始的分钟           | 可选必选说明：可选参数 参数含义：用于指定启动内存库定时加载的分钟数。 取值范围：0~59。 默认值：无。 配置原则：无。                                                                                                                                                               |
| FILELID | 定时加载源文件所属LocationID | 可选必选说明：可选参数 参数含义：用于指定需要获取的第三方服务器上备份文件对应的目标局点的LocationID。 取值范围：1~512。 默认值：无。 配置原则：备份文件的LocationID可以与本局的LocationID不一致。                                                                                                        |
| TIMEOUT | 定时加载超时周期            | 可选必选说明：可选参数 参数含义：用于指定单次加载的最大超时时长。如果在超时时长内未能从第三方加载，便上报12077 定时加载任务失败告警。 单位：分钟。 取值范围：60~240 默认值：120。 配置原则：无。                                                                                                                  |
| FILENUM | 第三方服务器上定时加载源文件最大份数  | 可选必选说明：可选参数 参数含义：用于指定第三方服务器上定时加载源文件的最大份数。下载备份文件时，进行老化删除管理。 取值范围：0~3 取值为“0”时，表示不对服务器文件进行管理。取值为非“0”时，会定时对下载的备份文件进行老化管理，并删除ADD RSFTPSERVER命令配置的“SFTP远端工作目录”参数或ADD RFTPSERVER命令配置的“FTP远端工作目录”参数指定目录下的非定时备份的其他文件。 默认值：3。 配置原则：无。 |
| SWITCH  | 定时加载开关              | 可选必选说明：可选参数 参数含义：用于指定本条配置数据是否启用。 取值范围： OFF(关)：不启用本条配置数据。ON(开)：启用本条配置数据。 默认值：无。 配置原则： 冷备USCDB接管期间必须修改为“OFF(关)”。冷备USCDB非接管期间必须修改为“ON(开)”。                                                                                     |

## 使用实例

修改一条“FE类型”为“SUP-FE”，“定时加载开始的小时”为“1”，“定时加载开始的分钟”为“10”，“定时加载源文件所属LocationID”为“1”，“加载超时时长”为“120”，“第三方服务器上定时加载源文件最大份数”为“3”，“定时加载开关”为“ON”的定时加载任务的“定时加载开始的小时”为“2”。

```
MOD DATALODTIMETASK: FETYPE="SUP-FE", HOUR=2, MINUTE=10, FILELID=1, TIMEOUT=120, FILENUM=3, SWITCH=ON;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                        | 原因分析                                               | 处理建议                                                                                                                               |
|-------:|:-----------------------------|:---------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------|
| 260616 | 指定的FETYPE未配置DATALODTIMETASK。 | 指定的“FE类型”未配置对应的定时加载任务。                             | 确认输入的“FE类型”是否为目标“FE类型”。 输入的“FE类型”是目标“FE类型”，执行ADD DATALODTIMETASK命令，添加指定“FE类型”对应的定时加载任务。输入的“FE类型”是不是目标“FE类型”，请输入正确的“FE类型”后，重新执行本命令。 |
| 260617 | 未配置第三方服务器。                   | “定时加载开关”取值为“ON”时，未配置第三方服务器。                        | 执行ADD RSFTPSERVER或ADD RFTPSERVER命令，新增第三方服务器后，重新执行本命令。                                                                              |
| 260618 | 至少需要选择一个可选项。                 | 未选择任何可选参数。                                         | 输入至少一个可选参数，重新执行本命令。                                                                                                                |
| 260619 | 升级状态软参为2时，不允许打开定时加载功能。       | “UPGRADESTATUS（升级状态）”软参取值为“2”，为升级状态，此时不允许打开定时加载功能。 | 请联系华为技术支持处理。                                                                                                                       |
