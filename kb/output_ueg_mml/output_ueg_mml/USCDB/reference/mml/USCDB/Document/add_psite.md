# 添加远端营帐配置(ADD PSITE)

## 命令功能

该命令用于在配置数据库中增加一条远端业务发放站点数据记录。

当系统需要对收到的业务发放系统指令（如开户、签约等）进行数据采集，用于分析用户数据的变化趋势或行为特点时，需要通过本命令增加远端业务发放站点数据。

业务发放系统指令通过系统向远端业务发放站点转发的过程如远端业务发放站点管理中的图1所示。

## 注意事项

- “业务场景”、“接口类型”、“本端provision端口”、“远端Partition ID”、“远端站点优先级”和“远端provision类型”六个参数都相同的记录只能添加一条。
- 不同的“远端Partition ID”，不能配置相同的非本地业务类型的“远端provision类型”。本地业务类型可以通过**LST FEPLUG**命令查询。
- 密码长期使用会增加被盗窃和破解的风险，而且使用的时间越长，被盗窃和破解的风险越高。定期修改密码可以有效防范这种情况的发生，因此强烈建议您定期修改密码。

## 使用实例

1. 某局点要求将业务发放指令转发到远端业务发放站点处理，需要进行如下操作：

   执行本命令增加远端业务发放站点数据。“Site ID”为“1”，“业务场景”为“PROV(业务发放)”，“接口类型”为“SOAP(SOAP接口)”，“IP类型”为“IPV4”，“远端provision IPV4”为“192.168.9.10”，“本端IPV4”为“192.168.9.11”，“远端provision端口”为“8001”，“远端provision类型”为“SUP-FE”，“连接数”为“1”，“远端Partition ID”为“1”，“远端站点优先级”为“1”，“系统HLR序列号”为“1”，“HLR序列号”为“1”，“操作员”为“admin”，“密码”为“\*\*\*\*\*”，“确认密码”为“\*\*\*\*\*”，“是否使用HTTPS”为“NO(否)”， “描述”为“Huawei HLR1”：

   ```
   ADD PSITE: SITEID=1, SRVSCENARIO=PROV, INTERFACE=SOAP, IPVER=IPV4, SITEIPV4="192.168.9.10", LOCALIPV4="192.168.9.11", SITEPORT=8001, SITEAPPTYPE="SUP-FE", LINKNUM=1, PARTITIONID=1, PRIORITY=1, SYSHLRSN=1, HLRSN=1, OPRNAME="admin", PWD="*****", CFM="*****", HTTPS=NO, DESCRIPTION="Huawei HLR1";
   ```

   **说明** 

   密码在命令行输入区域显示为\*\*\*\*\*。
2. 某HSS9860和IMS-HSS融合部署局点，业务发放系统指令转发到远端业务发放站点处理时，要求HSS9860的SOAP端口不使用头域鉴权，IMS-HSS的SOAP端口使用头域鉴权，故需要部署不同的“本端provision端口”来实现，需要进行如下操作：
   1. 执行本命令增加HSS9860的远端业务发放站点数据。“Site ID”为“1”，“业务场景”为“PROV(业务发放)”，“接口类型”为“SOAP(SOAP接口)”，“IP类型”为“IPV4”，“远端provision IPV4”为“192.168.9.10”，“本端IPV4”为“192.168.9.11”，“远端provision端口”为“8001”，“本端provision端口”为“8001”，“远端provision类型”为“HSS9860”，“连接数”为“1”，“远端Partition ID”为“1”，“远端站点优先级”为“1”，“系统HLR序列号”为“1”，“HLR序列号”为“1”，“操作员”为“admin”，“密码”为“\*\*\*\*\*”，“确认密码”为“\*\*\*\*\*”，“是否使用HTTPS”为“NO(否)”， “描述”为“Huawei HSS9860”：

      ```
      ADD PSITE: SITEID=1, SRVSCENARIO=PROV, INTERFACE=SOAP, IPVER=IPV4, SITEIPV4="192.168.9.10", LOCALIPV4="192.168.9.11", SITEPORT=8001, LOCALPORT=8001, SITEAPPTYPE="HSS9860", LINKNUM=1, PARTITIONID=1, PRIORITY=1, SYSHLRSN=1, HLRSN=1, OPRNAME="admin", PWD="*****", CFM="*****", HTTPS=NO, DESCRIPTION="Huawei HSS9860";
      ```

      **说明** 

      密码在命令行输入区域显示为\*\*\*\*\*。
   2. 执行本命令增加IMS-HSS的远端业务发放站点数据。“Site ID”为“1”，“业务场景”为“PROV(业务发放)”，“接口类型”为“SOAP(SOAP接口)”，“IP类型”为“IPV4”，“远端provision IPV4”为“192.168.9.10”，“本端IPV4”为“192.168.9.11”，“远端provision端口”为“8003”，“本端provision端口”为“8003”，“远端provision类型”为“HSS9860”，“连接数”为“1”，“远端Partition ID”为“1”，“远端站点优先级”为“1”，“系统HLR序列号”为“1”，“HLR序列号”为“1”，“操作员”为“admin”，“密码”为“\*\*\*\*\*”，“确认密码”为“\*\*\*\*\*”，“是否使用HTTPS”为“NO(否)”， “描述”为“Huawei IMS”：
