## 命令功能

该命令用于加载IDP端（即网管）的元数据。

当PGW Web LMT使用SSO（Single Sign On）功能时，需要使用该命令加载IDP端的元数据。

## 注意事项

在执行本命令前，需先从IDP端下载元数据文件，然后通过OM Portal的文件传输功能上传到CGPLite容器的“CGPLite文件 > 网元文件”文件夹内。上传方法请参考产品手册“GUI参考 > 文件传输”。

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                 |
|:-------------|:-------|:---------------------------------------------------------------------|
| METADATANAME | 元数据名称  | 可选必选说明：必选参数 参数含义：用于指定待加载的元数据文件名称。 取值范围：长度不超过128位的字符串。 默认值：无。 配置原则：无。 |

## 使用实例

加载元数据，“元数据名称”为“idp\_metadata.xml”：

```
LOD SSOMETADATA: METADATANAME="idp_metadata.xml";
```

## 参考信息

- SSO（Single Sign-On）：单点登录，是目前比较流行的服务于企业业务整合的解决方案之一，SSO使得在多个应用系统中，用户只需要登录一次，就可以访问所有相互信任的应用系统。
- 基于SAML 2.0（Security Assertion Markup Language 2.0，安全断言标记语言）协议实现的SSO登录，由IDP和SP组成，以实现在不同的安全域之间交换认证和授权数据。
  - SP（Service Provider）：向用户提供正式商业服务的实体，通常需要认证一个用户的身份。
  - IDP（Identity Provider）：提供用户的身份鉴别，确保用户是其所声明的身份。

  PGW Web LMT实现SSO单点接入功能，是以PGW Web LMT作为SP端，网管作为IDP端。
