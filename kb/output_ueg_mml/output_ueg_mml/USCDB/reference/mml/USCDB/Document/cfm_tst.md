## 命令功能

本命令用于确认试运行。试运行被确认后该网元转入正常模式运行，当前事务内执行的配置命令永久性生效。

试运行是OMU的一种运行模式，事务提交后OMU自动进入该模式，此时主机网元暂时按照事务提交的新配置数据运行，用户可以在这种模式下验证配置数据的正确性，如果对运行结果满意就可以通过本命令使网元进入正常模式；如果不满意就可以通过回退操作回退到事务提交以前的状态。用户无法手动进入试运行模式。

本命令的使用场景为：事务模式下进行的配置数据正确，结果符合预期时，可以使用本命令使事务内的配置永久性生效。

有关“试运行”与“事务”的关系请参见**CMT TRAN**命令的相关解释。

## 注意事项

- 确认试运行状态后，提交的数据在系统中永久生效。
- 在进入试运行模式后，若到达超时时间后（默认为24小时）仍未确认试运行，系统将视为超时，用户在进入事务模式后的所有操作将自动提交。系统在超时前五分钟将会上报告警。
- 确认试运行后，系统自动进入正常模式。

## 参数说明

无。

## 使用实例

确认试运行：

```
CFM TST:;
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，请联系华为技术支持处理。
