# 删除FTP用户(RMV FTPUSER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，删除FTP用户会造成该FTP用户失效。因此执行该命令前，需要与华为技术支持确认后才可以实施。

当用户不再需要通过FTP与PGW、DMA交互，使用该命令删除FTP用户。

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                              |
|:---------|:-------|:------------------------------------------------------------------|
| USERTYPE | 用户类型   | 标识一个FTP用户信息的关键字段之一。用于指定删除哪一种类型的FTP用户的配置信息。操作员可以使用LST FTPUSER查询获取。 |
| USERNAME | 用户名    | 标识一个FTP用户信息的关键字段之一。用于指定删除哪个FTP用户的配置信息。操作员可以使用LST FTPUSER查询获取。     |

## 使用实例

删除FTP用户，“用户类型”为“PROV”、“用户名”为“test1”:

```
RMV FTPUSER: USERTYPE=PROV, USERNAME="test1";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释   | 原因分析                  | 处理建议                               |
|-------:|:--------|:----------------------|:-----------------------------------|
| 256034 | 记录不存在。  | 执行该命令删除的“用户名”在系统中不存在。 | 执行LST FTPUSER命令查询已存在的用户名，再执行本命令删除。 |
