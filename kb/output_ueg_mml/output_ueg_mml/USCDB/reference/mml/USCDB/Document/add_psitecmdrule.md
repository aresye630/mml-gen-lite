# 添加PSITE参数过滤规则配置(ADD PSITECMDRULE)

- 参数说明

- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，该操作将添加PSITE参数过滤规则配置，操作不当会导致转发到远端的命令执行失败。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于添加PSITE参数过滤规则的配置。

在营帐双发场景下，本端PGW根据该命令配置的过滤规则删除指定命令的参数后再转发到远端业务发放站点。

## 注意事项

- PSITE参数过滤规则配置最多只能添加1024个。
- 系统只能存在一个“Site ID”和“命令名称”均相同的配置。

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                             |
|:--------|:--------|:---------------------------------------------------------------------------------------------------------------------------------|
| SITEID  | Site ID | 可选必选说明：必选参数 参数含义：用于唯一标识一个远端业务发放站点。该参数先由ADD PSITE命令定义，然后才能在此处引用。 取值范围：1～1024 默认值：无。 配置原则：无。                                       |
| CMDNAME | 命令名称    | 可选必选说明：必选参数 参数含义：用于指定PSITE参数过滤规则中的命令名称。 取值范围：长度为1~32个字符的字符串，字符串只能由数字（0～9）、大写英文字母（A～Z）、空格和下划线组成，必须以字母开头且末尾字符不能为空格。 默认值：无。 配置原则：无。 |
| TYPE    | 参数类型    | 可选必选说明：必选参数 参数含义：用于指定PSITE参数过滤规则中需要过滤的参数类型。 取值范围：WHITE(白名单)BLACK(黑名单) 默认值：无。 配置原则：无。                                             |
| CMDPARA | 命令参数    | 可选必选说明：必选参数 参数含义：用于指定PSITE参数过滤规则中需要过滤的命令参数。 取值范围：长度不超过2048个字符的字符串，字符串只能由数字（0～9）、大写英文字母（A～Z）、&和下划线组成，多个参数之间使用&符分隔。 默认值：无。 配置原则：无。 |

## 使用实例

添加一条PSITE参数过滤规则配置，“Site ID”为“5”，“命令名称”为“ADD ALLTYPE\_SUB1\_INFO5\_TPL”，“参数类型”为“WHITE(白名单)”，“命令参数”为“USCSN&SUB1\_INFO5\_TPL\_ID”：

```
ADD PSITECMDRULE: SITEID=5, CMDNAME="ADD ALLTYPE_SUB1_INFO5_TPL", TYPE=WHITE, CMDPARA="USCSN&SUB1_INFO5_TPL_ID";
```
