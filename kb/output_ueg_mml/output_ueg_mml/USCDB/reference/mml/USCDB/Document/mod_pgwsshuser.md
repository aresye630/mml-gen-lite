# 修改PGW SSH用户(MOD PGWSSHUSER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，修改PGW SSH用户会造成营帐连接异常。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对数据库中的一条SSH用户数据记录进行修改或调整。在该命令中，系统通过“USERNAME”来唯一标识一条用户数据记录。

## 注意事项

- 如果修改的是用户的密码，则参数“旧密码”、“新密码”和“确认密码”必须都指定。
- 该命令不允许进行批操作。
- 密码长期使用会增加被盗窃和破解的风险，而且使用的时间越长，被盗窃和破解的风险越高。定期修改密码可以有效防范这种情况的发生，因此强烈建议您定期修改密码。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                |
|:------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USERNAME    | 用户名     | 用于指定通过SSH登录的用户名。 取值范围：长度不超过31的字符串                                                                                                                                                                                                                                                   |
| OLD         | 旧密码     | 用于指定旧密码。 取值范围：长度不超过30的字符串。                                                                                                                                                                                                                                                          |
| PWD         | 新密码     | 用于指定通过SSH登录的用户的密码。 取值范围：符合密码复杂度的字符串。密码区分大小写，其复杂度需同时满足下列条件： 密码必须至少包含以下四个类别中的三类：英文大写字母英文小写字母数字：0～9特殊字符：~ ! # % ^ * ( ) _ - + [ ] { } | < > . ？ 不允许使用三个或三个以上连续的字母或数字（例如：ABC、123）。密码不能和用户名或者用户名的逆序一样，且不能包含用户名或者用户名的逆序。不允许使用三个或三个以上连续的相同字符（例如：AAA、111）。密码长度最短8个字符，最长30个字符。密码的第一个字符必须是字母。 |
| CFM         | 确认密码    | 用于指定通过SSH登录的用户的确认密码，该字符串必须与新密码相同。 取值范围：符合密码复杂度的字符串。                                                                                                                                                                                                                                 |
| PORT        | PGW服务端口 | 用于指定PGW与SSH连接的服务端口（其中SSH连接使用的端口号是22）。“PGW服务端口”可以通过LST PORT命令查询获得，使用“端口类型”为“PORT_FOR_PROV”，“端口子类型”为“PORT_FOR_MML”对应的端口作为“PGW服务端口”。 取值范围：0～65535                                                                                                                                      |
| DESCRIPTION | 用户描述    | SSH用户的描述信息。 取值范围：长度不超过64的字符串                                                                                                                                                                                                                                                        |

## 使用实例

1. 修改SSH用户，“用户名”为“sshuser”，“旧密码”为“ab12CD34!56”，“密码”为“ab12CD34#56”，“确认密码”为“ab12CD34#56”，“PGW服务端口”为“7776”，“用户描述”为“user info”。

   ```
   MOD PGWSSHUSER: USERNAME="sshuser", OLD="*****",PWD="*****", CFM="*****", PORT=7776, DESCRIPTION="user info";
   ```

**说明** 

- 密码在命令行输入区域显示为\*\*\*\*\*。
- 执行本命令时，若“密码”取值为样例中的弱口令“ab12CD34#56”，执行结果会返回“260566”错误码。
