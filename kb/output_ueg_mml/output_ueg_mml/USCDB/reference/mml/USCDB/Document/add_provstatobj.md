# 增加业务发放统计对象(ADD PROVSTATOBJ)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于添加一个业务发放的统计对象，用于跟踪业务发放命令的执行情况，如：成功次数、失败次数等。

## 注意事项

最多增加512个业务发放统计对象。

## 参数说明

| 参数标识            | 参数名称       | 参数说明                                                                                                                       |
|:----------------|:-----------|:---------------------------------------------------------------------------------------------------------------------------|
| PROVSTATOBJID   | 业务发放统计对象索引 | 用于指定业务发放统计对象的索引号，全局唯一。 取值范围：1～512 默认值：无。                                                                                   |
| PROVSTATOBJNAME | 业务发放统计对象名称 | 用于指定业务发放统计对象的名称，全局唯一。 该参数将在ADD PROVSTATRULE命令中被索引。 取值范围：长度不超过127位的字符串，字符串只能由数字（0～9）、英文字母（A～Z和a～z）、空格和下划线组成，必须以字母开头。 默认值：无。 |

## 使用实例

某局点需要统计业务发放命令中**ADD PSUB**的执行情况，配置方式如下：

1. 参考如下命令，添加业务发放统计对象。

   ```
   ADD PROVSTATOBJ: PROVSTATOBJID=1, PROVSTATOBJNAME="Example_1123";
   ```
2. 参考如下命令，在对象中添加需要统计的**ADD PSUB**命令。

   ```
   ADD PROVSTATRULE: PROVSTATOBJNAME="Example_1123", CMDNAME="ADD PSUB";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释            | 原因分析                    | 处理建议                                                                                                                                 |
|-------:|:-----------------|:------------------------|:-------------------------------------------------------------------------------------------------------------------------------------|
| 274579 | 业务发放统计对象索引号已经存在。 | “业务发放统计对象索引号”全局唯一，不能重复。 | 执行LST PROVSTATOBJ命令查询已存在的“业务发放统计对象索引号”，重新执行本命令添加新的“业务发放统计对象索引号”，确保新添加的“业务发放统计对象索引号”与查询到的不重复。                                         |
| 274580 | 业务发放统计对象名称已经存在。  | “业务发放统计对象名称”不能重复。       | 执行LST PROVSTATOBJ命令查询已存在的“业务发放统计对象名称”，重新执行本命令添加新的“业务发放统计对象名称”，确保新添加的“业务发放统计对象名称”与查询到的不重复。                                            |
| 274581 | 业务发放统计对象达到最大记录数。 | 最多只能添加513个业务发放统计对象。     | 执行LST PROVSTATOBJ命令查询已添加的业务发放统计对象。 若所需的业务发放统计对象已添加，请直接使用。若所需的业务发放统计对象未添加，请先执行RMV PROVSTATOBJ命令删除不需要的业务发放统计对象，再重新执行本命令添加所需要的业务发放统计对象。 |
