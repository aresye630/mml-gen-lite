# 修改DSG链路中心(MOD DSGLINKCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改DSG链路中心。

## 注意事项

- 通过“校验码”参数指定的本端链路中心的校验码，必须与在远端网元执行**ADD RDSGLINKCTRL**或**MOD RDSGLINKCTRL**指定的校验码一致，否则会导致本网元无法接收该远端的配置信息。
- 由于USCDB网元是链路中心的服务端，本命令配置的“校验码”参数检查在USCDB网元侧进行，因此需要先执行本命令配置本端链路中心的“校验码”，再到FE网元侧执行**ADD RDSGLINKCTRL**或**MOD RDSGLINKCTRL**命令配置相同取值的“校验码”参数，或者到FE网元侧执行**ADD DBSLINKCTRL**或**MOD DBSLINKCTRL**命令配置相同取值的“本地链路中心校验码”参数。

  **说明** 

  本命令禁止配置的“校验码”可以通过**ADD WEAKPWD**命令配置或通过**LST WEAKPWD**命令查询。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                        |
|:-------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MID    | 模块号      | 用于指定网元的DSG模块号。DSG模块号先由ADD MODULE命令定义，然后才能在此处索引。 取值范围：1～2047 默认值：无。                                                                                                                                                                                                                          |
| IPVER  | IP类型     | 用于指定IP地址类型。 取值范围： IPV4：当系统要求使用IPv4类型的IP地址时选择此选项。IPV6：当系统要求使用IPv6类型的IP地址时选择此选项。 默认值：无。                                                                                                                                                                                                       |
| IPV4   | 本端IPV4地址 | 用于指定IPV4类型的本地IP地址。 目前版本当参数“IP类型”设置为“IPV4(IPV4)”时，此参数才有效。 本端IP地址先由ADD SRVIPADDR命令定义，然后才能在此处索引。 取值范围：IPV4格式的地址。 默认值：无。  须知： 对于不同业务类型的DSG，执行该命令时，此参数的取值必须不同。                                                                                                                                   |
| IPV6   | 本端IPV6地址 | 用于指定IPV6类型的本地IP地址。目前版本当参数“IP类型”设置为“IPV6(IPV6)”时，此参数才有效。格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如：2001:DB8:8432:4098:4782:5784::。 本端IP地址先由ADD SRVIPADDR命令定义，然后才能在此处索引。 取值范围：IPV6格式的地址。 默认值：无。  须知： 对于不同业务类型的DSG，执行该命令时，此参数的取值必须不同。                                                     |
| SHAKEY | 校验码      | 用于指定本端链路中心的校验码。 取值范围：符合校验码复杂度的字符串。 校验码区分大小写，其复杂度需同时满足下列条件：必须至少包含以下四个类别中的三类：英文大写字母。英文小写字母。数字：0～9。特殊字符：~ ! # % ^ * ( ) _ - + [ ] { } | < > . ?。 不允许使用三个或三个以上连续的字母或数字（例如：ABC、123）。不允许使用三个或三个以上连续的相同字符（例如：AAA）。长度最短8个字符，最长30个字符。第一个字符必须是字母。不能和账号（即“unusedNmae”）或者账号的逆序一样，且不能包含账号或者账号的逆序。 默认值：无。 |

## 使用实例

修改DSG链路中心的IP地址，“模块号”为“52”，“IP类型”为“IPV4”，“本端IPV4地址”为“10.14.39.32”。命令示例如下：

```
MOD DSGLINKCTRL: MID=52, IPVER=IPV4, IPV4="10.14.39.32";
```
