# 显示增量营帐日志操作任务状态(DSP INCREASEPROREC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示增量营帐日志查询任务和批处理操作任务状态。增量营帐日志即局点升级期间执行的营帐命令。

在数据紧急修复场景，当执行**STR INCREASEPROREC**命令启动增量营帐日志操作任务时，可以通过本命令查看增量营帐日志查询任务和批处理操作任务状态。

## 注意事项

当不存在营帐日志操作任务时，执行该命令会报错。需要先执行**STR INCREASEPROREC**命令启动增量营帐日志操作任务，再通过该命令查看增量营帐日志查询任务和批处理操作任务状态。

## 参数说明

无。

## 使用实例

显示增量营帐日志查询任务和批处理操作任务状态。执行如下命令：

```
DSP INCREASEPROREC:;
```

```
%%DSP INCREASEPROREC:;%%
RETCODE = 0  操作成功

操作结果如下
------------------------
                任务标示  =  1
增量营帐日志查询任务状态  =  完成
      批处理操作任务状态  =  未开始
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1。

| 输出项名称        | 输出项解释                                                                   |
|:-------------|:------------------------------------------------------------------------|
| 任务标示         | 用于返回当前执行的增量营帐日志任务ID。                                                    |
| 增量营帐日志查询任务状态 | 用于返回增量营帐日志查询任务状态： 未开始：表示任务尚未运行。 执行中：表示任务正在执行。 完成：表示任务执行完成。 失败：表示任务执行失败。 |
| 批处理操作任务状态    | 用于返回批处理操作任务状态： 未开始：表示任务尚未运行。 执行中：表示任务正在执行。 完成：表示任务执行完成。 失败：表示任务执行失败。    |
