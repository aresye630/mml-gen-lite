# 启动恢复远端Partition的数据(STR RPRESTORE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

- 该命令属于高危命令，该操作可能会导致业务中断。因此执行该命令前，需要与华为技术支持确认后才可以实施。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于Global Local 2.0组网场景下，从Global BE恢复Local BE的数据。

## 注意事项

- 该命令仅支持在Global BE主用局执行，参数“远端Partition标识”是指Local BE的Partition标识。
- 对同一个Local BE的恢复任务只能串行执行该命令，如果上一条命令未执行完成，重复执行该命令，则返回错误。
- 重启全局DRU时，该命令执行会中断。

## 参数说明

| 参数标识         | 参数名称          | 参数说明                                                                                                               |
|:-------------|:--------------|:-------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE  | 业务类型          | 可选必选说明：必选参数 参数含义：用于指定恢复哪个业务类型的远端Partition数据。 取值范围：长度不超过128的字符串 默认值：无。 配置原则：此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。 |
| RPARTITIONID | 远端Partition标识 | 可选必选说明：必选参数 参数含义：用于指定恢复哪个远端Partition的数据。 取值范围：1～250 默认值：无。 配置原则：该参数通过ADD RPARTITION配置后在此引用。                        |

## 使用实例

Global Local 2.0组网场景下启动恢复远端Partition的数据，“业务类型”为“SUP-FE”，“远端Partition标识”为“1”：

```
STR RPRESTORE: SERVICETYPE="SUP-FE", RPARTITIONID=1;
```
