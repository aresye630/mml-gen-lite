# 修改PGW业务消息侦听端口(MOD PORT)

- 命令功能

- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，修改正在使用的端口会造成PGW无法处理来自此端口的业务发放消息。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改PGW使用的相关端口。在该命令中，系统通过以下关键参数的组合来唯一标识一条端口记录：

- “端口号”
- “端口类型”
- “端口子类型”

## 注意事项

- 当本命令仅修改参数“是否屏蔽本端口”时，命令执行后修改结果可以立即生效，避免系统因重启PGW进程对业务造成影响；如果修改其他参数，则必须通过**RST MODULE**命令重启所有PGW模块才能生效。
- 对于通过**ADD PORT**命令增加的自定义SOAP、MML端口，则其端口号不能修改；如果是默认端口，则其端口号可以修改。例如：对于默认端口80，保持其他参数不变的情况下，把端口号修改为81。
- 用户在修改PGW开放给业务发放系统的MML默认端口的信息时，不能修改对应的握手类型配置。即：当参数“端口子类型”取值为“PORT\_FOR\_MML”，同时“端口业务类型”取值为“USCDB”时，不能修改参数“端口的握手类型”、“端口的握手内容”、“握手消息长度”和“是否连接立即发送握手消息”的取值。
- 当参数“端口子类型”取值为“PORT\_FOR\_HTTP”时，只能修改“是否屏蔽本端口”和“是否使用HTTPS”的取值。
- 当执行此命令返回“原端口已被PGWSSHUSER使用”错误时，请通过**LST PORT**命令查询被使用的端口，其中参数“端口类型”、“端口子类型”和“端口业务类型”的取值与**MOD PORT**命令中的参数值保持一致。然后再通过**LST PGWSSHUSER**命令检查该端口是否已经被使用。
- 配置参数“PORTTYPENAME”应注意以下内容：
  - 取值为“PORT\_FOR\_SOAP”时，使用的SOAP端口使用协议类型，基于**“TLSMODE（TLS工作模式）”**软参控制。**“TLSMODE（TLS工作模式）”**软参默认值“3”，系统推荐使用TLS，即使用HTTPS协议，提高通信传输的安全性。
  - 取值为“PORT\_FOR\_LMT\_MML”或“PORT\_FOR\_MML”时，使用的MML端口推荐开启SSH安全通道，通过**ADD PGWSSHUSER**命令添加SSH用户，从而实现业务发放系统通过SSH加密的方式和PGW交互，提高通信传输的安全性。
  - 取值为“PORT\_FOR\_REST”、“PORT\_FOR\_MML”或“PORT\_FOR\_LMT\_MML”时，参数“是否使用HTTPS”建议使用默认值“YES”，即使用安全性较高的HTTPS协议，HTTP协议是不安全的协议，存在传输信息泄露的风险。
  - 取值为“PORT\_FOR\_REST”时，参数“是否使用头域鉴权”默认值为“NO”，为提升安全性，建议修改为“YES”，即PGW对业务发放系统发送过来的REST消息的头域中携带的登录信息进行登录鉴权。
  - 取值为“PORT\_FOR\_HTTP”时，使用的HTTP端口协议类型，参数“是否使用HTTPS”建议使用默认值“YES”，即使用安全性较高的HTTPS协议，HTTP协议是不安全的协议，存在传输信息泄露的风险。
- 该命令不允许进行批操作。
- 当修改PGW业务消息侦听端口时，如果软参“SSHSFTPSRVSEPARATION”的取值为“1”（执行**LST INSP**命令查看软参“SSHSFTPSRVSEPARATION”的取值是否为“1”。），则此时“端口号”参数取值不能为“20022”，否则会修改失败，并返回错误码275435。

## 参数说明

| 参数标识         | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|:-------------|:-------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PORTNO       | 端口号          | 用于指定要修改的PGW开放给业务发放系统和Web LMT使用的端口的编号。 取值范围： 当参数“端口类型”为“PORT_FOR_WEBLMT”时，端口号取值范围为：1～65534。 当参数“端口类型”为“PORT_FOR_PROV”时，端口号取值范围为：1～65535，建议端口范围为1025～65535。 当参数“端口类型”为“PORT_FOR_DMSWEB”时，端口号取值范围为：1025～65535。                                                                                                                                                                                                                                |
| PORTTYPE     | 端口类型         | 用于指定PGW开放的端口类型。 取值范围： PORT_FOR_WEBLMT：表示PGW开放给Web LMT使用的端口。PORT_FOR_PROV：表示PGW开放给业务发放系统使用的端口。PORT_FOR_DMSWEB：表示PGW开放给DMS WebUI使用的端口。                                                                                                                                                                                                                                                                                                       |
| PORTTYPENAME | 端口子类型        | 用于指定PGW开放给业务发放系统的端口的具体类型。 取值范围： PORT_FOR_CLIENT：表示PGW开放给Web LMT Server客户端的端口。 PORT_FOR_LMT_MML：表示PGW开放给Web LMT Server的MML端口。 PORT_FOR_REDIRECT：表示PGW开放给Web LMT Server客户端重定向的端口。 PORT_FOR_SOAP：表示PGW开放给业务发放系统的SOAP端口。 PORT_FOR_MML：表示PGW开放给业务发放系统的MML端口。 PORT_FOR_DMSWEB：表示PGW开放给DMS WebUI使用的端口。PORT_FOR_REST：表示PGW开放给业务发放系统的REST服务端口。PORT_FOR_HTTP：表示PGW开放给业务发放系统的HTTP端口。                                                                  |
| DISABLEPORT  | 是否屏蔽本端口      | 用于控制是否对端口进行屏蔽。当某端口暂时不需要使用时，为了保证网络安全（例如防止第三方利用端口对系统发起攻击等）可以选择“YES”进行屏蔽。 当参数“端口子类型”取值为“PORT_FOR_LMT_MML”、“PORT_FOR_SOAP”、“PORT_FOR_MML”、“PORT_FOR_HTTP”、“PORT_FOR_REST”、“PORT_FOR_CLIENT”或“PORT_FOR_DMSWEB”时，此参数有效。 取值范围：YES(是)：系统对此端口进行屏蔽，被屏蔽后端口失效。 NO(否)：系统不对此端口进行屏蔽，端口可正常工作。  说明： 当参数“端口子类型”取值为“PORT_FOR_CLIENT”时，此参数设置为“YES”会使PGW WebLMT服务不可用；此参数设置为“NO”，服务恢复。当参数“端口子类型”取值为“PORT_FOR_DMSWEB”时，此参数设置为“YES”会使DMS Web服务不可用；此参数设置为“NO”，服务恢复。 |
| PORTBUSSTYPE | 端口业务类型       | 用于指定PGW开放给业务发放系统的端口对应的业务类型。当前支持通过该命令添加FE类型和USCDB类型的端口业务类型： 当添加FE类型的端口业务类型时，此参数需通过LOD FEPLUG命令加载对应的FE插件包后才能在此进行设置。当需要接入无插件包的ENS/UIM/MNP/EIR应用类型的营帐系统，参数“端口子类型”取值为“PORT_FOR_SOAP”或“PORT_FOR_MML”时，可选择添加“USCDB”类型的端口业务类型。 当参数“端口类型”为“PORT_FOR_PROV”并且“端口子类型”为“PORT_FOR_SOAP”、“PORT_FOR_MML”、或“PORT_FOR_HTTP”、“PORT_FOR_REST”时此参数有效且必须配置。该参数必须与通过PGW开放给业务发放系统的FE类型保持一致。 取值范围：长度不超过128字节的字符串                                                    |
| PORTSHKTYP   | 端口的握手类型      | 用于指定PGW与业务发放系统之间的握手类型。 当参数“端口子类型”为“PORT_FOR_MML”时此参数有效。 取值范围：NORMAL：表示PGW和业务发放系统互相发送握手消息。RCVONLY：表示PGW只接收来自业务发放系统的握手消息，但不向业务发放系统发送握手消息。RESPONSE：表示PGW接收来自业务发放系统的握手消息，并向业务发放系统发送它刚接收到的握手消息。RSPWITHRPT：表示PGW接收来自业务发放系统的握手消息，并以MML消息格式向业务发放系统发送握手消息。                                                                                                                                                                                          |
| PORTCONTENT  | 端口的握手内容      | 用于指定PGW与业务发放系统之间的握手消息内容。 当参数“端口子类型”为“PORT_FOR_MML”时此参数有效且必须配置。 取值范围： SHK-HND：表示PGW与客户端握手消息内容为SHK-HND。 SHK-HAND：表示PGW与客户端握手消息内容为SHK-HAND。                                                                                                                                                                                                                                                                                                   |
| SHKLEN       | 握手消息长度       | 用于指定系统与业务发放系统之间的握手消息的长度。握手消息的长度为9个字节或10个字节。 当“端口的握手内容”为“SHK-HND”时此参数有效。 该参数的配置原则是：此参数需要和对端的业务发放系统所使用的握手消息长度保持一致。 取值范围：9～10                                                                                                                                                                                                                                                                                                                 |
| SNDSHKIMM    | 是否连接立即发送握手消息 | 用于控制在PGW与业务发放系统之间的连接建立之后是否立即发送握手消息。 当“端口的握手类型”为“NORMAL”时此参数有效。此参数需要和对端的业务发放系统所使用的发送设置保持一致。 取值范围： SNDIMMEDIATELY：立即发送握手消息。SNDDELAY：延迟20秒发送握手消息。SNDONCEONLY：只发送一次握手消息。                                                                                                                                                                                                                                                                       |
| HEADERAUTH   | 是否使用头域鉴权     | 用于控制当与业务发放系统通过SOAP或REST端口进行连接时，PGW是否对业务发放系统发送过来的SOAP或REST消息的头域中携带的登录信息进行登录鉴权。 当参数“端口子类型”为“PORT_FOR_SOAP”或“PORT_FOR_REST”时此参数有效。此参数需要根据对端的业务发放系统的要求进行设置。 取值范围： YES：PGW需要对SOAP或REST消息头域中携带的登录信息进行鉴权。NO：PGW不需要对SOAP或REST消息头域中携带的登录信息进行登录鉴权。  说明： 仅当软参“PROVRIGHTSWITCH（营帐权限开关）”为“1”，并且执行RST MODULE命令重启所有PGW模块后，此参数为“YES”才生效。当“端口子类型”取值为“PORT_FOR_SOAP”且“端口业务类型”取值为“USCDB”时，该功能不生效。                                                             |
| RETURNHEADER | 是否返回头域       | 用于控制当与业务发放系统通过SOAP端口进行连接时，PGW是否在返回给业务发放系统的SOAP响应消息中携带头域信息。 当参数“端口子类型”为“PORT_FOR_SOAP”时此参数有效。此参数需要根据对端的业务发放系统的要求进行设置。 取值范围： YES：在SOAP响应消息中返回头域信息。NO：在SOAP响应消息中不返回头域信息。  说明： 此参数配置为“YES”时需要配合参数“是否使用头域鉴权”和软参“PROVRIGHTSWITCH（营帐权限开关）”使用。当参数“是否使用头域鉴权”为“YES”，且软参“PROVRIGHTSWITCH（营帐权限开关）”为“1”时，并且执行RST MODULE命令重启所有PGW模块后，此参数为“YES”才生效。当“端口子类型”取值为“PORT_FOR_SOAP”且“端口业务类型”取值为“USCDB”时，该功能不生效。                                                 |
| HTTPS        | 是否使用HTTPS    | 仅当本命令中的“端口子类型”参数选择为“PORT_FOR_REST”、“PORT_FOR_HTTP”、“PORT_FOR_MML”或“PORT_FOR_LMT_MML”时该参数有效，用于设置REST端口、HTTP端口或MML端口是否使用HTTPS协议。 取值范围：YES：使用HTTPS协议。NO：使用HTTP协议。  说明： 如果该参数取值为“NO(否)”，即使用HTTP协议，会上报ALM-10031 系统存在不安全的配置项告警。                                                                                                                                                                                                                  |
| HTTPVER      | HTTP协议版本     | 仅当本命令中的“端口子类型”参数选择为“PORT_FOR_REST”时该参数有效，用于设置REST端口的HTTP协议版本。 取值范围： HTTP1.1HTTP2.0                                                                                                                                                                                                                                                                                                                                                         |
| FWDPORT      | 是否转发端口       | 可选必选说明：可选参数，当“端口子类型”取值为“PORT_FOR_SOAP”或“PORT_FOR_MML”时，该参数显示。 参数含义：该参数标识当前修改的PGW端口是否为转发端口。 取值范围： YES(是)：标识当前修改的端口是转发端口。NO(否)：标识当前修改的端口是非转发端口。 默认值：NO(否) 配置原则：当需要修改端口的配置信息时，需要执行LST PORT命令查询需要修改的端口的配置信息，该参数的取值需要和查询到的“是否转发端口”取值一致。不允许将转发端口修改为非转发端口或者将非转发端口修改为转发端口。                                                                                                                                                                         |
| REPORTCUSTOM | 转发端口定制报文     | 仅当本命令中的“端口业务类型”为“USCDB”并且“端口子类型”为“PORT_FOR_MML”时该参数有效，用于定制USCDB转发端口的输出报文。 取值范围：长度不超过256字节的字符串 默认值：无  说明： 该参数取值可以由多个“项:值|项:值|项:值|项:值”组成，项与项之间通过“|”分隔，项与值之间通过“:”分隔。参数取值样例如下：“PHEAD:+++ SPS |MHEAD:O&M |CONTAINPWD:true|PWDMARK:PASSWORD|RETCODE:false|TAILEND:--- END”。请联系华为技术支持并在技术支持人员指导下配置该参数。在LST PORT命令的输出报文中，该参数取值的所有"+"会被转义为"\+"，所有"-"会被转义为"\-"，即"+++"转义为"\+\+\+"，"---"转义为"\-\-\-"。                                                   |

## 使用实例

1. 修改端口信息并且修改“是否屏蔽本端口”属性：

   执行本命令修改“端口号”为“7775”的端口，将其“是否屏蔽本端口”参数修改为“YES”。

   ```
   MOD PORT: PORTNO=7775, PORTTYPE=PORT_FOR_PROV, PORTTYPENAME=PORT_FOR_MML, DISABLEPORT=YES, PORTBUSSTYPE="SUP-FE";
   ```
2. 修改端口信息但不修改“是否屏蔽本端口”属性：

   1. 修改PGW提供的SOAP默认端口号，将其“是否使用头域鉴权”参数的值改为“YES”，将其“是否返回头域”参数的值改为“YES”：

      ```
      MOD PORT: PORTNO=8001, PORTTYPE=PORT_FOR_PROV, PORTTYPENAME=PORT_FOR_SOAP, PORTBUSSTYPE="USCDB", HEADERAUTH=YES, RETURNHEADER=YES;
      ```
   2. 执行**RST MODULE**命令重启PGW进程使配置生效。
