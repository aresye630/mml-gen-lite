# 查询节点的配置信息(LST NODE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

用于查询Pod上节点的配置信息。

查询模块配置的相关方法如下：

- 若需要查询所有节点的配置信息，请不要输入任何参数。
- 若需要查询所有节点中符合某一参数条件的节点时，请在对应参数中输入对应的参数值。如：需要查询业务类型为USCDB的Cluster时，请在参数“业务类型”中选择对应的参数值“USCDB”。
- 若需要查询所有Cluste中符合多个参数条件的模块时，请在对应的多个参数中输入对应的参数值。如：需要查询Cluster类型为DRU且业务类型为SUP-FE的Cluster时，请在参数“Cluster类型”中选择对应的参数值“DRU(DRU)”，参数“业务类型”中选择对应值“SUP-FE”。

  **说明** 

  SUP-FE为一个举例的名称，请根据实际的查询情况选择对应的业务类型。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                             |
|:------------|:----------|:-------------------------------------------------------------------------------------------------|
| CID         | Cluster标识 | 用于指示系统需要按照哪个Cluster标识来查询节点的配置信息。 若输入该参数时，系统查询Cluster标识等于该参数值的节点的配置信息。 若不输入该参数时，则表示该参数不作为查询的限制条件。 |
| NID         | 节点标识      | 用于指示系统需要按照哪个节点标识来查询节点的配置信息。 若输入该参数时，系统查询Cluster标识等于该参数值的节点的配置信息。 若不输入该参数时，则表示该参数不作为查询的限制条件。      |
| MID         | 模块号       | 用于指示系统需要按照哪个模块号来查询节点的配置信息。 若输入该参数时，系统查询Cluster标识等于该参数值的节点的配置信息。 若不输入该参数时，则表示该参数不作为查询的限制条件。       |
| CT          | Cluster类型 | 用于指示系统需要按照哪个Cluster类型来查询节点的配置信息。 若输入该参数时，系统查询Cluster类型等于该参数值的节点的配置信息。 若不输入该参数时，则表示该参数不作为查询的限制条件。 |
| SERVICETYPE | 业务类型      | 用于指示系统需要按照哪个业务类型来查询节点的配置信息。 若输入该参数时，系统查询业务类型等于该参数值的节点的配置信息。 若不输入该参数时，则表示该参数不作为查询的限制条件。           |

## 使用实例

1. 查询所有节点配置信息：

   ```
   LST NODE:;
   ```

   ```
   %%LST NODE:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    Cluster标识  节点标识  模块号  Pod名称    Cluster类型  应急加载开关    业务类型

    11           11        11      USRSU_1       DRU          0               SUP-FE
    11           110       110     USRSU_2       DRU          0               SUP-FE
    12           12        12      USRSU_1       DRU          0               SUP-FE
    13           13        13      USRSU_1       DSU          0               SUP-FE
    13           130       130     USRSU_2       DSU          0               SUP-FE
   (结果个数 = 5)

   ---    END
   ```
2. 以单一参数为条件进行查询。例如：查询“Cluster标识”为“11”的节点的配置信息。

   ```
   LST NODE: CID=11;
   ```

   ```
   %%LST NODE: CID=11;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    Cluster标识  节点标识  模块号  Pod名称    Cluster类型  应急加载开关    业务类型

    11           11        11      USRSU_1       DRU          0               SUP-FE
    11           110       110     USRSU_2       DRU          0               SUP-FE
   (结果个数 = 2)

   ---    END
   ```
3. 以多个参数为条件进行组合查询。例如：查询“Cluster类型”为DSU，且“业务类型”为“SUP-FE”的Cluster的配置信息。

   ```
   LST NODE: CT=DSU, SERVICETYPE="SUP-FE";
   ```

   ```
   %%LST NODE: CT=DSU;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    Cluster标识  节点标识  模块号  Pod名称    Cluster类型  应急加载开关    业务类型

    13           13        13      USRSU_1       DSU          0               SUP-FE
    13           130       130     USRSU_2       DSU          0               SUP-FE
   (结果个数 = 2)

   ---    END
   ```

## 输出结果说明

| 输出项名称     | 输出项解释                                                        |
|:----------|:-------------------------------------------------------------|
| Cluster标识 | 用于表示节点所属Cluster的对应标识，此参数在同一USCDB网元下唯一。 取值范围：1～4096           |
| 节点标识      | 用于表示节点的节点标识，此参数在Location内唯一。节点标识和模块号一一对应。 取值范围：1～32768       |
| 模块号       | 用于表示节点对应的模块号，该模块在配置数据库中定义，即Pod上运行的进程。 取值范围： 1～4080           |
| Pod名称     | 描述模块所属Pod的名称。 取值范围：长度不超过128的字符串。                             |
| Cluster类型 | 用于表示节点所在Cluster的类型。 取值范围： DRU(DRU)DSU(DSU)                   |
| 应急加载开关    | 用于表示该节点应急加载开关状态。 取值范围： 0：关1：开                                |
| 业务类型      | 用于表示节点的业务类型，该参数通过LOD FEPLUG命令加载FE插件后在此引用。 取值范围：长度不超过128的字符串。 |
