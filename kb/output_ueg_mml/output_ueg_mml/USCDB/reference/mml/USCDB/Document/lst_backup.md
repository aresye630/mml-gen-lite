# 查询备份配置信息(LST BACKUP)

## 命令功能

该命令用于查询自动备份的配置信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

LST BACKUP:;

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见

**MOD BACKUP**

命令的参数说明，表1列出的是未包含在

**MOD BACKUP**

命令参数说明中的输出项。

| 输出项名称   | 输出项解释                                 |
|:--------|:--------------------------------------|
| 数据库标识   | 用来唯一标识一个物理数据库。 取值说明：目前此值固定为“数据库”。     |
| 备份配置标识  | 备份配置参数索引，用来唯一标识该对象的一个实例。              |
| NDF模块号  | NDF模块索引号。该参数必须由ADD MODULE命令定义后才能在此引用。 |
