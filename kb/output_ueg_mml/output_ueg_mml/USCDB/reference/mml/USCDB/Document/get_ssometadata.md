## 命令功能

该命令用于获取SP端的SSO元数据。

当PGW Web LMT使用SSO（Single Sign On）功能时，需要使用该命令获取SP端（即PGW Web LMT）元数据，提供给IDP端（即网管）使用。

## 注意事项

- 执行该命令之前，需要先执行**ADD SSOLNK**命令增加SSO链路。
- 执行该命令之后，主备PGW根据SSOLNK数据和证书数据生成元数据文件“sp\_metadata.xml”，并上传到CGPLite的“/opt/HUAWEI/cgp/workshop/omu/share/nefile/USCDB\_SSOMETADATA/ME网元号/”目录下。
- 生成的SSO元数据文件下载到本地的方式：登录OM Portal，单击“系统 > 文件传输”打开文件传输窗口，再单击“CGPLite文件 > 网元文件 > USCDB\_SSOMETADATA”，选择指定网元的文件下载获取。

## 参数说明

无。

## 使用实例

获取SSO元数据。

```
GET SSOMETADATA:;
```

## 参考信息

- SSO（Single Sign-On）：单点登录，是目前比较流行的服务于企业业务整合的解决方案之一，SSO使得在多个应用系统中，用户只需要登录一次，就可以访问所有相互信任的应用系统。
- 基于SAML 2.0（Security Assertion Markup Language 2.0，安全断言标记语言）协议实现的SSO登录，由IDP和SP组成，以实现在不同的安全域之间交换认证和授权数据。
  - SP（Service Provider）：向用户提供正式商业服务的实体，通常需要认证一个用户的身份。
  - IDP（Identity Provider）：提供用户的身份鉴别，确保用户是其所声明的身份。

  PGW Web LMT实现SSO单点接入功能，是以PGW Web LMT作为SP端，网管作为IDP端。
