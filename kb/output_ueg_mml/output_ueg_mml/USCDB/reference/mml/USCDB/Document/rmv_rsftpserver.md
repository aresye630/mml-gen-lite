# 删除远端SFTP服务器(RMV RSFTPSERVER)

- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，该操作将删除SFTP连接配置，操作不当将造成SFTP服务器无法连接、导出或备份文件无法上传等严重后果。因此执行该命令前，需要与华为技术支持确认后才可以实施。

当没有用户需要向SFTP服务器上传文件或从SFTP服务器下载文件时，使用该命令删除远端SFTP服务器。

该命令的使用场景：

- 开局场景：开局根据网设规划配置SFTP对接信息，用于修改错误配置。
- 网络改造场景：根据客户组网规划，需要调整SFTP对接信息。

## 注意事项

- 该命令不允许进行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。

## 参数说明

| 参数标识       | 参数名称    | 参数说明                                                                                |
|:-----------|:--------|:------------------------------------------------------------------------------------|
| SERVERTYPE | 远端服务器类型 | 标识一条远端SFTP服务器数据配置记录的关键字段之一，用于指定需要删除哪一类型的远端SFTP服务器配置信息，操作员可以使用LST RSFTPSERVER命令查询获得。 |
| SERVERNAME | 远端服务器名称 | 标识一条远端SFTP服务器数据配置记录的关键字段之一，用于指定需要删除哪一个远端SFTP服务器配置信息，操作员可以使用LST RSFTPSERVER命令查询获得。   |

## 使用实例

当某局点不再存在用户需要远端SFTP服务器提供服务时，需要删除远端SFTP服务器配置信息，“远端服务器类型”为“PROV”，“远端服务器名称”为“sftpserver”：

```
RMV RSFTPSERVER: SERVERTYPE=PROV, SERVERNAME="sftpserver";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                    | 原因分析                      | 处理建议                                                                                                                                                  |
|-------:|:-------------------------|:--------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------|
| 275046 | 记录不存在。                   | 执行该命令删除的远端SFTP服务器在系统中不存在。 | 请输入已存在的远端SFTP服务器名称，可执行LST RSFTPSERVER命令查询已添加的远端SFTP服务器配置信息，然后执行本命令删除。                                                                                 |
| 337167 | 配置的RSFTPSERVERNAME已经被使用。 | 输入的“远端服务器名称”已被使用，禁止删除。    | 请按如下步骤进行处理：执行LST CUSEXPCFG命令查看引用当前“远端服务器名称”的定制导出配置信息，主要查看返回报文的“远端SFTP服务端名称”和“备用SFTP服务器”。确认该配置记录已不再使用后执行RMV CUSEXPCFG命令删除引用当前“远端服务器名称”的配置记录，然后重新执行本命令。 |
