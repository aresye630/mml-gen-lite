# 查询恢复目录(LST RESTOREDIR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询系统中指定恢复目录的记录。如果带参数，则查询指定服务类型的记录，否则查询所有记录。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                     |
|:------------|:-------|:-----------------------------------------|
| SERVICETYPE | 服务类型   | 用于指定具体的服务类型。若不输入该参数，表示查询所有服务类型的指定恢复目录信息。 |

## 使用实例

1. 查询所有服务类型指定恢复目录信息。

   ```
   LST RESTOREDIR:;
   ```

   ```
   %%LST RESTOREDIR:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    服务类型  指定目录

    SUP-FE    指定1平面Pod的/opt/uscdb/SNP_UPG/目录。
    USCDB     指定1平面Pod的/opt/uscdb/SNP_UPG/目录。
   (结果个数 = 2)

   ---    END
   ```
2. 查询特定服务类型指定恢复目录信息：设置“服务类型”为“SUP-FE”。

   ```
   LST RESTOREDIR: SERVICETYPE="SUP-FE";
   ```

   ```
   %%LST RESTOREDIR: SERVICETYPE="SUP-FE";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
       服务类型  =  SUP-FE
       指定目录  =  指定1平面Pod的/opt/uscdb/SNP_UPG/目录。
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和查询结果。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释       | 原因分析          | 处理建议                                                                                                                         |
|------:|:------------|:--------------|:-----------------------------------------------------------------------------------------------------------------------------|
|  2059 | 指定的业务类型不存在。 | 输入的“服务类型”不存在。 | 通过LST FEPLUG命令查询加载的“FE类型名称”，“FE类型名称”即“服务类型”。 若“服务类型”加载成功，请在执行该命令时输入正确的服务类型名称。若“服务类型”加载不成功或者没有加载，通过LOD FEPLUG命令加载成功后，重新执行该命令。 |
