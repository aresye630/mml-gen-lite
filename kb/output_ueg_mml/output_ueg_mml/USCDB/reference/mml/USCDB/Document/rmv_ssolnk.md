# 删除SSO链路（RMV SSOLNK）

## 命令功能

**须知** 

该命令属于高危命令，删除SSO链路会造成WebLMT的SSO功能不可用。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除SSO链路。

## 注意事项

删除SSO链路会造成PGW Web LMT的SSO功能不可用，因此必须在华为技术支持工程师指导下使用，严禁私自执行。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                   |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------|
| LNKID  | 链路ID   | 可选必选说明：必选参数 参数含义：标识一条SSO链路数据记录的关键字段，用于指定需要删除哪一条SSO链路信息，操作员可以使用LST SSOLNK命令查询获得。 取值范围：1。 默认值：无。 配置原则：无。 |

## 使用实例

删除指定SSO链路，该“链路ID”为“1”。

```
RMV SSOLNK: LNKID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释   | 原因分析         | 处理建议              |
|-------:|:-------|:-------------|:------------------|
| 274632 | 链路不存在。 | 系统中不存在SSO链路。 | 系统中不存在SSO链路，无需处理。 |

## 参考信息

SSO（Single Sign-On）：单点登录，是目前比较流行的服务于企业业务整合的解决方案之一，SSO使得在多个应用系统中，用户只需要登录一次，就可以访问所有相互信任的应用系统。
