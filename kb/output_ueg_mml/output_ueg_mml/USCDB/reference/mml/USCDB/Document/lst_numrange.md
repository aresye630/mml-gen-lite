# 查询号段范围(LST NUMRANGE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于查询城市的MSISDN或IMSI号段范围信息。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                    |
|:-----------|:---------|:--------------------------------------------------------|
| CITY       | 城市       | 用于指定需要查询号段范围信息的城市。 取值范围：长度不超过128的字符串。 默认值：无。            |
| OBJECTID   | 对象ID     | 用于标识统计对象。 取值范围：OBJECT0～OBJECT829 默认值：无。                 |
| ISDNBEGNUM | ISDN起始号码 | 用于标识参数“CITY”指定的城市的MSISDN起始号码。 取值范围：长度不超过128的字符串。 默认值：无。 |
| ISDNENDNUM | ISDN结束号码 | 用于标识参数“CITY”指定的城市的MSISDN结束号码。 取值范围：长度不超过128的字符串。 默认值：无。 |
| IMSIBEGNUM | IMSI起始号码 | 用于标识参数“CITY”指定的城市的IMSI起始号码。 取值范围：长度不超过128的字符串。 默认值：无。   |
| IMSIENDNUM | IMSI结束号码 | 用于标识参数“CITY”指定的城市的IMSI结束号码。 取值范围：长度不超过128的字符串。 默认值：无。   |

## 使用实例

1. 查询城市“A”的号段范围信息：

   ```
   LST NUMRANGE: CITY="A";
   ```

   ```
   %%LST NUMRANGE: CITY="A";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
           城市  =  A
         对象ID  =  OBJECT1
   ISDN起始号码  =  0000
   ISDN结束号码  =  1111
   IMSI起始号码  =  2222
   IMSI结束号码  =  3333
   (结果个数 = 1)

   ---    END
   ```
2. 查询“ISDN起始号码”为“0000”的号段范围信息：

   ```
   LST NUMRANGE: ISDNBEGNUM="0000";
   ```

   ```
   %%LST NUMRANGE: ISDNBEGNUM="0000";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
           城市  =  A
         对象ID  =  OBJECT1
   ISDN起始号码  =  0000
   ISDN结束号码  =  1111
   IMSI起始号码  =  2222
   IMSI结束号码  =  3333
   (结果个数 = 1)

   ---    END
   ```
3. 查询所有城市的号段范围信息：

   ```
   LST NUMRANGE:;
   ```

   ```
   %%LST NUMRANGE:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    城市    对象ID  ISDN起始号码  ISDN结束号码  IMSI起始号码  IMSI结束号码

    B       OBJECT2       5555          6666          7777          8888        
    A       OBJECT1       0000          1111          2222          3333        
   (结果个数 = 2)

   ---    END
   ```
