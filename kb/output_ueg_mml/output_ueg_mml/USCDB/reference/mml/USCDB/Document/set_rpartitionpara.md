## 命令功能

**须知** 

该命令属于高危命令，该操作将改变Global-Local组网或混合组网的网络属性，操作不当将导致用户数据异常、业务受损。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置远端分区参数的配置。

该命令的使用场景：在Global-Local组网或混合组网升级及扩容场景下，根据工程操作指导书，按步骤执行该命令，以便升级和扩容操作正常实施。

## 注意事项

- 该命令不允许进行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。

## 参数说明

| 参数标识         | 参数名称          | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
|:-------------|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PARANAME     | 参数名称          | 用于标识远端分区软参的参数名。 取值范围： INTERPARTSTATUS：分区间状态开关。用于标识Partition的局间状态，共有“正常”、“停校验”、“停复制和校验”、“停复制”和“停快速校验”五种状态。在升级和扩容之前，需要修改分区间状态，一般设置为“停复制和校验”，停止局点之间的数据同步。完成升级操作之后，恢复为升级前的状态。PARTITIONVERIFYMODE：分区间校验模式。该参数仅在Global Local 2.0组网场景下使用，用于设置分区间的校验模式。vRSP（Global）与对应vSP（Local）的FE业务类型PARTITIONVERIFYMODE值必须设置一致，否则会上报“ALM-12067 Partition间软参不一致”告警。 默认值：无。                                                                                                                                                                                                                                                             |
| PARAVALUE    | 参数值           | 用于定义远端分区参数的参数值。 取值范围：0～4294967294 当“参数名称”为“INTERPARTSTATUS”时，取值范围如下：0：正常。1：停校验。（包括在“dbschema.xml”文件中，配置了IsSyncVSP=“1”的用户数据的跨分区周期性校验和跨分区快速校验）2：停复制和校验。（包括在“dbschema.xml”文件中，配置了IsSyncVSP=“1”的用户数据的跨分区复制校验）3：停复制。4：停快速校验。（包括在“dbschema.xml”文件中，配置了IsSyncVSP=“1”的用户数据的跨分区快速校验） 当“参数名称”为“PARTITIONVERIFYMODE”时，取值范围如下：0：当营帐从Local BE接入时，“PARTITIONVERIFYMODE”值设置为“0”，Global BE与Local BE之间的用户数据正向校验由Local BE发起。反向校验由Global BE发起，当数据不存在时，以Local BE的数据为准。1：当营帐从Global BE接入时，“PARTITIONVERIFYMODE”值设置为“1”，Global BE与Local BE之间的用户数据正向校验由Global BE发起。反向校验由Local BE发起，当数据不存在时，以Global BE的数据为准。 说明：5～4294967294为预留值。 默认值：0。 |
| RPARTITIONID | 远端Partition标识 | 用于定义待设置参数的远端Partition标识。 取值范围：1～250 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| SERVICETYPE  | 业务类型          | 用于定义待设置参数所属远端分区的业务类型。此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。 取值范围：长度不超过128的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |

## 使用实例

在升级操作之前，修改分区间状态开关，将分区间状态开关设置成“停复制和校验”。

```
SET RPARTITIONPARA: PARANAME=INTERPARTSTATUS, PARAVALUE=2, RPARTITIONID=8, SERVICETYPE="SUP-FE";
```
