# 查询恢复时间(LST RESTORETIME)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询系统中指定恢复时间记录：

- 若要查询所有服务类型的指定恢复时间记录，请不要输入任何参数。
- 若要查询指定服务类型的指定恢复时间记录，请输入“服务类型”参数。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                         |
|:------------|:-------|:---------------------------------------------------------------------------------------------|
| SERVICETYPE | 服务类型   | 可选必选说明：可选参数。 参数含义：用于指定具体的服务类型。若不输入该参数，表示查询所有服务类型的指定恢复时间记录。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询系统中全部服务类型的指定恢复时间记录。

   ```
   LST RESTORETIME;
   ```

   ```
   %%LST RESTORETIME: ;%% 
   RETCODE = 0  操作成功  

   操作结果如下 
   ------------  
   服务类型  指定日期   指定时间           
   SUP-FE    2022-03-17 21:07:31
   USCDB     2022-03-17 21:07:31
   (结果个数 = 2)  

   ---    END
   ```
2. 查询系统中指定服务类型指定恢复时间记录：设置“服务类型”为“SUP-FE”。

   ```
   LST RESTORETIME: SERVICETYPE="SUP-FE";
   ```

   ```
   %%LST RESTORETIME: SERVICETYPE="SUP-FE";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
       服务类型  =  SUP-FE
       指定日期  =  2022-05-26
       指定时间  =  11:40:36
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令操作成功的提示信息和相关参数，各参数含义请参见**SET RESTORETIME**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释       | 原因分析                                 | 处理建议                                                                                                                         |
|------:|:------------|:-------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------|
|  2059 | 指定的业务类型不存在。 | 参数SERVICETYPE的取值不存在，请确认已经成功加载了该FE插件。 | 通过LST FEPLUG命令查询加载的“FE类型名称”，“FE类型名称”即“服务类型”。 若“服务类型”加载成功，请在执行该命令时输入正确的服务类型名称。若“服务类型”加载不成功或者没有加载，通过LOD FEPLUG命令加载成功后，重新执行该命令。 |
