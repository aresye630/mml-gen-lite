# 设置Location信息(SET LOCATION)

## 命令功能

**须知** 

- 该命令属于高危命令，该操作将修改本局标识，且重启网元才能生效，设置不当会造成业务中断，局点商用后不允许修改。因此执行该命令前，需要与华为技术支持确认后才可以实施。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于设置Location信息。

该命令的使用场景：

- 开局场景：用于开局初始配置时设置本局标识。
- 网络改造场景：改造场景，按指导书步骤要求调整本局标识。

## 注意事项

- 不同网元的Location标识必须不一样，否则会被认为是同一网元。
- 该命令不允许进行批操作。
- 开局初始配置，首次执行本命令设置网元Location标识时，无需重启网元即可生效。网络改造场景需执行**RST ME**命令重启网元才能生效。
- 局点商用后严禁使用此命令修改网元的Location标识。
- 商用局点网络改造场景，如需使用本命令调整网元Location标识，会出现链路断开等问题，**因此需要联系华为技术支持定制操作指导书，按照定制操作指导书步骤调整本局标识。**

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                                                                      |
|:-------|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------|
| LOCID  | Location标识 | 用于标识一个网元，所有的网元标识唯一。Location标识在以下网元中需要配置：主用局FE、主用局USCDB、容灾局FE、容灾局USCDB。 取值范围：1～512 默认值：无。                                                  |
| CNFM   | 确认         | 用于确认是否强制设置Location标识。 取值范围：YES(是)，表示不管当前网元是否已经设置Location标识，此次均能设置成功。 NO(否)，若当前网元已经设置Location标识，则本次设置无效。若当前网元没有设置Location标识，则本次设置成功。 默认值：否 |

## 使用实例

在开局场景下，设置Location信息，“LOCID”为“12”:

```
SET LOCATION: LOCID=12;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|-------:|:---------------------------------------------------------------------------|:----------------------------------------------------------------|:------------------------------------------------------|
| 302000 | 参数Location标识指定的本地Location标识与远端Location配置中的远端Location标识重复。                  | 指定的Location标识与远端Location配置中的远端Location标识不允许重复。                  | 请执行LST RLOCATION命令查询“远端Location标识”配置信息，确保与查询结果不重复。    |
| 260543 | 参数Location标识指定的本地Location标识与虚拟远端Location配置中的虚拟远端Location标识或远端Location标识重复。 | 指定的Location标识与虚拟远端Location配置中的虚拟远端Location标识或远端Location标识不允许重复。 | 请执行LST VRLOCATION命令查询“虚拟远端Location标识”配置信息，确保与查询结果不重复。 |
| 302585 | Location标识已设置。                                                             | 指定的Location标识中“确认”参数值为“否”，且已在系统中配置该Location标识。                  | 将“确认”参数值改为“是”后，重新执行该命令。                               |
