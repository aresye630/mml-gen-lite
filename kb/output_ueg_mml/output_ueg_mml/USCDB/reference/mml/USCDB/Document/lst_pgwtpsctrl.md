# 查询TIPS控制配置（LST PGWTPSCTRL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查看TPS控制参数，包括控制开关，上报周期，控制周期。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查看当前TPS控制参数：

LST PGWTPSCTRL:;

```
%%LST PGWTPSCTRL:;%%
RETCODE = 0  操作成功

操作结果如下
------------
控制开关  =  关闭
上报周期  =  5
控制周期  =  60
(结果个数 = 1)

---    END
```

## 输出结果说明

请参见**SET PGWTPSCTRL**命令的参数说明。
