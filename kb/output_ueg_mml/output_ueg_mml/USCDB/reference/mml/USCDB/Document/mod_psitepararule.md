# 修改PSITE参数替换规则配置(MOD PSITEPARARULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**说明** 

该命令属于高危命令，该操作将修改PSITE参数替换规则配置，操作不当会导致转发到远端的命令执行失败。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改PSITE参数替换规则。在该命令中，系统通过“Rule ID”和“参数名”参数来唯一标识一条PSITE参数替换规则配置记录。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                |
|:------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------|
| RULEID      | Rule ID | 可选必选说明：必选参数 参数含义：唯一标识一条号段配置，用于指定需要修改哪一个Rule ID对应的PSITE参数替换规则配置，操作员可以使用LST PSITEPARARULE命令查询获得。 取值范围：1～65535 默认值：无。 配置原则：无。          |
| NAME        | 参数名     | 可选必选说明：必选参数 参数含义：用于指定需要修改哪一个参数名对应的PSITE参数替换规则配置，操作员可以使用LST PSITEPARARULE命令查询获得。 取值范围：1～32位的由数字(0～9)和大写字母(A～Z)组成的字符串。 默认值：无。 配置原则：无。 |
| NEWNAME     | 新参数名    | 可选必选说明：可选参数 参数含义：用于指定PSITE参数替换规则中替换后参数的名称。 取值范围：1～32位的由数字(0～9)和大写字母(A～Z)组成的字符串。 默认值：无。 配置原则：该参数的取值必须与“参数名”的取值不同。                    |
| VALUE       | 参数值     | 可选必选说明：可选参数 参数含义：用于指定PSITE参数替换规则中需要替换参数的取值。 取值范围：1～32位的由数字(0～9)和字母(A～Z、a～z)组成的字符串。 默认值：无。 配置原则：无。                                   |
| NEWVALUE    | 新参数值    | 可选必选说明：可选参数 参数含义：用于指定PSITE参数替换规则中替换后参数的取值。 取值范围：1～32位的由数字(0～9)和字母(A～Z、a～z)组成的字符串。 默认值：无。 配置原则：该参数的取值必须与“参数值”的取值不同。                  |
| DESCRIPTION | 描述信息    | 可选必选说明：可选参数 参数含义：用于指定PSITE参数替换规则配置的描述信息。 取值范围：不超过32个字符的字符串。 默认值：无。 配置原则：无。                                                          |

## 使用实例

修改一条PSITE参数替换规则，“Rule ID”为“11”，“参数名”为“USCSN”，“参数值”为“29”，“新参数值”为“30”：

```
MOD PSITEPARARULE: RULEID=11, NAME="USCSN", NEWNAME="29", VALUE="30";
```
