## 命令功能

**须知** 

该命令属于高危命令，复位模块可能导致业务中断。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在配置数据库中复位指定模块。

本命令有以下使用场景：

- 在开局、扩容或升级的过程中，需要为指定的模块加载新版本的主机软件，部分主机软件需要通过该命令复位模块才能生效。
- 在开局、扩容或升级的过程中，部分系统配置出现变更时，可能需要对相关模块执行复位操作使得修改生效。
  - 部分软参修改后需要复位模块，如：开局场景下，执行**MOD INSP**命令修改软参“MVNOSWITCH”，此时需要复位主备PGW模块。
  - 部分的配置命令变更时需要复位模块，如：开局场景下，执行**ADD PORT**命令增加端口后，需要复位所有PGW模块使新添加的端口生效。

## 注意事项

- 由于复位模块会导致业务中断，为确保系统的安全与稳定运行，除非紧急排除故障的需要，操作员在系统话务量少的时间段（例如凌晨2:00～4:00）执行该命令。
- NDF模块复位前，请关注是否存在以下任务：

  - 如果有物理库备份任务，复位后任务可能失效。如有必要请重新执行物理库备份任务。
  - 如果有物理库恢复任务，复位后任务可能失效。如有必要请重新执行物理库恢复任务。
- 复位主备PGW模块会导致DMS WebUI对应重启。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                       |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------|
| MID    | 模块号    | 标识一条模块配置信息的关键字段，用于指定待复位的模块，该参数可以使用LST MODULE命令查询获得。 取值范围：1～4080 默认值：无。                                                     |
| MT     | 模块类型   | 用于标识待复位模块的模块类型。该参数必须与模块号对应，否则命令执行失败。 取值范围： DPU(DPU)NDF(NDF)DBG(DBG)DSG(DSG)DRU(DRU)DSU(DSU)PGW(PGW)DMA(DMA)CAG(CAG) 默认值：无。 |

## 使用实例

复位一个“模块号”为“101”，“模块类型”为“DRU”的模块。

RST MODULE: MID=101, MT=DRU;

```
%%RST MODULE: MID=101, MT=DRU;%%
RETCODE = 0  操作成功

操作结果如下
------------
              模块号  =  101
            模块类型  =  DRU
          Pod名称  =  USRSU_1
            模块名称  =  DRU
          平台模块号  =  2148794370
            操作结果  =  成功
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 参数名称   | 参数描述                                                                  |
|:-------|:----------------------------------------------------------------------|
| 模块号    | 取值范围：1～4080                                                           |
| 模块类型   | 取值范围：DPU(DPU)NDF(NDF)DBG(DBG)DSG(DSG)DRU(DRU)DSU(DSU)PGW(PGW)CAG(CAG) |
| Pod名称  | 描述模块所属Pod的名称。 通过LST PODINFO命令查询是否已添加模块所属Pod。 取值范围：长度不超过127的字符串。       |
| 模块名称   | 模块的模块名称。 为便于识别，一般模块名称应包含模块类型和相应编号。                                    |
| 平台模块号  | 用于描述执行该命令时涉及的操作进程的模块号。                                                |
| 操作结果   | 用于描述命令是否执行成功。 取值说明： 成功失败                                              |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释          | 原因分析                             | 处理建议                                                                |
|-------:|:---------------|:---------------------------------|:--------------------------------------------------------------------|
| 330005 | 参数MID指定的进程不存在。 | 输入的“模块号”取值在系统中不存在或与输入的“模块类型”不对应。 | 执行命令LST MODULE查询系统中已存在的模块号和模块类型。重新输入参数“模块号”和“模块类型”取值，确保在查询结果中存在且对应。 |
| 260046 | 该模块不存在。        | 输入的“模块号”取值在系统中不存在或与输入的“模块类型”不对应。 | 执行命令LST MODULE查询系统中已存在的模块号和模块类型。重新输入参数“模块号”和“模块类型”取值，确保在查询结果中存在且对应。 |
