# 查询号段配置(LST PSITERULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询号段配置信息。

- 若需要查询全部号段配置的概要信息，请不要输入任何参数。
- 若需要查询某个号段配置数据记录的详细信息，请输入“Site ID”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                    |
|:------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SITEID      | Site ID | 用于指示系统需要按照哪个站点ID来查询号段配置数据；若不输入，则表示查询所有的站点ID的号段配置数据。 取值范围：1～1024 默认值：无。                                                                                                  |
| RULEID      | Rule ID | 用于指示系统需要按照哪个Rule ID来查询号段配置数据；若不输入，则表示查询所有的Rule ID的号段配置数据。 取值范围：1～65535 默认值：无。                                                                                           |
| RANGETYPE   | 号段类型    | 用于指示系统需要按照哪个号段类型来查询号段配置数据；若不输入，则表示查询所有号段类型的号段配置数据。 取值范围： IMSI(IMSI)：用户号码的号段类型为IMSI。ISDN(ISDN)：用户号码的号段类型为ISDN。 默认值：无。                                                    |
| PREFIX      | 号段前缀    | 用于指示系统需要按照哪个号段前缀来查询号段配置数据；若不输入，则表示查询所有号段前缀的号段配置数据。 取值范围：1～32位的由数字组成的字符串。 默认值：无。                                                                                         |
| ACTIVE      | 主设备     | 仅当ADD PSITE命令中的“业务场景”参数取值为“DUALPROV(营帐双发)”时该参数有效，用于指示系统需要按照哪个主设备来查询号段配置数据；若不输入，则表示查询所有的主设备的号段配置数据。 取值范围： LOCAL(本端为主设备)REMOTE(远端为主设备) 默认值：无。                             |
| CUTOVER     | 割接状态    | 仅当ADD PSITE命令中的“业务场景”参数取值为“DUALPROV(营帐双发)”时该参数有效，用于指示系统需要按照哪个割接状态来查询号段配置数据；若不输入，则表示查询所有的割接状态的号段配置数据。 取值范围： TRUE(TRUE)：号段已割接。FALSE(FALSE)：号段未割接。NONE(NONE)：非双发号段。 默认值：无。 |
| AREA        | 号段区域    | 号段所分配到区域的描述。 取值范围： 不超过64位的字符串。 默认值： 无。                                                                                                                                  |
| DESCRIPTION | 描述      | 号段配置描述信息。 取值范围：不超过128位的字符串。 默认值： 无。                                                                                                                                     |

## 使用实例

1. 查询所有的号段配置信息：

   ```
   LST PSITERULE:;
   ```

   ```
   %%LST PSITERULE:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    Site ID  Rule ID  号段类型    号段前缀    主设备         割接状态  站点描述        号段区域      描述

    1        1        IMSI        4600        远端为主设备   TRUE      Huawei HLR1     NULL          NULL       
    1        2        IMSI        6200        NULL           NULL      Huawei HLR1     NULL          NULL
   (结果个数 = 2)

   ---    END
   ```
2. 查询号码配置信息，“Site ID”为“1”，“Rule ID”为“1”，“号段类型”为“IMSI”，“号段前缀”为“4600”：

   ```
   LST PSITERULE: SITEID=1, RULEID=1, RANGETYPE=IMSI, PREFIX="4600";
   ```

   ```
   %%LST PSITERULE: SITEID=1, RULEID=1, RANGETYPE=IMSI, PREFIX="4600";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    Site ID  =  1
    Rule ID  =  1
   号段类型  =  IMSI
   号段前缀  =  4600
     主设备  =  远端为主设备
   割接状态  =  TRUE  
   站点描述  =  Huawei HLR1
   号段区域  =  NULL
       描述  =  NULL
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD PSITERULE**命令的参数说明。
