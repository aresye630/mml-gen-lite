# 删除号段配置(RMV PSITERULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，删除号段配置会造成营帐命令无法转发到其他设备。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在配置数据库中删除一条号段配置数据记录。

当需要修改站点ID和号段类型或号段前缀之间的关联关系，也必须首先执行本命令删除已有的关联关系后，再执行**ADD PSITERULE**命令增加修改后的关联关系。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                         |
|:-------|:--------|:---------------------------------------------------------------------------------------------|
| RULEID | Rule ID | 标识一条号段配置数据记录的关键字段，用于定需要删除哪一个Rule ID对应的号段配置数据，操作员可以使用LST PSITERULE命令查询获得。 取值范围：1～65535 默认值：无。 |

## 使用实例

某局端需要修改一条已有的号段配置数据，需要进行如下操作：

1. 执行本命令删除系统中已存在的需要修改的号段配置数据。“Rule ID”为“1”：

   ```
   RMV PSITERULE: RULEID=1;
   ```
2. 执行**ADD PSITERULE**命令增加新的号段配置数据。

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                  | 原因分析                          | 处理建议                                                                                                                   |
|-------:|:---------------------------------------|:------------------------------|:-----------------------------------------------------------------------------------------------------------------------|
| 256034 | 记录不存在。                                 | 只能删除已经存在的记录。                  | 执行LST PSITERULE命令查看当前已存在的记录，然后在已存在的记录上执行本命令进行删除。                                                                       |
| 275491 | RULEID正在使用，请执行RMV PSITEPARARULE命令删除配置。 | 输入的“Rule ID”正在被PSITE参数替换规则使用。 | 请参照如下步骤执行： 执行LST PSITEPARARULE命令查询出使用该“Rule ID”的PSITE参数替换规则配置记录。执行RMV PSITEPARARULE命令删除该PSITE参数替换规则配置记录。重新执行该命令删除号段配置。 |
