# 查询LDAP连接数阈值(LST LDAPCONNTHD)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**说明** 

该命令在25.1.0版本不支持。

该命令用于查询已配置的LDAP连接数阈值。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询已配置的LDAP连接数阈值。执行命令如下：

```
LST LDAPCONNTHD:;
```

```
%%LST LDAPCONNTHD:;%%
RETCODE = 0  操作成功

操作结果如下
------------
    一级告警阈值  =  80
    二级告警阈值  =  85
一级告警恢复阈值  =  75
二级告警恢复阈值  =  80
 (结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET LDAPCONNTHD**命令的参数说明。
