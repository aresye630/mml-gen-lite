# 去激活模块(DEA MODULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，该操作会导致业务中断。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于去激活DSG模块。

该命令的使用场景：在重启前需要对升级Pod进行去激活。

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                    |
|:-------|:-------|:------------------------------------------------------------------------|
| MID    | 模块号    | 标识一条模块配置信息的关键字段，用于指定待去激活的模块，该参数可以使用LST MODULE命令查询获得。 取值范围：1～2047 默认值：无。 |

## 使用实例

去激活4号模块。

```
DEA MODULE: MID=4;
```

```
%%DEA MODULE: MID=4;%%
RETCODE = 0  操作成功

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释        | 原因分析                    | 处理建议                                           |
|-------:|:-------------|:------------------------|:-----------------------------------------------|
| 260140 | 指定的DSG模块不存在。 | 当前操作的“模块号”对应的模块不是DSG模块。 | 通过LST MODULE命令查询DSG的模块号，输入查询到的DSG模块号后，重新执行该命令。 |
