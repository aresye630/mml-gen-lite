# 查看适配插件包加载状态(DSP ADPPLUG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询适配插件包在各个PGW上的加载状态。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询各个PGW上的适配插件包的加载状态。执行命令如下：

```
DSP ADPPLUG:;
```

## 输出结果说明

| 适配文件加载状态    | 用于返回适配文件的加载状态。此适配文件主要支撑第三方应用或具有相同命令名称的不同FE网元接入USCDB。 加载状态及含义如下： “加载成功”: 表示主机已经成功加载对应适配文件。插件包对应的第三方应用或FE网元可正常接入USCDB并进行数据处理。“加载失败”：表示主机在加载适配内容的时候出现了错误导致加载失败。此时建议查看“适配文件加载状态”、“定制插件包加载状态”和“融合插件包加载状态”是否存在多处失败。如果是则建议执行LOD ADPPLUG命令重新加载整个适配插件；否则建议检查加载失败的PGW模块是否存在异常，排除异常后执行RST MODULE命令重新启动PGW模块再次执行本命令进行查看加载结果。“未加载”：表示主机还未开始加载适配内容。建议执行LOD ADPPLUG命令加载适配插件，并执行RST MODULE命令重新启动所有PGW模块使加载生效。“NULL”：表示未加载成功或加载未生效。建议检查适配包是否已经加载。如果未加载，建议检查适配插件包文件是否已上传到指定加载目录，执行LOD ADPPLUG命令重新加载适配插件，并执行RST MODULE命令重启所有PGW模块使加载生效；如果已加载，则需要执行RST MODULE命令重启所有PGW模块使加载生效。                                                                                                                                                              |
