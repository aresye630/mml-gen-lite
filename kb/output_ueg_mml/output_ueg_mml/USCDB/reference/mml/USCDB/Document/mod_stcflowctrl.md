# 修改静态流控参数(MOD STCFLOWCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

- 该命令属于高危命令，该操作将修改PGW静态流控参数，操作不当将导致无法启控或过早起控，并造成营帐业务受损。因此执行该命令前，需要与华为技术支持确认后才可以实施。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于修改PGW静态流控参数。

当业务发放系统发送命令的速度过快，在流控周期内平均每秒发送的命令数大于PGW的静态流控阈值时，产生ALM-14022 PGW静态流控启用告警，且告警长时间未解除，可以通过本命令调整静态流控参数。

## 注意事项

- 当开启静态流控后，PGW将自动丢弃超过静态流控阈值的命令，导致与这些命令相关的业务处理失败。如果需要知道哪些命令在PGW静态流控期间被丢弃，则可以将“操作日志保存丢弃命令开关”设置为“1”。
- 在缺省的情况下，系统预置了如下参数:

  ```
  启控命令数 = 300 
    流控周期 = 5
  ```
- 该命令不允许进行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                       |
|:---------|:-------|:-----------------------------------------------------------|
| CMDCOUNT | 启控命令数  | 用于指定PGW模块启用静态流控特性的阈值。 取值范围：0～4294967294 单位：条/秒 系统初始设置值：300 |
| PERIOD   | 流控周期   | 用于指定PGW模块统计流量过程中的采样时间间隔。 取值范围：0～4294967294 单位：秒 系统初始设置值：5  |

## 使用实例

某局点的业务发放系统发送命令的速度过快，在流控周期内平均每秒发送的命令数大于PGW的静态流控阈值，将“启控命令数”修改为“700”，“流控周期”修改为“10”：

```
MOD STCFLOWCTRL: CMDCOUNT=700, PERIOD=10;
```

**说明** 

该命令表示10秒钟内允许7000条命令发送到PGW执行。
