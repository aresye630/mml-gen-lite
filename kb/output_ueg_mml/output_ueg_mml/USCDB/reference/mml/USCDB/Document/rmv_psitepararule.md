# 删除PSITE参数替换规则配置(RMV PSITEPARARULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，该操作将删除PSITE参数替换规则配置，操作不当会导致转发到远端的命令执行失败。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除PSITE参数替换规则配置。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                |
|:-------|:--------|:------------------------------------------------------------------------------------------------------------------------------------|
| RULEID | Rule ID | 可选必选说明：必选参数 参数含义：唯一标识一条号段配置，用于指定需要删除哪一个Rule ID对应的PSITE参数替换规则配置，操作员可以使用LST PSITEPARARULE命令查询获得。 取值范围：1～65535 默认值：无。 配置原则：无。          |
| NAME   | 参数名     | 可选必选说明：必选参数 参数含义：用于指定需要删除哪一个参数名对应的PSITE参数替换规则配置，操作员可以使用LST PSITEPARARULE命令查询获得。 取值范围：1～32位的由数字(0～9)和大写字母(A～Z)组成的字符串。 默认值：无。 配置原则：无。 |

## 使用实例

删除一条PSITE参数替换规则，“Rule ID”为“11”，“参数名”为“USCSN”：

```
RMV PSITEPARARULE: RULEID=11, NAME="USCSN";
```

该命令执行正常，会返回命令执行成功的提示信息。
