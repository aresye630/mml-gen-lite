# 查询物理数据库用户名(LST DB)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询USCDB物理数据库的用户名信息，为用户进行物理数据库的相关操作提供支持。

- 若需要查询USCDB物理数据库中所有用户的概要信息，请不要输入任何参数。
- 若需要查询USCDB物理数据库中某用户的详细信息，请输入对应的“用户名”。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                    |
|:---------|:-------|:----------------------------------------|
| USERNAME | 用户名    | 用于指定要查询物理数据库哪个用户的信息；若不输入，则表示所有的物理数据库用户。 |

## 使用实例

1. 查询USCDB物理数据库的所有用户信息：

   ```
   LST DB:;
   ```

   ```
   %%LST DB:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    数据库标识  用户名         修改状态

    数据库      uscdb_maintain 是
    数据库      pgw            是
    数据库      uscdb          是
    数据库      sys            是
    数据库      pgw_acc        是
    数据库      uscdb_acc      是
    (结果个数 = 6)

   ---    END
   ```
2. 查询USCDB物理数据库中“用户名”为“uscdb\_acc”的信息：

   ```
   LST DB: USERNAME="uscdb_acc";
   ```

   ```
   %%LST DB: USERNAME="uscdb_role";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   数据库标识  =  数据库
       用户名  =  uscdb_acc
     修改状态  =  是
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1。

| 输出项名称   | 输出项解释                                                    |
|:--------|:---------------------------------------------------------|
| 数据库标识   | 用于返回数据库标识，唯一标识一个数据库，目前该值固定为“数据库”。                        |
| 用户名     | 用于标识可以访问此物理数据库的用户的名称。                                    |
| 修改状态    | 用于标识用户名的密码修改状态。 取值范围：是：表示此用户名的密码有被修改过。 否：表示此用户名的密码未被修改过。 |
