# 删除业务发放统计规则(RMV PROVSTATRULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除业务发放统计对象的匹配规则。

## 注意事项

无。

## 参数说明

| 参数标识            | 参数名称       | 参数说明                                                                           |
|:----------------|:-----------|:-------------------------------------------------------------------------------|
| PROVSTATOBJNAME | 业务发放统计对象名称 | 标识一条业务发放统计规则数据记录的关键字段之一，用于指定需要删除哪一条业务发放统计对象数据记录，操作员可以使用LST PROVSTATRULE命令查询获得。 |
| CMDNAME         | 命令名称       | 标识一条业务发放统计规则数据记录的关键字段之一，用于指定需要删除哪一条命令数据记录，操作员可以使用LST PROVSTATRULE命令查询获得。       |

## 使用实例

某局点在网管上做话务统计时需要删除业务发放统计规则，“业务发放统计对象名称”为“HSS9860 Commands Statistic”，“命令名”为“LGI”：

```
RMV PROVSTATRULE: PROVSTATOBJNAME="HSS9860 Commands Statistic", CMDNAME="LGI";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                    | 原因分析                  | 处理建议                                                                 |
|-------:|:-------------------------|:----------------------|:---------------------------------------------------------------------|
| 274587 | 业务发放统计对象名称不存在。           | 要删除的“业务发放统计对象名称”不存在。  | 执行LST PROVSTATOBJ命令查看当前已经添加的业务发放统计对象，输入查询到的“业务发放统计对象名称”后，重新执行本命令。    |
| 274591 | 该业务发放统计对象下，不存在该命令名的匹配规则。 | 输入的该“命令名称”对应的匹配规则未配置。 | 执行LST PROVSTATRULE命令查看当前已配置的“命令名称”对应的业务发放统计规则，输入查询到的“命令名称”后，重新执行本命令。 |
