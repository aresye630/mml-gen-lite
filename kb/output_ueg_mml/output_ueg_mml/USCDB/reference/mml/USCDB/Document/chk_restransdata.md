# 检查迁移用户恢复状态(CHK RESTRANSDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于检查迁移用户数据的恢复状态。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称          | 参数说明                                                                                                             |
|:------------|:--------------|:-----------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 业务类型          | 可选必选说明：必选参数 参数含义：用于指定检查哪个业务类型的迁移用户数据的恢复状态。 取值范围：长度不超过128的字符串 默认值：无。 配置原则：此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。 |
| CID         | DSU cluster标识 | 可选必选说明：可选参数 参数含义：用于指定检查哪个DSU Cluster的迁移用户数据的恢复状态，若不输入，则表示对该业务类型的所有DSU Cluster进行检查。 取值范围：2～4096 默认值：无。 配置原则：无。    |

## 使用实例

检查业务类型为SUP-FE的所有DSU Cluster的迁移用户数据的恢复状态。

```
CHK RESTRANSDATA: SERVICETYPE="SUP-FE";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 节点标识      | 用于表示节点的节点标识。                                                                                                                                     |
| FE类型      | 用于返回迁移用户数据恢复状态的FE类型。                                                                                                                             |
| 已恢复对象数    | 用于返回迁移用户数据已恢复的对象数。                                                                                                                               |
