# 增加远端网元IP地址(ADD RIPADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，该操作可能会导致业务中断。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于增加远端网元IP地址，使得本端网元和远端USCDB或者远端FE网元链路互通。

## 注意事项

- 当对容灾场景下的容灾局USCDB进行配置时，远端IP地址业务类型必须通过本命令配置为远端对应的业务类型，而不能配置成USCDB类型，否则本端网元与远端网元连接不上。
- 执行该命令后需要通过**ACT IPDISP**命令激活IP链路之后配置才能生效。
- 该命令不允许进行批操作。
- 如果IP地址相同，“远端IP地址业务类型”必须不同。

## 参数说明

| 参数标识    | 参数名称               | 参数说明                                                                                                                                                                                                                                                                                        |
|:--------|:-------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RLOCID  | 远端Location标识       | 用于指定一个远端网元标识。该参数须在对接的远端USCDB网元或者FE网元中先定义，然后在本端网元通过ADD RLOCATION命令配置后，才能在此处索引。远端Location是相对的，具体如下：对于主用局FE，它的远端Location指主用局USCDB或容灾局USCDB。对于主用局USCDB，它的远端Location指主用局FE、容灾局FE或容灾局USCDB。对于容灾局FE，它的远端Location指容灾局USCDB或主用局USCDB。对于容灾局USCDB，它的远端Location指容灾局FE、主用局FE或主用局USCDB。 取值范围：1～512 默认值：无。 |
| ID      | 远端DPU模块号/远端业务IP索引  | 用于指定远端网元IP地址对应的远端DPU模块号/远端业务IP索引。在与远端ATCA或NFV USCDB对接场景下，需要配置“远端DPU模块号”；在与远端PaaS USCDB或FE网元对接场景下，需要配置“远端业务IP索引”。 该参数必须在对接的远端USCDB网元或者FE网元中先定义，然后才能在此处索引。 取值范围：1～4080 默认值：无。                                                                                                                 |
| IPVER   | IP类型               | 用于指定远端IP地址类型。 取值范围： IPV4：当系统要求使用IPv4类型的IP地址时选择此选项。IPV6：当系统要求使用IPv6类型的IP地址时选择此选项。 默认值：无。                                                                                                                                                                                                     |
| IPV4IP1 | 远端Location IPV4地址1 | 用于指定远端网元的Location IP地址。这个地址必须在对接的远端USCDB网元或者FE网元中已经配置完毕。当参数“IP类型”设置为“IPV4(IPV4)”时，该参数有效。 取值范围：IPV4地址。 默认值：无。                                                                                                                                                                                |
| IPV6IP1 | 远端Location IPV6地址1 | 用于指定远端网元的Location IP地址。这个地址必须在对接的远端USCDB网元或者FE网元中已经配置完毕。 当参数“IP类型”设置为“IPV6(IPV6)”时，该参数有效，格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如：2001:DB8:8432:4098:4782:5784::。 取值范围：IPV6地址。 默认值：无。                                                                                                |
| IPV4IP2 | 远端Location IPV4地址2 | 用于指定远端网元的Location IP地址。这个地址必须在对接的远端USCDB网元或者FE网元中已经配置完毕。当参数“IP类型”设置为“IPV4(IPV4)”时，该参数有效。 取值范围：IPV4地址。 默认值：无。                                                                                                                                                                                |
| IPV6IP2 | 远端Location IPV6地址2 | 用于指定远端网元的Location IP地址。这个地址必须在对接的远端USCDB网元或者FE网元中已经配置完毕。 当参数“IP类型”设置为“IPV6(IPV6)”时，该参数有效，格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如：2001:DB8:8432:4098:4782:5784::。 取值范围：IPV6地址。 默认值：无。                                                                                                |
| RDPUST  | 远端IP地址业务类型         | 用于指示远端IP地址的业务类型，此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。 取值范围：长度不超过128的字符串。 默认值：无。                                                                                                                                                                                                           |

## 使用实例

在开局场景下，增加远端网元IP地址，“远端Location标识”为“3”，“远端DPU模块号/远端业务IP索引”为“1”，“IP类型”为“IPV4”，“远端Location IPV4地址1”为“172.21.128.24”，“远端Location IPV4地址2”为“172.21.128.25”，“远端IP地址业务类型”为“SUP-FE”：

```
ADD RIPADDR: RLOCID=3, ID=1, IPVER=IPV4, IPV4IP1="172.21.128.24", IPV4IP2="172.21.128.25", RDPUST="SUP-FE";
```
