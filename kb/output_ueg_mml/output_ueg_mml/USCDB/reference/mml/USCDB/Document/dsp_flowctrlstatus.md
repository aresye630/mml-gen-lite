# 查询各模块系统流控状态相关信息（DSP FLOWCTRLSTATUS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询各模块的流控状态相关信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                    |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MID    | 模块号    | 可选必选说明：可选参数 参数含义：用于指定需要查询流控状态信息的模块号。若不输入，则表示查询所有模块号的流控状态信息。 取值范围：1~4080 默认值：无。 配置原则：无。                                                                                                  |
| MT     | 模块类型   | 可选必选说明：可选参数 参数含义：用于指定需要查询流控状态信息的模块类型。若不输入，则表示查询所有模块类型的流控状态信息。 取值范围： DPU(DPU)NDF(NDF)DBG(DBG)DRU(DRU)DSU(DSU)DSG(DSG)PGW(PGW)DMA(DMA)CAG(CAG) 默认值：无。 配置原则：当前版本仅支持查询DSG、DRU、DSU模块的流控状态信息。 |

## 使用实例

当需要查询“模块号”为“3”的流控状态信息时:

```
DSP FLOWCTRLSTATUS: MID=3;
```

```
%%DSP FLOWCTRLSTATUS: MID=3;%% 
RETCODE = 0  操作成功
操作结果如下
------------
模块号  模块类型    状态名称                                                          状态值   
3        DSG        Flow control status                                               1      
3        DSG        SCTP queue delay                                                  20      
3        DSG        Percentage of messages discarded due to coordinated flow control  0       
3        DSG        Percentage of messages discarded due to pre-queuing flow control  0      
 (结果个数 = 4)
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1。

| 输出项名称   | 输出项解释                                                                                                                                                                                                                                                              |
|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 模块号     | 用于返回查询到的流控状态信息对应的模块号。                                                                                                                                                                                                                                              |
| 模块类型    | 用于返回查询到的流控状态信息对应的模块类型。                                                                                                                                                                                                                                             |
| 状态名称    | 用于返回查询到的流控状态相关信息。 Flow control statusSCTP queue delayPercentage of messages discarded due to coordinated flow controlPercentage of messages discarded due to pre-queuing flow control  说明： SCTP queue delay仅支持测量DSG模块的流控状态信息。                                      |
| 状态值     | 用于返回各个流控状态值。  说明： “Flow control status”的状态值为“1”时表示开启流控，状态为“0”时表示关闭流控。“SCTP queue delay”的状态值的单位是毫秒（ms）。“Percentage of messages discarded due to coordinated flow control”的状态值的单位是“%”。“Percentage of messages discarded due to pre-queuing flow control”的状态值的单位是“%”。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释                         | 原因分析                                  | 处理建议                                                  |

|  2753 | 对应模块异常。                       | 执行该命令查询的对应模块异常。                       | 请联系华为技术支持。                                            |
|  2754 | 输入的模块号不存在。                    | 执行该命令查询的模块号不存在。                       | 执行LST MODULE命令查看需要查询流控状态信息的“模块号”，再执行该命令查询。            |
|  2755 | 模块号与模块类型不匹配。                  | 执行该命令查询的模块号和模块类型不匹配。                  | 执行LST MODULE命令查看需要查询流控状态信息的“模块号”和对应的“模块类型”，再执行该命令查询。  |
