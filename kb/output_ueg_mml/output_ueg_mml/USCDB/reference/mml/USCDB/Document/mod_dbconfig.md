# 修改物理库配置(MOD DBCONFIG)

## 命令功能

**须知** 

该命令属于高危命令，该操作可能会导致连接物理库失败。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改访问物理数据库的配置。PGW进程、DBG进程或DMA进程通过配置的端口访问物理数据库，命令使用端口需与USCDB创建物理数据库时的配置保持一致。

## 注意事项

- 本命令支持联机设定，修改后不必重启PGW进程、DBG进程或DMA进程。
- 本命令在实验室环境使用。
- 执行本命令修改物理数据库配置后，需要执行**RST MODULE**命令，重启全部的NDF模块。
- 请确认访问物理数据库的配置信息，可以使用**LST DBCONFIG**命令查询配置信息。默认情况下是ClickHouse数据库的配置信息，结果如下：

  ```
  %%LST DBCONFIG:;%%
  RETCODE = 0  操作成功

  操作结果如下
  ------------
           IP类型  =  IPV4
  物理库IPV4地址1  =  172.18.128.130
  物理库IPV6地址1  =  NULL
      物理库端口1  =  9201
  物理库IPV4地址2  =  172.19.128.130
  物理库IPV6地址2  =  NULL
      物理库端口2  =  9201
  (结果个数 = 1)

  ---    END
  ```
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                 |
|:-------|:-------|:-------------------------------------|
| PORT1  | 物理库端口1 | 用于指定物理数据库的IP地址1对应的端口。 取值范围：9201-9299 |
| PORT2  | 物理库端口2 | 用于指定物理数据库的IP地址2对应的端口。 取值范围：9201-9299 |

## 使用实例

修改访问物理数据库的端口为9210：

```
MOD DBCONFIG: PORT1=9210,PORT2=9210;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                        | 原因分析                                                                                               | 处理建议                                           |
|-------:|:-----------------------------|:---------------------------------------------------------------------------------------------------|:-----------------------------------------------|
| 483018 | 参数“PORT1”或者“PORT2”的值不在指定范围内。 | 参数“物理库端口1”或者“物理库端口2”的取值不在9201-9299范围内。                                                             | 重新执行本命令，输入参数“物理库端口1”和“物理库端口2”的取值在9201-9299范围内。 |
| 483019 | 无效的参数名称。                     | 输入了参数“物理库端口1”和“物理库端口2”之外的其他参数，如参数“IP类型”、“物理库IPV4地址1”、“物理库IPV6地址1”、“物理库IPV4地址2”、和“物理库IPV6地址2”不支持输入。 | 重新执行本命令，只输入参数“物理库端口1”和“物理库端口2”。                |
