## 命令功能

**须知** 

该命令属于高危命令，该命令会导致节点上的业务短暂中断，可能对业务造成影响。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于为节点设置或取消Master特权。在正常运行过程中，手工指定的Master节点成为Master节点的优先级最高。在一个Cluster中，只要存在手工指定的Master节点，其他Slave节点都不可能通过自动选举成为Master节点。

该命令主要用于维护场景，当一个Cluster内存在多个Master或没有Master时，可以通过该命令重新快速调整节点的状态。

## 注意事项

- 任意设置节点状态可能造成一个Cluster内出现多个Master或没有Master的情况，该场景下会对业务处理产生影响，因此建议操作员在设置节点状态前使用**DSP NODE**查询节点的信息。
- 手工指定某个Slave节点为Master节点，会导致业务的短暂中断。
- 在承载网故障场景下，执行该命令可能导致业务产生大量呼损。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                   |
|:--------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CID     | Cluster标识 | 用于定义一个待设置节点所属Cluster的Cluster标识。Cluster标识在2～4096的Cluster是通过ADD CLUSTER定义后在此引用，而Cluster标识为1的Cluster是添加USCDB网元时，系统自动生成供内部使用，不需要手工添加。 取值范围：1～4096 默认值：无。                                                                                                                                   |
| NID     | 节点标识      | 用于定义一个待设置节点的节点标识。 取值范围：1～32768 默认值：无。                                                                                                                                                                                                                                                  |
| SETTYPE | 设置类型      | 用于定义一个待设置节点的Master特权。如果手工指定的节点在指定前是被自动选举为Master节点的，则该Master节点会增加一项手工指定Master节点的特权。在特权未被取消之前，该Master节点不会自动退位为Slave节点。 该参数的配置原则： 当节点处于备份状态时，操作员不能通过该命令进行节点状态设置，否则命令会执行失败。 当待设置节点为Slave节点时，则不能重复取消节点的Master特权，否则命令会执行失败。 取值范围： CANCEL(取消)：取消节点的Master特权。SETTING(设置)：设置节点的Master特权。 默认值：无。 |
| FORCE   | 是否强制设置    | 用于定义一个待设置节点的Master特权是否强制执行。 用于设置是否强制指定节点状态。 取值范围：NO(否)：系统执行设置时，检测一些系统资源的使用情况，这些资源的使用率超过阈值时，会给出操作提示信息。YES(是)：系统直接执行。 默认值：NO(否)。                                                                                                                                                         |

## 使用实例

维护场景下，需要手工指定Slave节点为Master节点时，此时需要做如下配置。

1. 执行**DSP NODE**命令，确认待加载节点的“备份状态”为“未备份”，“流控状态”为“关”。

2. 执行如下命令，将节点101的Slave状态设置成Master状态。

   ```
   SET NODE: CID=100, NID=101, SETTYPE=SETTING;
   ```
3. 执行**DSP NODE**命令，查看执行命令后节点状态，节点100自动降为Slave状态。

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                           | 原因分析                   | 处理建议                                            |
|-------:|:--------------------------------|:-----------------------|:------------------------------------------------|
| 260104 | 该cluster不存在。                    | 输入的“Cluster标识”在系统中未配置。 | 通过LST CLUSTER命令查询已配置的“Cluster标识”，然后重新执行本命令。     |
| 260113 | 参数NID指定的节点在参数CID指定的cluster中不存在。 | 输入的“节点标识”在Cluster中未配置。 | 通过LST NODE命令查询已配置的“节点标识”和“Cluster标识”，然后重新执行本命令。 |
| 260115 | 参数NID指定的节点不存在。                  | 输入的“节点标识”在系统中未配置。      | 通过LST NODE命令查询已配置的“节点标识”，然后重新执行本命令。             |
