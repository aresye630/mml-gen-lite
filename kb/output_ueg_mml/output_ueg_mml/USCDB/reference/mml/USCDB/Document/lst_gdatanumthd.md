# 查询全局数据记录数超限阈值（LST GDATANUMTHD）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询全局数据记录数超限阈值配置信息。

- 若需要查询全部全局数据记录数超限阈值配置记录，请不要输入任何参数。
- 若需要查询某条全局数据记录数超限阈值配置的详细信息，请输入“业务类型”或“表名称”或这两个参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                          |
|:------------|:-------|:----------------------------------------------------------------------------------------------|
| SERVICETYPE | 业务类型   | 可选必选说明：可选参数。 参数含义：用于指定具体的服务类型，包括USCDB和FE的插件包类型。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。             |
| TABLENAME   | 表名称    | 可选必选说明：可选参数。 参数含义：用于指定内存库全局数据的表名。表名可通过执行DSP NODECOUNT命令查询获取。 取值范围：长度不超过64的字符串。 默认值：无。 配置原则：无。 |

## 使用实例

查询一条全局数据记录数超限阈值记录：设置“业务类型”为“SUP-FE”，“表名称”为“G\_ALLTYPE\_SUB1\_INFO5\_TPL”。

```
LST GDATANUMTHD: SERVICETYPE="SUP-FE", TABLENAME="G_ALLTYPE_SUB1_INFO5_TPL";
```

```
%%LST GDATANUMTHD: SERVICETYPE="SUP-FE", TABLENAME="G_ALLTYPE_SUB1_INFO5_TPL";%%
RETCODE = 0  操作成功

操作结果如下
------------------------
    业务类型  =  SUP-FE
      表名称  =  G_ALLTYPE_SUB1_INFO5_TPL
  记录数阈值  =  10
(结果个数 = 1)

---    END
```

查询全部已配置的全局数据记录数超限阈值记录。

```
LST GDATANUMTHD:;
```

```
%%LST GDATANUMTHD:;%%
RETCODE = 0  操作成功

操作结果如下
------------------------
 业务类型      表名称                    记录数阈值

 USCDB         G_ALLTYPE_SUB1_INFO5_TPL  10              
 SUP-FE        G_ALLTYPE_SUB1_INFO5_TPL  10              
 SUP-FE        G_ALLTYPE_SUB1_INFO7_TPL  5               
(结果个数 = 3)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD GDATANUMTHD**命令的参数说明。
