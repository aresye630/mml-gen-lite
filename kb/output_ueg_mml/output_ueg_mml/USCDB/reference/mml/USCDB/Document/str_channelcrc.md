# 启动Channel数据CRC检查(STR CHANNELCRC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于启动模块的Channel数据一致性检查和校正功能。

实验局在涉及到DRU Cluster的增加、删除或者修改时，会造成Channel数据和DRU Cluster对应关系的不一致，此时需要通过本命令重新调整channel数据和DRU Cluster的对应关系。如果实验局中已经有模拟用户，需要将模拟用户删除之后，再执行本命令。

## 注意事项

- 网上运行局点严禁执行本命令，否则会使Channel数据和DRU Cluster对应关系不一致，从而导致业务失败。
- 该命令只支持模块类型为DRU、DSU以及DSG的模块进行Channel数据一致性检查和校正功能。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                   |
|:------------|:-------|:-----------------------------------------------------------------------------------------------------------------------|
| MID         | 模块号    | 用于指定对哪个模块启动Channel数据一致性检查和校正功能。该参数通过ADD MODULE命令定义后才能在此引用。 说明： 当该参数配置为“0”或不配置，表示对所有DRU、DSU、DSG模块启动Channel数据一致性检查或校正功能。 |
| CORRECTTYPE | 校正类型   | 用于指定命令是否进行校正。 各参数选项的含义是： NO(不执行校正)：只对Channel数据进行检查，不自动进行校正。YES(执行校正)：对Channel数据进行检查并自动校正。 默认值：NO(不执行校正)。               |
| MT          | 模块类型   | 用于定义待启动Channel数据CRC检查的模块类型。 取值范围： DSG(DSG)DRU(DRU)DSU(DSU) 默认值：无。                                                      |
| FETYPE      | FE类型   | 用于指定待启动Channel数据CRC检查的FE类型。 该参数在USCDB下唯一，在通过LOD FEPLUG命令加载FE插件包之后才能在此引用。                                               |

## 使用实例

实验局中进行DRU Cluster调整后，启动Channel数据检查：以“模块号”为“22”为例，执行如下命令：

```
STR CHANNELCRC: MID=22;
```

```
%%STR CHANNELCRC: MID=22;%%

------------

  FE类型  =  SUP-FE

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                     | 原因分析                          | 处理建议                                                                    |
|------:|:--------------------------|:------------------------------|:------------------------------------------------------------------------|
|  2043 | 模块号不存在。                   | 输入的“模块号”在系统中不存在。              | 执行LST MODULE命令查询“模块号”信息，然后参考本命令的“模块号”参数说明，重新执行本命令。                      |
|  2044 | 参数模块号指定的模块不是DRU，DSU或者DSG。 | 输入的“模块号”对应的模块必须是DRU、DSU或者DSG。 | 执行LST MODULE命令查询“模块号”信息，然后重新执行本命令。                                      |
|  2045 | 参数模块号指定的模块状态异常。           | 输入的“模块号”对应的模块状态异常。            | 请参见产品手册的“模块故障”进行处理。                                                     |
|  2053 | 已有一个检查任务在运行。              | 上一次执行的检查任务未结束，系统正在处理中。        | 无需处理。                                                                   |
|  2175 | 仅当校正类型为YES时模块号可以设置为0      | 输入的“模块号”为“0”时，“校正类型”必须为“YES”。 | 请确认需要对“模块号”为“0”的模块进行channel数据一致性校验：把“校正类型”设置为“YES”，“模块号”为“0”，然后重新执行本命令。 |
|  2593 | 模块ID和模块类型不匹配              | 输入的“模块号”与输入的“模块类型”不匹配。        | 执行LST MODULE命令查询“模块号”信息，重新输入正确的“模块类型”后执行本命令。                            |
|  2594 | 模块ID和FE类型不匹配              | 输入的“模块号”与输入的“FE类型”不匹配。        | 执行LST MODULE命令查询“模块号”信息，重新输入正确的“FE类型”后执行本命令。                            |
