# 修改号段范围(MOD NUMRANGE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改某个城市的MSISDN或IMSI号段范围信息。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                    |
|:-----------|:---------|:--------------------------------------------------------|
| CITY       | 城市       | 用于指定需要修改号段范围信息的城市。 取值范围：长度不超过128的字符串。 默认值：无。            |
| OBJECTID   | 对象ID     | 用于标识统计对象。 取值范围：OBJECT0～OBJECT829 默认值：无。                 |
| ISDNBEGNUM | ISDN起始号码 | 用于标识参数“CITY”指定的城市的MSISDN起始号码。 取值范围：长度不超过128的字符串。 默认值：无。 |
| ISDNENDNUM | ISDN结束号码 | 用于标识参数“CITY”指定的城市的MSISDN结束号码。 取值范围：长度不超过128的字符串。 默认值：无。 |
| IMSIBEGNUM | IMSI起始号码 | 用于标识参数“CITY”指定的城市的IMSI起始号码。 取值范围：长度不超过128的字符串。 默认值：无。   |
| IMSIENDNUM | IMSI结束号码 | 用于标识参数“CITY”指定的城市的IMSI结束号码。 取值范围：长度不超过128的字符串。 默认值：无。   |

## 使用实例

修改城市“A”的号段范围信息：

```
MOD NUMRANGE: CITY="A", OBJECTID=OBJECT2, ISDNBEGNUM="5555", ISDNENDNUM="6666", IMSIBEGNUM="7777", IMSIENDNUM="8888";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                | 原因分析                  | 处理建议                                                                      |
|-------:|:---------------------|:----------------------|:--------------------------------------------------------------------------|
| 260257 | 输入的CITY参数值不存在。       | 输入的“CITY”参数在系统中未配置。   | 执行LST NUMRANGE命令查看已经配置了哪些号段范围信息，将输入的“CITY”参数和查询到的信息中“城市”这一列进行对比，检查输入是否正确。 |
| 260008 | 参数未修改，请至少指定一个待修改的参数。 | 输入的参数未对系统中原有的配置做任何修改。 | 执行LST NUMRANGE命令，输入参数和执行MOD NUMRANGE输入的参数保持一致，对比查询到的结果，至少修改一个参数的值。        |
| 275492 | 参数CITY取值无效。          | 参数“CITY”的取值不能只为空格。    | 请重新输入，确保输入的“CITY”符合参数的取值范围。                                               |
