# 查询第三方网管参数（LST NMDCONN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为维护类命令，用于查询网管直连性能管理功能开关状态。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询网管直连性能管理功能开关状态:

```
LST NMDCONN:;
```

操作结果如下：

```
%%LST NMDCONN:;%%
RETCODE = 0  操作成功

操作结果如下:
------------------------
  SW  =  ON
(结果个数 = 1)

---    END
```

## 输出结果说明

| 参数名称   | 参数描述                          |
|:-------|:------------------------------|
| SW     | 表示网管直连性能管理功能的开关状态，其值为“开”或“关”。 |
