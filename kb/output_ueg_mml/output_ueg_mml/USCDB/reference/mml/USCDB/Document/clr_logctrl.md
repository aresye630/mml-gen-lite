# 清空日志手动控制(CLR LOGCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于清空日志手动控制记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                         |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------|
| TYPE   | 模块类型   | 可选必选说明：必选参数 参数含义：用于指定需要清空日志手动控制记录的模块类型。 取值范围：DPU(DPU)NDF(NDF)DBG(DBG)DSG(DSG)DRU(DRU)DSU(DSU)PGW(PGW)DMA(DMA) 默认值：无。 配置原则：无。 |

## 使用实例

清空日志手动控制记录，“模块类型”为“PGW”。

```
CLR LOGCTRL: TYPE=PGW;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释   | 原因分析                               | 处理建议                                  |
|------:|:--------|:-----------------------------------|:--------------------------------------|
|  1710 | 无可用模块。  | 系统中未添加指定“模块类型”的模块。指定“模块类型”的模块全部异常。 | 根据原因进行对应的处理： 无需处理。请参见产品手册的“模块故障”进行处理。 |
|  1967 | 部分操作超时。 | 指定“模块类型”的部分模块异常。                   | 请参见产品手册的“模块故障”进行处理。                   |
