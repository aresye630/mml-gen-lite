# 设置第三方网管参数（SET NMDCONN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

此命令是高危命令，该操作将设置第三方网管功能配置，操作不当将造成业务功能受损，需联系华为技术支持确认后再执行。

该命令为维护类命令，用于设置网管直连性能管理功能开关状态。

该命令的使用场景：在开局场景下，根据客户的特殊组网要求，在明确使用兼容的第三方网管场景下，参考操作指导书步骤配置。

## 注意事项

- 在打开网管直连性能管理功能开关前，必须要确保omu中至少有800MB的空间，用于存放性能测量数据。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。
- 非使用第三方兼容网管场景下严禁使用该命令。

## 参数说明

| 参数标识   | 参数名称           | 参数说明                                              |
|:-------|:---------------|:--------------------------------------------------|
| SW     | 网管直连性能管理功能开关状态 | 用于设置网管直连性能管理功能开关状态。 取值说明： “OFF(关)”“ON(开)” 默认值： 无。 |

## 使用实例

设置网管直连性能管理功能开关状态，“网管直连性能管理功能开关状态”为“ON(开)”:

```
SET NMDCONN: SW=ON;
```

操作结果如下：

```
%%SET NMDCONN: SW=ON;%%
RETCODE = 0  操作成功
```
