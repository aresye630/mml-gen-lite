## 命令功能

**须知** 

该命令属于高危命令，该操作将启动用户数据迁移，话务高峰、过多任务并行、参数设置不当等，将导致业务呼损，扩容失败等严重后果。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于启动一个用户数据迁移任务。用户数据迁移的主要使用场景为：

- 在DSU扩容场景，需要手工将原DSU节点中的部分用户数据迁移到扩容的DSU节点中。
- 当某个DSU节点内存占用率较高，需要将用户数据迁移到其它的DSU节点。
- 在DSU扩容场景，需要将新扩节点上新开户的用户数据迁移至旧DSU节点。
- 在DSU缩容场景，需要先执行**MOD SEGSTATE**设置隔离模块，否则，主PGW接收到**STR USERTRANS**命令后，将认为是扩容迁移。

## 注意事项

- 用户数据迁移启动前

  - 检查DSU、DMA模块状态，确保模块状态正常。
  - 暂停业务发放系统下发开销户、补卡、改号等涉及用户数据修改的指令。

  **说明** 

  系统进行用户数据迁移所需要的时间长短与用户量大小有关。因此，在进行用户数据迁移操作之前请联系华为技术支持明确具体的迁移时长。
- 用户数据迁移启动前通过**LST INSP**命令检查如下开关已正确设置:
  - 周期性校验开关确保已全部关闭，包括软参FWDRTVFYSWT（正向路由校验开关）、REVVFYSWT（反向校验开关）、FWDVFYSWT（正向校验开关）、REVRTVFYSWT（反向路由校验开关）要全部设置为“0”。
  - 用户数据统计开关确保已关闭，即软参USERDATAMEASUREFLAG（定时用户数据统计开关）已设置为“0”。
  - 周期性备份开关已关闭，即软参TIMEBACKUPFLAG（定时备份开关）设置为“0”。
  - 局间校验已关闭，即软参REDUNDANCYSWITCH（容灾开关）已设置为“1”。
- 混合组网场景下，对于执行扩缩容操作的分区以及该分区对接的其他分区，通过**LST PARTITIONPARA**命令检查“全局路由校验开关”的状态是否已关闭。如没有关闭，需要通过**SET PARTITIONPARA**命令将“全局路由校验开关”设置为“Off（关闭）”。
- 用户数据迁移过程中

  - 可以执行**DSP USERTRANS**命令查询用户数据迁移的状态。
  - 除查询命令之外，不允许执行其他任何涉及数据修改的命令。
- 用户数据迁移完成后

  - 恢复暂停的业务发放系统业务。
  - 打开内存数据库的校验开关。
  - 打开用户数据统计开关。
  - 打开定时备份开关。
  - 恢复局间校验正常进行。
  - 混合组网场景下，恢复扩缩容操作的分区以及该分区对接的其他分区“全局路由校验开关”为初始状态。
- 在融合场景下，为保证用户数据迁移操作的数据安全性，减少对业务发放系统的影响，建议每个FE网元单独进行用户数据迁移操作。
- 为保证用户数据迁移操作的数据完整性，不对开户60秒之内的用户数据进行迁移。
- 该命令禁止通过定时自动任务执行。
- 启动用户数据迁移任务的DMA模块状态必须正常。若无“ALM-1003 模块故障”，则说明DMA模块状态正常。
- 在同构容灾场景下，无论BE主备组网还是BE互备组网，都只能在主用BE进行数据迁移的操作。因为数据迁移就是一个销户再开户的操作，而备用BE是不能进行此类涉及到路由修改的操作。
- 用户数据迁移不能和内存库导出同时进行，会增大USCDB的负荷，导致用户数据迁移及其他业务失败。
- 为确保系统的稳定运行，用户数据迁移必须在话务量低的时间段（例如凌晨2:00～4:00）进行。
- 该命令不允许进行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                    |
|:-------|:-------|:----------------------------------------------------------------------------------------|
| FETYPE | FE类型   | 用于指定启动哪个FE类型的用户数据迁移任务，此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。 取值范围：长度不超过128的字符串。 默认值：无。 |

## 使用实例

在DSU扩容场景下启动一个用户数据迁移，“FE类型”为“SUP-FE”：

```
STR USERTRANS: FETYPE="SUP-FE";
```
