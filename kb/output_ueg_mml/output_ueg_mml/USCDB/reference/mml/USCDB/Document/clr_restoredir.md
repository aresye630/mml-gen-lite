# 删除恢复目录(CLR RESTOREDIR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，该操作将删除特定目录的内存库备份文件，操作不当会影响数据的恢复。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于按指定服务类型删除已设置的指定恢复目录记录，且支持删除紧急恢复目录下的文件。

## 注意事项

- 命令成功执行需满足如下条件：

  - 指定目录恢复开关“SPCFDIRRSTSWT（指定目录恢复开关）”关闭，即参数取值为“0”。
  - “LDRSOURCE（加载数据源）”参数值设置为非指定目录加载，即参数取值为非“3”。
- 该命令执行成功后，ALM-10004 系统处于指定目录恢复数据模式告警恢复。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                  |
|:------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 服务类型   | 用于指定待删除指定恢复目录具体的服务类型。                                                                                                                                                                                                                                                                                                                                 |
| LOCINFO     | 位置信息   | 用于指定待删除恢复目录所在局点的位置信息。 取值范围： LOCAL（本地） REMOTE（远端） 默认值：Local                                                                                                                                                                                                                                                                                            |
| DIRECTORY   | 目录     | 用于指定待删除的恢复目录。 取值范围： UPGPLANE1(1平面/opt/uscdb/SNP_UPG/目录) UPGPLANE0(0平面/opt/uscdb/SNP_UPG/目录) EMGRST(紧急恢复目录)：目录为“/opt/uscdb/emgRst”。CURRENT(今日周期备份)：目录“/opt/uscdb/snp”中当天周期性备份文件。LAST(昨日周期备份)：目录“/opt/uscdb/snp”中前一天周期性备份文件。MIGRATION(迁入用户数据备份文件)： 目录“opt/uscdb/snp/USERDATA_BACKUP”中迁入用户数据备份文件。CHOPLOG(操作日志缓存文件)：目录“/opt/pgw/choplog”中操作日志缓存文件。 默认值：无。 |
| DELFILE     | 删除文件   | 仅当该命令中“目录”参数为“EMGRST(紧急恢复目录)”时该参数有效，用于表示是否删除指定目录下的文件。 取值范围： YES(是) NO(否) 默认值：NO(否)                                                                                                                                                                                                                                                                    |

## 使用实例

删除“服务类型”为“SUP-FE”、“位置信息”为“LOCAL（本地）”、“目录”为“EMGRST(紧急恢复目录)”、“删除文件”为“YES(是)”的恢复目录文件信息。

```
CLR RESTOREDIR: SERVICETYPE="SUP-FE", LOCINFO=LOCAL, DIRECTORY=EMGRST, DELFILE=YES;
```
