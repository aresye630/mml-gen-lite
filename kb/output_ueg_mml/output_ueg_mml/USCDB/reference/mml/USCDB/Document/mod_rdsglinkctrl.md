# 修改远端DSG链路中心(MOD RDSGLINKCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改远端DSG或DBS链路中心。

## 注意事项

- 通过“校验码”参数指定的远端链路中心的校验码，必须与在远端网元执行**ADD DSGLINKCTRL**或**MOD DSGLINKCTRL**指定的校验码一致，否则会导致配置消息无法发送到该远端。
- 由于USCDB网元是链路中心的服务端，本命令配置的“校验码”参数检查在USCDB网元侧进行，因此需要先执行本命令配置远端链路中心的“校验码”，再到FE网元侧执行**ADD DSGLINKCTRL**或**MOD DSGLINKCTRL**命令配置相同取值的“校验码”参数，或者到FE网元侧执行**ADD DBSLINKCTRL**或**MOD DBSLINKCTRL**命令配置相同取值的“本地链路中心校验码”参数。

  **说明** 

  本命令禁止配置的“校验码”可以通过**ADD WEAKPWD**命令配置或通过**LST WEAKPWD**命令查询。

## 参数说明

| 参数标识            | 参数名称              | 参数说明                                                                                                                                                                                                                                                                                        |
|:----------------|:------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RLOCID          | 远端Location标识      | 用于指定一个远端网元标识。该参数须在对接的远端USCDB网元或者FE网元中先定义，然后在本端网元通过ADD RLOCATION命令配置后，才能在此处索引。远端Location是相对的，具体如下：对于主用局FE，它的远端Location指主用局USCDB或容灾局USCDB。对于主用局USCDB，它的远端Location指主用局FE、容灾局FE或容灾局USCDB。对于容灾局FE，它的远端Location指容灾局USCDB或主用局USCDB。对于容灾局USCDB，它的远端Location指容灾局FE、主用局FE或主用局USCDB。 取值范围：1～512 默认值：无。 |
| RLINKCENTERTYPE | 远端链路中心类型          | 用于指定远端FE Location链路中心类型。 取值范围： DSG：表示大颗粒DSG链路中心。DBS：表示dbbroker微服务链路中心。 默认值：DSG                                                                                                                                                                                                              |
| IPVER           | IP类型              | 用于指定IP地址类型。 取值范围： IPV4：当系统要求使用IPv4类型的IP地址时选择此选项。IPV6：当系统要求使用IPv6类型的IP地址时选择此选项。 默认值：无。                                                                                                                                                                                                       |
| IPV4            | 远端Location IPV4地址 | 用于指定远端网元的Location IP地址。这个地址必须在对接的远端USCDB网元或者FE网元中已经配置完毕。当参数“IP类型”设置为“IPV4(IPV4)”时，该参数有效。 取值范围：IPV4格式的地址。 默认值：无。  须知： 对于不同业务类型的远端DSG，该参数的取值必须不同。                                                                                                                                             |
| IPV6            | 远端Location IPV6地址 | 用于指定远端网元的Location IP地址。这个地址必须在对接的远端USCDB网元或者FE网元中已经配置完毕。 当参数“IP类型”设置为“IPV6(IPV6)”时，该参数有效，格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如：2001:DB8:8432:4098:4782:5784::。 取值范围：IPV6格式的地址。 默认值：无。  须知： 对于不同业务类型的远端DSG，该参数的取值必须不同。                                                             |
| RDSGST          | 远端DSG业务类型         | 用于指定维护链路的远端网元类型名称。该参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。 取值范围：长度不超过128的字符串。 默认值：无。                                                                                                                                                                                                         |
| SHAKEY          | 校验码               | 用于指定远端链路中心的校验码。 取值范围：符合校验码复杂度的字符串。 校验码区分大小写，其复杂度需同时满足下列条件：必须至少包含以下四个类别中的三类：英文大写字母。英文小写字母。数字：0～9。特殊字符：~ ! # % ^ * ( ) _ - + [ ] { } | < > . ?。 不允许使用三个或三个以上连续的字母或数字（例如：ABC、123）。不允许使用三个或三个以上连续的相同字符（例如：AAA）。长度最短8个字符，最长30个字符。第一个字符必须是字母。不能和账号（即“unusedNmae”）或者账号的逆序一样，且不能包含账号或者账号的逆序。 默认值：无。 |

## 使用实例

修改远端DSG链路中心，“远端Location标识”为“77”，“远端链路中心类型”为“DSG”，“IP类型”为“IPV4”，“远端Location IPV4地址”为“172.21.128.25”，“远端DSG业务类型”为“SUP-FE”。命令示例如下：

```
MOD RDSGLINKCTRL: RLOCID=77, RLINKCENTERTYPE=DSG, IPVER=IPV4, IPV4="172.21.128.25", RDSGST="SUP-FE";
```
