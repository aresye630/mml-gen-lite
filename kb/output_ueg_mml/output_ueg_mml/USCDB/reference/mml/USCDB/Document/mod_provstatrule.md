# 修改业务发放统计规则(MOD PROVSTATRULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于修改业务发放统计对象的匹配规则。在该命令中，系统通过“业务发放统计对象名称”和“命令名”参数来唯一标识一条业务发放统计规则的数据记录。

## 注意事项

一个匹配规则里，“业务发放统计对象名称”标识规则所属的对象，“命令名”标识规则对应的MML命令，而其他参数则表示具体的匹配规则。这些参数之间的关系即：“第一个匹配参数的名称”和“第一个匹配参数对应的值”对应，标识MML命令中第一个需匹配的参数的名称和取值，可以只配置参数名称或者同时配置参数名称和取值，其它参数以此类推。

| PARA1NAME       | 第一个匹配参数的名称  | 用于指定业务发放统计规则的第一个匹配参数的名称，所输入的值必须是“命令名”对应的命令所允许携带的参数。 取值范围：长度不超过127位的字符串，字符串只能由数字（0～9）、大写英文字母（A～Z）、空格和下划线组成，必须以字母开头。 |

## 使用实例

修改业务发放统计规则，“业务发放统计对象名称”为“HSS9860 Commands Statistic”，“命令名”为“LGI”，“第一个匹配参数的名称”为“HLRSN”，“第一个匹配参数对应的值”修改为“2”：

```
MOD PROVSTATRULE: PROVSTATOBJNAME="HSS9860 Commands Statistic", CMDNAME="LGI", PARA1NAME="HLRSN", PARA1VALUE="2";
```
