# 查询节点加载的信息(DSP LOADINFO)

## 命令功能

该命令用于查询节点加载的信息：

- 若要查询所有节点加载的信息，请不要输入任何参数。
- 若要查询指定节点加载的信息，请输入“Cluster标识”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                |
|:------------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| CID         | Cluster标识 | 可选必选说明：可选参数。 参数含义：用于指示系统按照“Cluster标识”来查询节点加载的信息，该参数是通过ADD CLUSTER定义后在此引用；若不输入，则表示查询所有Cluster标识的加载信息。 取值范围：1～4096 默认值：无。 配置原则：无。                     |
| NID         | 节点标识      | 可选必选说明：可选参数。 参数含义：用于指示系统是按照哪个节点标识来查询节点加载的信息；若不输入，则表示查询所有节点标识的加载信息。 取值范围：1～32768 默认值：无。 配置原则：无。                                                      |
| CT          | Cluster类型 | 可选必选说明：可选参数。 参数含义：用于指定需要查询节点加载信息的Cluster类型；若不输入，则表示查询所有Cluster类型的加载信息。 取值范围： DRU(DRU)DSU(DSU) 默认值：无。 配置原则：无。                                        |
| SERVICETYPE | 业务类型      | 可选必选说明：可选参数。 参数含义：用于指定需要查询节点加载信息的业务类型；若不输入，则表示查询所有业务类型的加载信息。此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。USCDB类型默认已经加载。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。 |

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1中的参数说明。

| 输出项名称              | 输出项解释                                                                                                                                                                                                                                                                          |
|:-------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Cluster标识          | 用于表示节点所属的Cluster标识。为了便于管理和维护，Cluster标识建议遵循以下配置原则：“1”固定预留给存储USCDB公共数据的DRU Cluster，系统自动配置。从“2”到“30”，从“1025”到“4078”分配给存储全局数据的DRU Cluster。从“31”到“100”，从“513”到“612”，从“1025”到“4078”分配给存储路由数据的DRU Cluster。从“101”到“512”，从“613”到“1024”，从“1025”到“4078”分配给存储用户数据的DSU Cluster。 取值范围：1～4096 |
| 节点标识               | 用于表示节点的节点标识，此参数在Location内唯一。为了便于后续的维护，推荐节点标识和模块号的数值相同。                                                                                                                                                                                                                         |
| 加载源                | 用于表示该节点最近一次加载是从哪里加载的。 取值说明： 无数据源Master本地备份目录空库创建本地指定目录加载在线升级异常在线回退远端location数据紧急修复备份目录自带空间第三方服务器今日周期备份昨日周期备份本地指定时间加载第三方服务器（定时加载）本地备份目录（定时加载）Master（定时加载）  说明： 参数显示为“第三方服务器（定时加载）”、“本地备份目录（定时加载）”或者“Master（定时加载）”时，表示是ADD DATALODTIMETASK命令设置的定时加载任务。                           |
| 备份文件名称             | 用于表示该节点加载的备份文件的名称。                                                                                                                                                                                                                                                             |
| 加载的最后一个redolog文件名称 | 用于表示该节点加载的最后一个redolog文件的名称。                                                                                                                                                                                                                                                    |
| 加载的最后一条redolog的时间  | 用于表示该节点加载的最后一个redolog文件中最后一条redolog记录的操作时间。  说明： 报文中返回的最后一条redolog记录的操作时间为UTC时间。                                                                                                                                                                                               |
