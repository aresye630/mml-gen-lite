# 查询静态流控参数(LST STCFLOWCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询PGW静态流控参数。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询PGW静态流控参数：

```
LST STCFLOWCTRL:;
```

```
%%LST STCFLOWCTRL:;%%
RETCODE = 0  操作成功

操作结果如下
------------
启控命令数  =  300
  流控周期  =  5
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**MOD STCFLOWCTRL**命令的参数说明。
