# 查询FE插件和USCDB的升级信息(DSP UPGINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在升级实施阶段和升级观察期阶段查询USCDB和FE插件包的升级阶段和升级版本信息。在其他场景中，该命令执行后无信息返回。

## 注意事项

无。

## 参数说明

无。

## 使用实例

在升级实施阶段，查询USCDB和FE插件包的升级信息，执行命令如下：

```
DSP UPGINFO:;
```

```
%%DSP UPGINFO:;%%
RETCODE = 0  操作成功

操作结果如下
------------
 业务类型  源版本                     目标版本                   升级阶段  数据升级包

 USCDB     V100R002C06                V100R005C00B030            升级      USCDB_V100R005C00B030_SDB_UPG.tar
 SUP-FE    SUP-FE9820V900R006C00B061  SUP-FE9820V900R006C00B071  升级      SUP-FE_SUP-FE9820V900R006C00B071_SDB_UPG.tar
(结果个数 = 2)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1的参数说明。

| 输出项名称   | 输出项解释                                                                     |
|:--------|:--------------------------------------------------------------------------|
| 业务类型    | 用于表示FE类型名称。如果执行了USCDB版本升级，则此参数也可以表示USCDB。                                 |
| 源版本     | 用于表示USCDB或者FE插件包的源版本。如果FE类型是USCDB，此参数表示USCDB升级前的网元版本号；否则，表示FE升级前的插件包版本号。  |
| 目标版本    | 用于表示USCDB或者FE插件包的目标版本。如果FE类型是USCDB，此参数表示USCDB升级后的网元版本号；否则，表示FE升级后的插件包版本号。 |
| 升级阶段    | 用于表示升级阶段。 取值说明： 升级：表示处于升级实施状态中。观察期：表示升级实施已经结束，并处于升级观察期阶段。观察期一般为升级实施后两个星期。 |
| 数据升级包   | 用于表示USCDB或者FE插件包的数据升级包。                                                   |
