# 设置通知失败同步配置(SET NTFFAILEDSYNC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此命令用于设置订阅通知失败同步相关配置。

## 注意事项

与软参“NOTIFYCONTROL”相关联。

1. 当“NOTIFYCONTROL”设置为“1”时，**SET NTFFAILEDSYNC**的参数“SYNCSWITCH”设置为“ON”，可以记录订阅通知失败列表；**SET NTFFAILEDSYNC**的参数“SYNCSWITCH”设置为“OFF”，可以记录订阅通知失败列表。
2. 当“NOTIFYCONTROL”设置为“0”时，**SET NTFFAILEDSYNC**的参数“SYNCSWITCH”设置为“ON”，可以记录订阅通知失败列表；**SET NTFFAILEDSYNC**的参数“SYNCSWITCH”设置为“OFF”，无法记录订阅通知失败列表。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                          |
|:-----------|:-------|:----------------------------------------------|
| SUBERGRPID | 订阅组ID  | 用于标识订阅组ID。 取值范围：整型(1～255)。 默认值：无。             |
| SYNCSWITCH | 失败同步开关 | 用于标识订阅通知失败同步的开关。 取值范围： ON：开关打开OFF：开关关闭 默认值：无。 |
| PERIOD     | 文件生成周期 | 用于标识文件生成周期，单位为分钟。 取值范围：整型(1～1440)。 默认值：60分钟。  |

## 使用实例

设置通知失败同步配置，输入“订阅组ID”为“1”，“失败同步开关”为“ON”，“文件生成周期”为“10”：

```
SET NTFFAILEDSYNC:SUBERGRPID=1,SYNCSWITCH=ON,PERIOD=10;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释      | 原因分析       | 处理建议                                                                |
|-------:|:-----------|:-----------|:--------------------------------------------------------------------|
| 274638 | 该订阅组ID不存在。 | 该订阅组ID不存在。 | 先执行LST SUBSCRIBERGRP命令查询已经存在的“订阅组ID”，然后重新执行本命令，确保要查询的“订阅组ID”的值已经存在。 |
