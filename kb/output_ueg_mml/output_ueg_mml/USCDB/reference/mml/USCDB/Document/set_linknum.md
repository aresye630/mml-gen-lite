# 设置DSG链路条数(SET LINKNUM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，该操作将修改链路数配置，操作不当将造成链路故障，导致业务呼损。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置DSG模块之间的链路条数。DSG建链只限定与同业务类型之间的DSG模块，不同业务类型之间的DSG模块无链路。对接网元时，为避免大容量场景下DSG模块的链路数过多（会导致CPU资源占用过大，虚拟机（裸机）内存不足）的问题，可以使用本命令来设置DSG模块之间的链路条数，以达到减少链路条数的目的。

该命令的使用场景：在开局及扩容场景下，由于局点大小存在不均衡，经过评估链路数需要修改时，按指导书步骤进行配置。

## 注意事项

FE与BE互连时，假设FE的DBS个数为m，BE的DSG个数为n，链路数为LINKNUM，分为以下几种场景：

**说明** 

- 查询m的值，可在FE执行LST DBSSERVICENO命令。
- 查询n的值，可在BE执行LST MODULE命令。

- 当n小于LINKNUM时，采用全互连的方式。
- 当n大于等于LINKNUM时，BE的DSG个数除以FE的DBS个数大于4时，即x=n/m，当x＞4时，FE的DBS只向BE发起x个DSG建链请求。

  例如，当系统的链路数LINKNUM为8时：设n=10，m=2，则n＞LINKNUM，x=n/m，x=5，FE的DBS只向BE发起5个DSG建链请求。
- 当n大于等于LINKNUM时，BE的DSG个数除以FE的DBS个数小于等于4时，即x=n/m，当x≤4时，FE的DBS向BE的DSG按照配置的链路条数进行发起建链请求，但是实际链路数不超过全互连的链路数。

  例如，当系统的链路数LINKNUM为8时：

  - 设n=9，m=2，则n＞LINKNUM，x=n/m，x=4（向下取整），FE的DBS向BE的DSG按照配置的链路数LINKNUM进行发起建链请求；
  - 设n=8，m=2，则n=LINKNUM，x=n/m，x=4，FE的DBS向BE的DSG按照配置的链路数LINKNUM进行发起建链请求。
- FE和BE的链路数LINKNUM设置需一致。系统的链路数LINKNUM默认为8，不修改默认值的情况下，不需要设置链路数，也无法使用**LST LINKNUM**查询系统默认值。需要修改链路数默认值的时候，需要用本命令。
- 该命令不允许进行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                            |
|:------------|:-------|:--------------------------------------------------------------------------------|
| SERVICETYPE | 业务类型   | 用于表示FE网元的业务类型，此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。 取值范围：长度不超过128的字符串。 默认值：无。 |
| LINKNUM     | 链路数    | 用于设置FE与BE之间的链路条数。 取值范围：4～512，实际配置时33～511不能配置，512代表的是全互联。 默认值：无。                 |

## 使用实例

某局点为大容量局点，需要避免SUP-FE网元的DSG链路数过多，设置“业务类型”为“SUP-FE”，“链路数”为“16”。执行如下命令：

```
SET LINKNUM: SERVICETYPE="SUP-FE", LINKNUM=16;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                    | 原因分析               | 处理建议                                                                                                               |
|-------:|:-------------------------|:-------------------|:-------------------------------------------------------------------------------------------------------------------|
| 275308 | 参数SERVICETYPE指定的业务类型未配置。 | 指定的“业务类型”不存在或者未加载。 | 通过LST FEPLUG命令查询已加载的“FE类型名称”，“FE类型名称”即“业务类型”。 若业务类型加载成功，请输入正确的业务类型名称。若业务类型加载不成功或者没有加载，通过LOD FEPLUG命令加载成功后，重新执行该命令。 |
