# 设置NF信息(SET NFPROFILE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令属于高危命令，该操作设置网元的网络功能实体标识信息，配置错误将导致相关话统指标在网管上无法关联。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置NF（network function）信息，用于网管上报。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                       |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| NFINSID  | 服务实例ID | 用于标识一个NF实例的唯一通用识别码，由运营商统一规划，建议格式为“xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx”。例如：4947a69a-f61b-4bc1-b9da-47c9c5d14b64。 取值范围：长度不超过128的字符串。 默认值：无。 |
| FQDN     | 全量域名   | 用于定义一个NF在NRF注册的FQDN，由运营商统一规划。 取值范围：长度不超过128位的字符串。 默认值：无。                                                                                   |
| VNFINSID | 网元实例ID | 用于标识一个北向功能实体。 取值范围：长度不超过128位的字符串。 默认值：无。                                                                                                   |

## 使用实例

设置NF信息，“服务实例ID”为“4947a69a-f61b-4bc1-b9da-47c9c5d14b64”，“全量域名”为“udr001.5gc.mnc012.mcc345.3gppnetwork.org”。

```
SET NFPROFILE: NFINSID="4947a69a-f61b-4bc1-b9da-47c9c5d14b64", FQDN="udr001.5gc.mnc012.mcc345.3gppnetwork.org";
```
