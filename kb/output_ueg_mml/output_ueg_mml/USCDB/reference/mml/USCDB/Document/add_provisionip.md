# 添加业务发放系统IP地址(ADD PROVISIONIP)

- 命令功能

- 参数说明

## 命令功能

该命令用于在PGW中添加允许接入到PGW的SOAP、BOSS、REST、HTTP和WebLMT的IP地址。PGW中添加的IP地址用于PGW对客户端的鉴权，只有已经添加过的IP地址才允许建立链路。当SOAP、业务发放系统或WEBLMT客户端的连接请求到达PGW时，PGW从连接请求上获取客户端的IP地址。如果获取的该IP地址在SOAP、业务发放系统或Web LMT Server允许的IP地址列表中，则接受该连接，并进行后续的业务处理；否则拒绝该连接。为确保安全功能，在需要进行IP权限控制的场景下，可通过本命令进行设置。

## 注意事项

- PGW只使用IP地址进行鉴权，不保证IP地址的连通性，IP地址的连通性需要根据实际组网规划保证。
- 客户端接入管理配置受IP限制开关配置的影响，只有IP限制开关配置打开的情况下，客户端接入管理配置才生效。客户端接入管理配置生效时，如果没有配置对应端口类型的客户端接入IP，则无法通过该类型端口对系统做业务发放操作。

  IP限制开关配置包括2个：软参“GRANTIPSWITCH（IP限制开关）”配置和**SET GRANTIPSWITCH**命令配置。
  1. 软参“GRANTIPSWITCH（IP限制开关）”配置是IP限制总开关。
     - 软参值为“1”表示IP限制总开关打开。
     - 软参值为“0”表示IP限制总开关关闭。
  2. **SET GRANTIPSWITCH**命令配置是针对不同端口类型的IP限制子开关。
     - 命令配置中对应端口类型的“开关”配置为“打开”或者没有对应端口类型配置时表示子开关打开。
     - 命令配置中对应端口类型的“开关”配置为“关闭”时表示子开关关闭。
  - IP限制总开关打开，而子开关关闭时，对应端口类型的IP限制开关是关闭状态。
  - IP限制总开关打开，并且子开关打开时，对应端口类型的IP限制开关是打开状态。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|:---------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ADDRID   | IP地址索引   | 用于指定业务发放系统IP地址的IP地址索引（编号），本局内唯一。 取值范围：1～1024 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ADDRNAME | IP地址名称   | 用于指定业务发放系统IP地址的名称。用于描述IP地址，方便用户识别IP地址。导出设备档案需要使用此参数作为输入信息。 取值范围：长度不超过256的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| IPVER    | IP类型     | 用于表示IP地址类型。 取值范围：IPV4：当系统要求使用IPv4类型的IP地址时选择此选项。IPV6：当系统要求使用IPv6类型的IP地址时选择此选项。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| IPV4ADDR | IPV4地址   | 仅当本命令中的“IP类型”参数为“IPV4”时该参数有效，用于指定业务发放系统的IPV4地址信息。 取值范围：IPv4格式的地址。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| IPV6ADDR | IPV6地址   | 仅当本命令中的“IP类型”参数为“IPV6”时该参数有效，用于指定业务发放系统的IPV6地址信息。 取值范围：IPv6格式的地址。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| IPTYPE   | IP地址类型   | 用于指定业务发放系统的IP地址类型。 各参数选项的含义是： BOSS（BOSS）：表示此IP供营帐客户端使用，采用的是MML接口。SOAP（SOAP）：表示此IP供营帐客户端使用，采用的是SOAP接口。WEBLMT（WEBLMT）：表示此IP供PGW Web LMT客户端使用，采用的是HTTP/HTTPS接口。REST（REST）：表示此IP供营帐客户端使用，采用的是REST接口。HTTP（HTTP）：表示此IP供营帐客户端使用，采用的是HTTP接口。 默认值：无。                                                                                                                                                                                                                                                                                                                |
| IPV4MASK | IPV4地址掩码 | 仅当本命令中的“IP类型”参数选择为“IPV4”时该参数有效，用于指定本地IP地址的地址掩码，由运营商统一规划。 取值范围：255.0.0.0255.255.0.0255.255.255.0255.255.255.255 默认值：255.255.255.255  说明： 用户输入对应的“IPV4地址”时，可同时输入对应的“IPV4地址掩码”，比如“IP类型”为“IPV4”时，若输入的IP地址为10.19.42.145，则“IPV4地址”与“IPV4地址掩码”配置关系如下所述。 不输入地址掩码，则系统默认地址掩码为255.255.255.255，只有10.19.42.145可以接入PGW。地址掩码取为255.255.255.0，则10.19.42.0-10.19.42.255都可接入PGW。地址掩码取为255.255.0.0，则10.19.0.0-10.19.255.255都可接入PGW。地址掩码取为255.0.0.0，则10.0.0.0-10.255.255.255都可接入PGW。                                                                                            |
| IPV6MASK | IPV6地址掩码 | 仅当本命令中的“IP类型”参数选择为“IPV6”时该参数有效，用于指定本地IP地址的地址掩码，由运营商统一规划。 取值范围：1~128 默认值：128  说明： “IPV6地址掩码”输入为1~128的整型，主机侧会将其转化成对应的掩码。比如输入3，则会转化为111后接125个0；输入5，会转化为11111后接123个0；其余以此类推。用户输入对应的“IPV6地址”时，可同时输入对应的“IPV6地址掩码”，比如“IP类型”为“IPV6”时，若输入的IP地址为2001:0db8:0000:0000:0000:0000:0000:0000，则“IPV6地址”与“IPV6地址掩码”配置关系如下举例所述，其余以此类推。不输入地址掩码，则地址掩码默认为128，则只有这一个地址可以接入PGW。地址掩码取为64，则2001:0db8:0000:0000:0000:0000:0000:0000-2001:0db8:0000:0000:FFFF:FFFF:FFFF:FFFF都可接入PGW。地址掩码取为96，则2001:0db8:0000:0000:0000:0000:0000:0000-2001:0db8:0000:0000:0000:0000:FFFF:FFFF都可接入PGW。 |

## 使用实例

某局点需要对SOAP客户端进行IP限制，添加业务发放系统IP地址，“IP类型”为“IPV4”，“IPV4地址”为“192.168.31.43”，“IP地址索引”为“41”，“IP地址名称”为“SoapClient1”，“IP地址类型”为“SOAP（SOAP）”：

```
ADD PROVISIONIP: ADDRID=41, ADDRNAME="SoapClient1", IPVER=IPV4, IPV4ADDR="192.168.31.43", IPTYPE=SOAP;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。
