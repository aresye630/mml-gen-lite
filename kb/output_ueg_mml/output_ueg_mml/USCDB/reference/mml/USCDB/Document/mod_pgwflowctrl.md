# 修改PGW流控参数(MOD PGWFLOWCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

- 该命令属于高危命令，该操作将修改PGW流控参数，操作不当将导致无法起控或过早起控，并造成业务呼损。因此执行该命令前，需要与华为技术支持确认后才可以实施。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于修改PGW动态流控软参。

在不改变系统初始设置的情况下，PGW模块会根据所在虚拟机（裸机Pod）的CPU占用率、消息延迟时间和配置的流控软参值，自动开启流控和解除流控。

该命令的使用场景：用于异常场景下的调测，当出现系统不稳定，如频繁开启流控和解除流控，操作员可以使用本命令修改流控软参以使系统保持健康的运行状态，始终提供最大能力的消息响应服务。

## 注意事项

- 当PGW模块所在虚拟机（裸机Pod）的CPU占用率或消息延迟时间任一负荷超出预先设置的负荷过载阈值，PGW必须丢弃业务发放系统超载的请求消息以降低自身负荷保证模块正常运行，PGW模块产生ALM-14007 PGW流控启用告警。
- 起控后，将限制业务发放系统访问PGW请求消息的处理，造成业务呼损。如果需要知道哪些命令在PGW动态流控期间被丢弃，则可以将“操作日志保存丢弃命令开关”设置为“1”。
- 在缺省的情况下，系统预置了如下参数:

  ```
   系统配置参数  流控配置参数名称  流控开关类型  流控开关参数              CPU起控门限  CPU解控门限  PGW消息队列消息堆积时间起控门限(毫秒)  PGW消息队列消息堆积时间解控门限(毫秒)

   系统参数      流控参数          NOTIFY        OFF                       NULL         NULL         600                                    100                                  
   系统参数      流控参数          BOSS          MSGFC                     95           85           600                                    100
  ```
- 当PGW模块所在虚拟机（裸机Pod）的CPU占用率或消息延迟时间过高产生ALM-14007 PGW流控启用告警时，如果通过执行本命令将流控开关参数修改为关闭，PGW模块流控状态不会立刻解除，告警也不会立刻清除，需等待负荷都恢复正常状态。
- 该命令不允许进行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。

## 参数说明

| 参数标识          | 参数名称                  | 参数说明                                                                                                                                                                                 |
|:--------------|:----------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PGWSYSCP      | 系统配置参数                | 用于指定系统配置参数，目前此参数只有“SYSPARA(系统参数)”一个选项。 系统初始设置值：SYSPARA(系统参数)。                                                                                                                        |
| PGWFCCPN      | 流控配置参数名称              | 用于指定流控配置参数，目前此参数只有“FLOWCTRL(流控参数)”一个选项。 系统初始设置值：FLOWCTRL(流控参数)。                                                                                                                      |
| PGWFLWCTRTYPE | 流控开关类型                | 用于指定PGW流控功能的类型。 取值范围：BOSS(BOSS)：表示流控类型为BOSS。NOTIFY(NOTIFY)：表示流控类型为订阅通知，仅对数据层订阅通知生效。 默认值：BOSS(BOSS)。                                                                                  |
| PGWFLWCTRFLG  | 流控开关参数                | 用于指定PGW流控功能是否开启。 取值范围：BOSSOFF(OFF)：BOSSON(ON)MSGFC(MSGFC)NOTIFYOFF(OFF)NOTIFYON(ON) 当“流控开关类型”为“BOSS(BOSS)”时，系统初始设置值：MSGFC(MSGFC)；当“流控开关类型”为“NOTIFY(NOTIFY)”时，系统初始设置值：NOTIFYOFF(OFF)。 |
| PGWCPUFLWSTR  | CPU起控门限               | 仅当“流控开关参数”为“BOSSON(ON)”时该参数有效，用于指定当CPU的使用率大于或等于该值时开启流控。CPU起控门限的值必须比CPU解控门限的值至少大10。 取值范围：10～100 单位：％ 系统初始设置值：95                                                                       |
| PGWCPUFLWEND  | CPU解控门限               | 仅当“流控开关参数”为“BOSSON(ON)”时该参数有效，用于指定当CPU的使用率小于或等于该值时解除流控。CPU解控门限的值必须比CPU起控门限的值至少小10。 取值范围：0～90 单位：% 系统初始设置值：85                                                                         |
| PGWTSSTR      | PGW消息队列消息堆积时间起控门限(毫秒) | 仅当“流控开关参数”为“BOSSON(ON)”或“NOTIFYON(ON)”或“MSGFC(MSGFC)”时该参数有效，用于指定当消息在PGW消息队列堆积的时间大于或等于该值时开启流控。 取值范围：500～3000 单位：ms 系统初始设置值：600                                                        |
| PGWTSEND      | PGW消息队列消息堆积时间解控门限(毫秒) | 仅当“流控开关参数”为“BOSSON(ON)”或“NOTIFYON(ON)”或“MSGFC(MSGFC)”时该参数有效，用于指定当消息在PGW消息队列堆积的时间小于或等于该值时解除流控。 取值范围：1～1000 单位：ms 系统初始设置值：100                                                          |

## 使用实例

1.某局点由于BOSS类型的流控频繁起控，修改PGW流控软参阈值，“系统配置参数”为“SYSPARA(系统参数)”，“流控配置参数名称”为“FLOWCTRL(流控参数)”，“流控开关类型”为“BOSS(BOSS)”，“流控开关参数 ”为“BOSSON(ON)”，“CPU起控门限”为“95”，“CPU解控门限”为“85”，“PGW消息队列消息堆积时间起控门限”为“1000”，“PGW消息队列消息堆积时间解控门限”为“100”：

```
MOD PGWFLOWCTRL: PGWSYSCP=SYSPARA, PGWFCCPN=FLOWCTRL, PGWFLWCTRTYPE=BOSS, PGWFLWCTRFLG=BOSSON, PGWCPUFLWSTR=95, PGWCPUFLWEND=85, PGWTSSTR=1000, PGWTSEND=100;
```

2.某局点由于订阅通知类型的流控频繁起控，修改PGW流控软参阈值，“系统配置参数”为“SYSPARA(系统参数)”，“流控配置参数名称”为“FLOWCTRL(流控参数)”，“流控开关类型”为“NOTIFY(NOTIFY)”，“流控开关参数 ”为“NOTIFYON(ON)”，“PGW消息队列消息堆积时间起控门限”为“1000”，“PGW消息队列消息堆积时间解控门限”为“100”：

```
MOD PGWFLOWCTRL: PGWSYSCP=SYSPARA, PGWFCCPN=FLOWCTRL, PGWFLWCTRTYPE=NOTIFY, PGWFLWCTRFLG=NOTIFYON, PGWTSSTR=1000, PGWTSEND=100;
```

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。
