## 命令功能

**须知** 

回退事务需要大约10分钟完成，请务必在华为技术支持人员的指导下操作。

本命令用于回退当前事务。用户可以在提交事务之前执行本命令回退当前事务，事务回退后网元转入正常模式运行。

放弃本事务中所做的修改称为事务“回退”，普通用户可以使用本命令回退自己开始的事务，admin用户还可以使用**STP TRAN**命令回退任何事务。

本命令的使用场景为：事务模式下执行的配置命令不符合预期结果或者用户放弃事务模式下的配置更改时，使用本命令回退事务。

## 注意事项

- 事务回退后，系统将进入开始事务之前的正常模式。
- 事务回退命令会将在事务模式下所做的增加、删除、修改等操作全部取消。

## 参数说明

无。

## 使用实例

事务回退：

```
RBK TRAN:;
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，请联系华为技术支持处理。
