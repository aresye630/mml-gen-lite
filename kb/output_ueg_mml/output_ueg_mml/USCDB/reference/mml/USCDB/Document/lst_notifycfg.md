# 查询PGW订阅通知配置（LST NOTIFYCFG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询PGW订阅通知的订阅配置信息。

- 若需要查询全部PGW订阅通知的概要信息，请不要输入任何参数。
- 若需要查询某条PGW订阅通知的详细信息，请输入“订阅通知对端的ID”或其他参数或这些参数的组合。

  **说明** 

  当操作员通过**ADD NOTIFYCFG**命令添加服务端URL地址时，如果输入URL前携带空格时，通过该命令查询的URL地址信息也会携带空格。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称        | 参数说明                                                            |
|:---------|:------------|:----------------------------------------------------------------|
| FETYPE   | 订阅通知的FE类型   | 用于指示系统需要按照“订阅通知的FE类型”来查询PGW订阅通知的配置信息；若不输入，则表示所有“订阅通知的FE类型”。     |
| REMOTEID | 订阅通知对端的ID   | 用于指示系统需要按照“订阅通知对端的ID”来查询PGW订阅通知的配置信息，系统默认值为“1”。                 |
| FEID     | FE标识        | 用于指示系统需要按照“FE标识”来查询PGW订阅通知的配置信息；若不输入，则表示所有“FE标识”。               |
| PID      | Partition标识 | 用于指示系统需要按照“Partition标识”来查询PGW订阅通知的配置信息；若不输入，则表示所有“Partition标识”。 |
