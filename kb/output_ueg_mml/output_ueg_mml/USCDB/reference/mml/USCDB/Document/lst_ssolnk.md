# 查询SSO链路（LST SSOLNK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明
- 参考信息

## 命令功能

该命令用于查询SSO链路信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                            |
|:-------|:-------|:----------------------------------------------------------------|
| LNKID  | 链路ID   | 可选必选说明：可选参数 参数含义：用于指示系统按照链路ID来查询SSO链路信息。 取值范围：1。 默认值：无。 配置原则：无。 |

## 使用实例

查询SSO链路的配置，“链路ID”为“1”。

```
LST SSOLNK: LNKID=1;
```


## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，参数含义请参见**ADD SSOLNK**命令的参数说明。

## 参考信息

SSO（Single Sign-On）：单点登录，是目前比较流行的服务于企业业务整合的解决方案之一，SSO使得在多个应用系统中，用户只需要登录一次，就可以访问所有相互信任的应用系统。
