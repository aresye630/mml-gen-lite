# 设置分组开关（SET GROUPSWITCH）

## 命令功能

**须知** 

该命令属于高危命令，该操作涉及业务分组功能的控制，配置错误会导致FE访问BE业务失败。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置FE侧支持多应用共存的业务分组的开关状态。

## 注意事项

- 执行本命令打开分组开关前，请确认FE侧是否需要支持多应用共存。
- 执行本命令关闭分组开关前，请确认FE侧是否不需要支持多应用共存。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                               |
|:------------|:-------|:-------------------------------------------------------------------|
| GROUPNAME   | 分组名称   | FE侧支持多应用共存的分组名称。 取值范围：长度不超过128的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 |
| GROUPSWITCH | 开关     | FE侧支持多应用共存的业务分组开关，表示分组功能是否打开。 取值范围：CLOSE（开关关闭）OPEN（开关打开） 默认值：CLOSE |

## 使用实例

当FE侧需要支持多应用，通过设置分组开关打开分组功能，设置“分组名称”“GU-SUP-DNS”的开关为“OPEN”：

```
SET GROUPSWITCH: GROUPNAME="GU-SUP-DNS", GROUPSWITCH=OPEN;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                      | 原因分析                                                                                                                                                                     | 处理建议                                                                                                                                         |
|-------:|:---------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------|
| 302520 | 所输入的分组名称不存在。               | 输入参数“分组名称”在分组记录中不存在。                                                                                                                                                     | 先执行LST GROUPSWITCH命令查询业务分组信息，然后输入存在的分组名称执行SET GROUPSWITCH命令。                                                                                 |
| 302536 | 存在分组中的多种业务类型远端配置，需要先删除再关闭。 | RDSG配置中存在分组内业务类型不同但“远端Location标识”和“远端DSG模块号”都相同的记录。RIPADDR配置中存在分组内业务类型不同但“远端Location标识”、“远端DPU模块号/远端业务IP索引”及远端IP1/IP2都相同的记录。RLOCATION配置中存在分组内业务类型不同但“远端Location标识”相同的记录。 | 先执行LST RDSG、LST RIPADDR、LST RLOCATION命令查询是否存在分组内多种业务类型对应的重复记录，如果存在，执行RMV RDSG、RMV RIPADDR、RMV RLOCATION命令删除多余的远端配置，再执行SET GROUPSWITCH命令关闭分组。 |
