# 查询SSO元数据(LST SSOMETADATA)

- 注意事项

## 命令功能

该命令用于查询已加载的IDP端（即网管）元数据信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询SSO元数据。

```
LST SSOMETADATA:;
```

```
%%LST SSOMETADATA:;%%
RETCODE = 0  操作成功

操作结果如下
------------------------
元数据名称  =  idp_metadata.xml

(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息，参数含义请参见**LOD SSOMETADATA**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释     | 原因分析         | 处理建议                                           |
|------:|:----------|:-------------|:-----------------------------------------------|
|  2761 | 元数据文件不存在。 | 系统中不存在元数据文件。 | 元数据不存在，如有需要，请先执行LOD SSOMETADATA命令加载元数据后再执行该命令。 |

## 参考信息

- SSO（Single Sign-On）：单点登录，是目前比较流行的服务于企业业务整合的解决方案之一，SSO使得在多个应用系统中，用户只需要登录一次，就可以访问所有相互信任的应用系统。
- 基于SAML 2.0（Security Assertion Markup Language 2.0，安全断言标记语言）协议实现的SSO登录，由IDP和SP组成，以实现在不同的安全域之间交换认证和授权数据。
  - SP（Service Provider）：向用户提供正式商业服务的实体，通常需要认证一个用户的身份。
  - IDP（Identity Provider）：提供用户的身份鉴别，确保用户是其所声明的身份。

  PGW Web LMT实现SSO单点接入功能，是以PGW Web LMT作为SP端，网管作为IDP端。
