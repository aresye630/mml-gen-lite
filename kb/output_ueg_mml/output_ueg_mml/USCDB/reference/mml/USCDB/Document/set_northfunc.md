# 设置北向关联配置(SET NORTHFUNC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令属于高危命令，该操作设置网元在北向网管上的功能实体信息，配置错误将导致相关话统指标在网管上无法关联。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置北向功能实体信息。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                                |
|:------------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NORTHOBJECT | 北向功能实体对象 | 用于标识北向功能实体。 取值范围： HSS9860(HSS9860)GUHLR(GUHLR)SAEHSS(SAEHSS)IMSHSS(IMSHSS)UIM(UIM)SLF(SLF)ENS(ENS)DRA(DRA)UPCC(UPCC)NPHLR(NPHLR)NPMSC(NPMSC)UDM(UDM)UPCF(UPCF) 默认值：HSS9860(HSS9860) |

## 使用实例

设置北向功能实体信息，“NORTHOBJECT”为“HSS9860”:

```
SET NORTHFUNC: NORTHOBJECT=HSS9860-1&GUHLR-0&SAEHSS-0&IMSHSS-0&UIM-0&SLF-0&ENS-0&DRA-0&UPCC-0&NPHLR-0&NPMSC-0&UDM-0&UPCF-0;
```
