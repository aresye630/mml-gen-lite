# 添加ADD服务器配置(ADD ADDCONFIG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于添加ADD服务器的相关配置信息，关于ADD业务请参考自动设备检查配置管理的功能描述。

## 注意事项

一个局点只允许添加一个ADD服务器配置。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                           |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| IPVER    | IP类型   | 用于表示IP地址类型。 取值范围： IPV4：当系统要求使用IPv4类型的IP地址时选择此选项。IPV6：当系统要求使用IPv6类型的IP地址时选择此选项。 默认值：无。                                                          |
| IPV4ADDR | IPV4地址 | 仅当本命令中的“IP类型”参数选择为“IPV4”时该参数有效，用于指定ADD服务器的IPv4地址，需与对端ADD服务器配置保持一致并在此引用。 取值范围：IPv4格式的地址。 默认值：无。                                                 |
| IPV6ADDR | IPV6地址 | 仅当本命令中的“IP类型”参数选择为“IPV6”时该参数有效，用于指定ADD服务器的IPv6地址，需与对端ADD服务器配置保持一致并在此引用。 取值范围：IPv6格式的地址。 默认值：无。                                                 |
| PORT     | 端口     | 用于指定ADD服务器的端口，需与对端ADD服务器配置保持一致并在此引用。 取值范围：1～65535 默认值：无。                                                                                       |
| URL      | 网址     | 用于指定ADD服务器的网络地址，系统初始设置“网址”为“/ADDWeb/services/SetSubscriberDetails”。 取值范围：长度不超过255的字符串，且必须以“/”字符开头。 默认值：无。 配置原则：该参数不能配置绝对路径的URL，只能输入域名之后的URL片段。 |

## 使用实例

添加ADD服务器配置信息，ADD服务器“IP类型”为“IPV4”，“IPV4地址”为“10.85.165.185”，“端口”为“9080”，“网址”为“/servlet/MessageHandler”：

```
ADD ADDCONFIG: IPVER=IPV4, IPV4ADDR="10.85.165.185", PORT=9080, URL="/servlet/MessageHandler";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释           | 原因分析                 | 处理建议                                                                                                         |
|-------:|:----------------|:---------------------|:-------------------------------------------------------------------------------------------------------------|
| 275029 | 只能增加一条自动设备检测记录。 | 一个局点只允许添加一个ADD服务器配置。 | 执行LST ADDCONFIG命令查看已添加的ADD服务器配置是否满足需求。 如果满足，则无需处理。如果不满足，请执行RMV ADDCONFIG命令删除已添加的ADD服务器配置后，重新执行该命令添加所需的服务器配置。 |
| 275034 | ADD服务器网址格式不正确。  | “网址”的第一个字符必须是“/”。    | 输入长度不超过255的字符串且以“/”字符开头的“网址”后，重新执行该命令。                                                                       |
