# 设置关键资源告警配置（SET ESSRESALMCFG）

## 命令功能

该命令用于设置各类关键资源监控的告警上报阈值、告警恢复阈值以及是否开启监控功能。

该命令的使用场景：系统通过内部定时器，以5秒为周期定时检查各个关键资源的使用率，并判断是否要上报**ALM-12070 关键资源使用率过高**告警或**ALM-12071 关键资源不足**告警。

如果修改了告警上报阈值或恢复阈值，系统会在下一次检查时按照最新阈值重新判断是否上报或恢复**ALM-12070 关键资源使用率过高**告警或**ALM-12071 关键资源不足**告警。

## 注意事项

- 各级告警阈值与恢复阈值需满足如下限制：
  - “一级告警阈值”大于“一级告警恢复阈值”。
  - “一级告警恢复阈值”大于“二级告警阈值”。
  - “二级告警阈值”大于“二级告警恢复阈值”。
  - “一级告警阈值”和“溢出恢复阈值”对于百分比类型需要小于等于“100”。

- “二级告警阈值”、“二级告警恢复阈值”、“一级告警阈值”、“一级告警恢复阈值”、“溢出恢复阈值”、“状态”六个参数必须至少有一个不为空，否则将会上报错误码“至少修改一个参数值”。

## 使用实例

1. 设置“Cache消息队列”关键资源告警相关配置信息为：模块类型为“DRU(DRU)”，业务类型为“SUP-FE”，溢出恢复阈值为“85”，且监控该关键资源时，配置命令示例如下：

   ```
   SET ESSRESALMCFG: ESSRESID=CACHEMESSAGEQUEUE, MODULETYPE=DRU, SERVICETYPE="SUP-FE", OVERFLOWRCYTHD=85, ENABLESTATUS=ON;
   ```
2. 设置“异常路由快速校验队列”关键资源告警相关配置信息为：模块类型为“DRU(DRU)”，业务类型为“SUP-FE”，二级告警阈值为“85”，二级告警恢复阈值为“82”，一级告警阈值为“95”，一级告警恢复阈值为“92”且监控该关键资源时，配置命令示例如下：

   ```
   SET ESSRESALMCFG: ESSRESID=EXCEPROUTEFASTVERQUEUE, MODULETYPE=DRU, SERVICETYPE="SUP-FE", LEVEL2ALMTHD=85, LEVEL2ALMRCYTHD=82, LEVEL1ALMTHD=95, LEVEL1ALMRCYTHD=92, ENABLESTATUS=ON;
   ```
