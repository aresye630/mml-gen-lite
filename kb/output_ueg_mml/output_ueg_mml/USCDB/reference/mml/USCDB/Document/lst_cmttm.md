# 查询自动确认时间(LST CMTTM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于在数据库中查询配置回退的自动确认时间。

后台系统提供的自动确认机制（系统缺省的自动确认时间为24小时，操作员可以通过**MOD CMTTM**命令进行修改），指的是数据表在“试运行模式”下超时设定的自动确认时间，系统将自动确认数据表的修改，数据表进入“常规运行状态”。通过该命令可查询设定的配置回退自动确认时间。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询自动确认时间：

`LST CMTTM:;`

```
%%LST CMTTM:;%%
RETCODE = 0  操作成功

自动确认时间
------------
确认时间(小时)  =  24
(结果个数 = 1)

---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。输出结果说明如表1所示。

命令执行异常，请联系华为技术支持处理。

| 输出项名称    | 输出项解释                              |
|:---------|:-----------------------------------|
| 确认时间（小时） | 用于表示在“试运行模式”下超时设定的自动确认时间，其单位为“小时”。 |
