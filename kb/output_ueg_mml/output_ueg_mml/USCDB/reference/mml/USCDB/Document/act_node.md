# 激活节点(ACT NODE)

## 命令功能

该命令用于激活处于去激活状态的节点。该命令一般与**DEA NODE**命令配合使用。

命令主要运用于升级场景：在升级过程中，为减少呼损，系统会先去激活待升级节点，升级完成后，系统会将自动调用该命令重新激活该节点。以上过程为系统自动调用命令，无需手动执行。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                                     |
|:-------|:----------|:-----------------------------------------------------------------------------------------|
| CID    | Cluster标识 | 用于定义待激活节点所属Cluster的Cluster标识。 此参数在同一USCDB下唯一。是通过ADD CLUSTER命令定义后在此引用。 取值范围：1～4096 默认值：无。 |
| NID    | 节点标识      | 用于定义待激活节点所属Cluster的节点标识。 此参数在同一USCDB下唯一。是通过ADD NODE命令定义后在此引用。 取值范围：1～32768 默认值：无。        |

## 使用实例

激活一个节点，该节点所属Cluster的Cluster标识为12，节点标识为1。

```
ACT NODE: CID=12, NID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                           | 原因分析                   | 处理建议                                                    |
|-------:|:--------------------------------|:-----------------------|:--------------------------------------------------------|
| 260104 | 该cluster不存在。                    | 输入的“Cluster标识”在系统中未配置。 | 通过LST CLUSTER命令查询已配置的“Cluster标识”并输入正确的参数，然后重新执行本命令。     |
| 260113 | 参数NID指定的节点在参数CID指定的cluster中不存在。 | 输入的“节点标识”在cluster中未配置。 | 通过LST NODE命令查询已配置的“节点标识”和“Cluster标识”并输入正确的参数，然后重新执行本命令。 |
| 260115 | 参数NID指定的节点不存在。                  | 输入的“节点标识”在系统中未配置。      | 通过LST NODE命令查询已配置的“节点标识”并输入正确的参数，然后重新执行本命令。             |
