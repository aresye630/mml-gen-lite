# 查看PHYDB状态（DSP PHYDB）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询物理数据库的运行状态。

## 注意事项

无。

## 参数说明

无。

## 使用实例

某局点需要查询物理数据库当前的运行状态：

```
DSP PHYDB:;
```

返回结果如下：

```
%%DSP PHYDB:;%% 
RETCODE = 0  操作成功  
操作结果如下
------------------------  
数据库类型     资源状态         Pod名称           
ClickHouse     Idle(Running)    usdid3bservice5-0  
ClickHouse     Idle(Running)    usdid3aservice5-0 
(结果个数 = 2)  
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1的输出结果解释。

| 输出项名称   | 输出结果解释                                                                                                                                                                                                                                                                                                                              |
|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 数据库类型   | 用于返回系统当前使用的物理数据库类型： Clickhouse：表示系统当前使用的物理数据库类型是Clickhouse。                                                                                                                                                                                                                                                                         |
| 资源状态    | 用于返回数据库当前的运行任务和运行状态： 运行任务： Idle：物理库无业务STR INSTENV：物理库建表BKP DB：物理库备份UPG DB：物理库升级RST DB：物理库恢复RBK DB：物理库回退 运行状态： Running：数据库运行Pending：数据库停止Abnormal：物理库异常Backing up：物理库备份Restoring：物理库恢复Fast recovering：物理库单边恢复Upgrading：物理库升级Rolling back：物理库回退Changing password：物理库密码修改Installing DB：物理库建库Installing table：物理库建表Initializing：物理库初始状态 |
| Pod名称   | 用于返回当前物理库所在的POD名称。                                                                                                                                                                                                                                                                                                                  |
