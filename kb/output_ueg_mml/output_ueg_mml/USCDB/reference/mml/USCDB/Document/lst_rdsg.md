# 查询远端DSG(LST RDSG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令为用于查询远端DSG模块配置信息。

- 若需要查询全部的远端DSG概要信息，请不要输入任何参数。
- 若需要查询某条远端DSG详细信息，请输入“远端Location标识”或者其他参数或者这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称         | 参数说明                                                          |
|:---------|:-------------|:--------------------------------------------------------------|
| RLOCID   | 远端Location标识 | 用于指示系统需要按照远端Location的标识来查询远端DSG配置信息；若不输入，则表示所有的远端Location的标识。 |
| RDSGMID  | 远端DSG模块号     | 用于指示系统需要按照远端DSG模块号来查询远端DSG配置信息；若不输入，则表示所有的远端DSG模块号。           |
| RDSGST   | 远端DSG业务类型    | 用于指示系统需要按照远端DSG的业务类型来查询远端DSG配置信息；若不输入，则表示所有的远端DSG的业务类型。       |
| RDSGTYPE | 远端DSG类型      | 用于指示系统需要按照远端DSG的类型来查询远端DSG配置信息；若不输入，则表示所有的远端DSG类型。            |

## 使用实例

查询所有远端DSG。

```
LST RDSG:;
```

```
%%LST RDSG:;%%
RETCODE = 0  操作成功

操作结果如下
------------
远端Location标识  =  100
   远端DSG模块号  =  123
 远端DSG业务类型  =  SUP-FE
     远端DSG类型  =  DSG
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD RDSG**命令的参数说明。
