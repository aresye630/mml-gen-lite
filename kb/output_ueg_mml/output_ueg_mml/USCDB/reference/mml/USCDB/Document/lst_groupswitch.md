# 查询分组开关（LST GROUPSWITCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明
- 参考信息

## 命令功能

该命令用于查询FE侧支持多应用共存的业务分组控制信息。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                     |
|:----------|:-------|:-----------------------------------------|
| GROUPNAME | 分组名称   | FE侧支持多应用共存的分组名称。若不输入，则表示查询所有分组的业务分组控制信息。 |

## 使用实例

1.查询所有分组的开关状态信息。

```
LST GROUPSWITCH:;
```

```
%%LST GROUPSWITCH:;%%
RETCODE = 0  操作成功

操作结果如下
------------
 分组ID  分组名称    开关  

 33      GU-SUP-DNS  关闭  
 109     MVAS        关闭  
(结果个数 = 2)

---    END
```

2.查询分组名称为“GU-SUP-DNS”的开关状态信息。

```
LST GROUPSWITCH: GROUPNAME="GU-SUP-DNS";
```

```
%%LST GROUPSWITCH: GROUPNAME="GU-SUP-DNS";%%
RETCODE = 0  操作成功

操作结果如下
------------
  分组ID  =  33
分组名称  =  GU-SUP-DNS
    开关  =  关闭
(结果个数 = 1)

---    END
```

## 输出结果说明

| 参数名称   | 描述                    |
|:-------|:----------------------|
| 分组ID   | FE侧支持多应用共存的分组名称对应的ID。 |
| 分组名称   | FE侧支持多应用共存的分组名称。      |
| 开关     | FE侧支持多应用共存的分组开关。      |
