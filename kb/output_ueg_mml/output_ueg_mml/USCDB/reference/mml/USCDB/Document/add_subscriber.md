# 增加订阅者(ADD SUBSCRIBER)

- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

用于增加订阅者信息。

该命令的参数索引关系如图1所示。

**图1** 命令参数的索引关系图

## 注意事项

- 如果参数“超时时间”不为默认值，建议设置为大于25的值。
- 密码长期使用会增加被盗窃和破解的风险，而且使用的时间越长，被盗窃和破解的风险越高。定期修改密码可以有效防范这种情况的发生，因此强烈建议您定期修改密码。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                                                                     |
|:------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBERID     | 订阅者ID  | 可选必选说明：必选参数 参数含义：用于标识一个订阅者，不能重复。 取值范围：1～255。 默认值：无。 配置原则：无。                                                                                                                                                                                                              |
| SUBERNAME   | 订阅者名称  | 可选必选说明：可选参数 参数含义：用于标识订阅者名称。 取值范围：长度不超过32的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                             |
| INFTYPE     | 接口类型   | 可选必选说明：必选参数 参数含义：用于标识订阅通知的接口类型。 取值范围： HTTP(Http)：采用HTTP接口通知变更消息。TCP(Tcp)：采用TCP接口通知变更消息。SOAP(Soap)：采用SOAP接口通知变更消息。MCI(MCI)：采用MCI接口通知变更消息。 默认值：无。 配置原则：无。                                                                                                                  |
| LKSID       | 链路集ID  | 可选必选说明：必选参数 参数含义：用于标识链路集ID。链路集必须存在，可以根据接口类型的不同使用LST TCPLNK、LST HTTPLNK、LST SOAPLNK或者LST MCILNK命令查询得到已经添加的链路集ID。 取值范围：1～50。 默认值：无。 配置原则：无。                                                                                                                                |
| RESENDTIMES | 重发次数   | 可选必选说明：可选参数 参数含义：用于标识向对端发送通知，响应超时后，重发的次数。 取值范围：0～10。 默认值：0。 配置原则：无。                                                                                                                                                                                                      |
| WAITTIMEOUT | 超时时间   | 可选必选说明：可选参数 参数含义：用于标识向对端发送通知后，等待响应的超时时长。该参数的单位为秒。 取值范围：1～250。 默认值：25。 配置原则：无。                                                                                                                                                                                            |
| USERNAME    | 用户名    | 可选必选说明：条件可选参数 参数含义：该参数取值为对端鉴权用户的用户名。用于标识当需要对用户进行登录鉴权，鉴权用户名。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：仅当本命令的参数“接口类型”取值为“HTTP(Http)”或“SOAP(Soap)”时，该参数有效。                                                                                                                            |
| PWD         | 密码     | 可选必选说明：条件可选参数 参数含义：用于标识鉴权用户的密码。 取值范围：长度不超过63的字符串。 默认值：无。 配置原则：仅当本命令的参数“接口类型”取值为“HTTP(Http)”或“SOAP(Soap)”时，该参数有效。  说明： 该参数取值为对端鉴权用户的密码，其密码复杂度由对端产品进行约束。                                                                                                                   |
| CFM         | 确认密码   | 可选必选说明：条件可选参数 参数含义：用于标识再次确认输入的密码，两次输入的密码必须一致。 取值范围：长度不超过63的字符串。 默认值：无。 配置原则：仅当本命令的参数“接口类型”取值为“HTTP(Http)”或“SOAP(Soap)”时，该参数有效。  说明： 该参数取值为对端鉴权用户的密码，其密码复杂度由对端产品进行约束。                                                                                                     |
| CUSTOM      | 场景     | 可选必选说明：条件可选参数 参数含义：当对接局点使用的消息格式不是标准协议里规定的消息格式时，使用此参数，表示需要对消息进行定制化的解析。此参数是定制化场景参数，共定义100个场景，每个场景对应一个对接局点的消息解析格式。FE需要使用此参数时需要到BE申请场景参数，防止冲突。 取值范围： NULL(NULL)SCENE1(场景1)～SCENE100(场景100) 默认值：NULL(NULL) 配置原则：仅当本命令的参数“接口类型”取值为“HTTP(Http)”、“TCP(Tcp)”或“SOAP(Soap)”时，该参数有效。 |
| CACHENUM    | 缓存通知数  | 可选必选说明：条件可选参数 参数含义：用于标识缓存HTTP订阅通知的条数。 取值范围：1～20。 默认值：无。 配置原则：仅当本命令的参数“接口类型”取值为“HTTP(Http)”时，该参数有效。                                                                                                                                                                       |

## 使用实例

1.增加订阅者，“订阅者ID”为“1”，“订阅者名称”为“huawei”，“接口类型”为“HTTP”，“链路集ID”为“1”，“重发次数”为“0”，“超时时间”为“25”，“用户名”为“huawei”，“密码”为“\*\*\*\*\*”，“密码确认”为“\*\*\*\*\*”，“场景”为“NULL”。

```
ADD SUBSCRIBER: SUBERID=1, SUBERNAME="huawei", INFTYPE=HTTP, LKSID=1, RESENDTIMES=0, WAITTIMEOUT=25, USERNAME="huawei", PWD="*****", CFM="*****", CUSTOM=NULL;
```

2.增加订阅者，“订阅者ID”为“2”，“订阅者名称”为“huawei”，“接口类型”为“TCP”，“链路集ID”为“1”，“重发次数”为“0”，“超时时间”为“25”，“场景”为“NULL”。

```
ADD SUBSCRIBER: SUBERID=2, SUBERNAME="huawei", INFTYPE=TCP, LKSID=1, RESENDTIMES=0, WAITTIMEOUT=25, CUSTOM=NULL;
```

3.增加订阅者，“订阅者ID”为“3”，“订阅者名称”为“huawei”，“接口类型”为“SOAP”，“链路集ID”为“1”，“重发次数”为“0”，“超时时间”为“25”，“用户名”为“huawei123”，“密码”为“\*\*\*\*\*”，“密码确认”为“\*\*\*\*\*”，“场景”为“NULL”。

```
ADD SUBSCRIBER: SUBERID=3, SUBERNAME="huawei", INFTYPE=SOAP, LKSID=1, RESENDTIMES=0, WAITTIMEOUT=25, USERNAME="huawei123", PWD="*****", CFM="*****", CUSTOM=NULL;
```

**说明** 

密码在命令行输入区域显示为\*\*\*。

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 274634 | 订阅者ID已经存在。              | “订阅者ID”在系统中已添加。            | 先执行LST SUBSCRIBER命令查询已添加的“订阅者ID”，重新执行本命令，确保新添加的“订阅者ID”与查询结果中的不相同。        |
| 274633 | 链路集不存在。                 | 未添加“链路集ID”。                | 先执行ADD TCPLNK、ADD HTTPLNK、ADD SOAPLNK或者LST MCILNK命令成功添加“链路集ID”后，重新执行本命令。 |
| 274659 | 参数取值无效：参数CFM与参数PWD必须一致。 | “确认密码”与“密码”不一致。            | 请输入和“密码”一致的“确认密码”。                                                       |
| 274706 | 参数用户名，密码和确认密码必须同时输入。    | 参数“用户名”、“密码”和“确认密码”必须同时输入。 | 请同时输入参数“用户名”、“密码”和“确认密码”。                                                |
