# 删除FTP服务器(RMV FTPSERVER)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，该操作将删除FTP连接配置，操作不当将造成FTP客户端无法连接、批操作无法执行等严重后果。因此执行该命令前，需要与华为技术支持确认后才可以实施。

当没有用户需要通过FTP与PGW和DMA交互时，使用该命令删除本端FTP服务器。

该命令的使用场景：

- 开局场景：开局根据网设规划配置FTP对接信息，用于修改错误配置。
- 网络改造场景：根据客户组网规划，需要调整FTP对接信息。

## 注意事项

- 删除本端FTP服务器前请确保没有用户需要FTP与PGW和DMA交互，否则不允许删除。
- 该命令不允许进行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。

## 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                                                                                      |
|:-----------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVERTYPE | 服务类型      | 用于指定待删除的本端FTP服务器服务类型。 取值范围： PROV(业务)：表示该FTP为营帐相关功能提供服务，且本端FTP服务由网关类型为PGW的DPU提供。DATAMTN(维护)：表示该FTP为数据维护（数据导出、数据备份）相关功能提供服务，且本端FTP服务由网关类型为DMA的DPU提供。 默认值：无。 |
| IPVER      | IP类型      | 用于指定IP地址类型。 取值范围：IPV4：当系统要求使用IPv4类型的IP地址时选择此选项。IPV6：当系统要求使用IPv6类型的IP地址时选择此选项。 默认值：无。                                                                      |
| SERVERIPV4 | 服务器IPV4地址 | 仅当本命令中的“IP类型”参数选择为“IPV4”时该参数有效，用于指定本端FTP服务器提供服务的IPv4地址。 取值范围：符合IPv4格式要求。 默认值：无。                                                                           |
| SERVERIPV6 | 服务器IPV6地址 | 仅当本命令中的“IP类型”参数选择为“IPV6”时该参数有效，用于指定本端FTP服务器提供服务的IPv6地址。 取值范围：符合IPv6格式要求。 默认值：无。                                                                           |
| SERVERPORT | 服务器端口     | 用于指定待删除的本端FTP服务器提供服务的端口号。 取值范围：1～65535 默认值：无。                                                                                                             |

## 使用实例

当某局点不再存在用户需要PGW本端FTP服务器提供服务时，需要删除PGW本端FTP服务器配置信息，“IP类型”为“IPV4”，“服务器IPV4地址”为“10.94.1.131”，“服务器端口”为“5555”:

```
RMV FTPSERVER: SERVERTYPE=PROV, IPVER=IPV4, SERVERIPV4="10.94.1.131", SERVERPORT=5555;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                | 原因分析                                      | 处理建议                                                              |
|-------:|:-------------------------------------|:------------------------------------------|:------------------------------------------------------------------|
| 260282 | 该FTP下有用户存在，不允许删除，请使用RMV FTPUSER删除用户。 | 当“服务类型”选择“PROV(业务)”时，该本端FTP服务器下还有FTP用户存在。 | 请先执行RMV FTPUSER命令删除FTP用户信息，再删除本端FTP服务器配置。                         |
| 275046 | 指定的记录不存在。                            | 执行该命令删除的本端FTP服务器在系统中不存在。                  | 请输入已存在的本端FTP服务器配置记录，可执行LST FTPSERVER命令查询已添加的本端FTP服务器配置，然后执行本命令删除。 |
| 332601 | 该IP地址无效。                             | 输入的IP地址不符合IP地址的格式要求。                      | 请重新输入，确保输入的IP地址符合IP地址的格式要求。                                       |
| 260069 | IP地址的类型不匹配。                          | 输入的IP地址类型和“IP类型”参数设置的IP类型不一致。             | 请重新输入，确保输入的IP地址类型和“IP类型”参数设置的IP类型一致。                              |
