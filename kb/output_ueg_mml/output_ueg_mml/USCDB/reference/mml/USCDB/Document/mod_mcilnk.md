# 修改MCI链路（MOD MCILNK）

## 命令功能

**须知** 

该命令属于高危命令，如果MCI链路参数配置不合理，将导致对端设备接收不到订阅通知。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改MCI链路配置。

## 注意事项

- 该命令不允许进行批操作。
- 在配置MCI链路时，对于MCI消息通知按照如下原则处理：
  - 如果未配置“Location标识”参数，则自动选择该“FE类型”的一个优先级别高的FE对端发送。优先级别可以通过**LST RLOCATION**查询。
  - 如果配置了“Location标识”参数，则此条MCI消息通知将只会发送给该指定“Location标识”的FE对端。

## 参数说明

| 参数标识        | 参数名称        | 参数说明                                                                                                                  |
|:------------|:------------|:----------------------------------------------------------------------------------------------------------------------|
| LNKID       | 链路ID        | 可选必选说明：必选参数 参数含义：标识一条MCI链路数据记录的关键字段之一，用于指定需要修改的哪一条MCI链路数据记录，操作员可以使用LST MCILNK命令查询获得。                                  |
| FETYPE      | FE类型        | 可选必选说明：可选参数 参数含义：标识一条MCI链路数据记录的关键字段之一，用于指定需要修改的哪一个MCI链路数据记录，操作员可以使用LST MCILNK命令查询获得。                                  |
| RLOCID      | Location标识  | 可选必选说明：可选参数 参数含义：该Location标识用于定义一个接收MCI订阅通知消息的网元标识。当配置该参数为非0值时，需保证该值为真实存在的远端“Location标识”。 取值范围： 0～512。 默认值：无。 配置原则：无。 |
| SERVICENAME | 服务名称        | 可选必选说明：可选参数 参数含义：本参数用于指定远端用于接收订阅通知服务的服务名称（可通过LST NTFSRVNAME命令查询）。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                   |
| PID         | Partition标识 | 可选必选说明：可选参数 参数含义：本参数用于指定一个接收MCI订阅通知消息接收端的Partition标识。 取值范围：0～255。 默认值：无。 配置原则：当配置该参数为非0值时，需保证该值为真实存在的远端“Partition标识”。 |
| LNKDESC     | 链路描述        | 可选必选说明：可选参数 参数含义：本参数用于标识MCI链路的描述信息。 取值范围：长度不超过32的字符串。 默认值：无。 配置原则：无。                                                  |

## 使用实例

修改一条MCI链路的“Location标识”，指定“链路ID”为“1”，修改“Location标识”为“2”。

```
MOD MCILNK: LNKID=1, RLOCID=2;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 消息解释             | 原因分析                 | 处理建议                                                                                  |
|-------:|:-----------------|:---------------------|:--------------------------------------------------------------------------------------|
| 274632 | 链路不存在。           | 只能修改已经存在的链路。         | 先执行LST MCILNK命令查询已经添加的“链路ID”，再重新执行本命令，确保要修改的“链路ID”在查询结果中。                             |
| 275434 | 指定的FE类型不存在该服务名称。 | 指定的“FE类型”不存在该“服务名称”。 | 先执行LST NTFSRVNAME命令查询指定“FE类型”已经存在的“服务名称”，然后重新执行本命令，确保要添加的“服务名称”在查询的结果中存在，并且与“FE类型”对应。 |
