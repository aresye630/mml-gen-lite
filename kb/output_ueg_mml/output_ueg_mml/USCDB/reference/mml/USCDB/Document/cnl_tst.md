## 命令功能

**须知** 

取消试运行需要大约10分钟完成，请务必在华为技术支持人员的指导下操作。

本命令用于撤销试运行状态。

本命令的使用场景为：试运行状态下配置数据的执行结果与期望的结果不相符时，用户可以使本命令撤销试运行，本命令将回退先前通过事务模式执行的配置命令，放弃本次事务执行的所有修改，主机使用执行本事务之前的配置数据转入正常模式运行。admin用户还可以用**STP TST**命令强行停止试运行，这条命令也同样会造成事务回退。

## 注意事项

- 取消试运行后，将在事务模式下做的所有操作进行回退，回退后主机侧的数据也将恢复到事务模式之前的状态。
- 取消试运行状态后，将恢复到正常的模式下。

## 参数说明

无。

## 使用实例

取消试运行：

```
CNL TST:;
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，请联系华为技术支持处理。
