## 命令功能

**须知** 

该命令属于高危命令，清除元数据会导致SSO功能不可用。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于清除IDP端（即网管）的SSO元数据。

本命令的使用场景如下：

- 当不需要使用IDP端的元数据时，此时可执行本命令进行清除。
- 当IDP端的元数据需要被替换更新时，需要使用本命令清除元数据，然后再执行**LOD SSOMETADATA**命令重新加载。

## 注意事项

无。

## 参数说明

无。

## 使用实例

清除IDP端（即网管）的SSO元数据。

```
CLR SSOMETADATA:;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释   | 原因分析                    | 处理建议   |
|-------:|:--------|:------------------------|:-------|
| 275461 | 元数据不存在。 | 系统中不存在IDP端（即网管）的SSO元数据。 | 无需处理。  |

## 参考信息

- SSO（Single Sign-On）：单点登录，是目前比较流行的服务于企业业务整合的解决方案之一，SSO使得在多个应用系统中，用户只需要登录一次，就可以访问所有相互信任的应用系统。
- 基于SAML 2.0（Security Assertion Markup Language 2.0，安全断言标记语言）协议实现的SSO登录，由IDP和SP组成，以实现在不同的安全域之间交换认证和授权数据。
  - SP（Service Provider）：向用户提供正式商业服务的实体，通常需要认证一个用户的身份。
  - IDP（Identity Provider）：提供用户的身份鉴别，确保用户是其所声明的身份。

  PGW Web LMT实现SSO单点接入功能，是以PGW Web LMT作为SP端，网管作为IDP端。
