# 设置IP限制开关(SET GRANTIPSWITCH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令属于高危命令，打开此开关会造成未授权的客户端无法连接。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置各类端口的IP限制子开关信息，为确保安全功能，在需要对登录PGW客户端的IP进行权限控制时，可通过本命令进行设置。

## 注意事项

- 软参“GRANTIPSWITCH（IP限制开关）”是通用（对所有端口类型）的IP限制总开关，可通过**LST INSP**命令进行查询，软参值为“1”表示打开，软参值为“0”表示关闭。
- 本命令是针对不同端口类型的IP限制子开关进行设置的，当“开关”为“OFF”时表示IP限制子开关关闭，当“开关”为“ON”时表示IP限制子开关打开。
  - 只有“GRANTIPSWITCH”值为“1”时，执行本命令配置的针对各类端口类型的IP限制子开关才生效，否则不生效。

    - IP限制总开关打开，而子开关关闭时，对应端口类型的IP限制开关是关闭的。
    - IP限制总开关打开，并且子开关打开时，对应端口类型的IP限制开关是打开的。
    - IP限制总开关关闭时，子开关不生效，所有端口类型的IP限制开关是关闭的。
  - 如果某类端口类型未设置IP限制子开关信息，则该类端口类型的IP限制状态和软参“GRANTIPSWITCH”对应的限制状态相同。

    - 某类端口类型未设置IP限制子开关信息，IP限制总开关打开，这类端口类型的IP限制开关是打开的。
    - 某类端口类型未设置IP限制子开关信息，IP限制总开关关闭，这类端口类型的IP限制开关是关闭的。
- 当未执行该命令时，此时如果软参“GRANTIPSWITCH（IP限制开关）”取值为“1”，则默认限制访问全部端口类型的PGW客户端IP地址。
- 该命令不允许进行批操作。
- 使用**SET GRANTIPSWITCH**命令设置IP限制开关时，联机设定会重启SSH服务，系统可能上报“ALM-14023 SSH服务故障”告警。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                          |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PORTTYPE | 端口类型   | 用于表示IP限制开关的端口类型。 各参数选项的含义是： SOAP（SOAP）：SOAP（Simple Object Access Protocol）端口类型BOSS（BOSS）：BOSS（Business And Operation Support System）端口类型WEBLMT（WEBLMT）：Web LMT（Web Local Maintenance Terminal）端口类型REST（REST）：REST（Representational State Transfer）端口类型HTTP（HTTP）：HTTP（Hypertext Transfer Protocol）端口类型 默认值：无。 |
| SWITCH   | 开关     | 用于表示IP限制开关的状态。 取值范围： OFF（关闭）：关闭ON（打开）：打开 默认值：无。                                                                                                                                                                                                                                                               |

## 使用实例

某局点需要对SOAP的端口类型IP进行权限控制，“GRANTIPSWITCH”为“1”时，执行命令如下：“端口类型”为“SOAP（SOAP）”，“开关”为“ON（打开）”：

```
SET GRANTIPSWITCH: PORTTYPE=SOAP, SWITCH=ON;
```
