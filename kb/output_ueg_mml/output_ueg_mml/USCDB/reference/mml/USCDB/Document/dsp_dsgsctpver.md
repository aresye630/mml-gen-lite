# 查看DSG模块SCTP组件版本(DSP DSGSCTPVER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在数据库中查询一个DSG模块所用SCTP组件的版本，在维护时用于故障定位。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                           |
|:-------|:-------|:-----------------------------------------------|
| MID    | DSG模块号 | 用于请求系统显示哪个DSG模块内的SCTP组件协议版本；若不输入，则表示所有的DSG模块号。 |

## 使用实例

查看DSG模块SCTP组件版本，“DSG模块号”为“102”。

```
DSP DSGSCTPVER: MID=102;
```

```
%%DSP DSGSCTPVER: MID=102;%%
RETCODE = 0  操作成功

操作结果如下
------------
SCTP版本号  =  VPP V300R021C00SPC111 (SCTP)
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称   | 输出项解释                                   |
|:--------|:----------------------------------------|
| SCTP版本号 | 用于返回指定模块的SCTP协议版本号。 如需定位SCTP问题，需提供该版本号。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释     | 原因分析                | 处理建议                                       |
|-------:|:----------|:--------------------|:-------------------------------------------|
| 302019 | DSG模块不存在。 | 输入的“DSG模块号”在系统中不存在。 | 通过LST MODULE命令查询已加载的DSG模块号并正确设置，然后重新执行本命令。 |
