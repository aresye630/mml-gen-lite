# 增加触发器(ADD TRIGGER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

当配置数据层订阅通知的输出内容时，使用该命令添加一条触发器记录。

## 注意事项

最多可以配置1024条触发器记录。

## 参数说明

| 参数标识          | 参数名称     | 参数说明                                                                          |
|:--------------|:---------|:------------------------------------------------------------------------------|
| SUBID         | 订阅ID     | 用于标识一条数据订阅配置记录。此参数在USCDB网元下唯一，由ADD SUBSCRIPTION命令添加而来。 取值范围：1～1024 默认值：无。     |
| TRIGGERTPLID  | 触发器模板ID  | 用于标识一条触发器模板记录。此参数在USCDB网元下唯一，由ADD TRIGGERTPL命令添加而来。 取值范围：1～100 默认值：无。         |
| OUTPUT        | 输出内容     | 用于标识一条触发器的输出内容，内容来源于FE插件包所配置的发布数据，多个属性使用“&”分割。 取值范围：长度不超过1023的字符串。 默认值：无。     |
| TRIGGERSTATUS | 触发器状态    | 用于标识一条触发器的状态。 取值范围：Active(激活)：表示触发器可用。Inactive(未激活)：表示触发器不可用。 默认值：Active(激活)。 |
| SAVNOTIFYLOG  | 记录订阅通知日志 | 用于标识记录订阅通知日志。 取值范围：YES(是)NO(否) 默认值：NO(否)                                      |

## 使用实例

添加一条触发器记录，设置“订阅ID”为“1”“触发器模板ID”为“1”，“输出内容”为“IMSI”，“触发器状态”为“Active”，“记录订阅通知日志”为“YES”。

```
ADD TRIGGER: SUBID=1, TRIGGERTPLID=1, OUTPUT="IMSI", TRIGGERSTATUS=Active, SAVNOTIFYLOG=YES;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释         | 原因分析                                | 处理建议                                                                                 |
|-------:|:--------------|:------------------------------------|:-------------------------------------------------------------------------------------|
| 259211 | 触发器模板ID不存在。   | 触发器模板记录中不存在指定“触发器模板ID”的触发器模板。       | 执行LST TRIGGERTPL命令查询触发器模板记录，再重新输入“触发器模板ID”，确保“触发器模板ID”存在于查询记录中。                      |
| 259213 | 参数OUTPUT格式不对。 | “输出内容”格式输入不对。                       | “输出内容”支持的配置的格式为：[ATTR]&[ATTR]。重新输入“输出内容”，确保其格式正确。                                    |
| 275321 | 该订阅ID不存在。     | 订阅记录中不存在指定“订阅ID”的记录。                | 先执行LST SUBSCRIPTION命令查询订阅记录，再重新输入“订阅ID”，确保其存在于查询记录中。                                 |
| 301252 | 记录数已经达到最大元组数。 | 触发器记录已经超过1024条。                     | 达到最大元组数限制后，不允许再添加，可以先执行LST TRIGGER命令查询已经存在的触发器记录。如果要添加，请执行RMV TRIGGER命令删除无效的触发器后再添加。 |
| 301265 | 表中记录已经存在。     | 触发器记录中已经存在与指定“订阅ID”和“触发器模板ID”相同的记录。 | 执行LST TRIGGER命令查询触发器记录，重新输入“订阅ID”、“触发器模板ID”，确保取值与查询结果中不重复。                           |
