# 查询DH配置(LST DHCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询DH域参数的长度配置信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询当前“素数bit数”的配置信息。

```
LST DHCFG:;
```

```
%%LST DHCFG:;%%
RETCODE = 0  操作成功

操作结果如下
------------------------
素数bit数  =  3072
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET DHCFG**命令的参数说明。
