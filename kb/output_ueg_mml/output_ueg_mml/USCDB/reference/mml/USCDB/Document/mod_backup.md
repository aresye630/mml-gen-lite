## 命令功能

**须知** 

该命令属于高危命令，该操作将修改物理库备份配置，操作不当将造成备份失败，影响数据的安全性。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改USCDB物理数据库自动备份的配置信息。为了物理数据库中数据的安全性，系统提供了物理数据库备份功能。通过自动备份功能将数据在特定时间备份到虚拟机硬盘（裸机硬盘）或指定的第三方存储介质，以保证在内存数据库或物理数据库中数据异常时使用预先备份的数据进行恢复，保证系统的可靠性。

## 注意事项

- 物理数据库备份文件包含用户的个人数据，如：IMSI、MSISDN等，需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护，例如：
  1. 采用安全的文件传输协议（如SFTP）传输导出文件。
  2. 并严格控制备份文件的访问权限。
  3. 及时清理备份文件。

  在从运营商网络获取数据前，必须要获得运营商的授权。

  若需从运营商网络中获取必要的数据，需要运营商维护人员对其中的个人数据进行匿名化处理，匿名化后的数据由运营商维护人员审核后提供，以防止个人数据泄露。匿名化处理工具可以在https://support.huawei.com/获取，获取方法请参见产品手册“匿名化工具安全策略”页面。

  **说明** 

  获取该软件或文档需要一定的权限，如果无法直接下载，请联系华为工程师获取。
- 备份配置参数的取值不同物理数据库会对将备份的文件采用不同的备份策略。如果“备份数据保存方式”为“FTPSERVER(保存到FTP服务器)”或“SFTPSERVER(保存到SFTP服务器)”，则“服务器IPV4地址”或“服务器IPV6地址”、“服务器用户名”、“服务器密码”、“服务器路径”和“服务器端口”都需要配置，且“本地IPV4地址”或“本地IPV6地址”、“本地IPV4网关”或“本地IPV6网关”、“本地IPV4子网掩码”或“本地IPV6前缀长度”三个参数中只需要配置“本地IPV4地址”或“本地IPV6地址”。

  **说明** 

  FTP服务器不安全，建议使用SFTP服务器。如果通过执行该命令配置了物理数据库备份文件保存在FTP服务器，系统会上报“ALM-10031 系统存在不安全的配置项”告警。
- 在执行此命令前必须保证系统中已配置NDF模块，可通过在“USCDB MML命令” 界面执行**LST MODULE**命令进行查询是否已配置，如果NDF模块没有配置，请执行**ADD MODULE**命令定义NDF的模块号。
- 该命令不允许进行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。
- 当通过该命令修改如下场景信息后，需要执行**RST MODULE**命令重启对应的NDF模块才能生效。
  - 场景一：修改“备份数据保存方式”，从之前的“NOSTOSERVER(不保存到服务器)”修改为“FTPSERVER(保存到FTP服务器)”或“SFTPSERVER(保存到SFTP服务器)”。
  - 场景二：修改用于访问远程备份服务器的本地IP地址。
  - 场景三：修改“备份数据保存方式”，从之前的“FTPSERVER(保存到FTP服务器)”或“SFTPSERVER(保存到SFTP服务器)”修改为“NOSTOSERVER(不保存到服务器)”。
- 密码长期使用会增加被盗窃和破解的风险，而且使用的时间越长，被盗窃和破解的风险越高。定期修改密码可以有效防范这种情况的发生，因此强烈建议您定期修改密码。

## 使用实例

1. 修改USCDB物理数据库自动备份的配置信息：“自动备份开关”为“ON(开)”，“备份时间点”为“03：00：00”，“保存的最大周期的个数”为“3”，“备份数据保存方式”为“FTPSERVER(保存到FTP服务器)”，“IP类型”为“IPV4”，“本地IPV4地址”是“192.168.0.3”，“IP地址的VPN”名称为“VRF\_CC\_DATA”，FTP“服务器IPV4地址”是“192.168.0.4”，FTP“服务器用户名”是“ftpuser”，“服务器密码”是“123456”，“服务器路径”为根目录，“服务器端口号”为“21”。

   ```
   MOD BACKUP: BAKSWH=ON, BAKDAY=03&00&00, STOTIM=3, STOTYP=FTPSERVER, IPVER=IPV4,LIPV4="192.168.0.3", IPVPNNAME="VRF_CC_DATA", FTPIPV4="192.168.0.4", FTPUSR="ftpuser", FTPPAS="*****", FTPPATH="/", FTPPORT=21;
   ```

   **说明** 

   “服务器密码”在命令输入区域显示\*\*\*\*\*。
2. 在某局点升级场景中，将“自动备份开关”修改为“OFF(关)”。

   ```
   MOD BACKUP: BAKSWH=OFF;
   ```
