# 查询PGW流控参数(LST PGWFLOWCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询PGW流控参数配置信息：

- 若需要查询全部PGW流控软参的概要信息，请不要输入任何参数。
- 若需要查询某条PGW流控软参的详细信息，请输入“流控开关参数”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称                  | 参数说明                                                                                                                             |
|:--------------|:----------------------|:---------------------------------------------------------------------------------------------------------------------------------|
| PGWSYSCP      | 系统配置参数                | 用于指示系统需要按照系统配置参数来查询流控软参配置信息，系统初始设置值为“SYSPARA(系统参数)”。                                                                             |
| PGWFCCPN      | 流控配置参数名称              | 用于指示系统需要按照流控配置参数名称来查询流控软参配置信息，系统初始设置值为“FLOWCTRL(流控参数)”。                                                                          |
| PGWFLWCTRTYPE | 流控开关类型                | 用于指示系统需要按照流控开关类型来查询流控软参配置信息。                                                                                                     |
| PGWFLWCTRFLG  | 流控开关参数                | 用于指示系统需要按照是否开启流控来查询流控软参配置信息，当“流控开关类型”为“BOSS(BOSS)”时，系统初始设置值为“MSGFC（MSGFC）”；当“流控开关类型”为“NOTIFY(NOTIFY)”时，系统初始设置值为“NOTIFYOFF(OFF)”。 |
| PGWCPUFLWSTR  | CPU起控门限               | 用于指示系统需要按照“CPU起控门限”的值来查询流控软参配置信息，系统初始设置值为“95”。                                                                                   |
| PGWCPUFLWEND  | CPU解控门限               | 用于指示系统需要按照“CPU解控门限”的值来查询流控软参配置信息，系统初始设置值为“85”。                                                                                   |
| PGWTSSTR      | PGW消息队列消息堆积时间起控门限(毫秒) | 用于指示系统需要按照“PGW消息队列消息堆积时间起控门限(毫秒)”的值来查询流控软参配置信息，系统初始设置值为“600”。                                                                    |
| PGWTSEND      | PGW消息队列消息堆积时间解控门限(毫秒) | 用于指示系统需要按照“PGW消息队列消息堆积时间解控门限(毫秒)”的值来查询流控软参配置信息，系统初始设置值为“100”。                                                                    |

## 使用实例

查询PGW的流控参数信息：

```
LST PGWFLOWCTRL:;
```

```
%%LST PGWFLOWCTRL:;%%
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**MOD PGWFLOWCTRL**命令的参数说明。
