# 显示清除垃圾路由数据的结果(DSP JUNKROUTE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询垃圾路由数据校验状态信息。

在DRU路由数据迁移场景下，在执行**FIN ROUTETRANS**时，如果系统异常重启，会造成系统产生垃圾路由数据。这些数据不影响系统功能，但会占用DRU节点的内存。此时可通过执行本命令查询垃圾路由数据校验状态信息，以确认是否需要执行**CLR JUNKROUTE**命令清除垃圾路由数据。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称         | 参数说明                                                                                                                                  |
|:------------|:-------------|:--------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 业务类型         | 用于请求系统显示哪个业务类型的垃圾路由数据的校验状态信息；若不输入，则表示所有业务类型。 该值取决于加载的FE插件包。如果该USCDB网元是IMS-HSS、HSS9860的融合网元，那么取值就是IMS-HSS和HSS9860。可通过LST FEPLUG命令查询获取。 |
| DRUCID      | DRU Cluster号 | 用于请求系统显示哪个DRU Cluster标识的垃圾路由数据校验状态信息；若不输入，则表示所有的DRU Cluster标识。                                                                        |

## 使用实例

DRU路由数据迁移场景下，执行**FIN ROUTETRANS**时，系统异常重启。查询“业务类型”为“SUP-FE”，“DRU Cluster标识”为“66”的垃圾路由数据清理状态，执行命令如下：

```
DSP JUNKROUTE: SERVICETYPE="SUP-FE", DRUCID=66;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1的参数说明。

| 输出项名称     | 输出项解释                                                                                                                           |
|:----------|:--------------------------------------------------------------------------------------------------------------------------------|
| Cluster标识 | 用于返回查询的Cluster标识。                                                                                                               |
| FE类型      | 用于返回FE类型，对应业务类型。                                                                                                                |
| 返回结果描述    | 用于返回命令的执行结果是成功还是失败。                                                                                                             |
| 垃圾路由校验状态  | 用于返回垃圾路由校验状态。                                                                                                                   |
| 路由表名      | 用于返回校验的路由表名。                                                                                                                    |
| 节点对象数量    | 用于返回进行垃圾路由数据校验的节点记录数量。                                                                                                          |
| 已校验对象     | 用于返回已进行垃圾路由数据校验的记录数量。如下场景中，“已校验对象”和“不一致对象”都显示为“0”，否则，查询出来的都是最近一次垃圾数据清理的结果： 未执行CLR JUNKROUTE命令。进程异常重启。进程刚加载成功。                   |
| 不一致对象     | 用于返回已进行垃圾路由数据校验的垃圾路由数据记录个数（即不一致的路由表个数）。如下场景中，“已校验对象”和“不一致对象”都显示为“0”，否则，查询出来的都是最近一次垃圾数据清理的结果： 未执行CLR JUNKROUTE命令。进程异常重启。进程刚加载成功。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释           | 原因分析                                                                                | 处理建议                                                                                                  |
|------:|:----------------|:------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------|
|  2114 | 业务类型不存在         | 输入的“业务类型”不存在。                                                                       | 执行LST FEPLUG命令查看已加载的FE插件包，即业务类型。 FE插件包加载成功，在执行该命令时输入正确的业务类型。FE插件包加载失败，通过LOD FEPLUG命令加载FE插件包后，重新执行该命令。 |
|  2115 | DRU节点不存在        | 输入的“DRU Cluster号”对应的节点不存在。                                                          | 执行ADD NODE命令为Cluster增加节点，然后重新执行本命令。                                                                   |
|  2116 | DRU Cluster不存在  | 输入的“DRU Cluster号”不存在。                                                               | 执行LST CLUSTER命令查询系统中存在的DRU Cluster标识，然后重新执行本命令。                                                       |
|  2125 | 不是路由DRU cluster | DRU Cluster的数据类型有“全局数据”和“路由数据”，而本命令是用于删除垃圾路由数据，因此本命令输入的“DRU Cluster号”的数据类型应为“路由数据”。 | 执行LST CLUSTER命令查询“数据类型”为“路由数据”的DRU Cluster，然后重新执行本命令。                                                 |
|  2119 | FE类型和Cluster不匹配 | 输入的“业务类型”参数和“DRU Cluster号”参数取值不匹配。                                                  | 执行LST CLUSTER命令查询“DRU Cluster号”对应的FE类型，然后重新执行本命令。                                                     |
