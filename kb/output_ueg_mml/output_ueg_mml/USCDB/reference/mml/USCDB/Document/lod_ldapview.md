## 命令功能

**须知** 

该命令属于高危命令，该操作将加载视图包，操作不当或加载错误的视图包，将导致业务处理失败。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于加载LDAP视图包。

该命令的使用场景：在开局或者改造场景下，加载LDAP视图包，满足局点的定制适配需求。

## 注意事项

- 在执行此命令前，LDAP视图包必须通过OM Portal的文件传输服务上传到“CGPLite文件 > 软件包”文件夹内。上传方法可参考产品文档中“GUI参考 > 文件传输”，并且该适配包必须使用CMS签名。上传后，需先在“CSP MML命令”界面上执行**LOD PKG**命令，然后登录“USCDB MML命令”界面执行本命令才能生效。
- 该命令不允许进行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                                              |
|:------------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VIEWPKGNAME | LDAP视图包名称 | 可选必选说明：必选参数 参数含义：用于指定LDAP视图包名称，为上传至在OM Portal“应用文件”文件夹内的LDAP视图包文件名。 取值范围：长度不超过128的字符串。字符串需由字母（A～Z、a～z）、数字（0～9）和特殊字符（.、_、-、+、=、英文括号、空格）构成，且必须以“.tar”结尾。 默认值：无。 配置原则：无。  说明： LDAP视图包名称的命名必须为“*_VIEW_VXXXRXXXCXXSPCXXX.tar”或“*_VIEW_VXXXRXXXCXX.tar”格式，其中，“*”表示取值范围内的任意字符，“X”表示单个字符。 |

## 使用实例

1. 通过OM Portal的文件传输服务上传LDAP视图包“XX\_SESSIONDB\_VIEW\_V200R025C02.tar”到“CGPLite文件 > 软件包”文件夹内。上传方法可参考产品文档中“GUI参考 > 文件传输”，并且该适配包必须使用CMS签名。上传后，需先在“CSP MML命令”界面上执行**LOD PKG**命令。
2. 加载LDAP视图包，“LDAP视图包名称”为“XX\_SESSIONDB\_VIEW\_V200R025C02.tar”。

   ```
   LOD LDAPVIEW: VIEWPKGNAME="XX_SESSIONDB_VIEW_V200R025C02.tar";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
