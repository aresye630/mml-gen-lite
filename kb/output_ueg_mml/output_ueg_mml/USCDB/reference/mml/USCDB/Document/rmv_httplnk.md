# 删除HTTP链路（RMV HTTPLNK）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，删除HTTP链路会造成对端设备接收不到订阅通知。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除HTTP链路。

## 注意事项

- 在删除一个HTTP链路集前，请先确认该链路集是否被**ADD SUBSCRIBER**命令配置的订阅者所引用，可以通过**LST SUBSCRIBER**命令查询该链路集是否被引用。如果该链路集被引用，则删除该链路集失败。
- 参数“链路ID”与参数“链路集ID”的取值不能同时为空。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                |
|:-------|:-------|:--------------------------------------------------------------------|
| LNKID  | 链路ID   | 标识一条HTTP链路数据记录的关键字段之一，用于指定需要删除哪一条HTTP链路，操作员可以使用LST HTTPLNK命令查询获得。   |
| LKSID  | 链路集ID  | 标识一条HTTP链路集数据记录的关键字段之一，用于指定需要删除哪一条HTTP链路集，操作员可以使用LST HTTPLNK命令查询获得。 |

## 使用实例

1. 删除指定HTTP链路，该“链路ID”为“50”。

   ```
   RMV HTTPLNK: LNKID=50;
   ```
2. 删除指定HTTP链路集，该“链路集ID”为“3”。

   ```
   RMV HTTPLNK: LKSID=3;
   ```
3. 删除指定HTTP链路，该链路同时满足“链路ID”为“3”，“链路集ID”为“2”。

   ```
   RMV HTTPLNK: LNKID=3, LKSID=2;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                | 原因分析                         | 处理建议                                                                                                                                                                                |
|-------:|:---------------------|:-----------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 274631 | 链路集已经被使用，不能删除。       | 链路集已经被“订阅者”使用，不能删除。          | 先执行LST SUBSCRIBERGRP命令查询其它订阅组是否仍在引用此订阅者。 若引用先执行RMV SUBSCRIBERGRP命令删除该“订阅组ID”，再执行RMV SUBSCRIBER命令删除该链路集的“订阅者ID”，最后重新执行本命令删除该链路集。若没有引用先执行RMV SUBSCRIBER命令删除该链路集的“订阅者”，再重新执行本命令删除该链路集。 |
| 274632 | 链路不存在。               | 只能删除已经存在的链路。                 | 先执行LST HTTPLNK命令查询已经存在的链路，再重新执行本命令删除所需的链路。                                                                                                                                          |
| 274633 | 链路集不存在。              | 只能删除已经存在的链路集。                | 先执行LST HTTPLNK命令查询已经添加的链路集，再重新执行本命令删除所需要的链路集。                                                                                                                                       |
| 274704 | 参数LNKID和LKSID必须选择一个。 | “链路ID”和“链路集ID”不能同时为空，否则无法删除。 | 输入“链路ID”或者“链路集ID”，再重新执行本命令。                                                                                                                                                         |
| 274705 | 符合该链路集的链路不存在。        | 指定链路不在链路集中。                  | 先执行LST HTTPLNK命令查询链路集与链路的对应关系，再重新执行本命令，确保要删除的与查询结果中相同。                                                                                                                              |
