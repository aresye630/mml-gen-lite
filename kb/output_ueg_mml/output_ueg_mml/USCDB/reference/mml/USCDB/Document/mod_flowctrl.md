# 修改流控参数(MOD FLOWCTRL)

- 命令功能
- 注意事项

- 输出结果说明

## 命令功能

**须知** 

- 该命令属于高危命令，该操作将修改流控参数，操作不当将导致流控不能触发或过早触发，并导致业务严重呼损。因此执行该命令前，需要与华为技术支持确认后才可以实施。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于对默认的流控参数信息进行修改或调整，负责流控功能的软件模块会根据当前USCDB的DRU/DSU/DSG模块的负荷状态和配置的流控参数信息，自动开启流控和解除流控。

该命令的使用场景：用于异常场景下的调测，当出现系统不稳定，如频繁起控解控，操作员可以使用本命令修改流控参数以使系统保持健康的运行状态，始终提供最大能力的消息响应服务。

## 注意事项

- 各参数起控门限的值一定要大于解控门限的值。
- 起控后，将限制访问USCDB的请求消息的处理，可能造成部分业务请求失败。
- 在缺省的情况下，系统预置了如下参数:

  ```
                            流控开关参数  =  仅消息阻塞流控
                             CPU起控门限  =  95
                             CPU解控门限  =  85
   DRU消息队列消息堆积时间起控门限(毫秒)  =  500
   DSU消息队列消息堆积时间起控门限(毫秒)  =  500
   DSG消息队列消息堆积时间起控门限(毫秒)  =  500
   DRU消息队列消息堆积时间解控门限(毫秒)  =  100
   DSU消息队列消息堆积时间解控门限(毫秒)  =  100
   DSG消息队列消息堆积时间解控门限(毫秒)  =  100
  LDAP消息队列消息堆积时间起控门限(毫秒)  =  80
  LDAP消息队列消息堆积时间解控门限(毫秒)  =  50
  ```
- 当USCDB的DRU/DSU/DSG模块的负荷过高产生流控启用告警时，如果通过执行本命令将流控开关参数修改为关闭，流控状态不会立刻解除，告警也不会立刻清除，需等待模块负荷恢复正常状态。
- 该命令不允许进行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。

## 参数说明

| 参数标识      | 参数名称                   | 参数说明                                                                                                                                                    |
|:----------|:-----------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------|
| FLWCTRFLG | 流控开关参数                 | 用于指定流控功能是否开启。 各参数选项的含义是：OFF（关）：表示流控功能关闭。ON（开）：表示流控功能开启。MSGFC（仅消息阻塞流控）：表示仅消息阻塞流控。 系统初始设置值：MSGFC(仅消息阻塞流控)。                                                |
| CPUFLWSTR | CPU起控门限                | 仅当“流控开关参数”为“ON（开）”时该参数有效，用于指定当CPU的使用率大于或等于该值时开启流控。CPU起控门限的值必须比CPU解控门限的值至少大10。 取值范围：10～100 单位：％ 系统初始设置值：95                                               |
| CPUFLWEND | CPU解控门限                | 仅当“流控开关参数”为“ON（开）”时该参数有效，用于指定当CPU的使用率小于或等于该值时解除流控。CPU解控门限的值必须比CPU起控门限的值至少小10。 取值范围：0～90 单位：% 系统初始设置值：85                                                 |
| DRUTSSTR  | DRU消息队列消息堆积时间起控门限(毫秒)  | 仅当“流控开关参数”为“ON（开）”或“MSGFC（仅消息阻塞流控）”时该参数有效，用于指定当消息在DRU消息队列堆积的时间大于或等于该值时开启流控，相关原理请参见消息队列处理过程。 取值范围：200～2500 单位：ms 系统初始设置值：500                             |
| DSUTSSTR  | DSU消息队列消息堆积时间起控门限(毫秒)  | 仅当“流控开关参数”为“ON（开）”或“MSGFC（仅消息阻塞流控）”时该参数有效，用于指定当消息在DSU消息队列堆积的时间大于或等于该值时开启流控。 取值范围：200～2500 单位：ms 系统初始设置值：500                                             |
| DSGTSSTR  | DSG消息队列消息堆积时间起控门限(毫秒)  | 仅当“流控开关参数”为“ON（开）”或“MSGFC（仅消息阻塞流控）”时该参数有效，用于指定当消息在DSG消息队列堆积的时间大于或等于该值时开启流控。 取值范围：200～2500 单位：ms 系统初始设置值：500                                             |
| DRUTSEND  | DRU消息队列消息堆积时间解控门限(毫秒)  | 仅当“流控开关参数”为“ON（开）”或“MSGFC（仅消息阻塞流控）”时该参数有效，用于指定当消息在DRU消息队列堆积的时间小于或等于该值时解除流控。 取值范围：1～1000 单位：ms 系统初始设置值：100                                               |
| DSUTSEND  | DSU消息队列消息堆积时间解控门限(毫秒)  | 仅当“流控开关参数”为“ON（开）”或“MSGFC（仅消息阻塞流控）”时该参数有效，用于指定当消息在DSU消息队列堆积的时间小于或等于该值时解除流控。 取值范围：1～1000 单位：ms 系统初始设置值：100                                               |
| DSGTSEND  | DSG消息队列消息堆积时间解控门限(毫秒)  | 仅当“流控开关参数”为“ON（开）”或“MSGFC（仅消息阻塞流控）”时该参数有效，用于指定当消息在DSG消息队列堆积的时间小于或等于该值时解除流控。 取值范围：1～1000 单位：ms 系统初始设置值：100                                               |
| LDAPTSSTR | LDAP消息队列消息堆积时间起控门限(毫秒) | 仅当“流控开关参数”为“ON（开）”或“MSGFC（仅消息阻塞流控）”时该参数有效，用于指定当LDAP消息队列消息堆积时间大于或等于该值时开启流控，相关原理请参见LDAP接口流量控制。该参数仅在CAG或DSG模块使用LDAP接口接入业务时有效。 取值范围：40～200 单位：ms 系统初始设置值：80 |
| LDAPTSEND | LDAP消息队列消息堆积时间解控门限(毫秒) | 仅当“流控开关参数”为“ON（开）”或“MSGFC（仅消息阻塞流控）”时该参数有效，用于指定当LDAP消息队列消息堆积时间小于或等于该值时解除流控。该参数仅在CAG或DSG模块使用LDAP接口接入业务时有效。 取值范围：20～180 单位：ms 系统初始设置值：50                   |

## 使用实例

设置“流控开关参数”为“ON(开)”，“CPU起控门限”为“95”，“CPU解控门限”为“85”，“DRU消息队列消息堆积时间起控门限(毫秒)”为“500”，“DSU消息队列消息堆积时间起控门限(毫秒)”为“500”，“DSG消息队列消息堆积时间起控门限(毫秒)”为“500”，“DRU消息队列消息堆积时间解控门限(毫秒)”为“100”，“DSU消息队列消息堆积时间解控门限(毫秒)”为“100”，“DSG消息队列消息堆积时间解控门限(毫秒)”为“100”， “LDAP消息队列消息堆积时间起控门限(毫秒)”为“80”，“LDAP消息队列消息堆积时间解控门限(毫秒)”为“50”：

```
MOD FLOWCTRL: FLWCTRFLG=ON, CPUFLWSTR=95, CPUFLWEND=85, DRUTSSTR=500, DSUTSSTR=500, DSGTSSTR=500, DRUTSEND=100, DSUTSEND=100, DSGTSEND=100, LDAPTSSTR=80, LDAPTSEND=50;
```
