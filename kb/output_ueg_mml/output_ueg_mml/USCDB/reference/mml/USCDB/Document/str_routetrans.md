## 命令功能

**须知** 

该命令属于高危命令，该操作将启动路由数据迁移，操作不当将导致数据无法访问、业务严重呼损。因此执行该命令前，需要与华为技术支持确认后才可以实施。

路由数据迁移使用的场景如下：

- DRU扩容

  当运营商需要对现有局点设备进行DRU扩容时，操作员需要在增加了新的DRU cluster之后，使用本命令完成原有DRU cluster和新增DRU cluster之间的路由数据迁移操作，以保持原有DRU cluster和新增DRU cluster节点之间的负载均衡。
- DRU缩容

  当运营商局点话务量长期降低，为有效利用资源，经过评估确认需要对局点业务模块进行缩容时，先执行**MOD SEGSTATE**对缩容的模块进行隔离，再启动本命令进行路由数据迁移。
- DRU cluster路由数据均衡

  当DRU cluster间用户路由数据出现严重的负载失衡情况时，系统会产生ALM-12016 DRU Cluster间channel个数量失衡告警，操作员需要使用该命令完成各DRU cluster之间的路由数据迁移操作，以保持各DRU cluster之间的负载均衡。

该命令用于DRU扩/缩容或者DRU cluster负载失衡时启动DRU cluster之间的路由数据迁移操作。迁移路由数据处理流程如图1所示。

## 注意事项

- 路由数据迁移启动前

  - 检查DRU节点状态，确保节点状态正常。
  - 暂停业务发放系统下发开销户、补卡、改号等涉及路由数据修改的指令。

  **说明** 

  系统进行路由数据迁移所需要的时间会随DRU中路由数据量的增加而延长。通常对于500万用户容量的标准配置局点，完成一个DRU节点的路由数据迁移大约需要1小时左右。因此，在进行路由数据迁移操作之前请联系华为技术支持明确具体的迁移时长。
- 路由数据迁移启动前通过**LST INSP**命令检查如下开关已正确设置:
  - 周期性校验开关确保已全部关闭，包括软参FWDRTVFYSWT（正向路由校验开关）、REVVFYSWT（反向校验开关）、FWDVFYSWT（正向校验开关）、REVRTVFYSWT（反向路由校验开关）要全部设置为“0”。
  - 用户数据统计开关确保已关闭，即软参USERDATAMEASUREFLAG（定时用户数据统计开关）已设置为“0”。
  - 周期性备份开关已关闭，即软参TIMEBACKUPFLAG（定时备份开关）已设置为“0”。
  - 局间校验已关闭，即软参REDUNDANCYSWITCH（容灾开关）已设置为“1”。
- 混合组网场景下，对于执行扩缩容操作的分区以及该分区对接的其他分区，通过****LST PARTITIONPARA****命令检查“全局路由校验开关”的状态是否已关闭。如没有关闭，需要通过****SET PARTITIONPARA****命令将“全局路由校验开关”设置为“Off（关闭）”。
- 混合组网场景下，涉及路由分区（包含vRP、vRSP和vRSP\_R）主用局或容灾局的扩缩容，执行该命令前，需将主用局和容灾局的软参GRDSYNCMODE（全局路由数据同步模式）改成“1”（全局路由数据采用hash分发的模式同步），确保主用局和容灾局全局路由数据的一致性。
- 路由数据迁移过程中

  - 可以执行**DSP ROUTETRANS**命令查询路由数据迁移的状态。
  - 除查询命令之外，不允许执行其他任何涉及数据修改的命令。
- 路由数据迁移完成后

  - 恢复暂停的业务发放系统业务。
  - 打开内存数据库的校验开关。
  - 打开用户数据统计开关。
  - 打开定时备份开关。
  - 恢复局间校验正常进行。
  - 混合组网场景下，恢复扩缩容操作的分区以及该分区对接的其他分区“全局路由校验开关”为初始状态。
  - 混合组网场景下，涉及路由分区（包含vRP、vRSP和vRSP\_R）主用局或容灾局的扩缩容，需要恢复主用局和容灾局软参GRDSYNCMODE（全局路由数据同步模式）为“0”（全局路由数据采用点对点的模式同步）。
- 在融合场景下，为保证路由数据迁移操作的数据安全性，减少对业务发放系统的影响，建议每个FE网元单独进行路由数据迁移操作。
- 如果迁移后出现异常需要回退路由数据，执行**RBK ROUTETRANS**命令将路由数据回退到迁移前的状态。
- 在完成迁移路由数据一周后，如果系统运行正常，执行**FIN ROUTETRANS**命令删除冗余的路由数据。
- 为确保系统的稳定运行，用户数据迁移必须在话务量低的时间段（例如凌晨2:00～4:00）进行。
- 该命令禁止通过定时自动任务执行。
- 该命令不允许进行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                             |
|:-------|:-------|:-----------------------------------------------------------------|
| FETYPE | FE类型   | 用于标识进行路由数据迁移的FE网元类型。该参数在USCDB下唯一，在通过LOD FEPLUG命令加载FE插件包之后才能在此引用。 |

## 使用实例

某局点需要进行主用局和容灾局USCDB的DRU迁移操作，需要执行操作步骤如下：

1. 在“CSP MML命令”界面，执行**DSP NODE**命令查询DRU节点状态，确保其状态正常。
2. 在业务发放系统端停止下发开销户、补卡、改号等涉及路由数据修改的指令。
3. 关闭内存数据库校验开关，以“SUP-FE”类型为例：

   ```
   MOD INSP: INSPT=FE, INSPN=FWDVFYSWT, INSPV=0, FETYPEN="SUP-FE";
   MOD INSP: INSPT=FE, INSPN=REVVFYSWT, INSPV=0, FETYPEN="SUP-FE";
   MOD INSP: INSPT=FE, INSPN=FWDRTVFYSWT, INSPV=0, FETYPEN="SUP-FE";
   MOD INSP: INSPT=FE, INSPN=REVRTVFYSWT, INSPV=0, FETYPEN="SUP-FE";
   MOD INSP: INSPT=FE, INSPN=REDUNDANCYSWITCH, INSPV=1, FETYPEN="SUP-FE";
   ```
4. 关闭定时备份功能，以“SUP-FE”类型为例：

   ```
   MOD INSP: INSPT=FE, INSPN=TIMEBACKUPFLAG, INSPV=0, FETYPEN="SUP-FE";
   ```
5. 执行本命令启动DRU cluster之间的路由数据迁移操作，以“SUP-FE”类型为例：

   ```
   STR ROUTETRANS: FETYPE="SUP-FE";
   ```
6. 恢复暂停的业务发放系统业务。
7. 打开内存数据库校验开关，以“SUP-FE”类型为例：

   ```
   MOD INSP: INSPT=FE, INSPN=FWDVFYSWT, INSPV=1, FETYPEN="SUP-FE";
   MOD INSP: INSPT=FE, INSPN=REVVFYSWT, INSPV=1, FETYPEN="SUP-FE";
   MOD INSP: INSPT=FE, INSPN=FWDRTVFYSWT, INSPV=1, FETYPEN="SUP-FE";
   MOD INSP: INSPT=FE, INSPN=REVRTVFYSWT, INSPV=1, FETYPEN="SUP-FE";
   MOD INSP: INSPT=FE, INSPN=REDUNDANCYSWITCH, INSPV=0, FETYPEN="SUP-FE";
   ```
8. 开启定时备份功能，以“SUP-FE”类型为例：

   ```
   MOD INSP: INSPT=FE, INSPN=TIMEBACKUPFLAG, INSPV=1, FETYPEN="SUP-FE";
   ```
