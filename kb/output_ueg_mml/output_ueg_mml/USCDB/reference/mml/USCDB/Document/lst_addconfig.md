# 查询ADD服务器配置(LST ADDCONFIG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询ADD服务器的相关配置信息，关于ADD业务请参考自动设备检查配置管理的功能描述。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                          |
|:---------|:-------|:------------------------------------------------------------------------------|
| IPVER    | IP类型   | 用于指示系统根据哪种IP地址类型来查询ADD服务器配置。                                                  |
| IPV4ADDR | IPV4地址 | 仅当本命令中的“IP类型”参数选择为“IPV4”时该参数有效，用于指示系统根据哪个IPv4地址来查询ADD服务器配置；若不输入，则表示所有的IPv4地址。 |
| IPV6ADDR | IPV6地址 | 仅当本命令中的“IP类型”参数选择为“IPV6”时该参数有效，用于指示系统根据哪个IPv6地址来查询ADD服务器配置；若不输入，则表示所有的IPv6地址。 |

## 使用实例

查询ADD服务器配置信息：

```
LST ADDCONFIG: IPVER=IPV4;
```

```
%%LST ADDCONFIG: IPVER=IPV4;%%
RETCODE = 0  操作成功

操作结果如下
------------
    IP类型  =  IPV4
  IPV4地址  =  10.85.165.185
  IPV6地址  =  NULL
      端口  =  9080
      网址  =  /servlet/MessageHandler
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD ADDCONFIG**命令的参数说明。
