## 命令功能

**须知** 

停止试运行需要大约10分钟完成，请务必在华为技术支持人员的指导下操作。

本命令用于admin用户强制终止试运行。执行的效果与**CNL TST**相同。

普通用户只能停止（回退）自己开始的事务引发的试运行模式，admin用户可以用本命令强行终止其他用户开始的事务引发的试运行模式。

本命令的使用场景为：试运行状态下配置数据的执行结果与期望的结果不相符时，admin用户可以使用本命令撤销试运行，转入正常模式运行。

## 注意事项

- admin用户强制终止事务命令会将在事务模式下所做的增加、删除、修改等操作全部取消，主机侧的数据也回退到事务模式前的状态。
- 命令执行后进入开始事务之前的正常模式。

## 参数说明

无。

## 使用实例

admin用户强制终止试运行：

```
STP TST:;
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，请联系华为技术支持处理。
