# 查询网元业务IP地址(LST SRVIPADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询网元业务IP地址配置信息：

- 若需要查询网元业务IP配置的概要信息，请不要输入任何参数。
- 若需要查询网元业务IP类型满足某个条件的IP配置详细信息，请输入对应的“业务IP索引”或其他参数或这些参数的组合 。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称                 | 参数说明                                                                                                                                           |
|:------------|:---------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| SRVINDEX    | 业务IP索引               | 用于指示系统需要按照哪个业务IP索引来查询业务IP地址信息；若不输入，则表示查询所有业务IP索引所对应的业务IP地址信息。                                                                                  |
| SRVIPTYPE   | 业务IP类型               | 用于指示系统需要按照哪个业务IP类型来查询业务IP地址信息；若不输入，则表示查询所有业务IP类型的业务IP地址信息。                                                                                     |
| DPUMID      | DPU模块号               | 用于指示系统需要按照哪个DPU模块号来查询业务IP地址信息；如不输入，则表示查询所有DPU模块号的业务IP地址信息。                                                                                     |
| IPVER       | IP类型                 | 用于指示系统需要按照哪个IP类型来查询业务IP地址信息；若不输入，则表示查询所有IP类型所对应的业务IP地址信息。                                                                                      |

| IPV4IP1     | 本地Location IPV4地址1   | 用于指示系统按照哪个IP地址来查询业务IP地址信息；若不输入，则表示查询所有本地IP地址信息。                                                                                                |
| IPV4GW1     | 本地Location IPV4网关1   | 用于指示系统按照哪个网关来查询业务IP地址信息；若不输入，则表示查询所有网关对应的业务IP地址信息。                                                                                             |
| IPV4MASK1   | 本地Location IPV4子网掩码1 | 用于指示系统按照哪个子网掩码来查询业务IP地址信息；若不输入，则表示查询所有子网掩码对应的业务IP地址信息。                                                                                         |
| IPV6IP1     | 本地Location IPV6地址1   | 用于指示系统按照哪个IP地址来查询业务IP地址信息；若不输入，则表示查询所有本地IP地址信息。IPv6格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如：2001:0DB8:02de:0000:0000:0000:0000:0e13。    |

| IPV6MASK1   | 本地Location IPV6前缀长度1 | 用于指示系统按照哪个前缀长度来查询业务IP地址信息；若不输入，则表示查询所有前缀长度对应的业务IP地址信息。                                                                                         |
| IP2VPNNAME  | IP地址2的VPN名称          | 用于指示系统需要按照哪个IP地址2的VPN名称来查询业务IP地址信息；若不输入，则表示查询所有IP地址2的VPN名称的业务IP地址信息。                                                                           |
| IPV4IP2     | 本地Location IPV4地址2   | 用于指示系统按照哪个IP地址来查询业务IP地址信息；若不输入，则表示查询所有本地IP地址信息。                                                                                                |
| IPV4GW2     | 本地Location IPV4网关2   | 用于指示系统按照哪个网关来查询业务IP地址信息；若不输入，则表示查询所有网关对应的业务IP地址信息。                                                                                             |
| IPV4MASK2   | 本地Location IPV4子网掩码2 | 用于指示系统按照哪个子网掩码来查询业务IP地址信息；若不输入，则表示查询所有子网掩码对应的业务IP地址信息。                                                                                         |
| IPV6IP2     | 本地Location IPV6地址2   | 用于指示系统按照哪个IP地址来查询业务IP地址信息；若不输入，则表示查询所有本地IP地址信息。IPv6格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如：2001:0DB8:02de:0000:0000:0000:0000:0e13。    |

| IPV6MASK2   | 本地Location IPV6前缀长度2 | 用于指示系统按照哪个前缀长度来查询业务IP地址信息；若不输入，则表示查询所有前缀长度对应的业务IP地址信息。                                                                                         |
| SERVICETYPE | 业务类型                 | 用于指示系统需要按照哪个业务类型来查询业务IP地址信息；若不输入，则表示查询所有业务类型的业务IP地址信息。                                                                                         |

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释       | 原因分析                          | 处理建议                                 |
|-------:|:------------|:------------------------------|:-------------------------------------|
| 260069 | IP地址的类型不匹配。 | 输入的IP地址类型和“IP类型”参数设置的IP类型不一致。 | 请重新输入，确保输入的IP地址类型和“IP类型”参数设置的IP类型一致。 |
