## 命令功能

**须知** 

该命令属于高危命令，该操作将修改DTLS协议配置，操作不当将造成业务严重损失，且必须重启服务才能生效。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于配置局间链路使用的DTLS协议版本号和加密套件信息。

该命令的使用场景：系统启用DTLS Over SCTP链路协议后，用于修改DTLS的协议配置。

## 注意事项

- 执行**LST INSP**命令，查询软参“DTLSOVERSCTPSWT”的值，当软参“DTLSOVERSCTPSWT”设置为“1”时，本命令设置才有效。否则，执行**MOD INSP**命令，修改软参“DTLSOVERSCTPSWT”的值为“1”后，再执行本命令。
- 服务端与客户端进行DTLS协议配置时，需要同时满足以下两个条件，否则，会导致链路断链，并上报22004-DSG SCTP链路故障告警。
  - 服务端与客户端的DTLS协议版本号至少有一个相同。
  - 服务端与客户端的加密套件信息至少有一条相同。
- 本命令需要重启DSG进程才能生效。

  **说明** 

  重启DSG进程时会引起链路断开从而导致业务失败，因此此操作需要在夜间执行，并提前通知客户做好准备。

  重启DSG进程的方法：

  1. 登录“USCDB MML命令”界面。
  2. 使用**LST MODULE**命令查出所有DSG模块号。
  3. 按查询得到的DSG模块号使用**RST MODULE**命令重启模块。
  4. 登录“CSP MML命令”界面。
  5. 使用**DSP MODULE**命令查询上述重启模块的“可用状态”为“正常”。
  6. 按2查询到的DSG模块依次重复执行3~5重启下一模块。

## 使用实例

用户需要配置局间链路DTLS协议版本号和加密套件信息为：“协议版本”为“DTLS1.2”、“强加密套件”为“TLS\_DHE\_DSS\_WITH\_AES\_128\_GCM\_SHA256&TLS\_DHE\_DSS\_WITH\_AES\_256\_GCM\_SHA384”、“DTLS配置描述”为“DTLS Config”。

```
 SET DTLSCFG: PROTOCOLVER=DTLS1.2-1, STRONGSUITE=TLS_DHE_DSS_WITH_AES_128_GCM_SHA256-1&TLS_DHE_DSS_WITH_AES_256_GCM_SHA384-1, DESCRIPTION="DTLS Config";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                   | 原因分析                    | 处理建议                          |
|-------:|:------------------------|:------------------------|:------------------------------|
| 275391 | “强加密套件”和“兼容加密套件”不能同时为空。 | “强加密套件”和“兼容加密套件”不能同时为空。 | 输入“强加密套件”或者“兼容加密套件”，再重新执行本命令。 |
