# 添加PSITE参数替换规则配置(ADD PSITEPARARULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，该操作将添加PSITE参数替换规则配置，操作不当会导致转发到远端的命令执行失败。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于添加PSITE参数替换规则的配置。

在营帐双发场景下，本端PGW根据该命令配置的替换规则替换参数名或参数值后再转发到远端业务发放站点。

## 注意事项

- PSITE参数替换规则配置最多只能添加64个。
- 系统只能存在一个“Rule ID”和“参数名”均相同的配置。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                                                                             |
|:------------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RULEID      | Rule ID | 可选必选说明：必选参数 参数含义：用于唯一标识一条号段配置，该参数先由ADD PSITERULE命令定义，然后才能在此处引用。 取值范围：1～65535 默认值：无。 配置原则：输入的“Rule ID”对应PSITE配置的业务场景必须为营帐双发。可通过如下方法查询：执行LST PSITE命令查询“业务场景”为“营帐双发”的远端业务发放站点的“Site ID”。根据1中查询出的“Site ID”，执行LST PSITERULE命令查询“Site ID”对应的“Rule ID”。 |
| NAME        | 参数名     | 可选必选说明：必选参数 参数含义：用于指定PSITE参数替换规则中需要替换参数的名称。 取值范围：1～32位的由数字(0～9)和大写字母(A～Z)组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                  |
| NEWNAME     | 新参数名    | 可选必选说明：可选参数 参数含义：用于指定PSITE参数替换规则中替换后参数的名称。 取值范围：1～32位的由数字(0～9)和大写字母(A～Z)组成的字符串。 默认值：无。 配置原则：该参数的取值必须与“参数名”的取值不同。                                                                                                                                 |
| VALUE       | 参数值     | 可选必选说明：必选参数 参数含义：用于指定PSITE参数替换规则中需要替换参数的取值。 取值范围：1～32位的由数字(0～9)和字母(A～Z、a～z)组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                |
| NEWVALUE    | 新参数值    | 可选必选说明：必选参数 参数含义：用于指定PSITE参数替换规则中替换后参数的取值。 取值范围：1～32位的由数字(0～9)和字母(A～Z、a～z)组成的字符串。 默认值：无。 配置原则：该参数的取值必须与“参数值”的取值不同。                                                                                                                               |
| DESCRIPTION | 描述信息    | 可选必选说明：可选参数 参数含义：用于指定PSITE参数替换规则配置的描述信息。 取值范围：不超过32个字符的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                       |

## 使用实例

添加一条PSITE参数替换规则，“Rule ID”为“11”，“参数名”为“USCSN”，“参数值”为“29”，“新参数值”为“30”：

```
ADD PSITEPARARULE: RULEID=11, NAME="USCSN", VALUE="29", NEWVALUE="30";
```
