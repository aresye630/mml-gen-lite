# 启用指定的FE插件(ACT FEPLUG)

- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

本命令用于启用指定的FE插件。

在加载插件包的过程中，当执行**LOD FEPLUG**命令加载插件包完成之后，必须执行本命令对插件包进行激活。

## 注意事项

- 执行本命令之前，请确保所有的DRU Cluster已经配置完成。
- 执行本命令之后，如果需要增加新的DRU Cluster，请执行DRU扩容操作。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                           |
|:-----------|:-------|:-----------------------------------------------------------------------------------------------|
| FETYPENAME | FE类型名称 | 用于描述要启动的FE插件包对应的FE网元类型名称。由LOD FEPLUG命令执行后自动生成。可通过LST FEPLUG命令进行查询。 取值范围： 长度不超过128的字符串。 默认值： 无。 |

## 使用实例

启用FE类型名称为“SUP-FE”的FE插件。执行命令如下：

```
ACT FEPLUG: FETYPENAME="SUP-FE";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 301400 | 没有配置任何该FE类型的路由DRU cluster。               | 执行本命令之前，应确保所有的DRU Cluster已经配置完成。 | 执行ADD CLUSTER命令配置DRU Cluster。重新执行本命令，确保配置成功。                                                                                                                             |
| 330021 | FETYPENAME参数指定的CLUSTER中存在未配置NODE的情况，请检查。 | “FE类型名称”参数指定的Cluster中存在未配置的节点。   | 请按如下步骤进行处理。执行LST CLUSTER命令查看“业务类型”对应的Cluster。执行LST NODE命令查看哪一个Cluster没有配置节点。若节点未配置可以执行ADD NODE命令进行配置或者执行RMV CLUSTER命令删除Cluster，再重新执行本命令激活。                               |
