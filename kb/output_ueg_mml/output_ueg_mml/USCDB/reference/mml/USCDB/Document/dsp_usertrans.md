# 查询用户数据迁移状态(DSP USERTRANS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

同一时间只允许一个用户数据执行任务迁移，该命令用于查询正在执行迁移任务的DMA模块的用户数据状态。

- 若需要查询所有模块的迁移数据信息，请不要输入“DMA模块号”参数。
- 若需要查询某个模块的迁移数据信息，请输入“DMA模块号”参数。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                 |
|:-------|:-------|:---------------------------------------------------------------------|
| FETYPE | FE类型   | 用于指定需要查询哪个FE类型的用户数据迁移状态。该参数在USCDB下唯一，在通过LOD FEPLUG命令加载FE插件包之后才能在此引用。 |
| MID    | DMA模块号 | 用于请求系统显示哪个DMA模块的数据迁移状态；若不输入，则表示所有DMA模块。 取值范围：1～4080 默认值：无。           |

## 使用实例

1. 查询所有模块的数据迁移状态：

   ```
   DSP USERTRANS: FETYPE="SUP-FE";
   ```

   ```
   %%DSP USERTRANS: FETYPE="SUP-FE";%%
   RETCODE = 0  操作成功

   操作结果
   --------
   FE类型   迁移类型     主键类型    迁移记录数    迁移成功记录数    迁移失败记录数   回滚成功记录数   状态 

   SUP-FE   扩容         RAW_PK      10000         10000             0                0                成功
   SUP-FE   扩容         I4_FK       10001         10001             0                0                成功
   SUP-FE   扩容         STR_FK      10002         10002             0                0                成功

   (结果个数 = 3)

   ---    END
   ```
2. 查询“DMA模块号”为“1027”的数据迁移任务状态：

   ```
   DSP USERTRANS: FETYPE="SUP-FE", MID=1027;
   ```

   ```
   %%DSP USERTRANS: FETYPE="SUP-FE", MID=1027;%%
   RETCODE = 0  操作成功

   操作结果
   --------
             FE类型  =  SUP-FE
           迁移类型  =  缩容
           主键类型  =  SID
         迁移记录数  =  20000
     迁移成功记录数  =  19999
     迁移失败记录数  =  1
     回滚成功记录数  =  1
               状态  =  成功

   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称   | 输出项解释                                                                                                                                                                                                                                   |
|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FE类型    | 用于返回用户数据迁移任务的FE类型。                                                                                                                                                                                                                      |
| 迁移类型    | 用于返回用户数据迁移任务的迁移类型。 扩容缩容                                                                                                                                                                                                                 |
| 主键类型    | 用于返回用户数据迁移的主键类型。                                                                                                                                                                                                                        |
| 迁移记录数   | 用于返回待迁移的用户总数，在迁移任务启动时统计。                                                                                                                                                                                                                |
| 迁移成功记录数 | 用于返回迁移成功的用户个数，在迁移过程中实时更新。  说明： 当“迁移类型”为“扩容”时，“迁移成功记录数”将比DSP NODE和DSP NODECOUNT命令查看的实际迁移的节点对象数量多。一种“主键类型”在迁出节点和迁入节点间的数据差值在1000以内则认为数据已经均衡，此时进行迁移会按照轮询机制将数据分发到所有DSU节点，所以数据在迁移后可能会保留在迁出节点上，属于迁移成功。如果在迁移过程中对待迁移的用户进行了删除操作，则迁移成功记录数会小于迁移记录数。 |
| 迁移失败记录数 | 用于返回迁移失败的用户个数。                                                                                                                                                                                                                          |
| 回滚成功记录数 | 用于返回迁移失败后回滚成功的用户个数。                                                                                                                                                                                                                     |
| 状态      | 用于返回用户数据的迁移结果。 成功失败迁移中                                                                                                                                                                                                                  |
