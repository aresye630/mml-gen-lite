# 删除订阅组(RMV SUBSCRIBERGRP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，删除订阅组会造成对端设备接收不到订阅通知。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除一个订阅组或者从订阅组中删除一个订阅者。

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                  |
|:-----------|:-------|:------------------------------------------------------|
| SUBERGRPID | 订阅组ID  | 用于指定一个订阅组。如果该命令中只指定该参数，则删除整个订阅组。 取值范围：1～255。 默认值：无    |
| SUBERID    | 订阅者ID  | 用于指定一个订阅者。如果该参数被指定，则从指定订阅组中删除指定订阅者。 取值范围：1～255。 默认值：无 |

## 使用实例

1. 删除指定订阅组，该“订阅组ID”为“1”。

   ```
   RMV SUBSCRIBERGRP: SUBERGRPID=1;
   ```
2. 从指定订阅组中删除指定订阅者，“订阅组ID”为“1”，“订阅者ID”为“2”。

   ```
   RMV SUBSCRIBERGRP: SUBERGRPID=1, SUBERID=2;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释        | 原因分析                                                                                      | 处理建议                                                                                                                                                |
|-------:|:-------------|:------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| 274636 | 订阅者ID不存在。    | 该订阅组中不存在这个“订阅者ID”，无法删除。                                                                   | 请先执行LST SUBSCRIBERGRP命令查看当前存在的订阅组中的订阅者，然后删除已经存在的订阅者。                                                                                                |
| 274638 | 订阅组ID不存在     | 只能删除已经存在的“订阅组ID”。                                                                         | 请先执行LST SUBSCRIBERGRP查看当前存在的订阅组，然后删除已经存在的订阅组。                                                                                                       |
| 274641 | 订阅组被使用，不能删除。 | 原因有如下两种： 如果该订阅组添加了数据订阅配置，则必须先删除数据订阅配置，然后删除订阅组。如果该订阅组添加了PGW订阅通知配置，则必须先删除PGW订阅通知配置，然后删除订阅组。 | 根据不同的原因分别有如下两种处理建议： 如果该订阅组添加了数据订阅配置，则必须先执行RMV SUBSCRIPTION命令删除数据订阅配置，然后执行本命令删除订阅组。如果该订阅组添加了PGW订阅通知配置，则必须先执行RMV NOTIFYCFG命令删除PGW订阅通知配置，然后执行本命令删除订阅组。 |
