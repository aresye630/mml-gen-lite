# 查询触发器模板(LST TRIGGERTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询触发器模板信息。

- 若需要查询全部触发器模板的概要信息，请不要输入任何参数。
- 若需要查询某个触发器模板的详细信息，请输入“触发器模板ID”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识         | 参数名称    | 参数说明                                                       |
|:-------------|:--------|:-----------------------------------------------------------|
| TRIGGERTPLID | 触发器模板ID | 用于标识一条触发器模板记录；若不输入，则表示查询所有的触发器模板ID。                        |
| CONDITION    | 过滤条件    | 用于标识一条触发器模板记录的过滤条件，过滤条件来源于FE插件包所配置的发布数据；若不输入，则表示查询所有的过滤条件。 |
| NAME         | 触发器模板名称 | 用于标识一条触发器模板记录的名称；若不输入，则表示查询所有的触发器模板名称。                     |

## 使用实例

1. 查询指定触发器模板记录，该“触发器模板ID”为“1”。

   ```
   LST TRIGGERTPL: TRIGGERTPLID=1;
   ```

   ```
   %%LST TRIGGERTPL: TRIGGERTPLID=1;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
     触发器模板ID  =  1
         过滤条件  =  IMSI IN 460000000000000
   触发器模板名称  =  IMSITPL
   (结果个数 = 1)

   ---    END
   ```
2. 查询触发器模板中的所有记录。

   ```
   LST TRIGGERTPL:;
   ```

   ```
   %%LST TRIGGERTPL:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    触发器模板ID  过滤条件                   触发器模板名称

    1             IMSI IN 460000000000000    IMSITPL       
    2             MSISDN IN 861370000000000  ISDNTPL       
   (结果个数 = 2)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数详见**ADD TRIGGERTPL**命令的参数说明。
