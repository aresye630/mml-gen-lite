# 查询业务发放系统IP地址（LST PROVISIONIP）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询允许接入到PGW的SOAP、BOSS、REST、HTTP和WebLMT的IP地址的配置信息。

- 若需要查询全部业务发放系统IP地址的概要信息，请不要输入任何参数。
- 若需要查询某条业务发放系统IP地址的详细信息，请输入“IP地址索引”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|:---------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ADDRID   | IP地址索引   | 用于指示系统需要按照哪个IP地址索引来查询业务发放系统IP地址；若不输入，则表示所有的IP地址索引。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ADDRNAME | IP地址名称   | 用于指示系统需要按照哪个IP地址名称来查询业务发放系统IP地址；若不输入，则表示所有的IP地址名称。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| IPVER    | IP类型     | 用于指示系统需要按照哪个IP类型来查询业务发放系统IP地址；若不输入，则表示所有的IP类型。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| IPV4ADDR | IPV4地址   | 用于指示系统需要按照哪个IPV4地址来查询业务发放系统IP地址；若不输入，则表示所有的IPV4地址。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| IPV6ADDR | IPV6地址   | 用于指示系统需要按照哪个IPV6地址来查询业务发放系统IP地址；若不输入，则表示所有的IPV6地址。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| IPTYPE   | IP地址类型   | 用于指示系统需要按照哪个IP地址类型来查询业务发放系统IP地址；若不输入，则表示所有的IP地址类型。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| IPV4MASK | IPV4地址掩码 | 仅当本命令中的“IP类型”参数选择为“IPV4”时该参数有效，用于指定本地IP地址的地址掩码，由运营商统一规划。 取值范围：255.0.0.0255.255.0.0255.255.255.0255.255.255.255 默认值：255.255.255.255  说明： 用户输入对应的“IPV4地址”时，可同时输入对应的“IPV4地址掩码”，比如“IP类型”为“IPV4”时，若输入的IP地址为10.19.42.145，则“IPV4地址”与“IPV4地址掩码”配置关系如下所述。 不输入地址掩码，则系统默认地址掩码为255.255.255.255，只有10.19.42.145可以接入PGW。地址掩码取为255.255.255.0，则10.19.42.0-10.19.42.255都可接入PGW。地址掩码取为255.255.0.0，则10.19.0.0-10.19.255.255都可接入PGW。地址掩码取为255.0.0.0，则10.0.0.0-10.255.255.255都可接入PGW。                                                                                            |
| IPV6MASK | IPV6地址掩码 | 仅当本命令中的“IP类型”参数选择为“IPV6”时该参数有效，用于指定本地IP地址的地址掩码，由运营商统一规划。 取值范围：1~128 默认值：128  说明： “IPV6地址掩码”输入为1~128的整型，主机侧会将其转化成对应的掩码。比如输入3，则会转化为111后接125个0；输入5，会转化为11111后接123个0；其余以此类推。用户输入对应的“IPV6地址”时，可同时输入对应的“IPV6地址掩码”，比如“IP类型”为“IPV6”时，若输入的IP地址为2001:0db8:0000:0000:0000:0000:0000:0000，则“IPV6地址”与“IPV6地址掩码”配置关系如下举例所述，其余以此类推。不输入地址掩码，则地址掩码默认为128，则只有这一个地址可以接入PGW。地址掩码取为64，则2001:0db8:0000:0000:0000:0000:0000:0000-2001:0db8:0000:0000:FFFF:FFFF:FFFF:FFFF都可接入PGW。地址掩码取为96，则2001:0db8:0000:0000:0000:0000:0000:0000-2001:0db8:0000:0000:0000:0000:FFFF:FFFF都可接入PGW。 |

## 使用实例

1. 查询允许接入PGW的所有SOAP客户端的IP地址：

   ```
   LST PROVISIONIP: IPTYPE=SOAP;
   ```

   ```
   %%LST PROVISIONIP: IPTYPE=SOAP;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------------------
   IP地址索引  =  1
   IP地址名称  =  1
       IP类型  =  IPV4
     IPV4地址  =  10.85.53.155
     IPV6地址  =  NULL
    IP地址类型 =  SOAP
   (结果个数 = 1)

   ---    END
   ```
2. 查询允许接入PGW所有客户端的IP地址：

   ```
   LST PROVISIONIP:;
   ```

   ```
   %%LST PROVISIONIP:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    IP地址索引  IP地址名称  IP类型  IPV4地址       IPV6地址  IP地址类型

    1           NULL        IPV4    192.168.31.43  NULL      SOAP      
    2           NULL        IPV4    192.168.31.44  NULL      BOSS      
   (结果个数 = 2)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD PROVISIONIP**命令的参数说明。
