# 删除全局数据记录数超限阈值（RMV GDATANUMTHD）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中删除一条全局数据记录数超限阈值配置。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                          |
|:------------|:-------|:----------------------------------------------------------------------------------------------|
| SERVICETYPE | 业务类型   | 可选必选说明：必选参数。 参数含义：用于指定具体的服务类型，包括USCDB和FE的插件包类型。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。             |
| TABLENAME   | 表名称    | 可选必选说明：必选参数。 参数含义：用于指定内存库全局数据的表名。表名可通过执行DSP NODECOUNT命令查询获取。 取值范围：长度不超过64的字符串。 默认值：无。 配置原则：无。 |

## 使用实例

删除一条全局数据记录数超限阈值记录：设置“业务类型”为“SUP-FE”，“表名称”为“G\_ALLTYPE\_SUB1\_INFO5\_TPL”。

```
RMV GDATANUMTHD: SERVICETYPE="SUP-FE", TABLENAME="G_ALLTYPE_SUB1_INFO5_TPL";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                    | 原因分析             | 处理建议                                                                        |
|-------:|:-------------------------|:-----------------|:----------------------------------------------------------------------------|
| 260681 | 全局数据记录数超限阈值不存在。          | 待删除的记录不存在。       | 执行LST GDATANUMTHD命令查询已存在的全局数据记录数超限阈值记录，确保需删除的记录存在，然后重新执行本命令删除全局数据记录数超限阈值记录。 |
| 302533 | 输入的业务类型不正确，请输入正确的业务类型参数。 | 输入的“业务类型”参数取值有误。 | 输入正确的“业务类型”后重新执行本命令。 若为非USCDB的应用类型，则需要通过LOD FEPLUG命令加载对应的网元插件包之后才能在此处进行设置。  |
