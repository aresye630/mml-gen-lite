# 局间数据一致性检查（CHK LOCATIONCONS）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令通过收集记录数、局间复制、局间快速校验、局间周期性校验的信息综合判断局间数据是否一致。

- 若需要确认全部业务类型的局间数据是否一致，请不要输入任何参数。
- 若需要确认某个业务类型的局间数据是否一致，请输入“业务类型”参数。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                              |
|:------------|:-------|:----------------------------------------------------------------------------------|
| SERVICETYPE | 业务类型   | 可选必选说明：可选参数。 参数含义：用于指定具体的服务类型，包括USCDB和FE的插件包类型。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。 |

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。各输出项含义请参见表1。

| 输出项名称         | 输出项解释                                                                                |
|:--------------|:-------------------------------------------------------------------------------------|
| 一致性信息         | 用作局间数据一致性检查的判断项。 取值范围： 记录数信息 局间复制和快速校验信息局间全局数据周期性校验信息局间全局路由周期性数据信息局间用户数据周期性校验信息加载源信息 |
| 业务类型          | 用于表示该判断项的所属的业务类型。                                                                    |
| 源Location ID  | 用于表示该判断项发起的源Location ID。                                                             |
| 目的Location ID | 用于表示该判断项接收的目的Location ID。                                                            |
| 检查通过          | 用于表示该判断项检查是否通过。 取值范围： 是 否                                                            |
| 最大差异记录数       | 用于表示该判断项的最大差异记录数。                                                                    |
| 预计数据一致所需时间    | 用于表示该判断项恢复一致所需的大概时间。单位为“分钟”。                                                         |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释                                       | 原因分析                                       | 处理建议                                                                                                                          |
|------:|:--------------------------------------------|:-------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------|
|  2059 | 参数取值无效：参数SERVICETYPE的取值不存在，请确认已经成功加载了该FE插件。 | 输入的“业务类型”在系统中未配置。                          | 通过命令LST FEPLUG查询加载的“FE类型名称”，“FE类型名称”即“业务类型”。 若“业务类型”加载成功，请在执行该命令时输入正确的业务类型名称。 若“业务类型”加载不成功或者没有加载，通过LOD FEPLUG命令加载成功后，重新执行该命令。 |
|  2797 | 局间数据存在不一致。                                  | 通过收集的记录数、局间复制、局间快速校验、局间周期性校验信息判断局间数据存在不一致。 | 根据“预计数据一致所需时间”取值时长，等待局间快速校验和周期性校验完成后再检查局间数据一致性。若局间数据仍存在不一致，请联系华为技术支持处理。                                                       |
