# 查询订阅配置信息(LST SUBSCRIPTION)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询数据集的订阅的配置信息，该订阅配置用于数据层订阅通知。

- 若需要查询全部数据订阅配置的概要信息，请不要输入任何参数。
- 若需要查询指定数据订阅配置的详细信息，请输入“订阅ID”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                |
|:-----------|:-------|:----------------------------------------------------|
| SUBID      | 订阅ID   | 用于指示系统需要按照哪个订阅ID来查询数据订阅配置；若不输入，则表示查询所有的数据订阅配置。      |
| SUBFETYPE  | 订阅者类型  | 用于指示系统需要按照哪个订阅者类型来查询数据订阅配置；若不输入，则表示查询所有的数据订阅配置。     |
| SUBDATA    | 订阅的数据  | 用于指示系统需要按照哪个订阅的数据来查询数据订阅配置；若不输入，则表示查询所有的数据订阅配置。     |
| SUBERGRPID | 订阅组ID  | 用于指示系统需要按照哪个订阅者的订阅组ID来查询数据订阅配置；若不输入，则表示查询所有的数据订阅配置。 |

## 使用实例

1. 查询所有数据订阅配置。

   ```
   LST SUBSCRIPTION:;
   ```

   ```
   %%LST SUBSCRIPTION:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    订阅ID  订阅者类型  订阅的数据      订阅组ID

    1       SUP-FE      SUP-FE_GROUP_1  NULL    
    2       SUP-FE      SUP-FE_GROUP_2  NULL    
    3       SUP-FE      SUP-FE_GROUP_3  NULL    
   (结果个数 = 3)

   ---    END
   ```
2. 查询指定数据订阅配置：设置“订阅ID”为“1”。

   ```
   LST SUBSCRIPTION: SUBID=1;
   ```

   ```
   %%LST SUBSCRIPTION: SUBID=1;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
       订阅ID  =  1
   订阅者类型  =  SUP-FE
   订阅的数据  =  SUP-FE_GROUP_1
     订阅组ID  =  NULL
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD SUBSCRIPTION**命令的参数说明。
