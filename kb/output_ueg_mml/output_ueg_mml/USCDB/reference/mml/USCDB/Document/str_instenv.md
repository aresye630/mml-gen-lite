# 物理数据库环境安装(STR INSTENV)

## 命令功能

**须知** 

- 该命令属于高危命令，该操作将重装和配置物理库，物理库数据将丢失，请谨慎操作，操作前请务必联系华为技术支持工程师确认。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于安装配置物理数据库。

当出现以下应用场景时，需要安装配置物理数据库：

- 新建局。

  无磁盘阵列：系统以虚拟机本地（裸机）磁盘作为物理数据库存储介质。
- 单机下数据库虚拟机（裸机）故障

## 注意事项

- 执行本命令前，首先需要在“CSP MML命令”界面执行**DSP MODULE**命令确认USCDB网元已经添加NDF模块并且运行正常。若不正常会导致物理数据库环境安装失败。
- 对于主备2块数据库虚拟机（裸机）均故障场景，需要重新配置数据库。需与华为技术支持确认在MANO上重新增加两块数据库虚拟机（裸机）后，才能执行本命令。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                    |
|:------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ENVTYPE     | 安装环境类型 | 用于表示物理数据库的安装环境类型。 各参数选项的含义是： LocalDisk(本地物理库)：表示当系统无磁盘阵列，以本地磁盘作为物理数据库时选择此选项。FESQL(插件脚本执行)：表示当重新安装物理数据库之后，需要加载FE插件脚本时选择此选项。SINGLEDB(单机物理库)：表示当按照物理库单机模式进行安装时选择此选项。 默认值：无。 说明： 执行该命令并且不输入该参数时，系统会设置初始值“LocalDisk(本地物理库)”。 |
| SERVICETYPE | 业务类型   | 仅当本命令中的“安装环境类型”参数为“FESQL(插件脚本执行)”时，该参数有效。用于标识FE业务的业务类型。此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。 取值范围：长度不超过128的字符串。 默认值：无。                                                                                                |
| OPTYPE      | 操作类型   | 仅当本命令中的“安装环境类型”参数为“FESQL(插件脚本执行)”时，该参数有效。用于标识加载FE插件脚本时在物理库创建全局数据表还是删除全局数据表。 取值范围：CREATE：创建“业务类型”参数类型的FE插件包对应的全局数据表。DELETE：删除“业务类型”参数类型的FE插件包对应的全局数据表。 默认值：无。 说明：如果需要支持SQL模板导出任务的功能，该参数必须设置为“CREATE”。                    |

## 使用实例

1. 系统无磁盘阵列作为物理数据库，通过如下操作完成本地数据库的安装：

   1. 登录“CSP MML命令”界面，执行**DSP MODULE**命令查看NDF模块已配置并正常运行。
   2. 登录“USCDB MML命令” 界面，安装物理数据库环境：

      ```
      STR INSTENV: ENVTYPE=LocalDisk;
      ```
2. 选择的安装模式是单机物理数据库安装模式，通过如下操作完成本地数据库的安装：

   1. 登录“CSP MML命令”界面，执行**DSP MODULE**命令查看NDF模块配置并正常运行。
   2. 登录“USCDB MML命令” 界面，执行**STR INSTENV**命令安装物理库环境：

      ```
      STR INSTENV: ENVTYPE=SINGLEDB;
      ```
3. 当需要支持SQL模板导出任务功能而创建全局数据表时，通过如下操作在物理库创建全局数据表：
   1. 登录“CSP MML命令”界面，执行**DSP MODULE**命令查看NDF模块配置并正常运行。
   2. 登录“USCDB MML命令” 界面，执行**STR INSTENV**命令安装物理库环境：

      ```
      STR INSTENV: ENVTYPE=FESQL, SERVICETYPE="SUP-FE", OPTYPE=CREATE;
      ```
