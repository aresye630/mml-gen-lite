# 查询Partition的配置信息(LST PARTITIONPARA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于对本地Partition的参数配置进行查询。

该命令的使用场景：根据运营商的需求或实际的现网情况，需要对Partition的参数进行相关的配置修改，修改后需要通过该命令进行查询确认。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                     |
|:------------|:-------|:-----------------------------------------|
| SERVICETYPE | 业务类型   | 用于指示系统按照哪种业务类型来查询USCDB网元内配置的Partition信息。 |

## 使用实例

1. 查询所有应用类型的参数配置：

   ```
   LST PARTITIONPARA:;
   ```

   ```
   %%LST PARTITIONPARA:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    业务类型  校验速率  校验消息超时定时器时长(毫秒)  复制响应超时定时器时长(毫秒)  局间反向生成全局路由数据开关  本地数据修改开关  全局路由校验开关  全局数据迁移开关

    SUP-FE    5         5000                          5000                          打开                          关闭              打开              关闭
    USCDB     5         5000                          5000                          打开                          关闭              打开              关闭
   (结果个数 = 2)

   ---    END
   ```
2. 查询“业务类型”为“SUP-FE”的Partition信息的参数配置：

   ```
   LST PARTITIONPARA: SERVICETYPE="SUP-FE";
   ```

   ```
   %%LST PARTITIONPARA: SERVICETYPE="SUP-FE";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
                       业务类型  =  SUP-FE
                       校验速率  =  5
   校验消息超时定时器时长(毫秒)  =  5000
   复制响应超时定时器时长(毫秒)  =  5000
   局间反向生成全局路由数据开关  =  打开
               本地数据修改开关  =  关闭
               全局路由校验开关  =  打开
               全局数据迁移开关  =  关闭        
   (结果个数 = 1)

   ---    END
   ```
