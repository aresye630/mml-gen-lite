# 增加订阅组(ADD SUBSCRIBERGRP)

- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于添加订阅者到订阅组中。

该命令的参数索引关系如图1所示。

**图1** 命令参数的索引关系图

## 注意事项

- 添加到订阅组中的订阅者必须已经通过**ADD SUBSCRIBER**命令配置。
- 同一订阅组下的订阅者的发送模式必须一致。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                              |
|:-----------|:-------|:--------------------------------------------------------------------------------------------------|
| SUBERGRPID | 订阅组ID  | 用于标识一个订阅组。 取值范围：1～255。 默认值：无                                                                      |
| SUBERID    | 订阅者ID  | 用于标识一个订阅者。 取值范围：1～255。 默认值：无                                                                      |
| SM         | 发送模式   | 订阅者的发送模式。 取值范围： BROADCAST（广播）UNICAST（单播）CYCLIC（轮选） 默认值：BROADCAST（广播）                              |
| PRI        | 优先级    | 订阅者的优先级。当参数“SM”取值为“UNICAST”时，必须指定参数“PRI”的取值。“PRI”值越小，优先级越高。发送订阅通知时选择优先级高的订阅者发送。 取值范围：1～255。 默认值：无 |
| GRPDESC    | 订阅组描述  | 订阅组的描述信息。 取值范围：长度不超过32的字符串。 默认值：无                                                                 |

## 使用实例

1. 添加订阅者到订阅组，“订阅组ID”为“1”，“订阅者ID”为“1”，订阅者的“发送模式”为“广播”。

   ```
   ADD SUBSCRIBERGRP: SUBERGRPID=1, SUBERID=1, SM=BROADCAST;
   ```
2. 添加订阅者到订阅组，“订阅组ID”为“1”，“订阅者ID”为“2”，订阅者的“发送模式”为“单播”，“优先级”为“1”。

   ```
   ADD SUBSCRIBERGRP: SUBERGRPID=1, SUBERID=2, SM=UNICAST, PRI=1;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释         | 原因分析                                         | 处理建议                                                                                      |
|-------:|:--------------|:---------------------------------------------|:------------------------------------------------------------------------------------------|
| 274634 | 订阅者ID已经存在。    | 一个订阅组中，一个“订阅者ID”只能被添加一次。                     | 请不要重复的将同一个订阅者添加到同一个订阅组中，可执行LST SUBSCRIBERGRP命令查询订阅者中已存在的订阅者。                              |
| 274636 | 订阅者ID不存在。     | 要加到某个订阅组中的“订阅者ID”必须是已经通过ADD SUBSCRIBER命令添加的。 | 请执行ADD SUBSCRIBER命令添加订阅者，然后通过本命令将该订阅者添加到订阅组中。                                             |
| 274637 | 订阅者发送模式配置不一致。 | 一个订阅组只能有一种“发送模式”，默认为“广播”。                    | 请将“发送模式”一样的订阅者添加到同一个订阅组中，不同发送模式的订阅者添加到不同的订阅组中，可执行LST SUBSCRIBERGRP命令查看“订阅组”中“订阅者”的“发送模式”。 |
| 274738 | 该优先级已经存在。     | 如果一个订阅组的“发送模式”为“单播”，则该订阅组中订阅者的“优先级”不能重复。     | 请为一个“发送模式”为“单播”的订阅组添加不同“优先级”的订阅者，可执行LST SUBSCRIBERGRP命令产看订阅组中各订阅者的“优先级”。                  |
