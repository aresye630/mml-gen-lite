# 查询业务发放统计规则(LST PROVSTATRULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询业务发放统计对象的匹配规则：

- 若需要查询全部业务发放统计规则的概要信息，请不要输入任何参数。
- 若需要查询某个业务发放统计规则的详细信息，请输入“业务发放统计对象名称”参数。
- 若需要查询某个命令相关的所有业务发放统计规则的详细信息，请输入“命令名”参数。
- 若需要查询某个业务发放统计对象下某个命令对应的规则的详细信息，请同时输入“业务发放统计对象名称”和“命令名”参数。

## 注意事项

无。

## 参数说明

| 参数标识            | 参数名称       | 参数说明                                                  |
|:----------------|:-----------|:------------------------------------------------------|
| PROVSTATOBJNAME | 业务发放统计对象名称 | 用于指示系统需要按照哪个业务发放统计对象的名称来查询规则信息；若不输入，则表示所有的业务发放统计对象名称。 |
| CMDNAME         | 命令名称       | 用于指示系统需要按照哪个命令名来查询规则信息；若不输入，则表示所有的命令名。                |

## 使用实例

1. 查询所有业务发放统计规则：

   ```
   LST PROVSTATRULE:;
   ```

    HSS9860 Commands Statistic  LGI     NULL                  NULL                    NULL                  NULL                    NULL                  NULL                  
    UPCC Commands Statistic     LGI     HLRSN                 1                       NULL                  NULL                    NULL                  NULL

   ---    END
   ```
2. 查询业务发放统计规则，其中“业务发放统计对象名称”为“HSS9860 Commands Statistic”：

   ```
   LST PROVSTATRULE: PROVSTATOBJNAME="HSS9860 Commands Statistic";
   ```

   ```

   RETCODE = 0  操作成功

## 输出结果说明
