# 删除流量策略(RMV TRAFFICPOLICY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，对于被删除流量策略的LDAP用户或FE类型，会导致系统不能再通过流量策略来控制其访问系统的消息量。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除一条流量策略。

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                               |
|:-----------|:-------|:-----------------------------------------------------------------------------------|
| ACCESSTYPE | 接入类型   | 标识一条流量策略数据记录的关键字段之一，用于指定需要删除哪一种接入类型对应的流量策略数据记录，操作员可以使用LST TRAFFICPOLICY命令查询获得。     |
| LDAPUSER   | LDAP用户 | 标识一条流量策略数据记录的关键字段之一，用于指定需要删除哪一个LDAP用户名称对应的流量策略数据记录，操作员可以使用LST TRAFFICPOLICY命令查询获得。 |
| FETYPENAME | FE类型名称 | 标识一条流量策略数据记录的关键字段之一，用于指定需要删除哪一个FE类型名称对应的流量策略数据记录，操作员可以使用LST TRAFFICPOLICY命令查询获得。   |

## 使用实例

1. 删除一条LDAP用户流量策略，“接入类型”为“LDAP”,“LDAP用户”为“ldap\_u1”。

   ```
   RMV TRAFFICPOLICY: ACCESSTYPE=LDAP, LDAPUSER="ldap_u1";
   ```
2. 删除一条FE类型流量策略，“接入类型”为“DCI”,“FE类型名称”为“SUP-FE”。

   ```
   RMV TRAFFICPOLICY: ACCESSTYPE=DCI, FETYPENAME="SUP-FE";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释      | 原因分析         | 处理建议                                       |
|-------:|:-----------|:-------------|:-------------------------------------------|
| 257123 | 要删除的对象不存在。 | 未添加要删除的流量策略。 | 执行LST TRAFFICPOLICY命令查询此对象是否存在。若不存在，则无需处理。 |
