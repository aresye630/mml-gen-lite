# 显示日志跟踪信息(DSP LOGTRACE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于请求系统显示指定模块的用户跟踪信息。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                   |
|:--------|:-------|:---------------------------------------------------------------------------------------|
| AT      | 业务类型   | 用于请求系统显示的用户的业务类型，此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。                               |
| MID     | 模块号    | 用于请求系统显示的用户所在的模块号。 说明：当输入“模块号”时，表示查询显示该模块中的跟踪任务详情。当不输入“模块号”时，表示查询显示应用类型最小的DSG模块中的跟踪任务。 |
| TRCTYPE | 跟踪类型   | 用于请求系统显示表示获取单用户日志跟踪类型。                                                                 |

## 使用实例

查询“业务类型”为“SUP-FE”的52号模块日志跟踪信息，执行命令如下：

```
DSP LOGTRACE: AT="SUP-FE", MID=52, TRCTYPE=DCICONTENT;
```

```

RETCODE = 0  Operation succeeded
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义优先请参见

**SET LOGTRACE**

命令的参数说明，其余请参见表1的参数说明。

| 输出项名称   | 输出项解释            |
|:--------|:-----------------|
| 跟踪开始时间  | 用于表示启动跟踪任务的起始时间。 |
| 跟踪时长    | 用于表示启动跟踪任务的跟踪时长。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释                     | 原因分析                        | 处理建议                                                                     |
|------:|:--------------------------|:----------------------------|:-------------------------------------------------------------------------|
|  1890 | 指定的业务类型不存在或者未加载。          | 输入的“业务类型”在系统中未配置。           | 执行LST FEPLUG命令查询已经配置的FE类型，然后再执行本命令查询已配置的FE的日志跟踪信息。                       |
|  1909 | 模块号不存在。                   | 输入的“模块号”在系统中未配置。            | 执行LST MODULE命令查询已经配置的模块号，然后再执行本命令查询已配置的FE模块的日志跟踪信息。                      |
|  2084 | 参数模块号指定的模块状态异常。           | 输入的模块状态异常。                  | 请参见产品手册的“模块故障”进行处理。                                                      |
|  2181 | 参数模块号指定的模块不是DRU，DSU或者DSG。 | 本命令只能查询DRU、DSU或者DSG模块的日志信息。 | 执行LST MODULE命令查询已配置的模块号，然后再执行本命令时，输入已配置的对应DRU、DSU或者DSG的模块号。              |
|  2219 | 模块号参数指定的模块类型与业务类型不匹配。     | 模块号参数指定的模块类型与业务类型不是对应关系。    | 执行LST MODULE命令查询已配置的模块号与应用类型的对应关系，然后再执行本命令，输入有对应关系的“应用类型”参数和“模块号”参数进行查询。 |
