# 查询物理库配置(LST DBCONFIG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于查询物理数据库的配置信息：

- 若需要查询全部物理数据库配置的概要信息，请不要输入任何参数。
- 若需要查询某条物理数据库配置的详细信息，请输入“IP类型”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称       | 参数说明                                                                                    |
|:--------|:-----------|:----------------------------------------------------------------------------------------|
| IPVER   | IP类型       | 用于指定系统需要按照哪个IP类型来查询物理数据库的配置数据；若不输入，则表示所有的IP类型。                                          |
| IPV4IP1 | 物理库IPV4地址1 | 仅当本命令中的“IP类型”参数为“IPV4”时该参数有效，用于指定系统需要按照哪个物理库IPV4地址1来查询物理数据库的配置数据；若不输入，则表示所有的物理库IPV4地址1。 |
| IPV6IP1 | 物理库IPV6地址1 | 仅当本命令中的“IP类型”参数为“IPV6”时该参数有效，用于指定系统需要按照哪个物理库IPV6地址1来查询物理数据库的配置数据；若不输入，则表示所有的物理库IPV6地址1。 |
| PORT1   | 物理库端口1     | 用于指定系统需要按照哪个物理库端口1来查询物理数据库的配置数据；若不输入，则表示所有的物理库端口1。                                      |
| IPV4IP2 | 物理库IPV4地址2 | 仅当本命令中的“IP类型”参数为“IPV4”时该参数有效，用于指定系统需要按照哪个物理库IPV4地址2来查询物理数据库的配置数据；若不输入，则表示所有的物理库IPV4地址2。 |
| IPV6IP2 | 物理库IPV6地址2 | 仅当本命令中的“IP类型”参数为“IPV6”时该参数有效，用于指定系统需要按照哪个物理库IPV6地址2来查询物理数据库的配置数据；若不输入，则表示所有的物理库IPV6地址2。 |
| PORT2   | 物理库端口2     | 用于指定系统需要按照哪个物理库端口2来查询物理数据库的配置数据；若不输入，则表示所有的物理库端口2。                                      |

## 使用实例

数据库类型是“ClickHouse”时，查询全部物理数据库配置：

```
LST DBCONFIG:;
```

```
%%LST DBCONFIG:;%%
RETCODE = 0  操作成功

操作结果如下
------------
         IP类型  =  IPV4
物理库IPV4地址1  =  172.18.128.130
物理库IPV6地址1  =  NULL
    物理库端口1  =  9201
物理库IPV4地址2  =  172.19.128.130
物理库IPV6地址2  =  NULL
    物理库端口2  =  9201
(结果个数 = 1)

---    END
```
