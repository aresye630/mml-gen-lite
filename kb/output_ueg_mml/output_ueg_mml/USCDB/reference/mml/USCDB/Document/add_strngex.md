# 增加用户数据统计对象(ADD STRNGEX)

- 命令功能

## 命令功能

**须知** 

该命令属于高危命令，该操作将增加统计对象，操作不当将造成系统过载、业务流控等严重问题。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于增加一个用户数据统计对象。设备中存储的特定号段的用户数、特定主机名后缀的用户数等指标可以认为是用户数据统计对象。当客户需要进一步了解设备中存储用户的统计数据情况时，使用该命令添加一条新的用户数据统计对象。

用户数据统计是一个定时话务统计任务，在话务统计台显示统计结果，观察业务变化趋势。

该命令的使用场景：在开局或者维护场景下，根据客户需求，在产品经过严格验证后，为满足客户对某些特殊指标的统计，而添加统计对象。

## 注意事项

- 统计功能消耗较多系统资源，请合理增加用户数据统计对象的数量。
- 统计类型按HLRSN统计的对象不能超过29个。
- 统计类型按RN统计的对象数不能超过30个。
- 按号段统计、按源RN和目的RN统计两类统计对象之和不能超过9个，当等于9时，不允许再添加以下类型的统计对象：对所有用户进行统计。
- 统计类型按MME主机名后缀统计的对象不能超过800个。
- 统计类型按MME主机名后缀统计时，如果MMETYPE参数被赋值，那么DESCRIPTION不能为空。
- 统计类型按VLRNUM前缀统计的对象不能超过800个。
- 统计类型按NPRN统计的对象个数不能超过800个。
- 在加载业务网元插件包时，系统自动增加一个对象ID为OBJECT0的统计对象，针对所有用户进行统计，对象OBJECT0只允许查询，不允许添加、删除和修改。
- 以下九种类型的统计对象允许进行查询、添加、删除和修改操作：对所有用户进行统计、按HLRSN统计、按号段统计、按RN统计、按源RN和目的RN统计、按MME主机名后缀统计、按VLRNUM前缀统计、按APN名称统计、按NPRN统计。
- 主备容灾场景下，主用局执行该命令增加一个用户数据统计对象时，备用局需要同步增加。
- 该命令不允许进行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。

## 使用实例

1. 增加用户数据统计对象，“网元类型”为“SUP-FE”，“统计对象ID”为“OBJECT1”，“统计类型”为“按HLRSN统计”，“MVNO/HLRSN”为“1”，“DESCRIPTION”为“plmnxxx”。

   ```
   ADD STRNGEX: NETTYP="SUP-FE", OBJECTID=OBJECT1, TYPE=STAT_SN, HLRSN=1, DESCRIPTION="plmnxxx";
   ```
2. 增加用户数据统计对象，“网元类型”为“SUP-FE”，“统计对象ID”为“OBJECT2”，“统计类型”为“按号段统计”，“统计起始号码”为“13500000000”，“统计结束号码”为“13599999999”，“DESCRIPTION”为“plmnxxx”。

   ```
   ADD STRNGEX: NETTYP="SUP-FE", OBJECTID=OBJECT2, TYPE=STAT_NUMBER, BEGINNUM="13500000000", ENDNUM="13599999999", DESCRIPTION="plmnxxx";
   ```
3. 增加用户数据统计对象，“网元类型”为“SUP-FE”，“统计对象ID”为“OBJECT3”，“统计类型”为“按RN统计”，“RN”为“12345ABCDE”，“DESCRIPTION”为“plmnxxx”。

   ```
   ADD STRNGEX: NETTYP="SUP-FE", OBJECTID=OBJECT3, TYPE=STAT_RN, RN="12345ABCDE", DESCRIPTION="plmnxxx";
   ```
4. 增加用户数据统计对象，“网元类型”为“SUP-FE”，“统计对象ID”为“OBJECT4”，“统计类型”为“按源RN和目的RN统计”，“源RN”为“13555ABCDE”，“目的RN”为“13666ABCDE”，“DESCRIPTION”为“plmnxxx”。

   ```
   ADD STRNGEX: NETTYP="SUP-FE", OBJECTID=OBJECT4, TYPE=STAT_MULTIRN, SRCRN="13555ABCDE", DESRN="13666ABCDE", DESCRIPTION="plmnxxx";
   ```
5. 增加用户数据统计对象，“网元类型”为“SUP-FE”，“统计对象ID”为“OBJECT5”，“统计类型”为“按MME主机名后缀统计”，“MME主机名后缀”为“460-00-65534-254”，“MMETYPE”为“PLMN”，“DESCRIPTION”为“plmnxxx”。

   ```
   ADD STRNGEX: NETTYP="SUP-FE", OBJECTID=OBJECT5, TYPE=STAT_MMEHOSTPOSTFIX, MMEHOST="460-00-65534-254", MMETYPE=PLMN, DESCRIPTION="plmnxxx";
   ```
6. 增加用户数据统计对象，“网元类型”为“SUP-FE”，“统计对象ID”为“OBJECT6”，“统计类型”为“按VLRNUM前缀统计”，“VLRNUM前缀”为“137”，“DESCRIPTION”为“plmnxxx”。

   ```
   ADD STRNGEX: NETTYP="SUP-FE", OBJECTID=OBJECT6, TYPE=STAT_VLRNUMPREFIX, VLRNUM="137", DESCRIPTION="plmnxxx";
   ```
7. 增加用户数据统计对象，“网元类型”为“SUP-FE”，“统计对象ID”为“OBJECT7”，“统计类型”为“按APN名称统计”，“APN”为“cmnet.000.460.gprs”，“DESCRIPTION”为“plmnxxx”。

   ```
   ADD STRNGEX: NETTYP="SUP-FE", OBJECTID=OBJECT7, TYPE=STAT_APN, APN="cmnet.000.460.gprs", DESCRIPTION="plmnxxx";
   ```
8. 增加用户数据统计对象，“网元类型”为“SUP-FE”，“统计对象ID”为“OBJECT8”，“统计类型”为“按NPRN统计”，“NPRN”为“137”，“DESCRIPTION”为“plmnxxx”。

   ```
   ADD STRNGEX: NETTYP="SUP-FE", OBJECTID=OBJECT8, TYPE=STAT_NPRN, NPRN=137, DESCRIPTION="plmnxxx";
   ```
