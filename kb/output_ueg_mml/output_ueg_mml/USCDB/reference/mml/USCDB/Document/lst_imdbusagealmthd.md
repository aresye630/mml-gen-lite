# 查询内存数据库使用率告警阈值配置(LST IMDBUSAGEALMTHD)

## 命令功能

该命令用于查询内存数据库使用率告警阈值配置信息：

- 若要查询全部内存数据库使用率告警阈值配置信息，请不要输入任何参数。
- 若要查询某个或某些内存数据库使用率告警阈值配置信息，请输入“FE类型”或“Cluster类型”，或者“FE类型”和“Cluster类型”的组合。

## 注意事项

执行本命令前，若没有通过**SET IMDBUSAGEALMTHD**命令设置内存数据库使用率告警阈值配置信息，则本命令的查询结果为空。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                               |
|:------------|:----------|:-------------------------------------------------------------------------------------------------------------------|
| FETYPE      | FE类型      | 可选必选说明：可选参数 参数含义：用于指示系统按照FE类型来查询内存数据库使用率告警阈值的配置信息；若不输入，则表示所有的FE类型。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。               |
| CLUSTERTYPE | Cluster类型 | 可选必选说明：可选参数 参数含义：用于指示系统按照Cluster类型来查询内存数据库使用率告警阈值的配置信息；若不输入，则表示所有的Cluster类型。 取值范围： DRU(DRU)DSU(DSU) 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询内存数据库使用率告警阈值配置信息，“FE类型”为“SUP-FE”，“Cluster类型”为“DRU”。

   ```
   LST IMDBUSAGEALMTHD: FETYPE="SUP-FE", CLUSTERTYPE=DRU;
   ```

   ```
   %%LST IMDBUSAGEALMTHD: FETYPE="SUP-FE", CLUSTERTYPE=DRU;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------------------
                                 FE类型  =  SUP-FE
                            Cluster类型  =  DRU
         节点内存使用率过高告警上报阈值  =  85
         节点内存使用率过高告警恢复阈值  =  80
               节点内存不足告警上报阈值  =  95
               节点内存不足告警恢复阈值  =  93
   (结果个数 = 1)

   ---    END
   ```
2. 查询全部内存数据库使用率告警阈值配置信息。

   ```
   LST IMDBUSAGEALMTHD:;
   ```

   ```
   %%LST IMDBUSAGEALMTHD:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------------------
    FE类型   Cluster类型   节点内存使用率过高告警上报阈值   节点内存使用率过高告警恢复阈值   节点内存不足告警上报阈值   节点内存不足告警恢复阈值

    GU-HLR   DRU           85                               80                               95                         93                                                
    GU-HLR   DSU           85                               80                               95                         93                                                
    SUP-FE   DRU           85                               80                               95                         93                                                
    SUP-FE   DSU           85                               80                               95                         93                                                
   (结果个数 = 4)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数请参见**SET IMDBUSAGEALMTHD**命令的参数说明。
