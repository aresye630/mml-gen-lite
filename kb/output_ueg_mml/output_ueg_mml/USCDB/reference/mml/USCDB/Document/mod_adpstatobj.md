# 修改适配测量对象(MOD ADPSTATOBJ)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改适配测量对象，包括适配测量对象名称，业务类型等。

## 注意事项

无。

## 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                              |
|:---------------|:---------|:----------------------------------------------------------------------------------|
| ADPSTATOBJID   | 适配测量对象ID | 用于标识一条适配测量对象记录。此参数在USCDB网元下唯一。 取值范围：1～512                                         |
| ADPSTATOBJNAME | 适配测量对象名称 | 用于标识一条适配测量对象的名称。此参数在USCDB网元下唯一。 取值范围：长度不超过127的字符串。                                |
| SERVICETYPE    | 业务类型     | 用于指定适配测量对象针对哪种业务类型的操作进行统计，该参数必须先通过LOD FEPLUG命令加载FE插件，然后才能在此引用。 取值范围：长度不超过127的字符串。 |

## 使用实例

修改一条适配测量对象记录，指定“适配测量对象ID”为“3”，修改“适配测量对象名称”为“THIRD”,“业务类型”为“SUP-FE”。

```
MOD ADPSTATOBJ: ADPSTATOBJID=3, ADPSTATOBJNAME="THIRD", SERVICETYPE="SUP-FE";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                    | 原因分析                                     | 处理建议                                                                                        |
|-------:|:-------------------------|:-----------------------------------------|:--------------------------------------------------------------------------------------------|
| 260008 | 参数未修改。请至少指定一个待修改的参数。     | 指定修改的适配测量对象的“适配测量对象名称”和“业务类型”与数据库中保存的一致。 | 执行LST ADPSTATOBJ命令查询指定的适配测量对象，再重新执行MOD ADPSTATOBJ命令，输入“适配测量对象名称”和“业务类型”，确保其与原来的不同。          |
| 275016 | 指定的记录不存在。                | 数据库中不存在指定的适配测量对象记录。                      | 执行LST ADPSTATOBJ命令查适配测量对象，再重新执行MOD ADPSTATOBJ命令，输入“适配测量对象ID”，确保其存在。                         |
| 275308 | 参数SERVICETYPE指定的业务类型未配置。 | 网元未加载参数“业务类型”指定的FE插件包。                   | 执行LST FEPLUG命令查询触已加载的FE插件包，再重新执行MOD ADPSTATOBJ命令，输入“业务类型”，确保其存在于查询记录中。                      |
| 335427 | 适配测量对象名称已经存在。            | “适配测量对象名称”已经存在。                          | 执行LST ADPSTATOBJ命令查询已经添加的适配测量对象，然后重新执行MOD ADPSTATOBJ命令，输入“适配测量对象名称”，确保与查询结果中的“适配测量对象名称”不重复。 |
