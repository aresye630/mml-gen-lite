# 查询IP限制开关(LST GRANTIPSWITCH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询各类端口类型的IP限制子开关信息。

- 若需要查询全部IP限制开关的概要信息，请不要输入任何参数。
- 若需要查询某条IP限制开关的详细信息，请输入“端口类型”或“IP限制开关”或这两个参数的组合。

## 注意事项

执行该命令查询后：

- 报文显示的端口类型记录，对应的IP限制开关取值与显示值一致。
- 报文不显示的端口类型记录，其IP限制开关的取值在实际处理流程中按照打开处理。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                          |
|:---------|:-------|:----------------------------------------------|
| PORTTYPE | 端口类型   | 用于指示系统需要按照哪个端口类型查询IP限制开关信息记录；若不输入，则表示所有的端口类型。 |
| SWITCH   | 开关     | 用于指示系统需要按照哪个开关状态查询IP限制开关信息记录；若不输入，则表示所有的开关状态。 |

## 使用实例

1. 查询IP限制开关配置信息：

   ```
   LST GRANTIPSWITCH:;
   ```

   ```
   %%LST GRANTIPSWITCH:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   端口类型  开关  

    SOAP      打开  
   (结果个数 = 1)

   ---    END
   ```
2. 查询IP限制开关配置信息，“端口类型”为“SOAP(SOAP)”，“开关”为“打开（ON）”：

   ```
   LST GRANTIPSWITCH: PORTTYPE=SOAP, SWITCH=ON:;
   ```

   ```
   %%LST GRANTIPSWITCH: PORTTYPE=SOAP, SWITCH=ON;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   端口类型  =  SOAP
       开关  =  打开
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET GRANTIPSWITCH**命令的参数说明。
