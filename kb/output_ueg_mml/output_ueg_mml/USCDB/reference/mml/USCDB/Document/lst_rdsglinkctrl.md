# 查询远端DSG链路中心(LST RDSGLINKCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询远端DSG或DBS链路中心的配置信息：

- 若需要查询所有远端DSG或DBS链路中心的配置信息，请不要输入任何参数。
- 若需要查询某个“远端Location标识”的远端DSG或DBS链路中心配置信息，请输入对应的“远端Location标识”。
- 若需要查询某个“远端DSG业务类型”的远端DSG或DBS链路中心配置信息，请输入对应的“远端DSG业务类型”。
- 若需要查询某个“远端链路中心类型”的远端DSG或DBS链路中心配置信息，请输入对应的“远端链路中心类型”。

## 注意事项

无。

## 参数说明

| 参数标识            | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                        |
|:----------------|:-------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RLOCID          | 远端Location标识 | 用于指定一个远端网元标识。该参数须在对接的远端USCDB网元或者FE网元中先定义，然后在本端网元通过ADD RLOCATION命令配置后，才能在此处索引。远端Location是相对的，具体如下：对于主用局FE，它的远端Location指主用局USCDB或容灾局USCDB。对于主用局USCDB，它的远端Location指主用局FE、容灾局FE或容灾局USCDB。对于容灾局FE，它的远端Location指容灾局USCDB或主用局USCDB。对于容灾局USCDB，它的远端Location指容灾局FE、主用局FE或主用局USCDB。 取值范围：1～512 默认值：无。 |
| RDSGST          | 远端DSG业务类型    | 用于指定维护链路的远端网元类型名称。该参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。 取值范围：长度不超过128的字符串。 默认值：无。                                                                                                                                                                                                         |
| RLINKCENTERTYPE | 远端链路中心类型     | 用于指定远端FE Location链路中心类型。 取值范围： DSG：表示大颗粒DSG链路中心。DBS：表示dbbroker微服务链路中心。 默认值：DSG                                                                                                                                                                                                              |

## 使用实例

1. 查询所有远端DSG链路中心配置：

   ```
   LST RDSGLINKCTRL:;
   ```

   ```
   %%LST RDSGLINKCTRL:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    远端Location标识  远端链路中心类型  IP类型  远端Location IPV4地址  远端Location IPV6地址  远端DSG业务类型

    76                DSG               IPV4    172.21.128.36          NULL                   SUP-FE
    66                DSG               IPV4    172.21.128.35          NULL                   SUP-FE                
   (结果个数 = 2)

   ---    END
   ```
2. 查询指定“远端DSG业务类型”的远端DSG链路中心，“远端DSG业务类型”为“SUP-FE”：

   ```
   LST RDSGLINKCTRL: RDSGST="SUP-FE";
   ```

   ```
   %%LST RDSGLINKCTRL: RDSGST="SUP-FE";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
        远端Location标识  =  66
        远端链路中心类型  =  DSG
                  IP类型  =  IPV4
   远端Location IPV4地址  =  172.21.128.35
   远端Location IPV6地址  =  NULL
         远端DSG业务类型  =  SUP-FE
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD RDSGLINKCTRL**命令的参数说明。
