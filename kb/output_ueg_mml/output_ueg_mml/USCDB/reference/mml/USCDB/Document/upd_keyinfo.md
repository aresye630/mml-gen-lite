# 更新密钥信息(UPD KEYINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于触发更新USCDB密钥信息。

该命令的使用场景：长期使用同一密钥，可能存在安全风险，为了提高系统安全性，建议运营商根据安全需要定期更新密钥信息，但不建议频繁更新。管理员权限（G\_1，管理员级别命令组）的用户可以手动更新包括“密钥加密密钥”和“工作密钥”的密钥信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                              |
|:-------|:-------|:------------------------------------------------------------------|
| KTYPE  | 密钥类型   | 可选必选说明：必选参数。 参数含义：用于指定需要更新的密钥类型。 KEK(密钥加密密钥)WK(工作密钥) 默认值：无 配置原则：无 |

## 使用实例

更新密钥类型为“KEK”的密钥配置信息。

```
UPD KEYINFO: KTYPE=KEK;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。
