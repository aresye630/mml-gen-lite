# 查询适配包(LST ADPPKG)

- 注意事项

- 输出结果说明

## 命令功能

该命令用于查询已加载的适配包信息：

- 若需要查询全部适配包信息，请不要输入任何参数。
- 若需要查询某个适配包的详细信息，请输入“适配包名称”、“适配包类型名称”、“适配包类型”、“服务类型”、“适配包主机加载状态”参数或者这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识             | 参数名称      | 参数说明                                                                                              |
|:-----------------|:----------|:--------------------------------------------------------------------------------------------------|
| ADPPKGNAME       | 适配包名称     | 用于指示系统按照哪个适配包名称查询适配包信息；若不输入则表示查询所有的适配包信息。                                                         |
| ADAPTERTYPENAME  | 适配包类型名称   | 用于指示系统按照哪个适配包类型名称查询适配包信息；若不输入则表示查询所有适配包类型名称的适配包信息。                                                |
| PKGTYPE          | 适配包加载类型   | 用于指示系统按照哪个适配包类型查询适配包信息；若不输入则表示查询所有加载类型的适配包信息。 取值范围： EXPORT(EXPORT)IMPORT(IMPORT)MIGRATE(MIGRATE)  |
| SERVICETYPE      | 服务类型      | 用于指示系统按照哪个服务类型查询适配包信息；若不输入则表示查询所有服务的适配包信息。该参数在通过LOD FEPLUG命令加载FE插件后才能在此引用。                        |
| ADPPKGLOADSTATUS | 适配包主机加载状态 | 用于指示系统按照哪种适配包主机加载状态查询适配包信息；若不输入则表示查询所有加载状态的适配包信息。 取值范围： LOAD_NOT_SUCCESS(加载未成功)LOAD_SUCCESS(加载成功) |

## 使用实例

1. 查询所有的适配包，执行如下命令：

   ```
   LST ADPPKG:;
   ```

   ```
   %%LST ADPPKG:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ----------
    适配包名称           适配包类型名称    加载时间              适配包加载类型    服务类型     适配包主机加载状态
    SUP-FE_ADPPKG.tar    SUP-FE            2017-03-06 11:24:35   EXPORT            SUP-FE       LOAD_SUCCESS
    Test_ADPPKG.tar      SUP-FE            2017-03-06 13:29:55   IMPORT            SUP-FE       LOAD_SUCCESS
   (结果个数 = 2)

   ---    END
   ```
2. 查询“适配包类型”为“EXPORT”的适配包，执行如下命令：

   ```
   LST ADPPKG: PKGTYPE=EXPORT;
   ```

   ```
   %%LST ADPPKG: PKGTYPE=EXPORT;%%
   RETCODE = 0  操作成功

   操作结果如下
   ----------
           适配包名称  =  SUP-FE_ADPPKG.tar
       适配包类型名称  =  SUP-FE
             加载时间  =  2017-03-06 11:24:35
       适配包加载类型  =  EXPORT 
             服务类型  =  SUP-FE
   适配包主机加载状态  =  LOAD_SUCCESS
    (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1。

| 输出项名称     | 输出结果解释            |
|:----------|:------------------|
| 适配包名称     | 用于标识一个已加载的适配包名称。  |
| 适配包类型名称   | 用于标识加载的适配包类型的名称。  |
| 加载时间      | 用于标识适配包开始加载的时间。   |
| 适配包加载类型   | 用于标识加载的适配包类型。     |
| 服务类型      | 用于标识加载适配包的FE应用类型。 |
| 适配包主机加载状态 | 用于标识加载适配包的结果状态。   |
