# 查询流控参数(LST FLOWCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询USCDB的流控参数信息：

- 若需要查询USCDB的当前所有流控参数的概要信息，请不要输入任何参数。
- 若需要查询满足某一条件的USCDB的当前流控参数的详细信息，请输入“流控开关参数”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称                   | 参数说明                                                      |
|:----------|:-----------------------|:----------------------------------------------------------|
| FLWCTRFLG | 流控开关参数                 | 用于指示系统需要按照是否开启“流控开关参数”来查询流控参数，系统初始设置值为“MSGFC（仅消息阻塞流控）”。   |
| CPUFLWSTR | CPU起控门限                | 用于指示系统需要按照“CPU起控门限”的值来查询流控参数，系统初始设置值为“95”。                |
| CPUFLWEND | CPU解控门限                | 用于指示系统需要按照“CPU解控门限”的值来查询流控参数，系统初始设置值为“85”。                |
| DRUTSSTR  | DRU消息队列消息堆积时间起控门限(毫秒)  | 用于指示系统需要按照“DRU消息队列消息堆积时间起控门限（毫秒）”的值来查询流控参数，系统初始设置值为“500”。 |

| DSGTSSTR  | DSG消息队列消息堆积时间起控门限(毫秒)  | 用于指示系统需要按照“DSG消息队列消息堆积时间起控门限（毫秒）”的值来查询流控参数，系统初始设置值为“500”。 |
| DRUTSEND  | DRU消息队列消息堆积时间解控门限(毫秒)  | 用于指示系统需要按照“DRU消息队列消息堆积时间解控门限（毫秒）”的值来查询流控参数，系统初始设置值为“100”。 |

```
LST FLOWCTRL:;
```
