# 启动物理数据库（STR PHYDB）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于执行物理数据库的启动功能，当执行**DSP PHYDB**命令查询物理数据库状态为“Abnormal”时，可执行该命令启动物理数据库。

## 注意事项

无。

## 参数说明

无。

## 使用实例

某局点需要执行物理数据库启动操作时：

```
STR PHYDB:;
```

返回结果如下：

```
%%STR PHYDB:;%% 
RETCODE = 0  操作成功  
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释      | 原因分析              | 处理建议                                  |
|------:|:-----------|:------------------|:--------------------------------------|
|  1730 | 部分操作失败。    | 主用或备用NDF模块其中一个异常。 | 请联系华为技术支持。                            |
|  2742 | 启动物理数据库失败。 | 文件配置异常导致物理数据库异常。  | 使用RST PHYDB命令重启物理数据库，如果还有异常请联系华为技术支持。 |
