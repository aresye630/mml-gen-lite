# 查看节点状态(DSP NODE)

## 命令功能

该命令用于查询节点的运行状态，如节点状态、备份状态、CPU占用率等。

该命令的使用场景：

- 升级场景：升级会导致Master节点异常。为了避免升级导致的业务呼损，升级前建议先使用**DSP NODE**命令确认待升级Pod内的节点状态为Slave。
- 节点删除场景：删除Master节点将可能导致用户数据的丢失和业务的呼损，所以为了避免直接删除Master节点带来的影响，推荐在删除节点前使用该命令进行相关查询。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                       |
|:------------|:----------|:-------------------------------------------------------------------------------------------|
| CID         | Cluster标识 | 用于请求系统是按照哪个Cluster标识来显示节点状态。若输入该参数时，系统显示Cluster标识等于该参数值的节点状态。 若不输入该参数时，则表示该参数不作为系统显示的限制条件。 |
| NID         | 节点标识      | 用于请求系统是按照哪个节点标识来显示节点状态。若输入该参数时，系统显示节点标识等于该参数值的节点状态。 若不输入该参数时，则表示该参数不作为系统显示的限制条件。           |
| CT          | Cluster类型 | 用于请求系统是按照哪个Cluster类型来显示节点状态。若输入该参数时，系统显示Cluster类型等于该参数值的节点状态。 若不输入该参数时，则表示该参数不作为系统显示的限制条件。 |
| SERVICETYPE | 业务类型      | 用于请求系统是按照哪个业务类型来显示节点状态。若输入该参数时，系统显示业务类型等于该参数值的节点状态。 若不输入该参数时，则表示该参数不作为系统显示的限制条件。           |
