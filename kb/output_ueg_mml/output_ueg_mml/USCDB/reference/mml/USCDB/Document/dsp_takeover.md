# 显示接管状态信息(DSP TAKEOVER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在主用局BE故障时，查询容灾局BE的业务发放自动接管状态信息。

使用此命令查询业务发放自动接管状态，在主用局和容灾局上执行的结果一致。

## 注意事项

该命令查询出来的信息只有在“AAMODESWITCH（A-A组网开关）”参数取值为“0”时有效。“AAMODESWITCH（A-A组网开关）”参数的取值可以通过**LST INSP**命令查询。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                       |
|:------------|:-------|:-----------------------------------------------------------|
| SERVICETYPE | 业务类型   | 用于请求系统显示哪个业务类型的接管状态信息，此参数在USCDB下通过LOD FEPLUG命令加载FE插件后在此引用。 |

## 使用实例

查询业务类型为SUP-FE，容灾局自动接管状态信息。

```
DSP TAKEOVER: SERVICETYPE="SUP-FE";
```

```
%%DSP TAKEOVER: SERVICETYPE="SUP-FE";%%
RETCODE = 0  操作成功

操作结果如下
------------
业务类型  =  SUP-FE
    状态  =  接管状态
(结果个数 = 1)
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称   | 输出项解释                       |
|:--------|:----------------------------|
| 状态      | 用于显示当前容灾局自动接管的状态: 接管状态非接管状态 |
| 业务类型    | 用于标识查询接管状态的业务类型。            |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释                | 原因分析                          | 处理建议                                                                                                                         |
|------:|:---------------------|:------------------------------|:-----------------------------------------------------------------------------------------------------------------------------|
|  2059 | 指定的业务类型不存在。          | 输入的“业务类型”在系统中不存在。             | 通过LST FEPLUG命令查询加载的“FE类型名称”，“FE类型名称”即“业务类型”。 若“业务类型”加载成功，请在执行该命令时输入正确的业务类型名称。若“业务类型”加载不成功或者没有加载，通过LOD FEPLUG命令加载成功后，重新执行该命令。 |
|  2112 | 在指定的业务类型下没有可用的DSG模块。 | 没有配置DSG模块，或者已配置的DSG模块处于不可用状态。 | 在“CSP MML命令”界面执行DSP MODULE命令查看DSG模块的状态信息。若无DSG模块，通过ADD MODULE命令为对应的“业务类型”添加DSG模块，然后重新执行本命令。若DSG模块故障，请参见产品手册的“模块故障”进行处理。      |
