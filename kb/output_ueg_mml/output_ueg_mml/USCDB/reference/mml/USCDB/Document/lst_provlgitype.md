# 查询营帐设备登录类型(LST PROVLGITYPE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询营帐客户端登录类型。

- 若需要查询全部营帐客户端登录类型的概要信息，请不要输入任何参数。
- 若需要查询某条营帐客户端登录类型的详细信息，请输入“登录ID”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称        | 参数说明                                                                                |
|:-------|:------------|:------------------------------------------------------------------------------------|
| LGIID  | 登录ID        | 用于指示系统需要按照哪个登录ID来查询营帐客户端登录类型；若不输入，则表示所有的登录ID。                                       |
| IPVER  | IP类型        | 用于指示系统根据哪种IP地址类型来查询营帐客户端登录类型。                                                       |
| RIPV4  | 营帐客户端IPV4地址 | 仅当本命令中的“IP类型”参数选择为“IPV4”时该参数有效，用于指示系统根据哪个IPv4地址来查询营帐客户端登录类型；若不输入，则表示所有的营帐客户端IPv4地址。 |
| RIPV6  | 营帐客户端IPV6地址 | 仅当本命令中的“IP类型”参数选择为“IPV6”时该参数有效，用于指示系统根据哪个IPv6地址来查询营帐客户端登录类型；若不输入，则表示所有的营帐客户端IPv6地址。 |
| LPORT  | PGW本端端口     | 用于指示系统需要按照哪个PGW本端端口来查询营帐客户端登录类型；若不输入，则表示所有的PGW本端端口。                                 |
| TYPE   | 登录类型        | 用于指示系统需要按照哪个登录类型来查询营帐客户端登录类型；若不输入，则表示所有登录类型。                                        |

## 使用实例

1. 查询营帐客户端登录类型，“登录类型”为“TELNET”。

   ```
   LST PROVLGITYPE: TYPE=TELNET;
   ```

   ```
   %%LST PROVLGITYPE: TYPE=TELNET;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    登录ID  IP类型   营帐客户端IPV4地址   营帐客户端IPV6地址   PGW本端端口  登录类型  登录描述

    1       IPV4     192.168.2.120        NULL                 7776         TELNET    NULL    
    2       IPV4     192.168.2.121        NULL                 7776         TELNET    NULL    
    3       IPV4     192.168.2.122        NULL                 7776         TELNET    NULL    
    4       IPV4     192.168.2.123        NULL                 7776         TELNET    NULL    
   (结果个数 = 4)

   ---    END
   ```
2. 查询所有营帐客户端登录类型。

   ```
   LST PROVLGITYPE:;
   ```

   ```

   RETCODE = 0  操作成功

   操作结果如下

    1       IPV4     192.168.2.120        NULL                 7776         TELNET    NULL    
    2       IPV4     192.168.2.121        NULL                 7776         TELNET    NULL    
    3       IPV4     192.168.2.122        NULL                 7776         TELNET    NULL    
    4       IPV4     192.168.2.123        NULL                 7776         TELNET    NULL    
    5       IPV4     192.168.2.124        NULL                 7776         HW        NULL
   ```
