# 修改动网操作软参(MOD OPERATIONINSP)

- 注意事项

## 命令功能

**须知** 

该命令属于高危命令，该操作将修改软件业务参数，配置不当，将导致业务严重错误。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于扩缩容，割接等动网操作前，对动网操作软参配置进行备份与修改，待动网操作后根据备份内容恢复软参配置。

该命令可以修改的动网操作软参如下所示：

- FWDVFYSWT（正向校验开关）：备份软参当前配置后，修改软参值为“0”。
- REVVFYSWT（反向校验开关）：备份软参当前配置后，修改软参值为“0”。
- FWDRTVFYSWT（正向路由校验开关）：备份软参当前配置后，修改软参值为“0”。
- REVRTVFYSWT（反向路由校验开关）：备份软参当前配置后，修改软参值为“0”。
- REDUNDANCYSWITCH（容灾开关）：备份软参当前配置后，修改软参值为“1”。
- TIMEBACKUPFLAG（定时备份开关）：备份软参当前配置后，修改软参值为“0”。
- USERDATAMEASUREFLAG（定时用户数据统计开关）：备份软参当前配置后，修改软参值为“0”。
- INNERHEARTBEATTIMEOUT（局内心跳超时时长）：备份软参当前配置后，修改软参值为“20000”。
- UIVFYSWT（用户完整性校验开关）：备份软参当前配置后，修改软参值为“0”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                           |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| OPTYPE | 操作类型   | 可选必选说明：必选参数。 参数含义：区分当前操作为动网操作前的软参配置备份与修改还是动网操作后的软参配置恢复。 取值范围： PRE(操作前)：动网操作前备份软参配置，并根据动网要求修改软参配置。 AFTER(操作后)：动网操作后根据备份内容恢复软参配置。 默认值：无。 配置原则：无。 |

## 使用实例

1. 扩容操作前，对动网软参配置进行备份与修改。

   ```
   MOD OPERATIONINSP: OPTYPE=PRE;
   ```

   ```
   %%MOD OPERATIONINSP: OPTYPE=PRE;%%
   RETCODE = 0  操作成功

   ---    END
   ```
2. 扩容操作完成后，根据备份内容恢复动网软参配置。

   ```
   MOD OPERATIONINSP: OPTYPE=AFTER;
   ```

   ```
   %%MOD OPERATIONINSP: OPTYPE=AFTER;%%
   RETCODE = 0  操作成功

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                           | 原因分析                                | 处理建议                                                                                                                                      |
|-------:|:--------------------------------|:------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------|
| 260687 | 软参修改失败。                         | 动网操作软参中存在一个或多个软参修改失败。               | 重新执行MOD OPERATIONINSP命令，若仍反馈“软参修改失败”，联系华为技术支持处理。                                                                                          |
| 260688 | 已经执行软参备份和修改，需要先恢复软参后再执行软参备份和修改。 | 当前参数“操作类型”取值为“PRE”时，不允许再次设置为“PRE”。  | 若此时确认仍需再次设置“操作类型”取值为“PRE”：执行MOD OPERATIONINSP命令设置“操作类型”取值为“AFTER”后，再执行MOD OPERATIONINSP命令修改“操作类型”取值为“PRE”。若此时确认无需再次设置“操作类型”取值为“PRE”：操作结束。 |
| 260689 | 未执行过备份软参。                       | 当前参数“操作类型”不为“PRE”时，不允许直接设置为“AFTER”。 | 执行MOD OPERATIONINSP命令设置“操作类型”取值为“PRE”后，再执行MOD OPERATIONINSP命令修改“操作类型”取值为“AFTER”。                                                          |
