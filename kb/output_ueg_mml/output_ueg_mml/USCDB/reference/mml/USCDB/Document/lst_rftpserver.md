# 查询远端FTP服务器(LST RFTPSERVER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询远端FTP服务器配置信息：

- 若需要查询全部服务器类型的远端FTP服务器配置的概要信息，不要输入任何参数。
- 若需要查询某个服务器类型的远端FTP服务器配置信息，请输入“远端服务器类型”参数，或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称      | 参数说明                                                            |
|:-----------|:----------|:----------------------------------------------------------------|
| SERVERTYPE | 远端服务器类型   | 用于指示系统根据哪个服务器类型来查询远端FTP服务器配置信息。                                 |
| SERVERNAME | 远端服务器名称   | 用于指示系统根据哪个服务器名称来查询远端FTP服务器配置信息。                                 |
| IPVER      | IP类型      | 用于指示系统根据哪种IP地址类型来查询远端FTP服务器配置信息。                                |
| SERVERIPV4 | 服务端IPV4地址 | 仅当本命令中的“IP类型”参数选择为“IPV4”时该参数有效，用于指示系统根据哪个IPv4地址来查询远端FTP服务器配置信息。 |
| SERVERIPV6 | 服务端IPV6地址 | 仅当本命令中的“IP类型”参数选择为“IPV6”时该参数有效，用于指示系统根据哪个IPv6地址来查询远端FTP服务器配置信息。 |
| SERVERPORT | 服务端端口     | 用于指示系统根据哪个端口号来查询远端FTP服务器信息。                                     |
| USERNAME   | 用户名称      | 用于指示系统根据哪个用户名称来查询远端FTP服务器信息。                                    |

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD RFTPSERVER**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释       | 原因分析                          | 处理建议                                 |
|-------:|:------------|:------------------------------|:-------------------------------------|
| 332601 | 该IP地址无效。    | 输入的IP地址不符合IP地址的格式要求。          | 请重新输入，确保输入的IP地址符合IP地址的格式要求。          |
| 260069 | IP地址的类型不匹配。 | 输入的IP地址类型和“IP类型”参数设置的IP类型不一致。 | 请重新输入，确保输入的IP地址类型和“IP类型”参数设置的IP类型一致。 |
