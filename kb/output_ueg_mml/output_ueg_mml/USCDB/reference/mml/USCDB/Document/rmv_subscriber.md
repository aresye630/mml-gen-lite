# 删除订阅者(RMV SUBSCRIBER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，删除订阅者会造成对端设备接收不到订阅通知。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除订阅者的相关配置信息。

## 注意事项

- 当订阅者在订阅组中仍然被引用时，不允许删除该订阅者，操作员可使用**LST SUBSCRIBERGRP**命令查询订阅组是否仍在引用此订阅者。在正常情况下，删除一条订阅者数据的步骤为：**RMV SUBSCRIBERGRP**-->**RMV SUBSCRIBER**。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                        |
|:--------|:-------|:------------------------------------------------------------------------------------------------------------|
| SUBERID | 订阅者ID  | 可选必选说明：必选参数。 参数含义：标识一个订阅者数据记录的关键字段之一，用于指定需要删除哪一个订阅者，操作员可以使用LST SUBSCRIBER命令查询获得。 取值范围：1～255。 默认值：无。 配置原则：无。 |

## 使用实例

按照如下步骤删除一个订阅者：

1.删除订阅组，“订阅组ID”为“1”，“订阅者ID”为“1”的订阅组信息。命令如下：

```
RMV SUBSCRIBERGRP: SUBERGRPID=1, SUBERID=1;
```

2.删除订阅者，“订阅者ID”为“1”的订阅者信息。命令如下：

```
RMV SUBSCRIBER: SUBERID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释         | 原因分析            | 处理建议                                                                                       |
|-------:|:--------------|:----------------|:-------------------------------------------------------------------------------------------|
| 274635 | 订阅者ID被使用，不能删除 | “订阅者ID”被订阅组使用。  | 先执行LST SUBSCRIBERGRP命令查询所有订阅组使用的“订阅者ID”，再执行RMV SUBSCRIBERGRP命令删除该“订阅组ID”的“订阅者ID”，再重新执行本命令。 |
| 274636 | 订阅者ID不存在。     | 未添加要删除的“订阅者ID”。 | 先执行LST SUBSCRIBER命令查询已添加的“订阅者ID”，重新执行本命令，确保删除的“订阅者ID”与查询结果中的相同。                            |
