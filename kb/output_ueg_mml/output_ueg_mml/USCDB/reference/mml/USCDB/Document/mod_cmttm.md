# 修改自动确认时间(MOD CMTTM)

## 命令功能

本命令用于修改配置回退的自动确认时间。

后台系统提供的自动确认机制，指的是数据表在“试运行状态”下超过设定的自动“确认时间”，操作员还未下发确认命令时，系统将自动确认数据表的修改，数据表进入“常规运行模式”。系统缺省的自动“确认时间”为“24小时”，操作员可以通过该命令进行修改。当前系统的“确认时间”，可通过**LST CMTTM** 命令查询。

## 注意事项

自动确认时间是以操作系统时间为基础计算的。夏令时操作会修改操作系统时间，导致自动“确认时间”计算不准确。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                    |
|:-------|:---------|:--------------------------------------------------------|
| TM     | 确认时间（小时） | 用于设置配置回退的自动确认时间，其单位为“小时”。 取值范围：9～168 默认值：无。 系统初始设置值：24。 |

## 使用实例

修改自动确认时间：

```
MOD CMTTM: TM=168;
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。
