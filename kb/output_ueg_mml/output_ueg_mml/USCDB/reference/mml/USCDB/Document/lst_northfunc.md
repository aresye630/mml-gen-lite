# 查询北向关联配置(LST NORTHFUNC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询北向功能实体信息。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询北向功能实体信息:

LST NORTHFUNC:;

```
%%LST NORTHFUNC:;%%
RETCODE = 0  操作成功

操作结果如下
----------
北向功能实体  =  HSS9860
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称   | 输出项解释         |
|:--------|:--------------|
| 北向功能实体  | 用于返回北向功能实体信息。 |
