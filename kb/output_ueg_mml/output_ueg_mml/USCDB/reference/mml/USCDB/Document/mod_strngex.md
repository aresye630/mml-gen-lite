# 修改用户数据统计对象(MOD STRNGEX)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改或调整一个用户数据统计对象。在该命令中，系统通过以下关键参数的组合来唯一标识一条用户数据统计对象记录。

- “网元类型”
- “统计对象ID”

## 注意事项

- 在加载业务网元插件包时，系统自动增加一个对象ID为OBJECT0的统计对象，针对所有用户进行统计，对象OBJECT0只允许查询，不允许添加、删除和修改。
- 以下九种类型的统计对象允许进行查询、添加、删除和修改操作：对所有用户进行统计、按HLRSN统计、按号段统计、按RN统计、按源RN和目的RN统计、按MME主机名后缀统计、按VLRNUM前缀统计、按APN名称统计、按NPRN统计。
- 不允许修改统计类型。

## 使用实例

1. 修改用户数据统计对象，“网元类型”为“SUP-FE”，“对象ID”为“OBJECT1”，按HLRSN统计，“MVNO/HLRSN”为“2”，“DESCRIPTION”为“plmnxxx”。

   ```
   MOD STRNGEX: NETTYP="SUP-FE", OBJECTID=OBJECT1, TYPE=STAT_SN, HLRSN=2, DESCRIPTION="plmnxxx";
   ```
2. 修改用户数据统计对象，“网元类型”为“SUP-FE”，“统计对象ID”为“OBJECT2”，按号段统计，“统计起始号码”为“13500000000”，“统计结束号码”为“13899999999”，“DESCRIPTION”为“plmnxxx”。

   ```
   MOD STRNGEX: NETTYP="SUP-FE", OBJECTID=OBJECT2, TYPE=STAT_NUMBER, BEGINNUM="13500000000", ENDNUM="13899999999", DESCRIPTION="plmnxxx";
   ```
3. 修改用户数据统计对象，“网元类型”为“SUP-FE”，“统计对象ID”为“OBJECT3”，按RN统计，“RN值”为“11111ABCDE”，“DESCRIPTION”为“plmnxxx”。

   ```
   MOD STRNGEX: NETTYP="SUP-FE", OBJECTID=OBJECT3, TYPE=STAT_RN, RN="11111ABCDE", DESCRIPTION="plmnxxx";
   ```
4. 修改用户数据统计对象，“网元类型”为“SUP-FE”，“统计对象ID”为“OBJECT4”，按源RN和目的RN统计，“源RN值”为“13777ABCDE”，“目的RN值”为“13888ABCDE”，“DESCRIPTION”为“plmnxxx”。

   ```
   MOD STRNGEX: NETTYP="SUP-FE", OBJECTID=OBJECT4, TYPE=STAT_MULTIRN, SRCRN="13777ABCDE", DESRN="13888ABCDE", DESCRIPTION="plmnxxx";
   ```
5. 修改用户数据统计对象，“网元类型”为“SUP-FE”，“统计对象ID”为“OBJECT5”，按MME主机名后缀统计，“MME主机名后缀”为“460-00-65534-254”，“MMETYPE”为“PLMN”，“DESCRIPTION”为“plmnxxx”。

   ```
   MOD STRNGEX: NETTYP="SUP-FE", OBJECTID=OBJECT5, TYPE=STAT_MMEHOSTPOSTFIX, MMEHOST="460-00-65534-254", MMETYPE=PLMN, DESCRIPTION="plmnxxx";
   ```
6. 修改用户数据统计对象，“网元类型”为“SUP-FE”，“统计对象ID”为“OBJECT6”，按VLRNUM前缀统计，“VLRNUM前缀”为“137”，“DESCRIPTION”为“plmnxxx”。

   ```
   MOD STRNGEX: NETTYP="SUP-FE", OBJECTID=OBJECT6, TYPE=STAT_VLRNUMPREFIX, VLRNUM="137", DESCRIPTION="plmnxxx";
   ```
7. 修改用户数据统计对象，“网元类型”为“SUP-FE”，“统计对象ID”为“OBJECT7”，“统计类型”为“按APN名称统计”，“APN”为“cmnet.000.460.gprs”，“DESCRIPTION”为“plmnxxx”。

   ```
   MOD STRNGEX: NETTYP="SUP-FE", OBJECTID=OBJECT7, TYPE=STAT_APN, APN="cmnet.000.460.gprs", DESCRIPTION="plmnxxx";
   ```
8. 修改用户数据统计对象，“网元类型”为“SUP-FE”，“统计对象ID”为“OBJECT8”，按NPRN统计，“NPRN”为“137”，“DESCRIPTION”为“plmnxxx”。

   ```
   MOD STRNGEX: NETTYP="SUP-FE", OBJECTID=OBJECT8, TYPE=STAT_NPRN, NPRN=137, DESCRIPTION="plmnxxx";
   ```
