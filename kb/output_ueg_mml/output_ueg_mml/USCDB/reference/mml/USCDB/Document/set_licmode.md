# 设置License兼容模式(SET LICMODE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令在25.1.0版本不支持。

该命令属于高危命令，该操作可能会导致License文件失效。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置License兼容模式。各网元需要加载License后业务才能生效。一般情况下一份License文件只对应一个FE，融合场景中存在多个FE网元，此时需要打开License兼容模式，使一份License文件对应多个FE，从而保证每个FE网元业务都能正常生效。

## 注意事项

必须已经加载一个IMS-HSS或IMS-SLF插件包，才能设置License兼容模式。

该命令不允许进行批操作。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                       |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------------|
| COMFLAG | 兼容类型   | 用于指定多FE数据融合场景下是否开启License文件的兼容处理方式。 各参数选项的含义是：OFF（关闭）：关闭兼容模式。ON（打开）：开启兼容模式，打开该开关后多FE可共用同一份License文件。 默认值：无。                |
| ESN     | ESN    | 仅当本命令中的“兼容类型”参数为“打开”时该参数有效，其值域类型为字符串，用于指定各FE共用License文件对应的ESN值，可在OM Portal的“应用管理 > 应用License > License管理”中选择应用名称查询对应的ESN值。 |
| FETYPE  | FE类型   | 仅当本命令中的“兼容类型”参数为“打开”时该参数有效，其值域类型为字符串，用于指定需要设置License兼容模式的FE类型。 取值范围与加载的FE插件包有关，可通过LST FEPLUG命令查询获取。                        |

## 使用实例

设置License“兼容类型”为“关闭”。

```
SET LICMODE: COMFLAG=OFF;
```
