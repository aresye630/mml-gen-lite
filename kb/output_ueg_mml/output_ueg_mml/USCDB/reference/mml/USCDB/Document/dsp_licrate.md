# 查询License资源数目和使用率(DSP LICRATE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于请求系统显示当前License资源数目和使用率。

在维护过程中，操作人员可以使用该命令显示当前License的使用情况，包括当前License资源数目和使用资源项与容量比例。这些基本信息可用于帮助评估是否需要申请更大容量的License，或者是否需要进行扩容操作。

## 注意事项

在执行命令之前请确保主备PGW模块状态正常。

## 参数说明

| 参数标识   | 参数名称          | 参数说明                                                                                                                                 |
|:-------|:--------------|:-------------------------------------------------------------------------------------------------------------------------------------|
| FETYPE | FE类型          | 可选必选说明：可选参数。 参数含义：用于请求系统显示哪个FE类型的License资源数目和使用率，此参数通过LOD FEPLUG命令加载FE插件后在此引用，可通过LST FEPLUG命令查询获取。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。 |
| SHOWID | 是否显示LicenseID | 可选必选说明：可选参数。 参数含义：用于指定系统是否显示License资源项的名称。 取值范围： YES(是)：显示License资源项名称。NO(否)：不显示License资源项名称。 默认值：无。 配置原则：无。                         |

## 使用实例

查询“FE类型”为“GU-HLR”，“是否显示LicenseID”为“YES(是)”的License资源数目和使用率。

`DSP LICRATE: FETYPE="GU-HLR", SHOWID=YES;`

当配置“FE类型”为不同FE时，会输出各个FE自己的License资源结果，此处仅供示例。各个License资源项具体功能请参考FE产品文档中的“**License控制项**”页面。

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1的参数说明。

| 输出项名称      | 输出项解释                                                                                       |
|:-----------|:--------------------------------------------------------------------------------------------|
| License ID | 用于返回License资源项的名称。                                                                          |
| 资源         | 用于返回License资源项的描述信息，通过该输出项可了解当前FE使用的资源项。                                                    |
| 实际数目       | 用于返回系统中License资源项实际值，通过该值可以了解当前FE业务资源项具体的使用数量。                                              |
| 最大限制数目     | 用于返回License资源项最大限制数目，此为当前FE资源项的License容量。                                                   |
| 使用率        | 用于返回FE的License实际数目和最大限制数目的比值，通过该比率了解当前FE业务类型资源项使用情况，从而为是否需要申请更大容量License或者是否需要进行扩容操作提供判断依据。 |
