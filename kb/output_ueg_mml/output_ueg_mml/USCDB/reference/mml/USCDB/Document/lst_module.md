## 命令功能

该命令用于查询Pod上的模块情况，使操作员了解当前USCDB网元内模块的相关配置信息时。模块即Pod上运行的业务进程。

查询模块配置的相关方法如下：

- 若需要查询全部模块信息，请不要输入任何参数值。
- 若需要查询全部模块信息中符合某一参数条件的模块时，请在对应参数中输入对应的参数值。如：需要查询USCPID3\_1 Pod内配置的所有模块信息时，请在参数“主用Pod名称”中输入对应的参数值“USCPID3\_1”。
- 若需要查询全部模块信息中符合多个参数条件的模块时，请在对应的多个参数中输入对应的参数值。如：需要查询USCPID3\_1 Pod内配置的所有NDF模块信息时，请在参数“主用Pod名称”中输入对应的参数值“USCPID3\_1”，参数“模块类型”中输入对应值“NDF”。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                      |
|:------------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MID         | 模块号     | 用于指示系统需要按照哪个模块号来查询模块配置信息。 若输入该参数时，系统查询模块号等于该参数值的模块配置信息。 若不输入该参数时，则表示该参数不作为查询的限制条件。 取值范围：1～4080 默认值：无。                                                                     |
| MT          | 模块类型    | 用于指示系统需要按照哪个模块类型来查询模块配置信息。 若输入该参数时，系统查询模块类型等于该参数值的模块配置信息。 若不输入该参数时，则表示该参数不作为查询的限制条件。 取值范围：DPU(DPU)NDF(NDF)DSG(DSG)DBG(DBG)DRU(DRU)DSU(DSU)PGW(PGW)DMA(DMA)CAG(CAG) 默认值：无。 |
| SERVICETYPE | 业务类型    | 用于指示系统需要按照哪个业务类型来查询模块配置信息。 若输入该参数时，系统查询业务类型等于该参数值的模块配置信息。 若不输入该参数时，则表示该参数不作为查询的限制条件。 取值范围：长度不超过128的字符串 默认值：无。                                                             |
| VMNAME1     | 主用Pod名称 | 用于指示系统需要按照哪个主用Pod的名称来查询模块配置信息。 取值范围：长度不超过128的字符串。 默认值：无。                                                                                                                  |
| VMNAME2     | 备用Pod名称 | 用于指示系统需要按照哪个备用Pod的名称来查询模块配置信息。 当备Pod名为32个F时，表示查询的模块是单机部署下的主备模块。 取值范围：长度不超过128的字符串。 默认值：无。                                                                                 |
| MNAME       | 模块名称    | 用于指示系统需要按照哪个模块名称来查询模块配置信息。 若输入该参数时，系统查询模块名称等于该参数值的模块配置信息。 若不输入该参数时，则表示该参数不作为查询的限制条件。 取值范围：长度不超过32的字符串 默认值：无。                                                              |

## 使用实例

1. 查询所有模块的配置信息。

   ```
   LST MODULE:;
   ```

   ```
   %%LST MODULE:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    模块号  模块类型  业务类型  主用Pod名称  备用Pod名称  模块名称

    21      DBG       USCDB     USPID3_1         NULL           DBG_21  
    22      DBG       USCDB     USPID3_2         NULL           DBG_22  
    (结果个数 = 7)

   ---    END
   ```
2. 以单一参数为条件进行查询。例如：查询“备用Pod名称”为“FFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFF”的模块的配置信息。

   ```
   LST MODULE: VMNAME2="FFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFF";
   ```

   ```
   %%LST MODULE: VMNAME2="FFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFF";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    模块号  模块类型    业务类型  主用Pod名称        备用Pod名称                          模块名称

    30      PGW         USCDB       USPID3_1         FFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFF           PGW_30  
    (结果个数 = 1)

   ---    END
   ```
3. 以单一参数为条件进行查询。例如：查询“模块号”为“100”的模块的配置信息。

   ```
   LST MODULE: MID=100;
   ```

   ```
   %%LST MODULE: MID=100;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
                     模块号  =  100
                   模块类型  =  NDF
                   业务类型  =  USCDB
                主用Pod名称  =  USPID3_1
                备用Pod名称  =  USPID3_2
                   模块名称  =  NDF100
   (结果个数 = 1)

   ---    END
   ```
4. 以多个参数为条件进行组合查询。例如：查询“查询类型”为“DPU”且“业务类型”为“USCDB”的模块的配置信息。

   ```
   LST MODULE: MT=DPU, SERVICETYPE="USCDB";
   ```

   ```
   %%LST MODULE: MT=DPU, SERVICETYPE="USCDB";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
                     模块号  =  35
                   模块类型  =  DPU
                   业务类型  =  USCDB
                主用Pod名称  =  USPID3_1
                备用Pod名称  =  NULL
                   模块名称  =  NULL
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD MODULE**命令的参数说明。
