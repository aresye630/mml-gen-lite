## 命令功能

**须知** 

该命令属于高危命令，如果此操作是增加DSU或DRU节点操作，那么此DSU或DRU节点将用于保存用户数据，不能轻易的删除此DSU或DRU节点。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于将DRU、DSU模块作为节点添加到对应的Cluster中。

该命令用于开局和扩容场景，在模块、Cluster配置完成之后，将具有相同处理功能的模块添加到对应的Cluster内。一个Cluster内的节点是采用负载均衡的工作方式，因此每个Cluster内建议添加两个节点，用来提高软件的可靠性。

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                       |
|:-------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CID    | Cluster标识 | 用于定义一个待增加节点所属Cluster的Cluster标识。该参数是通过ADD CLUSTER定义后在此引用。 该参数的配置原则： 为了便于管理和维护，Cluster标识建议遵循以下配置原则。“1”固定预留给存储USCDB公共数据的DRU Cluster，系统自动配置。从“2”到“30”，从“1025”到“4078”分配给存储全局数据的DRU Cluster。从“31”到“100”，从“513”到“612”，从“1025”到“4078”分配给存储路由数据的DRU Cluster。从“101”到“512”，从“613”到“1024”，从“1025”到“4078”分配给存储用户数据的DSU Cluster。 Cluster标识对应的Cluster类型要与模块号对应的模块类型一致。 取值范围：1～4096 默认值：无。 |
| NID    | 节点标识      | 用于定义一个待增加节点的节点标识，此参数在Location内唯一。节点标识必须与模块号一一对应。为了便于后续的维护，推荐节点标识和模块号的数值相同。 取值范围：1～32768 默认值：无。                                                                                                                                                                                                                                                                             |
| MID    | 模块号       | 用于定义一个待增加节点的模块号，该参数是通过ADD MODULE定义后在此引用。 该参数的配置原则：模块号所对应模块类型必须是DRU或DSU。Cluster标识对应的Cluster类型要与模块号对应的模块类型一致。 取值范围：1～4080 默认值：无。                                                                                                                                                                                                                                             |

## 使用实例

在开局场景下，为USCDB的USRSU Pod配置对应的节点信息，此时需要进行如下配置。

1. 根据图1中的参数索引关系，确认准备条件是否完成。

   1. 执行**LST MODULE**命令查询待添加节点对应的模块是否已添加。若未添加，需执行**ADD MODULE**命令添加该模块，模块的模块号为25。
   2. 执行**LST CLUSTER**命令查询待添加节点所属的Cluster是否已添加。若未添加，需执行**ADD CLUSTER**命令添加该Cluster，Cluster的Cluster标识为31。
2. 执行如下命令，添加节点。

   ```
   ADD NODE: CID=31, NID=25, MID=25;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                               | 原因分析                                                 | 处理建议                                                           |
|-------:|:------------------------------------|:-----------------------------------------------------|:---------------------------------------------------------------|
| 260046 | 该模块不存在。                             | 输入的“模块号”在系统中未配置。                                     | 通过LST MODULE命令查询已配置的“模块号”，然后重新执行本命令。                           |
| 260104 | 该cluster不存在。                        | 输入的“Cluster标识”在系统中未配置。                               | 通过LST CLUSTER命令查询已配置的“Cluster标识”，然后重新执行本命令。                    |
| 260106 | 参数NID指定的节点ID已被另一节点或远端节点使用。          | 输入的“节点标识”在系统中已配置。                                    | 通过LST NODE命令查询已配置的“节点标识”，输入一个不同值，然后重新执行本命令。                    |
| 260110 | 参数MID指定的模块的类型与参数CID指定的cluster类型不一致。 | 指定的“模块号”所对应的“模块类型”必须与指定的“Cluster标识”对应的“Cluster类型”一致。 | 通过LST MODULE命令和LST CLUSTER命令，使用对应的“Cluster标识”和“模块号”，然后重新执行本命令。 |
| 260111 | 该模块号已被另一节点使用。                       | 不能在同一模块上配置2个以上节点。                                    | 通过LST MODULE和LST NODE命令查询已配置节点的“模块号”，输入一个不同值，然后重新执行本命令。        |
