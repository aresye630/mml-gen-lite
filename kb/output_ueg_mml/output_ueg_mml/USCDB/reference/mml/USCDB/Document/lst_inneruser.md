# 查询局内FTP用户(LST INNERUSER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询局内FTP用户。

- 若需要查询全部局内FTP用户的概要信息，请不要输入任何参数。
- 若需要查询某一用户的信息，请输入“用户名”。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                        |
|:---------|:-------|:--------------------------------------------------------------------------------------------|
| USERNAME | 用户名    | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个用户名查询局内FTP用户；若不输入，则表示所有的局内FTP用户。 取值范围：长度不超过31位的字符串 默认值：无。 配置原则：无 |

## 使用实例

查询指定局内FTP用户，该“用户名”为“pgw”。

```
LST INNERUSER: USERNAME="pgw";
```

```
%%LST INNERUSER: USERNAME="pgw";%%
RETCODE = 0  操作成功

操作结果如下
------------------------
    用户名    =  pgw
      密码    =  *****
  修改状态    =  否
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见

**MOD INNERUSER**

命令的参数说明。表1列出的是未包含在

**MOD INNERUSER**

命令参数含义中的输出项。

| 输出项名称   | 输出项解释                                                    |
|:--------|:---------------------------------------------------------|
| 修改状态    | 用于标识用户名的密码修改状态。 取值范围：是：表示此用户名的密码有被修改过。 否：表示此用户名的密码未被修改过。 |
