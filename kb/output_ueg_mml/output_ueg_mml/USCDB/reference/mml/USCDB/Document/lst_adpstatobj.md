# 查询适配测量对象(LST ADPSTATOBJ)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询适配测量对象信息。

- 若需要查询全部适配测量对象的概要信息，请不要输入任何参数。
- 若需要查询某个适配测量对象的详细信息，请输入“适配测量对象ID”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识           | 参数名称     | 参数说明                                         |
|:---------------|:---------|:---------------------------------------------|
| ADPSTATOBJID   | 适配测量对象ID | 用于标识一条适配测量对象记录；若不输入，则表示查询所有适配测量对象ID。         |
| ADPSTATOBJNAME | 适配测量对象名称 | 用于标识一条适配测量对象的名称；若不输入，则表示查询所有的适配测量对象名称。       |
| SERVICETYPE    | 业务类型     | 用于指定适配测量对象针对哪种业务类型的操作进行统计；若不输入，则表示查询所有的业务类型。 |

## 使用实例

1. 查询指定适配测量对象记录，该“适配测量对象ID”为“1”，“适配测量对象名称”为“TestObj”，“业务类型”为“SUP-FE”。

   ```
   LST ADPSTATOBJ: ADPSTATOBJID=1, ADPSTATOBJNAME="TestObj", SERVICETYPE="SUP-FE";
   ```

   ```
   %%LST ADPSTATOBJ: ADPSTATOBJID=1, ADPSTATOBJNAME="TestObj", SERVICETYPE="SUP-FE";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------------------
     适配测量对象ID  =  1
   适配测量对象名称  =  TestObj
           业务类型  =  SUP-FE
   (结果个数 = 1)

   ---    END
   ```
2. 查询适配测量对象的所有记录。

   ```
   LST ADPSTATOBJ:;
   ```

   ```
   %%LST ADPSTATOBJ:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------------------
    适配测量对象ID  适配测量对象名称  业务类型

    1               TestObj           SUP-FE      
    2               TWO               SUP-FE      
    3               THREE             SUP-FE      
   (结果个数 = 3)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数详见**ADD ADPSTATOBJ**命令的参数说明。
