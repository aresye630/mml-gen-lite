# 查询LDAP客户端用户名及其对应的描述(LST LDAPUSER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询已配置的LDAP客户端用户相关信息。

- 若需要查询全部LDAP客户端用户名及其对应的描述信息，不需要输入参数。
- 若需要查询某个LDAP客户端用户名及其对应的描述信息，请输入“用户名”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                    |
|:-----------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------|
| USERNAME   | 用户名      | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个LDAP客户端用户名来查询数据记录；若不输入，则表示所有的LDAP客户端的用户名。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                                  |
| USERDESC   | 用户描述     | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个LDAP客户端用户描述来查询数据记录。若不输入，则表示所有的LDAP客户端的用户描述。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                                |
| FEVIEWTYPE | LDAP视图名称 | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个LDAP视图名称来查询数据记录，若不输入，则表示所有的LDAP视图名称。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：此参数需要在执行LOD LDAPVIEW命令加载LDAP视图包后才能在此处引用。 |

## 使用实例

1. 查询全部LDAP客户端用户名及其对应的描述信息。

   ```
   LST LDAPUSER:;
   ```

   ```
   %%LST LDAPUSER:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------

   用户名     用户描述       LDAP视图名称 

   mrk        cnp200_HW      XX_SESSIONDB               
   test1      NULL           XX_SESSIONDB             
   (结果个数 = 2)

   ---    END
   ```
2. 查询LDAP客户端用户名及其对应的描述信息，“用户名”为“test1”。

   ```
   LST LDAPUSER: USERNAME="test1";
   ```

   ```
   %%LST LDAPUSER: USERNAME="test1";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------

                               用户名  =  test1
                             用户描述  =  NULL
                         LDAP视图名称  =  XX_SESSIONDB

   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD LDAPUSER**命令的参数说明。
