## 命令功能

**须知** 

该命令属于高危命令，该操作将修改本局的PARTITION参数，操作不当将导致业务中断、数据丢失等重大事故。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改一个USCDB网元内Partition的参数配置。

该命令的使用场景：

- 开局场景：用于Global-Local组网或混合组网局点开局时，根据指导书要求，设置本局的Partition参数。
- 网络改造场景：非Global-Local组网或非混合组网改造成Global-Local组网或混合组网时，根据改造指导书步骤，设置本局的Partition参数。

## 注意事项

- 当本地数据修改开关打开，即参数“LOCALPGWSWITCH”选择为“On”时，如果需要在Service Partition局点执行全局数据更新操作，需要将Routing Partition局点的全局数据刷新周期开关“GLOBALDATAREFRESHCYCLE”打开，执行命令：

  ****MOD INSP: INSPT=PGW, INSPN=GLOBALDATAREFRESHCYCLE, INSPV=\*;****

  修改INSPV的值来设定打开时间，打开时间以具体业务模型而定，建议时间1小时。期间不允许将营帐接入到Routing Provision局点，因为如果刷新周期较长，全局数据更新不能马上在Routing Partition局点的PGW生效，与此相关的业务操作会失败。
- 该命令不允许进行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。

## 参数说明

| 参数标识              | 参数名称            | 参数说明                                                                                                                                                                                                                                                                               |
|:------------------|:----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE       | 业务类型            | 用于定义待设置Partition的业务类型。此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。 取值范围：长度不超过128的字符串 默认值：无                                                                                                                                                                                              |
| VFYSPD            | 校验速率            | 用于定义待设置Partition的全局路由校验速率。 该参数的配置原则： 只能修改本端的校验速率。 取值范围：1～100 默认值：5                                                                                                                                                                                                                 |
| TMREGVFY          | 校验消息超时定时器时长(毫秒) | 用于定义待设置Partition的校验消息超时定时器时长。 该参数的配置原则： 只能修改本端的校验消息超时定时器时长。 取值范围：500～6000 默认值：5000                                                                                                                                                                                                 |
| TMREGREP          | 复制响应超时定时器时长(毫秒) | 用于定义待设置Partition的复制响应超时定时器时长。 该参数的配置原则： 只能修改本端的复制响应超时定时器时长。 取值范围：500～6000 默认值：5000                                                                                                                                                                                                 |
| GENROUTINGSWITCH  | 局间反向生成全局路由数据开关  | 用于定义待设置Partition的局间反向生成全局路由数据开关。 该参数的配置原则： 只能修改本端的局间反向生成全局路由数据开关。 取值范围： off(关闭) on(打开) 默认值：on(打开)                                                                                                                                                                                  |
| LOCALPGWSWITCH    | 本地数据修改开关        | 用于定义待设置Partition的本地数据修改开关。 该参数的配置原则： 只能修改本端的本地数据修改开关。 取值范围： Off（关闭） On（打开） 默认值：Off（关闭）                                                                                                                                                                                             |
| ROUTEVERIFYSWITCH | 全局路由校验开关        | 用于定义待设置Partition的局间开关。 该参数的配置原则： 只能修改本端的局间路由校验开关。 取值范围： Off（关闭） On（打开） 默认值：On（打开）                                                                                                                                                                                                  |
| GLBDATAMIGSWITCH  | 全局数据迁移开关        | 用于定义全局数据迁移开关。该参数仅在Global Local 2.0组网场景下使用。 该参数的配置原则： 只能修改本端的全局数据迁移开关。Global BE和Local BE的该参数取值需保持一致。 取值范围： On（打开），Global BE和Local BE之间的全局数据周期性校验只比对不校正。设置为此取值后，手工执行STR GLBDATAVFY命令校验全局数据，全局数据以Local BE为准进行校正。Off（关闭），Global BE和Local BE之间的全局数据周期性校验以Global BE数据为准进行校正。 默认值：Off（关闭） |

## 使用实例

修改本地Partition业务类型为SUP-FE的校验速率。

```
SET PARTITIONPARA: SERVICETYPE="SUP-FE", VFYSPD=10;
```

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 250098 | 参数取值无效：参数SERVICETYPE的取值不存在，请确认已经成功加载了该FE插件。  | “业务类型”必须从已加载的值中选择。                               | 通过LST FEPLUG命令查询加载的“FE类型名称”，“FE类型名称”即“业务类型”。 若“业务类型”加载成功，请在执行该命令时输入正确的业务类型名称。 若“业务类型”加载不成功或者没有加载，通过LOD FEPLUG命令加载成功后，重新执行该命令。 |
