# 修改LDAP客户端用户名和密码（MOD LDAPUSER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改LDAP客户端的用户密码。

## 注意事项

密码长期使用会增加被盗窃和破解的风险，而且使用的时间越长，被盗窃和破解的风险越高。定期修改密码可以有效防范这种情况的发生，因此强烈建议您定期修改密码。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                              |
|:-----------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USERNAME   | 用户名      | 可选必选说明：必选参数 参数含义：用于指定LDAP客户端的用户名称。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                              |
| PWD        | 密码       | 可选必选说明：可选参数 参数含义：用于指定LDAP客户端用户名对应的密码。 取值范围：符合密码复杂度的字符串。 默认值：无。 配置原则：密码区分大小写，其复杂度需同时满足下列条件。必须至少包含以下四个类别中的三类：英文大写字母。英文小写字母。数字：0～9。特殊字符：~ ! # % ^ * ( ) _ - + [ ] { } | < > . ?。 不允许使用三个或三个以上连续的字母或数字（例如：ABC、123）。密码不能和用户名或者用户名的逆序一样，且不能包含用户名或者用户名的逆序。不允许使用三个或三个以上连续的相同字符（例如：AAA、111）。长度最短16个字符，最长128个字符。第一个字符必须是字母。 |
| CFM        | 确认密码     | 可选必选说明：可选参数 参数含义：用于指定LDAP客户端的用户名对应的确认密码。 取值范围：符合密码复杂度的字符串。 默认值：无。 配置原则：“确认密码”必须与“密码”相同。                                                                                                                                                                                                                           |
| USERDESC   | 用户描述     | 可选必选说明：可选参数 参数含义：用于对LDAP客户端的用户信息进行描述说明。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                         |
| FEVIEWTYPE | LDAP视图名称 | 可选必选说明：可选参数 参数含义：用于指定LDAP视图的名称。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：此参数需要在执行LOD LDAPVIEW命令加载LDAP视图包后才能在此处引用。                                                                                                                                                                                                           |

## 使用实例

1. 通过OM Portal的文件传输服务上传LDAP视图包“XX\_SESSIONDB\_VIEW\_V200R025C02.tar”到“CGPLite文件 > 软件包”文件夹内。上传方法可参考产品文档中“GUI参考 > 文件传输”，并且该适配包必须使用CMS签名。上传后，需先在“CSP MML命令”界面上执行**LOD PKG**命令。
2. 执行**LOD LDAPVIEW**命令加载LDAP视图包，“LDAP视图包名称”为“XX\_SESSIONDB\_VIEW\_V200R025C02.tar”。
3. 将LDAP客户端“用户名”为“test”的用户“密码”改为“ab12CD34#56”。

   ```
   MOD LDAPUSER: USERNAME="test", PWD="*****", CFM="*****", USERDESC="for test", FEVIEWTYPE="XX_SESSIONDB";
   ```

   **说明** 

   - 密码在命令行输入区域显示为“\*\*\*\*\*”。
   - 执行本命令时，若“密码”取值为样例中的弱口令“ab12CD34#56”，执行结果会返回“260566”错误码。

| 257126 | 密码和确认密码必须一致。         | 密码和确认密码不相同。                  | 请输入和密码相同的确认密码。                                                              |
