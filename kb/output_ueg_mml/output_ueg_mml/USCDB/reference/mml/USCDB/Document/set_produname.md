# 设置产品名称(SET PRODUNAME)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令在25.1.0版本不支持。

该命令用于设置产品名称。在OM Portal的“应用管理 > 应用License > License管理”激活License时，如果USCDB网元上的产品名称与License文件中的产品名称不一致，则会导致激活License失败，此时需使用该命令将USCDB网元上的产品名称设为与License文件中的产品名称一致。

## 注意事项

- 此命令为IMS-SLF、IMS-HSS网元定制，“产品名称”可设置为“USC”或者“HSS9820”。
- 如下场景允许把“产品名称”设置为“HSS9820”，其他场景不允许设置为“HSS9820”。

  - 系统仅加载了IMS-SLF插件包。
  - 系统仅加载了IMS-HSS插件包。
  - 系统仅加载了HSS9860插件包，且加载模式为“单应用类型”。
  - 系统仅加载了IMS-SLF和IMS-HSS插件包。
  - 系统仅加载了IMS-SLF和HSS9860插件包，且HSS9860插件包的加载模式为“单应用类型”。
- 该命令不支持联机设定，设置后需重启License中心所在的PGW模块。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                     |
|:----------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PRODUNAME | 产品名称   | 用于定义网元产品名称。 取值范围：USCMODE(USC)：表示把产品名称设置为USC。用于IMS-SLF与USCDB分离部署或IMS-HSS与USCDB分离部署的场景。IMSMODE(HSS9820)：表示把产品名称设置为HSS9820。用于IMS-SLF与USCDB合一部署或IMS-HSS与USCDB合一部署的场景。 默认值：无。 |

## 使用实例

设置“产品名称”为“HSS9820”，执行如下命令：

```
SET PRODUNAME: PRODUNAME=IMSMODE;
```
