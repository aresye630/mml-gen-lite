# 删除Cluster信息(RMV CLUSTER)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令。除了在开局初始配置时，其他情况下删除Cluster将会有降低系统的软件可靠性和业务处理能力的影响。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在USCDB网元内删除一个Cluster信息。

该命令的使用场景：

- 存在冗余的Cluster。冗余的Cluster会对后续的操作和维护产生干扰，因此建议立即删除。
- 已添加Cluster的配置信息错误，且不能通过**MOD
  CLUSTER**命令修改。如：Cluster的模块号错误。

## 注意事项

必须保证待删除Cluster内的节点信息已删除，否则命令无法执行。可通过执行**RMV NODE**命令删除Cluster内的节点信息。

该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                  |
|:-------|:----------|:----------------------------------------------------------------------|
| CID    | Cluster标识 | 标识一条Cluster配置信息的关键字段，用于指定需要删除哪一条Cluster配置记录，该参数可以使用LST CLUSTER命令查询获得。 |

## 使用实例

在开局场景下，由于误操作，操作员额外添加了一个Cluster信息。冗余的Cluster标识为10。

1. 执行**LST NODE**命令，确认该Cluster内是否已配置了节点信息。

   ```
   LST NODE:;
   ```

   - 是 => 步骤2
   - 否 => 步骤3
2. 执行**RMV NODE**命令，删除Cluster内的节点信息。
3. 执行**RMV CLUSTER**命令，删除多余的Cluster信息

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                  | 原因分析                   | 处理建议                                                             |
|-------:|:-----------------------|:-----------------------|:-----------------------------------------------------------------|
| 260104 | 该cluster不存在。           | 指定的“Cluster标识”在系统中不存在。 | 通过LST CLUSTER命令，查询已加载的“Cluster标识”，并正确填写命令的“Cluster标识”，然后重新执行本命令。 |
| 260105 | 该cluster已被另一节点或远端节点使用。 | 无法删除一个使用中的cluster。     | 通过LST NODE命令查询该cluster被占用的节点，然后通过RMV NODE删除对应的节点，最后重新执行本命令。      |
