# 查询DSG链路条数(LST LINKNUM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询DSG模块之间的链路条数：

- 若需要查询全部DSG链路数据记录的概要信息，请不要输入任何参数。
- 若需要查询某条DSG链路数据记录的详细信息，请输入“业务类型”参数或“链路数”参数或这2个参数的组合。

## 注意事项

系统的链路数默认为8，不修改默认值的情况下，不需要设置“链路数”，也无法使用本命令查询系统默认值。需要修改“链路数”默认值的时候，需要用**SET LINKNUM**命令。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                           |
|:------------|:-------|:-----------------------------------------------|
| SERVICETYPE | 业务类型   | 用于指示系统按照哪个FE网元的业务类型来查询DSG链路条数；若不输入，则表示所有的业务类型。 |
| LINKNUM     | 链路数    | 用于查询DSG之间的链路条数。                                |

## 使用实例

1. 查询所有DSG之间的链路条数，执行命令如下：

   ```
   LST LINKNUM:;
   ```

   ```
   %%LST LINKNUM:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   业务类型  =  SUP-FE
     链路数  =  16
   (结果个数 = 1)

   ---    END
   ```
2. 查询“业务类型”为“SUP-FE”的DSG之间的链路条数，执行命令如下：

   ```
   LST LINKNUM: SERVICETYPE="SUP-FE";
   ```

   ```
   %%LST LINKNUM: SERVICETYPE="SUP-FE";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   业务类型  =  SUP-FE
     链路数  =  16
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见**SET LINKNUM**命令的参数说明。
