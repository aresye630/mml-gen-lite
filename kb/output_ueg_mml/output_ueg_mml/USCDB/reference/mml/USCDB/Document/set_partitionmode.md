# 设置Partition模式(SET PARTITIONMODE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

- 该命令属于高危命令，Partition模式的修改会对现网的运行产生影响，可能导致业务中断和呼损。因此执行该命令前，需要与华为技术支持确认后才可以实施。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于设置本端USCDB网元内指定业务类型的分区模式。

该命令的使用场景：在云部署开局或者组网更改的场景下，根据运营商的需求或实际的现网情况，需要对某种业务类型的分区模式进行设置。

## 注意事项

- 当设置“Partition角色”为“vRouting\_Service\_Region”时，不能设置“Partition模式”为“SINGLEACCESS（单点接入）”、“BETRANS（BE转发）”、“LOCALACCESS（本地访问）”、“GLOBALROUTEBETRANS(全局路由BE转发)”或“GLOBALLOCAL(全局本地)”。
- 在Global-Local组网或混合组网场景下，当本端的某种业务类型配置了多个远端Partition时，该业务类型的“Partition模式”不能设置为“单点接入”。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识        | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
|:------------|:------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 业务类型        | 用于定义本端Partition的业务类型。此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。 取值范围：长度不超过128的字符串 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| PMODE       | Partition模式 | 用于定义本端分区模式。不同的模式代表云部署不同的接入方式。 取值范围： GLOBALROUTE（全局路由接入）：路由分区收到这个业务类型的DCI请求消息时，查询DRU中的路由数据，再根据路由信息判断用户所在分区，如果是同构分区，则由BE转发给指定的分区处理，如果是异构分区，则由FE转发给指定的分区处理。 同构分区即业务接入分区和用户所在分区为全含“v”类型的分区或全不含“v”类型的分区，比如vRSP和vSP。 异构分区即业务接入分区和用户所在分区包含“v”类型的分区和不含“v”类型的分区，比如vRSP和SP。 SINGLEACCESS（单点接入）：路由分区收到这个业务类型的请求消息时，直接转发到指定的分区处理。 BETRANS（BE转发）：路由分区收到这个业务类型的DCI请求消息时，先在本端分区查询，如果本端分区查询不到再转发到远端分区查询。不支持Partition间的路由数据同步和校验。LOCALACCESS（本地访问）：路由分区收到这个业务类型的DCI请求消息时，直接在本端分区处理。全局数据和用户数据都在本端分区访问，不支持Partition间的数据复制、校验和消息转发。GLOBALROUTEBETRANS(全局路由BE转发)：路由分区收到这个业务类型的DCI请求消息时，查询DRU中的路由数据，由BE根据路由信息转发消息给对应的分区处理。GLOBALLOCAL(全局本地)：在Global Local 2.0组网场景下，vRSP和vSP需要设置为该枚举值。vRSP为Global，vSP为Local。业务发放消息可以从Global BE或Local BE接入，但不能同时接入Global BE和Local BE。信令消息从Local BE接入，在Local BE故障场景下，Global BE支持接管Local BE的信令业务。 默认值：GLOBALROUTE(全局路由接入)。 |

## 使用实例

设置SUP-FE业务类型的“Partition模式”为“单点接入”。

```
SET PARTITIONMODE: SERVICETYPE="SUP-FE", PMODE=SINGLEACCESS;
```
