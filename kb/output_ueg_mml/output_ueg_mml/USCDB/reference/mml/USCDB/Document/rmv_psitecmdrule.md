# 删除PSITE参数过滤规则配置(RMV PSITECMDRULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，该操作将删除PSITE参数过滤规则配置，操作不当会导致转发到远端的命令执行失败。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除PSITE参数过滤规则配置。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                                                                     |
|:--------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SITEID  | Site ID | 可选必选说明：必选参数 参数含义：用于唯一标识一个远端业务发放站点，指定需要删除哪一个Site ID对应的PSITE参数过滤规则配置，操作员可以使用LST PSITECMDRULE命令查询获得。 取值范围：1～1024 默认值：无。 配置原则：无。                                             |
| CMDNAME | 命令名称    | 可选必选说明：必选参数 参数含义：用于指定需要删除哪一个命令名称对应的PSITE参数过滤规则配置，操作员可以使用LST PSITECMDRULE命令查询获得。 取值范围：长度为1~32个字符的字符串，字符串只能由数字（0～9）、大写英文字母（A～Z）、空格和下划线组成，必须以字母开头且末尾字符不能为空格。 默认值：无。 配置原则：无。 |

## 使用实例

删除一条PSITE参数过滤规则配置，“Site ID”为“5”，“命令名称”为“ADD ALLTYPE\_SUB1\_INFO5\_TPL”：

```
RMV PSITECMDRULE: SITEID=5, CMDNAME="ADD ALLTYPE_SUB1_INFO5_TPL";
```
