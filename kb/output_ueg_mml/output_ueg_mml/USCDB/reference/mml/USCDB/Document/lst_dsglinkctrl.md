# 查询DSG链路中心(LST DSGLINKCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询DSG链路中心的配置信息：

- 若需要查询所有DSG链路中心的配置信息，请不要输入任何参数。
- 若需要查询某个“DSG业务类型”的DSG链路中心配置信息，请输入对应的“DSG业务类型”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                            |
|:-------|:--------|:--------------------------------------------------------------------------------|
| DSGST  | DSG业务类型 | 用于指定维护链路的业务类型。该参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。 取值范围：长度不超过128的字符串。 默认值：无。 |

## 使用实例

1. 查询所有DSG链路中心配置：

   ```
   LST DSGLINKCTRL:;
   ```

   ```
   %%LST DSGLINKCTRL:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    DSG业务类型  模块号  IP类型  本端IPV4地址  本端IPV6地址

    SUP-FE       53      IPV4    10.14.39.40  NULL  
    SUP-FE       52      IPV4    10.14.39.42  NULL  
    (结果个数 = 2)

   ---    END
   ```
2. 查询指定“DSG业务类型”的DSG链路中心，“DSG业务类型”为“SUP-FE”：

   ```
   LST DSGLINKCTRL: DSGST="SUP-FE";
   ```

   ```
   %%LST DSGLINKCTRL: DSGST="SUP-FE";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    DSG业务类型  =  SUP-FE
         模块号  =  52
         IP类型  =  IPV4
   本端IPV4地址  =  10.14.39.42
   本端IPV6地址  =  NULL
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD DSGLINKCTRL**命令的参数说明。
