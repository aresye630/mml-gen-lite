# 设置应急加载开关(SET EMERGENCYSWITCH)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

**须知** 

- 该命令属于高危命令，执行该命令会造成少量用户数据丢失。因此执行该命令前，需要与华为技术支持确认后才可以实施。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于设置节点的应急加载开关。由于增量数据导致主用局和容灾局中同一个Cluster内的主备节点都故障，在经过检查确认需要使用应急加载模式来恢复数据时，设置应急加载开关为开启。当系统因DRU/DSU cluster容量不足而进行扩容或DRU/DSU cluster负载严重失衡时，系统需要进行DRU/DSU cluster之间的数据迁移，在完成各DRU/DSU cluster节点之间的数据均衡之后，设置应急加载开关为关闭。

**说明** 

当出现故障的节点进入应急加载模式后，通过以下两种方式恢复数据：

- 根据全量导出备份文件备份时间前的营业厅操作日志，由华为技术支持工程师重新执行营业厅指令，恢复数据。
- 根据全量导出备份文件备份时间后的Redo文件，由华为技术支持工程师构造营业厅指令，恢复数据。

## 注意事项

- 当出现故障的DRU/DSU节点“应急开关”设置为“ON（打开）”时，会产生以下两种影响：
  - 节点下次重启后将采用应急加载模式进行加载，只加载全量导出备份文件，不加载对应的Redo文件，导致备份后的增量redo数据丢失，对全量导出备份文件备份时间后新增的业务有影响。
  - 节点重启加载成功进入应急加载模式后，系统自动关闭该节点内的周期性校验任务和定时备份任务。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识            | 参数名称   | 参数说明                                                                                                                  |
|:----------------|:-------|:----------------------------------------------------------------------------------------------------------------------|
| NODEID          | 节点ID   | 用于标识节点，此参数在Location内唯一，通过ADD NODE命令加载之后在此引用。 取值范围：0～32768 默认值：无。  说明： 当该参数取值为“0”时必须输入参数“业务类型”，表示设置该“业务类型”所有节点的应急加载开关。 |
| EMERGENCYSWITCH | 应急开关   | 用于设置应急加载开关。 取值范围：OFF（关闭）ON（打开） 默认值：无。                                                                                 |
| SERVICETYPE     | 业务类型   | 用于表示FE网元的业务类型，通过LOD FEPLUG命令加载FE插件包之后在此引用。 取值范围：长度不超过128的字符串。 默认值：无。                                                  |

## 使用实例

当某节点需要通过应急加载模式来恢复数据时，可通过设置“节点ID”和打开应急加载开关来操作。

设置“节点ID”为“60”，“应急加载开关”为“ON”：

```
SET EMERGENCYSWITCH: NODEID=60, EMERGENCYSWITCH=ON;
```
