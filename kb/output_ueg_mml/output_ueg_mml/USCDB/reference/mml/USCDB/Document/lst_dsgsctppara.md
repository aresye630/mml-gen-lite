# 查询DSG模块SCTP参数配置信息(LST DSGSCTPPARA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在数据库中查询DSG模块的SCTP配置信息。主要包括重传超时时间（Retransmission Time-Out）配置，重传配置，校验配置，拥塞阈值配置等。

- 若需要查询SCTP参数配置的概要信息，请不要输入任何参数。
- 若需要查询SCTP参数配置的详细信息，请输入“报文重发间隔初始值”或者其他参数或者这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识                  | 参数名称        | 参数说明                                                                                                                                                                                                                          |
|:----------------------|:------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RTOINIT               | 报文重发间隔初始值   | 用于定义RTO初始时长；若不输入，则表示所有的报文重发间隔初始值。                                                                                                                                                                                             |
| RTOMIN                | 报文重发间隔最小值   | 用于定义RTO最小时长；若不输入，则表示所有的报文重发间隔最小值。                                                                                                                                                                                             |
| RTOMAX                | 报文重发间隔最大值   | 用于定义RTO最大时长；若不输入，则表示所有的报文重发间隔最大值。                                                                                                                                                                                             |
| RTOALPHA              | Rto Alpha值  | 用于在协议栈运行期间计算双向时延和RTO值的常量；若不输入，则表示所有的Rto Alpha值。                                                                                                                                                                               |
| RTOBETA               | Rto Beta值   | 用于在协议栈运行期间计算双向传播时间和RTO值的常量；若不输入，则表示所有的Rto Beta值。                                                                                                                                                                              |
| COOKIELIFE            | Cookie有效生命期 | 用于定义Cookie的有效期，在该时间里，在接收到来自SCTP服务器的INIT ACK消息后，Cookie Echo消息必须由SCTP客户端发送返回。即，当接收到Cookie Echo消息时，用户可允许SCTP服务器不发送“Stale Cookie错误”到对端。在超过Cookie有效生命期时间后，如果SCTP收到Cookie Echo消息，将返回“Stale Cookie”作为原因的错误消息；若不输入，则表示所有的Cookie有效生命期。 |
| MAXARETR              | 偶联最大重传次数    | 用于定义偶联可承受的最大重传次数；若不输入，则表示所有的偶联最大重传次数。                                                                                                                                                                                         |
| MAXPRETR              | 路径最大重传次数    | 用于定义偶联的一条路径可承受的最大重传次数；若不输入，则表示所有的路径最大重传次数。                                                                                                                                                                                    |
| INITMAXRETR           | 初始化最大重传次数   | 用于定义偶联中INIT块最大重传次数；若不输入，则表示所有的初始化最大重传次数。                                                                                                                                                                                      |
| HBINTER               | 心跳消息间隔      | 用于定义心跳间隔时间。用于计算在空闲时间时，来自SCTP主机的相邻2条心跳消息的间隔；若不输入，则表示所有的心跳消息间隔。                                                                                                                                                                 |
| CHKSUMTX              | 发送消息时计算校验和  | 用来指示当SCTP块被送到对端时是否加校验和的标识；若不输入，则表示所有的发送消息时计算校验和。                                                                                                                                                                              |
| CHKSUMRX              | 接收消息时检查校验和  | 用来指示当从对端接收SCTP块时是否计算校验和的标识；若不输入，则表示所有的接收消息时检查校验和。                                                                                                                                                                             |
| CHKSUMTYPE            | 校验和算法       | 用来表示校验和的算法；若不输入，则表示所有的校验和算法。                                                                                                                                                                                                  |
| CNGLEVELNO            | 无拥塞级阈值      | 用于定义无拥塞的发送缓存中数据占用率；若不输入，则表示所有的无拥塞级阈值。                                                                                                                                                                                         |
| CNGLEVELL             | 低拥塞级阈值      | 用于定义低拥塞的发送缓存中数据占用率；若不输入，则表示所有的低拥塞级阈值。                                                                                                                                                                                         |
| CNGLEVELH             | 高拥塞级阈值      | 用于定义高拥塞的发送缓存中数据占用率；若不输入，则表示所有的高拥塞级阈值。                                                                                                                                                                                         |
| TOS                   | DSCP值       | 用于指定DSCP差分服务代码点（Differentiated Services Code Point）的取值。                                                                                                                                                                       |
| CONGESTIONFLAG        | 拥塞控制开关      | 设置发送数据时是否使用拥塞控制开关；若不输入，则表示所有的拥塞控制开关。                                                                                                                                                                                          |
| SERVICEPORT           | 业务基值端口      | 用于定义FE DSG和USCDB DSG之间创建偶联时获取该基值端口和模块号生成通信端口；若不输入，则表示所有的业务基值端口。                                                                                                                                                               |
| BUNDINGFLAG           | 绑定开关        | 用于定义是否使用SCTP数据块绑定机制的标识。如果设置该标识，SCTP可以把多个块（控制数据）捆绑到同一个数据包里。在SCTP中处理，捆绑并不影响用户数据传输；若不输入，则表示所有的绑定开关。                                                                                                                              |
| MAXNUMASSOC           | 最大偶联数       | 用于定义当前可以使用的最大偶联数量；若不输入，则表示所有的最大偶联数。                                                                                                                                                                                           |
| LINKMODE              | 建链模式        | 用于定义本端DSG的建链模式；若不输入，则表示所有的建链模式。                                                                                                                                                                                               |
| PINGBYPASS            | 旁路ping结果    | 用于按照是否关闭IPS测量任务来查询DSG模块SCTP参数配置信息；若不输入，则表示查询系统中已有的DSG模块SCTP参数配置的IPS测量任务信息。                                                                                                                                                    |
| CHKSUMEFFECTIMMD      | 校验和修改立即生效开关 | 用于提示系统需要按照哪个校验和修改立即生效开关来查询DSG模块SCTP参数配置信息；若不输入，则表示所有的校验和修改立即生效开关。                                                                                                                                                             |
| SUBHEALTHYCHECKSWITCH | 亚健康检测开关     | 用于定义是否打开偶联亚健康监控功能；若不输入，则表示所有的亚健康检测开关。                                                                                                                                                                                         |
| SUBHEALTHYNETPLR      | 亚健康网络丢包率    | 用于定义偶联亚健康时的网络丢包率；若不输入，则表示所有的亚健康网络丢包率。                                                                                                                                                                                         |
| SUBHEALTHYRCI         | 亚健康恢复检查间隔   | 用于定义检查偶联亚健康恢复的时间间隔；若不输入，则表示所有的亚健康恢复检查间隔。                                                                                                                                                                                      |
