# 查询动网操作软参(LST OPERATIONINSP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询动网操作软参配置状态以及扩缩容，割接等动网操作需修改的软参备份结果。

## 注意事项

无。

## 参数说明

无。

## 使用实例

1. 查询动网操作软参备份配置，此时“操作类型”取值未设置为“PRE”。

   ```
   LST OPERATIONINSP:;
   ```

   ```
   %%LST OPERATIONINSP:;%%
   RETCODE = 0  操作成功

   没有查到相应的结果
   ---    END
   ```
2. 查询动网操作软参备份配置，此时“操作类型”取值已设置为“PRE”。

   ```
   LST OPERATIONINSP:;
   ```

   ```
   %%LST OPERATIONINSP:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。各输出项含义请参见表1。

| 输出项名称   | 输出项解释            |
|:--------|:-----------------|
| 软件参数类型  | 用于表示软件参数类型。      |
| 软件参数名称  | 用于表示备份配置的软件参数名称。 |
| 软件参数值   | 用于表示备份的软件参数值。    |
| 网元类型    | 用于表示所属的网元类型。     |
