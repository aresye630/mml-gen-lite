# 清除SSH Key配置（CLR SSHKEY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，执行该命令后将导致该模块类型不能进行公钥认证。因此执行该命令前，请确认待删除SSH Key文件是否已经被使用，若已经被使用则不允许删除。

本命令用于清除指定模块的SSH Key文件，以下两种情况下需要执行该命令清除SSH Key文件：

- 不再需要对指定模块进行公钥认证。
- 更换指定模块SSH Key文件的Key类型。

## 注意事项

如果待删除SSH Key文件已经被**ADD RSFTPSERVER**命令添加的配置所使用，则不允许删除。如果确实需要删除SSH Key文件，请先删除使用该SSH Key文件的配置信息。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                           |
|:-------|:-------|:-----------------------------------------------|
| MT     | 模块类型   | 用于指示SSH Key的模块类型。 取值范围：PGW(PGW)DMA(DMA) 默认值：无。 |

## 使用实例

1. 当待删除SSH Key文件已经被使用时，以清除DMA模块类型的SSH Key文件为例：
   1. 执行**RMV RSFTPSERVER**命令删除DMA模块配置。
   2. 执行**CLR SSHKEY**命令清除DMA模块类型的SSH Key文件。

      ```
      CLR SSHKEY: MT=DMA;
      ```
2. 当需要为某一模块类型重新生成SSH Key文件时，以DMA模块类型为例：
   1. 执行**CLR SSHKEY**命令清除DMA模块类型的SSH Key文件。

      ```
      CLR SSHKEY: MT=DMA;
      ```
   2. 执行**GEN SSHKEY**命令重新生成DMA模块类型的SSH Key文件。

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释         | 原因分析                          | 处理建议                                                                                                                                         |
|-------:|:--------------|:------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------|
| 256034 | 记录不存在         | 指定模块类型的SSH Key文件记录不存在         | 执行LST SSHKEY命令查询已经生成SSH Key文件的模块类型，若需要删除的“模块类型”在查询结果中，请重新执行该命令；若需要删除的“模块类型”不在查询结果中，则无需处理。                                                    |
| 337071 | 该模块类型的Key已使用。 | 指定模块类型的SSH Key文件正在被该类型的模块所使用。 | 执行LST RSFTPSERVER命令查询PGW或DMA模块配置信息，查看参数“鉴权类型”是否为“PUBLICKEY(公钥认证)”，如果是，执行第2步。执行RMV RSFTPSERVER命令删除PGW或DMA模块配置信息。执行本命令清除PGW或DMA模块类型的SSH Key文件。 |
