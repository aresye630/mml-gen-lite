# 添加FTP用户(ADD FTPUSER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

当用户需要通过FTP与PGW、DMA交互时，使用该命令添加FTP用户。添加的FTP用户用于FTP客户端访问本端FTP服务器。

## 注意事项

- 执行本命令前请确保FTP服务器已添加。
- FTP用户最多只能增加10个。
- 一个“工作路径名称”只能增加一个FTP用户。
- 为了避免出现PGW扫描并执行未完全同步的文件，当上传的批处理文件扩展名为SFTPPARTFILE时，不进行拷贝处理。
- 密码长期使用会增加被盗窃和破解的风险，而且使用的时间越长，被盗窃和破解的风险越高。定期修改密码可以有效防范这种情况的发生，因此强烈建议您定期修改密码。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
|:------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USERTYPE    | 用户类型   | 用于指定FTP用户的类型。 取值范围：PROV(业务)：表示该用户为营帐功能的FTP用户，必须通过ADD FTPSERVER添加了“SERVERTYPE”为“PROV”的FTP服务器后才能添加PROV类型的FTP用户。DATAMTN(维护)：表示该用户为数据维护功能的FTP用户，必须通过ADD FTPSERVER添加了“SERVERTYPE”为“DATAMTN”的FTP服务器后才能添加DATAMTN类型的FTP用户。 默认值：无。                                                                                                                                                                                                                                                            |
| USERNAME    | 用户名    | 用于指定通过FTP登录的用户名，由数字、字母组成，且必须以字母开头。 取值范围：长度不超过31的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                          |
| PWD         | 密码     | 用于指定通过FTP登录用户的密码。 密码区分大小写，其复杂度需同时满足下列条件：密码必须至少包含以下四个类别中的三类：英文大写字母。英文小写字母。数字：0～9。特殊字符：~ ! # % ^ * ( ) _ - + [ ] { } | < > . ?。 不允许使用三个或三个以上连续的字母或数字（例如：ABC、123）。密码不能和用户名或者用户名的逆序一样，且不能包含用户名或者用户名的逆序。不允许使用三个或三个以上连续的相同字符（例如：AAA）。密码长度最短8个字符。密码的第一个字符必须是字母。 取值范围：长度不超过31的字符串。 默认值：无。                                                                                                                                                                                                    |
| CFM         | 确认密码   | 用于指定通过FTP服务器登录用户的确认密码，该字符串必须与“密码”相同。 取值范围：长度不超过31的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                        |
| WORKPATH    | 工作路径名称 | 根据插件包配置的FTP用户工作路径读取，读取到的工作路径名称对应的具体路径可通过LST FTPPATHCFG命令查询。用于指定FTP用户的工作目录，该参数为联想参数列表，不能手动输入。 取值范围：UPLOAD：FTP用户用于上传批处理文件的工作路径。DOWNLOAD：FTP用户进行下载批处理结果文件的工作路径。GENFTP：FTP用户用于上传或下载批处理文件的工作路径。REDUNDANCE：FTP用户用于下载容灾文件的工作路径。DOWNLOADEXPORTFILE：“用户类型”取值“DATAMTN(维护)”时选择“DOWNLOADEXPORTFILE”，表示DMA模块提供的下载导出文件的工作路径。DOWNLOADEXPLOGFILE：“用户类型”取值“DATAMTN(维护)”时选择“DOWNLOADEXPLOGFILE”，表示DMA模块提供的下载导出日志文件的工作路径。FE插件包中配置的指定目录：FE插件配置的工作路径。配置的工作路径名称要求为长度不超过127的字符串，不支持特殊字符：“，”、“'”和“；”。 默认值：无。 |
| PERMISSION  | 权限     | 用于指定FTP用户的权限。 取值范围：全部选中全部清空全部灰化UPLOAD(上传)DOWNLOAD(下载) 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                         |
| DESCRIPTION | 用户描述   | 用于描述FTP用户。 取值范围：长度不超过64的字符串，取值不能包含逗号、反斜杠。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                     |

## 使用实例

1. 添加FTP用户，参数设置如下：
   - “用户类型”为“PROV”；
   - “用户名”为“test”；
   - “密码”为“ab12CD34#56”；
   - “确认密码”为“ab12CD34#56”；
   - “工作路径名称”为“UPLOAD”；
   - “权限”为“UPLOAD”；
   - “用户描述”为“userinfo”；

   ```
   ADD FTPUSER: USERTYPE=PROV, USERNAME="test", PWD="*****", CFM="*****", WORKPATH="UPLOAD", PERMISSION=UPLOAD-1&DOWNLOAD-0, DESCRIPTION="userinfo";
   ```

**说明** 

- 密码在命令行输入区域显示为\*\*\*\*\*。
- 执行本命令时，若“密码”取值为样例中的弱口令“ab12CD34#56”，执行结果会返回“260566”错误码。
