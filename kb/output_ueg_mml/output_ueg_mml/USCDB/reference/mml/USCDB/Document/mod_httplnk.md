# 修改HTTP链路(MOD HTTPLNK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，如果HTTP链路参数配置不合理，将导致对端设备接收不到订阅通知。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改HTTP链路配置，包括服务器端IP地址，服务器端口，客户端IP地址等。

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识    | 参数名称       | 参数说明                                                                                                                          |
|:--------|:-----------|:------------------------------------------------------------------------------------------------------------------------------|
| LNKID   | 链路ID       | 标识一条HTTP链路数据记录的关键字段之一，用于指定需要修改哪一条HTTP链路，操作员可以使用LST HTTPLNK命令查询获得。                                                             |
| IPVER   | IP类型       | 用于表示IP地址类型。 取值范围： IPV4：当系统要求使用IPv4类型的IP地址时选择此选项。IPV6：当系统要求使用IPv6类型的IP地址时选择此选项。 默认值：无。                                         |
| SIPV4   | 服务器端IPV4地址 | 仅当本命令中的“IP类型”参数选择为“IPV4”时该参数有效，用于标识HTTP链路服务器端的IPv4地址。 取值范围：符合IPv4格式要求。 默认值：无。                                                 |
| SIPV6   | 服务器端IPV6地址 | 仅当本命令中的“IP类型”参数选择为“IPV6”时该参数有效，用于标识HTTP链路服务器端的IPv6地址。 取值范围：符合IPv6格式要求。 默认值：无。                                                 |
| SPORT   | 服务器端端口     | 用于标识HTTP链路服务器端的端口号。 取值范围：1～65534。 默认值：无。                                                                                      |
| CIPV4   | 客户端IPV4地址  | 仅当本命令中的“IP类型”参数选择为“IPV4”时该参数有效，用于标识HTTP链路客户端的IPv4地址。该IP地址必须为ADD SRVIPADDR命令添加的IPv4地址。 取值范围：符合IPv4格式要求。 默认值：无。                 |
| CIPV6   | 客户端IPV6地址  | 仅当本命令中的“IP类型”参数选择为“IPV6”时该参数有效，用于标识HTTP链路客户端的IPv6地址。该IP地址必须为ADD SRVIPADDR命令添加的IPv6地址。 取值范围：符合IPv6格式要求。 默认值：无。                 |
| URL     | URL        | 用于标识HTTP服务器URL。 取值范围：长度不超过255的字符串。 默认值：无。 配置原则：该参数不能配置绝对路径的URL，只能输入域名之后的URL片段。 说明：当操作人员在输入URL前多输入一个空格时，系统默认该参数与未输入空格的URL地址一样。 |
| LNKDESC | 链路描述       | 用于标识HTTP链路的描述信息。 取值范围：长度不超过32的字符串。                                                                                            |

## 使用实例

修改一条HTTP链路的服务器端IP地址，指定“链路ID”为“1”，修改“服务器端IPV4地址”为“192.168.2.119”。

```
MOD HTTPLNK: LNKID=1, IPVER=IPV4, SIPV4="192.168.2.119";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                            | 原因分析                           | 处理建议                                                             |
|-------:|:---------------------------------|:-------------------------------|:-----------------------------------------------------------------|
| 260069 | IP地址的类型不匹配。                      | 服务端IP地址类型与客户端IP地址类型不匹配。        | 请确保服务端IP地址类型与客户端IP地址类型一致，可以执行LST HTTPLNK命令查询当前链路配置的服务端和客户端的IP类型。 |
| 274632 | 链路不存在。                           | 只能修改已经存在的链路。                   | 先执行LST HTTPLNK命令查询已经添加的“链路ID”，再重新执行本命令，确保要修改的“链路ID”在查询结果中。       |
| 274703 | Client IP不存在，请使用ADD SRVIPADDR添加。 | 输入的“客户端IPV4地址”或“客户端IPV6地址”不存在。 | 执行ADD SRVIPADDR命令添加所需的“客户端IPV4地址”或“客户端IPV6地址”，确保成功添加后，再重新执行本命令。  |
