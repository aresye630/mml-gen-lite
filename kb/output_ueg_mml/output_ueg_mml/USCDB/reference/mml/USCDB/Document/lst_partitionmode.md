# 查询Partition模式(LST PARTITIONMODE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询本端分区模式的信息。

- 若需要查询本端所有分区模式信息，请不要输入任何参数。
- 若需要查询某种业务类型或者某种分区模式的信息，请输入对应的参数。

## 注意事项

- 该命令不允许进行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。

## 参数说明

| 参数标识        | 参数名称        | 参数说明                                                |
|:------------|:------------|:----------------------------------------------------|
| SERVICETYPE | 业务类型        | 用于指示系统需要按照哪种业务类型来查询本端分区模式信息。若不输入则查询所有业务类型的分区模式信息。   |
| PMODE       | Partition模式 | 用于指示系统需要按照哪种分区模式来查询本端分区模式信息。若不输入则查询本端所有分区模式的分区模式信息。 |

## 使用实例

查询“业务类型”为“SUP-FE”的分区模式信息。

```
LST PARTITIONMODE: SERVICETYPE="SUP-FE";
```

```
%%LST PARTITIONMODE: SERVICETYPE="SUP-FE";%%
RETCODE = 0  操作成功

操作结果如下
------------
     业务类型  =  SUP-FE
Partition模式  =  单点接入
(结果个数 = 1)

---    END
```

各输出项含义请参见****SET PARTITIONMODE****的参数说明。
