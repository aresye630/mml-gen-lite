# 删除PGW业务消息侦听端口(RMV PORT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，删除正在使用的端口会造成PGW无法处理来自此端口的业务发放消息。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除PGW开放给业务发放系统使用的相关端口。

当出于系统安全考虑或不再需要使用某端口时，可以使用本命令删除相关的端口。

## 注意事项

- 本命令只能删除通过ADD PORT命令添加的端口，其他默认的端口无法删除。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                     |
|:-------|:-------|:---------------------------------------------------------|
| PORTNO | 端口号    | 标识一条端口数据记录的关键字段，用于指定需要删除哪一条端口数据记录，操作员可以使用LST PORT命令查询获得。 |

## 使用实例

删除“端口号”为“7775”的端口：

```
RMV PORT: PORTNO =7775;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 274673 | 营帐客户端登录类型中配置了该端口。                     | 营帐客户端登录类型中配置了该端口。                                                                                | 先执行LST PROVLGITYPE命令查看该端口被哪个登录类型使用，再执行RMV PROVLGITYPE命令删除该登录类型后，重新执行本命令删除该端口。                                                     |
| 274717 | 原端口已被PGWSSHUSER使用。                    | 原端口已被PGW SSH用户使用。                                                                                | 执行LST PGWSSHUSER命令查看使用的端口，执行RMV PGWSSHUSER删除该PGW SSH用户后再重新执行本命令删除该端口。                                                             |
