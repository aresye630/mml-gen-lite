# 查询FTP配置信息(LST FTPPATHCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询FTP路径配置信息：

- 若需要查询所有的FTP路径配置的概要信息，请不要输入任何参数。
- 若需要查询某个FTP路径配置的详细信息，请输入“用户类型”或其它参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                               |
|:------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------|
| USERTYPE    | 用户类型   | 用于指示系统需要按照哪个“用户类型”来查询FTP路径配置；若不输入，则表示查询所有用户类型的FTP路径配置信息。 取值范围：PROV(业务)：表示查询的FTP路径配置信息为营帐功能。DATAMTN(维护)：表示查询的FTP路径配置信息为导出功能。 默认值：无。 |
| SERVICETYPE | 业务类型   | 若输入，用于指示系统需要按照哪个业务类型来查询FTP路径配置；若不输入，则表示查询所有业务类型的FTP路径配置信息。 取值范围：长度不超过128的字符串。 默认值：无。                                               |
| NAME        | 配置名称   | 若输入，用于指示系统需要按照哪个配置名称来查询FTP路径配置；若不输入，则表示查询所有的FTP配置信息。 取值范围：长度不超过31的字符串。 默认值：无。                                                      |
| PATH        | 配置路径   | 若输入，用于指示系统需要按照哪个配置路径来查询FTP路径配置；若不输入，则表示查询所有配置路径的FTP路径配置信息。 取值范围：长度不超过127的字符串。 默认值：无。                                               |

## 使用实例

1. 查询所有FTP路径配置信息。

   ```
   LST FTPPATHCFG:;
   ```

   ```
   %%LST FTPPATHCFG:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    用户类型      业务类型       配置名称                          配置路径    
    Prov          SUP-FE         123                               321                             
    DataMtn       SUP-FE         321                               123                             
    Prov          SUP-FE         6                                 abce0ABC_A                      
    Prov          SUP-FE         ABCDEFGADFDFDFSADFABCDEFGADFD_89  ABCDEFGADFDFDbFaSADFA_CDEFGab_89
    Prov          SUP-FE         FFFF                              FFFF                            
    DataMtn       SUP-FE         G                                 G                               
    DataMtn       SUP-FE         ADD                               add                             
    Prov          SUP-FE         LACCIMA                           laccima  
   (结果个数 = 8)

   ---    END
   ```
2. 查询“配置名称”为“ADD”的FTP路径配置信息。

   ```
   LST FTPPATHCFG: NAME="ADD";
   ```

   ```
   %%LST FTPPATHCFG: NAME="ADD";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
        用户类型  =  DataMtn
        业务类型  =  SUP-FE
        配置名称  =  ADD
        配置路径  =  add
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。
