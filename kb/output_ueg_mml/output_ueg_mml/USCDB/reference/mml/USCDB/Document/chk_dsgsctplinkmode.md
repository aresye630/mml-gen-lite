## 命令功能

该命令用于检查当前USCDB网元的对接配置是否满足系统配置的“建链模式”。“建链模式”通过**SET DSGSCTPPARA**命令进行设定。“建链模式”包含“顺序模式”和“奇偶模式”两种。“顺序模式”无特殊的系统配置要求。在“奇偶模式”下，建链的DSG模块需要有相同的奇偶属性，以保证它们属于相同的升级或补丁平面。

在IPV4/IPV6双栈场景下，“建链模式”不允许配置成“奇偶模式”，否则会导致DSG建链模式检查失败。

该命令针对本端和对端Location标识，并区分FE类型进行检查。如果参数“建链模式”配置成“顺序模式”，则本命令返回检查成功。如果参数“建链模式”配置成“奇偶模式”，则对接配置需满足如下条件中任意一个，才能检查成功。

- 当前USCDB网元是初始配置场景，本端没有添加DSG模块，并且也没有通过**ADD RDSG**命令添加远端DSG对接配置。
- SCTP服务端DSG的数目小于“链路数”。
- SCTP服务端DSG的数目大于等于“链路数”，并且SCTP客户端DSG的数目是偶数，则需满足如下任意一个条件：
  - SCTP服务端DSG的数目大于SCTP客户端DSG的数目，其倍数小于等于4，SCTP服务端DSG数目大于等于“链路数”的两倍，并且SCTP服务端DSG数目大于16。
  - SCTP服务端DSG的数目大于SCTP客户端DSG的数目，并且其倍数大于4。

该命令主要用在升级前健康检查工具以及巡检工具中。

## 注意事项

建链模式的检查结果需要查看返回报文中的“检查结果”。命令的返回码“RETCODE = 0 操作成功”不能作为检查是否成功的标准。

## 参数说明

无。

## 使用实例

检查当前USCDB网元的DSG建链模式。

```
CHK DSGSCTPLINKMODE:;
```

```
%%CHK DSGSCTPLINKMODE:;%%
RETCODE = 0  操作成功

操作结果如下
------------
 远端Location标识  FE类型名称  检查结果

 189               SUP-FE      检查成功
 190               SUP-FE      检查成功
(结果个数 = 2)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1。

| 输出项名称        | 输出项解释                                                                      |
|:-------------|:---------------------------------------------------------------------------|
| 远端Location标识 | 用于表示远端Location标识。                                                          |
| FE类型名称       | 用于表示和远端Location对接的远端DSG的FE类型。远端DSG配置可以通过LST RDSG命令查询得到。                    |
| 检查结果         | 用于表示检查结果：检查成功检查失败本端或者远端DSG配置缺失奇偶建链模式下SCTP客户端的DSG数目非法奇偶建链模式下SCTP服务端的DSG数目非法 |
