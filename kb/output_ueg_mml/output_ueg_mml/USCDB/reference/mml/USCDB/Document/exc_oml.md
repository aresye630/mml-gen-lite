# 操作内存数据库（EXC OML）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，该操作直接修改内存数据库数据，操作不当可能导致用户数据被破坏。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对GMDB内存数据库的数据进行查询操作。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                      |
|:--------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MID     | 模块号    | 用于标识指定DRU/DSU的模块号，该参数必须先由ADD MODULE命令定义，然后才能在此处索引。 取值范围：1～4080 默认值：无。                                                                                                                                                                                                                                                                                     |
| OBJNAME | 对象名    | 用于标识对象树的名称。 取值范围：长度不超过127的英文字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                   |
| OBJKEY  | 主键     | 用于标识用户对应的主键。 取值范围：长度不超过1552的英文字符串。 输入原则： 如果取值中存在“'”字符，则需要输入转义字符“/q”。如果取值中存在“=”字符，则需要输入转义字符“/e”。如果取值中存在“,”字符，则需要输入转义字符“/c”。如果取值中存在“;”字符，则需要输入转义字符“/s”。如果取值中存在“\"”字符，则需要输入转义字符“/Q”。如果取值中存在“/”字符，则需要输入转义字符“//”。 默认值：无。                                                                                                                                       |
| OML     | 对象操作语言 | 用于指定完成某项GMDB内存数据库操作的OML语句。 OML语句中操作的节点，必须是“对象名”参数指定的根节点或者子节点。 取值范围：长度不超过4095的英文字符串。 输入原则： 如果OML语句中存在“'”字符，则需要输入转义字符“/q”。如果OML语句中存在“=”字符，则需要输入转义字符“/e”。如果OML语句中存在“,”字符，则需要输入转义字符“/c”。如果OML语句中存在“;”字符，则需要输入转义字符“/s”。如果OML语句中存在“\"”字符，则需要输入转义字符“/Q”。如果OML语句中存在“/”字符，则需要输入转义字符“//”。 默认值：无。 说明：当输入“对象操作语言”为“delete”时，系统只支持删除路由记录。同时“对象名”必须输入完整的路由表名，且“主键”不能为空。 |

## 使用实例

查询“模块号”为“60”，“对象名”为“PGW\_VHLR\_RANGE\_IMSI”，“主键”为“100”，“对象操作语言”为“select \* from PGW\_VHLR\_RANGE\_IMSI filter PGW\_VHLR\_RANGE\_IMSI where SYSTEM\_HLRSN/e99”的内存数据库全局数据记录，执行下面的命令：

```
EXC OML: MID=60, OBJNAME="PGW_VHLR_RANGE_IMSI", OBJKEY="*****", OML="*****";
```

```
%%EXC OML: MID=60, OBJNAME="PGW_VHLR_RANGE_IMSI", OBJKEY="*****", OML="*****";%%
```

## 输出结果说明

命令执行正常，会返回命令执行成功的信息。输出结果说明如表1所示。

| 输出项名称   | 输出项解释                  |
|:--------|:-----------------------|
| 键       | 用于返回该条目在整个目录树中的键值。     |
| 区别名     | 用于返回该条目在整个目录树中的唯一名称标识。 |
| 值       | 用于返回查询结果。              |

命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释      | 原因分析                              | 处理建议                                    |
|------:|:-----------|:----------------------------------|:----------------------------------------|
|  1855 | 执行SQL语句失败。 | 输入的参数“对象名”错误或超出了取值范围。             | 请参照“对象名”参数的取值范围说明，输入正确的取值。              |
|  2496 | 查询不到对象     | 输入的参数“对象名”在GMDB数据库中未找到。           | 请重新获取“对象名”，确保在GMDB数据库存在。                |

|  2508 | 不允许进行更新操作  | 输入的“对象操作语言”为增加、修改、删除操作。           | “对象操作语言”仅能进行查询操作，请重新输入。                 |
