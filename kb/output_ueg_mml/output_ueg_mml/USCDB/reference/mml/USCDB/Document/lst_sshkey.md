# 查询SSH Key配置（LST SSHKEY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询生成的SSH Key文件。

- 若需要查询全部SSH Key文件，请不要输入任何参数。
- 若需要查询某一模块类型的SSH Key文件，请输入“模块类型”参数。

## 注意事项

- 本命令查询结果只显示SSH Key文件名，不显示SSH Key内容。
- 对于从低版本升级上来的局点，如果低版本已采用数字签名算法（DSA）生成SSH公私钥文件，则执行此命令后报文里会存在“Key类型”为“DSA”的数据。DSA算法为不安全算法，建议使用更安全的算法重新生成SSH公私钥文件。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                             |
|:-------|:-------|:-------------------------------------------------|
| MT     | 模块类型   | 用于指示SSH Key文件的模块类型。 取值范围：PGW(PGW)DMA(DMA) 默认值：无。 |
| KT     | key类型  | 用于指示SSH Key的类型。 取值范围：RSA(RSA)ECDSA(ECDSA) 默认值：无。 |

## 使用实例

1. 查询全部SSH Key文件：

   ```
   LST SSHKEY:;
   ```

   ```
   %%LST SSHKEY:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    模块类型  Key类型   Key文件描述     公钥文件名                      私钥文件名

    PGW       RSA       NULL            id_rsa_20160607103419.pub       id_rsa_20160607103419
   (结果个数 = 1)

   ---    END
   ```
2. 查询PGW模块SSH Key文件。“模块类型”为“PGW”，“Key类型”为“RSA”：

   ```
   LST SSHKEY: MT=PGW, KT=RSA;
   ```

   ```
   %%LST SSHKEY: MT=PGW, KT=RSA;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
           模块类型  =  PGW
            Key类型  =  RSA
         Key文件描述 =  NULL
         公钥文件名  =  id_rsa_20160607103419.pub
         私钥文件名  =  id_rsa_20160607103419
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**GEN SSHKEY**命令参数说明。
