# 增加流量策略(ADD TRAFFICPOLICY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加一条流量策略记录，系统可以通过流量策略来控制LDAP（Lightweight Directory Access Protocol）用户和各FE类型对系统进行访问的消息量，以针对不同应用进行流量控制，来满足不同应用对于服务质量的要求。

**说明** 

License按TPS（Transaction Per Second）销售的流量策略功能，该版本暂不支持。

## 注意事项

- 当加载的销售模式License为按TPS（Transaction Per Second）销售，则可以添加相关应用的流量策略。
- 系统当前的License信息可以通过登录OM Portal选择“应用管理 > 应用License”查询。

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                                                                                                                     |
|:-------------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ACCESSTYPE   | 接入类型   | 用于指定访问USCDB的消息接入的接口类型。通常第三方应用通过LDAP接口访问USCDB，FE类型通过DCI接口访问USCDB。 各参数选项的含义是： LDAP(LDAP)：通过LDAP接口接入，当系统增加按LDAP用户来控制的流量策略时使用此类型。DCI(DCI)：通过DCI接口接入，当系统增加按FE类型来控制的流量策略时使用此类型。 默认值：无。                         |
| LDAPUSER     | LDAP用户 | 用于指定加入的LDAP用户名称，仅当本命令中的“接入类型”参数为“LDAP”时该参数有效。 此参数需要通过ADD LDAPUSER命令添加LDAP用户后才能在此引用。 取值范围：长度不超过128的字符串。 默认值：无。                                                                                            |
| FETYPENAME   | FE类型名称 | 用于指定加入的FE类型名称，仅当本命令中的“接入类型”参数为“DCI”时该参数有效。 此参数需要通过LOD FEPLUG命令加载FE插件后才能在此引用。 取值范围：长度不超过128的字符串。 默认值：无。                                                                                                   |
| TRAFFICVALUE | 流量值    | 用于指定增加的流量策略的配置值。表示系统允许每秒钟处理某种接入的应用的消息的数量。 该参数的配置原则是：通过本命令增加的流量策略值之和不能超过“融合数据访问事务数-每TPS”和“数据访问事务数-每TPS”这两个License项的值之和。这两个License项的信息可以通过登录OM Portal选择“应用管理 > 应用License”查询。 取值范围：0～2147483647 单位：个 默认值：无。 |

## 使用实例

1. 增加一条LDAP用户流量策略，“接入类型”为“LDAP”,“LDAP用户”为“ldap\_u1”，“流量值”为“100”。

   ADD TRAFFICPOLICY: ACCESSTYPE=LDAP, LDAPUSER="ldap\_u1", TRAFFICVALUE=100;
2. 增加一条FE类型用户流量策略，“接入类型”为“DCI”,“FE类型名称”为“SUP-FE”，“流量值”为“100”。

   ADD TRAFFICPOLICY: ACCESSTYPE=DCI, FETYPENAME="SUP-FE", TRAFFICVALUE=100;

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。
