## 命令功能

**须知** 

该命令属于高危命令，该操作若修改模块所属Pod，可能导致系统内存不足而引发Pod或虚拟机重启。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对模块的配置信息（如：模块名称）进行修改。在该命令中，系统通过参数“模块号”来唯一标识一条模块配置信息。

该命令的使用场景：当操作员添加了错误的模块信息，可通过该命令修改对应的模块配置信息。

## 注意事项

- 随意修改模块可能会导致系统产生致命错误，因此执行该命令时需要联系华为技术支持。
- PGW模块支持单配模式，即只有一个Pod的情况下，PGW模块仍然能以主备工作方式提供服务，此时备Pod名应配置为32个F。
- 输入的“模块号”是DMA模块号时，不允许执行此命令。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                                                                                                                                                            |
|:--------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MID     | 模块号     | 标识一条模块配置信息的关键字段（其取值不能被修改），用于指定需要对哪一条模块配置信息进行修改，操作员可以使用LST MODULE命令查询获得。 模块号无法通过该命令进行修改。如果模块号错误，操作员应执行RMV MODULE命令删除错误的节点信息，然后再执行ADD MODULE添加正确的模块。模块号对应的模块必须是本USCDB网元内的模块，否则命令执行失败。 取值范围：1～4080 默认值：无。                                                          |
| MT      | 模块类型    | 用于定义待修改模块的模块类型，当需要明确待修改模块时可填写该参数，该参数必须与模块号对应，否则命令执行失败，因此不推荐填写该参数。 该参数的修改原则： 模块类型无法通过该命令进行修改。如果模块类型错误，操作员应执行RMV MODULE命令删除错误的节点信息，然后再执行ADD MODULE命令添加正确的模块。 取值范围： DPU(DPU)NDF(NDF)DSG(DSG)DBG(DBG)DRU(DRU)DSU(DSU)PGW(PGW)DMA(DMA)CAG(CAG) 默认值：无。                |
| VMNAME1 | 主用Pod名称 | 用于定义待修改模块所属主用Pod的名称。 该参数的修改原则： 主用进程所在的Pod名称和备用进程所在的Pod名称不能完全相同。主用进程所在的Pod名称无法通过该命令进行修改。如果主用进程所在Pod名称错误，操作员应执行RMV MODULE命令删除错误的节点信息，然后再执行ADD MODULE添加正确的模块。 取值范围：长度不超过128的字符串。 默认值：无。 说明：修改DRU/DSU模块所在的Pod名称时，DMA模块所在的Pod名称会随着DRU/DSU模块所在的Pod名称同时修改。             |
| VMNAME2 | 备用Pod名称 | 用于定义待修改模块所属备用Pod的名称。 当备Pod名为32个F时，表示操作的模块是单机部署下的主备模块。 该参数的修改原则： 主用进程所在的Pod名称和备用进程所在的Pod名称不能完全相同。备用进程所在的Pod名称无法通过该命令进行修改。如果备用进程所在Pod名称错误，操作员应执行RMV MODULE命令删除错误的节点信息，然后再执行ADD MODULE添加正确的模块。负载均衡方式PGW模块不能修改为主备方式；主备方式PGW模块不能修改为负载均衡方式。 取值范围：长度不超过128的字符串。 默认值：无。 |
| MNAME   | 模块名称    | 用于定义待修改模块的模块名称。 该参数的修改原则： 为便于识别，模块名称应包含模块类型和相应的模块编号。如：模块号为5的DPU模块建议命名为DPU5。 取值范围：长度不超过32的字符串 默认值：无。                                                                                                                                                             |

## 使用实例

在开局场景下，由于操作失误，导致模块名称不是推荐的命名方式。例如：“模块号”为“1”的DPU模块的模块名称为“DSG\_2”。

运行以下命令，将模块名称改为“DPU1”:

```
MOD MODULE: MID=1, MNAME="DPU1";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 260047 | 模块类型不能修改。                           | 模块类型无法通过该命令进行修改。            | 模块类型无法进行修改。如果模块类型错误，操作员应执行RMV MODULE命令删除错误的节点信息，然后再执行ADD MODULE命令添加正确的模块。 |
| 260048 | 参数MID指定的模块没有配置备进程，因此更改备进程位置的操作不能执行。 | “模块号”指定的NDF模块没有配置备进程。       | 指定的NDF模块没有配置备进程，因此不能更改备进程位置。                                              |
