## 命令功能

**须知** 

该命令属于高危命令，删除模块可能导致致命错误。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在USCDB网元内删除一个模块。

该命令的使用场景：

- 存在冗余模块。
- 已添加模块的配置信息错误，且不能通过**MOD MODULE**命令修改。如：模块的模块号、模块类型错误。

## 注意事项

- 除了在开局初始配置时，其他情况下随意删除模块可能会导致系统产生致命错误，因此执行该命令时需要联系华为技术支持。
- 要删除的模块必须存在且未被使用，否则命令无法执行。其中模块是否被使用可以在USCDB MML命令界面通过命令查询：
  - NDF模块可通过执行**LST BACKUP**命令查询。
  - DSU、DRU模块可通过执行**LST NODE**命令查询。

  **说明** 

  PGW、DBG、CAG模块可以直接通过命令删除。
- 当删除的模块为DSG时，且该DSG被设置成链路中心时，不允许删除此模块。可以使用**LST DSGLINKCTRL**命令查询DSG链路中心配置。
- 输入的是DMA的“模块号”和“模块类型”时，不允许执行此命令。
- 执行该命令时，输入的“模块号”和“模块类型”状态为“隔离”，删除该模块同时会删除该模块上的数据。
- 执行该命令后，需要执行**CLR MSPROCESS**命令清除CMF缓存中残留的进程。可通过执行**DSP SERVICEINST**命令查询模块号和进程ID的对应关系。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                    |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MID    | 模块号    | 标识一条模块配置信息的关键字段，用于指定需要删除哪一条模块配置记录，该参数可以使用LST MODULE命令查询获得。 取值范围：1～4080 默认值：无。 说明：删除的模块号为DRU类型的模块时，会同时删除模块号为DRU模块号加2对应的DMA模块。删除的模块号为DSU类型的模块时，会同时删除模块号为DSU模块号加2对应的DMA模块。 |
| PHA    | 主用/备用  | 当待删除模块为主备工作状态时，用于指示系统删除主用工作方式还是备用工作方式的模块。 该参数的删除原则： 若删除“主用”工作方式的模块时，备用工作方式的模块也会一并删除。 取值范围： 主用备用 默认值：无。                                                                  |
| MT     | 模块类型   | 用于定义待删除模块的模块类型。该参数必须与模块号对应，否则命令执行失败。 取值范围：DPU(DPU)NDF(NDF)DBG(DBG)DSG(DSG)DRU(DRU)DSU(DSU)PGW(PGW)DMA(DMA)CAG(CAG) 默认值：无。                                               |

## 使用实例

在开局场景下，由于误操作，操作员额外添加了一个模块，此时需要删除该模块。冗余模块的模块号为1。

1. 登录“USCDB MML命令” 界面，执行**LST MODULE**命令查询模块号为1的模块所对应的模块类型。查询的模块类型为DSU。
2. 登录“USCDB MML命令” 界面，执行**LST NODE**命令查询DSU模块是否已配置。

   - 是 => 3
   - 否 => 4
3. 执行**RMV NODE**命令删除已配置的DSU模块。
4. 执行**RMV MODULE**命令删除模块。例如：删除模块号为“1”，模块类型为“DSU”的模块。

   ```
   RMV MODULE: MID=1, MT=DSU;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                    | 原因分析                             | 处理建议                                                                                        |
|-------:|:-------------------------|:---------------------------------|:--------------------------------------------------------------------------------------------|
| 260045 | 该模块没有备进程。                | DPU模块没有添加备用进程。                   | 可通过执行ADD MODULE添加备用进程。                                                                      |
| 260046 | 该模块不存在。                  | 输入的“模块号”取值在系统中不存在或与输入的“模块类型”不对应。 | 执行命令LST MODULE查询系统中已存在的模块号和模块类型。重新输入参数“模块号”和“模块类型”取值，确保在查询结果中存在且对应。                         |
| 260057 | 该模块已经开启了FTP备份功能。         | 该模块已经开启了FTP备份功能。                 | 执行命令MOD BACKUP，参数“备份数据保存方式”改为“NOSTOSERVER(不保存到服务器)”或“SFTPSERVER(保存到SFTP服务器)”，然后重新执行本命令删除模块。 |

| 330022 | 只有DPU模块允许单独删除备进程。        | DPU以外的模块不允许删除备进程。                | DPU以外的模块不允许删除备进程。                                                                           |
| 260327 | 不能单独操作DMA模块。             | 执行该命令时输入的是DMA的“模块号”和“模块类型”。      | 执行LST MODULE查询已有的模块信息，重新输入非DMA模块的模块号和模块类型执行该命令。                                             |
