# 激活SCTP链路(ACT DSGSCTP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令属于高危命令，该操作将激活SCTP链路。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于激活一条SCTP链路。目前仅用于测试SCTP链路状态。

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识    | 参数名称         | 参数说明                                       |
|:--------|:-------------|:-------------------------------------------|
| MID     | DSG模块号       | 用于指定需要激活链路的DSG模块号。 取值范围：1～2047 默认值：无。      |
| RLOCID  | 远端Location标识 | 用于指定需要激活链路的远端Location标识。 取值范围：1～512 默认值：无。 |
| RDSGMID | 远端DSG模块号     | 用于指定需要激活链路的远端DSG模块号。 取值范围：1～2047 默认值：无。    |

## 使用实例

激活一条链路，“DSG模块号”为“2”，“远端Location标识”为“6”，“远端DSG模块号”为“3”，执行命令如下：

```
ACT DSGSCTP: MID=2, RLOCID=6, RDSGMID=3;
```
