# 查询配置开关状态(LST CMSTS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询当前网元配置的格式化开关状态，设定标记，网元状态，联机设定报文是否显示成功记录、是否在网管上显示。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询配置开关状态:

`LST CMSTS:;`

```
%%LST CMSTS:;%%
RETCODE = 0  操作成功

操作结果如下
------------
    格式化开关状态  =  打开格式化开关
          设定标记  =  联机
          网元状态  =  正常模式
是否显示成功的记录  =  显示成功记录
  是否在网管上显示  =  在网管上显示
(结果个数 = 1)

---    END
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。输出结果说明如表1所示。

命令执行异常，请联系华为技术支持处理。

| 输出项名称     | 输出项解释                                                                                                                                                                                      |
|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 格式化开关状态   | 格式化开关的状态。 取值范围： “打开格式化开关”：格式化开关打开，系统能进行格式化操作。“关闭格式化开关”：格式化开关关闭，系统不能进行格式化操作。                                                                                                                |
| 设定标记      | 联机设定标记。 取值范围： “联机”：系统处于联机状态，执行的配置命令结果会实时同步到主机进程。“脱机”：系统处于脱机状态下，执行的配置命令结果不会同步到主机进程。                                                                                                         |
| 网元状态      | 网元的配置回退事务状态。 取值范围： “正常模式”：系统处于正常模式，联机状态下执行的配置命令结果会立刻设定到主机进程，立即生效，无法回退。“事务模式”：系统处于事务模式，联机状态下执行的配置命令结果只保存在OMU数据库中，不会设定到主机进程，只有提交事务后才会设定到主机进程。“试运行模式”：系统处于试运行模式，联机状态下执行的配置命令结果已经设定到主机进程，并且生效。 |
| 是否显示成功的记录 | 是否显示联机设定成功的记录。 取值范围： “显示成功记录”：显示联机设定成功的数据记录。“不显示成功记录”：不显示联机设定成功的数据记录。                                                                                                                      |
| 是否在网管上显示  | 是否在网管上显示。 取值范围： “在网管上显示”：网元在网管上显示。“不在网管上显示”：网元不在网管上显示。                                                                                                                                     |
