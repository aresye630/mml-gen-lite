# 查询定时加载配置(LST DATALODTIMETASK)

- 注意事项

- 参考信息

## 命令功能

该命令用于查询一个冷备USCDB从第三方服务器加载备份数据的定时加载任务的配置信息。

- 若要查询全部FE类型的定时加载任务的配置信息，请不要输入任何参数。
- 若要查询某个FE类型的定时加载任务的配置信息，请输入“FE类型”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                  |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------|
| FETYPE | FE类型   | 可选必选说明：可选参数 参数含义：用于指示系统按照FE类型来查询定时加载任务信息；若不输入，则表示所有的FE类型。 取值范围：长度不超过128位字符组成的字符串。 默认值：无。 配置原则：此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。 |

## 使用实例

1. 若要查询全部FE类型的定时加载任务的配置信息。

   ```
   LST DATALODTIMETASK:;
   ```

   ```
   %%LST DATALODTIMETASK:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    FE类型  定时加载开始的小时  定时加载开始的分钟  定时加载源文件所属LocationID  定时加载超时周期  第三方服务器上定时加载源文件最大份数  定时加载开关

    GU-HLR   3                  2                   1                             120               3                                      开              
    SUP-FE   1                  10                  1                             120               3                                      开                      
   (结果个数 = 2)

   ---    END
   ```
2. 若要查询“FE类型”为“SUP-FE”的定时加载任务的配置信息。

   ```
   LST DATALODTIMETASK: FETYPE="SUP-FE";
   ```

   ```
   %%LST DATALODTIMETASK:FETYPE="SUP-FE";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
                                 FE类型  =  SUP-FE
                     定时加载开始的小时  =  1
                     定时加载开始的分钟  =  10
           定时加载源文件所属LocationID  =  1
                       定时加载超时周期  =  120
   第三方服务器上定时加载源文件最大份数  =  3
                           定时加载开关  =  开
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD DATALODTIMETASK**命令的参数说明。
