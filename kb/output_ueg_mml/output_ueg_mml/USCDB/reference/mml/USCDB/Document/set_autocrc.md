# 设置是否停止最近一次自动CRC校验(SET AUTOCRC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于设置是否停止最近一次的凌晨自动CRC校验。

在数据割接时，需要支持全天不中断业务发放，当跨越凌晨3:00时，系统自动CRC校验可能会导致业务配置失败或上报“ALM-4756 数据表自动CRC校验错误”告警。此时，操作人员可以提前使用本命令停止最近的一次自动CRC校验。

## 注意事项

使用本命令停止最近一次凌晨自动CRC校验，可能会导致不能及时发现数据的不一致性，请在华为技术支持人员的指导下操作。

使用本命令，停止单表的最近一次自动CRC时，可能会恢复之前因该表不一致而上报的“ALM-4756 数据表自动CRC校验错误”告警。

## 参数说明

| 参数标识   | 参数名称          | 参数说明                                                                                                                   |
|:-------|:--------------|:-----------------------------------------------------------------------------------------------------------------------|
| STPCRC | 停止最近一次自动CRC校验 | 标识是否停止最近一次的凌晨自动CRC校验。 取值说明：“YES(是)”：表示停止最近一次凌晨3:00的自动CRC校验。“NO(否)”：表示不停止最近一次凌晨3:00的自动CRC校验。 默认值：无。                     |
| TID    | 表号            | 仅当本命令中的“停止最近一次自动CRC校验”参数选择为“YES(是)”时该参数有效。标识在最近一次的自动CRC校验中，仅停止该业务表的校验。 取值范围：下拉列表中给出的所有表。 默认值：无。 配置原则：若不输入，则表示停止所有表的校验。 |

## 使用实例

设置停止最近一次自动CRC校验：

```
SET AUTOCRC: STPCRC=YES;
```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，请联系华为技术支持处理。
