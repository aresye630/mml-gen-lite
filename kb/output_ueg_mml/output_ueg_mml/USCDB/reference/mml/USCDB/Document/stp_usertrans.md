## 命令功能

**须知** 

该命令属于高危命令，执行该命令会停止正在执行的用户数据迁移任务。因此执行该命令前，需要与华为技术支持确认后才可以实施。

用户数据迁移过程中，可能会导致DSU、DSG资源紧张，例如CPU升高等。该命令用于停止某个正在执行的用户数据迁移任务。

## 注意事项

- 同一时间只允许一个用户数据执行任务迁移。
- 为了保证数据一致性，DMA收到停止任务请求后，会继续完成本轮正在处理的用户数据，停止迁移任务将在下一轮生效。
- 执行**STP USERTRANS**命令成功后，本次扩容或缩容迁移结束，但隔离的DSU并没有恢复，新的开户消息不会均衡到隔离DSU Cluster中。需要手工执行**MOD SEGSTATE**命令，恢复隔离模块的状态后，所有DSU业务才可恢复。
- 该命令不允许进行批操作。

## 参数说明

无。

## 使用实例

停止用户数据迁移任务。

```
STP USERTRANS:;
```

执行结果如下：

```
%%STP USERTRANS:;%%
RETCODE = 0  操作成功

操作结果如下
------------------------
DMA模块号    状态
1095	     成功
1096	     成功
(结果个数 = 2)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称   | 输出项解释                                                     |
|:--------|:----------------------------------------------------------|
| DMA模块号  | 用于返回待停止用户数据迁移任务的模块号。                                      |
| 状态      | 用于返回待停止用户数据迁移任务的处理结果： 成功失败超时超时时长为20秒，超时后可重启2次（即总超时时长60秒）。 |

|   1952 | 已有停止迁移任务正在执行。 | 已有停止迁移任务正在执行，系统每次仅能执行一个停止任务。         | 无需处理。                                                                                               |
