# 设置远端加载开关(SET RLOADCFG)

## 命令功能

**须知** 

- 该命令属于高危命令，该操作用于设置远端加载开关，可能导致模块从远端加载源加载数据。请谨慎操作，操作前请务必联系华为技术支持工程师确认。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于设置远端加载开关，当本地为容灾局且处于非容灾接管状态，或当本地为主用局且业务类型不支持周期性备份和记录Redo日志时，可以通过本命令打开远端加载数据开关。

## 注意事项

- 相同“业务类型”下，从远端局点加载数据时只能配置一个远端加载源：
  - 若目的Location不可用，执行本命令前需要重新配置远端Location。
  - 执行本命令在相同“业务类型”下配置新的“远端Location标识”，则新的配置记录会覆盖上一个已配置的远端加载记录。
- 远端加载开关打开，系统上报“ALM-12074 远端加载开关已打开”告警。
- 远端加载开关打开，以下两种场景时远端加载失败，此时上报“ALM-12007 节点加载失败”告警。
  - 若容灾倒换后本局切换为主用局且业务类型支持周期性备份或记录Redo日志。
  - 节点处于接管状态。

## 参数说明

| 参数标识        | 参数名称         | 参数说明                                                                                                                                                                      |
|:------------|:-------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 业务类型         | 可选必选说明：必选参数。 用于指定系统给哪个业务类型配置远端加载信息。该参数由LOD FEPLUG命令执行后自动生成，可通过LST FEPLUG命令进行查询。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                                                         |
| RLOCID      | 远端Location标识 | 可选必选说明：必选参数。 用于指定本端网元设备对应的远端网元设备的Location标识，可以设置为虚拟远端Location标识，也可以根据远端Location配置信息设置。一个远端Location标识唯一对应一个远端网元。 取值范围： 1～512 默认值： 无。 配置原则：该参数必须在ADD RLOCATION命令配置后才能在此处引用。 |
| RLOADSWT    | 远端加载开关       | 可选必选说明：必选参数。 用于指定远端加载开关状态。 取值范围： OFF(关)ON(开) 默认值：无。 配置原则：无。                                                                                                               |

## 使用实例

打开“SUP-FE”的“远端加载开关”，其中“远端Location标识”为“82”：

```
SET RLOADCFG: SERVICETYPE="SUP-FE", RLOCID=82, RLOADSWT=ON;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释                | 原因分析                                                       | 处理建议                                                                         |
|------:|:---------------------|:-----------------------------------------------------------|:-----------------------------------------------------------------------------|
|  2725 | 在容灾接管状态下不允许执行远端加载操作。 | 本局为容灾接管状态，不允许执行远端加载操作。                                     | 执行DSP CLUSTER命令查询本局为主用局还是容灾局以及当前的接管状态，确认本局处于非容灾和接管状态时，重新执行本命令。               |
|  2726 | 远端加载配置已存在。           | 当前“业务类型”下已存在一个相同的“远端Location标识”。                           | 重新执行本命令，确保相同“业务类型”下，所配置的“远端Location标识”不同。已配置的“远端加载开关”可以通过执行LST RLOADCFG命令查询。 |
|  2727 | 远端加载功能已关闭。           | 当前“业务类型”下配置的“远端Location标识”对应的“远端加载开关”参数取值为“OFF(关)”，不能重复关闭。 | 执行LST RLOADCFG命令查询当前业务类型下的“远端加载开关”状态，如已关闭，无需重复执行。                            |
|  2729 | RLOCID与本局非容灾关系。      | 配置的“远端Location标识”所在局和本局非容灾关系。                              | 确认“远端Location标识”所在局和本局为容灾关系后重新执行本命令。                                         |
|  2730 | 该业务类型不支持在主用局进行远端加载。  | 指定的“业务类型”不支持在主用局进行远端加载。                                    | 请联系华为技术支持处理。                                                                 |
