## 命令功能

该命令用于升级物理数据库或者安装数据库软件补丁。

## 注意事项

- 在升级时，升级系统会自动执行该命令升级物理数据库。安装数据库软件补丁时，需要参考相应升级、补丁安装指导书进行操作。其他场景严禁执行该命令。
- PT数据库升级到ClickHouse数据库需要把PT数据库里面的数据迁移到ClickHouse数据库中，如果迁移失败会上报ALM-11015 物理库升级数据迁移失败告警。
- 当系统判断PT数据库的数据已成功转换为ClickHouse的数据，并且结束观察期后，会自动删除冗余的物理库相关数据，如果PT数据库关联目录（如/opt/USCDB\_APP/PROTON）下没有文件，则默认为删除成功。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                      |
|:-----------|:-------|:----------------------------------------------------------|
| PKGNAME    | 升级包名称  | 用于指定升级包名称。可通过在“CSP MML命令”界面使用LST PKG命令查询。                 |
| FETYPENAME | 网元类型   | 用于指定升级的网元类型。取值范围取决于当前安装的网元。可通过在“CSP MML命令”界面执行LST ME命令查询。 |
| OLDVER     | 旧插件包版本 | 用于指定升级前插件包版本。可通过LST FEPLUG命令查询。                           |
| NEWVER     | 新插件包版本 | 用于指定目标版本的插件包版本。可通过LST FEPLUG命令查询。                         |

## 使用实例

升级时，执行本命令对物理数据库进行升级操作，以“SUP-FE”网元类型为例：

```
UPG DB: PKGNAME="SUP-FE_V300R005C01SPC100_UPG.tar", FETYPENAME="SUP-FE", OLDVER="V300R005C01", NEWVER="V300R005C01SPC100";
```
