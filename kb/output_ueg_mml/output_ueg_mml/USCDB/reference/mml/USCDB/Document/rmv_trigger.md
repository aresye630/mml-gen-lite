# 删除触发器(RMV TRIGGER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，删除触发器会造成对端设备接收不到订阅通知。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除触发器记录。

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识         | 参数名称    | 参数说明                                     |
|:-------------|:--------|:-----------------------------------------|
| SUBID        | 订阅ID    | 用于标识一条数据订阅配置记录。操作员可以使用LST TRIGGER命令查询获得。 |
| TRIGGERTPLID | 触发器模板ID | 用于标识一条触发器模板记录。操作员可以使用LST TRIGGER命令查询获得。  |

## 使用实例

删除指定触发器记录，该“订阅ID”为“1”，“触发器模板ID”为“1”。

```
RMV TRIGGER: SUBID=1, TRIGGERTPLID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释     | 原因分析                            | 处理建议                                                                 |
|-------:|:----------|:--------------------------------|:---------------------------------------------------------------------|
| 275016 | 指定的记录不存在。 | 触发器记录中不存在指定“订阅ID”和“触发器模板ID”的记录。 | 先执行LST TRIGGER命令查询触发器记录中的“订阅ID”和“触发器模板ID”，再重新执行本命令，确保要删除的记录存在于查询结果中。 |
