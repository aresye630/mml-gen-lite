# 设置系统序列号(SET SYSNO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，修改系统序列号会造成PGW中已经登录的操作员全部无法执行命令。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在开局场景下设置当前局点的系统序列号，唯一标识该系统。

## 注意事项

执行本命令后，必须执行以下步骤，保证OMU与PGW Web LMT上设置的信息保持一致：

1. 在“USCDB MML命令” 界面，执行**LST INSP: INSPT=PGW, INSPN=MVNOSWITCH;**查询“MVNO 开关”参数的取值。
   - 当“MVNO 开关”取值为“0”时，执行步骤2。
   - 当“MVNO 开关”取值为“1”时，执行步骤3。
2. 登录PGW Web LMT，在系统管理下执行**ADD SYSHLRSN**命令，且**ADD SYSHLRSN**命令中的“系统HLR序列号”参数必须与本命令中的“系统序列号”参数的值保持一致，“状态”参数的值必须为“MASTER（主用HLR）”。
3. 登录PGW Web LMT，在系统管理下执行**ADD SYSNO**命令，且**ADD SYSNO**命令中的“系统序列号”参数必须与本命令中的“系统序列号”参数的值保持一致，“状态”参数的值必须为“MASTER（主用）”。

该命令不允许进行批操作。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                      |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SYSTEMNO | 系统序列号  | 用于定义系统的序列号，全局唯一。 取值范围：1～255 默认值：无。                                                                                                                                                                                                                                                                                        |
| CNFM     | 确认     | 可选必选说明：可选参数 参数含义：用于确认是否强制设置“系统序列号”。 取值范围： YES(是)：表示不管当前网元是否已经设置“系统序列号”，此次都会强制设置成功。NO(否)：表示如果当前网元没有设置“系统序列号”，则本次设置成功。如果当前网元已经设置了“系统序列号”，则本次设置无效并返回错误码“275449 系统序列号已设置”。 默认值：NO(否) 配置原则：“系统序列号”为网元唯一标识，如果随意修改会造成FE和BE间对接失败，从而导致致命的业务影响，因此请确保在非商用局点进行修改设置，如新建部署网元在调测阶段设置“系统序列号”与规划取值不一致，需重新修改为规划的取值，则可将该参数设置为“YES”，商用局点禁止修改。 |

## 使用实例

在开局场景下，设置当前局点的“系统序列号”为“10”，“确认”为“YES(是)”：

```
SET SYSNO: SYSTEMNO=10, CNFM=YES;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释     | 原因分析             | 处理建议                                                                                                        |
|-------:|:----------|:-----------------|:------------------------------------------------------------------------------------------------------------|
| 275449 | 系统序列号已设置。 | 当前网元已设置了“系统序列号”。 | “系统序列号”为网元唯一标识，如果随意修改会造成网元间对接失败，从而导致致命的业务影响，因此请确保在非商用局点进行修改设置。如确认需要修改当前网元的“系统序列号”，请重新执行本命令，将参数“确认”设置为“YES”。 |
