# 修改FTP用户(MOD FTPUSER)

## 命令功能

**须知** 

该命令属于高危命令，修改FTP用户可能会导致该FTP用户失效。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对数据库中的一条FTP用户数据记录进行修改或调整。在该命令中，系统通过“用户类型”、“用户名”来唯一标识一条用户数据记录。

## 注意事项

- 如果修改的是用户的密码，则参数“密码”和“确认密码”都必须指定。
- 该命令不允许进行批操作。
- 密码长期使用会增加被盗窃和破解的风险，而且使用的时间越长，被盗窃和破解的风险越高。定期修改密码可以有效防范这种情况的发生，因此强烈建议您定期修改密码。

## 参数说明

|:------------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USERTYPE    | 用户类型   | 标识一个FTP用户的关键字段之一，用于指定FTP用户的类型。 取值范围：PROV(业务)：表示该用户为营帐功能的FTP用户。DATAMTN(维护)：表示该用户为数据维护功能的FTP用户。                                                                                                                                                                                                                                                                                                                                                                                 |
| USERNAME    | 用户名    | 标识一个FTP用户的关键字段之一，用于指定对哪个FTP用户的配置信息进行修改。操作员可以使用LST FTPUSER查询获取。 取值范围：长度不超过31的字符串。                                                                                                                                                                                                                                                                                                                                                                                              |
| PWD         | 密码     | 用于指定待修改密码的FTP服务器用户修改后的密码。 密码区分大小写，其复杂度需同时满足下列条件：密码必须至少包含以下四个类别中的三类：英文大写字母。英文小写字母。数字：0～9。特殊字符：~ ! # % ^ * ( ) _ - + [ ] { } | < > . ?。 不允许使用三个或三个以上连续的字母或数字（例如：ABC、123）。密码不能和用户名或者用户名的逆序一样，且不能包含用户名或者用户名的逆序。不允许使用三个或三个以上连续的相同字符（例如：AAA）。密码长度最短8个字符。密码的第一个字符必须是字母。 取值范围：长度不超过31的字符串。                                                                                                                                                                                            |

| WORKPATH    | 工作路径名称 | 根据插件包配置的FTP用户工作路径读取，读取到的工作路径名称对应的具体路径可通过LST FTPPATHCFG命令查询。用于指定FTP用户的工作路径，该参数为联想参数列表，不能手动输入。 取值范围：UPLOAD：FTP用户用于上传批处理文件的工作路径。DOWNLOAD：FTP用户进行下载批处理结果文件的工作路径。GENFTP：FTP用户用于上传或下载批处理文件的工作路径。REDUNDANCE：FTP用户用于下载容灾文件的工作路径。DOWNLOADEXPORTFILE：“用户类型”取值“DATAMTN(维护)”时选择“DOWNLOADEXPORTFILE”，表示DMA模块提供的下载导出文件的工作路径。DOWNLOADEXPLOGFILE：“用户类型”取值“DATAMTN(维护)”时选择“DOWNLOADEXPLOGFILE”，表示DMA模块提供的下载导出日志文件的工作路径。FE插件包中配置的指定目录：FE插件配置的工作路径。配置的工作路径名称要求为长度不超过127的字符串，不支持特殊字符：“，”、“'”和“；”。 |
| PERMISSION  | 权限     | 用于指定FTP用户的权限。有上传、下载、上传和下载三种权限。 取值范围：全部选中全部清空全部灰化UPLOAD(上传)DOWNLOAD(下载)                                                                                                                                                                                                                                                                                                                                                                                                        |

## 使用实例

1. 修改FTP用户。将“用户类型”为“PROV”、“用户名”为“test”的用户“密码”修改为“ab12CD34#56”。

   ```
   MOD FTPUSER: USERTYPE=PROV, USERNAME="test", PWD="*****", CFM="*****";
   ```

**说明** 

- 密码在命令行输入区域显示为\*\*\*\*\*。
- 执行本命令时，若“密码”取值为“ab12CD34#56”，执行结果会返回“260566”错误码。
