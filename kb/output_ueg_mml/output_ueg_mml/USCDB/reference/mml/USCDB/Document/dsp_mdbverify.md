# 显示内存库校验结果(DSP MDBVERIFY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于显示内存库校验结果。内存库校验可分为局内校验、局间（主用BE和容灾BE）校验和云部署场景下的BE局点间校验。

该命令主要在执行升级、扩容、容灾倒换、主备倒换等重大操作前使用。在现网局点中由于承载网故障、节点异常等场景，容易导致节点间的数据产生不一致，尤其是主用局与容灾局之间。因此在执行升级、扩容、容灾倒换、主备倒换等重大操作前，需要执行本命令来确认主用局、容灾局数据以及局内节点间数据的一致性。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                 |
|:------------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MDBVT       | 校验类型      | 用于查询如下校验类型的内存库校验结果： INNER(局内)：重置局内水平正向校验、局内水平反向校验、局内正向路由校验、局内反向路由校验。OUTERREDUN(容灾局间)：重置局间用户数据正向校验、局间用户数据反向校验、局间全局数据正向校验、局间全局数据反向校验。OUTERCLOUD(云部署局间)：重置云部署全局数据正向校验、云部署全局数据反向校验、云部署用户全局路由正向校验、云部署用户全局路由反向校验。                                                                                                                                          |
| MDBVR       | 校验状态      | 用于查询如下校验状态的内存库校验结果： RUNR(运行中的校验结果)LASTFR(上次完成的校验结果)                                                                                                                                                                                                                                                                                                  |
| UDT         | 用户数据类型    | 用于查询如下用户数据类型的内存库校验结果：USERDATA(用户数据)GBLDATA(局间全局数据)GLBROUTEDATA(局间全局路由数据) 说明：当“校验类型”为“OUTERREDUN（容灾局间）”时，如果查询全局数据的局间正向校验或局间反向校验的结果，本参数选择为“GBLDATA(局间全局数据)”。当“校验类型”为“OUTERREDUN（容灾局间）”时，如果查询全局路由数据的局间正向校验或局间反向校验的结果，本参数选择为“GLBROUTEDATA(局间全局路由数据)”。当“校验类型”为“OUTERCLOUD（云部署局间）”时，如果查询云部署局间全局路由数据正向校验或云部署局间全局路由数据反向校验的结果，本参数选择为“GLBROUTEDATA(局间全局路由数据)”。 |
| CID         | Cluster标识 | 用于查询具体Cluster标识的内存库校验结果。                                                                                                                                                                                                                                                                                                                             |
| SERVICETYPE | 业务类型      | 用于指示系统需要按照哪个业务类型来查询校验结果，此参数在USCDB下通过LOD FEPLUG命令加载FE插件后在此引用；若不输入，则表示查询所有业务类型所对应的校验结果。                                                                                                                                                                                                                                                                |

## 使用实例

进行升级操作前，查询上次完成的内存库校验结果，执行命令如下：

```
DSP MDBVERIFY: MDBVT=INNER, MDBVR=LASTFR;
```
