# 启动软参CRC校验(STR SPCRC)

## 命令功能

该命令为维护类命令，用于校验所有未生效软参信息，或在重启软参所在模块使所有软参一致后，通过该命令手动恢复ALM-10023 系统软参修改未生效告警。

## 注意事项

- 该命令下发给所有状态正常模块，各模块根据请求消息返回本模块的未生效软参信息。
- 如果没有未生效的软参，则向最小状态正常的DSG模块下发告警恢复请求，由该模块向CSP上报ALM-10023 系统软参修改未生效故障恢复告警。
- 存在状态异常的主用模块，直接返回模块无效状态记录，不上报告警恢复请求。
- 备用模块故障不影响上报告警恢复请求。

## 参数说明

无。

## 使用实例

1、如果存在未生效的软参，显示如下:

```
%%STR SPCRC:;%%
RETCODE = 0  操作成功

软参当前值和配置值不一致结果
----------------------------
 模块号  模块类型  软参类型  软参名称         软参配置值  软参当前值  网元类型
  
 82      DSG       FE        EXTENDMEMSIZE    201         200         USCDB    
 46      DRU       FE        GDRUIMDBS        1536        512         SUP-FE    
(结果个数 = 2)

---    END
```

2、存在31，79号模块故障时，显示如下：

```
%%STR SPCRC:;%%
RETCODE = 332612  操作部分失败。

软参当前值和配置值不一致结果
----------------------------
 模块号  模块类型  软参类型  软参名称  软参配置值  软参当前值  网元类型

 31      DSG       NULL      NULL      NULL        NULL        NULL   
 79      NDF       NULL      NULL      NULL        NULL        NULL     
(结果个数 = 2)

---    END
```

3、不存在未生效软参，显示如下：

```
%%STR SPCRC:;%%
RETCODE = 0  操作成功

No matching result is found
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释   | 原因分析                    | 处理建议                                  |
|-------:|:--------|:------------------------|:--------------------------------------|
| 332612 | 操作部分失败。 | 命令请求下发给主机模块，部分模块异常没有响应。 | 执行RST MODULE命令复位故障模块。如仍未解决，请联系华为技术支持。 |
