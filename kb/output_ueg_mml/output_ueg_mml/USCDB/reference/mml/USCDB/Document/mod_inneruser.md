# 修改局内FTP用户密码(MOD INNERUSER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，修改用户密码将导致FTP服务重启，导致文件上传、下载失败。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改局内FTP用户的密码。在该命令中，系统通过“用户名”来唯一标识一条局内FTP用户数据记录。

该命令的使用场景：该帐号仅用于PGW/DMA内部的FTP传输，不作其他用途，当需要修改密码时，使用本命令修改。

## 注意事项

- 修改用户密码将导致FTP服务重启，导致文件上传、下载失败。以下场景严禁执行该命令：
  - 系统正在执行批操作任务。
  - 系统正在执行数据导入任务。
  - 系统正在执行数据导出任务。
  - 系统正在执行数据维护任务。
- 密码长期使用会增加被盗窃和破解的风险，而且使用的时间越长，被盗窃和破解的风险越高。定期修改密码可以有效防范这种情况的发生，因此强烈建议您定期修改密码。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                        |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USERNAME | 用户名    | 可选必选说明：必选参数 参数含义：用于指定的局内FTP用户名。 取值范围：长度不超过31位的字符串 默认值：无。 配置原则：无                                                                                                                                                                                                                             |
| OLD      | 旧密码    | 可选必选说明：必选参数 参数含义：用于指定局内FTP用户的旧密码。 取值范围：8～30位的字符串。 默认值：无。 配置原则：无                                                                                                                                                                                                                             |
| PWD      | 密码     | 可选必选说明：必选参数 参数含义：用于指定局内FTP用户的新密码。 默认值：无。 配置原则： 密码区分大小写，其复杂度需同时满足下列条件：密码至少包含以下四个类别中的三类：英文大写字母。英文小写字母。数字：0～9。特殊字符：~ ! # % ^ * ( ) _ - + [ ] { } | < > . ?。 密码的第一个字符必须是字母。不允许使用三个或三个以上连续的字母或数字（例如：ABC、123）。密码不能和用户名或者用户名的逆序一样，且不能包含用户名或者用户名的逆序。不允许使用三个或三个以上连续的相同字符（例如：AAA）。密码长度最短8个字符，最长30个字符。 |
| CFM      | 确认密码   | 可选必选说明：必选参数 参数含义：用于指定局内FTP用户的确认密码，该字符串必须与新密码相同。 取值范围：8～30位的字符串。 默认值：无。 配置原则：无                                                                                                                                                                                                               |

## 使用实例

1. 修改局内FTP用户的密码，“用户名”为“pgw”，“旧密码”为“\*\*\*\*\*”，“密码”为“\*\*\*\*\*”，“确认密码”为“\*\*\*\*\*”。

   ```
   MOD INNERUSER: USERNAME="pgw", OLD="*****", PWD="*****", CFM="*****";
   ```

**说明** 

密码在命令行输入区域显示为\*\*\*\*\*。

该命令执行正常，会返回命令执行成功的提示信息。
