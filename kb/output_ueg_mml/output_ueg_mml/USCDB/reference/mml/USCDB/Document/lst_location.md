# 查询Location信息(LST LOCATION)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询Location信息：

- 若需要查询全部Location信息记录的概要信息，请不要输入任何参数。
- 若需要查询某条Location信息记录的详细信息，请输入“Location标识”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                       |
|:-------|:-----------|:-----------------------------------------------------------|
| LOCID  | Location标识 | 用于指示系统需要按照哪个Location标识来查询Location信息；若不输入，则表示所有的Location标识。 |

## 使用实例

在维护场景下，查询Location配置信息:

LST LOCATION:;

```
%%LST LOCATION:;%%
RETCODE = 0  操作成功

操作结果如下
------------
Location标识  =  6
    网元类型  =  USCDB
(结果个数 = 1)

---    END
```

## 输出结果说明

| 输出项名称      | 输出项解释                      |
|:-----------|:---------------------------|
| Location标识 | 用于返回一个Location标识，唯一标识一个网元。 |
| 网元类型       | 用于返回本Location的网元类型。        |
