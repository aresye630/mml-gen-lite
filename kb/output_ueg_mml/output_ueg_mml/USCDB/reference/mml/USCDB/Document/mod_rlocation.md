# 修改远端Location信息(MOD RLOCATION)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，如果远端Location参数配置不合理，将导致FE访问BE的业务失败。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对配置数据库中的一条远端网元设备的Location信息记录的某些参数进行修改或调整。

## 注意事项

修改远端网元设备的Location信息可能会影响本端网元设备对远端设备访问关系和顺序。

该命令不允许进行批处理操作。

## 参数说明

| 参数标识      | 参数名称         | 参数说明                                                                                                                                                                                            |
|:----------|:-------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RLOCID    | 远端Location标识 | 可选必选说明：必选参数。 表示远端网元设备的Location标识。用于指定需要对哪一个远端网元设备的参数进行修改或调整，用户可以通过LST RLOCATION命令查询获得。 取值范围： 1～512                                                                                              |
| RMT       | 远端网元类型       | 可选必选说明：可选参数。 用于指定本端网元设备对应的远端网元设备的类型。 如果修改的远端Location信息对应的“远端网元类型”在分组中，且分组开关打开，则必须输入该参数，否则可以不输入。 用户可通过LST SERVICEGROUP命令查看对应业务类型是否在分组中，再执行LST GROUPSWITCH命令查看分组开关是否打开。 取值范围：长度不超过128的字符串。 默认值：无。 |
| LP        | 位置ID优先级      | 可选必选说明：可选参数。 用于指定远端网元设备的Location优先级。 该参数的配置原则是：设置的优先级值越小，则其优先级越高。如果一个本端网元设备对应多个远端网元设备，则远端网元设备会按照优先级从高到低的顺序选择远端网元设备进行访问。 取值范围： 1～512                                                             |
| REDUNFLAG | 是否容灾关系       | 可选必选说明：可选参数。 用于指定本端网元设备和远端网元设备是否存在容灾关系。 取值范围： YES(是)：表示本端网元设备和远端网元设备之间存在容灾关系。 NO(否)：表示本端网元设备和远端网元设备之间不存在容灾关系。                                                                                   |

## 使用实例

某容灾局点根据需要修改远端设备的Location信息配置。“远端Location标识”为“3”，“远端网元类型”为“SUP-FE”，“位置ID优先级”值为“1”。

```
MOD RLOCATION: RLOCID=3, RMT="SUP-FE", LP=1;
```

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 302003 | 远端location不存在。                    | 输入的“远端location标识”参数不存在。                            | 请先执行LST RLOCATION命令查看已存在的“远端location标识”，再执行本命令重新输入已存在的参数。                                                                           |
| 302531 | 业务分组功能开关打开，请输入正确的业务类型参数。          | 业务分组功能开关打开时，必须输入对应的业务类型参数。                         | 请执行LST RLOCATION查询记录对应“远端网元类型”，然后输入该参数值重新执行MOD RLOCATION命令。                                                                         |

| 260147 | 远端网元类型不为USCDB时，参数REDUNFLAG只能设置为否。 | “远端网元类型”不为USCDB时，参数“是否容灾关系”设置为了“YES(是)”。           | 请重新设置参数，确保“远端网元类型”不为USCDB时，参数“是否容灾关系”设置为“NO(否)”。                                                                                    |
