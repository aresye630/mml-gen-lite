# 加载SSH公钥(LOD SSHPUBKEY)

- 输出结果说明

## 命令功能

该命令用于为USCDB网元添加指定的公钥文件。

当客户端需要使用公钥认证来提高系统的安全可靠性时，客户端需要先执行**GEN SSHKEY**命令生成公私钥文件，之后再执行**EXP SSHKEY**命令将生成的公钥文件导出，并将导出的公钥文件上传到服务器，最后服务端执行该命令加载上传的公钥文件才能与客户端进行公钥认证。

## 注意事项

- 公钥文件大小不能超过8K字节。
- 同一用户加载的公钥文件数不能超过32。
- 服务器加载的公钥文件总数不能超过128。
- 执行本命令之前需要通过OM Portal的文件传输服务上传SSH公钥文件到CGPLite容器的“CGPLite文件 > 网元文件”文件夹内。上传方法可参考产品文档中“GUI参考 > 文件传输”。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                     |
|:------------|:-------|:-------------------------------------------------------------------------------------------------------------------------|
| PUBKEYID    | 公钥ID   | 用于指示公钥在系统内的唯一标识。 取值范围：1～128 默认值：无。                                                                                       |
| USERNAME    | 用户名    | 用于指示加载公钥到指定用户的用户名。该参数只能是通过ADD RSFTPSERVER命令、ADD FTPUSER命令、ADD SFTPUSER命令、和ADD PGWSSHUSER命令添加的用户。 取值范围：长度不超过31的字符串 默认值：无。 |
| PUBKEYFILE  | 公钥文件名  | 用于指示待加载公钥文件的文件名。 取值范围：长度不超过128位由数字、字母、下划线和点组成的字符串。 默认值：无。                                                                |
| DESCRIPTION | 公钥描述   | 用于指示公钥的描述信息。 取值范围：长度不超过128位由数字、字母、下划线和空格组成的字符串。 默认值：无。                                                                   |

## 使用实例

当客户端需要使用公钥认证来提高系统的安全可靠性时，在SFTP服务端执行**LOD SSHPUBKEY**命令加载客户端上传的公钥文件。以用户“dsa\_user”添加公钥文件为例：

`LOD SSHPUBKEY: PUBKEYID=1, USERNAME="dsa_user", PUBKEYFILE="id_dsa.pub";`
