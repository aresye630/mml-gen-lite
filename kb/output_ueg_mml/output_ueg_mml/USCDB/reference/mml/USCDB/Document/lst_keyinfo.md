# 查询密钥信息(LST KEYINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询USCDB密钥信息。

- 若要查询USCDB全部密钥信息，请不要输入任何参数。
- 若要查询某个密钥类型的信息，请输入对应的“密钥类型”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                              |
|:-------|:-------|:--------------------------------------------------------------------------------------------------|
| KTYPE  | 密钥类型   | 可选必选说明：可选参数。 参数含义：用于指示系统按照“密钥类型”来查询密钥信息；若不输入，则表示所有的“密钥类型”。 取值范围： KEK(密钥加密密钥)WK(工作密钥) 默认值：无 配置原则：无 |
| KID    | 密钥编号   | 可选必选说明：可选参数。 参数含义：用于指示系统按照“密钥编号”来查询密钥信息；若不输入，则表示所有的“密钥编号”。 取值范围：0~1023 默认值：无 配置原则：无               |

## 使用实例

1. 查询USCDB全部密钥信息。

   ```
   LST KEYINFO:;
   ```

   ```
   %%LST KEYINFO:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------------------
   密钥类型            密钥编号  密钥更新时间    

   密钥加密密钥       0         2021-08-17 05:32:42
   工作密钥           0         2021-08-17 05:32:42
   (结果个数 = 2)

   ---    END
   ```
2. 查询密钥类型为“WK”的密钥配置信息。

   ```
   LST KEYINFO: KTYPE=WK;
   ```

   ```
   %%LST KEYINFO: KTYPE=WK;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------------------
       密钥类型  =  工作密钥
       密钥编号  =  0
   密钥更新时间  =  2021-08-12 05:36:16
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称   | 输出项解释                               |
|:--------|:------------------------------------|
| 密钥类型    | 表示密钥的类型。                            |
| 密钥编号    | 表示密钥被更新的次数。初始值为0，每更新一次，对应密钥类型的该值加1。 |
| 密钥更新时间  | 表示密钥被更新的时间。                         |
