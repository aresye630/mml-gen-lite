## 命令功能

**须知** 

该命令属于高危命令，该命令是更新数据库密码命令。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于更新Pod上的物理数据库密码。本命令使用场景如下：

- 在调测完成后，系统管理员必须及时更新物理数据库帐号的密码，确保系统安全。
- 在日常维护中，系统管理员必须定期更新物理数据库帐号的密码，确保系统安全。

## 注意事项

- 执行此命令前，必须保证物理数据库状态正常且NDF模块已经添加。可通过**LST MODULE**查看NDF模块是否已经添加，如果NDF模块没有添加，通过**ADD MODULE**增加NDF模块。
- 密码长期使用会增加被盗窃和破解的风险，而且使用的时间越长，被盗窃和破解的风险越高。定期修改密码可以有效防范这种情况的发生，因此强烈建议您定期修改密码。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                             |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USERNAME | 用户名    | 用来唯一标识一个数据库用户。 数据库用户名包含如下6个：uscdb_acc：用于设置DBG模块访问物理数据库的用户账号。可以新增、删除、修改或查询uscdb_acc用户授权的对象。pgw_acc：用于设置PGW模块访问物理数据库中PGW操作日志的用户账号。可以新增、删除、修改或查询pgw_acc用户授权的对象。sys：默认的管理员帐号，主要用于数据库的启停、数据库状态查询、数据库的备份与恢复等日常维护管理。拥有对USCDB数据库的最高权限。uscdb：用于对USCDB数据库中维护数据的管理。可以创建维护信息表。pgw：用于对USCDB数据库中业务发放日志的管理。可以创建业务发放日志信息表。uscdb_maintain：用于对USCDB\PGW数据库中维护数据的管理。可以新增、删除、修改或查询uscdb_role\pgw_role用户授权的对象。 默认值：无。 |

## 使用实例

软件调测完成之后，系统管理员需要及时更新物理数据库帐号的密码，以更新“uscdb\_acc”帐户密码为例：

```
SET DB: USERNAME="uscdb_acc";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释               | 原因分析                                                           | 处理建议                                                                                           |
|-------:|:--------------------|:---------------------------------------------------------------|:-----------------------------------------------------------------------------------------------|
| 260132 | 该用户名不存在。            | 输入的“用户名”在系统中不存在。                                               | 执行LST DB命令查询USCDB的物理数据库用户名信息，然后重新执行本命令。                                                        |
| 330001 | 在当前系统中，未找到运行该命令的模块。 | NDF模块具有物理数据库管理功能和平台资源监控功能，USCDB需要先添加该模块，然后才能执行本命令更新物理数据库帐号的密码。 | 执行ADD MODULE命令增加NDF模块，然后重新执行本命令。                                                               |
| 331001 | 操作失败。               | 主备NDF模块其中之一故障或全部故障。主备物理数据库其中之一故障或全部故障。                         | 查看是否有如下告警： ALM-1003 模块故障（由NDF模块故障上报）ALM-11014 物理库状态异常 如有，请参见相应的告警帮助进行处理后重新执行该命令。否则请联系华为技术支持处理。 |
