# 同步远端IP信息到本端(SYN RIPADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**说明** 

该命令属于高危命令，该操作将修改本端的远端IP配置。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于手工同步远端IP地址信息到本端网元，并且将同步到OMU表中的远端IP地址信息加载到DSG模块中。

## 注意事项

- 首先通过ADD RLOCATION命令配置远端Location后，才能通过该命令同步对端IP地址信息。
- 在手工同步对端IP地址信息到本端配置之后，通过ACT IPDISP命令激活链路，配置才能生效。
- 本端与远端的服务器时间必须保持一致。

## 参数说明

| 参数标识   | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                        |
|:-------|:-------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RLOCID | 远端Location标识 | 用于指定一个远端网元标识。该参数须在对接的远端USCDB网元或者FE网元中先定义，然后在本端网元通过ADD RLOCATION命令配置后，才能在此处索引。远端Location是相对的，具体如下：对于主用局FE，它的远端Location指主用局USCDB或容灾局USCDB。对于主用局USCDB，它的远端Location指主用局FE、容灾局FE或容灾局USCDB。对于容灾局FE，它的远端Location指容灾局USCDB或主用局USCDB。对于容灾局USCDB，它的远端Location指容灾局FE、主用局FE或主用局USCDB。 取值范围：1～512 默认值：无。 |
| RDPUST | 远端IP地址业务类型   | 用于指定远端IP地址业务类型名称。该参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。 取值范围：长度不超过128的字符串。 默认值：无。                                                                                                                                                                                                          |

## 使用实例

当本端与远端IP地址信息不一致时，手工同步“远端Location标识”为“77”，“远端IP地址业务类型”为“SUP-FE”的远端IP地址信息到本端网元，并且加载OMU表中的该远端IP地址信息到DSG模块中，命令示例如下：

```
SYN RIPADDR: RLOCID=77, RDPUST="SUP-FE";
```
