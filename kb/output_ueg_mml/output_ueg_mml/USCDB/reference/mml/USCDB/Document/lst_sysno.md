# 查询系统序列号(LST SYSNO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询当前局点的系统序列号。

## 注意事项

无。

## 参数说明

无。

## 使用实例

查询当前局点的系统序列号：

```
LST SYSNO:;
```

```
%%LST SYSNO:;%%
RETCODE = 0  操作成功

操作结果如下
------------
系统序列号  =  1
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET SYSNO**命令的参数说明。
