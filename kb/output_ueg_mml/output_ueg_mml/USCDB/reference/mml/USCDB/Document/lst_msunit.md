# 查询测量单元描述的配置信息(LST MSUNIT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询当前系统中测量单元描述的配置信息。

- 若需要查询全部测量单元的概要配置信息，不输入任何参数。
- 若需要查询某个测量单元的详细配置信息，请输入“测量单元标识”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                                                                                                                                   |
|:-------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UNITID | 测量单元标识  | 用于指示系统需要按照测量单元标识的值来查询配置信息；若不输入，表示所有的测量单元。 取值范围：0～65535 默认值：无。                                                                                                                                                                                          |
| ENNUM  | 测量指标数目  | 用于指示系统需要按照测量指标数目的值来查询测量单元描述的配置信息；若不输入，表示所有的测量单元描述的配置信息。 取值范围：0～65535 默认值：无。                                                                                                                                                                            |
| OBJID  | 测量对象ID  | 用于指示系统需要按照测量对象ID来查询测量单元描述的配置信息；若不输入，表示所有测量单元描述的配置信息。 取值范围：0～65535 默认值：无。                                                                                                                                                                               |
| PERIOD | 输出结果周期  | 用于指示系统需要按照输出结果周期来查询测量单元描述的配置信息；若不输入，表示所有测量单元描述的配置信息。 各参数选项的含义是： ONEMINUTE(1分钟)：表示每隔1分钟输出一次测量结果。FIVEMINUTES(5分钟)：表示每隔5分钟输出一次测量结果。FIFTEENMINUTES(15分钟)：表示每隔15分钟输出一次测量结果。THIRTYMINUTES(30分钟)：表示每隔30分钟输出一次测量结果。SIXTYMINUTES(60分钟)：表示每隔60分钟输出一次测量结果。 默认值：无。 |
| ISUSED | 系统中是否使用 | 用于指示系统需要按照系统中是否使用该测量单元来查询测量单元描述的配置信息；若不输入，表示所有的测量单元描述的配置信息。 各参数选项的含义是： NOTUSED（没有使用）：表示系统没有使用该测量单元。USED（使用）：表示系统使用该测量单元。 默认值：无。                                                                                                                        |

## 使用实例

1. 查询全部测量单元描述的配置信息。

   ```
   LST MSUNIT:;
   ```

   ```
   %%LST MSUNIT:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    测量单元标识  测量指标数目  测量对象ID  输出结果周期  系统中是否使用

    47            15            1098        5分钟         没有使用      
    48            15            1098        5分钟         没有使用      
    49            15            1098        5分钟         没有使用      
    50            15            1098        5分钟         没有使用      
   (结果个数 = 4)

   ---    END
   ```
2. 查询“测量单元标识”为“47”的描述的配置信息。

   ```
   LST MSUNIT: UNITID=47;
   ```

   ```
   %%LST MSUNIT: UNITID=47;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
     测量单元标识  =  47
     测量指标数目  =  15
       测量对象ID  =  1098
     输出结果周期  =  5分钟
   系统中是否使用  =  没有使用
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

| 参数名称    | 参数描述                                                               |
|:--------|:-------------------------------------------------------------------|
| 测量单元标识  | 用于唯一标识一个测量单元。                                                      |
| 测量指标数目  | 用于表示测量指标的个数。                                                       |
| 测量对象ID  | 用于唯一标识一个被测量对象。                                                     |
| 输出结果周期  | 用于定义测量任务每隔多长时间输出一次测量结果。如果测量任务多而且测量周期设置太短会影响系统的性能，比较合理的输出结果周期是60分钟。 |
| 系统中是否使用 | 用于标识系统是否使用该测量单元。                                                   |
