# 设置是否显示成功记录(MOD SETRST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于设置配置模块的联机设定命令的报文信息开关，该开关控制是否显示联机设定成功的记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                                                                                       |
|:-------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| SSR    | 是否显示成功的记录 | 用于描述联机设定后是否显示成功的记录。 各参数选项的含义是： “YES(显示成功记录)”：表示联机设定的报文中要显示全部的记录。“NO(不显示成功记录)”：表示只显示联机设定失败的记录。当参数SSR设置成“不显示成功记录”时，成功的联机设定记录将不会被显示出来。 默认值：无。 |

## 使用实例

1. 设置配置模块的联机设定命令的报文信息开关，设置“显示成功记录”为“YES(显示成功记录)”。

   ```
   MOD SETRST: SSR=YES;
   ```

   以**SND USD**命令为例，输出报文如下：

   ```
   %%SND USD:;%%
   RETCODE = 414024  联机设定未完全成功，系统将自动进行重新设定

   Pod联机设置结果
   ------------------
    网元ID  模块号  Pod名称    位置描述  主/备状态  设定结果描述  

    5       202     omu0        NULL      故障       模块状态不正常
    5       203     omu0        NULL      主用       操作成功      
   (结果个数 = 2)

   共有3个报告
   ---    END
   ```
2. 设置配置模块的联机设定命令的报文信息开关，设置“显示成功记录”为“NO(不显示成功记录)”。

   ```
   MOD SETRST: SSR=NO;
   ```

   以**SND USD**命令为例，输出报文如下：

   ```
   %%SND USD:;%%
   RETCODE = 414024  联机设定未完全成功，系统将自动进行重新设定

   Pod联机设置结果
   ------------------
         网元ID  =  5
         模块号  =  202
        Pod名称  =  omu0
       位置描述  =  NULL
      主/备状态  =  故障
   设定结果描述  =  模块状态不正常
   (结果个数 = 1)

   共有3个报告
   ---    END
   ```

## 输出结果说明

命令执行正常，会返回命令执行成功的提示信息。

命令执行异常，请联系华为技术支持处理。
