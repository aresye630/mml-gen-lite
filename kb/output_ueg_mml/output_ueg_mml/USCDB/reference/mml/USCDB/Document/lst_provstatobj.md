# 查询业务发放统计对象(LST PROVSTATOBJ)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询业务发放统计对象：

- 若需要查询全部业务发放统计对象信息，请不要输入任何参数。
- 若需要查询某个业务发放统计对象信息，请输入“业务发放统计对象索引”参数。
- 系统默认对所有业务发放命令进行统计，此统计对象也可以被查询。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称       | 参数说明                                                    |
|:--------------|:-----------|:--------------------------------------------------------|
| PROVSTATOBJID | 业务发放统计对象索引 | 用于指示系统按哪个业务发放统计对象的索引号来查询业务发放统计对象，如果不输入，则表示查询所有业务发放统计对象。 |

## 使用实例

1. 查询所有业务发放统计对象：

   ```
   LST PROVSTATOBJ:;
   ```

   ```
   %%LST PROVSTATOBJ:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------------------
    业务发放统计对象索引  业务发放统计对象名称      

    0                     ALL Commands Statistic    
    1                     HSS9860 Commands Statistic
   (结果个数 = 2)

   ---    END
   ```
2. 查询业务发放统计对象，“业务发放统计对象索引”为“0”：

   ```
   LST PROVSTATOBJ: PROVSTATOBJID=0;
   ```

   ```
   %%LST PROVSTATOBJ: PROVSTATOBJID=0;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------------------
   业务发放统计对象索引  =  0
   业务发放统计对象名称  =  ALL Commands Statistic
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD PROVSTATOBJ**命令的参数说明。
