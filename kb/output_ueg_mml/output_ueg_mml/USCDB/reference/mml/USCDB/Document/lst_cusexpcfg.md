# 查询定制导出配置(LST CUSEXPCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询园区的定制导出配置信息：

- 若要查询全部园区定制导出配置的配置信息，请不要输入任何参数。
- 若要查询某个园区的定制导出配置信息，请输入“园区名称”，或者“园区名称”和其他参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识           | 参数名称        | 参数说明                                                                                                                                                                                                       |
|:---------------|:------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FETYPE         | FE类型        | 可选必选说明：可选参数 参数含义：用于指示系统根据哪个服务类型来查询定制导出配置信息。若不输入，则表示所有的FE类型。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                                                                                                              |
| CAMPUSNAME     | 园区名称        | 可选必选说明：可选参数 参数含义：用于指示系统根据哪个园区名称来查询定制导出配置信息。若不输入，则表示所有的园区名称。 取值范围：由数字（0~9）、字母（a~z和A~Z）或下划线组成的长度不超过63的字符串。 默认值：无。 配置原则：无。                                                                                    |
| SFTPTYPE       | SFTP类型      | 可选必选说明：可选参数 参数含义：用于指示系统根据哪个SFTP类型来查询定制导出配置信息。若不输入，则表示所有的SFTP类型。 取值范围： CLIENT：表示园区导出时，本端作为客户端上传导出结果到远端。SERVER：表示园区导出时，本端作为服务端供远端下载导出结果文件。IMPORTCLIENT：表示园区导入时，本端作为客户端从远端服务器中下载导出结果文件，进行数据导入。 默认值：无。 配置原则：无。 |
| SFTPSERVERNAME | 远端SFTP服务端名称 | 可选必选说明：可选参数 参数含义：用于指示系统根据哪个SFTP服务端的名称来查询定制导出配置信息。若不输入，则表示所有的远端SFTP服务端名称。 取值范围：由数字（0~9）、字母（a~z和A~Z）和下划线组成的不超过127位的字符串。 默认值：无。 配置原则：仅当该命令中“SFTP类型”参数为“CLIENT”时该参数有效。                                         |
| SFTPUSERNAME   | SFTP用户名称    | 可选必选说明：可选参数 参数含义：用于指示系统根据哪个SFTP用户名称来查询定制导出配置信息。若不输入，则表示所有的SFTP用户名称。 取值范围：由数字（0~9）、字母（a~z和A~Z）组成，且必须以字母开头长度不超过31的字符串。 默认值：无。 配置原则：仅当该命令中“SFTP类型”参数为“SERVER”时该参数有效。                                          |
| DESC           | 配置描述        | 可选必选说明：可选参数 参数含义：用于指定园区的配置描述。若不输入，则表示所有园区的配置描述。 取值范围：由数据、字母、下划线组成的长度不超过64的字符串。 默认值：无。 配置原则：无。                                                                                                              |

## 使用实例

1. 所有园区需要查询定制导出配置：

```
LST CUSEXPCFG:;
```

```
%%LST CUSEXPCFG:;%%
RETCODE = 0  操作成功

操作结果如下
------------------------

 SUP-FE     123		 CLIENT       s123asdasd	     NULL                   NULL	     *****    NULL
 SUP-FE     123123324	 CLIENT	      qq123we		     NULL                   NULL	     *****    NULL
 SUP-FE     123qew	 CLIENT	      s123asdasd	     NULL                   NULL 	     *****    NULL

(结果个数 = 3)

---    END
```

2. 某园区需要查询定制导出配置：

- “FE类型”：“SUP-FE”
- “园区名称”：“CAMPUStest1”

```
LST CUSEXPCFG: FETYPE="SUP-FE", CAMPUSNAME="CAMPUStest1";
```

```
%%LST CUSEXPCFG:FETYPE="SUP-FE", CAMPUSNAME="CAMPUStest1";%%
RETCODE = 0  操作成功

操作结果如下
------------------------
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD CUSEXPCFG**命令的参数说明。
