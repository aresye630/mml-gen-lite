# 修改内存库密码(MOD IMDBPWD)

## 命令功能

该命令用于修改内存数据库密码。

## 注意事项

- 密码区分大小写，其复杂度需同时满足下列条件：

  - 密码至少包含以下四个类别中的三类：
    1. 英文大写字母。
    2. 英文小写字母。
    3. 数字：0～9。
    4. 特殊字符：~ ! # % ^ \* ( ) \_ - + [ ] { } | < > . ?。
  - 密码的第一个字符必须是字母。
  - 不允许使用三个或三个以上连续的字母或数字（例如：ABC、123）。
  - 不允许使用三个或三个以上连续的相同字符（例如：AAA）。
  - 密码长度最短8个字符，最长30个字符。
  - 密码不能和账号或者账号的逆序一样，且不能包含账号或者账号的逆序。
- 该命令不允许进行批操作。
- 密码长期使用会增加被盗窃和破解的风险，而且使用的时间越长，被盗窃和破解的风险越高。定期修改密码可以有效防范这种情况的发生，因此强烈建议您定期修改密码。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                             |
|:-------|:-------|:-------------------------------------------------|
| OLD    | 旧密码    | 用于指定内存数据库的原密码。 取值范围：符合密码复杂度的字符串。 默认值：无。          |
| PWD    | 新密码    | 用于指定内存数据库的新密码。 取值范围：符合密码复杂度的字符串。 默认值：无。          |
| CFM    | 确认密码   | 用于确认内存数据库的新密码，必须与新密码相同。 取值范围：符合密码复杂度的字符串。 默认值：无。 |

## 使用实例

修改内存数据库密码为“\*\*\*\*\*”。

```
MOD IMDBPWD: OLD="*****", PWD="*****", CFM="*****";
```

**说明** 

密码在命令行输入区域显示为\*\*\*\*\*。
