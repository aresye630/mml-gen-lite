# 显示License统计校验任务状态(DSP LICCHECK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询当前对License资源数目的统计校验任务状态。

## 注意事项

如果该命令查询到全部License统计校验任务的状态都是“校验中”，且一分钟后查询无变化，则查看是否有因DSG模块故障上报的“ALM-1003 模块故障”告警，若有则按告警帮助进行处理，若无请联系华为技术支持处理。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                    |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------|
| FETYPE | FE类型   | 可选必选说明：可选参数。 参数含义：用于指定需要查询的License统计校验任务的FE类型。此参数通过LOD FEPLUG命令加载FE插件后在此引用，可通过LST FEPLUG命令查询获取。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。  说明： 该参数不允许输入“USCDB”。 |

## 使用实例

查询全量License统计校验任务。

`DSP LICCHECK:;`

```
%%DSP LICCHECK:;%% 
RETCODE = 0  操作成功  
操作结果如下
------------  
Cluster标识   类型        状态
1065          手工       已完成
1073          手工       已完成
1093          手工       已完成
1097          手工       已完成
1101          手工       已完成
(结果个数 = 5)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1的参数说明。

| 输出项名称     | 输出项解释                                                                                                                                |
|:----------|:-------------------------------------------------------------------------------------------------------------------------------------|
| Cluster标识 | 用于返回License统计校验任务所在DMA模块的归属Cluster，此参数在USCDB下唯一，通过ADD CLUSTER命令定义后在此引用。                                                              |
| 类型        | 用于返回License统计校验任务的类型。 手工：该任务是手工触发。定时：该任务是定时任务触发。                                                                                     |
| 状态        | 用于返回License统计校验任务的状态。 取值说明：未启动：未启动该任务。启动中：正在启动该任务。统计中：正在进行统计操作。校验中：正在进行校验操作。已完成：该任务已经成功完成。超时：该任务超时，请联系华为技术支持处理。异常：该任务失败，请联系华为技术支持处理。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释                         | 原因分析                   | 处理建议                                                                                                        |
|------:|:------------------------------|:-----------------------|:------------------------------------------------------------------------------------------------------------|
|  2059 | 指定的业务类型不存在。                   | 输入的“FE类型”不存在。          | 通过LST FEPLUG命令查询加载的“FE类型名称”，即“FE类型”。 若“FE类型”加载成功，请输入正确的FE类型。若“FE类型”加载不成功或者没有加载，通过LOD FEPLUG命令加载成功后，重新执行该命令。 |
|  2787 | 参数取值无效：参数FETYPE必须由1-128个字符组成。 | 参数“FE类型”的值为空或超过128个字符。 | 请重新输入，确保输入的参数“FE类型”由1-128个字符组成。                                                                             |
