# 查询应用优先级（LST APPPRIORITY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询第三方FE应用的优先级。

- 若需要查询全部的第三方FE优先级的概要信息，请不要输入任何参数。
- 若需要查询某个第三方FE优先级的详细信息，请输入“用户名”或“优先级”。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                             |
|:---------|:-------|:-------------------------------------------------|
| USERNAME | 用户名    | 用于指定按照“用户名”来查询第三方FE的应用优先级；若不输入，则表示所有第三方FE的应用优先级。 |
| PRIORITY | 优先级    | 用于指定按照“优先级”来查询第三方FE的应用优先级；若不输入，则表示所有第三方FE的应用优先级。 |

## 使用实例

1. 查询所有第三方FE应用的优先级:

   ```
   LST APPPRIORITY:;
   ```

   ```
   %%LST APPPRIORITY:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    用户名     优先级

    user_high  高    
    user_low   低    
   (结果个数 = 2)

   ---    END
   ```
2. 查询“用户名”为“user\_low”的优先级:

   ```
   LST APPPRIORITY: USERNAME="user_low";
   ```

   ```
   %%LST APPPRIORITY: USERNAME="user_low";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
   用户名  =  user_low
   优先级  =  低
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令操作成功的提示信息和相关参数，各参数含义请参见**SET APPPRIORITY**命令的参数说明。
