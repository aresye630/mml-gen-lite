# 删除适配测量对象(RMV ADPSTATOBJ)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除适配测量对象记录。

## 注意事项

在删除一条适配测量对象记录前，请先确认该适配测量对象是否被**ADD ADPSTATOPRULE**命令配置的适配测量操作员规则所引用，可以通过**LST ADPSTATOPRULE**命令查询该适配测量对象是否被引用。如果该适配测量对象被引用，则删除该适配测量对象失败。

## 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                           |
|:-------------|:---------|:-------------------------------------------------------------------------------|
| ADPSTATOBJID | 适配测量对象ID | 标识一条适配测量对象记录的关键字段，用于指定需要删除哪一条适配测量对象记录，可以使用LST ADPSTATOBJ命令查询获得。此参数在USCDB网元下唯一。 |

## 使用实例

删除指定适配测量对象记录，该“适配测量对象ID”为“1”。

```
RMV ADPSTATOBJ: ADPSTATOBJID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释              | 原因分析                 | 处理建议                                                                                                         |
|-------:|:-------------------|:---------------------|:-------------------------------------------------------------------------------------------------------------|
| 275016 | 指定的记录不存在。          | 系统配置中不存在指定的适配测量对象记录。 | 执行LST ADPSTATOBJ命令查询适配测量对象，再重新执行RMV ADPSTATOBJ命令输入“适配测量对象ID”，确保其存在。                                          |
| 335428 | 该适配测量对象正在被使用，不能删除。 | 适配测量对象正在被使用。         | 执行LST ADPSTATOPRULE命令查询适配测量操作员规则使用的适配测量对象。如果要删除适配测量对象，则要先执行RMV ADPSTATOPRULE命令删除引用适配测量对象的适配测量操作员规则，再重新执行本命令。 |
