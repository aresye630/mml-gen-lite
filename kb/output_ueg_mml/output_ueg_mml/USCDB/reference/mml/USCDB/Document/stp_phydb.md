# 停止物理数据库（STP PHYDB）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，该操作将停止物理库，物理库连接会中断，请谨慎操作，操作前请务必联系华为技术支持工程师确认。

执行该命令为系统高危操作，需要第二个具有授权权限的用户授权后才能执行该操作。

该命令用于执行停止物理数据库功能，当执行**DSP PHYDB**命令查询物理数据库状态不为“Abnormal”时，可执行该命令停止物理数据库。

## 注意事项

无。

## 参数说明

无。

## 使用实例

某局点需要执行物理数据库停止操作时：

```
STP PHYDB:;
```

返回结果如下：

```
%%STP PHYDB:;%% 
RETCODE = 0  操作成功  
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释      | 原因分析                 | 处理建议                                                       |
|------:|:-----------|:---------------------|:-----------------------------------------------------------|
|  1730 | 部分操作失败。    | 主用或备用NDF模块其中一个异常。    | 请联系华为技术支持。                                                 |
|  2733 | 数据库已经停止。   | 物理数据库已经停止运行，不需要重复停止。 | 执行DSP PHYDB命令查询物理数据库状态，请在物理数据库状态不为“Pending”时，执行该命令停止物理数据库。 |
|  2747 | 停止物理数据库失败。 | 物理数据库存在异常导致中断。       | 联系华为技术支持。                                                  |
