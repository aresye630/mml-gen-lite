# 查看DSG链路信息(DSP DSGSCTPLINK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于请求系统显示DSG模块链路的配置信息。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称         | 参数说明                                                 |
|:--------|:-------------|:-----------------------------------------------------|
| MID     | DSG模块号       | 用于请求系统显示哪个DSG模块号的链路信息。                               |
| RLOCID  | 远端Location标识 | 用于请求系统显示哪个远端Location标识的链路信息；若不输入，则表示所有的远端Location标识。 |
| RDSGMID | 远端DSG模块号     | 用于请求系统显示哪个远端DSG模块号的链路信息；若不输入，则表示所有的远端DSG模块号。         |

## 使用实例

查看DSG链路信息，“DSG模块号”为“111”，“远端Location标识”为“12”，“远端DSG模块号”为“21”，执行命令如下：

```
DSP DSGSCTPLINK: MID=111, RLOCID=12, RDSGMID=21;
```

```

--------

远端Location标识  =  12

      远端端口号  =  2021
(结果个数 = 1)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1。

| 输出项名称        | 输出项解释                               |
|:-------------|:------------------------------------|
| DSG模块号       | 用于返回链路状态信息所在的DSG模块号。                |
| 远端Location标识 | 用于返回本网元所连接的FE或容灾USCDB网元的Location标识。 |
| 远端DSG模块号     | 用于返回本网元所连接的FE或容灾USCDB网元的DSG模块号。     |
| 本端IP地址       | 用于返回DSG链路连接的本端设备的IP地址。              |
| 远端IP地址       | 用于返回DSG链路连接的远端设备的IP地址。              |
| 本端端口号        | 用于返回DSG链路连接的本端设备的端口号。               |
| 远端端口号        | 用于返回DSG链路连接的远端设备的端口号。               |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释             | 原因分析                                | 处理建议                                           |
|------:|:------------------|:------------------------------------|:-----------------------------------------------|
|  2084 | 参数模块号指定的模块状态异常。   | “DSG模块号”对应的模块状态异常。                  | 请参见产品手册的“模块故障”进行处理。                            |
|  2180 | 条件参数缺失。           | 当“远端DSG模块号”配置时，“远端Location标识”也必须配置。 | 当已配置“远端DSG模块号”，请配置“远端Location标识”。              |
|  2192 | 参数MID指定的DSG模块不存在。 | “DSG模块号”对应的模块不存在。                   | 通过LST MODULE命令查询DSG的模块号，输入查询到的DSG模块号后，重新执行该命令。 |
