# 修改远端营帐配置(MOD PSITE)

## 命令功能

**须知** 

该命令属于高危命令，该操作将修改远端业务发放站点配置，操作不当将造成业务中断。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一条远端业务发放站点配置数据进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识远端业务发放站点配置数据记录。

- Site ID
- 业务场景
- 接口类型

当远端业务发放站点的数据发生变化（例如由于故障等异常原因需要进行主备局点切换等）时，需要使用本命令修改远端业务发放站点的IP地址和端口等数据。

该命令的使用场景：

- 开局场景：开局根据网设规划配置PSITE时，用于修改错误配置。
- 网络改造场景：根据客户组网规划，需要调整部分远端业务发放站点配置。

## 注意事项

- “业务场景”、“接口类型”、“本端provision端口”、“远端Partition ID”、“远端站点优先级”和“远端provision类型”六个参数都相同的记录只能添加一条。

- “接口类型”、“远端provision IPV4地址”（或“远端provision IPV6地址”）、“远端provision端口”、“本端provision端口”和“远端provision类型”五个参数都相同的记录只能添加一条。
- 不同的“远端Partition ID”，不能配置相同的非本地业务类型“远端provision类型”。本地业务类型可以通过**LST FEPLUG**命令查询。
- 密码长期使用会增加被盗窃和破解的风险，而且使用的时间越长，被盗窃和破解的风险越高。定期修改密码可以有效防范这种情况的发生，因此强烈建议您定期修改密码。
- 该命令不允许进行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。
- 如果远端业务发放站点配置里有“操作员”和“密码”参数，则修改“远端provision IPV4”、“远端provision IPV6”或者“远端provision端口”参数时，必须同时输入“操作员”和“密码”参数。

## 使用实例

某局点的远端业务发放站点的配置变化，需要修改远端业务发放站点数据。“Site ID”为“1”，“业务场景”为“PROV(业务发放)”，“接口类型”为“SOAP(SOAP接口)”，“IP类型”为“IPV4”，“远端provision IPV4”为“192.168.9.10”，“本端IPV4”为“192.168.9.11”，“远端provision端口”为“8001”，“远端provision类型”为“SUP-FE”，“系统HLR序列号”为“1”，“HLR序列号”为“1”，“操作员”为“admin”，“密码”为“\*\*\*\*\*”，“确认密码”为“\*\*\*\*\*”，“是否使用HTTPS”为“NO(否)”，“描述”为“Huawei HLR1”：

```
MOD PSITE: SITEID=1, SRVSCENARIO=PROV, INTERFACE=SOAP, IPVER=IPV4, SITEIPV4="192.168.9.10", LOCALIPV4="192.168.9.11", SITEPORT=8001, SITEAPPTYPE="SUP-FE", SYSHLRSN=1, HLRSN=1, OPRNAME="admin", PWD="*****", CFM="*****", HTTPS=NO, DESCRIPTION="Huawei HLR1";
```

**说明** 

密码在命令行输入区域显示为\*\*\*\*\*。
