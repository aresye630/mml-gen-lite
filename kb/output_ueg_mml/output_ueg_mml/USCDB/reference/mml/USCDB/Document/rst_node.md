# 重启节点(RST NODE)

## 命令功能

**须知** 

该命令属于高危命令，该操作会重启所有DRU或DSU节点，导致业务完全中断。因此执行该命令前，需要与华为技术支持确认后才可以实施。

用于重启DRU或者DSU节点。

该命令主要使用场景：

- 指定目录加载场景中，需要重启所有的DRU和DSU，加载指定目录的数据。
- 内存数据库恢复场景中，如果需要恢复所有DRU或者DSU的内存数据库，可以使用该命令重启DRU或者DSU，重新加载数据。

## 注意事项

- 重启节点会导致业务中断，为确保系统的安全与稳定运行，除非紧急排除故障的需要，操作员在系统话务量少的时间段（例如凌晨2:00～4:00）或者系统处于去激活模式时执行该命令。
- 该命令不允许进行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。

**说明** 

使用**LST SYSRM**命令查看系统的运行模式。使用**MOD SYSRM**命令修改系统的运行模式。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                              |
|:------------|:----------|:--------------------------------------------------------------------------------------------------|
| SERVICETYPE | 业务类型      | 用于指定待重启的节点所属的业务类型。此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。USCDB类型默认已经加载。 取值范围：长度不超过128的字符串。 默认值：无。 |
| CT          | Cluster类型 | 用于指定待重启的节点的Cluster类型。 取值范围： DRU(DRU)DSU(DSU) 默认值：无。                                               |

## 使用实例

某局点发现数据异常，需要恢复DRU的内存数据库数据。设置“业务类型”为“SUP-FE”，“Cluster类型”为“DRU”，重启节点：

```
RST NODE: SERVICETYPE="SUP-FE", CT=DRU;
```

```
%%RST NODE: SERVICETYPE="SUP-FE", CT=DRU;%%
RETCODE = 0  操作成功

操作结果如下
------------------------
 业务类型    Cluster类型     模块号           操作结果

 SUP-FE        DRU            82               成功      
 SUP-FE        DRU            83               成功      
(结果个数 = 2)

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1中的参数说明。

| 参数名称      | 参数描述                      |
|:----------|:--------------------------|
| 业务类型      | 用于描述节点的业务类型。              |
| Cluster类型 | 用于描述节点所属的Cluster类型。       |
| 模块号       | 用于描述节点对应的模块号。 取值范围：0～4080 |
| 操作结果      | 用于描述节点是否重启成功。 取值范围：成功失败   |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|    错误码 | 错误码解释                                       | 原因分析                                     | 处理建议                                                                                                                      |
|-------:|:--------------------------------------------|:-----------------------------------------|:--------------------------------------------------------------------------------------------------------------------------|
| 260254 | Cluster类型非法。                                | 输入的“Cluster类型”非法，仅支持“DRU”或者“DSU”类型的节点重启。 | 修改命令中“Cluster类型”为“DRU”或者为“DSU”，然后重新执行该命令。                                                                                 |
| 250098 | 参数取值无效：参数SERVICETYPE的取值不存在，请确认已经成功加载了该FE插件。 | 没有加载对应的插件包。                              | 通过LST FEPLUG命令查看已加载“FE类型名称”， “FE类型名称”即“业务类型”。如果业务类型加载成功，在执行命令时请输入正确的业务类型名称。如果业务类型加载不成功或者没有加载，通过LOD FEPLUG命令加载成功后，重新执行该命令。 |
| 330002 | 在当前系统中，未找到运行该命令的节点。                         | 根据输入的“业务类型”和“Cluster类型”找不到对应的节点。         | 通过LST NODE命令，查看已经添加的节点。如果节点已经添加，请在执行命令时输入正确的业务类型名称和Cluster类型名称。如果没有添加节点，通过ADD NODE命令添加节点。节点添加成功后，重新执行该命令。                 |
