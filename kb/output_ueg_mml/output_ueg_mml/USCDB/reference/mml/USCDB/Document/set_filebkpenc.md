## 命令功能

**须知** 

该命令属于高危命令，请自行记录文件备份密钥材料，若密钥材料丢失，将无法找回密钥。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置文件备份加密信息。

该命令的使用场景：当需要对内存库备份文件或者物理库备份文件进行加密时，需要执行该命令设置文件备份加密信息，提升备份文件的安全性。若没有设置文件备份加密信息，安全性较低，系统会上报“ALM-10031 系统存在不安全的配置项”告警。

## 注意事项

- 最多可以配置1024条文件备份加密信息的记录。
- 执行该命令设置文件备份的加密信息后，设置软参FILEBKPENCSWT（加密备份开关）为“1”，内存库备份文件加密功能才生效，相关的影响请见软参页面。
- 执行该命令设置文件备份的加密信息后，当备份内存库数据到自带空间或第三方服务器时，会对校验文件进行加密。

## 使用实例

用户需要设置文件备份加密信息，“密钥材料1”为“cnp200\_H”，“密钥材料2”为“cnp200\_H”，“密钥材料3”为“cnp200\_H”，“描述”为“test”。

```
SET FILEBKPENC: KEY1="*****", KEY2="*****", KEY3="*****", DESC="test";
```

**说明** 

密钥材料在命令行输入区域显示为\*\*\*\*\*。
