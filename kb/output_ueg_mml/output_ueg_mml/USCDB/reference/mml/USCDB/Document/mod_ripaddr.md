# 修改远端网元IP地址(MOD RIPADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，该操作可能会导致业务中断。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一个远端网元IP地址进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一个远端网元IP地址：

- 远端Location标识
- 远端DPU模块号/远端业务IP索引

## 注意事项

- 修改远端网元IP地址将影响本端DSG和远端DSG的网络连接，导致业务中断，请慎重执行此命令。
- 执行该命令后需要通过**ACT IPDISP**命令激活IP链路之后配置才能生效。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识    | 参数名称               | 参数说明                                                                                                                                                       |
|:--------|:-------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| RLOCID  | 远端Location标识       | 标识一个远端网元IP地址的关键字段之一，用于指定需要对哪一个远端Location的远端网元IP地址进行修改或调整。此参数必须在远端网元中已经配置完毕。操作员可以通过LST RIPADDR命令查询获得。                                                       |
| ID      | 远端DPU模块号/远端业务IP索引  | 标识一个远端网元IP地址的关键字段之一，用于指定需要对哪一个远端DPU模块号/远端业务IP索引的网元IP地址进行修改或调整。此参数必须在远端网元中已经配置完毕。 操作员可以使用LST RIPADDR命令查询获得。                                                 |
| IPVER   | IP类型               | 用于表示IP地址类型。 取值范围： IPV4：当系统要求使用IPv4类型的IP地址时选择此选项。IPV6：当系统要求使用IPv6类型的IP地址时选择此选项。                                                                             |
| IPV4IP1 | 远端Location IPV4地址1 | 用于指定远端网元的Location IP地址。这个地址必须在远端网元中已经配置完毕。                                                                                                                 |
| IPV6IP1 | 远端Location IPV6地址1 | 用于指定远端网元的Location IP地址。这个地址必须在远端网元中已经配置完毕。 当参数“IP类型”设置为“IPV6(IPV6)”时，该参数有效，格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如：2001:DB8:8432:4098:4782:5784::。 |
| IPV4IP2 | 远端Location IPV4地址2 | 用于指定远端网元的Location IP地址。这个地址必须在远端网元中已经配置完毕。                                                                                                                 |
| IPV6IP2 | 远端Location IPV6地址2 | 用于指定远端网元的Location IP地址。这个地址必须在远端网元中已经配置完毕。 当参数“IP类型”设置为“IPV6(IPV6)”时，该参数有效，格式为“xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx”，例如：2001:DB8:8432:4098:4782:5784::。 |
| RDPUST  | 远端IP地址业务类型         | 用于指定远端IP地址的业务类型，通过LOD FEPLUG命令加载FE插件后在此引用。业务分组开关打开时，如果远端IP地址的业务类型属于分组内，则必须输入此参数，通过LST SERVICEGROUP命令查看对应业务类型是否在分组中，再执行LST GROUPSWITCH命令查看分组开关是否打开。         |

## 使用实例

在维护场景下，修改远端网元IP地址，“远端Location标识”为“3”，“远端DPU模块号/远端业务IP索引”为“1”，“IP类型”为“IPV4”，“远端Location IPV4地址1”为“192.168.128.12”，“远端Location IPV4地址2”为“192.168.128.13”，“远端IP地址业务类型”为“SUP-FE”：

```
MOD RIPADDR: RLOCID=3, ID=1, IPVER=IPV4, IPV4IP1="192.168.128.12", IPV4IP2="192.168.128.13", RDPUST="SUP-FE";
```
