# 查询接管标记（LST TAKEOVERFLAG）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询相应的业务类型的接管标记配置。

- 若需要查询全部业务类型的接管标记配置，请不要输入任何参数。
- 若需要查询某个业务类型的接管标记配置，请输入“业务类型”参数。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                 |
|:------------|:-------|:-----------------------------------------------------------------------------------------------------|
| SERVICETYPE | 业务类型   | 可选必选说明：可选参数 参数含义：用于指定具体的业务类型。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。 |

## 使用实例

1. 查询SUP-FE业务类型设置的接管标记。

   ```
   LST TAKEOVERFLAG: SERVICETYPE="SUP-FE";
   ```

   ```
   %%LST TAKEOVERFLAG: SERVICETYPE="SUP-FE";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------------------
       业务类型  =  SUP-FE
       接管标记  =  开
       自动恢复  =  否
   (结果个数 = 1)

   ---    END
   ```
2. 查询全部业务类型设置的接管标记。

   ```
   LST TAKEOVERFLAG:;
   ```

   ```
   %%LST TAKEOVERFLAG:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------------------
       业务类型     接管标记   自动恢复
       GU-HLR       开         否
       SUP-FE       开         是
   (结果个数 = 2)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET TAKEOVERFLAG**命令的参数说明。
