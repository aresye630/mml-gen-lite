# 添加号段配置(ADD PSITERULE)

- 命令功能
- 注意事项

- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，增加号段配置会造成营帐命令转发到其他设备。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在配置数据库中增加一条号段数据记录。

业务发放系统指令通过系统向远端业务发放站点转发的过程如远端业务发放站点规则管理中的图1所示。

当出现如下场景时，系统需要通过本命令增加用户号码（包括号段类型、号段前缀等）和远端业务发放站点之间的关联关系。

- 新增一条用户号段和远端业务发放站点之间的对应关系。
- 修改已有的用户号段和远端业务发放站点之间的对应关系。

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                               |
|:------------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------|
| SITEID      | Site ID | 唯一标识一个远端业务发放站点。用于对系统转发的业务发放指令进行处理。 取值范围：1～1024 默认值：无。                                                                              |
| RULEID      | Rule ID | 用于唯一标识一条号段配置。 取值范围：1～65535 默认值：无。                                                                                                  |
| RANGETYPE   | 号段类型    | 用于指定业务发放指令携带的用户号码的号段类型。 取值范围： IMSI(IMSI)：用户号码的号段类型为IMSI。ISDN(ISDN)：用户号码的号段类型为ISDN。 默认值：无。                                          |
| PREFIX      | 号段前缀    | 用于指定业务发放指令携带的用户号码的号码前缀。 取值范围：1～32位的由数字组成的字符串。 默认值：无。                                                                               |
| ACTIVE      | 主设备     | 仅当ADD PSITE命令中的“业务场景”参数取值为“DUALPROV(营帐双发)”时该参数有效，用于指定配置号段的主设备。 取值范围： LOCAL(本端为主设备)REMOTE(远端为主设备) 默认值：无。                            |
| CUTOVER     | 割接状态    | 仅当ADD PSITE命令中的“业务场景”参数取值为“DUALPROV(营帐双发)”时该参数有效，用于指定配置号段的割接状态。 取值范围： TRUE(TRUE)：号段已割接。FALSE(FALSE)：号段未割接。NONE(NONE)：非双发号段。 默认值：无。 |
| AREA        | 号段区域    | 用于指定业务发放指令携带的用户号码的号段所分配到区域的描述。例如“Beijing”、“Shenzhen”等。 取值范围：不超过64位的字符串。 默认值：无。                                                     |
| DESCRIPTION | 描述      | 用于指定业务发放指令携带的用户号码的号段配置描述信息。 取值范围：不超过128位的字符串。 默认值：无。                                                                               |

## 使用实例

某局点要求将业务发放指令转发到远端业务发放站点处理，需要进行如下操作：

1. 执行**LOD ADPPLUG**命令加载SUP-FE网元定制好的适配插件包“AdpConfig.zip”。
2. 执行**ADD PSITE**增加远端业务发放站点数据。
3. 执行本命令增加号段配置。“Site ID”为“1”，“Rule ID”为“1”，“号段类型”为“IMSI”，“号段前缀”为“4600”：

   ```
   ADD PSITERULE: SITEID=1, RULEID=1, RANGETYPE=IMSI, PREFIX="4600";
   ```
4. 执行**RST MODULE**命令重启PGW进程使配置生效。

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 275327 | SITEID不存在。                            | 输入的“Site ID”在系统中不存在。                                      | 执行ADD PSITE命令添加远端业务发放站点数据的“Site ID”记录，再执行本命令添加号段配置的“Site ID”记录。                         |
