## 命令功能

**须知** 

该命令属于高危命令，执行该操作可能修改ALM-369 节点内存使用率过高、ALM-371 节点内存不足两个告警的上报、恢复阈值，若设置不当可能导致告警误上报、恢复。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置节点内存数据库使用率告警阈值信息。

系统根据当前节点内存使用率和该命令配置的告警阈值进行比较，超出相应的上报阈值时，上报“ALM-369 节点内存使用率过高”或“ALM-371 节点内存不足”告警。用户可以根据业务的需要，执行该命令修改参数值，从而监控节点内存使用率，以免内存不足造成业务处理失败。

## 注意事项

通过本命令配置告警阈值时，参数取值需要符合条件：“节点内存不足告警上报阈值” > “节点内存不足告警恢复阈值” > “节点内存使用率过高告警上报阈值” > “节点内存使用率过高告警恢复阈值 ”。

## 参数说明

| 参数标识               | 参数名称            | 参数说明                                                                                                                                                                                    |
|:-------------------|:----------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FETYPE             | FE类型            | 可选必选说明：必选参数 参数含义：用于指定设置哪个FE类型的内存数据库使用率告警阈值。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：此参数需要通过LOD FEPLUG命令加载FE插件后才能在此引用。                                                                            |
| CLUSTERTYPE        | Cluster类型       | 可选必选说明：必选参数 参数含义：用于指定设置哪个Cluster类型的内存数据库使用率告警阈值。 取值范围：DRU(DRU)DSU(DSU) 默认值：无。 配置原则：无。                                                                                                   |
| TOOHIGHALMSTRTHD   | 节点内存使用率过高告警上报阈值 | 可选必选说明：可选参数 参数含义：用于设置节点内存使用率过高告警上报阈值。当节点内存使用率大于该参数设置值时，产生“ALM-369 节点内存使用率过高”告警。 取值范围：1～99，整数类型，单位为%。 默认值：无。 配置原则： 该参数取值大于“节点内存使用率过高告警恢复阈值”参数取值，并且小于“节点内存不足告警恢复阈值”参数取值。该参数的系统初始设置值为“85”。 |
| TOOHIGHALMENDTHD   | 节点内存使用率过高告警恢复阈值 | 可选必选说明：可选参数 参数含义：用于设置节点内存使用率过高告警恢复阈值。当节点内存使用率小于或等于该参数设置值时，“ALM-369 节点内存使用率过高”告警恢复。 取值范围：1～99，整数类型，单位为%。 默认值：无。 配置原则： 该参数取值小于“节点内存使用率过高告警上报阈值”参数取值。该参数的系统初始设置值为“80”。                     |
| NOTENOUGHALMSTRTHD | 节点内存不足告警上报阈值    | 可选必选说明：可选参数 参数含义：用于设置节点内存不足告警上报阈值。当节点内存使用率大于该参数设置值时，产生“ALM-371 节点内存不足”告警。 取值范围：1～99，整数类型，单位为%。 默认值：无。 配置原则： 该参数取值要大于“节点内存不足告警恢复阈值”参数取值。该参数的系统初始设置值为“95”                                 |
| NOTENOUGHALMENDTHD | 节点内存不足告警恢复阈值    | 可选必选说明：可选参数 参数含义：用于设置节点内存不足告警恢复阈值。当节点内存使用率小于或等于该参数设置值时，“ALM-371 节点内存不足”告警恢复。 取值范围：1～99，整数类型，单位为%。 默认值：无。 配置原则： 该参数取值小于“节点内存不足告警上报阈值”参数取值，并且大于“节点内存使用率过高告警上报阈值”参数值。该参数的系统初始设置值为“93”。     |

## 使用实例

设置内存数据库使用率告警阈值，“FE类型”为“SUP-FE”，“Cluster类型”为“DRU”，“节点内存使用率过高告警上报阈值”为“85”，“节点内存使用率过高告警恢复阈值”为“80”，“节点内存不足告警上报阈值”为“95”，“节点内存不足告警恢复阈值”为“93”：

```
SET IMDBUSAGEALMTHD: FETYPE="SUP-FE", CLUSTERTYPE=DRU, TOOHIGHALMSTRTHD=85, TOOHIGHALMENDTHD=80, NOTENOUGHALMSTRTHD=95, NOTENOUGHALMENDTHD=93;
```
