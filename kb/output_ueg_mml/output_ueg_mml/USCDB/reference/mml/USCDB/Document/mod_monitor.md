# 修改资源监控配置信息(MOD MONITOR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于对资源监控配置信息进行修改或者调整。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                                       |
|:--------|:---------|:-----------------------------------------------------------------------------------------------------------|
| SWITCH  | 平台资源监控开关 | 平台资源监控的开关，通过这个参数控制是否进行平台资源监控。 各参数选项的含义是： OFF(关)ON(开) 默认值：无。                                                |
| MOPTION | 监控资源列表   | 仅当本命令中的“平台资源监控开关”选择为“开”时本参数有效，用于配置需要监控的资源。 各参数选项的含义是： DAS(磁阵的状态)DBS(数据库状态)CRS(集群服务状态)SSH(主备机信任主机关系) 默认值：无。 |

## 使用实例

修改资源监控列表：打开平台资源监控开关，并且监控磁阵状态。

```
MOD MONITOR: SWITCH=ON, MOPTION=DAS-1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见本命令参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                | 原因分析                                           | 处理建议                           |
|-------:|:---------------------|:-----------------------------------------------|:-------------------------------|
| 260008 | 参数未修改。请至少指定一个待修改的参数。 | “平台资源监控开关”选择为“ON（打开）”后，“资源监控列表”参数至少指定一个待修改的参数。 | 选择需要修改的“资源监控列表”参数取值，然后重新执行本命令。 |
