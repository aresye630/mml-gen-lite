# 添加定制导出配置(ADD CUSEXPCFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于添加园区定制导出配置。

当用户需要为不同园区的导出结果文件使用不同的密码加密时，使用该命令为园区添加定制导出配置。

## 注意事项

- 同一种“FE类型”配置的“SFTP类型”必须一致，即全部为“CLIENT”或全部为“SERVER”。
- 最多可以添加1024条定制导出配置记录。
- 密码长期使用会增加被盗窃和破解的风险，而且使用的时间越长，被盗窃和破解的风险越高。定期修改密码可以有效防范这种情况的发生，因此强烈建议您定期修改密码。

## 参数说明

| 参数标识           | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                           |
|:---------------|:------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FETYPE         | FE类型        | 可选必选说明：必选参数 参数含义：本参数用于描述成功加载的插件包FE类型（可通过LST FEPLUG命令查询）。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                     |
| CAMPUSNAME     | 园区名称        | 可选必选说明：必选参数 参数含义：本参数用于唯一标识一个园区。 取值范围：由数字（0~9）、字母（a~z和A~Z）或下划线组成的长度不超过63的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                    |
| SFTPTYPE       | SFTP类型      | 可选必选说明：必选参数 参数含义：用于指定SFTP类型。 取值范围： CLIENT：表示园区导出时，本端作为客户端上传导出结果到远端。SERVER：表示园区导出时，本端作为服务端供远端下载导出结果文件。IMPORTCLIENT：表示园区导入时，本端作为客户端从远端服务器中下载导出结果文件，进行数据导入。 默认值：无。 配置原则：无。                                                                                                                                        |
| SFTPSERVERNAME | 远端SFTP服务端名称 | 可选必选说明：条件必选参数 参数含义：用于指定远端SFTP服务端的名称。 取值范围：由数字（0~9）、字母（a~z和A~Z）和下划线组成的不超过127位的字符串。 默认值：无。 配置原则：仅当该命令中“SFTP类型”参数为“CLIENT”或“IMPORTCLIENT”时该参数有效。                                                                                                                                                                  |
| STANDBYSFTP    | 备用SFTP服务端名称 | 可选必选说明：条件可选参数 参数含义：用于指定备用远端SFTP服务端的名称。 取值范围：由数字（0~9）、字母（a~z和A~Z）和下划线组成的不超过127位的字符串。 默认值：无。 配置原则：仅当该命令中“SFTP类型”参数为“IMPORTCLIENT”时该参数有效。                                                                                                                                                                         |
| SFTPUSERNAME   | SFTP用户名称    | 可选必选说明：条件必选参数 参数含义：用于指定SFTP用户名称。 取值范围：由数字（0~9）、字母（a~z和A~Z）组成，且必须以字母开头长度不超过31的字符串。 默认值：无。 配置原则：仅当该命令中“SFTP类型”参数为“SERVER”时该参数有效。                                                                                                                                                                                 |
| PWD            | 密码          | 可选必选说明：必选参数 参数含义：用于指定导出园区文件的加密密码。 密码区分大小写，其复杂度需同时满足下列条件： 密码必须至少包含以下四个类别中的三类：英文大写字母。英文小写字母。数字：0～9。特殊字符：~ ! # % ^ * ( ) _ - + [ ] { } | < > . ?。 不允许使用三个或三个以上连续的字母或数字（例如：ABC、123）。密码不能和园区名称或者园区名称的逆序一样，且不能包含园区名称或者园区名称的逆序。不允许使用三个或三个以上连续的相同字符（例如：AAA）。密码长度最短8个字符。密码的第一个字符必须是字母。 取值范围：长度不超过31的字符串。 默认值：无。 配置原则：无。 |
| CFM            | 确认密码        | 可选必选说明：必选参数 参数含义：用于指定导出园区文件的确认密码，该字符串必须与“密码”相同。 取值范围：长度不超过31的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                               |
| DESC           | 配置描述        | 可选必选说明：可选参数 参数含义：用于指定园区的配置描述。 取值范围：由数据、字母、下划线组成的长度不超过64的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                    |

## 使用实例

1. 某园区需要添加定制导出配置，本端作为客户端上传导出结果到远端时：
   - “FE类型”：“SUP-FE”
   - “园区名称”：“CAMPUStest000”
   - “SFTP类型”：“CLIENT”
   - “远端SFTP服务端名称”：“cumpustestserver000”
   - “密码”：“ab12CD34#56”
   - “确认密码”：“ab12CD34#56”
   - “配置描述”：“CAMPUStest000 Config”

   ```
   ADD CUSEXPCFG: FETYPE="SUP-FE", CAMPUSNAME="CAMPUStest000", SFTPTYPE=CLIENT, SFTPSERVERNAME="cumpustestserver000", PWD="*****", CFM="*****",  DESC="CAMPUStest000 Config";
   ```

2. 某园区需要添加定制导出配置，本端作为服务端供远端下载导出结果文件时：
   - “FE类型”：“SUP-FE”
   - “园区名称”：“CAMPUStest000”
   - “SFTP类型”：“SERVER”
   - “SFTP用户名称”：“cumpustestuser000”
   - “密码”：“ab12CD34#56”
   - “确认密码”：“ab12CD34#56”
   - “配置描述”：“CAMPUStest000 Config”

   ```
   ADD CUSEXPCFG: FETYPE="SUP-FE", CAMPUSNAME="CAMPUStest000", SFTPTYPE=SERVER, SFTPUSERNAME="cumpustestuser000", PWD="*****", CFM="*****", DESC="CAMPUStest000 Config";
   ```
3. 某园区需要添加定制导入配置，本端作为客户端从远端服务器中下载导出结果文件时：
   - “FE类型”：“SUP-FE”
   - “园区名称”：“CAMPUStest000”
   - “SFTP类型”：“IMPORTCLIENT”
   - “远端SFTP服务端名称”：“cumpustestserver000”
   - “备用SFTP服务器”：“cumpustestserver001”
   - “密码”：“ab12CD34#56”
   - “确认密码”：“ab12CD34#56”
   - “配置描述”：“CAMPUStest000 Config”

   ```
   ADD CUSEXPCFG: FETYPE="SUP-FE", CAMPUSNAME="CAMPUStest000", SFTPTYPE=IMPORTCLIENT, SFTPSERVERNAME="cumpustestserver000",STANDBYSFTP=" cumpustestserver001",PWD="*****", CFM="*****",  DESC="CAMPUStest000 Config";
   ```

**说明** 

执行本命令时，若“密码”取值为样例中的弱口令“ab12CD34#56”，执行结果会返回“260566”错误码。
