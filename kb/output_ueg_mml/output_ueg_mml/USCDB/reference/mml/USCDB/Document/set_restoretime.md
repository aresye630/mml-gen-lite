## 命令功能

**须知** 

- 该命令属于高危命令，在执行前请联系华为技术支持确认。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用来指定系统48小时内的恢复时间，命令执行成功并重启Cluster内所有节点后，可以从本地加载设置时间点的数据。

该命令使用的场景：如果当前局点由于被误操作加载了异常数据，导致用户数据异常时，可以使用该命令将数据恢复到48小时内的指定时间点来恢复业务。执行该命令并重启Cluster内所有节点后，数据将恢复到指定时间点，请谨慎操作，操作前请务必联系华为技术支持工程师确认。

## 注意事项

- 对系统的影响：
  - 指定时间恢复加载时长依赖从上一次备份到指定时间的业务量，业务量越大则需要加载的Redolog数量越多，可能会导致加载时长超过60分钟。
  - 指定时间恢复的过程中会导致所有业务中断，而且恢复成功后容灾局点需要基线重建。
  - 由于各个容器之间存在时间差异，从指定时间点恢复无法保证数据的准确性，可能造成数据的不一致、丢失或产生垃圾数据，该情况产生的异常数据需要人工介入进行清理。
  - 节点重启恢复到指定时间点的数据后，全局数据和用户数据可能不匹配，需要优先恢复全局数据。
  - 节点重启恢复到指定时间点的数据后，如果从指定时间点到当前时间点的数据全部丢失，则需要通过营帐指令和网络侧操作来恢复数据。
  - 进行指定时间加载操作之后，License会恢复到指定时间点，可能导致License数据发生变更。
- 命令成功执行需满足如下条件：
  - 指定时间恢复开关“SPCFTIMERSTSWT（指定时间恢复开关）”参数值为“1”。
  - 系统处于退服状态。
  - 升级状态开关“UPGRADESTATUS（升级状态）”参数值为“0”。
  - 当前未进行DRU扩容操作。
  - 容灾开关“REDUNDANCYSWITCH（容灾开关）”参数值为“2”或“3”。
  - 定时备份开关“TIMEBACKUPFLAG（定时备份开关）”参数值为“0”。
- 该命令执行成功后，会上报**ALM-12075 系统处于指定时间恢复数据模式**告警。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                             |
|:------------|:-------|:---------------------------------------------------------------------------------|
| SERVICETYPE | 服务类型   | 可选必选说明：必选参数。 参数含义：用于指定具体的服务类型。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。                 |
| DATE        | 日期     | 可选必选说明：必选参数。 参数含义：用于设置系统指定恢复的日期。 取值范围：系统当前时间开始向前推算48小时内的日期值。 默认值：当前日期。 配置原则：无。   |
| TIME        | 时间     | 可选必选说明：必选参数。 参数含义：用于设置系统指定恢复的时间。 取值范围： 小时为0～24。分钟为0～60。秒为0～60。 默认值：当前时间。 配置原则：无。 |

## 使用实例

设置“服务类型”为“SUP-FE”的指定时间恢复信息，“日期”为2022年4月10日，“时间”为15点58分15秒。

```
SET RESTORETIME: SERVICETYPE="SUP-FE", DATE=2022&04&10, TIME=15&58&15;
```
