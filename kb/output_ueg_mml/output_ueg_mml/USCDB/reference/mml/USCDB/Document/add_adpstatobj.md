# 添加适配测量对象(ADD ADPSTATOBJ)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

当用户需要对业务发放命令进行统计时，使用该命令添加一条适配测量对象记录。

## 注意事项

最多可以配置512条适配测量对象记录。

## 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                       |
|:---------------|:---------|:-------------------------------------------------------------------------------------------|
| ADPSTATOBJID   | 适配测量对象ID | 用于标识一条适配测量对象记录。此参数在USCDB网元下唯一。 取值范围：1～512 默认值：无。                                           |
| ADPSTATOBJNAME | 适配测量对象名称 | 用于标识一条适配测量对象的名称。此参数在USCDB网元下唯一。 取值范围：长度不超过127的字符串。 默认值：无。                                  |
| SERVICETYPE    | 业务类型     | 用于指定适配测量对象针对哪种业务类型的操作进行统计测量，该参数必须先通过LOD FEPLUG命令加载FE插件，然后才能在此引用。 取值范围：长度不超过127的字符串。 默认值：无。 |

## 使用实例

添加一条适配测量对象，设置“适配测量对象ID”为“1”，“适配测量对象名称”为“TestObj”，“业务类型”为“SUP-FE”。

```
ADD ADPSTATOBJ: ADPSTATOBJID=1, ADPSTATOBJNAME="TestObj", SERVICETYPE="SUP-FE";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                    | 原因分析                   | 处理建议                                                                     |
|-------:|:-------------------------|:-----------------------|:-------------------------------------------------------------------------|
| 275308 | 参数SERVICETYPE指定的业务类型未配置。 | 网元未加载参数“业务类型”指定的FE插件包。 | 执行LST FEPLUG命令查询已加载的FE插件包，再重新输入“业务类型”，确保其存在于查询记录中。                       |
| 335426 | 适配测量对象ID已经存在。            | 参数“适配测量对象ID”已经存在。      | 执行LST ADPSTATOBJ命令查询已经添加的适配测量对象，然后重新输入“适配测量对象ID”，确保与查询结果中的“适配测量对象ID”不重复。 |
| 335427 | 适配测量对象名称已经存在。            | 参数“适配测量对象名称”已经存在。      | 执行LST ADPSTATOBJ命令查询已经添加的适配测量对象，然后重新输入“适配测量对象名称”，确保与查询结果中的“适配测量对象名称”不重复。 |
