# 清除会话数据(CLR CLUSTER)

## 命令功能

**须知** 

- 该命令属于高危命令。该操作将会清除cluster数据，因此执行该命令前，需要与华为技术支持确认后才可以实施。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于在USCDB网元内清除Cluster数据。

- 若需要清除所有“Cluster类型”为“DSU”和“Cluster类型”为“DRU”且“数据类型”为“ROUTE\_DATA(路由数据)”的Cluster数据，请不要输入“Cluster标识”参数。
- 若需要清除某个Cluster数据，请输入“Cluster标识”。

## 注意事项

- 该命令只允许清除“Cluster类型”为“DSU”和“Cluster类型”为“DRU”且“数据类型”为“ROUTE\_DATA(路由数据)”的Cluster数据。
- 系统默认DSU模块和DRU模块在每小时38分开始备份（备份时长约5~10分钟），此时不支持执行本命令清除Cluster数据，否则，正在备份的模块上清除数据操作失败。可通过执行**DSP NODE**命令查看模块是否处于备份状态。
- 执行完本命令后，被清除数据Cluster对应的模块会复位。
- 执行完本命令后，若存在“节点状态”为“初始化”的节点，请执行**STR INITDATA**命令初始化内存数据库。“节点状态”可以通过**DSP NODE**命令查询。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                |
|:------------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 业务类型      | 用于描述要清除Cluster数据的业务类型。由LOD FEPLUG命令执行后自动生成，可通过LST FEPLUG命令进行查询。                                                                                     |
| CID         | Cluster标识 | 标识一个Cluster的关键字段，用于指定需要清除哪个Cluster的数据，该参数可以使用LST CLUSTER命令查询获得。 说明：不选表示清除所有“Cluster类型”为“DSU”和“Cluster类型”为“DRU”且“数据类型”为“ROUTE_DATA(路由数据)”的Cluster数据。 |

## 使用实例

清除“业务类型”为“SUP-FE”的Cluster数据。

```
CLR CLUSTER: SERVICETYPE="SUP-FE";
```

该命令执行正常，会返回命令执行成功的提示信息。
