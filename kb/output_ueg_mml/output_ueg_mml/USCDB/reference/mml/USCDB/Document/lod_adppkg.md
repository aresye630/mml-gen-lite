# 加载适配包(LOD ADPPKG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，该操作将加载适配包，操作不当将导致导入导出任务无法正常执行。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于加载导入、导出模板。当需要执行用户数据导出或者导入任务时，必须通过本命令加载对应类型的适配包。

## 注意事项

- 在执行本命令前，待加载的适配包必须通过OM Portal的文件传输功能上传到CGPLite容器的指定目录内，上传方法请参考产品手册“GUI参考 > 文件传输”，指定目录为“CGPLite文件 > 软件包”，并且该适配包必须使用CMS签名。上传后，需先在“CSP MML命令”界面上执行**LOD PKG**命令，然后登录“USCDB MML命令”界面执行本命令才能生效。
- 在执行此命令时，该网元中的所有PGW/DRU/DSU/DMA模块都要处于Active状态，否则处于非Active状态的PGW/DRU/DSU/DMA模块可能会返回失败或者超时。
- “适配包加载类型”和“服务类型”都相同的适配包只能加载一个。
  - 当新加载的适配包名与已加载的适配包名相同时，可直接执行此命令，新加载的适配包会覆盖之前已加载的适配包。
  - 当新加载的适配包名与已加载的适配包名不同时，需先执行**CLR ADPPKG**删除已加载的适配包，再执行本命令重新加载。
- 当前系统存在使用已加载的适配包进行的数据导出任务，重新执行**LOD ADPPKG**加载新的适配包，正在执行的导出任务仍使用之前的适配包导出数据，导出任务执行完成后，新下发的导出任务使用新的适配包进行数据导出。
- 系统存在导入任务时，不能加载导入适配包。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                  |
|:------------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ADPPKGNAME  | 适配包名称   | 用于指定待加载的适配包名称。 取值范围：长度不超过128的字符串。字符串需由字母（A～Z、a～z）、数字（0～9）和特殊字符（“.”、“_”、“+”）构成，且必须以“.tar”结尾。 默认值：无                                                                                                                                                                                                                     |
| PKGTYPE     | 适配包加载类型 | 用于指定加载的适配包类型。 取值范围： EXPORT(EXPORT): 当加载的适配包为用户数据导出相关的配置文件时，配置为EXPORT，命令执行过程中，会将适配包中Export目录下的配置文件加载到PGW和DMA模块中。IMPORT(IMPORT): 当加载的适配包为用户数据导入相关的配置文件时，配置为IMPORT，命令执行过程中，会将适配包中Import目录下的配置文件加载到所有的PGW模块和对应的DMA模块中。MIGRATE(MIGRATE): 当加载的适配包为用户迁移相关的配置文件时，配置为MIGRATE，命令执行过程中，会将适配包中Migrate目录下的配置文件加载到PGW和DMA模块中。 默认值：无 |
| SERVICETYPE | 服务类型    | 用于指定FE适配包服务类型，通过LOD FEPLUG命令加载FE插件后在此引用。如果加载的是导出PGW全局数据的模板，选择“USCDB”。 取值范围：长度不超过128的字符串。 默认值：无                                                                                                                                                                                                                        |

## 使用实例

1. 待加载的适配包通过OM Portal的文件传输功能上传到CGPLite容器的指定目录内，上传方法请参考产品手册“GUI参考 > 文件传输”，指定目录为“CGPLite文件 > 软件包”，并且该适配包必须使用CMS签名。
2. 加载适配包，“适配包名称”为“ThirdSrv.tar”，“适配包类型”为“EXPORT”，“服务类型”为“SUP-FE”。执行如下命令：

   LOD ADPPKG: ADPPKGNAME="ThirdSrv.tar", PKGTYPE=EXPORT, SERVICETYPE="SUP-FE";
