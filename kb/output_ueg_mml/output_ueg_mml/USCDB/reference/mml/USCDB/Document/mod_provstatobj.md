# 修改业务发放统计对象(MOD PROVSTATOBJ)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改业务发放统计对象的名称，修改的业务发放统计对象名称不会影响统计结果的上报。

## 注意事项

无。

## 参数说明

| 参数标识            | 参数名称       | 参数说明                                                                                                                |
|:----------------|:-----------|:--------------------------------------------------------------------------------------------------------------------|
| PROVSTATOBJID   | 业务发放统计对象索引 | 标识一条业务发放统计对象数据记录的关键字段（其取值不能被修改），用于指定业务发放统计对象的索引号，全局唯一。                                                              |
| PROVSTATOBJNAME | 业务发放统计对象名称 | 用于指定业务发放统计对象的名称，全局唯一。 该参数将在ADD PROVSTATRULE命令中被索引。 取值范围：长度不超过127位的字符串，字符串只能由数字（0～9）、英文字母（A～Z和a～z）、空格和下划线组成，必须以字母开头。 |

## 使用实例

修改业务发放统计对象，“业务发放统计对象索引”为“1”，“业务发放统计对象名称”修改为“GU Commands Statistic”：

```
MOD PROVSTATOBJ: PROVSTATOBJID=1, PROVSTATOBJNAME="GU Commands Statistic";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释           | 原因分析               | 处理建议                                                            |
|-------:|:----------------|:-------------------|:----------------------------------------------------------------|
| 274582 | 业务发放统计对象索引号不存在。 | 只能修改已经存在的业务发放统计对象。 | 执行LST PROVSTATOBJ命令查询已添加业务发放统计对象，请重新执行本命令修改已经存在的业务发放统计对象。       |
| 274580 | 业务发放统计对象名称已经存在。 | “业务发放统计对象名称”不能重复。  | 执行LST PROVSTATOBJ命令查询已存在的“业务发放统计对象名称”，请重新执行本命令输入新的“业务发放统计对象名称”。 |
