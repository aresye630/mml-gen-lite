# 修改TIPS控制配置(SET PGWTPSCTRL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令属于高危命令，该操作修改营帐指令TPS控制配置，修改不当将导致营帐指令执行失败。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置TPS控制开关、上报周期和控制周期等相关参数。

当需要根据操作员对客户端的指令进行TPS控制时，可执行本命令打开TPS控制开关，设置上报周期和控制周期。

当需要关闭TPS控制时，可执行本命令关闭TPS控制开关。

## 注意事项

- 控制开关“CTLSWITCH”初始值为“OFF”，上报周期“RPTPERIOD”初始值为“5”，控制周期“CTLPERIOD”初始值为“60”。
- 设置的控制周期“CTLPERIOD”的值要大于上报周期“RPTPERIOD”的值。
- 启动TPS控制后，将限制业务发放系统访问PGW请求消息的处理，有可能造成业务呼损。
- 本命令设置的参数对PGW上所有设置了TPS控制的操作员都生效，可通过PGW Web LMT上的**LST OPR**查询操作员设置。打开TPS控制需要依据系统实际情况进行操作。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                   |
|:----------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CTLSWITCH | 控制开关   | 用于标识TPS控制开关打开或关闭。 取值范围： OFF（关闭）ON（打开） 默认值：无。                                                                                                                           |
| RPTPERIOD | 上报周期   | 用于标识TPS上报周期，单位为秒。各PGW在一个上报周期内统计各操作员在本模块执行的命令条数，上报给负责汇总的主PGW。仅当本命令中的“CTLSWITCH”参数为“ON”时该参数有效。 取值范围：1～60 默认值：无。                                                          |
| CTLPERIOD | 控制周期   | 用于标识TPS控制周期，单位为秒。在一个控制周期内，当某操作员执行的命令条数超过该操作员的上限值时，将启动TPS控制，操作员上限在PGW Web LMT上的ADD OPR命令中被设置。本控制周期结束后自动解控并进入下一个控制周期。仅当本命令中的“CTLSWITCH”参数为“ON”时该参数有效。 取值范围：2～3600 默认值：无。 |

## 使用实例

1. 打开TPS控制，设置上报周期为10秒，控制周期为120秒：

   ```
   SET PGWTPSCTRL: CTLSWITCH=ON, RPTPERIOD=10, CTLPERIOD=120;
   ```
2. 关闭TPS控制：

   ```
   SET PGWTPSCTRL: CTLSWITCH=OFF;
   ```
