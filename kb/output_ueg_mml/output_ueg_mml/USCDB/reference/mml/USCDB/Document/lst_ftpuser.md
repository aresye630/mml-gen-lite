# 查询FTP用户(LST FTPUSER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询FTP用户信息：

- 若需要查询全部用户的详细信息，请不要输入任何参数。
- 若需要查询某个用户的详细信息，请输入“用户类型”、“用户名”、“工作路径名称”、“权限”、“用户描述”参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                   |
|:------------|:-------|:-------------------------------------------------------|
| USERTYPE    | 用户类型   | 用于指示系统需要按照哪个“用户类型”来查询FTP用户信息；若不输入，则表示查询所有服务类型的FTP用户信息。 |
| USERNAME    | 用户名    | 用于指示系统需要按照哪个“用户名”来查询FTP用户信息；若不输入，则表示查询所有用户名的FTP用户信息。   |
| WORKPATH    | 工作路径名称 | 用于指示系统按照哪个“工作路径名称”查询用户信息；若不输入，则表示查询所有工作路径名称的FTP用户信息。   |
| PERMISSION  | 权限     | 用于指示系统按照哪个“权限”查询用户信息；若不输入，则表示查询所有权限的FTP用户信息。           |
| DESCRIPTION | 用户描述   | 用于指示系统按照哪个“用户描述”查询用户信息；若不输入，则表示查询所有用户描述的FTP用户信息。       |

## 使用实例

1. 查询所有FTP用户:

   ```
   LST FTPUSER:;
   ```

   ```
   %%LST FTPUSER:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    用户类型     用户名          密码        工作路径名称        权限                    用户描述

    Prov         test            *****       UPLOAD              UPLOAD                  userinfo
    Prov         ftpuser         *****       DOWNLOAD            UPLOAD, DOWNLOAD        ftpuser
   (结果个数 = 2)

   ---    END
   ```
2. 查询“工作路径名称”为“UPLOAD”的FTP用户:

   ```
   LST FTPUSER: WORKPATH="UPLOAD";
   ```

   ```
   %%LST FTPUSER: WORKPATH="UPLOAD";%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
       用户类型  =  Prov
         用户名  =  ftpuser
           密码  =  *****
   工作路径名称  =  UPLOAD
           权限  =  UPLOAD
                 =  DOWNLOAD
       用户描述  =  ftpuser
   (结果个数 = 1)

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD FTPUSER**命令的参数说明。
