# 删除垃圾路由数据(CLR JUNKROUTE)

## 命令功能

**须知** 

该命令属于高危命令，该操作将删除垃圾路由数据。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于启动或者停止垃圾路由数据校验任务。

在DRU路由数据迁移场景下，如果DRU路由数据迁移过程中出现异常，系统会产生垃圾路由数据。可以通过启动垃圾路由数据校验任务清理这些垃圾路由数据，从而保证用户数据的可靠性。删除完毕后，系统自动停止垃圾路由校验。

**说明** 

当执行该命令启动垃圾路由数据校验任务时，可以通过设置“JRVFYUNITNUM（垃圾路由校验每周期校验对象个数）”和“JRVFYPRD（垃圾路由校验周期）”软参控制删除垃圾路由数据的速度。

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识        | 参数名称         | 参数说明                                                                                                                                |
|:------------|:-------------|:------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 业务类型         | 用于指定需要对哪种FE业务类型进行启动或者停止垃圾路由数据校验操作。每种业务类型在USCDB中是唯一的。该参数必须先通过LOD FEPLUG命令加载FE插件包，然后才能在此引用，可通过执行LST FEPLUG命令查询获取。 若不输入该参数，则表示所有的业务类型。 |
| DRUCID      | DRU Cluster号 | 用于指定是对哪个DRU Cluster标识进行启动或者停止垃圾路由数据校验操作。 取值范围：1～4096                                                                                |
| OPTYPE      | 操作类型         | 用于指定需要进行启动还是停止垃圾路由校验。 各参数选项的含义是： STOP(停止垃圾路由校验)：表示停止正在运行的垃圾路由数据校验。START(开始垃圾路由校验)：表示启动垃圾路由数据校验。                                     |

## 使用实例

启动SUP\_FE业务类型“DRU Cluster标识”为“130”的垃圾路由数据校验流程，执行命令如下：

```
CLR JUNKROUTE: SERVICETYPE="SUP-FE", DRUCID=130, OPTYPE=START;
```


## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见表1的参数说明。

| 输出项名称     | 输出项解释                             |
|:----------|:----------------------------------|
| Cluster标识 | 用于返回进行启动或者停止垃圾路由数据校验操作的Cluster标识。 |
| FE类型      | 用于返回进行启动或者停止垃圾路由数据校验操作的业务类型。      |
| 返回结果描述    | 用于返回命令的执行结果是成功还是失败。               |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|   错误码 | 错误码解释           | 原因分析                                                                                | 处理建议                                                                                                  |
|------:|:----------------|:------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------|
|  2114 | 业务类型不存在         | 输入的“业务类型”不存在。                                                                       | 执行LST FEPLUG命令查看已加载的FE插件包，即业务类型。 FE插件包加载成功，在执行该命令时输入正确的业务类型。FE插件包加载失败，通过LOD FEPLUG命令加载FE插件包后，重新执行该命令。 |
|  2115 | DRU节点不存在        | 输入的“DRU Cluster号”对应的节点不存在。                                                          | 执行ADD NODE命令为Cluster增加节点，然后重新执行本命令。                                                                   |
|  2116 | DRU Cluster不存在  | 输入的“DRU Cluster号”不存在。                                                               | 执行LST CLUSTER命令查询系统中存在的DRU Cluster标识，然后重新执行本命令。                                                       |
|  2125 | 不是路由DRU cluster | DRU Cluster的数据类型有“全局数据”和“路由数据”，而本命令是用于删除垃圾路由数据，因此本命令输入的“DRU Cluster号”的数据类型应为“路由数据”。 | 执行LST CLUSTER命令查询“数据类型”为“路由数据”的DRU Cluster，然后重新执行本命令。                                                 |
|  2119 | FE类型和Cluster不匹配 | 输入的“业务类型”参数和“DRU Cluster号”参数取值不匹配。                                                  | 执行LST CLUSTER命令查询“DRU Cluster号”对应的FE类型，然后重新执行本命令。                                                     |
