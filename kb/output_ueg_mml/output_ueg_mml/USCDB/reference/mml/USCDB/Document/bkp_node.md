# 备份节点数据(BKP NODE)

- 命令功能

- 参数说明

- 输出结果说明

## 命令功能

该命令用于将节点的内存库中的数据备份到虚拟机硬盘（裸机硬盘）上。

该命令主要用于升级场景，在升级前准备阶段，需要对节点数据进行备份。

## 注意事项

- 不允许对同一Cluster中的多个节点同时执行该命令，否则将会导致部分业务中断。
- 备份指定节点的内存数据库，备份的文件所在目录为：“/opt/uscdb/snp/Dump\_LID\_MID”。

  **说明** 

  - “LID”表示节点所在Location的标识，可以通过**LST LOCATION**命令查询。
  - “MID”表示节点的模块号，可以通过**LST NODE**命令查询。

## 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                                                                                                                               |
|:--------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CID     | Cluster标识 | 用于定义一个待备份节点所属Cluster的Cluster标识。Cluster标识在2～4096的Cluster是通过ADD CLUSTER定义后在此引用，而Cluster标识为1的Cluster是添加USCDB网元时，系统自动生成供内部使用，不需要手工添加。 取值范围：0～4096 默认值：无。 说明：当该参数和“节点标识”参数同时取值为“0”时，表示备份所有节点。           |
| NID     | 节点标识      | 用于定义一个待备份节点的节点标识。操作人员可通过LST NODE获取节点信息。 取值范围：0～32768 默认值：无。 说明：当该参数和“Cluster标识”参数同时取值为“0”时，表示备份所有节点。                                                                                               |
| BKPTYPE | 备份类型      | 用于定义一个待备份节点的备份类型。 该参数的配置原则：正常备份只能备份Slave节点，不能备份Master节点，Master节点仍提供业务，因此正常备份不会影响业务提供。强制备份是不管备份的节点是否在处理业务，直接进行备份，对于Master节点和Slave节点都可以使用，对Master节点备份容易造成业务中断。 取值范围： NORMAL(正常备份)FORCED(强制备份) 默认值：无。 |
| LOCINFO | 位置信息      | 用于定义一个待备份节点的位置信息。 取值范围： LOCAL(本地)REMOTE(远端) 默认值：LOCAL(本地)。                                                                                                                                         |

## 使用实例

升级场景下，对待升级节点进行备份。

1. 执行**DSP NODE**命令，查询网元内待备份节点的状态。

   查询后的报文如下所示：

   ```
   %%DSP NODE:;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------
    Cluster标识  节点标识  节点状态  备份状态  CPU占用率(%)  流控状态  手动指定Master  IMDB版本  共享内存创建时间     共享内存容量(兆字节)  共享内存占用率(%)  加载源       加载时间             节点对象数量  校验消息队列大小  校验消息队列使用率  复制消息队列大小  复制消息队列使用率  同步消息队列大小  同步消息队列使用率   应急加载开关  应急加载模式

    1            60        Slave     未备份    0             关        否              3.34      2011-05-04 16:24:16  128                   18                 Master       2011-05-04 16:24:16  0             0                 0                   0                 0                   0                 0                    关            否
    1            61        Master    未备份    0             关        否              3.34      2011-05-04 16:23:56  128                   18                 本地目录     2011-05-04 16:23:56  0             0                 0                   0                 0                   0                 0                    关            否
    62           62        Master    未备份    0             关        否              3.34      2011-05-04 16:23:58  128                   14                 本地目录     2011-05-04 16:23:58  0             0                 0                   0                 0                   0                 0                    关            否
   (结果个数 = 3)

   ---    END
   ```
2. 采用正常备份的方式备份Slave节点，待备份节点的节点标识为100，节点所在Cluster的Cluster标识为100。具体命令如下：

   ```
   BKP NODE: CID=100, NID=100, BKPTYPE=NORMAL;
   ```
3. 等待一分钟后，重复执行**DSP NODE**，确认输出报文中，执行备份操作的Slave节点的“备份状态”为“未备份”。
4. 采用强制备份的方式备份Master节点，待备份节点的节点标识为101，节点所在Cluster的Cluster标识为100。具体命令如下：

   ```
   BKP NODE: CID=100, NID=101, BKPTYPE=FORCED;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 260104 | 该cluster不存在。                    | 输入的“Cluster标识”在系统中未配置。                                 | 通过LST CLUSTER命令查询已配置的“Cluster标识”，然后重新执行本命令。                                                                                      |
| 260113 | 参数NID指定的节点在参数CID指定的cluster中不存在。 | 输入的“节点标识”在cluster中未配置。参数“Cluster标识”和“节点标识”中存在一个取值为“0”。 | 通过LST NODE命令查询已配置的“节点标识”和“Cluster标识”，然后重新执行本命令。参数“Cluster标识”和“节点标识”取值必须同时为“0”或者同时不为“0”。 说明： 本版本仅支持“Cluster标识”和“节点标识”参数取值同时不为“0”。 |
| 260115 | 参数NID指定的节点不存在。                  | 输入的“节点标识”在系统中未配置。                                      | 通过LST NODE命令查询已配置的“节点标识”，然后重新执行本命令。                                                                                              |
