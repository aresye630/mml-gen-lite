# 添加PGW业务消息侦听端口(ADD PORT)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

该命令用于增加PGW开放给业务发放系统的端口。

当系统提供的默认端口（参见PGW端口配置管理）无法满足业务发放系统的需求时，可以使用本命令增加自定义端口给业务发放系统使用。

在该命令中，以下关键参数需要与对端的业务发放系统协商：

- “端口子类型”
- “端口的握手类型”
- “端口的握手内容”
- “握手消息长度”
- “是否连接立即发送握手消息”

## 注意事项

- 增加端口后，必须在USCDB网元下执行**RST MODULE**重启所有PGW模块才能使新增加的端口生效。由于本操作可能会导致短暂的业务发放指令执行失败，为确保系统的安全与稳定运行，除非紧急排除故障的需要，一般建议在系统话务量少的时间段（例如凌晨2:00～4:00）执行，并提前做好准备。
- 配置参数“PORTTYPENAME”应注意以下内容：
  - 取值为“PORT\_FOR\_SOAP”时，使用的SOAP端口协议类型，基于**“TLSMODE（TLS工作模式）”**软参控制。**“TLSMODE（TLS工作模式）”**软参默认值“3”，系统推荐使用TLS，即使用HTTPS协议，提高通信传输的安全性。
  - 取值为“PORT\_FOR\_MML”时，使用的MML端口推荐开启SSH安全通道，通过**ADD PGWSSHUSER**命令添加SSH用户，从而实现业务发放系统通过SSH加密的方式和PGW交互，提高通信传输的安全性。
  - 取值为“PORT\_FOR\_REST”或“PORT\_FOR\_MML”时，使用的REST端口或MML端口协议类型，参数“是否使用HTTPS”建议使用默认值“YES”，即使用安全性较高的HTTPS协议，HTTP协议是不安全的协议，存在传输信息泄露的风险。
  - 取值为“PORT\_FOR\_REST”时，当参数“是否使用头域鉴权”取值为“NO”时，为提升安全性，建议修改为“YES”，即PGW对业务发放系统发送过来的REST消息的头域中携带的登录信息进行登录鉴权。
  - 取值为“PORT\_FOR\_HTTP”时，使用的HTTP端口协议类型，参数“是否使用HTTPS”建议使用默认值“YES”，即使用安全性较高的HTTPS协议，HTTP协议是不安全的协议，存在传输信息泄露的风险。
- 当新添加PGW业务消息侦听端口时，如果软参“SSHSFTPSRVSEPARATION”的取值为“1”（执行**LST INSP**命令查看软参“SSHSFTPSRVSEPARATION”的取值是否为“1”。），则此时“端口号”参数取值不能为“20022”，否则会添加失败，并返回错误码275435。

## 参数说明

| 参数标识         | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|:-------------|:-------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PORTNO       | 端口号          | 用于指定增加的PGW开放给业务发放系统和Web LMT使用的端口的编号。 取值范围： 当参数“端口类型”为“PORT_FOR_WEBLMT”时，端口号取值范围为：1～65534。 当参数“端口类型”为“PORT_FOR_PROV”时，端口号取值范围为：1～65535，建议端口范围为1025～65535。 默认值：无                                                                                                                                                                                                                                                                                                                                               |
| PORTTYPE     | 端口类型         | 用于指定PGW开放的端口类型。 取值范围： PORT_FOR_WEBLMT: 表示PGW开放给Web LMT使用的端口。 PORT_FOR_PROV：表示PGW开放给业务发放系统的端口。 默认值：无                                                                                                                                                                                                                                                                                                                                                                                                          |
| PORTTYPENAME | 端口子类型        | 用于指定PGW开放给业务发放系统的端口的协议类型。 取值范围： PORT_FOR_REDIRECT：表示PGW开放给Web LMT Server客户端重定向的端口。当用户需要HTTP跳转到HTTPS方式登录时选择此选项。 PORT_FOR_SOAP：表示PGW开放给业务发放系统的SOAP端口。当对端使用的是SOAP协议类型的端口时选择此选项。 PORT_FOR_MML：表示PGW开放给业务发放系统的MML端口。当对端使用的是MML类型的端口时选择此选项。 PORT_FOR_REST：表示PGW开放给业务发放系统的REST服务端口。当对端使用的是REST协议类型的端口时选择此选项。PORT_FOR_HTTP：表示PGW开放给业务发放系统的HTTP端口。当对端使用的是HTTP协议类型的端口时选择此选项。 默认值：无                                                                                                                                     |
| DISABLEPORT  | 是否屏蔽本端口      | 用于控制是否对新增的端口进行屏蔽。 该参数的配置原则是：通常情况下该参数使用默认值即可。当增加的端口暂时不需要使用时，为了保证网络安全（例如防止第三方利用端口对系统发起攻击等）可以选择“YES”进行屏蔽。待需要启用时再执行MOD PORT命令直接打开即可。避免要生效端口而重启所有PGW进程对业务造成影响。 YES(是)：系统对此端口进行屏蔽，被屏蔽后端口失效。 NO(否)：系统不对此端口进行屏蔽，端口可正常工作。 默认值：NO(否)。                                                                                                                                                                                                                                                                                  |
| PORTBUSSTYPE | 端口业务类型       | 用于指定PGW开放给业务发放系统的端口对应的业务类型。当前支持通过该命令添加FE类型和USCDB类型的端口业务类型： 当添加FE类型的端口业务类型时，此参数需通过LOD FEPLUG命令加载对应的FE插件包后才能在此进行设置。当需要接入无插件包的ENS/UIM/MNP/EIR应用类型的营帐系统，参数“端口子类型”取值为“PORT_FOR_SOAP”或“PORT_FOR_MML”时，可选择添加“USCDB”类型的端口业务类型。 说明： 系统默认不提供“端口业务类型”为“USCDB”的REST服务端口，也不能通过此命令增加。但默认提供“端口业务类型”为“USCDB”的其他服务端口，不需要手工增加即可使用。 取值范围：长度不超过128字节的字符串 默认值：无 配置原则： 当参数“端口类型”为“PORT_FOR_PROV”并且“端口子类型”为“PORT_FOR_SOAP”、“PORT_FOR_MML”或“PORT_FOR_REST”、“PORT_FOR_HTTP”时此参数有效且必须配置。当添加FE类型的端口业务类型时，该参数必须与通过PGW开放给业务发放系统的FE类型保持一致。 |
| PORTSHKTYP   | 端口的握手类型      | 用于指定PGW与业务发放系统之间的握手类型。 当参数“端口子类型”为“PORT_FOR_MML”时此参数有效且必须配置。此参数需要和对端的业务发放系统所使用的握手类型保持一致。 取值范围：NORMAL：表示PGW和业务发放系统互相发送握手消息。RCVONLY：表示PGW只接收来自业务发放系统的握手消息，但不向业务发放系统发送握手消息。RESPONSE：表示PGW接收来自业务发放系统的握手消息，并向业务发放系统发送它刚接收到的握手消息。RSPWITHRPT：表示PGW接收来自业务发放系统的握手消息，并以MML消息格式向业务发放系统发送握手消息。 默认值：无                                                                                                                                                                                                                     |
| PORTCONTENT  | 端口的握手内容      | 用于指定PGW与业务发放系统之间的握手消息内容。 当参数“端口子类型”为“PORT_FOR_MML”时此参数有效且必须配置。此参数需要和对端的业务发放系统所使用的握手内容保持一致。 取值范围： SHK-HND：表示PGW与对端的业务发放系统的握手消息内容为SHK-HND。SHK-HAND：表示PGW与对端的业务发放系统的握手消息内容为SHK-HAND。 默认值：SHK-HND                                                                                                                                                                                                                                                                                                                |
| SHKLEN       | 握手消息长度       | 用于指定系统与业务发放系统之间的握手消息的长度。握手消息的长度为9个字节或10个字节。 当“端口的握手内容”为“SHK-HND”时此参数有效。 该参数的配置原则是：此参数需要和对端的业务发放系统所使用的握手消息长度保持一致。 取值范围：9～10 默认值：9                                                                                                                                                                                                                                                                                                                                                                             |
| SNDSHKIMM    | 是否连接立即发送握手消息 | 用于控制在PGW与业务发放系统之间的连接建立之后是否立即发送握手消息。 当“端口的握手类型”为“NORMAL”时此参数有效。此参数需要和对端的业务发放系统所使用的发送设置保持一致。 取值范围： SNDIMMEDIATELY：立即发送握手消息。SNDDELAY：延迟20秒发送握手消息。SNDONCEONLY：只发送一次握手消息。 默认值：SNDIMMEDIATELY(立即发送握手消息)                                                                                                                                                                                                                                                                                                            |

| HTTPS        | 是否使用HTTPS    | 仅当本命令中的“端口子类型”参数选择为“PORT_FOR_REST”、“PORT_FOR_HTTP”或“PORT_FOR_MML”时该参数有效，用于设置REST端口、HTTP端口或MML端口是否使用HTTPS协议。 取值范围：YES(是)：使用HTTPS协议。NO(否)：使用HTTP协议。 默认值：YES(是)  说明： 如果该参数取值为“NO(否)”，即使用HTTP协议，会上报ALM-10031 系统存在不安全的配置项告警。                                                                                                                                                                                                                                                                                      |
| HTTPVER      | HTTP协议版本     | 仅当本命令中的“端口子类型”参数选择为“PORT_FOR_REST”时该参数有效，用于设置REST端口的HTTP协议版本。 取值范围： HTTP1.1HTTP2.0 默认值：HTTP1.1                                                                                                                                                                                                                                                                                                                                                                                                               |

## 使用实例

某业务类型需要PGW为业务发放系统开放自定义的SOAP类型端口，需要进行如下操作：

1. 执行本命令增加端口，“端口号”为“8002”，“端口类型”为“PORT\_FOR\_PROV”，“端口子类型”为“PORT\_FOR\_SOAP”，“是否屏蔽本端口”为“否”，“端口业务类型”为“USCDB”：

   ```
   ADD PORT: PORTNO=8002, PORTTYPE=PORT_FOR_PROV, PORTTYPENAME=PORT_FOR_SOAP, DISABLEPORT=NO, PORTBUSSTYPE="USCDB";
   ```
2. 执行**RST MODULE**命令重启PGW进程使配置生效。
