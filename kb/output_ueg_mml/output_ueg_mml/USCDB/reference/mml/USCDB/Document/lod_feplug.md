# 添加FE插件(LOD FEPLUG)

## 命令功能

**须知** 

该命令属于高危命令，该操作将加载插件包，操作不当将导致业务访问完全中断。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于为USCDB网元添加指定的FE插件。

该命令的使用场景：在开局或者改造场景下，通过OM Portal执行此命令安装FE插件包，使USCDB能为FE网元提供相应的数据服务。

## 注意事项

- 在执行本命令前，FE插件包必须通过OM Portal的文件传输功能上传到CGPLite容器的指定目录内，上传方法请参考产品手册“GUI参考 > 文件传输”，指定目录为“CGPLite文件 > 软件包”，并且该插件包必须使用CMS签名。上传后，需先在“CSP MML命令”界面上执行**LOD PKG**命令，然后登录“USCDB MML命令”界面执行本命令才能生效。
- 在执行本命令后，还需要执行**ACT FEPLUG**命令并且重启PGW模块，新加载的插件包才能生效。
- 该命令不允许进行批操作。
- 执行该命令不输入参数“FE插件包名称”时，插件包名称中必须包含“\_PLUG”，否则命令会执行失败。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。

## 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                                                                                                                                                                                     |
|:-----------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| UPFILENAME | FE插件包名称   | 用于描述FE网元插件包的名称。插件包名称的格式通常为“FE类型名称+PLUG+版本号.tar”。例如“SUP-FE_PLUG_V900R008C02.tar”表示该插件包为SUP-FE网元的V900R008C02版本的插件包。 取值范围：长度不超过128的字符串。字符串需由字母（A～Z、a～z）、数字（0～9）和特殊字符（.、_、-、+、=、英文括号和空格）构成。 默认值：“无”。                                                         |
| LODMODE    | FE插件包加载模式 | 用于描述插件包的加载模式。单FE业务类型局点：采用默认值即可，不需要单独设置；多FE业务类型局点：对于UDM产品，此值要设置为“MAT”，而对于非UDM产品，采用默认值“SAT”即可，不需要单独设置。 取值范围：“SAT(单应用类型)”：插件包加载后只呈现一个FE类型。“MAT(多应用类型)”：插件包加载后呈现多个FE类型。 默认值：“SAT(单应用类型)”。                                                                    |
| FETYPENAME | FE类型名称    | 用于描述加载生成的FE业务类型的名称。该参数仅在加载模式选择单应用类型时出现。此参数现有的有效值请参考“CSP MML命令”界面的LST PKG命令“网元类型”参数中的UDM网元。对于UDM产品，该参数不输入时，系统默认“HSS9860”。如果需要对外呈现为具体业务类型，可以在新建局加载插件包时设置此参数值为某一业务类型。对于非UDM产品，不需要单独设置此参数，采用默认值即可。 取值范围：长度不超过128的字符串 默认值：“无”  说明： 该参数仅适用于UDM网元，其它网元当前版本暂不支持。 |

## 使用实例

1. USCDB需要加载SUP-FE插件包对外提供数据服务，插件包名称为“SUP\_FE\_PLUG\_V900R008C02.tar”。此时需要进行如下操作：

   ```
   LOD FEPLUG: UPFILENAME="SUP-FE_PLUG_V900R008C02.tar";
   ```
2. 对于融合插件包例如“HSS9860\_PLUG\_V900R008C20SPC010.tar”，其中version\_match\_info.xml文件配置了多个FE类型，例如HSS9860和IMS-HSS。当要进行单应用类型加载且让加载后的FE类型呈现为IMS-HSS，可以进行如下操作：

   ```
   LOD FEPLUG: UPFILENAME="HSS9860_PLUG_V900R008C20SPC010.tar", LODMODE=SAT, FETYPENAME="IMS-HSS";
   ```
3. 当要进行多应用类型加载让加载后呈现多个FE类型，可以进行如下操作：

   ```
   LOD FEPLUG: UPFILENAME="HSS9860_PLUG_V900R008C20SPC010.tar", LODMODE=MAT;
   ```
