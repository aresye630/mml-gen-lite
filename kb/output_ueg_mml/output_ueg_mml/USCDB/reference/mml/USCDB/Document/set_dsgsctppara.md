# 设置DSG模块SCTP参数配置信息(SET DSGSCTPPARA)

- 命令功能

- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，该操作将修改通信接口参数，操作不当将造成业务严重损失，且根据该命令联机帮助注意事项识别本次修改是否涉及冷参，如果涉及冷参则需要重启服务才会生效。如果修改CHKSUMEFFECTIMMD为TRUE，需要所有对接的远端局点均设置CHKSUMEFFECTIMMD为TRUE，否则请勿修改CHKSUMEFFECTIMMD。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在数据库中设置DSG模块的SCTP链路配置信息。主要包括重传超时时间（Retransmission Time-Out）配置，重传配置，校验配置，拥塞阈值配置等。局点对链路有特殊要求时通过此命令对SCTP配置信息修改。

该命令的使用场景：该命令仅用于开局场景通信异常时调测。

## 注意事项

- 该命令在配置后，如果指定的一个或多个参数中含有冷参，只有通过**RST MODULE**命令重新启动DSG后才会生效。

  该命令中的冷参包括：“报文重发间隔初始值”、“报文重发间隔最小值”、“报文重发间隔最大值”、“Rto Alpha值”、“Rto Beta值”、“Cookie有效生命期”、“偶联最大重传次数”、“路径最大重传次数”、“初始化最大重传次数”、“心跳消息间隔”、“校验和算法”、“无拥塞级阈值”、“低拥塞级阈值”、“高拥塞级阈值”、“拥塞控制开关”、“业务基值端口”、“绑定开关”、“最大偶联数”和“建链模式”。只有当参数“校验和修改立即生效开关”取值为“TRUE（是）”时，参数“发送消息时计算校验和”和“接收消息时检查校验和”为热参，否则依然为冷参。
- 设置该命令的业务基值端口值时，先执行**LST DSGTUPDISPTYP**命令查看DSG五元组分发类型，如果配置为“通配”，则“业务基值端口”值不能超过“30000”。
- 设置该命令时，保证FE侧与BE侧配置完全相同。
- 系统在初始化时已经自动配置的初始值如下所示：

- 该命令不允许进行批操作。
- 该命令必须在华为技术支持工程师指导下使用，严禁私自执行。
- 如下参数需要对接网元协同修改：
  - Cookie有效生命期
  - 发送消息时计算校验和
  - 接收消息时检查校验和
  - 校验和算法
  - 业务基值端口
  - 最大偶联数
  - 建链模式
- 在IPV4/IPV6双栈场景下，“建链模式”不允许配置成“奇偶模式”，否则会导致DSG建链模式检查失败。

| HBINTER               | 心跳消息间隔      | 用于定义心跳间隔时间。用于计算在空闲时间时，来自SCTP主机的相邻2条心跳消息的间隔。心跳传送不仅依赖于此参数，也依赖于偶联的当前RTO。 单位：毫秒 取值范围：1000～30000 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                         |

## 使用实例

修改“报文重发间隔初始值”为“1000”。

`SET DSGSCTPPARA: ID=1, RTOINIT=1000;`
