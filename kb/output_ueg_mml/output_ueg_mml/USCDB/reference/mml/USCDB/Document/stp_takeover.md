# 停止接管状态(STP TAKEOVER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

- 该命令属于高危命令，该命令会影响主用局和容灾局之间的数据处理流程。请在执行完成STR GLBDATAVFY命令后再执行该命令。因此执行该命令前，需要与华为技术支持确认后才可以实施。
- 该操作为系统高危操作，需要第二个具有二次授权权限的用户授权后才能执行该操作。请输入授权用户名和密码。

该命令用于停止容灾自动接管状态，适用于以下两个场景：

- 非A-A组网下，用于停止业务发放自动接管状态。
- A-A组网下，用于停止A-A组网下Cluster接管状态。

## 注意事项

- 在执行该命令之前，请务必先执行**STR GLBDATAVFY**命令，待**STR GLBDATAVFY**命令执行完毕之后，再执行该命令，否则，容灾局在自动接管期间修改的全局数据可能丢失而导致业务呼损。
- 当**MOD INSP**命令中参数“AAMODESWITCH（A-A组网开关）”取值为“0”时，执行该命令时只允许携带参数“业务类型”。“AAMODESWITCH（A-A组网开关）”的取值可以通过**LST INSP**命令查询。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                                                                          |
|:------------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 业务类型       | 用于指示需要停止接管状态的业务类型，该参数必须先通过LOD FEPLUG命令加载FE插件，然后才能在此引用。                                                                                                        |
| CT          | Cluster类型  | 仅当MOD INSP命令中参数“AAMODESWITCH（A-A组网开关）”取值为“1”时该参数有效且必须配置，用于指示需要停止接管状态的Cluster类型。 取值范围：DRU(DRU)DSU(DSU) 默认值：无。                                                  |
| LOCID       | Location标识 | 仅当本命令中的“Cluster类型”参数值为“DSU”时该参数有效，用于指示需要停止接管状态的Location。该参数须在对接的远端USCDB网元中先定义，然后在本端网元通过ADD RLOCATION命令配置，或者直接在本端网元SET LOCATION命令配置，才能在此处索引。 取值范围：1～512 默认值：无。 |
| CID         | Cluster标识  | 仅当本命令中的“Cluster类型”参数值为“DSU”时该参数有效，用于指示需要停止接管状态的Cluster。该参数是通过ADD CLUSTER定义后在此引用。 取值范围：1～4096 默认值：无。                                                           |

## 使用实例

1. 非A-A组网下停止自动接管状态，业务类型为SUP-FE：

   ```
   STP TAKEOVER: SERVICETYPE="SUP-FE";
   ```
2. A-A组网下停止自动接管状态，业务类型为SUP-FE、Cluster类型为DSU、Location标识为1、Cluster标识为512：

   ```
   STP TAKEOVER: SERVICETYPE="SUP-FE", CT=DSU, LOCID=1, CID=512;
   ```
