# 检查恢复目录(CHK RESTOREDIR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于检查指定目录恢复文件是否完整。当恢复源完整时，可以进行数据恢复操作。

## 注意事项

磁盘空间不足时会触发Redo清理机制删除备份文件，可能导致执行该命令检查“CURRENT(今日周期备份)”或“LAST(昨日周期备份)”时出现备份文件不完整的情况，需查看是否有ALM-14034 目录大小超过最大值告警，如有，请参见相应的告警帮助进行处理后重新执行该命令。否则请联系华为技术支持处理。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                      |
|:------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
| SERVICETYPE | 服务类型   | 用于指定具体的服务类型。此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。 取值范围：长度不超过128的字符串。 默认值：无。                                                                             |
| DIRECTORY   | 目录     | 用于设置指定系统恢复的目录。 取值范围：EMGRST(紧急恢复目录)：目录为“/opt/uscdb/emgRst”。CURRENT(今日周期备份)：目录“/opt/uscdb/snp”中当天周期性备份文件。LAST(昨日周期备份)：目录“/opt/uscdb/snp”中前一天周期性备份文件。 默认值：无。 |

## 使用实例

检查指定目录恢复文件是否完整。

```
CHK RESTOREDIR: SERVICETYPE="SUP-FE", DIRECTORY=EMGRST;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见表1的参数说明。

| 输出项名称     | 输出项解释                                                                        |
|:----------|:-----------------------------------------------------------------------------|
| Cluster标识 | 用于表示节点所属的Cluster标识。                                                          |
| 节点标识      | 用于表示节点的节点标识，此参数在Location内唯一。                                                 |
| 指定目录      | 指定系统恢复的目录。                                                                   |
| 备份时间      | 用于表示指定目录恢复文件备份的本地时间。                                                         |
| 结果        | 用于返回主机侧对指定恢复目录文件完整性检查结果。结果类型以及代表的含义如下： 完整：表示指定恢复目录内文件完整。 不完整：表示指定恢复目录内文件不完整。 |
