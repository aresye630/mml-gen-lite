# 增加远端DSG(ADD RDSG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加远端DSG模块，使本端DSG模块和远端DSG模块进行通信。当USCDB需进行容灾对接配置或与华为FE对接时，通过此命令增加一条远端DSG配置。

USCDB配置对接通常有以下步骤：

1. 通过**ADD RLOCATION**命令增加远端Location标识。
2. 通过**ADD RDSG**增加远端DSG模块。
3. 通过**ADD RIPADDR**命令增加远端IP地址。

在对接双方都经过以上配置之后，通过**ACT IPDISP**命令激活链路，完成USCDB的对接配置。

## 注意事项

- 首先通过**ADD RLOCATION**命令配置远端Location后，才能通过该命令配置远端DSG。
- 本端DSG工作正常，远端Location中需要存在DSG模块。
- 需要配置远端Location中所有存在的DSG模块。

## 参数说明

| 参数标识     | 参数名称         | 参数说明                                                                                                                                                                                                                                                    |
|:---------|:-------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RLOCID   | 远端Location标识 | 用于标识远端Location，远端Location和远端网元一一对应。远端Location在不同场景下是相对的，具体如下：对于主用局FE，它的远端Location指主用局USCDB、容灾局USCDB。对于主用局USCDB，它的远端Location指主用局FE、容灾局FE、容灾局USCDB。对于容灾局FE，它的远端Location指容灾局USCDB、主用局USCDB。对于容灾局USCDB，它的远端Location指容灾局FE、主用局FE、主用局USCDB。 取值范围：1～512 默认值：无。 |
| RDSGMID  | 远端DSG模块号     | 用于指定远端DSG模块号。远端DSG模块在不同场景下是相对的，具体如下：对于主用局FE，它的远端DSG模块指主用局USCDB、容灾局USCDB的DSG模块。对于主用局USCDB，它的远端DSG模块指主用局FE、容灾局FE、容灾局USCDB的DSG模块。对于容灾局FE，它的远端DSG模块指容灾局USCDB、主用局USCDB对外的DSG模块。对于容灾局USCDB，它的远端DSG模块指容灾局FE、主用局FE、主用局USCDB的DSG模块。 取值范围：1～2047 默认值：无。           |
| RDSGST   | 远端DSG业务类型    | 用于表示远端DSG的业务类型，此参数在USCDB下唯一，通过LOD FEPLUG命令加载FE插件后在此引用。当进行BE间的容灾对接配置时，远端DSG业务类型必须配置为该远端DSG在远端Location上所配置的业务类型，而不能配置成USCDB类型。 取值范围：长度不超过128的字符串。 默认值：无。                                                                                                  |
| RDSGTYPE | 远端DSG类型      | 用于指定远端DSG的类型。 取值范围： DSG：表示大颗粒中的DSG。DBS：表示dbbroker微服务。 默认值：DSG。                                                                                                                                                                                          |

## 使用实例

在配置对接时，增加远端Location标识后，增加一条远端DSG配置：“远端Location标识”为“3”，“远端DSG业务类型”为“SUP-FE”，“远端DSG模块号”为“3”，“远端DSG类型”为“DSG”。

```
ADD RDSG: RLOCID=3, RDSGMID=3, RDSGST="SUP-FE", RDSGTYPE=DSG;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释                                           | 原因分析                                                         | 处理建议                                                                                        |
|-------:|:------------------------------------------------|:-------------------------------------------------------------|:--------------------------------------------------------------------------------------------|
| 275126 | 远端Location为FE时，RDSGST参数所指业务类型必须与RLOCID所属业务类型相同。 | 指定的“远端DSG业务类型”与在ADD RLOCATION命令中配置的FE业务类型不匹配。                | 通过LST RLOCATION命令查询配置的业务类型，在本命令中填写“远端DSG业务类型”与查询结果保持一致，然后重新执行本命令。                           |
| 275133 | 参数RDSGST不能指定为USCDB。                             | 输入的参数“远端DSG业务类型”为“USCDB”。                                    | 请选择正确的“远端DSG业务类型”，然后重新执行本命令。                                                                |
| 302003 | 远端location不存在。                                  | 必须先配置远端Location，再配置远端DSG。                                    | 通过ADD RLOCATION命令先配置远端Location，再在本命令中引用。                                                    |
| 302500 | 该远端DSG模块已被同一远端location中的另一DSG使用。                | 不能重复加载同一个远端DSG。                                              | 通过LST RDSG命令确认填写不重复的“远端DSG模块号”，然后重新执行本命令。                                                   |
| 302606 | RDSGTYPE必须为DSG。                                 | 当指定的“远端Location标识”对应的“远端网元类型”为“USCDB”时，“远端DSG类型”的取值必须为“DSG”。 | 当该命令指定的“远端Location标识”对应的“远端网元类型”为“USCDB”时（可通过LST RLOCATION命令查询），输入“远端DSG类型”为“DSG”后，重新执行本命令。 |
