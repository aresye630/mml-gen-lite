# 删除用户数据统计对象(RMV STRNGEX)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一个用户数据统计对象。

## 注意事项

- 在加载业务网元插件包时，系统自动增加一个对象ID为OBJECT0的统计对象，针对所有用户进行统计，对象OBJECT0只允许查询，不允许添加、删除和修改。
- 以下九种类型的统计对象允许进行查询、添加、删除和修改操作：对所有用户进行统计、按HLRSN统计、按号段统计、按RN统计、按源RN和目的RN统计、按MME主机名后缀统计、按VLRNUM前缀统计、按APN名称统计、按NPRN统计。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                    |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------|
| NETTYP   | 网元类型   | 可选必选说明：必选参数 参数含义：标识一条用户数据统计对象数据记录的关键字段之一（其取值不能被修改），用于指定需要删除哪一个网元类型对应的用户数据统计对象，操作员可以使用LST STRNGEX命令查询获得。 取值范围：长度不超过128的字符串。 默认值：无 配置原则：无 |
| OBJECTID | 统计对象ID | 可选必选说明：必选参数 参数含义：标识一条用户数据统计对象数据记录的关键字段之一（其取值不能被修改），用于指定需要删除哪一个统计对象，操作员可以使用LST STRNGEX命令查询获得。 取值范围：OBJECT1～OBJECT829 默认值：无 配置原则：无        |

## 使用实例

删除用户数据统计对象，“网元类型”为“SUP-FE”，“统计对象ID”为“OBJECT1”。

```
RMV STRNGEX: NETTYP="SUP-FE", OBJECTID=OBJECT1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|    错误码 | 错误码解释     | 原因分析                | 处理建议                                                    |
|-------:|:----------|:--------------------|:--------------------------------------------------------|
| 258120 | 对象不存在。    | “统计对象ID”不存在。        | 请执行LST STRNGEX命令查看已存在对象，在已存在的对象上执行本命令。                  |
| 258128 | 不允许操作对象0。 | “统计对象ID”为“OBJECT0”。 | 执行LST STRNGEX命令查看确认是否已存在对象，不存在则执行ADD STRNGEX增加对象再执行本命令。 |
