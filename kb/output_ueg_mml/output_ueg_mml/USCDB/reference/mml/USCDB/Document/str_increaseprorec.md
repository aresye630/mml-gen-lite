## 命令功能

该命令用于查询并执行物理库中的增量营帐日志，也即从局点开始升级到该命令开始运行期间执行的营帐命令。

当主用局升级导致数据异常，切换到数据层容灾局点后也无法恢复业务时，数据紧急修复工具自动在容灾局执行该命令。

该命令运行后，会触发以下流程：

1. 查询并读取增量营帐日志。
2. 增量日志会根据各自FE的转化规则进行转化，若对应的FE没有实现适配接口，则使用默认的规则进行转化。默认规则会将日志中的命令字段提取出来，去掉前后空格。转化后的日志会保存到批操作文件中。“导出命令类型”为“正常导出”的批操作文件保存在/opt/pgw/recover目录下，“导出命令类型”为“加密字段导出”的批操作文件保存在/opt/pgw/EMGRST目录下，批操作文件的命名规则为recover\_FE类型\_yy\_mm\_dd\_hh\_mm\_ss.dat，文件名中的时间对应文件生成时间。每个批操作文件最多保存10万条记录，超过10万条即创建新的批操作文件。
3. 新建批操作处理任务，先后定时扫描/opt/pgw/recover和/opt/pgw/EMGRST目录下的批操作文件，并按照时间先后顺序执行营帐命令，/opt/pgw/recover目录下文件串行执行，/opt/pgw/EMGRST目录下文件并行执行，且最多能有3个任务并行。该批处理任务不受软参BATSEQLEN和BATSUSPENDSWITCH控制，执行该批操作任务的操作员应对所有命令和号段均有操作权限。除该批处理任务外，所有正在执行的批操作均会被暂停。
4. 转化失败和执行失败的营帐命令都保存在/opt/uscdb/emgRst目录。转化失败的文件命名规则分两种情况，“导出命令类型”为“正常导出”时为recover\_FE类型\_trans\_failed\_MML\_序列号，“导出命令类型”为“加密字段导出”时为recover\_FE类型\_encrypt\_trans\_failed\_MML\_序列号。执行失败的文件命名规则统一为recover\_FE类型\_exc\_failed\_MML\_序列号，可使用**GET NODEINFO**命令获取执行失败的命令。

## 注意事项

- 该命令会引发部分或全部增量营帐日志重复执行。
- 该命令执行前，需确保环境中存在的批操作任务数（包括执行的和挂起的）小于环境允许的最大批操作可执行数，否则执行转化后的批操作将会失败。
- 该命令执行后，其他的批操作会被挂起，等待增量营帐日志完成后，被挂起的批操作才能继续执行。
- 该命令执行期间，主用局和容灾局对接入的营帐命令均返回5001错误。
- 执行本命令时，将不可避免的涉及到用户的个人数据，因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护。例如：
  1. 采用安全的文件传输协议（如SFTP）传输导出的文件。
  2. 并严格控制文件的访问权限。
  3. 及时清理文件。

  在从运营商网络获取数据前，必须要获得运营商的授权。

  若需从运营商网络中获取必要的数据，需要运营商维护人员对其中的个人数据进行匿名化处理，匿名化后的数据由运营商维护人员审核后提供，以防止个人数据泄露。匿名化处理工具可以在https://support.huawei.com/获取，获取方法请参见产品手册“匿名化工具安全策略”页面。

## 参数说明

| 参数标识           | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                      |
|:---------------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| STARTTIME      | 开始时间     | 用于指示系统需要按照指定的开始时间来查询操作日志；若不输入，则表示查询所有时间。 取值范围：格式为“YYYY&MM&DD&HH&MM&SS”的字符串。 默认值：无                                                                                                                                                                                                                                                                                                         |
| ENDTIME        | 结束时间     | 用于指示系统需要按照指定的结束时间来查询操作日志；若不输入，则表示查询所有时间。 取值范围：格式为“YYYY&MM&DD&HH&MM&SS”的字符串。 默认值：无                                                                                                                                                                                                                                                                                                         |
| SERVICETYPE    | 服务类型     | 用于指定FE插件包类型；若不输入，则表示查询系统中所有服务类型。 取值范围：已加载的FE插件包名称字符串。 默认值：无                                                                                                                                                                                                                                                                                                                               |
| EXPORTCMDTYPE  | 任务类型     | 用于指示系统需要指定的任务类型。 取值范围： Common（正常导出）：导出所有命令，但不执行被导出的命令。 EncryptPara（加密字段导出）：导出带加密参数的命令。 ExecMML（执行MML命令）：执行所有导出的MML命令。 默认值：Common（正常导出）                                                                                                                                                                                                                                                    |
| NN             | 用户号码名称   | 仅当“任务类型”为“Common（正常导出）”或“EncryptPara（加密字段导出）”时该参数有效，用于指示系统需要按照指定的用户号码名称来查询增量营帐日志。 取值范围： IMSI（IMSI） ISDN（ISDN） IMPU（IMPU） IMPI（IMPI） SUBID（SUBID） 默认值：无。                                                                                                                                                                                                                                   |
| UNLISTFILE     | 用户号码列表文件 | 仅当“用户号码名称”不为空时该参数有效，用于指定查询哪些用户号码的增量营帐日志。 取值范围：长度不超过128的字符串，可由字母、数字或字符“_”、“.”组成。用户号码列表文件支持“.txt”一种格式、不能超过512M且文件中数据不能超过500000行。  说明： 执行该命令前，用户号码列表文件必须先通过OM Portal的文件传输功能上传到“CGPLite文件 > 网元文件 > USCDB_NODEINFO”文件夹内（如果不存在USCDB_NODEINFO文件夹，则需创建）。上传方法请参考产品手册“GUI参考 > 文件传输”。用户列表文件内容格式要求如下：不能只包含空格或空行。用户号码都需要加双引号。每行一个用户号码，每个用户号码不能超过256个字符（即忽略前后空格后每行不能超过258个字符，用户号码256个字符+双引号2个字符）。 默认值：无 |
| ISEXPORTSAVLOG | 是否导出空口日志 | 用于指定是否导出空口日志。 取值说明： FALSE（否）: 不导出空口日志TRUE（是）：导出空口日志 默认值：无                                                                                                                                                                                                                                                                                                                                 |

## 使用实例

1. 查询所有时间范围内，所有服务类型的增量营帐日志。

   ```
   STR INCREASEPROREC:;
   ```
2. 查询指定起始时间，结束时间和服务类型的增量营帐日志。“开始时间”为“2018&01&11&19&03&21”，“结束时间”为“2018&01&11&22&27&45”，“服务类型”为“SUP-FE，”“任务类型”为“Common（正常导出）”。

   ```
   STR INCREASEPROREC: STARTTIME=2018&01&11&19&03&21, ENDTIME=2018&01&11&22&27&45, SERVICETYPE="SUP-FE", EXPORTCMDTYPE=Common;
   ```
3. 查询“服务类型”为“SUP-FE”，“任务类型”为“Common（正常导出）”，“用户号码名称”为“IMSI（IMSI）”，“用户号码列表文件”为“userlist.txt”的增量营帐日志。

   ```
   STR INCREASEPROREC: SERVICETYPE="SUP-FE", EXPORTCMDTYPE=Common, NN=IMSI, UNLISTFILE="userlist.txt";
   ```
