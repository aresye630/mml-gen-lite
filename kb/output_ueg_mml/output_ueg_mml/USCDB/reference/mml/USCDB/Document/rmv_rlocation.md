# 删除远端Location信息(RMV RLOCATION)

- 命令功能
- 注意事项

## 命令功能

**须知** 

该命令属于高危命令，如果远端Location参数配置不合理，将导致FE业务失败或者ESN发生变动从而导致License失效。因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在配置数据库中删除一条远端网元设备的Location信息。

## 注意事项

- BE的ESN信息与License有关，BE的ESN是由首个与该BE对接成功的FE对应的ESN和通过****ADD SRVIPADDR****添加的PGW类型的IP1地址通过加密算法处理后获得。执行该命令可能会导致ESN变动，一旦ESN变动则需要重新申请License文件，请谨慎操作。
- 如果本端Location还存在远端DSG模块、远端DPU/业务IP索引IP或远端DSG链路中心的配置信息，则无法删除该Location。正常情况下，删除一条远端网元设备的Location信息的步骤为：
  - 本端Location存在远端DSG模块的配置信息：**RMV RDSG**->**RMV RLOCATION**。
  - 本端Location存在远端DPU/业务IP索引IP的配置信息：**RMV RIPADDR**->**RMV RLOCATION**。
  - 本端Location存在远端RPARTITION的配置信息：**RMV RPARTITION**->**RMV RLOCATION**。
  - 若存在业务分组并且分组开关打开，则必须输入“远端网元类型”参数进行删除操作。
  - 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称         | 参数说明                                                                                                                                         |
|:-------|:-------------|:---------------------------------------------------------------------------------------------------------------------------------------------|
| RLOCID | 远端Location标识 | 可选必选说明：必选参数。 标识一条远端网元设备的Location信息数据记录的关键字段之一，用于指定需要删除的远端网元设备的Location标识，操作员可以使用LST RLOCATION命令查询获得。                                         |
| RMT    | 远端网元类型       | 可选必选说明：可选参数。 标识一条远端网元设备的Location信息数据记录的关键字段之一，用于指定需要删除的远端网元设备的业务类型，操作员可以使用LST RLOCATION命令查询获得。 取值范围：通过LOD FEPLUG命令加载的插件包的业务类型或者USCDB。 默认值：无。 |

## 使用实例

删除远端Location ID为2的远端网元设备的Location信息。此时需要进行如下操作：

1. 如果本端Location存在远端DSG模块的配置信息，请执行RMV RDSG命令删除本端Location存在远端DSG模块的配置信息。
2. 如果本端Location存在远端DPU IP的配置信息，请执行RMV RIPADDR命令删除本端Location存在远端DPU IP的配置信息。
3. 执行**RMV RLOCATION**命令删除远端“Location ID”为“2”的远端网元设备的Location信息。

   `RMV RLOCATION: RLOCID=2;`
