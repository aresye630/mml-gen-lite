# 网管用户认证结果通知(ACK LGI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

当使用网管用户登录OM Portal时，用于通知CSP网管用户的认证结果。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称         | 参数说明                                                                                |
|:-----------|:-------------|:------------------------------------------------------------------------------------|
| OP         | 帐号           | 需要认证的网管用户名。 取值范围：长度不超过256的字符串。 默认值：无。                                               |
| RETCODE    | 返回码          | 网管返回的认证返回码。 取值范围：长度不超过256的字符串。 默认值：无。                                               |
| MSG        | 提示信息         | 错误描述，描述网管认证失败的原因。 取值范围：长度不超过256的字符串。 默认值：无。                                         |
| CMDS       | 权限命令码集合      | 网管用户的权限信息。每个命令码代表一个权限集。 取值范围：长度不超过256的字符串。 默认值：无。                                   |
| MUSTMODPWD | 是否需要修改密码     | 是否需要修改网管用户的密码。 取值范围： OFF：不需要修改密码ON：需要修改密码 默认值：无。                                    |
| MUSTTIPPWD | 是否提示密码到期剩余天数 | 是否提示密码到期剩余天数。 取值范围： OFF：不需要提示ON：需要提示 默认值：无。 注：该参数仅在Soap通道使用；在MML通道不使用，MML配置文件中无该参数。 |
| PWDEXPRT   | 密码到期剩余天数     | 网管用户密码的到期剩余天数。 取值范围：长度不超过256的字符串。 默认值：无。                                            |
| DNAME      | 域名称          | 网管所属域名称。 取值范围：长度不超过256的字符串。 默认值：无。                                                  |
| MEIDS      | 网元ID         | 网元ID列表。 取值范围：长度不超过256的字符串。 默认值：无。                                                   |
| AUTHTYPE   | 认证类型         | 网管用户的认证类型。 取值范围： 不填写：表示认证用户名和密码。SSO: 认证SSO单点登录的一次性token。 默认值：无。                     |
| RELATEDID  | 关联ID         | 网管认证请求的唯一ID。 取值范围：长度不超过256的字符串。 默认值：无。                                              |
| TOKEN      | 令牌           | SSO单点登录的认证凭证。 取值范围：长度不超过256的字符串。 默认值：无。                                             |

## 使用实例

无。
