# 强制注销网管在线用户(KIK OP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

通知OM Portal强制注销已登录OM Portal的网管在线用户。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                               |
|:-------|:-------|:-----------------------------------|
| DN     | 网管类型   | 对接OM Portal的网管类型。 取值范围：EMS。 默认值：无。 |
| OP     | 帐号     | 网管用户名。 取值范围：长度不超过256的字符串。 默认值：无。   |

无。
