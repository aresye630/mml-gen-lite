# 修改SNMP用户(MOD SNMPUSER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于提供给网管修改SNMP用户共享密钥。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                  |
|:---------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USER     | 用户名称   | 用于标识唯一的用户名称。 取值范围：无。 默认值：无。  说明： 用户名称必须满足如下要求： 请控制在6到20个字符，支持字母和数字（A~Z、a~z、0~9）、空格和下划线，不支持中文。                                                                                                                                                                                         |
| PROTVER  | 协议版本   | 当前SNMP协议支持的版本。 取值范围：SNMPv3 默认值：无。                                                                                                                                                                                                                                                     |
| AUTHPROT | 认证协议   | 当前SNMP协议支持的认证协议。 取值范围： 2：认证协议SHA3：认证协议SHA2564：认证协议SHA3845：认证协议SHA512 默认值：无。                                                                                                                                                                                                           |
| AUTHKEY  | 认证密码   | 认证协议对应的共享密钥。 取值范围：无。 默认值：无。  说明： 密钥必须满足如下要求： 密钥不能少于10个字符且不超过64个字符。密钥至少包括1个大写字母（A~Z），1个小写字母（a~z），1个数字（0~9）和1个特殊字符（包括!"#$%&'()*+,-./:;<=>?@[]^`{_|}~）。密钥中不能包含3位及以上的连续字母、数字（如abc、123），或3位及以上的重复字母、数字、特殊字符（如xxx、666、^^^）。密钥不能由2个及以上完全重复的字符串组成。密钥不能包含用户名或用户名的倒序，用户名不能包含密钥或密钥的倒序，该校验不区分大小写。 |
| PRVPROT  | 加密协议   | 当前SNMP协议支持的加密协议。 取值范围： 2：加密协议AES1283：加密协议AES1924：加密协议AES256 默认值：无。                                                                                                                                                                                                                    |
| PRVKEY   | 加密密码   | 加密协议对应的共享密钥。 取值范围：无。 默认值：无。  说明： 密钥必须满足如下要求： 密钥不能少于10个字符且不超过64个字符。密钥至少包括1个大写字母（A~Z），1个小写字母（a~z），1个数字（0~9）和1个特殊字符（包括!"#$%&'()*+,-./:;<=>?@[]^`{_|}~）。密钥中不能包含3位及以上的连续字母、数字（如abc、123），或3位及以上的重复字母、数字、特殊字符（如xxx、666、^^^）。密钥不能由2个及以上完全重复的字符串组成。密钥不能包含用户名或用户名的倒序，用户名不能包含密钥或密钥的倒序，该校验不区分大小写。 |
