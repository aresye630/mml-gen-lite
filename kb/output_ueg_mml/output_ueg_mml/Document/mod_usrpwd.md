# 修改当前用户密码(MOD USRPWD)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

#### 命令功能

该命令用于修改MML建链用户的密码。

#### 注意事项

无。

#### 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                     |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| USER   | 用户名称   | 用于标识唯一的用户名称。 取值范围：无。 默认值：无。  说明： 用户名称必须满足如下要求： 请控制在4到32个字符，支持中英文、数字、下划线、中划线，不支持生僻字。                                                                                                                                                                      |
| OLD    | 旧密码    | 用户未修改前的密码。 取值范围：无。 默认值：无。                                                                                                                                                                                                                                |
| NEW    | 新密码    | 用户修改后的密码。 取值范围：无。 默认值：无。  说明： 密码必须满足如下要求： 密码至少包括1个大写字母（A~Z），1个小写字母（a~z），1个数字（0~9）和1个特殊字符（包括!"#$%&'()*+,-./\:;<=>?@[]^`{_|}~）。密码不能少于10个字符且不超过64个字符。密码中不能包含3位及以上的连续字母、数字（如abc、123），或3位及以上的重复字母、数字、特殊字符（如xxx、666、^^^）。密码不能包含用户名，用户名的倒序。                     |
| CFM    | 确认密码   | 再次输入修改后的密码，确认密码不能为空，且须与新密码一致。 取值范围：无。 默认值：无。  说明： 密码必须满足如下要求： 密码至少包括1个大写字母（A~Z），1个小写字母（a~z），1个数字（0~9）和1个特殊字符（包括!"#$%&'()*+,-./\:;<=>?@[]^`{_|}~）。密码不能少于10个字符且不超过64个字符。密码中不能包含3位及以上的连续字母、数字（如abc、123），或3位及以上的重复字母、数字、特殊字符（如xxx、666、^^^）。密码不能包含用户名，用户名的倒序。 |

无。
