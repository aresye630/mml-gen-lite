# 校验静默补丁(CHK SPATCH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于校验指定网元下通过静默方式加载的补丁信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                              |
|:-------|:-------|:------------------------------------------------------------------|
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：该参数用于唯一标识一个子网下的网元实例。 取值范围：0～1023 默认值：无。 配置原则：无。 |

## 使用实例

校验网元下以静默安装的补丁包信息。“网元ID”为“10”：

`CHK SPATCH: MEID=10;`

1. 10号网元不存在静默安装的补丁

   ```
   %%CHK SPATCH: MEID=10;%%
   RETCODE = 0  操作成功

   ---    END
   ```
2. 10号网元存在静默安装的补丁

   ```
   %%CHK SPATCH: MEID=10;%%
   RETCODE = 0  操作成功

   操作结果如下
   ------------------------
       网元ID  =  10
     网元名称  =  MSOFTX
     网元版本  =  V200R006C01
   补丁包名称  =  MSOFTX_V200R006C01SP001.tar
   补丁包状态  =  成功
   冷补丁名称  =  SPC001
   冷补丁状态  =  成功
   热补丁名称  =  SPH001
   热补丁状态  =  成功
   (结果个数 = 1)

   ---    END
   ```
