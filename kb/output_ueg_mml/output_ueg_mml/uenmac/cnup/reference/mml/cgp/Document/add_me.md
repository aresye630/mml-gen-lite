# 增加网元(ADD ME)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于VNFM自动部署时，在配置数据库中增加一个网元实例。

本命令的使用场景为：在开局和扩容进行系统配置的过程中，通过本命令增加需要的网元实例。

**须知** 

执行该命令后，添加网元需要大约20分钟完成，请务必在华为技术支持人员的指导下操作。

## 注意事项

- 增加一个网元实例大概需要20分钟，如果要在CSP网元下执行其他配置命令，请在增加网元命令返回成功结果后再执行。
- 在增加的过程中停止CGPLite服务会有数据残留，服务再次启动时，会进行遗留数据的清理，因此启动的时间会比正常情况下慢。
- 网元实例增加成功只是配置的第一步，如果需要网元实体能够正常运行，还需要配置基本信息，如：配置模块实例，配置对接数据等。网元实例下的所有数据配置完成后，将主机的程序文件和数据文件一同加载到主机，才能使网元实体运行起来；网元实体运行起来后，后续配置的数据，可以通过联机设定到主机。
- 增加网元时，磁盘opt分区的剩余空间必须大于5G。
- 如果在执行**BKP SYS**期间执行了本命令，则不归档备份包文件，如果需要执行备份系统操作，请在本命令执行完毕后，重新执行**BKP SYS**命令。
- 由于CSP从V200R019C10切换Guest OS为Euler OS操作系统，不允许在CSP上添加未适配Euler OS的网元。

## 使用实例

1. 增加网元：设置“网元ID”为“50”，“网元名称”为“MsoftX”，“网元类型”为“MSOFTX(MSOFTX3000网元)”，“网元版本”为“V200R006C01”，“网元制造商名称”是“huawei”，“网元本地名称”为“site”。

   `ADD ME: MEID=50, MENAME="MsoftX", METYPE=MSOFTX, MEVER="V200R006C01", MEVD="huawei", MELN="site";`
2. 增加网元：设置“网元ID”为“100”，“网元名称”为“MSX100”，“网元类型”为“MSOFTX(MSOFTX3000网元)”，“网元版本”为“V200R009C00”。

   `ADD ME: MEID=100, MENAME="MSX100", METYPE=MSOFTX, MEVER="V200R009C00";`
3. 增加网元：设置“网元ID”为“50”，“网元名称”为“MsoftX”，“网元类型”为“MSOFTX(MSOFTX3000网元)”，“网元版本”为“V200R006C01”，“网元制造商名称”是“huawei”，“网元本地名称”为“site”,“架构类型”为“X86(X86)”。

   `ADD ME: MEID=50, MENAME="MsoftX", METYPE=MSOFTX, MEVER="V200R006C01", MEVD="huawei", MELN="site"``, ARCHTYPE=X86;`
4. 增加网元：设置“网元ID”为“100”，“网元名称”为“MSX100”，“网元类型”为“MSOFTX(MSOFTX3000网元)”，“网元版本”为“V200R009C00”。

   `ADD ME: MEID=100, MENAME="MSX100", METYPE=MSOFTX, MEVER="V200R009C00"``;`
