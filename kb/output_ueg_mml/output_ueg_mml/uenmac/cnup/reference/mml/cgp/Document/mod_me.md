# 修改网元信息(MOD ME)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于对配置数据库中的一个网元实例的某些参数进行修改和调整。在本命令中，系统通过“网元ID”来唯一标识一个网元实例。

本命令的使用场景为：网元名称和网元本地名称与实际不符时可以使用本命令进行修改。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                         |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID     | 网元ID   | 可选必选说明：必选参数。 参数含义：标识一个网元实例的关键字段，用于指定需要对哪一个网元对象实例的参数进行修改或调整，操作员可以使用LST ME命令查询获得。 取值范围：无。 默认值：无。 配置原则：无。                                                       |
| MENAME   | 网元名称   | 可选必选说明：必选参数。 参数含义：用于标识网元的名称，可自定义。其值域类型为字符串。 取值范围：长度不超过64个英文字符（中文字符不超过32个）。 默认值：无。 配置原则：按照网元的实际情况命名，建议定义具有说明性质的名称。不能包含字符 “?”、“:”、“>”、“<”、“*”、“/”、“\”、“|”、“"”。 |
| MELN     | 网元本地名称 | 可选必选说明：必选参数。 参数含义：用于标识网元的本地名称，可自定义。其值域类型为字符串。 取值范围：长度不超过40个英文字符（中文字符不超过20个）。 默认值：无。 配置原则：根据实际情况定义网元的本地名称，建议取用有说明性质的本地名称。                                     |
| DS       | 网元显示标志 | 可选必选说明：必选参数。 参数含义：用于标识业务网元在网管是否显示。 取值范围： “YES(是)”：表示在网管上显示该业务网元。“NO(否)”：表示在网管上不显示该业务网元。 默认值：“YES(是)”。 配置原则：无。                                                |
| ARCHTYPE | 架构类型   | 可选必选说明：可选参数。 参数含义：其值域为枚举类型，用于标识网元的架构类型。 取值范围： “X86(X86)”：表示修改为X86类型。“ARM(ARM)”：表示修改为ARM类型。 默认值：无。 配置原则：无。                                                    |

## 使用实例

使用实例修改网元：“网元ID”为“5”，“网元名称”为“MeName5”。

MOD ME: MEID=5, MENAME="MeName5";

修改网元：“网元ID”为“55”，“网元名称”为“MeName55”,“网元本地名称”为“site”，“网元显示标志”为“NO(否)”。

MOD ME: MEID=55, MENAME="MeName55", MELN="site", DS=NO;

修改网元：“网元ID”为“5”，“架构类型”为“X86(X86)”。

MOD ME: MEID=5, ARCHTYPE=X86;
