# 设置CGPLite倒换状态(SET SWAPSTATE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置主备CGPLite禁止倒换状态为“禁止主备倒换”或者“允许主备倒换”。

该命令的使用场景为：升级、打补丁等重大操作时，避免主备异常倒换时使用该命令。

## 注意事项

设置禁止倒换状态为“禁止主备倒换”时，如果主CGPLite出现进程资源异常，备CGPLite将无法自动倒换成为主CGPLite来接管业务。

## 参数说明

| 参数标识     | 参数名称         | 参数说明                                                                                                        |
|:---------|:-------------|:------------------------------------------------------------------------------------------------------------|
| SETPOS   | 命令设置方向       | 可选必选说明：必选参数。 参数含义：用于指定命令执行的范围。 取值范围：“Local(只设置本端)”“Peer(只设置对端)”“Both(两端都进行设置)” 默认值：“Both(两端都进行设置)”。 配置原则：无。 |
| OPTTYPE  | 命令操作类型       | 可选必选说明：必选参数。 参数含义：用于指定命令的操作类型。 取值范围：“Forbid(禁止倒换)”“Allow(启动倒换)” 默认值：无。 配置原则：无。                              |
| KEEPTIME | 禁止倒换状态时长(小时) | 可选必选说明：必选参数。 参数含义：用于指定禁止倒换的时长。 取值范围：1～48 默认值：24。 配置原则：无。                                                    |

## 使用实例

设置CGPLite禁止倒换状态：“命令设置方向”为“Both(两端都进行设置)”，“命令操作类型”为“Forbid(禁止倒换)”，“禁止倒换状态时长”为“1（小时）”：

`SET SWAPSTATE: OPTTYPE=Forbid, KEEPTIME=1;`
