# 平台网元升级(UPG PLATFORM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于PMU进程的升级。

该命令的使用场景为：在CSP切换工作区后，可以使用该命令完成所有PMU进程的升级。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                             |
|:-------|:-------|:-----------------------------------------------------------------|
| DMID   | 域标识    | 可选必选说明：必选参数。 参数含义：用于唯一标识一个域。 取值范围：1 默认值：1。 配置原则：无。               |
| SNID   | 子网标识   | 可选必选说明：必选参数。 参数含义：用于唯一标识一个域下的子网。 取值范围：0～255 默认值：0。 配置原则：无。       |
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：用于唯一标识一个网元实例。此处只能取值为“0”。 取值范围：0 默认值：无。 配置原则：无。 |

## 使用实例

升级PMU进程：

`UPG PLATFORM: MEID=0;`
