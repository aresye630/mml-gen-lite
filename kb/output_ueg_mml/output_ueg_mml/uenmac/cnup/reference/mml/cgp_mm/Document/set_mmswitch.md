# 设置维护命令统计开关(SET MMSWITCH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置维护命令执行时间的统计开关。

## 注意事项

该开关打开后可以通过**LST CMDEXECTIME**查看维护命令执行时间的统计结果。

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                                |
|:-------------|:-------|:----------------------------------------------------------------------------------------------------|
| MMSWITCHTYPE | 开关类型   | 可选必选说明：必选参数。 参数含义：开关类型标识，用于指示系统设置维护命令执行时间的统计开关类型。 取值范围： “CETS(命令执行时间统计)” 默认值：CETS(命令执行时间统计) 配置原则：无。 |
| STS          | 开关状态   | 可选必选说明：必选参数。 参数含义：标识设置的统计开关状态。 取值范围： “OFF(关)”“ON(开)” 默认值：OFF(关) 配置原则：无。                             |

## 使用实例

打开维护命令执行时间的统计开关：

`SET MMSWITCH: MMSWITCHTYPE=CETS, STS=ON;`
