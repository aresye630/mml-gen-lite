# 数据加载开关（SET DATASWITCH）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 参考信息

## 命令功能

该命令用于脱机部署或者扩容中，设置打开或者关闭配置数据加载开关。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                |
|:-----------|:-------|:--------------------------------------------------------------------------------------------------------------------|
| MEID       | 网元ID   | 可选必选说明：必选参数 参数含义：用于指示设置哪个网元的配置数据加载开关。 取值范围：0～1023 默认值：无。 配置原则：操作员可以使用LST ME命令查询获得。                                  |
| LOADSWITCH | 数据加载开关 | 可选必选说明：必选参数 参数含义：用于指示是否开启配置数据加载开关。 默认值：无。 取值范围： “OFF(关闭)”：用于表示该网元配置数据加载开关是关闭的。“ON(打开)”：用于表示该网元配置数据加载开关是打开的。 配置原则：无。 |

## 使用实例

设置“网元ID”为“5”的网元配置数据加载开关：

`SET DATASWITCH:MEID=5,LOADSWITCH=ON;`
