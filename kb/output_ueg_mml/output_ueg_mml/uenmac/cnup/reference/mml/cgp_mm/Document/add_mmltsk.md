# 增加MML批处理任务(ADD MMLTSK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于增加MML批处理任务。MML批处理任务是指按固定顺序执行一系列MML命令的任务。增加的MML批处理任务将通过升级结束观察期等消息触发执行。

该命令的使用场景为：升级结束观察期进行特定清理操作时使用该命令。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                                                               |
|:--------------|:-------|:-------------------------------------------------------------------------------------------------------------------|
| MEID          | 网元ID   | 可选必选说明：必选参数。 参数含义：用于唯一标识一个网元实例。 取值范围：0～1023 默认值：无。 配置原则：无。                                                         |
| TSKNAME       | 任务名称   | 可选必选说明：必选参数。 参数含义：用于标识MML批处理任务。 取值范围：无。 默认值：无。 配置原则：无。                                                             |
| TSKDESC       | 任务描述   | 可选必选说明：必选参数。 参数含义：用于介绍任务的内容。 取值范围：无。 默认值：无。 配置原则：无。                                                                |
| SCRPTFNAME    | 脚本文件名  | 可选必选说明：必选参数。 参数含义：用于标识要执行的脚本文件。 取值范围：无。 默认值：无。 配置原则：无。                                                             |
| EXETYPE       | 触发方式   | 可选必选说明：必选参数。 参数含义：用于标识MML批处理任务的触发方式。 RESERVED2~2(保留2)RESERVED1~1(保留1)FINUPGWATCH~0(升级观察期结束) 取值范围：无。 默认值：无。 配置原则：无。 |
| CONT_WHEN_ERR | 出错是否停止 | 可选必选说明：必选参数。 参数含义：用于指示MML批处理任务执行出错时是否停止。 取值范围： “CONTINUE(不停止)”“BREAK(停止)” 默认值：“CONTINUE(不停止)”。 配置原则：无。             |
| FALPROC       | 失败处理方式 | 可选必选说明：必选参数。 参数含义：用于指示MML批处理任务执行失败后的处理方式。 取值范围： “ALARM(发送告警)”“NONE(误动作)” 默认值：“ALARM(发送告警)”。 配置原则：无。                |

## 使用实例

增加MML批命令任务“UPAWATCHEXE”：

`ADD MMLTSK: MEID=0, TSKNAME="UPAWATCHEXE", SCRPTFNAME="mml_task1.txt", EXETYPE=FINUPGWATCH;`
