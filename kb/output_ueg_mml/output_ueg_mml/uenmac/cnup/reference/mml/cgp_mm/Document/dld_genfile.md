# 一般文件下载 (DLD GENFILE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于一般文件下载。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称          | 参数说明                                                            |
|:-------|:--------------|:----------------------------------------------------------------|
| SRCF   | FTP服务器端文件目录路径 | 可选必选说明：必选参数。 参数含义：用于指定FTP服务端文件目录路径。 取值范围：无。 默认值：无。 配置原则：无。      |
| DSTF   | 本地文件名称        | 可选必选说明：必选参数。 参数含义：用于指定需要下载的本地文件名称。 取值范围：无。 默认值：无。 配置原则：无。       |
| IP     | FTP服务器IPv4地址  | 可选必选说明：必选参数。 参数含义：用于指定FTP服务器IP地址。 取值范围：无。 默认值：无。 配置原则：无。        |
| USR    | FTP用户名        | 可选必选说明：必选参数。 参数含义：FTP用户名。 取值范围：无。 默认值：无。 配置原则：无。                |
| PWD    | FTP密码         | 可选必选说明：必选参数。 参数含义：FTP密码。 取值范围：无。 默认值：无。 配置原则：无。                 |
| GA     | 进度上报标识        | 可选必选说明：必选参数。 参数含义：用于打开或者关闭文件下载进度的参数。 取值范围：“否”“是” 默认值：是。 配置原则：无。 |

## 使用实例

一般文件下载：“FTP服务器端文件目录路径”为“/FTP/SBC\_VT\_1110\_FTP.log”，“本地文件名称”为“x.txt”，“FTP服务器IP地址”为“10.156.6.47”，“FTP用户名”为“abcd”，“FTP密码”为“abcd”，“进度上报标识”为“是”：

`DLD GENFILE: SRCF="/FTP/SBC_VT_1110_FTP.log", DSTF="x.txt", IP="10.156.6.47", USR="abcd", PWD="****";`
