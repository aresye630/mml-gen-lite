# 备份进度检查(CHK BKSTATS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于无损升级过程，检查指定网元主备进程备份进度状况，如果备份进度达到100%，则检查成功，否则检查失败。

该命令的使用场景为：在备平面进程激活后，使用该命令检查主备平面间的版本备份进度。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                       |
|:----------|:---------|:-----------------------------------------------------------|
| DMID      | 域标识      | 可选必选说明：必选参数。 参数含义：用于唯一标识一个域。 取值范围：1 默认值：1。 配置原则：无。         |
| SNID      | 子网标识     | 可选必选说明：必选参数。 参数含义：用于唯一标识一个域下的子网。 取值范围：0～255 默认值：0。 配置原则：无。 |
| MEID      | 网元ID     | 可选必选说明：必选参数。 参数含义：用于唯一标识一个网元实例。 取值范围：5～1023 默认值：无。 配置原则：无。 |
| BKFINFLAG | 进程备份完成标识 | 可选必选说明：必选参数。 参数含义：用于标识进程备份是否完成。 取值范围：0～1 默认值：0。 配置原则：无。    |
| CMPLTSTP  | 已完成升级步骤  | 可选必选说明：必选参数。 参数含义：用于标识已完成的升级步骤。 取值范围：0～255 默认值：2。 配置原则：无。  |

## 使用实例

检查网元10主备进程备份进度：

`CHK BKSTATS: MEID=10;`

## 输出结果说明

| 输出项名称     | 输出项解释           |
|:----------|:----------------|
| 网元ID      | 用于唯一标识一个网元实例。   |
| 模块标识      | 用于唯一标识一个模块。     |
| 备份阶段      | 用于标识当前所处的备份阶段。  |
| 进程备份百分比   | 用于标识当前的备份进度。    |
| 进程跨版本备份状态 | 用于标识跨版本备份的状态。   |
| 允许调换标志位   | 用于标识是否允许切换主备进程。 |
