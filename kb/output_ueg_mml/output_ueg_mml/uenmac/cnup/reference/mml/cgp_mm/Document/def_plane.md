# 平面定义(DEF PLANE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于网元的无损升级，给主机下发主备平面的定义，将主备类型的进程分别划分到主备平面。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                       |
|:---------|:-------|:-------------------------------------------------------------------------------------------|
| DMID     | 域标识    | 可选必选说明：必选参数。 参数含义：用于唯一标识一个域。 取值范围：1 默认值：1。 配置原则：无。                                         |
| SNID     | 子网标识   | 可选必选说明：必选参数。 参数含义：用于唯一标识一个域下的子网。 取值范围：0～255 默认值：0。 配置原则：无。                                 |
| MEID     | 网元ID   | 可选必选说明：必选参数。 参数含义：用于唯一标识一个网元实例。 取值范围：5～1023 默认值：无。 配置原则：无。                                 |
| OPERTYPE | 操作类型   | 可选必选说明：必选参数。 参数含义：该参数用与区分当前操作是在升级还是扩容场景下执行。 取值范围： “UPGRADE(升级)”“EXPAND(扩容)” 默认值：无。 配置原则：无。 |

## 使用实例

定义网元7的主备平面:

`DEF PLANE: MEID=7;`
