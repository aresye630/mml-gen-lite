# 查询命令执行时间(LST CMDEXECTIME)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询网元下命令的执行时间统计结果。若需要查询所有网元命令的统计结果，请不要输入任何参数。若需要进行过滤查询，请输入“网元ID”及“统计类型”等参数的组合。

## 注意事项

如果需要查询配置命令详细统计，需要执行**SET CMDSTAT**打开配置命令统计开关。

如果需要查询维护命令详细统计，需要执行**SET MMSWITCH**打开维护命令统计开关。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                     |
|:---------|:-------|:-------------------------------------------------------------------------------------------------------------------------|
| MEID     | 网元ID   | 可选必选说明：必选参数。 参数含义：网元对象标识。用于指示系统查询某个网元下命令的执行时间统计结果。 取值范围：0～1023 默认值：无。 配置原则：无。                                            |
| CMDCOUNT | 命令个数   | 可选必选说明：必选参数。 参数含义：用于指定所要查询的命令个数。 取值范围：0～10000 默认值：5000 配置原则：无。                                                           |
| STATTYPE | 统计类型   | 可选必选说明：必选参数。 参数含义：用于指定查询的执行时间统计类型。 取值范围： “SIMPLE(简单)”“CMDETAILED(配置命令详细统计)”“MMDETAILED(维护命令详细统计)” 默认值：SIMPLE(简单) 配置原则：无。 |

## 使用实例

查询“网元ID”为“5”的网元下命令的执行时间统计结果：

`LST CMDEXECTIME: MEID=5;`
