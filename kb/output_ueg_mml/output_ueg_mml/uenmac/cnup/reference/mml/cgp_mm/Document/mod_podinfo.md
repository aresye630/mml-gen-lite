# 修改Pod信息(MOD PODINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 参考信息

## 命令功能

该命令用于修改Pod信息。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称       | 参数说明                                                                                                     |
|:--------------|:-----------|:---------------------------------------------------------------------------------------------------------|
| PODNAME       | Pod名称      | 可选必选说明：必选参数。 参数含义：用于指定需要修改相关属性的Pod名称，唯一标识一个Pod。操作员可以使用LST PODINFO查询获取。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：无。 |
| PODLOC        | 节点名称       | 可选必选说明：必选参数。 参数含义：用于指定需要修改相关属性的节点名称。操作员可以使用LST PODINFO查询获取。 取值范围：长度不超过60的字符串。 默认值：无。 配置原则：无。             |
| APPTYPE       | 应用类型       | 可选必选说明：必选参数。 参数含义：用于指定修改后的Pod是哪种应用类型。 取值范围： “OMU”：表示主备OMU。 默认值：无。 配置原则：无。                                |
| BASE1MAC      | Base1平面MAC | 可选必选说明：必选参数。 参数含义：用于指定修改后的Pod的Base1的MAC地址信息。 取值范围：长度不超过60的字符串。 默认值：无。 配置原则：无。                            |
| BASE2MAC      | Base2平面MAC | 可选必选说明：必选参数。 参数含义：用于指定修改后的Pod的Base2的MAC地址信息。 取值范围：长度不超过60的字符串。 默认值：无。 配置原则：无。                            |
| BASE1IP       | BASE1 IP   | 可选必选说明：必选参数。 参数含义：用于指定修改后的Pod的BASE1的IP地址。 取值范围：无。 默认值：无。 配置原则：无。                                         |
| BASE2IP       | BASE2 IP   | 可选必选说明：必选参数。 参数含义：用于指定修改后的POD的BASE2的IP地址。 取值范围：无。 默认值：无。 配置原则：无。                                         |
| FABRIC1IP     | FABRIC1 IP | 可选必选说明：必选参数。 参数含义：用于指定修改后的Pod的FABRIC1的IP地址。 取值范围：无。 默认值：无。 配置原则：无。                                       |
| FABRIC2IP     | FABRIC2 IP | 可选必选说明：必选参数。 参数含义：用于指定修改后的Pod的FABRIC2的IP地址。 取值范围：无。 默认值：无。 配置原则：无。                                       |
| FABRIC3IP     | FABRIC3 IP | 可选必选说明：必选参数。 参数含义：用于指定修改后的Pod的FABRIC3的IP地址。 取值范围：无。 默认值：无。 配置原则：无。                                       |
| FABRIC4IP     | FABRIC4 IP | 可选必选说明：必选参数。 参数含义：用于指定修改后的Pod的FABRIC4的IP地址。 取值范围：无。 默认值：无。 配置原则：无。                                       |
| BASEPORTNUM   | BASE网口个数   | 可选必选说明：必选参数。 参数含义：用于指定修改后的Pod的BASE网口个数。 取值范围：1～4。 默认值：2。 配置原则：无。                                         |
| FABRICPORTNUM | FABRIC网口个数 | 可选必选说明：必选参数。 参数含义：用于指定修改后的Pod的FABRIC网口个数。 取值范围：0~4。 默认值：2。 配置原则：无。                                       |
| SIGNALPORTNUM | 信令网口个数     | 可选必选说明：必选参数。 参数含义：用于指定修改后的Pod的信令网口个数。 取值范围：0~24。 默认值：0。 配置原则：无。                                          |
| VNFID         | VNF ID     | 可选必选说明：必选参数。 参数含义：用于指定需要修改Pod的VNF ID。 取值范围：长度不超过64的字符串。 默认值：无。 配置原则：无。                                   |

## 使用实例

修改“Pod名称”为“VNF\_OMU\_0”的Pod，“Base1平面MAC”为“02:02:05:DE:09:F0”，“Base2平面MAC”为“02:02:05:DE:09:F1”：

`MOD PODINFO: PODNAME="VNF_OMU_0", BASE1MAC="02:02:05:DE:09:F0", BASE2MAC="02:02:05:DE:09:F1";`
