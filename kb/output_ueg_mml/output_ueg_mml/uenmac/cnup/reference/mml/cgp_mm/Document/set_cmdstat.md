# 设置配置命令统计开关(SET CMDSTAT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置配置命令执行时间的统计开关。

## 注意事项

该开关打开后可以通过**LST CMDEXECTIME**查看配置命令执行时间的统计结果。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                              |
|:-------|:-------|:----------------------------------------------------------------------------------|
| STS    | 开关状态   | 可选必选说明：必选参数。 参数含义：用于指示系统打开或者关闭配置命令执行时间的统计开关。 取值范围： “OFF(关)”“ON(开)” 默认值：无。 配置原则：无。 |

## 使用实例

打开配置命令执行时间的统计开关：

`SET CMDSTAT: STS=ON;`
