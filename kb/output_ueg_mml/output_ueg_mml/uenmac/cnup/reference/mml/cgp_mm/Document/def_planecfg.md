# 划分平面(DEF PLANECFG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于网元的无损升级，按照定义的划分规则，把网元进程划分为主备两个平面。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称        | 参数说明                                                                                       |
|:----------|:------------|:-------------------------------------------------------------------------------------------|
| MEID      | 网元ID        | 可选必选说明：必选参数。 参数含义：用于唯一标识一个网元实例。 取值范围：5～1023 默认值：无。 配置原则：无。                                 |
| ACTOMUSRN | 主用CSP容器虚拟框号 | 可选必选说明：必选参数。 参数含义：用于标识主用CSP容器的虚拟框号。 取值范围：0～63 默认值：无。 配置原则：无。                               |
| ACTOMUSN  | 主用CSP容器虚拟槽号 | 可选必选说明：必选参数。 参数含义：用于标识主用CSP容器的虚拟槽号。 取值范围：0～31 默认值：无。 配置原则：无。                               |
| STBOMUSRN | 备用CSP容器虚拟框号 | 可选必选说明：必选参数。 参数含义：用于标识备用CSP容器的虚拟框号。 取值范围：0～63 默认值：无。 配置原则：无。                               |
| STBOMUSN  | 备用CSP容器虚拟槽号 | 可选必选说明：必选参数。 参数含义：用于标识备用CSP容器的虚拟槽号。 取值范围：0～31 默认值：无。 配置原则：无。                               |
| OPERTYPE  | 操作类型        | 可选必选说明：必选参数。 参数含义：该参数用与区分当前操作是在升级还是扩容场景下执行。 取值范围： “UPGRADE(升级)”“EXPAND(扩容)” 默认值：无。 配置原则：无。 |

## 使用实例

将网元10的进程划分为主备两个平面：

`DEF PLANECFG: MEID=10;`
