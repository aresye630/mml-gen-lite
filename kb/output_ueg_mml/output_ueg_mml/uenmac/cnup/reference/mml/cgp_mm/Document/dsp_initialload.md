# 查询初始加载进度(DSP INITIALLOAD)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询初始加载进度。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                         |
|:-------|:-------|:-----------------------------------------------------------------------------|
| SRN    | 框号     | 可选必选说明：必选参数。 参数含义：用于指示系统需要按照Pod的哪个虚拟框号来查询初始加载进度。 取值范围：0～63 默认值：无。 配置原则：无。    |
| SN     | 槽位号    | 可选必选说明：必选参数。 参数含义：用于指示系统需要按照Pod的哪个虚拟槽号来查询初始加载进度。 取值范围：0～31 默认值：无。 配置原则：无。    |
| TN     | 任务号    | 可选必选说明：必选参数。 参数含义：用于指示系统需要按照哪个任务号来查询初始加载进度。 取值范围：0～4294967295 默认值：无。 配置原则：无。 |

## 使用实例

查询“框号”为“0”，“槽号”为“1”，“任务号”为“0”的初始加载进度：

`DSP INITIALLOAD: SRN=0, SN=1, TN=0;`

## 输出结果说明

| 输出项名称   | 输出项解释                          |
|:--------|:-------------------------------|
| 框号      | 用于指示系统需要按照Pod的哪个虚拟框号来查询初始加载进度。 |
| 槽号      | 用于指示系统需要按照Pod的哪个虚拟槽号来查询初始加载进度。 |
| 任务号     | 用于指示系统需要按照哪个任务号来查询初始加载进度。      |
| 进度      | 用于指示查询到的初始加载进度。                |
| 加载任务状态  | 用于指示查询到的加载任务状态。                |
