# 开始进入升级观察期(STR UPGWATCH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于启动网元的升级观察期，仅在升级过程中使用。

## 注意事项

进入观察期后，限制执行跨网元配置命令。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                       |
|:-------|:-------|:-----------------------------------------------------------|
| DMID   | 域标识    | 可选必选说明：必选参数。 参数含义：用于唯一标识一个域。 取值范围：1 默认值：1。 配置原则：无。         |
| SNID   | 子网标识   | 可选必选说明：必选参数。 参数含义：用于唯一标识一个域下的子网。 取值范围：0～255 默认值：0。 配置原则：无。 |
| MEID   | 网元ID   | 可选必选说明：必选参数。 参数含义：用于唯一标识一个网元实例。 取值范围：0～1023 默认值：无。 配置原则：无。 |

## 使用实例

启动网元7的升级观察期：

`STR UPGWATCH: MEID=7;`
