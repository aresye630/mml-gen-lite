# 查询对象联想参数(LST MOCASS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于客户端从系统中查询某个对象的联想参数列表。

该命令的使用场景为：在客户端输入命令参数时，支持参数联想的输入参数可以通过单击下拉框显示出该参数已经配置过的数据。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称        | 参数说明                                                                             |
|:--------|:------------|:---------------------------------------------------------------------------------|
| MEID    | 网元ID        | 可选必选说明：必选参数。 参数含义：标识网元对象，用于指示系统查询哪一个网元的对象参数列表。 取值范围：0～65535 默认值：无。 配置原则：无。       |
| MOCNAME | 对象名称        | 可选必选说明：必选参数。 参数含义：标识对象名称，指示系统查询某个对象的参数。 取值范围：长度不超过20的字符串。 默认值：无。 配置原则：无。         |
| ASSLIST | 对象类联想参数名称列表 | 可选必选说明：必选参数。 参数含义：标识联想参数名称列表，用于指示系统查询对象的哪些参数。 取值范围：长度不超过1024的字符串。 默认值：无。 配置原则：无。 |

## 使用实例

查询“网元ID”为“0”，“POD”对象的“PODNAME”参数列表：

`LST MOCASS: MEID=0, MOCNAME="POD", ASSLIST="PODNAME";`

## 输出结果说明

| 输出项名称   | 输出项解释                     |
|:--------|:--------------------------|
| 网元ID    | 用于标识网元ID。                 |
| 对象名称    | 标识一个对象。                   |
| 对象配置标签  | 标签用于标识对象是否发生变化，随对象变更不断增大。 |
