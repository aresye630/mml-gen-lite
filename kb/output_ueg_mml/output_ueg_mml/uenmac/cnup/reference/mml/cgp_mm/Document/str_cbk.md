# 升级预处理(STR CBK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于升级预处理，按照指定的序号执行业务进程注册的预处理方法。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                                                                                                 |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MEID    | 网元ID   | 可选必选说明：必选参数。 参数含义：用于唯一标识一个网元实例。 取值范围：5～1023 默认值：无。 配置原则：无。                                                                                                                                                                                           |
| UPGSTEP | 步骤号    | 可选必选说明：必选参数。 参数含义：用于标识升级预处理的步骤。 取值范围： “LODVER(LOD VER)”:数据同步。“DEFPLANE(DEF PLANE)”:平面定义。“UPGPLANE1(UPG PLANE1)”：平面1升级。“ACTPLANE(ACT PLANE)”:平面激活。“SWPPLANE(SWP PLANE)”:平面切换。“UPGPLANE0(UPG PLANE0)”:平面0升级。“CBNPLANE(CBN PLANE)”:平面合并。 默认值：无。 配置原则：无。 |

## 使用实例

执行升级预处理第一步操作，网元ID为10，步骤号为“LODVER(LOD VER)”：

`STR CBK: MEID=10, UPGSTEP=LODVER;`
