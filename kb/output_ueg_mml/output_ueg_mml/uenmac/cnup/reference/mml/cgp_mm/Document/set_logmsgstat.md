# 设置日志统计功能开关(SET LOGMSGSTAT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于设置日志统计开关状态。

该命令的使用场景为：在系统运行过程中，若要统计接收到和保存的主机日志数目，可以使用该命令，将开关状态设置为“ON(开)”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                         |
|:-------|:-------|:-------------------------------------------------------------|
| CSTAT  | 开关状态   | 可选必选说明：必选参数。 参数含义：用于设置开关状态。 取值范围： OFF(关)ON(开) 默认值：无。 配置原则：无。 |

## 使用实例

设置日志统计功能开关，设置“CSTAT”为“OFF”表示关闭开关。

`SET LOGMSGSTAT: CSTAT=OFF;`
