# 增加ISDNPRE/GT号码模板(ADD ISDNPREGT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加ISDNPRE/GT号码模板，模板增加后在配置USSD控制数据业务时可直接调用。

增加ISDNPRE/GT号码模板可以将用户ISDN号码前缀和USSD中心GT号码对应起来。在配置USSD控制数据业务需要使用ISDN号码前缀和USSD中心GT号码时，可按照ISDN号段来匹配前转的USSD中心GT号码，使用更灵活。

## 注意事项

- 如果ISDNPRE/GT号码模板已配置“目标GT号码”，则HLR会优先匹配模板中配置的“目标GT号码”，如果没有匹配成功，则HLR会匹配**ADD USSDDAT**命令配置的“前转设备号码”。
- 系统中增加的ISDNPRE/GT号码模板记录数不能超过3000条，且所有ISDNPRE/GT号码模板增加的ISDN号码前缀/目标GT号码总记录数不能超过30000条。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                               |
|:-----------|:---------|:---------------------------------------------------------------------------------------------------|
| HLRSN      | HLR序列号   | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                       |
| TPLID      | 模板ID     | 用于标识待增加模板在系统中的序号，此参数在系统中唯一。 取值范围：0～65534。 默认值：无。                                                   |
| TPLNAME    | 模板名      | 用于标识ISDNPRE/GT号码模板的名称。 取值范围：1～60位字母或十进制数字组成的字符串。 默认值：无。                                            |
| ISDNPREFIX | ISDN号码前缀 | 用于标识一个MSISDN号码前缀。HLR收到USSD中心携带的用户MSISDN后，与已设置好的ISDN号码前缀按照最大匹配原则进行匹配。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 |
| DESTGT     | 目标GT号码   | 用于标识“ISDN号码前缀”参数对应的USSD中心的GT号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                      |

## 使用实例

配置USSD控制数据业务时，操作员需要配置以下数据。

1. 增加ISDNPRE/GT号码模板，其中“HLR序列号”为“1”，“模板ID”为“1”，“模板名”为“TPL1”，“ISDN号码前缀”为“86138”，“目标GT号码”为“8613910000”：

   ```
   ADD ISDNPREGT: HLRSN=1, TPLID=1, TPLNAME="TPL1", ISDNPREFIX="86138", DESTGT="8613910000";
   ```
2. 在“HLR序列号”为“1”的HLR上添加USSD控制数据类型为“WAP方式前转到USSD中心”。其中“业务码”为“168”，“USSD类型”为“WAPMODE”，“前转设备号码”为“86123999”，“ISDNPRE/GT号码模板ID”为“1”：

   ```
   ADD USSDDAT: HLRSN=1, SRCODE="168", FUNCTION=WAPMODE, FWDADD="86123999", ISDNGTTPL_ID=1;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                  | 处理建议                                                                                                                                                                                                        |
|:--------|:--------|:--------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3047 | 超过最大限制  | 可能原因为如下之一：增加的ISDNPRE/GT号码模板记录数超过3000条。所有ISDNPRE/GT号码模板增加的ISDN号码前缀/目标GT号码总记录数超过30000条。 | 根据实际情况，如需增加ISDNPRE/GT号码模板，处理步骤如下：执行LST ISDNPREGT命令，查询已存在的ISDNPRE/GT号码模板。执行RMV ISDNPREGT命令，删除不必要的ISDNPRE/GT号码模板记录。或执行MOD ISDNPREGT命令删除ISDN号码前缀/目标GT号码记录。执行该命令增加ISDNPRE/GT号码模板，确保增加的ISDNPRE/GT号码模板记录数在规定范围之内。 |
