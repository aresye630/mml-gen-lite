# 修改ISDNPRE/GT号码模板(MOD ISDNPREGT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使签约此模板的用户数据被同步修改，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改ISDNPRE/GT号码模板。

在该命令中，系统通过以下关键参数的组合来唯一标识一条ISDNPRE/GT号码模板数据记录：

- “HLR序列号”
- “模板ID”

## 注意事项

- 用户发送PUSSD请求消息时或触发其他涉及ISDNPRE/GT号码模板的流程时，系统会根据ISDNPRE/GT号码模板查询目标GT号码，会影响用户的USSD业务，因此现网执行修改模板操作时需要慎重。
- 系统中同一个ISDNPRE/GT号码模板增加的ISDN号码前缀/目标GT号码记录数不能超过4000条，且所有ISDNPRE/GT号码模板增加的ISDN号码前缀/目标GT号码总记录数不能超过30000条。

## 参数说明

| 参数标识       | 参数名称             | 参数说明                                                                                                                                                                                                                                                         |
|:-----------|:-----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN      | HLR序列号           | 标识ISDNPRE/GT号码模板信息数据的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR上的ISDNPRE/GT号码模板信息数据记录的参数进行修改，操作员可以使用LST HLRSN命令查询获得。                                                                                                                                                      |
| TPLID      | 模板ID             | 标识ISDNPRE/GT号码模板信息数据的关键字段之一（其取值不能被修改），用于指定需要对哪个ISDNPRE/GT号码模板信息数据记录的参数进行修改，操作员可以使用LST ISDNPREGT命令查询获得。                                                                                                                                                       |
| TPLNAME    | 模板名              | 用于标识ISDNPRE/GT号码模板的名称。 取值范围：1～60位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                      |
| PROV       | 是否提供ISDNPRE/GT号码 | 用于标识是否提供ISDNPRE/GT号码。通过该参数可以修改或删除ISDNPRE/GT号码模板。 取值范围：TRUE：提供如果指定的ISDN号码前缀在模板中不存在，表示系统将会新生成一个ISDNPRE/GT号码模板。如果指定的ISDN号码前缀在模板中存在，表示将修改模板中的目标GT号码。 FALSE：不提供如果指定的ISDN号码前缀在模板中已存在，表示该ISDN号码前缀和对应的目标GT号码将被删除。如果指定的ISDN号码前缀在模板中不存在，会返回“ERR3003 模板未定义”的错误码。 默认值：无。 |
| ISDNPREFIX | ISDN号码前缀         | 用于标识一个MSISDN号码前缀。仅当本命令中的“是否提供ISDNPRE/GT号码”参数为“TRUE”或“FALSE”时该参数有效。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                             |
| DESTGT     | 目标GT号码           | 用于标识“ISDN号码前缀”参数对应的USSD中心的GT号码。仅当本命令中的“是否提供ISDNPRE/GT号码”参数为“TRUE”时该参数有效。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                       |

## 使用实例

修改ISDNPRE/GT号码模板，“HLR序列号”为“1”，“模板ID”为“65534”，“模板名”为“TPL1”，“是否提供ISDNPRE/GT号码”为“TRUE”，“ISDN号码前缀”为“86138”，“目标GT号码”为“8613910000”:

```
MOD ISDNPREGT: HLRSN=1, TPLID=65534, TPLNAME="TPL1", PROV=TRUE, ISDNPREFIX="86138", DESTGT="8613910000";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                                    | 处理建议                                                                                                                                                                                                                |
|:--------|:--------|:--------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | 执行命令当“是否提供ISDNPRE/GT号码”参数为“FALSE”时，“ISDN号码前缀”参数在模板中不存在。                                                 | 根据实际情况，重新输入“ISDN号码前缀”参数，确保该参数在模板中存在，可通过LST ISDNPREGT命令查询模板数据。                                                                                                                                                       |
| ERR3047 | 超过最大限制  | 可能原因为如下之一：同一个ISDNPRE/GT号码模板增加的ISDN号码前缀/目标GT号码记录数超过4000条。所有ISDNPRE/GT号码模板增加的ISDN号码前缀/目标GT号码总记录数超过30000条。 | 根据实际情况，如需增加ISDN号码前缀/目标GT号码数据，处理步骤如下：执行LST ISDNPREGT命令，查询已存在的ISDN号码前缀/目标GT号码数据。执行该命令，将“是否提供ISDNPRE/GT号码”设置为“FALSE”删除不必要的ISDN号码前缀/目标GT号码数据记录。执行该命令，将“是否提供ISDNPRE/GT号码”设置为“TRUE”增加数据，确保增加的ISDN号码前缀/目标GT号码数据记录数在规定范围之内。 |
