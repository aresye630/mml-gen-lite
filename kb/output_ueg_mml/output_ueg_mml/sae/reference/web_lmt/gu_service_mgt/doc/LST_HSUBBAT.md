## 命令功能

**须知** 

本命令属于高危命令，执行不当会增加数据库的负荷，引起系统过载，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在HSS的内存库中使用模糊IMPU查询签约用户的“SUBID”、“IMPI”和“IMPU”数据记录，模糊查询采用前向匹配方式。

- 若需要查询全部SUB签约信息，请不要输入任何参数。
- 若需要查询某个SUB签约的详细信息，请输入“模糊IMPU”参数。

**说明** 

- 查询结果包含用户的个人数据，如：IMSI、MSISDN等，因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护，并严格控制查询结果文件的访问权限。
- 在从运营商网络获取数据前，必须要获得运营商的授权。
- 若需从运营商网络中获取必要的数据，需要运营商维护人员对其中的个人数据进行匿名化处理，匿名化后的数据由运营商维护人员审核后提供，以防止个人数据泄露。匿名化处理工具可以在http://support.huawei.com/网站获取，获取方法请参见产品手册“匿名化工具安全策略”页面。

查询结果的文件名格式为“命令名称-时间-序列号.txt”，例如：LST\_HSUBBAT-2018-07-02-18-23-51-831.txt。

**SET MAPSERV**命令中的“LST命令导出文件压缩控制”取值不为“0”且**LST HSUBBAT**查询结果大于或者等于“LST命令导出文件压缩控制”设置的取值时，通过“文件管理器”查询结果的文件格式为命令名称-时间-序列号.tar.gz。**LST HSUBBAT**命令报文中查询结果的文件格式固定显示为“命令名称-时间-序列号.txt”

执行该命令返回成功结果后，系统下发导出任务开始导出查询结果文件，可通过**DSP EXPTASK**命令查询导出任务状态。

文件存放在PGW的“/opt/pgw/pgwtmpfile/SYSHLRSN+OPNAME”目录中。其中，SYSHLRSN默认为3位数字，不足3位时前面位需要用0补全，如：SYSHLRSN为1，OPNAME为admin时，最后一层目录的名称为001admin。文件可以通过“PGW Web LMT”界面上的“文件管理器”下载到本地。

## 注意事项

- 执行该命令会消耗较多的系统资源，影响系统性能，请在话务量较低的时候执行。
- 若匹配记录过多，文件中只保存先匹配到的10000条记录。
- 该命令执行结果只输出到文件，不能作为营帐指令使用。
- 当数据量过大时，执行本命令前可以通过配置软参“EXPORTSPEED（导出速度(记录数/秒)）”的值来提高用户数据查询效率，“EXPORTSPEED（导出速度(记录数/秒)）”值建议修改为“1000”，用户可以根据实际情况配置，导出完成后恢复原配置。当前导出速度可以通过**LST INSP**命令查询。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                             |
|:----------|:-------|:-------------------------------------------------------------------------------------------------|
| FUZZYIMPU | 模糊IMPU | 用于指示系统需要按照哪个IMPU前缀来查询一个签约用户数据。 取值范围：长度不超过122位的字符串。 默认值：无。 说明：要求输入为不带格式头的字符串或号段且输入的字符串或者字段不能包含空格。 |

## 使用实例

1. 查询所有的SUB签约信息：

   ```
   LST HSUBBAT:;
   ```

   ```
   %%LST HSUBBAT:;%%
   RETCODE = 0 SUCCESS0001:操作成功

   LST_HSUBBAT-2017-03-15-14-49-03-343.txt

   Total count = 1

   There is together 1 report

   ---    END
   ```
2. 查询“模糊IMPU”取值为“+86134”的SUB签约信息：

   ```
   LST HSUBBAT: FUZZYIMPU="+86134";
   ```

   ```
   %%LST HSUBBAT: FUZZYIMPU="+86134";%%
   RETCODE = 0 SUCCESS0001:操作成功

   LST_HSUBBAT-2017-03-15-14-50-16-416.txt

   Total count = 1

   There is together 1 report

   ---    END
   ```

|:--------|:----------------------|
| SUBID   | 用于显示模糊查询出来的用户精确SUBID。 |
| IMPI    | 用于显示模糊查询出来的用户精确IMPI。  |
| IMPU    | 用于显示模糊查询出来的用户精确IMPU。  |
