# 批量模板开户(BAT ADDTPLSUB)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令仅用于SOAP接口，批量对一个或多个用户采用开户模板进行开户，并设置用户APN数据信息。为具有同样业务类型的用户业务发放时使用。

## 注意事项

- 开户前，请使用**ADD KI**命令加载KI。

- “IMSI”、“MSISDN”参数不能与“IMSI/MSISDN文件名”参数同时配置。
- “用户个数”和“IMSI/MSISDN文件名”有且只能有一个参数出现。
- “5G用户模板ID”和“CSPS用户模板ID”同时存在时，如果“5G用户模板ID”中定义了“用户计费签约数据”参数，计费签约数据以“5G用户模板ID”中的为准，否则，以“CSPS用户模板ID”中定义的计费参数为准。
- 当用户签约的“5G用户模板ID”模板数据发生修改时，如果模板新增或修改了“用户计费签约数据”参数，计费签约数据以修改后的“5G用户模板ID”中的为准。
- 用户签约5G虚拟网络组时，对于同一个“切片标识”和“数据网名称”下的5G虚拟网络组，建议用户只签约一个。

## 使用实例

1. 为“IMSI/MSISDN文件名”为“IMSI\_SUB.txt”的用户开户，命令如下:

   ```
   BAT ADDTPLSUB: HLRSN=1, FILE="IMSI_SUB.txt", CSPSTPLID=1;
   ```
2. 为“IMSI/MSISDN文件名”为“IMSI\_NPN.txt”的NPN用户开户，其中，“5G用户模板ID”为“1”，“PLMNID”为“111111”，“是否只允许UE通过CAG小区接入5GS”为“TRUE”，“CAGID”为“11111111”，命令如下:

   ```
   BAT ADDTPLSUB: HLRSN=1, FILE="IMSI_NPN.txt", NGSUSERTPLID=1, PLMNID="111111", CAGONLY=TRUE, CAGID="11111111";
   ```
