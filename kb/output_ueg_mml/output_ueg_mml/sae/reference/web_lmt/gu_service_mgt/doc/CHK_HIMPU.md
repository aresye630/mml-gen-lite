# 校验IMPU(CHK HIMPU)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于校验“IMPU”与“IMPI”是否属于同一个IMS用户。

当需要检验“IMPU”和“IMPI”是否关联相同的“SUBID”时，操作员使用该命令完成。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                     |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------|
| IMPI   | IMPI   | 标识一个用户的关键参数之一，用于指示系统验证哪一个“IMPI”。要求输入的IMPI值符合NAI格式，字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：必选参数。             |
| IMPU   | IMPU   | 标识一个用户的关键参数之一，用于指示系统验证哪一个“IMPU”。要求输入的IMPU值符合SIP URI或TEL URI格式，字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：必选参数。 |

## 使用实例

校验IMPU，“IMPI”为“impiinfo”，“IMPU”为“sip:impuinfo@huawei.com”。

```
CHK HIMPU: IMPI="impiinfo", IMPU="sip:impuinfo@huawei.com";
```
