# 增加优化GPRS/EPS模板(ADD OPTGPRSTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此操作用于增加优化GPRS/EPS模板，使用**ADD OPTGPRSTPL**命令，只能增加一条PDP/PDN上下文，如果用户需要签约多条PDP/PDN上下文，请使用命令**MOD OPTGPRSTPL**。

## 注意事项

同一个“HLR序列号”中增加的优化GPRS/EPS模板记录数不能超过40000条，且系统中所有优化GPRS/EPS模板增加的PDP/PDN上下文总记录数不能超过40000条。

## 使用实例

1. 增加优化GPRS模板，模板ID为3，模板名称为optgprstpl，APN模板ID为2，QoS模板ID为2，Context ID为2，PDP地址类型为IPV4，允许访问VPLMN的APN，采用预付费计费方式。命令如下：

   ADD OPTGPRSTPL: HLRSN=1, TPLID=3, TPLNAME="optgprstpl", CNTXID=2, APNTPLID=2, QOSTPLID=2, PDPTYPE=IPV4, VPLMN=TRUE, CHARGE=PREPAID;
2. 增加EPS模板，模板ID为100，模板名称为EPS\_OPTGPRSTPL，APN类型为BOTH、APN模板ID为100，QoS模板ID为100，EPS QoS模板ID为100，PDN类型为IPV4，允许访问VPLMN的APN，采用平计费方式。命令如下：

   `ADD OPTGPRSTPL: HLRSN=1, TPLID=100, TPLNAME="EPS_OPTGPRSTPL", APN_TYPE=BOTH, APNTPLID=100, DEFAULTCFGFLAG=TRUE, QOSTPLID=100, EPS_QOSTPLID=100, PDPTYPE=IPV4, VPLMN=TRUE, CHARGE=FLAT;`

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。
