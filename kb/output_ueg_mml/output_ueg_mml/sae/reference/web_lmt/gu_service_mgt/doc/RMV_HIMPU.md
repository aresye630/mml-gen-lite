# 删除IMPU(RMV HIMPU)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于从HSS的业务数据库中删除一条指定的IMPU记录。

## 注意事项

如果操作员删除某条IMPU记录，将使相应的用户被注销，从而导致正在使用该IMPU的用户不能正常使用通信业务，请操作员在执行该操作之前仔细确认任务的可行性 。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                           |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------|
| IMPU   | IMPU   | 标识一条局向数据记录的关键字段，用于指定一个需要删除的IMPU，要求输入的IMPU值符合SIP URI或TEL URI格式。字母区分大小写。操作员可以使用LST HSUB命令查询获得。 取值范围：长度不超过127的字符串 默认值：无。 说明：必选参数。 |

## 使用实例

删除IMPU，“IMPU”为“sip:impuinfo@huawei.com”：

```
RMV HIMPU: IMPU="sip:impuinfo@huawei.com";
```
