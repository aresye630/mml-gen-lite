## 命令功能

**须知** 

该命令属于高危命令，执行不当会增加数据库的负荷，引起系统过载。请仔细评估数据查询的范围及执行的次数后方可执行。并且该命令不能和**LST LOG**、**LST HLOG**命令同时执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用于查询内存库的空口日志中通过PUR消息更新的IMS用户或PSI用户透明数据。

查询完成后，查询的结果以文本格式保存在PGW中，可以通过PGW Web LMT上的“文件管理器”下载到本地。

**说明** 

- 查询结果包含用户的个人数据，如：IMPU，因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护，并严格控制查询结果文件的访问权限。
- 在从运营商网络获取数据前，必须要获得运营商的授权。
- 若需从运营商网络中获取必要的数据，需要运营商维护人员对其中的个人数据进行匿名化处理，匿名化后的数据由运营商维护人员审核后提供，以防止个人数据泄露。匿名化处理工具可以在http://support.huawei.com/网站获取，获取方法请参见产品手册“匿名化工具安全策略”页面。

## 注意事项

- “开始时间”和“IMPU”两个参数至少存在一个。
- 当“结束时间”参数存在时，“开始时间”参数必须存在，且“开始时间”的取值必须小于或等于“结束时间”的取值。

## 参数说明

| 参数标识      | 参数名称        | 参数说明                                                                                                                                                                     |
|:----------|:------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMPU      | IMPU        | 用于指示系统需要按照指定的IMPU或PUSI来查询通过PUR消息更新的透明数据；若不输入，则表示查询所有的IMPU或PUSI。 取值范围：长度不超过127的字符串。 默认值：无。                                                                                |
| STARTTIME | 开始时间        | 用于指示系统需要按照指定的“开始时间”来查询通过PUR消息更新的透明数据；若不输入，则表示查询所有开始时间。 取值范围：为19位的字符串，“YYYY&MM&DD&HH&MM&SS”的字符串。 默认值：无。 说明：当“结束时间”参数未输入，“开始时间”参数输入时，则表示查询从“开始时间”到当前时间的时间段内通过PUR消息更新的透明数据。 |
| ENDTIME   | 结束时间        | 用于指示系统需要按照指定的“结束时间”来查询通过PUR消息更新的透明数据；若不输入，则表示查询所有结束时间。 取值范围：为19位的字符串，“YYYY&MM&DD&HH&MM&SS”的字符串。 默认值：无。                                                                   |
| RESULT    | 执行结果        | 用于指示系统需要按照指定的“执行结果”来查询操作日志；若不输入，则表示查询所有执行结果的操作日志。 取值范围：ERROR：表示通过PUR消息更新透明数据操作失败的操作日志。SUCCESS：表示通过PUR消息更新透明数据操作成功的操作日志。 默认值：无。                                           |
| SAVEAS    | 保存文件名       | 用于指示系统需要按照指定的文件名来保存查询的透明数据到文件中。操作员可以通过WebUI的文件下载功能获取该文件。 取值范围：1～20位由字母、十进制数字或“_”、“.”字符组成的字符串。 默认值：无。                                                                     |
| IMPUONLY  | 是否只导出IMPU列表 | 用于指示执行该命令后，查询结果是否只包含IMPU列表。 取值范围：TRUE：查询结果只包含IMPU列表。FALSE：查询结果包含所有的输出项。 默认值：FALSE。                                                                                       |

## 使用实例

1. 查询PUR消息更新的指定IMPU的透明数据。“IMPU”为“sip:impuinfo1@huawei.com”、“保存文件名”为“lsthpurrepdata01.txt”：

   ```
   LST HPURREPDATA: IMPU="sip:impuinfo1@huawei.com", SAVEAS="lsthpurrepdata01.txt";
   ```
2. 查询PUR消息更新的某时间段内的透明数据。“开始时间”为“2016&06&06&09&00&00”、“结束时间”为“2016&06&07&09&00&00”、“保存文件名”为“lsthpurrepdata02.txt”：

   ```
   LST HPURREPDATA: STARTTIME=2016&06&06&09&00&00, ENDTIME=2016&06&07&09&00&00, SAVEAS="lsthpurrepdata02.txt";
   ```

| IMPU       | 用于返回通过PUR消息更新的透明数据的IMPU或PUSI标识。 |
| RESULT     | 用于返回通过PUR消息更新透明数据操作的执行结果。       |
| MMLCOMMAND | 用于返回通过PUR消息更新的透明数据的记录。          |
