# 设置地址限制（SET BWADDR）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于设置地址限制表中地址号码和对应的MAP请求消息的处理规则。

地址限制表中包含的地址号码为：短消息中心地址、SCP地址及MSC地址。

## 注意事项

- 当参数“操作类型”为“ADD”时，“地址号码”和“地址号码文件名”是互斥参数，必需有且只能出现一个。
- 同一个“HLR序列号”中增加的地址限制记录数不能超过1000条。

## 参数说明

| 参数标识         | 参数名称               | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
|:-------------|:-------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN        | HLR序列号             | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| OPTYPE       | 操作类型               | 用于标识地址限制表中的地址号码对MAP请求消息处理的操作类型。 取值范围： ADD：增加一条记录或批量增加多条记录。 DELETE：删除一条已有记录。 MODIFY：修改一条已有记录的MAP请求消息的处理规则。 DELETEALL：删除所有记录。 DEFRULE：设置MAP请求消息的缺省处理规则。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ADDR         | 地址号码               | 仅当参数“操作类型”为“ADD”、“MODIFY”或“DELETE”时该参数有效。用于标识地址限制表中的地址号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| FILE         | 地址号码文件名            | 仅当参数“操作类型”为“ADD”时该参数有效。用于标识地址限制表中的地址号码文件名称。 地址号码批操作文件为文本编辑器编辑的文本文件（编码格式为ANSI），如“setbwaddr.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见地址号码文件格式。 取值范围：1～16位的数字或字符组成的字符串，不可包含路径名称。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| MAPPROCEDURE | MAP操作流程            | 仅当参数“操作类型”为“ADD”、“MODIFY”、“DELETE”或“DEFRULE”时该参数有效。用于标识地址限制表中对应的MAP操作流程。 取值范围： SRIFORSM：短信息取路由信息。 SRIFORGPRS：GPRS取路由信息。 ATI：任意时刻查询。 SRI：被叫取路由信息。 ATSI：任意时刻用户信息查询。 USSDR：非结构化补充业务数据请求。ATM：任意时刻修改。SRIFORLCS：LCS取路由。PURGEMS：清除终端信息。ISTALERT：立即业务终止警报。REGISTERSS：登记补充业务。ERASESS：去登记补充业务。ACTIVATESS：激活补充业务。DEACTIVATESS：去活补充业务。INTERROGATESS：查询补充业务。REGISTERPWD：登记密码。PUSSDR：处理非结构化补充业务数据请求。SENDIMSI：获取IMSI。READYFORSM：短消息功能已就绪。RSD：数据恢复流程。SENDPARAMETERS：SEND_PARAMETERS请求。USSDN：非结构化补充业务数据通知。REPORTSMDELSTA：短消息状态报告。FAILUREREPORT：失败报告。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                          |
| RULE         | 是否屏蔽发送到HLR的MAP请求消息 | 仅当参数“操作类型”为“ADD”、“MODIFY”或“DEFRULE”时该参数有效。用于标识在地址限制表中是否屏蔽发送到HLR的MAP请求消息。 取值范围： FORBIDDEN：屏蔽，即拒绝该MAP请求消息，并向对端地址返回拒绝消息。 ALLOWABLE：不屏蔽，即按照正常MAP流程进行处理。 默认值：无。 说明：UDM在接收到对端MAP消息后是否对其设置地址限制，请参见MAP消息处理原则。设置地址限制后：UDM在接收到SRIFORSM、SRIFORGPRS、ATI、ATSI、USSDR、ATM、SRIFORLCS、PURGEMS、ISTALERT、REGISTERSS、ERASESS、ACTIVATESS、DEACTIVATESS、INTERROGATESS、REGISTERPWD、PUSSDR、SENDIMSI、READYFORSM、RSD、SENDPARAMETERS、USSDN、REPORTSMDELSTA或FAILUREREPORT请求消息后，会拒绝该消息并向对端网元返回相应的错误码。返回的错误码如下：SRIFORSM：根据SET MAPSERV命令的参数“过滤的短消息取路由消息的返回值”设置，确定返回的错误码。SRIFORGPRS、USSDR、ATM、SRIFORLCS、PURGEMS、ISTALERT、REGISTERSS、ERASESS、ACTIVATESS、DEACTIVATESS、INTERROGATESS、REGISTERPWD、PUSSDR、SENDIMSI、READYFORSM、RSD、SENDPARAMETERS、USSDN、REPORTSMDELSTA或、FAILUREREPORT：返回“unexpectedDataValue”。ATI：根据SET MAPCONF命令的参数“ATI拒绝流程错误码信息”设置，返回“unexpectedDataValue”或者“ATI NOT ALLOWED”。ATSI：返回“atsi-NotAllowed”。 UDM在接收到SRI请求消息后，会将被叫号码作为MSRN直接返回。 |

## 使用实例

1. 增加一条地址限制表记录，其中“地址号码”为“861380755001”，“MAP操作流程”为“SRIFORSM”，“是否屏蔽发送到HLR的MAP请求消息”为“ALLOWABLE”：

   `SET BWADDR: HLRSN=1, OPTYPE=ADD, ADDR="861380755001", MAPPROCEDURE=SRIFORSM, RULE=ALLOWABLE;`
2. 批量增加地址限制表记录，其中“地址号码文件名”为“smcaddress.txt”，“MAP操作流程”为“SRIFORSM”，“是否屏蔽发送到HLR的MAP请求消息”为“ALLOWABLE”：

   `SET BWADDR: HLRSN=1, OPTYPE=ADD, FILE="smcaddress.txt", MAPPROCEDURE=SRIFORSM, RULE=ALLOWABLE;`

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释      | 原因分析                                                                      | 处理建议                                                                                                                           |
|:--------|:-----------|:--------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------|
| ERR1009 | 参数丢失       | 当参数“操作类型”选择“ADD”后，“地址号码”或“地址号码文件名”未输入。                                    | 根据实际情况，重新输入参数。并满足“地址号码”或“地址号码文件名”参数必须有且只能有一个参数出现的条件。                                                                           |
| ERR1010 | 参数冲突       | 当参数“操作类型”选择“ADD”后，“地址号码”和“地址号码文件名”参数同时输入。                                 | 根据实际情况，重新输入参数。并满足“地址号码”或“地址号码文件名”参数必须有且只能有一个参数出现的条件。                                                                           |
| ERR1111 | 记录数超过1000条 | 同一个“HLR序列号”中增加的地址限制记录数超过1000条。                                            | 根据实际情况，如需增加地址限制记录，处理步骤如下：执行LST BWADDR命令，查询已存在地址限制记录。执行该命令删除不必要的地址限制记录。执行该命令增加地址限制记录，确保增加的地址限制记录数在规定范围之内。                       |
| ERR1004 | 无效的参数值     | 输入的参数取值不在其取值范围内。                                                          | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                               |
| ERR3007 | 记录不存在      | 可能原因为如下之一：输入的“HLR序列号”不存在。参数“操作类型”设置为“MODIFY”或“DELETE”时，输入的“地址号码”对应的记录不存在。 | 根据实际情况选择：核实输入的“HLR序列号”，重新输入参数，确保输入的“HLR序列号”已存在，可通过LST HLRSN命令查询。核实输入的“地址号码”，重新输入参数，确保输入的“地址号码”已经在该命令中参数“操作类型”设置为“ADD”时添加了记录信息。 |
