# 修改短消息前转业务(MOD SMSCF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于为用户签约或去签约短消息前转业务。

当用户终端暂时无法接收短消息或希望通过其他终端接收短消息时，可以使用该命令签约短消息前转业务，再通过**ACT SMSCF**命令给用户激活短消息前转业务，满足用户紧急处理短消息的需求。

## 注意事项

- “IMSI”、“ISDN”、“IMSI文件名”和“MSISDN文件名 ”四个参数必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时存在，只能与“IMSI”或“MSISDN”一起出现，用于为用户签约或去签约短消息前转业务。

## 参数说明

| 参数标识        | 参数名称        | 参数说明                                                                                                                                                                                                                                                                     |
|:------------|:------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI        | 用于标识待签约或去签约短消息前转业务用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                               |
| ISDN        | ISDN        | 用于标识待签约或去签约短消息前转业务用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                             |
| RECORDCOUNT | 用户个数        | 用于标识待签约或去签约短消息前转业务用户的数目。 当需要为连续号码的多个用户签约或去签约短消息前转业务时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行签约或去签约短消息前转业务。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户进行签约或去签约短消息前转业务，当只有一个用户时，该参数不必配置。当一次签约或去签约短消息前转业务的用户个数很多时，对系统性能无影响，但签约或去签约短消息前转业务的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名     | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要签约或去签约短消息前转业务用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modsmscf.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                                                    |
| ISDNFILE    | MSISDN文件名   | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要签约或去签约短消息前转业务用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modsmscf.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                                              |
| PROV        | 是否提供SMSCF业务 | 用于标识执行该命令是为用户签约还是去签约短消息前转业务。 取值范围：TRUE：签约短消息前转业务。FALSE：去签约短消息前转业务。 默认值：无。                                                                                                                                                                                                |
| OFAID       | OFA模板ID     | 仅当本命令中“是否提供SMSCF业务”参数设置为“TRUE”时该参数有效，用于标识OFA（Origin for Forwarded-to number Analysis）模板ID。 取值范围：0～65534 默认值：无。 说明：OFA模板ID必须通过ADD OFATPL命令定义后才能使用。                                                                                                                        |

## 使用实例

1. 为IMSI号码是460021001008001的用户签约短消息前转业务。

   MOD SMSCF: IMSI="460021001008001", PROV=TRUE;
2. 为IMSI号码是460021001008001的用户去签约短消息前转业务。

   MOD SMSCF: IMSI="460021001008001", PROV=FALSE;

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释      | 原因分析                                                                                             | 处理建议                                                                                                            |
|:--------|:-----------|:-------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值     | 可能原因为如下之一：参数“IMSI”的取值不是6～15位十进制数字组成的字符串。参数“ISDN”的取值不是1～15位十进制数字组成的字符串。                           | 根据实际情况，重新输入“IMSI”或“ISDN”的取值，确保其取值符合要求。                                                                          |
| ERR1009 | 参数丢失       | “IMSI”、“ISDN”、“IMSI文件名”或“MSISDN文件名”四个参数一个都没有输入。                                                  | 根据实际情况，重新输入参数，确保满足“IMSI”、“ISDN”、“IMSI文件名”或“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                      |
| ERR1005 | 文件未找到      | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                 | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。              |
| ERR1010 | 参数冲突       | 可能原因为如下之一：“IMSI”、“ISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“ISDN”、“IMSI文件名”或“MSISDN文件名”四个参数必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR3007 | 记录不存在      | 用户的IMSI号码或MSISDN号码输入错误，实际输入的参数“IMSI”或“ISDN”对应的用户未开户。                                             | 核实用户的IMSI号码或ISDN号码，如果确定输入无误，证明实际输入的参数“IMSI”或“MSISDN”对应的用户未开户，请先通过ADD SUB命令给用户开户。                                |
| ERR1025 | 批操作文件中格式非法 | 参数“IMSI文件名”或“MSISDN文件名”、对应的批操作文件格式不正确。                                                           | 请根据IMSIFILE文件格式或ISDNFILE文件格式，重新确定对应的批操作文件格式。                                                                    |
| ERR3016 | 基本业务未提供    | 用户的短消息服务未开启。                                                                                     | 请先通过MOD TS命令为用户提供短消息业务。                                                                                         |
