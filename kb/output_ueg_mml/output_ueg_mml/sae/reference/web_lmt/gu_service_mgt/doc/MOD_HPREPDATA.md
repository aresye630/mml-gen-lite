# 修改扩展业务数据(MOD HPREPDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于在HSS的业务数据库修改指定IMPU的扩展业务数据，唯一标识数据记录的关键参数是IMPU。

## 注意事项

- 以下参数必须至少存在一个：“IMSI”，“是否支持自助业务”，“短消息中心地址”，“VoBB用户的位置信息”，“Numbering Plan Identity编码方案识别”，“是否支持通过Carrier Identification Code进行平等接入业务”，“是否支持CS绑定”。
- 当修改指定IMPU的扩展业务数据时，如果返回报文“解密失败”，表示该数据属于透明数据，需要使用**SET HREPDATA**命令进行修改。

## 参数说明

| 参数标识                | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|:--------------------|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMPU                | IMPU       | 用于指定修改扩展业务的IMPU，要求输入的IMPU值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无                                                                                                                                                                                                                                                                                                                                                                               |
| IMSI                | IMSI       | 用于指定需要修改的IMSI，由不超过15位的十进制数字(0～9)组成，采用E.212格式。例如：460001234567890。 取值范围：6–15 缺省值： 无                                                                                                                                                                                                                                                                                                                                                                              |
| SELFSERVICE         | 支持自助业务     | 用于指定需要修改的自助业务标识，其值域类型为布尔值。 取值范围： TRUE(True)：支持自助业务。 FALSE(False)：不支持自助业务。 缺省值： 无                                                                                                                                                                                                                                                                                                                                                                               |
| SMSCADDRESS         | 短消息中心地址    | 用于指定需要修改的短消息中心地址，由不超过40位的十进制数字(0～9)组成，采用E.164格式。例如：1234567890。 取值范围：长度不超过40的字符串 缺省值： 无                                                                                                                                                                                                                                                                                                                                                                         |
| LOCATIONINFORMATION | VoBB用户位置信息 | 用于定义一个VoBB用户的位置信息，合法长度为9、10、13、14位，可由十进制数字（0～9）、字符（'A'～'F'）组成。 位置区信息分为LAI和GCI类型： LAI号码的最大长度为10位，其编码格式为：MCC+MNC+LAC，一个典型的LAI号码例如为460-00-4777。其配置原则是： 当MNC为2位时，则需要填写9位的LAI号码。 当MNC为3位时，则需要填写10位的LAI号码。 LAI号码中的LAC部分不能为“0000”或“FFFE”。 GCI号码的最大长度为14位，其编码格式为：MCC+MNC+LAC+CI，一个典型的GCI号码例如为460-00-4777-0001。其配置原则是： 当MNC为2位时，则需要填写13位的GCI号码。 当MNC为3位时，则需要填写14位的GCI号码。 GCI号码中的LAC部分不能为“0000”或“FFFE”。 其中，MCC长度固定为3位，MCC和MNC部分只能为十进制数字（0～9）。 取值范围：长度为9、10、13、14位 缺省值： 无 |
| NPINDICATOR         | NPI编码方案识别  | 用于指定需要修改的Numbering Plan Identity编码方案，其值域类型为布尔值。 取值范围： TRUE(True)：识别。 FALSE(False)：不识别。 缺省值： 无                                                                                                                                                                                                                                                                                                                                                                  |
| CICINDICATOR        | 通过CIC接入业务  | 用于指定需要修改的是否支持通过Carrier Identification Code进行平等接入业务，其值域类型为布尔值。 取值范围： TRUE(True)：支持。 FALSE(False)：不支持。 缺省值： 无                                                                                                                                                                                                                                                                                                                                                    |
| BINDINDICATOR       | CS 绑定标识    | 用于指定需要修改的是否支持CS绑定，其值域类型为布尔值。 取值范围： TRUE(True)：支持。 FALSE(False)：不支持。 缺省值： 无                                                                                                                                                                                                                                                                                                                                                                                     |

## 使用实例

修改IMPU的扩展业务数据IMSI。IMPU：sip:impuinfo@huawei.com；IMSI：400612345678。

```
MOD HPREPDATA: IMPU="sip:impuinfo@huawei.com", IMSI="400612345678";
```
