## 命令功能

该命令用于在UDM增加自动批操作文件及各类结果名称的前缀。

批操作文件通过FTP服务器上传到PGW模板的“/opt/pgw/upload/HSS9860”目录下，UDM从FTP上传目录中根据最大前缀匹配的方式获取匹配的文件名，将该文件作为待执行的批操作文件。再根据定义的自动批操作文件名称获取各类结果文件名称前缀，使用该前缀与待执行的批操作文件名称进行拼接组装，并将组装后的名称返回给PGW。

**说明** 

- 自动批操作文件包含多个待执行的MML命令行，为文本编辑器编辑的文本文件。FTP方式上传的批操作文件，不能是.lst或.SFTPPARTFILE后缀的文件。
- FTP方式上传的批操作文件名是1～124位由字母、十进制数字、“\_”、“-”或“.”组成的字符串。

例如：待执行的“批操作文件名称”为“Bat.txt”，“结果文件名前缀”为“Rst”，“成功结果文件名前缀”为“succRst”、“失败结果文件名前缀”为“errRst”、“详细结果文件名前缀”为“detailRst”，组装后的文件名如下所示。

- 结果文件：不进行拆分处理，组装后的文件名为“RstBat.txt”。
- 成功结果文件、失败结果文件、详细结果文件：文件拆分逻辑为每100MB拆分一次，在组装后的文件名后增加“\_序号”。
  - “succRstBat.txt\_1”、“succRstBat.txt\_2”
  - “errRstBat.txt\_1”、“errRstBat.txt\_2”
  - “detailRstBat.txt\_1”、“detailRstBat.txt\_2”

通过该命令新增自动批操作文件名称时，系统支持在文件名的最后添加时间，定义格式为“Prefix\_YYYYMMDD\_HH\_MM\_SS\_NNNNNN.dat”，实现定时批操作功能。

**说明** 

- Prefix为前缀，由客户自定义。
- YYYYMMDD\_HH\_MM\_SS是文件创建的时间(年月日时分秒)，NNNNNN是从0开始循环累加的6位序号，.dat是固定的后缀。

当匹配到该命令定义的文件名前缀时，系统检查文件名中的时间，并和系统时间作比较。

- 当未匹配上时间格式的文件名时，系统直接执行批处理操作。
- 当匹配上时间格式的文件名时:
  - 对于小于或等于系统时间的文件系统直接执行批操作。
    - 当存在多条时间前缀小于或等于系统时间的文件，则按照时间先后顺序，优先返回时间最早的一个文件进行批操作。
    - 当存在多条时间前缀小于或等于系统时间，且时间前缀相同的文件，则按照序号大小顺序，优先返回序号最小的一个文件进行批操作。
  - 对于均大于系统时间的文件，需要等待系统时间与文件名中时间前缀一致时再执行批操作。

批操作文件执行结束后，系统自动删除FTP上传目录“/opt/pgw/upload/HSS9860”中的批操作文件。

## 注意事项

- 批操作文件执行时是否生成成功结果文件、失败结果文件和详细结果文件由“BATWRITERESULTAPART（批操作分成功、失败、查询详细结果文件开关）”软参控制。
- “批操作文件名前缀”和“结果文件名前缀”取值不能相同。
- “成功结果文件名前缀”、“失败结果文件名前缀”、“详细结果文件名前缀”取值不能相同。
- “批操作文件名前缀”和“成功结果文件名前缀”、“失败结果文件名前缀”、“详细结果文件名前缀”取值不能相同。
- “成功结果文件名前缀”、“失败结果文件名前缀”、“详细结果文件名前缀”必须同时存在或同时不存在。
- UDM支持设置的自动批操作文件名称最多为100个。

## 参数说明

| 参数标识            | 参数名称      | 参数说明                                                                                                                                                   |
|:----------------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
| BATPREFIX       | 批操作文件名前缀  | 用于标识批操作文件名的前缀。“批操作文件名前缀”区分大小写字母。 取值范围：1～32位字母或十进制数字组成的字符串。 默认值：无。 说明：PGW会在即将执行自动批操作的文件的文件名之前增加“pro_”前缀。因此，“批操作文件名前缀”不支持配置为“pro_”开头的前缀，其中pro三个字母不区分大小写。 |
| RSTPREFIX       | 结果文件名前缀   | 用于标识批操作结果文件名称前缀。“结果文件名前缀”区分大小写字母。 取值范围：1～32位字母或十进制数字组成的字符串。 默认值：无。                                                                                     |
| RSTSUCCPREFIX   | 成功结果文件名前缀 | 用于标识批操作成功结果文件名称前缀。“成功结果文件名前缀”区分大小写字母。 取值范围：1～32位字母或十进制数字组成的字符串。 默认值：无。                                                                                 |
| RSTERRPREFIX    | 失败结果文件名前缀 | 用于标识批操作失败结果文件名称前缀。 取值范围：1～32位字母或十进制数字组成的字符串。“失败结果文件名前缀”区分大小写字母。 默认值：无。                                                                                 |
| RSTDETAILPREFIX | 详细结果文件名前缀 | 用于标识批操作详细结果文件名称前缀。 取值范围：1～32位字母或十进制数字组成的字符串。“详细结果文件名前缀”区分大小写字母。 默认值：无。                                                                                 |

## 使用实例

增加自动批操作文件名称，参数配置如下：

- “批操作文件名前缀”为“Bat”
- “结果文件名前缀”为“Rst”
- “成功结果文件名前缀”为“succRst”
- “失败结果文件名前缀”为“errRst”
- “详细结果文件名前缀”为“detailRst”

```
ADD BATFILENAME: BATPREFIX="Bat", RSTPREFIX="Rst", RSTSUCCPREFIX="succRst", RSTERRPREFIX="errRst", RSTDETAILPREFIX="detailRst";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 消息解释     | 原因分析                                                                                   | 处理建议                                                                                          |
|:--------|:---------|:---------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数取值  | “批操作文件名前缀”设置为“pro_”开头的取值。                                                              | 根据实际情况，重新输入“批操作文件名前缀”的取值，确保其取值不是以“pro_”开头。                                                    |
| ERR1009 | 参数丢失     | 没有同时输入“成功结果文件名前缀”、“失败结果文件名前缀”、“详细结果文件名前缀”参数。                                           | 同时输入或者删除“成功结果文件名前缀”、“失败结果文件名前缀”、“详细结果文件名前缀”参数取值。                                              |
| ERR3804 | 参数取值不能相等 | 可能原因为如下之一：“批操作文件名前缀”与其他参数输入的值相同。“成功结果文件名前缀”、“失败结果文件名前缀”、“详细结果文件名前缀”三个参数其中的两个或多个输入的值相同。 | 根据实际情况，重新输入参数，确保满足注意事项要求。“批操作文件名前缀”与其他参数输入的值都不相同。“成功结果文件名前缀”、“失败结果文件名前缀”、“详细结果文件名前缀”输入的值都不相同。 |
