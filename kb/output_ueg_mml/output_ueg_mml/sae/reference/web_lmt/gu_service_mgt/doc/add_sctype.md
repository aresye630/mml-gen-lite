# 增加短消息Short-Code类型(ADD SCTYPE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HLR中增加短消息Short-Code类型。

## 注意事项

同一个“HLR序列号”中增加的短消息Short-Code前缀对应的短消息类型的记录数不能超过10000条。

## 参数说明

| 参数标识       | 参数名称         | 参数说明                                                                                             |
|:-----------|:-------------|:-------------------------------------------------------------------------------------------------|
| HLRSN      | HLR序列号       | 用于标识本地HLR。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                        |
| CODEPREFIX | Short-Code前缀 | 用于标识具有相同号码前缀的Short-Code。 取值范围：1～10位十进制数字组成的字符串。 默认值：无。                                           |
| PREMSMS    | 是否为付费短消息     | 用于标识Short-Code前缀对应的短消息是否为付费短消息。 取值范围： TRUE：是。FALSE：否。 默认值：FALSE。 说明：当执行命令时不输入该参数时，系统会设置初始值FALSE。 |
| ADULTSMS   | 是否为成人短消息     | 用于标识Short-Code前缀对应的短消息是否为成人短消息。 取值范围： TRUE：是。FALSE：否。 默认值：FALSE。 说明：当执行命令时不输入该参数时，系统会设置初始值FALSE。 |

## 使用实例

1. 在HLR中添加短消息类型码Short-Code前缀对应的类型为“付费短消息”。“HLR序列号”为“1”，“Short-Code前缀”为“800”，“是否为付费短消息”为“TRUE”：

   ```
   ADD SCTYPE: HLRSN=1,CODEPREFIX="800",PREMSMS=TRUE;
   ```
2. 在HLR中添加短消息类型码Short-Code前缀对应的类型为“不是付费短消息和成人短消息”。“HLR序列号”为“1”，“Short-Code前缀”为“800”，“是否为付费短消息”为“FALSE”，“是否为成人短消息”为“FALSE”：

   ```
   ADD SCTYPE: HLRSN=1,CODEPREFIX="800",PREMSMS=FALSE,ADULTSMS=FALSE;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                    | 处理建议                                                                                                                                                                                                                |
|:--------|:--------|:----------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1111 | 超过最大限制  | 增加的短消息Short-Code前缀对应的短消息类型的记录数超过10000条。 | 根据实际情况，如需增加短消息Short-Code前缀对应的短消息类型记录，处理步骤如下：执行LST SCTYPE命令，查询已存在短消息Short-Code前缀对应的短消息类型记录。执行RMV SCTYPE命令，删除不必要的短消息Short-Code前缀对应的短消息类型记录。执行该命令，增加的短消息Short-Code前缀对应的短消息类型记录，确保增加后短消息Short-Code前缀对应的短消息类型记录数在规定范围之内。 |
