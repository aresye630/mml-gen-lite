# 修改ODB-BOC业务(MOD ODBOC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来修改指定用户应用的ODB-BOC业务的种类。

如果UDM支持签约管理优化（执行**SET MAPCONF**命令将“用户被锁后是否允许操作相关补充业务”设置为“TRUE”），即使已执行**MOD LCK**命令禁止用户呼出，仍可以执行该命令修改用户的“ODB-闭锁出呼叫”业务。

执行此命令后，系统将向VLR/SGSN下发插入用户数据消息。

## 注意事项

- IMSI、ISDN、IMSIFILE和ISDNFILE是条件可选参数，有且只能有一个参数出现。
- RECORDCOUNT一定不能与IMSIFILE或SDNFILE同时存在。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                          |
|:------------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | IMSI号码，E.212格式的编码，为6～15位的十进制数字。                                                                                                                                                                                               |
| ISDN        | MSISDN    | MSISDN号码，E.164格式的编码，为1～15位的十进制数字。                                                                                                                                                                                             |
| RECORDCOUNT | 用户个数      | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。                                                                                                                                           |
| IMSIFILE    | IMSI文件名   | IMSI文件名称，1～16个字母或数字组成。IMSIFILE包含多个不连续的IMSI号码。                                                                                                                                                                                 |
| ISDNFILE    | MSISDN文件名 | ISDN文件名称，1～16个字母或数字组成。ISDNFILE包含多个不连续的MSISDN号码。                                                                                                                                                                               |
| ODBOC       | ODB-闭锁出呼叫 | 闭锁出呼叫的种类。 NOBOC：不闭锁出呼叫。 BAOC：闭锁所有呼出业务。 BOIC：闭锁国际呼出业务。 BOICEXHC：闭锁除到归属国以外的国际呼出业务。 BOCROAM：当漫游出HPLMN (Home PLMN)国家时，闭锁呼出业务。 BOCCROSSDOMESTIC：当漫游到国内跨网，闭锁出呼叫业务。BOCROAMORCROSSDOMESTIC：当漫游出HPLMN (Home PLMN)国家或者漫游在国内跨网时，闭锁出呼叫业务。 |

## 使用实例

运营商为IMSI号码是460000009123456 ODB-BOC业务，闭锁的类型为漫游出归属PLMN国家以外时，闭锁呼出业务。命令如下：

MOD ODBOC: IMSI="460000009123456", ODBOC= BOCROAM;
