# 修改NRBT业务(MOD NRBT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来修改用户的本国回铃音NRBT（National Ring Back Tone）业务签约情况。为未签约NRBT业务的用户提供该业务，或者为已签约NRBT业务的用户撤销该业务。

执行此命令后，如果是给用户签约该业务，则会下发插入用户数据消息；如果是给用户去签约该业务，则会下发删除用户数据消息。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。
- 参数“是否提供NRBT业务”、“是否给ALS辅号提供NRBT业务”和“是否提供ARBT业务”至少有一个参数出现。
- 参数“是否提供NRBT业务”和“是否给ALS辅号提供NRBT业务”不能同时出现。
- 参数“是否给ALS辅号提供NRBT业务”和“是否提供ARBT业务”不能同时出现。

## 参数说明

| 参数标识        | 参数名称             | 参数说明                                                                                |
|:------------|:-----------------|:------------------------------------------------------------------------------------|
| IMSI        | IMSI             | IMSI号码，E.212格式的编码，6～15位的十进制数字。                                                      |
| ISDN        | MSISDN           | ISDN号码，E.164格式的编码，为1～15位的十进制数字。                                                     |
| RECORDCOUNT | 用户个数             | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。 |
| IMSIFILE    | IMSI文件名          | IMSI文件名称，1～16个字母或数字组成的字符串。IMSIFILE包含多个不连续的IMSI号码。                                   |
| ISDNFILE    | MSISDN文件名        | MSISDN文件名称，1～16个字母或数字组成的字符串。ISDNFILE包含多个不连续的MSISDN号码。                               |
| PROV        | 是否提供NRBT业务       | 提供还是撤销NRBT业务。 TRUE：提供FALSE：撤销                                                       |
| NRBT        | NRBT索引           | 仅当本命令中的"是否提供NRBT业务"参数为"TRUE"时该参数有效。本国回铃音业务的索引值，用于标识用户已经签约NRBT业务。值域为1～65535。         |
| ALSNRBTPROV | 是否给ALS辅号提供NRBT业务 | 是否给ALS辅号提供NRBT业务。 TRUE：提供FALSE：撤销                                                   |
| ALSNRBT     | ALS辅号NRBT索引      | 仅当本命令中的"是否给ALS辅号提供NRBT业务"参数为"TRUE"时该参数有效。用于标识ALS辅号签约的NRBT业务。值域为1～65535。             |
| ARBTPROV    | 是否提供ARBT业务       | 提供还是撤销ARBT业务。 TRUE：提供FALSE：撤销                                                       |
| ARBT        | ARBT索引           | 仅当本命令中的"是否提供ARBT业务"参数为"TRUE"时该参数有效。ARBT业务的索引值，用于标识用户已经签约ARBT业务。值域为1～65535。          |

## 使用实例

1. 运营商为IMSI号码是460000001234567的用户提供NRBT业务，并指定NRBT索引值为600。

   MOD NRBT: IMSI="460000001234567", PROV=TRUE, NRBT=600;
2. 运营商为IMSI号码是460000009123455、460000009123466和460000009123477的用户提供NRBT业务，并指定NRBT索引值为600。
   1. 编写IMSIFILE，文件名称为IMSIBAT，内容如下：

      460000009123455

      460000009123466

      460000009123477
   2. 通过Web UI上的文件选项将文件上传到指定位置。
   3. 执行MOD NRBT命令提供NRBT业务，并指定NRBT索引值为600。

      MOD NRBT: IMSIFILE="IMSIBAT", PROV=TRUE, NRBT=600;
