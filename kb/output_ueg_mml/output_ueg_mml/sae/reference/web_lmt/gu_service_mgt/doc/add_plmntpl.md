## 命令功能

该命令用于增加EPS用户的PLMN区域漫游模板。

PLMN区域漫游模板定义了用户在PLMN内的不同区域的漫游限制状态，通过执行**MOD PLMNRSZI**命令为用户签约PLMN漫游区域业务，只需签约对应的PLMN区域漫游模板。UDM在位置更新或用户签约PLMN漫游区域业务时把用户签约的ZC列表下发到用户所在的MME，MME收到ZC列表后，根据用户所在漫游区域中的ZC决定用户的漫游状态。

- 用户当前所在区域的ZC在用户签约的ZC列表中，用户是否能漫游根据“漫游限制状态”参数来决定。
- 用户当前所在区域的ZC不在用户签约的ZC列表中，用户是否能漫游根据“缺省漫游限制状态”参数来决定。

## 注意事项

- 系统中增加的PLMN区域漫游模板记录数不能超过20000条。
- 系统中每个PLMN区域漫游模板最多包含PLMN区域的号码标识（MCC+MNC的组合）3000条。
- VoWiFi场景下，**MOD PLMNRSZI**命令中“漫游控制类型”参数接口为“S6a\_SWx”或“SWx”时，如果MAR消息未携带VNI，则不支持通过“PLMN漫游限制模板ID”限制下发APN。
- 同一个PLMN区域漫游模板（配置一个PLMN或多个PLMN）只能配置一个“缺省业务下发模板ID”、 “NON\_3GPP缺省业务限制模板ID”和“3GPP缺省业务限制模板ID”。
- 用于DNN/APN替换业务时，只能使用PLMN区域的号码标识（MCC+MNC的组合）进行用户区域匹配，不使用ZC区域码进行匹配。

## 使用实例

为用户签约PLMN区域漫游业务，操作员需要配置以下数据。

1. 增加一个PLMN区域漫游模板。“HLR序列号”为“1”，“模板ID”为“1”，“模板名”为“test”，“缺省漫游限制状态”为“PERMISSION”,“移动国家码”为“460”，“移动网络码”为“03”，“是否本地PLMN”为“FALSE”，“漫游限制状态”为“RESTRICT”，“区域码1”为“0001”，“业务下发模板ID”为“1”：

   ```
   ADD PLMNTPL: HLRSN=1, TPLID=1, TPLNAME="test", DEFAULTRULE=PERMISSION, MCC="460", MNC="03", ISLOCAL=FALSE, RULE=RESTRICT, ZC1="0001", RSITPLID=1;
   ```
2. 执行**MOD PLMNRSZI**命令给用户签约PLMN区域漫游业务。

   ```
   MOD PLMNRSZI: IMSI="460000009123456", PROV=TRUE, PLMNTPLID=2;
   ```
