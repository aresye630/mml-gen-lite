# 修改PLMN区域漫游模板(MOD PLMNTPL)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使签约该模板的用户数据被同步修改，会影响在网用户业务体验，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改EPS用户的PLMN区域漫游模板信息数据。在该命令中，系统通过以下关键参数的组合来唯一标识一个PLMN区域漫游模板信息：

- “HLR序列号”
- “模板ID”

## 注意事项

- 该命令不允许进行批操作。
- 系统中同一个PLMN区域漫游模板增加的移动国家码（MCC）记录数不能超过200条，其中每个MCC最多包含200个移动网络码（MNC），且每个PLMN区域漫游模板最多包含PLMN区域的号码标识（MCC+MNC的组合）3000条。
- VoWiFi场景下，**MOD PLMNRSZI**命令中“漫游控制类型”参数接口为“S6a\_SWx”或“SWx”时，如果MAR消息未携带VNI，则不支持通过“PLMN漫游限制模板ID”限制下发APN。
- 同一个PLMN区域漫游模板（配置一个PLMN或多个PLMN）只能配置一个“缺省业务下发模板ID”、 “NON\_3GPP缺省业务限制模板ID”和“3GPP缺省业务限制模板ID”。

## 使用实例

1. 修改PLMN区域漫游模板数据，“HLR序列号”为“1”，“模板ID”为“1”，“操作类型”为“MOD\_DEFAULTRULE”，“缺省漫游限制状态”为“PERMISSION”：

   ```
   MOD PLMNTPL: HLRSN=1, TPLID=1, MODIFYTYPE=MOD_DEFAULTRULE, DEFAULTRULE=PERMISSION;
   ```
2. 修改PLMN区域漫游模板数据，“HLR序列号”为“1”，“模板ID”为“1”，“操作类型”为“ADD\_MCC”，“移动国家码”为“461”，“移动网络码”为“03”，“是否本地PLMN”为“TRUE”，“漫游限制状态”为“RESTRICT”，“区域码1”为“0001”，“业务下发模板ID”为“1”：

   ```
   MOD PLMNTPL: HLRSN=1, TPLID=1, MODIFYTYPE=ADD_MCC, MCC="461", MNC="03", ISLOCAL=TRUE, RULE=RESTRICT, ZC1="0001", RSITPLID=1;
   ```
3. 修改PLMN区域漫游模板数据，“HLR序列号”为“1”，“模板ID”为“1”，“操作类型”为“MOD\_MNC”，“移动国家码”为“460”，“移动网络码”为“00”，“漫游限制状态”为“RESTRICT”，“区域码1”为“1111”，“业务下发模板ID”为“1”：

   ```
   MOD PLMNTPL: HLRSN=1, TPLID=1, MODIFYTYPE=MOD_MNC, MCC="460", MNC="00", ISLOCAL=FALSE, RULE=RESTRICT, ZC1="1111", RSITPLID=1;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释    | 原因分析                                                                                                                                                                             | 处理建议                                                                                                                                                                                                                                                                                  |
