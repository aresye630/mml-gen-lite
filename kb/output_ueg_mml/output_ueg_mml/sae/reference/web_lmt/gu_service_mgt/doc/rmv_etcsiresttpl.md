# 删除ETCSI限制模板（RMV ETCSIRESTTPL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于从UDM中删除一条ETCSI限制模板记录。

## 注意事项

如果已经通过**ADD VLRTYP**命令关联该模板，当执行该命令删除ETCSI限制模板时，系统会提示“ERR3005:模板已经被使用”的错误信息，该ETCSI限制模板不能被删除。如果要删除该ETCSI限制模板，必须先执行**MOD VLRTYP**命令去掉VLR类型数据与ETCSI限制模板的关联关系。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                           |
|:-------|:-------|:-------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 标识一条ETCSI限制模板数据记录的关键字段之一，用于标识需要删除哪个HLR上的ETCSI限制模板记录，操作员可以使用LST HLRSN命令查询获得。    |
| TPLID  | 模板ID   | 标识一条ETCSI限制模板数据记录的关键字段之一，用于标识需要删除哪一条ETCSI限制模板记录，操作员可以使用LST ETCSIRESTTPL命令查询获得。 |

## 使用实例

删除“HLR序列号”为“1”、“模板ID”为“2”的ETCSI限制模板信息。命令如下：

```
RMV ETCSIRESTTPL: HLRSN=1, TPLID=2;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                  | 处理建议                                                                               |
|:--------|:--------|:--------------------------------------|:-----------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | “HLR序列号”和“模板ID”参数对应的ETCSI限制模板数据记录不存在。 | 可通过LST ETCSIRESTTPL命令只输入参数“HLR序列号”获取有效的“模板ID”。                                     |
| ERR3005 | 模板已经被使用 | VLR类型数据已关联该模板。                        | 根据实际情况，确定是否要删除该模板。如果确实需要删除，先通过MOD VLRTYP命令去掉VLR类型数据与ETCSI限制模板的关联关系，然后才能执行本命令删除该模板。 |
