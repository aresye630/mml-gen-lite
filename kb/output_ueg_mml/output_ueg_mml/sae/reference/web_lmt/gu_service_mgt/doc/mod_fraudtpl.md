# 修改防欺诈模板(MOD FRAUDTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此命令用于修改防欺诈模板。

## 注意事项

此模板被修改后，签约此模板的用户数据也会被修改，修改后的数据在用户新注册时会下发到网络。

## 参数说明

| 参数标识            | 参数名称       | 参数说明                                                                       |
|:----------------|:-----------|:---------------------------------------------------------------------------|
| HLRSN           | HLR序列号     | HLR序列号，在PGW支持容灾功能或虚拟HLR功能时设置。 取值范围：1～255 缺省值：无 说明：必选参数                     |
| TPLID           | 模板ID       | 用于在模板ID列表框中选择模板的ID。 取值范围：0～65534 缺省值：无 说明：必选参数                             |
| TPLNAME         | 模板名        | 用于定义新增防欺诈模板的名称。 取值范围：长度不超过60的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 缺省值：无            |
| MO_CONTROL_MODE | MO呼叫时间限制方式 | MO呼叫时间限制方式。 MOTIME：根据参数“MO呼叫时间限制”的取值进行控制 NE：使用对端网元设定的值 NONE：无限制            |
| MOTIME          | MO呼叫时间限制   | 仅当本命令中的“MO呼叫时间限制方式”参数为“MOTIME”时该参数有效。MO呼叫时间限制，单位为分钟。 取值范围：1～64800          |
| MOACT           | MO呼叫动作参数   | 仅当本命令中的“MO呼叫时间限制方式”参数为“MOTIME”或“NE”时该参数有效。MO呼叫动作参数。 NE：使用VLR默认处理 REJECT：拒绝 |
| CF_CONTROL_MODE | CF呼叫时间限制方式 | CF呼叫时间限制方式。 CFTIME：根据参数“CF呼叫时间限制”的取值进行控制 NE：使用对端网元设定的值 NONE：无限制            |
| CFTIME          | CF呼叫时间限制   | 仅当本命令中的“CF呼叫时间限制方式”参数为“CFTIME”时该参数有效。CF呼叫时间限制，单位为分钟。 取值范围：1～64800          |
| CFACT           | CF呼叫动作参数   | 仅当本命令中的“CF呼叫时间限制方式”参数为“CFTIME”或“NE”时该参数有效。CF呼叫动作参数。 NE：使用VLR默认处理 REJECT：拒绝 |
| CFRMAX          | CF登记最大数    | CF登记最大数。 取值范围：0～254(取值为0表示无限制)                                             |

## 使用实例

修改防欺诈模板，HLR序列号为1，模板号为2，模板名为FRAUD-01，MO呼叫时间限制方式为MOTIME，MO呼叫时间限制为6，MO呼叫动作参数为REJECT，CF呼叫时间限制方式为NONE，命令如下：

```
MOD FRAUDTPL: HLRSN=1, TPLID=2, TPLNAME="FRAUD-01", MO_CONTROL_MODE=MOTIME, MOTIME=6, MOACT=REJECT, CF_CONTROL_MODE=NONE;
```
