# 删除号码前缀和国家码数据(RMV NUMBERCCODE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中删除一条号码前缀和国家码数据记录。

## 注意事项

删除一条号码前缀和国家码数据记录，当用户做被叫，并且该用户号码匹配为该号码前缀时，呼叫该用户失败，请谨慎操作。

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                       |
|:-------------|:-------|:---------------------------------------------------------------------------|
| NUMBERPREFIX | 号码前缀   | 标识一条号码前缀和国家码数据记录的关键字段，用于标识需要删除哪一个号码前缀对应的数据记录，操作员可以使用LST NUMBERCCODE命令查询获得。 |

## 使用实例

删除“号码前缀”为“1380270”的数据记录：

```
RMV NUMBERCCODE: NUMBERPREFIX="1380270";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析               | 处理建议                                                                                         |
|:--------|:--------|:-------------------|:---------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | 输入的“号码前缀”在数据库中不存在。 | 核实用户的“号码前缀”，如果确定输入无误，证明该用户不存在号码前缀和国家码的对应关系，不需要再执行该命令，否则重新输入正确的“号码前缀”，可通过LST NUMBERCCODE命令查询。 |
