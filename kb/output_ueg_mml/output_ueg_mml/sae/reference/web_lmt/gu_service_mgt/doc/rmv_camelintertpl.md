# 删除CAMEL查询模板(RMV CAMELINTERTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条CAMEL（Customized Applications for Mobile network Enhanced Logic）查询协议模板的数据记录。

## 注意事项

如果已经通过**ADD OCSITPL**或**ADD TCSITPL**命令关联该模板，当执行该命令删除CAMEL查询协议模板时，系统会提示“ERR3005:模板已经被使用”的错误信息，该CAMEL查询协议模板不能被删除。如果要删除该CAMEL查询协议模板，必须先执行**MOC OCSITPL**或**MOD TCSITPL**命令去掉O-CSI模板或T-CSI模板与CAMEL查询协议模板的关联关系。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                |
|:-------|:-------|:------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 标识CAMEL查询协议模板数据记录的关键字段之一，用于指定在哪个HLR上删除CAMEL查询协议模板的数据记录，操作员可以使用LST HLRSN命令查询获得。      |
| TPLID  | 模板ID   | 标识CAMEL查询协议模板数据记录的关键字段之一，用于指定需要删除哪个CAMEL查询协议模板的数据记录，操作员可以使用LST CAMELINTERTPL命令查询获得。 |

## 使用实例

删除CAMEL查询协议模板。“HLR序列号”为“1”，“模板ID”为“1”：

```
RMV CAMELINTERTPL: HLRSN=1, TPLID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                  | 处理建议                                                                                                                   |
|:--------|:--------|:--------------------------------------|:-----------------------------------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | “HLR序列号”和“模板ID”对应的CAMEL查询协议模板数据记录不存在。 | 根据实际情况，重新输入已定义的“HLR序列号”和“模板ID”，可通过LST HLRSN命令查询已定义的“HLR序列号”，通过LST CAMELINTERTPL命令查询已定义的“模板ID”。                         |
| ERR3005 | 模板已经被使用 | O-CSI模板或T-CSI模板已关联该模板。                | 根据实际情况，确定是否要删除该模板。如果确实需要删除，先通过MOC OCSITPL或MOD TCSITPL命令去掉O-CSI模板或T-CSI模板与CAMEL查询协议模板的关联关系，然后才能执行RMV CAMELINTERTPL命令删除。 |
