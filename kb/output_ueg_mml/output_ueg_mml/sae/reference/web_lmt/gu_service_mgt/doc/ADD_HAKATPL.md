# 增加AKA鉴权信息模板(ADD HAKATPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS业务数据库中添加一个AKA鉴权信息模板。

## 注意事项

- 如果K4SNO参数取值为0，表明K未被加密，否则，K是经过K4加密的值。
- 如果OPSNO参数取值为0，OPC参数必须存在；如果OPSNO参数取值不为0，OPC参数不存在。
- 参数OPC和OPCK4SNO必须同时填写或同时不填写。如果输入的参数OPC是使用K4加密过的，则通过参数OPCK4SNO指定对OPC进行加密的K4索引；若输入的参数OPC是没有经过加密的，则参数OPCK4SNO必须填写为无效值（取值为0）。
- 如果在“命令输入区”输入命令后再输入各参数，“OPC值”出于安全原因，仅显示“\*”。
- 如果在“MML命令编辑区”直接输入带参数的命令，命令中的“OPC值”以明文显示。
- 当**SET MAPCONF**命令中的“是否启用随机密钥”参数为“TRUE”时，如果未执行**SET MAPSERV**命令设置“随机密钥默认ID”参数为系统已存在的随机密钥，则执行该命令时会返回错误：“已启用随机密钥功能，请先执行**SET RANDOMKEY**命令生成随机密钥”。

## 参数说明

| 参数标识     | 参数名称      | 参数说明                                                                                                                                                               |
|:---------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TPLID    | AKA鉴权模板ID | 用于定义AKA鉴权信息模板的序号，以方便对AKA鉴权信息模板进行查询和引用，配置原则是不能与已有的AKA鉴权信息模板的模板ID重复。 取值范围： 0～254 缺省值： 无                                                                              |
| TPLNAME  | AKA模板名称   | 该参数用于具体描述一个AKA鉴权信息模板，以便于识别。 取值范围： 长度不超过64的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 缺省值： 无                                                                                      |
| K4SNO    | K4索引号     | 用于指定AKA鉴权使用的K4的值，该参数必须先由ADD HK4操作定义，然后才能在此处索引。说明：如果K4SNO参数取值为0，表明K未被加密，否则，K是经过K4加密的值。 取值范围： 0～128 缺省值： 无                                                           |
| OPSNO    | OP索引号     | 用于指定AKA鉴权使用的OP的值，该参数必须先由ADD HOP操作定义，然后才能在此处索引。说明：如果OPSNO参数取值为0，OPC参数必须存在；如果OPSNO参数取值不为0，OPC参数不能存在。 取值范围： 0～128 缺省值： 无                                              |
| AMFSNO   | AMF索引号    | 用于指定AKA鉴权使用的AMF的值，该参数必须先由ADD HAMF操作定义，然后才能在此处索引。 取值范围： 1～128 缺省值： 无                                                                                                |
| OPC      | OPC值      | 用于定义鉴权数据OPC的值，要求输入16进制字符，字母不区分大小写。说明：当OPC取值全零时为无效值，禁止输入。 取值范围： 长度等于32的16进制字符串 缺省值： 无                                                                               |
| OPCK4SNO | OPC K4索引号 | 用于指定AKA鉴权中对OPC进行解密时使用的K4的值，该参数必须先由ADD HK4操作定义，然后才能在此处索引。说明： 如果OPCK4SNO取值为0， 表明OPC未被加密；否则， 表明OPC是经OPCK4加密过的； OPC和OPCK4SNO条件可选，如果设置了其中一个，另一个必须设置。 取值范围： 0～128 缺省值： 无 |
| COMMENT  | 模板注释说明    | 该参数用于具体描述一个AKA鉴权信息模板的注释信息，以便于理解和使用。 取值范围： 长度不超过512的字符串 缺省值： 无                                                                                                      |

## 使用实例

增加AKA鉴权信息模板。AKA鉴权模板ID：10，AKA模板名称：AKA Template，K4索引号：1，OP索引号：1，AMF索引号：1，模板注释说明：AKA Template For ADD HKI。

```
ADD HAKATPL: TPLID=10, TPLNAME="AKA Template", K4SNO=1, OPSNO=1, AMFSNO=1, COMMENT="AKA Template For ADD HKI";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 900003515 | 已启用随机密钥功能，请先执行SET RANDOMKEY命令生成随机密钥。 | 已启用随机密钥功能，但SET MAPSERV命令中的“随机密钥默认ID”参数为0。                     | 根据实际情况，执行SET RANDOMKEY命令生成随机密钥，并设置SET MAPSERV命令中的“随机密钥默认ID”参数为系统已存在的随机密钥。 |
| 900003523 | 密钥丢失                                 | 当SET MAPSERV命令中的“随机密钥默认ID”参数为非0，“随机密钥默认ID”参数对应的随机密钥材料不存在或不完整。 | 联系华为技术支持处理。                                                               |
