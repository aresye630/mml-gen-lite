## 命令功能

该命令用于签约一条SMSF数据。

该命令的使用场景：5G物联网终端不依赖IP网络，可以通过NAS信令发送短消息，节省网络资源，即SMSF通过N21接口向UDM注册和去注册，读取和订阅SMSF管理的用户签约数据。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”参数同时配置。
- “用户个数”必须与“IMSI”或“MSISDN”参数中的一个同时存在。
- 该命令必须在用户已经开通5G SA业务，且存在SMSF签约数据时使用，如果未签约SMSF数据，可通过**MOD AMDATA**，**ADD NGSUSERTPL**命令签约SMSF数据。
- 首次签约SMSF数据时：
  - “SMSF号码”参数和“SMSF主机名”与“SMSF域名”参数对至少出现一个。
  - “SMSF实例ID”和“PLMNID”参数必须输入。
- 修改SMSF签约数据时：
  - “SMSF主机名”与“SMSF域名”参数对为空时，参数对必须同时输入，或者都不输入。
  - “SMSF主机名”与“SMSF域名”参数对不为空时，可以修改单独的一个参数，或者同时修改，但不能把其中一个修改为空。

## 使用实例

1. 增加一条SMSF签约信息记录，其中：
   - “IMSI”为“460000009123456”
   - “SMSF实例ID”为“3a80e8fa-80a4-4d21-8cde-9567a8”
   - “SMSF支持能力”为“ffdde”
   - “PLMNID”为“123456”
   - “SMSF号码”为“123453”

   ```
   MOD SMSFINFO: IMSI="460000009123456", SMSFINSTANCEID="3a80e8fa-80a4-4d21-8cde-9567a8", SUPPORTEDFEATURES="ffdde", PLMNID="123456", SMSFNUMBER="123453";
   ```
2. 为3个连续用户增加一条SMSF签约信息记录，其中：
   - “IMSI”为“460000009123456”、“460000009123457”、“460000009123458”
   - “SMSF实例ID”为“3a80e8fa-80a4-4d21-8cde-9567a8”
   - “SMSF支持能力”为“ffdde”
   - “PLMNID”为“123456”
   - “SMSF号码”为“123453”

   ```
   MOD SMSFINFO: IMSI="460000009123456", RECORDCOUNT=3, SMSFINSTANCEID="3a80e8fa-80a4-4d21-8cde-9567a8", SUPPORTEDFEATURES="ffdde", PLMNID="123456", SMSFNUMBER="123453";
   ```

## 参考信息

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1 
IMSI2 
IMSI3 
IMSI4 
…… 
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1 
MSISDN2 
MSISDN3 
MSISDN4 
…… 
MSISDNn
```

MSISDNn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
