# 修改远端用户数据(MOD RMPY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

操作员通过此命令为GSM用户或者虚拟号码签约/去签约FM业务的远端用户，并可以增加/修改/删除相关的远端用户参数。

## 注意事项

- RMNUM、FILE是条件可选参数，任何一个参数出现即可，但不能同时出现。
- RECORDCOUNT一定不能与FILE同时存在。
- 远端用户最多可以添加255个潜在初始用户和255个管理者。
- 如果远端号码签约了COR，则需要进行COR验证。修改远端号码的COR不影响当前远端号码和初始号码的绑定关系。
- 去签约远端用户的FM业务时，如果远端号码和初始号码已经建立绑定，则需去绑定。

## 参数说明

| 参数标识        | 参数名称            | 参数说明                                                                                                                                                                                                                                                                                                                                                                                          |
|:------------|:----------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号          | HLR序列号，有效值域为1～255，在PGW支持容灾功能或虚拟HLR功能时设置。                                                                                                                                                                                                                                                                                                                                                      |
| RMNUM       | 远端号码            | 远端用户号码，E.164格式的编码。 当SET MAPCONF命令中“是否支持远端号码里包含字母”标志位为缺省值“FALSE”时，远端号码为1～15位的十进制数字。 当SET MAPCONF命令中是否支持远端号码中包含字母标志位为“TRUE”时，远端号码为中国GSM-R网络用户号码： 不以2开头时，为1～15位的十进制数字。以2开头时，为可以包含字母和数字的4～10位字符。 说明：远端号码要携带国家码前缀且该前缀必须与SET INTROFF命令配置的国家码一致。                                                                                                                                                     |
| RECORDCOUNT | 用户个数            | 用户的数目，最大100000个。 若只有一个远端号码，该参数不必提供。 若该参数提供，代表对以指定的远端号码为起始号码，号码连续的RECORDCOUNT个远端号码进行操作。 此参数必须与RMNUM同时出现。                                                                                                                                                                                                                                                                                       |
| FILE        | 远端号码文件名         | 远端号码文件名称，由1～16个字母或数字组成。FILE包含多个不连续的远端用户号码。                                                                                                                                                                                                                                                                                                                                                    |
| PROV        | 是否提供FM业务的远端用户签约 | 提供/修改还是撤销FM远端用户签约。 TRUE:提供或修改 FALSE:撤销                                                                                                                                                                                                                                                                                                                                                        |
| FUNCDESC    | 功能描述            | 仅当本命令中的“是否提供FM业务的远端用户签约”参数为“TRUE”时该参数有效。远端用户的功能描述。可选参数。由1～60个字母或数字组成。                                                                                                                                                                                                                                                                                                                         |
| CORSET      | COR集合           | 仅当本命令中的“是否提供FM业务的远端用户签约”参数为“TRUE”时该参数有效。提供/修改或者删除用户的COR的集合，此参数可选。 值域： COR_1、COR_2、COR_3...COR_254、Delete_COR。 说明： 最多可以选择5个COR（不包括Delete COR），也可以不签约任何COR。签约的COR必须是HLR已定义的。签约多个COR时，各COR之间用“&”连接。 不选择Delete COR，表示提供或修改用户的COR(若修改，则以修改后的COR为准)。 选择Delete COR和其他具体的COR，表示要删除所选择的COR。比如：选择Delete COR和COR_1，表示要删除用户角色中的COR_1。 如果只选择Delete COR，表示要删除用户的所有COR。 如果用户没有对COR进行设置，表示不修改COR，而不是删除全部的COR。 |
| FFNADDRESS  | FFN的地址          | 仅当本命令中的“是否提供FM业务的远端用户签约”参数为“TRUE”时该参数有效。Follow ME功能节点地址，E.164格式的编码。可选参数。 说明： 新增远端号码时，如果FFN的地址不设置，表示FM功能节点由本HLR实现，不允许修改时再设置FFN的地址。 修改远端号码时，如果FFN的地址不设置，表示FFN地址不修改。 如果给一个远端用户设置了FFNADDRESS，则FFNADDRESS不能删，只能修改。                                                                                                                                                                                 |

## 使用实例

为RMNUM号码为8613900001234的用户提供FM远端用户签约，其功能描述为funcdesc，远端用户的角色范围为COR\_2&COR\_4&COR\_20&COR\_22，FFN的地址为8613911111234。

```
MOD RMPY: HLRSN=1, RMNUM="8613900001234", PROV=TRUE, FUNCDESC="funcdesc", CORSET=COR_2&COR_4&COR_20&COR_22, FFNADDRESS="8613911111234";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                  | 处理建议                                                       |
|:--------|:--------|:----------------------|:-----------------------------------------------------------|
| ERR3114 | COR未定义  | 输入的“COR集合”参数中的COR未定义。 | 根据实际情况，重新输入“COR集合”参数，确保参数中的COR已定义，可通过LST COR命令查询已定义的COR数据。 |
