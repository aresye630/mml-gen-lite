# 删除本网携出用户(RMV NPDONORSUB)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用于删除携出用户数据。

此操作支持批处理。

## 注意事项

- IMSI、ISDN、IMSIFILE、ISDNFILE是条件可选参数，任何一个参数出现即可。
- RECORDCOUNT一定不能与IMSIFILE或ISDNFILE同时存在。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                           |
|:------------|:----------|:-------------------------------------------------------------------------------|
| IMSI        | IMSI      | IMSI号码，E.212格式的编码，为6～15位的十进制数字。                                                |
| ISDN        | MSISDN    | MSISDN号码，E.164格式的编码，为1～15位的十进制数字。                                              |
| RECORDCOUNT | 用户个数      | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的MSISDN为起始号码，号码连续的RECORDCOUNT个用户。 |
| ISDNFILE    | MSISDN文件名 | ISDN文件名称，1～16个字母或数字组成。ISDNFILE包含多个不连续的MSISDN号码。                                |
| IMSIFILE    | IMSI文件名   | IMSI文件名称，1～16位的数字或字符组成的字符串，不可包括路径名称。 IMSIFILE的内容由不连续的IMSI号码组成。 说明：可选参数。        |

## 使用实例

删除单个携出用户。

将MSISDN号码为86138075003001的携出用户数据删除。命令如下：

```
RMV NPDONORSUB: ISDN="86138075003001";
```
