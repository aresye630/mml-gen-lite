# 查询对应网络漫游用户数(LST ROAMNUM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询和刷新对应网络漫游用户数：

- 若需要查询某组运营商对应网络漫游用户数，请输入“HLR序列号”和“分组ID”参数。
- 若需要查询某个运营商对应网络漫游用户数，请输入“HLR序列号”和“运营商名称”参数。
- 若需要刷新某个运营商对应网络漫游用户数，请输入“HLR序列号”、“运营商名称”和“刷新标志”参数。

## 注意事项

- “分组ID”和“运营商名称”两个参数只能同时输入其中一个。
- “分组ID”和“刷新标志”两个参数只能同时输入其中一个。
- 该命令刷新运营商网络下漫游用户数时使用了DSU数据统计，所以只能在话务量低时使用该命令，并且不得连续执行。
- 查询CS域、PS域、EPS域网络漫游用户数刷新统计结果时，需要将“刷新标志”设置为“TRUE”。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                               |
|:--------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN   | HLR序列号 | 用于标识本地HLR。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1～255 默认值：无。                                                                                                        |
| GRPID   | 分组ID   | 用于标识一个运营商所属的分组ID。 取值范围：1～999 默认值：无。                                                                                                                                |
| OPRNAME | 运营商名称  | 用于标识运营商网络中的运营商名称。 取值范围：1～60位由字母、数字和特殊字符组成的字符串。 默认值：无。                                                                                                              |
| REFRESH | 刷新标志   | 用于标识运营商网络中是否刷新统计结果标志。 取值范围： TRUE：刷新统计结果。FALSE：不刷新统计结果。 默认值：FALSE 说明：当执行SET ROAMPER命令调整运营商名称或漫游比例后会导致实际漫游用户数的统计结果在一段时间内不一致，如果该参数取值为“FALSE”，则有可能导致查询出来的结果和实际统计结果不一致。 |
| REGION  | 分域刷新标志 | 仅当参数“刷新标志”为“TRUE”时该参数有效，用于标识运营商网络中刷新统计结果分域标志。 取值范围： CS：刷新CS域统计结果。PS：刷新PS域统计结果。EPS：刷新EPS域统计结果。 默认值：CS                                                               |

## 使用实例

1. 查询对应网络漫游用户数，“HLR序列号”为“1”，“分组ID”为“1”：

   ```
   LST ROAMNUM: HLRSN=1, GRPID=1;
   ```

   ```
   %%LST ROAMNUM: HLRSN=1, GRPID=1;%%
   RETCODE = 0 SUCCESS0001:操作成功

   	HLRSN = 1
   	GRPID = 1

   	OPRID = 1
   	OPRNAME = OPR1
   	CSROAMSUBNUM = 0
   	PSROAMSUBNUM = 0
          EPSROAMSUBNUM = 0

   	OPRID = 2
   	OPRNAME = OPR2
   	CSROAMSUBNUM = 0
   	PSROAMSUBNUM = 0
          EPSROAMSUBNUM = 0

   (结果个数 = 12)

   -    END
   ```
2. 查询对应网络漫游用户数，“HLR序列号”为“1”，“运营商名称”为“OPR1”：

   ```
   LST ROAMNUM: HLRSN=1, OPRNAME="OPR1";
   ```

   ```
   %%LST ROAMNUM: HLRSN=1, OPRNAME="OPR1";%%
   RETCODE = 0 SUCCESS0001:操作成功

   	HLRSN = 1
   	GRPID = 1

   	OPRID = 1
   	OPRNAME = OPR1
   	CSROAMSUBNUM = 0
   	PSROAMSUBNUM = 0
          EPSROAMSUBNUM = 0

   (结果个数 = 7)

   -    END
   ```
3. 查询对应网络漫游用户数，“HLR序列号”为“1”，“运营商名称”为“OPR1”，“刷新标志”为“TRUE”，“分域刷新标志”为“CS”：

   ```
   LST ROAMNUM: HLRSN=1, OPRNAME="OPR1", REFRESH=TRUE, REGION=CS;
   ```

   ```
   %%LST ROAMNUM: HLRSN=1, OPRNAME="OPR1", REFRESH=TRUE, REGION=CS;%%
   RETCODE = 0 SUCCESS0001:操作成功

   	HLRSN = 1
   	GRPID = 1

   	OPRID = 1
   	OPRNAME = OPR1
   	CSROAMSUBNUM = 0

   (结果个数 = 5)

   -    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数请参见本命令的参数说明。表1列出的是未包含在本命令参数说明中的输出项。

| 输出项名称         | 输出项解释                |
|:--------------|:---------------------|
| CSROAMSUBNUM  | 用于返回查询对应网络CS域漫游用户数。  |
| PSROAMSUBNUM  | 用于返回查询对应网络PS域漫游用户数。  |
| EPSROAMSUBNUM | 用于返回查询对应网络EPS域漫游用户数。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

| 错误码     | 错误码解释     | 原因分析                                                | 处理建议                                                                             |
|:--------|:----------|:----------------------------------------------------|:---------------------------------------------------------------------------------|
| ERR3097 | HLR序列号未定义 | 参数“HLR序列号”输入错误，实际输入的参数“HLR序列号”未定义。                  | 根据实际情况，重新输入参数“HLR序列号”的取值，确保其取值已被定义。已定义的“HLR序列号”可通过LST HLRSN命令查询。                 |
| ERR1010 | 参数冲突      | 可能原因为如下之一：同时输入参数“分组ID”和“运营商名称”。同时输入参数“分组ID”和“刷新标志”。 | 根据实际情况，重新输入参数，确保满足以下两点：“分组ID”和“运营商名称”两个参数只能同时输入其中一个。“分组ID”和“刷新标志”两个参数只能同时输入其中一个。 |
