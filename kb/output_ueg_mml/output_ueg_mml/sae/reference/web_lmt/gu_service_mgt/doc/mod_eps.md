## 命令功能

该命令用于为用户提供、撤销或修改EPS（Evolved Packet System）业务数据。当GSM/UMTS用户需要改造为GSM/UMTS/EPS融合用户、GSM/UMTS用户需要改造为VoLTE用户时，可以执行该命令为用户提供EPS业务数据。具体的业务配置流程可参考产品手册中《用户管理》手册。

- 对于在网用户执行该命令后：
  - 如果是给用户签约该业务，则UDM会向MME/S4-SGSN/3GPP AAA下发插入用户数据消息（Insert Subscriber Data）。
  - 如果是给用户去签约该业务，则UDM会向MME/S4-SGSN/3GPP AAA下发删除用户数据消息（Delete Subscriber Data）。
- 对于不在网用户执行该命令只更新数据库，当用户进行位置更新时UDM将用户的EPS业务数据下发给对端设备。

执行以下命令也可以为用户提供、撤销或修改EPS业务数据。

- **ADD SUB**/**ADD TPLSUB**/**ADD TPLUSCSUB**

  开户时直接为用户提供EPS业务数据。
- STNSR地址管理/UE级别APN运营商标识管理/UE级别EPS用户AMBR管理/无线频率选择优先级管理/EPS用户EGR业务管理

  通过执行这五组命令可以为用户修改EPS业务相关数据。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。
- “周期RA/TA更新时间间隔”和“周期RAU/TAU更新时间间隔”两个参数不能同时签约，如果用户先签约了其中一个参数，再签约另一个参数时会强制修改第一个签约的参数值为“0”。
- 软参“NPSWITCH（NP 开关）”取值为“0”或“2”时，执行**MOD EPS**命令，若用户不存在，则返回错误码ERR3001；软参“NPSWITCH（NP 开关）”取值为“1”时，执行**MOD EPS**命令，若用户不存在，则返回错误码ERR3810。

## 使用实例

1. 给IMSI号码为“460000009123456”的用户提供EPS业务数据，“是否提供EPS业务”为“TRUE”，“UE最大上行带宽”为“500000”，“UE最大下行带宽”为“100000”：

   ```
   MOD EPS: IMSI="460000009123456", PROV=TRUE, AMBRMAXUL=500000, AMBRMAXDL=100000;
   ```
2. 给3个连续号码的用户提供EPS业务数据，这3个MSISDN号码分别为“13310911001”、“13310911002”、“13310911003”，“是否提供EPS业务”为“TRUE”，“UE最大上行带宽”为“500000”，“UE最大下行带宽”为“100000”：

   ```
   MOD EPS: ISDN="13310911001", RECORDCOUNT=3, PROV=TRUE, AMBRMAXUL=500000, AMBRMAXDL=100000;
   ```
3. 给3个非连续号码的用户撤销EPS业务数据，这3个MSISDN号码分别为“13310911001”、“13310911003”、“13310911005”，已保存在“MSISDN文件名”为“modeps.txt”的文件中，并通过文件管理功能上传到指定目录，“是否提供EPS业务”为“FALSE”：

   ```
   MOD EPS: ISDNFILE="modeps.txt", PROV=FALSE;
   ```
4. 给IMSI号码为“460001480000001”的用户提供EPS业务服务，“是否提供EPS业务”为“TRUE”，“是否支持WB模式PTW”为“TRUE”，“WB模式PTW”为“15”，“是否支持NB模式PTW”为“TRUE”，“NB模式PTW”为“15”：

   ```
   MOD EPS: IMSI="460001480000001", PROV=TRUE, SUPWBPTW=TRUE, WBPTW=15, SUPNBPTW=TRUE, NBPTW=15;
   ```
