# 删除私有密钥(RMV PRVTKEY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条私有密钥数据记录。

## 注意事项

只有没有被使用的私有密钥数据才可以删除。

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                        |
|:--------|:--------|:----------------------------------------------------------------------------|
| HLRSN   | HLR序列号  | 标识私有密钥数据记录的关键字段之一，用于指定删除哪个HLR上的私有密钥数据记录，操作员可以使用LST HLRSN命令查询获得。             |
| PKEYSNO | 私有密钥序列号 | 标识一条私有密钥数据记录的关键字段之一，用于标识需要删除哪一条私有密钥序列号对应的私有密钥数据记录，操作员可以使用LST PRVTKEY命令查询获得。 |

## 使用实例

删除私有密钥数据，“HLR序列号”为“6”，“私有密钥序列号”为“1”：

```
RMV PRVTKEY: HLRSN=6, PKEYSNO=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                               | 处理建议                                                   |
|:--------|:--------|:-----------------------------------|:-------------------------------------------------------|
| ERR3007 | 记录不存在   | HLR序列号和私有密钥序列号对应的私有密钥数据记录不存在或已被删除。 | 使用LST PRVTKEY命令查询后，重新确认要删除哪个HLR序列号和私有密钥序列号对应的私有密钥数据记录。 |
