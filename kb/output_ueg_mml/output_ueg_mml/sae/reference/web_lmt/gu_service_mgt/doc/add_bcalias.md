# 增加承载能力别名(ADD BCALIAS)

- 输出结果说明

## 命令功能

承载能力定义了一种承载业务的技术特征，它包含一系列的参数，如：Information Transfer Capability (ITC)、Signaling Access Protocols (SAP)和Synchronous/Asynchronous (SA)等。

每种承载业务都有相应的承载能力，以此来定义建立的呼叫的类型。通常一种承载业务可以应用多种承载能力，但每次呼叫只能应用一种承载能力。

## 注意事项

- 当STRUCT参数取值为SDUI时，CE必须为NON TRANSPARENT，当STRUCT参数取值为UNSTR时， CE必须为TRANSPARENT。
- 系统中增加的承载能力别名记录数不能超过1000条。

## 使用实例

为BS20业务增加承载能力。命令如下：

```
ADD BCALIAS: HLRSN=1, ALIASNAME="BC20", DSCODE=BS20, ITC=Unrestricted Digital Info, RA=V.110 I.460/X.30 Rate Adaption;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释        | 原因分析                       | 处理建议                                                                                                                    |
|:--------|:-------------|:---------------------------|:------------------------------------------------------------------------------------------------------------------------|
| ERR3010 | 承载能力与数据业务不匹配 | 参数“数据业务码”和“信息传输能力”输入内容不匹配。 | 根据实际情况，重新输入参数，确保输入的“数据业务码”和“信息传输能力”输入内容匹配。参数能力是否匹配，请参见承载业务管理。                                                           |
| ERR3047 | 超过最大限制       | 增加的承载能力别名记录数超过1000条。       | 根据实际情况，如需增加承载能力别名，处理步骤如下：执行LST BCALIAS命令，查询已存在的承载能力别名。执行RMV BCALIAS命令，删除不必要的承载能力别名。执行该命令增加承载能力别名，确保增加的承载能力别名记录数在规定范围之内。 |
