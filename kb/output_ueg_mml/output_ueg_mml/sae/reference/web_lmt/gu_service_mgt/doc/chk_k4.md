# 校验K4(CHK K4)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于校验K4密钥，以检查已添加的K4密钥是否正确。

## 注意事项

DES和3DES为业界已知的安全强度较弱的算法，应避免使用。建议直接使用AES128或AES256算法，其中AES256加密强度高于AES128。

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                                                                    |
|:--------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN   | HLR序列号  | HLR序列号，有效值域为1～255，在PGW支持容灾功能或虚拟HLR功能时设置。                                                                                                                                |
| K4SNO   | K4序列号   | K4序列号，值域为1～65535。                                                                                                                                                       |
| ALGTYPE | 算法类型    | 标识K4值的加密算法类型。 取值范围： DES：K4值为16位的十六进制数字组成的字符串。AES128：K4值为32位的十六进制数字组成的字符串。AES256：K4值为64位的十六进制数字组成的字符串。3DES：K4值为3个16位的十六进制数字组成的字符串。SM4：K4密文为32位的十六进制数字组成的字符串。 默认值：AES128。 |
| K4VALUE | K4值     | 仅当本命令中的“算法类型”参数为“DES”，“AES128”、“AES256”或“SM4”时该参数有效。K4密钥值，16位或32位、64位的十六进制数字组成的字符串。                                                                                     |
| K7SNO   | K7序列号   | 用于标识K7序列号。该参数必须先由ADD K7命令定义，然后才能在此处引用。 取值范围：1～10。 默认值：无。                                                                                                                |
| DESK1   | 3DES密钥1 | 仅当本命令中的“算法类型”参数为“3DES”时该参数有效。用于标识3DES算法中密钥一。 取值范围：16位的十六进制数字组成的字符串。 默认值：无。                                                                                              |
| DESK2   | 3DES密钥2 | 仅当本命令中的“算法类型”参数为“3DES”时该参数有效。用于标识3DES算法中密钥二。 取值范围：16位的十六进制数字组成的字符串。 默认值：无。                                                                                              |
| DESK3   | 3DES密钥3 | 仅当本命令中的“算法类型”参数为“3DES”时该参数有效。用于标识3DES算法中密钥三。 取值范围：16位的十六进制数字组成的字符串。 默认值：无。                                                                                              |

## 使用实例

校验K4，序列号为2，K4值为ABCDEF1234567890，算法类型为“AES128”。命令如下：

CHK K4: HLRSN=1, K4SNO=2, ALGTYPE=AES128, K4VALUE="\*\*\*\*\*";

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释              | 原因分析                                                                                      | 处理建议                                          |
|:--------|:-------------------|:------------------------------------------------------------------------------------------|:----------------------------------------------|
| ERR3098 | 验证的数据与HLR数据库的数据不相同 | 填写的K4值算法类型与HLR数据库保存的K4值算法类型不一致。填写的K4值算法类型与HLR数据库保存的K4值算法类型一致但经过算法加密后的K4值与HLR数据库保存的K4值不一致。 | 根据K4值的位数选择正确的算法类型。根据实际情况，重新输入正确的K4值。          |
| ERR4133 | 密钥丢失               | 当SET MAPSERV命令中的“随机密钥默认ID”参数为非0，“随机密钥默认ID”参数对应的随机密钥材料不存在或不完整。                             | 联系华为技术支持处理。                                   |
| ERR4195 | 不支持处理保存在HSM的记录     | 待校验的“K4序列号”为HSM类型。                                                                        | 在用户签约的K4记录中查询“K4密钥输入方式”，确保待校验的“K4序列号”不为HSM类型。 |
