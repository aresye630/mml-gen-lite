# 修改CAMEL漫游模板(MOD CAMELROAMTPL)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使引用此模板的OCSI模板或TCSI模板数据被同步修改，会影响在网用户业务体验，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改CAMEL漫游模板，通过该命令，可以添加或删除一条VLR号码前缀到CAMEL漫游模板里，使该VLR与UDM具有CAMEL漫游协议，或者修改模板名称。在该命令中，系统通过以下关键参数的组合来唯一标识一个CAMEL漫游模板：

- “HLR序列号”
- “模板ID”

## 注意事项

- 模板中必须保证至少有一条VLR号码前缀记录，如果该命令的“是否提供VLR数据”设置为“FALSE”，要删除模板中唯一一条VLR号码前缀记录，则无法删除。
- 因为当用户进行位置更新或触发其他涉及CAMEL漫游协议模板的流程时，系统会根据用户签约的CAMEL漫游协议模板ID下发模板中的数据，修改模板数据会使签约此模板的用户数据被同步修改，会影响在网用户，因此现网执行修改模板操作时需要慎重。
- 执行该命令修改CAMEL漫游模板信息数据，如果此模板已经被用户使用，请根据实际情况考虑是否需要针对这些用户执行**SND RESET**命令发送reset消息。模拟Reset消息通常在HLR割接时进行，使原来的用户找到新割接的HLR，在新HLR中存储用户的位置信息（VLR号码），以保证用户能够正常呼叫。
- 该命令不允许进行批操作。
- 系统中同一个CAMEL漫游模板增加的VLR号码前缀记录数不能超过3000条，且所有CAMEL漫游模板增加的VLR号码前缀总记录数不能超过15000条。

## 参数说明

| 参数标识        | 参数名称        | 参数说明                                                                                                                                                                                                            |
|:------------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号      | 标识CAMEL漫游协议模板信息数据的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR上的CAMEL漫游协议模板数据记录的参数进行修改或调整，操作员可以使用LST HLRSN命令查询获得。                                                                                                              |
| TPLID       | 模板ID        | 用于标识一个CAMEL漫游模板在系统中的序号。该参数在UDM中唯一，不能重复。 取值范围：0～65534 默认值：无。                                                                                                                                                     |
| TPLNAME     | 模板名         | 用于标识一个新的CAMEL漫游模板在系统中的名称。不同模板ID的模板名称允许相同。 取值范围：1～60个字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                      |
| PROV        | 是否提供VLR数据   | 用于标识该命令是增加还是删除一条VLR号码前缀到CAMEL漫游模板中。 TRUE： 增加一条VLR号码前缀FALSE：删除一条VLR号码前缀 默认值：无。                                                                                                                                   |
| VLRSGSNNP   | VLR号码前缀     | 仅当“是否提供VLR数据”取值为“TRUE”或“FALSE”时该参数存在。用于标识需要签约或去签约CAMEL漫游协议的VLR的号码前缀。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 说明：当CAMEL漫游模板用作T-CSI限制功能，且SET MAPSERV中的参数“TCSITPL里CAMELROAMTPL的使用场景”被设置为“TCSI_SUPPRESS”时，需输入整个VLR号码，而不是号码前缀。 |
| CAMEL       | CAMEL业务处理能力 | 仅当“是否提供VLR数据”取值为“TRUE”时该参数存在。用于指示添加的VLR的号码前缀对应的业务实体所要求的CAMEL业务阶段。CAMEL的4个阶段请参见CAMEL业务。 取值范围：PHASE1(1)PHASE2(2)PHASE3(3)PHASE4(4) 默认值：无。                                                                         |
| VLRSGSNNAME | VLR名称       | 仅当“是否提供VLR数据”取值为“TRUE”时该参数存在。用于标识需要签约CAMEL漫游协议的VLR在系统中的名称。不同VLR前缀允许相同的名称。 取值范围：1～16个字母或十进制数字组成的字符串。 默认值：无。                                                                                                      |

## 使用实例

1. 修改CAMEL漫游模板，新增一个VLR号码前缀，设置“参数HLR序列号”为“1”，“模板ID”为“3”，“模板名”为“CAMELROAMTPL”，“是否提供VLR数据”为“TRUE”，“VLR号码前缀”为“12345678912”，“CAMEL业务处理能力”为“PHASE1”，“VLR名称”为“VLR1”：

   ```
   MOD CAMELROAMTPL: HLRSN=1, TPLID=3, TPLNAME="CAMELROAMTPL", PROV=TRUE, VLRSGSNNP="12345678912", CAMEL=PHASE1, VLRSGSNNAME="VLR1";
   ```
2. 删除CAMEL漫游模板中的一个VLR号码前缀，设置“参数HLR序列号”为“1”，“模板ID”为“3”，“是否提供VLR数据”为“FALSE”，“VLR号码前缀”为“12345678912”：

   ```
   MOD CAMELROAMTPL: HLRSN=1, TPLID=3, TPLNAME="CAMELROAMTPL", PROV=FALSE, VLRSGSNNP="12345678912";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                       | 处理建议                                                                                                                |
|:--------|:--------|:-------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 参数“VLR号码前缀”的取值不是1～15位十进制数字组成的字符串。                                                          | 根据实际情况，重新输入参数“VLR号码前缀”的取值，确保其取值符合要求。                                                                                |
| ERR3003 | 模板未定义   | 可能原因为如下之一：参数“HLR序列号”和“模板ID”对应的模板数据记录不存在。参数“是否提供VLR数据”设置为“FALSE”时，参数“VLR号码前缀”的取值在对应的模板中不存在。 | 根据实际情况，重新输入参数，确保“HLR序列号”和“模板ID”参数对应的模板数据记录已存在。如要删除一条VLR号码前缀记录，确保其在对应的模板数据中已存在。已存在的模板数据记录可以通过LST CAMELROAMTPL命令查询。   |
| ERR3004 | 模板已存在   | 参数“是否提供VLR数据”设置为“TRUE”时，参数“VLR号码前缀”的取值在对应的模板中已存在，不能重复添加。                                   | 根据实际情况，重新输入参数，确保“VLR号码前缀”参数对应的记录在“HLR序列号”和“模板ID”参数对应的模板中不存在。已存在的模板数据记录可以通过LST CAMELROAMTPL命令查询。                     |
| ERR3007 | 记录不存在   | “HLR序列号”和“模板ID”对应的CAMEL漫游协议模板数据记录不存在。                                                      | 使用LST CAMELROAMTPL命令查询后，重新确认要修改哪个“HLR序列号”和“模板ID”对应的CAMEL漫游协议模板数据记录。                                                 |
| ERR3047 | 超过最大限制  | 可能原因为如下之一：同一个“模板ID”增加的“VLR号码前缀”数据记录数超过3000条。所有CAMEL漫游模板增加的“VLR号码前缀”总记录数超过15000条。           | 根据实际情况，如需增加VLR号码前缀，处理步骤如下：执行LST CAMELROAMTPL命令，查询已存在的VLR号码前缀。执行该命令删除不必要的VLR号码前缀。执行该命令增加VLR号码前缀，确保增加的VLR号码前缀在规定范围之内。 |
| ERR3096 | 模板不能为空  | 参数“是否提供VLR数据”设置为“FALSE”时，参数“VLR号码前缀”的取值是模板中唯一的一条记录。                                        | 不允许删除模板中唯一的一条VLR号码前缀记录。                                                                                             |
