# 设置缺省前转通知主叫方属性(SET DEFNCS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于设置缺省前转通知主叫用户的属性。通过设置缺省前转通知主叫用户属性，当某前转号码是未定义通知主叫用户属性的前转号码且呼叫前转到该号码时，运营商可以决定是否通知主叫用户。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称          | 参数说明                                                                                       |
|:-------|:--------------|:-------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号        | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                               |
| DEFNCS | 发生前转时是否通知主叫用户 | 用于标识发生缺省前转时是否通知主叫用户。 取值范围： NOTNOTIFY：不通知 NOTIFY：通知 USERDEFINE：按运营商要求配置的签约属性 默认值：USERDEFINE |

## 使用实例

运营商通过PGW Web LMT，在“HLR序列号”为“1”的HLR上，实现前转放音抑制功能，即当发生缺省前转时，不通知主叫用户。

执行**SET DEFNCS**命令设置缺省前转通知主叫用户的属性：

```
SET DEFNCS: HLRSN=1, DEFNCS=NOTNOTIFY;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                         | 处理建议                                                           |
|:--------|:--------|:-----------------------------|:---------------------------------------------------------------|
| ERR3006 | 记录已存在   | 重复为同一个HLR序列号设置缺省前转通知主叫用户的属性。 | 该HLR序列号已添加，根据实际情况确认是否需要设置其他HLR序列号缺省前转通知主叫用户的属性。                |
| ERR3007 | 记录不存在   | HLR序列号未定义。                   | 如果HLR序列号未定义，则执行ADD HLRSN命令先定义该HLR序列号，再为该HLR序列号设置缺省前转通知主叫用户的属性。 |
