# 查询O-CSI数据模板(LST HOCSITPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询一条O-CSI(Originating CAMEL Subscription Information)模板数据记录，该数据记录用O-CSI数据模板ID来唯一标识，一次只能查询一条O-CSI模板的数据记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                    |
|:-------|:----------|:------------------------------------------------------------------------|
| TPLID  | O-CSI模板ID | 可选必选说明：必选参数 参数含义：用于指示系统需要按照哪个模板ID来查询一条O-CSI数据模板数据记录。 取值范围： 0～254 默认值： 无 |

## 使用实例

查询O-CSI数据模板。O-CSI模板ID：10。

```
LST HOCSITPL: TPLID=10;
```

## 输出结果说明

| 参数标识       | 参数说明                |
|:-----------|:--------------------|
| TPLNAME    | 显示O-CSI模板名称。        |
| GSMSCFADDR | 显示O-CSI模板的gsmSCF地址。 |
| SK         | 显示O-CSI模板的业务键。      |
| DEFCALL    | 显示O-CSI模板的缺省呼叫处理。   |
| IMSSF      | 显示O-CSI模板的IM-SSF地址。 |
| COMMENT    | 显示O-CSI模板的模板注释说明。   |
