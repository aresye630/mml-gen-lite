# 删除IMSI与云分区数据(RMV IMSIPID)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此命令用于删除某一IMSI号段与云分区的映射关系。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                      |
|:---------|:-------|:----------------------------------------------------------|
| IMSIPRFX | IMSI前缀 | 与云分区建立映射关系的IMSI号段。 取值范围：1～15位的十进制数字组成的字符串。 缺省值：无 说明：必选参数。 |

## 使用实例

删除IMSI号段为460123的相关数据，命令如下：

```
RMV IMSIPID: IMSIPRFX="460123";
```
