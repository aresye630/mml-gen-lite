# 增加LCS模板(ADD LCSTPL)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

该命令用于在配置数据库中增加一条LCS（Location Services）模板数据记录。

## 注意事项

- 执行该命令只能给一个模板增加一条PE（Privacy Exception） List数据和三条MO-LR list数据。如果需要增加多条PE List数据和MO-LR list数据，请执行**MOD LCSTPL**命令。
- “LCS client1的地址”～“LCS client5的地址”五个参数必须按顺序配置，先配置前一个，再配置后一个。
- “Molr1的补充业务码”、“Molr2的补充业务码”和“Molr3的补充业务码”必须按顺序设置。如果“Molr1的补充业务码”没有配置，其它两个一定不能配置。如果“Molr1的补充业务码”配置为“ALLMOLR-SS”，那么“Molr2的补充业务码”和“Molr3的补充业务码”不需要再进行配置。
- 同一个“HLR序列号”中增加的LCS模板记录数不能超过2000条。

## 使用实例

1. 在“HLR序列号”为“1”的HLR上增加一条LCS模板数据记录，增加一条业务码为PLMNOPERATOR的PE list数据。其中，“模板ID”为“2”，“模板名”为“LCS1”，“GMLC1地址”为“345678912”，“GMLC2地址”为“345678934”，“本地优先标志”为“MSC”，“Privacy Class的补充业务码”为“Plmnoperator”，“LCS client的类别”为“BROADCAST”：

   ```
   ADD LCSTPL: HLRSN=1, TPLID=2, TPLNAME="LCS1", GMLC1="345678912", GMLC2="345678934", PLF=MSC, PECODE=Plmnoperator, PLMNCL=BROADCAST;
   ```
2. 在“HLR序列号”为“1”的HLR上增加一条LCS模板数据记录，增加一条业务码为CALLRELATED的PE list数据和两条MO-LR list数据。其中，“模板ID”为“5”，“模板名”为“huawei”，“本地优先标志”为“MSC”，“Privacy Class的补充业务码”为“Callrelated”，“是否通知用户”为“NotifyLocationAllowed”，“LCS client1的地址”为“8613800001111”，“GMLC的区域限制”为“Gmlc\_List”，“是否通知用户”为“NotifyAndVerify-LocationAllowedifNoResponse”，“Molr1的补充业务码”为“BasicSelfLocation”，“Molr2的补充业务码”为“AutonomousSelfLocation”：

   ```
   ADD LCSTPL: HLRSN=1, TPLID=5, TPLNAME="huawei", PLF=MSC, PECODE=Callrelated, NTMU=NotifyLocationAllowed, EC1EA="8613800001111", EC1GR=Gmlc_List, EC1NTMU=NotifyAndVerify-LocationAllowedifNoResponse, MOLR1=BasicSelfLocation, MOLR2=AutonomousSelfLocation;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。
