# 模板修改用户数据（MOD TPLSUB）

- 命令功能
- 注意事项
- 参数说明

## 命令功能

**说明** 

该命令为运营商定制功能，如需使用请联系华为技术支持获取相关约束后再启用该功能。

该命令用于对一个或多个用户采用模板修改用户签约的业务。为具有同样业务类型的用户修改签约数据时使用。

使用该命令修改用户已签约的业务，即设置“EPS业务标识”参数时，会影响待修改域的业务数据，取值为“TRUE”时：

- 初始化**MOD LCK**命令的“是否提供EPS锁业务”、“是否提供NON3GPP锁业务”参数值。
- PLMN区域漫游限制、Diameter漫游限制等业务数据，使用本命令模板中配置的数据为用户重新签约。

## 注意事项

- 以下参数设置不满足要求，上报系统不支持该特性：
  - **SET MAPCONF**命令的“是否支持通过模板修改用户签约数据”参数设置为“TRUE”。
  - **SET MAPSERV**命令的“GPRS管理方式”参数设置为“SuppGprsManageOptimizeon”。
  - **SET MAPSERV**命令的“GPRS数据索引化压缩存储”参数设置为“NotSupport”。
  - **SET MAPCONF**命令的“是否支持一卡多号多profile业务”参数设置为“FALSE”。
  - **SET MAPCONF**命令的“是否支持LINKED SIM业务”参数设置为“FALSE”。
  - **SET MAPCONF**命令的“是否支持GPRS调整方式管理过渡”参数设置为“FALSE”。
  - “EPS业务标识”取值为“FALSE”，用户的“APN类型”需要签约为“PS\_APN”、“EPS\_APN”。
  - “EPS业务标识”取值为“FALSE”，修改用户业务的模板中“APN类型”需设置为“PS\_APN”、“EPS\_APN”。
  - 修改用户签约数据的模板不能携带“GPRS模板ID”、“PSUSERTPL模板ID”参数。
- 多MSISDN业务，MIMSI业务，多卡多号（MIMM）场景下只允许修改主卡、主号，输入附卡，附号报系统不支持该特性。
- 用户签约了FM（Follow Me）业务，执行该命令时报系统不支持该特性。
- MIMSI业务，多卡多号（MIMM）场景下修改“UE应用类型”，输入主IMSI号码，修改对应IMSI的“UE应用类型”；输入MSISDN号码，修改所有卡的“UE应用类型”。
- **SET MAPCONF**设置了不支持ALS辅号码与主号码同时签约补充业务，即“是否支持ALS辅号码补充业务特殊处理”设置为“TRUE”并且“是否支持ALS特殊方案”设置为“FALSE”时，ALS双线路可选业务只支持修改主号业务。
- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”参数只能配置一个。
- “用户个数”、“IMSI文件名”、“MSISDN文件名”参数只能配置一个。
- 一号多卡业务（又称多IMSI业务或者MIMSI业务）签约“是否提供IMEI绑定业务”：
  - 输入主“IMSI”号码执行该命令，只修改对应IMSI的“是否提供IMEI绑定业务”。
  - 输入“MSISDN”号码签约“是否提供IMEI绑定业务”，只为主卡签约“是否提供IMEI绑定业务”，辅卡是否提供“是否提供IMEI绑定业务”不受影响。
  - 输入“MSISDN”号码去签约“是否提供IMEI绑定业务”，会同时去签约主卡和辅卡的IMEI绑定业务。
- “EPS业务标识”参数设置的取值影响业务数据的修改范围：
  - 取值“TRUE”时，支持修改CS域/PS域/EPS域和NON3GPP业务数据，同时修改CS域/PS域/EPS域/NGS域共用的业务数据和EPS域/NGS域共用的业务数据。
  - 取值“FALSE”时，支持修改CS域/PS域业务数据，同时修改CS域/PS域/EPS域/NGS域共用的业务数据。

    **说明** 

    - CS域/PS域/EPS域/NGS域共用的业务数据：ODBROAM/ODBPOS/NAM/CN Restriction/全局计费/标准计费参数。
    - EPS域/NGS域共用数据：NR5GSNOTALLOWED和NGCNOTALLOWED。
- 通过本命令修改用户签约数据后，UDM通过**SET UDMSERV**命令中软参“DELAYCANCELTIMER”来控制下发CANCEL消息清除用户的动态数据：
  - CS域下发MAP\_CANCEL\_LOCATION消息，是否清除动态数据由**SET MAPCONF**命令“是否保留CS域动态数据”参数设置的取值决定。
  - PS域下发MAP\_CANCEL\_LOCATION消息清除动态数据。
  - EPS域下发CLR消息和RTR消息清除动态数据。
  - NGS域向AMF发送去注册消息。
  - 可通过**SET UDMSERV**命令中软参“DELAYCANCELSPEED”来控制延迟CANCEL消息的发送速度。
- 用户签约了“CS与VoLTE补充业务数据一致性”业务，UDM向AS发送PNR消息通知透明数据变更。
- 如果“模板ID”引用的SUBTPL模板携带“EPSUSERTPL模板ID”参数，则SUBTPL模板必须同时配置以下参数，未配置则删除用户的EPS签约数据。
  - “UE最大上行带宽”和“NR上行速率”两个参数必须且只能配置一个。
  - “UE最大下行带宽”和“NR下行速率”两个参数必须且只能配置一个。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                      |
|:------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 用于标识需要修改签约数据的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                     |
| ISDN        | MSISDN    | 用于标识需要修改签约数据的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                   |
| RECORDCOUNT | 用户个数      | 用于标识需要修改签约数据的用户数目。当需要修改连续号码的多个用户的签约数据时配置。系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行修改。 取值范围：1～10000 默认值：无。 说明：该参数为可选参数，是对连续号码的多个用户进行签约数据修改，当只有一个用户时，该参数不必配置。 当一次修改签约数据的用户个数很多时，对系统性能无影响，但修改签约数据的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名   | 用于标识需要修改签约数据的用户的IMSI批操作文件。 IMSI批操作文件包含多个不连续待修改签约数据的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modsub.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                   |
| ISDNFILE    | MSISDN文件名 | 用于标识需要修改签约数据的用户的MSISDN批操作文件。 MSISDN批操作文件包含多个不连续待修改签约数据的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modsub.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                             |
| TPLID       | 模板ID      | 用于标识修改用户签约数据的模板ID。该模板需要通过命令ADD SUBTPL定义，才能在此处索引。 取值范围：0～65534 默认值：无。                                                                                                                                                      |
| EPS         | EPS业务标识   | 用于标识是否修改EPS域业务的签约数据。 取值范围： TRUE：修改CS域/PS域/EPS域和NON3GPP业务数据，同时修改CS域/PS域/EPS域/NGS域共用的业务数据和EPS域/NGS域共用的业务数据。FALSE：修改CS域/PS域业务数据，同时修改CS域/PS域/EPS域/NGS域共用的业务数据。 默认值：FALSE。                                                     |

## 使用实例

1. 为“IMSI”为“460000009123456”的用户使用模板修改签约数据，“模板ID”为“2”，命令如下:

   ```
   MOD TPLSUB: IMSI="460000009123456", TPLID=2;
   ```
2. 批量为“IMSI”号码分别为“460000009012346”、“460000009012347”、“460000009012348”的连续3个用户使用模板修改签约数据，“模板ID”为“2”，“EPS业务标识”为“TRUE”，命令如下：

   ```
   MOD TPLSUB: IMSI="460000009012346", RECORDCOUNT=3, TPLID=2, EPS=TRUE;
   ```
