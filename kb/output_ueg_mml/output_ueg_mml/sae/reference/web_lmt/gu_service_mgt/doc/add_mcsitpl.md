# 增加M-CSI模板(ADD MCSITPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于为HLR在配置数据库中增加一条M-CSI（Mobility Management CAMEL Subscription Information）模板数据记录，根据运营商CAMEL网络的实际情况进行配置，相关参数由运营商提供。用户通过签约M-CSI模板ID签约M-CSI业务。

M-CSI是CAMEL PHASE 3中的一个CAMEL签约项，用来通知CSE（CAMEL Service Environment）关于移动性管理的事件。M-CSI数据包括通知原则、业务键和gsmSCF（GSM Service Control Function）地址。

## 注意事项

- “用户在同一个VLR内进行位置登记”、“用户在不同VLR间进行位置登记”、“IMSI附着”、“MS发起的IMSI分离”、“网络发起的IMSI分离”参数为5种通知原则，至少需要设置一个参数取值为TRUE。
- 同一个“HLR序列号”中增加的M-CSI模板记录数不能超过5000条。

## 参数说明

| 参数标识           | 参数名称             | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|:---------------|:-----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN          | HLR序列号           | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| TPLID          | 模板ID             | 用于标识待增加模板在系统中的序号。 取值范围：0～65534 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| TPLNAME        | 模板名              | 用于标识待增加模板在系统中的名称。 取值范围：1～60位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| LUSVLR         | 用户在同一个VLR内进行位置登记 | 用于标识用户在同一个VLR内进行位置登记，是否通知gsmSCF。 取值范围：TRUE：通知FALSE：不通知 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| LUAVLR         | 用户在不同VLR间进行位置登记  | 用于标识用户在不同VLR间进行位置登记，是否通知gsmSCF。 取值范围：TRUE：通知FALSE：不通知 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| IMSIATT        | IMSI附着           | 用于标识IMSI附着（MS开机，网络发起的IMSI分离后位置更新成功），是否通知gsmSCF。 取值范围：TRUE：通知FALSE：不通知 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| MSIMSIDET      | MS 发起的IMSI分离     | 用于标识MS发起的IMSI分离（MS关机），是否通知gsmSCF。 取值范围：TRUE：通知FALSE：不通知 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| NWIMSIDET      | 网络发起的IMSI分离      | 用于标识网络发起的IMSI分离（周期性位置更新失败），是否通知gsmSCF。 取值范围：TRUE：通知FALSE：不通知 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| SK             | 业务键              | 用于标识用户在gsmSCF中签约的CAMEL业务。gsmSSF（GSM Service Switching Function）将业务键发给gsmSCF后，gsmSCF根据该业务键执行对应的业务逻辑。业务键是HLR与SCP的对接参数之一，用于在CAP/INAP消息中唯一标识一种智能业务，它是一种号码资源，需要由运营商向本国的电信主管部门申请获得。 取值范围：0～2147483647 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                     |
| GSMSCFADD      | SCP地址            | 用于标识接入gsmSCF功能实体的地址。 取值范围：1～15位十进制数字组成的字符串。 采用E.164编码方式，编码格式为：CC+NDC+LSP，例如，一个典型的“SCP地址”为：“86-139-00777”。各关键字段的含义是： CC（Country Code）：国家码，即SCP所处国家在国际PSTN编号计划中的国家码，它由ITU-T在全球范围内统一分配，其最大长度为3位。例如，中国的国家码为86、英国的国家码为44等。NDC（National Destination Code）：国内目的码，即移动业务接入码，它是由本国电信主管部门在本国范围内统一分配的PLMN网络号，其最大长度为3位。例如，某运营商使用的PLMN网络号为134～139。LSP（Locally Significant Part）：本地有效部分，它是由某个运营商在本PLMN网络运营范围内统一分配的、用于具体代表某个SCP的号码，其最大长度为9位。 默认值：无。                                                                                                                                                        |
| AVAILABLE_PLMN | M-CSI模板使用范围      | 用于标识当用户漫游在哪个地区时，UDM返回M-CSI模板的数据。 取值范围：HPLMN：当用户在HPLMN内漫游时，返回M-CSI。FPLMN：当用户在HPLMN外漫游时，返回M-CSI。INTERNATIONAL：当用户漫游出本国时，返回M-CSI。HPLMNC：当用户在本国漫游时，返回M-CSI。ALL_PLMN：当用户在任何网络漫游时，均返回M-CSI。NOT_AVAILABLE：当用户在任何网络漫游时，均不返回M-CSI。 M-CSI模板使用范围和VLR类型的对应关系如下：HPLMN对应VLR类型：LOCAL、LOCALDOMESTIC、LOCALINTERNATIONAL、LOCALAREA。FPLMN对应VLR类型：CROSSDOMESTIC、CROSSINTERNATIONAL、CROSSAREA。INTERNATIONAL对应VLR类型：LOCALINTERNATIONAL、CROSSINTERNATIONAL。HPLMNC对应VLR类型：LOCAL、LOCALDOMESTIC、CROSSDOMESTIC、LOCALAREA、CROSSAREA。ALL_PLMN对应VLR类型：ALL。 说明：VLR类型请参考ADD VLRTYP命令的“VLR号相对于本HLR所属的网络类型”参数。 默认值：ALL_PLMN。 |

## 使用实例

在“HLR序列号”为“1”的HLR上增加一条M-CSI模板数据记录。其中，“模板ID”为“3”，“模板名”为“MCSI1”，“用户在同一个VLR内进行位置登记”为“TRUE”，“用户在不同VLR间进行位置登记”为“TRUE”，“IMSI附着”为“TRUE”，“MS发起的IMSI分离”为“TRUE”，“网络发起的IMSI分离”为“TRUE”，“业务键”为“56”，“SCP地址”为“8613911111”：

```
ADD MCSITPL: HLRSN=1, TPLID=3, TPLNAME="MCSI1", LUSVLR=TRUE, LUAVLR=TRUE, IMSIATT=TRUE, MSIMSIDET=TRUE, NWIMSIDET=TRUE, SK=56, GSMSCFADD="8613911111";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                              | 处理建议                                                                                                                         |
|:--------|:--------|:----------------------------------|:-----------------------------------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | “HLR序列号”未定义。                      | 根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求。                                                                                            |
| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”参数不在相应的参数取值范围内。     | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                             |
| ERR3004 | 模板已存在   | 本次操作输入的“模板ID”在数据库中已存在。            | 根据实际情况，重新输入参数，确保输入的“模板ID”和系统中已存在的不重复。可执行LST MCSITPL命令查询系统中已存在的M-CSI模板。                                                       |
| ERR3047 | 超过最大限制  | 同一个“HLR序列号”中增加的M-CSI模板记录数超过5000条。 | 根据实际情况，如需增加M-CSI模板，处理步骤如下：执行LST MCSITPL命令，查询已存在的M-CSI模板。执行RMV MCSITPL命令，删除不必要的M-CSI模板。执行该命令增加M-CSI模板，确保增加的M-CSI模板记录数在规定范围之内。 |
