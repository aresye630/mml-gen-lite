# 增加NGC漫游限制区域模板(ADD NGCRRAREATPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在数据库中添加一个NGC漫游限制区域模板。在AMF注册流程中，AMF向UDM发起注册，UDM检测用户是否签约了NGC漫游限制模板，如果签约，则根据签约规则匹配PLMN等，以实现5G漫游限制。

## 注意事项

- 系统中增加的NGC漫游限制区域模板记录数不能超过10000条。
- 系统中通过NGC漫游限制区域模板增加的所有漫游限制区域信息数不能超过65535条。

## 使用实例

增加NGC漫游限制区域模板后，该模板会被NGC漫游限制模板引用，用户通过签约NGC漫游限制模板签约5G网络的漫游限制业务。

1. 增加一个NGC漫游限制区域模板。“HLR序列号”为“1”，“模板ID”为“1”，“模板名”为“test”，“AMF限制类型”为“AMFPOINTER”,“PLMNID”为“12345”，“AMF Region ID”为“1”，“AMF Set ID”为“1”，“AMF Pointer ID”为“1”。

   ```
   ADD NGCRRAREATPL: HLRSN=1, TPLID=1, TPLNAME="test", AREATYPE=AMFPOINTER, PLMN="12345", AMFREGION=1, AMFSET=1, AMFPOINTER=1;
   ```
2. 增加一个NGC漫游限制区域模板。“HLR序列号”为“1”，“模板ID”为“3”，“模板名”为“test”，“AMF限制类型”为“AMFPOINTER”,“PLMNID”为“11111”，“AMF Region ID”为“2”。

   ```
   ADD NGCRRAREATPL: HLRSN=1, TPLID=3, TPLNAME="test", AREATYPE=AMFREGION, PLMN="11111", AMFREGION=2;
   ```
