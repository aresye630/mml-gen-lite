# 设置EPS黑名单用户列表(SET BEPSLIST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于按照MSISDN号码在UDM上设置黑名单，只有管理员有权限对黑名单进行设置、查询和删除的操作，从而保证黑名单不会被随意更改。用户在开户签约EPS功能时，如果MSISDN号码与EPS黑名单完全匹配上，则限制其签约EPS业务，若要开通，则需要管理员根据MSISDN号码删除该条名单记录。

## 注意事项

- 如果参数“操作类型”取值为“ADD”，参数“EPS黑名单的用户号码”和“用户号码文件名”是条件可选参数，必须有且只能有一个参数出现。
- 多卡多号用户的主辅号均需要进行配置。
- 同一个“HLR序列号”中增加的EPS黑名单用户记录数不能超过30000条。

## 参数说明

| 参数标识      | 参数名称        | 参数说明                                                                                                                                                                                                           |
|:----------|:------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN     | HLR序列号      | 用于标识一个HLR序列号，有效值域为1～255。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                        |
| OPTYPE    | 操作类型        | 用于标识EPS黑名单表中用户号码的操作类型。 取值范围：ADD：增加一条记录或批量增加多条记录。DELETE：删除一条已有记录。DELETEALL：删除所有记录。 默认值：无。                                                                                                                       |
| BEPS_ISDN | EPS黑名单的用户号码 | 仅当本命令中的“操作类型”参数为“ADD”或“DELETE”时该参数有效，用于标识EPS黑名单的用户号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                            |
| FILE      | 用户号码文件名     | 仅当本命令中的“操作类型”参数为“ADD”时该参数有效，用于标识EPS黑名单的用户号码文件名称。 EPS黑名单的用户号码文件批操作文件为文本编辑器编辑的文本文件（编码格式为ANSI），如“SETBEPSLIST.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或十进制数字组成的字符串，不可包含路径名称。 默认值：无。 |

## 使用实例

设置EPS黑名单列表，数据配置可参考如下示例。

1. 为“HLR序列号”为“1”的用户增加一条记录，“操作类型”为“ADD”，“EPS黑名单的用户号码”为“460000009123456”:

   ```
   SET BEPSLIST: HLRSN=1, OPTYPE=ADD, BEPS_ISDN="460000009123456";
   ```
2. 为“HLR序列号”为“1”的用户删除一条已有记录，“操作类型”为“DELETE”，“EPS黑名单的用户号码”为“460000009123456”:

   ```
   SET BEPSLIST: HLRSN=1, OPTYPE=DELETE, BEPS_ISDN="460000009123456";
   ```
3. 为“HLR序列号”为“1”的用户批量增加多条记录，“操作类型”为“ADD”，“用户号码文件名”为“123.txt”：

   ```
   SET BEPSLIST: HLRSN=1, OPTYPE=ADD, FILE="123.txt";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                 | 处理建议                                                                                                                                                             |
|:--------|:--------|:-------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1005 | 文件未找到   | “用户号码文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。 | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                                                               |
| ERR1009 | 参数丢失    | “EPS黑名单的用户号码”、“用户号码文件名”两个参数一个都没有输入。  | 根据实际情况，重新输入参数并且满足“EPS黑名单的用户号码”或“用户号码文件名”的取值，确保其取值符合要求。                                                                                                           |
| ERR1010 | 参数冲突    | “EPS黑名单的用户号码”、“用户号码文件名”同时被输入。        | 根据实际情况，重新输入参数，确保满足“EPS黑名单的用户号码”、“用户号码文件名”两个参数是可选参数，必须有且只能有一个参数出现。                                                                                                |
| ERR3006 | 记录已存在   | 重复为同一个“HLR序列号”设置EPS黑名单列表。            | 该“HLR序列号”已添加，根据实际情况确认是否需要设置其他“HLR序列号”EPS黑名单列表。                                                                                                                   |
| ERR3007 | 记录不存在   | “HLR序列号”未定义。                         | 如果“HLR序列号”未定义，则执行ADD HLRSN命令先定义该“HLR序列号”，再为该“HLR序列号”设置EPS黑名单列表。                                                                                                  |
| ERR1111 | 超过最大限制  | 增加的EPS黑名单用户记录数超过30000条。              | 根据实际情况，如需增加EPS黑名单用户，处理步骤如下：执行LST BEPSLIST命令，查询已存在的EPS黑名单用户记录。执行该命令，将参数“操作类型”设置为“DELETE”删除不必要的EPS黑名单用户记录。执行该命令，将“操作类型”设置为“ADD”增加EPS黑名单用户，确保增加的EPS黑名单用户记录数在规定范围之内。 |
