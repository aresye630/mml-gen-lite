# 激活辅号码业务(ACT ISDN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来激活指定用户的辅ISDN号码为主ISDN号码，激活辅号后，该辅号成为主号。激活ISDN前，该ISDN必须是用户签约的辅号。

## 注意事项

- ISDN、ISDNFILE是条件可选参数，有且只能有一个参数出现。
- RECORDCOUNT一定不能与ISDNFILE同时存在。
- 该ISDN必须是用户签约的辅号。
- 激活的号码不能是ALS号码或VVDN号码。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                |
|:------------|:----------|:------------------------------------------------------------------------------------|
| ISDN        | MSISDN    | MSISDN号码，E.164格式的编码。 取值范围：1～15位的十进制数字。                                              |
| RECORDCOUNT | 用户个数      | 用户的数目。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的MSISDN为起始号码，号码连续的RECORDCOUNT个用户。 取值范围：1～100000  |
| ISDNFILE    | MSISDN文件名 | ISDNFILE文件名称。ISDNFILE是由多个不连续的MSISDN号码组成的批操作文件，每个MSISDN号码占一行。 取值范围：1～16个字母或数字组成的字符串。 |

## 使用实例

激活号码13516888888。命令如下：

ACT ISDN: ISDN="13516888888";
