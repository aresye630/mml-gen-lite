# 修改IMPU基本信息模板(MOD HIMPUTPL)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使引用该模板的用户数据被同步修改，会影响在网用户业务体验，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该操作用于在HSS的业务数据库中修改一个IMPU基本信息模板，在该操作中系统通过“IMPU模板ID”来唯一标识一条IMPU基本信息模板记录，可以修改除“IMPU模板ID”以外的所有参数。

## 注意事项

- “NASS游牧模板ID”参数和“NASS游牧模板名称”参数不能同时存在。
- 当通过**SET HSYSTEMPARA**命令设置“USINGHLRSNFORIMS（是否启用IMS-HSS的分权分域功能）”软参为“TRUE(TRUE)”时，执行该命令时会返回错误。
- 该命令不允许进行批操作。

## 使用实例

修改IMPU基本信息模板。IMPU模板ID：10，IMPU模板名称:“Modify an IMPU Template”。

```
MOD HIMPUTPL: TPLID=10, TPLNAME="Modify an IMPU Template";
```
