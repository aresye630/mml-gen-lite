# 删除IMSI号码(RMV HIMSI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于从HSS的业务数据库中删除一条IMSI数据记录。

## 注意事项

执行命令前，需要确保对应的IMSI没有被IMPI关联。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                              |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------|
| IMSI   | IMSI   | 标识一条IMSI数据记录的关键参数，用于指定需要删除哪一条IMSI数据记录。IMSI由长度[6，15]位的十进制数字(0～9)组成，采用E.212格式。例如：460001234567890。 取值范围： 6–15 缺省值： 无 |

## 使用实例

删除IMSI号码。IMSI：460001234567890。

```
RMV HIMSI: IMSI="460001234567890";
```
