# 删除IMPU的参考位置信息(RMV HNNRLI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在IMS-HSS的业务数据库中删除指定“IMPU”的参考位置信息数据记录。

## 注意事项

- 删除该IMPU的参考位置信息后，IMS-HSS下发的用户数据中将不携带该参考位置信息，会引起S-CSCF获取不到该IMPU用户的固网位置业务状态信息，造成获取固网位置业务失败。请操作员谨慎操作。
- 如果该参考位置信息为默认参考位置信息（可以使用**LST HNNRLI**命令查询，其输出报文参数“DEFRLI”取值为“1”），则不允许删除。

## 参数说明

| 参数标识             | 参数名称            | 参数说明                                                                                                                                                                                                 |
|:-----------------|:----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMPU             | IMPU            | 标识一条“IMPU”的参考位置信息数据记录的关键参数之一，用于指定需要删除哪个“IMPU”的参考位置信息记录。操作员可以使用LST HSUB操作查询获得。                                                                                                                        |
| RLINDEX          | 参考位置信息索引        | 标识一条IMPU的参考位置信息数据记录的关键参数之一，用于标识需要删除IMPU的哪一条参考位置信息记录，操作员可以使用LST HNNRLI操作查询获得。如果不带该参数，表示删除用户标识下所有的参考位置信息。                                                                                              |
| MODALLIMPUSINIRS | 修改隐式注册集中的所有IMPU | 用于标识是否将隐式注册集中所有IMPU的参考位置信息与该命令删除后的参考位置信息保持一致。 取值范围：FALSE(False)：仅删除该IMPU的参考位置信息，隐式注册集中其他IMPU的参考位置信息不删除。TRUE(True)：将隐式注册集中其他IMPU的参考位置信息设置为和该IMPU删除后的参考位置信息一致，即命令执行成功后，隐式注册集中所有IMPU的参考位置信息完全一致。 默认值：无。 |

## 使用实例

删除业务数据库中用户已签约的参考位置信息数据记录，可如下操作：

1. 删除IMPU的指定参考位置信息，“IMPU”为“sip:impuinfo@huawei.com”，“参考位置信息索引”为“1”：

   ```
   RMV HNNRLI: IMPU="sip:impuinfo@huawei.com", RLINDEX=1;
   ```
2. 删除IMPU的所有参考位置信息，“IMPU”为“sip:impuinfo@huawei.com”：

   ```
   RMV HNNRLI: IMPU="sip:impuinfo@huawei.com";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释                             | 原因分析                          | 处理建议                                                        |
|----------:|:----------------------------------|:------------------------------|:------------------------------------------------------------|
| 900001007 | 无效的参数值                            | 输入的参数取值不符合取值范围。               | 根据实际情况，重新输入“IMPU”、“参考位置信息索引”或“修改隐式注册集中的所有IMPU”，确保其取值符合取值范围。 |
| 900003060 | 请求消息中的IMPU不存在                     | “IMPU”参数取值实际不存在。              | 需要重新输入“IMPU”，使用LST HSUB命令查询已存在的IMPU后，重新确认要删除哪个数据记录。         |
| 900003182 | referLocIndex在IMPU签约的参考位置信息索引中不存在 | “IMPU”参数指定的“参考位置信息索引”数据记录不存在。 | 该“参考位置信息索引”指定的数据记录不存在，执行LST HNNRLI命令先查询已定义的“参考位置信息索引”。      |
