# 增加SKTYPE(ADD SKTYPE)

## 命令功能

**须知** 

本命令属于高危命令，执行该命令前，需要与华为技术支持确认后才可以实施。

操作员可以通过此命令增加一个智能业务类型。

## 注意事项

- SKBEGIN和SKEND可能相同，若相同，则用来设置单点SK值。
- 系统中增加的智能业务类型记录数不能超过1000条。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                 |
|:--------|:-------|:---------------------------------------------------------------------|
| HLRSN   | HLR序列号 | HLR序列号，有效值域为1～255，在PGW支持容灾功能或虚拟HLR功能时设置。                             |
| SKINDEX | 索引号    | 用来标识智能业务编码号段的记录，两条智能业务编码号段记录不能使用同一个SKINDEX。 值域：0～999。 必选参数。          |
| SKTYPE  | 智能业务类型 | 智能业务的类型。 值域： PrePaid：预付费 默认值：PrePaid。 必选参数。                          |
| SKBEGIN | 业务键起始值 | 智能业务编码起始值，值域：0～2147483647。和SKEND共同描述一个连续的SK号码段，且小于等于SKEND。 必选参数。     |
| SKEND   | 业务键结束值 | 智能业务编码结束值，值域：0～2147483647。和SKBEGIN共同描述一个连续的SK号码段，且大于等于SKBEGIN。 必选参数。 |

## 使用实例

增加一个预付费的智能业务类型，其中SKINDEX为3，SKBEGIN为123456，SKEND为1234567。

ADD SKTYPE: HLRSN=1, SKINDEX=3, SKTYPE=PrePaid, SKBEGIN=123456, SKEND=1234567;

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                 | 处理建议                                                                                                                    |
|:--------|:--------|:---------------------|:------------------------------------------------------------------------------------------------------------------------|
| ERR3047 | 超过最大限制  | 增加的智能业务类型记录数超过1000条。 | 根据实际情况，如需增加智能业务类型，处理步骤如下：执行LST SKTYPE命令，查询已存在的智能业务类型。执行RMV SKTYPE命令，删除不必要的智能业务类型记录。执行该命令增加智能业务类型，确保增加的智能业务类型记录数在规定范围之内。 |
