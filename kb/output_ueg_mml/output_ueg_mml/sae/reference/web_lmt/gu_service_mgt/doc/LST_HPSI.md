# 查询PSI用户(LST HPSI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询指定PISI或指定PUSI归属的PSI用户中的所有PISI和PUSI的关联关系。

## 注意事项

参数PISI和参数PUSI必须存在且只能存在一个。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                |
|:-------|:-------|:----------------------------------------------------------------------------------------------------|
| PISI   | PISI   | 用于指示系统需要按照哪个PISI来查询PSI用户数据，要求输入的PISI值符合NAI格式，字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。             |
| PUSI   | PUSI   | 用于指示系统需要按照哪个PUSI来查询PSI用户数据，要求输入的PUSI值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。 |

## 使用实例

PSI用户关系查询。PISI：pisiinfo。

```
LST HPSI: PISI="pisiinfo";
```

命令参数说明中的输出项。

| 输出项名称    | 输出项解释                                              |
