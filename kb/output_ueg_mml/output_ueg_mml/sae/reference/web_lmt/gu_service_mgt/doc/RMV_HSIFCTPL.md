# 删除共享iFC模板(RMV HSIFCTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在HSS的业务数据库中删除一个共享iFC模板。

## 注意事项

- 当共享iFC模板被用户引用时，不能被删除。
- 当“HLR序列号”参数不输入时，默认删除“HLR序列号”为“0”的记录。

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                       |
|:-------|:----------|:---------------------------------------------------------------------------|
| HLRSN  | HLR序列号    | 用于指定需要删除哪一个HLR序列号对应的共享iFC模板，操作员可以使用LST HTPLINF命令查询获得。 说明：可选参数              |
| TPLID  | 共享iFC模板ID | 标识一条共享iFC模板数据记录的关键字段，用于指定需要删除哪一条共享iFC模板，操作员可以使用LST HTPLINF命令查询获得。 说明：必选参数。 |

## 使用实例

删除共享iFC模板，“共享iFC模板ID”为“10”：

```
RMV HSIFCTPL: TPLID=10;
```
