# 修改切片管理数据（MOD SNSSAI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改5GS用户的S-NSSAI签约数据。

## 注意事项

- 该命令一次只修改一条S-NSSAI签约数据。修改后的数据必须确保至少包含一条默认S-NSSAI数据，至多包含8条默认S-NSSAI数据。
- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识        | 参数名称        | 参数说明                                                                                                                                                                                                                                                        |
|:------------|:------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI        | 可选必选说明：条件可选参数 参数含义：用于标识需要修改S-NSSAI数据的5GS用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                    |
| ISDN        | MSISDN      | 可选必选说明：条件可选参数 参数含义：用于标识需要修改S-NSSAI数据的5GS用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                  |
| RECORDCOUNT | 用户个数        | 可选必选说明：条件可选参数 参数含义：用于标识需要修改S-NSSAI数据的用户数目。 取值范围：1～100000 默认值：无。 配置原则：当需要为连续号码的多个用户修改S-NSSAI数据时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户修改S-NSSAI数据。该参数是对连续号码的多个用户修改S-NSSAI数据，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名     | 可选必选说明：条件可选参数 参数含义：用于标识IMSI批操作文件。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。 配置原则：IMSI批操作文件包含多个不连续的待修改S-NSSAI数据的5GS用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modsnssai.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。                                             |
| ISDNFILE    | MSISDN文件名   | 可选必选说明：条件可选参数 参数含义：用于标识MSISDN批操作文件。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。 配置原则：MSISDN批操作文件包含多个不连续的待修改S-NSSAI数据的5GS用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modsnssai.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。                                       |
| SNSSAI      | 切片标识        | 可选必选说明：必选参数 参数含义：用于标识5G系统中的网络切片，由SST（Slice/Service Type）与SD（Slice Differentiator）组成。 例如：当SST为1，SD为D143A5，则BOSS填写为1-D143A5；当SST为1，无SD，则BOSS填写为1。 取值范围：1～10位字符串。 默认值：无。 配置原则：SST为取值范围是0～255的数字SD是固定长度为3字节的十六进制字符串。当该参数不携带SD或SD取值为FFFFFF时，系统按照相同取值处理。          |
| DEFAULT     | 是否默认S-NSSAI | 可选必选说明：必选参数 参数含义：用于标识需要修改的S-NSSAI数据是否为默认S-NSSAI数据。 取值范围： TRUE：需要修改的S-NSSAI数据为默认S-NSSAI数据。FALSE：需要修改的S-NSSAI数据为非默认S-NSSAI数据。 默认值：无。 配置原则：无。                                                                                                                  |

## 使用实例

修改“IMSI”为“460030913121001”的5GS用户的切片管理数据。其中，“切片标识”为“1”，“是否默认S-NSSAI”为“TRUE”：

```
MOD SNSSAI: IMSI="460030913121001", SNSSAI="1", DEFAULT=TRUE;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

| ERR1009 | 参数丢失           | “IMSI”、“MSISDN”、“IMSI文件名”或“MSISDN文件名”四个参数一个都没有输入。                                                   | 根据实际情况，重新输入参数，确保满足“IMSI”、“MSISDN”、“IMSI文件名”或“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                             |
| ERR1010 | 参数冲突           | 可能原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。 “用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。 “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR1025 | 批操作文件中格式非法     | 参数“IMSI文件名”或“MSISDN文件名”对应的批操作文件格式不正确。                                                               | 请根据IMSIFILE文件格式和ISDNFILE文件格式重新确定对应的批操作文件格式。                                                                              |

| ERR4109 | 用户至少必须存在一个默认切片 | 用户存在多个S-NSSAI数据，且只有一个默认S-NSSAI数据，修改的数据为默认S-NSSAI数据。                                                 | 当用户需要继续修改S-NSSAI数据时，执行LST SNSSAI命令，查询已签约的S-NSSAI数据，选择其中的非默认数据，执行本命令，确保用户的默认S-NSSAI数量在取值范围内。                              |
