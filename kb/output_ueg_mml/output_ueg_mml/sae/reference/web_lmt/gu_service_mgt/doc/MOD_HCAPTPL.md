# 修改能力集信息模板(MOD HCAPTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于在业务数据库中修改一个能力集模板的相关数据。该操作中用能力集模板ID来唯一标识一个能力集模板。

## 注意事项

修改的参数必须至少存在一个，否则HSS返回失败。

当MCAP参数和OCAP参数都存在，且取值都为下面第二种情况时，两个参数的集合之间不允许有相同的整数。

MCAP和OCAP的合法取值分为以下几种情况：

- 只有一个无效ID值，0为无效ID值；
- 由1到32个整数用“&”连接起来的整数集合，其中每个整数的取值范围为1～4294967295，集合里的整数不允许重复；

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                      |
|:----------|:--------|:------------------------------------------------------------------------------------------|
| HLRSN     | HLR序列号  | 用于标识一个HLR序列号。 取值范围：0~255 默认值：无。 说明：当该参数不输入时，系统默认初始设置值为0。                                  |
| TPLID     | 能力集模板ID | 标识一条能力集模板的关键字段，用于指定需要修改哪一条能力集模板数据记录。可以通过LST HTPLINF查询获得。                                  |
| TPLNAME   | 能力集模板名称 | 用于修改一个能力集模板名称。 取值范围： 长度不超过64的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值： 无                          |
| MCAP      | 必选能力集   | 用于修改一个能力集模板的必选能力集，配置原则是能力之间不能重复，不同的能力以“&”符连接。只有一个无效ID值，0为无效ID值。 取值范围： 长度不超过352的字符串 默认值： 无 |
| OCAP      | 可选能力集   | 用于修改一个能力集模板的可选能力集，配置原则是能力之间不能重复，不同的能力以“&”符连接。只有一个无效ID值，0为无效ID值。 取值范围： 长度不超过352的字符串 默认值： 无 |
| SCSCFLIST | SCSCF列表 | 用于修改一个能力集模板的SCSCF的名称集合，不同的SCSCF的名称以“&”符连接。 取值范围： 长度不超过649的字符串 默认值： 无                      |
| COMMENT   | 模板注释说明  | 用于修改一个能力集模板的注释。 取值范围： 长度不超过512的字符串 默认值： 无                                                 |

## 使用实例

修改能力集信息模板。能力集模板ID：10，能力集模板名称：Modify a Capability Template，必选能力集：2。

```
MOD HCAPTPL: TPLID=10, TPLNAME="Modify a Capability Template", MCAP="2";
```
