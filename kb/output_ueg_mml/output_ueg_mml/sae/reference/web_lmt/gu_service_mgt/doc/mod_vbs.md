# 修改VBS业务(MOD VBS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改用户的VBS（Voice Broadcast Service）业务数据。

对于在网用户执行该命令后，如果是给用户签约该业务，则UDM会向MSC/VLR下发插入用户数据消息（Insert Subscriber Data）；如果是给用户去签约该业务，则UDM会向MSC/VLR下发删除用户数据消息（Delete Subscriber Data）。对于不在网用户执行该命令后，则仅会更新用户在数据库中的数据，当用户进行位置更新时UDM将用户的VBS业务数据下发给MSC/VLR。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。
- 一个用户最多可以设置50个组ID数据，一次最多只能设置一个组ID数据。

## 参数说明

| 参数标识                | 参数名称       | 参数说明                                                                                                                                                                                                                    |
|:--------------------|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI                | IMSI       | 用于标识需要修改VBS业务的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                  |
| ISDN                | MSISDN     | 用于标识需要修改VBS业务的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                |
| RECORDCOUNT         | 用户个数       | 用于标识需要修改VBS业务的用户数目。 当需要为连续号码的多个用户修改VBS业务时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户修改VBS业务。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户修改VBS业务，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE            | IMSI文件名    | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要修改VBS业务的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modvbs.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                          |
| ISDNFILE            | MSISDN文件名  | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要修改VBS业务的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modvbs.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                    |
| CAPINITVBSONROAMING | VBS初始化呼叫能力 | 用于标识当用户漫游出归属PLMN（Public Land Mobile Network）时，是否具有初始化VBS组呼业务的能力。 取值范围：TRUE：具有初始化VBS组呼业务的能力FALSE：不具有初始化VBS组呼业务的能力 默认值：无。                                                                                                 |
| OPTYPE              | 操作类型       | 用于标识执行该命令所实现的操作类型。 取值范围：ADD：表示为用户增加新的“组ID”数据。DELETE：表示为用户删除已存在的“组ID”数据。MODIFY：表示修改已存在的“组ID”数据对应的“VBS组呼1发起能力”参数。 默认值：无。                                                                                                  |
| COUNT               | 组ID个数      | 仅当本命令中的“操作类型”参数为“ADD”、“DELETE”或“MODIFY”时该参数有效。用于标识执行该命令给用户增加、删除或修改的组ID个数。 取值范围：1 当“操作类型”为“ADD”时无默认值。当“操作类型”为“DELETE”时默认值为1。当“操作类型”为“MODIFY”时默认值为1。                                                                      |
| GROUPID1            | 组ID1       | 仅当本命令中的“操作类型”参数为“ADD”、“DELETE”或“MODIFY”并且“组ID个数”参数为“1”时该参数有效。用于标识组呼ID。将业务用户划分为不同的功能组，用组呼ID标识。业务用户签约组呼业务时将组呼ID存储在UDM中，同时组呼ID也需要存储在业务用户的手机SIM卡中。业务用户在组呼区域中通过拨打组呼ID发起组呼。 取值范围：1～8位十进制数字组成的字符串。 默认值：无。                      |
| CAPINITVBS1         | VBS组呼1发起能力 | 仅当本命令中的“操作类型”参数为“ADD”或“MODIFY”并且“组ID个数”参数为“1”时该参数有效。用于标识用户在归属PLMN时，是否支持初始化VBS组呼业务的能力。 取值范围：TRUE：具有初始化VBS类型组呼的能力 FALSE：不具有初始化VBS类型组呼的能力 默认值：无。                                                                           |

## 使用实例

1. 给IMSI号码为“460000009123456”的用户增加一个新的组ID数据，“操作类型”为“ADD”，“组ID个数”为“1”，“组ID1”为“111111”，“VBS组呼1发起能力”为“TRUE”：

   ```
   MOD VBS: IMSI="460000009123456", OPTYPE=ADD, COUNT=1, GROUPID1="111111", CAPINITVBS1=TRUE;
   ```
2. 给3个连续号码的用户的删除一个已存在的组ID数据，这3个MSISDN号码分别为“13310911001”、“13310911002”、“13310911003”，“操作类型”为“DELETE”，“组ID个数”为“1”，“组ID1”为“111112”，“VBS组呼1发起能力”为“TRUE”：

   ```
   MOD VBS: ISDN="13310911001", RECORDCOUNT=3, OPTYPE=DELETE, COUNT=1, GROUPID1="111112", CAPINITVBS1=TRUE;
   ```
3. 给3个非连续号码的用户修改“VBS初始化呼叫能力”参数，这3个MSISDN号码分别为“13310911001”、“13310911003”、“13310911005”，已保存在“MSISDN文件名”为“modvbs.txt”的文件中，并通过文件管理功能上传到指定目录，对应的“VBS初始化呼叫能力”修改为“FALSE”：

   ```
   MOD VBS: ISDNFILE="modvbs.txt", CAPINITVBSONROAMING=FALSE;
   ```

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| ERR1009 | 参数丢失       | 可能原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数一个都没有输入。“VBS初始化呼叫能力”或“操作类型”参数一个都没有输入。           | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现。至少输入“VBS初始化呼叫能力”或“操作类型”参数其中之一。            |

| ERR1025 | 批操作文件中格式非法 | 参数“IMSI文件名”或“MSISDN文件名”对应的批操作文件格式不正确。                                                              | 请根据IMSIFILE文件格式和ISDNFILE文件格式，重新确定对应的批操作文件格式。                                                                            |
| ERR3015 | 业务未提供      | 在用户未签约VBS业务的情况下，执行该命令修改或删除组ID数据或修改“VBS初始化呼叫能力”。                                                    | 当用户未签约VBS业务时，执行该命令必须增加组ID数据。                                                                                            |
