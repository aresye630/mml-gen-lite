## 命令功能

该命令用于增加虚拟HLR上的MSISDN号码前缀和IMSI号码前缀的映射关系。

该映射定义了短消息流程中消息携带的MSISDN和IMSI之间的关系，其中，MSISDN为MAP Server发送给UDM的SRI-SM消息中携带的信元，IMSI为UDM返回给MAP Server的响应消息中携带的信元。

当特殊一卡多号业务用户漫游出归属网络后，通过辅MSISDN号码发送短消息时，MAP Server会触发一次SRI-SM消息给UDM，该消息中包含如下数据：

- msisdn：该号码是一卡多号用户的辅MSISDN号码。
- serviceCentreAddress：MAP Server地址，该地址是通过**SET SELIST**命令的“PLMN自定义补充业务”参数取值为“OCMN\_MAP\_SERVER”时配置的地址号码。

UDM接收到这个消息后，会返回SRI-SM Ack响应消息给MAP Server，会携带如下数据：

- networkNode-Number：MAP Server地址，即SRI-SM消息中携带的“serviceCentreAddress”信元值。
- imsi：虚拟IMSI号码，该号码由IMSI前缀（通过该命令定义）+去掉国家码的主MSISDN号码组成。

## 注意事项

系统中增加的MSISDN号码前缀和IMSI号码前缀的对应关系记录数不能超过3000条。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                      |
|:-----------|:---------|:--------------------------------------------------------------------------|
| HLRSN      | HLR序列号   | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                              |
| ISDNPREFIX | ISDN号码前缀 | 用于标识一个MSISDN号码前缀。该参数用于查找对应的IMSI前缀。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。          |
| IMSIPREFIX | IMSI号码前缀 | 用于标识一个IMSI号码前缀。该参数会在UDM返回的SRI-SM消息的响应消息中携带。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 |

## 使用实例

增加“HLR序列号”为“1”的虚拟HLR上的MSISDN号码前缀和IMSI号码前缀的映射关系，“ISDN号码前缀”为“180”，“IMSI号码前缀”为“4600”，命令如下：

```
ADD OCMNISDN: HLRSN=1, ISDNPREFIX="180", IMSIPREFIX="4600";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|:--------|:--------|:----------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 输入的“ISDN号码前缀”或“IMSI号码前缀”参数不在取值范围内。                  | 根据实际情况，重新输入“ISDN号码前缀”或“IMSI号码前缀”的取值，确保其取值符合要求。                                                                                                                                                  |
| ERR1040 | 记录超过上限  | 添加的数据记录数量超过3000个。                                   | 若要继续添加新的数据记录，请先使用RMV OCMNISDN命令删除旧的不需要的数据记录，确保删除后的总数据记录数量不超过3000，然后再使用本命令添加新的数据记录。                                                                                                              |
| ERR3006 | 记录已存在   | 输入的“HLR序列号”、“ISDN号码前缀”及“IMSI号码前缀”三个参数值对应的数据记录已经添加过。 | 请先使用LST OCMNISDN命令查询已添加过的数据记录，根据查询结果重新输入“HLR序列号”、“ISDN号码前缀”及“IMSI号码前缀”三个参数值，确保这三个参数中至少有一个参数值未在查询结果中存在。                                                                                          |
| ERR3007 | 记录不存在   | 输入的“HLR序列号”未在系统中添加。                                 | 请先使用ADD HLRSN命令添加要输入的“HLR序列号”，然后再执行该命令。                                                                                                                                                         |
