# 删除业务限制模板(RMV SERRESTTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中删除一个业务限制模板。

## 注意事项

如果已经通过**ADD VSLIST**命令关联该模板，当执行该命令删除业务限制模板时，系统会提示“ERR3005:模板已经被使用”的错误信息，该业务限制模板不能被删除。如果要删除该业务限制模板，必须先执行**MOD VSLIST**命令去掉业务限制模板与VLR/SGSN漫游限制模板的关联关系。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                   |
|:-------|:-------|:-----------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 标识业务限制模板数据记录的关键字段之一，用于指定在哪个HLR上删除业务限制模板的数据记录，操作员可以使用LST HLRSN命令查询获得。   |
| TPLID  | 模板ID   | 标识业务限制模板信息数据的关键字段之一，用于指定需要删除哪个业务限制模板的数据记录，操作员可以使用LST SERRESTTPL命令查询获得。 |

## 使用实例

删除业务限制模板，“HLR序列号”为“1”，“模板ID”为“3”。命令如下：

```
RMV SERRESTTPL: HLRSN=1, TPLID=3;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                 | 处理建议                                                                                |
|:--------|:--------|:-------------------------------------|:------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | “HLR序列号”和“模板ID”参数对应的模板数据记录不存在。       | 根据实际情况，重新输入参数，确保“HLR序列号”和“模板ID”参数对应的模板数据记录已存在。已存在的模板数据记录可以通过LST SERRESTTPL命令查询。     |
| ERR3005 | 模板已经被使用 | “HLR序列号”和“模板ID”参数对应的业务限制模板数据已经被系统使用。 | 根据实际情况，确定是否要删除该模板。如果确实需要删除，先通过MOD VSLIST命令去掉业务限制模板与VLR/SGSN漫游限制模板的关联关系，然后才能执行本命令删除。 |
