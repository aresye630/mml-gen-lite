## 命令功能

该命令用于对CS域用户、PS域用户或允许同时接入CS域和PS域的用户进行开户。

## 注意事项

- “IMSI”、“MSISDN”参数不能与“IMSI/MSISDN文件名”参数同时配置。
- “RECORDCOUNT”参数只能与“IMSI/ISDN”一起出现，用于增加多个连续号码的用户时使用。此种情况下，开户操作为批操作。
- 通过开户批操作文件为不连续号码的M2M用户开户成为MSISDN-Less用户时，由于开户批操作文件必须同时输入IMSI和MSISDN，需在批操作文件中将用户的MSISDN与IMSI保持一致。
- 如果输入“CHARGE\_GLOBAL”或“SCHARGE\_GLOBAL”，则“GPRSTPLID”不允许输入。
- 如果通过“优化GPRS模板ID”给用户签约GPRS业务，则必须在命令**SET MAPSERV**中设置“GPRS管理方式”参数为“NotSupportGPRSManager”、“SupportGPRSManager”或“SuppGprsManageOptimizeon”。“GPRS管理方式”参数开局设定之后不能修改，如非开局场景，请勿修改此参数配置。
- 如果签约闭锁业务BAOC、BOIC、BOICEXHC、BAIC、BICROAM的任意一种，则必须设置“CBCOU”。
- 如果签约MPTY业务，必须先签约HOLD业务。
- 如果用户签约ODB-POS，“ODBPOS”和“ODBPOSTYPE”两个参数为必选参数。
- 如果签约ACR业务，必须先签约CLIP业务。
- 开户前，请使用**ADD KI**命令加载KI。
- 当PGW为简单模式时，不需要设置参数HLRSN，HLRSN仅在完整模式中设置。
- 由于HLR数据库性能和大小跟签约的业务多少有关，对于运营商没有开通的业务建议不要签约。
- 如果输入的“ECATOPTION”为有效值，则必须输入“ECATEGORY”。
- 用户签约5G虚拟网络组时，对于同一个“切片标识”和“数据网名称”下的5G虚拟网络组，建议用户只签约一个。

## 使用实例

1. 增加用户，“HLR序列号”为“1”，“IMSI”为“460000009123456”，“MSISDN”为“8613900001234”，“网络接入模式”为“BOTH”，“缺省呼叫类型”为“TS11”，“全局计费特性”为“5”，命令如下：

   ```
   ADD CSPSSUB: HLRSN=1, IMSI="460000009123456", ISDN="8613900001234", NAM=BOTH, DEFAULTCALL=TS11, CHARGE_GLOBAL=5;
   ```
2. 增加普通M2M用户，“HLR序列号”为“1”，“IMSI”为“460000009123456”，“MSISDN”为“8613900001234”，“网络接入模式”为“BOTH”，“缺省呼叫类型”为“TS11”，“是否是M2M用户”为“M2M”，命令如下:

   ```
   ADD CSPSSUB: HLRSN=1, IMSI="460000009123456", ISDN="8613900001234", NAM=BOTH, DEFAULTCALL=TS11, USERCATEGORY=M2M;
   ```
3. 增加MSISDN-Less用户，“HLR序列号”为“1”，“IMSI”为“460000009123456”，“网络接入模式”为“BOTH”，“缺省呼叫类型”为“TS11”，“是否是M2M用户”为“M2M”，命令如下:

   ```
   ADD CSPSSUB: HLRSN=1, IMSI="460000009123456", NAM=BOTH, DEFAULTCALL=TS11, USERCATEGORY=M2M;
   ```
4. 增加M2M Common MSISDN用户，“HLR序列号”为“1”，“IMSI”为“460000009123456”，“MSISDN”为“8613900001234”，“网络接入模式”为“BOTH”，“缺省呼叫类型”为“TS11”，“是否是M2M用户”为“M2M”，“M2MCISDN号码”为“8613900001235”，命令如下:

   ```
   ADD CSPSSUB: HLRSN=1, IMSI="460000009123456", ISDN="8613900001234", NAM=BOTH, DEFAULTCALL=TS11, USERCATEGORY=M2M, M2MCISDN="8613900001235";
   ```
