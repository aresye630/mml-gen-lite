# 设置短消息中心地址(SET HSMSCADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在IMS-HSS中为用户设置短消息中心地址信息。

在GSM/UMTS/EPS/IMS融合网络场景下，由于运营商现网号段多，如果为用户完全配置短消息中心地址信息会带来复杂的维护问题，为避免运营商基于号段为用户设置短消息中心地址，通过执行该命令即可为用户设置短消息中心地址。设置完成后，IMS-HSS在下发UDA（User Data Answer）消息中携带该地址信息，从而降低AS（Application Server）设置、维护的复杂度，节省额外成本，提高产品竞争力。

当AS从IMS-HSS获取用户签约短消息中心数据时，发送UDR（User Data Request）请求获取用户签约的短消息中心地址信息，IMS-HSS查询用户签约的短消息中心地址成功后，在UDA（User Data Answer）消息中携带短消息中心地址信息并下发给AS，完成短消息业务。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                            |
|:---------|:--------|:----------------------------------------------------------------|
| ISDN     | MSISDN  | 用于标识待设置短消息中心地址的MSISDN号码。该参数必须先由ADD HIMSI命令定义，然后才能在此处引用。         |
| SMSCADDR | 短消息中心地址 | 用于标识待设置的短消息中心地址，即用户需要签约的短消息中心地址。 取值范围：1～20位的十进制数字组成的字符串。 默认值：无。 |

## 使用实例

为已开户用户签约短消息中心地址，“MSISDN”号码为“4600000091234”，“短消息中心地址”为“1234567890”，执行命令如下：

```
SET HSMSCADDR: ISDN="4600000091234", SMSCADDR="1234567890";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释         | 原因分析                                       | 处理建议                                                                                           |
|----------:|:--------------|:-------------------------------------------|:-----------------------------------------------------------------------------------------------|
| 900001007 | 无效的参数值        | 输入的参数取值不符合要求。                              | 根据实际情况，重新输入“MSISDN”或“短消息中心地址”，确保其取值符合要求。                                                       |
| 900001008 | 参数不足          | 可能原因为如下之一：参数“MSISDN”没有输入。参数“短消息中心地址”没有输入。  | 根据实际情况选择：输入“MSISDN”。输入“短消息中心地址”                                                                |
| 900003062 | 请求消息中的ISDN不存在 | 用户的“MSISDN”号码输入错误，实际输入的参数“MSISDN”对应的用户未开户。 | 核实用户的“MSISDN”号码，如果确定输入无误，说明实际输入的参数“MSISDN”对应的用户未开户，请先通过ADD HIMSI命令给用户开户，完成后再执行该命令为用户签约短消息中心地址。 |
