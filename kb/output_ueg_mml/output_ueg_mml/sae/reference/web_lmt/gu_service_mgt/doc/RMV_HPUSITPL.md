# 删除PUSI基本信息模板(RMV HPUSITPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于从HSS的业务数据库中删除一个PUSI基本信息模板。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                       |
|:-------|:---------|:-----------------------------------------------------------------------------------------------------------|
| TPLID  | PUSI模板ID | 可选必选说明：必选参数 参数含义：标识一个PUSI基本信息模板记录的关键字段，用于指定需要删除哪一个PUSI基本信息模板记录，操作员可以使用LST HTPLINF操作查询获得。 取值范围：0～254 缺省值： 无 |

## 使用实例

删除PUSI基本信息模板。PUSI模板ID：10。

```
RMV HPUSITPL: TPLID=10;
```
