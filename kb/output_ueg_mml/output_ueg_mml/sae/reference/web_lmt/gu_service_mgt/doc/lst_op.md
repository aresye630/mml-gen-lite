# 查询OP(LST OP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此操作用来查询OP。

## 注意事项

如果CMCC鉴权增强开关打开，该命令不允许执行。可通过**LST MAPCONF**查看CMCC鉴权增强开关是否打开。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                         |
|:-------|:-------|:---------------------------------------------|
| HLRSN  | HLR序列号 | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 |

## 使用实例

查询OP，HLR序列号为1。命令如下：

```
LST OP: HLRSN=1;
```

```
%%LST OP: HLRSN=1;%%
RETCODE = 0 SUCCESS0001:操作成功

        "OPSNO"
        1
        3

Total count = 2

There is together 1 report

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD OP**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析         | 处理建议                                                  |
|:--------|:--------|:-------------|:------------------------------------------------------|
| ERR3007 | 记录不存在   | “HLR序列号”未定义。 | 根据实际情况，重新输入已定义的“HLR序列号”，可通过LST HLRSN命令查询已定义的“HLR序列号”。 |
