# 删除NEF检查策略配置(RMV NEFCHKPOLICY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会影响能力开放功能，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除系统配置的NEF合法性检查的数据记录。

## 注意事项

删除指定NEF检查策略数据记录，系统不对该NEF的合法性进行校验，NEF订阅用的个人信息存在安全隐患，请谨慎执行本命令。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                  |
|:--------|:-------|:--------------------------------------------------------------------------------------|
| NEFNAME | NEF名称  | 可选必选说明：必选参数 参数含义：用于指定根据哪个NEF名称来删除已配置的NEF合法性检查策略数据记录。 取值范围：长度不超过64的字符串。 默认值：无。 配置原则：无。 |

## 使用实例

删除“NEF名称”取值为“nefIPv4”的NEF的检查策略。

```
RMV NEFCHKPOLICY: NEFNAME="nefIPv4";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 消息解释   | 原因分析                      | 处理建议                                                       |
|:--------|:-------|:--------------------------|:-----------------------------------------------------------|
| ERR3007 | 记录不存在  | 输入“NEF名称”对应的NEF检查策略记录不存在。 | 请使用LST NEFCHKPOLICY命令查询对应结果，根据实际情况重新输入已有NEF检查策略对应的“NEF名称”。 |
