# 删除它网携转用户数据(RMV NPOTHERRPT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来删除它网携转用户数据。

此操作支持批处理。

## 注意事项

ISDN和ISDNFILE是条件可选参数，有且只能有一个参数出现。RECORDCOUNT一定不能与ISDNFILE同时存在。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                           |
|:------------|:----------|:-------------------------------------------------------------------------------|
| ISDN        | MSISDN    | MSISDN号码，E.164格式的编码，为1～15位的十进制数字。 说明：可选参数。                                     |
| RECORDCOUNT | 用户个数      | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的MSISDN为起始号码，号码连续的RECORDCOUNT个用户。 |
| ISDNFILE    | MSISDN文件名 | ISDN文件名称，1～16个字母或数字组成。ISDNFILE包含多个不连续的MSISDN号码。 说明：可选参数。                       |

## 使用实例

删除单个它网携转用户。

将MSISDN号码为86131075003002的它网携转用户数据删除。命令如下：

```
RMV NPOTHERRPT: ISDN="86131075003002";
```
