# 删除IMS用户标识的号段前缀信息(RMV IMSMVNORANGE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，删除MVNO对应的IMPI或IMPU号段前缀会缩小既有操作员的号段范围，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除一条IMS用户标识的号段前缀信息记录。

使用本命令删除IMPI或IMPU号段前缀后，既有操作员不能通过**ADD IMSMVNORANGE**命令配置的“虚拟运营商号码”对删除的IMPI或IMPU号段进行管理。

## 注意事项

- 只有超级管理员帐户具有本命令的操作权限。
- 执行该命令前运营商需要完成号段规划。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                     |
|:----------|:-------|:-------------------------------------------------------------------------|
| PREFIX    | 号段前缀   | 标识一条IMS用户标识的号段前缀信息记录的关键字段之一，用于指定需要删除哪一个号段前缀，操作员可以使用LST IMSMVNORANGE查询获得。 |
| RANGETYPE | 号段类型   | 标识一条IMS用户标识的号段前缀信息记录的关键字段之一，用于指定需要删除哪种号段类型的号段前缀信息记录。                     |

## 使用实例

既有操作员已管理IMPI“号段前缀”为“46000”、“46001”的用户，现由于号段调整，需删除既有操作员对IMPI“号段前缀”为“46000”的管理权限，命令如下:

```
RMV IMSMVNORANGE: PREFIX="46000", RANGETYPE=IMPI;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                           | 处理建议                                                                                                                 |
|:--------|:--------|:-------------------------------|:---------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 参数“号段前缀”的取值不是1～15位十进制数字组成的字符串。 | 根据实际情况，重新输入“号段前缀”参数的取值，确保其取值符合要求。                                                                                    |
| ERR3007 | 记录不存在   | “号段类型”对应的“号段前缀”数据记录不存在。        | 请按照以下步骤操作： 核实输入的“号段前缀”和“号段类型”。执行LST IMSMVNORANGE输入“号段类型”，查询已配置的IMPI或IMPU号段前缀信息。根据查询结果重新输入“号段前缀”，确保输入的“号段前缀”包含在查询结果中。 |
