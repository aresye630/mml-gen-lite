# 查询APN运营商标识符模板(LST APNOITPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询APN运营商标识符模板信息：

- 若需要查询某个HLR序列号下全部APN运营商标识符模板的概要信息，请只输入“HLR序列号”。
- 若需要查询某个HLR序列号下某个APN运营商标识符模板的详细配置信息，请输入“HLR序列号”和“模板ID”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                              |
|:-------|:-------|:--------------------------------------------------|
| HLRSN  | HLR序列号 | 用于指示系统按照哪个HLR序列号来查询APN运营商标识符模板信息数据。               |
| TPLID  | 模板ID   | 用于指示系统按照哪个模板ID来查询APN运营商标识符模板信息数据；若不输入，则表示所有的模板ID。 |

## 使用实例

1. 查询全部PN运营商标识符模板的概要信息，“HLR序列号”为“1”：

   ```
   LST APNOITPL: HLRSN=1;
   ```

   ```
   %%LST APNOITPL: HLRSN=1;%%
   RETCODE = 0 SUCCESS0001:操作成功

                  TPLID        TPLNAME
                  1            <NULL>

   Total count = 1

   There is together 1 report

   ---    END
   ```
2. 查询“HLR序列号”为“1”，“模板ID”为“1”的模板信息：

   ```
   LST APNOITPL: HLRSN=1, TPLID=1;
   ```

   ```
   %%LST APNOITPL: HLRSN=1, TPLID=1;%%
   RETCODE = 0 SUCCESS0001:操作成功

                            HLRSN = 1
                            TPLID = 1
                          TPLNAME = <NULL>
                            APNOI = 1111111

   Total count = 4

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，请参见**ADD APNOITPL**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                            | 处理建议                                     |
|:--------|:--------|:--------------------------------|:-----------------------------------------|
| ERR3003 | 模板未定义   | 用户输入的“HLR序列号”和“模板ID”对应的模板信息未添加。 | 执行LST APNOITPL命令查询已添加的模板信息，根据查询结果重新输入参数。 |
