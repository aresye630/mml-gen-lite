# 修改5G业务区域信息模板(MOD SERAREATPL)

## 命令功能

**须知** 

该命令属于高危命令，修改5G业务区域模板会使引用此模板的用户5G业务区域信息数据被同步修改。因此执行该命令前，请仔细评估当前操作的风险，确认对业务没有影响后方可执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用于修改5G业务区域信息模板。在该命令中，系统通过以下关键参数的组合来唯一标识一个5G业务区域信息模数据记录：

- “HLR序列号”
- “模板ID”

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|:------------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号   | 可选必选说明：必选参数 参数含义：标识5G业务区域信息模板数据记录的关键字段之一（其取值不能被修改），用于指定对哪个HLR上的5G业务区域信息模板漫游信息数据记录的参数进行修改，操作员可以使用LST HLRSN命令查询获得。 取值范围：1~255 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| TPLID       | 模板ID     | 可选必选说明：必选参数 参数含义：标识5G业务区域信息模板信息数据的关键字段之一（其取值不能被修改），用于指定需要对哪个5G业务区域信息模板信息数据记录的参数进行修改，操作员可以使用LST SERAREATPL命令查询获得。 取值范围：1～2147483646 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| TPLNAME     | 模板名      | 可选必选说明：可选参数 参数含义：用于标识待修改模板在系统中的名称。 取值范围：1～60个字母或十进制数字组成的字符串。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| SERAREAINFO | 业务区域限制信息 | 可选必选说明：可选参数 参数含义：用于标识业务区域限制信息。 取值范围：不超过4000位的字符串。业务区域限制信息符合Json格式，具体格式请参考3GPP 29.503协议。名称和类型如下： restrictionType：业务区域限制类型。字符串枚举类型，取值可以是：ALLOWED_AREAS：允许服务区域注册的区域。NOT_ALLOWED_AREAS：不允许服务区域注册的区域。 areas：区域信息。包含以下字段：tacs：跟踪区域代码。areaCode/areaCodes：区域代码，每个区域代码代表跟踪区域的集合。29.571-f30及之前版本协议支持信元名称为areaCodes，29.571-f40及之后版本协议支持信元名称为areaCode。 maxNumOfTAs：允许跟踪区域的最大数量。最小值为0的整数类型。 格式如下：{\"restrictionType\":\"ALLOWED_AREAS\"\,\"areas\":[{\"areaCodes\":\"4305\"}]}{\"restrictionType\":\"ALLOWED_AREAS\"\,\"areas\":[{\"areaCode\":\"4305\"}]}{\"restrictionType\":\"ALLOWED_AREAS\"\,\"areas\":[{\"tacs\":[\"63F84B\"]}]\,\"maxNumOfTAs\":2} 默认值：无 配置原则： 该参数的配置需要满足Json格式，如果输入中包含“"”和“,”特殊字符，则在这些特殊字符前添加转义字符“\”。areas数组中，每一个对象中的tacs、areaCode和areaCodes同时仅允许配置1个。当restrictionType=NOT_ALLOWED_AREAS时，不需要配置参数maxNumOfTAs。业务区域限制类型不能同时配置两种枚举类型。 |

## 使用实例

若运营商需要对指定5G业务区域调整其限制管理策略，则需要修改5G业务区域信息模板。

1. 修改一条5G业务区域信息模板，“HLR序列号”为“1”，“模板ID”为“1”，“模板名”为“TPL”，“业务区域限制信息”为"{\"restrictionType\":\"ALLOWED\_AREAS\"\,\"areas\":[{\"areaCodes\":\"4305\"}]}":

   ```
   MOD SERAREATPL: HLRSN=1, TPLID=1, TPLNAME="TPL", SERAREAINFO="{\"restrictionType\":\"ALLOWED_AREAS\"\,\"areas\":[{\"areaCodes\":\"4305\"}]}";
   ```
2. 修改一条5G业务区域信息模板，“HLR序列号”为“1”，“模板ID”为“104”，“模板名”为“SERA\_Test”，“业务区域限制信息”为“{\"restrictionType\":\"ALLOWED\_AREAS\"\,\"areas\":[{\"tacs\":[\"63F84B\"]}]\,\"maxNumOfTAs\":2}”：

   ```
   MOD SERAREATPL: HLRSN=1, TPLID=104, TPLNAME="SERA_Test", SERAREAINFO="{\"restrictionType\":\"ALLOWED_AREAS\"\,\"areas\":[{\"tacs\":[\"63F84B\"]}]\,\"maxNumOfTAs\":2
   ```
3. 修改一条5G业务区域信息模板，“HLR序列号”为“1”，“模板ID”为“1”，“模板名”为“TPL”，“业务区域限制信息”为"{\"restrictionType\":\"ALLOWED\_AREAS\"\,\"areas\":[{\"areaCode\":\"4305\"}]}":

   ```
   MOD SERAREATPL: HLRSN=1, TPLID=1, TPLNAME="TPL", SERAREAINFO="{\"restrictionType\":\"ALLOWED_AREAS\"\,\"areas\":[{\"areaCode\":\"4305\"}]}";
   ```

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。
