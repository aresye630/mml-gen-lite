# 增加EPS QoS模板(ADD EPSQOSTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在数据库中增加一条EPS QoS模板数据记录。

EPS QoS（Quality of Service）机制是指EPS系统中通信系统或信道的常用性能指标之一，包括业务承载能力及业务建立时延迟等。用来衡量一个传输系统的传输质量和服务有效性，评估服务商满足客户需求的能力。

## 注意事项

- 如果对扩展QoS没有要求，扩展QoS相关的参数不需要出现。
- 同一个“HLR序列号”中增加的EPS QoS模板记录数不能超过3000条。

## 参数说明

| 参数标识           | 参数名称          | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
|:---------------|:--------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN          | HLR序列号        | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| TPLID          | QoS模板ID       | 用于标识EPS QoS模板ID。 取值范围：0～65534。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| TPLNAME        | QoS模板名        | 用于标识EPS QoS模板名称。 取值范围：60个以内的数字或英文字母组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| QOSCLASUID     | QoS分类ID       | 用于标识QoS分类ID。 取值范围：1～127。 默认值：无。 说明： 一般情况下，“QoS分类ID”数值越小，QoS等级越高。当“QoS分类ID”值在1~9之外，且大部分对端不支持1~9之外取值时，需要优先设置SET DEFREPEPSQOSID命令设置缺省的替代关系，将该模板替换为一个“QoS分类ID”取值为1~9之内的模板。对于支持的对端，由于系统已经设置了缺省替代关系，需要通过ADD REPEPSQOSID或MOD REPEPSQOSID命令，将“用户签约的EPS QoS模板ID”和“替代的EPS QoS模板ID”都设置成该EPS QoS模板的ID，从而对于这些对端，依然下发该EPS QoS模板的数据。对于不支持的对端通过系统设置缺省的替代关系，UDM提供在默认替换模板中配置的“QoS分类ID”值。 当“QoS分类ID”取值在1~9之外，且大部分对端支持1~9之外取值时：对于支持的对端无需配置替代关系。UDM提供该模板中配置的“QoS分类ID”值。对于不支持的对端只需要使用ADD REPEPSQOSID或MOD REPEPSQOSID命令添加替代EPS QoS数据的配置，将该模板替换为一个“QoS分类ID”取值为1~9之内的模板。UDM提供替换后模板中配置的“QoS分类ID”值。 |
| EXTQCI         | 扩展QoS分类ID     | 用于标识扩展QoS分类ID。当用户接入的网络是本地PLMN时（是否本地PLMN由ADD PLMNTPL命令配置）则在业务流程中UDM不下发“QoS分类ID”参数，而是下发该参数。 取值范围：128～254。 默认值：无。 说明：一般情况下，“扩展QoS分类ID”数值越小，QoS等级越高。                                                                                                                                                                                                                                                                                                                                                                                                                         |
| PRILEVEL       | 分配/保留优先级数据    | 用于标识用户在网络资源拥塞时的优先级。 取值范围：1～15级。 默认值：无。 说明：运营商可以根据接入过程、业务保持过程等，分别设置用户的优先级。用户的优先级分为15个等级，数值越小，优先级越高。                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| PREEMPTIONCAP  | 业务数据流是否能够占有能力 | 用于标识是否允许该业务数据流占有优先级相对较低的业务数据流的资源。 取值范围： ENABLE：允许。DISABLE：禁止。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| PREEMPTIONVUL  | 业务数据流是否能够被占有  | 用于标识是否允许该业务数据流丢失分配给它的资源，用于接纳一个优先级相对较高的业务数据流。 取值范围： ENABLE：允许。DISABLE：禁止。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| AMBRMAXREQBWUL | 最大请求上行带宽      | 用于标识4G网络最大请求上行带宽，即发送消息的最大带宽。 取值范围：1～4294967295，单位：bit/s 默认值：无。 说明：该参数与本命令中“NR上行速率”参数必须且只能配置一个。                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| AMBRMAXREQBWDL | 最大请求下行带宽      | 用于标识4G网络最大请求下行带宽，即接受消息的最大带宽。 取值范围：1～4294967295，单位：bit/s 默认值：无。 说明：该参数与本命令中“NR下行速率”参数必须且只能配置一个。                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| AMBRNRUL       | NR上行速率        | 用于标识5G网络UE最大上行带宽，即UE最大的上传速率。 取值范围：1～4294967295，单位：kbit/s（1kbit/s = 1000bit/s） 默认值：无。 说明：该参数与本命令中“最大请求上行带宽”参数必须且只能配置一个。如果上行速率配置该参数，则“最大请求上行带宽”参数由系统赋值为4294967295。                                                                                                                                                                                                                                                                                                                                                                                                         |
| AMBRNRDL       | NR下行速率        | 用于标识5G网络UE最大下行带宽，即UE最大的下载速率。 取值范围：1～4294967295，单位：kbit/s（1kbit/s = 1000bit/s） 默认值：无。 说明：该参数与本命令中“最大请求下行带宽”参数必须且只能配置一个。如果下行速率配置该参数，则“最大请求下行带宽”参数由系统赋值为4294967295。                                                                                                                                                                                                                                                                                                                                                                                                         |

## 使用实例

增加一个EPS QoS漫游模板数据，“HLR序列号”为1，“模板ID”为10，“模板名”为EPS-QoS，“QoS分类ID”为5,“扩展QoS分类ID”为130，“分配/保留优先级数据”为1，“业务数据流是否能够占有能力”为允许，“业务数据流是否能够被占有”为允许，“最大请求上行带宽”为100000 bit/s,“最大请求下行带宽”为200000 bit/s。命令如下:

```
ADD EPSQOSTPL: HLRSN=1, TPLID=10, TPLNAME="EPS-QoS", QOSCLASUID=5, EXTQCI=130, PRILEVEL=1, PREEMPTIONCAP=ENABLE, PREEMPTIONVUL=ENABLE, AMBRMAXREQBWUL=100000, AMBRMAXREQBWDL=200000;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|:--------|:--------|:-------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”参数不在相应的参数取值范围内。                                            | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                                    |
| ERR1009 | 参数丢失    | 可能原因为如下之一：“最大请求上行带宽”和“NR上行速率”参数未输入其中任意一个。“最大请求下行带宽”和“NR下行速率”参数未输入其中任意一个。 | 根据实际情况，重新输入参数，确保满足以下两点：“最大请求上行带宽”和“NR上行速率”两个参数必须配置一个。“最大请求下行带宽”和“NR下行速率”两个参数必须配置一个。                                                                 |
| ERR1010 | 参数冲突    | 可能原因为如下之一：“最大请求上行带宽”和“NR上行速率”参数同时输入。“最大请求下行带宽”和“NR下行速率”参数同时输入。           | 根据实际情况，重新输入参数，确保满足以下两点：“最大请求上行带宽”和“NR上行速率”两个参数只能配置一个。“最大请求下行带宽”和“NR下行速率”两个参数只能配置一个。                                                                 |
| ERR1111 | 超过最大限制  | 增加的EPS QoS模板记录数超过3000条。                                                  | 根据实际情况，如需增加EPS QoS模板记录，处理步骤如下：执行LST EPSQOSTPL命令，查询已存在EPS QoS模板记录。执行RMV EPSQOSTPL命令，删除不必要的EPS QoS模板记录。执行该命令，增加的EPS QoS模板记录，确保增加后EPS QoS模板记录数在规定范围之内。 |
| ERR3004 | 模板已存在   | “QoS模板ID”在数据库中已存在。                                                       | 根据实际情况，重新输入参数，确保输入的“QoS模板ID”和系统中已存在的不重复。可执行LST EPSQOSTPL命令查询系统中已存在的区域漫游模板。                                                                          |
| ERR3007 | 记录不存在   | “HLR序列号”未定义。                                                             | 根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求。                                                                                                                   |
