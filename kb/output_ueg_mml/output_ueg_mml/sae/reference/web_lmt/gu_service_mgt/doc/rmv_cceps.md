# 删除计费特性和EPS数据对应关系(RMV CCEPS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条计费特性和EPS数据对应关系记录。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                            |
|:----------|:-------|:--------------------------------------------------------------------------------|
| HLRSN     | HLR序列号 | 标识计费特性和EPS数据对应关系记录的关键字段之一，用于指定在哪个HLR上删除计费特性和EPS数据对应关系记录，操作员可以使用LST HLRSN命令查询获得。 |
| STDCHARGE | 标准计费特性 | 标识计费特性和EPS数据对应关系记录的关键字段之一，用于指定需要删除哪个标准计费特性和EPS数据对应关系记录，操作员可以使用LST CCEPS命令查询获得。  |

## 使用实例

删除“HLR序列号”为“1”，“标准计费特性”为“0800”的计费特性和EPS数据对应关系记录：

```
RMV CCEPS: HLRSN=1, STDCHARGE="0800";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                             | 处理建议                                                                                                 |
|:--------|:--------|:-----------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | 可能原因为如下之一：“HLR序列号”未定义。 “HLR序列号”和“标准计费特性”的对应的计费特性和EPS数据对应关系记录不存在。 | 根据实际情况，重新输入已定义的“HLR序列号”或“标准计费特性”。 已定义的“HLR序列号”可通过LST HLRSN命令查询。已存在的计费特性和EPS数据对应关系记录可通过LST CCEPS命令查询。 |
