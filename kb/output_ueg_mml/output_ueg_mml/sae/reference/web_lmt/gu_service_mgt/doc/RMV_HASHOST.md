# 删除AS主机名(RMV HASHOST)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除一条AS对端实体和数据库中的ASID间的对应关系。

## 注意事项

- 执行该命令时，只需要输入“ASID”和“主机名”参数中的一个，两个参数同时输入会返回报错“参数冲突”。
- IMS-HSS和AS间的PNR/PNA和SNR/SNA消息基于ASID和AS主机名间的对应关系进行处理，随意删除AS主机名会导致AS相关的业务异常。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                |
|:---------|:-------|:----------------------------------------------------|
| ASID     | ASID   | 用于标识需要删除的AS对端实体的Diameter对端实体标识。 取值范围：0～65534 默认值：无。 |
| HOSTNAME | 主机名    | 用于标识需要删除的AS对端实体的网络主机名。 取值范围：长度不超过127的字符串。 默认值：无。    |

## 使用实例

删除“ASID”为“1”的一条AS对端实体和ASID间的对应关系：

```
RMV HASHOST: ASID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释   | 原因分析                                 | 处理建议                                                    |
|----------:|:--------|:-------------------------------------|:--------------------------------------------------------|
| 900003495 | AS信息不存在 | 该命令输入的“ASID”或“主机名”参数标识的记录不存在，参数输入有误。 | 执行LST HASHOST查询当前的数据记录，确保需要删除的记录的“ASID”或“主机名”信息正确后重新执行。 |
| 900001009 | 参数冲突    | 执行命令时同时输入了“ASID”和“主机名”参数。            | 重新执行命令，确保只输入“ASID”和“主机名”参数中的一个。                         |
