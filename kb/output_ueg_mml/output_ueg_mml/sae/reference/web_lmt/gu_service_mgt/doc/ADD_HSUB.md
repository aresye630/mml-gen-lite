# 开户(ADD HSUB)

## 命令功能

该命令用于在HSS的业务数据库中新增一个IMS签约用户，为该IMS签约用户设置一个指定的“SUBID”，可同时为该IMS签约用户添加“IMPI”和“IMPU”，也可后续使用**ADD HIMPI**操作和**ADD HIMPU**操作为该IMS签约用户添加“IMPI”和“IMPU”。在用户进行开户时需要使用该操作。

## 注意事项

如果使用该命令新增一个IMS签约用户的同时添加一个“IMPU”，则参数“IMPI”必须指定。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|:------------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SUBID       | SUBID   | 在IMS中，一个IMS签约用户唯一对应一个SUBID。 取值范围：长度不超过127的字符串。 默认值：无。 说明：必选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| IMPI        | IMPI    | 用于指定与签约用户关联的IMPI的值，该参数必须先由增加鉴权数据的相关操作定义，然后才能在此处索引，要求输入IMPI值符合NAI格式，字母区分大小写。 取值范围：长度不超过127的字符串。 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| IMPU        | IMPU    | 用于指定一个与签约用户关联的IMPU。该参数的配置原则是：新开的IMPU必须与已有的IMPU不同。输入的IMPU值符合SIP URI或TEL URI格式，字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数，当该参数存在时，IMPI必须存在。当IMPU为通配类型时，IMPU的格式必须含有“!.*!”且符合TEL URI和SIP URI格式的通配IMPU规则，目前支持以下4种格式，以固定号码为3314529的SIP URI格式举例如下：格式1：sip:3314529!.*!@huawei.com。格式2：sip:3314529![mnp].*!@huawei.com。例如sip:3314529![247].*!@huawei.com，以下号码可以匹配：sip:33145292!.*!@huawei.com sip:33145294!.*!@huawei.com sip:33145297!.*!@huawei.com 格式3：sip:3314529![m-p].*!@huawei.com。例如sip:3314529![2-4].*!@huawei.com，以下号码可以匹配：sip:33145292!.*!@huawei.com sip:33145293!.*!@huawei.com sip:33145294!.*!@huawei.com 格式4：格式2和格式3的混合格式。例如sip:3314529![02-57-9].*!@huawei.com，以下号码可以匹配：sip:33145290!.*!@huawei.com sip:33145292!.*!@huawei.com sip:33145293!.*!@huawei.com sip:33145294!.*!@huawei.com sip:33145295!.*!@huawei.com sip:33145297!.*!@huawei.com sip:33145298!.*!@huawei.com sip:33145299!.*!@huawei.com 注意事项： 对于格式2、格式3和格式4，要求m、n、p只能代表取值范围为0-9的一位数字（m<n<p），并且m、n、p的取值不能重复。 上述4种格式号码配置时不能出现号段重复，比如通配IMPU号码sip:3314529!.*!@huawei.com和sip:3314529![247].*!@huawei.com就含有sip:33145292!.*!@huawei.com、sip:33145294!.*!@huawei.com和sip:33145297!.*!@huawei.com三个重复号段，是不允许同时配置的。 |
| IMPUTYPE    | IMPU的类型 | 用于标识新增IMPU的类型。 取值范围：DIMPU(DIMPU)：表示新增的IMPU为非通配型。WIMPU(WIMPU)：表示新增的IMPU为通配型。 默认值：DIMPU(DIMPU)。 说明：当IMPU存在时该参数为可选参数，否则不存在。一个通配IMPU代表一组IMPU。该通配IMPU或者一个能匹配到此通配IMPU的特定IMPU（specific IMPU）发起注册，均能达到注册整组IMPU的目的。注册完成后，所有匹配到该通配IMPU的特定IMPU（specific IMPU）均能够在HSS取到相同的业务签约数据和路由信息。系统允许添加的通配IMPU和通配PUSI数量根据不同的保存方式有所不同。保存在DRU：最多可添加120000个。保存在DSU：无数量限制。 说明：通配用户数据保存方式依赖于运营商的配置需求，在开局阶段必须指定，若运营商无配置需求，则默认保存于DRU中。配置命令可参见SET HSYSTEMPARA。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| PBXUSERFLAG | PBX用户标识 | 用于标识一个IMS签约用户是否PBX用户。PBX指Private Branch eXchange，PBX用户通常指总分机用户，应用时公布总机号码，分机不分配公网号码，以通配的方式接入IMS网络。 取值范围: TRUE(TRUE)：PBX用户。FALSE(FALSE)：非PBX用户。 默认值：FALSE（FALSE）。 说明：可选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| SYSNO       | 系统序列号   | 用于标识一个IMS签约用户属于哪个虚拟HSS。通过ADD HLRSN定义，然后才能在此处索引。 取值范围：0～255 默认值：0 说明：可选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |

## 使用实例

1. 开户，“SUBID”为“+8675556671001@domain7.huawei.com”，“IMPI”为“+8675500@huawei.com”，“IMPU”为“sip:33145294!.\*!@huawei.com”，“PBX用户标识”为“FALSE(FALSE)”：

```
ADD HSUB: SUBID="+8675556671001@domain7.huawei.com", IMPI="+8675500@huawei.com", IMPU="sip:33145294!.*!@huawei.com", PBXUSERFLAG=FALSE;
```

2. 开户，“SUBID”为“+862970119992@domain50.huawei.com”，“IMPI”为“+862986010343@huawei.com”，“IMPU”为“sip:3314529!.\*!@huawei.com”，“IMPUTYPE”为“WIMPU(WIMPU)”，“PBX用户标识”为“FALSE(FALSE)”，“系统序列号”为“1”：

```
ADD HSUB: SUBID="+862970119992@domain50.huawei.com", IMPI="+862986010343@huawei.com", IMPU="sip:3314529!.*!@huawei.com", IMPUTYPE=WIMPU, PBXUSERFLAG=FALSE, SYSNO=1;
```
