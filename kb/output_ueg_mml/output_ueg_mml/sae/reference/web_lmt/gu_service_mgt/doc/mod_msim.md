# 修改多SIM业务(MOD MSIM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此操作用于给用户签约、去签约以及修改多SIM业务。

## 注意事项

- IMSI和ISDN是条件可选参数，有且只能有一个参数出现。
- 如果PROV=TRUE，MSIMTYPE参数必须设置；如果PROV=FALSE，MSIMTYPE参数不必设置。
- 如果用户已经使用**MOD COMISDN**命令签约了COMISDN业务，则不能同时签约多SIM业务。
- 如果用户签约了多SIM业务，则需要执行**MOD COMISDN**命令为多SIM群组增加成员。该用户可绑定的IMSI个数可通过**SET MAPSERV**命令中的“单个Multi SIM用户支持的最大IMSI个数”参数配置。
- 多SIM业务还与其他许多业务存在冲突，不能同时签约。这些业务包括：一卡多号、一号多卡、一卡多号多Profile、GROUPSIM、FM、VVDN、ALS、LINKED SIM、M2M COMISDN和M2M ISDN-Less。
- 融合HSS和IMS-HSS分离部署场景下不支持**MOD MSIM**命令中的“是否限制非激活号码的主叫业务”功能。
- 仅在**SET MAPCONF**命令中的“是否支持多SIM增强业务”取值为“TRUE”时才可以设置“是否限制非激活号码的主叫业务”功能。

## 参数说明

| 参数标识       | 参数名称           | 参数说明                                                                                                                                                                                                                                                                                                                                     |
|:-----------|:---------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI       | 主IMSI号码        | 多SIM群组主用户的IMSI号码。 取值范围：E.212格式的编码，为6～15位的十进制数字。 缺省值：无                                                                                                                                                                                                                                                                                    |
| ISDN       | 主MSISDN号码      | 多SIM群组主用户的MSISDN号码。 取值范围：E.164格式的编码，为1～15位的十进制数字。 缺省值：无                                                                                                                                                                                                                                                                                  |
| PROV       | 是否提供多SIM业务     | 此参数用于设置用户是否提供多SIM业务。 取值范围： TRUE：提供 FALSE：不提供 说明：必选参数。                                                                                                                                                                                                                                                                                    |
| MSIMTYPE   | 多SIM业务类型       | 仅当本命令中的“是否提供多SIM业务”参数为“TRUE”时该参数有效。此参数用于设置多SIM群组的业务类型。 取值范围： ActiveByUPL：以最近一次位置登记的用户为激活用户 ActiveByUSSD：通过USSD操作设置激活用户                                                                                                                                                                                                                   |
| RESTRICTMO | 是否限制非激活号码的主叫业务 | 仅当本命令中的“是否提供多SIM业务”参数为“TRUE”时该参数有效。用于标识UDM是否限制签约多SIM增强业务的非激活用户进行语音呼叫及短消息始发。 取值范围： FALSE：不限制语音呼叫及短消息始发TRUE：限制语音呼叫及短消息始发VOICE_TRUE：只限制语音呼叫SMS_TRUE：只限制短消息始发 缺省值：无。 说明： 当SET MAPCONF与MOD MSIM同时设置“是否限制非激活号码的主叫业务”功能时，MOD MSIM命令设置的取值优先级高于SET MAPCONF。不使用MOD MSIM配置“是否限制非激活号码的主叫业务”功能时，系统将该参数设置为255，表示由SET MAPCONF命令“是否限制非激活号码的主叫业务”参数的取值控制。 |

## 使用实例

1. 为IMSI号码为460030912000001的用户签约多SIM业务，多SIM业务类型为ActiveByUPL。

   MOD MSIM: IMSI="460030912000001", PROV=TRUE, MSIMTYPE=ActiveByUPL;
2. 为IMSI号码为460030912000001的用户撤销多SIM业务。

   MOD MSIM: IMSI="460030912000001", PROV=FALSE;

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 消息解释                      | 原因分析                                                                       | 处理建议                                                                   |
|:--------|:--------------------------|:---------------------------------------------------------------------------|:-----------------------------------------------------------------------|
| ERR4134 | 只有多SIM增强业务才可以签约RESTRICTMO | SET MAPCONF命令中的“是否支持多SIM增强业务”取值为“FALSE”时，使用MOD MSIM命令设置“是否限制非激活号码的主叫业务”功能。 | 执行LST MAPCONF命令，确认“EMSIM”取值为“TRUE”时，再使用MOD MSIM命令设置“是否限制非激活号码的主叫业务”功能。 |
