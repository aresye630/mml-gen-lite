# 删除主叫号码智能业务策略(RMV CALLINGCAMEL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条主叫号码智能业务策略记录，在该命令中，系统通过以下关键参数的组合来唯一标识一条主叫号码智能业务策略：

- “HLR序列号”
- “主叫号码”

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                   |
|:--------------|:-------|:-----------------------------------------------------------------------|
| HLRSN         | HLR序列号 | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                           |
| CALLINGNUMBER | 主叫号码   | 用于标识一个待删除智能业务策略的主叫号码前缀。在业务处理时，按照前缀最大匹配原则进行匹配。 取值范围：1～15位的十进制数字。 默认值：无。 |

## 使用实例

删除一条“HLR序列号”为“1”，“主叫号码”为“12345678912”的主叫号码智能业务策略记录：

```
RMV CALLINGCAMEL: HLRSN=1, CALLINGNUMBER="12345678912";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                         | 处理建议                                                                         |
|:--------|:--------|:---------------------------------------------|:-----------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 参数“主叫号码”的取值不是1～15位十进制数字组成的字符串。               | 根据实际情况，重新输入参数“主叫号码”的取值，确保其取值符合要求。                                            |
| ERR3007 | 记录不存在   | 参数“HLR序列号”和“主叫号码”对应的记录不存在，无法删除对应的主叫号码智能业务策略。 | 使用LST CALLINGCAMEL命令查询系统中已存在的主叫号码智能业务策略，根据查询结果中存在的记录，重新输入“HLR序列号”和“主叫号码”参数值。 |
