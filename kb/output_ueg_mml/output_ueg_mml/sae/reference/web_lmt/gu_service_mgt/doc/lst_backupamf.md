# 查询备份AMF信息(LST BACKUPAMF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询备份AMF信息:

- 若要查询所有备份AMF信息，请不要输入任何参数。
- 若要查询部分备份AMF信息，请输入一种参数或是多种参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                 |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------|
| MCC    | 移动国家码  | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个移动国家码来查询AMF备用信息；若不输入，则表示所有的AMF备用信息。 取值范围：3位十进制数字组成的字符串。 默认值：无。 配置原则：无。    |
| MNC    | 移动网络码  | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个移动网络码来查询AMF备用信息；若不输入，则表示所有的AMF备用信息。 取值范围：2或3位的十进制数字组成的字符串。 默认值：无。 配置原则：无。 |
| AMFID  | AMF标识  | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个AMF标识来查询AMF备用信息；若不输入，则表示所有的AMF备用信息。 取值范围：6位十六进制的字符串。 默认值：无。 配置原则：无。       |

## 使用实例

1. 查询所有备用AMF信息。

   ```
   LST BACKUPAMF:;
   ```

   ```
   %%LST BACKUPAMF:;%%
   RETCODE = 0 SUCCESS0001:操作成功

   MCC         MNC         AMFID       BK_FQDN          BK_MCC      BK_MNC      BK_AMFID    Timestamp
   460         06          123123      huawei.com       123         123         123123      2020-04-17 01:37:11
   460         06          123456      huawei.com       NULL        NULL        NULL        2020-04-17 01:16:47
   460         06          123456      huawei.com       460         999         654321      2020-04-17 00:45:07

   Total count = 3

   There is together 1 report

   ---    END
   ```
2. 查询部分备用AMF的信息，“移动国家码”为“460”，“移动网络码”为“06”，“AMF标识”为“123456”。

   ```
   LST BACKUPAMF: MCC="460", MNC="06", AMFID="123456";
   ```

   ```

   Total count = 2

   There is together 1 report

   ---    END
   ```
