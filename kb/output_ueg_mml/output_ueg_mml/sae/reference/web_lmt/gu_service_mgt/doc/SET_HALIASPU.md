# 设置别名组ID(SET HALIASPU)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

别名IMPU组是指IMPU隐式注册集中共享Service Profile的IMPU组成的一个集合。该命令用于在HSS的业务数据库中设置多个IMPU为一个别名IMPU组。使用场景有：

- 完全新增一个别名组。
- 向一个已存在的“别名IMPU组ID”对应的别名IMPU组中增加IMPU。
- 从一个已存在的别名IMPU组中删除IMPU或完全删除此别名IMPU组。

## 注意事项

- 完全新增一个别名组时必须满足以下要求：

  - 参数“IMPU别名组ID”不为“0”。
  - “IMPU别名组ID”在“IMPU列表”归属的IMS签约用户中未被使用。
  - “IMPU列表”中的IMPU的个数大于等于两个。
  - “IMPU列表”中的IMPU属于同一个隐式注册集且共享Service Profile。
  - “IMPU列表”中的IMPU一致性标识必须一致。
- 向一个已存在的“IMPU别名组ID”对应的别名IMPU组中增加IMPU时必须满足以下要求：

  - 参数“IMPU别名组ID”不为“0”。
  - “IMPU别名组ID”在“IMPU列表”归属IMS签约用户中已存在。
  - “IMPU列表”中的IMPU的个数至少为1。
  - “IMPU列表”中的IMPU和“IMPU别名组ID”对应的别名IMPU组属于同一个隐式注册集且共享Service Profile。
  - “IMPU列表”中的IMPU和“IMPU别名组ID”对应的别名IMPU组中的IMPU一致性标识必须一致。
- 从一个已存在的“IMPU别名组ID”对应的别名IMPU组中删除IMPU或完全删除此别名IMPU组时必须满足以下要求：

  - 参数“IMPU别名组ID”设为“0”。
  - “IMPU列表”中的IMPU必须归属于相同的别名IMPU组。
  - 当“IMPU别名组ID”对应的别名IMPU组中无IMPU或只有一个IMPU时，此别名IMPU组被自动删除。
- 一个IMPU只能属于一个“IMPU别名组ID”。

## 参数说明

| 参数标识     | 参数名称      | 参数说明                                                                                                                                                                                                                                                                     |
|:---------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ALIASID  | IMPU别名组ID | 用于指定一个别名IMPU组ID。取值为“0”时表示把指定的IMPU从别名组中删除。 取值范围：0~255 默认值：无。 说明：必选参数。                                                                                                                                                                                                     |
| IMPULIST | IMPU列表    | 用于指定要添加或者从别名组中删除的成员。该参数的配置原则是：由1到10个IMPU以“&”连接组成（例如："sip:impuinfo1@huawei.com"&"sip:impuinfo2@huawei.com"，在字符"前需要添加转义字符\）。该参数中的IMPU必须先由ADD HSUB、ADD HIMPI、ADD HIMPU或ADD HTPLIMPU命令定义，然后才能在此处索引。要求输入的IMPU值符合SIP URI或TEL URI格式，字母区分大小写。 取值范围：长度不超过1300的字符串 默认值：无。 说明：必选参数。 |

## 使用实例

1. 新增别名组，“ALIASID”为“1”，“IMPU列表”为**"sip:impuinfo\_1@huawei.com"&"sip:impuinfo\_2@huawei.com"**：

   ```
   SET HALIASPU: ALIASID=1, IMPULIST="\"sip:impuinfo_1@huawei.com\"&\"sip:impuinfo_2@huawei.com\"";
   ```
2. 向已有的别名组中增加IMPU，“ALIASID”为“1”，“IMPU列表”为**"sip:impuinfo\_3@huawei.com"&"sip:impuinfo\_4@huawei.com"**：

   ```
   SET HALIASPU: ALIASID=1, IMPULIST="\"sip:impuinfo_3@huawei.com\"&\"sip:impuinfo_4@huawei.com\"";
   ```
3. 从已有的别名组中删除IMPU，“ALIASID”为“0”，“IMPU列表”为**"sip:impuinfo\_4@huawei.com"**：

   ```
   SET HALIASPU: ALIASID=0, IMPULIST="\"sip:impuinfo_4@huawei.com\"";
   ```
