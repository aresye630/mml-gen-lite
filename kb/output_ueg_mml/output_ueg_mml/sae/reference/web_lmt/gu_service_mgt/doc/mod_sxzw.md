# 修改DNN/APN替换业务(MOD SXZW)

## 命令功能

该命令用于为用户提供、撤销或修改DNN/APN替换业务。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。
- 仅当**SET UDMSERV**命令“DNN/APN替换业务是否免用户签约”参数取值为“FALSE”时可以执行该命令。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                               |
|:------------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 可选必选说明：条件可选参数 参数含义：用于标识需要修改DNN/APN替换业务的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                            |
| ISDN        | MSISDN    | 可选必选说明：条件可选参数 参数含义：用于标识需要修改DNN/APN替换业务的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                  |
| RECORDCOUNT | 用户个数      | 可选必选说明：条件可选参数 参数含义：用于标识需要修改DNN/APN替换业务的用户数目。 当需要为连续号码的多个用户修改DNN/APN替换业务时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户修改DNN/APN替换业务。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户修改DNN/APN替换业务，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名   | 可选必选说明：条件可选参数 参数含义：用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要修改DNN/APN替换业务的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modsxzw.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或十进制数字组成的字符串。 默认值：无。                                                        |
| ISDNFILE    | MSISDN文件名 | 可选必选说明：条件可选参数 参数含义：用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要修改DNN/APN替换业务的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modsxzw.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或十进制数字组成的字符串。 默认值：无。                                                  |
| CTRLSCHE    | 业务码       | 可选必选说明：必选参数 参数含义：用于标识DNN/APN替换业务类型。 取值范围：1～30位的字符串，有效取值如下所示。SXZW：表示签约4G&5G DNN/APN替换业务。4GSXZW：表示签约4G APN替换业务。5GSXZW：表示签约5G DNN替换业务。*：表示去签约4G&5G DNN/APN替换业务。其他字符串形式：表示签约4G&5G DNN/APN替换业务。该参数必须先由ADD DNNREPRULETPL命令定义，然后才能在此处引用。 默认值：无。 配置原则：字母不区分大小写。            |

## 使用实例

1. 给IMSI号码为“460000009123456”的用户提供DNN/APN替换业务，“业务码”为“SXZW”。

   ```
   MOD SXZW: IMSI="460000009123456", CTRLSCHE="SXZW";
   ```
2. 给3个连续号码的用户提供DNN/APN替换业务，这3个MSISDN号码分别为“13310911001”、“13310911002”、“13310911003”，“业务码”为“4GSXZW”。

   ```
   MOD SXZW: ISDN="13310911001", RECORDCOUNT=3, CTRLSCHE="4GSXZW";
   ```
3. 给3个非连续号码的用户撤销DNN/APN替换业务，这3个MSISDN号码分别为“13310911001”、“13310911003”、“13310911005”，已保存在“MSISDN文件名”为“modsxzw.txt”的文件中，并通过文件管理功能上传到指定目录，“业务码”为“\*”。

   ```
   MOD SXZW: ISDNFILE="modsxzw.txt", CTRLSCHE="*";
   ```

## 参考信息

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
