# 增加NGS对端类型（ADD NGSPETYPE）

## 命令功能

**须知** 

该命令属于高危命令，执行不当会影响用户的漫游业务，影响在网用户业务体验。因此执行该命令前，请仔细评估当前操作的风险，确认对业务没有影响后方可执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用于给5G用户在UDM中增加对端类型数据，定义对端所属的网络类型，包括国际、国内、本网等。

- 可以通过该命令在UDM中增加AMF/SMF/SMSF等网元相对于本地UDM的位置信息。
- 当用户需要签约5G漫游闭锁业务时，可以通过该命令签约AMF/SMF/SMSF的业务属性以识别具体的闭锁限制。

## 注意事项

- 同一个“HLR序列号”中增加的“AMF身份类型”记录数不能超过5000条。
- 同一个“PLMNID”中增加的“PLMNID”、“AMF Region ID”或“AMF Set ID”记录数不能超过999条。
- 执行该命令配置SMF的对端业务属性时，“AMF身份类型”参数取值为“PLMN”。

| PEERNAME  | 对端名称            | 可选必选说明：可选参数 参数含义：用于标识对端名称。 取值范围：长度不超过30的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                  |

## 使用实例

当用户需要签约5G漫游闭锁业务时，需要先在UDM配置AMF属性，通过AMF属性的识别来实现5G漫游闭锁业务。配置举例如下：

1. 在“HLR序列号”为“3”的UDM上添加“业务属性”为“LOCAL”的身份类型。其中“AMF身份类型”为“PLMN”、“PLMNID”为“11111”：

   ```
   ADD NGSPETYPE: HLRSN=3, PETYPE=PLMN, PLMN="11111", TYPE=LOCAL;
   ```
2. 在“HLR序列号”为“1”的UDM上添加“业务属性”为“LOCALDOMESTIC”的身份类型。其中“AMF身份类型”为“AMFREGION”、“PLMNID”为“11111”、“AMF Region ID”为“2”：

   ```
   ADD NGSPETYPE: HLRSN=1, PETYPE=AMFREGION, PLMN="11111", AMFREGION=2, TYPE=LOCALDOMESTIC;
   ```
