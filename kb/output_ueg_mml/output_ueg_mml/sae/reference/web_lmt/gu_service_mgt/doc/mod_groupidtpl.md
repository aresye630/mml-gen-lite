# 修改组ID模板(MOD GROUPIDTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该操作会修改组ID模板数据，是否继续？

该命令用于对一条组ID模板数据记录的某些参数进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一条组ID模板数据记录：

- “HLR序列号”
- “模板ID”
- “组类型”

## 注意事项

- 执行该命令修改模板数据后，已经签约被修改模板的用户，其签约数据不会被同步修改；后续再签约此模板的用户将使用修改后的模板数据。
- 系统中同一个VGCS模板增加的VGCS数据记录数不能超过50条，且所有VGCS模板增加的VGCS数据总记录数不能超过3000条。
- 系统中同一个VBS模板增加的VBS数据记录数不能超过50条，且所有VBS模板增加的VBS数据总记录数不能超过3000条。

## 参数说明

| 参数标识                    | 参数名称                  | 参数说明                                                                                                                                                                                                                            |
|:------------------------|:----------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN                   | HLR序列号                | 标识组ID模板数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR中组ID模板数据记录的参数进行修改或调整，操作员可以使用LST HLRSN命令查询获得。                                                                                                                                           |
| TPLID                   | 模板ID                  | 标识组ID模板数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪个模板数据记录的参数进行修改或调整，操作员可以使用LST GROUPIDTPL命令查询获得。                                                                                                                                             |
| TPLNAME                 | 模板名                   | 用于标识待修改模板在系统中的名称。 取值范围：1～60个字母或十进制数字组成的字符串 默认值：无。                                                                                                                                                                               |
| GROUPTYPE               | 组类型                   | 标识组ID模板数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪种组呼类型数据记录的参数进行修改或调整，操作员可以使用LST GROUPIDTPL命令查询获得。                                                                                                                                           |
| CAPINITONROAMING        | 初始化组呼能力               | 用于标识当用户漫游出归属PLMN（Public Land Mobile Network）时，是否支持初始化组呼业务的能力。 取值范围：TRUE：支持初始化组呼业务的能力。 FALSE：不支持初始化组呼业务的能力。 默认值：无。                                                                                                               |
| OPTYPE                  | 操作类型                  | 仅当本命令中的“组类型”参数为“VGCS”或“VBS”时该参数有效。用于标识执行该命令实现的操作类型。 取值范围：ADD：表示在该模板中增加新的“组ID”数据。 MODIFY：仅当本命令中的“组类型”参数为“VBS”时该参数有效。表示修改该模板中已存在的“组ID”数据。 DELETE：表示删除该模板中已存在的“组ID”数据。 默认值：无。                                                      |
| COUNT                   | 组ID个数                 | 仅当本命令中的“操作类型”参数为“ADD”、“MODIFY”或“DELETE”时该参数有效。用于标识组ID模板中组ID的个数，每个组ID模板最多可以设置50个组ID。 取值范围：当“操作类型”参数为“ADD”时，取值范围为1～50。当“操作类型”参数为“MODIFY”或“DELETE”时，其值只能为1。 默认值：当“操作类型”参数为“ADD”时无默认值。当“操作类型”参数为“MODIFY”或“DELETE”时默认值为1。            |
| GROUPID1-GROUPIDX       | 组ID1～组IDX             | 仅当本命令中的“组ID个数”参数为“1”～“50”时该参数有效。用于标识组呼ID。将业务用户划分为不同的功能组，用组呼ID标识。业务用户签约组呼业务时将组呼ID存储在UDM中，同时组呼ID也需要存储在业务用户的手机SIM卡中。业务用户在组呼区域中通过拨打组呼ID发起组呼。 取值范围：1～8位十进制数字组成的字符串。 默认值：无。 说明：当SET MAPCONF命令中“是否支持GT800业务”为“FALSE”时，取值范围为0～99999999。 |
| CAPINITVBS1-CAPINITVBSX | VBS组呼1发起能力～VBS组呼X发起能力 | 仅当本命令中的“组类型”参数为“VBS”并且“组ID个数”参数为“1”～“50”时该参数有效。用于标识用户在归属PLMN时，是否支持初始化VBS组呼业务的能力。 取值范围：TRUE：支持初始化VBS组呼业务的能力 FALSE：不支持初始化VBS组呼业务的能力 默认值：无。                                                                                        |

## 使用实例

1. 给一个“组类型”为“VGCS”的组ID模板增加新的组ID数据。其中“HLR序列号”为“1”，“模板ID”为“1”，“组类型”为“VGCS”，“操作类型”为“ADD”，“组ID个数”为“2”，“组ID1”为“1111”，“组ID2”为“1112”：

   ```
   MOD GROUPIDTPL: HLRSN=1, TPLID=1, GROUPTYPE=VGCS, OPTYPE=ADD, COUNT=2, GROUPID1="1111", GROUPID2="1112";
   ```
2. 给一个“组类型”为“VBS”的组ID模板修改组ID数据，将“VBS组呼1发起能力”由“TRUE”修改为“FALSE”。其中“HLR序列号”为“1”，“模板ID”为“1”，“组类型”为“VBS”，“操作类型”为“MODIFY”，“组ID个数”为“1”，“组ID1”为“1111”，“VBS组呼1发起能力”为“FALSE”：

   ```
   MOD GROUPIDTPL: HLRSN=1, TPLID=1, GROUPTYPE=VBS, OPTYPE=MODIFY, COUNT=1, GROUPID1="1111", CAPINITVBS1=FALSE;
   ```
3. 给一个“组类型”为“VGCS”的组ID模板删除组ID数据。其中“HLR序列号”为“1”，“模板ID”为“1”，“组类型”为“VGCS”，“操作类型”为“DELETE”，“组ID个数”为“1”，“组ID1”为“1112”：

   ```
   MOD GROUPIDTPL: HLRSN=1, TPLID=1, GROUPTYPE=VGCS, OPTYPE=DELETE, COUNT=1, GROUPID1="1112";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                                                                                    | 处理建议                                                                                                                                                                                                |
|:--------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | 可能原因为如下之一：“HLR序列号”和“模板ID”对应的组ID模板数据记录不存在。 需要修改的模板的“模板ID”和“组类型”不匹配。 当“组类型”为“VBS”、“操作类型”为“MODIFY”时，输入的“组IDX”在数据库中不存在。当“操作类型”为“DELETE”时，输入的“组IDX”在数据库中不存在。 | 使用LST GROUPIDTPL命令查询后，重新确认要修改哪个“HLR序列号”和“模板ID”对应的组ID模板数据记录。使用LST GROUPIDTPL命令查询后，重新确认需要修改的模板的“模板ID”和“组类型”的匹配关系。当“组类型”为“VBS”、“操作类型”为“MODIFY”时，确保数据库中存在相应的“组IDX”。当“操作类型”为“DELETE”时，确保数据库中存在相应的“组IDX”。 |
| ERR3004 | 记录已存在   | 当“操作类型”选择“ADD”时，操作输入的“组IDX”在数据库中已存在。                                                                                                                    | 根据实际情况，重新输入参数，保证输入的“组IDX”和系统中已存在的组ID不重复。查询系统中的已存在组ID可使用命令LST GROUPIDTPL。                                                                                                                            |
| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”、“模板ID”和“组类型”参数不在相应的参数取值范围内。                                                                                                              | 根据实际情况，重新输入“组IDX”的取值，确保其取值符合要求。                                                                                                                                                                     |
| ERR3047 | 超过最大限制  | 可能原因为如下之一：同一个VGCS模板增加的“组ID个数”数据记录数超过50条。所有VGCS模板增加的“组ID个数”总记录数超过3000条。同一个VBS模板增加的“组ID个数”数据记录数超过50条。所有VBS模板增加的“组ID个数”总记录数超过3000条。                        | 根据实际情况，如需增加组ID，处理步骤如下：执行LST GROUPIDTPL命令，查询已存在的组ID。执行该命令删除不必要的组ID。执行该命令增加组ID，确保增加的组ID在规定范围之内。                                                                                                       |
