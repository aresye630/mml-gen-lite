# 模板方式修改5G数据（MOD TPLNGS）

- 命令功能

## 命令功能

该命令用于对已经签约5GS业务的一个或多个用户使用，用来修改5GS业务数据。

- 若需要使用模板方式修改单个用户的5G数据，请输入“IMSI”或“MSISDN”。
- 若需要使用模板方式修改多个连续用户的5G数据，请输入“IMSI”或“MSISDN”与“用户个数”的组合。
- 若需要使用模板方式修改多个不连续用户的5G数据，请输入“IMSI文件名”或“MSISDN文件名”。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。
- “用户个数”必须与“IMSI”或“MSISDN”中的一个同时存在。
- “5GS漫游限制模板”与“5GS用户数据模板”至少要配置一个。
- 用户签约5G虚拟网络组时，对于同一个“切片标识”和“数据网名称”下的5G虚拟网络组，建议用户只签约一个。

## 使用实例

1. 对一个或者多个已签约5G数据的用户，使用已定义的“5GS漫游限制模板”与“5GS用户数据模板”，修改用户签约5G业务。
   1. 给“IMSI”为“46100000912345”的5G用户使用模板方式修改5G数据，“5GS漫游限制模板”的ID为“3”，“5GS用户数据模板”的ID为“6”，命令如下:

      ```
      MOD TPLNGS: IMSI="46100000912345", NGCNODETPL_ID=3, NGSUSERTPLID=6;
      ```
   2. 批量为“IMSI”首号码为“461000009012346”的连续3个5G用户使用模板方式修改5G数据，“5GS漫游限制模板”的ID为“3”，“5GS用户数据模板”的ID为“6”，命令如下：

      ```
      MOD TPLNGS: IMSI="461000009012346", RECORDCOUNT=3, NGCNODETPL_ID=3, NGSUSERTPLID=6;
      ```
2. 给IMSI为“460031200100003”的4G用户使用模板方式修改5G数据，“5GS用户数据模板”的ID为“10”，将“旧DNN名称列表”为"Enet.com"^"Fnet.com"、“旧的切片列表”为"123-B123C4"^"234-B123C4"替换为“新DNN名称列表”为"Gnet.com"^"Hnet.com"、“新的切片列表”为"123-B123D4"^"234-B123D4"，命令如下：

   ```
   MOD TPLNGS: IMSI="460031200100003", NGSUSERTPLID=10,OLDDNNLIST="\"Enet.com\"&\"Fnet.com\"", NEWDNNLIST="\"Gnet.com\"&\"Hnet.com\"", 
   OLDNSSAILIST="\"123-B123C4\"^\"234-B123C4\"", NEWNSSAILIST="\"123-B123D4\"^\"234-B123D4\"";
   ```
3. 为“IMSI”为“460000009123456”的已经开通5G业务的用户签约CAG数据，“5GS用户数据模板”的ID为“1”，“PLMNID”为“111111”，“是否只允许UE通过CAG小区接入5GS”为“TRUE”，“CAGID”为“11111111”，命令如下：

   ```
   MOD TPLNGS: IMSI="460000009123456", NGSUSERTPLID=1, PLMNID="111111", CAGONLY=TRUE, CAGID="11111111";
   ```

该命令执行正常，会返回命令执行成功的提示信息。
