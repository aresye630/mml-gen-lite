# 查询主叫号码智能业务策略(LST CALLINGCAMEL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询指定的主叫号码前缀签约的智能业务策略或者一个虚拟HLR中的所有主叫号码智能业务策略。

- 若需要查询一条主叫号码的智能业务策略记录，请输入参数“HLR序列号”和“主叫号码”。
- 若需要查询一个虚拟HLR中的所有主叫号码智能业务策略，请输入参数“HLR序列号”。

## 注意事项

无。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                                                   |
|:--------------|:-------|:-----------------------------------------------------------------------|
| HLRSN         | HLR序列号 | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                           |
| CALLINGNUMBER | 主叫号码   | 用于标识一个待查询智能业务策略的主叫号码前缀。在业务处理时，按照前缀最大匹配原则进行匹配。 取值范围：1～15位的十进制数字。 默认值：无。 |

## 使用实例

1. 查询“HLR序列号”为“1”，“主叫号码”为“123456789012”的主叫号码智能业务策略记录：

   ```
   LST CALLINGCAMEL: HLRSN=1, CALLINGNUMBER="123456789012";
   ```

   ```
   %%LST CALLINGCAMEL: HLRSN=1, CALLINGNUMBER="123456789012";%%
   RETCODE = 0 SUCCESS0001:Operation is successful

                  "CALLINGNUMBER"      "TCSIRULE"
                  123456789012         ALL_PLMN

   Total count = 1

   There is together 1 report

   ---    END
   ```
2. 查询“HLR序列号”为“1”下的所有主叫号码智能业务策略记录：

   ```
   LST CALLINGCAMEL: HLRSN=1;
   ```

   ```
   %%LST CALLINGCAMEL: HLRSN=1;%%
   RETCODE = 0 SUCCESS0001:Operation is successful

                  "CALLINGNUMBER"      "TCSIRULE"
                  123456789012         HPLMN
                  138                  HPLMNC

   Total count = 2

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                         | 处理建议                                                                                              |
|:--------|:--------|:---------------------------------------------|:--------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 参数“主叫号码”的取值不是1～15位十进制数字组成的字符串。               | 根据实际情况，重新输入参数“主叫号码”的取值，确保其取值符合要求。                                                                 |
| ERR3007 | 记录不存在   | 参数“HLR序列号”和“主叫号码”对应的记录不存在，无法查询对应的主叫号码智能业务策略。 | 核实要查询的“HLR序列号”和“主叫号码”，如果确定输入无误，证明该主叫号码前缀并未签约智能业务策略或该虚拟HLR下未配置主叫号码智能业务策略，否则重新输入正确的“HLR序列号”和“主叫号码”。 |
