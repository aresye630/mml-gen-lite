# 查询UE级别EPS用户AMBR数据(LST EPSAMBR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询EPS用户的AMBR数据。

- 若需要查询单个用户的AMBR数据，请输入“IMSI”或“MSISDN”。
- 若需要查询多个连续用户的AMBR数据，请输入“IMSI”或“MSISDN”与“用户个数”的组合。
- 若需要查询多个不连续用户的AMBR数据，请输入“IMSI文件名”或“MSISDN文件名”。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                  |
|:------------|:----------|:--------------------------------------|
| IMSI        | IMSI      | 用于指示系统按照哪个IMSI号码来查询EPS用户的AMBR数据。      |
| ISDN        | MSISDN    | 用于指示系统需要按照哪个MSISDN号码来查询EPS用户的AMBR数据。  |
| RECORDCOUNT | 用户个数      | 用于指示系统需要查询连续多少个EPS用户的AMBR数据。          |
| IMSIFILE    | IMSI文件名   | 用于指示系统需要按照哪个IMSI文件名来查询EPS用户的AMBR数据。   |
| ISDNFILE    | MSISDN文件名 | 用于指示系统需要按照哪个MSISDN文件名来查询EPS用户的AMBR数据。 |

## 使用实例

1. 查询IMSI号码为“460000009123456”的EPS用户的AMBR数据：

   ```
   LST EPSAMBR: IMSI="460000009123456";
   ```

   ```

   ```

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见

**MOD EPSAMBR**

命令的参数说明，表1列出的是未包含在

**MOD EPSAMBR**

命令参数说明中的输出项。

| 输出项名称   | 输出项解释                                      |
|:--------|:-------------------------------------------|
| 批操作ID   | 用于返回批操作的任务号。通过执行CHK BATSTAT命令可以查询该任务的详细信息。 |
