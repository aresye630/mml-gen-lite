# 修改MSC号码(MOD MSCNUM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改用户的MSC号码。

该命令属于调试命令，正常情况下不使用，只有在进行系统调试或问题处理时才有可能使用。

## 注意事项

- 正常情况下，位置更新可以自动更新用户当前的MSC号码，因此应避免用该命令随意修改用户的MSC号码，否则可能导致用户无法作被叫等问题。
- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                    |
|:------------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 用于标识需要修改MSC号码的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                  |
| ISDN        | MSISDN    | 用于标识需要修改MSC号码的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                |
| RECORDCOUNT | 用户个数      | 用于标识需要修改MSC号码的用户数目。 当需要为连续号码的多个用户修改MSC号码时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户修改MSC号码。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户修改MSC号码，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名   | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要修改MSC号码的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modmscnum.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                       |
| ISDNFILE    | MSISDN文件名 | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要修改MSC号码的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modmscnum.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                 |
| MSCNUM      | 新MSC号码    | 用于标识修改后的新MSC号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                           |

## 使用实例

1. 修改MSISDN号码为“13310911001”的用户的MSC号码，新的MSC号码为“23”：

   ```
   MOD MSCNUM: ISDN="13310911001", MSCNUM="23";
   ```
2. 修改3个连续号码的用户的MSC号码，这3个MSISDN号码分别为“13310911001”、“13310911002”、“13310911003”，对应的新MSC号码为“23”：

   ```
   MOD MSCNUM: ISDN="13310911001", RECORDCOUNT=3, MSCNUM="23";
   ```
3. 修改3个非连续号码的用户的MSC号码，这3个MSISDN号码分别为“13310911001”、“13310911003”、“13310911005”，已保存在“MSISDN文件名”为“modmscnum.txt”的文件中，并通过文件管理功能上传到指定目录，对应的新MSC号码为“23”：

   ```
   MOD MSCNUM: ISDNFILE="modmscnum.txt", MSCNUM="23";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释      | 原因分析                                                                                                     | 处理建议                                                                                                                    |
|:--------|:-----------|:---------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值     | 可能原因为如下之一：参数“IMSI”的取值不是6～15位十进制数字组成的字符串。参数“MSISDN”的取值不是1～15位十进制数字组成的字符串。参数“新MSC号码”的取值不是1～15位十进制数字组成的字符串。 | 根据实际情况，重新输入“IMSI”、“MSISDN”或“新MSC号码”的取值，确保其取值符合要求。                                                                       |
| ERR1009 | 参数丢失       | “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数一个都没有输入。                                                        | 根据实际情况，重新输入参数，并满足“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                             |
| ERR1005 | 文件未找到      | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                         | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                      |
| ERR1010 | 参数冲突       | 可能原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。       | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR3001 | 用户未开户      | 用户的IMSI号码或MSISDN号码输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户。                                                   | 核实用户的IMSI号码或MSISDN号码，如果确定输入无误，证明实际输入的参数“IMSI”或“MSISDN”对应的用户未开户，请先通过ADD SUB命令给用户开户。                                      |
| ERR1025 | 批操作文件中格式非法 | 参数“IMSI文件名”或“MSISDN文件名”对应的批操作文件格式不正确。                                                                    | 请根据IMSIFILE文件格式和ISDNFILE文件格式，重新确定对应的批操作文件格式。                                                                            |
