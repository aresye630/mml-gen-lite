# 删除游牧模板(RMV HNATPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于从HSS的业务数据库中删除一个指定的游牧模板。

## 注意事项

- “NASS游牧模板ID”参数和“NASS游牧模板名称”参数必须存在且只能存在一个。
- 当模板被用户引用时，不能被删除。

## 参数说明

| 参数标识    | 参数名称       | 参数说明                                                                                                                       |
|:--------|:-----------|:---------------------------------------------------------------------------------------------------------------------------|
| TPLID   | NASS游牧模板ID | 标识一条游牧地址模板的关键字段，用于指定需要删除哪一条游牧模板ID的数据记录，操作员可以使用LST HTPLINF命令查询获得。 取值范围：0～67108863 默认值：无。 说明：可选参数。该参数为255表示无效值。              |
| TPLNAME | NASS游牧模板名称 | 标识一条游牧地址模板的关键字段，用于指定需要删除哪一条游牧模板名称的数据记录，操作员可以使用LST HTPLINF命令查询获得。 取值范围：长度不超过64的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 说明：可选参数。 |

## 使用实例

1. 删除游牧模板，“NASS游牧模板ID”为“10”：

   ```
   RMV HNATPL: TPLID=10;
   ```
2. 删除游牧模板，“NASS游牧模板名称”为“07550011”：

   ```
   RMV HNATPL: TPLNAME="07550011";
   ```
