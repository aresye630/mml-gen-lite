# 设置补充业务SIP格式前转号码后缀(SET HCFFTNPOSTFIX)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于IMS-HSS和第三方AS网元对接时，设置Sh接口消息中呼叫前转类补充业务的前转号码为SIP格式时的号码后缀。

当登录“UDM MML命令”窗口，执行**MOD INSP**命令设置“VOLTE Sh接口补充业务数据格式”软参值为“1”，且设置**SET HSYSTEMPARA**命令中“前转号码的格式”参数为“SIP\_FORMAT”时，需要通过该命令设置补充业务SIP格式前转号码后缀。

## 注意事项

无。

## 参数说明

| 参数标识             | 参数名称      | 参数说明                                                             |
|:-----------------|:----------|:-----------------------------------------------------------------|
| SIPFORMATPOSTFIX | SIP格式号码后缀 | 用于标识Sh接口消息中呼叫前转类补充业务的前转号码为SIP格式时的后缀部分。 取值范围：长度不超过127的字符串。 默认值：无。 |

## 使用实例

增加一条补充业务SIP格式前转号码后缀。“SIP格式号码后缀”为“ims.mnc123.mcc732.3gppnetwork.org”：

```
SET HCFFTNPOSTFIX: SIPFORMATPOSTFIX="ims.mnc123.mcc732.3gppnetwork.org";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释   | 原因分析              | 处理建议                               |
|----------:|:--------|:------------------|:-----------------------------------|
|      1001 | 无效的命令   | 输入的命令名称不正确。       | 重新输入正确的命令。                         |
| 900001007 | 无效的参数值  | 输入的参数取值不在其取值范围内。  | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。   |
| 900001008 | 参数不足    | “SIP格式号码后缀”参数未输入。 | 根据实际情况，重新输入参数，确保“SIP格式号码后缀”参数必须输入。 |
