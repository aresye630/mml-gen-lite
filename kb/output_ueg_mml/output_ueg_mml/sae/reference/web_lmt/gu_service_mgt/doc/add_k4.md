# 增加K4(ADD K4)

## 命令功能

此操作用来增加K4密钥值。KI值是为用户鉴权而设。建议给KI值加密，并且需要由SIM/USIM卡厂商提供对应的K4。加载加密的KI时，必须加载对应的K4，UDM系统才能算出正确的KI。所以K4在KI需要加密时设置。

## 注意事项

- 添加K4成功后，请使用**CHK K4**命令校验K4VALUE。
- “K4密钥输入方式”为“ClearKey”时，K4密钥输入为密文；“K4密钥输入方式”为“6EyesRule”或“6EyesRuleXOR”时，K4由三部分组成，每部分由不同的操作人员输入，并且每部分输入两遍。如果两次输入不等，会弹出提示框提示“K4密钥的第一/二/三部分输入不一致，请重新输入”，请用户重新输入密钥。
- **DES和3DES为业界已知**的安全强度较弱的算法，应避免使用。建议：
  - 直接使用AES128或AES256算法其中之一，AES256加密强度高于AES128。
  - 如果使用3DES算法，必须保证密钥DESK1、DESK2和DESK3设置为不同值。
- 同一个“HLR序列号”中增加的K4密钥值记录数不能超过5000条。
- “算法类型”为“AES128”，K4值必须为32位；“算法类型”为“AES256”，K4值必须为64位。
- 当**SET MAPCONF**命令中的“是否启用随机密钥”参数为“TRUE”时，如果未执行**SET MAPSERV**命令设置“随机密钥默认ID”参数为系统已存在的随机密钥，则执行该命令时会返回错误：“ERR4086 随机密钥默认ID未设置”。
- “算法类型”为“DES”或“3DES”，K4不支持用于搬迁加密场景。
- 执行本命令携带的“K4序列号”对应的“算法类型”为“SM4”时，默认**SET MAPCONF**命令的“是否启用随机密钥”参数为“TRUE”，**SET MAPSERV**命令的“SAE-HSS AES加密模式”参数为“CBC”。

## 使用实例

**说明** 

本页面示例仅为举例参考，请勿直接拷贝脚本操作。

1. 在HSS/HLR中添加K4。“HLR序列号”为“1”，“K4序列号”为“1”，“K4值”为“1234567890abcde1234567890abcde12”：

   ```
   ADD K4: HLRSN=1, K4SNO=1, KEYTYPE=ClearKey, ALGTYPE=AES128, K4VALUE="*****";
   ```
2. 在HSS/HLR中添加K4。“HLR序列号”为“1”，“K4序列号”为“1”，“K4值”为“1234567890abcde1234567890abcde12”，“K7序列号”为“2”：

   ```
   ADD K4: HLRSN=1, K4SNO=1, KEYTYPE=ClearKey, ALGTYPE=AES128, K4VALUE="*****", K7SNO=2;
   ```
3. 在HSS/HLR中添加K4。“HLR序列号”为“1”，“K4序列号”为“1”，“K4密钥输入方式”为“6EyesRule”，“算法类型”为“AES128”，“K7序列号”为“2”，“K4第一部分取值”为“1234567890a”，“K4第一部分取值确认”为“1234567890a”，“K4第二部分取值”为“bcde1234567”，“K4第二部分取值确认”为“bcde1234567”，“K4第三部分取值”为“890abcde12”，“K4第三部分取值确认”为“890abcde12”：

   ```
   ADD K4: HLRSN=1, K4SNO=1, KEYTYPE=6EyesRule, ALGTYPE=AES128, K7SNO=2, KEYPART1="*****", KEYPART1CNF="*****", KEYPART2="*****", KEYPART2CNF="*****", KEYPART3="*****", KEYPART3CNF="*****";
   ```
4. 在HSS/HLR中添加K4，“HLR序列号”为“1”，“K4序列号”为“2”，“K4密钥输入方式”为“ClearKey”，“算法类型”为“3DES”，“3DES密钥1”取值为“1234567890abcde1”，“3DES密钥2”取值为“1234567890abcde1”，“3DES密钥3”取值为“1234567890abcde1”：

   ```
   ADD K4: HLRSN=1, K4SNO=2, KEYTYPE=ClearKey, ALGTYPE=3DES, DESK1="*****", DESK2="*****", DESK3="*****";
   ```
5. 在UDM中添加K4，“HLR序列号”为“1”，“K4序列号”为“3”，“K4密钥输入方式”为“ClearKey”，“算法类型”为“SM4”，“K4密文”取值为“\*\*\*\*\*\*”，“密钥生成时间”取值为“2024-10-01 14:00:00”，“签名值”为“04DC406DDC9A75D8DFBC50E258F5c2DB6C71F1CF1AFDC1EA4615233603EFBCC3C0A24130C5579843DAB47119EC1D1BF3C5ED595B7C9C3AEE97D00146A23872A0”，“签名者名称”为“PKEYnamehlr1pkeysno1”，“接收方名称”为“PKEYnamehlr1pkeysno2”（执行本命令时，需确保密钥生成时间和本地时间相差不超过1分钟；K4密文按参数配置要求输入，本样例不具体列举。）

   ```
   ADD K4: HLRSN=1, K4SNO=3, KEYTYPE=ClearKey, ALGTYPE=SM4, K4CIPHER="*****", CREATETIME="2024-10-01 14:00:00", SIGNATURE="*****", SIGNER="PKEYnamehlr1pkeysno1", VERIFIER="PKEYnamehlr1pkeysno2";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。“K4密钥输入方式”为“6EyesRuleXOR”时会返回校验码，操作人员检查该校验码是否与卡号中心提供的校验码一致，如果不一致则表示输入的密钥错误，需要删除此K4并重新输入。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。
