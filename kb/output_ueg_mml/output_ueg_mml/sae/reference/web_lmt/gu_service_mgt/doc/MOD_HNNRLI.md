# 修改IMPU的参考位置信息(MOD HNNRLI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在IMS-HSS的业务数据库中修改指定“IMPU”的参考位置信息。在该命令中，系统通过以下关键参数的组合来唯一标识一条“IMPU”的参考位置信息数据记录：

- “IMPU”
- “参考位置信息索引”

## 注意事项

- “参考位置信息”、“参考位置信息类型”和“设为默认参考位置信息”参数至少存在一个。
- 通过**LST HNNRLI**查询指定“IMPU”的参考位置信息，若“参考位置信息类型”为“IPRANGE(IPRANGE)”时，不能执行该命令修改参考位置信息。

## 使用实例

修改IMS-HSS下发的用户参考位置信息，“IMPU”为“sip:impuinfo@huawei.com”，“参考位置信息索引”为“1”，“参考位置信息”为“huawei”，“参考位置信息类型”为“IEEE-802.11b(IEEE-802.11b)”。执行命令如下：

```
MOD HNNRLI: IMPU="sip:impuinfo@huawei.com", RLINDEX=1, RLI="huawei", RLT=IEEE-802.11b;
```

该命令执行正常，会返回命令执行成功的提示信息。
