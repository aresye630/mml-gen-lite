# 修改锚定AS配置(MOD ANCHORMGCF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来修改前缀锚定方式中前缀号码和MSISDN号段的关系，PRN锚定方式中锚定AS和MSISDN号段的关系。

## 注意事项

修改“锚定前缀”参数值时，请合理配置其长度，确保修改后通过此锚定前缀号码生成的IMRN号码（国家码+锚定前缀号码+ISDN号码）长度不超过16位。

## 参数说明

| 参数标识          | 参数名称       | 参数说明                                                                                                                                 |
|:--------------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN         | HLR序列号     | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                         |
| MSISDN_PREFIX | MSISDN前缀   | 用于标识国内移动号码前缀。 取值范围：1～15位的十进制数字组成的字符串。 默认值：无。 说明：MSISDN前缀包含国家码。                                                                       |
| ANCHOR_PREFIX | 锚定前缀       | 用于标识增加前缀方式锚定时的锚定前缀。 取值范围：1～15位的十六进制数字（0～E）组成的字符串。 默认值：无。 说明：锚定前缀不包含国家码。输入的十六进制数“A”、“B”、“C”、“D”、“E”，分别代表电信业务BCD字符“*”、“#”、“a”、“b”、“c”。 |
| MGCF_ADDR1    | 锚定AS GT 地址 | 用于标识发送PRN方式锚定时的锚定AS地址。 取值范围：1～15位的十进制数字组成的字符串。 默认值：无。                                                                                |

## 使用实例

修改锚定AS，锚定前缀和MSISDN号段关系，MSISDN前缀为861380270，锚定前缀为1234，锚定AS GT地址为460000000000000，命令如下：

MOD ANCHORMGCF: HLRSN=1, MSISDN\_PREFIX="861380270", ANCHOR\_PREFIX="1234", MGCF\_ADDR1="460000000000000";
