# 修改UUS业务(MOD UUS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

通过此命令操作员可以修改用户UUS业务设置，包括提供和撤销。用户NAM必须是MSC或者BOTH。

执行此命令后，如果是给用户签约该业务，则会下发插入用户数据消息；如果是给用户去签约该业务，则会下发删除用户数据消息。

## 注意事项

- IMSI、ISDN、IMSIFILE、ISDNFILE是条件可选参数，任何一个参数出现即可，但不能同时出现。
- RECORDCOUNT一定不能与IMSIFILE或ISDNFILE同时存在。
- HLR支持当修改用户NAM为SGSN时，不去签约UUS业务，但是保留原来的UUS业务数据。
- MAP 1、MAP2的业务流程支持UUS1，MAP 3的业务流程支持UUS1、UUS2和UUS3。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                         |
|:------------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | IMSI号码， E.212格式的编码，6～15位的十进制数字。                                                                                                              |
| ISDN        | MSISDN    | MSISDN号码，E.164格式的编码，1～15位的十进制数字。                                                                                                             |
| RECORDCOUNT | 用户个数      | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。                                                          |
| IMSIFILE    | IMSI文件名   | IMSIFILE文件名称，由16个以内的数字或字母组成。 IMSIFILE是由多个不连续的IMSI号码组成的批操作文件，每个IMSI号码占一行。                                                                     |
| ISDNFILE    | MSISDN文件名 | ISDNFILE文件名称，由16个以内的数字或字母组成。 ISDNFILE是由多个不连续的MSISDN号码组成的批操作文件，每个MSISDN号码占一行。                                                                 |
| PROV        | 是否提供UUS业务 | 提供还是撤销UUS业务。 TRUE：提供 FALSE：撤销 必选参数。                                                                                                          |
| UUS         | UUS业务     | UUS业务就是用户到用户的信令。必选参数。 根据触发UUI消息的不同阶段，UUS取值范围如下： UUS1：在始呼和终呼中发送和接收UUI消息。 UUS2：在听到对方振铃时发送UUI信息。UUS3：在通信连接建立之后发送和接收UUI消息。 可以使用任一个或者用“&”连接的任意组合。 |

## 使用实例

为IMSI号码是460000009123456的用户提供UUS业务,在听到对方振铃时发送UUI信息。

MOD UUS: IMSI="460000009123456", PROV=TRUE, UUS=UUS2;
