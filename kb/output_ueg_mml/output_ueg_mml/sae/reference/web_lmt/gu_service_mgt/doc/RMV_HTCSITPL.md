# 删除T-CSI数据模板(RMV HTCSITPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于在HSS的业务数据库中删除一条T-CSI(Terminating CAMEL Subscription Information)模板数据记录。如果指定的模板已经被使用，则不允许删除。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                                                              |
|:-------|:----------|:------------------------------------------------------------------------------------------------------------------|
| TPLID  | T-CSI模板ID | 可选必选说明：必选参数 参数含义：标识一条T-CSI数据模板的关键字段，用于指定需要删除哪一条T-CSI数据模板。可以通过LST HTCSITPL查询获得一条T-CSI数据模板的详细信息。 取值范围： 0-254 默认值： 无 |

## 使用实例

删除T-CSI数据模板。T-CSI模板ID：10。

```
RMV HTCSITPL: TPLID=10;
```
