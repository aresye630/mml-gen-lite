# 修改非携转全局数据(MOD NPPREFIXRN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此操作用来修改非携转用户数据配置。

## 注意事项

RN和MSCID为可选参数，但两个参数必须至少出现一个。

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                        |
|:------------|:---------|:--------------------------------------------|
| ISDN_PREFIX | MSISDN前缀 | MSISDN前缀号码，E.164格式的编码，1～15位的十进制数字。 说明：必选参数。 |
| RN          | 路由码      | 路由码，1～10位的十进制数字或者A~E字符。                     |
| MSCID       | MSCID    | MSCID号码，E.164格式的编码，1～15位的十进制数字。             |

## 使用实例

修改MSISDN前缀号码为86131075003001的非携转用户数据配置。命令如下：

```
MOD NPPREFIXRN: ISDN_PREFIX="86131075003001", RN="1113";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析       | 处理建议                       |
|:--------|:--------|:-----------|:---------------------------|
| ERR4006 | 本局RN未配置 | 本网路由号码未配置。 | 通过SET INTROFF命令配置“本网RN”参数。 |
