# 删除AKA鉴权信息模板(RMV HAKATPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于在HSS的业务数据库中删除一个AKA鉴权信息模板。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                                    |
|:-------|:----------|:----------------------------------------------------------------------------------------|
| TPLID  | AKA鉴权模板ID | 标识一个AKA鉴权信息模板记录的关键字段，用于指定需要删除哪一个AKA鉴权信息模板记录，操作员可以使用LST HTPLINF操作查询获得。 取值范围：0～254 缺省值： 无 |

## 使用实例

删除AKA鉴权信息模板。AKA鉴权模板ID：10。

```
RMV HAKATPL: TPLID=10;
```
