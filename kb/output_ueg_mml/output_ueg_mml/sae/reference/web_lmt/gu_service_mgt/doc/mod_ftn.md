# 用户FTN扩展(MOD FTN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于用户号码升位的场景下扩展用户的前转号码。

营帐系统不能使用该命令修改用户前转业务签约的前转号码，当营帐系统需要修改用户签约的前转号码时，请执行对应前转业务涉及的命令**REG CFU**、**REG CFB**、**REG CFNRY**、**REG CFNRC**或**MOD CFD**。

## 注意事项

- 输入“旧FTN”和“新FTN”参数时，需要加上号码规整前缀“91”。
- 输入的“旧FTN”参数必须在数据库中存在，如果不存在，会报错“ERR3007：记录不存在”。
- 输入的“新FTN”参数直接保存到数据库，系统不会对其进行号码规整，也不检查其是否是禁止前转号码，请务必保证新前转号码的正确性。

## 参数说明

| 参数标识   | 参数名称   | 参数描述                                                      |
|:-------|:-------|:----------------------------------------------------------|
| IMSI   | IMSI   | 此参数用于设置IMSI号码。 取值范围：E.212格式的编码，为6～15位的十进制数。 说明：必选参数。      |
| OLDFTN | 旧FTN   | 用于标识用户的旧前转号码。具体格式可参见前转号码格式。 取值范围：1～28位十进制数字组成的字符串。 默认值：无。 |
| NEWFTN | 新FTN   | 用于标识用户的新前转号码。具体格式可参见前转号码格式。 取值范围：1～28位十进制数字组成的字符串。 默认值：无。 |

## 使用实例

将“IMSI”号码为“460030913121002”的用户的前转号码“9113566666”扩展为“911350066666”。

```
MOD FTN: IMSI="460030913121002", OLDFTN="9113566666", NEWFTN="911350066666";
```
