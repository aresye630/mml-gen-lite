## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成全网设备过载、CPU负荷过载等现象，因此建议在夜间话务量低时执行该命令，执行本命令后需要通过**DSP EXPTASK**命令查询触发的导出任务状态。

该命令用来获取发送到VLR、Gn/Gp SGSN、MME、S4 SGSN和AAA的Reset消息数据，数据存储到内存库中。

该命令通常在HLR/HSS割接时进行，获取被割接HLR/HSS的Reset消息数据并将其存储到新割接的HLR/HSS内存库中。

## 注意事项

- 执行该命令会消耗较多系统资源，影响系统性能，请在话务量较低的时候执行。
- 该命令不允许进行批操作。
- 执行该命令返回成功结果后，系统下发导出任务开始导出Reset消息数据，导出完成后将其存储到内存库中。可通过**DSP EXPTASK**命令查询导出任务状态，当导出任务完成后才能执行**SND RESET**命令。

## 参数说明

无。

## 使用实例

获取发送到VLR、Gn/Gp SGSN、MME、S4 SGSN和AAA的Reset消息数据，命令如下：

```
GET RESETDATA:;
```

```
%%GET RESETDATA:;%%
RETCODE = 0 SUCCESS0001:操作成功

There is together 1 report

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释     | 原因分析   | 处理建议                   |
|------:|:----------|:-------|:-----------------------|
|  3000 | HDU内部运行错误 | 系统失败   | 查看系统告警，排查系统环境问题后再执行命令。 |
