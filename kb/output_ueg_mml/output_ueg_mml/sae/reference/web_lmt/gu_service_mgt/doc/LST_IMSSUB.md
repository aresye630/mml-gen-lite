# 查询IMS用户信息(LST IMSSUB)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HSS的业务数据库中查询IMS用户的数据信息，执行命令一次只能查询一个用户的数据。

## 注意事项

“IMSI”、“MSISDN”、“IMPI”和“IMPU”是可选参数，必须有且只能有一个参数出现。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                          |
|:-------|:-------|:------------------------------|
| IMSI   | IMSI   | 用于指示系统按照哪个IMSI号码来查询IMS用户信息。   |
| ISDN   | MSISDN | 用于指示系统按照哪个MSISDN号码来查询IMS用户信息。 |
| IMPI   | IMPI   | 用于指示系统按照哪个IMPI值来查询IMS用户信息。    |
| IMPU   | IMPU   | 用于指示系统按照哪个IMPU值来查询IMS用户信息。    |

## 使用实例

查询IMS用户信息，“IMSI”为“460030913121001”：

```
LST IMSSUB: IMSI="460030913121001";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数请参见

**ADD IMSSUB**

命令的参数说明。表1列出的是未包含在

**ADD IMSSUB**

命令参数说明中的输出项。

| 输出项名称   | 输出项解释                                                |
|:--------|:-----------------------------------------------------|
| IRSID   | 用于返回用户的隐式注册集ID，“0”表示该IMPU不属于任何隐式注册集。                 |
| ALIASID | 用于返回别名组ID，“0”表示该IMPU不属于任何别名组。                        |
| DEFIMPU | 用于返回该IMPU是否为默认IMPU。0：指该IMPU不是默认IMPU。1：指该IMPU是默认IMPU。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。
