# 修改PS业务(MOD PSSER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于修改用户的PS业务数据。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。
- 执行本命令删除用户通过APN模板签约的APN数据时，用户通过**SET APNLIST**命令签约的具有相同PDP上下文索引的APN数据会被同时删除。

## 参数说明

| 参数标识          | 参数名称                | 参数说明                                                                                                                                                                                                                                                                                  |
|:--------------|:--------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI          | IMSI                | 用于标识需要修改PS数据的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                 |
| ISDN          | MSISDN              | 用于标识需要修改PS业务的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                               |
| RECORDCOUNT   | 用户个数                | 用于标识需要修改PS业务的用户数目。 当需要为连续号码的多个用户修改PS业务时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户修改PS业务。 取值范围：1～100000 默认值：无。 说明： 该参数是对连续号码的多个用户修改PS业务，当只有一个用户时，该参数不必配置。 当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。                                                                 |
| IMSIFILE      | IMSI文件名             | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要修改PS业务的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modpsser.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～35位字母或数字组成的字符串。 默认值：无。                                                                                                       |
| ISDNFILE      | MSISDN文件名           | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要修改PS业务的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modpsser.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～35位字母或数字组成的字符串。 默认值：无。                                                                                                 |
| PROV          | 操作类型                | 用于标识操作类型取值。 取值范围： ADDPDPCNTX：增加新PDP上下文。MODPDPCNTX：修改用户PDP上下文。RMVPDPCNTX：删除用户的指定的一个PDP上下文。RMVALLCNTX：删除用户所有PDP上下文。 默认值：无。 说明： 如果参数“操作类型”为“ADDPDPCNTX”时，那么参数“PDP上下文索引值”和“PSAPNQOS模板ID”必须出现； 如果参数“操作类型”为“MODPDPCNTX”时，那么参数“PDP上下文索引值”必须出现； 如果参数“操作类型”为“RMVPDPCNTX”时，那么参数“PDP上下文索引值”必须出现。 |
| CNTXID        | PDP上下文索引值           | 仅当本命令中的“操作类型”参数为“ADDPDPCNTX”、“MODPDPCNTX”或“RMVPDPCNTX”时该参数有效。用于标识PDP上下文索引值。 取值范围:1～50 默认值：无。                                                                                                                                                                                          |
| PSAPNQOSTPLID | PSAPNQOS模板ID        | 仅当本命令中的“操作类型”参数为“ADDPDPCNTX”或“MODPDPCNTX”时该参数有效。用于标识PSAPNQOS模板ID。 取值范围：0～65534 默认值：无。                                                                                                                                                                                                 |
| IPV4ADDIND    | PDP IPV4类型地址标识      | 仅当本命令中的“操作类型”参数为“ADDPDPCNTX”或“MODPDPCNTX”时该参数有效。用于标识PDP IPV4类型地址标识。 取值范围： STATIC：静态地址。DYNAMIC：动态地址。 默认值：无。                                                                                                                                                                            |
| IPV4ADD       | PDP IPV4类型地址        | 仅当本命令中的“PDP IPV4类型地址标识”参数为“STATIC”时该参数有效。用于标识PDP IPV4类型地址。该参数仅用于设置IPV4类型地址，仅在需要配置静态IP地址的时候选配。 取值范围：0～39位字符长度的字符串。 默认值：无。                                                                                                                                                              |
| OTHERADDIND   | PDP除IPV4类型外其他类型地址标识 | 仅当本命令中的“操作类型”参数为“ADDPDPCNTX”或“MODPDPCNTX”时该参数有效。用于标识PDP除IPV4类型外其他类型地址标识。 取值范围： STATIC：静态地址。DYNAMIC：动态地址。 默认值：无。                                                                                                                                                                       |
| OTHERADD      | PDP其他类型地址           | 仅当本命令中的“PDP除IPV4类型外其他类型地址标识”参数为“STATIC”时该参数有效。用于标识PDP其他类型地址。设置除IPV4类型以外的其他类型地址,例如IPV6等，仅在需要配置静态IP地址的时候选配。 取值范围：0～39位字符长度的字符串。 默认值：无。                                                                                                                                                  |
| APN           | PS域接入点名称            | 仅当参数“操作类型”为“ADDPDPCNTX”或“MODPDPCNTX”时，该参数有效。用于标识PS域接入点的名称。 取值范围：1～63位字符长度的字符串。 默认值：无                                                                                                                                                                                                  |

## 使用实例

1. 给IMSI为“460000009012345”，“操作类型”取值为“ADDPDPCNTX”，“PDP上下文索引值”取值为“2”，“PSAPNQOS模板ID”为“2”的用户修改PS数据业务，命令如下：

   ```
   MOD PSSER: IMSI="460000009012345", PROV=ADDPDPCNTX, CNTXID=2, PSAPNQOSTPLID=2;
   ```
2. 给IMSI为“460000009012344”，“操作类型”取值为“MODPDPCNTX”，“PDP上下文索引值”取值为“2”，“PSAPNQOS模板ID”为“2”的用户修改PS数据业务，命令如下：

   ```
   MOD PSSER: IMSI="460000009012344", PROV=MODPDPCNTX, CNTXID=2, PSAPNQOSTPLID=2;
   ```
3. 给IMSI为“460000009012343”，“操作类型”取值为“RMVPDPCNTX”，“PDP上下文索引值”取值为“2”的用户修改PS数据业务，命令如下：

   ```
   MOD PSSER: IMSI="460000009012343", PROV=RMVPDPCNTX, CNTXID=2;
   ```
