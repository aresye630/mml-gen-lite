# 修改K4(MOD K4)

- 命令功能
- 注意事项

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成用户鉴权失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在HSS/HLR中修改K4密钥名称和K7序列号。在该命令中，系统通过以下关键参数的组合来唯一标识一条K4密钥信息：

- HLR序列号
- K4序列号

## 注意事项

- **LST K4**命令查询结果中的“ALGTYPE”不为空，且执行本命令签约了“HSM密钥索引”时，新开卡用户在UDM上加密。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                                                                                      |
|:------------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号  | 标识K4数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR上的K4数据记录的参数进行修改或调整，操作员可以使用LST HLRSN命令查询获得。                                                                                                                                                                          |
| K4SNO       | K4序列号   | 标识K4数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪个K4序列号对应的K4名称进行修改或调整，操作员可以使用LST K4命令查询获得。                                                                                                                                                                               |
| KEYNAME     | K4名称    | 用于标识K4密钥名称。 取值范围：1位～60位的字符串。 默认值：无。                                                                                                                                                                                                                       |
| K7SNO       | K7序列号   | 用于标识需要修改的加密K4的K7序列号。此参数适用于如下场景：将无K7密钥加密的K4改为由HSM上K7密钥加密的K4，即新增K4的K7密钥。修改加密K4的HSM上的K7密钥。                                                                                                                                                                   |
| HSMKEYINDEX | HSM密钥索引 | 用于标识HSM上的密钥索引，在HSM上导入密钥后，把对应的HSM密钥索引添加到UDM。 取值范围：5位～60位的字符串。 默认值：无。 配置原则：该参数由组名称+参数名称+ID组成，中间使用“:”分开：组名称和参数名称为字符串形式，且不为空，分别对应导入密钥时的Object group和Object name参数；ID为十进制数字，取值范围是0～2147483647，对应导入密钥时的Object specifier参数。例如：mnts:myParam:1。该参数取值包含字母时，字母区分大小写。 |

## 使用实例

1. 在HSS/HLR中修改K4名称。“HLR序列号”为“1”，“K4序列号”为“1”，“K4名称”改为“K4namehlr1k4sno1”：

   ```
   MOD K4: HLRSN=1, K4SNO=1, KEYNAME="K4namehlr1k4sno1";
   ```
2. 在HSS/HLR中修改K7序列号。“HLR序列号”为“1”，“K4序列号”为“1”，“K7序列号”改为“2”：

   ```
   MOD K4: HLRSN=1, K4SNO=1, K7SNO=2;
   ```

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| ERR4195 | 不支持处理保存在HSM的记录 | 待修改的“K4序列号”为HSM类型。                                                                                                                                                         | 在用户签约的K4记录中查询“K4密钥输入方式”，确保待修改的“K4序列号”不为HSM类型。                                                                                                                                                            |
