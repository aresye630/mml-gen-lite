# 查询短消息中心地址(LST HSMSCADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在IMS-HSS中查询用户已签约的短消息中心地址信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                      |
|:-------|:-------|:------------------------------------------------------------------------------------------|
| ISDN   | MSISDN | 标识一条短消息中心地址数据记录的关键参数（其取值不能被修改），用于标识需要对哪个MSISDN号码的短消息中心地址进行查询。操作员可以使用LST IMSSUB命令查询用户信息获得。 |

## 使用实例

查询“MSISDN”号码为“4600000091234”用户的已签约短消息中心地址，执行命令如下：

```
LST HSMSCADDR: ISDN="4600000091234";
```

```

```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息，各参数含义请参见**SET HSMSCADDR**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释   | 原因分析            | 处理建议                            |
|----------:|:--------|:----------------|:--------------------------------|
| 900001007 | 无效的参数值  | 输入的参数取值不符合要求。   | 根据实际情况，重新输入“MSISDN”，确保其取值符合要求。  |
| 900001008 | 参数不足    | 参数“MSISDN”没有输入。 | 根据实际情况，输入“MSISDN”参数，并确保其取值符合要求。 |
