# 改号（MOD ISDN）

## 命令功能

该命令用于更改用户的MSISDN号码。

当用户希望换号不换卡时，可以进行改号。改号后，系统将向VLR/SGSN下发新的MSISDN号码。

当用户是M2M用户时，系统会根据以下情况对MSISDN-Less用户的属性进行变更：

- 支持从MSISDN-Less用户变更为非MSISDN-Less用户

  输入“新MSISDN”且与“IMSI”不同。
- 支持从非MSISDN-Less用户变更为MSISDN-Less用户

  不输入“新MSISDN”或输入的“新MSISDN”与“IMSI”值相同。

## 注意事项

- “IMSI”、“旧MSISDN”、“MSISDN/新MSISDN文件名”、“IMSI/新MSISDN文件名”四个参数是互斥参数，必须有且只能有一个参数出现。
- “新MSISDN”不能与“MSISDN/新MSISDN文件名”或“IMSI/新MSISDN文件名”同时配置。
- “用户个数”不能与“MSISDN/新MSISDN文件名”或“IMSI/新MSISDN文件名”同时配置。
- 改号后具有MSISDN-Less属性的用户不能同时签约MIMSI、多SIM、COMISDN、GROUPSIM、多号码用户群组、ALS、Follow Me、Home Zone业务。

## 参数说明

| 参数标识        | 参数名称              | 参数说明                                                                                                                                                                                                        |
|:------------|:------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI              | 用于标识待改号用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                             |
| ISDN        | 旧MSISDN           | 用于标识待改号用户的旧MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                          |
| NEWISDN     | 新MSISDN           | 用于标识待改号用户的新MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 说明：该参数输入值必须与“旧MSISDN”不同。                                                                                                                                 |
| RECORDCOUNT | 用户个数              | 用于标识待改号用户的数目。 当需要为连续号码的多个用户改号时配置该参数，配置后，系统将会从已指定的“IMSI”号码或“旧MSISDN”号码开始，对连续号码的多个用户进行改号。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户进行改号，当只有一个用户时，该参数不必配置。当一次改号的用户个数很多时，对系统性能无影响，但改号的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| ISDNFILE    | MSISDN/新MSISDN文件名 | 用于标识MSISDN/新MSISDN文件名称。 MSISDN/新MSISDN文件包含多个不连续的待改号用户的旧MSISDN号码和新MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modisdn.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见改号批操作文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。          |
| IMSIFILE    | IMSI/新MSISDN文件名   | 用于标识IMSI/新MSISDN文件名称。 IMSI/新MSISDN文件包含多个不连续的待改号用户的IMSI号码和新MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modisdn.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见改号批操作文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                 |

## 使用实例

1. 将“IMSI”号码为“460030913121001”的用户的手机号码改为“13310911002”：

   ```
   MOD ISDN: IMSI="460030913121001", NEWISDN="13310911002";
   ```
2. 为从“旧MSISDN”为“13310911001”的号码开始的3个连续号码的用户改号，改号后的“新MSISDN”为从“13310911004”开始的3个连续号码。

   ```
   MOD ISDN: ISDN="13310911001", NEWISDN="13310911004", RECORDCOUNT=3;
   ```
3. 为3个非连续号码的用户改号。

   - 3个旧MSISDN号码分别为“13310911001”、“13310911003”、“13310911005”。
   - 3个新MSISDN号码分别为“13310911002”、“13310911004”、“13310911006”。
   - 旧MSISDN号码和新MSISDN号码已保存在“MSISDN/新MSISDN文件名”为“modisdn.txt”的文件中，并通过文件管理功能上传到指定目录。

   ```
   MOD ISDN: ISDNFILE="modisdn.txt";
   ```
