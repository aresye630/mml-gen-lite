# 删除5GS用户模板(RMV NGSUSERTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条5GS用户模板数据记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                          |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 可选必选说明：必选参数 参数含义：标识一条5GS用户模板数据记录的关键字段之一，用于指定系统按照哪个HLR序列号来删除5GS用户模板信息数据，操作员可使用LST NGSUSERTPL命令获得。 取值范围：1~255 默认值：无 配置原则：无      |
| TPLID  | 模板ID   | 可选必选说明：必选参数 参数含义：标识一条5GS用户模板数据记录的关键字段之一，用于指定系统按照哪个模板ID来删除5GS用户模板信息数据，操作员可使用LST NGSUSERTPL命令获得。 取值范围：1～2147483646 默认值：无 配置原则：无 |

## 使用实例

删除5GS用户模板，“HLR序列号”为“1”，“模板ID”为“1”，命令如下：

```
RMV NGSUSERTPL: HLRSN=1, TPLID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                | 处理建议                                                           |
|:--------|:--------|:------------------------------------|:---------------------------------------------------------------|
| ERR1004 | 无效的参数值。 | 输入的参数值不在其取值范围内或者输入的参数值不符合要求。        | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                               |
| ERR1009 | 参数丢失。   | 未输入必选参数或条件必选参数。                     | 根据实际情况，确保必选参数“HLR序列号”和“模板ID”必须输入。                              |
| ERR3003 | 模板未定义。  | 待删除的“HLR序列号”与“模板ID”标识的5GS用户模板数据不存在。 | 通过LST NGSUSERTPL命令查询已定义的5GS用户模板，重新输入需要删除的模板对应的“HLR序列号”与“模板ID”。 |
