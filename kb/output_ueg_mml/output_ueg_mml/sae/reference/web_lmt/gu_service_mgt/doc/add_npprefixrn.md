# 增加非携转全局数据(ADD NPPREFIXRN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此操作用于增加非携转用户数据配置。

## 注意事项

系统中增加的非携转用户数据配置记录数不能超过3000条。

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                        |
|:------------|:---------|:--------------------------------------------|
| ISDN_PREFIX | MSISDN前缀 | MSISDN前缀号码，E.164格式的编码，1～15位的十进制数字。 说明：必选参数。 |
| RN          | 路由码      | 路由码，1～10位的十进制数字或者A~E字符。 说明：必选参数。            |
| MSCID       | MSCID    | MSCID号码，E.164格式的编码，1～15位的十进制数字。             |

## 使用实例

在客户端增加MSISDN前缀为86131075003003，路由码为1112的非携转用户，命令如下：

```
ADD NPPREFIXRN: ISDN_PREFIX="86131075003003", RN="1112";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                    | 处理建议                                                                                                                                           |
|:--------|:--------|:------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| ERR4006 | 本局RN未配置 | 本网路由号码未配置。              | 通过SET INTROFF命令配置“本网RN”参数。                                                                                                                     |
| ERR1111 | 超过最大限制  | 增加的非携转用户数据配置记录数超过3000条。 | 根据实际情况，如需增加非携转用户数据配置，处理步骤如下：执行LST NPPREFIXRN命令，查询已存在的非携转用户数据配置。执行RMV NPPREFIXRN命令，删除不必要的非携转用户数据配置记录。执行该命令增加非携转用户数据配置，确保增加的非携转用户数据配置记录数在规定范围之内。 |
