# 查询测试用户（LST TESTUSERLIST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询测试用户数据:

- 若需要查询所有测试用户数据，请不要输入任何参数。
- 若需要查询指定测试用户数据，请输入“用户类型”，“IMSI号码”或“IMPI号码”参数。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                 |
|:---------|:-------|:-----------------------------------------------------------------------------------------------------|
| USERTYPE | 用户类型   | 可选必选说明：必选参数 参数含义：用于标识待查询的测试用户类型。 取值范围： IMSIIMPI 默认值：无。 配置原则：无。                                       |
| IMSI     | IMSI号码 | 可选必选说明：条件可选参数 参数含义：用于标识待查询的测试用户的IMSI号码。 取值范围：6～15位的十进制数字组成的字符串。 默认值：无。 配置原则：该参数仅在“用户类型”取值为“IMSI”时有效。 |
| IMPI     | IMPI号码 | 可选必选说明：条件可选参数 参数含义：用于标识待删除的测试用户的IMPI号码。 取值范围：长度不超过127的字符串。 默认值：无。 配置原则：该参数仅在“用户类型”取值为“IMPI”时有效。      |

## 使用实例

1. 查询“IMSI号码”为“460990000000000”的测试用户信息。

   ```
   LST TESTUSERLIST: USERTYPE=IMSI, IMSI="460990000000000";
   ```

   ```
   %%LST TESTUSERLIST: USERTYPE=IMSI, IMSI="460990000000000";%%
   RETCODE = 0 SUCCESS0001:Operation is successful

   IMSI
   460990000000000

   Total count = 1

   There is together 1 report

   ---    END
   ```
2. 查询所有IMSI号码的测试用户信息。

   ```
   LST TESTUSERLIST: USERTYPE=IMSI;
   ```

   ```
   %%LST TESTUSERLIST: USERTYPE=IMSI;%%
   RETCODE = 0 SUCCESS0001:Operation is successful

   IMSI
   460001234567890
   460001234567891
   460001234567892

   Total count = 3

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1 错误码列表所示。

| 错误码     | 错误码解释   | 原因分析                                        | 处理建议                                                      |
|:--------|:--------|:--------------------------------------------|:----------------------------------------------------------|
| ERR1010 | 参数冲突    | 可能原因为如下之一： IMSI和IMPI不能同时输入。用户类型和输入的号码类型不匹配。 | 根据实际情况，重新输入参数，确保满足以下两点： IMSI和IMPI只能输入1个。用户类型和输入的号码类型需要匹配。 |
| ERR3007 | 记录不存在   | 当前输入的测试用户不存在。                               | 执行LST TESTUSERLIST命令查询已经添加的测试用户，根据查询结果，重新输入一个已添加的测试用户。    |
