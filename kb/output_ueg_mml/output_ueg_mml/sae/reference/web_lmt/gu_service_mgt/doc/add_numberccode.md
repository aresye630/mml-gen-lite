# 增加号码前缀和国家码数据(ADD NUMBERCCODE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HLR中增加一条号码前缀和国家码数据的匹配记录。

当现网为多国部署，即多国数据部署在同一个HLR设备上，HLR在系统初始化时已添加了一条本局数据，即已配置了国家码（通过**SET INTROFF**命令配置），而多国部署需要有多个国家码，HLR在SRI流程中处理SRI消息时，SRI请求消息中携带的MSISDN号码或GMSC号码为本地号码格式，因此通过该命令给当前HLR增加号码前缀和国家码数据对应关系。

## 注意事项

- 通过本命令配置的“国家码”和通过**SET INTROFF**命令配置的“国家码”的生效方式通过**SET MAPSERV**中的参数“给SRI请求消息携带的国内属性的被叫号码或GMSC号码添加国家码的方式”设置。
- 系统中增加的号码前缀和国家码数据记录数不能超过3000条。

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                      |
|:-------------|:-------|:------------------------------------------|
| NUMBERPREFIX | 号码前缀   | 用于标识一个号码前缀。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 |
| CCODE        | 国家码    | 用于标识国家代码信息。 取值范围：1～6位十进制数字组成的字符串。 默认值：无。  |
| DESCRIPTION  | 描述     | 用于描述号码前缀和国家码数据。 取值范围：长度不超过60位的字符串。 默认值：无。 |

## 使用实例

在系统中增加一条号码前缀和国家码数据记录，“号码前缀”为“1380270”，“国家码”为“86”：

```
ADD NUMBERCCODE: NUMBERPREFIX="1380270", CCODE="86";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                    | 处理建议                                                                                                                                                        |
|:--------|:--------|:------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 界面输入的参数不在相应的参数取值范围内。    | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                                            |
| ERR3006 | 记录已存在   | 添加的“号码前缀”在数据库中已存在。      | 根据实际情况，重新输入参数，确保输入的“号码前缀”和系统中已存在的不重复。可执行LST NUMBERCCODE命令查询系统中已存在的号码前缀。                                                                                     |
| ERR3047 | 超过最大限制  | 增加的号码前缀和国家码数据记录超过3000条。 | 根据实际情况，如需增加号码前缀和国家码数据记录，处理步骤如下： 执行LST NUMBERCCODE命令，查询所有的号码前缀和国家码数据记录。执行RMV NUMBERCCODE命令，删除不必要的号码前缀和国家码数据记录。执行该命令增加号码前缀和国家码数据记录，确保增加的号码前缀和国家码数据记录数在规定范围之内。 |
