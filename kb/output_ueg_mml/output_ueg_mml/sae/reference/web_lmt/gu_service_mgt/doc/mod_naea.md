# 修改NAEA业务(MOD NAEA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来修改用户的NAEA业务签约情况。为未签约NAEA业务的用户提供该业务，或者为已签约NAEA业务的用户撤销该业务。

执行此命令后，如果是给用户签约该业务，则会下发插入用户数据消息；如果是给用户去签约该业务，则会下发位置取消消息。

## 注意事项

- IMSI、ISDN、IMSIFILE、ISDNFILE是条件可选参数，有且只能有一个参数出现。
- RECORDCOUNT一定不能与IMSIFILE或ISDNFILE同时出现。

## 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                             |
|:------------|:-----------|:-----------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI       | IMSI号码，E.212格式的编码，为6～15位的十进制数字。                                                                                  |
| ISDN        | MSISDN     | MSISDN号码，E.164格式的编码，为1～15位的十进制数字。                                                                                |
| RECORDCOUNT | 用户个数       | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。                              |
| IMSIFILE    | IMSI文件名    | IMSI文件名称，IMSIFILE包含多个不连续的IMSI号码，每个IMSI号码占一行，16个以内的字母或数字组成的字符串。                                                   |
| ISDNFILE    | MSISDN文件名  | MSISDN文件名称，ISDNFILE包含多个不连续的MSISDN号码，每个MSISDN号码占一行。16个以内的字母或数字组成的字符串。                                             |
| PROV        | 是否提供NAEA业务 | 提供还是撤销NAEA。 TRUE：提供 FALSE：撤销                                                                                     |
| NAEA        | 平等接入运营商ID  | 仅当本命令中的“是否提供NAEA业务”参数为“TRUE”时该参数有效。平等接入运营商ID标识，值域为0～9999。                                                        |
| NAEATYPE    | NAEA类型     | 仅当本命令中的“是否提供NAEA业务”参数为“TRUE”时该参数有效。用于标识平等接入业务NAEA的类型。 取值范围：BOTH：国内或者国际长途呼叫。NATIONAL：国内长途呼叫。INTERNATIONAL：国际长途呼叫。 |

## 使用实例

1. 运营商为IMSI号码是460000009123456的用户提供NAEA值业务，并指定NAEA运营商ID值为39。

   MOD NAEA: IMSI="460000009123456", PROV=TRUE, NAEA=39;
2. 运营商为IMSI号码是460000009123455、460000009123466和460000009123477的用户提供NAEA业务，并指定NAEA运营商ID值为39。

   1. 编写IMSIFILE，文件名称为IMSIBAT，内容如下：

      460000009123455

      460000009123466

      460000009123477
   2. 通过Web UI上的文件选项将文件上传到指定位置。
   3. 执行MOD NAEA命令提供NAEA业务，并指定NAEA业务运营商ID为39。

      MOD NAEA: IMSIFILE="IMSIBAT", PROV=TRUE, NAEA=39;
