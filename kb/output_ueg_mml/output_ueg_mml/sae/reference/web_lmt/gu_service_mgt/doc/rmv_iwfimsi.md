# 删除IMSI号段属性(RMV IWFIMSI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除某个IMSI号段属性信息。

## 注意事项

如果删除了某个IMSI号段属性，则认为该IMSI号段是未配置的，默认对未被配置的IMSI号段提供融合UDM/HSS功能。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                           |
|:--------|:-------|:-------------------------------------------------------------------------------------------------------------------------------|
| IMSIPRE | IMSI前缀 | 可选必选参数：必选参数 参数含义：标识一条IMSI号段属性数据记录的关键字段，用于指定需要删除哪一条IMSI号段属性数据记录，操作员可以使用LST IWFIMSI命令查询获得。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。 |

## 使用实例

调整UTA业务时，如果需要删除某IMSI号段的UTA业务，例如删除“IMSI前缀”为“46000”的号段属性信息，进行如下配置：

```
RMV IWFIMSI: IMSIPRE="46000";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                               | 处理建议                                     |
|:--------|:--------|:-----------------------------------|:-----------------------------------------|
| ERR1009 | 参数丢失    | “IMSI前缀”参数未输入。                     | 根据实际情况，重新输入参数，确保“IMSI前缀”参数出现。            |
| ERR3007 | 记录不存在   | 输入的“IMSI前缀”参数值没有在ADD IWFIMSI命令中定义。 | 执行LST IWFIMSI命令查询已存在的IMSI号段，并根据实际情况重新输入。 |
