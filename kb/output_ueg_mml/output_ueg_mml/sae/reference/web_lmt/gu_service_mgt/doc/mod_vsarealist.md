# 修改VLR/SGSN漫游区域模板(MOD VSAREALIST)

## 命令功能

**须知** 

该命令属于高危命令，修改VLR/SGSN漫游区域模板会使引用此模板的VLR/SGSN漫游限制模板数据被同步修改。因此执行该命令前，请仔细评估当前操作的风险，确认对业务没有影响后方可执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用于对一条VLR/SGSN漫游区域模板数据记录的某些参数进行修改或调整，同时还用于为一条VLR/SGSN漫游区域模板数据记录增加多条VLR/SGSN号码资源。在该命令中，系统通过以下关键参数的组合来唯一标识一个VLR/SGSN漫游区域模板信息：

- “HLR序列号”
- “模板ID”
- “模板类型”

## 注意事项

- 该命令不允许进行批操作。
- “模板名”和“是否提供VLR/SGSN数据”两个参数至少输入一个。
- VLR/SGSN漫游区域模板中必须保证至少有一条VLR/SGSN号码前缀数据记录，如果本命令中的参数“是否提供VLR/SGSN数据”设置为“FALSE”，要删除VLR/SGSN漫游区域模板中唯一一条VLR/SGSN号码前缀数据记录，则无法删除，会返回错误码“ERR3096：模板不能为空”。
- 系统中同一个VLR漫游区域模板增加的VLR号码前缀数据记录数不能超过4000条，且所有VLR漫游区域模板增加的VLR号码前缀数据总记录数不能超过40000条。
- 系统中同一个SGSN漫游区域模板增加的SGSN号码前缀数据记录数不能超过4000条，且所有SGSN漫游区域模板增加的SGSN号码前缀数据总记录数不能超过40000条。
- 如果多个漫游区域模板中存在相同的VLR/SGSN前缀记录，则以漫游区域模板ID最小的为准。

## 参数说明

| 参数标识      | 参数名称           | 参数说明                                                                                                                                                                                                                                                             |
|:----------|:---------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN     | HLR序列号         | 标识VLR/SGSN漫游区域模板数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR中VLR/SGSN漫游区域模板数据记录的参数进行修改，操作员可以使用LST HLRSN命令查询获得。                                                                                                                                                             |
| TPLID     | 模板ID           | 标识VLR/SGSN漫游区域模板数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪个VLR/SGSN漫游区域模板数据记录的参数进行修改，操作员可以使用LST VSAREALIST命令查询获得。                                                                                                                                                            |
| TPLNAME   | 模板名            | 用于标识待修改的VLR/SGSN漫游区域模板的名称。 取值范围：1～60个字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                      |
| TPLTYPE   | 模板类型           | 标识VLR/SGSN漫游区域模板数据记录的关键字段之一（其取值不能被修改），用于对指定需要对哪个模板类型的模板进行修改，操作员可以使用LST VSAREALIST命令查询获得。                                                                                                                                                                         |
| PROV      | 是否提供VLR/SGSN数据 | 用于标识是否提供VLR/SGSN数据。通过该参数可以修改或删除模板中已经存在的VLR/SGSN数据。 取值范围：TRUE：如果指定的VLR/SGSN号码在模板中不存在，表示VLR/SGSN号码将被增加到模板中。如果指定的VLR/SGSN号码在模板中存在，会提示“SUCCESS0002:已经存在，不需要更新”。 FALSE：如果指定的VLR/SGSN号码在模板中已存在，表示该VLR/SGSN号码将被删除。如果指定的VLR/SGSN号码在模板中不存在，会返回“ERR3003：模板未定义”的错误码。 默认值：无。 |
| VLRSGSNNO | VLR/SGSN号码前缀   | 仅当本命令中的“是否提供VLR/SGSN数据”参数为“TRUE”或“FALSE”时该参数有效。用于标识VLR或SGSN号码前缀，用户在位置更新时，通过该参数进行最大前缀匹配。 该参数支持最大匹配原则，输入的内容可以是完整的VLR/SGSN号码，也可以是VLR/SGSN的号码前缀。最大匹配原则是指在查询时对于一个具体的号码而言，系统将在所有的记录中查找与其号码最相近的一个。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                        |

## 使用实例

1. 修改一条VLR/SGSN漫游区域模板数据记录。其中，“HLR序列号”为“1”，“模板ID”为“1”，“模板类型”为“VLR”，将“模板名”由“ARST”修改为“DESR”：

   ```
   MOD VSAREALIST: HLRSN=1, TPLID=1, TPLNAME="DESR", TPLTYPE=VLR;
   ```
2. 新增一条VLR/SGSN漫游区域模板数据记录。其中，“HLR序列号”为“1”，“模板ID”为“1”，“模板类型”为“VLR”，“是否提供VLR/SGSN数据”为“TRUE”，“VLR/SGSN号码前缀”为“567”：

   ```
   MOD VSAREALIST: HLRSN=1, TPLID=1, TPLTYPE=VLR, PROV=TRUE, VLRSGSNNO="567";
   ```
3. 删除一条VLR/SGSN漫游区域模板数据记录。其中：“HLR序列号”为“1”，“模板ID”为“1”，“模板类型”为“VLR”，“是否提供VLR/SGSN数据”为“FALSE”，“VLR/SGSN号码前缀”为“222”：

   ```
   MOD VSAREALIST: HLRSN=1, TPLID=1, TPLTYPE=VLR, PROV=FALSE, VLRSGSNNO="222";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                                                                                     | 处理建议                                                                                                                                       |
|:--------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1009 | 参数丢失    | “模板名”和“是否提供VLR/SGSN数据”两个参数一个都没有输入。                                                                                                                       | 根据实际情况，重新输入参数，确保“模板名”和“是否提供VLR/SGSN数据”两个参数至少输入一个。                                                                                          |
| ERR3003 | 模板未定义   | 可能原因为如下之一：“HLR序列号”或“模板ID”未定义。需要修改的模板的“模板ID”和“模板类型”不匹配。                                                                                                   | 根据实际情况，重新输入已定义的“HLR序列号”和“模板ID”，可通过LST HLRSN命令查询已定义的“HLR序列号”，通过LST VSAREALIST命令查询已定义的“模板ID”和“模板类型”在数据库中的匹配关系。                               |
| ERR3047 | 超过最大限制  | 可能原因为如下之一：同一个VLR漫游区域模板增加的VLR号码前缀数据记录数超过4000条。所有VLR漫游区域模板增加的VLR号码前缀总记录数超过40000条。同一个SGSN漫游区域模板增加的SGSN号码前缀数据记录数超过4000条。所有SGSN漫游区域模板增加的SGSN号码前缀总记录数超过40000条。 | 根据实际情况，如需增加VLR/SGSN号码前缀，处理步骤如下：执行LST VSAREALIST命令，查询已存在的VLR/SGSN号码前缀。执行该命令删除不必要的VLR/SGSN号码前缀。执行该命令增加VLR/SGSN号码前缀，确保增加的VLR/SGSN号码前缀在规定范围之内。 |
| ERR3096 | 模板不能为空  | 当参数“是否提供VLR/SGSN数据”设置为“FALSE”时，参数“VLR/SGSN号码前缀”的取值是该VLR/SGSN漫游区域模板中唯一的一条数据记录。                                                                            | 请确认是否需要删除VLR/SGSN漫游区域模板内唯一一条VLR/SGSN号码前缀记录，若需要删除，请通过RMV VSAREALIST命令删除相应模板。                                                                |
