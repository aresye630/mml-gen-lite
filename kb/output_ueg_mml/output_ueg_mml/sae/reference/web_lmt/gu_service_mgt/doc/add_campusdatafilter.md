# 增加园区数据过滤条件(ADD CAMPUSDATAFILTER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加园区用户数据导出的过滤条件。

该命令的使用场景：

该命令与**ADD CAMPUSCFG**命令配合使用。当使用**ADD CAMPUSCFG**命令增加园区配置时，会调用本命令配置的过滤条件。

1. 当大网UDM与园区UDM间由于传输网络故障和大网UDM失联时，为保证园区UDM上有对应的用户数据可供应急故障使用，使业务能够接续不中断，从而需要导出用户数据。
2. 在导出用户数据的过程中会根据园区配置数据以及本命令配置的过滤条件来导出对应用户数据。
3. 在导出过程中，根据过滤条件类型IMSI、MSISDN、DNN、切片依次和各个园区数据进行对比，找出归属的园区名称以及对应用户数据，用户数据只要匹配到其中一个则认为是匹配到此园区的数据。

## 注意事项

- 该命令仅在特定局点使用，其他局点不需要配置。
- 该命令使用时受**SET UDMSERV**命令中以下参数的控制，当以下参数实际取值满足参数取值范围要求时，该命令才生效。
  - “园区IMSI前缀过滤条件最大个数”
  - “园区MSISDN前缀过滤条件最大个数”
  - “园区DNN过滤条件最大个数”
  - “园区SNSSAI过滤条件最大个数”

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                        |
|:------------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FILTERNAME  | 过滤条件名称 | 可选必选说明：必选参数 参数含义：用于标识园区用户数据导出的过滤条件名称。 取值范围：长度不超过64位的字符串，只允许输入数字和字母。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                          |
| FILTERTYPE  | 过滤条件类型 | 可选必选说明：必选参数 参数含义：用于标识园区用户数据导出的过滤条件类型。 取值范围： IMSIPRE：IMSI前缀过滤条件类型。MSISDNPRE：MSISDN前缀过滤条件类型。DNN：DNN过滤条件类型。SNSSAI：切片过滤条件类型。 默认值：无。 配置原则：无。                                                                                                                                                                                     |
| FILTERVALUE | 过滤条件值  | 可选必选说明：必选参数 参数含义：用于标识园区用户数据导出的过滤条件值。 取值范围：长度不超过64位的字符串。 当“过滤条件类型”参数为“IMSIPRE”或者“MSISDNPRE”时：10~15位十进制字符串。当“过滤条件类型”参数为“DNN”时：1～64位的字符串，只允许输入字母、数字、“-”、“_”、“.”和“*”。当“过滤条件类型”参数为“SNSSAI”时：长度为1～10位字符串，由SST（Slice/Service Type）与SD（Slice Differentiator）组成，SST与SD间使用“-”连接。SST为取值范围是0～255的数字。SD是固定长度为3字节的十六进制字符串。 默认值：无。 配置原则：无。 |

## 使用实例

当前大网UDM对接管理3个园区UDM的园区数据过滤条件，需要增加3条园区数据过滤条件记录。

1. 增加一条园区用户数据导出的过滤条件：“过滤条件名称”为“FILTERNAME1”,“过滤条件类型”为“IMSIPRE”，“过滤条件值”为“963589125423”。

   ```
   ADD CAMPUSDATAFILTER: FILTERNAME="FILTERNAME1", FILTERTYPE=IMSIPRE, FILTERVALUE="963589125423";
   ```
2. 增加一条园区用户数据导出的过滤条件：“过滤条件名称”为“FILTERNAME2”,“过滤条件类型”为“DNN”，“过滤条件值”为“1-Y143D5”。

   ```
   ADD CAMPUSDATAFILTER: FILTERNAME="FILTERNAME2", FILTERTYPE=DNN, FILTERVALUE="1-Y143D5";
   ```
3. 增加一条园区用户数据导出的过滤条件：“过滤条件名称”为“FILTERNAME3”,“过滤条件类型”为“SNSSAI”，“过滤条件值”为“1-F143A5”。

   ```
   ADD CAMPUSDATAFILTER: FILTERNAME="FILTERNAME3", FILTERTYPE=SNSSAI, FILTERVALUE="1-F143A5";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 消息解释    | 原因分析                           | 处理建议                                                                                                                                                                                                                                                        |
|:--------|:--------|:-------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值。 | 输入的“过滤条件名称”参数取值没有在相应的参数取值范围之内。 | 根据实际情况，重新输入参数的取值，确保其取值符合要求。                                                                                                                                                                                                                                 |
| ERR1037 | 记录已存在。  | 输入的“过滤条件名称”参数对应的数据记录已经添加过。     | 使用LST CAMPUSDATAFILTER命令查询已添加过的数据记录。根据查询结果重新输入参数值，确保参数中至参数值未在查询结果中存在。                                                                                                                                                                                       |
| ERR1040 | 记录超过上限。 | 添加的过滤条件类型对应的取值超过上限。            | 根据实际情况，如需增加园区过滤数据，处理步骤如下： 执行LST CAMPUSDATAFILTER命令，查询已存在的园区过滤类型。执行LST UDMSERV命令查询“CAMPUS_MAX_IMSIPRE_NUM”“CAMPUS_MAX_MSISDNPRE_NUM”“CAMPUS_MAX_DNN_NUM”和“CAMPUS_MAX_SNSSAI_NUM”参数的默认取值。执行RMV CAMPUSDATAFILTER命令，删除不需要的过滤条件类型数据记录，直到已存在的数据记录小于默认参数取值时才可进行添加。 |
