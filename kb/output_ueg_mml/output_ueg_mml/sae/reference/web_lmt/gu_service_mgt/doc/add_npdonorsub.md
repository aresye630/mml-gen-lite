# 增加本网携出用户(ADD NPDONORSUB)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用于增加携出用户数据。此操作支持批处理。

## 注意事项

- IMSI/ISDN、ISDNFILE和FILE是条件可选参数，提供IMSI/ISDN参数、ISDNFILE或FILE参数中的其中之一即可，但这三组参数不能同时出现。
- 增加单个携出用户时，可使用IMSI/ISDN参数，其中，ISDN为必选参数，IMSI为可选参数。
- 增加多个携出用户时，可使用RECORDCOUNT、ISDNFILE或FILE参数，这三个参数为条件可选参数，提供其中之一即可，但不能同时出现。

## 参数说明

| 参数标识        | 参数名称           | 参数说明                                                                             |
|:------------|:---------------|:---------------------------------------------------------------------------------|
| IMSI        | IMSI           | IMSI号码，E.212格式的编码，6～15位的十进制数字。 说明：可选参数。                                          |
| ISDN        | MSISDN         | MSISDN号码，E.164格式的编码，1～15位的十进制数字。                                                 |
| RECORDCOUNT | 用户个数           | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。 |
| ISDNFILE    | MSISDN文件名      | 文件名称，1～16位的数字或字符组成的字符串，不可包括路径名称。 ISDNFILE的内容由不连续的MSISDN号码组成。 说明：可选参数。            |
| FILE        | IMSI/MSISDN文件名 | 文件名称，1～16位的数字或字符组成的字符串，不可包括路径名称。 FILE的内容由不连续的IMSI号码和对应的MSISDN号码的组成。              |
| RN          | 路由码            | 路由码，1～10位的十进制数字或者A~E字符。 说明：必选参数。                                                 |
| MSCNUM      | MSC号码          | MSC号码，E.164格式的编码，1～15位的十进制数字。                                                    |

## 使用实例

增加单个携出用户。

增加IMSI号码为4601075003001，MSISDN号码为86131075003001，路由码为1112的携出用户，命令如下：

```
ADD NPDONORSUB: IMSI="4601075003001",ISDN="86131075003001", RN="1112";
```
