# 删除前转号码数据(RMV FTNNCS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除前转号码是否通知主叫用户的属性。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                    |
|:-------|:-------|:------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 标识前转号码属性记录的关键字段之一，用于指定在哪个HLR上删除前转号码的是否通知主叫用户的属性，操作员可以使用LST HLRSN命令查询获得。 |
| FTN    | 前转号码   | 标识前转号码属性记录的关键字段之一，用于指定需要删除哪个前转号码的是否通知主叫用户的属性，操作员可以使用LST FTNNCS命令查询获得。   |

## 使用实例

删除“HLR序列号”为“1”的前转号码及其属性。其中，“前转号码”为“8613907550001”：

```
RMV FTNNCS: HLRSN=1, FTN="8613907550001";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                            | 处理建议                                               |
|:--------|:--------|:--------------------------------|:---------------------------------------------------|
| ERR1004 | 无效的参数值  | 参数“前转号码”的取值中含有0～9以外的字符。         | 重新输入“前转号码”，确保只含有0～9以内的字符。                          |
| ERR3007 | 记录不存在   | HLR序列号和前转号码对应的前转号码属性记录不存在或已被删除。 | 使用LST FTNNCS命令查询后，重新确认要删除哪个HLR序列号和前转号码对应的前转号码属性记录。 |
