# 增加SM2公钥（ADD SM2PUBKEY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加SM2公钥记录。

## 注意事项

- 本命令为局点定制命令，非定制局点使用前请务必先联系华为技术支持。
- 执行本命令生成SM2公钥记录时，相同“HLR序列号”下的“公钥名”参数取值不能重复。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                               |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN   | HLR序列号 | 可选必选说明：必选参数 参数含义：用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1~255 默认值：无。 配置原则：无。                                                                                            |
| KEYSNO  | 密钥序列号  | 可选必选说明：必选参数 参数含义：用于标识国密SM2公钥序列号。 取值范围：1～65535 默认值：无。 配置原则：无。                                                                                                                       |
| KEYNAME | 公钥名    | 可选必选说明：必选参数 参数含义：用于标识国密SM2公钥名称。 取值范围：1～60位由字母、数字或“.”、“-”等字符组成的字符串。该参数输入字母时字母转换为小写在数据库中存储。 默认值：无。 配置原则： 该参数取值和业务发放系统的数字证书CN取值相同。同一个“HLR序列号”下该参数唯一。                                  |
| PUBKEY  | 公钥值    | 可选必选说明：必选参数 参数含义：用于标识国密SM2公钥值。 取值范围：130位的十六进制字符串。 默认值：无。 配置原则：SM2公钥长度为65个字节，第一个字节为压缩标识，固定为“04”，表示公钥未被压缩。当密钥中间存在空格或":"时，系统默认去除空格和":"，去除空格和":"后公钥有效长度为130位；包含空格和":"时，最大允许的输入长度为194位。 |

## 使用实例

增加一个SM2公记录，其中“HLR序列号”为“1”、“密钥序列号”为“2”、“公钥名”为“PKEYnamehlr1pkeysno1”、“公钥值”为“04DC406DDC9A75D8DFBC50E258F5B2DB6C71F1CF1AFDC1EA4615233603EFBCC3C0A24130C5579843DAB47119EC1D1BF3C5ED595B7C9C3AEE97D00146A23872A0B0”:

```
ADD SM2PUBKEY: HLRSN=1, KEYSNO=2, KEYNAME="PKEYnamehlr1pkeysno1", PUBKEY="04DC406DDC9A75D8DFBC50E258F5B2DB6C71F1CF1AFDC1EA4615233603EFBCC3C0A24130C5579843DAB47119EC1D1BF3C5ED595B7C9C3AEE97D00146A23872A0B0";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                   | 处理建议                                                                                                                     |
|:--------|:--------|:-------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------|
| ERR3047 | 超过最大限制  | 同一个“HLR序列号”中增加的SM2公钥记录数超过5000条。                        | 根据实际情况，如需生成SM2公钥，处理步骤如下： 执行LST SM2PUBKEY命令，查询已存在的SM2公钥。执行RMV SM2PUBKEY命令，删除不必要的SM2公钥记录。执行该命令增加SM2公钥，确保增加的记录数在规定范围之内。     |
| ERR3006 | 记录已存在   | 可能原因如下： 该“HLR序列号”下已存在相同的“密钥序列号”。该“HLR序列号”下已存在相同的“公钥名”。 | 执行LST SM2PUBKEY命令，查询已存在的SM2公钥。重新输入“HLR序列号”或“密钥序列号”，确保同一个“HLR序列号”下的“密钥序列号”不重复。重新输入“HLR序列号”或“公钥名”，确保同一个“HLR序列号”下的“公钥名”不重复。 |
| ERR3044 | 无效的参数取值 | 输入的“公钥名”或“公钥值”不在取值范围内。                                 | 按照参数取值范围和配置原则修改参数取值后重新执行本命令增加SM2公钥。                                                                                      |
