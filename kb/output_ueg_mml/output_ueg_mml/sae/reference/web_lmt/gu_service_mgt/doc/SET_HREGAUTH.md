# 设置IMPU的注册权限(SET HREGAUTH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于在HSS的业务数据库中设置指定IMPU的注册权限。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                             |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------------------|
| IMPU    | IMPU   | 用于指定一个需要设置注册权限的IMPU，要求输入的IMPU值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无                                             |
| REGAUTH | 注册权限   | 用于指定IMPU的注册权限。 取值范围：FALSE(False)：不允许注册。TRUE(True)：允许注册 缺省值： 无 说明：当用户只开户但不执行本命令签约该业务，执行LST HREGAUTH命令查询时，参数“注册权限”默认为“TRUE(True)”。 |

## 使用实例

设置IMPU的注册权限。IMPU：sip:impuinfo@huawei.com，注册权限：FALSE。

```
SET HREGAUTH:IMPU="sip:impuinfo@huawei.com", REGAUTH=FALSE;
```
