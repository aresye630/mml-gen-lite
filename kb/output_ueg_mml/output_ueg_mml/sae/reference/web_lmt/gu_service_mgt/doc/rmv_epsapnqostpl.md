# 删除EPSAPNQOS模板(RMV EPSAPNQOSTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条EPS模板数据记录。

## 注意事项

如果已经通过**MOD EPSSER**命令关联该模板，当执行该命令删除EPS模板时，系统会提示“ERR3005:模板已经被使用”的错误信息，该EPS模板不能被删除。如果要删除该EPS模板，必须先执行**MOD EPSSER**命令去签约用户EPS业务。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                   |
|:-------|:-------|:-----------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 标识EPS模板数据记录的关键字段之一，用于指定在哪个HLR上删除EPS模板的数据记录，操作员可以使用LST HLRSN命令查询获得。     |
| TPLID  | 模板ID   | 标识EPS模板数据记录的关键字段之一，用于指定需要删除哪条EPS模板的数据记录，操作员可以使用LST EPSAPNQOSTPL命令查询获得。 |

## 使用实例

删除“HLR序列号”为“1”，“模板ID”为“10”的EPS模板，命令如下：

```
RMV EPSAPNQOSTPL: HLRSN=1, TPLID=10;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                              | 处理建议                                                                                    |
|:--------|:--------|:----------------------------------|:----------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | “HLR序列号”和“模板ID”参数对应的EPS模板数据记录不存在。 | 根据实际情况，重新输入参数，确保“HLR序列号”和“模板ID”参数对应的EPS模板数据记录已存在。已存在的EPS模板数据记录可以通过LST EPSAPNQOSTPL命令查询。 |
| ERR3005 | 模板已经被使用 | 用户已签约该模板。                         | 根据实际情况，确定是否要删除该模板。如果确实需要删除，先通过MOD EPSSER命令去签约用户EPS业务，然后才能执行RMV EPSAPNQOSTPL命令删除。        |
