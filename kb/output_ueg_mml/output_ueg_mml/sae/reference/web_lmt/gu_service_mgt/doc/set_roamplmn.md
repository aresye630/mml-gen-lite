# 配置运营商的PLMN标识(SET ROAMPLMN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于配置运营商的PLMN标识，用以匹配一个PLMN号码对应的运营商。设置不同运营商对应的PLMN号码时，命令支持运营商网络PLMN标识的增加，修改和删除。

## 注意事项

- 该命令只可以配置非本国网络。
- UDM支持增加500个运营商，支持每个运营商增加500个“PLMN标识”，所有运营商的“PLMN标识”最多为10000个。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                  |
|:--------|:-------|:--------------------------------------------------------------------------------------|
| HLRSN   | HLR序列号 | 用于标识本地HLR。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1～255 默认值：无。                           |
| OPRID   | 运营商ID  | 用于标识一个运营商数据记录。 取值范围：1～65535 默认值：无。                                                    |
| OPTYPE  | 操作类型   | 用于标识执行该命令所实现的操作类型。 取值范围：ADD：增加PLMN标识DEL：删除PLMN标识MOD：修改运营商名称DELALL：删除运营商配置信息 默认值：无。    |
| OPRNAME | 运营商名称  | 仅当本命令中的“操作类型”设置为“ADD”或者“MOD”时该参数有效。用于标识一个运营商数据记录。 取值范围：1～60位由字母、数字或特殊字符组成的字符串。 默认值：无。 |
| PLMNID  | PLMN标识 | 仅当本命令中的“操作类型”设置为“ADD”或者“DEL”时该参数有效。用于标识运营商网络PLMN标识。 取值范围：5位或6位十进制数字组成的字符串。 默认值：无。     |

## 使用实例

配置运营商的PLMN标识，“HLR序列号”为“1”，“运营商ID”为“1”，“操作类型”为“ADD”，“运营商名称”为“Peking1”，“PLMN标识”为“22356”：

```
SET ROAMPLMN: HLRSN=1, OPRID=1, OPTYPE=ADD, OPRNAME="Peking1", PLMNID="22356";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见本命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释                         | 原因分析                                    | 处理建议                                        |
|:--------|:------------------------------|:----------------------------------------|:--------------------------------------------|
| ERR1004 | 无效的参数值                        | 参数“PLMN标识”的取值不是5位或6位十进制数字组成的字符串。        | 根据实际情况，重新输入参数“PLMN标识”的取值，确保其取值符合要求。         |
| ERR4048 | 运营商名称和运营商ID不一致                | 参数“运营商名称”和参数“运营商ID”的取值不一致。              | 根据实际情况，重新输入参数“运营商名称”和参数“运营商ID”的取值，确保其取值相一致。 |
| ERR4096 | 运营商的最后一条PLMN标识，需要通过DELALL方式删除 | 删除运营商的最后一条PLMN标识时，参数“操作类型”取值为“DEL”。     | 删除运营商的最后一条PLMN标识，参数“操作类型”取值应为“DELALL”。      |
| ERR4095 | PLMN标识已经被其他运营商使用              | 当“操作类型”为“ADD”时，参数“PLMN标识”的取值已经被其他运营商使用。 | 根据实际情况，重新输入参数“PLMN标识”的取值，确保其取值未被其他运营商使用。    |
