# 增加组ID模板(ADD GROUPIDTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该组命令用于增加一条组ID模板数据记录。

操作员通过执行**MOD TPLVGCS**或**MOD TPLVBS**命令给用户签约组ID模板ID签约VGCS（Voice Group Call Service）/VBS（Voice Broadcast Service）业务，可减少用户签约VGCS/VBS业务的复杂性。

## 注意事项

系统中增加的VGCS/VBS模板记录数分别不能超过3000条。

## 参数说明

| 参数标识                    | 参数名称                  | 参数说明                                                                                                                                                                                                                                            |
|:------------------------|:----------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN                   | HLR序列号                | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                                                    |
| TPLID                   | 模板ID                  | 用于标识待增加模板在系统中的序号。 取值范围：0～65534 默认值：无。                                                                                                                                                                                                           |
| TPLNAME                 | 模板名                   | 用于标识待增加模板在系统中的名称。 取值范围：1～60个字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                              |
| GROUPTYPE               | 组类型                   | 用于标识HLR支持的组呼类型。 取值范围：VGCS：语音群组呼叫业务，用户可以通过数字集群终端发起VGCS呼叫，实现多对多的话音呼叫业务。 VBS：语音广播业务，用户可以通过数字集群终端发起VBS呼叫，实现一对多的话音呼叫业务。 默认值：无。                                                                                                                       |
| CAPINITONROAMING        | 初始化组呼能力               | 用于标识当用户漫游出归属PLMN（Public Land Mobile Network）时，是否支持初始化组呼业务的能力。 取值范围：TRUE：支持初始化组呼业务的能力。 FALSE：不支持初始化组呼业务的能力。 默认值：无。                                                                                                                               |
| COUNT                   | 组ID个数                 | 仅当本命令中的“组类型”参数为“VGCS”或“VBS”时该参数有效。用于标识组ID模板中组ID的个数，每个组ID模板最多可以设置50个组ID。 取值范围：1～50 默认值：无。                                                                                                                                                        |
| GROUPID1-GROUPIDX       | 组ID1～组IDX             | 仅当本命令中的“组ID个数”参数为“1”～“50”时该参数有效。用于标识组呼ID。将业务用户划分为不同的功能组，用组呼ID标识。业务用户签约组呼业务时将组呼ID存储在UDM中，同时组呼ID也需要存储在业务用户的手机SIM卡中。业务用户在组呼区域中通过拨打组呼ID发起组呼。 取值范围：1～8位十进制数字组成的字符串。 默认值：无。 说明：当SET MAPCONF命令中“是否支持GT800业务”为“FALSE”时，取值范围为0～99999999。 说明：X为“组ID个数”的值。 |
| CAPINITVBS1-CAPINITVBSX | VBS组呼1发起能力～VBS组呼X发起能力 | 仅当本命令中的“组类型”参数为“VBS”并且“组ID个数”参数为“1”～“50”时该参数有效。用于标识用户在归属PLMN时，是否支持初始化VBS组呼业务的能力。 取值范围：TRUE：支持初始化VBS组呼业务的能力。 FALSE：不支持初始化VBS组呼业务的能力。 默认值：无。 说明：X为“组ID个数”的值。                                                                                      |

## 使用实例

为用户以模板方式签约VGCS业务，操作员需要配置以下数据。

1. 在“HLR序列号”为“1”的UDM上增加一条“组类型”为“VGCS”的组ID模板数据记录，实现多对多的话音呼叫业务。其中，“初始化组呼能力”为“TRUE”，“组ID个数”为“1”，“组IDX”为“1234”：

   ```
   ADD GROUPIDTPL: HLRSN=1, TPLID=1, GROUPTYPE=VGCS, CAPINITONROAMING=TRUE, COUNT=1, GROUPID1="1234";
   ```
2. 执行**MOD TPLVGCS**命令给用户以模板方式签约VGCS业务。

   ```
   MOD TPLVGCS: IMSI="460000009123456", PROV=TRUE, TPLID=1;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释     | 原因分析                                              | 处理建议                                                                                                                                              |
|:--------|:----------|:--------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3097 | HLR序列号未定义 | “HLR序列号”未定义。                                      | 根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求。                                                                                                                 |
| ERR1004 | 无效的参数值    | 界面输入的非“HLR序列号”参数不在相应的参数取值范围内。                     | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                                  |
| ERR3004 | 记录已存在     | 本次操作输入的“模板ID”在数据库中已存在。                            | 根据实际情况，重新输入参数，保证输入的“模板ID”和系统中已存在的模板ID不重复。可执行LST GROUPIDTPL命令查询系统中已存在的组ID模板。                                                                       |
| ERR3044 | 无效的参数取值   | 界面输入的“组ID1”～“组IDX”参数不唯一。                          | 界面输入的“组ID1”～“组IDX”参数必须两两不同。                                                                                                                       |
| ERR3047 | 超过最大限制    | 可能原因为如下之一：增加的VGCS模板记录数超过3000条。增加的VBS模板记录数超过3000条。 | 根据实际情况，如需增加VGCS/VBS模板，处理步骤如下：执行LST GROUPIDTPL命令，查询已存在的VGCS/VBS模板。执行RMV GROUPIDTPL命令，删除不必要的VGCS/VBS模板。执行该命令增加VGCS/VBS模板，确保增加的VGCS/VBS模板记录数在规定范围之内。 |
