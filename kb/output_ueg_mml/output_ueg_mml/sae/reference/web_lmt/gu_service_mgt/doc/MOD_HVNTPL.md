# 修改拜访网络模板(MOD HVNTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成用户注册失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在HSS的业务数据库中修改一个拜访网络模板的信息，可以修改除拜访网络模板ID以外的所有参数。在该命令中，系统通过“拜访网络模板ID”来唯一标识一个拜访网络模板，该参数可以通过使用**LST HTPLINF**命令查询获得。

## 注意事项

- 如果操作员在指定拜访网络模板中修改参数属性，则所有引用该模板的用户都会修改该属性，将可能导致用户注册失败，请操作员在执行该操作之前仔细确认任务的可行性。
- 使用该命令时，待修改的可选参数中必须设置其中至少一个，否则HSS返回失败。
- 如果用户处于限制漫游状态，要放开用户的漫游权限，使用本命令将“缺省漫游限制策略”参数修改为“PERMISSION(Permission)”。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                  |
|:------------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号   | 用于标识一个HLR序列号。 取值范围：0~255 默认值：无。 说明： 可选参数当该参数不输入时，系统默认初始设置值为0。                                                                                                                                                                                                                         |
| TPLID       | 拜访网络模板ID | 标识指定拜访网络模板的关键字段（其取值不能被修改），用于指定需要对哪一条拜访网络模板的参数进行修改或调整，操作员可以使用LST HTPLINF命令查询获得。 说明：必选参数。                                                                                                                                                                                               |
| TPLNAME     | 拜访网络模板名称 | 用于标识拜访网络模板修改后的名称。 取值范围：长度不超过64的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 说明：可选参数。                                                                                                                                                                                                           |
| MATCHTYPE   | 匹配类型     | 用于标识指定拜访网络模板修改后的匹配类型。 取值范围： FRONT(Front)：表示前向匹配。前向匹配原则表示拜访网络地址只要前缀相同的都匹配。如果签约的拜访网络地址模板信息为HSS，则前缀为HSS的拜访网络地址都能匹配成功，例如携带的拜访网络地址为“HSS.com”。BACK(Back)：表示后向匹配。后向匹配原则表示拜访网络地址后缀相同的都匹配。如果签约的拜访网络地址模板信息为huawei.com，则后缀为huawei.com的拜访网络地址都能匹配成功，例如携带的拜访网络地址为“HSS.huawei.com”。 默认值：无。 说明：可选参数。 |
| DEFAULTRULE | 缺省漫游限制策略 | 用于标识指定拜访网络模板修改后的缺省限制策略，当用户携带的接入位置信息与签约的拜访网络地址信息匹配失败时决策是否允许用户从此接入位置注册。 取值范围： PERMISSION(Permission)：表示IMS系统将允许用户注册。RESTRICTION(Restriction)：表示IMS系统将限制用户注册。 默认值：无。 说明：可选参数。                                                                                                            |
| COMMENT     | 模板注释说明   | 用于标识指定拜访网络模板修改后的注释。 取值范围：长度不超过512的字符串 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                 |

## 使用实例

1. 修改拜访网络模板，“拜访网络模板ID”为“10”，“匹配类型”为“BACK(Back)”：

   ```
   MOD HVNTPL: TPLID=10, MATCHTYPE=BACK;
   ```
2. 修改拜访网络模板，“拜访网络模板ID”为“10”，“拜访网络模板名称”为“VN Templet”，“匹配类型”为“BACK(Back)”，“缺省漫游限制策略”为“RESTRICTION(Restriction)”，“模板注释说明”为“Visited Network Templet”：

   ```
   MOD HVNTPL: TPLID=10, TPLNAME="VN Templet", MATCHTYPE=BACK, DEFAULTRULE=RESTRICTION, COMMENT="Visited Network Templet";
   ```
