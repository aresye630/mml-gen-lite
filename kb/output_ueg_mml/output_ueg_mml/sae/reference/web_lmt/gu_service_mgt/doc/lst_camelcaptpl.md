# 查询CAMEL能力模板(LST CAMELCAPTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用于查询CAMEL能力配置模板。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                          |
|:-------|:-------|:----------------------------------------------|
| HLRSN  | HLR序列号 | HLR序列号。 取值范围：1～255。 说明：在PGW支持容灾功能或虚拟HLR功能时设置。 |
| TPLID  | 模板ID   | CAMELCAP模板ID。 取值范围：0～65534。                   |

## 使用实例

查询虚拟HLR1上模板ID为“1”的CAMEL能力配置模板，命令如下：

LST CAMELCAPTPL:HLRSN=1, TPLID=1;
