# 增加PS用户模板(ADD PSUSERTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在数据库中增加一条PS用户模板数据记录。用户通过**MOD TPLPSSER**命令使用PS用户模板ID签约PS业务。

## 注意事项

系统中增加的PS用户模板记录数不能超过20000条，且所有PS用户模板增加的PDP/PDN上下文总记录数不能超过40000条。

## 参数说明

| 参数标识          | 参数名称          | 参数说明                                                                       |
|:--------------|:--------------|:---------------------------------------------------------------------------|
| HLRSN         | HLR序列号        | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                               |
| TPLID         | 模板ID          | 用于标识模板ID。 取值范围：0～65534 默认值：无。                                              |
| TPLNAME       | 模板名           | 用于标识模板名称。 取值范围：1～60位字母或数字组成的字符串。 默认值：无。                                    |
| CNTXID        | PDP/PDN上下文索引值 | 用于标识PDP/PDN上下文索引值，每个PDP/PDN上下文的索引值不能相同。 取值范围：1～50 默认值：无。                   |
| PSAPNQOSTPLID | PSAPNQOS模板ID  | 用于标识PSAPNQOS模板ID。该参数必须先由ADD PSAPNQOSTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。 |

## 使用实例

增加PS用户模板，“模板ID”为“2”，“模板名”为“PSUSERTPL\_01”，“PDP/PDN上下文索引值”为“1”，“PSAPNQOS模板ID”为“1”。命令如下：

```
ADD PSUSERTPL: HLRSN=1, TPLID=2, TPLNAME="PSUSERTPL_01", CNTXID=1, PSAPNQOSTPLID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                    | 处理建议                                                                                                                                                               |
|:--------|:--------|:------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3047 | 超过最大限制  | 可能原因为如下之一：增加的PS用户模板记录数超过20000条。 所有PS用户模板增加的“PDP/PDN上下文索引值”总记录数超过40000条。 | 根据实际情况，如需增加PS用户模板，处理步骤如下：执行LST PSUSERTPL命令，查询已存在的PS用户模板。执行RMV PSUSERTPL命令，删除不必要的PS用户模板。或执行MOD PSUSERTPL命令，删除不必要的PDP/PDN上下文索引值。执行该命令增加PS用户模板，确保增加的PS用户模板记录数在规定范围之内。 |
