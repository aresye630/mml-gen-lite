# 修改CR业务(MOD CR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于修改呼叫重定向业务，包括签约、去签约呼叫重定向业务。

执行此命令后，如果是给用户签约该业务，则会下发插入用户数据消息；如果是给用户去签约该业务，则会下发删除用户数据消息。

## 注意事项

- 当使用连续批操作时需定义RECORDCOUNT与IMSI/ISDN参数，当使用非连续批操作时需定义IMSIFILE/ISDNFILE参数。
- IMSI、ISDN、IMSIFILE、ISDNFILE是条件可选参数，有且只能有一个参数出现。
- RECORDCOUNT一定不能与IMSIFILE或ISDNFILE同时存在。

## 参数说明

| 参数标识         | 参数名称      | 参数说明                                                                               |
|:-------------|:----------|:-----------------------------------------------------------------------------------|
| IMSI         | IMSI      | IMSI号码，E.212格式的编码，6～15位的十进制数字。                                                     |
| ISDN         | MSISDN    | ISDN号码，E.164格式的编码，为1～15位的十进制数字。                                                    |
| RECORDCOUNT  | 用户个数      | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。 |
| IMSIFILE     | IMSI文件名   | IMSI文件名称，IMSIFILE包含多个不连续的IMSI号码，每个IMSI号码占一行，16个以内的字母或数字组成的字符串。                     |
| ISDNFILE     | MSISDN文件名 | MSISDN文件名称，ISDNFILE包含多个不连续的MSISDN号码，每个MSISDN号码占一行。16个以内的字母或数字组成的字符串。               |
| PROV         | 是否提供呼叫重定向 | 是否提供呼叫重定向业务。TRUE：提供FALSE：不提供 可选参数。                                                 |
| CALLREDIRECT | 呼叫重定向类别   | 仅当本命令中的“是否提供呼叫重定向”参数为“TRUE”时该参数有效。呼叫重定向业务标识，值域为0～255。                              |

## 使用实例

1. 为IMSI号码是460000009123456的用户提供呼叫重定向业务。

   MOD CR: IMSI="460000009123456", PROV=TRUE, CALLREDIRECT =1;
2. 为IMSI号码是460000009123456的用户撤销呼叫重定向业务。

   MOD CR: IMSI="460000009123456", PROV=FALSE;
3. 为IMSI号码是460000009123455、460000009123466和460000009123477的用户提供呼叫重定向业务。
   1. 编写IMSIFILE，文件名称为IMSIBAT，内容如下：

      460000009123455

      460000009123466

      460000009123477
   2. 通过Web UI上的文件选项将文件上传到指定位置。
   3. 执行MOD CR命令提供CR业务。

      MOD CR: IMSIFILE="IMSIBAT", PROV=TRUE, CALLREDIRECT=1;
