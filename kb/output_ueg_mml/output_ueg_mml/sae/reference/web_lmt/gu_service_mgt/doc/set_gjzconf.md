# 设置高价值业务（SET GJZCONF）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于为高价值用户设置业务参数。

## 注意事项

一个“HLR序列号”下仅可配置一条高价值业务配置记录，系统中最多可配置255条高价值业务记录。

## 参数说明

| 参数标识       | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|:-----------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN      | HLR序列号      | 可选必选说明：必选参数 参数含义：用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1～255 默认值：无。 配置原则：一个“HLR序列号”下仅可配置一条高价值业务配置记录。                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| PROV       | 是否提供业务      | 可选必选说明：必选参数 参数含义：用于标识是否提供高价值业务。 取值范围： TRUE：提供FALSE：不提供 默认值：无。 配置原则：如果该参数取值为“FALSE”时，表示删除配置记录。                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| AREATYPE   | 区域类型        | 可选必选说明：条件可选参数 参数含义：用于标识区域类型，在该区域内高价值用户不下发“APN和DNN控制列表”中APN/DNN下签约的静态IP地址。 取值范围： LOCAL：本地网络，表示用户所在的服务网络和用户归属网络在同一个地区。LOCALDOMESTIC：国内本网，表示用户所在的服务网络和用户归属网络在同一个国家，且在同一个PLMN内。CROSSDOMESTIC：国内跨网，表示用户所在的服务网络和用户归属网络在同一个国家，但在不同的PLMN内。LOCALINTERNATIONAL：国际本网，表示用户所在的服务网络和用户归属网络不在同一个国家，但在相同的PLMN内。CROSSINTERNATIONAL：国际跨网，表示用户所在的服务网络和用户归属网络不在同一个国家，也不在同一个PLMN内。LOCALAREA：省内本网，表示用户所在的服务网络和用户归属网络在同一个省，且在同一个PLMN内。CROSSAREA：省内跨网，表示用户所在的服务网络和用户归属网络在同一个省，但在不同的PLMN内。 默认值：无。 配置原则： 仅当“是否提供业务”取值为“TRUE”时，该参数生效。如果为首次配置，该参数必须配置。如果不是首次配置，该参数与“APN和DNN控制列表”参数至少配置一个即可，如不携带则表示保持原值。 |
| APNDNNLIST | APN和DNN控制列表 | 可选必选说明：条件可选参数 参数含义：用于标识APN和DNN控制列表，用于在配置的“区域类型”范围内高价值用户不下发该列表中APN/DNN下签约的静态IP地址。 取值范围：1~4000个字符组成的字符串。 默认值：无。 配置原则： 仅当“是否提供业务”取值为“TRUE”时，该参数生效。 如果为首次配置，该参数必须配置。如果不是首次配置，该参数与“区域类型”参数至少配置一个即可，如不携带则表示保持原值。该参数由1个或多个APN/DNN组成。每个APN/DNN格式为1～63位的字符串，字符串由数字、字母、“.”、“-”或“_”组成。如果只有一个APN/DNN，参数不允许出现“"”或“&”，例如：Mnet.com。如果存在多个APN/DNN时，每个APN/DNN需要使用“""”标识，APN/DNN之间使用 “&”进行连接，在字符“"”前需要添加转义字符“\”，例如：\"Mnet.com\"&\"Cnet.com\"。如果存在多个APN/DNN时，单个APN/DNN中不允许出现“"”或“&”。如果存在多个APN/DNN时，多个APN/DNN不能重复。APN/DNN不允许配置为通配APN/DNN。                                                       |

## 使用实例

1. 给“HLR序列号”为“1”配置高价值业务。

   ```
   SET GJZCONF: HLRSN=1, PROV=TRUE, AREATYPE=LOCAL&LOCALDOMESTIC&CROSSDOMESTIC&LOCALAREA&CROSSAREA, APNDNNLIST="\"Mnet.com\"&\"Cnet.com\"";
   ```
2. 删除“HLR序列号”为“1”的高价值业务配置记录。

   ```
   SET GJZCONF: HLRSN=1, PROV=FALSE;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释     | 原因分析                                                                                                                                       | 处理建议                                                                                                                                                              |
|:--------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值    | 界面输入的“HLR序列号”参数不在相应的参数取值范围内。                                                                                                               | 根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求。                                                                                                                                 |
| ERR1009 | 参数丢失      | 可能原因为如下之一：未输入“HLR序列号”或“是否提供业务”。如果为首次配置，当“是否提供业务”取值为“TRUE”时，未同时设置“区域类型”和“APN和DNN控制列表”。如果不为首次配置，当“是否提供业务”取值为“TRUE”时，未设置“区域类型”和“APN和DNN控制列表”。 | 根据实际情况，重新输入参数，确保满足以下三点：“HLR序列号”或“是否提供业务”为必选参数，必须设置。如果为首次配置，当“是否提供业务”取值为“TRUE”时，“区域类型”和“APN和DNN控制列表”必须都配置。如果不为首次配置，当“是否提供业务”取值为“TRUE”时，“区域类型”或“APN和DNN控制列表”至少配置一个。 |
| ERR1010 | 参数冲突      | “是否提供业务”取值为“FALSE”时，输入了“区域类型”或“APN和DNN控制列表”参数。                                                                                             | 当“是否提供业务”取值为“FALSE”时，“区域类型”或“APN和DNN控制列表”参数不能存在。                                                                                                                  |
| ERR3007 | 记录不存在     | “是否提供业务”取值为“FALSE”时，输入的“HLR序列号”未配置高价值业务数据。                                                                                                 | 根据实际情况，重新输入“HLR序列号”的取值，确保该“HLR序列号”已配置高价值业务数据，或设置“是否提供业务”取值为“TRUE”为该“HLR序列号”配置高价值业务数据。                                                                             |
| ERR3097 | HLR序列号未定义 | “HLR序列号”未定义。                                                                                                                               | 根据实际情况，重新输入“HLR序列号”的取值，或先由ADD HLRSN命令定义“HLR序列号”，然后才能在此处引用。                                                                                                        |
