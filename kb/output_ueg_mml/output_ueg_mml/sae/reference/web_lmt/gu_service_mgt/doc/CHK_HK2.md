# 校验K2(CHK HK2)

## 命令功能

该命令用于校验K2密钥，以检查已添加的K2密钥是否正确。

## 注意事项

- 如果在“命令输入区”输入命令后再输入各参数，“K2值”出于安全原因，仅显示“\*”。
- 如果在“MML命令编辑区”直接输入带参数的命令，命令中的“K2值”以明文显示。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                       |
|:--------|:-------|:---------------------------------------------------------------------------|
| K2SNO   | K2序列号  | 标识K2数据记录的关键字段（其取值不能被修改），用于指定需要对哪个K2序列号的K2数据记录的参数进行校验，操作员可以使用LST HK2命令查询获得。 |
| K2VALUE | K2值    | 用于标识K2密钥值。 取值范围：64位的十六进制数字组成的字符串 默认值：无。                                    |

## 使用实例

校验一条K2数据记录，“K2序列号”为“2”，“K2值”为“8765432187654321876543218765432187654321876543218765432187654321”。

```
CHK HK2: K2SNO=2, K2VALUE="*****";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释            | 原因分析                                                          | 处理建议                                              |
|----------:|:-----------------|:--------------------------------------------------------------|:--------------------------------------------------|
| 900003520 | 请求消息中的K2Index不存在 | “K2序列号”未定义。                                                   | 根据实际情况，重新输入已定义的“K2序列号”，可通过LST HK2命令查询已定义的“K2序列号”。 |
| 900003523 | 密钥丢失             | 当SET MAPSERV命令中的“随机密钥默认ID”参数为非0，“随机密钥默认ID”参数对应的随机密钥材料不存在或不完整。 | 联系华为技术支持处理。                                       |
