# 查询K2(LST HK2)

- 注意事项

## 命令功能

该命令用于查询鉴权数据K2的配置信息。

- 若需要查询全部鉴权数据K2的配置信息，请不要输入任何参数。
- 若需要查询某条鉴权数据K2的配置信息，请输入“K2序列号”参数。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                            |
|:-------|:-------|:------------------------------------------------|
| K2SNO  | K2序列号  | 用于指示系统需要按照哪个K2序列号来查询K2数据记录；若不输入，则表示查询所有的K2数据记录。 |

## 使用实例

1. 查询全部鉴权数据K2的配置信息，不输入任何参数。

   ```
   LST HK2:;
   ```

   ```
   %%LST HK2:;%%
   RETCODE = 0 SUCCESS0001:操作成功

           "K2SNO" "KEYNAME"
           1       k2name1
           2       k2name2

   Total count = 2

   There is together 1 report

   --- END
   ```
2. 查询某条鉴权数据K2的配置信息，“K2序列号”为“1”。

   ```
   LST HK2: K2SNO=1;
   ```

   ```
   %%LST HK2: K2SNO=1;%%
   RETCODE = 0 SUCCESS0001:操作成功

           "K2SNO"    "KEYNAME"
           1          k2name1

   Total count = 1

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD HK2**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释            | 原因分析        | 处理建议                                               |
|----------:|:-----------------|:------------|:---------------------------------------------------|
| 900003520 | 请求消息中的K2Index不存在 | “K2序列号”未定义。 | 根据实际情况，重新输入已定义的“K2序列号”参数，可通过LST HK2命令查询已定义的K2数据记录。 |
