# 删除K4(RMV K4)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行该命令前，需要与华为技术支持确认后才可以实施。

此操作用来删除K4数据。

## 注意事项

只有没有被使用的K4数据才可以删除。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                     |
|:-------|:-------|:-----------------------------------------|
| HLRSN  | HLR序列号 | HLR序列号，有效值域为1～255，在PGW支持容灾功能或虚拟HLR功能时设置。 |
| K4SNO  | K4序列号  | K4序列号，值域为1～65535，必选参数。                   |

## 使用实例

删除2号K4索引对应且HLRSN=1的K4值。命令如下：

RMV K4: HLRSN=1,K4SNO=2;
