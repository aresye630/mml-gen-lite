## 命令功能

该命令用于给一号多卡用户修改语音邮箱业务，包括签约、去签约语音邮箱业务。

对于顺振类型的一号多卡用户，当某主叫用户呼叫被叫MSISDN号码的时候，系统会根据用户IMSI号码的呼叫序号顺序振铃，直到IMSI号码的呼叫序号较高用户通话成功，有可能9个在网的IMSI对应的用户都不接听电话，这时UDM支持把本次入呼叫转移到指定的语音邮箱中。当前UDM只支持2个语音邮箱号码。

对于在网用户执行该命令后，如果是给用户签约该业务，则UDM会向MSC/VLR/MME/S4SGSN下发插入用户数据消息；如果是给用户去签约该业务，则UDM会向MSC/VLR/MME/S4SGSN下发删除用户数据消息。对于不在网用户执行该命令后，则仅会更新用户在数据库中的数据，当用户进行位置更新时UDM将用户的一卡多号业务数据下发给MSC/VLR/MME/S4SGSN。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。
- 需要先执行**MOD MIMSI**命令给用户签约一号多卡业务，再执行该命令修改语音邮箱数据。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                    |
|:------------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 用于标识需要修改语音邮箱的一号多卡用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                               |
| ISDN        | MSISDN    | 用于标识需要修改语音邮箱的一号多卡用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                             |
| RECORDCOUNT | 用户个数      | 用于标识需要修改语音邮箱的一号多卡用户数目。 当需要为连续号码的多个用户修改语音邮箱时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户修改语音邮箱。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户修改语音邮箱，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名   | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要修改语音邮箱的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modmimsivm.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或十进制数字组成的字符串。 默认值：无。                                    |
| ISDNFILE    | MSISDN文件名 | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要修改语音邮箱的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modmimsivm.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或十进制数字组成的字符串。 默认值：无。                              |
| PROV        | 是否提供语音邮箱  | 用于标识是否向用户提供增强语音邮箱业务。 取值范围：TRUE：提供FALSE：不提供 默认值：无。                                                                                                                                                                       |
| VOICENUMBER | 语音邮箱号码    | 仅当本命令中的“是否提供语音邮箱”参数为“TRUE”时该参数有效。用于标识语音邮箱的号码。 取值范围：ISDN号码，E.164格式的编码，1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                           |
| VOICE_INDEX | 语音邮箱序号    | 用于标识语音邮箱的序号，即一号多卡顺振用户做被叫时，前转到语音邮箱的次序。 取值范围：1～2 默认值：无。 说明：当“是否提供增强语音邮箱业务”参数为“TRUE”，不携带“语音邮箱序号”参数时，表示签约1号语音邮箱。当“是否提供增强语音邮箱业务”参数为“FALSE”，不携带“语音邮箱序号”时，表示去签约所有语音邮箱。                                                         |

## 使用实例

需要先执行**MOD MIMSI**命令为用户签约一号多卡业务，再执行该命令为“IMSI”为“460000009123456”的用户提供语音邮箱业务，“语音邮箱号码”为“86123456”，“语音邮箱序号”为“1”，命令如下：

```
MOD MIMSIVM: IMSI="460000009123456", PROV=TRUE, VOICENUMBER="86123456", VOICE_INDEX=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| ERR1009 | 参数丢失       | “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数一个都没有输入。                                                  | “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现。                                                                 |

| ERR1025 | 批操作文件中格式非法 | 参数“IMSI文件名”或“MSISDN文件名”对应的批操作文件格式不正确。                                                              | 请根据IMSIFILE文件格式和ISDNFILE文件格式，重新确定对应的批操作文件格式。                                                                            |
