# 增加MAP消息地址过滤模板(ADD MAPADDRRESTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加MAP消息地址过滤模板。根据消息来源地址和模板中配置的地址号码前缀匹配结果（采用最大匹配原则）与定义的过滤规则，判断放通或者限制对应的MAP操作流程，若匹配，则返回“34（SYSTEM\_FAILURE）”即“系统失败”响应，此时短消息发送失败。

## 注意事项

无。

## 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                      |
|:-------------|:--------|:--------------------------------------------------------------------------------------------------------------------------|
| HLRSN        | HLR序列号  | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                              |
| TPLID        | 模板ID    | 用于标识MAP消息地址过滤模板在系统中的序号。 取值范围：0～65534 默认值：无。                                                                               |
| TPLNAME      | 模板名     | 用于标识MAP消息地址过滤模板在系统中的名称。 取值范围：1～60位字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。                                                     |
| MAPPROCEDURE | MAP操作流程 | 用于标识该MAP消息地址过滤模板增加的地址信息为哪个消息流程使用的地址。 取值范围：SRIFORSM：表示该模板中添加的地址信息为短信息取路由消息流程使用的地址。SRI：表示该模板中添加的地址信息为被叫取路由消息流程使用的地址。 默认值：无。 |
| RULE         | 地址过滤规则  | 用于标识该MAP消息地址过滤模板是限制或放通指定消息流程。 RESTRICT：表示限制指定的消息流程。PERMISSION：表示放通指定的消息流程。 默认值：RESTRICT。                                  |
| ADDRPREFIX   | 地址号码前缀  | 用于标识MAP消息地址号码前缀。当用户签约了该模板时，HSS9860将会消息流程中的地址信息与此处定义的地址号码前缀采用最大匹配原则进行匹配。 取值范围：1～15个十进制数字组成的字符串。 默认值：无。                     |

## 使用实例

增加一个MAP消息地址过滤模板信息，“HLR序列号”为“1”，“模板ID”为“2”，“模板名”为“test”，“MAP操作流程”为“SRIFORSM”，“地址过滤规则”为“RESTRICT”，“地址号码前缀”为“861389955”，命令如下：

```
ADD MAPADDRRESTPL: HLRSN=1, TPLID=2, TPLNAME="test", MAPPROCEDURE=SRIFORSM, RULE=RESTRICT, ADDRPREFIX="861389955";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释         | 原因分析                         | 处理建议                                                                                                                                 |
|:--------|:--------------|:-----------------------------|:-------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值        | 输入的“地址号码前缀”参数不在取值范围内。        | 重新输入“地址号码前缀”参数值，确保其为十进制数字格式。                                                                                                         |
| ERR3004 | 模板已存在         | 同一个虚拟HLR中，“模板ID”对应的模板信息已添加过。 | 先执行LST MAPADDRRESTPL命令查询系统中已存在的模板信息，根据查询结果重新执行该命令添加模板，确保“模板ID”在同一个虚拟HLR中唯一。                                                          |
| ERR3007 | 记录不存在         | “HLR序列号”未定义。                 | 根据实际情况，确认是否需要在新的虚拟HLR中添加模板信息，若需要则先使用ADD VHLRSN命令添加新的虚拟HLR，然后再执行该命令在新的虚拟HLR上添加模板信息；若不需要则请先使用LST HLRSN命令查询已存在的虚拟HLR序列号，根据查询结果重新添加模板信息。 |
| ERR4145 | 同一操作流程过滤规则不相同 | 同一操作流程的过滤规则必须相同。             | 重新输入“地址过滤规则”参数值，确保同一操作流程（短消息取路由或被叫取路由）的过滤规则相同，即同时限制或同时放通。                                                                            |
