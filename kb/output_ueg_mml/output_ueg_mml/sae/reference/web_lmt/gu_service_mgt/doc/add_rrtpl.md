# 设置RR模板(ADD RRTPL)

## 命令功能

该命令用于在HLR中增加区域漫游RR（Regional Roaming）模板。

区域漫游模板定义了用户在CC（Country Code）和NDC（National Destination Code）匹配下1～10个ZC（Zone Code）内的漫游限制状态，用户可以通过执行**MOD RSZI**命令签约区域漫游模板，只需签约对应区域数据的区域漫游模板，减少了操作的复杂性。用户在位置更新或签约时如果用户当前所在VLR/SGSN的CC和NDC在签约信息中，HLR就把ZC列表数据下发到用户所在的VLR/SGSN，VLR/SGSN收到ZC列表数据后，就可以根据用户所在漫游区域中的地区码来限制用户的漫游状态。如果用户不在签约的ZC列表中就限制用户漫游。

## 注意事项

- 系统中最多可增加20000条RR模板记录。
- 当系统中存在的RR模板记录数较多时，批量增加模板会导致CCU模块的CPU占用率上升幅度偏高，请在话务量低时执行。例如：当RR模板记录数为19900时，批量增加100个模板，CCU模块的CPU占用率增加8%。

## 参数说明

| 参数标识     | 参数名称       | 参数说明                                                                                                                                                                      |
|:---------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN    | HLR序列号     | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                              |
| TPLID    | 模板ID       | 用于标识待增加模板在系统中的序号。 取值范围：0～65534 默认值：无。                                                                                                                                     |
| TPLNAME  | 模板名        | 用于标识待增加模板在系统中的名称。 取值范围：1～60位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                        |
| CC       | CC         | 用于标识国家码，每个国家码最多可以对应200个国内目的地代码。 取值范围：1～6位十进制数字组成的字符串。 默认值：无。                                                                                                              |
| NDC      | NDC        | 用于标识国内目的地代码。即移动业务接入码，它是由本国电信主管部门在本国范围内统一分配的PLMN网络号。例如，目前在中国，中国移动使用的PLMN网络号为134～139、中国联通使用的PLMN网络号为130～133。 取值范围：1～6位十进制数字组成的字符串。 默认值：无。 配置原则：执行该命令添加模板时每个CC最多可以对应200个NDC。 |
| ZC1-ZC10 | 区域码1～区域码10 | 用于标识漫游地区码，最多可设置10个漫游地区码。 取值范围：0000～FFFF（4位十六进制数字组成的字符串），其中FFFF是无效值。 默认值：无。 配置原则：执行该命令添加模板时每对CC和NDC的组合最多可以对应10个ZC。                                                         |

## 使用实例

为用户签约区域漫游业务操作员需要配置以下数据。

1. 在“HLR序列号”为“1”的HLR上增加一条区域漫游模板的数据记录。其中，“模板号”为“2”，“模板名”为“RR-01”，“国家码”为“86”， “国内目的地代码”为“000001”，“地区码1”为“0001”，“地区码10”为“0010”：

   ```
   ADD RRTPL: HLRSN=1, TPLID=2, TPLNAME="RR-01", CC="86", NDC="000001", ZC1="0001", ZC10="0010";
   ```
2. 执行**MOD RSZI**命令给用户签约区域漫游限制业务。

   ```
   MOD RSZI: IMSI="13902912345", RROPTION=RR_TEMPLATE, RRTPL=2;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                 | 处理建议                                                                                                      |
|:--------|:--------|:-------------------------------------|:----------------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | “HLR序列号”未定义。                         | 根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求。                                                                         |
| ERR3047 | 超过最大限制  | 增加的RR模板记录数超过20000条。                  | 根据实际情况，如需增加RR模板，处理步骤如下：执行LST RRTPL命令，查询已存在的RR模板。执行RMV RRTPL命令，删除不必要的RR模板。执行该命令增加RR模板，确保增加的RR模板记录数在规定范围之内。 |
| ERR3109 | 国家码未定义  | “CC”参数输入错误。                          | 根据实际情况，重新输入“CC”的取值，确保其取值符合要求。可通过LST INTROFF和LST CNTRCD命令查询，确保使用的“CC”在两个命令查询结果中都有记录。                       |
| ERR1004 | 无效的参数值  | “区域码1～区域码10”参数的取值不是0～4位十六进制数字组成的字符串。 | 根据实际情况，重新输入“区域码1～区域码10”的取值，确保其取值符合要求。                                                                     |
| ERR3004 | 模板已存在   | “模板ID”在数据库中已存在。                      | 根据实际情况，重新输入参数，确保输入的“模板ID”和系统中已存在的不重复。可执行LST RRTPL命令查询系统中已存在的区域漫游模板。                                       |
| ERR1009 | 参数丢失    | 未输入“区域码1”～“区域码10”参数中至少一个。            | 根据实际情况，至少输入“区域码1”～“区域码10”其中一个参数。                                                                          |
| ERR1118 | 参数重复    | 输入的“区域码1”～“区域码10”参数存在重复的取值。          | 根据实际情况，重新输入“区域码1”～“区域码10”参数，确保取值两两不同。                                                                     |
