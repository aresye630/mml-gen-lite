## 命令功能

该命令用于给5GS用户签约CAG（Convergence Access Gateway）数据。

该命令的使用场景：当用户需要接入5G系统中提供基于CAG的网络功能和网络特征的逻辑网络时，执行该命令进行签约。

## 注意事项

- 每个用户可以签约多个“PLMNID”并且所有“PLMNID”下签约的“CAGID”数据记录总数不能超过50个。
  - 单个“PLMNID”下必须包含至少一个“CAGID”数据。
  - 单个“PLMNID”下最多包含12个“CAGID”数据。

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现。

- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 使用实例

5G开户场景，为5GS用户签约CAG数据。

1. 为“IMSI”为“460030913121001”的用户签约CAG数据。其中，“PLMNID”为“11111”，“是否只允许UE通过CAG小区接入5GS”为“FALSE”，“CAGID”为“11111111”：

   ```
   ADD CAGDATA: IMSI="460030913121001", PLMNID="11111", CAGONLY=FALSE, CAGID="11111111";
   ```
2. 为连续3个IMSI用户签约CAG数据。其中，第一个“IMSI”为“460030913121001”，“用户个数”为“3”，“PLMNID”为“11111”,“是否只允许UE通过CAG小区接入5GS”为“FALSE”，“CAGID”为“11111111”：

   ```
   ADD CAGDATA: IMSI="460030913121001", RECORDCOUNT=3, PLMNID="11111", CAGONLY=FALSE, CAGID="11111111";
   ```
3. 为多个IMSI用户批量签约CAG数据。其中，“IMSI文件名”为“addcagdata.txt”，“PLMNID”为“11111”,“是否只允许UE通过CAG小区接入5GS”为“FALSE”，“CAGID”为“11111111”：

   ```
   ADD CAGDATA: IMSIFILE="addcagdata.txt", PLMNID="11111", CAGONLY=FALSE, CAGID="11111111";
   ```

## 参考信息

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
