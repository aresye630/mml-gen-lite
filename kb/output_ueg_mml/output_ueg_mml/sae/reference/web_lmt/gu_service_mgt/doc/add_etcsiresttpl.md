# 增加ETCSI限制模板（ADD ETCSIRESTTPL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在UDM中增加一条ETCSI限制模板数据记录。使用该命令，只能在模板中增加一个ETCSI业务键，如果一个模板需要配置多个ETCSI业务键，使用该命令定义一个ETCSI限制模板，然后使用**MOD ETCSIRESTTPL**命令增加多个ETCSI业务键。

UDM在SRI消息处理中通过ETCSI限制模板中的配置数据，判断是否限制下发ETCSI业务给GMSC。

## 注意事项

系统中增加的ETCSI限制模板记录数不能超过3000条。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                               |
|:---------|:---------|:---------------------------------------------------|
| HLRSN    | HLR序列号   | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。       |
| TPLID    | 模板ID     | 用于标识待增加模板在系统中的序号。 取值范围：0～65534 默认值：无。              |
| TPLNAME  | 模板名      | 用于标识待增加模板在系统中的名称。 取值范围：1～60位字母或十进制数字组成的字符串。 默认值：无。 |
| ETCSI_SK | ETCSI业务键 | 用于标识模板中限制下发的ETCSI业务键。 取值范围：1～999 默认值：无。            |

## 使用实例

在“HLR序列号”为“1”的HLR上增加一个ETCSI限制模板，并在该模板中添加多个ETCSI业务键，具体步骤如下：

1. 使用该命令添加一个ETCSI限制模板，其中“模板ID”为“2”、“模板名”为“ETCSI1”、“ETCSI业务键”为“1”，命令如下：

   ```
   ADD ETCSIRESTTPL: HLRSN=1, TPLID=2, TPLNAME="ETCSI1", ETCSI_SK=1;
   ```
2. 使用**MOD ETCSIRESTTPL**命令在已定义的模板中增加一个ETCSI业务键，其中“ETCSI业务键”为“2”，命令如下：

   ```
   MOD ETCSIRESTTPL: HLRSN=1, TPLID=2, PROV=TRUE, ETCSI_SK=2;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                    | 处理建议                                                                                                                                            |
|:--------|:--------|:------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | “HLR序列号”未定义。            | 根据实际情况，重新输入已定义的“HLR序列号”，可通过LST HLRSN命令查询已定义的“HLR序列号”。                                                                                           |
| ERR3004 | 模板已存在   | 输入的“模板ID”在数据库中已存在。      | 根据实际情况，重新输入参数，确保输入的“模板ID”和系统中已存在的不重复。可执行LST ETCSIRESTTPL命令查询系统中已存在的ETCSI限制模板。                                                                   |
| ERR3047 | 超过最大限制  | 增加的ETCSI限制模板记录数超过3000条。 | 根据实际情况，如需增加ETCSI限制模板，处理步骤如下：执行LST ETCSIRESTTPL命令，查询已存在ETCSI限制模板。执行RMV ETCSIRESTTPL命令，删除不必要的ETCSI限制模板。执行该命令增加ETCSI限制模板，确保增加的ETCSI限制模板记录数在规定范围之内。 |
