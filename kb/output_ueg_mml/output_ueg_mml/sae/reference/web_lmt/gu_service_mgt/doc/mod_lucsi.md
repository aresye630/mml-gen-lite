# 修改LU-CSI业务(MOD LUCSI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用于增加或删除用户LUCSI业务。

## 注意事项

- “IMSI”、“ISDN”、“IMSIFILE”、“ISDNFILE”是互斥参数，有且只能有一个参数出现。
- “RECORDCOUNT”存在时，“IMSIFILE”和“ISDNFILE”不能存在；“IMSI”或“ISDN”必须存在一个。

## 参数说明

| 参数标识        | 参数名称         | 参数说明                                                                                                                                            |
|:------------|:-------------|:------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI         | IMSI号码。 参数类型：E.212格式的编码 取值范围6～15位的十进制数字 默认值：无。 说明：条件必选参数。                                                                                       |
| ISDN        | MSISDN       | MSISDN号码。 参数类型：E.164格式的编码 取值范围：1～15位的十进制数 默认值：无。 说明：条件必选参数。                                                                                     |
| RECORDCOUNT | 用户个数         | 用户数量，用于连续号段批操作。代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。 取值范围：1～100000 默认值：无。 说明：可选参数，如果只有一个用户，该参数不必提供。                                       |
| IMSIFILE    | IMSI文件名      | IMSI文件名称，IMSIFILE是由多个不连续的IMSI号码组成的批操作文件，每个IMSI号码占一行。 取值范围：1~16个由字母、数字、下划线和点号组成的字符串。 默认值：无。 说明：可选参数。文件后缀名为.txt，通常通过Web UI上的文件选项将文件上传到指定位置。       |
| ISDNFILE    | MSISDN文件名    | MSISDN文件名称，ISDNFILE是由多个不连续的MSISDN号码组成的批操作文件，每个MSISDN号码占一行。 取值范围：1~16个由字母、数字、下划线和点号组成的字符串。 默认值：无。 说明：可选参数。文件后缀名为.txt，通常通过Web UI上的文件选项将文件上传到指定位置。 |
| PROV        | 是否提供LU-CSI业务 | 是否提供LU-CSI业务。 取值范围： TRUE：提供。FALSE：撤销。 默认值：无。 说明：必选参数。                                                                                           |
| TPLID       | LU-CSI业务模板号  | LU-CSI业务模板号。该参数必须通过ADD LUCSITPL命令定义后才能在此处引用。 取值范围：0～65534。 默认值：无。 说明：当“是否提供LU-CSI业务”为“TRUE”时，该参数为必选参数。当“是否提供LU-CSI业务”为“FALSE”时，该参数不可见。          |

## 使用实例

如果需要为IMSI号码为460000009123456用户提供LU-CSI业务，LU-CSI业务模板ID为2。命令如下：

`MOD LUCSI: IMSI="460000009123456", PROV=TRUE, TPLID=2;`
