# 修改SCP地址模板(MOD SCPTPL)

## 命令功能

**须知** 

该操作会修改SCP地址模板数据，是否继续？

该命令用于对一个SCP（Service Control Point）地址模板中的某些参数进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一个SCP地址模板：

- “HLR序列号”
- “模板ID”

## 注意事项

- 此模板被修改后，签约此模板的用户数据也会被修改，修改后的数据在用户新注册时会下发到网络。
- 系统中所有SCP地址模板增加的Camel版本记录数不能超过3000条。
- 系统中所有SCP地址模板增加的SCP地址总记录数不能超过5000条。
- 系统中同一个SCP地址模板增加的VLR号码前缀数据记录数不能超过1000条，且所有SCP地址模板增加的VLR号码前缀数据总记录数不能超过5000条。

## 参数说明

| 参数标识          | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|:--------------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN         | HLR序列号    | 标识一个SCP地址模板的关键字段之一（其取值不能被修改），用于指定需要对哪一个SCP地址模板的参数进行修改或调整，操作员可以使用LST HLRSN命令查询获得。                                                                                                                                                                                                                                                                                                                                                                                        |
| TPLID         | 模板ID      | 标识一个SCP地址模板的关键字段之一（其取值不能被修改），用于指定需要对哪一个SCP地址模板的参数进行修改或调整，操作员可以使用LST SCPTPL命令查询获得。                                                                                                                                                                                                                                                                                                                                                                                       |
| TPLNAME       | 模板名       | 用于标识SCP地址模板在系统中的名称。 取值范围：1～60位由字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                   |
| PROV          | 控制SCP模板数据 | 用于标识该命令是用来增加，修改还是删除SCP数据。 取值范围： TRUE：增加或者修改。当参数“CAMEL版本”和“使用范围”输入数据和模板中原有数据不相同时，为增加操作，在模板中新增一组数据。当参数“CAMEL版本”和“使用范围”输入的数据和模板中原有数据相同时，为修改操作，对模板中的词组数据的配置信息进行修改。 FALSE：删除。如果指定的模板数据存在，则此组模板数据将被删除。当模板中只有一组数据时，不能执行删除操作。 默认值：无。                                                                                                                                                                                                                                            |
| CAMEL         | CAMEL版本   | 仅当本命令中的“控制SCP模板数据”参数为“TRUE”时该参数有效。用于标识SCP地址模板支持的CAMEL业务处理能力，即gsmSCF所要求的CAMEL业务阶段。可参考CAMEL业务管理。 取值范围： PHASE1: 表示支持CAMEL phase 1，该CAMEL phase用于与移动始发和移动终结的呼叫相关的业务。 PHASE2: 表示支持CAMEL phase 2，该CAMEL phase用于与补充业务调用相关的业务。 PHASE3: 表示支持CAMEL phase 3，该CAMEL phase用于始发短消息业务（SMS MO）、GPRS会话和PDP上下文、HLR用户数据的控制和网络信令负荷。 PHASE4: 表示支持CAMEL phase 4，该CAMEL phase用于终结短消息业务（SMS MT）。 默认值：无。                                                                                         |
| AVAILABLEPLMN | 使用范围      | 仅当本命令中的“控制SCP模板数据”参数为“TRUE”时该参数有效。用于标识SCP地址模板的使用范围。即当用户处在网络中的什么位置时才使用SCP地址模板中的SCP地址。 取值范围： LOCALDOMESTIC：国内本网。表示用户漫游地的VLR和用户归属HLR在同一个国家，且在同一个PLMN（Public Land Mobile Network）内。CROSSDOMESTIC：国内跨网。表示用户漫游地VLR和用户归属HLR在同一个国家，但在不同的PLMN内。LOCALINTERNATIONAL：国际本网。表示用户漫游地VLR和用户HLR不在同一个国家，但在相同的PLMN内。CROSSINTERNATIONAL：国际跨网。表示用户漫游地VLR和用户归属HLR不在同一个国家，也不在同一个PLMN内。 默认值：无。                                                                                                  |
| VLRPREFIX     | VLR号码前缀   | 仅当本命令中的“控制SCP模板数据”参数为“TRUE”时该参数有效。用于标识具有相同号码前缀的VLR。VLR号码前缀支持最大匹配和精确匹配，即可以输入具有相同前缀的一组VLR号码的前缀，也可以输入一个VLR号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                |
| SCPADDR       | SCP地址     | 仅当本命令中的“控制SCP模板数据”参数为“TRUE”时该参数有效。用于标识接入gsmSCF功能实体的地址。 取值范围：采用E.164编码方式，15位以内的十进制数字组成的字符串。 编码格式为：CC+NDC+LSP，例如，一个典型的“SCP地址”为：“86-139-00777”。各关键字段的含义是： CC（Country Code）：国家码，即SCP所处国家在国际PSTN编号计划中的国家码，它由ITU-T在全球范围内统一分配，其最大长度为3位。例如，中国的国家码为86、英国的国家码为44等。NDC（National Destination Code）：国内目的码，即移动业务接入码，它是由本国电信主管部门在本国范围内统一分配的PLMN网络号，其最大长度为3位。例如，某运营商使用的PLMN网络号为134～139。LSP（Locally Significant Part）：本地有效部分，它是由某个运营商在本PLMN网络运营范围内统一分配的、用于具体代表某个SCP的号码，其最大长度为10位。 默认值：无。 |
| SK            | 业务键       | 仅当本命令中的“控制SCP模板数据”参数为“TRUE”时该参数有效。用于标识用户在gsmSCF中签约的CAMEL业务。gsmSSF（GSM Service Switching Function）将业务键发给gsmSCF后，gsmSCF根据该业务键执行对应的业务逻辑。业务键是HLR与SCP的对接参数之一，用于在CAP/INAP消息中唯一标识一种智能业务，它是一种号码资源，需要由运营商向本国的电信主管部门申请获得。 取值范围：0～2147483647 默认值：无。                                                                                                                                                                                                                                |
| DEFCALL       | 缺省呼叫处理    | 仅当本命令中的“控制SCP模板数据”参数为“TRUE”时该参数有效。用于标识当gsmSSF与gsmSCF之间的对话出现差错时或者呼叫受限于gsmSSF里的CallGap时，缺省呼叫处理指示出对呼叫应给予释放还是继续。 取值范围： RELEASECALL：gsmSCF指示gsmSSF释放呼叫。CONTINUECALL：gsmSCF指示gsmSSF继续呼叫。 默认值：无。                                                                                                                                                                                                                                                                               |
| NETTYPE       | 网络类型      | 仅当本命令中的“控制SCP模板数据”参数为“TRUE”时该参数有效。用于标识用户使用该SCP地址模板时所指定的网络是否支持VoLTE。 取值范围：VoLTE: 支持VoLTE。NON_VoLTE: 不支持VoLTE。ALL：支持所有网络。 默认值：无。                                                                                                                                                                                                                                                                                                                                          |

## 使用实例

修改SCP地址模板，“HLR序列号”为“1”，“模板ID”为“1”，“控制SCP模板数据”为“TRUE”，“CAMEL版本”为“PHASE1”，“使用范围”为“LOCALDOMESTIC”，“SCP地址”为“8613911111”，“业务键”为“56”，“缺省呼叫处理”为“RELEASECALL”。命令如下：

```
MOD SCPTPL: HLRSN=1, TPLID=1, PROV=TRUE, CAMEL=PHASE1, AVAILABLEPLMN=LOCALDOMESTIC, SCPADDR="8613911111", SK=56, DEFCALL=RELEASECALL;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释     | 原因分析                                                                                                                                              | 处理建议                                                                                                                                                                                |
|:--------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1009 | 参数丢失      | “使用范围”和“VLR号码前缀”都没有输入。                                                                                                                            | 根据实际情况，输入“使用范围”和“VLR号码前缀”参数的取值，确保其取值符合要求。                                                                                                                                           |
| ERR3003 | 模板未定义     | “HLR序列号”和“模板ID”参数对应的模板数据记录不存在。                                                                                                                    | 根据实际情况，重新输入参数，确保“HLR序列号”和“模板ID”参数对应的模板数据记录已存在。已存在的模板数据记录可以通过LST SCPTPL命令查询。                                                                                                         |
| ERR3047 | 超过最大限制    | 可能原因为如下之一：系统中所有SCP地址模板增加的“Camel版本”记录数超过3000条。系统中所有SCP地址模板增加的“SCP地址”记录数超过5000条。同一个“模板ID”增加的“VLR号码前缀”数据记录数超过1000条。所有SCP地址模板增加的“VLR号码前缀”总记录数超过5000条。 | 根据实际情况，如需增加Camel版本/SCP地址/VLR号码前缀，处理步骤如下：执行LST SCPTPL命令，查询已存在的Camel版本/SCP地址/VLR号码前缀。执行该命令删除不必要的Camel版本/SCP地址/VLR号码前缀。执行该命令增加Camel版本/SCP地址/VLR号码前缀，确保增加的Camel版本/SCP地址/VLR号码前缀在规定范围之内。 |
| ERR3097 | HLR序列号未定义 | “HLR序列号”未定义。                                                                                                                                      | 根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求。                                                                                                                                                   |
