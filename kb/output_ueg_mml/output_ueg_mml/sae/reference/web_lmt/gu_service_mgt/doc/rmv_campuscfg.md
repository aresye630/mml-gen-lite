# 删除园区配置(RMV CAMPUSCFG)

- 命令功能
- 注意事项

- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成园区数据无法导出，需要与华为技术支持确认后才可以实施。

该命令用于在UDM中对一条园区配置数据记录进行删除。

## 注意事项

- 该命令仅在特定局点使用，其他局点不需要配置。
- 执行该命令，会导致无法导出对应园区用户数据，请谨慎操作。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                  |
|:-----------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------|
| CAMPUSNAME | 园区名称   | 可选必选说明：必选参数 参数含义：标识一条园区配置数据记录的关键字段，用于指定需要对哪一条园区配置数据记录的参数进行删除，操作员可以使用LST CAMPUSCFG命令查询获得。 取值范围：长度不超过16位的字符串，只允许输入数字、字母和下划线。 默认值：无。 配置原则：“园区名称”区分大小写字母。 |

## 使用实例

删除一条园区配置数据记录：

```
RMV CAMPUSCFG : CAMPUSNAME="campus1";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                   | 处理建议                                                        |
|:--------|:--------|:-----------------------|:------------------------------------------------------------|
| ERR3007 | 记录不存在。  | 输入的“园区名称”对应记录在数据库中不存在。 | 根据实际情况，重新输入参数，确保通过LST CAMPUSCFG命令查询， “园区名称”参数对应的配置数据记录是存在的。 |
