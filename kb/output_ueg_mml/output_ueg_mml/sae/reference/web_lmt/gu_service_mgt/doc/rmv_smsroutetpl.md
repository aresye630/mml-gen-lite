# 删除SMS-Route模板(RMV SMSROUTETPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用于删除SMS-Route模板。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                |
|:-------|:-------|:------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 标识一条SMS-Route模板数据记录的关键字段之一，用于标识需要删除哪一条SMS-Route模板数据记录，操作员可以使用LST HLRSN命令查询获得。       |
| TPLID  | 模板ID   | 标识一条SMS-Route模板数据记录的关键字段之一，用于标识需要删除哪一条SMS-Route模板数据记录，操作员可以使用LST SMSROUTETPL命令查询获得。 |

## 使用实例

删除SMS-Route模板，“模板ID”为“3”。命令如下：

RMV SMSROUTETPL: HLRSN=1, TPLID=3;
