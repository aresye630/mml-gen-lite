# 校验AMF配置中的C1~C5和R1~R5参数(CHK AMFCR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于校验AMF配置中的C1～C5和R1～R5参数，以检查已添加的AMF记录中C1～C5和R1～R5是否正确。

## 注意事项

- 执行该命令校验数据时，C1～C5必须同时输入，或都不输入。
- 执行该命令校验数据时，R1～R5必须同时输入，或都不输入。
- 执行该命令校验数据时，C1～C5或R1～R5必须至少存在一种。

## 使用实例

校验AMF配置中的C1～C5和R1～R5。各参数分别设置为：

- “HLR序列号”为“1”
- “AMF序列号”为“2”
- “Milenage鉴权算法c1参数”为“00000000000000000000000000000000”
- “Milenage鉴权算法c2参数”为“00000000000000000000000000000001”
- “Milenage鉴权算法c3参数”为“00000000000000000000000000000002”
- “Milenage鉴权算法c4参数”为“00000000000000000000000000000004”
- “Milenage鉴权算法c5参数”为“00000000000000000000000000000008”

```
CHK AMFCR: HLRSN=1, AMFSNO=2, C1="*****", C2="*****", C3="*****", C4="*****", C5="*****";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释              | 原因分析                                                                                    | 处理建议                                                                                                      |
|:--------|:-------------------|:----------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------|
| ERR1009 | 参数丢失               | 可能原因如下： “HLR序列号”和“AMF序列号”参数没有输入。C1～C5参数只输入部分参数。R1～R5参数只输入部分参数。C1～C5和R1～R5都没有输入。         | 根据实际情况，重新输入参数，并满足如下条件： “HLR序列号”和“AMF序列号”参数必须输入。参数C1～C5必须同时存在或不存在。参数R1～R5必须同时存在或不存在。参数C1～C5和参数R1～R5必须存在一种。 |
| ERR3098 | 验证的数据与HLR数据库的数据不相同 | 填写的C1～C5和R1～R5值与HLR数据库保存的C1～C5和R1～R5值不一致。填写的C1～C5和R1～R5值经过加密后与HLR数据库保存的C1～C5和R1～R5值不一致。 | 根据实际情况，重新输入正确的C1～C5和R1～R5值。                                                                               |
