# 修改TAI与ZC映射关系(MOD TAIZCLIST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HSS中修改TAI(Tracking Area Identity)与ZC(Zone Code)映射关系。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                  |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 用于标识本地HLR，标识TAI与ZC映射关系数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR上的TAI与ZC映射关系数据记录的参数进行修改或调整，操作员可以使用LST HLRSN命令查询获得。                                                                                                                                                                            |
| TAI    | 跟踪区标识  | 用于标识跟踪区，标识TAI与ZC映射关系数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪些TAI与ZC映射关系数据记录的参数进行修改或调整，操作员可以使用LST TAIZCLIST命令查询获得。 默认值：无。 说明：TAI由MCC(Mobile Country Code)，MNC(Mobile Network Code)及TAC(Tracking Area Code)组成，总长度为9或10位。MCC为3个BCD码字符，MNC为2个或者3个BCD码字符，填写时请遵循实际长度。TAC编码为16进制数，固定为4位，有效范围0000-FFFE。 |
| ZC     | 区域码    | 用于标识地区码。 取值范围：4位十六进制字符串。 默认值：无。 说明: 必选参数。FFFF表示无效。                                                                                                                                                                                                                                    |

## 使用实例

1. 在“HLR序列号”为“1”的HSS上修改TAI为“460212345”对应的ZC映射关系。其中，“ZC”为“0002”：

   ```
   MOD TAIZCLIST: HLRSN=1, TAI="460212345", ZC="0002";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                       | 处理建议                                                                                                                                                               |
|:--------|:--------|:---------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | 根据实际情况选择：HLR序列号未定义。TAI未定义。 | 根据实际情况选择：如果需要为已定义的HLRSN修改TAI与ZC映射关系，则执行LST HLRSN命令先查询已定义的HLRSN，再为已定义的HLRSN修改TAI与ZC映射关系。如果需要为已定义的TAI修改对应的ZC映射关系，则执行LST TAIZCLIST命令先查询已定义的TAI，再为已定义的TAI修改TAI与ZC映射关系。 |
