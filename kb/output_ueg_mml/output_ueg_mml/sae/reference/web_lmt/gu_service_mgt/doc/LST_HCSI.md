# 查询用户CAMEL签约数据(LST HCSI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询指定IMSI的CAMEL(Customized Applications for Mobile network Enhanced Logic)签约数据。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称        | 参数说明                                                                                                                                |
|:--------|:------------|:------------------------------------------------------------------------------------------------------------------------------------|
| IMSI    | IMSI        | 用于指定一个需要查询CAMEL签约数据的IMSI。由不超过15位的十进制数字(0～9)组成，采用E.212格式。例如：460001234567890。 取值范围： 6–15 缺省值： 无                                       |
| CSITYPE | CAMEL签约数据类型 | 用于指定待查询的CAMEL签约数据的类型。此参数不设置表示查询所有类型的数据；取值为O-CSI表示查询O-CSI类型的数据；取值为T-CSI表示查询T-CSI类型的数据；取值默认为ALL。 取值范围：O-CSI(O-CSI)T-CSI(T-CSI) 缺省值： 无 |

## 使用实例

查询用户CAMEL签约数据。IMSI：125353，CAMEL签约数据类型：O-CSI。

```
LST HCSI: IMSI="125353", CSITYPE=O-CSI;
```
