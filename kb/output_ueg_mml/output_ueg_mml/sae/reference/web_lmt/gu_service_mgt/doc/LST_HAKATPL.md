# 查询AKA鉴权信息模板(LST HAKATPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询一个AKA鉴权信息模板记录，一次只能查询一个AKA鉴权信息模板记录，需要输入唯一标识该数据记录的关键参数AKA鉴权模板ID。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                           |
|:-------|:----------|:-------------------------------------------------------------------------------|
| TPLID  | AKA鉴权模板ID | 用于指示系统需要按照哪个AKA鉴权模板ID来查询AKA鉴权信息模板数据，一次只能查询一个AKA鉴权基本信息模板的数据。 取值范围： 0～254 缺省值： 无 |

## 使用实例

查询AKA鉴权信息模板。AKA鉴权模板ID：10。

```
LST HAKATPL: TPLID=10;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义如表1所示。

| 参数标识     | 参数说明                                                                                |
|:---------|:------------------------------------------------------------------------------------|
| TPLNAME  | 显示AKA鉴权模板名称。                                                                        |
| K4SNO    | 显示AKA鉴权模板的K4索引号。                                                                    |
| OPSNO    | 显示AKA鉴权模板的OP索引号。                                                                    |
| AMFSNO   | 显示AKA鉴权模板的AMF索引号。                                                                   |
| OPC      | 显示AKA鉴权模板的OPC值。 说明： 如果软参“AUTHENCRYMODEDISP”为1，显示“*”。如果软参“AUTHENCRYMODEDISP”为0，明文显示。 |
| OPCK4SNO | 显示AKA鉴权模板的OPC K4索引号。                                                                |
| COMMENT  | 显示AKA鉴权模板的模板注释说明。                                                                   |
