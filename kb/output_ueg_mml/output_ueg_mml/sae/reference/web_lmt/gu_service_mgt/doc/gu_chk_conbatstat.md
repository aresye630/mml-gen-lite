# 查询业务条件批操作状态(CHK CONBATSTAT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于查询业务条件批操作的状态：

- 如果没有输入任何参数，将列出系统中保存的所有业务条件批操作ID。
- 如果需要查询某条业务条件批操作的详细状态信息，请输入“批操作任务ID”或其他参数或这些参数的组合。

**说明** 

查看业务批操作执行的详细信息（业务、操作结果、状态等），请通过USCDB的**LST LOG**命令来查询。

## 注意事项

- “起始时间”和“结束时间”必须同时指定或同时不指定。
- 这两个参数同时指定时，“结束时间”的取值必须大于“起始时间”的取值。
- 系统最多纪录最近100个任务的结果信息。

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                          |
|:----------|:--------|:----------------------------------------------------------------------------------------------|
| TASKID    | 批操作任务ID | 使用不输入任何参数的CHK CONBATSTAT命令可以查询出所有的批操作任务ID。 取值范围： 1879048192～2147483647。 缺省值：无                 |
| OPNAME    | 操作员名称   | 执行业务条件批操作的操作员的名称。 取值范围：不超过32位的字符串，由数字和字母组成，且首字符必须为字母。 缺省值：无 说明：可选参数。                          |
| BEGINTIME | 起始时间    | 用于设置查找业务条件批操作任务的起始时间。 取值范围：格式为“YYYY&MM&DD&HH&MM&SS”的字符串。 缺省值：无 说明：该参数与“批操作任务ID”不能同时存在。        |
| ENDTIME   | 结束时间    | 用于设置查找业务条件批操作任务的结束时间。 取值范围：格式为“YYYY&MM&DD&HH&MM&SS”的字符串。 缺省值：无 说明：该参数与“批操作任务ID”不能同时存在。        |
| STATE     | 执行状态    | 要查询的业务条件批操作的状态。 取值范围： READY：准备 RUNNING：运行COMPLETED：完成ABORTED：终止 缺省值：无 说明：该参数与“批操作任务ID”不能同时存在。 |

## 使用实例

查询“批操作任务ID”为“1879048192”的批操作任务状态。

**CHK CONBATSTAT: TASKID=1879048192;**
