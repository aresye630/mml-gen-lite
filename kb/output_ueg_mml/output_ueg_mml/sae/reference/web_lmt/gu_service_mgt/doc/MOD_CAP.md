# 修改业务能力(MOD CAP)

## 命令功能

该命令用于修改用户所需要的业务能力。当一个用户发起SIP注册请求时，I-CSCF需要为该用户分配一个S-CSCF，即选择能够满足该用户业务要求的S-CSCF，I-CSCF通过向HSS查询用户的能力集来选择S-CSCF。

执行该命令后IMS-HSS会向当前的S-CSCF发送RTR消息注销用户，RTR消息的Deregistration-Reason的Reason-Code值为SERVER\_CHANGE。

## 注意事项

- “IMSI”和“MSISDN”是可选参数，必须有且只能有一个参数出现。
- “必选能力集”、“可选能力集”和“SCSCF列表”参数至少输入一个。
- “必选能力集”和“可选能力集”的合法取值分为以下两种情况：
  - 只有一个无效ID值，0为无效ID值；
  - 由1到32个整数用“&”连接起来的整数集合，其中每个整数的取值范围为1～4294967295，集合里的整数不允许重复；当“必选能力集”参数和“可选能力集”参数都存在，且取值都为第二种情况时，两个参数的集合之间不允许有相同的整数。

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                                                                              |
|:----------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI      | IMSI    | 用于标识待修改用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                   |
| ISDN      | MSISDN  | 用于标识待修改用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                 |
| MCAP      | 必选能力集   | 用于标识用户的必选业务能力。 取值范围：1～352位由十进制数字和“&”组成的字符串。该参数是1到32个用“&”连接起来的整数集合，其中每个整数的取值范围为1～4294967295，集合里的整数不允许重复。例如1&2，取值代表能力，是由运营商统一规划的。 默认值：无。 说明：当该参数设置为“0”时，0为无效ID值，表示清除原有配置。           |
| OCAP      | 可选能力集   | 用于标识用户的可选业务能力。 取值范围：1～352位由十进制数字和“&”组成的字符串。该参数是1到32个用“&”连接起来的整数集合，其中每个整数的取值范围为1～4294967295，集合里的整数不允许重复。例如1&2，取值代表能力，是由运营商统一规划的。 默认值：无。 说明：当该参数设置为“0”时，0为无效ID值，表示清除原有配置。           |
| SCSCFLIST | SCSCF列表 | 用于标识能力集模板的S-CSCF的名称集合，可以由1到5个S-CSCF名称组成，每个S-CSCF名称不超过127个字符，不同的S-CSCF的名称以“&”符连接，在字符“"”前需要添加转义字符“\”。例如：\"sip:scscf1.huawei.com\"&\"sip:scscf2.huawei.com\"。 取值范围：1～649位字符串。 默认值：无。 |

## 使用实例

修改用户的业务能力，参数取值如表1所示。

| 参数         | 值                                                   |
|:-----------|:----------------------------------------------------|
| HLR序列号     | 1                                                   |
| 必选能力集      | 1&2                                                 |
| 可选能力集      | 3&4                                                 |
| S-CSCF名称列表 | \"sip:scscf1.huawei.com\"&\"sip:scscf2.huawei.com\" |

```
MOD CAP: IMSI="123456789", MCAP="1&2", OCAP="3&4", SCSCFLIST="\"sip:scscf1.huawei.com\"&\"sip:scscf2.huawei.com\"";
```
