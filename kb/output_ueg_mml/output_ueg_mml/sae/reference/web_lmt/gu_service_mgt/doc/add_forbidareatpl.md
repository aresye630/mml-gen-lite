# 增加5G禁止区域模板管理（ADD FORBIDAREATPL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于设置5G禁止区域模板，为用户签约5G禁止区域做准备。

该命令使用场景如下：

- 操作员使用**MOD AMDATA**给用户签约AMF数据时，若用户签约了5G禁止区域模板，则该用户将被禁止访问这些区域。
- 操作员使用****ADD NGSUSERTPL****定义5G开户模板时，若引用通过该命令定义的5G禁止区域模板，则该用户将被禁止访问这些区域。

## 注意事项

系统中增加的5G禁止区域模板记录数不能超过20000条。

## 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|:---------------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN          | HLR序列号 | 可选必选说明：必选参数 参数含义：用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1~255 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                                        |
| TPLID          | 模板ID   | 可选必选说明：必选参数 参数含义：用于标识待增加模板在系统中的序号。 取值范围：1～2147483646 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                                                            |
| TPLNAME        | 模板名    | 可选必选说明：可选参数 参数含义：用于标识待增加模板在系统中的名称。 取值范围：1～60个字母或十进制数字组成的字符串。 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                                                                                                                    |
| FORBIDDENAREAS | 禁止区域   | 可选必选说明：必选参数 参数含义：用于标识禁止业务区域信息。 取值范围：不超过4000位的字符串。 禁止业务区域信息符合Json格式，具体格式请参考3GPP 29.503协议。名称和类型如下：areas：区域信息。包含以下字段：tacs：跟踪区域代码。areaCode/areaCodes：区域代码，每个区域代码代表跟踪区域的集合。29.571-f30及之前版本协议支持信元名称为areaCodes，29.571-f40及之后版本协议支持信元名称为areaCode。 样例如下：[{\"tacs\":[\"63F84B\"\,\"63F84A\"]}][{\"areaCodes\":\"4305\"}][{\"areaCode\":\"4305\"}] 默认值：无 配置原则： 该参数的配置需要满足Json格式，如果输入中包含“"”和“,”特殊字符，则在这些特殊字符前添加转义字符“\”。areas数组中，每一个对象中的tacs、areaCode和areaCodes同时仅允许配置1个。 |

## 使用实例

假如运营商需要某一个区域为5G禁止访问区域，则需要先增加5G禁止区域模板，后续签约给用户以对用户进行移动性管理。下面示例为增加一个5G禁止区域模板，areas数组中的tacs、areaCode和areaCodes取值配置样例的几种场景。

```
ADD FORBIDAREATPL: HLRSN=1, TPLID=1, TPLNAME="TPL", FORBIDDENAREAS="[{\"tacs\":[\"63F84B\"\,\"63F84A\"]}]";
ADD FORBIDAREATPL: HLRSN=1, TPLID=2, TPLNAME="TPL1", FORBIDDENAREAS="[{\"areaCode\":\"4305\"}]";
ADD FORBIDAREATPL: HLRSN=1, TPLID=3, TPLNAME="TPL2", FORBIDDENAREAS="[{\"areaCodes\":\"4305\"}]";
ADD FORBIDAREATPL: HLRSN=1, TPLID=4, TPLNAME="TPL3", FORBIDDENAREAS="[{\"tacs\":[\"430A5F\"]}\,{\"tacs\":[\"63F84B\"\,\"63F84A\"]}]";
ADD FORBIDAREATPL: HLRSN=1, TPLID=5, TPLNAME="TPL4", FORBIDDENAREAS="[{\"areaCodes\":\"4305\"}\,{\"areaCodes\":\"4306\"}]";
ADD FORBIDAREATPL: HLRSN=1, TPLID=6, TPLNAME="TPL5", FORBIDDENAREAS="[{\"areaCode\":\"4305\"}\,{\"areaCode\":\"4306\"}]";
ADD FORBIDAREATPL: HLRSN=1, TPLID=7, TPLNAME="TPL6", FORBIDDENAREAS="[{\"areaCodes\":\"4305\"}\,{\"tacs\":[\"63F84B\"]}]";
ADD FORBIDAREATPL: HLRSN=1, TPLID=8, TPLNAME="TPL7", FORBIDDENAREAS="[{\"areaCode\":\"4305\"}\,{\"tacs\":[\"63F84B\"]}]";
```
