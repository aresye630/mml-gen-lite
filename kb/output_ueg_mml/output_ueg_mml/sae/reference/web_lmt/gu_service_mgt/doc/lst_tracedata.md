# 查询全网跟踪数据(LST TRACEDATA)

## 命令功能

该命令用于查询用户的全网跟踪数据。

- 若需要查询单个用户的全网跟踪数据，请输入参数“IMSI”或“MSISDN”其中的一个，其他参数不输入。
- 若需要查询连续多个用户的全网跟踪数据，请输入参数“IMSI”或“MSISDN”的同时，再输入参数“用户个数”，其他参数不输入。
- 若需要查询不连续的多个用户的全网跟踪数据，请输入参数“IMSI文件名”或“MSISDN文件名”，其他参数不输入。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”参数同时配置。
- “用户个数”必须与“IMSI”或“MSISDN”参数中的一个同时存在。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                    |
|:------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 可选必选说明：条件必选 参数含义：用于标识需要查询哪个IMSI号码对应用户的全网跟踪数据。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                     |
| ISDN        | MSISDN    | 可选必选说明：条件必选 参数含义：用于标识需要查询哪个MSISDN号码对应用户的全网跟踪数据。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                   |
| RECORDCOUNT | 用户个数      | 可选必选说明：条件必选 参数含义：用于指定需要查询从IMSI或者MSISDN对应用户开始的全网跟踪数据的个数。 取值范围：1～10000 默认值：无。 配置原则： 当需要为连续号码的多个用户查询全网跟踪数据时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行查询全网跟踪数据。当只有一个用户时，该参数不必配置。 当一次查询全网跟踪数据的用户个数很多时，对系统性能无影响，但查询全网跟踪数据的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名   | 可选必选说明：条件必选 参数含义：用于指定需要查询的全网跟踪数据的IMSI批操作文件。 取值范围：1～35个由字母、数字、下划线和“.”组成的字符串。 默认值：无。 配置原则：IMSI批操作文件包含多个不连续的需要查询全网跟踪数据用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“lsttracedata.txt”。通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。                         |
| ISDNFILE    | MSISDN文件名 | 可选必选说明：条件必选 参数含义：用于指定需要查询的全网跟踪数据的MSISDN批操作文件。 取值范围：1～35个由字母、数字、下划线和“.”组成的字符串。 默认值：无。 配置原则：MSISDN批操作文件包含多个不连续的需要查询全网跟踪数据用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“lsttracedata.txt”。通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。                   |

## 使用实例

1. 查询“IMSI”为“460000009123456”的用户的全网跟踪数据：

   ```
   LST TRACEDATA: IMSI="460000009123456";
   ```

   ```
   %%LST TRACEDATA: IMSI="460000009123456";%%
   RETCODE = 0 SUCCESS0001:Operation is successful

                             IMSI = 460000009123456
                           MSISDN = 86111111113
                         TRACEREF = 46000-000204
                       TRACEDEPTH = 2
                       NETYPELIST = gNB-CU-UP & gNB-CU-CP & UPF & PCF & SMF & AMF & eNB & PDN GW & ng-eNB & gNB-DU
                        EVENTLIST = 0000000000000000007F3FF1
                         IPV4ADDR = 10.145.227.139
                        TRACEMODE = E2E signaling transmission-based trace mode
                       INTERTRACE = True

   Total count = 9

   There is together 1 report

   ---    END
   ```
2. 查询第一个MSISDN号码为“86111111113”的连续3个用户的全网跟踪数据：

   ```
   LST TRACEDATA: ISDN="86111111113", RECORDCOUNT=3;
   ```

   ```
   %%LST TRACEDATA: ISDN="86111111113", RECORDCOUNT=3;%%
   RETCODE = 0 SUCCESS0001:操作成功 批操作ID：7. 使用CHK BATSTAT指令可查看此批操作的执行情况

   There is together 1 report

   ---    END
   ```
3. 查询“MSISDN文件名”为“tracedata.txt”的用户的全网跟踪数据：

   ```
   LST TRACEDATA: ISDNFILE="tracedata.txt";
   ```

   ```
   %%LST TRACEDATA: ISDNFILE="tracedata.txt";%%
   RETCODE = 0 SUCCESS0001:操作成功 批操作ID：268435464. 使用CHK BATSTAT指令可查看此批操作的执行情况

   There is together 1 report

   ---    END
   ```

| EVENTLIST  | 用于返回跟踪事件类型列表。                                                                                                                                                                                                                                                                                                          |
| IPV4ADDR   | 用于返回上报跟踪文件或消息码流的IPv4地址。IPV4ADDR与IPV6ADDR至少携带一个。                                                                                                                                                                                                                                                                        |
| IPV6ADDR   | 用于返回上报跟踪文件或消息码流的IPv6地址。IPV4ADDR与IPV6ADDR至少携带一个。                                                                                                                                                                                                                                                                        |

## 参考信息

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1 
IMSI2 
IMSI3 
IMSI4 
…… 
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1 
MSISDN2 
MSISDN3 
MSISDN4 
…… 
MSISDNn
```

MSISDNn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
