# 删除5G QoS模板(RMV NGCQOSTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条5G QoS模板数据记录。

## 注意事项

若待删除的QoS模板已经通过**ADD DNNQOSTPL**命令被引用，执行该命令删除5G QoS模板时，会提示“ERR3005:Template already in use <"HLR\_INDEX=\*"&"NGCQOSTPLID=\*">”的错误信息。如果要删除该5G QoS模板，必须先执行**MOD DNNQOSTPL**命令去签约5G QoS模板。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                            |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 可选必选说明：必选参数 参数含义：标识5G QoS模板信息数据的关键字段之一，用于指示系统按照哪个HLR序列号来删除5G QoS模板信息数据，操作员可以使用LST HLRSN命令查询获得。 取值范围：1~255 默认值：无 配置原则：无          |
| TPLID  | 模板ID   | 可选必选说明：必选参数 参数含义：标识5G QoS模板信息数据的关键字段之一，用于指示系统按照哪个模板ID来删除5G QoS模板信息数据，操作员可以使用LST NGCQOSTPL命令查询获得。 取值范围：1～2147483646 默认值：无 配置原则：无 |

## 使用实例

删除5G QoS模板,“HLR序列号”为“1”，“模板ID”为“3”,命令如下：

```
RMV NGCQOSTPL: HLRSN=1, TPLID=3;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                    | 处理建议                                                                                                                                          |
|:--------|:--------|:------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | “HLR序列号”未定义或者“模板ID”未定义。 | 根据实际情况，重新输入已定义的“HLR序列号”和“模板ID”，可通过LST HLRSN命令查询已定义的“HLR序列号”，通过LST NGCQOSTPL命令查询已定义的“模板ID”。                                                    |
| ERR3005 | 模板已经被使用 | 该5G QoS模板已经被引用。         | 根据实际情况，确定是否要删除该模板。如果确实需要删除，需要执行以下步骤：执行MOD SMDATA命令为用户修改5GS DNN QoS模板。执行RMV DNNQOSTPL命令删除引用该模板的5GS DNN QoS模板。执行RMV NGCQOSTPL命令删除该5G QoS模板数据记录。 |
