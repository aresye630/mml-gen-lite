# 修改IMS签约ID(MOD HSUBID)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于对HSS的业务数据库中的一条签约用户数据记录中的SUBID值进行修改。在该命令中，系统通过“SUBID”参数来唯一标识一条账户的数据记录。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                        |
|:---------|:--------|:------------------------------------------------------------------------------------------------------------|
| SUBID    | SUBID   | 标识一个签约用户数据记录的关键参数，用于指定需要修改哪一个签约用户数据记录，操作员可以使用LST HSUB操作查询获得，SUBID字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：必选参数。 |
| NEWSUBID | 新的SUBID | 用于定义签约数据中SUBID的值。该参数的配置原则是：必须保证新的SUBID在运营商网络中唯一。SUBID字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：必选参数。             |

## 使用实例

修改IMS签约ID，“SUBID”为“+862970119992@domain50.huawei.com”，“新的SUBID”为“+862970119994@domain50.huawei.com”：

```
MOD HSUBID: SUBID="+862970119992@domain50.huawei.com", NEWSUBID="+862970119994@domain50.huawei.com";
```
