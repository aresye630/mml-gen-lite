# 删除NEF订阅事件记录(RMV EESUBSCRIPTION)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除用户的NEF监视事件：

- 若需要删除用户所有NEF请求订阅的监视事件，请输入用户标识。
- 若需要删除用户某个NEF请求订阅的所有监视事件，请输入用户标识和“订阅ID”。
- 若需要删除用户某个NEF请求订阅的单个监视事件，请输入用户标识、“订阅ID”和“事件ID”。
- 若需要删除用户某个NEF请求订阅的某类监视事件，请输入用户标识、“订阅ID”和“事件类型”。
- 若需要删除用户的所有NEF请求订阅的某类NEF监视事件，请输入用户标识和“事件类型”。

  **说明** 

  用户标识分为以下三类：

  - 单个用户，请输入“IMSI”或“MSISDN”。
  - 多个连续用户，请输入“IMSI”与“用户个数”的组合，或者“MSISDN”与“用户个数”的组合。
  - 多个不连续用户，请输入“IMSI文件名”或“MSISDN文件名”。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是互斥参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。
- “用户个数”必须与“IMSI”或“MSISDN”中的一个同时存在。
- “事件ID”不能与“事件类型”同时配置。
- 输入“事件ID”时，必须同时输入“订阅ID”。

## 使用实例

1. 删除“IMSI”号码为“4600000110609”，“订阅ID”为“5F871A4E2D540027”，“事件ID”为“22222”的NEF监视事件：

   ```
   RMV EESUBSCRIPTION: IMSI="4600000110609", EVENTSUBID="5F871A4E2D540027", REFERENCEID=22222;
   ```
2. 删除3个连续号码的用户的“订阅ID”为“5F871A4E2D540027”的NEF监视事件，这3个MSISDN号码分别为“86123110601929”、“86123110601930”、“86123110601931”：

   ```
   RMV EESUBSCRIPTION: ISDN="86123110601929", RECORDCOUNT=3, EVENTSUBID="5F871A4E2D540027";
   ```
3. 修改3个非连续号码的用户的“事件类型”为“UE\_REACHABILITY\_FOR\_DATA”的NEF监视事件，这3个MSISDN号码分别为“86123110601921”、“86123110601923”、“86123110601925”，已保存在“MSISDN文件名”为“rmvee.txt”的文件中：

   ```
   RMV EESUBSCRIPTION: ISDNFILE="rmvee.txt", EVENTTYPE=UE_REACHABILITY_FOR_DATA;
   ```

该命令执行正常，会返回命令执行成功的提示信息。
