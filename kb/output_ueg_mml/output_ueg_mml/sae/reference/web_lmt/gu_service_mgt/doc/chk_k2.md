# 校验K2(CHK K2)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于校验K2密钥，以检查已添加的K2密钥是否正确。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                               |
|:--------|:-------|:-----------------------------------------------------------------------------------|
| HLRSN   | HLR序列号 | 用于标识本地HLR。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                          |
| K2SNO   | K2序列号  | 用于标识K2序列号。 取值范围：1～254。 默认值：无。                                                      |
| K2VALUE | K2值    | 用于标识K2密钥值。 取值范围：32位或64位的十六进制数字组成的字符串 默认值：无。                                        |
| K7SNO   | K7序列号  | 用于标识K7序列号。该参数必须先由ADD K7命令定义，然后才能在此处引用。 取值范围：1～10。 默认值：无。                           |
| ALGTYPE | 算法类型   | 标识K2值的加密算法类型。 AES128：K2值为32位的十六进制数字组成的字符串。AES256：K2值为64位的十六进制数字组成的字符串。 默认值：AES128。 |

## 使用实例

1. 在HSS/HLR中校验K2。“HLR序列号”为“1”，“K2序列号”为“1”，“K2值”为“1234567890abcde1234567890abcde12”：

   ```
   CHK K2: HLRSN=1, K2SNO=1, K2VALUE="*****";
   ```
2. 在HSS/HLR中校验K2。“HLR序列号”为“1”，“K2序列号”为“2”，“K2值”为“1234567890abcde1234567890abcde12”,“K7序列号”为“2”：

   ```
   CHK K2: HLRSN=1, K2SNO=2, K2VALUE="*****", K7SNO=2;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释              | 原因分析                                                                                      | 处理建议                                                    |
|:--------|:-------------------|:------------------------------------------------------------------------------------------|:--------------------------------------------------------|
| ERR3098 | 验证的数据与HLR数据库的数据不相同 | 填写的K2值算法类型与HLR数据库保存的K2值算法类型不一致。填写的K2值算法类型与HLR数据库保存的K2值算法类型一致但经过算法加密后的K2值与HLR数据库保存的K2值不一致。 | 根据K2值的位数选择正确的算法类型。根据实际情况，重新输入正确的K2值。                    |
| ERR4133 | 密钥丢失               | 当SET MAPSERV命令中的“随机密钥默认ID”参数为非0，“随机密钥默认ID”参数对应的随机密钥材料不存在或不完整。                             | 联系华为技术支持处理。                                             |
| ERR4195 | 不支持处理保存在HSM的记录     | 待校验的“K2序列号”为HSM类型。                                                                        | 在用户签约的K2记录中查询“K2密钥输入方式”，然后重新执行本命令，确保待校验的“K2序列号”不为HSM类型。 |
