# 修改无线接入类型限制(MOD RATRESTRICT)

- 命令功能

- 使用实例

## 命令功能

该命令用于修改用户的无线接入网类型，当用户接入5G网络时，根据该数据来允许或限制用户接入指定的无线网。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数必须有且只能有一个参数出现。
- “用户个数” 参数不能与“IMSI文件名”或“MSISDN文件名”同时存在，“用户个数”参数只能与“IMSI”或“MSISDN”一起出现。

## 参数说明

| 参数标识        | 参数名称          | 参数说明                                                                                                                                                                                                                                                                |
|:------------|:--------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI          | 可选必选说明：条件可选参数 参数含义：用于标识需要修改无线接入类型限制的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                |
| ISDN        | MSISDN        | 可选必选说明：条件可选参数 参数含义：用于标识需要修改无线接入类型限制的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                              |
| RECORDCOUNT | 用户个数          | 可选必选说明：条件可选参数 参数含义：用于标识需要修改无线接入类型限制的用户的数目。 取值范围：1～100000 默认值：无。 配置原则： 需要为连续号码的多个用户修改无线接入类型限制时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行修改无线接入类型限制管理数据。该参数是对连续号码的多个用户进行修改无线接入类型限制，当只有一个用户时，该参数不必配置。当一次修改无线接入类型限制的用户个数很多时，对系统性能无影响，但修改无线接入类型限制的用户个数越多，消耗的时间越长。 |
| IMSIFILE    | IMSI文件名       | 可选必选说明：条件可选参数 参数含义：用于标识IMSI批操作文件。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。 配置原则：IMSI批操作文件包含多个不连续的需要修改的无线接入类型限制管理数据的用户的IMSI号码，本编辑器编辑的文本文件（编码格式为ANSI），如“modratrestrict.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。                                                |
| ISDNFILE    | MSISDN文件名     | 可选必选说明：条件可选参数 参数含义：用于标识MSISDN批操作文件。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。 配置原则：MSISDN批操作文件包含多个不连续的需要修改无线接入类型限制管理数据的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modratrestrict.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。                                         |
| WLAN        | 是否限制WLAN接入    | 可选必选说明：可选参数 参数含义：用于标识是否限制WLAN（无线局域网）接入。 取值范围：TRUE：是FALSE：否 默认值：无。 配置原则：无。                                                                                                                                                                                           |
| VIRTUAL     | 是否限制VIRTUAL接入 | 可选必选说明：可选参数 参数含义：用于标识是否限制VIRTUAL（虚拟专用网）接入。 取值范围：TRUE：是FALSE：否 默认值：无。 配置原则：无。                                                                                                                                                                                        |

## 使用实例

当用户接入5G网络时，配置是否限制用户接入指定的无线网类型。

1. 修改“IMSI”为“461120093456123”的用户的无线接入类型限制管理数据，其中“是否限制WLAN接入”为“TRUE”，“是否限制VIRTUAL接入”为“TRUE”：

   ```
   MOD RATRESTRICT: IMSI="461120093456123", WLAN=TRUE, VIRTUAL=TRUE;
   ```
2. 修改“IMSI”为“461120093456123”、“461120093456124”、“461120093456125”的3个连续用户的无线接入类型限制管理数据，其中“是否限制WLAN接入”为“TRUE”，“是否限制VIRTUAL接入”为“FALSE”：

   ```
   MOD RATRESTRICT: IMSI="461120093456123", RECORDCOUNT=3, WLAN=TRUE, VIRTUAL=FALSE;
   ```

## 参考信息

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
