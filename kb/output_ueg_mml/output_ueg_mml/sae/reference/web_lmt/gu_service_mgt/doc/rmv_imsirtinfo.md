# 删除IMSI全局路由数据(RMV IMSIRTINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用来删除IMSI全局路由数据。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                |
|:-----------|:-------|:----------------------------------------------------|
| IMSIPREFIX | IMSI前缀 | IMSI号段，对应于此地区的IMSI号段。 取值范围：1～15位的十进制数字组成的字符串。 必选参数。 |

## 使用实例

删除IMSI全局路由数据：IMSIPREFIX=1234，命令如下：

RMV IMSIRTINFO: IMSIPREFIX="1234";
