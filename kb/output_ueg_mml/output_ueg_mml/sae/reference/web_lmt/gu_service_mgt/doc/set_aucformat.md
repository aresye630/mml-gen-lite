## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成用户鉴权失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

UDM支持与外置AUC之间使用HTTPS/HTTP消息建立链路连接。该命令用于设置UDM与外置AUC之间的鉴权接口格式。

系统初始化的时候已经在配置数据库中预置了初始数据记录，可以通过**LST AUCFORMAT**命令查询。

## 注意事项

UDM需要与外置AUC设备协商鉴权接口格式，若接口格式不一致可能导致用户鉴权失败。

| SUPPAUC     | 支持外置AUC鉴权 | 可选必选说明：必选参数 参数含义：用于标识是否支持外置AUC鉴权。 取值范围： FALSETRUE 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| URI         | URI定义     | 可选必选说明：可选参数 参数含义：用于标识AUSF向AUC发送鉴权向量请求时使用的URI。 取值范围：长度不超过128位的字符串，不允许输入空格。该参数不区分大小写，在执行LST AUCFORMAT命令查询出的报文中为全小写形式。 默认值：无。 配置原则： 当“支持外置AUC鉴权”取值为“TRUE”时，该参数可选。配置该参数时不能输入协议类型(http/https)、IP和端口号。例如：配置URI为"/nauc-avg/v1/security-information/generate-av"，则最终的URI在发送前动态组装为"https://172.16.128.1:443/nauc-avg/v1/security-information/generate-av"                                                                                                                                                                                                                                                                                                           |
| AV          | 鉴权向量路径    | 可选必选说明：可选参数 参数含义：用于标识AUSF接收AUC鉴权向量时，鉴权向量的路径。 取值范围：长度不超过64位的字符串。支持输入0～9、a～z、A～Z、“-”、“_”和“/”。 默认值：无。 配置原则： 当“支持外置AUC鉴权”取值为“TRUE”时，该参数可选。例如鉴权向量路径设置为：authenticationVectors。使用“/”分割路径。                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| RAND        | RAND参数名   | 可选必选说明：可选参数 参数含义：用于标识AUSF接收AUC鉴权向量时，鉴权向量RAND的名称。 取值范围：长度不超过32位的字符串。支持输入0～9、a～z、A～Z、“-”和“_”。 默认值：无。 配置原则：当“支持外置AUC鉴权”取值为“TRUE”时，该参数可选。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| AUTN        | AUTN参数名   | 可选必选说明：可选参数 参数含义：用于标识AUSF接收AUC鉴权向量时，鉴权向量AUTN的名称。 取值范围：长度不超过32位的字符串。支持输入0～9、a～z、A～Z、“-”和“_”。 默认值：无。 配置原则：当“支持外置AUC鉴权”取值为“TRUE”时，该参数可选。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| XRES        | XRES参数名   | 可选必选说明：可选参数 参数含义：用于标识AUSF接收AUC鉴权向量时，鉴权向量XRES的名称。 取值范围：长度不超过32位的字符串。支持输入0～9、a～z、A～Z、“-”和“_”。 默认值：无。 配置原则：当“支持外置AUC鉴权”取值为“TRUE”时，该参数可选。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| CK          | CK参数名     | 可选必选说明：可选参数 参数含义：用于标识AUSF接收AUC鉴权向量时，鉴权向量CK的名称。 取值范围：长度不超过32位的字符串。支持输入0～9、a～z、A～Z、“-”和“_”。 默认值：无。 配置原则：当“支持外置AUC鉴权”取值为“TRUE”时，该参数可选。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| IK          | IK参数名     | 可选必选说明：可选参数 参数含义：用于标识AUSF接收AUC鉴权向量时，鉴权向量IK的名称。 取值范围：长度不超过32位的字符串。支持输入0～9、a～z、A～Z、“-”和“_”。 默认值：无。 配置原则：当“支持外置AUC鉴权”取值为“TRUE”时，该参数可选。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| REQFORGETAV | 鉴权请求格式    | 可选必选说明：可选参数 参数含义：用于标识AUSF发送鉴权向量请求时使用的数据格式。 取值范围：长度不超过512位的字符串。该参数为JSON格式。 默认值：无。 配置原则： 当“支持外置AUC鉴权”取值为“TRUE”时，该参数可选。发送消息时系统默认根据用户实际请求消息替换“${}”中的imsi和鉴权向量请求个数，“${}”中的字符串为固定配置，不允许修改。如果存在“,”和“""”，则需要输入转义字符“\”。以4G为例，配置举例：{ \"imsi\":\"${imsi}\"\, \"numOfRequestedVectors\":${numOfRequestedVectors}\, \"requestingNodeType\":\"MME\" } 则系统发送的最终请求格式为： { "imsi": 460001480000001, "numOfRequestedVectors": 1, "requestingNodeType": "MME" }                                                                                                                                                                                                                |
| REQFORSYN   | 鉴权重同步请求格式 | 可选必选说明：可选参数 参数含义：用于标识AUSF发送鉴权重同步请求时使用的数据格式。 取值范围：长度不超过512位的字符串。该参数为JSON格式。 默认值：无。 配置原则： 当“支持外置AUC鉴权”取值为“TRUE”时，该参数可选。发送消息时系统默认根据用户实际请求消息替换“${}”中的imsi、鉴权向量请求个数、重同步参数rand和auts，“${}”中的字符串为固定配置，不允许修改。如果存在“,”和“""”，则需要输入转义字符“\”。以4G为例，配置举例：{ \"imsi\":\"${imsi}\"\, \"numOfRequestedVectors\":${numOfRequestedVectors}\, \"requestingNodeType\":\"MME\"\, \"resynchronizationInfo\":{ \"rand\":\"${rand}\"\, \"auts\":\"${auts}\" } } 则系统发送的最终请求格式为： { "imsi": "460001480000001", "numOfRequestedVectors": 1, "requestingNodeType": "MME", "resynchronizationInfo": { "rand": "01234567890123456789012345678901", "auts": "7D894C5687456932145879632547" } } |

## 使用实例

支持外置AUC鉴权时，配置4G域UDM与外置AUC之间的鉴权接口格式，其中“URI定义”为“/nauc-avg/v1/security-information/generate-av”、“鉴权向量路径”为“authenticationVectors”、“RAND参数名”为“rand”、“AUTN参数名”为“autn”、“XRES参数名”为“xres”、“CK参数名”为“ck”、“IK参数名”为“ik”、“鉴权请求格式为”“{\"imsi\":\"${imsi}\"\,\"numOfRequestedVectors\":${numOfRequestedVectors}\,\"requestingNodeType\":\"MME\"}”、“鉴权重同步请求格式”为“{\"imsi\":\"${imsi}\"\,\"numOfRequestedVectors\":${numOfRequestedVectors}\,\"requestingNodeType\":\"MME\"\,\"resynchronizationInfo\":{\"rand\":\"${rand}\"\,\"auts\":\"${auts}\"}}”：

```
SET AUCFORMAT: DOMAIN=4G, SUPPAUC=TRUE, URI="/nauc-avg/v1/security-information/generate-av", AV="authenticationVectors", RAND="rand", AUTN="autn", XRES="xres", CK="ck", IK="ik", REQFORGETAV="{\"imsi\":\"${imsi}\"\,\"numOfRequestedVectors\":${numOfRequestedVectors}\,\"requestingNodeType\":\"MME\"}", REQFORSYN="{\"imsi\":\"${imsi}\"\,\"numOfRequestedVectors\":${numOfRequestedVectors}\,\"requestingNodeType\":\"MME\"\,\"resynchronizationInfo\":{\"rand\":\"${rand}\"\,\"auts\":\"${auts}\"}}";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                           | 处理建议                                   |
|:--------|:--------|:-------------------------------|:---------------------------------------|
| ERR1004 | 无效的参数值  | 输入的参数值不在其取值范围内或者输入的参数值不符合要求。   | 根据界面提示，输入正确的参数值后执行本命令重试。               |
| ERR1009 | 参数丢失    | 提示的必选参数没有输入。                   | 输入提示的必选参数后执行本命令重试。                     |
| ERR1010 | 参数冲突    | “支持外置AUC鉴权”取值为“FALSE”时输入了可选参数。 | “支持外置AUC鉴权”取值为“FALSE”时，删除可选参数后执行本命令重试。 |
