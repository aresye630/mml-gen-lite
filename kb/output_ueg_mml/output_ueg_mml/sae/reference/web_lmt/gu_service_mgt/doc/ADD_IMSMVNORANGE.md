# 添加IMS用户标识的号段前缀信息(ADD IMSMVNORANGE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，增加MVNO对应的IMPI或IMPU号段前缀会扩大既有操作员的号段范围，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于添加IMS用户标识的号段前缀信息记录，对IMPI或IMPU号段进行管理。

当系统需要进行IMPI或IMPU号段检查时配置，用于检查当前操作员是否拥有当前执行命令中携带IMPI或IMPU的操作权限。

1. 系统在号段匹配时，先对IMPI和IMPU进行如下处理：
   - 若为IMPI，则将用户IMPI的域名部分剥离。
   - 若为IMPU，则将SIP URI格式的IMPU的“sip:+”或“sip:”以及域名部分剥离；TEL URI格式的IMPU的“tel:+”部分剥离。
2. 根据处理结果来判断是否进行号段匹配：
   - 若剥离后的部分全部为数字，系统将此部分与配置的IMPI或IMPU号段前缀进行匹配。
     - 如果匹配成功，则既有操作员可通过该命令配置的“虚拟运营商号码”对该IMPI或IMPU进行操作。
     - 如果匹配失败，则既有操作员不能通过该命令配置的“虚拟运营商号码”对该IMPI或IMPU进行操作。
   - 若剥离后的部分包含非数字，系统不进行号段前缀匹配，该命令配置的“虚拟运营商号码”不能对此类IMPI或IMPU进行权限管理控制。

例如：使用本命令配置“号段前缀”为“86755”，“虚拟运营商号码”为“1”，“号段类型”为“IMPU”后：

- 若用户的IMPU为“sip:+8675528714565@huawei.com”，则该IMPU与“号段前缀”匹配成功，既有操作员可通过虚拟运营商号码“1”对该IMPU进行操作。
- 若用户的IMPU为“sip:+8675688714565@huawei.com”，则该IMPU与“号段前缀”匹配失败，既有操作员不能通过虚拟运营商号码“1”对该IMPI进行操作。
- 若用户的IMPU为“sip:+86755287abcde@huawei.com”，则不对该IMPU进行“号段前缀”匹配，该IMPU不能通过虚拟运营商号码“1”来进行权限控制管理。

## 注意事项

- 只有超级管理员帐户具有本命令的操作权限。
- 执行该命令前运营商需要完成号段规划。
- “虚拟运营商号码”仅对如下格式的IMS用户标识进行管理：
  - “IMSI@域名”的IMPI格式。
  - “sip:IMSI@域名”、“sip:+MSISDN@域名”或“tel:+MSISDN@域名”的IMPU格式。
- 执行该命令前必须确保已添加系统HLR以及虚拟HLR（添加系统HLR及虚拟HLR可参见**ADD SYSHLRSN**及**ADD VHLRSN**命令）。
- 不同的“虚拟运营商号码”不能配置相同“号段类型”的“号段前缀”。
- 当配置的“号段前缀”为包含关系，按照最长匹配原则，只有通过最长匹配“号段前缀”对应的“虚拟运营商号码”可以操作用户。

  例如：
  - 使用本命令配置“号段前缀”为“86755”，“虚拟运营商号码”为“1”。
  - 使用本命令配置“号段前缀”为“867”，“虚拟运营商号码”为“2”。

  则操作员仅可通过虚拟运营商号码“1”对“号段前缀”为“86755”的用户进行操作。
- 未使用该命令配置时，通过**ADD VHLRSN**命令配置的“虚拟HLR序列号”，可以对任何号段进行操作；当使用本命令配置了一个“号段前缀”后，其他未配置“号段前缀”的“虚拟运营商号码”，均不能对任何号段操作。

  例如：
  - 通过**ADD VHLRSN**命令配置的“虚拟HLR序列号”为“3”，未使用该命令配置时，操作员可通过虚拟运营商号码“3”对所有用户进行操作。
  - 使用本命令配置“号段前缀”为“86756”，“虚拟运营商号码”为“4”，则操作员仅可通过虚拟运营商号码“4”对“号段前缀”为“86756”的用户进行操作；“号段前缀”不为“86756”的用户，操作员不能再通过虚拟运营商号码“3”对其进行操作。

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                               |
|:----------|:--------|:---------------------------------------------------------------------------------------------------|
| PREFIX    | 号段前缀    | 用于标识IMPI或IMPU号段前缀。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                   |
| MVNO      | 虚拟运营商号码 | 用于标识一个虚拟运营商号码。该参数引用ADD VHLRSN命令的“虚拟HLR序列号”，必须先由ADD VHLRSN命令定义，然后才能在此处引用。 取值范围：1～255 默认值：无。         |
| RANGETYPE | 号段类型    | 用于标识号段类型，通过该参数区分“号段前缀”标识的是IMPI前缀还是IMPU前缀。 取值范围：IMPI：“号段前缀”标识的是IMPI前缀。IMPU：“号段前缀”标识的是IMPU前缀。 默认值：无。 |

## 使用实例

为某虚拟运营商添加IMS用户标识的号段前缀信息，虚拟运营商的“虚拟运营商号码”为“1”，且可以管理IMPI前缀为“46000”、“46001”，IMPU前缀为“86755”的用户，需要执行如下操作：

1. 登录“系统管理”界面，执行**ADD SYSHLRSN**添加系统HLR，“系统HLR序列号”为“1”，“系统HLR名称”为“MASTERNO1”，“状态”为“MASTER”，命令如下：

   ```
   ADD SYSHLRSN: SYSHLRSN=1, HLRNAME="MASTERNO1", STATUS=MASTER;
   ```
2. 执行**ADD VHLRSN**添加虚拟HLR，“虚拟HLR序列号”为“1”，PGW为简单模式，命令如下：

   ```
   ADD VHLRSN: HLRSN=1, HLRNAME="huawei";
   ```
3. 登录“IMS-HSS业务管理”窗口，执行本命令为该“虚拟运营商号码”添加需要管理的IMPI或IMPU号段前缀信息，命令如下：

   ```
   ADD IMSMVNORANGE: PREFIX="46000", MVNO=1, RANGETYPE=IMPI;
   ADD IMSMVNORANGE: PREFIX="46001", MVNO=1, RANGETYPE=IMPI;
   ADD IMSMVNORANGE: PREFIX="86755", MVNO=1, RANGETYPE=IMPU;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释     | 原因分析                                                                               | 处理建议                                                                                                                                                                    |
|:--------|:----------|:-----------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值    | 可能原因为如下之一：参数“号段前缀”的取值不是1～15位十进制数字组成的字符串。参数“虚拟运营商号码”的取值不在1～255之间。                   | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                                                        |
| ERR1037 | 记录已存在     | 可能原因为如下之一：输入的IMPI或IMPU“号段前缀”已经被输入的“虚拟运营商号码”配置过。输入的IMPI或IMPU“号段前缀”已经被其它“虚拟运营商号码”配置。 | 核实输入的“号段前缀”和“号段类型”，执行LST IMSMVNORANGE输入“号段类型”，查询已配置的IMPI或IMPU号段前缀信息，确保输入的“号段前缀”不在查询结果中。                                                                                 |
| ERR3097 | HLR序列号未定义 | 输入的“虚拟运营商号码”对应的虚拟HLR未预先使用ADD VHLRSN命令定义。                                           | 根据实际情况选择：如果用户需要在输入的“虚拟运营商号码”添加号段前缀信息，则登录“系统管理”界面执行ADD VHLRSN命令，添加所需的“虚拟HLR序列号”，然后再引用。如果需要在已定义的“虚拟运营商号码”添加号段前缀信息，则登录“系统管理”界面执行LST VHLRSN先查询已定义的“虚拟HLR序列号”，重新输入“虚拟运营商号码”。 |
