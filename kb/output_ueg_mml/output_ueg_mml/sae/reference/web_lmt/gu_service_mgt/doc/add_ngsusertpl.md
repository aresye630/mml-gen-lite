## 命令功能

该命令用于在数据库中增加5GS用户模板数据记录。

5GS用户模板包含5G基本数据，Snssai和Dnn数据：

- 5GS基本数据主要包含接入和移动性管理、鉴权算法等签约数据。
- Snssai和Dnn数据定义在会话信息模板中，最多16个Snssai数据，最多50个Dnn数据。 以模板引用的方式关联到了5GS用户模板中。

## 注意事项

系统中增加的5GS用户模板记录数不能超过20000条。

## 使用实例

用户开户或者设置用户5G自动开户时，通过引用该模板给用户签约5G业务。

1. 增加一个5GS用户模板，各参数取值如下。
   - “HLR序列号”为“1”
   - “模板ID”为“1”
   - “UE级别上行速率”为“200”
   - “UE级别上行速率单位”为“bps”
   - “UE级别下行速率”为“500”
   - “UE级别下行速率单位”为“bps”
   - “是否支持多媒体优先级服务”为“FALSE”
   - “是否支持关键任务优先级服务”为“FALSE”
   - “提供签约高延迟通信时的下行缓存大小”为“NOT\_REQUESTED”
   - “鉴权方式”为“5G-AKA”
   - “指示是否支持MICO模式”为“FALSE”

   ```
   ADD NGSUSERTPL: HLRSN=1, TPLID=1, AMBRUP=200, UPUNIT=bps, AMBRDW=500, DWUNIT=bps, MPS=FALSE, MCS=FALSE, DLBUFFERIND=NOT_REQUESTED, AUTHTYPE=5G-AKA, MICOALLOWED=FALSE;
   ```
2. 增加一个5GS用户模板，各参数取值如下。
   - “HLR序列号”为“1”
   - “模板ID”为“3”
   - “UE级别上行速率”为“100”
   - “UE级别上行速率单位”为“bps”
   - “UE级别下行速率”为“200”
   - “UE级别下行速率单位”为“bps”
   - “是否支持多媒体优先级服务”为“TRUE”
   - “是否支持关键任务优先级服务”为“TRUE”
   - “提供签约高延迟通信时的下行缓存大小”为“NOT\_REQUESTED”
   - “鉴权方式”为“5G-AKA”
   - “是否支持MICO模式”为“FALSE”
   - “是否允许SMS over NAS”为“TRUE”
   - “是否允许被叫短信”为“TRUE”
   - “是否闭锁被叫短信”为“TRUE”

   ```
   ADD NGSUSERTPL: HLRSN=1, TPLID=3, AMBRUP=100, UPUNIT=bps, AMBRDW=200, DWUNIT=bps, MPS=TRUE, MCS=TRUE, DLBUFFERIND=NOT_REQUESTED, AUTHTYPE=5G-AKA, MICOALLOWED=FALSE, SMSSUBSCRIBED=TRUE, MTSMS=TRUE, MTSMSBA=TRUE;
   ```
