# 增加IMSI全局路由数据(ADD IMSIRTINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用来增加IMSI全局路由数据。

- 当收到以IMSI路由的消息（如UPL，SAI）并且查询不到用户的KI时，先查询用户级的IMSI重定向记录（通过执行**ADD IMSIRTSUB**命令配置），如果不存在，则会查询全局的IMSI的全局路由数据，根据号码最大前缀匹配的原则匹配一条全局路由数据，将消息转发到此号段归属的HLR/AUC中。
- 当UDM收到业务流程请求消息，消息中的用户未在该UDM开户也未开卡并且**SET MAPCONF**命令中“是否支持异厂商Proxy转发功能”参数为“TRUE”时，UDM查询IMSI全局路由数据配置信息，根据消息中携带的号码最大前缀匹配原则获取PID（如果未查询到对应数据，则获取**SET MAPSERV**配置的“默认转发分区ID”），然后根据PID从**ADD SPRTINFO**配置的云分区路由数据记录中获取对端，进行消息的转发。

## 注意事项

系统中增加的IMSI全局路由数据记录数不能超过10000条。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                     |
|:-----------|:-------|:---------------------------------------------------------------------------------------------------------|
| IMSIPREFIX | IMSI前缀 | IMSI号段，对应于此地区的IMSI号段。 取值范围：1～15位的十进制数字组成的字符串。 必选参数。                                                      |
| HLRNO      | HLR号码  | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1～15位的十进制数字组成的字符串。 可选参数。 说明：“HLR号码”和“分区ID”互斥，只能设置其中一个。 |
| PID        | 分区ID   | 用于标识云分区的UDM编号。该参数必须先由ADD SPRTINFO命令定义，然后才能在此处引用。 取值范围：1～250 可选参数。 说明：“HLR号码”和“分区ID”互斥，只能设置其中一个。          |

## 使用实例

新增IMSI全局路由数据：IMSIPREFIX为1234, HLRNO为55,命令如下：

ADD IMSIRTINFO: IMSIPREFIX="1234", HLRNO="55";

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                      | 处理建议                                                                                                                                                |
|:--------|:--------|:--------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1111 | 超过最大限制  | 增加的IMSI全局路由数据记录数超过10000条。 | 根据实际情况，如需增加IMSI全局路由数据，处理步骤如下：执行LST IMSIRTINFO命令，查询已存在的IMSI全局路由数据。执行RMV IMSIRTINFO命令，删除不必要的IMSI全局路由数据记录。执行该命令增加IMSI全局路由数据，确保增加的IMSI全局路由数据记录数在规定范围之内。 |
| ERR4142 | PID不存在  | PID未定义。                   | 执行LST SPRTINFO命令查询已配置云分区路由数据，重新执行该命令。                                                                                                               |
