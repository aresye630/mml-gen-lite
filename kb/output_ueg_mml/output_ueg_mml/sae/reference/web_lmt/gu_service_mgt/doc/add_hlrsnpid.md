# 增加HLRSN与云分区数据(ADD HLRSNPID)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在数据库中增加一条HLRSN与云分区映射关系的数据记录。

## 注意事项

使用该命令，请提前检查要配置的参数值与实际规划的数据是否一致，避免配置错误。如果配置的参数值有误，需要使用**RMV HLRSNPID**先删除该错误记录，然后重新配置。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                            |
|:-------|:-------|:--------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 用于标识本地HLR。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                       |
| PID    | 分区ID   | 用于标识分区编号。该参数必须先由“USCDB MML命令”界面下ADD RPARTITION命令定义，然后才能在此处引用。 取值范围：1～250 默认值：无。 |

## 使用实例

在数据库中增加一条“HLR序列号”为“5”与“分区ID”为“2”的映射关系的数据记录：

```
ADD HLRSNPID: HLRSN=5, PID=2;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释     | 原因分析                  | 处理建议                                                                                                                           |
|:--------|:----------|:----------------------|:-------------------------------------------------------------------------------------------------------------------------------|
| ERR3097 | HLR序列号未定义 | HLR序列号未定义。            | 根据实际情况，重新输入已定义的“HLR序列号”，可使用LST HLRSN命令查询已定义的HLR序列号。                                                                            |
| ERR3342 | PID不存在    | PID未定义。               | 请检查确保输入的PID已由“USCDB MML命令”界面下ADD RPARTITION命令配置，然后重新输入。                                                                        |
| ERR1037 | 记录已存在     | 输入的HLR序列号已添加过云分区映射关系。 | 请确认是否需要修改HLRSN与PID的映射关系：是：使用LST HLRSNPID命令查询已添加的HLRSN与云分区映射关系，然后使用RMV HLRSNPID命令删除对应HLRSN与云分区映射关系，再重新输入。否：请输入正确的“HLRSN”和“PID”。 |
