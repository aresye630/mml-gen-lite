# 查询CAVEAKA鉴权能力(LST HCAA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于从HSS的业务数据库中查询指定IMPI对Cave AKA鉴权的支持情况和其UIMID信息，需要输入唯一标识该数据记录的关键参数IMPI。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                 |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------|
| IMPI   | IMPI   | 用于指示系统需要按照哪个IMPI来查询Cave AKA数据。该参数的配置原则是要求输入的IMPI值符合username@realm形式的NAI格式。 取值范围： 长度不超过127的字符串 缺省值： 无 |

## 使用实例

查询Cave AKA鉴权能力。IMPI：460001234567890@huawei.com。

```
LST HCAA: IMPI="460001234567890@huawei.com";
```

## 输出结果说明

| 参数标识       | 参数说明                                           |
|:-----------|:-----------------------------------------------|
| IMPI       | 显示用于查询Cave AKA鉴权能力的IMPI。                       |
| CAVEAKAFLG | 显示CAVEAKA鉴权标识。                                 |
| UIMID      | 显示UIMID信息。当CAVEAKAFLG为TRUE时，才显示UIMID的值；否则不会显示。 |
