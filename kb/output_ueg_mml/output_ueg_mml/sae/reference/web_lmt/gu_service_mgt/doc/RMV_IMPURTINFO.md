# 删除IMPU全局路由数据(RMV IMPURTINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于删除一条IMPU全局路由数据记录。

## 注意事项

删除一条IMPU全局路由数据记录，会导致用户业务流程失败，请谨慎操作。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                  |
|:-----------|:-------|:--------------------------------------------------------------------------------------|
| IMPUPREFIX | IMPU前缀 | 标识一条IMPU全局路由数据记录的关键字段之一，用于指定需要删除哪一个IMPU前缀对应的IMPU全局路由数据记录，操作员可以使用LST IMPURTINFO命令查询获得。 |

## 使用实例

删除IMPU全局路由数据：“IMPU前缀”为“112”，命令如下：

```
RMV IMPURTINFO: IMPUPREFIX="112";
```

## 输出结果说明

输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                     | 处理建议                                                                            |
|:--------|:--------|:-------------------------|:--------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | 输入的“IMPU前缀”参数对应的数据记录不存在。 | 根据实际情况，重新输入参数，确保输入的“IMPU前缀”参数对应的数据记录是存在的，可通过LST IMPURTINFO命令查询已存在的IMPU全局路由数据记录。 |
