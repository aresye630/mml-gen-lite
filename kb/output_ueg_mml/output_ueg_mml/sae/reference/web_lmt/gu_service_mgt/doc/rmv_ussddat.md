# 删除USSD控制数据(RMV USSDDAT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使PUSSD消息处理失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除一条或多条USSD控制数据记录。

## 注意事项

- 删除USSD控制数据会导致USSD业务操作无法正常进行，请谨慎操作。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                |
|:-------|:-------|:--------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 标识USSD控制数据记录的关键字段之一，用于指定在哪个HLR上删除USSD控制数据记录，操作员可以使用LST HLRSN命令查询获得。 |
| SRCODE | 业务码    | 标识USSD控制数据记录的关键字段之一，用于指定需要删除哪些业务码相关的数据记录，操作员可以使用LST USSDDAT命令查询获得。  |

## 使用实例

删除“HLR序列号”为“1”的HLR上的USSD控制数据。其中“业务码”为“168”：

```
RMV USSDDAT: HLRSN=1, SRCODE="168";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                               | 处理建议                                                   |
|:--------|:--------|:-----------------------------------|:-------------------------------------------------------|
| ERR1004 | 无效的参数值  | 参数“业务码”的取值中含有0～9、“*”和“#”以外的字符。     | 根据实际情况，重新输入“业务码”，确保其取值为长度不超过16位的数字组成的字符串。              |
| ERR3007 | 记录不存在   | “HLR序列号”和“业务码”对应的USSD数据记录不存在或已被删除。 | 使用LST USSDDAT命令查询后，重新确认要删除哪个“HLR序列号”和“业务码”对应的USSD数据记录。 |
