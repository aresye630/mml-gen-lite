# 增加IMPU的参考位置信息(ADD HNNRLI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在IMS-HSS的业务数据库中增加一条IMPU的“参考位置信息”的数据记录。

当接入网不能将用户位置信息上报给IMS网络时，IMS网络可以基于用户签约时指定的位置信息来为用户提供固网位置业务，这种位置信息称为参考位置信息。参考位置信息主要应用于固网位置业务，如果设置了IMPU的参考位置信息，在IMS-HSS检查NASS游牧权限时，将优先匹配用户签约的参考位置信息。新增IMPU参考位置信息时，默认参考位置信息为首个与该IMPU关联且“参考位置信息类型”不为“IPRANGE(IPRANGE)”的参考位置信息，也可以使用**MOD HNNRLI**命令重新设置已有IMPU的默认参考位置信息。

## 注意事项

当软参“DOWNLOADRLI”（下发参考位置信息开关）设置为“1”或者“2”：

- 增加参考位置信息的IMPU为隐式注册集的默认IMPU时，SAR携带IMPU为隐式注册集中的默认IMPU或非默认IMPU，SAA返回携带隐式注册集的默认IMPU的默认参考位置信息，若该默认参考位置信息不存在，则SAA响应不携带参考位置信息。
- 增加参考位置信息的IMPU不为隐式注册集的默认IMPU时，SAA发送到S-CSCF的响应消息中携带默认的参考位置信息。

## 使用实例

1. 为了使IMS-HSS能够下发用户的参考位置信息，S-CSCF获取用户固网位置业务状态信息，操作员需要给用户签约IMPU参考位置信息业务。其中“IMPU”为“sip:impuinfo@huawei.com”，“参考位置信息索引”为“1”，“参考位置信息”为“shenzhen”，“参考位置信息类型”为IEEE-“802.11(IEEE-802.11)”：

   ```
   ADD HNNRLI: IMPU="sip:impuinfo@huawei.com", RLINDEX=1, RLI="shenzhen", RLT=IEEE-802.11;
   ```
2. 为了使IMS-HSS能够下发用户的参考位置信息，S-CSCF获取用户固网位置业务状态信息，操作员需要给用户签约IMPU参考位置信息业务。其中“IMPU”为“sip:impuinfo1@huawei.com”，“参考位置信息索引”为“1”，“参考位置信息”为“shen=zhen”，“参考位置信息类型”为IEEE-“802.11(IEEE-802.11)”：

   ```
   ADD HNNRLI: IMPU="sip:impuinfo1@huawei.com", RLINDEX=1, RLI="shen\=zhen", RLT=IEEE-802.11;
   ```
3. 为了使IMS-HSS能够下发用户的参考位置信息，S-CSCF获取用户固网位置业务状态信息，操作员需要给用户签约IMPU参考位置信息业务。其中“IMPU”为“sip:impuinfo2@huawei.com”，“参考位置信息索引”为“1”，“参考位置信息”为“shen'zhen”，“参考位置信息类型”为IEEE-“802.11(IEEE-802.11)”：

   ```
   ADD HNNRLI: IMPU="sip:impuinfo2@huawei.com", RLINDEX=1, RLI="shen\'\'zhen", RLT=IEEE-802.11;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 900001007 | 无效的参数值        | 输入的参数取值不符合取值范围。          | 根据实际情况，重新输入不符合取值范围要求的参数。                                                                |
| 900003183 | 参考位置信息Index存在 | “参考位置信息索引”参数指定的数据记录已经存在。 | 该“参考位置信息索引”指定的数据记录已添加，根据实际情况确认是否需要添加其他的“参考位置信息索引”记录。用户可以通过执行LST HNNRLI查询已定义的“参考位置信息索引”。 |
