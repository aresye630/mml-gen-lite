# 修改Diameter漫游限制业务(MOD DIAMRRS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于给EPS用户以模板方式提供或撤销Diameter漫游限制业务。

在用户业务流程中，Diameter漫游限制业务数据作用如下：

- 在S6a/S6d位置更新流程中，UDM根据用户签约的Diameter服务节点漫游限制模板数据判断是否允许用户访问当前服务的MME/S4-SGSN。如果不允许访问，则位置更新拒绝，否则继续位置更新流程。
- 在SWx的鉴权流程中，UDM根据用户签约的Diameter服务节点漫游限制模板数据判断是否允许用户访问当前服务的3GPP AAA Server。如果不允许访问，则鉴权拒绝，否则继续鉴权流程。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识           | 参数名称                | 参数说明                                                                                                                                                                                                                                                        |
|:---------------|:--------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI           | IMSI                | 用于标识需要修改Diameter漫游限制业务的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                             |
| ISDN           | MSISDN              | 用于标识需要修改Diameter漫游限制业务的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                           |
| RECORDCOUNT    | 用户个数                | 用于标识需要修改Diameter漫游限制业务的用户数目。 当需要为连续号码的多个用户修改Diameter漫游限制业务时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户修改Diameter漫游限制业务。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户修改Diameter漫游限制业务，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE       | IMSI文件名             | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要修改Diameter漫游限制业务的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“moddiamrrs.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或十进制数字组成的字符串。 默认值：无。                                                              |
| ISDNFILE       | MSISDN文件名           | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要修改Diameter漫游限制业务的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“moddiamrrs.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或十进制数字组成的字符串。 默认值：无。                                                        |
| PROV           | 提供或撤销Diameter漫游限制业务 | 用于标识执行该命令是给EPS用户提供/修改还是撤销Diameter漫游限制业务。 取值范围：TRUE：提供/修改FALSE：撤销 默认值：无。                                                                                                                                                                                     |
| DIAMNODETPL_ID | DIAMRR模板ID          | 仅当本命令中的“提供或撤销Diameter漫游限制业务”参数为“TRUE”时该参数有效。用于标识待给用户修改的Diameter漫游限制模板ID。该参数必须先由ADD DIAMRRTPL命令定义，然后才能在此处引用。执行MOD DIAMRRTPL命令修改模板数据会使签约此模板的用户数据被同步修改，会影响在网用户。 取值范围：0～65534 默认值：无。                                                                            |

## 使用实例

1. 修改IMSI号码为“460000009123456”的用户的Diameter漫游限制业务，“提供或撤销Diameter漫游限制业务”为“TRUE”，“DIAMRR模板ID”为“2”：

   ```
   MOD DIAMRRS: IMSI="460000009123456", PROV=TRUE, DIAMNODETPL_ID=2;
   ```
2. 修改3个连续号码的用户的Diameter漫游限制业务，这3个MSISDN号码分别为“13310911001”、“13310911002”、“13310911003”，“提供或撤销Diameter漫游限制业务”为“TRUE”，“DIAMRR模板ID”为“2”：

   ```
   MOD DIAMRRS: ISDN="13310911001", RECORDCOUNT=3, PROV=TRUE, DIAMNODETPL_ID=2;
   ```
3. 修改3个非连续号码的用户的Diameter漫游限制业务，这3个MSISDN号码分别为“13310911001”、“13310911003”、“13310911005”，已保存在“MSISDN文件名”为“moddiamrrs.txt”的文件中，并通过文件管理功能上传到指定目录，“提供或撤销Diameter漫游限制业务”为“FALSE”：

   ```
   MOD DIAMRRS: ISDNFILE="moddiamrrs.txt", PROV=FALSE;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释         | 原因分析                                                                                               | 处理建议                                                                                                                    |
|:--------|:--------------|:---------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值        | 可能原因为如下之一：参数“IMSI”的取值不是6～15位十进制数字组成的字符串。参数“MSISDN”的取值不是1～15位十进制数字组成的字符串。                           | 根据实际情况，重新输入“IMSI”或“MSISDN”的取值，确保其取值符合要求。                                                                                |
| ERR1009 | 参数丢失          | “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数一个都没有输入。                                                  | 根据实际情况，重新输入参数，并满足“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                             |
| ERR1005 | 文件未找到         | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                   | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                      |
| ERR1010 | 参数冲突          | 可能原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR3001 | 用户未开户         | 用户的IMSI号码或MSISDN号码输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户。                                             | 核实用户的IMSI号码或MSISDN号码，如果确定输入无误，证明实际输入的参数“IMSI”或“MSISDN”对应的用户未开户，请先通过ADD SUB命令给用户开户。                                      |
| ERR1025 | 批操作文件中格式非法    | 参数“IMSI文件名”或“MSISDN文件名”对应的批操作文件格式不正确。                                                              | 请根据IMSIFILE文件格式和ISDNFILE文件格式，重新确定对应的批操作文件格式。                                                                            |
| ERR3810 | 用户不是EPS用户或未开户 | 待签约Diameter漫游限制业务的用户不是EPS用户。                                                                       | 待签约Diameter漫游限制业务的用户必须是EPS用户，可以通过执行MOD EPS命令给用户签约EPS数据。                                                                 |
