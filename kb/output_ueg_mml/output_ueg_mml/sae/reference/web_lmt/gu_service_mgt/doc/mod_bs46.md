# 修改承载业务BS46(MOD BS46)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来修改用户的承载业务数据。签约BS46业务的用户其网络接入模式必须为MSC或BOTH。

BS46业务是指异步PAD存取电路业务-9600Bit/s。

执行此命令后，如果是给用户签约该业务，则会下发插入用户数据消息；如果是给用户去签约该业务，则会下发删除用户数据消息。

## 注意事项

- IMSI、ISDN、IMSIFILE和ISDNFILE是条件可选参数，任何一个参数出现即可。
- RECORDCOUNT一定不能与IMSIFILE或ISDNFILE同时存在。
- 如果要提供BS46业务，PROV＝TRUE；如果要撤销BS46业务，PROV＝FALSE。

## 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                |
|:------------|:-----------|:------------------------------------------------------------------------------------|
| IMSI        | IMSI       | IMSI号码，E.212格式的编码，为6～15位的十进制数字。 可选参数。                                               |
| ISDN        | MSISDN     | MSISDN号码，E.164格式的编码，为1～15位的十进制数字。 可选参数。                                             |
| RECORDCOUNT | 用户个数       | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。 |
| IMSIFILE    | IMSI文件名    | IMSI文件名称，1～16个字母或数字组成。IMSIFILE包含多个不连续的IMSI号码。 可选参数。                                 |
| ISDNFILE    | MSISDN文件名  | ISDN文件名称，1～16个字母或数字组成。 ISDNFILE包含多个不连续的MSISDN号码。 可选参数。                              |
| PROV        | 是否提供BS46业务 | 提供还是撤销BS46业务。 TRUE：提供 FALSE：撤销 必选参数。                                                |

## 使用实例

1. 运营商为IMSI号码是460000009012345的用户签约BS46业务。命令如下：

   MOD BS46: IMSI="460000009012345", PROV=TRUE;
2. 运营商为IMSI号码是460000009012342、460000009012344、460000009012347和460000009012349的用户提供BS46业务。

   1. 编写IMSIFILE，文件名称为IMSIBAT，内容如下：

      460000009012342

      460000009012344

      460000009012347

      460000009012349
   2. 通过Web UI上的文件选项将文件上传到指定位置。
   3. 执行MOD BS46命令提供BS46业务。

      MOD BS46: IMSIFILE="IMSIBAT", PROV=TRUE;
