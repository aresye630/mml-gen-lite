# 校验用户数据一致性（CHK CONSY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会导致DRU模块、DSU模块内存占有率上升，性能消耗大，因此建议在夜间话务量低时执行该命令。

此操作用于对内存数据库中各节点的用户数据进行一致性校验。系统显示校验结果，并以DSU Master节点中的数据为基准进行一致性处理。

## 注意事项

- IMSI、ISDN、IMSIFILE和ISDNFILE是条件可选参数，有且只能有一个参数出现。
- RECORDCOUNT一定不能与IMSIFILE或ISDNFILE同时出现。
- 批操作执行本命令会导致DRU模块、DSU模块内存占有率上升，性能消耗大，建议在夜间话务量低时操作。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                           |
|:------------|:----------|:-------------------------------------------------------------------------------|
| IMSI        | IMSI      | IMSI号码，E.212格式的编码。 取值范围：6～15位的十进制数字。                                           |
| ISDN        | MSISDN    | MSISDN号码，E.164格式的编码。 取值范围：1～15位的十进制数字。                                         |
| RECORDCOUNT | 用户个数      | 用户的数目。此参数必须与IMSI或MSISDN同时出现，但一定不能与IMSIFILE或ISDNFILE同时出现。 取值范围：1～100000         |
| IMSIFILE    | IMSI文件名   | IMSI文件名称，不包括文件所在的路径。文件包含多个不连续的IMSI号码，每个IMSI号码占一行。 取值范围：1～16个字母或数字组成的字符串。       |
| ISDNFILE    | MSISDN文件名 | MSISDN文件名称，不包括文件所在的路径。文件包含多个不连续的MSISDN号码，每个MSISDN号码占一行。 取值范围：1～16个字母或数字组成的字符串。 |

## 使用实例

对IMSI号码是460000009123456的用户数据进行一致性校验。

CHK CONSY: IMSI="460000009123456";
