## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成业务呼损甚至中断，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在配置UDM业务数据时设置业务的相关参数。例如，在配置AMF注册类的业务时，通过该命令配置注册时安全策略有关的参数。

## 注意事项

- 该命令的全部参数都为可选参数，但是执行命令时必须保证至少选择其中一个参数。
- 该命令中所描述的系统初始设置值，是指操作员通过**LST UDMSERV**命令查询得出的系统在初始化时的预置参数值。
- 该命令不允许进行批操作。

## 使用实例

部署UDM后进行业务配置时，需要设置UDM业务参数。例如，在配置AMF注册类的业务时，通过该命令配置注册时安全策略有关的参数。

1. 例如设置“AMF注册的安全策略”为鉴权生效时长校验，“鉴权生效时长”为“11”，“全局数据刷新周期”为“61”秒：

   ```
   SET UDMSERV:SECPOLICYOFAMFREG=CHECKAUTHVALIDATIONTIME, AUTHVALIDATIONTIME=11, GLOBALDATAREFRESH=61;
   ```
2. 例如设置“AMF注册的安全策略”为鉴权生效时长校验，“鉴权方式”为“AUTHENTICATION\_TYPE\_LEGACY”，“最大备份AMF重发次数”为“1”：

   ```
   SET UDMSERV: SECPOLICYOFAMFREG=CHECKAUTHVALIDATIONTIME, AUTHENTICATION_TYPE=AUTHENTICATION_TYPE_LEGACY, RESENT_TIMES_BKAMF=1;
   ```
