# 批量删除IMPI的SIP Digest鉴权信息(RMV HSDABAT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于在HSS的业务数据库中批量删除指定IMPI的SIP Digest鉴权信息。

## 注意事项

- 参数IMPI和IMPIFILE只能存在一个。
- 该命令涉及批量处理用户数据，请操作人员谨慎操作。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                                                                                                                                    |
|:---------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| BATTYPE  | 批操作类型    | 指定批操作的类型，为枚举类型。 取值范围： DISCONTINUOUS(1)CONTINUOUS(5) 缺省值： 无                                                                                                                                                                                              |
| IMPI     | IMPI     | 仅当本命令中的“批操作类型”参数为“CONTINUOUS”时该参数有效。用于指定一个需要删除SIP Digest鉴权信息的IMPI。字母区分大小写。IMPI支持正则表达式，正则表达式主要用于处理连续号段。正则表达式以“!”开始和结尾，正则表达式包含两个字段，第一个字段表示取值范围，此字段以“[”和“]”为开始和结尾；另一个是长度字段，表明要生成几位字段，范围是1~4。使用正则表达方式批操作时，IMPI参数中正则表达式外不能使用其它“!”。 取值范围： 长度不超过133的字符串 缺省值： 无 |
| IMPIFILE | IMPI导入文件 | 仅当本命令中的“批操作类型”参数为“DISCONTINUOUS”时该参数有效。用于指定一个需要删除SIP Digest鉴权信息的IMPI导入文件名。导入文件中为需要批量删除SIP Digest鉴权信息的IMPI集合。IMPI值符合NAI格式，长度不超过127，字母区分大小写。每一个文件中IMPI不能超过10万条记录。导入文件主要用于非连续号段。 取值范围： 长度不超过127的字符串 缺省值： 无                                                 |

## 使用实例

删除SIP Digest鉴权信息。批操作类型：CONTINUOUS，IMPI：test![0-9]{2}!。

```
RMV HSDABAT: BATTYPE=CONTINUOUS, IMPI="test![0-9]{2}!";
```

删除SIP Digest鉴权信息。批操作类型：DISCONTINUOUS，IMPI导入文件：IMPI\_LIST.txt。IMPI导入文件中的内容如下：

test01

test02

...

test99

```
RMV HSDABAT: BATTYPE=DISCONTINUOUS, IMPIFILE="IMPI_LIST.txt";
```
