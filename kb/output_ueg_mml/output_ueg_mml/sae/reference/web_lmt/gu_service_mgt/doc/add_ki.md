## 命令功能

该命令用于增加或更新用户的鉴权密钥KI。

KI用于用户鉴权。建议给KI/OPC加密，并且需要一个加密参数，UDM系统中该参数为K4。K4序列号为0表示KI/OPC不加密。

多用户批加载KI时，KI以文本的形式存放在KI批操作文件中，加载KI也就是加载该文件。在加载KI时，需要KI的文本文件以及给KI加密用的K4参数所对应的K4序列号。批加载的KI只能对应一个K4，可通过选择K4序列号选择加密所需的K4。

## 注意事项

- 当参数“操作类型”取值为“MOD”的情况下，修改KI时，建议把KI、OPC、K4、K2的值填写完整，原因如下：
  - 如果执行命令时不携带K4、K2的值，数据库中依然保留之前K4、K2的值（可以使用**LST KI**命令查询当前数据库中K4、K2的值）。
  - 如果执行命令时携带K4、K2的值，数据库中存储新携带的K4、K2的值。
  - 如果要清除数据库中K4、K2的值，需要在执行命令时把K4、K2的值都取为“0”。
- 当数据库中“K4的值不为0，K2的值为0”时，执行该命令修改KI，分以下4种情况：
  - 如果命令中不携带K2的值或携带的K2值为0，此时无论携带的K4值如何，系统都将命令中携带的KI值直接存入数据库。
  - 如果命令中携带K2的值且不为0，携带K4的值也不为0，系统就用命令中携带的K4先解密KI，再用命令中携带的K2加密KI，最后把加密后的KI保存在数据库中。
  - 如果命令中携带K2的值且不为0，携带K4的值为0，系统就用命令中携带的K2加密KI，然后把加密后的KI保存在数据库中。
  - 如果命令中携带K2的值且不为0，但未携带K4，系统就用数据库中携带的K4先解密KI，再用命令中携带的K2加密KI，最后把加密后的KI保存在数据库中。
- 当数据库中“K4的值和K2的值均为0”时，执行该命令修改KI，分以下3种情况：
  - 如果命令中不携带K2的值或携带的K2值为0，此时无论携带的K4值如何，系统都将命令中携带的KI值直接存入数据库。
  - 如果命令中携带K2的值且不为0，携带K4的值也不为0，系统就用命令中携带的K4先解密KI，再用命令中携带的K2加密KI，最后把加密后的KI保存在数据库中。
  - 如果命令中携带K2的值且不为0，但未携带K4或携带K4的值为0，系统就用命令中携带的K2加密KI，然后把加密后的KI保存在数据库中。
- 当数据库中“K4的值为0，K2的值不为0”时，执行该命令修改KI，分以下5种情况：
  - 如果命令中携带的K2值为0，此时无论携带的K4值如何，系统都将命令中携带的KI值直接存入数据库。
  - 如果命令中携带K2的值且不为0，携带K4的值也不为0，系统就用命令中携带的K4先解密KI，再用命令中携带的K2加密KI，最后把加密后的KI保存在数据库中。
  - 如果命令中携带K2的值且不为0，携带K4的值为0，系统就用命令中携带的K2加密KI，然后把加密后的KI保存在数据库中。
  - 如果命令中不携带K2的值，携带K4的值为0或者不携带K4，系统就用数据库中携带的K2加密KI，然后把加密后的KI保存在数据库中。
  - 如果命令中不携带K2的值，但携带K4的值不为0，系统就用命令中携带的K4先解密KI，再用数据库中携带的K2加密KI，最后把加密后的KI保存在数据库中。
- 当数据库中“K4的值不为0，K2的值也不为0”时，执行该命令修改KI，分以下9种情况：
  - 如果命令中携带K4、K2的值且都不为0，系统就用命令中携带的K4先解密KI，再用命令中携带的K2加密KI，最后把加密后的KI保存在数据库中。
  - 如果命令中携带K4、K2的值且都为0，系统将命令中携带的KI值直接存入数据库。
  - 如果命令中携带K4的值且为0，携带K2的值且不为0，系统就用命令中携带的K2加密KI，然后把加密后的KI保存在数据库中。
  - 如果命令中携带K4的值且不为0，携带K2的值且为0，系统将命令中携带的KI值直接存入数据库。
  - 如果命令中K4、K2的值都没有携带，系统就用数据库中的K4先解密KI，再用数据库中的K2加密KI，最后把加密后的KI保存在数据库中。
  - 如果命令中不携带K4的值、只携带K2的值且为0，系统将命令中携带的KI值直接存入数据库。
  - 如果命令中不携带K4的值、只携带K2的值且不为0，系统就用数据库中的K4先解密KI，再用命令中携带的K2加密KI，最后把加密后的KI保存在数据库中。
  - 如果命令中只携带K4的值且不为0、没有携带K2的值，系统就用命令中携带的K4先解密KI，再用数据库中的K2加密KI，最后把加密后的KI保存在数据库中。
  - 如果命令中只携带K4的值且为0、没有携带K2的值，系统就用数据库中携带的K2加密KI，然后把加密后的KI保存在数据库中。
- 执行本命令修改KI，如果携带的K4算法类型为SM4且没有携带K2，当数据库中的KI没有使用K2加密时，使用默认K2加密KI后存储到数据库，如果默认K2不存在，系统提示“ERR3111 系统不支持该特性”。
- 当**SET MAPCONF**命令中的“KI加密检测”参数为“TRUE”，加载KI时必须填写对应的K4序列号。
- 添加KI成功后，请使用**CHK KI**命令校验“KI值”。
- 当“鉴权算法类型”为“MILENAGE”、“MILENAGE\_2”或“CUSTOM\_1”时，“OPC值”和“OP序列号”的其中之一必须出现但不能同时出现。
- 如果“KI文件名”参数出现了，“IMSI”，“KI值”，“OPC值”不能出现。
- 如果“KI值”参数出现了，“IMSI”和“鉴权算法类型”也需要出现。
- 加载KI批操作文件（KI文件名）格式。

  **当“鉴权算法类型”参数取值为“MILENAGE”、“MILENAGE\_2”或“CUSTOM\_1”，文件格式如下时，“OP序列号”不能配置：**

  IMSI1 KI1 OPC1

  IMSI2 KI2 OPC1

  IMSI3 KI3 OPC2

  IMSI4 KI4 OPC3

  ……

  IMSIn KIn OPCn

  #IMSIn为6～15位的十进制数字，KI为32位的十六进制数字，OPC为32位的十六进制数字。

  **当“鉴权算法类型”参数取值为“MILENAGE”、“MILENAGE\_2”或“CUSTOM\_1”，文件格式如下时，“OP序列号”必须配置：**

  IMSI1 KI1

  IMSI2 KI2

  IMSI3 KI3

  IMSI4 KI4

  ……

  IMSIn KIn

  #IMSIn为6～15位的十进制数字，KI为32位的十六进制数字。

  **当“鉴权算法类型”参数取值不是“MILENAGE”、“MILENAGE\_2”、“CUSTOM\_1”或“CUSTOM\_6”时，文件格式如下：**

  IMSI1 KI1

  IMSI2 KI2

  IMSI3 KI3

  IMSI4 KI4

  ……

  IMSIn KIn

  #IMSIn为6～15位的十进制数字，KI为32位的十六进制数字。
- 当**SET MAPCONF**命令中的“是否启用随机密钥”参数为“TRUE”，存在以下两种情况。
  - 当“操作类型”为“ADD”时，执行该命令时如果未使用K2或K4对KI进行加密，同时未执行**SET DEFAULTK2SNO**命令设置默认K2，则执行该命令时会返回错误。
  - 当“操作类型”为“MOD”时，执行该命令时以数据库最终结果来判断，如果KI未使用K2或K4进行加密，同时未执行**SET DEFAULTK2SNO**命令设置默认K2，则执行该命令时会返回错误。
- 执行本命令携带的“K4序列号”对应的“算法类型”为“SM4”时，“K2序列号”参数必选，且**SET MAPCONF**命令的“是否启用随机密钥”参数必需为“TRUE”、**SET MAPSERV**命令的“SAE-HSS AES加密模式”参数必需为“CBC”、**SET MAPCONF**命令的“是否支持K2加密OPC”参数必需为“TRUE”。

## 使用实例

1. 单用户加载KI：

   运营商为IMSI号码是460000009123456的用户加载KI，“KI值”为“1234567890ABCDEF1111111111111111”，“K4序列号”为“2”，“卡类型”为“USIM”，“鉴权算法类型”为“MILENAGE”，“OPC值”为“12345678901234561234567890123456”，“K2序列号”为“0”，“K2密钥输入方式”为“ClearKey”。命令如下：

   ```
   ADD K4: HLRSN=1, K4SNO=2, K4VALUE="*****";
   ```

   ```
   ADD KI: HLRSN=1, IMSI="460000009123456", KIVALUE="*****", K4SNO=2, CARDTYPE=USIM, ALG=MILENAGE, OPCVALUE="*****", K2SNO=0, KEYTYPE=ClearKey;
   ```
2. 批加载KI：
   1. 设置K4数据，命令如下：

      ```
      ADD K4: HLRSN=1, K4SNO=2, K4VALUE="*****";
      ```
   2. 编写KI批操作文件。

      文件名ADDKI.txt

      文件格式为：

      460001480000001 c85a3a2bb6becb70701538fc3209b887

      460001480000003 87272008ccd41520a21f245e40bd528a

      460001480000006 66a214d47632257f05cb3efb21e4200d

      460001480000008 2f1a67549a86e3a6374ae637b700a8de
   3. 将KI批操作文件传到指定位置。

      通过PGW主界面上的“文件管理器”上传到系统中。
   4. 加载KI，命令如下：

      ```
      ADD KI: HLRSN=1, FNAME="ADDKI.txt", K4SNO=2, CARDTYPE=SIM, ALG=COMP128_1;
      ```
