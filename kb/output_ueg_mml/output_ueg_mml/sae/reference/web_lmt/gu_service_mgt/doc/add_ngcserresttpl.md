# 增加5G业务限制模板(ADD NGCSERRESTTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加5G业务限制模板数据记录。

UDM向对端下发业务数据时，首先根据5G业务下发模板和5G业务限制模板对用户需要下发的DNN进行控制，实现按照不同预期下发不同的DNN。

## 注意事项

所有“HLR序列号”中增加的5G业务限制模板记录数不能超过3000条。

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                |
|:------------|:---------|:------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号   | 可选必选说明：必选参数 参数含义：用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1～255 默认值：无。 配置原则：无。                                             |
| TPLID       | 模板ID     | 可选必选说明：必选参数 参数含义：用于标识待增加模板在系统中的序号。 取值范围：0～65534 默认值：无。 配置原则：无。                                                                      |
| TPLNAME     | 模板名      | 可选必选说明：可选参数 参数含义：用于标识待增加模板在系统中的名称。 取值范围：1～60个字母或十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                         |
| SERCODE     | 业务限制列表   | 可选必选说明：必选参数 参数含义：用于标识当用户漫游到特定的5G区域后，对哪些业务进行限制。 取值范围： SMDATA：SMF数据 默认值：无。 配置原则：无。                                                    |
| SMDATATPLID | 会话信息模板ID | 可选必选说明：条件必选参数 参数含义：用于标识会话信息模板ID。该参数必须先由ADD SMDATATPL命令定义，然后才能在此处引用。 取值范围：1～2147483646 默认值：无。 配置原则：仅当本命令中的“业务限制列表”参数为“SMDATA”时该参数有效。 |

## 使用实例

增加一个5G业务限制模板。“HLR序列号”为“1”，“模板ID”为“8”，“业务限制列表”为“SMDATA”，“会话信息模板ID”为“2”。

```
ADD NGCSERRESTTPL: HLRSN=1, TPLID=8, SERCODE=SMDATA, SMDATATPLID=2;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                   | 处理建议                                                                                                                                             |
|:--------|:--------|:-----------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 界面输入的参数不在相应的参数取值范围内。   | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                                 |
| ERR3004 | 模板已存在   | “模板ID”在数据库中已存在。        | 根据实际情况，重新输入参数，确保输入的“模板ID”和系统中已存在的不重复。可执行LST NGCSERRESTTPL命令查询系统中已存在的5G业务限制模板。                                                                    |
| ERR3007 | 记录不存在   | “HLR序列号”未定义。           | 根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求，可通过LST HLRSN命令查询已定义的“HLR序列号”。                                                                                   |
| ERR3047 | 超过最大限制  | 增加的5G业务限制模板记录数超过3000条。 | 根据实际情况，如需增加5G业务限制模板，处理步骤如下： 执行LST NGCSERRESTTPL命令，查询已存在的5G业务限制模板。 执行RMV NGCSERRESTTPL命令，删除不必要的5G业务限制模板。 执行该命令增加5G业务限制模板，确保增加的5G业务限制模板记录数在规定范围之内。 |
