# 修改5G QoS模板(MOD NGCQOSTPL)

## 命令功能

**须知** 

该命令属于高危命令，修改5G QoS模板会使引用此模板的用户5G QoS数据被同步修改。因此执行该命令前，请仔细评估当前操作的风险，确认对业务没有影响后方可执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用于对一条5G QoS模板数据记录的某些参数进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一个5G QoS模板信息：

- “HLR序列号”
- “模板ID”

## 注意事项

此模板被修改后，签约此模板的用户数据也会被修改，修改后的数据在用户新注册时会下发到网络。

## 参数说明

| 参数标识          | 参数名称            | 参数说明                                                                                                                                                              |
|:--------------|:----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN         | HLR序列号          | 可选必选说明：必选参数 参数含义：标识5G QoS模板信息数据的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR上的5G QoS模板信息数据记录的参数进行修改，操作员可以使用LST HLRSN命令查询获得。 取值范围：1~255 默认值：无 配置原则：无                              |
| TPLID         | 模板ID            | 可选必选说明：必选参数 参数含义：标识5G QoS模板信息数据的关键字段之一（其取值不能被修改），用于指定需要对哪个5G QoS模板信息数据记录的参数进行修改，操作员可以使用LST NGCQOSTPL命令查询获得。 取值范围：1～2147483646 默认值：无 配置原则：无                        |
| TPLNAME       | 模板名             | 可选必选说明：可选参数 参数含义：用于标识待修改5G QoS模板在系统中的名称。 取值范围：1～60个字母或十进制数字组成的字符串。 默认值：无 配置原则：无                                                                                   |
| NGQI          | 5QI             | 可选必选说明：可选参数 参数含义：用于标识5G QoS特性的参数，是业务质量的索引，代表了资源类型、优先级、可靠性、丢包率等一组参数的取值集合，应用于所有的通路。定义了索引之后，核心网不需要传递全部参数，只传递索引值就可以将一组QoS信息通知无线侧，减少了网元间的参数传递。 取值范围：0～255 默认值：无 配置原则：无 |
| ARPPRILEVEL   | ARP优先级          | 可选必选说明：可选参数 参数含义：用于标识用户在网络资源拥塞时的优先级。运营商可以根据接入过程、业务保持过程等，分别设置用户的优先级。用户的优先级分为15个等级，数值越小，优先级越高。 取值范围：1～15 默认值：无 配置原则：无                                               |
| PREEMPTIONCAP | 是否允许抢占低优先级业务的资源 | 可选必选说明：可选参数 参数含义：用于标识是否允许该业务数据流占有优先级相对较低的业务数据流的资源。 取值范围：TRUE：允许FALSE：禁止 默认值：无 配置原则：无                                                                              |
| PREEMPTIONVUL | 是否允许资源被高优先级业务抢占 | 可选必选说明：可选参数 参数含义：用于标识是否允许业务数据流丢失分配给它的资源，用于接纳一个优先级相对较高的业务数据流。 取值范围：TRUE：允许FALSE：禁止 默认值：无 配置原则：无                                                                    |
| NGQIPRILEVEL  | 5QI优先级          | 可选必选说明：可选参数 参数含义：用于标识5QI优先级的参数，数值越小，优先级越高。 取值范围：1～127 默认值：无 配置原则：无                                                                                                |

## 使用实例

1. 修改5G QoS模板数据，“HLR序列号”为“1”，“模板ID”为“1”，“模板名”为“ngcqostpl”，“5QI”为“2”，“ARP优先级”为“1”，“是否允许抢占低优先级业务的资源”为“true”，“是否允许资源被高优先级业务抢占”为“TRUE”，“5QI优先级”为“1”：

   ```
   MOD NGCQOSTPL: HLRSN=1, TPLID=1, TPLNAME="ngcqostpl", NGQI=2, ARPPRILEVEL=1, PREEMPTIONCAP=TRUE, PREEMPTIONVUL=TRUE, NGQIPRILEVEL=1;
   ```
2. 修改5G QoS模板数据，“HLR序列号”为“1”，“模板ID”为“3”，“模板名”为“ngcqostpl”，“5QI”为“7”，“ARP优先级”为“3”，“是否允许抢占低优先级业务的资源”为“TRUE”，“是否允许资源被高优先级业务抢占”为“FALSE”：

   ```
   MOD NGCQOSTPL: HLRSN=1, TPLID=3, TPLNAME="ngcqostpl", NGQI=7, ARPPRILEVEL=3, PREEMPTIONCAP=TRUE, PREEMPTIONVUL=FALSE;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释     | 原因分析         | 处理建议                                                  |
|:--------|:----------|:-------------|:------------------------------------------------------|
| ERR3003 | 模板未定义     | “模板ID”未定义。   | 根据实际情况，重新输入已定义的“模板ID”，可通过LST NGCQOSTPL命令查询已定义的“模板ID”。 |
| ERR3097 | HLR序列号未定义 | “HLR序列号”未定义。 | 根据实际情况，重新输入已定义的“HLR序列号”，可通过LST HLRSN命令查询已定义的“HLR序列号”。 |
