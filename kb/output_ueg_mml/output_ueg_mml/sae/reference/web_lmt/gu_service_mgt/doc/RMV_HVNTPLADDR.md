# 删除拜访网络地址(RMV HVNTPLADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成用户注册失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在HSS的业务数据库中从已经存在的拜访网络模板中删除一个拜访网络地址。

## 注意事项

- 如果操作员在指定拜访网络模板中删除一条拜访网络地址，则所有引用该模板的用户都将删除这条拜访网络地址，可能导致用户注册失败，请操作员在执行该操作之前仔细确认任务的可行性。
- 拜访网络模板中必须至少保留一条拜访网络地址信息，如果不需要模板中存在拜访网络地址，操作员可以使用**RMV HVNTPL**命令将该模板删除。
- 一次只能删除指定拜访网络模板中的一条拜访网络地址。
- 对于有具体拜访网络地址的用户，如果要放开用户的漫游权限，使用本命令删除地址放开用户的漫游范围。
- 该命令不允许进行批操作。
- 当“HLR序列号”参数不输入时，默认删除“HLR序列号”为“0”的记录。

## 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                              |
|:--------|:---------|:----------------------------------------------------------------------------------|
| HLRSN   | HLR序列号   | 用于指定需要删除哪一个HLR序列号对应的拜访网络地址，操作员可以使用LST HTPLINF命令查询获得。 说明：可选参数                      |
| VNTPLID | 拜访网络模板ID | 标识一条拜访网络地址的关键字段之一，用于指定需要删除哪一个拜访网络模板中的拜访网络地址，操作员可以使用LST HTPLINF命令查询获得。 说明：必选参数。    |
| VN      | 拜访网络地址   | 标识一条拜访网络地址的关键字段之一，用于标识需要删除拜访网络模板中的哪一条拜访网络地址，操作员可以使用LST HVNTPLADDR命令查询获得。 说明：必选参数。 |

## 使用实例

删除拜访网络地址，“拜访网络模板ID”为“10”，“拜访网络地址”为“china.huawei.com”：

```
RMV HVNTPLADDR: VNTPLID=10, VN="china.huawei.com";
```
