# 修改UE级别EPS用户AMBR数据(MOD EPSAMBR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改EPS用户的AMBR数据。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。
- 如果用户不是EPS类型用户，执行此命令时：
  - 若参数“是否强制签约EPS业务”取值为“TRUE”，会强制开通EPS业务。
  - 若参数“是否强制签约EPS业务”取值为“FALSE”，返回ERR3810“用户不是EPS用户或未开户”。
- 如果用户不是EPS类型用户，执行此命令时：
  - “UE最大上行带宽”和“NR上行速率”两个参数必须且只能配置一个。
  - “UE最大下行带宽”和“NR下行速率”两个参数必须且只能配置一个。
- 如果用户是EPS类型用户，执行此命令时，“UE最大上行带宽”、“UE最大下行带宽”、“NR上行速率”和“NR下行速率”四个参数必须至少配置一个。

## 参数说明

| 参数标识            | 参数名称        | 参数说明                                                                                                                                                                                                                                                    |
|:----------------|:------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI            | IMSI        | 用于标识需要修改AMBR数据的EPS用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                              |
| ISDN            | MSISDN      | 用于标识需要修改AMBR数据的EPS用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                            |
| RECORDCOUNT     | 用户个数        | 用于标识需要修改AMBR数据的EPS用户数目。 当需要为连续号段的多个EPS用户修改AMBR数据时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个EPS用户修改AMBR数据。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个EPS用户修改AMBR数据，当只有一个用户时，该参数不必配置。当一次修改AMBR数据的用户个数很多时，对系统性能无影响，但修改AMBR数据的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。     |
| IMSIFILE        | IMSI文件名     | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要修改AMBR数据的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modepsambr.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                                     |
| ISDNFILE        | MSISDN文件名   | 用于标识MSISDN批操作文件。 MSISDN文件名称，ISDNFILE是由多个不连续的MSISDN号码组成的批操作文件，每个MSISDN号码占一行。 MSISDN批操作文件包含多个不连续的需要修改AMBR数据的EPS用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modepsambr.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。 |
| AMBRMAXUL       | UE最大上行带宽    | 用于标识UE最大上行带宽，即UE最大的上传速率。 取值范围：1～4294967295，单位为bit/s。 默认值：无。 说明：该参数与本命令中“NR上行速率”两个参数必须且只能配置一个。                                                                                                                                                           |
| AMBRMAXDL       | UE最大下行带宽    | 用于标识UE最大下行带宽，即UE最大的下载速率。 取值范围：1～4294967295，单位为bit/s。 默认值：无。 说明：该参数与本命令中“NR下行速率”两个参数必须且只能配置一个。                                                                                                                                                           |
| FORCETOBEEPSSUB | 是否强制签约EPS业务 | 用于标识在修改AMBR数据时，UDM是否给用户强制签约EPS业务。 取值范围：TRUE：强制签约EPS业务。FALSE：不强制签约EPS业务。 默认值：TRUE                                                                                                                                                                        |
| AMBRNRUL        | NR上行速率      | 用于标识5G网络UE最大上行带宽，即UE最大的上传速率。 取值范围：1～4294967295，单位为kbit/s（1kbit/s = 1000bit/s） 默认值：无。 说明：该参数与本命令中“UE最大上行带宽”两个参数必须且只能配置一个。如果上行速率配置该参数，则“UE最大上行带宽”参数由系统赋值为“4294967295”。                                                                                    |
| AMBRNRDL        | NR下行速率      | 用于标识5G网络UE最大下行带宽，即UE最大的下载速率。 取值范围：1～4294967295，单位为kbit/s（1kbit/s = 1000bit/s） 默认值：无。 说明：该参数与本命令中“UE最大下行带宽”两个参数必须且只能配置一个。如果下行速率配置该参数，则“UE最大下行带宽”参数由系统赋值为“4294967295”。                                                                                    |

## 使用实例

1. 修改“IMSI”号码为“460000009123456”的“UE最大上行带宽”为“100000” ，“UE最大下行带宽”为“200000 ”：

   `MOD EPSAMBR: IMSI="460000009123456", AMBRMAXUL=100000, AMBRMAXDL=200000;`
2. 批量修改用户的“AMBR”：
   1. 编写ISDNFILE批操作文件。
      - 文件名为“ISDN.txt”。
      - 文件格式：
        - 380561234561
        - 380561234562
        - 380561234563
        - 380561234564
   2. 通过Web UI上的文件选项将ISDNFILE批操作文件上传到指定位置。
   3. 批量修改用户的“UE最大上行带宽”为“500000”，“UE最大下行带宽”为“1000000”，：

      `MOD EPSAMBR: ISDNFILE="ISDN.txt", AMBRMAXUL=500000, AMBRMAXDL=1000000;`
