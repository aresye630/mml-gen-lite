# 增加VT-CSI模板(ADD VTCSITPL)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

该命令用于为HLR在配置数据库中增加一条VT-CSI（VMSC Terminating CAMEL Subscription Information）模板数据记录，根据运营商CAMEL网络的实际情况进行配置，相关参数由运营商提供。用户通过签约VT-CSI模板ID签约VT-CSI业务。

VT-CSI是VMSC被叫CAMEL签约信息，当用户签约VT-CSI业务或进行位置更新流程时，HLR通过插入用户数据消息将VT-CSI数据下发给MSC/VLR。当移动用户在VMSC做被叫时，VT-CSI智能业务将被触发，按照用户签约的VT-CSI模板中的信息进行业务逻辑处理。

## 注意事项

- 该命令只能给一个模板增加一个DP值的触发准则，如果需要增加多个DP值的触发准则，请执行**MOD VTCSITPL**命令。
- 系统中增加的VT-CSI模板记录数不能超过5000条。

## 使用实例

增加VT-CSI模板数据记录，“HLR序列号”为“1”，“模板ID”为“2”，“模板名”为“VTCSITPL”，“CAMEL业务处理能力”为“PHASE3”，“VLR不支持CAMEL时的处理方式”为“RR”，“DP值”为“8613911111”，“业务键”为“12”，“缺省呼叫处理”为“continueCall”：

```
ADD VTCSITPL: HLRSN=1, TPLID=2, TPLNAME="VTCSITPL", CAMEL=PHASE3, USHNDL=RR, DP=TAA, GSMSCFADD="8613911111", SK=12, DEFCALL=continueCall;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|:--------|:--------|:------------------------------|:------------------------------------------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | “HLR序列号”未定义。                  | 根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求。                                                                                                   |
| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”参数不在相应的参数取值范围内。 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                    |
| ERR3004 | 模板已存在   | 本次操作输入的“模板ID”在数据库中已存在。        | 根据实际情况，重新输入参数，确保输入的“模板ID”和系统中已存在的不重复。可执行LST VTCSITPL命令查询系统中已存在的VT-CSI模板。                                                            |
| ERR3047 | 超过最大限制  | 增加的VT-CSI模板记录数超过5000条。        | 根据实际情况，如需增加VT-CSI模板，处理步骤如下：执行LST VTCSITPL命令，查询已存在的VT-CSI模板。执行RMV VTCSITPL命令，删除不必要的VT-CSI模板。执行该命令增加VT-CSI模板，确保增加的VT-CSI模板记录数在规定范围之内。 |
