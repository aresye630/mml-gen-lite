# 增加MSISDN与区号数据(ADD ISDNARC)

- 命令功能
- 注意事项

## 命令功能

**须知** 

本命令属于高危命令，执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在HLR中增加一条MSISDN与区号数据记录。MSISDN与区号数据记录是用来进行号码规整时，取得前转号码所属的地区码。

- 在前转号码登记时首先查询数据库中的MSISDN与区号数据记录确定前转号码所属地区，在号码规整时与**SET MAPSERV**命令中的“前转地区限制”参数配合使用，控制用户的前转号码登记。当**SET MAPSERV**命令中的“前转地区限制”参数取值为“FWDREGDSAMEAREA”（只能登记相同地区的前转号码）时，需要将通过IMSI与区号数据记录获取的待登记用户的地区码，和MSISDN与区号数据记录获取的前转号码的地区码进行比较，两个地区码相同时，才允许登记，否则不允许。
- 增加MSISDN与区号数据的对应关系为可选配置。如果**SET MAPSERV**命令中的参数“前转地区限制”设为“NORESTRICTION”时，可以不执行该命令增加MSISDN与区号数据的对应关系。
- 在开局配置本局数据时需要将该HLR中使用的MSISDN前缀和对应的区号全部添加到配置数据库。

## 注意事项

同一个“HLR序列号”中增加的MSISDN前缀和对应的区号记录数不能超过3000条。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                                  |
|:-----------|:---------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN      | HLR序列号   | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                          |
| ISDNPREFIX | MSISDN前缀 | 用于标识待增加MSISDN与区号数据记录对应的国内移动号码前缀。 该参数支持最大匹配原则，输入的内容可以是完整的MSISDN，也可以是MSISDN的前缀。最大匹配原则是指在查询时对于一个具体的号码而言，系统将在所有的记录中查找与其号码最相近的一个。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 说明：MSISDN前缀不带国家码。例：138755。 |
| AREACODE   | 区号       | 用于标识各地区电话号码的区号，与执行ADD DAREA命令增加的国内长途区号数据记录对应。 取值范围：1～6位十进制数字组成的字符串。 默认值：无。                                                                                                            |

## 使用实例

1. 在“HLR序列号”为“1”的HLR上增加MSISDN与区号数据。其中，“MSISDN前缀”为“1380270”，“区号”为“755”：

   ```
   ADD ISDNARC: HLRSN=1, ISDNPREFIX="1380270", AREACODE="755";
   ```
2. 在“HLR序列号”为“1”的HLR上增加MSISDN与区号数据。其中，“MSISDN前缀”为“1380271”，“区号”为“10”：

   ```
   ADD ISDNARC: HLRSN=1, ISDNPREFIX="1380271", AREACODE="10";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                         | 处理建议                                                                                                                                                                |
|:--------|:--------|:---------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | “HLR序列号”未定义。                                 | 根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求。                                                                                                                                   |
| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”参数不在相应的参数取值范围内。                | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                                                    |
| ERR1111 | 超过最大限制  | 同一个“HLR序列号”中增加的“MSISDN前缀”和对应的“区号”记录数超过3000条。 | 根据实际情况，如需增加MSISDN前缀和对应的区号，处理步骤如下：执行LST ISDNARC命令，查询已存在的MSISDN前缀和对应的区号记录。执行RMV ISDNARC命令，删除不必要的MSISDN前缀和对应的区号记录。执行该命令增加MSISDN前缀和对应的区号，确保增加的MSISDN前缀和对应的区号记录数在规定范围之内。 |
| ERR3006 | 记录已存在   | 本次操作输入的“MSISDN前缀”和“区号”对应的数据记录在数据库中已存在。       | 根据实际情况，重新输入参数，确保输入的“MSISDN前缀”和“区号”与系统中已存在的不重复。可执行LST ISDNARC命令查询系统中已存在的MSISDN与区号数据。                                                                                 |
