# 删除增强VLR/SGSN漫游限制(RMV ERR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行不当会导致用户漫游限制数据被删除，因此执行该命令前，需要与华为技术支持确认后才可以实施。

此操作用于删除已设置HLR的增强用户VLR/SGSN漫游限制状态的VLR/SGSN号码。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称         | 参数说明                                     |
|:----------|:-------------|:-----------------------------------------|
| HLRSN     | HLR序列号       | HLR序列号，有效值域为1～255，在PGW支持容灾功能或虚拟HLR功能时设置。 |
| VLRSGSNNO | VLR/SGSN号码前缀 | VLR或SGSN号码前缀，E.164格式的编码，为1～6位的十进制数字。     |

## 使用实例

删除已设置HLR的增强用户VLR/SGSN漫游限制状态的VLR/SGSN号码前缀，其中HLRSN=1，VLRSGSNNO=861380，命令如下：

RMV ERR: HLRSN=1, VLRSGSNNO="861380";
