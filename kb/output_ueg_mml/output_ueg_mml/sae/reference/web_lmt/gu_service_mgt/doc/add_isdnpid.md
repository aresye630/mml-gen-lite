# 增加MSISDN与云分区数据(ADD ISDNPID)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中增加一条MSISDN号段与云分区的映射关系数据记录。

## 注意事项

- 系统中增加的MSISDN号段与云分区的映射关系数据记录数和通过执行**ADD IMSIPID**命令增加的IMSI号段与云分区的映射关系数据记录数总共不能超过20000条。
- 在Global-Local组网下，当本端“partition角色”是“vRouting\_Service”时，不允许设置“分区ID”为本partition的云分区编号。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                      |
|:---------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------|
| ISDNPRFX | MSISDN号段 | 用于标识与云分区建立映射关系的MSISDN号段。该参数的配置与运营商的网络规划和运营策略有关，配置前需要与运营商确认。 取值范围：1～15位的十进制数字组成的字符串。 默认值：无。 说明：该参数的取值不能与ADD IMSIPID命令已经设置的“IMSI号段”参数的取值相同。 |
| PID      | 分区ID     | 用于标识云分区编号。该参数必须由“USCDB MML命令”界面下“SET PARTITION”定义，然后才能在此处引用。 取值范围：1～250 默认值：无。                                                            |

## 使用实例

增加MSISDN与云分区数据的映射关系数据记录，“MSISDN号段”为“86139”，“分区ID”为“7”：

```
ADD ISDNPID: ISDNPRFX="86139", PID=7;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释           | 原因分析                                                                                                                                | 处理建议                                                                                                                                                                                                                                      |
|:--------|:----------------|:------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3047 | 超过最大限制          | 增加的MSISDN号段与云分区的映射关系数据记录数和通过执行ADD IMSIPID命令增加的IMSI号段与云分区的映射关系数据记录数总共超过20000条。                                                       | 根据实际情况，如需增加MSISDN号段与云分区的映射关系数据记录，处理步骤如下：执行LST ISDNPID和LST IMSIPID命令，查询已存在的映射关系数据记录。执行RMV ISDNPID或RMV IMSIPID命令，删除不必要的映射关系数据记录。执行该命令增加MSISDN号段与云分区的映射关系数据记录，确保增加的MSISDN号段与云分区的映射关系数据记录数和通过执行ADD IMSIPID命令增加的IMSI号段与云分区的映射关系数据记录数总和在规定范围之内。 |
| ERR4068 | Partition ID 无效 | 当本端“partition角色”是“vRouting_Service”时，输入的“分区ID”与已配置的本端“Partition标识”重复。当本端“partition角色”是“vService”时，输入的“分区ID”与已配置的本端“Partition标识”不重复。 | 通过在“USCDB MML命令”窗口执行LST PARTITION命令查询本端已配置的Partition信息： 当本端“partition角色”是“vRouting_Service”时，重新执行该命令，确保本次输入的“分区ID”与已配置的本端“Partition标识”不相同。当本端“partition角色”是“vService”时，重新执行该命令，确保本次输入的“分区ID”与已配置的本端“Partition标识”相同。                       |
