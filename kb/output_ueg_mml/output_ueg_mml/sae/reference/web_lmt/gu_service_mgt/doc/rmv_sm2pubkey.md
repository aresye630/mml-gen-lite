# 删除SM2公钥（RMV SM2PUBKEY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除已配置的SM2公钥记录。

## 注意事项

本命令为局点定制命令，非定制局点使用前请务必先联系华为技术支持。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                         |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 可选必选说明：必选参数 参数含义：标识国密SM2公钥记录的关键字段之一，用于指定删除哪个HLR上的国密SM2公钥记录，操作员可以使用LST HLRSN命令查询获得。 取值范围：1~255 默认值：无。 配置原则：无。 |
| KEYSNO | 密钥序列号  | 可选必选说明：必选参数 参数含义：用于标识系统按照哪个密钥序列号来删除国密SM2公钥。 取值范围：1～65535 默认值：无。 配置原则：无。                                      |

## 使用实例

删除“HLR序列号”为“1”，“密钥序列号”为“2”的国密SM2公钥记录：

```
RMV SM2PUBKEY: HLRSN=1, KEYSNO=2;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析             | 处理建议                                                        |
|:--------|:--------|:-----------------|:------------------------------------------------------------|
| ERR3007 | 记录不存在   | 待删除的国密SM2公钥记录不在。 | 执行LST SM2PUBKEY命令查询已生成的国密SM2公钥记录，根据实际情况，输入已存在的记录后重新执行本命令删除。 |
