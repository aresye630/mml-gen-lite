# 校验K7(CHK K7)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于校验K7密钥，以检查已添加的K7密钥是否正确。

## 注意事项

K7的密钥输入方式选择“HSM\_MBK”时，该命令不适用。系统会每10s检测PGW输入的K7的HASH值和HSM(Hardware Security Machine)上的MBK(Master Backup Key)的HASH值是否一致，如果不一致，则系统上报告警。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                               |
|:--------|:-------|:-----------------------------------------------------------------------------------|
| HLRSN   | HLR序列号 | 用于标识本地HLR。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                          |
| K7SNO   | K7序列号  | 用于标识校验的K7密钥的序列号。 取值范围：1～10。 默认值：无。                                                 |
| K7VALUE | K7值    | 用于标识校验的K7密钥值。 取值范围：32位或64位的十六进制数字组成的字符串。 默认值：无。                                    |
| ALGTYPE | 算法类型   | 标识K7值的加密算法类型。 AES128：K7值为32位的十六进制数字组成的字符串。AES256：K7值为64位的十六进制数字组成的字符串。 默认值：AES128。 |

## 使用实例

在HSS/HLR中校验“HLR序列号”为“1”，“K7序列号”为“2”，“K7值”为“ABCDEF1234567890ABCDEF1234567890”的K7密钥：

```
CHK K7: HLRSN=1, K7SNO=2, K7VALUE="*****";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释              | 原因分析                                                                                      | 处理建议                                 |
|:--------|:-------------------|:------------------------------------------------------------------------------------------|:-------------------------------------|
| ERR3098 | 验证的数据与HLR数据库的数据不相同 | 填写的K7值算法类型与HLR数据库保存的K7值算法类型不一致。填写的K7值算法类型与HLR数据库保存的K7值算法类型一致但经过算法加密后的K7值与HLR数据库保存的K7值不一致。 | 根据K7值的位数选择正确的算法类型。根据实际情况，重新输入正确的K7值。 |
| ERR4133 | 密钥丢失               | 当SET MAPSERV命令中的“随机密钥默认ID”参数为非0，“随机密钥默认ID”参数对应的随机密钥材料不存在或不完整。                             | 联系华为技术支持处理。                          |
