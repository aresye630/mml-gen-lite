# 增加共享iFC模板(ADD HSIFCTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于在HSS的业务数据库中添加一个共享iFC模板。

iFC指初始过滤规则，是一种业务触发原则，描述了能够提供给用户的应用签约信息，作为用户配置存储在HSS中，并且在用户注册时可以下载到S-CSCF。

共享iFC是指一组被多个service profile共享的iFC的集合。在HSS和S-CSCF的数据库中都保存一份相同的共享iFC数据，数据的内容包括共享iFC的内容和对应的“共享iFC模板ID”。S-CSCF仅向HSS下载“共享iFC模板ID”，并根据“共享iFC模板ID”从本地数据库中取到具体的iFC内容。 运营商可以通过共享iFC来避免S-CSCF从HSS下载并存储冗余的iFC数据，从而减少Cx接口流量负载，节省S-CSCF和HSS存储空间，提高S-CSCF的系统性能。有助于运营商降低设备成本。

因此，当多个service profile有相同的iFC时，操作员可以使用**ADD HSIFCTPL**命令增加共享iFC模板之后，执行**ADD HSIFC**命令，设置此共享iFC模板与用户IMPU的对应关系，以对用户的业务触发原则进行管理。

## 注意事项

- 当使用该命令添加共享iFC模板后，必须使用**ADD HSIFCINF**命令为指定的共享iFC模板添加iFC信息。
- 系统中增加的共享iFC模板记录数不能超过5000条。

## 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                                                               |
|:--------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------|
| HLRSN   | HLR序列号    | 用于标识一个HLR序列号。 取值范围：0~255 默认值：无。 说明： 可选参数当该参数不输入时，系统默认初始设置值为0。                                                                      |
| TPLID   | 共享iFC模板ID | 用于定义一个新的共享iFC模板索引，系统可以通过该索引找到新增的共享iFC模板。 该参数的配置原则是： 同一“HLR序列号”的共享iFC模板ID唯一。已有模板ID可以使用LST HTPLINF命令获得。 取值范围：0～65535 默认值：无。 说明：必选参数。 |
| TPLNAME | 共享iFC模板名称 | 用于具体描述一个共享iFC模板，以便于识别。 取值范围：长度不超过64的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 说明：可选参数。                                                   |
| COMMENT | 模板注释说明    | 用于具体描述一个共享iFC模板的注释信息，以便于理解和使用。 取值范围：长度不超过512的字符串 默认值：无。 说明：可选参数。                                                                   |

## 使用实例

增加共享iFC模板，“共享iFC模板ID”为“10”，“共享iFC模板名称”为“SiFC Template”，“模板注释说明”为“SiFC Template”：

```
ADD HSIFCTPL: TPLID=10, TPLNAME="SiFC Template", COMMENT="SiFC Template";
```
