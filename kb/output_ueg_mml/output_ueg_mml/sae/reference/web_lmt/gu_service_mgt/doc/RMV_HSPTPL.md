# 删除Service Profile信息模板(RMV HSPTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中删除一个Service Profile基本信息模板。

## 注意事项

当“HLR序列号”参数不输入时，默认删除“HLR序列号”为“0”的记录。

## 参数说明

| 参数标识   | 参数名称                | 参数说明                                                                                                           |
|:-------|:--------------------|:---------------------------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号              | 可选必选说明：可选参数 参数含义：用于指定需要删除哪一个HLR序列号的Service Profile基本信息模板记录，操作员可以使用LST HTPLINF操作查询获得。                           |
| TPLID  | Service Profile模板ID | 可选必选说明：必选参数 参数含义：标识一个Service Profile基本信息模板记录的关键字段，用于指定需要删除哪一个Service Profile基本信息模板记录，操作员可以使用LST HTPLINF操作查询获得。 |

## 使用实例

删除Service Profile信息模板。Service Profile模板ID：10。

```
RMV HSPTPL: TPLID=10;
```
