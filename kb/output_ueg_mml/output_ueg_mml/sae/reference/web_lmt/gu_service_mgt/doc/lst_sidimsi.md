# 查询SID与IMSI对应关系(LST SIDIMSI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询现网用户的SID（Subscriber ID）与IMSI对应关系。为了方便维护工作，该命令提供SID和IMSI互查功能：

- 输入“SID”时，查询SID匹配的IMSI信息。
- 输入“IMSI”时，查询IMSI匹配的SID信息。

## 注意事项

参数“SID”和“IMSI”必须输入且只能输入一个。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                         |
|:-------|:-------|:---------------------------------------------|
| SID    | SID    | 用于标识用户的SID。 取值范围：16位十六进制数字组成的字符串。 默认值：无。     |
| IMSI   | IMSI   | 用于标识用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 |

## 使用实例

1. 查询“SID”为“1e000b174a590004”匹配的IMSI信息:

   ```
   LST SIDIMSI: SID="1e000b174a590004";
   ```

   ```
   %%LST SIDIMSI: SID="1e000b174a590004";%%
   RETCODE = 0 SUCCESS0001:Operation is successful

       IMSI = 46000249999

   Total count = 1

   There is together 1 report

   ---    END
   ```
2. 查询“IMSI”为“46000249999”匹配的SID信息:

   ```
   LST SIDIMSI: IMSI="46000249999";
   ```

   ```
   %%LST SIDIMSI: IMSI="46000249999";%%
   RETCODE = 0 SUCCESS0001:Operation is successful

        SID = 1e000b174a590004

   Total count = 1

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，参数含义请参见参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                              | 处理建议                                         |
|:--------|:--------|:--------------------------------------------------------------------------------------------------|:---------------------------------------------|
| ERR1004 | 无效的参数值  | 原因为如下情形中的一种：参数“SID”的取值中含有0～f以外的字符。参数“IMSI”的取值中含有0～9以外的字符。参数“IMSI”的取值长度小于6个字符。参数“SID”的取值长度小于16个字符。 | 根据实际情况，重新输入参数“SID”和“IMSI”的取值，确保其取值符合取值范围的要求。 |
| ERR1009 | 参数丢失    | 参数“SID”和“IMSI”都没有输入。                                                                              | 参数“SID”和“IMSI”必须输入且只能输入一个，请重新输入。             |
| ERR1010 | 参数冲突    | 参数“SID”和“IMSI”同时输入。                                                                               | 参数“SID”和“IMSI”必须输入且只能输入一个，请重新输入。             |
| ERR3001 | 用户未开户   | 原因为如下情形中的一种：参数“SID”不存在。参数“IMSI”不存在。                                                               | 请检查输入的参数值是否正确，然后重新输入。                        |
