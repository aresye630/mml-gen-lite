# 修改LU-CSI模板(MOD LUCSITPL)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使签约此模板的用户数据被同步修改，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一条LU-CSI（Location Upgrade Services CAMEL Subscription Information）模板数据记录的某些参数进行修改或调整，同时还用于为一条LU-CSI模板数据记录增加多条触发准则。在该命令中，系统通过以下关键参数的组合来唯一标识一条LU-CSI模板数据记录：

- “HLR序列号”
- “模板ID”

## 注意事项

- 当用户进行位置更新或触发其他涉及LU-CSI模板的流程时，系统会根据用户签约的LU-CSI模板ID下发模板中的数据，修改模板数据会使签约此模板的用户数据被同步修改，会影响在网用户，因此现网执行修改模板操作时需要慎重。
- “模板名”和“操作类型”参数至少输入一个。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:-----------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN      | HLR序列号 | 标识一条LU-CSI模板数据记录的关键字段之一（其取值不能被修改），用于标识需要对哪一条LU-CSI模板数据记录的参数进行修改或调整，操作员可以使用LST HLRSN命令查询获得。                                                                                                                                                                                                                                                                                                                                                                                                                |
| TPLID      | 模板ID   | 标识一条LU-CSI模板数据记录的关键字段之一（其取值不能被修改），用于标识需要对哪一条LU-CSI模板数据记录的参数进行修改或调整，操作员可以使用LST LUCSITPL命令查询获得。                                                                                                                                                                                                                                                                                                                                                                                                             |
| TPLNAME    | 模板名    | 用于标识待修改模板在系统中的名称。 取值范围：1～60位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| PROV       | 操作类型   | 用于标识对模板的操作类型。如果待修改模板中只设置了一个DP值，该参数不能设置为RMV_DP。 取值范围：ADD_DP：给模板新增一个DP类型数据。MOD_DP：修改模板中已经存在的DP业务数据，当设置为该枚举值时，必须至少输入“SCP地址”、“业务键”、“处理类型”参数其中一个。RMV_DP：删除模板中存在的DP类型。 默认值：无。                                                                                                                                                                                                                                                                                                                                   |
| DP         | DP类型   | 仅当本命令中的“操作类型”参数为“ADD_DP”、“RMV_DP”或“MOD_DP”时该参数有效。用于标识触发LU-CSI业务的检出点，当在检出点满足相应的DP触发准则时，就会触发相应的CAMEL业务。 用户进行位置更新时HLR是否下发该DP值相关数据给VLR取决于该VLR是否支持DP3或DP4，可以通过执行LST VLRTYP命令查看该VLR是否签约NCC模板，如果未签约，则默认不支持。如果已签约，则执行LST NCCTPL命令查看“LU是否支持DP3”参数是否为“SR”（LU-CSI中的DP3数据下发到VLR）和“LU是否支持DP4”参数是否为“SR”（LU-CSI中的DP4数据下发到VLR）。 取值范围：DP3：由MSC触发INAP（Intelligent Network Application Part）消息到智能网络DP4：由HLR触发INAP消息到智能网络 默认值：无。                                                                                              |
| SCPADDR    | SCP地址  | 仅当本命令中的“操作类型”参数为“ADD_DP”或“MOD_DP”时该参数有效。用于标识接入gsmSCF（GSM Service Control Function）功能实体的地址。 取值范围：1～15位十进制数字组成的字符串。 采用E.164编码方式，编码格式为：CC+NDC+LSP，例如，一个典型的“SCP地址”为：“86-139-00777”。各关键字段的含义是： CC（Country Code）：国家码，即SCP所处国家在国际PSTN编号计划中的国家码，它由ITU-T在全球范围内统一分配，其最大长度为3位。例如，中国的国家码为86、英国的国家码为44等。NDC（National Destination Code）：国内目的码，即移动业务接入码，它是由本国电信主管部门在本国范围内统一分配的PLMN网络号，其最大长度为3位。例如，某运营商使用的PLMN网络号为134～139。LSP（Locally Significant Part）：本地有效部分，它是由某个运营商在本PLMN网络运营范围内统一分配的、用于具体代表某个SCP的号码，其最大长度为9位。 默认值：无。 |
| SKEY       | 业务键    | 仅当本命令中的“操作类型”参数为“ADD_DP”或“MOD_DP”时该参数有效。用于标识用户在gsmSCF中签约的CAMEL业务。gsmSSF（GSM Service Switching Function）将业务键发给gsmSCF后，gsmSCF根据该业务键执行对应的业务逻辑。业务键是HLR与SCP的对接参数之一，用于在CAP/INAP消息中唯一标识一种智能业务，它是一种号码资源，需要由运营商向本国的电信主管部门申请获得。 取值范围：0～2147483647 默认值：无。                                                                                                                                                                                                                                                            |
| TRANS_TYPE | 处理类型   | 仅当本命令中的“操作类型”参数为“ADD_DP”或“MOD_DP”并且“DP类型”参数为“DP3”时该参数有效。用于标识系统在何时触发LU-CSI业务。 取值范围：L(normal-location-update)：正常位置更新时触发A(IMSI-attach)：IMSI附着时触发P(periodic-location-update)：周期性位置更新时触发 默认值：无。 说明：用户可以修改多个DP触发准则，并用“&”连接，例如L-1&A-1&P-1。参数复选框中的灰化表示不修改系统原有值。                                                                                                                                                                                                                                                   |

## 使用实例

1. 修改“HLR序列号”为“1”的HLR上的LU-CSI模板数据记录，给“模板ID”为“2”的模板新增一个DP值。其中，“DP类型”为“DP4”，“SCP地址”为“8613759”，“业务键”为“12”：

   ```
   MOD LUCSITPL: HLRSN=1, TPLID=2, PROV=ADD_DP, DP=DP4, SCPADDR="8613759", SKEY=12;
   ```
2. 修改“HLR序列号”为“1”的HLR上的LU-CSI模板数据记录。其中，“模板ID”为“2”、“DP”为“D3”中的SCP地址为“8613759”，业务键为“22”，处理类型为“L-0”：

   ```
   MOD LUCSITPL: HLRSN=1, TPLID=2, PROV=MOD_DP, DP=DP3, SCPADDR="8613759", SKEY=22, TRANS_TYPE=L-0;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                 | 处理建议                                                         |
|:--------|:--------|:-------------------------------------|:-------------------------------------------------------------|
| ERR3003 | 模板未定义   | “HLR序列号”和“模板ID”对应的LU-CSI模板数据记录不存在。   | 使用LST LUCSITPL命令查询后，重新确认要修改哪个“HLR序列号”和“模板ID”对应的LU-CSI模板数据记录。 |
| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”和“模板ID”参数不在相应的参数取值范围内。 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                             |
