# 删除支持一卡多号的VLR信息(RMV OCMNVLR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会影响用户的号码资费业务，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除虚拟HLR上的VLR号码前缀和MSISDN号码前缀的对应关系信息记录。

## 注意事项

删除VLR号码前缀和MSISDN号码前缀的对应关系信息记录会影响用户的号码资费，删除前请操作员谨慎考虑。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                 |
|:-----------|:---------|:-------------------------------------------------------------------------------------|
| HLRSN      | HLR序列号   | 标识VLR号码前缀和MSISDN号码前缀对应关系的关键字段之一，用于指定需要删除哪个虚拟HLR上的对应关系信息记录，操作员可以使用LST HLRSN命令查询获得。    |
| VLRPREFIX  | VLR号码前缀  | 标识VLR号码前缀和MSISDN号码前缀对应关系的关键字段之一，用于指定需要删除哪个VLR号码前缀的对应关系信息记录，操作员可以使用LST OCMNVLR命令查询获得。 |
| ISDNPREFIX | ISDN号码前缀 | 用于标识需要删除哪个ISDN号码前缀的对应关系信息记录，操作员可以使用LST OCMNVLR命令查询获得。                                |

## 使用实例

删除“HLR序列号”为“1”的虚拟HLR上的对应关系信息记录，“VLR号码前缀”参数取值为“8866”，命令如下：

```
RMV OCMNVLR: HLRSN=1, VLRPREFIX="8866";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                              | 处理建议                                            |
|:--------|:--------|:----------------------------------|:------------------------------------------------|
| ERR3007 | 记录不存在   | 输入的参数对应的数据记录未在系统中添加。              | 请先使用LST OCMNVLR命令查询已添加的记录信息，然后再根据需要执行该命令进行删除操作。 |
| ERR1004 | 无效的参数值  | 输入的“VLR号码前缀”或“ISDN号码前缀”参数不在取值范围内。 | 请参考ADD OCMNVLR命令中参数的取值范围进行输入。                   |
