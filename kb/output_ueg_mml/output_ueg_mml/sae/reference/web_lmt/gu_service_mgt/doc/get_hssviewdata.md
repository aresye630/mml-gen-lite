# 获取HSS订阅数据(GET HSSVIEWDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于当UDM中现网用户的签约信息、位置信息、终端信息以及基站的配置信息发生变化时，系统会自动触发该命令，通过用户的SID（Subscriber ID）获取到这些变更的数据，并通过SOAP接口发送给DSP（Dynamic Subscriber Profile），DSP在符合当地法律法规和安全规定的前提下，将这些数据共享到第三方应用进行数据分析和挖掘，开展增值服务。

## 注意事项

该命令仅限于在系统内部调用使用，请勿手动执行，如果需要执行，请先联系华为技术支持。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                |
|:-------|:-------|:------------------------------------------------------------------------------------|
| SID    | SID    | 用于标识订阅数据的用户ID，指系统在新用户开户时根据站点编号、局点编号以及其他信息自动生成的用户唯一标识。 取值范围：6～16位十进制数字组成的字符串。 默认值：无。 |

## 使用实例

手动执行命令，获取“SID”为“1111111111111111”的订阅数据：

```
GET HSSVIEWDATA: SID="1111111111111111";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析             | 处理建议                             |
|:--------|:--------|:-----------------|:---------------------------------|
| ERR1004 | 无效的参数值  | 输入的参数取值不在其取值范围内。 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。 |
