# 设置国家分组中运营商的漫游比例(SET ROAMPER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于配置国家分组中运营商的漫游比例，支持国家分组中运营商漫游比例的增加，修改和删除。

## 注意事项

- 该命令只可以配置非本国网络。
- 调整运营商名称或漫游比例后会导致实际设置的漫游比例与统计结果在一段时间内不一致，导致用户使用**LST ROAMNUM**命令查询的漫游用户数不准确。恢复一致的速度取决于当前漫游用户数和用户活跃度。
- 漫游比例为0表示用户在需要位置更新时不进行优选网络比例判断，直接允许。
- 同一分组下所有配置了的运营商漫游比例总和必须小于或等于100。
- 当需要位置更新的用户连续N次由于优选网络问题导致位置更新失败，则第N+1次不再因优选网络拒绝用户位置更新。

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表3所示。

| 错误码             | 错误码解释             | 原因分析                                     | 处理建议                                                                    |
|:----------------|:------------------|:-----------------------------------------|:------------------------------------------------------------------------|
