# 删除操作员号段权限(RMV OPRANGE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令属于高危命令，删除操作员号段权限会造成操作员无权限操作号段。因此执行该命令前，请仔细评估当前操作员权限，确认对业务发放系统没有影响后方可执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用来删除指定操作员所能操作的号段组范围。

## 注意事项

- 操作员的级别为ADMINISTRATOR或操作员被赋给该命令权限时，才具有删除的权限。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                   |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------|
| OPNAME | 操作员名称  | 标识操作员数据记录的唯一关键字段，用于指定需要删除哪个操作员的数据记录，操作员可以使用LST OPR命令查询获得。 说明：LST OPR命令是系统管理类型的命令，需要在“MML导航树”下拉框中选择“系统管理”，才可以在MML界面中执行。 |

## 使用实例

删除操作员号段权限，“操作员名称”为“opr1”：

```
RMV OPRANGE: OPNAME="opr1";
```
