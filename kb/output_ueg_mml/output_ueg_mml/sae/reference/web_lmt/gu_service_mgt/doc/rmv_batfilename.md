# 删除自动批操作文件名称(RMV BATFILENAME)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除自动批操作文件名称的配置记录。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称     | 参数说明                                                                        |
|:----------|:---------|:----------------------------------------------------------------------------|
| BATPREFIX | 批操作文件名前缀 | 标识一个自动批操作文件名称前缀的关键字段。用于指定需要对哪一个“批操作文件名前缀”进行删除，操作员可以使用LST BATFILENAME命令查询获得。 |

## 使用实例

删除系统中“批操作文件名前缀”为“bat1”的批操作文件名数据记录。

```
RMV BATFILENAME: BATPREFIX="Bat1";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 消息解释   | 原因分析           | 处理建议                                              |
|:--------|:-------|:---------------|:--------------------------------------------------|
| ERR3007 | 记录不存在  | “批操作文件名前缀”未定义。 | 先执行LST BATFILENAME命令查询，重新确认要删除哪个“批操作文件名前缀”再执行该命令。 |
