# 删除平台地址配置(RMV ADSUADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用于删除ADSU平台地址配置。

## 注意事项

参数ECATEGORY必选。

## 参数说明

| 参数标识      | 参数名称   | 参数说明               |
|:----------|:-------|:-------------------|
| ECATEGORY | 增强用户类别 | 增强用户类别。取值范围为1～254。 |

## 使用实例

在［ADSU平台地址配置表］中删除一条记录，增强用户类别为120。例如：

RMV ADSUADDR: ECATEGORY=120;
