# 增加国内长途区号(ADD DAREA)

## 命令功能

**须知** 

本命令属于高危命令，执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在HLR中增加一条国内长途区号数据记录。

在开局配置本局数据时需要将每个“HLR序列号”管辖的所有国内长途区号全部添加到配置数据库，通常配置一个国家内允许前转的所有区号，用于在业务处理过程中对号码进行分析并按相应的逻辑流程进行处理。例如，当手机登记前转业务时，系统会对登记的前转号码进行号码规整，在号码规整过程中系统会在配置数据库中查找国内长途区号数据记录，如果查找不到相应的数据记录，登记将会失败。

## 注意事项

同一个“HLR序列号”中增加的国内长途区号数据记录数不能超过1000条。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                       |
|:---------|:-------|:---------------------------------------------------------------------------|
| HLRSN    | HLR序列号 | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                               |
| AREACODE | 国内长途区号 | 用于标识国内长途区号。 取值范围：1～6位十进制数字组成的字符串。 默认值：无。 配置原则：在配置国内长途区号时，不能在其前面加国内长途字冠“0”。 |
| CNAME    | 国内地区名称 | 用于标识国内地区名称。 取值范围：由不超过30位字符组成的字符串。 默认值：无。                                   |

## 使用实例

1. 在“HLR序列号”为“1”的HLR上增加国内长途区号。其中，“国内长途区号”为“755”，“国内地区名称”为“Shenzhen”：

   ```
   ADD DAREA: HLRSN=1, AREACODE="755", CNAME="Shenzhen";
   ```
2. 在“HLR序列号”为“1”的HLR上增加国内长途区号。其中，“国内长途区号”为“10”，“国内地区名称”为“Beijing”：

   ```
   ADD DAREA: HLRSN=1, AREACODE="10", CNAME="Beijing";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                          | 处理建议                                                                                                                                   |
|:--------|:--------|:------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | “HLR序列号”未定义。                  | 根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求。                                                                                                      |
| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”参数不在相应的参数取值范围内。 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                       |
| ERR3006 | 记录已存在   | 本次操作输入的“国内长途区号”在数据库中已存在。      | 根据实际情况，重新输入参数，确保输入的“国内长途区号”与系统中已存在的不重复。可执行LST DAREA命令查询系统中已存在的国内长途区号。                                                                  |
| ERR1111 | 超过最大限制  | 增加的国内长途区号数据记录数超过1000条。        | 根据实际情况，如需增加国内长途区号数据记录，处理步骤如下：执行LST DAREA命令，查询已存在国内长途区号数据记录。执行RMV DAREA命令，删除不必要的国内长途区号数据记录。执行该命令，增加的国内长途区号数据记录，确保增加后国内长途区号数据记录数在规定范围之内。 |
