# 增加O-CSI模板(ADD OCSITPL)

## 命令功能

该命令用于为HLR在配置数据库中增加一条O-CSI（Originating CAMEL Subscription Information）模板数据记录，根据运营商CAMEL网络的实际情况进行配置，相关参数由运营商提供。用户通过签约O-CSI模板ID签约O-CSI业务。

O-CSI是主叫CAMEL签约信息。当用户位置更新时，O-CSI数据将被插入用户当前所在的VPLMN（VLR）；在移动用户作被叫（接收从GMSC转发的来电）的SRI流程中，O-CSI数据将被传给IPLMN（Interrogating PLMN）。

O-CSI包含用来调用CAMEL业务逻辑的触发信息。当移动用户在VMSC中做主叫时，或移动用户在VMSC或GMSC中发生前转时，O-CSI智能业务将被触发。

## 注意事项

- **ADD OCSITPL**只能给一个模板增加一个DP值的触发准则，如果需要增加多个DP值的触发准则，请执行**MOD OCSITPL**命令。
- 同一个“HLR序列号”中增加的O-CSI模板记录数不能超过5000条，且系统中所有O-CSI模板增加的DP值总记录数不能超过5000条。

## 使用实例

增加O-CSI模板数据记录，“HLR序列号”为“1”，“模板ID”为“2”，“模板名”为“OCSI1”，“CAMEL业务处理能力”为“PHASE3”，“DP值”为“COLLECTINFO”，“SCP地址”为“8613911111”，“业务键”为“11”，“缺省呼叫处理”为“continueCall”，VLR/MSC和GMSC的处理方式均采用参数表中第一项，命令如下：

```
ADD OCSITPL: HLRSN=1, TPLID=2, TPLNAME="OCSI1", CAMEL=PHASE3, DP=COLLECTINFO, GSMSCFADD="8613911111", SK=11, DEFCALL=continueCall, WITHROAMAGRE_SUPCAMEL=ReturnO-CSI, WITHOUTROAMAGRE_SUPCAMEL=DenyLocationUpdate, HPLMNROAM_SUPCAMEL=ReturnO-CSI, WITHROAMAGRE_SUPLPCAMEL=ReturnLPO-CSI, WITHOUTROAMAGRE_SUPLPCAMEL=DenyLocationUpdate, HPLMNROAM_SUPLPCAMEL=AllowLocationUpdateWithMOCall, WITHROAMAGRE_NOTSUPCAMEL=AllowLocationUpdateWithMOCall, WITHOUTROAMAGRE_NOTSUPCAMEL=DenyLocationUpdate, HPLMNROAM_NOTSUPCAMEL=AllowLocationUpdateWithMOCall, WITHROAMAGRE_SUPHPCAMEL=NoProcess, WITHINTERAGRE_SUPCAMEL=ReturnO-CSI, WITHOUTINTERAGRE_SUPCAMEL=ReturnBAIC, HPLMNINTER_SUPCAMEL=ReturnO-CSI, WITHINTERAGRE_SUPLPCAMEL=ReturnLPO-CSI, WITHOUTINTERAGRE_SUPLPCAMEL=ReturnBAIC, HPLMNINTER_SUPLPCAMEL=ReturnLPO-CSI, WITHINTERAGRE_NOTSUPCAMEL=AllowMTCall, WITHOUTINTERAGRE_NOTSUPCAMEL=ReturnBAIC, HPLMNINTER_NOTSUPCAMEL=AllowMTCall;
```
