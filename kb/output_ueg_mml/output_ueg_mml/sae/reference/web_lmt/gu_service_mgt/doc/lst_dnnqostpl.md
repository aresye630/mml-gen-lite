# 查询5GS DNN QoS模板(LST DNNQOSTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询5GS DNN QoS模板数据。

- 若需要查询某个HLR序列号下全部的5GS DNN QoS模板数据，请根据模板记录数进行操作：
  - 模板记录数小于或等于5000条时，请输入“HLR序列号”参数或“HLR序列号”参数与“保存文件名”参数的组合。
  - 模板记录数大于5000条时，请输入“HLR序列号”参数及“保存文件名”参数。

- 若需要查询某条5GS DNN QoS模板数据，请同时输入“HLR序列号”和“模板ID”参数。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                             |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 可选必选说明：必选参数 参数含义：标识一条5GS DNN QoS模板信息数据记录的关键字段之一，用于指示该条记录的模板ID。 取值范围：1~255 默认值：无 配置原则：无                                                                                                                                                                                                                           |
| TPLID  | 模板ID   | 可选必选说明：可选参数 参数含义：标识一条5GS DNN QoS模板信息数据记录的关键字段之一，用于指示该条记录的模板ID。若不输入，则表示查询所有5GS DNN QoS模板信息数据。 取值范围：1～2147483646 默认值：无 配置原则：无                                                                                                                                                                                      |
| SAVEAS | 保存文件名  | 可选必选说明：可选参数 参数含义：用于指示保存查询结果的文件名称。当模板记录数超过5000条时必须输入该参数，将查询结果保存在PGW模块所在容器上，否则会报错“ERR4153：报文数量超过上限，需要指定保存文件名进行查询”。 取值范围：1~20位字符串，可由字母、数字或字符“_”、“.”组成。 默认值：无 配置原则： 该参数与“模板ID”参数只能输入一个。保存文件名参数指定的文件，可以通过“PGW Web LMT”界面的“文件管理器”下载。“保存文件名”使用不支持的字符会导致文件无法下载、下载文件内容异常、文件无法删除的情况，请修改保存文件名并重新执行命令获取文件。删除异常文件请联系华为技术支持处理。 |

## 使用实例

1. 查询“HLR序列号”为“1”的5GS DNN QoS模板信息：

   ```
   LST DNNQOSTPL: HLRSN=1;
   ```

   ```
   %%LST DNNQOSTPL: HLRSN=1;%% 
   RETCODE = 0 SUCCESS0001:操作成功

                    TPLID        TPLNAME                
                    2            test                
                    1            ngcqostpl 
    
   Total count = 2  

   There is together 1 report
     
   ---    END
   ```
2. 查询“HLR序列号”为“1”，“模板ID”为“2”的5GS DNN QoS模板信息:

   ```
   LST DNNQOSTPL: HLRSN=1, TPLID=2;
   ```

   ```
   %%LST DNNQOSTPL: HLRSN=1, TPLID=2;%%
   RETCODE = 0 SUCCESS0001:操作成功

                             HLRSN = 1
                             TPLID = 2
                           TPLNAME = tplname
                           PDUTYPE = IPV4V6
                    ALLOWEDPDUTYPE = IPV4 | IPV6
                           SSCMODE = SSC_MODE_1
                    ALLOWEDSCCMODE = SSC_MODE_2 | SSC_MODE_3
                         IWKEPSIND = TRUE
                              LADN = FALSE
                               LBO = TRUE
                        NGCQOSTPLID = 1
                            AMBRUP = 111
                            UPUNIT = Kbps
                            AMBRDW = 111
                            DWUNIT = Tbps
                            CHARGE = 2222
                          UPINTEGR = NOT_NEEDED

   Total count = 18  

   There is together 1 report  

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD DNNQOSTPL**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释                   | 原因分析                        | 处理建议                                                            |
|:--------|:------------------------|:----------------------------|:----------------------------------------------------------------|
| ERR3003 | 模板未定义                   | 输入的“模板ID”参数未定义。             | 根据实际情况，重新输入“模板ID”参数的取值，确保其存在。已存在的“模板ID”参数可以通过LST DNNQOSTPL命令查询。 |
| ERR3097 | HLR序列号未定义               | “HLR序列号”未定义。                | 根据实际情况，重新输入已定义的“HLR序列号”，可通过LST HLRSN命令查询已定义的“HLR序列号”。           |
| ERR4153 | 报文数量超过上限，需要指定保存文件名进行查询。 | 5GS DNN QoS模板信息的数量超过了5000个。 | 输入参数“保存文件名”，将查询结果保存在文件中。                                        |
