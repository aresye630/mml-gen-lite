# 删除MSISDN号码(RMV HISDN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于从HSS的业务数据库中删除一条MSISDN与IMSI的关联关系记录，并删除对应的MSISDN。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                       |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| ISDN   | MSISDN | 标识一条IMSI和MSISDN关联关系记录的关键参数，用于指定需要删除哪一条MSISDN和IMSI之间的关联关系。MSISDN由不超过15位的十进制数字(0～9)组成，采用E.164格式。例如：861381234567890。 取值范围： 长度不超过15的字符串 缺省值： 无 |

## 使用实例

删除MSISDN号码。MSISDN：861381234567890。

```
RMV HISDN: ISDN="861381234567890";
```
