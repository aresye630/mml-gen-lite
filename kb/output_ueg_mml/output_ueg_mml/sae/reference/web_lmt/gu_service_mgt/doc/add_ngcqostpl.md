# 增加5G QoS模板(ADD NGCQOSTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在数据库中增加5G QoS（Quality of Service）模板数据记录。

5G QoS是指网络通信过程中，允许用户业务在丢包率、延迟、抖动和带宽等方面获得可预期的服务水平，通过执行**ADD NGCQOSTPL**命令签约5G QoS模板，然后通过**ADD DNNQOSTPL**命令引用5G QoS模板，用户通过命令**ADD SMDATA**签约会话管理数据时，即可通过签约DNN QOS模板时引用5G QoS模板数据。

## 注意事项

所有“HLR序列号”中增加的5G QoS模板记录数不能超过20000条。

## 参数说明

| 参数标识          | 参数名称            | 参数说明                                                                                                                                                              |
|:--------------|:----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN         | HLR序列号          | 可选必选说明：必选参数 参数含义：用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1~255 默认值：无 配置原则：无                                                                             |
| TPLID         | 模板ID            | 可选必选说明：必选参数 参数含义：用于标识待增加模板在系统中的序号。该参数在系统中唯一，不能重复。 取值范围：1～2147483646 默认值：无 配置原则：无                                                                                  |
| TPLNAME       | 模板名             | 可选必选说明：可选参数 参数含义：用于标识待增加5G QoS模板在系统中的名称。 取值范围：1～60个字母或十进制数字组成的字符串。 默认值：无 配置原则：无                                                                                   |
| NGQI          | 5QI             | 可选必选说明：必选参数 参数含义：用于标识5G QoS特性的参数，是业务质量的索引，代表了资源类型、优先级、可靠性、丢包率等一组参数的取值集合，应用于所有的通路。定义了索引之后，核心网不需要传递全部参数，只传递索引值就可以将一组QoS信息通知无线侧，减少了网元间的参数传递。 取值范围：0～255 默认值：无 配置原则：无 |
| ARPPRILEVEL   | ARP优先级          | 可选必选说明：必选参数 参数含义：用于标识用户在网络资源拥塞时的优先级。运营商可以根据接入过程、业务保持过程等，分别设置用户的优先级。用户的优先级分为15个等级，数值越小，优先级越高。 取值范围：1～15 默认值：无 配置原则：无                                               |
| PREEMPTIONCAP | 是否允许抢占低优先级业务的资源 | 可选必选说明：可选参数 参数含义：用于标识是否允许业务数据流占有优先级相对较低的业务数据流的资源。 取值范围：TRUE：允许FALSE：禁止 默认值：无 配置原则：无                                                                               |
| PREEMPTIONVUL | 是否允许资源被高优先级业务抢占 | 可选必选说明：可选参数 参数含义：用于标识是否允许业务数据流丢失分配给它的资源，用于接纳一个优先级相对较高的业务数据流。 取值范围：TRUE：允许FALSE：禁止 默认值：无 配置原则：无                                                                    |
| NGQIPRILEVEL  | 5QI优先级          | 可选必选说明：可选参数 参数含义：用于标识5QI优先级的参数，数值越小，优先级越高。 取值范围：1～127 默认值：无 配置原则：无                                                                                                |

## 使用实例

5G用户开户前，运营商需要提前在系统增加5G QoS模板，以便后续签约给用户使用。例如：

1. 增加一个5G QoS模板。 “HLR序列号”为“1”，“模板ID”为“1”，“模板名”为“ngcqostpl”，“5QI”为“1”,“ARP优先级”为“1”，“是否允许抢占低优先级业务的资源”为“FALSE”，“是否允许资源被高优先级业务抢占”为“FALSE”，“5QI优先级”为“1”。

   ```
   ADD NGCQOSTPL: HLRSN=1, TPLID=1, TPLNAME="ngcqostpl", NGQI=1, ARPPRILEVEL=1, PREEMPTIONCAP=FALSE, PREEMPTIONVUL=FALSE, NGQIPRILEVEL=1;
   ```
2. 增加一个5G QoS模板。“HLR序列号”为“1”，“模板ID”为“3”，“模板名”为“ngcqostpl”，“5QI”为“7”,“ARP优先级”为“1”，“是否允许抢占低优先级业务的资源”为“FALSE”，“是否允许资源被高优先级业务抢占”为“FALSE”。

   ```
   ADD NGCQOSTPL: HLRSN=1, TPLID=3, TPLNAME="ngcqostpl", NGQI=7, ARPPRILEVEL=1, PREEMPTIONCAP=FALSE, PREEMPTIONVUL=FALSE;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                             | 处理建议                                                                                                                                    |
|:--------|:--------|:---------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 界面输入的参数不在相应的参数取值范围内。             | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                        |
| ERR3004 | 模板已存在   | “模板ID”在数据库中已存在。                  | 根据实际情况，重新输入“模板ID”的取值，确保输入的“模板ID”和系统中已存在的不重复。可通过执行LST NGCQOSTPL命令，查询已存在的5G QoS模板ID。                                                      |
| ERR3007 | 记录不存在   | “HLR序列号”未定义。                     | 根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求，可通过LST HLRSN命令查询已定义的“HLR序列号”。                                                                          |
| ERR3047 | 超过最大限制  | “HLR序列号”中增加的5G QoS模板记录数超过20000条。 | 根据实际情况，如需增加5G QoS模板，处理步骤如下：执行LST NGCQOSTPL命令，查询已存在的5G QoS模板。执行RMV NGCQOSTPL命令，删除不必要的5G QoS模板。执行ADD NGCQOSTPL命令，确保增加的5G QoS模板记录数在规定范围之内。 |
