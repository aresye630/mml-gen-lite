# 设置用户漫游限制(MOD HLRRR)

- 命令功能
- 注意事项

- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会影响该HLRSN中用户的漫游能力，因此执行该命令前，请详细阅读本命令的联机帮助和注意事项，需要与华为技术支持联系制定修改的实施方案、测试方案和回退方案后才可以实施。

该命令用于设置HLRSN中的用户在“VLR/SGSN号码前缀”对应的端局下是否允许漫游的能力。

## 注意事项

- “漫游限制状态”参数作用范围为本命令中输入的“VLR/SGSN号码前缀”。如果设置不当将导致该HLRSN下的用户，在设置的“VLR/SGSN号码前缀”下不能正常漫游控制。
- 网上重大问题案例：K国V局工程师，原本期望通过**MOD HLRRR**设置对漫游到某两个VLR前转端局下用户漫游限制，但由于执行**SET DEFHLRRR**命令设置了“缺省漫游限制状态”参数为“漫游限制”，导致整局用户漫游在匹配和未匹配“VLR/SGSN号码前缀”的端局下都被漫游限制，影响业务X小时。实际修改方案只需要执行**MOD HLRRR**设置“VLR/SGSN号码前缀”和对应的“漫游限制状态”参数，“缺省漫游限制状态”保持“漫游允许”取值。
- 该命令不允许进行批操作。
- 同一个“HLR序列号”中增加的用户漫游限制的记录数不能超过4000条。

## 参数说明

| 参数标识      | 参数名称         | 参数说明                                                                         |
|:----------|:-------------|:-----------------------------------------------------------------------------|
| HLRSN     | HLR序列号       | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                 |
| VLRSGSNNO | VLR/SGSN号码前缀 | 用于标识一个VLR或SGSN号码前缀。 取值范围：1～15位的十进制数字。 默认值：无。                                 |
| ROAMRULE  | 漫游限制状态       | 用于设置HLR中所有用户在指定VLR/SGSN中的漫游限制状态。 取值范围：PERMISSION：漫游允许。 RESTRICT：漫游限制。 默认值：无。 |

## 使用实例

禁止HLR中所有用户在号码前缀为“8613800001”和“8613800002”的VLR/SGSN中漫游。命令如下：

```
MOD HLRRR: HLRSN=1, VLRSGSNNO="8613800001", ROAMRULE=RESTRICT;
MOD HLRRR: HLRSN=1, VLRSGSNNO="8613800002", ROAMRULE=RESTRICT;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                        | 处理建议                                                                                                                        |
|:--------|:--------|:----------------------------|:----------------------------------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | “HLR序列号”未定义。                | 根据实际情况，重新输入参数“HLR序列号”，确保输入的“HLR序列号”已定义。                                                                                     |
| ERR1004 | 无效的参数值  | 界面输入的参数“VLR/SGSN号码前缀”不符合要求。 | 根据实际情况，重新输入参数“VLR/SGSN号码前缀”，确保其取值为1～15位的十进制数字。                                                                              |
| ERR1111 | 超过最大限制  | 增加的用户漫游限制记录数超过4000条。        | 根据实际情况，如需增加用户漫游限制记录，处理步骤如下：执行LST HLRRR命令，查询已存在用户漫游限制记录。执行RMV HLRRR命令，删除不必要的用户漫游限制记录。执行该命令，增加的用户漫游限制记录，确保增加用户漫游限制记录数在规定范围之内。 |
