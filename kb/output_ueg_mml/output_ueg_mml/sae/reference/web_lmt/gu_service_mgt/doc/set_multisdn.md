# 多MSISDN用户开户(SET MULTISDN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于为多MSISDN用户的指定MSISDN号码设定或修改缺省呼叫处理和承载能力。

“MSISDN”参数可以是主MSISDN号码或辅MSISDN号码其中任一个。

- 当“MSISDN”参数是已经签约的MSISDN号码时，该操作为修改该MSISDN对应的承载能力。
- 当“MSISDN”参数是新增的辅MSISDN号码时，该操作根据数据业务和承载能力定义辅MSISDN号码。

## 注意事项

- “IMSI”（“MSISDN”）和“IMSI/MSISDN文件名”是条件参数，两者有且只能出现一个。
- “用户个数”只能与“IMSI”或“MSISDN”同时配置，表示设置缺省多用户服务的批处理命令。
- “用户个数”不能与“IMSI/MSISDN文件名”同时配置。
- 一卡多号业务还与其他许多业务存在冲突，不能同时签约。这些业务包括：COMISDN、MIMSI、多SIM、多SIM增强和一卡多号多Profile。

  **说明** 

  ALS业务、VP双号业务（VVDN）和多卡多号业务相关详细介绍请参照“特性文档 > UDM特性 > 特性（GSM/UMTS网络）  > HLR特色业务 > ALS业务”、“特性文档 > UDM特性 > 特性（GSM/UMTS网络）  > HLR特色业务 > VP双号业务（VVDN） ”、“特性文档 > UDM特性 > 特性（GSM/UMTS/EPS融合网络）  > 多卡多号”。

## 参数说明

| 参数标识        | 参数名称           | 参数说明                                                                                                                                                                                                            |
|:------------|:---------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI           | 用于标识待开户用户的IMSI号码。 取值范围：6～15位的十进制数组成的字符串。 默认值：无。                                                                                                                                                                 |
| ISDN        | MSISDN         | 用于标识待开户用户的主MSISDN或辅MSISDN号码。 取值范围：1～15位的十进制数组成的字符串。 默认值：无。                                                                                                                                                      |
| RECORDCOUNT | 用户个数           | 用于标识待开户用户的数目。 当需要为连续号码的多个用户开户时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行开户。 取值范围：1～100000 默认值：无。 说明： 该参数是对连续号码的多个用户进行开户，当只有一个用户时，该参数不必配置。当一次开户的用户个数很多时，对系统性能无影响，但开户的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。         |
| FILE        | IMSI/MSISDN文件名 | 用于标识待开户用户所对应的IMSI/MSISDN文件名称。 IMSI/MSISDN文件包含多个不连续的待开户用户的IMSI号码和对应的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“setmultisdn.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见开户批操作文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。        |
| PROV        | 是否签约辅号         | 用于标识是否给用户签约辅号。辅号是基于用户的主IMSI或主MSISDN，为用户签约的辅MSISDN号码。 取值范围： TRUE：签约辅号。FALSE：撤销辅号。 默认值：TRUE                                                                                                                       |
| DEFAULTCALL | 缺省呼叫类型         | 仅当本命令中的“是否签约辅号”参数为“TRUE”时该参数有效。用于标识呼入过程中主号码的缺省呼叫类型。 主号码的缺省呼叫类型包括TSCODE和BSCODE。 取值范围：TS11TS12TS21TS22TS61TS62BS20BS21BS22BS23BS24BS25BS26BS30BS31BS32BS33BS34BS41BS42BS43BS44BS45BS46BS51BS52BS53BS61BS81 默认值：无。 |
| BCALIAS     | 承载能力别名         | 仅当本命令中的“是否签约辅号”参数为“TRUE”时该参数有效。用于标识承载能力的别名，该参数在系统中唯一，该参数必须在ADD BCALIAS命令中定义后才能在此使用。                                                                                                                             |
| SER_TYPE    | 多MSISDN业务类型    | 仅当本命令中的“是否签约辅号”参数为“TRUE”时该参数有效。用于标识新增辅卡的业务类型。 取值范围： MULISDN：多MSISDN业务。OCMN：特殊一卡多号业务。 默认值：无。 说明： 设置该参数设置为“OCMN”时，参数“缺省呼叫类型”允许不输入。当该参数没有输入或者设置为“MULISDN”时，参数“缺省呼叫类型”必须输入。当为用户增加附加号码，没有输入该参数时，则默认用户类型为“MULISDN”。   |

## 使用实例

为“IMSI”号码为“460000009012345”的用户开户。

1. 设置辅“MSISDN”号码“460000009012345”，其中“缺省呼叫类型”为“BS20”，BS20对应的“承载能力别名”为“BS20”，“多MSISDN业务类型”设置为“OCMN”。命令如下：

   1. 执行**ADD BCALIAS**命令设置BS20对应的“承载能力别名”。

      `ADD BCALIAS: HLRSN=1, ALIASNAME="BS20", DSCODE=BS20, ITC=Unrestricted Digital Info, RCR=Dual Rate Support MS/Half Rate Preferred, RA=V.110 I.460/X.30 Rate Adaption;`
   2. 为辅“MSISDN”号码“460000009012345”的用户开户。

      `SET MULTISDN: IMSI="460000009012345", ISDN="460000009012345", PROV=TRUE, DEFAULTCALL=BS20, BCALIAS="BS20", SER_TYPE=OCMN;`
2. 修改该辅“MSISDN”的用户数据业务的承载能力。命令如下：

   1. 执行**ADD BCALIAS**命令设置BS24对应的“承载能力别名”。

      `ADD BCALIAS: HLRSN=1, ALIASNAME="BS24", DSCODE=BS24, ITC=3.1KHz Audio;`
   2. 设置该辅“MSISDN”号码的用户数据业务的承载能力。

      `SET MULTISDN: IMSI="460000009012345", ISDN="460000009012345", PROV=TRUE, DEFAULTCALL=BS24, BCALIAS="BS24", SER_TYPE=OCMN;`
