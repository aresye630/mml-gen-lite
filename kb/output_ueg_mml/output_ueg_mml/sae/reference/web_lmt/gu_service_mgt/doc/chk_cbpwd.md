# 校验CBPWD(CHK CBPWD)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于校验用户或系统闭锁业务CB密钥信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                     |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------|
| TYPE   | 类型     | 可选必选说明：必选参数 参数含义：用于标识CB密钥信息的类型。 取值范围：CBPWD：用户CB密钥信息DEFCBPWD：系统CB密钥信息 默认值：无。 配置原则：无。                      |
| IMSI   | IMSI   | 可选必选说明：条件必选参数 参数含义：用于标识待校验CB密钥信息的用户IMSI。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 配置原则：仅当本命令中的“类型”参数为“CBPWD”时该参数有效。 |
| PWD    | 密码     | 可选必选说明：必选参数 参数含义：用于标识用户或系统闭锁业务CB密码。 取值范围：0000～9999 默认值：无。 配置原则：无。                                        |

## 使用实例

校验系统CB密钥信息，“类型”为“DEFCBPWD”，“密码”为“1234”。

```
CHK CBPWD: TYPE=DEFCBPWD, PWD="****";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释              | 原因分析                        | 处理建议                |
|:--------|:-------------------|:----------------------------|:--------------------|
| ERR3098 | 验证的数据与HLR数据库的数据不相同 | 输入的“密码”参数经过算法加密后与数据库中的值不相同。 | 确认输入的密码是否正确后再次执行命令。 |
