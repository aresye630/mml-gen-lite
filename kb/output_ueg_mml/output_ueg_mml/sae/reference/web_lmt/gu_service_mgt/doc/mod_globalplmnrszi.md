# 设置全局PLMN区域漫游限制(MOD GLOBALPLMNRSZI)

## 命令功能

**须知** 

该命令属于高危命令，执行不当会影响该HLRSN中用户的漫游能力，影响在网用户业务体验。因此执行该命令前，请仔细评估当前操作的风险，确认对业务没有影响后方可执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用于设置全局PLMN区域漫游限制业务数据。通过本命令可以为指定HLRSN中的所有用户签约或去签约全局PLMN区域漫游限制业务，签约后运营商不需要添加任何附加网络设备，可以限定HLRSN中所有用户允许/禁止访问其他运营商网络，灵活高效的加强了用户的移动性管理。

## 注意事项

- 该命令不允许进行批操作。
- 同一个“HLR序列号”中增加的PLMN区域漫游限制的记录数不能超过5000条。
- 当“操作类型”参数为“ADD\_MCC”或“ADD\_MNC”时，“移动国家码”、“移动网络码”和“漫游限制状态”参数必须输入。
- 当“操作类型”参数为“MOD\_MNC”时，“移动国家码”和“移动网络码”参数必须输入，“漫游限制状态”和“漫游限制时的错误码”参数至少输入一个。
- 当“操作类型”参数为“DEL\_MNC”时，“移动国家码”和“移动网络码”参数必须输入，不能输入“漫游限制状态”和“漫游限制时的错误码”参数。
- 当“操作类型”参数为“DEL\_MCC”时，“移动国家码”参数必须输入，不能输入“移动网络码”、“漫游限制状态”和“漫游限制时的错误码”参数。
- 当未通过本命令设置或通过本命令删除某个HLRSN中PLMN区域号码标识（MCC+MNC的组合）对应的全局PLMN区域漫游限制相关数据时，该HLRSN中用户的全局PLMN区域缺省漫游限制数据生效。
- 通过该命令设置的数据只对S6a/S6d接口生效。

## 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|:--------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN   | HLR序列号    | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| OPTYPE  | 操作类型      | 用于标识执行该命令对全局PLMN区域漫游限制数据实现的操作类型。 取值范围：ADD_MCC：表示增加MCC（Mobile Country Code）数据。ADD_MNC：表示增加MNC（Mobile Network Code）数据。MOD_MNC：表示修改对应MNC漫游限制的相关数据信息。DEL_MNC：表示删除MNC数据。DEL_MCC：表示删除MCC数据。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| MCC     | 移动国家码     | 用于标识移动国家码。移动国家码由ETSI（European Telecommunications Standards Institute）在世界范围内统一分配，标识用户漫游移动网络所属的国家，例如中国为460，英国为234等。 取值范围：3位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| MNC     | 移动网络码     | 仅当本命令中的“操作类型”参数不为“DEL_MCC”时该参数有效。用于标识移动网络码。移动网络码用来在一个国家内唯一标识一个移动网络，它由本国电信主管部门在本国范围内统一分配，如中国移动为00，中国联通为01等。 取值范围：2位或3位的十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| RULE    | 漫游限制状态    | 仅当本命令中的“操作类型”参数为“ADD_MCC”、“ADD_MNC”和“MOD_MNC”时该参数有效。用于标识PLMN区域漫游限制状态，即用户漫游的PLMN区域的号码标识（MCC+MNC的组合）与通过本命令签约的PLMN区域号码标识匹配时的漫游支持能力。 取值范围：PERMISSION：漫游允许RESTRICT：漫游限制 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ERRCODE | 漫游限制时的错误码 | 仅当本命令中的“操作类型”参数为“ADD_MCC”、“ADD_MNC”和“MOD_MNC”时该参数有效。用于标识UDM处理用户的PLMN区域漫游限制时返回给网络侧的错误码。通过返回的错误码或其携带的诊断信息可以排查出用户漫游失败的原因。 取值范围： ROAMNTALD：返回DIAMETER_ERROR_ROAMING_NOT_ALLOWED (5004)，不携带诊断信息。ROAMNTALDODBH：返回DIAMETER_ERROR_ROAMING_NOT_ALLOWED (5004)，携带诊断信息为ODB_HPLMN_APN，表示闭锁了归属PLMN的APN。ROAMNTALDODBV：返回DIAMETER_ERROR_ROAMING_NOT_ALLOWED (5004)，携带诊断信息为ODB_VPLMN_APN，表示闭锁了拜访PLMN的APN。ROAMNTALDODBA：返回DIAMETER_ERROR_ROAMING_NOT_ALLOWED (5004)，携带诊断信息为ODB_ALL_APN，表示闭锁了所有的APN。RATNTALD：返回DIAMETER_ERROR_RAT_NOT_ALLOWED (5421)，不携带诊断信息。UNEPSSUB：返回DIAMETER_ERROR_UNKNOWN_EPS_SUBSCRIPTION (5420)，不携带诊断信息。UNEPSSUBNOGD：返回DIAMETER_ERROR_UNKNOWN_EPS_SUBSCRIPTION (5420)，携带诊断信息为NO_GPRS_DATA_SUBSCRIBED，表示无GPRS签约数据。USERUNKNOWN：返回DIAMETER_ERROR_USER_UNKNOWN (5001)，不携带诊断信息。 默认值：无。 说明：如果执行该命令时“操作类型”参数为“ADD_MCC”或“ADD_MNC”，并且不输入该参数时，系统会设置初始值“ROAMNTALD”。 |

## 使用实例

1. 为“HLR序列号”为“1”中的用户设置全局PLMN区域漫游限制业务数据。“操作类型”为“ADD\_MCC”，“移动国家码”为“460”，“移动网络码”为“00”，“漫游限制状态”为“RESTRICT”：

   ```
   MOD GLOBALPLMNRSZI: HLRSN=1, OPTYPE=ADD_MCC, MCC="460", MNC="00", RULE=RESTRICT;
   ```
2. 为“HLR序列号”为“2”中的用户修改全局PLMN区域漫游限制业务数据。“操作类型”为“MOD\_MNC”，“移动国家码”为“461”，“移动网络码”为“03”，“漫游限制状态”为“PERMISSION”：

   ```
   MOD GLOBALPLMNRSZI: HLRSN=2, OPTYPE=MOD_MNC, MCC="461", MNC="03", RULE=PERMISSION;
   ```
3. 删除“HLR序列号”为“3”的全局PLMN区域漫游限制业务数据。“操作类型”为“DEL\_MNC”，“移动国家码”为“460”，“移动网络码”为“01”：

   ```
   MOD GLOBALPLMNRSZI: HLRSN=3, OPTYPE=DEL_MNC, MCC="460", MNC="01";
   ```
