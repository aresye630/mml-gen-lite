# 修改Service Profile信息模板(MOD HSPTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中修改一个Service Profile基本信息模板，在该操作中系统通过Service Profile模板ID来唯一标识一条Service Profile基本信息模板记录。

## 注意事项

- TPLID标识一个Service Profile基本信息模板记录的关键字段，不允许修改。其他的则允许修改。
- “Service Profile模板名称”、“签约媒体ID”、“iFC模板ID列表”、“共享iFC模板ID列表”、“模板注释说明”参数必须至少输入一个。
- 修改Service Profile信息模板记录时，输入的“Service Profile模板ID”、“iFC模板ID列表”中的iFC模板ID和“共享iFC模板ID列表”中的共享iFC模板ID必须对应同一个“HLR序列号”。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识     | 参数名称                | 参数说明                                                                                                                                                                                                      |
|:---------|:--------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN    | HLR序列号              | 可选必选说明：可选参数 参数含义：用于标识一个HLR序列号。 取值范围：0~255 默认值：无。 说明：当该参数不输入时，系统默认初始设置值为0。                                                                                                                                 |
| TPLID    | Service Profile模板ID | 可选必选说明：必选参数 参数含义：标识一个Service Profile基本信息模板记录的关键字段，用于指定需要对哪一个Service Profile基本信息模板记录的参数进行修改或调整，操作员可以使用LST HTPLINF操作查询获得。                                                                                   |
| TPLNAME  | Service Profile模板名称 | 可选必选说明：可选参数 参数含义：该参数用于具体描述一个Service Profile基本信息模板，以便于识别。 取值范围：长度不超过64的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无                                                                                                  |
| MEDIAID  | 签约媒体ID              | 可选必选说明：可选参数 参数含义：用于指定一个需要设置签约媒体ID信息所要指定的签约媒体ID值，签约媒体ID取值为4294967295 时，表示设置Service Profile模板中的签约媒体ID信息为无效值。 取值范围：0~4294967295 默认值：无                                                                        |
| IFCLIST  | iFC模板ID列表           | 可选必选说明：可选参数 参数含义：用于指明该Service Profile基本信息模板用到的所有iFC模板的模板ID，iFC模板ID列表参数为iFC模板ID用“&”连接起来的集合，集合中的iFC模板ID不允许重复，集合中的iFC模板ID至少要存在一个，最多不超过16个。iFC模板ID可以通过操作ADD HIFCTPL操作增加。 取值范围：长度不超过80的字符串 默认值：无               |
| SIFCLIST | 共享iFC模板ID列表         | 可选必选说明：可选参数 参数含义：用于指明该Service Profile基本信息模板用到的所有共享iFC模板的模板ID，共享iFC模板ID列表参数为共享iFC模板ID用“&”连接起来的集合，集合中的共享iFC模板ID不允许重复，集合中的共享iFC模板ID至少要存在一个，最多不超过32个。共享iFC模板ID可以通过操作ADD HSIFCTPL操作增加。 取值范围：长度不超过192的字符串 默认值：无 |
| COMMENT  | 模板注释说明              | 可选必选说明：可选参数 参数含义：该参数用于具体描述一个Service Profile基本信息模板的注释信息，以便于理解和使用。 取值范围：长度不超过512的字符串 默认值：无                                                                                                                  |

## 使用实例

修改Service Profile信息模板。Service Profile模板ID：10，iFC模板ID列表：3&4，共享iFC模板ID列表：1&2。

```
MOD HSPTPL: TPLID=10, IFCLIST="3&4", SIFCLIST="1&2";
```
