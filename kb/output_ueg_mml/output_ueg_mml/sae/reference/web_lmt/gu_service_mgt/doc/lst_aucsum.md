# 查询鉴权数据校验值(LST AUCSUM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于查询鉴权数据的校验值。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                     |
|:-------|:-------|:-------------------------------------------------------------------------|
| IMSI   | IMSI   | 可选必选说明：必选参数 参数含义：IMSI号码，E.212格式的编码，6～15位的十进制数字。用于指定需要查询哪个IMSI号码的鉴权数据校验值。 |

## 使用实例

查询“IMSI”为“234432421111111”的用户的鉴权数据校验值：

```
LST AUCSUM: IMSI="234432421111111";
```

```
+++    USCDB        2023-08-30 11:13:50
PGW    #014649

There is together 1 report

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释    | 原因分析                      | 处理建议                            |
|:--------|:---------|:--------------------------|:--------------------------------|
| ERR4209 | 不支持的数据形态 | 当前用户数据在数据库中的加密形态不支持该查询功能。 | 软件不支持此能力。                       |
| ERR3048 | 未加载KI    | 查询校验值前，该用户未加载KI。          | 执行ADD KI命令添加用户鉴权密钥KI，然后执行本命令查询。 |
