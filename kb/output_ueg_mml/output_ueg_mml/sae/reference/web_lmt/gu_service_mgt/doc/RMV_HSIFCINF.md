# 删除共享iFC模板信息(RMV HSIFCINF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于在HSS的业务数据库中删除指定共享iFC模板中指定优先级的iFC信息。

## 注意事项

- 当“HLR序列号”参数不输入时，默认删除“HLR序列号”为“0”的记录。
- 如果操作员在指定共享iFC模板中删除了一条共享iFC模板信息，则所有引用该模板的用户都将删除这条共享iFC模板信息，可能会影响用户业务，请操作员在执行该操作之前仔细确认任务的可行性。

## 参数说明

| 参数标识      | 参数名称      | 参数说明                                                                               |
|:----------|:----------|:-----------------------------------------------------------------------------------|
| HLRSN     | HLR序列号    | 用于指定需要删除哪一个HLR序列号对应的共享iFC信息模板记录，操作员可以使用LST HTPLINF操作查询获得。 可选必选说明：可选参数              |
| SIFCTPLID | 共享iFC模板ID | 用于指定需要删除哪一个共享iFC信息模板记录，是标识一个共享iFC信息模板记录的关键字段，操作员可以使用LST HTPLINF操作查询获得。 可选必选说明：必选参数 |
| PRIORITY  | 优先级       | 用于指定一个需要删除的共享iFC的优先级。 可选必选说明：可选参数 取值范围：0～65535 默认值：无。                              |

## 使用实例

1. 删除共享iFC模板中的iFC信息，“共享iFC模板ID”为“10”，“优先级”为“10”：

   ```
   RMV HSIFCINF: SIFCTPLID=10, PRIORITY=10;
   ```
2. 删除共享iFC模板中的iFC信息，“共享iFC模板ID”为“10”：

   ```
   RMV HSIFCINF: SIFCTPLID=10;
   ```
