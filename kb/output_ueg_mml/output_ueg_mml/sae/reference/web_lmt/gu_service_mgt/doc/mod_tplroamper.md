# 修改优选漫游业务（MOD TPLROAMPER）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于为用户提供或撤销优选漫游业务。

使用该命令可以实现为用户配置用户级的优选漫游业务。

## 注意事项

- “IMSI”，“MSISDN”， “IMSI文件名”和“MSISDN文件名”四个参数必须有且只能有一个参数出现。
- “用户个数”一定不能与“IMSI文件名”或“MSISDN文件名”同时存在。

## 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                                                                                                                                                                       |
|:------------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI       | 用于标识待修改优选漫游业务用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                      |
| ISDN        | MSISDN     | 用于标识待修改优选漫游业务用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                    |
| RECORDCOUNT | 用户个数       | 用于标识待修改优选漫游业务用户的数目。 当需要为连续号码的多个用户修改优选漫游业务时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行修改优选漫游业务。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户进行修改优选漫游业务，当只有一个用户时，该参数不必配置。当一次修改优选漫游业务的用户个数很多时，对系统性能无影响，但修改优选漫游业务的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名    | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的待修改优选漫游业务用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modroamper.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                          |
| ISDNFILE    | MSISDN文件名  | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的待修改优选漫游业务用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modroamper.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                    |
| PROV        | 是否提供优选漫游业务 | 用于标识为用户提供还是撤销优选漫游业务。 取值范围：TRUE：提供优选漫游业务。FALSE：撤销优选漫游业务。 默认值：无。                                                                                                                                                                             |
| TPLTYPE     | 优选漫游模板类型   | 用于标识优选漫游模板的类型。 取值范围：CS：CS优选漫游模板。PS：PS优选漫游模板。 默认值：无。                                                                                                                                                                                        |
| TPLID       | 模板ID       | 仅当该命令中的“是否提供优选漫游业务”参数取值为“TRUE”时该参数有效，用于标识为用户签约的优选漫游业务的模板ID。该参数必须先通过SET ROAMPERTPL命令配置才能在此处引用。 取值范围：1～999之间的十进制数字组成的字符串。 默认值：无。                                                                                                             |

## 使用实例

1. 为“IMSI”为“460000009012345”的用户提供优选漫游业务。命令如下：

   ```
   MOD TPLROAMPER: IMSI="460000009012345", PROV=TRUE, TPLTYPE=PS, TPLID=1;
   ```
2. 为“IMSI”为“460000009012345”的用户撤销优选漫游业务。命令如下：

   ```
   MOD TPLROAMPER: IMSI="460000009012345", PROV=FALSE, TPLTYPE=PS;
   ```
3. 为第一个“IMSI”为“460000009012345”的3个连续用户提供优选漫游业务。命令如下：

   ```
   MOD TPLROAMPER: IMSI="460000009012345", RECORDCOUNT=3, PROV=TRUE, TPLTYPE=PS, TPLID=1;
   ```
4. 为“IMSI文件名”为“modroamper.txt”的多个用户提供优选漫游业务。命令如下：

   ```
   MOD TPLROAMPER: IMSIFILE="modroamper.txt", PROV=TRUE, TPLTYPE=PS, TPLID=1;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释      | 原因分析                                                                                               | 处理建议                                                                                                              |
|:--------|:-----------|:---------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值     | 可能原因为如下之一：参数“IMSI”的取值不是6～15位十进制数字组成的字符串。参数“MSISDN”的取值不是1～15位十进制数字组成的字符串。                           | 根据实际情况，重新输入“IMSI”或“MSISDN”的取值，确保其取值符合要求。                                                                          |
| ERR1005 | 文件未找到      | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                   | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                |
| ERR1009 | 参数丢失       | “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数一个都没有输入。                                                  | 根据实际情况，重新输入参数，并满足“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                       |
| ERR1010 | 参数冲突       | 可能原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR1025 | 批操作文件中格式非法 | 参数“IMSI文件名”或“MSISDN文件名”对应的批操作文件格式不正确。                                                              | 请根据IMSIFILE文件格式或ISDNFILE文件格式，重新确定对应的批操作文件格式。                                                                      |
| ERR3001 | 用户未开户      | 用户的IMSI号码或MSISDN号码输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户。                                             | 核实用户的IMSI号码或MSISDN号码，如果确定输入无误，证明实际输入的参数“IMSI”或“MSISDN”对应的用户未开户，请先通过ADD SUB命令给用户开户。                                |
| ERR3111 | 系统不支持该特性   | 用户级的优选漫游业务功能开关未开启。                                                                                 | 将命令SET MAPCONF中的参数“SUBLEVEL_ROAMPER_SUPP（是否支持用户级的优选漫游业务）”配置为“TRUE”，使UDM支持用户单独签约优选漫游模板，然后再使用此命令配置。                 |
