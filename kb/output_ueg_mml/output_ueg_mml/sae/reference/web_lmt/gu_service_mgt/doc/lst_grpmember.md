# 查询智家随行家庭网关(LST GRPMEMBER)

## 命令功能

该命令用于查询智家随行家庭网关数据记录。

- 若需要查询用户所有的智家随行家庭网关数据记录，请输入“智家随行家庭网关IMSI号码”或“智家随行家庭网关MSISDN号码”参数。
- 若需要查询用户签约的某个智家随行家庭网关数据记录，请输入“智家随行家庭网关IMSI号码”或“智家随行家庭网关MSISDN号码”与“智家随行家庭网关名称”参数的组合。
- 若需要根据“智家随行家庭网关扩展ID”参数查询智家随行家庭网关数据记录，请输入“智家随行家庭网关扩展ID”参数。

## 注意事项

“智家随行家庭网关IMSI号码”、“智家随行家庭网关MSISDN号码”和“智家随行家庭网关扩展ID”参数必须有且只能有一个参数出现。

## 参数说明

| 参数标识    | 参数名称             | 参数说明                                                                                                                      |
|:--------|:-----------------|:--------------------------------------------------------------------------------------------------------------------------|
| IMSI    | 智家随行家庭网关IMSI号码   | 可选必选说明：条件可选参数 参数含义： 用于指示系统按照哪个IMSI号码来查询智家随行家庭网关数据。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                  |
| ISDN    | 智家随行家庭网关MSISDN号码 | 可选必选说明：条件可选参数 参数含义：用于指示系统按照哪个MSISDN号码来查询智家随行家庭网关数据。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                 |
| GRPNAME | 智家随行家庭网关名称       | 可选必选说明：条件可选参数 参数含义：用于标识智家随行家庭网关名称。 取值范围：1～60位字符串，字符串由数字、字母、“.”、“-”或“_”组成。该参数输入的字母不区分大小写。 默认值：无。 配置原则：无。                   |
| EXTID   | 智家随行家庭网关扩展ID     | 可选必选说明：条件可选参数 参数含义：用于指示系统按照哪个扩展ID来查询智家随行家庭网关数据。 取值范围：格式为<IMSI>_XXX，其中<IMSI>为“智家随行家庭网关IMSI号码”，XXX为8位十进制随机数。 默认值：无。 配置原则：无。 |

**ADD GRPMEMBER**
