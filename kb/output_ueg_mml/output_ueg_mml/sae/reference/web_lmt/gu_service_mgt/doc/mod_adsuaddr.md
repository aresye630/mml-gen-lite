# 修改平台地址配置(MOD ADSUADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用于增加或修改ADSU平台地址配置。

## 注意事项

参数ECATEGORY和ADSUGT必选。

## 参数说明

| 参数标识      | 参数名称     | 参数说明                    |
|:----------|:---------|:------------------------|
| ECATEGORY | 增强用户类别   | 增强用户类别。取值范围为1～254。      |
| ADSUGT    | ADSU平台地址 | ADSU平台地址，15位以内数字组成的字符串。 |

## 使用实例

在［ADSU平台地址配置表］中增加一条记录，设置增强用户类别为120，ADSU平台地址为861380755001。命令如下：

MOD ADSUADDR: ECATEGORY=120, ADSUGT="861380755001";
