# 查询短号码变换(LST SHORTNUM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用于查询短号与长号的对应关系。

## 注意事项

- 如果只指定HLRSN，显示HLRSN下所有的短号与长号的对应关系。
- 如果指定了SHORTNUM，查询此短号相关的短号与长号的对应关系。
- 如果指定了LONGNUM，查询此长号相关的短号与长号的对应关系。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                           |
|:---------|:-------|:-----------------------------------------------|
| HLRSN    | HLR序列号 | HLR序列号，有效值域为1～255，在SMU支持容灾功能或虚拟HLR功能时设置。 必选参数。 |
| SHORTNUM | 短号码    | 短号码。 1～8位的十进制数字。 可选参数。                         |
| LONGNUM  | 长号码    | 长号码。 1～28位的十进制数字。 可选参数。                        |

## 使用实例

查询短号123456相关的短号与长号对应关系。命令如下：

LST SHORTNUM: HLRSN=1, SHORTNUM="123456";
