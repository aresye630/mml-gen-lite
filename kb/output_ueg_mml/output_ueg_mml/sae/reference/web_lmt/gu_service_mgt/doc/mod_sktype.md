# 修改SKTYPE(MOD SKTYPE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

本命令属于高危命令，执行该命令前，需要与华为技术支持确认后才可以实施。

操作员可以通过此命令修改智能业务类型的设置。

## 注意事项

SKBEGIN和SKEND可能相同，若相同，则用来设置单点SK值。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                        |
|:--------|:-------|:------------------------------------------------------------|
| HLRSN   | HLR序列号 | HLR序列号，有效值域为1～255，在PGW支持容灾功能或虚拟HLR功能时设置。                    |
| SKINDEX | 索引号    | 用来标识智能业务编码号段的记录，两条智能业务编码号段记录不能使用同一个SKINDEX。 值域：0～999。 必选参数。 |
| SKTYPE  | 智能业务类型 | 智能业务的类型。 值域： PrePaid：预付费 缺省值：PrePaid。                       |
| SKBEGIN | 业务键起始值 | 智能业务编码起始值，值域：0～2147483647。和SKEND共同描述一个连续的SK号码段。             |
| SKEND   | 业务键结束值 | 智能业务编码结束值，值域：0～2147483647。和SKBEGIN共同描述一个连续的SK号码段。           |

## 使用实例

修改SKINDEX为3的预付费业务的SKBEGIN为100000，SKEND为200000。

MOD SKTYPE: HLRSN=1, SKINDEX=3, SKTYPE=PrePaid, SKBEGIN=100000, SKEND=200000;
