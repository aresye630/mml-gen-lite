# 查询小区锁定业务(LST ZCLOCK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HSS中查询小区锁定业务。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                 |
|:------------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | IMSI号码，E.212格式的编码。 取值范围：6～15位的十进制数字。 默认值：无。                                                                                                                                          |
| ISDN        | MSISDN    | MSISDN号码，E.164格式的编码。 取值范围:1～15位的十进制数字。 默认值:无。                                                                                                                                        |
| RECORDCOUNT | 用户个数      | 用户的数目，该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。 取值范围：1～100000。 默认值：无。                                                                                                        |
| IMSIFILE    | IMSI文件名   | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要修改类型的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“lstzclock.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。       |
| ISDNFILE    | MSISDN文件名 | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要修改类型的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“lstzclock.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。 |

## 使用实例

1. 在HSS上查询“IMSI”为“460000009123456”的EPS用户的小区锁定信息。命令如下：

   ```
   LST ZCLOCK: IMSI="460000009123456";
   ```

   ```
   %%LST ZCLOCK: IMSI="460000009123456";%%
   RETCODE = 0 SUCCESS0001:操作成功

                             IMSI = 460000009123456
                             ISDN = 135000000123456
                       ZCLOCKPROV = TRUE

   Total count = 3

   There is together 1 report
   ```
2. 在HSS上查询“MSISDN”为“135000000123456”的EPS用户的小区锁定信息。命令如下：

   ```
   LST ZCLOCK: ISDN="135000000123456";
   ```

   ```
   %%LST ZCLOCK: ISDN="135000000123456";%%
   RETCODE = 0 SUCCESS0001:操作成功

                             IMSI = 460000009123456
                             ISDN = 135000000123456
                       ZCLOCKPROV = TRUE

   Total count = 3

   There is together 1 report
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                                 | 处理建议                                                                                                                      |
|:--------|:--------|:-----------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------|
| ERR1010 | 参数冲突    | 可能原因为如下之一： “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数中有两个以上的参数被输入。 “用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点： “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。 “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
