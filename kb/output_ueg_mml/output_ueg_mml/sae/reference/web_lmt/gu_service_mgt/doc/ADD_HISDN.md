# 增加MSISDN号码(ADD HISDN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于在HSS的业务数据库中新增一个MSISDN记录，并建立MSISDN与指定IMSI的关联关系。2G用户进行鉴权时会用到该数据。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                            |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------|
| IMSI   | IMSI   | 用于指定与MSISDN关联的IMSI的值，该参数必须先由ADD HIMSI操作定义，然后才能在此处索引。IMSI由长度[6，15]位的十进制数字(0～9)组成，采用E.212格式。例如：460001234567890。 取值范围： 6–15 缺省值： 无 |
| ISDN   | MSISDN | 用于指定与IMSI关联的MSISDN值，由不超过15位的十进制数字(0～9)组成，采用E.164格式。例如：861381234567890。 取值范围： 长度不超过15的字符串 缺省值： 无                                 |

## 使用实例

增加MSISDN号码。IMSI：861381234567890，MSISDN：861381234567890。

```
ADD HISDN: IMSI="861381234567890", ISDN="861381234567890";
```
