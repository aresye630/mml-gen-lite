# 短信中心号码扩展(MOD SCISDN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此命令用于修改用户短信中心的用户号码或者短信中心地址。

## 注意事项

OLDFTN和OLDSCADD二者可同时存在。

## 参数说明

| 参数标识     | 参数名称    | 参数描述                                                                                     |
|:---------|:--------|:-----------------------------------------------------------------------------------------|
| IMSI     | IMSI    | 此参数用于设置IMSI号码。 取值范围：E.212格式的编码，为6～15位的十进制数。 说明：必选参数。                                     |
| OLDISDN  | 旧MSISDN | 此参数用于设置短信中心用户当前的ISDN，为有效的国际格式号码。 取值范围：E.164格式的编码，1～15位的十进制数字。                            |
| NEWISDN  | 新MSISDN | 此参数用于设置短信中心中将要修改后的ISDN，为有效的国际格式号码。 取值范围：E.164格式的编码，1～15位的十进制数字。 当OLDISDN存在时，NEWISDN必须存在。 |
| OLDSCADD | 旧短消息地址  | 此参数用于设置短信中心的当前地址。                                                                        |
| NEWSCADD | 新短消息地址  | 此参数用于设置将要修改后的短信中心地址。 当OLDSCADD存在时，NEWSCADD必须存在。                                          |

## 使用实例

将IMSI号码为460012333333333的用户在短信中心的ISDN修改为 15523658745。

```
MOD SCISDN: IMSI="460012333333333",OLDISDN="13523232222",NEWISDN="15523658745";
```
