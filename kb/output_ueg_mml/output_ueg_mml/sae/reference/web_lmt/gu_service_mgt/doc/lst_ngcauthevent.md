## 命令功能

该命令用于用户查询5G核心网鉴权事件信息。

- 如果查询单个用户的鉴权信息，请输入参数“IMSI”。
- 如果查询多个用户的鉴权信息，请输入参数“用户个数”或者“IMSI文件名”。
- 如果查询特定鉴权信息，请输入参数“IMSI”和“PLMNID”。

## 注意事项

- “IMSI”和“IMSI文件名”是互斥参数，不能同时输入，否则会提示参数冲突。
- “用户个数”参数和“IMSI文件名”是互斥参数，不能同时输入，否则会提示参数冲突。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                                                   |
|:------------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI    | 可选必选说明：条件可选参数 参数含义：用于指示系统按照哪个“IMSI”来查询5G核心网鉴权事件信息。 取值范围：6~15位的十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                              |
| PLMNID      | PLMN标识  | 可选必选说明：可选参数 参数含义：用于标识PLMN序列号。 取值范围：0～6个字符的字符串。 默认值：无。 配置原则：无。                                                                                                                                                          |
| RECORDCOUNT | 用户个数    | 可选必选说明：条件可选参数 参数含义：用于标识需要查询5G核心网鉴权事件信息的用户数目。 取值范围：1～10000。 默认值：无。 配置原则： 该参数提供，代表以指定的IMSI为起始号码，号码连续的RECORDCOUNT个用户。该参数是对连续号码的多个用户查询NGC鉴权事件信息业务，当只有一个用户时，该参数不必配置。当一次查询的用户个数很多时，对系统性能无影响，但查询的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名 | 可选必选说明：条件可选参数 参数含义：用于标识IMSI批操作文件。 取值范围：1-16个字符组成的字符串。 默认值：无。 配置原则：IMSI批操作文件包含多个不连续的需要查询的NGC鉴权事件信息的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“lstngcauthevent.txt”，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。                         |

## 使用实例

1. 查询NGC鉴权事件信息，“IMSI”为“460004009123456”，PLMN标识为“460004”;

   ```
   LST NGCAUTHEVENT: IMSI="460004009123456", PLMNID="460004";
   ```

   ```
   %%LST NGCAUTHEVENT: IMSI="460004009123456", PLMNID="460004";%%
   RETCODE = 0 SUCCESS0001:Operation is successful

                             IMSI = 460004009123456

                              SNN = 5G:mnc004.mcc460.3gppnetwork.org
                          SUCCESS = TRUE
                         AUTHTYPE = EAP-AKA’
                        EVENTTIME = 2019-06-19 15:54:11

   Total count = 5

   There is together 1 report

   ---    END
   ```
2. 查询3个连续用户的NGC鉴权事件信息，“IMSI”为“460004009123456”、“460004009123457”、“460004009123458”，PLMN标识为“460004”；

   ```
   LST NGCAUTHEVENT: IMSI="460004009123456", PLMNID="460004", RECORDCOUNT=3;
   ```

   ```
   %%LST NGCAUTHEVENT: IMSI="460004009123456", PLMNID="460004", RECORDCOUNT=3;%%
   RETCODE = 0 SUCCESS0001:Operation is successful Batch ID: 17. CHK BATSTAT can be used to obtain the status of batch operation

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，具体参数含义请参见表1的参数说明。

| 输出项名称     | 输出项解释                                       |
|:----------|:--------------------------------------------|
| SNN       | 服务网络名称。                                     |
| SUCCESS   | 用于返回本次鉴权时间对应的鉴权是否成功，“TRUE”表示成功，“FALSE”表示失败。 |
| AUTHTYPE  | 用于返回鉴权类型，5G-AKA或EAP-AKA'。                   |
| EVENTTIME | 用于返回鉴权发生时间。                                 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

| 错误码     | 错误码解释   | 原因分析                                                   | 处理建议                                                                                           |
|:--------|:--------|:-------------------------------------------------------|:-----------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 参数“IMSI”的取值不是6～15位十进制数字组成的字符串。                         | 根据实际情况，重新输入“IMSI”的取值，确保其取值符合要求。                                                                |
| ERR3001 | 用户未开户   | 用户的“IMSI”输入错误，实际输入的参数“IMSI”对应的用户未开户。                   | 核实用户的“IMSI”，如果确定输入无误，证明实际输入的参数“IMSI”对应的用户未开户，请先通过ADD SUB命令给用户开户，根据需要对用户进行签约等操作后，再查询其NGC鉴权事件信息。 |
| ERR3007 | 记录不存在   | IMSI对应的用户未进行鉴权，不存在该用户的鉴权记录信息。                          | 核实IMSI号码是否输入正确。                                                                                |
| ERR1010 | 参数冲突    | 可能的原因为如下之一： “IMSI”和“IMSI文件名”同时输入。“用户个数”和“IMSI文件名”同时输入。 | 根据实际情况，重新输入参数，确保满足以下两点： “IMSI”和“IMSI文件名”不能同时配置“用户个数”和“IMSI文件名”不能同时配置。                          |

## 参考信息

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
