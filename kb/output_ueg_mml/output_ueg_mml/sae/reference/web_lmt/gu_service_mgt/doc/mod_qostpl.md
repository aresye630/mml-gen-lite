# 修改QoS模板(MOD QOSTPL)

- 参数说明

- 输出结果说明

## 命令功能

该命令用于对一条QoS模板数据记录的某些参数进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一个QoS模板信息：

- “HLR序列号”
- “模板ID”

## 注意事项

- 如果对扩展QoS没有要求，扩展QoS相关的参数不需要出现。
- 此模板被修改后，签约此模板的用户数据也会被修改，修改后的数据在用户新注册时会下发到网络。
- 首次配置参数“分配/保留优先级数据”、“业务数据流是否能够占有能力”和“业务数据流是否能够被占有”时，三个参数必须同时存在或同时不存在。

## 使用实例

修改一个QoS漫游模板数据，“模板ID”为“3”，“模板名”为“qostpl”，“可靠性级别”为“ACKALLPRODT”，“延迟级别”为“DELAY2”，“优先级别”为“NORMAL”，“峰值吞吐量”为“8000 Octet/s”，“平均吞吐量”为“200Octet/h”，“保留优先级别”为“NORMAL”。命令如下：

```
MOD QOSTPL:  HLRSN=1, TPLID=3, TPLNAME="qostpl", RELCLS=ACKALLPRODT, DELAYCLS=DELAY2, PRECLS=NORMAL, PEAKTHR=8000 OCT, ARPRIORITY=NORMAL, ERRSDU=YES;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析            | 处理建议                                                         |
|:--------|:--------|:----------------|:-------------------------------------------------------------|
| ERR3003 | 模板未定义   | 输入的“模板ID”参数未定义。 | 根据实际情况，重新输入“模板ID”参数的取值，确保其存在。已存在的“模板ID”参数可以通过LST QOSTPL命令查询。 |
