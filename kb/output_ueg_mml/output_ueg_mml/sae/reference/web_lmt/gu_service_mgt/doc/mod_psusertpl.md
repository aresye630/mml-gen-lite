# 修改PS用户模板(MOD PSUSERTPL)

- 命令功能

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使签约此模板的用户数据被同步修改，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一条PS（Packet Switched domain）用户模板数据记录的某些参数进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一条PS用户模板数据记录：

- “HLR序列号”
- “模板ID”

## 注意事项

- 用户进行位置更新或触发其他涉及PS用户模板的流程时，系统会根据用户签约的PS用户模板ID下发模板中的数据，修改模板数据会使签约此模板的用户数据被同步修改，会影响在网用户，因此现网执行修改模板操作时需要慎重。
- 系统中所有PS用户模板增加的PDP/PDN上下文总记录数不能超过10000条。
- 执行本命令“操作类型”取值为“ADDPDPCNTX”新增签约PSAPNQOS模板时，系统会和已签约的PSAPNQOS模板进行对比。当新签约PSAPNQOS模板引用的APN模板与已签约PSAPNQOS模板引用的APN模板关联的APN相同时，系统会校验新签约PSAPNQOS模板与已签约PSAPNQOS模板中“PDP类型”，必须满足如下条件之一，系统校验成功。
  - 新签约PSAPNQOS模板中“PDP类型”为“IPV4”，同时已签约PSAPNQOS模板中“PDP类型”为“IPV6”
  - 新签约PSAPNQOS模板中“PDP类型”为“IPV6”，同时已签约PSAPNQOS模板中“PDP类型”为“IPV4”

## 参数说明

| 参数标识          | 参数名称          | 参数说明                                                                                                                                                                            |
|:--------------|:--------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN         | HLR序列号        | 标识PS用户模板数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR上的PS用户模板数据记录的参数进行修改或调整，操作员可以使用LST HLRSN命令查询获得。                                                                                        |
| TPLID         | 模板 ID         | 标识PS用户模板数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪些PS用户模板数据记录的参数进行修改或调整，操作员可以使用LST PSUSERTPL命令查询获得。                                                                                         |
| TPLNAME       | 模板名称          | 用于标识模板名称。 取值范围：1～60位字母或数字组成的字符串。 默认值：无。                                                                                                                                         |
| PROV          | 操作类型          | 用于标识新增、修改和删除用户PDP上下文，取值如下： ADDPDPCNTX：添加新的PDP上下文。MODPDPCNTX：修改用户现有PDP上下文。RMVPDPCNTX：删除PDP上下文。 默认值：无。 说明：当参数“操作类型”为“ADDPDPCNTX”或“MODPDPCNTX”时，参数“PDP上下文索引值”和“PS APNQOS模板ID”必须出现。 |
| CNTXID        | PDP/PDN上下文索引值 | 仅当本命令中的“操作类型”参数为“ADDPDPCNTX”、“MODPDPCNTX”或“RMVPDPCNTX”时该参数有效。用于标识PDP/PDN上下文索引值，每个PDP/PDN上下文的索引值不能相同。 取值范围：1～50 默认值：无。                                                           |
| PSAPNQOSTPLID | PSAPNQOS模板ID  | 仅当本命令中的“操作类型”参数为“ADDPDPCNTX”或“MODPDPCNTX”时该参数有效。用于标识PSAPNQOS模板ID。该参数必须先由ADD PSAPNQOSTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。                                                      |

## 使用实例

修改一个PS用户模板数据，“HLR序列号”为“1”，“模板ID”为“10”，“模板名”为“PSUSERTPL\_10”，“操作类型”为“ADDPDPCNTX”，“PDP/PDN上下文索引值”为“11”，“PS APNQOS模板ID”为“1”。命令如下:

```
MOD PSUSERTPL: HLRSN=1, TPLID=10, TPLNAME="PSUSERTPL_10", PROV=ADDPDPCNTX, CNTXID=11, PSAPNQOSTPLID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                    | 处理建议                                                                                                                                           |
|:--------|:--------|:----------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3047 | 超过最大限制  | 所有PS用户模板增加的“PDP/PDN上下文索引值”总记录数超过10000条。 | 根据实际情况，如需增加PDP/PDN上下文索引值，处理步骤如下：执行LST PSUSERTPL命令，查询已存在的PDP/PDN上下文索引值。执行该命令删除不必要的PDP/PDN上下文索引值。执行该命令增加PDP/PDN上下文索引值，确保增加的PDP/PDN上下文索引值在规定范围之内。 |
