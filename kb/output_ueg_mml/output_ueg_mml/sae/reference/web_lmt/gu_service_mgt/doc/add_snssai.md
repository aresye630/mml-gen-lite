## 命令功能

该命令用于给5GS用户签约S-NSSAI数据。

当用户需要接入5G系统中提供特定网络功能和网络特征的逻辑网络时，执行该命令进行签约。

## 注意事项

- 执行该命令前，请先执行**MOD AMDATA**命令签约接入和移动管理数据。
- 用户签约的第一个S-NSSAI必须是默认S-NSSAI。
- 用户签约的S-NSSAI数据中，至少需要包含一条默认S-NSSAI数据，最多允许给用户签约8条默认S-NSSAI数据。每个用户最多可以签约16条S-NSSAI数据。
- 不同切片下，同一个用户，相同DNN可以签约不同5QI配置；同一个切片下，同一个用户，相同DNN只能签约一个5QI配置。
- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。

- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识        | 参数名称        | 参数说明                                                                                                                                                                                                                                                               |
|:------------|:------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI        | 可选必选说明：条件可选参数 参数含义：用于标识需要签约S-NSSAI数据的5GS用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                           |
| ISDN        | MSISDN      | 可选必选说明：条件可选参数 参数含义：用于标识需要签约S-NSSAI数据的5GS用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                         |
| RECORDCOUNT | 用户个数        | 可选必选说明：条件可选参数 参数含义：用于标识需要签约S-NSSAI数据的5GS用户的数目。 取值范围：1～100000 默认值：无。 配置原则： 当需要为连续号码的多个用户签约S-NSSAI数据时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行签约S-NSSAI数据。该参数是对连续号码的多个用户签约S-NSSAI数据，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名     | 可选必选说明：条件可选参数 参数含义：用于标识IMSI批操作文件。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。 配置原则：IMSI批操作文件包含多个不连续的待签约S-NSSAI数据的5GS用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“addsnssai.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。                                                    |
| ISDNFILE    | MSISDN文件名   | 可选必选说明：条件可选参数 参数含义：用于标识MSISDN批操作文件。 取值范围：1～16位字母或数字组成的字符串。 默认值：无。 配置原则：MSISDN批操作文件包含多个不连续的待签约S-NSSAI数据的5GS用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“addsnssai.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。                                              |
| SNSSAI      | 切片标识        | 可选必选说明：必选参数 参数含义：用于标识5G系统中的网络切片，由SST（Slice/Service Type）与SD（Slice Differentiator）组成。 例如：当SST为1，SD为D143A5，则BOSS填写为1-D143A5；当SST为1，无SD，则BOSS填写为1。 取值范围：1～10位字符串。 默认值：无。 配置原则： SST为取值范围是0～255的数字。SD是固定长度为3字节的十六进制字符串。当该参数不携带SD或SD取值为FFFFFF时，系统按照相同取值处理。               |
| DEFAULT     | 是否默认S-NSSAI | 可选必选说明：可选参数 参数含义：用于标识签约的S-NSSAI数据是否为默认S-NSSAI数据。 取值范围： TRUE：签约的S-NSSAI数据为默认S-NSSAI数据。FALSE：签约的S-NSSAI数据为非默认S-NSSAI数据。 默认值：无。 配置原则：当该命令增加第一条S-NSSAI签约数据时，该参数必须设置为“TRUE”。                                                                                            |

## 使用实例

5G开户场景，为用户签约5G的切片信息。

1. 为“IMSI”为“460030913121001”的5GS用户签约S-NSSAI数据。其中，“切片标识”为“1”，“是否默认S-NSSAI”为“TRUE”：

   ```
   ADD SNSSAI: IMSI="460030913121001", SNSSAI="1", DEFAULT=TRUE;
   ```
2. 为连续3个IMSI用户签约S-NSSAI数据。其中，第一个“IMSI”为“460030913121001”，“用户个数”为“3”，“切片标识”为“1”,“是否默认S-NSSAI”为“TRUE”：

   ```
   ADD SNSSAI: IMSI="460030913121001", RECORDCOUNT=3, SNSSAI="1", DEFAULT=TRUE;
   ```
3. 为多个IMSI用户批量签约S-NSSAI数据。其中，“IMSI文件名”为“addsnssai.txt”，“是否默认S-NSSAI”为“TRUE”：

   ```
   ADD SNSSAI: IMSIFILE="addsnssai.txt", DEFAULT=TRUE;
   ```

## 参考信息

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
