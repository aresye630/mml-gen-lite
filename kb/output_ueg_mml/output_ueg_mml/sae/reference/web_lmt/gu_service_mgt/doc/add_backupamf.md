# 增加备份AMF信息(ADD BACKUPAMF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加备份AMF信息。

该命令的使用场景：在域选和通知场景中，UDM会作为客户端主动向主用AMF发送请求，当主用AMF发生故障的时候，UDM会向通过该命令增加的备用AMF发送请求。

## 注意事项

- 当**SET UDMSERV**命令中“最大备份AMF记录数”参数取值大于“0”时，该命令才生效。
- 该命令的最大记录数为**SET UDMSERV**命令中“最大备份AMF记录数”参数取值。

## 参数说明

| 参数标识     | 参数名称        | 参数说明                                                                                                                                                                  |
|:---------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MCC      | 移动国家码       | 可选必选说明：必选参数 参数含义：用于标识移动国家码。移动国家码由ETSI（European Telecommunications Standards Institute）在世界范围内统一分配，标识用户漫游移动网络所属的国家，例如中国为460，英国为234等。 取值范围：3位十进制数字组成的字符串。 默认值：无。 配置原则：无。 |
| MNC      | 移动网络码       | 可选必选说明：必选参数 参数含义：用于标识移动网络码。移动网络码用来在一个国家内唯一标识一个移动网络，它由本国电信主管部门在本国范围内统一分配，如中国移动为00，中国联通为01等。 取值范围：2或3位的十进制数字组成的字符串。 默认值：无。 配置原则：无。                                      |
| AMFID    | AMF标识       | 可选必选说明：必选参数 参数含义：用于标识同一PLMN下的AMF的名称，具有唯一性。 取值范围：6位十六进制的字符串。 默认值：无。 配置原则：无。                                                                                            |
| BK_FQDN  | 备用AMF的FQDN  | 可选必选说明：必选参数 参数含义：用于标识备用AMF的全量域名。 取值范围：1～128位的字符串。仅可输入数字、字母、中划线（-）、下划线（_）和英文点（.）。 默认值：无。 配置原则：无。                                                                       |
| BK_MCC   | 备用AMF的移动国家码 | 可选必选说明：可选参数 参数含义：用于标识备用AMF的移动国家码。 取值范围：3位十进制数字组成的字符串。 默认值：无。 配置原则：当参数“备用AMF的移动网络码”、“备用AMF的标识”均配置时，此参数配置才生效。                                                           |
| BK_MNC   | 备用AMF的移动网络码 | 可选必选说明：条件可选参数 参数含义：用于标识备用AMF的移动网络码。 取值范围：2或3位十进制数字组成的字符串。 默认值：无。 配置原则：当参数“备用AMF的移动国家码”、“备用AMF的标识”均配置时，此参数配置才生效。                                                       |
| BK_AMFID | 备用AMF的标识    | 可选必选说明：条件可选参数 参数含义：用于指定备用AMF的标识。 取值范围：6位十六进制的字符串。 默认值：无。 配置原则：当参数“备用AMF的移动国家码”、“备用AMF的移动网络码”均配置时，此参数配置才生效。                                                            |

## 使用实例

1. 增加一条备份AMF信息，“移动国家码”为“460”，“移动网络码”为“06”，“AMF标识”为“123456”，“备用AMF的FQDN”为“huawei.com”，“备用AMF的移动国家码”为“460”，“备用AMF的移动网络码”为“999”，“备用AMF的标识”为“654321”：

   ```
   ADD BACKUPAMF: MCC="460", MNC="06", AMFID="123456", BK_FQDN="huawei.com", BK_MCC="460", BK_MNC="999", BK_AMFID="654321";
   ```
2. 增加一条备份AMF信息，“移动国家码”为“460”，“移动网络码”为“00”，“AMF标识”为“6A23B4”，“备用AMF的FQDN”为“huawei.com”，“备用AMF的移动国家码”为“460”，“备用AMF的移动网络码”为“999”，“备用AMF的标识”为“6A83B4”：

   ```
   ADD BACKUPAMF: MCC="460", MNC="00", AMFID="6A23B4", BK_FQDN="huawei.com", BK_MCC="460", BK_MNC="999", BK_AMFID="6A83B4";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释                  | 原因分析                                             | 处理建议                                                                                                                                                         |
|:--------|:-----------------------|:-------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值                 | 输入的参数不在对应参数的取值范围内。                               | 根据实际情况，重新输入提示错误的参数取值，确保其取值符合要求。                                                                                                                              |
| ERR1009 | 参数丢失                   | “备用AMF的移动国家码”、“备用AMF的移动网络码”和“备用AMF的标识”三个参数未同时配置。 | 根据实际情况，重新输入参数，确保“备用AMF的移动国家码”、“备用AMF的移动网络码”和“备用AMF的标识”三个参数同时配置。                                                                                              |
| ERR4132 | 备份AMF记录数超过软参MAXBKAMF配置 | 当前备份AMF记录数超过了“最大备份AMF记录数”参数取值。                   | 根据实际情况，如需增加备用AMF信息，处理步骤如下： 执行LST BACKUPAMF命令查询已存在的备份AMF信息。执行LST UDMSERV命令查询“最大备份AMF记录数”参数取值。执行RMV BACKUPAMF命令删除无用的备份AMF，直到已存在的数据记录小于“最大备份AMF记录数”参数取值时才可进行添加。 |
| ERR3006 | 记录已存在                  | 输入所有参数值所组成的数据记录已经添加过。                            | 根据实际情况，重新输入参数，确保输入参数所组成的数据记录未添加过。可执行LST BACKUPAMF命令查询已存在的备份AMF信息。                                                                                            |
