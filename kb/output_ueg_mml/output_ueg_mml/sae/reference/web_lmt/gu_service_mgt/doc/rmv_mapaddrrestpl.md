# 删除MAP消息地址过滤模板(RMV MAPADDRRESTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一个MAP消息地址过滤模板。

## 注意事项

当执行该命令删除用户已签约的MAP消息地址过滤模板时，系统会提示“ERR3005:模板已经被使用”的错误信息，该模板不能被删除。如果要删除该MAP消息地址过滤模板，必须先执行**MOD MAPADDRRES**命令给用户去签约相关的MAP消息地址过滤模板。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                |
|:-------|:-------|:------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 标识MAP消息地址过滤模板数据记录的关键字段之一，用于指定删除哪个HLR上的MAP消息地址过滤模板记录。操作员可以使用LST HLRSN命令查询获得。         |
| TPLID  | 模板ID   | 标识MAP消息地址过滤模板数据记录的关键字段之一，用于指定需要删除哪个MAP消息地址过滤模板的数据记录。操作员可以使用LST MAPADDRRESTPL命令查询获得。 |

## 使用实例

删除MAP消息地址过滤模板，“HLR序列号”为“1”，“模板ID”为“2”，命令如下：

```
RMV MAPADDRRESTPL: HLRSN=1, TPLID=2;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                   | 处理建议                                                                                           |
|:--------|:--------|:---------------------------------------|:-----------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | 输入的“HLR序列号”和“模板ID”对应的MAP消息地址过滤模板记录不存在。 | 根据实际情况，重新输入已定义的“HLR序列号”和“模板ID”，可通过LST HLRSN命令查询已定义的“HLR序列号”，通过LST MAPADDRRESTPL命令查询已定义的“模板ID”。 |
| ERR3005 | 模板已经被使用 | 用户已签约该模板。                              | 根据实际情况，确定是否要删除该模板。如果确实需要删除，先通过MOD MAPADDRRES命令给用户去签约该模板，然后再执行该命令删除。                            |
