# 修改5G自动开户黑白名单（MOD NGCAUTOIMSIPRE）

- 命令功能

- 参数说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会影响用户自动开户业务，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于增加或删除需要进行5G自动开户控制的用户IMSI号码前缀信息。在该命令中，系统通过“IMSI前缀”参数来唯一标识一条用户IMSI号码前缀信息数据记录。

当系统需要对5G自动开户的用户按IMSI号码前缀进行控制时配置。

## 注意事项

- 仅当“NGC\_AUTOPROV”全局参数（通过**SET UDMSERV**命令的参数“是否启用5G自动开户特性”设置）取值为“TRUE”场景下，该命令使用IMSI号码前缀对5G自动开户的控制才会生效。
- 系统中增加的IMSI号码前缀记录数不能超过10000条。
- 鉴权阶段触发自动开户场景，因本UDM无用户数据，当用户归属号段的“是否启用5G自动开户特性”的参数取值不为“FALSE”时，UDM不区分“4G-5G”和“4G\_VoLTE-5G”，均触发5G自动开户业务。

## 参数说明

| 参数标识        | 参数名称         | 参数说明                                                                                                                                                                                                                                                                   |
|:------------|:-------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OPTYPE      | 操作类型         | 可选必选说明：必选参数 参数含义：用于标识执行该命令所实现的操作类型。 取值范围：ADD：增加前缀。DELETE：删除前缀。 默认值：无。 配置原则：无                                                                                                                                                                                           |
| IMSIPREFIX  | IMSI前缀       | 可选必选说明：必选参数 参数含义：标识一条用户IMSI号码前缀信息数据记录的关键字段，用于指定需要进行自动开户控制的用户IMSI号码前缀，操作员可以使用LST NGCAUTOIMSIPRE命令查询获得已存在的IMSI号码前缀信息。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 配置原则：无                                                                                                               |
| NGCAUTOPROV | 是否启用5G自动开户特性 | 可选必选说明：条件必选参数 参数含义：用于标识UDM是否启用5G自动开户特性。 取值范围：FALSE：不支持5G自动开户。4G-5G：仅支持4G到5G自动开户。4G_VoLTE-5G：仅支持4G_VoLTE用户自动开户成为5G用户。 默认值：无。 配置原则： 仅当本命令的“操作类型”参数为“ADD”时该参数有效。执行LST EPS命令查询“EPS”输出项为“PROV”可判断用户为4G用户。执行LST EPS命令查询“EPS”输出项为“PROV”且“VOLTETAG”输出项为“TRUE”可判断用户为4G_VoLTE用户。 |

## 使用实例

配置5G自动开户业务时，当某些号段用户需要进行自动开户，某些号段用户不需要进行自动开户时，可以进行配置。

1. 配置5G自动开户业务时，当某些号段用户需要进行自动开户，则增加一条IMSI前缀数据记录到自动开户白名单。例如设置IMSI号码前缀为“46000”的用户支持4G用户自动开户为5G用户。

   则配置“操作类型”为“ADD”，“IMSI前缀”为“46000”，“是否启用5G自动开户特性”为“4G-5G”。

   ```
   MOD NGCAUTOIMSIPRE: OPTYPE=ADD, IMSIPREFIX="46000", NGCAUTOPROV=4G-5G;
   ```
2. 配置5G自动开户业务时，当禁止某些号段用户进行自动开户时，则增加一条IMSI前缀数据记录到自动开户黑名单。例如设置IMSI号码前缀为“46001”的用户禁止进行自动开户，则配置“操作类型”为“ADD”，“IMSI前缀”为“46001”，“是否启用5G自动开户特性”为“FALSE”。

   ```
   MOD NGCAUTOIMSIPRE: OPTYPE=ADD, IMSIPREFIX="46001", NGCAUTOPROV=FALSE;
   ```
3. 当某些号段用户的5G自动开户业务需要调整，例如原黑/白名单号段用户不再进行或禁止自动开户，则删除对应IMSI前缀数据。例如取消对IMSI号码前缀为“46001”的用户进行的5G自动开户控制，则设置“操作类型”为“DELETE”，“IMSI前缀”为“46001”。

   ```
   MOD NGCAUTOIMSIPRE: OPTYPE=DELETE, IMSIPREFIX="46001";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                               | 处理建议                                                                                                                                    |
|:--------|:--------|:---------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 可能原因为如下之一：参数“操作类型”的取值不是“ADD”或“DELETE”。参数“IMSI前缀”的取值不是1～15位十进制数字组成的字符串。参数“是否启用5G自动开户特性”的取值不是取值范围之一。 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                        |
| ERR1111 | 超过最大限制  | 参数“操作类型”取值为“ADD”时，所增加的“IMSI前缀”数据记录超过了10000条。                                                       | 根据实际情况，如需增加IMSI号码前缀信息，处理步骤如下：执行LST NGCAUTOIMSIPRE命令，查询已配置的IMSI号码前缀信息。执行该命令删除不必要的IMSI号码前缀信息。执行该命令增加IMSI号码前缀信息，确保增加的IMSI号码前缀信息记录数在规定范围之内。 |
| ERR3006 | 记录已存在   | 参数“操作类型”取值为“ADD”时，所输入的“IMSI前缀”数据记录已存在。                                                             | 请按照以下步骤操作：执行LST NGCAUTOIMSIPRE命令，查询已配置的IMSI号码前缀信息。根据查询结果重新输入“IMSI前缀”，确保输入的“IMSI前缀”不在查询结果中。                                              |
| ERR3007 | 记录不存在   | 参数“操作类型”取值为“DELETE”时，所输入的“IMSI前缀”数据记录不存在。                                                          | 请按照以下步骤操作：执行LST NGCAUTOIMSIPRE命令，查询已配置的IMSI号码前缀信息。根据查询结果重新输入“IMSI前缀”，确保输入的“IMSI前缀”包含在查询结果中。                                             |
