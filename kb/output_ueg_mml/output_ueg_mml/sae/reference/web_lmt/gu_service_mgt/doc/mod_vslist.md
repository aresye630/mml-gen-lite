# 修改VLR/SGSN漫游限制模板(MOD VSLIST)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使签约该模板的用户数据被同步修改，会影响在网用户业务体验，并且“漫游区域配置方式”参数取值必须与**SET MAPSERV**命令的“VLR/SGSN漫游限制模板使用的漫游区域配置方式”参数取值一致才会生效，因此执行该命令前，请仔细检查配置的正确性，需要与华为技术支持确认后才可以实施。

该命令用于对一条VLR/SGSN漫游限制模板数据记录的某些参数进行修改或调整，同时还用于为一条VLR/SGSN漫游限制模板数据记录增加多条VLR/SGSN号码资源。在该命令中，系统通过以下关键参数的组合来唯一标识一个VLR/SGSN漫游限制模板信息：

- “HLR序列号”
- “模板ID”
- “模板类型”

## 注意事项

- 执行该命令时系统会提示“该操作会修改VLR/SGSN漫游限制模板数据，是否继续？”的提示框。因为当用户进行位置更新或触发其他涉及VLR/SGSN漫游限制模板的流程时，系统会根据用户签约的VLR/SGSN漫游限制模板ID下发模板中的数据，修改模板数据会使签约此模板的用户数据被同步修改，会影响在网用户，因此现网执行修改模板操作时需要慎重。
- 该命令不允许进行批操作。
- 系统中同一个VLR漫游限制模板增加的VLR号码前缀数据记录数不能超过4000条，且所有VLR漫游限制模板增加的VLR号码前缀数据总记录数不能超过40000条。
- 系统中同一个SGSN漫游限制模板增加的SGSN号码前缀数据记录数不能超过4000条，且所有SGSN漫游限制模板增加的SGSN号码前缀数据总记录数不能超过40000条。
- 当参数“是否提供VLR/SGSN数据”携带时，才可以携带参数“漫游区域配置方式”。当参数“漫游区域配置方式”取值为“VSAREA\_TPL\_TYPE”时，参数“VLR/SGSN漫游区域模板ID”为必选参数，参数“VLR/SGSN号码前缀”不能携带。当参数“漫游区域配置方式”取值为“VSAREA\_NUMBER\_TYPE”或不携带该参数时，参数“VLR/SGSN号码前缀”为必选参数，参数“VLR/SGSN漫游区域模板ID”不能携带。

## 参数说明

| 参数标识            | 参数名称             | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|:----------------|:-----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN           | HLR序列号           | 标识VLR/SGSN漫游限制模板数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR中VLR/SGSN漫游限制模板数据记录的参数进行修改，操作员可以使用LST HLRSN命令查询获得。                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| TPLID           | 模板ID             | 标识VLR/SGSN漫游限制模板数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪个VLR/SGSN漫游限制模板数据记录的参数进行修改，操作员可以使用LST VSLIST命令查询获得。                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| TPLNAME         | 模板名              | 用于标识VLR/SGSN漫游限制模板的名称。 取值范围：1～60个字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| TPLTYPE         | 模板类型             | 标识VLR/SGSN漫游限制模板数据记录的关键字段之一（其取值不能被修改），用于对指定需要对哪个模板类型进行修改，操作员可以使用LST VSLIST命令查询获得。                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| PROV            | 是否提供VLR/SGSN数据   | 用于标识是否提供VLR/SGSN数据。通过该参数可以修改或删除模板中已经存在的VLR/SGSN数据。 取值范围：TRUE：如果指定的VLR/SGSN号码在模板中不存在，表示VLR/SGSN号码将被增加到模板中。如果指定的VLR/SGSN号码在模板中存在，表示将修改模板中的VLR/SGSN号码数据。 FALSE：如果指定的VLR/SGSN号码在模板中已存在，表示该VLR/SGSN号码将被删除。如果指定的VLR/SGSN号码在模板中不存在，会返回“ERR3003 模板未定义”的错误码。 默认值：无。                                                                                                                                                                                                                                                                                             |
| VSAREATYPE      | 漫游区域配置方式         | 仅当本命令中的参数“是否提供VLR/SGSN数据”取值为“TRUE”或“FALSE”时，该参数有效。用于标识在VLR/SGSN漫游限制模板中，UDM使用的漫游区域配置方式。 配置方式有以下两种：签约VLR/SGSN号码前缀：通过该命令分别给每个VLR/SGSN号码前缀设置“漫游限制状态”、“业务限制模板ID”、“业务下发模板ID”、“是否提供超级ARD”、“是否限制接入GERAN”和“是否限制接入UTRAN”等数据。签约VLR/SGSN漫游区域模板：给通过ADD VSAREALIST命令签约的VLR/SGSN漫游区域模板中的所有的VLR/SGSN号码前缀设置一个规则，包括“漫游限制状态”、“业务限制模板ID”、“业务下发模板ID”、“是否提供超级ARD”、“是否限制接入GERAN”和“是否限制接入UTRAN”等数据。 取值范围：VSAREA_NUMBER_TYPE：使用签约VLR/SGSN号码前缀的配置方式。VSAREA_TPL_TYPE：使用签约VLR/SGSN漫游区域模板的配置方式。 默认值：无。 说明：两种签约配置方式可以并存。该参数取值必须与SET MAPSERV命令的“VLR/SGSN漫游限制模板使用的漫游区域配置方式”参数取值一致才会生效。 |
| VLRSGSNNO       | VLR/SGSN号码前缀     | 仅当本命令中的“是否提供VLR/SGSN数据”参数为“TRUE”或“FALSE”时该参数有效。用于标识VLR或SGSN号码前缀，用户在位置更新时，通过该参数进行最大前缀匹配。 该参数支持最大匹配原则，输入的内容可以是完整的VLR/SGSN号码，也可以是VLR/SGSN的号码前缀。最大匹配原则是指在查询时对于一个具体的号码而言，系统将在所有的记录中查找与其号码最相近的一个。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                              |
| VSAREATPLID     | VLR/SGSN漫游区域模板ID | 仅当参数“漫游区域配置方式”取值为“VSAREA_TPL_TYPE”时，该参数有效。用于标识VLR/SGSN漫游区域的模板ID。该参数必须先由ADD VSAREALIST命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ROAMRULE        | 漫游限制状态           | 仅当本命令中的“是否提供VLR/SGSN数据”参数为“TRUE”时该参数有效。用于标识用户在指定VLR/SGSN中的漫游限制状态。 取值范围：PERMISSION：漫游允许，表示允许用户在该VLR/SGSN区域漫游。 RESTRICT：漫游限制，表示不允许用户在该VLR/SGSN区域漫游。 BAOCTS11：闭锁语音出呼，表示用户在该VLR/SGSN区域漫游，只限制语音呼出业务，不限制语音呼入及数据业务。 CUSTOMIZED：定制业务，表示可根据客户的要求定制业务。 默认值：无。                                                                                                                                                                                                                                                                                                    |
| SERRESTTPLID    | 业务限制模板ID         | 仅当本命令中的“漫游限制状态”参数为“CUSTOMIZED”时该参数有效。用于标识业务限制模板ID，通过签约业务限制模板HLR向指定VLR/SGSN下发运营商限制的业务。该参数必须先由ADD SERRESTTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                          |
| RSITPLID        | 业务下发模板ID         | 仅当本命令中的“漫游限制状态”参数为“CUSTOMIZED”时该参数有效。用于标识业务下发模板ID，通过签约业务下发模板HLR向指定VLR/SGSN下发运营商定制的业务。该参数必须先由ADD RSITPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                              |
| SUPERARD        | 是否提供超级ARD        | 仅当本命令中的“是否提供VLR/SGSN数据”参数为“TRUE”时该参数有效。用于标识是否提供超级接入限制数据ARD（Access Restriction Data），运营商可以通过设置ARD，增加接入控制信息标识，来限制移动用户使用2G和3G网络。超级ARD相对于普通ARD，其优先级高。 取值范围：TRUE：提供FALSE：不提供 默认值：无。 配置原则：超级ARD优先级高于ARD，如果用户通过MOD ARD命令签约了ARD，同时通过MOD VSRR签约了超级ARD且用户漫游所在的VLR/SGSN与超级ARD对应的VLR/SGSN漫游限制模板配置的地址匹配，那么超级ARD生效，用户签约的ARD无效。                                                                                                                                                                                                                                       |
| GERANNOTALLOWED | 是否限制接入GERAN      | 仅当本命令中的“是否提供超级ARD”参数为“TRUE”时该参数有效。用于标识是否限制接入GERAN（GSM/EDGE Radio Access Network）网络。 取值范围：TRUE：限制FALSE：不限制 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| UTRANNOTALLOWED | 是否限制接入UTRAN      | 仅当本命令中的“是否提供超级ARD”参数为“TRUE”时该参数有效。用于标识是否限制接入UTRAN（Universal Terrestrial Radio Access Network）网络。 取值范围：TRUE：限制FALSE：不限制 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                          |

## 使用实例

1. 修改“HLR序列号”为“1”的HLR上的VLR/SGSN漫游限制模板数据记录，使签约此模板的用户在指定VLR区域内允许漫游。其中，“模板ID”为“1”，“模板名”为“mod\_test”，“模板类型”为“VLR”，“是否提供VLR/SGSN数据”为“TRUE”，“VLR/SGSN号码前缀”为“029”，“漫游限制状态”为“PERMISSION”：

   ```
   MOD VSLIST: HLRSN=1, TPLID=1, TPLNAME="mod_test", TPLTYPE=VLR, PROV=TRUE, VLRSGSNNO="029", ROAMRULE=PERMISSION;
   ```
2. 已通过执行**ADD VSLIST**命令增加了一个VLR/SGSN漫游限制模板并定义了一个VLR号码前缀，再执行**MOD VSLIST**命令增加一个VLR号码前缀，其中“HLR序列号”为“1”，“模板ID”为“123”，“模板名”为“SZLG”，“模板类型”为“VLR”，“是否提供VLR/SGSN数据”为“TRUE”，“VLR/SGSN号码前缀”为“8613900002”，“漫游限制状态”为“PERMISSION”：

   ```
   MOD VSLIST: HLRSN=1, TPLID=123, TPLNAME="SZLG", TPLTYPE=VLR, PROV=TRUE, VLRSGSNNO="8613900002", ROAMRULE=PERMISSION;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|:--------|:--------|:---------------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | 可能原因为如下之一：待修改的VLR/SGSN漫游限制模板未定义：“HLR序列号”或者“模板ID”未定义。需要修改的模板的“模板ID”和“模板类型”不匹配。 当界面输入“漫游限制状态”参数为“CUSTOMIZED”时，“业务限制模板ID”或“业务下发模板ID”参数指示的模板在数据库中未定义。        | 根据实际情况，重新输入参数，确保满足以下两点：使用LST VSLIST命令查询后，重新确认要修改哪个“HLR序列号”和“模板ID”对应的VLR/SGSN漫游限制模板数据记录。在使用“业务限制模板ID”或“业务下发模板ID”参数指示的模板前，确保这些模板在数据库中已存在。 |
| ERR3047 | 超过最大限制  | 可能原因为如下之一：同一个VLR漫游限制模板增加的VLR号码前缀数据记录数超过4000条。所有VLR漫游限制模板增加的VLR号码前缀总记录数超过40000条。同一个SGSN漫游限制模板增加的SGSN号码前缀数据记录数超过4000条。所有SGSN漫游限制模板增加的SGSN号码前缀总记录数超过40000条。 | 根据实际情况，如需增加VLR/SGSN号码前缀，处理步骤如下：执行LST VSLIST命令，查询已存在的VLR/SGSN号码前缀。执行该命令删除不必要的VLR/SGSN号码前缀。执行该命令增加VLR/SGSN号码前缀，确保增加的VLR/SGSN号码前缀在规定范围之内。  |
| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”、“模板ID”和“模板类型”参数不在相应的参数取值范围内。                                                                                                              | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                        |
