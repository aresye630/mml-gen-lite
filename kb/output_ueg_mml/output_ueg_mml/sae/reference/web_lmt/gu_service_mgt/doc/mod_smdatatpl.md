## 命令功能

**须知** 

该命令属于高危命令，执行该命令前，请仔细评估当前操作的风险，确认对业务没有影响后方可执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用于在数据库中修改5G会话信息模板数据记录。在该命令中，系统通过以下关键参数的组合来唯一标识一个5G会话信息模板数据：

- “HLR序列号”
- “模板ID”

## 注意事项

- 修改时必须保证至少存在一个默认SNSSAI，每个默认S-NSSAI下必须有一个默认DNN，且只允许定义一个默认DNN。当**SET UDMSERV**命令的“修改SMDATATPL控制”参数取值为“1”时 ，必须输入“数据网名称”参数，“5GS DNNQOS模板ID”和“是否为默认DNN”参数可选。
  - 当需要将一个已经存在的SNSSAI改为默认SNSSAI，且已签约的默认SNSSAI数量达到最大数量限制时，将“操作类型”设置为“MOD\_SNSSAI”修改一个默认SNSSAI为非默认状态，然后再将待修改的SNSSAI修改为默认SNSSAI。
  - 当需要签约新的默认DNN数据时，请将“操作类型”设置为“ADD\_DNN”进行签约，已存在的默认DNN自动更新为非默认DNN。
- 修改5G SMDATA模板时，引用此模板的用户5G SMDATA数据不会被同步修改。

| TPLNAME              | 模板名            | 可选必选说明：可选参数 参数含义：用于标识5G会话信息模板在系统中的名称。 取值范围：1～60位字符串。 默认值：无 配置原则：无                                                                                                                                                                                                                                                               |
| SNSSAI               | 切片标识           | 可选必选说明：必选参数 参数含义：用于标识5G系统中的网络切片，由SST(Slice/Service Type)与SD(Slice Differentiator)组成。 取值范围：1～10位字符串。 SST为取值范围是0～255的数字；SD是固定长度为3字节的十六进制字符串。SST与SD间使用“-”连接。 例如：当SST为1，SD为D143A5，则填写为1-D143A5；当SST为1，无SD，则填写为1。 默认值：无 配置原则：无                                                                                                       |

| DEFAULT              | 是否为默认DNN       | 可选必选说明：当本命令中的“操作类型”参数为“ADD_DNN”时该参数必选，为条件必选参数。当本命令中的“操作类型”参数为“ADD_SNSSAI”和“MOD_DNN”时该参数有效，为条件可选参数。 参数含义：用于标识签约的DNN数据是否为默认DNN数据。 取值范围：TRUE：签约的DNN数据为默认DNN数据。FALSE：签约的DNN数据为非默认DNN数据。 默认值：当本命令中的“操作类型”参数为“ADD_SNSSAI”时，该参数默认值为“TRUE”。其他场景无默认值。 配置原则：无。                                                                            |
| SUGGESTEDPACKETNUMDL | 建议的下行数据缓存包大小   | 可选必选说明：可选参数 参数含义：用于标识建议的下行数据缓存包大小。当网络设备向终端用户发送数据，发现终端用户不可达， 数据需要被缓存起来时，SMF可以使用该参数配置SMF/UPF或NEF中的缓存数据包大小。 取值范围：0～2147483647 默认值：无。 配置原则：仅当本命令中的“操作类型”参数为“ADD_DNN”或“MOD_DNN”时该参数有效。当该参数取值为“0”时，表示去签约。                                                                                                                             |

## 使用实例

1. 修改“HLR序列号”为“1”，“模板ID”为“1”的5G会话信息模板数据。“切片标识”为“1-D143A5”，“操作类型”为“MOD\_DNN”，“数据网名称”为“12543”，“5GS DNNQOS模板ID”为“2”，“是否为默认DNN”为“FALSE”：

   ```
   MOD SMDATATPL: HLRSN=1, TPLID=1, SNSSAI="1-D143A5", PROV=MOD_DNN, DNN="12543", DNNQOSTPLID=2, DEFAULT=FALSE;
   ```
2. 修改“HLR序列号”为“1”，“模板ID”为“3”的5G会话信息模板数据。“切片标识”为“1”，“操作类型”为“ADD\_SNSSAI”，“是否默认S-NSSAI”为“FALSE”，“数据网名称”为“23456”，“5GS DNNQOS模板ID”为“3”，“是否为默认DNN”为“TRUE”：

   ```
   MOD SMDATATPL: HLRSN=1, TPLID=3, SNSSAI="1", PROV=ADD_SNSSAI, DEFSNSSAI=FALSE, DNN="23456", DNNQOSTPLID=3, DEFAULT=TRUE;
   ```
