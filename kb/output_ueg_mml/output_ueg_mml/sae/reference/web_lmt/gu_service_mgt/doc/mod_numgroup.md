# 修改号段组(MOD NUMGROUP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

**须知** 

该命令属于高危命令，修改号段组会造成扩大或缩小已有操作员的号段范围。因此执行该命令前，请仔细评估当前操作员权限，确认对业务发放系统没有影响后方可执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用于修改号段组标识2G/3G/4G用户的IMSI/MSISDN号段前缀信息。在该命令中，系统通过以下关键参数“号段组ID”来唯一标识一个号段组信息。

## 注意事项

- 参数“号段组名”和“操作类型”是可选参数，任何一个参数出现即可，但不能同时出现。
- 相同的IMSI/MSISDN号段前缀不允许配置在不同的号段组中。
- 系统中增加的IMSI/MSISDN号段前缀记录数分别不能超过5000条。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识      | 参数名称            | 参数说明                                                                                                                                                                              |
|:----------|:----------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GROUPID   | 号段组ID           | 标识号段组信息数据的唯一关键字段（其取值不能被修改），用于指定需要对哪一条号段组数据记录的参数进行修改，操作员可以使用LST NUMGROUP命令查询获得。                                                                                                    |
| GROUPNAME | 号段组名            | 用于标识待修改号段组在系统中的名称。 取值范围：1～60个字母或十进制数字组成的字符串。 默认值：无。                                                                                                                               |
| OPTYPE    | 操作类型            | 用于标识在待修改号段组记录中增加、修改或删除号段组记录。 取值范围：ADD：新增号段组前缀。MOD: 修改号段组前缀对应的IMSI/MSISDN的号码长度。DEL：删除号段组前缀。 默认值：无。                                                                                 |
| GROUPTYPE | 号段类型            | 仅当参数“操作类型”取值为“ADD”、“MOD”或“DEL”时该参数有效。 用于标识待修改号段组的类型。 取值范围：IMSI：表示IMSI号段组。MSISDN：表示MSISDN号段组。 默认值：无。                                                                               |
| PREFIX    | IMSI/MSISDN号段前缀 | 仅当参数“操作类型”取值为“ADD”、“MOD”或“DEL”时该参数有效。 用于标识待修改号段组的IMSI/MSISDN号段前缀。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 说明：操作员进行业务发放操作时，先通过该参数进行最大前缀匹配，匹配成功后操作员才能对权限范围内的号段进行业务发放操作，否则无权限进行业务发放操作。         |
| LENGTH    | 号码长度            | 仅当参数“操作类型”取值为“ADD”或“MOD”时该参数有效。 用于标识允许操作员进行业务发放操作的IMSI/MSISDN的号码长度。 取值范围：0～15 系统初始设置值为：0。 说明：操作员进行业务发放操作时，通过该参数进行号码长度匹配，匹配成功后操作员才能对权限范围内的号段进行业务发放操作，否则无权限进行业务发放操作。“0”表示不需要号码长度匹配。 |

## 使用实例

修改号段组，“号段组ID”为“1”、“操作类型”为“ADD”、“号段类型”为“MSISDN”、“IMSI/MSISDN号段前缀”为“138”、“号码长度”为“11”：

```
MOD NUMGROUP: GROUPID=1, OPTYPE=ADD, GROUPTYPE=MSISDN, PREFIX="138", LENGTH=11;
```
