# 修改USSD响应内容(MOD USSDSTR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加或删除USSD（Unstructured Supplementary Service Data）响应内容。

UDM会在PUSSD（ProcessUnstructuredSS-Data）响应中向用户返回系统设置的USSD响应字符串，用于指示用户执行USSD操作的结果，如果没有配置，系统会返回默认值，例如该操作无法识别。

## 注意事项

无。

## 使用实例

1. 在多SIM业务和GROUPSIM用户组业务中，用户可以通过USSD操作实现业务配置，操作员需要预先在系统中配置以下数据。
   1. 执行**ADD USSDDAT**命令增加USSD控制数据，“业务码”为“\*123#”，“USSD类型”为“EMSIM\_ACT”。
   2. 执行**MOD USSDSTR**增加USSD响应内容，其中“HLR序列号”为“1”，“操作类型”为“ADD”，“业务类型”为“MultiSIM”，“业务场景”为“SuccActiveId”，“USSD响应内容”为“Success\_Actived”：

      ```
      MOD USSDSTR: HLRSN=1, OPTYPE=ADD, SERVICE=MultiSIM, SCEN=SuccActiveId, CONTENT="Success_Actived";
      ```
   3. 用户在UE上输入设置激活成员用户的USSD操作码，如“\*123#”。系统设置用户输入的IMSI为激活用户，并向UE返回系统设置的USSD响应字符串。
2. 删除一条USSD响应内容，其中“HLR序列号”为“1”，“操作类型”为“DELETE”，“业务类型”为“NoSuchCode”：

   ```
   MOD USSDSTR: HLRSN=1, OPTYPE=DELETE, SERVICE=NoSuchCode;
   ```
3. 删除所有USSD响应内容，其中“HLR序列号”为“1”，“操作类型”为“DELETEALL”：

   ```
   MOD USSDSTR: HLRSN=1, OPTYPE=DELETEALL;
   ```

该命令执行正常，会返回命令执行成功的提示信息。
