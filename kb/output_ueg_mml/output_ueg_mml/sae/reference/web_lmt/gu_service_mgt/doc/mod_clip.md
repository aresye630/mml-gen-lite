# 修改CLIP业务(MOD CLIP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来提供、撤销CLIP业务或修改CLIP业务的属性。

签约CLIP业务的用户，必须已经成功开户，并且未签约CLIP业务。撤销CLIP业务的用户，必须已经成功开户，并且已经签约CLIP业务。

CLIP业务提供后自动激活，不需要单独的激活操作。

执行此命令后，如果是给用户签约该业务，则会下发插入用户数据消息；如果是给用户去签约该业务，则会下发删除用户数据消息。

## 注意事项

- “IMSI”，“MSISDN”， “IMSI文件名”和“MSISDN文件名”是条件可选参数，任何一个参数出现即可。
- “用户个数”一定不能与“IMSI文件名”或“MSISDN文件名”同时存在。

## 参数说明

| 参数标识        | 参数名称          | 参数说明                                                                                                                                                                                                                                              |
|:------------|:--------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI          | 用于标识待修改CLIP业务用户的MSISDN号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                           |
| ISDN        | MSISDN        | 用于标识待修改CLIP业务用户的IMSI号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                             |
| RECORDCOUNT | 用户个数          | 用于标识待修改CLIP业务用户的数目。 当需要为连续号码的多个用户修改CLIP业务时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行修改CLIP业务。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户进行修改CLIP业务，当只有一个用户时，该参数不必配置。当一次修改CLIP业务的用户个数很多时，对系统性能无影响，但修改CLIP业务的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。        |
| IMSIFILE    | IMSI文件名       | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的待修改CLIP业务用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modclip.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                                    |
| ISDNFILE    | MSISDN文件名     | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的待修改CLIP业务用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modclip.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                              |
| PROV        | 是否提供CLIP业务    | 用于标识提供还是撤销CLIP业务。 取值范围：TRUE：提供CLIP业务。FALSE：撤销CLIP业务。 默认值：无。                                                                                                                                                                                       |
| OVERRIDE    | CLIP超越属性      | 仅当该命令中“是否提供CLIP业务”参数为“TRUE”时该参数有效，用于标识超越主叫号码识别属性是否有效。 取值范围：TRUE：有效。FALSE：无效。 默认值：无。                                                                                                                                                               |
| BSGTYPE     | CLIP基本业务组操作类型 | 仅当该命令中“是否提供CLIP业务”参数为“TRUE”时该参数有效，用于标识CLIP基本业务组操作类型，对该基本业务组进行删除、添加和重置操作。同时配合参数BSGLIST中设置的具体业务进行配置。 取值范围： REMOVE: 删除。ADD: 添加。RESET: 重置。 默认值：无。                                                                                                     |
| BSGLIST     | CLIP基本业务组     | 仅当该命令中“是否提供CLIP业务”参数为“TRUE”时该参数有效，用于标识CLIP基本业务组。 取值范围： TS1X: Telephony Service，话音业务。TS2X: Short Message Service，短消息业务。TS6X: Facsimile Service Group，传真业务。BS2X: Asynchronous Bearer Service，异步承载业务。BS3X: Synchronous Bearer Service，同步承载业务。 默认值：无。 |

## 使用实例

运营商为IMSI号码是460000009012345的用户提供CLIP业务，超越主叫号码识别属性无效，在短消息业务上激活CLIP业务。例如：

MOD CLIP: IMSI="460000009012345", PROV=TRUE, OVERRIDE=FALSE, BSGTYPE=ADD, BSGLIST=TS2X;
