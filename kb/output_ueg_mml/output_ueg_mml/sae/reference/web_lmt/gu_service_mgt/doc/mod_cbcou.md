# 修改闭锁业务控制属性(MOD CBCOU)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来设置闭锁业务的控制权由用户掌握还是由运营商掌握。

## 注意事项

- IMSI、ISDN、IMSIFILE、ISDNFILE是条件可选参数，有且只能有一个参数出现。
- RECORDCOUNT一定不能与IMSIFILE或ISDNFILE同时存在。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                       |
|:------------|:----------|:---------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | IMSI号码，E.212格式的编码，6～15位的十进制数字。 可选参数。                                                                                       |
| ISDN        | MSISDN    | MSISDN号码，E.164格式的编码，1～15位的十进制数字。 可选参数。                                                                                     |
| RECORDCOUNT | 用户个数      | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。                                        |
| IMSIFILE    | IMSI文件名   | IMSIFILE文件名称，由16个以内的数字或字母组成。IMSIFILE是由多个不连续的IMSI号码组成的批操作文件，每个IMSI号码占一行。 可选参数。                                              |
| ISDNFILE    | MSISDN文件名 | ISDNFILE文件名称，由16个以内的数字或字母组成。ISDNFILE是由多个不连续的MSISDN号码组成的批操作文件，每个MSISDN号码占一行。 可选参数。                                          |
| COU         | 用户控制属性    | Operator： 选中此项闭锁业务由运营者控制。用户的闭锁业务只能由运营商设置，用户无权在手机上设置。Subscriber： 选中此项闭锁业务不仅可以由运营商控制，也可以由用户控制。用户有权在自己的手机上设置如限制呼出等闭锁业务。 必选参数。 |

## 使用实例

修改IMSI号码460000009123456的用户的闭锁业务控制权。例如：

MOD CBCOU: IMSI="460000009123456", COU=OPERATOR;
