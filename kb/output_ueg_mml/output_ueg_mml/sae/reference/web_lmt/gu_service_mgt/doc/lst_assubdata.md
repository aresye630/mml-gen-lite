# 查询用户的AS订阅数据信息(LST ASSUBDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询指定EPS用户的被AS订阅的数据信息。

- 若需要查询某个用户的AS订阅数据，请输入“IMSI”或“MSISDN”参数中的任意一个。
- 若需要查询多个连续用户的AS订阅数据，请输入“IMSI”或“MSISDN”与“用户个数”的组合。
- 若需要查询多个不连续用户的AS订阅数据，请输入“IMSI文件名”或“MSISDN文件名”。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                                            |
|:------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 用于指示系统按照哪个IMSI号码来查询用户的AS订阅数据。 取值范围：6～15位的十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                    |
| ISDN        | MSISDN    | 用于指示系统按照哪个MSISDN号码来查询用户的AS订阅数据。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                   |
| RECORDCOUNT | 用户个数      | 用于指示系统根据设置的用户个数来查询用户的AS订阅数据。 当需要查询连续号码的AS订阅数据时配置该参数，选择后，系统将会从已指定的IMSI号码或MSISDN号码开始，查询出连续号码的多个用户的AS订阅数据。 配置原则：输入该参数时，“IMSI文件名”和“MSISDN文件名”不能输入。输入该参数时，“IMSI”或“MSISDN”必须存在一个。如果只查询一个用户的AS订阅数据，该参数不必提供。当一次查询的用户个数很多时，对系统性能无影响，但查询的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 取值范围：1～10000 默认值：无。 |
| IMSIFILE    | IMSI文件名   | 用于指示系统按照哪个IMSIFILE批操作文件来查询用户的AS订阅数据。 IMSI批操作文件包含多个不连续的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“lstassubdata.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或十进制数字组成的字符串。 默认值：无。                                                                             |
| ISDNFILE    | MSISDN文件名 | 用于指示系统按照哪个ISDNFILE批操作文件来查询用户的AS订阅数据。 ISDN批操作文件包含多个不连续的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“lstassubdata.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或十进制数字组成的字符串。 默认值：无。                                                                           |

## 使用实例

1. 查询“MSISDN”为“8613310911001”的EPS用户的AS订阅数据信息。

   ```
   LST ASSUBDATA: ISDN="8613310911001";
   ```

   ```
   %%LST ASSUBDATA: ISDN="8613310911001";%%
   RETCODE = 0 SUCCESS0001:Operation is successful

                             IMSI = 46000456004003
                             ISDN = 8613310911001

                   "DataRefrence"                "AsHost"                                                                                                                         "AsRealm"                                                                                                                        "ExpiryTime"
                   UE-SRVCC-Capability           as13.huawei.com                                                                                                                  huawei.com                                                                                                                       2036-02-06 04:37:22
                   UE-SRVCC-Capability           as14.huawei.com                                                                                                                  huawei.com                                                                                                                       2036-02-06 04:37:22
                   UEreachabilityforIP           as13.huawei.com                                                                                                                  huawei.com                                                                                                                       2036-02-06 04:37:22

   Total count = 5

   There is together 1 report

   ---    END
   ```
2. 查询第一个“MSISDN”为“8613310911001”的连续3个用户的AS订阅数据信息。

   ```
   LST ASSUBDATA: ISDN="8613310911001", RECORDCOUNT=3;
   ```

   ```
   %%LST ASSUBDATA: ISDN="8613310911001", RECORDCOUNT=3;%%
   RETCODE = 0 SUCCESS0001:操作成功 批操作ID：7. 使用CHK BATSTAT指令可查看此批操作的执行情况

   There is together 1 report

   ---    END
   ```
3. 查询“MSISDN文件名”为“lstassubdata.txt”的用户的AS订阅数据信息。

   ```
   LST ASSUBDATA: ISDNFILE="lstassubdata.txt";
   ```

   ```
   %%LST ASSUBDATA: ISDNFILE="lstassubdata.txt";%%
   RETCODE = 0 SUCCESS0001:操作成功 批操作ID：268435464. 使用CHK BATSTAT指令可查看此批操作的执行情况

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见

**LST ASSUBDATA**

命令的参数说明，表1列出的是未包含在

**LST ASSUBDATA**

命令参数说明中的输出项。

| 输出项名称        | 输出项解释                                                                    |
|:-------------|:-------------------------------------------------------------------------|
| DataRefrence | 显示用户的AS订阅数据类型：UE_SRVCC_CAPABILITY(终端SRVCC能力)UEREACHABILITYFORIP(终端IP可达性) |
| AsHost       | AS名称，即订阅数据的对端AS主机名。                                                      |
| AsRealm      | AS域名，即订阅数据的对端AS域名。                                                       |
| ExpiryTime   | 订阅数据的失效日期。取值为0时表示订阅数据不会失效。                                               |
| 批操作ID        | 用于返回批操作的任务号。通过执行CHK BATSTAT命令可以查询该任务的详细信息。                               |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

| 错误码     | 错误码解释         | 原因分析                                                                                               | 处理建议                                                                                                                    |
|:--------|:--------------|:---------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------|

| ERR1009 | 参数丢失          | “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数一个都没有输入。                                                  | 根据实际情况，重新输入参数，并满足“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                             |
| ERR1005 | 文件未找到         | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                   | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                      |
| ERR1010 | 参数冲突          | 可能原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR3001 | 用户未开户         | 用户的IMSI号码或MSISDN号码输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户。                                             | 核实IMSI号码或MSISDN号码，确保其对应的用户为EPS用户并验证其正确性，如果确定输入无误，证明实际输入的参数“IMSI”或“MSISDN”对应的用户未开户，请参考ADD SUB页面给用户开户。                    |
| ERR3810 | 用户不是EPS用户或未开户 | 用户的IMSI号码或MSISDN号码输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户不是EPS用户。                                         | 核实IMSI号码或MSISDN号码，确保其对应的用户为EPS用户并验证其正确性，如果确定输入无误，证明实际输入的参数“IMSI”或“MSISDN”对应的用户不是EPS用户，请参考MOD EPS命令给用户签约EPS数据。           |
| ERR1025 | 批操作文件中格式非法    | 参数“IMSI文件名”或“MSISDN文件名”对应的批操作文件格式不正确。                                                              | 请根据IMSIFILE文件格式和ISDNFILE文件格式，重新确定对应的批操作文件格式。                                                                            |
