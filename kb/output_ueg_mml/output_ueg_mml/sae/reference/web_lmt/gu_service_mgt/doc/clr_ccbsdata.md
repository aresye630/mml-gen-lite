# 清除CCBS动态数据(CLR CCBSDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于清除CCBS（Completion of Calls to Busy Subscriber）用户的动态数据。

用户在CCBS业务过程中，HLR会在CCBS的动态表中记录数据，在异常场景下（模块重启/处理异常）可能会造成动态数据无法清理，为保证用户后续可正常使用CCBS业务，需要执行该命令清理动态数据。

## 注意事项

执行该命令可能会对用户正在使用的CCBS业务造成影响，执行前请联系华为技术支持确认无误后方可执行。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                               |
|:-------|:-------|:-------------------------------------------------------------------|
| IMSI   | IMSI   | 用于标识待清除CCBS动态数据的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。              |
| DELTYP | 删除类型   | 用于标识待清除CCBS动态数据的类型。 取值范围：HLRA：CCBS主叫侧动态数据。HLRB：CCBS被叫侧动态数据。 默认值：无。 |

## 使用实例

为“IMSI”号码为“460000009123456”的用户清除“删除类型”为“HLRA”的CCBS动态数据：

```
CLR CCBSDATA: IMSI="460000009123456", DELTYP=HLRA;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                        | 处理建议                                                                                                      |
|:--------|:--------|:------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 参数“IMSI”的取值不是6～15位十进制数字组成的字符串。                              | 根据实际情况，重新输入“IMSI”的取值，确保其取值符合要求。                                                                           |
| ERR1009 | 参数丢失    | 参数“IMSI”或“删除类型”没有输入。                                        | 根据实际情况，重新输入参数，确保满足“IMSI”和“删除类型”都必须输入的条件。                                                                  |
| ERR3007 | 记录不存在   | 可能原因为如下之一：输入的“IMSI”对应的用户未开户。输入的“IMSI”和“删除类型”对应的CCBS动态数据不存在。 | 通过LST SUB命令查询输入的“IMSI”对应的用户是否开户。若未开户，则先通过ADD SUB命令给该用户开户。若已开户，则说明输入的“IMSI”和“删除类型”对应的CCBS动态数据不存在，请确认后重新输入。 |
