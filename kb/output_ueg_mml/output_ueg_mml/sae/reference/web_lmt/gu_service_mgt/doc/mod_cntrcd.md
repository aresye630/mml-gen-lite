# 修改国家/地区码(MOD CNTRCD)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于对一条国家/地区码数据记录的某些参数进行修改或调整。在该命令中，系统通过“国家/地区码”参数来唯一标识一条国家/地区码数据记录。

## 注意事项

无。

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                               |
|:---------|:--------|:-----------------------------------------------------------------------------------|
| CNTRCODE | 国家/地区码  | 标识一条国家/地区码数据记录的关键字段（其取值不能被修改），用于指定需要对哪一条国家/地区码数据记录的参数进行修改，操作员可以使用LST CNTRCD命令查询获得。 |
| CNAME    | 国家/地区名称 | 用于标识国家/地区名称。 取值范围：1～30位字母或十进制数字组成的字符串。 默认值：无。                                      |

## 使用实例

修改系统中一条国家/地区码数据记录，“国家/地区码”为“91”，修改后的“国家/地区名称”为“INDIA”：

```
MOD CNTRCD: CNTRCODE="91",CNAME="INDIA";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                      | 处理建议                                              |
|:--------|:--------|:--------------------------|:--------------------------------------------------|
| ERR3007 | 记录不存在   | “国家/地区码”对应的国家/地区码数据记录不存在。 | 使用LST CNTRCD命令查询后，重新确认要修改哪个“国家/地区码”对应的国家/地区码数据记录。 |
