# 修改私有密钥(MOD PRVTKEY)

- 注意事项

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成用户鉴权失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在HSS/HLR中修改私有密钥名称。在该命令中，系统通过以下关键参数的组合来唯一标识一条私有密钥信息：

- HLR序列号
- 私有密钥序列号

## 注意事项

该命令不允许进行批操作。

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                   |
|:--------|:--------|:---------------------------------------------------------------------------------------|
| HLRSN   | HLR序列号  | 标识私有密钥数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR上的私有密钥数据记录的参数进行修改或调整，操作员可以使用LST HLRSN命令查询获得。   |
| PKEYSNO | 私有密钥序列号 | 标识私有密钥数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪个私有密钥序列号对应的私有密钥名称进行修改或调整，操作员可以使用LST PRVTKEY命令查询获得。 |
| KEYNAME | 私有密钥名称  | 用于标识私有密钥名称。 取值范围：1～60位的字符串。 默认值：无。                                                     |

## 使用实例

1. 在HSS/HLR中修改私有密钥名称。“HLR序列号”为“1”，“私有密钥序列号”为“1”，“私有密钥名称”改为“PKEYnamehlr1pkeysno1”：

   ```
   MOD PRVTKEY: HLRSN=1, PKEYSNO=1, KEYNAME="PKEYnamehlr1pkeysno1";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                 | 处理建议                                                                                                                                   |
|:--------|:--------|:-------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | 有两点原因：HLR序列号未定义。HLR序列号对应的私有密钥序列号未添加。 | 对于第一点原因，处理步骤如下：执行LST HLRSN命令查询出已定义的HLRSN。执行LST PRVTKEY命令查询出该HLRSN对应的私有密钥序列号。结合实际情况，根据HLRSN和私有密钥序列号修改对应的私有密钥数据。 对于第二点原因，只需执行上述处理步骤的2和3。 |
