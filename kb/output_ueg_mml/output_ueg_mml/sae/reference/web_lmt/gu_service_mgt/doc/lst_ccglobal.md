# 查询用户全局计费特性(LST CCGLOBAL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于查询用户全局计费特性。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                  |
|:------------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 用于标识待查询用户全局计费特性的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                              |
| ISDN        | MSISDN    | 用于标识待查询用户全局计费特性的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                            |
| RECORDCOUNT | 用户个数      | 用于标识待查询用户全局计费特性的用户数目。 当需要为连续号码的多个用户查询用户全局计费特性时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行查询用户全局计费特性。 取值范围：1～10000 默认值：无。 说明：该参数是对连续号码的多个用户进行查询用户全局计费特性，当只有一个用户时，该参数不必配置。当一次查询用户全局计费特性的用户个数很多时，对系统性能无影响，但查询用户全局计费特性的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名   | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的待查询用户全局计费特性的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“lstccglobal.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16位字母或数字组成的字符串。 默认值：无。                                                                 |
| ISDNFILE    | MSISDN文件名 | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的待查询用户全局计费特性的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“lstccglobal.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16位字母或数字组成的字符串。 默认值：无。                                                           |

## 使用实例

1. 查询IMSI号码为“460000009123456”用户的全局计费特性信息。结果如下：

   ```
   LST CCGLOBAL: IMSI="460000009123456";
   ```

   ```
   %%LST CCGLOBAL: IMSI="460000009123456";%%
   RETCODE = 0 SUCCESS0001:操作成功

                             IMSI = 460000009123456
                             ISDN = 13484929766
                     CHARGEGLOBAL = NONE

   Total count = 3

   There is together 1 report

   ---    END
   ```
2. 查询第一个IMSI号码为“460000009123456”的连续3个用户的全局计费特性信息。结果如下：

   ```
   LST CCGLOBAL: IMSI="460000009123456",RECORDCOUNT=3;
   ```

   ```
   %%LST CCGLOBAL: IMSI="460000009123456", RECORDCOUNT=3;%%
   RETCODE = 0 SUCCESS0001:操作成功 批操作ID：14. 使用CHK BATSTAT指令可查看此批操作的执行情况

   There is together 1 report

   ---    END
   ```
3. 查询“MSISDN文件名”为“lstccglobal.txt”的用户的全局计费特性信息。结果如下：

   ```
   LST CCGLOBAL: ISDNFILE="lstccglobal.txt";
   ```

   ```
   %%LST CCGLOBAL: ISDNFILE="lstccglobal.txt";%%
   RETCODE = 0 SUCCESS0001:操作成功 批操作ID：268435458. 使用CHK BATSTAT指令可查看此批操作的执行情况

   There is together 1 report

   ---    END
   ```
