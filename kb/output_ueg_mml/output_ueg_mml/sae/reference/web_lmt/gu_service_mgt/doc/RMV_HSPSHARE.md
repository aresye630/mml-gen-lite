# 取消业务签约信息共享(RMV HSPSHARE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HSS的业务数据库中取消一个或多个IMPU的Service Profile的共享关系。

## 注意事项

- 被取消共享的一个或多个IMPU会自动重新与同一个新的Service Profile建立关联关系，新的Service Profile所包含的签约信息与原来被共享的Service Profile相同。
- 如果希望被取消共享的多个IMPU自动与不同的新的Service Profile关联，可以执行多次RMV HSPSHARE操作，每次在“IMPU列表”中只输入一个IMPU。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                            |
|:---------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMPULIST | IMPU列表 | 标识需要取消共享Service Profile的“IMPU列表”的关键字段，用于指定对哪些IMPU取消共享Service Profile，操作员可以使用LST HSPSHARE命令查询获得。该参数配置原则是：可以一次输入多个（最多十个）IMPU，中间用连字符进行连接（例如："sip:impuinfo1@huawei.com"&"sip:impuinfo2@huawei.com"，在字符"前需要添加转义字符\）。“IMPU列表”中的多个IMPU取值不能相同。要求输入的IMPU值符合SIP URI或TEL URI格式，字母区分大小写。 取值范围：长度不超过1300的字符串 默认值：无。 说明：必选参数。 |

## 使用实例

取消业务签约信息共享，“IMPU列表”为"sip:impuinfo\_1@huawei.com"&"sip:impuinfo\_2@huawei.com"：

```
RMV HSPSHARE: IMPULIST="\"sip:impuinfo_1@huawei.com\"&\"sip:impuinfo_2@huawei.com\"";
```
