# 修改CAMEL限制业务键模板(MOD CAMELRESSKTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改CAMEL限制业务键模板的数据信息或在指定的CAMEL限制业务键模板记录中添加或删除一个CAMEL业务键。如果CAMEL限制业务键模板中需要定义多个CAMEL业务键，则首先使用**ADD CAMELRESSKTPL**命令定义一个CAMEL限制业务键模板，然后使用该命令增加多个CAMEL业务键。

在该命令中，系统通过以下关键参数的组合来唯一标识一个CAMEL限制业务键模板：

- “HLR序列号”
- “模板ID”

## 注意事项

- “模板名”和“操作类型”参数至少输入一个。
- 所有CAMEL限制业务键模板增加的CAMEL业务键总记录数不能超过3000条。

## 参数说明

| 参数标识    | 参数名称       | 参数说明                                                                                                |
|:--------|:-----------|:----------------------------------------------------------------------------------------------------|
| HLRSN   | HLR序列号     | 标识CAMEL限制业务键模板记录的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR上的CAMEL限制业务键模板记录的参数进行修改或调整，操作员可以使用LST HLRSN命令查询获得。    |
| TPLID   | 模板ID       | 标识CAMEL限制业务键模板记录的关键字段之一（其取值不能被修改），用于指定需要对哪个CAMEL限制业务键模板记录的参数进行修改或调整，操作员可以使用LST CAMELRESSKTPL命令查询获得。 |
| TPLNAME | 模板名        | 用于标识CAMEL限制业务键模板在系统中的名称。 取值范围：1～60个字母或十进制数字组成的字符串。 默认值：无。                                           |
| OPTYPE  | 操作类型       | 用于标识在CAMEL限制业务键模板记录中添加或删除CAMEL业务键。 取值范围：ADD：新增CAMEL业务键DEL：删除CAMEL业务键 默认值：无。                         |
| SKTYPE  | CAMEL业务键类型 | 仅当本命令中的“操作类型”参数为“ADD”或“DEL”时该参数有效。用于标识待修改的CAMEL业务键类型。 取值范围：OCSI，即主叫用户CAMEL签约数据。 默认值：无。              |
| SK      | CAMEL业务键   | 仅当本命令中的“操作类型”参数为“ADD”或“DEL”时该参数有效。用于标识待添加或删除的限制下发的CAMEL业务键。 取值范围：0～2147483647 默认值：无。                |

## 使用实例

在“HLR序列号”为“1”、“模板ID”为“1”对应的CAMEL限制业务键模板中增加一个“CAMEL业务键类型”为“OCSI”、“CAMEL业务键”为“1”的业务键，命令如下：

```
MOD CAMELRESSKTPL: HLRSN=1, TPLID=1, OPTYPE=ADD, SKTYPE=OCSI, SK=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|:--------|:--------|:-----------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3006 | 记录已存在   | “操作类型”参数设置为“ADD”添加CAMEL业务键时，输入的“CAMEL业务键”对应的记录已存在。                                                   | 输入的“CAMEL业务键”已添加，根据实际情况确认是否需要添加其他的CAMEL业务键。                                                                                                                                           |
| ERR3007 | 记录不存在   | 可能原因为如下之一：“HLR序列号”和“模板ID”参数对应的CAMEL限制业务键模板数据记录不存在。“操作类型”参数设置为“DEL”删除CAMEL业务键时，输入的“CAMEL业务键”对应的记录不存在。 | 根据实际情况，重新输入参数，确保满足以下两点：“HLR序列号”和“模板ID”参数对应的CAMEL限制业务键模板数据记录存在。已存在的模板数据记录可通过LST CAMELRESSKTPL命令查询。需要删除的“CAMEL业务键”对应的记录存在。已存在的“CAMEL业务键”可通过LST CAMELRESSKTPL命令查询。                       |
| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”参数不在相应的参数取值范围内。                                                                        | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                                                                      |
| ERR1009 | 参数丢失    | “模板名”参数和“操作类型”参数都没有输入。                                                                               | 根据实际情况，重新输入参数，确保满足“模板名”和“操作类型”参数至少输入一个。                                                                                                                                               |
| ERR3096 | 模板不能为空  | 当“操作类型”参数设置为“DEL”时，删除的CAMEL业务键是模板的最后一条记录。                                                            | 请确认是否需要删除模板内的最后一条信息记录，若需要删除，请通过RMV CAMELRESSKTPL命令删除相应模板。                                                                                                                             |
| ERR3047 | 超过最大限制  | 所有CAMEL限制业务键模板增加的CAMEL业务键总记录数超过3000条。                                                                | 根据实际情况，如需增加CAMEL限制业务键模板，处理步骤如下：执行LST CAMELRESSKTPL命令，查询已存在的CAMEL限制业务键模板。执行该命令，将“操作类型”设置为“DELETE”删除不必要的CAMEL限制业务键模板记录。执行该命令，将“操作类型”设置为“ADD”增加CAMEL限制业务键模板，确保增加的CAMEL限制业务键模板记录数在规定范围之内。 |
