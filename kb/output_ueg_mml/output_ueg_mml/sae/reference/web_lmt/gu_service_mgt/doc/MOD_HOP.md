## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成用户鉴权失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该操作用于对HSS的业务数据库中的一个鉴权数据OP的数据记录中的OP值进行修改或调整，唯一标识数据记录的关键参数是OP索引号。

## 注意事项

- 待修改的OP必须没有被使用。
- 如果在“命令输入区”输入命令后再输入各参数，“OP值”出于安全原因，仅显示“\*”。
- 如果在“MML命令编辑区”直接输入带参数的命令，命令中的“OP值”以明文显示。
- 该命令不允许进行批操作。
- 当**SET MAPCONF**命令中的“是否启用随机密钥”参数为“TRUE”时，如果未执行**SET MAPSERV**命令设置“随机密钥默认ID”参数为系统已存在的随机密钥，则执行该命令时会返回错误：“已启用随机密钥功能，请先执行**SET RANDOMKEY**命令生成随机密钥”。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                         |
|:--------|:-------|:---------------------------------------------------------------------------------------------|
| OPSNO   | OP索引号  | 标识一条OP数据记录的关键参数（其取值不能被修改），用于指定需要对哪一条OP数据记录的参数进行修改或调整，操作员可以使用LST HOP操作查询获得。 取值范围：1～128 缺省值： 无 |
| OPVALUE | OP值    | 用于定义鉴权数据OP的值，要求输入16进制字符，字母不区分大小写。 取值范围： 长度等于32的16进制字符串 缺省值： 无                                |

## 使用实例

修改OP。OP索引号：10，OP值：9876543210ABCDEFabcdef1234567890。

```
MOD HOP: OPSNO=10, OPVALUE="*****";
```

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。
