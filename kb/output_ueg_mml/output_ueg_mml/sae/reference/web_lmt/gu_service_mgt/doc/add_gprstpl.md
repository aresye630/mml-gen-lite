# 增加GPRS模板(ADD GPRSTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于增加GPRS（PDP Context）模板，使用ADD GPRSTPL命令，只能增加一条PDP上下文，如果用户需要签约多条PDP Context，请使用命令**MOD GPRSTPL**。

## 注意事项

- 一个GPRS模板可能关联一个或多个PDP数据，但系统中所有GPRS模板所关联的PDP数量最大为5000个。
- 如果采用动态寻址，参数PDPADD不需要设置。
- 如果对扩展QoS没有要求，扩展QoS相关的参数不需要出现。
- PDP上下文中MAXGBRDWL参数的值不能大于MAXBRDWL参数的值。
- PDP上下文中MAXGBRUPL参数的值不能大于MAXBRUPL参数的值。
- PDP上下文中MAXEXTGBRDWL参数的值不能大于MAXEXTBRDWL参数的值。

## 使用实例

增加GPRS模板，模板ID为3，模板名称为gprstpl，Context ID为2，PDP地址类型为IPV4，可靠性级别为ACKALLPRODT，延迟级别为DELAY2，优先级别为NORMAL，峰值吞吐量为8000 Octet/s，平均吞吐量为200 Octet/h，接入点名称为APN1，允许访问VPLMN的APN，采用预付费计费方式。命令如下：

ADD GPRSTPL: HLRSN=1, TPLID=3, TPLNAME="gprstpl", CNTXID=2, PDPTYPE=IPV4, RELCLS=ACKALLPRODT, DELAYCLS=DELAY2, PRECLS=NORMAL, PEAKTHR=8000 OCT, MEANTHR=200 OCT, ARPRIORITY=NORMAL, APN="APN1", VPLMN=TRUE, CHARGE=PREPAID;
