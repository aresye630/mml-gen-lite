# 删除Diameter对端类型(RMV DPETYPE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使用户漫游到此Diameter对端区域后可能出现位置更新失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除一条Diameter对端类型的记录。

## 注意事项

- 当执行该命令删除Diameter对端类型时，会造成统计漫游用户数不正确或给用户签约闭锁漫游业务失败，请谨慎操作。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                |
|:-----------|:-------|:----------------------------------------------------------------------------------------------------|
| HLRSN      | HLR序列号 | 标识Diameter对端类型信息数据的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR上的Diameter对端类型信息数据记录的参数进行删除，操作员可以使用LST HLRSN命令查询获得。 |
| PEERENTITY | 对端身份标识 | 标识Diameter对端类型信息数据的关键字段之一（其取值不能被修改），用于指定需要对哪个Diameter对端类型信息数据记录的参数进行删除，操作员可以使用LST DPETYPE命令查询获得。    |

## 使用实例

删除一个Diameter对端类型，“HLR序列号”为“1”，“对端身份标识”为“test.huawei.com”。命令如下:

```
RMV DPETYPE: HLRSN=1, PEERENTITY="test.huawei.com";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析               | 处理建议                                                 |
|:--------|:--------|:-------------------|:-----------------------------------------------------|
| ERR1004 | 无效的参数值  | 参数的取值中含有不符合要求的字符串。 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合取值范围。                   |
| ERR3007 | 记录不存在   | HLR序列号未定义。         | 使用LST HLRSN命令查询后，重新确认要删除哪个“HLR序列号”对应的Diameter对端数据记录。 |
