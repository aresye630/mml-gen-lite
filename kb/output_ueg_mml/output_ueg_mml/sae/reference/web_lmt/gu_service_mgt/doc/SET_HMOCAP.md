# 设置必选或可选能力(SET HMOCAP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于设定指定用户（Subscription用户或PSI用户）所需要的业务能力需求，包括可选能力和必选能力。

## 注意事项

- SUBID参数与PISI参数存在且仅能存在一个。
- MCAP参数与OCAP参数必须至少存在一个，可同时存在。
- MCAP和OCAP的合法取值分为以下两种情况：
  - 只有一个无效ID值，0为无效ID值；
  - 由1到32个整数用“&”连接起来的整数集合，其中每个整数的取值范围为1～4294967295，集合里的整数不允许重复；当MCAP参数和OCAP参数都存在，且取值都为第二种情况时，两个参数的集合之间不允许有相同的整数。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                               |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------|
| SUBID  | SUBID  | 用于指定一个需要设置能力集的SUBID，该参数必须先由ADD HSUB操作定义，然后才能在此处索引，SUBID字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无                                          |
| PISI   | PISI   | 用于定义PISI的值，配置原则是要求输PISI值符合NAI格式，字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无                                                                 |
| MCAP   | 必选能力集  | 用户必选业务能力需求，0为无效ID值； 由1到32个整数用“&”连接起来的整数集合，其中每个整数的取值范围为1～4294967295，集合里的整数不允许重复。 取值范围： 长度不超过352的字符串 缺省值： 无 说明：当该参数设置为“0”时，表示清除原有配置。 |
| OCAP   | 可选能力集  | 用户可选业务能力需求，0为无效ID值； 由1到32个整数用“&”连接起来的整数集合，其中每个整数的取值范围为1～4294967295，集合里的整数不允许重复。 取值范围： 长度不超过352的字符串 缺省值： 无 说明：当该参数设置为“0”时，表示清除原有配置。 |

## 使用实例

设置必选或可选能力。SUBID：subinfo，必选能力集：1&2，可选能力集：3&4。

```
SET HMOCAP: SUBID="subinfo", MCAP="1&2", OCAP="3&4";
```
