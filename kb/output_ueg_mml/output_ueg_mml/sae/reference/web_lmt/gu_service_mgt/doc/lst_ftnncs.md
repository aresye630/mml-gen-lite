# 查询前转号码数据(LST FTNNCS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询前转号码是否通知主叫用户的属性：

- 若需要查询全部的前转号码属性，请输入“HLR序列号”，其他参数不输入。
- 若需要查询某个前转号码的通知主叫用户属性，请输入“HLR序列号”和“前转号码”。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                         |
|:-------|:-------|:---------------------------------------------|
| HLRSN  | HLR序列号 | 用于指示系统按照哪个HLR序列号来查询前转号码属性，该参数必须选择。           |
| FTN    | 前转号码   | 用于指示系统按照哪个前转号码来查询前转号码属性；若不输入，则表示查询所有的前转号码属性。 |

## 使用实例

1. 查询“HLR序列号”为“1”的HLR上的前转号码属性记录：

   ```
   LST FTNNCS: HLRSN=1;
   ```

   ```
   %%LST FTNNCS: HLRSN=1;%%
   RETCODE = 0 SUCCESS0001:操作成功

           "Forward to Number"             "Notification to Calling Subscriber"
           8613907550001                   TRUE
           8613907550002                   FALSE
           8613907550003                   TRUE
           8613907550004                   TRUE

   Total count = 4

   There is together 1 report

   ---    END
   ```
2. 查询“HLR序列号”为“1”的HLR上的前转号码属性记录。其中，“前转号码”为“8613907550002”：

   ```
   LST FTNNCS: HLRSN=1, FTN="8613907550002";
   ```

   ```
   %%LST FTNNCS: HLRSN=1, FTN="8613907550002";%%
   RETCODE = 0 SUCCESS0001:操作成功

           "Forward to Number"             "Notification to Calling Subscriber"
           8613907550001                   FALSE

   Total count = 1

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息，各参数含义请参见**ADD FTNNCS**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                       | 处理建议                                                                                              |
|:--------|:--------|:---------------------------|:--------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 参数“前转号码”的取值中含有0～9以外的字符。    | 重新输入“前转号码”，确保只含有0～9以内的字符。                                                                         |
| ERR3007 | 记录不存在   | 有两点原因：HLR序列号未定义。前转号码属性未添加。 | 对于第一点原因，执行LST HLRSN命令查询出已定义的“HLRSN”，然后在执行LST FTNNCS命令时输入即可。 对于第二点原因，在执行LST FTNNCS命令时只输入“HLRSN”即可。 |
