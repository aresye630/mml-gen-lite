# 查询切片管理数据（LST SNSSAI）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询5GS用户签约的切片管理数据。

- 若需要查询某个用户的切片管理数据，请输入参数“IMSI”或“MSISDN”其中一个，其他参数不输入。
- 若需要查询多个连续用户的切片管理数据，请输入参数“IMSI”或“MSISDN”的同时，再输入参数“用户个数”，其他参数不输入。
- 若需要查询多个不连续IMSI用户的切片管理数据，请输入“IMSI文件名”或“MSISDN文件名”，其他参数不输入。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                            |
|:------------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 可选必选说明：条件可选参数 参数含义：用于指示系统按照哪个IMSI号码查询用户的S-NSSAI数据。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                        |
| ISDN        | MSISDN    | 可选必选说明：条件可选参数 参数含义：用于指示系统按照哪个MSISDN号码查询用户的S-NSSAI数据。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                      |
| RECORDCOUNT | 用户个数      | 可选必选说明：条件可选参数 参数含义：用于指示系统需要查询S-NSSAI数据的用户个数。 取值范围：1～10000 默认值：无。 配置原则： 当需要为连续号码的多个用户查询S-NSSAI数据时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行查询S-NSSAI数据。该参数是对连续号码的多个用户查询S-NSSAI数据，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名   | 可选必选说明：条件可选参数 参数含义：用于指示系统按照哪个IMSI文件名查询用户的S-NSSAI数据。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。 配置原则：IMSI批操作文件包含多个不连续的待查询S-NSSAI数据的5GS用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“lstsnssai.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。                               |
| ISDNFILE    | MSISDN文件名 | 可选必选说明：条件可选参数 参数含义：用于指示系统按照哪个MSISDN文件名查询用户的S-NSSAI数据。 取值范围：1～16位字母或数字组成的字符串。 默认值：无。 配置原则：MSISDN批操作文件包含多个不连续的待查询S-NSSAI数据的5GS用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“lstsnssai.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。                         |

## 使用实例

1. 查询“IMSI”为“460030913121001”的用户的切片管理数据：

   ```
   LST SNSSAI:IMSI="460030913121001";
   ```

   ```
   %%LST SNSSAI: IMSI="460030913121001";%%                       
   RETCODE = 0 SUCCESS0001:操作成功

                             IMSI = 460030913121001
                             ISDN = 1

                           SNSSAI = 1
                          DEFAULT = TRUE

   Total count = 4

   There is together 1 report

   ---    END
   ```
2. 批量查询IMSI用户的切片管理数据。其中，“IMSIFILE”为“lstsnssai.txt”：

   ```
   LST SNSSAI: IMSIFILE="lstsnssai.txt";
   ```

   ```
   %%LST SNSSAI: IMSIFILE="lstsnssai.txt";%%
   RETCODE = 0 SUCCESS0001:操作成功 批操作ID: 21. 使用CHK BATSTAT指令可查看此批操作的执行情况

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD SNSSAI**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| ERR1005 | 文件未找到      | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                    | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                       |
| ERR1009 | 参数丢失       | “IMSI”、“MSISDN”、“IMSI文件名”或“MSISDN文件名”四个参数一个都没有输入。                                                   | 根据实际情况，重新输入参数，确保满足“IMSI”、“MSISDN”、“IMSI文件名”或“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                             |

| ERR1025 | 批操作文件中格式非法 | 参数“IMSI文件名”或“MSISDN文件名”对应的批操作文件格式不正确。                                                               | 请根据IMSIFILE文件格式和ISDNFILE文件格式重新确定对应的批操作文件格式。                                                                              |
