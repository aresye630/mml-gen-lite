# 查询高价值业务标志（LST GJZ）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询用户的高价值业务数据。

- 若需要查询单个用户的高价值业务数据，请输入“IMSI”或“MSISDN”。
- 若需要查询多个连续用户的高价值业务数据，请输入“IMSI”或“MSISDN”与“用户个数”的组合。
- 若需要查询多个不连续用户的高价值业务数据，请输入“IMSI文件名”或“MSISDN文件名”。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                  |
|:------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 可选必选说明：条件可选参数 参数含义：用于标识系统需要查询哪个IMSI号码的用户的高价值业务数据。 取值范围：6～15位十进制数字组成的字符串 默认值：无。 配置原则：无。                                                                                                                                                |
| ISDN        | MSISDN    | 可选必选说明：条件可选参数 参数含义：用于标识系统需要查询哪个MSISDN号码的用户的高价值业务数据。 取值范围：1～15位十进制数字组成的字符串 默认值：无。 配置原则：无。                                                                                                                                              |
| RECORDCOUNT | 用户个数      | 可选必选说明：条件可选参数 参数含义：用于标识系统需要查询连续多少个高价值用户的业务数据。 取值范围：1～10000 默认值：无。 配置原则： 该参数是对连续号码的多个用户进行高价值业务数据查询，当只有一个用户时，该参数不必配置。 当一次查询的用户个数很多时，对系统性能无影响，但查询的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。                                                           |
| IMSIFILE    | IMSI文件名   | 可选必选说明：条件可选参数 参数含义：用于标识待查询高价值业务用户的IMSI批操作文件。 取值范围：1～16个由字母、数字、下划线和“.”组成的字符串 默认值：无。 配置原则：IMSI批操作文件包含多个不连续的待查询的高价值业务用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modsmsfinfo.txt”。通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。         |
| ISDNFILE    | MSISDN文件名 | 可选必选说明：条件可选参数 参数含义：用于标识待查询高价值业务用户的MSISDN批操作文件。 取值范围：1～16个由字母、数字、下划线和“.”组成的字符串 默认值：无。 配置原则：MSISDN批操作文件包含多个不连续的待查询的高价值业务用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modsmsfinfo.txt”。通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见MSISDNFILE文件格式。 |

## 使用实例

1. 查询IMSI号码为“460030913121001”的用户的高价值业务数据。

   ```
   LST GJZ: IMSI="460030913121001";
   ```

   ```
   %%LST GJZ: IMSI="460030913121001";%%
   RETCODE = 0 SUCCESS0001:操作成功

                             IMSI = 460030913121001
                             ISDN = 13310911001
                             PROV = TRUE

   Total count = 3

   There is together 1 report

   ---    END
   ```
2. 查询第一个MSISDN号码为“13310911001”的高价值业务数据。

   ```
   LST GJZ: ISDN="13310911001";
   ```

   ```
   %%LST GJZ: ISDN="13310911001";%%
   RETCODE = 0 SUCCESS0001:操作成功

                             IMSI = 460030913121001
                             ISDN = 13310911001
                             PROV = TRUE

   Total count = 3

   There is together 1 report

   ---    END
   ```
3. 查询第一个MSISDN号码为“13310911001”的连续3个用户的高价值业务数据。

   ```
   LST GJZ: ISDN="13310911001", RECORDCOUNT=3;
   ```

   ```
   %%LST GJZ: ISDN="13310911001", RECORDCOUNT=3;%%
   RETCODE = 0 SUCCESS0001:操作成功 批操作ID：7. 使用CHK BATSTAT指令可查看此批操作的执行情况

   There is together 1 report

   ---    END
   ```
4. 查询“MSISDN文件名”为“lstgjz.txt”的用户的高价值业务数据。

   ```
   LST GJZ: ISDNFILE="lstgjz.txt";
   ```

   ```
   %%LST GJZ: ISDNFILE="lstgjz.txt";%%
   RETCODE = 0 SUCCESS0001:操作成功 批操作ID：268435464. 使用CHK BATSTAT指令可查看此批操作的执行情况

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**MOD GJZ**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| ERR1005 | 文件未找到      | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                   | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                      |
