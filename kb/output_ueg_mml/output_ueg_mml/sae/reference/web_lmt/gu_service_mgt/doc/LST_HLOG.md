# 查询操作日志(LST HLOG)

## 命令功能

该命令用于查询HSS业务操作日志记录：

- 若需要查询全部已执行命令操作记录，请直接执行该命令无需输入任何参数。
- 若需要查询某些已执行命令操作记录，请输入其他参数或这些参数的组合。

## 注意事项

- 查询日志操作主要用于日志审计，将不可避免涉及用户的个人信息，如IMSI、MSISDN等。因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护。例如：
  1. 采用安全的文件传输协议（如SFTP）传输文件。
  2. 严格控制文件的访问权限。
  3. 及时清理数据文件。

  在从运营商网络获取数据前，必须要获得运营商的授权。

  若需从运营商网络中获取必要的数据，需要运营商维护人员对其中的个人数据进行匿名化处理，匿名化后的数据由运营商维护人员审核后提供，以防止个人数据泄露。匿名化处理工具可以在http://support.huawei.com/网站获取，获取方法请参见产品手册“匿名化工具安全策略”页面。
- “开始时间”和“结束时间”必须同时指定或同时不指定，并且“开始时间”时间点要早于“结束时间”。
- 如果输入的“是否包含批操作命令”为“NO”，则不能输入“批操作任务ID”。
- 如果“保存文件名”参数没有输入值，则不会保存为文件，查询结果显示在“PGW Web LMT”界面上，最大记录数为150条操作日志。
- 如果“保存文件名”参数有输入值，则会保存为文件，文件中保存的操作日志最大记录数为1000000条，所保存的文件，可以通过“PGW Web LMT”界面右上角的“文件管理器”下载。

## 参数说明

| 参数标识            | 参数名称        | 参数说明                                                                                                                                                                                                               |
|:----------------|:------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OPNAME          | 操作员名称       | 用于指示系统需要按照哪个“操作员名称”来查询操作日志；若不输入，则表示查询所有的“操作员名称”的操作日志。 取值范围：不超过32位的字符串，由数字和字母组成，且首字符必须为字母。 缺省值：无。 说明：可选参数。                                                                                                          |
| SUBID           | SUBID       | 用于指示系统需要按照指定的“SUBID”来查询操作日志；若不输入，则表示查询所有的“SUBID”的操作日志。 取值范围：长度不超过127的字符串。 默认值：无。 说明：可选参数。                                                                                                                          |
| IMPI            | IMPI        | 用于指示系统需要按照指定的“IMPI”来查询操作日志；若不输入，则表示查询所有的“IMPI”的操作日志。 取值范围：长度不超过127的字符串。 默认值：无。 说明：可选参数。                                                                                                                            |
| IMPU            | IMPU        | 用于指示系统需要按照指定的“IMPU”来查询操作日志；若不输入，则表示查询所有的“IMPU”的操作日志。 取值范围：长度不超过127的字符串。 默认值：无。 说明：可选参数。                                                                                                                            |
| IMSI            | IMSI        | 用于指示系统需要按照指定的“IMSI”来查询操作日志；若不输入，则表示查询所有的“IMSI”的操作日志。 取值范围：6–15。 默认值：无。 说明：可选参数。                                                                                                                                    |
| ISDN            | MSISDN      | 用于指示系统需要按照指定的“MSISDN”来查询操作日志；若不输入，则表示查询所有的“MSISDN”的操作日志。 取值范围：长度不超过15的字符串。 默认值：无。 说明：可选参数。                                                                                                                         |
| STARTTIME       | 开始时间        | 用于指示系统需要按照指定的“开始时间”来查询操作日志；若不输入，则表示查询所有时间的操作日志。 取值范围：为19位的字符串，“YYYY&MM&DD&HH&MM&SS”的字符串。 默认值：无。 说明：可选参数。                                                                                                           |
| ENDTIME         | 结束时间        | 用于指示系统需要按照指定的“结束时间”来查询操作日志；若不输入，则表示查询所有时间的操作日志。 取值范围：为19位的字符串，“YYYY&MM&DD&HH&MM&SS”的字符串。 默认值：无。 说明：可选参数。                                                                                                           |
| CMD             | 命令名称        | 用于指示系统需要按照指定的“命令名称”来查询操作日志；若不输入，则表示查询所有“命令名称”的操作日志。 取值范围：不超过20位的字符串。 默认值：无。 说明：可选参数。                                                                                                                               |
| RESULT          | 执行结果        | 用于指示系统需要按照指定的“执行结果”来查询操作日志；若不输入，则表示查询所有“执行结果”的操作日志。 取值范围：ERROR：表示操作失败的操作日志。SUCCESS：表示操作成功的操作日志。 默认值：无。 说明：可选参数。                                                                                                    |
| MSGTYPE         | 消息类型        | 用于指示系统需要按照指定的“消息类型”来查询操作日志；若不输入，则表示查询所有“消息类型”的操作日志。 取值范围：MMLSOAPMAP 默认值：无。 说明：可选参数。                                                                                                                                |
| SAVEAS          | 保存文件名       | 用于指示系统需要按照指定的“保存文件名”来保存操作日志到文件。 取值范围：不超过20位的字符串。 默认值：无。 说明：可选参数。                                                                                                                                                   |
| INCLUDEBAT      | 是否包含批操作命令   | 用于指示系统是否需要在查询的操作日志中包含批操作任务中执行的命令。如果查询时该参数取值为“YES”，则查询的结果中包含批操作中执行的命令。如果查询时该参数取值“NO”，则查询的结果中不包含批操作中执行的命令。如果查询时该参数不输入，则需看“批操作任务ID”是否有输入：如果有输入，则包括此批操作任务中执行的命令；否则不包含批操作任务中执行的命令。 取值范围：NOYES 默认值：无。 说明：可选参数。           |
| TASKID          | 批操作任务ID     | 用于指示系统按照指定的“批操作任务ID”来查询操作日志。如果查询时该参数不输入，则需看“否包含批操作命令”是否有输入。如果有输入且为“YES”，查询的结果中包含所有批操作中执行的命令；否则查询的结果中不包含批操作中执行的命令。如果查询时该参数有输入，则查询的结果中包含此批操作任务中执行的命令。 可以使用CHK BATSTAT命令来查询批操作任务ID。 取值范围：1～2147483647 默认值：无。 说明：可选参数。 |
| DISPLAYOPRLOGIP | 是否显示IP和端口信息 | 用于指示系统是否需要在查询的操作日志中显示执行命令的客户端的IP和端口号。如果查询时该参数取值为“YES”，则查询的结果中显示操作日志的IP和端口信息。如果查询时该参数取值“NO”或者该参数未输入，则查询的结果中不显示操作日志的IP和端口信息。 取值范围：NOYES 默认值：无。 说明：可选参数。                                                              |
