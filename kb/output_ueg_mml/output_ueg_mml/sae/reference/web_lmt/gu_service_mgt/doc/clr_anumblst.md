# 清理主叫号码黑名单（CLR ANUMBLST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于清理精确类型的主叫号码黑名单垃圾数据。系统根据“存储模式”参数取值判断清理哪个模块中的黑名单记录数据。

## 注意事项

- 该命令仅在特定局点使用，其他局点不需要配置。
- 混合组网场景下，**SET MAPCONF**命令中“是否支持主叫黑名单精确记录存储DSU”为“TRUE”时，该命令仅支持在路由分区执行，非路由分区下执行该命令上报错误码“ERR3111:系统不支持该特性”。

## 参数说明

| 参数标识          | 参数名称   | 参数说明                                           |
|:--------------|:-------|:-----------------------------------------------|
| HLRSN         | HLR序列号 | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。   |
| CALLINGNUMBER | 主叫号码   | 标识主叫号码黑名单记录的关键字段之一，用于指定删除哪个号码的主叫号码黑名单记录。       |
| STOREMODE     | 存储模式   | 用于标识删除哪个模块内的主叫号码黑名单记录。 取值范围： BOTHDRU DSU 默认值：无 |

## 使用实例

删除一条“HLR序列号”为“1”，“主叫号码”为“8613310911001”的黑名单记录：

```
CLR ANUMBLST: HLRSN=1, CALLINGNUMBER="8613310911001", STOREMODE=DSU;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释    | 原因分析                                                             | 处理建议                                                               |
|:--------|:---------|:-----------------------------------------------------------------|:-------------------------------------------------------------------|
| ERR3007 | 记录不存在    | 指定的“主叫号码”和“存储模式”没有匹配的精确类型的黑名单记录。                                 | 执行LST ANUMBLST命令查询已存在的记录，根据实际情况，重新输入精确类型的“主叫号码”和“存储模式”，删除对应的垃圾记录。  |
| ERR3111 | 系统不支持该特性 | 混合组网场景下，SET MAPCONF命令中“是否支持主叫黑名单精确记录存储DSU”为“TRUE”时，在非路由分区下执行该命令。 | 混合组网场景下，SET MAPCONF命令中“是否支持主叫黑名单精确记录存储DSU”为“TRUE”时，该命令仅支持在路由分区下执行。 |
