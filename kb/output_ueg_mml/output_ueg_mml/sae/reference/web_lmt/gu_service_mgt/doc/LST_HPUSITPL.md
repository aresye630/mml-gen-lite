# 查询PUSI基本信息模板(LST HPUSITPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询一个PUSI基本信息模板记录，一次只能查询一个PUSI基本信息模板记录，需要输入唯一标识该数据记录的关键参数PUSI模板ID。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                           |
|:-------|:---------|:-----------------------------------------------------------------------------------------------|
| TPLID  | PUSI模板ID | 可选必选说明：必选参数 参数含义：用于指示系统需要按照哪个PUSI模板ID来查询PUSI基本信息模板数据，一次只能查询一个PUSI基本信息模板的数据。 取值范围： 0～254 缺省值： 无 |

## 使用实例

查询PUSI基本信息模板。PUSI模板ID：10。

```
LST HPUSITPL: TPLID=10;
```

## 输出结果说明

| 参数标识     | 参数说明              |
|:---------|:------------------|
| TPLNAME  | 显示PUSI模板名称。       |
| AS       | 显示PUSI模板的AS地址。    |
| BAR      | 显示PUSI模板的闭锁标志。    |
| ACTSTATE | 显示PUSI模板的激活状态。    |
| SERPRVID | 显示PUSI模板的服务提供商标识。 |
| LRI      | 显示PUSI模板的松路由指示。   |
| COMMENT  | 显示PUSI模板的模板注释说明。  |
