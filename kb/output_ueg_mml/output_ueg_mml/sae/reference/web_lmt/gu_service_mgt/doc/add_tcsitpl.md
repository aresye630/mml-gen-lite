# 增加T-CSI模板(ADD TCSITPL)

## 命令功能

该命令用于为HLR在配置数据库中增加一条T-CSI（Terminating CAMEL Subscription Information）模板数据记录，根据运营商CAMEL网络的实际情况进行配置，相关参数由运营商提供。用户通过签约T-CSI模板ID签约T-CSI业务。

T-CSI是被叫CAMEL签约信息，在移动用户做被叫的SRI流程，T-CSI数据由HLR传递给GMSC，T-CSI智能业务将被触发。

相对于呼叫普通用户，呼叫签约T-CSI模板的CAMEL用户时，GMSC将向用户归属HLR发起两次SRI（Send Routing Information）请求消息，HLR在第一次SRI响应消息中返回T-CSI数据，然后GMSC在第二次SRI请求消息中带上抑制T-CSI信元（即suppress-T-CSI），HLR检查到该信元后才向用户当前所在VLR取漫游号码，并在第二次SRI响应消息中返回取到的漫游号码。

## 注意事项

- 该命令只能给一个模板增加一个DP值的触发准则，如果需要增加多个DP值的触发准则，请执行**MOD TCSITPL**命令。
- 系统中增加的T-CSI模板记录数不能超过5000条。

## 使用实例

增加T-CSI模板数据记录，“HLR序列号”为“1”，“模板ID”为“2”，“模板名”为“TCSITPL”，“CAMEL业务处理能力”为“PHASE3”，“DP值”为“TAA”，“SCP地址”为“8613911111”，“业务键”为“12”，“缺省呼叫处理”为“continueCall”，“基本业务码”为“TS11、TS12、TS21、TS22”，GMSC的处理方式采用参数表中第一项：

```
ADD TCSITPL: HLRSN=1, TPLID=2, TPLNAME="TCSITPL", CAMEL=PHASE3, DP=TAA, GSMSCFADD="8613911111", SK=12, DEFCALL=continueCall, BASCODE1=TS11, BASCODE2=TS12, BASCODE3=TS21, BASCODE4=TS22, WITHINTERAGRE_SUPCAMEL=ReturnT-CSI, WITHOUTINTERAGRE_SUPCAMEL=ReturnT-CSI, HPLMNINTER_SUPCAMEL=ReturnT-CSI, WITHINTERAGRE_SUPLPCAMEL=ReturnLPT-CSI, WITHOUTINTERAGRE_SUPLPCAMEL=ReturnLPT-CSI, HPLMNINTER_SUPLPCAMEL=ReturnLPT-CSI, WITHINTERAGRE_NOTSUPCAMEL=AllowMTCall, WITHOUTINTERAGRE_NOTSUPCAMEL=AllowMTCall, HPLMNINTER_NOTSUPCAMEL=AllowMTCall;
```
