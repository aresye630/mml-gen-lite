# 删除NT-U-CSI模板(RMV NTUCSITPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中删除一条NT-U-CSI模板数据记录。

## 注意事项

当执行该命令删除NT-U-CSI模板时，如果已执行**ADD TPLSUB**命令关联该模板时，系统会提示“ERR3005:模板已经被使用”的错误信息，该NT-U-CSI模板不能被删除。如果要删除该NT-U-CSI模板，必须先执行**MOD SUBTPL**命令在开户模板中删除对应的NT-U-CSI模板。

## 参数说明

| 参数标识   | 参数名称         | 参数说明                                                                                |
|:-------|:-------------|:------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号       | 标识一条NT-U-CSI模板数据记录的关键字段之一，用于标识需要删除哪一条NT-U-CSI模板数据记录，可以使用LST HLRSN命令查询获得。 默认值：无。     |
| TPLID  | NT-U-CSI模板ID | 标识一条NT-U-CSI模板数据记录的关键字段之一，用于标识需要删除哪一条NT-U-CSI模板数据记录，可以使用LST NTUCSITPL命令查询获得。 默认值：无。 |

## 使用实例

删除“HLR序列号”为“1”的HLR上的NT-U-CSI模板数据记录。其中，“NT-U-CSI模板ID”为“3”：

```
RMV NTUCSITPL: HLRSN=1, TPLID=3;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                         | 处理建议                                                                                                                                               |
|:--------|:--------|:---------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 输入的参数取值不在其取值范围内。                             | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                                   |
| ERR3003 | 模板未定义   | “HLR序列号”和“NT-U-CSI模板ID”对应的NT-U-CSI模板数据记录不存在。 | 根据实际情况，重新输入参数“HLR序列号”或“NT-U-CSI模板ID”，确保“HLR序列号”和“NT-U-CSI模板ID”对应的NT-U-CSI模板数据记录存在，可使用LST NTUCSITPL命令进行查询。                                          |
| ERR3005 | 模板已经被使用 | 已执行ADD SUBTPL命令关联该NT-U-CSI模板。                | 根据实际情况，确定要删除该NT-U-CSI模板，处理步骤：执行MOD SUBTPL命令，设置参数“是否提供NT-U-CSI模板”的值为“FALSE”，并输入参数“NT-U-CSI模板ID”，在开户模板中删除该NT-U-CSI模板。执行RMV NTUCSITPL命令删除该NT-U-CSI模板。 |
