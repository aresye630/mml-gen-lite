## 命令功能

该命令用于在HLR中增加一个业务下发模板。

业务下发模板服务于VLR/SGSN区域漫游限制业务、PLMN区域漫游业务和Diameter漫游限制业务，以上业务会根据运营商、网络或用户的要求，对用户移动性进行管理，设置用户允许漫游的范围。

- VLR/SGSN区域漫游限制业务通过命令**MOD VSRR**签约，在签约时需要引用VLR/SGSN漫游限制模板，VLR/SGSN漫游限制模板由命令**ADD VSLIST**进行定义，在定义VLR/SGSN漫游限制模板时，需要引用业务下发模板。在业务下发模板中设置了当用户漫游到特定的VLR/SGSN区域后下发哪些业务。
- PLMN区域漫游业务通过命令**MOD PLMNRSZI**签约，在签约时需要引用PLMN区域漫游模板，PLMN区域漫游模板由命令**ADD PLMNTPL**进行定义，在定义PLMN区域漫游模板时，需要引用业务下发模板。在业务下发模板中设置了当用户漫游到特定的PLMN区域后下发哪些业务。
- Diameter漫游限制业务通过命令**MOD DIAMRRS**签约，在签约时需要引用DIAMRR模板ID，DIAMRR模板ID由命令**ADD DIAMRRTPL**进行定义，在定义DIAMRR模板ID时，需要引用业务下发模板。在业务下发模板中设置了当用户漫游到特定的Diameter漫游区域后下发哪些业务。

## 注意事项

- “增强用户类别”和“下发业务列表”参数为条件可选参数，至少要有一个参数出现。
- 如果参数“下发业务列表”为“OPTGPRS”时，参数“优化GPRS模板ID”是必选参数。
- 如果参数“下发业务列表”为“BAOC”、“BAIC”、“BOICEXHC”或“BOIC”时，参数“基本业务组”是必选参数。
- 如果参数“下发业务列表”为“CLIR”时，参数“CLIR限制模式”和“基本业务组”是必选参数。
- 如果参数“下发业务列表”为“ODBECT”时，参数“ODB-闭锁显式呼叫转移业务”是必选参数。
- 系统中增加的业务下发模板记录数不能超过3000条。
- 参数“下发业务列表”为“BAIC”时，漫游用户的BAIC业务会生效，但在用户做被叫的流程中不下发BAIC业务。

## 使用实例

签约VLR/SGSN区域漫游限制业务，需要配置以下数据：

1. 增加业务下发模板，“HLR序列号”为“1”，“模板ID”为“1”，“模板名”为“TEST”，“下发业务列表”为“BAIC”，“基本业务组”为“TS1X”，命令如下：

   ```
   ADD RSITPL: HLRSN=1, TPLID=1, TPLNAME="TEST", SERCODE=BAIC, BSG=TS1X;
   ```
2. 执行**ADD VSLIST**命令给用户增加VLR/SGSN漫游限制模板，命令如下：

   ```
   ADD VSLIST: HLRSN=1, TPLID=1, TPLNAME="VSLIST", TPLTYPE=VLR, VLRSGSNNO="8613900001", ROAMRULE=CUSTOMIZED, RSITPLID=1, ROAMDEFAULTRULE=PERMISSION, SUPERARD=TRUE, GERANNOTALLOWED=TRUE, UTRANNOTALLOWED=TRUE;
   ```
3. 执行**MOD VSRR**命令给用户签约VLR/SGSN漫游限制业务，命令如下：

   ```
   MOD VSRR: IMSI="20140815", PROV=TRUE, TPLTYPE=VLR, TPLID=1;
   ```
