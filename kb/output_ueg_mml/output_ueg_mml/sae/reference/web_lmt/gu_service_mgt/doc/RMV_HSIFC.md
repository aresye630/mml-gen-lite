# 删除共享iFC(RMV HSIFC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于从HSS的业务数据库中删除指定的共享iFC数据记录。

## 注意事项

“IMPU”和“PUSI”必须存在且只能存在一个。

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                                                                                                         |
|:-------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------|
| IMPU   | IMPU      | 标识一条指定“IMPU”的共享iFC数据记录的关键字段之一，用于指定需要删除哪一个“IMPU”的共享iFC数据记录。该参数的配置原则是：要求输入的IMPU值符合SIP URI或TEL URI格式，字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。 |
| PUSI   | PUSI      | 标识一条指定“PUSI”的共享iFC数据记录的关键字段之一，用于指定需要删除哪一个“PUSI”的共享iFC数据记录。该参数的配置原则是：要求输入的PUSI值符合SIP URI或TEL URI格式，字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。 |
| SIFCID | 共享iFC模板ID | 标识一条指定“IMPU”或“PUSI”的共享iFC数据记录的关键字段之一，用于指定需要删除指定“IMPU”或“PUSI”的哪一条共享iFC数据记录。该参数必须先由ADD HSIFCTPL命令定义，然后才能在此处引用。 说明：必选参数。                        |

## 使用实例

删除共享iFC，“IMPU”为“sip:impuinfo@huawei.com”，“共享iFC模板ID”为“10”：

```
RMV HSIFC: IMPU="sip:impuinfo@huawei.com", SIFCID=10;
```
