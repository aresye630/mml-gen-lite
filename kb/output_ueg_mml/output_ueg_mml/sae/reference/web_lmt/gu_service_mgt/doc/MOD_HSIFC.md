# 修改共享iFC(MOD HSIFC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在HSS的业务数据库中修改指定“IMPU”或者“PUSI”相关的Service Profile所包含的某个共享iFC的信息。在该命令中，系统通过以下关键参数的组合来唯一标识一条共享iFC数据记录：

- “IMPU”或“PUSI”
- “OSIFCID”

## 注意事项

- “IMPU”和“PUSI”必须存在且只能存在一个。
- 执行该命令会触发PPR消息。

## 参数说明

| 参数标识    | 参数名称        | 参数说明                                                                                                                                                                                        |
|:--------|:------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMPU    | IMPU        | 标识一条iFC数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪一个“IMPU”的共享iFC进行修改或调整，操作员可以使用LST HSUB命令查询获得。该参数的配置原则是：要求输入的IMPU值符合SIP URI或TEL URI格式，字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。                         |
| PUSI    | PUSI        | 标识一条iFC数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪一个“PUSI”的共享iFC进行修改或调整，操作员可以使用LST HPSI命令查询获得。该参数的配置原则是：要求输入的PUSI值符合SIP URI或TEL URI格式，字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。                         |
| OSIFCID | 共享iFC模板ID   | 标识一条iFC数据记录的关键字段之一，用于指定需要对指定“IMPU”或“PUSI”的哪一个共享iFC模板进行修改或调整，操作员可以使用LST HTPLINF命令查询获得。 说明：必选参数。                                                                                              |
| NSIFCID | 新的共享iFC模板ID | 用于指定新的共享iFC模板的索引，该参数必须先由ADD HSIFCTPL命令定义，然后才能在此处索引。 取值范围：0～65535 默认值：无 说明： 必选参数。当通过SET HSYSTEMPARA命令设置“USINGHLRSNFORIMS（是否启用IMS-HSS的分权分域功能）”软参为“TRUE(TRUE)”时，该参数需要引用用户签约的“HLR序列号”下的共享iFC模板。 |

## 使用实例

修改共享iFC，“IMPU”为“sip:impuinfo@huawei.com”，“共享iFC模板ID”为“10”，“新的共享iFC模板ID”为“11”：

```
MOD HSIFC: IMPU="sip:impuinfo@huawei.com", OSIFCID=10, NSIFCID=11;
```
