# 删除数据变更通知分发的规则(RMV NOTIFYRULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成CPU和网络信令负荷过载现象，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在UDM中删除数据变更通知分发规则的数据记录信息。

## 注意事项

该命令用于FE适配BE新的MCI订阅通知机制，删除数据变更通知分发规则的数据记录信息会影响BE发送订阅通知消息的目的端、FE局点的CPU使用和网络信令负荷，操作时请谨慎执行。

## 参数说明

| 参数标识          | 参数名称         | 参数说明                                                                                                 |
|:--------------|:-------------|:-----------------------------------------------------------------------------------------------------|
| RULE_TYPE     | 分发类型         | 标识数据变更通知分发规则数据记录的关键字段之一，用于指定需要删除哪一种分发类型的数据记录信息，操作员可以使用LST NOTIFYRULE命令查询获得。                          |
| OPTYPE        | 操作类型         | 用于标识需要进行哪种删除操作。 取值范围： ALL（1）：删除当前类型的所有规则数据记录信息。SINGLE（0）：删除当前类型的单条规则数据记录信息。 默认值：无。                   |
| HLRSN         | HLR序列号       | 仅当“分发类型”参数取值为“HLRSN”时该参数有效，标识数据变更通知分发规则数据记录的关键字段之一，用于指定需要删除哪一个HLR序列号对应的数据变更通知分发规则的数据记录信息。            |
| IMSI_PREFIX   | IMSI前缀       | 仅当“分发类型”参数取值为“IMSI_PREFIX”时该参数有效，标识数据变更通知分发规则数据记录的关键字段之一，用于指定需要删除哪一个IMSI号码段对应的数据变更通知分发规则的数据记录信息。     |
| MSISDN_PREFIX | MSISDN前缀     | 仅当“分发类型”参数取值为“MSISDN_PREFIX”时该参数有效，标识数据变更通知分发规则数据记录的关键字段之一，用于指定需要删除哪一个MSISDN号码段对应的数据变更通知分发规则的数据记录信息。 |
| PI_PREFIX     | IMPI或者PISI前缀 | 仅当“分发类型”参数取值为“PI_PREFIX”时该参数有效，标识数据变更通知分发规则数据记录的关键字段之一，用于指定需要删除哪一个IMPI或者PISI号码段对应的数据变更通知分发规则的数据记录信息。 |
| PU_PREFIX     | IMPU或者PUSI前缀 | 仅当“分发类型”参数取值为“PU_PREFIX”时该参数有效，标识数据变更通知分发规则数据记录的关键字段之一，用于指定需要删除哪一个IMPU或者PUSI号码段对应的数据变更通知分发规则的数据记录信息。 |
| SUBID_PREFIX  | SUBID前缀      | 仅当“分发类型”参数取值为“SUBID_PREFIX”时该参数有效，标识数据变更通知分发规则数据记录的关键字段之一，用于指定需要删除哪一个SUBID号码段对应的数据变更通知分发规则的数据记录信息。   |

## 使用实例

1. 删除“分发类型”为“HLRSN”对应的所有数据变更通知分发规则的数据记录信息，“操作类型”为“ALL”，命令如下：

```
RMV NOTIFYRULE: RULE_TYPE=HLRSN, OPTYPE=ALL;
```

2. 删除“分发类型”为“HLRSN”的单条数据变更通知分发规则的数据记录信息，“操作类型”为“SINGLE”，“HLR序列号”为“1”，命令如下：

```
RMV NOTIFYRULE: RULE_TYPE=HLRSN, OPTYPE=SINGLE, HLRSN=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                                         | 处理建议                                                                |
|:--------|:--------|:-------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 用户输入的“IMSI前缀”、“MSISDN前缀”、“IMPI或者PISI前缀”、“IMPU或者PUSI前缀”或“SUBID前缀”参数不符合取值范围。                                   | 参考参数说明，重新输入取值范围内的参数值。                                               |
| ERR3007 | 记录不存在   | 原因可能有以下两种： 当“操作类型”取值为“ALL”时，需要删除的“分发类型”下无任何数据信息记录。当“操作类型”取值为“SINGLE”时，需要删除的“分发类型”对应的前缀号码或HLR序列号参数未添加过数据信息记录。 | 请按照以下步骤操作： 执行LST NOTIFYRULE命令查询需要查询的“分发类型”对应的数据记录信息。根据查询结果重新执行删除操作。 |
