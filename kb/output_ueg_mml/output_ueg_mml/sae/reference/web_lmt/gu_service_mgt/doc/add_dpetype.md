# 增加Diameter对端类型(ADD DPETYPE)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使用户漫游到此Diameter对端区域后可能出现位置更新失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在UDM中增加MME/S4SGSN相对于本地UDM的位置信息。

当用户漫游到一个MME/S4SGSN区域时，用户归属UDM判断用户是通过MME还是S4SGSN发起的位置更新，该位置更新信息中包含本命令定义的Diameter对端主机名和域名，并据此判断Diameter对端（MME/S4SGSN）的网络类型，并将其记录在用户动态数据表中，对用户漫游数据进行上报。例如：当用户漫游的MME/S4SGSN为“国际本网”类型或者“国际跨网”类型时，该用户会被当做国际漫游用户进行统计并上报给网元管理系统。

## 注意事项

- 该命令不允许进行批操作。
- 同一个“HLR序列号”中增加的Diameter对端类型的记录数不能超过500条。

## 参数说明

| 参数标识           | 参数名称               | 参数说明                                                                                                                                                                                            |
|:---------------|:-------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN          | HLR序列号             | 用于标识HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                      |
| PEERENTITYTYPE | 对端身份标识类型           | 用于标识对端Diameter身份标识类型。 取值范围： Host Name：主机名，表示通过Diameter服务节点设备的主机名进行身份标识。Realm Name：域名，表示通过Diameter服务节点所在域的域名进行身份标识。 默认值：无。                                                                       |
| PEERENTITY     | 对端身份标识             | 用于标识对端Diameter身份标识，该标识唯一确定一个Diameter服务节点。 取值范围：1～127位字符组成的相对域名格式字符串。 默认值：无。                                                                                                                     |
| PEERNAME       | 对端实体的名称            | 用于标识对端实体的名称。 取值范围：1～30位的字符串。 默认值：无。                                                                                                                                                             |
| TYPE           | 业务属性               | 用于标识对端实体相对于本UDM所属的网络类型。关于网络类型划分可参考VLR和本地HLR的位置关系示意图。 取值范围： LOCAL：本地。LOCALDOMESTIC：国内本网。CROSSDOMESTIC：国内跨网。LOCALINTERNATIONAL：国际本网。CROSSINTERNATIONAL：国际跨网。LOCALAREA：省内本网。CROSSAREA：省内跨网。 默认值：无。 |
| NETTYPE        | 网络类型               | 用于标识对端实体所在的网络是否支持VoLTE。 取值范围： VoLTE：支持VoLTE。NON_VoLTE：不支持VoLTE。 默认值：无。 说明：执行该命令并且不输入该参数时，系统会设置初始值为“VoLTE”。                                                                                      |
| MMENCCTPL      | MME实体对应的NCC模板ID    | 用于标识MME实体所使用的NCC模板号，指定MME实体的NCC模板能力。该参数必须先由ADD NCCTPL命令定义，然后才能在此处引用。 取值范围：0～99998 默认值：无。                                                                                                        |
| S4SGSNNCCTPL   | S4SGSN实体对应的NCC模板ID | 用于标识S4SGSN实体所使用的NCC模板号，指定S4SGSN实体的NCC模板能力。该参数必须先由ADD NCCTPL命令定义，然后才能在此处引用。 取值范围：0～99998 默认值：无。 说明：该参数取值可以与“MME实体对应的NCC模板ID”参数相同，也可以不同。                                                          |

## 使用实例

配置对端的闭锁漫游业务，该特性的数据配置流程如下:

1. 登录PGW Web LMT，执行该命令设置MME/S4SGSN相对于本UDM所属的网络类型，即MME/S4SGSN相对于本地UDM的位置信息。其中“HLR序列号”为“1”，“对端身份标识类型”为“Host Name”，“对端身份标识”为“test.huawei.com”，“对端实体的名称”为“test”，“业务属性”为“LOCAL”，“网络类型”为“NON\_VoLTE”，“MME实体对应的NCC模板ID”为“1”，“S4SGSN实体对应的NCC模板ID”为“1”:

   ```
   ADD DPETYPE: HLRSN=1, PEERENTITYTYPE=Host Name, PEERENTITY="test.huawei.com", PEERNAME="test", TYPE=LOCAL, NETTYPE=NON_VoLTE, MMENCCTPL=1, S4SGSNNCCTPL=1;
   ```
2. 设置是否控制用户在EPS网络中的漫游。执行**SET MAPCONF**命令设置“ODBROAM是否控制EPS域”参数为“TRUE”。

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                  | 处理建议                                                                                                                                                           |
|:--------|:--------|:------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”参数不在相应的参数取值范围内。                         | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                                               |
| ERR3003 | 模板未定义   | “MME实体对应的NCC模板ID”或“S4SGSN实体对应的NCC模板ID”参数对应的模板数据记录不存在。 | 根据实际情况，重新输入参数，确保“MME实体对应的NCC模板ID”或“S4SGSN实体对应的NCC模板ID”参数对应的模板数据记录已存在。已存在的模板数据记录可以通过LST NCCTPL命令查询。                                                             |
| ERR3006 | 记录已存在   | 重复为同一个HLR序列号添加相同的Diameter对端。                          | 该Diameter对端已添加，根据实际情况确认是否需要添加其他的Diameter对端。                                                                                                                    |
| ERR3007 | 记录不存在   | “HLR序列号”未定义。                                          | 根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求。                                                                                                                              |
| ERR3047 | 超过最大限制  | 增加的Diameter对端实体记录数超过500条。                             | 根据实际情况，如需增加Diameter对端实体记录，处理步骤如下：执行LST DPETYPE命令，查询已存在Diameter对端实体记录。执行RMV DPETYPE命令，删除不必要的Diameter对端实体记录。执行该命令，增加的Diameter对端实体记录，确保增加后Diameter对端实体记录数在规定范围之内。 |
