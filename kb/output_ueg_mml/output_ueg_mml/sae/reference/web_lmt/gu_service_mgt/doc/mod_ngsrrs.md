## 命令功能

该命令用于在UDM中为用户提供或撤销基于5GS的漫游限制业务。5GS漫游限制业务会根据运营商、网络或用户的要求，对用户移动性进行管理，设置用户允许漫游的范围。

在通过该命令为用户签约5GS漫游限制业务之前，需要先用**ADD NGCRRAREATPL**命令定义NGC漫游限制区域模板，再通过**ADD NGCRRNODETPL**命令定义NGC漫游限制模板，最后通过该命令引用对应的模板为用户提供业务。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。
- “用户个数”必须与“IMSI”或“MSISDN”中的一个同时存在。

## 参数说明

| 参数标识         | 参数名称         | 参数说明                                                                                                                                                                                                                                                                |
|:-------------|:-------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI         | IMSI         | 可选必选说明：条件可选参数 参数含义：用于标识需要修改5GS漫游限制业务的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                               |
| ISDN         | MSISDN       | 可选必选说明：条件可选参数 参数含义：用于标识需要修改5GS漫游限制业务的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                             |
| RECORDCOUNT  | 用户个数         | 可选必选说明：条件可选参数 参数含义：用于标识需要修改5GS漫游限制业务数据的用户数目。 取值范围：1～100000 默认值：无。 配置原则：当需要为连续号码的多个用户修改5GS漫游限制业务数据时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户修改5GS漫游限制业务数据。该参数是对连续号码的多个用户修改5GS漫游限制业务数据，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |

| NGCNODETPLID | 5GS漫游限制模板ID  | 可选必选说明：条件可选参数 参数含义：用于标识5GS漫游限制模板号。该参数必须先由ADD NGCRRNODETPL命令定义，然后才能在此处引用。 取值范围：1～2147483646。 默认值：无。 配置原则：仅当本命令中的“提供或撤销5GS漫游限制”参数取值为“TRUE”时该参数有效。                                                                                                                     |

## 使用实例

1. 给IMSI号码为“46100009123456”的用户提供5GS漫游限制业务，“提供或撤销5GS漫游限制”为“TRUE”，“5GS漫游限制模板ID”为“1”：

   ```
   MOD NGSRRS: IMSI="46100009123456", PROV=TRUE, NGCNODETPLID=1;
   ```
2. 给3个连续号码的用户提供5GS漫游限制业务数据，这3个MSISDN号码分别为“13310911001”、“13310911002”、“13310911003”，“用户个数”为“3”，“提供或撤销5GS漫游限制”为“TRUE”，“5GS漫游限制模板ID”为“1”：

   ```
   MOD NGSRRS: ISDN="13310911001", RECORDCOUNT=3, PROV=TRUE, NGCNODETPLID=1;
   ```
3. 给3个非连续号码的用户撤销5GS漫游限制业务，这3个MSISDN号码分别为“13310911001”、“13310911003”、“13310911005”，已保存在“MSISDN文件名”为“modngsrrs.txt”的文件中，并通过文件管理功能上传到指定目录，“提供或撤销5GS漫游限制”为“FALSE”：

   ```
   MOD NGSRRS: ISDNFILE="modngsrrs.txt", PROV=FALSE;
   ```

## 参考信息

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
