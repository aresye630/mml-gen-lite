# 删除SMSF数据（RMV SMSFINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条SMSF签约数据。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”参数同时配置。
- “用户个数”必须与“IMSI”或“MSISDN”参数中的一个同时存在。
- 执行该命令，将会导致用户的SMSF动态注册数据丢失，请谨慎执行。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                          |
|:------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 可选必选说明：条件可选参数 参数含义：用于指定需要删除哪一个用户的SMSF签约信息。 取值范围：6～15位十进制数字组成的字符串 默认值：无。 配置原则：无。                                                                                                                                                                               |
| ISDN        | MSISDN    | 可选必选说明：条件可选参数 参数含义：用于指定需要删除哪一个用户的SMSF签约信息。 取值范围：1～15位十进制数字组成的字符串 默认值：无。 配置原则：无。                                                                                                                                                                               |
| RECORDCOUNT | 用户个数      | 可选必选说明：条件可选参数 参数含义：用于指定需要删除从IMSI或者MSISDN对应的用户开始的SMSF签约数据的个数。 取值范围：1～100000 默认值：无。 配置原则： 当需要为连续号码的多个用户删除SMSF业务时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行删除SMSF业务。当只有一个用户时，该参数不必配置。 当一次删除SMSF业务的用户个数很多时，对系统性能无影响，但删除SMSF业务的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名   | 可选必选说明：条件可选参数 参数含义：用于指定需要删除的SMSF签约数据的IMSI批操作文件。 取值范围：1～35个由字母、数字、下划线和“.”组成的字符串 默认值：无。 配置原则：IMSI批操作文件包含多个不连续的需要删除的SMSF业务用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“rmvsmsfinfo.txt”。通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。                            |
| ISDNFILE    | MSISDN文件名 | 可选必选说明：条件可选参数 参数含义：用于指定需要删除的SMSF签约数据的MSISDN批操作文件。 取值范围：1～35个由字母、数字、下划线和“.”组成的字符串 默认值：无。 配置原则：MSISDN批操作文件包含多个不连续的需要删除的SMSF业务用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“rmvsmsfinfo.txt”。通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。                      |

## 使用实例

1. 删除一条SMSF签约信息，“IMSI”为“460000009123456”：

   ```
   RMV SMSFINFO: IMSI="460000009123456";
   ```
2. 删除3个连续用户的SMSF签约信息，“IMSI”为“460000009123456”、“460000009123457”、“460000009123458”：

   ```
   RMV SMSFINFO: IMSI="460000009123456", RECORDCOUNT=3;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                               | 处理建议                                                                                                                    |
|:--------|:--------|:---------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------|
| ERR1005 | 文件未找到   | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                   | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                      |
| ERR1009 | 参数丢失。   | “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数一个都没有输入。                                                  | 根据实际情况，重新输入参数，并满足“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                             |
| ERR1010 | 参数冲突    | 可能原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR3007 | 记录不存在。  | 输入的“IMSI”或“MSISDN”无对应的SMSF签约数据。                                                                    | 执行LST SMSFINFO命令查询SMSF签约数据，确认需要删除的“IMSI”或“MSISDN”对应的用户SMSF签约数据后执行本命令删除。                                                 |
