# 修改号码前缀和国家码数据(MOD NUMBERCCODE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于对一条号码前缀和国家码数据记录的某些参数进行修改或调整。在该命令中，系统通过“号码前缀”参数来唯一标识一条号码前缀和国家码数据记录。

## 注意事项

“国家码”和“描述”参数至少存在一个。

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                                                                    |
|:-------------|:-------|:----------------------------------------------------------------------------------------|
| NUMBERPREFIX | 号码前缀   | 标识一条号码前缀和国家码数据记录的关键字段（其取值不能被修改），用于指定需要对哪一个号码前缀对应的数据记录进行修改，操作员可以使用LST NUMBERCCODE命令查询获得。 |
| CCODE        | 国家码    | 用于标识国家代码信息。 取值范围：1～6位十进制数字组成的字符串。 默认值：无。                                                |
| DESCRIPTION  | 描述     | 用于描述号码前缀和国家码数据。 取值范围：长度不超过60位的字符串。 默认值：无。                                               |

## 使用实例

修改系统中与“号码前缀”为“1380270”匹配的“国家码”为“86”：

```
MOD NUMBERCCODE: NUMBERPREFIX="1380270", CCODE="86";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                 | 处理建议                                                     |
|:--------|:--------|:---------------------|:---------------------------------------------------------|
| ERR1009 | 参数丢失    | “国家码”和“描述”参数一个都没有输入。 | 根据实际情况，重新输入参数，并满足“国家码”和“描述”至少输入一个。                       |
| ERR3007 | 记录不存在   | 输入的“号码前缀”在数据库中不存在。   | 根据实际情况，重新输入参数，确保输入的“号码前缀”已在系统中存在。可执行LST NUMBERCCODE命令查询。 |
