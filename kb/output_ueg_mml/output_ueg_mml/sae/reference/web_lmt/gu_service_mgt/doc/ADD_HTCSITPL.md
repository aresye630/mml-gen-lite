# 增加T-CSI数据模板(ADD HTCSITPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于在HSS的业务数据库中增加一条T-CSI(Terminating CAMEL Subscription Information)模板数据记录。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称      | 参数说明                                                                                                                                                                                                   |
|:-----------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TPLID      | T-CSI模板ID | 可选必选说明：必选参数 参数含义：用于定义T-CSI数据模板的序号，以方便对T-CSI数据模板进行查询和引用，配置原则是不能与已有的T-CSI数据模板的模板ID重复。 取值范围： 0~254 默认值： 无                                                                                                 |
| TPLNAME    | T-CSI模板名称 | 可选必选说明：可选参数 参数含义：用于定义一个T-CSI数据模板名称，以便于识别。 取值范围： 长度不超过64的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值： 无                                                                                                            |
| GSMSCFADDR | gsmSCF地址  | 可选必选说明：必选参数 参数含义：用于在T-CSI数据模板中定义一个gsmSCF地址。gsmSCF地址用于路由寻址，采用E.164格式。不同的gsmSCF地址可以与不同的TDPs（Trigger Detection Point）相关。 取值范围： 长度不超过15的字符串 默认值： 无                                                         |
| SK         | 业务键       | 可选必选说明：必选参数 参数含义：用于在T-CSI数据模板中定义一个业务键。业务键即用户标识智能业务的编码。 取值范围： 0～2147483647 默认值： 无                                                                                                                       |
| DEFCALL    | 缺省呼叫处理    | 可选必选说明：必选参数 参数含义：用于在T-CSI数据模板中定义缺省呼叫处理类型。当gsmSSF与gsmSCF之间的对话出现差错或者呼叫受限时，缺省呼叫处理指示出对呼叫应给予释放还是继续。 取值范围： CONTINUECALL(CONTINUECALL)：gsmSCF指示gsmSSF继续呼叫。RELEASECALL(RELEASECALL)：gsmSCF指示gsmSSF释放呼叫。 默认值： 无 |
| IMSSF      | IM-SSF地址  | 可选必选说明：必选参数 参数含义：用于在T-CSI数据模板中新增一个IM-SSF地址。IM-SSF地址是为用户服务实现预付费的网元地址，用于对预付费网元进行路由寻址，IM-SSF地址采用E.164格式。 取值范围： 长度不超过15的字符串 默认值： 无                                                                         |
| COMMENT    | 模板注释说明    | 可选必选说明：可选参数 参数含义：用于在T-CSI数据模板中添加对T-CSI模板的注释说明。 取值范围： 长度不超过512的字符串 默认值： 无                                                                                                                               |

## 使用实例

增加T-CSI数据模板。T-CSI模板ID：10，T-CSI模板名称：T-CSI Template，gsmSCF地址：8613911111，业务键：4，缺省呼叫处理：呼叫继续，IM-SSF地址：831380755，模板注释说明：T-CSI Template For SET HCSI。

```
ADD HTCSITPL: TPLID=10, TPLNAME="T-CSI Template", GSMSCFADDR="8613911111", SK=4, DEFCALL=CONTINUECALL, IMSSF="831380755", COMMENT="T-CSI Template For SET HCSI";
```
