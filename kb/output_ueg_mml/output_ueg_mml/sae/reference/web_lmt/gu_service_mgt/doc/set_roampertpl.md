# 设置优选漫游模板（SET ROAMPERTPL）

- 命令功能
- 注意事项

- 输出结果说明

## 命令功能

该命令用于配置优选漫游模板中运营商的漫游比例，支持优选漫游模板中运营商漫游比例的增加，修改和删除。

UDM为漫游国家内的运营商提前配置不同的漫游比例，在接到漫游用户的位置更新请求后基于不同的漫游比例确定是否允许用户接入运营商网络。

## 注意事项

- 该命令只可以配置非本国网络。
- 漫游比例为0表示用户在需要位置更新时不进行优选网络比例判断。
- 同一分组下所有配置了的运营商漫游比例总和必须小于或等于100。
- 同一分组下最多允许配置10个运营商的漫游比例信息。
- 当需要位置更新的用户连续N次（通过该命令中“拒绝位置更新次数”参数配置）由于优选网络问题导致位置更新失败，则第N+1次不再因优选网络拒绝用户位置更新。
- “运营商1～10名称”需提前使用**SET ROAMPREFIX**命令配置。

## 使用实例

配置优选漫游模板中国家分组中运营商的漫游比例，参数取值如表1所示。

| 参数       | 值       |
|:---------|:--------|
| HLR序列号   | 1       |
| 模板ID     | 1       |
| 模板类型     | PS      |
| 分组ID     | 1       |
| 操作类型     | ADD     |
| 分组名称     | Group1  |
| 国家码      | 86      |
| 移动国家码    | 460     |
| 拒绝位置更新次数 | 5       |
| 运营商1名称   | Peking1 |
| 运营商1漫游比例 | 40      |
| 运营商2名称   | Peking2 |
| 运营商2漫游比例 | 30      |
| 运营商3名称   | Peking3 |
| 运营商3漫游比例 | 30      |

```
SET ROAMPERTPL: HLRSN=1, TPLID=1, TPLTYPE=PS, GRPID=1, OPTYPE=ADD, GRPNAME="Group1", CC="86", MCC="460", REJECTNUM=5, OPR1NAME="Peking1", OPR1ROAMPRO=40, OPR2NAME="Peking2", OPR2ROAMPRO=30, OPR3NAME="Peking3", OPR3ROAMPRO=30;
```

该命令执行正常，会返回命令执行成功的提示信息。
