## 命令功能

该命令用于为用户签约会话管理数据信息，当用户接入5G网络时必须签约会话管理数据。

## 注意事项

- 签约会话管理数据前必须通过**MOD AMDATA**命令签约接入和移动管理数据。
- 单用户所有S-NSSAI下最多签约50条DNN数据，每个S-NSSAI下最多签约50条DNN数据。
- 单个S-NSSAI下必须存在一个且只允许存在一个默认DNN数据，当新签约的DNN数据为默认DNN时，系统中已存在的默认DNN自动更新为非默认DNN。
- 同一用户的不同DNN数据中S-NSSAI、DNN不能够全部相同。
- 使用该命令为某个S-NSSAI签约的第一个DNN必须为默认DNN。
- 签约静态IP地址时，外部业务发放系统应确保IP地址的唯一性。
- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数必须有且只能有一个参数出现。
- “用户个数” 参数不能与“IMSI文件名”或“MSISDN文件名”同时存在，“用户个数”参数只能与“IMSI”或“MSISDN”一起出现。

## 使用实例

5G开户场景，为用户签约会话管理数据信息，“IMSI”为“460000009123456”，“切片标识”为“1-123456”，“数据网名称”为“dnn”，“5GS DNNQoS模板ID”为“1”，“是否默认DNN”为“FALSE”：

```
ADD SMDATA: IMSI="460000009123456", SNSSAI="1-123456", DNN="dnn", DNNQOSTPLID=1, DEFAULT=FALSE;
```

## 参考信息

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
