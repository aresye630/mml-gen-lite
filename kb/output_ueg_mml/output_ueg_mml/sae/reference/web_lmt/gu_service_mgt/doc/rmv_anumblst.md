# 删除主叫号码黑名单（RMV ANUMBLST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条主叫号码黑名单记录。

当本命令中“主叫号码类型”未设置，或设置为“NUMBER”时，系统通过与**SET MAPCONF**命令中“是否支持主叫黑名单精确记录存储DSU”参数配合使用对黑名单进行删除操作。

- 当“是否支持主叫黑名单精确记录存储DSU”为“FALSE”时，系统只访问并删除DRU中记录。
- 当“是否支持主叫黑名单精确记录存储DSU”为“TRUE”时，系统同时访问DRU和DSU中记录，若同时存在则同时删除记录。

**说明** 

系统不支持通过本命令单独访问并删除DSU中记录。

## 注意事项

- 该命令仅在特定局点使用，其他局点不需要配置。
- 如果操作员删除主叫号码黑名单中的一条记录，将对该主叫用户的呼叫权限有影响，请操作员慎重执行该操作。如果从主叫号码黑名单中删除期望不被接入的主叫号码，则该主叫用户的呼叫请求消息将被正常处理。
- 混合组网场景下，**SET MAPCONF**命令中“是否支持主叫黑名单精确记录存储DSU”为“TRUE”时，该命令仅支持在路由分区执行，非路由分区下执行该命令上报错误码“ERR3111:系统不支持该特性”。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识              | 参数名称   | 参数说明                                                              |
|:------------------|:-------|:------------------------------------------------------------------|
| HLRSN             | HLR序列号 | 标识主叫号码黑名单记录的关键字段之一，用于指定在哪个HLR上删除主叫号码黑名单记录，操作员可以使用LST HLRSN命令查询获得。 |
| CALLINGNUMBER     | 主叫号码   | 标识主叫号码黑名单记录的关键字段之一，用于指定删除哪个号码的主叫号码黑名单记录。                          |
| CALLINGNUMBERTYPE | 主叫号码类型 | 用于标识删除哪个匹配类型的主叫号码黑名单记录。 取值范围： NUMBER：精确类型PREFIX：前缀类型 默认值：NUMBER   |

## 使用实例

删除一条“HLR序列号”为“1”，“主叫号码”为“8613310911001”的黑名单记录：

```
RMV ANUMBLST: HLRSN=1, CALLINGNUMBER="8613310911001";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|:--------|:---------|:-----------------------------------------------------------------|:-------------------------------------------------------------------|
| ERR1004 | 无效的参数值   | 参数“主叫号码”的取值不是1～15位十进制数字组成的字符串。                                   | 根据实际情况，重新输入参数“主叫号码”的取值，确保其取值符合要求。                                  |
| ERR3007 | 记录不存在    | “HLR序列号”对应的“主叫号码”记录不存在。                                          | 使用LST ANUMBLST命令查询系统中已存在的记录，根据查询结果中存在的记录，重新输入“HLR序列号”和“主叫号码”参数值。   |
| ERR3111 | 系统不支持该特性 | 混合组网场景下，SET MAPCONF命令中“是否支持主叫黑名单精确记录存储DSU”为“TRUE”时，在非路由分区下执行该命令。 | 混合组网场景下，SET MAPCONF命令中“是否支持主叫黑名单精确记录存储DSU”为“TRUE”时，该命令仅支持在路由分区下执行。 |
