# 设置业务签约信息的签约媒体ID(SET HMEDIAID)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于在HSS的业务数据库中设置指定IMPU或PUSI相关Service Profile所包含的签约媒体信息。

## 注意事项

参数IMPU和参数PUSI必须存在且只能存在一个。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                       |
|:--------|:-------|:---------------------------------------------------------------------------------------------------------------------------|
| IMPU    | IMPU   | 用于指定一个需要设置签约媒体ID信息的IMPU，要求输入的IMPU值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无                                   |
| PUSI    | PUSI   | 用于指定一个需要设置签约媒体ID信息的PUSI，要求输入的PUSI值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无                                   |
| MEDIAID | 签约媒体ID | 用于指定一个需要设置签约媒体ID信息所要指定的签约媒体ID值，当MEDIAID取值为4294967295时，表示去掉此IMPU或PUSI关联的Service Profile的签约媒体ID信息。 取值范围： 0～4294967295 缺省值： 无 |

## 使用实例

设置业务签约信息的签约媒体ID。PUSI：sip:pusiinfo@huawei.com，签约媒体ID：4294967293。

```
SET HMEDIAID: PUSI="sip:pusiinfo@huawei.com", MEDIAID=4294967293;
```
