# 修改游牧模板(MOD HNATPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成用户注册失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在HSS的业务数据库中修改一个游牧模板的信息，可以修改除“NASS游牧模板ID”以外的所有参数。在该命令中，系统通过“NASS游牧模板ID”或“已有NASS游牧模板名称”来标识一个游牧模板，该参数可以通过使用**LST HTPLINF**命令查询获得。

## 注意事项

- “NASS游牧模板ID”参数和“已有NASS游牧模板名称”参数必须存在且仅能存在一个。
- 如果操作员在指定游牧模板中修改参数属性，则所有引用该模板的用户都会修改该属性，将可能导致用户注册失败，请操作员在执行该操作之前仔细确认任务的可行性。
- 使用该命令时，待修改的可选参数中必须设置其中至少一个，否则HSS返回失败。
- 不能通过**MOD HNATPL**命令，使“IPSEGMENT”与其他两种类型“FRONT”、“BACK”之间相互转换。
- 如果用户处于限制游牧状态，要放开用户的游牧权限，使用本命令将“缺省漫游限制策略”参数修改为“PERMISSION(Permission)”。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识        | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                                                                                                                               |
|:------------|:-------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TPLID       | NASS游牧模板ID   | 标识指定游牧模板的关键字段（其取值不能被修改），用于指定需要对哪一条游牧模板的参数进行修改或调整，操作员可以使用LST HTPLINF命令查询获得。 取值范围：0-67108863 默认值：无。 说明：可选参数。该参数为255表示无效值。                                                                                                                                                                                                                                                                            |
| OLDTPLNAME  | 已有NASS游牧模板名称 | 标识指定游牧模板的关键字段，用于指定需要对哪一条游牧模板的参数进行修改或调整，操作员可以使用LST HTPLINF命令查询获得。 取值范围：长度不超过64的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                         |
| TPLNAME     | 新NASS游牧模板名称  | 用于标识游牧模板修改后的名称。 取值范围：长度不超过64的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                                          |
| MATCHTYPE   | 匹配类型         | 用于标识指定游牧模板修改后的匹配类型。 取值范围： FRONT(Front)：表示前向匹配。前向匹配原则表示游牧地址只要前缀相同的都匹配。如果签约的游牧地址模板信息为HSS，则前缀为HSS的游牧地址都能匹配成功，例如携带的游牧地址为“HSS.com”。BACK(Back)：表示后向匹配。后向匹配原则表示游牧地址后缀相同的都匹配。如果签约的游牧地址模板信息为huawei.com，则后缀为huawei.com的游牧地址都能匹配成功，例如携带的游牧地址为“HSS.huawei.com”。CONTAIN(Contain)：表示包含匹配。即游牧地址只要包含该地址的都匹配。如果签约的游牧地址模板信息为HSS，则包含HSS的游牧地址都能匹配成功，例如携带的游牧地址为“huawei.HSS.com”、“HSS.com”、“huawei.HSS”。 默认值：无。 说明：可选参数。 |
| DEFAULTRULE | 缺省游牧限制策略     | 用于标识指定游牧模板修改后的缺省限制策略，当用户携带的接入位置信息与签约的游牧地址信息匹配失败时决策是否允许用户从此接入位置注册。 取值范围： PERMISSION(Permission)：表示IMS系统将允许用户注册。RESTRICTION(Restriction)：表示IMS系统将限制用户注册。 默认值：无。 说明：可选参数。                                                                                                                                                                                                                             |
| COMMENT     | 模板注释说明       | 用于标识指定游牧地址模板修改后的注释。 取值范围：长度不超过512的字符串 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                                                              |

## 使用实例

1. 修改游牧模板，“NASS游牧模板ID”为“10”，“新NASS游牧模板名称”为“07550011”：

   ```
   MOD HNATPL: TPLID=10, TPLNAME="07550011";
   ```
2. 修该游牧模板，“已有NASS游牧模板名称”为“Templet1”，“新NASS游牧模板名称”为“Templet2”，“匹配类型”为“FRONT(Front)”，“模板注释说明”为“NASS Nomadism Template”：

   ```
   MOD HNATPL: OLDTPLNAME="Templet1",TPLNAME="Templet2", MATCHTYPE=FRONT, COMMENT="NASS Nomadism Template";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释                             | 原因分析                                       | 处理建议                                                                         |
|----------:|:----------------------------------|:-------------------------------------------|:-----------------------------------------------------------------------------|
| 900003513 | 游牧模板匹配类型为IPSEGMENT时，不能修改匹配类型为包含匹配 | 将待修改的游牧模板的“匹配类型”取值“IPSEGMENT”修改为“CONTAIN”。 | 当待修改的游牧模板的“匹配类型”为“IPSEGMENT”时，不能修改为“CONTAIN”。可通过LST HNATPL命令查询待修改的游牧模板的匹配类型。 |
