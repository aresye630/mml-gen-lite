# 查询IMPU的拜访网络模板ID(LST HVNTPLID)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询指定IMPU的拜访网络模板ID。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                     |
|:-------|:-------|:-----------------------------------------------------------------------------------------|
| IMPU   | IMPU   | 用于指定一个需要查询拜访网络模板信息的IMPU，要求输入的IMPU值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无 |

## 使用实例

查询IMPU的拜访网络模板ID。IMPU：sip:impuinfo@huawei.com。

```
LST HVNTPLID: IMPU="sip:impuinfo@huawei.com";
```

## 输出结果说明

| 参数标识   | 参数说明          |
|:-------|:--------------|
| TPLID  | 显示拜访网络地址模板ID。 |
