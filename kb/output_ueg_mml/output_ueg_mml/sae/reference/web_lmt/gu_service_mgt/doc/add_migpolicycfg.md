## 命令功能

**须知** 

本命令属于高危命令，执行不当会使签约该策略ID的用户的消息被转发到错误的HSS或HLR，导致业务呼损，因此执行该命令前，请仔细检查配置的正确性，确认无误方可执行。如有疑问请与华为技术支持联系，制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用于在UDM中增加一条割接策略模板数据记录。使用该命令，只能在模板中增加一条模板记录且模板中只能签约一种路由记录，如果一个模板需要配置多个路由记录，则首先使用该命令定义一个割接策略模板，然后使用**MOD MIGPOLICYCFG**命令增加多个路由记录。割接策略模板定义“路由类型”、“是否转发MAP消息”、“是否发送ATI”、“是否转发EPS DIAMETER消息”和“是否转发IMS DIAMETER消息”。

- 当用户MAP消息中携带IMSI用户标识，UDM根据“路由类型”为“IMSI\_TYPE”查询割接策略模板中“是否转发MAP”配置确定是否对用户消息进行转发。
- 当用户MAP消息中携带MSISDN用户标识，UDM根据“路由类型”为 “MSISDN\_TYPE”查询割接策略模板中“是否转发MAP”配置确定是否对用户MAP消息进行转发。
- 当用户MAP消息中携带MSISDN用户标识，UDM根据“路由类型”为 “ATI\_TYPE”查询割接策略模板中“是否发送ATI”配置确定是否发送用户ATI消息到待割接的HLR。
- 当用户EPS Diameter消息中携带IMSI或MSISDN用户标识，UDM根据“路由类型”为 “EPS\_TYPE”查询割接策略模板中“是否转发EPS DIAMETER消息”配置确定是否转发S6a/S6d/SWx/SLh接口DIAMETER消息。
- 当用户IMS Diameter消息中携带IMPI或IMPU用户标识
  - UDM根据“路由类型”为 “IMS\_TYPE”查询割接策略模板中“是否转发IMS DIAMETER消息”配置确定是否转发Cx/Sh/Zh接口DIAMETER消息。
  - UDM根据“路由类型”为 “REPSYNC\_TYPE”查询割接策略模板中“是否提供透明数据同步规则”配置确定是否向被割接局点自动同步透明数据。

为提升现网平滑搬迁用户消息的能力，实现用户MAP消息、Diameter消息按IMSI、MSISDN、IMPI或IMPU号段分批割接。操作员通过执行**MOD MIGPOLICY**或**MOD IMSMIGPOLICY**命令为IMS用户或其他用户签约割接策略配置信息，只需签约对应的割接策略模板。UDM在割接用户MAP消息或Diameter消息时，根据消息中携带的用户标识及根据用户签约的割接策略配置对用户MAP消息或Diameter消息进行转发。

## 注意事项

系统中增加的割接策略模板记录数不能超过5000条。

## 参数说明

| HLRSN                        | HLR序列号             | 用于标识本地HLR。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                                                                                           |
| MIG_POLICYID                 | 割接策略ID             | 用于标识配置割接策略ID。 取值范围：0～65534 默认值：无。                                                                                                                                                                                                                                                   |

| ROUTETYPE                    | 路由类型               | 用于标识UDM对哪种路由类型的消息进行转发处理。 取值范围： IMSI_TYPEMSISDN_TYPEATI_TYPEEPS_TYPEIMS_TYPEREPSYNC_TYPE 默认值：无。                                                                                                                                                                                      |

| WHETHER_SEND_ATI             | 是否发送ATI            | 仅当本命令中的“路由类型”设置为“ATI_TYPE”时该参数有效。用于标识UDM在接收到待割接用户的SRI请求消息时，是否发送ATI消息到待割接的HLR查询用户的VLRNUM。 取值范围： TRUE：UDM在接收到待割接用户的SRI消息时，发送ATI消息到待割接HLR查询用户VLRNUM。FALSE：UDM在接收到待割接用户的SRI消息时，不发送ATI消息到待割接HLR查询用户VLRNUM。 默认值：无。                                                                        |

| WHETHER_FORWARD_IMS_DIAMETER | 是否转发IMS DIAMETER消息 | 仅当本命令中的“路由类型”设置为“IMS_TYPE”时该参数有效。用于标识UDM是否转发Cx/Sh/Zh接口DIAMETER消息。 取值范围： TRUE：UDM将接收到的Cx/Sh/Zh接口Diameter消息转发给待割接设备进行处理。FALSE：UDM对接收到的Cx/Sh/Zh接口Diameter消息不转发，本地进行处理。 默认值：无。 说明：“是否转发EPS DIAMETER消息”与“是否转发IMS DIAMETER消息”不能同时填写。                                                      |
| WHETHER_PROV_REPSYNC_RULE    | 是否提供透明数据同步规则       | 仅当本命令中的“路由类型”参数为“REPSYNC_TYPE”时该参数有效。用于标识UDM是否向被割接局点自动同步透明数据。 取值范围： TRUE：支持UDM收到AS发送的透明数据变更后自动同步到被割接局点。FALSE：不支持UDM收到AS发送的透明数据变更后自动同步到被割接局点。 默认值：无 说明： 该参数与“是否转发IMS DIAMETER消息”不能同时设置为“TRUE”，仅当“是否转发IMS DIAMETER消息”参数为“FALSE”时，该参数有效。当该参数取值为“TRUE”时，“分区ID”和“透明数据同步规则ID”均有效，且必须同时配置。 |
| RULEID                       | 透明数据同步规则ID         | 仅当本命令中的“是否提供透明数据同步规则”为“TRUE”时该参数有效。用于标识透明数据同步规则ID。该参数必须先由ADD REPSYNCRULE命令定义，然后才能在此处引用。 取值范围：1～65534 默认值：无。                                                                                                                                                                         |
| HLRNO                        | HLR号码              | 仅当本命令中的“是否转发MAP消息”或“是否发送ATI”设置为“TRUE”时该参数有效，用于标识该割接策略下对应用户归属的HLR号码。 取值范围：1～15位的十进制数字组成的字符串。 默认值：无。 说明：“HLR号码”与“分区ID”不能同时填写。                                                                                                                                                         |
| PID                          | 分区ID               | 仅当本命令中“是否转发MAP消息”、“是否发送ATI”，“是否转发EPS DIAMETER消息”，“是否转发IMS DIAMETER消息”、“是否提供透明数据同步规则”中有一个设置为“TRUE”时该参数有效。用于标识分区编号。该参数必须先由ADD SPRTINFO命令定义，然后才能在此处引用。 取值范围：1～250 默认值：无。 说明：“HLR号码”与“分区ID”不能同时填写。                                                                                      |

## 使用实例

当UDM割接现网用户时，配置UDM的割接策略，需要进行如下配置。以IMSI号段割接为例。

为用户设置策略模板，“HLR序列号”为“1”、“割接策略ID”为“0”、“路由类型”为“IMSI\_TYPE”、“是否转发MAP消息”为“TRUE”、“HLR号码”为“1”。命令如下：

```
ADD MIGPOLICYCFG: HLRSN=1, MIG_POLICYID=0, ROUTETYPE=IMSI_TYPE, WHETHER_FORWARD_MAP=TRUE, HLRNO="1";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释                        | 原因分析                                                  | 处理建议                                                                                                                              |
|:--------|:-----------------------------|:------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在                        | “HLR序列号”未定义。                                          | 根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求。可通过LST HLRSN命令查询已定义的“HLR序列号”。                                                                    |
| ERR3047 | 超过最大限制                       | 系统中增加的割接策略模板记录数超过5000条。                               | 根据实际情况，如需增加割接策略模板，处理步骤如下：执行LST MIGPOLICYCFG命令，查询已存在的割接策略模板。执行RMV MIGPOLICYCFG命令，删除不必要的割接策略模板。执行该命令增加割接策略模板，确保增加的割接策略模板记录数在规定范围之内。 |
| ERR4188 | RULEID未在ADD REPSYNCRULE命令中配置 | 当参数“是否提供透明数据同步规则”为“TRUE”时，“透明数据同步规则ID”指示的透明数据同步规则不存在。 | 根据实际情况，重新输入“透明数据同步规则ID”的取值，确保其取值符合要求。可通过LST REPSYNCRULE命令查询已定义的“透明数据同步规则ID”。                                                      |
