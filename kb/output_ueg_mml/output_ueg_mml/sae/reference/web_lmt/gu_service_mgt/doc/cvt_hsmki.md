## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成用户鉴权失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于将UDM/HSM鉴权用户转换为HSM鉴权用户。

## 注意事项

- 如果用户执行**ADD KI**命令添加鉴权密钥KI时携带“OPC值”，转换后“KI值”与“OPC值”统一通过HSM上保存的K2加密。
- 对于使用GK2加密的用户，在执行**ADD KI**命令添加鉴权密钥KI时，携带的KI值需要经过K4加密。否则执行本命令会报错“ERR4205：不支持转换未经过K4加密过的用户”。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                  |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------|
| IMSI   | IMSI   | 可选必选说明：必选参数 参数含义：用于标识待改造为HSM用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                          |
| K2SNO  | K2序列号  | 可选必选参数：必选参数 参数含义：用于标识转换后的K2序列号。 取值范围：1～254。 默认值：无。 配置原则：“K2序列号”必须为HSM类型。该序列号必须先通过ADD K2命令添加，且“K2密钥输入方式”必须为“GenOnHSM”。 |
| AMFSNO | AMF序列号 | 可选必选参数：可选参数 参数含义：用于标识转换后的AMF序列号。 取值范围：1～65535。 默认值：无。 配置原则：如果未携带本参数，则使用用户转换前通过ADD AMF命令签约的“AMF序列号”。                   |

## 使用实例

转换“IMSI”为“460000009123456”的用户，转换后“K2序列号”为“2”：

```
CVT HSMKI: IMSI="460000009123456", K2SNO=2;
```
