# 修改园区配置(MOD CAMPUSCFG)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成园区数据无法导出，需要与华为技术支持确认后才可以实施。

该命令用于在UDM中对一条园区配置数据记录进行修改。在该命令中，系统通过“园区名称”参数来唯一标识园区配置数据记录。

## 注意事项

- 该命令仅在特定局点使用，其他局点不需要配置。
- “过滤条件名称”、“K4序列号”、“OP序列号”参数至少要输入其中一个。

## 参数说明

| 参数标识            | 参数名称       | 参数说明                                                                                                                                                                                                                                |
|:----------------|:-----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| CAMPUSNAME      | 园区名称       | 可选必选说明：必选参数 参数含义：标识一条园区配置数据记录的关键字段，用于指定需要对哪一条园区配置数据记录的参数进行修改，操作员可以使用LST CAMPUSCFG命令查询获得。 取值范围：长度不超过16位的字符串，只允许输入数字、字母和下划线。 默认值：无。 配置原则：“园区名称”区分大小写字母。                                                                               |
| FILTERNAME      | 过滤条件名称     | 可选必选说明：可选参数 参数含义：用于标识一条园区配置数据记录的过滤条件名称。该参数必须由ADD CAMPUSDATAFILTER命令定义后才能在此处引用。 取值范围：长度不超过64位的字符串，只允许输入数字和字母。 默认值：无。 配置原则：无。                                                                                                         |
| K4SNO           | K4序列号      | 可选必选说明：可选参数 参数含义：用于标识园区的K4序列号。 取值范围：0～65535 默认值：无。 配置原则：无。                                                                                                                                                                          |
| OPSNO           | OP序列号      | 可选必选说明：可选参数 参数含义：用于标识园区的OP序列号。 取值范围：1～16777215 默认值：无。 配置原则：无。                                                                                                                                                                       |
| EXPDATATYPE     | 园区导出数据类型   | 可选必选说明：可选参数 参数含义：用于标识园区导出的用户数据类型。 取值范围： 全部选中全部清空5G：导出5G签约数据4G：导出4G签约数据，包括NSA和NB-IoTIMS：导出IMS签约数据 默认值：无。 配置原则：当该参数取值包含“4G”时，仅当SET MAPSERV命令“GPRS管理方式”参数取值为“SuppPsEpsSeparateTplManager”或“SuppGprsManageOptimizeon”时系统支持园区用户4G签约数据导出。 |
| PROVFEATURETYPE | 是否提供特性数据类型 | 可选必选说明：可选参数 参数含义：用于标识是否提供特性数据类型。 取值范围： TRUE：表示需要提供特性数据类型，如果原来有配置，则修改为本次新配置的数据。 FALSE：表示不提供特性数据类型，如果原来有配置，表示去签约。 默认值：无。 配置原则：无。                                                                                                      |
| FEATURETYPE     | 特性数据类型     | 可选必选说明：条件可选参数 参数含义：用于标识园区导出的用户特性数据类型。 取值范围： 全部选中全部清空REDCAP：RedCap特性相关字段，仅当本命令中“园区导出数据类型”参数取值包含“5G”时，允许配置该枚举值，否则系统会报错。 默认值：无。 配置原则：仅当本命令中的“是否修改特性数据类型”参数为“TRUE”时该参数有效。                                                               |

## 使用实例

修改一条园区配置数据记录，“园区名称”为“campus1”，“过滤条件名称”为“filter1”，“K4序列号”为“1”，“OP序列号”为“1”：

```
MOD CAMPUSCFG: CAMPUSNAME="campus1", FILTERNAME="filter1", K4SNO=1, OPSNO=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                                                                                                                        | 处理建议                                                                                                                                                                                                      |
|:--------|:--------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值。 | 输入的参数值不在其取值范围内或者输入的参数值不符合要求。                                                                                                                                                                | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                                                                                          |
| ERR1010 | 参数冲突    | 可能的原因为如下之一： 输入的“园区导出数据类型”参数取值未包含“5G”时，设置“特性数据类型”参数为“REDCAP”。不输入“园区导出数据类型”参数，数据库中“园区导出数据类型”参数取值未包含“5G”时，设置“特性数据类型”参数为“REDCAP”。不输入“特性数据类型”参数，数据库中“特性数据类型”参数取值为“REDCAP”，修改“园区导出数据类型”参数，删掉5G选项。 | 根据实际情况，重新输入参数，确保满足以下要求。 输入的“园区导出数据类型”参数取值包含“5G”时，“特性数据类型”参数可以设置为“REDCAP”。不输入“园区导出数据类型”参数，数据库中“园区导出数据类型”参数取值包含“5G”时，可以设置“特性数据类型”参数为“REDCAP”。不输入“特性数据类型”参数，数据库中“特性数据类型”参数取值为“REDCAP”，不能删掉“园区导出数据类型”参数的5G选项。 |
| ERR3007 | 记录不存在。  | 输入的“园区名称”对应记录在数据库中不存在。                                                                                                                                                                      | 根据实际情况，重新输入参数，确保通过LST CAMPUSCFG命令查询， “园区名称”参数对应的配置数据记录是存在的。                                                                                                                                               |
