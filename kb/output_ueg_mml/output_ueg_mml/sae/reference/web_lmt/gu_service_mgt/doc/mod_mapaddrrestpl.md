# 修改MAP消息地址过滤模板(MOD MAPADDRRESTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改MAP消息地址过滤模板信息。在该命令中，系统通过以下关键参数的组合来唯一标识一个MAP消息地址过滤模板信息：

- “HLR序列号”
- “模板ID”

## 注意事项

- 当“操作类型”参数不选择输入时，表示使用该命令修改模板名称。
- 系统中所有MAP消息地址过滤模板增加的地址号码前缀总记录数不能超过5000条。

## 参数说明

| 参数标识         | 参数名称    | 参数说明                                                                                                                                                   |
|:-------------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN        | HLR序列号  | 标识MAP消息地址过滤模板信息的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR上的MAP消息地址过滤模板信息记录的参数进行修改。操作员可通过LST HLRSN命令查询。                                                             |
| TPLID        | 模板ID    | 标识MAP消息地址过滤模板信息的关键字段之一（其取值不能被修改），用于指定需要对哪个模板的MAP消息地址过滤模板信息记录的参数进行修改。操作员可通过LST MAPADDRRESTPL命令查询。 取值范围：0～65534 默认值：无。                                   |
| TPLNAME      | 模板名     | 用于标识MAP消息地址过滤模板在系统中的名称。 取值范围：1～60位字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。                                                                                  |
| OPTYPE       | 操作类型    | 用于标识执行该命令实现的操作类型。 取值范围：ADD：表示在MAP消息地址过滤模板中增加一条地址信息。DELETE：表示删除MAP消息地址过滤模板中的一条已添加的地址信息。 默认值：无。                                                          |
| MAPPROCEDURE | MAP操作流程 | 仅当“操作类型”参数取值为“ADD”或“DELETE”时该参数有效。用于标识该MAP消息地址过滤模板增加的地址信息为哪个消息流程使用的地址。 SRIFORSM：表示该模板中添加的地址信息为短信息取路由消息流程使用的地址。SRI：表示该模板中添加的地址信息为被叫取路由消息流程使用的地址。 默认值：无。 |
| RULE         | 地址过滤规则  | 仅当“操作类型”参数取值为“ADD”时该参数有效。用于标识该MAP消息地址过滤模板是限制或放通指定消息流程。 RESTRICT：表示限制指定的消息流程。PERMISSION：表示放通指定的消息流程。 默认值：RESTRICT。                                      |
| ADDRPREFIX   | 地址号码前缀  | 仅当“操作类型”参数取值为“ADD”或“DELETE”时该参数有效。用于标识MAP消息地址号码前缀。当用户签约了该模板时，UDM会将消息流程中的地址信息与此处定义的地址号码前缀采用最大匹配原则进行匹配。 取值范围：1～15个十进制数字组成的字符串。 默认值：无。                    |

## 使用实例

1、修改MAP消息地址过滤模板名称，“HLR序列号”为“1”，“模板ID”为“2”，“模板名”修改为“test01”，命令如下：

```
MOD MAPADDRRESTPL: HLRSN=1, TPLID=2, TPLNAME="test01";
```

2、增加一条需要受限的短消息取路由消息地址号码前缀，“HLR序列号”为“1”，“模板ID”为“2”，“模板名”修改为“test01”，“操作类型”为“ADD”，“MAP操作流程”为“SRIFORSM”，“地址过滤规则”为“RESTRICT”，“地址号码前缀”为“861389966”，命令如下：

```
MOD MAPADDRRESTPL: HLRSN=1, TPLID=2, TPLNAME="test01", OPTYPE=ADD, MAPPROCEDURE=SRIFORSM, RULE=RESTRICT, ADDRPREFIX="861389966";
```

3、删除一条已添加的地址信息，“HLR序列号”为“1”，“模板ID”为“2”，“模板名”为“test01”，“操作类型”为“DELETE”，“MAP操作流程”为“SRIFORSM”，“地址号码前缀”为“861389966”，命令如下：

```
MOD MAPADDRRESTPL: HLRSN=1, TPLID=2, TPLNAME="test01", OPTYPE=DELETE, MAPPROCEDURE=SRIFORSM, ADDRPREFIX="861389966";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释         | 原因分析                                     | 处理建议                                                                                                               |
|:--------|:--------------|:-----------------------------------------|:-------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值        | 输入的“地址号码前缀”参数不在取值范围内。                    | 重新输入“地址号码前缀”参数值，确保其为十进制数字格式。                                                                                       |
| ERR3003 | 模板未定义         | “HLR序列号”和“模板ID”对应的数据记录不存在。               | 先使用LST MAPADDRRESTPL命令查询已添加过的模板信息，根据查询结果再次执行此命令。                                                                   |
| ERR3004 | 模板已存在         | 当“操作类型”参数为“ADD”时，输入的“地址号码前缀”信息已添加过。      | 使用LST MAPADDRRESTPL命令查询后，根据查询结果重新添加“地址号码前缀”信息，确保同一个虚拟HLR中同一个模板里添加的“地址号码前缀”信息不重复。                                   |
| ERR3047 | 超过最大限制        | 所有MAP消息地址过滤模板增加的“地址号码前缀”记录数超过5000条。      | 根据实际情况，如需增加地址号码前缀，处理步骤如下：执行LST MAPADDRRESTPL命令，查询已存在的地址号码前缀。执行该命令删除不必要的地址号码前缀。执行该命令增加地址号码前缀，确保增加的地址号码前缀记录数在规定范围之内。 |
| ERR3096 | 模板不能为空        | 当“操作类型”参数为“DELETE”时，删除的地址号码前缀是模板的最后一条记录。 | 请确认是否需要删除模板内的最后一条信息记录，若需要删除，请执行RMV MAPADDRRESTPL命令删除相应的模板。                                                         |
| ERR4145 | 同一操作流程过滤规则不相同 | 同一操作流程的过滤规则必须相同。                         | 重新输入“地址过滤规则”参数值，确保同一操作流程（短消息取路由或被叫取路由）的过滤规则相同，即同时限制或同时放通。                                                          |
