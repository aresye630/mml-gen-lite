# 增加私有密钥(ADD PRVTKEY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HSS/HLR中增加私有密钥。

## 注意事项

- 私有密钥输入使用六眼法则。即私有密钥由三部分组成，三部分长度合计32位。每部分由不同的操作人员输入，并且每部分输入两遍。如果两次输入不等，会弹出提示框提示“私有密钥的第1/2/3部分输入不一致，请重新输入”，请用户重新输入密钥。
- 当**SET MAPCONF**命令中的“是否启用随机密钥”参数为“TRUE”时，如果未执行**SET MAPSERV**命令设置“随机密钥默认ID”参数为系统已存在的随机密钥，则执行该命令时会返回错误：“已启用随机密钥功能，请先执行**SET RANDOMKEY**命令生成随机密钥”。

## 参数说明

| 参数标识        | 参数名称         | 参数说明                                              |
|:------------|:-------------|:--------------------------------------------------|
| HLRSN       | HLR序列号       | 用于标识本地HLR。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。         |
| PKEYSNO     | 私有密钥序列号      | 用于标识私有密钥序列号。 取值范围：1～10。 默认值：无。                    |
| KEYNAME     | 私有密钥名称       | 用于标识私有密钥名称。 取值范围：1～60位的字符串。 默认值：无。                |
| KEYPART1    | 私有密钥第一部分取值   | 用于标识私有密钥第一部分取值。 取值范围：8～16位的十六进制数字组成的字符串。 默认值：无。   |
| KEYPART1CNF | 私有密钥第一部分取值确认 | 用于标识私有密钥第一部分取值确认。 取值范围：8～16位的十六进制数字组成的字符串。 默认值：无。 |
| KEYPART2    | 私有密钥第二部分取值   | 用于标识私有密钥第二部分取值。 取值范围：8～16位的十六进制数字组成的字符串。 默认值：无。   |
| KEYPART2CNF | 私有密钥第二部分取值确认 | 用于标识私有密钥第二部分取值确认。 取值范围：8～16位的十六进制数字组成的字符串。 默认值：无。 |
| KEYPART3    | 私有密钥第三部分取值   | 用于标识私有密钥第三部分取值。 取值范围：8～16位的十六进制数字组成的字符串。 默认值：无。   |
| KEYPART3CNF | 私有密钥第三部分取值确认 | 用于标识私有密钥第三部分取值确认。 取值范围：8～16位的十六进制数字组成的字符串。 默认值：无。 |

## 使用实例

1. 在HSS/HLR中添加私有密钥。“HLR序列号”为“1”，“私有密钥序列号”为“2”，“私有密钥名称”为“keynamehlr1pkeysno2”，“私有密钥第一部分取值”为“1234567890a”,“私有密钥第一部分取值确认”为“1234567890a”,“私有密钥第二部分取值”为“bcde1234567”，“私有密钥第二部分取值确认”为“bcde1234567”，“私有密钥第三部分取值”为“890abcde12”，“私有密钥第三部分取值确认”为“890abcde12”：

   ```
   ADD PRVTKEY: HLRSN=1, PKEYSNO=2, KEYNAME="keynamehlr1pkeysno2", KEYPART1="*****", KEYPART1CNF="*****", KEYPART2="*****", KEYPART2CNF="*****", KEYPART3="*****", KEYPART3CNF="*****";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释       | 原因分析                                                          | 处理建议                                                                                                                                         |
|:--------|:------------|:--------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值      | 参数“私有密钥第一部分取值”或“私有密钥第二部分取值”或“私有密钥第三部分取值”的取值中含有十六进制数字以外的字符。    | 根据实际情况，重新输入“私有密钥第一部分取值”或“私有密钥第二部分取值”或“私有密钥第三部分取值”，确保其取值为长度为8～16位的十六进制数字组成的字符串。                                                               |
| ERR3006 | 记录已存在       | 重复为同一个HLR序列号添加相同的私有密钥序列号。                                     | 该私有密钥序列号已添加，根据实际情况确认是否需要添加其他的私有密钥序列号。                                                                                                        |
| ERR3007 | 记录不存在       | HLR序列号未定义。                                                    | 根据实际情况选择：如果需要为该HLRSN添加私有密钥数据，则执行ADD HLRSN命令先定义该HLRSN，再为该HLRSN添加私有密钥数据。如果需要为已定义的HLRSN添加私有密钥数据，则执行LST HLRSN命令先查询已定义的HLRSN，再为已定义的HLRSN添加私有密钥数据。 |
| ERR4086 | 随机密钥默认ID未设置 | 要使用随机密钥功能，但SET MAPSERV命令中的“随机密钥默认ID”参数为0。                     | 根据实际情况，设置SET MAPSERV命令中的“随机密钥默认ID”参数为系统已存在的随机密钥。                                                                                             |
| ERR4133 | 密钥丢失        | 当SET MAPSERV命令中的“随机密钥默认ID”参数为非0，“随机密钥默认ID”参数对应的随机密钥材料不存在或不完整。 | 联系华为技术支持处理。                                                                                                                                  |
