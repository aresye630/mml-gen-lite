# 修改用户申请锁(MOD SABLCK)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改用户申请锁的状态。当用户主动申请停机或取消停机时，可以使用该命令给用户加锁或解锁：

- 通过加锁，禁止用户的呼入、呼出，即给用户停机。
- 通过解锁，恢复用户的呼入、呼出，即给用户复机。

**ADD NCCTPL**命令的“Cancel location中的私有信元”参数取值可控制PS域的位置更新和GPRS业务：

- 取值为“NR”，该命令无法闭锁PS域的位置更新和GPRS业务。
- 取值为“SR”，该命令可以闭锁PS域的位置更新和GPRS业务。

该命令无法闭锁5GC域的AMF注册。

该命令仅适用于“网络接入模式”为“MSC”或“BOTH”的用户，可以通过**LST NAM**命令查询用户的网络接入模式。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，但必须且只能选择其中之一。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。
- 系统在初始化的时候已经预置了“是否提供锁呼入业务”、“是否提供锁呼出业务”两个参数的值为“FALSE（不加锁）”，操作员可以通过**LST SABLCK**命令查询得出。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                            |
|:------------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 用于标识需要修改锁状态的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                            |
| ISDN        | MSISDN    | 用于标识需要修改锁状态的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                          |
| RECORDCOUNT | 用户个数      | 用于标识需要修改锁状态的用户数目。 当需要为连续号码的多个用户修改锁状态时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户修改锁状态。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户修改锁状态，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名   | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要修改锁状态的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modsablck.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                 |
| ISDNFILE    | MSISDN文件名 | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要修改锁状态的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modsablck.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                           |
| IC          | 是否提供锁呼入业务 | 用于标识是否禁止用户的呼入。 取值范围：TRUE：加锁，禁止用户的呼入。FALSE：不加锁，允许用户的呼入。 默认值：无。                                                                                                                                                   |
| OC          | 是否提供锁呼出业务 | 用于标识是否禁止用户的呼出。 取值范围：TRUE：加锁，禁止用户的呼出。是否禁止用户EPS域位置更新由SET MAPCONF命令的“SABLCK是否控制4G位置更新”参数取值控制。“SABLCK是否控制4G位置更新”取值为“CTRL”，禁止用户EPS域位置更新。“SABLCK是否控制4G位置更新”取值为“NOTCTRL”，允许用户EPS域位置更新。 FALSE：不加锁，允许用户的呼出。 默认值：无。       |

## 使用实例

1. 禁止IMSI号码为“460030913121001”的用户的呼入：

   ```
   MOD SABLCK: IMSI="460030913121001", IC=TRUE;
   ```
2. 禁止3个连续号码的用户的呼入和呼出，这3个MSISDN号码分别为“13310911001”、“13310911002”、“13310911003”：

   ```
   MOD SABLCK: ISDN="13310911001", RECORDCOUNT=3, IC=TRUE, OC=TRUE;
   ```
3. 禁止3个非连续号码的用户的呼出，这3个MSISDN号码分别为“13310911001”、“13310911003”、“13310911005”，已保存在“MSISDN文件名”为“modsablck.txt”的文件中，并通过文件管理功能上传到指定目录：

   ```
   MOD SABLCK: ISDNFILE="modsablck.txt", OC=TRUE;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释      | 原因分析                                                                                               | 处理建议                                                                                                                    |
|:--------|:-----------|:---------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值     | 可能原因为如下之一：参数“IMSI”的取值不是6～15位十进制数字组成的字符串。参数“MSISDN”的取值不是1～15位十进制数字组成的字符串。                           | 根据实际情况，重新输入“IMSI”或“MSISDN”的取值，确保其取值符合要求。                                                                                |
| ERR1009 | 参数丢失       | “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数一个都没有输入。                                                  | 根据实际情况，重新输入参数，并满足“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                             |
| ERR1005 | 文件未找到      | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                   | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                      |
| ERR1010 | 参数冲突       | 可能原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR3001 | 用户未开户      | 用户的IMSI号码或MSISDN号码输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户。                                             | 核实用户的IMSI号码或MSISDN号码，如果确定输入无误，证明实际输入的参数“IMSI”或“MSISDN”对应的用户未开户，请先通过ADD SUB命令给用户开户。                                      |
| ERR1025 | 批操作文件中格式非法 | 参数“IMSI文件名”或“MSISDN文件名”对应的批操作文件格式不正确。                                                              | 请根据IMSIFILE文件格式和ISDNFILE文件格式，重新确定对应的批操作文件格式。                                                                            |
