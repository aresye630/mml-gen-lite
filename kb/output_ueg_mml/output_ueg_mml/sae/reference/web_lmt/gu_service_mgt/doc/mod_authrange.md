# 修改授权号段数据(MOD AUTHRANGE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在功能号码寻址业务（Follow Me）中配置授权号段数据，可以通过远端号码号段增加或删除远端用户的潜在初始用户或者管理者。

## 注意事项

系统中增加的远端用户的潜在初始用户或者管理者的记录数不能超过3000条。

## 参数说明

| 参数标识         | 参数名称     | 参数说明                                                                       |
|:-------------|:---------|:---------------------------------------------------------------------------|
| HLRSN        | HLR序列号   | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1～255 默认值：无。             |
| BEGINRMNUM   | 远端号码开始   | 用于标识远端号码号段的开始值。 取值范围：1～15位的十进制数字组成的字符串。 默认值：无。                             |
| ENDRMNUM     | 远端号码结束   | 仅当本命令中的“操作类型”参数为“ADD”时该参数有效。用于标识远端号码号段的结束值。 取值范围：1～15位的十进制数字组成的字符串。 默认值：无。 |
| PROV         | 操作类型     | 用于标识增加还是删除远端用户的潜在初始用户或者管理者。 取值范围： ADD：增加。RMV：删除。 默认值：无。                    |
| TYPE         | 授权类型     | 用于标识初始用户的类型。 取值范围： Initiating subscriber：潜在初始用户。Supervisor：管理者。 默认值：无。     |
| BEGININITNUM | 初始用户号码开始 | 用于标识初始号码开始值。 取值范围：1～15位的十进制数字组成的字符串。 默认值：无。                                |
| ENDINITNUM   | 初始用户号码结束 | 仅当本命令中的“操作类型”参数为“ADD”时该参数有效。用于标识初始号码结束值。 取值范围：1～15位的十进制数字组成的字符串。 默认值：无。    |

## 使用实例

为远端用户的潜在初始用户进行授权，参数取值如下：

- HLRSN：1
- 远端号码开始：12345
- 远端号码结束：12356
- 操作类型：ADD
- 授权类型：Initiating subscriber
- 初始用户号码开始：8613900001234
- 初始用户号码结束：8613900001256

执行命令如下：

```
MOD AUTHRANGE: HLRSN=1, BEGINRMNUM="12345", ENDRMNUM="12356", PROV=ADD, TYPE=Initiating subscriber, BEGININITNUM="8613900001234", ENDINITNUM="8613900001256";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释     | 原因分析                                                             | 处理建议                                                                                                                                                                                                           |
|:--------|:----------|:-----------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值    | 参数“远端号码开始”、“远端号码结束”、“初始用户号码开始”或“初始用户号码结束”的取值不是1～15位的十进制数字组成的字符串。 | 根据实际情况，重新输入参数“远端号码开始”、“远端号码结束”、“初始用户号码开始”或“初始用户号码结束”的取值，确保其取值符合要求。                                                                                                                                             |
| ERR3097 | HLR序列号未定义 | 参数“HLR序列号”输入错误，实际输入的参数“HLR序列号”未定义。                               | 根据实际情况,重新输入参数“HLR序列号”的取值，确保其取值已被定义。已定义的“HLR序列号”可通过LST HLRSN命令查询。                                                                                                                                               |
| ERR3007 | 记录不存在     | 当参数“操作类型”设为“RMV”时，参数“远端号码开始”或“初始用户号码开始”输入错误，实际输入的参数值未被添加。        | 根据实际情况，重新输入参数“远端号码开始”和“初始用户号码开始”，确保“远端号码开始”和“初始用户号码开始”输入正确。                                                                                                                                                    |
| ERR3047 | 超过最大限制    | 增加的远端用户的潜在初始用户或者管理者记录数超过3000条。                                   | 根据实际情况，如需增加远端用户的潜在初始用户或者管理者记录，处理步骤如下：执行LST AUTHRANGE命令，查询已存在远端用户的潜在初始用户或者管理者记录。执行该命令，将参数“操作类型”设置为“DELETE”删除不必要的远端用户的潜在初始用户或者管理者记录。执行该命令，将参数“操作类型”设置为“ADD”增加远端用户的潜在初始用户或者管理者记录，确保增加后远端用户的潜在初始用户或者管理者记录数在规定范围之内。 |
