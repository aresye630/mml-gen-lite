# 查询K4(LST HK4)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询鉴权数据K4的业务信息，若需要查询全部鉴权数据K4，请不要输入任何参数，若需要查询某条鉴权数据K4，请输入参数K4索引号。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                        |
|:-------|:-------|:------------------------------------------------------------|
| K4SNO  | K4索引号  | 用于指示系统需要按照哪个K4SNO来查询K4值；若不输入，则表示查询所有的K4值。 取值范围：1～128 缺省值： 无 |

## 使用实例

查询K4。K4索引号：10。

```
LST HK4: K4SNO=10;
```

## 输出结果说明

| 参数标识    | 参数说明                 |
|:--------|:---------------------|
| K4SNO   | 显示K4索引号。             |
| K4VALUE | 显示K4值，出于安全原因，仅显示“*”。 |
