## 命令功能

该命令用于为单个用户或多个用户进行补卡。

**说明** 

该命令仅支持2G/3G/4G用户数据修改。

SIM卡或USIM卡丢失或损坏后，用户通过补卡可以使用和原来相同的手机号码（即MSISDN号码），补卡的前提是新IMSI号码在操作员管理的IMSI号段中，并且新IMSI对应的KI（Individual Subscriber Authentication Key）已经加载（使用**ADD KI**命令加载KI），同时新IMSI号码与原IMSI号码必须归属于同一个“虚拟HLR序列号”。查询操作员管理的IMSI号段的方法如下：

登录System Management界面，执行**LST OPRHLRSN**命令查询出该操作员所能操作的虚拟HLR，然后通过**LST VHLRRANGE**命令查询出该虚拟HLR对应的IMSI号段，此号段即该操作员管理的IMSI号段。

如果用户是M2M用户，系统会做如下处理：

- 修改MSISDN-Less用户的IMSI，则该用户的MSISDN会同步修改，修改值与IMSI保持一致。
- 修改非MSISDN-Less用户的IMSI，存在以下两种情况：
  - 若修改后的IMSI和MSISDN一致，则系统自动将该用户置为MSISDN-Less用户。
  - 若修改后的IMSI和MSISDN不一致，则该用户依然为非MSISDN-Less用户。

## 注意事项

- “MSISDN”、“旧IMSI”、“MSISDN/新IMSI文件名”、“IMSI/新IMSI文件名”四个参数是互斥参数，必须有且只能有一个参数出现。
- “新IMSI”不能与“MSISDN/新IMSI文件名”或“IMSI/新IMSI文件名”同时配置。
- “用户个数”不能与“MSISDN/新IMSI文件名”或“IMSI/新IMSI文件名”同时配置。
- 如要为用户签约自动换卡功能，则需要通过**SET MAPCONF**命令设置参数“是否支持自动换卡功能”的值为“TRUE”，使系统支持自动换卡功能。
- 在混合组网下，当用户从SP迁移至另一个SP、vSP或vRSP时，静态用户数license统计数据通过凌晨校验更新。
- 在混合组网下，如存在异常场景下进行跨SP数据迁移时，需要通过设置“USERDATAMIGEXCEPENHANCESW（用户数据迁移容错能力增强开关）”软参支持数据的兼容处理，避免因为UDB和PaasDB数据模型不一致而处理失败。
  - 插件包schemamap.xml文件中配置RDN冲突节点（rdnconflictexcepproc），即从5G接入查询4G用户和用户数据迁移过程中该节点存在冲突记录时，若该软参为“1”，根据timestampfield配置字段取最新的一条数据，无timestampfield配置，随机取一条数据；若软参为“0”，则从5G接入查询4G用户和迁移失败。
  - 插件包schemamap.xml文件中配置无父节点的节点（noparentnodeexcepproc），即从5G接入查询4G用户和用户数据迁移过程中该节点无父节点记录时，若软参为“1”，忽略该节点数据不处理；若软参为“0”，则从5G接入查询4G用户和迁移失败。

## 参数说明

| 参数标识        | 参数名称            | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
|:------------|:----------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ISDN        | MSISDN          | 用于标识待补卡用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| IMSI        | 旧IMSI           | 用于标识待补卡用户的旧IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| NEWIMSI     | 新IMSI           | 用于标识待补卡用户的新IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 说明：该参数输入值必须与“旧IMSI”不同。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| RECORDCOUNT | 用户个数            | 用于标识待补卡用户的数目。 当需要为连续号码的多个用户补卡时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行补卡。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户进行补卡，当只有一个用户时，该参数不必配置。当一次补卡的用户个数很多时，对系统性能无影响，但补卡的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。                                                                                                                                                                                                                                                                                                                                                                                |
| ISDNFILE    | MSISDN/新IMSI文件名 | 用于标识MSISDN/新IMSI批操作文件。 MSISDN/新IMSI批操作文件包含多个不连续的待补卡用户的MSISDN号码和新IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modimsi.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见补卡批操作文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                       |
| IMSIFILE    | IMSI/新IMSI文件名   | 用于标识IMSI/新IMSI批操作文件。 IMSI/新IMSI批操作文件包含多个不连续的待补卡用户的旧IMSI号码和新IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modimsi.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见补卡批操作文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                            |
| CARDTYPE    | 卡类型             | 用于标识待补卡用户的卡类型。 取值范围：SIM：SIM卡。USIM：USIM卡。 默认值：无。 说明：配置该参数需要与“新IMSI”对应的卡类型一致。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ALG         | 鉴权算法类型          | 用于标识卡类型对应的鉴权算法。 取值范围：COMP128_1、COMP128_2、COMP128_3、CUSTOM_1、MILENAGE、MILENAGE_2、XOR、CAVE38、CUSTOM_2、CUSTOM_3、CUSTOM_4、CUSTOM_5、CUSTOM_6、CUSTOM_7、CUSTOM_8和CUSTOM_9。 默认值：无。 说明：当“卡类型”取值为“SIM”时，鉴权算法可以为“COMP128_1”、“COMP128_2”、“COMP128_3”、“MILENAGE”、“MILENAGE_2”、“XOR”、“CAVE38”、“CUSTOM_2”、“CUSTOM_3”、“CUSTOM_4”、“CUSTOM_5”、“CUSTOM_7”、“CUSTOM_8”和“CUSTOM_9”。当“卡类型”取值为“USIM”时，鉴权算法只能为“CUSTOM_1”、“CUSTOM_6”、“CUSTOM_9”、“MILENAGE”和“MILENAGE_2”。“MILENAGE_2”与“MILENAGE”的区别在于将鉴权五元组的XRES转换为鉴权三元组的SRES时使用的算法不同。如果该参数不配置，补卡时默认采用“新IMSI”对应的鉴权算法。COMP128_1、COMP128_2鉴权算法为不安全算法，建议使用更安全的鉴权算法。 |
| CHANGEIMSI  | 签约/去签约自动换卡功能    | 用于标识是否为用户签约自动换卡功能。 自动换卡功能是指用户可以在“有效期限”内任意时刻换卡，换卡后保持用户的MSISDN号码不变。用户在有效期内，如果一直没有使用新卡，则旧卡仍能正常使用；一旦使用了一次新卡，则换卡完成，旧卡就不能再使用。如果超过了有效日期，用户仍没有使用新卡，换卡会自动完成，旧卡就不能再使用。该功能相当于提供了一个灵活的补卡方式，通过先为用户备份一张与原MSISDN号码相同的卡，一旦用户的SIM卡或USIM卡丢失或损坏，可以快速换卡使用。 取值范围： TRUE：签约，表示为用户提供自动换卡功能，为用户增加备份IMSI，该备份的IMSI即参数“新IMSI”。FALSE：去签约，表示不为用户提供自动换卡功能，取消用户的备份IMSI，该备份的IMSI即参数“新IMSI”。 默认值：无。 说明：如果该参数不配置，表示立即换卡操作，即补卡操作立刻生效。                                                                                                                                                                                     |
| EXPIRYDATE  | 有效期限            | 用于标识自动换卡的有效日期。如果超过了这个有效日期，用户仍没有使用新卡，换卡会自动完成，旧卡就不能再使用。 取值范围：最多设置为200年，格式为“YYYY&MM&DD”。 默认值：无。 说明：当“签约/去签约自动换卡功能”选择为“TRUE”时，该参数必选。                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

## 使用实例

1. 为“MSISDN”号码为“13310911001”的单个用户补卡，“新IMSI”号码为“460030913121002”：

   ```
   MOD IMSI: ISDN="13310911001", NEWIMSI="460030913121002";
   ```
2. 为从“MSISDN”为“13310911001”的号码开始的3个连续号码的用户补卡，补卡后的“新IMSI”为从“460030913121002”开始的3个连续号码。

   ```
   MOD IMSI: ISDN="13310911001", NEWIMSI="460030913121002", RECORDCOUNT=3;
   ```
3. 为3个非连续号码的用户补卡。
   - 3个“MSISDN”号码分别为：“13310911001”、“13310911003”、“13310911005”。
   - 3个“新IMSI”号码分别为：“460030913121002”、“460030913121004”、“460030913121006”。
   - 3组“MSISDN”和“新IMSI”号码已保存在“MSISDN/新IMSI文件名”为“modimsi.txt”的文件中，并通过文件管理功能上传到指定目录。

   ```
   MOD IMSI: ISDNFILE="modimsi.txt";
   ```
4. 为“MSISDN”号码为“13310911001”的单个用户签约自动换卡功能，“新IMSI”号码为“460030913121002”，“有效期限”至“2013年08月01日”：

   ```
   MOD IMSI: ISDN="13310911001", NEWIMSI="460030913121002", CHANGEIMSI=TRUE, EXPIRYDATE=2013&08&01;
   ```
