# 查询VoLTE多SIM业务(LST HMSIM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在IMS网络中查询VoLTE用户的Multi-SIM业务信息。若需要查询VoLTE用户Multi-SIM业务信息，请输入参数“IMS用户标识”和参数“IMSI”其中的一个。

## 注意事项

“IMS用户标识”和“IMSI”两个参数必须有且只能有一个参数出现。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                     |
|:-------|:--------|:---------------------------------------------------------------------------------------------------------|
| SUBID  | IMS用户标识 | 用于标识查询VoLTE用户的Multi-SIM业务信息的SUBID。操作员可以使用LST HSUB操作查询获得，SUBID字母区分大小写。 取值范围：长度不超过127的由字母和数字组成的字符串。 默认值：无。 |
| IMSI   | IMSI    | 用于查询VoLTE用户Multi-SIM业务的IMSI号码。                                                                           |

## 使用实例

查询VoLTE用户的Multi-SIM业务信息，“IMS用户标识”为“subinfo”：

```
LST HMSIM: SUBID="subinfo";
```

```
%%LST HMSIM: SUBID="subinfo";%%
RETCODE = 0 SUCCESS0001:Operation is successful

SUBID = subinfo

IMSI       MASTERFLAG
1234567891 1
1234567892 0
1234567893 0
1234567894 0
1234567895 0

Total count = 6

There is together 1 report

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数请参见本命令的参数说明。表1列出的是未包含在本命令参数说明中的输出项。

| 输出项名称      | 输出项解释                                |
|:-----------|:-------------------------------------|
| MASTERFLAG | 用于返回查询的IMSI是否是主卡。“0”表示不是主卡，“1”表示是主卡。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|       错误码 | 错误码解释          | 原因分析                           | 处理建议                                               |
|----------:|:---------------|:-------------------------------|:---------------------------------------------------|
| 900001007 | 无效的参数值         | 参数“IMSI”的取值不是6～15位十进制数字组成的字符串。 | 根据实际情况，重新输入参数“IMSI”的取值，确保其取值符合要求。                  |
| 900003051 | 请求消息中的SubId不存在 | 输入的参数“IMSI”不存在。                | 根据实际情况，重新输入参数，确保参数“IMSI”已经存在。                      |
| 900001008 | 参数不足           | 参数“IMS用户标识”和“IMSI”都没有输入。       | 根据实际情况，重新输入参数，确保“IMS用户标识”和“IMSI”两个参数必须有且只能有一个参数出现。 |
| 900001009 | 参数冲突           | 同时输入参数“IMS用户标识”和“IMSI”。        | 根据实际情况，重新输入参数，确保“IMS用户标识”和“IMSI”两个参数必须有且只能有一个参数出现。 |
