# 修改前转号码数据(MOD FTNNCS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改前转号码是否通知主叫用户的属性。在该命令中，系统可以通过以下关键参数的组合来唯一标识某条前转号码是否通知主叫用户的属性信息：

- HLR序列号
- 前转号码
- 是否通知主叫用户

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                             |
|:-------|:---------|:---------------------------------------------------------------------------------|
| HLRSN  | HLR序列号   | 标识前转号码属性记录的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR上的前转号码的属性进行修改或调整，操作员可以使用LST HLRSN命令查询获得。 |
| FTN    | 前转号码     | 标识前转号码属性记录的关键字段之一（其取值不能被修改），用于指定需要对哪个前转号码的属性进行修改或调整，操作员可以使用LST FTNNCS命令查询获得。     |
| NCS    | 是否通知主叫用户 | 用于标识当发生呼叫前转时是否通知主叫用户。 取值范围：TRUE：通知FALSE：不通知 默认值：无。                               |

## 使用实例

1. 在“HLR序列号”为“1”的HLR上，修改呼叫前转补充业务中前转号码的属性。其中，“前转号码”为“8613907550001”，“是否通知主叫用户”为“FALSE”：

   ```
   MOD FTNNCS: HLRSN=1, FTN="8613907550001", NCS=FALSE;
   ```
2. 在“HLR序列号”为“1”的HLR上，修改呼叫前转补充业务中前转号码的属性。其中，“前转号码”为“8613907550002”，“是否通知主叫用户”为“TRUE”：

   ```
   MOD FTNNCS: HLRSN=1, FTN="8613907550002", NCS=TRUE;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                       | 处理建议                                                                                                                                 |
|:--------|:--------|:---------------------------|:-------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 参数“前转号码”的取值中含有0～9以外的字符。    | 重新输入“前转号码”，确保只含有0～9以内的字符。                                                                                                            |
| ERR3007 | 记录不存在   | 有两点原因：HLR序列号未定义。前转号码属性未添加。 | 对于第一点原因，处理步骤如下：执行LST HLRSN命令查询出已定义的HLR序列号。执行LST FTNNCS命令查询出该HLR序列号对应的前转号码属性。结合实际情况，根据HLR序列号和前转号码修改对应的前转号码属性。 对于第二点原因，只需执行上述处理步骤的2和3。 |
