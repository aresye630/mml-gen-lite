# 修改NGC漫游限制区域模板(MOD NGCRRAREATPL)

## 命令功能

**须知** 

该命令属于高危命令，修改NGC漫游限制区域模板会使引用此模板的用户NGC漫游限制区域数据被同步修改。因此执行该命令前，请仔细评估当前操作的风险，确认对业务没有影响后方可执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该操作用于在数据库中修改一个NGC漫游限制区域模板。在该命令中，系统通过以下关键参数的组合来唯一标识一个漫游限制区域模板：

- “HLR序列号”
- “模板ID”

## 注意事项

无。

## 使用实例

1. 修改“HLR序列号”为“1”的NGC漫游限制区域模板数据，增加漫游区域数据。其中“HLR序列号”为“1”，“模板ID”为“1”，“模板名”为“new”，“漫游区域操作类型”为“ADD”，“AMF限制类型”为“AMFPOINTER”，“PLMNID”为“12345”，“AMF Region ID”为“1”，“AMF Set ID”为“1”，“AMF Pointer ID”为“1”：

   ```
   MOD NGCRRAREATPL: HLRSN=1, TPLID=1, TPLNAME="new", OPTYPE=ADD, AREATYPE=AMFPOINTER, PLMN="12345", AMFREGION=1, AMFSET=1, AMFPOINTER=1;
   ```
2. 修改“HLR序列号”为“1”的NGC漫游限制区域模板数据，增加漫游区域数据。其中“HLR序列号”为“1”，“模板ID”为“3”，“模板名”为“new”，“漫游区域操作类型”为“ADD”，“AMF限制类型”为“PLMN”，“PLMNID”为“12323”：

   ```
   MOD NGCRRAREATPL: HLRSN=1, TPLID=3, TPLNAME="new", OPTYPE=ADD, AREATYPE=PLMN, PLMN="12323";
   ```

该命令执行正常，会返回命令执行成功的提示信息。
