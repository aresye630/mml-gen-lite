# 查询指定的IMPI对TAA鉴权模式的支持情况(LST HTAA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询指定的IMPI的对TAA鉴权模式的支持情况。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                             |
|:-------|:-------|:---------------------------------------------------------------------------------|
| IMPI   | IMPI   | 用于指定一个需要查询其是否支持TAA鉴权模式的IMPI，要求输入的IMPI值符合NAI格式，字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无 |

## 使用实例

查询指定的IMPI对TAA鉴权模式的支持情况。IMPI：impiinfo。

```
LST HTAA: IMPI="impiinfo";
```

## 输出结果说明

| 参数标识    | 参数说明       |
|:--------|:-----------|
| TAAFLAG | 显示TAA鉴权标识。 |
