# 删除LU-CSI模板(RMV LUCSITPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在配置数据库中删除一条LU-CSI（Location Upgrade Services CAMEL Subscription Information）模板数据记录。

## 注意事项

当执行**RMV LUCSITPL**命令删除用户已签约的LU-CSI模板时，系统会提示“ERR3005:模板已经被使用”的错误信息，该LU-CSI模板不能被删除。如果要删除该LU-CSI模板，必须先执行**MOD LUCSI**命令给用户去签约相关的LU-CSI模板。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                       |
|:-------|:-------|:---------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 标识一条LU-CSI模板数据记录的关键字段之一，用于标识需要删除哪一条LU-CSI模板数据记录，操作员可以使用LST HLRSN命令查询获得。    |
| TPLID  | 模板ID   | 标识一条LU-CSI模板数据记录的关键字段之一，用于标识需要删除哪一条LU-CSI模板数据记录，操作员可以使用LST LUCSITPL命令查询获得。 |

## 使用实例

删除“HLR序列号”为“1”的HLR上的LU-CSI模板数据记录。其中，“模板ID”为“2”：

```
RMV LUCSITPL: HLRSN=1, TPLID=2;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                               | 处理建议                                                                       |
|:--------|:--------|:-----------------------------------|:---------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | “HLR序列号”和“模板ID”对应的LU-CSI模板数据记录不存在。 | 使用LST LUCSITPL命令查询后，重新确认要删除哪个“HLR序列号”和“模板ID”对应的LU-CSI模板数据记录。               |
| ERR3005 | 模板已经被使用 | 用户已签约该模板。                          | 根据实际情况，确定是否要删除该模板。如果确实需要删除，先通过MOD LUCSI命令给用户去签约该模板，然后才能执行RMV LUCSITPL命令删除。 |
