# 发送模拟Update Location消息（SND UPL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来发送模拟位置更新消息。

NPMSC在发起模拟位置更新请求之后，接收HLR的插入用户数据请求消息，不存储用户数据，返回成功的插入用户数据响应消息，接受位置更新响应消息并将HLRNumber记录到用户数据表中。

如果NPMSC收到归属HLR返回位置更新失败响应时，NPMSC应在规定时间根据消息中的IMSI，得到对应携出用户信息，重新发起位置更新。该时间取值可配置，取值范围在0秒-65535秒，0秒代表立刻发起位置更新，并且重试次数可设。

## 注意事项

- ISDN、ISDNFILE是条件可选参数，此操作中，有且只能一个参数出现。
- RECORDCOUNT一定不能与ISDNFILE同时存在。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                        |
|:------------|:----------|:----------------------------------------------------------------------------|
| ISDN        | MSISDN    | MSISDN号码，E.164格式的编码，1～15位的十进制数字。                                            |
| RECORDCOUNT | 用户个数      | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供以指定的MSISDN为起始号码，号码连续的RECORDCOUNT个用户。 |
| ISDNFILE    | MSISDN文件名 | MSISDN文件名称，1～16位的数字或字符组成的字符串，不可包括路径名称。 FILE的内容由不连续的MSISDN号码组成。 说明：可选参数      |

## 使用实例

对MSISDN号码是86131075003003的用户发起模拟位置更新,命令如下：

SND UPL: ISDN="86131075003003";
