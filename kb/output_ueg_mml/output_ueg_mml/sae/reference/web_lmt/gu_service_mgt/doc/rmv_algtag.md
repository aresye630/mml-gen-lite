# 删除ADSU鉴权算法配置(RMV ALGTAG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用于删除ADSU鉴权算法配置。

## 注意事项

参数ADSUALG必选。

## 参数说明

| 参数标识    | 参数名称      | 参数说明                        |
|:--------|:----------|:----------------------------|
| ADSUALG | ADSU鉴权算法值 | ADSU鉴权算法值，必选参数。 取值范围：1～127。 |

## 使用实例

在［ADSU鉴权算法配置表］中删除一条记录，ADSU鉴权算法值为1。命令如下：

RMV ALGTAG: ADSUALG=1;
