# 用户签约去签约MAP消息地址过滤模板（MOD MAPADDRRES）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于为用户签约/去签约MAP消息地址过滤模板。

该模板必须通过**ADD MAPADDRRESTPL**命令定义后才能使用。当用户签约了该模板之后：

- 在短消息取路由流程中，UDM会根据短消息来源地址与模板中的地址匹配结果判断是否要过滤掉垃圾短消息，满足如下任一条件，UDM向对端返回失败响应，短消息被过滤不能发送成功。
  - 匹配且命令**ADD MAPADDRRESTPL**的参数“地址过滤规则”取值为“RESTRICT”。
  - 不匹配且命令**ADD MAPADDRRESTPL**的参数“地址过滤规则”取值为“PERMISSION”。
- 在被叫取路由流程中，UDM会根据GMSC地址与模板中的地址匹配结果判断是否要限制指定的GMSC获取用户的路由信息，满足如下任一条件，UDM向对端返回失败响应，不允许此GMSC获取用户的路由信息。
  - 匹配且命令**ADD MAPADDRRESTPL**的参数“地址过滤规则”取值为“RESTRICT”。
  - 不匹配且命令**ADD MAPADDRRESTPL**的参数“地址过滤规则”取值为“PERMISSION”。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时存在，只能与“IMSI”或“MSISDN”一起出现，用于为连续多个用户签约或去签约MAP消息地址过滤模板。

## 参数说明

| 参数标识        | 参数名称            | 参数说明                                                                                                                                                                                                                                                                                             |
|:------------|:----------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI            | 用于标识待签约/去签约MAP消息地址过滤模板用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                   |
| ISDN        | MSISDN          | 用于标识待签约/去签约MAP消息地址过滤模板用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                 |
| RECORDCOUNT | 用户个数            | 用于标识待签约/去签约MAP消息地址过滤模板用户的数目。 当需要为连续号码的多个用户签约/去签约MAP消息地址过滤模板时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行签约/去签约MAP消息地址过滤模板。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户进行签约/去签约MAP消息地址过滤模板，当只有一个用户时，该参数不必配置。当一次签约/去签约MAP消息地址过滤模板的用户个数很多时，对系统性能无影响，但签约/去签约MAP消息地址过滤模板的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名         | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要签约/去签约MAP消息地址过滤模板用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“mapaddrres.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                                                                      |
| ISDNFILE    | MSISDN文件名       | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要签约/去签约MAP消息地址过滤模板用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“mapaddrres.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                                                                |
| PROV        | 是否提供MAP消息地址过滤业务 | 用于标识是否为用户提供MAP消息地址过滤业务。 取值范围：TRUE：签约MAP消息地址过滤业务。FALSE：去签约MAP消息地址过滤业务。 默认值：无。                                                                                                                                                                                                                     |
| TPLID       | 模板ID            | 仅当本命令中“是否提供MAP消息地址过滤业务”参数设置为“TRUE”时该参数有效，用于标识MAP消息地址过滤模板的模板号。 取值范围：0～65534 默认值：无。 说明：该参数必须通过ADD MAPADDRRESTPL命令定义后才能使用。                                                                                                                                                                          |

## 使用实例

1. 为IMSI号码为“460000009012345”的用户提供MAP消息地址过滤业务。命令如下：

   ```
   MOD MAPADDRRES: IMSI="460000009012345", PROV=TRUE, TPLID=1;
   ```
2. 为IMSI号码为“460000009012345”的用户撤销MAP消息地址过滤业务。命令如下：

   ```
   MOD MAPADDRRES: IMSI="460000009012345", PROV=FALSE;
   ```
