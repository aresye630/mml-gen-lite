# 查询业务签约信息共享(LST HSPSHARE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HSS的业务数据库中查询与指定“IMPU”共享Service Profile的IMPU列表。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                        |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------|
| IMPU   | IMPU   | 用于指定需要查询共享Service Profile信息的“IMPU”。要求输入的IMPU值符合SIP URI或TEL URI格式，字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：必选参数。 |

## 使用实例

查询业务签约信息共享，“IMPU”为“sip:impuinfo@huawei.com”：

```
LST HSPSHARE: IMPU="sip:impuinfo@huawei.com";
```

```
%%LST HSPSHARE: IMPU="sip:impuinfo@huawei.com";%%
RETCODE = 0 操作成功

IMPU
sip:impuinfo3@huawei.com
sip:impuinfo2@huawei.com
sip:impuinfo@huawei.com

Total count = 3

There is together 1 report

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各输出项含义请参见参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释   | 原因分析             | 处理建议                             |
|----------:|:--------|:-----------------|:---------------------------------|
| 900001008 | 参数不足    | 参数“IMPU”没有输入。    | 根据实际情况，重新输入参数，确保“IMPU”必须存在。      |
|      1001 | 无效的命令   | 输入的命令名称不正确。      | 重新输入正确的命令。                       |
| 900001007 | 无效的参数值  | 输入的参数取值不在其取值范围内。 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。 |
| 900001010 | 参数重复    | 输入命令中的同一参数重复出现。  | 根据实际情况，删除重复的参数，确保命令中每一个参数只出现一次。  |
