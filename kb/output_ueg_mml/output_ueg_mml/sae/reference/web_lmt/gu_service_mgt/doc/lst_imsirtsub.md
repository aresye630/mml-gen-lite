# 查询IMSI用户路由数据(LST IMSIRTSUB)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询鉴权AUC中配置的IMSI号码和HLR的对应关系：

- 若需要查询单个IMSI用户的路由数据，请输入“IMSI”。
- 若需要查询多个连续IMSI用户的路由数据，请输入“IMSI”和“用户个数”。
- 若需要查询多个不连续IMSI用户的路由数据，请输入“IMSI文件名”。

## 注意事项

- “IMSI”和“IMSI文件名”是可选参数，必须有且只能有一个参数出现。
- “用户个数”和“IMSI文件名”不能同时配置。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                      |
|:------------|:--------|:----------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI    | 用于指示系统按照哪个“IMSI号码”来查询用户路由数据。                                                                                                                              |
| RECORDCOUNT | 用户个数    | 用于指示系统需要查询IMSI用户路由数据的用户个数。 当需要查询连续号码的多个用户的IMSI用户路由数据时配置该参数，配置后，系统将会从已指定的IMSI号码开始，查询连续号码的多个用户的IMSI用户路由数据。 说明：该参数用于查询连续号码的多个用户的IMSI用户路由数据，当只有一个用户时，该参数不必配置。 |
| IMSIFILE    | IMSI文件名 | 用于指示系统按照哪个“IMSI批操作文件”来查询用户路由数据。                                                                                                                           |

## 使用实例

1. 查询“IMSI”为“460030913121001”的用户的路由数据：

   ```
   LST IMSIRTSUB: IMSI="460030913121001";
   ```

   ```
   %%LST IMSIRTSUB: IMSI="460030913121001";%%
   RETCODE = 0 SUCCESS0001:操作成功

                             IMSI = 460030913121001
                            HLRSN = 1

   Total count = 2

   There is together 1 report

   ---    END
   ```
2. 批量查询IMSI用户的路由数据。其中，“IMSIFILE”为“lstimsirtsub.txt”：

   ```
   LST IMSIRTSUB: IMSIFILE="lstimsirtsub.txt";
   ```

   ```
   %%LST IMSIRTSUB: IMSIFILE="imsi.txt";%%
   RETCODE = 0 SUCCESS0001:操作成功 批操作ID: 268435476. 使用CHK BATSTAT指令可查看此批操作的执行情况

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见

**ADD IMSIRTSUB**

命令的参数说明。表1列出的是未包含在

**ADD IMSIRTSUB**

命令参数说明中的输出项。

| 输出项名称   | 输出项解释                                      |
|:--------|:-------------------------------------------|
| 批操作ID   | 用于返回批操作的任务号。通过执行CHK BATSTAT命令可以查询该任务的详细信息。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

| 错误码     | 错误码解释      | 原因分析                                                   | 处理建议                                                                                               |
|:--------|:-----------|:-------------------------------------------------------|:---------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值     | 参数“IMSI”的取值不是6～15位十进制数字组成的字符串。                         | 根据实际情况，重新输入“IMSI”的取值，确保其取值符合要求。                                                                    |
| ERR1009 | 参数丢失       | “IMSI”和“IMSI文件名”一个都没有输入。                               | 根据实际情况，重新输入参数，并满足“IMSI”和“IMSI文件名”必须有且只能有一个参数出现的条件。                                                 |
| ERR1005 | 文件未找到      | “IMSI文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                   | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。 |
| ERR1010 | 参数冲突       | 可能原因为如下之一：“IMSI”和“IMSI文件名”同时被输入。“用户个数”与“IMSI文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”和“IMSI文件名”必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”同时配置。                       |
| ERR1025 | 批操作文件中格式非法 | 参数“IMSI文件名”对应的批操作文件格式不正确。                              | 请根据IMSIFILE文件格式重新确定对应的批操作文件格式。                                                                     |
