# 修改核心网接入类型限制(MOD CNRESTRICT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于配置指定用户允许或限制接入指定的核心网。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数必须有且只能有一个参数出现。
- “用户个数” 参数不能与“IMSI文件名”或“MSISDN文件名”同时存在，“用户个数”参数只能与“IMSI”或“MSISDN”一起出现。

## 参数说明

| 参数标识          | 参数名称      | 参数说明                                                                                                                                                                                                                                                 |
|:--------------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI          | IMSI      | 用于标识需要修改核心网接入类型限制的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                           |
| ISDN          | MSISDN    | 用于标识需要修改核心网接入类型限制的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                         |
| RECORDCOUNT   | 用户个数      | 用于标识需要修改核心网接入类型限制的用户的数目。需要为连续号码的多个用户修改核心网接入类型限制时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行修改核心网接入类型限制管理数据。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户进行修改核心网接入类型限制，当只有一个用户时，该参数不必配置。 当一次修改核心网接入类型限制的用户个数很多时，对系统性能无影响，但修改核心网接入类型限制的用户个数越多，消耗的时间越长。 |
| IMSIFILE      | IMSI文件名   | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要修改的核心网接入类型限制管理数据的用户的IMSI号码，本编辑器编辑的文本文件（编码格式为ANSI），如“modcnrestrict.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                         |
| ISDNFILE      | MSISDN文件名 | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要修改核心网接入类型限制管理数据的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modcnrestrict.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                  |
| EPCNOTALLOWED | 是否限制接入EPC | 用于标识是否限制用户接入EPC网络。 取值范围：TRUE：限制，表示不允许用户接入EPC网络。FALSE：不限制，表示允许用户接入EPC网络。 默认值：无。 说明：该参数与SET MAPSERV命令的“EPC接入限制处理规则”参数配合使用，设置用户接入EPC网络的处理规则。                                                                                                            |
| NGCNOTALLOWED | 是否限制接入5GC | 用于标识是否限制用户接入5G核心网。 取值范围：TRUE：限制，表示不允许用户接入5G核心网。FALSE：不限制，表示允许用户接入5G核心网。 默认值：无。 说明：通过该参数为用户签约5G核心网接入限制业务后，可通过ADD NCCTPL命令的“Core-Network-Restrictions下发控制”参数设置Core-Network-Restrictions信元的下发处理。                                                        |

## 使用实例

修改“IMSI”为461120093456123的用户的核心网接入类型限制管理数据，其中“是否限制5GC接入”为“TRUE”，“是否限制EPC接入”为“TRUE”：

```
MOD CNRESTRICT: IMSI="461120093456123", NGCNOTALLOWED=TRUE, EPCNOTALLOWED=TRUE;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释      | 原因分析                                                                                                 | 处理建议                                                                                                               |
|:--------|:-----------|:-----------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值     | 可能的原因为如下之一： 参数“IMSI”的取值不是6～15位十进制数字组成的字符串。参数“MSISDN”的取值不是1～15位十进制数字组成的字符串。                           | 根据实际情况，重新输入“IMSI”或“MSISDN”的取值，确保其取值符合要求。                                                                           |
| ERR1005 | 文件不存在      | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                     | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                 |
| ERR1009 | 参数丢失       | 参数“IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数一个都没有输入。                                                  | 根据实际情况，重新输入参数，并满足“IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                        |
| ERR1010 | 参数冲突       | 可能的原因为如下之一： “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点： “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR1025 | 批操作文件中格式非法 | 参数“IMSI文件名”和“MSISDN文件名”对应的批操作文件格式不正确。                                                                | 请根据IMSIFILE文件格式或ISDNFILE文件格式，重新确定对应的批操作文件格式。                                                                       |
| ERR3001 | 用户未开户      | 用户的IMSI号码或MSISDN号码输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户。                                               | 核实用户的IMSI号码或MSISDN号码，如果输入有误，重新输入正确的IMSI号码或MSISDN号码。                                                                |
| ERR3007 | 记录不存在      | 用户未签约接入和移动管理数据。                                                                                      | 请执行LST AMDATA命令查询IMSI对应的用户是否未签约，若未签约请参考MOD AMDATA为用户签约正确的接入和移动管理数据后重新执行本条命令。                                       |
