# 删除透明数据同步规则(RMV REPSYNCRULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除透明数据同步规则数据记录。

## 注意事项

该命令用只允许通过以下几种方式删除透明数据同步规则数据：

- 仅输入“记录索引”。
- 仅输入“规则类型”。
- 仅输入“透明数据同步规则ID”
- 仅输入“透明数据同步规则ID”和“服务标识”

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                                                                   |
|:-------|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------|
| INDEX  | 记录索引       | 可选必选说明：可选参数 参数含义：用于指定根据哪个索引来删除透明数据同步规则。 取值范围：1～65534 默认值：无。 配置原则：无。                                                                    |
| RULEID | 透明数据同步规则ID | 可选必选说明：可选参数 参数含义：用于标识删除哪个透明数据同步规则ID的同步规则。 取值范围：1～65534 默认值：无。 配置原则：无。                                                                  |
| TYPE   | 规则类型       | 可选必选说明：可选参数 参数含义：用于标识删除哪种类型的透明数据同步规则。 取值范围： Global：全局规则SubBasis：用户级同步规则 默认值：无。 配置原则：无。                                                 |
| SRVIND | 服务标识       | 可选必选说明：可选参数 参数含义：用于标识删除哪个ServiceIndication对应的透明数据同步规则。如果存在字符“=”、“;”、“\”、“,”、“"”和“'”，需要在该字符前添加转义字符“\”。 取值范围：长度不超过127的字符串 默认值：无。 配置原则：无。 |

## 使用实例

当不再使用某些透明数据同步规则时，需要将其删除，配置举例如下：

1. 删除“记录索引”为“1”的透明数据同步规则：

   ```
   RMV REPSYNCRULE:INDEX=1;
   ```
2. 删除“规则类型”为SubBasis的透明数据同步规则。

   ```
   RMV REPSYNCRULE: TYPE = SubBasis;
   ```
3. 删除“透明数据同步规则ID”为“1”的透明数据同步规则：

   ```
   RMV REPSYNCRULE:RULEID=1;
   ```
4. 删除“透明数据同步规则ID”为“1”、“服务标识”为“abc”的透明数据同步规则：

   ```
   RMV REPSYNCRULE:RULEID=1, SRVIND="abc";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 消息解释                                         | 原因分析                    | 处理建议                                                      |
|:--------|:---------------------------------------------|:------------------------|:----------------------------------------------------------|
| ERR4186 | SRVIND对应的规则不存在，请使用LST REPSYNCRULE命令查询对应结果确认。 | 输入“服务标识”对应的规则不存在。       | 请使用LST REPSYNCRULE命令查询对应结果，重新输入已有透明数据同步规则对应的“服务标识”。       |
| ERR4187 | RULEID对应的规则不存在，请使用LST REPSYNCRULE命令查询对应结果确认。 | 输入“透明数据同步规则ID”对应的规则不存在。 | 请使用LST REPSYNCRULE命令查询对应结果，重新输入已有透明数据同步规则对应的“透明数据同步规则ID”。 |
