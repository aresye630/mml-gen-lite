# 查询KI(LST KI)

- 输出结果说明

## 命令功能

该命令用于查询相应用户的鉴权信息。

## 注意事项

执行该命令查询鉴权信息时，KI值是否隐藏由**SET MAPCONF**命令的“是否在查询KI结果中隐藏KI和OPC”参数控制：

- 新建局点中，该参数默认值为“TRUE”。
- 升级局点中，建议修改参数值为“TRUE”，如有疑问，请联系华为技术支持。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                        |
|:------------|:--------|:----------------------------------------------------------------------------|
| IMSI        | IMSI    | IMSI号码，E.212格式的编码，6～15位的十进制数字。                                              |
| RECORDCOUNT | 用户个数    | 用户的数目，最大10000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI为起始号码，号码连续的RECORDCOUNT个用户。 |
| IMSIFILE    | IMSI文件名 | IMSI文件名称，IMSIFILE包含多个不连续的IMSI号码，每个IMSI号码占一行，16个以内的字母或数字组成的字符串。              |

## 使用实例

查询“IMSI”号码为“460000009123456”的用户对应的KI。命令如下：

```
LST KI: IMSI="460000009123456";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD KI**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                          | 处理建议        |
|:--------|:--------|:--------------------------------------------------------------|:------------|
| ERR4133 | 密钥丢失    | 当SET MAPSERV命令中的“随机密钥默认ID”参数为非0，“随机密钥默认ID”参数对应的随机密钥材料不存在或不完整。 | 联系华为技术支持处理。 |
