# 增加云分区路由数据(ADD SPRTINFO)

## 命令功能

在混合组网平滑演进场景下，该命令用于设置云分区ID与HSS GT(Global Title)、SAE-HSS主机名和SAE-HSS域名、IMS-HSS主机名和IMS-HSS域名之间的对应关系，以实现数据不在接收消息的UDM上时，将数据转发至目标UDM上进行处理。

在UDM Translation Agent场景下，该命令用于设置对端HSS ID与HSS GT、SAE-HSS主机名和SAE-HSS域名、IMS-HSS主机名和IMS-HSS域名之间的对应关系，以实现UTA与HSS进行信令交互来获取用户数据。

## 注意事项

- UDM最多支持新增1000个云分区路由数据记录。
- “分区HLR号码”、“分区SAE-HSS主机名”、“分区IMS-HSS主机名”或“UDM的URI”至少存在一个。
- “分区SAE-HSS主机名”和“分区SAE-HSS域名”必须同时配置。
- “分区IMS-HSS主机名”和“分区IMS-HSS域名”必须同时配置。

## 使用实例

添加一条云分区路由数据，参数设置如下：

- “记录索引”取值为“2”
- “分区ID”取值为“20”
- “分区HSS名称”取值为“HSS9860”
- “分区HSS优先级”取值为“1”
- “分区HLR号码”取值为“8613901000”
- “分区SAE-HSS主机名”取值为“SAE-HSS-Host-1”
- “分区SAE-HSS域名”取值为“www.huawei.com”
- “分区IMS-HSS主机名”取值为“IMS-HSS-Host-1”
- “分区IMS-HSS域名”取值为“s1.huawei.com”

```
ADD SPRTINFO: INDEX=2, PID=20, HSSNAME="HSS9860", PRI=1, HLRNO="8613901000", SAEHSSHOST="SAE-HSS-Host-1", SAEHSSREALM="www.huawei.com", IMSHSSHOST="IMS-HSS-Host-1", IMSHSSREALM="s1.huawei.com";
```
