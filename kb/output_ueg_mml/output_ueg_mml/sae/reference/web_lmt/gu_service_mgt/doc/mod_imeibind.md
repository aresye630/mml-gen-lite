# 修改M2M绑定业务(MOD IMEIBIND)

- 命令功能

## 命令功能

该命令用于为用户签约、修改或撤销M2M绑定业务。

为了实现SIM卡防盗功能，可以通过该命令进行IMSI和IMEI绑定配置。

当签约M2M绑定业务时，一个IMSI仅能绑定一个IMEI，该绑定关系涉及PS、EPS和NGC域，即PS域、EPS域和NGC域使用同一个绑定关系。

M2M绑定分为如下2种：

- 自动绑定：用户签约了绑定关系，但没有输入要绑定的IMEI，则使用首次注册的IMEI与用户的IMSI进行绑定。
- 手工绑定：用户签约了绑定关系，同时输入了要绑定的IMEI，则使用提供的IMEI与用户的IMSI进行绑定。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”、“IMSI/IMEI文件名”、“MSISDN/IMEI文件名”六个参数必须有且只能有一个参数出现。
- “用户个数”参数一定不能与“IMSI文件名”、“MSISDN文件名”、“IMSI/IMEI文件名”或“MSISDN/IMEI文件名”同时存在，“用户个数”参数只能与“IMSI”或“MSISDN”一起出现，用于签约、修改或撤销多个用户的M2M绑定业务时使用。

## 参数说明

| 参数标识         | 参数名称           | 参数说明                                                                                                                                                                                                                                                                                 |
|:-------------|:---------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI         | IMSI           | 用于标识待签约、修改或撤销M2M绑定业务用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                         |
| ISDN         | MSISDN         | 用于标识待签约、修改或撤销M2M绑定业务用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                       |
| RECORDCOUNT  | 用户个数           | 用于标识待签约、修改或撤销M2M绑定业务用户的数目。 当需要为连续号码的多个用户签约、修改或撤销M2M绑定业务时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行签约、修改或撤销M2M绑定业务。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户进行签约、修改或撤销M2M绑定业务，当只有一个用户时，该参数不必配置。当一次签约、修改或撤销M2M绑定业务的用户个数很多时，对系统性能无影响，但签约、修改或撤销M2M绑定业务的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| OPTIONTYPE   | 操作类型           | 用于标识执行该命令时对IMEI绑定业务执行哪种操作。 取值范围：PROVIDE：签约IMEI绑定业务。MODIFY：修改已绑定的IMEI。WITHDRAW：撤销IMEI绑定业务。DELETEIMEI：删除已绑定的IMEI。 默认值：无。                                                                                                                                                               |

| ISDNFILE     | MSISDN文件名      | 仅当本命令中的“操作类型”参数设置为“PROVIDE”、“WITHDRAW”或“DELETEIMEI”时该参数有效，用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要签约、修改或撤销M2M绑定业务用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modimeibind.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                           |
| IMSIIMEIFILE | IMSI/IMEI文件名   | 仅当本命令中的“操作类型”参数设置为“PROVIDE”或“MODIFY”时该参数有效，用于标识IMSI/IMEI批操作文件。 IMSI/IMEI批操作文件包含多个不连续的需要签约、修改或撤销M2M绑定业务用户的IMSI号码和IMEI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modimeibind.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSI/IMEI文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                              |
| ISDNIMEIFILE | MSISDN/IMEI文件名 | 仅当本命令中的“操作类型”参数设置为“PROVIDE”或“MODIFY”时该参数有效，用于标识MSISDN/IMEI批操作文件。 MSISDN批操作文件包含多个不连续的需要签约、修改或撤销M2M绑定业务用户的MSISDN号码和IMEI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modimeibind.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见MSISDN/IMEI文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                           |
| IMEI         | 与IMSI绑定的IMEI   | 仅当本命令中的“操作类型”参数设置为“PROVIDE”或“MODIFY”时该参数有效，用于标识与IMSI绑定的IMEI号码。 取值范围：14位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                           |
| DELAYCANCEL  | 延迟下线标识         | 仅当本命令中的“操作类型”参数设置为“PROVIDE”、“MODIFY”或“DELETEIMEI”时该参数有效，用于在为用户签约IMEI绑定业务或修改绑定的IMEI的过程中，如果UDM的检查结果为禁止用户接入，那么UDM可以根据该参数来控制是否延迟将用户下线。 取值范围： TRUE：延迟将用户下线，表示UDM会在下一次位置更新或注册流程中将用户下线。FALSE：立即将用户下线。 默认值：FALSE。 说明：执行该命令并且不输入该参数时，系统会设置初始值FALSE。                                           |

## 使用实例

1. 为IMSI号码为“123456789012345”的用户提供M2M绑定业务，手工绑定IMEI为：12345678901234。命令如下：

   MOD IMEIBIND: IMSI="123456789012345", OPTIONTYPE=PROVIDE, IMEI="12345678901234";
2. 为IMSI号码为“123456789012345”的用户提供M2M绑定业务，自动绑定IMEI。命令如下：

   MOD IMEIBIND: IMSI="123456789012345", OPTIONTYPE=PROVIDE;
