# 增加NEF检查策略配置(ADD NEFCHKPOLICY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加系统对NEF网元合法性检查的配置策略。UDM收到NEF订阅、去订阅消息时，系统通过该命令配置白名单校验对端NEF的合法性。

**说明** 

- NEF合法性检查功能需要优先执行**SET UDMSERV**命令将参数“CLOSENEFCHECKURL”设置为“OPEN”，打开安全检查功能，校验NEF的合法性。
- 对于现网已经使用该功能场景，工程改造过程中在保证环境安全可信的情况下，为避免影响用户订阅业务，需要先执行**SET UDMSERV**命令将参数“CLOSENEFCHECKURL”设置为“CLOSE”，关闭安全检查功能放通消息。

## 注意事项

系统最多允许添加500条NEF检查策略记录。

## 参数说明

| 参数标识     | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                                                                                       |
|:---------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NEFNAME  | NEF名称      | 可选必选说明：必选参数 参数含义：用于标识NEF在系统中的名称。 取值范围：长度不超过64的字符串。 默认值：无。 配置原则：该参数全局唯一且该名称须与NEF端配置保持一致。                                                                                                                                                                                                                                                                                                    |
| TYPE     | 类型         | 可选必选说明：必选参数 参数含义：用于标识系统按照哪种类型配置NEF检查策略。 取值范围：IPV4：IPv4地址IPV6：IPv6地址FQDN：FQDNHOST_AND_REALM：主机名和域名 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                           |
| NEFFQDN  | NEF FQDN名称 | 可选必选说明：可选参数。 参数含义：用于标识NEF的全量域名。 取值范围：长度不超过255的字符串。 默认值：无。 配置原则：仅当本命令中的“类型”参数为“FQDN”时该参数有效。                                                                                                                                                                                                                                                                                                 |
| NEFHOST  | NEF主机名     | 可选必选说明：可选参数 参数含义：用于标识指定NEF网元的主机名。 取值范围：1～127位字符串。 默认值：无。 配置原则： 仅当本命令中“类型”参数为“HOST_AND_REALM”时该参数有效。“NEF主机名”和“NEF域名”必须同时存在，或同时不存在。 该参数取值必须满足以下配置原则：任意两个“.”不允许相邻。 任意两个“.”之间，第一个字符和最后一个字符必须为数字（0～9）或字母（a～z或A～Z）且长度小于等于63。 当SET MAPCONF命令中“是否进行主机名/域名合法性增强检查”参数取值为“TRUE”时，该参数除上述配置原则外还需满足以下配置原则：所有字符只能是数字（0-9）、字母（a～z或A～Z）、“.”或“-”。 首字符必须是数字（0～9）或字母（a～z或A～Z），最后一个字符必须是数字（0-9）、字母（a～z或A～Z）或“.” |
| NEFREALM | NEF域名      | 可选必选说明：可选参数 参数含义：用于标识指定NEF网元的域名。 取值范围：1～127位字符串。 默认值：无。 配置原则： 仅当本命令中“类型”参数为“HOST_AND_REALM”时该参数有效。 “NEF主机名”和“NEF域名”必须同时存在，或同时不存在。该参数取值必须满足以下配置原则：任意两个“.”不允许相邻。 任意两个“.”之间，第一个字符和最后一个字符必须为数字（0～9）或字母（a～z或A～Z）且长度小于等于63。 当SET MAPCONF命令中“是否进行主机名/域名合法性增强检查”参数取值为“TRUE”时，该参数除上述配置原则外还需满足以下配置原则：所有字符只能是数字（0-9）、字母（a～z或A～Z）、“.”或“-”。 首字符必须是数字（0～9）或字母（a～z或A～Z），最后一个字符必须是数字（0-9）、字母（a～z或A～Z）或“.”  |
| NEFIPV4  | NEF IPV4地址 | 可选必选说明：可选参数 参数含义：用于标识指定NEF网元的IPV4地址，由运营商统一规划。 取值范围：IPv4格式的地址。 默认值：无。 配置原则：仅当本命令中的“类型”参数为“IPV4”时该参数有效。                                                                                                                                                                                                                                                                                      |
| NEFIPV6  | NEF IPV6地址 | 可选必选说明：可选参数 参数含义：用于标识指定NEF网元的IPV6地址，由运营商统一规划。 取值范围：IPv6格式的地址。 默认值：无。 配置原则：仅当本命令中的“类型”参数为“IPV6”时该参数有效。                                                                                                                                                                                                                                                                                      |

## 使用实例

增加一条NEF检查策略配置记录。参数设置如下：

- “NEF名称”取值为“nefIPv4”
- “类型”取值为“IPV4”
- “NEF IPV4地址”取值为“127.20.128.110”

```
ADD NEFCHKPOLICY: NEFNAME="nefIPv4", TYPE=IPV4, NEFIPV4="127.20.128.110";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|:--------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------|

| ERR3006 | 记录已经存在 | 可能原因为如下之一： 输入的“NEF名称”已存在。参数“类型”取值为“IPV4”或“IPV6”时，输入的IP地址已存在。参数“类型”取值为“FQDN”时，输入的“NEF FQDN名称”已存在。参数“类型”取值为“HOST_AND_REALM”时，输入的“NEF主机名”和“NEF域名”已存在。    | 请按照以下步骤操作：执行LST NEFCHKPOLICY命令，查询已配置的NEF检查策略配置信息。根据查询结果重新输入“NEF名称”、“NEF IPV4地址”、“NEF IPV6地址”、“NEF FQDN名称”或“NEF主机名”和“NEF域名”，确保输入的参数不在查询结果中。 |
