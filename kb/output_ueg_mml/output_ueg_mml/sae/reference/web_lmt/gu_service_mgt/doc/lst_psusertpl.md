# 查询PS用户模板(LST PSUSERTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询PS用户模板的信息：

- 若需要查询全部的PS用户模板数据，请输入“HLR序列号”，其他参数不输入。
- 若需要查询某个模板ID的PS用户模板数据的详细信息，请输入“HLR序列号”和“模板ID”。

## 注意事项

仅输入“HLR序列号”查询所有的模板数据时，会导致PGW模块的CPU占用率升高，因此推荐输入“HLR序列号”和“模板ID”精确查询模板数据。当必须查询所有的模板数据时，请在低话务量时执行。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                       |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 用于指示系统按照哪个HLR序列号来查询PS用户模板数据，该参数必须选择。                                                                                                                                                                                                                                                                                       |
| TPLID  | 模板ID   | 用于指示系统按照哪个模板ID来查询PS用户模板数据；若不输入，则表示查询所有的PS用户模板数据。                                                                                                                                                                                                                                                                           |
| SAVEAS | 保存文件名  | 用于标识保存查询结果的文件名称。 当查询结果的记录数超过5000条时必须输入该参数，将查询结果保存在文件中，否则会报错“ERR4102：查询结果已经超过5000条，需要指定保存文件名进行查询”。 取值范围：长度不超过20的字符串。 默认值：无 说明：“保存文件名”参数指定的文件存放在主备PGW模块所在容器上，容器目录为“/opt/pgw/pgwtmpfile/SYSHLRSN+OPNAME”。SYSHLRSN默认为3位数字，不足3位时前面补0。如：SYSHLRSN=1，OPNAME=admin时，最后一层目录为001admin。 保存文件名参数指定的文件，可以通过“PGW Web LMT”界面右上角的“文件管理器”下载。 |

## 使用实例

1. 查询“HLR序列号”为“1”的所有PS用户模板信息。命令如下：

   ```
   LST PSUSERTPL: HLRSN=1;
   ```

   如果操作成功，返回的结果可能如下：

   ```
   %%LST PSUSERTPL: HLRSN=1;%%
   RETCODE = 0 SUCCESS0001:操作成功

                  TPLID        TPLNAME
                  1            PSUSERTPL_1
                  2            PSUSERTPL_2
                  3            PSUSERTPL_3

   Total count = 3

   There is together 1 report

   ---    END
   ```
2. 查询“HLR序列号”为“1”，“模板ID”为“10”的PS用户模板信息。命令如下：

   ```
   LST PSUSERTPL: HLRSN=1, TPLID=10;
   ```

   如果操作成功，返回的结果可能如下：

   ```
   %%LST PSUSERTPL: HLRSN=1, TPLID=10;%%
   RETCODE = 0 SUCCESS0001:操作成功

                            HLRSN = 1
                            TPLID = 10
                          TPLNAME = PSUSERTPL_10
                           CNTXID = 1
                    PSAPNQOSTPLID = 1

   Total count = 5

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释                        | 原因分析                       | 处理建议                     |
|:--------|:-----------------------------|:---------------------------|:-------------------------|
| ERR4102 | 查询结果已经超过5000条，需要指定保存文件名进行查询。 | 查询结果超过5000条，但未输入参数“保存文件名”。 | 输入参数“保存文件名”，将查询结果保存在文件中。 |
