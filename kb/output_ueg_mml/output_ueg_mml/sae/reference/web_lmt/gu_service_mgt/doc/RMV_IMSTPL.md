# 删除IMS用户模板(RMV IMSTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HSS的业务数据库中删除一个IMS用户模板。

## 注意事项

当“HLR序列号”参数不输入时，默认删除“HLR序列号”为“0”的记录。

## 参数说明

| 参数标识   | 参数名称      | 参数说明                                                      |
|:-------|:----------|:----------------------------------------------------------|
| HLRSN  | HLR序列号    | 用于指定需要删除哪一个HLR序列号的IMS用户基本信息模板记录，操作员可以使用LST HTPLINF命令查询获得。 |
| TPLID  | IMS用户模板ID | 用于指定需要删除哪一个IMS用户基本信息模板记录，操作员可以使用LST HTPLINF命令查询获得。        |

## 使用实例

删除IMS用户模板。IMS用户模板ID：1。

```
RMV IMSTPL: TPLID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                   | 处理建议                              |
|:--------|:--------|:---------------------------------------|:----------------------------------|
| ERR3003 | 模板未定义   | “IMS用户模板ID”输入错误，实际输入的参数“IMS用户模板ID”未定义。 | 可通过LST HTPLINF命令获取有效的“IMS用户模板ID”。 |
