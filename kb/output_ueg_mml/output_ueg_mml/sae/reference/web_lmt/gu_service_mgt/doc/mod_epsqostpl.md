# 修改EPS QoS模板(MOD EPSQOSTPL)

## 命令功能

此操作用于修改EPS QoS模板中的数据。

该命令用于对一条EPS QoS模板数据记录的某些参数进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一条EPS QoS模板数据记录：

- “HLR序列号”
- “模板ID”

## 注意事项

此模板被修改后，签约此模板的用户数据也会被修改，修改后的数据在用户新注册时会下发到网络。

## 参数说明

| 参数标识           | 参数名称          | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
|:---------------|:--------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN          | HLR序列号        | 标识EPS QoS模板数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR上的EPS QoS模板数据记录的参数进行修改或调整，操作员可以使用LST HLRSN命令查询获得。                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| TPLID          | QoS模板ID       | 标识EPS QoS模板数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪些EPS QoS模板数据记录的参数进行修改或调整，操作员可以使用LST EPSQOSTPL命令查询获得。                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| TPLNAME        | QoS模板名        | 用于标识EPS QoS模板名称。 取值范围：60个以内的数字或英文字母组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| QOSCLASUID     | QoS分类ID       | 用于标识QoS分类ID。 取值范围：1～127。 默认值：无。 说明： 一般情况下，“QoS分类ID”数值越小，QoS等级越高。当“QoS分类ID”值在1~9之外，且大部分对端不支持1~9之外取值时，需要优先设置SET DEFREPEPSQOSID命令设置缺省的替代关系，将该模板替换为一个“QoS分类ID”取值为1~9之内的模板。对于支持的对端，由于系统已经设置了缺省替代关系，需要通过ADD REPEPSQOSID或MOD REPEPSQOSID命令，将“用户签约的EPS QoS模板ID”和“替代的EPS QoS模板ID”都设置成该EPS QoS模板的ID，从而对于这些对端，依然下发该EPS QoS模板的数据。对于不支持的对端通过系统设置缺省的替代关系，UDM提供在默认替换模板中配置的“QoS分类ID”值。 当“QoS分类ID”取值在1~9之外，且大部分对端支持1~9之外取值时：对于支持的对端无需配置替代关系。UDM提供该模板中配置的“QoS分类ID”值。对于不支持的对端只需要使用ADD REPEPSQOSID或MOD REPEPSQOSID命令添加替代EPS QoS数据的配置，将该模板替换为一个“QoS分类ID”取值为1~9之内的模板。UDM提供替换后模板中配置的“QoS分类ID”值。 |
| EXTQCI         | 扩展QoS分类ID     | 用于标识扩展QoS分类ID。当用户接入的网络是本地PLMN时（是否本地PLMN由ADD PLMNTPL命令配置）则在业务流程中UDM不下发“QoS分类ID”参数，而是下发该参数。 取值范围：128～254。 默认值：无。 说明：一般情况下，“扩展QoS分类ID”数值越小，QoS等级越高。                                                                                                                                                                                                                                                                                                                                                                                                                         |
| PRILEVEL       | 分配/保留优先级数据    | 用于标识用来设置用户在网络资源拥塞时的优先级。 取值范围：1～15级。 默认值：无。 说明：运营商可以根据接入过程、业务保持过程等，分别设置用户的优先级。用户的优先级分为15个等级，数值越小，优先级越高。                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| PREEMPTIONCAP  | 业务数据流是否能够占有能力 | 用于标识是否允许该业务数据流占有优先级相对较低的业务数据流的资源。 取值范围： ENABLE：允许。DISABLE：禁止。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| PREEMPTIONVUL  | 业务数据流是否能够被占有  | 用于标识是否允许该业务数据流丢失分配给它的资源，用于接纳一个优先级相对较高的业务数据流。 取值范围： ENABLE：允许。DISABLE：禁止。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| AMBRMAXREQBWUL | 最大请求上行带宽      | 用于标识4G网络最大请求上行带宽，即发送消息的最大带宽。 取值范围：1～4294967295，单位：bit/s 默认值：无。 说明：该参数与本命令中“NR上行速率”只能配置一个。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| AMBRMAXREQBWDL | 最大请求下行带宽      | 用于标识4G网络最大请求下行带宽，即接受消息的最大带宽。 取值范围：1～4294967295，单位：bit/s 默认值：无。 说明：该参数与本命令中“NR下行速率”只能配置一个。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| AMBRNRUL       | NR上行速率        | 用于标识5G网络UE最大上行带宽，即UE最大的上传速率。 取值范围：1～4294967295，单位：kbit/s（1kbit/s = 1000bit/s） 默认值：无。 说明：该参数与本命令中“最大请求上行带宽”只能配置一个。如果上行速率配置该参数，则“最大请求上行带宽”参数由系统赋值为4294967295。当已配置“NR上行速率”参数时，如果配置“最大请求上行带宽”参数，则表示去签约“NR上行速率”。                                                                                                                                                                                                                                                                                                                                                              |
| AMBRNRDL       | NR下行速率        | 用于标识5G网络UE最大下行带宽，即UE最大的下载速率。 取值范围：1～4294967295，单位：kbit/s（1kbit/s = 1000bit/s） 默认值：无。 说明：该参数与本命令中“最大请求下行带宽”只能配置一个。如果下行速率配置该参数，则“最大请求下行带宽”参数由系统赋值为4294967295。当已配置“NR下行速率”参数时，如果配置“最大请求下行带宽”参数，则表示去签约“NR下行速率”。                                                                                                                                                                                                                                                                                                                                                              |

## 使用实例

修改一个EPS QoS漫游模板数据，“HLR序列号”为1，“模板ID”为10，“最大请求上行带宽”由100000 bit/s修改为200000 bit/s,“最大请求下行带宽”由200000 bit/s修改为400000 bit/s。命令如下:

`MOD EPSQOSTPL: HLRSN=1, TPLID=10, AMBRMAXREQBWUL=200000, AMBRMAXREQBWDL=400000;`

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                           | 处理建议                                                                                |
|:--------|:--------|:---------------------------------------------------------------|:------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”参数不在相应的参数取值范围内。                                  | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                    |
| ERR1010 | 参数冲突    | 可能原因为如下之一：“最大请求上行带宽”和“NR上行速率”参数同时输入。“最大请求下行带宽”和“NR下行速率”参数同时输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“最大请求上行带宽”和“NR上行速率”两个参数只能配置一个。“最大请求下行带宽”和“NR下行速率”两个参数只能配置一个。 |
| ERR3003 | 模板未定义   | “QoS模板ID”在数据库中未定义。                                             | 根据实际情况，重新输入参数，确保输入的“QoS模板ID”和系统中已存在的不重复。可执行LST EPSQOSTPL命令查询系统中已存在的区域漫游模板。          |
| ERR3007 | 记录不存在   | “HLR序列号”和“QoS模板ID”参数对应的模板不存在。                                  | 根据实际情况，重新输入“HLR序列号”和“模板ID”参数的取值，确保其对应的模板已存在。可执行LST EPSQOSTPL命令查询系统中已存在的PS模板。        |
