# 查询5G业务限制模板(LST NGCSERRESTTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询5G业务限制模板的数据：

- 若需要查询某个HLR序列号下全部的5G业务限制模板数据，请输入“HLR序列号”参数，其他参数不输入。
- 若需要查询某条5G业务限制模板的详细信息，请同时输入“HLR序列号”和“模板ID”参数。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                      |
|:-------|:-------|:------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 可选必选说明：必选参数 参数含义：用于指示系统按照哪个HLR序列号来查询5G业务限制模板数据。 取值范围：1～255 默认值：无。 配置原则：无。                 |
| TPLID  | 模板ID   | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个模板ID来查询5G业务限制模板数据，若不输入，则表示所有的模板ID。 取值范围：0～65534 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询5G业务限制模板信息，“HLR序列号”为“1”。

   ```
   LST NGCSERRESTTPL: HLRSN=1;
   ```

   ```
   %%LST NGCSERRESTTPL: HLRSN=1;%% 
   RETCODE = 0 SUCCESS0001:操作成功 
    
                  TPLID        TPLNAME 
                  1            NGCSERRESTTPL1 
                  65534        NGCSERRESTTPL2 
    
   Total count = 2 
    
   There is together 1 report 
    
   ---    END
   ```
2. 查询5G业务限制模板信息，“HLR序列号”为“1”，“模板ID”为“8”。

   ```
   LST NGCSERRESTTPL: HLRSN=1, TPLID=8;
   ```

   ```
   %%LST NGCSERRESTTPL: HLRSN=1, TPLID=8;%% 
   RETCODE = 0 SUCCESS0001:操作成功 
    
                            HLRSN = 1 
                            TPLID = 8 
                          TPLNAME = NGCSERRESTTPL1 
    
                         SERCODE1 = SMDATA 
                      SMDATATPLID = 1 
    
   Total count = 5 
    
   There is together 1 report 
    
   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD NGCSERRESTTPL**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                           | 处理建议                                                                                           |
|:--------|:--------|:-------------------------------|:-----------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | “HLR序列号”和“模板ID”参数对应的模板数据记录不存在。 | 根据实际情况，重新输入已定义的“HLR序列号”和“模板ID”，可通过LST HLRSN命令查询已定义的“HLR序列号”，通过LST NGCSERRESTTPL命令查询已定义的“模板ID”。 |
