# 新增外置AUC错误码映射(ADD AUCERRORCODE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于配置外置AUC返回的错误码与UDM最终返回给对端的错误码的映射信息。

UDM获取外置AUC返回的响应，响应失败时UDM按照本命令配置的错误码映射关系将“4G返回错误码”/“IMS返回错误码”发送给MME/SCSCF，如果错误码映射未配置，则统一向对端返回“5012 DIAMETER\_UNABLE\_TO\_COMPLY”错误提示。

## 注意事项

本命令最多支持配置100条错误码映射记录。

## 使用实例

给4G域配置错误码映射关系，其中，“原始错误码”为“403”，“4G返回错误码”为“DIAMETER\_MULTI\_ROUND\_AUTH(1001)”：

```
ADD AUCERRORCODE: DOMAIN=4G, ERRORCODE=403, 4G_RETURNCODE=DIAMETER_MULTI_ROUND_AUTH(1001);
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                             | 处理建议                                                                  |
|:--------|:--------|:-------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 输入的参数值不在其取值范围内或者输入的参数值不符合要求。                                                                     | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                      |
| ERR1009 | 参数丢失    | 可能原因如下： 必选参数中的一个或者多个没有输入。条件必选参数缺失：参数“域”取值为“4G”时，没有输入“4G返回错误码”参数；参数“域”取值为“IMS”时，没有输入“IMS返回错误码”参数。 | 重新输入参数，确保必选参数“域”、“原始错误码”都输入，同时确保条件必选参数“4G返回错误码”和“IMS返回错误码”符合参数配置原则。   |
| ERR1010 | 参数冲突    | 同时输入了“4G返回错误码”和“IMS返回错误码”参数。                                                                     | 根据“域”参数取值重新输入对应的返回错误码参数： 取值为“4G”时，输入“4G返回错误码”。取值为“IMS”时，输入“IMS返回错误码”。 |
| ERR3006 | 记录已存在   | 输入的“域”下对应的“原始错误码”已存在对应的“4G返回错误码”/“IMS返回错误码”。                                                     | 执行LST AUCERROCODE命令查看已存在的错误码映射，重新输入该域下其他错误码配置映射关系。                    |
