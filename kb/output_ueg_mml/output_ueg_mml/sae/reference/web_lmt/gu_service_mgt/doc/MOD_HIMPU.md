# 修改IMPU(MOD HIMPU)

## 命令功能

该命令用于对HSS的业务数据库中的一条IMPU记录进行修改。

当用户需要在不换卡的情况下更改号码，且新号码继承之前号码所有业务的时候，操作员可以使用该命令完成。在该命令中，系统通过“IMPU”参数来唯一标识一条IMPU数据记录。

## 注意事项

如果操作员修改某条IMPU记录，将使相应的用户被注销，从而导致正在使用该IMPU的用户不能正常使用通信业务，请操作员在执行该操作之前仔细确认任务的可行性 。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|:------------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMPU        | IMPU      | 标识一条IMPU数据记录的关键字段（其取值不能被修改），用于指定需要对哪一条IMPU数据记录进行修改，操作员可以使用LST HSUB命令查询获得。 取值范围：长度不超过127的字符串 默认值：无。 说明：必选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| NEWIMPU     | 新的IMPU    | 用于指定一个新IMPU。该参数的配置原则是：新开的IMPU必须与已有的IMPU不同。输入的IMPU值符合SIP URI或TEL URI格式，字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：必选参数。当IMPU为通配类型时，IMPU的格式必须含有“!.*!”且符合TEL URI和SIP URI格式的通配IMPU规则，目前支持以下4种格式，以固定号码为3314529的SIP URI格式举例如下：格式1：sip:3314529!.*!@huawei.com。格式2：sip:3314529![mnp].*!@huawei.com。例如sip:3314529![247].*!@huawei.com，以下号码可以匹配：sip:33145292!.*!@huawei.com sip:33145294!.*!@huawei.com sip:33145297!.*!@huawei.com 格式3：sip:3314529![m-p].*!@huawei.com。例如sip:3314529![2-4].*!@huawei.com，以下号码可以匹配：sip:33145292!.*!@huawei.com sip:33145293!.*!@huawei.com sip:33145294!.*!@huawei.com 格式4：格式2和格式3的混合格式。例如sip:3314529![02-57-9].*!@huawei.com，以下号码可以匹配：sip:33145290!.*!@huawei.com sip:33145292!.*!@huawei.com sip:33145293!.*!@huawei.com sip:33145294!.*!@huawei.com sip:33145295!.*!@huawei.com sip:33145297!.*!@huawei.com sip:33145298!.*!@huawei.com sip:33145299!.*!@huawei.com 注意事项： 对于格式2、格式3和格式4，要求m、n、p只能代表取值范围为0-9的一位数字（m<n<p），并且m、n、p的取值不能重复。 上述4种格式号码配置时不能出现号段重复，比如通配IMPU号码sip:3314529!.*!@huawei.com和sip:3314529![247].*!@huawei.com就含有sip:33145292!.*!@huawei.com、sip:33145294!.*!@huawei.com和sip:33145297!.*!@huawei.com三个重复号段，是不允许同时配置的。 |
| NEWIMPUTYPE | 新的IMPU的类型 | 用于标识修改后IMPU的类型。 取值范围：DIMPU(DIMPU)：表示新增的IMPU为非通配型。WIMPU(WIMPU)：表示新增的IMPU为通配型。 默认值：无。 说明：可选参数。一个通配IMPU代表一组IMPU。该通配IMPU或者一个能匹配到此通配IMPU的特定IMPU（specific IMPU）发起注册，均能达到注册整组IMPU的目的。注册完成后，所有匹配到该通配IMPU的特定IMPU（specific IMPU）均能够在HSS取到相同的业务签约数据和路由信息。系统允许的通配IMPU和通配PUSI数量最大为120000个。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |

## 使用实例

1. 修改IMPU，“IMPU”为“sip:impuinfo@huawei.com”，“新的IMPU”为“sip:new\_impuinfo@huawei.com”：

```
MOD HIMPU:IMPU="sip:impuinfo@huawei.com", NEWIMPU="sip:new_impuinfo@huawei.com";
```

2. 修改IMPU，“IMPU”为“sip:impuinfo@huawei.com”，“新的IMPU”为“tel:+33145297![247].\*!”，“NEWIMPUTYPE”为“WIMPU(WIMPU)”：

```
MOD HIMPU:IMPU="sip:impuinfo@huawei.com", NEWIMPU="tel:+33145297![247].*!", NEWIMPUTYPE=WIMPU;
```
