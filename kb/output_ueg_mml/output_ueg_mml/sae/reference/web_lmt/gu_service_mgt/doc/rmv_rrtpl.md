# 删除RR模板(RMV RRTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条区域漫游RR（Regional Roaming）模板数据记录。

## 注意事项

当执行该命令删除用户已签约的区域漫游模板时，系统会提示“ERR3005:模板已经被使用”的错误信息，该区域漫游模板不能被删除。如果要删除该区域漫游模板，必须先执行**MOD RSZI**命令给用户去签约相关的区域漫游模板。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                  |
|:-------|:-------|:----------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 标识区域漫游模板数据记录的关键字段之一，用于指定需要删除哪个HLR上的区域漫游模板数据记录，操作员可以使用LST HLRSN命令查询获得。 |
| TPLID  | 模板ID   | 标识区域漫游模板数据记录的关键字段之一，用于指定需要删除哪一条区域漫游模板数据记录，操作员可以使用LST RRTPL命令查询获得。     |

## 使用实例

删除“HLR序列号”为“1”的HLR上的区域漫游模板数据记录。其中，“模板ID”为“1”：

```
RMV RRTPL: HLRSN=1, TPLID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                             | 处理建议                                                                   |
|:--------|:--------|:---------------------------------|:-----------------------------------------------------------------------|
| ERR3003 | 模板未定义   | “HLR序列号”和“模板ID”对应的区域漫游模板数据记录不存在。 | 使用LST RRTPL命令查询后，重新确认要删除哪个“HLR序列号”和“模板ID”对应的区域漫游模板数据记录。                |
| ERR3005 | 模板已经被使用 | 用户已签约该模板。                        | 根据实际情况，确定是否要删除该模板。如果确实需要删除，先通过MOD RSZI命令给用户去签约该模板，然后才能执行RMV RRTPL命令删除。 |
