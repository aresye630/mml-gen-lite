# 删除号段组(RMV NUMGROUP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一个号段组。

## 注意事项

当执行该命令删除已签约的号段组时，系统会提示“ERR4082：号段组已经被使用”，该号段组不能被删除。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                           |
|:--------|:-------|:---------------------------------------------------------------|
| GROUPID | 号段组ID  | 标识号段组数据记录的唯一关键字段，用于指定需要删除哪个号段组的数据记录，操作员可以使用LST NUMGROUP命令查询获得。 |

## 使用实例

删除号段组，“号段组ID”为“1”：

```
RMV NUMGROUP: GROUPID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释    | 原因分析                          | 处理建议                                                                  |
|:--------|:---------|:------------------------------|:----------------------------------------------------------------------|
| ERR4082 | 号段组已经被使用 | 输入的参数“号段组ID”被ADD OPRANGE命令关联。 | 根据实际情况，如果需要删除该号段组：执行MOD OPRANGE命令，输入参数“号段组ID”，删除操作员签约的号段组。执行该命令删除号段组。 |
