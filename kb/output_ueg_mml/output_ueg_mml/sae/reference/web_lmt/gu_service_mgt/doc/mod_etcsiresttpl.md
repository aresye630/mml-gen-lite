# 修改ETCSI限制模板（MOD ETCSIRESTTPL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改ETCSI限制模板中的参数设置或在指定的ETCSI限制模板记录中添加或删除一个ETCSI业务键。如果ETCSI限制模板中需要定义多个ETCSI业务键，需要使用**ADD ETCSIRESTTPL**命令定义一个ETCSI限制模板，然后使用该命令增加多个ETCSI业务键。

在该命令中，系统通过以下关键参数的组合来唯一标识一个ETCSI限制模板：

- “HLR序列号”
- “模板ID”

## 注意事项

- “模板名”和“是否提供ETCSI”两个参数至少存在一个。
- 系统中所有ETCSI限制模板增加的ETCSI业务键总记录数不能超过3000条。

## 参数说明

| 参数标识     | 参数名称      | 参数说明                                                                                         |
|:---------|:----------|:---------------------------------------------------------------------------------------------|
| HLRSN    | HLR序列号    | 标识ETCSI限制模板记录的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR上的ETCSI限制模板记录的参数进行修改或调整，操作员可以使用LST HLRSN命令查询获得。   |
| TPLID    | 模板ID      | 标识ETCSI限制模板记录的关键字段之一（其取值不能被修改），用于指定需要对哪个ETCSI限制模板记录的参数进行修改或调整，操作员可以使用LST ETCSIRESTTPL命令查询获得。 |
| TPLNAME  | 模板名       | 用于标识待修改模板在系统中的名称。 取值范围：1～60位字母或十进制数字组成的字符串。 默认值：无。                                           |
| PROV     | 是否提供ETCSI | 用于标识待修改模板是否提供限制下发的ETCSI业务键。 取值范围：TRUE：提供FALSE：不提供 默认值：无。                                     |
| ETCSI_SK | ETCSI业务键  | 仅当本命令中的“是否提供ETCSI”参数为“TRUE”或 “FALSE”时该参数有效，用于标识模板中限制下发的ETCSI业务键。 取值范围：1～999 默认值：无。           |

## 使用实例

1. 修改“HLR序列号”为“1”、“模板ID”为“2”的ETCSI限制模板信息，修改“模板名”为“ETCSI2”、并增加“ETCSI业务键”为“2”的记录，命令如下：

   ```
   MOD ETCSIRESTTPL: HLRSN=1, TPLID=2, TPLNAME="ETCSI2", PROV=TRUE, ETCSI_SK=2;
   ```
2. 修改“HLR序列号”为“1”、“模板ID”为“2”的ETCSI限制模板信息，删除“ETCSI业务键”为“2”的记录，命令如下：

   ```
   MOD ETCSIRESTTPL: HLRSN=1, TPLID=2, PROV=FALSE, ETCSI_SK=2;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                                      | 处理建议                                                                                                                                       |
|:--------|:--------|:----------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | 可能原因为如下之一：“HLR序列号”和“模板ID”参数对应的ETCSI限制模板数据记录不存在。 “是否提供ETCSI”参数设置为“FALSE”删除ETCSI业务键时，输入的“ETCSI业务键”对应的记录不存在。 | 根据实际情况，重新输入参数，确保满足以下两点：可通过LST ETCSIRESTTPL命令只输入参数“HLR序列号”获取有效的“模板ID”。可通过LST ETCSIRESTTPL命令输入参数“HLR序列号”和“模板ID”获取有效的“ETCSI业务键”。              |
| ERR3006 | 记录已存在   | “是否提供ETCSI”参数设置为“TRUE”添加ETCSI业务键时，输入的“ETCSI业务键”对应的记录已存在。                                                  | 该ETCSI业务键已添加，根据实际情况确认是否需要添加其他的ETCSI业务键。                                                                                                    |
| ERR3047 | 超过最大限制  | 增加的“ETCSI业务键”记录数超过3000条。                                                                                  | 根据实际情况，如需增加ETCSI业务键，处理步骤如下：执行LST ETCSIRESTTPL命令，查询已存在ETCSI业务键。执行RMV ETCSIRESTTPL命令，删除不必要的ETCSI业务键。执行该命令增加ETCSI业务键，确保增加的ETCSI业务键记录数在规定范围之内。 |
| ERR1009 | 参数丢失    | “模板名”和“是否提供ETCSI”两个参数都没有输入。                                                                               | 根据实际情况，重新输入参数，并满足“模板名”和“是否提供ETCSI”两个参数至少存在一个。                                                                                              |
| ERR3096 | 模板不能为空  | 当“是否提供ETCSI”参数设置为“FALSE”时，删除的ETCSI业务键是模板的最后一条记录。                                                          | 请确认是否需要删除模板内的最后一条信息记录，若需要删除，请通过RMV ETCSIRESTTPL命令删除相应模板。                                                                                   |
