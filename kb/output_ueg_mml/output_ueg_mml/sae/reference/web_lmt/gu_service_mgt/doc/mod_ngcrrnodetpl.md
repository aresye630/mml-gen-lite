# 修改NGC漫游限制模板操作(MOD NGCRRNODETPL)

## 命令功能

**须知** 

该命令属于高危命令，修改NGC漫游限制模板会使引用此模板的用户NGC漫游限制数据被同步修改。因此执行该命令前，请仔细评估当前操作的风险，确认对业务没有影响后方可执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该操作用于完成漫游限制模板中区域模板的添加，修改和删除。删除区域模板时，如果是最后一个区域模板，则不允许删除。在该命令中，系统通过以下关键参数的组合来唯一标识一个漫游限制模板：

- “HLR序列号”
- “模板ID”

## 注意事项

执行此命令时，“模板名”和“区域模板操作类型”两个参数必须至少配置一个。

## 使用实例

修改NGC漫游限制模板数据，“HLR序列号”为“1”，“模板ID”为“1”，“模板名”为“a”，“区域模板操作类型”为“ADD”，“漫游限制区域模板ID”为“1”，“漫游限制状态”为“RESTRICT”：

```
MOD NGCRRNODETPL: HLRSN=1,TPLID=1,TPLNAME="a", OPTYPE=ADD, RRAREATPLID=1,RULE= RESTRICT;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                       | 处理建议                                                                                                                                   |
|:--------|:--------|:---------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 界面输入的“HLR序列号”、“模板ID”、“模板名”、“区域模板操作类型”、“漫游限制区域模板ID”或“漫游限制状态”参数不在相应的参数取值范围内。 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                       |
| ERR3003 | 模板未定义   | “HLR序列号”和“模板ID”参数对应的模板记录不存在。                                               | 根据实际情况，重新输入已定义的“HLR序列号”和“模板ID”，可通过LST HLRSN命令查询已定义的“HLR序列号”，通过LST NGCRRNODETPL命令查询已定义的“模板ID”。                                          |
| ERR3007 | 记录不存在   | “HLR序列号”未定义。                                                               | 根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求。                                                                                                      |
| ERR3047 | 超过最大限制  | NGC漫游限制模板关联的漫游限制区域模板数超过20000个。                                             | 根据实际情况，如需修改NGC漫游限制模板，处理步骤如下：执行LST NGCRRNODETPL命令，查询已存在的NGC漫游限制模板关联的漫游限制区域模板。执行RMV NGCRRNODETPL命令，删除不必要的NGC漫游限制模板关联的漫游限制区域模板。再次使用本命令修改。 |
