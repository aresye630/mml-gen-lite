# 修改IMPI的SIP Digest鉴权信息(MOD HSDAINF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HSS的业务数据库中修改已经支持SIP Digest鉴权的“IMPI”的“用户名称”、“密码”、“HA1值”和“域名”。在该命令中，系统通过“IMPI”参数来唯一标识一条“IMPI”的SIP Digest鉴权信息。

如果用户的注册状态为REGISTERED或UNREGISTERED：若执行此命令修改用户的“密码”或“域名”后，HSS将发送PPR消息到用户所在的S-CSCF；若执行此命令修改用户的“用户名称”后，HSS将发送RTR消息到用户所在的S-CSCF。

## 注意事项

- “用户名称”、“密码”、“域名”、“HA1值”四个参数中必须至少存在一个。
- 对于一个“IMPI”，“HA1值”和“用户名称”、“密码”只能存在一种，即只有“HA1值”或只有“用户名称”和“密码”。推荐使用HA1值。
- 如果在“命令输入区”输入命令后再输入各参数，“密码”和“HA1值”出于安全原因，仅显示“\*”。
- 如果在“MML命令编辑区”直接输入带参数的命令，命令中的“密码”和“HA1值”以明文显示。
- 当**SET MAPCONF**命令中的“是否启用随机密钥”参数为“TRUE”，执行该命令时如果未执行**SET DEFAULTK2SNO**命令设置默认K2，则执行该命令时会返回错误。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                    |
|:----------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMPI      | IMPI   | 标识一条SIP Digest数据记录的关键参数（其取值不能被修改），用于指定需要对哪一条SIP Digest数据记录的参数进行修改或调整。要求输入的IMPI值符合NAI格式，字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：必选参数。                                                                                                                                                                                                                       |
| HUSERNAME | 用户名称   | 用于定义一个新的用户名称，该参数的配置原则是要求输入的用户名必须唯一。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                   |
| PWD       | 密码     | 用于定义一个新的密码。 取值范围：长度不超过128的字符串 “密码”参数支持输入的字符串类型由SET HSECPOLICY命令的“密码字符集”参数控制，默认支持输入大写字母、小写字母、数字。运营商设置支持输入特殊字符且输入的特殊字符中包含“;”、“,”时，则需要在特殊字符前添加转义字符“\”。例如参数输入“\;”，输出为“;”。 默认值：无。 说明：为提升系统的安全性，该参数在输入值时请参考已配置的密码强度检查策略。IMS-HSS在操作人员输入密码时会按照已配置的密码强度检查策略进行检查，若此参数的设置不符合检查策略，则会提示错误信息。密码强度检查策略可通过SET HSECPOLICY命令配置，通过LST HSECPOLICY命令查询，检查策略具体流程可参考密码强度检查流程图。 |
| REALM     | 域名     | 用于定义一个新的域名。 取值范围：由1～46位字母、数字、“-”和“.”组成的字符串。 默认值：无。 说明：可选参数。为HTTP Digest鉴权用户提供SIP Digest鉴权数据时必须输入。该参数仅在域名后缀为“.3gppnetwork.org”（不区分大小写）的情况下支持32～46位域名输入，其他域名格式只支持到31位。当支持32～46位格式时由于域名后缀匹配不区分大小写，在使用相关查询命令查询时，域名后缀显示结果均按小写显示。例如输入“域名”参数为“SOFT300.IMS.mnc001.mcc001.3gPPNETwork.org”时，查询结果为“SOFT300.IMS.mnc001.mcc001.3gppnetwork.org”。                    |
| HA1       | HA1值   | 用于定义一个HA1值。要求输入16进制字符，字母不区分大小写。 取值范围：长度等于32的16进制字符串 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                     |

## 使用实例

1. 修改IMPI的SIP Digest鉴权信息，“IMPI”为“impiinfo”，“用户名称”为“impiinfo”，“密码”为“Sysabcde@2009”，“域名”为“huawei.com”：

   ```
   MOD HSDAINF: IMPI="impiinfo", HUSERNAME="impiinfo", PWD="*****", REALM="huawei.com";
   ```
2. 修改IMPI的SIP Digest鉴权信息，“IMPI”为“impiinfo”，“域名”为“huawei.com”，“HA1”为“11112222333344445555666677778888”：

   ```
   MOD HSDAINF: IMPI="impiinfo", REALM="huawei.com", HA1="*****";
   ```

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。
