# 增加业务区域限制模板(ADD OKSCTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此操作用来设置业务区域限制模板，为用户签约业务区域限制做准备。

## 注意事项

同一个“HLR序列号”中增加的业务区域限制模板记录数不能超过5000条。

## 使用实例

增加1号业务区域限制模板：

- “模板名”为“OKSCTPL”。
- “话音业务”为“TS11”。
- “短消息业务”为“TS21”。
- “传真业务”为“TS61”。
- “承载业务”为“BS20”。
- “GPRS业务”为“RESTRICT”。

命令如下：

ADD OKSCTPL: HLRSN=1, TPLID=1, TPLNAME="OKSCTPL", TELE=TS11, SMS=TS21, FAX=TS61, BS=BS20, GPRS=RESTRICT;

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                               | 处理建议                                                                                                                              |
|:--------|:--------|:-----------------------------------|:----------------------------------------------------------------------------------------------------------------------------------|
| ERR3047 | 超过最大限制  | 同一个“HLR序列号”中增加的业务区域限制模板记录数超过5000条。 | 根据实际情况，如需增加业务区域限制模板，处理步骤如下：执行LST OKSCTPL命令，查询已存在的业务区域限制模板。执行RMV OKSCTPL命令，删除不必要的业务区域限制模板。执行该命令增加业务区域限制模板，确保增加的业务区域限制模板记录数在规定范围之内。 |
