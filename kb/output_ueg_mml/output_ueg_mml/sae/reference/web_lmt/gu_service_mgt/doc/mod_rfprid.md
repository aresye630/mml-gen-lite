# 修改无线频率选择优先级(MOD RFPRID)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改用户无线频率选择优先级数据。

## 注意事项

“IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”是互斥参数，有且只能有一个参数出现。

## 参数说明

| 参数标识            | 参数名称      | 参数说明                                                                                                                                                                                                                    |
|:----------------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI            | IMSI      | 用于标识需要修改无线频率选择优先级的用户的IMSI号码。 取值范围：E.212格式的编码，6～15位的十进制数字。 默认值：无。                                                                                                                                                        |
| ISDN            | MSISDN    | 用于标识需要修改无线频率选择优先级的用户的MSISDN号码。 取值范围：E.164格式的编码，1～15位的十进制数。 默认值：无。                                                                                                                                                       |
| RECORDCOUNT     | 用户个数      | 用于标识需要修改无线频率选择优先级的用户数量。 当需要为多个连续号段的用户修改无线频率选择优先级时配置该参数，选择后，系统将会从已指定的IMSI或MSISDN号码开始，对连续号码的多个用户修改优先级。 取值范围：1～100000。 默认值：无。 该参数使用约束如下： “IMSI文件名”和“MSISDN文件名”不能输入。“IMSI”或“MSISDN”必须存在一个。如果只有一个用户，该参数不必提供。                 |
| IMSIFILE        | IMSI文件名   | 用于标识IMSI批操作文件名称。 IMSI批操作文件包含多个不连续的待修改无线频率选择优先级的用户IMSI号码，该文件为文本编辑器编辑的文本文件（编码格式为ANSI），如“modrfprid.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。 说明：每个IMSI号码占一行。文件后缀名为“.txt”。   |
| ISDNFILE        | MSISDN文件名 | 用于标识MSISDN批操作文件名称。 MSISDN批操作文件包含多个不连续的待修改无线频率选择优先级的用户IMSI号码，该文件为文本编辑器编辑的文本文件（编码格式为ANSI），如“modrfprid.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDN文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。 说明：每个MSISDN号码占一行。文件后缀名为“.txt”。 |
| RATFREQSELPRIID | 无线频率选择优先级 | 用于标识无线接入网分配和维护无线信道时所采用的无线资源管理策略，数值越小优先级越高。 取值范围：0～256。 0：表示去签约无线频率选择优先级。1～256：表示签约的无线频率选择优先级。 默认值：无。                                                                                                                    |

## 使用实例

1. 修改“IMSI”为“460000009123456”的“无线频率选择优先级”为“1”：

   `MOD RFPRID: IMSI="460000009123456", RATFREQSELPRIID=1;`
2. 为“IMSI”为“460000009123456”的用户去签约“无线频率选择优先级”：

   `MOD RFPRID: IMSI="460000009123456", RATFREQSELPRIID=0;`
3. 批量修改用户的“无线频率选择优先级”，具体操作如下：
   1. 编写IMSI批操作文件。
      - 文件名为“IMSI.txt”。
      - 文件格式：
        - 460000009012345
        - 460000009012346
        - 460000009012347
        - 460000009012348
   2. 通过Web UI上的文件选项将IMSI批操作文件上传到指定位置。
   3. 批量修改用户的“无线频率选择优先级”为“2”：

      `MOD RFPRID: IMSIFILE="IMSI.txt", RATFREQSELPRIID=2;`

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释         | 原因分析                                                                                               | 处理建议                                                                                                                    |
|:--------|:--------------|:---------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值        | 可能原因为如下之一：参数“IMSI”的取值不是6～15位十进制数字组成的字符串。参数“MSISDN”的取值不是1～15位十进制数字组成的字符串。                           | 根据实际情况，重新输入“IMSI”或“MSISDN”的取值，确保其取值符合要求。                                                                                |
| ERR1009 | 参数丢失          | “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数一个都没有输入。                                                  | 根据实际情况，重新输入参数，并满足“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                             |
| ERR1005 | 文件未找到         | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                   | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                      |
| ERR1010 | 参数冲突          | 可能原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR3810 | 用户不是EPS用户或未开户 | 用户的IMSI号码或MSISDN号码输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户或者不是EPS用户。                                    | 核实IMSI号码或MSISDN号码，确保其对应的用户为EPS用户并验证其正确性，如果确定输入无误，证明实际输入的参数“IMSI”或“MSISDN”对应的用户未开户，请参考ADD SUB页面给用户开户。                    |
| ERR1025 | 批操作文件中格式非法    | 参数“IMSI文件名”或“MSISDN文件名”对应的批操作文件格式不正确。                                                              | 请根据IMSIFILE文件格式和ISDNFILE文件格式，重新确定对应的批操作文件格式。                                                                            |
