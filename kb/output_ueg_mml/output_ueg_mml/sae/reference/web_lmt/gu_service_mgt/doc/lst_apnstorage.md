# 查询APN数据存储信息(LST APNSTORAGE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询用户APN数据在数据库中的存储信息：

- 若需要查询单个用户APN数据在数据库中的存储信息，请输入“IMSI”或“MSISDN”。
- 若需要查询多个连续用户APN数据在数据库中的存储信息，请输入“IMSI”或“MSISDN”与“用户个数”的组合。
- 若需要查询多个不连续用户APN数据在数据库中的存储信息，请输入“IMSI文件名”或“MSISDN文件名”。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                     |
|:------------|:----------|:-----------------------------------------|
| IMSI        | IMSI      | 用于指定系统按照哪个IMSI号来查询用户APN数据在数据库中的存储信息。     |
| ISDN        | MSISDN    | 用于指定系统按照哪个MSISDN号来查询用户APN数据在数据库中的存储信息。   |
| RECORDCOUNT | 用户个数      | 用于指定系统查询多少个连续用户APN数据在数据库中的存储信息。          |
| IMSIFILE    | IMSI文件名   | 用于指定系统按照哪个IMSI文件名来查询用户APN数据在数据库中的存储信息。   |
| ISDNFILE    | MSISDN文件名 | 用于指定系统按照哪个MSISDN文件名来查询用户APN数据在数据库中的存储信息。 |

## 使用实例

1. 查询“IMSI”号码为“460000009123456”的用户APN数据在数据库中的存储信息：

```
LST APNSTORAGE: IMSI="460000009123456";
```

```
%%LST APNSTORAGE: IMSI="460000009123456";%%
RETCODE = 0 SUCCESS0001:操作成功

                          IMSI = 460000009123456
                          ISDN = 460000009123456

      CONTEXTID  APN_TYPE  STORAGE     ADDIND   APN
      3          PS        PSINDEXED   STATIC   APN

Total count = 3

There is together 1 report

---    END
```

2. 查询第一个“IMSI”号码为“460000009123456”的连续3个用户APN数据在数据库中的存储信息：

```
LST APNSTORAGE: IMSI="460000009123456", RECORDCOUNT=3;
```

```
%%LST APNSTORAGE: IMSI="460000009123456", RECORDCOUNT=3;%%
RETCODE = 0 SUCCESS0001:操作成功 批操作ID：7. 使用CHK BATSTAT指令可查看此批操作的执行情况

There is together 1 report

---    END
```

3. 查询“MSISDN文件名”为“lstapnstorage.txt”的用户APN数据在数据库中的存储信息：

```
LST APNSTORAGE: ISDNFILE="apnstorage.txt";
```

```
%%LST APNSTORAGE: ISDNFILE="apnstorage.txt";%%
RETCODE = 0 SUCCESS0001:操作成功 批操作ID：268435464. 使用CHK BATSTAT指令可查看此批操作的执行情况

There is together 1 report

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**MOD APNSTORAGE**命令的参数说明，表1列出的是未包含在**MOD APNSTORAGE**命令参数说明中的输出项。

| 输出项名称     | 输出项解释                                                                                                                                                    |
|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------|
| CONTEXTID | 用于返回PDP/PDN上下文索引值。                                                                                                                                       |
| APN_TYPE  | 用于返回APN类型。                                                                                                                                               |
| STORAGE   | 用于返回用户APN数据信息存储位置。该参数值为“GPRS”、“OPTGPRS”、“PSSER”或“EPSSER”时，表示对应数据存储方式为非索引化数据存储，其存储位置为原业务表。该参数值为“PSINDEXED”或“EPSINDEXED”时，表示数据存储方式为索引化数据存储，其索引数据存储在对应的索引表。 |
| ADDIND    | 用于返回PDP/PDN地址标识。                                                                                                                                         |
| APN       | 用于返回模板中的APN的值。                                                                                                                                           |
| 批操作ID     | 用于返回批操作的任务号。通过执行CHK BATSTAT命令可以查询该任务的详细信息。                                                                                                               |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

| 错误码     | 错误码解释      | 原因分析                                                                                               | 处理建议                                                                                                                    |
|:--------|:-----------|:---------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值     | 输入的界面参数不在取值范围内。                                                                                    | 参考MOD APNSTORAGE命令的参数说明，重新输入取值范围内的参数值。                                                                                  |
| ERR1009 | 参数丢失       | “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数一个都没有输入。                                                  | 根据实际情况，重新输入参数，确保“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                              |
| ERR1005 | 文件未找到      | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                   | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                      |
| ERR1010 | 参数冲突       | 可能原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR1025 | 批操作文件中格式非法 | 参数“IMSI文件名”或“MSISDN文件名”对应的批操作文件格式不正确。                                                              | 请根据IMSIFILE文件格式和ISDNFILE文件格式，重新确定对应的批操作文件格式。                                                                            |
| ERR3001 | 用户未开户      | 用户输入的参数“IMSI”或“MSISDN”对应的用户未开户。                                                                    | 核实用户的IMSI号码或MSISDN号码，如果确定输入无误，证明该用户已销户，不需要再执行命令，否则重新输入正确的IMSI号码或MSISDN号码。                                               |
