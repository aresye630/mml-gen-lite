# 删除园区数据过滤条件(RMV CAMPUSDATAFILTER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成园区数据无法导出，需要与华为技术支持确认后才可以实施。

该命令用于删除园区数据导出的过滤条件。

## 注意事项

- 该命令仅在特定局点使用，其他局点不需要配置。
- 执行该命令，会导致过滤不到对应园区用户数据，请谨慎操作。
- 删除时需要校验“FILTERNAME”是否已经被园区引用，如果被引用则会有错误提示。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                  |
|:------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| FILTERNAME  | 过滤条件名称 | 可选必选说明：必选参数 参数含义：标识一条园区数据记录的关键字段，用于指定需要删除哪一条“过滤条件名称”对应的园区数据过滤条件记录，操作员可以使用LST CAMPUSDATAFILTER命令查询获得。 取值范围：长度不超过64位的字符串，只允许输入数字和字母。 默认值：无。 配置原则：无。                                                                                                                                                                                     |
| FILTERTYPE  | 过滤条件类型 | 可选必选说明：必选参数 参数含义：用于指定需要删除哪一条“过滤条件类型”园区数据过滤条件记录。 取值范围： IMSIPRE：IMSI前缀过滤条件类型。MSISDNPRE：MSISDN前缀过滤条件类型。DNN：DNN过滤条件类型。SNSSAI：SNSSAI过滤条件类型。 默认值：无。 配置原则：无。                                                                                                                                                                                 |
| FILTERVALUE | 过滤条件值  | 可选必选说明：必选参数 参数含义：用于指定需要删除哪一条“过滤条件值”园区数据过滤条件记录。 取值范围：长度不超过64位的字符串。 当“过滤条件类型”参数为“IMSIPRE”或者“MSISDNPRE”时：10~15位十进制字符串。当“过滤条件类型”参数为“DNN”时：1～64位的字符串，只允许输入字母、数字、“-”、“_”、“.”和“*”。当“过滤条件类型”参数为“SNSSAI”时：长度为1～10位字符串，由SST（Slice/Service Type）与SD（Slice Differentiator）组成，SST与SD间使用“-”连接。SST为取值范围是0～255的数字。SD是固定长度为3字节的十六进制字符串。 默认值：无。 配置原则：无。 |

## 使用实例

删除全部匹配过滤条件记录，输入“过滤条件名称”为“FILTERNAME3”,“过滤条件类型”为“DNN”，“过滤条件值”为“1-F143A5”。

```
RMV CAMPUSDATAFILTER: FILTERNAME="FILTERNAME3", FILTERTYPE=DNN, FILTERVALUE="1-F143A5";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 消息解释           | 原因分析                               | 处理建议                                                               |
|:--------|:---------------|:-----------------------------------|:-------------------------------------------------------------------|
| ERR3007 | 记录不存在。         | 输入“过滤条件名称”参数对应的记录不存在。              | 通过LST CAMPUSDATAFILTER命令查询已存在的记录。根据已存在的记录重新输入“过滤条件名称”参数。           |
| ERR4166 | FILTERNAME被引用。 | 执行该命令时，“过滤条件名称”不能被ADD CAMPUSCFG引用。 | 通过LST CAMPUSCFG命令查询是否存在引用的“过滤条件名称”。如果存在引用的“过滤条件名称”，请根据实际情况重新输入该参数。 |
