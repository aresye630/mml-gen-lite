# 删除APN限制模板(RMV APNRESTTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此命令用于删除APN限制模板。

## 注意事项

无。

## 参数说明

| 参数标识         | 参数名称   | 参数说明                                         |
|:-------------|:-------|:---------------------------------------------|
| HLRSN        | HLR序列号 | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 |
| APNRESTTPLID | 模板ID   | 用于指示系统需要删除哪个APN限制模板。 取值范围：0～65534 说明：此参数为必选。 |

## 使用实例

删除一条APN限制模板，“HLR序列号”为“1”，“模板ID”为“2”：

```
RMV APNRESTTPL: HLRSN=1, APNRESTTPLID=2;
```
