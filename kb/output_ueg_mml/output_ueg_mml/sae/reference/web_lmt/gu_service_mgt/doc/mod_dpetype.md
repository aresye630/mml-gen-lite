# 修改Diameter对端类型(MOD DPETYPE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使用户漫游到此Diameter对端区域后可能出现位置更新失败，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改MME/S4SGSN类型信息。在该命令中，系统通过以下关键参数的组合来唯一标识一条MME/S4SGSN类型信息：

- “HLR序列号”
- “对端身份标识”

## 注意事项

- 若随意修改该配置，会造成对端网元上报用户漫游数据不正确或者签约闭锁漫游业务失败，请谨慎操作。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识           | 参数名称               | 参数说明                                                                                                                                                                                            |
|:---------------|:-------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN          | HLR序列号             | 标识Diameter对端类型信息数据的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR上的Diameter对端类型信息数据记录的参数进行修改，操作员可以使用LST HLRSN命令查询获得。                                                                                             |
| PEERENTITYTYPE | 对端身份标识类型           | 用于标识对端Diameter身份标识类型。 取值范围： Host Name：主机名，表示通过Diameter服务节点设备的主机名进行身份标识。Realm Name：域名，表示通过Diameter服务节点所在域的域名进行身份标识。 默认值：无。                                                                       |
| PEERENTITY     | 对端身份标识             | 标识Diameter对端类型信息数据的关键字段之一（其取值不能被修改），用于指定需要对哪个Diameter对端类型信息数据记录的参数进行修改，操作员可以使用LST DPETYPE命令查询获得。                                                                                                |
| PEERNAME       | 对端实体的名称            | 用于标识对端实体的名称。 取值范围：1～30位的字符串。 默认值：无。                                                                                                                                                             |
| TYPE           | 业务属性               | 用于标识对端实体相对于本HSS所属的网络类型。关于网络类型划分可参考VLR和本地HLR的位置关系示意图。 取值范围： LOCAL：本地。LOCALDOMESTIC：国内本网。CROSSDOMESTIC：国内跨网。LOCALINTERNATIONAL：国际本网。CROSSINTERNATIONAL：国际跨网。LOCALAREA：省内本网。CROSSAREA：省内跨网。 默认值：无。 |
| NETTYPE        | 网络类型               | 用于标识对端实体所在的网络是否支持VoLTE。 取值范围： VoLTE: 支持VoLTE。NON_VoLTE: 不支持VoLTE。 默认值：无。                                                                                                                        |
| MMENCCPROV     | 是否提供MME NCC        | 用于标识是否提供MME实体的NCC模板。 取值范围： TRUE: 设置FALSE: 不设置 默认值：无。                                                                                                                                            |
| MMENCCTPL      | MME实体对应的NCC模板ID    | 仅当本命令中的“是否提供MME NCC”参数为“TRUE”时该参数有效。用于标识MME实体所使用的NCC模板号，指定MME实体的NCC模板能力。该参数必须先由ADD NCCTPL命令定义，然后才能在此处引用。 取值范围：0～99998 默认值：无。                                                                    |
| S4SGSNNCCPROV  | 是否提供S4SGSN NCC     | 用于标识是否提供S4SGSN实体的NCC模板。 取值范围： TRUE: 设置FALSE: 不设置 默认值：无。                                                                                                                                         |
| S4SGSNNCCTPL   | S4SGSN实体对应的NCC模板ID | 仅当本命令中的“是否提供S4SGSN NCC”参数为“TRUE”时该参数有效。用于标识S4SGSN实体所使用的NCC模板号，指定S4SGSN实体的NCC模板能力。该参数必须先由ADD NCCTPL命令定义，然后才能在此处引用。 取值范围：0～99998 默认值：无。                                                           |

## 使用实例

修改对端的闭锁漫游业务配置，其数据配置流程如下:

1. 登录PGW Web LMT，执行该命令设置MME/S4SGSN相对于本UDM所属的网络类型，即MME/S4SGSN相对于本地UDM的位置信息。其中“HLR序列号”为“1”，“对端身份标识”为“test.huawei.com”，“对端实体的名称”为“test”，“网络类型”为“NON\_VoLTE”，“是否提供MME NCC”为“TRUE”，“MME实体对应的NCC模板ID”为“1”:

   ```
   MOD DPETYPE: HLRSN=1, PEERENTITY="test.huawei.com", PEERNAME="test", NETTYPE=NON_VoLTE, MMENCCPROV=TRUE, MMENCCTPL=1;
   ```
2. 设置是否控制用户在EPS网络中的漫游。执行**SET MAPCONF**命令设置“ODBROAM是否控制EPS域”参数为“TRUE”。

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                  | 处理建议                                                                                               |
|:--------|:--------|:------------------------------------------------------|:---------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”参数不在相应的参数取值范围内。                         | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                   |
| ERR3003 | 模板未定义   | “MME实体对应的NCC模板ID”或“S4SGSN实体对应的NCC模板ID”参数对应的模板数据记录不存在。 | 根据实际情况，重新输入参数，确保“MME实体对应的NCC模板ID”或“S4SGSN实体对应的NCC模板ID”参数对应的模板数据记录已存在。已存在的模板数据记录可以通过LST NCCTPL命令查询。 |
| ERR3007 | 记录不存在   | “HLR序列号”和“对端身份标识”对应的Diameter对端数据记录不存在。                | 使用LST DPETYPE命令查询后，重新确认要修改哪个“HLR序列号”和“对端身份标识”对应的Diameter对端数据记录。                                    |
