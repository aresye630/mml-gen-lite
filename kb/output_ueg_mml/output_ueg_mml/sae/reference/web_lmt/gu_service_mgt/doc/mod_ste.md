# 修改STE业务(MOD STE)

## 命令功能

该命令用于修改2G/3G用户的Spatial Triggers业务数据。

- 对于在网用户执行该命令后，如果是给用户签约Spatial Triggers业务，则UDM会向VLR下发Spatial Triggers业务数据并且更新数据库中的数据；如果是给用户去签约Spatial Triggers业务，则UDM会向VLR下发删除Spatial Triggers业务数据并且更新数据库中的数据。
- 对于不在网用户执行该命令后，则仅会更新用户在数据库中的数据。当用户进行位置更新时，如果用户签约了Spatial Triggers业务，UDM将用户的Spatial Triggers业务数据下发给VLR。

**说明** 

仅当用户所处VLR在**ADD NCCTPL**命令中“STE下发受限标志”参数设置为“SR”时，才会向VLR下发Spatial Triggers业务数据，否则不会下发。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                |
|:------------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 用于标识需要修改Spatial Triggers业务数据的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                               |
| ISDN        | MSISDN    | 用于标识需要修改Spatial Triggers业务数据的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                             |
| RECORDCOUNT | 用户个数      | 用于标识需要修改Spatial Triggers业务数据的用户数目。 当需要为连续号码的多个用户修改Spatial Triggers业务数据时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户修改Spatial Triggers业务数据。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户修改Spatial Triggers业务数据，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名   | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要修改Spatial Triggers业务数据的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modsgsnnum.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                                                   |
| ISDNFILE    | MSISDN文件名 | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要修改Spatial Triggers业务数据的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modsgsnnum.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                                             |
| STE_PROV    | 是否提供STE业务 | 用于标识是否为用户提供STE(Spatial triggers event)业务。 取值范围：TRUE：提供STE业务FALSE：撤销STE业务 默认值：FALSE。                                                                                                                                                                                                 |
| GMLC_ADD    | GMLC地址    | 仅当本命令中的“是否提供STE业务”参数取值为“TRUE”时该参数有效。用于标识STE业务触发时，MSC发送通知消息的目的GMLC地址。GMLC接到通知消息后转发给LCS客户端。 取值范围：E.164格式的地址，1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                  |

## 使用实例

1. 给IMSI号码为“460000009123456”的用户提供STE业务，“IMSI”号码为“460000009123456”，“是否提供STE业务”为“TRUE”，“GMLC地址”为“345678912”：

   ```
   MOD STE: IMSI="460000009123456", STE_PROV=TRUE, GMLC_ADD="345678912";
   ```
2. 给3个连续号码的用户提供STE业务，这3个MSISDN号码分别为“13310911001”、“13310911002”、“13310911003”，“是否提供STE业务”为“TRUE”，“GMLC地址”为“345678912”：

   ```
   MOD STE: ISDN="460000009123456", RECORDCOUNT=3, STE_PROV=TRUE, GMLC_ADD="345678912";
   ```
3. 给3个非连续号码的用户撤销STE业务，这3个MSISDN号码分别为“13310911001”、“13310911003”、“13310911005”，已保存在“MSISDN文件名”为“modspn.txt”的文件中，并通过文件管理功能上传到指定目录，“是否提供STE业务”为“FALSE”：

   ```
   MOD STE: ISDNFILE="modspn.txt", STE_PROV=FALSE;
   ```

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| ERR1004 | 无效的参数值     | 输入的界面参数不在取值范围内。                                                                                    | 参考参数说明，重新输入取值范围内的参数值。                                                                                               |
| ERR1005 | 文件未找到      | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                   | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                  |
| ERR1009 | 参数丢失       | “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数一个都没有输入。                                                  | 根据实际情况，重新输入参数，并满足“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现。                                            |
