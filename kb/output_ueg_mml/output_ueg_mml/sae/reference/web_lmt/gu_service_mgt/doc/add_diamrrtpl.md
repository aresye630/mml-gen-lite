# 增加Diameter漫游限制模板(ADD DIAMRRTPL)

## 命令功能

该命令用于增加Diameter漫游限制模板的信息数据。操作员通过执行**MOD DIAMRRS**命令可以给EPS用户签约该模板，签约后运营商可以灵活高效的对用户进行移动性管理。

## 注意事项

- 执行该命令只能给一个模板增加一个“Diameter身份标识”，如果需要增加多个“Diameter身份标识”，请执行**MOD DIAMRRTPL**命令。
- 系统中增加的Diameter漫游限制模板个数不能超过3000个，同一个Diameter漫游限制模板增加的Diameter身份标识记录数不能超过4000条，且所有Diameter漫游限制模板增加的Diameter身份标识总记录数不能超过40000条。
- 同一个Diameter漫游限制模板只能配置一个“缺省业务下发模板ID”和“缺省业务限制模板ID”。

## 使用实例

为EPS用户签约Diameter漫游限制业务操作员需要配置以下数据。

1. 增加一个Diameter漫游限制模板。“HLR序列号”为“1”，“模板ID”为“100”，“缺省漫游限制状态”为“PERMISSION”，“缺省业务下发模板ID”为“11”，“Diameter身份标识”为“test.huawei.com”，“Diameter身份标识类型”为“HOSTNAME”，“主机域名”为“huawei.com”，“漫游限制状态”为“RESTRICT”，“业务下发模板ID”为“22”：

   ```
   ADD DIAMRRTPL: HLRSN=1, TPLID=100, DEFAULTRULE=PERMISSION, DEFRSITPLID=11, DIAMIDENTITY="test.huawei.com", DIAMIDENTITYTYPE=HOSTNAME, REALMNAME="huawei.com", RULE=RESTRICT, RSITPLID=22;
   ```
2. 执行**MOD DIAMRRS**命令给用户签约Diameter漫游限制业务。

   ```
   MOD DIAMRRS: IMSI="460000009034567", PROV=TRUE, DIAMNODETPL_ID=100;
   ```

该命令执行正常，会返回命令执行成功的提示信息。

| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”参数不在相应的参数取值范围内。                                                                                                | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                                                                                                         |
