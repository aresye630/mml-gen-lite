# 设置IRS的默认IMPU(SET HDEFIMPU)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HSS的业务数据库中设置指定隐式注册集的默认IMPU，执行该操作后，指定的“IMPU”将被设置为默认IMPU，原默认IMPU将被取消。

S-CSCF使用默认IMPU实现呼叫和会话控制。当HSS通过SAA消息发送签约数据给S-CSCF时，同时也在该消息中携带隐式注册集的默认IMPU。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                                                                                                      |
|:-------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------|
| IRSID  | 隐式注册集ID | 用于指定一条隐式注册集记录，该参数必须先由SET HIRS操作定义，然后才能在此处索引。 取值范围：1～255 默认值：无。 说明：必选参数。                                                                   |
| IMPU   | IMPU    | 用于指定一个需要设置为默认IMPU的“IMPU”。该参数的配置原则是：该IMPU必须不是闭锁状态（可以通过LST HBAR命令查询）。输入的IMPU值符合SIP URI或TEL URI格式，字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：必选参数。 |

## 使用实例

设置IRS的默认IMPU，“隐式注册集ID”为“2”，“IMPU”为“sip:impuinfo@huawei.com”：

```
SET HDEFIMPU: IRSID=2, IMPU="sip:impuinfo@huawei.com";
```
