# 撤销GPRS业务(RMV GPRS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本操作提供直接删除GPRS业务的操作方法。采用此操作取消用户所有PDP上下文相关的数据。

执行此命令后，会下发删除用户数据消息。

## 注意事项

IMSI、ISDN是条件可选参数，有且只能有一个参数出现。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                          |
|:-------|:-------|:----------------------------------------------|
| IMSI   | IMSI   | 此参数用于设置IMSI号码。 取值范围：E.212格式的编码，6～15位的十进制数字。   |
| ISDN   | MSISDN | 此参数用于设置MSISDN号码。 取值范围：E.164格式的编码，1～15位的十进制数字。 |

## 使用实例

撤销GPRS业务：IMSI为“460000009123456”，执行如下命令：

```
RMV GPRS: IMSI="460000009123456";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释    | 原因分析                                                                                                                 | 处理建议                                                                     |
|:--------|:---------|:---------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------|
| ERR3111 | 系统不支持该特性 | 该命令不支持GPRS优化管理或者PS/EPS独立模板管理，即仅当SET MAPSERV命令中“GPRS管理方式”取值为“NotSupportGPRSManager” 或“SupportGPRSManager”时，该命令才能执行成功。 | 联系华为技术支持，确认当前局点软参“GPRS管理方式”是否设置正确、当前局点使用的GPRS管理方式是否正确。详情见“GPRS管理方式”软参描述。 |
