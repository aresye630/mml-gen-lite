# 增加操作员号段权限(ADD OPRANGE)

## 命令功能

**须知** 

该命令属于高危命令，增加操作员号段权限会造成扩大操作员所能操作的号段范围。因此执行该命令前，请仔细评估当前操作员权限，确认对业务发放系统没有影响后方可执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用来增加操作员所能操作的2G/3G/4G用户的号段组范围。

系统通过**ADD NUMGROUP**命令增加号段组后，然后执行该命令为操作员配置号段组权限，同时通过参数“操作员所允许操作号段的类型”检测相应号段组的合法性，相同的号段组可被多个操作员管理。

## 注意事项

- 仅当**SET MAPSERV**命令中“号段权限检测方式”参数值设置为“OPR\_NUMBER”时，通过用户归属HLRSN和所属操作员的号段两个维度同时检测操作员的权限。
- 执行该命令只能为操作员定义一个号段组，如果需要定义多个号段组，则需要执行**MOD OPRANGE**命令进行添加。
- 操作员的级别为ADMINISTRATOR或操作员被赋给该命令权限时，才具有增加号段的权限。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识      | 参数名称          | 参数说明                                                                                                                                                                                                                                                                                           |
|:----------|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OPNAME    | 操作员名称         | 用于标识操作员登录的名称。该参数必须先由ADD OPR命令定义，然后才能在此处引用。 取值范围：不超过32位的数字、字母和下划线组成的字符串，且首字符必须为字母。 默认值：无。 说明：ADD OPR命令是系统管理类型的命令，需要在“MML导航树”下拉框中选择“系统管理”，才可以在MML界面中执行。                                                                                                                                          |
| GROUPTYPE | 操作员所允许操作号段的类型 | 用于标识操作员对IMSI/MSISDN号段所允许操作的类型。 该参数用于对ADD NUMGROUP命令中参数“IMSI/MSISDN号段前缀”和“号码长度”进行合法性检测，检测成功后，操作员可以管理该号段组的用户数据，否则操作员无权管理该号段组的用户数据。 取值范围：BOTH：对IMSI/MSISDN号段都进行合法性检测。IMSI：只对IMSI号段进行合法性检查。无需检测MSISDN号段，操作员对MSISDN号段可以进行业务发放操作。MSISDN：只对MSISDN号段进行合法性检查。无需检测IMSI号段，操作员对IMSI号段可以进行业务发放操作。 默认值：BOTH。 |
| GROUPID   | 号段组ID         | 用于标识号段组ID。该参数必须先由ADD NUMGROUP命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。                                                                                                                                                                                                                               |

## 使用实例

增加一条操作员号段权限记录，需要进行如下配置：

1. 登录OM Portal的“USCDB MML命令”界面。
2. 执行**MOD INSP**命令，设置软参NP开关的值为“0”。“软件参数类型”为“PGW(业务发放网关)”、“软件参数名称”为“NPSWITCH(NP 开关)”、“软件参数值”为“0”：

   ```
   MOD INSP: INSPT=PGW, INSPN=NPSWITCH, INSPV=0;
   ```
3. 登录PGW MML系统管理窗口。
4. 执行**ADD OPR**命令，增加操作员。“操作员名称”为“opr1”：

   ```
   ADD OPR: SYSHLRSN=1, OPNAME="opr1", PWD="*****", CFM="*****", UG=ADMINISTRATOR, STATUS=ACTIVE;
   ```
5. 执行**ADD OPRHLRSN**命令，增加操作员虚拟HLR。“操作员名称”为“opr1”，“虚拟HLR序列号”为“1”：

   ```
   ADD OPRHLRSN: SYSHLRSN=1, OPNAME="opr1", HLRSN=1;
   ```
6. 登录“UDM业务管理”窗口。
7. 执行**SET MAPSERV**命令，设置号段权限检测方式的值为“OPR\_NUMBER”。“号段权限检测方式”为“OPR\_NUMBER”：

   ```
   SET MAPSERV: NUMBERRIGHTCHECK=OPR_NUMBER;
   ```
8. 执行**ADD NUMGROUP**命令，增加号段组。“号段组ID”为“1”：

   ```
   ADD NUMGROUP: GROUPID=1, GROUPTYPE=MSISDN, PREFIX="139", LENGTH=11;
   ```
9. 增加操作员号段权限。“操作员名称”为“opr1”、“操作员所允许操作号段的类型”为“MSISDN”、“号段组ID”为“1”：

   ```
   ADD OPRANGE: OPNAME="opr1", GROUPTYPE=MSISDN, GROUPID=1;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                       | 处理建议                                                              |
|:--------|:--------|:---------------------------|:------------------------------------------------------------------|
| ERR4083 | 号段组未定义  | 输入的参数“号段组ID”对应的号段组数据记录不存在。 | 根据实际情况，重新输入参数“号段组ID”，确保“号段组ID”对应的号段组数据记录存在，可使用LST NUMGROUP命令进行查询。 |
