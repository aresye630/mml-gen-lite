# 修改操作员号段权限(MOD OPRANGE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

该命令属于高危命令，修改操作员号段权限会造成扩大或缩小操作员所能操作的号段范围。因此执行该命令前，请仔细评估当前操作员权限，确认对业务发放系统没有影响后方可执行。如有疑问请与华为技术支持联系制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用来修改操作员所能操作的2G/3G/4G用户的号段组范围。在该命令中，系统通过以下关键参数的组合来唯一标识一个操作员号段权限信息：

- “操作员名称”
- “号段组ID”

## 注意事项

- 操作员的级别为ADMINISTRATOR或操作员被赋给该命令权限时，才具有修改号段的权限。
- 系统中所有操作员签约的号段组总记录数不能超过1000条。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识      | 参数名称          | 参数说明                                                                                                                                                                                                                                                                                        |
|:----------|:--------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OPNAME    | 操作员名称         | 用于标识操作员号段权限信息数据的唯一关键字段（其取值不能被修改），用于指定需要对哪个操作员的权限信息进行修改，操作员可以使用LST OPR命令查询获得。 说明：LST OPR命令是系统管理类型的命令，需要在“MML导航树”下拉框中选择“系统管理”，才可以在MML界面中执行。                                                                                                                                                   |
| GROUPTYPE | 操作员所允许操作号段的类型 | 用于标识操作员对IMSI/MSISDN号段所允许操作的类型。 该参数用于对ADD NUMGROUP命令中参数“IMSI/MSISDN号段前缀”和“号码长度”进行合法性检测，检测成功后，操作员可以管理该号段组的用户数据，否则操作员无权管理该号段组的用户数据。 取值范围：BOTH：对IMSI/MSISDN号段都进行合法性检测。IMSI：只对IMSI号段进行合法性检查。无需检测MSISDN号段，操作员对MSISDN号段可以进行业务发放操作。MSISDN：只对MSISDN号段进行合法性检查。无需检测IMSI号段，操作员对IMSI号段可以进行业务发放操作。 默认值：无。 |
| OPTYPE    | 操作类型          | 用于标识在操作员记录中添加或删除号段组。 取值范围：ADD：新增号段组。DEL：删除号段组。 默认值：无。 说明：操作员签约的最后一个号段组不能被删除。                                                                                                                                                                                                                |
| GROUPID   | 号段组ID         | 仅当参数“操作类型”取值为“ADD”或“DEL”时该参数有效。 用于标识操作员号段权限信息数据的关键字段之一（其取值不能被修改），用于指定需要操作员的哪个号段组权限信息进行修改，操作员可以使用LST NUMGROUP命令查询获得。                                                                                                                                                                         |

## 使用实例

修改操作员号段权限，“操作员名称”为“opr1”、“操作员所允许操作号段的类型”为“MSISDN”、“操作类型”为“ADD”、“号段组ID”为“2”：

```
MOD OPRANGE: OPNAME="opr1", GROUPTYPE=MSISDN, OPTYPE=ADD, GROUPID=2;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                       | 处理建议                                                              |
|:--------|:--------|:---------------------------|:------------------------------------------------------------------|
| ERR4083 | 号段组未定义  | 输入的参数“号段组ID”对应的号段组数据记录不存在。 | 根据实际情况，重新输入参数“号段组ID”，确保“号段组ID”对应的号段组数据记录存在，可使用LST NUMGROUP命令进行查询。 |
