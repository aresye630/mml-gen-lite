# 增加号段组(ADD NUMGROUP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于增加号段组，即为号段组配置标识2G/3G/4G用户的IMSI/MSISDN号段前缀信息。

号段组管理方式：系统为号段组定义可匹配的IMSI/MSISDN号段前缀及号码长度，以便配置了相应号段权限的操作员管理号段组的用户数据，否则操作员无权管理号段组的用户数据。通过执行**ADD OPRANGE**命令为操作员配置号段组管理权限，相同的IMSI/MSISDN号段组可被多个操作员管理。

## 注意事项

- 执行该命令只能为号段组定义一个IMSI/MSISDN号段前缀，如果需要定义多个IMSI/MSISDN号段前缀，则需要执行**MOD NUMGROUP**命令进行添加。
- 相同的IMSI/MSISDN号段前缀不允许配置在不同的号段组中。
- 系统中增加的号段组记录数不能超过1000条。

## 参数说明

| 参数标识      | 参数名称            | 参数说明                                                                                                                                              |
|:----------|:----------------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
| GROUPID   | 号段组ID           | 用于标识待增加的一个号段组。该参数在UDM中唯一，不能重复。 取值范围：0～65534 默认值：无。                                                                                                |
| GROUPNAME | 号段组名            | 用于标识待增加号段组在系统中的名称。 取值范围：1～60个字母或十进制数字组成的字符串。 默认值：无。                                                                                               |
| GROUPTYPE | 号段类型            | 用于标识待增加号段组的类型。 取值范围：IMSI：表示IMSI号段组。MSISDN：表示MSISDN号段组。 默认值：无。                                                                                     |
| PREFIX    | IMSI/MSISDN号段前缀 | 用于标识待增加号段组的IMSI/MSISDN号段前缀。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 说明：操作员进行业务发放操作时，先通过该参数进行最大前缀匹配，匹配成功后操作员才能对权限范围内的号段进行业务发放操作，否则无权限进行业务发放操作。               |
| LENGTH    | 号码长度            | 用于标识允许操作员进行业务发放操作的IMSI/MSISDN的号码长度。 取值范围：0～15 系统初始设置值为：0。 说明：操作员进行业务发放操作时，通过该参数进行号码长度匹配，匹配成功后操作员才能对权限范围内的号段进行业务发放操作，否则无权限进行业务发放操作。“0”表示不需要号码长度匹配。 |

## 使用实例

增加号段组，“号段组ID”为“1”、“号段组名”为“numgroup1”、“号段类型”为“MSISDN”、“IMSI/MSISDN号段前缀”为“139”、“号码长度”为“11”：

```
ADD NUMGROUP: GROUPID=1, GROUPNAME="numgroup1", GROUPTYPE=MSISDN, PREFIX="139", LENGTH=11;
```
