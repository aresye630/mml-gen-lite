# 删除IMPI和IMSI的关联关系(RMV HASSOC)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于从HSS的业务数据库中删除一条IMPI与IMSI的关联的数据记录。

## 注意事项

执行命令前，需要确保对应的IMSI没有被同一SUBID下的其他EAA用户关联。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                  |
|:-------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------|
| IMPI   | IMPI   | 标识一条IMPI与IMSI关联关系的数据记录的关键参数，用于指定需要删除哪一条IMPI和IMSI关联关系的数据记录。要求输入的IMPI值符合NAI格式，字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无                        |
| IMSI   | IMSI   | 标识一条IMPI与IMSI关联关系的数据记录的关键参数，用于指定需要删除哪一条IMPI和IMSI关联关系的数据记录，IMSI由长度[6，15]位的十进制数字(0～9)组成，采用E.212格式。例如：460001234567890。 取值范围： 6–15 缺省值： 无 |

## 使用实例

删除IMPI和IMSI的关联关系。IMPI：impiinfo，IMSI：460001234567890。

```
RMV HASSOC: IMPI="impiinfo", IMSI="460001234567890";
```
