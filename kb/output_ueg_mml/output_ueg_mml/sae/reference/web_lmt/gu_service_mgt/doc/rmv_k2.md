# 删除K2(RMV K2)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条K2数据记录。

## 注意事项

只有没有被使用的K2数据才可以删除。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                             |
|:-------|:-------|:-----------------------------------------------------------------|
| HLRSN  | HLR序列号 | 标识K2数据记录的关键字段之一，用于指定在哪个HLR上删除K2的数据记录，操作员可以使用LST HLRSN命令查询获得。     |
| K2SNO  | K2序列号  | 标识一条K2数据记录的关键字段之一，用于标识需要删除哪一个K2序列号对应的K2数据记录，操作员可以使用LST K2命令查询获得。 |

## 使用实例

删除K2数据，“HLR序列号”为“6”，“K2序列号”为“100”：

```
RMV K2: HLRSN=6, K2SNO=100;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD KI**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析             | 处理建议        |
|:--------|:--------|:-----------------|:------------|
| ERR3359 | K2在使用   | 删除的K2正在被KI值加密使用。 | 联系华为技术支持处理。 |
