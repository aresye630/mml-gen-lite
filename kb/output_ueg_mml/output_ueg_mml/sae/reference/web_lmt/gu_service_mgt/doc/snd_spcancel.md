# 指定Service Partition发送模拟Cancel Location消息（SND SPCANCEL）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在混合组网下，用户从其他网元迁移到UDM后，UDM触发指定Service Partition的HSS向用户漫游地VLR/SGSN/MME/AAA/CSCF发送模拟Cancel Location消息。

## 注意事项

- “SID”、“IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”五个参数必须有且只能有一个参数出现。
- “用户个数” 参数一定不能与“SID”或“IMSI文件名”或“MSISDN文件名”同时存在，“用户个数”参数只能与“IMSI”或“MSISDN”一起出现。
- 该命令只能在混合组网下使用，且必须在vRSP上执行。

## 使用实例

1. “IMSI”为“460000009123456”的用户从ATCA HSS迁移到UDM后，UDM触发“PID”为“55”的HSS向用户漫游地发送模拟Cancel Location消息：

   ```
   SND SPCANCEL: IMSI="460000009123456", PID=55;
   ```
2. “IMSI”为“460000009123456”、“460000009123457”、“460000009123458”的3个连续用户从ATCA HSS迁移到UDM后，UDM触发“PID”为“100”的HSS向用户漫游地发送模拟Cancel Location消息：

   ```
   SND SPCANCEL: IMSI="46000000912346", RECORDCOUNT=3, PID=100;
   ```
