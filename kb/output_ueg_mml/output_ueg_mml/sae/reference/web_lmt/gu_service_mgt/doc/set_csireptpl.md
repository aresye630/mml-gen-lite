# 设置CSI替代模板(SET CSIREPTPL)

## 命令功能

该命令用于设置CSI（CAMEL Subscription Information）替代模板，即增加、修改或者删除VLR/SGSN漫游区域模板与UCSI模板的对应关系。

**图1** 命令参数的索引关系图

CSI替代模板使用场景：

1. 在系统中配置相关模板数据。
   1. 执行**ADD UCSITPL**命令增加UCSI模板1，UCSI“模板类型”设置为“REPLACE”。
   2. 执行**SET CSIREPTPL**命令增加CSI替代模板1，关联UCSI模板1。
   3. 执行**ADD UCSITPL**命令增加UCSI模板2，UCSI“模板类型”设置为“SUB”，并关联CSI替代模板1。
2. 执行**MOD CAMEL**或**MOD UCSI**命令给用户签约UCSI模板。
   - 当用户签约了“模板类型”为“SUB”的USCI模板2，如果用户的漫游区域在用户签约的CSI替代模板1的VLR/SGSN漫游区域模板中有定义时，则采用该替代模板中关联的USCI模板1替代用户签约的UCSI模板2。
   - 当用户签约了“模板类型”为“REPLACE”的USCI模板1，则不进行替换。

## 注意事项

系统中增加的CSI替代模板记录数不能超过1000条。一个CSI替代模板增加的VLR/SGSN漫游区域模板记录数不能超过100条，且所有CSI替代模板增加的VLR/SGSN漫游区域模板总记录数不能超过5000条。

## 参数说明

| 参数标识        | 参数名称             | 参数说明                                                                                                                                                                                                                                                                                              |
|:------------|:-----------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号           | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                                                                                                      |
| OPTYPE      | 操作类型             | 用于标识执行该命令所实现的操作类型。 取值范围：ADD：增加一条VLR/SGSN漫游区域模板与UCSI模板的对应关系记录。新增记录时，如果同时输入新的模板名称，会同时修改对应模板的名称。MODIFY：修改一条已存在的VLR/SGSN漫游区域模板与UCSI模板的对应关系记录或修改模板名称。DELETE：删除一条已存在的VLR/SGSN漫游区域模板与UCSI模板的对应关系记录。当待删除的记录是模板的最后一条记录，则删除该模板。DELETEALL：删除一个模板。 默认值：无。 说明：如果已经通过ADD UCSITPL命令关联CSI替代模板，则不允许执行该命令删除CSI替代模板。 |
| REPTPLID    | 替代模板ID           | 用于标识待增加模板在系统中的序号。该参数在UDM中唯一，不能重复。 取值范围：0～65534 默认值：无。                                                                                                                                                                                                                                             |
| TPLNAME     | 模板名              | 仅当本命令中的“操作类型”参数为“ADD”或“MODIFY”时该参数有效。用于标识待处理模板在系统中的名称。 取值范围：1～60个字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                           |
| VSAREATPLID | VLR/SGSN漫游区域模板ID | 仅当本命令中的“操作类型”参数为“ADD”、“MODIFY”或“DELETE”时该参数有效。用于标识VLR/SGSN漫游区域模板ID。该参数必须先由ADD VSAREALIST命令定义，然后才能在此处引用。该命令配置的CSI替代模板配置信息只针对VLR/SGSN漫游区域模板中“VLR/SGSN号码前缀”参数对应的VLR/SGSN号码生效。 取值范围：0～65534 默认值：无。                                                                                                    |
| UCSITPLID   | UCSI模板ID         | 仅当本命令中的“操作类型”参数为“ADD”或“MODIFY”时该参数有效。用于标识UCSI模板ID。该参数必须先在ADD UCSITPL命令定义，且“模板类型”必须是“REPLACE”，然后才能在这里引用。当用户的漫游区域在VLR/SGSN漫游区域模板中有定义时，则采用该模板中定义的USCI模板替代用户签约的UCSI规则。 取值范围：0～65534 默认值：无。                                                                                                            |

## 使用实例

1. 增加一个CSI替代模板，模板中增加一条VLR/SGSN漫游区域模板数据记录，“HLR序列号”为“1”，“操作类型”为“ADD”，“替代模板ID”为“1”，“VLR/SGSN漫游区域模板ID”为“1”，“UCSI模板ID”为“2”：

   ```
   SET CSIREPTPL: HLRSN=1, OPTYPE=ADD, REPTPLID=1, VSAREATPLID=1, UCSITPLID=2;
   ```
2. 修改一个CSI替代模板的模板名称，“HLR序列号”为“1”，“操作类型”为“MODIFY”，“替代模板ID”为“1”，“模板名”为“CSIREPTPL1”，“VLR/SGSN漫游区域模板ID”为“1”，“UCSI模板ID”为“2”：

   ```
   SET CSIREPTPL: HLRSN=1, OPTYPE=MODIFY, REPTPLID=1, TPLNAME="CSIREPTPL1", VSAREATPLID=1, UCSITPLID=2;
   ```
3. 删掉一个CSI替代模板的一条VLR/SGSN漫游区域模板数据记录，“HLR序列号”为“1”，“操作类型”为“DELETE”，“替代模板ID”为“1”，“VLR/SGSN漫游区域模板ID”为“1”：

   ```
   SET CSIREPTPL: HLRSN=1, OPTYPE=DELETE, REPTPLID=1, VSAREATPLID=1;
   ```
4. 删掉一个CSI替代模板，“HLR序列号”为“1”，“操作类型”为“DELETEALL”，“替代模板ID”为“1”：

   ```
   SET CSIREPTPL: HLRSN=1, OPTYPE=DELETEALL, REPTPLID=1;
   ```
