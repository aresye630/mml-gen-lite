# 修改NEF漫游状态事件通知PLMN黑白名单(MOD NEFROAMNTFPLMNWBLIST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使NEF漫游状态事件通知行为变化，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改一条NEF漫游状态事件通知PLMN黑白名单数据记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                           |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 可选必选说明：必选参数 参数含义：用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1～255 默认值：无。 配置原则：无。                                                                        |
| PLMN   | PLMNID | 可选必选说明：必选参数 参数含义：用于标识待增加的PLMN序列号。 取值范围：5～6位的十进制数字组成的字符串。 默认值：无。 配置原则：“PLMNID”的取值是由MCC（前三位）和MNC（后两至三位）组成，当输入的MNC不足三位时前面会自动补0。如：输入“12345”，系统识别为 PLMNID=“123045”。 |
| TYPE   | PLMN类型 | 可选必选说明：必选参数。 参数含义：用于指定配置的PLMNID所属的PLMN类型。 取值范围：WHITELIST：白名单，允许向NEF发送漫游状态事件通知的PLMN列表。BLACKLIST：黑名单，禁止向NEF发送漫游状态事件通知的PLMN列表。 默认值：无。 配置原则：无。                     |

## 使用实例

修改一条NEF漫游状态事件通知PLMN黑白名单记录。参数设置如下：

- “HLRSN”取值为“1”
- “PLMNID”取值为“333333”
- “PLMN类型”取值为“WHITELIST”

```
MOD NEFROAMNTFPLMNWBLIST: HLRSN=1, PLMN="333333", TYPE=WHITELIST;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 消息解释      | 原因分析                             | 处理建议                                                                                                            |
|:--------|:----------|:---------------------------------|:----------------------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在     | 输入的“HLR序列号”和“PLMNID”对应记录不存在。     | 请按照以下步骤操作：执行LST NEFROAMNTFPLMNWBLIST命令，查询已配置的NEF漫游状态事件通知PLMN黑白名单配置信息。根据查询结果重新输入“HLR序列号”和“PLMNID”，确保输入的参数在查询结果中。 |
| ERR1004 | 无效的参数值    | 参数取值范围不符。                        | 根据系统提示及实际情况，重新输入参数值，确保其取值符合取值范围的要求。                                                                             |
| ERR3097 | HLR序列号未定义 | 输入的“HLR序列号”参数值没有在ADD HLRSN命令中定义。 | 执行LST HLRSN命令查询虚拟HLR的配置信息，然后输入正确的HLR序列号。                                                                        |
