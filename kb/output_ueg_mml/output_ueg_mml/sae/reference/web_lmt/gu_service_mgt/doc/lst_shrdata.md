# 模板方式查询共享数据(LST SHRDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询用户模板方式签约的共享数据信息。

- 若需要查询单个用户的数据，请输入参数“IMSI”或“MSISDN”。
- 若需要查询连续多个用户的数据，请输入参数“IMSI”或“MSISDN”的同时，再输入参数“用户个数”。
- 若需要查询不连续的多个用户的数据，请输入参数“IMSI文件名”或“MSISDN文件名”。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                            |
|:------------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 可选必选说明：条件可选参数 参数含义：用于指示系统按照哪个IMSI来查询用户模板方式签约的共享数据信息。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                      |
| ISDN        | MSISDN    | 可选必选说明：条件可选参数 参数含义：用于指示系统按照哪个MSISDN来查询用户模板方式签约的共享数据信息。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                    |
| RECORDCOUNT | 用户个数      | 可选必选说明：条件可选参数 参数含义：用于指示系统需要查询多少个用户的模板方式签约共享数据信息。 取值范围：1~10000。 默认值：无。 配置原则： 当需要为连续号码的多个用户查询用户的签约数据时配置该参数，配置后，系统将会从已指定的IMSI号码或者MSISDN号码开始，对连续号码的多个用户进行查询用户的签约数据。该参数是对连续号码的多个用户查询用户的签约数据，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名   | 可选必选说明：条件可选参数 参数含义：用于指示系统按照哪个IMSI文件名来查询不连续的多个用户模板方式签约的共享数据信息。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。 配置原则：IMSI批操作文件包含多个不连续的待查询用户签约数据的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“lstshrdat.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。                              |
| ISDNFILE    | MSISDN文件名 | 可选必选说明：条件可选参数 参数含义：用于指示系统按照哪个MSISDN文件名来查询不连续的多个用户模板方式签约的共享数据信息。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。 配置原则：MSISDN批操作文件包含多个不连续的需要查询用户签约数据的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“lstshrdat.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。                    |

## 使用实例

1. 查询“IMSI”为“460000009123456”的用户的模板方式签约的共享数据信息：

   ```
   LST SHRDATA: IMSI="460000009123456";
   ```

   ```
   %%LST SHRDATA: IMSI="460000009123456";%%
   RETCODE = 0 SUCCESS0001:Operation is successful    
       
                         IMSI = 460000009123456    
                       MSISDN = 13500111111
                EPCNOTALLOWED = TRUE
                NGCNOTALLOWED = TRUE
             EUTRANNOTALLOWED = FALSE
              NBIOTNOTALLOWED = FALSE
                 NRNOTALLOWED = FALSE
              NR5GSNOTALLOWED = FALSE

   Total count = 8

   There is together 1 report

   ---    END
   ```
2. 查询第一个MSISDN号码为“13500111111”的连续3个用户的模板方式签约的共享数据信息：

   ```
   LST SHRDATA: ISDN="13500111111", RECORDCOUNT=3;
   ```

   ```
   %%LST SHRDATA: ISDN="13500111111", RECORDCOUNT=3;%%
   RETCODE = 0 SUCCESS0001:Operation is successful Batch ID: 2. CHK BATSTAT can be used to obtain the status of batch operation

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，具体参数含义请参见**MOD SHRDATA**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                   | 处理建议                                                                                                                |
|:--------|:--------|:-------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 参数取值范围不符。                                              | 根据实际情况，重新输入“IMSI”或“MSISDN”的取值，确保其取值符合要求。                                                                            |
| ERR1009 | 参数丢失    | 参数“IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数同时缺失。       | 根据实际情况，重新输入参数，并满足“IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                         |
| ERR1010 | 参数冲突    | “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数中有两个以上的参数被输入。 | 根据实际情况，重新输入参数，确保满足以下两点： “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数必须有且只能有一个参数出现。 “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR3001 | 用户未开户   | 用户的“IMSI”或“MSISDN”输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户。 | 核实用户的IMSI号码或MSISDN号码，如果输入有误，重新输入正确的IMSI号码或MSISDN号码。                                                                 |
