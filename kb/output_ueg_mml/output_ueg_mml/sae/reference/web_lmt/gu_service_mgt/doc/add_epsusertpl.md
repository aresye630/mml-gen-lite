# 增加EPS用户模板（ADD EPSUSERTPL）

- 命令功能
- 注意事项

## 命令功能

该命令用于在数据库中增加一条EPS用户模板数据记录。用户通过**MOD TPLEPS**命令使用EPS用户模板ID签约EPS业务。

**图1** 命令参数的索引关系图

## 注意事项

系统中增加的EPS用户模板记录数不能超过20000条，且所有EPS用户模板增加的PDN上下文总记录数不能超过40000条。

## 使用实例

增加EPS用户模板，“模板ID”为“2”，“模板名”为“EPSUSERTPL\_01”，“UE最大上行带宽”为“200000bit/s”, “UE最大下行带宽”为“400000bit/s”, “PDN上下文索引值”为“1”，“EPSAPNQOS模板ID”为“1”。具体步骤如下：

1. 增加HLR序列号。

   `ADD HLRSN: HLRSN=1, HLRNO="8613800", STATUS=MASTER, CCODE="86", MAXEPSUSERNUM=200;`
2. 增加APN模板。

   `ADD APNTPL: HLRSN=1, TPLID=1, APN="*", PDNGWALLOCTYPE=DYNAMIC;`
3. 增加EPS QoS模板。

   `ADD EPSQOSTPL: HLRSN=1, TPLID=1, TPLNAME="EPS-QoS", QOSCLASUID=5, EXTQCI=130, PRILEVEL=1, PREEMPTIONVUL=ENABLE, AMBRMAXREQBWUL=200000, AMBRMAXREQBWDL=400000;`
4. 增加EPSAPNQOS模板。

   `ADD EPSAPNQOSTPL: HLRSN=1, TPLID=1, APNTPLID=1, EPSQOSTPLID=1, PDNTYPE=IPV4, VPLMN=TRUE, PDNCHARGE=NONE;`
5. 增加EPS用户模板。

   `ADD EPSUSERTPL: HLRSN=1, TPLID=2, TPLNAME="EPSUSERTPL_01", AMBRMAXUL=200000, AMBRMAXDL=400000, CNTXID=1, EPSAPNQOSTPLID=1;`

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                  | 处理建议                                                                                                                                                                   |
|:--------|:--------|:----------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | EPSAPNQOS模板未定义。                                                       | 根据实际情况选择： 如果需要使用已定义的模板，则执行LST EPSAPNQOSTPL查询已定义的EPSAPNQOS模板ID。如果需要重新定义新的模板，则执行ADD EPSAPNQOSTPL命令定义新的EPSAPNQOS模板。                                                       |
| ERR3047 | 超过最大限制  | 可能原因为如下之一：增加的EPS用户模板记录数超过20000条。 所有EPS用户模板增加的“PDN上下文索引值”总记录数超过40000条。 | 根据实际情况，如需增加EPS用户模板，处理步骤如下：执行LST EPSUSERTPL命令，查询已存在的EPS用户模板。执行RMV EPSUSERTPL命令，删除不必要的EPS用户模板。或执行MOD EPSUSERTPL命令，删除不必要的PDN上下文索引值。执行该命令增加EPS用户模板，确保增加的EPS用户模板记录数在规定范围之内。 |
