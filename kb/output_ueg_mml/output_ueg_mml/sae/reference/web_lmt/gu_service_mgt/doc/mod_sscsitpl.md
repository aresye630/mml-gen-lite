# 修改SS-CSI模板(MOD SSCSITPL)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使签约此模板的用户数据被同步修改，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一条SS-CSI（Supplementary Service Invocation Notification CAMEL Subscription Information）模板数据记录的某些参数进行修改或调整，同时还用于为一条SS-CSI模板数据记录增加多条触发准则。在该命令中，系统通过以下关键参数的组合来唯一标识一条SS-CSI模板数据记录：

- “HLR序列号”
- “模板ID”

## 注意事项

用户进行位置更新或触发其他涉及SS-CSI模板的流程时，系统会根据用户签约的SS-CSI模板ID下发模板中的数据，修改模板数据会使签约此模板的用户数据被同步修改，会影响在网用户，因此现网执行修改模板操作时需要慎重。

## 参数说明

| 参数标识           | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                |
|:---------------|:-------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN          | HLR序列号       | 标识一条SS-CSI模板数据记录的关键字段之一（其取值不能被修改），用于标识需要对哪一条SS-CSI模板数据记录的参数进行修改或调整，操作员可以使用LST HLRSN命令查询获得。                                                                                                                                                                                                                                                                                                                                          |
| TPLID          | 模板ID         | 标识一条SS-CSI模板数据记录的关键字段之一（其取值不能被修改），用于标识需要对哪一条SS-CSI模板数据记录的参数进行修改或调整，操作员可以使用LST SSCSITPL命令查询获得。                                                                                                                                                                                                                                                                                                                                       |
| TPLNAME        | 模板名          | 用于标识待修改模板在系统中的名称。 取值范围：1～60位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                  |
| ECT            | ECT          | 用于标识调用ECT（Explicit Call Transfer）补充业务时，MSC是否向gsmSCF发送补充业务调用通知。 取值范围：TRUE：发送通知FALSE：不发送通知 默认值：无。                                                                                                                                                                                                                                                                                                                                     |
| CD             | CD           | 用于标识调用CD（Call Deflection）补充业务时，MSC是否向gsmSCF发送补充业务调用通知。 取值范围：TRUE：发送通知FALSE：不发送通知 默认值：无。                                                                                                                                                                                                                                                                                                                                             |
| MPTY           | MPTY         | 用于标识调用MPTY（MultiParty Service）补充业务时，MSC是否向gsmSCF发送补充业务调用通知。 取值范围：TRUE：发送通知FALSE：不发送通知 默认值：无。                                                                                                                                                                                                                                                                                                                                        |
| CCBS           | 遇忙呼叫完成       | 用于标识调用CCBS（Completion of Call to Busy Subscriber）补充业务时，HLR是否向gsmSCF发送补充业务调用通知。 取值范围：TRUE：发送通知FALSE：不发送通知 默认值：无。                                                                                                                                                                                                                                                                                                                     |
| GSMSCFADD      | SCP地址        | 用于标识接入gsmSCF功能实体的地址。 取值范围：1～15位十进制数字组成的字符串。 采用E.164编码方式，编码格式为：CC+NDC+LSP，例如，一个典型的“SCP地址”为：“86-139-00777”。各关键字段的含义是： CC（Country Code）：国家码，即SCP所处国家在国际PSTN编号计划中的国家码，它由ITU-T在全球范围内统一分配，其最大长度为3位。例如，中国的国家码为86、英国的国家码为44等。NDC（National Destination Code）：国内目的码，即移动业务接入码，它是由本国电信主管部门在本国范围内统一分配的PLMN网络号，其最大长度为3位。例如，某运营商使用的PLMN网络号为134～139。LSP（Locally Significant Part）：本地有效部分，它是由某个运营商在本PLMN网络运营范围内统一分配的、用于具体代表某个SCP的号码，其最大长度为9位。 默认值：无。 |
| AVAILABLE_PLMN | SS-CSI模板使用范围 | 用于标识用户在不同的网络中漫游时是否下发SS-CSI数据。 取值范围：HPLMN：用户在HPLMN（Home Public Land Mobile Network）内漫游时，HLR向VLR下发SS-CSI数据，否则不下发。VPLMN：用户在VPLMN（Visited PLMN）内漫游时，HLR向VLR下发SS-CSI数据，否则不下发。ALL_PLMN：用户在所有PLMN内漫游时，HLR均向VLR下发SS-CSI数据。 默认值：无。 说明：由于CCBS业务是在HLR触发，下发的SS-CSI数据中不包含CCBS信息。                                                                                                                                                                 |

## 使用实例

1. 修改“HLR序列号”为“1”的HLR上的SS-CSI模板数据记录，增加补充业务调用条件，当发生MPTY业务和CCBS业务时触发SS-CSI业务。其中，“模板ID”为“2”，“MPTY”为“TRUE”，“遇忙呼叫完成”为“TRUE”：

   ```
   MOD SSCSITPL: HLRSN=1, TPLID=2, MPTY=TRUE, CCBS=TRUE;
   ```
2. 修改“HLR序列号”为“1”的HLR上的SS-CSI模板数据记录，修改SS-CSI模板使用范围。其中，“模板ID”为“2”，“SS-CSI模板使用范围”为“HPLMN”：

   ```
   MOD SSCSITPL: HLRSN=1, TPLID=2, AVAILABLE_PLMN=HPLMN;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                 | 处理建议                                                         |
|:--------|:--------|:-------------------------------------|:-------------------------------------------------------------|
| ERR3003 | 模板未定义   | “HLR序列号”和“模板ID”对应的SS-CSI模板数据记录不存在。   | 使用LST SSCSITPL命令查询后，重新确认要修改哪个“HLR序列号”和“模板ID”对应的SS-CSI模板数据记录。 |
| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”和“模板ID”参数不在相应的参数取值范围内。 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                             |
