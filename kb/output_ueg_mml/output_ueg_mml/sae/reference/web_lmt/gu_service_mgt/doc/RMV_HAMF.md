# 删除AMF(RMV HAMF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于从HSS的业务数据库中删除一个鉴权数据AMF的数据记录。

## 注意事项

待删除的AMF必须没有被使用。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                         |
|:-------|:-------|:-----------------------------------------------------------------------------|
| AMFSNO | AMF索引号 | 标识一条AMF数据记录的关键参数，用于指定需要删除哪一条AMF数据记录，操作员可以使用LST HAMF操作查询获得。 取值范围：1～128 缺省值： 无 |

## 使用实例

删除AMF。AMF索引号：10。

```
RMV HAMF: AMFSNO=10;
```
