## 命令功能

该命令用于优化用户存储在数据库中的SIFC（Shared Initial Filter Criteria）数据记录。

IMS-HSS数据库存储SIFC数据时，有两种存储方式（可通过**SET HSYSTEMPARA**命令的“SIFC存储方式”参数进行设置），第一种是一条数据库记录只能存储一个SIFCID，即一个共享iFC模板ID，第二种是一条数据库记录能存储四个SIFCID。本命令应用于当存储方式为第二种时对已存储的用户数据记录进行优化，达到节省存储空间的作用。

**说明** 

优化数据时会优先按照一条记录存储满四个SIFCID进行优化。例如有三条记录，每一条记录保存了一个SIFCID，那么可以通过本命令将三条记录合并为一条记录，合并后只有一条记录，这一条记录中存储了三个SIFCID。若有三条记录，每一条记录保存了2个SIFCID，那么可以通过本命令将三条记录合并为两条记录，合并后一条记录中有四个SIFCID，另一条中有两个SIFCID。

## 注意事项

- “IMPU”和“PUSI”两个参数必须且只能输入一个，在输入时可根据用户的类别进行选择输入。
  - 若用户是以IMPI和IMPU作为用户标识的IMS域用户，则输入“IMPU”号码。
  - 若用户以PISI和PUSI作为业务标识的PSI用户，则输入“PUSI”号码。

  **说明** 

  系统中已添加的“IMPU”和“PUSI”信息可通过**LST HSUB**和**LST HPSI**命令查询。
- 一个用户最多配置8条数据记录，即最多保存32个SIFCID。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                       |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| IMPU   | IMPU   | 用于标识按照哪个IMPU号码整理用户存储在IMS-HSS数据库中的SIFC数据记录。 取值范围：1～127位的字符串。 默认值：无。 说明：该参数值输入时必须符合SIP URI或TEL URI格式，且字母区分大小写。详细取值格式请参考ADD HSUB命令中的“IMPU”参数。 |
| PUSI   | PUSI   | 用于标识按照哪个PUSI号码整理用户存储在IMS-HSS数据库中的SIFC数据记录。 取值范围：1～127位的字符串。 默认值：无。 说明：该参数值输入时必须符合SIP URI或TEL URI格式，且字母区分大小写。详细取值格式请参考ADD HPSI命令中的“PUSI”参数。 |

## 使用实例

整理“IMPU”号码为“sip:impuinfo@huawei.com”的用户的SIFC数据记录，命令如下：

```
OPT HDATA: IMPU="sip:impuinfo@huawei.com";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释         | 原因分析                       | 处理建议                           |
|----------:|:--------------|:---------------------------|:-------------------------------|
| 900001007 | 无效的参数值        | 输入的参数值格式不正确。               | 请参考取值范围中的正确格式重新输入。             |
| 900001008 | 参数不足          | “IMPU”和“PUSI”号码两个都没有输入。    | “IMPU”和“PUSI”两个参数必须输入一个。       |
| 900001009 | 参数冲突          | 操作人员同时输入了“IMPU”和“PUSI”号码。  | “IMPU”和“PUSI”两个参数只能输入一个。       |
| 900003060 | 请求消息中的IMPU不存在 | 操作人员输入的“IMPU”参数取值对应的用户未开户。 | 执行LST HSUB命令查询已存在的IMPU，然后重新输入。 |
| 900003092 | 请求消息中的PUSI不存在 | 操作人员输入的“PUSI”参数取值对应的用户未开户。 | 执行LST HPSI命令查询已存在的PUSI，然后重新输入。 |
