# 修改SMF数据(MOD SMDATA)

## 命令功能

该命令用于修改会话管理数据信息，每次仅能修改一条签约的会话管理数据。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数必须有且只能有一个参数出现。
- “用户个数” 参数不能与“IMSI文件名”或“MSISDN文件名”同时存在，“用户个数”参数只能与“IMSI”或“MSISDN”一起出现。
- 单个SNSSAI下必须存在一个且只允许存在一个默认DNN数据，当新签约的DNN数据为默认DNN时，系统中已存在的默认DNN自动更新为非默认DNN。
- SNSSAI、DNN参数用于定位即将修改的会话管理签约数据条目。如果某个已有的会话管理签约数据条目已签约SNSSAI且具有SD值时，则需要为本命令指定相同的SD参数才能修改此条目。
- 签约静态IP地址时，外部业务发放系统应自行保证IP地址的唯一性。

## 参数说明

| 参数标识                 | 参数名称           | 参数说明                                                                                                                                                                                                                                                                                       |
|:---------------------|:---------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI                 | IMSI           | 可选必选说明：条件可选参数 参数含义：用于标识需要修改哪个IMSI号码的会话管理数据。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                          |
| ISDN                 | MSISDN         | 可选必选说明：条件可选参数 参数含义：用于标识需要修改哪个MSISDN号码的会话管理数据。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                        |

| DNN                  | 数据网名称          | 可选必选说明：必选参数 参数含义：用于标识数据网名称。 取值范围：1～64位的字符串，只允许输入字母、数字、“-”、“_”、“.”和“*”。 默认值：无。 配置原则：不允许将通配DNN配置为默认DNN，通配DNN即该参数取值为“*”的DNN。                                                                                                                                                                  |

| DEFAULT              | 是否默认DNN        | 可选必选说明：可选参数 参数含义：用于标识是否默认DNN。 取值范围： TRUE：是FALSE：否 默认值：无。 配置原则：如果将一个已经存在的DNN改为默认DNN，则需要将原DNN默认标记清除。                                                                                                                                                                                         |

| IPV4ADDR             | 终端IPv4地址       | 可选必选说明：条件可选参数 参数含义：用于标识终端IPv4地址。 取值范围：字符串格式表示的合法IPv4地址。 默认值：无。 配置原则： 签约静态IP地址时，外部业务发放系统应确保IP地址的唯一性。仅当本命令中的“是否提供IPv4地址”参数取值为“TRUE”时该参数有效。                                                                                                                                                   |
| IPV6IND              | 是否提供IPv6地址     | 可选必选说明：可选参数 参数含义：用于标识是否提供IPv6地址。 取值范围： TRUE：是 FALSE：否 默认值：无。 配置原则：取值为“FALSE”表示清除IPv6地址。                                                                                                                                                                                                    |
| IPV6ADDR             | 终端IPv6地址       | 可选必选说明：条件可选参数 参数含义：用于标识终端IPv6地址或者IPv6前缀。 取值范围：字符串格式表示的合法IPv6地址或者IPv6前缀。 IPv6地址示例如下： FE80:910A:2222:5498:8475:1111:3900:2020 IPv6地址前缀示例如下： 2001:0DB8:0:CD30::/60 IPV6地址前缀中前缀长度有效值范围：1～128。 默认值：无。 配置原则： 不支持全0或全F的IPv6地址。签约静态IP地址时，外部业务发放系统应确保IP地址的唯一性。仅当本命令中的“是否提供IPv6地址”参数取值为“TRUE”时该参数有效。 |
| NEWDNN               | 新的数据网名称        | 可选必选说明：可选参数 参数含义：用于标识新的数据网名称。 取值范围：1～64位的字符串，只允许输入字母、数字、“-”、“_”、“.”和“*”。 默认值：无。 配置原则：不允许将默认DNN修改为通配DNN，通配DNN即该参数取值为“*”的DNN。                                                                                                                                                                |
| SUGGESTEDPACKETNUMDL | 建议的下行数据缓存包大小   | 可选必选说明：可选参数 参数含义：用于标识建议的下行数据缓存包大小。当网络设备向终端用户发送数据，发现终端用户不可达，数据需要被缓存起来时，SMF可以使用该参数配置SMF/UPF或NEF中的缓存数据包大小。 取值范围：0～2147483647 默认值：无。 配置原则：当该参数取值为“0”时，表示去签约。                                                                                                                                   |

## 使用实例

修改会话管理数据信息，“IMSI”为“460000009123456”，“切片标识”为“1-123456”，“数据网名称”为“dnn1”，“5GS DNNQoS模板ID”为“80”：

```
MOD SMDATA: IMSI="460000009123456", SNSSAI="1-123456", DNN="dnn1", DNNQOSTPLID=80;
```
