# 增加VLR/SGSN漫游区域模板(ADD VSAREALIST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HLR中增加VLR/SGSN区域模板数据记录，通过定义VLR/SGSN号码前缀，来标识有相同前缀的VLR/SGSN号码的区域范围。

当一个VLR/SGSN区域的移动用户向网络发起位置更新请求时，根据位置更新请求消息中携带的VLR/SGSN号码是否能匹配（最大前缀匹配）用户已签约VLR/SGSN漫游限制模板中的某个VLR/SGSN：

- 如果能匹配，则根据该VLR/SGSN对应的漫游限制标志来判断允许该用户漫游还是禁止该用户漫游。
- 如果不能匹配，则根据该模板中的缺省漫游限制标志来判断允许该用户漫游还是禁止该用户漫游。

## 注意事项

- 执行该命令只能对一个模板定义一个VLR/SGSN号码前缀，如果需要在一个模板中定义多个VLR/SGSN号码前缀，则需要执行**MOD VSAREALIST**命令进行添加。
- 系统中增加的VLR/SGSN漫游区域模板记录数分别不能超过6000条。
- 系统中所有VLR漫游区域模板增加的VLR号码前缀数据总记录数不能超过40000条。
- 系统中所有SGSN漫游区域模板增加的SGSN号码前缀数据总记录数不能超过40000条。

## 参数说明

| 参数标识      | 参数名称         | 参数说明                                                                                                                                                                                        |
|:----------|:-------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN     | HLR序列号       | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                |
| TPLID     | 模板ID         | 用于标识待增加模板在系统中的序号。 取值范围：0～65534 默认值：无。                                                                                                                                                       |
| TPLNAME   | 模板名          | 用于标识VLR/SGSN漫游区域模板的名称。 取值范围：1～60个字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                     |
| TPLTYPE   | 模板类型         | 用于标识模板类型，通过该参数区分是VLR模板还是SGSN模板。 取值范围：VLR：表示通过拜访位置寄存器限制用户漫游区域，若限制CS域选择VLR。SGSN：表示通过服务GPRS支持节点限制用户漫游区域，若限制PS域选择Gn/Gp SGSN。 默认值：无。                                                             |
| VLRSGSNNO | VLR/SGSN号码前缀 | 用于标识VLR或SGSN号码前缀，用户在位置更新时，通过该参数进行最大前缀匹配。 该参数支持最大匹配原则，输入的内容可以是完整的VLR/SGSN号码，也可以是VLR/SGSN的号码前缀。最大匹配原则是指在查询时对于一个具体的号码而言，系统会查找所有等于该号码前缀若干位的记录，并且从中匹配一条与该号码最接近的记录。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 |

## 使用实例

为用户签约VLR/SGSN漫游限制业务操作员需要配置以下数据。

1. 增加VLR/SGSN漫游区域模板：“HLR序列号”为“1”，“模板ID”为“1”，“模板名”为“VSST”，“模板类型”为“VLR”，“VLR/SGSN号码前缀”为“222”：

   ```
   ADD VSAREALIST: HLRSN=1, TPLID=1, TPLNAME="VSST", TPLTYPE=VLR, VLRSGSNNO="222";
   ```
2. 增加VLR/SGSN漫游限制模板：“HLR序列号”为“1”，“模板ID”为“1”，“模板名”为“VSST”，“模板类型”为“VLR”，“漫游区域配置方式”为“VSAREA\_TPL\_TYPE”，“VLR/SGSN漫游区域模板ID”为“1”，“漫游限制状态”为“PERMISSION”，“缺省漫游限制状态”为“RESTRICT”：

   ```
   ADD VSLIST: HLRSN=1, TPLID=1, TPLNAME="VSST", TPLTYPE=VLR, VSAREATYPE=VSAREA_TPL_TYPE, VSAREATPLID=1, ROAMRULE=PERMISSION, ROAMDEFAULTRULE=RESTRICT;
   ```
3. 执行**MOD VSRR**命令给用户签约VLR/SGSN漫游限制业务:

   ```
   MOD VSRR: IMSI="460000009034567", PROV=TRUE, TPLTYPE=VLR, TPLID=1;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                                                                      | 处理建议                                                                                                                                                                                                                   |
|:--------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 输入的参数取值不在其取值范围内。                                                                                                                          | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                                                                                                       |
| ERR3004 | 模板已存在   | 输入的“模板ID”在数据库中已存在。                                                                                                                        | 根据实际情况，重新输入参数，确保输入的“模板ID”和系统中已存在的模板ID不重复。可通过LST VSAREALIST命令查询系统中已存在的VLR/SGSN漫游区域模板。                                                                                                                                   |
| ERR3007 | 记录不存在   | 输入的“HLR序列号”未定义。                                                                                                                           | 根据实际情况，重新输入参数“HLR序列号”，可通过LST HLRSN命令查询已定义的“HLR序列号”。                                                                                                                                                                    |
| ERR3047 | 超过最大限制  | 可能原因为如下之一：增加的VLR漫游区域模板记录数超过6000条。增加的SGSN漫游区域模板记录数超过6000条。系统中所有VLR漫游区域模板增加的VLR号码前缀数据总记录数超过40000条。系统中所有SGSN漫游区域模板增加的SGSN号码前缀数据总记录数超过40000条。 | 根据实际情况，如需增加VLR/SGSN漫游区域模板，处理步骤如下：执行LST VSAREALIST命令，查询已存在的VLR/SGSN漫游区域模板。执行RMV VSAREALIST命令删除不必要的VLR/SGSN漫游区域模板或执行MOD VSAREALIST命令删掉不必要的VLR/SGSN号码前缀。执行该命令增加VLR/SGSN漫游区域模板，确保增加的VLR/SGSN漫游区域模板和VLR/SGSN号码前缀记录数在规定范围之内。 |
