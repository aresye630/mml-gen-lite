## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成全网设备过载、链路拥塞、CPU负荷过载等现象，因此执行该命令前，请详细阅读本命令的联机帮助和注意事项，并评估全网信令处理能力，禁止使用“发送消息的范围”为“ALL”方式对全网进行RESET操作。 操作前务必明确对端网元对IMSI号段方式的RESET支持情况，对于存在不支持的网元，执行本命令时禁止携带“IMSI前缀”参数。如果使用DIAMRRTPL方式发送RESET且DIAMRRTPL模板中DIAMIDENTITYTYPE取值为HOSTNAME，模板中REALMNAME参数必须存在，否则将不会发送RESET。RESET操作将对系统和网络产生重大影响，请务必联系华为技术支持。

此操作用来发送Reset到VLR、Gn/Gp SGSN、MME、S4 SGSN和AAA。

消息可以发送到一个或者几个在相应模板中定义的VLR、Gn/Gp SGSN、MME、S4 SNSN或AAA，或者允许用户漫游的全部VLR、Gn/Gp SGSN、MME、S4 SGSN或AAA。

消息发送到多个VLR/SGSN/MME/S4SGSN/AAA时，系统会按照VLR/SGSN/MME/S4SGSN/AAA号码一个一个的发送，发送速度为20个/s，如果上一个未处理完成，再执行SND RESET命令发送多个VLR/SGSN/MME/S4SGSN/AAA时，会返回已有命令在执行的错误提示。

此操作必须在非繁忙时间进行。

## 注意事项

- 操作前务必明确对端网元对IMSI号段方式的SND RESET支持情况，对于存在不支持的网元，执行本指令时禁止携带IMSI前缀参数。RESET操作将对系统和网络产生重大影响，请务必联系华为工程师处理。
- 当RANGE=SOME时，当发送目的地为VLR/SGSN时需要在VLR/SGSN漫游限制模板中设置好VLRSGSNNO，当发送目的地为MME/S4SGSN/AAA时需要在Diameter漫游限制模板中设置好主机名称和域名。
- 当PGW为简单模式时，不需要设置参数HLRSN，HLRSN仅在完整模式中设置。
- 在云部署场景下，该命令只对本Partition用户有效。
- “发送消息的范围”为“ALL”、“PREFIX”、“EXTEND\_RANGE”时，需要先执行**GET RESETDATA**获取Reset数据，**GET RESETDATA**执行结束以后，才能执行**SND RESET**。
- 该命令不允许进行批操作。

   ```
   SND RESET: HLRSN=1, DEST=SGSN, RANGE=ONE, VLRSGSNNO="2341", REVERSE=FALSE;
   ```
2. 向“MME主机名称”为“mme1.abc.com”，“MME主机域名”为“abc.com”的MME发送Reset消息，命令如下：

   ```
   SND RESET: HLRSN=1, DEST=MME, RANGE=ONE, MMEHOST="mme1.abc.com", MMEREALM="abc.com", REVERSE=FALSE;
   ```
3. 向“VLR/SGSN号码前缀”为“12345678912”的VLR发送Reset消息，命令如下：

   ```
   SND RESET: HLRSN=1, DEST=VLR, RANGE=PREFIX, REVERSE=FALSE, VLRSGSNPREFIX="12345678912";
   ```
4. 向“发送消息的范围”为“EXTEND\_RANGE”的SGSN发送Reset消息，命令如下：

   ```
   SND RESET: HLRSN=1, DEST=SGSN, RANGE=EXTEND_RANGE, SPECIFY_EXRANGE=HPLMN;
   ```
