# 根据模板信息新增IMPI用户数据(ADD HTPLIMPI)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中，利用IMPI相关的计费地址模板、ServiceProfile模板、IMPU基本信息模板，增加一个IMPI用户。

**说明** 

使用此命令为IMS签约增加IMPI时，可以同时通过可选参数配置IMPI的鉴权信息。

## 注意事项

- 参数SPTPLID或者IMPUTPLID存在时，IMPU参数必须存在。
- 当参数“IMPI的鉴权类型”为“HDA”或者“SDA”时，存在“HA1值”和“用户名称”、“密码”两种加密方式。对于一个“IMPI”，“HA1值”和“用户名称”、“密码”只能存在一种，即只存在“HA1值”或只存在“用户名称”和“密码”的组合。推荐使用HA1值。
- 当**SET MAPCONF**命令中的“是否启用随机密钥”参数为“TRUE”，本命令中的“IMPI的鉴权类型”参数为“HDA(HTTP Digest)”或“SDA(SIP Digest)”，执行该命令时如果未执行**SET DEFAULTK2SNO**命令设置默认K2，则执行该命令时会返回错误。
- 当通过**SET HSYSTEMPARA**命令设置“USINGHLRSNFORIMS（是否启用IMS-HSS的分权分域功能）”软参为“TRUE(TRUE)”时，执行该命令时会返回错误。
- 在混合组网下，如存在异常场景下进行跨SP数据迁移时，需要通过设置“USERDATAMIGEXCEPENHANCESW（用户数据迁移容错能力增强开关）”软参支持数据的兼容处理，避免因为UDB和PaasDB数据模型不一致而处理失败。
  - 插件包schemamap.xml文件中配置RDN冲突节点（rdnconflictexcepproc），即从5G接入查询4G用户和用户数据迁移过程中该节点存在冲突记录时，若该软参为“1”，根据timestampfield配置字段取最新的一条数据，无timestampfield配置，随机取一条数据；若软参为“0”，则从5G接入查询4G用户和迁移失败。
  - 插件包schemamap.xml文件中配置无父节点的节点（noparentnodeexcepproc），即从5G接入查询4G用户和用户数据迁移过程中该节点无父节点记录时，若软参为“1”，忽略该节点数据不处理；若软参为“0”，则从5G接入查询4G用户和迁移失败。

## 使用实例

1. 根据模板信息新增IMPI用户数据，“SUBID”为“subinfo”，“IMPI”为“impiinfo”，“IMPU”为“sip:impuinfo@huawei.com”，“计费地址模板ID”为“1”，“ServiceProfile模板ID”为“1”，“IMPU基本信息模板ID”为“1”：

   ```
   ADD HTPLIMPI: SUBID="subinfo", IMPI="impiinfo", IMPU="sip:impuinfo@huawei.com", CHARGTPLID=1, SPTPLID=1, IMPUTPLID=1;
   ```
2. 根据模板信息新增IMPI用户数据，“SUBID”为“subinfo”，“IMPI”为“impiinfo”，“IMPI的鉴权类型”为“HDA”，“用户名称”为“user\_name”，“密码”为“A7Bh94”，“IMPU”为“tel:+33145297![247].\*!”，“IMPU的类型”为“WIMPU（WIMPU）”，“计费地址模板ID”为“1”，“ServiceProfile模板ID”为“1”“IMPU基本信息模板ID”为“1”：

   ```
   ADD HTPLIMPI: SUBID="subinfo", IMPI="impiinfo", IMPIAUTHTYPE=HDA, HUSERNAME="user_name", PWD="*****", IMPU="tel:+33145297![247].*!", IMPUTYPE=WIMPU, CHARGTPLID=1, SPTPLID=1, IMPUTPLID=1;
   ```
3. 根据模板信息新增IMPI用户数据，“SUBID”为“subinfo”，“IMPI”为“impiinfo”，“IMPI的鉴权类型”为“HDA”，“HA1值”为“11112222333344445555666677778888”，“IMPU”为“tel:+33145297![247].\*!”，“IMPU的类型”为“WIMPU（WIMPU）”，“计费地址模板ID”为“1”，“ServiceProfile模板ID”为“1”“IMPU基本信息模板ID”为“1”：

   ```
   ADD HTPLIMPI: SUBID="subinfo", IMPI="impiinfo", IMPIAUTHTYPE=HDA, HA1="*****", IMPU="tel:+33145297![247].*!", IMPUTYPE=WIMPU, CHARGTPLID=1, SPTPLID=1, IMPUTPLID=1;
   ```
