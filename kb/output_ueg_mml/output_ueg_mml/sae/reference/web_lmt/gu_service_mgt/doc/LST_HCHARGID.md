# 查询IMPI或PISI的计费地址ID(LST HCHARGID)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询指定IMPI或PISI的计费地址信息所对应ID。

## 注意事项

参数IMPI和参数PISI必须存在且仅能存在一个。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                          |
|:-------|:-------|:----------------------------------------------------------------------------------------------|
| IMPI   | IMPI   | 用于指示系统需要按照哪个IMPI来查询计费数据；若不输入，则表示按PISI来查询。要求输入的IMPI值符合NAI格式，字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无 |
| PISI   | PISI   | 用于指示系统需要按照哪个PISI来查询计费数据；若不输入，则表示按IMPI来查询。要求输入的PISI值符合NAI格式，字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无 |

## 使用实例

查询PISI的计费地址ID。PISI：pisiinfo。

```
LST HCHARGID: PISI="pisiinfo";
```

## 输出结果说明

| 参数标识       | 参数说明        |
|:-----------|:------------|
| CHARGTPLID | 显示计费地址模板ID。 |
