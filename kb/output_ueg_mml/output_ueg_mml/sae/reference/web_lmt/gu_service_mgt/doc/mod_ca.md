# 修改计费区域业务(MOD CA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来签约、去签约CA（Charging Area）业务。

执行此命令后，如果是给用户签约该业务，则会下发插入用户数据消息；如果是给用户去签约该业务，则会下发删除用户数据消息。

## 注意事项

- IMSI、ISDN、IMSIFILE、ISDNFILE是条件可选参数，有且只能有一个参数出现。
- RECORDCOUNT一定不能与IMSIFILE或ISDNFILE同时存在。
- CA1、CA2、CA3不能重复。

## 参数说明

| 参数标识        | 参数名称       | 参数说明                                                                                     |
|:------------|:-----------|:-----------------------------------------------------------------------------------------|
| IMSI        | IMSI       | 此参数用于设置IMSI号码。 取值范围：E.212格式的编码，6～15位的十进制数字。                                              |
| ISDN        | MSISDN     | 此参数用于设置MSISDN号码。 取值范围：E.164格式的编码，1～15位的十进制数字。                                            |
| RECORDCOUNT | 用户个数       | 用户的数目。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。 取值范围：1～100000。 |
| IMSIFILE    | IMSI文件名    | 此参数用于设置IMSI文件名称。IMSIFILE是由多个不连续的IMSI号码组成的批操作文件，每个IMSI号码占一行。 取值范围：1～16个字母或数字。             |
| ISDNFILE    | MSISDN文件名  | 此参数用于设置ISDN文件名称。ISDNFILE是由多个不连续的MSISDN号码组成的批操作文件，每个MSISDN号码占一行。 取值范围：1～16个字母或数字。         |
| PROV        | 是否提供计费区域业务 | 是否提供计费区域业务。 TRUE：提供 FALSE：撤销 必选参数。                                                       |
| CA1         | 计费区域1      | 仅当本命令中的“是否提供计费区域业务”参数为“TRUE”时该参数有效。计费区域1。 取值范围：1～9999                                    |
| CA2         | 计费区域2      | 仅当本命令中的“是否提供计费区域业务”参数为“TRUE”时该参数有效。计费区域2。 取值范围：1～9999                                    |
| CA3         | 计费区域3      | 仅当本命令中的“是否提供计费区域业务”参数为“TRUE”时该参数有效。计费区域3。 取值范围：1～9999                                    |

## 使用实例

运营商为IMSI号码是460000009012345的用户提供CA业务，计费区域1为1，计费区域2为2。例如：

```
MOD CA: IMSI="460000009012345", PROV=TRUE, CA1=1, CA2=2;
```
