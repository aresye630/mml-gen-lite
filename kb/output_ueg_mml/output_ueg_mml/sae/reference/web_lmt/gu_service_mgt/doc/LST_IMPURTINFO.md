# 查询IMPU全局路由数据(LST IMPURTINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询IMPU全局路由数据信息。

- 若需要查询所有IMPU全局路由数据的配置信息，请不输入参数。
- 若需要查询某个IMPU前缀对应的IMPU全局路由数据的配置信息，请只输入“IMPU前缀”参数。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                     |
|:-----------|:-------|:---------------------------------------------------------|
| IMPUPREFIX | IMPU前缀 | 用于指示系统需要按照哪个IMPU前缀来查询IMPU全局路由数据；若不输入，则表示查询所有的IMPU全局路由数据。 |

## 使用实例

1. 查询所有IMPU全局路由数据配置信息：

   ```
   LST IMPURTINFO:;
   ```

   ```
   %%LST IMPURTINFO:;%%
   RETCODE = 0 SUCCESS0001:操作成功
    
   "IMPUPREFIX"       "PID"
   112                12
   11                 1
   123                1
   1                  1
    
   Total count = 4
   There is together 1 report
    
   ---    END
   ```
2. 查询指定IMPU全局路由数据配置信息，“IMPU前缀”为“11”：

   `LST IMPURTINFO: IMPUPREFIX="11";`

   ```
   %%LST IMPURTINFO: IMPUPREFIX="11";%% 
   RETCODE = 0 SUCCESS0001:操作成功  
            
   "IMPUPREFIX"       "PID"         
   11                 1  

   Total count = 1  
   There is together 1 report  

   ---    END
   ```

## 输出结果说明

输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                     | 处理建议                                                                            |
|:--------|:--------|:-------------------------|:--------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | 输入的“IMPU前缀”参数对应的数据记录不存在。 | 根据实际情况，重新输入参数，确保输入的“IMPU前缀”参数对应的数据记录是存在的，可通过LST IMPURTINFO命令查询已存在的IMPU全局路由数据记录。 |
