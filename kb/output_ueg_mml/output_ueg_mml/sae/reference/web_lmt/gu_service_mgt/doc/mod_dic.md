# 修改DIC业务(MOD DIC)

- 参数说明

- 输出结果说明

## 命令功能

本命令用于设置DIC业务，包括签约或去签约DIC业务以及设定计费码的长度。

执行此命令后，如果是给用户签约该业务，则会下发插入用户数据消息；如果是给用户去签约该业务，则会下发删除用户数据消息。

## 注意事项

- 当使用连续批操作时需定义RECORDCOUNT与IMSI/ISDN参数，当使用非连续批操作时需定义IMSIFILE/ISDNFILE参数。
- IMSI、ISDN、IMSIFILE、ISDNFILE是条件可选参数，有且只能有一个参数出现。
- RECORDCOUNT一定不能与IMSIFILE或ISDNFILE同时存在。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                |
|:------------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | IMSI号码，E.212格式的编码，6～15位的十进制数字。                                                                                                                                                                                                                                                                                                      |
| ISDN        | MSISDN    | ISDN号码，E.164格式的编码，为1～15位的十进制数字。                                                                                                                                                                                                                                                                                                     |
| RECORDCOUNT | 用户个数      | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。                                                                                                                                                                                                                                                 |
| IMSIFILE    | IMSI文件名   | IMSI文件名称，IMSIFILE包含多个不连续的IMSI号码，每个IMSI号码占一行，16个以内的字母或数字组成的字符串。                                                                                                                                                                                                                                                                      |
| ISDNFILE    | MSISDN文件名 | MSISDN文件名称，ISDNFILE包含多个不连续的MSISDN号码，每个MSISDN号码占一行。16个以内的字母或数字组成的字符串。                                                                                                                                                                                                                                                                |
| PROV        | 是否提供DIC业务 | 是否向用户提供DIC业务。 该参数必选。 TRUE：提供FALSE：不提供                                                                                                                                                                                                                                                                                               |
| DICLENGTH   | DIC长度     | 仅当本命令中的“是否提供DIC业务”参数为“TRUE”时该参数有效。 签约的计费码长度。DICR_0：拨号时必须携带Dial Identification Code，如果不带则呼叫失败，但是对Dial Identification Code长度没有限制。 DICR_1～DICR_16：表示拨号时必须带Dial Identification Code，如果不带则呼叫失败，并且携带的Dial Identification Code长度必须是所签约的长度（1～16），如果长度不对也会导致呼叫失败。DICV：拨号时可以携带Dial Identification Code，也可以不携带Dial Identification Code，呼叫不受影响。 |

## 使用实例

为IMSI号码是460000009123456的用户提供DIC业务。

```
MOD DIC: IMSI="460000009123456", PROV=TRUE, DICLENGTH=DICR_0;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释      | 原因分析                                                                              | 处理建议                                                                                 |
|:--------|:-----------|:----------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------|
| ERR3210 | 系统不支持ACC业务 | 执行该命令时，SET MAPCONF命令中的“是否支持DIC业务”取值为“FALSE”或SET MAPSERV命令中的“设置DIC业务SSCODE”参数取值为空。 | 执行该命令前，确保SET MAPCONF命令中的“是否支持DIC业务”取值为“TRUE”且SET MAPSERV命令中的“设置DIC业务SSCODE”参数取值为不为空。 |
