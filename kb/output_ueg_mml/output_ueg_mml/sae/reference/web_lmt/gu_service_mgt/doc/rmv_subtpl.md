# 删除开户模板(RMV SUBTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于注销用户模板。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                     |
|:-------|:-------|:-----------------------------------------|
| HLRSN  | HLR序列号 | HLR序列号，有效值域为1～255，在PGW支持容灾功能或虚拟HLR功能时设置。 |
| TPLID  | 模板ID   | 模板ID，为十进制的数字，0～65534。                    |

## 使用实例

删除模板ID为2的开户模板。命令如下：

`RMV SUBTPL: HLRSN=1, TPLID=2;`
