# 更新携入用户的HLRSN(UPG NPHLRSN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于更新NPHLR（号码携带归属位置寄存器）上携入用户的HLR序列号。

当本局的HLR属性为NPHLR时，从不支持该功能的版本升级到该版本后，需要通过该命令来更新NPHLR上升级前携入用户的HLR序列号为该用户归属的HLR序列号。

**说明** 

升级后，仅需执行该命令成功更新一次携入用户的HLR序列号。

## 注意事项

“IMSI”、“MSISDN”、“IMSI文件名”及“MSISDN文件名”是条件可选参数，有且只能有一个参数出现。

## 参数说明

| 参数标识     | 参数名称      | 参数说明                                                                                                                                                                                                |
|:---------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI     | IMSI      | 用于标识系统按照哪个IMSI号码更新携入用户的HLR序列号。 取值范围：6～15位的十进制数字组成的字符串。 默认值：无。                                                                                                                                       |
| ISDN     | MSISDN    | 用于标识系统按照哪个MSISDN号码更新携入用户的HLR序列号。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                      |
| IMSIFILE | IMSI文件名   | 用于标识系统按照哪个IMSI文件名更新携入用户的HLR序列号。 IMSI批操作文件包含多个不连续的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“upgnphlrsn.txt.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16位由字母或十进制数字组成的字符串。 默认值：无。   |
| ISDNFILE | MSISDN文件名 | 用于标识系统按照哪个MSISDN文件名更新携入用户的HLR序列号。 MSISDN批操作文件包含多个不连续的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“upgnphlrsn.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16位由字母或十进制数字组成的字符串。 默认值：无。 |

## 使用实例

更新“IMSI”号码为“460000009123456”的携入用户的HLR序列号：

```
UPG NPHLRSN: IMSI="460000009123456";
```
