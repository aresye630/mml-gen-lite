# 修改SQN的IND分域配置(MOD SQNINDINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会触发鉴权重同步，因此执行该命令前，需要与华为技术支持确认后才可以实施。

本令用于修改SQN IND分域配置记录。

## 注意事项

- 执行本命令修改SQN IND签约的域，若“IND”参数取值为“NULL”，表示去签约该IND对应的域。
- 执行本命令去签约SQN IND对应域时，需要确保去签约后配置记录中每个域都被使用。

- 该命令不允许进行批操作。

## 参数说明

| 参数标识       | 参数名称       | 参数说明                                                                                                                                                                                       |
|:-----------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN      | HLR序列号     | 可选必选说明：必选参数 参数含义：标识IND分域记录的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR上的IND分域记录的参数进行修改或调整，操作员可以使用LST HLRSN命令查询获得。 取值范围：1～255 默认值：无。 配置原则：无。                                                              |
| INDSNO     | IND分域序列号   | 可选必选说明：必选参数 参数含义：标识IND分域记录的关键字段之一（其取值不能被修改），用于指定需要对哪个IND分域记录的参数进行修改或调整，操作员可以使用LST SQNINDINFO命令查询获得。 取值范围：0～65534 默认值：无。 配置原则：无。                                                            |
| IND0~IND31 | IND0~IND31 | 可选必选说明：可选参数 参数含义：用于标识修改后IND0~IND31签约的域。 取值范围： CS：表示签约CS域PS：表示签约PS域LTE：表示签约EPS域IMS：表示签约IMS域BSF：表示签约BSF域AAA：表示签约NON-3GPP域NGC：表示签约5GC域NULL：表示给IND去签约该域 默认值：无。 配置原则：修改该参数后，必须确保枚举中所有的域都配置了IND。 |

## 使用实例

修改“HLR序列号”为“1”，“IND分域序列号”为“1”的配置记录，将“IND0”的签约域修改为“PS”：

```
MOD SQNINDINFO: HLRSN=1, INDSNO=1, IND0=PS;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释       | 原因分析                       | 处理建议                                                       |
|:--------|:------------|:---------------------------|:-----------------------------------------------------------|
| ERR1004 | 无效的参数值      | 界面报错的参数不在取值范围内。            | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                           |
| ERR3007 | 记录不存在       | 待修改的“HLR序列号”配置记录不存在。       | 执行LST SQNINDINFO命令查询已配置的记录，根据实际情况，选择已配置的“HLR序列号”然后执行本命令修改。 |
| ERR4210 | 存在未配置IND值的域 | 修改“IND”参数值后，枚举中的一个或多个域未使用。 | 查看报错的配置记录，和“IND”的枚举进行对比，重新修改“IND”参数后执行本命令，确保每个域都被使用。       |
