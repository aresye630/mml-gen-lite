# 修改5G业务限制模板(MOD NGCSERRESTTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于对一条5G业务限制模板数据记录的某些参数进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一条5G业务限制模板数据记录：

- “HLR序列号”
- “模板ID”

## 注意事项

5G业务限制模板中必须保证至少有一条SMF数据记录，如果本命令中的“是否提供限制业务”参数为“FALSE”，要删除5G业务限制模板中唯一的一条SMF数据记录，则无法删除，系统会返回错误码“ERR3096：模板不能为空”。

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                              |
|:------------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号   | 可选必选说明：必选参数 参数含义：标识5G业务限制模板数据的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR上的5G业务限制模板数据记录的参数进行修改，操作员可以使用LST HLRSN命令查询获得。 取值范围：1～255 默认值：无。 配置原则：无。                                |
| TPLID       | 模板ID     | 可选必选说明：必选参数 参数含义：标识5G业务限制模板数据的关键字段之一（其取值不能被修改），用于指定需要对哪个5G业务限制模板数据记录的参数进行修改，操作员可以使用LST NGCSERRESTTPL命令查询获得。 取值范围：0～65534 默认值：无。 配置原则：无。                           |
| TPLNAME     | 模板名      | 可选必选说明：可选参数 参数含义：用于标识待修改模板在系统中的名称。 取值范围：1～60个字母或十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                       |
| PROV        | 是否提供限制业务 | 可选必选说明：可选参数 参数含义：用于标识是否提供限制业务。 取值范围：FALSE：不提供TRUE：提供 默认值：无。 配置原则：无。                                                                                               |
| SERCODE     | 业务限制列表   | 可选必选说明：条件必选参数 参数含义：用于标识当用户漫游到特定的5G区域后，对哪些业务进行限制。 取值范围： SMDATA：SMF数据 默认值：无。 配置原则：仅当本命令中的“是否提供限制业务”参数取值不为空时，该参数有效。当“是否提供限制业务”为“TRUE”时为限制，当“是否提供限制业务”为“FALSE”时为解除限制。 |
| SMDATATPLID | 会话信息模板ID | 可选必选说明：条件必选参数 参数含义：用于标识会话信息模板ID。该参数必须先由ADD SMDATATPL命令定义，然后才能在此处引用。 取值范围：1～2147483646 默认值：无。 配置原则：仅当本命令中的“业务限制列表”参数为“SMDATA”时该参数有效。                               |

## 使用实例

修改5G业务限制模板的数据记录，“HLR序列号”为“1”，“模板ID”为“8”，“是否提供限制业务”为“TRUE”，“业务限制列表”为“SMDATA”，“会话信息模板ID”为“3”。

```
MOD NGCSERRESTTPL: HLRSN=1, TPLID=8, PROV=TRUE, SERCODE=“SMDATA”, SMDATATPLID=3;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                  | 处理建议                                                                     |
|:--------|:--------|:------------------------------------------------------|:-------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 界面输入的参数不在相应的参数取值范围内。                                  | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                         |
| ERR1009 | 参数丢失    | “模板名”和“是否提供限制业务”两个参数任意一个都没有输入。                        | 根据实际情况，确保输入“模板名”和“是否提供限制业务”两个参数任意一个。                                     |
| ERR3003 | 模板未定义   | 输入的“HLR序列号”和“模板ID”对应的5G业务限制模板数据记录不存在。                 | 根据实际情况，使用LST NGCSERRESTTPL命令查询后，重新确认要修改哪个“HLR序列号”和“模板ID”对应的5G业务限制模板数据记录。 |
| ERR3007 | 记录不存在   | “HLR序列号”未定义。                                          | 根据实际情况，重新输入已定义的“HLR序列号”，可通过LST HLRSN命令查询已定义的“HLR序列号”。                    |
| ERR3096 | 模板不能为空  | 当“是否提供限制业务”参数为“FALSE”时，待删除的业务限制记录是5G业务限制模板中唯一的一条数据记录。 | 请确认是否需要删除5G业务限制模板中唯一的一条SMF数据记录，若需要删除，请通过RMV NGCSERRESTTPL命令删除相应模板。       |
