# 增加GUSS数据(ADD HGUSS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于在HSS的业务数据库中增加指定IMPI的GUSS数据，即GBA用户安全设置数据。该数据用于用户通过用户设备管理AS业务时的鉴权认证。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|:------------|:----------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMPI        | IMPI      | 用于指定一个用来增加GUSS数据的IMPI，要求输入的IMPI值符合NAI格式，字母区分大小写。 取值范围： 长度不超过127的字符串 默认值： 无 说明：必选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| GSID        | GAA服务类型   | 用于指定一个GUSS数据的“GAA服务类型”。HSS在配置时需要与对端BSF协商，并与对端BSF配置的GSID保持一致。 取值范围： UNSPECIFIC_SERVICE(Unspecific service)：表示系统取值为0。PKI-PORTAL(PKI-Portal)：表示系统取值为1。AUTHENTICATION_PROXY(Authentication Proxy)：表示系统取值为2。PRESENCE(Presence)：表示系统取值为3。MBMS(MBMS)：表示系统取值为4。LIBERTY_ALLIANCE_PROJECT(Liberty Alliance Project)：表示系统取值为5。UICC-TERMINAL_KEY_ESTABLISHMENT(UICC-Terminal Key Establishment)：表示系统取值为6。TERMINAL-REMOTE_DEVICE_KEY_ESTABLISHMENT(Terminal-Remote Device Key Establishment)：表示系统取值为7。ANDSF(ANDSF)：表示系统取值为8。GBA_PUSH(GBA Push)：表示系统取值为9。IMS_BASED_PSS_MBMS(IMS based PSS MBMS)：表示系统取值为10。OPENID_GBA_INTERWORKING(OpenID GBA Interworking)：表示系统取值为11。GENERIC_PUSH_LAYER(Generic Push Layer)：表示系统取值为12。OPENID_INTERWORKING(OpenID Interworking)：表示系统取值为13。 默认值：无。 说明：必选参数。 |
| GAAAUTHFLAG | S-GAA鉴权标志 | 仅当参数“GAA服务类型”为“PKI-PORTAL”、“ANDSF”或“OPENID_INTERWORKING”时该参数有效，用于指定一个GUSS数据的“S-GAA鉴权标志”信息。 取值范围：0～2 默认值：无 说明：该参数的取值规定如下：当参数“GAA服务类型”为“PKI-PORTAL”时，取值范围： 1（Authentication allowed） 2（Non-repudiation allowed） 当参数“GAA服务类型”为“ANDSF”时，取值范围： 0（Not authorized） 1（Authorized according to policy stored in ANDSF server） 当参数“GAA服务类型”为“OPENID_INTERWORKING”时，取值范围： 0（Not authorized） 1（Authorized）                                                                                                                                                                                                                                                                                                                                                                              |
| NAFGROUP    | NAF群组     | 用于指定一个GUSS数据的网络应用功能群组信息。 取值范围： 长度不超过127的字符串 默认值： 无 说明：可选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| UICCTYPE    | 可产生密钥种类   | 用于标识增加一条GUSS数据管理用户在进行AS业务操作时可产生哪种类型的密钥。 取值范围： GBA(GBA)：仅能产生Ks_NAF类型的密钥。GBA_U(GBA_U)：可产生Ks_NAF类型和Ks_int_NAF类型的密钥。 默认值： 无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| KEYCHOICE   | 认证密钥选择策略  | 用于标识增加一条GUSS数据管理用户在进行AS业务操作时的密钥认证策略。 取值范围： ME-based-key(ME-based-key)：仅可选取Ks_NAF类型的密钥。UICC-based-key(UICC-based-key)：仅可选取Ks_int_NAF类型的密钥。ME-UICC-based-keys(ME-UICC-based-keys)：可选取Ks_NAF或Ks_int_NAF类型的密钥。 默认值： 无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| LIFETIME    | 密钥有效时间    | 用于标识IMS-HSS通过Zh接口向BSF下发GUSS信息管理用户进行AS业务操作时，GUSS信息携带的密钥信息的有效时间。UIM按照此参数对用户密钥信息的有效性进行判断。 取值范围：1～4294967295，单位为秒。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |

## 使用实例

增加GUSS数据。“IMPI”为“impiinfo”，“GAA服务类型”为“PKI-PORTAL”，“S-GAA鉴权标志”为“1”，“NAF群组”为“nafgroup”。

```
ADD HGUSS: IMPI="impiinfo", GSID=PKI-PORTAL, GAAAUTHFLAG=1, NAFGROUP="nafgroup";
```
