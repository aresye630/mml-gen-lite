# 修改5GS用户模板(MOD NGSUSERTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于对一条5GS用户模板数据记录的某些参数进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一个5GS用户模板信息：

- “HLR序列号”
- “模板ID”

## 注意事项

无。

## 使用实例

1. 修改5GS用户模板数据，将“HLR序列号”为“1”，“模板ID”为“1”的5GS用户模板中“UE级别上行速率”修改为“3000”，“UE级别上行速率单位”修改为“bps”：

   ```
   MOD NGSUSERTPL: HLRSN=1, TPLID=1, AMBRUP=3000, UPUNIT=bps;
   ```
2. 修改5GS用户模板数据，将“HLR序列号”为“1”，“模板ID”为“1”的5GS用户模板中“是否支持切片包含模式”修改为“FALSE”：

   ```
   MOD NGSUSERTPL: HLRSN=1, TPLID=1, NSSAIINCLUSIONALLOWED=FALSE;
   ```
