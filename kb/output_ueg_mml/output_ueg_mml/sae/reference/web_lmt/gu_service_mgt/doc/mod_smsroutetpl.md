# 修改SMS-Route模板(MOD SMSROUTETPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用于修改SMS-Route模板。

## 注意事项

此模板被修改后，签约此模板的用户数据也会被修改，修改后的数据在用户新注册时会下发到网络。

## 参数说明

| 参数标识       | 参数名称                       | 参数说明                                                                                                                                                         |
|:-----------|:---------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN      | HLR序列号                     | 标识一条SMS-Route模板数据记录的关键字段之一（其取值不能被修改），用于标识需要对哪一条SMS-Route模板数据记录的参数进行修改或调整，操作员可以使用LST HLRSN命令查询获得。                                                             |
| TPLID      | 模板ID                       | 标识一条SMS-Route模板数据记录的关键字段之一（其取值不能被修改），用于标识需要对哪一条SMS-Route模板数据记录的参数进行修改或调整，操作员可以使用LST SMSROUTETPL命令查询获得。                                                       |
| TPLNAME    | 模板名                        | 用于标识待修改的SMS-Route模板名称。 取值范围：1～60位字母或数字组成的字符串。 默认值：无。                                                                                                         |
| PROV       | 是否提供SMS-Route地址和IP-SM-GW地址 | 用于标识是否提供SMS-Route和IP-SM-GW地址。 取值范围：TRUE：增加FALSE：删除 默认值：无。                                                                                                    |
| ROUTEADDR  | SMS-Route地址                | 仅当本命令中的“是否提供SMS-Route地址和IP-SM-GW地址”参数为“TRUE”或“FALSE”时该参数有效。用于标识待修改的SMS-Route模板中的SMS-Route地址。此地址用于短消息重定向时作为目的GT地址。 取值范围：1～15位的十进制数字组成的字符串。 默认值：无。             |
| IP_SM_ADDR | IP-SM-GW地址                 | 仅当本命令中的“是否提供SMS-Route地址和IP-SM-GW地址”参数为“TRUE”或“FALSE”时该参数有效。用于标识待修改的SMS-Route模板中的IP-SM-GW地址。此地址用于VoLTE用户在IMS域发送IP短消息时作为目的GT地址。 取值范围：1～15位的十进制数字组成的字符串。 默认值：无。 |

## 使用实例

修改SMS-Route模版，“模板ID”为“3”，“模板名”为“SMSRoute”，“SMS-Route地址”为“123456”，“IP-SM-GW地址”为“123”。命令如下：

```
MOD SMSROUTETPL: HLRSN=1, TPLID=3, TPLNAME="SMSRoute", PROV=TRUE, ROUTEADDR="123456", IP_SM_ADDR="123";
```
