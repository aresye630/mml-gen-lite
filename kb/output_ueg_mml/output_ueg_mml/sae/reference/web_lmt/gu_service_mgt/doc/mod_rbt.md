# 修改RBT业务(MOD RBT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来修改用户的RBT业务签约情况。为未签约RBT业务的用户提供该业务，或者为已签约RBT业务的用户撤销该业务。

## 注意事项

- IMSI、ISDN、IMSIFILE、ISDNFILE是条件可选参数，有且只能有一个参数出现。
- RECORDCOUNT一定不能与IMSIFILE或ISDNFILE同时存在。
- 如果PROV=TRUE，表示提供RBT业务，参数RBT必须出现；如果PROV=FALSE，表示撤销RBT业务，参数RBT不出现。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                             |
|:------------|:----------|:-----------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | IMSI号码，E.212格式的编码，6～15位的十进制数字。                                                                                   |
| ISDN        | MSISDN    | MSISDN号码，E.164格式的编码，1～15位的十进制数字。                                                                                 |
| RECORDCOUNT | 用户个数      | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。                              |
| IMSIFILE    | IMSI文件名   | IMSI文件名称，IMSIFILE包含多个不连续的IMSI号码，每个IMSI号码占一行，16个以内的数字或字母组成的字符串。                                                   |
| ISDNFILE    | MSISDN文件名 | MSISDN文件名称，ISDNFILE包含多个不连续的MSISDN号码，每个MSISDN号码占一行。16个以内的数字或字母组成的字符串。                                             |
| PROV        | 是否提供RBT业务 | 提供还是撤销RBT业务。 TRUE：提供 FALSE：撤销                                                                                    |
| RBT         | RBT索引     | 仅当本命令中的“是否提供RBT业务”参数为“TRUE”时该参数有效。回铃音业务的索引值，在第一次取路由信息响应中返回GMSC，在于标识用户已经签约的RBT业务。值域0～254。 该参数的配置需要和对端GMSC的配置要求一致。 |

## 使用实例

1. 运营商为IMSI号码是460000009123456的用户提供RBT业务，并指定RBT索引值为6。

   MOD RBT: IMSI="460000009123456", PROV=TRUE, RBT=6;
2. 运营商为IMSI号码是460000009123455、460000009123466和460000009123477的用户提供RBT业务，并指定RBT索引值为6。

   1. 编写IMSIFILE, 文件名称为IMSIBAT, 内容如下:

      460000009123455

      460000009123466

      460000009123477
   2. 通过Web UI上的文件选项将文件上传到指定位置。
   3. 执行MOD RBT命令提供RBT业务, 并指定RBT索引值为6。

      MOD RBT: IMSIFILE="IMSIBAT", PROV=TRUE, RBT=6;
