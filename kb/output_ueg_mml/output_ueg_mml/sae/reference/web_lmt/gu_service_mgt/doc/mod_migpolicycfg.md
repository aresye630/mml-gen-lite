## 命令功能

**须知** 

本命令属于高危命令，执行不当会使签约该策略ID的用户的消息被转发到错误的HSS或HLR，导致业务呼损，因此执行该命令前，请仔细检查配置的正确性，确认无误方可执行。如有疑问请与华为技术支持联系，制定操作的实施方案、测试方案和应急措施后才可以实施。

该命令用于修改割接策略键模板的数据信息或在指定的割接策略模板记录中添加或删除一条路由记录。如果割接策略模板中需要定义多个路由记录，则首先使用**ADD MIGPOLICYCFG**命令定义一个割接策略模板，然后使用该命令增加多个路由记录。

在该命令中，系统通过以下关键参数的组合来唯一标识一个割接策略模板信息：

- “HLR序列号”
- “割接策略ID”

## 注意事项

系统中增加的割接策略模板记录数不能超过5000条，且所有割接策略模板增加的路由记录数不能超过5000条。

## 参数说明

| 参数标识                         | 参数名称               | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                               |
|:-----------------------------|:-------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN                        | HLR序列号             | 标识割接策略模板信息数据的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR上的割接策略模板信息数据记录的参数进行修改，操作员可以使用LST HLRSN命令查询获得。                                                                                                                                                                                                                                                                                                                                            |
| MIG_POLICYID                 | 割接策略ID             | 用于标识配置割接策略ID。 取值范围：0～65534 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                  |
| POLICY_NAME                  | 策略名称               | 用于标识待修改割接策略在系统中的名称。 取值范围：1～60位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                               |
| PROV                         | 操作类型               | 用于标识是增加/修改还是删除数据。 取值范围： TRUE：增加/修改。如果指定的路由类型值在模板中存在，则修改模板中对应的数据。如果指定的路由类型值在模板中不存在，则与该路由类型值对应的数据将被增加到模板中。 FALSE：删除。如果指定的路由类型值在模板中存在，则删除模板中对应的数据。如果指定的路由类型值在模板中不存在，系统将会提示错误。 默认值：无。                                                                                                                                                                                                                                                  |
| ROUTETYPE                    | 路由类型               | 仅当本命令中的“操作类型”参数为“TRUE”或“FALSE”时该参数有效。用于标识UDM对哪种路由类型的消息进行转发处理。 取值范围： IMSI_TYPEMSISDN_TYPEATI_TYPEEPS_TYPEIMS_TYPEREPSYNC_TYPE 默认值：无。                                                                                                                                                                                                                                                                                                |
| WHETHER_FORWARD_MAP          | 是否转发MAP消息          | 仅当本命令中的“路由类型”设置为“IMSI_TYPE”或“MSISDN_TYPE”时该参数有效。用于标识UDM是否将接收到的MAP消息转发给待割接设备。 取值范围： TRUE：UDM将接收到的MAP消息转发给待割接设备进行处理。FALSE：UDM对接收到的MAP消息不转发，本地进行处理。 默认值：无。                                                                                                                                                                                                                                                                            |
| WHETHER_SEND_ATI             | 是否转发ATI            | 仅当本命令中的“路由类型”设置为“ATI_TYPE”时该参数有效。用于标识UDM在接收到待割接用户的SRI请求消息时，是否发送ATI消息到待割接的HLR查询用户的VLRNUM。 取值范围： TRUE：UDM在接收到待割接用户的SRI消息时，发送ATI消息到待割接HLR查询用户VLRNUM。FALSE：UDM在接收到待割接用户的SRI消息时，不发送ATI消息到待割接HLR查询用户VLRNUM。 默认值：无。                                                                                                                                                                                                                       |
| WHETHER_FORWARD_EPS_DIAMETER | 是否转发EPS DIAMETER消息 | 仅当本命令中的“路由类型”设置为“EPS_TYPE”时该参数有效。用于标识UDM是否转发S6a/S6d/SWx/SLh接口DIAMETER消息。 取值范围： TRUE：UDM将接收到的S6a/S6d/SWx/SLh接口 Diameter消息转发给待割接设备进行处理。FALSE：UDM对接收到的S6a/S6d/SWx/SLh接口Diameter消息不转发，本地进行处理。 默认值：无。 说明：“是否转发EPS DIAMETER消息”与“是否转发IMS DIAMETER消息”不能同时填写。                                                                                                                                                                               |
| WHETHER_FORWARD_IMS_DIAMETER | 是否转发IMS DIAMETER消息 | 仅当本命令中的“路由类型”设置为“IMS_TYPE”时该参数有效。用于标识UDM是否转发Cx/Sh/Zh接口DIAMETER消息。 取值范围： TRUE：UDM将接收到的Cx/Sh/Zh接口Diameter消息转发给待割接设备进行处理。FALSE：UDM对接收到的Cx/Sh/Zh接口Diameter消息不转发，本地进行处理。 默认值：无。 说明：“是否转发EPS DIAMETER消息”与“是否转发IMS DIAMETER消息”不能同时填写。                                                                                                                                                                                                     |
| WHETHER_PROV_REPSYNC_RULE    | 是否提供透明数据同步规则       | 仅当本命令中的“路由类型”参数为“REPSYNC_TYPE”时该参数有效。用于标识UDM是否向被割接局点自动同步透明数。 取值范围： TRUE：支持UDM收到AS发送的透明数据变更后自动同步到被割接局点。FALSE：不支持UDM收到AS发送的透明数据变更后自动同步到被割接局点 默认值：无 说明： 当该参数取值为“TRUE”时，“分区ID”和“透明数据同步规则ID”有效。当首次添加“路由类型”参数为“REPSYNC_TYPE”类型的记录，设置该参数取值为“TRUE”时，“分区ID”和“透明数据同步规则ID”参数必须同时设置。当已存在“路由类型”参数为“REPSYNC_TYPE”类型的记录，修改该参数取值为“TRUE”时，“分区ID”或“透明数据同步规则ID”至少配置一个。 该参数与“是否转发IMS DIAMETER消息”不能同时设置为“TRUE”，仅当“是否转发IMS DIAMETER消息”参数为“FALSE”时，该参数有效。 |
| RULEID                       | 透明数据同步规则ID         | 仅当本命令中的“是否提供透明数据同步规则”为“TRUE”时该参数有效。用于标识透明数据同步规则ID。该参数必须先由ADD REPSYNCRULE命令定义，然后才能在此处引用。 取值范围：1～65534 默认值：无。                                                                                                                                                                                                                                                                                                                        |
| HLRNO                        | HLR号码              | 仅当本命令中的“是否转发MAP消息”或“是否发送ATI”设置为“TRUE”时该参数有效，用于标识该割接策略下对应用户归属的HLR号码。 取值范围：1～15位的十进制数字组成的字符串。 默认值：无。 说明： “HLR号码”与“分区ID”不能同时填写。已经配置了“分区ID”的割接策略模板无法再配置“HLR号码”。                                                                                                                                                                                                                                                                        |
| PID                          | 分区ID               | 仅当本命令中“是否转发MAP消息”、“是否发送ATI”，“是否转发EPS DIAMETER消息”，“是否转发IMS DIAMETER消息”、“是否提供透明数据同步规则”中有一个设置为“TRUE”时该参数有效。用于标识分区编号。该参数必须先由ADD SPRTINFO命令定义，然后才能在此处引用。 取值范围：1～250 默认值：无。 说明： “HLR号码”与“分区ID”不能同时填写。已经配置了“分区ID”的割接策略模板无法再修改为“HLR号码”。                                                                                                                                                                                                    |

## 使用实例

修改的UDM上的策略模板数据记录。将“HLR序列号”为“1”、“割接策略ID”为“0”、“操作类型”为“TRUE”、“路由类型”为“IMSI\_TYPE”、“是否转发MAP消息”改为“FALSE”。命令如下：

```
MOD MIGPOLICYCFG: HLRSN=1, MIG_POLICYID=0, PROV=TRUE, ROUTETYPE=MSISDN_TYPE, WHETHER_FORWARD_MAP=FALSE;
```
