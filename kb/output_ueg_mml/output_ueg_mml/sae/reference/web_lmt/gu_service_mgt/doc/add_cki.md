# 异地加载KI(ADD CKI)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

此命令用于云部署环境下补卡时，在原MSISDN归属的云分区上加载KI。

KI是为用户鉴权而设。建议给KI/OPC加密，并且需要一个加密参数，UDM系统中该参数为K4。K4序列号为0表示KI/OPC不加密。

## 注意事项

- 加载KI前，需要事先通过**ADD K4**命令增加K4数据。
- 添加KI成功后，请使用**CHK KI**命令校验KIVALUE。
- 当“鉴权算法类型”取值为“MILENAGE”、“MILENAGE\_2”或“CUSTOM\_1”时，“OPC值”和“OP序列号”的其中之一必须设置但不能同时设置。
- 当**SET MAPCONF**命令中的“是否启用随机密钥”参数为“TRUE”，执行该命令时如果未使用K4对KI进行加密，同时未执行**SET DEFAULTK2SNO**命令设置默认K2，则执行该命令时会返回错误。
- 如果携带的“K4序列号”对应的“算法类型”为“SM4”，系统返回“ERR3111 系统不支持该特性”提示。

## 使用实例

为新IMSI号码460000009123456异地加载KI，原MSISDN号码为86131234567，新KI值为1234567890ABCDEF1111111111111111，K4索引号为2，卡的类型为SIM，鉴权算法为COMP128\_1。命令如下：

```
ADD K4: HLRSN=1, K4SNO=2, K4VALUE="*****";
```

```
ADD CKI: HLRSN=1, IMSI="460000009123456", MSISDN="86131234567", KIVALUE="*****", K4SNO=2, CARDTYPE=SIM, ALG=COMP128_1;
```

该命令执行正常，会返回命令执行成功的提示信息。
