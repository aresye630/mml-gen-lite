# 查询相邻TAI关系(LST TAILIST)

- 注意事项

## 命令功能

该命令用于在HSS中查询TAI及相邻TAI映射关系：

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                      |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 用于标识本地HLR，用于指示系统按照哪个HLR序列号来查询相邻TAI关系数据，该参数必须选择。                                                                                                                                                                                           |
| TAI    | 跟踪区标识  | 用于标识跟踪区，用于指示系统按照哪个跟踪区标识来查询相邻TAI关系数据；若不输入，则表示查询所有的相邻TAI关系数据。 默认值：无。 说明：TAI由MCC(Mobile Country Code)，MNC(Mobile Network Code)及TAC(Tracking Area Code)组成，总长度为9或10位。MCC为3个BCD码字符，MNC为2个或者3个BCD码字符，填写时请遵循实际长度。TAC编码为16进制数，固定为4位，有效范围0000-FFFE。 |

## 使用实例

1. 在HSS上查询“HLR序列号”为“1”的所有TAI信息：

   ```
   LST TAILIST: HLRSN=1;
   ```

   ```
   %%LST TAILIST: HLRSN=1;%%
   RETCODE = 0 SUCCESS0001:操作成功

                  TAI
                  1111111111
                  2222222222
                  3333333333
                  4444444444
                  5555555555

   Total count = 5

   There is together 1 report

   ---    END
   ```
2. 在HSS/HLR上查询“HLR序列号”为“1”，TAI为“3333333333”对应的所有相邻TAI信息：

   ```
   LST TAILIST: HLRSN=1, TAI="3333333333";
   ```

   ```
   %%LST TAILIST: HLRSN=1, TAI="3333333333";%%
   RETCODE = 0 SUCCESS0001:操作成功

                            HLRSN = 1
                              TAI = 3333333333

   Total count = 2

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                       | 处理建议                                                                                                                                                                        |
|:--------|:--------|:---------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | 根据实际情况选择：HLR序列号未定义。TAI未定义。 | 根据实际情况选择：如果需要为已定义的HLRSN查询TAI与相邻TAI映射关系，则执行LST HLRSN命令先查询已定义的HLRSN，再为已定义的HLRSN查询TAI与相邻TAI映射关系。如果需要为已定义的TAI查询对应的相邻TAI映射关系，则执行LST TAILIST命令先查询已定义的TAI，再为已定义的TAI查询对应的相邻TAI映射关系。 |
