## 命令功能

该命令用于修改用户锁的状态。当给欠费的用户停机或对已停机的用户取消停机时，可以使用该命令给用户加锁或解锁：

- 通过加锁，禁止用户的呼入、呼出、CS/PS域的位置更新以及对CS/PS/EPS/NON3GPP业务和5GS业务的使用，即给用户停机。
- 通过解锁，恢复用户的呼入、呼出、CS/PS域的位置更新以及对CS/PS/EPS/NON3GPP业务和5GS业务的使用，即给用户复机。

通过该命令给用户加锁禁止用户呼入、呼出时，HLR在取路由信息操作的响应中返回呼叫拒绝实现禁止用户呼入，HLR向VLR下发ISD消息插入ODB数据，通过ODB业务实现禁止用户呼出：

- 如果**SET MAPCONF**命令中的参数“加锁操作时是否提供删除用户位置”设置为“TRUE”，且同时给用户签约了锁呼入和锁呼出，则HLR会向VLR下发Cancel Location消息，清除VLR中该用户的相关数据。
- 如果**SET MAPCONF**命令中的参数“加锁操作时是否提供删除用户位置”设置为“FALSE”，则不会清除VLR中该用户的数据。

通过该命令给用户加锁，禁止用户PS域位置更新和GPRS业务的使用时：

- 如果**SET MAPSERV**命令中的参数“GPRS用户加锁控制开关”设置为“CANCELLOCATION”，则HLR会向SGSN下发Cancel Location消息，清除SGSN中该用户的相关数据。当该用户之后的PS域位置登记请求上报给HLR，HLR将直接拒绝用户PS域的位置更新请求，通过此方式实现禁止用户PS域位置更新和GPRS业务的使用。
- 如果**SET MAPSERV**命令中的参数“GPRS用户加锁控制开关”设置为“ROAMINGRESTRICT”，则HLR会向SGSN下发ISD消息插入ODB数据，通过ODB业务实现禁止用户PS域位置更新和GPRS业务的使用。

通过该命令给用户加锁，禁止用户5GS业务的使用时，在主机侧流程中限制用户。主机侧在MCI消息中判断用户是否已经在AMF注册，如果已经注册，则向AMF发送去注册请求，删除用户的所有动态信息，包括订阅信息。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，但必须且只能选择其中之一。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。
- 系统在初始化的时候已经预置了“是否提供锁呼入业务”、“是否提供锁呼出业务”、“是否提供GPRS锁业务”、“是否闭锁CS位置更新”、“是否闭锁GPRS位置更新”、“是否提供EPS锁业务”、“是否提供NON3GPP锁业务”和“是否提供5GS锁业务”八个参数的值为“FALSE（不加锁）”，操作员可以通过**LST LCK**命令查询得出。

## 参数说明

| 参数标识        | 参数名称           | 参数说明                                                                                                                                                                                                            |
|:------------|:---------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI           | 用于标识需要修改锁状态的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                            |
| ISDN        | MSISDN         | 用于标识需要修改锁状态的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                          |
| RECORDCOUNT | 用户个数           | 用于标识需要修改锁状态的用户数目。 当需要为连续号码的多个用户修改锁状态时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户修改锁状态。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户修改锁状态，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名        | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要修改锁状态的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modlck.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～35个字母或数字组成的字符串。 默认值：无。                                    |
| ISDNFILE    | MSISDN文件名      | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要修改锁状态的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modlck.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～35个字母或数字组成的字符串。 默认值：无。                              |
| IC          | 是否提供锁呼入业务      | 用于标识是否禁止用户的呼入。 取值范围：TRUE：加锁，禁止用户的呼入。FALSE：不加锁，允许用户的呼入。 默认值：无。                                                                                                                                                   |
| OC          | 是否提供锁呼出业务      | 用于标识是否禁止用户的呼出。 取值范围：TRUE：加锁，禁止用户的呼出。FALSE：不加锁，允许用户的呼出。 默认值：无。                                                                                                                                                   |
| GPRSLOCK    | 是否提供GPRS锁业务    | 用于标识是否禁止用户使用GPRS业务。 取值范围：TRUE：加锁，禁止用户使用GPRS业务。FALSE：不加锁，允许用户使用GPRS业务。 默认值：无。                                                                                                                                    |
| CSUPLLCK    | 是否闭锁CS位置更新     | 用于标识是否禁止用户在CS域位置更新。 取值范围：TRUE：加锁，禁止用户在CS域位置更新。FALSE：不加锁，允许用户在CS域位置更新。 默认值：无。                                                                                                                                    |
| PSUPLLCK    | 是否闭锁GPRS位置更新   | 用于标识是否禁止用户在PS域位置更新。 取值范围：TRUE：加锁，禁止用户在PS域位置更新。FALSE：不加锁，允许用户在PS域位置更新。 默认值：无。                                                                                                                                    |
| EPSLOCK     | 是否提供EPS锁业务     | 用于标识是否禁止用户使用EPS业务。 取值范围：TRUE：加锁，禁止用户使用EPS业务。FALSE：不加锁，允许用户使用EPS业务。 默认值：无。                                                                                                                                       |
| NON3GPPLOCK | 是否提供NON3GPP锁业务 | 用于标识是否禁止用户使用NON3GPP业务。 取值范围：TRUE：加锁，禁止用户使用NON3GPP业务。FALSE：不加锁，允许用户使用NON3GPP业务。 默认值：无。                                                                                                                           |
| NGSLOCK     | 是否提供5GS锁业务     | 用于标识是否禁止用户使用5G业务。 取值范围：TRUE：加锁，禁止用户使用5G业务。FALSE：不加锁，允许用户使用5G业务。 默认值：无。                                                                                                                                          |

## 使用实例

1. 禁止IMSI号码为“460030913121001”的用户的呼入与呼出：

   ```
   MOD LCK: IMSI="460030913121001", IC=TRUE, OC=TRUE;
   ```
2. 禁止3个连续号码的用户在CS域位置更新，这3个MSISDN号码分别为“13310911001”、“13310911002”、“13310911003”：

   ```
   MOD LCK: ISDN="13310911001", RECORDCOUNT=3, CSUPLLCK=TRUE;
   ```
3. 禁止3个非连续号码的用户使用NON3GPP业务，这3个MSISDN号码分别为“13310911001”、“13310911003”、“13310911005”，已保存在“MSISDN文件名”为“modlck.txt”的文件中，并通过文件管理功能上传到指定目录：

   ```
   MOD LCK: ISDNFILE="modlck.txt", NON3GPPLOCK=TRUE;
   ```
