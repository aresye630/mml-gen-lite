## 命令功能

**须知** 

本命令属于高危命令。操作前请务必确认指定的用户为本UDM中已不再使用或测试的用户。否则执行不当将删除正常用户的5G业务数据，导致正常用户无法使用5G业务，且删除后该用户的相关数据无法恢复。

该命令用于为单个5G用户或多个5G用户删除5G业务和数据。

该命令的使用场景：当用户为本UDM中已不再使用或测试的用户时，执行本命令取消用户的5G业务。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。
- 执行该命令取消用户5G业务时，UDM会给当前注册的AMF发送去注册消息（Nudm\_UECM\_DeregistrationNotification），同时删除与用户相关的静态和动态数据，这些数据包括5G基本信息、会话信息、AMF注册信息等。

## 参数说明

| 参数标识        | 参数名称          | 参数说明                                                                                                                                                                                                                                                                                                                         |
|:------------|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI          | 可选必选说明：条件可选参数 参数含义：用于标识需要删除5G业务数据的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                           |
| ISDN        | MSISDN        | 可选必选说明：条件可选参数 参数含义：用于标识需要删除5G业务数据的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                         |
| RECORDCOUNT | 用户个数          | 可选必选说明：条件可选参数 参数含义：用于标识需要删除5G业务数据的用户的数目。 取值范围：1～100000 默认值：无。 配置原则： 当需要为连续号码的多个用户销户时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户删除5G业务数据。该参数是对连续号码的多个用户删除5G业务数据，当只有一个用户时，该参数不必配置。当一次删除5G业务数据的用户个数很多时，对系统性能无影响，但删除5G业务数据的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。                                                                      |
| IMSIFILE    | IMSI文件名       | 可选必选说明：条件可选参数 参数含义：用于标识IMSI批操作文件。 取值范围：1～35位字母或十进制数字组成的字符串。 默认值：无。 配置原则：IMSI批操作文件包含多个不连续的需要删除5G业务数据的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“rmvngssub.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。                                                                                                                |
| ISDNFILE    | MSISDN文件名     | 可选必选说明：条件可选参数 参数含义：用于标识MSISDN批操作文件。 取值范围：1～35个字母或十进制数字组成的字符串。 默认值：无。 配置原则：MSISDN批操作文件包含多个不连续的需要删除5G业务数据的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“rmvngssub.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。                                                                                                          |
| SUPCAN      | 是否抑制下发消息给对端网元 | 可选必选说明：可选参数 参数含义：用于标识UDM是否抑制下发删除用户5G业务数据时触发的Nudm_UECM_DeregistrationNotification消息给对端设备。 取值范围:SUPPRESSION：抑制，即不下发删除用户5G业务数据时触发的Nudm_UECM_DeregistrationNotification消息给对端设备。UNSUPPRESSION：不抑制，即下发删除用户5G业务数据时触发的Nudm_UECM_DeregistrationNotification消息给对端设备。 默认值：UNSUPPRESSION。 配置原则：该参数设置为“SUPPRESSION”时，会导致UDM与对端设备存储的数据不一致。 |

## 使用实例

1. 删除IMSI号码为“461120093456123”的用户的5G业务和数据：

   ```
   RMV NGSSUB: IMSI="461120093456123", SUPCAN=UNSUPPRESSION;
   ```
2. 删除IMSI号码为“461120093456123”、“461120093456124”、“461120093456125”的3个连续用户的5G业务和数据：

   ```
   RMV NGSSUB: IMSI="461120093456123", RECORDCOUNT=3, SUPCAN=UNSUPPRESSION;
   ```

## 参考信息

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
