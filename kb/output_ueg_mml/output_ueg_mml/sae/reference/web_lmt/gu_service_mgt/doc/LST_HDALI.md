# 查询IMPU的动态位置信息(LST HDALI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询指定IMPU的接入动态位置信息，需要输入唯一标识该数据记录的关键参数IMPU。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                        |
|:-------|:-------|:--------------------------------------------------------------------------------------------|
| IMPU   | IMPU   | 用于指示系统需要查询指定IMPU对应的接入动态位置信息。要求输入的IMPU值符合SIP URI或TEL URI格式，字母区分大小写。 取值范围：长度不超过127的字符串 缺省值：无。 |

## 使用实例

查询IMPU的动态位置信息。IMPU：sip:impuinfo@huawei.com。

```
LST HDALI: IMPU="sip:impuinfo@huawei.com";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义如表1所示。

| 参数标识       | 参数说明          |
|:-----------|:--------------|
| IMSALI     | 显示IMS接入位置信息。  |
| NASSALI    | 显示NASS接入位置信息。 |
| IPV4ADDR   | 显示IPv4地址。     |
| IPV6ADDR   | 显示IPv6地址。     |
| SIPADDR    | 显示SIP地址。      |
| NASSSTATUS | 显示NASS游牧状态。   |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

|       错误码 | 错误码解释         | 原因分析                                                             | 处理建议                                |
|----------:|:--------------|:-----------------------------------------------------------------|:------------------------------------|
| 900001004 | 无效的参数名        | 参数“IMPU”输入不正确。                                                   | 重新输入正确的参数。                          |
| 900001007 | 无效的参数值        | 可能原因为如下之一：参数“IMPU”的取值不符合SIP URI或TEL URI格式。参数“IMPU”取值的字符串长度超过127。 | 根据实际情况，重新输入“IMPU”的取值，确保其取值符合要求。     |
| 900001008 | 参数不足          | 参数“IMPU”没有输入。                                                    | 根据实际情况，重新输入参数，确保“IMPU”必须存在。         |
| 900001010 | 参数重复          | 重复输入参数“IMPU”。                                                    | 删除多余的重复参数“IMPU”后，重新执行该命令。           |
| 900003060 | 请求消息中的IMPU不存在 | 参数“IMPU”取值实际不存在，即用户对应的IMPU未定义。                                   | 通过LST HSUB命令查询已存在的IMPU后，根据实际情况重新输入。 |
| 900003257 | 表中没有任何记录      | 输入的“IMPU”没有对应的接入动态位置信息。                                          | 无需处理。                               |
