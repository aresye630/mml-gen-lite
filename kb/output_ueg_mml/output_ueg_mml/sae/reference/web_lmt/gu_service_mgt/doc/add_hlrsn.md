## 命令功能

**须知** 

本命令属于高危命令，执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于增加一条虚拟HLR的配置信息。

虚拟HLR为网络中重要的组成部分，既可以配置为具有虚拟HLR功能的HLR，为分权分域管理和按照虚拟HLR提供差异化业务，又可以配置为具有容灾功能的HLR，保障通信系统的安全性。因此在开局阶段，为了满足不同地区本地网的功能需求，需要使用此命令为已添加的虚拟HLR添加配置信息，使其能按照设定好的功能进行工作。

**说明** 

- 新建局点：在全新部署流程中，首次通过**ADD HLRSN**命令添加HLRSN记录时，系统会默认生成一条KEYID为3001的缺省随机密钥记录，同时会自动生成一条“GK2SNO”为“1”全局的随机默认GK2记录，并使用KEYID为3001的随机秘钥加密该GK2数据。
- 执行本命令时，系统默认会添加两条AMF记录，该记录中的C1～C5、R1～R5需要支持使用加密默认GK2的随机密钥加密。

## 注意事项

- 增加HLR配置信息之前必须确保已添加系统HLR以及虚拟HLR（添加系统HLR及虚拟HLR可参见**ADD SYSHLRSN**及**ADD VHLRSN**命令）。
- 只有admin具有此命令的操作权限。
- 当**SET MAPCONF**命令中“主备容灾部署时容灾FE是否使用主用局主机名”参数取值为“TRUE”并且**SET MAPSERV**中参数“本局信息选取方式”取值为“DEFAULT”时，该命令配置的“主用局主机名”和“主用局域名”、或者“IMS主用局主机名”和“IMS主用局域名”参数必须也在“UDM MML命令”界面执行**ADD DMLE**/**MOD DMLE**命令进行配置，否则会上报“ALM-16014 本端信令配置数据不一致”告警。
- 混合组网下，执行该命令设置“HLR最大用户数”、“HLR最大EPS用户数”、“IMS最大用户数”参数值，只能在vRSP上生效，不支持同步到SP。
- 执行本命令前，需通过**SET MAPSERV** 设置“CB密码”的取值，否则执行该命令时会上报“4172：系统缺省CB密码无效，请先通过MAPSERV设置CB密码”错误。

## 使用实例

- 若要将新增加的HLR配置成具有虚拟HLR功能的HLR，操作员需要进行以下配置。

  1. 添加一个系统HLR，“系统HLR序列号”为“1”，“系统HLR名称”为“MASTERNO1”，“状态”为“MASTER”，命令如下：

     ```
     ADD SYSHLRSN: SYSHLRSN=1, HLRNAME="MASTERNO1", STATUS=MASTER;
     ```
  2. 加一个虚拟HLR，“系统HLR序列号”为“1”，“虚拟HLR序列号”为“1”，“虚拟HLR名称”为“huawei”，命令如下：

     ```
     ADD VHLRSN: SYSHLRSN=1, HLRSN=1, HLRNAME="huawei";
     ```
  3. 为“HLR序列号”为“1”的虚拟HLR增加配置信息，使其具有虚拟HLR功能。“HLR号码”为“8613800”，“状态”为“MASTER”，“国家码”为“86”，“HLR最大EPS用户数”为“200”，“IMS最大用户数”为“200”：

     ```
     ADD HLRSN: HLRSN=1, HLRNO="8613800", STATUS=MASTER, CCODE="86", MAXEPSUSERNUM=200, MAXIMSUSERNUM=200;
     ```
- 若要将新增加的HLR配置成具有容灾功能的HLR，操作员需要进行以下配置（默认已配置系统HLR及虚拟HLR）。

  为“HLR序列号”为“1”的虚拟HLR增加配置信息，使其具有容灾HLR功能。“HLR号码”为“8613800”，“状态”为“ACTIVE”，“国家码”为“89”：

  ```
  ADD HLRSN: HLRSN=1, HLRNO="8613800", STATUS=ACTIVE, CCODE="89";
  ```
