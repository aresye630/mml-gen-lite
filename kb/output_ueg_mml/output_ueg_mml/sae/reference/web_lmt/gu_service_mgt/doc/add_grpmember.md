# 增加智家随行家庭网关(ADD GRPMEMBER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于增加智家随行家庭网关。UDM支持对签约的智家随行家庭网关数据的下发。

## 注意事项

- “智家随行家庭网关IMSI号码”和“智家随行家庭网关MSISDN号码”必须有且只能有一个参数出现。
- 每个“智家随行家庭网关IMSI号码”最多可以签约5个智家随行家庭网关。
- 每个“智家随行家庭网关IMSI号码”签约的“智家随行家庭网关名称”不能重复。

## 参数说明

| 参数标识      | 参数名称             | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                |
|:----------|:-----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI      | 智家随行家庭网关IMSI号码   | 可选必选说明：条件可选参数 参数含义： 用于标识家庭网关身份的IMSI，多个家庭网关的IMSI可以相同。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                          |
| ISDN      | 智家随行家庭网关MSISDN号码 | 可选必选说明：条件可选参数 参数含义： 用于标识智家随行家庭网关MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                                     |
| GRPNAME   | 智家随行家庭网关名称       | 可选必选说明：必选参数 参数含义：用于标识智家随行家庭网关名称。 取值范围：1～60位字符串，字符串由数字、字母、“.”、“-”或“_”组成。该参数输入的字母不区分大小写。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                               |
| INGROUPID | 智家随行内部群组号        | 可选必选说明：必选参数 参数含义：用于标识智家随行内部群组号，指的是智家随行群组使用的5G LAN群组号。该参数必须由ADD VNGROUP命令定义后才能在此处引用。 取值范围：10～38个十进制数字、十六进制数字或“-”组成的字符串。 默认值：无。 配置原则：格式为：1-46001-4F124689，由“-”字符分割的三部分组成。第一部分表示Group service ID，格式为十进制数字组成的字符串，取值范围为1～4294967295。超过1000的取值由归属运营商自行规划，1000以内的取值含义由3GPP协议定义。 第二部分表示归属PLMNID，格式为5～6位的十进制数字组成的字符串，前三个数字表示MCC，最后剩余的2个或3个数字表示MNC。第三部分为Local-Group-ID，格式为长度不超过20的十六进制数字组成的字符串。长度必须是偶数。取值由运营商规划，避免在多个UDM之间重复。 该参数输入的字母不区分大小写。 |
| EXTID     | 智家随行家庭网关扩展ID     | 可选必选说明：可选参数 参数含义：用于标识智家随行群组中家庭网关的扩展ID。 取值范围：格式为<IMSI>_XXX，其中<IMSI>为“智家随行家庭网关IMSI号码”，XXX为8位十进制随机数。 默认值：无。 配置原则：执行该命令并且不输入该参数时，UDM会自动设置数值。                                                                                                                                                                                                                                                                                            |

## 使用实例

1. 执行命令增加智家随行家庭网关，“智家随行家庭网关IMSI号码”为“460030913121001”、“智家随行家庭网关名称”为“home1”，“智家随行内部群组号”为“1001-46008-01”：

   ```
   ADD GRPMEMBER: IMSI="460030913121001", GRPNAME="home1", INGROUPID="1001-46008-01";
   ```
2. 执行命令增加智家随行家庭网关，“智家随行家庭网关MSISDN号码”为“13310911001”、“智家随行家庭网关名称”为“home1”，“智家随行内部群组号”为“1001-46008-01”、“智家随行家庭网关扩展ID”为“460030913121001\_00000001”：

   ```
   ADD GRPMEMBER: ISDN="13310911001", GRPNAME="home1", INGROUPID="1001-46008-01", EXTID="460030913121001_00000001";
   ```
