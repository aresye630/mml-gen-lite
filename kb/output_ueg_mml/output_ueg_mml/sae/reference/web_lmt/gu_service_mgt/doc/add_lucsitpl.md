## 命令功能

该命令用于为HLR在配置数据库中增加一条LU-CSI（Location Upgrade Services CAMEL Subscription Information）模板数据记录，根据运营商CAMEL网络的实际情况进行配置，相关参数由运营商提供。用户通过签约LU-CSI模板ID签约LU-CSI业务。

LU-CSI是一种CAMEL签约数据，目前只用于LBS（Location Based Services）业务。VLR支持DP3或DP4时，处理逻辑如下：

- 用户签约的“DP类型”为“DP3”，NCCTPL模板的“LU是否支持DP3”参数为“SR”，用户在进行位置更新时，MSC在插入用户信息消息中下发签约了DP3的LU-CSI信息给VLR，由MSC触发INAP（Intelligent Network Application Part）消息到智能网络。
- 用户签约的“DP类型”为“DP4”，NCCTPL模板的“LU是否支持DP4”参数为“SR”，HLR收到位置更新请求时，判断MAP协议版本为V3且VLR发生变化，给VLR回位置更新响应前，HLR触发INAP（Intelligent Network Application Part）消息到智能网络。

智能网络基于INAP消息实现不同业务逻辑，譬如欢迎短消息、OTA Roaming list更新和欢迎消息可以包含套餐资费宣传信息等。

## 注意事项

**ADD LUCSITPL**命令只能给一个模板增加一个DP值的触发准则，如果需要增加多个DP值的触发准则，请执行**MOD LUCSITPL**命令。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
|:-----------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN      | HLR序列号 | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                                                                                                                                                                                                                                                                      |
| TPLID      | 模板ID   | 用于标识待增加模板在系统中的序号。 取值范围：0～65534 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                             |
| TPLNAME    | 模板名    | 用于标识待增加模板在系统中的名称。 取值范围：1～60位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                |
| DP         | DP类型   | 用于标识触发LU-CSI业务的检出点，当在检出点满足相应的DP触发准则时，就会触发相应的CAMEL业务。 用户进行位置更新时HLR是否下发该DP值相关数据给VLR取决于该VLR是否支持DP3或DP4，可以通过执行LST VLRTYP命令查看该VLR是否签约NCC模板，如果未签约，则默认不支持。如果已签约，则执行LST NCCTPL命令查看“LU是否支持DP3”参数是否为“SR”（LU-CSI中的DP3数据下发到VLR）和“LU是否支持DP4”参数是否为“SR”（LU-CSI中的DP4数据下发到VLR）。 取值范围：DP3：由MSC触发INAP（Intelligent Network Application Part）消息到智能网络DP4：由HLR触发INAP消息到智能网络 默认值：无。                                                                                                       |
| SCPADDR    | SCP地址  | 用于标识接入gsmSCF（GSM Service Control Function）功能实体的地址。 取值范围：1～15位十进制数字组成的字符串。 采用E.164编码方式，编码格式为：CC+NDC+LSP，例如，一个典型的“SCP地址”为：“86-139-00777”。各关键字段的含义是： CC（Country Code）：国家码，即SCP所处国家在国际PSTN编号计划中的国家码，它由ITU-T在全球范围内统一分配，其最大长度为3位。例如，中国的国家码为86、英国的国家码为44等。NDC（National Destination Code）：国内目的码，即移动业务接入码，它是由本国电信主管部门在本国范围内统一分配的PLMN网络号，其最大长度为3位。例如，某运营商使用的PLMN网络号为134～139。LSP（Locally Significant Part）：本地有效部分，它是由某个运营商在本PLMN网络运营范围内统一分配的、用于具体代表某个SCP的号码，其最大长度为9位。 默认值：无。 |
| SKEY       | 业务键    | 用于标识用户在gsmSCF中签约的CAMEL业务。gsmSSF（GSM Service Switching Function）将业务键发给gsmSCF后，gsmSCF根据该业务键执行对应的业务逻辑。业务键是HLR与SCP的对接参数之一，用于在CAP/INAP消息中唯一标识一种智能业务，它是一种号码资源，需要由运营商向本国的电信主管部门申请获得。 取值范围：0～2147483647 默认值：无。                                                                                                                                                                                                                                                            |
| TRANS_TYPE | 处理类型   | 仅当本命令中的“DP类型”参数为“DP3”时该参数有效。用于标识系统在何时触发LU-CSI业务。 取值范围：L(normal-location-update)：正常位置更新时（默认值：TRUE）A(IMSI-attach)：IMSI附着时（默认值：FALSE）P(periodic-location-update)：周期性位置更新时（默认值：FALSE） 说明：用户可以签约多个DP触发准则，并用“&”连接，例如L-1&A-1&P-1。参数复选框中的灰化表示不修改系统原有值。                                                                                                                                                                                                                    |

## 使用实例

在“HLR序列号”为“1”的HLR上增加一条LU-CSI模板数据记录。其中，“模板ID”为“2”，“模板名”为“LUCSITPL”，“DP类型”为“D3”，“SCP地址”为“8613758”，“业务键”为“11”，“处理类型”为“L”时：

```
ADD LUCSITPL: HLRSN=1, TPLID=2, TPLNAME="LUCSITPL", DP=DP3, SCPADDR="8613758", SKEY=11, TRANS_TYPE=L-1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                          | 处理建议                                                                     |
|:--------|:--------|:------------------------------|:-------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | “HLR序列号”未定义。                  | 根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求。                                        |
| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”参数不在相应的参数取值范围内。 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                         |
| ERR3004 | 模板已存在   | 本次操作输入的“模板ID”在数据库中已存在。        | 根据实际情况，重新输入参数，确保输入的“模板ID”和系统中已存在的不重复。可执行LST LUCSITPL命令查询系统中已存在的LU-CSI模板。 |
