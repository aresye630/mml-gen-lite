# 修改它网携转用户数据(MOD NPOTHERRPT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用于修改它网携转用户数据。

该指令支持批操作。

## 注意事项

- ISDN、ISDNFILE是条件可选参数，此操作中有且只能一个参数出现。
- RECORDCOUNT一定不能与ISDNFILE同时存在。
- RN和MSCID是可选参数，必须出现一个。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                           |
|:------------|:----------|:-------------------------------------------------------------------------------|
| ISDN        | MSISDN    | MSISDN号码，E.164格式的编码，为1～15位的十进制数字。                                              |
| RECORDCOUNT | 用户个数      | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的MSISDN为起始号码，号码连续的RECORDCOUNT个用户。 |
| ISDNFILE    | MSISDN文件名 | ISDN文件名称，1～16个字母或数字组成。ISDNFILE包含多个不连续的MSISDN号码。 说明：可选参数。                       |
| RN          | 路由码       | 路由码，1～10位的十进制数字或者A~E字符。 说明：可选参数。                                               |
| MSCID       | MSCID     | MSCID号码，E.164格式的编码，1～15位的十进制数字。 说明：可选参数。                                       |

## 使用实例

修改单个它网携转用户。

修改MSISDN号码为86131075003003的它网携转用户的路由码为1113。命令如下：

```
MOD NPOTHERRPT: ISDN="86131075003003", RN="1113";
```
