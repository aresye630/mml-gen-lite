# 以格式2查询用户鉴权数据(LST NZMAO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于以格式2查询用户的鉴权数据，输入用户的“IMSI”号码，系统将以特定的格式返回查询结果。

使用场景限于运营商对返回报文格式有特殊适配需求。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数描述                                                      |
|:-------|:-------|:----------------------------------------------------------|
| IMSI   | IMSI   | 用于指示系统需要查询哪个IMSI号码的用户的鉴权数据。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 |

## 使用实例

查询IMSI号码为“461380000000000”的用户的鉴权数据，以特定的数据格式返回。命令如下：

```
LST NZMAO: IMSI="461380000000000";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 消息解释   | 原因分析                                 | 处理建议                                                             |
|:--------|:-------|:-------------------------------------|:-----------------------------------------------------------------|
| ERR1004 | 无效的参数值 | 参数“IMSI”的取值不是6～15位十进制数字组成的字符串。       | 根据实际情况，重新输入“IMSI”的取值，确保其取值符合要求。                                  |
| ERR1009 | 参数丢失   | 参数“IMSI”没有输入。                        | 根据实际情况，重新输入参数。                                                   |
| ERR3001 | 用户未开户  | 用户的IMSI号码输入错误，实际输入的参数“IMSI”对应的用户未开户。 | 核实用户的IMSI号码，如果确定输入无误，证明实际输入的参数“IMSI”对应的用户未开户，请先通过ADD SUB命令给用户开户。 |
