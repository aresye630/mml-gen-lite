## 命令功能

该命令用于签约、修改和删除用户的接入和移动管理数据。通过本命令给用户签约5G业务，可以触发自动将用户从ATCA BE迁移至UDR中。

在混合组网场景，执行该命令会触发用户迁移到新的分区。用户数据仅支持迁移，不支持5G相关业务。

- 对于增强GROUPSIM用户（通过**SET MAPCONF**命令设置“是否支持GROUPSIM增强业务”参数为“TRUE”），执行该命令时可以将组内所有成员一同迁移到新的分区。对于普通的GROUPSIM用户（通过**SET MAPCONF**命令设置“是否支持GROUPSIM增强业务”参数为“FALSE”），执行该命令时无法将组内所有成员一同迁移到新的分区，会造成普通GROUPSIM的主卡、辅卡不在同一个归属分区的场景。各业务流程已实现成员跨分区业务无影响。
- 迁移过程中License统计结果不更新，依赖License周期性校验校正。

## 注意事项

- 如果给非5G用户（2G/3G/4G用户）初始增加AMF数据，用户会变为5G用户。
- 初始签约AMF数据时，“是否提供AM签约数据”参数取值“TRUE”，其它签约项均为可选，根据业务情况选择，用户数据中增加一条记录。
- 修改AMF数据时，“是否提供AM签约数据”参数取值“TRUE”，其它签约项均为可选，只修改被选择的签约项目对应的字段，其它字段值保持不变。
- 删除AMF数据时，“是否提供AM签约数据”参数取值“FALSE”，删除对应用户数据记录。
- 在删除用户AMF数据之前，应先通过**RMV SNSSAI**删除用户签约的切片管理数据。
- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数必须有且只能有一个参数出现。
- “用户个数” 参数一定不能与“IMSI文件名”或“MSISDN文件名”同时存在，“用户个数”参数只能与“IMSI”或“MSISDN”一起出现。
- 当用户首次签约5G业务时，“UE级别上行速率”、“UE级别上行速率单位”、“UE级别下行速率”和“UE级别下行速率单位”四个参数必须同时出现。
- 当通过本命令设置“无线接入类型限制”参数为“全部选中”、“WLAN”或“VIRTUAL”后，将无法通过本命令清除无线接入类型限制，即设置“无线接入类型限制”为“全部清空”，如果需要清除无线接入类型限制，则需通过**MOD RATRESTRICT**命令设置“是否限制WLAN接入”与“是否限制VIRTUAL接入”参数的取值。
- 在混合组网下，如存在异常场景下进行跨SP数据迁移时，需要通过设置“USERDATAMIGEXCEPENHANCESW（用户数据迁移容错能力增强开关）”软参支持数据的兼容处理，避免因为UDB和PaasDB数据模型不一致而处理失败。
  - 插件包schemamap.xml文件中配置RDN冲突节点（rdnconflictexcepproc），即从5G接入查询4G用户和用户数据迁移过程中该节点存在冲突记录时，若该软参为“1”，根据timestampfield配置字段取最新的一条数据，无timestampfield配置，随机取一条数据；若软参为“0”，则从5G接入查询4G用户和迁移失败。
  - 插件包schemamap.xml文件中配置无父节点的节点（noparentnodeexcepproc），即从5G接入查询4G用户和用户数据迁移过程中该节点无父节点记录时，若软参为“1”，忽略该节点数据不处理；若软参为“0”，则从5G接入查询4G用户和迁移失败。

## 使用实例

1. 为用户签约或修改接入和移动管理数据，“IMSI”为“460000009123456”，“是否提供AM签约数据”为“TRUE”，“UE级别上行速率”为“2342432”，“UE级别上行速率单位”为“bps”，“UE级别下行速率”为“3123133”，“UE级别下行速率单位”为“bps”，“无线接入类型限制”为“WLAN”，“禁止区域模板”为“1”，“业务限制信息模板”为“123123”，“是否支持多媒体优先级服务”为“TRUE”，“鉴权方式”为“5G-AKA”：

   ```
   MOD AMDATA: IMSI="460000009123456", PROV=TRUE, AMBRUP=2342432, UPUNIT=bps, AMBRDW=3123133, DWUNIT=bps, RATRESTRICT=WLAN, FORBIDTPLID=1, SERAREATPLID=123123, MPS=TRUE, AUTHTYPE=5G-AKA;
   ```
2. 删除用户已签约的接入和移动管理数据。“IMSI”为“460000009123456”，“是否提供AM签约数据”为“FALSE”：

   ```
   MOD AMDATA: IMSI="46000000912346", PROV=FALSE;
   ```

## 参考信息

**IMSIFILE文件格式**

IMSIFILE文件包含不连续的IMSI号码，格式如下所示：

```
IMSI1
IMSI2
IMSI3
IMSI4
……
IMSIn
```

IMSIn为6～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**ISDNFILE文件格式**

ISDNFILE文件包含不连续的MSISDN号码，格式如下所示：

```
MSISDN1
MSISDN2
MSISDN3
MSISDN4
……
MSISDNn
```

MSISDNn为1～15位的十进制数字，行结束为回车换行符，行与行之间不能存在空行。

第一行和最后一行数据必须是有效数据，不能是空格、空行或Tab键。

**批操作资源文件存放位置**

在PGW Web LMT执行批操作处理前，要上传预先编写的批操作资源文件到PGW Server的指定目录。

批操作资源文件可通过PGW Web LMT的文件上传功能上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。

例如，当前的SYSHLRSN为“1”，操作员名称为“admin”，则存储批操作资源文件的目录为：“/opt/pgw/pgwtmpfile/001admin”。

其中，SYSHLRSN和操作员名称均为当前登录的系统HLRSN和操作员。系统HLRSN可以通过命令**LST SYSHLRSN**进行查询。
