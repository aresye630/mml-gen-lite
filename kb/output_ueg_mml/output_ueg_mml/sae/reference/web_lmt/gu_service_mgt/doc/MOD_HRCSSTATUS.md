# 修改RCS业务状态(MOD HRCSSTATUS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改RCS业务中的条款接受状态，并根据该状态自动刷新IMS用户的SIFC记录。

## 注意事项

“IMSI”和“MSISDN”是可选参数，必须输入且只能有一个参数出现。

## 参数说明

| 参数标识           | 参数名称   | 参数说明                                                                                                           |
|:---------------|:-------|:---------------------------------------------------------------------------------------------------------------|
| IMSI           | IMSI   | 标识RCS业务的关键字段之一（其取值不能被修改），用于修改RCS业务接受请求的状态，操作员可以使用LST HRCSSERVICE命令查询获得。                                        |
| ISDN           | MSISDN | 标识RCS业务的关键字段之一（其取值不能被修改），用于修改RCS业务接受请求的状态，操作员可以使用LST HRCSSERVICE命令查询获得。                                        |
| ACPTTERMSTATUS | 条款接受状态 | 用于显示RCS业务接受请求的状态。 取值范围： NOTPROCESSED：未处理TCACCEPTED：TC接受TCDENIED：TC拒绝TCPENDING：TC接受，待激活NOPERMISSION：TC未准许 默认值：无 |

## 使用实例

为“IMSI”取值为“216309434161234”的用户修改RCS-e业务条款接受状态：将“条款接受状态”修改为“NOTPROCESSED”。

```
MOD HRCSSTATUS: IMSI="216309434161234", ACPTTERMSTATUS=NOTPROCESSED;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释                      | 原因分析                                               | 处理建议                                             |
|----------:|:---------------------------|:---------------------------------------------------|:-------------------------------------------------|
| 900003466 | 关联的IMS用户未开户或者和IMPI关联关系不存在。 | 未执行ADD HIMSI与IMSI建立关联关系。未执行ADD HISDN与MSISDN建立关联关系。 | 通过ADD HIMSI与IMSI建立关联关系。通过ADD HISDN与MSISDN建立关联关系。 |
| 900003472 | RCS业务不存在。                  | 未签约RCS业务。                                          | 通过ADD HRCSSERVICE命令签约RCS业务。                      |
