# 设置Diameter业务实体(SET DIAMSELIST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于将UDM对接的Diameter业务实体地址按照支持“业务类型”的不同添加到Diameter业务实体表中，以及对Diameter业务实体表中的记录进行删除。

## 注意事项

- 同一个“HLR序列号”中“业务类型”为“GMLC”时，增加的主机名记录数不能超过100条。
- 同一个“HLR序列号”中“业务类型”为“GMLC\_DS”时，增加的主机名记录数不能超过100条。
- 系统中增加的主机名记录数不能超过1000条。

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
|:------------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号   | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| OPTYPE      | 操作类型     | 用于标识执行该命令所实现的操作类型。 取值范围： ADD：增加一条记录。 DELETE：删除一条已有记录。 DELETEALL：删除所有记录。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                        |
| DIAMSERVICE | 业务类型     | 用于标识GMLC是否支持LCS增强或域选。 取值范围：GMLC：支持LCS增强的GMLC。在LCS（Location Services）业务流程中，当UDM收到支持LCS增强的GMLC发送的RIR（Routing-Info-Request）消息时，即使请求的用户未签约LCS，或消息中携带的GMLC地址和用户签约的LCS模板中的GMLC地址不匹配，如果SET MAPCONF命令的“是否支持对RIR进行特殊处理”参数取值为“TRUE”，则正常返回用户的位置信息，并且跳过R-GMLC访问限制模板权限检查。GMLC_DS：支持域选的GMLC。在LCS业务流程中，UDM在收到GMLC的RIR消息后，通过RIA（Routing-Info-Answer）消息返回用户的位置信息。如果发送RIR消息的GMLC网元通过本命令配置为支持域选且用户注册在EPS域，则HSS在RIR消息处理时先发送IDR消息进行域选，根据域选结果返回用户的位置信息：域选在4G，只返回MME地址，不返回MSC/SGSN地址。域选在2G/3G，只返回MSC和SGSN地址，不返回MME地址。 默认值：无。 |
| HOSTNAME    | 主机名      | 仅当“操作类型”取值为“ADD”或“DELETE”时，该参数有效。 用于标识需要配置是否支持域选的GMLC业务实体的主机名。 取值范围：长度不超过127的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                              |
| SENAME      | GMLC地址名称 | 仅当“操作类型”取值为“ADD”时，该参数有效。用于标识需要配置是否支持域选的GMLC业务实体的地址。 取值范围：长度不超过60的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                          |

## 使用实例

1. 增加一条支持域选的GMLC业务实体，设置“HLR序列号”为“1”，“操作类型”为“ADD”，“业务类型”为“GMLC\_DS”，“主机名”为“gmlc.hostname1”，“GMLC地址名称”为“gmlc\_addr1”：

   ```
   SET DIAMSELIST: HLRSN=1, OPTYPE=ADD, DIAMSERVICE=GMLC_DS, HOSTNAME="gmlc.hostname1", SENAME="gmlc_addr1";
   ```
2. 删除一条支持域选的GMLC业务实体，设置“HLR序列号”为“1”，“操作类型”为“DELETE”，“业务类型”为“GMLC\_DS”，“主机名”为“gmlc.hostname1”：

   ```
   SET DIAMSELIST: HLRSN=1, OPTYPE=DELETE, DIAMSERVICE=GMLC_DS, HOSTNAME="gmlc.hostname1";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释     | 原因分析                                                                                                                             | 处理建议                                                                                                                      |
|:--------|:----------|:---------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------|
| ERR1003 | 无效的参数名称   | 任何一个参数名称输入不正确，都会引起此错误。                                                                                                           | 检查提示的错误参数名称，并输入正确的名称。                                                                                                     |
| ERR1004 | 无效的参数值    | 可能原因为如下之一：参数“HLR序列号”的取值不在1～255范围内。参数“操作类型”和“业务类型”的取值不在给出的枚举值范围之内。参数“主机名”的取值不为1～127位数字组成的字符串。参数“GMLC地址名称”的取值不为1～60位由数字组成的字符串。     | 根据参数说明中的参数取值范围，重新输入相应参数。                                                                                                  |
| ERR1009 | 参数丢失      | 可能原因为如下之一：参数“HLR序列号”或“操作类型”未输入。当“操作类型”取值不为“DELETEALL”时，参数“业务类型”未输入。                                                              | 根据提示缺失的参数，添加相应的参数输入。                                                                                                      |
| ERR1037 | 记录已存在     | 当命令中的“操作类型”参数取值为“ADD”，即进行添加记录的操作时，需要添加的记录已经存在了。                                                                                  | 使用LST DIAMSELIST命令查看对应“业务类型”取值之下，是否已经存在了要添加的“主机名”或“GMLC地址名称”值，如是则无需再重新添加。                                                 |
| ERR3007 | 记录未定义     | 当命令中“操作类型”参数取值为“DELETE”，即进行删除操作时记录不存在，没有预先配置对应的业务实体表。                                                                            | 使用LST DIAMSELIST命令查看对应“业务类型”取值之下，是否存在对应的要删除的“主机名”或“GMLC地址名称”值，如不存在，则根据LST DIAMSELIST命令返回的结果删除相应的实体。                       |
| ERR3047 | 超过最大限制    | 可能原因为如下之一：同一个“HLR序列号”中“业务类型”为“GMLC”时，增加的“主机名”记录数超过100条。同一个“HLR序列号”中“业务类型”为“GMLC_DS”时，增加的“主机名”记录数不能超过100条。系统中增加的“主机名”总记录数超过1000条。 | 根据实际情况，如需增加主机名，处理步骤如下：执行LST DIAMSELIST命令，查询已存在的主机名。执行该命令删除不必要的主机名。执行该命令增加主机名，确保增加的主机名在规定范围之内。                             |
| ERR3097 | HLR序列号未定义 | 参数“HLR序列号”的取值未预先定义，对应序号的HLR不存在。                                                                                                  | 使用LST HLRSN命令查询已定义的HLR序列号，检查需要添加业务实体表的HLR序列号是否存在：是，根据LST HLRSN查询结果中存在的HLR序列号，重新输入“HLR序列号”参数值。否，使用ADD HLRSN命令，添加所需的HLR序列号。 |
