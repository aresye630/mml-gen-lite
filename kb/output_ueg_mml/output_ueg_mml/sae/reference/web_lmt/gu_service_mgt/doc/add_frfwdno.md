# 增加禁止前转号码(ADD FRFWDNO)

## 命令功能

**须知** 

本命令属于高危命令，执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在UDM中增加一条禁止前转号码数据记录。

通常在开局配置本局数据时根据运营商要求在数据库中增加禁止前转号码数据记录。当用户签约前转业务登记前转号码时，在号码规整流程中查询**禁止前转号码表**按照完全匹配方式进行业务处理，如果匹配成功则登记到被禁止的前转号码的操作会失败，系统不允许用户前转到**禁止前转号码表**中的前转号码。禁止前转号码是规整之后的号码，不包含国家码。例如，执行该命令增加“112”为禁止前转号码，则当用户登记前转到“112”的号码时会失败。

## 注意事项

同一个“HLR序列号”中增加的禁止前转号码数据记录数不能超过1000条。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                         |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                 |
| FWDNO  | 禁止前转号码 | 用于标识待增加的禁止前转号码。根据运营商要求，通过该参数使系统禁止某些号码作为用户登记的前转号码，如紧急呼叫号码。 取值范围：1～15位十进制数字组成的字符串，PSTN（Public Switched Telephone Network）号码或E.164格式的编码。 默认值：无。 |

## 使用实例

在“HLR序列号”为“1”的HLR上增加禁止前转号码。其中，“禁止前转号码”为“112”：

```
ADD FRFWDNO: HLRSN=1, FWDNO="112";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                          | 处理建议                                                                                                                                       |
|:--------|:--------|:------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | “HLR序列号”未定义。                  | 根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求。                                                                                                          |
| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”参数不在相应的参数取值范围内。 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                           |
| ERR3006 | 记录已存在   | 本次操作输入的“禁止前转号码”在数据库中已存在。      | 根据实际情况，重新输入参数，确保输入的“禁止前转号码”与系统中已存在的不重复。可执行LST FRFWDNO命令查询系统中已存在的禁止前转号码。                                                                    |
| ERR1111 | 超过最大限制  | 增加的禁止前转号码数据记录数超过1000条。        | 根据实际情况，如需增加禁止前转号码数据记录，处理步骤如下：执行LST FRFWDNO命令，查询已存在禁止前转号码数据记录。执行RMV FRFWDNO命令，删除不必要的禁止前转号码数据记录。执行该命令，增加的禁止前转号码数据记录，确保增加后禁止前转号码数据记录数在规定范围之内。 |
