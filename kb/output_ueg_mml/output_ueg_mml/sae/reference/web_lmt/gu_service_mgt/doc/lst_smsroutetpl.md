# 查询SMS-Route模板(LST SMSROUTETPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来查询用户的SMS-Route模板。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                              |
|:-------|:-------|:--------------------------------------------------|
| HLRSN  | HLR序列号 | 用于标识系统需要按照哪个HLR序列号来查询SMS-Route模板数据。               |
| TPLID  | 模板ID   | 用于标识系统需要按照哪个模板ID来查询SMS-Route模板数据；若不输入，则表示所有的模板ID。 |

## 使用实例

查询SMS-Route模板，“模板ID”为“3”。命令如下：

LST SMSROUTETPL: HLRSN=1, TPLID=3;
