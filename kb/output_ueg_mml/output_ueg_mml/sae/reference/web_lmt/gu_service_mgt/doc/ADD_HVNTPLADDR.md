# 增加拜访网络地址(ADD HVNTPLADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在HSS的业务数据库中向已经存在的拜访网络模板中增加一个拜访网络地址。

拜访网络地址也称漫游地址，操作员可以使用**ADD HVNTPLADDR**增加拜访网络地址到指定的拜访网络模板，以对用户的漫游范围进行控制：

- 当IMS移动用户进入拜访网络地址允许的区域时，将使用用户携带的接入位置信息与签约的拜访网络地址信息进行匹配，此时匹配成功，拜访网络地址信息中的拜访网络地址类型是允许漫游，IMS系统将允许用户注册。
- 当IMS移动用户进入拜访网络地址限制的区域时，将使用用户携带的接入位置信息与签约的拜访网络地址信息进行匹配，此时匹配成功，拜访网络地址信息中的拜访网络地址类型是限制漫游，IMS系统将限制用户注册。
- 当IMS移动用户进入的区域在拜访网络地址信息中不存在时，将使用用户携带的接入位置信息与签约的拜访网络地址信息进行匹配，此时匹配失败，根据拜访网络模板中的缺省漫游限制策略决定是否允许用户注册，PERMISSION表示IMS系统将允许用户注册，RESTRICTION表示IMS系统将限制用户注册。

## 注意事项

- 如果操作员在指定拜访网络模板中增加了一条拜访网络地址，则所有引用该模板的用户都将增加这条拜访网络地址，请操作员在执行该操作之前仔细确认任务的可行性。
- 对于有具体拜访网络地址的用户，如果要放开用户的漫游权限，使用**RMV HVNTPLADDR**命令删除地址放开用户的漫游范围。
- 系统中每个拜访网络模板增加的最大记录数不能超过180条，总记录数不能超过5000条。

## 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                                                                                                                   |
|:--------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN   | HLR序列号   | 用于标识一个HLR序列号。 取值范围：0~255 默认值：无。 说明： 可选参数当该参数不输入时，系统默认初始设置值为0。                                                                                                                          |
| VNTPLID | 拜访网络模板ID | 用于标识一个拜访网络模板索引，系统可以通过该索引找到需要增加拜访网络地址的拜访网络模板。该参数必须先由ADD HVNTPL命令定义，然后才能在此处索引。 说明：必选参数。 配置原则：ADD HVNTPL命令中“拜访网络模板ID”参数取值范围为0~1024，本参数仅支持引用0~254，超过该范围取值，系统上报“900003245：拜访网络模板ID不存在”错误提示。 |
| VN      | 拜访网络地址   | 用于指定在拜访网络模板中增加的拜访网络地址，操作员可以使用LST HVNTPLADDR命令查询指定拜访网络模板内的所有拜访网络地址信息。 取值范围：长度不超过127的字符串 默认值：无。 说明：必选参数。                                                                                 |
| VNTYPE  | 拜访网络地址类型 | 用于指定新增拜访网络地址的类型。 取值范围： PERMISSION(Permission)：表示IMS系统将允许用户注册。RESTRICTION(Restriction)：表示IMS系统将限制用户注册。 默认值：无。 说明：必选参数。                                                                  |

## 使用实例

增加拜访网络地址,“拜访网络模板ID”为“10”，“拜访网络地址”为“china.huawei.com”，“拜访网络地址类型”为“PERMISSION(Permission)”：

```
ADD HVNTPLADDR: VNTPLID=10, VN="china.huawei.com", VNTYPE=PERMISSION;
```
