# 查询IMPU的参考位置信息(LST HNNRLI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在IMS-HSS的业务数据库中查询指定“IMPU”的参考位置信息：

- 若需要查询指定“IMPU”的全部参考位置信息，请输入“IMPU”。
- 若需要查询指定“IMPU”的某条参考位置信息，请输入“IMPU”与“参考位置信息索引”的组合。

## 注意事项

无。

## 参数说明

| 参数标识    | 参数名称     | 参数说明                                                          |
|:--------|:---------|:--------------------------------------------------------------|
| IMPU    | IMPU     | 用于指示系统按照哪个IMPU来查询参考位置信息数据。该参数操作员可以使用LST HSUB操作查询获得。           |
| RLINDEX | 参考位置信息索引 | 用于指示系统需要按照哪个“参考位置信息索引”来查询参考位置信息；若不输入，则表示查询“IMPU”对应的所有的参考位置信息。 |

## 使用实例

1. 查询IMPU的全部参考位置信息，“IMPU”为“sip:impuinfo@huawei.com”：

   ```
   LST HNNRLI: IMPU="sip:impuinfo@huawei.com";
   ```

   ```
   %%LST HNNRLI: IMPU="sip:impuinfo@huawei.com";%%
   RETCODE = 0 操作成功

   RLINDEX          RLI                           RLT              DEFRLI
   3                xian                          2                0
   2                shanghai                      3                0
   1                shenzhen                      0                1

   Total count = 3

   There is together 1 report

   ---    END
   ```
2. 查询IMPU的指定参考位置信息，“IMPU”为“sip:impuinfo@huawei.com”，“参考位置信息索引”为“1”：

   ```
   LST HNNRLI: IMPU="sip:impuinfo@huawei.com", RLINDEX=1;
   ```

   ```
   %%LST HNNRLI: IMPU="sip:impuinfo@huawei.com", RLINDEX=1;%%
   RETCODE = 0 操作成功

   RLINDEX          RLI                           RLT              DEFRLI
   1                shenzhen                      0                1

   Total count = 1

   There is together 1 report

   ---    END
   ```

## 输出结果说明

**ADD HNNRLI**

参数说明。

| 输出项名称   | 输出项解释                                 |
|:--------|:--------------------------------------|
| DEFRLI  | 用于显示默认参考位置信息。 0：非默认参考位置信息。1：默认参考位置信息。 |

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释                                           | 原因分析                           | 处理建议                                                                                              |
|----------:|:------------------------------------------------|:-------------------------------|:--------------------------------------------------------------------------------------------------|
| 900001007 | 无效的参数值                                          | “IMPU”或“参考位置信息索引”参数的取值不符合取值范围。 | 根据实际情况，重新输入“IMPU”或“参考位置信息索引”，确保其取值符合取值范围。                                                         |
| 900003412 | IMPU或referLocIndex在IMPU签约的参考位置信息索引中不存在或表中没有任何记录 | “IMPU”或“参考位置信息索引”参数的取值未定义。     | 操作员通过执行LST HSUB命令先查询已定义的“IMPU”，确保IMPU取值已经定义。在获取已存在“IMPU”后，操作员通过执行该命令先查询已定义的“参考位置信息索引”，确保索引取值已经定义。 |
