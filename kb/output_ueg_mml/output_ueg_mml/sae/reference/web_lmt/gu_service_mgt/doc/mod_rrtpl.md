# 修改RR模板(MOD RRTPL)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使签约该模板的用户数据被同步修改，会影响在网用户业务体验，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改区域漫游RR（Regional Roaming）模板。当运营商或用户的需求变化时，例如增加或减少用户签约的漫游区域等，可以通过该命令修改区域漫游限制模板，提高HLR的灵活性。在该命令中，系统通过以下关键参数的组合来唯一标识一个区域漫游模板：

- HLR序列号
- 模板ID

## 注意事项

- 执行该命令时系统会提示“该操作会修改RR模板数据，是否继续？”的信息。因为当用户进行位置更新或触发其他涉及区域漫游模板的流程时，系统会根据用户签约的区域漫游模板ID下发模板中的数据，修改模板数据会使签约此模板的用户数据被同步修改，会影响在网用户，因此现网执行修改模板操作时需要慎重。
- 该命令不允许进行批操作。
- 系统中同一个RR模板增加的国家码（CC）记录数不能超过20000条，其中每个CC最多包含200个国内目的码（NDC），且所有RR模板最多包含20000个NDC。

## 参数说明

| 参数标识       | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                     |
|:-----------|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN      | HLR序列号     | 标识区域漫游模板数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR中区域漫游模板数据记录的参数进行修改，操作员可以使用LST HLRSN命令查询获得。                                                                                                                                                                                                                     |
| TPLID      | 模板ID       | 标识区域漫游模板数据记录的关键字段之一（其取值不能被修改），用于指定需要对哪个区域漫游模板数据记录的参数进行修改，操作员可以使用LST RRTPL命令查询获得。                                                                                                                                                                                                                         |
| TPLNAME    | 模板名        | 用于标识待修改模板在系统中的名称。 取值范围：1～60位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                       |
| MODIFYTYPE | 操作类型       | 用于标识执行该命令实现的操作类型。 取值范围：ADD_CC：表示增加一条新的国家码对应的允许用户漫游的区域数据，“CC”、“NDC”和“区域码X”必须设置，并且“CC”参数需要与数据库中已存在的不同。 ADD_NDC：表示增加一条新的国内目的地代码对应的允许用户漫游的区域数据，“CC”、“NDC”和“区域码X”必须设置，并且“CC”参数需要与数据库中已存在的相同。 MODIFY_ZC：表示修改区域码，“CC”、“NDC”和“区域码X”必须设置，并且“CC”和“NDC”参数需要与数据库中已存在的相同。 DEL_NDC：表示删除国内目的地代码。 DEL_CC：表示删除国家码。 默认值：无。 |
| CC         | CC         | 仅当本命令中的“修改RR模板类型”参数为其取值范围中任意一个枚举值时该参数有效。用于标识国家码，每个国家码最多可以对应200个国内目的地代码。 取值范围：1～6位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                     |
| NDC        | NDC        | 仅当本命令中的“修改RR模板类型”参数不为“DEL_CC”时该参数有效。用于标识国内目的地代码。即移动业务接入码，它是由本国电信主管部门在本国范围内统一分配的PLMN网络号。例如，目前在中国，中国移动使用的PLMN网络号为134～139、中国联通使用的PLMN网络号为130～133。 取值范围：1～6位十进制数字组成的字符串。 默认值：无。                                                                                                                              |
| ZC1～ZC10   | 区域码1～区域码10 | 仅当本命令中的“修改RR模板类型”参数为“ADD_CC”、“ADD_NDC”或“MODIFY_ZC”时该参数有效。用于标识漫游地区码，最多可设置10个漫游地区码。 取值范围：0000～FFFF（4位十六进制数字组成的字符串），其中FFFF是无效值。 默认值：无。 说明：区域码FFFF为无效值，如将区域码设置为FFFF，表示删除之前设置的区域码，例如在修改模板前设置了10个区域码，若将其中某1个设置为FFFF，修改模板生效后，用户只能签约模板中设置的剩余9个有效区域码。                                                             |

## 使用实例

1. 修改“HLR序列号”为“1”的HLR上的区域漫游模板数据记录，增加一条新的国家码对应的允许用户漫游的区域数据。其中，“模板号”为“1”，“模板名”为“RR-01”，“修改RR模板类型”为“ADD\_CC”，“CC”为“86”，“NDC”为“000001”，“区域码2”为“0001”，“区域码10”为“0010”：

   ```
   MOD RRTPL: HLRSN=1, TPLID=1, TPLNAME="RR-01", MODIFYTYPE=ADD_CC, CC="86", NDC="000001", ZC2="0001", ZC10="0010";
   ```
2. 修改“HLR序列号”为“1”的HLR上的区域漫游模板数据记录，修改某国家码和国内目的地代码对应的区域码。其中，“模板号”为“1”，“修改RR模板类型”为“MODIFY\_ZC”，“CC”为“86”，“NDC”为“000001”，“ZC1”为“0100”：

   ```
   MOD RRTPL: HLRSN=1, TPLID=1, MODIFYTYPE=MODIFY_ZC, CC="86", NDC="000001", ZC1="0100";
   ```
3. 修改“HLR序列号”为“1”的HLR上的区域漫游模板数据记录，删除一个国家的区域漫游限制数据。其中，“模板号”为“1”，“修改RR模板类型”为“DEL\_CC”，“CC”为“86”：

   ```
   MOD RRTPL: HLRSN=1, TPLID=1, MODIFYTYPE=DEL_CC, CC="86";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                                                                                                                                                   | 处理建议                                                                                                                                                                                                                                                                                                                                       |
|:--------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3109 | 国家码未定义  | 当“操作类型”选择“ADD_CC”时，“CC”参数输入错误。                                                                                                                                                                                         | 根据实际情况，重新输入“CC”的取值，确保其取值符合要求。可通过LST INTROFF和LST CNTRCD命令查询，确保使用的“CC”在两个命令查询结果中都有记录。                                                                                                                                                                                                                                                        |
| ERR3003 | 模板未定义   | 可能原因为如下之一：“HLR序列号”和“模板ID”对应的区域限制模板数据记录不存在。 当“修改RR模板类型”参数为“ADD_NDC”时，输入的“CC”在实际模板中不存在。当“修改RR模板类型”参数为“MODIFY_ZC”时，输入的“CC”或“NDC”在实际模板中不存在。当“修改RR模板类型”为“DEL_NDC”时，“CC”或“NDC”在实际模板中不存在。当“修改RR模板类型”为“DEL_CC”时，“CC”在实际模板中不存在。 | 根据实际情况，重新输入参数，确保满足以下几点：使用LST RRTPL命令查询后，重新确认要修改哪个“HLR序列号”和“模板ID”对应的区域限制模板数据记录。 使用LST RRTPL命令查询，确认当“修改RR模板类型”参数为“ADD_NDC”时，输入的“CC”在实际模板中存在。使用LST RRTPL命令查询，当“修改RR模板类型”参数为“MODIFY_ZC”时，输入的“CC”在实际模板中存在，并且存在对应“NDC”。使用LST RRTPL命令查询，当“修改RR模板类型”为“DEL_NDC”时，输入的“CC”在实际模板中存在，并且存在对应“NDC”。使用LST RRTPL命令查询，当“修改RR模板类型”为“DEL_CC”时，输入的“CC”在实际模板中存在。 |
| ERR3004 | 模板已存在   | 当“修改RR模板类型”参数为“ADD_CC”或者“ADD_NDC”时，输入的“CC”或“NDC”在数据库中已存在。                                                                                                                                                              | 使用LST RRTPL命令查询后，确认在模板中已存在的“CC”和“NDC”的取值，重新输入时避免“CC”或“NDC”与数据库中的内容重复。                                                                                                                                                                                                                                                                      |
| ERR3047 | 超过最大限制  | 可能原因为如下之一：同一个“模板ID”增加的“CC”数据记录数超过20000条。同一个“CC”增加的“NDC”数据记录数超过200条。所有RR模板增加的“NDC”总记录数超过20000条。                                                                                                                         | 根据实际情况，如需增加CC或NDC，处理步骤如下：执行LST RRTPL命令，查询已存在的CC或NDC。执行该命令删除不必要的CC或NDC。执行该命令增加CC或NDC，确保增加的CC或NDC在规定范围之内。                                                                                                                                                                                                                                    |
| ERR1004 | 无效的参数值  | 可能原因为如下之一：“NDC”参数的取值不是1～6位十进制数字组成的字符串。“区域码1”～“区域码10”参数的取值不是0～4位十六进制字符串。                                                                                                                                                | 根据实际情况，重新输入“NDC”或“区域码1”～“区域码10”的取值，确保其取值符合要求。                                                                                                                                                                                                                                                                                              |
| ERR1009 | 参数丢失    | 当“修改RR模板类型”参数为“ADD_CC”、“ADD_NDC”或“MODIFY_ZC”时“区域码1”～“区域码10”参数没有输入。                                                                                                                                                     | 根据实际情况，当“修改RR模板类型”参数为“ADD_CC”、“ADD_NDC”或“MODIFY_ZC”时，确保输入“区域码1”～“区域码10”参数至少一个。                                                                                                                                                                                                                                                             |
