# 查询IMPU或PUSI的闭锁状态(LST HBAR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询指定IMPU或PUSI的闭锁标志状态。

## 注意事项

参数IMPU和参数PUSI必须存在且只能存在一个。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                 |
|:-------|:-------|:-------------------------------------------------------------------------------------|
| IMPU   | IMPU   | 用于指定一个需要查询闭锁状态的IMPU，要求输入的IMPU值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无 |
| PUSI   | PUSI   | 用于指定一个需要查询闭锁状态的PUSI，要求输入的PUSI值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无 |

## 使用实例

查询IMPU的闭锁状态。IMPU：sip:impuinfo@huawei.com。

```
LST HBAR: IMPU="sip:impuinfo@huawei.com";
```

## 输出结果说明

| 参数标识   | 参数说明                                      |
|:-------|:------------------------------------------|
| BAR    | 显示IMPU或PUSI的闭锁标志。 0：FALSE，解除闭锁。1：TRUE，闭锁。 |
