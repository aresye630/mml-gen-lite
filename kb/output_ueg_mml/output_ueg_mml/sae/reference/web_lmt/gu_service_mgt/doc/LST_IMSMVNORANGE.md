# 查询IMS用户标识的号段前缀信息(LST IMSMVNORANGE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询IMS用户标识的号段前缀信息。

- 若需要查询IMPI或IMPU的全部号段前缀信息，请输入“号段类型”参数。
- 若需要查询某个“虚拟运营商号码”所管理的号段前缀信息，请同时输入“虚拟运营商号码”和“号段类型”参数。
- 若需要查询某个IMPI或IMPU号段前缀的详细信息，请同时输入“号段前缀”和“号段类型”参数。

## 注意事项

- 只有超级管理员帐户具有本命令的操作权限。
- “号段前缀”和“虚拟运营商号码”参数不能同时出现。

## 参数说明

| 参数标识      | 参数名称    | 参数说明                                                                                                                                                                                                                               |
|:----------|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PREFIX    | 号段前缀    | 用于指示系统需要按照哪个号码前缀来查询号段信息；若不输入则表示所有的号段前缀。                                                                                                                                                                                            |
| MVNO      | 虚拟运营商号码 | 用于指示系统需要按照哪个虚拟运营商号码来查询号段信息；若不输入则表示所有的虚拟运营商号码。                                                                                                                                                                                      |
| RANGETYPE | 号段类型    | 用于指示系统需要按照哪个号段类型来查询号段信息。                                                                                                                                                                                                           |
| SAVEAS    | 保存文件名   | 用于指示系统需要按照指定的“保存文件名”来保存号段到文件。 取值范围：1～20位字符串，可由字母、数字或字符“_”、“.”组成。 默认值：无。 说明：如果指定“保存文件名”，命令执行结果保存在文件内，不在WebUI显示命令执行结果。操作员可以通过WebUI的文件下载功能获取该文件。如果不指定“保存文件名”，且显示的记录超过1000条，则返回错误“超过最大限制”。如果不指定“保存文件名”，且显示的记录不超过1000条，则在WebUI显示所有记录信息。 |

## 使用实例

1. 查询“号段类型”为“IMPI”的全部号段前缀信息：

   ```
   LST IMSMVNORANGE: RANGETYPE=IMPI;
   ```

   ```
   %%LST IMSMVNORANGE: RANGETYPE=IMPI;%%
   RETCODE = 0 SUCCESS0001:操作成功

   MVNO PREFIX
   1    46000
   2    46001
   2    46002
   2    46003

   Total count = 4

   There is together 1 report

   ---    END
   ```
2. 查询值为“1”的“虚拟运营商号码”所管理的IMPI号段前缀信息，将查询结果保存在文件名为“lstimsmvnorange.txt”的文件中：

   ```
   LST IMSMVNORANGE: MVNO=1, RANGETYPE=IMPI, SAVEAS="lstimsmvnorange.txt";
   ```

   ```
   %%LST IMSMVNORANGE: MVNO=1, RANGETYPE=IMPI, SAVEAS="lstimsmvnorange.txt";%%
   RETCODE = 0 SUCCESS0001:操作成功

   There is together 1 report

   ---    END
   ```
3. 查询“号段前缀”为“86134”的IMPU号段前缀信息：

   ```
   LST IMSMVNORANGE: PREFIX="86134", RANGETYPE=IMPU;
   ```

   ```
   %%LST IMSMVNORANGE: PREFIX="86134", RANGETYPE=IMPU;%%
   RETCODE = 0 SUCCESS0001:操作成功

   MVNO PREFIX
   2    86134

   Total count = 1

   There is together 1 report

   ---    END
   ```
