# 查询Diameter业务实体(LST DIAMSELIST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询Diameter业务实体信息。

- 若需要查询出所有配置为支持域选的GMLC信息时，请将“业务类型”参数设为“GMLC\_DS”。
- 若需要查询出所有配置为支持LCS增强的GMLC信息时，请将“业务类型”参数设为“GMLC”。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                       |
|:------------|:-------|:-----------------------------------------------------------|
| HLRSN       | HLR序列号 | 用于指示系统按照哪个HLR序列号来查询业务实体表信息。                                |
| DIAMSERVICE | 业务类型   | 用于指示系统需要查询哪类业务实体。 取值范围：GMLC：普通GMLCGMLC_DS：支持域选的GMLC 默认值：无。 |

## 使用实例

要查询所有配置为支持域选的GMLC信息，“HLR序列号”为“1”，“业务类型”为“GMLC\_DS”：

```
LST DIAMSELIST: HLRSN=1, DIAMSERVICE=GMLC_DS;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数。各参数含义请参见**SET DIAMSELIST**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释     | 原因分析                                                       | 处理建议                                                                                                                                                |
|:--------|:----------|:-----------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1003 | 无效的参数名称   | 任何一个参数名称输入不正确，都会引起此错误。                                     | 检查提示的错误参数名称，并输入正确的名称。                                                                                                                               |
| ERR1004 | 无效的参数值    | 可能原因为如下之一：参数“HLR序列号”的取值不在1～255范围内。参数“业务类型”的取值不在给出的枚举值范围之内。 | 根据参数说明中的参数取值范围，重新输入相应参数。                                                                                                                            |
| ERR3097 | HLR序列号未定义 | 参数“HLR序列号”的取值未预先定义，对应序号的HLR不存在。                            | 使用LST HLRSN命令查询已定义的HLR序列号，检查需要查询业务实体表的HLR序列号是否存在：是，根据LST HLRSN查询结果中存在的HLR序列号，重新输入“HLRSN”参数值。否，使用ADD HLRSN命令添加所需的HLR序列号，并使用SET DIAMSELIST命令添加所需业务实体。 |
