# 增加U-CSI模板(ADD UCSITPL)

## 命令功能

该命令用于为HLR在配置数据库中增加一条U-CSI（USSD CAMEL Subscription Information）模板数据记录，根据运营商CAMEL网络的实际情况进行配置，相关参数由运营商提供。用户通过签约U-CSI模板ID签约U-CSI业务。

U-CSI是USSD（Unstructured Supplementary Service Data） CAMEL签约信息，该数据由HLR保存，不发送给其他网元。U-CSI包含用来为服务的用户调用USSD应用的触发信息。USSD智能应用时，MSC将USSD请求路由到用户归属的HLR，由HLR路由到相应的SCP进行处理。

非结构化补充业务数据USSD即非结构化的补充业务数据，它允许用户通过移动终端输入符合USSD格式的非标准的补充业务操作命令向网络发起特定的业务请求，或者由网络侧向移动终端发起USSD命令以完成某种特定的业务。

USSD业务与短消息业务相比，主要是移动终端与网络能实时交互信息，非常适合于开展股票查询、天气预报、航班信息等增值业务。CAMEL业务与USSD业务相结合可以满足用户多方面的信息查询需求。

## 注意事项

系统中增加的U-CSI模板记录数不能超过5000条，且所有U-CSI模板增加的业务码总记录数不能超过45000条。

## 参数说明

| 参数标识              | 参数名称        | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
|:------------------|:------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN             | HLR序列号      | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| TPLID             | 模板ID        | 用于标识待增加模板在系统中的序号。 取值范围：0～65534 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| TPLNAME           | 模板名         | 用于标识待增加模板在系统中的名称。 取值范围：1～60位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| SCODE             | 业务码         | 用于标识用户在通过移动终端发起USSD操作时所需输入的、gsmSCF（GSM Service Control Function）中指定应用的业务码。 取值范围：1～16个十进制数字组成的字符串。仅当操作员通过SET MAPCONF命令将“是否支持特殊的USSD业务码”参数设为“TRUE”时，业务码可以包含“*”、“#”符号。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| GSMSCFADD         | SCP地址       | 用于标识接入gsmSCF功能实体的地址。 取值范围：1～15位十进制数字组成的字符串。 采用E.164编码方式，编码格式为：CC+NDC+LSP，例如，一个典型的“SCP地址”为：“86-139-00777”。各关键字段的含义是： CC（Country Code）：国家码，即SCP所处国家在国际PSTN编号计划中的国家码，它由ITU-T在全球范围内统一分配，其最大长度为3位。例如，中国的国家码为86、英国的国家码为44等。NDC（National Destination Code）：国内目的码，即移动业务接入码，它是由本国电信主管部门在本国范围内统一分配的PLMN网络号，其最大长度为3位。例如，某运营商使用的PLMN网络号为134～139。LSP（Locally Significant Part）：本地有效部分，它是由某个运营商在本PLMN网络运营范围内统一分配的、用于具体代表某个SCP的号码，其最大长度为9位。 默认值：无。                                                                                                                                                                                                                                  |
| PUSSDOPTION       | PUSSD号码携带选项 | 用于标识HLR在透明传输PUSSD请求消息时的号码携带选项，设置该参数时需与运营商确认使用何种号码携带方式。 取值范围：NONE：PUSSD请求在TCAP层不携带MSISDN和VLR Number，携带目的参考，在MAP层携带MSISDN。ONLY_MSISDN：PUSSD请求在TCAP层携带MSISDN和目的参考，MAP层不携带MSISDN。ONLY_VLRNUM：PUSSD请求在TCAP层携带VLR Number和目的参考，MAP层携带MSISDN。BOTH_MSISDN_VLRNUM：PUSSD请求在TCAP层携带MSISDN、VLR Number和目的参考，MAP层不携带MSISDN。NO_DESTREF：PUSSD请求在TCAP层携带MSISDN，不携带目的参考，MAP层不携带MSISDN。BSAMSISDN：PUSSDv1请求在BSA消息中携带MSISDN号码。DESTREF_MSISDN：PUSSD请求在TCAP层携带目的参考，目的参考携带MSISDN，MAP层不携带MSISDN。DESTREF_MAP_MSISDN：PUSSD请求在TCAP层携带目的参考，目的参考携带MSISDN，MAP层携带MSISDN。 默认值：无。 说明：当HLR收到用户发送的PUSSD请求消息时，处理的优先级是：先检查用户级U-CSI模板的号码携带选项。再检查通过执行ADD USSDDAT命令增加的号码携带选项。最后检查通过执行SET MAPSERV命令配置的全局号码携带选项。 |
| FUNCTION          | USSD类型      | 用于标识USSD数据的转发模式。 取值范围：GSMMODE：GSM方式前转到USSD中心，当USSD中心支持通过IMSI标识用户时，选择此项。对应的“SSN”为“MSC(0x08)”。WAPMODE：WAP方式前转到USSD中心，当USSD中心支持通过MSISDN标识用户时，选择此项。对应的“SSN”为“MSC(0x08)”。GSMSCF：当USSD中心支持U-CSI时，用户的USSD请求被前转到gsmSCF。对应的SCCP子系统号“SSN”为“GSMSCF(0x93)”。MAP：当USSD中心支持通过IMSI标识用户时，用户的USSD请求以MAP方式被前转到USSD中心。对应的SCCP子系统号“SSN”为“MAP(0x05)”。GSMSPECIALMODE：GSMSPECIALMODE方式前转到USSD中心，当USSD中心支持通过IMSI标识用户时，选择此项。对应的“SSN”为“SSN15(0x0F)”。 默认值：GSMSCF。 说明：需要在OM Portal的“UDM MML命令”界面执行ADD SCCPSSN命令配置SCCP子系统号才能转发成功。                                                                                                                                                                  |
| MATCH_RULE        | 业务码匹配原则     | 设置业务码的匹配原则。 MAX_MATCH：最大匹配ALL_MATCH：完全匹配 说明：最大匹配即匹配到与业务码最大相似的地方，如：数据库中有三条记录139、1385、13852，则当需要和数据库中记录匹配的数据为1385213时，就会匹配到13852；如果需要和数据库匹配的数据为13851，那么匹配到的就是1385。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| PUSSDORIGINREFCFG | PUSSD源参考配置  | 用于标识HLR转发PUSSD消息时，TCAP层携带源参考地址的方式。 取值范围：GLOBAL_CFG: PUSSD消息携带的源参考地址通过命令SET MAPCONF中的参数“USSDSENDVLRGT”进行配置。HLR_GT：PUSSD消息携带HLR_GT作为源参考地址。VLR_GT：PUSSD消息携带VLR_GT作为源参考地址。 默认值：GLOBAL_CFG                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| TPLTYPE           | 模板类型        | 用于标识U-CSI模板的模板类型。 取值范围：SUB：用户规则模板，允许被替换。REPLACE：替代规则模板，不允许被替换。 默认值：SUB 说明：SUB类型U-CSI模板可以引用CSI替代模板，并且一个SUB类型U-CSI模板只能引用一个CSI替代模板；CSI替代模板只能引用REPLACE类型的U-CSI模板。当“模板类型”从“SUB”改为“REPLACE”时，如果之前签约了替代模板ID，则替代模板ID会被删除。                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| PROVREPTPL        | 是否提供替代模板    | 用于标识增加/修改或删除替代模板ID。 取值范围：TRUE：增加/修改替代模板ID。FALSE：删除替代模板ID。 默认值：无 说明：该参数只有当参数“模板类型”取值为“SUB”时才显示。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| REPTPLID          | 替代模板ID      | 用于标识CSI替代模板ID号，该参数必须先由SET CSIREPTPL命令定义，然后才能在此处引用。 取值范围： 0～65534 默认值：无 说明：该参数只有当参数“模板类型”取值为“SUB”，且“是否提供替代模板”为“TRUE”时才显示。当用户所在网络（VLR前缀/漫游区域）与模板定义的使用范围一致时，采用CSI替代模板里的参数控制U-CSI业务。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

## 使用实例

在“HLR序列号”为“1”的HLR上增加一条U-CSI模板数据记录。其中，“模板ID”为“3”，“模板名”为“UCSI1”，“业务码”为“13”，“SCP地址”为“8613907551111”：

```
ADD UCSITPL: HLRSN=1, TPLID=3, TPLNAME="UCSI1", SCODE="13", GSMSCFADD="8613907551111";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                          | 处理建议                                                                                                                                                    |
|:--------|:--------|:--------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | “HLR序列号”或“替代模板ID”未定义。                                         | 根据实际情况，重新输入“HLR序列号”或“替代模板ID”的取值，确保其取值符合要求。                                                                                                              |
| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”参数不在相应的参数取值范围内。                                 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                                        |
| ERR3004 | 模板已存在   | 本次操作输入的“模板ID”在数据库中已存在。                                        | 根据实际情况，重新输入参数，确保输入的“模板ID”和系统中已存在的不重复。可执行LST UCSITPL命令查询系统中已存在的U-CSI模板。                                                                                  |
| ERR3047 | 超过最大限制  | 可能原因为如下之一：增加的U-CSI模板记录数超过5000条。所有U-CSI模板增加的“业务码”总记录数超过45000条。 | 根据实际情况，如需增加U-CSI模板，处理步骤如下：执行LST UCSITPL命令，查询已存在的U-CSI模板。执行RMV UCSITPL命令，删除不必要的U-CSI模板。或执行MOD UCSITPL命令，删除不必要的业务码。执行该命令增加U-CSI模板，确保增加的U-CSI模板记录数在规定范围之内。 |
