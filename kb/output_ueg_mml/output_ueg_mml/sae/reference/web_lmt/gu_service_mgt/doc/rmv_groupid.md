# 删除5G虚拟网络组成员 (RMV GROUPID)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除用户的5G虚拟网络组成员签约数据。

- 若需要删除用户所有5G虚拟网络组成员签约数据，请输入用户标识。
- 若需要删除用户某个5G虚拟网络组成员签约数据，请输入用户标识和“内部组ID”，或用户标识和“外部组ID”。

  **说明** 

  用户标识分为以下三类：
  - 单个用户，请输入“IMSI”或“MSISDN”。
  - 多个连续用户，请输入“IMSI”与“用户个数”的组合，或者“MSISDN”与“用户个数”的组合。
  - 多个不连续用户，请输入“IMSI文件名”或“MSISDN文件名”。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                         |
|:------------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 可选必选说明：条件可选参数 参数含义：用于标识需要删除哪个IMSI号码的5G虚拟网络组成员签约数据。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                     |
| ISDN        | MSISDN    | 可选必选说明：条件可选参数 参数含义：用于标识需要删除哪个MSISDN号码的5G虚拟网络组成员签约数据。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                   |
| RECORDCOUNT | 用户个数      | 可选必选说明：条件可选参数 参数含义：用于标识待删除5G虚拟网络组成员签约数据的用户的数目。 取值范围：1～100000 默认值：无。 配置原则： 需要为连续号码的多个用户删除5G虚拟网络组成员签约数据时配置该参数。当只有一个用户时，该参数无需配置。配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行删除5G虚拟网络组成员签约数据。当一次删除5G虚拟网络组成员签约数据的用户个数很多时，对系统性能无影响，但删除5G虚拟网络组成员签约数据的用户个数越多，消耗的时间越长。 |
| IMSIFILE    | IMSI文件名   | 可选必选说明：条件可选参数 参数含义：用于标识IMSI批操作文件。 取值范围：1～16位字母或十进制数字组成的字符串。 默认值：无。 配置原则：IMSI批操作文件包含多个不连续的需要删除的5G虚拟网络组成员签约数据的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“rmvgroupid.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。                                       |
| ISDNFILE    | MSISDN文件名 | 可选必选说明：条件可选参数 参数含义：用于标识MSISDN批操作文件。 取值范围：1～16位字母或十进制数字组成的字符串。 默认值：无。 配置原则：MSISDN批操作文件包含多个不连续的需要删除5G虚拟网络组成员签约数据的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“rmvgroupid.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。                                  |
| INGROUPID   | 内部组ID     | 可选必选说明：可选参数 参数含义：用于标识移动网络内部设备之间通信时互相传递的组ID。可以执行LST GROUPID命令查询获得。 取值范围：10～38个十进制数字、十六进制数字或“-”组成的字符串。 默认值：无。 配置原则： 该参数与“外部组ID”两个参数只能输入其中一个。该参数与“外部组ID”两个参数都不输入表示将该用户从其签约的所有5G虚拟网络组中删除。该参数输入的字母不区分大小写。                                                         |
| EXTGROUPID  | 外部组ID     | 可选必选说明：可选参数 参数含义：用于标识移动网络对外能力开放接口中提供的组ID。可以执行LST GROUPID命令查询获得。 取值范围：3～128个字母、十进制数字、“@”、“.”、“-”或“_”组成的字符串。 默认值：无。 配置原则： 该参数与“内部组ID”两个参数只能输入其中一个。该参数与“内部组ID”两个参数都不输入表示将该用户从其签约的所有5G虚拟网络组中删除。该参数输入的字母不区分大小写。                                                   |

## 使用实例

1. 删除“IMSI”号码为“4600000110609”，“内部组ID”为“1-46001-2D”的5G虚拟网络组成员签约数据：

   ```
   RMV GROUPID: IMSI="4600000110609", INGROUPID="1-46001-2D";
   ```
2. 删除3个连续号码的用户的“外部组ID”为“group1@huawei.com”的5G虚拟网络组成员签约数据，这3个MSISDN号码分别为“86123110601929”、“86123110601930”、“86123110601931”：

   ```
   RMV GROUPID: ISDN="86123110601929", RECORDCOUNT=3, EXTGROUPID="group1@huawei.com";
   ```
3. 删除3个非连续号码的用户的所有5G虚拟网络组成员签约数据，这3个MSISDN号码分别为“86123110601921”、“86123110601923”、“86123110601925”，已保存在“MSISDN文件名”为“rmvgroupid.txt”的文件中：

   ```
   RMV GROUPID: ISDNFILE="rmvgroupid.txt";
   ```
