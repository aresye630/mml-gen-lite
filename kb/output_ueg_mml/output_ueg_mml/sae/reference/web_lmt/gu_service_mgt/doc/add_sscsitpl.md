# 增加SS-CSI模板(ADD SSCSITPL)

- 命令功能
- 注意事项

- 使用实例
- 输出结果说明

## 命令功能

该命令用于为HLR在配置数据库中增加一条SS-CSI（Supplementary Service Invocation Notification CAMEL Subscription Information）模板数据记录，根据运营商CAMEL网络的实际情况进行配置，相关参数由运营商提供。用户通过签约SS-CSI模板ID签约SS-CSI业务。

SS-CSI是MSC处理ECT（Explicit Call Transfer）、CD（Call Deflection）、MPTY（MultiParty Service）业务调用时，或HLR处理CCBS（Completion of Call to Busy Subscriber）业务调用时触发CAMEL业务处理的签约信息。HLR中存储SS-CSI签约数据，在位置更新流程、数据恢复流程或用户SS-CSI签约信息发生变化时将SS-CSI数据下发给VLR。当ECT、CD、MPTY业务发生时，VLR向gsmSCF发送补充业务调用通知。当CCBS补充业务发生时，HLR向gsmSCF发送补充业务调用通知。

## 注意事项

- ECT、CD、MPTY、CCBS四个参数中，至少有一个参数值必须设置为TRUE。
- 同一个“HLR序列号”中增加的SS-CSI模板记录数不能超过5000条。

## 参数说明

| 参数标识           | 参数名称         | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                |
|:---------------|:-------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN          | HLR序列号       | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                                                                                                                                                                                                                                        |
| TPLID          | 模板ID         | 用于标识待增加模板在系统中的序号。 取值范围：0～65534 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                               |
| TPLNAME        | 模板名          | 用于标识待增加模板在系统中的名称。 取值范围：1～60位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                  |
| ECT            | ECT          | 用于标识调用ECT补充业务时，MSC是否向gsmSCF发送补充业务调用通知。 取值范围：TRUE：发送通知FALSE：不发送通知 默认值：无。                                                                                                                                                                                                                                                                                                                                                             |
| CD             | CD           | 用于标识调用CD补充业务时，MSC是否向gsmSCF发送补充业务调用通知。 取值范围：TRUE：发送通知FALSE：不发送通知 默认值：无。                                                                                                                                                                                                                                                                                                                                                              |
| MPTY           | MPTY         | 用于标识调用MPTY补充业务时，MSC是否向gsmSCF发送补充业务调用通知。 取值范围：TRUE：发送通知FALSE：不发送通知 默认值：无。                                                                                                                                                                                                                                                                                                                                                            |
| CCBS           | 遇忙呼叫完成       | 用于标识调用CCBS补充业务时，HLR是否向gsmSCF发送补充业务调用通知。 取值范围：TRUE：发送通知FALSE：不发送通知 默认值：无。                                                                                                                                                                                                                                                                                                                                                            |
| GSMSCFADD      | SCP地址        | 用于标识接入gsmSCF功能实体的地址。 取值范围：1～15位十进制数字组成的字符串。 采用E.164编码方式，编码格式为：CC+NDC+LSP，例如，一个典型的“SCP地址”为：“86-139-00777”。各关键字段的含义是： CC（Country Code）：国家码，即SCP所处国家在国际PSTN编号计划中的国家码，它由ITU-T在全球范围内统一分配，其最大长度为3位。例如，中国的国家码为86、英国的国家码为44等。NDC（National Destination Code）：国内目的码，即移动业务接入码，它是由本国电信主管部门在本国范围内统一分配的PLMN网络号，其最大长度为3位。例如，某运营商使用的PLMN网络号为134～139。LSP（Locally Significant Part）：本地有效部分，它是由某个运营商在本PLMN网络运营范围内统一分配的、用于具体代表某个SCP的号码，其最大长度为9位。 默认值：无。 |
| AVAILABLE_PLMN | SS-CSI模板使用范围 | 用于标识用户在不同的网络中漫游时是否下发SS-CSI数据。 取值范围：HPLMN：用户在HPLMN（Home Public Land Mobile Network）内漫游时，HLR向VLR下发SS-CSI数据，否则不下发。VPLMN：用户在VPLMN（Visited PLMN）内漫游时，HLR向VLR下发SS-CSI数据，否则不下发。ALL_PLMN：用户在所有PLMN内漫游时，HLR均向VLR下发SS-CSI数据。 默认值：无。 说明：执行该命令并且不输入该参数时，系统会设置初始值ALL_PLMN。由于CCBS业务是在HLR触发，下发的SS-CSI数据中不包含CCBS信息。                                                                                                                                 |

## 使用实例

在“HLR序列号”为“1”的HLR上增加一条SS-CSI模板数据记录。其中，“模板ID”为“2”，“模板名称”为“cdsstpl1”，当调用ECT业务、CD业务时发送补充业务调用通知，“SCP地址”为“8613911111”：

```
ADD SSCSITPL: HLRSN=1, TPLID=2, TPLNAME="cdsstpl1", ECT=TRUE, CD=TRUE, GSMSCFADD="8613911111";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                               | 处理建议                                                                                                                                |
|:--------|:--------|:-----------------------------------|:------------------------------------------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | “HLR序列号”未定义。                       | 根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求。                                                                                                   |
| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”参数不在相应的参数取值范围内。      | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                    |
| ERR3004 | 模板已存在   | 本次操作输入的“模板ID”在数据库中已存在。             | 根据实际情况，重新输入参数，确保输入的“模板ID”和系统中已存在的不重复。可执行LST SSCSITPL命令查询系统中已存在的SS-CSI模板。                                                            |
| ERR3047 | 超过最大限制  | 同一个“HLR序列号”中增加的SS-CSI模板记录数超过5000条。 | 根据实际情况，如需增加SS-CSI模板，处理步骤如下：执行LST SSCSITPL命令，查询已存在的SS-CSI模板。执行RMV SSCSITPL命令，删除不必要的SS-CSI模板。执行该命令增加SS-CSI模板，确保增加的SS-CSI模板记录数在规定范围之内。 |
