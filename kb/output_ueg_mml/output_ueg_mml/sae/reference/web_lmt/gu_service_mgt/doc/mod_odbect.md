# 修改ODB-ECT业务(MOD ODBECT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来修改运营商决定的闭锁－闭锁显式呼叫转移业务。

执行此命令后，系统将向VLR下发插入用户数据消息。

## 注意事项

- IMSI、SDN、IMSIFILE和ISDNFILE是条件可选参数，任何一个参数出现即可。
- RECORDCOUNT一定不能与IMSIFILE或SDNFILE同时存在。

## 参数说明

| 参数标识        | 参数名称                            | 参数说明                                                                                                                                                                                                                                                    |
|:------------|:--------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI                            | IMSI号码，E.212格式的编码，为6～15位的十进制数字。                                                                                                                                                                                                                         |
| ISDN        | MSISDN                          | MSISDN号码，E.164格式的编码，为1～15位的十进制数字。                                                                                                                                                                                                                       |
| RECORDCOUNT | 用户个数                            | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。                                                                                                                                                                     |
| IMSIFILE    | IMSI文件名                         | IMSI文件名称，1～16个字母或数字组成。IMSIFILE包含多个不连续的IMSI号码。                                                                                                                                                                                                           |
| ISDNFILE    | MSISDN文件名                       | ISDN文件名称，1～16个字母或数字组成。ISDNFILE包含多个不连续的MSISDN号码。                                                                                                                                                                                                         |
| ODBECT      | ODB-闭锁显式呼叫转移业务                  | 运营商决定的闭锁－闭锁显式呼叫转移业务，闭锁类型如下。 NOBECT：不闭锁显式呼叫转移。 BALLECT：闭锁所有的显式呼叫转移。 BChargeableECT：当用户漫游出归属网络且呼入和呼出业务中的至少有一种是由被服务用户付费，闭锁显式呼叫转移。 BInternationalECT：当用户国际漫游且呼入和国际呼出业务中的至少有一种是由被服务用户付费，闭锁显式呼叫转移。 BInterzonalECT：当用户区间漫游且呼入和区间呼出业务中的至少有一种是由被服务用户付费，闭锁显式呼叫转移。 |
| ODBDECT     | ODBECT-呼入/呼出业务均由被服务用户付费         | 当呼入和呼出业务均由被服务用户付费时，闭锁显式呼叫转移业务。 TRUE：闭锁显式呼叫转移业务FALSE：不闭锁显式呼叫转移业务                                                                                                                                                                                         |
| ODBMECT     | ODBECT-被服务用户在同一MSC/VLR中存在已被转移呼叫 | 当被服务用户在同一MSC/VLR中存在已被转移的呼叫，则闭锁显式呼叫转移业务。 TRUE：闭锁显式呼叫转移业务FALSE：不闭锁显式呼叫转移业务                                                                                                                                                                                |

## 使用实例

运营商为IMSI号码是460000009012345的用户应用ODB-ECT业务，闭锁的类型为BChargeableECT。命令如下：

MOD ODBECT: IMSI="460000009012345", ODBECT=BChargeableECT, ODBDECT=FALSE, ODBMECT=FALSE;
