# 新增或修改APN信息(SET APNLIST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于设置用户APN数据信息。HSS进行业务处理时使用本命令签约的APN，还是用户签约的APN模板中的APN由**SET MAPCONF**的“是否支持替换APN数据”参数控制。

## 注意事项

- 同时满足如下条件时HSS支持通过本命令给用户签约APN，当参数取值为其他值时，执行本命令会报错“ERR3111：系统不支持该特性”。
  - **SET MAPSERV**的“GPRS管理方式”参数取值为“SuppPsEpsSeparateTplManager”。
  - **SET MAPSERV**的“GPRS数据索引化压缩存储”参数取值为“NotSupport”。
  - **SET MAPCONF**的“是否支持替换APN数据”参数取值为“TRUE”。
- “IMSI”、“MSISDN”、“IMSI/MSISDN文件名”、“IMSI文件名”及“MSISDN文件名”五个参数中至少有一个存在。
- “IMSI”、“MSISDN”不能与“IMSI/MSISDN文件名”、“IMSI文件名”、“MSISDN文件名”同时出现。
- “IMSI/MSISDN文件名”、“IMSI文件名”、“MSISDN文件名”三个参数是互斥参数，有且只能有一个参数出现。

## 参数说明

| 参数标识          | 参数名称           | 参数说明                                                                                                                                                                                                                                                                                                                                                     |
|:--------------|:---------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI          | IMSI           | 用于标识用户的“IMSI”号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                           |
| ISDN          | MSISDN         | 用于标识用户的“MSISDN”号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                         |
| RECORDCOUNT   | 用户个数           | 用于标识需要新增、修改或删除APN数据的用户数目。 当需要为连续号码的多个用户新增、修改或删除APN数据时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户的APN数据进行相应操作。 取值范围：1～100000 默认值：无。 该参数使用约束如下： 输入该参数时，“IMSI/MSISDN文件名”、“IMSI文件名”和“MSISDN文件名”不能输入。 “IMSI”和“MSISDN”必须只存在一个。 如果只有一个用户，该参数不必提供。                                                                                                           |
| FILE          | IMSI/MSISDN文件名 | 用于标识待新增、修改或删除APN数据的用户的IMSI/MSISDN批操作文件。 IMSI/MSISDN批操作文件包含多个不连续的用户的IMSI号码和对应的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“imsimsisdn.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSI/MSISDN文件格式。 取值范围：1～35个字母或数字组成的字符串。 默认值：无。                                                                                                                                  |
| IMSIFILE      | IMSI文件名        | 用于标识待新增、修改或删除APN数据的用户的IMSI批操作文件名称。 IMSI批操作文件包含多个不连续的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“imsi.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～35个字母或数字组成的字符串。 默认值：无。                                                                                                                                                                   |
| ISDNFILE      | MSISDN文件名      | 用于标识待新增、修改或删除APN数据的用户的MSISDN批操作文件名称。 MSISDN批操作文件包含多个不连续的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“msisdn.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～35个字母或数字组成的字符串。 默认值：无。                                                                                                                                                           |
| PROV          | 操作类型           | 用于标识执行该命令实现的操作类型。 取值范围： ADDPDNCNTX：增加新PDP/PDN上下文。 MODPDNCNTX：修改用户PDP/PDN上下文。 RMVPDNCNTX：删除用户PDP/PDN上下文。 RMVALLCNTX：删除用户所有PDP/PDN上下文。 默认值：无。 说明：当该参数取值为“ADDPDNCNTX”时，请先执行LST SUB命令查询用户签约的APN模板的PDP/PDN上下文索引值，并通过本命令给用户新增与APN模板中的PDP/PDN上下文索引值相同的APN数据。                                                                                                    |
| PSCNTXIDLIST  | PS域上下文索引值列表    | 仅当“操作类型”为“ADDPDNCNTX”、“MODPDNCNTX”或“RMVPDNCNTX”时该参数有效。用于标识PS域PDP上下文索引值列表。 配置原则：由最多5个上下文索引值以&连接组成且每个索引值需要用""标识，在字符"前需要添加转义字符\（例如：\"1\"&\"2\"），当只有一个上下文索引值时，参数不携带字符""和&。 每个PDP上下文索引值的取值范围为1～50。 PDP上下文索引值的取值不能重复。 PDP上下文索引值必须是系统中PS用户模板签约的PDP上下文索引值。 该参数必须和“PS域接入点名称列表”同时输入，且每个PDP上下文索引值与接入点名称一一对应。 取值范围：1～24位字符的字符串。 默认值：无。 说明：最多给用户签约5个PS域PDP上下文索引值。     |
| PSAPNLIST     | PS域接入点名称列表     | 仅当“操作类型”为“ADDPDNCNTX”或“MODPDNCNTX”时该参数有效。用于标识PS域接入点名称列表。 配置原则：由最多5个接入点名称以&连接组成且每个接入点名称需要用""标识，在字符"前需要添加转义字符\（例如：\"huawei1.com\"&\"huawei2.com\"），当只有一个接入点名称时，参数不携带字符""和&。 每个接入点名称的取值范围为1～63位字符的字符串。 该参数必须和“PS域上下文索引值列表”同时输入，且每个接入点名称与PDP上下文索引值一一对应。 取值范围：1～339位字符的字符串。 默认值：无。                                                                            |
| EPSCNTXIDLIST | EPS域上下文索引值列表   | 仅当“操作类型”为“ADDPDNCNTX”、“MODPDNCNTX”或“RMVPDNCNTX”时该参数有效。用于标识EPS域PDN上下文索引值列表。 配置原则：由最多5个上下文索引值以&连接组成且每个索引值需要用""标识，在字符"前需要添加转义字符\（例如：\"1\"&\"2\"），当只有一个上下文索引值时，参数不携带字符""和&。 每个PDN上下文索引值的取值范围为1～50。 PDN上下文索引值的取值不能重复。 PDN上下文索引值必须是系统中EPS用户模板签约的PDN上下文索引值。 该参数必须和“EPS域接入点名称列表”同时输入，且每个PDN上下文索引值与接入点名称一一对应。 取值范围：1～24位字符的字符串。 默认值：无。 说明：最多给用户签约5个EPS域PDN上下文索引值。 |
| EPSAPNLIST    | EPS域接入点名称列表    | 仅当“操作类型”为“ADDPDNCNTX”或“MODPDNCNTX”时该参数有效。用于标识EPS域接入点名称列表。 配置原则：由最多5个接入点名称以&连接组成且每个接入点名称需要用""标识，在字符"前需要添加转义字符\（例如：\"huawei1.com\"&\"huawei2.com\"），当只有一个接入点名称时，参数不携带字符""和&。 每个接入点名称的取值范围为1～63位字符的字符串。 该参数必须和“EPS域上下文索引值列表”同时输入，且每个接入点名称与PDN上下文索引值一一对应。 取值范围：1～339位字符的字符串。 默认值：无。                                                                          |

## 使用实例

删除“IMSI”为“460000009123451”、“460000009123452”和“460000009123453”的用户的所有PDP/PDN上下文。

```
SET APNLIST: IMSI="460000009123451", RECORDCOUNT=3, PROV=RMVALLCNTX;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。
