# 设置检测条件(SET DETECTCONDITION)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

当系统配置为支持在线检测增强IMEI轨迹记录的异常用户时，该命令用于配置IMEI轨迹变化异常用户筛选条件。

**说明** 

系统支持在线监测增强IMEI轨迹记录异常用户，需要通过**SET MAPCONF**命令将“增强IMEI轨迹记录是否判断位置变化”和“是否支持在线检测增强IMEI轨迹记录的异常用户”参数均设置为“TRUE”。

系统根据配置将指定时间内，位置信息发生多次变化的用户视为可疑用户，并记录该用户信息（包含位置信息）到IMEI变化轨迹异常用户记录结果文件。方便运营商快速识别定位可疑用户，提高客户网络安全能力。

## 注意事项

该命令中所描述的初始设置值，是指操作员通过**LST DETECTCONDITION**命令查询得出的系统在初始化时的预置参数值。

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                      |
|:------------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INTERVAL    | 间隔时长     | 可选必选说明：可选参数 参数含义：用于标识IMEI轨迹变化异常用户记录的间隔时间。 取值范围：1~120，单位：分 系统初始设置值：30 配置原则：无                                                                                                                                                                                                               |
| TIMES       | 异常次数     | 可选必选说明：可选参数 参数含义：用于标识IMEI轨迹变化异常用户记录的出现次数。 取值范围：2~10，单位：次 系统初始设置值：3 配置原则：无。                                                                                                                                                                                                                |
| STARTHOUR   | 定时任务启动时  | 可选必选说明：可选参数。 参数含义：用于标识IMEI轨迹变化异常用户记录任务的启动时刻小时部分。 取值范围：1~5，单位：时 系统初始设置值：1 配置原则：无。                                                                                                                                                                                                          |
| STARTMINUTE | 定时任务启动分  | 可选必选说明：可选参数。 参数含义：用于标识IMEI轨迹变化异常用户记录任务的启动时刻分钟部分。 取值范围：0~59，单位：分 系统初始设置值：0 配置原则：无。                                                                                                                                                                                                         |
| FILEPREFIX  | 结果文件名称前缀 | 可选必选说明：可选参数 参数含义：用于标识IMEI变化轨迹异常用户记录结果文件的文件名前缀。最终结果文件会包含时间戳。如result_20230101。 取值范围：1～50位字符串，可由字母、数字或字符组成，字符不能包含“>”、“/”、“?”、“\”、“:”、“*”、“"”、“<”、“|”、“,”、“;”、“=”和“'”。 系统初始设置值：result。 配置原则：该参数不建议使用中文字符命名，中文字符会导致导出的结果文件名称前缀乱码。该参数不能与IMEI变化轨迹文件的前缀相同，即不能设置为以IMEI_RECODE_开头的字符串，否则会影响导出和老化功能。 |
| STORAGETIME | 结果文件保存时长 | 可选必选说明：可选参数 参数含义：用于标识记录IMEI变化轨迹异常用户记录结果文件的保存时长。 取值范围：1~180，单位：天 系统初始设置值：180 配置原则：无                                                                                                                                                                                                        |

## 使用实例

设置IMEI轨迹变化异常用户筛选条件。参数设置如下：

```
SET DETECTCONDITION: INTERVAL=120, TIMES=3, STARTHOUR=1, STARTMINUTE=0, FILEPREFIX="result", STORAGETIME=180;
```
