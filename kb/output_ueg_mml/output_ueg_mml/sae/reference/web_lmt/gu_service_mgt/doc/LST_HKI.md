# 查询KI(LST HKI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询鉴权数据KI的业务信息，一次只能查询一条鉴权数据KI的业务信息，需要输入唯一标识该数据记录的关键参数IMPI。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                        |
|:-------|:-------|:----------------------------------------------------------------------------|
| IMPI   | IMPI   | 用于指示系统需要按照哪个IMPI来查询KI数据记录；一次只能查询一条KI数据记录，字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无 |

## 使用实例

查询KI。IMPI：impiinfo。

```
LST HKI: IMPI="impiinfo";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义如表1所示。

| 输出项名称    | 参数说明                                                                        |
|:---------|:----------------------------------------------------------------------------|
| K        | 显示KI值。 说明： 如果软参“AUTHENCRYMODEDISP”为1，显示“*”。如果软参“AUTHENCRYMODEDISP”为0，明文显示。  |
| K4SNO    | 显示K4索引号。                                                                    |
| AMFSNO   | 显示AMF索引号。                                                                   |
| OPSNO    | 显示OP索引号。                                                                    |
| OPCK4SNO | 显示OPC K4索引号。                                                                |
| OPC      | 显示OPC值。 说明： 如果软参“AUTHENCRYMODEDISP”为1，显示“*”。如果软参“AUTHENCRYMODEDISP”为0，明文显示。 |
| K2SNO    | 显示K2索引号。                                                                    |
| OPCK2SNO | 显示OPC K2索引号。                                                                |
