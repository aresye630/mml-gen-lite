# 修改CARP业务(MOD CARP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来修改用户的CS域分配/保留优先级数据。

执行此命令后，如果是给用户签约该业务，则会下发插入用户数据消息；如果是给用户去签约该业务，则会下发位置取消消息。

## 注意事项

- IMSI、ISDN、IMSIFILE、ISDNFILE是条件可选参数，有且只能有一个参数出现。
- 如果“是否提供CARP业务”取值为“TRUE”，则表示提供CARP业务，执行**MOD CARP**命令时“CS域的分配/保留优先级”参数必须设置；“是否提供CARP业务”取值为 “FALSE”，则表示撤销CARP业务，此时不能携带“CS域的分配/保留优先级”参数。

## 参数说明

| 参数标识        | 参数名称         | 参数说明                                                                                |
|:------------|:-------------|:------------------------------------------------------------------------------------|
| IMSI        | IMSI         | IMSI号码，E.212格式的编码，为6～15位的十进制数字。                                                     |
| ISDN        | MSISDN       | MSISDN号码，E.164格式的编码，为1～15位的十进制数字。                                                   |
| RECORDCOUNT | 用户个数         | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。 |
| IMSIFILE    | IMSI文件名      | IMSI文件名称，IMSIFILE包含多个不连续的IMSI号码，每个IMSI号码占一行，16个以内的字母或数字组成的字符串。                      |
| ISDNFILE    | MSISDN文件名    | MSISDN文件名称，ISDNFILE包含多个不连续的MSISDN号码，每个MSISDN号码占一行。16个以内的字母或数字组成的字符串。                |
| PROV        | 是否提供CARP业务   | 提供还是撤销CARP业务。 TRUE(1)：提供。FALSE(0)：撤销。                                               |
| CARP        | CS域的分配/保留优先级 | 仅当本命令中的“是否提供CARP业务”参数为“TRUE”时该参数有效。CS域的分配/保留优先级，值域1～255。                            |

## 使用实例

**例1**

运营商为IMSI号码是460000009123456的用户提供CARP业务，CS允许/限制优先级为3。

MOD CARP: IMSI="460000009123456", PROV=TRUE, CARP=3;

**例 2:**

为IMSI号码是460456789012345的用户撤销CARP业务。命令如下：

MOD CARP: IMSI="460456789012345", PROV=FALSE;
