# 修改割接策略配置(MOD MIGPOLICY)

- 命令功能

## 命令功能

该命令用于为用户系统，撤销或修改割接策略信息。用户通过该命令配置的“割接策略ID”与**割接策略模板**关联，UDM根据用户消息中携带的用户标识及用户签约的割接策略判断是否对用户的MAP消息转发到待割接设备进行处理。

- 当系统对现网用户进行割接操作时，用户签约的割接策略中“是否转发MAP消息”为“TRUE”时，UDM转发用户的MAP消息到对应的待割接设备处理。
- 当系统对现网用户进行割接操作时，用户签约的割接策略中“是否转发MAP消息”为“FALSE”时，用户的MAP消息保留在本地处理。
- 当系统对现网用户进行割接操作时，用户签约的割接策略中“是否转发EPS DIAMETER消息”为“TRUE”时，UDM转发用户的EPS DIAMETER消息到对应的待割接设备处理。
- 当系统对现网用户进行割接操作时，用户签约的割接策略中“是否转发EPS DIAMETER消息”为“FALSE”时，用户的EPS DIAMETER消息保留在本地处理。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”只能与“IMSI”或“MSISDN”同时配置，表示设置缺省多用户服务的批处理命令。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识         | 参数名称      | 参数说明                                                                                                                                                                                                                     |
|:-------------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI         | IMSI      | 用于标识配置割接策略的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                      |
| ISDN         | MSISDN    | 用于标识配置割接策略的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                    |
| RECORDCOUNT  | 用户个数      | 用于标识配置割接策略的用户数目。 当需要为连续号码的多个用户修改割接策略数据时配置该参数。配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户修改割接策略数据。 取值范围：1～100000 默认值：无。  说明： 该参数是对连续号码的多个用户修改割接策略数据，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响。设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE     | IMSI文件名   | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要修改割接策略数据的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modeps.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或十进制数字组成的字符串。 默认值：无。                                       |
| ISDNFILE     | MSISDN文件名 | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要修改割接策略数据的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modeps.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或十进制数字组成的字符串。 默认值：无。                                 |
| PROV         | 是否提供割接策略  | 用于标识执行该命令是提供/修改还是撤销割接策略。 取值范围：TRUE：提供/修改割接策略。FALSE：撤销割接策略。 默认值：无。                                                                                                                                                        |
| MIG_POLICYID | 割接策略ID    | 仅当本命令中的“是否提供割接策略”参数为“TRUE”时该参数有效。用于标识配置割接策略ID。该参数必须先由ADD MIGPOLICYCFG命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。                                                                                                                 |

## 使用实例

当UDM割接现网用户时，配置UDM的割接策略，需要进行如下配置。以用户标识为IMSI为例。

1. 执行**ADD MIGPOLICYCFG**命令增加割接策略模板，该模板“割接策略ID”为“0”。其中“HLR序列号”为“1”、“路由类型”为“IMSI\_TYPE”、“是否转发MAP消息”为 “TRUE”、“HLR号码”为“1”。

   ```
   ADD MIGPOLICYCFG: HLRSN=1, MIG_POLICYID=0, ROUTETYPE=IMSI_TYPE, WHETHER_FORWARD_MAP=TRUE, HLRNO="1";
   ```
2. 执行本命令，增加一条割接策略记录。“IMSI”为“460000009123456”。

   ```
   MOD MIGPOLICY: IMSI="460000009123456", RECORDCOUNT=1, PROV=TRUE, MIG_POLICYID=0;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释      | 原因分析                                                                                             | 处理建议                                                                                                                    |
|:--------|:-----------|:-------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值     | 原因为如下之一：参数“IMSI”的取值不是6～15位十进制数字组成的字符串。参数“MSISDN”的取值不是1～15位十进制数字组成的字符串。                           | 根据实际情况，重新输入“IMSI”或“MSISDN”的取值，确保其取值符合要求。                                                                                |
| ERR1005 | 文件未找到      | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                 | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                      |
| ERR1009 | 参数丢失       | “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数一个都没有输入。                                                | 根据实际情况，重新输入参数，并满足“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                             |
| ERR1010 | 参数冲突       | 原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR1025 | 批操作文件中格式非法 | 参数“IMSI文件名”或“MSISDN文件名”对应的批操作文件格式不正确。                                                            | 请根据IMSIFILE文件格式和ISDNFILE文件格式，重新确定对应的批操作文件格式。                                                                            |
| ERR3007 | 记录不存在      | 用户的IMSI号码或MSISDN号码输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户。                                           | 核实用户的IMSI号码或MSISDN号码，如果确定输入无误，证明实际输入的参数“IMSI”或“MSISDN”对应的用户未开户，请先通过ADD SUB命令给用户开户。                                      |
