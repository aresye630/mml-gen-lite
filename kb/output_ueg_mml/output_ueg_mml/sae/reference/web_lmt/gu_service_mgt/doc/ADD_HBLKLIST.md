# 增加记录空口日志的透明数据黑名单(ADD HBLKLIST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在空口日志的透明数据黑名单中增加一条记录，若一次PUR消息中所携带的所有透明数据对应在“服务标识”都在透明数据黑名单中有记录，则进行更新透明数据操作时不记录空口日志。

## 注意事项

无。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                       |
|:----------|:-------|:---------------------------------------------------------------------------|
| SERVICEID | 服务标识   | 用于标识需要增加的记录空口日志的透明数据黑名单的IMPU或PUSI的服务标识。 取值范围：长度不超过127的字符串。 默认值：无。 说明：必选参数。 |

## 使用实例

增加一条空口日志中的透明数据黑名单的记录，“服务标识”为“TAS-UPDATE-DATA”：

```
ADD HBLKLIST: SERVICEID="TAS-UPDATE-DATA";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码       | 错误码解释   | 原因分析                            | 处理建议                                                                                         |
|:----------|:--------|:--------------------------------|:---------------------------------------------------------------------------------------------|
| 900001007 | 无效的参数值  | 输入的参数取值不符合要求。                   | 根据实际情况，重新输入参数，并确保各参数取值都符合要求。                                                                 |
| ERR1037   | 记录已存在   | 本次操作输入的“服务标识”在空口日志的透明数据黑名单中已存在。 | 根据实际情况，重新输入参数，确保输入的“服务标识”与系统中已存在的不重复。可执行LST HBLKLIST命令查询系统中已存在的透明数据黑名单记录。                    |
| ERR3047   | 超过最大限制  | 为空口日志中增加的透明数据黑名单记录超过了64条。       | 根据实际情况，如需增加透明数据黑名单记录，处理步骤如下： 执行LST HBLKLIST命令，查询系统中已存在的透明数据黑名单记录。执行RMV HBLKLIST命令删除不必要的数据记录。 |
