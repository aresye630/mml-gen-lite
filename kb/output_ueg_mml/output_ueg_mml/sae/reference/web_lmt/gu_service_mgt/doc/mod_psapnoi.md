# 修改PS域UE级别的APN运营商标识符(MOD PSAPNOI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改用户PS域UE级别的APN运营商标识符。

- 对于在网用户执行该命令后，如果是给用户签约运营商标识符数据，则UDM会向SGSN下发运营商标识符数据并且更新数据库中的数据；如果是给用户去签约运营商标识符数据，则UDM会向SGSN下发删除运营商标识符数据并且更新数据库中的数据。
- 对于不在网用户执行该命令后，则仅会更新用户在数据库中的数据。当用户进行位置更新时，如果用户签约了运营商标识符数据，UDM将用户的运营商标识符数据下发给SGSN。

**说明** 

上面所述UDM向SGSN下发用户的运营商标识符的前提是要配置支持下发APNOI的NCC模板（即执行命令**ADD NCCTPL**，参数“APN运营商标识符下发受限标志”选择“SR”）。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”及“MSISDN文件名”是条件可选参数，有且只能有一个参数出现。
- “RECORDCOUNT”参数不能与“IMSIFILE”或“ISDNFILE”参数同时存在。

## 参数说明

| 参数标识         | 参数名称                  | 参数说明                                                                                                                                                                                                      |
|:-------------|:----------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI         | IMSI                  | 用于标识系统按照哪个IMSI号码修改PS域UE级别的APN运营商标识符。 取值范围：6～15位的十进制数字组成的字符串。 默认值：无。                                                                                                                                       |
| ISDN         | MSISDN                | 用于标识系统按照哪个MSISDN号码修改PS域UE级别的APN运营商标识符。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                      |
| RECORDCOUNT  | 用户个数                  | 用于标识系统需要修改PS域UE级别的APN运营商标识符的用户个数。 当需要修改连续号码的APN运营商标识符时配置该参数，选择后，系统将会从已指定的IMSI号码或MSISDN号码开始，修改连续多个号码的APN运营商标识符。 取值范围：1～100000 默认值：无。                                                                       |
| IMSIFILE     | IMSI文件名               | 用于标识系统按照哪个IMSI文件名修改PS域UE级别的APN运营商标识符。 IMSI批操作文件包含多个不连续的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modpsapnoi.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16位由字母或十进制数字组成的字符串。 默认值：无。       |
| ISDNFILE     | MSISDN文件名             | 用于标识系统按照哪个MSISDN文件名修改PS域UE级别的APN运营商标识符。 MSISDN批操作文件包含多个不连续的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modpsapnoi.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16位由字母或十进制数字组成的字符串。 默认值：无。 |
| PROV         | 是否提供PS域UE级别的APN运营商标识符 | 用于标识系统是否提供PS域UE级别的APN运营商标识符。 取值范围： TRUE：提供APN运营商标识符。FALSE：不提供APN运营商标识符。 默认值：无。                                                                                                                            |
| PSAPNOITPLID | PS域UE级别的APN运营商标识符模板ID | 仅当本命令中的“是否提供PS域UE级别的APN运营商标识符”参数为“TRUE”时该参数有效。用于标识PS域UE级别的APN运营商标识符模板ID。该参数必须先由ADD APNOITPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。                                                                            |

## 使用实例

1. 提供“IMSI”号码为“123456789”的用户的PS域UE级别的APN运营商标识符，“PS域UE级别的APN运营商标识符模板ID”为“1”：

   ```
   MOD PSAPNOI: IMSI="123456789", PROV=TRUE, PSAPNOITPLID=1;
   ```
2. 不提供“IMSI”号码为“123456789”的用户的PS域UE级别的APN运营商标识符：

   ```
   MOD PSAPNOI: IMSI="123456789", PROV=FALSE;
   ```
