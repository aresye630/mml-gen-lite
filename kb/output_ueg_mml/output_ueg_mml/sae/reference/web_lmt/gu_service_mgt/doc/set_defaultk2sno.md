# 设置默认K2(SET DEFAULTK2SNO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于设置默认K2密钥的索引数据，可以设置2G/3G/4G/IMS网络的默认K2。

当**SET MAPCONF**命令中的“是否启用随机密钥”参数为“TRUE”时需要执行该命令设置默认K2。默认K2数据配置后，在2G/3G/4G网络执行KI配置命令，或在IMS网络执行KI/OPC/HA1/PWD相关命令时不需要携带额外的参数，系统自动判断有默认K2数据，自动在配置KI/OPC/HA1/PWD相关数据时，对KI/OPC/HA1/PWD等数据进行存储加密，解密时需要在K2存在时对KI/OPC/HA1/PWD等数据通过K2进行解密。

**说明** 

无论**SET MAPCONF**命令中的“是否启用随机密钥”参数如何设置，都可通过执行该命令设置默认GK2记录。

## 注意事项

- 当“类型”参数选择为“K2”时，执行**ADD K2**命令时“K2密钥输入方式”不允许为“Ciphertxt”。
- 混合组网场景下，系统不支持使用该命令配置默认全局存储密钥。

## 参数说明

| 参数标识   | 参数名称       | 参数说明                                                                                                                                                                                                                                                                                                                                                                      |
|:-------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TYPE   | 类型         | 用于标识默认K2的类型。 取值范围： K2：用于设置2G/3G/4G用户的指定HLR序列号下的默认存储加密的K2索引。HK2：用于设置IMS用户的默认存储加密的K2索引。GK2：用于设置全局存储密钥的K2索引。 默认值：无。                                                                                                                                                                                                                                                          |
| HLRSN  | HLR序列号     | 仅当本命令中的“类型”参数选择为“K2”时该参数有效。用于标识HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1～255。 默认值：无。                                                                                                                                                                                                                                                                                  |
| K2SNO  | 缺省存储加密密钥索引 | 用于标识缺省存储加密密钥K2的索引。设置前需要确保K2数据已经添加，该K2数据为用于加密存储的密钥数据。 当“类型”参数选择为“K2”时，该参数必须先由ADD K2命令定义“K2序列号”参数，然后才能在此处引用。当“类型”参数选择为“HK2”时，该参数必须先由ADD HK2命令定义“K2序列号”参数，然后才能在此处引用。当“类型”参数选择为“GK2”时，该参数必须先由SET GK2命令定义“GK2序列号”参数，然后才能在此处引用。当该参数取值为0，则表示不再配置全局存储密钥。当该参数取值为非0，表示签约全局存储密钥。 取值范围：0～254。0表示系统无默认K2数据。 默认值：0 说明：混合组网场景下，当“类型”参数选择为“GK2”时，该参数仅支持设置为0，设置为非0，系统报错“ERR3111：系统不支持该特性”。 |

## 使用实例

1. 设置默认K2，“类型”为“K2”，“HLRSN序列号”为“1”，“缺省存储加密密钥索引”为“100”。

   ```
   SET DEFAULTK2SNO: TYPE=K2, HLRSN=1, K2SNO=100;
   ```
2. 设置默认HK2，“类型”为“HK2”，“缺省存储加密密钥索引”为“100”。

   ```
   SET DEFAULTK2SNO: TYPE=HK2, K2SNO=100;
   ```
