# 根据模板信息新增PSI用户数据(ADD HTPLPSI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中，利用PSI的相关的能力集模板，计费地址模板，ServiceProfile模板和PUSI模板，增加一个PSI用户。

该命令的参数索引关系如图1所示。

**图1** 命令的参数索引关系图

## 注意事项

当通过**SET HSYSTEMPARA**命令设置“USINGHLRSNFORIMS（是否启用IMS-HSS的分权分域功能）”软参为“TRUE(TRUE)”时，执行该命令时会返回错误。

## 参数说明

| 参数标识       | 参数名称               | 参数说明                                                                                                                                                                                                       |
|:-----------|:-------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PISI       | PISI               | 用于新增一个PISI用户，输入的PISI必须符合NAI格式。 取值范围： 长度不超过127的字符串 缺省值： 无                                                                                                                                                   |
| PUSI       | PUSI               | 用于指定一个需要根据模板信息新增PSI用户的PUSI。要求输入的PUSI值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无                                                                                                                |
| PUSITYPE   | PUSI的类型            | 用于标识新增PUSI的类型，当取值为DPUSI，表示新增的PUSI为非通配型；当取值为WPUSI，表示新增的PUSI为通配型。当PUSI为通配型时，PUSI的格式必须符合@符之前是“!.*!”，例如sip:chatlist_!.*!@huawei.com。 取值范围： DPUSI(DPUSI)WPUSI(WPUSI) 缺省值： 无 说明： 系统允许的通配IMPU和通配PUSI数量最大为120000个。 |
| CAPTPLID   | 能力集模板ID            | 用于唯一标识一个能力集模板，通过ADD HCAPTPL定义，然后才能在此处索引。 取值范围：0～254 默认值：0 配置原则：ADD HCAPTPL命令中“能力集模板ID”参数取值范围为0~1024，本参数仅支持引用0~254，超过该范围取值，系统上报“900003239：能力集模板ID不存在”错误提示。                                                  |
| CHARGTPLID | 计费地址模板ID           | 用于唯一标识一个计费地址模板，通过ADD HCHGTPL定义，然后才能在此处索引。 取值范围：0～254 默认值：0 配置原则：ADD HCHGTPL命令中“计费地址模板ID”参数取值范围为0~1024，本参数仅支持引用0~254，超过该范围取值，系统上报“900003243：计费地址模板ID不存在”错误提示。                                               |
| SPTPLID    | ServiceProfile模板ID | 用于唯一标识一个Service Profile模板，通过ADD HSPTPL定义，然后才能在此处索引。 取值范围：0～254 默认值：0 配置原则：ADD HSPTPL命令中“Service Profile模板ID”参数取值范围为0~1024，本参数仅支持引用0~254，超过该范围取值，系统上报“900003240：SP模板ID不存在”错误提示。                             |
| PUSITPLID  | PUSI基本信息模板ID       | 用于唯一标识一个PUSI模板，通过ADD HPUSITPL定义，然后才能在此处索引。 取值范围：0～254 默认值：0                                                                                                                                                |
| SYSNO      | 系统序列号              | 用于标识一个PSI用户属于哪个虚拟HSS。通过ADD HLRSN定义，然后才能在此处索引。 取值范围：0～255 缺省值：0 说明：可选参数。                                                                                                                                    |

## 使用实例

根据模板信息新增PSI用户数据。PISI：pisiinfo，PUSI：sip:pusiinfo@huawei.com，PUSI的类型：DPUSI，能力集模板ID：1，计费地址模板ID：1。

```
ADD HTPLPSI: PISI="pisiinfo", PUSI="sip:pusiinfo@huawei.com", PUSITYPE=DPUSI, CAPTPLID=1, CHARGTPLID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释         | 原因分析                                                                       | 处理建议                                                                   |
|----------:|:--------------|:---------------------------------------------------------------------------|:-----------------------------------------------------------------------|
| 900003524 | 分权分域模式下不支持此命令 | SET HSYSTEMPARA命令的“USINGHLRSNFORIMS（是否启用IMS-HSS的分权分域功能）”软参设置为“TRUE(TRUE)”。 | 无需处理。                                                                  |
| 900003239 | 能力集模板ID不存在    | “能力集模板ID”输入错误，实际输入的参数“能力集模板ID”未定义。                                         | 如果输入的“能力集模板ID”确定正确，说明实际输入的参数“能力集模板ID”未定义，请先通过ADD HCAPTPL命令定义“能力集模板ID”。 |
| 900003240 | SP模板ID不存在     | 输入的Service Profile模板ID在系统中未定义。                                             | 根据实际情况，重新输入Service Profile模板ID，确保输入的Service Profile模板ID已定义。            |
| 900003243 | 计费地址模板ID不存在   | “计费模板ID”参数输入错误，实际输入的“计费模板ID”参数未定义。                                         | 根据实际情况，重新输入参数，确保“计费模板ID”参数已存在。“计费模板ID”参数可以通过ADD HCHGTPL命令增加。           |
