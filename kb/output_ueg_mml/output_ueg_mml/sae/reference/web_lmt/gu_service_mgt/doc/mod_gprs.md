# 修改GPRS业务(MOD GPRS)

- 命令功能

- 输出结果说明

## 命令功能

本操作提供了不需要事先设置GPRS模板，直接提供/修改/删除GPRS业务的操作方法。

执行此命令后，如果是给用户签约该业务，则会下发插入用户数据消息；如果是给用户去签约该业务，则会下发删除用户数据消息。

## 注意事项

- IMSI、ISDN、IMSIFILE、ISDNFILE是条件可选参数，有且只能有一个参数出现。
- 如果PROV=TRUE，则该命令用于提供/修改指定的PDP数据；如果PROV=FALSE，则该命令用于删除指定的PDP数据。
- 如果PROV=TRUE并且已经签约了CNTX业务，则该命令用于修改PDP数据。如果可选参数没有指定值，则系统将采用原值替代。
- 如果PROV=TRUE并且没有签约CNTX业务，则该命令用于增加新的PDP数据。
- 如果PROV=FALSE并且已经签约CNTX业务，则该命令用于删除指定的PDP数据，如果PDP数据已经被删除，则GPRS业务也会被删除。
- 如果PROV=FALSE并且没有签约CNTX业务，系统将返回错误。
- RECORDCOUNT一定不能与IMSIFILE或ISDNFILE同时存在。
- 新签约的GPRS PDP上下文和已经签约PDP上下文中PDPTYPE、ADDIND、APN三个参数不能同时一样。
- ADDIND为DYNAMIC，PDPADD参数不允许存在。ADDIND为STATIC，PDPADD参数必需存在。
- 如果PROV=TRUE并且CNTXID在用户数据中不存在，CNTXID、PDPTYPE、RELCLS、DELAYCLS、PRECLS、PEAKTHR、MEANTHR、APN参数为必选参数。
- PDP上下文中MAXGBRDWL参数值不能大于MAXBRDWL参数。
- PDP上下文中MAXGBRUPL参数不能大于MAXBRUPL参数。
- PDP上下文中MAXEXTGBRDWL参数不能大于MAXEXTBRDWL参数。
- PDP上下文中如果MAXEXTGBRDWL参数存在并且不为NOExtend时，MAXGBRDWL参数不能存在。
- PDP上下文中如果MAXEXTBRDWL参数存在并且不为NOExtend时，MAXBRDWL参数不能存在。
- 所有参数都为条件可选参数。
- 该命令每次只能提供一条PDP上下文相关的数据，支持修改/删除多条PDP上下文相关的数据。
- 该命令支持根据“接入点名称”参数来删除或修改PDP上下文相关的数据。

  **说明** 

  PDP上下文：PDP Context，是PDP地址在MS和SGSN中存储的信息集。
- 当用户已签约静态IPv4地址且“PDP类型”参数为“IPV4”，或已签约静态IPv6地址且“PDP类型”参数为“IPV6”，再携带以下参数执行该命令进行双栈改造会导致用户已签约的静态IPv4或IPv6地址被删除。
  - “PDP类型”参数为“IPV4IPV6”。
  - “PDP地址标识”和“PDP地址2标识”为“DYNAMIC”或不输入这两个参数。
  - 不输入“PDP地址”和“PDP地址2”参数。

## 使用实例

修改GPRS业务，“IMSI”为“460000009123456”，“是否提供CNTXID数据”为“TRUE”，“PDP上下文索引值”为“3”，“PDP类型”为“IPV4”，“PDP地址”为“10.76.133.191”，“PDP地址标识”为“STATIC”，“可靠性级别”为“ACKALLPRODT”，“延迟级别”为“DELAY1”，“优先级别”为“HIGH”，“峰值吞吐量”为“16000 OCT”，“平均吞吐量”为“5000 OCT”，接入点为“APN”，“计费特性”为“1234”。

```
MOD GPRS: IMSI="460000009123456", PROV=TRUE, CNTXID=3, PDPTYPE=IPV4, ADDIND=STATIC, PDPADD="10.76.133.191", RELCLS=ACKALLPRODT, DELAYCLS=DELAY1, PRECLS=HIGH, PEAKTHR=16000 OCT, MEANTHR=5000 OCT, APN="APN", VPLMN=TRUE, STDCHARGE="1234";
```
