# 设置缺省EPS QoS模板替代配置(SET DEFREPEPSQOSID)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会导致HSS下发错误的EPS QoS数据，因此执行本命令前，需要和运营商的EPS QoS模板替代配置表进行仔细核对，并详细阅读本命令的联机帮助和注意事项，确保添加的EPS QoS模板替代配置完全正确。如运营商无法给出具体的配置表或有其他疑问，请与华为技术支持联系制定操作的实施方案、测试方案和回退方案后才可以实施。

该命令用于在UDM中设置缺省的EPS QoS模板替代配置记录，将一个EPS QoS模板默认替换为另一个EPS QoS模板进行下发。增加了一条缺省替代配置记录之后，如果需要下发EPS QoS数据，UDM将根据缺省的EPS QoS模板替代配置，使用替代模板代替用户签约的EPS QoS模板进行下发。

如果同一EPS QoS模板通过**ADD REPEPSQOSID**设置了指定Diameter节点下的替代配置，且用户漫游在相应的MME/S4-SGSN/3GPP AAA Server下时，则缺省EPS QoS模板替代配置将不生效，UDM使用**ADD REPEPSQOSID**命令签约的替代配置进行下发。

在该命令中，系统通过以下关键参数的组合来唯一标识一条缺省EPS QoS模板替代配置记录，实现对替代配置的增加和删除：

- HLR序列号
- 用户签约的EPS QoS模板ID

## 注意事项

- 当设置了EPS QoS模板替代配置，系统会根据用户签约的EPS QoS模板找到替换的模板配置并下发数据，用户原来签约的EPS QoS模板将不会生效，会影响大量在网用户，因此现网执行该操作时需要慎重。执行该命令前需确定待添加的EPS QoS替代配置和运营商的EPS QoS模板替代配置表完全一致，并确保使用原EPS QoS模板的MME/S4-SGSN/3GPP AAA Server上支持替换后的EPS QoS模板对应的QoS数据。
- 参数“用户签约的EPS QoS模板ID”和“替代的EPS QoS模板ID”的取值不能相同。
- 该命令不允许进行批操作。
- 替换后和替换前的EPS QoS模板中，“QoS分类ID”（QCI）取值对应的Resource Type需要保持一致。GBR类型的QCI替换后必须仍为GBR类型，Non-GBR类型的QCI替换后必须仍为Non-GBR类型。QCI取值和Resource Type具体的对应关系，请参见协议3GPP TS 23.203中的相应内容。

## 参数说明

| 参数标识        | 参数名称             | 参数说明                                                                                                                                                                         |
|:------------|:-----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号           | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                 |
| OPTYPE      | 操作类型             | 用于标识缺省EPS QoS模板替代配置的操作类型。 取值范围：ADD：增加一条记录。DELETE：删除一条已有记录。DELETEALL：删除所有记录。 默认值：无。                                                                                           |
| USREPSQOSID | 用户签约的EPS QoS模板ID | 仅当参数“操作类型”为“ADD”或“DELETE”时该参数有效，且为必选。用于标识一个待设置替换关系的EPS QoS模板ID。当用户签约了该ID对应的EPS QoS模板时，将使用“替代的EPS QoS模板ID”设置的替换模板进行下发。该参数必须先由ADD EPSQOSTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。 |
| REPEPSQOSID | 替代的EPS QoS模板ID   | 仅当参数“操作类型”为“ADD”时该参数有效，且为必选。用于标识一个替换后的EPS Qos模板ID。使用该ID对应的模板代替“用户签约的EPS QoS模板ID”进行下发。该参数必须先由ADD EPSQOSTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。                                 |

## 使用实例

1. 增加一条缺省EPS QoS模板替代配置记录，设置参数“HLR序列号”为“1”，“操作类型”为“ADD”，“用户签约的EPS QoS模板ID”为“1”，“替代的EPS QoS模板ID”为“300”：

   ```
   SET DEFREPEPSQOSID: HLRSN=1, OPTYPE=ADD, USREPSQOSID=1, REPEPSQOSID=300;
   ```
2. 删除一条缺省EPS QoS模板替代配置记录，设置参数“HLR序列号”为“1”，“操作类型”为“DELETE”，“用户签约的EPS QoS模板ID”为“1”：

   ```
   SET DEFREPEPSQOSID: HLRSN=1, OPTYPE=DELETE, USREPSQOSID=1;
   ```
3. 删除“HLR序列号”为“1”的虚拟HLR下的全部缺省EPS QoS模板替代配置记录：

   ```
   SET DEFREPEPSQOSID: HLRSN=1, OPTYPE=DELETEALL;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。
