# 修改Service Partition虚拟HLR最大用户数(MOD SPHLRUSERNUM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在vRouting Partition/vRouting\_Service Partition下修改Service Partition虚拟HLRSN最大用户数的配置信息。

虚拟HLRSN的最大用户数通过执行**ADD HLRSN**或**MOD HLRSN**命令配置并通过License记录。若存在多个Partition时，由于每个Partition的License申请量不同，因此需要对各Partition分别设置虚拟HLRSN最大用户数。

## 注意事项

执行该命令时，“HLR最大用户数”、“HLR最大EPS用户数”和“IMS最大用户数”参数至少需要输入一个。

## 参数说明

| 参数标识          | 参数名称                | 参数说明                                                                                                       |
|:--------------|:--------------------|:-----------------------------------------------------------------------------------------------------------|
| PID           | Service Partition标识 | 用于标识Service Partition标识。该参数的取值必须先由OM Portal的“USCDB MML命令”界面上SET PARTITION命令定义，然后才能在此引用。 取值范围：1～250。 默认值：无。 |
| HLRSN         | HLR序列号              | 用于标识待修改的HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1～255。 默认值：无。                                          |
| MAXUSERNUM    | HLR最大用户数            | 用于标识当前虚拟HLR允许添加的最大2G/3G用户数。 取值范围：0～100000000。其中，取值为0表示不限制最大用户数。 默认值：无。                                     |
| MAXEPSUSERNUM | HLR最大EPS用户数         | 用于标识当前虚拟HLR所允许添加的最大EPS用户数量。 取值范围：0～100000000。其中，取值为0表示不限制最大用户数。 默认值：无。                                     |
| MAXIMSUSERNUM | IMS最大用户数            | 用于标识当前HLRSN所允许添加的最大IMS用户数量。 取值范围：0～100000000。其中，取值为0表示不限制最大用户数。 默认值：无。                                     |

## 使用实例

修改Service Partition虚拟HLR最大用户数的配置信息，“Service Partition标识”为“20”，“HLR序列号”为“2”，“HLR最大EPS用户数”为“200”：

```
MOD SPHLRUSERNUM: PID=20, HLRSN=2, MAXEPSUSERNUM=200;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释       | 原因分析               | 处理建议                                                                                                         |
|:--------|:------------|:-------------------|:-------------------------------------------------------------------------------------------------------------|
| ERR1009 | 参数丢失        | 未输入必选参数或条件必选参数。    | 根据实际情况，重新输入参数，确保满足以下两点： 必须输入“Service Partition标识”、“HLR序列号”参数。 “HLR最大用户数”、“HLR最大EPS用户数”和“IMS最大用户数”参数至少需要输入一个。 |
| ERR4103 | 此命令不允许在SP执行 | 只能在vRP/vRSP下执行本命令。 | 无需处理。                                                                                                        |
