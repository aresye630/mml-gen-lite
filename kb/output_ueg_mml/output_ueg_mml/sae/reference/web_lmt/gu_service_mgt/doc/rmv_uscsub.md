# 统一销户(RMV USCSUB)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于对单个用户进行统一销户，删除其在GSM/UMTS/EPS/IMS/5G网络的用户信息。

## 注意事项

- “IMSI”和“MSISDN”两个参数必须有且只能有一个参数出现。
- 如果操作员在删除了签约用户，则可能会影响该签约用户对应用户业务，请操作员在执行该操作之前仔细确认任务的可行性。

## 参数说明

| 参数标识   | 参数名称          | 参数说明                                                                                                                                                                          |
|:-------|:--------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI   | IMSI          | 用于标识待销户用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                               |
| ISDN   | MSISDN        | 用于标识待销户用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                             |
| SUPCAN | 是否抑制下发消息给对端网元 | 用于标识UDM是否抑制下发销户时触发的网络侧消息给对端设备。 取值范围： SUPPRESSION：抑制，不下发销户时触发的网络侧消息给对端设备。UNSUPPRESSION：不抑制，下发销户时触发的网络侧消息给对端设备。 默认值：UNSUPPRESSION。 说明：该参数设置为“SUPPRESSION”时，会导致HSS与对端设备存储的数据不一致。 |

## 使用实例

1. 为IMSI号码为“460000009123456”的单个用户销户：

   ```
   RMV USCSUB: IMSI="460000009123456";
   ```
2. 为MSISDN号码为“4600000091234”的单个用户销户：

   ```
   RMV USCSUB: ISDN="4600000091234";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                   | 处理建议                                                                  |
|:--------|:--------|:-----------------------------------------------------------------------|:----------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 可能原因为如下之一：参数“IMSI”的取值不是6～15位十进制数字组成的字符串。参数“ISDN”的取值不是1～15位十进制数字组成的字符串。 | 根据实际情况，重新输入“IMSI”或“ISDN”的取值，确保其取值符合要求。                                |
| ERR1009 | 参数丢失    | 参数“IMSI”和“ISDN”都没有输入。                                                  | 根据实际情况，重新输入参数，并满足“IMSI”和“ISDN”必须存在且只能存在一个的条件。                         |
| ERR1010 | 参数冲突    | 同时输入了参数“IMSI”和“ISDN”。                                                  | 根据实际情况，重新输入参数，并满足“IMSI”和“ISDN”必须存在且只能存在一个的条件。                         |
| ERR3001 | 用户未开户   | 用户的“IMSI”或“ISDN”输入错误，实际输入的参数“IMSI”或“ISDN”对应的用户未开户。                     | 核实用户的“IMSI”或“ISDN”，如果确定输入无误，证明该用户已销户，不需要再执行命令，否则重新输入正确的“IMSI”或“ISDN”。 |
