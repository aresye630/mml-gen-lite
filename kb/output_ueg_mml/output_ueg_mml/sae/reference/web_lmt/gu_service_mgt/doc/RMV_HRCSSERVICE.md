# 删除RCS业务(RMV HRCSSERVICE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于移除用户已签约的RCS业务。

## 注意事项

“IMSI”和“MSISDN”是可选参数，必须输入且只能有一个参数出现。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                  |
|:-------|:-------|:----------------------------------------------------------------------|
| IMSI   | IMSI   | 标识RCS业务的关键字段之一（其取值不能被修改），用于移除用户已签约RCS业务，操作员可以使用LST HRCSSERVICE命令查询获得。 |
| ISDN   | MSISDN | 标识RCS业务的关键字段之一（其取值不能被修改），用于移除用户已签约RCS业务，操作员可以使用LST HRCSSERVICE命令查询获得。 |

## 使用实例

为“IMSI”取值为“216309434161234”的用户去签约RCS业务。

```
RMV HRCSSERVICE: IMSI="216309434161234";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释     | 原因分析      | 处理建议                        |
|----------:|:----------|:----------|:----------------------------|
| 900003472 | RCS业务不存在。 | 未签约RCS业务。 | 通过ADD HRCSSERVICE命令签约RCS业务。 |
