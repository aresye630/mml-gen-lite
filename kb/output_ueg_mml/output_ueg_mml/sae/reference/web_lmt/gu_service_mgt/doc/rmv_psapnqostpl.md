# 删除PSAPNQOS模板(RMV PSAPNQOSTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条PS模板数据记录。

## 注意事项

如果已经通过**MOD PSSER**命令关联该模板，当执行该命令删除PS模板时，系统会提示“ERR3005:模板已经被使用”的错误信息，该PS模板不能被删除。如果要删除该PS模板，必须先执行**MOD PSSER**命令去签约用户PS业务。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                |
|:-------|:-------|:--------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 标识PS模板数据记录的关键字段之一，用于指定在哪个HLR上删除PS模板的数据记录，操作员可以使用LST HLRSN命令查询获得。    |
| TPLID  | 模板ID   | 标识PS模板数据记录的关键字段之一，用于指定需要删除哪条PS模板的数据记录，操作员可以使用LST PSAPNQOSTPL命令查询获得。 |

## 使用实例

删除“HLR序列号”为“1”，“模板ID”为“10”的PS模板，命令如下：

```
RMV PSAPNQOSTPL: HLRSN=1, TPLID=10;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                             | 处理建议                                                                                 |
|:--------|:--------|:---------------------------------|:-------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | “HLR序列号”和“模板ID”参数对应的PS模板数据记录不存在。 | 根据实际情况，重新输入参数，确保“HLR序列号”和“模板ID”参数对应的PS模板数据记录已存在。已存在的PS模板数据记录可以通过LST PSAPNQOSTPL命令查询。 |
| ERR3005 | 模板已经被使用 | 用户已签约该模板。                        | 根据实际情况，确定是否要删除该模板。如果确实需要删除，先通过MOD PSSER命令去签约用户PS业务，然后才能执行RMV PSAPNQOSTPL命令删除。        |
