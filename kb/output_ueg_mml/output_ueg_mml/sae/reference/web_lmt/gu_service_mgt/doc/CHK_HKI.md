# 校验KI(CHK HKI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于校验IMPI的KI密钥，如果K4值存在，表示输入的KI密钥为密文，否则表示输入的是明文。

## 注意事项

- 如果在“命令输入区”输入命令后再输入各参数，“KI密钥”和“K4值”出于安全原因，仅显示“\*”。
- 如果在“MML命令编辑区”直接输入带参数的命令，命令中的“KI密钥”和“K4值”以明文显示。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                  |
|:--------|:-------|:--------------------------------------------------------------------------------------|
| IMPI    | IMPI   | 标识一条KI的关键参数，用于指示系统验证哪一条IMPI的KI信息。要求输入IMPI值符合NAI格式，字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无  |
| K       | KI密钥   | 标识一条KI中的K值，用于指示系统验证哪一条IMPI的K值。要求输入16进制字符，字母不区分大小写。 取值范围： 长度等于32的16进制字符串 缺省值： 无        |
| K4VALUE | K4值    | 解密K值对应的K4的值，如果此值不存在，表示输入的K值为明文。否则为密文。要求输入16进制字符，字母不区分大小写。 取值范围： 长度等于16的16进制字符串 缺省值： 无 |

## 使用实例

校验KI。IMPI：impiinfo，KI密钥：1234567890abcdef1234567890ABCDEF。

```
CHK HKI: IMPI="impiinfo", K="*****";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释   | 原因分析                                                          | 处理建议        |
|----------:|:--------|:--------------------------------------------------------------|:------------|
| 900003523 | 密钥丢失    | 当SET MAPSERV命令中的“随机密钥默认ID”参数为非0，“随机密钥默认ID”参数对应的随机密钥材料不存在或不完整。 | 联系华为技术支持处理。 |
