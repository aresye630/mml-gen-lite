# 查询OP(LST HOP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询鉴权数据OP的业务信息，若需要查询全部鉴权数据OP，请不要输入任何参数，若需要查询某条鉴权数据OP，请输入参数OP索引号。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                        |
|:-------|:-------|:------------------------------------------------------------|
| OPSNO  | OP索引号  | 用于指示系统需要按照哪个OPSNO来查询OP值；若不输入，则表示查询所有的OP值。 取值范围：1～128 缺省值： 无 |

## 使用实例

查询OP。OP索引号：10。

```
LST HOP: OPSNO=10;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，参数含义请参见表1的参数说明。

| 输出项名称   | 输出项名称.1   | 输出项名称.2   | 输出项解释                |
|:--------|:----------|:----------|:---------------------|
| OPSNO   | OPSNO     | OPSNO     | 显示OP索引号。             |
| OPVALUE | OPVALUE   | OPVALUE   | 显示OP值，出于安全原因，仅显示“*”。 |
