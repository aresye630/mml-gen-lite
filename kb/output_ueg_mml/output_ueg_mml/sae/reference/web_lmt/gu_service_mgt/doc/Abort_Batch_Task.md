# 中止批操作(ABT BAT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

本命令用于终止定时执行的或正在执行的某个批操作。

## 注意事项

可通过**CHK BATSTAT**命令查询批操作任务号。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                    |
|:-------|:--------|:----------------------------------------|
| TASKID | 批操作任务ID | 批操作任务号 取值范围：1～4294967295。 缺省值：无 说明：必选参数 |

## 使用实例

中止“批操作任务ID”为“56”的批操作任务。

**ABT BAT: TASKID=56;**
