# 删除退网区域（RMV DETACHREGION）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除退网区域。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                                                                                                                          |
|:-----------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------|
| REGIONTYPE | 区域类型   | 可选必选说明：必选参数 参数含义：用于标识删除退网区域的区域类型。 取值范围 ALLOWMMELIST：支持MME控制用户2G退网。NOTALLOWMMELIST：支持MME控制用户2G不退网。ALLVPLMNLIST：支持VPLMN控制用户2G退网。 默认值：无。 配置原则：无。 |
| MMEHOST    | MME地址  | 可选必选说明：条件必选参数 参数含义：用于删除添加退网区域的MME地址。 取值范围：长度不超过128的字符串。 默认值：无。 配置原则：该参数仅在“区域类型”取值为“ALLOWMMELIST”或“NOTALLOWMMELIST”时有效。                        |
| VPLMN      | 漫游区域   | 可选必选说明：条件必选参数 参数含义：用于标识删除退网区域的漫游区域。 取值范围：长度不超过6的字符串。 默认值：无。 配置原则：该参数仅在“区域类型”取值为“ALLVPLMNLIST”时有效。                                             |

## 使用实例

1. 删除“区域类型”为“ALLOWMMELIST”、“MME地址”为“test”的退网区域。

   ```
   RMV DETACHREGION: REGIONTYPE=ALLOWMMELIST,MMEHOST="test";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1 错误码列表所示。

| 错误码     | 错误码解释   | 原因分析                                             | 处理建议                                                                                                                                    |
|:--------|:--------|:-------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------|
| ERR1009 | 参数丢失    | 必选参数和条件必选参数未填。                                   | 请重新输入，确保必选参数和条件必选参数均有输入。                                                                                                                |
| ERR1010 | 参数冲突    | 可能原因为如下之一： “MME地址”和“漫游区域”不能同时输入。“区域类型”和输入的地址不匹配。 | 根据实际情况，重新输入参数，确保满足以下两点： “MME地址”和“漫游区域”只能输入一个。“区域类型”取值为“ALLOWMMELIST”或“NOTALLOWMMELIST”时，才能输入“MME地址”，“区域类型”取值为“ALLVPLMNLIST”时才能输入“漫游区域”。 |
| ERR3007 | 记录不存在   | 当前输入的“MME地址”或“漫游区域”不存在。                          | 执行LST DETACHREGION命令查询已经添加的退网区域，根据查询结果，重新输入一个已存在的“MME地址”或“漫游区域”。                                                                        |
