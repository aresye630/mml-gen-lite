# 删除服务号码(RMV OSNNUM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此命令用于删除一条指定的服务号码。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                |
|:-------|:-------|:----------------------------------------------------|
| HLRSN  | HLR序列号 | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。        |
| OSNNUM | 服务号码   | 用于标识SRI消息中需要进行特殊处理的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 |

## 使用实例

删除一条服务号码，“HLR序列号”为“1”，“服务号码”为“12334567890”：

```
RMV OSNNUM: HLRSN=1, OSNNUM="12334567890";
```
