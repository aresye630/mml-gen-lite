# 修改EPSAPNQOS模板(MOD EPSAPNQOSTPL)

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使签约此模板的用户数据被同步修改，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一条EPS模板数据记录的某些参数进行修改或调整。在该命令中，系统通过以下关键参数的组合来唯一标识一条EPS模板数据记录：

- “HLR序列号”
- “模板ID”

## 注意事项

当用户进行位置更新或触发其他涉及EPS模板的流程时，系统会根据用户签约的EPS模板ID下发模板中的数据，修改模板数据会使签约此模板的用户数据被同步修改，会影响在网用户，因此现网执行修改模板操作时需要慎重。

| IW5GSINDICATOR | 是否签约5GS互操作          | 用于标识用户是否签约5GS互操作业务。UDM收到MME发送的ULR消息或发送IDR消息给MME时，判断用户是否签约该业务，若有签约且ADD NCCTPL命令中的“是否下发Interworking-5GS-Indicator”参数设置为“SR”时，则在ULA消息或IDR消息中将该取值下发给MME，MME通过该取值确定是否选择4/5G融合网关。 取值范围：SUBSCRIBED：签约。NOT-SUBSCRIBED：未签约。 默认值：无。 说明：仅当该参数有效且不输入该参数时，系统会设置初始值NOT-SUBSCRIBED。该参数设置为“SUBSCRIBED” 后，还需要和周边涉及互操作的HSS网元以及MME网元的“Interworking-5GS-Indicator”信元的AVP Code值保持一致，若不一致可通过ADD DMDICTCHG命令进行修改。 |

## 使用实例

修改一个EPS模板数据，“HLR序列号”为“1”，“模板ID”为“10”，“模板名称”由“EPSAPNQOSTPL\_1”修改为“EPSAPNQOSTPL\_10”，命令如下:

```
MOD EPSAPNQOSTPL: HLRSN=1, TPLID=2, TPLNAME="EPSAPNQOSTPL_10";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                            | 处理建议                                                                                                                    |
|:--------|:--------|:--------------------------------|:------------------------------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | 输入的“HLR序列号”和“模板ID”参数对应的模板不存在。   | 根据实际情况，重新输入“HLR序列号”和“模板ID”参数的取值，确保其对应的模板已存在。可执行LST EPSAPNQOSTPL命令查询系统中已存在的EPS模板。                                        |
| ERR1004 | 无效的参数值  | 界面输入的参数不在相应的参数取值范围内。            | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                        |
| ERR3003 | 模板未定义   | 输入的“APN模板ID”或“EPSQOS模板ID”参数未定义。 | 根据实际情况，重新输入“APN模板ID”或“EPSQOS模板ID”参数的取值，确保其存在。已存在的“APN模板ID”参数可以通过LST APNTPL命令查询。已存在的“EPSQOS模板ID”参数可以通过LST EPSQOSTPL命令查询。 |
| ERR1010 | 参数冲突    | “PDN级别计费特性”和“标准计费特性”参数都输入。      | 根据实际情况，重新输入参数，确保“PDN级别计费特性”和“标准计费特性”参数不能同时输入。                                                                           |
