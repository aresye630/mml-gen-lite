# 修改5G虚拟网络组 (MOD VNGROUP)

- 命令功能

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成当前5G虚拟网络组下所有用户业务受损或系统产生过载，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于修改一条5G虚拟网络组配置信息。在该命令中，系统通过“内部组ID”或“外部组ID”参数来唯一标识一条5G虚拟网络组配置信息。

## 注意事项

- 修改5G虚拟网络组时，对于一个“切片标识”和“数据网名称”有如下建议：
  - “精简标识”参数取值唯一，只能是“TRUE”或者“FALSE”。
  - 定义一个“精简标识”参数取值为“FALSE”的VN组。
  - 定义多个“精简标识”参数取值为“TRUE”的VN组。
- 混合组网场景下，该命令仅支持在路由分区执行，非路由分区下执行该命令上报错误码“ERR3111:系统不支持该特性”。

## 参数说明

| 参数标识           | 参数名称          | 参数说明                                                                                                                                                                                                                                                                                                                           |
|:---------------|:--------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| INGROUPID      | 内部组ID         | 可选必选说明：条件必选参数 参数含义：标识一条5G虚拟网络组数据记录的关键字段（其取值不能被修改），用于指定需要对哪个内部组ID对应的5G虚拟网络组数据记录进行修改或调整，操作员可以使用LST VNGROUP命令查询获得。 取值范围：10～38个十进制数字、十六进制数字或“-”组成的字符串。 默认值：无。 配置原则：该参数与“外部组ID”两个参数必须输入且只能输入其中一个。该参数输入的字母不区分大小写。                                                                                                                    |
| EXTGROUPID     | 外部组ID         | 可选必选说明：条件必选参数 参数含义：标识一条5G虚拟网络组数据记录的关键字段（其取值不能被修改），用于指定需要对哪个外部组ID对应的5G虚拟网络组数据记录进行修改或调整，操作员可以使用LST VNGROUP命令查询获得。 取值范围：3～128个字母、十进制数字、“@”、“.”、“-”或“_”组成的字符串。 默认值：无。 配置原则： 该参数与“内部组ID”两个参数必须输入且只能输入其中一个。该参数输入的字母不区分大小写。                                                                                                           |
| GROUPNAME      | 组名称           | 可选必选说明：可选参数 参数含义：用于标识5G虚拟网络组名称。 取值范围：长度不超过32位的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                              |
| SNSSAI         | 切片标识          | 可选必选说明：可选参数 参数含义：用于标识5G系统中的网络切片，由SST（Slice/Service Type）与SD（Slice Differentiator）组成。 取值范围：1～10位字符串。 默认值：无。 配置原则： SST为取值范围是0～255的数字。SD是固定长度为3字节的十六进制字符串。 例如：当SST为1，SD为D143A5，则输入1-D143A5。当SST为1，无SD，则输入1。                                                                                                                       |
| DNN            | 数据网名称         | 可选必选说明：可选参数 参数含义：用于标识数据网名称。 取值范围：1～64位的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                     |
| PDUTYPES       | 允许的PDU类型      | 可选必选说明：可选参数 参数含义：用于标识允许的PDU类型。 取值范围： 全部选中：选中除“全部清空”外的所有取值。全部清空：清空所有取值。IPV4V6：设置允许的会话类型为IPv4v6双栈类型，即同时使用IPv6/IPv4两个可以并行工作的协议栈。 IPV4：设置允许的会话类型为IPv4单栈类型。 IPV6：设置允许的会话类型为IPv6单栈类型。 UNSTR：点对点隧道技术可以用于向数据网络中的目的地传递非结构化PDU会话类型数据。 ETHER：SMF和UPF可以支持与PDU会话承载以太网帧相关的功能。 默认值：无。 配置原则：可同时设置多个PDU类型，并用“&”连接，例如“IPV4V6&IPV4”，也可以在复选框中进行复选。 |
| APPDESCRIPTORS | 应用描述信息        | 可选必选说明：可选参数 参数含义：用于标识应用描述信息。 取值范围：长度不超过1024位的字符串。 默认值：无。 配置原则：该参数为JSON格式，必须包括osId或appId。osId：表示操作系统标识，不包括操作系统版本号。appId：表示应用标识，不包括应用的版本号。 取值为“null”时表示将对应的数据库字段设置为空。                                                                                                                                                            |
| SECONDARYAUTH  | 是否需要二次认证      | 可选必选说明：可选参数 参数含义：用于标识SMF在用户PDU会话建立时是否需要二次认证授权，如果需要则发起到DN-AAA的二次认证授权流程。 取值范围： TRUE：需要二次认证授权FALSE：不需要二次认证授权 默认值：无。 配置原则：取值为“FALSE”时会清除对应的“DN-AAA的IPv4地址”或“DN-AAA的IPv6地址”为空。                                                                                                                                                      |
| AAAIPV4ADDR    | DN-AAA的IPv4地址 | 可选必选说明：可选参数 参数含义：用于标识二次认证授权的DN-AAA服务器IPv4地址。 取值范围：字符串格式表示的合法IPv4地址。 默认值：无。 配置原则：仅当本命令中的参数“是否需要二次认证”取值为“TRUE”时，该参数有效。不支持取值为0.0.0.0或255.255.255.255的IPv4地址。                                                                                                                                                                      |
| AAAIPV6ADDR    | DN-AAA的IPv6地址 | 可选必选说明：可选参数 参数含义：用于标识二次认证授权的DN-AAA服务器IPv6地址。 取值范围：字符串格式表示的合法IPv6地址或者IPv6前缀。 IPv6地址示例如下： FE80:910A:2222:5498:8475:1111:3900:2020 IPv6地址前缀示例如下： 2001:0DB8:0:CD30::/60 IPv6地址前缀中前缀长度有效值范围：1～128。 默认值：无。 配置原则：仅当本命令中的参数“是否需要二次认证”取值为“TRUE”时，该参数有效。不支持全0或全F的IPv6地址。                                                                 |
| SIMPLFIN       | 精简标识          | 可选必选说明：可选参数 参数含义：用于标识5G LAN精简标识，该精简标识用于告知SMF一个切片标识及一个数据网名称下用户是否能签约多个5G LAN群组。 取值范围： TRUE：能签约多个5G LAN群组。 FALSE：只能签约一个5G LAN群组。 默认值：无。 配置原则：无。                                                                                                                                                                                   |

## 使用实例

修改一条5G虚拟网络组数据记录，“内部组ID”为“1-46001-2D”，“是否需要二次认证”为“TRUE”，“DN-AAA的IPv4地址”为“10.20.30.101”。

```
MOD VNGROUP: INGROUPID="1-46001-2D", SECONDARYAUTH=TRUE, AAAIPV4ADDR="10.20.30.101";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释    | 原因分析                                | 处理建议                                                   |
|:--------|:---------|:------------------------------------|:-------------------------------------------------------|
| ERR1010 | 参数冲突     | 执行命令时同时输入“内部组ID”和“外部组ID”参数。         | “内部组ID”与“外部组ID”两个参数必须输入且只能输入其中一个。                      |
| ERR3007 | 记录不存在    | “内部组ID”或“外部组ID”参数对应的5G虚拟网络组数据记录不存在。 | 可以先通过LST VNGROUP命令查询“内部组ID”或“外部组ID”对应的5G虚拟网络组数据记录是否存在。 |
| ERR3111 | 系统不支持该特性 | 混合组网场景下，在非路由分区下执行该命令。               | 混合组网场景下，该命令仅支持在路由分区下执行。                                |
