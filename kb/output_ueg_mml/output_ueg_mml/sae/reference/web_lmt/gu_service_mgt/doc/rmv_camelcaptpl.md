# 删除CAMEL能力模板(RMV CAMELCAPTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用于删除CAMEL能力配置模版。

## 注意事项

如果CAMEL能力模板被VLR类型或SGSN类型使用，则不能删除该模板。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                          |
|:-------|:-------|:----------------------------------------------|
| HLRSN  | HLR序列号 | HLR序列号。 取值范围：1～255。 说明：在PGW支持容灾功能或虚拟HLR功能时设置。 |
| TPLID  | 模板ID   | CAMELCAP模板ID。 取值范围：0～65534。                   |

## 使用实例

删除虚拟HLR1上模板ID为“1”的CAMEL能力配置模板，命令如下：

RMV CAMELCAPTPL:HLRSN=1, TPLID=1;
