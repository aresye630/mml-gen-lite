# 删除NEF全局订阅信息(RMV NEFANYUEINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成订阅事件无法上报，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除指定NEF请求配置的所有用户漫游状态变更的监视事件信息。

UDM与NEF通过N52接口进行订阅消息的交互。NEF发送订阅请求消息到UDM，UDM发现订阅的externalGroupId为AnyUE时，当用户发生漫游则触发漫游状态上报NEF。

## 注意事项

使用该删除命令后会导致用户订阅的NEF监视事件无法上报，需要和技术人员确认后再实施该操作。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                             |
|:---------|:-------|:---------------------------------------------------------------------------------|
| NEFSUBID | 订阅ID   | 可选必选说明：必选参数 参数含义：用于标识需要删除哪个NEF请求配置监视事件信息。 取值范围：1～16位十六进制数字组成的字符串。 默认值：无。 配置原则：无。 |

## 使用实例

删除“订阅ID”为“111111”的NEF监视事件信息：

```
RMV NEFANYUEINFO: NEFSUBID="111111";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析              | 处理建议                                                   |
|:--------|:--------|:------------------|:-------------------------------------------------------|
| ERR3007 | 记录不存在   | 输入的“订阅ID”对应记录不存在。 | 重新输入参数“订阅ID”，确保“订阅ID”数据记录存在，可使用LST NEFANYUEINFO命令进行查询。 |
