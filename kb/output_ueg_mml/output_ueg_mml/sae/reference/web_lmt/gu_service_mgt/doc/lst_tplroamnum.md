# 查询某个优选模板下对应网络漫游用户数（LST TPLROAMNUM）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

查询某个优选漫游模板下对应网络的漫游用户数。

- 若要查询某个优选漫游模板中某个运营商网络中的漫游用户数，请输入“HLR序列号”、“模板ID”、“模板类型”、“运营商名称”参数。
- 若要查询某个优选漫游模板中某个国家分组中所有运营商网络的漫游用户数，请输入“HLR序列号”、“模板ID”、“模板类型”、“分组ID”参数。

## 注意事项

- “分组ID”、“运营商名称”两个参数必须有且只能有一个参数出现。
- 该命令刷新运营商网络下漫游用户数时使用了DSU数据统计，所以只能在话务量低时使用该命令，并且不得连续执行。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                                                                   |
|:--------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN   | HLR序列号 | 用于标识本地HLR。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1～255 默认值：无。                                                                                                            |
| TPLID   | 模板ID   | 用于标识一个优选漫游模板ID。 取值范围：1～999 默认值：无。                                                                                                                                      |
| TPLTYPE | 模板类型   | 用于标识优选漫游模板的类型。 取值范围：CS：CS优选漫游模板。PS：PS优选漫游模板。EPS：EPS优选漫游模板。 默认值：无。                                                                                                      |
| GRPID   | 分组ID   | 用于标识一个运营商所属的分组ID。该参数可通过LST ROAMPERTPL命令查询获得。 取值范围：1～999 默认值：无。 说明：当本命令中“刷新标志”参数为“TRUE”时，该参数不能输入。                                                                       |
| OPRNAME | 运营商名称  | 用于标识运营商网络中的运营商名称。该参数可通过LST ROAMPREFIX命令查询获得。 取值范围：1～60位由字母、数字和特殊字符组成的字符串。 默认值：无。 说明：当本命令中“刷新标志”参数为“TRUE”时，该参数必须输入。                                                     |
| REFRESH | 刷新标志   | 用于标识运营商网络中是否刷新统计结果标志。 取值范围： TRUE：刷新统计结果。FALSE：不刷新统计结果。 默认值：FALSE。 说明：当执行SET ROAMPERTPL命令调整运营商名称或漫游比例后会导致实际漫游用户数的统计结果在一段时间内不一致，如果该参数取值为“FALSE”，则有可能导致查询出来的结果和实际统计结果不一致。 |

## 使用实例

1. 查询“HLRSN”为“1”、“模板ID”为“1”、“模板类型”为“PS”、“运营商名称”为“Peking1”、“刷新标志”为“TRUE”的优选漫游模板中该分组下的漫游用户数：

   ```
   LST TPLROAMNUM: HLRSN=1, TPLID=1, TPLTYPE=PS, OPRNAME="Peking1", REFRESH=TRUE;
   ```

   ```
   %%LST TPLROAMNUM: HLRSN=1, TPLID=1, TPLTYPE=PS, OPRNAME="Peking1", REFRESH=TRUE;%%
   RETCODE = 0 SUCCESS0001:操作成功

                            GRPID = 1
                            OPRID = 1
                          OPRNAME = Peking1
                       ROAMSUBNUM = 0

   Total count = 4

   There is together 1 report

   ---    END
   ```
2. 查询“HLRSN”为“1”、“模板ID”为“1”、“模板类型”为“PS”、“分组ID”为“1”的优选漫游模板中运营商网络下的漫游用户数：

   ```
   LST TPLROAMNUM: HLRSN=1, TPLID=1, TPLTYPE=PS, GRPID=1;
   ```

   ```
   %%LST TPLROAMNUM: HLRSN=1, TPLID=1, TPLTYPE=PS, GRPID=1;%%
   RETCODE = 0 SUCCESS0001:操作成功

                            GRPID = 1

                          OPRNAME = Peking2

                            GRPID = 1
                            OPRID = 3
                          OPRNAME = Peking3
                       ROAMSUBNUM = 0

   Total count = 12

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数请参见本命令的参数说明。表1列出的是未包含在本命令参数说明中的输出项。

| 输出项名称      | 输出项解释          |
|:-----------|:---------------|
| ROAMSUBNUM | 用于返回对应网络漫游用户数。 |

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

| 错误码     | 错误码解释     | 原因分析                                                         | 处理建议                                                                                              |
|:--------|:----------|:-------------------------------------------------------------|:--------------------------------------------------------------------------------------------------|
| ERR1009 | 参数丢失      | 参数“分组ID”和“运营商名称”均没有输入。                                       | 根据实际情况，重新输入参数，确保“分组ID”和“运营商名称”两个参数必须有且只能有一个参数出现。                                                  |
| ERR1010 | 参数冲突      | 可能原因为如下之一：同时输入参数“分组ID”和“运营商名称”。 “刷新标志”参数为“TRUE”时，输入“分组ID”参数。 | 根据实际情况，重新输入参数，确保满足以下两点：“分组ID”和“运营商名称”两个参数必须有且只能有一个参数出现。“刷新标志”参数为“TRUE”时，“分组ID”参数不能输入。             |
| ERR3097 | HLR序列号未定义 | 参数“HLR序列号”输入错误，实际输入的参数“HLR序列号”未定义。                           | 根据实际情况，重新输入参数“HLR序列号”的取值，确保其取值已被定义。已定义的“HLR序列号”可通过LST HLRSN命令查询。                                  |
| ERR3111 | 系统不支持该特性  | 用户级的优选漫游业务功能开关未开启。                                           | 将命令SET MAPCONF中的参数“SUBLEVEL_ROAMPER_SUPP（是否支持用户级的优选漫游业务）”配置为“TRUE”，使UDM支持用户单独签约优选漫游模板，然后再使用此命令查询。 |
