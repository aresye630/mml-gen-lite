# 修改DNN列表(MOD DNNLIST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改数据网名称列表信息，支持替换单用户或批量替换多个用户的DNN的功能。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数必须有且只能有一个参数出现。
- “用户个数” 参数不能与“IMSI文件名”或“MSISDN文件名”同时存在，“用户个数”参数只能与“IMSI”或“MSISDN”一起出现。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                                         |
|:------------|:----------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 可选必选说明：条件可选参数 参数含义：用于标识需要修改哪个IMSI号码的DNN列表信息。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                           |
| ISDN        | MSISDN    | 可选必选说明：条件可选参数 参数含义：用于标识需要修改哪个MSISDN号码的DNN列表信息。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                         |
| RECORDCOUNT | 用户个数      | 可选必选说明：条件可选参数 参数含义：用于标识待修改DNN列表信息的用户数目。 取值范围：1～100000 默认值：无。 配置原则： 需要为连续号码的多个用户修改DNN列表信息时配置该参数。当只有一个用户时，该参数无需配置。配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行修改DNN列表信息。当一次修改DNN列表信息的用户个数很多时，对系统性能无影响，但修改DNN列表信息的用户个数越多，消耗的时间越长。                                                |
| IMSIFILE    | IMSI文件名   | 可选必选说明：条件可选参数 参数含义：用于标识IMSI批操作文件。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。 配置原则：IMSI批操作文件包含多个不连续的需要修改的DNN列表信息的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“moddnnlist.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。                                                                |
| ISDNFILE    | MSISDN文件名 | 可选必选说明：条件可选参数 参数含义：用于标识MSISDN批操作文件。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。 配置原则：MSISDN批操作文件包含多个不连续的需要修改DNN列表信息的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“moddnnlist.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。                                                           |
| OLDDNNLIST  | 旧DNN名称列表  | 可选必选说明：必选参数 参数含义：用于标识旧的数据网名称列表。 取值范围：1~334个字符组成的字符串。 默认值：无。 配置原则：该参数由1到5个DNN以“&”连接组成（例如："DNN1.com"&"DNN2.com"）;如果只有一个DNN时，参数不带字符"" 和 &；如果存在多个DNN时，每个DNN需要使用""标识，用&进行连接。该参数和“新DNN名称列表”同时存在，并和“新DNN名称列表”中DNN的个数保持一致并一一对应。该参数定义的每个DNN在5GS用户模板中存在。                               |
| NEWDNNLIST  | 新DNN名称列表  | 可选必选说明：必选参数 参数含义：用于标识新的数据网名称列表。 取值范围：1~334个字符组成的字符串。 默认值：无。 配置原则：该参数由1到5个DNN以“&”连接组成（例如："Mnet.com"&"Cnet.com"）;如果只有一个DNN时，参数不带字符"" 和 &；如果存在多个DNN时，每个DNN需要使用""标识，用&进行连接。该参数和“旧DNN名称列表”同时存在，并和“旧DNN名称列表”中DNN的个数保持一致并一一对应。该参数定义的每个DNN在数据插入时覆盖5GS用户模板中对应的DNN(OLDDNNLIST中对应的DNN)。 |

## 使用实例

1. 修改DNN列表信息，“IMSI”为“460000009123456”，“旧DNN名称列表”为“DNN1.com&DNN2.com”，“新DNN名称列表”为“Mnet.com&Cnet.com”：

   ```
   MOD DNNLIST: IMSI="460000009123456", OLDDNNLIST="\"DNN1.com\"&\"DNN2.com\"", NEWDNNLIST="\"Mnet.com\"&\"Cnet.com\"";
   ```
2. 修改DNN列表信息，“IMSI”为“460000009123456”、“460000009123457”、“460000009123458”的3个连续用户，“旧DNN名称列表”为“DNN1.com&DNN2.com”，“新DNN名称列表”为“Mnet.com&Cnet.com”：

   ```
   MOD DNNLIST: IMSI="460000009123456", RECORDCOUNT=3, OLDDNNLIST="\"DNN1.com\"&\"DNN2.com\"", NEWDNNLIST="\"Mnet.com\"&\"Cnet.com\"";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|:--------|:-----------------|:-----------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值           | 参数取值范围不符。                                                                                            | 根据系统提示及实际情况，重新输入参数值，确保其取值符合取值范围的要求。                                                                               |
| ERR1005 | 文件不存在            | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                     | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                |
| ERR1009 | 参数丢失             | 参数“IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数同时缺失。                                                     | 根据实际情况，“IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数必须有且只能有一个参数出现。                                                    |
| ERR1010 | 参数冲突             | 可能的原因为如下之一： “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点： “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数必须有且只能有一个参数出现。“用户个数”不与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR3006 | 记录已存在            | 输入的“新DNN名称列表”中的DNN已存在。                                                                               | 根据实际情况，重新输入参数，确保输入的“新DNN名称列表”中的每个DNN都未被使用，可通过LST SMDATA查询已存在的DNN数据。                                               |
| ERR3007 | 记录不存在            | 输入的“旧DNN名称列表”中存在DNN未定义。                                                                              | 根据实际情况，重新输入参数，确保输入的“旧DNN名称列表”中的每个DNN都已定义，可通过LST SMDATA查询已存在的DNN数据。                                                |
| ERR4146 | 通配DNN不允许设置为默认DNN | “旧DNN名称列表”参数中存在默认DNN，执行该命令将默认DNN修改为通配DNN。                                                            | 根据实际情况，重新输入参数，确认不会将“旧DNN名称列表”参数中的默认DNN修改为通配DNN，可通过LST SMDATA查询已存在的DNN数据。                                          |
