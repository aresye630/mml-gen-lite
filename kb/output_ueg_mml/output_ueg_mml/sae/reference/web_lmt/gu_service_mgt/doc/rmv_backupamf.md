# 删除备份AMF信息(RMV BACKUPAMF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除备份AMF的信息。

该命令仅在现网规划调整后不需要备用AMF的时候使用。

## 注意事项

- 当执行该命令删除一条备用AMF的信息后，会造成该备用AMF与UDM之间信令交互失败，请谨慎操作。
- 操作员在执行此命令之前，必须先执行**LST BACKUPAMF**命令查询所有备份AMF信息，并记录需要删除的备份AMF信息数据：
  - 如果待删除的备份AMF信息记录中“备用AMF的移动国家码”、“备用AMF的移动网络码”和“备用AMF的标识”三个参数值均不为“NULL”，则必须根据记录的备份AMF信息数据填写该命令的所有参数。
  - 如果待删除的备份AMF信息记录中“备用AMF的移动国家码”、“备用AMF的移动网络码”和“备用AMF的标识”三个参数值均为“NULL”，则删除时必须不携带这三个参数。

## 参数说明

|:---------|:------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MCC      | 移动国家码       | 可选必选说明：必选参数 参数含义：标识一条备份AMF信息数据记录的关键字段之一，用于指定需要删除哪个移动国家码的数据记录，操作员可以使用LST BACKUPAMF命令查询获得。 取值范围：3位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                 |
| MNC      | 移动网络码       | 可选必选说明：必选参数 参数含义：标识一条备份AMF信息数据记录的关键字段之一，用于指定需要删除哪个移动网络码的数据记录，操作员可以使用LST BACKUPAMF命令查询获得。 取值范围：2或3位的十进制数字组成的字符串。 默认值：无。 配置原则：无。                              |
| AMFID    | AMF标识       | 可选必选说明：必选参数 参数含义：标识一条备份AMF信息数据记录的关键字段之一，用于指定需要删除哪个AMF标识的数据记录，操作员可以使用LST BACKUPAMF命令查询获得。 取值范围：6位十六进制的字符串。 默认值：无。 配置原则：无。                                    |
| BK_FQDN  | 备用AMF的FQDN  | 可选必选说明：必选参数 参数含义：标识一条备份AMF信息数据记录的关键字段之一，用于指定需要删除哪个备用AMF全量域名的数据记录，操作员可以使用LST BACKUPAMF命令查询获得。 取值范围：1～128位的字符串。仅可输入数字、字母、中划线（-）、下划线（_）和英文点（.）。 默认值：无。 配置原则：无。 |
| BK_MCC   | 备用AMF的移动国家码 | 可选必选说明：可选参数 参数含义：用于指定系统删除哪个备用AMF移动国家码的数据记录，操作员可以使用LST BACKUPAMF命令查询获得。 取值范围：3位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                   |
| BK_MNC   | 备用AMF的移动网络码 | 可选必选说明：条件可选参数 参数含义：用于指定系统删除哪个备用AMF移动网络码的数据记录，操作员可以使用LST BACKUPAMF命令查询获得。 取值范围：2或3位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                               |
| BK_AMFID | 备用AMF的标识    | 可选必选说明：条件可选参数 参数含义：用于指定系统删除哪个备用AMF标识的数据记录，操作员可以使用LST BACKUPAMF命令查询获得。 取值范围：6位十六进制的字符串。 默认值：无。 配置原则：无。                                                       |

## 使用实例

1. 删除一条备份AMF的信息,“移动国家码”为“460”，“移动网络码”为“06”，“AMF标识”为“111111”，“备用AMF的FQDN”为“huawei.com”，“备用AMF的移动国家码”为“111”，“备用AMF的移动网络码”为“06”，“备用AMF的标识”为“222222”。

   ```
   RMV BACKUPAMF: MCC="460", MNC="06", AMFID="111111", BK_FQDN="huawei.com", BK_MCC="111", BK_MNC="06", BK_AMFID="222222";
   ```
2. 删除一条备份AMF的信息,“移动国家码”为“460”，“移动网络码”为“00”，“AMF标识”为“6F23B4”，“备用AMF的FQDN”为“huawei.com”。

   ```
   RMV BACKUPAMF: MCC="460", MNC="00", AMFID="6F23B4", BK_FQDN="huawei.com";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                             | 处理建议                                                                  |
|:--------|:--------|:-------------------------------------------------|:----------------------------------------------------------------------|
| ERR3007 | 记录不存在   | 输入所有参数值所组成的数据记录不存在。                              | 根据实际情况，重新输入参数，确保输入参数所组成的数据记录已存在。已存在的备份AMF信息数据记录可以通过LST BACKUPAMF命令查询。 |
| ERR1004 | 无效的参数值  | 输入的参数不在对应参数的取值范围内。                               | 根据实际情况，重新输入提示错误的参数取值，确保其取值符合要求。                                       |
| ERR1009 | 参数丢失    | “备用AMF的移动国家码”、“备用AMF的移动网络码”和“备用AMF的标识”三个参数未同时配置。 | 根据实际情况，重新输入参数，确保“备用AMF的移动国家码”、“备用AMF的移动网络码”和“备用AMF的标识”三个参数同时配置。       |
