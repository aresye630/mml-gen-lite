# 查询COR数据(LST COR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

操作员可以通过本操作查询HLR中已经定义的COR数据。

## 注意事项

当用户输入指定的HLRSN，COR时，表示查询指定的COR记录；当用户不输入COR时，表示查询所有的COR记录。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                     |
|:-------|:-------|:-----------------------------------------|
| HLRSN  | HLR序列号 | HLR序列号，有效值域为1～255，在PGW支持容灾功能或虚拟HLR功能时设置。 |
| COR    | COR    | COR的索引值，有效值域为COR_1～COR_254。可选参数。         |

## 使用实例

查询COR索引值为COR\_228的COR数据。

LST COR: HLRSN=1, COR=COR\_228;
