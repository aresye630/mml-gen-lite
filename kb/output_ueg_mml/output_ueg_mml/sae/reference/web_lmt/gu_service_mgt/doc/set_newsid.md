# 设置新SID(SET NEWSID)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于更新现网用户的SID（Subscriber ID）标识。当现网HLR由分离部署升级改造为云部署时，由于改造前某两个局点会存在Location ID相同的情况，导致升级云部署场景时使用当前的SID算法，会存在重复的SID。此时操作维护人员可以通过该命令对重复的SID进行更新，从而保证云部署场景下，每个用户的SID唯一。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                         |
|:-------|:-------|:---------------------------------------------|
| SID    | SID    | 用于标识某个需要更新的SID。 取值范围：16位十六进制数字组成的字符串。 默认值：无。 |

## 使用实例

某HLR局点改造为云部署场景前，发现当前网络存在重复SID，“SID”为“1e000b174a590004”，操作维护人员对此SID进行更新:

```
SET NEWSID: SID="1e000b174a590004";
```

## 输出结果说明

该命令执行正常，会返回修改后新的SID信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                   | 处理建议                                                    |
|:--------|:--------|:-------------------------------------------------------|:--------------------------------------------------------|
| ERR1004 | 无效的参数值  | 原因为如下情形中的一种：参数“SID”的取值中含有0～f以外的字符。参数“SID”的取值长度小于16个字符。 | 根据实际情况，重新输入参数“SID”的取值，确保其取值符合取值范围的要求。                   |
| ERR3001 | 用户未开户   | 参数“SID”不存在。                                            | 请检查输入的参数值是否与需要更新的SID一致：如果不一致，请重新输入。如果一致，请重新获取SID，并重新输入。 |
