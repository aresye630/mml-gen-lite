# 生成SM2密钥（GEN SM2KEY）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于生成国密SM2密钥以加密K4。

## 注意事项

- 本命令为局点定制命令，非定制局点使用前请务必先联系华为技术支持。
- 执行本命令时，UDM自动生成私钥，私钥使用随机密钥默认按CBC模式进行加密。如果**SET MAPCONF**命令的“是否启用随机密钥”参数不为“TRUE”，系统上报“ERR3111 系统不支持该特性 ”错误提示；如果**SET MAPSERV**命令的“随机密钥默认ID”参数未配置，系统上报“ERR4086 随机密钥默认ID未设置”错误提示。
- 执行本命令生成SM2密钥时，相同“HLR序列号”下的“密钥名”参数取值不能重复。

## 参数说明

| 参数标识     | 参数名称   | 参数说明                                                                                            |
|:---------|:-------|:------------------------------------------------------------------------------------------------|
| HLRSN    | HLR序列号 | 可选必选说明：必选参数 参数含义：用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1~255 默认值：无。 配置原则：无。         |
| KEYSNO   | 密钥序列号  | 可选必选说明：必选参数 参数含义：用于标识国密密钥序列号。 取值范围：1～65535 默认值：无。 配置原则：无。                                       |
| KEYNAME  | 密钥名    | 可选必选说明：必选参数 参数含义：用于标识国密SM2密钥名。 取值范围：1～60位由字母、数字或“.”、“-”等字符组成的字符串。 默认值：无。 配置原则：该参数取值一般和证书CN取值相同。 |
| C        | 国家名    | 可选必选说明：可选参数 参数含义：用于标识使用国密SM2密钥的国家码。例如：中国固定为CN。根据证书颁发机构要求输入。 取值范围：2位或3位的英文字母。 默认值：无。 配置原则：无。     |
| ST       | 省名     | 可选必选说明：可选参数 参数含义：用于标识国密SM2密钥省名。 取值范围：1～60位的字符串。 默认值：无。 配置原则：无。                                  |
| ORG      | 组织名    | 可选必选说明：可选参数 参数含义：用于标识国密SM2密钥组织名。 取值范围：1～60位的字符串。 默认值：无。 配置原则：无。                                 |
| ORGUNIT  | 单位名    | 可选必选说明：可选参数 参数含义：用于标识国密SM2密钥单位名。 取值范围：1～60位的字符串。 默认值：无。 配置原则：无。                                 |
| LOCALITY | 城市     | 可选必选说明：可选参数 参数含义：用于标识国密SM2密钥城市。 取值范围：1～60位的字符串。 默认值：无。 配置原则：无。                                  |
| EMAIL    | 邮箱地址   | 可选必选说明：可选参数 参数含义：用于标识国密SM2密钥的邮箱地址。 取值范围：1～60位的字符串。 默认值：无。 配置原则：无。                               |

## 使用实例

生成一个SM2密钥记录，其中“HLR序列号”为“1”、“密钥序列号”为“2”、“密钥名”为“PKEYnamehlr1pkeysno2”、“国家名”为“CN”：

```
GEN SM2KEY: HLRSN=1, KEYSNO=2, KEYNAME="PKEYnamehlr1pkeysno2", C="CN";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释       | 原因分析                                                   | 处理建议                                                                                                                            |
|:--------|:------------|:-------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------|
| ERR1111 | 超过最大限制      | 同一个“HLR序列号”中增加的国密SM2密钥记录数超过5000条。                      | 根据实际情况，如需生成国密SM2密钥，处理步骤如下： 执行LST SM2KEY命令，查询已存在的国密SM2密钥。执行RMV SM2KEY命令，删除不必要的国密SM2密钥值记录。执行该命令增加国密SM2密钥，确保增加的国密SM2密钥值记录数在规定范围之内。 |
| ERR3006 | 记录已存在       | 可能原因如下： 该“HLR序列号”下已存在相同的“密钥序列号”。该“HLR序列号”下已存在相同的“密钥名”。 | 执行LST SM2KEY命令，查询已存在的国密SM2密钥：重新输入“HLR序列号”或“密钥序列号”，确保同一个“HLR序列号”下的“密钥序列号”不重复。重新输入“HLR序列号”或“密钥名”，确保同一个“HLR序列号”下的“密钥名”不重复。         |
| ERR3044 | 无效的参数取值     | 界面提示的参数不在取值范围内。                                        | 重新输入界面提示的参数，确保参数取值合法。                                                                                                           |
| ERR3111 | 系统不支持该特性    | SET MAPCONF命令的“是否启用随机密钥”参数设置为“FALSE”。                  | 启用该功能需要先完成随机密钥整改。请参考产品手册配置随机密钥章节，并根据实际情况，修改SET MAPCONF命令的“是否启用随机密钥”参数后重新执行本命令。                                                  |
| ERR4086 | 随机密钥默认ID未设置 | 要使用随机密钥功能，但SET MAPSERV命令中的“随机密钥默认ID”参数为0。              | 根据实际情况，设置SET MAPSERV命令中的“随机密钥默认ID”参数为系统已存在的随机密钥。                                                                                |
