# 查询游牧模板(LST HNATPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HSS的业务数据库中查询一条游牧模板ID或游牧模板名称指定的游牧模板的配置信息。

## 注意事项

“NASS游牧模板ID参数”和“NASS游牧模板名称”参数必须存在且仅能存在一个。ADD HNATPL命令里的游牧地址信息由LST HNATPLADDR命令查询。

## 参数说明

| 参数标识    | 参数名称       | 参数说明                                                                                                          |
|:--------|:-----------|:--------------------------------------------------------------------------------------------------------------|
| TPLID   | NASS游牧模板ID | 用于指示系统需要按照哪个模板ID来查询游牧模板数据，操作员可以使用LST HTPLINF命令查询获得。 取值范围：0～67108863 默认值：无。 说明：可选参数。该参数为255表示无效值。              |
| TPLNAME | NASS游牧模板名称 | 用于指示系统需要按照哪个模板名称来查询游牧模板数据，操作员可以使用LST HTPLINF命令查询获得。 取值范围：长度不超过64的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 说明：可选参数。 |

## 使用实例

1. 查询游牧模板，“NASS游牧模板ID”为“10”：

   ```
   LST HNATPL: TPLID=10;
   ```

   ```
   %%LST HNATPL: TPLID=10;%%
   RETCODE = 0 操作成功

   TPLID            TPLNAME                                                        MATCHTYPE           DEFAULTRULE         COMMENT
   10               Templet2                                                       0                   0                   NASS Nomadism Template

   Total count = 1

   There is together 1 report

   ---    END
   ```
2. 查询游牧模板，“NASS游牧模板名称”为“07550011”：

   ```
   LST HNATPL: TPLNAME="07550011";
   ```

   ```
   %%LST HNATPL: TPLNAME="07550011";%%
   RETCODE = 0 操作成功

   TPLID            TPLNAME                                                        MATCHTYPE           DEFAULTRULE         COMMENT
   10               07550011                                                       0                   0                   NASS Nomadism Template

   Total count = 1

   There is together 1 report

   ---    END
   ```

## 输出结果说明

| 输出项名称       | 输出项解释                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|:------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| TPLID       | 用于显示游牧模板ID。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| TPLNAME     | 用于显示游牧模板的名称。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| MATCHTYPE   | 用于显示游牧模板的匹配类型。 取值范围：“0”：表示前向匹配。前向匹配原则表示游牧地址只要前缀相同的都匹配。如果签约的游牧地址模板信息为HSS，则前缀为HSS的游牧地址都能匹配成功，例如携带的游牧地址为“HSS.com”。“1”：表示后向匹配。后向匹配原则表示游牧地址后缀相同的都匹配。如果签约的游牧地址模板信息为huawei.com，则后缀为huawei.com的游牧地址都能匹配成功，例如携带的游牧地址为“HSS.huawei.com”。“2”：表示IP地址段匹配。IP地址段匹配原则表示所有位于“IP地址段起始地址”至“IP地址段结束地址”范围内的游牧地址IP都匹配。如果签约的IP地址段起始地址为10.144.163.100，IP地址段结束地址为10.144.163.120，则位于“10.144.163.100”至“10.144.163.120”范围内的游牧地址IP都能匹配成功，例如携带的游牧地址IP为10.144.163.118。“3”：表示包含匹配。即游牧地址只要包含该地址的都匹配。如果签约的游牧地址模板信息为HSS，则包含HSS的游牧地址都能匹配成功，例如携带的游牧地址为“huawei.HSS.com”、“HSS.com”、“huawei.HSS”。 |
| DEFAULTRULE | 用于显示游牧模板的缺省限制策略，当用户携带的接入位置信息与签约的游牧地址信息匹配失败时决策是否允许用户从此接入位置注册。 取值范围： “0”：表示IMS系统将限制用户注册。“1”：表示IMS系统将允许用户注册。                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| COMMENT     | 用于显示游牧模板的注释。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
