# 修改授权用户数据(MOD AUTHUSER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

操作员通过此命令可以增加/删除远端用户的潜在初始用户或者管理者。

## 注意事项

- INITNUM、FILE是条件可选参数，任何一个参数出现即可，但不能同时出现。
- RECORDCOUNT一定不能与FILE同时存在。
- 潜在初始用户或者管理者要求是本HLR的注册用户。
- 将某一号码从远端号码的潜在初始用户范围内删去，不影响当前已经建立起来的初始用户和远端用户的绑定。

## 参数说明

| 参数标识        | 参数名称           | 参数说明                                                                                                                                                                                                  |
|:------------|:---------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号         | HLR序列号，有效值域为1～255，在容灾版本中设置。                                                                                                                                                                           |
| RMNUM       | 远端号码           | 远端用户号码，E.164格式的编码。 当SET MAPCONF命令中“是否支持远端号码里包含字母”标志位为缺省值“FALSE”时，远端号码为1～15位的十进制数字。 当SET MAPCONF命令中是否支持远端号码中包含字母标志位为“TRUE”时，远端号码为中国GSM-R网络用户号码： 不以2开头时，为1～15位的十进制数字。以2开头时，为可以包含字母和数字的4～10位字符。 说明：必选参数。 |
| PROV        | 增加/删除远端用户的授权范围 | 增加还是删除远端用户的潜在初始用户或者管理者。 TRUE:增加 FALSE:删除                                                                                                                                                              |
| TYPE        | 授权类型           | 是对远端用户的潜在初始用户还是管理者进行授权。 Initiating subscriber: 潜在初始用户 Supervisor: 管理者                                                                                                                                 |
| INITNUM     | 初始用户的MSISDN号码  | 给远端号码授权的潜在初始用户或管理者的MSISDN号码，E.164格式的编码，1～15位的十进制数字。                                                                                                                                                   |
| RECORDCOUNT | 用户个数           | 给远端号码授权的潜在初始用户或管理者的个数，最多可以设置255个。 若只有一个初始用户的MSISDN号码，该参数不必提供。 若该参数提供，代表对以指定的初始用户的MSISDN号码为起始号码，号码连续的RECORDCOUNT个初始用户的MSISDN号码进行操作。 此参数必须与初始用户的MSISDN号码同时出现。                                           |
| FILE        | 初始用户号码文件名      | 初始用户号码文件名，1～16个字母或数字组成。FILE最多包含255个不连续的初始用户的MSISDN号码。                                                                                                                                                 |

## 使用实例

为远端用户的潜在初始用户进行授权，远端用户的远端号码为8613900001234，潜在初始用户的MSISDN为8613865591111。

MOD AUTHUSER: HLRSN=1, RMNUM="8613900001234", PROV=TRUE, TYPE=Initiating subscriber, INITNUM="8613865591111";
