# 查询Service Profile信息模板(LST HSPTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询一个Service Profile基本信息模板记录，一次只能查询一个Service Profile基本信息模板记录，需要输入唯一标识该数据记录的关键参数Service Profile模板ID。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称                | 参数说明                                                                                                                                  |
|:-------|:--------------------|:--------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号              | 可选必选说明：可选参数 参数含义：用于指示系统需要按照哪个HLR序列号来查询Service Profile基本信息模板数据，如果不输入，则表示查询“HLR序列号”为“0”的所有Service Profile基本信息模板数据。                      |
| TPLID  | Service Profile模板ID | 可选必选说明：必选参数 参数含义：用于指示系统需要按照哪个Service Profile模板ID来查询Service Profile基本信息模板数据，一次只能查询一个Service Profile基本信息模板的数据，操作员可以使用LST HTPLINF命令查询获得。 |

## 使用实例

查询Service Profile信息模板。Service Profile模板ID：10。

```
LST HSPTPL: TPLID=10;
```
