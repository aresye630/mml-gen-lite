# 删除5G业务限制模板(RMV NGCSERRESTTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条5G业务限制模板数据记录。

## 注意事项

如果已经通过**ADD NGCRRNODETPL**命令关联该模板，当执行该命令删除5G业务限制模板时，系统会提示“ERR3005:模板已经被使用”的错误信息，该5G业务限制模板不能被删除。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                          |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 可选必选说明：必选参数 参数含义：标识一条5G业务限制模板数据记录的关键字段之一，用于指定系统按照哪个HLR序列号来删除5G业务限制模板数据，操作员可以使用LST HLRSN命令获得。 取值范围：1～255 默认值：无。 配置原则：无。        |
| TPLID  | 模板ID   | 可选必选说明：必选参数 参数含义：标识一条5G业务限制模板数据记录的关键字段之一，用于指定系统按照哪个模板ID来删除5G业务限制模板数据，操作员可使用LST NGCSERRESTTPL命令获得。 取值范围：0～65534 默认值：无。 配置原则：无。 |

## 使用实例

删除5G业务限制模板，“HLR序列号”为“1”，“模板ID”为“8”。

```
RMV NGCSERRESTTPL: HLRSN=1, TPLID=3;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见的错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                 | 处理建议                                                                                                                                                     |
|:--------|:--------|:-------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | “HLR序列号”未定义或者“模板ID”未定义。              | 根据实际情况，重新输入已定义的“HLR序列号”和“模板ID”，可通过LST HLRSN命令查询已定义的“HLR序列号”，通过LST NGCSERRESTTPL命令查询已定义的“模板ID”。                                                           |
| ERR3005 | 模板已经被使用 | “HLR序列号”和“模板ID”参数对应的业务限制模板数据已经被系统使用。 | 根据实际情况，确定是否要删除5G业务限制模板。如果确实需要删除，必须先执行以下操作，然后才能执行该命令删除5G业务限制模板。执行MOD NGCRRNODETPL命令去掉NGC漫游限制模板与5G业务限制模板的关联关系。执行RMV NGCRRNODETPL命令删除与5G业务限制模板关联的NGC漫游限制模板。 |
