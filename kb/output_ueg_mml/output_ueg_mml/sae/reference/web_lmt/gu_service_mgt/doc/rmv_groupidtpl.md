# 删除组ID模板(RMV GROUPIDTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条组ID模板数据记录。

## 注意事项

执行该命令删除组ID模板数据记录后，操作员不能以模板方式给用户签约VGCS/VBS业务。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                 |
|:----------|:-------|:---------------------------------------------------------------------|
| HLRSN     | HLR序列号 | 标识组ID模板数据记录的关键字段之一，用于指定在哪个HLR上删除组ID模板的数据记录，操作员可以使用LST HLRSN命令查询获得。   |
| TPLID     | 模板ID   | 标识组ID模板数据记录的关键字段之一，用于指定需要删除哪个组ID模板的数据记录，操作员可以使用LST GROUPIDTPL命令查询获得。 |
| GROUPTYPE | 组类型    | 标识组ID模板数据记录的关键字段之一，用于指定需要删除哪种组呼类型的数据记录，操作员可以使用LST GROUPIDTPL命令查询获得。  |

## 使用实例

删除“HLR序列号”为“1”的HLR上的一条组ID模板的数据记录。其中，“模板ID”为“1”，“组类型”为“VBS”：

```
RMV GROUPIDTPL: HLRSN=1, TPLID=1, GROUPTYPE=VBS;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                             | 处理建议                                                                                                        |
|:--------|:--------|:-----------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | 可能原因为如下之一：“HLR序列号”或者“模板ID”未定义。 “模板ID”和“组类型”的匹配关系和数据库中实际存在的模板不一致。 | 根据实际情况，重新输入已定义的“HLR序列号”和“模板ID”，可通过LST HLRSN命令查询已定义的“HLR序列号”，通过LST GROUPIDTPL命令查询已定义的“模板ID”和“组类型”在数据库中的匹配关系。 |
