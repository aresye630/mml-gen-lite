# 删除IMPI的HTTP Digest鉴权信息(RMV HHDAINF)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于从HSS的业务数据库中删除一条HTTP Digest鉴权的IMPI的数据记录，或删除一条IMPI的HTTP Digest信息的数据记录。

## 注意事项

- 如果指定IMPI仅支持HDA鉴权并且IMPI未被使用，此操作用于删除IMPI。
- 如果指定IMPI支持HDA鉴权外还支持其它鉴权，此操作仅删除IMPI下的HDA鉴权信息。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                |
|:-------|:-------|:----------------------------------------------------------------------------------------------------|
| IMPI   | IMPI   | 用于指定需要删除Http Digest鉴权的用户私有标识，要求输入的IMPI值符合NAI格式，字母区分大小写。在归属网络中唯一标识一个IMS签约。 取值范围： 长度不超过127的字符串 缺省值： 无 |

## 使用实例

删除IMPI的HTTP Digest鉴权信息。IMPI：impiinfo。

```
RMV HHDAINF: IMPI="impiinfo";
```
