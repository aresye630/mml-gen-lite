# 修改共享iFC模板(MOD HSIFCTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在HSS的业务数据库中修改一个共享iFC模板基本信息，系统通过“共享iFC模板ID”来唯一标识一条共享iFC基本信息模板记录。

## 注意事项

参数TPLNAME和COMMENT必须至少有一个存在，否则HSS返回失败。

## 参数说明

| 参数标识    | 参数名称      | 参数说明                                                                                        |
|:--------|:----------|:--------------------------------------------------------------------------------------------|
| HLRSN   | HLR序列号    | 用于标识一个HLR序列号。 取值范围：0~255 默认值：无。 说明： 可选参数当该参数不输入时，系统默认初始设置值为0。                               |
| TPLID   | 共享iFC模板ID | 标识一条共享iFC模板记录的关键字段（其取值不能被修改），用于指定需要对哪一条共享iFC模板的参数进行修改或调整，操作员可以使用LST HTPLINF命令查询获得。 说明：必选参数。 |
| TPLNAME | 共享iFC模板名称 | 用于具体描述一个共享iFC模板。 取值范围：长度不超过64的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 说明：可选参数。                  |
| COMMENT | 模板注释说明    | 用于具体描述一个共享iFC模板的注释信息。 取值范围：长度不超过512的字符串 默认值：无。 说明：可选参数。                                     |

## 使用实例

修改共享iFC模板基本信息，“共享iFC模板ID”为“10”，“共享iFC模板名称”为“Modify an SiFC Template”：

```
MOD HSIFCTPL: TPLID=10, TPLNAME="Modify an SiFC Template";
```
