# 校验IMPI的SIP Digest鉴权信息(CHK HSDAPWD)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于校验SIP Digest鉴权信息中的“用户名称”与“密码”是否匹配。

## 注意事项

- 如果在“命令输入区”输入命令后再输入各参数，“密码”出于安全原因，仅显示“\*”。
- 如果在“MML命令编辑区”直接输入带参数的命令，命令中的“密码”以明文显示。
- 对于“密码”参数，为提升系统的安全性，建议设置密码时至少包含以下四个类别中的三类：

  - 英文大写字母；
  - 英文小写字母；
  - 数字：0–9；
  - 特殊字符：`~!@#$%^&\*()-\_=+\|[{}];:'",<.>/?；

  **说明** 

  - 输入的特殊字符中包含“;”、“,”时，则需要在特殊字符前添加转义字符“\”。例如参数输入“\;”，输出为“;”。
  - 应避免使用三个或三个以上连续的字母或数字（例如：ABC、123）；
  - 应避免和帐号或者帐号的倒写一样；
  - 应避免使用三个或三个以上连续的相同字符（例如：AAA）。

## 参数说明

| 参数标识      | 参数名称   | 参数说明                                                                                       |
|:----------|:-------|:-------------------------------------------------------------------------------------------|
| HUSERNAME | 用户名称   | 标识一个用户的关键参数之一，用于指示系统验证哪个用户名称。 取值范围：长度不超过127的字符串 默认值：无。 说明：必选参数。                            |
| PWD       | 密码     | 标识一个用户的关键参数之一，用于指示系统被验证的密码。 取值范围：长度不超过128的字符串 默认值：无。 说明：必选参数。 为提升系统的安全性，此参数建议按照注意事项中的描述设置。 |

## 使用实例

校验SIP Digest鉴权信息，“用户名称”为“impiinfo”，“密码”为“pwd”：

```
CHK HSDAPWD: HUSERNAME="impiinfo", PWD="*****";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释   | 原因分析                                                          | 处理建议        |
|----------:|:--------|:--------------------------------------------------------------|:------------|
| 900003523 | 密钥丢失    | 当SET MAPSERV命令中的“随机密钥默认ID”参数为非0，“随机密钥默认ID”参数对应的随机密钥材料不存在或不完整。 | 联系华为技术支持处理。 |
