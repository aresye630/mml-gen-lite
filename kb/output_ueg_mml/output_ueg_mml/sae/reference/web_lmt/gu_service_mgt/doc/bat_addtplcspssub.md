# CSPS批量模板开户(BAT ADDTPLCSPSSUB)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令仅用于SOAP接口，批量对一个或多个用户采用CSPS模板进行开户，并设置用户APN数据信息。为具有同样业务类型的用户业务发放时使用。

## 注意事项

- 开户前，请使用**ADD KI**命令加载KI。

- “IMSI”、“MSISDN”参数不能与“IMSI/MSISDN文件名”参数同时配置。
- “用户个数”和“IMSI/MSISDN文件名”有且只能有一个参数出现。

## 参数说明

| 参数标识         | 参数名称           | 参数说明                                                                                                                                                                                                                                             |
|:-------------|:---------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN        | HLR序列号         | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                                                     |
| USERNUM1     | IMSI           | 用于标识需要进行模板开户的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                            |
| USERNUM2     | MSISDN         | 用于标识需要进行模板开户的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                          |
| RECORDCOUNT  | 用户个数           | 用于标识需要模板开户的用户数目。 当需要为连续号码的多个用户开户时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行操作。 取值范围：1～100000 默认值：无。 说明：该参数为可选参数，是对连续号码的多个用户开户，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。                                    |
| FILE         | IMSI/MSISDN文件名 | 用于标识待开户用户的IMSI/MSISDN批操作文件。 IMSI/MSISDN批操作文件包含多个不连续的待开户用户的IMSI号码和MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“addtplsub.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见开户批操作文件格式。 取值范围：1～35个字母或十进制数字组成的字符串。 默认值：无。                                          |
| CSPSTPLID    | CSPS用户模板ID     | 用于标识CSPS用户开户模板ID。该参数必须先由ADD SUBTPL命令定义，然后才能在此处引用，且ADD SUBTPL命令参数“用户模板类型”必须为“CSPSTPL”。                                                                                                                                                            |
| PSUSERTPLID  | PS用户模板ID       | 用于标识PS用户模板ID。该参数必须先由ADD PSUSERTPL命令定义，然后才能在此处引用。                                                                                                                                                                                                 |
| PSCNTXIDLIST | PS域上下文索引值列表    | 用于标识PS域上下文索引值列表。 配置原则：由最多5个上下文索引值以&连接组成且每个索引值需要用""标识，在字符"前需要添加转义字符\（例如：\"1\"&\"2\"），当只有一个上下文索引值时，参数不携带字符""和&。 每个上下文索引值的取值范围为1～50。 上下文索引值的取值不能重复。 上下文索引值必须是系统中用户模板签约的上下文索引值。 该参数必须和“PS域接入点名称列表”同时输入，且每个上下文索引值与接入点名称一一对应。 取值范围：1～24位字符的字符串。 默认值：无。 |
| PSAPNLIST    | PS域接入点名称列表     | 用于标识PS域接入点名称列表。 配置原则：由最多5个接入点名称以&连接组成且每个接入点名称需要用""标识，在字符"前需要添加转义字符\（例如：\"huawei1.com\"&\"huawei2.com\"），当只有一个接入点名称时，参数不携带字符""和&。 每个接入点名称的取值范围为1～63位字符的字符串。 该参数必须和“PS域上下文索引值列表”同时输入，且每个接入点名称与上下文索引值一一对应。 取值范围：1～339位字符的字符串。 默认值：无。                |

## 使用实例

为“IMSI/MSISDN文件名”为“IMSI\_SUB.txt”的用户开户，命令如下:

```
BAT ADDTPLCSPSSUB: HLRSN=1, FILE="IMSI_SUB.txt", CSPSTPLID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释      | 原因分析                                                                            | 处理建议                                                                                                                         |
|:--------|:-----------|:--------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值     | 可能原因为如下之一：参数“IMSI”的取值不是6～15位十进制数字组成的字符串。参数“MSISDN”的取值不是1～15位十进制数字组成的字符串。        | 根据实际情况，重新输入“IMSI”或“MSISDN”的取值，确保其取值符合要求。                                                                                     |
| ERR1005 | 文件未找到      | “IMSI/MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                     | 通过PGW Web LMT的文件上传功能将文件上传到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                                    |
| ERR1025 | 批操作文件中格式非法 | “IMSI/MSISDN文件名”参数对应的批操作文件格式不正确。                                                | 请根据开户批操作文件格式，修改对应的批操作文件格式。                                                                                                   |
| ERR3002 | 用户已存在      | 输入的“IMSI”对应的用户已经开户。                                                             | 核实用户的IMSI号码，使用LST SUB命令输入待开户用户的“IMSI”，若查询结果返回错误“用户未开户”，则可使用本命令给用户开户。                                                         |
| ERR3048 | 未加载KI      | 用户开户之前，未配置用户鉴权密钥KI。                                                             | 执行ADD KI命令添加用户鉴权密钥KI。                                                                                                        |
| ERR3097 | HLR序列号未定义  | 参数“HLR序列号”的取值未预先定义，对应序号的HLR不存在。                                                 | 根据实际情况选择：如果需要用户在输入的“HLR序列号”开户，则执行ADD HLRSN命令，添加所需的HLR序列号，然后再引用。如果需要用户在已定义的“HLR序列号”开户，则执行LST HLRSN先查询已定义的HLR序列号，重新输入“HLR序列号”。 |
| ERR3196 | 参数冲突       | 可能原因为如下之一：“IMSI”或“MSISDN”与“IMSI/MSISDN文件名”参数同时设置。“用户个数”和“IMSI/MSISDN文件名”参数同时设置。 | 根据实际情况，重新输入参数，并确保满足以下要求：“IMSI”或“MSISDN”不和“IMSI/MSISDN文件名”参数同时出现。“用户个数”和“IMSI/MSISDN文件名”有且只能有一个参数出现。                          |
