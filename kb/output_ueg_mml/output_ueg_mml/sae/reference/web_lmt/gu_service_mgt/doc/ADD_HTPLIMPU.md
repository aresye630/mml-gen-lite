# 根据模板信息新增IMPU用户数据(ADD HTPLIMPU)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中，利用ServiceProfile模板和IMPU模板数据，增加一个IMPU用户。

该命令的参数索引关系如图1所示。

**图1** 命令的参数索引关系图

## 注意事项

当通过**SET HSYSTEMPARA**命令设置“USINGHLRSNFORIMS（是否启用IMS-HSS的分权分域功能）”软参为“TRUE(TRUE)”时，执行该命令时会返回错误。

## 参数说明

| 参数标识      | 参数名称               | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:----------|:-------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMPI      | IMPI               | 用于新增一个IMPU对应的IMPI，IMPI必须通过ADD HIMPI或者ADD HSUB开户才能在此处索引。要求输入的IMPI值符合NAI格式，字母区分大小写。 取值范围： 长度不超过127的字符串 默认值： 无。 说明：必选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| IMPU      | IMPU               | 用于指定一个新IMPU。该参数的配置原则是：新开的IMPU必须与已有的IMPU不同。输入的IMPU值符合SIP URI或TEL URI格式，字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：必选参数。当IMPU为通配类型时，IMPU的格式必须含有“!.*!”且符合TEL URI和SIP URI格式的通配IMPU规则，目前支持以下4种格式，以固定号码为3314529的SIP URI格式举例如下：格式1：sip:3314529!.*!@huawei.com。格式2：sip:3314529![mnp].*!@huawei.com。例如sip:3314529![247].*!@huawei.com，以下号码可以匹配：sip:33145292!.*!@huawei.com sip:33145294!.*!@huawei.com sip:33145297!.*!@huawei.com 格式3：sip:3314529![m-p].*!@huawei.com。例如sip:3314529![2-4].*!@huawei.com，以下号码可以匹配：sip:33145292!.*!@huawei.com sip:33145293!.*!@huawei.com sip:33145294!.*!@huawei.com 格式4：格式2和格式3的混合格式。例如sip:3314529![02-57-9].*!@huawei.com，以下号码可以匹配：sip:33145290!.*!@huawei.com sip:33145292!.*!@huawei.com sip:33145293!.*!@huawei.com sip:33145294!.*!@huawei.com sip:33145295!.*!@huawei.com sip:33145297!.*!@huawei.com sip:33145298!.*!@huawei.com sip:33145299!.*!@huawei.com 注意事项： 对于格式2、格式3和格式4，要求m、n、p只能代表取值范围为0-9的一位数字（m<n<p），并且m、n、p的取值不能重复。上述4种格式号码配置时不能出现号段重复，比如通配IMPU号码sip:3314529!.*!@huawei.com和sip:3314529![247].*!@huawei.com就含有sip:33145292!.*!@huawei.com、sip:33145294!.*!@huawei.com和sip:33145297!.*!@huawei.com三个重复号段，是不允许同时配置的。 |
| IMPUTYPE  | IMPU的类型            | 用于标识新增IMPU的类型。 取值范围：DIMPU(DIMPU)：表示新增的IMPU为非通配型。WIMPU(WIMPU)：表示新增的IMPU为通配型。 默认值：无。 说明：可选参数。一个通配IMPU代表一组IMPU。该通配IMPU或者一个能匹配到此通配IMPU的特定IMPU（specific IMPU）发起注册，均能达到注册整组IMPU的目的。注册完成后，所有匹配到该通配IMPU的特定IMPU（specific IMPU）均能够在HSS取到相同的业务签约数据和路由信息。系统允许的通配IMPU和通配PUSI数量最大为120000个。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| SPTPLID   | ServiceProfile模板ID | 用于唯一标识一个Service Profile模板，通过ADD HSPTPL定义，然后才能在此处索引。 取值范围：0～254 默认值：无。 说明：可选参数。 配置原则：ADD HSPTPL命令中“Service Profile模板ID”参数取值范围为0~1024，本参数仅支持引用0~254，超过该范围取值，系统上报“900003240：SP模板ID不存在”错误提示。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| IMPUTPLID | IMPU基本信息模板ID       | 用于唯一标识一个IMPU模板，通过ADD HIMPUTPL定义，然后才能在此处索引。 取值范围：0～254 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

## 使用实例

1. 根据模板信息新增IMPU用户数据。“IMPI”为“impiinfo”，“IMPU”为“sip:impuinfo@huawei.com”，“ServiceProfile模板ID”为“1”，“IMPU基本信息模板ID”为“1”：

   ```
   ADD HTPLIMPU: IMPI="impiinfo", IMPU="sip:impuinfo@huawei.com", SPTPLID=1, IMPUTPLID=1;
   ```
2. 2. 根据模板信息新增IMPU用户数据。“IMPI”为“impiinfo”，“IMPU”为“tel:+33145297![247].\*!”，“IMPUTYPE”为“WIMPU（WIMPU）”，“ServiceProfile模板ID”为“1”，“IMPU基本信息模板ID”为“1”：

   ```
   ADD HTPLIMPU: IMPI="impiinfo", IMPU="tel:+33145297![247].*!", IMPUTYPE=WIMPU, SPTPLID=1, IMPUTPLID=1;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释                    | 原因分析                                                                       | 处理建议                                                                                                                      |
|----------:|:-------------------------|:---------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------|
| 900003100 | IMPU已存在，或与IMPU同名的PUSI已存在 | 可能原因如下之一：实际输入的参数“IMPU”已经签约过IMS业务数据。实际输入的参数“IMPU”与IMS网络中已存在的PUSI同名。         | 根据实际情况，重新输入参数，确保满足以下两点：输入的“IMPU”没有签约IMS业务数据。可通过LST HSUB命令查询IMPU是否已签约。输入的“IMPU”与IMS网络已存在的PUSI不同名。可通过LST HPSI命令查询PUSI是否已存在。 |
| 900003240 | SP模板ID不存在                | 输入的Service Profile模板ID在系统中未定义。                                             | 根据实际情况，重新输入Service Profile模板ID，确保输入的Service Profile模板ID已定义。                                                               |
| 900003524 | 分权分域模式下不支持此命令            | SET HSYSTEMPARA命令的“USINGHLRSNFORIMS（是否启用IMS-HSS的分权分域功能）”软参设置为“TRUE(TRUE)”。 | 无需处理。                                                                                                                     |
