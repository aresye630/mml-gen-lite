# 根据模板新增AKA鉴权信息(ADD HTPLKI)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中，利用AKA模板，为一个IMPI增加AKA鉴权数据。

## 注意事项

- 如果在“命令输入区”输入命令后再输入各参数，“KI密钥”出于安全原因，仅显示“\*”。
- 如果在“MML命令编辑区”直接输入带参数的命令，命令中的“KI密钥”以明文显示。
- 当**SET MAPCONF**命令中的“是否启用随机密钥”参数为“TRUE”，执行该命令时如果KI/OPC未使用K4进行加密，同时未执行**SET DEFAULTK2SNO**命令设置默认K2，则执行该命令时会返回错误。

## 参数说明

| 参数标识     | 参数名称        | 参数说明                                                                           |
|:---------|:------------|:-------------------------------------------------------------------------------|
| IMPI     | IMPI        | 用于新增一个IMPI，输入的IMPI必须符合NAI格式。 取值范围： 长度不超过127的字符串 缺省值： 无                         |
| K        | KI密钥        | 用于新增一个KI，该参数值域为BCD字符串，最大长度为32。要求输入16进制字符，字母不区分大小写。 取值范围： 长度等于32的16进制字符串 缺省值： 无 |
| AKATPLID | AKA鉴权信息模板ID | 用于唯一标识一个AKA模板，通过ADD HAKATPL定义，然后才能在此处索引。 取值范围： 0～254 缺省值： 无                    |

## 使用实例

根据模板新增AKA鉴权信息。IMPI：impiinfo，KI密钥：1234567890abcdef1234567890abcdef，AKA鉴权信息模板ID：1。

```
ADD HTPLKI: IMPI="impiinfo", K="*****", AKATPLID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释   | 原因分析                                                                                      | 处理建议                                                                                       |
|----------:|:--------|:------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------|
| 900003522 | 默认K2不存在 | 当SET MAPCONF命令中的“是否启用随机密钥”参数为“TRUE”，执行该命令时KI/OPC未使用K4进行加密，同时未执行SET DEFAULTK2SNO命令设置默认HK2。 | 当SET MAPCONF命令中的“是否启用随机密钥”参数为“TRUE”，执行该命令时确保使用K4对KI/OPC进行加密，或已执行SET DEFAULTK2SNO命令设置默认HK2。 |
| 900003523 | 密钥丢失    | 当SET MAPSERV命令中的“随机密钥默认ID”参数为非0，“随机密钥默认ID”参数对应的随机密钥材料不存在或不完整。                             | 联系华为技术支持处理。                                                                                |
