# 删除AMF 3GPP注册信息数据（RMV AMF3GPPREGINFO）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除AMF 3GPP注册信息数据。

## 注意事项

- “IMSI”和“IMSI文件名”不能同时输入，否则会提示参数错误。
- “用户个数”参数和“IMSI文件名”不能同时输入，否则会提示参数错误。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                             |
|:------------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI    | 可选必选说明：条件可选参数 参数含义：用于标识需要删除AMF 3GPP注册信息业务的用户的IMSI号码。 取值范围：6~15位的十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                      |
| RECORDCOUNT | 用户个数    | 可选必选说明：条件可选参数 参数含义：用于标识需要删除AMF 3GPP业务的用户数目。 取值范围：1~100000。 默认值：无。 配置原则：当需要删除连续号码的多个用户的静态数据时配置。配置后，系统将会从已指定的IMSI号码开始，删除连续号码的多个用户的静态数据。                                                            |
| IMSIFILE    | IMSI文件名 | 可选必选说明：条件可选参数 参数含义：用于标识IMSI批操作文件。 取值范围：1~16位字母或十进制数字组成的字符串。 默认值：无。 配置原则：IMSI批操作文件包含多个不连续的需要删除AMF 3GPP的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“rmvamf3gpp.txt”，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 |

## 使用实例

1. 删除“IMSI号码”为“460000009123456”的用户注册信息数据。

   ```
   RMV AMF3GPPREGINFO: IMSI="460000009123456";
   ```
2. 删除“IMSI号码”为“460000009123456”、“460000009123457”、“460000009123458”的3个连续用户的注册信息数据。

   ```
   RMV AMF3GPPREGINFO: IMSI="460000009123456", RECORDCOUNT=3;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1 错误码列表所示。

| 错误码     | 错误码解释   | 原因分析                                       | 处理建议                                                                              |
|:--------|:--------|:-------------------------------------------|:----------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 参数“IMSI”的取值不是6～15位十进制数字组成的字符串。             | 根据实际情况，重新输入“IMSI”的取值，确保其取值符合要求。                                                   |
| ERR3001 | 用户未开户   | 用户的IMSI号码输入错误，实际输入的参数“IMSI”对应的用户未开户。       | 核实IMSI号码，确保其对应的用户为5G用户并验证其正确性，如果确定输入无误，证明实际输入的参数“IMSI”对应的用户未开户，请参考ADD SUB页面给用户开户。 |
| ERR1010 | 参数冲突    | “IMSI”和“IMSI文件名”同时输入。“用户个数”和“IMSI文件名”同时输入。 | “IMSI”和“IMSI文件名”不能同时输入，“用户个数”和“IMSI文件名”不能同时存在。                                    |
