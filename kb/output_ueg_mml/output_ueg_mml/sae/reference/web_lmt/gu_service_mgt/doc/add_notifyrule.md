# 增加数据变更通知分发的规则(ADD NOTIFYRULE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在UDM中增加一条数据变更通知分发规则的数据记录。

订阅通知是USCDB的基本能力，在MCI（Message Call Interface）订阅通知机制中，对于用户数据的变化，在多个FE公用一个BE时，BE会将所有的通知消息都发送到高优先级的FE，导致高优先级的FE和信令资源消耗过高。为了减轻高优先级的FE承载压力，BE提供了一套新的通知机制，可以将特定号段/HLRSN用户的订阅通知消息以不同优先级发送到特定的FE。该命令用于在新的通知机制下增加特定号段对应多个不同优先级的FE标识信息以便于后续BE通过调用这些信息完成新的订阅通知消息下发。

在同时配置了“第一优先级Location标识”，“第二优先级Location标识”和“第三优先级Location标识”时，USCDB按照优先级发送给不同优先级的FE，如果发送高优先级FE失败后，则发送到次优先级的FE。这样USCDB可以按照优先级分发到不同FE实现容灾功能。

## 注意事项

- 该命令用于FE适配BE新的MCI订阅通知机制，在BE按照号段/HLRSN进行订阅通知分发后不但会影响订阅通知的目的端、FE局点的CPU使用和网络信令负荷，而且会降低BOSS性能和增加时延。
- 系统中增加的同一种“分发类型”的规则数据记录数不能超过1000条。
- 号段参数在处理时的匹配原则均为最大匹配原则。

## 参数说明

| 参数标识               | 参数名称                | 参数说明                                                                                                                                                                                                                                                         |
|:-------------------|:--------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| RULE_TYPE          | 分发类型                | 用于标识数据变更时BE将订阅通知消息发送到FE时对应的分发类型。 取值范围： HLRSN（0）：发送到HLRSN对应的FE。IMSI_PREFIX（1）：发送到IMSI号段对应的FE。MSISDN_PREFIX（2）：发送到MSISDN号段对应的FE。PI_PREFIX（3）：发送到IMPI或者PISI号段对应的FE。PU_PREFIX（4）：发送到IMPU或者PUSI号段对应的FE。SUBID_PREFIX（5）：发送到SUBID号段对应的FE。 默认值：无。                    |
| HLRSN              | HLR序列号              | 仅当“分发类型”参数取值为“HLRSN”时该参数有效，用于标识变更通知分发规则中待增加的本地HLR。                                                                                                                                                                                                           |
| IMSI_PREFIX        | IMSI前缀              | 仅当“分发类型”参数取值为“IMSI_PREFIX”时该参数有效，用于标识变更通知分发规则中待增加的IMSI号段。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                      |
| MSISDN_PREFIX      | MSISDN前缀            | 仅当“分发类型”参数取值为“MSISDN_PREFIX”时该参数有效，用于标识变更通知分发规则中待增加的MSISDN号段。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                  |
| PI_PREFIX          | IMPI或者PISI前缀        | 仅当“分发类型”参数取值为“PI_PREFIX”时该参数有效，用于标识变更通知分发规则中待增加的IMPI或者PISI号段。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                  |
| PU_PREFIX          | IMPU或者PUSI前缀        | 仅当“分发类型”参数取值为“PU_PREFIX”时该参数有效，用于标识变更通知分发规则中待增加的IMPU或者PUSI号段。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                  |
| SUBID_PREFIX       | SUBID前缀             | 仅当“分发类型”参数取值为“SUBID_PREFIX”时该参数有效，用于标识变更通知分发规则中待增加的SUBID号段。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                    |
| LOCATION_ID        | 第一优先级Location标识     | 用于标识第一优先级变更通知分发规则中待增加的号段/HLRSN对应的FE标识。 取值范围：0～512 默认值：无。 配置原则：仅当“分发类型”参数取值为“IMSI_PREFIX”，“MSISDN_PREFIX”，“PI_PREFIX”，“PU_PREFIX”或“SUBID_PREFIX”并且“Location取值非法时是否下发成功”取值为“TRUE”时，该参数才可以设置“0”。                                                                |
| SECOND_LOCATION_ID | 第二优先级Location标识     | 用于标识第二优先级变更通知分发规则中待增加的号段/HLRSN对应的FE标识。 取值范围：1～512 默认值：无。                                                                                                                                                                                                     |
| THIRD_LOCATION_ID  | 第三优先级Location标识     | 用于标识第三优先级变更通知分发规则中待增加的号段/HLRSN对应的FE标识。 取值范围：1～512 默认值：无。                                                                                                                                                                                                     |
| IS_ILLEGAL_SUCCESS | Location取值非法时是否下发成功 | 仅当“分发类型”参数取值为“IMSI_PREFIX”，“MSISDN_PREFIX”，“PI_PREFIX”，“PU_PREFIX”或“SUBID_PREFIX”时该参数有效。 用于标识Location取值为非法值（0）时MCI通知消息是否按照不下发处理，直接返回成功。 取值范围： TRUE：Location取值为非法值（0）时不下发MCI消息，按照成功处理。FALSE：按照Location优先级下发MCI消息。 默认值：无。 配置原则：执行该命令并且不输入该参数时，系统会设置初始值“FALSE”。 |

## 使用实例

1. 为“HLR序列号”为“3”的虚拟HLR增加一条数据变更通知分发规则的数据记录信息，“第一优先级Location标识”为“1”，命令如下：

   ```
   ADD NOTIFYRULE: RULE_TYPE=HLRSN, HLRSN=3, LOCATION_ID=1;
   ```
2. 为“HLR序列号”为“4”的虚拟HLR增加一条数据变更通知分发规则的数据记录信息，“第一优先级Location标识”为“1”，“第二优先级Location标识”为“2”，“第三优先级Location标识”为“3”，命令如下：

   ```
   ADD NOTIFYRULE: RULE_TYPE=HLRSN, HLRSN=4, LOCATION_ID=1, SECOND_LOCATION_ID=2, THIRD_LOCATION_ID=3;
   ```

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。
