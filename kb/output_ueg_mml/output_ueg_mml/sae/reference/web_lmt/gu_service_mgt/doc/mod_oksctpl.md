# 修改业务区域限制模板(MOD OKSCTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此命令用来修改业务区域限制模板数据。

## 注意事项

此模板被修改后，签约此模板的用户数据也会被修改，修改后的数据在用户新注册时会下发到网络。

## 使用实例

修改1号业务区域限制模板：

- “模板名”为“OKSCTPL”。
- “话音业务”为“TS11-0”。
- “短消息业务”为“TS21-1”。
- “传真业务”为“TS61-0”。
- “承载业务”为“BS20-1”。
- “GPRS业务”为“PERMISSION”。

命令如下：

MOD OKSCTPL: HLRSN=1, TPLID=1, TPLNAME="OKSCTPL", TELE=TS11-0, SMS=TS21-1, FAX=TS61-0, BS=BS20-1, GPRS=PERMISSION;
