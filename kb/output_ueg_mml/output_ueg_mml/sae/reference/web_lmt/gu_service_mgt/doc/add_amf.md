# 增加AMF(ADD AMF)

## 命令功能

该命令用于在UDM中添加鉴权管理域AMF的取值、各域SQN的IND取值、Milenage鉴权算法参数的取值。在UMTS鉴权中，AMF和SQN都是AUTN的重要组成部分。AMF用于计算MAC-S和MAC-A，SQN是实现UE对网络合法性验证的一个重要参数。终端在保存SQN信息时，会根据SQN IND的取值不同，将SQN保存在不同的位置。一般针对不同的网络，SQN IND也会设置为不同的取值。

在该命令中，系统通过以下关键参数的组合来唯一标识一条AMF鉴权管理域信息：

- “HLR序列号”
- “AMF序列号”

## 注意事项

- 仅当参数“是否设置各域SQN的IND取值”为“TRUE”时，设置各域SQN的IND取值的才有效，否则系统会默认采用**SET MAPSERV**命令中配置参数计算鉴权向量或使用**ADD SQNINDINFO**命令配置的各域SQN的IND范围内轮询使用IND计算鉴权向量。
- 仅当参数“是否使用Milenage鉴权算法的控制参数”为“TRUE”时，设置的Milenage鉴权算法参数值才有效，否则系统会默认采用**SET MAPSERV**命令中配置参数。
- 同一个“HLR序列号”中增加的AMF鉴权管理域信息记录数不能超过1000条。
- 当**SET MAPCONF**中“是否支持C和R参数加密存储”为“TRUE”
  - 执行该命令输入C1～C5、R1～R5时，系统对参数C1～C5、R1～R5进行加密处理。
  - 执行该命令未输入C1～C5、R1～R5时，则系统根据该命令中C1～C5、R1～R5的默认值对其进行加密处理。
  - 执行**ADD HLRSN**命令时，系统默认会添加两条AMF记录，系统会对该记录的C1～C5、R1～R5做加密处理。
- 当**SET MAPCONF**中“是否支持C和R参数加密存储”为“FALSE”
  - 执行该命令输入C1～C5、R1～R5时，系统不对参数C1～C5、R1～R5进行加密处理。
  - 执行该命令未输入C1～C5、R1～R5时，则系统根据C1～C5、R1～R5的默认值赋值不对其进行加密处理。
  - 执行**ADD HLRSN**命令时，系统默认会添加两条AMF记录，系统不对该记录的C1～C5、R1～R5做加密处理。
- 执行**ADD HLRSN**命令时，系统默认会添加两条AMF记录。
  - 当**SET MAPSERV**中“SAE-HSS AES加密模式”参数为“ECB”时，这两条AMF记录的IV字段取值为全F。
  - 当**SET MAPSERV**中“SAE-HSS AES加密模式”参数为“CBC”时，这两条AMF记录的IV字段取值不为全F。
- 当**SET MAPCONF**命令中的“是否启用随机密钥”参数为“TRUE”时，如果未执行**SET MAPSERV**命令设置“随机密钥默认ID”参数为系统已存在的随机密钥，则执行该命令时会返回错误：“ERR4086 随机密钥默认ID未设置”。
- HSM加密场景下，C1~C5、R1~R5值使用HSM上配置的值，本命令配置的值无效。

## 使用实例

1. 添加一个AMF鉴权数据，“HLR序列号”设置为“1”，“AMF序列号”设置为“3”，“AMF值”设置为“724C”，“是否设置各域SQN的IND取值”设置为“FALSE”：

   ```
   ADD AMF: HLRSN=1, AMFSNO=3, AMFVALUE="*****", SQNINDPROV=FALSE;
   ```
2. 添加一个AMF鉴权数据，同时设置各域SQN的IND取值，各参数分别设置为：
   - “HLR序列号”为“1”
   - “AMF序列号”为“1”
   - “AMF值”为“724C”
   - “是否设置各域SQN的IND取值”为“TRUE”
   - “CS域SQN的IND取值”为“0”
   - “PS域SQN的IND取值”为“1”
   - “EPS域SQN的IND取值”为“16”
   - “IMS域SQN的IND取值”为“2”
   - “NON-3GPP域SQN的IND取值”为“17”
   - “BSF域SQN的IND取值”为“3”
   - “5GC域SQN的IND取值”为“18”
