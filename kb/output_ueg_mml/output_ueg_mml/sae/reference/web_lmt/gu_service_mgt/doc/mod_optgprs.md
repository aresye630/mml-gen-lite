# 修改优化GPRS/EPS业务(MOD OPTGPRS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此操作用于修改用户优化GPRS/EPS签约信息。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”是条件可选参数，有且只能有一个参数出现。
- “用户个数”参数一定不能与“IMSI文件名”或“MSISDN文件名”参数同时存在。
- 给用户添加新PDP/PDN上下文、修改用户现有PDP/PDN上下文、用户修改PDP/PDN上下文、删除用户PDP/PDN上下文参数设置与**SET MAPSERV**命令的“OPTGPRS命令APN签约方式”参数取值相关：
  - FALSE：不支持同时输入“APN模板ID”和“接入点名称”参数。
    - 如果给用户添加新PDP/PDN上下文，“操作类型”设置为“ADDPDPCNTX”，同时需要设置“APN模板ID”或“接入点名称”、“QoS模板ID”、“PDP/PDN类型”、“PDP/PDN地址标识”、“是否允许用户从VPLMN访问PDP/PDN网络”和“计费特性”。如“PDP/PDN地址标识”参数为“STATIC”，“PDP/PDN地址”参数必须存在；否则，“PDP/PDN地址”参数不能存在。
    - 如果修改用户现有PDP/PDN上下文，“操作类型”设置为“MODPDPCNTX”，“PDP/PDN上下文索引值”、“APN模板ID”或“接入点名称”参数至少需要输入其中一个参数，且不能同时输入“APN模板ID”和“接入点名称”参数。
    - 当给用户修改PDP/PDN上下文时，“APN模板ID”和“接入点名称”都可以作为APN模板的索引，只能输入一个，不能同时输入。
    - 如果删除用户PDP/PDN上下文，“操作类型”设置为“RMVPDPCNTX”，同时需要设置输入“PDP/PDN上下文索引值”、“APN模板ID”或“接入点名称”中的任意一个参数值。
  - TRUE：支持同时输入“APN模板ID”和“接入点名称”参数。
    - 如果给用户添加新PDP/PDN上下文，“操作类型”设置为“ADDPDPCNTX”，支持“APN模板ID”和“接入点名称”同时输入，同时需要设置“QoS模板ID”、“PDP/PDN类型”、“PDP/PDN地址标识”、“是否允许用户从VPLMN访问PDP/PDN网络”和“计费特性”。如“PDP/PDN地址标识”参数为“STATIC”，“PDP/PDN地址”参数必须存在；否则，“PDP/PDN地址”参数不能存在。
    - 如果修改用户现有PDP/PDN上下文，“操作类型”设置为“MODPDPCNTX”，“PDP/PDN上下文索引值”、“APN模板ID”或“接入点名称”参数至少需要输入其中一个参数，“APN模板ID”和“接入点名称”可以同时输入。
    - 给用户修改PDP/PDN上下文，“APN模板ID”和“接入点名称”都可以作为APN模板的索引，“APN模板ID”和“接入点名称”可以同时输入。
    - 如果删除用户PDP/PDN上下文，“操作类型”设置为“RMVPDPCNTX”，同时需要设置输入“PDP/PDN上下文索引值”、“APN模板ID”和“接入点名称”任意一个参数值。

- 如果去签约GPRS/EPS业务，“操作类型”设置为“RMVALLCNTX”，将删除用户所有GPRS/EPS数据，清除GPRS/EPS签约标志位。
- 如是修改全局计费特性，“操作类型”设置为“MODGLOBALCHARING”，需要设置新的全局计费特性值。
- 当给用户增加PDP/PDN上下文时，如果系统支持ContextID自动排序生成，则“PDP/PDN上下文索引值”可以不设置；反之，这个参数则一定要设置。
- 一个用户最多可定义50个PDP/PDN上下文。
- 同一用户的不同PDP上下文中PDP/PDN类型、PDP/PDN地址、APN模板ID不能够全部相同。
- 当删除用户所有4G的APN时，触发的CancelLocation消息中信元cancelType的取值由**SET MAPSERV**命令中参数“cancelType的取值”控制。
- 系统中必须存在且只能存在一个默认APN模板。
- 系统中存在多个EPS\_APN或BOTH类型的APN，“操作类型”为“RMVPDPCNTX”时，不能删除默认APN模板 。
- 当用户已签约静态IPv4地址且“PDP/PDN类型”参数为“IPV4”，或已签约静态IPv6地址且“PDP/PDN类型”参数为“IPV6”，再携带以下参数执行该命令进行双栈改造会导致用户已签约的静态IPv4或IPv6地址被删除。
  - “操作类型”参数为“MODPDPCNTX”。
  - “PDP/PDN类型”参数为“IPV4IPV6”。
  - “PDP/PDN地址标识”和“PDP/PDN地址2标识”为“DYNAMIC”或不输入这两个参数。
  - 不输入“PDP/PDN地址”和“PDP/PDN IPV4地址”参数。

## 使用实例

例1：修改非EPS用户优化GPRS签约信息。

给IMSI号为123456789012345的用户增加PDP模板数据和QoS模板数据，APN模板号为3，QoS模板号为3。命令如下：

```
MOD OPTGPRS: IMSI="123456789012345", PROV=ADDPDPCNTX, CNTXID=1, APNTPLID=3, QOSTPLID=3, PDPTYPE=IPV4, ADDIND=STATIC, PDPADD="10.64.12.11", VPLMN=TRUE, CHARGE=HOT;
```

例2：修改EPS用户签约信息。

给IMSI号码为460000009123456的EPS用户新增一条PDN上下文，EPS APN模板号为100，EPS QoS模板号为100，PDN地址是静态地址，PDN地址类型为IPV4IPV6，PDN IPV6地址为fe80:0000:0000:034B:0034:0006:FFFF:0001，允许访问VPLMN的APN，计费特性为NORMAL。命令如下：

```
MOD OPTGPRS: IMSI="460000009123456", PROV=ADDPDPCNTX, CNTXID=1, APN_TYPE=EPS_APN, APNTPLID=100, DEFAULTCFGFLAG=TRUE, EPS_QOSTPLID=100, ADDIND=STATIC, PDPTYPE=IPV4IPV6, PDPADD="fe80:0000:0000:034B:0034:0006:FFFF:0001", VPLMN=TRUE, CHARGE=NORMAL;
```

例3：删除EPS用户签约信息。

删除IMSI号码为460000009123456的EPS用户的PDN上下文，PDN上下文索引值为2。命令如下：

```
MOD OPTGPRS: IMSI="460000009123456", PROV=RMVPDPCNTX, CNTXID=2;
```
