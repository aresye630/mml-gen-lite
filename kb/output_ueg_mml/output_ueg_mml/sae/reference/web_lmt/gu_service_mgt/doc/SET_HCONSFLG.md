# 设置用户数据一致性标识(SET HCONSFLG)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HSS的业务数据库中设置指定“SUBID”或“IMPU”的“一致性标识”。

## 注意事项

只允许同时用“SUBID”或“IMPU”中一种签约方式为用户签约一致性标识，如果需要改成另一种签约方式，需要先将原有方式去签约才能使用新的签约方式。

- 当使用“SUBID”签约/去签约一致性标识时，该用户对应的所有IMPU均签约/去签约了一致性标识。
- 当使用“IMPU”签约/去签约一致性标识时，该用户下与此“IMPU”在同一别名组下的所有IMPU均签约/去签约了一致性标识。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                                                                                                  |
|:--------|:-------|:----------------------------------------------------------------------------------------------------------------------|
| SUBID   | SUBID  | 标识一条IMS签约用户数据记录的关键字段（其取值不能被修改），用于指定需要对哪一条IMS签约用户数据记录的参数进行修改或调整，操作员可以使用LST HSUB命令查询获得。 取值范围：长度不超过127的字符串 默认值：无。        |
| IMPU    | IMPU   | 用于标识待设置用户数据一致性标识的“IMPU”。 取值范围：长度不超过127的字符串 配置原则： 该IMPU必须已经存在。输入的IMPU值符合SIP URI或TEL URI格式，字母区分大小写。 默认值：无。              |
| CONSFLG | 一致性标识  | 用于标识一个IMS签约用户是否需要保持CS与IMS业务数据一致性。 取值范围：TRUE(TRUE)：表示该用户需要保持CS与IMS业务数据一致性。FALSE(FALSE)：表示该用户不需要保持CS与IMS业务数据一致性。 默认值：无。 |

## 使用实例

设置用户数据一致性标识，“SUBID”为“+862970119992@domain50.huawei.com”，“一致性标识”为“TRUE(TRUE)”：

```
SET HCONSFLG: SUBID="+862970119992@domain50.huawei.com", CONSFLG=TRUE;
```
