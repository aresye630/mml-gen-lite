# 修改用户UE应用类型(MOD UEUSAGETYPE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于为用户签约或去签约UE应用类型（UE-Usage-Type）的业务数据。该命令允许对只开卡未开户用户的UE应用类型（UE-Usage-Type）进行修改。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识            | 参数名称       | 参数说明                                                                                                                                                                                                                                        |
|:----------------|:-----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI            | IMSI       | 用于标识需要修改UE应用类型业务数据的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                    |
| ISDN            | MSISDN     | 用于标识需要修改UE应用类型业务数据的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                  |
| RECORDCOUNT     | 用户个数       | 用于标识需要修改UE应用类型业务数据的用户数目。 当需要为连续号码的多个用户修改UE应用类型业务数据时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户修改UE应用类型业务数据。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户修改UE应用类型业务数据，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE        | IMSI文件名    | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要修改UE应用类型业务数据的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“ueusagetype.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或十进制数字组成的字符串。 默认值：无。                                                 |
| ISDNFILE        | MSISDN文件名  | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要修改UE应用类型业务数据的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“ueusagetype.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或十进制数字组成的字符串。 默认值：无。                                           |
| PROVUEUSAGETYPE | 是否提供UE应用类型 | 用于标识是否提供签约UE应用类型业务数据。 取值范围：TRUE：提供FALSE：不提供 默认值：FALSE。                                                                                                                                                                                      |
| UEUSAGETYPE     | UE应用类型     | 仅当本命令的参数“是否提供UE应用类型”取值为“TRUE”时，该参数有效。用于标识用户UE应用类型。该值用于选择特定的专用核心网络（Dedicated Core Network）。 取值范围：0～255 默认值：无。 说明：该参数具体取值由运营商统一规划。                                                                                                            |

## 使用实例

1. 给IMSI号码为“460000009123456”的用户提供签约UE应用类型业务数据，“是否提供UE应用类型”为“TRUE”：

   ```
   MOD UEUSAGETYPE: IMSI="460000009123456", PROVUEUSAGETYPE=TRUE, UEUSAGETYPE=1;
   ```
2. 给3个连续号码的用户提供签约UE应用类型业务数据，这3个MSISDN号码分别为“13310911001”、“13310911002”、“13310911003”，“是否提供UE应用类型”为“TRUE”：

   ```
   MOD UEUSAGETYPE: ISDN="13310911001", RECORDCOUNT=3, PROVUEUSAGETYPE=TRUE, UEUSAGETYPE=1;
   ```
3. 给3个非连续号码的用户去签约UE应用类型业务数据，这3个MSISDN号码分别为“13310911001”、“13310911003”、“13310911005”，已保存在“MSISDN文件名”为“ueusagetype.txt”的文件中，并通过文件管理功能上传到指定目录，“是否提供UE应用类型”为“FALSE”：

   ```
   MOD UEUSAGETYPE: ISDNFILE="ueusagetype.txt", PROVUEUSAGETYPE=FALSE;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释      | 原因分析                                                                                               | 处理建议                                                                                                                    |
|:--------|:-----------|:---------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值     | 可能原因为如下之一：参数“IMSI”的取值不是6～15位十进制数字组成的字符串。参数“MSISDN”的取值不是1～15位十进制数字组成的字符串。                           | 根据实际情况，重新输入“IMSI”或“MSISDN”的取值，确保其取值符合要求。                                                                                |
| ERR1005 | 文件未找到      | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                   | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                      |
| ERR1009 | 参数丢失       | “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数一个都没有输入。                                                  | 根据实际情况，重新输入参数，确保满足“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现。                                               |
| ERR1010 | 参数冲突       | 可能原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR1025 | 批操作文件中格式非法 | 参数“IMSI文件名”或“MSISDN文件名”对应的批操作文件格式不正确。                                                              | 请根据IMSIFILE文件格式和ISDNFILE文件格式，重新确定对应的批操作文件格式。                                                                            |
