# 删除K2(RMV HK2)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条鉴权数据K2的数据记录。

## 注意事项

当执行该命令删除K2数据记录时，需要执行**LST DEFAULTK2SNO**命令检查待删除K2数据记录是否已被设置为默认K2，或在用户数据中已经引用（通过执行**UPG KEY**命令，“类型”参数为“IMSI”或“IMPI”，同时输入“K2索引号”参数，将用户数据的加密方式由固定密钥更新成指定密钥），如果是则不允许删除。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                    |
|:-------|:-------|:--------------------------------------------------------|
| K2SNO  | K2序列号  | 标识一条K2数据记录的关键参数，用于指定需要删除哪一条K2数据记录，操作员可以使用LST HK2操作查询获得。 |

## 使用实例

删除一条K2数据记录，“K2序列号”为“3”。

```
RMV HK2: K2SNO=3;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释            | 原因分析                                                                                                                                   | 处理建议                                               |
|----------:|:-----------------|:---------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------|
| 900003520 | 请求消息中的K2Index不存在 | “K2序列号”未定义。                                                                                                                            | 根据实际情况，重新输入已定义的“K2序列号”参数，可通过LST HK2命令查询已定义的K2数据记录。 |
| 900003521 | K2已经被使用          | 可能原因为如下之一： 已执行LST DEFAULTK2SNO命令将待删除K2数据记录设置为默认K2。在用户数据中已经引用（通过执行UPG KEY命令，“类型”参数为“IMSI”或“IMPI”，同时输入“K2索引号”参数，将用户数据的加密方式由固定密钥更新成指定密钥）。 | 如果K2数据记录已经被使用，则不允许被删除。                             |
