# 查询业务区域限制模板(LST OKSCTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此命令用来查询业务区域限制模板数据。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                       |
|:-------|:-------|:-----------------------------------------------------------|
| HLRSN  | HLR序列号 | HLR序列号，有效值域为1～255，在PGW支持容灾功能或虚拟HLR功能时设置。                   |
| TPLID  | 模板ID   | 模板号码，取值范围为0～65534。如果此参数没有给出，数据库中的所有业务区域限制模板ID和相关的数据都将显示出来。 |

## 使用实例

查询1号业务区域限制模板中的数据。例如：

LST OKSCTPL: HLRSN=1, TPLID=1;
