# 查询平台地址配置(LST ADSUADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用于查询ADSU平台地址配置。

## 注意事项

参数ECATEGORY可选，如果该参数没有出现，查询所有ADSU平台地址配置。

## 参数说明

| 参数标识      | 参数名称   | 参数说明               |
|:----------|:-------|:-------------------|
| ECATEGORY | 增强用户类别 | 增强用户类别。取值范围为1～254。 |

## 使用实例

在［ADSU平台地址配置表］中查找一条记录，增强用户类别为120。例如：

LST ADSUADDR: ECATEGORY=120;
