# 查询授权用户数据(LST AUTHUSER)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

操作员通过此命令可以查询远端用户的潜在初始用户或管理者的信息。

## 注意事项

- 此命令查询的远端用户必须在本HLR的潜在初始用户和管理者范围内。
- “远端号码”、“远端号码文件名”两个参数是条件可选参数，必须有且只能有一个参数出现。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                       |
|:------------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号  | HLR序列号，有效值域为1～255，在PGW支持容灾功能或虚拟HLR功能时设置。                                                                                                                                                   |
| RMNUM       | 远端号码    | 远端号码，E.164格式的编码。 当SET MAPCONF命令中“是否支持远端号码里包含字母”标志位为缺省值“FALSE”时，远端号码为1～15位的十进制数字。 当SET MAPCONF命令中是否支持远端号码中包含字母标志位为“TRUE”时，远端号码为中国GSM-R网络用户号码： 不以2开头时，为1～15位的十进制数字。以2开头时，为可以包含字母和数字的4～10位字符。 |
| TYPE        | 授权类型    | 对远端用户的潜在初始用户或管理者的信息进行查询。 取值范围： Initiating subscriber(1): 潜在初始用户Supervisor(2): 管理者 必选参数。                                                                                                    |
| RECORDCOUNT | 用户个数    | 用户的数目，最大10000个。如果只有一个用户，该参数不必提供。 若该参数提供，代表对以指定的初始用户的MSISDN号码为起始号码，号码连续的RECORDCOUNT个初始用户的MSISDN号码进行操作。 此参数必须与初始用户的MSISDN号码同时出现。                                                             |
| FILE        | 远端号码文件名 | 远端号码文件名称，1～16个字母或数字组成。FILE最多包含255个不连续的初始用户的MSISDN号码。                                                                                                                                       |

## 使用实例

查询远端号码为8613900001234的初始用户信息。

```
LST AUTHUSER: HLRSN=1, RMNUM="8613900001234", TYPE=Initiating subscriber;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                      | 处理建议                                                   |
|:--------|:--------|:--------------------------|:-------------------------------------------------------|
| ERR1009 | 参数丢失    | “远端号码”、“远端号码文件名”两个参数同时缺失。 | 根据实际情况，重新输入参数，并满足“远端号码”、“远端号码文件名”两个参数必须有且只能有一个参数出现的条件。 |
