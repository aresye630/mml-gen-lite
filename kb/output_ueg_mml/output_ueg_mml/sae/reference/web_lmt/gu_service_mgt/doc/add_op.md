# 增加OP(ADD OP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在系统中增加OP数据。使用MILENAGE鉴权算法时引入，是鉴权计算的一个输入参数。当使用3G鉴权算法，且使用OP时，需要预先设置OP。

## 注意事项

- 添加OP成功后，请使用CHK OP命令校验OPVALUE。
- 如果CMCC鉴权增强开关打开，该命令不允许执行。可通过**LST MAPCONF**查看CMCC鉴权增强开关是否打开。
- 同一个“HLR序列号”中增加的OP数据记录数不能超过1000条。
- 当**SET MAPCONF**命令中的“是否启用随机密钥”参数为“TRUE”，且**SET MAPSERV**命令中的“OP加密存储模式”参数为“ENHANCED”时，如果未执行**SET MAPSERV**命令设置“随机密钥默认ID”参数为系统已存在的随机密钥，则执行该命令时会返回错误：“已启用随机密钥功能，请先执行**SET RANDOMKEY**命令生成随机密钥”。

## 参数说明

| 参数标识    | 参数名称   | 参数说明                                           |
|:--------|:-------|:-----------------------------------------------|
| HLRSN   | HLR序列号 | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。   |
| OPSNO   | OP序列号  | 用于标识一个鉴权数据OP的序号。 取值范围：1～16777215 默认值：无。        |
| OPVALUE | OP值    | 用于标识一个32位鉴权数据OP的值。 取值范围：32位十六进制数字组成的字符串 默认值：无。 |

## 使用实例

增加OP，序列号为1，OP数据为12345678901234561234567890123456。命令如下：

```
ADD OP: HLRSN=1, OPSNO=1, OPVALUE="12345678901234561234567890123456";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释       | 原因分析                                                          | 处理建议                                                                                                  |
|:--------|:------------|:--------------------------------------------------------------|:------------------------------------------------------------------------------------------------------|
| ERR3047 | 超过最大限制      | 同一个“HLR序列号”中增加的OP数据记录数超过1000条。                                | 根据实际情况，如需增加OP数据，处理步骤如下：执行LST OP命令，查询已存在的OP数据。执行RMV OP命令，删除不必要的OP数据记录。执行该命令增加OP数据，确保增加的OP数据记录数在规定范围之内。 |
| ERR4086 | 随机密钥默认ID未设置 | 要使用随机密钥功能，但SET MAPSERV命令中的“随机密钥默认ID”参数为0。                     | 根据实际情况，设置SET MAPSERV命令中的“随机密钥默认ID”参数为系统已存在的随机密钥。                                                      |
| ERR4133 | 密钥丢失        | 当SET MAPSERV命令中的“随机密钥默认ID”参数为非0，“随机密钥默认ID”参数对应的随机密钥材料不存在或不完整。 | 联系华为技术支持处理。                                                                                           |
