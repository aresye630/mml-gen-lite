# 修改EIN业务(MOD EIN)

- 命令功能

## 命令功能

该命令用于修改用户的EIN（Enhanced Intelligent Network Service）业务数据。

执行此命令后，可以给用户签约/去签约EOCSI业务、ETCSI业务、BEOCSI业务、EOICK（Extended Originating Intelligent Network Category Key）业务或ETICK（Extended Terminating Intelligent Network Category Key）业务。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数是互斥参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。
- “是否提供EOCSI业务”、“是否提供ETCSI业务”、“是否提供BEOCSI业务”、“是否提供EOICK业务”和“是否提供ETICK业务”五个参数至少输入一个。

## 参数说明

| 参数标识              | 参数名称          | 参数说明                                                                                                                                                                                                                                   |
|:------------------|:--------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI              | IMSI          | 用于标识待修改EIN业务的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。E.212格式的编码。 默认值：无。                                                                                                                                                                          |
| ISDN              | MSISDN        | 用于标识待修改EIN业务的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。E.164格式的编码。 默认值：无。                                                                                                                                                                        |
| RECORDCOUNT       | 用户个数          | 用于标识待修改EIN业务的用户的数目。 当需要为连续号码的多个用户修改EIN业务时配置该参数，配置后，系统将会从已指定的“IMSI”号码或“MSISDN”号码开始，对连续号码的多个用户修改EIN业务。 取值范围：1～100000 默认值：无。 说明： 该参数是对连续号码的多个用户修改EIN业务，当只有一个用户时，该参数不必配置。当一次修改EIN业务的用户个数很多时，对系统性能无影响，但修改EIN业务的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE          | IMSI文件名       | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要修改EIN业务的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modein.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                         |
| ISDNFILE          | MSISDN文件名     | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要修改EIN业务的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modein.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                                   |
| OSKPROV           | 是否提供EOCSI业务   | 用于标识是否给用户提供EOCSI业务。 取值范围： TRUE：提供。FALSE：撤销。 默认值：无。                                                                                                                                                                                     |
| OSK               | EOCSI业务键      | 仅当参数“是否提供EOCSI业务”取值为“TRUE”时该参数有效。用于标识用户签约EOCSI业务的业务键值。 取值范围：1～999。 默认值：无。                                                                                                                                                              |
| TSKPROV           | 是否提供ETCSI业务   | 用于标识是否给用户提供ETCSI业务。 取值范围： TRUE：提供。FALSE：不提供。 默认值：无。                                                                                                                                                                                    |
| TSK               | ETCSI业务键      | 仅当参数“是否提供ETCSI业务”取值为“TRUE”时该参数有效。用于标识用户签约ETCSI业务的业务键值。 取值范围：1～999。 默认值：无。                                                                                                                                                              |
| ETCSICONVER_PROV  | 是否提供ETCSI转换模板 | 仅当参数“是否提供ETCSI业务”取值为“TRUE”时该参数有效。用于标识是否为用户签约ETCSI转换模板。 取值范围： TRUE：签约。FALSE：不签约。 默认值：无。                                                                                                                                                 |
| ETCSICONVER_TPLID | ETCSI转换模板ID   | 仅当参数“是否提供ETCSI转换模板”取值为“TRUE”时该参数有效。用于标识为用户签约的ETCSI转换模板的模板号。该参数必须先由SET ETCSICONVERTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。                                                                                                                |
| BOSKPROV          | 是否提供BEOCSI业务  | 用于标识是否给用户提供BEOCSI业务。 取值范围： TRUE：提供。FALSE：不提供。 默认值：无。                                                                                                                                                                                   |
| BOSK              | BEOCSI业务键     | 仅当参数“是否提供BEOCSI业务”取值为“TRUE”时该参数有效。用于标识用户签约BEOCSI业务的业务键值。 取值范围：1～999。 默认值：无。                                                                                                                                                            |
| EOICKPROV         | 是否提供EOICK业务   | 用于标识是否给用户提供EOICK业务。 取值范围： TRUE：提供。FALSE：不提供。 默认值：无。                                                                                                                                                                                    |
| EOICK             | EOICK业务键      | 仅当参数“是否提供EOICK业务”取值为“TRUE”时该参数有效。用于标识用户签约EOICK业务的业务键值。 取值范围：1～999 默认值：无。                                                                                                                                                               |
| ETICKPROV         | 是否提供ETICK业务   | 用于标识是否给用户提供ETICK业务。 取值范围： TRUE：提供。FALSE：不提供。 默认值：无。                                                                                                                                                                                    |
| ETICK             | ETICK业务键      | 仅当参数“是否提供ETICK业务”取值为“TRUE”时该参数有效。用于标识用户签约ETICK业务的业务键值。 取值范围：1～999 默认值：无。                                                                                                                                                               |

## 使用实例

1. 为IMSI号码是“460000009123456”的用户提供EOCSI业务，EOCSI业务键为2。

   `MOD EIN: IMSI="460000009123456", OSKPROV=TRUE, OSK=2;`
2. 为从IMSI号码是“460000009123456”的号码开始的3个连续号码的用户提供EOCSI业务，EOCSI业务键为2。

   ```
   MOD EIN: IMSI="460000009123456", RECORDCOUNT=3, OSKPROV=TRUE, OSK=2;
   ```
3. 为3个非连续号码的用户提供EOCSI业务，EOCSI业务键为2。
   - 3个IMSI号码分别为：460000009123456、460000019123456、460000029123456。
   - 3个IMSI号码已保存在IMSI文件名为“modein.txt”的文件中，并通过文件管理功能上传到指定目录。

   ```
   MOD EIN: IMSIFILE="modein.txt", OSKPROV=TRUE, OSK=2;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释      | 原因分析                                                                                               | 处理建议                                                                                                                    |
|:--------|:-----------|:---------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值     | 可能原因为如下之一：参数“IMSI”的取值不是6～15位十进制数字组成的字符串。参数“MSISDN”的取值不是1～15位十进制数字组成的字符串。                           | 根据实际情况，重新输入“IMSI”或“MSISDN”的取值，确保其取值符合要求。                                                                                |
| ERR1009 | 参数丢失       | “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数一个都没有输入。                                                  | 根据实际情况，重新输入参数，并满足“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                             |
| ERR1005 | 文件未找到      | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                   | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                      |
| ERR1010 | 参数冲突       | 可能原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是互斥参数，必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR1025 | 批操作文件中格式非法 | 参数“IMSI文件名”或“MSISDN文件名”对应的批操作文件格式不正确。                                                              | 请根据批操作文件格式，重新确定对应的批操作文件格式。                                                                                              |
