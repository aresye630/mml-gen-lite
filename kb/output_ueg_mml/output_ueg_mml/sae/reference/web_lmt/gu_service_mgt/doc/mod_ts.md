# 修改电信业务(MOD TS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来为用户签约或去签约电信业务的语音传输业务（TS11/TS12）、短消息业务（TS21/TS22）和数据业务（TS61/TS62）。

此操作仅适用于网络接入模式为MSC或BOTH的用户。

执行此命令后，如果是给用户签约该业务，则会下发插入用户数据消息；如果是给用户去签约该业务，则会下发删除用户数据消息。

## 注意事项

- 条件参数IMSI、ISDN必须且只能有一个存在。
- 条件参数TS11、TS21、TS22、TS61和TS62必须至少指定一个。

## 参数说明

| 参数标识        | 参数名称              | 参数说明                                                                                |
|:------------|:------------------|:------------------------------------------------------------------------------------|
| IMSI        | IMSI              | IMSI号码，E.212格式的编码。 取值范围：6～15位的十进制数字。                                                |
| ISDN        | MSISDN            | MSISDN号码，E.164格式的编码。 取值范围：1～15位的十进制数字。                                              |
| RECORDCOUNT | 用户个数              | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。 |
| IMSIFILE    | IMSI文件名           | IMSI文件名称。 取值范围：1～35个字母或数字组成的字符串。 说明：IMSIFILE包含多个不连续的IMSI号码，每个IMSI号码占一行。             |
| ISDNFILE    | MSISDN文件名         | MSISDN文件名称。 取值范围：1～35个字母或数字组成的字符串。 说明：ISDNFILE包含多个不连续的MSISDN号码，每个MSISDN号码占一行。       |
| TS11        | 是否提供语音业务          | 提供还是撤销语音业务。 TRUE：提供FALSE：撤销 可选参数。                                                   |
| TS21        | 是否提供短消息终结业务       | 提供还是撤销短消息终结业务。 TRUE：提供FALSE：撤销 可选参数。                                                |
| TS22        | 是否提供短消息始发业务       | 提供还是撤销短消息始发业务。 TRUE：提供FALSE：撤销 可选参数。                                                |
| TS61        | 是否提供语音与3类传真自动交替业务 | 提供还是撤销语音与3类传真自动交替业务。 TRUE：提供FALSE：撤销 可选参数。                                          |
| TS62        | 是否提供自动3类传真业务      | 提供还是撤销自动3类传真业务。 TRUE：提供FALSE：撤销 可选参数。                                               |

## 使用实例

1. 为IMSI号码为460000009123456的用户提供语音业务、短消息终结业务、语音与3类传真自动交替业务。

   MOD TS: IMSI="460000009123456", TS11=TRUE, TS21=TRUE, TS61=TRUE;
2. 为ISDN号码为4600000091234的用户提供语音业务、短消息终结业务、语音与3类传真自动交替业务。

   MOD TS: ISDN ="4600000091234", TS11=TRUE, TS21=TRUE, TS61=TRUE;
