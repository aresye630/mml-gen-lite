## 命令功能

**须知** 

本命令属于高危命令，当未携带主叫号码参数进行查询时，会增加数据库的负荷，引起系统过载，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于查询指定主叫号码的黑名单记录或者一个虚拟HLR中的所有主叫号码黑名单记录。

- 若需要查询一条主叫号码黑名单记录，请输入参数“HLR序列号”和“主叫号码”。
- 若需要查询一个虚拟HLR中所有的主叫号码黑名单记录，请输入参数“HLR序列号”。

当本命令中“主叫号码类型”未设置或设置为“NUMBER”时，系统通过与**SET MAPCONF**命令中“是否支持主叫黑名单精确记录存储DSU”参数配合使用对黑名单进行查询操作。

- 当“是否支持主叫黑名单精确记录存储DSU”为“FALSE”，系统仅支持访问并查询DRU中记录。
- 当“是否支持主叫黑名单精确记录存储DSU”为“TRUE”，根据本命令中“存储模式”参数取值，系统支持访问并查询DRU或DSU中记录。

  **说明** 

  当本命令中“存储模式”参数未设置时，无论**SET MAPCONF**命令中“是否支持主叫黑名单精确记录存储DSU”参数如何设置，系统默认都访问并查询DRU中记录。

## 注意事项

- 该命令仅在特定局点使用，其他局点不需要配置。
- 当**SET MAPCONF**命令中“是否支持主叫黑名单精确记录存储DSU”为“TRUE”时，待查询的黑名单记录可能在DRU和DSU都有存储，如需查询全量数据记录，则需要执行两次该命令，分别将软参“存储模式”设置为“DRU”和“DSU”进行查询。
- 建议在执行本命令批量查询前先登录“系统管理”页面，执行**DSP EXPTASK**命令查询所有导出任务的状态，若当前已经有两个任务处在“running”状态，建议当这两个任务的状态为“COMPLETED”后再执行本命令。
- 执行本命令批量查询前，请确保已通过“USCDB MML命令”界面执行**ADD SRVIPADDR**命令增加DMA类型的IP地址。
- 当数据量过大时，执行本命令批量查询前可以通过**MOD INSP**设置如下软参来提高数据查询效率，导出完成后恢复原配置。当前导出速度可以通过**LST INSP**命令查询。
  - 配置软参**“EXPORTSPEED（导出速度）”**的取值提高DSU中数据查询效率。
  - 配置软参**“GDATAEXPORTSPEED（全局数据导出速度）”**的取值提高DRU中数据查询效率。
- 执行本命令批量查询返回成功结果后，可通过**DSP EXPTASK**命令查询导出任务状态。

## 参数说明

| 参数标识              | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
|:------------------|:-------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN             | HLR序列号 | 用于指示系统按照哪个HLR序列号来查询主叫号码黑名单记录。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| CALLINGNUMBER     | 主叫号码   | 用于指示系统按照哪个号码来查询主叫号码黑名单记录。若不输入，则表示所有的主叫号码。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| SAVEAS            | 保存文件名  | 用于标识保存查询结果的文件名称。 当查询结果中“主叫号码类型”为“NUMBER”时：执行本命令未携带“主叫号码”查询DRU中精确记录数超过5000条，则必须输入该参数，并将查询结果保存在文件中，否则会报错“ERR4102：查询结果已经超过5000条，需要指定保存文件名进行查询”。当SET MAPCONF命令中“是否支持主叫黑名单精确记录存储DSU”为“TRUE”，执行本命令未携带“主叫号码”查询DSU中精确记录时，则必须输入该参数，并将查询结果保存在文件中，否则会报错“ERR4220：不支持在DSU存储模式下批量显示数据至客户端，需要指定保存文件名进行查询”。 取值范围：长度不超过20的字符串，可由字母、数字或字符组成，字符不能包含“>”、“/”、“?”、“\”、“:”、“*”、“"”、“<”、“|”和“'”。 默认值：无 说明：“保存文件名”参数指定的文件存放在主备PGW模块所在容器上，容器目录为“/opt/pgw/pgwtmpfile/SYSHLRSN+OPNAME”。SYSHLRSN默认为3位数字，不足3位时前面补0。如：SYSHLRSN=1，OPNAME=admin时，最后一层目录为001admin。 保存文件名参数指定的文件，可以通过“PGW Web LMT”界面右上角的“文件管理器”下载。 |
| CALLINGNUMBERTYPE | 主叫号码类型 | 用于标识查询哪个匹配类型的主叫号码黑名单记录。 取值范围： NUMBER：精确类型PREFIX：前缀类型 默认值：NUMBER                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| STOREMODE         | 存储模式   | 用于标识查询哪个模块内的主叫号码黑名单记录。该参数仅支持在批量查询精确号码场景中使用。 取值范围： DRU DSU 默认值：DRU                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |

## 使用实例

1. 查询“HLR序列号”为“1”，“主叫号码”为“8613310911001”的主叫号码黑名单记录：

   ```
   LST ANUMBLST: HLRSN=1, CALLINGNUMBER="8613310911001";
   ```

   ```
   %%LST ANUMBLST: HLRSN=1, CALLINGNUMBER="8613310911001";%%
   RETCODE = 0 SUCCESS0001:Operation is successful

                  "CALLINGNUMBER"
                  8613310911001

   Total count = 1

   There is together 1 report

   ---    END
   ```
2. 查询“HLR序列号”为“1”下的所有黑名单记录：

   ```
   LST ANUMBLST: HLRSN=1;
   ```

   ```
   %%LST ANUMBLST: HLRSN=1;%%
   RETCODE = 0 SUCCESS0001:Operation is successful

                  "CALLINGNUMBER"
                  8613310911001
                  8613310911005

   Total count = 2

   There is together 1 report

   ---    END
   ```
