# 删除改号表数据(RMV CHANGEDISDN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除改号表中的MSISDN号码。

改号表中保存的是用户改号后的旧MSISDN号码，其大小可以通过**SET MAPSERV**命令中的参数“改号表最大记录数”设置，并且可以通过**SET MAPCONF**命令中的参数“是否限制向改号表增加记录”设置改号命令执行时是否在改号表中保存用户的旧MSISDN号码。

当改号表中的记录数达到并超过其设定容量的90%时，系统会上报事件告警“10009 改号表到达容量的90%”，此时对系统正常运行无影响。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                            |
|:-------|:-------|:------------------------------------------------|
| ISDN   | MSISDN | 用于标识用户的旧MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 |

## 使用实例

删除改号表中的MSISDN号码记录，MSISDN号码为“8613772408888”：

```
RMV CHANGEDISDN: ISDN="8613772408888";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                             | 处理建议                                                 |
|:--------|:--------|:---------------------------------|:-----------------------------------------------------|
| ERR1004 | 无效的参数值  | 参数“MSISDN”的取值不是1～15位十进制数字组成的字符串。 | 根据实际情况，重新输入“MSISDN”的取值，确保其取值符合要求。                    |
| ERR3007 | 记录不存在   | 改号表中不存在输入的MSISDN号码记录。            | 核实输入的MSISDN号码，如果确定输入无误，证明实际输入的MSISDN号码在改号表中不存在，无需处理。 |
