# 增加计费地址模板(ADD HCHGTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于在HSS的业务数据库中增加一个计费地址模板。

## 注意事项

- 系统中存在一条默认计费地址模板，该模板的“HLR序列号”为“0”，“计费地址模板ID”为“0”。该模板允许修改，不允许删除。
- 新增计费地址模板时，参数PCCF和PECF至少有一个存在。
- “主在线计费地址”、“备在线计费地址”、“主离线计费地址”和“备离线计费地址”参数的取值必须是Diameter对端主机名。
- 系统中增加的计费地址模板记录数不能超过5000条。

## 参数说明

| 参数标识    | 参数名称     | 参数说明                                                                                                                                                                    |
|:--------|:---------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN   | HLR序列号   | 可选必选说明：可选参数 参数含义：用于标识一个HLR序列号。 取值范围：0~255 默认值：无。 说明：当该参数不输入时，系统默认初始设置值为0。                                                                                               |
| TPLID   | 计费地址模板ID | 可选必选说明：必选参数 参数含义：用于新增一个计费地址模板ID。 取值范围：0~1024 默认值： 无 说明： 同一个“HLR序列号”，计费地址模板ID唯一，已有模板ID可以使用LST HTPLINF命令查询获得。参数取值为“255”时为无效值。该参数取值大于“254”时只支持“IMS用户模板管理”（IMSTPL）命令组引用该模板。 |
| TPLNAME | 计费地址模板名称 | 可选必选说明：可选参数 参数含义：用于新增一个计费地址模板名称。 取值范围： 长度不超过64的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值： 无                                                                                      |
| PECF    | 主在线计费地址  | 可选必选说明：可选参数 参数含义：用于新增一个主在线计费地址。 取值范围： 长度不超过127的字符串 默认值： 无                                                                                                               |
| SECF    | 备在线计费地址  | 可选必选说明：可选参数 参数含义：用于新增一个备在线计费地址。 取值范围： 长度不超过127的字符串 默认值： 无                                                                                                               |
| PCCF    | 主离线计费地址  | 可选必选说明：可选参数 参数含义：用于新增一个主离线计费地址。 取值范围： 长度不超过127的字符串 默认值： 无                                                                                                               |
| SCCF    | 备离线计费地址  | 可选必选说明：可选参数 参数含义：用于新增一个备离线计费地址。 取值范围： 长度不超过127的字符串 默认值： 无                                                                                                               |
| COMMENT | 模板注释说明   | 可选必选说明：可选参数 参数含义：用于新增一个计费地址模板的注释。 取值范围： 长度不超过512的字符串 默认值： 无                                                                                                             |

## 使用实例

增加计费地址模板。计费地址模板ID：10，计费地址模板名称：Charge Address Template，主在线计费地址：pecf.huawei.com，备在线计费地址：secf.huawei.com，模板注释说明：Charge Address Template For ADD HTPLIMPI。

```
ADD HCHGTPL: TPLID=10, TPLNAME="Charge Address Template", PECF="pecf.huawei.com", SECF="secf.huawei.com", COMMENT="Charge Address Template For ADD HTPLIMPI";
```
