# 查询APN信息(LST APNLIST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于查询通过**SET APNLIST**命令给用户签约的APN数据信息。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                        |
|:-------|:-------|:----------------------------|
| IMSI   | IMSI   | 用于指示系统需要查询哪个IMSI号码的APN数据。   |
| ISDN   | MSISDN | 用于指示系统需要查询哪个MSISDN号码的APN数据。 |

## 使用实例

查询“IMSI”为“460000009123451”的用户的APN数据信息。

```
LST APNLIST: IMSI="460000009123451";
```
