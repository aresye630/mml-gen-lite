# 查询缺省前转通知主叫方属性(LST DEFNCS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询缺省前转通知主叫用户的属性：

查询时请输入“HLR序列号”，即可查询全部的缺省前转通知主叫用户属性数据。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                               |
|:-------|:-------|:-----------------------------------|
| HLRSN  | HLR序列号 | 用于指示系统按照哪个HLR序列号来查询前转号码属性，该参数必须选择。 |

## 使用实例

查询“HLR序列号”为“1”的HLR上的缺省前转通知主叫用户属性记录：

```
LST DEFNCS: HLRSN=1;
```

```
%%LST DEFNCS: HLRSN=1;%%
RETCODE = 0 SUCCESS0001:操作成功

                        DEFNCS = USERDEFINE

Total count = 1

There is together 1 report

---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息，各参数含义请参见**SET DEFNCS**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析       | 处理建议                                                |
|:--------|:--------|:-----------|:----------------------------------------------------|
| ERR3007 | 记录不存在   | HLR序列号未定义。 | 执行LST HLRSN命令查询出已定义的“HLRSN”，然后在执行LST DEFNCS命令时输入即可。 |
