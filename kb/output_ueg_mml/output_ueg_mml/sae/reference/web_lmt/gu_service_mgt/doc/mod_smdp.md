# 修改短消息下发路径(MOD SMDP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于设置当短消息取路由信息的消息中未携带gprsSupportIndicator信元时，短消息通过MSC还是通过SGSN下发给用户。如果不设置，则默认通过MSC下发。

该操作仅适用于“网络接入模式”为“BOTH”的用户，可通过**LST NAM**命令查询用户的“网络接入模式”。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。
- 对于“网络接入模式”为“BOTH”的用户，系统在初始化的时候已经预置了“短消息下发路径”为“MSC”，操作员可以通过**LST SMDP**命令查询得出。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                            |
|:------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 用于标识需要设置短消息下发路径的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                        |
| ISDN        | MSISDN    | 用于标识需要设置短消息下发路径的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                                      |
| RECORDCOUNT | 用户个数      | 用于标识需要设置短消息下发路径的用户数目。 当需要为连续号码的多个用户设置短消息下发路径时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户设置短消息下发路径。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户设置短消息下发路径，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名   | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要设置短消息下发路径的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modsmdp.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                               |
| ISDNFILE    | MSISDN文件名 | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要设置短消息下发路径的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modsmdp.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                         |
| SMDP        | 短消息下发路径   | 用于标识当短消息取路由信息的消息中未携带gprsSupportIndicator信元时，短消息是通过MSC下发给用户还是通过SGSN下发给用户。 取值范围：MSC：通过MSC下发 SGSN：通过SGSN下发 默认值：无。                                                                                                                  |

## 使用实例

1. 为IMSI号码为“460000009123456”的用户设置短消息下发路径为“MSC”：

   ```
   MOD SMDP: IMSI="460000009123456",SMDP=MSC;
   ```
2. 为3个连续号码的用户设置短消息下发路径，这3个MSISDN号码分别为“13310911001”、“13310911002”、“13310911003”，对应的短消息下发路径为“SGSN”：

   ```
   MOD SMDP: ISDN="13310911001", RECORDCOUNT=3, SMDP=SGSN;
   ```
3. 为3个非连续号码的用户设置短消息下发路径，这3个MSISDN号码分别为“13310911001”、“13310911003”、“13310911005”，已保存在“MSISDN文件名”为“modsmdp.txt”的文件中，并通过文件管理功能上传到指定目录，对应的短消息下发路径为“SGSN”：

   ```
   MOD SMDP: ISDNFILE="modsmdp.txt", SMDP=SGSN;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释      | 原因分析                                                                                               | 处理建议                                                                                                                    |
|:--------|:-----------|:---------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值     | 可能原因为如下之一：参数“IMSI”的取值不是6～15位十进制数字组成的字符串。参数“MSISDN”的取值不是1～15位十进制数字组成的字符串。                           | 根据实际情况，重新输入“IMSI”或“MSISDN”的取值，确保其取值符合要求。                                                                                |
| ERR1009 | 参数丢失       | “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数一个都没有输入。                                                  | 根据实际情况，重新输入参数，并满足“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                             |
| ERR1005 | 文件未找到      | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                   | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。                      |
| ERR1010 | 参数冲突       | 可能原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR3007 | 记录不存在      | 用户的IMSI号码或MSISDN号码输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户。                                             | 核实用户的IMSI号码或MSISDN号码，如果确定输入无误，证明实际输入的参数“IMSI”或“MSISDN”对应的用户未开户，请先通过ADD SUB命令给用户开户。                                      |
| ERR1025 | 批操作文件中格式非法 | 参数“IMSI文件名”或“MSISDN文件名”对应的批操作文件格式不正确。                                                              | 请根据IMSIFILE文件格式和ISDNFILE文件格式，重新确定对应的批操作文件格式。                                                                            |
| ERR3027 | 无效的NAM     | 用户的“网络接入模式”不为“BOTH”。                                                                               | 由于修改短消息下发路径的操作只适用于“网络接入模式”为“BOTH”的用户，因此需要根据实际情况，通过MOD NAM命令修改用户的“网络接入模式”为“BOTH”。                                        |
