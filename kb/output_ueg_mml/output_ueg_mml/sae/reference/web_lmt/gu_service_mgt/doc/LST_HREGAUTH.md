# 查询IMPU的注册权限(LST HREGAUTH)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询指定IMPU的注册权限。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                  |
|:-------|:-------|:--------------------------------------------------------------------------------------|
| IMPU   | IMPU   | 用于指定一个需要查询注册权限的IMPU ，要求输入的IMPU值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无 |

## 使用实例

查询IMPU注册权限。IMPU：sip:impuinfo@huawei.com。

```
LST HREGAUTH: IMPU="sip:impuinfo@huawei.com";
```

## 输出结果说明

| 参数标识    | 参数说明                                    |
|:--------|:----------------------------------------|
| REGAUTH | 显示IMPU的注册权限。 0：FALSE，不允许注册。1：TRUE，允许注册。 |
