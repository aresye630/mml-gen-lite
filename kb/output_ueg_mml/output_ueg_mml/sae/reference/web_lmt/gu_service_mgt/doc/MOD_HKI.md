# 修改KI(MOD HKI)

- 输出结果说明

## 命令功能

该操作用于对HSS的业务数据库中的一个鉴权数据KI的数据记录中的KI值进行修改或对KI相关的鉴权参数进行调整，唯一标识数据记录的关键参数是IMPI。

## 注意事项

- 如果在“命令输入区”输入命令后再输入各参数，“KI密钥”和“OPC值”出于安全原因，仅显示“\*”。
- 如果在“MML命令编辑区”直接输入带参数的命令，命令中的“KI密钥”和“OPC值”以明文显示。
- 当**SET MAPCONF**命令中的“是否启用随机密钥”参数为“TRUE”，执行该命令时以数据库最终结果来判断，如果KI/OPC未使用K4进行加密，同时未执行**SET DEFAULTK2SNO**命令设置默认K2，则执行该命令时会返回错误。
- 执行该命令未携带“KI密钥”或“OPC值”参数，单独修改“K4索引号”参数时，数据库中“KI密钥”或“OPC值”值不变。
- “OPC值”与“OPC K4索引号”条件可选，如果设置了其中一个，另一个必须设置，否则系统会上报错误码“900001009参数冲突”。

## 参数说明

| 参数标识     | 参数名称      | 参数说明                                                                                                                                                                                              |
|:---------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMPI     | IMPI      | 标识一条KI数据记录的关键参数（其取值不能被修改），用于指定需要对哪一条KI数据记录的参数进行修改或调整，操作员可以使用LST HKI操作查询获得，要求输入IMPI值符合NAI格式，字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无                                                                     |
| K        | KI密钥      | 用于定义鉴权数据空KI的值，要求输入16进制字符，字母不区分大小写。 取值范围： 长度等于32的16进制字符串 缺省值： 无                                                                                                                                    |
| K4SNO    | K4索引号     | 用于指定AKA鉴权使用的K4的值，该参数必须先由ADD HK4操作定义，然后才能在此处索引。说明：如果K4SNO参数取值为0，表明K未被加密，否则，K是经过K4加密的值。 取值范围：0～128 缺省值： 无                                                                                           |
| OPSNO    | OP索引号     | 用于指定AKA鉴权使用的OP的值，该参数必须先由ADD HOP操作定义，然后才能在此处索引。说明：如果OPSNO参数取值为0，OPC参数必须存在；如果OPSNO参数取值不为0，OPC参数不存在。 取值范围：0～128 缺省值： 无                                                                               |
| AMFSNO   | AMF索引号    | 用于指定AKA鉴权使用的AMF的值，该参数必须先由ADD HAMF操作定义，然后才能在此处索引。 取值范围：1～128 缺省值： 无                                                                                                                                |
| OPC      | OPC值      | 用于定义鉴权数据OPC的值，要求输入16进制字符，字母不区分大小写。说明：当OPC取值全零时为无效值，禁止输入。 取值范围： 长度等于32的16进制字符串 缺省值： 无                                                                                                              |
| OPCK4SNO | OPC K4索引号 | 用于指定AKA鉴权中对OPC进行解密时使用的K4的值，该参数必须先由ADD HK4操作定义，然后才能在此处索引。说明： 如果OPCK4SNO取值为0， 表明OPC未被加密；否则， 表明OPC是经OPCK4加密过的； “OPC值”与“OPC K4索引号”条件可选，如果设置了其中一个，另一个必须设置，否则系统会上报错误码“900001009参数冲突”。 取值范围：0～128 缺省值： 无 |

## 使用实例

修改KI。IMPI：impiinfo，KI密钥：abcdef1234567890ABCDEF1234567890，K4索引号：1，OP索引号：0，AMF索引号：1，OPC值“ABCDef1234567890ABCDef1234567890”，OPC K4索引号：1。

```
MOD HKI: IMPI="impiinfo", K="*****", K4SNO=1, OPSNO=0, AMFSNO=1, OPC="*****", OPCK4SNO=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释   | 原因分析                                                                                                  | 处理建议                                                                                                   |
|----------:|:--------|:------------------------------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------|
| 900003522 | 默认K2不存在 | 当SET MAPCONF命令中的“是否启用随机密钥”参数为“TRUE”，执行该命令时以数据库最终结果来判断，KI/OPC未使用K4进行加密，同时未执行SET DEFAULTK2SNO命令设置默认HK2。 | 当SET MAPCONF命令中的“是否启用随机密钥”参数为“TRUE”，执行该命令时以数据库最终结果来判断，确保KI/OPC已使用K4进行加密，或已执行SET DEFAULTK2SNO命令设置默认HK2。 |
| 900003523 | 密钥丢失    | 当SET MAPSERV命令中的“随机密钥默认ID”参数为非0，“随机密钥默认ID”参数对应的随机密钥材料不存在或不完整。                                         | 联系华为技术支持处理。                                                                                            |
