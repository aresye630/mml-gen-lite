# 删除全网跟踪数据(RMV TRACEDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条或多条用户的全网跟踪数据。

## 注意事项

- 该命令通常用于当用户数据在网元侧残留时删除残留数据。
- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”参数同时配置。
- “用户个数”必须与“IMSI”或“MSISDN”参数中的一个同时存在。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                     |
|:------------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI      | 可选必选说明：条件必选 参数含义：用于指定需要删除哪一个IMSI号码对应用户的全网跟踪数据。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                     |
| ISDN        | MSISDN    | 可选必选说明：条件必选 参数含义：用于指定需要删除哪一个MSISDN号码对应用户的全网跟踪数据。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                   |
| RECORDCOUNT | 用户个数      | 可选必选说明：条件必选 参数含义：用于指定需要删除从IMSI或者MSISDN对应用户开始的全网跟踪数据的个数。 取值范围：1～100000 默认值：无。 配置原则： 当需要为连续号码的多个用户删除全网跟踪数据时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户进行删除全网跟踪数据。当只有一个用户时，该参数不必配置。 当一次删除全网跟踪数据的用户个数很多时，对系统性能无影响，但删除全网跟踪数据的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名   | 可选必选说明：条件必选 参数含义：用于指定需要删除的全网跟踪数据的IMSI批操作文件。 取值范围：1～35个由字母、数字、下划线和“.”组成的字符串。 默认值：无。 配置原则：IMSI批操作文件包含多个不连续的需要删除全网跟踪数据用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“rmvtracedata.txt”。通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。                          |
| ISDNFILE    | MSISDN文件名 | 可选必选说明：条件必选 参数含义：用于指定需要删除的全网跟踪数据的MSISDN批操作文件。 取值范围：1～35个由字母、数字、下划线和“.”组成的字符串。 默认值：无。 配置原则：MSISDN批操作文件包含多个不连续的需要删除全网跟踪数据用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“rmvtracedata.txt”。通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。                    |

## 使用实例

1. 删除“IMSI”为“460000009123456”的用户的全网跟踪数据：

   ```
   RMV TRACEDATA: IMSI="460000009123456";
   ```
2. 删除“IMSI”为“460000009123456”、“460000009123457”、“460000009123458”的3个连续用户的全网跟踪数据：

   ```
   RMV TRACEDATA: IMSI="460000009123456", RECORDCOUNT=3;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                               | 处理建议                                                                                                                    |
|:--------|:--------|:---------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 可能原因为如下之一：参数“IMSI”的取值不是6～15位十进制数字组成的字符串。参数“MSISDN”的取值不是1～15位十进制数字组成的字符串。                           | 根据实际情况，重新输入“IMSI”或“MSISDN”的取值，确保其取值符合要求。                                                                                |
| ERR1010 | 参数冲突    | 可能原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR3001 | 用户未开户   | 用户的“IMSI”或“MSISDN”输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户。                                             | 核实用户的“IMSI”或“MSISDN”，如果确定输入无误，证明实际输入的参数“IMSI”或“MSISDN”对应的用户未开户，请先通过ADD SUB命令给用户开户。                                      |
| ERR3007 | 记录不存在   | 输入的“IMSI”或“MSISDN”无对应的全网跟踪数据。                                                                      | 执行LST TRACEDATA命令查询已存在的全网跟踪数据，确认需要删除的“IMSI”或“MSISDN”对应的用户的全网跟踪数据后执行本命令删除。                                               |
