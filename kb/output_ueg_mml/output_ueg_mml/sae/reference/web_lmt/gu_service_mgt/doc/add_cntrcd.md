# 增加国家/地区码(ADD CNTRCD)

## 命令功能

**须知** 

本命令属于高危命令，执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在HLR中增加一条国家/地区码数据记录。

系统在初始化的时候已经在配置数据库中预置了国家/地区码数据记录，操作员一般不需要另外单独配置。如果运营商需要新增某个国家/地区码，则操作员应使用**ADD CNTRCD**命令进行配置。通常配置一个国家内所允许前转的所有国家的国家/地区码，用于在业务处理过程中对号码进行分析并按相应的逻辑流程进行处理。例如当手机登记前转业务时，系统会对登记的前转号码进行号码规整，在号码规整过程中系统会在配置数据库中查找国家/地区码数据记录，如果查找不到相应的数据记录，登记将会失败。

## 注意事项

- 国际电信联盟分配的国家/地区码可能会发生变更，所以需要定期核对和刷新。如果出现某个国家/地区的国家/地区码没有配置，将导致不能登记这个国家/地区的号码作为前转号码。
- 系统中增加的国家/地区码数据记录数不能超过1000条。

## 参数说明

| 参数标识     | 参数名称    | 参数说明                                                                                                             |
|:---------|:--------|:-----------------------------------------------------------------------------------------------------------------|
| CNTRCODE | 国家/地区码  | 用于标识国家/地区代码。 取值范围：1～6位十进制数字组成的字符串。 默认值：无。                                                                        |
| CNAME    | 国家/地区名称 | 用于标识国家/地区名称。 取值范围：1～30位字母或十进制数字组成的字符串。 默认值：无。 配置原则：在配置国家/地区码时，不能在其前面加国际长途字冠“00”。 说明：执行该命令并且不输入该参数时，系统会设置初始值NULL。 |

## 使用实例

在系统中增加一条国家/地区码数据记录，“国家/地区码”为“86”，“国家/地区名称”为“China”：

```
ADD CNTRCD: CNTRCODE="86",CNAME="China";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                   | 处理建议                                                                                                                              |
|:--------|:--------|:---------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 界面输入的“国家/地区码”和“国家/地区名称”参数不在相应的参数取值范围内。 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                  |
| ERR3006 | 记录已存在   | 本次操作输入的“国家/地区码”在数据库中已存在。               | 根据实际情况，重新输入参数，确保输入的“国家/地区码”和系统中已存在的不重复。可执行LST CNTRCD命令查询系统中已存在的国家/地区码。                                                            |
| ERR1111 | 超过最大限制  | 增加的国家/地区码数据记录数超过1000条。                 | 根据实际情况，如需增加国家/地区码数据，处理步骤如下：执行LST CNTRCD命令，查询已存在的国家/地区码的配置信息。执行RMV CNTRCD命令，删除不必要的国家/地区码数据。执行该命令增加国家/地区码数据，确保增加国家/地区码数据记录数在规定范围之内。 |
