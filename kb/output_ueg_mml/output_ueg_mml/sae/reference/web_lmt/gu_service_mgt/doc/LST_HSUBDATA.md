# 一键式查询IMS签约信息(LST HSUBDATA)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在HSS的业务数据库中一键式查询用户签约的“SUBID”，“IMPI”，“IMPU”，“IMSI”和“MSISDN”相关数据信息，一次只能查询一个“SUBID”下的数据。

## 注意事项

- “SUBID”、“IMPI”、“IMPU”、“IMSI”、“MSISDN”五个参数必须存在且只能存在一个。
- 系统将根据输入的“SUBID”、“IMPI”、“IMPU”、“IMSI”、“MSISDN”五个条件中的任意一个查询其所对应IMS签约用户下的所有数据信息。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                                                                                                  |
|:-------|:---------|:----------------------------------------------------------------------------------------------------------------------|
| SUBID  | SUBID    | 用于指示系统需要按照哪个SUBID来查询一个签约用户数据。一次只能查询一个签约用户数据记录，字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。                              |
| IMPI   | IMPI     | 用于指示系统需要按照哪个IMPI来查询一个签约用户数据。一次只能查询一个签约用户数据记录，要求输入IMPI值符合NAI格式，字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。              |
| IMPU   | IMPU     | 用于指示系统需要按照哪个IMPU来查询一个签约用户数据。一次只能查询一个签约用户数据记录，要求输入的IMPU值符合SIP URI或TEL URI格式，字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。 |
| IMSI   | IMSI     | 用于指示系统按照哪个IMSI号码来查询IMS用户信息。 取值范围：6～15位十进制数字组成的字符串 默认值：无。 说明：可选参数。                                                     |
| ISDN   | MSISDN   | 用于指示系统按照哪个MSISDN号码来查询IMS用户信息。 取值范围：1～15位十进制数字组成的字符串 默认值：无。 说明：可选参数。                                                   |
| DETAIL | 是否显示简约格式 | 用于标识查询后返回的报文中是否按照简约XML格式显示用户的详细信息。 取值范围：TRUE：简约XML格式显示用户的详细信息。FALSE：普通XML格式显示用户的详细信息。 默认值：FALSE。 说明：可选参数。             |

## 使用实例

查询IMS签约信息，“SUBID”为“+862970119992@domain50.huawei.com”：

```
LST HSUBDATA: SUBID="+862970119992@domain50.huawei.com";
```
