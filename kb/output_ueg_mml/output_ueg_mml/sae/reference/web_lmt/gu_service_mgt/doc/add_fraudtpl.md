# 增加防欺诈模板(ADD FRAUDTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此命令用于增加防欺诈模板。

## 注意事项

同一个“HLR序列号”中增加的防欺诈模板记录数不能超过5000条。

## 参数说明

| 参数标识            | 参数名称       | 参数说明                                                                                  |
|:----------------|:-----------|:--------------------------------------------------------------------------------------|
| HLRSN           | HLR序列号     | HLR序列号，在PGW支持容灾功能或虚拟HLR功能时设置。 取值范围：1～255 缺省值：无 说明：必选参数                                |
| TPLID           | 模板ID       | 用于在模板ID列表框中选择模板的ID。 取值范围：0～65534 缺省值：无 说明：必选参数                                        |
| TPLNAME         | 模板名        | 用于定义新增防欺诈模板的名称。 取值范围：长度不超过60的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 缺省值：无 说明：可选参数               |
| MO_CONTROL_MODE | MO呼叫时间限制方式 | MO呼叫时间限制方式。 MOTIME：根据参数“MO呼叫时间限制”的取值进行控制 NE：使用对端网元设定的值 NONE：无限制 说明：必选参数               |
| MOTIME          | MO呼叫时间限制   | 仅当本命令中的“MO呼叫时间限制方式”参数为“MOTIME”时该参数有效。用于标识MO呼叫时间限制，单位为分钟。 取值范围：1～64800                 |
| MOACT           | MO呼叫动作参数   | 仅当本命令中的“MO呼叫时间限制方式”参数为“MOTIME”或“NE”时该参数有效。用于标识MO呼叫动作参数。 NE：使用VLR默认处理 REJECT：拒绝 缺省值：NE |
| CF_CONTROL_MODE | CF呼叫时间限制方式 | CF呼叫时间限制方式。 CFTIME：根据参数“CF呼叫时间限制”的取值进行控制 NE：使用对端网元设定的值 NONE：无限制 说明：必选参数               |
| CFTIME          | CF呼叫时间限制   | 仅当本命令中的“CF呼叫时间限制方式”参数为“CFTIME”时该参数有效。用于标识CF呼叫时间限制，单位为分钟。 取值范围：1～64800                 |
| CFACT           | CF呼叫动作参数   | 仅当本命令中的“CF呼叫时间限制方式”参数为“CFTIME”或“NE”时该参数有效。用于标识CF呼叫动作参数。 NE：使用VLR默认处理 REJECT：拒绝 缺省值：NE |
| CFRMAX          | CF登记最大数    | CF登记最大数。 取值范围：0～254(取值为0表示无限制) 缺省值：0                                                  |

## 使用实例

增加防欺诈模板，HLR序列号为1，模板号为2，模板名为FRAUD-01，MO呼叫时间限制方式为MOTIME，MO呼叫时间限制为5，MO呼叫动作参数为REJECT，CF呼叫时间限制方式为NONE，命令如下：

```
ADD FRAUDTPL: HLRSN=1, TPLID=2, TPLNAME="FRAUD-01", MO_CONTROL_MODE=MOTIME, MOTIME=5, MOACT=REJECT, CF_CONTROL_MODE=NONE;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                            | 处理建议                                                                                                                 |
|:--------|:--------|:--------------------------------|:---------------------------------------------------------------------------------------------------------------------|
| ERR3047 | 超过最大限制  | 同一个“HLR序列号”中增加的防欺诈模板记录数超过5000条。 | 根据实际情况，如需增加防欺诈模板，处理步骤如下：执行LST FRAUDTPL命令，查询已存在的防欺诈模板。执行RMV FRAUDTPL命令，删除不必要的防欺诈模板。执行该命令增加防欺诈模板，确保增加的防欺诈模板记录数在规定范围之内。 |
