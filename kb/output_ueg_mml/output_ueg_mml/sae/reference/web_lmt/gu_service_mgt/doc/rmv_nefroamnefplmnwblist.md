# 删除NEF漫游状态事件通知PLMN黑白名单(RMV NEFROAMNTFPLMNWBLIST)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使NEF漫游状态事件通知行为变化，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于删除系统配置的NEF漫游状态事件通知PLMN黑白名单的数据记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                         |
|:-------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 可选必选说明：必选参数 参数含义：用于标识一条NEF漫游状态事件通知PLMN黑白名单记录的关键字段，用于指定需要按照哪个HLR序列号删除对应NEF漫游状态事件通知PLMN黑白名单数据记录。 取值范围：1～255 默认值：无。 配置原则：无。                                                                                                     |
| PLMN   | PLMNID | 可选必选说明：必选参数 参数含义：用于标识一条NEF漫游状态事件通知PLMN黑白名单记录的关键字段，用于指定需要按照哪个PLMN序列号删除一条NEF漫游状态事件通知PLMN黑白名单数据记录。 取值范围：5～6位的十进制数字组成的字符串。 默认值：无。 配置原则：“PLMNID”的取值是由MCC（前三位）和MNC（后两至三位）组成，当输入的MNC不足三位时前面会自动补0。如：输入“12345”，系统识别为 PLMNID=“123045”。 |

## 使用实例

删除“HLR序列号”取值为“1”，“PLMNID”取值为“111111”的NEF漫游状态事件通知PLMN白名单记录。

```
RMV NEFROAMNTFPLMNWBLIST: HLRSN=1, PLMN="111111";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| ERR1009 | 参数缺失      | 必选参数缺失：“HLR序列号”、“PLMNID”参数中的一个或多个缺失。 | 重新输入缺失的参数。                                                                                                          |
