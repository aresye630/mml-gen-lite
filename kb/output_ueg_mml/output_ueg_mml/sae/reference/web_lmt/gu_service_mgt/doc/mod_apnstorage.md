# 修改APN数据存储信息(MOD APNSTORAGE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改用户APN数据的存储方式。

由于GPRS数据越来越多，非索引化压缩存储会导致DSU内存不足，通过索引化压缩存储可以改善DSU内存不足的问题，提高DSU内存使用效率。执行该命令会改变当前用户的GPRS数据的存储方式。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”及“MSISDN文件名”是条件可选参数，有且只能有一个参数出现。
- “用户个数”参数不能与“IMSI文件名”或“MSISDN文件名”参数同时存在。
- “PS APN数据规整”和“EPS APN数据规整”两个参数至少出现一个。

## 参数说明

| 参数标识        | 参数名称         | 参数说明                                                                                                                                                                                                    |
|:------------|:-------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI         | 用于标识系统按照哪个IMSI号码修改用户APN数据的存储方式。 取值范围：6～15位的十进制数字组成的字符串。 默认值：无。                                                                                                                                          |
| ISDN        | MSISDN       | 用于标识系统按照哪个MSISDN号码修改用户APN数据的存储方式。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                         |
| RECORDCOUNT | 用户个数         | 用于标识系统需要修改APN数据的存储方式的用户个数。 当需要修改连续号码用户的APN数据的存储方式时配置该参数，选择后，系统将会从已指定的IMSI号码或MSISDN号码开始，修改连续多个号码用户的APN数据的存储方式。 取值范围：1～100000 默认值：无。                                                                      |
| IMSIFILE    | IMSI文件名      | 用于标识系统按照哪个IMSI文件名修改用户APN数据的存储方式。 IMSI批操作文件包含多个不连续的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modapnstorage.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16位由字母或十进制数字组成的字符串。 默认值：无。       |
| ISDNFILE    | MSISDN文件名    | 用于标识系统按照哪个MSISDN文件名修改用户APN数据的存储方式。 MSISDN批操作文件包含多个不连续的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“modapnstorage.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16位由字母或十进制数字组成的字符串。 默认值：无。 |
| PSAPN       | PS APN数据的处理  | 用于标识PS域APN数据的存储方式。 取值范围：INDEXED：索引化压缩存储。UNINDEXED：非索引化压缩存储。 默认值：无。                                                                                                                                      |
| EPSAPN      | EPS APN数据的处理 | 用于标识EPS域APN数据的存储方式。 取值范围：INDEXED：索引化压缩存储。UNINDEXED：非索引化压缩存储。 默认值：无。                                                                                                                                     |

## 使用实例

修改“IMSI”号码为“460000009123456”的用户APN数据的存储方式：

```
MOD APNSTORAGE: IMSI="460000009123456", PSAPN=INDEXED;
```
