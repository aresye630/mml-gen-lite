# 删除云分区路由数据(RMV SPRTINFO)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除云分区ID与HSS GT(Global Title)、SAE-HSS主机名和SAE-HSS域名、IMS-HSS主机名和IMS-HSS域名之间的对应关系的路由数据记录。

## 注意事项

当需要删除某条云分区路由数据时，请先执行**LST IWFIMSI**命令查询即将删除的云分区路由数据是否被引用（当该条云分区路由数据“记录索引”取值与查询记录中某条记录的“分区ID”参数取值相等时，即认为已被引用）：

- 如果已被引用，请先执行**RMV IWFIMSI**命令删除引用该云分区路由数据的IMSI号段属性数据记录，然后再执行**RMV SPRTINFO**命令删除该条云分区路由数据记录。
- 如果未被引用，则可以直接执行**RMV SPRTINFO**命令删除该条云分区路由数据记录。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                   |
|:-------|:-------|:-----------------------------------------------------------------------|
| INDEX  | 记录索引   | 标识云分区路由数据的关键字段（其取值不能被修改）。用于指定需要删除哪一个云分区路由数据记录，操作员可以使用LST SPRTINFO命令获取。 |

## 使用实例

删除“记录索引”取值为“2”的云分区路由数据。

```
RMV SPRTINFO: INDEX=2;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                        | 处理建议                                                                                 |
|:--------|:--------|:----------------------------------------------------------------------------|:-------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 输入的参数值不在其取值范围内或者输入的参数值不符合要求。                                                | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                     |
| ERR3007 | 记录不存在   | 输入的“记录索引”对应的记录不存在。                                                          | 执行LST SPRTINFO查看已存在的云分区路由数据，重新输入“记录索引”取值，再执行该命令。                                     |
| ERR4143 | PID已被使用 | 删除的记录索引对应的PID已被IMSI全局路由数据、MSISDN全局路由数据、IMPI全局路由数据、IMPU全局路由数据或者“默认转发分区ID”引用。 | 删除被IMSI全局路由数据、MSISDN全局路由数据、IMPI全局路由数据、IMPU全局路由数据或者“默认转发分区ID”引用的PID，再执行该命令删除该云分区路由数据。 |
