# 修改状态主动上报M2M业务(MOD M2MNOTIFY)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于为用户提供/撤销状态主动上报第三方业务。

- 当给用户提供状态主动上报M2M业务时（即该命令中的“提供还是撤销状态主动上报第三方平台特性”取值为“TRUE”），用户必须已经成功开户且在开户时未签约状态主动上报M2M业务（即开户命令中的“提供状态主动上报第三方平台特性”参数取值为“FALSE”或“LU”）。
- 当给用户提供PS域位置更新上报业务时（即该命令中的“提供还是撤销状态主动上报第三方平台特性”取值为“LU”），用户必须已经成功开户且在开户时未签约位置更新上报业务（即用户开户时开户命令中的“提供状态主动上报第三方平台特性”参数取值为“TRUE”或“FALSE”）。
- 当给用户撤销状态主动上报第三方平台业务时，（即该命令中的“提供还是撤销状态主动上报第三方平台特性”取值为“FALSE”），用户必须已经成功开户且在开户时已签约状态主动上报第三方平台业务（即用户开户时开户命令中的“提供状态主动上报第三方平台特性”参数取值为“TRUE”或“LU”）。

## 注意事项

- IMSI、ISDN、IMSIFILE、ISDNFILE是条件可选参数，有且只能有一个参数出现。
- RECORDCOUNT一定不能与IMSIFILE或ISDNFILE同时存在。
- M2M通知功能与位置更新通知功能为互斥关系，不支持同时签约。

## 参数说明

| 参数标识        | 参数名称                | 参数说明                                                                                                                                                       |
|:------------|:--------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI                | IMSI号码，E.212格式的编码，6～15位的十进制数字。                                                                                                                             |
| ISDN        | MSISDN              | MSISDN号码，E.164格式的编码，1～15位的十进制数字。                                                                                                                           |
| RECORDCOUNT | 用户个数                | 用户的数目，最大100000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。                                                                        |
| IMSIFILE    | IMSI文件名             | IMSI文件名称，由16个以内的数字或字母组成。IMSIFILE是由多个不连续的IMSI号码组成的批操作文件，每个IMSI号码占一行。                                                                                        |
| ISDNFILE    | MSISDN文件名           | ISDN文件名称，由16个以内的数字或字母组成。ISDNFILE是由多个不连续的MSISDN号码组成的批操作文件，每个MSISDN号码占一行。                                                                                    |
| PROV        | 提供还是撤消状态主动上报第三方平台特性 | 用于标识给用户提供还是撤销状态主动上报第三方平台特性。 取值范围： TRUE(1)：提供M2M通知功能。FALSE(0)：撤销状态主动上报第三方平台特性。LU(2)：提供位置更新通知功能。 说明： 当该参数取值为“LU(2)”时，完成一次位置更新通知后，参数取值自动恢复为“FALSE(0)”。 默认值：无。 |

## 使用实例

为IMSI号码为123456789012345的用户提供状态主动上报M2M业务。命令如下：

MOD M2MNOTIFY: IMSI="123456789012345", PROV=TRUE;
