# 查询IMPU的游牧模板(LST HNATPLID)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询指定IMPU的游牧模板信息，需要输入唯一标识该数据记录的关键参数IMPU。

## 注意事项

当查询的指定IMPU的NASS游牧模板信息不存在时，返回结果为空。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                     |
|:-------|:-------|:-----------------------------------------------------------------------------------------|
| IMPU   | IMPU   | 用于指示系统需要查询哪个IMPU的游牧模板信息。要求输入的IMPU值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无 |

## 使用实例

查询IMPU的游牧模板。IMPU：sip:impuinfo@huawei.com。

```
LST HNATPLID: IMPU="sip:impuinfo@huawei.com";
```

## 输出结果说明

| 参数标识    | 参数说明          |
|:--------|:--------------|
| NATPLID | 显示NASS游牧模板ID。 |
| TPLNAME | 显示NASS游牧模板名称。 |
