# 修改自动批操作文件名称(MOD BATFILENAME)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在UDM修改自动批操作文件名称及各类结果名称的前缀。

## 注意事项

- “批操作文件名前缀”和“结果文件名前缀”取值不能相同。
- “成功结果文件名前缀”、“失败结果文件名前缀”、“详细结果文件名前缀”取值不能相同。
- “批操作文件名前缀”和“成功结果文件名前缀”、“失败结果文件名前缀”、“详细结果文件名前缀”取值不能相同。
- “成功结果文件名前缀”、“失败结果文件名前缀”、“详细结果文件名前缀”必须同时存在或同时不存在。
- “结果文件名前缀”和“成功结果文件名前缀”、“失败结果文件名前缀”、“详细结果文件名前缀”必须至少存在一种。

## 参数说明

| 参数标识            | 参数名称      | 参数说明                                                                                  |
|:----------------|:----------|:--------------------------------------------------------------------------------------|
| BATPREFIX       | 批操作文件名前缀  | 标识一个自动批操作文件名称前缀的关键字段（其取值不能被修改）。用于指定需要对哪一个“批操作文件名前缀”进行修改，操作员可以使用LST BATFILENAME命令查询获得。 |
| RSTPREFIX       | 结果文件名前缀   | 用于标识批操作结果文件名称前缀。“结果文件名前缀”区分大小写字母。 取值范围：1～32位字母或十进制数字组成的字符串。 默认值：无。                    |
| RSTSUCCPREFIX   | 成功结果文件名前缀 | 用于标识批操作成功结果文件名称前缀。“成功结果文件名前缀”区分大小写字母。 取值范围：1～32位字母或十进制数字组成的字符串。 默认值：无。                |
| RSTERRPREFIX    | 失败结果文件名前缀 | 用于标识批操作失败结果文件名称前缀。 取值范围：1～32位字母或十进制数字组成的字符串。“失败结果文件名前缀”区分大小写字母。 默认值：无。                |
| RSTDETAILPREFIX | 详细结果文件名前缀 | 用于标识批操作详细结果文件名称前缀。 取值范围：1～32位字母或十进制数字组成的字符串。“详细结果文件名前缀”区分大小写字母。 默认值：无。                |

## 使用实例

修改自动批操作文件名称，“批操作文件名前缀”为“Bat”，修改的参数配置如下：

- “结果文件名前缀”修改为“Rstlog”
- “成功结果文件名前缀”修改为“succRstlog”
- “失败结果文件名前缀”修改为“errRstlog”
- “详细结果文件名前缀”修改为“detailRstlog”

```
MOD BATFILENAME: BATPREFIX="Bat", RSTPREFIX="Rstlog", RSTSUCCPREFIX="succRstlog", RSTERRPREFIX="errRstlog", RSTDETAILPREFIX="detailRstlog";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 消息解释     | 原因分析                                                                                   | 处理建议                                                                                          |
|:--------|:---------|:---------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------|
| ERR1009 | 参数丢失     | “结果文件名前缀”或者“成功结果文件名前缀”、“失败结果文件名前缀”、“详细结果文件名前缀”三个参数的组合一个都没有输入。                          | 根据实际情况，重新输入参数，并满足“结果文件名前缀”或者“成功结果文件名前缀”、“失败结果文件名前缀”、“详细结果文件名前缀”三个参数的组合必须至少有一个出现的条件。           |
| ERR3804 | 参数取值不能相等 | 可能原因为如下之一：“批操作文件名前缀”与其他参数输入的值相同。“成功结果文件名前缀”、“失败结果文件名前缀”、“详细结果文件名前缀”三个参数其中的两个或多个输入的值相同。 | 根据实际情况，重新输入参数，确保满足注意事项要求。“批操作文件名前缀”与其他参数输入的值都不相同。“成功结果文件名前缀”、“失败结果文件名前缀”、“详细结果文件名前缀”输入的值都不相同。 |
