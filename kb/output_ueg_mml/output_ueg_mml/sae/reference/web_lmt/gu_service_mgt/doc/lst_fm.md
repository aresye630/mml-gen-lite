# 查询FM业务数据(LST FM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

操作员可以查询某一个用户的FM业务信息，查询内容包括：

- 是否签约FM业务的初始用户或者管理者以及相应的COR定义。
- 本HLR可以查询到的与该用户绑定的远端号码（本HLR和FFN在同一个网元）。

## 注意事项

IMSI、ISDN是条件可选参数，此操作中，有且只能有一个参数出现。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                               |
|:------------|:----------|:-----------------------------------------------------------------------------------|
| IMSI        | IMSI      | IMSI号码，E.212格式的编码，6～15位的十进制数字。                                                     |
| ISDN        | MSISDN    | MSISDN号码，E.164格式的编码，1～15位的十进制数字。                                                   |
| RECORDCOUNT | 用户个数      | 用户的数目，最大10000个。如果只有一个用户，该参数不必提供。 该参数提供，代表以指定的IMSI、MSISDN为起始号码，号码连续的RECORDCOUNT个用户。 |
| IMSIFILE    | IMSI文件名   | IMSI文件名称，1~16个由字母、数字、下划线和点号组成的字符。IMSIFILE包含多个不连续的IMSI号码。                           |
| ISDNFILE    | MSISDN文件名 | ISDN文件名称，1~16个由字母、数字、下划线和点号组成的字符。ISDNFILE包含多个不连续的MSISDN号码。                         |

## 使用实例

查询IMSI号码为460000009123456的用户的FM业务信息。

```
LST FM: IMSI="460000009123456";
```
