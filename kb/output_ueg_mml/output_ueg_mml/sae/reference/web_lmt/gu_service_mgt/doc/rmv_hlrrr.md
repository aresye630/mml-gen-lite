# 删除用户漫游限制(RMV HLRRR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会影响该HLRSN中用户的漫游能力（如：在本命令删除了“VLR/SGSN号码前缀”端局的配置，但仍保留“缺省漫游限制状态”为“漫游限制”，导致正常用户被漫游限制引起业务受损），因此执行该命令前，请详细阅读本命令的联机帮助和注意事项，需要与华为技术支持联系制定修改的实施方案、测试方案和回退方案后才可以实施。

该命令用于删除HLRSN中的用户在“VLR/SGSN号码前缀”对应的端局下是否允许漫游的“漫游限制状态”能力配置。

## 注意事项

- 该命令仅删除了指定“VLR/SGSN号码前缀”的能力配置，如果删除不当将导致该HLRSN的用户不能正常漫游。
- 该命令仅删除了指定“VLR/SGSN号码前缀”的能力配置，“缺省漫游限制状态”配置仍然生效，如需修改缺省漫游限制状态，需要执行**SET DEFHLRRR**命令修改参数“缺省漫游限制状态”的取值。
- 该命令删除指定的“VLR/SGSN号码前缀”配置记录后，剩下的“VLR/SGSN号码前缀”配置记录越少，按“缺省漫游限制状态”配置进行漫游控制的用户量越大。全部“VLR/SGSN号码前缀”配置记录被删除后，整个HLRSN范围内的用户按“缺省漫游限制状态”配置进行漫游控制。
- 网上重大问题案例：M国T局工程师，原本期望通过**RMV HLRRR**删除本局的“用户漫游限制”配置，执行**RMV HLRRR**删除了所有“VLR/SGSN号码前缀”端局的配置后，但仍保留“缺省漫游限制状态”为“漫游限制”，导致整局用户漫游无匹配的“VLR/SGSN号码前缀”配置，均按“缺省漫游限制状态”配置的“漫游限制”控制被漫游限制，影响业务X小时。实际修改方案在**RMV HLRRR**删除“VLR/SGSN号码前缀”端局的配置前，需要通过**SET DEFHLRRR**命令修改“缺省漫游限制状态”取值为“漫游允许”。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识      | 参数名称         | 参数说明                                                                                                                                                                                                               |
|:----------|:-------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN     | HLR序列号       | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                       |
| VLRSGSNNO | VLR/SGSN号码前缀 | 用于标识一个VLR或SGSN号码前缀。 取值范围：1～15位的十进制数字。 默认值：无。                                                                                                                                                                       |
| CHKDFT    | 是否检查缺省漫游限制状态 | 用于标识是否检查缺省漫游限制状态。 取值范围：TRUE：检查。当待删除用户漫游限制数据记录是“PERMISSION”时，需要检查“ROAMDEFAULTRULE”是否为“RESTRICT”。可以执行LST HLRRR命令查询用户漫游限制数据记录和系统缺省漫游限制状态数据。如果是“RESTRICT”，则系统返回ERR4067错误码。如果不是“RESTRICT”，则可以删除成功。 FALSE：不检查。 默认值：TRUE。 |

## 使用实例

现网已设置HLR中所有用户在号码前缀为“8613800001”的VLR/SGSN中漫游，禁止在号码前缀为“8613800002”的VLR/SGSN中漫游，且禁止在其他的VLR/SGSN中漫游。但由于网络调整，需要删除当前“VLR/SGSN号码前缀”的漫游能力配置，允许HLR中的所有用户在全网范围内漫游。

具体操作步骤如下：

1. 执行**SET DEFHLRRR**把“缺省漫游限制状态”的值设置为“漫游允许”。

   ```
   SET DEFHLRRR: HLRSN=1, ROAMDEFAULTRULE=PERMISSION;
   ```
2. 执行**RMV HLRRR**命令删除已配置的VLR/SGSN号码前缀。

   ```
   RMV HLRRR: HLRSN=1, VLRSGSNNO="8613800001", CHKDFT=TRUE;
   RMV HLRRR: HLRSN=1, VLRSGSNNO="8613800002", CHKDFT=TRUE;
   ```

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|:--------|:-------------------------------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在                                                                          | “HLR序列号”未定义或者输入的“VLR/SGSN号码前缀”未配置。                                                                                                     | 根据实际情况，重新输入参数“HLR序列号”，确保输入的“HLR序列号”已定义。执行LST HLRRR命令查看HLR所配置的“VLR/SGSN号码前缀”，输入正确的“VLR/SGSN号码前缀”后执行此命令。        |
| ERR4067 | 缺省漫游限制状态是漫游限制。请执行SET DEFHLRRR修改缺省漫游限制状态为漫游允许，或者修改CHKDFT为FALSE后重新执行RMV HLRRR命令。 | 当同时满足以下条件，执行该命令时会报错。“是否检查缺省漫游限制状态”参数为“TRUE”。执行LST HLRRR命令查询得到“ROAMDEFAULTRULE”为“RESTRICT”。执行LST HLRRR命令查询得到待删除用户漫游限制数据记录为“PERMISSION”。 | 根据实际情况，如需删除用户漫游限制数据记录，方法为如下之一：执行SET DEFHLRRR命令将“缺省漫游限制状态”参数设置为“PERMISSION”。执行该命令时将“是否检查缺省漫游限制状态”参数设置为“FALSE”。 |
