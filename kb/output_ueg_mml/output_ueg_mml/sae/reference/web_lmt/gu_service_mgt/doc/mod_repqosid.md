# 修改QoS模板替代配置(MOD REPQOSID)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会导致用户漫游到指定的SGSN时下发错误的QoS，因此执行该命令前，需要和运营商的QoS模板替代配置表进行仔细核对，并详细阅读本命令的联机帮助和注意事项，确保修改的QoS模板替代配置完全正确。如运营商无法给出具体的配置表或有其他疑问，请与华为技术支持联系制定操作的实施方案、测试方案和回退方案后才可以实施。

该命令用于在UDM中修改一条QoS模板替代配置记录。在该命令中，系统通过以下关键参数的组合来唯一标识一条QoS模板替代配置记录：

- “HLR序列号”
- “用户签约的QoS模板ID”
- “SGSN号码或号码前缀”

从而对对应的“替换的QoS模板ID”进行修改。

## 注意事项

- 当设置了QoS模板替代配置，系统会根据用户签约的QoS模板找到替换的模板配置并下发数据，用户原来签约的QoS模板将不会生效，会影响大量在网用户，因此现网执行该操作时需要慎重。执行该命令前需确定修改后的QoS替代配置和运营商的QoS模板替代配置表完全一致，并确保指定的SGSN上支持替换后的QoS模板对应的QoS数据。
- 修改后的“替换的QoS模板ID”取值不能和输入的“用户签约的QoS模板ID”取值相同。
- 该命令不允许进行批操作。

## 参数说明

| 参数标识       | 参数名称         | 参数说明                                                                                                            |
|:-----------|:-------------|:----------------------------------------------------------------------------------------------------------------|
| HLRSN      | HLR序列号       | 用于标识QoS模板替代配置记录的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR中QoS模板替代配置记录的参数进行修改，操作员可以使用LST HLRSN命令查询获得。                        |
| USRQOSID   | 用户签约的QoS模板ID | 用于标识QoS模板替代配置记录的关键字段之一（其取值不能被修改），用于指定需要对哪个用户签约的QoS模板ID修改替换的QoS模板ID，操作员可以使用LST REPQOSID命令查询获得。                   |
| SGSNPREFIX | SGSN号码或号码前缀  | 用于标识QoS模板替代配置记录的关键字段之一（其取值不能被修改），用于指定需要对哪个SGSN号码或号码前缀修改替换的QoS模板ID，操作员可以使用LST REPQOSID命令查询获得。                    |
| REPQOSID   | 替换的QoS模板ID   | 用于标识一个替换后的Qos模板ID。在匹配的SGSN上，使用该ID对应的模板代替“用户签约的QoS模板ID”进行下发。该参数必须先由ADD QOSTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。 |

## 使用实例

修改“HLR序列号”为“1”，“用户签约的QoS模板ID”为“1”，“SGSN号码或号码前缀”为“860001”的一条QoS模板替换配置记录，将“替换的QoS模板ID”修改为“300”：

```
MOD REPQOSID: HLRSN=1, USRQOSID=1, SGSNPREFIX="860001", REPQOSID=300;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释                    | 原因分析                                                           | 处理建议                                                                                                        |
|:--------|:-------------------------|:---------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值                   | 参数“SGSN号码或号码前缀”的取值不是1～15位十进制数字组成的字符串。                          | 根据实际情况，重新输入参数“SGSN号码或号码前缀”的取值，确保其取值符合要求。                                                                    |
| ERR3003 | 模板未定义                    | 参数“用户签约的QoS模板ID”或“替换的QoS模板ID”没有在“HLR序列号”对应的虚拟HLR中预先定义。         | 根据实际情况，重新输入已定义的“用户签约的QoS模板ID”和“替换的QoS模板ID”，可通过LST QOSTPL命令查询虚拟HLR中已定义的QoS模板，确保输入的模板ID在“HLR序列号”对应的虚拟HLR中已定义。 |
| ERR3007 | 记录不存在                    | 参数“HLR序列号”、“用户签约的QoS模板ID”和“SGSN号码或号码前缀”的组合对应的QoS模板替换配置记录未预先定义。 | 使用LST REPQOSID令查询系统中已存在的QoS模板替代配置记录，根据查询结果中存在的QoS模板替换配置记录，重新输入相应的参数值。                                       |
| ERR4075 | 业务冲突，USRQOSID和REPQOSID相同 | 参数“用户签约的QoS模板ID”和“替换的QoS模板ID”的取值相同。                            | 根据实际情况，重新输入参数“用户签约的QoS模板ID”和“替换的QoS模板ID”，确保二者取值不同。                                                          |
