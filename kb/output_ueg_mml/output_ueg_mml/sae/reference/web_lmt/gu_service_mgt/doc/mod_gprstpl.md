## 命令功能

**须知** 

该操作会修改GPRS模板数据，是否继续？

该命令用于修改GPRS模板中的参数设置或在指定的GPRS模板中增加一条PDP Context。如果GPRS模板中需要定义多条PDP Context，需要使用**ADD GPRSTPL**命令定义一条PDP Context，然后使用命令MOD GPRSTPL增加多条数据。

## 注意事项

- 一个GPRS模板可能关联一个或多个PDP数据，但系统中所有GPRS模板所关联的PDP数量最大为5000个。
- PROV参数出现的时候，CNTXID参数必须同时出现。
- 当PROV=TRUE时，CNTXID在模板中已经存在，该操作为修改PDP context的内容。
- 当PROV=TRUE时，CNTXID在模板中不存在，则以下参数为必选参数：CNTXID、PDPTYPE、RELCLS、DELAYCLS、PRECLS、PEAKTHR、MEANTHR、APN，且该操作为增加PDP context至模板中。
- 当PROV=FALSE时，CNTXID在模板中已经存在，且该操作为删除PDP context。
- 当PROV=FALSE时，CNTXID在模板中不存在，系统会提示错误。
- 同一模板中的“CNTXID”不能重复。
- 新签约的GPRS PDP上下文和已经签约PDP上下文中PDPTYPE、ADDIND、APN三个参数不能同时一样。
- ADDIND为DYNAMIC，PDPADD参数不允许存在。ADDIND为STATIC，PDPADD参数必需存在。
- PDP上下文中MAXGBRDWL参数的值不能大于MAXBRDWL参数的值。
- PDP上下文中MAXGBRUPL参数的值不能大于MAXBRUPL参数的值。
- PDP上下文中MAXEXTGBRDWL参数的值不能大于MAXEXTBRDWL参数的值。
- PDP上下文中如果MAXEXTGBRDWL参数存在并且不为NOExtend时，MAXGBRDWL参数不能存在。
- PDP上下文中如果MAXEXTBRDWL参数存在并且不为NOExtend时，MAXBRDWL参数不能存在。
- 此模板被修改后，已经签约此模板的用户，数据不会被同步修改；后续再签约此模板的用户将使用修改后的模板数据。

## 使用实例

修改GPRS模板中的PDP上下文数据。PDP上下文索引为2，该索引在模板中已经存在，可靠性级别为ACKALLPRODT，延迟级别为DELAY3, 优先级别为HIGH, 峰值吞吐量为32000 Octet/s。命令如下：

MOD GPRSTPL: HLRSN=1, TPLID=3, PROV=TRUE, CNTXID=2, PDPTYPE=IPV4, RELCLS=ACKALLPRODT, DELAYCLS=DELAY3, PRECLS=HIGH, PEAKTHR=32000 OCT, ARPRIORITY=NORMAL;
