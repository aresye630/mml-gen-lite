# 修改用户的组属性(MOD GRPUSERATTR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改用户的组属性。

## 注意事项

- “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。
- “用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。

## 参数说明

| 参数标识        | 参数名称         | 参数说明                                                                                                                                                                                                            |
|:------------|:-------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI         | 用于标识需要修改组属性的用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                            |
| ISDN        | MSISDN       | 用于标识需要修改组属性的用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。                                                                                                                                                          |
| RECORDCOUNT | 用户个数         | 用于标识需要修改组属性的用户数目。 当需要为连续号码的多个用户修改组属性时配置该参数，配置后，系统将会从已指定的IMSI号码或MSISDN号码开始，对连续号码的多个用户修改组属性。 取值范围：1～100000 默认值：无。 说明：该参数是对连续号码的多个用户修改组属性，当只有一个用户时，该参数不必配置。当一次设置的用户个数很多时，对系统性能无影响，但设置的用户个数越多，消耗的时间越长，一般从几分钟到几小时不等。 |
| IMSIFILE    | IMSI文件名      | 用于标识IMSI批操作文件。 IMSI批操作文件包含多个不连续的需要修改组属性的用户的IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“IMSIBAT”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                                       |
| ISDNFILE    | MSISDN文件名    | 用于标识MSISDN批操作文件。 MSISDN批操作文件包含多个不连续的需要修改组属性的用户的MSISDN号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“MSISDNBAT”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见ISDNFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。                               |
| DENYUSSD    | 成员用户USSD操作权限 | 用于标识成员用户USSD操作权限。 取值范围：Denied：成员用户允许通过USSD请求操作自己的GROUPSIM业务。Not_Denied：成员用户允许通过USSD请求操作该用户所在群组的所有成员用户的GROUPSIM业务。Not_Support：成员用户不允许通过USSD请求操作该用户所在群组的所有成员用户的GROUPSIM业务。 默认值：Not_Support                        |
| MBRDC       | 成员用户直接呼叫权限   | 用于标识直接拨打GROUPSIM组的成员号码时，HSS/HLR是否禁止此呼叫。 取值范围： Denied：禁止。该成员用户无法收到主叫用户的呼叫。Not_Denied：不禁止。该成员用户能正常收到主叫用户的呼叫。 默认值：Not_Denied                                                                                       |

## 使用实例

1. 修改IMSI号码为“123111111111111”的用户的组属性，并指定“成员用户USSD操作权限”为“Denied”：

   ```
   MOD GRPUSERATTR: IMSI="123111111111111", DENYUSSD=Denied;
   ```
2. 修改3个连续号码的用户的“成员用户USSD操作权限”，这3个MSISDN号码分别为“13310911001”、“13310911002”、“13310911003”，对应的“成员用户USSD操作权限”为“Denied”：

   ```
   MOD GRPUSERATTR: ISDN="13310911001", RECORDCOUNT=3, DENYUSSD=Denied;
   ```
3. 修改两个非连续号码的用户的组属性，这2个IMSI号码分别为“460000000000000”和“123111111111111”，已保存在“IMSI文件名”为“IMSIBAT”的文件中，并通过文件管理功能上传到指定目录，并指定“成员用户USSD操作权限”为“Denied”：

   ```
   MOD GRPUSERATTR: IMSIFILE="IMSIBAT", DENYUSSD=Denied;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                                               | 处理建议                                                                                                                    |
|:--------|:--------|:---------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 可能原因为如下之一：参数“IMSI”的取值不是6～15位十进制数字组成的字符串。参数“MSISDN”的取值不是1～15位十进制数字组成的字符串。                           | 根据实际情况，重新输入“IMSI”或“MSISDN”的取值，确保其取值符合要求。                                                                                |
| ERR1009 | 参数丢失    | “IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数一个都没有输入。                                                  | 根据实际情况，重新输入参数，并满足“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数必须有且只能有一个参数出现的条件。                                             |
| ERR1005 | 文件未找到   | “IMSI文件名”或“MSISDN文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                                                   | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。                                       |
| ERR1010 | 参数冲突    | 可能原因为如下之一：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数中有两个以上的参数被输入。“用户个数”与“IMSI文件名”或“MSISDN文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”、“MSISDN”、“IMSI文件名”、“MSISDN文件名”四个参数是可选参数，必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”或“MSISDN文件名”同时配置。 |
| ERR3001 | 用户未开户   | 用户的IMSI号码或MSISDN号码输入错误，实际输入的参数“IMSI”或“MSISDN”对应的用户未开户。                                             | 核实用户的IMSI号码或MSISDN号码，如果确定输入无误，证明实际输入的参数“IMSI”或“MSISDN”对应的用户未开户，请先通过ADD SUB命令给用户开户。                                      |
