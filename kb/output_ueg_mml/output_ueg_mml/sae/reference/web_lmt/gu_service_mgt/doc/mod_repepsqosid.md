# 修改EPS QoS模板替代配置(MOD REPEPSQOSID)

- 命令功能
- 注意事项
- 参数说明

- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行不当会导致用户漫游到指定的MME/S4SGSN/AAA时下发错误的QoS，因此执行本命令前，需要和运营商的EPS QoS模板替代配置表进行仔细核对，并详细阅读本命令的联机帮助和注意事项，确保修改的EPS QoS模板替代配置完全正确。如运营商无法给出具体的配置表或有其他疑问，请与华为技术支持联系制定操作的实施方案、测试方案和回退方案后才可以实施。

该命令用于在UDM中修改一条EPS QoS模板替代配置记录。在该命令中，系统通过以下关键参数的组合来唯一标识一条EPS QoS模板替代配置记录：

- “HLR序列号”
- “用户签约的EPS QoS模板ID”
- “对端身份标识”

从而对对应的“对端身份标识类型”或“替代的EPS QoS模板ID”进行修改。

## 注意事项

- 当设置了EPS QoS模板替代配置，系统会根据用户签约的EPS QoS模板找到替换的模板配置并下发数据，用户原来签约的EPS QoS模板将不会生效，会影响大量在网用户，因此现网执行该操作时需要慎重。执行该命令前需确定待修改的EPS QoS替代配置和运营商的EPS QoS模板替代配置表完全一致，并确保使用原EPS QoS模板的MME/S4-SGSN/3GPP AAA Server上支持替换后的EPS QoS模板对应的QoS数据。
- 该命令不允许进行批操作。
- 替换后和替换前的EPS QoS模板中，“QoS分类ID”（QCI）取值对应的Resource Type需要保持一致。GBR类型的QCI替换后必须仍为GBR类型，Non-GBR类型的QCI替换后必须仍为Non-GBR类型。QCI取值和Resource Type具体的对应关系，请参见协议3GPP TS 23.203中的相应内容。

## 参数说明

| 参数标识           | 参数名称             | 参数说明                                                                                                                                                                                                                               |
|:---------------|:-----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN          | HLR序列号           | 用于标识EPS QoS模板替代配置记录的关键字段之一（其取值不能被修改），用于指定需要对哪个HLR中EPS QoS模板替代配置记录的参数进行修改，操作员可以使用LST HLRSN命令查询获得。                                                                                                                                   |
| USREPSQOSID    | 用户签约的EPS QoS模板ID | 用于标识EPS QoS模板替代配置记录的关键字段之一（其取值不能被修改），用于指定需要对哪个用户签约的EPS QoS模板ID修改替代后的模板ID，操作员可以使用LST REPEPSQOSID命令查询获得。                                                                                                                             |
| PEERENTITYTYPE | 对端身份标识类型         | 用于标识修改后的Diameter服务节点身份标识类型。 取值范围：Host Name：主机名，表示通过Diameter服务节点设备的主机名进行身份标识。Realm Name：域名，表示通过Diameter服务节点所在域的域名进行身份标识。 默认值：无。 说明：如果一个Diameter服务节点同时对应“对端身份标识类型”为“Host Name”和“Realm Name”的两条记录，则只会匹配其中“对端身份标识类型”为“Host Name”的一条记录。 |
| PEERENTITY     | 对端身份标识           | 用于标识EPS QoS模板替代配置记录的关键字段之一（其取值不能被修改），用于指定需要修改替代配置的Diameter服务节点的身份标识，操作员可以使用LST REPEPSQOSID命令查询获得。                                                                                                                                  |
| REPEPSQOSID    | 替代的EPS QoS模板ID   | 用于标识一个替换后的EPS Qos模板ID。使用该ID对应的模板代替“用户签约的EPS QoS模板ID”进行下发。该参数必须先由ADD EPSQOSTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。                                                                                                                   |

## 使用实例

1. 修改“HLR序列号”为“1”，“用户签约的QoS模板ID”为“1”，“对端身份标识”为“test.huawei.com”的一条EPS QoS模板替代配置记录，将“替代的EPS QoS模板ID”修改为“200”：

   ```
   MOD REPEPSQOSID: HLRSN=1, USREPSQOSID=1, PEERENTITY="test.huawei.com", REPEPSQOSID=200;
   ```
2. 修改“HLR序列号”为“1”，“用户签约的QoS模板ID”为“1”，“对端身份标识”为“test.huawei.com”的一条EPS QoS模板替代配置记录，将“对端身份标识类型”修改为“Realm Name”：

   ```
   MOD REPEPSQOSID: HLRSN=1, USREPSQOSID=1, PEERENTITYTYPE=Realm Name, PEERENTITY="test.huawei.com";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                | 处理建议                                                                                                                        |
|:--------|:--------|:--------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”参数不在相应的参数取值范围内。                                       | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                            |
| ERR1009 | 参数丢失    | 参数“对端身份标识类型”和“替代的EPS QoS模板ID”都没有输入。                                 | 根据实际情况，重新输入参数，确保满足“对端身份标识类型”和“替代的EPS QoS模板ID”参数至少输入一个。                                                                      |
| ERR3003 | 模板未定义   | 参数“用户签约的EPS QoS模板ID”或“替代的EPS QoS模板ID”没有在“HLR序列号”对应的虚拟HLR中预先定义。      | 根据实际情况，重新输入已定义的“用户签约的EPS QoS模板ID”和“替代的EPS QoS模板ID”，可通过LST EPSQOSTPL命令查询虚拟HLR中已定义的EPS QoS模板，确保输入的模板ID在“HLR序列号”对应的虚拟HLR中都已定义。 |
| ERR3007 | 记录不存在   | 参数“HLR序列号”、“用户签约的EPS QoS模板ID”和“对端身份标识”三者的组合对应的EPS QoS模板替代配置记录未预先定义。 | 使用LST REPEPSQOSID命令查询系统中已存在的EPS QoS模板替代配置记录，根据查询结果中存在的EPS QoS模板替代配置记录，重新输入相应的参数值。                                           |
