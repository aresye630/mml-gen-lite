## 命令功能

**须知** 

本命令属于高危命令，执行不当会造成用户的CB、ODB等业务失效，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于在HLR中增加一条被叫号码分析数据记录。在开局配置本局数据时需要根据运营商要求将该HLR中使用的所有被叫号码分析数据全部添加到配置数据库。

被叫号码分析数据主要用于：

- 分析前转号码和规整号码

  将前转号码同号码分析数据记录中的“呼叫字冠”进行最大匹配，获取前转号码的业务属性从而进行号码规整的相关逻辑流程。
- 检查号码属性

  在前转号码规整得到的一些前转号码属性，也是前转业务与其他业务（如CB、ODB等）进行冲突检测的依据。例如用户签约禁止前转到娱乐台，通过被叫号码分析数据记录查找到被前转号码是一个娱乐台，则禁止用户登记该前转号码。

## 注意事项

- 该命令不允许进行批操作。
- 同一个“HLR序列号”中增加的被叫号码分析数据记录数不能超过1000条。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                                                                                                                                                                                       |
|:-----------|:---------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN      | HLR序列号   | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                                                                               |
| CALLPREFIX | 呼叫字冠     | 用于标识需要分析的被叫号码的前缀，是被叫号码中从第一位开始且连续的一串号码，它既可以是被叫号码的前一位或前几位号码，也可以是被叫号码的全部号码，也就是说，呼叫字冠是被叫号码的一个子集。本字段一般需要配置PSTN（Public Switched Telephone Network）前转号码前缀0～9 ，本网的移动号码前缀，以及国际号码前缀00或001。 该参数支持最大匹配原则。最大匹配原则是指在查询时对于一个具体的号码而言，系统将在所有的记录中查找与其号码最相近的一个。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 |
| SERPROP    | 业务属性     | 用于标识被叫号码的属性。业务属性的配置主要用于判断前转号码的属性，并通过前转号码的属性对照SET MAPSERV命令中的“前转地区限制”参数，来决定前转号码登记能否成功。 取值范围：LOCAL：本地固定号码NATIONAL：国内长途PLMN：移动号码INTERNATIONAL：国际长途OTHER：属性未知，无法设置为前转号码，会导致号码处理失败 默认值：无。                                                                                       |
| INFOFLAG   | 是否信息台号码  | 用于标识是否信息台号码。执行MOD ODBINFO命令可以设置是否被闭锁信息台业务，根据该业务的闭锁情况，决定信息台号码作为前转号码登记能否成功。 取值范围：TRUE：是信息台号码FALSE：不是信息台号码 默认值：无。                                                                                                                                                             |
| ENTERFLAG  | 是否娱乐台号码  | 用于标识是否娱乐台号码。执行MOD ODBENTE命令可以设置是否被闭锁娱乐台业务，根据该业务的闭锁情况，决定娱乐台号码作为前转号码登记能否成功。 取值范围：TRUE：是娱乐台号码FALSE：不是娱乐台号码 默认值：无。                                                                                                                                                             |
| VMSFLAG    | 是否语音信箱号码 | 用于标识是否语音信箱号码。 用户签约闭锁出呼叫的类型为闭锁所有呼出业务ODB-BAOC（Operator-Determined Barring–Barring of All Outgoing Calls），且呼叫前转业务激活时： 如果用户的前转号码是语音信箱号码，则登记前转号码成功。如果前转号码是其他号码，则登记前转号码失败。 取值范围：TRUE：是语音信箱号码FALSE：不是语音信箱号码 默认值：无。                                                                |
| PROV       | 是否提供号码长度 | 用于标识是否启用号码长度限制功能。例如，前转号码与“呼叫字冠”最大匹配结果是“PLMN”，但是此时的前转号码长度不在“最小号码长度”以及“最大号码长度”区间内，那么该号码的属性就不是“PLMN”，继续寻求其次的匹配结果进行处理。 取值范围： TRUE：启用FALSE：不启用 默认值：无。                                                                                                                           |
| MINLEN     | 最小号码长度   | 仅当本命令中的“是否提供号码长度”参数为“TRUE”时该参数有效。用于标识前转号码的最小长度。 取值范围：1～32 默认值：无。 配置原则：该参数的取值不能大于“最大号码长度”参数的取值。该参数的取值不能小于“呼叫字冠”参数的长度。                                                                                                                                                       |
| MAXLEN     | 最大号码长度   | 仅当本命令中的“是否提供号码长度”参数为“TRUE”时该参数有效。用于标识前转号码的最大长度。 取值范围：1～32 默认值：无。                                                                                                                                                                                                           |

## 使用实例

在被叫号码分析数据记录中，配置数据如表1所示。

|   呼叫字冠 | 业务属性   | 信息台号码   | 娱乐号码   | 语音信箱号码   |
|-------:|:-------|:--------|:-------|:---------|
|    138 | 移动网    | 否       | 否      | 否        |
|    168 | 本地     | 否       | 是      | 是        |
|   1860 | 本地     | 是       | 否      | 是        |

命令如下：

- ```
  ADD CALLEDNA: HLRSN=1, CALLPREFIX="138", SERPROP=PLMN, INFOFLAG=FALSE, ENTERFLAG=FALSE, VMSFLAG=FALSE;
  ```
- ```
  ADD CALLEDNA: HLRSN=1, CALLPREFIX="168", SERPROP=LOCAL, INFOFLAG=FALSE, ENTERFLAG=TRUE, VMSFLAG=TRUE;
  ```
- ```
  ADD CALLEDNA: HLRSN=1, CALLPREFIX="1860", SERPROP=LOCAL, INFOFLAG=TRUE, ENTERFLAG=FALSE, VMSFLAG=TRUE;
  ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表2所示。

| 错误码     | 错误码解释   | 原因分析                                   | 处理建议                                                                                                                                |
|:--------|:--------|:---------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | “HLR序列号”未定义。                           | 根据实际情况，重新输入“HLR序列号”的取值，确保其取值符合要求。                                                                                                   |
| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”参数不在相应的参数取值范围内。          | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                                                    |
| ERR3006 | 记录已存在   | 本次操作输入的“HLR序列号”和“呼叫字冠”对应的数据记录在数据库中已存在。 | 根据实际情况，重新输入参数，确保输入的“HLR序列号”和“呼叫字冠”与系统中已存在的不重复。可执行LST CALLEDNA命令查询系统中已存在的被叫号码分析数据。                                                   |
| ERR3047 | 超过最大限制  | 同一个“HLR序列号”中增加的被叫号码分析数据记录数超过1000条。     | 根据实际情况，如需增加被叫号码分析数据，处理步骤如下：执行LST CALLEDNA命令，查询已存在的被叫号码分析数据。执行RMV CALLEDNA命令，删除不必要的被叫号码分析数据。执行该命令增加被叫号码分析数据，确保增加的被叫号码分析数据记录数在规定范围之内。 |
