# 查询4升5迁移指令PID规则(LST SINGLEUSERMOVEPIDS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询4升5迁移指令PID规则数据记录。

- 若需要查询所有已配置的4升5迁移指令PID规则，则不输入任何参数。
- 若需要查询某个4升5迁移指令PID规则，请输入“用户源PID”参数。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                         |
|:-------|:-------|:-----------------------------------------------------------------------------|
| SRCPID | 用户源PID | 可选必选说明：可选参数 参数含义：用于标识要查询哪个用户源PID对应的4升5迁移指令PID规则记录。 取值范围：1～250 默认值：无。 配置原则：无。 |

## 使用实例

1. 查询“用户源ID”为“21”的4升5迁移指令PID规则数据：

   ```
   LST SINGLEUSERMOVEPIDS: SRCPID=21;
   ```

   ```
   %%LST SINGLEUSERMOVEPIDS: SRCPID=21;%%
   RETCODE = 0 SUCCESS0001:操作成功

                             SRCPID = 21
                            DESTPID = 81

   Total count = 2

   There is together 1 report

   ---    END
   ```
2. 查询所有的4升5迁移指令PID规则数据：

   ```
   LST SINGLEUSERMOVEPIDS:;
   ```

   ```
   %%LST SINGLEUSERMOVEPIDS:;%%
   RETCODE = 0 SUCCESS0001:操作成功

   SRCPID           DESTPID 
   21                81
   22                82

   Total count = 2

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                    | 处理建议                                                                                              |
|:--------|:--------|:------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | 输入了“用户源PID”参数，“用户源PID”对应的4升5迁移指令PID规则记录不存在。未输入参数，UDM中不存在4升5迁移指令PID规则记录。 | 不输入参数执行LST SINGLEUSERMOVEPIDS查询4升5迁移指令PID规则记录。先执行ADD SINGLEUSERMOVEPIDS增加4升5迁移指令PID规则记录，再执行该命令查询。 |
