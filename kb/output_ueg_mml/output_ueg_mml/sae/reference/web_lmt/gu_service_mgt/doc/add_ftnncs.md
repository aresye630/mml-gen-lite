# 增加前转号码数据(ADD FTNNCS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于增加前转号码是否通知主叫用户的属性。在呼叫前转补充业务中，对于某个前转号码，有前转通知主叫用户的签约项，可以设置为“通知”或“不通知”。通过增加前转号码的通知主叫用户属性，运营商可以决定当呼叫前转到某个前转号码时，是否通知主叫用户。

前转号码的通知主叫用户属性属于本局数据，在系统配置本局数据时进行设置。

## 注意事项

同一个“HLR序列号”中增加的前转号码是否通知主叫用户的属性记录数不能超过1000条。

## 参数说明

| 参数标识   | 参数名称     | 参数说明                                               |
|:-------|:---------|:---------------------------------------------------|
| HLRSN  | HLR序列号   | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。       |
| FTN    | 前转号码     | 用于标识用户签约的前转号码。 取值范围：1～28位十进制数字组成的字符串。 默认值：无。       |
| NCS    | 是否通知主叫用户 | 用于标识当发生呼叫前转时是否通知主叫用户。 取值范围：TRUE：通知FALSE：不通知 默认值：无。 |

## 使用实例

1. 运营商通过PGW Web LMT给“MSISDN”为“008618912340000”的用户签约缺省呼叫前转业务，当发生呼叫前转时，系统不通知主叫用户，此时需要做如下配置。

   1. 执行**MOD CFD**命令为用户签约缺省呼叫前转业务。其中，“是否提供CFD业务”为“TRUE”，“前转号码”为“8613955550000”：

      ```
      MOD CFD: IMSI="8618912340000", PROV=TRUE, FTN="8613955550000";
      ```
   2. 执行**ADD FTNNCS**命令为用户设置前转号码的通知主叫用户属性。其中，“HLR序列号”为“1”，“前转号码”为“8613955550000”，“是否通知主叫用户”为“FALSE”：

      ```
      ADD FTNNCS: HLRSN=1, FTN="8613955550000", NCS=FALSE;
      ```

      **说明** 

      **MOD CFD**命令也可以用来设置前转号码的通知主叫用户属性。只是**ADD FTNNCS**命令配置的通知主叫用户属性比**MOD CFD**命令配置的通知主叫用户属性优先级高。
2. 在“HLR序列号”为“1”的HLR上，增加呼叫前转补充业务中前转号码的属性，使得发生呼叫前转时，系统通知主叫用户。其中，“前转号码”为“8613955550001”，“是否通知主叫用户”为“TRUE”：

   ```
   ADD FTNNCS: HLRSN=1, FTN="8613955550001", NCS=TRUE;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                          | 处理建议                                                                                                                                                                        |
|:--------|:--------|:------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 参数“前转号码”的取值中含有0～9以外的字符。       | 重新输入“前转号码”，确保只含有0～9以内的字符。                                                                                                                                                   |
| ERR3006 | 记录已存在   | 重复为同一个HLR序列号下的同一个前转号码添加相同的属性。 | 该前转号码属性已添加，根据实际情况确认是否需要添加其他前转号码的属性。                                                                                                                                         |
| ERR3007 | 记录不存在   | HLR序列号未定义。                    | 根据实际情况选择：如果需要为某个HLR序列号添加前转号码属性，则执行ADD HLRSN命令先定义该HLR序列号，再为该HLR序列号添加前转号码属性。如果需要为已定义的HLR序列号添加前转号码属性，则执行LST HLRSN命令先查询已定义的HLR序列号，再为已定义的HLR序列号添加前转号码属性。                         |
| ERR1111 | 超过最大限制  | 增加的前转号码是否通知主叫用户的属性记录数超过1000条。 | 根据实际情况，如需增加前转号码是否通知主叫用户的属性记录，处理步骤如下：执行LST FTNNCS命令，查询已存在前转号码是否通知主叫用户的属性记录。执行RMV FTNNCS命令，删除不必要的前转号码是否通知主叫用户的属性记录。执行该命令，增加的前转号码是否通知主叫用户的属性记录，确保增加后前转号码是否通知主叫用户的属性记录数在规定范围之内。 |
