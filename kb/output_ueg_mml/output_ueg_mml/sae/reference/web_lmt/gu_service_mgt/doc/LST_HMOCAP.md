# 查询必选或可选能力(LST HMOCAP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询指定IMPU或PUSI关联的必选能力和可选能力需求。

## 注意事项

参数SUBID和参数PISI必须存在且仅能存在其中的一个。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                      |
|:-------|:-------|:------------------------------------------------------------------------------------------|
| SUBID  | SUBID  | 用于指定一个需要设置能力集的SUBID，该参数必须先由ADD HSUB操作定义，然后才能在此处索引，SUBID字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无 |
| PISI   | PISI   | 用于定义PISI的值，配置原则是要求输IMPI值符合NAI格式，字母区分大小写。 取值范围： 长度不超过127的字符串 缺省值： 无                        |

## 使用实例

查询必选或可选能力。用户ID：subinfo。

```
LST HMOCAP: SUBID="subinfo";
```

## 输出结果说明
