# 修改CSI前缀号码匹配(MOD CSIPREFIX)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

此命令用来管理ISDN或IMSI号码前缀和UCSI模板之间的对应关系。

如果系统中同时存在IMSI前缀和ISDN前缀的记录，进行匹配时优先根据IMSI前缀来进行匹配。

## 注意事项

- 添加或者修改ISDN或IMSI号码前缀和UCSI的对应关系前，先要添加相应UCSI模板。
- 同一个“HLR序列号”中增加的ISDN或IMSI号码前缀与UCSI模板对应关系记录数不能超过3000条。

## 参数说明

| 参数标识       | 参数名称     | 参数说明                                                                                                    |
|:-----------|:---------|:--------------------------------------------------------------------------------------------------------|
| HLRSN      | HLR序列号   | HLR序列号。 取值范围：1～255。 说明：必选参数，在PGW支持容灾功能或虚拟HLR功能时设置。                                                      |
| PREFIXNUM  | 号码前缀     | ISDN或IMSI号码前缀。 取值范围：1～15位十进制数字组成的字符串。 说明：必选参数。                                                          |
| OPTYPE     | 操作类型     | 操作类型。 取值范围： ADD：增加 MODIFY：修改 DELETE：删除 说明：必选参数，该参数用来设置是增加、修改或者删除ISDN或IMSI号码前缀与UCSI模板对应关系。               |
| CSITPLID   | UCSI模板ID | UCSI模板ID。 取值范围：0～65534。 说明：当操作类型为ADD或MODIFY时，此参数为必选参数。                                                  |
| PREFIXTYPE | 号段类型     | 仅当“操作类型”取值为“ADD”时，该参数有效。 用于标识参数“号码前缀”指定的前缀号码类型。 取值范围： MSISDN：ISDN号码前缀IMSI：IMSI号码前缀 缺省值： MSISDN 说明：可选参数。 |

## 使用实例

1. 增加一个ISDN号码前缀，“HLR序列号”为“1”，“号码前缀”为“12345”，“操作类型”为“ADD”，“UCSI模板ID”为“3”，“号段类型”为“MSISDN”：

   ```
   MOD CSIPREFIX: HLRSN=1, PREFIXNUM="12345", OPTYPE=ADD, CSITPLID=3, PREFIXTYPE=MSISDN;
   ```
2. 删除一个号码前缀，“HLR序列号”为“1”，“号码前缀”为“12345”，“操作类型”为“DELETE”：

   ```
   MOD CSIPREFIX: HLRSN=1, PREFIXNUM="12345", OPTYPE=DELETE;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                   | 处理建议                                                                                                                                                                                                                                                    |
|:--------|:--------|:---------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1111 | 超过最大限制  | 增加的ISDN或IMSI号码前缀与UCSI模板对应关系记录数超过3000条。 | 根据实际情况，如需增加ISDN或IMSI号码前缀与UCSI模板对应关系记录，处理步骤如下：执行LST CSIPREFIX命令，查询已存在ISDN或IMSI号码前缀与UCSI模板对应关系记录。执行该命令，将参数“操作类型”设置为“DELETE”删除不必要的ISDN或IMSI号码前缀与UCSI模板对应关系记录。执行该命令，将参数“操作类型”设置为“ADD”增加的ISDN或IMSI号码前缀与UCSI模板对应关系记录，确保增加后ISDN或IMSI号码前缀与UCSI模板对应关系记录数在规定范围之内。 |
