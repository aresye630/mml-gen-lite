# 查询特殊前转号码限制（LST RESSPECFTN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于查询特殊前转号码限制表中的前转号码信息：

- 若需要查询特殊前转号码限制表中的所有前转号码信息，则输入“HLR序列号”。
- 若需要查询特殊前转号码限制表中的指定前转号码信息，则输入“HLR序列号”和“前转限制号码”参数。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                   |
|:-------|:-------|:---------------------------------------|
| HLRSN  | HLR序列号 | 用于指示系统按照哪个HLR序列号来查询特殊前转号码限制表中的前转号码信息。  |
| RESFTN | 前转限制号码 | 用于指示系统需要按照哪个前转限制号码查询特殊前转号码限制表中的前转号码信息。 |

## 使用实例

1. 查询特殊前转号码限制表中的“前转限制号码”为“861380755001”的信息：

   ```
   LST RESSPECFTN: HLRSN=1, RESFTN="861380755001";
   ```

   ```
   %%LST RESSPECFTN: HLRSN=1, RESFTN="861380755001";%%
   RETCODE = 0 SUCCESS0001:操作成功

   "RESFTN"
    861380755001

   Total count = 1

   There is together 1 report

   ---    END
   ```
2. 查询特殊前转号码限制表中的所有前转号码信息：

   ```
   LST RESSPECFTN: HLRSN=1;
   ```

   ```
   %%LST RESSPECFTN: HLRSN=1%%
   RETCODE = 0 SUCCESS0001:操作成功

   "RESFTN"
   861380755001
   861380755002

   Total count = 2

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**SET RESSPECFTN**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                  | 处理建议                                                                       |
|:--------|:--------|:------------------------------------------------------|:---------------------------------------------------------------------------|
| ERR3007 | 记录不存在   | 可能原因为如下之一：“HLR序列号”或“前转限制号码”不存在。输入的“HLR序列号”下无前转限制号码记录。 | 根据实际情况，重新输入参数，确保满足以下两点：输入的“HLR序列号”或“前转限制号码”参数其取值符合要求。输入的“HLR序列号”有前转限制号码记录。 |
