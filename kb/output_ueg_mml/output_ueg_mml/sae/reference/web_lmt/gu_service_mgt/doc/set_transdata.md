# 数据迁移和整改 (SET TRANSDATA)

- 命令功能
- 注意事项
- 参数说明

## 命令功能

该命令用于在混合组网场景下，将在HSS上的2G/3G/4G/IMS用户签约数据迁移至5G的UDM中，并根据该命令中的模板参数，整改迁移过来的用户数据。

## 注意事项

- 该命令不支持一号多卡、一卡多号、多号多卡类业务。
- 执行该命令时，**SET MAPSERV**命令的“GPRS管理方式”参数必须设置为“SuppPsEpsSeparateTplManager”。“GPRS管理方式”参数开局设定之后不能修改。如非开局场景，请勿修改此参数配置。
- “IMSI”、“MSISDN”、“IMSI文件名”和“MSISDN文件名”四个参数必须有且只能有一个参数出现。
- “用户个数” 参数不能与“IMSI文件名”或“MSISDN文件名”同时存在，“用户个数”参数只能与“IMSI”或“MSISDN”一起出现。
- 在混合组网模式为1（**MOD INSP**命令中的“组网模式”软参为“1”）时，HSS和UDM全局数据不同步。UDM和HSS的K4配置必须一致，如果有冲突，需要先整改，否则会导致迁移后解密出错误的KI数据。
- 该命令为局点定制命令，非定制局点使用前请务必先联系华为技术支持。
- 该命令仅限于迁移签约了VLR/SGSN漫游限制模板、LCS模板、O-CSI模板、T-CSI模板、CFU OFA模板、CFB OFA模板、EPS用户模板、EPS漫游限制模板、拜访网络模板、Service Profile信息模板、能力集信息模板或计费地址模板的用户，如果用户签约的模板范围超过这个范围，迁移到UDM后会由于找不到模板数据，造成用户业务受损。如果超过了范围外的模板，需要提前对范围外的模板类型进行检查。
- “5G用户模板ID”和“CSPS用户模板ID”同时存在时，如果“5G用户模板ID”中定义了“用户计费签约数据”参数，计费签约数据以“5G用户模板ID”中的为准，否则，以“CSPS用户模板ID”中定义的计费参数为准。
- 当用户签约的“5G用户模板ID”模板数据发生修改时，如果模板新增或修改了“用户计费签约数据”参数，计费签约数据以修改后的“5G用户模板ID”中的为准。

## 使用实例

混合组网场景下，将在HSS上的用户签约数据迁移至5G的UDM后，使用已定义好的“CSPS用户模板”，“EPS用户模板”，“PS用户模板”，“IMS用户模板”，“EPS漫游限制模板”，对迁移过来的用户数据进行整改。

1. 对“HLR序列号”为“1”，“IMSI”为“460000009123456”的用户进行数据迁移和整改，其中“CSPS用户模板ID”为“1”，“EPS用户模板ID”为“1”，“PS用户模板ID”为“1”，“5G用户模板ID”为“1”，“IMS用户模板ID”为“1”，“EPS漫游限制模板ID”为“1”：

   ```
   SET TRANSDATA: HLRSN=1, IMSI="460000009123456", CSPSTPLID=1, EPSUSERTPLID=1, PSUSERTPLID=1, NGSUSERTPLID=1, IMSTPLID=1, DIAMNODETPL_ID=1;
   ```
2. 对“HLR序列号”为“1”，“IMSI”为“460000009123456”、“460000009123457”、“460000009123458”的3个连续用户进行数据迁移和整改，其中“CSPS用户模板ID”为“5”，“EPS用户模板ID”为“5”，“PS用户模板ID”为“5”，“5G用户模板ID”为“5”，“IMS用户模板ID”为“5”，“EPS漫游限制模板ID”为“5”：

   ```
   SET TRANSDATA: HLRSN=1, IMSI="460000009123456", RECORDCOUNT=3, CSPSTPLID=5, EPSUSERTPLID=5, PSUSERTPLID=5, NGSUSERTPLID=5, IMSTPLID=5, DIAMNODETPL_ID=5;
   ```
