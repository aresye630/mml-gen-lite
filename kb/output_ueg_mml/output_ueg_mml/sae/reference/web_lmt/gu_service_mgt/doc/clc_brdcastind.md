# 生效取消广播指示(CLC BRDCASTIND)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于从集中业务管理系统CSMS（Central Service Management System）到本地业务管理系统LSMS（Local Service Management System）发送指示消息，通知所有参与的网络，NP（Number Portability）生效广播失败，LSMS更新号码携带数据库NPDB（Number Portability Database），恢复生效广播前的数据。

## 注意事项

- 此命令只适用NP业务SOAP（Simple Object Access Protocol）格式接口，且运营商有此适配需求。
- 华为NP业务SOAP格式接口遵循中国移动规范设计。
- **SET MAPCONF**的“NPHLR是否检查网络ID”设置为“TRUE”时，携入网络ID和用户归属网络ID归属同一个运营商，则NPHLR删除携转记录。

## 参数说明

| 参数标识        | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
|:------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MSGID       | 消息ID   | 用于标识消息ID的值。 取值范围：长度为16位的十进制数字。 默认值：无。 说明：必选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| CMDCODE     | 消息命令码  | 用于标识消息命令码的值。 取值范围：ACT_BROADCAST_REVERSE_IND。 默认值：无。 说明：必选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| SERVICETYPE | 业务类型   | 用于标识业务类型。 取值范围：MOBILE：移动号码携带。FIXED：固定号码携带。 默认值：无。 说明：必选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| BRCID       | 广播ID   | 用于标识广播消息ID的值。 取值范围：长度为16位的十进制数字。 默认值：无。 说明：必选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ISDN        | NP号码   | 用于标识中国区用户号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无。 说明：必选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| NPDATALIST  | NP数据列表 | 用于标识NP业务的数据列表。 取值范围：48～61位字符串。 配置原则：该参数格式为“NP号码|携入方网络ID|携出方网络ID|号码拥有网络ID|时间戳”。 “NP号码”是1～14位十进制数字组成的字符串。“携入方网络ID”、“携出方网络ID”和“号码拥有网络ID”是长度均为8位的十进制数字。前三位为运营商代码（中国区现有四个运营商，中国电信001，中国移动002，中国联通003，中国广电005）；第四位为运营商网络标识符（1为CDMA，2为CDMA2000，3为GSM，4为TD-SCDMA，5为WCDMA）；5～7位为本地网标识码；第8位为拓展位，默认值为0。“携入方网络ID”、“携出方网络ID”和“号码拥有网络ID”的前四位支持以下取值：0011：中国电信CDMA。0012：中国电信CDMA2000。0023：中国移动GSM。0024：中国移动TD-SCDMA。0033：中国联通GSM。0035：中国联通WCDMA。0000：存有试验本地网数据的CSMS。0010：新增网络ID。0020：新增网络ID。0030：新增网络ID。0050：中国广电网络。 “时间戳”是长度为19位的字符串，参数格式为：yyyy-mm-dd hh:mm:ss。 默认值：无。 说明：必选参数。 |
| REMARK      | 备注     | 用于标识备注信息。 取值范围：1～128位字符串。 默认值：无。 说明：可选参数。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |

## 使用实例

NP生效取消的广播指示，“消息ID”为“1234567891563589”，“消息命令码”为“ACT\_BROADCAST\_REVERSE\_IND”，“业务类型”为“MOBILE”，“广播ID”为“1230564896312563”，“NP号码”为“8615963256984”，“NP数据列表”为“8615963526868|00231250|00243650|00114890|1988-12-19 15:35:39”，命令如下：

```
CLC BRDCASTIND: MSGID = "1234567891563589", CMDCODE = "ACT_BROADCAST_REVERSE_IND", SERVICETYPE = "MOBILE", BRCID = "1230564896312563", ISDN = "8615963256984", NPDATALIST = "8615963526868|00231250|00243650|00114890|1988-12-19 15:35:39";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|   错误码 | 错误码解释            | 原因分析                                  | 处理建议                                                                                                                                                                  |
|------:|:-----------------|:--------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|   621 | 本局功能属性不对         | 功能属性不是NPMSC或者NPHLR                    | 登录PGW Web LMT，在“UDM业务管理”MML导航树下执行SET FUNCCONF命令，将功能属性改为NPMSC或者NPHLR。                                                                                                  |
|   401 | 网络ID的值未定义        | 网络ID取值有固定范围                           | 参考“NP数据列表”的参数含义说明，确保其取值符合要求。                                                                                                                                          |
|   621 | 本局RN未配置          | 本局RN未在环境中配置                           | 登录PGW Web LMT，在“UDM业务管理”MML导航树下执行SET INTROFF命令配置本局RN，“本网RN”参数取值范围如下: 1241：中国电信。1242：中国移动。1243：中国联通。                                                                   |
|   621 | 本局RN不正确          | 本局RN取值有固定范围                           | 登录PGW Web LMT，在“UDM业务管理”MML导航树下执行LST INTROFF命令查询本局RN，然后执行SET INTROFF命令修改“本网RN”，参数取值范围如下: 1241：中国电信。1242：中国移动。1243：中国联通。                                               |
|   621 | 网络ID与本局RN有冲突     | 携入方网络ID对应的RN、携出方网络ID对应的RN与本局RN三者不能够相等 | 修改方案：修改参数“NP数据列表”中的“携入方网络ID”，使其对应的RN与本局RN不同。修改参数“NP数据列表”中的“携出方网络ID”，使其对应的RN与本局RN不同。 网络ID中运营商代码部分与RN有一定的对应关系： “001”对应“1241”。“002”对应“1242”。“003”对应“1243”。“005”对应“1245”。 |
|   401 | RN不一致            | 号码拥有网络ID与本局RN不一致                      | 修改“NP数据列表”参数中的“号码拥有网络ID”部分，使其与LST INTROFF命令查询出的本局RN一致。 网络ID中运营商代码部分与RN有一定的对应关系：“001”对应“1241”。“002”对应“1242”。“003”对应“1243”。“005”对应“1245”。                               |
|   621 | 记录未定义            | 它网携转用户数据在数据库中不存在                      | 登录PGW Web LMT，在“UDM业务管理”MML导航树下执行ADD NPDONORSUB命令，将“NP数据列表”参数中的“NP号码”增加为本网携出用户。                                                                                       |
|   621 | MSISDN所在网络的RN不存在 | 用户所在网络的RN不存在                          | 登录PGW Web LMT，在“UDM业务管理”MML导航树下执行ADD NPPREFIXRN命令，将“NP数据列表”参数中的“NP号码”增加为非携转用户。                                                                                        |
