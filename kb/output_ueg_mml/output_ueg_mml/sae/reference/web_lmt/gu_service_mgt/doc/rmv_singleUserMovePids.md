# 删除4升5迁移指令PID规则(RMV SINGLEUSERMOVEPIDS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除一条5G SA或者NSA的迁移指令PID规则。

## 注意事项

删除4升5迁移指令PID规则后，将导致“用户源PID”对应CloudDB或ATCA版本的HSS无法将5G SA或者NSA数据迁移到UDM，请谨慎操作。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                     |
|:-------|:-------|:---------------------------------------------------------------------------------------------------------|
| SRCPID | 用户源PID | 可选必选说明：必选参数 参数含义：用于标识一条4升5迁移指令PID规则记录的关键字段，用于指定需要按照哪个用户源PID删除对应4升5迁移指令PID规则记录。 取值范围：1～250 默认值：无。 配置原则：无。 |

## 使用实例

删除“用户源PID”为“21”的4升5迁移指令PID规则。

```
RMV SINGLEUSERMOVEPIDS: SRCPID=21;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                   | 处理建议                                                            |
|:--------|:--------|:---------------------------------------|:----------------------------------------------------------------|
| ERR3007 | 记录不存在   | “用户源PID”和“用户新PID”配置的4升5迁移指令PID规则记录不存在。 | 执行LST SINGLEUSERMOVEPIDS查询用户源PID已配置的目标PID，再执行该命令删除4升5迁移指令PID规则。 |
