# 查询授权号段信息(LST AUTHRANGE)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于按远端号码号段查询远端用户的潜在初始用户或管理者的信息：

- 若需要查询某个虚拟HLR中所有授权号段信息，请只输入“HLR序列号”参数。
- 若需要查询某个虚拟HLR中某条初始用户的详细信息，请输入“HLR序列号”和“远端号码开始”或其他参数或这些参数的组合。

## 注意事项

无。

## 参数说明

| 参数标识       | 参数名称   | 参数说明                                             |
|:-----------|:-------|:-------------------------------------------------|
| HLRSN      | HLR序列号 | 用于指示系统需要按照哪个HLR序列号来查询授权号段数据，该参数必须选择。             |
| BEGINRMNUM | 远端号码开始 | 用于指示系统需要按照哪个远端号码开始值来查询授权号段数据；若不输入，则表示所有的远端号码开始值。 |
| TYPE       | 授权类型   | 用于指示系统需要按照哪个授权类型来查询授权号段数据；若不输入，则表示所有的授权类型。       |

## 使用实例

1. 查询“HLRSN”为“1”的所有初始用户信息：

   ```
   LST AUTHRANGE: HLRSN=1;
   ```

   ```
   %%LST AUTHRANGE: HLRSN=1;%%
   RETCODE = 0 SUCCESS0001:操作成功

           "HLRSN"     "BEGINRMNUM"      "ENDRMNUM"        "TYPE"                    "BEGININITNUM"    "ENDINITNUM"
           1           12                25                Initiating subscriber     8613900001234     8613900001256
           1           43                46                Supervisor                8613900001240     8613900001245
           1           12765             12780             Initiating subscriber     8613900001234     8613900001256

   Total count = 3

   There is together 1 report

   ---    END
   ```
2. 查询“HLRSN”为“1”，“远端号码开始”为“12765”，“授权类型”为“Initiating subscriber”的所有初始用户信息：

   ```
   LST AUTHRANGE: HLRSN=1, BEGINRMNUM="12765", TYPE=Initiating subscriber;
   ```

   ```
   %%LST AUTHRANGE: HLRSN=1, BEGINRMNUM="12765", TYPE=Initiating subscriber;%%
   RETCODE = 0 SUCCESS0001:操作成功

           "HLRSN"     "BEGINRMNUM"      "ENDRMNUM"        "TYPE"                    "BEGININITNUM"    "ENDINITNUM"
           1           12765             12780             Initiating subscriber     8613900001234     8613900001256

   Total count = 1

   There is together 1 report

   ---    END
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数请参见MOD AUTHRANGE命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释     | 原因分析                                             | 处理建议                                                             |
|:--------|:----------|:-------------------------------------------------|:-----------------------------------------------------------------|
| ERR1004 | 无效的参数值    | 参数“远端号码开始”的取值不是1～15位的十进制数字组成的字符串。                | 根据实际情况，重新输入参数“远端号码开始”的取值，确保其取值符合要求。                              |
| ERR3097 | HLR序列号未定义 | 参数“HLR序列号”输入错误，实际输入的参数“HLR序列号”未定义。               | 根据实际情况，重新输入参数“HLR序列号”的取值，确保其取值已被定义。已定义的“HLR序列号”可通过LST HLRSN命令查询。 |
| ERR3007 | 记录不存在     | 参数“远端号码开始”或“授权类型”输入错误，实际输入的参数“远端号码开始”或“授权类型”不存在。 | 根据实际情况，重新输入参数“远端号码开始”和“授权类型”的取值，确保其正确性。                          |
