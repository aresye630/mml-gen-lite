# 删除非携转全局数据(RMV NPPREFIXRN)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来删除非携转用户数据。

## 注意事项

无。

## 参数说明

| 参数标识        | 参数名称     | 参数说明                                         |
|:------------|:---------|:---------------------------------------------|
| ISDN_PREFIX | MSISDN前缀 | MSISDN前缀号码，E.164格式的编码，为1～15位的十进制数字。 说明：必选参数。 |

## 使用实例

将MSISDN前缀为86131075003003的非携转用户数据删除。命令如下：

```
RMV NPPREFIXRN: ISDN_PREFIX="86131075003003";
```
