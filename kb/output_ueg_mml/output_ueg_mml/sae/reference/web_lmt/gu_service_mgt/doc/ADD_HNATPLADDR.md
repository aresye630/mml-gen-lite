# 增加游牧地址(ADD HNATPLADDR)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该命令用于在HSS的业务数据库中向已经存在的游牧模板中增加一条游牧地址。

操作员可以使用**ADD HNATPLADDR**增加游牧地址到指定的游牧模板，以对用户的游牧范围进行控制：

- 当IMS移动用户进入游牧地址允许的区域时，将使用用户携带的接入位置信息与签约的游牧地址信息进行匹配，此时匹配成功，游牧地址信息中的NASS游牧地址类型是允许游牧，IMS系统将允许用户注册。
- 当IMS移动用户进入游牧地址限制的区域时，将使用用户携带的接入位置信息与签约的游牧地址信息进行匹配，此时匹配成功，游牧地址信息中的NASS游牧地址类型是限制游牧，IMS系统将限制用户注册。
- 当IMS移动用户进入的区域在游牧地址信息中不存在时，将使用用户携带的接入位置信息与签约的游牧地址信息进行匹配，此时匹配失败，根据游牧模板中的缺省游牧限制策略决定是否允许用户游牧，PERMISSION表示IMS系统将允许用户注册，RESTRICTION表示IMS系统将限制用户注册。

## 注意事项

- “NASS游牧模板ID”参数和“NASS游牧模板名称”参数必须存在且仅能存在一个。
- 如果操作员在指定游牧模板中增加了一条游牧地址，则所有引用该模板的用户都将增加这条游牧地址，请操作员在执行该操作之前仔细确认任务的可行性。
- 系统允许的游牧地址数量最大为40000个，请操作员在执行该命令前妥善规划，仔细确认任务的可行性。
- 对于有具体游牧地址的用户，如果要放开用户的游牧权限，使用**RMV HNATPLADDR**命令删除地址以放开用户的游牧范围。

## 参数说明

| 参数标识    | 参数名称       | 参数说明                                                                                                                                                                                         |
|:--------|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NATPLID | NASS游牧模板ID | 用于标识一个游牧模板索引，系统可以通过该索引找到需要增加游牧地址的游牧模板。该参数必须先由ADD HNATPL命令定义，然后才能在此处索引。操作员可以使用LST HTPLINF命令查询获得。 取值范围：0~67108863 默认值：无。 说明：可选参数。该参数为255表示无效值。                                                 |
| TPLNAME | NASS游牧模板名称 | 用于标识一个游牧模板的名称，系统可以通过模板名称找到需要增加游牧地址的游牧模板。该参数必须先由ADD HNATPL命令定义，然后才能在此处索引。操作员可以使用LST HTPLINF命令查询获得。 取值范围：长度不超过64的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 默认值：无。 说明：可选参数。                                  |
| nan     | NASS游牧地址   | 用于指定在游牧地址模板中增加的游牧地址，操作员可以使用LST HNATPLADDR命令查询指定游牧模板内的所有游牧地址信息。 取值范围：长度不超过127的字符串 默认值：无。 说明：可选参数。输入参数“NASS游牧模板ID”对应游牧模板的“匹配类型”为“FRONT”、“BACK”或“CONTAIN”时，该参数有效。操作员可以使用LST HNATPL命令查询对应游牧模板信息。 |
| BEGINIP | IP地址段起始地址  | 用于定义在游牧模板中增加的IP地址段的起始地址。 取值范围：IPV4地址 默认值：无。 说明：可选参数。输入参数“NASS游牧模板ID”对应游牧模板的“匹配类型”为“IPSEGMENT”时，该参数有效。操作员可以使用LST HNATPL命令查询对应游牧模板信息。                                                          |
| ENDIP   | IP地址段结束地址  | 用于定义在游牧模板中增加的IP地址段的结束地址。 取值范围：IPV4地址 默认值：无。 说明：可选参数。输入参数“NASS游牧模板ID”对应游牧模板的“匹配类型”为“IPSEGMENT”时，该参数有效。操作员可以使用LST HNATPL命令查询对应游牧模板信息。该参数IP必须大于或等于“IP地址段起始地址”的IP。                               |
| NATYPE  | NASS游牧地址类型 | 用于指定新增游牧地址的类型。 取值范围： PERMISSION(Premission)：表示IMS系统将允许用户注册。RESTRICTION(Restriction)：表示IMS系统将限制用户注册。 默认值：无。 说明：必选参数。                                                                          |

## 使用实例

1. 增加游牧地址,“NASS游牧模板ID”为“10”，“NASS游牧地址”为“china.huawei.com”，“NASS游牧地址类型”为“PERMISSION(Permission)”：

   ```
   ADD HNATPLADDR: NATPLID=10, NA="china.huawei.com", NATYPE=PERMISSION;
   ```
2. 增加游牧地址,“NASS游牧模板名称”为“07550011”，“IP地址段起始地址”为“10.2.2.10”，“IP地址段结束地址”为“10.2.2.50”，“NASS游牧地址类型”为“PERMISSION(Permission)”：

   ```
   ADD HNATPLADDR: TPLNAME="07550011", BEGINIP="10.2.2.10", ENDIP="10.2.2.50", NATYPE=PERMISSION;
   ```
