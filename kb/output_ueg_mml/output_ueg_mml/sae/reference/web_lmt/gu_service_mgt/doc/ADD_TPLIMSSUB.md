# 利用模板增加用户IMS数据(ADD TPLIMSSUB)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于GSM/UMTS/EPS/IMS融合网络，IMS-HSS与SAE-HSS/HLR融合部署，在HSS的业务数据库中利用模板为GSM/UMTS用户、EPS用户或GSM/UMTS/EPS融合网络用户签约IMS业务数据。

GSM/UMTS用户、EPS用户或GSM/UMTS/EPS融合网络用户申请签约IMS业务数据的操作流程如图1所示。

**图1** GSM/UMTS用户、EPS用户或GSM/UMTS/EPS融合网络用户申请签约IMS业务数据

## 注意事项

- “IMSI”和“MSISDN”是可选参数，必须有且只能有一个参数出现。
- 在混合组网环境执行该命令，若IMPI已存在，系统提示IMPI已与其它用户关联。
- 当通过**SET HSYSTEMPARA**命令设置“USINGHLRSNFORIMS（是否启用IMS-HSS的分权分域功能）”软参为“TRUE(TRUE)”时，执行该命令时需要注意：
  - 引用用户签约的“HLR序列号”下的IMS用户模板。
  - 本命令的“HLR序列号”与签约IMS用户模板对应的“HLR序列号”要一致。
- 执行本命令为用户签约IMS业务数据，用户“漫游权限检查标志”默认取值为“TRUE(TRUE)”，即默认对用户的IMS漫游权限进行检查，可以通过执行**SET HVNCFLAG**命令修改。

## 参数说明

| 参数标识        | 参数名称      | 参数说明                                                                                                                                                                                                                                                                                                                      |
|:------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN       | HLR序列号    | 用于标识一个IMS签约用户属于哪个虚拟HSS。通过ADD HLRSN定义，然后才能在此处索引。 取值范围：0～255 默认值：0                                                                                                                                                                                                                                                          |
| IMSI        | IMSI      | 用于标识用户的IMSI号码。 取值范围：6～15位十进制数字组成的字符串。 默认值：无                                                                                                                                                                                                                                                                               |
| ISDN        | MSISDN    | 用于标识用户的MSISDN号码。 取值范围：1～15位十进制数字组成的字符串。 默认值：无                                                                                                                                                                                                                                                                             |
| IMPI        | IMPI      | 用于指定需要增加的IMPI的值。 取值范围：长度不超过127的字符串。 默认值：无 说明：输入的IMPI值符合NAI格式，字母区分大小写。输入的IMPI未增加过鉴权信息，为新增的IMPI记录。                                                                                                                                                                                                                          |
| IMPULIST    | IMPU列表    | 用于指定要添加的IMPU的值。该参数的配置原则是：由1到10个IMPU以“&”连接组成（例如：\"sip:impuinfo1@huawei.com\"&\"sip:impuinfo2@huawei.com\"，在字符"前需要添加转义字符\）。输入的IMPU值符合SIP URI或TEL URI格式，字母区分大小写。 取值范围：1～1300位由数字、字母或“.”、“&”、“：”等特殊字符组成的字符串。 默认值：无 说明：输入的IMPU为非通配型。一个用户可以签约多个IMPU，系统将这些IMPU设置到同一个隐式注册集，“隐式注册集ID”默认为“1”，将所有的IMPU都设置到同一个别名组下，“IMPU别名组ID”默认为“1”。 |
| BARIMPULIST | 闭锁的IMPU列表 | 用于指定要闭锁的IMPU的值。该参数的配置原则是：由1到10个IMPU以“&”连接组成（例如：\"sip:impuinfo1@huawei.com\"&\"sip:impuinfo2@huawei.com\"，在字符"前需要添加转义字符\）。输入的IMPU值符合SIP URI或TEL URI格式，字母区分大小写。 取值范围：1～1300位由数字、字母或“.”、“&”、“：”等特殊字符组成的字符串。 默认值：无 说明：输入的IMPU为非通配型，包含在“IMPU列表”中。并且被闭锁的IMPU不能为默认IMPU。                                                          |
| VOLTETAG    | VoLTE用户标志 | 用于指定用户是否是VoLTE用户。 取值范围：TRUE(TRUE)：表示该用户是VoLTE用户。FALSE(FALSE)：表示该用户不是VoLTE用户。 默认值：无                                                                                                                                                                                                                                        |
| IMSTPLID    | IMS用户模板ID | 用于对新增IMS用户指定一个IMS用户模板，该模板需要通过命令ADD IMSTPL定义，才能在此处索引。 取值范围：０～1024 默认值：无 说明：如果没有设置“IMS用户模板ID”参数值，表示用户未签约特殊的业务数据，IMS用户模板信息全部使用系统默认值。可通过LST IMSTPL查询IMS用户模板信息。如果设置“IMS用户模板ID”参数值，每个用户对应所有IMPU的签约属性都一致，都采用同一个模板中的数据。                                                                                                           |

## 使用实例

为一个GSM/UMTS用户签约IMS业务数据，参数取值如表1所示。

| 参数        | 值                                                         |
|:----------|:----------------------------------------------------------|
| HLR序列号    | 1                                                         |
| IMSI      | 460001234567890                                           |
| IMPI      | impiinfo                                                  |
| IMPU列表    | \"sip:impuinf_2@huawei.com\"&\"sip:impuinf_3@huawei.com\" |
| VoLTE用户标志 | TRUE                                                      |
| IMS用户模板ID | 1                                                         |

```
ADD TPLIMSSUB: HLRSN=1, IMSI="460001234567890", IMPI="impiinfo", IMPULIST="\"sip:impuinfo_1@huawei.com\"&\"sip:impuinfo_2@huawei.com\"", VOLTETAG=TRUE, IMSTPLID=1;
```
