# 设置前转号码变换(SET FTNTRANS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于增加、修改或者删除前转号码变换表的记录，从而按照前转号码的更改准则进行相应的前转号码变换。

## 注意事项

- 前转号码的格式只能是国内格式。
- 同一个“HLR序列号”中增加的前转号码变换记录数不能超过1000条。

## 参数说明

| 参数标识    | 参数名称    | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                         |
|:--------|:--------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN   | HLR序列号  | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                                                                                                                                                                                                                 |
| SETTYPE | 操作类型    | 用于标识前转号码变换记录的操作类型。 取值范围：Add：增加一条记录。Modify：修改一条已有记录。Delete：删除一条已有记录。DeleteAll：删除所有记录。 默认值：无。 说明：如果参数“SETTYPE”取值为“Add”或“Modify”，则参数“OLDFTN”出现且必须输入，同时参数“NEWFTN”也会出现，它可以输入，也可以不输入。如果输入了“NEWFTN”，则用“NEWFTN”取代“OLDFTN”，否则前转号码前缀将从前转号码中去掉。如果参数“SETTYPE”取值为“Delete”，则参数“OLDFTN”出现且必须输入，参数“NEWFTN”不出现。此时表示删除前转号码前缀为“OLDFTN”的前转号码变换的记录信息。如果参数“SETTYPE”取值为“DeleteAll”，则参数“OLDFTN”和“NEWFTN”均不出现。此时表示删除所有在HLR中的前转号码变换信息。 |
| OLDFTN  | 旧前转号码前缀 | 仅当本命令中的“操作类型”参数为“Add”、“Modify”或“Delete”时该参数有效。用于标识变换前的前转号码前缀。 取值范围：1～28位的十进制数字。 默认值：无。                                                                                                                                                                                                                                                                                                                       |
| NEWFTN  | 新前转号码前缀 | 仅当本命令中的“操作类型”参数为“Add”或“Modify”时该参数有效。用于标识变换后的前转号码前缀。 取值范围：1～28位的十进制数字。 默认值：无。                                                                                                                                                                                                                                                                                                                                |

## 使用实例

某运营商计划对某PLMN内的前转号码进行变换和规整，操作如下：

1. 先执行**SET FTNTRANS**命令增加了一条记录。其中“HLR序列号”为“1”，“旧前转号码前缀”为“01”，“新前转号码前缀”为“1”：

   ```
   SET FTNTRANS: HLRSN=1, SETTYPE=Add, OLDFTN="01", NEWFTN="1";
   ```
2. 然后执行**SET FTNTRANS**命令修改了一条记录。其中“HLR序列号”为“1”，“旧前转号码前缀”为“01”，“新前转号码前缀”为“2”：

   ```
   SET FTNTRANS: HLRSN=1, SETTYPE=Modify, OLDFTN="01", NEWFTN="2";
   ```
3. 最后再执行**SET FTNTRANS**命令删除了一条记录。其中“HLR序列号”为“1”，“旧前转号码前缀”为“003”：

   ```
   SET FTNTRANS: HLRSN=1, SETTYPE=Delete, OLDFTN="003";
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见的错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                  | 处理建议                                                                                                                                                         |
|:--------|:--------|:--------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值  | 参数“OLDFTN”或“NEWFTN”的取值中含有0～9以外的字符。    | 重新输入“前转号码”，确保只含有0～9以内的字符。                                                                                                                                    |
| ERR3006 | 记录已存在   | 重复为同一个HLR序列号下的同一个旧前转号码前缀添加相同的新前转号码前缀。 | 该新前转号码前缀已添加，根据实际情况确认是否需要给其他的旧前转号码前缀添加新前转号码前缀。                                                                                                                |
| ERR3007 | 记录不存在   | HLR序列号未定义。                            | 根据实际情况选择：如果需要为某个HLR序列号添加新前转号码前缀，则执行ADD HLRSN命令先定义该HLR序列号，再为该HLR序列号添加前转号码前缀。如果需要为已定义的HLR序列号添加新前转号码前缀，则执行LST HLRSN命令先查询已定义的HLR序列号，再为已定义的HLR序列号添加前转号码前缀。        |
| ERR1111 | 超过最大限制  | 增加的前转号码变换记录数超过1000条。                  | 根据实际情况，如需增加前转号码变换记录，处理步骤如下：执行LST FTNTRANS命令，查询已存在前转号码变换记录。执行该命令，将参数“操作类型”设置为“DELETE”删除不必要的前转号码变换记录。执行该命令，将参数“操作类型”设置为“ADD”增加的前转号码变换记录，确保增加后前转号码变换记录数在规定范围之内。 |
