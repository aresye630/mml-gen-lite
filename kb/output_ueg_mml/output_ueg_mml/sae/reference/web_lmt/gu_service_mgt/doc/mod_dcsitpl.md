# 修改D-CSI模板(MOD DCSITPL)

- 命令功能

## 命令功能

**须知** 

本命令属于高危命令，执行不当会使签约此模板的用户数据被同步修改，因此执行该命令前，需要与华为技术支持确认后才可以实施。

该命令用于对一条D-CSI（Dialed Services CAMEL Subscription Information）模板数据记录的某些参数进行修改或调整，同时还用于为一条D-CSI模板数据记录增加多条触发准则。在该命令中，系统通过以下关键参数的组合来唯一标识一条D-CSI模板数据记录：

- “HLR序列号”
- “模板ID”

## 注意事项

- 用户进行位置更新或触发其他涉及D-CSI模板的流程时，系统会根据用户签约的D-CSI模板ID下发模板中的数据，修改模板数据会使签约此模板的用户数据被同步修改，会影响在网用户，因此现网执行修改模板操作时需要慎重。
- “是否提供DP值”和“被叫号码准则”两个参数必须同时输入。
- 当“是否提供DP值”参数为“TRUE”、但指定的DP值在模板中不存在时，“SCP地址”、“业务键”和“缺省呼叫处理”参数是必选参数。
- 系统中同一个D-CSI模板增加的被叫号码准则记录数不能超过20条，且所有D-CSI模板增加的被叫号码准则总记录数不能超过5000条。

## 参数说明

| 参数标识      | 参数名称                   | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
|:----------|:-----------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN     | HLR序列号                 | 标识一条D-CSI模板数据记录的关键字段之一（其取值不能被修改），用于标识需要对哪一条D-CSI模板数据记录的参数进行修改或调整，操作员可以使用LST HLRSN命令查询获得。                                                                                                                                                                                                                                                                                                                                                                            |
| TPLID     | 模板ID                   | 标识一条D-CSI模板数据记录的关键字段之一（其取值不能被修改），用于标识需要对哪一条D-CSI模板数据记录的参数进行修改或调整，操作员可以使用LST DCSITPL命令查询获得。                                                                                                                                                                                                                                                                                                                                                                          |
| TPLNAME   | 模板名                    | 用于标识待修改模板在系统中的名称。 取值范围：1～60位字母或十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                                                                                                  |
| CAMEL     | CAMEL业务处理能力            | 用于标识gsmSCF（GSM Service Control Function）在处理该项具体CAMEL业务时所需要的CAMEL协议阶段的支持。CAMEL的发展经历了四个阶段，不同的阶段CAMEL特性的应用范围不同，可以按运营商的需要进行配置。该参数的配置应该与本命令中的“业务键”参数对应的具体CAMEL业务所要求支持的CAMEL支持能力一致。 取值范围：PHASE3：CAMEL特性应用于始发短消息业务（SMS MO）、GPRS会话和PDP上下文、HLR用户数据的控制和网络信令负荷。PHASE4：是PHASE3的增强，同时可应用于终结短消息业务（SMS MT）。 默认值：无。                                                                                                                                                                 |
| USHNDL    | VLR/GMSC不支持CAMEL时的处理方式 | 用于标识当VLR/GMSC不支持D-CSI所需要的CAMEL业务处理能力时的HLR替代下发的处理方式。 取值范围：CALLBAR：呼叫闭锁，与签约了ODB-BAOC（闭锁所有呼出业务）相同。RR：漫游限制。NONCAMEL：呼叫被当作非CAMEL呼叫继续处理。 默认值：无。                                                                                                                                                                                                                                                                                                                           |
| PROV      | 是否提供DP值                | 用于标识执行该命令是增加/修改还是删除DP数据。如果待修改模板中只设置了一个DP值，该参数不能设置为FALSE。 取值范围：TRUE：增加/修改如果指定的DP值在模板中不存在，则与该DP值对应的数据将被增加到模板中。 FALSE：删除如果指定的DP值已经存在，与指定的DP值相关的数据将被删除。如果指定的DP值在模板中不存在，系统将会提示错误。 默认值：无。                                                                                                                                                                                                                                                                                 |
| DIALLEDNO | 被叫号码准则                 | 仅当本命令中的“是否提供DP值”参数为“TRUE”或“FALSE”时该参数有效。用于标识D-CSI业务的触发准则，即被叫号码准则（DP3）。当用户拨打此号码为前缀的被叫号码，则会触发D-CSI智能业务。 取值范围：1～15位的十进制数字组成的字符串。 默认值：无。                                                                                                                                                                                                                                                                                                                                |
| GSMSCFADD | SCP地址                  | 仅当本命令中的“是否提供DP值”参数为“TRUE”时该参数有效。用于标识接入gsmSCF功能实体的地址。 取值范围：1～15位十进制数字组成的字符串。 采用E.164编码方式，编码格式为：CC+NDC+LSP，例如，一个典型的“SCP地址”为：“86-139-00777”。各关键字段的含义是： CC（Country Code）：国家码，即SCP所处国家在国际PSTN编号计划中的国家码，它由ITU-T在全球范围内统一分配，其最大长度为3位。例如，中国的国家码为86、英国的国家码为44等。NDC（National Destination Code）：国内目的码，即移动业务接入码，它是由本国电信主管部门在本国范围内统一分配的PLMN网络号，其最大长度为3位。例如，某运营商使用的PLMN网络号为134～139。LSP（Locally Significant Part）：本地有效部分，它是由某个运营商在本PLMN网络运营范围内统一分配的、用于具体代表某个SCP的号码，其最大长度为9位。 默认值：无。 |
| SK        | 业务键                    | 仅当本命令中的“是否提供DP值”参数为“TRUE”时该参数有效。用于标识用户在gsmSCF中签约的CAMEL业务。gsmSSF（GSM Service Switching Function）将业务键发给gsmSCF后，gsmSCF根据该业务键执行对应的业务逻辑。业务键是HLR与SCP的对接参数之一，用于在CAP/INAP消息中唯一标识一种智能业务，它是一种号码资源，需要由运营商向本国的电信主管部门申请获得。 取值范围：0～2147483647 默认值：无。                                                                                                                                                                                                                              |
| DEFCALL   | 缺省呼叫处理                 | 仅当本命令中的“是否提供DP值”参数为“TRUE”时该参数有效。用于标识当gsmSSF与gsmSCF之间的对话出现差错或者呼叫受限于gsmSSF里的CallGap（CallGap是为了保证SCP系统不过负荷运行，需要在话务量过高时对相应的智能呼叫实施呼叫间隙控制的功能）时，缺省呼叫处理指示出对呼叫应给予释放还是继续。 取值范围：ReleaseCall：gsmSCF指示gsmSSF释放呼叫。ContinueCall：gsmSCF指示gsmSSF继续呼叫。 默认值：无。                                                                                                                                                                                                                         |

## 使用实例

1. 修改“HLR序列号”为“1”的HLR上的D-CSI模板数据记录，增加号码触发条件，拨打5555555时触发D-CSI业务。其中，“模板ID”为“2”，“被叫号码准则”为“5555555”，“SCP地址”为“8613759”，“SCP地址”为“8613911111”，“业务键”为“1”，“缺省呼叫处理”为“呼叫释放”：

   ```
   MOD DCSITPL: HLRSN=1, TPLID=2, PROV=TRUE, DIALLEDNO="5555555", GSMSCFADD="8613759", SK=1, DEFCALL=ReleaseCall;
   ```
2. 修改“HLR序列号”为“1”的HLR上的D-CSI模板数据记录。其中，“HLR序列号”为“1”，“模板ID”为“2”，“CAMEL业务处理能力”为“PHASE4”，“VLR/GMSC不支持CAMEL时的处理方式”为“CALLBAR”：

   ```
   MOD DCSITPL: HLRSN=1, TPLID=2, CAMEL=PHASE4, USHNDL=CALLBAR;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                                       | 处理建议                                                                                                      |
|:--------|:--------|:---------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | “HLR序列号”和“模板ID”对应的D-CSI模板数据记录不存在。                                          | 使用LST DCSITPL命令查询后，重新确认要修改哪个“HLR序列号”和“模板ID”对应的D-CSI模板数据记录。                                                |
| ERR3047 | 超过最大限制  | 可能原因为如下之一：所有D-CSI模板增加的“被叫号码准则”总记录数超过5000条。 同一个“模板ID”增加的“被叫号码准则”数据记录数超过20条。 | 根据实际情况，如需增加被叫号码准则，处理步骤如下：执行LST DCSITPL命令，查询已存在的被叫号码准则。执行该命令删除不必要的被叫号码准则。执行该命令增加被叫号码准则，确保增加的被叫号码准则在规定范围之内。 |
| ERR1004 | 无效的参数值  | 界面输入的非“HLR序列号”和“模板ID”参数不在相应的参数取值范围内。                                       | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。                                                                          |
