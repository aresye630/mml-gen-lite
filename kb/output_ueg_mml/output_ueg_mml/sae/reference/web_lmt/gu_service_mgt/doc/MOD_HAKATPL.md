# 修改AKA鉴权信息模板(MOD HAKATPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中修改一个AKA鉴权信息模板，在该操作中系统通过AKA鉴权模板ID来唯一标识一条AKA鉴权信息模板记录。

## 注意事项

- 如果K4SNO参数取值为0，表明K未被加密，否则，K是经过K4加密的值。
- 如果OPSNO参数取值为0，OPC参数必须存在；如果OPSNO参数取值不为0，OPC参数不存在。
- 如果OPCK4SNO参数取值为0，表明OPC是明文，否则，OPC是经过OPCK4加密的值，OPC和OPCK4SNO必须同时存在或同时不存在。
- 待修改的可选参数必须至少设置其中一个，否则HSS返回失败。
- 如果在“命令输入区”输入命令后再输入各参数，“OPC值”出于安全原因，仅显示“\*”。
- 如果在“MML命令编辑区”直接输入带参数的命令，命令中的“OPC值”以明文显示。
- 当**SET MAPCONF**命令中的“是否启用随机密钥”参数为“TRUE”时，如果未执行**SET MAPSERV**命令设置“随机密钥默认ID”参数为系统已存在的随机密钥，则执行该命令时会返回错误：“已启用随机密钥功能，请先执行**SET RANDOMKEY**命令生成随机密钥”。

## 参数说明

| 参数标识     | 参数名称      | 参数说明                                                                                             |
|:---------|:----------|:-------------------------------------------------------------------------------------------------|
| TPLID    | AKA鉴权模板ID | 标识一个AKA鉴权信息模板记录的关键字段，用于指定需要对哪一个AKA鉴权信息模板记录的参数进行修改或调整，操作员可以使用LST HTPLINF操作查询获得。 取值范围：0～254 缺省值： 无 |
| TPLNAME  | AKA模板名称   | 该参数用于具体描述一个AKA鉴权信息模板，以便于识别。 取值范围： 长度不超过64的字符串，字符串由数字、字母、“.”、“-”或“_”组成。 缺省值： 无                    |
| K4SNO    | K4索引号     | 用于指定AKA鉴权使用的K4的值，该参数必须先由ADD HK4操作定义，然后才能在此处索引。 取值范围：0～128 缺省值： 无                                 |
| OPSNO    | OP索引号     | 用于指定AKA鉴权使用的OP的值，该参数必须先由ADD HOP操作定义，然后才能在此处索引。 取值范围：0～128 缺省值： 无                                 |
| AMFSNO   | AMF索引号    | 用于指定AKA鉴权使用的AMF的值，该参数必须先由ADD HAMF操作定义，然后才能在此处索引。 取值范围：1～128 缺省值： 无                               |
| OPC      | OPC值      | 用于定义鉴权数据OPC的值，要求输入16进制字符，字母不区分大小写。说明：当OPC取值全零时为无效值，禁止输入。 取值范围： 长度等于32的16进制字符串 缺省值： 无             |
| OPCK4SNO | OPC K4索引号 | 用于指定AKA鉴权中对OPC进行解密时使用的K4的值，该参数必须先由ADD HK4操作定义，然后才能在此处索引。 取值范围：0～128 缺省值： 无                       |
| COMMENT  | 模板注释说明    | 该参数用于具体描述一个AKA鉴权信息模板的注释信息，以便于理解和使用。 取值范围： 长度不超过512的字符串 缺省值： 无                                    |

## 使用实例

修改AKA鉴权信息模板。AKA鉴权模板ID：10，AKA模板名称：Modify an AKA Template。

```
MOD HAKATPL: TPLID=10, TPLNAME="Modify an AKA Template";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 错误码解释                                | 原因分析                                                          | 处理建议                                                                      |
|----------:|:-------------------------------------|:--------------------------------------------------------------|:--------------------------------------------------------------------------|
| 900003515 | 已启用随机密钥功能，请先执行SET RANDOMKEY命令生成随机密钥。 | 已启用随机密钥功能，但SET MAPSERV命令中的“随机密钥默认ID”参数为0。                     | 根据实际情况，执行SET RANDOMKEY命令生成随机密钥，并设置SET MAPSERV命令中的“随机密钥默认ID”参数为系统已存在的随机密钥。 |
| 900003523 | 密钥丢失                                 | 当SET MAPSERV命令中的“随机密钥默认ID”参数为非0，“随机密钥默认ID”参数对应的随机密钥材料不存在或不完整。 | 联系华为技术支持处理。                                                               |
