# 设置ETCSI转换模板(SET ETCSICONVERTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于设置ETCSI转换模板，用以实现在不修改用户签约的ETCSI数据的前提下灵活调整用户的ETCSI业务。

该命令支持ETCSI转换模板的增加，修改和删除。

## 注意事项

- HSS存在多组命令功能可以实现对ETCSI业务的控制，本命令和其他命令间的优先级由高到低排序如下：
  - **ADD SERRESTTPL**和**ADD RSITPL**配置的业务限制、业务下发控制。
  - 本命令配置的ETCSI转换功能。
  - **ADD VLRTYP**中“ETCSI限制模板ID”配置的基于VLR的ETCSI限制能力。同时配置了多项控制能力时，以优先级高的配置为准。
- 系统中增加的ETCSI转换模板记录数不能超过1000条。

## 参数说明

| 参数标识               | 参数名称        | 参数说明                                                                                                                                                                                                                                                                  |
|:-------------------|:------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN              | HLR序列号      | 用于标识本地HLR。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1～255 默认值：无。                                                                                                                                                                                                           |
| ETCSICONVER_TPLID  | ETCSI转换模板ID | 用于标识一个ETCSI转换模板数据记录。 取值范围：0～65534 默认值：无。                                                                                                                                                                                                                              |
| TPLNAME            | 模板名         | 用于标识当前ETCSI转换模板在系统中的名称。 取值范围：1～60位由字母、数字或特殊字符组成的字符串。 默认值：无。                                                                                                                                                                                                           |
| OPTYPE             | 操作类型        | 用于标识执行该命令所实现的操作类型。 取值范围：ADD：新增ETCSI转换模板MOD：修改已有ETCSI转换模板DEL_ALL：删除当前ETCSI转换模板 默认值：无。                                                                                                                                                                                  |
| MAP_VERSION        | MAP版本号      | 仅当本命令中的“操作类型”参数为“ADD”或“MOD”时该参数有效。用于标识当前数据记录在哪个版本的MAP协议下生效。当前仅实现MAP Phase3。 取值范围：MAPV3 默认值：无。                                                                                                                                                                         |
| ETCSI_RANGE        | ETCSI生效范围   | 仅当本命令中的“操作类型”参数为“ADD”或“MOD”时该参数有效。用于标识ETCSI业务生效的范围，即用户处于哪种网络时下发ETCSI信息。 取值范围：HPLMN：用户在本网范围内ETCSI生效。FPLMN：用户在FPLMN（Foreign PLMN）内漫游时ETCSI生效。INTERNATIONAL：用户漫游出本国时ETCSI生效。HPLMNC：用户在本国漫游时ETCSI生效。ALL_PLMN：用户在任何网络时ETCSI都生效。 默认值：无。 说明：执行该命令并且不输入该参数时，系统会设置初始值ALL_PLMN。 |
| DEP_SEVTYPE        | ETCSI依赖业务类型 | 仅当本命令中的“操作类型”参数为“ADD”或“MOD”时该参数有效。用于标识ETCSI业务生效是否依赖OCSI业务。 取值范围：OCSI：只有在用户同时签约了OCSI业务时，ETCSI业务才生效。NONE：ETCSI业务生效不依赖其他业务。 默认值：无。                                                                                                                                       |
| ETCSI_RESTRAIN_IND | 是否抑制ETCSI   | 仅当本命令中的“操作类型”参数为“ADD”或“MOD”时该参数有效。用于标识是否抑制ETCSI业务数据的下发。 取值范围：TRUE：抑制ETCSI业务数据的下发。FALSE：不抑制，ETCSI下发范围以“ETCSI生效范围”取值为准。 默认值：无。                                                                                                                                          |
| ETCSI_CONVER_TYPE  | ETCSI转换类型   | 仅当本命令中的“操作类型”参数为“ADD”或“MOD”时该参数有效。用于标识对ETCSI业务键采用哪种转换方式。 如果用户签约了ETCSI转换模板，ETCSI业务下发时会根据配置的转换方式对用户签约的ETCSI业务键进行转换后再下发。 取值范围：EQUAL：将用户签约的ETCSI业务键转换为“ETCSI业务键转换值”。PLUS：将用户签约的ETCSI业务键在当前取值基础上增加“ETCSI业务键转换值”。SUBTRACT：将用户签约的ETCSI业务键在当前取值基础上减少“ETCSI业务键转换值”。 默认值：无。     |
| ETCSI_CONVER_VALUE | ETCSI业务键转换值 | 仅当本命令中的"ETCSI转换类型"参数不为空时该参数有效。和参数“ETCSI转换类型”配合决定如何对用户签约的ETCSI业务键进行转换。 取值范围：1～999 默认值：0                                                                                                                                                                                |

## 使用实例

1. 增加一个ETCSI转换模板，“HLR序列号”为“1”，“ETCSI转换模板ID”为“1”，“操作类型”为“ADD”，“MAP版本号”为“MAPV3”，“ETCSI转换类型”为“EQUAL”，“ETCSI业务键转换值”为“56”：

   ```
   SET ETCSICONVERTPL: HLRSN=1, ETCSICONVER_TPLID=1, OPTYPE=ADD, MAP_VERSION=MAPV3, ETCSI_CONVER_TYPE=EQUAL, ETCSI_CONVER_VALUE=56;
   ```
2. 修改一个ETCSI转换模板，“HLR序列号”为“1”，“ETCSI转换模板ID”为“3”，“操作类型”为“MOD”，“MAP版本号”为“MAPV3”，“ETCSI转换类型”为“EQUAL”，“ETCSI业务键转换值”为“56”：

   ```
   SET ETCSICONVERTPL: HLRSN=1, ETCSICONVER_TPLID=3, OPTYPE=MOD, MAP_VERSION=MAPV3, ETCSI_CONVER_TYPE=EQUAL, ETCSI_CONVER_VALUE=56;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见本命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                                       | 处理建议                                                                                                                                                                        |
|:--------|:--------|:-----------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ERR1010 | 参数冲突    | “是否抑制ETCSI”参数为“TRUE”时，同时输入了“ETCSI转换类型”和“ETCSI业务键转换值”，引起冲突。 | 重新输入参数值，确保“是否抑制ETCSI”参数为“TRUE”时，不输入“ETCSI转换类型”和“ETCSI业务键转换值”。                                                                                                               |
| ERR1004 | 无效的参数值  | 输入的某个参数不在取值范围内。                                            | 重新输入参数值，确保取值和参数说明中的取值范围相符。                                                                                                                                                  |
| ERR3006 | 记录已存在   | 当“操作类型”参数为“ADD”时，输入的“ETCSI转换模板ID”信息已添加过。                   | 使用LST ETCSICONVERTPL命令查询后，根据查询结果重新添加“ETCSI转换模板ID”信息，确保同一个虚拟HLR中添加的“ETCSI转换模板ID”信息不重复。                                                                                       |
| ERR3007 | 记录未定义   | 当“操作类型”参数为“MOD”或“DEL_ALL”时，输入的“ETCSI转换模板ID”对应的数据记录不存在。     | 先使用LST ETCSICONVERTPL命令查询已添加过的模板信息，根据查询结果再次执行此命令。                                                                                                                           |
| ERR3047 | 超过最大限制  | 增加的ETCSI转换模板记录数超过1000条。                                    | 根据实际情况，如需增加ETCSI转换模板，处理步骤如下：执行LST ETCSICONVERTPL命令，查询已存在的ETCSI转换模板记录。执行该命令，将参数“操作类型”设置为“DELALL”删除不必要的ETCSI转换模板记录。执行该命令，将“操作类型”设置为“ADD”增加ETCSI转换模板，确保增加的ETCSI转换模板记录数在规定范围之内。 |
