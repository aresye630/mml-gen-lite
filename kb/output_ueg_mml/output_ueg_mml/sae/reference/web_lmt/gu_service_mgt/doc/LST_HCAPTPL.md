# 查询能力集信息模板(LST HCAPTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在HSS的业务数据库中查询能力集模板数据。该操作输入能力集模板ID来查询单条记录，不能查询多条记录。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                                       |
|:-------|:--------|:-----------------------------------------------------------|
| HLRSN  | HLR序列号  | 用于指示系统需要按照哪个HLR序列号来查询能力集数据。若不输入，则表示查询“HLR序列号”为“0”的所有能力集数据。 |
| TPLID  | 能力集模板ID | 用于指示系统需要按照哪个模板ID来查询能力集数据，操作员可以使用LST HTPLINF命令查询获得。         |

## 使用实例

查询能力集信息模板。能力集模板ID：10。

```
LST HCAPTPL: TPLID=10;
```

## 输出结果说明

| 参数标识      | 参数说明             |
|:----------|:-----------------|
| TPLNAME   | 显示能力集模板名称。       |
| MCAP      | 显示能力集模板的必选能力集。   |
| OCAP      | 显示能力集模板的可选能力集。   |
| SCSCFLIST | 显示能力集模板的SCSCF列表。 |
| COMMENT   | 显示能力集模板的模板注释说明。  |
