# 删除CAMEL限制业务键模板(RMV CAMELRESSKTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于从UDM中删除一条CAMEL限制业务键模板数据记录。

## 注意事项

当执行该命令删除用户已签约的CAMEL限制业务键模板时，系统会提示“ERR3005:模板已经被使用”的错误信息，该模板不能被删除。如果要删除该CAMEL限制业务键模板，必须先执行**MOD SERRESTTPL**命令给用户去签约相关的CAMEL限制业务键模板。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                  |
|:-------|:-------|:--------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 标识CAMEL限制业务键模板数据记录的关键字段之一，用于指定需要删除哪个HLR上的CAMEL限制业务键模板的数据记录，操作员可以使用LST HLRSN命令查询获得。    |
| TPLID  | 模板ID   | 标识CAMEL限制业务键模板数据记录的关键字段之一，用于指定需要删除哪个CAMEL限制业务键模板的数据记录，操作员可以使用LST CAMELRESSKTPL命令查询获得。 |

## 使用实例

删除“HLR序列号”为“1”、“模板ID”为“1”的CAMEL限制业务键模板数据记录。命令如下：

```
RMV CAMELRESSKTPL: HLRSN=1, TPLID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                     | 处理建议                                                                                          |
|:--------|:--------|:-----------------------------------------|:----------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | “HLR序列号”和“模板ID”参数对应的CAMEL限制业务键模板数据记录不存在。 | 根据实际情况，重新输入已定义的“HLR序列号”和“模板ID”参数，确保其对应的CAMEL限制业务键模板数据记录存在。已存在的模板数据记录可通过LST CAMELRESSKTPL命令查询。 |
| ERR3005 | 模板已经被使用 | 用户已签约该模板。                                | 根据实际情况，确定是否要删除该模板。如果确实需要删除，先通过MOD SERRESTTPL命令给用户去签约该模板，然后才能执行RMV CAMELRESSKTPL命令删除。          |
