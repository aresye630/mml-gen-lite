# 设置用户显示名称(SET HCNAP)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于在UDM的业务数据库中为指定IMPU或者PUSI签约、去签约Display name业务。

Display name业务（显示主叫号码名称）是指在会话时显示IMPU关联的显示名称。

- 注册和鉴权过程中会对用户身份进行验证，发起方的一个或多个IMPU存储在P-CSCF中，此时，UDM会下发每个IMPU关联的显示名称给P-CSCF。用户发起会话时，用户的INVITE请求包含在注册时收到的IMPU，P-CSCF将经过身份验证的IMPU及关联显示名称转发给S-CSCF。
- S-CSCF1将INVITE请求转发给S-CSCF2，其中包含经过身份验证的IMPU和主叫方的显示名称，S-CSCF2存储IMPU及显示名称，S-CSCF2将INVITE请求转发给P-CSCF2，P-CSCF2将INVITE请求转发给用户，用户终端显示IMPU和显示名称信息。

## 注意事项

- “用户显示名称”参数取值为空表示为指定的IMPU或者PUSI去签约Display name名称。
- 参数“IMPU”和参数“PUSI”必须存在且只能存在一个。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                        |
|:-------|:-------|:------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMPU   | IMPU   | 可选必选说明：可选参数 参数含义：用于指定一个需要设置Display name的IMPU，要求输入的IMPU值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无 配置原则：无                                          |
| PUSI   | PUSI   | 可选必选说明：可选参数 参数含义：用于指定一个需要设置Display name的PUSI，要求输入的PUSI值符合SIP URI或TEL URI格式。字母区分大小写。 取值范围：长度不超过127的字符串 默认值：无 配置原则：无                                          |
| CNAP   | 用户显示名称 | 可选必选说明：可选参数 参数含义：用于为指定IMPU或PUSI签约的Display name名称。 取值范围：长度不超过127的字符串 默认值：无 配置原则： 如果输入中包含“'”、“\”、“;”、“,”、“"”和“=”这几个特殊字符，则在这些特殊字符前添加转义字符“\”。例如参数输入“\;”，输出为“;”。 |

## 使用实例

为已开户用户签约用户显示名称，“IMPU”为“sip:impuinfo@huawei.com”，“用户显示名称”为“1234567890”，执行命令如下：

```
SET HCNAP: IMPU="sip:impuinfo@huawei.com", CNAP="1234567890";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

|       错误码 | 消息解释   | 原因分析                   | 处理建议                                        |
|----------:|:-------|:-----------------------|:--------------------------------------------|
| 900001007 | 无效的参数值 | 输入的参数取值不在其取值范围内。       | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。            |
| 900001008 | 参数不足   | 参数“IMPU”或“PUSI”没有输入。   | 根据实际情况，重新输入参数，确保“IMPU”或“PUSI”必须存在。          |
| 900001009 | 参数冲突   | “IMPU”和“PUSI”两个参数同时输入。 | 根据实际情况，重新输入参数，参数“IMPU”和参数“PUSI”必须存在且只能存在一个。 |
