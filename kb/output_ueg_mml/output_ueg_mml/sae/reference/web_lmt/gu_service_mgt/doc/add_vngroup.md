# 创建5G虚拟网络组 (ADD VNGROUP)

## 命令功能

该命令用于增加5G虚拟网络组，同时会自动生成5G虚拟网络组对应的共享数据模板数据。

通过执行**ADD GROUPID**命令为用户签约5G虚拟网络组数据，只需签约5G虚拟网络组对应的“内部组ID”或“外部组ID”。

## 注意事项

- 创建5G虚拟网络组时，对于一个“切片标识”和“数据网名称”有如下建议：
  - “精简标识”参数取值唯一，只能是“TRUE”或者“FALSE”。
  - 定义一个“精简标识”参数取值为“FALSE”的VN组。
  - 定义多个“精简标识”参数取值为“TRUE”的VN组。
- 混合组网场景下，该命令仅支持在路由分区执行，非路由分区下执行该命令上报错误码“ERR3111:系统不支持该特性”。

## 参数说明

| 参数标识           | 参数名称          | 参数说明                                                                                                                                                                                                                                                                                                                                                                                        |
|:---------------|:--------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN          | HLR序列号        | 可选必选说明：必选参数 参数含义：用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。 取值范围：1～255 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                     |
| INGROUPID      | 内部组ID         | 可选必选说明：必选参数 参数含义：用于标识移动网络内部设备之间通信时互相传递的组ID。 取值范围：10～38个十进制数字、十六进制数字或“-”组成的字符串。 默认值：无。 配置原则：格式为：1-46001-4F124689，由“-”字符分割的三部分组成。第一部分表示Group service ID，格式为十进制数字组成的字符串，取值范围为1～4294967295。超过1000的取值由归属运营商自行规划，1000以内的取值含义由3GPP协议定义。 第二部分表示归属PLMNID，格式为5～6位的十进制数字组成的字符串，前三个数字表示MCC，最后剩余的2个或3个数字表示MNC。第三部分为Local-Group-ID，格式为长度不超过20的十六进制数字组成的字符串。长度必须是偶数。取值由运营商规划，避免在多个UDM之间重复。 该参数输入的字母不区分大小写。 |
| EXTGROUPID     | 外部组ID         | 可选必选说明：必选参数 参数含义：用于标识移动网络对外能力开放接口中提供的组ID。 取值范围：3～128个字母、十进制数字、“@”、“.”、“-”或“_”组成的字符串。 默认值：无。 配置原则：格式同电子邮件地址格式<name>@<domain>该参数输入的字母不区分大小写。                                                                                                                                                                                                                                                  |
| SHAREDID       | 共享数据ID        | 可选必选说明：必选参数 参数含义：用于标识为内部组创建的共享数据的ID。 取值范围：长度不超过64位的字符串。 默认值：无。 配置原则：格式为：46001-icbc0001第一部分表示归属PLMNID，格式为5～6位的十进制数字组成的字符串，前三个数字表示MCC，最后剩余的2个或3个数字表示MNC。第二部分为自定义字符串，取值由运营商规划，避免在多个UDM之间重复。 该参数输入的字母不区分大小写。                                                                                                                                                                                    |
| GROUPNAME      | 组名称           | 可选必选说明：可选参数 参数含义：用于标识5G虚拟网络组名称。 取值范围：长度不超过32位的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                           |
| SNSSAI         | 切片标识          | 可选必选说明：必选参数 参数含义：用于标识5G系统中的网络切片，由SST（Slice/Service Type）与SD（Slice Differentiator）组成。 取值范围：1～10位字符串。 默认值：无。 配置原则： SST为取值范围是0～255的数字。SD是固定长度为3字节的十六进制字符串。 例如：当SST为1，SD为D143A5，则输入1-D143A5。当SST为1，无SD，则输入1。                                                                                                                                                                                    |
| DNN            | 数据网名称         | 可选必选说明：必选参数 参数含义：用于标识数据网名称。 取值范围：1～64位的字符串。 默认值：无。 配置原则：无。                                                                                                                                                                                                                                                                                                                                  |
| PDUTYPES       | 允许的PDU类型      | 可选必选说明：必选参数 参数含义：用于标识允许的PDU类型。 取值范围： 全部选中：选中除“全部清空”外的所有取值。全部清空：清空所有取值。IPV4V6：设置允许的会话类型为IPv4v6双栈类型，即同时使用IPv6/IPv4两个可以并行工作的协议栈。 IPV4：设置允许的会话类型为IPv4单栈类型。 IPV6：设置允许的会话类型为IPv6单栈类型。 UNSTR：点对点隧道技术可以用于向数据网络中的目的地传递非结构化PDU会话类型数据。 ETHER：SMF和UPF可以支持与PDU会话承载以太网帧相关的功能。 默认值：无。 配置原则：可同时设置多个PDU类型，并用“&”连接，例如“IPV4V6&IPV4”，也可以在复选框中进行复选。                                                              |
| APPDESCRIPTORS | 应用描述信息        | 可选必选说明：可选参数 参数含义：用于标识应用描述信息。 取值范围：长度不超过1024位的字符串。 默认值：无。 配置原则：该参数为JSON格式，必须包括osId或appId。osId：表示操作系统标识，不包括操作系统版本号。appId：表示应用标识，不包括应用的版本号。                                                                                                                                                                                                                                                    |
| SECONDARYAUTH  | 是否需要二次认证      | 可选必选说明：可选参数 参数含义：用于标识SMF在用户PDU会话建立时是否需要二次认证授权，如果需要则发起到DN-AAA的二次认证授权流程。 取值范围： TRUE：需要二次认证授权FALSE：不需要二次认证授权 默认值：无。 配置原则：执行该命令并且不输入该参数时，系统会设置初始值FALSE。                                                                                                                                                                                                                                         |
| AAAIPV4ADDR    | DN-AAA的IPv4地址 | 可选必选说明：条件可选参数 参数含义：用于标识二次认证授权的DN-AAA服务器IPv4地址。 取值范围：字符串格式表示的合法IPv4地址。 默认值：无。 配置原则：仅当本命令中的参数“是否需要二次认证”取值为“TRUE”时，该参数有效。当本命令中的参数“是否需要二次认证”取值为“TRUE”时，该参数与“DN-AAA的IPv6地址”参数至少输入其中一个。不支持取值为0.0.0.0或255.255.255.255的IPv4地址。                                                                                                                                                                      |
| AAAIPV6ADDR    | DN-AAA的IPv6地址 | 可选必选说明：条件可选参数 参数含义：用于标识二次认证授权的DN-AAA服务器IPv6地址。 取值范围：字符串格式表示的合法IPv6地址或者IPv6前缀。 IPv6地址示例如下： FE80:910A:2222:5498:8475:1111:3900:2020 IPv6地址前缀示例如下： 2001:0DB8:0:CD30::/60 IPv6地址前缀中前缀长度有效值范围：1～128。 默认值：无。 配置原则：仅当本命令中的参数“是否需要二次认证”取值为“TRUE”时，该参数有效。当本命令中的参数“是否需要二次认证”取值为“TRUE”时，该参数与“DN-AAA的IPv4地址”参数至少输入其中一个。不支持全0或全F的IPv6地址。                                                                 |
| SIMPLFIN       | 精简标识          | 可选必选说明：可选参数 参数含义：用于标识5G LAN精简标识，该精简标识用于告知SMF同一个切片标识及同一个数据网名称下用户是否能签约多个5G LAN群组。 取值范围： TRUE：能签约多个5G LAN群组。 FALSE：只能签约一个5G LAN群组。 默认值：FALSE 配置原则：执行该命令并且不输入该参数时，系统会设置初始值FALSE。                                                                                                                                                                                                                |

## 使用实例

配置5G LAN功能时，执行该命令增加一个5G虚拟网络组，“HLR序列号”为“1”，“内部组ID”为“1-46001-2D”，“外部组ID”为“group1@huawei.com”，“共享数据ID”为“46001-shared1”，“组名称”为“Huawei”，“切片标识”为“1-123456”，“数据网名称”为“dnn”，“允许的PDU类型”为“ETHER”，“应用描述信息”为“[{\"osId\":\"4947a69a-f61b-4bc1-b9da-47c9c5d14b64\"}\,{\"osId\":\"4947a69a-f61b-4bc1-b9da-47c9c5d14b64\"}]”，“是否需要二次认证”为“TRUE”，“DN-AAA的IPv4地址”为“10.20.30.100”，“DN-AAA的IPv6地址”为“2001:0db8::1234”，“精简标识”为“FALSE”。

```
ADD VNGROUP: HLRSN=1, INGROUPID="1-46001-2D", EXTGROUPID="group1@huawei.com", SHAREDID="46001-shared1", GROUPNAME="Huawei", SNSSAI="1-123456", DNN="dnn", PDUTYPES=ETHER, APPDESCRIPTORS="[{\"osId\":\"4947a69a-f61b-4bc1-b9da-47c9c5d14b64\"}\,{\"osId\":\"4947a69a-f61b-4bc1-b9da-47c9c5d14b64\"}]", SECONDARYAUTH=TRUE, AAAIPV4ADDR="10.20.30.100", AAAIPV6ADDR="2001:0db8::1234", SIMPLFIN=FALSE;
```

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如下表1所示。
