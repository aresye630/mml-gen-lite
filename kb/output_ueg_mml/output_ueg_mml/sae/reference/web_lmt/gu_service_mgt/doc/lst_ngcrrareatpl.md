# 查询NGC漫游限制区域模板(LST NGCRRAREATPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该操作用于在数据库中查询NGC漫游限制区域模板数据。

- 若需要查询全部的NGC漫游限制区域模板数据，请输入“HLR序列号”参数，其它参数不输入。
- 若需要查询某条NGC漫游限制区域模板数据，请同时输入“HLR序列号”和“模板ID”参数。

## 注意事项

- 输入“HLR序列号”查询所有的NGC漫游限制区域模板数据时，会导致PGW模块的CPU占用率升高，请在系统低话务量时执行。
- 当单条模板添加有多个NGC漫游限制区域信息时，查询或保存此模板会引起PGW模块的CPU占用率升高，请在系统低话务量时执行。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                                                                                                                                                                                                                                     |
|:-------|:-------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 可选必选说明：必选参数 参数含义：用于指示系统按照哪个HLR序列号来查询NGC漫游限制区域模板数据。 取值范围：1～255 默认值：无 配置原则：无                                                                                                                                                                                                                                                                                               |
| TPLID  | 模板ID   | 可选必选说明：可选参数 参数含义：用于指示系统按照哪个模板ID来查询NGC漫游限制区域模板数据；若不输入，则表示查询所有的模板ID。 取值范围：1～2147483646 默认值：无 配置原则：无                                                                                                                                                                                                                                                                        |
| SAVEAS | 保存文件名  | 可选必选说明：可选参数 参数含义：用于标识保存查询结果的文件名称。当单个模板的查询结果的NGC漫游限制区域信息超过999个时必须输入该参数，将查询结果保存在文件中，否则会报错“ERR4153：报文数量超过上限，需要指定保存文件名进行查询”。 取值范围：长度不超过20的字符串。 默认值：无 配置原则： “保存文件名”和“模板ID”必须同时输入。“保存文件名”参数指定的文件存放在主备PGW模块所在容器上，容器目录为“/opt/pgw/pgwtmpfile/SYSHLRSN+OPNAME”。SYSHLRSN默认为3位数字，不足3位时前面补0。如：SYSHLRSN=1，OPNAME=admin时，最后一层目录为001admin。保存文件名参数指定的文件，可以通过“PGW Web LMT”界面右上角的“文件管理器”下载。 |

## 使用实例

1.查询NGC漫游限制区域模板信息，“HLR序列号”为“1”：

```
LST NGCRRAREATPL: HLRSN=1;
```

```

---    END
```

2.查询NGC漫游限制区域模板信息，“HLR序列号”为“1”，“模板ID”为“1”：

```
LST NGCRRAREATPL: HLRSN=1, TPLID=1;
```

```
---    END
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息和相关参数，各参数含义请参见**ADD NGCRRAREATPL**命令的参数说明。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释                   | 原因分析                                | 处理建议                                                                                          |
|:--------|:------------------------|:------------------------------------|:----------------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义                   | “HLR序列号”和“模板ID”参数对应的模板数据记录不存在。      | 根据实际情况，重新输入已定义的“HLR序列号”和“模板ID”，可通过LST HLRSN命令查询已定义的“HLR序列号”，通过LST NGCRRAREATPL命令查询已定义的“模板ID”。 |
| ERR4153 | 报文数量超过上限，需要指定保存文件名进行查询。 | NGC漫游限制区域信息数量超过了999个，但未输入参数“保存文件名”。 | 输入参数“模板ID”和“保存文件名”，将查询结果保存在文件中。                                                               |
