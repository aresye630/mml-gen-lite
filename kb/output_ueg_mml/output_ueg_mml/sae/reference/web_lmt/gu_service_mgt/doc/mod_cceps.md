# 修改计费特性和EPS数据对应关系(MOD CCEPS)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于修改计费特性和EPS数据对应关系的记录。在该命令中，系统通过以下关键参数的组合来唯一标识一条计费特性和EPS数据对应关系信息：

- “HLR序列号”
- “标准计费特性”

## 注意事项

- 参数“优化GPRS模板ID”、“UE最大上行带宽”、“UE最大下行带宽”、“是否提供Diameter漫游限制业务”和“是否提供PLMN漫游限制业务”五个参数至少需要输入一个。
- 参数“是否提供Diameter漫游限制业务”取值为“FALSE”时，参数“Diameter漫游限制模板ID”不能存在。
- 参数“是否提供PLMN漫游限制业务”取值为“FALSE”时，参数“PLMN漫游限制模板ID”不能存在。

## 参数说明

| 参数标识          | 参数名称               | 参数说明                                                                                                                                                                                                                                                                                                                                                                                                         |
|:--------------|:-------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN         | HLR序列号             | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                                                                                                                                                                                                                 |
| STDCHARGE     | 标准计费特性             | 用于标识标准计费特性，实现计费特性和标准计费特性两种计费控制方式，具体的计费方式需要在网络规划的时候决定并与设备商约定在业务流程中可以识别。针对所有PDP/PDN类型都生效。 取值范围：0000～FFFF（4位十六进制数字组成的字符串） 默认值：无。 说明：如果该参数为计费特性，则取值如下：0000：不签约计费特性。0100：热计费，实时计费。0200：平计费。0400：预付费用户。0800：普通用户。0300：热计费和平计费。0500：热计费和预付费。0600：平计费和预付费。0700：热计费、平计费和预付费。0900：热计费和普通计费。0A00：平计费和普通计费。0B00：热计费、平计费和普通计费。0C00：预付费和普通计费。0D00：热计费、预付费和普通计费。0E00：平计费、预付费和普通计费。0F00：热计费、平计费、预付费和普通计费。F100～FE00：为自定义计费特性。 |
| OPTGPRSTPLID  | 优化GPRS模板ID         | 用于标识优化GPRS模板ID。该参数必须先由ADD OPTGPRSTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。                                                                                                                                                                                                                                                                                                                                      |
| AMBRMAXUL     | UE最大上行带宽           | 用于标识UE最大上行带宽，即UE最大的上传速率。 取值范围：1～4294967295，单位为bit/s 默认值：无。                                                                                                                                                                                                                                                                                                                                                   |
| AMBRMAXDL     | UE最大下行带宽           | 用于标识UE最大下行带宽，即UE最大的下载速率。 取值范围：1～4294967295，单位为bit/s 默认值：无。                                                                                                                                                                                                                                                                                                                                                   |
| PROVDIAMNODE  | 是否提供Diameter漫游限制业务 | 用于标识执行该命令是提供/修改或者撤销Diameter漫游限制业务。 取值范围：TRUE：提供/修改。FALSE：撤销。 默认值：无。                                                                                                                                                                                                                                                                                                                                          |
| DIAMNODETPLID | Diameter漫游限制模板ID   | 仅当本命令中的参数“是否提供Diameter漫游限制业务”取值为“TRUE”时，该参数有效。用于标识Diameter漫游限制模板ID。该参数必须先由ADD DIAMRRTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。                                                                                                                                                                                                                                                                                   |
| PROVPLMN      | 是否提供PLMN漫游限制业务     | 用于标识执行该命令是提供/修改或者撤销PLMN漫游限制业务。 取值范围：TRUE：提供/修改。FALSE：撤销。 默认值：无。                                                                                                                                                                                                                                                                                                                                              |
| PLMNTPLID     | PLMN漫游限制模板ID       | 仅当本命令中的参数“是否提供PLMN漫游限制业务”取值为“TRUE”时，该参数有效。用于标识PLMN区域漫游限制模板号。该参数必须先由ADD PLMNTPL命令定义，然后才能在此处引用。 取值范围：0～65534 默认值：无。                                                                                                                                                                                                                                                                                            |

## 使用实例

修改一条计费特性和EPS数据对应关系记录：“HLR序列号”为“1”，“标准计费特性”为“0800”，“优化GPRS模板ID”修改为“1”，“UE最大上行带宽”修改为“600000”，“UE最大下行带宽”修改为“200000”：

```
MOD CCEPS: HLRSN=1, STDCHARGE="0800", OPTGPRSTPLID=1, AMBRMAXUL=600000, AMBRMAXDL=200000;
```
