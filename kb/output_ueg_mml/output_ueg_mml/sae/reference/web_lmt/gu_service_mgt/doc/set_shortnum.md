# 设置短号码变换(SET SHORTNUM)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

**须知** 

本命令属于高危命令，执行该命令前，需要与华为技术支持确认后才可以实施。

此操作用于增加、删除和修改短号与长号的对应关系。

## 注意事项

- HLRSN和OPTYPE为必选参数。
- 如果OPTYPE为ADD时，SHORTNUM和LONGNUM都必须出现。
- 如果OPTYPE为MODIFY时，SHORTNUM必须出现。
- 如果OPTYPE=DELETE，参数SHORTNUM是必选，其它的参数不能出现。
- 如果OPTYPE=DELETEALL，其它的参数不能出现。
- 短号与长号的对应关系为多对一。最多可以增加1000条长、短号的对应记录。
- 同一个“HLR序列号”中增加的短号与长号对记录数不能超过1000条。

## 参数说明

| 参数标识          | 参数名称       | 参数说明                                                                                            |
|:--------------|:-----------|:------------------------------------------------------------------------------------------------|
| HLRSN         | HLR序列号     | HLR序列号，有效值域为1～255，在PGW支持容灾功能或虚拟HLR功能时设置。                                                        |
| OPTYPE        | 操作类型       | 操作类型。取值如下： ADD：增加一条记录或批增加多条记录。 MODIFY：修改一条已有记录的MAP请求消息的处理规则。 DELETE：删除一条已有记录。 DELETEALL：删除所有记录。 |
| SHORTNUM      | 短号码        | 仅当本命令中的“操作类型”参数为“ADD”、“MODIFY”或“DELETE”时该参数有效。用于标识短号码。 取值范围：1～8位的十进制数字组成的字符串。 默认值：无。            |
| SHORTNUM_NAME | 短号码名称      | 仅当本命令中的“操作类型”参数为“ADD”或“MODIFY”时该参数有效。用于标识短号码名称。 取值范围：1～16位字母或十进制数字组成的字符串。 默认值：无。                |
| FILE          | 短号码/长号码文件名 | 仅当本命令中的“操作类型”参数为“ADD”时该参数有效。用于标识文件名称。 取值范围：1～16位字母或十进制数字组成的字符串。 默认值：无。                          |
| LONGNUM       | 长号码        | 仅当本命令中的“操作类型”参数为“ADD”或“MODIFY”时该参数有效。用于标识长号码。 取值范围：1～28位的十进制数字组成的字符串。 默认值：无。                    |

## 使用实例

增加短号777与长号8675512345678之间的对应关系。命令如下：

SET SHORTNUM: HLRSN=1, OPTYPE=ADD, SHORTNUM="777", LONGNUM="8675512345678";

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                | 处理建议                                                                                                                 |
|:--------|:--------|:------------------------------------|:---------------------------------------------------------------------------------------------------------------------|
| ERR3047 | 超过最大限制  | 同一个“HLR序列号”增加的短号码与长号码对数据记录数超过1000条。 | 根据实际情况，如需增加短号码与长号码对，处理步骤如下：执行LST SHORTNUM命令，查询已存在的短号码与长号码对。执行该命令删除不必要的短号码与长号码对。执行该命令增加短号码与长号码对，确保增加的短号码与长号码对在规定范围之内。 |
