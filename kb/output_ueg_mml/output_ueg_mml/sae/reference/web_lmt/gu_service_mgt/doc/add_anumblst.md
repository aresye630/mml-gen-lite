# 增加主叫号码黑名单（ADD ANUMBLST）

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于按照MSISDN号码在UDM上设置主叫号码黑名单，只有管理员有权限对黑名单进行设置、查询和删除的操作，从而保证黑名单不会被随意更改。

当本命令中“主叫号码类型”未设置，或设置为“NUMBER”时，系统通过与**SET MAPCONF**命令中“是否支持主叫黑名单精确记录存储DSU”参数配合使用对黑名单进行添加操作。

- 当“是否支持主叫黑名单精确记录存储DSU”为“FALSE”时，系统添加新记录到DRU。
- 当“是否支持主叫黑名单精确记录存储DSU”为“TRUE”时，系统添加新记录到DSU。

主叫用户发起呼叫，当UDM接收到SRI请求消息后，会分析SRI请求消息中是否携带有主叫号码。

- 携带了主叫号码
  - 如果主叫号码在HSS配置的主叫号码黑名单中，则用户呼叫失败。
  - 否则，按照原有的呼叫流程处理。
- 未携带主叫号码，按照原有的呼叫流程处理。

## 注意事项

- 该命令仅在特定局点使用，其他局点不需要配置。
- 如果操作员增加一条主叫号码黑名单记录，将对该主叫用户的呼叫权限有影响，请操作员结合运营商的需求慎重选择。
- 最多允许添加1000条“主叫号码类型”为“PREFIX”的主叫号码黑名单记录。
- 对于“主叫号码类型”为“NUMBER”的主叫号码黑名单记录：
  - 当**SET MAPCONF**命令中“是否支持主叫黑名单精确记录存储DSU”为“FALSE”时，系统最多允许添加100000条。
  - 当**SET MAPCONF**命令中“是否支持主叫黑名单精确记录存储DSU”为“TRUE”时，系统根据申请的license进行控制允许增加的记录数，对应的License控制项为：“82200HTY LKQ7UDMBE27 DSU中主叫黑名单记录数-每黑名单记录”。
- 混合组网场景下，**SET MAPCONF**命令中“是否支持主叫黑名单精确记录存储DSU”为“TRUE”时，该命令仅支持在路由分区执行，非路由分区下执行该命令上报错误码“ERR3111:系统不支持该特性”。
- 在Global-Local或UDM+UDM混合组网中，所有UDM分区都需要申请“82200HTY LKQ7UDMBE27 DSU中主叫黑名单记录数-每黑名单记录”License控制项，vSP分区对应的该License控制项需要等待凌晨校验后才能生效。

## 参数说明

| 参数标识              | 参数名称   | 参数说明                                                                                                                                                                                                                   |
|:------------------|:-------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| HLRSN             | HLR序列号 | 用于标识一个HLR序列号。该参数必须先由ADD HLRSN命令定义，然后才能在此处引用。                                                                                                                                                                           |
| CALLINGNUMBER     | 主叫号码   | 用于标识一个待增加到黑名单中的主叫号码。在业务处理时，按照完全匹配原则进行匹配。该参数在同一“HLR序列号”中唯一，不能重复。 取值范围：1～15位的十进制数字组成的字符串。 默认值：无。 说明：主叫号码必须携带国家码前缀。                                                                                                       |
| CALLINGNUMBERTYPE | 主叫号码类型 | 用于标识增加到黑名单中的主叫号码的匹配类型。 取值范围： NUMBER：精确类型PREFIX：前缀类型 默认值：NUMBER 配置原则：主叫用户发起呼叫，UDM接收的SRI请求消息中携带了主叫号码时，如果配置了主叫号码黑名单，UDM首先使用精确匹配对主叫号码和配置的黑名单进行匹配，如果主叫号码在黑名单中，则呼叫失败，流程结束；如果主叫号码不在黑名单中，则使用前缀匹配类型进行匹配，如果主叫号码在黑名单中，则呼叫失败，流程结束。 |

## 使用实例

将主叫号码为8613310911001的号码增加到主叫号码黑名单中，参数“HLR序列号”为“1”，“主叫号码”为“8613310911001”：

```
ADD ANUMBLST: HLRSN=1, CALLINGNUMBER="8613310911001";
```
