# 批量设置紧急服务路由号码(SET HESRNBAT)

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

该操作用于在HSS的业务数据库中批量设置指定IMPU的紧急服务路由号码。

## 注意事项

- 参数IMPU和IMPUFILE只能存在一个。
- 该命令涉及批量处理用户数据，请操作人员谨慎操作。

## 参数说明

| 参数标识     | 参数名称     | 参数说明                                                                                                                                                                                                                                                                                          |
|:---------|:---------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ESRN     | 紧急服务路由号码 | 指定该IMPU的紧急服务路由号码，可以为任意字符串。 取值范围： 长度不超过127的字符串 缺省值： 无                                                                                                                                                                                                                                          |
| BATTYPE  | 批操作类型    | 指定批操作的类型，为枚举类型。 取值范围： DISCONTINUOUS(1)CONTINUOUS(5) 缺省值： 无                                                                                                                                                                                                                                    |
| IMPU     | IMPU     | 仅当本命令中的“批操作类型”参数为“CONTINUOUS”时该参数有效。用于指定一个需要设置紧急服务路由号码的IMPU，要求输入的IMPU值符合SIP URI或TEL URI格式。字母区分大小写。IMPU支持正则表达式，例如：![0-9]{4}!，正则表达式主要用于处理连续号段。正则表达式以“!”开始和结尾，正则表达式包含两个字段，第一个字段表示取值范围，此字段以“[”和“]”为开始和结尾；另一个是长度字段，表明要生成几位字段，范围是1~4。使用正则表达方式批操作时，IMPU参数中正则表达式外不能使用其它‘!’。 取值范围： 长度不超过133的字符串 缺省值： 无 |
| IMPUFILE | IMPU导入文件 | 仅当本命令中的“批操作类型”参数为“DISCONTINUOUS”时该参数有效。用于指定一个需要设置紧急服务路由号码的IMPU导入文件名。导入文件中为需要批量修改的IMPU集合，要求输入的IMPU值符合SIP URI或TEL URI格式。字母区分大小写。导入文件主要用于非连续号段。 取值范围： 长度不超过127的字符串 缺省值： 无                                                                                                                        |

## 使用实例

设置IMPU的紧急服务路由号码。紧急服务路由号码：shenzhenbantian，批操作类型：CONTINUOUS，IMPU：sip:hello![0-9]{2}!@huawei.com。

```
SET HESRNBAT: ESRN="shenzhenbantian", BATTYPE=CONTINUOUS, IMPU="sip:hello![0-9]{2}!@huawei.com";
```

设置IMPU导入文件的紧急服务路由号码。紧急服务路由号码：shenzhenbantian，批操作类型：DISCONTINUOUS，IMPU导入文件：impu.txt。IMPU导入文件中的内容如下：

tel:+2154140000

tel:+2154140033

...

tel:+2154149999

```
SET HESRNBAT: ESRN="shenzhenbantian", BATTYPE=DISCONTINUOUS, IMPUFILE="impu.txt";
```
