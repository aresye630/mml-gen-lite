# 删除IMSI用户路由数据(RMV IMSIRTSUB)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

该命令用于删除鉴权AUC中IMSI号码与HLR的对应关系。

## 注意事项

- 删除IMSI用户路由数据后，将导致KI数据不在鉴权AUC中的IMSI号码无法完成鉴权和信令转发，请谨慎操作。
- “IMSI”和“IMSI文件名”是可选参数，必须有且只能有一个参数出现。
- “用户个数”和“IMSI文件名”不能同时配置。

## 参数说明

| 参数标识        | 参数名称    | 参数说明                                                                                                                                                                                      |
|:------------|:--------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| IMSI        | IMSI    | 用于标识待删除用户路由数据的IMSI号码。 取值范围：6～15位的十进制数字组成的字符串。 默认值：无。                                                                                                                                      |
| RECORDCOUNT | 用户个数    | 用于标识待删除IMSI用户路由数据的用户个数。 当需要删除连续号码的多个用户的IMSI用户路由数据时配置该参数，配置后，系统将会从已指定的IMSI号码开始，删除连续号码的多个用户的IMSI用户路由数据。 取值范围：1～100000 默认值：无。 说明：该参数用于删除连续号码的多个用户的IMSI用户路由数据，当只有一个用户时，该参数不必配置。               |
| IMSIFILE    | IMSI文件名 | 用于标识IMSI批操作文件名称。 IMSI批操作文件包含多个不连续的待删除IMSI用户路由数据的用户IMSI号码，为文本编辑器编辑的文本文件（编码格式为ANSI），如“rmvimsirtsub.txt”，通过文件管理功能上传到指定目录，具体请参见批操作资源文件存放位置。文件格式请参见IMSIFILE文件格式。 取值范围：1～16个字母或数字组成的字符串。 默认值：无。 |

## 使用实例

删除“IMSI”为“460030913121001”的用户的路由数据：

```
RMV IMSIRTSUB: IMSI="460030913121001";
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释      | 原因分析                                                   | 处理建议                                                                                               |
|:--------|:-----------|:-------------------------------------------------------|:---------------------------------------------------------------------------------------------------|
| ERR1004 | 无效的参数值     | 参数“IMSI”的取值不是6～15位十进制数字组成的字符串。                         | 根据实际情况，重新输入“IMSI”的取值，确保其取值符合要求。                                                                    |
| ERR1009 | 参数丢失       | “IMSI”和“IMSI文件名”一个都没有输入。                               | 根据实际情况，重新输入参数，并满足“IMSI”和“IMSI文件名”必须有且只能有一个参数出现的条件。                                                 |
| ERR1005 | 文件未找到      | “IMSI文件名”对应的文件没有通过文件管理功能上传到PGW的指定目录。                   | 通过PGW Web LMT的文件上传功能上传预先编写的批操作资源文件到PGW的如下目录：“/opt/pgw/pgwtmpfile/SYSHLRSN+操作员名称”。具体请参见批操作资源文件存放位置。 |
| ERR1010 | 参数冲突       | 可能原因为如下之一：“IMSI”和“IMSI文件名”同时被输入。“用户个数”与“IMSI文件名”同时被输入。 | 根据实际情况，重新输入参数，确保满足以下两点：“IMSI”和“IMSI文件名”必须有且只能有一个参数出现。“用户个数”不能与“IMSI文件名”同时配置。                       |
| ERR1025 | 批操作文件中格式非法 | 参数“IMSI文件名”对应的批操作文件格式不正确。                              | 请根据IMSIFILE文件格式重新确定对应的批操作文件格式。                                                                     |
| ERR3007 | 记录不存在      | 参数“IMSI”对应的用户的IMSI号码与HLR的对应关系不存在或已被删除。                 | 根据实际情况，重新确定需要删除哪个IMSI用户的路由数据。可使用LST IMSIRTSUB命令查询当前存在的IMSI用户的路由数据。                                 |
