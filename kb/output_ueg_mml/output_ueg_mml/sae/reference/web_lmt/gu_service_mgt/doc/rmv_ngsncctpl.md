# 删除5G NCC模板(RMV NGSNCCTPL)

- 命令功能
- 注意事项
- 参数说明
- 使用实例
- 输出结果说明

## 命令功能

本命令用于删除已配置的5G NCC模板数据记录。

## 注意事项

无

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                     |
|:-------|:-------|:-------------------------------------------------------------------------|
| HLRSN  | HLR序列号 | 用于标识5G NCC模板数据记录的关键字段之一，用于指定需要删除哪个UDM上的NCC模板数据记录，操作员可以使用LST HLRSN命令查询获得。 |
| TPLID  | 模板ID   | 用于标识NCC模板数据记录的关键字段之一，用于指定需要删除哪个NCC模板的数据记录，操作员可以使用LST NGSNCCTPL命令查询获得。    |

## 使用实例

删除“HLR序列号”为“1”的UDM上的5G NCC模板数据记录。其中，“模板ID”为“1”：

```
RMV NGSNCCTPL: HLRSN=1, TPLID=1;
```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                                     | 处理建议                                                                                    |
|:--------|:--------|:-----------------------------------------|:----------------------------------------------------------------------------------------|
| ERR3003 | 模板未定义   | “HLR序列号”和“模板ID”对应的5G NCC模板数据记录不存在。       | 使用LST NGSNCCTPL命令查询后，重新确认要删除哪个“HLR序列号”和“模板ID”对应的5G NCC模板数据记录。                           |
| ERR3005 | 模板已经被使用 | 待删除的模板在ADD NGSPETYPE命令或SET DEFNCC命令中被引用。 | 执行LST NGSPETYPE和LST DEFNCC命令查询被引用的模板，如需继续删除，请先执行RMV NGSPETYPE或SET DEFNCC删除模板，然后执行本命令删除。 |
