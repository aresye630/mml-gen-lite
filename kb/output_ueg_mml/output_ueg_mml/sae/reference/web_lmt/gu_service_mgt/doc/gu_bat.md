## 命令功能

该命令用于执行文件批处理操作。文件批操作指通过将所有需要执行的命令写入文件中自动执行。批操作可以分为立即执行和定时执行两类。

通常将一些常用任务的操作命令或者完成特定任务的一组命令用文本形式保存，以后运行时无须再手动输入单条命令，直接执行该文本文件中的命令即可。

## 注意事项

- 批操作文件中的命令数不能超过单个批操作支持的最大命令条数。单个批操作支持的最大命令条数由软参“MAXCMDNUMPERBAT”决定。
- 在执行批操作的过程中，如果主备PGW发生双机倒换或复位，可能导致批操作详细结果文件中部分信息丢失。
- 执行定时批操作的时间点不能设置在夏令时跳变的时间段内，否则可能会造成定时批操作延期等异常。
- 可以同时执行的批操作的最大个数在10～200之间，具体个数依据PGW模块个数和单个PGW支持的最大批操作数而定。单个PGW支持的最大批操作数由软参“MAXBATNUMBER”决定。
  - 当（PGW模块个数×单个PGW支持的最大批操作数）小于10时，可以同时执行的批操作个数为10。
  - 当（PGW模块个数×单个PGW支持的最大批操作数）大于等于10且小于等于200时，可以同时执行的批操作个数为（PGW模块个数×单个PGW支持的最大批操作数）。
  - 当（PGW模块个数×单个PGW支持的最大批操作数）大于200时，可以同时执行的批操作个数为200。

  **说明** 

  批操作命令包含批操作（BAT）和导入批操作（BAT IMP）。例如可执行的批操作命令为10条，导入批操作（BAT IMP）命令执行了4条，那么批操作（BAT）命令可执行6条。
- 该命令不允许进行批操作。
- 批操作中包含涉及全局数据增加/修改/删除的命令时，为防止引起FE模块大量加载全局数据，导致全局DRU流控，请联系华为技术支持确认。全局数据命令请参见产品手册中“PGW Web LMT命令”页面。
- 批操作中包含涉及全局数据查询的命令时，为防止引起PGW模块大量加载全局数据，导致PGW流控，请联系华为技术支持确认。全局数据命令请参见产品手册中“**PGW Web LMT命令**”页面。
- 执行本命令时，将不可避免的涉及到用户的个人数据，因此您需遵循所适用国家的法律或贵公司的用户隐私政策并采取足够的措施，以确保用户的个人数据受到充分的保护，并在操作完成后及时清理结果文件。

## 参数说明

| 参数标识   | 参数名称   | 参数说明                                                                                                                                                |
|:-------|:-------|:----------------------------------------------------------------------------------------------------------------------------------------------------|
| FILE   | 文件名    | 用于标识批处理文件的名称。 批操作文件包含多个待执行的MML命令行，为文本编辑器编辑的文本文件（编码格式为ANSI），如“file.txt”，通过文件管理功能上传到指定目录，具体请参见批操作文件存放位置。 取值范围：1～128位由字母、十进制数字或“_”、“.”字符组成的字符串。 默认值：无。 |
| TIME   | 执行时间   | 用于标识执行批操作的起始时间。 取值范围：格式为“YYYY&MM&DD&HH&MM&SS”的字符串。 默认值：执行命令的当前时间。 说明：该参数为可选参数。如果参数没有提供，表示立刻执行。不要把执行定时批操作任务的时间点设置在夏令时跳变的时间段内，否则可能会造成任务延期等异常。         |

## 使用实例

操作员通过以下操作执行批操作任务。

1. 将待执行的文件通过文件上传功能上传到指定目录。
2. 执行“文件名”为“file.txt”的批操作文件，“执行时间”为“2009/06/23 10:00:00”：

   ```
   BAT: FILE="file.txt", TIME=2009&06&23&10&00&00;
   ```

## 输出结果说明

该命令执行正常，会返回命令执行成功的提示信息。

该命令执行异常，会返回对应的错误码。常见错误码如表1所示。

| 错误码     | 错误码解释   | 原因分析                             | 处理建议                             |
|:--------|:--------|:---------------------------------|:---------------------------------|
| ERR1009 | 参数丢失    | “文件名”参数是必选参数，执行该命令时未输入。          | 执行该命令时必须输入“文件名”参数。               |
| ERR1005 | 文件未找到   | “文件名”参数指示的文件未通过文件管理功能上传到指定目录。    | 通过文件管理功能将待执行的文件上传到指定目录。          |
| ERR1004 | 无效的参数值  | 界面输入的“文件名”和“执行时间”参数不在相应的参数取值范围内。 | 根据实际情况，重新输入提示错误的参数的取值，确保其取值符合要求。 |
