# 删除PLMN信息（RMV PLMN）

- 命令功能
- 注意事项
- 参数说明
- 使用实例

## 命令功能

此操作用来删除PLMN优选漫游配置。

## 注意事项

无。

## 参数说明

| 参数标识   | 参数名称    | 参数说明                                      |
|:-------|:--------|:------------------------------------------|
| HLRSN  | HLR序列号  | HLR序列号，在PGW支持容灾功能或虚拟HLR功能时设置。 取值范围：1～255。 |
| PLMNID | PLMN序列号 | PLMN序列号。 取值范围：0～999。                      |

## 使用实例

删除PLMN优选漫游配置，运营商删除HLR序列号为1，PLMN序列号为1的网络的优选漫游配置。

RMV PLMN: HLRSN=1, PLMNID=1;
